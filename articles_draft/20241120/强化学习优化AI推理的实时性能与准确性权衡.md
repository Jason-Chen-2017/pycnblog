## 第1章 核心概念与联系

### 1.1 强化学习概述
强化学习是一种通过不断试错和反馈来学习如何在不同环境中做出最佳决策的人工智能方法。它与传统的监督学习和无监督学习不同，其核心在于奖励机制和探索-利用策略。

### 1.2 AI推理性能与准确性权衡
AI推理性能通常以响应时间和吞吐量来衡量，而准确性则关注模型预测结果的正确率。在实时应用中，性能与准确性之间存在权衡，优化一个方面往往会影响另一个方面。

## 第2章 强化学习基础

### 2.1 强化学习基本原理
强化学习通过一个智能体与环境之间的交互来学习最优策略，使用奖励信号来指导学习过程。

### 2.2 强化学习算法类型
强化学习算法可分为值函数方法（如Q-learning）和政策梯度方法（如SARSA和DQN）。

### 2.3 Q-learning算法原理与伪代码
$$
Q(s, a) = Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]
$$
伪代码：
```
初始化 Q(s, a)
for each episode:
  选择动作 a
  执行动作，获得奖励 r 和下一个状态 s'
  更新 Q(s, a) 的估计值
```

### 2.4 SARSA算法原理与伪代码
$$
(s, a, r, s', a') \to (s, a', r + \gamma Q(s', a'))
$$
伪代码：
```
初始化 Q(s, a)
for each episode:
  选择动作 a
  执行动作，获得奖励 r 和下一个状态 s'
  选择动作 a' 根据 ε-贪心策略
  更新 Q(s, a) 的估计值
```

### 2.5 DQN算法原理与伪代码
$$
Q(s, a) = r + \gamma \max_{a'} Q(s', a')
$$
伪代码：
```
初始化 Q(s, a)
创建经验池
for each episode:
  选择动作 a
  执行动作，获得奖励 r 和下一个状态 s'
  存储经验 (s, a, r, s', a') 到经验池
  使用经验池中的经验进行更新 Q(s, a)
```
