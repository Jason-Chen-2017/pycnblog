## 第1章：哲学的本质与价值

### 1.1 哲学的定义与历史背景

哲学，一词源于希腊语的 "philosophia"，意为“爱智慧”。它是一门探讨存在、知识、价值、理性、心灵、语言等基本问题的学科。哲学的历史可以追溯到古希腊，亚里士多德、柏拉图、苏格拉底等哲学家的思想至今仍然影响着我们。

#### Mermaid 流程图：哲学发展历程

```mermaid
A[起源] --> B[古希腊哲学]
B --> C[中世纪哲学]

```

### 1.2 哲学的主要分支

哲学的主要分支包括形而上学、认识论、伦理学、逻辑学、政治哲学和美学。每个分支都有其独特的核心问题和研究方法。

#### Mermaid 流程图：哲学主要分支
```mermaid

B --> C[伦理学]

```
