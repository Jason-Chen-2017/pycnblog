## 数学模型和数学公式讲解
### 3.1 词嵌入模型
词嵌入模型是将词汇映射到高维空间中的过程。一个简单的词嵌入模型可以使用以下公式表示：

$$
x_i = W * e_{word_i}
$$

其中，$x_i$ 是词汇 $word_i$ 的嵌入向量，$W$ 是词嵌入矩阵，$e_{word_i}$ 是词汇 $word_i$ 的原始向量表示。

### 3.2 Transformer模型
Transformer模型的核心是自注意力机制。自注意力机制通过计算序列中每个元素与所有其他元素之间的相似性来生成加权表示。以下是一个自注意力的数学公式：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

其中，$Q$ 是查询向量，$K$ 是键向量，$V$ 是值向量，$d_k$ 是键向量的维度。

### 3.3 BERT模型
BERT模型的训练目标包括Masked Language Model（MLM）和Next Sentence Prediction（NSP）。MLM的目标是预测被遮盖的词汇，NSP的目标是预测两个句子是否是连续的。以下是一个MLM的目标函数的公式：

$$
\log P(y=word_i | x) = \log \frac{\exp(e_{word_i}^T W_o v)}{\sum_{j=1}^{V} \exp(e_{word_j}^T W_o v)}
$$

其中，$e_{word_i}$ 是词汇 $word_i$ 的嵌入向量，$W_o$ 是输出层权重，$v$ 是预测层激活值，$V$ 是词汇表大小。

### 3.4 举例说明
假设我们有一个包含词汇表{“猫”，“狗”，“鼠”}的小规模BERT模型，输入序列是“猫吃__”，遮盖的词汇是“狗”。根据MLM目标函数，我们需要计算：

$$
\log P(y=\text{狗} | x) = \log \frac{\exp(e_{\text{狗}}^T W_o v)}{\exp(e_{\text{猫}}^T W_o v) + \exp(e_{\text{鼠}}^T W_o v)}

```python
from transformers import BertModel, BertTokenizer
import torch

# 加载预训练的BERT模型和分词器
model = BertModel.from_pretrained('bert-base-uncased')
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

# 输入序列，这里以“药物A”为例
input_sequence = "药物A"

# 分词和编码
encoded_input = tokenizer.encode(input_sequence, add_special_tokens=True)

# 转换为Tensor
input_tensor = torch.tensor(encoded_input).unsqueeze(0)

# 通过BERT模型生成药物分子
with torch.no_grad():
    outputs = model(input_tensor)

# 提取生成的分子序列
drug_sequence = outputs[0][0][-1:].numpy()

# 解码为文本
drug_name = tokenizer.decode(drug_sequence, skip_special_tokens=True)

print(drug_name)
```
