  ```plaintext

  accuracy = (TP + TN) / (TP + TN + FP + FN)

  // 召回率
  recall = TP / (TP + FN)

  // F1值
  F1 = 2 * (precision * recall) / (precision + recall)

  // BLEU
  BLEU = \sum_{i=1}^{N} \frac{|G|}{|P|^i} \log_2 \left(\frac{|P|}{|G|}\right)
  ```
