# 第1章 格雷厄姆价值投资理念概述

## 1.1 格雷厄姆及其投资理念的起源

### 1.1.1 本杰明·格雷厄姆的生平简介
本杰明·格雷厄姆（Benjamin Graham）是20世纪著名的投资学家，被誉为“价值投资之父”。他出生于1894年，早年在哥伦比亚大学学习，后来进入华尔街工作，逐渐发展出一套独特的投资理论。

### 1.1.2 价值投资理念的核心思想
格雷厄姆的核心思想是“安全第一”。他认为，投资者应以低于内在价值的价格购买优质股票，以确保投资的安全性和稳定性。他强调长期投资和复利效应的重要性。

### 1.1.3 格雷厄姆投资理念的演变与影响
格雷厄姆的投资理念影响了后来的许多投资大师，如沃伦·巴菲特。他的著作《证券分析》和《聪明的投资者》奠定了价值投资的基础。

---

## 1.2 价值投资的基本原则

### 1.2.1 投资的定义与目标
投资的目标是通过长期持有优质资产，实现财富的稳步增长。格雷厄姆强调，投资不同于投机，投资者应注重基本面分析，而非短期价格波动。

### 1.2.2 安全边际的概念与重要性
安全边际是指股票的市场价格低于其内在价值的部分。通过购买具有安全边际的股票，投资者可以降低风险，确保投资的安全性。

### 1.2.3 内在价值的计算与市场定价
内在价值是基于公司基本面（如盈利能力、财务状况等）计算出的合理价格。市场定价可能偏离内在价值，投资者应寻找价格低于内在价值的股票。

---

## 1.3 格雷厄姆的价值投资策略

### 1.3.1 购买低于内在价值的股票
格雷厄姆建议投资者购买那些市场价格低于内在价值的股票，以确保投资的安全性。

### 1.3.2 避免短期市场波动的影响
他强调长期投资的重要性，建议投资者忽略短期价格波动，专注于长期价值。

### 1.3.3 长期投资与复利效应
通过长期持有优质资产，投资者可以享受复利效应，实现财富的稳步增长。

# 第3章 格雷厄姆价值投资理念的核心概念与联系

## 3.1 核心概念原理

### 3.1.1 安全边际的数学模型
安全边际计算公式为：
$$ M = V - P $$
其中，$M$ 为安全边际，$V$ 为内在价值，$P$ 为市场价格。

### 3.1.2 内在价值的计算公式
内在价值计算公式为：
$$ V = \frac{E}{P} $$
其中，$E$ 为预期收益，$P$ 为折现率。

### 3.1.3 市场定价与投资决策的关系
市场定价可能偏离内在价值，投资者应根据价格与价值的偏离程度做出投资决策。

---

## 3.2 核心概念对比分析

### 3.2.1 安全边际与风险控制的对比
安全边际通过降低价格风险，而风险控制则通过分散投资降低整体风险。

### 3.2.2 内在价值与市场价值的对比
内在价值基于基本面分析，而市场价值反映市场情绪。

### 3.2.3 投资策略与市场环境的对比
不同市场环境下，投资策略需要进行调整。

## 6.2 系统核心实现源代码

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(eps, peg):
    return eps / peg

def calculate_margin_of_safety(intrinsic_value, price):
    return intrinsic_value - price

# 示例数据
data = {
    '公司': ['A公司', 'B公司', 'C公司'],
    'eps': [10, 15, 20],
    'peg': [1.5, 1.2, 1.0],
    '价格': [50, 60, 70]
}

df = pd.DataFrame(data)

# 计算内在价值和安全边际
df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['eps'], x['peg']), axis=1)
df['安全边际'] = df.apply(lambda x: calculate_margin_of_safety(x['内在价值'], x['价格']), axis=1)

print(df)
```
