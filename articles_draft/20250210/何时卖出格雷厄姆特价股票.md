## 第三部分：技术分析算法

### 第3章：技术分析算法的应用

#### 3.1 移动平均线算法

移动平均线通过计算一定时期内的平均价格，过滤短期波动，反映长期趋势。常用的方法包括简单移动平均线（SMA）和指数移动平均线（EMA）。

```mermaid

    C --> D[比较当前价格与MA]
    D --> E[生成买卖信号]
    E --> F[结束]
```

#### 3.2 相对强弱指数（RSI）算法

RSI衡量价格在特定时期内的超买或超卖状态，通常在0-100之间。RSI低于30表示超卖，高于70表示超买。

```python
import pandas as pd
import numpy as np

def calculate_rsi(df, period=14):
    # 计算相对强弱指数
    close = df['收盘价']
    delta = close.diff()
    up = delta.where(delta > 0, 0)
    down = delta.where(delta < 0, 0)
    avg_up = up.rolling(period).mean()
    avg_down = down.rolling(period).mean()
    rsi = 100 - (100 - (avg_up / avg_down))
    return rsi

# 示例数据
data = {'收盘价': [100, 102, 101, 103, 104, 105]}
df = pd.DataFrame(data)
rsi = calculate_rsi(df)
print(rsi)
```

#### 3.3 数学模型

移动平均线公式：

$$ SMA = \frac{1}{n} \sum_{i=1}^{n} P_i $$

指数移动平均线公式：

$$ EMA = P_t + \alpha (P_t - EMA_{t-1}) $$

其中，$\alpha = \frac{2}{n+1}$，$n$为周期数。
