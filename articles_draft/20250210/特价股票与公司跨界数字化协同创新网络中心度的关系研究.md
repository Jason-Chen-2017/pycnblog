##### 3.3 Python代码实现
```python
import networkx as nx

def calculate_centralities(G):
    degree_cent = nx.degree_centrality(G)
    between_cent = nx.betweenness_centrality(G)
    closeness_cent = nx.closeness_centrality(G)
    return degree_cent, between_cent, closeness_cent

# 示例网络
G = nx.Graph()
G.add_edges_from([('A', 'B'), ('B', 'C'), ('C', 'D'), ('D', 'E')])
degree_cent, between_cent, closeness_cent = calculate_centralities(G)

print("度中心度:", degree_cent)
print("中间中心度:", between_cent)
print("接近中心度:", closeness_cent)
```

##### 3.4 数学模型与公式
- 度中心度公式：
  $$ degree\_centrality(i) = \frac{1}{\sum_{j} A_{ij}} $$
- 中间中心度公式：
  $$ betweenness\_centrality(i) = \sum_{j > i} \frac{g_{ik} - g_{ik|j}}{g_{ik}} $$
- 接近中心度公式：
  $$ closeness\_centrality(i) = \frac{1}{\sum_{j} d(i,j)} $$
