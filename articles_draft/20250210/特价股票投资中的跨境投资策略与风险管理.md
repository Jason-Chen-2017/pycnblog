| **術語**       | **定義**                                                                 |
|----------------|-------------------------------------------------------------------------|

- **邊界**: 縮制在股票市場，不涉及其他金融工具（如債券、金屬等）。

## 第二部分: 核心概念與理論

### 第2章: 核心概念原理

#### 2.1 投資組合理論

- **Markowitz投資組合理論**: 
  - 核心思想: 投資者應該基於風險承受能力選擇最優投資組合。
  - 公式: 
    $$ E(r_p) = \sum w_i E(r_i) $$
    $$ Var(r_p) = \sum w_i^2 Var(r_i) + \sum w_i w_j Cov(r_i, r_j) $$

#### 2.2 股票估值模型

- **CAPM模型**: 
  - 公式: 
    $$ r_i = r_f + \beta_i (r_m - r_f) $$
  - 解釋: 股票回報率由無風險回報率和市場風險溢价決定。

#### 2.3 跨市風險評估

- **汇率風險模型**: 
  - 公式: 
    $$ \text{匯率波動} = \sqrt{\sigma_{domestic}^2 + \sigma_{foreign}^2 - 2\rho \sigma_{domestic}\sigma_{foreign}} $$
  - 解釋: 市場之間的相關性影響整體風險。

## 第三部分: 算法原理與實現

### 第4章: 算法原理

#### 4.1 股票估值算法

- **算法步驟**:
  1. 收集目標股票的基本數據（價格、成交量、財務數據）。
  2. 使用CAPM模型計算理論價值。
  3. 比較市場價格與理論價值，確定是否為特价股票。

#### 4.2 算法實現

```python
import pandas as pd
import numpy as np

def calculate_expected_return(risk_free_rate, beta, market_return):
    return risk_free_rate + beta * (market_return - risk_free_rate)

# 示例數據
risk_free_rate = 0.02
beta = 1.5
market_return = 0.1

expected_return = calculate_expected_return(risk_free_rate, beta, market_return)
print(f"預期回報率: {expected_return:.2f}")
```

import pandas as pd
import numpy as np

def calculate_beta(stocks_returns, market_returns):
    # 計算回報率的平均值
    mean_market = np.mean(market_returns)
    mean_stocks = np.mean(stocks_returns)
    # 計算回報率與市場回報率的協方差
    covariance = np.cov(stocks_returns, market_returns)[0,1]
    # 計算市場回報率的方差
    market_variance = np.var(market_returns)
    beta = covariance / market_variance
    return beta

# 示例數據
stocks_returns = [0.1, 0.05, 0.15, 0.08]
market_returns = [0.12, 0.07, 0.10, 0.09]

beta = calculate_beta(stocks_returns, market_returns)
print(f"Beta值: {beta:.2f}")
