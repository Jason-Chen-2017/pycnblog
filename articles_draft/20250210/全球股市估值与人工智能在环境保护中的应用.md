# 第2章: 全球股市估值的基本概念

## 2.1 股市估值的定义与分类

### 2.1.1 股市估值的基本定义
- 股市估值是通过分析企业财务数据和市场因素，评估其内在价值。

### 2.1.2 股市估值的主要分类
- 市盈率法、市净率法、股息率法等。

### 2.1.3 股市估值的核心要素
- 营收、利润、现金流、行业地位等。

## 2.2 传统股市估值方法

### 2.2.1 市盈率法
- 市盈率 = 股价 / 每股收益。
- 示例：某公司股价为50元，每股收益为5元，市盈率为10倍。

### 2.2.2 市净率法
- 市净率 = 股价 / 每股净资产。
- 示例：某公司股价为30元，每股净资产为10元，市净率为3倍。

### 2.2.3 股息率法
- 股息率 = 每股股息 / 股价。
- 示例：某公司股息为2元，股价为20元，股息率为10%。
