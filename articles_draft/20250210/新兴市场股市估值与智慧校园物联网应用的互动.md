##### 5.2 核心代码实现
- 服务器端代码：
  ```python
  from flask import Flask, jsonify
  import requests
  
  app = Flask(__name__)
  
  @app.route('/get_stock_price', methods=['GET'])
  def get_stock_price():
      # 获取物联网设备数据
      device_data = requests.get('http://iot_device:8080/data').json()
      # 返回股票价格
      return jsonify({'price': device_data['price']})
  
  if __name__ == '__main__':
      app.run(debug=True)
  ```
