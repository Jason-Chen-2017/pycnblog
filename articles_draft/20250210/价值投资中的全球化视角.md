### 附录B：数学模型与公式

- DCF模型公式：
  $$ V = \sum_{t=1}^n \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n} $$
- 市盈率（P/E）公式：
  $$ P/E = \frac{市价}{每股收益} $$

import pandas as pd
import numpy as np

# 示例：计算苹果公司的市盈率
def calculate_pe_ratio(stock_price, earnings_per_share):
    return stock_price / earnings_per_share

# 数据输入
stock_price = 150  # 假设苹果股价为150美元
earnings_per_share = 2.5  # 假设每股收益为2.5美元

# 计算市盈率

print(f"市盈率为：{pe_ratio}")
