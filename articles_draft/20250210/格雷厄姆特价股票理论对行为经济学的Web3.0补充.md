## # 第二部分：格雷厄姆特价股票理论基础

### ## 第2章：格雷厄姆理论的核心要素

#### ### 2.1 核心概念与属性
- **安全边际**：投资价格低于内在价值的部分。
- **内在价值**：未来现金流的现值。

#### ### 2.2 格雷厄姆理论的数学模型
$$
\text{内在价值} = \sum_{t=1}^{n} \frac{C_t}{(1+r)^t}
$$
其中，$C_t$为第t年的现金流，$r$为折现率。

#### ### 2.3 格雷厄姆与现代投资理论的对比
| 理论 | 格雷厄姆 | 现代投资组合理论 |
|------|----------|------------------|
| 核心 | 价值投资 | 多元化与风险分散 |

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

# 数据预处理
data = pd.read_csv('投资者情绪.csv')
X = data.drop('情绪', axis=1)
y = data['情绪']

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 建立决策树模型
model = DecisionTreeClassifier()
model.fit(X_train, y_train)

# 预测测试集
y_pred = model.predict(X_test)
print("准确率：", model.score(X_test, y_test))
```
