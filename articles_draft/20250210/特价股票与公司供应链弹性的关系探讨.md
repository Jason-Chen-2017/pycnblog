# 第1章 特价股票与供应链弹性的背景介绍

## 1.1 特价股票的定义与背景
### 1.1.1 特价股票的定义
特价股票通常指价格相对较低的股票，通常具有较高的波动性和潜在的高回报。这类股票通常来自中小型企业或处于困境中的企业。

### 1.1.2 特价股票的市场背景
特价股票在市场波动较大时更受关注，投资者希望通过低价买入，高价卖出。然而，这类股票的风险较高，需谨慎评估。

### 1.1.3 特价股票的投资价值分析
特价股票可能因公司重组或转机而价值上升，但也可能因业绩不佳而继续下跌。投资者需分析公司基本面。

## 1.2 供应链弹性的定义与特点
### 1.2.1 供应链弹性的定义
供应链弹性指企业在供应链中断或需求变化时的适应能力，确保业务连续性。

### 1.2.2 供应链弹性的核心特点
包括灵活性、响应速度、冗余能力、协作能力等。

### 1.2.3 供应链弹性与企业竞争力的关系
供应链弹性强的企业能更快适应市场变化，提升竞争力。

## 1.3 特价股票与供应链弹性关系的背景
### 1.3.1 特价股票与供应链弹性关联性
供应链弹性影响企业业绩，进而影响股价。特价股票可能因供应链弹性问题而波动。

### 1.3.2 供应链弹性对股价波动的影响
供应链弹性差可能导致股价下跌，而弹性好则可能支撑股价。

### 1.3.3 研究意义
理解两者关系有助于投资者优化策略，企业提升供应链管理。

## 1.4 本章小结
本章介绍了特价股票和供应链弹性，及其关系的重要性，为后续分析奠定基础。

# 计算供应链弹性指数
def calculate_sei(data):
    weights = [0.4, 0.3, 0.2, 0.1]
    features = ['supply_chain', 'inventory', 'logistics', 'supplier']
   sei = 0
    for i in range(len(weights)):
        sei += weights[i] * data[features[i]]
    sei = sei / sum(weights)
    return sei

sei = calculate_sei(data)
