### 第2章：格雷厄姆理论的核心概念解析

本章节将详细分析格雷厄姆理论的核心概念，包括安全边际、内在价值和股票市场的非理性波动，并通过对比分析，展示这些概念在数字平台协同经济产业中的具体应用。

**2.1 核心概念原理**

- **安全边际**：如何计算安全边际
  - 公式：$ \text{安全边际} = \frac{\text{内在价值} - \text{市场价格}}{\text{市场价格}} $
  - 示例：假设一只股票的内在价值为$50，市场价格为$40，则安全边际为$50 - $40 = $10，安全边际率为25%。
- **内在价值**：如何计算内在价值
  - 公式：$ V = \frac{E}{P} $，其中$E$为未来现金流的现值，$P$为折现率。
  - 示例：假设某公司的未来现金流现值为$1000，折现率为10%，则内在价值为$1000 / 1.1 = $909.09。
- **股票价格波动**：如何利用非理性波动获利
  - 波动性分析：市盈率、市净率、股息率的波动
  - 示例：在数字平台协同经济产业中，如何通过市盈率的波动找到被低估的股票。

import pandas as pd
import numpy as np

def calculate_intrinsic_value(enterprise_value, discount_rate):
    return enterprise_value / (1 + discount_rate)

def calculate_margin_of_safety(intrinsic_value, market_price):
    return (intrinsic_value - market_price) / market_price

# 示例数据
data = {
    '股票代码': ['A', 'B', 'C'],
    '企业价值': [1000, 1200, 1500],
    '市场价格': [900, 1000, 1200],
    '折现率': [0.1, 0.1, 0.1]
}

df = pd.DataFrame(data)

# 计算内在价值和安全边际
df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['企业价值'], x['折现率']), axis=1)
df['安全边际'] = df.apply(lambda x: calculate_margin_of_safety(x['内在价值'], x['市场价格']), axis=1)
