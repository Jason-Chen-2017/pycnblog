### 第3章: 核心算法与模型

#### 3.1 时间序列预测模型
- 3.1.1 ARIMA模型
  - 原理：ARIMA（自回归积分滑动平均模型）通过捕捉数据的自相关性和趋势性来预测未来值。
  - 优缺点：适合线性趋势，但对非线性数据表现较差。
  - 示例代码：
    ```python
    from statsmodels.tsa.arima_model import ARIMA
    model = ARIMA(train_data, order=(5,1,0))
    model_fit = model.fit()
    ```

- 3.1.2 LSTM网络
  - 原理：LSTM（长短期记忆网络）通过细胞状态和门控机制处理长序列数据。
  - 优缺点：适合处理非线性数据，但训练时间较长。
  - 示例代码：
    ```python
    from keras.layers import LSTM, Dense
    model = Sequential()
    model.add(LSTM(50, input_shape=(timesteps, features)))
    model.add(Dense(1))
    model.compile(optimizer='adam', loss='mean_squared_error')
    ```

#### 3.2 机器学习与深度学习模型
- 3.2.1 机器学习模型
  - 使用随机森林和梯度提升树（如XGBoost）进行交通流量预测。
- 3.2.2 深度学习模型
  - 使用卷积神经网络（CNN）处理空间数据，如交通监控图像。
