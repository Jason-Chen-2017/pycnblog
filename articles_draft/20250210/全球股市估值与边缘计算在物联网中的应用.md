### 第2章：全球股市估值的核心概念

#### 2.1 股市估值的原理与方法

- **市盈率（P/E）**：计算公式为P/E = 市场价/每股收益。市盈率反映了投资者对公司未来盈利能力的预期。
- **市净率（P/B）**：计算公式为P/B = 市场价/每股净资产。市净率适用于评估资产密集型企业的价值。
- **股东权益回报率（ROE）**：计算公式为ROE = 净利润/平均股东权益。ROE衡量了公司使用股东资金的效率。

#### 2.2 全球股市估值的关键影响因素

- **宏观经济因素**：GDP增长率、利率水平、通货膨胀率等宏观经济指标直接影响股市估值。
- **行业因素**：行业周期、竞争格局、政策法规等影响特定行业的估值。
- **公司基本面因素**：盈利能力、财务状况、管理团队等影响公司的股票价值。

#### 2.3 股市估值与边缘计算的关系

- **实时性**：边缘计算能够在数据产生的源头立即处理，确保股市数据的实时性。
- **数据隐私**：边缘计算减少了数据传输到云端的过程，保护了数据隐私，符合金融行业的严格要求。
- **效率提升**：边缘计算通过分布式处理，提高了数据处理的效率，使股市估值更加迅速和准确。

### 第3章：边缘计算的核心原理

#### 3.1 边缘计算的定义与特点

- **定义**：边缘计算是在数据源附近进行数据处理和存储，减少对云端的依赖。
- **特点**：实时性高、低延迟、数据隐私好、分布式架构。

#### 3.2 边缘计算的体系结构

- **层次结构**：边缘计算通常分为边缘设备层、边缘节点层和云端层。
- **分工与协作**：边缘设备负责数据采集，边缘节点进行数据处理和分析，云端提供数据存储和长期分析。
- **通信协议**：常用MQTT、HTTP等协议进行数据传输，确保数据的可靠性和实时性。

#### 3.3 边缘计算的关键技术

- **数据采集与处理技术**：使用传感器、IOT设备进行数据采集，并通过边缘节点进行初步处理。
- **边缘智能与机器学习**：利用机器学习模型在边缘设备上进行实时预测和分析。
- **边缘安全与隐私保护**：通过加密技术、访问控制等手段，确保边缘设备和数据的安全。

```python
import paho.mqtt.client as mqtt
import json

# 连接 MQTT 代理
client = mqtt.Client()
client.connect("localhost", 1883, 60)

# 定义股票数据
stock_data = {
    "stock_code": "AAPL",
    "price": 150.25,
    "volume": 1000
}

# 发布股票数据到主题
client.publish("stock_data", json.dumps(stock_data), qos=1)

# 接收股票数据
def on_message(client, userdata, msg):
    data = json.loads(msg.payload)
    print(f"Received stock data: {data}")

client.on_message = on_message
client.loop_start()
```
