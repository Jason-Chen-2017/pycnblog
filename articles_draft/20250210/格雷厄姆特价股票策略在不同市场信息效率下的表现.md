## 第一部分: 格雷厄姆特价股票策略概述

### 第1章: 格雷厄姆特价股票策略的核心概念

#### 1.1 价值投资的背景与发展
- 1.1.1 价值投资的起源与发展
  - 价值投资理念起源于20世纪初，由本杰明·格雷厄姆和戴维德·多德提出。
  - 格雷厄姆的学生彼得·林奇和沃伦·巴菲特继承并发展了这一理论。
  - 价值投资的核心在于寻找市场价格低于内在价值的股票。

- 1.1.2 格雷厄姆投资理念的核心思想
  - **安全边际**：买入价格低于内在价值的股票，以降低投资风险。
  - ** Margin of Safety**: 格雷厄姆提出的核心概念，确保投资者在买入时留有安全空间。
  - **内在价值计算**：通过基本面分析，计算股票的真正价值，而非依赖市场价格。

- 1.1.3 特价股票策略的定义与目标
  - **特价股票策略**：通过分析公司基本面，寻找市场价格低于内在价值的股票。
  - **目标**：在控制风险的前提下，实现长期稳定的投资收益。

#### 1.2 市场信息效率的基本概念
- 1.2.1 市场信息效率的定义
  - 市场信息效率衡量的是市场价格反映所有相关信息的程度。
  - 高效市场：价格反映所有信息；低效市场：价格反映部分信息。

- 1.2.2 市场信息效率的分类与特征
  - **低效市场**：信息传播不充分，市场参与者获取信息有限。
  - **中度有效市场**：信息传播较快，但市场反应存在滞后。
  - **高度有效市场**：信息迅速反映在价格中，市场参与者难以找到定价错误。

- 1.2.3 市场信息效率与股票定价的关系
  - 信息效率越高，股票定价越合理，市场越难找到低估股票。
  - 信息效率低，存在定价错误，为价值投资者提供机会。

### 第2章: 格雷厄姆特价股票策略的理论基础

#### 2.1 价值投资与市场有效性的关系
- 2.1.1 价值投资的基本假设
  - 市场价格与内在价值存在差异，这种差异为投资机会。
  - 市场短期波动，但长期趋向于反映内在价值。

- 2.1.2 市场有效性对价值投资的影响
  - 高效市场：价值投资机会减少，难以找到低估股票。
  - 低效市场：价值投资机会增加，策略表现更优。

- 2.1.3 格雷厄姆策略在不同市场环境下的适用性
  - 在低效市场中，策略表现较好。
  - 在高效市场中，策略表现受限，需调整策略。

#### 2.2 格雷厄姆策略的核心原则
- 2.2.1 安全边际的定义与计算
  - 安全边际 = 内在价值 - 市场价格。
  - 股票价格应低于其内在价值的一定比例。

- 2.2.2 股票内在价值的评估方法
  - 股票内在价值 = 股东权益 + 长期债务 - 短期债务。
  - 使用市盈率、市净率等指标进行估值。

- 2.2.3 避免情绪化投资的重要性
  - 投资决策应基于理性分析，而非市场情绪。
  - 避免追涨杀跌，坚持价值投资理念。

### 第4章: 格雷厄姆策略的数学模型与算法

#### 4.1 格雷厄姆策略的数学模型
- 4.1.1 内在价值的计算公式
  - 内在价值 = 股东权益 + 长期债务 - 短期债务。
  - 内在价值 = E + L - S，其中E为股东权益，L为长期债务，S为短期债务。

- 4.1.2 安全边际的数学表达
  - 安全边际 = 内在价值 - 市场价格。
  - SM = V - P，其中V为内在价值，P为市场价格。

- 4.1.3 市场价格与内在价值的对比分析
  - 当P < V时，股票被低估。
  - 当P ≈ V时，市场效率高，机会减少。

def calculate_intrinsic_value(equity, long_debt, short_debt):
    return equity + long_debt - short_debt

def calculate_margin_of Safety(price, intrinsic_value):
    return intrinsic_value - price

def graham_strategy screener(stocks, margin_of_safety_threshold):
    selected_stocks = []
    for stock in stocks:
        iv = calculate_intrinsic_value(stock.equity, stock.long_debt, stock.short_debt)
        mos = calculate_margin_of_Safety(stock.price, iv)
        if mos > margin_of_safety_threshold:
