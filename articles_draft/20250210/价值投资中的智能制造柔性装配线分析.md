### 3.2 数学模型

#### 成本模型
$$C = a \cdot Q + b$$
其中：
- \( C \) 表示总成本
- \( Q \) 表示产量
- \( a \) 表示单位成本
- \( b \) 表示固定成本

#### 效率模型
$$E = \frac{P}{Q}$$
其中：
- \( E \) 表示效率
- \( P \) 表示生产量
- \( Q \) 表示投入资源

### 5.2 核心代码实现

```python
def calculate_cost(quantity):
    fixed_cost = 100000
    variable_cost = 50
    return fixed_cost + variable_cost * quantity

def calculate_efficiency(production):
    return production / (production + production * 0.1)

# 示例计算
quantity = 1000
cost = calculate_cost(quantity)
efficiency = calculate_efficiency(1000)
print(f"成本: {cost}$, 效率: {efficiency:.2f}%")
```
