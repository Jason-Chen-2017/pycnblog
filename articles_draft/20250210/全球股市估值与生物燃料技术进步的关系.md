### 2.1 回归模型实现

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

data = pd.read_csv('bi燃料数据.csv')
X = data[['技术成熟度', '研发投入']]
y = data['股价']

model = LinearRegression()
model.fit(X, y)
预测值 = model.predict(X)
print(mean_squared_error(y, 预测值))
```
