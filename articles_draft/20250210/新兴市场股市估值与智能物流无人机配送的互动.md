股市估值与无人机配送效率的相关性模型：

$$ r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}} $$

其中，$r$为相关系数，$x$为股市估值，$y$为配送效率。

### 4.3 Python代码实现

```python
import numpy as np

def calculate_correlation(stock_valuation, delivery_efficiency):
    x = np.array(stock_valuation)
    y = np.array(delivery_efficiency)
    covariance = np.cov(x, y)[0, 1]
    std_deviation_x = np.std(x)
    std_deviation_y = np.std(y)
    correlation = covariance / (std_deviation_x * std_deviation_y)
    return correlation

stock_valuation = [10, 15, 20, 25, 30]
delivery_efficiency = [80, 70, 60, 50, 40]

correlation = calculate_correlation(stock_valuation, delivery_efficiency)
print(f"相关系数为：{correlation}")
```
