## 第1章：价值投资与区块链时代的结合

### 1.1 格雷厄姆价值投资理念概述  
格雷厄姆是价值投资的鼻祖，他提出的“安全边际”和“内在价值”理论为现代投资学奠定了基础。  

#### 核心概念：  
- **安全边际**：指资产的内在价值与市场价格之间的差距，确保投资的安全性。  
- **内在价值**：资产在理性分析下所能体现的真实价值。  

#### 区块链特点：  
- **分布式账本**：确保数据的透明性和不可篡改性。  
- **智能合约**：通过代码自动执行合约条款，降低信任成本。  
- **通证经济**：将资产转化为可流通的数字通证，提升资产流动性。

```python
# 部署智能合约
contract_address = w3.toChecksumAddress('0x...')  # 替换为实际地址
contract_abi = [  # 替换为实际ABI
    {
        "constant": false,
        "inputs": [],
        "name": "buy_asset",
        "outputs": [],
        "payable": true,
        "stateMutability": "payable",
        "type": "function"
    }
]

contract = w3.eth.contract(contract_address, abi=contract_abi)

# 调用智能合约
tx_hash = contract.functions.buy_asset().transact({'from': w3.eth.defaultAccount, 'gas': 100000})
receipt = w3.eth.waitForTransactionReceipt(tx_hash)
```
