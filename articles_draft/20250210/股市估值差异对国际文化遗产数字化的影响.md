## 第三部分：算法原理讲解

### 第4章：模型构建

#### 4.1 回归模型：股市波动对数字化项目的影响
- 模型：$$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \epsilon $$
  - $y$：文化遗产数字化项目的成功率
  - $x_1$：股市波动指数
  - $x_2$：项目资金投入
  - $\epsilon$：误差项

#### 4.2 数字化项目成本-收益分析
- 成本模型：$$ C = a + b \times \text{数字化技术复杂度} $$
- 收益模型：$$ R = c + d \times \text{市场覆盖范围} $$

#### 4.3 算法实现
```python
import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据准备
data = pd.DataFrame({
    'StockVolatility': [0.2, 0.3, 0.1, 0.4],
    'ProjectFunding': [100, 200, 150, 300],
    'SuccessRate': [0.6, 0.7, 0.5, 0.8]
})

# 建模
model = LinearRegression()
model.fit(data[['StockVolatility', 'ProjectFunding']], data['SuccessRate'])

# 预测
print(model.predict([[0.25, 250]]))
```
