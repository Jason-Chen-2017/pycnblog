特价股票指的是市场价格低于其内在价值的股票，通常被视为投资机会。公司股东积极主义则指股东主动参与公司治理，推动变革以实现自身利益最大化。两者看似独立，但实际市场中，股东积极主义可能影响公司股价，进而影响特价股票的出现。

## 第2章：核心概念与联系

### 2.1 特价股票的原理  
特价股票的定价受市场情绪、公司基本面和投资者行为影响。投资者利用低估值机会，推动股价回归合理水平。

### 2.2 股东积极主义的原理  
股东通过提案、投票等方式影响公司决策，提升公司价值，进而影响股价。

### 2.3 两者关联的机制  
股东积极主义可能引发股价波动，影响特价股票的出现。通过Mermaid流程图展示机制：

## 第3章：算法原理讲解

### 3.1 金融模型  
使用CAPM模型评估股价：

$$ R = R_f + \beta (R_m - R_f) $$

其中，$R$为预期回报率，$R_f$为无风险利率，$\beta$为贝塔系数，$R_m$为市场回报率。

### 3.2 算法流程  
1. 收集数据：股价、股东行为数据。
2. 计算贝塔系数。
3. 评估预期回报。
4. 分析与实际回报差异。

### 3.3 Python代码  
```python
import pandas as pd
import yfinance as yf

# 下载数据
data = yf.download('AAPL', start='2020-01-01', end='2023-12-31')

# 计算贝塔系数
data['returns'] = data['Adj Close'].pct_change()
market_data = yf.download('^GSPC', start='2020-01-01', end='2023-12-31')
market_returns = market_data['Adj Close'].pct_change()

# 回归分析
import statsmodels.api as sm
X = sm.add_constant(data['returns'].dropna())
Y = data['returns'].dropna()
model = sm.OLS(Y, X)
results = model.fit()
beta = results.params[1]
print(beta)
```
