## 第3章：算法原理讲解

### 3.1 金融模型  
使用CAPM模型评估股价：

$$ R = R_f + \beta (R_m - R_f) $$

其中，$R$为预期回报率，$R_f$为无风险利率，$\beta$为贝塔系数，$R_m$为市场回报率。

### 3.2 算法流程  
1. 收集数据：股价、股东行为数据。
2. 计算贝塔系数。
3. 评估预期回报。
4. 分析与实际回报差异。

### 3.3 Python代码  
```python
import pandas as pd
import yfinance as yf

# 下载数据
data = yf.download('AAPL', start='2020-01-01', end='2023-12-31')

# 计算贝塔系数
data['returns'] = data['Adj Close'].pct_change()
market_data = yf.download('^GSPC', start='2020-01-01', end='2023-12-31')
market_returns = market_data['Adj Close'].pct_change()

# 回归分析
import statsmodels.api as sm
X = sm.add_constant(data['returns'].dropna())
Y = data['returns'].dropna()
model = sm.OLS(Y, X)
results = model.fit()
beta = results.params[1]
print(beta)
```
