### 5.2 或有资产的期望值模型

#### 5.2.1 期望值计算公式
$$ E[Value] = \sum_{i=1}^{n} P_i \times V_i $$
其中，$P_i$ 是第i种情况的概率，$V_i$ 是第i种情况的资产价值。

#### 5.2.2 通过Python实现期望值计算
```python
def expected_value(probabilities, values):
    return sum(p * v for p, v in zip(probabilities, values))

# 示例
probabilities = [0.3, 0.5, 0.2]
values = [100000, 200000, 50000]
ev = expected_value(probabilities, values)
print(f"期望值为: {ev:.2f}")
```

import numpy as np
import pandas as pd

def assess_or_assets(assets_data):
    # 计算现值
    pv = []
    for asset in assets_data:
        future_value, rate, periods = asset['FV'], asset['r'], asset['n']
        pv_asset = future_value / (1 + rate) ** periods
        pv.append(pv_asset)
    return pv

# 示例数据
assets_data = [
    {'FV': 1000000, 'r': 0.05, 'n': 5},
    {'FV': 2000000, 'r': 0.03, 'n': 10}
]
# 评估
pv_results = assess_or_assets(assets_data)
print("现值结果:", pv_results)
