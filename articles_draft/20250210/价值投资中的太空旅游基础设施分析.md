#### **Python代码示例：IRR计算**
```python
import numpy as np

def calculate_irr(cash_flows):
    # 现金流量：前几项为负数（投资），后续为正数（收益）
    # 计算IRR
    try:
        rate = np.irr(cash_flows)
        return f"IRR: {rate:.2%}"
    except ValueError:
        return "IRR无法计算"

# 示例数据
cash_flows = [-1000000, 400000, 500000, 200000]
print(calculate_irr(cash_flows))
```

#### **数学模型：IRR公式**
$$ \text{IRR} = r \quad \text{使得} \quad \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t} = 0 $$
