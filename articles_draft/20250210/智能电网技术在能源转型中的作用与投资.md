```python
# 负荷预测算法代码示例
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据加载与预处理
data = pd.read_csv('load_data.csv')
features = data[['temperature', 'time_of_day', 'season']]
labels = data['load']

# 模型训练
model = LinearRegression()
model.fit(features, labels)

# 预测与评估
predicted_load = model.predict(features)
print('预测结果:', predicted_load)
print('系数:', model.coef_)
print('截距:', model.intercept_)
```

## 3.3 负荷预测的数学模型与公式
### 3.3.1 线性回归模型
$$ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_n x_n $$

### 3.3.2 优化目标
$$ \text{最小化} \sum_{i=1}^{m} (y_i - (\beta_0 + \beta_1 x_{i1} + \cdots + \beta_n x_{in}))^2 $$
