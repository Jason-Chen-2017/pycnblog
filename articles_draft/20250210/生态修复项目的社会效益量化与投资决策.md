## 第一部分：生态修复项目的社会效益量化与投资决策概述

### 第1章：生态修复项目与社会效益量化概述

#### 1.1 生态修复的定义与重要性
- **1.1.1 生态修复的基本概念**  
  生态修复是指通过人为干预，恢复受损生态系统的结构和功能，使其接近自然状态的过程。这包括对土壤、水体、植被等的修复。

- **1.1.2 生态修复的必要性与意义**  
  随着工业化和城市化的快速发展，生态系统受到严重破坏，生态修复成为维护生态平衡、改善环境质量的关键手段。

- **1.1.3 生态修复与可持续发展的关系**  
  生态修复是实现可持续发展的重要组成部分，它不仅保护环境，还能促进经济和社会的长期健康发展。

#### 1.2 社会效益量化的核心概念
- **1.2.1 社会效益的定义**  
  社会效益是指生态修复项目对社会整体产生的积极影响，包括改善居民生活、提升公共健康、促进社会公平等。

- **1.2.2 生态修复项目中的社会效益范畴**  
  包括生态效益、经济效益、社会效益三方面，其中社会效益是本文的重点。

- **1.2.3 社会效益量化的目标与方法**  
  目标是通过量化方法，将生态修复项目的社会效益转化为可衡量的指标，为投资决策提供依据。

#### 1.3 投资决策在生态修复项目中的作用
- **1.3.1 投资决策的基本概念**  
  投资决策是指在多个备选方案中选择最优方案的过程，通常基于成本、收益和风险的评估。

- **1.3.2 生态修复项目投资决策的特点**  
  生态修复项目具有公益性和长期性，其社会效益难以直接量化，但可以通过间接指标进行评估。

- **1.3.3 投资决策与社会效益的关系**  
  社会效益是影响投资决策的重要因素，尤其是在公共资金分配中，社会效益的量化有助于优化资源配置。

### 1.4 本章小结  
本章介绍了生态修复的基本概念及其重要性，阐述了社会效益量化的核心概念，并分析了投资决策在生态修复项目中的作用。

```python
import numpy as np

# 比较判断矩阵
matrix = np.array([
    [1, 3, 2],
    [1/3, 1, 4],
    [1/2, 1/4, 1]
])

# 计算权重
特征值 = np.linalg.eigvals(matrix)
权重 = 特征值 / np.sum(特征值)

print("权重:", 权重)
```
