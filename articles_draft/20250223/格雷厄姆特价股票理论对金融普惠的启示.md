### 第4章：特价股票理论的数学模型与算法

#### 4.1 特价股票价值评估的数学模型
- 内在价值公式：$V = \frac{E}{k}$
  - $E$ 表示预期收益，$k$ 表示折现率
- 市场价格与内在价值的比较：$P < V$ 表示低估，$P > V$ 表示高估

#### 4.2 算法流程图
```mermaid

    A[开始] --> B[计算预期收益]
    B --> C[确定折现率]
    C --> D[计算内在价值]
    D --> E[比较市场价格]
    E --> F[得出结论]
```

#### 4.3 算法实现代码
```python
def calculate_intrinsic_value(expected_income, discount_rate):
    intrinsic_value = expected_income / discount_rate
    return intrinsic_value
```

#### 4.4 实际案例分析
- 案例：假设某公司预期收益为100万元，折现率为8%，则内在价值为125万元
- 如果市场价格为100万元，则该股票被低估，适合投资
