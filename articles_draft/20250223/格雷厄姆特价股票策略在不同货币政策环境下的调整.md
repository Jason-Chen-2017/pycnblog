## 第一章: 格雷厄姆投资理论的背景与核心思想

### 1.1 格雷厄姆投资理论的起源

格雷厄姆投资理论由本杰明·格雷厄姆在20世纪初提出，强调安全边际和价值投资。格雷厄姆认为，股票不仅是收益工具，更是企业的所有权证明。他主张以低于内在价值的价格买入股票，以确保安全边际。

**核心概念：**
- **安全边际**：买入价格低于内在价值的差额，确保投资的安全性。
- **价值投资**：寻找被市场低估的股票，长期持有，等待其价值回归。

### 1.2 格雷厄姆策略与现代投资理论的对比

现代投资理论强调分散投资和资产配置，而格雷厄姆策略侧重于个股选择和安全边际。两者的结合可以优化投资组合的风险收益比。

**对比表格：**

| 对比维度 | 格雷厄姆策略 | 现代投资理论 |
|----------|--------------|---------------|
| 核心理念 | 安全边际与低估 | 分散投资与资产配置 |
| 选股方法 | 基于价值评估 | 基于统计与风险模型 |
| 投资期限 | 长期持有 | 短期与长期结合 |

### 1.3 格雷厄姆策略在不同经济周期的表现

格雷厄姆策略在经济衰退期表现尤为突出，因为市场恐慌导致股票低估，提供安全边际。而在经济繁荣期，策略可能表现平平，但长期来看，其收益稳定。

## 第二章: 货币政策对股市的影响

### 2.1 货币政策的基本概念与工具

货币政策由中央银行通过调整利率、货币供应量和汇率等工具影响经济和金融市场。

**货币政策工具：**
1. **利率政策**：影响借贷成本，进而影响企业投资和个人消费。
2. **货币供应量**：通过增减货币供给影响市场流动性。
3. **汇率政策**：影响出口和进口，间接影响股市。

### 2.2 货币政策对股市的直接影响

- **利率下降**：降低企业融资成本，提升股市估值。
- **货币宽松**：增加市场流动性，推高股价。

### 2.3 不同货币政策环境下股市的表现

- **通货膨胀**：高通胀导致利率上升，股市可能下跌。
- **通货紧缩**：低通胀或通缩，企业盈利下降，股市走弱。
- **低利率环境**：资金流入股市，推高股价。

## 第三章: 格雷厄姆策略在不同货币政策环境下的调整方法

### 3.1 通货膨胀环境下的策略调整

**调整方法：**
1. **增加防御性股票**：如公用事业和消费品行业。
2. **降低杠杆比例**：避免利率上升带来的风险。

**实例分析：**
20世纪70年代通胀期间，格雷厄姆策略通过买入低估的防御性股票，实现了稳健收益。

### 3.2 通货紧缩环境下的策略调整

**调整方法：**
1. **增加周期性股票**：如科技和制造业，受益于经济复苏。
2. **提高安全边际**：严格评估内在价值，确保买入价格足够低。

### 3.3 低利率环境下的策略调整

**调整方法：**
1. **增加成长股**：低利率环境下，成长股的高市盈率可能被市场接受。
2. **分散投资**：平衡价值与成长风格，降低风险。

    return eps / (1 - growth_rate)

def graham_strategy(data, margin):
    buy_signals = []
    for stock in data:
        iv = calculate_intrinsic_value(stock.eps, stock.growth_rate)
