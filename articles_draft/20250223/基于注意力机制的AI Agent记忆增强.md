## 第三部分: 算法原理讲解

### 第3章: 注意力机制的数学模型与算法实现

#### 3.1 自注意力机制的数学模型
- **查询（Query）**：表示当前输入的向量。
- **键（Key）**：表示记忆中的向量。
- **值（Value）**：表示与键相对应的向量。
- **注意力权重计算**：通过计算查询与键的相关性，得到注意力权重。
- **加权求和**：根据注意力权重，对值向量进行加权求和，得到最终结果。

#### 3.2 注意力机制的Python实现
```python
def attention(query, keys, values):
    # 计算查询与键的相关性
    scores = torch.matmul(query, keys.T)
    # 计算注意力权重
    attention_weights = torch.softmax(scores, dim=-1)
    # 加权求和
    output = torch.matmul(attention_weights, values)
    return output
```

#### 5.2 核心代码实现
```python
import torch
import torch.nn as nn

class Attention(nn.Module):
    def __init__(self, embed_dim):
        super(Attention, self).__init__()
        self.embed_dim = embed_dim
        self.query = nn.Parameter(torch.randn(embed_dim, embed_dim))
        self.key = nn.Parameter(torch.randn(embed_dim, embed_dim))
        self.value = nn.Parameter(torch.randn(embed_dim, embed_dim))

    def forward(self, inputs):
        # 计算查询、键、值
        query = torch.matmul(inputs, self.query)
        key = torch.matmul(inputs, self.key)
        value = torch.matmul(inputs, self.value)
        # 计算注意力权重
        attention_weights = torch.softmax(torch.matmul(query, key.T), dim=-1)
        # 加权求和
        output = torch.matmul(attention_weights, value)
        return output

# 使用示例
inputs = torch.randn(10, 512)  # 输入向量
attention = Attention(512)
output = attention(inputs)
print(output.size())  # 输出形状
```
