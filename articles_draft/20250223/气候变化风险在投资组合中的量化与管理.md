# 第1章：气候变化风险概述

## 1.1 气候变化的基本概念

### 1.1.1 气候变化的定义与特征
气候变化是指地球气候系统长期的变化，主要表现为温度上升、极端天气事件增多等。其特征包括渐进性、不可逆性和全球性。

### 1.1.2 气候变化的主要驱动因素
- 自然因素：火山活动、太阳辐射变化
- 人为因素：温室气体排放、森林砍伐

### 1.1.3 气候变化对全球经济与金融的影响
- 经济损失：农业减产、基础设施损毁
- 金融市场波动：企业价值下降、投资信心减弱

## 1.2 投资组合风险管理的重要性

### 1.2.1 投资组合风险管理的传统方法
- 风险分散：通过多样化投资降低风险
- 价值-at-风险（VaR）：量化潜在损失

### 1.2.2 气候变化对投资组合风险的影响
- 物理风险：极端天气导致资产损失
- 转移风险：政策变化影响企业利润

### 1.2.3 量化与管理气候变化风险的必要性
- 避免重大损失
- 符合可持续投资理念

## 1.3 气候变化风险的分类

### 1.3.1 物理风险
- 自然灾害导致的资产损失

### 1.3.2 转移风险
- 碳税政策对企业利润的影响

### 1.3.3 诉讼风险
- 企业因排放超标被起诉的风险

# 第2章：气候变化风险的量化方法

## 2.1 气候变化风险的量化指标

### 2.1.1 温室气体排放强度
- 指标计算：单位产品排放量
- 示例：某企业每吨产品排放10吨CO₂

### 2.1.2 碳足迹
- 定义：产品生命周期内的总排放量
- 计算方法：从原材料到废弃物处理的全生命周期

### 2.1.3 气候风险值（CRV）
- 定义：衡量企业受气候变化影响的程度
- 计算公式：CRV = ∑(影响因子 × 权重)

### 2.2.2 数据清洗与预处理

## 2.3 气候变化风险量化模型

### 2.3.1 蒙特卡洛模拟模型

### 2.3.2 情景分析模型
