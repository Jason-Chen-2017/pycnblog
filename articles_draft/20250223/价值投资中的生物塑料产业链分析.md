# 第1章：生物塑料产业链的背景与现状

## 1.1 生物塑料的定义与分类

### 1.1.1 生物塑料的基本概念  
生物塑料是一种以可再生资源（如植物淀粉、纤维素等）为原料，通过生物或化学方法制成的塑料材料。与传统石油基塑料相比，生物塑料具有可降解、环保性好、资源消耗少等优势。

### 1.1.2 生物塑料的分类与特点  
生物塑料主要分为三类：  
1. **可生物降解塑料**：如聚乳酸（PLA）和聚己内酯（PCL），适用于一次性包装、农用薄膜等领域。  
2. **生物基不可降解塑料**：如聚乙烯（PE）和聚丙烯（PP）的生物基替代品，性能与传统塑料相似。  
3. **完全生物基塑料**：从可再生资源中提取，且具有可降解性。  

### 1.1.3 生物塑料的环境影响与优势  
- **减少碳足迹**：生物塑料生产过程中二氧化碳排放较低。  
- **资源可持续性**：依赖可再生资源，减少对化石燃料的依赖。  
- **环保性**：可生物降解，减少白色污染。

## 1.2 产业链结构与关键环节

### 1.2.1 产业链的整体架构  
生物塑料产业链包括 **上游原材料供应**、**中游生产制造** 和 **下游应用领域** 三个主要环节。

### 1.2.2 上游原材料供应  
- **主要原料**：玉米淀粉、甘蔗渣、蓖麻油等。  
- **特点**：可再生、价格波动小、供应稳定。  

### 1.2.3 中游生产制造  
- **主要工艺**：挤出成型、注塑成型、吹塑成型等。  
- **技术壁垒**：生物塑料生产技术复杂，需专利支持。  

### 1.2.4 下游应用领域  
- **主要应用**：包装、农用薄膜、纺织品、电子设备等。  
- **发展趋势**：向高端应用领域扩展，如汽车内饰和医疗用品。
