### 第4章: 创造性问题解决能力的算法原理

#### 4.1 基于搜索的创造性问题解决算法
- **搜索算法的定义与特点**：基于搜索的算法通过生成所有可能的解决方案，并通过评估选择最优解。深度优先搜索（DFS）适用于探索深度问题，而广度优先搜索（BFS）适用于探索广度问题。
- **常见搜索算法的实现**：以下是一个简单的DFS算法实现：
  ```python
  def dfs(problem, visited):
      if problem.goal_test():
          return problem.solution
      for action in problem.actions():
          next_state = problem.apply_action(action)
          if next_state not in visited:
              result = dfs(next_state, visited | {next_state})
              if result is not None:
                  return result
      return None
  ```
- **搜索算法在创造性问题解决中的应用**：基于搜索的算法适用于结构化问题，但在处理复杂问题时，可能会面临计算量过大和效率低下的问题。

#### 4.2 启发式创造性问题解决算法
- **启发式算法的定义与特点**：启发式算法通过引入启发函数，优先探索具有更高潜力的解决方案。例如，A*算法结合了BFS和贪心算法，能够在较短的时间内找到最优解。
- **常见启发式算法的实现**：以下是一个简单的A*算法实现：
  ```python
  def a_star_search(problem, heuristic):
      open_set = {problem.initial_state}
      came_from = {}
      g_score = {problem.initial_state: 0}
      f_score = {problem.initial_state: heuristic(problem.initial_state, problem.goal_state)}
      
      while open_set:
          current = pop_item(open_set, f_score)
          if current == problem.goal_state:
              return reconstruct_path(came_from, current)
          
          for neighbor in problem.get_neighbors(current):
              tentative_g_score = g_score[current] + problem.cost(current, neighbor)
              if neighbor not in g_score or tentative_g_score < g_score[neighbor]:
                  came_from[neighbor] = current
                  g_score[neighbor] = tentative_g_score
                  f_score[neighbor] = g_score[neighbor] + heuristic(neighbor, problem.goal_state)
                  open_set.add(neighbor)
      return None
  ```
- **启发式算法在创造性问题解决中的应用**：启发式算法适用于复杂问题，能够快速找到最优解，但需要设计合适的启发函数。
