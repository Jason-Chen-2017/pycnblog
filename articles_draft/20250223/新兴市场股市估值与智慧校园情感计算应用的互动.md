#### 第6章：项目实战
- 6.1 环境安装

- 6.2 系统核心实现源代码
  - 6.2.1 情感计算代码示例
    ```python
    import numpy as np
    from sklearn.feature_extraction.text import TfidfVectorizer
    from sklearn.svm import SVC
    # 数据预处理
    texts = ["This stock is a good investment.", "The market is performing poorly."]
    vectorizer = TfidfVectorizer()
    X = vectorizer.fit_transform(texts)
    y = [1, 0]  # 1表示正面，0表示负面
    # 模型训练
    model = SVC()
    model.fit(X, y)
    # 预测
    new_text = "I recommend buying this stock."
    new_X = vectorizer.transform([new_text])
    print(model.predict(new_X))  # 输出：[1]
    ```
  - 6.2.2 股市预测代码示例
    ```python
    import numpy as np
    import pandas as pd
    from sklearn.neural_network import MLPRegressor
    # 数据加载
    df = pd.read_csv('stock_data.csv')
    X = df[['PE', 'PB', 'Market Sentiment']]
    y = df['Price']
    # 模型训练
    model = MLPRegressor(hidden_layer_sizes=(10, 10))
    model.fit(X, y)
    # 预测
    new_X = np.array([[15, 3, 0.8]])
    print(model.predict(new_X))  # 输出：预测的股票价格
    ```
