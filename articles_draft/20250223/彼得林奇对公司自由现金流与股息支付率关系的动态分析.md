## 第二部分：核心概念与联系

### 第2章：自由现金流与股息支付率的原理与对比

#### 2.1 核心概念原理

- 2.1.1 自由现金流的计算公式
  $$\text{自由现金流} = \text{净利润} - \text{非现金支出}$$

- 2.1.2 股息支付率的计算公式
  $$\text{股息支付率} = \frac{\text{股息支付总额}}{\text{净利润}} \times 100\%$$

#### 2.2 属性特征对比

| 指标 | 定义 | 重要性 | 计算公式 |
|------|------|--------|----------|
| 自由现金流 | 净利润减去非现金支出 | 评估企业财务健康 | $$\text{FCF} = \text{净利润} - \text{非现金支出}$$ |
| 股息支付率 | 股息支付总额占净利润的比例 | 评估股东回报 | $$\text{DPR} = \frac{\text{股息支付总额}}{\text{净利润}} \times 100\%$$ |

## 第三部分：算法原理讲解

### 第3章：动态分析模型

#### 3.1 算法步骤

1. **数据收集**：获取公司历史财务数据。
2. **计算自由现金流**：
   $$\text{FCF}_t = \text{净利润}_t - \text{非现金支出}_t$$
3. **计算股息支付率**：
   $$\text{DPR}_t = \frac{\text{股息支付总额}_t}{\text{净利润}_t} \times 100\%$$
4. **动态分析**：比较FCF和DPR的变化趋势，评估企业财务健康和投资价值。

#### 3.3 Python代码实现

```python
import pandas as pd

def calculate_fcf(net_income, non_cash_expenses):
    return net_income - non_cash_expenses

def calculate DPR(dividends_paid, net_income):
    return (dividends_paid / net_income) * 100

# 示例数据
data = {
    '年份': [2020, 2021, 2022],
    '净利润': [100, 120, 150],
    '非现金支出': [20, 25, 30],
    '股息支付总额': [10, 15, 20]
}

df = pd.DataFrame(data)

df['自由现金流'] = df.apply(lambda x: calculate_fcf(x['净利润'], x['非现金支出']), axis=1)
df['股息支付率'] = df.apply(lambda x: calculate_DPR(x['股息支付总额'], x['净利润']), axis=1)

print(df)
```

import pandas as pd
import matplotlib.pyplot as plt

def calculate_fcf(net_income, non_cash_expenses):
    return net_income - non_cash_expenses

def calculate_DPR(dividends_paid, net_income):
    return (dividends_paid / net_income) * 100

# 示例数据
data = {
    '年份': [2020, 2021, 2022],
    '净利润': [100, 120, 150],
    '非现金支出': [20, 25, 30],
    '股息支付总额': [10, 15, 20]
}

df = pd.DataFrame(data)

df['自由现金流'] = df.apply(lambda x: calculate_fcf(x['净利润'], x['非现金支出']), axis=1)
df['股息支付率'] = df.apply(lambda x: calculate_DPR(x['股息支付总额'], x['净利润']), axis=1)

print(df)

# 可视化
plt.figure(figsize=(10, 6))
plt.plot(df['年份'], df['自由现金流'], label='自由现金流')
plt.plot(df['年份'], df['股息支付率'], label='股息支付率')
plt.xlabel('年份')
plt.ylabel('值')
plt.title('自由现金流与股息支付率的动态关系')
plt.legend()
plt.show()
