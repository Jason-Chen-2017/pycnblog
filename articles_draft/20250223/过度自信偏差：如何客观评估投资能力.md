## 第1章：过度自信偏差概述

### 1.1 过度自信偏差的定义与表现
#### 1.1.1 过度自信偏差的定义
过度自信偏差是一种认知偏差，表现为个体高估自己的能力、知识或判断的准确性。

#### 1.1.2 过度自信偏差的表现形式
- 过度相信自己的分析能力。
- 高估自己预测的准确性。
- 忽略外部信息或专家意见。

#### 1.1.3 过度自信偏差的成因分析
- 信息处理偏差。
- 过度自信的心理机制。
- 社会认同与自我价值维护。

### 1.2 过度自信偏差在投资中的体现
#### 1.2.1 投资决策中的过度自信现象
投资者可能过高估计自己的选股能力，忽视市场波动。

#### 1.2.2 过度自信偏差对投资结果的影响
可能导致错误决策，增加投资风险。

#### 1.2.3 投资者如何识别过度自信偏差
通过反思和自我评估，识别过度自信的迹象。

### 1.3 过度自信偏差的边界与外延
#### 1.3.1 过度自信偏差与其他认知偏差的区别
与确认偏向、选择性记忆等偏差的区别。

#### 1.3.2 过度自信偏差的适用范围
主要影响个体决策，但也存在于团队决策中。

#### 1.3.3 过度自信偏差的潜在风险
可能导致投资损失和决策失误。

### 1.4 过度自信偏差的核心要素
#### 1.4.1 个体认知偏差的核心要素

```python
import numpy as np

def detect_overconfidence(portfolio_return, benchmark_return):
    excess = portfolio_return - benchmark_return
    if excess > 0:
        return "可能存在过度自信"
    else:
        return "无过度自信"

# 示例
print(detect_overconfidence(10, 8))
```
