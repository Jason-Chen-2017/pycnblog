## 第3章：算法原理讲解

### 3.1 遗传算法

#### 3.1.1 算法流程
```mermaid
graph TD
A[开始] --> B[初始化种群]
B --> C[计算适应度]
C --> D[选择]
D --> E[交叉]
E --> F[变异]
F --> G[检查终止条件]
G --> H[输出结果]
H --> 结束
```

#### 3.1.2 适应度函数
$$适应度函数 = \frac{1}{平均等待时间} + \frac{1}{平均通行时间}$$

#### 3.1.3 选择与交叉操作
- 选择：基于适应度值进行选择，概率基于适应度比例。
- 交叉：采用单点交叉或双点交叉。

### 3.2 模拟退火算法

#### 3.2.1 算法步骤
```mermaid
graph TD
A[开始] --> B[初始化]
B --> C[计算目标函数]
C --> D[判断是否接受]
D --> E[降温]
E --> F[检查终止条件]
F --> 结束
```

#### 3.2.2 降温策略
- 线性降温：$$T_{k+1} = \alpha T_k$$
- 对数降温：$$T_{k+1} = \frac{T_k}{\log(k+1)}$$
