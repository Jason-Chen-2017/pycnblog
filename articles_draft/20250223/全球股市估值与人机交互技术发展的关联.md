### 7.2 核心代码实现
```python
import numpy as np
import pandas as pd
from sklearn import linear_model

# 数据加载与预处理
data = pd.read_csv('stock_data.csv')
X = data[['市盈率', '市净率', 'ROE']]
y = data['股价']

# 模型训练
model = linear_model.LinearRegression()
model.fit(X, y)

# 预测与评估
predicted = model.predict(X)
print('预测准确性:', np.mean(abs(predicted - y)/y))
```
