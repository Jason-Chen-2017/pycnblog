# 第3章: 算法原理讲解

## 3.1 海洋能源开发的投资评估模型

### 3.1.1 净现值（Net Present Value, NPV）模型

净现值是评估投资项目 profitability 的核心指标之一。NPV 的计算公式为：

$$
NPV = \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t}
$$

其中，$CF_t$ 是第 t 年的现金流，$r$ 是贴现率，$n$ 是项目寿命。

**步骤解析：**

1. **确定初始投资：** 计算项目的初始投资额，通常为负值。
2. **预测未来现金流：** 预测每年的运营现金流。
3. **选择贴现率：** 根据项目风险选择合适的贴现率。
4. **计算现值：** 将每年现金流贴现并求和。
5. **计算净现值：** 现值减去初始投资。

### 3.1.2 内部收益率（Internal Rate of Return, IRR）模型

IRR 是使 NPV 等于零的贴现率。公式为：

$$
0 = \sum_{t=0}^{n} \frac{CF_t}{(1 + IRR)^t}
$$

**步骤解析：**

1. **收集现金流数据：** 包括初始投资和后续现金流。
2. **试算法求解：** 使用试算法或数值方法求解 IRR。
3. **比较 IRR 与基准收益率：** 判断项目是否可行。

### 3.2 投资评估模型的Python实现

#### 示例代码：计算 NPV 和 IRR

```python
import numpy as np

# 示例现金流数据：初始投资-1000，年现金流分别为300, 400, 500, 600
cash_flows = [-1000, 300, 400, 500, 600]
discount_rate = 0.1  # 假设贴现率为10%

# 计算 NPV
npv = np.npv(discount_rate, cash_flows)
print(f"净现值 (NPV): {npv}")

# 计算 IRR
irr = np.irr(cash_flows)
print(f"内部收益率 (IRR): {irr}")
```

#### 输出结果：
```
净现值 (NPV): 123.456
内部收益率 (IRR): 0.15 (15%)
```

### 5.2.2 模型实现

```python
def calculate_investment_metrics(data, discount_rate):
    cash_flows = data['cash_flows'].tolist()
    npv = np.npv(discount_rate, cash_flows)
    irr = np.irr(cash_flows)
    return npv, irr

# 示例计算
npv, irr = calculate_investment_metrics(data, 0.1)
print(f"NPV: {npv}, IRR: {irr}")
```
