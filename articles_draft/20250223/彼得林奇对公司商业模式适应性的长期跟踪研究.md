## 第一部分：背景介绍

### 第1章：彼得·林奇的投资理念与方法

#### 1.1 投资哲学

- **长期投资**：林奇强调长期投资，认为市场波动是短期的，优秀企业能经受时间考验。
- **价值投资**：寻找基本面良好、管理优秀的企业，关注内在价值而非市场波动。
- **耐心资本**：长期持有优质企业，分享其成长收益。

#### 1.2 选股标准与策略

- **选股标准**：高ROE、持续增长的收入和利润、竞争优势明显。
- **分散投资**：避免过度集中，降低风险。
- **逆向投资**：市场恐慌时寻找被低估的机会。

#### 1.3 应对市场波动

- **市场波动的应对**：避免频繁交易，专注于基本面分析。
- **风险管理**：分散投资、定期复盘、及时调整。

### 第2章：商业模式适应性分析

#### 2.1 商业模式的定义

- **构成要素**：价值主张、资源、流程、客户关系、收益模型。
- **适应性定义**：企业能否灵活调整以应对市场变化。

#### 2.2 林奇关注的点

- **盈利能力**：ROE、毛利率、净利率。
- **灵活性**：企业能否适应市场变化。
- **竞争优势**：独特的资源或能力。

### 第3章：长期跟踪的意义与方法

#### 3.1 重要意义

- **应对市场变化**：企业需灵活调整商业模式。
- **投资决策支持**：通过长期跟踪发现机会和风险。
- **评估公司业绩**：分析企业长期表现。

#### 3.2 方法论

- **数据收集**：定期收集财务数据和市场信息。
- **定性与定量结合**：分析财务指标和市场趋势。
- **持续评估**：定期评估商业模式适应性。

def model_adaptability_analysis(data):
    # 初步筛选
    filtered_data = data[data['profitability'] > data['industry_avg']]
    # 定量分析
    quantitative_score = filtered_data['profitability'].mean()
    # 定性分析
    qualitative_score = 0
    if quantitative_score > 0.8:
        qualitative_score = 0.8
    elif quantitative_score > 0.6:
        qualitative_score = 0.6
    # 综合评估
    total_score = (quantitative_score + qualitative_score) / 2
    return total_score
```

import pandas as pd

def calculate_roe(data):
    data['roe'] = data['净利润'] / data['股东权益']
    return data

# 示例数据
data = {
    '公司': ['A', 'B', 'C'],
    '净利润': [10, 15, 20],
    '股东权益': [50, 60, 70],
    '行业平均': [8, 8, 8]
}
df = pd.DataFrame(data)
result = calculate_roe(df)
print(result)
```
