# 第二部分: 核心概念与算法原理

## 第2章: 深度强化学习的核心概念与原理

### 2.1 深度强化学习的基本原理
- 2.1.1 状态、动作、奖励的定义
  - 状态：市场环境（如价格、成交量）。
  - 动作：买入、卖出或持有。
  - 奖励：投资收益或损失。
- 2.1.2 Q-learning算法的基本原理
  - 使用Q表记录状态-动作对的期望奖励，通过经验更新Q值。

### 2.2 深度强化学习的核心算法
- 2.2.1 DQN算法的原理与实现
  - 使用两个神经网络，一个作为主网络，一个作为目标网络，通过经验回放和折扣因子优化。
- 2.2.2 A3C算法的原理与实现
  - 异步优势Actor-Critic算法，分布式训练，适用于多线程环境。
- 2.2.3 PPO算法的原理与实现
  - 基于策略梯度，通过限制策略更新幅度，保证收敛性。

### 2.3 深度强化学习与股票投资的结合
- 2.3.1 股票市场中的状态表示
  - 使用K线图、技术指标（如MACD、RSI）等。
- 2.3.2 动作空间的设计
  - 买入、卖出或持有三种动作。
- 2.3.3 奖励函数的定义
  - 基于收益、风险、交易成本等多因素设计。

## 第3章: 深度强化学习模型的数学模型与算法实现

### 3.1 Q-learning算法的数学模型
- 更新公式：
$$ Q(s, a) = (1-\alpha)Q(s, a) + \alpha(r + \gamma \max Q(s', a')) $$

### 3.2 DQN算法的数学模型
- 网络结构：
  - 输入层（市场数据）→ 隐藏层（神经网络）→ 输出层（Q值）。
- 损失函数：
$$ \mathcal{L} = \mathbb{E}[(r + \gamma Q(s', a') - Q(s, a))^2] $$

### 3.3 PPO算法的数学模型
- 损失函数：
$$ \mathcal{L} = -\mathbb{E}[\text{CLIP}(r_t - \hat{r}_t) \cdot \text{log} \pi_\theta(a_t|s_t)] $$

# 定义DQN网络
class DQNetwork:
    def __init__(self, state_space, action_space):
        self.model = tf.keras.Sequential([
            tf.keras.layers.Dense(64, activation='relu'),
            tf.keras.layers.Dense(64, activation='relu'),
            tf.keras.layers.Dense(action_space)
        ])
        
    def call(self, state):
        return self.model(state)
    
# DQN算法实现
class DQN:
    def __init__(self, state_space, action_space):
        self.state_space = state_space
        self.action_space = action_space
        self.gamma = 0.99
        self.epsilon = 1.0
        self.epsilon_min = 0.01
        self.memory = []

        self.target_model = DQNetwork(state_space, action_space)
    
    def remember(self, state, action, reward, next_state):
        self.memory.append((state, action, reward, next_state))
    
    def act(self, state):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.action_space)
        q_values = self.model.call(state).numpy()[0]
        return np.argmax(q_values)

        states = np.array([t[0] for t in minibatch])
