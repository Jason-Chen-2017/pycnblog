#### 3.2 Python源代码

```python
# Python代码示例：最小二乘法求解参数
import numpy as np

# 数据
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])

# 建立线性模型：y = ax + b
# 最小化残差平方和：sum((y - (ax + b))**2)
a = np.sum((x - np.mean(x)) * (y - np.mean(y))) / np.sum((x - np.mean(x))**2)
b = np.mean(y) - a * np.mean(x)

print(f"a: {a}, b: {b}")
```

### 第4章: 数学模型和数学公式详细讲解

#### 4.1 概念解释

- 最小二乘法：最小化误差平方和的方法。
- 残差：观测值与模型预测值之间的差。

#### 4.2 数学模型和公式

$$
\begin{cases}
\min \sum_{i=1}^{n} (y_i - (a x_i + b))^2 \\
y_i = a x_i + b + e_i \\
e_i \sim N(0, \sigma^2)
\end{cases}
$$
