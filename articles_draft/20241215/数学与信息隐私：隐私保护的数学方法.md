### 第三部分：算法原理讲解

#### 3.1 对称加密算法

##### 3.1.1 对称加密的定义
对称加密是指加密和解密使用相同的密钥。

##### 3.1.2 对称加密的原理
对称加密的原理是通过加密算法将明文信息转换为密文，解密时使用相同的加密算法和密钥将密文还原为明文。

##### 3.1.3 对称加密的示例
```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad

key = b'mysecretdkey123456'
cipher = AES.new(key, AES.MODE_CBC)
ct_bytes = cipher.encrypt(pad(b'my secret message', AES.block_size))
iv = cipher.iv
print(ct_bytes)
print(iv)

# 解密
cipher = AES.new(key, AES.MODE_CBC, iv)
pt = unpad(cipher.decrypt(ct_bytes), AES.block_size)
print(pt)
```

##### 3.1.4 对称加密的优势和局限性
对称加密的优势在于速度快、效率高，但局限性在于密钥管理复杂。

#### 3.2 非对称加密算法

##### 3.2.1 非对称加密的定义
非对称加密是指加密和解密使用不同的密钥，一个为私钥，一个为公钥。

##### 3.2.2 非对称加密的原理
非对称加密的原理是加密时使用公钥，解密时使用私钥。公钥和私钥通过数学关系生成，但私钥不能从公钥推导出来。

##### 3.2.3 非对称加密的示例
```python
from Crypto.PublicKey import RSA
from Crypto.Cipher import PKCS1_OAEP

key = RSA.generate(2048)
private_key = key.export_key()
public_key = key.publickey().export_key()

cipher = PKCS1_OAEP.new(public_key)
ct = cipher.encrypt(b'my secret message')
print(ct)

decryptor = PKCS1_OAEP.new(private_key)
pt = decryptor.decrypt(ct)
print(pt)
```

##### 3.2.4 非对称加密的优势和局限性
非对称加密的优势在于安全性高，但缺点是计算复杂度高。
