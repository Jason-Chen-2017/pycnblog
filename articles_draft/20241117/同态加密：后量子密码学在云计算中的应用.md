### 4. 后量子密码学的数学模型与公式
$$
\begin{aligned}
\text{量子门} & : \{U_1, U_2, \ldots, U_n\} \\
\text{量子态} & : |\psi\rangle = \sum_{i=1}^n a_i |i\rangle \\
\text{量子测量} & : P(\psi) = |\psi|^2
\end{aligned}
$$
示例：
```

U = [1 0; 0 e^(i\theta)]
// 量子态示例
|\psi\rangle = [1/\sqrt{2}] [0; 1]
// 量子测量示例
P = |\psi\rangle^* \psi\rangle = 1/2
```

```
// 同态加密实现的伪代码
class HomomorphicEncryptionScheme:
    def __init__(self):
        self.public_key, self.private_key = self.key_gen()

    def encrypt(self, message):
        return self.public_key.encrypt(message)

    def decrypt(self, ciphertext):
        return self.private_key.decrypt(ciphertext)

    def homomorphic_compute(self, op1, op2):
        encrypted_op1 = self.encrypt(op1)
        encrypted_op2 = self.encrypt(op2)
        return self.public_key.homomorphic_compute(encrypted_op1, encrypted_op2)

    def decrypt_result(self, encrypted_result):
        return self.private_key.decrypt(encrypted_result)
```
