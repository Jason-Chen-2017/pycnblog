#### 第2章：区块链的核心算法

区块链的核心算法包括共识算法和加密算法。共识算法用于在网络中的多个节点之间达成一致，确保区块链的分布式特性。加密算法用于确保数据的安全性和隐私性。

**核心算法原理讲解**

**2.1 共识算法**

共识算法的定义：

共识算法是一种分布式系统中的算法，用于在网络中的多个节点之间达成一致。

常见的共识算法：

- POW（Proof of Work）：通过解决数学难题证明工作量的算法。
- POS（Proof of Stake）：通过持有代币数量和时间证明权益的算法。

共识算法的优缺点：

- POW：安全性高，但计算资源消耗大。
- POS：资源消耗小，但可能存在“富者愈富”的问题。

**伪代码示例**

下面是一个简单的 POW 共识算法的伪代码示例：

```python
def proofOfWork(difficulty):
    nonce = 0
    while calculateHash() != getTargetHash(difficulty):
        nonce += 1
    return nonce
```

**2.2 加密算法**

加密算法的定义：

加密算法是一种将明文数据转换为密文的算法。

常见的加密算法：

- RSA：一种非对称加密算法。
- SHA：一种散列函数。

加密算法在区块链中的应用：

- 确保交易数据的安全性。
- 保护节点间的通信。

**伪代码示例**

下面是一个简单的 RSA 加密算法的伪代码示例：

```python
def rsaEncrypt(plaintext, publicKey):
    ciphertext = []
    for char in plaintext:
        encryptedChar = pow(ord(char), publicKey)
        ciphertext.append(encryptedChar)
    return ciphertext
```

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract DigitalCopyright {

    struct Transaction {
        address sender;
        address recipient;
        uint256 amount;
        string copyrightId;
        bool completed;
    }

    mapping(string => Transaction[]) private transactions;

    function createTransaction(
        address _recipient,
        uint256 _amount,
        string memory _copyrightId
    ) public {
        require(_recipient != address(0), "Invalid recipient");
        require(_amount > 0, "Invalid amount");
        require(bytes(_copyrightId).length > 0, "Invalid copyrightId");

        Transaction memory transaction;
        transaction.sender = msg.sender;
        transaction.recipient = _recipient;
        transaction.amount = _amount;
        transaction.copyrightId = _copyrightId;
        transaction.completed = false;

        transactions[_copyrightId].push(transaction);
    }

    function completeTransaction(string memory _copyrightId) public {
        require(msg.sender == transactions[_copyrightId][0].sender, "Not authorized");

        Transaction[] storage t = transactions[_copyrightId];
        t[0].completed = true;
    }

    function getTransactionStatus(string memory _copyrightId) public view returns (bool) {
        return transactions[_copyrightId][0].completed;
    }
}
```
