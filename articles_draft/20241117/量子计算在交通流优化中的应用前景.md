### 量子计算基础

#### 量子比特与量子门

量子比特（qubit）是量子计算的基本单元，它不仅具有0和1的基态，还可以处于叠加态。叠加态可以表示为0和1的线性组合，如$$\frac{1}{\sqrt{2}} |0\rangle + \frac{1}{\sqrt{2}} |1\rangle$$。量子比特之间的叠加和纠缠特性，使得量子计算具有巨大的并行性。

量子门（quantum gate）是操作量子比特的基本操作。常见的量子门包括Hadamard门（实现叠加态）、Pauli门（实现量子比特的翻转）、控制非门（实现量子比特之间的纠缠）等。量子门的作用可以用矩阵表示，如Hadamard门的矩阵表示为：

$$
H = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}
$$

通过量子门的作用，可以实现对量子比特的变换和运算。

#### 量子算法概述

量子算法是利用量子比特和量子门的特性进行信息处理和计算的算法。与经典算法相比，量子算法在特定问题上具有显著的优势。常见的量子算法包括Shor算法、Grover算法等。

Shor算法是一种利用量子计算求解整数分解问题的算法。Shor算法的核心思想是通过量子并行性和量子干涉，将复杂问题转化为求解周期性问题，从而实现快速求解。

Grover算法是一种用于搜索未排序数据库的算法。Grover算法利用量子叠加和干涉的特性，将搜索时间从O(n)降低到O(√n)，显著提高了搜索效率。

   def find_period(g, N):
       # 求解g的周期
       T = 1
       for i in range(2, N):
           if (g^i) % N == 1:
               T = i
               break
       return T
   
   def factor(N, period):
       # 求解N的因子
       for j in range(1, period):
           if (N/j) % period == 0:
               return [N/j, j]
       return [N]
   ```
