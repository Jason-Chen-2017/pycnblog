```plaintext
// 加密算法原理：RSA算法
// 公钥加密
publicKey := (n, e)
message := 明文信息
cipherText := RSAEncrypt(message, publicKey)

// 解密算法
privateKey := (n, d)
decryptedMessage := RSADecrypt(cipherText, privateKey)

// RSA加密算法伪代码
func RSAEncrypt(message, publicKey):
    n, e = publicKey
    p, q = GetPrimes()
    n = p * q
    phi = (p-1) * (q-1)
    d = ModInverse(e, phi)
    cipherText = (message^e) mod n
    return cipherText

// RSA解密算法伪代码
func RSADecrypt(cipherText, privateKey):
    n, d = privateKey
    decryptedMessage = (cipherText^d) mod n
    return decryptedMessage
```

**数学模型和数学公式 & 详细讲解 & 举例说明**：

```latex
$$
E_k(m) = C = D^{E_k}(m)
$$

其中，$E_k$ 表示加密函数，$D$ 表示解密函数，$m$ 表示明文信息，$C$ 表示密文信息。

举例说明：
假设密钥 $k$ 为 3，明文信息 $m$ 为 "hello"，则加密过程为：
$$
C = D^{E_3}("hello") = ("hello"^{3}) \mod 26 = ("hello" * 3) \mod 26 = 16
$$
因此，密文信息为 "16"。

解密过程为：
$$
m = D(C) = D^{E_3}(16) = (16^{3}) \mod 26 = (16 * 3) \mod 26 = 7
$$
因此，明文信息为 "7"。
```
