## 第4章: 经济护城河的数学模型与公式

### 4.1 经济护城河的数学模型  
- 经济护城河的量化指标：ROE（净资产收益率）  
  $$ROE = \frac{\text{净利润}}{\text{净资产}}$$  
- 经济护城河的动态评估模型：  
  $$\text{经济护城河强度} = \text{成本优势} + \text{网络效应} \times \text{用户粘性} + \text{品牌忠诚度} \times \text{市场份额}$$

import pandas as pd

def load_data(filename):
    df = pd.read_csv(filename)
    return df

def calculate_roe(df):
    df['ROE'] = df['净利润'] / df['净资产']
    return df

def assesscompetitive_advantage(df):
    df['经济护城河强度'] = df['成本优势'] + df['网络效应'] * df['品牌忠诚度'] * df['市场份额']
    return df

# 示例代码
