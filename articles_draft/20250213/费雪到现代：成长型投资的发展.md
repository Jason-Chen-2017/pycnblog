#### 3.2 核心代码实现

##### 3.2.1 数据处理代码
```python
import pandas as pd
import numpy as np

# 数据加载
df = pd.read_csv('stock_data.csv')

# 数据清洗
df.dropna(inplace=True)
df['收入增长率'] = (df['收入'] / df['收入'].shift(1)) - 1
df['利润增长率'] = (df['利润'] / df['利润'].shift(1)) - 1
```

##### 3.2.2 成长性评估模型
```python
from sklearn.ensemble import RandomForestClassifier

# 特征矩阵和标签
X = df[['收入增长率', '利润增长率', '市盈率']]
y = df['是否成长股']

# 模型训练
model = RandomForestClassifier()
model.fit(X, y)

# 预测结果
pred = model.predict(X)
```

##### 3.2.3 投资组合优化
```python
import matplotlib.pyplot as plt

# 绘制成长性评分分布

plt.title('成长性评分分布')
plt.show()
```
