# 第一章: 系统性风险与图表示学习概述

## 1.1 系统性风险的定义与特征

### 1.1.1 系统性风险的定义
系统性风险是指由于金融系统中各机构之间的高度关联性，导致某一机构的危机可能引发整个金融系统的崩溃。其本质是由于金融网络中存在复杂的相互依赖关系，导致风险在系统中快速传播。

### 1.1.2 系统性风险的核心特征
- **传染性**：风险从一家机构或市场向其他机构或市场扩散。
- **系统性影响**：风险影响整个金融系统的稳定性。
- **复杂性**：风险传导路径复杂，涉及多个层级和机构。

### 1.1.3 系统性风险的传导机制
- **直接传染**：两家金融机构之间存在直接的债务或投资关系，一家机构的危机直接导致另一家机构的危机。
- **间接传染**：通过第三方机构或市场，风险在金融机构之间间接传播。
- **市场传染**：由于市场参与者的信心下降，导致资产价格下跌，进一步引发连锁反应。

## 1.2 图表示学习的定义与特点

### 1.2.1 图表示学习的定义
图表示学习是一种通过图结构数据来表示和学习的方法，其目标是将图中的节点或边映射到低维向量空间，同时保留图的结构信息和节点之间的关系。

### 1.2.2 图表示学习的核心特点
- **全局性**：能够捕捉图中所有节点之间的关系。
- **结构性**：能够反映图中节点的结构特征。
- **可解释性**：通过向量表示，可以直观地理解节点之间的关系。

### 1.2.3 图表示学习与传统机器学习的区别
- **输入数据**：传统机器学习通常处理的是独立样本，而图表示学习处理的是具有复杂关系的图数据。
- **依赖关系**：传统机器学习不考虑数据之间的依赖关系，而图表示学习能够捕捉数据之间的依赖关系。
- **应用场景**：传统机器学习适用于单样本分析，而图表示学习适用于复杂网络分析。

## 1.3 系统性风险与图表示学习的结合

### 1.3.1 系统性风险分析中的图结构
- **金融机构网络**：将金融机构看作图中的节点，金融机构之间的关联关系看作图中的边。
- **金融市场网络**：将金融资产或市场看作图中的节点，资产之间的价格波动关系看作图中的边。

### 1.3.2 图表示学习在金融领域的优势
- **捕捉复杂关系**：能够捕捉金融机构之间复杂的相互依赖关系。
- **风险传导路径分析**：通过图表示学习，可以识别系统性风险的传导路径。
- **风险预测**：通过图表示学习，可以预测系统性风险的发生概率。

# 第三章: 图表示学习的核心算法原理

## 3.1 图表示学习的基本原理

### 3.1.1 图表示学习的目标
- **节点表示**：将图中的节点映射到低维向量空间。
- **图表示**：将整个图映射到低维向量空间。

### 3.1.2 图表示学习的核心思想
- **保留局部结构**：在低维向量空间中保留图中节点的局部结构特征。
- **捕捉全局关系**：在低维向量空间中捕捉图中节点的全局关系。

### 3.1.3 图表示学习的主要方法
- **基于节点嵌入的方法**：如Node2Vec、Word2Vec。
- **基于图嵌入的方法**：如GraphSAGE、GAT。

## 3.2 基于节点嵌入的图表示学习

### 3.2.1 节点嵌入的定义与特点
- **节点嵌入**：将图中的节点映射到低维向量空间。
- **节点嵌入的特点**：能够捕捉节点的局部结构特征。

### 3.2.2 常见的节点嵌入算法
- **Node2Vec**：通过随机游走生成节点的上下文，学习节点嵌入。
- **Word2Vec**：通过上下文学习节点嵌入。

### 3.2.3 节点嵌入在系统性风险中的应用
- **风险识别**：通过节点嵌入识别系统性风险的关键节点。
- **风险预测**：通过节点嵌入预测系统性风险的发生概率。

## 3.3 基于图嵌入的系统性风险分析

### 3.3.1 图嵌入的定义与特点
- **图嵌入**：将整个图映射到低维向量空间。
- **图嵌入的特点**：能够捕捉图的全局结构特征。

### 3.3.2 常见的图嵌入算法
- **GraphSAGE**：通过聚合邻居节点的信息生成节点嵌入。
- **GAT**：通过注意力机制生成节点嵌入。

### 3.3.3 图嵌入在系统性风险分析中的应用
- **风险传播路径识别**：通过图嵌入识别系统性风险的传播路径。
- **风险强度评估**：通过图嵌入评估系统性风险的强度。
