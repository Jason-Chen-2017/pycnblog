## 第三章: 多尺度分析的算法原理

### 3.1 小波分析（Wavelet Analysis）

#### 3.1.1 小波分析的基本原理与流程

小波分析是一种有效的信号处理方法，能够在不同尺度上分解时间序列数据。其核心思想是将数据分解为不同频率的子信号，以便捕捉不同时间尺度下的特征。

**流程步骤**：
1. 选择合适的小波基函数（如Meyer小波）。
2. 对时间序列数据进行小波变换，分解为不同尺度的子信号。
3. 分析各尺度下的特征（如趋势、周期性）。
4. 反变换重建信号或提取特定尺度的特征。

**Mermaid 流程图**：

```mermaid
graph TD
    A[原始时间序列数据] --> B[选择小波基函数]
    B --> C[小波变换]
    C --> D[分解为多尺度信号]
    D --> E[分析各尺度特征]
    E --> F[反变换或特征提取]
    F --> G[结果]
```

#### 3.1.2 小波分析的数学模型

小波变换的数学公式如下：

$$ W_{\psi}(t) = \int_{-\infty}^{\infty} x(\tau) \psi(t-\tau) d\tau $$

其中，$\psi(t)$ 是小波基函数，$W_{\psi}(t)$ 是小波变换结果。

**示例**：假设我们有股票价格数据，使用小波分析可以检测价格中的趋势和周期性波动。

### 3.2 移动平均与指数平滑

#### 3.2.1 移动平均法（Moving Average）

移动平均法是一种简单的时间序列平滑方法，通过计算过去若干期的平均值来预测未来值。

**公式**：
$$ \hat{y}_t = \frac{1}{n} \sum_{i=1}^{n} y_{t-i} $$

**示例**：使用5天的移动平均预测第6天的价格。

#### 3.2.2 指数平滑法（Exponential Smoothing）

指数平滑法通过递减权重计算过去值的加权平均。

**公式**：
$$ \hat{y}_t = \alpha y_{t-1} + (1-\alpha)\hat{y}_{t-1} $$

其中，$\alpha$ 是平滑系数（$0 < \alpha < 1$）。

**示例**：预测未来汇率走势。

---

#### 5.2.2 特征提取

```python
import pywt

def wavelet_transform(data, wavelet='db1'):
    coeffs = pywt.wavedec(data, wavelet)
    # 提取不同尺度的特征
    features = [np.mean(level) for level in coeffs[1:]]
    return features

features = wavelet_transform(data['close'])
```

---

#### 5.2.3 预测模型

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(features, data['close'].iloc[-len(features):])
```
