## 第1章: 投资的基本概念与多元化的重要性

### 1.1 投资的基本概念

#### 1.1.1 投资的定义与分类

- **提高收益潜力**：多元化可以平衡风险与收益，捕捉不同资产的上涨机会。

#### 1.1.3 投资风险与收益的关系

- **风险与收益的正相关性**：高风险通常意味着高收益，但并非绝对。
- **风险分散化**：通过多元化投资，可以有效降低非系统性风险。

# 第二部分: 投资组合构建的理论基础

## 第2章: 现代投资组合理论与CAPM模型

### 2.1 现代投资组合理论（MPT）概述

#### 2.1.1 MPT的核心思想

- **核心思想**：通过优化投资组合的收益与风险关系，找到最优风险回报比。

#### 2.1.2 MPT的数学模型

- **公式推导**：
  - 投资组合的期望收益：$$E(r_p) = \sum w_i E(r_i)$$
  - 投资组合的方差：$$\sigma_p^2 = \sum w_i^2 \sigma_i^2 + 2 \sum w_i w_j \sigma_i \sigma_j \rho_{ij}$$

#### 2.1.3 MPT的实践意义

- **实践意义**：帮助投资者找到在给定风险水平下收益最大的投资组合。

### 2.2 CAPM模型的原理与应用

#### 2.2.1 CAPM模型的定义

- **定义**：资本资产定价模型，用于计算资产的预期收益。

#### 2.2.2 CAPM模型的公式推导

- **公式**：$$E(r_i) = R_f + \beta_i (E(r_m) - R_f)$$
  - $$R_f$$：无风险利率
  - $$E(r_m)$$：市场预期收益率
  - $$\beta_i$$：资产i的贝塔系数

#### 2.2.3 CAPM模型在投资组合构建中的应用

- **应用**：通过计算不同资产的贝塔系数，确定最优资产配置比例。

### 2.3 本章小结

# 第三部分: 投资组合构建的核心算法与数学模型

## 第3章: 投资组合优化的数学模型

### 3.1 均值-方差优化模型

#### 3.1.1 均值-方差优化的定义

- **定义**：通过优化投资组合的期望收益与方差，找到最优投资组合。

#### 3.1.2 均值-方差优化的数学公式

- **优化目标**：$$\min \sigma_p^2$$
  - 约束条件：$$\sum w_i = 1$$

#### 3.1.3 均值-方差优化的实现步骤

1. 收集资产的历史收益数据。
2. 计算资产的期望收益和协方差矩阵。
3. 使用优化算法求解最优权重。

### 3.2 使用Python实现投资组合优化

#### 3.2.1 Python环境安装与配置

- **工具安装**：安装Python、NumPy、Pandas、SciPy。

#### 3.2.2 投资组合优化的代码实现

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_var(weights, returns):
    return (weights.T @ returns @ weights)

weights = [0.5, 0.5]
returns = np.array([[0.1, 0.2], [0.2, 0.1]])

result = minimize(portfolio_var, weights, args=(returns,), method='SLSQP')
print(result.x)
```

#### 3.2.3 代码的功能解读与分析

- **功能解读**：代码通过优化算法求解最优权重，使得投资组合的方差最小。

### 5.1 投资组合实战案例

#### 5.1.1 环境安装与配置

#### 5.1.2 核心代码实现

```python
import pandas as pd
import matplotlib.pyplot as plt

# 数据加载
data = pd.read_csv('assets.csv')

# 计算收益
returns = data.pct_change().dropna()

# 优化模型
from pyparetopy import pyparetopy
model = pyparetopy.PyPortfolioOpt(returns)
model.minimize_volatility()
weights = model.weights

# 可视化
plt.bar(weights.index, weights.values)
plt.title('Optimal Weights')
plt.show()
```
