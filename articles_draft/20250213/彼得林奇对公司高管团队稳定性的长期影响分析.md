## 3.1 稳定性指数计算公式

$$
S = \frac{\sum_{i=1}^{n} w_i \cdot s_i}{\sum_{i=1}^{n} w_i}
$$

其中：
- \( S \) 为稳定性指数。
- \( w_i \) 为指标权重。
- \( s_i \) 为指标得分。

### 5.2.1 稳定性指数计算代码

```python
import pandas as pd
import numpy as np

def calculate_stability_index(data):
    # 假设data是DataFrame，包含高管变动信息
    # 计算每家公司高管团队的稳定性指数
    stability_index = []
    for company in data['Company'].unique():
        company_data = data[data['Company'] == company]
        # 计算各指标得分
        retention_rate = company_data['Retention'].mean()
        collaboration_score = company_data['Collaboration'].mean()
        strategy_alignment = company_data['Strategy'].mean()
        # 计算稳定性指数
        S = (retention_rate + collaboration_score + strategy_alignment) / 3
        stability_index.append((company, S))
    return pd.DataFrame(stability_index, columns=['Company', 'Stability Index'])

# 示例数据
data = pd.DataFrame({
    'Company': ['A', 'A', 'B', 'B'],
    'Retention': [0.8, 0.8, 0.7, 0.7],
    'Collaboration': [0.9, 0.9, 0.8, 0.8],
    'Strategy': [0.8, 0.8, 0.7, 0.7]
})

result = calculate_stability_index(data)
print(result)
```
