# 第1章：投资组合再平衡概述

## 1.1 投资组合再平衡的定义与重要性

### 1.1.1 投资组合再平衡的定义
投资组合再平衡是指根据市场变化和个人投资目标的调整，定期或不定期地调整投资组合的资产配置，使其恢复到预定的目标比例。

### 1.1.2 再平衡的重要性与作用
- **分散风险**：通过调整资产配置，降低投资组合的波动性。
- **优化收益**：使投资组合在不同市场环境下保持最优收益风险比。
- **适应市场变化**：及时应对市场波动和投资者风险偏好的变化。

### 1.1.3 再平衡的适用范围与边界
- 适用于所有类型的投资组合，尤其适合长期投资。
- 边界包括市场剧烈波动、投资者风险承受能力变化等。

## 1.2 格雷厄姆的投资理念与再平衡策略

### 1.2.1 格雷厄姆的价值投资理论
- 强调安全边际和长期稳健投资。
- 通过分散投资降低风险。

### 1.2.2 格雷厄姆的再平衡策略
- 通过定期调整投资组合的资产配置，维持目标比例。
- 强调纪律性和系统性，避免情绪化决策。

# 第2章：投资组合再平衡的数学模型与算法

## 2.1 投资组合再平衡的数学模型

### 2.1.1 投资组合的权重计算公式
$$w_i = \frac{v_i}{\sum_{j=1}^{n} v_j}$$
其中，$w_i$ 是第i个资产的权重，$v_i$ 是第i个资产的价值，$\sum_{j=1}^{n} v_j$ 是总价值。

### 2.1.2 资产调整金额计算
调整金额 = 目标权重 × 总资产 - 当前权重 × 总资产

    total = sum(asset_values)
    weights = [v/total for v in asset_values]
    return weights

    # 计算调整金额
    adjust_amounts = [target_weights[i] * total_value - current_weights[i] * total_value for i in range(len(target_weights))]
