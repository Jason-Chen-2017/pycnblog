### 第3章: 概率思维的数学基础

#### 3.1 概率论的基本原理
- **概率的基本定义**：
  - 概率：0 ≤ P ≤ 1，表示事件发生的可能性。
- **概率的加法法则**：
  - P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
- **条件概率与贝叶斯定理**：
  - 条件概率公式：P(B|A) = P(A ∩ B) / P(A)
  - 贝叶斯定理：P(A|B) = [P(B|A) * P(A)] / P(B)

#### 3.2 量子概率的数学模型
- **量子态的数学表示**：
  - 量子态：|ψ⟩ = a|0⟩ + b|1⟩
  - 概率：P(0) = |a|²，P(1) = |b|²
- **量子概率的计算公式**：
  - 量子叠加：P(0) + P(1) = 1
- **量子概率与经典概率的区别**：
  - 经典概率：独立事件的概率相加。
  - 量子概率：事件之间存在量子叠加和纠缠关系。
