## 第1章: 价值投资的起源与发展

### 1.1 价值投资的定义与核心理念
价值投资是一种以基本面分析为基础的投资策略，强调以低于内在价值的价格购买优质资产。其核心理念是寻找市场上的“烟堆”，即那些被市场低估的投资标的。

- **核心概念**：
  - **内在价值**：资产在未来现金流的现值，不依赖于市场情绪。
  - **安全边际**：买入价格与内在价值的差距，提供了风险缓冲。

### 1.2 马克·莫比乌斯的贡献与影响力

  - 倡导长期投资，避免短期市场波动的干扰。

### 1.3 新兴市场的定义与特点
新兴市场通常指那些经济快速发展但尚未完全工业化的国家，如中国、印度、巴西等。这些市场的特点是：

- **高波动性**：市场容易受到外部因素影响，价格波动剧烈。
- **高增长潜力**：经济发展速度快，企业盈利能力强。
- **不完善性**：市场机制不完善，信息透明度较低。

# 第二部分: 新兴市场价值投资的核心策略

## 第3章: 新兴市场的基本面分析

### 3.1 基本面分析的核心要素
基本面分析是价值投资的核心，主要包括以下几个方面：

- **政治经济环境分析**：
  - 政治稳定性：新兴市场容易受到政局变化的影响。
  - 经济政策：货币、财政政策对市场的影响。

- **行业发展趋势分析**：
  - 行业周期：选择处于上升周期的行业。
  - 市场竞争格局：选择具有竞争优势的企业。

- **公司财务状况评估**：
  - 盈利能力：ROE（净资产收益率）是衡量公司盈利能力的重要指标。
  - 偿债能力：关注资产负债率和流动比率。
  - 成长能力：关注收入和利润的持续增长。

### 3.2 马克·莫比乌斯的选股标准
莫比乌斯的选股标准主要基于以下几个指标：

- **低市盈率（P/E）**：
  - 市盈率低于行业平均水平，意味着股票价格被低估。
  - 公式：P/E = 市场价 / 每股收益。

- **低市净率（P/B）**：
  - 市净率低于行业平均水平，表明资产价值被低估。
  - 公式：P/B = 市场价 / 每股净资产。

- **高股息率**：
  - 股息率高，意味着公司盈利稳定，愿意回馈股东。
  - 公式：股息率 = 每股股息 / 市场价。

### 3.3 行业选择与投资时机
- **行业选择**：
  - 优先选择那些具有高增长潜力的行业，如科技、消费和医疗。
  - 避免选择那些竞争激烈且增长空间有限的行业。

- **投资时机**：
  - 在市场下跌时买入，尤其是当市场出现恐慌性抛售时。
  - 长期持有，避免频繁交易。
