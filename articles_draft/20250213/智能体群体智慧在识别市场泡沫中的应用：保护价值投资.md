## 第1章 背景介绍

### 1.1 市场泡沫的定义与特征

市场泡沫是指资产价格偏离其实际价值的非理性上涨现象。其主要特征包括价格虚高、交易量激增、投资者情绪盲目乐观等。

### 1.2 智能体群体智慧的定义与特征

智能体是具备感知、决策和行动能力的实体；群体智慧则通过个体协作形成整体的智慧，其优势在于去中心化、鲁棒性和涌现性。

### 1.3 智能体群体智慧在金融领域的应用前景

金融领域的复杂性要求更高效的分析工具，智能体群体智慧凭借其独特优势，为市场泡沫识别提供了新的可能性。

## 第5章 项目实战

### 5.1 环境安装

### 5.2 核心代码实现

训练LSTM模型识别市场泡沫。

```python
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow.keras import layers

# 数据加载与预处理
data = pd.read_csv('market_data.csv')
data = data.values
data = data.astype('float32')

# 划分训练集和测试集
train_size = int(len(data) * 0.7)
train_data = data[:train_size]
test_data = data[train_size:]

# 数据标准化
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
train_data = scaler.fit_transform(train_data)
test_data = scaler.fit_transform(test_data)

# 构建数据集
def create_dataset(data, look_back=1):
    X, Y = [], []
    for i in range(len(data)-look_back):
        X.append(data[i:i+look_back])
        Y.append(data[i+look_back])
    return np.array(X), np.array(Y)

look_back = 1
X_train, Y_train = create_dataset(train_data, look_back)
X_test, Y_test = create_dataset(test_data, look_back)

# 模型构建
model = tf.keras.Sequential()
model.add(layers.LSTM(64, input_shape=(look_back, train_data.shape[1])))
model.add(layers.Dense(1))
model.compile(loss='mean_squared_error', optimizer='adam')

# 训练模型
model.fit(X_train, Y_train, epochs=50, batch_size=32, verbose=1)

# 预测与评估
train预测 = model.predict(X_train)
test预测 = model.predict(X_test)
```
