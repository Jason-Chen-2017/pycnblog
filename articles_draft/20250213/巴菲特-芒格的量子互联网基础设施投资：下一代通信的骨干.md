# 第二部分：量子互联网基础设施的技术背景

## 第2章：量子互联网的基本概念

### 2.1 量子通信的定义

量子通信是一种利用量子力学原理进行信息传输的技术，主要包括量子密钥分发（QKD）和量子中继（QR）。

$$\text{量子密钥分发：} QKD = \text{安全性} + \text{不可克隆性}$$

### 2.2 量子互联网的技术优势

#### 2.2.1 量子通信的安全性

量子通信的核心优势在于其安全性。基于量子力学的特性，任何对量子密钥的测量都会破坏密钥的状态，从而实现通信的安全性。

### 2.3 量子互联网的关键技术领域

#### 2.3.1 量子纠缠与量子密钥分发

量子纠缠是一种量子状态，使得两个或多个粒子之间可以瞬间建立关联。量子密钥分发利用这种特性，实现安全的密钥传输。

#### 2.3.2 量子中继与量子网络协议

量子中继是一种通过中继站扩展量子通信距离的技术。量子网络协议则定义了量子通信的规则和流程。
