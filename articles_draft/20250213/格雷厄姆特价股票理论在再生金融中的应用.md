# 第1章：格雷厄姆特价股票理论概述

## 1.1 格雷厄姆投资理论的核心理念

### 1.1.1 价值投资的定义与核心要素
- 价值投资：寻找市场价格低于内在价值的股票。
- 核心要素：安全边际、低市盈率、低市净率。

### 1.1.2 格雷厄姆的“安全边际”概念
- 安全边际：买入价格与内在价值的差距，确保投资的安全性。
- 计算公式：安全边际 = 市场价格 - 内在价值。

### 1.1.3 特价股票的定义与特征
- 特价股票：市场价格远低于内在价值的股票。
- 特征：低市盈率、低市净率、高股息率。

## 1.2 格雷厄姆特价股票的筛选标准

### 1.2.1 市盈率（P/E）的计算与应用
- 市盈率公式：P/E = 市场价格 / 每股收益。
- 应用：寻找低市盈率的股票，避免高估。

### 1.2.2 市净率（P/B）的计算与应用
- 市净率公式：P/B = 市场价格 / 每股净资产。
- 应用：寻找低市净率的股票，避免高估。

### 1.2.3 股东权益收益率（ROE）的计算与应用
- ROE公式：ROE = 净利润 / 股东权益。
- 应用：高ROE表示公司盈利能力强。

## 1.3 格雷厄姆投资策略的优缺点分析

### 1.3.1 优点：低估股票的长期增值潜力
- 长期持有，价值回归。

### 1.3.2 缺点：短期市场波动的应对挑战
- 市场波动可能导致短期亏损。

### 1.3.3 适用场景与限制条件
- 适用于市场低谷期，不适用于市场牛市。

## 1.4 本章小结
- 格雷厄姆理论强调安全边际和价值投资，适用于市场低谷期。
