### 3.2 筛选算法的实现  
通过Python代码实现20格打孔卡的筛选算法：

```python
def score_company(company_data):
    # 公司数据：company_data 包含20个维度的评分
    weights = [0.05, 0.1, 0.05, ...]  # 权重分配
    total_score = sum(score * weight for score, weight in zip(company_data, weights))
    return total_score

# 示例应用
companies = [
    {"name": "苹果", "scores": [...]},
    {"name": "微软", "scores": [...]},
    # 更多公司数据
]

for company in companies:
    score = score_company(company["scores"])
    if score > 80:
        selected_companies.append(company)
```
