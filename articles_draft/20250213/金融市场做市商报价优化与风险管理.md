### 数学公式示例

在报价优化中，常用的统计套利模型可以通过数学公式描述。例如，均值回归模型可以表示为：

$$ \text{spread} = \text{max}(0, \mu - \sigma) $$

其中，$\mu$ 是均值，$\sigma$ 是标准差，spread 是价差。

### 代码实现示例

以下是报价优化模块的一个简单Python实现示例：

```python
import numpy as np
import pandas as pd

# 示例数据
data = pd.DataFrame({
    'bid': [100, 101, 102],
    'ask': [101, 102, 103]
})

# 统计套利模型
def calculate_spread(data):
    bid = data['bid']
    ask = data['ask']
    spread = ask - bid
    return spread.mean()

# 计算并输出平均价差
average_spread = calculate_spread(data)
print(f"Average Spread: {average_spread}")
```
