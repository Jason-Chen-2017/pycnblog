#### 1.1.1 图表示学习的定义与核心概念
图表示学习是一种将图结构数据转换为低维向量表示的方法。其核心目标是将图中的节点、边或子图表示为具有语义信息的低维向量，同时保留图的结构特征和节点之间的关系。

- **图的定义**：图由节点（顶点）和边（边）组成，节点表示实体（如公司、投资者、交易），边表示实体之间的关系（如交易、投资、关联）。
- **图表示学习的核心任务**：将图中的节点或子图映射到低维空间，同时保留图的结构特征和语义信息。

#### 1.1.2 图表示学习在金融领域的应用价值
金融市场的复杂性要求我们不仅关注单个实体的风险，还需考虑实体之间的关联和网络化风险传播机制。图表示学习在以下方面具有重要应用：

## 第3章: 图表示学习算法原理

### 3.1 节点嵌入算法

#### 3.1.1 Node2Vec算法原理
Node2Vec是一种基于随机游走的节点嵌入算法，通过在图中进行随机游走生成节点序列，然后使用Word2Vec进行训练。

- **随机游走**：在图中随机游走，生成节点序列。
- **Word2Vec训练**：将节点序列输入Word2Vec模型，生成节点嵌入。

#### 3.1.2 Node2Vec算法实现流程
1. 初始化嵌入向量。
2. 进行随机游走生成节点序列。
3. 使用Word2Vec训练节点嵌入。

---

### 3.2 图嵌入算法

#### 3.2.1 图卷积网络（GCN）原理
GCN是一种基于图卷积的深度学习模型，通过聚合邻居节点的信息生成节点表示。

- **GCN层**：通过聚合邻居节点的信息生成新的节点表示。
- **激活函数**：如ReLU。

#### 3.2.2 图注意力网络（GAT）原理
GAT通过注意力机制聚合邻居节点的信息，生成节点表示。

- **注意力机制**：计算每个邻居节点的重要性。
- **聚合邻居信息**：根据注意力权重聚合邻居节点的信息。

### 3.3 图表示学习的数学模型

#### 3.3.1 图表示学习的数学公式
1. GCN的数学公式：
   $$ h^{(l+1)} = \text{ReLU}(\sum_{j \in N(i)} A_{ij} h_j^{(l)}) $$
2. GAT的数学公式：

```python
import tensorflow as tf
from tensorflow.keras import layers

# 定义图卷积层
def gcn_layer(inputs, kernel_size, activation='relu'):
    adj = tf.sparse_ops.SparseTensor(indices=inputs[1].indices,
                                      values=inputs[1].values,
                                      dense_shape=inputs[1].dense_shape)
    outputs = tf.sparse_ops.sparse_matmul(inputs[0], adj)
    outputs = layers.Dense(kernel_size, activation=activation)(outputs)
    return outputs

# 定义图卷积网络模型
def build_gcn_model(input_shape, kernel_size):
    inputs = tf.keras.Input(shape=input_shape)
    outputs = gcn_layer(inputs, kernel_size)
    model = tf.keras.Model(inputs=inputs, outputs=outputs)
    return model
```
