# 第1章 公司环境责任评估的背景介绍

## 1.1 环境责任评估的定义与核心概念

### 1.1.1 环境责任的定义

环境责任是指公司在经营过程中对环境造成的影响及相应的责任，包括减少污染、节约资源和应对气候变化等方面。

### 1.1.2 公司环境责任的核心要素

- 环境影响：公司对自然资源的消耗和排放。
- 社会责任：公司在社会中的角色和影响。
- 治理结构：公司内部的管理机制。

### 1.1.3 环境责任与企业可持续发展的关系

环境责任是企业实现可持续发展的重要组成部分，直接影响企业的长期竞争力。
