## 第一部分: 价值投资大师的智慧概述

### 第1章: 价值投资的核心理念

#### 1.1 价值投资的定义与背景

价值投资是一种以企业内在价值为核心的投资策略，强调以低于内在价值的价格买入优质资产，长期持有，获得超额收益。其核心理念来源于格雷厄姆和多德的价值投资理论，强调安全边际、基本面分析和长期持有。

**核心概念：**
- **内在价值**：资产的公允价值，基于其未来现金流的现值。
- **安全边际**：买入价格低于内在价值，以降低风险并确保收益。
- **长期持有**：避免频繁交易，减少交易成本和市场波动的影响。

#### 1.2 价值投资的关键要素

1. **企业基本面分析**：
   - 通过财务报表分析企业的盈利能力、成长性和财务健康状况。
2. **安全边际**：
   - 买入价格与内在价值之间的折扣，确保投资的安全性。
3. **长期投资与复利效应**：
   - 长期持有优质资产，利用复利效应实现财富增长。

#### 1.3 价值投资的适用场景与局限性

1. **适用场景**：
   - 市场估值过高时，寻找被低估的资产。
2. **局限性**：
   - 短期市场波动可能导致账面亏损。
   - 需要较高的研究能力和信息处理能力。

### 第2章: 格雷厄姆的价值投资体系

#### 2.1 格雷厄姆的生平与贡献

格雷厄姆（1897-1975）是价值投资的奠基人，其核心思想体现在《证券分析》和《聪明的投资者》中。他强调安全边际和防御性投资，倡导以低于内在价值的价格买入股票。

#### 2.2 格雷厄姆的价值投资体系

1. **安全边际**：
   - 买入价格 ≤ 内在价值 × 折扣率。
2. **内在价值计算**：
   - 基于企业的未来现金流，使用DCF模型计算内在价值。
3. **投资组合管理**：
   - 分散投资，降低风险。

#### 2.3 格雷厄姆的经典投资案例

- **具体案例**：购买某公司股票时，计算其内在价值为100美元，以80美元买入，确保安全边际。

### 第3章: 巴菲特的价值投资实践

#### 3.1 巴菲特的生平与投资理念

巴菲特（1934-）是格雷厄姆的学生，继承并发展了价值投资理论。他强调寻找具有“护城河”的企业，长期持有优质资产。

#### 3.2 巴菲特的投资策略与技巧

1. **护城河**：
   - 企业竞争优势，如品牌、技术壁垒、成本优势。
2. **集中投资**：
   - 重点投资少数优质企业，提高收益。
3. **长期持有**：
   - 避免短期波动，获得复利收益。

#### 3.3 巴菲特的经典投资案例

- **可口可乐**：巴菲特长期持有，因其强大的品牌和市场地位。

### 第4章: 费雪的投资策略与思想

#### 4.1 费雪的生平与主要思想

费雪（1933-2008）倡导“成长股”投资，强调寻找具有持续增长潜力的企业。

#### 4.2 费雪的投资策略与选股标准

1. **成长股**：
   - 企业收入和利润持续增长。
2. **管理层质量**：
   - 高层团队能力强，企业治理良好。
3. **行业前景**：
   - 投资具有广阔增长空间的行业。

#### 4.3 费雪的经典投资案例

- **英特尔**：选择具有技术壁垒和增长潜力的企业。

### 第5章: 伯格的投资哲学与策略

#### 5.1 伯格的生平与贡献

伯格（1934-）是指数投资的倡导者，强调长期投资和分散风险。

#### 5.2 伯格的投资策略与思想

1. **指数投资**：
   - 通过投资指数基金，获得市场平均收益。
2. **分散投资**：
   - 降低非系统性风险。
3. **长期持有**：
   - 避免频繁交易，减少成本。

#### 5.3 伯格的经典投资案例

- ** Vanguard 指数基金**：长期持有指数基金，获得市场平均收益。

import numpy as np

# 计算内在价值（简化版DCF模型）
def calculate_intrinsic_value(cash_flows, discount_rate):
    return np.irr(cash_flows) / (1 + discount_rate)

# 计算投资组合风险与收益
def portfolio_analysis(returns, weights):
    returns = np.array(returns)
    weights = np.array(weights)
    expected_return = np.sum(returns * weights)
    variance = np.dot(weights.T, np.dot(np.cov(returns), weights))
    return expected_return, variance

# 示例数据：股票A和股票B的预期收益和权重
returns = [0.1, 0.15]
weights = [0.5, 0.5]

# 计算投资组合的预期收益和风险
expected_return, variance = portfolio_analysis(returns, weights)
print(f"预期收益: {expected_return}")
print(f"风险: {variance}")
