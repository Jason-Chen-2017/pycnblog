# 第一部分: 芒格的"数学期望"思维基础

## 第1章: 数学期望的基本概念与芒格投资哲学

### 1.1 数学期望的定义与基本属性

数学期望是概率论中的核心概念，用于量化随机变量的平均值或长期趋势。其定义如下：

$$
E[X] = \sum_{i=1}^{n} x_i \cdot P(X = x_i)
$$

其中，$x_i$ 是随机变量 $X$ 的可能取值，$P(X = x_i)$ 是对应取值的概率。

数学期望具有以下关键属性：
- 线性性：$E[aX + b] = aE[X] + b$
- 对称性：如果随机变量对称分布，其期望等于分布的中心点
- 风险中性：期望值不考虑实际结果与期望值的偏差（即不考虑风险）

### 1.2 芒格的生平与投资哲学

芒格（Warren Buffett）是全球著名投资者，其投资哲学以价值投资为核心，强调长期持有优质资产。芒格的投资决策过程深受数学期望思维的影响，他认为：

- 投资的本质是通过概率分析，找到具有安全边际的高概率投资机会
- 长期来看，市场波动不影响投资收益，真正的投资是时间的朋友
- 风险控制是投资成功的关键，而数学期望思维帮助他在概率上优化投资组合

### 1.3 数学期望在投资中的应用

数学期望在投资中主要用于：
1. 计算资产的期望收益率
2. 评估投资组合的风险与收益比
3. 判断投资决策的长期可行性

## 第3章: 数学期望的算法原理与实现

### 3.1 数学期望的计算方法

#### 离散型随机变量的期望值计算

假设有一个掷骰子的随机试验，骰子的点数为 $1, 2, 3, 4, 5, 6$，每种结果的概率均为 $\frac{1}{6}$。期望值为：

$$
E[X] = \frac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = 3.5
$$

#### 连续型随机变量的期望值计算

对于均匀分布在区间 $[a, b]$ 的随机变量，期望值为：

$$
E[X] = \frac{a + b}{2}
$$

### 3.2 数学期望的Python实现

以下是计算掷骰子期望值的Python代码：

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义随机变量
x = np.array([1, 2, 3, 4, 5, 6])
p = np.array([1/6]*6)

# 计算期望值
E_X = np.sum(x * p)
print("期望值 E[X] =", E_X)

# 可视化概率分布
plt.bar(x, p)
plt.title('Probability Distribution')
plt.xlabel('Possible Outcomes')
plt.ylabel('Probability')
plt.show()
```

### 6.2 核心代码实现

计算股票投资组合的期望收益：

```python
import numpy as np

# 定义资产的收益率
returns = np.array([0.1, 0.15, 0.08, 0.12])
p = np.array([0.3, 0.4, 0.2, 0.1])

# 计算期望收益
E_Return = np.sum(returns * p)
print("期望收益 =", E_Return)
```

### 6.3 代码解读与分析

- **输入**：资产的收益率及对应概率
- **输出**：投资组合的期望收益
- **意义**：帮助投资者量化投资组合的长期收益

### 6.4 实际案例分析

以股票投资为例，假设某股票有以下可能的收益率和概率：

| 收益率（%） | 概率 |
|------------|------|
| 10         | 0.3  |
| 15         | 0.4  |
| 8          | 0.2  |
| 12         | 0.1  |

计算其期望收益率：

$$
E[R] = 0.3 \times 10 + 0.4 \times 15 + 0.2 \times 8 + 0.1 \times 12 = 10.5\%
$$
