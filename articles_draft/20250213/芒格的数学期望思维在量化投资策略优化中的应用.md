## 第二部分: 数学期望模型与量化投资策略

### 第2章: 数学期望模型的构建与分析

#### 2.1 数学期望的基本概念

数学期望是概率论中的核心概念，表示随机变量的平均值。其公式为：

$$ E[X] = \sum_{i=1}^{n} P(x_i) \cdot x_i $$

其中，$P(x_i)$ 是结果 $x_i$ 的概率。

#### 2.2 投资收益的数学期望模型

投资收益的期望值计算公式为：

$$ E[R] = \sum_{i=1}^{n} P(r_i) \cdot r_i $$

其中，$r_i$ 是可能的收益，$P(r_i)$ 是对应的概率。

#### 2.3 蒙特卡洛模拟在数学期望中的应用

蒙特卡洛模拟是一种通过随机采样来估计概率分布的方法。在投资中，可以用来模拟不同市场条件下的收益分布，从而计算期望值。

#### 6.2 代码实现

```python
import yfinance as yf
import numpy as np

def fetch_data(ticker, start, end):
    df = yf.download(ticker, start=start, end=end)
    return df['Adj Close']

def compute_optimal_portfolio(prices, weights):
    returns = np.log(prices[1:] / prices[:-1])
    covariance_matrix = np.cov(returns.T)
    portfolio_return = np.sum(weights * np.mean(returns))
    portfolio_risk = np.sqrt(np.dot(weights.T, np.dot(covariance_matrix, weights)))
    return portfolio_return, portfolio_risk

# 示例代码
tickers = ['AAPL', 'MSFT', 'GOOGL']
weights = np.array([0.4, 0.4, 0.2])
prices = [fetch_data(ticker, '2020-01-01', '2023-01-01') for ticker in tickers]
prices = pd.DataFrame({tickers[0]: prices[0], tickers[1]: prices[1], tickers[2]: prices[2]})

portfolio_return, portfolio_risk = compute_optimal_portfolio(prices.values, weights)
print(f'Portfolio Expected Return: {portfolio_return:.2%}')
print(f'Portfolio Risk: {portfolio_risk:.2%}')
```
