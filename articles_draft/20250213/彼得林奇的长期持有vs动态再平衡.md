```python
def calculate_rebalance(current_weights, target_weights):
    rebalanced = {}
    total = sum(current_weights.values())
    for asset in target_weights:
        rebalanced[asset] = (target_weights[asset] / total) * current_weights.get(asset, 0)
    return rebalanced
```

### 10.3 代码应用解读
- 计算当前资产权重与目标权重的差异。
