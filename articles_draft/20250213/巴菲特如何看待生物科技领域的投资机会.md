## 第2章：核心概念与联系

### 2.1 核心概念的定义与特征

#### 2.1.1 核心概念的定义
- **ROE**：净利润/股东权益，衡量股东资金的使用效率。
- **ROA**：净利润/总资产，衡量资产的盈利能力。
- **ROCE**：息税前利润/总资本，衡量资本的回报效率。

#### 2.1.2 核心概念的属性特征对比
| 指标 | 定义 | 适用场景 |
|------|------|----------|
| ROE | 净利润/股东权益 | 评估股东资金使用效率 |
| ROA | 净利润/总资产 | 评估资产盈利能力 |
| ROCE | 息税前利润/总资本 | 评估资本回报效率 |

## 第3章：数学模型与算法原理

### 3.1 投资评估的数学模型

#### 3.1.1 ROE计算公式
$$ \text{ROE} = \frac{\text{净利润}}{\text{股东权益}} $$

#### 3.1.2 投资决策流程
```mermaid
graph TD
    A[开始] --> B[收集公司数据]
    B --> C[计算ROE、ROA、ROCE]
    C --> D[评估企业竞争优势]
    D --> E[分析行业趋势]
    E --> F[确定投资决策]
    F --> G[结束]
```

#### 3.1.3 Python代码实现
```python
def calculate_roe(net_profit, shareholders_equity):
    return net_profit / shareholders_equity

def calculate_roa(net_profit, total_assets):
    return net_profit / total_assets

def calculate_roce(ebit, total_capital):
    return ebit / total_capital

# 示例数据
net_profit = 100
shareholders_equity = 500
total_assets = 1000
total_capital = 800
ebit = 150

# 计算指标
roe = calculate_roe(net_profit, shareholders_equity)
roa = calculate_roa(net_profit, total_assets)
roce = calculate_roce(ebit, total_capital)

print(f"ROE: {roe:.2f}, ROA: {roa:.2f}, ROCE: {roce:.2f}")
```
