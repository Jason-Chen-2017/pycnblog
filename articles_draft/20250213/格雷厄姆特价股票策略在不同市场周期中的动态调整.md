## 第一部分: 格雷厄姆价值投资概述

### 第1章: 价值投资的起源与发展

#### 1.1 价值投资的定义与核心理念
- **定义**: 价值投资是一种以低于内在价值的价格买入优质股票的投资策略。
- **核心理念**: 强调安全边际、内在价值和市场情绪的周期性波动。
- **与现代投资理论的对比**: 价值投资注重基本面分析，而现代投资理论更倾向于市场有效性和资产配置。

#### 1.2 格雷厄姆的投资哲学与方法
- **安全边际**: 买入价格低于内在价值的股票，以降低投资风险。
- **内在价值计算**: 通过分析公司财务报表，估算公司未来现金流的现值。
- **逆向思维**: 在市场恐慌时寻找低估股票，在市场狂热时保持冷静。

#### 1.3 价值投资与现代投资策略的联系与区别
- **联系**: 两者都强调风险控制和长期投资。
- **区别**: 价值投资注重个股筛选，而现代投资策略更注重资产配置和分散投资。

### 第2章: 特价股票的定义与特征

#### 2.1 特价股票的定义
- 特价股票是指市场价格低于其内在价值的股票，通常是由于市场恐慌或投资者情绪导致的低估。

#### 2.2 特价股票的特征与筛选标准
- **低市盈率（P/E）**: 市盈率低于行业平均水平。
- **低市净率（P/B）**: 市净率低于行业平均水平。
- **高股息率**: 股息收益率高于市场平均水平。

#### 2.3 特价股票与市场周期的关系
- **牛市**: 特价股票较少，市场情绪高涨，股票价格被高估。
- **熊市**: 特价股票较多，市场恐慌导致股票价格被低估。
- **震荡市**: 特价股票出现的频率较高，但需要结合市场周期判断。

### 第3章: 市场周期的基本分析

#### 3.1 市场周期的定义与分类
- **定义**: 市场周期是指股票市场在一段时间内的波动和变化，通常分为牛市、熊市和震荡市。
- **分类**: 
  1. **牛市**: 市场整体上涨，投资者情绪乐观。
  2. **熊市**: 市场整体下跌，投资者情绪悲观。
  3. **震荡市**: 市场波动较大，方向不明确。

#### 3.2 不同市场周期对投资策略的影响
- **牛市**: 
  - 特价股票较少，需降低仓位，选择优质成长股。
  - 增加对高增长行业的配置。
- **熊市**: 
  - 特价股票较多，需增加仓位，寻找被低估的股票。
  - 优先选择高分红股，以减少市场波动的影响。
- **震荡市**: 
  - 特价股票可能出现，但需谨慎选择。
  - 保持中等仓位，避免过度集中。

#### 3.3 市场周期分析的工具与方法
- **技术分析工具**: 移动平均线、相对强弱指数（RSI）、MACD等。
- **基本面分析**: GDP增长率、企业盈利状况、行业趋势等。

## 第二部分: 格雷厄姆策略的核心概念

### 第4章: 格雷厄姆策略的核心原理

#### 4.1 安全边际的概念与作用
- **安全边际**: 股票的市场价格与内在价值之间的差距。
- **作用**: 提供风险缓冲，降低投资损失的可能性。

#### 4.2 内在价值的计算方法
- **公式**: 
  内在价值 = 未来现金流的现值。
  $$ V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$
  其中，CF_t 是第t年的现金流，r是折现率。

#### 4.3 价格与价值的偏离与回归
- **偏离**: 市场价格与内在价值的偏离，通常由市场情绪引起。
- **回归**: 长期来看，市场价格会回归其内在价值。

### 第5章: 特价股票筛选的指标体系

#### 5.1 市盈率（P/E）分析
- **定义**: 市盈率 = 股票价格 / 每股收益（EPS）。
- **应用**: 选择市盈率低于行业平均水平的股票。

#### 5.2 市净率（P/B）分析
- **定义**: 市净率 = 股票价格 / 每股净资产（BPS）。
- **应用**: 选择市净率低于1的股票。

#### 5.3 股息率与股息支付率分析
- **股息率**: 股息率 = 每股股息 / 股票价格。
- **股息支付率**: 股息支付率 = 股息 / 净利润。

#### 5.4 其他指标
- **ROE**: 净资产收益率。
- **负债率**: 负债总额 / 资产总额。

### 第6章: 格雷厄姆策略与现代投资策略的对比

#### 6.1 格雷厄姆策略与趋势投资法的对比
- **趋势投资法**: 顺势而为，跟随市场趋势。
- **格雷厄姆策略**: 逆市而行，寻找低估股票。

#### 6.2 格雷厄姆策略与技术分析的对比
- **技术分析**: 通过价格和成交量预测未来走势。
- **格雷厄姆策略**: 通过基本面分析寻找低估股票。

#### 6.3 格雷厄姆策略与量化投资的对比
- **量化投资**: 使用数学模型进行投资决策。
- **格雷厄姆策略**: 更注重基本面分析和安全边际。

### 第11章: 牛市中的策略调整

#### 11.1 环境安装
- **工具**: Python 3.8以上版本，pandas、numpy、scikit-learn库。

#### 11.2 核心实现代码
```python
import pandas as pd
import numpy as np

def calculate_pe(df):
    pe = df['Price'] / df['EPS']
    return pe

def calculate_pb(df):
    pb = df['Price'] / df['BPS']
    return pb

def main():
    # 假设df是股票数据
    df = pd.read_csv('stock_data.csv')
    pe = calculate_pe(df)
    pb = calculate_pb(df)
    # 筛选低估股票
    value_stocks = df[(pe < pe.mean()) & (pb < pb.mean())]
    print(value_stocks)

if __name__ == "__main__":
    main()
```

import pandas as pd
import numpy as np

def calculate_pe(df):
    pe = df['Price'] / df['EPS']
    return pe

def calculate_pb(df):
    pb = df['Price'] / df['BPS']
    return pb

def main():
    # 假设df是股票数据
    df = pd.read_csv('stock_data.csv')
    pe = calculate_pe(df)
    pb = calculate_pb(df)
    # 筛选低估股票
    value_stocks = df[(pe < pe.mean() * 0.8) & (pb < pb.mean() * 0.8)]

if __name__ == "__main__":
    main()
