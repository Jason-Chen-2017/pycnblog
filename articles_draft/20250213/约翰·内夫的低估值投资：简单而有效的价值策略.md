## 第一章：低估值投资的背景与基础

### 1.1 投资的基石：低估值策略

#### 1.1.1 低估值投资的核心概念

低估值投资是一种基于价值投资的策略，旨在寻找市场价格低于其内在价值的股票。核心在于识别被市场低估的企业，通过长期持有实现资本增值。

#### 1.1.2 低估值投资的历史发展

低估值投资起源于本杰明·格雷厄姆的价值投资理论，强调安全边际和对公司内在价值的评估。约翰·内夫在此基础上发展了更为系统的筛选方法，结合定量分析和定性评估。

#### 1.1.3 约翰·内夫的投资哲学

内夫注重企业的基本面分析，强调企业的财务健康、竞争优势和可持续发展能力。他认为，低估值股票往往在市场低迷时期出现，耐心持有是成功的关键。

## 第二章：低估值投资的理论基础

### 2.1 价值投资的起源

#### 2.1.1 本杰明·格雷厄姆的价值投资理论

格雷厄姆提出“安全边际”概念，建议投资者购买市场价格远低于其内在价值的股票，以降低风险并确保收益。

#### 2.1.2 约翰·内夫对价值投资的贡献

内夫将格雷厄姆的理论转化为具体的投资策略，通过量化指标和系统筛选方法，进一步优化了低估值投资的实践。

## 第四章：低估值投资的筛选标准

### 4.1 低估值股票的筛选标准

#### 4.1.1 市盈率低于行业平均水平

市盈率 = 股价 / 每股净利润

#### 4.1.2 市净率低于行业平均水平

市净率 = 股价 / 每股净资产

#### 4.1.3 股息率高于行业平均水平

股息率 = 每股股息 / 股价

### 5.2 算法实现代码

```python
import pandas as pd

def screen_low_valuation(stocks, industry_avg_pe, industry_avg_pb, industry_avg_div_yield):
    low_valuation_stocks = []
    for stock in stocks:
        if (stock.pe < industry_avg_pe and
            stock.pb < industry_avg_pb and
            stock.div_yield > industry_avg_div_yield):
            low_valuation_stocks.append(stock)
    return low_valuation_stocks

# 示例数据
class Stock:
    def __init__(self, name, pe, pb, div_yield):
        self.name = name
        self.pe = pe
        self.pb = pb
        self.div_yield = div_yield

stocks = [
    Stock("公司A", 10, 1.5, 2.5),
    Stock("公司B", 12, 1.2, 3.0),
    Stock("公司C", 8, 2.0, 1.8)
]

industry_avg_pe = 15
industry_avg_pb = 2.0
industry_avg_div_yield = 2.0

result = screen_low_valuation(stocks, industry_avg_pe, industry_avg_pb, industry_avg_div_yield)
for stock in result:
    print(f"{stock.name}: 市盈率={stock.pe}, 市净率={stock.pb}, 股息率={stock.div_yield}")
```
