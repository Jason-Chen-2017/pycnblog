## 第一部分: 净净股策略的背景与核心概念

### 第1章: 净净股策略的起源与背景

#### 1.1 净净股策略的起源

格雷厄姆是价值投资的鼻祖，他的净净股策略是基于对公司内在价值的深入分析。净净股策略的核心是寻找市场价格低于其净资产价值的股票，即市净率（P/B）小于1的股票。这种策略在市场低迷或公司暂时困境时尤为有效。

#### 1.2 格雷厄姆的价值投资理论

格雷厄姆认为，股票的内在价值是其未来现金流的现值。他强调安全边际的重要性，即买入价格远低于内在价值，以降低风险。这种理念在净净股策略中得到体现，通过关注市净率，确保买入价格具有足够的安全边际。

#### 1.3 净净股策略的其他特点

- **低市净率**：净净股通常具有较低的市净率，表明市场对其估值较低。
- **高资产质量**：公司资产质量高，即使市场波动，其价值也能得到保障。
- **防御性投资**：净净股策略适合防御性投资，在市场下跌时表现相对稳定。

### 第2章: 净净股策略的核心概念与原理

#### 2.1 净净股的定义与分类

净净股是指市场价格低于其净资产价值的股票。分类上，净净股可以分为两类：一类是市场价格远低于净资产，具有较大的安全边际；另一类是市场价格略低于净资产，风险相对较低。

#### 2.2 净值与股价的关系

- **净资产价值**：公司每股的净资产价值（BV）是衡量其内在价值的重要指标。
- **股价波动**：股价受市场情绪和市场周期影响，可能远低于或高于其实际价值。
- **长期趋势**：长期来看，股价会趋向于其内在价值，但短期波动较大。

#### 2.3 净净股策略的数学模型与公式

- **市净率计算公式**：  
  $$ 市净率 = \frac{股价}{每股净资产} $$  
  净净股的市净率通常小于1，即股价 < 每股净资产。

- **安全边际计算**：  
  $$ 安全边际 = \frac{股价}{内在价值} \times 100\% $$  
  安全边际越高，投资风险越低。

## 第二部分: 净净股策略的算法原理

### 第3章: 净净股策略的评估模型

#### 3.1 净净股的评估流程

1. **计算每股净资产**：  
   $$ 每股净资产 = \frac{净资产}{总股本} $$

2. **计算市净率**：  
   $$ 市净率 = \frac{股价}{每股净资产} $$

3. **筛选市净率小于1的股票**：  
   优先选择市净率 < 1，且公司基本面良好的股票。

#### 3.2 净净股策略的优化

- **行业比较**：不同行业的合理市净率不同，需考虑行业特性。
- **财务指标分析**：结合ROE（净资产收益率）等指标，进一步筛选优质股票。
- **动态调整**：定期评估和调整投资组合，避免长期持有低增长股票。

#### 5.2 核心代码实现

```python
import pandas as pd
import yfinance as yf

def get_netanyahu_stocks(tickers):
    data = {}
    for ticker in tickers:
        stock = yf.Ticker(ticker)
        info = stock.info
        if 'regularMarketPrice' in info and 'bookValue' in info:
            price = info['regularMarketPrice']
            book_value = info['bookValue']
            pb_ratio = price / book_value
            if pb_ratio < 1:
                data[ticker] = {'price': price, 'book_value': book_value, 'pb_ratio': pb_ratio}
    return data

tickers = ['AAPL', 'MSFT', 'GOOGL']
net_stocks = get_netanyahu_stocks(tickers)
print(net_stocks)
```
