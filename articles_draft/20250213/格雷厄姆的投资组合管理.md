## 第一部分：投资组合管理概述

### 第1章：投资组合管理的基本概念

#### 1.1 投资组合管理的定义与重要性
投资组合管理是一种系统化的方法，用于优化投资组合的收益与风险比。其核心目标是在给定风险水平下最大化收益，或在给定收益水平下最小化风险。

#### 1.2 投资组合管理的核心要素
- **资产配置**：决定投资组合中各类资产的比例。
- **风险控制**：通过分散化降低投资组合的整体风险。
- **收益优化**：通过科学的组合构建提高投资回报。

### 第2章：格雷厄姆的投资理念

#### 2.1 价值投资的核心思想
- 格雷厄姆是价值投资的鼻祖，强调以低于内在价值的价格买入优质资产。
- 安全边际：买入价格与内在价值的差距越大，投资的安全性越高。

#### 2.2 防御性投资策略
- 以长期稳健收益为目标，注重资产的安全性。
- 通过分散化降低风险，避免过度集中于高风险资产。

#### 2.3 投资组合构建原则
- **分散化**：通过投资不同资产类别降低风险。
- **长期持有**：避免频繁交易，降低交易成本。
- **价值导向**：优先选择低估的资产。

### 第4章：投资组合优化的数学模型

#### 4.1 现代投资组合理论（MPT）
- MPT由哈里·马科维茨提出，是投资组合管理的理论基础。
- 核心思想：通过分散化投资降低风险。

#### 4.2 均值-方差优化模型
- 投资组合收益的期望值与方差的优化。
- 使用Python实现均值-方差优化。

#### 4.3 投资组合优化的实战应用
```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

# 示例数据：假设我们有两只资产的收益率
returns = np.array([0.1, 0.2])
cov_matrix = np.array([[0.01, 0.005], [0.005, 0.02]])

# 定义优化目标函数
def portfolio_var(weights, returns, cov_matrix):
    return (weights.T @ returns) * (weights.T @ cov_matrix @ weights)

# 约束条件：权重之和为1
def constraint(weights):
    return np.sum(weights) - 1

# 初始权重
weights = [0.5, 0.5]

# 使用scipy优化
result = minimize(portfolio_var, weights, args=(returns, cov_matrix), method='SLSQP', 
                  constraints={'type': 'eq', 'fun': constraint})

print(result.x)
```

import numpy as np

data = {
