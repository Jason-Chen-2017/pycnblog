## 第2章: 巴菲特投资清单的核心要素

### 2.1 企业基本面分析

#### 2.2.1 资产配置与风险控制

### 3.2 投资清单的数学模型

#### 3.2.1 内在价值计算公式

$$
\text{内在价值} = \sum_{t=1}^{\infty} \frac{CF_t}{(r - g)^t}
$$

其中，$CF_t$ 是第 $t$ 年的现金流，$r$ 是折现率，$g$ 是现金流增长率。

#### 3.2.2 安全边际计算公式

$$
\text{安全边际} = \text{市场价格} < \text{内在价值} \times (1 - \text{margin})
$$

def calculate_intrinsic_value(fcf, discount_rate, growth_rate, perpetuity):
    if perpetuity == 0:
        return fcf / discount_rate
    else:
        terminal_value = fcf * (1 + growth_rate) / (discount_rate - growth_rate)
