## 第八章：项目实战

### 8.1 环境安装

### 8.2 核心实现代码
```python
def evaluate_successor(candidates):
    scores = []
    for candidate in candidates:
        investment_score = candidate['investment_skills'] / 100
        leadership_score = candidate['leadership_skills'] / 100
        total_score = investment_score * 0.5 + leadership_score * 0.5
        scores.append(total_score)
    return scores

candidates = [
    {'name': 'Charlie Munger', 'investment_skills': 95, 'leadership_skills': 80},
    {'name': 'Greg Abel', 'investment_skills': 90, 'leadership_skills': 85}
]

scores = evaluate_successor(candidates)
print(scores)
```

### 8.3 代码解读
- 函数`evaluate_successor`计算候选人的综合得分。
- 结果展示：各候选人的得分，用于评估接班可能性。
