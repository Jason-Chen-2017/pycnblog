## 第1章: 引言

### 1.1 特价股票投资的背景与意义
#### 1.1.1 特价股票的定义与特点
特价股票是指价格低于其内在价值，具有较大上涨潜力的股票。其特点包括低估值、高增长潜力和市场波动性。

#### 1.1.2 行业轮动策略的重要性
行业轮动策略通过动态调整投资组合，捕捉不同行业间的轮动机会，优化投资回报。

#### 1.1.3 本文研究目标与结构安排

## 第2章: 特价股票投资中的行业轮动基础

### 2.1 行业轮动的基本概念
#### 2.1.1 行业轮动的定义
行业轮动是指根据市场环境变化，调整投资组合中各行业的权重，以优化收益的过程。

#### 2.1.2 行业轮动的分类
包括周期性轮动、趋势性轮动和事件驱动轮动。

#### 2.1.3 行业轮动的核心要素
包括行业周期、宏观经济指标和市场情绪。

### 2.2 行业轮动的驱动因素
#### 2.2.1 宏观经济因素
如GDP增长率、利率和通货膨胀率。

#### 2.2.2 行业周期性
行业在不同阶段的表现差异。

#### 2.2.3 市场情绪与资金流动
投资者情绪和资金流向对行业轮动的影响。

### 2.3 行业轮动策略的历史案例分析
#### 2.3.1 历史上的行业轮动实例
如2008年金融危机后金融行业的复苏。

#### 2.3.2 从案例中总结的经验与教训

def industry_rotation_strategy(data):
    # 数据预处理
    data_clean = data.dropna()
    # 计算因子
    factor = data_clean['PE'].mean() / data_clean['ROE'].mean()
    # 筛选行业
    selected_industry = data_clean[factor > 1.5]
    return selected_industry
```
