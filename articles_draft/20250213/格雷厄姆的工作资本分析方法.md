#### 9.2 核心实现代码
```python
import pandas as pd

# 示例数据
data = {
    '流动资产': [100, 200, 150],
    '流动负债': [50, 100, 75]
}

df = pd.DataFrame(data)

# 计算流动比率和速动比率
df['流动比率'] = df['流动资产'] / df['流动负债']
df['速动比率'] = (df['流动资产'] - df['存货']) / df['流动负债']

print(df)
```
