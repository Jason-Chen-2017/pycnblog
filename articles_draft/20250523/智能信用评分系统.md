  ```python
  import numpy as np
  from sklearn.linear_model import LogisticRegression

  # 数据预处理
  X = np.array([[...], [...]])  # 特征向量
  y = np.array([...])  # 标签

  # 模型训练
  model = LogisticRegression()
  model.fit(X, y)

  # 预测
  new_data = np.array([[...], [...]])
  print(model.predict(new_data))
  ```

#### 3.4 数学模型与公式
- 逻辑回归模型
  $$ P(y=1|x) = \frac{1}{1 + e^{-z}} $$
  其中，$$ z = w \cdot x + b $$

- 随机森林模型
  $$ L = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$
