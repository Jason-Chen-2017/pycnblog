## 第3章: 算法原理讲解

### 3.1 相关性分析的基本原理
- 协方差衡量变量间变化方向。
- 相关系数衡量变量间线性关系强度。

### 3.2 算法流程图
```mermaid
graph TD
    A[数据采集] --> B[数据清洗]
    B --> C[计算协方差]
    C --> D[计算相关系数]
    D --> E[可视化结果]
```

### 3.3 数学模型与公式
协方差公式：
$$\text{Cov}(X,Y) = E[(X - E[X])(Y - E[Y])]$$
相关系数公式：
$$\rho_{X,Y} = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y}$$
示例计算：X和Y的协方差为0.5，标准差分别为1和2，则相关系数为0.25。

## 第5章: 项目实战

### 5.1 环境安装
安装Python、Pandas、Matplotlib。

### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 数据加载
data = pd.read_csv('economic_data.csv')

# 数据清洗
data_clean = data.dropna()

# 计算协方差
cov = np.cov(data_clean['GDP'], data_clean['MarketValuation'])

# 计算相关系数
corr = np.corrcoef(data_clean['GDP'], data_clean['MarketValuation'])

print(f'协方差: {cov[0,1]}, 相关系数: {corr[0,1]}')

# 可视化
plt.scatter(data_clean['GDP'], data_clean['MarketValuation'])
plt.xlabel('GDP')
plt.ylabel('MarketValuation')
plt.show()
```
