#### 8.3.2 DCF模型计算代码
```python
def discounted_cash_flow(cash_flows, discount_rate):
    return sum(cash_flow / (1 + discount_rate)**t for t, cash_flow in enumerate(cash_flows))

# 示例现金流和折现率
cash_flows = [100, 200, 300]
discount_rate = 0.10

# 计算终值
terminal_value = discounted_cash_flow(cash_flows, discount_rate)
print(f"终值为：{terminal_value}")
```
