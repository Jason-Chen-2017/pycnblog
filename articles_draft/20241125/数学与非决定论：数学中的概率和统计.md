## 第1章：概率论基础

### 背景介绍
概率论作为数学的一个分支，起源于17世纪的赌博游戏。当时，数学家们试图解决如何公平地分配赌注的问题，从而诞生了概率论的基础理论。概率论的核心在于对随机事件的发生可能性进行量化，这在自然科学、社会科学和工程学等领域有着广泛的应用。

### 核心概念与联系
概率论的基本概念包括样本空间、事件、概率的加法规则、乘法规则和条件概率。其中，样本空间是所有可能结果的集合，事件是样本空间的一个子集，概率是事件发生的可能性大小。

### 核心算法原理讲解
概率论的核心算法包括概率分布的计算、随机变量的期望和方差的计算，以及大数定律和中心极限定理。

#### Python源代码实例
```python
import numpy as np
import matplotlib.pyplot as plt

# 概率分布计算
def probability_distribution(n, p):
    return [np.math.comb(n, k) * (p ** k) * ((1 - p) ** (n - k)) for k in range(n + 1)]

# 随机变量期望和方差计算
def expectation_variance(p_x):
    n = len(p_x)
    mean = sum([i * p_x[i] for i in range(n)])
    variance = sum([((i - mean) ** 2) * p_x[i] for i in range(n)])
    return mean, variance

# 大数定律和中心极限定理
def large_number_law(p):
    n = 1000
    experiments = [np.random.binomial(n, p) for _ in range(1000)]
    mean = sum(experiments) / len(experiments)
    plt.hist(experiments, bins=50, alpha=0.5)
    plt.plot([mean - 1.96 * np.sqrt(p * (1 - p) / n), mean + 1.96 * np.sqrt(p * (1 - p) / n)], [0.03, 0.03], 'r--')
    plt.show()
    return mean

# 概率分布实例
p_x = probability_distribution(10, 0.5)
mean, variance = expectation_variance(p_x)
print("概率分布:", p_x)
print("期望:", mean)
print("方差:", variance)

# 大数定律和中心极限定理实例
large_number_law(0.5)
```

#### 数学模型和公式
$$
P(A) = \frac{n(A)}{n(S)}
$$
$$
P(A \cap B) = P(A) \cdot P(B|A)
$$
$$
\text{期望} E(X) = \sum_{i=1}^{n} x_i \cdot p_i
$$
$$
\text{方差} Var(X) = \sum_{i=1}^{n} (x_i - \mu)^2 \cdot p_i
$$
$$
\text{大数定律} \lim_{n \to \infty} \frac{1}{n} \sum_{i=1}^{n} X_i = \mu
$$
$$
\text{中心极限定理} \lim_{n \to \infty} \frac{\sum_{i=1}^{n} X_i - n\mu}{\sqrt{n}\sigma} = N(0,1)
$$
