### 3.4 Python 源代码

为了更好地理解数学模型和算法在城市网络中的应用，以下是一个简单的 Python 源代码示例，用于计算交通网络中的最短路径。

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建一个图
G = nx.Graph()

# 添加节点和边
G.add_nodes_from([1, 2, 3, 4, 5])
G.add_edges_from([(1, 2, {'weight': 1}),
                  (1, 3, {'weight': 2}),
                  (2, 3, {'weight': 1}),
                  (3, 4, {'weight': 3}),
                  (4, 5, {'weight': 2})])

# 计算最短路径
path = nx.shortest_path(G, source=1, target=5, weight='weight')

# 绘制图
nx.draw(G, with_labels=True)
plt.show()

# 输出最短路径
print("最短路径：", path)
```

### 3.5 数学模型和公式

在交通网络优化中，常用的数学模型和公式如下：

- **最短路径公式**：

  $$d(s, t) = \min_{x \in S} \{ w(x, t) : x \in s \}$$

  其中，$d(s, t)$ 表示从源点 $s$ 到目标点 $t$ 的最短路径长度，$w(x, t)$ 表示从节点 $x$ 到节点 $t$ 的权重。

- **优化目标**：

  $$\min \sum_{i=1}^{n} \sum_{j=1}^{m} c_{ij} x_{ij}$$

  其中，$c_{ij}$ 表示从节点 $i$ 到节点 $j$ 的路径成本，$x_{ij}$ 表示从节点 $i$ 到节点 $j$ 的路径流量。

### 4.3 源代码实现与解读

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建图
G = nx.Graph()

# 添加节点和边
G.add_nodes_from([1, 2, 3, 4, 5])
G.add_edges_from([(1, 2, {'weight': 1}),
                  (1, 3, {'weight': 2}),
                  (2, 3, {'weight': 1}),
                  (3, 4, {'weight': 3}),
                  (4, 5, {'weight': 2})])

# 计算最短路径
path = nx.shortest_path(G, source=1, target=5, weight='weight')

# 绘制图
nx.draw(G, with_labels=True)
plt.show()

# 输出最短路径
print("最短路径：", path)

# 优化路径
for i in range(len(path) - 1):
    u, v = path[i], path[i + 1]
    G[u][v]['weight'] = min(G[u][v]['weight'], 1)

# 重新计算最短路径
path = nx.shortest_path(G, source=1, target=5, weight='weight')

# 输出优化后的最短路径
print("优化后的最短路径：", path)
```

- **分析**：通过优化交通网络中的路径权重，可以减少交通拥堵，提高交通效率。该方法可以应用于智慧城市交通网络优化，为居民的出行提供更好的服务。
