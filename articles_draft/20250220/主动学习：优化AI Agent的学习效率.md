# 第1章: 主动学习的核心概念

## 1.1 什么是主动学习？

### 1.1.1 主动学习的定义

主动学习是一种机器学习方法，其中模型能够主动选择最有益于其学习的数据样本。与被动学习（如随机采样）不同，主动学习通过策略选择最具代表性的样本，从而提高学习效率和模型性能。

$$
\text{主动学习} = \text{数据选择策略} + \text{学习模型优化}
$$

### 1.1.2 主动学习的关键特征

- **样本选择性**：模型主动选择数据，而非被动接受。
- **迭代优化**：模型通过多次选择和学习逐步改进。
- **领域适应性**：适用于数据稀缺或标注成本高的场景。

### 1.1.3 与被动学习的区别

| 特性        | 被动学习                | 主动学习                |
|-------------|-------------------------|-------------------------|
| 数据选择    | 随机或固定选择          | 智能选择最有益样本      |
| 学习效率    | 通常较低                | 通常较高                |
| 数据成本    | 较高（需要大量标注）    | 较低（选择关键样本）    |

## 1.2 主动学习在AI Agent中的作用

### 1.2.1 提高学习效率

AI Agent通过主动选择关键数据，快速优化模型，减少训练时间。

### 1.2.2 优化学习效果

选择最具代表性的样本，提升模型在特定任务上的性能。

### 1.2.3 降低学习成本

减少标注数据量，降低成本，同时保持模型性能。

## 1.3 主动学习的核心要素

### 1.3.1 数据选择策略

- **不确定性采样**：选择模型最不确定的样本。
- **多样性采样**：选择覆盖数据分布的样本。
- **风险最小化采样**：选择减少预测错误的样本。

### 1.3.2 学习模型优化

- **模型更新**：根据选择的样本更新模型。
- **反馈机制**：利用标注数据优化选择策略。

### 1.3.3 性能评估指标

- **准确率**：模型在选择数据上的表现。
- **效率提升**：相比被动学习的效率提升比例。

# 第2章: 主动学习的算法原理

## 2.1 不确定性采样

### 2.1.1 算法流程

```mermaid

```

### 2.1.2 样本选择的不确定性度量

- 使用熵值衡量样本不确定性：
$$
\text{熵} = -\sum p_i \log p_i
$$

- 选择熵值最高的样本进行标注。

## 2.2 多样性采样

### 2.2.1 算法流程


### 2.2.2 数据分布的衡量方法

- 使用聚类算法（如K-means）选择每个簇的代表样本。

## 2.3 风险最小化采样

### 2.3.1 算法流程

```mermaid

B --> C[标注样本并加入训练集]
C --> D[训练模型]
D --> E[结束]
```

### 2.3.2 风险函数的定义

$$
\text{风险} = \sum p(x) L(f(x), y)

其中，\( L \) 是损失函数，\( p(x) \) 是数据分布。
