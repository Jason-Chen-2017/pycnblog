### 第4章：认知偏差的类型与特征

#### 4.1 认知偏差的主要类型
- 确认偏差：倾向于寻找支持已有假设的信息。
- 选择性注意偏差：关注特定信息而忽略其他信息。
- 过度自信偏差：高估自身判断的准确性。

#### 4.2 不同偏差类型的特征对比
| 偏差类型   | 特征描述                     |

| 确认偏差   | 寻找支持信息，忽略反面信息   |
| 选择性注意偏差 | 注意特定信息，忽略其他信息 |

#### 5.3 Python代码示例
```python
import numpy as np
from sklearn.metrics import accuracy_score

def detect_bias(data):
    # 简单的偏差检测算法
    mean = np.mean(data)
    threshold = 0.1
    if np.abs(mean) > threshold:
        return "存在偏差"
    else:
        return "无偏差"

data = np.random.normal(0.5, 0.1, 100)
result = detect_bias(data)
print(result)
```
