# 第3章: 微观结构变化预测的算法原理

## 3.1 时间序列分析算法

### 3.1.1 ARIMA模型

ARIMA模型通过自回归和移动平均部分预测未来价格。公式如下：

$$ARIMA(p, d, q) = y_t = \phi_1 y_{t-1} + \dots + \phi_p y_{t-p} + \theta_1 \epsilon_{t-1} + \dots + \theta_q \epsilon_{t-q} + \epsilon_t$$

### 3.1.2 LSTM网络

LSTM通过长短期记忆单元处理时间序列数据。其结构包括输入门、遗忘门和输出门。

### 3.1.3 GARCH模型

GARCH模型预测 volatility，公式为：

$$\sigma_t^2 = \alpha_0 + \alpha_1 r_{t-1}^2 + \beta_1 \sigma_{t-1}^2$$
