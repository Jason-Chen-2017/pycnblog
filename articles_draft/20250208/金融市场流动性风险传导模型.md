## 5.3 系统实现代码

以下是一个简化的Python代码示例，展示了流动性风险传导模型的核心计算部分：

```python
import numpy as np
import pandas as pd

def calculate_liq_risk(data, window_size=10):
    # 计算流动性风险指标（示例：波动率）
    data['volatility'] = data['price'].rolling(window_size).std()
    # 计算风险传导系数
    risk_transmission = np.zeros(len(data))
    for i in range(window_size, len(data)):
        risk_transmission[i] = np.dot(data['volatility'].iloc[i-window_size:i], 
                                      data['market_returns'].iloc[i-window_size:i]) / window_size
    return risk_transmission
```
