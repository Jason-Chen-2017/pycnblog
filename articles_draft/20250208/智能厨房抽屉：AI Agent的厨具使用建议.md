## 第5章: 项目实战

### 5.1 环境安装与配置
- 工具：Python、Scikit-learn、Mermaid。
- 环境搭建：安装依赖库并配置开发环境。

### 5.2 核心代码实现
- 示例代码：
  ```python
  import numpy as np
  from sklearn.metrics.pairwise import cosine_similarity

  def recommend_utensil(user_input, utensil_list):
      vectorizer = TfidfVectorizer()
      input_vec = vectorizer.fit_transform([user_input]).toarray()
      utensil_vec = vectorizer.fit_transform(utensil_list).toarray()
      similarity = cosine_similarity(input_vec, utensil_vec)
      return utensil_list[np.argmax(similarity)]
  ```
