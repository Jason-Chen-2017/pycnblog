### 第3章: 传统投资组合归因算法

#### 3.1 风险调整收益模型
- CAPM模型
  - **定义**: 用于计算资产的预期收益，公式为：
    $$ E(R_i) = R_f + \beta_i (R_m - R_f) $$
  - **流程图**：
  ```mermaid
  graph TD
      A[开始] --> B[计算无风险利率]
      B --> C[计算市场预期收益]
      C --> D[计算β系数]
      D --> E[计算资产预期收益]
      E --> F[结束]
  ```

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

def portfolio_attribution(returns, factors):
    model = LinearRegression()
    model.fit(factors, returns)
    return model.coef_

# 示例数据
returns = pd.Series([0.05, 0.03, 0.02, -0.01])
factors = pd.DataFrame({
    'market': [0.08, 0.07, 0.06, 0.05],
    'value': [0.10, 0.08, 0.06, 0.04]
})

result = portfolio_attribution(returns, factors)
print("归因结果:", result)
```
