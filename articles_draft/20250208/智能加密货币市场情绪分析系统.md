#### 3.5 核心代码实现

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score

# 示例数据
tweets = ["I love Bitcoin!", "This is a scam.", "The market is bullish today."]

# 文本预处理
vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(tweets)

# 模型训练
model = SVC()
model.fit(X, [1, 0, 1])

# 预测与评估
new_tweet = ["I'm bearish on Ethereum."]
X_new = vectorizer.transform([new_tweet[0]])
print("预测结果：", model.predict(X_new))
print("准确率：", accuracy_score([0], model.predict(X_new)))
```

#### 3.6 数学公式

- 情感分类的损失函数：
  $$ L = -\frac{1}{n}\sum_{i=1}^{n} [y_i \cdot \log(p_i) + (1-y_i) \cdot \log(1-p_i)] $$
  
  其中，$y_i$ 是真实标签，$p_i$ 是模型预测的概率。
