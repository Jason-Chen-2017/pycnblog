# 第二部分: 算法原理与数学模型

## 第3章: 算法原理讲解

### 3.1 线性回归模型
线性回归是一种简单而强大的回归算法，适用于连续型变量的预测。其核心思想是通过最小化预测值与真实值之间的平方差，找到最佳拟合直线。

#### 线性回归公式
$$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + ... + \beta_nx_n + \epsilon $$

### 3.2 随机森林模型
随机森林是一种基于决策树的集成学习算法，具有高准确性和良好的鲁棒性。它通过随机选择特征和样本进行训练，最终通过投票的方式得出预测结果。

#### 随机森林公式
$$ y = \sum_{i=1}^{n} \text{Tree}(x_i) $$

### 3.3 算法选择与优化
- **特征选择**：使用特征重要性分析选择关键特征。
- **模型调优**：通过交叉验证优化模型参数。

### 5.2 核心代码实现

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 数据加载
data = pd.read_csv('customer_satisfaction.csv')

# 数据清洗
data = data.dropna()

# 特征选择
X = data[['age', 'income', 'product_rating']]
y = data['satisfaction']

# 数据分割
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 模型训练
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X_train, y_train)

# 模型预测
y_pred = model.predict(X_test)

# 模型评估
print("Accuracy:", accuracy_score(y_test, y_pred))
```
