## 第三章：智能免疫策略的算法原理

### 3.1 算法原理概述
3.1.1 凸优化问题的数学模型
$$ \text{目标函数：} \quad \min_{w} \frac{1}{2}w^T \Sigma w $$
$$ \text{约束条件：} \quad w^T \mu = T \quad \text{和} \quad 1^T w = 1 $$

3.1.2 拉格朗日乘数法的应用
$$ \mathcal{L} = \frac{1}{2}w^T \Sigma w - \lambda (w^T \mu - T) - \gamma (1^T w - 1) $$$

### 3.2 算法实现
3.2.1 Python实现
```python
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def objective(w):
    return 0.5 * np.dot(w.T, np.dot(sigma, w))

# 定义约束条件
def constraint1(w):
    return np.dot(mu, w) - T

def constraint2(w):
    return np.dot(np.ones(len(w)), w) - 1

# 初始化权重
w0 = np.array([1.0, 0.0, 0.0])

# 使用拉格朗日乘数法求解
result = minimize(objective, w0, method='SLSQP', constraints=[
    {'type': 'eq', 'fun': constraint1},
    {'type': 'eq', 'fun': constraint2}
])
```

```python
import numpy as np
from scipy.optimize import minimize

# 数据准备
mu = np.array([0.05, 0.06, 0.07])
sigma = np.array([[0.02, 0.01, 0.01],
                  [0.01, 0.03, 0.02],
                  [0.01, 0.02, 0.04]])
T = 0.06

# 定义目标函数
def objective(w):
    return 0.5 * np.dot(w.T, np.dot(sigma, w))

# 定义约束条件
def constraint1(w):
    return np.dot(mu, w) - T

def constraint2(w):
    return np.dot(np.ones(len(w)), w) - 1

# 初始化权重
w0 = np.array([1.0, 0.0, 0.0])

# 使用拉格朗日乘数法求解
result = minimize(objective, w0, method='SLSQP', constraints=[
    {'type': 'eq', 'fun': constraint1},
    {'type': 'eq', 'fun': constraint2}
])

print(result.x)
```
