# 第1章：联邦学习与金融应用概述

## 1.1 联邦学习的定义与背景

### 1.1.1 问题背景与挑战

数据隐私和合规性要求使得跨机构数据共享困难，限制了模型的优化。

联邦学习通过加密和分布式的训练方式，确保数据隐私。

## 3.3 联邦学习的数学模型

### 3.3.1 联邦平均算法的数学推导
局部模型更新：
$$ \theta_i^{new} = \theta_i^{old} - \eta \nabla L_i(\theta_i^{old}) $$
全局模型聚合：
$$ \theta_{global} = \frac{1}{n}\sum_{i=1}^{n}\theta_i^{new} $$

$$ \theta_{global} = \frac{1}{n}\sum_{i=1}^{n}\theta_i^{new} $$

## 7.2 核心代码实现

### 7.2.1 联邦平均算法实现
```python
import numpy as np
from fedlearning import FedAvg

class CreditScoreModel:
    def __init__(self, input_dim):
        self.theta = np.zeros(input_dim)

    def forward(self, X):
        return np.dot(X, self.theta)

    def backward(self, X, y):
        return 2 * np.dot(X.T, (y - np.dot(X, self.theta)))

def main():
    # 初始化模型
    model = CreditScoreModel(input_dim=10)
    # 初始化FedAvg
    fed_avg = FedAvg(parties=5, model=model)
    # 开始训练
    fed_avg.train(epochs=10)
    # 输出结果
    print(fed_avg.get_global_model())

if __name__ == "__main__":
    main()
```
