- **3.2 算法实现代码**
  ```python
  import numpy as np
  from sklearn.linear_model import LinearRegression

  # 示例数据
  X = np.array([[2], [3], [4], [5]])  # 自变量
  y = np.array([2, 3, 5, 6])          # 因变量

  # 训练模型
  model = LinearRegression()
  model.fit(X, y)

  # 预测
  new_X = np.array([[6]])
  predicted_y = model.predict(new_X)
  print("预测值:", predicted_y)
  ```

- **3.3 数学公式讲解**
  - 线性回归公式：$$ y = \beta_0 + \beta_1 x + \epsilon $$
  - 最小二乘法：$$ \hat{\beta} = (X^T X)^{-1} X^T y $$
