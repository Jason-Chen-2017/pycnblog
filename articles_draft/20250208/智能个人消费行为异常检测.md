#### 4.1 基于聚类的异常检测
- **K-means算法**：将数据分成K个簇，判断离簇中心较远的点为异常。
- **代码示例**：
```python
from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=3)
kmeans.fit(X)
# 判断异常点
distances = kmeans.transform(X)
threshold = distances.max() * 0.5
outliers = distances[:, 0] > threshold
```
