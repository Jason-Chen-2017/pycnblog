# 第1章: 研究背景与意义

## 1.1 研究背景

### 1.1.1 全球股市估值的现状与挑战

全球股市估值是衡量经济发展的重要指标，但近年来，传统能源价格波动、全球经济不确定性以及新冠疫情的影响，使得股市估值面临诸多挑战。投资者需要寻找新的增长点，而技术创新，尤其是绿色技术，成为推动股市增长的新动力。

### 1.1.2 可持续航空生物燃料技术的发展趋势

可持续航空生物燃料（SAF）是减少碳排放的重要技术，其研发和应用受到政策和市场的双重推动。随着环保意识的增强，航空公司和投资者越来越关注 SAF 的潜力。

### 1.1.3 两者关系研究的必要性

研究 SAF 技术对股市估值的影响，可以帮助投资者识别新的投资机会，同时推动技术创新和可持续发展。
