## 1. 特价股票与连续两年表现不佳股票的定义与分类

### 1.1 特价股票的定义与特征

- **定义**：特价股票是指价格相对较低，通常被市场低估的股票，具有较大的增长潜力。
- **特征**：
  - 价格低于行业平均水平
  - 市盈率、市净率等估值指标低于市场平均水平
  - 公司基本面较好，但市场情绪较低

### 1.2 连续两年表现不佳股票的定义与特征

- **定义**：连续两年股票价格表现不佳，年收益率低于市场平均水平的股票。
- **特征**：
  - 连续两年股价下跌或涨幅远低于市场平均水平
  - 市场情绪低迷，投资者信心不足
  - 公司基本面可能存在一定的问题

### 1.3 特价股票与连续两年表现不佳股票的关联性分析

- **关联性**：
  - 特价股票可能因市场情绪低迷而表现不佳
  - 连续两年表现不佳的股票可能被市场低估，成为特价股票
  - 两者的结合可能导致股票价格进一步下跌

### 5.2 数据清洗与特征工程

```python
import pandas as pd
import numpy as np

# 数据清洗
data = pd.read_csv('stock_data.csv')
data.dropna(inplace=True)
data['price'] = data['price'].astype(float)
```

### 5.3 数据建模与预测

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 特征工程
features = data[['price', 'pe_ratio', 'pb_ratio']]
target = data['target']  # 1表示表现不佳，0表示表现良好

# 建模
model = RandomForestClassifier()
model.fit(features, target)

# 预测
predictions = model.predict(features)
print("Accuracy:", accuracy_score(target, predictions))
```
