## 第二部分：全球股市估值的核心模型与技术应用

### 第3章：股市估值的核心模型

#### 3.1 传统估值模型
- **市盈率模型（P/E）**：
  - 公式：$$ P = E \times \text{市盈率} $$
  - 优点：简单易用，适用于盈利稳定的公司。
  - 缺点：不适用于亏损企业。

- **现金流折现模型（DCF）**：
  - 公式：$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n} $$
  - 优点：考虑了未来现金流的现值。
  - 缺点：需要准确预测未来现金流。

#### 3.2 机器学习在股市估值中的应用
- **算法选择**：
  - 线性回归：用于预测股票价格。
  - 随机森林：用于分类和回归任务。

- **代码实现**：
  ```python
  from sklearn.ensemble import RandomForestRegressor
  import pandas as pd

  # 加载数据
  data = pd.read_csv('stock_data.csv')

  # 分割特征和目标
  X = data[['PE', 'PB', 'ROE']]
  y = data['Price']

  # 训练模型
  model = RandomForestRegressor(n_estimators=100)
  model.fit(X, y)

  # 预测
  predicted_price = model.predict(X)
  ```

  - **结果分析**：模型预测与实际价格的对比，评估模型准确性。
