# 第一部分: 格雷厄姆特价股票理论基础

## 第1章: 格雷厄姆特价股票理论概述

### 1.1 格雷厄姆投资理论的起源与发展

#### 1.1.1 本杰明·格雷厄姆及其投资理念
- 格雷厄姆是价值投资之父，其投资理念以基本面分析为核心。
- 他强调以低于内在价值的价格买入优质股票，追求长期稳定收益。
- 格雷厄姆的投资理念在20世纪初提出，至今仍对全球投资界产生深远影响。

#### 1.1.2 格雷厄姆特价股票理论的核心思想
- 特价股票的定义：市场价格低于内在价值的股票。
- 安全边际：买入价格与内在价值之间的差额，是投资的安全垫。
- 逆向投资：在市场恐慌时买入，在市场狂热时卖出。

#### 1.1.3 格雷厄姆理论在不同经济周期中的表现
- 在经济繁荣期，格雷厄姆策略可能表现平平，但在经济衰退期往往表现优异。
- 在新兴市场和成熟市场中的表现差异显著。

### 1.2 格雷厄姆特价股票的核心概念

#### 1.2.1 特价股票的定义与特征
| 特价股票特征 | 描述 |
|--------------|------|
| 市盈率低     | P/E < 市场平均值 |
| 市净率低     | P/B < 市场平均值 |
| 股价低于清算价值 | P < 清算价值 |

#### 1.2.2 格雷厄姆的安全边际理论
- 安全边际 = 内在价值 - 市场价格
- 内在价值公式：
$$ V = \frac{E}{4.41} $$
其中，$E$ 是企业未来7年预期收益的总和。

#### 1.2.3 格雷厄姆的价值投资策略
- 以安全边际为核心，选择低估的股票。
- 长期持有，避免频繁交易。

## 第2章: 格雷厄姆特价股票理论的数学模型与公式

### 2.1 格雷厄姆投资模型的数学表达

#### 2.1.1 内在价值公式
$$ V = \frac{E}{4.41} $$
其中，$E$ 是未来7年预期收益的总和。

#### 2.1.2 安全边际计算公式
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

#### 2.1.3 多因子模型
- 格雷厄姆多因子模型将多个基本面指标（如市盈率、市净率、股息率）结合在一起，以筛选出具有安全边际的股票。
- 模型权重分配：
  - 市盈率：30%
  - 市净率：30%
  - 股息率：20%
  - 营业利润率：20%

### 2.2 格雷厄姆多因子模型的优缺点分析

| 优点 | 缺点 |
|------|------|
| 能够综合考虑多个基本面指标 | 权重分配主观性较强 |
| 稳定性高 | 无法适应市场短期波动 |
| 适合长期投资 | 对短期市场变化反应较慢 |

### 4.2 核心实现代码

#### 4.2.1 数据收集模块
```python
import pandas as pd
import yfinance as yf

def get_stock_data(tickers):
    data = {}
    for ticker in tickers:
        df = yf.download(ticker, start='2020-01-01', end='2023-12-31')
        data[ticker] = df
    return data

tickers = ['AAPL', 'MSFT', 'GOOGL']
stock_data = get_stock_data(tickers)
```

#### 4.2.2 数据处理模块
```python
def calculate_intrinsic_value(data):
    intrinsic_value = {}
    for ticker, df in data.items():
        E = df['Adj Close'].rolling(7).mean() * 7
        V = E / 4.41
        intrinsic_value[ticker] = V
    return intrinsic_value

intrinsic_values = calculate_intrinsic_value(stock_data)
```

#### 4.2.3 策略筛选模块
```python
def screen_stocks(data, intrinsic_values):
    screened_stocks = []
    for ticker, df in data.items():
        price = df['Adj Close'].iloc[-1]
        V = intrinsic_values[ticker].iloc[-1]
        margin = V - price
        if margin > 0:
            screened_stocks.append(ticker)
    return screened_stocks

result = screen_stocks(stock_data, intrinsic_values)
print(result)
```
