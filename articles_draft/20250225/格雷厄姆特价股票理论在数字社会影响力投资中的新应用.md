## 第二部分: 理论基础与系统分析

### 第2章: 格雷厄姆特价股票理论的数学模型与公式

#### 2.1 格雷厄姆安全边际公式
$$
\text{安全边际} = \text{市场价格} - \text{内在价值}
$$

#### 2.2 内在价值计算公式
$$
\text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}
$$
其中，$CF_t$ 是第$t$年的现金流，$r$ 是贴现率。

#### 2.3 投资组合优化的数学模型
$$
\max \mu \cdot w - \lambda \cdot \sigma^2 \cdot w^T
$$
其中，$\mu$ 是收益向量，$\sigma^2$ 是协方差矩阵，$\lambda$ 是风险厌恶系数。

### 第3章: 影响力投资的量化评估模型

#### 3.1 ESG评分体系
- ESG评分公式：
$$
\text{ESG评分} = \frac{\text{E评分} + \text{S评分} + \text{G评分}}{3}
$$

#### 3.2 社会影响力指数
$$
\text{社会影响力指数} = \sum_{i=1}^{n} w_i \cdot S_i
$$
其中，$w_i$ 是第$i$个因子的权重，$S_i$ 是第$i$个因子的评分。

#### 3.3 数字社会投资回报模型
$$
\text{投资回报} = \alpha \cdot \text{内在价值} + \beta \cdot \text{社会影响力}
$$

#### 4.2 系统核心实现源代码
```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate):
    return np.npv(discount_rate, cash_flows)

def calculate_margin_of_safety(price, intrinsic_value):
    return price - intrinsic_value

def calculate_esg_score(e_score, s_score, g_score):
    return (e_score + s_score + g_score) / 3

# 示例数据
cash_flows = [100, 150, 200, 250]
discount_rate = 0.08
price = 100
e_score = 80
s_score = 85
g_score = 75

# 计算内在价值
intrinsic_value = calculate_intrinsic_value(cash_flows, discount_rate)
print(f"内在价值: {intrinsic_value}")

# 计算安全边际
margin_of_safety = calculate_margin_of_safety(price, intrinsic_value)
print(f"安全边际: {margin_of_safety}")

# 计算ESG评分
esg_score = calculate_esg_score(e_score, s_score, g_score)
print(f"ESG评分: {esg_score}")
```
