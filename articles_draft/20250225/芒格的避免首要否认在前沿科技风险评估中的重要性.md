# 第1章: 芒格的“避免首要否认”原则概述

## 1.1 “避免首要否认”的定义与核心理念  
“避免首要否认”（Avoid the First Mistake）是芒格提出的一项核心投资原则，旨在提醒投资者在决策过程中避免因情绪或认知偏差而陷入错误判断。这一原则强调理性思考和客观分析，尤其是在面对不确定性和复杂性时，要避免过早下结论或忽视潜在风险。

## 1.2 科技风险评估的背景与挑战  
前沿科技的发展往往伴随着高度的不确定性和复杂性。从人工智能到量子计算，这些技术的潜在风险不仅涉及技术本身，还包括市场需求、法律合规、伦理问题等多个方面。科技从业者在评估风险时，常常受到认知偏差的影响，导致决策失误。

## 1.3 芒格原则与科技风险评估的结合  
芒格原则为科技风险评估提供了一种新的视角。通过避免首要否认，科技从业者可以在评估过程中保持理性和客观，从而更准确地识别和规避潜在风险。

import pandas as pd
import numpy as np

def calculate_risk_factors(data):
    # 计算风险因素得分
    factors = ['技术可行性', '市场需求', '法律合规性']
    scores = []
    for factor in factors:
        score = np.mean(data[factor])
        scores.append(score)
    return scores

# 示例数据
data = pd.DataFrame({
    '技术可行性': [4, 3, 5],
    '市场需求': [5, 6, 4],
    '法律合规性': [3, 4, 5]
})

# 计算风险因素得分
scores = calculate_risk_factors(data)
print(scores)  # 输出：[4.0, 5.0, 4.0]
