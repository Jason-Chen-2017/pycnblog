### 第1章: 什么是反向思考

#### 1.1 反向思考的定义
反向思考是一种思维方式，强调从对立面或反方向出发，寻找解决问题的方法。芒格将其应用于投资和市场分析中，主张逆向思考市场行为，避开从众陷阱，寻找被市场忽视的机会。

在市场分析中，反向思考可以帮助投资者避免盲目跟随市场趋势，识别潜在风险，捕捉低估的机会。通过反向思考，投资者能够更好地理解市场波动背后的逻辑。

#### 1.3 反向思考在市场分析中的应用

### 第2章: 芝加哥学派与反向思考

#### 2.1 芝加哥学派的起源
芝加哥学派以行为心理学为基础，研究市场参与者的行为模式，强调情绪和认知偏差对市场的影响。

#### 2.2 芝加哥学派的核心思想
该学派认为市场行为并非完全理性，而是受情绪驱动。反向思考通过识别这些情绪偏差，帮助投资者做出更明智的决策。

#### 2.3 反向思考与芝加哥学派的关系

#### 13.2 核心实现代码

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 示例数据
data = np.random.randn(100, 5)
df = pd.DataFrame(data, columns=['A', 'B', 'C', 'D', 'E'])

# 反向思考策略：寻找偏离均值的值
mean = df.mean()
std = df.std()
outliers = df[(df < mean - 2*std) | (df > mean + 2*std)]

print("均值：", mean)
print("标准差：", std)
print("异常值：", outliers)
```
