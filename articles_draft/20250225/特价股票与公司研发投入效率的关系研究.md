#### 6.2 系统核心实现源代码

##### 6.2.1 数据预处理代码
```python
import pandas as pd
import numpy as np

# 读取股票数据
stock_data = pd.read_csv('stock.csv')

# 读取研发投入数据
research_data = pd.read_csv('research.csv')

# 合并数据
merged_data = pd.merge(stock_data, research_data, on='公司代码')

# 数据清洗
merged_data.dropna(inplace=True)
```

##### 6.2.2 关系模型训练代码
```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据准备
X = merged_data[['研发投入', '研发效率']]
y = merged_data['股票价格']

# 训练模型
model = LinearRegression()
model.fit(X, y)

# 评估模型
y_pred = model.predict(X)
print(r2_score(y, y_pred))
```

##### 6.2.3 可视化代码
```python
import matplotlib.pyplot as plt

# 可视化研发投入与股票价格的关系
plt.scatter(X['研发投入'], y)
plt.plot(X['研发投入'], y_pred, color='red')
plt.xlabel('研发投入')
plt.ylabel('股票价格')
plt.show()
```

#### 6.3 代码应用解读与分析

##### 6.3.1 代码功能解读
- 数据预处理：读取和合并股票和研发投入数据，清洗缺失值。
- 模型训练：使用线性回归模型训练关系模型。
- 模型评估：计算R²分数，评估模型拟合程度。
- 可视化：绘制散点图和回归线，直观展示关系。
