### 第5章：项目实战

#### 5.1 实际案例分析

我需要选择一个具体的公司，分析其DRIP的效果，并提供代码实现。

**示例代码：**

```python
import pandas as pd
import numpy as np

def calculate_dividend_reinvestment(initial_investment, dividend_yield, years):
    """
    计算股息再投资的回报
    :param initial_investment: 初始投资金额
    :param dividend_yield: 股息率
    :param years: 投资年数
    :return: 最终价值
    """
    investment = initial_investment
    for _ in range(years):
        # 计算股息收入
        dividends = investment * dividend_yield
        # 再投资购买更多股票
        investment += dividends
    return investment

# 示例计算
initial_investment = 1000  # 初始投资1000元
dividend_yield = 0.05      # 股息率5%
years = 10                 # 投资10年

final_value = calculate_dividend_reinvestment(initial_investment, dividend_yield, years)
print(f"最终价值：{final_value:.2f}元")
```
