##### 5.2 项目核心实现源代码

- 资本配置效率分析的Python实现
  ```python
  def calculate_roe(net_profit, total_equity):
      return net_profit / total_equity
  
  def calculate_roa(net_profit, total_assets):
      return net_profit / total_assets
  
  def calculate_npv(cash_flows, discount_rate):
      return sum(cash_flow / (1 + discount_rate)**t for t, cash_flow in enumerate(cash_flows))
  
  # 示例数据
  net_profit = 1000000
  total_equity = 5000000
  total_assets = 10000000
  discount_rate = 0.1
  cash_flows = [100000, 150000, 200000, 250000, 300000]
  
  roe = calculate_roe(net_profit, total_equity)
  roa = calculate_roa(net_profit, total_assets)
  npv = calculate_npv(cash_flows, discount_rate)
  
  print(f"ROE: {roe:.2f}%")
  print(f"ROA: {roa:.2f}%")
  print(f"NPV: {npv:.2f}")
  ```
