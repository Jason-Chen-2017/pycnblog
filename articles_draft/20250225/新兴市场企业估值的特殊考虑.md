#### 3.3.1 数据预处理
```python
import pandas as pd

# 假设df是收集的数据
df = pd.DataFrame({
    '收入': [100, 200, 150],
    '成本': [50, 100, 70],
    '利润': [30, 80, 60]
})

# 处理缺失值
df = df.dropna()

# 处理异常值
Q1 = df['收入'].quantile(0.25)
Q3 = df['收入'].quantile(0.75)
IQR = Q3 - Q1
df['收入'] = df['收入'].where((df['收入'] >= Q1 - 1.5*IQR) & (df['收入'] <= Q3 + 1.5*IQR))
```

#### 3.3.2 选择模型
```python
def choose_model(market_type):
    if market_type == '新兴':
        return 'DCF'
    else:
        return '相对估值法'
```

#### 3.3.3 调整参数
```python
def adjust_parameters(financial_data, market_risk):
    WACC = financial_data['WACC'] + market_risk*0.1
    return WACC
```

#### 3.3.4 计算终值
```python
def calculate_tv(FCF, WACC, g):
    return FCF * (1 + g) / (WACC - g)
```

#### 3.3.5 结果验证
```python
def validate_result(estimated_value, actual_value):
    return abs(estimated_value - actual_value)/actual_value < 0.2
```
