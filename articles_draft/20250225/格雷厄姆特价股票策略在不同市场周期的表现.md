### 1.1 价值投资的基本概念

#### 1.1.1 投资的定义与分类

- **投资**是指将资金投入到某个项目或资产中，以期在未来获得超过初始投入的回报。
- **投资分类**：主要包括股票、债券、房地产、商品等。

#### 1.1.2 价值投资的核心理念

- **核心理念**：寻找市场低估的资产，长期持有，等待其价值回归。
- **主要特征**：注重基本面分析，关注内在价值而非市场情绪。

#### 1.1.3 格雷厄姆的学术贡献与投资思想

- **学术贡献**：本杰明·格雷厄姆是价值投资的鼻祖，著有《证券分析》和《 Intelligent Investor》。
- **投资思想**：强调安全边际，注重低市盈率、低市净率等估值指标。

### 1.2 格雷厄姆特价股票策略的定义

#### 1.2.1 特价股票的定义与特征

- **定义**：指市场价格低于其内在价值的股票。
- **特征**：通常表现为低市盈率、低市净率、高股息率等。

#### 1.2.2 格雷厄姆策略的核心要素

- **安全边际**：购买价格低于内在价值，确保收益的确定性。
- **基本面分析**：通过财务报表分析企业的盈利能力、成长性和稳定性。

#### 1.2.3 策略的适用场景与边界

- **适用场景**：市场低迷、个股被低估的时期。
- **边界**：避免投资于亏损企业、行业衰退企业等。

## 第2章：市场周期的基本概念

### 2.1 市场周期的定义与分类

#### 2.1.1 牛市、熊市、震荡市的定义

- **牛市**：市场持续上涨，投资者情绪乐观。
- **熊市**：市场持续下跌，投资者情绪悲观。
- **震荡市**：市场波动剧烈，缺乏明确趋势。

#### 2.1.2 市场周期的特征与规律

- **特征**：每个周期都有特定的市场表现和投资者行为。
- **规律**：周期性波动，但长期趋势向上。

#### 2.1.3 市场周期对投资策略的影响

- **影响**：不同周期下，策略的有效性和风险不同。

### 2.2 格雷厄姆策略与市场周期的关系

#### 2.2.1 不同市场周期下策略的有效性

- **牛市**：策略表现不佳，因为高价股票可能不再被低估。
- **熊市**：策略表现优异，因为市场下跌往往导致股票价格低于内在价值。
- **震荡市**：策略表现取决于市场波动幅度和策略调整能力。

## 第3章：格雷厄姆策略的核心原理

### 3.1 格雷厄姆策略的数学模型

#### 3.1.1 简单的估值模型（如市盈率、市净率）

- **市盈率（P/E）**：市价/每股收益。
- **市净率（P/B）**：市价/每股净资产。

#### 3.1.2 格雷厄姆的内在价值计算公式

$$ V = \frac{E}{1 + g} $$
其中，V为内在价值，E为未来收益，g为增长率。

#### 3.1.3 安全边际的计算

- **安全边际**：市场价格应低于内在价值的一定比例，通常为20%-30%。

### 3.2 格雷厄姆策略与市场周期的关系

| 震荡市   | 中          | 中   | 中   |

#### 3.2.2 市场周期对策略收益的影响

- **牛市**：高价导致策略失效。
- **熊市**：低价带来超额收益。

import pandas as pd
import numpy as np

def calculate_intrinsic_value(earnings, growth_rate):
    return earnings / (1 + growth_rate)

def greyhammer_strategy(stocks, market_cycle):
    intrinsic_values = {}
    for stock in stocks:
        iv = calculate_intrinsic_value(stock['earnings'], stock['growth_rate'])
        price = stock['price']
        margin = iv * 0.2  # 安全边际20%
        if market_cycle == 'bear':
            threshold = price < iv
        elif market_cycle == 'bull':
            threshold = price < iv * 0.8
        else:
            threshold = price < iv * 0.9
        intrinsic_values[stock['symbol']] = {'intrinsic_value': iv, 'threshold': threshold}
    return intrinsic_values

import pandas as pd
import numpy as np
import yfinance as yf

def get_stock_data(tickers):
    data = yf.download(tickers, start='2020-01-01', end='2023-12-31')
    return data

def apply_greyhammer_strategy(data):
    # 计算市盈率和市净率
    pe = data['Adj Close'] / data[' earnings']
    pb = data['Adj Close'] / data[' book_value']
    # 筛选低价股票
    selected = data[pe < 15 & pb < 2]
    return selected

# 示例
tickers = ['AAPL', 'MSFT', 'GOOGL']
data = get_stock_data(tickers)
result = apply_greyhammer_strategy(data)
print(result)
