## 第1章: 均等权重投资的背景与概念

### 1.1 均等权重投资的起源

#### 1.1.1 投资学的基本概念

投资学是研究资金分配、资产管理和财富增长的科学。在投资学中，资金分配是核心问题之一，它决定了投资组合的风险和收益。均等权重投资是一种简单而有效的资金分配方法，其核心思想是将资金平均分配到不同的资产或投资标的中。

#### 1.1.2 均等权重投资的定义

均等权重投资（Equal Weighting Investment）是一种投资策略，其特点是将资金按相等的比例分配到多个资产或投资类别中。这种方法避免了集中投资的风险，同时确保了投资组合的分散性。

#### 1.1.3 彼得·林奇与均等权重投资的联系

彼得·林奇是美国著名的基金经理和投资作家，他以管理富达麦哲伦基金而闻名。虽然他并未专门提出均等权重投资这一术语，但他的投资理念与均等权重投资的核心思想不谋而合，即通过分散投资降低风险。

#### 2.1.2 均等权重分配的数学模型

均等权重分配的数学模型如下：

$$
w_i = \frac{1}{n}
$$

其中，$w_i$ 是第 $i$ 个资产的权重，$n$ 是资产总数。

#### 2.1.3 资金分配的边界与外延

```python
def equal_weighting_allocation(assets, total_investment):
    n = len(assets)
    weights = [1/n for _ in range(n)]
    allocation = {}
    for i in range(n):
        allocation[assets[i]] = total_investment * weights[i]
    return allocation
```

```python
    # 计算差异
    difference = {asset: target - current for asset, target in target_weights.items()}
    # 调整权重
    for asset, weight in difference.items():
        if weight > 0:
            current_weights[asset] += weight
        else:
            current_weights[asset] -= abs(weight)
    return current_weights
```
