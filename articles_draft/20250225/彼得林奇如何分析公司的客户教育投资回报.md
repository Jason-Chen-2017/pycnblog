### 第三部分：客户教育投资回报的算法原理

#### 第3章：分析算法的数学模型

- **3.1 投资回报率（ROI）计算**
  - 3.1.1 ROI公式：$$ ROI = \frac{净收益}{投资成本} \times 100\% $$
  - 3.1.2 示例计算：假设投资成本为100万元，净收益为250万元，ROI为150%

- **3.2 净现值（NPV）计算**
  - 3.2.1 NPV公式：$$ NPV = \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t} $$
  - 3.2.2 示例计算：假设现金流为-100万（第0年），+150万（第1年），折现率r=50%，NPV=50万

- **3.3 内部收益率（IRR）计算**
  - 3.3.1 IRR公式：$$ NPV = 0 $$
  - 3.3.2 示例计算：假设投资为100万，收益为150万，IRR为50%

  def calculate_roi(net_profit, investment_cost):
      return (net_profit / investment_cost) * 100

  def calculate_npv(cash_flows, discount_rate):
      return sum(cash_flow / (1 + discount_rate) ** t for t, cash_flow in enumerate(cash_flows))

  def calculate_irr(cash_flows):
      return np.irr(cash_flows)
