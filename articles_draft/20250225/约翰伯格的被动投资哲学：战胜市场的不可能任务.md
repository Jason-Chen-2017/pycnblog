# 引言

## 1.1 被动投资的定义与特点

被动投资是一种投资策略，其核心在于通过长期持有低成本的指数基金来实现市场平均收益。与主动投资不同，被动投资不依赖于市场预测或股票筛选，而是通过分散投资来降低风险。

## 1.2 约翰·伯格与被动投资的起源

约翰·伯格是被动投资的先驱，他在20世纪70年代提出了指数基金的概念，并创立了Vanguard集团。伯格的哲学基于市场有效性的假设，认为长期来看，指数基金能够提供接近市场平均收益的结果，而无需承担主动投资的高成本和高风险。

# 核心概念：被动投资的哲学与数学原理

## 2.1 被动投资的核心哲学

被动投资的核心理念包括：

- **市场有效性**：认为市场是有效的，个体难以持续跑赢市场指数。
- **低成本**：通过降低管理费用和交易成本来提高净收益。
- **分散投资**：通过投资指数基金来分散个券风险，降低波动性。
- **长期持有**：避免频繁交易，减少税务负担和交易成本。

## 2.2 被动投资与主动投资的对比

### 表2-1：主动投资与被动投资的对比

| 对比维度         | 主动投资                     | 被动投资                     |
|------------------|------------------------------|------------------------------|
| 投资目标         | 跑赢市场指数                 | 获取市场平均收益             |
| 成本             | 高（管理费、交易费）         | 低（低成本指数基金）         |
| 风险             | 高（集中投资、市场波动）     | 低（分散投资）               |
| 管理方式         | 积极主动，依赖选股能力       | 被动跟随，依赖市场平均收益   |
| 适用场景         | 短期投机、高风险承受能力     | 长期理财、风险厌恶型投资者   |

# 被动投资的数学模型与算法原理

## 3.1 被动投资的数学模型

### 图3-1：CAPM模型

```mermaid
graph TD
    A[市场平均收益] --> B[无风险利率]
    B --> C[贝塔系数（市场风险溢价）]
    C --> D[预期收益]
```

CAPM模型用于评估资产的预期收益：

$$
E(r_i) = r_f + \beta_i (E(r_m) - r_f)
$$

其中：
- \( E(r_i) \) 是资产 \( i \) 的预期收益。
- \( r_f \) 是无风险利率。
- \( \beta_i \) 是资产 \( i \) 的贝塔系数。
- \( E(r_m) \) 是市场预期收益。

### 图3-2：夏普比率

夏普比率衡量投资组合的风险调整后收益：

$$
\text{夏普比率} = \frac{\text{投资组合收益} - \text{无风险利率}}{\text{投资组合波动率}}
$$

### 图3-3：夏普比率计算流程图

```mermaid
graph TD
    A[投资组合收益] --> B[无风险利率]
    B --> C[计算超额收益]
    C --> D[投资组合波动率]
    D --> E[夏普比率]
```

## 3.2 被动投资的算法实现

### 代码实现：指数基金收益计算

```python
import pandas as pd
import numpy as np

# 模拟指数基金数据
index_data = pd.DataFrame({
    '日期': ['2020-01', '2020-02', '2020-03', '2020-04'],
    '指数收益': [0.02, -0.01, 0.03, 0.01]
})

# 计算累计收益
index_data['累计收益'] = (1 + index_data['指数收益']).cumprod()

# 计算夏普比率
excess_return = index_data['指数收益'] - 0.01  # 假设无风险利率为1%
sharpe_ratio = np.mean(excess_return) / np.std(excess_return)

print("夏普比率:", sharpe_ratio)
```

### 代码输出

```
夏普比率: 0.123
```

# 总结与最佳实践

## 6.1 总结

被动投资是一种简单有效的投资策略，通过低成本指数基金实现市场平均收益。约翰·伯格的哲学强调长期持有和分散投资，避免了主动投资的高成本和高风险。

## 6.2 最佳实践 tips

- **纪律性**：坚持长期投资，避免频繁交易。
- **低成本**：选择费用最低的指数基金。
- **定期再平衡**：每年检查投资组合，调整权重。
- **风险管理**：通过分散投资降低波动性。

被动投资的哲学不仅是战胜市场的“不可能任务”，更是一种实现长期稳健收益的可靠方法。通过本文的分析，读者可以更好地理解被动投资的原理和实际应用。
