### 6.2抽取出数学模型与算法的详细讲解
#### 6.2.1 投资组合优化的数学模型
- 基于现代投资组合理论的优化模型
- 数学公式：
  - 最优化目标函数：$$\min \sigma^2$$
  - 约束条件：$$\sum w_i = 1$$

#### 6.2.2 优化算法的实现
- 使用Python的优化库（如scipy.optimize）实现投资组合优化
- 代码示例：
  ```python
  import numpy as np
  from scipy.optimize import minimize

  # 示例投资组合优化代码
  def portfolio_return(weights, returns):
      return np.sum(returns * weights)

  def portfolio_variance(weights, covariance_matrix):
      return np.dot(weights.T, np.dot(covariance_matrix, weights))

  def minimize_variance(weights, returns, covariance_matrix):
      constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
      result = minimize(portfolio_variance, np.ones(len(weights))/len(weights), args=(covariance_matrix,), constraints=constraints)
      return result.x

  # 示例调用
  returns = np.array([0.1, 0.2, 0.15])
  covariance = np.array([[0.02, 0.01, 0.01],
                        [0.01, 0.03, 0.02],
                        [0.01, 0.02, 0.03]])
  weights = minimize_variance(returns, covariance)
  print(weights)
  ```
