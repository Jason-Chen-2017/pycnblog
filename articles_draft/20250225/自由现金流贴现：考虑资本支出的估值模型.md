## 第1章: 自由现金流贴现模型概述

### 1.1 自由现金流贴现模型的定义与背景

#### 1.1.1 什么是自由现金流贴现模型

自由现金流贴现模型（DCF模型）是一种用于估算企业内在价值的方法。它通过将未来现金流折现到现值，来评估企业的价值。DCF模型的核心在于将企业的未来自由现金流贴现，以确定其当前的合理估值。

#### 1.1.2 模型的背景与应用领域

DCF模型起源于财务学和金融学领域，广泛应用于企业估值、投资决策、并购分析等方面。该模型尤其适用于那些现金流稳定、未来增长可预测的企业。

#### 1.1.3 模型的核心假设与边界条件

- **核心假设**：企业在未来永续经营，现金流可以无限期持续。
- **边界条件**：模型假设市场利率和企业风险水平稳定，且贴现率不变。

### 1.2 自由现金流贴现模型的核心概念

#### 1.2.1 自由现金流的定义与计算公式

自由现金流（FCF）是指企业在支付了所有运营费用和资本支出后的剩余现金流量。其计算公式为：
$$\text{FCF} = \text{EBIT} \times (1 - \text{税率}) + \text{折旧} - \text{资本支出}$$

#### 1.2.2 贴现率的定义与计算方法

贴现率通常采用加权平均资本成本（WACC）计算，公式为：
$$\text{WACC} = w_d \times r_d \times (1 - \text{税率}) + w_e \times r_e$$

其中，$w_d$ 和 $w_e$ 分别为债务和股权的权重，$r_d$ 和 $r_e$ 分别为债务和股权的资本成本。

#### 1.2.3 模型的输入变量与输出结果

- **输入变量**：历史财务数据、未来增长率、税率、资本支出、资本成本。
- **输出结果**：企业股权价值或整体价值。

### 1.3 自由现金流贴现模型的优缺点

#### 1.3.1 模型的优点

- 理论基础扎实，逻辑清晰。
- 可以反映企业的内在价值，不受市场短期波动影响。

#### 1.3.2 模型的缺点

- 依赖于对未来现金流的准确预测，存在较大的主观性。
- 假设企业永续经营，忽视了企业生命周期的有限性。

#### 1.3.3 模型的适用场景与限制

适用于企业未来现金流稳定、可预测的企业，不适用于处于快速变化或衰退期的企业。

## 第2章: 自由现金流贴现模型的数学基础

### 2.1 现值计算公式

#### 2.1.1 单笔现金流的现值计算

单笔现金流的现值公式为：
$$\text{PV} = \frac{CF}{(1 + r)^t}$$

其中，$CF$ 是现金流，$r$ 是贴现率，$t$ 是时间。

#### 2.1.2 多笔现金流的现值计算

多笔现金流的现值公式为：
$$\text{PV} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$

#### 2.1.3 永续年金的现值计算

永续年金的现值公式为：
$$\text{PV} = \frac{CF}{r}$$

### 2.2 贴现率的计算与选择

#### 2.2.1 贴现率的定义与计算公式

贴现率通常采用WACC计算，公式如前所述。

#### 2.2.2 贴现率的选择依据

- 市场利率水平。
- 企业的风险水平。

#### 2.2.3 贴现率的敏感性分析

### 2.3 自由现金流贴现模型的数学公式推导

#### 2.3.1 模型的基本公式

企业价值公式为：
$$\text{EV} = \frac{\text{FCF}_1}{r - g} \times (1 + g)^n$$

其中，$\text{FCF}_1$ 是第一期现金流，$r$ 是贴现率，$g$ 是增长率，$n$ 是永续期。

#### 2.3.2 模型的简化与变形

简化模型为：
$$\text{EV} = \frac{\text{FCF}}{r - g}$$

## 第5章: 项目实战

### 5.1 环境安装

安装Python和必要的库（如numpy、pandas）。

### 5.2 核心实现

```python
import numpy as np

def calculate_wacc(wd, rd, we, re, tax_rate):
    return wd * rd * (1 - tax_rate) + we * re

def calculate_fcf(ebit, tax_rate, deprecation, capital_expenditure):
    return ebit * (1 - tax_rate) + deprecation - capital_expenditure

def calculate_ev(fcf, wacc, growth_rate):
    return fcf / (wacc - growth_rate)

# 示例数据
wd = 0.4
rd = 0.05
we = 0.6
re = 0.1
tax_rate = 0.3
ebit = 100
deprecation = 20
capital_expenditure = 30
growth_rate = 0.02

wacc = calculate_wacc(wd, rd, we, re, tax_rate)
fcf = calculate_fcf(ebit, tax_rate, deprecation, capital_expenditure)
ev = calculate_ev(fcf, wacc, growth_rate)

print(f"加权平均资本成本：{wacc:.2%}")
print(f"自由现金流：{fcf}")
print(f"企业价值：{ev}")
```
