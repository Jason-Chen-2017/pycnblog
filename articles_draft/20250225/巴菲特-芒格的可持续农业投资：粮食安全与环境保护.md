## 第3章: 可持续农业投资的数学模型与算法原理

### 3.1 可持续农业投资的数学模型
#### 3.1.1 现金流折现模型（DCF模型）
- **定义**  
  将未来现金流折现，计算企业内在价值。

- **公式**  
  $$ V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} $$  
  其中，$V$ 是企业价值，$CF_t$ 是第 $t$ 年的现金流，$r$ 是折现率。

- **流程图**  

```mermaid

B --> C[计算折现率]
C --> D[计算未来现金流现值]
D --> E[求和得到企业价值]
E --> F[结束]
```

#### 3.1.2 农业企业的内在价值计算
- **步骤**  
  1. 估算未来现金流。  
  2. 确定合适的折现率。  
  3. 计算未来现金流的现值。  
  4. 求和得到企业价值。

def calculate_intrinsic_value(cash_flows, discount_rate):
    present_value = 0
    for t, cf in enumerate(cash_flows):
        if t == 0:
            present_value += cf
        else:
            present_value += cf / (1 + discount_rate) ** t
    return present_value

cash_flows = [100, 200, 300, 400]
discount_rate = 0.05
iv = calculate_intrinsic_value(cash_flows, discount_rate)
print(f"企业内在价值：{iv}")
