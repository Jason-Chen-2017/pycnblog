## 第3章: 投资回报分析的算法原理

### 3.1 投资回报分析的原理
#### 3.1.1 净现值（NPV）模型
- 公式：$$NPV = \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t}$$
- 代码示例：
  ```python
  def calculate_npv(cash_flows, discount_rate):
      return sum(cash_flows[i]/(1+discount_rate)**i for i in range(len(cash_flows)))
  ```

#### 3.1.2 内部收益率（IRR）模型
- 公式：$$IRR = r \text{ 使得 } NPV = 0$$
- 代码示例：
  ```python
  def calculate_irr(cash_flows):
      return np.irr(cash_flows)
  ```

#### 3.1.3 投资回收期（Payback Period）模型
- 简单介绍：计算回收初始投资的时间。
