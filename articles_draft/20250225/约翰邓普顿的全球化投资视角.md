## 3.3 投资组合优化的代码实现
### 3.3.1 Python代码实现
```python
import numpy as np
import pandas as pd

def optimize_portfolio(returns, weights):
    # 计算投资组合的期望收益和风险
    expected_return = np.dot(weights, returns)
    risk = np.sqrt(np.dot(weights.T, np.dot(returns.cov(), weights)))
    return expected_return, risk

# 示例数据
returns = pd.DataFrame({
    '资产1': [0.05, 0.03, 0.07],
    '资产2': [0.02, 0.06, 0.05]
})

weights = [0.5, 0.5]

expected_return, risk = optimize_portfolio(returns, weights)
print(f"期望收益: {expected_return}")
print(f"风险: {risk}")
```
