## 第一部分：NCAV策略的背景与基础

### 第1章：NCAV策略的起源与核心思想

#### 1.1 本杰明·格雷厄姆与价值投资
- **1.1.1 格雷厄姆的生平简介**  
  格雷厄姆是20世纪著名投资家，著有《证券分析》和《聪明的投资者》，强调安全边际和价值投资。
- **1.1.2 格雷厄姆的价值投资理念**  
  强调购买低于内在价值的股票，注重安全边际和长期投资。
- **1.1.3 NCAV策略的提出背景**  
  在20世纪30年代经济危机中，格雷厄姆开发NCAV策略，帮助投资者识别低估股票。

#### 1.2 NCAV策略的核心思想
- **1.2.1 什么是NCAV**  
  NCAV是每股净流动资产价值，衡量公司清算价值。
- **1.2.2 NCAV策略的目标**  
  筛选股价低于NCAV的股票，利用市场低估的机会。
- **1.2.3 NCAV与市场估值的关系**  
  当股价低于NCAV时，股票具有安全边际，投资风险低。

### 第2章：NCAV策略的核心计算方法

#### 2.1 NCAV的计算公式
- **NCAV计算公式**：
  $$ NCAV = \frac{流动资产 - 非流动资产}{流通股数量} $$
  其中，流动资产包括现金、应收账款和存货，非流动资产包括固定资产和长期投资。

#### 2.2 NCAV计算的步骤
- **步骤1：获取公司财务报表**  
  收集资产负债表和利润表，确保数据准确。
- **步骤2：计算流动资产与非流动资产**  
  流动资产：现金 + 应收账款 + 存货  
  非流动资产：固定资产 + 长期投资
- **步骤3：计算NCAV值**  
  用公式计算NCAV，得到每股净流动资产价值。
- **步骤4：对比市场价与NCAV值**  
  如果股价低于NCAV，股票可能被低估。

#### 2.3 NCAV计算的注意事项
- **数据来源的可靠性**  
  使用可靠的财务报表数据，避免错误。
- **行业差异的影响**  
  不同行业流动资产占比不同，需考虑行业特性。
- **时间周期的选择**  
  通常使用季度或年度数据，保持一致性。

### 第3章：NCAV策略在投资中的应用

#### 3.1 NCAV策略的应用场景
- **低估值股票的筛选**  
  通过NCAV找到股价低于净值的股票。
- **投资组合的构建**  
  将NCAV策略与其他指标结合，优化投资组合。
- **风险控制的实施**  
  设置止损点，避免市场波动带来的损失。

#### 3.2 NCAV策略的优缺点
- **优点**  
  简单易懂，适合新手；强调安全边际，风险低。
- **缺点**  
  忽略了成长性和非流动资产价值；在高成长行业效果有限。
- **与其他策略的对比**  
  PE、PB策略各有优劣，NCAV适合寻找低估股票。

### 第5章：NCAV策略的项目实战

#### 5.1 环境安装

#### 5.2 核心实现源代码
```python
import pandas as pd
import requests

def calculate_n cav(stock_data):
   流动资产 = stock_data['流动资产']
    非流动资产 = stock_data['非流动资产']
    流通股数量 = stock_data['流通股数量']
    return (流动资产 - 非流动资产) / 流通股数量

url = "https://api.example.com/financial_data"
response = requests.get(url)
data = response.json()

# 假设data包含多个公司的财务数据
companies = data['companies']
results = []
for company in companies:
    stock_data = company['financials']
    n cav_value = calculate_n cav(stock_data)
    market_price = company['market_price']
    if market_price < n cav_value:
        results.append(company['name'])

print("低估股票列表：", results)
```

#### 5.3 代码应用解读
- **数据获取**  
  使用requests库从API获取数据。
- **计算NCAV**  
  调用calculate_n cav函数计算每股NCAV。
- **筛选股票**  
  比较股价与NCAV，收集低估股票名称。
