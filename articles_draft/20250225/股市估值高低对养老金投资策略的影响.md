# 第2章: 股市估值的理论与方法

## 2.1 股市估值的理论基础

### 2.1.1 基本分析法
基本分析法关注企业的财务报表和行业地位，通过分析企业的盈利能力、成长性等指标，评估其内在价值。

### 2.1.2 技术分析法
技术分析法通过研究股票价格的历史走势，预测未来的价格变动趋势。

### 2.1.3 行为分析法
行为分析法研究投资者的心理和行为，揭示市场中的非理性行为对股价的影响。

## 2.2 常用估值指标

### 2.2.1 市盈率（P/E）
公式：$$P/E = \frac{股票价格}{每股净利润}$$
市盈率反映了市场对企业的盈利能力的预期。

### 2.2.2 市净率（P/B）
公式：$$P/B = \frac{股票价格}{每股净资产}$$
市净率适用于评估资产密集型企业的估值。

### 2.2.3 股息率（Dividend Yield）
公式：$$股息率 = \frac{每股股息}{股票价格}$$
股息率反映了股票的分红能力。

## 2.3 估值模型与方法

### 2.3.1 现金流折现模型（DCF）
DCF模型通过折现企业未来现金流，评估其内在价值。

步骤：
1. 估计未来现金流。
2. 选择适当的折现率。
3. 计算现值。
4. 与市场价格比较。

### 2.3.2 市盈率模型
通过比较企业的P/E与行业平均水平，判断其估值是否合理。

### 2.3.3 市净率模型
通过比较企业的P/B与行业平均水平，判断其估值是否合理。

## 2.4 本章小结
本章详细介绍了股市估值的理论基础和常用指标，为后续分析提供了方法论支持。
