# 第2章: 产品线分析的核心要素

## 2.1 产品线的生命周期  
产品线的生命周期分为四个阶段：  
1. **引入期**：新产品进入市场，销售额逐步增长。  
2. **成长期**：市场需求旺盛，销售额迅速上升。  
3. **成熟期**：市场饱和，销售额趋于稳定。  
4. **衰退期**：市场需求下降，销售额开始下滑。

## 2.2 产品线的竞争优势分析  
竞争优势是产品线成功的关键。彼得·林奇通过以下指标评估竞争优势：  
- **市场占有率**：产品在市场中的份额占比。  
- **品牌影响力**：品牌知名度和美誉度。  
- **成本优势**：生产成本是否低于竞争对手。

## 2.3 产品线的财务表现分析  
财务表现是评估产品线盈利能力的关键。彼得·林奇关注以下指标：  
- **销售收入**：产品线的总收入。  
- **利润率**：净利润率和毛利率。  
- **增长潜力**：未来销售额的预期增长率。  

### 财务表现分析的数学模型  
$$ 利润率 = \frac{净利润}{销售收入} $$

# 第3章: 产品线分析的数学模型与算法

## 3.1 产品线评分系统  
彼得·林奇设计了一个评分系统，通过量化指标评估产品线的竞争力。评分系统包括以下步骤：  
1. 收集产品线的市场数据和财务数据。  
2. 根据指标权重计算各产品的得分。  
3. 综合得分，得出最终评分。  

### 评分系统示例代码  
```python
def calculate_score(product_data):
    weights = {'market_share': 0.4, 'profitability': 0.3, 'growth': 0.3}
    scores = []
    for product in product_data:
        score = 0
        for metric, weight in weights.items():
            score += product[metric] * weight
        scores.append(score)
    return scores

# 示例数据
product_data = [
    {'market_share': 0.3, 'profitability': 0.25, 'growth': 0.2},
    {'market_share': 0.2, 'profitability': 0.3, 'growth': 0.3}
]

# 计算评分
scores = calculate_score(product_data)
print(scores)  # 输出：[0.3*0.4 + 0.25*0.3 + 0.2*0.3, 0.2*0.4 + 0.3*0.3 + 0.3*0.3]
```

def analyze_product_line(data):
