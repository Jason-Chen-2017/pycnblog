# 第1章 巴菲特的长期主义概述

## 1.1 长期主义的定义与核心理念

### 1.1.1 长期主义的定义  
长期主义（Long-termism）是一种投资和管理哲学，强调关注长期价值的创造，而非短期收益。它主张通过持续的投入、稳健的决策和对未来的深刻理解，实现可持续的成功。巴菲特的长期主义以价值投资为核心，注重企业的内在价值和长期增长潜力。

### 1.1.2 长期主义的核心理念  
- **价值投资**：寻找具有持续竞争优势的企业，关注企业的内在价值而非市场波动。  
- **安全边际**：在投资中留出足够的安全空间，以应对不确定性和市场波动。  
- **时间复利**：长期投资能够通过复利效应实现财富的指数级增长。  

### 1.1.3 长期主义与短期主义的对比  
| 对比维度 | 长期主义 | 短期主义 |
|----------|----------|----------|
| 目标     | 长期价值 | 短期收益 |
| 风险     | 较低     | 较高     |
| 投资策略 | 价值投资 | 技术套利 |

---

## 1.2 巴菲特的长期主义投资策略

### 1.2.1 巴菲特的投资哲学  
巴菲特的投资哲学可以用一句话概括：**“价格是市场决定的，价值是企业决定的”**。他强调通过研究企业的基本面，寻找那些具有强大竞争优势、良好管理和稳健财务状况的企业。

### 1.2.2 长期主义在投资中的应用  
- **集中投资**：将资金集中在少数具有长期竞争优势的企业中，避免分散投资带来的风险。  
- **长期持有**：除非企业基本面发生变化，否则长期持有优质资产。  
- **逆周期投资**：在市场低迷时增加投资，利用市场非理性行为创造长期价值。  

### 1.2.3 长期主义的数学模型与公式  
长期主义的投资回报可以通过复利公式计算：  
$$ FV = PV \times (1 + r)^n $$  
其中，PV 是现值，r 是年化收益率，n 是投资时间。

def monte_carlo_simulation(n, iterations=1000):

    outcomes = np.random.rand(iterations)
    returns = np.where(outcomes > 0.5, 1, -1)
    cumulative = np.cumsum(returns)
    plt.plot(cumulative)
