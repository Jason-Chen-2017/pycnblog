# 第1章 格雷厄姆特价股票理论概述

## 1.1 格雷厄姆投资理论的背景与发展

### 1.1.1 投资理论的演变
- **传统投资理论**：基于市场有效性和资产组合理论。
- **价值投资的兴起**：本杰明·格雷厄姆提出“安全边际”概念，强调寻找市场低估的股票。
- **量化投资的崛起**：大数据和算法驱动的投资方式。

### 1.1.2 格雷厄姆的安全边际理论
- **定义**：安全边际=内在价值-市场价格。
- **投资策略**：买入市场价格低于内在价值的股票。
- **核心思想**：价格波动是投资机会的来源。

### 1.1.3 格雷厄姆理论的核心要素
| 核心要素 | 描述 |
|----------|------|
| 内在价值 | 股票的真实价值，基于基本面分析 |
| 安全边际 | 价格与内在价值的差异，提供风险缓冲 |
| 选股标准 | 市盈率、市净率、股息率等指标 |

## 1.2 格雷厄姆理论与现代投资理论的结合

### 1.2.1 格雷厄姆理论的现代视角
- **价值发现**：通过大数据分析寻找被低估的股票。
- **风险管理**：利用量化方法控制投资组合风险。

### 1.2.2 格雷厄姆理论对量化投资的启示
- **因子化**：将安全边际转化为可量化的因子。
- **系统化**：构建自动化交易策略。
