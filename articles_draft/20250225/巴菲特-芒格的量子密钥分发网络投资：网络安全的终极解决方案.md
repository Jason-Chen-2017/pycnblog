# 第4章 量子密钥分发的算法与数学模型

## 4.1 量子密钥分发的数学基础

### 4.1.1 量子态的数学表示

量子态可以通过向量和矩阵形式进行数学表示，例如：

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$

其中，$\alpha$ 和 $\beta$ 是复数，满足 $|\alpha|^2 + |\beta|^2 = 1$。

### 4.1.2 量子纠缠的数学描述

量子纠缠可以通过贝尔态（Bell states）来表示，例如：

$$|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$$

## 4.2 量子密钥分发的协议分析

### 4.2.1 BB84协议

BB84协议是QKD的经典协议，包括量子态的发送、测量和密钥协商三个步骤。其流程如下：

1. 量子态的发送：Alice发送一系列量子态（使用两个不同的编码basis：{|0⟩, |1⟩}和{|+⟩, |−⟩}）。
2. 量子态的测量：Bob随机选择测量basis并测量接收到的量子态。
3. 量子态的比较：Alice和Bob公佈测量的basis，并比较，保留使用相同basis测量的部分作为密钥。

### 4.2.2 去除错误和信息泄露的步骤

通过基底比较，Alice和Bob会发现由于传输过程中的噪声或窃听导致的错误，并通过经典信息进行协商，最终得到一致的密钥。
