## 第一部分：背景介绍

### 第1章：金融危机与股市估值概述

#### 1.1 金融危机的定义与特征
金融危机是指金融系统中的重大失衡或崩溃，通常由经济衰退、市场崩盘或金融机构的失败引发。金融危机的主要特征包括市场波动加剧、资产价格急剧下跌、投资者信心下降等。这些因素会导致股市估值的显著变化。

#### 1.2 股市估值的基本概念
股市估值是通过分析公司基本面和市场状况来确定股票合理价格的过程。常用的估值指标包括市盈率（P/E）和市净率（P/B）。  
- **市盈率（P/E）**：股价与每股收益的比率，反映市场对公司的盈利能力的预期。  
- **市净率（P/B）**：股价与每股净资产的比率，衡量股价相对于账面价值的高低。  

股市估值与市场波动密切相关，金融危机会导致这些指标发生显著变化。

### 第2章：金融危机与股市估值的核心要素

#### 2.1 金融危机对股市估值的影响机制
金融危机通过多种途径影响股市估值：
1. **投资者信心下降**：恐慌情绪导致抛售压力增加，股价下跌。
2. **流动性危机**：资金短缺导致市场资金减少，股价被低估。
3. **公司盈利预期**：经济衰退影响企业盈利，降低估值。

#### 6.2 核心代码实现

```python
import pandas as pd
import matplotlib.pyplot as plt

# 数据收集
data = {
    '时间': ['2007', '2008', '2009', '2010'],
    '股价': [100, 80, 60, 70],
    '每股收益': [10, 5, 3, 4],
    '每股净资产': [20, 15, 10, 12]
}

df = pd.DataFrame(data)

# 计算市盈率和市净率
df['市盈率'] = df['股价'] / df['每股收益']
df['市净率'] = df['股价'] / df['每股净资产']

# 可视化
plt.figure(figsize=(12, 6))
plt.plot(df['时间'], df['市盈率'], label='市盈率')
plt.plot(df['时间'], df['市净率'], label='市净率')
plt.title('金融危机前后市盈率与市净率变化')
plt.xlabel('时间')
plt.ylabel('比率')
plt.legend()
plt.show()
```

#### 6.3 实际案例分析
