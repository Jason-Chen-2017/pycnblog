### 第1章：彼得林奇与小盘价值股投资

#### 1.1 彼得林奇的背景与投资理念
彼得·林奇是美国著名基金经理人，以其在富达麦哲伦基金的长期任职中表现出色而闻名。他的投资理念强调长期持有优质股票，尤其是那些被市场低估的小盘价值股。林奇认为，小盘股具有较大的增长潜力，而价值股则提供了较高的安全边际。

#### 1.2 小盘价值股的定义与特征
小盘价值股通常指市值较小、市盈率和市净率低于市场平均水平的股票。这些股票往往具有较高的股息率和较低的估值，但被市场忽视或低估。

### 第2章：经济周期与投资策略

#### 2.1 经济周期的定义与分类
经济周期通常分为衰退、复苏、稳定和增长四个阶段，每个阶段对股票投资的影响不同。

#### 2.2 小盘价值股在不同经济周期中的表现
- **衰退期**：小盘价值股表现不佳，但具有较高的安全边际，适合长期持有。
- **复苏期**：小盘价值股逐渐恢复，适合逐步建仓。
- **稳定期**：小盘价值股表现稳定，适合长期持有。
- **增长期**：小盘价值股表现优异，适合积极投资。

### 第3章：小盘价值股的筛选策略

#### 3.1 小盘价值股的筛选标准
- **市盈率（P/E）**：低于市场平均值。
- **市净率（P/B）**：低于市场平均值。
- **股息率**：高于市场平均水平。

#### 3.2 彼得林奇的选股方法
- **买入并持有**：选择低估的股票长期持有。
- **基本面分析**：分析公司的盈利能力、财务状况和行业地位。
- **行业分析**：选择具有竞争优势的行业。

### 第4章：小盘价值股投资的数学模型与算法

#### 4.1 筛选标准的数学模型
- **市盈率计算公式**：$$P/E = \frac{Price}{Earnings}$$
- **市净率计算公式**：$$P/B = \frac{Price}{Book\ Value}$$
- **股息率计算公式**：$$Dividend\ Yield = \frac{Dividend}{Price}$$

#### 6.2 核心实现源代码

```python
import pandas as pd

# 加载股票数据
data = pd.read_csv('stocks.csv')

# 计算市盈率和市净率
data['PE'] = data['Price'] / data['Earnings']
data['PB'] = data['Price'] / data['Book Value']

# 筛选标准
filtered_stocks = data[(data['PE'] < data['PE'].mean()) &
                        (data['PB'] < data['PB'].mean()) &
                        (data['Dividend Yield'] > data['Dividend Yield'].mean())]

# 输出结果
print(filtered_stocks)
```
