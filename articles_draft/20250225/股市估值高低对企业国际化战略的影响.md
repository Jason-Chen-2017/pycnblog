# 第1章: 股市估值的基本概念与影响因素

## 1.1 股市估值的定义与计算方法

### 1.1.1 股市估值的定义  
股市估值是指通过对企业市值的评估，判断其内在价值和市场表现的过程。市值=股价×流通股数量，是企业市场价值的核心指标。

### 1.1.2 市盈率与市净率的计算公式  
- **市盈率（P/E Ratio）**：衡量企业股价与每股收益之间的关系，公式为：
  $$\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}$$  
  例如，假设某企业股价为30元，每股收益为5元，则市盈率为6倍。

- **市净率（P/B Ratio）**：衡量企业股价与每股净资产之间的关系，公式为：
  $$\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}$$  
  例如，某企业股价为20元，每股净资产为10元，则市净率为2倍。

### 1.1.3 市值与企业价值的关系  
市值反映了市场对企业未来盈利能力的预期，而企业价值则包括资产、品牌、技术等多方面因素。市值与企业价值的差异可能反映市场的低估或高估。

## 1.2 国际化战略的定义与特征

### 1.2.1 国际化战略的定义  
国际化战略是指企业在全球范围内扩展业务，进入新市场、并购海外企业或建立合资公司等行为。

### 1.2.2 国际化战略的主要类型  
- **出口模式**：通过贸易出口进入国际市场，风险较低，但增长有限。  
- **合资模式**：与当地企业合作，分担风险和成本。  
- **并购模式**：通过收购海外企业快速进入市场，但风险较高。  

### 1.2.3 国际化战略的核心要素  
- 市场选择：目标国家的市场规模、竞争环境、政策法规等。  
- 进入方式：直接投资、间接投资、合作模式等。  
- 资源配置：资金、技术、人才等的投入。

## 1.3 股市估值与国际化战略的关系

### 1.3.1 股市估值对企业国际化战略的影响  
高估值可能推动企业进行海外并购，而低估值可能促使企业调整市场拓展策略。  

### 1.3.2 国际化战略对股市估值的反向影响  
国际化战略的成功可能提升企业市值，而失败可能降低市值。

### 2.1.2 高估值对企业扩张的推动作用
