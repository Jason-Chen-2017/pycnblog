### 第一部分：格雷厄姆策略与产业集群基础

#### 第1章：价值投资与格雷厄姆策略概述

##### 1.1 价值投资的核心理念
- 1.1.1 价值投资的定义与历史发展
  - 价值投资是一种以内在价值为导向的投资策略，由本杰明·格雷厄姆和戴维·多德提出。
  - 格雷厄姆的学生彼得·林奇进一步发展了这一理论，使其成为现代投资学的重要组成部分。
  - 价值投资的核心思想是寻找市场价格低于其内在价值的股票。

- 1.1.2 格雷厄姆的投资理念与方法
  - 格雷厄姆提出的“安全边际”概念：购买价格低于内在价值的一定折扣，以降低投资风险。
  - 格雷厄姆的选股标准：低市盈率、低市净率、高股息率等。

- 1.1.3 格雷厄姆策略在现代投资中的地位
  - 格雷厄姆策略是价值投资的基石，至今仍被广泛应用于股票投资中。
  - 该策略特别适合在市场低迷或股票价格被低估的情况下使用。

##### 1.2 特价股票的定义与特征
- 1.2.1 特价股票的定义
  - 特价股票是指市场价格显著低于其内在价值的股票，通常被认为是被市场忽视或低估的投资机会。
  - 这类股票通常具有较高的安全边际，适合长期投资。

- 1.2.2 特价股票的市场表现特征
  - 特价股票往往在市场低迷时出现，具有较高的反弹潜力。
  - 由于其价格低廉，适合中小投资者参与。

- 1.2.3 特价股票与普通股票的对比分析
  | 特性      | 特价股票                  | 普通股票                  |
  |-----------|---------------------------|---------------------------|
  | 价格      | 低于内在价值              | 接近或高于内在价值        |
  | 风险      | 较低（安全边际高）         | 较高（安全边际低）         |
  | 收益      | 高（长期）                 | 中等或低                  |

#### 第2章：产业集群的定义与分类
- 2.1 产业集群的基本概念
  - 产业集群是指在地理上相对集中、具有相似或相关联的企业群体。
  - 产业集群通常具有专业化分工明确、资源集中、竞争力强的特点。

- 2.2 主要产业集群的分类
  - 制造业产业集群：如汽车制造、电子产品制造等。
  - 科技产业集群：如硅谷的科技公司集群。
  - 服务业产业集群：如金融服务业集群。

### 第二部分：格雷厄姆策略的数学模型与算法

#### 第3章：格雷厄姆策略的核心原理
- 3.1 格雷厄姆策略的主要原则
  - 安全边际：购买价格 ≤ 内在价值 × 折扣率。
  - 内在价值的计算公式：$$ V = \frac{E}{1 + r} $$
    - 其中，E为未来现金流的现值，r为贴现率。
  - 市场先生理论：投资者应避免与市场的短期波动对抗，而是关注企业的内在价值。

- 3.2 格雷厄姆策略的适用场景
  - 在市场低迷或恐慌时，更容易找到特价股票。
  - 在企业盈利稳定、行业前景良好的产业集群中，策略效果更佳。

#### 第4章：数学模型与算法实现
- 4.1 内在价值计算模型
  - 以制造业企业为例，计算其内在价值：
    $$ V = \frac{E}{1 + r} $$
    其中，E为企业未来5年的平均净利润，r为折现率（假设为10%）。
  - 例如，某制造业企业年净利润为1000万元，折现率为10%，则其内在价值为：
    $$ V = \frac{1000}{1 + 0.10} ≈ 909.09 \text{万元} $$

- 4.2 特价股票筛选算法
  - 算法步骤：
    1. 收集目标产业集群内的企业数据。
    2. 计算每家企业的内在价值。
    3. 比较市场价格与内在价值，筛选出市场价格 ≤ 内在价值 × 80% 的股票。

### 第五部分：项目实战与优化建议

#### 第10章：项目实战
- 10.1 环境安装与配置
  - 安装Python、Pandas、Matplotlib等工具。
  - 数据源：使用Yahoo Finance获取企业数据。

- 10.2 核心代码实现
  ```python
  import pandas as pd
  import yfinance as yf

  def calculate_intrinsic_value(ticker, years=5, discount_rate=0.1):
      data = yf.download(ticker, period='5y')
      # 计算净利润
      net_income = data['Adj Close'].pct_change().cumprod().iloc[-1]
      # 计算内在价值
      intrinsic_value = net_income / (1 + discount_rate)
      return intrinsic_value

  # 筛选特价股票
  tickers = ['AAPL', 'MSFT', 'GOOGL']
  for ticker in tickers:
      iv = calculate_intrinsic_value(ticker)
      price = yf.download(ticker)['Adj Close'][-1]
      if price <= iv * 0.8:
          print(f"{ticker} 是特价股票")
  ```
