## 第二部分：格雷厄姆价值投资理论基础

### 第1章：格雷厄姆价值投资理论

#### 1.1 格雷厄姆价值投资理论的核心概念

- **价值投资的定义**：寻找市场价格低于内在价值的股票，注重安全边际。
- **内在价值计算**：基于企业基本面，包括收益、资产和现金流。
- **安全边际的重要性**：确保投资的安全性，减少市场波动影响。

#### 1.2 格雷厄姆的选股标准

- **低市盈率和市净率**：避免高估股票。
- **高股息率**：寻找稳定收益。
- **财务健康状况**：关注低债务和高利润率。

#### 1.3 格雷厄姆投资策略

- **长期投资**：避免短期波动。
- **分散投资**：降低风险。
- **持续学习**：更新投资知识。

#### 1.4 格雷厄姆理论的优缺点

- **优点**：风险控制，长期回报。
- **缺点**：忽视市场变化，低估成长股。

### 第2章：影响力投资的定义与目标

#### 2.1 影响力投资的定义

- **社会和环境影响**：投资不仅追求财务回报，还关注其对社会和环境的影响。
- **联合国可持续发展目标**：投资需符合全球可持续发展目标。

#### 2.2 影响力投资的目标

- **经济回报**：与传统投资相比，影响力投资可能有较低的回报。
- **社会价值**：解决社会问题，如贫困、教育、健康。
- **环境可持续性**：减少碳足迹，支持可再生能源。

#### 2.3 影响力投资与传统投资的区别

- **目标**：传统投资追求利润，影响力投资兼顾社会价值。
- **评估标准**：传统投资看财务指标，影响力投资看社会和环境影响。

## 第五部分：数学模型与算法实现

### 第4章：数学模型与算法实现

#### 4.1 改进的多因子模型

- **模型目标**：最大化财务回报，最小化社会影响风险。
- **因子选择**：财务健康、社会影响评分、管理质量。
- **权重分配**：根据市场环境动态调整。

#### 4.2 算法实现

- **步骤1：数据收集**
  - 收集股票的财务数据和社会影响评分。
- **步骤2：计算因子得分**
  - 计算每个因子的得分，如市盈率、市净率。
- **步骤3：加权计算**
  - 根据权重计算综合评分。
- **步骤4：筛选股票**
  - 选择综合评分高的股票。

#### 4.3 数学公式

- **财务健康因子 (FH)**
  \[
  FH = \frac{\text{净利润}}{\text{资产}}
  \]
- **社会影响评分 (SI)**
  \[
  SI = 0.5 \times \text{环境影响} + 0.5 \times \text{社会责任}
  \]
- **综合评分 (SC)**
  \[
  SC = w_1 \times FH + w_2 \times SI
  \]

#### 4.4 代码实现

```python
import pandas as pd

def calculate_sc(financial_health, social_impact):
    weight_fh = 0.7
    weight_si = 0.3
    sc = weight_fh * financial_health + weight_si * social_impact
    return sc

# 示例数据
data = {
    '股票代码': ['A', 'B', 'C'],
    '净利润': [100, 150, 200],
    '资产': [500, 600, 700],
    '环境影响': [2, 3, 4],
    '社会责任': [3, 2, 1]
}

df = pd.DataFrame(data)

df['财务健康'] = df['净利润'] / df['资产']
df['社会影响评分'] = 0.5 * df['环境影响'] + 0.5 * df['社会责任']
df['综合评分'] = calculate_sc(df['财务健康'], df['社会影响评分'])

print(df)
```

#### 6.2 核心代码实现

```python
import pandas as pd
import numpy as np

def calculate_social_impact(environmental_score, social_responsibility_score):
    return 0.5 * environmental_score + 0.5 * social_responsibility_score

def calculate_financial_health(net_income, total_assets):
    return net_income / total_assets

def calculate_composite_score(financial_health, social_impact):
    weight_fh = 0.7
    weight_si = 0.3
    return weight_fh * financial_health + weight_si * social_impact

# 示例数据
data = {
    '股票代码': ['A', 'B', 'C'],
    '净利润': [100, 150, 200],
    '资产': [500, 600, 700],
    '环境影响': [2, 3, 4],
    '社会责任': [3, 2, 1]
}

df = pd.DataFrame(data)

df['财务健康'] = df.apply(lambda x: calculate_financial_health(x['净利润'], x['资产']), axis=1)
df['社会影响评分'] = df.apply(lambda x: calculate_social_impact(x['环境影响'], x['社会责任']), axis=1)
df['综合评分'] = df.apply(lambda x: calculate_composite_score(x['财务健康'], x['社会影响评分']), axis=1)

print(df)
```

- **选择股票C**：财务健康0.4，社会影响评分2.5，综合评分0.7*0.4 + 0.3*2.5 = 0.28 + 0.75 = 1.03。
