#### 1.1 彼得林奇与"家庭股票"的概念

  彼得林奇提出的“家庭股票”是指那些具有长期稳定增长潜力，适合家庭长期持有的股票。这些股票通常具有较高的股息收益率、良好的成长性和较强的抗跌性。

  跨代财富传承是指将财富从一代人传递到下一代人，同时保持财富的增值和保值。目标是在传承过程中实现财富的可持续增长，同时避免因财富分配不当导致的家庭矛盾或财务风险。

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

# 示例数据：股票收益和风险
stocks = pd.DataFrame({
    '收益': [0.1, 0.15, 0.08, 0.12],
    '风险': [0.1, 0.2, 0.05, 0.15]
})

# 定义优化目标函数
def portfolio Optimization(weights, stocks):
    return -weights.dot(stocks['收益'])

# 定义约束条件
def constraint(weights):
    return weights.sum() - 1

# 初始权重
initial_weights = [0.25, 0.25, 0.25, 0.25]

# 使用最小化器优化
result = minimize(portfolio Optimization, initial_weights, args=(stocks,), 
                  method='SLSQP', constraints={'type': 'eq', 'fun': constraint})

# 输出最优权重
print("最优权重:", result.x)
```
