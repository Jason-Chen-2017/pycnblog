## 第一章：量子密码学的背景与重要性

### 1.1 量子计算的基本原理

- **量子位与经典位的对比**
  - 量子位（Qubit）与经典位（Bit）的根本区别在于量子叠加态和纠缠态。
  - 量子叠加态：$|0\rangle$, $|1\rangle$, $|+\rangle = \frac{|0\rangle + |1\rangle}{\sqrt{2}}$, $|-\rangle = \frac{|0\rangle - |1\rangle}{\sqrt{2}}$。
  - 量子纠缠态：两个或多个量子位之间的强关联，如EPR对。

- **量子计算的优势**
  - 通过量子并行性，量子计算机在特定问题（如大数分解）上的速度远超经典计算机。

- **量子密码学的潜力**
  - 利用量子力学的特性，构建更安全的加密算法。

```mermaid

    B --> C{叠加态}
    C --> D[|0\rangle]
    C --> E[|1\rangle]

    F --> G[EPR对]
```

### 1.2 量子密码学的核心概念

- **量子密钥分发（QKD）**：通过量子态传输实现安全密钥分发。
- **量子签名**：利用量子力学特性实现签名验证。
- **抗量子加密**：设计抵抗量子计算攻击的加密算法。

## 第二章：量子密码学的核心原理

### 2.1 量子密钥分发（QKD）的实现

- **BB84协议**
  - **步骤**：Alice生成随机密钥并用两个基向量编码，Bob用随机基测量。双方通过经典通信同步基，并丢弃未匹配的位。
  - **流程图**：
  
  ```mermaid
  graph TD
      Alice[爱丽丝] --> Protocol[协议]
      Protocol --> Bob[鲍勃]
      Protocol --> ClassicalCommunication[经典通信]
      ClassicalCommunication --> Alice
      ClassicalCommunication --> Bob
  ```

- **数学模型**
  - 爱丽丝发送量子态：$\rho = \sum_{i=1}^2 \frac{1}{2} (|x_i\rangle \langle x_i|)$。
  - 鲍勃测量：$\langle x_j | \rho | x_j \rangle$，若基相同，测量结果正确。

### 2.2 量子签名与认证

- **量子签名的实现**
  - 签名生成：利用纠缠态和Bell基。
  - 验证：通过比较测量结果判断签名的有效性。

- **数学模型**
  - 签名生成：$|\Psi\rangle = \frac{1}{\sqrt{2}}(|01\rangle - |10\rangle)$。
  - 验证：$\langle \Psi | \rho | \Psi \rangle$，若等于1，则签名有效。

## 第六章：安全风险与防护策略

### 6.1 量子计算带来的安全威胁

- **传统加密算法的脆弱性**
  - RSA、ECC等公钥加密算法易被量子攻击破解。
  - SHA系列哈希函数的安全性降低。

### 6.2 抗量子加密算法的选择

- **抗量子算法类型**
  - 哈希-Based签名（如Schnorr签名）。
  - 椴树密码（Lattice-based）。
  - 零知识证明（如ZK-SNARK）。

- **选择标准**
  - 算法成熟度：NIST标准化或接近。
  - 实施难度：是否支持现有系统和协议。
