#### 3.2 算法实现
- 3.2.1 算法的数学模型
$$
\text{收益} = \sum_{i=1}^{n} (r_i \times w_i)
$$
其中，$r_i$ 表示第 $i$ 项资产的收益率，$w_i$ 表示第 $i$ 项资产的权重。

- 3.2.2 算法的Python实现
```python
def track_and_record(assets, weights):
    returns = [asset.return() for asset in assets]
    portfolio_return = sum(r * w for r, w in zip(returns, weights))
    return portfolio_return
```
