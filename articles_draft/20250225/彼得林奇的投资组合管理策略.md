#### 1.1 投资组合管理的定义与概念

投资组合管理是指通过科学配置和调整投资组合中的资产，以实现既定目标（如收益最大化、风险最小化）的过程。其核心在于平衡风险与收益，优化资产配置。

- **定义**: 投资组合管理是对资产的科学管理和调整，以实现收益与风险的最佳平衡。
- **重要性**: 在不确定性市场中，科学的投资组合管理能有效分散风险，提升整体收益。

#### 1.2 投资组合管理的重要性

- **风险控制**: 通过分散投资降低特定资产的风险。

- **适应市场变化**: 根据市场波动及时调整投资策略。

### 第3章: 现代投资组合理论与优化算法

#### 3.1 均值-方差优化模型

均值-方差模型由Harry Markowitz提出，用于优化资产配置。

- **数学模型**:

$$ \text{目标函数: } \min \sigma^2 $$
$$ \text{约束条件: } \sum w_i r_i = \mu $$

其中，$\sigma^2$为风险，$w_i$为权重，$r_i$为预期收益。

- **现代投资组合理论(MPT)**: 通过优化模型构建有效前沿，找到最优组合。

#### 3.2 投资组合优化算法

- **随机优化算法**: 如蒙特卡洛模拟。
- **确定性优化算法**: 如拉格朗日乘数法。
- **智能优化算法**: 如遗传算法。

以下是实现投资组合优化的Python代码：

```python
import numpy as np
import pandas as pd

def mean_variance_optimization(mu, sigma):
    n = len(mu)
    # 构建协方差矩阵
    cov = sigma.T.dot(sigma)
    # 使用numpy求解
    inv_cov = np.linalg.inv(cov)
    w = inv_cov.dot(mu) / (mu.T.dot(inv_cov).dot(mu))
    return w

# 示例数据
mu = np.array([0.1, 0.15, 0.08])
sigma = np.array([[0.15, 0.05, 0.07],
                  [0.05, 0.20, 0.05],
                  [0.07, 0.05, 0.25]])

weights = mean_variance_optimization(mu, sigma)
print("最优权重:", weights)
```
