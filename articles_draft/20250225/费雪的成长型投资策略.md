## 第3章：成长型投资的数学模型与公式

### 3.1 投资回报率的计算
- 投资回报率的公式：$$ ROI = \frac{利润}{投资成本} \times 100\% $$
- 复利计算公式：$$ A = P(1 + r)^n $$

### 3.2 费雪策略中的关键指标计算
- 净利润增长率：$$ 净利润增长率 = \frac{当年净利润 - 上年净利润}{上年净利润} \times 100\% $$
- 股东权益回报率（ROE）：$$ ROE = \frac{净利润}{股东权益} \times 100\% $$

import pandas as pd

def筛选成长股(财务数据):
    # 筛选净利润增长率大于15%的公司
   净利润增长率 = (财务数据['净利润'] - 财务数据['上年净利润']) / 财务数据['上年净利润'] * 100
    筛选条件1 = 净利润增长率 > 15

    # 筛选股东权益回报率大于20%的公司
    ROE = 财务数据['净利润'] / 财务数据['股东权益'] * 100
    筛选条件2 = ROE > 20

    # 同时满足两个条件的公司
    筛选结果 = 财务数据[筛选条件1 & 筛选条件2]
    return 筛选结果

# 示例数据
财务数据 = pd.DataFrame({
    '公司': ['A', 'B', 'C'],
    '净利润': [10, 15, 20],
    '上年净利润': [5, 10, 15],
    '股东权益': [50, 30, 40]
})

# 调用函数
筛选结果 = 筛选成长股(财务数据)
print(筛选结果)
