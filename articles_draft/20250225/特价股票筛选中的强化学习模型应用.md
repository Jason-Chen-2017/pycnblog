# 第1章: 特价股票筛选的背景与强化学习概述

## 1.1 特价股票的定义与特点

### 1.1.1 特价股票的定义
特价股票是指市场价格低于面值的股票，通常被视为具有潜在投资价值的标的。这类股票可能因市场波动、公司短期问题或投资者情绪影响而被低估。

### 1.1.2 特价股票的特点
- **低估性**：市场价格低于内在价值。
- **波动性**：价格波动较大，存在短期反弹机会。
- **周期性**：通常出现在市场低迷期或行业调整期。

### 1.1.3 特价股票的市场意义
- 投资者可以通过挖掘低估股票获得超额收益。
- 特价股票往往具有较高的反转潜力。

## 1.2 强化学习的基本概念

### 1.2.1 强化学习的定义
强化学习是一种机器学习范式，通过智能体与环境的交互，学习最优策略以最大化累积奖励。

### 1.2.2 强化学习的核心要素
- **状态 (State)**：智能体所处的环境信息。
- **动作 (Action)**：智能体采取的行为。
- **奖励 (Reward)**：智能体行为的反馈，用于指导学习方向。

### 1.2.3 强化学习与传统机器学习的区别
| 特性 | 监督学习 | 强化学习 |
|------|----------|----------|
| 数据来源 | 标签数据 | 奖励信号 |
| 目标 | 最小化预测误差 | 最大化累积奖励 |
| 交互性 | 非交互式 | 交互式 |

## 1.3 强化学习在金融领域的应用

### 1.3.1 金融领域的强化学习应用现状
- 股票交易策略优化
- 风险控制
- 市场预测

### 1.3.2 强化学习在股票筛选中的优势
- 能够处理非线性关系
- 能够适应市场动态变化
- 能够优化投资组合

# 第2章: 强化学习的核心概念与数学基础

## 2.1 强化学习的核心概念

### 2.1.1 状态、动作、奖励的定义
- **状态 (S)**：市场数据、财务指标等。
- **动作 (A)**：买入、卖出或持有。
- **奖励 (R)**：投资收益或损失。

### 2.1.2 策略与价值函数的关系
- **策略 (π)**：定义了动作的选择概率。
- **价值函数 (V)**：评估状态的期望收益。

### 2.1.3 探索与利用的平衡
- **探索**：尝试未尝试过的动作。
- **利用**：选择当前最优的动作。

## 2.2 强化学习的数学模型

### 2.2.1 状态转移概率矩阵
$$ P(s'|s, a) = \text{从状态 } s \text{ 采取动作 } a \text{ 后转移到状态 } s' \text{ 的概率} $$

### 2.2.2 Q值函数的定义与更新公式
- **Q值函数**：$ Q(s, a) = \max_{a'} Q(s', a') + R(s, a, s') $
- **更新公式**：$$ Q(s, a) = Q(s, a) + \alpha [R + \gamma \max Q(s', a') - Q(s, a)] $$

### 2.2.3 策略函数的数学表达
$$ \pi(a|s) = \arg \max_a Q(s, a) $$

## 2.3 强化学习的核心算法框架

### 2.3.1 Q-learning算法
```mermaid
graph TD
    A[开始] --> B[初始化Q表]
    B --> C[选择动作]
    C --> D[执行动作，观察新状态]
    D --> E[更新Q值]
    E --> F[结束或继续循环]
```

### 2.3.2 Deep Q-Network (DQN) 算法
```mermaid
graph TD
    A[开始] --> B[环境交互]
    B --> C[神经网络处理]
    C --> D[更新目标网络]
    D --> E[结束或继续循环]
```

### 2.3.3 策略梯度方法
- **策略梯度**：优化策略函数的梯度。
- **数学表达**：$$ \nabla \theta \leftarrow \nabla J(\theta) $$
