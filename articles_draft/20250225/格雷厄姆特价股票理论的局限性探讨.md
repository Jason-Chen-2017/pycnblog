## 第一部分: 格雷厄姆特价股票理论的背景与核心概念

### 第1章: 格雷厄姆特价股票理论的发展历程

#### 1.1 价值投资的起源与背景

- **价值投资的起源**：价值投资的概念起源于20世纪初，本杰明·格雷厄姆是该领域的先驱。他通过分析市场波动和投资者心理，提出了安全边际和内在价值的概念。
- **学术与实践经历**：格雷厄姆在哥伦比亚大学任教，培养了包括巴菲特在内的众多投资大师，其实践经验和理论研究为价值投资奠定了基础。
- **理论提出背景**：20世纪30年代的大萧条时期，格雷厄姆观察到市场的恐慌性和非理性，促使他提出了寻找廉价股票的策略。

#### 1.2 格雷厄姆的核心思想

- **安全边际**：安全边际是指股票的市场价格低于其内在价值的部分，确保投资的安全性。
- **内在价值计算**：通过分析公司基本面，如市盈率、市净率等指标，估算股票的真正价值。
- **市场先生理论**：投资者应忽视市场的短期波动，专注于长期价值。

#### 1.3 特价股票理论的实践基础

- **早期成功案例**：格雷厄姆的学生巴菲特在实践中取得了巨大成功，证明了价值投资的有效性。
- **理论的适用环境**：适用于市场波动较大、股票价格被低估的时期。

### 第2章: 格雷厄姆特价股票理论的核心观点

#### 2.1 价值投资的核心理念

- **安全边际**：通过购买价格远低于内在价值的股票，降低投资风险。
- **内在价值评估**：分析公司的财务状况、盈利能力，计算其真实价值。
- **市场非理性**：市场短期波动不可预测，投资者应关注长期价值。

#### 2.2 格雷厄姆筛选法的步骤与要点

- **第一步：筛选低估股票的标准**：市盈率低于行业平均水平，市净率低于历史平均水平。
- **第二步：财务指标分析**：关注ROE、ROA等指标，评估公司的盈利能力。
- **第三步：买入与卖出策略**：在价格低于内在价值时买入，高于时卖出。

#### 7.2 核心代码实现

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(revenue, profit_margin, discount_rate):
    # 计算自由现金流
    free_cash_flow = revenue * profit_margin
    # 计算终值
    terminal_value = free_cash_flow / (discount_rate - growth_rate)
    # 计算内在价值
    intrinsic_value = (free_cash_flow + terminal_value) / (discount_rate - growth_rate)
    return intrinsic_value

# 示例数据
revenue = 1000000
profit_margin = 0.1
discount_rate = 0.08
growth_rate = 0.05

iv = calculate_intrinsic_value(revenue, profit_margin, discount_rate)
print(f"内在价值: ${iv:.2f}")
```
