- **1.1.3 六类公司类型的概念提出**

## 第2章: 六类公司类型的核心概念与对比分析

### 2.1 六类公司类型的核心定义与特点

- **2.1.1 增长型公司（Growth Companies）**  
  特点：收入和利润持续增长，市盈率较高。  
  适用场景：经济繁荣期，适合长期投资。

- **2.1.2 稳定型公司（Stable Companies）**  
  特点：收入稳定，利润波动小，市盈率适中。  
  适用场景：经济波动期，适合稳健投资者。

- **2.1.3 停滞型公司（Stagnant Companies）**  
  特点：收入和利润增长停滞，市盈率较低。  
  适用场景：经济低迷期，需谨慎评估。

- **2.1.4 衰退型公司（Declining Companies）**  
  特点：收入和利润持续下降，市盈率低。  
  适用场景：需避免长期投资。

- **2.1.5 周期型公司（Cyclical Companies）**  
  特点：收入和利润受经济周期影响较大。  
  适用场景：周期性波动中，适合短期交易。

- **2.1.6 杠杆型公司（Leveraged Companies）**  
  特点：高负债，财务风险较高。  
  适用场景：经济上行期，收益可能更高，风险也更大。

### 5.2 数学模型与公式

#### 5.2.1 收入增长率公式

$$
\text{收入增长率} = \frac{\text{今年收入} - \text{去年收入}}{\text{去年收入}} \times 100\%
$$

#### 5.2.2 净利润增长率公式

$$
\text{净利润增长率} = \frac{\text{今年净利润} - \text{去年净利润}}{\text{去年净利润}} \times 100\%
$$

#### 5.2.3 市盈率公式

$$
\text{市盈率} = \frac{\text{股票价格}}{\text{每股净利润}}
$$

### 7.3 分类算法实现

```python
def classify_company(row):
    if row['收入增长率'] > 15 and row['净利润增长率'] > 15:
        return '增长型公司'
    elif row['收入增长率'] > 5 and row['净利润增长率'] > 5:
        return '稳定型公司'
    elif row['收入增长率'] < 5 and row['净利润增长率'] < 5:
        return '停滞型公司'
    elif row['收入增长率'] < -5 and row['净利润增长率'] < -5:
        return '衰退型公司'
    elif row['收入增长率'] > 10 and row['净利润增长率'] < 0:
        return '周期型公司'
    else:
        return '杠杆型公司'

data['公司类型'] = data.apply(classify_company, axis=1)
```
