# 第一部分：行业轮动与供应链重构的背景与概念

## 第1章：行业轮动的基本概念

### 1.1 行业轮动的定义与特点

行业轮动是指在不同的经济周期中，不同行业之间表现轮流上升的现象。其特点是周期性、轮动性、行业间差异性。行业轮动的核心在于识别经济周期变化中的行业趋势，从而优化投资组合。

### 1.2 供应链重构的背景与趋势

全球供应链重构是近年来全球经济的重大变革，主要由地缘政治风险、疫情冲击、技术进步等因素驱动。重构的目标是提高供应链的韧性和效率，降低风险。

### 1.3 行业轮动与供应链重构的关联

行业轮动与供应链重构密切相关。供应链重构会改变行业间的竞争格局，进而影响行业轮动的节奏和方向。例如，供应链本地化可能导致某些行业（如制造业）在特定地区轮动上升。

## 第2章：行业轮动与供应链重构的关联

### 2.1 行业轮动在供应链重构中的作用

行业轮动能够帮助投资者识别供应链重构中的机会。例如，当供应链从中国转移到东南亚时，东南亚的制造业和物流行业可能进入轮动上升阶段。

### 2.2 供应链重构对行业轮动的影响

供应链重构可能改变行业的周期性。例如，某些行业可能因为供应链重构而提前进入上升周期，而其他行业则可能因为供应链断裂而进入衰退周期。

### 3.1 彼得林奇的投资理念

### 3.2 彼得林奇行业轮动模型

彼得林奇的行业轮动模型基于经济周期分析。模型包括以下几个步骤：
1. 分析当前经济周期所处的阶段（复苏、过热、滞胀、衰退）。
2. 根据经济周期阶段，选择表现较好的行业。
3. 调整投资组合，增加轮动上升行业的权重。

## 第5章：行业轮动与供应链重构的数学模型

### 5.1 行业轮动指数的构建

行业轮动指数是衡量行业轮动强度的重要指标。公式如下：
$$
I = \sum_{i=1}^{n} w_i \cdot r_i
$$
其中，\( w_i \) 是行业权重，\( r_i \) 是行业收益。

### 5.2 供应链重构对行业轮动的影响模型

供应链重构对行业轮动的影响可以通过以下公式表示：
$$
R = \alpha \cdot S + \beta \cdot T
$$
其中，\( R \) 是行业轮动强度，\( S \) 是供应链重构强度，\( T \) 是时间因素。

### 7.2 系统核心实现源代码

以下是行业轮动指数计算的Python代码：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 示例数据
industry_returns = pd.DataFrame({
    '制造业': [0.1, 0.2, 0.15, 0.05, 0.1],
    '科技': [0.05, 0.1, 0.2, 0.15, 0.05],
    '物流': [0.15, 0.05, 0.2, 0.1, 0.15]
})

# 行业权重
weights = pd.Series([0.4, 0.3, 0.3], index=['制造业', '科技', '物流'])

# 计算行业轮动指数
def calculate_index(returns, weights):
    index = returns.dot(weights)
    return index

index = calculate_index(industry_returns, weights)
print("行业轮动指数：")
print(index)
```
