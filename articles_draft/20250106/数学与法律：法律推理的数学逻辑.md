### 3.3 数学模型和公式

- **概率计算公式**：$P(A|B) = \frac{P(A \cap B)}{P(B)}$
- **推理规则**：$A \rightarrow B, \neg B \rightarrow \neg A$

### 3.4 举例说明

假设有一件案件，证据显示被告有罪的几率为0.6，无罪的几率为0.4。根据概率计算公式，我们可以计算出被告有罪的条件下，证据成立的概率。

$$P(\text{证据成立}|\text{被告有罪}) = \frac{P(\text{证据成立} \cap \text{被告有罪})}{P(\text{被告有罪})} = \frac{0.6}{0.6 + 0.4} = \frac{3}{5}$$

## 四、数学模型和数学公式 & 详细讲解 & 举例说明

### 4.1 数学公式

$$
\begin{aligned}
P(A|B) &= \frac{P(A \cap B)}{P(B)} \\
P(A \cup B) &= P(A) + P(B) - P(A \cap B)
\end{aligned}
$$

### 4.2 详细讲解

- **条件概率**：$P(A|B)$ 表示在事件 $B$ 发生的条件下，事件 $A$ 发生的概率。
- **联合概率**：$P(A \cap B)$ 表示事件 $A$ 和事件 $B$ 同时发生的概率。

### 4.3 举例说明

假设有两个事件 $A$ 和 $B$，其中 $P(A) = 0.4$，$P(B) = 0.3$，$P(A \cap B) = 0.2$。

- **条件概率**：$P(B|A) = \frac{P(A \cap B)}{P(A)} = \frac{0.2}{0.4} = 0.5$
- **联合概率**：$P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.4 + 0.3 - 0.2 = 0.5$

### 6.2 系统核心实现源代码

以下是系统核心实现的源代码：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

def calculate_probability(evidence, case_data):
    # 计算证据的概率
    probability = np.mean(evidence)
    return probability

def judge_case(evidence, case_data):
    # 判断案件是否成立
    probability = calculate_probability(evidence, case_data)
    if probability > 0.5:
        return "成立"
    else:
        return "不成立"

def main():
    case_data = np.array([0.3, 0.4, 0.5])
    evidence = np.array([0.6, 0.4, 0.3])
    result = judge_case(evidence, case_data)
    print(result)

if __name__ == "__main__":
    main()
```

### 6.4 实际案例分析和详细讲解剖析
