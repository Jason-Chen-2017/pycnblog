## 第2章 未解之谜一：费马大定理

### 2.1 费马大定理的背景

费马大定理，也称为费马的最后定理，是由法国数学家皮埃尔·费马在17世纪提出的一个著名数学问题。该定理表明，对于任何大于2的自然数n，方程\(a^n + b^n = c^n\)没有正整数解。

### 2.3 解决费马大定理的方法

费马大定理在提出后，吸引了无数数学家的关注。最终，英国数学家安德鲁·怀尔斯在1995年证明了费马大定理。他的证明方法结合了多种数学工具，包括椭圆曲线和模形式等。

## 第3章 未解之谜二：哥德巴赫猜想

### 3.1 哥德巴赫猜想的背景

哥德巴赫猜想是另一个著名的数学问题，由俄国数学家哥德巴赫在1742年提出。该猜想表明，任何大于2的偶数都可以表示为两个素数之和。

### 3.2 哥德巴赫猜想的数学模型

为了解释哥德巴赫猜想，我们可以使用Mermaid绘制一个数学模型图：


在这个模型中，n表示大于2的偶数，p和q表示素数。

### 3.3 哥德巴赫猜想的证明尝试

尽管哥德巴赫猜想已经提出了数百年，但至今仍未被证明。数学家们尝试了各种方法，包括直接的构造法、反证法、概率方法等，但都未能成功。

### 4.3 Python代码示例

下面是解决哥德巴赫猜想的一个Python代码示例：

```python
def is_prime(num):
    if num < 2:
        return False
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False
    return True

def find_prime_sum(n):
    for p in range(2, n):
        if is_prime(p) and is_prime(n - p):
            return p, n - p
    return None

n = 100
solution = find_prime_sum(n)
if solution:
    print(f"{n} can be expressed as {solution[0]} + {solution[1]}")
else:
    print(f"{n} cannot be expressed as the sum of two primes.")
```

在这个代码中，我们首先定义了一个判断素数的函数`is_prime`，然后定义了一个寻找两个素数和的函数`find_prime_sum`。最后，我们输入一个偶数100，尝试将其分解为两个素数之和。

## 第5章 未解之谜三：庞加莱猜想

### 5.1 庞加莱猜想的背景

庞加莱猜想是19世纪末由法国数学家亨利·庞加莱提出的一个关于三维球面的问题。该猜想表明，任何有限单连通的三维球面都是同胚于三维空间中的三维球面。

### 5.2 庞加莱猜想的数学模型

为了解释庞加莱猜想，我们可以使用Mermaid绘制一个数学模型图：

```mermaid

A[三维球面M] --> B[同胚映射f]
B --> C[三维空间N]
```

在这个模型中，M表示三维球面，N表示三维空间，f表示从M到N的同胚映射。

### 5.3 庞加莱猜想的证明

庞加莱猜想在数学界引起了广泛关注。最终，美国数学家理查德·舍尔平斯基和俄罗斯数学家格里戈里·佩雷尔曼分别提出了证明。他们的证明方法涉及到偏微分方程、拓扑学和几何测度论等多个数学领域。
