### 第一部分：和声理论概述

#### 第1章：音乐创作与和声理论的基础

##### 1.1 音乐创作的基本概念

音乐创作是人类艺术创作的一个重要领域，它涉及到旋律、和声、节奏等多个方面。旋律是音乐的核心，它是由一系列有组织的音高变化构成的。而和声则是旋律的伴奏，通过不同的音程和和弦来丰富旋律的听觉效果。

##### 1.2 和声理论的基本概念

和声理论是音乐理论的一个重要分支，它研究音乐中的声音组合和声音之间的关系。核心概念包括音阶、和弦、和声功能等。音阶是音乐中音高的排列方式，而和弦则是三个或更多音符的组合。和声功能则是指和弦在音乐中的作用，例如主和弦、副和弦等。

##### 1.3 和声与旋律的关系

和声与旋律是密不可分的。和声可以为旋律提供伴奏，增强旋律的听觉效果。同时，旋律也可以通过和声的变化来增加音乐的表现力。例如，在一个简单的旋律中，通过添加和弦，可以使旋律变得更加丰富和有层次。

### 第二部分：核心概念与联系

#### 第2章：核心概念与联系

##### 2.1 音阶与音程

音阶是音乐中音高的基本排列方式，它由一系列等距的音高构成。而音程则是两个音高之间的距离。了解音阶和音程的关系对于理解和声理论至关重要。

##### 2.2 和弦与和声功能

和弦是音乐中三个或更多音符的组合，它是和声理论的核心。和声功能则是指和弦在音乐中的作用，例如主和弦、副和弦等。和弦的功能可以通过和声功能表来理解。

# 定义和弦生成函数
def generate_chord(tonic, scale):
    chord = []
    for i in range(len(scale)):
        if i == 0:
            chord.append(scales[i])
        else:
            interval = intervals[i - 1]
            if interval == 'P1':
                chord.append(scales[i])
            else:
                chord.append(scales[(i + 12 - intervals.index(interval)) % 12])
    return chord
