## 4. 核心算法原理讲解

简约主义摄影的核心算法主要涉及图像处理技术，如滤波、色调调整、对比度增强等。以下是一个简单的 Python 代码示例，展示了如何使用 OpenCV 库实现这些算法：

```python
import cv2

def minimalist_filter(image):
    # 滤波
    filtered_image = cv2.GaussianBlur(image, (5, 5), 0)

    # 色调调整
    hsv_image = cv2.cvtColor(filtered_image, cv2.COLOR_BGR2HSV)
    hsv_image[..., 1] = cv2.add(hsv_image[..., 1], 50)  # 增强饱和度
    hsv_image[..., 2] = cv2.add(hsv_image[..., 2], 50)  # 增强亮度
    color_image = cv2.cvtColor(hsv_image, cv2.COLOR_HSV2BGR)

    # 对比度增强
    alpha = 1.5
    beta = -50
    contrast_enhanced_image = cv2.convertScaleAbs(color_image, alpha=alpha, beta=beta)

    return contrast_enhanced_image

image = cv2.imread('input_image.jpg')
result = minimalist_filter(image)
cv2.imshow('Minimalist Image', result)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

def minimalist_filter(image):

    filtered_image = cv2.GaussianBlur(image, (5, 5), 0)

    # 色调调整
    hsv_image = cv2.cvtColor(filtered_image, cv2.COLOR_BGR2HSV)
