### 3.2 教学方法与评估

教学方法与评估是教学实践的关键。以下是一个教学方法的Python代码示例：

```python
def teaching_method(student, subject):
    # 根据学生特点选择教学方法
    if student['ability'] == 'high':
        method = '探究式教学'
    elif student['interest'] == 'high':
        method = '游戏化教学'
    else:
        method = '传统教学'

    # 教学方法实施
    print(f"对学生{student['name']}实施{method}教学。")

    # 教学评估
    score = student['knowledge'] + student['skills']
    print(f"学生{student['name']}的教学评估得分为：{score}。")

# 示例数据
student = {'name': '张三', 'ability': 'high', 'interest': 'high', 'knowledge': 80, 'skills': 85}

# 执行教学方法和评估
teaching_method(student, '数学')
```
