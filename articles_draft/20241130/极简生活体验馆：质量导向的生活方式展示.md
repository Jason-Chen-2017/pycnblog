## 极简生活体验馆的设计原则
### 空间布局
极简生活体验馆的空间布局应该简洁明了，避免过多的装饰和杂乱。空间布局的设计要考虑到参观者的流动路线，使他们能够轻松地浏览和体验各种展示内容。

### 源代码实现
```python
import matplotlib.pyplot as plt
import numpy as np

# 定义函数，计算质心
def calculate_center_of_mass(points):
    num_points = len(points)
    sum_x = sum(points[:, 0])
    sum_y = sum(points[:, 1])
    center_of_mass = (sum_x / num_points, sum_y / num_points)
    return center_of_mass

# 生成数据点
data = np.random.rand(100, 2)

# 计算质心
center = calculate_center_of_mass(data)

# 绘制数据点和质心
plt.scatter(data[:, 0], data[:, 1], label='Data Points')
plt.scatter(center[0], center[1], color='red', label='Center of Mass')
plt.xlabel('X')
plt.ylabel('Y')
plt.legend()
plt.show()
```

### 代码解读
- `calculate_center_of_mass` 函数用于计算给定数据点的质心。
- `data` 变量用于生成随机数据点。
- `center` 变量用于存储计算出的质心。
- `plt.scatter` 函数用于绘制数据点和质心。
