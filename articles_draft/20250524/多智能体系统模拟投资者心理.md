### 1.1 问题背景

- 定义：由多个相互作用的智能体组成的系统。
- 特性：分布式、自治性、反应性、协作性。

#### 1.2.2 投资者心理模型
- 层次结构：认知层、情感层、决策层。
- 核心属性：风险偏好、情绪波动、信息处理能力。

```python
class Agent:
    def __init__(self, id, emotion_factor=0.5):
        self.id = id
        self.emotion_factor = emotion_factor
        self.risk_tolerance = 0.1
    
    def decide(self, market_data):
        # 基于情绪和数据的决策
        if market_data['return'] > self.risk_tolerance:
            return 'buy'
        elif market_data['return'] < -self.risk_tolerance:
            return 'sell'
        else:
            return 'hold'
```

#### 4.2.2 系统运行
```python
class MarketSimulator:
    def __init__(self, agents):
        self.agents = agents
        self.prices = [100]  # 初始价格
    
    def step(self):
        # 计算新价格
        demand = sum(1 for a in self.agents if a.decide(self.prices[-1]) == 'buy')
        supply = sum(1 for a in self.agents if a.decide(self.prices[-1]) == 'sell')
        new_price = self.prices[-1] + (demand - supply) * 0.1
        self.prices.append(new_price)
```
