## 引言

### 1.1 投资组合再平衡的定义与重要性

投资组合再平衡是指定期调整投资组合的资产配置，以维持目标风险水平或资产权重的过程。这种策略通过动态调整资产比例，确保投资组合的表现与预设目标一致。

**重要性**：
- **风险控制**：避免单一资产权重过大，分散风险。
- **收益优化**：通过定期调整，捕捉市场机会，提高收益潜力。
- **长期稳健**：适应市场变化，保持投资组合的长期稳定性。

### 1.2 约翰·伯格的投资理念

约翰·伯格是指数基金之父，倡导长期投资和分散投资。他认为再平衡是维持投资组合健康的重要手段，通过定期调整，确保资产配置与风险目标一致。

## 理论基础

### 2.1 现代投资组合理论

**马科维茨的有效前沿**：投资者在给定风险下追求最大收益，或在给定收益下最小化风险。

**公式**：
$$
\text{投资组合的方差} = \sum_{i=1}^{n} \sum_{j=1}^{n} w_i w_j \sigma_i \sigma_j \rho_{ij}
$$

### 2.2 资产配置与风险控制

**资产配置分类**：
- **股票、债券、现金**：不同类型资产的风险和收益不同。

**风险水平量化**：
- 使用波动率或VaR（在险价值）衡量风险。

### 2.3 数学模型

**投资组合优化公式**：
$$
\text{最大化 } \mu^T w - \lambda w^T \Sigma w
$$

**约束条件**：
$$
\sum_{i=1}^{n} w_i = 1 \\
w_i \geq 0
$$

## 方法论

### 3.1 定期再平衡策略

**触发条件**：
- 时间驱动：定期调整，如季度或半年。
- 阈值驱动：资产权重偏离目标比例一定幅度时调整。

### 3.2 动态再平衡策略

**动态调整**：
- 根据市场变化实时调整，保持目标权重。

### 3.3 目标日期策略

**特点**：
- 随着目标日期临近，逐步增加保守资产比例。

### 3.4 量化方法

**算法步骤**：
1. 计算当前资产权重。
2. 与目标权重对比。
3. 调整权重至目标范围。

## 实战案例

### 4.1 伯格的经典案例

**指数基金再平衡**：
- 每年调整一次，保持股票和债券比例稳定。

### 4.2 不同市场条件下的应用

**熊市**：
- 增加防御性资产，降低波动性。

### 6.2 Python实现

**代码示例**：
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_variance(weights, covariance_matrix):
    return weights.T @ covariance_matrix @ weights

def rebalance(weights, target_weights, covariance_matrix):
    return minimize(portfolio_variance, weights, args=covariance_matrix, 
                   method='SLSQP', bounds=[(0,1)]*len(weights))

# 示例数据
covariance_matrix = np.array([[0.05, 0.02], [0.02, 0.03]])
weights_initial = np.array([0.6, 0.4])
target_weights = np.array([0.5, 0.5])

result = rebalance(weights_initial, target_weights, covariance_matrix)
print(result.x)
```
