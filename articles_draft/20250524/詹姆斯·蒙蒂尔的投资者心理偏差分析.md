## 第1章: 背景介绍

### 1.1 心理偏差的基本概念
心理偏差是人类在决策过程中由于认知局限或情感因素导致的非理性行为。在投资领域，心理偏差直接影响投资者的决策，可能导致错误的投资选择和市场波动。

### 1.2 心理偏差在金融领域的重要性
投资者心理偏差是行为金融学的核心研究对象。行为金融学认为，市场参与者的非理性行为会导致资产价格偏离其内在价值。

### 1.3 詹姆斯·蒙蒂尔的研究贡献
詹姆斯·蒙蒂尔是行为金融学领域的权威学者，其研究揭示了投资者心理偏差的复杂性及其对金融市场的影响。

### 2.1 确认偏差与损失厌恶的对比分析
| 偏差类型 | 定义 | 表现形式 | 对投资的影响 |
|----------|------|----------|--------------|

### 3.2 Python代码实现
```python
def quantify_bias(data):
    import pandas as pd
    df = pd.DataFrame(data)
    # 确认偏差计算
    confirm_bias = df['confirm'].mean()
    # 损失厌恶计算
    loss_aversion = df['loss'].mean()
    return confirm_bias, loss_aversion

# 示例数据
data = {
    'confirm': [0.8, 0.6, 0.7],
    'loss': [0.9, 0.8, 0.7]
}
quantify_bias(data)
```

## 第4章: 数学模型与公式

### 4.1 前景理论公式
$$ V(P) = \alpha \cdot P + \beta \cdot \ln(P) $$

其中：
- \( V(P) \) 表示投资者对收益的效用函数。
- \( \alpha \) 和 \( \beta \) 是参数。

### 4.2 应用实例
假设一个投资者面临两种选择：
1. 确定收益 $100。
2. 50%概率收益 $200，50%概率收益 $0。

根据前景理论，投资者更倾向于选择确定收益。
