```python
import pandas as pd
import numpy as np

# 示例数据：假设我们从Yahoo Finance获取数据
def get_data(ticker):
    # 这里需要实现实际的数据获取逻辑
    return pd.DataFrame({'price': [100], 'book_value': [50]}, index=[ticker])

# 获取股票数据
tickers = ['AAPL', 'MSFT', 'GOOGL']
df = pd.DataFrame()
for t in tickers:
    data = get_data(t)
    df = df.append(data)
```

##### 6.2.2 计算市净率并筛选
```python
# 计算市净率
df['PB'] = df['price'] / df['book_value']

# 筛选PB < 1的股票
low_pb_stocks = df[df['PB'] < 1]
print(low_pb_stocks)
```
