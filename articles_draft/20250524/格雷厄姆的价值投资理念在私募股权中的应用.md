# 第1章 格雷厄姆价值投资理念概述

## 1.1 价值投资的定义与核心理念

### 背景介绍
- **价值投资**：一种以基本面分析为基础的投资策略，强调以低于内在价值的价格购买优质资产。
- **格雷厄姆的贡献**：提出“安全边际”和“内在价值”等核心概念，为价值投资奠定了理论基础。

### 核心概念与联系
- **安全边际**：购买价格低于内在价值的差额，提供风险缓冲。
- **内在价值**：资产在未来现金流的现值，计算公式为：
  $$ \text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}}{(1 + r)^t} $$
  其中，r为折现率，n为现金流期限。

# 第2章 私募股权的特点与运作机制

## 2.1 私募股权的基本概念

### 背景介绍
- **私募股权**：对未上市公司部分或全部股权的投资，通常通过杠杆收购、管理层收购等方式进行。
- **运作机制**：私募基金通过收购、重组、增值后出售实现收益。

### 核心概念与联系
- **私募股权的三阶段模型**：
  1. **收购阶段**：评估目标公司，进行尽职调查。
  2. **持有阶段**：优化管理，提升价值。
  3. **退出阶段**：通过IPO或出售实现收益。

def calculate_intrinsic_value(df):
    # 简单示例，实际应根据具体模型计算
    average_cash_flow = df['现金流'].mean()
