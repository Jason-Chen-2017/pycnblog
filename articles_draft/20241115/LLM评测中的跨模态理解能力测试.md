### LLM工作原理

LLM（Large Language Model）是一种基于神经网络的深度学习模型，主要用于处理和生成自然语言。LLM的核心组件包括：

1. **嵌入层（Embedding Layer）**：将单词、句子等文本转换为固定长度的向量表示。
2. **编码器（Encoder）**：采用堆叠的多层神经网络，对输入文本进行编码。
3. **注意力机制（Attention Mechanism）**：在编码过程中，对文本的不同部分进行加权，提高模型的上下文理解能力。
4. **解码器（Decoder）**：生成文本序列，对编码器的输出进行解码。

```mermaid

    A[Input Word]
    A --> B[Embedding Layer]
    B --> C[Encoder]
    C --> D[Attention Layer]
    D --> E[Decoder]
    E --> F[Output Word]
```

### 评测方法

在评测LLM性能时，常用的指标包括：

1. **准确率（Accuracy）**：预测正确的样本数占总样本数的比例。
2. **召回率（Recall）**：预测正确的正类样本数占总正类样本数的比例。
3. **精确率（Precision）**：预测正确的正类样本数占总预测正类样本数的比例。
4. **F1值（F1 Score）**：精确率和召回率的调和平均。
