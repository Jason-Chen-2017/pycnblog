#### 5.2 核心代码实现
```python
import numpy as np
from scipy.optimize import minimize

def objective_function(x):
    return np.sum(x**2)

def constraint_function(x):
    return np.sum(x) - 1

x0 = np.array([1, 1])
result = minimize(objective_function, x0, constraints={'type': 'eq', 'fun': constraint_function})
print(result.x)
```
