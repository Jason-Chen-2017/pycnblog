# 第一部分: 全球化与去全球化的背景与核心概念

## 第1章: 全球化与去全球化的定义与特征

### 1.1 全球化的定义与特征
- 全球化的定义：全球化是指经济、政治、文化等领域的国际化和一体化过程，表现为跨国公司的扩张、国际贸易的增加和资本的自由流动。
- 全球化的核心特征：
  - 经济一体化：跨国贸易、投资和生产活动的增加。
  - 文化多样性：全球文化交流和融合。
  - 技术共享：技术标准和知识的跨国传播。

### 1.2 去全球化的定义与特征
- 去全球化的定义：去全球化是指经济、政治等领域从全球化中撤出，强调本土化、保护主义和自我依赖。
- 去全球化的核心特征：
  - 经济保护主义：增加关税、限制外国投资。
  - 地缘政治冲突：贸易摩擦、供应链本地化。

## 第2章: 全球化与去全球化的主要驱动因素

### 2.1 经济驱动因素
- 全球化下的经济一体化：跨国公司、自由贸易协定的增加。
- 去全球化下的经济保护主义：贸易壁垒、本地供应链的构建。

### 2.2 政治驱动因素
- 全球化下的国际合作：国际组织、多边贸易协定的推动。
- 去全球化下的地缘政治冲突：主权保护、资源争夺。

### 2.3 技术驱动因素
- 全球化下的技术创新：技术标准的统一、共享。
- 去全球化下的技术壁垒：自主研发、技术保护。

## 第3章: 全球化与去全球化对投资的影响

### 3.1 全球化对投资的影响
- 投资机会：跨国投资、新兴市场增长。
- 投资风险：全球经济波动、地缘政治风险。

### 3.2 去全球化对投资的影响
- 投资机会：本地市场增长、供应链重构。
- 投资风险：政策不确定性、贸易摩擦。

## 第4章: 全球化与去全球化的相互关系

### 4.1 全球化与去全球化的矛盾与冲突
- 经济全球化与去全球化的矛盾：自由流动与保护主义的冲突。
- 地缘政治与去全球化的冲突：国际合作与主权保护的对立。

### 4.2 全球化与去全球化的平衡与协调
- 经济全球化与去全球化的平衡：合理配置本地化与全球化战略。
- 地缘政治与去全球化的协调：通过国际合作缓解冲突。

import pandas as pd
import numpy as np

# 示例代码：计算投资组合的最优配置
def compute_portfolio_optimization(returns):
    # 计算协方差矩阵
    cov_matrix = returns.cov()
    # 计算最优权重
    weights = np.linalg.inv(cov_matrix).sum()
    weights /= weights.sum()
    return weights

# 示例数据：假设 returns 是一个包含资产收益率的 DataFrame
returns = pd.read_csv('asset_returns.csv')
weights = compute_portfolio_optimization(returns)
print(weights)
