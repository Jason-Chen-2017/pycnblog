## 第2章 核心概念与联系

### 2.1 核心概念原理

#### 2.1.1 因果图的基本概念
因果图（Directed Acyclic Graph, DAG）是一种有向无环图，用于表示变量之间的因果关系。例如，因果图可以表示为：
$$P(Y|do(X), Z)$$

#### 2.1.2 潜在结果与DO算子
潜在结果是指在不同干预条件下变量的可能结果。DO算子（do operator）用于模拟干预操作，例如：
$$Y^x = f(x, Z)$$

#### 2.1.3 干预与反事实推理的数学模型
干预效果可以通过反事实推理进行评估，公式为：
$$P(Y=y | do(X=x), Z=z)$$

### 2.2 核心概念属性特征对比

#### 2.2.1 因果图与相关图的区别
- **因果图**：表示变量间的因果关系，有向边表示因果影响。
- **相关图**：仅表示变量间的相关性，无向边表示相关关系。

#### 2.2.2 潜在结果与观测结果的对比
- **潜在结果**：假设在干预条件下变量的可能结果。
- **观测结果**：实际观测到的变量值。

#### 2.2.3 DO算子与反事实推理的联系
- DO算子用于模拟干预，反事实推理用于评估干预效果。

```python
import networkx as nx

def build_causal_graph(edges):
    graph = nx.DiGraph()
    for edge in edges:
        graph.add_edge(edge[0], edge[1])
    return graph
```

#### 5.2.2 应用DO算子
```python
def apply_do_operator(graph, treatment):
    intervened_graph = graph.copy()
    for node in graph.nodes():
        if node == treatment:
            intervened_graph.remove_edges_from([ (treatment, neighbor) for neighbor in graph[treatment] ])
    return intervened_graph
```
