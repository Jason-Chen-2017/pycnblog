#### 源代码详细实现

以下是一个简单的手账应用，主要包含添加任务、查看任务、完成任务的三个功能。

```python
class TaskManager:
    def __init__(self):
        self.tasks = []

    def add_task(self, task):
        self.tasks.append(task)
        print("任务添加成功：", task)

    def view_tasks(self):
        print("当前任务列表：")
        for task in self.tasks:
            print(task)

    def complete_task(self, task):
        if task in self.tasks:
            self.tasks.remove(task)
            print("任务完成：", task)
        else:
            print("任务不存在：", task)

# 实例化对象
task_manager = TaskManager()

# 添加任务
task_manager.add_task("购买牛奶")
task_manager.add_task("打扫房间")

# 查看任务
task_manager.view_tasks()

# 完成任务
task_manager.complete_task("购买牛奶")

# 再次查看任务
task_manager.view_tasks()
```

#### 代码解读与分析

1. **类定义**：定义一个`TaskManager`类，用于管理任务。
2. **添加任务**：通过`add_task`方法，将任务添加到任务列表。
3. **查看任务**：通过`view_tasks`方法，输出任务列表。
4. **完成任务**：通过`complete_task`方法，将完成的任务从任务列表中移除。
