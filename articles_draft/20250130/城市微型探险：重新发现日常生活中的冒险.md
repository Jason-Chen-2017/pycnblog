### 数学公式与Python代码

在探险活动中，我们可能会遇到一些需要计算的情景，如测量距离、计算时间等。以下是一个简单的Python代码示例，用于计算两个地点之间的距离：

```python
import math

# 经度和纬度
lat1, lon1 = 39.9042, 116.4074  # 北京天安门
lat2, lon2 = 31.2304, 121.4737  # 上海外滩

# 地球半径（单位：千米）
R = 6371.0

# 计算两点之间的距离
d = 2 * R * math.asin(math.sqrt(math.sin((lat2 - lat1) * math.pi / 360) * math.sin((lat2 - lat1) * math.pi / 360) + math.cos(lat1 * math.pi / 180) * math.cos(lat2 * math.pi / 180) * math.sin((lon2 - lon1) * math.pi / 360) * math.sin((lon2 - lon1) * math.pi / 360)))
print(f"北京天安门与上海外滩之间的距离为：{d}千米")

```
