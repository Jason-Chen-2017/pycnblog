# 数字化转型对估值的影响

## 4.1 数字化转型如何影响估值

### 4.1.1 技术应用的影响

- 数字化转型通过提升效率和用户体验，增加企业价值。

### 4.1.2 数学模型构建

构建回归模型分析数字化转型对估值的影响：

```python
import statsmodels.api as sm

x = sm.add_constant([1,2,3])
y = [5,6,7]

model = sm.OLS(y, x)
results = model.fit()

print(results.summary())
```

## 5.1 互动机制

### 5.1.1 双向影响路径

- 估值差异影响投资，投资影响数字化转型，反过来，转型又影响估值。

### 5.1.2 数学模型

构建动态平衡模型：

$$ V = aD + bT + c $$

其中，V为估值，D为数字化程度，T为转型投入。
