## 第3章: 算法原理与数学模型

### 3.1 股市估值算法原理

#### 3.1.1 移动平均线（MA）算法

- **基本原理**: 移动平均线通过计算一定时期内的平均价格，反映市场趋势。
- **算法流程图**

```mermaid
graph TD
    Start --> ComputeAverage
    ComputeAverage --> OutputMA
    OutputMA --> End
```

- **数学公式**

  $$ MA_t = \frac{1}{n} \sum_{i=t-n+1}^{t} P_i $$

  其中，\( P_i \) 表示第 \( i \) 天的价格，\( n \) 表示窗口大小。

#### 3.1.2 算法实现与代码示例

- **Python代码实现**

```python
def moving_average(prices, window_size):
    ma = []
    for i in range(len(prices)):
        if i >= window_size - 1:
            ma_val = sum(prices[i - window_size + 1:i + 1]) / window_size
            ma.append(ma_val)
        else:
            ma.append(0)
    return ma
```
