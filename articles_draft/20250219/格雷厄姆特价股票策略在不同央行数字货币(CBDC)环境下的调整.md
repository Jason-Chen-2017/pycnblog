## 第1章: 格雷厄姆投资理论的核心原则

### 1.1 价值投资的基本概念
价值投资是一种以基本面分析为基础的投资策略，旨在通过寻找市场价格低于内在价值的证券进行投资。其核心理念是“买入便宜的东西”，即寻找市场估值低于其实际价值的资产。

- **内在价值**：资产的真实价值，通常通过财务指标（如市盈率、市净率、股息率等）进行评估。
- **市场价格**：资产在市场上的交易价格，可能受到情绪、市场波动等因素的影响。

### 1.2 格雷厄姆的选股标准
格雷厄姆提出了以下几个核心选股标准：
1. **安全边际**：买入价格低于内在价值，确保有一定的安全空间。
2. **低市盈率**：选择市盈率低于市场平均水平的股票。
3. **低市净率**：市净率低于行业平均水平。
4. **股息率**：股息率稳定且合理。

### 1.3 央行数字货币的基本概念
央行数字货币（CBDC）是由中央银行发行的数字货币，具有以下几个核心特点：
1. **法定货币地位**：CBDC由国家信用背书，具有法偿性。
2. **数字化**：基于区块链等技术，实现数字化交易。
3. **可编程性**：支持智能合约，可以实现自动化的金融交易。

### 1.4 CBDC与传统货币的主要区别
| 特性       | 传统货币          | CBDC             |
|------------|-------------------|------------------|
| 发行机构   | 中央银行           | 中央银行           |
| 存在形式   | 实体货币（纸币、硬币） | 数字货币             |
| 交易效率   | 低效               | 高效               |
| 跟踪性     | 低                 | 高                 |
| 反洗钱     | 依赖金融机构记录    | 更容易追踪           |

### 1.5 格雷厄姆策略与CBDC的结合
格雷厄姆策略的核心是寻找低估的资产，而CBDC的引入可能会改变市场的估值逻辑。例如，CBDC可能导致市场流动性增加，从而影响股票的估值。
