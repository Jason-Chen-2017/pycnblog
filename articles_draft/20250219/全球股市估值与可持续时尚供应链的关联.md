# 第二部分：全球股市估值与可持续时尚供应链的核心概念

## 第2章：全球股市估值的理论基础

### 2.1 股市估值的基本原理

#### 2.1.1 股价与公司价值的关系

股价是市场对公司价值的反映，受多种因素影响，包括财务表现、行业地位、市场前景等。

#### 2.1.2 市盈率、市净率等核心指标的计算公式

市盈率（P/E）= 股价 / 每股收益；市净率（P/B）= 股价 / 每股净资产。

#### 2.1.3 影响股市估值的主要因素

包括宏观经济、行业环境、公司基本面、市场情绪等。

### 2.2 经济学视角下的股市估值模型

#### 2.2.1 CAPM模型

CAPM模型用于确定资产的预期收益，公式为：$R_i = R_f + β_i (R_m - R_f)$，其中$R_f$是无风险利率，$R_m$是市场预期收益率，$β_i$是资产的贝塔系数。

#### 2.2.2 WACC模型

WACC（加权平均成本资本）用于评估企业资本成本，公式为：$WACC = w_d \times k_d \times (1 - t) + w_l \times k_l + w_e \times k_e$，其中$w_d$是债务权重，$k_d$是债务成本，$t$是税率，$w_l$是杠杆权重，$k_l$是杠杆成本，$w_e$是股权权重，$k_e$是股权成本。

### 9.2 核心实现

```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('stock_data.csv')

# ESG评分计算
def calculate_esg_score(row):
    return row['环境'] * 0.4 + row['社会'] * 0.3 + row['治理'] * 0.3

data['ESG评分'] = data.apply(calculate_esg_score, axis=1)

# 回归分析
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(data[['ESG评分']], data['股价'])
r_squared = model.score(data[['ESG评分']], data['股价'])
print(f"R² = {r_squared}")
```
