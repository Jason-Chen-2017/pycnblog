## 第1章：股市估值与企业治理概述

### 1.1 股市估值的基本概念

#### 1.1.1 股市估值的定义
股市估值是指通过对企业的财务状况、市场地位、盈利能力等多方面因素的分析，对其在股票市场上的价值进行评估的过程。常用的估值方法包括市盈率（P/E）、市净率（P/B）和 enterprise value（EV）等。

#### 1.1.2 股市估值的核心指标
- **市盈率（P/E）**：企业股价与每股收益的比率，反映市场对企业盈利能力的预期。
- **市净率（P/B）**：企业股价与每股净资产的比率，适用于评估资产密集型行业。
- **EV（企业价值）**：考虑企业债务和现金储备的全面估值指标。

#### 1.1.3 股市估值对企业治理的影响
股市估值不仅是企业市场价值的体现，还影响着企业的战略决策、管理层激励和资本运作。高估值企业通常面临更高的市场期待，而低估值企业则可能面临资产重组的压力。

def calculate_stock_valuation(company_data):
    # 计算市盈率
    pe_ratio = company_data['股价'] / company_data['每股收益']
    # 计算市净率
    pb_ratio = company_data['股价'] / company_data['每股净资产']
    # 计算企业价值
    ev = company_data['企业价值'] = company_data['企业市值'] + company_data['债务'] - company_data['现金储备']
    return {
        '市盈率': pe_ratio,
        '市净率': pb_ratio,
        '企业价值': ev
    }

# 示例数据
company_data = {
    '股价': 100,
    '每股收益': 20,
    '每股净资产': 25,
    '企业市值': 500,
    '债务': 100,
    '现金储备': 50
}

valuation = calculate_stock_valuation(company_data)
print(valuation)
