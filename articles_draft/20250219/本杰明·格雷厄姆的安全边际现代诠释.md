## 第一部分：安全边际的基本概念

### 第1章：安全边际的定义与背景

#### 1.1 安全边际的核心概念
- **1.1.1 安全边际的定义**  
  安全边际是资产的内在价值与其市场价格之间的差额，表示投资者在价格波动中能够承受的最大损失。

- **1.1.2 安全边际的历史背景**  
  格雷厄姆在20世纪初提出安全边际，强调在市场波动中保护资本的重要性。

- **1.1.3 安全边际在投资中的作用**  
  通过安全边际，投资者可以避免支付过高的价格，降低投资风险。

#### 1.2 安全边际的数学模型
- **1.2.1 安全边际的计算公式**  
  $$\text{安全边际} = \text{内在价值} - \text{市场价格}$$  
  内在价值是资产的真实价值，市场价格是当前市价。

- **1.2.2 安全边际与投资风险的关系**  
  安全边际越大，投资风险越低，反之亦然。

#### 1.3 安全边际的现代应用
- **1.3.1 现代投资环境中的安全边际**  
  在当前市场中，安全边际的计算需要考虑通货膨胀、利率变化等因素。

- **1.3.2 技术进步对安全边际的影响**  
  数据分析和算法的进步使安全边际的计算更加精确和高效。

## 第二部分：安全边际的核心概念与联系

### 第2章：安全边际的数学模型与公式

#### 2.1 安全边际的数学模型
- **2.1.1 基于价值的安全边际计算**  
  $$\text{内在价值} = \frac{\text{年收益}}{\text{预期收益率}}$$  
  例如，年收益为100，预期收益率为10%，则内在价值为100/0.1=1000。

- **2.1.2 基于价格的安全边际计算**  
  $$\text{安全边际} = \text{内在价值} - \text{市场价格}$$  
  如果市场价格为800，内在价值为1000，则安全边际为200。

| 时间因素      | 长期     | 短期     | 短期     |

## 第三部分：算法原理讲解

### 第3章：安全边际算法的实现

#### 3.1 算法原理
- **步骤1：计算内在价值**  
  基于现金流折现法（DCF）计算资产的内在价值。

- **步骤2：确定市场价格**  
  获取资产当前市场价格。

- **步骤3：计算安全边际**  
  $$\text{安全边际} = \text{内在价值} - \text{市场价格}$$

#### 3.2 Python源代码实现
```python
def calculate_margin(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例计算
iv = 1000
mp = 800
margin = calculate_margin(iv, mp)
print(f"安全边际为: {margin}")
```

#### 5.2 核心代码实现

```python
import pandas as pd

def calculate_margin(iv, mp):
    return iv - mp

# 示例数据
data = {'资产': ['资产A', '资产B'], 
        '年收益': [100, 150], 
        '预期收益率': [0.1, 0.12]}
df = pd.DataFrame(data)

# 计算内在价值和安全边际
df['内在价值'] = df['年收益'] / df['预期收益率']
df['市场价格'] = [800, 900]
df['安全边际'] = df['内在价值'] - df['市场价格']

print(df)
```
