## 第一部分: 格雷厄姆特价股票理论与社会企业融资概述

### 第1章: 格雷厄姆特价股票理论基础

#### 1.1 格雷厄姆投资理论的起源与核心思想
格雷厄姆是价值投资的鼻祖，其理论强调以低于内在价值的价格买入股票。他提出的核心思想包括：
- **内在价值**：企业未来现金流的现值，是衡量股票价值的标准。
- **安全边际**：买入价格与内在价值的差距，确保投资的安全性。
- **市场先生**：市场情绪波动对企业估值的影响。

#### 1.2 社会企业的定义与特点
社会企业是以创造社会价值为核心目标的企业，其特点包括：
- **社会使命**：致力于解决社会问题。
- **财务可持续性**：通过商业运作实现自我造血。
- **透明度**：信息公开，接受社会监督。

#### 1.3 格雷厄姆理论与社会企业融资的结合
社会企业在融资过程中，同样需要考虑投资回报和社会影响力的双重目标。格雷厄姆的理论为社会企业提供了一种以价值为导向的融资方式，帮助企业在获得资金的同时实现可持续发展。

### 第2章: 格雷厄姆特价股票理论的核心概念与联系

#### 2.1 核心概念原理
- **内在价值**：通过DCF模型计算企业未来现金流的现值，确定其合理估值。
- **安全边际**：买入价格低于内在价值，以降低市场波动带来的风险。
- **市场先生**：市场情绪的波动会影响股价，但长期来看，股价会回归其内在价值。

### 第3章: 格雷厄姆特价股票理论的数学模型与公式

#### 3.1 内在价值计算公式
$$ V = \frac{E}{1 + r} $$
其中，\( V \) 是内在价值，\( E \) 是未来现金流，\( r \) 是折现率。

#### 3.2 安全边际计算公式
$$ M = V - P $$
其中，\( M \) 是安全边际，\( V \) 是内在价值，\( P \) 是市场价格。

### 第5章: 项目实战

#### 5.1 环境安装

#### 5.2 核心代码实现
```python
import numpy as np
import pandas as pd

def calculate_intrinsic_value(future_cash_flows, discount_rate):
    return np.sum(future_cash_flows / (1 + discount_rate) ** np.arange(len(future_cash_flows)))

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
future_cash_flows = [100, 200, 300]  # 未来三年现金流
discount_rate = 0.05
intrinsic_value = calculate_intrinsic_value(future_cash_flows, discount_rate)
market_price = 250
margin_of_safety = calculate_margin_of_safety(intrinsic_value, market_price)

print(f"内在价值: {intrinsic_value}")
print(f"安全边际: {margin_of_safety}")
```

#### 5.3 代码解读与分析
- `calculate_intrinsic_value`函数计算内在价值，使用未来现金流的折现值求和。
- `calculate_margin_of_safety`函数计算安全边际，评估投资的安全性。

#### 5.4 实际案例分析
假设某社会企业未来三年现金流分别为100万、200万、300万，折现率为5%，市场价为250万。计算得出内在价值为350万，安全边际为100万，表明投资具有较高的安全性。
