## 第一部分: 价值投资的核心原理基础

### 第1章: 价值投资的定义与背景

#### 1.1 价值投资的定义
- **1.1.1 价值投资的基本概念**
  - 价值投资是一种基于对企业内在价值评估的投资策略。
  - 核心目标是通过识别市场价格低于内在价值的股票，实现长期收益。
- **1.1.2 价值投资的核心目标**
  - 寻找市场价格低于内在价值的投资标的。
  - 通过长期持有优质资产，实现财富的稳定增长。
- **1.1.3 价值投资与其它投资策略的区别**
  - 与投机投资不同，价值投资注重长期基本面分析。
  - 与趋势投资不同，价值投资不依赖短期价格波动。

#### 1.2 价值投资的历史发展
- **1.2.1 价值投资的起源**
  - 20世纪初，本杰明·格雷厄姆和戴维·多德奠定了价值投资的基础。
  - 早期价值投资主要关注企业账面价值与市场价格的差异。
- **1.2.2 格雷厄姆与多德的贡献**
  - 提出了“安全边际”概念，强调以低于内在价值的价格买入股票。
  - 强调对公司基本面的深入研究，包括财务报表分析。
- **1.2.3 菲利普斯·费雪的现代价值投资理念**
  - 强调企业的成长性和竞争优势。
  - 将价值投资从“捡烟蒂”策略扩展到长期成长股投资。

#### 1.3 价值投资的适用场景
- **1.3.1 价值投资在股票市场中的应用**
  - 适用于成熟市场中的低估股票。
  - 适合长期投资者，尤其是厌恶短期波动的投资者。
- **1.3.2 价值投资在其他资产类别中的应用**
  - 房地产、债券等资产也可以应用价值投资理念。
  - 重点在于识别资产的内在价值与市场价格的差异。
- **1.3.3 价值投资的局限性**
  - 在新兴市场或波动性较大的市场中效果有限。
  - 需要较高的研究能力和信息获取能力。

## 第2章: 价值投资的核心概念与原理

### 2.1 内在价值的计算
#### 2.1.1 内在价值的定义
- 内在价值是基于企业未来现金流的现值。
- 通过对企业未来盈利能力和资产价值的评估，确定其合理的市场价格。

#### 2.1.2 DCF模型（现金流折现法）
- **DCF模型公式**
  $$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{CF}_t}{(1+r)^t} + \frac{\text{TV}}{(1+r)^n}$$
  - CFₜ：第t年的自由现金流。
  - r：折现率。
  - TV：终值，即永续年的现金流按稳定增长率计算的现值。
- **应用实例**
  以一家预期未来5年现金流分别为100万、120万、150万、180万、200万的公司为例，假设折现率为10%。
  $$\text{内在价值} = \frac{100}{1.1} + \frac{120}{1.1^2} + \frac{150}{1.1^3} + \frac{180}{1.1^4} + \frac{200}{1.1^5}$$

#### 2.1.3 市盈率与市净率分析
- **市盈率公式**
  $$\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}$$
- **市净率公式**
  $$\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}$$
- **应用**
  - 当市盈率低于行业平均水平时，可能意味着股票被低估。
  - 市净率同样适用于评估资产密集型企业的价值。

### 2.2 安全边际的概念
#### 2.2.1 安全边际的定义
- 安全边际 = 内在价值 - 市场价格。
- 安全边际率 = (内在价值 - 市场价格) / 内在价值。
- 例如，如果内在价值为100元，市场价格为80元，安全边际为20元，安全边际率为20%。

#### 2.2.2 安全边际的计算方法
- 通过比较市场价格与内在价值的差额计算。
- 也可以通过比较市盈率或市净率与行业平均水平的差异间接评估。

#### 2.2.3 安全边际与投资风险的关系
- 安全边际越大，投资风险越低。
- 在市场恐慌时，安全边际往往较高，是较好的投资机会。

### 2.3 竞争优势的分析
#### 2.3.1 竞争优势的定义
- 竞争优势是企业能够在长期竞争中保持高于行业平均水平利润率的能力。
- 包括成本优势、技术优势、品牌优势等。

#### 2.3.2 企业竞争优势的来源
- **成本优势**
  - 规模经济。
  - 供应链优势。
- **技术优势**
  - 独特的技术专利。
  - 技术研发能力。
- **品牌优势**
  - 强大的品牌认知度。
  - 忠诚的客户群体。

#### 2.3.3 竞争优势的持续性评估
- 评估企业竞争优势的可持续性。
- 关注企业的管理能力、创新能力和发展战略。

## 第3章: 价值投资的核心数学模型与公式

### 3.1 内在价值计算公式
#### 3.1.1 DCF模型公式
$$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{CF}_t}{(1+r)^t} + \frac{\text{TV}}{(1+r)^n}$$
- 例如，假设CF₁=100，CF₂=120，r=10%，则：
$$\text{内在价值} = \frac{100}{1.1} + \frac{120}{1.1^2} = 90.91 + 98.18 = 189.09$$

#### 3.1.2 市盈率公式
$$\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}$$
- 例如，股价=20元，每股收益=2元，则市盈率=10倍。

#### 3.1.3 市净率公式
$$\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}$$
- 例如，股价=15元，每股净资产=5元，则市净率=3倍。

### 3.2 安全边际计算公式
#### 3.2.1 安全边际 = 内在价值 - 市场价格
- 例如，内在价值=100元，市场价格=80元，安全边际=20元。

#### 3.2.2 安全边际率 = (内在价值 - 市场价格) / 内在价值
- 例如，安全边际率=(100-80)/100=20%。

### 3.3 竞争优势评估模型
#### 3.3.1 竞争优势指数 = (行业地位 + 财务状况 + 管理能力 + 创新能力) / 4
- 例如，某公司行业地位=90分，财务状况=80分，管理能力=85分，创新能力=90分，则竞争优势指数=(90+80+85+90)/4=87.5分。

import pandas as pd
import numpy as np

def calculate_intrinsic_value(free_cash_flows, discount_rate, terminal_value):
    intrinsic_value = 0
    for t in range(len(free_cash_flows)):
        intrinsic_value += free_cash_flows[t] / (1 + discount_rate) ** t
    if terminal_value:
        intrinsic_value += terminal_value / (1 + discount_rate) ** len(free_cash_flows)
    return intrinsic_value

# 示例数据
free_cash_flows = [100, 120, 150, 180, 200]
discount_rate = 0.1
terminal_value = 2000

intrinsic_value = calculate_intrinsic_value(free_cash_flows, discount_rate, terminal_value)
print(f"内在价值为：{intrinsic_value}")
