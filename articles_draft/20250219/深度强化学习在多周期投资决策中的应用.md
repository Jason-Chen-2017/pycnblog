# 第一章 引言

## 1.1 深度强化学习与多周期投资决策概述

### 1.1.1 深度学习与强化学习的定义与区别
- **深度学习**：基于人工神经网络的机器学习方法，通过多层非线性变换从数据中提取特征。
- **强化学习**：通过智能体与环境交互，基于奖励机制优化决策策略。
- **区别**：深度学习侧重于特征提取，强化学习关注于策略优化和目标最大化。

### 1.1.2 多周期投资决策的背景与挑战
- **多周期投资**：在不同时间框架（如短期、中期、长期）上进行投资决策。
- **挑战**：市场波动、信息不全、策略调整复杂性。

### 1.1.3 深度强化学习在投资中的应用潜力
- **优势**：处理非线性关系、适应市场变化、优化投资组合。
