## 摘要：
企业自由现金流（FCFE，Free Cash Flow to Equity）是企业估值中最重要的指标之一，它反映了企业在扣除所有费用和再投资需求后的剩余现金流量。本文详细讲解企业自由现金流的计算方法、估值模型、系统架构设计以及实际应用案例，帮助读者掌握从理论到实践的企业估值方法。

def free_cash_flow_valuation(cash_flows, discount_rate):
    present_value = sum(cash_flow / (1 + discount_rate)**i for i, cash_flow in enumerate(cash_flows))
    return present_value

# 示例
cash_flows = [100, 200, 300]
discount_rate = 0.1
print(free_cash_flow_valuation(cash_flows, discount_rate))
