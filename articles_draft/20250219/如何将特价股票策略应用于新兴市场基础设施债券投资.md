# 第一部分: 特价股票策略与新兴市场基础设施债券投资背景

## 第1章: 特价股票策略的基本概念

### 1.1 特价股票的定义与特点

#### 1.1.1 特价股票的定义
特价股票是指价格低于其内在价值，且具有较大上涨潜力的股票。其核心在于“便宜”，即市场价格低于公允价值。

#### 1.1.2 特价股票的核心特点
| 特性 | 描述 |
|------|------|
| 低估值 | 市盈率、市净率等指标低于行业平均水平 |
| 高股息率 | 相对于市场价格，股息收益率较高 |
| 市场流动性 | 通常属于中小盘股，流动性相对较低 |
| 风险 | 投资者可能面临较高的市场波动风险 |

#### 1.1.3 特价股票与普通股票的区别
- 投资逻辑：普通股票基于成长性，特价股票基于估值修复。
- 投资期限：普通股票长期持有，特价股票短期波动较大。

## 第2章: 新兴市场的特点

### 2.1 新兴市场的定义与范围
新兴市场指经济发展水平较低但增长潜力较大的国家或地区，如中国、印度、巴西等。

### 2.2 新兴市场的经济特征
- 经济增长快，但波动性大。
- 市场流动性不足，价格波动剧烈。

### 2.3 新兴市场的投资机会与风险
- 机会：高增长行业的股票具有较大增值空间。
- 风险：政策风险、汇率风险、市场流动性风险。

---

## 第3章: 基础设施债券的基本概念

### 3.1 基础设施债券的定义
基础设施债券是指由政府或国有企业发行，用于基础设施建设的债券。

### 3.2 基础设施债券的发行主体
| 主体 | 描述 |
|------|------|
| 政府 | 主要发行主体 |
| 国有企业 | 受政府控制的大型企业 |

### 3.3 基础设施债券的收益与风险
- 收益：固定利息收入，风险较低。
- 风险：信用风险、流动性风险。
