# 第一部分: 特价股票策略与另类数据因子策略结合概述

## 第1章: 特价股票策略与另类数据因子策略概述

### 1.1 特价股票策略的定义与背景
- **1.1.1 特价股票的定义**: 特价股票指的是市场价格低于其内在价值的股票，通常被视为被市场低估的投资机会。
- **1.1.2 特价股票策略的核心思想**: 通过基本面分析，识别那些价格被市场低估的股票，期望在市场恢复时获得超额收益。
- **1.1.3 特价股票策略的市场背景**: 在市场低迷或震荡时期，特价股票策略尤为重要，投资者可以利用市场恐慌寻找价值。

### 1.2 另类数据因子策略的定义与特点
- **1.2.1 另类数据的定义**: 另类数据是指传统金融数据之外的其他数据源，如社交媒体情绪、卫星图像、供应链数据等。
- **1.2.2 另类数据因子策略的核心要素**: 利用非传统数据源构建投资因子，捕捉传统数据无法捕捉的信息。
- **1.2.3 另类数据与传统金融数据的区别**: 另类数据更注重实时性和细节，传统金融数据更注重历史和结构化。

### 1.3 特价股票策略与另类数据因子策略的结合意义
- **1.3.1 结合的必要性**: 利用传统数据和另类数据的互补性，提高投资决策的全面性。
- **1.3.2 结合的优势**: 通过结合两种策略，可以在价值发现和风险控制方面取得更好的效果。
- **1.3.3 结合的潜在价值**: 提高投资组合的收益和稳定性，降低市场风险。

### 2.2 特价股票策略的关键要素
- **2.2.1 价格与价值的对比**: 判断股票是否被低估的关键指标。

- **2.2.3 公司基本面分析**: 收入、利润、资产负债等财务指标的分析。

### 2.3 特价股票策略的核心算法

- **2.3.2 基于价格动量的股票筛选算法**: 结合价格动量和价值指标，优化选股效果。
