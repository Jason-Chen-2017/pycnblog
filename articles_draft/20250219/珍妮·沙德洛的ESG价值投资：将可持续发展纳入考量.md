#### Python代码实现简单的ESG评分模型

```python
def calculate_esg_score(environment_score, social_score, governance_score):
    # 简单的加权平均模型
    weight_env = 0.4
    weight_social = 0.3
    weight_governance = 0.3
    total_score = (environment_score * weight_env) + (social_score * weight_social) + (governance_score * weight_governance)
    return total_score

# 示例数据
env_score = 80
social_score = 75
governance_score = 85

esg_total = calculate_esg_score(env_score, social_score, governance_score)
print(f"ESG总评分为: {esg_total}")
```

#### Latex公式：ESG评分的数学模型

$$
\text{ESG总评分} = w_e \times E + w_s \times S + w_g \times G
$$

其中，\( w_e \)、\( w_s \)、\( w_g \) 分别为环境、社会、治理三个维度的权重，\( E \)、\( S \)、\( G \) 分别为各维度的评分。
