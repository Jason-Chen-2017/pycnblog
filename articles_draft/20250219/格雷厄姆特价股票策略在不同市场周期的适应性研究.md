### 第二部分: 格雷厄姆策略的核心模型与数学公式  

#### 第2章: 格雷厄姆模型的基本原理  

##### 2.1 内在价值的计算公式  
- 格雷厄姆的内在价值公式：  
$$ V = \frac{E}{4.41} \times (8.5 + g) $$  
其中，  
- $E$ 是企业过去7年平均收益。  
- $g$ 是预期年增长率。  

##### 2.2 安全边际的计算方法  
- 安全边际的定义：  
$$ \text{安全边际} = \text{市场价格} \times \text{安全边际率} $$  

##### 2.3 市盈率与市净率的比较  
- 市盈率公式：  
$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$  
- 市净率公式：  
$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$  

##### 2.4 格雷厄姆筛选法的数学模型  
- 筛选标准：  
  - 市盈率 < 15。  
  - 市净率 < 2。  
  - 股东权益回报率（ROE） > 10%。

##### 5.2 核心算法实现  
- Python代码实现格雷厄姆筛选法：  
```python
import pandas as pd
import requests

# 获取股票数据
def get_stock_data(ticker):
    url = f"https://query1.finance.yahoo.com/ws/fundamentals/v1/{ticker}"
    response = requests.get(url)
    data = response.json()
    return data['result'][0]['概要']

# 筛选特价股票
def screen_special_stocks(tickers):
    special_stocks = []
    for ticker in tickers:
        data = get_stock_data(ticker)
        pe = data['PE']
        pb = data['PB']
        roe = data['ROE']
        if pe < 15 and pb < 2 and roe > 10:
            special_stocks.append(ticker)
    return special_stocks

# 示例：筛选标普500成分股
tickers = ['AAPL', 'MSFT', 'GOOGL', ...]
result = screen_special_stocks(tickers)
print("特价股票列表:", result)
```
