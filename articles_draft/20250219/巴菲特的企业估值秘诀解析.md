# 第1章：企业估值的背景与基础

## 1.1 企业估值的基本概念

### 1.1.1 什么是企业估值
企业估值是确定企业内在价值的过程，旨在评估其未来现金流的现值。

### 1.1.2 企业估值的意义与作用
企业估值帮助投资者识别被低估或高估的投资标的，指导投资决策。

### 1.1.3 企业估值的核心要素
- 自由现金流
- 折现率
- 终值

## 1.2 巴菲特投资理念概述

### 1.2.1 巴菲特的投资哲学
价值投资，寻找具有持续竞争优势的企业。

### 1.2.2 巴菲特的企业估值观
企业价值是未来现金流的折现，强调安全边际。

### 1.2.3 巴菲特估值方法的核心思想
买入低于内在价值的股票，长期持有优秀企业。

## 1.3 企业价值与股价的关系

### 1.3.1 企业价值的定义与计算
企业价值=息税折旧及摊销前利润（EBITDA）-资本性支出+净债务。

### 1.3.2 股价的波动与市场情绪
股价围绕内在价值波动，受市场情绪影响。

### 1.3.3 安全边际的概念与应用
安全边际=内在价值-市场价格，提供风险缓冲。

## 1.4 企业估值的主要指标

### 1.4.1 市盈率（P/E）
股价/每股净利润，反映盈利能力。

### 1.4.2 市净率（P/B）
股价/每股净资产，评估资产价值。

### 1.4.3 股息率与股息增长
股息/股价，衡量收益能力。

### 1.4.4 EV/EBITDA
企业价值/息税折旧及摊销前利润，评估企业价值。

### 1.4.5 其他相关指标
ROE、ROA、净利润增长率。

# 第2章：现金流折现模型（DCF）解析

## 2.1 DCF模型的基本原理

### 2.1.1 什么是DCF模型
通过折现未来现金流评估企业内在价值。

### 2.1.2 DCF模型的核心假设
- 稳定的自由现金流增长率。
- 合理的折现率。

### 2.1.3 DCF模型的适用场景
适用于成长型企业或具有稳定现金流的企业。

## 2.2 自由现金流的计算

### 2.2.1 自由现金流的定义
净利润+非现金费用-资本性支出。

### 2.2.2 自由现金流的计算公式
$$\text{FCF} = \text{净利润} + \text{折旧} + \text{摊销} - \text{资本性支出}$$

### 2.2.3 自由现金流的估算方法
历史数据、行业平均增长率、管理层预期。

## 2.3 现金流折现的数学模型

### 2.3.1 现金流折现的公式
$$\text{企业价值} = \sum_{t=1}^{n} \frac{\text{FCF}_t}{(1+r)^t} + \frac{\text{TV}}{(1+r)^n}$$

### 2.3.2 折现率的计算
使用CAPM或WACC模型确定折现率。

### 2.3.3 终值的计算与假设
终值=最后一年现金流/（折现率-增长率）。

## 2.4 DCF模型的实现步骤

### 2.4.1 确定自由现金流
$$\text{FCF}_t = \text{FCF}_1 \times (1+g)^{t-1}$$

### 2.4.2 计算终值
$$\text{TV} = \frac{\text{FCF}_{n+1}}{r - g}$$

### 2.4.3 折现并求和
$$\text{企业价值} = \sum_{t=1}^{n} \frac{\text{FCF}_t}{(1+r)^t} + \frac{\text{TV}}{(1+r)^n}$$

## 2.5 案例分析：以苹果为例

### 2.5.1 数据收集与假设
- FCF1 = $100亿
- g = 5%
- r = 10%

### 2.5.2 计算DCF
$$\text{企业价值} = \frac{100}{1.1} + \frac{100 \times 1.05}{1.1^2} + \dots + \frac{100 \times 1.05^{10}}{1.1^{10}} + \frac{\text{TV}}{1.1^{10}}$$

# 第3章：DCF模型与其他估值方法的对比

## 3.1 其他估值方法概述

### 3.1.1 市盈率法
$$\text{目标股价} = \text{P/E} \times \text{每股收益}$$

### 3.1.2 市净率法
$$\text{目标股价} = \text{P/B} \times \text{每股净资产}$$

## 3.2 各种估值方法的优缺点对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| DCF | 精确，考虑现金流 | 需准确预测现金流 |
| P/E | 简单，反映盈利能力 | 受行业影响大 |
| P/B | 稳定，反映资产价值 | 忽略收益能力 |

## 3.3 适用场景分析

### 3.3.1 DCF适用于高成长企业
- 现金流增长稳定，行业前景良好。

### 3.3.2 P/E适用于成熟企业
- 盈利稳定，市盈率合理。

### 3.3.3 P/B适用于周期性企业
- 资产负债表稳健。

### 4.2.1 安全边际公式
$$\text{安全边际} = \text{内在价值} - \text{市场价格}$$

### 4.2.2 安全边际的重要性

## 4.3 风险调整后的DCF模型

使用更高的折现率反映更高的风险。

### 4.3.2 调整终值
降低终值或延长增长期。
