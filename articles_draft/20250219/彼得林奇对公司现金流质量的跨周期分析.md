## 第三部分：算法原理讲解

### 第4章：现金流质量分析的算法原理

#### 4.1 班氏模型的现金流质量评估
- 班氏模型的基本原理：通过现金流质量指数（Q值）量化企业现金流健康度
- 现金流质量指数的计算公式：
  $$ Q = \frac{FCF}{\text{营业收入}} \times 100 $$
  其中，FCF为自由现金流，营业收入为企业当期收入。

## 第五部分：项目实战与案例分析

### 第6章：现金流质量分析的项目实战

#### 6.1 环境安装
- 安装Python、Pandas、Matplotlib等工具
- 数据来源：企业财务报表数据（如营业收入、净利润、现金流等）

#### 6.2 核心实现源代码
```python
import pandas as pd
import matplotlib.pyplot as plt

# 示例数据
data = {
    '年份': [2018, 2019, 2020, 2021, 2022],
    '营业收入': [100, 120, 110, 130, 140],
    '净利润': [20, 25, 18, 28, 32],
    '经营活动现金流': [15, 20, 16, 22, 24]
}

df = pd.DataFrame(data)

# 计算自由现金流（假设净利润=经营活动现金流+非现金费用）
df['自由现金流'] = df['净利润'] + df['经营活动现金流']

# 计算现金流质量指数
df['现金流质量指数'] = (df['自由现金流'] / df['营业收入']) * 100

print(df)
```
