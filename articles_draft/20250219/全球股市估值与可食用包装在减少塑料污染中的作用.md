## 第1章: 股市估值的核心概念

### 1.1 股市估值的基本方法

股市估值是投资者评估企业价值的重要工具，以下是几种常用的估值方法：

#### 1.1.1 市盈率（P/E）

市盈率是衡量企业股票价值的重要指标，计算公式为：

$$P/E = \frac{\text{股价}}{\text{每股收益}}$$

例如，假设某公司股价为 $50，每股收益为 $5，则市盈率为 $50 / $5 = 10。

#### 1.1.2 市净率（P/B）

市净率是衡量企业股价与账面价值之间的关系，计算公式为：

$$P/B = \frac{\text{股价}}{\text{每股净资产}}$$

例如，假设某公司股价为 $30，每股净资产为 $10，则市净率为 $30 / $10 = 3。

#### 1.1.3 市销率（P/S）

市销率是衡量企业股价与销售收入之间的关系，计算公式为：

$$P/S = \frac{\text{股价}}{\text{每股收入}}$$

例如，假设某公司股价为 $20，每股收入为 $5，则市销率为 $20 / $5 = 4。
