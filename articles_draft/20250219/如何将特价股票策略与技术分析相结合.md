## 第1章：特价股票策略的基础

### 1.1 特价股票的定义与特点

#### 1.1.1 特价股票的定义
特价股票是指市场价格低于其内在价值的股票。这种差异可能是由于市场波动、投资者情绪或短期市场失灵造成的。投资者可以利用这种价格差异进行套利，以期获得短期收益。

#### 1.1.2 特价股票的特点
- **价格低估**：市场价格低于内在价值。
- **波动性高**：通常波动较大，适合短线交易。
- **市场关注度低**：可能被市场忽视，具有潜在的上升空间。

#### 1.1.3 特价股票的优势与劣势
- **优势**：潜在的高收益，套利机会。
- **劣势**：高风险，波动性大，市场关注度低。

### 1.2 技术分析的基本概念

#### 1.2.1 技术分析的定义
技术分析是一种通过分析历史价格数据来预测未来价格走势的方法。它假设市场行为反映所有信息，并通过价格图表和指标来识别趋势和模式。

#### 1.2.2 技术分析的核心假设
- 市场行为反映所有信息。
- 价格走势具有趋势性。
- 历史形态会重复出现。

#### 1.2.3 技术分析与基本面分析的区别
- **技术分析**：基于价格和成交量数据。
- **基本面分析**：基于公司财务状况和行业前景。

### 1.3 特价股票策略与技术分析的结合意义

#### 1.3.1 结合的必要性
- 利用技术分析筛选潜在的特价股票。
- 提高交易决策的效率和准确性。

#### 1.3.2 结合的优势
- 综合考虑价格波动和内在价值。
- 提高策略的可靠性和稳定性。

#### 1.3.3 结合的适用场景
- 短期套利机会。
- 市场波动剧烈时。

## 第2章：技术分析的基础指标

### 2.1 移动平均线（MA）

#### 2.1.1 MA的定义与计算公式
- **简单移动平均（SMA）**：$$SMA = \frac{p_1 + p_2 + \dots + p_n}{n}$$
- **指数移动平均（EMA）**：$$EMA = p_n + \alpha (p_n - SMA_{n-1})$$，其中$\alpha$为衰减因子。

#### 2.1.2 MA的类型
- 简单移动平均（SMA）。
- 指数移动平均（EMA）。

#### 2.1.3 MA的应用实例
- 通过MA识别价格趋势。
- 使用MA交叉点（Golden Cross和Death Cross）作为买卖信号。

### 2.2 相对强弱指数（RSI）

#### 2.2.1 RSI的定义与计算公式
$$RSI = \frac{100}{1 + \frac{A}{B}}$$，其中$A$为上涨幅度，$B$为下跌幅度。

#### 2.2.2 RSI的应用规则
- RSI > 70：超买信号。
- RSI < 30：超卖信号。

#### 2.2.3 RSI的超买超卖信号
- 超买信号：价格可能回调。
- 超卖信号：价格可能反弹。

### 2.3 MACD指标

#### 2.3.1 MACD的定义与计算公式
- **MACD线**：$$MACD = EMA_{12} - EMA_{26}$$
- **信号线**：$$Signal = EMA_{9}$$

#### 2.3.2 MACD的应用规则
- MACD线与信号线交叉：买入或卖出信号。
- MACD线在0线上方：趋势向上。

#### 2.3.3 MACD的顶底背离
- 价格创出新高，MACD未创新高：顶部信号。
- 价格创出新低，MACD未创新低：底部信号。

#### 3.1.2 Python实现
```python
import pandas as pd

def calculate_sma(data, window):
    return data['close'].rolling(window).mean()

def calculate_ema(data, window):
    return data['close'].ewm(alpha=0.5, min_periods=0, adjust=False).mean()
```

### 3.2 RSI算法

#### 3.2.1 算法流程图

```mermaid

    A[开始] --> B[计算上涨幅度]
    B --> C[计算下跌幅度]
    C --> D[计算RSI]
    D --> E[生成信号]
    E --> F[结束]
```

#### 3.2.2 Python实现
```python
def calculate_rsi(data, window):
    up = data['close'] - data['close'].shift(1)
    down = data['close'].shift(1) - data['close']
    up = pd.Series(up, name='up').where(up > 0, 0)
    down = pd.Series(down, name='down').where(down > 0, 0)
    rsi = (100 / (1 + (up.rolling(window).mean() / down.rolling(window).mean())))
    return rsi
```

### 3.3 MACD算法

#### 3.3.1 算法流程图

```mermaid
graph TD
    A[开始] --> B[计算EMA12]
    B --> C[计算EMA26]
    C --> D[计算MACD线]
    D --> E[计算信号线]
    E --> F[生成信号]
    F --> G[结束]
```

#### 3.3.2 Python实现
```python
def calculate_macd(data):
    ema12 = data['close'].ewm(span=12, min_periods=0, adjust=False).mean()
    ema26 = data['close'].ewm(span=26, min_periods=0, adjust=False).mean()
    macd = ema12 - ema26
    signal = macd.ewm(span=9, min_periods=0, adjust=False).mean()
    return macd, signal
```
