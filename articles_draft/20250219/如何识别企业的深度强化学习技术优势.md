#### 3.1 Q-learning的数学模型
- Q-learning的更新公式：
  $$ Q(s,a) = Q(s,a) + \alpha (r + \max Q(s',a') - Q(s,a)) $$
- Q-learning的收敛性分析

#### 3.2 DQN算法的数学模型
- DQN的网络结构：输入层、隐藏层、输出层
- DQN的损失函数：
  $$ \mathcal{L} = \mathbb{E}[ (r + \gamma Q(s',a') - Q(s,a))^2 ] $$
- DQN的策略网络与值网络的关系

#### 3.3 Policy Gradient Methods的数学模型
- Policy Gradient的梯度计算公式：
  $$ \nabla \theta = \mathbb{E}[ \nabla \log \pi_\theta(a|s) \cdot Q(s,a) ] $$
- Policy Gradient的优化目标：
  $$ \mathcal{J} = \mathbb{E}[ Q(s,a) \log \pi_\theta(a|s) ] $$

#### 5.2 核心代码实现
- Q-learning算法实现
  ```python
  import numpy as np

  class QLearning:
      def __init__(self, state_space, action_space, learning_rate=0.1, gamma=0.9):
          self.q_table = np.zeros((state_space, action_space))
          self.learning_rate = learning_rate
          self.gamma = gamma

      def choose_action(self, state):
          return np.argmax(self.q_table[state])

      def learn(self, state, action, reward, next_state):
          self.q_table[state, action] += self.learning_rate * (reward + self.gamma * np.max(self.q_table[next_state]) - self.q_table[state, action])
  ```

- DQN算法实现
  ```python
  import tensorflow as tf
  import numpy as np

  class DQN:
      def __init__(self, input_dim, output_dim, learning_rate=0.001):
          self.model = tf.keras.Sequential([
              tf.keras.layers.Dense(24, activation='relu', input_shape=(input_dim,)),
              tf.keras.layers.Dense(24, activation='relu'),
              tf.keras.layers.Dense(output_dim)
          ])
          self.optimizer = tf.keras.optimizers.Adam(learning_rate)
          self.loss_fn = tf.keras.losses.mean_squared_error

      def call(self, x):
          return self.model(x)

      def train_step(self, states, actions, rewards, next_states, gamma=0.99):
          with tf.GradientTape() as tape:
              current_q = self.call(states)
              next_q = self.call(next_states)
              target = rewards + gamma * np.max(next_q, axis=1)
              target = tf.stop_gradient(target)
              loss = self.loss_fn(target, current_q[:, actions])
          gradients = tape.gradient(loss, self.model.trainable_weights)
          self.optimizer.apply_gradients(zip(gradients, self.model.trainable_weights))
  ```
