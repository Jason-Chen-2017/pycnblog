#### 3.1 算法概述

#### 3.2 算法流程图

#### 3.3 Python实现代码

```python
def calculate_sustainability_score(criteria_scores, weights):
    return sum(criteria_scores[i] * weights[i] for i in range(len(criteria_scores)))

# 示例权重分配
weights = [0.4, 0.3, 0.3]
criteria_scores = [0.8, 0.6, 0.7]
score = calculate_sustainability_score(criteria_scores, weights)
print(score)
```

#### 3.4 数学模型与公式

综合评估模型可以表示为：

$$
S = \sum_{i=1}^{n} w_i \times x_i
$$

其中，$S$ 是综合评分，$w_i$ 是第 $i$ 个指标的权重，$x_i$ 是第 $i$ 个指标的评分。

#### 5.2 核心代码实现

```python
import numpy as np
import pandas as pd

def calculate_sustainability_score(criteria_scores, weights):
    return np.dot(criteria_scores, weights)

# 示例数据
data = pd.DataFrame({
    '财务指标': [0.8, 0.7, 0.9],
    '社会责任': [0.6, 0.8, 0.7],
    '环境影响': [0.7, 0.6, 0.8]
})

weights = np.array([0.4, 0.3, 0.3])

result = calculate_sustainability_score(data.values.flatten(), weights)
print(result)
```
