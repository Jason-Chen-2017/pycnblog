#### 3.2 影响力期权的预测
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 假设数据集包含社交媒体影响力评分和股票价格
data = pd.DataFrame({
    '影响力评分': [70, 80, 65, 90, 85],
    '股票价格': [100, 110, 90, 130, 120]
})

# 使用线性回归模型预测影响力评分对股票价格的影响
model = LinearRegression()
model.fit(data[['影响力评分']], data['股票价格'])

# 预测新的影响力评分对应的股票价格
new_influence = np.array([[75]])
predicted_price = model.predict(new_influence)
print(f'预测股票价格为: {predicted_price[0]:.2f}')
```
