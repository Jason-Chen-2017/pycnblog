### 2.1.3 神经网络的反向传播
$$L = L_{\text{损失}}(y, \hat{y})$$
$$\frac{\partial L}{\partial w} = \text{反向传播算法的核心公式}$$

## 2.2 神经网络算法的流程图
```mermaid

    Start --> 输入数据
    输入数据 --> 前向传播
    前向传播 --> 计算损失
    计算损失 --> 反向传播
    反向传播 --> 更新权重
    更新权重 --> 结束
```

## 2.3 神经网络算法的数学模型
- 线性部分：$z = Wx + b$
- 激活函数：$a = \sigma(z)$
- 损失函数：$L = \frac{1}{n}\sum_{i=1}^{n} (y_i - \hat{y_i})^2$
