#### 3.1 内在价值的计算公式

$$ V = \frac{E}{k} $$

其中，V为内在价值，E为预期收益，k为折现率。

#### 3.2 安全边际的定义与计算

$$ \text{安全边际} = \frac{\text{内在价值} - \text{市场价格}}{\text{市场价格}} $$

#### 5.2 Python代码实现

```python
def calculate_intrinsic_value(earning, discount_rate):
    return earning / discount_rate

def calculate_margin_of_safety(intrinsic_value, market_price):
    return (intrinsic_value - market_price) / market_price

# 示例计算
earning = 100
discount_rate = 0.05
market_price = 80

iv = calculate_intrinsic_value(earning, discount_rate)
mos = calculate_margin_of_safety(iv, market_price)

print(f"内在价值: {iv}")
print(f"安全边际: {mos}")
```

#### 7.2 核心代码实现

```python
import numpy as np
import pandas as pd

def adjust_discount_rate(current_policy):
    if current_policy == '紧缩':
        return 0.03
    elif current_policy == '宽松':
        return 0.07
    else:
        return 0.05

# 示例数据
data = {'earning': [100, 120, 90], 'market_price': [80, 100, 70}
df = pd.DataFrame(data)
df['discount_rate'] = df['earning'].apply(lambda x: adjust_discount_rate('宽松'))
df['intrinsic_value'] = df['earning'] / df['discount_rate']
df['margin_of_safety'] = (df['intrinsic_value'] - df['market_price']) / df['market_price']

print(df)
```

展示了如何根据不同的货币政策环境调整折扣率，并计算内在价值和安全边际。
