## 第二部分：核心概念与联系

### 第2章：核心概念与数据模型

#### 2.1 核心概念
- 2.1.1 股市估值的基本概念  
  股市估值是通过对企业财务数据和市场信息进行分析，估算其内在价值，帮助投资者判断股票价格是否合理。
- 2.1.2 市盈率、市净率等关键指标  
  - 市盈率（P/E Ratio）：市盈率 = 股价 / 每股净利润。
  - 市净率（P/B Ratio）：市净率 = 股价 / 每股净资产。
- 2.1.3 数据更新频率与实时性要求  
  每日更新数据要求系统具备高实时性，能够快速响应市场变化。

## 第六部分：数学模型与公式

### 第6章：数学模型与公式

#### 6.1 移动平均数模型
- 模型公式：
  $$MA_t = \frac{1}{n} \sum_{i=1}^{n} P_{t-i}$$
- 示例计算：假设n=3，序列P1=100，P2=200，P3=300，则MA4 = (100 + 200 + 300) / 3 = 200。

#### 6.2 指数平滑法
- 模型公式：
  $$F_t = \alpha D_{t-1} + (1-\alpha)F_{t-1}$$
- 示例计算：假设α=0.3，D3=300，F2=200，则F3 = 0.3*300 + 0.7*200 = 130。
