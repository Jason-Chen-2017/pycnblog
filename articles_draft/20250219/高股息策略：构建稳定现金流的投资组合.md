## 第二章: 高股息策略的核心要素

### 2.1 高股息策略的三大核心要素
#### 2.1.1 股息率
- 股息率定义：股息率 = 年度股息 / 当前股价。
- 示例：某股票股息率为5%，即每年每股分红5元，股价为100元。

#### 2.1.2 股息增长能力
- 股息增长能力是公司持续分红能力的体现。
- 示例：公司过去5年股息增长率分别为5%、6%、4%、7%、5%。

#### 2.1.3 股东权益回报率(ROE)
- ROE定义：ROE = 净利润 / 股东权益。
- 高ROE意味着公司使用股东资金的效率高，盈利能力强。

### 2.2 高股息策略的筛选标准
#### 2.2.1 股息率的计算与分析
- 股息率计算公式：$$股息率 = \frac{股息}{股价}$$
- 示例：某股票股息率为5%，即每年每股分红5元，股价为100元。

#### 2.2.2 股息增长的稳定性
- 稳定的股息增长是高股息策略的关键。
- 示例：某公司过去5年股息增长分别为5%、6%、4%、7%、5%。

#### 2.2.3 股东权益回报率的评估
- 高ROE意味着公司盈利能力强，分红能力高。
- 示例：某公司ROE为15%，表明其股东资金使用效率较高。

### 2.3 高股息策略的风险管理
#### 2.3.1 高股息策略的主要风险
- **流动性风险**：高股息股票可能流动性较差。
- **分红能力不足**：股息率过高的公司可能无法持续分红。

#### 2.3.2 风险的量化与评估
- 通过股息率和ROE评估公司的分红能力和盈利能力。
- 示例：某公司股息率为10%，但ROE仅为5%，可能存在分红能力不足的风险。

#### 2.3.3 风险控制的策略
- **分散投资**：避免过度集中于单一行业或公司。
- **动态调整**：定期评估投资组合，及时调整持仓。

    selected = []
    for stock in stocks:
        dividend_yield = stock.dividend / stock.price
        roe = stock.net_profit / stock.shareholder_equity
        if dividend_yield > 0.05 and roe > 0.1:

    return selected
