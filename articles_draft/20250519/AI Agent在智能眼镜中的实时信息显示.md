### 示例代码：
```python
import cv2
from yolo import YOLO

def detect_objects(image):
    boxes = YOLO.detect(image)
    for box in boxes:
        cv2.rectangle(image, (box.x1, box.y1), (box.x2, box.y2), (0, 255, 0), 2)
    return image
```
