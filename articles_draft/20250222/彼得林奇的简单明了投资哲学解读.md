## 第一部分: 投资哲学的背景与核心概念

### 第1章: 投资哲学的背景介绍

#### 1.1 投资哲学的背景  
投资哲学是指导投资者做出决策的理论体系，经历了从传统到现代的演变。传统投资依赖于市场波动和短期收益，而现代投资理论强调基本面分析和长期持有。彼得·林奇的出现，将投资哲学推向了一个新的高度，倡导简单明了的投资策略，强调长期价值和基本面分析。

#### 1.2 彼得·林奇的生平与成就  
彼得·林奇是美国著名投资专家，曾任富达麦哲伦基金的经理，创造了辉煌的投资业绩。他的投资哲学以简单、明确著称，强调长期投资和基本面分析，成为无数投资者的导师。

#### 1.3 简单明了投资哲学的定义  
简单明了投资哲学是一种以基本面分析为基础，注重长期投资和价值投资的投资策略。它强调通过分析公司的财务状况、行业地位和未来前景，选择具有长期增长潜力的公司，避免短期市场波动的干扰。

### 第2章: 简单明了投资哲学的核心概念

#### 2.1 投资哲学的核心要素  
- 价值投资：寻找被市场低估的公司，关注其内在价值。
- 长期投资：长期持有优质资产，避免频繁交易。
- 市场分析：分析行业趋势和市场环境，识别投资机会。

#### 2.2 简单明了投资哲学的特征  
- 简洁性：策略简单，易于理解和执行。
- 明确性：目标明确，避免模糊决策。
- 可操作性：易于在实际投资中应用，适合不同投资者。

#### 2.3 简单明了投资哲学与复杂投资哲学的对比  

| 对比维度       | 简单明了投资哲学                  | 复杂投资哲学                  |
|----------------|-----------------------------------|------------------------------|
| 分析方法       | 侧重基本面分析                  | 包括技术分析和复杂模型        |
| 投资策略       | 长期持有优质资产                | 短期交易和多样化策略          |
| 风险管理       | 侧重长期风险控制                | 侧重短期风险管理              |
| 适用场景       | 适合长期稳健投资者              | 适合专业投资者和机构投资者      |

# 读取公司数据
data = pd.read_csv('company_data.csv')

# 计算市盈率
data['市盈率'] = data['股价'] / data['每股收益']

# 筛选市盈率低于行业平均水平的公司
average_pe = data['市盈率'].mean()
selected_companies = data[data['市盈率'] < average_pe]
