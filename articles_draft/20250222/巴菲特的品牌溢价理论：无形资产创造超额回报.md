#### 6.2 品牌溢价的算法实现
- 6.2.1 算法步骤
- 6.2.2 代码实现
  ```python
  def calculateDCF(cash_flows, discount_rate, terminal_value):
      present_value = 0
      for t, cash_flow in enumerate(cash_flows):
          if t == 0:
              present_value += cash_flow
          else:
              present_value += cash_flow / (1 + discount_rate) ** t
      present_value += terminal_value / (1 + discount_rate) ** len(cash_flows)
      return present_value
  ```
