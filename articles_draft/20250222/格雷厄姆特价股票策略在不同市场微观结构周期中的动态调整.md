## 第一部分：格雷厄姆特价股票策略基础

### 第1章：格雷厄姆投资理论概述

#### 1.1 格雷厄姆投资理论的核心理念
格雷厄姆是价值投资之父，他的理论强调以低于内在价值的价格购买股票，长期持有，等待市场的价值回归。核心理念包括：
- **安全边际**：购买价格远低于内在价值，以降低风险。
- **长期视角**：关注企业的基本面，而非短期市场波动。
- **逆向投资**：在市场恐慌时买入，在市场狂热时卖出。

#### 1.2 特价股票的定义与特征
- **定义**：指市场价格远低于其内在价值的股票。
- **特征**：
  - 低市盈率（P/E）或低市净率（P/B）。
  - 高股息率，且股息来自稳定盈利。
  - 行业地位稳固，但暂时被市场忽视。

#### 1.3 格雷厄姆策略的历史背景
- 20世纪30年代经济大萧条后，格雷厄姆总结经验，提出价值投资理论，强调安全边际和长期持有。

### 第2章：市场微观结构周期分析

#### 2.1 市场微观结构的基本概念
- **定义**：指市场中买卖双方的互动方式，包括订单簿、交易量、价格波动等。
- **周期分类**：
  - 牛市：价格持续上涨，投资者情绪乐观。
  - 熊市：价格持续下跌，投资者情绪悲观。
  - 震荡市：价格波动剧烈，市场情绪摇摆不定。

#### 2.2 市场周期对投资策略的影响
- **牛市**：投资者倾向于高估股票，价值投资者需警惕。
- **熊市**：市场恐慌，提供廉价买入机会。
- **震荡市**：市场波动大，策略需灵活调整。

## 第二部分：动态调整策略

### 第3章：动态调整策略的理论基础

#### 3.1 动态调整的必要性
- 市场变化不可预测，需根据周期调整策略。
- 投资者心理影响市场行为，需灵活应对。

#### 3.2 动态调整的核心原则
- **风险控制**：设定止损点，避免重大损失。
- **仓位管理**：根据市场情况调整持仓比例。
- **动态再平衡**：定期调整投资组合，以适应市场变化。

### 第4章：不同市场周期中的策略调整

#### 4.1 牛市中的策略调整
- 牛市特征：价格高估，风险上升。
- 调整措施：
  - 减少持仓，降低风险。
  - 选择性增持低估股票。

#### 4.2 熊市中的策略调整
- 熊市特征：价格低估，市场恐慌。
- 调整措施：
  - 增加持仓，抓住低估机会。
  - 选择性卖出高估股票。

#### 4.3 震荡市中的策略调整
- 震荡市特征：价格波动大，市场情绪不稳定。
- 调整措施：
  - 灵活调整仓位，跟随市场趋势。
  - 结合技术指标，优化买卖时机。

- **指标计算**：
  ```python
  def calculate_rsi(data, period=14):
      diff = data['close'].diff()
      up = diff.where(diff > 0, 0)
      down = diff.where(diff < 0, 0)
      rsi = (100 - (down.ewm(alpha=1/period).mean() / (up.ewm(alpha=1/period).mean() + down.ewm(alpha=1/period).mean())) * 100)
      return rsi
  ```

- **策略执行**：
  ```python
  def execute_strategy(data, rsi_data):
      signals = []
      for i in range(len(data)):
          if i == 0:
              signals.append('hold')
          else:
              if rsi_data[i-1] < 30 and data['close'][i] > data['close'][i-1]:
                  signals.append('buy')
              elif rsi_data[i-1] > 70 and data['close'][i] < data['close'][i-1]:
                  signals.append('sell')
              else:
                  signals.append('hold')
      return signals
  ```
