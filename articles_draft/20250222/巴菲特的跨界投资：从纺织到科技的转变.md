### 第3章：巴菲特投资决策的算法原理

#### 3.1 投资决策的量化分析

- 3.1.1 市盈率（P/E Ratio）计算公式
  $$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
  
- 3.1.2 市净率（P/B Ratio）计算公式
  $$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$
  
- 3.1.3 市盈率与市净率的比较

#### 3.2 投资决策流程的mermaid流程图

#### 3.3 投资评估的Python代码实现

```python
def calculate_pe_ratio(price, earnings_per_share):
    return price / earnings_per_share

def calculate_pb_ratio(price, book_value_per_share):
    return price / book_value_per_share

# 示例数据
price = 150  # 假设股价为150美元
earnings_per_share = 5  # 每股收益为5美元
book_value_per_share = 10  # 每股净资产为10美元

pe_ratio = calculate_pe_ratio(price, earnings_per_share)
pb_ratio = calculate_pb_ratio(price, book_value_per_share)

print(f"市盈率：{pe_ratio}\n市净率：{pb_ratio}")
```

#### 3.4 投资决策的数学模型

- 市盈率反映市场对收益的估值，市净率反映市场对资产的估值。
- 通过比较市盈率和市净率与行业平均水平，巴菲特评估投资的潜在价值。

#### 5.2 核心代码实现

```python
import pandas as pd

# 假设数据为苹果公司财务数据
data = {
    '公司': ['苹果'],
    '股价': [150],
    '每股收益': [5],
    '每股净资产': [10]
}

df = pd.DataFrame(data)

pe = df['股价'] / df['每股收益']
pb = df['股价'] / df['每股净资产']

print(f"市盈率：{pe.values[0]}\n市净率：{pb.values[0]}")
```

#### 5.3 代码解读与分析

- 计算苹果的市盈率和市净率，评估其投资价值。
- 对比行业平均水平，判断是否值得投资。

#### 5.4 实际案例分析

- 苹果公司的案例：高市盈率和高市净率，但因其高增长和盈利能力，巴菲特可能认为其有投资价值。
