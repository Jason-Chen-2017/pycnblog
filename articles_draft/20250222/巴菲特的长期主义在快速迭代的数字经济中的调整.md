## 第三部分：长期主义的算法原理讲解

### 第3章：长期主义的数学模型与公式

#### 3.1 长期主义的数学模型  
- **长期价值计算模型**：基于现金流折现法（DCF模型）。  
  公式：$$V = \sum_{t=1}^{\infty} \frac{CF_t}{(1+r)^t}$$  
  其中，\(CF_t\) 是第 \(t\) 年的现金流，\(r\) 是折现率。  

- **投资回报预测模型**：基于资产的未来现金流折现。  
  公式：$$NPV = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} - Initial\ Investment$$  

- **风险调整后的长期收益模型**：基于风险调整的资本资产定价模型（CAPM）。  
  公式：$$E(R_i) = R_f + \beta_i (R_m - R_f)$$

def calculate_long_term_value(cash_flows, discount_rate):
    present_value = 0
    for t in range(len(cash_flows)):
        present_value += cash_flows[t] / (1 + discount_rate) ** t
    return present_value

# 示例数据
cash_flows = [100, 200, 300, 400]
discount_rate = 0.1

lt_value = calculate_long_term_value(cash_flows, discount_rate)
print(f"长期价值：{lt_value}")
