## 第一部分: 格雷厄姆特价股票策略与货币政策周期的背景介绍

### 第1章: 格雷厄姆特价股票策略概述

#### 1.1 格雷厄姆特价股票策略的定义与核心思想  
格雷厄姆的价值投资策略强调以低于内在价值的价格买入股票，重点关注低市盈率、低市净率和高股息率的股票。其核心思想是寻找市场先生的错误定价，通过安全边际来降低投资风险。

#### 1.2 货币政策周期的定义与特征  
货币政策周期是指经济周期中货币政策的调整阶段，包括扩张周期和收缩周期。扩张周期通过宽松的货币政策（如降息、增加货币供应）刺激经济增长，而收缩周期则通过紧缩政策控制通胀和过度需求。

#### 1.3 格雷厄姆策略与货币政策周期的关联性  
货币政策周期影响市场流动性、利率水平和企业盈利预期，进而影响股票估值。格雷厄姆策略在不同周期下的表现不同，需根据经济环境进行调整。

### 第2章: 格雷厄姆策略与货币政策周期的对比分析

#### 2.1 格雷厄姆策略的核心属性  
- **低市盈率（P/E）**：市盈率低于行业平均水平，反映股票价格被低估。
- **低市净率（P/B）**：市净率低于行业平均水平，反映资产价值被低估。
- **高股息率**：股息收益率较高，提供稳定的现金流。

#### 2.2 货币政策周期的核心属性  
- **扩张周期**：低利率、高流动性，股市通常表现较好。
- **收缩周期**：高利率、低流动性，股市可能调整。

#### 2.3 格雷厄姆策略与货币政策周期的对比表格

| 影响因素 | 股价、估值 | 利率、流动性 |
| 结果 | 稳定收益 | 经济波动 |

#### 5.2 核心代码实现

```python
import pandas as pd

def calculate_pe_ratio(df):
    df['PE'] = df['净利润'] / df['股价']
    return df

def adjust_strategy(economic_cycle, df):
    if economic_cycle == 'expansion':
        selected = df[df['PE'] < df['PE'].median()]
    else:
        selected = df[df['股息率'] > df['股息率'].median()]
    return selected

# 示例数据
data = {
    '股价': [10, 20, 30, 40],
    '净利润': [5, 10, 15, 20],
    '股息率': [2%, 3%, 4%, 5%]
}
df = pd.DataFrame(data)
adjusted = adjust_strategy('expansion', df)
print(adjusted)
```
