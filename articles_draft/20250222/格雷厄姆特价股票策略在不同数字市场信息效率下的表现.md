# 第一部分：格雷厄姆投资理论与数字市场信息效率概述

## 第1章：格雷厄姆投资理论的核心概念

### 1.1 价值投资的定义与原则

价值投资是一种投资策略，主张以低于其内在价值的价格购买股票。其核心原则包括：

1. **安全边际**：购买价格低于内在价值，以降低风险。
2. **长期视角**：关注企业的长期盈利能力，而非短期市场波动。
3. **基本面分析**：通过分析企业的财务状况、行业地位和管理团队等基本面因素来评估其价值。

### 1.2 数字市场信息效率的定义

数字市场信息效率指信息在市场中传播的速度和准确性。高效的信息传播可以迅速反映到股票价格中，而低效的信息传播可能导致价格偏离内在价值。

### 1.3 格雷厄姆策略与数字市场信息效率的关系

- **高效信息环境**：信息传播快，股票价格反映真实价值，格雷厄姆策略更容易找到低估的股票。
- **低效信息环境**：信息传播慢，市场可能存在信息不对称，格雷厄姆策略可能需要更长时间才能见效。

## 第2章：数字市场信息效率对股票定价的影响

### 2.1 信息效率与股票价格的关系

信息效率越高，股票价格越能反映企业的真实价值。反之，信息效率低可能导致股票价格被高估或低估。

### 2.2 不同市场环境下的信息效率差异

- **牛市**：信息效率较高，市场情绪乐观，股票价格可能被高估。
- **熊市**：信息效率较低，市场情绪悲观，股票价格可能被低估。

## 第3章：格雷厄姆策略的核心数学模型

### 3.1 内在价值的计算公式

$$
\text{内在价值} = \frac{\text{预期现金流}}{\text{折现率}}
$$

### 3.2 安全边际的计算公式

$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

### 3.3 市盈率与市净率的计算

- 市盈率（P/E）：$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
- 市净率（P/B）：$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

```python
import pandas as pd
import matplotlib.pyplot as plt

# 计算市盈率
def calculate_pe_ratio(df):
    df['PE'] = df['股价'] / df['每股收益']
    return df

# 计算市净率
def calculate_pb_ratio(df):
    df['PB'] = df['股价'] / df['每股净资产']
    return df

# 主函数
def main():
    data = pd.read_csv('stock_data.csv')
    data = calculate_pe_ratio(data)
    data = calculate_pb_ratio(data)
    plt.plot(data['PE'])
    plt.title('市盈率变化')
    plt.show()

if __name__ == "__main__":
    main()
```
