## 第3章：回归分析法

### 3.2 Python代码实现
```python
import pandas as pd
import statsmodels.api as sm

# 数据预处理
data = pd.read_csv('emerging_markets.csv')
data = data.dropna()

# 建立多元回归模型
X = data[['GDP_growth', 'inf_rate', 'inv_inf']]
X = sm.add_constant(X)
Y = data['stock_valuation']

model = sm.OLS(Y, X)
result = model.fit()

# 输出回归结果
print(result.summary())
```

### 3.3 数学模型与公式
$$ Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \epsilon $$

其中：
- $Y$：股市估值
- $X_1$：GDP增长率
- $X_2$：基础设施投资
- $\beta_0$：截距
- $\beta_1, \beta_2$：回归系数
- $\epsilon$：误差项

### 5.2 核心代码实现
```python
import pandas as pd
import statsmodels.api as sm
import matplotlib.pyplot as plt

# 数据获取
data = pd.read_csv('emerging.csv')

# 数据处理
data.dropna(inplace=True)

# 建立回归模型
X = data[['GDP_growth', 'inf_rate', 'inv_inf']]
X = sm.add_constant(X)
Y = data['stock_valuation']

model = sm.OLS(Y, X)
result = model.fit()

# 可视化
plt.scatter(data['GDP_growth'], Y)
plt.title('GDP Growth vs Stock Valuation')
plt.xlabel('GDP Growth (%)')
plt.ylabel('Stock Valuation Index')
plt.show()
```
