# 第一章: 长期价值投资的定义与核心理念

## 1.1 长期价值投资的定义
### 1.1.1 投资的定义与分类
- 投资：通过购买资产以获得未来收益的行为。
- 分类：包括短期投资和长期投资，长期投资关注资产的长期价值和稳定性。

### 1.1.2 长期价值投资的核心理念
- **长期价值投资**：以企业的内在价值为核心，关注企业的基本面、财务状况和管理能力。
- **彼得林奇的策略**：寻找具有持续竞争优势和良好管理的企业，长期持有，获得稳定收益。

## 1.2 ESG投资的定义与发展
### 1.2.1 ESG投资的定义
- **环境（Environmental）**：关注企业的碳排放、资源利用效率等环境表现。
- **社会（Social）**：关注企业在社会责任、员工福利、社区贡献等方面的表现。
- **治理（Governance）**：关注企业的公司治理结构、董事会效率、透明度等。

### 1.2.2 ESG投资的发展历程
- **背景**：随着环保意识和社会责任的增强，ESG投资逐渐成为主流。
- **现状**：越来越多的投资者将ESG因素纳入投资决策，推动企业可持续发展。

## 1.3 长期价值投资与ESG投资的联系
### 1.3.1 共同点
- 都关注企业的长期表现和可持续性。
- 重视企业的基本面和管理能力。

### 1.3.2 区别
- **目标**：长期价值投资关注企业的内在价值，ESG投资关注企业的外部影响。
- **策略**：长期价值投资注重企业盈利能力，ESG投资注重企业的社会和环境责任。

def calculate_esg_score(environment, social, governance):
    # 环境评分权重为40%，社会评分权重为30%，治理评分权重为30%
    total_score = environment * 0.4 + social * 0.3 + governance * 0.3
    return total_score

## 3.2 长期价值评估模型
### 3.2.1 模型概述
- **模型目标**：评估企业的长期价值，预测未来现金流。
- **公式**：
  $$ \text{长期价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} $$
  其中，$r$为折现率，$n$为预测年数。

### 3.2.2 代码实现
```python
def calculate_long_term_value(cash_flows, discount_rate, years):
    ltv = 0
    for t in range(years):
        ltv += cash_flows[t] / (1 + discount_rate) ** (t + 1)
    return ltv

# 示例数据
cash_flows = [100, 120, 150, 180]  # 每年的现金流
discount_rate = 0.08                # 折现率
years = 4                           # 预测年数

ltv = calculate_long_term_value(cash_flows, discount_rate, years)
print(f"长期价值：{ltv}")
```

import pandas as pd

def main():
    # 示例数据
    data = {
        '公司': ['A', 'B', 'C'],
        '环境': [85, 70, 90],
        '社会': [75, 85, 65],
        '治理': [80, 70, 90]
    }
    df = pd.DataFrame(data)
    
    # 计算ESG评分
    df['ESG评分'] = df['环境'] * 0.4 + df['社会'] * 0.3 + df['治理'] * 0.3
    
    # 计算长期价值
    cash_flows = [100, 120, 150, 180]
    discount_rate = 0.08
    ltv = sum(cash_flows[t] / (1 + discount_rate) ** (t + 1) for t in range(4))
    
    print("ESG评分结果：")
    print(df[['公司', 'ESG评分']])
    print(f"\n长期价值：{ltv}")

if __name__ == "__main__":
    main()
