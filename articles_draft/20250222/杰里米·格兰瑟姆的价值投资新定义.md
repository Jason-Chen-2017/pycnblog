## 第一部分：价值投资新定义的背景与核心概念

### 第1章：价值投资的起源与演变

#### 1.1 价值投资的起源

价值投资是一种以基本面分析为基础的投资策略，起源于20世纪初。其核心理念是通过分析公司的财务状况、行业地位和未来前景，寻找市场价格低于其内在价值的标的资产进行投资。

##### 1.1.1 价值投资的定义与核心理念

- **定义**：价值投资强调买入被市场低估的资产，长期持有，等待其价值回归。
- **核心理念**：
  1. 质量优先：选择具有强大财务状况和竞争优势的公司。
  2. 价格敏感：关注市场价格与内在价值的差异。
  3. 长期视角：耐心持有，等待市场重新认识其价值。

##### 1.1.2 格兰瑟姆在价值投资中的地位

杰里米·格兰瑟姆是价值投资的重要代表人物之一，他是本杰明·格雷厄姆的学生，继承和发展了价值投资理论，提出了许多创新性的投资策略。

##### 1.1.3 价值投资的发展历程

价值投资从最初的“烟屁股”策略（即寻找被市场忽视的低增长公司）逐渐发展为更加多样化的策略，包括寻找成长型公司、防御性公司等。

#### 1.2 价值投资新定义的背景

##### 1.2.1 当前金融市场的新特点

- **全球化**：市场的波动性和复杂性增加。
- **量化投资**：越来越多的投资者采用量化模型进行投资决策。
- **技术驱动**：大数据、人工智能等技术的应用改变了投资方式。

##### 1.2.2 传统价值投资的局限性

- **信息不对称**：传统分析难以捕捉实时市场变化。
- **效率低下**：手动分析耗时且成本高。
- **可扩展性差**：难以应对大规模数据和复杂场景。

##### 1.2.3 新定义的必要性与意义

- **适应性**：新定义将传统价值投资与现代量化方法结合，适应市场变化。
- **效率提升**：通过量化分析提高投资决策的效率和准确性。
- **可扩展性**：新方法适用于更大规模和更复杂的投资场景。

## 第二部分：格兰瑟姆新定义的数学模型与算法原理

### 第3章：算法原理讲解

#### 3.1 算法流程

1. 数据收集：获取标的资产的财务数据、市场数据等。
2. 数据预处理：清洗和标准化数据。
3. 特征提取：提取关键量化指标（如市盈率、市净率、股息率等）。
4. 模型训练：构建多因子模型，计算内在价值。
5. 结果输出：生成投资建议或信号。

#### 3.2 数学模型与公式

##### 3.2.1 核心公式

$$ \text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$

其中，\( CF_t \) 为第 \( t \) 年的现金流，\( r \) 为贴现率。

##### 3.2.2 示例

假设某公司未来5年的现金流分别为10、12、15、18、20，贴现率 \( r = 8\% \)。

计算内在价值：

$$ \text{内在价值} = \frac{10}{1.08} + \frac{12}{1.08^2} + \frac{15}{1.08^3} + \frac{18}{1.08^4} + \frac{20}{1.08^5} $$

import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(cash_flow / (1 + discount_rate) ** t for t, cash_flow in enumerate(cash_flows))

# 示例数据
