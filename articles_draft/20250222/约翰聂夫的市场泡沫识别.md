## 第1章 市场泡沫的定义与历史案例

### 1.1 市场泡沫的定义与特征
市场泡沫是指资产价格在短期内急剧上涨，远远超过其内在价值的现象。其特征包括价格虚高、交易量激增和市场情绪过热。

### 1.2 历史案例分析
- **郁金香泡沫**：17世纪荷兰的郁金香狂热，价格在短时间内暴涨，最终暴跌。
- **互联网泡沫**：20世纪90年代末，互联网公司的股票价格虚高，最终泡沫破裂导致市场崩盘。
- **2008年金融危机**：次贷危机引发的全球金融危机，暴露了市场的过度投机行为。

### 1.3 约翰·聂夫的投资理念
- **价值投资**：聂夫强调投资于具有持续盈利能力且估值合理的公司。
- **逆向投资**：在市场恐慌时寻找被低估的资产，避免追涨杀跌。
- **长期持有**：注重长期投资，避免频繁交易以减少成本。

## 第2章 市场泡沫识别的核心概念与联系

### 2.1 市场泡沫的形成机制
- **心理因素**：投资者的贪婪和恐惧导致价格波动。
- **市场行为**：投资者的羊群效应和情绪化决策。
- **市场结构**：市场的流动性和信息不对称影响泡沫的形成。

### 2.2 投资者心理与市场波动
- **认知偏差**：投资者的过度自信和确认偏差导致错误决策。
- **情绪波动**：贪婪和恐惧情绪推动市场价格偏离理性区间。
- **社会影响**：市场参与者的相互影响加剧了泡沫的形成。

### 2.3 约翰·聂夫的市场分析框架
- **基本面分析**：通过财务指标评估公司的内在价值。
- **相对估值法**：比较同类资产的估值差异。
- **市场情绪指标**：利用成交量、换手率等指标判断市场热度。

## 第3章 约翰·聂夫的市场泡沫识别算法原理

### 3.1 市盈率（P/E）计算
- **公式**：$$P/E = \frac{股价}{每股收益}$$
- **解读**：P/E低于行业平均水平可能表明低估。

### 3.2 市盈率增长比（PEG）计算
- **公式**：$$PEG = \frac{P/E}{净利润增长率}$$
- **解读**：PEG小于1通常被视为合理估值。

### 3.3 股息率计算
- **公式**：$$股息率 = \frac{每股股息}{股价} \times 100\%$$
- **解读**：股息率过高可能暗示股价被高估。

### 3.5 Python代码实现
```python
def calculate_pe(stock_price, eps):
    return stock_price / eps

def calculate_peg(pe, growth_rate):
    if growth_rate == 0:
        return float('inf')
    return pe / growth_rate

def calculate_dividend_yield(dividend, stock_price):
    return (dividend / stock_price) * 100

# 示例数据
stock_price = 50
eps = 5
growth_rate = 10
dividend = 2

pe = calculate_pe(stock_price, eps)
peg = calculate_peg(pe, growth_rate)
dividend_yield = calculate_dividend_yield(dividend, stock_price)

print(f"PE: {pe}, PEG: {peg}, 股息率: {dividend_yield}%")
```
