```python
def pete_strategy(data):
    import pandas as pd
    import numpy as np

    # 数据清洗
    df = pd.DataFrame(data)
    df.dropna()
    df = df[df['region'] != '']

    # 特征提取
    features = ['score', 'region']
    df_features = df[features]

    # 权重计算
    weights = {'score': 0.7, 'region': 0.3}
    df_weighted = df_features * weights

    # 总分计算
    total_scores = df_weighted.sum(axis=1)
    df['total_score'] = total_scores

    return df
```

#### 3.4 数学模型与公式
- **权重分配公式**：
  $$ total\_score = 0.7 \times score + 0.3 \times region\_score $$
