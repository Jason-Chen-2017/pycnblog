## 第一部分: 格雷厄姆特价股票策略基础

### 第1章: 格雷厄姆投资理论与数字市场成熟度

#### 1.1 格雷厄姆投资理论的核心思想
格雷厄姆是价值投资之父，其核心思想是寻找市场价格低于内在价值的股票，即“便宜货”。他认为市场情绪波动会导致短期价格偏离长期价值，投资者应以基本面分析为基础，寻找被低估的投资标的。

- **核心概念**：
  - 内在价值：股票的真实价值，基于公司盈利能力、资产质量等因素计算。
  - 市场价格：市场参与者情绪和交易行为决定的价格。
  - 低估股票：市场价格 < 内在价值。

#### 1.2 数字市场成熟度的定义与分类
数字市场成熟度是指市场参与者、交易机制、信息透明度等方面的完善程度。根据市场特征，可将数字市场分为以下三类：

- **传统数字市场**：如传统股票市场，参与者成熟，信息透明度高。
- **新兴数字市场**：如加密货币市场，参与者多为散户，市场波动剧烈。
- **前沿数字市场**：如新兴区块链项目市场，交易机制不完善，信息不对称严重。

#### 1.3 数字市场成熟度的影响
- **传统市场**：市场机制成熟，适合格雷厄姆策略长期投资。
- **新兴市场**：市场波动大，策略需调整参数。
- **前沿市场**：信息不透明，策略需谨慎使用。

### 第2章: 格雷厄姆策略的数学模型与算法原理

#### 2.1 格雷厄姆策略的核心公式
- **市净率（P/B）**：$$P/B = \frac{\text{股价}}{\text{每股净资产}}$$
- **市盈率（P/E）**：$$P/E = \frac{\text{股价}}{\text{每股收益}}$$
- **内在价值计算**：$$\text{内在价值} = \text{净利润} \times \text{合理市盈率}$$

#### 2.3 算法实现代码

```python
import pandas as pd

def calculate_pb(stock_data):
    return stock_data['price'] / stock_data['book_value']

def calculate_pe(stock_data):
    return stock_data['price'] / stock_data['eps']

def gray_gram_strategy(stock_data, industry_avg_pb, industry_avg_pe):
    stock_data['pb_ratio'] = calculate_pb(stock_data)
    stock_data['pe_ratio'] = calculate_pe(stock_data)
    stock_data['below_avg_pb'] = stock_data['pb_ratio'] < industry_avg_pb
    stock_data['below_avg_pe'] = stock_data['pe_ratio'] < industry_avg_pe
    return stock_data[stock_data['below_avg_pb'] & stock_data['below_avg_pe']]
```
