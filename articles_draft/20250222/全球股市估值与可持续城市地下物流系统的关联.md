### 第3章: 全球股市估值的核心概念与模型

#### 3.1 股市估值的基本原理
##### 3.1.1 股票价值的评估方法
- 市盈率（P/E）：股价与每股收益的比率。
- 市净率（P/B）：股价与每股净资产的比率。
- 现金流折现模型：将未来现金流折现为当前价值。

#### 3.2 股市估值的数学模型
##### 3.2.1 市盈率模型
- 公式：P/E = 市场价 / 每股收益
- 应用：评估企业盈利能力与市场预期。

##### 3.2.2 市净率模型
- 公式：P/B = 市场价 / 每股净资产
- 应用：评估企业资产质量。

##### 3.2.3 现金流折现模型
- 公式：企业价值 = 现金流 / 折现率
- 应用：评估企业未来现金流的现值。

### 第4章: 可持续城市地下物流系统的原理与特征

#### 4.1 物流系统的核心原理
##### 4.1.1 货物运输的优化算法
- 路径优化：通过算法找到最优运输路径。
- 车辆调度：合理分配运输资源。

#### 4.2 物流系统优化的数学模型
##### 4.2.1 路径优化模型
- 公式：min ∑(距离) → 约束条件：满足货物运输需求。
- 应用：降低物流成本，提高效率。

##### 4.2.2 资源分配模型
- 公式：max ∑(资源利用效率) → 约束条件：资源限制。
- 应用：合理分配物流资源，提高整体效率。

def optimize_path(start, end, nodes):
    graph = nx.DiGraph()
    for node in nodes:
        graph.add_edge(node['from'], node['to'], weight=node['cost'])
    return nx.shortest_path(graph, start, end, weight='weight')
