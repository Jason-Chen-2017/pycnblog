## 第一部分：背景介绍

### 第1章：常识投资的基本概念

#### 1.1 什么是常识投资
常识投资是基于对公司基本面和行业趋势的深入分析，结合长期投资和分散投资策略的一种投资方法。其核心理念是通过持有优质资产，长期获得稳定的收益。

#### 1.2 彼得林奇的投资哲学
彼得林奇强调：
1. **长期投资**：避免频繁交易，关注企业的长期价值。
2. **价值投资**：寻找被市场低估的公司。
3. **分散投资**：通过投资不同行业和公司降低风险。

#### 1.3 复杂市场的现状
复杂市场具有高波动性、不确定性增强、经济周期变化快等特点，对投资者的决策能力提出更高要求。

---

### 第2章：复杂市场环境下的投资挑战

#### 2.1 投资者在复杂市场中的常见误区
1. **过度交易**：频繁买卖导致交易成本增加。
2. **情绪化决策**：受市场波动影响，做出非理性决策。
3. **忽视风险**：过度关注收益，忽视潜在风险。

#### 2.2 常识投资在复杂市场的优势
1. **长期视角**：减少短期波动的干扰。
2. **分散风险**：通过多元化投资降低市场波动的影响。
3. **价值导向**：在市场低迷时发现优质资产。

## 第二部分：常识投资的核心原理

### 第3章：常识投资的核心原理

#### 3.1 投资决策的逻辑框架
1. **设定明确的投资目标**：收益目标、风险承受能力。
2. **选择合适的投资策略**：长期持有、分散投资。
3. **构建合理投资组合**：根据目标分配资产权重。

#### 3.2 彼得林奇的选股方法
1. **基本面分析**：分析公司的财务状况、行业地位。
2. **估值指标**：市盈率、市净率等。
3. **竞争优势**：公司的核心竞争力。

#### 3.3 投资组合优化的数学模型

##### 3.3.1 现金流贴现模型（DCF）

$$

```python
import pandas as pd
import numpy as np

def calculate_return(prices):
    return prices.pct_change().cumprod()

def calculate_risk(returns):
    return returns.std()

# 示例数据
prices = pd.DataFrame({
    'stock1': [100, 110, 105, 120],
    'stock2': [80, 90, 95, 100]
})

returns = calculate_return(prices)
risk = calculate_risk(returns)
print("回报:", returns)
print("风险:", risk)
```
