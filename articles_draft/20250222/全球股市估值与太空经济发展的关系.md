### 1. 背景介绍

#### 1.1 全球股市估值的背景

全球股市估值是衡量市场整体表现的重要指标，包括市场资本总额、市盈率（P/E比率）和市净率（P/B比率）。这些指标反映了投资者对市场的信心和对经济前景的预期。

#### 1.2 太空经济发展的背景

太空经济包括卫星通信、太空探索和商业航天等领域。随着技术进步，太空经济的市场规模持续扩大，吸引了大量投资。SpaceX和Blue Origin等公司的崛起，推动了太空经济的快速发展。

#### 1.3 问题解决

通过分析太空经济的投资活动，可以发现这些投资如何影响股市估值。例如，成功发射卫星可能会提升相关公司的股价，进而影响整体股市估值。反之，股市的波动也可能影响太空公司的融资能力。

#### 1.4 边界与外延

全球股市估值的范围涵盖主要市场，而太空经济则涉及技术和资源等多个方面。理解两者的边界有助于明确分析范围，避免混淆。

```python
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
```

```python
data = pd.read_csv('stock_data.csv')
data = data.dropna()
X = data[['revenue', 'profit']]
y = data['valuation']

# 模型构建
model = LinearRegression()
model.fit(X, y)

# 可视化
plt.scatter(X, y, alpha=0.5)
plt.plot(X, model.predict(X), color='red')
plt.xlabel('Revenue and Profit')
plt.ylabel('Valuation')
plt.title('Stock Valuation vs. Financials')
plt.show()
```
