## 第一部分：背景介绍

### 第1章：价值投资的定义与核心概念

#### 1.1 价值投资的背景与问题背景

价值投资是一种以基本面分析为基础的投资策略，其核心在于寻找市场定价低于其内在价值的证券。本章将从投资历史的角度，分析传统投资方法的局限性，以及价值投资如何应运而生。

- 1.1.1 传统投资方法的局限性
  - 基于市场情绪的投资方法难以长期稳定盈利。
  - 缺乏对证券内在价值的深入分析，容易受到市场波动影响。

- 1.1.2 价值投资的兴起
  - 格雷厄姆与戴维斯的贡献。
  - 价值投资的核心问题：如何通过基本面分析发现市场低估的证券。

- 1.1.3 问题的边界与外延
  - 价值投资的适用场景：稳定、低波动的市场环境。
  - 价值投资的局限性：周期性行业的波动性较大。

#### 1.2 格雷厄姆的投资哲学

- 核心概念：安全边际与市场先生。
- 基本属性对比表：

| 概念       | 定义                                                                 | 特性                              |
|------------|----------------------------------------------------------------------|-----------------------------------|
| 安全边际   | 证券市场价与内在价值之间的差额。                                       | 提供缓冲空间，降低投资风险。     |
| 市场先生    | 比喻市场波动的因素，投资者应与市场先生博弈而非对抗。                 | 心理因素主导，非基本面因素。     |

- 概念结构：安全边际 = 内在价值 - 市场价；市场先生 = 市场波动的代表。

## 第二部分：价值投资的核心概念与联系

### 第2章：安全边际与市场先生

#### 2.1 安全边际的数学模型

- 格雷厄姆的安全边际公式：
  $$
  \text{安全边际} = \text{内在价值} - \text{市场价格}
  $$

- 内在价值的计算公式：
  $$
  \text{内在价值} = \frac{\text{年收益}}{\text{折现率} - \text{增长率}}
  $$

  例如，假设年收益为100，折现率为10%，增长率=0，则内在价值为1000。

#### 2.2 市场先生的模型分析

- 市场先生的随机游走模型：
  $$
  \text{市场价格} = \text{内在价值} + \epsilon
  $$
  其中，$\epsilon$代表市场波动。

  - $\epsilon$为正：市场价格高于内在价值。
  - $\epsilon$为负：市场价格低于内在价值。

- Python实现代码示例：

```python
def calculate_intrinsic_value(annual_profit, discount_rate, growth_rate):
    return annual_profit / (discount_rate - growth_rate)

def screen_stocks(stocks, max_pe_ratio):
    return [stock for stock in stocks if stock.pe_ratio <= max_pe_ratio]

def graham_strategy(stocks, discount_rate=0.1):
    selected_stocks = screen_stocks(stocks, max_pe_ratio=15)
    for stock in selected_stocks:
        iv = calculate_intrinsic_value(stock.annual_profit, discount_rate, 0)
        margin = iv - stock.price
        if margin > 0:
            print(f"{stock.name}: 内在价值 {iv}, 安全边际 {margin}")
    return selected_stocks
```

#### 5.2 核心代码实现

- 价值投资策略实现：

```python
import pandas as pd
import numpy as np

class Stock:
    def __init__(self, name, price, pe_ratio, annual_profit):
        self.name = name
        self.price = price
        self.pe_ratio = pe_ratio
        self.annual_profit = annual_profit

def calculate_intrinsic_value(stock, discount_rate=0.1):
    return stock.annual_profit / (discount_rate - 0)

def graham_investment_strategy(stocks):
    selected = []
    for stock in stocks:
        iv = calculate_intrinsic_value(stock)
        margin = iv - stock.price
        if margin > 0:
            selected.append(stock)
    return selected

# 示例数据
stocks = [
    Stock("AAPL", 150, 10, 50),
    Stock("MSFT", 200, 12, 60),
    Stock("GOOGL", 250, 15, 70)
]

selected_stocks = graham_investment_strategy(stocks)
for stock in selected_stocks:
    print(f"{stock.name}: 内在价值 {calculate_intrinsic_value(stock)}, 安全边际 {calculate_intrinsic_value(stock) - stock.price}")
```
