### 第1章：芒格的“智者圈”理论

#### 1.1 “智者圈”理论的背景与核心概念

“智者圈”理论由查理·芒格提出，是一种基于认知边界的决策框架。其核心思想是：人类的认知是有边界的，决策者需要在自己的知识领域内构建一个“智者圈”，并通过不断学习和实践来扩大和优化这个圈层。以下是“智者圈”理论的核心要素对比表：

| 属性        | 描述                                         |
|-------------|----------------------------------------------|
| 知识边界     | 决策者知识的局限性                           |
| 学习策略     | 通过学习和经验扩展知识边界                   |
| 决策框架     | 基于知识边界构建的决策模型                   |
| 优化目标     | 提高决策的准确性和效率                       |

from qiskit import QuantumCircuit, Aer, execute

def quantum_expert_system():
    # 定义量子电路
    qc = QuantumCircuit(2, 2)
    qc.h(0)
    qc.cx(0, 1)
    qc.measure_all()
    # 模拟器
    simulator = Aer.get_backend('qasm_simulator')
    job = execute(qc, simulator)
    result = job.result()
    return result.get_counts()
