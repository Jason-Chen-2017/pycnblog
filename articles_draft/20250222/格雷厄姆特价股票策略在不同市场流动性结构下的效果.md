## 第一部分: 背景介绍

### 第1章: 格雷厄姆投资理论与市场流动性

#### 1.1 格雷厄姆投资理论的核心思想

格雷厄姆是价值投资的鼻祖，他的投资理论强调以低于内在价值的价格购买股票。以下是格雷厄姆策略的核心思想：

- **价值投资**: 寻找市场价格低于内在价值的股票，长期持有，等待市场回归理性。
- **安全边际**: 通过购买价格显著低于内在价值的股票，降低投资风险。
- **逆向投资**: 在市场恐慌时寻找低估股票，在市场狂热时保持谨慎。

#### 1.2 市场流动性结构的基本概念

市场流动性是指资产在市场中迅速转化为现金的能力。以下是不同市场流动性结构的特点：

- **高流动性市场**: 交易量大，买卖价差小，市场深度高。
- **低流动性市场**: 交易量小，买卖价差大，市场深度低。
- **混合流动性市场**: 不同时间段或不同资产类别的流动性表现不一。

#### 1.3 格雷厄姆策略与市场流动性的关系

格雷厄姆策略的实施效果受到市场流动性的影响：

- **高流动性市场**: 价格波动小，交易机会多，但竞争激烈，低估股票难以长期持有。
- **低流动性市场**: 价格波动大，交易机会少，但可能存在长期低估股票。
- **混合流动性市场**: 需要根据不同时间段或资产类别调整策略。

#### 5.2 核心代码实现

以下是格雷厄姆策略的Python实现代码：

```python
import pandas as pd
import numpy as np

def calculate_value(stock_data):
    # 计算内在价值
    intrinsic_value = stock_data['eps'] * 8.5
    return intrinsic_value

def graham_strategy(stock_data, market_price):
    # 格雷厄姆策略筛选
    margin_of_safety = (calculate_value(stock_data) - market_price) / calculate_value(stock_data)
    return margin_of_safety

# 示例数据
data = {
    'eps': [10, 15, 20, 25],
    'market_price': [50, 70, 80, 100]
}
stock_data = pd.DataFrame(data)

# 计算并筛选股票
margin_of_safety = graham_strategy(stock_data, stock_data['market_price'])
print(margin_of_safety)
```
