#### 1.2 巴菲特与芒格的投资理念  
巴菲特和芒格的投资理念以价值投资和长期视角为核心。巴菲特强调寻找具有持续竞争优势的企业，芒格则倡导多元思维模型，以避免决策偏差。两人均意识到通货膨胀对投资的影响，并开发了一系列对冲策略。

#### 1.3 通货膨胀对冲策略的重要性  
在通货膨胀环境下，传统固定收益投资（如债券）往往无法跑赢通胀，导致实际收益为负。因此，寻找能够抵御通货膨胀的资产配置至关重要。

### 第3章: 通货膨胀对冲的数学模型与公式  

#### 3.1 通货膨胀调整的现值计算  
现值公式用于计算通货膨胀调整后的资产价值：  
$$ PV = \frac{FV}{(1 + r)^n} $$  
其中，$PV$ 为现值，$FV$ 为未来价值，$r$ 为通货膨胀率，$n$ 为时间期限。

#### 3.2 资产回报率与通货膨胀的关系  
资产回报率公式：  
$$ R = \frac{P_{t+1} - P_t}{P_t} $$  
其中，$R$ 为资产回报率，$P_t$ 和 $P_{t+1}$ 分别为当前和未来的价格。

#### 3.3 巴菲特-芒格模型的数学推导  
巴菲特-芒格模型通过结合资产回报率和通货膨胀率，优化投资组合以最大化实际收益。模型假设：  
1. 资产类别间的回报率独立。  
2. 通货膨胀率 $r$ 为已知或可估计的参数。  
3. 投资组合的权重通过优化算法确定。

#### 5.2 核心实现代码  

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 示例数据：不同资产类别在通货膨胀周期中的表现
assets = ['股票', '债券', '房地产']
returns = {'股票': [0.1, 0.05, 0.15],
           '债券': [0.02, 0.03, 0.04],
           '房地产': [0.08, 0.12, 0.06]}

# 计算通货膨胀调整后的回报率
def inflation_adjusted_return(returns, inflation_rate):
    adjusted_returns = {}
    for asset in returns:
        adjusted_returns[asset] = []
        for r in returns[asset]:
            adjusted = r - inflation_rate
            adjusted_returns[asset].append(adjusted)
    return adjusted_returns

# 示例通货膨胀率为2%
inflation_rate = 0.02
adjusted_returns = inflation_adjusted_return(returns, inflation_rate)

# 绘制调整后的回报率分布
data = pd.DataFrame(adjusted_returns)
data.T.plot(kind='bar', stacked=True, figsize=(10,6))
plt.title('通货膨胀调整后的资产回报率')
plt.show()
```
