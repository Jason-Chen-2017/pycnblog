  耐心资本理念起源于彼得林奇的投资实践，强调长期持有优质资产，避免频繁交易。

  | 交易频率     | 极低                              | 高频                            |
  | 风险承受能力 | 较高                              | 较低                            |

### 1.2 彼得林奇与耐心资本的关系

  彼得林奇是美国著名投资家，以其长期投资策略闻名。他强调深入研究和长期持有优质股票。

  耐心资本是彼得林奇策略的核心，强调通过长期持有优质资产实现财富增长。

  通过公式计算，耐心资本的增长是指数级的，远超短期投资的线性增长。

## 第3章：耐心资本的算法原理

### 3.1 耐心资本的算法概述
- **3.1.1 耐心资本的基本算法**  
  算法基于复利计算，模拟长期投资收益。

- **3.1.3 耐心资本的复杂度分析**  
  算法复杂度较低，主要为O(n)，适合长期模拟。

### 3.2 耐心资本的实现步骤
- **3.2.1 算法输入与输出**  
  输入：本金P，年增长率r，时间t；输出：终值A。

- **3.2.2 算法实现的详细步骤**  
  1. 初始化本金P。  
  2. 计算每期收益并更新本金。  
  3. 循环t次，计算终值A。

- **3.2.3 算法实现的注意事项**  
  确保计算精度，避免浮点数误差。

### 3.3 耐心资本的代码实现
```python
def compound_growth(principal, rate, time):
    amount = principal
    for _ in range(time):
        amount *= (1 + rate)
    return amount

# 示例
P = 1000
r = 0.1
t = 30
result = compound_growth(P, r, t)
print(f"终值为：{result:.2f}元")
```
