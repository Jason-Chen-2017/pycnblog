# 第二部分：市场估值指标的核心概念与联系

## 第2章：市场估值指标的核心概念

### 2.1 核心概念与原理

- **2.1.1 市场估值指标的定义与分类**
  - 估值指标的定义：衡量企业价值的工具。
  - 常见分类：市盈率、市净率、股息率等。

- **2.1.2 市盈率（P/E）的计算与意义**
  - 市盈率公式：$$ P/E = \frac{\text{股票价格}}{\text{每股收益}} $$
  - 市盈率的意义：衡量企业价格相对于收益的高低。

- **2.1.3 市净率（P/B）的计算与意义**
  - 市净率公式：$$ P/B = \frac{\text{股票价格}}{\text{每股净资产}} $$
  - 市净率的意义：衡量企业价格相对于资产的高低。

- **2.1.4 股息率的计算与意义**
  - 股息率公式：$$ \text{股息率} = \frac{\text{每股股息}}{\text{股票价格}} \times 100\% $$
  - 股息率的意义：衡量股票分红能力。

### 2.2 核心概念的属性特征对比

- **2.2.1 市盈率与市净率的对比分析**
  - 计算公式对比：市盈率基于收益，市净率基于资产。
  - 适用场景：市盈率适用于盈利稳定的公司，市净率适用于净资产较多的公司。

- **2.2.2 股息率与股息支付率的对比分析**
  - 股息支付率：$$ \text{股息支付率} = \frac{\text{每股股息}}{\text{每股净利润}} \times 100\% $$
  - 股息率与股息支付率的区别：股息率衡量分红能力，股息支付率衡量分红意愿。

### 5.2 核心代码实现

- **5.2.1 估值指标计算模块**
  ```python
  import pandas as pd

  # 示例数据
  data = {
      '股票名称': ['A', 'B', 'C'],
      '股票价格': [50, 60, 70],
      '每股收益': [5, 6, 7],
      '每股净资产': [20, 25, 30],
      '每股股息': [2, 3, 4]
  }
  df = pd.DataFrame(data)

  # 计算估值指标
  df['市盈率'] = df['股票价格'] / df['每股收益']
  df['市净率'] = df['股票价格'] / df['每股净资产']
  df['股息率'] = (df['每股股息'] / df['股票价格']) * 100

  print(df)
  ```

- **5.2.2 可视化分析模块**

  import matplotlib.pyplot as plt

  plt.plot(df['股票名称'], df['市净率'], label='市净率')
  plt.xlabel('股票名称')
  plt.ylabel('指标值')
