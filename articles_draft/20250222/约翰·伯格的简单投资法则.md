## 第1章: 投资的基础概念

### 1.1 投资的基本定义
- 1.1.1 投资的定义与分类  
  投资是指将资金投入到某个项目或资产中，以期获得未来收益的行为。投资可以分为短期投资和长期投资，也可以分为实物投资和金融投资。

- 1.1.2 投资的基本原则  
  投资的核心原则包括分散投资、长期持有、价值投资和成本控制。

- 1.1.3 投资与投机的区别  
  投资注重长期价值，而投机则追求短期价格波动的利润。

### 1.2 约翰·伯格的生平简介
- 1.2.1 伯格的早年经历  
  约翰·伯格出生于美国宾夕法尼亚州，早年对投资产生了浓厚的兴趣。

- 1.2.2 伯格的职业生涯  
  伯格在投资领域有着丰富的经验，致力于研究简单而有效的投资策略。

- 1.2.3 伯格的投资理念  
  伯格主张长期持有优质资产，避免频繁交易，以降低交易成本和风险。

### 1.3 简单投资法则的核心思想
- 1.3.1 长期投资的重要性  
  长期投资能够摊薄成本，降低市场波动的影响。

- 1.3.2 分散投资的风险控制  
  通过分散投资不同资产类别，可以有效降低投资组合的整体风险。

- 1.3.3 价值投资的本质  
  价值投资注重购买具有内在价值的资产，而非关注短期价格波动。

## 第2章: 简单投资法则的核心概念

### 2.1 投资组合的构建原理
- 2.1.1 投资组合的定义  
  投资组合是指将多种资产按一定比例配置在一起的投资方式。

- 2.1.2 投资组合的风险与收益  
  投资组合的收益与风险是相互关联的，风险较高的组合通常具有较高的预期收益。

- 2.1.3 投资组合的优化方法  
  通过优化投资组合的资产配置，可以在风险可控的前提下，最大化预期收益。

### 2.2 简单投资法则的数学模型
- 2.2.1 投资组合的数学表达  
  投资组合的收益可以用期望收益来衡量，风险则可以用方差或标准差来表示。

- 2.2.2 风险与收益的量化分析  
  通过量化分析，可以更科学地评估不同投资组合的风险收益比。

- 2.2.3 投资组合的优化算法  
  简单投资法则通过长期持有和分散投资的方式，优化投资组合的风险收益比。

### 2.3 简单投资法则与现代投资组合理论的对比
- 2.3.1 现代投资组合理论的核心思想  
  现代投资组合理论强调通过分散投资降低风险，同时优化投资组合的收益。

- 2.3.2 简单投资法则的优势与劣势  
  简单投资法则的优势在于其简单易行，劣势在于其在极端市场条件下的表现可能不如复杂的投资策略。

- 2.3.3 两者的适用场景分析  
  简单投资法则适用于长期稳健的投资，而现代投资组合理论更适合复杂多变的市场环境。

import numpy as np
import pandas as pd

def optimize_portfolio(returns):
    # 计算协方差矩阵
    covariance_matrix = returns.cov()
    
    # 计算资产的权重
    weights = np.random.random(len(returns.columns))
    weights = weights / weights.sum()
    
    # 计算投资组合的收益和风险
    portfolio_return = np.dot(weights, returns.mean())
    portfolio_variance = np.dot(weights.T, np.dot(covariance_matrix, weights))
    
    return portfolio_return, np.sqrt(portfolio_variance)
