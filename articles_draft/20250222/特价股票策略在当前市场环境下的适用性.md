- 2.2.1 长期投资 vs. 短期投机

## 第三部分：算法原理讲解

### 第3章：特价股票策略的数学模型
#### 3.1 均值-方差模型
- 3.1.1 模型定义
  - 最优化投资组合，最小化风险，最大化收益。
- 3.1.2 数学公式
  - $$\text{方差} = \sigma^2 = \sum_{i=1}^{n} w_i^2 \sigma_i^2 + 2 \sum_{i=1}^{n} \sum_{j=i+1}^{n} w_i w_j \sigma_{ij}$$
- 3.1.3 应用实例
  - 使用均值-方差模型优化投资组合，降低风险。

#### 3.2 技术指标分析
- 3.2.1 移动平均线（MA）
  - $$MA_n = \frac{1}{n} \sum_{i=1}^{n} P_i$$
- 3.2.2 相对强弱指数（RSI）

#### 5.2 代码实现
- 示例代码：使用技术指标检测特价股票信号。
  ```python
  import pandas as pd
  import numpy as np

  def calculate_rsi(data, period=14):
      diff = data['收盘价'].diff().dropna()
      up = diff.where(diff >= 0, 0)
      down = diff.where(diff < 0, 0)
      rs = up.ewm(span=period, adjust=False).mean() / down.ewm(span=period, adjust=False).mean()
      rsi = 100 - (100 - (rs.rolling(1).mean() / 1))
      return rsi

  # 示例数据
  data = pd.DataFrame({'收盘价': np.random.rand(100) * 100})
  rsi = calculate_rsi(data)
  ```
