# 第1章: 格雷厄姆特价股票策略概述

## 1.1 格雷厄姆投资理论的核心思想

### 1.1.1 价值投资的基本概念

价值投资是一种以基本面分析为基础的投资策略，其核心在于寻找市场价格低于其内在价值的证券。格雷厄姆是价值投资的奠基人，他提出的“安全边际”概念强调在购买股票时，应关注其市场价格与内在价值之间的差异，以确保投资的安全性。

**公式：**
$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

### 1.1.2 格雷厄姆的选股标准

格雷厄姆提出的选股标准包括以下几个方面：

1. **低市盈率**：市盈率（P/E）低于市场平均水平。
2. **低市净率**：市净率（P/B）低于市场平均水平。
3. **高股息率**：股息率（Dividend Yield）高于市场平均水平。
4. **低于清算价值**：市场价格低于公司资产的清算价值。

### 1.1.3 特价股票的定义与特征

格雷厄姆认为，特价股票是指那些市场价格低于其内在价值的股票。这类股票通常具有以下特征：
- **低估性**：市场价格低于内在价值。
- **稳定性**：公司业绩稳定，财务状况健康。
- **防御性**：在市场波动中表现较为抗跌。

## 1.2 通胀预期的宏观经济影响

### 1.2.1 通胀预期的定义与测量

通胀预期是指市场参与者对未来通货膨胀率的预测。常用的测量方法包括：
- **问卷调查法**：通过向投资者发放问卷，收集对未来通胀的预期。
- **债券市场法**：通过长期债券收益率与短期债券收益率的差异（即泰勒规则）来估计通胀预期。
- **公众预期调查**：如美联储的通胀预期调查。

### 1.2.2 通胀预期对股市的宏观影响

通胀预期通过以下几个方面影响股市：
1. **利率政策**：通胀预期上升可能导致央行加息，进而影响股市估值。
2. **企业盈利**：通胀上升可能推高企业成本，压缩利润空间。
3. **消费者行为**：通胀预期可能影响消费者信心和支出，进而影响股市。

### 1.2.3 不同经济周期中的通胀预期变化

在不同的经济周期中，通胀预期表现出不同的特征：
- **经济衰退期**：通胀预期较低，甚至可能出现通缩预期。
- **经济复苏期**：通胀预期逐渐上升。
- **经济过热期**：通胀预期显著上升，甚至可能引发加息预期。
