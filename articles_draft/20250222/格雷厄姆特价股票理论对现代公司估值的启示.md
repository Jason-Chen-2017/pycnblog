### 1.1.2 格雷厄姆的价值投资理念
- **核心思想**：投资的本质是购买公司的一部分，而不是赌博。
- **安全边际**：买入价格低于内在价值，以确保投资的安全性。
- **长期视角**：关注企业的长期价值，而非短期市场波动。

### 1.1.3 特价股票理论的核心思想
- **低市盈率策略**：寻找市盈率低于市场平均水平的股票。

## 1.2 格雷厄姆特价股票理论的核心概念

### 1.2.1 内在价值的定义与计算
- **内在价值**：公司未来现金流的现值，是其真实价值的体现。
- **计算方法**：使用现金流折现模型（DCF）计算内在价值。

### 1.2.2 安全边际的理论基础
- **安全边际**：买入价格低于内在价值，以应对市场波动和不确定性。
- **安全边际的计算**：市场价格与内在价值的差距。

### 1.2.3 市场先生与投资者的关系
- **市场先生**：比喻市场情绪的波动性。
- **投资者的角色**：在市场低估时买入，高估时卖出。

## 1.3 格雷厄姆投资策略的关键要素

### 1.3.1 低市盈率策略
- **市盈率公式**：市盈率 = 股价 / 每股收益（EPS）。
- **策略优势**：寻找被市场低估的公司。

### 1.3.2 低市净率策略
- **市净率公式**：市净率 = 股价 / 每股净资产（BPS）。
- **策略优势**：关注资产质量较高的公司。

### 1.3.3 股息率分析
- **股息率公式**：股息率 = 每股股息（DIV） / 股价。
- **策略优势**：选择股息稳定的公司。

## 1.4 格雷厄姆理论的局限性与改进方向

# 第2章: 格雷厄姆特价股票理论的数学模型与公式

## 2.1 内在价值的计算公式

### 2.1.1 现金流折现模型（DCF）
- **公式**：
  $$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1+r)^t}$$
  其中，r为折现率，n为预测年数。

### 2.1.2 股权自由现金流模型
- **公式**：
  $$\text{股权价值} = \frac{\text{自由现金流}_\text{永续}}{r - g}$$
  其中，g为现金流增长率。

### 2.1.3 市盈率与市净率的比较
- **市盈率公式**：P/E = 股价 / EPS。
- **市净率公式**：P/B = 股价 / BPS。

## 2.2 安全边际的量化方法

### 2.2.1 安全边际的计算公式
- **公式**：
  $$\text{安全边际} = \text{内在价值} - \text{市场价格}$$

### 2.2.2 市场价格与内在价值的偏离度
- **偏离度公式**：
  $$\text{偏离度} = \frac{\text{市场价格} - \text{内在价值}}{\text{内在价值}} \times 100\%$$

### 2.2.3 安全边际的动态调整
- **动态调整公式**：
  $$\text{调整后安全边际} = \text{安全边际} \times (1 + \text{通胀率})$$

## 2.3 格雷厄姆筛选法的数学实现

### 2.3.1 筛选法的条件设定
- **条件1**：市盈率 < 市场平均市盈率。
- **条件2**：市净率 < 市场平均市净率。
- **条件3**：股息率 > 市场平均股息率。

### 2.3.3 筛选法的优缺点分析
