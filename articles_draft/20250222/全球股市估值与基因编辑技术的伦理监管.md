# 第2章: 全球股市估值的基础知识

## 2.1 股市估值的核心概念
### 2.1.1 股票估值的基本定义
股票估值是通过分析企业的财务状况、市场地位和行业前景，估算其内在价值的过程。

### 2.1.2 常用估值方法
- **市盈率（P/E）**：企业股价与每股收益的比率。
- **市净率（P/B）**：企业股价与每股净资产的比率。
- **现金流折现法（DCF）**：通过现金流预测企业价值。

### 2.1.3 影响股市估值的主要因素
- **宏观经济因素**：GDP增长率、利率、通货膨胀等。
- **行业因素**：行业周期、政策法规。
- **企业基本面**：盈利能力、财务状况、管理团队。

## 2.2 全球股市的现状与趋势
### 2.2.1 全球主要股市概况
- 美国：纳斯达克、纽约证券交易所。
- 欧洲：伦敦金融时报指数、法兰克福DAX指数。
- 亚洲：香港恒生指数、东京日经指数。

### 2.2.2 近年来股市估值的变化趋势
近年来，科技股的估值显著上升，尤其是人工智能、基因编辑等领域。

### 2.2.3 不同经济周期下的估值特点
在经济繁荣期，成长股估值较高；在衰退期，防御性股票更受青睐。

# 第3章: 基因编辑技术的伦理监管

## 3.1 基因编辑技术的基本原理
### 3.1.1 CRISPR-Cas9技术的工作机制
CRISPR-Cas9通过引导RNA与目标DNA序列配对，切割DNA双链，实现基因编辑。

### 3.1.2 其他基因编辑技术的简介
- **TALENs技术**：基于转录激活因子样效应核酸酶。
- **锌指核酸酶（ZFNs）**：通过锌指结构识别目标基因。

### 3.1.3 基因编辑技术的伦理争议
- **人类基因编辑**：可能导致基因歧视。
- **动物实验**：引发动物福利问题。
- **环境影响**：基因编辑生物可能破坏生态系统。

## 3.2 基因编辑技术的监管框架
### 3.2.1 国际层面的监管政策
- **美国**：FDA监管基因治疗产品。
- **欧盟**：严格的基因编辑监管法规。
- **中国**：加强基因编辑技术的伦理审查。

### 3.2.2 各国的监管差异与挑战
不同国家的法律法规和文化背景导致监管政策差异显著。

### 3.2.3 伦理审查的流程与标准
伦理审查委员会（IRB）负责评估基因编辑技术的伦理风险，确保符合伦理标准。
