## 第一部分：背景介绍

### 第1章：价值投资与风险投资的背景

#### 1.1 价值投资的起源与发展
- **1.1.1 价值投资的定义与核心理念**  
  价值投资是一种以基本面分析为基础的投资策略，强调购买被市场低估的资产。其核心理念是寻找市场价格低于内在价值的股票，长期持有以实现收益。格雷厄姆作为价值投资的鼻祖，提出了“安全边际”的概念，即市场价格与内在价值之间的差距。

- **1.1.2 格雷厄姆的贡献与影响**  
  格雷厄姆通过《证券分析》和《聪明的投资者》奠定了价值投资的理论基础。他的方法强调对企业的深入分析，尤其是关注财务指标如市盈率（P/E）和市净率（P/B），以寻找具有安全边际的投资机会。

- **1.1.3 风险投资的基本概念与特点**  
  风险投资主要指对高成长潜力企业的股权投资，具有高风险、高回报的特点。其核心在于识别具有创新能力和市场潜力的企业，通过长期持有分享其增长收益。然而，风险投资的高波动性要求投资者具备精准的判断能力和风险管理能力。

### 第2章：格雷厄姆特价股票理论的核心概念

#### 2.1 特价股票的定义与特征
- **2.1.1 特价股票的定义**  
  特价股票是指市场价格低于其内在价值的股票。这种股票通常具有较高的安全边际，适合长期持有。

- **2.1.2 特价股票的核心特征对比表**  
  以下是特价股票与其他类型股票的对比：

  | 特性         | 特价股票       | 非特价股票     |
  |--------------|----------------|----------------|
  | 市盈率       | 低于行业平均   | 高于或等于行业平均 |
  | 市净率       | 低于行业平均   | 高于或等于行业平均 |
  | 内在价值     | 高于市场价格   | 低于市场价格     |
  | 风险         | 较低           | 较高             |

#### 2.2 格雷厄姆投资策略的关键要素
- **2.2.1 市盈率与市净率分析**  
  格雷厄姆强调使用市盈率和市净率作为主要筛选指标。以下是市盈率和市净率的计算公式：

  $$ \text{市盈率} = \frac{\text{股价}}{\text{每股收益}} $$
  $$ \text{市净率} = \frac{\text{股价}}{\text{每股净资产}} $$

- **2.2.2 股票内在价值的计算公式**  
  格雷厄姆提出内在价值的计算方法：

  $$ \text{内在价值} = \frac{\text{每股收益} \times (4.5 \times \text{保留比率} + 10)}{市盈率} $$

- **2.2.3 风险承受能力与投资期限**  
  投资者应根据自身风险承受能力和投资期限选择适合的股票。长期投资者更适合持有特价股票，因为其内在价值的实现需要时间。

  ```python
  def calculate_intrinsic_value(stock_price, earnings_per_share):
      return stock_price / earnings_per_share

  def is_special_stock(stock_price, earnings_per_share, book_value_per_share):
      pe_ratio = stock_price / earnings_per_share
      pb_ratio = stock_price / book_value_per_share
      intrinsic_value = calculate_intrinsic_value(stock_price, earnings_per_share)
      return pe_ratio < 15 and pb_ratio < 2 and stock_price < intrinsic_value
  ```

  ```python
  import pandas as pd

  def main():
      # 读取股票数据
      df = pd.read_csv('stocks.csv')
      # 筛选低市盈率股票
      low_pe_stocks = df[df['P/E'] < 15]
      # 筛选低市净率股票
      low_pb_stocks = low_pe_stocks[low_pe_stocks['P/B'] < 2]
      # 计算内在价值
      low_pb_stocks['Intrinsic Value'] = low_pb_stocks['Price'] / low_pb_stocks['EPS']
      # 筛选特价股票
      special_stocks = low_pb_stocks[low_pb_stocks['Price'] < low_pb_stocks['Intrinsic Value']]
      # 输出结果
      print(special_stocks)
  ```
