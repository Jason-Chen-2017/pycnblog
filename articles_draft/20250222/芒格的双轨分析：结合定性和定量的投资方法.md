# 第一部分: 芒格的"双轨分析"概述

## 第1章: 芒格"双轨分析"的背景与核心理念

### 1.1 投资分析的双轨模式

#### 1.1.1 定性分析与定量分析的定义

定性分析关注企业非财务因素，如管理层能力、竞争优势和行业地位。定量分析则通过财务指标和估值模型评估企业价值。两者结合能更全面地评估投资标的。

#### 1.1.2 芒格双轨分析的提出背景

芒格提出双轨分析，旨在解决传统单一分析方法的局限性，通过结合定性和定量分析，提高投资决策的准确性和全面性。

#### 1.1.3 双轨分析在投资决策中的作用

双轨分析帮助投资者在决策中平衡感性与理性，避免单一分析的片面性，提高投资判断的准确性。

### 1.2 芒格的投资理念与方法

#### 1.2.1 芒格的"双轨分析"框架

双轨分析包括定性分析和定量分析两部分，前者关注企业内核，后者关注数据指标。

#### 1.2.2 定性分析的核心要素

定性分析关注管理层能力、竞争优势、行业地位和企业治理等方面。

#### 1.2.3 定量分析的关键指标

定量分析关注市盈率、ROE等财务指标。

### 1.3 双轨分析的逻辑结构

定性分析与定量分析相辅相成，共同构建投资决策的全面框架。

## 第7章: 核心实现代码

```python
import pandas as pd

def calculate_metrics(df):
    df['市盈率'] = df['股价'] / df['每股收益']
    df['ROE'] = df['净利润'] / df['股东权益']
    return df

# 示例数据
data = {
    '企业': ['公司A', '公司B'],
    '股价': [50, 60],
    '每股收益': [10, 15],
    '净利润': [50, 75],
    '股东权益': [50, 75]
}

df = pd.DataFrame(data)
df = calculate_metrics(df)
print(df)
```
