# 第4章: 数学公式与模型

## 4.1 格雷厄姆模型的数学公式
$$ V = \frac{E}{(D \times (1 - D))} $$

其中，V是内在价值，E是息税前利润，D是折现率。

## 4.2 优化公式
$$ V_{\text{优化}} = \frac{E}{(D \times (1 - D) \times (1 - t))} $$

其中，t是税率。

## 4.3 示例计算
假设E=100，D=0.05，t=0.2，

```python
import pandas as pd

def calculate_intrinsic_value(ebitda, discount_rate):
    return ebitda / (discount_rate * (1 - discount_rate))

def evaluate_social_impact(impact_score):
    return impact_score > 0.7

# 示例数据
data = {
    '公司': ['公司A', '公司B', '公司C'],
    'ebitda': [100, 150, 80],
    'discount_rate': [0.05, 0.06, 0.04],
    'impact_score': [0.8, 0.6, 0.7]
}

df = pd.DataFrame(data)

for index, row in df.iterrows():
    iv = calculate_intrinsic_value(row['ebitda'], row['discount_rate'])
    si = evaluate_social_impact(row['impact_score'])
    print(f"{row['公司']}的内在价值: {iv}")
    print(f"{row['公司']}的社会影响力评估: {si}")
    print('---')
```
