# 第二部分：彼得·林奇市场情绪判断方法的核心原理

## 2.1 市场情绪的类型与特征

### 2.1.1 情绪类型

- **多头情绪**：市场参与者乐观，买方力量强。
- **空头情绪**：市场参与者悲观，卖方力量强。
- **中性情绪**：市场参与者观望，买卖力量均衡。

### 2.1.2 情绪特征对比

下表对比了三种情绪的特征：

| 情绪类型 | 价格走势 | 交易量 | 市场参与度 |
|----------|----------|--------|------------|
| 多头     | 上涨     | 高     | 高          |
| 空头     | 下跌     | 高     | 低          |
| 中性     | 稳定     | 低     | 中          |

---

## 2.2 情绪指标的计算方法

### 2.2.1 指标的定义

情绪指标衡量市场情绪，公式为：

$$
\text{情绪指标} = \frac{\sum (\text{收盘价} - \text{开盘价})}{n}
$$

其中，n为交易日数量。

### 2.2.2 情绪强度的计算

情绪强度由以下公式计算：

$$
\text{强度} = \frac{\text{情绪指标}}{\text{波动率}}
$$

---

## 2.3 情绪拐点的识别

### 2.3.1 二次导数计算

拐点识别基于价格和情绪指标的二次导数：

$$
\frac{d^2}{dt^2} (\text{情绪指标}) = 0
$$

## 4.2 核心代码实现

```python
import pandas as pd
import matplotlib.pyplot as plt

def calculate_emotion_index(data):
    emotion_index = sum(data['close'] - data['open']) / len(data)
    return emotion_index

def plot_emotion(emotion_values):
    plt.plot(emotion_values, color='blue')
    plt.title('情绪指标走势')
    plt.xlabel('时间')
    plt.ylabel('情绪指标')
    plt.show()

# 示例数据
data = {
    'open': [100, 101, 102, 101, 100],
    'close': [101, 102, 103, 102, 101]
}
df = pd.DataFrame(data)
emotion_index = calculate_emotion_index(df)
plot_emotion([emotion_index] * 5)
```
