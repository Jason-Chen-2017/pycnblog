### 第1章: 全球股市估值与国际金融中心竞争的背景介绍

#### 1.1 全球股市估值的基本概念

##### 1.1.1 股市估值的定义与核心指标
股市估值是衡量一个市场整体价值的重要指标，主要包括市盈率（P/E）、市净率（P/B）等。这些指标反映了市场的整体健康状况和投资者信心。

##### 1.1.2 国际金融中心的定义与作用
国际金融中心是全球金融市场的重要枢纽，如纽约、伦敦、上海等。它们通过提供资金流动、定价和风险管理服务，影响全球经济。

##### 1.1.3 股市估值与国际金融中心的关联性
股市估值直接影响金融中心的吸引力，高估值可能意味着高风险，而合理的估值则能吸引更多投资者。

#### 1.2 问题背景与问题描述

##### 1.2.1 全球化背景下股市估值的变化
全球化促进了资本流动，但同时也带来了波动性，股市估值呈现出周期性变化。

##### 1.2.2 国际金融中心竞争的现状
主要金融中心之间的竞争日益激烈，如纽约和伦敦争夺全球资本市场的主导地位。

##### 1.2.3 股市估值与金融中心竞争的双向影响
高估值可能提升金融中心的吸引力，但也可能引发泡沫，进而影响其竞争力。

#### 1.3 问题解决与边界外延

##### 1.3.1 股市估值与金融中心竞争的解决路径
通过量化分析，找出影响估值的关键因素，优化金融中心的竞争力。

##### 1.3.2 问题的边界与外延分析
限定主要国际金融中心，考虑宏观经济因素，如GDP增长率、通货膨胀率等。

### 第3章: 股市估值的数学模型与公式

#### 3.1 股市估值的核心公式

##### 3.1.1 市盈率（P/E）的计算公式
$$ P/E = \frac{Stock Price}{Earnings Per Share} $$

##### 3.1.2 市净率（P/B）的计算公式
$$ P/B = \frac{Stock Price}{Book Value Per Share} $$

##### 3.1.3 其他估值指标
例如，EV/EBITDA = 企业价值 / 息税折旧及摊销前利润。

#### 3.2 股市估值与金融中心竞争力的关联模型

##### 3.2.1 股市估值与金融中心竞争力的多元回归模型

import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 数据加载
data = pd.read_csv('financial_centers.csv')

# 特征选择
X = data[['P/E', 'P/B', 'GDP_growth']]
y = data['Competitiveness']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测与评估
y_pred = model.predict(X)
print('均方误差:', mean_squared_error(y, y_pred))
