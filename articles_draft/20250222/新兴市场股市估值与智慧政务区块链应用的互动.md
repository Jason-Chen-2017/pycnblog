#### 1.1 新兴市场的经济特征
- **定义**：新兴市场是指那些经济快速增长、工业化程度较高、但尚未完全发达国家的市场，如中国、印度、巴西等。

  - 政府政策对经济影响显著

#### 1.2 新兴市场股市的独特性
- **市场规模**：新兴市场的股市规模通常介于发达国家与发展中国家之间。
- **投资者结构**：散户投资者占比较大，机构投资者相对较少。
- **流动性**：与发达国家市场相比，新兴市场股市的流动性较低。

#### 1.3 新兴市场股市与发达市场的对比

#### 2.1 估值的基本概念与方法
- **定义**：股市估值是指通过分析公司的基本面、市场环境等因素，确定其股票的合理价格。
- **传统方法**：市盈率（P/E）、市净率（P/B）、股息率等。
- **新兴市场特点**：需要考虑更高的风险溢价。

#### 2.2 新兴市场股市估值的特殊性

- **数据不完整性**：新兴市场的一些公司财务数据可能存在不透明性。
- **政策不确定性**：政府政策的突然变化可能对股市估值产生重大影响。

#### 2.3 新兴市场股市估值的主要影响因素
- **宏观经济因素**：GDP增速、通胀率、利率等。
- **行业结构因素**：新兴市场中某些行业（如科技、金融）可能具有更高的增长潜力。

### 第4章: 区块链技术的基本原理

#### 4.1 区块链的定义与特点
- **定义**：区块链是一种去中心化的分布式账本技术，通过密码学保证数据的安全性和不可篡改性。
- **特点**：
  - 去中心化：没有单一的控制节点。
  - 不可篡改性：数据一旦写入区块链，难以被修改。
  - 可追溯性：每笔交易都可以被追溯。

#### 4.2 区块链的核心技术
- **共识机制**：确保所有节点达成一致的技术，如工作量证明（PoW）、权益证明（PoS）等。
- **智能合约**：通过预设的程序自动执行合同条款，减少人工干预。
- **节点分布**：区块链网络中的节点负责存储和传播数据。

#### 4.3 区块链的共识机制
- **工作量证明（PoW）**：通过计算找到特定的哈希值来验证交易。
- **权益证明（PoS）**：根据节点持有的代币数量来决定其在网络中的权重。
- ** delegated Proof of Stake（dPoS）**：通过选举产生记账节点。

        self.index = index
        self.timestamp = timestamp
        self.data = data
        self.prev_hash = prev_hash
        self.hash = self.compute_hash()

    def compute_hash(self):
        import hashlib
        return hashlib.sha256(str(self.index) + str(self.timestamp) + str(self.data) + str(self.prev_hash)).hexdigest()

# 智能合约实现
