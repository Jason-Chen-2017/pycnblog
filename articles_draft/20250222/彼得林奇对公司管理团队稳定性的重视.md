### 第2章：团队稳定性核心概念

#### 2.1 团队稳定性定义与维度  
- 团队稳定性的定义：  
  - 团队稳定性是指团队成员的稳定性、目标一致性和协作效率的综合表现。  

- 关键维度：  
  - 人员稳定性：团队成员的离职率和保留情况。  
  - 目标一致性：团队成员对共同目标的认同和追求。  
  - 协作效率：团队内部的沟通与协作效率。  

- 彼得林奇视角下的团队稳定性特征：  
  - 团队成员之间的信任与合作。  
  - 领导层的战略一致性。  

#### 2.2 彼得林奇团队稳定性分析模型  
- 模型的核心要素：  
  - 团队结构：团队成员的角色和职责。  
  - 目标一致性：团队目标的明确性和一致性。  
  - 外部环境：市场环境和行业竞争。  
  - 内部协作：团队内部的沟通与合作效率。  

- 模型的数学表达：  
  $$稳定性指数 = \frac{人员稳定性 + 目标一致性 + 协作效率}{3}$$  

- 稳定性指数的分类：  
  - 高稳定性：指数 ≥ 0.8。  
  - 中稳定性：0.5 ≤ 指数 < 0.8。  
  - 低稳定性：指数 < 0.5。  

#### 2.3 团队稳定性与公司绩效的关系  
- 团队稳定性对财务绩效的影响：  
  - 稳定的管理团队能够制定长期战略，提高公司盈利能力。  

- 管理团队稳定性与公司股价的相关性：  
  - 稳定的管理团队通常会带来股价的稳定性。  

- 彼得林奇案例中的稳定性与投资回报分析：  
  - 通过分析彼得林奇投资的公司，验证团队稳定性与投资回报的相关性。

## 第三部分：团队稳定性评估与数学模型

### 第3章：团队稳定性评估模型

#### 3.1 团队稳定性评估指标  
- 人员变动率：$$人员变动率 = \frac{年度离职率}{平均员工数}$$  
- 目标一致性评估：基于团队目标的达成情况。  
- 协作效率评估：基于团队内部沟通与决策效率。  

#### 3.2 团队稳定性指数计算  
- 稳定性指数公式：  
  $$稳定性指数 = 0.4 \times 人员变动率 + 0.3 \times 目标一致性 + 0.3 \times 协作效率$$  

- 稳定性指数的分类：  
  - 高稳定性：指数 ≥ 0.8。  
  - 中稳定性：0.5 ≤ 指数 < 0.8。  
  - 低稳定性：指数 < 0.5。

import pandas as pd
import numpy as np

def calculate_stability_index(company_data):
   人员变动率 = company_data['年度离职率'] / company_data['平均员工数']
    目标一致性 = company_data['目标达成情况']
    协作效率 = company_data['协作效率评分']
    稳定性指数 = 0.4 * 人员变动率 + 0.3 * 目标一致性 + 0.3 * 协作效率
