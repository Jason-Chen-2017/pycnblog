## 第一章：巴菲特-芒格策略概述

### 1.1 巴菲特与芒格的投资哲学
- 巴菲特：价值投资之父，强调安全边际和长期持有。
- 芒格：多元思维模型，注重企业护城河和管理层素质。
- 投资哲学：寻找具有持续竞争优势的企业，长期投资。

### 1.2 价值投资的核心原则
- 买入低于内在价值的股票。
- 长期持有优质企业。
- 避免短期市场波动，关注企业基本面。

### 1.3 投资策略的核心要素
- 企业护城河：竞争优势，防止被替代。
- 管理层素质：诚信、能力、决策。
- 财务健康：ROE、现金流、债务状况。

## 第二章：巴菲特-芒格策略的理论基础

### 2.1 价值投资的理论基础
- 理论来源：格雷厄姆的价值投资理论。
- 核心假设：市场短期波动，长期趋向均值。
- 理论结构：安全边际 + 内在价值。

### 2.2 内在价值的计算方法
- **定义**：企业未来现金流的现值。
- **公式**：$$\text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n}$$
- **步骤**：预测现金流、确定折现率、计算终值。

### 2.3 安全边际的概念与应用
- **定义**：买入价格低于内在价值的折扣。
- **作用**：降低投资风险，应对市场波动。
- **计算**：$$\text{安全边际} = \text{内在价值} - \text{买入价格}$$

## 第三章：巴菲特-芒格策略在牛市中的表现

### 3.1 牛市环境下的投资机会
- 市场特征：价格高估，投资者情绪乐观。
- 投资机会：寻找低估企业，长期持有。

### 3.2 策略调整：牛市中的应对方法
- **避免高估值**：忽略短期高增长，关注长期价值。
- **增加防御性股票**：如公用事业、消费品。
- **定期再平衡**：调整投资组合，降低风险。

### 3.3 成功案例：可口可乐的长期投资
- 投资理由：强大的品牌、稳定的现金流、优秀的管理层。
- 表现：长期持有带来稳定收益。

## 第四章：巴菲特-芒格策略在熊市中的表现

### 4.1 熊市环境下的挑战
- 市场特征：价格低估，投资者情绪悲观。
- 策略挑战：如何在恐慌中找到机会。

### 4.2 策略调整：熊市中的应对方法
- **增加仓位**：利用低价买入优质资产。
- **关注现金流**：选择财务健康的企业。
- **长期持有**：避免频繁交易。

### 4.3 成功案例：巴菲特在1987年股灾后的投资
- 投资策略：利用股灾后的低价，买入 berkshire Hathaway。

## 第五章：巴菲特-芒格策略在新兴行业中的应用

### 5.1 新兴行业的特点
- 高增长、高风险、技术驱动。
- 竞争激烈，护城河不明显。

### 5.2 策略调整：新兴行业的应对方法
- **关注护城河**：寻找技术壁垒和品牌优势。
- **管理层考察**：选择有愿景和能力的领导者。
- **长期跟踪**：新兴行业变化快，需持续评估。

### 5.3 成功案例：苹果公司的投资
- 投资理由：强大的技术护城河、优秀的管理层。
- 表现：长期持有带来巨大收益。

def calculate_intrinsic_value(cash_flows, discount_rate, terminal_value):
    pv = 0
    for i in range(len(cash_flows)):
        pv += cash_flows[i] / (1 + discount_rate) ** i
    pv += terminal_value / (1 + discount_rate) ** len(cash_flows)
    return pv

# 示例数据
cash_flows = [100, 150, 200, 250]
discount_rate = 0.1
terminal_value = 1000

intrinsic_value = calculate_intrinsic_value(cash_flows, discount_rate, terminal_value)
print("内在价值为：", intrinsic_value)
