# 第三部分：算法原理与系统分析

## 第5章：杜邦分析法在效率评估中的应用

### 5.1 杜邦分析法的原理
- **5.1.1 模型公式**：ROE = 净利润 / 净资产 = (净利润 / 营业收入) × (营业收入 / 总资产) × (总资产 / 净资产)。

### 5.2 杜邦分析法的步骤
1. **计算净利润率**：净利润 / 营业收入。
2. **计算资产周转率**：营业收入 / 总资产。
3. **计算权益乘数**：总资产 / 净资产。
4. **综合计算ROE**：三者相乘的结果。

### 5.3 案例分析
- 某制造企业的杜邦分析：通过公式计算，找出效率提升的关键点。
