- **股市估值**：公司的市场价值，涉及市盈率、市净率等指标。

## 第二部分：算法原理讲解

### 第3章：品牌估值的多因素模型

#### 3.1 算法原理
- **多因素模型**：考虑品牌知名度、市场占有率、盈利能力等多个因素。
- **计算公式**：$$ 品牌价值 = \sum (\text{因素权重} \times \text{因素值}) $$


#### 3.3 Python代码实现
```python
import pandas as pd

# 数据准备
brand_data = pd.DataFrame({
    '品牌': ['BrandA', 'BrandB', 'BrandC'],
    '知名度': [85, 70, 65],
    '市场占有率': [25, 18, 12],
    '盈利能力': [0.3, 0.25, 0.2]
})

# 权重设定
weights = {'知名度': 0.4, '市场占有率': 0.3, '盈利能力': 0.3}

# 计算品牌价值
brand_value = []
for index, row in brand_data.iterrows():
    value = 0
    for factor in ['知名度', '市场占有率', '盈利能力']:
        value += row[factor] * weights[factor]
    brand_value.append(value)

# 结果展示
brand_data['品牌价值'] = brand_value
print(brand_data)
```
