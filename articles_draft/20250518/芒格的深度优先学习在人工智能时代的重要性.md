## 第1章：深度优先学习的定义与背景

### 1.1 深度优先学习的定义

- **知识体系的构建**：通过层次化知识图谱，将知识点进行系统性整理和关联。
- **核心问题的深入挖掘**：找到问题的关键节点，进行深度分析和解决。
- **系统性思维的培养**：通过问题分解和关联分析，提升解决复杂问题的能力。

### 6.2 核心代码实现
以下是深度优先搜索的Python代码：

```python
import networkx as nx
import matplotlib.pyplot as plt

def depth_first_search(G, start_node):
    visited = set()
    path = []
    def dfs(node):
        if node not in visited:
            visited.add(node)
            path.append(node)
            for neighbor in G.neighbors(node):
                if neighbor not in visited:
                    dfs(neighbor)
    dfs(start_node)
    return path

G = nx.Graph()
G.add_edges_from([('A','B'), ('B','C'), ('C','D'), ('B','E'), ('E','F')])
start_node = 'A'
path = depth_first_search(G, start_node)
print(path)
```
