## 第一章 背景介绍

### 1.1 核心概念术语说明

- **代表性偏差（Representativeness Bias）**：投资者基于样本的代表性不足而做出错误决策的现象。

### 1.2 问题背景

- 投资决策中，投资者常依赖有限的样本做判断，导致偏差。

### 1.3 问题描述

- 样本不具代表性，导致错误判断。

### 1.4 问题解决

- 通过统计方法和系统设计，识别和纠正偏差。

### 1.5 边界与外延

- 限定于统计学和行为经济学领域。

### 1.6 概念结构与核心要素

- 样本、总体、偏差来源、纠正方法。

## 第二章 核心概念与联系

### 2.1 偏差原理

- 代表性偏差源于对样本的过度概括。

### 2.2 对比其他偏差

- 确认偏差：寻求支持现有假设的信息。
- 从众偏差：因群体影响改变判断。

### 2.3 概念对比表

| 偏差类型      | 描述                             | 表现形式                        |
|---------------|----------------------------------|---------------------------------|
| 代表性偏差    | 样本不具代表性导致错误判断       | 以小样本推断整体                |
| 确认偏差      | 追求支持现有假设的信息           | 忽略反面证据                    |
| 从众偏差      | 因群体压力改变判断               | 跟随多数意见                    |

## 第三章 算法原理讲解

### 3.1 识别偏差算法

- 检查样本是否具有代表性，使用统计指标如均值、标准差等。

### 3.2 纠正偏差算法

- 增加样本量，重新采样，调整分析方法。

### 3.3 Mermaid 流程图


### 3.4 Python 实现

```python
import numpy as np
from statsmodels import robust

# 示例数据
data = np.random.normal(loc=0, scale=1, size=100)

# 计算稳健标准差
std_robust = robust.standardize(data).std()

print("稳健标准差:", std_robust)
```

### 3.5 数学模型

- **条件概率公式**：
  $$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$
- **置信区间**：
  $$\text{置信区间} = \text{均值} \pm z \times \text{标准误}$$
- **假设检验**：
  $$H_0: \mu = \mu_0$$
  $$H_1: \mu \neq \mu_0$$
