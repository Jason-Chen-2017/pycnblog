## 第三部分：算法原理讲解

### 第3章：层次分析法（AHP）与模糊综合评价法（FCE）

#### 3.1 层次分析法（AHP）
- **原理**：通过构建层次结构，计算各指标的权重，进行综合评价。
- **流程图**：
```mermaid
graph TD
A[目标层] --> B[准则层]
B --> C[方案层]
A --> C
```
- **数学模型**：
  $$ A = \lambda \cdot R \cdot C $$
  其中，$R$ 是一致性矩阵，$C$ 是权重向量。

#### 3.2 模糊综合评价法（FCE）
- **原理**：通过模糊集合和模糊推理，进行综合评价。
- **流程图**：
```mermaid
graph TD
A[输入指标] --> B[模糊化]
B --> C[模糊推理]
C --> D[结果评价]
```

#### 3.3 算法实现
- **Python代码示例**：
```python
import numpy as np

# 定义层次分析法计算权重
def calculate_weights(matrix):
    # 计算一致性系数
    n = len(matrix)
    a = np.array(matrix)
    w = np.mean(a, axis=1)
    return w

# 示例矩阵
matrix = [
    [1, 3, 2],
    [1/3, 1, 2/3],
    [1/2, 3/2, 1]
]

weights = calculate_weights(matrix)
print("权重向量为：", weights)
```
