## 第一部分: 芒格的"不做"清单概述

### 第1章: 芒格的投资哲学与"不做"清单

#### 1.1 芒格的投资理念概述
- **1.1.1 芒格的投资哲学核心**
  芒格的投资哲学基于“避免错误”，而非追求高回报。他强调长期价值投资，避免短期波动干扰。
  
- **1.1.2 "不做"清单的背景与重要性**
  清单源于芒格对投资风险的深刻理解，旨在帮助投资者避开低效和高风险的投资领域。
  
- **1.1.3 清单在投资决策中的作用**
  清单作为决策工具，帮助投资者快速筛选出不符合投资标准的项目，减少决策失误。

#### 1.2 "不做"清单的来源与演变
- **1.2.1 清单的起源与芒格的投资原则**
  清单起源于芒格的“机会成本”概念，强调避免浪费时间和资源在低效领域。
  
- **1.2.2 清单的演变与优化**
  随着市场变化，清单不断优化，加入更多具体的投资领域和风险因素。
  
- **1.2.3 清单在投资实践中的应用**
  清单被广泛应用于机构和个人投资决策中，帮助投资者筛选出优质标的。

#### 1.3 清单的核心原则与应用场景
- **1.3.1 清单的主要原则**
  包括不投资不懂的领域、不投资高风险行业等。
  
- **1.3.2 清单在不同投资领域的应用**
  适用于股票、债券、房地产等多种投资类型。
  
- **1.3.3 清单的局限性与改进方向**
  清单并非绝对，需根据市场变化灵活调整。

### 3.2 数学模型
- **3.2.1 评估公司质量的公式**
  $$\text{ROE} = \frac{\text{净利润}}{\text{所有者权益}}$$
  $$\text{负债率} = \frac{\text{负债}}{\text{资产}}$$

### 3.3 Python代码实现
```python
def芒格筛选(stocks):
    筛选结果 = []
    for stock in stocks:
        if stock.ROE > 15% and stock.负债率 < 50%:
            筛选结果.append(stock)
    return 筛选结果
```
