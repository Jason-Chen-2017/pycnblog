## 第1章: 生态修复项目背景与概念

### 1.1 生态修复的定义与内涵
生态修复是指通过人为干预，恢复被破坏的生态系统，使其接近自然状态的过程。它包括对土地、水源、植被等的修复，以改善生态功能和生物多样性。

**核心概念**：
- **生态修复**：修复被破坏的生态系统。
- **社会效益**：生态修复带来的社会价值，包括经济效益、环境效益和社会认可度。

### 1.2 生态修复项目的社会效益
社会效益是生态修复项目的重要组成部分，包括提升居民生活质量、减少环境污染、促进经济增长等方面。

### 2.1 层次分析法（AHP）原理
层次分析法是一种用于多目标决策的结构化方法，适用于生态修复项目的多维度评价。

**步骤**：
1. 构建层次结构。
2. 确定各层次的权重。
3. 计算综合评价。

## 第3章: 生态修复项目社会效益量化的理论基础

### 3.1 层次分析法（AHP）的应用
通过案例分析，详细讲解AHP在生态修复项目中的应用步骤，包括指标权重计算和综合评价模型的构建。

**Python代码示例**：
```python
import numpy as np
from scipy.stats import rankdata

def calculate_weights(criteria_values):
    # 计算权重
    n = len(criteria_values)
    weights = rankdata(criteria_values, method='min') / sum(rankdata(criteria_values, method='min'))
    return weights

criteria_values = [0.4, 0.2, 0.3, 0.1]
weights = calculate_weights(criteria_values)
print("权重为：", weights)
```

**数学公式**：
$$权重 = \frac{rank}{\sum rank}$$

### 3.2 综合评价模型的构建
结合经济效益、社会效益和环境效益，构建综合评价模型。

**公式**：
$$总评分 = \sum (权重_i \times 评分_i)$$
