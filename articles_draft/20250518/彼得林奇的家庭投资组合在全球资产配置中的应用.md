### 第4章: 数学模型与公式

#### 4.1 投资组合优化模型
- **均值-方差优化模型**：
$$\text{Minimize } \sigma^2 \text{ subject to } \mathbf{w}^T\mathbf{r} = \text{target return}$$
其中，$\mathbf{w}$是权重向量，$\mathbf{r}$是收益向量，$\sigma^2$是风险。

#### 4.2 风险评估公式
- **夏普比率**：
$$\text{夏普比率} = \frac{E[r] - r_f}{\sigma}$$
其中，$E[r]$是预期收益，$r_f$是无风险利率，$\sigma$是收益的标准差。

# 计算最优配置比例
def optimize_portfolio(data):
    # 计算协方差矩阵
    cov_matrix = data.cov()
    # 计算收益向量
    returns = data.mean()
    # 使用均值-方差优化
    weights = np.linalg.solve(cov_matrix, returns)
    weights = weights / weights.sum()
    return weights

# 调整配置
