# 第一部分: 背景介绍

## 第1章: 新兴市场债券投资的背景与现状

### 1.1 新兴市场债券的定义与特点
- **定义**: 新兴市场债券是指发行主体位于新兴市场国家，以本币或外币计价的债务工具。
- **特点**: 
  1. 高收益与高风险并存。
  2. 市场流动性较低，波动性较大。
  3. �受全球经济和地缘政治影响显著。

### 1.2 彼得林奇投资理念的概述
- **生平简介**: 彼得林奇是美国著名基金经理，以价值投资和逆向思维著称。
- **逆向思维**: 在市场低迷时寻找被低估的投资标的，逆市场情绪进行投资。
- **债券投资**: 林奇认为债券是稳定收益的重要来源，尤其在新兴市场中有独特优势。

# 第二部分: 核心概念与联系

## 第2章: 逆向思维在债券投资中的核心概念

### 2.1 逆向思维的核心原理
- **定义**: 逆向思维是指在市场普遍看跌时买入，看涨时卖出。
- **特征**: 
  1. 逆市场情绪。
  2. 重视估值，而非市场趋势。
  3. 长期持有，避免频繁交易。

### 2.2 逆向思维与传统投资思维的对比
| 对比维度 | 逆向思维 | 传统投资思维 |
|----------|----------|--------------|
| 投资时机 | 逆市买入 | 趋势跟随     |
| 估值考量 | 重视估值 | 侧重技术分析 |
| 风险控制 | 高风险承受 | 风险厌恶     |

import pandas as pd
import numpy as np

def calculate_duration(price, coupon, yield_to_maturity):
    duration = (price * coupon) / (1 + yield_to_maturity)
    return duration

# 示例数据
price = 100
coupon = 5
ytm = 0.05

duration = calculate_duration(price, coupon, ytm)
print(f"久期: {duration}")
