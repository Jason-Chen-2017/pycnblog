# 第一部分: 多智能体系统与投资者心理偏差基础

## 第1章: 多智能体系统概述

### 1.1 多智能体系统的定义与特点

- **1.1.1 多智能体系统的定义**  
  多智能体系统（Multi-Agent Systems, MAS）由多个智能体组成，这些智能体能够自主决策、协作或竞争，以实现特定目标。

- **1.1.2 多智能体系统的核心特点**  
  - 分布式：智能体独立运作。
  - 交互性：智能体之间通过通信协作。
  - 反应式：能够实时响应环境变化。
  - 社会性：智能体之间存在社会关系和互动。

- **1.1.3 多智能体系统与单智能体系统的区别**  
  | 特性       | 单智能体系统             | 多智能体系统             |
  |------------|--------------------------|--------------------------|
  | 结构       | 单一智能体               | 多个智能体               |
  | 交互       | 无或有限               | 高度交互                 |
  | 复杂性     | 简单                   | 复杂                   |

### 1.2 投资者心理偏差的定义与分类

- **1.2.1 心理偏差的定义**  
  投资者在决策过程中因心理因素导致的非理性行为。

- **1.2.2 常见的投资者心理偏差类型**  
  - **锚定效应**：过度依赖初始信息。
  - **损失厌恶**：害怕损失，影响决策。
  - **从众心理**：跟随大众决策，避免孤立。

- **1.2.3 心理偏差对投资决策的影响**  
  心理偏差导致市场波动，影响资产定价。

### 1.3 多智能体系统模拟投资者行为的意义

- **1.3.1 理解投资者行为模式**  
  通过建模揭示心理偏差的规律。

- **1.3.2 预测市场波动**  
  模拟市场行为，预测价格变化。

- **1.3.3 改进投资策略**  
  基于模拟结果优化投资决策。

## 第3章: 投资者心理偏差的建模方法

### 3.1 心理偏差的分类与特征

- **3.1.1 锚定效应**  
  依赖初始信息，影响决策。

- **3.1.2 损失厌恶**  
  更怕损失，影响风险偏好。

- **3.1.3 从众心理**  
  跟随大众，避免孤立。

### 3.2 基于多智能体系统的建模框架

- **3.2.1 MAS建模的基本原则**  
  - 简单性：个体行为简单。
  - 可扩展性：支持大规模模拟。

- **3.2.2 个体行为模型的设计**  
  每个智能体代表投资者，具有决策规则。

- **3.2.3 群体行为模型的构建**  
  群体行为由个体互动产生。

### 3.3 心理偏差的数学模型

- **3.3.1 锚定效应的数学表达**  
  $$ P(\text{选择} x) = \frac{x - a}{b - a} $$  
  其中，a和b是决策范围的端点。

- **3.3.2 损失厌恶的数学模型**  
  使用 prospect theory 表示。

- **3.3.3 从众心理的建模**  
  使用社会影响理论。

### 3.4 心理偏差与市场行为的关系

- **3.4.1 心理偏差如何影响价格波动**  
  集体心理偏差引发市场泡沫或崩盘。

- **3.4.2 集体心理偏差的市场表现**

### 6.2 核心代码实现

```python
import networkx as nx
import matplotlib.pyplot as plt

# 初始化智能体
agents = [Agent(i) for i in range(10)]

# 生成网络
G = nx.DiGraph()
for agent in agents:
    for neighbor in agents:
        if agent != neighbor:
            G.add_edge(agent.id, neighbor.id)

# 可视化网络
nx.draw(G, with_labels=True)
plt.show()
```
