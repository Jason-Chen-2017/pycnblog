## 第4章：家庭作业投资法的数学模型与公式

### 4.1 投资回报的计算公式
- **4.1.1 单利与复利的计算**
  - 单利：$A = P(1 + rt)$
  - 复利：$A = P(1 + r)^t$
- **4.1.2 投资回报率的计算**
  - ROI = (净收益 / 投资成本) × 100%
- **4.1.3 风险调整后的收益计算**
  - 使用夏普比率衡量风险调整后的收益。

### 4.2 财务指标的分析公式
- **4.2.1 市盈率（P/E）公式**
  - P/E = 市场价 / 每股收益
- **4.2.2 市净率（P/B）公式**
  - P/B = 市场价 / 每股净资产
- **4.2.3 股息率计算公式**
  - 股息率 = 每股股息 / 市场价 × 100%
