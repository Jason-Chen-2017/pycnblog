### 第2章: 费雪消费者行为分析的核心原理

#### 2.2 消费者效用与选择行为

- 效用函数：$U(x_1, x_2) = u_1x_1 + u_2x_2$
- 边际效用递减法则：$MU_1 = \frac{dU}{dx_1}$
- 预算约束：$p_1x_1 + p_2x_2 = M$

## 第三部分: 费雪消费者行为分析的算法原理

### 第3章: 费雪消费者行为分析算法

#### 3.1 费雪模型的数学表达式

- 消费者效用最大化问题：  
  $$ \max_{x_1, x_2} U(x_1, x_2) = u_1x_1 + u_2x_2 $$
  $$ \text{subject to } p_1x_1 + p_2x_2 = M $$

- 最优解条件：  
  $$ \frac{u_1}{p_1} = \frac{u_2}{p_2} $$

#### 3.2 费雪模型的实现步骤

1. **数据预处理**：清洗数据，处理缺失值和异常值。
2. **特征提取**：提取消费者的相关特征，如收入、偏好等。
3. **模型训练**：基于费雪模型建立效用函数，求解最优解。
4. **结果分析**：分析消费者选择行为，验证模型的准确性。

#### 3.3 费雪模型的Python实现

import numpy as np

def fisherConsumerBehaviorAnalysis(data):
    # 数据预处理
    processed_data = data.dropna()
    
    # 特征提取
    features = processed_data[['income', 'preference']]
    
    # 计算最优解
    u1, u2 = features['preference'].mean(), features['income'].mean()
    p1, p2 = 1, 1
    M = 1000  # 假设预算为1000
    
    # 求解最优解条件
    ratio = u1 / p1
    x2 = (M - (u1 / ratio) * p1) / p2
    x1 = (M - p2 * x2) / p1
    
    return x1, x2

# 示例数据
data = {
    'income': [50000, 60000, 70000],
    'preference': [0.8, 0.6, 0.9]
}

x1, x2 = fisherConsumerBehaviorAnalysis(data)
print(f"Optimal x1: {x1}, Optimal x2: {x2}")
