# 假设df为股票数据，包含'PE'（市盈率）、'PB'（市净率）、'ROE'（净资产收益率）等指标
def screen_stocks(df):
    # 筛选条件：市盈率 < 15，市净率 < 2，净资产收益率 > 10%
    selected = df[(df['PE'] < 15) & (df['PB'] < 2) & (df['ROE'] > 0.1)]
    return selected

## 附录：数学公式与估值指标

### 附录A：估值指标公式

#### 1. 市盈率（P/E）
$$ P/E = \frac{股价}{每股收益} $$

#### 2. 市净率（P/B）
$$ P/B = \frac{股价}{每股净资产} $$

#### 3. 股息率
$$ 股息率 = \frac{每股股息}{股价} \times 100\% $$

#### 4. 净资产收益率（ROE）
$$ ROE = \frac{净利润}{净资产} \times 100\% $$
