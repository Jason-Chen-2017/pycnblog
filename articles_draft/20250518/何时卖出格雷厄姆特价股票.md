# 引言

价值投资是一种长期被验证有效的投资策略，其核心在于购买那些市场价格低于其内在价值的股票。格雷厄姆作为价值投资的鼻祖，提出了许多经典理论，如安全边际和内在价值。本文将从价值投资的基础出发，探讨何时卖出特价股票的策略，帮助投资者在市场中做出更明智的决策。

# 第一部分: 价值投资与特价股票基础

## 第1章: 价值投资的起源与核心理念

### 1.1 价值投资的起源

价值投资起源于20世纪，由本杰明·格雷厄姆和戴维德·多德共同提出。其核心理念是购买那些市场价格低于其内在价值的股票，从而在市场波动中获得超额收益。价值投资强调安全边际，即买入价格与内在价值的差距，以降低投资风险。

### 1.2 特价股票的定义与特征

特价股票是指市场价格低于其内在价值的股票。其核心特征包括低市盈率、低市净率和高股息率。特价股票通常属于价值型股票，与成长型股票相比，其特点是低增长、高稳定性。

### 1.3 价值投资的决策框架

格雷厄姆的价值投资框架包括选股标准、安全边际和内在价值计算。选股标准注重财务健康、低估值和高分红；安全边际通过买入价格低于内在价值来降低风险；内在价值是基于财务数据和市场分析计算出的理论价值。

#### Python代码实现

```python
def graham_screen(stocks):
    selected = []
    for stock in stocks:
        pe = stock.pe_ratio
        pb = stock.pb_ratio
        if pe < 15 and pb < 1.5:
            selected.append(stock)
    return selected
```

### 3.2 内在价值计算模型

#### 净现值模型

$$ NPV = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$

其中，\( CF_t \) 是第 \( t \) 年的现金流，\( r \) 是贴现率。

#### 股息贴现模型

$$ DDM = \frac{D_1}{k - g} $$

其中，\( D_1 \) 是下一期的股息，\( k \) 是预期回报率，\( g \) 是股息增长率。
