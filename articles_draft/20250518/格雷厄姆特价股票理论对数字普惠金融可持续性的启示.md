## 第四章：算法实现与案例分析

### 4.1 格雷厄姆模型的数学公式
$$ V = \text{收入} \times (1 + g) / (r - g) $$
其中，$V$为内在价值，$g$为收入增长率，$r$为折现率。

### 4.2 算法实现
```python
def calculate_intrinsic_value(revenue, growth_rate, discount_rate):
    return revenue * (1 + growth_rate) / (discount_rate - growth_rate)
```
