### 卷积神经网络（CNN）原理与结构

**2.1 CNN 基本原理**

卷积神经网络（CNN）是一种专门用于处理图像数据的神经网络架构。其核心思想是通过卷积运算提取图像特征，并通过层级结构将特征逐渐抽象和整合。

**2.1.1 卷积运算**

卷积运算是 CNN 的基础操作。它通过在输入图像上滑动一个卷积核（也称为过滤器或卷积矩阵），与图像局部区域进行点积运算，生成特征图。卷积运算可以捕捉图像中的局部特征，如图形边缘、纹理等。

**2.1.2 池化操作**

池化操作用于减少特征图的大小，降低模型的计算复杂度。常见的池化操作包括最大池化和平均池化。最大池化选取特征图中每个局部区域的最大值，而平均池化则是计算每个局部区域的平均值。

**2.1.3 全连接层**

全连接层将特征图上的所有像素映射到一个线性空间中，输出最终的分类结果。全连接层通常位于卷积层的最后，用于对提取到的特征进行分类。

**2.2 CNN 结构与层次**

CNN 的结构通常包括多个卷积层、池化层和全连接层。每个卷积层负责提取图像特征，而池化层用于下采样，减少模型参数。全连接层则将特征映射到输出类别。

**2.2.1 卷积层**

卷积层由多个卷积核组成，每个卷积核负责提取图像的某种特征。卷积层的参数包括卷积核的大小、步长和填充方式。

**2.2.2 激活函数**

激活函数用于引入非线性，使得神经网络可以学习复杂的非线性关系。常用的激活函数包括 sigmoid、ReLU 和 tanh。

**2.2.3 池化层**

池化层通常位于卷积层之后，用于减小特征图的大小。最大池化和平均池化是最常用的两种池化方式。

**2.3 CNN 实例分析**

**2.3.1 LeNet-5 网络**

LeNet-5 是最早的卷积神经网络之一，由卷积层、池化层和全连接层组成，主要用于手写数字识别。

**2.3.2 AlexNet 网络**

AlexNet 是深度学习在图像识别领域的重要里程碑，引入了深度卷积网络结构，显著提高了图像识别的准确率。

**4.3.1 数字识别**

数字识别是一个经典的图像识别问题。可以使用 CNN 模型对其进行分类。

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

model = Sequential()
model.add(Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)))
model.add(MaxPooling2D(pool_size=(2, 2)))
model.add(Flatten())
model.add(Dense(10, activation='softmax'))

model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])
```

**4.3.2 车辆检测**

车辆检测是自动驾驶中的重要任务。可以使用 CNN 模型检测图像中的车辆。

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

model = Sequential()
model.add(Conv2D(32, (3, 3), activation='relu', input_shape=(128, 128, 3)))
model.add(MaxPooling2D(pool_size=(2, 2)))
model.add(Conv2D(64, (3, 3), activation='relu'))
model.add(MaxPooling2D(pool_size=(2, 2)))
model.add(Flatten())
model.add(Dense(128, activation='relu'))
model.add(Dense(1, activation='sigmoid'))

model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
model.fit(x_train, y_train, epochs=10, batch_size=32)
```
