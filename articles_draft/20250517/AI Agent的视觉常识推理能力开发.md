# 第二部分: 视觉常识推理的核心算法

## 第2章: 视觉常识推理模型的结构与算法

### 2.1 模型的整体架构
- **输入层**：视觉数据（图像、视频）。
- **特征提取层**：使用CNN或Transformer提取视觉特征。
- **常识推理层**：基于知识图谱或语言模型进行推理。
- **输出层**：生成推理结果或决策指令。

### 2.2 视觉特征提取算法
- **CNN的原理**：通过卷积操作提取空间特征。
- **Transformer的原理**：通过自注意力机制提取全局特征。
- **对比学习**：通过对比损失函数优化特征表示。

### 2.3 常识推理算法
- **基于知识图谱的推理**：通过图遍历进行路径推理。
- **基于语言模型的推理**：利用大语言模型进行上下文推理。
- **自监督学习**：通过无标签数据进行自适应学习。
