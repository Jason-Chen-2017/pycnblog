## 第4章: 文本相似度计算

### 4.1 余弦相似度
- **原理**：计算两个向量的余弦值，值越大表示相似度越高。
- **公式**：
  $$
  \text{余弦相似度} = \frac{\vec{A} \cdot \vec{B}}{|\vec{A}| |\vec{B}|}
  $$
- **实现步骤**：将文本向量化，计算向量间的余弦相似度。

### 4.2 基于深度学习的相似度计算
- **BERT模型**：利用预训练的BERT模型计算文本的深度语义相似度。
- **实现步骤**：使用BERT模型获取文本向量，计算相似度。

### 7.2 核心代码实现
```python
import jieba

def tokenize(text):
    return jieba.lcut(text)

def compute_cosine_similarity(vector1, vector2):
    dot_product = sum(a * b for a, b in zip(vector1, vector2))
    magnitude1 = sum(a**2 for a in vector1) ** 0.5
    magnitude2 = sum(a**2 for a in vector2) ** 0.5
    if magnitude1 == 0 or magnitude2 == 0:
        return 0.0
    return dot_product / (magnitude1 * magnitude2)
```
