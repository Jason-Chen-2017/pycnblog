## 第一部分: 投资简化论的背景与核心概念

### 第1章: 投资简化论的背景与问题背景

#### 1.1 金融产品的复杂化现状
金融市场的发展带来了金融产品的多样化和复杂化。投资者面临越来越多的复杂工具，如ETF、衍生品等，这些产品增加了投资的难度，使普通投资者难以理解和选择。

#### 1.2 投资者面临的挑战与困惑
投资者在复杂市场中常常感到困惑，难以制定有效策略。传统理论如CAPM和APT虽然提供了一定指导，但过于复杂，难以实际应用。

#### 1.3 传统投资理论的局限性
传统理论计算复杂，忽视实际操作中的简化因素，导致投资者难以应用。

#### 1.4 约翰·伯格的投资者身份与经验
作为投资专家，伯格强调长期投资和分散化，积累了丰富经验，促使他提出简化论。

### 第2章: 投资简化论的核心概念与联系

#### 2.1 简化论的核心理念与目标
简化论主张简化策略，关注长期目标，避免过度关注短期波动。目标在于降低复杂性，使投资更易操作。

#### 4.2 投资组合优化的数学公式
简化论的组合优化公式为：
$$ w_1r_1 + w_2r_2 = \text{预期回报} $$

#### 5.2 核心实现代码
```python
import pandas as pd
import numpy as np

def portfolioOptimizer(assets, weights):
    # 计算组合波动率
    cov_matrix = np.cov(assets)
    portfolio_variance = np.dot(weights.T, np.dot(cov_matrix, weights))
    return np.sqrt(portfolio_variance)

assets_returns = pd.DataFrame({
    '股票': [0.08, 0.07, 0.09],
    '债券': [0.05, 0.04, 0.06]
})

weights = np.array([0.6, 0.4])
risk = portfolioOptimizer(assets_returns, weights)
print(f'组合风险：{risk}')
```

#### 5.3 案例分析与解读
案例中，投资组合风险为约0.065，低于单独投资股票的风险，验证了简化策略的有效性。
