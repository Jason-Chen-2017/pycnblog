- 3.2.1 CVaR的定义与计算公式
  $$ CVaR = \frac{1}{1-\alpha} \int_{\alpha}^1 VaR(\alpha) d\alpha $$

5.2 风险管理模型的实现
- 5.2.1 计算VaR和CVaR的Python代码
  ```python
  import numpy as np
  def calculate_var(data, confidence_level):
      sorted_data = np.sort(data)
      index = int(len(data) * confidence_level)
      return sorted_data[index]
  
  def calculate_cvar(data, confidence_level):
      var = calculate_var(data, confidence_level)
      cvar = np.mean(data[data <= var])
      return cvar
  
  # 示例数据
  data = np.random.normal(0, 1, 1000)
  confidence_level = 0.95
  
  var = calculate_var(data, confidence_level)
  cvar = calculate_cvar(data, confidence_level)
  
  print(f"VaR at {confidence_level} confidence level: {var}")
  print(f"CVaR at {confidence_level} confidence level: {cvar}")
  ```
