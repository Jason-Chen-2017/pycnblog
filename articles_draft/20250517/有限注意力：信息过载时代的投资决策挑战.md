# 第1章 有限注意力与信息过载概述

## 1.1 有限注意力的定义与特征

### 1.1.1 注意力资源的有限性

注意力是人类处理信息的核心资源。在信息过载的时代，注意力资源的有限性使得投资者难以处理海量信息，影响决策效率。

$$\text{注意力资源有限性} = \text{信息总量} > \text{处理能力}$$

### 1.1.2 信息过载的概念与表现

信息过载是指信息总量超过个体处理能力的情况，表现为信息碎片化、信息冗余和信息超载。

### 1.1.3 有限注意力与信息过载的关系

有限注意力与信息过载相互作用，信息过载导致注意力分配不当，注意力不足又加剧信息过载。
