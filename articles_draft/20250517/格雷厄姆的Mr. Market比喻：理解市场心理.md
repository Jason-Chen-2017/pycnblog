# 3. 市场分析方法

## 3.1 技术分析与Mr. Market
- 技术分析的核心假设：市场价格反映所有信息。
- 常用技术指标：移动平均线（MA）、相对强弱指数（RSI）、MACD。

### 3.1.1 移动平均线（MA）的数学模型
- 简单移动平均线公式：
  $$ S_{MA}(n) = \frac{1}{n} \sum_{i=1}^{n} P_i $$
  其中，$P_i$为第i天的价格，$n$为天数。

### 3.1.2 相对强弱指数（RSI）的计算
- RSI公式：
  $$ RSI = \frac{100}{1 + \frac{A}{B}} $$
  其中，$A$为上涨幅度，$B$为下跌幅度。

## 3.2 基本面分析与Mr. Market
- 通过分析公司的财务状况和行业前景，评估其内在价值。

# 4. 投资策略制定

## 4.1 价值投资与成长投资
- 价值投资：寻找被市场低估的股票。
- 成长投资：投资于高成长潜力的公司。

### 4.1.1 价值投资的筛选标准
- 市盈率（P/E）：$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
- 市净率（P/B）：$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

## 4.2 根据市场情绪调整策略
- 在市场恐慌时买入，在市场狂热时卖出。

- 使用VaR模型评估潜在损失。
- VaR计算公式：
  $$ VaR = \mu + z \cdot \sigma $$

```python
import pandas as pd

# 获取数据
data = pd.read_csv('stock_data.csv')

data = data.dropna()

```

## 8.2 技术指标计算
```python
# 计算移动平均线
data['ma_50'] = data['close'].rolling(50).mean()

# 计算RSI
def calculate_rsi(data, period=14):
    diff = data['close'].diff()
    up = diff.where(diff > 0, 0)
    down = -diff.where(diff < 0, 0)
    rs = up.rolling(period).mean() / down.rolling(period).mean()
    rsi = 100 - 100/(1 + rs)
    return rsi
data['rsi'] = calculate_rsi(data)
```

## 8.3 投资策略回测
```python
# 策略回测
data['signal'] = 1  # 1表示持有，-1表示卖出

# 计算收益
data['return'] = data['close'].pct_change()
data['strategy_return'] = data['signal'].shift(1) * data['return']
```
