```python
import pandas as pd

# 基本面分析数据
data = {
    '公司名称': ['公司A', '公司B', '公司C'],
    '市盈率': [10, 20, 15],
    '市净率': [2, 3, 2.5],
    '企业价值/EBITDA': [5, 7, 6]
}

# 创建DataFrame
df = pd.DataFrame(data)

# 估值方法
def evaluate_company(df):
    # 计算每个公司的平均估值
    average_pe = df['市盈率'].mean()
    average_pb = df['市净率'].mean()
    average_evebitda = df['企业价值/EBITDA'].mean()

    # 打印平均估值
    print(f"平均市盈率: {average_pe}")
    print(f"平均市净率: {average_pb}")
    print(f"平均企业价值/EBITDA: {average_evebitda}")

    # 找出估值最低的公司
    lowest_pe = df['市盈率'].min()
    lowest_pb = df['市净率'].min()
    lowest_evebitda = df['企业价值/EBITDA'].min()

    print(f"市盈率最低的公司：{df[df['市盈率'] == lowest_pe]['公司名称'].values}")
    print(f"市净率最低的公司：{df[df['市净率'] == lowest_pb]['公司名称'].values}")
    print(f"企业价值/EBITDA最低的公司：{df[df['企业价值/EBITDA'] == lowest_evebitda]['公司名称'].values}")

# 执行估值分析
evaluate_company(df)
```

- 导入 pandas 库，用于数据分析和处理。
- 创建一个 DataFrame，包含公司名称、市盈率、市净率和企业价值/EBITDA 等指标。
- 定义一个函数 `evaluate_company`，用于计算平均估值和找出估值最低的公司。
- 在函数中，使用 DataFrame 的 mean() 方法计算平均市盈率、平均市净率和平均企业价值/EBITDA。
- 使用 DataFrame 的 min() 方法找出市盈率、市净率和企业价值/EBITDA最低的公司。
- 打印出平均估值和估值最低的公司名称。
