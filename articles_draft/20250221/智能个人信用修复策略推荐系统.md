#### 4.5 数学公式与代码实现
- 4.5.1 协同过滤的相似度计算公式：
  $$ sim(i,j) = \frac{\sum_{k} (r_{i,k} - \bar{r_i})(r_{j,k} - \bar{r_j})}{\sqrt{\sum_{k} (r_{i,k} - \bar{r_i})^2} \cdot \sqrt{\sum_{k} (r_{j,k} - \bar{r_j})^2}} $$

- 4.5.2 Python代码示例：
```python
import numpy as np

def compute_similarity(user_items, user_avg):
    # 计算用户i和j的相似度
    numerator = np.sum((user_items[i] - user_avg[i]) * (user_items[j] - user_avg[j]))
    denominator = np.sqrt(np.sum((user_items[i] - user_avg[i])**2)) * np.sqrt(np.sum((user_items[j] - user_avg[j])**2))
    return numerator / denominator
```
