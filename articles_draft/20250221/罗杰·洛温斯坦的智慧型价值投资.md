## 第一部分：价值投资的背景与基础

### 第1章：价值投资的起源与核心理念

#### 1.1 价值投资的定义与历史发展

价值投资是一种以企业内在价值为基础的投资策略，起源于20世纪初。其核心理念是购买价格低于内在价值的股票，长期持有，等待市场重新认识其价值。

#### 1.2 价值投资的核心理念

- **安全边际**：购买价格远低于内在价值，以降低风险。
- **长期视角**：关注企业的长期盈利能力，而非短期市场波动。
- **基本面分析**：通过财务报表等数据评估企业的内在价值。

## 第二部分：智慧型价值投资的核心概念

### 第2章：智慧型价值投资的定义与特点

#### 2.1 智慧型价值投资的定义

智慧型价值投资是罗杰·洛温斯坦提出的一种投资方法，结合了基本面分析和行为金融学，强调理性与情绪的平衡，注重长期投资和高质量企业的选择。

#### 2.2 智慧型价值投资的特点

| 特性 | 描述 |
|------|------|
| 理性与情绪的平衡 | 避免情绪化决策，结合市场情绪分析 |
| 高质量企业的选择 | 选择具有强大竞争优势的企业 |
| 长期持有与动态调整 | 长期持有优质资产，定期评估并调整 |

### 第3章：智慧型价值投资的决策模型

#### 3.1 投资决策的逻辑框架

- **企业基本面分析**：评估企业的盈利能力、财务状况和行业地位。
- **市场情绪分析**：判断市场的非理性波动，寻找低估机会。
- **安全边际计算**：确定买入价格与内在价值的差距。

#### 3.2 投资决策的数学模型

现值计算公式：
$$ PV = \frac{CF}{r} $$

折现现金流模型：
$$ DCF = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$

# 示例代码：计算DCF模型
def calculateDCF(revenue, growth_rate, discount_rate):
    CF = revenue * (1 + growth_rate)
    PV = CF / discount_rate
    return PV

revenue = 1000000
growth_rate = 0.1
discount_rate = 0.05
