### 4.2 Python代码实现
#### 4.2.1 数据预处理代码
```python
import pandas as pd
import numpy as np

# 数据加载
df = pd.read_csv('食材数据.csv')

# 数据清洗
df.dropna(inplace=True)
df['使用频率'] = df['使用频率'].astype(int)
```

#### 4.2.2 模型训练代码
```python
from sklearn.neighbors import NearestNeighbors

# 基于协同过滤的推荐模型
model = NearestNeighbors(n_neighbors=5, algorithm='brute')
model.fit(df[['使用频率', '保质期天数', '存储位置']])
```

#### 4.2.3 推荐系统实现代码
```python
def get_recommendations(item_id):
    distances, indices = model.kneighbors([item_id])
    return indices.flatten()
```
