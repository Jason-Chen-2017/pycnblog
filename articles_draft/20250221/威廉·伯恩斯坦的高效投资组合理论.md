#### 3.1 优化模型
- **目标函数**：最大化夏普比率。
  $$ \text{夏普比率} = \frac{E[r_p] - r_f}{\sigma_p} $$
- **约束条件**：权重之和为1，权重非负。
  $$ \sum_{i=1}^n w_i = 1 $$

#### 5.2 核心代码实现
```python
import numpy as np
from scipy.optimize import minimize

def objective(weights, returns, risks, r_f):
    return -(weights.dot(returns) - r_f) / (weights.dot(risks))

def constraint(weights):
    return np.sum(weights) - 1

def portfolio_optimization(returns, risks, r_f):
    n = len(returns)
    weights = np.ones(n) / n
    res = minimize(objective, weights, args=(returns, risks, r_f), method='SLSQP', 
                   constraints={'type': 'eq', 'fun': constraint})
    return res.x
```
