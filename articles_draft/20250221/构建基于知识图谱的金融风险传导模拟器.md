# 第1章: 知识图谱与金融风险传导概述

## 1.1 知识图谱的基本概念

### 1.1.1 知识图谱的定义与特点
知识图谱是一种以图结构表示知识的语义网络，由节点（实体）和边（关系）组成。其特点包括：
- **可扩展性**：支持大规模数据的存储与查询。
- **语义关联**：通过关系描述实体之间的联系。
- **动态更新**：支持实时更新以反映最新信息。

### 1.1.2 知识图谱与传统数据库的区别
| 特性         | 知识图谱           | 传统数据库       |
|--------------|-------------------|-----------------|
| 数据结构     | 图结构             | 行列式           |
| 数据关联性   | 高                 | 低               |
| 查询效率     | 较低               | 高               |
| 应用场景     | 分析与推理         | 基础数据存储     |

### 1.1.3 知识图谱在金融领域的应用潜力
- **风险评估**：识别关联企业间的风险传导。
- **欺诈检测**：发现异常交易模式。
- **投资决策**：提供数据支持。

## 1.2 金融风险传导的定义与特点

### 1.2.1 金融风险的基本概念
金融风险指资产价值因市场波动而遭受损失的可能性，包括市场风险、信用风险等。

### 1.2.2 风险传导的机制与路径
风险通过关联主体（如企业、银行）在金融体系中扩散，路径包括直接和间接传导。

### 1.2.3 金融风险传导的复杂性与挑战
- **非线性关系**：风险传导路径复杂。
- **实时性要求**：需要快速响应。

## 1.3 知识图谱与金融风险传导的结合

### 1.3.1 知识图谱在风险传导中的优势
- **关联性**：捕捉机构间复杂关系。
- **动态性**：实时更新风险信息。

### 1.3.2 知识图谱技术如何支持风险模拟
通过构建知识图谱，模拟风险传导路径，评估影响范围。

### 1.3.3 金融风险传导模拟器的目标与意义
目标是量化风险传导路径，意义在于提升风险管理能力。

### 5.2.2 知识图谱构建模块实现
```python
from neo4j import GraphDatabase

def create_graph(neo4j_uri, entities, relations):
    driver = GraphDatabase.driver(neo4j_uri)
    with driver.session() as session:
        # 创建实体
        for entity in entities:
            session.run("CREATE (n:{label} {{name: '{name}'}})", label=entity['label'], name=entity['name'])
        # 创建关系
        for relation in relations:
            session.run("MATCH (a), (b) WHERE a.name = '{a_name}' AND b.name = '{b_name}' CREATE (a)-[r:{relation}]->(b)", 
                        a_name=relation['a'], relation=relation['relation'], b_name=relation['b'])
    driver.close()
```

def simulate_risk(neo4j_uri, source_node):
    driver = GraphDatabase.driver(neo4j_uri)
    with driver.session() as session:
        result = session.run("MATCH (a)-[r]->(b) WHERE a.name = $source RETURN b.name, r.weight", source=source_node)
        for record in result:
            print(f"Affected node: {record['b.name']}, Weight: {record['r.weight']}")
    driver.close()
