- Black-Scholes模型的数学公式
  $$ C = S_0 \Phi(d_1) - K e^{-rT} \Phi(d_2) $$
  其中，$$ d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma \sqrt{T}} $$
  $$ d_2 = d_1 - \sigma \sqrt{T} $$

#### 附录B：量子算法代码示例

- 使用Qiskit实现量子傅里叶变换
```python
from qiskit import QuantumCircuit, Aer, execute
from qiskit.circuit import QuantumFourierTransform

# 创建量子电路
qc = QuantumCircuit(2)
qc.h(0)
qc.circuit.append(QuantumFourierTransform(2), [0, 1])
qc.measure_all()
# 模拟器执行
simulator = Aer('qasm_simulator')
job = execute(qc, simulator)
result = job.result()
print(result.get_counts())
```
