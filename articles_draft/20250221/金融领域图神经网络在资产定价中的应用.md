## 第二部分: 图神经网络的核心概念与原理

### 第2章: 图神经网络的核心概念与原理

#### 2.1 图论基础
##### 2.1.1 图的基本定义
图由节点和边组成，节点表示实体，边表示关系。例如，在股票市场中，节点可以是公司，边可以是公司之间的关联。

##### 2.1.2 邻接矩阵与边权重
邻接矩阵是一个方阵，表示节点之间的连接情况。边权重表示连接的强度，可以用数值量化。

##### 2.1.3 图的表示与编码
图的表示可以采用邻接矩阵或边列表。节点编码是将节点特征转化为数值，便于模型处理。

#### 2.2 神经网络基础
##### 2.2.1 神经网络的基本结构
神经网络由输入层、隐藏层和输出层组成，通过激活函数处理数据。

##### 2.2.2 深度学习的核心原理
深度学习通过多层网络提取数据特征，自动学习数据的规律。

##### 2.2.3 图神经网络的独特性
图神经网络结合了图结构和深度学习，能够处理复杂的网络关系。

#### 2.3 图神经网络的算法原理
##### 2.3.1 图卷积网络（GCN）
GCN通过聚合邻居节点的信息，进行图数据的卷积操作。例如，在股票市场中，可以通过GCN聚合相关股票的信息。

##### 2.3.2 图注意力机制（GAT）
GAT引入注意力机制，根据节点的重要性调整聚合权重。例如，在风险评估中，可以关注高风险节点的注意力。

##### 2.3.3 图嵌入与节点表示
图嵌入是将节点特征转化为低维向量的过程，便于模型处理。例如，使用Node2Vec算法生成节点的嵌入表示。

import torch
from torch import nn
import torch.nn.functional as F

class GNN(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GNN, self).__init__()
        self.conv1 = nn.Conv2d(input_dim, hidden_dim, kernel_size=1)
        self.conv2 = nn.Conv2d(hidden_dim, output_dim, kernel_size=1)

    def forward(self, x, adj):
        x = F.relu(self.conv1(x))
        x = x * adj[:, None, :, None]  # 图卷积操作
        x = F.relu(self.conv2(x))
        return x.mean(dim=1)
```
