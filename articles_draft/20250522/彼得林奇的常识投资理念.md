### 第3章：常识投资的数学模型与公式

#### 3.1 投资回报的数学模型

##### 3.1.1 投资回报的计算公式

$$回报率 = \frac{最终价值 - 初始价值}{初始价值} \times 100\%$$

**举例说明**：假设某投资者以100元买入一只股票，一年后卖出价为120元，则回报率为：

$$回报率 = \frac{120 - 100}{100} \times 100\% = 20\%$$

##### 3.1.2 投资风险的数学模型

$$风险 = 标准差 \times \sqrt{投资时间}$$

**解释**：标准差衡量了资产回报率的波动程度，而投资时间越长，风险的计算结果会越大，因为长期投资需要考虑更多的不确定性。

#### 3.2 常识投资的数学公式

##### 3.2.1 常识投资的资产配置公式

$$资产配置 = \alpha \times 风险资产 + \beta \times 安全资产$$

**解释**：$\alpha$ 和 $\beta$ 是权重系数，分别代表风险资产（如股票）和安全资产（如债券）的配置比例，$\alpha + \beta = 1$。

##### 3.2.2 常识投资的组合管理公式

$$组合收益 = \sum_{i=1}^{n} w_i \times r_i$$

**解释**：$w_i$ 是第$i$项资产的权重，$r_i$ 是第$i$项资产的回报率，组合收益是各资产回报率的加权平均值。

```python
import pandas as pd
import numpy as np

# 示例：简单资产配置模型
def calculate_asset_allocation(risk_asset_return, safe_asset_return, risk_tolerance=0.5):
    # 风险资产和安全资产的配置比例
    alpha = risk_tolerance  # 风险承受系数
    beta = 1 - alpha        # 安全资产系数
    expected_return = alpha * risk_asset_return + beta * safe_asset_return
    return expected_return

# 示例数据
risk_asset_return = 0.12  # 风险资产年化回报率
safe_asset_return = 0.03  # 安全资产年化回报率
expected_return = calculate_asset_allocation(risk_asset_return, safe_asset_return)
print(f"预期回报率：{expected_return:.2f}%")
```

##### 5.1.2.2 投资组合优化的Python代码

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, weights):
    # 定义目标函数：最小化投资组合的方差
    def objective(weights):
        return np.dot(weights.T, np.dot(returns, weights))
    # 约束条件：权重之和为1
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    # 边界条件：权重在0到1之间
    bounds = [(0, 1) for _ in range(len(weights))]
    # 优化求解
    result = minimize(objective, weights, bounds=bounds, constraints=constraints)
    return result.x

# 示例数据
returns = np.array([0.1, 0.15, 0.08])  # 三个资产的回报率
weights = np.array([1/3, 1/3, 1/3])     # 初始权重
optimal_weights = portfolio_optimization(returns, weights)
print(f"最优权重：{optimal_weights}")
```
