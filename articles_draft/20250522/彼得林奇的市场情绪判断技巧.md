## 第4章: 市场情绪的量化分析

### 4.1 情绪指标的计算方法

彼得林奇使用多种情绪指标来衡量市场情绪，例如波动率和交易量。

```python
import pandas as pd
import numpy as np

# 示例数据：假设我们有一个包含收盘价和交易量的数据集
data = pd.DataFrame({
    'Close': [100, 105, 98, 102, 104],
    'Volume': [1000, 1500, 800, 1200, 1300]
})

# 计算波动率
volatility = np.std(data['Close']) / np.mean(data['Close']) * 100

# 计算交易量的平均值
avg_volume = np.mean(data['Volume'])
```

波动率和交易量的变化可以帮助投资者判断市场情绪的变化。
