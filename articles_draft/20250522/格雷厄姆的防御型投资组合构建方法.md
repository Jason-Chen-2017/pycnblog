## 第二部分：格雷厄姆防御型投资组合的构建原理

### 第3章：投资组合优化的数学模型

#### 3.1 均值-方差模型
使用均值-方差模型优化投资组合，公式如下：

$$\text{Minimize } \sigma^2 \text{ subject to } \mathbf{w}^T \mathbf{r} = r_p$$

其中，$\mathbf{w}$是权重向量，$\mathbf{r}$是收益向量，$r_p$是目标收益。

### 第5章：Python代码实现

#### 5.1 环境安装
需要安装`pandas`和`numpy`库。

#### 5.2 代码实现
以下是优化代码示例：

```python
import numpy as np
import pandas as pd

def optimize_portfolio(returns):
    n = returns.shape[1]
    returns_cov = returns.cov()
    returns_mean = returns.mean()
    
    # 均值-方差优化
    from pypfolio import PyPfolio
    p = PyPfolio(returns_cov.values, returns_mean.values)
    w = p.optimize()
    return w

# 示例数据
data = pd.read_csv('stock_data.csv')
returns = data.pct_change().dropna()
weights = optimize_portfolio(returns)
print(weights)
```
