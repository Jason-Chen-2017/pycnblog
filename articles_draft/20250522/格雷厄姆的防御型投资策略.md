# 第1章：防御型投资的核心理念

## 1.1 格雷厄姆的防御型投资理论

### 1.1.1 防御型投资的定义
防御型投资是一种以稳健性和风险控制为核心的投资策略，旨在通过选择具有内在价值且价格被市场低估的资产，构建一个能够在市场波动中保持稳定的组合。

### 1.1.2 格雷厄姆的安全边际概念
安全边际是格雷厄姆防御型投资理论的核心，它是指资产的内在价值与市场价格之间的差距。通过买入价格低于内在价值的资产，投资者可以降低市场波动带来的风险。

$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

### 1.1.3 防御型投资与进攻型投资的区别
| 属性       | 防御型投资             | 进攻型投资             |
|------------|----------------------|----------------------|
| 目标       | 稳定收益与本金保护     | 高收益               |
| 风险承受   | 低风险偏好             | 高风险偏好             |
| 时间 horizon | 中长期               | 短期或中短期           |

---

## 1.2 防御型投资的哲学基础

### 1.2.1 投资的三项基本原则
1. **本金保护**：优先考虑本金的安全性。
2. **价值发现**：寻找市场价格低于内在价值的资产。
3. **分散风险**：通过多样化投资降低特定风险。

### 1.2.2 防御型投资的长期视角
格雷厄姆强调长期投资的重要性，认为短期市场波动不可预测，但长期来看，资产的内在价值会反映其真实价值。

# 第2章：防御型投资的数学模型与风险管理

## 2.1 风险与收益的数学模型

### 2.1.1 马科维茨的有效前沿理论
马科维茨提出的投资组合理论为防御型投资提供了数学基础。通过优化投资组合的收益与风险，投资者可以在可行的范围内找到最优配置。

$$
\text{收益最大化} = \sum w_i r_i
$$

$$
\text{风险最小化} = \sqrt{\sum w_i^2 \sigma_i^2 + \sum w_i w_j \sigma_{ij}}
$$

### 2.1.2 风险调整后的收益模型
在防御型投资中，收益需扣除因风险承担而获得的超额收益。

$$
\text{风险调整后收益} = \text{收益} - \text{风险溢价}
$$

## 2.2 防御型投资的风险管理策略

### 2.2.1 基于VaR的风险度量
Value at Risk（VaR）是一种常用的风险度量方法，用于估计投资组合在特定置信水平下的潜在损失。

$$
\text{VaR} = \text{损失的最高值在特定概率下}
$$

### 2.2.2 保险策略的数学模型
保险策略通过设定止损点或保险资产来保护本金。

$$
\text{止损点} = \text{买入价} - \text{安全边际}
$$

import numpy as np

# 示例：计算投资组合的夏普比率
def calculate Sharpe_ratio(returns, risk_free_rate):
    excess_returns = returns - risk_free_rate
    average_excess_return = np.mean(excess_returns)
    std_deviation = np.std(excess_returns)
    sharpe_ratio = average_excess_return / std_deviation
    return sharpe_ratio

# 示例数据
