# 第五章：算法原理讲解

## 5.1 K近邻算法（K-Nearest Neighbor, KNN）

- **原理**：基于距离度量，找到最相似的邻居进行分类。
- **流程图**：数据预处理 → 计算距离 → 确定邻居数 → 预测结果。
- **数学模型**：使用欧氏距离公式：$$d(x_i, x_j) = \sqrt{\sum_{k=1}^{n}(x_{ik} - x_{jk})^2}$$
- **代码实现**：Python示例代码，包括数据加载、预处理、模型训练和预测。

## 5.2 线性回归（Linear Regression）

- **原理**：通过最小二乘法拟合直线，预测目标变量。
- **流程图**：数据清洗 → 特征选择 → 模型训练 → 预测。
- **数学模型**：$$y = \beta_0 + \beta_1x + \epsilon$$
- **代码实现**：使用Scikit-learn库，包括数据加载、模型训练和评估。
