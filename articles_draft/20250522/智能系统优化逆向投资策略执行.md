## 第3章 逆向投资策略的数学模型与公式

### 3.1 投资组合优化

#### 3.1.1 数学模型
$$\text{目标函数: } \min_w \sum_{i=1}^n w_i^2$$  
$$\text{约束条件: } \sum_{i=1}^n w_i = 1$$

#### 3.1.2 风险-收益平衡
$$\text{收益: } r = w^T \mu$$  
$$\text{风险: } \sigma^2 = w^T \Sigma w$$

### 3.2 算法实现

#### 3.2.1 遗传算法实现
```python
def fitness(w, mu, Sigma):
    return w.T.dot(mu) - 0.5 * w.T.dot(Sigma).dot(w)

def evolve(w, fitness_func, mu, Sigma, pop_size=100, generations=50):
    for _ in range(generations):
        population = [w + np.random.randn(1, len(w)) * 0.1 for _ in range(pop_size)]
        fitnesses = [fitness(wi, mu, Sigma) for wi in population]
        best = max(population, key=lambda x: fitness(x, mu, Sigma))
        w = best
    return w
```
