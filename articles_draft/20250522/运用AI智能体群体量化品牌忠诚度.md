## 第3章: 算法原理

### 3.1 协同过滤算法
通过分析用户行为数据，找到相似用户群体，预测品牌忠诚度。

#### 3.1.1 算法原理
```mermaid
graph TD
    A[用户] --> B[相似用户]
    B --> C[推荐]
```

#### 3.1.2 数学模型
$$相似度 = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2} \sqrt{\sum (y_i - \bar{y})^2}}$$

### 3.2 聚类分析

### 5.2 核心实现代码
```python
from sklearn.metrics.pairwise import cosine_similarity

# 示例数据
users = ['A', 'B', 'C']
prefs = {'A': {'X': 5, 'Y': 3},
         'B': {'X': 4, 'Y': 4},
         'C': {'X': 3, 'Y': 5}}

# 转换为矩阵
user_ids = ['A', 'B', 'C']
item_ids = ['X', 'Y']

# 计算相似度
pref_matrix = [[prefs[u][i] if i in prefs[u] else 0 for i in item_ids] for u in user_ids]
similarity = cosine_similarity(pref_matrix)

print(similarity)
```
