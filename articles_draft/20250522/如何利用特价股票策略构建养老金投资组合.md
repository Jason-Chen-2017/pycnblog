# 第1章: 特价股票的定义与特性

## 1.1 什么是特价股票
- 特价股票是指价格低于市场平均值，具有较高价值的股票。
- 具体表现：低估值、高股息率、潜在上涨空间。

## 1.2 特价股票的市场定位
- 通常出现在周期性行业，如能源、材料等。
- 投资者可以通过分析市盈率、市净率等指标识别特价股票。

## 1.3 特价股票与普通股票的区别
| 特性 | 特价股票 | 普通股票 |
|------|----------|----------|
| 估值 | 低       | 市场价    |
| 风险 | 较低     | 较高     |
| 收益 | 高       | 稳定     |

# 第2章: 养老金投资的基本概念

## 2.1 养老金的定义与目标
- 养老金是为了保障退休后的生活质量，确保资金安全和稳定增长。
- 投资目标：保值、增值，注重长期收益。

## 2.2 养老金投资的原则
- 分散投资：避免过度集中风险。
- 长期视角：耐心持有，避免短期波动影响。

## 2.3 养老金投资的常见策略
- 值股策略：投资低估股票，长期持有。
- 定期定额投资：分散风险，平滑波动。

# 第3章: 特价股票策略在养老金投资中的应用

## 3.1 特价股票策略的优势
- 低估值：潜在上涨空间大。
- 高股息率：稳定收益。

## 3.2 投资组合构建的关键因素
- 股票选择：根据基本面和技术分析筛选。
- 分散投资：避免单一股票风险。

## 3.3 风险与控制
- 市场波动：通过多样化和定期调整降低风险。
- 行业风险：分散投资不同行业。
