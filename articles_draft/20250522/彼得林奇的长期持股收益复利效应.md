# 第1章: 彼得林奇的长期持股与复利效应概述

## 1.1 彼得林奇的投资理念
### 1.1.1 彼得林奇的生平简介
彼得·林奇是全球著名投资专家，强调长期持股和基本面分析。他的成功源于对市场趋势的精准把握和长期投资策略。

### 1.1.2 长期持股的核心理念
彼得林奇认为，长期持有优质股票，避免频繁交易，才能最大化收益。长期持股允许复利效应发挥作用，使收益呈指数级增长。

### 1.1.3 复利效应的定义与特点
复利效应是指投资收益再投资后，产生的收益再次产生收益，形成指数增长。其特点包括时间依赖性、初期增长慢、后期爆发性强。

## 1.2 复利效应与长期持股的结合
长期持股为复利效应提供了时间基础，而复利效应则放大了长期持股的收益。两者结合是实现财富增长的关键。

# 第2章: 复利效应的数学模型与公式

## 2.1 复利效应的基本公式
### 2.1.1 复利计算公式
$$ A = P \times (1 + r)^n $$
其中，A为终值，P为本金，r为年利率，n为年数。

### 2.1.2 年金公式
$$ A = P \times \frac{(1 + r)^n - 1}{r} $$

## 2.2 投资组合的收益模型
### 2.2.1 期望收益公式
$$ E[r] = \frac{1}{n} \sum_{i=1}^{n} r_i $$

### 2.2.2 投资风险与收益的关系
$$ \sigma = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (r_i - E[r])^2} $$

## 2.3 投资组合理论
### 2.3.1 马科维茨投资组合理论
$$ \min_{w} \frac{1}{2} w^T \Sigma w $$
$$ \text{subject to } w^T \mu = r, w^T 1 = 1 $$

### 4.2.2 投资组合优化代码
```python
import numpy as np

def optimize_portfolio(weights, returns):
    # 计算方差
    variance = np.dot(weights.T, np.dot(returns, weights))
    return variance

# 示例权重和收益
weights = np.array([0.6, 0.4])
returns = np.array([0.08, 0.05])
print(optimize_portfolio(weights, returns))
```
