## 正文

### 第一部分: 价值投资的背景与核心理念

#### 第1章: 价值投资的定义与历史演变

##### 1.1 价值投资的定义与特征
- **投资的基本概念**：投资是将资金投入资产以获得未来收益的行为。资产可以是股票、债券、房地产等。
- **价值投资的定义**：寻找市场价格低于内在价值的资产进行投资，以期获得长期收益。
- **与其他投资策略的对比**：与趋势投资和技术分析不同，价值投资注重基本面分析，寻找市场低估的企业。

##### 1.2 价值投资的历史演变
- **起源与发展**：价值投资起源于20世纪初，格雷厄姆和多德是早期代表人物。
- **现代演变**：格林布拉特在传统价值投资基础上，引入安全边际和市场先生理论，使理念更加系统化。

##### 1.3 格林布拉特的贡献
- **生平简介**：格林布拉特是哥伦比亚大学教授，著有《安全边际》等书籍。
- **创新贡献**：提出安全边际和市场先生理论，强调情绪化对市场的影响。

#### 第2章: 格林布拉特的价值投资理念

##### 2.1 核心投资策略
- **安全边际**：内在价值与市场价格的差额，是投资的安全垫。
- **市场先生理论**：将市场情绪化为市场先生，帮助投资者理性决策。

##### 2.2 投资组合管理
- **构建原则**：分散投资，降低风险。
- **股票选择标准**：低市盈率、低市净率、高收益率的股票。

##### 2.3 长期投资策略
- **优势**：避免短期波动，捕捉长期增长。
- **挑战**：需要耐心和纪律。

#### 投资组合优化算法
```python
def calculate_intrinsic_value(earnings, discount_rate):
    return earnings / discount_rate

def calculate_margin_of_safety(intrinsic_value, price):
    return intrinsic_value - price

# 示例计算
earnings = 100
discount_rate = 0.1
price = 50

iv = calculate_intrinsic_value(earnings, discount_rate)
mos = calculate_margin_of_safety(iv, price)

print(f"内在价值: {iv}, 安全边际: {mos}")
```

import pandas as pd

def analyze_stock(finance_data):
    iv = finance_data['earnings'] / finance_data['discount_rate']
    mos = iv - finance_data['price']
    return iv, mos

# 数据输入
data = {
    'earnings': 100,
    'discount_rate': 0.1,
    'price': 50
}

# 分析
iv, mos = analyze_stock(data)
