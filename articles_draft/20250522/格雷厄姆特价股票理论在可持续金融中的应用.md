## 第二部分：核心概念与联系

### 第2章：格雷厄姆特价股票理论的核心要素

#### 2.1 分析工具与方法

- **内在价值计算公式**：
  内在价值 = 股息率 / (增长率 - 股票必要回报率)
  $$ V = \frac{D}{k - g} $$
  其中，D为股息，k为必要回报率，g为增长率。

- **市盈率与市净率的分析**：通过比较市盈率和市净率，判断股票是否被低估。

#### 2.2 格雷厄姆防御性投资策略

- **防御性投资的核心**：投资于基本面稳健、财务健康的公司。

#### 4.2 核心实现

- **代码示例**：计算内在价值并结合ESG评分。
  ```python
  import pandas as pd
  import requests

  def calculate_intrinsic_value(dividends, growth_rate, required_return):
      return dividends / (required_return - growth_rate)

  def get_esg_rating(ticker):
      # 示例：使用公开API获取ESG评分
      response = requests.get(f'https://api.example.com/esg/{ticker}')
      return response.json()['rating']

  # 示例计算
  ticker = 'AAPL'
  dividends = 3.28  # 假设股息
  growth_rate = 0.05
  required_return = 0.10
  iv = calculate_intrinsic_value(dividends, growth_rate, required_return)
  esg = get_esg_rating(ticker)
  print(f"{ticker}的内在价值为{iv}，ESG评分为{esg}")
  ```
