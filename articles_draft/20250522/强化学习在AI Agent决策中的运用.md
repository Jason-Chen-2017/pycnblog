## 第二部分: 强化学习的核心概念与数学模型

### 第3章: 强化学习的核心概念

#### 3.1 状态、动作和奖励
- 状态：环境中的信息表示
- 动作：AI Agent的决策输出
- 奖励：环境对决策的反馈

#### 3.2 策略与价值函数
- 策略：AI Agent决策的规则
- 价值函数：状态或动作的价值评估
- 探索与利用：平衡新旧策略的选择

#### 3.3 强化学习的数学模型
- 状态转移概率：P(s', r | s, a)
- 价值函数的数学表达：V(s) = max_a Q(s,a)
- 策略的数学表示：π(a|s) = P(a|s)

### 第4章: 强化学习的核心算法

#### 4.1 Q-Learning算法
- Q-Learning的基本原理：通过经验更新Q值表
- Q-Learning的数学公式：Q(s,a) = Q(s,a) + α[r + γ max Q(s',a')]
- Q-Learning的实现步骤：环境交互、状态转移、奖励计算、Q值更新

#### 4.2 策略梯度方法
- 策略梯度的基本概念：通过梯度上升优化策略
- 策略梯度的数学推导：∇J = E[∇log π(a|s) Q(s,a)]
- 策略梯度的实现步骤：状态感知、策略输出、梯度计算、策略更新
