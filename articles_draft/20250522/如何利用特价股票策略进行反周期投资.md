## 1. 特价股票策略与反周期投资基础

### 1.1 特价股票的定义与特征

#### 1.1.1 特价股票的定义

特价股票是指在市场低迷或经济不景气时期，价格被市场低估的股票。这些股票通常具有较高的安全边际，适合在市场底部阶段买入。

#### 1.1.2 特价股票的特征

| 特性 | 描述 |
|------|------|
| 低估值 | PE、PB等估值指标低于行业平均水平 |
| 高股息率 | 相对于市场平均水平，股息率较高 |
| 弱势行业龙头 | 在行业低谷期，龙头企业更具抗风险能力 |
| 基本面改善 | 公司财务状况逐步改善，业绩预期向好 |

### 1.2 反周期投资的定义与特点

#### 1.2.1 反周期投资的定义

反周期投资是指在经济周期的低谷期进行投资，利用市场的低估和恐慌情绪，捕捉被市场忽视的投资机会。

#### 1.2.2 反周期投资的核心特征

| 特性 | 描述 |
|------|------|
| 抗跌性 | 在市场下跌时表现相对稳定 |
| 低相关性 | 与其他资产类别相关性较低，分散风险 |
| 逆向思维 | 在市场恐慌时买入，在市场疯狂时卖出 |
