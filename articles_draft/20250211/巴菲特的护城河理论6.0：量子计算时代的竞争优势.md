## 第2章：护城河理论的核心要素与分析框架

### 2.1 护城河理论的核心要素
护城河的五大要素是企业竞争优势的核心来源：
1. **品牌优势**：强大的品牌能够吸引客户并形成忠诚度。
2. **成本优势**：通过规模效应或流程优化降低生产成本。
3. **资源优势**：拥有独特的资源储备或供应链优势。
4. **技术优势**：掌握核心技术或专利，形成技术壁垒。
5. **创新优势**：持续创新能力是企业长期竞争优势的关键。

#### 图表2-1：护城河要素属性对比
| 要素       | 属性       | 描述                               |
|------------|------------|------------------------------------|
| 品牌优势   | 客户忠诚度 | 强大的品牌能够提高客户忠诚度       |
| 成本优势   | 价格优势   | 低成本策略能够提高市场竞争力       |
| 资源优势   | 稀缺性     | 独特资源的稀缺性形成竞争优势       |
| 技术优势   | 技术壁垒   | 核心技术或专利形成市场进入障碍     |
| 创新优势   | 持续能力   | 持续创新能力能够保持竞争优势       |

import numpy as np

def calculate_weights(matrix):
    # 计算一致性系数
    n = len(matrix)
    max_values = np.max(matrix, axis=1)
    CI = np.zeros(n)
    for i in range(n):
        CI[i] = (max_values[i] - 1) / (n - 1)
    return CI

# 示例矩阵
matrix = np.array([
    [1, 2, 3],
    [2, 1, 2],
    [3, 2, 1]
])

# 计算一致性系数
weights = calculate_weights(matrix)
print(weights)
