  ```python
  import numpy as np
  def generate_photon_signal(frequency, duration, sampling_rate):
      t = np.linspace(0, duration, sampling_rate)
      I0 = 1
      I1 = 2
      signal = I0 + I1 * np.cos(2 * np.pi * frequency * t)
      return signal
  ```

- 6.2.2 光子信号处理的代码实现
  ```python
  from scipy import signal
  def process_photon_signal(signal, cutoff_frequency, sampling_rate):
      nyquist = 0.5 * sampling_rate
      cutoff = cutoff_frequency / nyquist
      b, a = signal.butter(4, cutoff, 'low')
      output = signal.lfilter(b, a, signal)
      return output
  ```
