#### 第4章: 经济护城河的数学模型与公式

- **4.1 成本优势的数学模型**
  - 4.1.1 成本优势指数 = (企业平均成本 / 行业平均成本) - 1
  - 4.1.2 示例：企业成本为 $10，行业成本为 $15，指数 = (10/15) - 1 = -0.33，表示企业成本优势为33%

- **4.2 品牌忠诚度的数学模型**
  - 4.2.1 忠诚度指数 = (重复购买率 + 好评率) / 2
  - 4.2.2 示例：重复购买率为80%，好评率为90%，指数 = (80 + 90)/2 = 85%

- **4.3 网络效应的数学模型**
  - 4.3.1 网络效应指数 = (新增用户数 / 现有用户数) * 网络效应系数
  - 4.2.2 示例：新增用户数为100，现有用户数为500，网络效应系数为2，指数 = (100/500)*2 = 0.4
