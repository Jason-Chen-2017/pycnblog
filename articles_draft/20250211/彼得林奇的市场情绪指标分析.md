## 第2章：彼得林奇市场情绪指标的核心概念

### 2.1 市场情绪指标的核心原理

彼得林奇的指标通过分析价格和成交量的变化，捕捉市场情绪的波动。其核心公式为：
$$
情绪指数 = \frac{价格波动率}{平均成交量}
$$

### 2.2 市场情绪指标的关键属性

| 属性 | 描述 |
|------|------|
| 敏感性 | 指标对市场变化的反应速度 |
| 滞后性 | 指标基于过去数据，存在滞后 |
| 可操作性 | 指标易于计算和应用 |

import pandas as pd

def calculate_momentum(close_prices, window=10):
