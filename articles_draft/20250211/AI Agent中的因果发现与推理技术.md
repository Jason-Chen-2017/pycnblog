# 第3章: 因果推理的数学模型与公式

## 3.1 因果关系的数学表示
### 3.1.1 因果图的结构化表示
- 因果图的结构化表示：通过节点和边表示因果关系。
- 示例：因果图中节点A指向节点B，表示A是B的原因。

### 3.1.2 因果关系的符号表示
- 符号表示：使用符号和公式表示因果关系。
- 示例：$A \rightarrow B$ 表示A是B的原因。

### 3.1.3 因果效应的定义与计算
- 因果效应的定义：因果效应是指原因变量的变化对结果变量的影响。
- 计算：通过因果图计算因果效应。

## 3.2 马尔可夫条件与因果推理
### 3.2.1 马尔可夫条件的定义
- 马尔可夫条件：在因果图中，每个节点只与其父节点和子节点相关。

### 3.2.2 马尔可夫条件与因果图的关系
- 马尔可夫条件用于简化因果推理的复杂性。
- 应用：通过马尔可夫条件简化因果图的计算。

### 3.2.3 马尔可夫假设在因果推理中的应用
- 马尔可夫假设用于处理因果关系中的条件独立性。
- 示例：在因果图中，节点A和C独立，因为它们共享一个共同的原因B。

## 3.3 因果推理的数学公式
### 3.3.1 因果效应的公式表示
$$P(y|x_{do}, w) = \frac{P(y, x_{do}, w)}{P(x_{do}|w)}$$

### 3.3.2 马尔可夫边界条件的应用
$$P(y|x_{do}, w) = P(y|x, w) \text{ 当 } x \text{ 是 } y \text{ 的后裔}$$

### 6.2.2 核心代码实现
```python
import numpy as np
import networkx as nx

def causal_discovery(data):
    # 数据预处理
    G = nx.DiGraph()
    # 构建因果图
    for i in range(data.shape[0]):
        for j in range(data.shape[1]):
            if data[i][j] > 0:
                G.add_edge(i, j)
    return G

# 示例数据
data = np.array([[0, 1, 0], [0, 0, 1], [0, 0, 0]])
causal_graph = causal_discovery(data)
print(causal_graph.nodes())
```
