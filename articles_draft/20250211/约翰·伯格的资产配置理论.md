## 第一部分: 资产配置理论的背景与核心概念

### 第1章: 资产配置理论的背景介绍

#### 1.1 资产配置的核心概念

##### 1.1.1 资产配置的定义与问题背景
资产配置是投资组合管理中的核心策略，指按比例分配资金到不同资产类别（股票、债券、现金等），以实现风险与收益的平衡。问题背景在于，单一资产的风险较高，通过分散投资降低整体风险。

##### 1.1.2 资产配置的目标与问题描述
目标：最大化收益，最小化风险。问题：如何在不同资产间分配资金，平衡风险与收益。

##### 1.1.3 资产配置问题的解决思路
通过数学模型优化资产比例，实现收益-风险最优。

##### 1.1.4 资产配置的边界与外延
边界：资金分配比例约束。外延：扩展到风险管理、动态调整等。

##### 1.1.5 资产配置的核心要素组成
- 资产类别：股票、债券、现金。
- 风险偏好：影响配置比例。
- 时间跨度：长期或短期。

#### 1.2 约翰·伯格的资产配置理论概述

##### 1.2.1 约翰·伯格的生平简介
约翰·伯格（John Bogle）是指数基金之父， Vanguard集团创始人，倡导低成本、被动投资。

##### 1.2.2 伯格理论的演变与核心思想
核心思想：长期投资、分散投资、低成本。理论演变：从主动管理转向被动管理。

##### 1.2.3 伯格理论与其他资产配置理论的对比
与MPT对比：MPT强调优化风险，伯格强调低成本和长期持有。

### 第3章: 约翰·伯格资产配置理论的数学模型与算法

#### 3.1 投资组合理论的数学模型

##### 3.1.1 资产配置的优化目标函数
$$ \text{最大化 } \mu \cdot w - 0.5 \cdot w^T \Sigma w $$

##### 3.1.2 风险与收益的数学表达
$$ \text{风险 } = w^T \Sigma w $$
$$ \text{收益 } = w^T \mu $$

#### 3.2 约翰·伯格的指数基金策略

##### 3.2.1 指数基金的数学模型
$$ \text{总收益 } = \sum_{i=1}^n w_i r_i $$

##### 3.2.2 成本最小化模型
$$ \text{总成本 } = \sum_{i=1}^n w_i c_i $$

#### 3.3 算法实现与代码示例

##### 3.3.1 投资组合优化的Python代码实现
```python
import numpy as np

# 示例数据
mu = np.array([0.1, 0.15])
Sigma = np.array([[0.05, 0.02], [0.02, 0.08]])

# 优化目标函数
def objective(w):
    return -w.T.dot(mu) + 0.5 * w.T.dot(Sigma).dot(w)

# 约束条件：w.sum() == 1
from scipy.optimize import minimize

w0 = np.array([0.5, 0.5])
cons = {'type': 'eq', 'fun': lambda w: sum(w) - 1}

result = minimize(objective, w0, constraints=cons)
print(result.x)
```

# 计算优化权重
def optimize_portfolio(expected_returns, covariance_matrix):
    n = len(expected_returns)
    mu = np.array(expected_returns)
    Sigma = np.array(covariance_matrix)
    
    def objective(w):
        return -w.T.dot(mu) + 0.5 * w.T.dot(Sigma).dot(w)
    
    cons = {'type': 'eq', 'fun': lambda w: sum(w) - 1}
    w0 = np.array([1.0/n]*n)
    
    result = minimize(objective, w0, constraints=cons)
    return result.x

# 示例应用
expected_returns = [0.1, 0.05]
covariance_matrix = [[0.05, 0.02], [0.02, 0.08]]
weights = optimize_portfolio(expected_returns, covariance_matrix)
print(weights)
