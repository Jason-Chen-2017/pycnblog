# 第1章: 知识图谱的基本概念

## 1.1 知识图谱的定义与特点

### 1.1.1 知识图谱的定义
知识图谱是一种以结构化形式表示知识的图数据，由节点和边组成，节点代表实体或概念，边表示它们之间的关系。知识图谱通过将分散的知识组织成图结构，实现了对现实世界的语义表示。

### 1.1.2 知识图谱的核心特点
1. **结构化**：知识图谱以图的形式组织数据，支持复杂的语义关系表示。
2. **可扩展性**：知识图谱可以通过不断添加新的节点和边扩展知识。
3. **语义丰富性**：知识图谱不仅存储事实，还能表示隐含的关系和语义。

### 1.1.3 知识图谱与传统数据库的区别
| 特性             | 知识图谱             | 传统数据库         |
|------------------|----------------------|---------------------|
| 数据结构         | 图结构               | 行数据             |
| 查询能力         | 支持复杂语义查询     | 支持简单查询       |
| 知识表示         | 面向语义             | 面向记录           |

## 1.2 AI Agent的基本概念

### 1.2.1 AI Agent的定义
AI Agent（智能体）是一种能够感知环境、自主决策并执行任务的实体。它可以是一个软件程序、机器人或其他智能系统。

### 1.2.2 AI Agent的核心特点
1. **自主性**：AI Agent能够自主决策，无需外部干预。
2. **反应性**：AI Agent能够实时感知环境并做出反应。
3. **社交能力**：AI Agent能够与其他智能体或人类进行交互。

### 1.2.3 AI Agent与传统程序的区别
| 特性             | AI Agent             | 传统程序           |
|------------------|----------------------|--------------------|
| 感知能力         | 具备                 | 无                 |
| 决策能力         | 具备                 | 无                 |
| 交互能力         | 具备                 | 无                 |
