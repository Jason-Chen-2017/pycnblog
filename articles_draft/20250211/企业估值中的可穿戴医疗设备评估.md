- **定义**：可穿戴医疗设备是指佩戴在身体上的医疗设备，用于监测、诊断或治疗医疗状况。

### 3.4 代码实现
以下是Python代码实现：

```python
# 数据预处理
import pandas as pd
data = pd.read_csv('medical_data.csv')
data_clean = data.dropna()

# 特征提取
features = data_clean[['heart_rate', 'temperature', 'activity_level']]
labels = data_clean['health_score']

# 模型训练
from sklearn.model import LinearRegression
model = LinearRegression()
model.fit(features, labels)

# 模型评估
from sklearn.metrics import r2_score
predictions = model.predict(features)
print(r2_score(labels, predictions))
```

import pandas as pd
from sklearn.model import LinearRegression

def evaluate_device(data):
    features = data[['heart_rate', 'temperature', 'activity_level']]
    labels = data['health_score']
    model = LinearRegression()
    model.fit(features, labels)
    return model.predict(features)

# 示例数据
data = pd.DataFrame({
    'heart_rate': [70, 75, 80],
    'temperature': [36, 36.5, 37],
    'activity_level': [low, medium, high],
    'health_score': [0.8, 0.85, 0.9]
})

result = evaluate_device(data)
print(result)
