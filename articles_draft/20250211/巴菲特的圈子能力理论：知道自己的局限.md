### 第1章：巴菲特的生平与投资理念

#### 1.1 巴菲特的早年经历
沃伦·巴菲特（Warren Buffett）出生于1930年，美国著名投资者、企业家和慈善家。他从小就展现出对投资的浓厚兴趣，12岁时开始购买股票。巴菲特的父亲是律师，母亲是家庭主妇，这使他从小接受了良好的教育和价值观培养。

#### 1.2 巴菲特的投资哲学
巴菲特的投资哲学以价值投资为核心，强调长期投资、安全边际和内在价值。他坚信市场短期波动无法预测，但长期趋势可以通过基本面分析来把握。巴菲特的价值观还包括节俭、耐心和对能力圈的坚持。

#### 1.3 巴菲特的价值观与人生信条
巴菲特的价值观包括诚实、正直、节俭和对家庭的重视。他的名言“我只想知道我将死的地方，这样我就可以确定我该去的地方”体现了他对长期目标的执着追求。

def calculate_circle_capability(S, T, G, R):
    return (S * T * G) / R
