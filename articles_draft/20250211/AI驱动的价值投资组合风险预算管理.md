### 第3章: 投资组合优化的AI算法

#### 3.1 均值-方差优化模型
##### 3.1.1 模型原理
均值-方差优化是一种经典的组合优化方法，目标是找到在给定风险水平下收益最大的投资组合。通过AI技术，可以高效计算资产的期望收益、方差和协方差矩阵，优化组合配置。

##### 3.1.2 算法实现
使用Python和机器学习库（如scikit-learn）实现均值-方差优化。以下是优化过程的代码示例：

```python
import numpy as np
import pandas as pd
from sklearn.covariance import LedoitWolf

# 假设我们有资产的收益率数据
returns = pd.DataFrame(...)

# 计算协方差矩阵
cov_matrix = LedoitWolf().fit(returns).covariance_

# 优化目标：最大化收益，最小化风险
# 使用scipy.optimize中的minimize函数进行优化
import scipy.optimize as optimize

# 定义目标函数（最小化风险）
def portfolio_variance(weights, covariance):
    return np.dot(weights.T, np.dot(covariance, weights))

# 约束条件：权重之和为1
def constraint(weights):
    return np.sum(weights) - 1

# 初始权重（均等分配）
initial_weights = np.array([1.0 / returns.shape[1]] * returns.shape[1])

# 优化
result = optimize.minimize(portfolio_variance, initial_weights, args=cov_matrix, method='SLSQP', 
                            constraints={'type': 'eq', 'fun': constraint})

# 优化后的权重
optimal_weights = result.x
```
