## 第四部分：数学模型与算法

### 第6章：风险评估的数学模型

#### 6.1 风险价值（VaR）的计算
$$ VaR = \mu + z \times \sigma $$
其中，$\mu$ 是平均回报，$z$ 是标准正态分布的分位数，$\sigma$ 是标准差。

#### 6.2 现代投资组合理论（MPT）
通过优化投资组合的方差和期望收益，实现风险与回报的最佳平衡。

### 第7章：投资组合优化的算法原理

#### 7.1 使用Python实现投资组合优化
```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def portfolio_optimization(returns, weights=None):
    n = returns.shape[0]
    if weights is None:
        weights = np.array([1.0/n]*n)
    returns = pd.DataFrame(returns)
    # 目标函数：最小化方差
    def objective(weights):
        return (weights.T @ returns.cov() @ weights)
    # 约束条件：权重之和为1
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    result = minimize(objective, weights, method='SLSQP', constraints=constraints)
    return result.x
```

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def portfolio_optimization(returns):
    n = len(returns.columns)
    returns_cov = returns.cov().values
    def objective(weights):
        return (weights.T @ returns_cov @ weights)
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    initial_guess = np.array([1.0/n]*n)
    result = minimize(objective, initial_guess, method='SLSQP', constraints=constraints)
    return pd.DataFrame(result.x, index=returns.columns)
```
