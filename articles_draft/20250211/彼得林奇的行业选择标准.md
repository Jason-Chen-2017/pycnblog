### 2.1 核心概念原理

彼得林奇的行业选择标准主要包括以下几个方面：

1. **行业前景**：行业是否处于增长阶段，市场需求是否稳定。
2. **企业竞争优势**：企业在行业内是否具有技术、成本或品牌等优势。

### 3.2 Python源代码实现

以下是一个简单的Python代码，用于评估企业的竞争优势：

```python
def assess_competitive_advantage(company_data):
    # 输入：company_data 包含企业数据，如技术投入、成本占比等
    # 输出：竞争优势评估结果（高、中、低）
    tech_investment = company_data['tech_investment']
    cost_ratio = company_data['cost_ratio']
    market_share = company_data['market_share']
    
    if tech_investment > 10% and cost_ratio < 20% and market_share > 25%:
        return "高"
    elif tech_investment > 8% and cost_ratio < 30% and market_share > 15%:
        return "中"
    else:
        return "低"
```
