## 第一部分：主动投资的背景与概念

### 第1章：主动投资的基本定义

#### 1.1 投资的定义与分类
投资是将资源（如资金）投入到特定项目或资产中，以期获得未来收益的行为。根据投资策略的不同，可以分为**主动投资**和**被动投资**。

- **主动投资**：投资者主动选择资产，通过分析市场趋势和公司基本面来优化投资组合，追求超越市场平均收益。
- **被动投资**：投资者遵循固定规则，如指数基金投资，追求与市场持平的收益。

#### 1.2 约翰·伯格的学术背景与投资理念
约翰·伯格是投资领域的权威，以其对指数基金的研究闻名。他于1973年提出了著名的**伯格公式**，并强调长期投资的重要性。

- **伯格公式**：$$ \text{预期收益} = \text{无风险利率} + \beta \times (\text{市场收益} - \text{无风险利率}) $$
- 伯格的投资理念：长期持有优质资产，避免频繁交易。

#### 1.3 主动投资的核心概念
主动投资的核心在于通过精选个股或特定资产，超越市场指数的表现。其成功依赖于投资者的分析能力和市场判断力。

---

### 第2章：主动投资与被动投资的对比

#### 2.1 主动投资的优缺点
- **优点**：可能获得超额收益，适合市场机会捕捉。
- **缺点**：交易成本高，市场波动风险大。

#### 2.2 约翰·伯格对主动投资的批评
伯格认为，大多数主动投资者无法长期跑赢市场，主要原因包括：
1. **交易成本**：频繁交易增加了佣金和税费。
2. **市场预测难度**：主动投资依赖于准确的市场预测，而市场具有不确定性。
3. **情绪干扰**：投资者容易受到市场情绪影响，做出非理性决策。

#### 2.3 被动投资的优势
伯格推荐被动投资，尤其是指数基金，因为其费用低、风险分散、长期收益稳定。

## 第二部分：主动投资的核心概念与原理

### 第3章：主动投资的数学模型

#### 3.1 资本资产定价模型（CAPM）
CAPM是主动投资的重要理论基础，用于计算资产的预期收益：
$$ E(r_i) = r_f + \beta_i (E(r_m) - r_f) $$
其中：
- \( E(r_i) \)：资产i的预期收益率
- \( r_f \)：无风险利率
- \( \beta_i \)：资产i的贝塔系数（衡量波动性）
- \( E(r_m) \)：市场预期收益率

#### 3.2 约翰·伯格的实证研究
伯格通过大量数据分析发现，主动投资的超额收益难以持续，且费用过高。

#### 4.2 代码实现
```python
import numpy as np

def expected_return(risk_free_rate, beta, market_return):
    return risk_free_rate + beta * (market_return - risk_free_rate)

# 示例数据
risk_free_rate = 0.05
beta = 1.2
market_return = 0.10

print(expected_return(risk_free_rate, beta, market_return))
```

#### 4.3 实例分析
假设市场预期收益率为10%，无风险利率为5%，某资产贝塔系数为1.2，其预期收益率为：
$$ 0.05 + 1.2 \times (0.10 - 0.05) = 0.11 \text{或} 11\% $$

### 第7章：投资策略优化

#### 7.1 最佳实践
- 长期投资优于短期交易。
