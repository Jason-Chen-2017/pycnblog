- **3.3 数学模型与公式**
  - **3.3.1 多智能体协作模型**
    - 状态表示：$s = (s_1, s_2, ..., s_n)$
    - 行动表示：$a_i = \arg\max_{a} Q(s_i, a)$
    - 奖励函数：$r = R(s, a)$
  - **3.3.2 跨域知识迁移模型**
    - 知识表示：$k = f(x)$
    - 迁移权重：$\alpha_{ij} = \frac{sim(k_i, k_j)}{\sum sim(k_i, k_j)}}$
  - **3.3.3 跨域决策优化模型**
    - 决策函数：$d = \arg\max_{d} \sum_{i=1}^{n} w_i Q_i(d)$
    - 优化目标：$\min_{d} \sum_{i=1}^{n} (Q_i(d) - y_i)^2$
