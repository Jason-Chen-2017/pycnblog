### 第3章: 费雪框架的算法原理

#### 3.1 博弈论模型的数学表达
##### 3.1.1 纳什均衡的数学公式
$$\text{纳什均衡定义为：对于策略组合 } (s_1, s_2, ..., s_n), \text{每个玩家的策略 } s_i \text{ 是最佳反应。}$$

##### 3.1.2 费雪框架的算法流程

    B --> C[确定收益函数]

#### 3.2 算法实现
##### 3.2.1 Python代码实现
```python
import numpy as np

def nash_equilibrium(payoff_matrix):
    # 假设 payoff_matrix 是一个二维数组，行代表当前玩家的策略，列代表对手的策略
    n = len(payoff_matrix)
    for i in range(n):
        for j in range(n):
            # 检查是否是纳什均衡
            is_nash = True
            current payoff = payoff_matrix[i][j]
            for k in range(n):
                if k != i:
                    if payoff_matrix[k][j] > current payoff:
                        is_nash = False
                        break
            if not is_nash:
                break
            if is_nash:
                return (i, j)
    return None

# 示例支付矩阵
payoff_matrix = np.array([[3, 1], [1, 2]])
equilibrium = nash_equilibrium(payoff_matrix)
print(f"纳什均衡点为：{equilibrium}")
```

##### 3.2.2 算法解读
上述代码实现了纳什均衡的计算，通过遍历所有可能的策略组合，检查每个策略是否是最佳反应。如果是，则返回纳什均衡点。
