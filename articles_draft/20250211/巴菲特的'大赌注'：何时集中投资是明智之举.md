# 第1章: 巴菲特的投资哲学概述

## 1.1 巴菲特的投资理念

### 1.1.1 价值投资的核心思想
价值投资是一种基于对公司内在价值评估的投资策略，核心在于寻找市场价格低于内在价值的公司。巴菲特的导师本杰明·格雷厄姆曾强调，投资的本质是寻找具有安全边际的企业。巴菲特在此基础上，发展出一套以企业基本面分析为核心的价值投资体系。

- **内在价值公式**：$$ V = \frac{E}{k} $$，其中$V$为内在价值，$E$为企业未来现金流的现值，$k$为折现率。

### 1.1.2 集中投资的哲学基础
巴菲特认为，集中投资于少数优质企业可以最大限度地利用知识优势，降低投资风险，并提高投资效率。他强调，投资者应将资金集中在那些具有强大竞争优势、良好管理团队和可持续盈利能力的企业上。

### 1.1.3 巴菲特投资成功的三大要素
1. **优秀的企业**：具有强大的竞争优势和持续的盈利能力。
2. **合理的市场价格**：以低于内在价值的价格买入。
3. **长期持有**：耐心持有优质资产，避免频繁交易。

## 1.2 集中投资的定义与特征

### 1.2.1 集中投资的定义
集中投资是指将大部分资金投资于少数优质企业，通过深度研究和精选个股来实现超额收益的投资策略。

### 1.2.2 集中投资的核心特征对比表格
| 特征          | 集中投资        | 分散投资        |
|---------------|----------------|----------------|
| 投资标的数    | 少              | 多              |
| 风险           | 高              | 低              |
| 收益潜力       | 高              | 中等            |
| 管理复杂度     | 高              | 低              |

### 1.2.3 集中投资与分散投资的ER实体关系图

巴菲特的投资决策模型可以简化为以下几个步骤：
1. 确定投资目标：寻找具有持续竞争优势的企业。
