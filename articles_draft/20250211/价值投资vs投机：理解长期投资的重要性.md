# 第一部分：价值投资与投机的背景与核心概念

## 第1章：价值投资与投机的背景介绍

### 1.1 价值投资与投机的核心概念

#### 1.1.1 价值投资的定义与背景
- **价值投资**：以低于内在价值的价格买入优质资产，长期持有，追求安全边际和复利效应。
- **背景**：起源于20世纪初，以本杰明·格雷厄姆和戴维·多德为代表，强调安全边际和基本面分析。

#### 1.1.2 投机的定义与背景
- **投机**：通过预测市场短期波动，以高买低卖或低买高卖赚取利润。
- **背景**：常见于短期交易，依赖市场情绪和技术分析，风险较高。

#### 1.1.3 价值投资与投机的边界与外延
- **边界**：长期 vs 短期、基本面分析 vs 技术分析。
- **外延**：价值投资强调长期稳健，而投机强调短期收益。

## 第2章：价值投资与投机的核心概念原理

### 2.1 价值投资的原理与方法
#### 2.1.1 股票的内在价值评估
- **公式**：内在价值 = 股息率 / WACC（加权平均资本成本）。
- **分析**：以苹果公司为例，计算其内在价值与市场价的对比。

#### 2.1.2 质量、价格与市场先生的关系
- **市场先生**：格雷厄姆的比喻，市场情绪波动影响价格，但不影响内在价值。
- **质量**：选择具有强大竞争优势的企业。

#### 2.1.3 安全边际的计算方法
- **公式**：安全边际 = 内在价值 - 市场价。
- **分析**：安全边际越大，投资风险越小。

### 2.2 投机的原理与风险
#### 2.2.1 市场情绪与价格波动
- **情绪周期**：市场的兴奋、贪婪、恐慌、绝望四个阶段。
- **分析**：利用情绪周期进行短期交易。

#### 2.2.2 技术分析与市场预测
- **技术指标**：如RSI（相对强度指数）、MACD（移动平均收敛散度）。
- **公式**：RSI = (n天内上涨天数 / n天总天数) * 100。

#### 2.2.3 投机的风险与收益平衡
- **风险**：高波动性导致高风险。
- **收益**：短期高收益，但需承担更大的风险。

### 2.3 价值投资与投机的对比分析
#### 2.3.1 核心概念对比
| 对比维度 | 价值投资 | 投机 |
|----------|-----------|------|
| 时间框架 | 长期      | 短期  |
| 分析方法 | 基本面分析 | 技术分析 |
| 风险承受 | 低        | 高    |

#### 2.3.2 投资策略差异
- **价值投资**：买入并持有，追求长期复利。
- **投机**：频繁交易，依赖市场波动。

#### 2.3.3 长期 vs 短期目标
- **长期目标**：稳健增长，注重安全边际。
- **短期目标**：快速获利，但风险较高。

import pandas as pd
import numpy as np

def calculate_rsi(data, n=14):
    # 计算n天的涨跌幅度
    df = data['Close'].diff().dropna()
    up_days = df[df > 0]
    down_days = df[df <= 0]
    rs = up_days.rolling(n).mean() / down_days.rolling(n).mean().abs()
    rsi = 100 - 100 * (1 - rs)
    return rsi

# 示例数据
data = pd.read_csv('stock_data.csv')
rsi = calculate_rsi(data)
print(rsi)
```
