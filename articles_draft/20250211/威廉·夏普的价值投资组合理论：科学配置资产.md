## 第一部分：价值投资组合理论的背景与基础

### 第1章：投资组合理论的历史演变

#### 1.1 投资组合理论的起源与发展

投资组合理论是现代金融学的核心理论之一，其起源可以追溯到20世纪初。早期的投资理论主要关注单个资产的收益与风险，而夏普的现代投资组合理论（MPT）则引入了分散化和风险调整的概念，彻底改变了传统的投资观念。

#### 1.2 威廉·夏普的贡献与影响

威廉·夏普因其在投资组合理论上的贡献而闻名，尤其是在夏普比率和有效边界理论上的突破性研究。夏普不仅提出了夏普比率，还通过数学模型证明了分散化投资的有效性，为现代金融理论奠定了基础。

#### 1.3 价值投资组合理论的核心理念

价值投资强调通过深入分析资产的内在价值来制定投资策略。夏普的理论则通过优化模型，帮助投资者在风险可控的前提下最大化收益，体现了科学与艺术的结合。

```python
import numpy as np

def sharpe_ratio(returns, r):
    # 计算夏普比率
    excess_returns = returns - r
    mean_excess_return = np.mean(excess_returns)
    std_deviation = np.std(excess_returns)
    return mean_excess_return / std_deviation
```
