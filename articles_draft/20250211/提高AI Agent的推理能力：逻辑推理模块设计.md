## 第2章: 核心概念与联系

### 2.1 逻辑推理的原理
#### 2.1.1 命题逻辑
处理原子命题和逻辑连接词，如“与”、“或”、“非”、“蕴含”和“当且仅当”。

#### 2.1.2 谓词逻辑
使用谓词和量词表示更复杂的事实和关系，如“所有人类都是 mortal”。

#### 2.1.3 模态逻辑
扩展逻辑系统，处理可能性、必然性和时态性，如“可能下雨”和“必然停止”。

### 2.2 核心概念对比
#### 2.2.1 不同逻辑系统的特征对比
| 逻辑类型 | 主要特征 | 示例 |
|----------|----------|------|
| 命题逻辑 | 处理原子命题 | P → Q |
| 谓词逻辑 | 使用谓词和量词 | ∀x Human(x) → Mortal(x) |
| 模态逻辑 | 处理可能性 | □P 表示必然P |

#### 2.2.2 逻辑推理与知识表示的关系
知识表示是逻辑推理的前提，逻辑推理是对知识进行处理和应用的过程。

#### 2.2.3 逻辑推理与不确定性推理的对比
逻辑推理处理确定性事实，不确定性推理处理概率和模糊信息。

## 第3章: 算法原理讲解

### 3.1 基于命题逻辑的推理算法
#### 3.1.1 DPLL算法
DPLL用于 SAT 问题，包括单元子句处理、纯符号消除和二进制决策等步骤。

#### 3.1.2 算法实现
```mermaid

    Start --> SelectVariable --> Branch --> Simplify --> CheckSAT
```

#### 3.1.3 算法实现代码
```python
def dpll(sat, symbols, model):
    if not symbols:
        return trivially_satisfied(sat, model)
    symbol = symbols[0]
    return dpll(sat, symbols[1:], model + {symbol: True}) or \
           dpll(sat, symbols[1:], model + {symbol: False})
```
