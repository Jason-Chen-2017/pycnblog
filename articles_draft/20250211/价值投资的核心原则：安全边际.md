### 第3章: 内在价值的数学模型

#### 3.1 内在价值的现值公式
$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$
其中，$V$ 是内在价值，$CF_t$ 是第 $t$ 年的现金流，$r$ 是折现率。

#### 3.2 内在价值与市场价值的对比
- 内在价值的计算步骤
- 市场价值的影响因素
- 安全边际的计算公式
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

#### 4.2 Python实现的安全边际算法
```python
def calculate_intrinsic_value(company_info):
    # 计算现金流
    cash_flows = company_info['cash_flows']
    discount_rate = company_info['discount_rate']
    # 现值计算
    intrinsic_value = sum(cash_flow / (1 + discount_rate)**t for t, cash_flow in enumerate(cash_flows))
    return intrinsic_value

def calculate_margin_of_safety(company_info):
    intrinsic_value = calculate_intrinsic_value(company_info)
    market_price = company_info['market_price']
    margin_of_safety = intrinsic_value - market_price
    return margin_of_safety

# 示例用法
company_info = {
    'cash_flows': [100, 120, 150],
    'discount_rate': 0.1,
    'market_price': 80
}
margin_of_safety = calculate_margin_of_safety(company_info)
print(f"安全边际为：{margin_of_safety}")
```

import pandas as pd
import numpy as np

def calculate_intrinsic_value(finance_data, discount_rate):
    cash_flows = finance_data['现金流']
    return np.npv(discount_rate, cash_flows)

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
finance_data = {
    '现金流': [100, 120, 150],
    '市场价': 80
}
discount_rate = 0.1

intrinsic_value = calculate_intrinsic_value(finance_data, discount_rate)
margin_of_safety = calculate_margin_of_safety(intrinsic_value, finance_data['市场价'])
print(f"内在价值：{intrinsic_value:.2f}")
print(f"安全边际：{margin_of_safety:.2f}")
