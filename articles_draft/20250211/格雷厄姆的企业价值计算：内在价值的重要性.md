# 第1章: 价值投资概述

## 1.1 价值投资的核心理念

### 1.1.1 价值投资的定义

价值投资是一种投资策略，旨在通过寻找市场定价低于其内在价值的资产，从而实现长期稳定的收益。其核心在于识别市场低估的机会，而不是跟随市场的短期波动。

### 1.1.2 价值投资的历史发展

价值投资起源于20世纪初，由本杰明·格雷厄姆和戴维德·多德共同提出。他们的理论奠定了价值投资的基础，强调通过基本面分析来评估资产的内在价值。

### 1.1.3 价值投资与其他投资方法的区别

与技术分析和趋势投资不同，价值投资注重企业的内在价值，而非市场的短期走势。它通过分析财务报表、行业地位和管理团队等因素，寻找具有长期竞争优势的企业。

## 1.2 格雷厄姆的投资理念

### 1.2.1 格雷厄姆的生平简介

本杰明·格雷厄姆（1894-1976）是价值投资的鼻祖，被誉为“价值投资之父”。他是哥伦比亚大学的教授，同时也是著名的投资经理人，曾管理过格雷厄姆-纽曼公司。

### 1.2.2 格雷厄姆的价值投资理论

格雷厄姆提出，市场价格与内在价值之间存在差异，这种差异为投资者提供了获利的机会。他强调安全边际的重要性，即内在价值与市场价格之间的差距，以降低投资风险。

### 1.2.3 格雷厄姆与巴菲特的关系

格雷厄姆是巴菲特的导师，巴菲特继承并发展了格雷厄姆的价值投资理论，将其应用于更广泛的领域。

## 1.3 企业价值评估的基本概念

### 1.3.1 企业价值的定义

企业价值是指企业在公平市场条件下，所有股东权益的公允价值。它包括企业的资产、负债、未来现金流和品牌价值等因素。

### 1.3.2 内在价值与市场价值的对比

内在价值是企业的真实价值，与市场波动无关；市场价值是资产在市场上的交易价格，受市场情绪和流动性影响。

### 1.3.3 企业价值评估的边界与外延

企业价值评估需要考虑的因素包括财务状况、行业竞争、管理团队、宏观经济环境等。外延则包括企业的未来增长潜力和市场地位。

## 1.4 本章小结

本章介绍了价值投资的核心理念和格雷厄姆的投资理论，明确了企业价值评估的基本概念和内在价值的重要性。

# 第2章: 格雷厄姆的企业价值评估方法

## 2.1 格雷厄姆的企业价值评估模型

### 2.1.1 格雷厄姆的基本公式

格雷厄姆提出了著名的内在价值公式：内在价值 = (盈利 + 非经营性资产价值) / 最低资本需求率。

### 2.1.2 格雷厄姆的内在价值计算公式

内在价值计算需要考虑企业的盈利能力和财务状况，通过分析净利润、资产和负债等因素来估算。

### 2.1.3 格雷厄姆模型的优缺点

优点：简单易懂，注重安全边际；缺点：忽略了市场波动和管理层因素。

## 2.2 格雷厄姆的企业价值评估步骤

### 2.2.1 确定企业的核心业务

分析企业的主营业务收入和利润来源，识别其核心竞争力。

### 2.2.2 评估企业的财务状况

通过财务报表分析企业的资产、负债和股东权益，计算关键财务指标。

### 2.2.3 计算企业的内在价值

结合财务数据和市场情况，应用格雷厄姆的公式估算企业的内在价值。

# 第3章: 企业价值评估的数学模型与公式

## 3.1 格雷厄姆的内在价值计算公式

### 3.1.1 内在价值公式

$$内在价值 = \frac{盈利 + 非经营性资产价值}{最低资本需求率}$$

### 3.1.2 股东权益公式的应用

股东权益 = 资产 - 负债

### 3.1.3 资产负债表分析公式

资产 = 负债 + 股东权益

## 3.2 格雷厄姆的股息贴现模型

### 3.2.1 股息贴现模型的定义

股息贴现模型（DDM）用于评估股票的价值，基于未来股息的现值。

### 3.2.2 股息贴现模型的公式

$$V = \frac{D_1}{r - g}$$

其中，V是股票价值，D1是第一期股息，r是贴现率，g是股息增长率。

### 3.2.3 股息贴现模型的优缺点

优点：简单直观；缺点：假设股息稳定增长，忽视市场波动。

## 3.3 格雷厄姆的市盈率与市净率分析

### 3.3.1 市盈率的定义与计算公式

市盈率 = 市场价格 / 每股收益

### 3.3.2 市净率的定义与计算公式

市净率 = 市场价格 / 每股净资产

### 3.3.3 市盈率与市净率的对比分析

市盈率适用于盈利稳定的公司，市净率适用于资产密集型企业。
