# 第1章：周期性行业的定义与特点

## 1.1 周期性行业的定义  
周期性行业是指那些需求与经济周期密切相关的行业。这些行业在经济繁荣时表现良好，在经济衰退时则面临压力。周期性行业的波动性较高，但长期来看，这些行业往往能够为投资者带来超额收益。

## 1.2 数字化转型的背景  
数字化转型是指企业利用数字技术（如人工智能、大数据、云计算等）改变其商业模式、业务流程和决策方式的过程。数字化转型正在重塑传统产业的格局，为周期性行业带来了新的机遇。

## 1.3 周期性行业与数字化转型的结合  
周期性行业在数字化转型中可以利用技术手段优化运营、降低成本、提升效率。例如，制造业可以通过工业互联网实现智能化生产，减少周期性波动的影响。

# 第2章：巴菲特的投资理念

## 2.1 巴菲特的价值投资策略  
巴菲特的价值投资策略强调长期持有优质资产，寻找具有持续竞争优势的企业。他注重企业的基本面分析，包括财务状况、盈利能力和发展前景。

## 2.2 巴菲特对周期性行业的估值方法  
巴菲特在投资周期性行业时，通常关注行业的周期性波动，并在行业低谷时买入，在行业高峰时卖出。他注重企业的内在价值，而不是市场的短期波动。

## 2.3 投资案例分析  
以巴菲特投资的石油行业为例，他在油价低迷时大量买入石油企业股票，利用周期性行业的波动性获得了超额收益。

## 6.2 核心实现代码  
以下是预测周期性行业波动的Python代码：

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 加载数据
data = pd.read_csv('industry_data.csv')

# 特征工程
X = data[['GDP', '失业率', '行业指数']]
y = data['价格']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测未来价格
future_GDP = 2.5
future_unemployment = 6.0
future_index = 100

predicted_price = model.predict([[future_GDP, future_unemployment, future_index]])[0]
print(f"预测价格：{predicted_price}")
```
