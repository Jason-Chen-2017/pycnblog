##### 4.2 矩阵评估的数学模型
- 4.2.1 风险评分公式
  $$ \text{风险评分} = \sum_{i=1}^{n} w_i \cdot r_i $$
  其中，$w_i$ 为第 $i$ 个维度的权重，$r_i$ 为第 $i$ 个维度的风险值。
- 4.2.2 综合风险评估公式
  $$ \text{综合风险} = \frac{\sum_{i=1}^{n} (w_i \cdot r_i)}{\sum_{i=1}^{n} w_i} $$

##### 4.3 算法实现的Python代码
```python
def risk_assessment_matrix(risk_prob, risk_impact, risk_time):
    # 计算风险评分
    risk_score = [w * r for w, r in zip([0.4, 0.3, 0.3], [p, i, t])]
    total_score = sum(risk_score)
    return total_score

# 示例数据
risk_prob = 0.6
risk_impact = 0.7
risk_time = 0.5

# 调用函数
total_score = risk_assessment_matrix(risk_prob, risk_impact, risk_time)
print("综合风险评分:", total_score)
```
