# 第1章: 量子通信卫星网络的背景与概念

## 1.1 量子通信的基本概念

### 1.1.1 量子通信的定义
量子通信是一种利用量子力学原理进行信息传输的技术，主要依赖于量子叠加态和量子纠缠态。其核心应用包括量子密钥分发（QKD）和量子隐形传态，确保通信的绝对安全性。

### 1.1.2 量子通信的基本原理
量子通信的原理基于量子力学的基本定律，包括：
- **量子叠加**：量子系统可以同时处于多个状态。
- **量子纠缠**：两个或多个粒子之间存在特殊关联，无论距离多远。
- **量子测量**：测量会破坏量子状态，确保信息的安全性。

### 1.1.3 量子通信与经典通信的区别
| 特性        | 量子通信                 | 经典通信                 |
|-------------|--------------------------|--------------------------|
| 安全性       | 绝对安全，基于量子原理   | 可能被破解，依赖加密算法 |
| 传输速度     | 理论上可超越光速          | 以光速为上限              |
| 带宽         | 高，支持多路复用          | 较低，受限于频段          |
| 应用领域     | 保密通信、量子计算        | 传统通信、互联网          |

### 1.1.4 量子通信在卫星网络中的应用
量子通信卫星网络将量子通信技术与卫星通信相结合，用于实现全球范围内的安全通信。例如，中国的“墨子号”卫星完成了全球首次量子通信实验。
