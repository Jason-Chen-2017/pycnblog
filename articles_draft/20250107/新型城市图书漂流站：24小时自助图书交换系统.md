**4.2 Python源代码示例**

```python
def borrow_book(book_barcode):
    # 读取图书条码
    book = get_book_by_barcode(book_barcode)
    
    # 检查图书状态
    if not book.is_available():
        print("图书不可借阅。")
        return False
    
    # 更新图书状态
    book.borrow()
    print("图书借阅成功。")
    return True
```

**4.3 算法原理的数学模型和公式**

我们将使用数学模型和公式来解释算法的原理。

$$
\text{图书借阅概率} = \frac{\text{可用图书数量}}{\text{总图书数量}}
$$
