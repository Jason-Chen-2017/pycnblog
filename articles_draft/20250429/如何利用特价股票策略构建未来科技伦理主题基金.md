# 第2章：特价股票策略的核心概念与原理

## 2.1 特价股票策略的定义与分类

### 2.1.1 特价股票的定义

特价股票指的是市场价格低于其内在价值的股票，通常出现在市场低估阶段。

### 2.1.2 特价股票的分类

- **周期性股票**：受经济周期影响较大的行业股票。
- **成长型股票**：具备高增长潜力但当前估值较低的股票。

## 2.2 特价股票策略的关键指标

### 2.2.1 市盈率（P/E）

市盈率=股价/每股净利润，用于衡量股票的估值水平。

$$ P/E = \frac{\text{股价}}{\text{每股净利润}} $$

### 2.2.2 市净率（P/B）

市净率=股价/每股净资产，用于衡量股票的资产价值。

$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

### 2.2.3 股息率

股息率=每股股息/股价，用于衡量股票的分红能力。

$$ \text{股息率} = \frac{\text{每股股息}}{\text{股价}} $$

## 2.3 特价股票策略的核心要素

### 2.3.1 市场周期分析

通过分析市场周期，识别低估阶段，寻找潜在投资机会。

### 2.3.2 行业分析

选择具备长期增长潜力的行业，如人工智能、大数据等领域。

### 2.3.3 公司基本面分析

评估公司的财务状况、盈利能力和发展潜力。

import pandas as pd
import numpy as np

def calculate_pe(stock_price, eps):
    return stock_price / eps

def calculate_pb(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

# 示例数据
data = {
    '公司名称': ['公司A', '公司B', '公司C'],
    '股价': [10, 20, 15],
    '每股净利润': [5, 10, 7.5],
    '每股净资产': [5, 10, 7.5]
}

df = pd.DataFrame(data)

# 计算市盈率和市净率
df['市盈率'] = df.apply(lambda x: calculate_pe(x['股价'], x['每股净利润']), axis=1)
df['市净率'] = df.apply(lambda x: calculate_pb(x['股价'], x['每股净资产']), axis=1)

print(df)
