### 1.1 芒格的“避免首要否认”概述

#### 1.1.1 芒格的“避免首要否认”定义
芒格的“避免首要否认”是一种思维方式，强调在面对问题时，不要过早地拒绝或否定某个观点，而是要保持开放性思维，全面分析问题的各个方面。这种方法的核心在于避免因先入为主的偏见或认知局限而错过潜在的重要信息。

#### 1.1.2 芒格思维方式的核心理念
芒格认为，人类的思维容易受到认知偏差的影响，如过度乐观偏差、过度悲观偏差等。为了避免这些偏差，他提倡在决策过程中保持开放性，先倾听和理解不同的观点，再进行综合判断。

#### 1.1.3 “避免首要否认”在决策中的应用
在决策过程中，芒格的“避免首要否认”可以帮助我们更全面地分析问题，尤其是在面对复杂的技术和不确定性较高的领域时，这种思维方式能够帮助我们避免因片面判断而引发的决策失误。

```python
import numpy as np
import pandas as pd

def calculate_risk(data):
    # 计算每个技术的风险概率
    risks = data['技术'].unique()
    risk_probabilities = {}
    for risk in risks:
        probability = np.mean(data[data['技术'] == risk]['概率'])
        risk_probabilities[risk] = probability
    return risk_probabilities

# 示例数据
data = pd.DataFrame({
    '技术': ['AI', '区块链', '量子计算'] * 3,
    '概率': [0.2, 0.3, 0.4] * 3
})

# 计算风险概率
risk_probabilities = calculate_risk(data)
print(risk_probabilities)
```
