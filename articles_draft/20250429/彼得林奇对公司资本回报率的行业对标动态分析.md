## 第一部分：资本回报率（ROE）与行业对标分析基础

### 第1章：资本回报率（ROE）的基本概念

#### 1.1 ROE的定义与计算公式
ROE（Return on Equity）是衡量公司盈利能力的重要指标，公式为：

$$ROE = \frac{净利润}{股东权益}$$

ROE反映了公司每单位股东权益创造的净利润，是评估公司盈利能力的核心指标之一。

#### 1.2 行业对标分析的必要性
行业对标分析是通过将公司ROE与行业基准进行对比，评估公司相对于行业平均水平的表现。其核心作用包括：

1. 识别行业平均水平。
2. 发现公司相对于行业的优劣势。
3. 为投资决策提供数据支持。

### 第2章：彼得·林奇的ROE分析方法

#### 2.1 彼得·林奇的投资理念
彼得·林奇是著名投资经理，其核心理念是通过基本面分析寻找具有持续增长潜力的公司。他强调ROE的重要性，并通过行业对标分析筛选出具有竞争优势的公司。

#### 2.2 林奇的行业对标分析框架
林奇的行业对标分析包括以下几个步骤：

1. 确定行业基准。
2. 计算公司ROE。
3. 比较公司ROE与行业基准的差异。
4. 分析差异背后的原因。

#### 6.2 核心算法实现
以下是ROE计算的Python代码：

```python
import pandas as pd

def calculate_roe(net_profit, shareholders_equity):
    return net_profit / shareholders_equity

# 示例数据
data = {
    '公司': ['A', 'B', 'C'],
    '净利润': [100, 150, 200],
    '股东权益': [500, 600, 700]
}

df = pd.DataFrame(data)
df['ROE'] = calculate_roe(df['净利润'], df['股东权益'])
print(df)
```
