## 第三部分：算法原理讲解

### 第3章：专利组合价值评估算法

#### 3.1 层次分析法（AHP）
- **步骤**：构建层次结构，确定权重，计算一致性检验。
- **数学模型**：权重计算公式，层次分析法的步骤。

#### 3.2 模糊综合评价法
- **步骤**：建立模糊评价矩阵，计算隶属度。
- **数学公式**：模糊综合评价公式。

#### 3.3 算法对比与选择
- **适用场景**：层次分析法适用于结构清晰的问题，模糊综合评价法适用于模糊问题。

#### 3.4 Python代码示例
```python
# 层次分析法示例
def calculate_weights(criteria_matrix):
    n = len(criteria_matrix)
    # 计算一致性检验
    CI = (sum(criteria_matrix[i] * criteria_matrix[i].T for i in range(n))) / n - 1
    return CI

# 模糊综合评价法示例
def fuzzy_evaluation(factors, criteria_weights):
    # 计算隶属度
    result = sum(factors[i] * criteria_weights[i] for i in range(len(factors)))
    return result
```
