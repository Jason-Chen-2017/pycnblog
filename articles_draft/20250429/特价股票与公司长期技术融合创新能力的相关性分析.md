## 第1章: 特价股票与公司技术融合创新能力的背景介绍

### 1.1 特价股票的定义与特点
特价股票是指以低于市场价或折扣形式出售的股票，通常用于促销或清理库存。其特点包括价格优惠、流动性较高、风险较低、吸引投资者等。

### 1.2 公司长期技术融合创新能力的定义与特点
技术融合创新能力是指公司在整合不同技术领域、创新技术应用和提升核心竞争力方面的能力。其特点包括技术整合能力强、创新能力突出、持续优化能力等。

### 1.3 相关性背景与意义
探讨特价股票与公司技术融合创新能力之间的相关性，有助于投资者更好地评估公司的长期价值，指导投资决策，同时帮助公司优化技术创新策略。

import pandas as pd
import matplotlib.pyplot as plt

# 示例数据
data = {
    '特价股票': [0.8, 1.2, 1.5, 0.9, 1.1],
    '技术创新': [0.7, 1.0, 1.2, 0.8, 0.9]

# 计算皮尔逊相关系数
correlation = df.corr()
print(correlation)

# 可视化
df.plot.scatter(x='特价股票', y='技术创新')
plt.title('相关性分析')
