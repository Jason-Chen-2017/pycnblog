##### 5.2 小盘股的筛选模型
- 市盈率筛选公式：
$$ P/E < 市场平均市盈率 $$
- 市净率筛选公式：
$$ P/B < 市场平均市净率 $$
- 结合市值与财务指标的多维度筛选模型：
$$ \text{筛选标准} = (P/E < 市场平均P/E) \land (P/B < 市场平均P/B) \land (\text{市值} < 小盘股界定值) $$

```python
import pandas as pd
import numpy as np

def calculate_value_ratios(df):
    df['PE'] = df['股价'] / df['每股收益']
    df['PB'] = df['股价'] / df['每股净资产']
    df['ROE'] = df['净利润'] / df['股东权益']
    return df

def select_undervalued_stocks(df, market_pe, market_pb):
    df['是否低估'] = (df['PE'] < market_pe) & (df['PB'] < market_pb) & (df['市值'] < 200)
    return df[df['是否低估']]

# 示例数据加载
data = pd.read_csv('market_data.csv')
data = calculate_value_ratios(data)
market_pe = data['PE'].mean()
market_pb = data['PB'].mean()

selected_stocks = select_undervalued_stocks(data, market_pe, market_pb)
print(selected_stocks)
```

- 结果展示：输出符合筛选条件的股票列表。
