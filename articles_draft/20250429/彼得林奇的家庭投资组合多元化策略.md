#### 1.1 多元化投资的定义与重要性
- **1.1.1 什么是多元化投资**  
  多元化投资是指将资金分散投资于不同的资产类别、行业或地区，以降低风险并提高收益。  
  $$\text{风险分散化} = \text{资产多样性} \times \text{投资组合管理}$$  

- **1.1.2 多元化投资的重要性**  
  通过分散投资，投资者可以降低特定资产或市场的风险，同时捕捉不同资产的收益潜力。  

- **1.1.3 多元化投资的核心目标**  
  稳定收益、风险控制、资产保值与增值。

## 第二部分：多元化投资的数学模型与算法原理

### 第3章：投资组合优化的数学模型

#### 3.1 均值-方差模型
- **马科维茨的现代投资组合理论（MPT）**  
  通过优化投资组合的收益-风险比率，实现收益最大化。  

- **数学公式**  
  $$\text{Minimize } \sigma^2 \text{ subject to } E(r) \geq \text{目标收益}$$  

#### 3.2 Python实现投资组合优化
```python
import numpy as np
import matplotlib.pyplot as plt

# 示例数据：资产的期望收益和协方差矩阵
returns = np.array([0.05, 0.07, 0.03])
cov_matrix = np.array([[0.02, 0.01, 0.005],
                        [0.01, 0.03, 0.01],
                        [0.005, 0.01, 0.02]])

# 计算最优投资组合
def optimize_portfolio(returns, cov_matrix):
    n = len(returns)
    # 构建优化问题
    from scipy.optimize import minimize
    # 初始猜测：等权重
    init_guess = np.array([1.0/n]*n)
    # 约束条件：权重之和为1
    constraints = {'type': 'eq', 'fun': lambda x: sum(x) - 1}
    # 目标函数：最小化方差
    def objective(x):
        return np.dot(x.T, np.dot(cov_matrix, x))
    # 使用SLSQP求解
    result = minimize(objective, init_guess, method='SLSQP', constraints=constraints)
    return result.x

# 调用函数
weights = optimize_portfolio(returns, cov_matrix)
print("最优权重:", weights)
```

#### 5.2 核心实现代码
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimizer(assets, returns):
    n = len(assets)
    # 初始化权重
    init_guess = np.array([1.0/n]*n)
    # 约束条件：权重之和为1
    constraints = [{'type': 'eq', 'fun': lambda x: sum(x) - 1}]
    # 目标函数：最小化方差
    def objective(x):
        return np.dot(x.T, np.dot(returns, x))
    # 求解
    result = minimize(objective, init_guess, method='SLSQP', constraints=constraints)
    return result.x

# 示例
assets = ['股票', '债券', '现金']
returns = np.array([0.07, 0.05, 0.02])
cov_matrix = np.array([[0.02, 0.01, 0.005],
                       [0.01, 0.03, 0.01],
                       [0.005, 0.01, 0.02]])

weights = portfolio_optimizer(assets, cov_matrix)
print("最优权重:", weights)
```
