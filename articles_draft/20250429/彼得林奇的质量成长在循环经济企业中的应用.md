### 第一部分：彼得·林奇的“质量成长”理论概述

#### 第1章：彼得·林奇与“质量成长”投资理念

##### 1.1 彼得·林奇及其投资理念
- **1.1.1 彼得·林奇的生平简介**
  彼得·林奇是美国著名投资经理人，以其在富达投资管理公司管理麦哲伦基金期间取得的卓越成绩而闻名。他强调长期投资和价值发现，注重企业的基本面分析，倡导寻找那些具有持续增长潜力的优秀企业。

- **1.1.2 “质量成长”投资策略的核心思想**
  质量成长策略关注那些具备强大竞争优势、良好财务状况和持续增长潜力的企业。林奇认为，投资的关键在于选择能够长期稳定增长的公司，而非短期市场波动。

- **1.1.3 彼得·林奇的成功投资案例**
  林奇在麦哲伦基金期间，成功投资了像可口可乐、迪士尼等企业，这些企业在他的投资组合中表现出色，验证了质量成长策略的有效性。

##### 1.2 循环经济的基本概念与特点
- **1.2.1 循环经济的定义与内涵**
  循环经济是一种以资源高效利用和循环利用为目标的经济模式，强调减少资源消耗和废弃物产生，促进可持续发展。

- **1.2.2 循环经济与传统经济的区别**
  传统经济基于资源的大量消耗和线性生产模式，而循环经济则强调闭环系统，资源在各环节间循环利用，减少对环境的影响。

- **1.2.3 循环经济对企业发展的意义**
  循环经济不仅有助于减少企业成本，还能提升企业的社会责任形象，促进长期可持续发展。

```python
import pandas as pd

def calculate_quality_growth_index(enterprise_data):
    # 计算质量指数
    quality_index = enterprise_data['ROE'] * 0.4 + enterprise_data['ROA'] * 0.2
    # 计算成长指数
    growth_index = enterprise_data['收入增长率'] * 0.3 + enterprise_data['净利润增长率'] * 0.1
    # 综合质量成长指数
    quality_growth_index = (quality_index + growth_index) * 0.5
    return quality_growth_index

# 示例数据
data = {
    'ROE': [0.15, 0.18, 0.12],
    'ROA': [0.1, 0.12, 0.08],
    '收入增长率': [0.2, 0.15, 0.25],
    '净利润增长率': [0.15, 0.1, 0.2]
}
df = pd.DataFrame(data)
result = calculate_quality_growth_index(df)
print(result)
```

#### 4.4 数学模型和公式
- **ROE（净资产收益率）**：$$ ROE = \frac{\text{净利润}}{\text{股东权益}} $$
- **ROA（资产回报率）**：$$ ROA = \frac{\text{净利润}}{\text{总资产}} $$
- **质量成长指数计算公式**：$$ QGI = 0.5 \times (0.4 \times ROE + 0.2 \times ROA + 0.3 \times GR + 0.1 \times NGR) $$
  其中，GR为收入增长率，NGR为净利润增长率。
