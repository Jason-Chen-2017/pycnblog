## 第一章：彼得林奇与高增长低估值选股策略

### 1.1 彼得林奇的生平与投资理念  
彼得·林奇是美国著名的投资专家，曾管理富达麦哲伦基金，创造了辉煌的投资业绩。他的投资理念强调基本面分析和长期投资，尤其关注具有高增长潜力但估值被低估的公司。

### 1.2 高增长低估值选股策略的定义  
该策略的核心在于寻找那些收入和利润快速增长，但市盈率（P/E）和市净率（P/B）等估值指标低于行业平均水平的公司。

### 1.3 该策略的有效性与适用性  
通过历史数据分析，高增长低估值策略在成长型股票投资中表现优异，尤其在新兴行业或周期性行业中表现突出。

### 2.1 高增长公司的定义与标准  
高增长公司通常具备收入增长率和净利润增长率显著高于行业平均水平的特点。

| 指标         | 高增长公司标准 | 中速增长公司标准 | 低增长公司标准 |
|--------------|----------------|------------------|----------------|

| 净利润增长率  | >15%           | 5%-15%           | <5%            |
| 市场占有率    | 上升趋势       | 稳定或略有增长   | 下降趋势       |

## 第七章：项目实战

### 7.1 环境安装

### 7.2 核心代码实现  
```python
import pandas as pd

# 假设df为公司数据
def high_growth_low_valuation_screening(df):
    # 收入增长率筛选
    df = df[df['收入增长率'] > 15]
    # 净利润增长率筛选
    df = df[df['净利润增长率'] > 10]
    # 市盈率筛选
    df = df[df['市盈率'] < df['行业平均市盈率']]
    # 市净率筛选
    df = df[df['市净率'] < df['行业平均市净率']]
    return df

# 示例数据
data = {
    '公司': ['A', 'B', 'C'],
    '收入增长率': [20, 5, 8],
    '净利润增长率': [12, 7, 6],
    '市盈率': [10, 15, 12],
    '行业平均市盈率': [12, 12, 12],
    '市净率': [1.5, 2, 1.8],
    '行业平均市净率': [2, 2, 2]
}
df = pd.DataFrame(data)
result = high_growth_low_valuation_screening(df)
print(result)
```
