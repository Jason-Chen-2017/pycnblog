# 第1章 全球股市估值概述

## 1.1 股票估值的基本概念

### 1.1.1 股票估值的定义与作用
股票估值是通过分析公司的财务状况、市场地位和行业前景，来确定其股票合理价格的过程。它帮助投资者做出理性决策，降低投资风险，同时为公司提供融资支持。

### 1.1.2 股票估值的核心要素
- **公司基本面**：收入、利润、资产负债表。
- **行业环境**：行业竞争、政策法规。
- **宏观经济**：GDP增长率、利率、通货膨胀。

### 1.1.3 股票估值的分类与特点
- **内在价值法**：基于公司未来现金流折现。
- **相对价值法**：通过比较同类股票的估值指标。

## 1.2 影响股票估值的主要因素

### 1.2.1 宏观经济因素
- **GDP增长率**：影响企业盈利能力。
- **利率水平**：影响资金成本和债券收益率。

### 1.2.2 行业因素
- **行业周期**：周期性行业波动较大。
- **政策支持**：环保政策影响绿色产业。

### 1.2.3 公司基本面因素
- **盈利能力**：净利润率和ROE。
- **财务状况**：资产负债率和现金流。

### 1.2.4 市场情绪与投资者行为
- **市场情绪**：投资者心理影响短期股价。
- **市场流动性**：资金充裕时股市上涨。

## 1.3 股票估值的主要方法

### 1.3.1 市盈率法
$$市盈率 = \frac{股价}{每股收益}$$

### 1.3.2 市净率法
$$市净率 = \frac{股价}{每股净资产}$$

### 1.3.3 现金流折现法
$$股票价值 = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$
