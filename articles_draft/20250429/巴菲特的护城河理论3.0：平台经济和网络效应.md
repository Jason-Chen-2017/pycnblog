## 第四部分：算法原理讲解

### 第4章：护城河要素的评估方法

#### 4.1 层次分析法（AHP）的应用

- **4.1.1 算法步骤**  
  1. 确定目标和因素。  
  2. 构建判断矩阵。  
  3. 计算权重。  
  4. 计算一致性比率。

- **4.1.2 Python实现**  
  ```python
  import numpy as np

  def calculate_weights(matrix):
      # 计算权重
      n = len(matrix)
      a = np.array(matrix)
      # 计算特征向量
      eigvals, eigvecs = np.linalg.eig(a.T.dot(a))
      # 找到最大的特征值和对应的特征向量
      max_eig = max(eigvals)
      max_index = np.argmax(eigvals)
      weight = eigvecs[max_index] / sum(eigvecs[max_index])
      return weight

  # 示例矩阵
  matrix = [
      [1, 3, 2],
      [1/3, 1, 1/2],
      [1/2, 2, 1]
  ]
  print(calculate_weights(matrix))
  ```
