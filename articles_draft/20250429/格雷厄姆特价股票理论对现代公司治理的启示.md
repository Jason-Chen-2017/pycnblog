## 第1章 格雷厄姆特价股票理论的核心概念

### 1.1 格雷厄姆投资理论的背景与起源

#### 1.1.1 价值投资的起源与发展
价值投资是一种长期投资策略，起源于20世纪初。本杰明·格雷厄姆是该领域的先驱，他强调以低于内在价值的价格买入优质股票。这一理论在金融界产生了深远影响，成为价值投资的基石。

#### 1.1.2 格雷厄姆的学术背景与投资实践
格雷厄姆是一位著名的经济学家和投资家，他的理论结合了深厚的学术背景和丰富的实战经验。他在《证券分析》一书中首次系统阐述了价值投资的理念。

#### 1.1.3 特价股票理论的基本思想
格雷厄姆认为，市场波动为投资者提供了以低于内在价值的价格买入优质股票的机会。这种理论强调安全边际的重要性，即市场价格与内在价值之间的差距。

---

### 1.2 特价股票理论的核心观点

#### 1.2.1 安全边际的概念与计算
安全边际是格雷厄姆理论中的关键概念，指市场价格与内在价值之间的差额。计算公式为：
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

#### 1.2.2 内在价值的定义与评估方法
内在价值是基于公司财务状况和未来现金流折现计算出的理论价值。格雷厄姆的内在价值公式为：
$$ \text{内在价值} = \frac{\text{息税前利润} \times 4 + \text{资本支出}}{1 - \text{折旧率}} $$

#### 1.2.3 市场先生的行为与投资机会
格雷厄姆将市场波动比作“市场先生”，认为市场的非理性行为为投资者提供了廉价买入股票的机会。

def calculate_intrinsic_value(enterprise_value, capital_expenditure, depreciation_rate):
    return (enterprise_value * (1 - depreciation_rate) + capital_expenditure) / (1 - depreciation_rate)

def calculate_market_price(current_price):
    return current_price

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例
enterprise_value = 1000000
capital_expenditure = 50000
depreciation_rate = 0.1
market_price = 800000

intrinsic_value = calculate_intrinsic_value(enterprise_value, capital_expenditure, depreciation_rate)
market_price = calculate_market_price(market_price)
margin_of_safety = calculate_margin_of_safety(intrinsic_value, market_price)

print(f"内在价值: {intrinsic_value}")
print(f"市场价格: {market_price}")
print(f"安全边际: {margin_of_safety}")
