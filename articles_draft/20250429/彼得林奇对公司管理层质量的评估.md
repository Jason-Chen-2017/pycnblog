### 3.1 财务指标分析
#### 3.1.1 净利润与利润率

### 3.2 非财务指标分析
#### 3.2.1 管理层的稳定性与忠诚度
- 管理层稳定有助于公司长期发展
- 忠诚度影响决策的一致性

#### 3.2.2 管理层的创新能力与适应性
- 创新能力推动公司发展
- 适应性应对市场变化

#### 3.2.3 管理层的声誉与行业口碑
- 声誉影响公司形象和合作伙伴关系
- 行业口碑反映公司在业内的地位

### 3.3 综合评估模型
#### 3.3.1 指标权重的分配
- 根据行业和公司特点分配权重
- 通常战略能力占40%，执行力占30%，决策能力占20%，声誉占10%

#### 3.3.2 综合评分的计算方法
$$ \text{综合评分} = \sum (\text{指标得分} \times \text{权重}) $$

#### 3.3.3 模型的优缺点分析
- 优点：全面考虑了多方面因素
- 缺点：权重分配主观，需要根据具体情况调整

### 6.2 核心实现源代码
```python
import pandas as pd
import numpy as np

def calculate_score(finance_data, non_finance_data):
    weights = {'战略能力': 0.4, '执行力': 0.3, '决策能力': 0.2, '声誉': 0.1}
    scores = {
        '战略能力': np.mean(finance_data['净利润'] / finance_data['总收入']),
        '执行力': np.mean(non_finance_data['团队协作']),
        '决策能力': np.mean(non_finance_data['决策透明度']),
        '声誉': np.mean(non_finance_data['行业口碑'])
    }
    total_score = sum(scores[cat] * weights[cat] for cat in weights)
    return total_score

data = pd.read_csv('管理层数据.csv')
finance_data = data[['净利润', '总收入']]
non_finance_data = data[['团队协作', '决策透明度', '行业口碑']]

score = calculate_score(finance_data, non_finance_data)
print(f"综合评分: {score}")
```
