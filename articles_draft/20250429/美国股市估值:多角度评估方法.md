### 2.1 常用估值指标
- **市盈率（PE）**：衡量股价与收益的关系。

### 2.2 估值方法概述
- **相对估值法**：基于市场数据进行比较。
- **绝对估值法**：基于DCF模型计算内在价值。
- **市场法与资产重估法**：综合考虑市场和资产价值。

# 第三部分: 股市估值的算法原理

## 第3章: 现金流贴现模型（DCF）

### 3.1 DCF模型的基本原理
DCF模型通过贴现未来现金流计算股票的内在价值。公式如下：
$$
FCF = EBIT(1 - 税率) + 折旧 - 资本支出
$$

### 3.2 DCF模型的流程图

### 3.3 算法的数学模型
- **终值公式**：$$TV = \frac{FCF_{n+1}}{WACC}$$
- **总价值公式**：$$V = \sum_{t=1}^{n} \frac{FCF_t}{(1 + WACC)^t} + TV$$

### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np

def calculate_pe(ticker):
    # 示例代码：计算市盈率
    df = pd.get_data(ticker)
    pe = df['Close'] / df['Earnings Per Share']
    return pe.mean()

def calculate_pb(ticker):
    # 示例代码：计算市净率
    df = pd.get_data(ticker)
    pb = df['Close'] / df['Book Value Per Share']
    return pb.mean()

if __name__ == "__main__":
    ticker = 'AAPL'
    pe = calculate_pe(ticker)
    pb = calculate_pb(ticker)
    print(f"{ticker}的市盈率为：{pe}")
    print(f"{ticker}的市净率为：{pb}")
```
