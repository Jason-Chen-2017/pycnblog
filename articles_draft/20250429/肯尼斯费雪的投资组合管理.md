## 第一部分：投资组合管理概述

### 第1章：投资组合管理的定义与背景

#### 1.1 投资组合管理的定义
- **1.1.1 投资组合管理的基本概念**
  - 投资组合管理是通过科学配置资产以实现收益最大化和风险最小化的管理过程。
  - 包括选择资产类别、确定权重以及定期调整以应对市场变化。

- **1.1.2 投资组合管理的重要性**
  - 通过分散投资降低风险，避免单一资产波动带来的损失。
  - 帮助投资者在不同市场条件下优化收益与风险的平衡。

- **1.1.3 投资组合管理的演变历程**
  - 从传统的资产选择到现代的量化管理，投资组合管理经历了从简单到复杂的演变。

#### 1.2 投资组合管理的核心要素
- **1.2.1 资产分配**
  - 根据风险承受能力和投资目标分配资金到不同资产类别。

- **1.2.2 风险与收益的平衡**
  - 在追求高收益的同时，合理控制风险以避免重大损失。

- **1.2.3 投资组合的多样化策略**
  - 通过投资不同资产和行业降低特定风险。

## 第二部分：现代投资组合理论（MPT）

### 第2章：现代投资组合理论基础

#### 2.1 投资组合理论的发展
- **2.1.1 马科维茨的均值-方差模型**
  - **数学公式：**
    - 最优化问题：$$ \min \sigma^2 \quad \text{subject to} \quad \mu \cdot w = \mu_p $$
    - 其中，$\sigma^2$ 是方差，$w$ 是投资权重向量，$\mu$ 是收益向量，$\mu_p$ 是目标收益。
  - 均值-方差模型通过数学优化找到最优资产组合。

- **2.1.2 马科维茨模型的假设与限制**
  - 假设资产收益符合正态分布，且协方差矩阵已知。
  - 限制包括计算复杂性和对实际市场的简化假设。

#### 2.2 有效前沿的概念
- **2.2.1 有效前沿的定义**
  - 有效前沿是在给定风险水平下，能够提供最高收益的所有投资组合的集合。

- **2.2.2 有效前沿的计算方法**
  - 使用马科维茨模型计算不同风险水平下的最优收益。

- **2.2.3 有效前沿的应用**
  - 帮助投资者选择最优风险-收益组合，指导投资决策。

## 第四部分：数学模型与算法

### 第5章：投资组合优化的数学模型

#### 5.1 均值-方差优化模型
- **5.1.1 模型的数学表达**
  - 优化目标：$$ \min \sum_{i=1}^n w_i^2 \sigma_i^2 + 2 \sum_{i<j} w_i w_j \sigma_{ij} $$
  - 约束条件：$$ \sum_{i=1}^n w_i = 1 \quad \text{和} \quad \sum_{i=1}^n w_i \mu_i = \mu_p $$

- **5.1.2 模型的求解方法**
  - 使用拉格朗日乘数法求解优化问题。
  - Python代码示例：
    ```python
    import numpy as np
    from scipy.optimize import minimize

    def portfolio_variance(weights, covariance_matrix):
        return np.dot(weights.T, np.dot(covariance_matrix, weights))

    covariance_matrix = np.array([[0.01, 0.005], [0.005, 0.02]])
    mu = np.array([0.05, 0.03])
    target_return = 0.04

    def constraint(weights, mu, target_return):
        return np.dot(weights, mu) - target_return

    initial_guess = np.array([0.5, 0.5])
    result = minimize(portfolio_variance, initial_guess, args=covariance_matrix, 
                     method='SLSQP', constraints={'type': 'eq', 'fun': constraint, 'mu': mu, 'target_return': target_return})
    ```

- **5.1.3 模型的优缺点分析**
  - 优点：数学严谨，结果最优。
  - 缺点：假设严格，计算复杂。

#### 5.2 风险调整后收益的计算
- **夏普比率**
  - 计算公式：$$ \text{夏普比率} = \frac{E[r - r_f]}{\sigma} $$
  - 其中，$E[r - r_f]$ 是超额收益的期望值，$\sigma$ 是收益的标准差。
