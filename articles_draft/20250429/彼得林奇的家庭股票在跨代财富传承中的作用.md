#### 3.2 家庭股票的投资组合优化（数学模型与公式）

##### 投资组合优化的数学模型
$$\text{目标函数：最大化收益} \quad \max \sum_{i=1}^{n} w_i r_i$$  
$$\text{约束条件：权重之和为1} \quad \sum_{i=1}^{n} w_i = 1$$  
$$\text{风险控制：最小化波动率} \quad \min \sqrt{\sum_{i=1}^{n} w_i^2 \sigma_i^2}$$  

##### 投资组合优化的Python实现

```python
import numpy as np
import pandas as pd

# 示例数据：资产的预期收益和波动率
assets = pd.DataFrame({
    '收益': [0.08, 0.12, 0.05],
    '波动率': [0.2, 0.3, 0.1]
})

# 计算协方差矩阵
cov_matrix = np.diag(assets['波动率'].values)  # 简单假设资产独立

# 使用优化算法求解最优权重
from scipy.optimize import minimize

def portfolio_risk(weights, cov_matrix):
    return np.sqrt(weights.T @ cov_matrix @ weights)

# 初始猜测权重（均等分配）
initial_weights = np.array([1/3, 1/3, 1/3])

# 约束条件：权重之和为1
cons = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1})

# 求解最小风险问题
result = minimize(portfolio_risk, initial_weights, args=cov_matrix, constraints=cons)

# 输出最优权重和最小风险
print("最优权重：", result.x)
print("最小风险：", result.fun)
```
