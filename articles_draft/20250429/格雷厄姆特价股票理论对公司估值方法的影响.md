## 第二部分: 公司估值方法的分析与应用

### 第3章: 公司估值的基本方法

#### 3.1 市盈率法
- **定义**: 市盈率（P/E）是股票价格与每股收益的比率。
- **计算公式**:
  $$ \text{市盈率} = \frac{\text{股价}}{\text{每股收益}} $$
- **应用**: 用于评估股票的相对价值，低于行业平均市盈率的股票可能为特价股票。

#### 3.2 市净率法
- **定义**: 市净率（P/B）是股票价格与每股净资产的比率。
- **计算公式**:
  $$ \text{市净率} = \frac{\text{股价}}{\text{每股净资产}} $$
- **应用**: 适用于评估银行、制造业等行业的公司价值。

#### 3.3 股息率法
- **定义**: 股息率是股票的股息与股价的比率。
- **计算公式**:
  $$ \text{股息率} = \frac{\text{股息}}{\text{股价}} \times 100\% $$
- **应用**: 用于评估股票的收益能力，高股息率可能意味着低估。

### 第6章: 格雷厄姆理论的实际应用

#### 6.1 经典案例分析
- **案例1**: 某制造公司，市盈率低于行业平均，股息率高，适合作为特价股票。
- **案例2**: 银行股，市净率低于1，显示低估。

#### 6.2 投资组合优化
- **实现代码**:
  ```python
  import pandas as pd
  import numpy as np

  def calculate_sharpe_ratio(returns, risk_free_rate):
      excess_returns = returns - risk_free_rate
      return np.mean(excess_returns) / np.std(excess_returns)

  # 示例数据
  returns = pd.Series([0.1, 0.05, -0.02, 0.08], index=['2020', '2021', '2022', '2023'])
  risk_free_rate = 0.02

  sharpe_ratio = calculate_sharpe_ratio(returns, risk_free_rate)
  print(f"夏普比率: {sharpe_ratio}")
  ```
