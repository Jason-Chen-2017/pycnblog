# 第一部分：反脆弱理论基础

## 2.1 反脆弱理论的核心概念
### 2.1.1 反脆弱的定义与特征
反脆弱性可以表示为：
$$ R = \frac{1}{1 + \alpha \cdot r} $$
其中，$R$ 表示反脆弱性，$\alpha$ 是风险调整系数，$r$ 是系统风险。

### 2.1.2 反脆弱的三个层次：反脆弱性、稳健性和脆弱性
| 特性 | 描述 |
|------|------|
| 反脆弱性 | 系统在压力下增强 |
| 稳健性 | 系统在压力下保持不变 |
| 脆弱性 | 系统在压力下恶化 |

### 2.1.3 反脆弱与系统性风险的关系
反脆弱性通过分散风险和增强系统韧性，降低系统性风险的影响。
