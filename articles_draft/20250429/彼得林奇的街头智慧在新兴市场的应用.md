- **价值投资**：寻找被市场低估的股票。
- **长期投资**：避免频繁交易，注重长期收益。
- **分散投资**：通过多样化降低风险。

##### 1.2 街头智慧的核心原则

- **价值评估**：通过分析公司的财务状况、行业地位和未来前景，判断其内在价值。

### 第三部分：数学模型与算法原理

#### 第3章：投资策略的数学模型

##### 3.1 CAPM模型

CAPM（资本资产定价模型）用于评估资产的预期回报率。公式如下：

$$ \text{CAPM} = r_f + \beta (r_m - r_f) $$

其中：
- $r_f$ 是无风险利率。
- $\beta$ 是股票的贝塔系数，衡量其波动性。
- $r_m$ 是市场预期回报率。

##### 3.2 市盈率分析

市盈率（P/E）用于评估股票的估值。公式如下：

$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$

低市盈率通常表示股票被低估，适合价值投资。

##### 3.3 实例分析

假设某新兴市场股票，无风险利率为3%，市场预期回报率为10%，贝塔系数为1.5。计算其预期回报率：

$$ \text{CAPM} = 3\% + 1.5 \times (10\% - 3\%) = 15.5\% $$

#### 第5章：新兴市场投资实战

##### 5.1 案例分析

假设在新兴市场中，某公司的市盈率为15，行业平均市盈率为20。根据市盈率分析，该股票可能被低估。

##### 5.2 代码实现

```python
import pandas as pd

def calculate_pe_ratio(stock_data):
    pe_ratio = stock_data['股价'] / stock_data['每股收益']
    return pe_ratio

# 示例数据
data = {
    '股价': [100, 200, 150],
    '每股收益': [5, 10, 7.5]
}
df = pd.DataFrame(data)
pe_ratios = calculate_pe_ratio(df)
print(pe_ratios)
```
