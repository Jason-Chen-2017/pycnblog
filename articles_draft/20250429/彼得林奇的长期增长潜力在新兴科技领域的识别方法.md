#### 3.3 Python代码实现

```python
def calculate_roe(net_income, shareholders_equity):
    return net_income / shareholders_equity

def calculate_growth_rate(revenue_current, revenue_previous):
    return (revenue_current - revenue_previous) / revenue_previous

def assess_market_position(market_share, competitive_advantages):
    if market_share > 0.2 and len(competitive_advantages) >= 2:
        return "Strong"
    elif market_share > 0.1 and len(competitive_advantages) >= 1:
        return "Moderate"
    else:
        return "Weak"

# 示例数据
net_income = 100
shareholders_equity = 500
revenue_current = 1000
revenue_previous = 800
market_share = 0.25
competitive_advantages = ["technology", "cost"]

# 计算ROE
roe = calculate_roe(net_income, shareholders_equity)
# 计算增长率
growth_rate = calculate_growth_rate(revenue_current, revenue_previous)
# 评估市场定位
market_position = assess_market_position(market_share, competitive_advantages)

print(f"ROE: {roe:.2f}")
print(f"增长率: {growth_rate:.2f}")
print(f"市场定位: {market_position}")
```

#### 3.4 数学模型与公式

- **ROE（净资产收益率）**：
  $$ROE = \frac{\text{净利润}}{\text{股东权益}}$$

- **增长率**：
  $$\text{增长率} = \frac{\text{当前收入} - \text{上期收入}}{\text{上期收入}}$$
