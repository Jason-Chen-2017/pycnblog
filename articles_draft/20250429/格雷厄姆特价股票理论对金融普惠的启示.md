## 第一部分：格雷厄姆特价股票理论的背景与基础

### 第1章：格雷厄姆与特价股票理论概述

#### 1.1 本杰明·格雷厄姆的生平简介
- **早年经历**：出生于美国纽约，早年经历经济大萧条，培养了稳健的投资理念。
- **学术贡献**：与大卫·多德合著《证券分析》，奠定价值投资基础。
- **投资哲学**：强调安全边际和内在价值，倡导长期投资。

#### 1.2 特价股票的定义与特点
- **定义**：市场价格低于内在价值的股票，具有较高的投资价值。
- **特点**：
  - 价格低估
  - 财务健康
  - 稳定的股息收益

#### 1.3 投资策略
- **价值投资**：买入并持有优质股票，长期增值。
- **安全边际**：确保买入价格远低于内在价值，降低风险。

### 第2章：格雷厄姆投资理论的核心概念

#### 2.1 安全边际的概念
- **定义**：市场价格与内在价值的差额，确保投资的安全性。
- **计算**：安全边际 = 内在价值 - 市场价格。
- **应用**：选择安全边际高的股票，降低投资风险。

#### 2.2 内在价值的评估
- **定义**：企业未来现金流的现值，反映其真实价值。
- **计算公式**：$$\text{内在价值} = \frac{\text{每股收益}}{\text{资本成本} - \text{增长率}}$$
- **影响因素**：盈利能力、财务状况、市场地位。

#### 2.3 股票分析的三要素
- **盈利能力**：ROE、净利润等指标。
- **财务状况**：资产负债表分析。
- **市场地位**：行业地位和竞争优势。

#### 3.1 内在价值计算
- **公式**：$$\text{内在价值} = \frac{\text{每股收益}}{r - g}$$
