### 第1章：芒格的“避免极端预测”概述

#### 1.1 芒格的“避免极端预测”核心思想

芒格的“避免极端预测”是一种思维方式，强调在决策中避免过于乐观或悲观的极端预测。这种思维模型通过关注概率和可能性，帮助投资者在技术估值中保持理性。例如，芒格曾指出，过度乐观的预测往往忽略了潜在风险，导致估值过高。

#### 1.2 新兴技术估值的背景与挑战

新兴技术如人工智能和区块链具有高度不确定性和快速变化的特点，传统估值方法往往依赖于历史数据和简单线性模型，难以捕捉新兴技术的复杂性和潜在风险。例如，过度乐观的预测可能导致估值过高，而忽视风险的预测可能导致估值过低。

#### 3.2 贝叶斯定理在估值中的应用

贝叶斯定理是一种用于更新概率的数学工具，可以帮助投资者根据新信息调整对技术的估值。例如，假设我们有一个技术，其成功的概率为0.6，但后来发现市场需求低于预期，概率调整为0.4。贝叶斯定理可以帮助我们根据新数据更新概率。

公式：
$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

```python
def bayes_theorem(P_A, P_B_given_A, P_B):
    return (P_B_given_A * P_A) / P_B

P_B_given_A = 0.8
P_B = 0.5
```
