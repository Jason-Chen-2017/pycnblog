## 第一部分: 格雷厄姆特价股票理论的背景与核心概念

### 第1章: 格雷厄姆特价股票理论概述

#### 1.1 格雷厄姆投资理论的基本概念
- **价值投资的核心理念**：格雷厄姆主张以低于内在价值的价格买入股票，长期持有，等待市场回归。
- **特价股票的定义与特征**：市盈率（P/E）<15，市净率（P/B）<1.5，股息率>5%。
- **格雷厄姆筛选法的基本框架**：通过多指标筛选出低估股票。

#### 1.2 格雷厄姆理论的适用场景
- **价值投资的市场环境**：适用于市场恐慌或非牛市时。
- **特价股票的筛选标准**：多指标交叉验证。
- **理论的边界与外延**：适用于传统行业，对科技股等新兴行业有局限性。

### 第2章: 格雷厄姆特价股票理论的核心要素

#### 2.1 格雷厄姆筛选法的关键指标
- **市盈率（P/E）的计算与应用**：P/E = 价格/每股收益。
- **市净率（P/B）的计算与应用**：P/B = 价格/每股净资产。
- **股息率的计算与应用**：股息率 = 股息/股价 × 100%。

#### 2.2 核心概念的属性特征对比
- **不同估值指标的对比分析**：表格展示P/E、P/B和股息率的差异。
- **格雷厄姆筛选法的优缺点**：优点是简单有效，缺点是忽略成长性和流动性。
- **不同市场环境下的表现差异**：牛市中表现不佳，熊市中表现优异。

### 第3章: 格雷厄姆理论与现代投资理论的联系

#### 3.1 格雷厄姆理论的内在逻辑
- **价值投资的哲学基础**：市场短期是投票机，长期是称重机。
- **股票价格与内在价值的关系**：价格围绕价值波动。
- **投资者心态对理论的影响**：恐慌和贪婪影响市场定价。

#### 3.2 格雷厄姆理论与现代投资组合理论的对比
- **现代投资组合理论的核心观点**：分散投资以降低风险。
- **格雷厄姆理论的局限性**：未充分考虑风险分散和市场流动性。
- **两者的结合与应用**：结合价值投资和分散投资策略。

#### 4.2 算法实现代码
```python
def graham_screen(stocks):
    selected_stocks = []
    for stock in stocks:
        pe = stock.pe
        pb = stock.pb
        dividend_yield = stock.dividend_yield
        if pe < 15 and pb < 1.5 and dividend_yield > 0.05:
            selected_stocks.append(stock)
    return selected_stocks

# 示例数据
class Stock:
    def __init__(self, name, pe, pb, dividend_yield):
        self.name = name
        self.pe = pe
        self.pb = pb
        self.dividend_yield = dividend_yield

stocks = [
    Stock("股票1", 10, 1.2, 0.06),
    Stock("股票2", 14, 1.4, 0.05),
    Stock("股票3", 16, 1.3, 0.04)
]

selected = graham_screen(stocks)
for stock in selected:
    print(f"名称: {stock.name}, 市盈率: {stock.pe}, 市净率: {stock.pb}, 股息率: {stock.dividend_yield}")
```

#### 4.3 数学模型和公式
- **市盈率计算**：$$P/E = \frac{\text{股价}}{\text{每股净利润}}$$
- **市净率计算**：$$P/B = \frac{\text{股价}}{\text{每股净资产}}$$
- **股息率计算**：$$\text{股息率} = \frac{\text{股息}}{\text{股价}} \times 100\%$$

```python
def graham_screen(stocks_df):
    selected = stocks_df[
        (stocks_df['市盈率'] < 15) &
        (stocks_df['市净率'] < 1.5) &
        (stocks_df['股息率'] > 0.05)
    ]
    return selected
```
