## 第1章: 全球股市估值的背景与现状

### 1.1 全球股市估值的基本概念

#### 1.1.1 什么是全球股市估值
全球股市估值是指对全球范围内股票市场的整体价值进行评估，通常通过市盈率（P/E ratio）、市净率（P/B ratio）等指标来衡量市场的整体健康状况。股市估值不仅是投资者决策的重要依据，也是反映经济状况的重要指标。

#### 1.1.2 全球股市估值的重要性
股市估值能够反映一个国家或地区的经济发展状况，同时也是全球资本流动的重要风向标。通过对全球股市估值的分析，投资者可以更好地理解市场的波动性和潜在的投资机会。

#### 1.1.3 全球股市估值的主要方法
- 市盈率（P/E ratio）：市盈率 = 每股价格 / 每股收益
- 市净率（P/B ratio）：市净率 = 每股价格 / 每股净资产
- 市销率（P/S ratio）：市销率 = 每股价格 / 每股收入
- 市盈率相对强弱指数（RSI）：衡量市场的超买或超卖状态

$$
\text{ReLU}(x) = \begin{cases}

#### 5.2.2 分类代码
```python
import tensorflow as tf
from tensorflow.keras import layers

# 加载预训练模型
model = tf.keras.models.load_model('garbage_classifier.h5')

# 图像预处理
def preprocess_image(image):
    image = cv2.resize(image, (64, 64))
    image = image / 255.0
    return image

# 分类函数
def classify_image(image):
    processed_image = preprocess_image(image)
    processed_image = processed_image.reshape(1, 64, 64, 3)
    prediction = model.predict(processed_image)
    return prediction.argmax(axis=1)[0]

# 测试分类
image = cv2.imread('test.jpg')
print(classify_image(image))
```
