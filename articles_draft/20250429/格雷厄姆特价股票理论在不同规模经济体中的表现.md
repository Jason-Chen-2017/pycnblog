## 第一部分: 格雷厄姆特价股票理论基础

### 第1章: 格雷厄姆特价股票理论概述

#### 1.1 格雷厄姆投资理论的起源
格雷厄姆价值投资理论是20世纪最经典的金融理论之一，由本杰明·格雷厄姆（Benjamin Graham）提出。该理论强调以低于内在价值的价格购买股票，注重安全边际和长期投资策略。

- **价值投资的起源与发展**  
  格雷厄姆在《证券分析》（1934年）和《聪明的投资者》（1949年）中系统阐述了价值投资理念，强调股票的内在价值是其未来现金流的现值，而市场价格经常偏离内在价值。

- **格雷厄姆的投资理念与方法**  
  格雷厄姆主张以安全边际为核心，即以低于内在价值的价格买入股票，避免过度依赖市场情绪，注重基本面分析。

- **格雷厄姆理论的核心思想**  
  格雷厄姆认为，市场先生（Market先生）是股票市场的化身，其情绪波动为投资者提供了低价买入和高价卖出的机会。

#### 1.2 特价股票的定义与特征
特价股票是指市场价格低于其内在价值的股票，通常具有以下特征：
- **低市盈率（P/E）**：市盈率低于行业平均水平。
- **低市净率（P/B）**：市净率低于行业平均水平。
- **高股息率**：股息收益率较高。
- **估值折扣**：市场价格低于根据未来现金流折现计算的内在价值。

#### 1.3 格雷厄姆理论在投资中的重要性
- **格雷厄姆理论的适用场景**  
  适用于市场恐慌、市场低估、经济衰退等情况下，寻找被市场忽视的优质股票。

- **格雷厄姆理论在投资决策中的作用**  
  作为价值投资的核心理论，格雷厄姆理论帮助投资者在市场波动中发现低估机会，降低投资风险。

- **格雷厄姆理论的局限性**  
  该理论假设股票价格最终会回归内在价值，但在市场有效或长期熊市中，部分股票可能长期被低估。

### 第2章: 格雷厄姆特价股票理论的核心概念

#### 2.1 格雷厄姆理论的核心要素
- **安全边际（Margin of Safety）**  
  安全边际是市场价格与内在价值之间的差额，确保投资者在买入时有一定的安全空间，即使价格波动，也能保证本金安全。

- **内在价值（Intrinsic Value）**  
  内在价值是股票的未来现金流的现值，通过分析公司的财务状况和未来盈利能力计算得出。

- **市场先生（Mr. Market）**  
  格雷厄姆将市场情绪化为市场先生，强调投资者应忽视短期市场波动，专注于长期投资。

#### 2.2 格雷厄姆理论的数学模型
- **内在价值的计算公式**  
  内在价值可以通过股利贴现模型（DDM）计算：
  $$ V = \sum_{t=1}^{n} \frac{D_t}{(1+r)^t} + \frac{P_n}{(1+r)^n} $$
  其中，$D_t$是第$t$年的股息，$r$是折现率，$P_n$是第$n$年的终值。

- **安全边际的计算公式**  
  安全边际可以通过以下公式计算：
  $$ S = V - P $$
  其中，$S$是安全边际，$V$是内在价值，$P$是市场价格。

- **市盈率的计算公式**  
  市盈率（P/E）计算公式为：
  $$ P/E = \frac{P}{E} $$
  其中，$P$是股价，$E$是每股收益。

### 第3章: 格雷厄姆理论在不同规模经济体中的应用

#### 3.1 发达国家经济环境下的应用
- **发达国家的市场特点**  
  发达国家市场成熟，波动性较低，公司治理完善，信息公开透明。

- **格雷厄姆理论在发达国家的应用案例**  
  在2008年金融危机期间，许多美国银行股价格被低估，投资者可以以低于内在价值的价格买入，最终获得超额收益。

- **发达国家市场中的策略调整**  
  在发达国家市场中，投资者可以结合宏观经济指标（如GDP增长率、通胀率）和行业趋势，优化投资组合。

#### 3.2 发展中国家经济环境下的应用
- **发展中国家的市场特点**  
  发展中国家市场波动性较大，信息不透明，但增长潜力较高。

- **格雷厄姆理论在发展中国家的应用案例**  
  在中国股市中，许多中小盘股由于市场关注度低，价格可能被低估，适合运用格雷厄姆理论进行投资。

- **发展中国家市场中的策略调整**  
  在发展中国家市场中，投资者需要更加关注公司基本面，如盈利能力、财务健康状况，同时注意宏观经济风险。

import pandas as pd
import numpy as np

def calculate_intrinsic_value(stock_data, required_return):
    # 假设股息增长率固定
    growth_rate = 0.05
    stock_data['Intrinsic Value'] = stock_data['股息'].apply(
        lambda d: d / (required_return - growth_rate)
    )
    return stock_data

# 示例数据
data = {
    '股票代码': ['A', 'B', 'C'],
    '股息': [1, 2, 1.5],
    '股价': [20, 30, 25],
    '市盈率': [10, 15, 12],
    '市净率': [2, 3, 2.5]
}
stock_data = pd.DataFrame(data)

# 计算内在价值（假设required_return=0.1）
intrinsic_value = calculate_intrinsic_value(stock_data, 0.1)
print(intrinsic_value)
