# 第二部分：现金流的基本概念与分类

## 2.1 现金流的定义与组成

### 2.1.1 现金流的定义

- **现金流**：企业在一定时期内现金和现金等价物的流入和流出。
- 包括经营活动、投资活动和筹资活动的现金流。

### 2.1.2 现金流的组成要素

- **经营活动现金流**：日常运营产生的现金流。
- **投资活动现金流**：购买或出售资产的现金流。
- **筹资活动现金流**：通过借款或发行股票获得的现金流。

### 2.1.3 现金流与企业利润的关系

- 净利润是会计利润，现金流是实际资金流动。
- 现金流反映企业的实际盈利能力。

## 2.2 现金流的分类与计算

### 2.2.1 经营活动现金流

- 主要来源：销售收入、应收账款收回。
- 主要流出：支付货款、工资、税费。

### 2.2.2 投资活动现金流

- 主要来源：出售资产、投资收回。
- 主要流出：购买资产、投资支出。

### 2.2.3 筹资活动现金流

- 主要来源：借款、发行股票。
- 主要流出：偿还债务、支付股息。

### 2.2.4 现金流净额的计算公式

$$\text{现金流净额} = \text{经营活动现金流} + \text{投资活动现金流} + \text{筹资活动现金流}$$

## 2.3 现金流的分析方法

### 2.3.1 现金流质量分析

- 现金流是否来自核心业务。
- 非核心业务的现金流占比。

### 2.3.2 现金流结构分析

- 各类现金流的占比。
- 结构是否合理。

### 2.3.3 现金流趋势分析

- 近期现金流变化趋势。
- 未来现金流预测。

# 第三部分：自由现金流的定义与重要性

## 3.1 自由现金流的定义

### 3.1.1 自由现金流的公式

$$\text{自由现金流} = \text{净利润} - \text{非现金项目} + \text{折旧与摊销}$$

### 3.1.2 自由现金流的来源

- 经营活动产生的现金流。
- 投资活动回收的资金。
- 筹资活动获得的资金。

## 3.2 自由现金流的核心特征

### 3.2.1 自由现金流的稳定性

- 现金流波动小，企业财务风险低。

### 3.2.2 自由现金流的增长性

- 现金流逐年增长，企业具有扩张能力。

### 3.2.3 自由现金流的可持续性

- 现金流来源稳定，企业持续盈利。

## 3.3 自由现金流与企业价值的关系

### 3.3.1 自由现金流是企业价值的核心驱动因素

- 企业价值 = 现金流的现值。
- 自由现金流越多，企业价值越高。

### 3.3.2 自由现金流与股价的关系

- 自由现金流增长，股价上升。
- 自由现金流下降，股价下跌。

### 3.3.3 自由现金流的未来预测

- 通过DCF模型预测未来现金流。
- 评估企业的长期投资价值。
