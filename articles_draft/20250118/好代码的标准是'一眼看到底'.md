## 第三部分：主流'一眼看到底'代码实践

### 第3章：主流'一眼看到底'代码实践

#### 3.1.1 使用函数和模块化

函数和模块化是编写'一眼看到底'代码的重要手段。通过将代码划分为独立的函数和模块，可以提高代码的可读性和可维护性。函数和模块应该具有明确的职责和功能，避免过于复杂和冗长的代码。

#### 3.1.2 遵循单一职责原则

单一职责原则（Single Responsibility Principle）是指一个函数或模块应该只负责一项任务。这有助于提高代码的可读性和可维护性，降低代码之间的耦合度。

#### 3.1.3 使用设计模式

设计模式是解决常见软件设计问题的经验总结。通过合理使用设计模式，可以提高代码的可读性和可维护性。例如，使用工厂模式、单例模式、观察者模式等，可以使代码更加简洁和灵活。

#### 3.1.4 关注性能优化

性能优化是编写'一眼看到底'代码的一个重要方面。通过使用高效的数据结构和算法，避免不必要的内存和计算开销，可以提高代码的性能。例如，使用哈希表代替线性搜索、使用二分查找代替顺序遍历等。

```python
class Singleton:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super(Singleton, cls).__new__(cls)
        return cls._instance

class Logger(Singleton):
    def log(self, message):
        print(message)
```

```python
def search_array(arr, target):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1
```
