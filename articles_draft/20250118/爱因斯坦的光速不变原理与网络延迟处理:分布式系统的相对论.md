### 1.2 核心概念与联系

#### 1.2.1 光速不变原理

爱因斯坦的光速不变原理是相对论的核心概念之一，指出在真空中，光速是一个恒定值，与光源和观察者的相对运动无关。这一原理颠覆了传统的牛顿力学观念，对现代物理学产生了深远影响。

| 特征         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 光速恒定     | 无论光源和观察者的相对运动如何，光速在真空中始终为 \(c = 299,792,458 \text{ m/s}\) |
| 相对论效应   | 物体的质量、长度、时间等会随着相对速度的变化而变化           |

#### 1.2.2 分布式系统

分布式系统是由多个独立计算机节点组成的网络，通过通信协议实现协作与资源共享。网络延迟是分布式系统中的一个重要指标，影响着系统的响应速度和稳定性。

| 特征         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 独立节点     | 每个节点具有独立的功能，可以独立运行和故障恢复                 |
| 通信协议     | 节点之间通过特定的通信协议进行数据传输和协同工作               |
| 网络延迟     | 数据在网络中传输所需的时间，包括传输时间、处理时间和传输带宽 |

#### 1.2.3 网络延迟处理机制

分布式系统中的网络延迟处理机制包括时间同步、负载均衡、缓存和压缩等策略。这些机制旨在降低网络延迟，提高系统性能。

| 处理机制     | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 时间同步     | 通过同步时间，减少由于时间不同步导致的延迟                     |
| 负载均衡     | 通过均衡各节点的负载，减少单点瓶颈引起的延迟                   |
| 缓存         | 通过缓存常用数据，减少重复查询和传输的延迟                   |
| 压缩         | 通过数据压缩，减少传输数据的大小，降低延迟                   |
