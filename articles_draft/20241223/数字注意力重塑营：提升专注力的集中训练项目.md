**2.1 定义与基本概念**

数字注意力是指个体在数字环境中专注于特定任务的能力。它包括注意力分配、注意力转移、注意力维持和注意力恢复等多个方面。

| 属性特征     | 传统注意力          | 数字注意力          |
| ------------ | ------------------- | ------------------- |
| 注意力分配   | 空间分布            | 时空分布            |
| 注意力转移   | 快速但容易分散      | 缓慢但持久          |
| 注意力维持   | 长时间保持专注      | 短时间内保持专注    |
| 注意力恢复   | 通过休息恢复        | 通过专注恢复        |

数字注意力的核心要素包括信息处理能力、认知资源管理、情绪调节和心理适应能力。

**5.1 项目介绍**
