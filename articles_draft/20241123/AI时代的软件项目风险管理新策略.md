##### 3.1.1 逻辑树算法

```
function riskAssessment(logicTree) {

}

function calculateRiskValue(node) {
    if (node is a leaf) {
        return node probability * node impact;
    } else {
        totalRisk = 0;
        for (each child in node) {
            totalRisk += calculateRiskValue(child);
        }
        return totalRisk;
    }
}
```
