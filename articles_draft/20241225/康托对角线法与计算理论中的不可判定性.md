#### 1.1 康托对角线法的基本概念

康托对角线法（Cantor's diagonal argument）是数学家康托尔（Georg Cantor）提出的一种著名的方法，用于证明实数集的势（cardinality）大于自然数集的势。这一方法首次发表于1874年，是对集合论中无穷大概念的深入研究。康托对角线法的核心思想是通过构造一个与给定列表不同的实数，来证明实数集不是可数的。

在康托对角线法中，我们首先有一个实数的列表，然后将每个实数的十进制表示法取出，并对它们进行修改，最终构造出一个新的实数。具体来说，对于每个第\(i\)个实数，我们将其第\(i\)位数字增加1（如果第\(i\)位是9，则变为0，并将下一位加1）。这样构造出来的实数与原始列表中的每个实数都不同，因此我们无法列出所有的实数。

#### 1.2 问题背景

康托对角线法的提出，是为了解决无穷大问题。在康托尔之前，人们普遍认为实数是可以一一列举的，即实数集是可数的。康托尔的证明揭示了实数集的势比自然数集的势更大，即实数集是不可数的。这一发现彻底改变了数学对无穷大的理解，并引发了关于无穷大的深入研究。

#### 1.3 历史发展

康托对角线法的提出，标志着数学史上的一次重要转折。康托尔不仅证明了实数集的不可数性，还引入了集合论的概念，为现代数学的发展奠定了基础。康托尔的贡献在数学界得到了广泛的认可，他也因此被誉为“集合论的奠基人”。

#### 1.4 康托对角线法在计算理论中的重要性

康托对角线法在计算理论中有着深远的影响。它不仅提供了一个证明不可判定性的方法，还在计算复杂性理论中有着广泛的应用。例如，康托对角线法可以用来证明某些问题在计算上是不可解的，这意味着我们无法设计出一个算法来解决这个问题。

```python
# 康托对角线法Python实现
def diagonal_argument(numbers):
    for i, number in enumerate(numbers):
        # 将实数转换为字符串
        number_str = str(number)
        # 修改第i位数字
        new_digit = int(number_str[i]) + 1
        if new_digit == 10:
            new_digit = 0
        # 组合新实数
        new_number = float(number_str[:i] + str(new_digit) + number_str[i+1:])
        # 检查新实数与原列表中的实数是否不同
        if new_number not in numbers:
            return new_number
    return None

# 示例：给定一个实数列表
numbers = [0.1, 0.2, 0.3, 0.4]
# 调用函数
new_number = diagonal_argument(numbers)
print(f"新实数：{new_number}")
```
