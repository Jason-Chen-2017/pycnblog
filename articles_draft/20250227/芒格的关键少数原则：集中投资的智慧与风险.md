### 第1章：芒格“关键少数”原则的背景与重要性

#### 1.1 投资领域的集中原则

- **1.1.1 什么是“关键少数”原则**
  - “关键少数”原则指出，在投资组合中，少数高质量的资产贡献了大部分价值。
  - 芒格强调集中投资于少数优质企业，而非分散投资。

- **1.1.2 芒格投资理念的核心**
  - 芒格的投资理念基于价值投资，寻找具有持续竞争优势的企业。
  - 集中投资于少数优质资产，而非追求短期收益。

- **1.1.3 集中投资的优缺点分析**
  - 优点：高回报潜力，简化决策过程。
  - 缺点：高风险，市场波动可能导致重大损失。

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

def calculate_key_ratio(key_assets, total_assets):
    return len(key_assets) / total_assets

def portfolio_return(weights, returns):
    return np.dot(weights, returns)

def portfolio_risk(weights, covariance_matrix):
    return np.sqrt(np.dot(weights.T, np.dot(covariance_matrix, weights)))

# 示例数据
assets = ['A', 'B', 'C', 'D']
returns = [0.1, 0.2, 0.05, 0.15]
covariance_matrix = np.array([[0.02, 0.01, 0.005, 0.01],
                              [0.01, 0.03, 0.008, 0.015],
                              [0.005, 0.008, 0.02, 0.01],
                              [0.01, 0.015, 0.01, 0.03]])

weights = [0.4, 0.3, 0.2, 0.1]

key_assets = ['B', 'A']
key_ratio = calculate_key_ratio(key_assets, len(assets))
print(f"关键少数比例: {key_ratio}%")

portfolio_return_val = portfolio_return(weights, returns)
portfolio_risk_val = portfolio_risk(weights, covariance_matrix)
print(f"投资组合预期收益: {portfolio_return_val}")
print(f"投资组合风险: {portfolio_risk_val}")
