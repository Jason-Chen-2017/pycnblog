# 第一部分: 资产相关性网络分析基础

## 第1章: 资产相关性的基本概念

### 1.1 相关性的定义与计算

相关性是衡量两个资产价格变动之间关系的指标。Pearson相关系数是最常用的度量方法，公式如下：

$$ r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2} \sqrt{\sum (y_i - \bar{y})^2}} $$

其中，$\bar{x}$和$\bar{y}$分别表示资产$x$和$y$的平均值。

### 1.2 跨资产相关性的网络表示

通过将资产视为网络中的节点，资产之间的相关性作为边的权重，可以构建一个资产相关性网络。例如，当两个资产的相关性较高时，它们之间的边会更粗且颜色更暖。

## 第2章: 资产相关性网络的构建方法

### 2.1 数据预处理

在构建相关性网络之前，需要对数据进行清洗和标准化处理。例如，使用Z-score方法将数据标准化：

$$ z = \frac{x - \mu}{\sigma} $$

其中，$\mu$是均值，$\sigma$是标准差。

### 2.2 网络构建算法

#### 2.2.1 基于相关性的网络构建

步骤如下：
1. 计算资产相关性矩阵。
2. 根据相关性阈值构建无向图。
3. 可视化网络。

代码示例：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler

# 示例数据：生成10个资产的随机数据
np.random.seed(42)
data = np.random.randn(10, 100)
df = pd.DataFrame(data)

# 数据标准化
scaler = StandardScaler()
df_scaled = pd.DataFrame(scaler.fit_transform(df))

# 计算相关性矩阵
correlation_matrix = df_scaled.corr()

# 构建网络：假设相关性大于0.3时连接
threshold = 0.3
edges = []
for i in range(len(correlation_matrix)):
    for j in range(i+1, len(correlation_matrix)):
        if correlation_matrix.iloc[i, j] > threshold:
            edges.append((i, j))

# 可视化网络
plt.figure(figsize=(10, 10))
plt.title("Asset Correlation Network")
# 使用networkx绘制网络图
import networkx as nx
G = nx.Graph()
G.add_edges_from(edges)
nx.draw(G, with_labels=True, node_size=500, edge_color='blue', edge_alpha=0.5, font_size=12)
plt.show()
```

## 第5章: 系统架构与实现

### 5.1 系统架构设计

使用分层架构，包括数据采集层、计算层和展示层。

### 5.2 系统实现代码

```python
import pandas as pd
import numpy as np
import networkx as nx
import matplotlib.pyplot as plt

def build_correlation_network(data, threshold=0.3):
    # 数据标准化
    scaler = StandardScaler()
    data_scaled = pd.DataFrame(scaler.fit_transform(data))
    
    # 计算相关性矩阵
    correlation_matrix = data_scaled.corr()
    
    # 构建网络
    G = nx.Graph()
    for i in range(len(correlation_matrix)):
        for j in range(i+1, len(correlation_matrix)):
            if correlation_matrix.iloc[i, j] > threshold:
                G.add_edge(i, j)
    
    return G

# 示例数据
np.random.seed(42)
data = np.random.randn(5, 100)
df = pd.DataFrame(data)

# 构建网络
G = build_correlation_network(df)

# 可视化
plt.figure(figsize=(10, 10))
nx.draw(G, with_labels=True, node_color='red', edge_color='blue', edge_alpha=0.5, font_size=12)
plt.title("Asset Correlation Network")
plt.show()
```
