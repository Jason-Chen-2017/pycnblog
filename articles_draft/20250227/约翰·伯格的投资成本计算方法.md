## 第1章: 投资成本计算的基本概念

### 1.1 投资成本的基本概念

#### 1.1.1 投资成本的定义
投资成本是指在投资过程中所需投入的所有资源的总和，包括资金、时间和人力资源等。

#### 1.1.2 投资成本的核心要素
- 资金成本：包括本金和利息支出。
- 时间成本：包括项目周期和机会成本。
- 风险成本：包括潜在损失和不确定性。

#### 1.1.3 投资成本的分类与特点
- 直接成本：与项目直接相关的成本。
- 间接成本：与项目间接相关的成本。
- 可变成本：随着项目规模变化而变化的成本。
- 固定成本：不随项目规模变化而变化的成本。

### 1.2 投资成本计算的重要性

#### 1.2.1 投资成本在投资决策中的作用
- 帮助投资者评估项目的可行性。
- 为投资决策提供数据支持。

#### 1.2.2 投资成本对投资收益的影响
- 高成本可能导致投资收益下降。
- 成本控制是提升投资收益的关键因素。

#### 1.2.3 投资成本计算的边界与外延
- 计算的范围和时间跨度。
- 需要考虑的外部因素，如市场波动和政策变化。

### 1.3 约翰·伯格的投资哲学

#### 1.3.1 约翰·伯格的投资理念概述
- 长期投资，价值投资。
- 重视企业的基本面分析。

#### 1.3.2 约翰·伯格的成本控制策略
- 降低投资成本，提升投资效率。
- 避免过度交易和频繁操作。

#### 1.3.3 约翰·伯格投资方法的核心思想
- 简单即是美，追求长期稳定的收益。

## 第2章: 投资成本计算的基本方法

### 2.1 投资成本计算的基本原理

#### 2.1.1 投资成本计算的公式
投资成本 = 初始投资 + 运营成本 + 维护成本 + 机会成本

#### 2.1.2 投资成本计算的步骤
1. 确定投资目标和范围。
2. 识别所有相关成本。
3. 量化各成本项。
4. 综合计算总成本。

#### 2.1.3 投资成本计算的关键因素
- 投资规模
- 时间跨度
- 风险水平

### 2.2 投资成本计算的数学模型

#### 2.2.1 投资成本计算的公式推导
$$ 总成本 = \sum_{i=1}^{n} C_i $$
其中，$C_i$ 是第i项的成本。

#### 2.2.2 投资成本计算的数学模型
$$ TC = C_1 + C_2 + ... + C_n $$
其中，$TC$ 是总成本，$C_i$ 是各项成本。

1. 输入投资项目的详细信息。
2. 确定各项成本。
3. 计算总成本。

    total_cost = 0
    for cost in investment.costs:

    return total_cost

    'costs': [100, 200, 300]
}
print(calculate_total_cost(investment))
