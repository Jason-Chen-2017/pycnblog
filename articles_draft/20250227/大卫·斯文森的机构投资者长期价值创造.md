## 第三部分：算法原理与数学模型

### 第3章：现代投资组合理论与算法实现

#### 3.1 现代投资组合理论概述

- **投资组合理论的基本假设**：投资者理性，市场有效，资产收益符合正态分布。
- **风险与收益的权衡**：在给定风险下追求最大收益，或在给定收益下追求最小风险。
- **投资组合优化的目标**：最大化收益，最小化风险，或在两者之间找到平衡点。

#### 3.2 均值-方差优化算法

```mermaid

```

#### 3.3 数学模型与公式

- **投资组合收益公式**：$$E(r_p) = \sum w_i E(r_i)$$
- **投资组合风险公式**：$$\sigma_p^2 = \sum \sum w_i w_j \sigma_{ij}$$
- **优化目标函数**：$$\min w^T \Sigma w \quad \text{subject to} \quad \sum w_i = 1$$

#### 3.4 算法实现与代码示例

```python
import numpy as np

def portfolio_optimization(returns):
    n = len(returns)
    Sigma = np.cov(returns)
    ones = np.ones(n)
    # 最小方差组合
    w_min_var = np.linalg.solve(Sigma, ones) / np.transpose(ones @ np.linalg.solve(Sigma, ones))
    return w_min_var
```
