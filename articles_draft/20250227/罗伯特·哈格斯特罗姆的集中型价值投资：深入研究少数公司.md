### 第三部分：集中型价值投资的数学模型与算法

#### 第3章：集中型价值投资的数学模型与算法

- **3.1 价值评估的数学模型**
  - 3.1.1 市盈率（P/E）模型
    - 公式：$$ P/E = \frac{当前股价}{每股净利润} $$
  - 3.1.2 市净率（P/B）模型
    - 公式：$$ P/B = \frac{当前股价}{每股净资产} $$
  - 3.1.3 股东权益回报率（ROE）模型
    - 公式：$$ ROE = \frac{净利润}{股东权益} $$

- **3.2 投资组合优化的数学模型**
  - 3.2.1 马科维茨投资组合理论
    - 公式：$$ \text{最小化} \sum_{i=1}^{n} w_i^2 \sigma_i^2 $$
    - 其中，\( w_i \) 是权重，\( \sigma_i \) 是资产 \( i \) 的标准差
  - 3.2.2 集中型投资组合优化的改进模型

- **3.3 集中型投资的风险评估与优化**
  - 3.3.1 风险调整后的收益评估
    - 公式：$$ \text{夏普比率} = \frac{E[r_i - r_f]}{\sigma_i} $$
    - 其中，\( E[r_i - r_f] \) 是资产 \( i \) 的超额收益，\( \sigma_i \) 是其标准差
  - 3.3.2 风险分层与集中度优化策略

- **3.4 数学模型的实际应用案例**
  - 3.4.1 使用P/E与P/B模型评估某公司的投资价值

  - 4.3.2 投资组合优化代码
    ```python
    import numpy as np
    from scipy.optimize import minimize

    # 示例优化问题：最小化投资组合风险
    def portfolio_variance(weights, covariance_matrix):
        return np.dot(weights.T, np.dot(covariance_matrix, weights))

    # 约束条件：权重之和为1
    def constraint(weights):
        return np.sum(weights) - 1

    # 使用scipy.optimize进行优化
    initial_weights = np.array([0.5, 0.5])
    covariance_matrix = np.array([[0.16, 0.05], [0.05, 0.16]])
    result = minimize(portfolio_variance, initial_weights, args=covariance_matrix, 
                     method='SLSQP', constraints={'type': 'eq', 'fun': constraint})
    print(result.x)
    ```
