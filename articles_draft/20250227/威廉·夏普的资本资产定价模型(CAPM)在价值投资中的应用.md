## 第1章: 引言

### 1.1 什么是威廉·夏普的CAPM
#### 1.1.1 资本资产定价模型的基本概念
资本资产定价模型（CAPM）是威廉·夏普在20世纪60年代提出的一种用于估计资产或投资组合期望收益的理论模型。它假设市场是有效的，并且投资者是理性的。

#### 1.1.2 CAPM的历史背景与发展
CAPM的提出基于现代投资组合理论（MPT），它在20世纪60年代被广泛接受，并成为金融学中的一个经典模型。

#### 1.1.3 CAPM在金融学中的重要性
CAPM为金融学家提供了一种量化风险和收益关系的方法，是金融学中最重要的工具之一。

### 1.2 CAPM的核心假设与局限性
#### 1.2.1 CAPM的基本假设
1. 投资者是理性的。
2. 市场是无摩擦的（无交易成本、无税收）。
3. 资产是可以完全流动的。
4. 无套利机会。

#### 1.2.2 CAPM的局限性与批评
1. 假设市场的无摩擦性和理性可能与现实不符。
2. 无法解释现实中的一些现象，如小盘股的高收益。

#### 1.2.3 CAPM在实际应用中的调整
在实践中，CAPM可以通过引入其他因素（如规模、价值等）进行扩展，形成多因子模型。

### 1.3 价值投资与CAPM的关系
#### 1.3.1 价值投资的基本理念
价值投资是一种投资策略，强调以低于内在价值的价格买入优质股票。

#### 1.3.2 CAPM在价值投资中的应用前景
CAPM可以帮助投资者量化资产的内在价值，并评估其相对于市场的公平性。

#### 1.3.3 价值投资与CAPP的结合点
价值投资者可以通过CAPM模型来评估市场的公平性，并寻找被低估的股票。

## 第2章: CAPM的理论基础

### 2.1 资本资产定价模型的推导
#### 2.1.1 投资者效用函数的构建
投资者追求效用最大化，即在给定风险下收益最大化，或在给定收益下风险最小化。

#### 2.1.2 无风险资产与风险资产的分离
无风险资产（如国债）的风险溢价为零，而风险资产的预期收益与其风险相关。

#### 2.1.3 风险溢价的计算
风险溢价是市场对承担系统性风险的补偿。

### 2.2 CAPM的核心公式
CAPM的公式为：
$$
E(R_i) = R_f + \beta_i (E(R_m) - R_f)
$$
其中：
- \(E(R_i)\) 是资产 \(i\) 的预期收益率。
- \(R_f\) 是无风险利率。
- \(\beta_i\) 是资产 \(i\) 的贝塔系数。
- \(E(R_m) - R_f\) 是市场风险溢价。

### 2.3 CAPM的假设与前提
#### 2.3.1 投资者理性假设
投资者追求效用最大化，并根据风险和收益做出决策。

#### 2.3.2 无摩擦市场假设
市场无交易成本、无税收，信息自由流动。

#### 2.3.3 资产完全流动性假设
所有资产都可以在市场上自由买卖。

#### 2.3.4 无税收与交易成本假设
假设无税收和交易成本。

## 第6章: 项目实战

### 6.1 环境安装
需要安装Python和相关库（如Pandas、NumPy、Scipy等）。

### 6.2 核心实现源代码
以下是实现CAPM模型的Python代码：
```python
import pandas as pd
import numpy as np
from scipy.stats import linregress

def calculate_beta(risky_returns, market_returns):
    # 计算贝塔系数
    slope, _, _, _, _ = linregress(market_returns, risky_returns)
    return slope

def calculate_capm(risk_free_rate, beta, market_return):
    # 计算CAPM预期收益率
    return risk_free_rate + beta * (market_return - risk_free_rate)

# 示例数据
data = pd.DataFrame({
    '市场收益率': [0.05, 0.06, 0.04, 0.07, 0.05],
    '风险资产收益率': [0.08, 0.09, 0.06, 0.10, 0.07]
})

beta = calculate_beta(data['风险资产收益率'], data['市场收益率'])
capm_return = calculate_capm(0.02, beta, data['市场收益率'].mean())

print(f"贝塔系数: {beta}")
print(f"CAPM预期收益率: {capm_return}")
```

### 6.3 代码应用解读与分析
以上代码通过线性回归计算贝塔系数，并利用CAPM公式计算资产的预期收益率，判断其是否被高估或低估。
