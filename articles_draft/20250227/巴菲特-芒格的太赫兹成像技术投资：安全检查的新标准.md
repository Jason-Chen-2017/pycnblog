### 第1章：太赫兹成像技术的背景与应用

#### 1.1 太赫兹成像技术的定义与特点

- **非电离辐射**：太赫兹波的能量较低，不会对人体或物体造成电离辐射伤害。
- **高分辨率**：太赫兹成像技术可以提供高分辨率的图像，能够检测到隐藏物体的形状和位置。
- **多用途**：适用于安全检查、医疗成像、无损检测等多个领域。

#### 1.2 太赫兹成像技术在安全检查中的应用

#### 4.2 代码实现
- **Python代码示例**：
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  def generate_terahertz_signal():
      # 生成太赫兹信号
      freq = np.linspace(0.1, 10, 1000)
      signal = np.sin(2 * np.pi * freq * 0.5)
      return signal

  def process_signal(signal):
      # 信号处理
      denoised_signal = signal * np.exp(-0.5 * np.linspace(0, 1, len(signal)))
      return denoised_signal

  if __name__ == "__main__":
      signal = generate_terahertz_signal()
      denoised_signal = process_signal(signal)
      plt.plot(signal, label="Original Signal")
      plt.plot(denoised_signal, label="Denoised Signal")
      plt.xlabel("Frequency (THz)")
      plt.ylabel("Amplitude")
      plt.legend()
      plt.show()
  ```
