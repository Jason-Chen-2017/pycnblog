## 第一章: 格雷厄姆工作资本分析概述

### 1.1 格雷厄姆及其投资理念
格雷厄姆是价值投资的鼻祖，其核心理念是寻找市场低估的企业，通过分析企业基本面进行投资。工作资本分析是其理论体系中的重要组成部分。

### 1.2 工作资本分析的定义与特点
工作资本指流动资产减去短期负债，反映企业的短期偿债能力和运营效率。

### 1.3 工作资本分析的现代扩展

## 第四章: 工作资本分析的现代应用

### 4.1 现代企业估值的挑战
技术投入、品牌价值等无形资产对企业价值的影响日益重要。

### 4.2 工作资本分析与现金流折现法
现金流折现法（DCF）是现代企业估值的重要方法，结合工作资本分析可以更全面地评估企业价值。

### 4.3 工作资本分析与相对估值法
相对估值法（Relative Valuation）通过比较可比公司，调整估值指标，提高估值的合理性。

```python
import pandas as pd
import numpy as np

# 数据导入
data = pd.read_csv('企业数据.csv')

# 工作资本计算
working_capital = data['流动资产'] - data['短期负债']

# 现金流折现计算
discount_rate = 0.1
cash_flows = data['现金流']
discounted_value = np.npv(discount_rate, cash_flows)

print("工作资本:", working_capital)
print("现金流折现值:", discounted_value)
```
