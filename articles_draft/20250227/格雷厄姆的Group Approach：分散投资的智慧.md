# 第一部分: 分散投资的智慧：格雷厄姆的Group Approach

## 第1章: 分散投资的基本概念与背景

### 1.1 投资的基本原理
#### 1.1.1 投资的定义与分类
- 投资的定义：将资金投入到资产中，以期获得收益的行为。
- 投资的分类：
  - 股票：高风险高回报。
  - 债券：相对稳定的收益。
  - 房地产：实物资产，抗跌性较强。
  - 其他：如黄金、货币基金等。

#### 1.1.2 传统投资方式的局限性
- 集中投资的风险：将所有资金投入到单一资产或少数资产中，风险过高。
- 市场波动的影响：市场下跌时，集中投资容易遭受重大损失。
- 投资者情绪的干扰：贪婪与恐惧导致非理性决策。

#### 1.1.3 分散投资的必要性与优势
- 分散投资的必要性：通过持有多种资产降低风险。
- 分散投资的优势：
  - 风险分散：避免单一资产的大幅波动。
  - 稳定收益：通过多元化的资产配置实现稳健回报。
  - 抗跌性：在市场低迷时，部分资产的收益可以弥补其他资产的损失。

### 1.2 格雷厄姆与价值投资的起源
#### 1.2.1 格雷厄姆的生平与贡献
- 本杰明·格雷厄姆（Benjamin Graham）：20世纪初著名投资家，价值投资之父。
- 主要贡献：
  - 提出“安全边际”概念。
  - 创立格雷厄姆-多德学院，培养了巴菲特等投资大师。

#### 1.2.2 价值投资的核心理念
- 价值投资的核心：寻找被市场低估的资产进行投资。
- 格雷厄姆的投资策略：
  - 买入低于内在价值的股票。
  - 长期持有，等待市场回归。

#### 1.2.3 Group Approach的提出背景
- Group Approach的背景：
  - 20世纪30年代经济大萧条后，投资者意识到集中投资的风险。
  - 格雷厄姆提出通过分散投资降低风险。

## 第2章: 格雷厄姆的Group Approach理论

### 2.1 Group Approach的核心概念
#### 2.1.1 分散投资的定义与目标
- 分散投资的定义：将资金分配到多个资产或资产类别中，以降低投资组合的整体风险。
- 分散投资的目标：
  - 最小化投资组合的波动性。
  - 实现稳健的长期收益。

#### 2.1.2 Group Approach的理论框架
- 格雷厄姆的Group Approach理论：
  - 将资金分配到多个资产类别中。
  - 通过资产配置降低风险。

#### 2.1.3 核心要素与属性对比表
| 核心要素 | 集中投资 | 分散投资 |
|----------|----------|----------|
| 风险     | 高       | 低       |
| 收益     | 高       | 中等     |
| 抗跌性   | 低       | 高       |
| 操作复杂性 | 低       | 中等     |

### 2.2 Group Approach的数学模型
#### 2.2.1 投资组合的期望收益公式
$$ E(r_p) = \sum w_i E(r_i) $$
- 解释：投资组合的期望收益等于各资产期望收益的加权平均。

#### 2.2.2 投资组合的方差公式
$$ Var(r_p) = \sum w_i^2 Var(r_i) + \sum w_i w_j Cov(r_i, r_j) $$
- 解释：投资组合的风险由各资产的风险及其相关性决定。

```python
import pandas as pd
import numpy as np

# 示例资产数据
assets = pd.DataFrame({
    '资产': ['股票', '债券', '黄金'],
    '权重': [0.6, 0.3, 0.1]
})

# 计算投资组合的期望收益
expected_return = np.sum(assets['权重'] * assets['权重'].apply(lambda w: w * np.mean([0.1, 0.05, 0.02])))
print(f"投资组合的期望收益为：{expected_return}")
```

#### 4.2.2 风险评估模块
```python
# 计算投资组合的方差
cov_matrix = np.array([[0.04, 0.02, 0.01],
                        [0.02, 0.03, 0.01],
                        [0.01, 0.01, 0.02]])

weights = np.array([0.6, 0.3, 0.1])

portfolio_variance = np.dot(weights.T, np.dot(cov_matrix, weights))
print(f"投资组合的方差为：{portfolio_variance}")
```
