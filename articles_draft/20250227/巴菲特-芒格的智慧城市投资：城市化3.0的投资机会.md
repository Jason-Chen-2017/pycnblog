# 第1章 巴菲特与芒格的投资理念

## 1.1 巴菲特的价值投资理论

### 1.1.1 价值投资的定义与核心原则
价值投资是一种以内在价值为导向的投资方法，强调以低于内在价值的价格买入优质资产。巴菲特的价值投资理论强调长期持有、关注企业基本面以及安全边际。

$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

### 1.1.2 巴菲特投资成功的关键因素
- **长期视角**：关注企业的长期盈利能力。
- **优质企业**：选择具有强大竞争优势的企业。
- **安全边际**：确保买入价格低于内在价值。

### 1.1.3 巴菲特投资理念的演变与应用
从早期的烟蒂股策略到后来的买入并持有优质企业的策略，巴菲特的投资理念随着市场变化不断优化。

### 4.1.1 投资评估模型

```python
import numpy as np
import pandas as pd

def calculate_intrinsic_value(cash_flows, discount_rate, period):
    return np.npv(discount_rate, cash_flows) / (1 + discount_rate)**period

# 示例数据
cash_flows = [100, 200, 300, 400]
discount_rate = 0.08
period = 3

iv = calculate_intrinsic_value(cash_flows, discount_rate, period)
print(f"内在价值：{iv:.2f}")
```

### 6.2.2 投资组合优化的实现
```python
import numpy as np
import scipy.optimize

def portfolio_optimization(returns, weights):
    n = len(returns)
    # 定义目标函数
    def objective(weights):
        return -np.sum(weights * returns @ weights.T)
    # 约束条件
    constraints = [
        {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
        {'type': 'ineq', 'fun': lambda w: w >= 0}
    ]
    result = scipy.optimize.minimize(objective, weights, constraints)
    return result.x

# 示例数据
returns = np.array([[0.1, 0.2], [0.15, 0.25]])
weights = np.array([0.5, 0.5])

optimal_weights = portfolio_optimization(returns, weights)
print(f"最优权重：{optimal_weights}")
```
