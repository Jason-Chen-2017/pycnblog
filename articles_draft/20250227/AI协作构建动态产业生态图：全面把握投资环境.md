#### 3.3 数学模型与公式
- 协同过滤的相似度计算公式：

$$ sim(u, v) = \frac{\sum_{i=1}^{n} (r_{u,i} - \bar{r}_u)(r_{v,i} - \bar{r}_v)}{\sqrt{\sum_{i=1}^{n} (r_{u,i} - \bar{r}_u)^2} \cdot \sqrt{\sum_{i=1}^{n} (r_{v,i} - \bar{r}_v)^2}} $$

- 其中，$\bar{r}_u$ 表示用户 $u$ 的平均评分。

#### 3.4 代码实现
- Python 实现基于用户的协同过滤算法：

```python
def compute_cosine_similarity(user_ratings, user_avg_ratings):
    similarity = {}
    for u in user_ratings:
        for v in user_ratings:
            if u == v:
                continue
            numerator = 0
            denominator_u = 0
            denominator_v = 0
            for i in range(len(user_ratings[u])):
                rating_u = user_ratings[u][i]
                rating_v = user_ratings[v][i]
                numerator += (rating_u - user_avg_ratings[u]) * (rating_v - user_avg_ratings[v])
                denominator_u += (rating_u - user_avg_ratings[u]) ** 2
                denominator_v += (rating_v - user_avg_ratings[v]) ** 2
            if denominator_u == 0 or denominator_v == 0:
                similarity[(u, v)] = 0.0
            else:
                similarity[(u, v)] = numerator / (math.sqrt(denominator_u) * math.sqrt(denominator_v))
    return similarity
```
