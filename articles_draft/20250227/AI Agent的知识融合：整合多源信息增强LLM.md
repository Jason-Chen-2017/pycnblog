## 第4章：知识融合的数学模型与公式

### 4.1 向量空间模型

#### 4.1.1 向量表示的公式
$$v_i = \sum_{j=1}^{n} w_{ij} \cdot x_j$$

其中，$v_i$ 表示第i个向量，$w_{ij}$ 是权重，$x_j$ 是输入特征。

#### 4.1.2 融合过程的公式
$$y = \sigma(W \cdot v + b)$$

其中，$\sigma$ 是sigmoid函数，$W$ 是权重矩阵，$b$ 是偏置。

### 4.2 概率图模型

#### 4.2.1 贝叶斯网络的公式
$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

其中，$P(A|B)$ 是在B条件下A发生的概率。

#### 4.2.2 在知识融合中的应用
通过概率图模型计算各数据源的可信度，进行加权融合。

import numpy as np

def attention(inputs, weights):
    # 计算注意力权重
    attention_weights = np.dot(inputs, weights)
    attention_weights = softmax(attention_weights)
    return attention_weights

def softmax(x):
    return np.exp(x) / np.sum(np.exp(x), axis=1, keepdims=True)

# 示例输入
inputs = np.random.randn(5, 3)
weights = np.random.randn(3, 2)

# 计算注意力权重
attention_weights = attention(inputs, weights)

print("Attention Weights:", attention_weights)
