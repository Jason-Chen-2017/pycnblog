## 第1章: 什么是周期性调整市盈率(CAPE)

### 1.1 市场估值的基本概念
#### 1.1.1 市盈率的定义与计算公式
市盈率（P/E Ratio）是衡量股票价值的重要指标，公式为：
$$ \text{市盈率} = \frac{\text{股价}}{\text{每股收益}} $$

#### 1.1.2 市盈率在投资分析中的作用
市盈率反映了市场对上市公司未来盈利能力的预期，常用于评估股票的估值水平。

#### 1.1.3 市盈率的局限性与改进方向
传统市盈率受短期经济波动影响较大，无法反映长期市场趋势，因此需要引入周期性调整。

### 1.2 周期性调整市盈率的提出背景
#### 1.2.1 罗伯特·希勒与现代金融学
罗伯特·希勒是耶鲁大学著名经济学家，专注于市场估值和行为金融学研究。

#### 1.2.2 经济周期波动对市盈率的影响
经济周期波动导致企业盈利不稳定，传统市盈率难以准确反映市场长期估值。

#### 1.2.3 市场估值指标的改进需求
希勒提出CAPE，通过调整历史收益数据，消除短期波动影响，提供更稳定的市场估值指标。

## 第2章: 周期性调整市盈率(CAPE)的定义与特点

### 2.1 周期性调整市盈率的定义
#### 2.1.1 市盈率的周期性调整方法
CAPE使用历史收益数据进行调整，公式为：
$$ \text{CAPE} = \frac{\text{股价}}{\text{平均历史收益}} $$

#### 2.1.2 周期性调整市盈率与传统市盈率的区别
- 传统市盈率基于最近一个会计年度的收益。
- CAPE基于长期历史平均收益，更能反映市场周期性波动。

### 2.2 周期性调整市盈率的核心特点
#### 2.2.1 考虑经济周期波动的特性
CAPE通过历史收益数据调整，反映市场在不同经济周期中的表现。

#### 2.2.2 适用于长期市场估值的特点
CAPE帮助投资者从长期视角分析市场估值，避免短期波动干扰。

#### 2.2.3 在不同市场环境下的表现差异
CAPE在牛市和熊市中的表现不同，可用于判断市场拐点。

## 第3章: 周期性调整市盈率的数学模型与公式

### 3.1 市盈率的基本公式
$$ \text{市盈率} = \frac{\text{股价}}{\text{每股收益}} $$

### 3.2 周期性调整市盈率的扩展公式
$$ \text{CAPE} = \frac{\text{股价}}{\text{平均历史收益}} $$

### 3.3 历史收益的计算方法
#### 3.3.1 简单平均法
$$ \text{简单平均收益} = \frac{\sum_{i=1}^{n} \text{收益}_i}{n} $$

#### 3.3.2 加权平均法
$$ \text{加权平均收益} = \frac{\sum_{i=1}^{n} w_i \cdot \text{收益}_i}{\sum_{i=1}^{n} w_i} $$

#### 3.3.3 趋势调整法
使用回归模型对历史收益进行趋势调整。

### 7.2 CAPE计算的Python实现
#### 7.2.1 数据预处理代码

```python
import pandas as pd
import requests

# 获取标普500指数的历史数据
url = 'https://query1.finance.yahoo.com/d/quotes.csv?s=^GSPC&period1=...'
data = pd.read_csv(url)
data['Date'] = pd.to_datetime(data['Date'])
data.set_index('Date', inplace=True)
```

#### 7.2.2 CAPE计算代码
```python
def calculate_cape(data, window=10):
    historical_earnings = data['Earnings'].rolling(window).mean()
    cape = data['Price'] / historical_earnings
    return cape

cape_values = calculate_cape(data)
```

#### 7.2.3 数据可视化代码
```python
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 6))
plt.plot(cape_values, label='CAPE')
plt.xlabel('Date')
plt.ylabel('CAPE Value')
plt.legend()
plt.show()
```
