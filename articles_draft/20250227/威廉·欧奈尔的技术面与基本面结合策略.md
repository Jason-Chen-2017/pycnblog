### 第一部分：背景介绍

#### 第1章：技术分析与基本面分析

##### 1.1 技术分析基础
- **技术分析的定义**：通过研究历史价格数据来预测未来走势的方法。
- **技术分析的特点**：侧重价格形态、趋势线、技术指标等。
- **技术分析与基本面分析的对比**：技术分析更注重市场情绪和趋势，而基本面分析关注公司的财务状况和行业地位。

##### 1.2 基本面分析基础
- **基本面分析的定义**：通过研究公司财务报表、行业地位等基本面因素来评估股票价值。
- **基本面分析的特点**：关注公司的盈利能力、成长性等内在价值。
- **技术分析与基本面分析的优缺点对比表**

| 对比维度         | 技术分析                     | 基本面分析                   |
|------------------|------------------------------|------------------------------|
| 适用周期         | 短期到中期                   | 长期                         |
| 数据来源         | 历史价格数据                 | 财务报表、行业数据           |
| 优势             | 灵敏捕捉短期趋势             | 提供长期投资价值判断         |
| 局限             | 易受市场情绪影响             | 数据滞后，难以捕捉短期变化   |

##### 1.3 技术面与基本面结合的意义
- 结合两者可弥补单一分析的不足，提供更全面的投资决策依据。
- 技术面分析帮助识别入场时机，基本面分析确认投资标的的价值。

##### 5.2 核心代码实现

```python
import pandas as pd
import yfinance as yf
import matplotlib.pyplot as plt

# 下载数据
data = yf.download('AAPL', start='2020-01-01', end='2023-12-31')

# 计算RSI
def calculate_rsi(data, period=14):
    delta = data['Close'].diff().dropna()
    up = delta.where(delta > 0, 0)
    down = delta.where(delta < 0, 0)
    rs = up.rolling(period).mean() / down.rolling(period).mean()
    rsi = 100 - (100 - rs.rolling(period).mean().fillna(0))
    return rsi

data['RSI'] = calculate_rsi(data)

# 计算MACD
def calculate_macd(data, fast_period=12, slow_period=26):
    ema_fast = data['Close'].ewm(span=fast_period, adjust=False).mean()
    ema_slow = data['Close'].ewm(span=slow_period, adjust=False).mean()
    macd = ema_fast - ema_slow
    return macd

data['MACD'] = calculate_macd(data)

# 绘制图表
plt.figure(figsize=(12, 6))
plt.subplot(3, 1, 1)
data['Close'].plot(title='AAPL Close Price')
plt.subplot(3, 1, 2)
data['RSI'].plot(title='RSI')
plt.subplot(3, 1, 3)
data['MACD'].plot(title='MACD')
plt.show()
```
