## 第3章：格雷厄姆企业价值评估的数学模型与公式

### 3.1 内在价值的计算公式
- 现金流量折现模型：
$$ V = \frac{CF_1}{(1+r)^1} + \frac{CF_2}{(1+r)^2} + \dots + \frac{CF_n}{(1+r)^n} $$
其中，\( V \) 是内在价值，\( CF \) 是未来现金流，\( r \) 是折现率。

- 股权自由现金流模型：
$$ FCFF = EBIT(1 - t) + Depreciation - Capital Expenditure $$
其中，\( FCFF \) 是股权自由现金流，\( EBIT \) 是息税前利润，\( t \) 是税率，\( Depreciation \) 是折旧，\( Capital Expenditure \) 是资本支出。

### 3.2 安全边际的数学模型
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$
如果安全边际为正，说明企业价值被市场低估，值得投资。

### 3.3 财务指标的数学模型
- 市盈率：
$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
- 市净率：
$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(enterprise_value, free_cash_flow, discount_rate):
    # 计算股权自由现金流
    fcff = enterprise_value - free_cash_flow
    # 现金流量折现模型
    intrinsic_value = 0
    for i in range(len(fcff)):
        intrinsic_value += fcff[i] / (1 + discount_rate) ** i
    return intrinsic_value

# 示例数据
enterprise_value = 1000000
free_cash_flow = [100000, 120000, 150000]
discount_rate = 0.1

# 计算内在价值
intrinsic_value = calculate_intrinsic_value(enterprise_value, free_cash_flow, discount_rate)
print("内在价值：", intrinsic_value)

# 计算安全边际
market_price = 500000
safety_margin = intrinsic_value - market_price
print("安全边际：", safety_margin)
```

- **安全边际分析**：比较内在价值与市场价格，确定投资的安全性。
