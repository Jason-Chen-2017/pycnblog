## 第1章：股息价值投资概述  

### 1.1 股息价值投资的定义与背景  
股息价值投资是一种以股息率为核心指标，结合公司基本面分析的投资策略。它起源于价值投资理念，但更注重股息的可持续性和增长潜力。乔尔·格林布拉特是该领域的代表性人物，他提出了一种通过股息率和股息增长的平衡来寻找优质投资标的的方法。  

#### 1.1.1 股息价值投资的核心目标  
- 实现稳健的股息收入，降低投资组合的波动性。  
- 通过股息增长实现长期资本增值。  

#### 1.1.2 股息价值投资与传统价值投资的区别  
- 传统价值投资更关注低市盈率和低市净率的股票，而股息价值投资更关注高股息率和股息增长潜力的股票。  
- 股息价值投资强调股息的可持续性，而传统价值投资更关注价格与内在价值的差距。  

### 1.2 股息价值投资的核心理念  
- **安全边际**：选择股息率高且股息增长稳定的公司，确保投资的安全性。  
- **收益与增长的平衡**：在追求高股息收益的同时，关注公司的盈利能力和成长潜力。

## 第2章：股息价值投资的核心概念  

### 2.1 股息率的定义与计算  
股息率是衡量股票股息收入与股票价格之比的重要指标，公式为：  
$$ \text{股息率} = \frac{\text{每股股息}}{\text{股价}} $$  

#### 2.1.1 影响股息率的因素  
- 公司的盈利能力：净利润高，才能支持较高的股息率。  
- 行业特性：公用事业、金融等行业的股息率通常较高。  
- 市场利率：市场利率上升时，股息率相对较低的股票可能面临抛售压力。  

### 2.2 股息增长的驱动因素  
股息增长主要由公司的盈利能力、现金流和股息政策决定。  

#### 2.2.1 股息增长率模型  
- **零增长模型**：假设股息增长率恒为零，适用于成熟但无增长潜力的公司。  
- **不变增长模型**：假设股息增长率恒定，适用于稳定增长的公司。  
- **可变增长模型**：股息增长率随时间变化，适用于快速增长的公司。  

### 2.3 股息率与股息增长的平衡  
- 高股息率但无增长的公司可能面临股息削减的风险。  
- 低股息率但高增长的公司可能在长期实现更高的收益。

## 第3章：股息折现模型（DDM）  

### 3.1 DDM的基本原理  
股息折现模型通过将未来股息的现值之和作为股票的内在价值。公式为：  
$$ V = \frac{D_1}{k - g} $$  
其中，\( D_1 \) 是第一年的股息，\( k \) 是折现率，\( g \) 是股息增长率。  

#### 3.1.1 DDM的适用场景  
- 公司股息稳定且可预测。  
- 股息增长率恒定或可变。  

### 3.2 股息增长率模型的对比  
- **零增长模型**：适用于股息无增长的公司。  
- **不变增长模型**：适用于股息稳定增长的公司。  
- **可变增长模型**：适用于股息增长率变化的公司。  

#### 3.2.1 示例：使用DDM计算股票价值  
假设某公司当前股息为$2，股息增长率 \( g = 5\% \)，折现率 \( k = 10\% \)。股票的内在价值为：  
$$ V = \frac{2 \times (1 + 0.05)}{0.10 - 0.05} = \frac{2.1}{0.05} = 42 $$

### 5.2 核心代码实现

```python
import pandas as pd

# 示例：计算股息率和股息增长率
def calculate_dividend_yield(price, dividend):
    return dividend / price

def calculate_growth_rate(prev_dividend, current_dividend):
    return (current_dividend - prev_dividend) / prev_dividend

# 示例数据
data = {
    '公司': ['A', 'B', 'C'],
    '股价': [50, 60, 70],
    '股息': [2, 3, 3.5]
}

df = pd.DataFrame(data)

# 计算股息率
df['股息率'] = df.apply(lambda x: calculate_dividend_yield(x['股价'], x['股息']), axis=1)

# 计算股息增长率
df['股息增长率'] = df['股息'].pct_change()

print(df)
```
