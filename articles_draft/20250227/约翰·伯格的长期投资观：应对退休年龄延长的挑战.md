## 第三部分：算法原理讲解

### 第3章：投资组合优化的数学模型

#### 3.1 现代投资组合理论（MPT）
现代投资组合理论由哈里·马科维茨提出，是长期投资观的重要理论基础。其核心思想是通过分散投资来降低风险。

#### 3.2 数学公式
以下是投资组合优化的数学模型：

$$
\text{最大化 } \mu_p \quad \text{在约束} \quad \sigma_p \leq \text{目标风险}
$$

其中：
- $\mu_p$ 是投资组合的预期收益
- $\sigma_p$ 是投资组合的风险

#### 3.3 Python代码实现
以下是投资组合优化的Python代码示例：

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

# 示例数据
returns = pd.DataFrame({
    '资产A': [0.1, 0.05, 0.07],
    '资产B': [0.08, 0.06, 0.04]
})

# 定义优化目标函数
def portfolio_var(weights, returns):
    return np.var(returns.dot(weights))

# 定义约束条件
cons = ({'type': 'eq', 'fun': lambda w: sum(w) - 1})

# 初始化权重
initial_guess = [0.5, 0.5]

# 使用scipy.optimize.minimize进行优化
result = minimize(portfolio_var, initial_guess, args=(returns,), constraints=cons)

# 输出结果
print("最优权重：", result.x)
print("最小方差：", result.fun)
```

#### 3.4 代码解读
上述代码通过优化投资组合的权重，实现风险最小化的目标。这正是长期投资观的核心思想，即通过分散投资来降低整体风险。

## 第五部分：项目实战

### 第5章：长期投资系统实现

#### 5.1 环境安装
需要安装Python和相关库（如numpy、pandas、scipy）。

#### 5.2 核心代码实现
以下是投资组合优化的核心代码：

```python
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def objective(weights, returns):
    return -np.mean(returns.dot(weights))  # 最小化收益的负值，即最大化收益

# 定义约束条件
cons = ({'type': 'eq', 'fun': lambda w: sum(w) - 1})

# 初始化权重
initial_guess = np.array([0.5, 0.5])

# 优化过程
result = minimize(objective, initial_guess, args=(returns,), constraints=cons)

# 输出结果
print("最优权重：", result.x)
print("最优收益：", -result.fun)
```

#### 5.3 代码解读
上述代码通过优化权重，实现收益最大化的目标。这正是长期投资观的核心思想，即通过优化资产配置实现稳健收益。
