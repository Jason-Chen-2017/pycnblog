# 第2章: 财务报表分析的基础知识

## 2.1 财务报表的基本结构与内容

### 2.1.1 资产负债表
- **定义**：资产负债表反映企业在某一特定日期的资产、负债和所有者权益的状况。
- **结构**：
  - 资产：企业拥有的资源，包括流动资产、非流动资产。
  - 负债：企业承担的债务，包括流动负债、非流动负债。
  - 所有者权益：企业资产减去负债后的剩余部分。

### 2.1.2 利润表
- **定义**：利润表反映企业在一定会计期间的收入、费用和利润情况。
- **结构**：
  - 收入：企业销售商品或提供服务所获得的收入。
  - 费用：企业为获得收入所发生的各项支出。
  - 利润：收入减去费用后的净收益。

### 2.1.3 现金流量表
- **定义**：现金流量表反映企业在一定会计期间现金和现金等价物的流入和流出情况。
- **结构**：
  - 经营活动现金流：企业日常经营活动中产生的现金流。
  - 投资活动现金流：企业投资活动产生的现金流。
  - 筹资活动现金流：企业筹资活动产生的现金流。

## 2.2 财务报表分析的核心指标

### 2.2.1 盈利能力分析
- **指标**：
  - 净利润率（Net Profit Margin）：净利润与收入的比率。
  - 营业利润率（Operating Profit Margin）：营业利润与收入的比率。
  - 净资产收益率（ROE）：净利润与所有者权益的比率。

### 2.2.2 偿债能力分析
- **指标**：
  - 负债率（Debt Ratio）：总负债与总资产的比率。
  - 速动比率（Quick Ratio）：速动资产与流动负债的比率。

### 2.2.3 运营能力分析
- **指标**：
  - 存货周转率（Inventory Turnover）：存货周转次数。
  - 资产周转率（Asset Turnover）：销售收入与平均资产的比率。

## 2.3 财务报表分析的基本方法

### 2.3.1 横向比较法
- **定义**：将同一时期内不同企业之间的财务数据进行比较，分析企业的相对表现。
- **应用**：比较不同企业的盈利能力、偿债能力和运营能力。

### 2.3.2 纵向比较法
- **定义**：将同一企业不同期间的财务数据进行比较，分析企业的变化趋势。
- **应用**：分析企业的盈利能力、偿债能力和运营能力的变化趋势。

### 2.3.3 趋势分析法
- **定义**：通过分析企业财务数据的变化趋势，预测未来的发展方向。
- **应用**：分析企业的销售收入、利润、现金流等指标的变化趋势。

# 第3章: 巴菲特的财务报表分析方法

## 3.1 巴菲特的财务报表分析框架

### 3.1.1 股东权益回报率（ROE）分析
- **定义**：ROE = 净利润 / 所有者权益。
- **意义**：ROE反映了企业使用股东资金的效率，ROE越高，企业的盈利能力越强。

### 3.1.2 资产回报率（ROA）分析
- **定义**：ROA = 净利润 / 总资产。
- **意义**：ROA反映了企业资产的使用效率，ROA越高，企业的资产利用效率越高。

### 3.1.3 投资资本回报率（ROIC）分析
- **定义**：ROIC = 净利润 / 投资资本。
- **意义**：ROIC反映了企业投资资本的回报率，ROIC越高，企业的投资回报率越高。

## 3.2 巴菲特对财务报表的关注点

### 3.2.1 盈利能力分析
- **关注点**：
  - 净利润是否稳定增长。
  - 营业利润率是否高于行业平均水平。
  - 净资产收益率是否高于行业平均水平。

### 3.2.2 偿债能力分析
- **关注点**：
  - 负债率是否低于行业平均水平。
  - 速动比率是否高于行业平均水平。
  - 现金流量是否充足。

### 3.2.3 现金流分析
- **关注点**：
  - 经营活动现金流是否为正。
  - 投资活动现金流是否合理。
  - 筹资活动现金流是否可控。
