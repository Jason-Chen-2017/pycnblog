### **1. 排序算法**

排序算法是面试中常见的问题，包括冒泡排序、选择排序、插入排序、快速排序等。以下是冒泡排序的伪代码：

```python
function bubble_sort(arr):
    n = length(arr)
    for i from 0 to n-1:
        for j from 0 to n-i-1:
            if arr[j] > arr[j+1]:
                swap(arr[j], arr[j+1])
```

### **2. 查找算法**

查找算法包括二分查找、顺序查找等。以下是二分查找的伪代码：

```python
function binary_search(arr, target):
    low = 0
    high = length(arr) - 1
    while low <= high:
        mid = (low + high) / 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

### **3. 遍历算法**

遍历算法用于遍历树和图等数据结构，常见的有深度优先搜索（DFS）和广度优先搜索（BFS）。以下是DFS的伪代码：

```python
function dfs(node):
    if node is null:
        return
    visit(node)
    for each child of node:
        dfs(child)
```

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

# 测试
```
