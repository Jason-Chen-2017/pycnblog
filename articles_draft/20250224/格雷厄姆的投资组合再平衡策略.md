### 第一部分：引言

#### 1.1 投资组合再平衡概述

##### 1.1.1 投资组合的定义
投资组合是投资者持有的多种资产（如股票、债券、基金等）的集合，旨在分散风险并实现收益最大化。通过合理配置资产，投资者可以在不同市场条件下平衡风险与收益。

##### 1.1.2 投资组合的重要性
投资组合的重要性体现在其分散风险的能力。单一资产的风险较高，而多样化投资可以有效降低整体风险，同时提高收益的稳定性。

##### 1.1.3 再平衡的概念与作用
再平衡是指定期调整投资组合，以维持预定的资产配置比例。其作用包括优化风险收益比、应对市场变化、保持投资策略一致性。

### 第二部分：格雷厄姆投资理念

#### 2.1 格雷厄姆的价值投资理论

##### 2.1.1 价值投资的核心思想
格雷厄姆强调以低于内在价值的价格购买资产，长期持有，通过安全边际（资产价格与内在价值的差距）来降低风险。

##### 2.1.2 安全边际的概念
安全边际是投资中保护投资者免受市场波动影响的缓冲区，确保以合理价格购买资产，避免过度支付。

##### 2.1.3 长期投资的重要性
格雷厄姆主张长期持有优质资产，避免频繁交易，降低交易成本和税务负担，实现复利效应。

### 第四部分：再平衡策略的核心内容

#### 4.1 再平衡的必要性

##### 4.1.1 市场变化的影响
市场波动导致资产比例偏离预期，需调整以维持目标配置。

##### 4.1.2 投资目标的变化
如风险偏好、收益目标的变化，需调整资产配置。

##### 4.1.3 风险偏好的调整
根据市场环境和个人情况，动态调整风险承受能力。

#### 4.2 再平衡的时机与频率

##### 4.2.1 定期再平衡
定期（如每年或每季度）调整，保持资产配置不变。

##### 4.2.2 事件驱动的再平衡
市场剧烈波动或重大事件后，及时调整。

#### 4.3 再平衡的步骤

##### 4.3.1 确定目标配置比例
根据投资目标和风险偏好设定各资产的比例。

##### 4.3.2 计算当前比例偏差
比较当前实际比例与目标比例，找出偏差。

##### 4.3.3 调整资产头寸
通过买卖资产，调整至目标比例，最小化偏差。

##### 5.1.1 问题场景

##### 5.1.2 算法步骤
1. 计算各资产偏离目标比例的部分。
2. 卖出或买入资产，调整至目标比例。
3. 记录调整后的组合情况。

##### 5.1.4 Python代码实现
```python
def calculate_weights(current_weights, target_weights):
    # 计算各资产的偏差
    deviations = {asset: target - current for asset, target in target_weights.items()}
    # 计算需要调整的金额
    adjustments = {}
    for asset in target_weights:
        current = current_weights.get(asset, 0)
        target = target_weights[asset]
        if current < target:
            adjustments[asset] = target - current
        else:
            adjustments[asset] = -(current - target)
    return adjustments

# 示例
current_weights = {'股票': 70, '债券': 20, '现金': 10}
target_weights = {'股票': 60, '债券': 30, '现金': 10}
adjustments = calculate_weights(current_weights, target_weights)
print(adjustments)
```

##### 5.1.5 数学模型
目标是调整投资组合，使各资产权重等于目标权重。数学模型如下：
$$ w_i' = w_i + \Delta w_i $$
其中，$$w_i$$是当前权重，$$\Delta w_i$$是调整量，确保$$\sum w_i' = 1$$。

import pandas as pd

def rebalance_portfolio(current_weights, target_weights):
    # 计算偏差
    deviations = {asset: target_weights[asset] - current_weights[asset] for asset in target_weights}
    # 调整头寸
    adjusted_weights = {}
    for asset in target_weights:
        current = current_weights.get(asset, 0)
        target = target_weights[asset]
        deviation = target - current
        if deviation > 0:
            adjusted_weights[asset] = current + deviation
        else:
            adjusted_weights[asset] = current + deviation
    return adjusted_weights

# 示例
current_weights = {'股票': 70, '债券': 20, '现金': 10}
target_weights = {'股票': 60, '债券': 30, '现金': 10}
adjusted_weights = rebalance_portfolio(current_weights, target_weights)
print(adjusted_weights)
