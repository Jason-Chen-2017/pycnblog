## 第二章：背景介绍

### 2.1 长期市场回报预期的定义

长期市场回报预期是指投资者对未来市场回报的预测。本文分析了约翰·伯格理论中的乐观与现实视角。

### 2.2 理论基础

约翰·伯格的理论基于市场均衡和投资者行为分析，提出了预期回报的计算方法。

### 2.3 核心概念的属性

- 乐观视角：高回报，低风险。
- 现实视角：回报与风险并存。

```python
import numpy as np
import pandas as pd

def calculate_expected_return(prices):
    returns = prices.pct_change().dropna()
    expected_return = returns.mean()
    return expected_return

prices = pd.read_csv('market_data.csv')
print(calculate_expected_return(prices))
```
