# 第1章: 约翰·伯格与价值投资概述

## 1.1 价值投资的起源与核心理念

### 1.1.1 价值投资的定义与核心要素
价值投资是一种以基本面分析为基础的投资策略，旨在通过识别市场价格低于其内在价值的资产来获取长期收益。其核心要素包括：
- **内在价值**：资产在合理市场条件下的公平价格。
- **安全边际**：市场价格与内在价值之间的差距，作为投资的安全垫。
- **长期视角**：关注企业的长期盈利能力，而非短期市场波动。

### 1.1.2 约翰·伯格的投资哲学
伯格认为，投资的本质是寻找那些具有持续竞争优势且管理良好的企业。他强调：
- **分散投资**：通过广泛分散投资降低风险。
- **低成本投资**：通过指数基金降低管理费用。
- **长期持有**：避免频繁交易，减少交易成本。

### 1.1.3 价值投资与短期投资的对比
| 对比维度 | 价值投资 | 短期投资 |
|----------|-----------|----------|
| 时间框架 | 长期      | 短期     |
| 风险管理 | 强调安全边际 | 风险敞口较大 |
| 成本控制 | 低成本     | 高交易成本 |

## 1.2 约翰·伯格的生平与投资历程

### 1.2.1 约翰·伯格的早期职业生涯
伯格于1949年加入费城国民银行，随后进入宾夕法尼亚大学沃顿商学院学习，奠定其在金融领域的基础。

### 1.2.2 伯格与Vanguard集团的创立
1974年，伯格创立了Vanguard集团，专注于低成本指数基金，成为现代指数投资的先驱。

### 1.2.3 伯格的投资理念演变
伯格的理念从早期的个股精选转向指数投资，强调通过分散化降低风险。

## 1.3 价值投资的核心原则

### 1.3.1 购买便宜的资产
伯格强调购买市场价格低于内在价值的资产，寻找市场先生的错误定价。

### 1.3.2 长期持有优质资产
伯格倡导长期持有优质资产，避免频繁交易，降低交易成本和税务负担。

### 1.3.3 风险管理与分散投资
通过分散投资降低风险，避免将所有资金投入单一资产或行业。

# 第2章: 价值投资的核心模型与数学分析

## 2.1 约翰·伯格的数学模型基础

### 2.1.1 投资决策的数学模型
价值投资依赖于数学模型，尤其是现金流折现模型（DCF）。

## 2.2 现金流折现模型（DCF）

### 2.2.1 DCF模型的定义与公式
DCF模型通过预测未来现金流并折现至现值，评估资产的内在价值。

公式：
$$
\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}}{(1 + r)^t}
$$
其中，$r$ 是折现率。

### 2.2.2 约翰·伯格对DCF模型的改进
伯格强调使用保守的假设和合理的折现率，避免过度乐观的预期。

### 2.2.3 DCF模型的优缺点分析
| 优点 | 缺点 |
|------|------|
| 精确评估内在价值 | 需要假设未来现金流 |
| 考虑时间价值 | 对模型假设敏感 |

### 2.2.4 现实中的DCF模型应用
伯格通过DCF模型评估企业的未来现金流，判断其市场价格是否低估。

## 2.3 投资决策中的数学模型

### 2.3.1 内部收益率（IRR）
IRR是DCF模型中的关键指标，用于评估项目的回报率。

公式：
$$
\text{IRR} = r \text{ 满足 } \sum_{t=1}^{n} \frac{\text{现金流}}{(1 + r)^t} = 0
$$

### 2.3.2 现金流折现模型的实现
使用Python代码实现DCF模型：

```python
def discounted_cash_flows(cash_flows, discount_rate):
    return sum(cf / (1 + discount_rate)**t for t, cf in enumerate(cash_flows))

cash_flows = [100, 200, 300]
discount_rate = 0.08
intrinsic_value = discounted_cash_flows(cash_flows, discount_rate)
print(f"内在价值：{intrinsic_value}")
```
