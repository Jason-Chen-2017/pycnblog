## 第一部分: 价值投资与魔术公式概述

### 第1章: 价值投资的背景与发展

#### 1.1 价值投资的起源与发展
价值投资是一种以基本面分析为基础的投资策略，起源于20世纪初。本杰明·格雷厄姆和戴维·多德是这一投资理念的奠基人。他们主张以低于内在价值的价格购买优质股票，长期持有，从而实现稳定的收益。

#### 1.2 乔尔·格林布拉特的背景与成就
乔尔·格林布拉特是美国著名的投资专家，以其独特的投资策略闻名。他是费米尼亚资本管理公司的创始人，曾出版《股票作手回忆录》等经典著作。格林布拉特的投资理念结合了基本面分析和量化模型，极大地简化了传统价值投资的复杂性。

#### 1.3 魔术公式的提出与意义
魔术公式是一种简化版的价值投资策略，旨在快速筛选出具有投资价值的股票。其核心在于通过简单的数学模型，评估企业的盈利能力、资本回报率和估值水平。这种方法不仅降低了投资门槛，还提高了筛选效率，适用于个人投资者和机构投资者。

## 第二部分: 魔术公式的原理与核心概念

### 第2章: 魔术公式的核心要素

#### 2.1 魔术公式的数学模型
魔术公式的计算公式为：
$$
\text{Magic Formula Value} = \frac{E}{V} \times \left( \frac{ROE \times ROIC}{2} \right)
$$

其中：
- \( E \) 是企业的账面价值
- \( V \) 是企业的市场价值
- \( ROE \) 是净资产收益率
- \( ROIC \) 是投入资本回报率

#### 2.2 核心指标的解析
- **ROE（净资产收益率）**：衡量企业盈利能力的重要指标，公式为：
  $$
  ROE = \frac{\text{净利润}}{\text{平均股东权益}}
  $$
- **ROIC（投入资本回报率）**：衡量企业资本使用效率的指标，公式为：
  $$
  ROIC = \frac{\text{息税前利润}}{\text{投入资本}}
  $$
- **E/V比值**：衡量企业估值水平的指标，E代表企业价值，V代表市场价值。

#### 2.3 魔术公式与传统价值投资的对比
| 对比维度 | 魔术公式 | 传统价值投资 |
|----------|----------|--------------|
| **指标选择** | ROE、ROIC、E/V | P/E、P/B、股息率等 |
| **计算复杂度** | 简单易行 | 复杂，需深入分析 |
| **适用场景** | 快速筛选 | 精准评估 |

#### 3.2 算法的数学模型
魔术公式的得分计算公式为：
$$
\text{综合得分} = \frac{ROE + ROIC}{2} \times \frac{E}{V}
$$

#### 3.3 算法的实现与应用
```python
def calculate_magic_formula(stock_data):
    roe = stock_data['net_profit'] / stock_data['average_equity']
    roic = stock_data['ebit'] / stock_data['total_capital']
    e_v = stock_data['enterprise_value'] / stock_data['market_value']
    score = (roe + roic) / 2 * e_v
    return score
```

import pandas as pd

def calculate_magic_formula(stock_data):
    roe = stock_data['net_profit'] / stock_data['average_equity']
    roic = stock_data['ebit'] / stock_data['total_capital']
    e_v = stock_data['enterprise_value'] / stock_data['market_value']

    return score

# 示例数据
data = {
    'net_profit': [100, 200, 300],
    'average_equity': [500, 600, 700],
    'ebit': [150, 250, 350],
    'total_capital': [800, 900, 1000],
    'enterprise_value': [1200, 1300, 1400],
    'market_value': [1000, 1100, 1200]

df = pd.DataFrame(data)
scores = df.apply(lambda x: calculate_magic_formula(x), axis=1)
print(scores)
