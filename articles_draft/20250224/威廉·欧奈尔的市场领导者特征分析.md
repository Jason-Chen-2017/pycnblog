## 第2章: 市场领导者特征的核心概念与联系

### 2.1 核心概念的原理分析
相对强度（RS）是衡量股票表现的重要指标，计算方法为股票价格与市场平均价格的比率。RS越高，股票的表现越优于市场。

### 2.2 核心概念的属性特征对比表
下表展示了相对强度、资金流动和趋势信号的主要属性对比：

| 特征     | 描述                              | 重要性 |
|----------|-----------------------------------|--------|
| 相对强度  | 衡量股票相对于市场的表现          | 高     |
| 资金流动  | 衡量资金在市场中的流动情况        | 中     |
| 趋势信号  | 衡量市场的趋势方向                | 高     |

### 3.2 算法实现的Python代码
```python
def calculate_relative_strength(data):
    return data['收盘价'] / data['均价']

def generate_trend_signal(rs):
    if rs > 1.2:
        return '买入'
    elif rs < 0.8:
        return '卖出'
    else:
        return '观望'
```

### 3.3 数学模型与公式
相对强度指数公式：
$$
RSI = \frac{\sum_{i=1}^{n} \text{上涨幅度}}{\sum_{i=1}^{n} \text{下跌幅度}}
$$

趋势信号生成条件：
$$
\text{如果 } RSI > 70 \Rightarrow \text{卖出信号}
$$
$$
\text{如果 } RSI < 30 \Rightarrow \text{买入信号}
$$
