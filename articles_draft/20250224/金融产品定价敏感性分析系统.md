## 第2章：敏感性分析的核心概念与联系

### 2.1 敏感性分析的原理与方法
- **线性回归**：通过回归分析确定各变量对价格的影响程度。
- **蒙特卡洛模拟**：通过随机模拟方法评估价格波动。

### 2.2 各种分析方法的对比分析
| 方法        | 优点                     | 缺点                     |
|-------------|--------------------------|--------------------------|
| 线性回归     | 简单，易于解释            | 仅适用于线性关系          |
| 蒙特卡洛模拟 | 考虑多种变量组合影响       | 计算复杂，耗时           |

### 3.1 算法概述
- **线性回归模型**：用于评估各变量对价格的影响程度。
- **方差分解方法**：用于确定各变量对价格波动的贡献比例。

### 3.3 算法实现
#### 线性回归模型公式
$$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon $$
#### 方差分解公式
$$ V(y) = \sum_{i=1}^n V(x_i) \cdot \beta_i^2 $$

### 5.2 核心代码实现
```python
import numpy as np
import pandas as pd

# 示例数据
data = pd.DataFrame({
    '利率': [1, 2, 3, 4, 5],
    '汇率': [1.1, 1.2, 1.3, 1.4, 1.5],
    '价格': [100, 90, 80, 70, 60]
})

# 线性回归模型
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(data[['利率', '汇率']], data['价格'])

# 输出系数
print('回归系数:', model.coef_)
```
