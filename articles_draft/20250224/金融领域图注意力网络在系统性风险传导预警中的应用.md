## 第1章 系统性风险与图注意力网络概述

### 1.1 系统性风险的基本概念

#### 1.1.1 系统性风险的定义与特征
系统性风险是指由于金融体系中的某个或某些关键节点出现问题，导致整个金融系统发生连锁反应，进而引发大规模金融动荡的风险。其主要特征包括：
- **系统性**：影响范围广泛，波及整个金融体系。
- **传染性**：风险在金融机构之间快速传播。
- **不可预测性**：由于复杂性，系统性风险难以准确预测。

#### 1.1.2 系统性风险的传播机制
系统性风险的传播通常通过金融机构之间的关联性进行扩散，例如：
- **直接传染**：一家金融机构出现问题，直接影响与其有业务往来的其他机构。
- **间接传染**：通过市场、资金链或投资者信心等因素间接影响其他机构。

#### 1.1.3 系统性风险对金融市场的危害
系统性风险可能导致金融市场崩溃、金融机构破产、经济衰退等问题，给全球经济带来严重后果。

---

### 1.2 图注意力网络的核心概念

#### 1.2.1 图注意力网络的定义
图注意力网络（Graph Attention Network, GAT）是一种结合图结构和注意力机制的深度学习模型，能够有效捕捉图中节点之间的关系和权重。

#### 1.2.2 图注意力网络与传统图模型的对比
| 特性           | 传统图模型（如GCN）       | 图注意力网络（GAT）           |
|----------------|--------------------------|-----------------------------|
| 权重分配方式     | 均匀分配                 | 动态分配，基于注意力机制     |
| 节点关系处理     | 稳定但缺乏灵活性         | 更灵活，可捕捉重要节点关系   |
| 复杂性           | 较低                     | 较高                        |

#### 1.2.3 图注意力网络在金融领域的应用潜力
- **风险传播路径识别**：通过图注意力网络，可以识别系统性风险在金融机构之间的传播路径。
- **风险传导概率预测**：利用注意力机制，预测特定机构的风险传导概率。
- **实时风险监控**：基于动态图结构，实现对金融市场的实时监控。

## 第2章 图注意力网络的原理

### 2.1 图注意力网络的基本结构

#### 2.1.1 图的表示方法
图通常由节点（顶点）和边组成，表示为：
$$ G = (V, E) $$
其中，$V$ 是节点集合，$E$ 是边的集合。

#### 2.1.2 注意力机制的引入
注意力机制通过计算节点之间的注意力权重，确定每个节点对其他节点的影响程度。注意力权重计算公式为：
$$ \alpha_{ij} = \frac{\exp(e_i^T W e_j)}{\sum_{k} \exp(e_i^T W e_k)} $$
其中，$e_i$ 和 $e_j$ 是节点 $i$ 和 $j$ 的嵌入向量，$W$ 是参数矩阵。

#### 2.1.3 图注意力网络的数学模型
图注意力网络的输出表示为：
$$ h_i^{(l+1)} = \sum_{j} \alpha_{ij} h_j^{(l)} $$
其中，$h_i^{(l)}$ 是节点 $i$ 在第 $l$ 层的表示，$\alpha_{ij}$ 是注意力权重。

#### 5.2.2 注意力机制的实现
```python
import torch

def attention(query, key, value, mask=None):
    scores = torch.matmul(query, key.T)  # 计算注意力分数
    if mask is not None:
        scores = scores * mask
    attention_weights = torch.softmax(scores, dim=-1)
    output = torch.matmul(attention_weights, value)
    return output, attention_weights
```

#### 5.2.3 系统性风险预警模型的训练与测试
```python
import torch
import torch.nn as nn

class GAT(nn.Module):
    def __init__(self, input_dim, hidden_dim):
        super(GAT, self).__init__()
        self.attention = nn.MultiheadAttention(input_dim, 8, batch_first=True)
        self.fc = nn.Linear(hidden_dim, 1)
    
    def forward(self, x, edge_index):
        out, _ = self.attention(x, x, x)  # 使用注意力层
        out = self.fc(out.mean(dim=1))  # 输出风险概率
        return out

model = GAT(input_dim=10, hidden_dim=64)
criterion = nn.BCELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```
