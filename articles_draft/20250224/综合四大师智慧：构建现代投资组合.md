## 第一部分：投资组合理论的背景与基础

### 第1章：投资组合理论概述

#### 1.1 投资组合理论的历史与发展

- **1.1.1 投资组合理论的起源**  
  投资组合理论起源于20世纪中期，最早的理论由哈里·马科维茨（Harry Markowitz）提出，他被认为是现代投资组合理论（MPT）之父。

- **1.1.2 现代投资组合理论的形成**  
  马科维茨的均值-方差模型为投资组合优化奠定了基础，随后夏普（William Sharpe）提出了夏普比率和资本资产定价模型（CAPM），APT模型（Arbitrage Pricing Theory）则进一步丰富了投资组合的理论框架。

- **1.1.3 投资组合理论的演变与应用**  
  随着金融市场的复杂化，投资组合理论不断演变，从单因子模型到多因子模型，从均值-方差模型到风险平价策略，投资组合理论在实践中得到了广泛应用。

#### 1.2 投资组合理论的核心概念

- **1.2.1 投资组合的基本定义**  
  投资组合是指将资金分配到不同资产或资产类别中，以实现风险与收益的最佳平衡。

- **1.2.2 风险与收益的权衡**  
  投资组合的核心在于在给定风险下最大化收益，或在给定收益下最小化风险。

- **1.2.3 投资组合的有效前沿**  
  有效前沿是指在所有可能的投资组合中，那些在特定风险水平下提供最高预期收益的投资组合的集合。

#### 1.3 四大师智慧的背景介绍

- **1.3.1 马科维茨的均值-方差模型**  
  马科维茨提出，投资者可以通过优化资产的预期收益和风险，构建最优投资组合。

- **1.3.2 夏普的单因子模型**  
  夏普提出，资产的预期收益可以用市场风险来解释，夏普比率衡量了资产的超额收益与市场风险的比值。

- **1.3.3 APT模型的多因子框架**  
  APT模型认为资产的收益可以通过多个因子（如市值、价值、动量等）来解释，投资组合可以通过对这些因子的暴露来优化收益和风险。

- **1.3.4 CAPM模型的理论基础**  
  CAPM模型认为，资产的预期收益与其系统性风险（beta）相关，提供了资产定价的理论框架。

#### 1.4 本章小结

- **1.4.1 投资组合理论的核心要素**  
  通过四大师的理论，我们可以从多个角度理解投资组合的构建和优化。

- **1.4.2 四大师智慧的整合思路**  
  将四大师的理论结合起来，可以构建一个更加全面和灵活的投资组合优化框架。

## 第二部分：四大师智慧的核心理论与模型

### 第2章：马科维茨的均值-方差模型

#### 2.1 均值-方差模型的原理

- **2.1.1 投资组合的期望收益与方差**  
  投资组合的期望收益是各资产期望收益的加权平均，方差是各资产收益波动的平方加权和。

- **2.1.2 优化问题的数学表达**  
  均值-方差模型的优化问题可以表示为：
  $$ \text{minimize } \sigma^2 \text{ subject to } \mu \geq \text{target return} $$

#### 2.2 均值-方差模型的实现

- **2.2.1 输入数据的准备**  
  需要历史收益数据、协方差矩阵或相关系数矩阵。

- **2.2.2 优化问题的求解**  
  使用拉格朗日乘数法或二次规划算法求解优化问题。

- **2.2.3 程序实现**  
  使用Python的`scipy.optimize`库实现均值-方差模型的优化。

```python
import numpy as np
from scipy.optimize import minimize

# 示例数据
mu = np.array([0.1, 0.2])
sigma_squared = np.array([[0.05, 0.02], [0.02, 0.1]])

# 定义目标函数
def objective(w):
    return np.dot(w.T, np.dot(sigma_squared, w))

# 定义约束条件
def constraint(w, mu, target):
    return np.dot(w, mu) - target

# 求解优化问题
w = minimize(objective, np.array([0.5, 0.5]), method='SLSQP',
             constraints={'type': 'eq', 'fun': lambda w: np.sum(w) - 1})

print("权重:", w.x)
print("最小方差:", objective(w.x))
```

### 第3章：夏普的单因子模型与CAPM

#### 3.1 夏普比率的原理

- **3.1.1 夏普比率的定义**  
  夏普比率衡量了投资组合的超额收益与投资组合风险的比值。

- **3.1.2 夏普比率的计算公式**  
  $$ \text{夏普比率} = \frac{E(r_p) - r_f}{\sigma_p} $$

#### 3.2 CAPM模型的原理

- **3.2.1 CAPM的理论基础**  
  资产的预期收益可以表示为：
  $$ E(r_i) = r_f + \beta_i (E(r_m) - r_f) $$

- **3.2.2 CAPM模型的应用**  
  通过CAPM模型可以计算资产的预期收益，并用于投资组合的优化。
