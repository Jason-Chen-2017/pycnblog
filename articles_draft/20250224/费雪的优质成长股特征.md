## 第3章: 费雪成长股投资的数学模型与算法

### 3.1 费雪筛选模型的数学表达

- 净利润增长率公式
  $$\text{净利润增长率} = \frac{\text{本期净利润} - \text{上期净利润}}{\text{上期净利润}} \times 100\%$$
- 市盈率与成长性的关系
  $$\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}$$
- 市场容量与公司潜力的数学模型
  $$\text{市场容量} = \text{行业规模} \times \text{公司市场份额}$$

```python
def fisher_growth_analysis(net_profit_prev, net_profit_curr, market_size, company_share):
    # 计算净利润增长率
    net_profit_growth = ((net_profit_curr - net_profit_prev) / net_profit_prev) * 100
    # 计算市盈率
    eps = net_profit_curr / market_size
    pe_ratio = (market_size * 100) / eps  # 示例市盈率计算
    # 评估市场容量
    market_capacity = market_size * company_share
    # 判断是否符合费雪筛选标准
    if net_profit_growth > 15 and pe_ratio < 15 and market_capacity > 1000:
        return "符合优质成长股特征"
    else:
        return "不符合优质成长股特征"
```

```python
import pandas as pd

def load_data(file_path):
    return pd.read_csv(file_path)

def calculate_profit_growth(data):
    return data['净利润'].pct_change() * 100

def calculate_pe_ratio(data):
    return data['股价'] / data['每股收益']

def main():
    data = load_data('stock_data.csv')
    growth = calculate_profit_growth(data)
    pe = calculate_pe_ratio(data)
    selected_stocks = data[growth > 15 & pe < 15]
    print(selected_stocks)

if __name__ == "__main__":
    main()
```
