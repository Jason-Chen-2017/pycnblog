### 4.3 选址优化的数学模型
- 4.3.1 线性规划模型
$$\min \sum_{i=1}^{n} c_i x_i$$
$$\text{s.t.} \quad \sum_{i=1}^{n} a_i x_i \geq D$$
$$x_i \in \{0,1\}$$
其中，$c_i$ 是选址成本，$a_i$ 是覆盖区域，$D$ 是需求总量。

### 4.4 选址优化的Python实现
```python
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def objective(x, A, D):
    return np.sum(A @ x >= D)

# 约束条件
A = np.array([[1, 1, 0], [0, 1, 1], [1, 0, 1]])
D = 3

# 初始猜测
x0 = np.array([1, 1, 1])

# 使用 scipy 最小化
result = minimize(objective, x0, args=(A, D), method='nelder-mead')
```
