# 第一部分: 背景与概念

## 第1章: 价值投资策略与风格漂移概述

### 1.1 价值投资策略的基本概念

- **1.1.1 价值投资的定义与核心理念**
  - 价值投资是基于对公司内在价值的评估，寻找市场价格低于内在价值的投资策略。
  - 核心理念：安全边际、长期持有、逆向投资。

- **1.1.2 投资策略的分类与特点**
  - 分类：成长型、价值型、收益型等。
  - 特点：每种策略都有其独特的风险收益特征。

- **1.1.3 价值投资在金融领域的应用**
  - 价值投资策略在股票、基金等金融产品中的应用。

### 1.2 风格漂移的定义与问题描述

- **1.2.1 风格漂移的定义**
  - 风格漂移是指投资组合的实际投资风格与预期投资策略发生偏离的现象。
  - 例如，原本专注于价值投资的基金转向了成长股投资。

- **1.2.2 风格漂移的常见原因**
  - 市场环境变化、管理人风格转变、投资目标调整等。

- **1.2.3 风格漂移对投资组合的影响**
  - 影响投资收益、偏离投资目标、增加投资风险。

### 1.3 AI驱动的风格漂移检测的必要性

- **1.3.1 传统风格漂移检测的局限性**
  - 传统方法依赖人工分析，效率低、主观性强。
  - 无法实时监测，难以应对快速变化的市场环境。

- **1.3.2 AI技术在金融分析中的优势**
  - 数据处理能力强、算法优化、实时监测。

- **1.3.3 AI驱动风格漂移检测的应用场景**
  - 基金管理、投资组合监控、风险控制。

### 1.4 本章小结
