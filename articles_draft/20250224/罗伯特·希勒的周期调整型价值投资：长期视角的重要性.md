# 第1章: 引言

## 1.1 罗伯特·希勒与周期调整型价值投资

### 1.1.1 罗伯特·希勒的学术背景
罗伯特·希勒（Robert J. Shiller）是美国著名经济学家，耶鲁大学经济学教授，以其在行为金融学领域的贡献而闻名。他提出了“有效市场假说”的挑战，并提出了周期调整后的市盈率（CAPE）理论，为价值投资提供了新的视角。

### 1.1.2 周期调整型价值投资的核心理念
周期调整型价值投资强调通过分析市场的周期性波动，识别资产的长期价值。希勒认为，市场的短期波动受到投资者心理和行为的影响，但长期价值取决于基本面因素。通过周期调整，投资者可以更准确地评估资产的真实价值。

### 1.1.3 长期视角的重要性
希勒的研究表明，短期市场波动往往被情绪和噪声驱动，而长期投资回报则与基本面密切相关。长期视角帮助投资者避免短期波动的干扰，专注于实现长期收益。

# 第2章: 罗伯特·希勒的周期调整模型

## 2.1 周期调整模型的原理

### 2.1.1 周期调整模型的基本概念
周期调整模型是一种用于评估资产长期价值的模型，通过调整短期市场波动对资产价值的影响，揭示资产的真实价值。

### 2.1.2 周期调整模型的数学公式
周期调整后的市盈率（CAPE）公式如下：

$$
CAPE = \frac{\text{指数成分股的平均盈利}}{\text{当前股价水平}}
$$

其中，平均盈利是过去10年平均净利润的几何平均值，用于消除短期盈利波动的影响。

### 2.1.3 周期调整模型的适用范围
周期调整模型适用于长期投资策略，尤其在市场波动较大时，能够帮助投资者识别低估或高估的资产。

## 2.2 希勒的市盈率理论

### 2.2.1 市盈率的定义与计算
市盈率（P/E）是衡量股票估值的重要指标，公式为：

$$
P/E = \frac{\text{股价}}{\text{每股收益}}
$$

### 2.2.2 周期调整后的市盈率（CAPE）
CAPE是对市盈率的改进，通过考虑更长期的盈利数据，减少短期波动对估值的影响。

### 2.2.3 CAPE与市场估值的关系
CAPE能够反映市场的整体估值水平，当CAPE高于历史平均水平时，市场可能被高估；反之，当CAPE低于历史平均水平时，市场可能被低估。

## 2.3 周期调整模型与传统价值投资的对比

### 2.3.1 传统价值投资的核心思想
传统价值投资强调购买被市场低估的资产，主要关注短期估值指标。

### 2.3.2 周期调整模型的独特视角
周期调整模型通过考虑更长期的盈利数据，提供更准确的资产估值。

### 2.3.3 两者的异同点分析
周期调整模型与传统价值投资的相同点在于都强调资产的内在价值，不同点在于周期调整模型更注重长期数据的分析。

## 4.2 核心实现源代码

### 4.2.1 CAPE计算函数
```python
import numpy as np
import pandas as pd

def calculate_cape(stock_prices, earnings):
    geometric_mean_earnings = np.exp(np.mean(np.log(earnings)))
    cape = stock_prices.mean() / geometric_mean_earnings
    return cape
```

### 4.2.2 投资决策函数
```python
def investment_decision(candidates):
    decisions = []
    for candidate in candidates:
        cape = calculate_cape(candidate['prices'], candidate['earnings'])
        if cape < 15:
            decisions.append('买入')
        elif cape > 25:
            decisions.append('卖出')
        else:
            decisions.append('观望')
    return decisions
```
