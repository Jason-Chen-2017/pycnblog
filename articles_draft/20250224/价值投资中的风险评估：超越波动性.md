## 第二部分：数学模型与算法

### 2.1 CAPM模型

CAPM（资本资产定价模型）用于评估资产的预期回报率，公式为：

$$
E(r_i) = r_f + \beta_i (E(r_m) - r_f)
$$

其中：
- \(E(r_i)\) 是资产的预期回报率
- \(r_f\) 是无风险利率
- \(\beta_i\) 是资产的贝塔系数
- \(E(r_m)\) 是市场预期回报率

以下是计算贝塔系数的Python代码示例：

```python
import numpy as np

# 假设数据为市场回报和资产回报
market_returns = [...]  # 市场回报数据
asset_returns = [...]    # 资产回报数据

covariance = np.cov(asset_returns, market_returns)[0, 1]
variance = np.var(market_returns)

beta = covariance / variance
```

### 2.2 夏普比率

夏普比率衡量投资组合的风险调整后收益，公式为：

$$
\text{夏普比率} = \frac{E(r_p) - r_f}{\sigma_p}
$$

其中：
- \(E(r_p)\) 是投资组合的预期回报率
- \(r_f\) 是无风险利率
- \(\sigma_p\) 是投资组合的波动率

以下是计算夏普比率的Python代码示例：

```python
import numpy as np

# 假设数据为投资组合回报和无风险利率
portfolio_returns = [...]  # 投资组合回报数据
risk_free_rate = [...]      # 无风险利率

expected_return = np.mean(portfolio_returns)
std_deviation = np.std(portfolio_returns)

sharpe_ratio = (expected_return - risk_free_rate) / std_deviation
```
