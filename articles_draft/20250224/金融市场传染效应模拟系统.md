## 第一部分: 金融市场传染效应概述

### 第1章: 金融市场传染效应的背景与概念

#### 1.1 金融市场传染效应的定义
金融市场传染效应是指在金融市场中，某一金融机构或市场的负面事件（如亏损、违约等）可能会通过直接或间接的渠道，引发其他金融机构或市场的连锁反应，从而导致系统性风险的传播和扩散。

#### 1.2 传染效应的传播机制
传染效应的传播机制主要包括以下几个方面：
1. **直接传染**：直接的债务或股权关联导致的风险传染。
2. **间接传染**：通过市场、价格或信用渠道引发的风险传染。
3. **羊群效应**：投资者的模仿行为导致的市场波动。

#### 1.3 传染效应的属性特征
| 属性 | 特征 |
|------|------|
| 传播速度 | 快速、非线性 |
| 影响范围 | 局部到全局 |
| 传染路径 | 直接关联、间接关联、市场情绪 |

#### 1.4 传染效应的核心要素
- **传染源**：触发传染的初始事件（如银行破产）。
- **传播路径**：传染的具体渠道（如市场、价格、信用）。
- **传染目标**：受传染的金融机构或市场。
- **传染结果**：系统性风险的放大和扩散。

## 第二部分: 金融传染效应的数学建模与算法原理

### 第2章: 金融传染效应的数学模型

#### 2.1 系统动力学模型
系统动力学模型通过描述金融系统的内部动态关系，模拟传染效应的传播过程。模型的基本方程如下：

$$
\frac{dS}{dt} = rS - \beta S I
$$

其中，\( S \) 表示易感状态的金融机构数量，\( I \) 表示被传染的金融机构数量，\( r \) 表示金融机构的恢复率，\( \beta \) 表示传染系数。

#### 2.2 网络动力学模型
网络动力学模型将金融市场视为一个复杂网络，节点代表金融机构，边代表金融机构之间的关联。模型通过描述网络中的信息传播过程，模拟金融传染效应的扩散。

网络动力学模型的传播概率公式如下：

$$
P(i,j) = \frac{\beta}{1 + \beta \cdot \text{degree}(i)}
$$

其中，\( \beta \) 表示传播系数，\( \text{degree}(i) \) 表示节点 \( i \) 的度数。

#### 3.2 算法实现代码

```python
import networkx as nx
import numpy as np

def simulateFinancialContagion(network, beta, initial_contagious):
    # 初始化传染状态
    for node in initial_contagious:
        network.nodes[node]['state'] = 'contagious'
    
    # 模拟传播过程
    for _ in range(100):
        for node in network.nodes():
            if network.nodes[node]['state'] == 'susceptible':
                neighbors = network.neighbors(node)
                total_contagious = sum(1 for n in neighbors if network.nodes[n]['state'] == 'contagious')
                if total_contagious > 0:
                    if np.random.rand() < beta / total_contagious:
                        network.nodes[node]['state'] = 'contagious'
    return network
```
