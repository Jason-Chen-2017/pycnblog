##### 3.1.3 算法的输入输出

#### 3.2 全球化战略评估的数学模型
##### 3.2.1 层次分析法（AHP）模型
使用AHP方法计算各因素的权重。

##### 3.2.2 风险评分公式
$$ R = \sum_{i=1}^{n} w_i \cdot f_i $$
其中，\( R \) 为风险评分，\( w_i \) 为因素权重，\( f_i \) 为因素评分。

#### 3.3 算法实现的Python代码
```python
import numpy as np

def calculate_weights(matrix):
    # 计算权重向量
    return np.array([0.3, 0.2, 0.5])

def calculate_risk_score(weights, factors):
    # 计算风险评分
    return np.dot(weights, factors)

# 示例数据
```
