# 第二章: LLM驱动的文本压缩与提炼原理

## 2.1 LLM在自动摘要中的作用
### 2.1.1 LLM的文本生成机制
LLM通过概率生成模型，预测文本的下一个词，生成连贯且有意义的摘要。

### 2.1.2 LLM在文本压缩中的优势
LLM能够捕捉文本的语义信息，生成简洁而准确的摘要，减少冗余信息。

## 2.2 自动摘要的算法原理
### 2.2.1 基于LLM的自动摘要算法流程（Mermaid图）
```mermaid
graph TD
    A[输入文本] --> B[分割句子]
    B --> C[计算词向量]
    C --> D[生成关键词]
    D --> E[输出摘要]
```

### 2.2.2 算法实现的核心代码（Python示例）
```python
import torch
from transformers import AutoTokenizer, AutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained('bert-base-uncased')
model = AutoModelForMaskedLM.from_pretrained('bert-base-uncased')

def generate_summary(text):
    inputs = tokenizer.encode_plus(text, max_length=512, truncation=True, padding=True, return_tensors='pt')
    with torch.no_grad():
        outputs = model(inputs.input_ids)
    summary = tokenizer.decode(outputs.logits.argmax(dim=-1).squeeze())
    return summary
```

### 2.2.3 数学模型与公式
LLM的损失函数：
$$ \text{Loss} = -\sum_{i=1}^{n} \log p(x_i) $$
其中，$p(x_i)$是模型生成第i个词的概率。

生成模型的条件概率：
$$ P(\text{摘要} | \text{输入文本}) = \prod_{i=1}^{m} P(x_i | x_{i-1}, \text{输入文本}) $$
