# 第一部分：元强化学习概述

## 第1章：元强化学习的背景与问题背景

### 1.1 传统强化学习的局限性
传统强化学习在处理新任务时需要从头开始学习，效率低下。其局限性包括：
- 需要大量数据支持
- 适应新任务时间较长
- 无法快速迁移已有经验

### 1.2 元强化学习的定义与目标
元强化学习是一种通过元学习机制，使AI代理能够快速适应新任务的强化学习方法。其目标是在有限时间内，利用已有经验快速优化新环境中的策略。

### 1.3 元强化学习的应用场景
- 多任务学习
- 快速适应新任务
- 连续控制与离散控制中的应用
