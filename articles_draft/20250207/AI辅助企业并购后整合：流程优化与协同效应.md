#### 第6章: 协同过滤算法

- 6.1 协同过滤算法的原理与数学模型
  - $$\text{相似度计算} = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n} (x_i - \bar{x})^2} \sqrt{\sum_{i=1}^{n} (y_i - \bar{y})^2}}$$
  - 代码实现示例：
    ```python
    def calculate_similarity(user_ratings, item_ratings):
        # 计算皮尔逊相关系数
        numerator = sum((user_ratings[i] - user_avg) * (item_ratings[i] - item_avg) for i in range(len(user_ratings)))
        denominator = (sqrt(sum(pow(user_ratings[i] - user_avg, 2) for i in range(len(user_ratings)))) *
                        sqrt(sum(pow(item_ratings[i] - item_avg, 2) for i in range(len(item_ratings)))))
        return numerator / denominator if denominator != 0 else 0
    ```
