## 2.2 法律文档分析的基本原理

### 2.2.1 法律文档的结构与特点
- 法律文档包括法律条文、案例判决书、合同协议等。
- 法律文档语言正式、复杂，且具有高度的专业性。

### 2.2.2 文本分析的关键技术
- 分词：将法律文本分割成词语或短语。
- 词性标注：识别词语的词性。
- 句法分析：分析句子的语法结构。
- 实体识别：提取法律文本中的实体信息（如人名、地名、机构名等）。
- 关系抽取：识别实体之间的关系。

### 2.2.3 法律知识库的构建与应用
- 法律知识库的构建：通过自然语言处理技术，从大量法律文档中提取知识并构建知识图谱。
- 法律知识库的应用：支持法律推理、案例分析和法律咨询。

```python
import spacy

nlp = spacy.load("en_core_web_sm")

def extract_entities(text):
    doc = nlp(text)
    entities = []
    for ent in doc.ents:
        entities.append((ent.text, ent.label_))
    return entities

text = "根据合同条款，违约金应为合同金额的10%。"
print(extract_entities(text))
```
