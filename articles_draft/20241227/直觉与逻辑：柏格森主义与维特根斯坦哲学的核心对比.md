- `print(a)`: 打印变量 `a` 的值。
- `if b then c else d`: 当条件 `b` 为真时执行 `c`，否则执行 `d`。

我们有以下代码：

```plaintext
print(5)

```

这种逻辑结构清晰地映射到了维特根斯坦的语言游戏理论，其中语法规则定义了游戏（编程语言）的规则，代码结构是游戏中的动作，而执行结果则是游戏的结果。
