### 第3章：对称加密算法

#### 3.1 对称加密算法概述
对称加密算法是一种加密和解密过程中使用相同密钥的加密方法。其核心思想是：加密算法和解密算法是相互逆的过程，即若E是加密算法，D是解密算法，则有D(E(K, M)) = M 和 E(D(K, C)) = C，其中K是密钥，M是明文，C是密文。

#### 3.1.1 对称加密的特点
对称加密算法具有以下几个特点：

- **安全性高**：由于加密和解密使用相同密钥，只要密钥安全，就可以保证数据的安全性。
- **速度快**：对称加密算法通常比非对称加密算法更快，因为计算复杂度较低。
- **密钥管理复杂**：对称加密需要确保密钥的安全传输和存储，否则可能导致整个系统的安全漏洞。

#### 3.1.2 主流对称加密算法介绍
以下是几个主流的对称加密算法：

- **AES（高级加密标准）**：AES是目前最广泛使用的对称加密算法，由NIST于2001年发布。它支持128、192和256位的密钥长度，具有良好的安全性。

#### 3.1.3 AES加密算法原理
AES加密算法的工作流程包括以下步骤：

1. **密钥扩展**：将用户输入的密钥扩展成多个轮密钥。
2. **初始轮**：将明文和第一个轮密钥进行字节替换、行移位、列混淆和轮密钥加。
3. **中间轮**：对每个轮进行字节替换、行移位、列混淆和轮密钥加，共进行10-14轮操作。
4. **最终轮**：对最后一轮的结果进行字节替换、行移位和列混淆。

#### 3.1.4 AES加密算法示例
以下是一个使用Python实现的AES加密算法示例：

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad
from Crypto.Random import get_random_bytes

# 生成密钥
key = get_random_bytes(16)

# 待加密的明文
plaintext = b"Hello, World!"

# 对明文进行填充
padded_plaintext = pad(plaintext, AES.block_size)

# 创建加密对象
cipher = AES.new(key, AES.MODE_CBC)

# 加密明文
ciphertext = cipher.encrypt(padded_plaintext)

# 输出密文和初始向量
print("Ciphertext:", ciphertext.hex())
print("IV:", cipher.iv.hex())
```

通过上述步骤，我们可以看到对称加密算法的原理和实现过程。
