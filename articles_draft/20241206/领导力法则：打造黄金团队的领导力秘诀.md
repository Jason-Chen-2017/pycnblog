### 第二部分：核心概念与联系

#### 第2章：领导力的核心概念解析

**2.1 权威与影响力的区别与联系**
权威是一种基于职位或权力赋予的合法影响力，而影响力则是基于个人特质、能力和关系的自然影响。权威和影响力相互作用，共同塑造领导力。

**2.2 领导风格的理论与实践**
领导风格是指领导者处理团队事务的方式。常见的领导风格包括专制式、民主式和放任式。每种风格都有其适用场景，领导者应根据团队情况和目标选择合适的领导风格。

```python
        return "立即行动"

        return "计划执行"

    # 根据决策执行相应的行动
    if decision == "立即行动":
        return "行动完成"
    elif decision == "计划执行":
        return "计划完成"
    else:
        return "决策无效"

context = "紧急情况"
decision = decision_making(context)
result = execute_decision(decision)
print(result)
```
