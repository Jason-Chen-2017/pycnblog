## 第一部分：价值投资的背景与基础

### 第1章：价值投资的定义与核心理念

#### 1.1 价值投资的定义

价值投资是一种基于公司基本面分析的投资策略，旨在通过识别市场价格低于其内在价值的股票，实现长期稳定的收益。格雷厄姆是该领域的奠基人，他强调安全边际和内在价值的重要性。

**核心理念：**
- **安全边际**：购买价格低于内在价值，以降低风险。
- **内在价值**：公司未来现金流的现值，计算其真实价值。

#### 1.2 价值投资的历史演变

- **早期发展**：20世纪初，格雷厄姆与多德共同提出价值投资理论。
- **现代演变**：格雷厄姆的理论被后来投资者如巴菲特、彼得·林奇等继承和发展，形成多样化的价值投资策略。

#### 1.3 核心要素

- **基本面分析**：分析公司的财务报表、行业地位、竞争优势等。
- **安全边际**：购买价格低于内在价值，确保收益。
- **内在价值**：通过DCF模型计算公司未来现金流的现值。

#### 1.4 对比其他投资策略

- **技术分析**：依赖价格走势和成交量，忽视基本面。
- **成长投资**：侧重公司未来的增长潜力，而非当前估值。

### 第2章：基本面分析与安全边际

#### 2.1 基本面分析

- **财务报表分析**：利润表、资产负债表、现金流量表。
  - **利润表**：收入、成本、利润。
  - **资产负债表**：资产、负债、所有者权益。
  - **现金流量表**：经营活动、投资活动、筹资活动的现金流。

- **行业分析与竞争优势**：分析行业趋势，评估公司在行业中的地位和竞争优势。

#### 2.2 安全边际计算

- **定义**：购买价格低于内在价值，确保收益。
- **计算公式**：
  \[
  安全边际 = 内在价值 - 市场价格
  \]
  若安全边际为正，说明价格合理。

#### 2.3 核心概念对比

| 概念       | 基本面分析 | 技术分析 |
|------------|------------|----------|
| 定价基础   | 公司价值   | 价格走势 |
| 数据来源   | 财务报表   | 价格和成交量 |
| 目标       | 寻找低估股票 | 预测价格走势 |

## 第二部分：算法原理与系统设计

### 第3章：DCF模型与内在价值计算

#### 3.1 DCF模型原理

- **定义**：通过现金流折现计算公司内在价值。
- **步骤**：
  1. 预测未来现金流。
  2. 计算加权平均资本成本（WACC）。
  3. 折现未来现金流，计算现值。
  4. 加上当前现金流，得出内在价值。

#### 3.2 DCF模型实现

- **Python代码示例**：

```python
import numpy as np

def calculate_intrinsic_value(fcf, wacc, horizon=10, discount_rate=0.05):
    # 预测未来现金流
    future_cash_flows = [fcf * (1 + 0.05)**i for i in range(horizon)]
    # 现金流的现值
    present_value = sum(fcf * (1 + wacc)**-i for i, fcf in enumerate(future_cash_flows))
    # 加上终值
    terminal_value = future_cash_flows[-1] * (1 + discount_rate)**-horizon
    total_intrinsic_value = present_value + terminal_value
    return total_intrinsic_value

# 示例计算
fcf = 100  # 自由现金流
wacc = 0.10  # 加权平均资本成本
iv = calculate_intrinsic_value(fcf, wacc)
print(f"内在价值：{iv:.2f}")
```
