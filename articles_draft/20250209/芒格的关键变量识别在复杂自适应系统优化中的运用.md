## 1.1 复杂自适应系统的定义与特点

### 1.1.1 系统的基本概念
复杂自适应系统（CAS）由多个主体组成，这些主体能够根据环境和相互作用进行调整。CAS的特点包括非线性互动、涌现性特征和适应性变化。

### 1.1.2 复杂自适应系统的特征
- **非线性互动**：系统中的元素相互作用，产生不可预测的结果。
- **涌现性**：系统整体表现出个体不具备的特征。
- **适应性**：系统能够根据反馈调整行为。

### 1.1.3 复杂自适应系统的分类
- **经济系统**：如市场和企业。

# 第2章: 芒格的关键变量识别方法的数学模型

## 2.1 关键变量识别的数学基础

### 2.1.1 熵值法的原理
熵值法基于信息论，计算各变量的重要性。信息熵越高，变量的重要性越大。

### 2.1.2 基于相关性的分析方法
通过变量间的相关性分析，筛选出对系统影响较大的变量。

### 2.1.3 基于回归分析的变量筛选
利用回归模型确定变量对系统输出的贡献程度。

## 2.2 关键变量识别的算法实现

### 2.2.1 熵值法的权重计算公式
$$
权重计算公式：w_i = \frac{f_i}{\sum_{j=1}^{n}f_j}
$$
其中，$f_i$为第i个变量的信息熵，总和为所有变量熵的总和。

### 2.2.2 基于回归分析的变量重要性排序
回归分析通过系数大小排序变量的重要性，系数越大，变量越关键。

### 2.2.3 算法的收敛性分析
熵值法和回归分析均为确定性算法，收敛性良好，计算效率高。

import numpy as np
from sklearn.linear_model import LinearRegression

def calculate_entropy_weights(data):
    # 数据标准化
    normalized_data = (data - data.min()) / (data.max() - data.min())
    # 计算熵
    n = len(normalized_data)
    entropy = np.zeros(n)
    for i in range(n):
        entropy[i] = -np.sum(normalized_data[i] * np.log(normalized_data[i]))
    # 计算权重
    total_entropy = np.sum(entropy)
    weights = entropy / total_entropy
    return weights

data = np.array([0.2, 0.4, 0.6, 0.8])
weights = calculate_entropy_weights(data)
print(weights)
