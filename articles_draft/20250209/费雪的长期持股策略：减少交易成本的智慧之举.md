### 第1章：价值投资的起源与发展

#### 1.1 价值投资的起源
- **投资学派的演变**：从格雷厄姆的“烟蒂投资”到巴菲特的“护城河”理论，价值投资经历了多个阶段的发展。

#### 1.2 费雪的投资理念
- **成长股理论**：投资于收入和利润持续增长的公司。
- **内在价值计算**：通过DCF模型评估公司的真实价值。

#### 1.3 长期持股的意义
- **减少交易成本**：避免频繁交易带来的佣金和税费。
- **复利效应**：长期持有优质资产能最大化复利收益。

#### 2.1 费雪的投资策略特点

### 第3章：投资的基本原理

#### 3.1 资产定价理论
- **内在价值公式**：$V = \frac{CF}{r - g}$
  其中，CF为现金流，r为折现率，g为增长率。
- **市场有效性**：市场价格与内在价值的偏差是投资机会的来源。

#### 3.2 长期投资的优势
- **复利效应的实现**：长期持有优质资产能最大化复利收益。
- **风险管理**：分散投资和长期持有能降低市场波动带来的风险。

### 第4章：价值投资的核心要素

#### 4.2 内在价值计算

```python
def calculate_roe(df):
    df['ROE'] = (df['Net Income'] / df['Total Equity']) * 100
    return df

# 示例：DCF模型计算内在价值
def calculate_intrinsic_value(df, discount_rate=0.1):
    # 假设自由现金流
    CF = df['Free Cash Flow'].iloc[-1]
    # 预测未来现金流
    CF_future = CF * (1 + 0.1) ** np.arange(5)
    # 计算现值
    PV = np.sum(CF_future / (1 + discount_rate) ** np.arange(5))
    return PV
```
