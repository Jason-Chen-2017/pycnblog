### 4.1 投资模型的构建
循环企业价值评估模型（CEVEM）结合了循环经济的资源效率和企业的财务指标，通过多维度分析评估企业的长期价值。

### 4.2 Python代码实现

```python
def calculate循环经济价值(企业基本面, 行业趋势, 政策支持):
    循环经济价值 = 企业基本面 * (行业趋势 + 政策支持)
    return循环经济价值

企业基本面 = {"净利润": 100, "ROE": 20, "研发投入": 50}
行业趋势 = 0.8
政策支持 = 0.7

value = calculate循环经济价值(企业基本面, 行业趋势, 政策支持)
print("循环经济价值:", value)
```

### 4.3 数学模型与公式
循环企业价值评估模型公式：
$$ CEV = (EBIT \times (1 - t)) + (R \times C) $$
其中，EBIT为息税前利润，t为税率，R为资源利用率，C为循环资源价值。
