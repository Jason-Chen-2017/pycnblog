# 第一部分: 公司内在价值计算的背景与核心概念

## 第1章: 内在价值计算的基本概念

### 1.1 内在价值的定义与背景

#### 1.1.1 什么是公司内在价值

公司内在价值是指一家公司基于其未来现金流的贴现值，即假设市场是理性的，公司股票的真正价值。内在价值与市场价值不同，后者是市场交易中股票的实际价格，而前者是公司未来现金流的现值。

#### 1.1.2 内在价值计算的必要性

在投资决策中，内在价值是判断一家公司是否被低估或高估的重要依据。通过计算内在价值，投资者可以判断股票是否值得买入或卖出。此外，内在价值也是公司战略决策（如并购、资本预算）的重要参考。

#### 1.1.3 内在价值与市场价值的区别

- **内在价值**：基于公司基本面的未来现金流折现值。
- **市场价值**：市场交易中股票的实际价格，受市场情绪和市场参与者的心理影响。

### 1.2 内在价值计算的核心要素

#### 1.2.1 自由现金流的定义与计算

**自由现金流（FCF）**是公司在偿还所有债务和再投资必要的资本支出之后，剩余的可用于分配给股东的现金流量。其计算公式为：

$$\text{自由现金流} = \text{净利润} + \text{折旧} + \text{摊销} - \text{资本支出}$$

#### 1.2.2 贴现率的确定方法

贴现率反映了投资者要求的必要回报率，通常由无风险利率和风险溢价组成：

$$\text{贴现率} = \text{无风险利率} + \text{风险溢价}$$

#### 1.2.3 永续增长率的假设与验证

永续增长率假设公司在未来稳定增长的速率，通常基于行业的平均增长率或公司自身的竞争优势。

### 1.3 内在价值计算的基本公式

贴现现金流模型（DCF）是计算公司内在价值的核心公式：

$$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} + \frac{\text{终值}}{(1 + r)^n}$$

其中：
- $\text{现金流}_t$ 是第 $t$ 年的自由现金流。
- $r$ 是贴现率。
- $n$ 是预测的年数。
- 终值是第 $n$ 年后稳定的现金流按永续增长率贴现的现值。

# 第二部分: 内在价值计算的算法原理

## 第3章: 贴现现金流模型（DCF）的原理与实现

### 3.1 DCF模型的算法原理

贴现现金流模型（DCF）是计算公司内在价值的核心方法。其基本思想是将公司未来的自由现金流折现，加终值（永续增长部分）的现值。

#### 3.1.1 自由现金流的计算公式

$$\text{自由现金流} = \text{净利润} + \text{折旧} + \text{摊销} - \text{资本支出}$$

#### 3.1.2 贴现率的计算公式

$$\text{贴现率} = \text{无风险利率} + \text{风险溢价}$$

#### 3.1.3 内在价值的计算公式

$$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} + \frac{\text{终值}}{(1 + r)^n}$$

### 3.2 DCF模型的Python实现

```python
def calculate_intrinsic_value(free_cash_flows, discount_rate, terminal_value, horizon):
    intrinsic_value = 0
    for t in range(1, horizon + 1):
        intrinsic_value += free_cash_flows[t] / (1 + discount_rate) ** t
    if horizon > 0:
        intrinsic_value += terminal_value / (1 + discount_rate) ** horizon
    return intrinsic_value

# 示例数据
free_cash_flows = [100, 120, 130]
discount_rate = 0.07
terminal_value = 200
horizon = 3

iv = calculate_intrinsic_value(free_cash_flows, discount_rate, terminal_value, horizon)
print(f"内在价值为: {iv:.2f}")
```

### 5.2 核心代码实现

```python
import numpy as np

def calculate_intrinsic_value(fcf, discount_rate, terminal_growth_rate, horizon):
    present_value = 0
    for t in range(horizon):
        cash_flow = fcf * (1 + terminal_growth_rate) ** t
        present_value += cash_flow / (1 + discount_rate) ** (t + 1)
    terminal_value = fcf * (1 + terminal_growth_rate) ** horizon / (discount_rate - terminal_growth_rate)
    present_value += terminal_value / (1 + discount_rate) ** horizon
    return present_value

# 示例数据
fcf = 100
discount_rate = 0.07
terminal_growth_rate = 0.03
horizon = 5

iv = calculate_intrinsic_value(fcf, discount_rate, terminal_growth_rate, horizon)
print(f"内在价值为: {iv:.2f}")
```
