## 第三部分: 巴菲特投资策略的数学模型与系统分析

### 第5章: 巴菲特投资策略的数学模型

#### 5.1 价值投资的数学模型

- **市盈率（P/E）分析**
  - 公式：P/E = 市场价 / 每股收益。
  - 低P/E可能意味着低估，但需结合ROE分析。

- **市净率（P/B）分析**
  - 公式：P/B = 市场价 / 每股净资产。
  - 低P/B可能表明资产被低估。

- **股息率分析**
  - 公式：股息率 = 每股股息 / 市场价。
  - 高股息率可能表明收益稳定，但需警惕过高可能为陷阱。

```python
import pandas as pd
import requests
from bs4 import BeautifulSoup

# 示例代码：获取CVS Health的财务数据
def get_finance_data(ticker):
    url = f"https://finance.yahoo.com/quote/{ticker}/financials"
    headers = {'User-Agent': 'Mozilla/5.0'}
    response = requests.get(url, headers=headers)
    soup = BeautifulSoup(response.text, 'html.parser')
    data = []
    for row in soup.find('div', {'class': ' financials-row'}):
        data.append({
            'metric': row.find('div', {'class': 'metric'}).text,
            'value': row.find('div', {'class': 'value'}).text
        })
    return pd.DataFrame(data)

cvs_data = get_finance_data('CVS')
print(cvs_data)
```
