### 第1章: 逆向思维的定义与背景

#### 1.1 逆向思维的定义
逆向思维是一种从结果出发，反向推导原因的思维方式。与传统的正向思维不同，逆向思维更注重从已知的结果出发，寻找可能的原因或解决方案。这种思维方式在投资决策中尤为重要，因为它可以帮助投资者在复杂多变的市场中找到潜在的投资机会。

#### 1.2 芒格的"逆向工程"思维
芒格的"逆向工程"思维是一种通过分析问题的结果，推导出问题的起因或解决方案的方法。这种方法在投资领域中被广泛应用，尤其是在寻找被低估的投资机会时。芒格认为，通过逆向思维，投资者可以更好地理解市场的运作机制，并找到那些被市场忽视的机会。

import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('market_data.csv')

# 数据分析
def reverse_engineer(data):
    # 计算收益
    returns = data.pct_change()
    # 计算期望收益
    expected_return = returns.mean()
    # 计算风险
    risk = returns.std()
    return expected_return, risk

expected_return, risk = reverse_engineer(data)

# 投资策略
if expected_return > risk:
    print("投资机会")
else:
    print("不值得投资")
