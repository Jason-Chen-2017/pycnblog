# 第1章: 价值投资与固定收益市场的基础

## 1.1 价值投资的核心概念

### 1.1.1 安全边际
安全边际是指资产的内在价值与其市场价格之间的差额。通过计算安全边际，投资者可以在市场价格低于内在价值时介入，降低投资风险。

数学公式：
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

### 1.1.2 内在价值
内在价值是基于债券的未来现金流折现值计算的理论价值。公式为：
$$ V = \sum_{t=1}^{n} \frac{C}{(1+r)^t} + \frac{F}{(1+r)^n} $$
其中，\( C \) 是每年的利息，\( F \) 是面值，\( r \) 是折现率，\( n \) 是债券的期限。

### 1.1.3 市场先生
市场先生是本格雷厄姆提出的一个隐喻，指市场情绪波动对资产价格的影响。投资者应独立于市场先生的情绪，基于基本面进行投资。

## 1.2 固定收益市场的运作机制

### 1.2.1 债券类型与特点
- **政府债券**：由政府发行，信用风险较低。
- **企业债券**：由企业发行，信用风险较高，利率也较高。

### 1.2.2 利率风险与信用风险
- **利率风险**：债券价格随市场利率变化而波动的风险。
- **信用风险**：债券发行人违约的风险。

### 1.2.3 债券定价与收益率
债券的收益率公式：
$$ \text{到期收益率} = \left( \frac{C + (F - P)}{P} \right) \times 100\% $$

## 3.2 算法实现

### 3.2.1 安全边际计算
使用 Python 计算债券的内在价值和安全边际：
```python
def calculate_intrinsic_value(face_value, coupon_rate, years, discount_rate):
    intrinsic_value = 0
    for year in range(years):
        cash_flow = face_value * coupon_rate
        intrinsic_value += cash_flow / (1 + discount_rate) ** (year + 1)
    intrinsic_value += face_value / (1 + discount_rate) ** years
    return intrinsic_value

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price
```
