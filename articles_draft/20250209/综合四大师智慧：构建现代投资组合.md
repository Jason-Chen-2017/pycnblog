## 第一部分：投资组合构建的背景与基础

### 第1章：投资组合构建的背景与重要性

#### 1.1 投资组合的基本概念

投资组合是指将一定资金按照特定比例分配到不同的资产或投资标的上的组合。通过合理的资产配置，投资组合能够在风险可控的前提下，实现收益的最大化。

#### 1.2 现代投资组合理论的演进

现代投资组合理论（MPT）由哈里·马科维茨在1952年提出，被认为是投资学的重要里程碑。马科维茨提出，通过优化资产配置，可以在相同风险下实现收益最大化，或在相同收益下实现风险最小化。

### 第2章：四位大师的投资理念与方法

#### 2.1 巴菲特的价值投资策略

巴菲特的价值投资策略强调以合理价格买入优质企业，长期持有。他认为市场的短期波动是噪声，长期来看，企业价值将反映其内在价值。

#### 2.2 彼得·林奇的选股方法

林奇的成长投资策略注重选择具有持续增长潜力的公司，尤其是那些市场份额稳定、竞争优势明显的企业。他认为，投资成长股的关键是找到那些未来几年销售额和利润都能快速增长的企业。

#### 2.3 格雷厄姆的防御性投资策略

格雷厄姆的防御性投资策略强调安全边际，即以低于内在价值的价格买入优质企业。他认为，投资的目的是避免重大损失，而不是追求超额收益。

#### 2.4 芒格的多元思维模型

芒格的多元思维模型强调通过多个学科的交叉应用，来理解复杂问题。他认为，投资不仅仅是对企业的分析，更是对整个商业生态的理解。

#### 3.3 投资组合构建的数学模型

现代投资组合理论的核心是马科维茨的有效前沿模型。该模型通过优化资产配置，使得在给定风险下，收益最大化，或者在给定收益下，风险最小化。

数学公式如下：

$$ \text{目标函数：} \quad \min \sigma^2 \quad \text{subject to} \quad \mu^T w = \mu_r \quad \text{和} \quad w^T \Sigma w = \text{最小化} $$

其中，\( \mu \) 是资产的期望收益向量，\( \Sigma \) 是资产的协方差矩阵，\( w \) 是投资权重向量，\( \mu_r \) 是目标收益。

def portfolio_optimization(returns, cov_matrix, target_return):
    n = len(returns)
    # 定义优化目标函数
    def objective(weights):
        return (weights.T @ cov_matrix @ weights)[0, 0]
    
    # 定义约束条件
    constraints = [
        ('sum', weights, target_return)
    ]

#### 6.2 核心实现代码

实现投资组合优化的代码：

```python
import numpy as np
from scipy.optimize import minimize

def portfoliooptimize(returns):
    n = len(returns.columns)
    # 计算协方差矩阵
    cov_matrix = returns.cov()
    # 计算期望收益向量
    mu = returns.mean()
    # 定义目标函数
    def objective(weights):
        return (weights.T @ cov_matrix @ weights)[0, 0]
    
    # 约束：收益等于目标收益
    target_return = 0.12
    def constraint(weights, mu, target_return):
        return (weights.T @ mu)[0] - target_return
    
    # 初始权重
    initial_weights = np.array([1.0/n]*n)
    # 优化
    result = minimize(objective, initial_weights, constraints=[{'type': 'eq', 'fun': constraint, 'args': (mu, target_return)}])
    return result.x
```
