公式1：一致性算法的目标是确保系统中所有节点的状态一致。$$ \text{一致性} = \frac{\text{节点状态的一致性}}{\text{总节点数}} $$

代码示例：一致性算法的Python实现

```python
def consistency_algorithm(nodes):
    # 初始化一致性指标
    consistency = 0
    # 计算一致性
    for node in nodes:
        if node.state == nodes[0].state:
            consistency += 1
    return consistency / len(nodes)
```

公式2：博弈论模型中的纳什均衡

$$ \text{纳什均衡} = \{i, j\} \text{ 满足 } u_i(a_i, a_{-i}) \geq u_i(a'_i, a_{-i}) \text{ 对所有 } a'_i \} $$

代码示例：博弈论模型的Python实现

```python
def nash_equilibrium(game_matrix):
    # 计算纳什均衡
    nash = []
    for strategy in itertools.product(*[range(len(row)) for row in game_matrix]):
        payoff = []
        for player in range(len(game_matrix)):
            payoff.append(game_matrix[player][strategy[player]])
        is_nash = True
        for player in range(len(game_matrix)):
            for alternative in range(len(game_matrix[player])):
                if game_matrix[player][alternative] > payoff[player]:
                    is_nash = False
                    break
            if not is_nash:
                break
        if is_nash:
            nash.append(strategy)
    return nash
```
