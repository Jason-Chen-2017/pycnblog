投资者权益保护是指通过法律、制度和市场机制，确保投资者在投资活动中享有知情权、参与权、收益权和求偿权等基本权益。在当前金融市场中，投资者权益保护不仅是维护市场公平的重要手段，也是提升投资者信心的关键因素。

约翰·伯格以其创立的 Vanguard 集团，推动了指数基金的普及，降低了投资成本，为中小投资者提供了更公平的投资选择。他的理念强调低成本、长期投资和分散化，这些都与投资者权益保护密切相关。

**1.1.3 当前投资环境中的主要问题**

当前市场中，投资者面临的主要问题包括信息不对称、高费用、市场操纵和监管不力等。这些问题不仅损害了投资者的权益，也影响了市场的健康发展。

```python
def investor_rights_protection(investment, risk_level):
    protected_rights = 0
    if risk_level == "low":
        protected_rights = investment * 0.95
    elif risk_level == "medium":
        protected_rights = investment * 0.90
    else:
        protected_rights = investment * 0.85
    return protected_rights
```
