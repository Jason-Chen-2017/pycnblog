## 第1章 彼得·林奇与PEG比率概述

### 1.1 彼得·林奇及其投资理念

彼得·林奇是美国著名投资家，曾任富达投资集团麦哲伦基金经理，创造了辉煌的投资业绩。他倡导“价值投资”，注重基本面分析，强调选择具有持续增长潜力的公司。

#### 1.1.1 彼得·林奇的生平简介
- 1948年出生，毕业于宾夕法尼亚大学和哈佛商学院。
- 1971年加入富达投资，1977年接手麦哲伦基金，创造了年均29%的回报率。
- 著名书籍《彼得·林奇的投资课》中提出PEG比率。

#### 1.1.2 林奇的投资哲学
- **价值投资**：寻找被市场低估的公司。
- **成长与估值的平衡**：关注公司未来增长潜力与当前估值。
- **长期投资**：避免短期波动，关注公司长期价值。

#### 1.1.3 PEG比率的重要性
- PEG是林奇选股的核心工具，用于衡量股票的估值与增长潜力。

### 1.2 PEG比率的基本概念

PEG比率（Price Earnings Growth ratio）是衡量股票估值与公司增长潜力的重要指标。

#### 1.2.1 定义
- PEG = 市盈率（PE） / 年增长率（Growth Rate）。
- 公式：$$PEG = \frac{PE}{Growth\ Rate}$$

#### 1.2.2 与PE和PG的关系
- **PE**：市盈率，反映市场对公司估值。
- **PG**：价格与增长率的比值。
- PEG综合考虑了PE和PG，更全面地衡量股票价值。

#### 1.2.3 核心要素
- **市盈率（PE）**：股价除以每股收益。
- **增长率（Growth Rate）**：公司净利润年增长率。
- **PEG比率**：综合PE和Growth Rate的比值。

## 第2章 PEG比率的数学模型与计算

### 2.1 PEG比率的公式推导

#### 2.1.1 PE与Growth Rate的计算
- PE公式：$$PE = \frac{Stock\ Price}{Earnings\ Per\ Share}$$
- Growth Rate公式：$$Growth\ Rate = \frac{Net\ Profit\ Growth}{100}$$

#### 2.1.2 PEG比率的计算
- 将PE除以Growth Rate得到PEG：$$PEG = \frac{PE}{Growth\ Rate}$$

### 2.2 PEG比率的数学模型

#### 2.2.1 PEG比率的公式表示
$$PEG = \frac{PE}{Growth\ Rate}$$

#### 2.2.2 PE与Growth Rate的关系
- 当Growth Rate固定时，PEG与PE成正比。
- 当PE固定时，Growth Rate越高，PEG越小。

### 2.3 PEG比率的计算实例

#### 2.3.1 实例1：公司A的计算
- 市盈率（PE）= 20
- 净利润增长率（Growth Rate）= 10%
- PEG = 20 / 0.10 = 2.0

#### 2.3.2 实例2：公司B的计算
- 市盈率（PE）= 30
- 净利润增长率（Growth Rate）= 15%
- PEG = 30 / 0.15 = 2.0

## 第3章 PEG比率的选股策略

### 3.1 确定目标行业与公司

#### 3.1.1 行业选择标准
- 行业增长潜力：选择高增长行业。
- 行业稳定性：选择具有抗跌性的行业。

#### 3.1.2 公司基本面分析
- 盈利能力：ROE、ROA等指标。
- 偿债能力：资产负债率等指标。
- 发展能力：收入增长率等指标。

### 3.2 计算目标公司的PEG比率

#### 3.2.1 收集财务数据
- 公司过去5年的PE和Growth Rate数据。

#### 3.2.2 计算PEG比率
- 使用公式：$$PEG = \frac{PE}{Growth\ Rate}$$

### 3.3 评估PEG比率的合理性

#### 3.3.1 PEG比率低于1的投资机会
- PEG < 1：股票估值低于市场预期。
- 例子：PEG = 0.8，表示股票被低估。

#### 3.3.2 PEG比率等于1的平衡点
- PEG = 1：股票估值与市场预期一致。
- 例子：PE = 15，Growth Rate = 15%，PEG = 1.

#### 3.3.3 PEG比率高于1的风险分析
- PEG > 1：股票估值可能被高估。
- 例子：PEG = 1.5，表示股票可能被高估。

```python
import pandas as pd
import numpy as np

class CompanyData:
    def __init__(self):
        self.data = pd.DataFrame(columns=['Company', 'PE', 'GrowthRate'])

    def add_company(self, company, pe, growth_rate):
        self.data = self.data.append({'Company': company, 'PE': pe, 'GrowthRate': growth_rate}, ignore_index=True)

    def calculate_peg(self):
        self.data['PEG'] = self.data['PE'] / self.data['GrowthRate']
        return self.data
```
