## 第二部分: 芒格的"数学期望"思维

### 2.1 数学期望的基本概念
数学期望是概率论中的核心概念，表示随机变量在多次试验中平均值的理论值。其计算公式为：
$$ E[X] = \sum_{i=1}^{n} x_i \cdot P(x_i) $$
其中，$x_i$ 是随机变量的取值，$P(x_i)$ 是对应的概率。

### 2.2 芒格思维在金融中的应用
芒格思维在金融中的应用主要体现在投资决策和风险管理方面：
- **投资决策**：通过计算投资的期望收益，选择期望收益最高的投资组合。
- **风险管理**：通过计算风险事件的期望损失，制定相应的风险控制策略。

### 2.3 量子概率与经典概率的对比
量子概率与经典概率的主要区别在于：
- **叠加性**：量子概率允许多个状态的叠加，而经典概率则不考虑状态之间的叠加。
- **纠缠性**：量子概率中的事件可能存在纠缠关系，而经典概率则假设事件是独立的。

import numpy as np
from qiskit import QuantumCircuit, execute, Aer

def quantum_financial_model():
    qc = QuantumCircuit(2, 2)
    qc.h(0)
    qc.cx(0, 1)
    qc.measure(0, 0)
    qc.measure(1, 1)
    backend = Aer.get_backend('qasm_simulator')
    result = execute(qc, backend).result()
    probabilities = result.get_counts()
    return probabilities

quantum_financial_model()
