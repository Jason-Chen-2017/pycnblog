# 第1章: 芒格的"智者圈"理论背景介绍

## 1.1 芒格"智者圈"理论的起源与核心观点

### 1.1.1 芒格投资哲学的核心思想
芒格的"智者圈"理论源于他的投资哲学，强调知识共享和信任机制的重要性。芒格认为，投资决策不仅仅依赖于个人的判断，而是需要构建一个高效的知识网络，通过信息共享和信任积累来优化决策。

### 1.1.2 "智者圈"理论的提出背景
在传统投资网络中，信息传播效率低下，知识共享不充分，导致投资决策容易受到信息偏差和认知局限的影响。芒格提出的"智者圈"理论，旨在通过构建高质量的投资网络，解决这些问题，提升投资决策的质量。

### 1.1.3 理论与实践的结合
芒格通过"智者圈"理论，将投资网络构建与知识共享、信任机制相结合，提出了一个系统化的解决方案，帮助投资者在复杂的投资环境中做出更明智的决策。

## 1.2 "智者圈"理论的核心概念与特点

### 1.2.1 投资网络的定义与属性
投资网络是指由投资者、知识节点、信任关系等组成的网络系统，具有知识共享、信息传播、信任积累等属性。

### 1.2.2 "智者圈"与传统投资网络的对比
| 特性 | 传统投资网络 | "智者圈"投资网络 |
|------|---------------|------------------|
| 信息传播效率 | 低效 | 高效 |
| 知识共享程度 | 有限 | 全面 |
| 信任机制 | 疏弱 | 强化 |

### 1.2.3 理论的边界与外延
"智者圈"理论不仅适用于个人投资者，也适用于机构投资者和投资平台，其外延包括知识管理、信任评估、信息传播等多个方面。

import networkx as nx

def calculate_influence(G):
    influence = {}
    for node in G.nodes():
        influence[node] = sum(G.nodes[node].get('weight', 0) for neighbor in G.neighbors(node))
    return influence

if __name__ == "__main__":
    G = nx.Graph()
    G.add_nodes_from(['I', 'K', 'T'])
    G.add_edges_from([('I', 'K'), ('K', 'T')])
    influence = calculate_influence(G)
