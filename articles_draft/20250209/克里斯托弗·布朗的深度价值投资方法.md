## 第1章: 深度价值投资的核心理念

### 1.1 价值投资的基本概念

#### 1.1.1 投资的定义与核心问题
投资是通过将资金投入特定资产或项目，以期获得未来收益的行为。核心问题包括：
- 如何选择具有长期价值的资产？
- 如何评估资产的内在价值？
- 如何在市场波动中保持理性？

#### 1.1.2 价值投资的起源与发展
价值投资由本杰明·格雷厄姆提出，强调以低于内在价值的价格购买资产。克里斯托弗·布朗继承并发展了这一理念，结合现代数学模型，形成了深度价值投资方法。

#### 1.1.3 深度价值投资的定义与特点
深度价值投资是通过详细分析企业基本面，寻找市场价格低于内在价值的投资机会。其特点是：
- 以基本面分析为基础
- 重视安全边际
- 长期持有优质资产

### 1.2 投资者心态与决策框架

#### 1.2.1 投资者的心理特征
投资者常受情绪影响，容易陷入贪婪和恐惧。深度价值投资要求投资者具备理性思维和耐心。

#### 1.2.2 理性与非理性的投资决策
非理性决策包括追涨杀跌、过度交易等。理性决策基于对企业内在价值的深入分析。

#### 1.2.3 投资决策框架的构建
构建决策框架包括：
1. 明确投资目标
2. 制定估值方法
3. 设定买入和卖出标准
4. 坚持长期投资

### 1.3 价值投资的核心要素

#### 1.3.1 财务报表分析基础
分析资产负债表、利润表和现金流量表，重点关注ROE、净利润、现金流等指标。

#### 1.3.2 企业估值的核心指标
包括市盈率（P/E）、市净率（P/B）、股息率等。

#### 1.3.3 安全边际的定义与作用
安全边际是市场价格与内在价值的差距，确保在市场波动中不会损失本金。

## 第2章: 价值投资的数学模型与算法原理

### 2.1 企业内在价值的计算方法

#### 2.1.1 现金流折现模型（DCF）

现金流折现模型是估算企业内在价值的核心方法，公式如下：

$$
\text{企业价值} = \sum_{t=1}^{n} \frac{\text{自由现金流}_t}{(1 + r)^t} + \frac{\text{终值}}{(1 + r)^n}
$$

其中，$r$是折现率，$n$是预测期数。

#### 2.1.2 市盈率与市净率分析
市盈率（P/E）= 股价 / 每股净利润  
市净率（P/B）= 股价 / 每股净资产

#### 2.1.3 股东权益收益率（ROE）
$$
ROE = \frac{\text{净利润}}{\text{股东权益}}
$$

### 2.2 投资组合优化的数学模型

#### 2.2.1 马科维茨投资组合理论
马科维茨理论通过优化投资组合的收益与风险，提出有效前沿的概念。

#### 2.2.2 现代投资组合理论（MPT）
MPT通过分散投资降低风险，公式如下：

$$
\sigma_p^2 = \sigma_1^2 w_1^2 + \sigma_2^2 w_2^2 + 2w_1 w_2 \sigma_1 \sigma_2 \rho_{12}
$$

其中，$\sigma_p$是组合风险，$w$是权重，$\rho$是相关系数。

#### 2.2.3 风险与收益的平衡
通过夏普比率衡量投资组合的超额收益与承担风险的关系：

$$
\text{夏普比率} = \frac{\text{超额收益}}{\text{标准差}}
$$`

#### 4.2.2 核心代码实现

```python
import pandas as pd
import yfinance as yf

apple = yf.download('AAPL', start='2020-01-01', end='2023-12-31')

# 计算财务指标
def calculate_roe(df):
    roe = df['Net Income'] / df['Total Equity']
    return roe

# 运行DCF模型
def dcf_valuation(df, discount_rate=0.08):
    # 假设自由现金流为净利润 + 非经营性现金流
    fcf = df['Net Income'] + df['Operating Cash Flow']
    # 折现计算
    present_value = sum(fcf / (1 + discount_rate)**i for i in range(len(fcf)))
    return present_value
```
