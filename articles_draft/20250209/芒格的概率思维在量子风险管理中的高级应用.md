# 第2章: 芒格"概率思维"的数学基础

## 2.1 概率论基础

概率论是概率思维的数学基础。以下是概率论的核心概念：

- **概率空间**：由样本空间、事件和概率测度组成。
- **条件概率**：事件A在事件B发生的条件下的概率，公式为：
  $$ P(A|B) = \frac{P(A \cap B)}{P(B)} $$
- **贝叶斯定理**：通过条件概率公式推导出后验概率的公式：
  $$ P(A|B) = \frac{P(B|A)P(A)}{P(B)} $$

---

## 2.2 贝叶斯定理与概率更新

贝叶斯定理在概率更新中具有重要作用，其应用步骤如下：

1. **先验概率**：根据已有信息确定初始概率。
2. **条件概率**：计算新证据出现的概率。
3. **后验概率**：通过贝叶斯定理更新概率信息。

---

## 2.3 量子概率的基本原理

量子概率是量子力学中的基本概念，与经典概率有显著区别。以下是量子概率的核心特征：

- **量子叠加**：粒子的状态可以同时处于多个状态的叠加态。
- **量子纠缠**：多个粒子之间存在纠缠关系，导致概率的相互影响。
- **量子测量**：测量会破坏量子状态，导致概率的不可逆变化。

```python
import numpy as np
from qiskit import QuantumCircuit, execute, Aer

# 定义量子电路
def quantum_risk_assessment(n):
    circuit = QuantumCircuit(n)
    # 添加量子门
    circuit.h(range(n))
    circuit.measure(range(n), range(n))
    return circuit

# 执行量子计算
def run_quantum_circuit(circuit):
    backend = Aer.get_backend('qasm_simulator')
    job = execute(circuit, backend)
    result = job.result()
    probabilities = result.get_counts()
    return probabilities

# 贝叶斯更新
def bayesian_update(prior, likelihood):
    posterior = prior * likelihood / np.sum(prior * likelihood)
    return posterior

# 主函数
def main():
    n = 3  # 量子位数
    circuit = quantum_risk_assessment(n)
    probabilities = run_quantum_circuit(circuit)
    prior = np.array([0.2, 0.3, 0.5])
    likelihood = np.array([0.1, 0.2, 0.7])
    posterior = bayesian_update(prior, likelihood)
    print("后验概率:", posterior)

if __name__ == "__main__":
    main()
```
