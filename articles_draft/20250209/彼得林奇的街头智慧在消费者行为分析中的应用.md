#### 3.2 算法实现
使用Python代码实现需求预测：
```python
import numpy as np
import matplotlib.pyplot as plt

# 数据准备
prices = np.array([10, 20, 30, 40, 50])
quantity = np.array([100, 80, 60, 40, 20])

# 模型训练
def demand_model(prices, quantity):
    params = np.polyfit(prices, quantity, 1)
    return params

params = demand_model(prices, quantity)
a, b = params[0], -params[1]

# 可视化
plt.plot(prices, quantity, 'o')
plt.plot(prices, a + b*prices)
plt.xlabel('Price')
plt.ylabel('Quantity')
plt.show()
```
