## 第一部分: 价值投资的基本概念

### 第1章: 价值投资的定义与背景

#### 1.1 价值投资的定义与背景
- 价值投资是一种以低于内在价值的价格买入优质资产的投资策略。
- 它强调对企业的深入研究，寻找被市场低估的投资标的。
- 价值投资与短期交易不同，更注重长期持有和价值回归。

#### 1.2 价值投资的背景与发展
- 起源于20世纪初，由本杰明·格雷厄姆和戴维德雷曼共同提出。
- 价值投资在20世纪30年代经济大萧条期间被广泛应用于投资实践中。
- 随着时间推移，价值投资方法不断优化，成为长期稳健投资的重要策略。

#### 1.3 价值投资与其他投资方法的对比
- 与趋势投资相比，价值投资更注重基本面分析。
- 与技术分析不同，价值投资关注企业的内在价值。
- 与成长投资相比，价值投资更看重企业的稳健性和安全边际。

## 第3章: 价值投资的核心要素

### 3.1 内在价值的计算方法
- 内在价值是企业未来现金流的现值。
- 使用现金流折现模型（DCF）进行计算。
- 示例：假设企业未来5年的自由现金流分别为100、120、140、160、180万元，折现率设为8%。
- 计算公式：
  $$
  \text{内在价值} = \frac{100}{1.08} + \frac{120}{1.08^2} + \frac{140}{1.08^3} + \frac{160}{1.08^4} + \frac{180}{1.08^5}
  $$

### 3.2 安全边际的概念与应用
- 安全边际 = 内在价值 - 市场价格。
- 通过寻找市场价格低于内在价值的投资标的，降低投资风险。
- 示例：若某股票的内在价值为50元，市场价格为40元，则安全边际为10元。

### 3.3 财务报表分析
- 利润表：分析企业的收入、成本和利润情况。
- 资产负债表：评估企业的资产、负债和所有者权益。
- 现金流量表：了解企业的现金流状况。

### 6.2 核心实现
```python
import pandas as pd
import numpy as np

# 示例：计算内在价值
def calculate_intrinsic_value(fcf, discount_rate):
    present_value = 0
    for year in range(len(fcf)):
        present_value += fcf[year] / (1 + discount_rate) ** (year + 1)
    return present_value

# 示例数据
fcf = [100, 120, 140, 160, 180]
discount_rate = 0.08

intrinsic_value = calculate_intrinsic_value(fcf, discount_rate)
print(f"内在价值为：{intrinsic_value}")
```
