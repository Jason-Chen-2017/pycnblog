```python
def calculate_environment_score(environment_data, weights):
    return sum(w * d for w, d in zip(weights, environment_data))

# 示例数据
environment_data = [85, 90, 75]
weights = [0.4, 0.3, 0.3]
score = calculate_environment_score(environment_data, weights)
print(f"环境评分: {score}")
```

##### 7.2.2 代码解读
函数 `calculate_environment_score` 计算环境评分，输入环境数据和权重，返回评分。示例中，环境数据为 `[85, 90, 75]`，权重为 `[0.4, 0.3, 0.3]`，计算出的环境评分为 83。
