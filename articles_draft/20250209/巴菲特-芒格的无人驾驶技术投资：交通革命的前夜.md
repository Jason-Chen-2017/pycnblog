#### 3.1.1 激光雷达（LiDAR）的工作原理
- LiDAR通过发射激光并测量反射信号的时间差，计算物体的距离和形状。
- 代码示例：
  ```python
  import numpy as np
  def lidar_distance(lidar_data):
      # lidar_data: 数组，存储激光雷达测量的距离值
      distances = []
      for data in lidar_data:
          distance = data['distance']
          distances.append(distance)
      return np.mean(distances)
  ```

- 代码示例：
