## 第2章：价值投资的核心概念

### 2.1 核心概念与联系
- **安全边际**：指股票价格低于其内在价值的程度，确保在市场波动中仍有获利空间。
- **内在价值**：公司未来现金流的现值，计算方法包括股息贴现模型和自由现金流贴现模型。

**概念对比表格**：
| 概念      | 定义                                                                 |
|-----------|--------------------------------------------------------------------|
| 安全边际  | 股票价格与内在价值之间的差距，提供缓冲以应对市场波动。         |
| 内在价值  | 公司未来现金流的现值，反映其真实价值。                             |

## 第3章：价值投资的算法原理

### 3.1 安全边际计算算法
- **算法流程**：
  1. 计算公司的内在价值。
  2. 确定市场价格。
  3. 计算安全边际（内在价值 - 市场价格）。

**Python实现代码**：
```python
def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例
intrinsic_value = 100  # 内在价值
market_price = 80       # 市场价格
margin = calculate_margin_of_safety(intrinsic_value, market_price)
print(f"安全边际为：${margin}")
```

### 3.2 内在价值计算算法
- **股息贴现模型（DDM）**：
  $$ \text{内在价值} = \frac{\text{预期股息}}{\text{折现率} - \text{增长率}} $$

**Python实现代码**：
```python
def calculate_intrinsic_value(dividend, discount_rate, growth_rate):
    return dividend / (discount_rate - growth_rate)

# 示例
dividend = 2.0  # 预期股息
discount_rate = 0.08  # 折现率
growth_rate = 0.02    # 股息增长率
intrinsic_value = calculate_intrinsic_value(dividend, discount_rate, growth_rate)
print(f"内在价值为：${intrinsic_value}")
```

## 第5章：项目实战

### 5.1 环境安装
- 安装Python和必要的库（如pandas、numpy）。

### 5.2 核心实现
```python
class InvestmentStrategy:
    def calculate_intrinsic_value(self, company):
        # 使用DDM计算内在价值
        dividend = company.dividend
        discount_rate = company.discount_rate
        growth_rate = company.growth_rate
        return dividend / (discount_rate - growth_rate)
    
    def calculate_margin_of_safety(self, company):
        return company.intrinsic_value - company.market_price
```
