## 第二部分：彼得林奇的投资策略

### 第2章：彼得林奇的投资理念

#### 2.1 彼得林奇的投资哲学
- **长期投资**：避免短期波动，关注公司长期价值。
- **价值投资**：寻找被市场低估的公司，长期持有。
- **分散投资**：降低风险，避免过度集中。

#### 2.2 彼得林奇的市场分析方法
- **市场周期**：识别市场的牛熊周期，抓住投资机会。
- **行业趋势**：关注行业发展方向，选择朝阳产业。
- **公司基本面**：分析财务报表，评估公司盈利能力。

### 第3章：彼得林奇的选股标准

#### 3.1 高科技股的选股指标
- **市盈率（P/E）**：衡量股票价格与盈利能力的关系。
  $$市盈率 = \frac{股票价格}{每股收益}$$
- **市净率（P/B）**：评估股票价格与账面价值的比率。
  $$市净率 = \frac{股票价格}{每股净资产}$$
- **营收增长率**：反映公司收入增长速度。
  $$营收增长率 = \frac{本年营收增长}{上年营收} \times 100\%$$

#### 3.2 公司竞争力评估
- **技术优势**：公司是否拥有独特的技术或专利。
- **市场地位**：公司是否为行业领导者，市场份额如何。
- **管理团队**：管理层的经验和能力是否可靠。

import pandas as pd
import numpy as np

# 示例代码：计算市盈率和市净率
def calculate_metrics(ticker):
    # 获取数据
    data = pd.DataFrame({'ticker': ticker})
    # 假设我们已经获取了每股收益和每股净资产
    eps = 2.5  # 示例数据
    book_value = 10.0  # 示例数据
    # 计算市盈率和市净率
    pe = data['股票价格'] / eps
    pb = data['股票价格'] / book_value
    return pe, pb

# 应用示例
ticker = 'AAPL'
pe, pb = calculate_metrics(ticker)
print(f"市盈率：{pe}, 市净率：{pb}")
