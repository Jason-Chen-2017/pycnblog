### 第1章: 价值投资的核心理念

#### 1.1 价值投资的基本概念

- **价值投资的定义与核心要素**
  - 价值投资是一种以内在价值为导向的投资方法，关注企业的真实价值而非市场波动。
  - 核心要素包括基本面分析、安全边际和长期视角。

- **托比亚斯·卡尔莱尔的投资哲学**
  - 强调企业内在价值，寻找被市场低估的机会。
  - 通过深入研究企业财务状况、行业地位和竞争优势，识别长期增长潜力。

- **价值投资与成长投资的区别**
  - 价值投资注重安全边际和低估值，而成长投资关注高增长潜力。
  - 两者在风险承受和投资策略上有所不同。

#### 1.2 价值投资的分析框架

- **基本面分析**
  - 资产负债表分析：评估企业的财务健康状况，关注资产质量、负债结构和偿债能力。
  - 利润表分析：分析收入、成本和利润，评估企业的盈利能力和成长性。
  - 现金流量表分析：关注现金流健康，确保企业具备持续经营的能力。

- **技术分析与行业分析**

  - 行业分析：评估行业生命周期、竞争结构和政策环境，选择具有竞争优势的行业。

- **代码实现**

  ```python
  import pandas as pd
  import numpy as np
  import yfinance as yf

  # 下载数据
  df = yf.download(['AAPL', 'MSFT', 'GOOGL'], start='2020-01-01', end='2023-12-31')

  # 计算移动平均线
  df['MA_20'] = df['Adj Close'].rolling(20).mean()
  df['MA_50'] = df['Adj Close'].rolling(50).mean()

  # 生成信号
  df['Signal'] = 0
  df['Signal'][(df['MA_20'] > df['MA_50']) & (df['MA_20'].shift(1) <= df['MA_50'].shift(1))] = 1
  df['Signal'][(df['MA_20'] < df['MA_50']) & (df['MA_20'].shift(1) >= df['MA_50'].shift(1))] = -1

  # 计算收益
  df['Return'] = df['Adj Close'].pct_change() * df['Signal'].shift(1)
  ```

- **代码解读**
  - 下载数据：使用yfinance获取多只股票的数据。
  - 计算移动平均线：使用滚动函数计算20日和50日均线。
  - 生成信号：基于均线交叉策略生成买入（1）和卖出（-1）信号。
  - 计算收益：根据信号计算每日收益。
