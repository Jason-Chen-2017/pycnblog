##### 1.2 巴菲特的价值投资理念
- **价值投资**：寻找市场价格低于内在价值的股票。
- **安全边际**：买入价格低于内在价值，确保安全空间。
- **长期思维**：关注企业的长期价值，而非短期波动。

#### 第5章：巴菲特投资模型的数学解析

##### 5.1 内在价值的计算公式
$$ \text{内在价值} = \sum_{t=1}^{\infty} \frac{C_t}{(1+r)^t} $$
其中，$C_t$是第t年的现金流，$r$是折现率。

##### 5.2 安全边际的计算公式
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

```python
import numpy as np
import pandas as pd

def calculate_intrinsic_value(cash_flows, discount_rate):
    # 计算未来现金流的现值
    present_value = np.sum(cash_flows / (1 + discount_rate)**np.arange(len(cash_flows)))
    return present_value

# 示例数据
cash_flows = [100, 120, 150, 200]
discount_rate = 0.08

intrinsic_value = calculate_intrinsic_value(cash_flows, discount_rate)
print(f"内在价值：{intrinsic_value:.2f}")
```
