## 第三部分：算法原理讲解

### 第4章：协同过滤算法在供应商关系评估中的应用

#### 4.1 协同过滤算法的数学模型
- **协同过滤公式**  
  $$sim(i,j) = \frac{\sum_{k} (r_{ik} - \bar{r_i})(r_{jk} - \bar{r_j})}{\sqrt{\sum_{k}(r_{ik} - \bar{r_i})^2} \sqrt{\sum_{k}(r_{jk} - \bar{r_j})^2}}$$  
  其中，$sim(i,j)$表示供应商i和j之间的相似度，$r_{ik}$和$r_{jk}$分别表示供应商i和j在k个评估指标上的评分，$\bar{r_i}$和$\bar{r_j}$是各自评分的平均值。

#### 4.3 协同过滤算法的Python实现
```python
import numpy as np

def calculate_similarity(matrix):
    n_items, n_users = matrix.shape
    sim = np.zeros((n_users, n_users))
    for i in range(n_users):
        for j in range(n_users):
            if i == j:
                sim[i][j] = 0
                continue
            numerator = np.sum((matrix[:, i] - np.mean(matrix[:, i])) * (matrix[:, j] - np.mean(matrix[:, j])))
            denominator = np.sqrt(np.sum((matrix[:, i] - np.mean(matrix[:, i]))**2)) * np.sqrt(np.sum((matrix[:, j] - np.mean(matrix[:, j]))**2))
            sim[i][j] = numerator / denominator if denominator != 0 else 0
    return sim
```
