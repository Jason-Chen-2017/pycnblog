## 第三章：全球市场分析

### 3.1 市场潜力评估方法
- **数据收集与处理**：通过收集各国的GDP、人口、消费习惯等数据，构建市场潜力评估模型。
- **市场潜力指数模型**：
  $$ P = \sum_{i=1}^{n} (w_i \times f_i) $$
  其中，\( w_i \) 是权重，\( f_i \) 是因素值。

- **Python代码实现**：
  ```python
  import pandas as pd
  data = {'国家': ['A', 'B', 'C'], 'GDP': [100, 200, 150], '人口': [50, 100, 75]}
  df = pd.DataFrame(data)
  df['潜力指数'] = df['GDP'] * 0.6 + df['人口'] * 0.4
  print(df)
  ```
