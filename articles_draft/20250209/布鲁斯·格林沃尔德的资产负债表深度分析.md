### 第一部分: 资产负债表的基本结构与重要性

#### 第1章: 资产负债表的基本概念与重要性

##### 1.1 资产负债表的定义与结构
- **1.1.1 资产负债表的定义**
  - 资产负债表是企业财务状况的静态反映，记录了企业在特定时间点的资产、负债和所有者权益的总额。
- **1.1.2 资产负债表的基本结构**
  - 资产 = 负债 + 所有者权益
  - 资产分为流动资产和非流动资产；负债分为流动负债和非流动负债。
- **1.1.3 资产负债表在企业中的重要性**
  - 评估企业财务健康状况的关键工具。
  - 为投资者、债权人和管理层提供决策依据。

##### 1.2 资产负债表的核心要素
- **1.2.1 资产的定义与分类**
  - 流动资产：现金、应收账款、存货等。
  - 非流动资产：长期投资、固定资产、无形资产等。
- **1.2.2 负债的定义与分类**
  - 流动负债：短期借款、应付账款、应付工资等。
  - 非流动负债：长期借款、应付债券等。
- **1.2.3 所有者权益的定义与分类**
  - 所有者权益包括实收资本、资本公积、盈余公积和未分配利润等。

##### 1.3 资产负债表的编制与作用
- **1.3.1 资产负债表的编制方法**
  - 确保资产和负债的对应关系，平衡借贷方。
  - 根据会计准则进行调整和披露。
- **1.3.2 资产负债表在财务分析中的作用**
  - 评估企业的偿债能力、运营能力和财务稳定性。

##### 1.4 本章小结
  - 资产负债表是财务报表的核心，反映了企业的财务状况。理解其结构和要素是进行深入分析的基础。

#### 第2章: 资产负债表的分析方法

##### 2.1 资产负债表的主要分析指标
- **2.1.1 流动比率**
  - 公式：$$流动比率 = \frac{流动资产}{流动负债}$$
  - 一般认为，流动比率应保持在2:1以上，以确保企业有足够的流动性。
- **2.1.2 速动比率**
  - 公式：$$速动比率 = \frac{速动资产}{流动负债}$$
  - 速动资产包括流动资产减去存货。
- **2.1.3 负债比率**
  - 公式：$$负债比率 = \frac{总负债}{总资产}$$
  - 反映了企业负债在总资产中的比例。

##### 2.2 资产负债表的趋势分析
- **2.2.1 资产负债表的趋势分析方法**
  - 比较不同期间的资产负债表，分析资产、负债和所有者权益的变化趋势。
- **2.2.2 资产负债表趋势分析的注意事项**
  - 考虑通货膨胀、会计政策变化等因素的影响。

##### 2.3 资产负债表的财务健康评估
- **2.3.1 财务健康评估的定义**
  - 通过综合分析企业的财务状况，评估其健康程度。
- **2.3.2 资产负债表在财务健康评估中的应用**
  - 结合其他财务报表（如利润表、现金流量表）进行综合分析。

##### 2.4 本章小结
  - 资产负债表的分析方法多种多样，需要结合具体情况进行综合判断。

#### 第3章: 资产负债表的核心概念与联系

##### 3.1 资产负债表的核心概念
- **3.1.1 资产、负债和所有者权益的定义**
  - 资产是企业拥有的资源，负债是企业的债务，所有者权益是企业净资产。
- **3.1.2 资产负债表的核心要素之间的关系**
  - 资产 = 负债 + 所有者权益

##### 3.2 资产负债表的核心概念对比
- **3.2.1 资产与负债的对比**
  - 资产是企业的资源，负债是企业的债务，两者都是企业的资金来源。
- **3.2.2 负债与所有者权益的对比**
  - 负债需要偿还，所有者权益是投资者对企业净资产的要求权。

- **5.2.2 计算比率**
  ```python
  def calculate_ratios(df):
      current_assets = df['流动资产'].sum()
      current_liabilities = df['流动负债'].sum()
      quick_assets = current_assets - df['存货'].sum()
      
      current_ratio = current_assets / current_liabilities
      quick_ratio = quick_assets / current_liabilities
      liability_ratio = df['总负债'].sum() / df['总资产'].sum()
      
      return {
          '流动比率': current_ratio,
          '速动比率': quick_ratio,
          '负债比率': liability_ratio
      }

  ratios = calculate_ratios(df)
  print(ratios)
  ```
