## 第1章 价值投资与周期性行业概述

### 1.1 价值投资的基本概念  
价值投资是一种以内在价值为核心的投资策略，强调以低于内在价值的价格买入优质资产。其核心理念包括：  
1. **安全边际**：买入价格低于内在价值，以降低风险。  
2. **长期视角**：关注企业的长期盈利能力，而非短期市场波动。  
3. **逆向思维**：在市场恐慌时寻找被低估的机会，在市场狂热时保持冷静。  

### 1.2 周期性行业的定义与特点  
周期性行业是指那些需求和供给受经济波动显著影响的行业，其特点是：  
1. **需求弹性**：需求受经济周期影响较大，景气时需求激增，衰退时需求骤减。  
2. **价格波动**：产品价格受供需关系影响，波动显著。  
3. **周期性风险**：行业业绩波动大，投资风险较高。  

### 1.3 价值投资与周期性行业的关系  
周期性行业的波动性为价值投资者提供了机会，尤其是在行业低谷时买入优质企业，待行业复苏时卖出获利。然而，周期性行业的分析难度较大，需要投资者具备较强的行业分析能力和对经济周期的敏感性。

## 第2章 周期性行业的核心概念与联系

### 2.1 周期性行业的核心概念  
周期性行业可以分为四个阶段：  
1. **复苏阶段**：行业从底部开始回升，需求逐步增加。  
2. **上升阶段**：行业景气度高，企业盈利能力显著提升。  
3. **衰退阶段**：行业需求下降，企业盈利能力减弱。  
4. **底部阶段**：行业处于最低点，需求和价格均处于低位。  

### 2.2 周期性行业的属性特征对比  
周期性行业与非周期性行业的对比如下：  

| 属性 | 周期性行业 | 非周期性行业 |  
|------|------------|---------------|  
| 需求弹性 | 高         | 低             |  
| 价格波动 | 高         | 低             |  
| 投资风险 | 高         | 中             |  
| 景气周期 | 明显       | 不明显         |

## 第3章 行业周期分析的理论基础

### 3.1 经济周期理论  
经济周期理论是分析周期性行业的基础，主要包括以下几个阶段：  
1. **衰退阶段**：经济活动下降，企业盈利减少。  
2. **底部阶段**：经济触底，需求开始回升。  
3. **复苏阶段**：经济逐步恢复，企业盈利改善。  
4. **繁荣阶段**：经济 overheating，企业盈利达到高点。  

### 3.2 行业生命周期模型  
行业生命周期模型将行业分为四个阶段：

### 3.3 行业周期分析的案例研究  
以制造业为例，分析其周期性特征：  
1. **衰退阶段**：市场需求疲软，企业库存积压。  
2. **底部阶段**：企业开始去库存，行业整合。  
3. **复苏阶段**：需求逐步回升，企业订单增加。  
4. **繁荣阶段**：行业景气度高，企业盈利创新高。

# 数据分割

y = data['target']

# 模型训练

model.fit(X, y)

# 模型预测
y_pred = model.predict(X)

# 模型评估
mae = mean_absolute_error(y, y_pred)
print(f'Mean Absolute Error: {mae}')
