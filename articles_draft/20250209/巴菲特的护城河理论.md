## 第3章：护城河的数学模型

### 3.1 护城河强度评分模型
$$ 护城河强度 = \sum_{i=1}^{n} w_i \cdot f_i $$
其中，$w_i$ 是第 $i$ 个因素的权重，$f_i$ 是第 $i$ 个因素的评分。

```python
import numpy as np
import pandas as pd

def calculate_护城河强度(enterprise_data):
    factors = ['成本优势', '品牌忠诚度', '网络效应', '技术壁垒']
    weights = [0.3, 0.4, 0.2, 0.1]
    scores = []
    for data in enterprise_data:
        factor_scores = []
        for i in range(len(factors)):
            if data[i] >= 0.8:
                factor_scores.append(weights[i] * 1)
            else:
                factor_scores.append(weights[i] * 0)
        scores.append(sum(factor_scores))
    return scores
```
