### 第一章：背景介绍

#### 1.1 罗伯特·希勒及其学术贡献
罗伯特·希勒（Robert Shiller）是美国著名经济学家，因其在行为金融学领域的贡献而闻名。他提出了周期调整型价值投资理论，强调市场周期对投资决策的影响。

- **学术背景**：希勒是耶鲁大学的经济学教授，专注于金融市场和行为经济学的研究。
- **理论贡献**：他提出了周期调整市盈率（CAPE）模型，用于评估股票市场的长期价值。

#### 1.2 价值投资的核心理念
价值投资是一种长期投资策略，强调购买被市场低估的资产。希勒的理论指出，投资者应关注市场周期，避免短期波动的干扰。

- **长期视角**：投资决策应基于长期的市场趋势，而非短期市场波动。
- **市场周期**：市场的波动性会影响资产价格，投资者需识别周期变化以优化策略。

---

### 第二章：周期调整型价值投资的核心概念

#### 2.1 周期调整市盈率（CAPE）
周期调整市盈率是一种衡量市场估值的方法，考虑了通货膨胀和市场周期因素。

- **计算公式**：CAPE = 市场总市值 / (GDP平减指数 × 消费者支出)
- **应用**：用于判断市场是否被高估或低估，指导投资决策。

#### 2.2 市场周期与投资策略
市场周期分为牛市和熊市，投资者需根据不同阶段调整策略。

- **牛市策略**：注重长期增长，选择基本面强劲的资产。
- **熊市策略**：寻找被低估的资产，进行长期投资。

### 第五章：项目实战

#### 5.1 环境安装
- **工具**：Python、Pandas、Matplotlib
- **数据源**：Yahoo Finance API

#### 5.2 核心实现代码
以下是计算CAPE的Python代码：

```python
import pandas as pd
import yfinance as yf
import matplotlib.pyplot as plt

# 下载数据
data = yf.download('SPY', start='2000-01-01', end='2023-12-31')

# 计算GDP平减指数和消费者支出（简化版）
gdp_deflator = [100] * len(data)
consumption = [data['Close'].iloc[-1] / 100] * len(data)

# 计算CAPE
market_cap = data['Close'].iloc[-1] * 1000000  # 假设为总市值
cape = market_cap / (gdp_deflator[-1] * consumption[-1])

print(f"周期调整市盈率（CAPE）为：{cape}")
```
