## 第一部分: 魔法公式的背景与基础

### 第1章: 投资的基本概念与魔法公式的起源

#### 1.1 投资的基本概念

- **价值投资**：以低于公平价值的价格购买优质资产，长期持有，等待价值回归。
- **成长投资**：投资于具有持续增长潜力的公司，注重企业的成长性和盈利能力。
- **魔法公式的提出背景**：结合价值与成长投资理念，寻找高ROE（股东权益收益率）和高ROCE（总资本回报率）的优质企业。

#### 1.2 魔法公式的起源

- **乔尔·格林布拉特**：美国著名投资专家，提出魔法公式，旨在筛选出具有高回报潜力的企业。
- **魔法公式的初衷**：通过量化指标筛选出被市场低估的优质企业，实现长期稳定的投资收益。

### 第2章: 魔法公式的核心指标与定义

#### 2.1 核心指标的定义

| 指标名称         | 定义与计算公式                                      |
|------------------|---------------------------------------------------|
| 股息率           | 股票年度股息/股票价格，衡量企业分红能力。          |
| 股价与账面价值比 | 股票价格/账面价值，衡量资产的市场估值与实际价值。 |
| 营业利润率       | 营业利润/营业收入，衡量企业的盈利能力。            |
| 股东权益收益率   | 净利润/平均股东权益，衡量股东投资回报能力。      |
| 总资本回报率     | 净利润/总资本，衡量企业整体资本使用效率。        |

#### 2.2 魔法公式的数学模型

$$ \text{魔法公式得分} = \frac{\text{ROE}}{\text{ROCE}} \times \left(1 - \frac{\text{股息率}}{2} \right) $$

其中：
- ROE：股东权益收益率
- ROCE：总资本回报率
- 股息率：股息与股价的比率

### 第6章: 项目实战

#### 6.1 环境安装

- 安装Python和相关库（如pandas、numpy）。

#### 6.2 核心实现代码

```python
import pandas as pd

def calculate_roe(net_profit, avg_equity):
    return net_profit / avg_equity

def calculate_roce(net_profit, total_capital):
    return net_profit / total_capital

def magic_formula_score(roe, roce, dividend_yield):
    return (roe / roce) * (1 - dividend_yield / 2)

# 示例数据
data = {
    'net_profit': [100, 200, 300],
    'avg_equity': [500, 600, 700],
    'total_capital': [800, 900, 1000],
    'dividend_yield': [2, 3, 4]
}

df = pd.DataFrame(data)
df['ROE'] = df.apply(lambda x: calculate_roe(x['net_profit'], x['avg_equity']), axis=1)
df['ROCE'] = df.apply(lambda x: calculate_roce(x['net_profit'], x['total_capital']), axis=1)
df['Magic Formula Score'] = df.apply(lambda x: magic_formula_score(x['ROE'], x['ROCE'], x['dividend_yield']), axis=1)
print(df)
```

#### 6.3 案例分析

- 使用示例数据计算魔法公式得分，筛选出得分最高的企业进行投资。
