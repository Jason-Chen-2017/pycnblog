### 1.1 彼得林奇的生平与投资理念

在现代商业环境中，公司面临着复杂多变的市场环境，包括技术变革、全球经济波动和竞争加剧。长期战略分析是企业在不确定环境中制定可持续增长计划的关键。彼得林奇的分析方法提供了一套系统化的工具，帮助投资者和企业识别长期机会和风险。

### 1.3 问题描述与解决方法

企业长期战略的核心问题在于如何在变化的环境中保持竞争力和盈利能力。彼得林奇的方法通过详细分析财务指标、行业趋势和竞争优势，提供了一个结构化的解决方案，帮助投资者识别具有长期增长潜力的公司。

### 3.2 Python代码实现

```python
import pandas as pd

def calculate_roe(df):
    roe = df['净利润'] / df['平均股东权益']
    return roe

# 示例数据
data = {
    '公司': ['A', 'B', 'C'],
    '净利润': [10, 15, 20],
    '平均股东权益': [50, 30, 40]
}
df = pd.DataFrame(data)

# 计算ROE
roe = calculate_roe(df)
print(roe)
```

### 3.3 数学模型和公式

净资产收益率（ROE）的计算公式为：
$$ \text{ROE} = \frac{\text{净利润}}{\text{平均股东权益}} $$

毛利率计算公式为：
$$ \text{毛利率} = \frac{\text{营业收入} - \text{营业成本}}{\text{营业收入}} \times 100\% $$
