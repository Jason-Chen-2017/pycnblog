## 1.1 系统性风险的定义与特点

系统性风险是指金融体系中某些重大风险事件可能引发连锁反应，导致整个金融系统崩溃的风险。其特点包括：

- **系统性**：风险可能从一个局部迅速蔓延至整个金融系统。
- **复杂性**：涉及多个金融机构、市场和经济主体，风险传导路径复杂。
- **不可预测性**：系统性风险往往源于难以预测的事件或市场行为。

# 第2章：图表示学习的核心概念与算法原理

## 2.1 图表示学习的核心概念

图表示学习的关键概念包括：

- **节点嵌入（Node Embedding）**：将图中的每个节点表示为低维向量，反映其在图中的位置和关系。
- **图嵌入（Graph Embedding）**：将整个图的结构信息表示为低维向量，用于图级别的任务。
- **邻接矩阵（Adjacency Matrix）**：表示图中节点之间关系的矩阵。

## 2.2 图表示学习算法原理

### 2.2.1 Node2Vec算法

Node2Vec是一种基于随机游走的图表示学习算法，其核心思想是通过生成节点的上下文表示，学习节点的嵌入向量。具体步骤如下：

1. **随机游走**：在图中进行随机游走，生成节点的上下文序列。
2. **训练模型**：使用 skip-gram 模型，基于上下文序列训练嵌入向量。

**公式：**
- 邻接矩阵表示：$A_{ij} = 1$ 表示节点 $i$ 和 $j$ 之间存在边。
- 嵌入向量：$v_i$ 表示节点 $i$ 的嵌入向量。

### 2.2.2 GraphSAGE算法

GraphSAGE是一种基于归纳式图表示学习算法，通过聚合邻居节点的嵌入向量，生成节点的嵌入表示。具体步骤如下：

1. **初始化嵌入向量**：为每个节点初始化一个随机嵌入向量。
2. **聚合邻居信息**：通过聚合函数（如平均、最大值）生成新的嵌入向量。
3. **更新嵌入向量**：重复上述步骤，直到达到预设的迭代次数。

**公式：**
- 聚合函数：$h_i^{(l+1)} = \text{AGGREGATE}(h_i^{(l)}, \{h_j^{(l)}\})$，其中 $j$ 是节点 $i$ 的邻居节点。

### 5.2.2 图构建与表示学习

```python
import networkx as nx

# 构建图
G = nx.Graph()
for i in range(len(data_filled)):
    for j in range(i+1, len(data_filled)):
        if data_filled[i][j] > 0.5:
            G.add_edge(i, j)

# 使用Node2Vec训练嵌入向量
from node2vec import Node2Vec

model = Node2Vec(G, walks_per_node=10, num_walks=10)
model.fit()
embeddings = model.get_embeddings()
```
