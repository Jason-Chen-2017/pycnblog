- 3.2.1 内在价值计算公式
  $$内在价值 = \sum_{t=1}^{\infty} \frac{CF_t}{(1 + r)^t}$$
- 3.2.2 市场价格与内在价值的比较
  $$市场价格 < 内在价值 \Rightarrow 投资机会$$
- 3.2.3 竞争优势评估模型
  $$竞争优势强度 = \sum_{i=1}^{n} w_i \cdot score_i$$

  import pandas as pd
  import numpy as np

  def calculate_intrinsic_value(financial_data, discount_rate):
      # 计算自由现金流
      fcfs = financial_data['Free Cash Flow'].values
      # 计算内在价值
      iv = np.nansum(fcfs / (1 + discount_rate) ** np.arange(len(fcfs)))
      return iv
  ```

  def assess_competitive_advantage(enterprise_data):
      # 定义竞争优势评分标准
      criteria = ['ROE', 'ROA', 'Net Margin', 'Gross Margin']
      weights = [0.4, 0.3, 0.2, 0.1]
      # 计算评分
      scores = [enterprise_data[c].mean() for c in criteria]
      weighted_scores = sum(w * s for w, s in zip(weights, scores))
      return weighted_scores
  ```
