#### ### 4.2.2 量子加密算法的代码实现
```python
from qiskit import QuantumCircuit, execute, Aer

# 创建量子电路
qc = QuantumCircuit(2, 2)

# 定义量子密钥分发协议
def qkd_circuit():
    # 创建Bell态
    qc.h(0)
    qc.cnot(0, 1)
    qc.measure_all()
    return qc

# 执行量子电路
backend = Aer.get_backend('qasm_simulator')
job = execute(qkd_circuit(), backend)
result = job.result()

# 获取结果
print(result.get_counts())
```
