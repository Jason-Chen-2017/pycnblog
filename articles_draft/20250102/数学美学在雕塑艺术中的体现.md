### 3.3 数学模型和公式

黄金比例公式：$$\frac{a+b}{a} = \frac{a}{b} = \frac{1+\sqrt{5}}{2}$$

其中，$a$ 和 $b$ 分别表示相邻两段长度。

### 3.4 详细讲解与举例说明

#### 详细讲解

黄金比例是数学美学中的一个重要概念，它广泛应用于雕塑艺术中。公式 $$\frac{a+b}{a} = \frac{a}{b} = \frac{1+\sqrt{5}}{2}$$ 描述了两个相邻长度的比例关系。

#### 举例说明

假设一个雕塑作品由两段长度分别为 $a$ 和 $b$ 的部分组成，且 $a$ 的长度为 10cm，根据黄金比例公式，$b$ 的长度应为 6cm（因为 $\frac{10+6}{10} = \frac{10}{6} = \frac{1+\sqrt{5}}{2}$）。

import numpy as np
import matplotlib.pyplot as plt

def calculate_proportion(length):
    golden_ratio = (1 + np.sqrt(5)) / 2
    proportion = length / golden_ratio
    return proportion

def plot_proportion(length, proportion):
    x = np.linspace(0, length, 1000)
    y = x / proportion
    plt.plot(x, y)
    plt.xlabel('Length')
    plt.ylabel('Proportion')
    plt.title('Proportion Plot')
    plt.show()

if __name__ == '__main__':
    length = 10
    proportion = calculate_proportion(length)
    plot_proportion(length, proportion)
