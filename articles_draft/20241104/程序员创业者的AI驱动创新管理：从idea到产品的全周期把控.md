```python
# 伪代码：线性回归模型
def linear_regression(X, y):
    # 计算权重
    theta = (X.T * X).inv() * (X.T * y)
    # 计算损失函数
    loss = (-1 / len(X)) * (y - X * theta).T * (y - X * theta)
    return theta, loss
```
