**Python源代码**：

```python
import networkx as nx
import matplotlib.pyplot as plt

# 初始化网络
G = nx.igraph.Graph()

# 添加节点和边
G.add_nodes_from(['User1', 'User2', 'User3'])
G.add_edges_from([('User1', 'User2'), ('User2', 'User3')])

# 定义用户接收信息的概率
prob = 0.5

# 初始化用户状态
user_status = {'User1': 'Uninformed', 'User2': 'Uninformed', 'User3': 'Informed'}

# 用户接收到信息的函数
def receive_info(user):
    return user_status[user] == 'Informed'

# 用户状态更新的函数
def update_status(user):
    if receive_info(user):
        user_status[user] = 'Informed'

# 更新网络结构的函数
def update_network():
    # 根据用户状态更新网络边
    for user in user_status:
        if user_status[user] == 'Informed':
            G.add_edges_from([(user, neighbor) for neighbor in G.neighbors(user)])

# 运行模型
for _ in range(10):
    # 随机选择用户
    user = random.choice(list(user_status.keys()))
    # 更新用户状态
    update_status(user)
    # 更新网络结构
    update_network()

# 绘制网络图
nx.draw(G, with_labels=True)
plt.show()
```

**数学模型和公式**：

1. **随机游走模型**：

   $$ P(\text{User } i \text{ receives information}) = p $$

   其中，$p$ 为用户接收到信息的概率。

2. **网络传播模型**：

   $$ \text{Propagation rate} = \alpha \cdot \frac{\text{Number of informed neighbors}}{\text{Total neighbors}} $$

   其中，$\alpha$ 为传播速度参数。

3. **考虑用户行为的传播模型**：

   $$ \text{Influence of User } i = \beta \cdot \text{Behavior factor of User } i $$

   其中，$\beta$ 为行为影响力参数。

**举例说明**：假设有一个包含 3 个用户的小网络，其中 1 个用户已经接收到信息。在 10 次迭代中，观察用户状态的演变和网络结构的变化。
