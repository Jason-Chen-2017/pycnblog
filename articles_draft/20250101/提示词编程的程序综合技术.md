
#### 2.2 控制结构

控制结构用于控制程序的执行流程。在提示词编程中，常用的控制结构有条件语句和循环语句。

##### 2.2.1 条件语句

条件语句用于根据某个条件的真假来执行不同的代码块。以下是一个简单的条件语句示例：

```python
if x > 10:
    print("x 大于 10")
elif x == 10:
    print("x 等于 10")
else:
    print("x 小于 10")
```

##### 2.2.2 循环语句

循环语句用于重复执行某个代码块。在提示词编程中，常用的循环语句有for循环和while循环。

- **for循环**：

```python
for i in range(5):
    print(i)
```

- **while循环**：

```python
x = 0
while x < 5:
    print(x)
    x += 1
```

#### 2.3 函数与模块

函数是一段可以重复调用的代码块，而模块则是用于组织代码的文件。在提示词编程中，函数和模块是编写可复用代码的重要手段。

##### 2.3.1 函数的定义与调用

以下是一个简单的函数示例：

```python
def greet(name):
    return "Hello, " + name

print(greet("Alice"))  # 输出：Hello, Alice
```

##### 2.3.2 模块的导入与使用

模块是用于组织代码的文件，可以通过导入模块来使用其中的函数和类。以下是一个简单的模块示例：

- `module1.py`：

```python
def add(a, b):
    return a + b
```

- 使用模块：

```python

result = add(3, 4)
print(result)  # 输出：7
```

#### 2.4 错误处理与调试技巧

错误处理是编程中非常重要的一环，它可以帮助我们识别和修复代码中的错误。在提示词编程中，常用的错误处理方法有异常处理和调试。

##### 2.4.1 错误类型

常见的错误类型有语法错误、逻辑错误和运行时错误等。

- **语法错误**：语法错误是代码中违反编程语言规则的错误，例如拼写错误、缺少括号等。
- **逻辑错误**：逻辑错误是代码中逻辑错误导致的错误，例如循环条件不正确、变量未初始化等。
- **运行时错误**：运行时错误是在程序运行过程中发生的错误，例如文件未找到、内存溢出等。

##### 2.4.2 错误处理方法

错误处理方法主要包括以下几种：

- **异常处理**：使用try-except语句捕获并处理异常，例如：

```python
try:
    # 可能会引发异常的代码
except Exception as e:
    # 处理异常
    print("发生异常：", e)
```

- **调试**：使用调试工具（如IDE的调试功能）来识别和修复代码中的错误，例如设置断点、查看变量值等。

##### 2.4.3 调试技巧

以下是几种常用的调试技巧：

- **设置断点**：在代码中设置断点，可以让程序在断点处暂停执行，方便我们查看当前状态。
- **单步执行**：单步执行可以让程序逐行执行，帮助我们理解程序执行过程。
- **查看变量值**：在调试过程中，可以查看变量的当前值，帮助我们识别和解决问题。
