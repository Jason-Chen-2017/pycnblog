```python
# 沟通技巧模块
class CommunicationSkills:
    def express_intention(self, intention):
        if intention == "positive":
            return "正面回应"
        elif intention == "negative":
            return "调整表达"
        else:
            return "无法理解意图"

# 语音表达模块
class VocalExpression:
    def express_verbally(self, content):
        print(content)

# 肢体语言模块

    def express_physically(self, action):
        print(action)
```

在这个案例中，我们首先创建了一个沟通技巧对象，并调用其`express_intention`方法表达了一个积极的意图。然后，我们创建了一个语音表达对象和一个肢体语言对象，分别调用它们的`express_verbally`和`express_physically`方法进行口头和身体动作的表达。
