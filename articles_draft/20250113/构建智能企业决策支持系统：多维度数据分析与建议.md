### 算法原理

决策树算法是一种常用的机器学习算法，通过树形结构对数据进行分类或回归。决策树的核心是节点划分，即在每个节点选择一个特征进行划分，使得分类或回归效果最好。

### 算法原理详细讲解

1. **特征选择**：选择一个特征进行划分，使得分类或回归效果最好。常见的特征选择方法有信息增益、基尼系数等。
2. **节点划分**：根据选定的特征，将数据集划分为多个子集。每个子集对应一个节点。
3. **递归构建**：对每个子集继续进行特征选择和节点划分，直到满足停止条件（如节点纯度达到一定程度或节点数量达到最大值）。
4. **分类或回归**：根据决策树的叶子节点，对新的数据进行分类或回归。

### 算法原理举例说明

假设有一个数据集，包含三个特征：年龄、收入和职业。我们可以选择年龄作为划分特征，将数据集划分为两个子集：年轻人（年龄小于30岁）和中年人（年龄大于等于30岁）。然后，我们可以选择收入作为划分特征，将中年人子集进一步划分为低收入群体和高收入群体。最后，我们可以选择职业作为划分特征，将年轻人子集进一步划分为工人、学生和白领。根据这些划分，我们可以建立一个决策树模型，对新的数据进行分类。

import pandas as pd

# 加载数据集
data = pd.read_csv('data.csv')

# 数据清洗

# 特征提取
X = data[['age', 'income', 'occupation']]
y = data['label']

# 训练模型
from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier()
model.fit(X, y)

# 预测结果
predictions = model.predict(X)

# 输出结果
print(predictions)
