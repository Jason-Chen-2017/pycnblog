#### 3.2 LLM的核心技术

### 数学模型和数学公式

$$
H = \frac{1}{N} \sum_{i=1}^{N} \frac{1}{L_i} \log P(y_i | \theta)
$$

其中，$H$ 表示模型在数据集上的损失，$N$ 表示数据集中的样本数，$L_i$ 表示第 $i$ 个样本的长度，$y_i$ 表示第 $i$ 个样本的标签，$P(y_i | \theta)$ 表示在参数 $\theta$ 下预测为标签 $y_i$ 的概率。

def evaluate_model(model, x_test, y_test):
    y_pred = model.predict(x_test)
    y_pred = np.argmax(y_pred, axis=1)
    accuracy = accuracy_score(y_test, y_pred)
    return accuracy

# 运行评测
