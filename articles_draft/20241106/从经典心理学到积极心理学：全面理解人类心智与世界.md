#### 核心算法原理讲解：认知心理学算法原理伪代码

```python
# 认知心理学算法：感知与知觉模型

# 输入：感知信号（s），感知阈值（threshold）
# 输出：知觉结果（perception）

def perception_model(s, threshold):
    if s > threshold:
        perception = "察觉到"
    else:
        perception = "未察觉到"
    return perception

# 举例说明
signal = 50
threshold = 30
result = perception_model(signal, threshold)
print(result)  # 输出："察觉到"
```
