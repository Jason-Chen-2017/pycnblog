```python
    activations = []
    for layer in range(number_of_layers):
        z = np.dot(inputs, weights[layer])
        activations.append(activation_function(z))
    return activations

# 反向传播伪代码
def backward_propagation(activations, expected_outputs, weights):
    deltas = []
    for layer in reversed(range(number_of_layers)):
```

- 全局解释方法：通过全局视角来解释模型行为。

**技术原理**：
- 局部解释方法：包括LIME、SHAP等。
- 全局解释方法：包括模型简化、可视化等。

**伪代码**：

```python
# LIME伪代码
def lime_explanation(inputs, model):
    local_model = create_local_model(inputs, model)

    return explanation

# SHAP伪代码
def shap_explanation(inputs, model):
```
