# 第二章：全球股市估值的核心原理  

## 2.1 股市估值的基本方法  
### 2.1.1 市盈率（P/E）的计算与应用  
市盈率 = 股价 / 每股净利润。例如，若股价为100元，每股净利润为10元，则市盈率为10。  

### 2.1.2 市净率（P/B）的计算与应用  
市净率 = 股价 / 每股净资产。例如，股价为50元，每股净资产为20元，则市净率为2.5。  

### 2.1.3 股息率的计算与应用  
股息率 = 每股股息 / 股价。例如，每股股息为2元，股价为20元，则股息率为10%。  

## 2.2 影响股市估值的主要因素  
### 2.2.1 宏观经济因素  
- 利率水平：低利率环境通常推高股市估值。  
- 经济增长：经济繁荣时，企业盈利增加，股市估值上升。  

### 2.2.2 行业发展趋势  
- 技术创新：推动行业增长，提高企业估值。  
- 市场竞争：竞争加剧可能导致估值下降。  

### 2.2.3 公司基本面分析  
- 盈利能力：净利润率高的公司通常有较高的估值。  
- 债务水平：高负债公司风险较大，估值可能较低。  

## 2.3 主流股市指数分析  
### 2.3.1 标普500指数  
标普500指数代表美国500家大型企业的股价表现，是全球最重要的股市指数之一。  

### 2.3.2 恒生指数  
恒生指数是香港股市的重要指数，反映了香港主要企业的股价走势。  

### 2.3.3 欧洲Stoxx指数  
Stoxx指数涵盖欧洲多个国家的蓝筹股，是衡量欧洲股市的重要指标。
