## 第一部分: 代表性偏差的背景与概述

### 第1章: 代表性偏差概述

#### 1.1 代表性偏差的定义与核心概念
- **认知偏差的基本概念**：认知偏差是指人们在处理信息时，由于认知限制或情绪影响，导致的系统性错误判断。
- **代表性偏差的定义**：代表性偏差是指人们根据片面信息或样本特征，过度推断整体特征，从而做出不准确判断。
- **代表性偏差的核心要素与属性特征**：
  - 部分信息驱动判断
  - 忽视概率和统计规律
  - 易受情绪和经验影响

#### 1.2 代表性偏差在投资中的具体表现
- **投资者的典型误区**：
  - 过度依赖市场趋势
  - 忽略行业周期性
  - 仅关注历史业绩
- **对投资决策的影响**：
  - 导致非理性决策
  - 增加投资风险
  - 降低投资回报率
- **常见认知误区**：
  - 简单线性思维
  - 过度自信
  - 忽略复杂性

#### 1.3 代表性偏差的成因与影响
- **成因分析**：
  - 人类认知的局限性
  - 信息不完全性
  - 心理偏差的影响
- **对投资结果的影响**：
  - 投资决策失误
  - 财务损失
  - 投资组合风险增加

#### 1.4 代表性偏差的边界与外延
- **与其他认知偏差的区别**：
  - 与确认偏差、从众偏差等对比
- **在不同投资场景中的表现**：
  - 股票投资、基金投资、风险投资
- **适用范围与限制**：
  - 适用于基于经验判断的投资场景
  - 不适用于完全理性分析的场景

## 第3章: 算法原理与数学模型

### 3.1 算法原理
- **贝叶斯定理的应用**：
  - 通过条件概率更新投资判断
  - ```mermaid
    graph TD
      A[初始概率] --> B[新证据]
      B --> C[更新概率]
      C --> D[投资决策]
    ```
  - Python代码示例：
    ```python
    def bayesian_inference(initial_prob, likelihood, evidence_prob):
        return (initial_prob * likelihood) / evidence_prob
    ```

### 3.2 数学模型
- **概率计算公式**：
  - 初始概率：$P(A)$
  - 似然度：$P(B|A)$
  - 全概率：$P(B) = \sum P(B|A_i)P(A_i)$
  - 后验概率：$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
