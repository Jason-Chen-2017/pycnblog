### 第一部分：逆向投资概述

#### 第1章：逆向投资的核心概念

##### 1.1 逆向投资的定义与特点

- **1.1.1 逆向投资的定义**
  逆向投资是一种投资策略，指的是在市场低迷、投资者情绪低落时买入，而在市场高涨、投资者情绪高涨时卖出。与顺势投资不同，逆向投资强调逆市场情绪操作。

- **1.1.2 逆向投资的核心特点**
  - **非趋势性**：逆向投资不依赖于市场的短期趋势，而是关注于基本面和长期价值。
  - **逆市场情绪**：在市场恐慌时买入，市场狂热时卖出。
  - **风险承受能力**：需要较强的心理素质和风险承受能力，因为常常需要在市场低谷时买入，而在市场高点时卖出。

- **1.1.3 逆向投资与传统投资的区别**
  - **传统投资**：依赖于技术分析和市场趋势，追求短期收益。
  - **逆向投资**：关注长期价值，逆市场情绪操作，注重风险控制。

##### 1.2 彼得·林奇的投资哲学

- **1.2.1 彼得·林奇的选股标准**
  - **公司基本面**：关注公司的财务状况、盈利能力、行业地位。
  - **管理层质量**：管理层是否稳健、有经验。
  - **估值**：公司股价是否低于其内在价值。

- **1.2.2 彼得·林奇的投资策略**
  - **长期持有**：注重长期投资，避免频繁交易。
  - **分散投资**：通过分散投资降低风险。

- **1.2.3 彼得·林奇的投资风格**

import numpy as np

def calculate_market_sentiment(data):
    # 计算恐慌指数
    # 这里简化的实现，实际可能需要更复杂的算法
    return np.mean(data['returns'].std())

def evaluate_company_value(company_data):
    # 评估公司价值，这里简化为市盈率
    pe_ratio = company_data['price'] / company_data['earnings_per_share']
    return pe_ratio

# 示例数据

        'earnings_per_share': [10, 12, 15, 8, 6]}

company_value = evaluate_company_value(df.iloc[-1])
