#### 第5章: 管理层决策一致性的算法原理

##### 5.1 算法原理的数学模型
- **5.1.1 决策一致性评分公式**  
  $$C = \frac{\sum_{i=1}^{n} w_i \cdot s_i}{\sum_{i=1}^{n} w_i}$$  
  其中，\(C\) 为一致性评分，\(w_i\) 为决策的权重，\(s_i\) 为评分。

##### 5.2 算法实现
- **5.2.1 算法步骤**  
  1. 收集管理层决策数据。  
  2. 确定决策权重。  
  3. 计算一致性评分。  

- **5.2.2 算法实现的Python代码**  
  ```python
  def calculate_consistency_score(decisions, weights):
      weighted_scores = [decision * weight for decision, weight in zip(decisions, weights)]
      total_weight = sum(weights)
      return sum(weighted_scores) / total_weight

  decisions = [0.8, 0.7, 0.9]
  weights = [0.3, 0.4, 0.3]
  score = calculate_consistency_score(decisions, weights)
  print(f"一致性评分：{score}")
  ```
