# 第1章：全球股市估值的现状与挑战

## 1.1 全球股市估值的基本概念

### 1.1.1 股市估值的定义与意义
股市估值是通过特定的金融模型和方法，对企业的内在价值进行评估的过程，是投资者决策的重要依据。 $$ V = \text{企业价值} = \text{净利润} \times \text{市盈率} $$

### 1.1.2 股市估值的主要方法
- **相对估值法**：基于市场可比公司进行比较，如市盈率（P/E）和市净率（P/B）。
- **绝对估值法**：基于企业未来现金流的折现，如 discounted cash flow (DCF) 模型。

### 1.1.3 全球股市估值的现状分析
近年来，全球股市估值受经济波动、政策变化和技术创新的影响，呈现多样化趋势。 $$ S = \text{股票价格} = \text{企业价值} - \text{债务} $$

---

## 1.2 股市估值的核心影响因素

### 1.2.1 经济周期与股市估值的关系
经济周期直接影响企业的盈利能力和投资者信心，进而影响股市估值。 $$ \text{GDP增长率} \propto \text{股市估值变化} $$

### 1.2.2 利率政策对股市估值的影响
低利率环境通常会推高股市估值，因为资金成本降低，企业融资更容易。 $$ r \downarrow \Rightarrow V \uparrow $$

### 1.2.3 企业盈利能力和股市估值的关联
企业盈利能力是股市估值的核心驱动力，高盈利能力通常意味着高估值。 $$ \text{ROE} \uparrow \Rightarrow P/E \uparrow $$

# 第2章：小型模块化核反应堆技术的核心概念

## 2.1 小型模块化核反应堆的定义与分类

### 2.1.1 小型模块化核反应堆的定义
小型模块化核反应堆（SMR）是功率在300 MW以下的核反应堆，具有模块化设计和可扩展性。

### 2.1.2 按用途分类的小型模块化核反应堆类型
- **电力生产型**：主要用于发电。
- **热能利用型**：用于工业加热和制氢。

### 2.1.3 按技术路线分类的小型模块化核反应堆类型
- **轻水堆**：使用轻水作为冷却剂。
- **重水堆**：使用重水作为冷却剂。

---

## 2.2 小型模块化核反应堆的技术优势

### 2.2.1 技术优势：安全性、灵活性与可扩展性
SMR设计采用非能动安全系统，简化了操作和维护。

### 2.2.2 经济优势：成本低、周期短
SMR的建造周期短，适合分期建设和扩展。

### 2.2.3 环境优势：低碳排放与核废料处理
SMR的碳排放低，且核废料处理技术更加成熟。

```python
def predict_stock_price(data):
    # 数据预处理
    from sklearn.preprocessing import MinMaxScaler
    scaler = MinMaxScaler()
    data_scaled = scaler.fit_transform(data)
    
    # 模型训练
    from sklearn.neural_network import MLPRegressor
    model = MLPRegressor(hidden_layer_sizes=(100, 10))
    model.fit(data_scaled[:-1], data_scaled[1:])
    
    # 预测
    prediction = model.predict(data_scaled[-1].reshape(1, -1))
    return scaler.inverse_transform(prediction)
```
