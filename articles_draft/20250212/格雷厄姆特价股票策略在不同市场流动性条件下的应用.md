# 第一部分: 格雷厄姆特价股票策略概述

## 第1章: 格雷厄姆投资理念的核心思想

### 1.1 价值投资的基本概念

- **价值投资**：寻找市场价格低于其内在价值的股票进行投资。
- **安全边际**：买入价格低于内在价值，确保投资的安全性。
- **特价股票**：市场价格远低于其内在价值的股票，具有较高的投资潜力。

### 1.2 市场流动性对股票价格的影响

- **市场流动性**：指在不显著影响价格的情况下，交易资产的数量。
- **流动性不足**：买卖价差大，交易成本高，价格波动剧烈。
- **流动性过剩**：买卖价差小，交易成本低，价格稳定。

### 1.3 格雷厄姆策略与市场流动性的结合

- **高流动性市场**：交易活跃，价格反映真实价值，适合长期投资。
- **低流动性市场**：价格波动大，存在套利机会，适合短期操作。
- **策略优化**：根据市场流动性调整筛选条件，优化投资组合。

## 第2章: 核心概念与联系

### 2.1 核心概念原理

- **格雷厄姆策略公式**：
  - 内在价值 = 股票的未来现金流的现值。
  - 计算公式：$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$
    - \( V \)：内在价值。
    - \( CF_t \)：第t年的现金流。
    - \( r \)：折现率。
- **流动性影响因子**：流动性不足时，调整折现率，增加风险溢价。

| 价格波动      | 稳定                 | 剧烈                 |
| 投资策略      | 长期持有             | 短期套利             |

# 第二部分: 数学模型与公式推导

## 第4章: 数学模型与公式

### 4.1 格雷厄姆策略的数学模型

- **内在价值计算公式**：
  $$V = \frac{E}{1 + g} + \frac{D}{1 + g}$$
  - \( E \)：企业未来现金流。
  - \( g \)：现金流增长率。
  - \( D \)：债务。

### 4.2 流动性影响的数学模型

- **流动性指数公式**：
  $$LI = \frac{V_a - V_b}{V_b} \times 100\%$$
  - \( V_a \)：买价。
  - \( V_b \)：卖价。

## 第6章: 项目实战

### 6.1 环境安装

- **工具**：Python、Jupyter Notebook、pandas、numpy。

### 6.2 核心代码实现

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(enterprise_value, growth_rate):
    return enterprise_value / (1 + growth_rate)

def calculate_liquidity_index(ask_price, bid_price):
    return (ask_price - bid_price) / bid_price * 100

# 示例数据
data = {
    'enterprise_value': [100, 200, 300],
    'growth_rate': [0.05, 0.03, 0.02],
    'ask_price': [10, 20, 30],
    'bid_price': [9, 18, 27]
}

df = pd.DataFrame(data)

# 计算内在价值
df['intrinsic_value'] = df.apply(lambda x: calculate_intrinsic_value(x['enterprise_value'], x['growth_rate']), axis=1)

# 计算流动性指数
df['liq_index'] = df.apply(lambda x: calculate_liquidity_index(x['ask_price'], x['bid_price']), axis=1)

print(df)
```
