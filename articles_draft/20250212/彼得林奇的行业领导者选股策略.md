```python
def evaluate_company(data):
    # 计算市盈率
    data['PE'] = data['市场价格'] / data['每股收益']
    # 计算市净率
    data['PB'] = data['市场价格'] / data['每股净资产']
    return data
```

##### 4.2.3 投资策略模块  
```python
def select_industry_leaders(data):
    leaders = data[(data['PE'] < data['PE'].mean()) &
                    (data['PB'] < data['PB'].mean())]
    return leaders
```
