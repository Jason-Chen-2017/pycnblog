# 第二部分: "街头智慧"的核心概念与数学模型

## 第4章: 投资决策中的数学模型与公式

### 4.1 常用投资数学模型概述
市盈率和市净率是衡量公司价值的重要指标，资本资产定价模型（CAPM）用于评估预期收益。

#### 4.1.1 市盈率与市净率的计算
市盈率=股价/每股收益，市净率=股价/每股净资产。

#### 4.1.2 预期收益与风险的数学表达
CAPM模型：R = Rf + β*(Rm - Rf)。

#### 4.1.3 资本资产定价模型(CAPM)
评估资产的预期收益，考虑系统性风险。

### 4.2 "街头智慧"中的数学公式
简单平均数和加权平均数用于评估投资组合的收益和风险。

#### 4.2.1 简单平均数与加权平均数的比较
简单平均数计算各因素的平均值，加权平均数考虑各因素的重要性。

#### 4.2.2 风险调整后的收益计算
风险调整后收益=预期收益 - 风险调整值。

#### 4.2.3 投资组合优化的数学表达
目标函数：最大化收益，约束条件：风险在可接受范围内。

## 第5章: 投资决策中的数学模型实现

### 5.1 投资模型的Python实现
使用Python代码计算市盈率和CAPM模型。

#### 5.1.1 计算市盈率和CAPM的Python代码
```python
def calculate_pe_ratio(price, earnings_per_share):
    return price / earnings_per_share

def calculate_capm(risk_free_rate, beta, market_return):
    return risk_free_rate + beta * (market_return - risk_free_rate)
```

#### 5.1.2 示例计算
```python
pe_ratio = calculate_pe_ratio(50, 10)  # 市盈率=5
capm_return = calculate_capm(0.05, 1.2, 0.1)  # 预期收益=0.076
```
