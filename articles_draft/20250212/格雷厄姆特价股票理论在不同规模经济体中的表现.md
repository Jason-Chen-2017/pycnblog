# 第2章 格雷厄姆特价股票理论的核心概念

## 2.1 核心概念

### 内在价值

股票的内在价值是其未来现金流的现值，计算公式为：
$$ V = \sum_{t=1}^n \frac{CF_t}{(1+r)^t} $$

### 市场价值

市场价值由供需决定，可能高于或低于内在价值。

### 安全边际

安全边际=内在价值 - 市场价值，确保投资的安全性。

## 2.2 核心概念对比

| 概念         | 内在价值 | 市场价值 | 安全边际 |
|--------------|----------|----------|----------|
| 定义         | 现金流现值 | 市场价格 | 投资缓冲 |
| 计算公式     | $$ V = \sum \frac{CF_t}{(1+r)^t} $$ | 市场价格 | $$ S = V - P $$ |
| 作用         | 确定价值 | 反映市场情绪 | 提供安全垫 |

# 第5章 项目实战

## 5.1 环境安装

安装Python和必要的库（pandas, numpy, matplotlib）。

## 5.2 代码实现

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(earnings, growth_rate, discount_rate):
    return earnings / (discount_rate - growth_rate)

def calculate_pe(stock_price, earnings):
    return stock_price / earnings

# 示例数据
earnings = 10
growth_rate = 0.05
discount_rate = 0.10
stock_price = 50

iv = calculate_intrinsic_value(earnings, growth_rate, discount_rate)
pe = calculate_pe(stock_price, earnings)
margin = iv - stock_price

print(f"内 在 价 值: {iv}")
print(f"市盈率: {pe}")
print(f"安全边际: {margin}")
```

## 5.3 实例分析

假设某股票的收益为$10，增长率5%，折现率10%，市场价格$50：

$$ V = 10 / (0.10 - 0.05) = 200 $$
$$ PE = 50 / 10 = 5 $$
$$ S = 200 - 50 = 150 $$
