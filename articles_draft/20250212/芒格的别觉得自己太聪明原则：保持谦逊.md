## 第一部分: 芒格的"别觉得自己太聪明"原则概述

### 第1章: 芒格的生平与投资理念

#### 1.1 芒格的生平简介  
查理·芒格（Charlie Munger）是世界著名投资家、作家和演讲家，以多元思维模型和价值投资理念闻名。他早年毕业于密歇根大学法学院，后加入巴菲特的合伙公司，逐步成为伯克希尔哈撒韦公司的副主席。芒格的哲学思想深受导师霍兰·帕顿的影响，注重跨学科思考和风险管理。

#### 1.2 芒格的投资理念  
芒格的投资理念强调安全边际、长期主义和价值投资。他主张以合理的价格买入具有持续竞争优势的公司，并长期持有。芒格认为，投资的核心是找到那些具有坚固“护城河”的企业，避免过度依赖市场波动进行短期交易。

#### 1.3 "别觉得自己太聪明"原则的提出背景  
“别觉得自己太聪明”原则源于芒格对人性弱点的深刻理解。他认为，投资者容易陷入过度自信的陷阱，忽视潜在风险。这一原则提醒投资者保持谦逊，承认自身的知识局限，并在决策中引入安全边际概念，以降低风险敞口。

## 第二部分: "别觉得自己太聪明"原则的核心概念

### 第2章: 芒格原则的核心概念解析

#### 2.1 "别觉得自己太聪明"的定义与特点  
- **定义**：芒格原则强调在投资决策中保持谦逊，避免过度自信，注重风险管理。
- **特点**：
  - 强调安全边际：买入价格远低于内在价值的资产。
  - 长期视角：关注企业的长期竞争优势，而非短期市场波动。
  - 跨学科思维：结合心理学、经济学、数学等多学科知识进行决策。

#### 2.2 芒格原则的核心要素  
- **谦逊与开放的心态**：承认自身知识的局限性，虚心接受反馈。
- **风险意识与安全边际**：在投资中留有余地，避免过度杠杆和集中投资。
- **复杂决策中的简单化思维**：通过简化问题，降低决策复杂性，避免过度自信。

#### 5.2 芒格原则的Python代码实现  
以下是一个简单的Python代码示例，用于计算投资组合的风险敞口：

```python
import numpy as np

def calculate_risk(weights, returns):
    # 计算投资组合的期望收益
    expected_return = np.dot(weights, returns)
    # 计算投资组合的风险（标准差）
    covariance_matrix = np.cov(returns.T)
    variance = np.dot(weights.T, np.dot(covariance_matrix, weights))
    risk = np.sqrt(variance)
    return expected_return, risk

# 示例数据
weights = [0.4, 0.4, 0.2]
returns = [0.1, 0.2, 0.15]

expected_return, risk = calculate_risk(weights, returns)
print(f"期望收益: {expected_return}")
print(f"风险敞口: {risk}")
```
