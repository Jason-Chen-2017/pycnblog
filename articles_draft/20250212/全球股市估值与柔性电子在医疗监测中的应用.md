## 第1章: 股票估值的核心概念与算法原理

### 1.1 股票估值的背景与意义

#### 1.1.1 股票估值的定义与作用
股票估值是通过对公司财务数据、市场环境和行业趋势的分析，估算其股票的内在价值，为投资者提供决策依据。

#### 1.1.2 全球股市估值的重要性
在全球化背景下，股市估值不仅是投资决策的关键，也是宏观经济分析的重要工具。

#### 1.1.3 股票估值的边界与外延
股票估值不仅涉及公司基本面分析，还包括市场情绪、政策环境等多方面因素。

---

### 1.2 股票估值的核心概念与联系

#### 1.2.1 股票估值的核心概念
- **内在价值**：基于公司基本面的理论价值。
- **市场价值**：实际交易中的价格。
- **相对估值**：与行业或市场的平均值进行比较。

#### 1.2.2 股票估值的核心要素
| 核心要素 | 描述 |
|----------|------|
| 财务数据 | 收入、利润、资产负债表等 |
| 市场环境 | 宏观经济、行业趋势等 |
| 风险因素 | 市场风险、流动性风险等 |

### 1.3 股票估值的算法原理

#### 1.3.1 常见股票估值方法
1. **市盈率法**：P/E = 市场价 / 每股收益。
2. **市净率法**：P/B = 市场价 / 每股净资产。
3. **现金流折现法**：DCF模型。

#### 1.3.2 机器学习在股票估值中的应用
```mermaid

    A[数据预处理] --> B[特征提取]
    B --> C[模型训练]
    C --> D[模型预测]
    D --> E[估值结果]
```

#### 1.3.3 示例：线性回归模型
股票价格预测的线性回归模型：
$$ y = \beta_0 + \beta_1 x + \epsilon $$
其中，$x$ 为自变量（如每股收益），$y$ 为股票价格。

## 第2章: 柔性电子在医疗监测中的应用

### 2.1 柔性电子的定义与特点

#### 2.1.1 柔性电子的定义
柔性电子是指在柔性基底上制成的电子设备，具有可弯曲、可拉伸的特性。

#### 2.1.2 柔性电子的核心特点
- **柔软性**：适应复杂形状。
- **可穿戴性**：便于医疗监测。
- **生物相容性**：适合直接接触人体。

---

### 2.2 柔性电子在医疗监测中的应用

#### 2.2.1 柔性传感器的原理
柔性传感器通过物理或化学变化，将生物信号（如心率、体温）转化为电信号。

#### 2.2.2 柔性电子在医疗监测中的优势
| 优势 | 描述 |
|------|------|
| 穿戴舒适 | 柔性设计适合长期佩戴。 |
| 实时监测 | 可连续采集生理数据。 |
| 非侵入性 | 减少患者痛苦。 |

#### 2.2.3 柔性电子的实际案例
- **可穿戴设备**：智能手表监测心率。
- **手术导航系统**：实时监测手术中的生理指标。

import torch.nn as nn

# 简单神经网络模型
class SensorModel(nn.Module):
    def __init__(self):
        super(SensorModel, self).__init__()
        self.fc1 = nn.Linear(2, 4)
        self.fc2 = nn.Linear(4, 1)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x
