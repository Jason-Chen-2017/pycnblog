### 附录：代码示例

#### 1. 现金流折现法（DCF模型）

```python
def dcf_analysis(revenue, growth_rate, discount_rate, period):
    cash_flow = []
    for i in range(period):
        if i == 0:
            cf = revenue
        else:
            cf = cf * (1 + growth_rate)
        cash_flow.append(cf)
    present_value = sum(cf / (1 + discount_rate)**i for i, cf in enumerate(cash_flow))
    return present_value
```

```python
def calculate_pe(stock_price, earnings_per_share):
    pe_ratio = stock_price / earnings_per_share
    return pe_ratio
```

#### 3. 股息率模型

```python
def calculate_dividend_yield(dividend_per_share, stock_price):
    dividend_yield = dividend_per_share / stock_price
    return dividend_yield
```
