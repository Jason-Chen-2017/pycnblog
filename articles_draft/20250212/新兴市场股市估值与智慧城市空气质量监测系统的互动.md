## 第1章：背景介绍与核心概念

### 1.1 问题背景与描述

#### 1.1.1 新兴市场股市估值的现状与挑战
新兴市场（如东南亚、南美等地区）的股市近年来发展迅速，但其估值波动性较大。传统估值方法（如PE、PB等）难以捕捉市场短期波动和非线性关系。

#### 1.1.2 智慧城市空气质量监测系统的建设与应用
随着技术进步，空气质量监测系统（如PM2.5、PM10、NO2等指标）在智慧城市中的应用越来越广泛。实时数据为城市环境管理提供了科学依据。

#### 1.1.3 两者互动关系的提出与研究意义
空气质量不仅影响居民健康，还可能间接影响市场情绪和企业盈利能力，进而影响股市估值。研究这一互动关系对优化投资决策具有重要意义。

### 5.2 核心代码实现

#### 5.2.1 数据清洗与特征提取
```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('data.csv')

# 数据清洗
data.dropna(inplace=True)
data = data[~(data['PM2.5'].isinf())]

# 特征提取
features = data[['PM2.5', 'Market Return']]
target = data['Stock Return']
```

#### 5.2.2 模型训练与预测
```python
from sklearn.model_selection import train_test_split
from xgboost import XGBRegressor

# 划分数据集
X_train, X_test, y_train, y_test = train_test_split(features, target, test_size=0.2, random_state=42)

# 模型训练
model = XGBRegressor(n_estimators=100, learning_rate=0.1)
model.fit(X_train, y_train)

# 模型预测
y_pred = model.predict(X_test)
print("均方误差:", mean_squared_error(y_test, y_pred))
```
