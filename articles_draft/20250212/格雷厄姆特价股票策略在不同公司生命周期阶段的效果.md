#### 2.2 公司生命周期对投资策略的影响
- **2.2.1 初创期公司的投资机会**
  初创期公司风险高，但潜在回报大，适合寻找基本面良好、管理团队优秀的公司。

- **2.2.2 成长期公司的投资策略**
  成长期公司收入和利润快速增长，适合寻找市盈率合理、成长性好的股票。

- **2.2.3 成熟期公司的投资分析**
  成熟期公司增长稳定，适合寻找低市盈率、高股息率的股票，符合格雷厄姆的安全边际原则。

- **2.2.4 衰退期公司的投资风险**
  衰退期公司利润下滑，股价波动大，投资风险高，通常不符合格雷厄姆的选股标准。

#### 3.1 格雷厄姆投资模型的数学表达
- **3.1.1 内在价值公式**
  $$ V = \frac{E}{1 + r} $$
  其中，\( V \) 是内在价值，\( E \) 是未来现金流，\( r \) 是折现率。

#### 3.2 生命周期阶段的多因子分析模型
- **3.2.1 基于生命周期的多因子构建**
  通过生命周期阶段调整因子权重，构建动态投资模型。

- **3.2.2 多因子模型的数学表达**
  $$ F = \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_n X_n $$
  其中，\( F \) 是综合因子，\( X_i \) 是各个因子，\( \beta_i \) 是因子权重。

#### 3.3 动态调整模型
- **3.3.1 动态调整的步骤**
  根据公司生命周期阶段的变化，动态调整投资组合。

- **3.3.2 动态调整的数学表达**
  $$ W_{t+1} = W_t + \alpha (R_t - W_t) $$
  其中，\( W_{t+1} \) 是调整后的权重，\( W_t \) 是当前权重，\( R_t \) 是目标权重，\( \alpha \) 是调整系数。

import pandas as pd
import numpy as np

def calculate_intrinsic_value(future_cash_flow, discount_rate):
    return future_cash_flow / (1 + discount_rate)

def determine_company_stage(revenue_growth, profit_margin):
    if revenue_growth > 0.3 and profit_margin > 0.15:
        return '成长期'
    elif 0 < revenue_growth <= 0.3 and 0 < profit_margin <= 0.15:
        return '成熟期'
    else:
        return '衰退期'

# 示例数据
data = {
    '公司名称': ['A', 'B', 'C'],
    '未来现金流': [100, 150, 80],
    '折现率': [0.1, 0.15, 0.08],
    '收入增长率': [0.2, 0.1, 0.05],
    '利润率': [0.1, 0.12, 0.08]
}

df = pd.DataFrame(data)

# 计算内在价值
df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['未来现金流'], x['折现率']), axis=1)

# 确定公司生命周期阶段
df['生命周期阶段'] = df.apply(lambda x: determine_company_stage(x['收入增长率'], x['利润率']), axis=1)

print(df)
