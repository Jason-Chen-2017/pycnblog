## 3. 空气质量预测系统的算法原理

### 3.1 线性回归模型
- 基本原理：通过最小二乘法拟合最佳回归线。
- 优缺点：简单易懂，但可能无法捕捉复杂关系。

### 3.2 随机森林模型
- 基于决策树的集成算法，具有较强的抗过拟合能力。
- 适合处理多维数据，准确率高。

### 3.3 神经网络模型
- 通过多层神经网络捕捉数据的非线性关系。
- 需要大量数据支持，计算复杂。

### 3.4 算法选择与优化
- 根据数据特征选择合适算法。
- 使用交叉验证优化模型参数。

## 5. 空气质量预测系统的项目实战

### 5.1 环境搭建
- 安装Python、NumPy、Pandas、Scikit-learn等库。

### 5.2 核心代码实现
```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error

# 数据加载与预处理
data = pd.read_csv('air_quality.csv')
X = data[['温度', '湿度', '风速']]
y = data['PM2.5']

# 模型训练
model_lr = LinearRegression()
model_lr.fit(X, y)
y_pred_lr = model_lr.predict(X)
print("线性回归均方误差:", mean_squared_error(y, y_pred_lr))

model_rf = RandomForestRegressor()
model_rf.fit(X, y)
y_pred_rf = model_rf.predict(X)
print("随机森林均方误差:", mean_squared_error(y, y_pred_rf))
```
