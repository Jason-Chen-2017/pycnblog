### 第1章: 格雷厄姆投资理论的核心理念

#### 1.1 价值投资的基本原则
- **内在价值与市场价格**：格雷厄姆认为，股票的内在价值是其未来现金流的现值，而市场价格经常偏离内在价值。
- **安全边际**：通过购买价格低于内在价值的股票，投资者可以降低风险并获得超额收益。

#### 1.2 中央银行数字货币的定义与特点
- **CBDC的定义**：中央银行数字货币是央行发行的数字化货币，具有去中心化、可追溯性和安全性高的特点。
- **CBDC与传统货币的对比**：
  | 特性 | 传统货币 | CBDC |
  |------|----------|------|
  | 发行主体 | 商业银行 | 中央银行 |
  | 支付方式 | 现金、电子支付 | 数字化支付 |
  | 管控能力 | 有限 | 更强 |

#### 1.3 格雷厄姆策略与CBDC的结合背景
- **数字货币时代的投资机会**：CBDC的普及可能改变传统金融市场的运作方式，为投资者提供新的机会。
- **CBDC对传统投资策略的挑战**：CBDC的透明性和监管力度可能影响市场的流动性，进而影响股票价格。
- **调整策略的必要性与目标**：为了适应CBDC环境，需要调整格雷厄姆策略，优化投资组合并降低风险。

### 第2章: 格雷厄姆策略的核心概念与数学模型

#### 2.1 格雷厄姆策略的核心要素
- **内在价值计算**：通过分析公司的财务数据（如净利润、现金流）来估算股票的内在价值。
- **安全边际**：购买价格低于内在价值一定比例的股票，以降低市场波动带来的风险。

#### 2.2 CBDC环境下的投资变量分析
- **市场波动性**：CBDC的引入可能导致市场波动性增加或减少，需要动态调整投资策略。

- **投资者行为变化**：CBDC可能改变投资者的行为模式，例如更倾向于短期交易。

#### 2.3 格雷厄姆策略的数学模型与公式
- **安全边际计算公式**：
  $$ 安全边际 = \frac{内在价值 - 市场价格}{市场价格} $$
- **投资组合优化模型**：
  $$ 最优投资组合 = \argmin_{w} \left( w^T \Sigma w + \lambda w^T \alpha \right) $$

import pandas as pd
import numpy as np

# 假设df是股票数据，包含'close'列
def calculate_margin_of_safety(df):
    intrinsic_value = df['intrinsic_value']
    market_price = df['close']
    margin = (intrinsic_value - market_price) / market_price
    return margin

# 示例数据
data = {
    'intrinsic_value': [100, 150, 200],
    'close': [80, 120, 180]
}
df = pd.DataFrame(data)
margin = calculate_margin_of_safety(df)
print(margin)
