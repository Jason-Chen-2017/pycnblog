## 第1章：ESG的背景与发展

### 1.1 ESG的起源与发展

ESG（环境、社会、治理）投资是一种新兴的可持续投资策略，起源于20世纪90年代。随着全球对环境问题和社会责任的关注增加，ESG投资逐渐成为主流。以下是ESG的起源与发展历程：

- **20世纪90年代**：ESG概念的初步提出，主要关注环境因素。
- **21世纪初**：社会和治理因素逐渐被纳入考虑，形成完整的ESG框架。
- **近年来**：随着气候变化和企业治理问题的加剧，ESG投资迅速发展，成为全球投资的重要组成部分。

### 1.2 ESG的核心要素

ESG由三个核心要素组成：环境（E）、社会（S）和治理（G）。

#### 1.2.1 环境（E）
- 包括碳排放、能源使用效率、环境合规等指标。
- 通过减少碳足迹和提高能源效率，企业可以降低环境风险。

#### 1.2.2 社会（S）
- 包括劳工权益、社区参与、产品责任等。
- 企业应关注员工福利、社会责任和产品安全，提升社会影响力。

#### 1.2.3 治理（G）
- 包括董事会结构、高管激励、透明度等。
- 良好的公司治理可以提高企业效率和抗风险能力。

### 1.3 ESG与传统投资的对比

| 项目 | ESG投资 | 传统投资 |
|------|---------|----------|
| 目标 | 长期可持续收益 | 短期最大化收益 |
| 风险 | 低环境和社会风险 | 高环境和社会风险 |
| 收益 | 包括社会和环境效益 | 仅考虑经济效益 |

## 第2章：ESG的理论框架与评估方法

### 2.1 环境（E）评估的核心指标

#### 2.1.1 碳排放
- **指标**：单位产品碳排放量。
- **影响**：高碳排放可能导致政策风险和声誉损失。

#### 2.1.2 能源使用效率
- **指标**：单位能源消耗产出。
- **影响**：提高效率可降低成本和环境影响。

### 2.2 社会（S）评估的核心指标

#### 2.2.1 劳工权益
- **指标**：员工满意度、劳动纠纷率。
- **影响**：良好的劳工关系有助于提高员工效率和企业声誉。

### 2.3 治理（G）评估的核心指标

#### 2.3.1 董事会结构
- **指标**：独立董事比例、董事会多样性。
- **影响**：多样化的董事会有助于更有效的决策。

def calculate_esg_score(company_data):
    e_score = sum(company_data['environment']) / len(company_data['environment'])
    s_score = sum(company_data['social']) / len(company_data['social'])
    g_score = sum(company_data['governance']) / len(company_data['governance'])
    total_score = (e_score + s_score + g_score) / 3
    return total_score

# 示例使用
company_data = {
    'environment': [85, 90, 75],
    'social': [80, 85, 70],
    'governance': [75, 90, 80]
}

print(f"ESG综合得分为：{score}")
