### 第5章: 数学模型与算法设计  

#### 5.1 特价股票投资的数学模型  
- 5.1.1 投资组合优化的数学公式  
  $$ \text{目标函数：} \quad \max \sum_{i=1}^{n} w_i r_i - \lambda \sum_{i=1}^{n} \sum_{j=1}^{n} w_i w_j \sigma_{ij} $$
  其中，\( w_i \) 是第 \( i \) 只股票的权重，\( r_i \) 是预期收益率，\( \sigma_{ij} \) 是协方差矩阵。  
- 5.1.2 基于可持续发展指标的权重分配  

#### 5.2 可持续发展指标的权重分配算法  
- 5.2.1 熵值法（Entropy Method）  
- 5.2.2 层次分析法（AHP）  

#### 5.3 算法实现的Python代码  
```python
import numpy as np

def calculate_weights(matrix):
    # 计算权重
    n = len(matrix)
    # 标准化矩阵
    normalized_matrix = (matrix - np.mean(matrix)) / np.std(matrix)
    # 计算熵值
    entropy = np.mean(-np.log(normalized_matrix + 1e-8), axis=1)
    # 计算权重
    weights = np.exp(-entropy)
    return weights / np.sum(weights)

# 示例数据
data = np.array([[10, 20, 30], [40, 50, 60], [70, 80, 90]])
weights = calculate_weights(data)
print(weights)
```
