## 引言

### 1.1 问题背景
- **格雷厄姆特价股票理论的起源与核心思想**：格雷厄姆是价值投资之父，强调以低于内在价值的价格买入优质股票。
- **数字社会下影响力投资的兴起**：投资者关注企业对社会的影响，如环保、教育等。
- **传统投资理论与数字社会需求的冲突**：传统理论忽视企业社会责任，无法满足数字社会的需求。

### 1.2 问题描述
- **格雷厄姆理论的应用局限**：仅关注财务指标，忽视社会因素。
- **影响力投资的定义**：投资于对社会有积极影响的企业。
- **理论与实践的结合**：如何将格雷厄姆理论与影响力投资结合，提升投资收益和社会价值。

### 1.3 问题解决
- **理论的潜在价值**：格雷厄姆理论可帮助评估企业的真实价值。
- **数字技术的赋能**：利用大数据分析企业影响力。
- **理论创新的方向**：扩展传统模型，融入社会影响力因素。

### 1.4 理论边界与外延
- **适用范围**：适用于企业价值评估。
- **边界条件**：企业影响力数据的准确性。
- **创新方向**：结合财务和影响力指标，构建综合评估模型。

## 数字社会影响力投资的理论框架与数学模型

### 3.1 理论框架
- **格雷厄姆理论的适用性**：在数字社会中，数据驱动的方法可以更准确地评估企业价值。
- **数学模型构建**：结合财务指标和影响力指标，构建综合评估模型。

### 3.2 算法原理
```mermaid
graph TD
    A[开始] --> B[计算企业内在价值]
    B --> C[获取企业影响力评分]
    C --> D[计算综合评分]
    D --> E[确定投资决策]
    E --> F[结束]
```

### 3.3 数学模型
综合评分公式：
$$
综合评分 = \alpha \times 内在价值 + (1-\alpha) \times 影响力评分
$$
其中，$$0 < \alpha < 1$$ 为权重系数。

### 3.4 Python代码实现
```python
def calculate综合评分(内在价值, 影响力评分, alpha=0.5):
    return alpha * 内在价值 + (1 - alpha) * 影响力评分

# 示例
内在价值 = 50
影响力评分 = 0.8
alpha = 0.6
综合评分 = calculate综合评分(内在价值, 影响力评分, alpha)
print(综合评分)
```
