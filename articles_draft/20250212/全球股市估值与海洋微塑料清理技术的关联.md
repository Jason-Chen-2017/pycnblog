## 第3章：算法原理讲解

### 3.1 算法原理

#### 3.1.1 机器学习算法的使用
使用线性回归模型预测股市估值，代码示例如下：

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据准备
data = pd.DataFrame({
    'Market Index': np.random.rand(100),
    'Valuation': np.random.rand(100)
})

# 模型训练
model = LinearRegression()
model.fit(data[['Market Index']], data['Valuation'])

# 预测结果
print(model.predict([[0.5]]))
```
