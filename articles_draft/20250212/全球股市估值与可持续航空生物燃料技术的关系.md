## 第6章: 项目实战

### 6.1 环境安装

- **Python 3.8+**
- **Jupyter Notebook**
- **安装库**：`pip install numpy pandas scikit-learn`

### 6.2 系统核心实现源代码

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载
data = pd.DataFrame({
    '技术创新': [1, 2, 3, 4, 5],
    '成本控制': [2, 3, 4, 5, 6],
    '估值': [10, 15, 20, 25, 30]
})

# 模型训练
X = data[['技术创新', '成本控制']]
y = data['估值']

model = LinearRegression()
model.fit(X, y)

# 预测与评估
predictions = model.predict(X)
print("R² Score:", r2_score(y, predictions))
```
