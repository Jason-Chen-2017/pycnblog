    # 市盈率法
    fair_value = company_data['股价'] * company_data['市盈率']
    return fair_value

# 应用模型

# 第七章: 反向投资的数学模型与公式

## 第7章: 数学模型与公式

### 7.1 基础公式

#### 7.1.1 市盈率公式
$$市盈率 = \frac{股价}{每股收益}$$

#### 7.1.2 市净率公式
$$市净率 = \frac{股价}{每股净资产}$$

### 7.2 估值模型

#### 7.2.1 理论基础
- 基于内在价值的评估
- 使用DCF模型（现金流贴现法）

#### 7.2.2 DCF模型公式
$$企业价值 = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{残值}{(1 + r)^n}$$
其中，CF_t为第t年的自由现金流，r为折现率。

### 7.3 风险评估

#### 7.3.1 风险调整公式
$$风险调整后价值 = 价值 \times (1 - 风险系数)$$
