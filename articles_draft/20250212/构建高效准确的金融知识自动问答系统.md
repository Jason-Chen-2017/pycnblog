## 5.2 系统核心功能实现

### 5.2.1 分词与词性标注
```python
import jieba

def tokenize_and_tag(text):
    tokens = jieba.lcut(text)
    # 使用spaCy进行词性标注
    nlp = spacy.load("zh_core_web_sm")
    doc = nlp(" ".join(tokens))
    tagged = []
    for token in doc:
        tagged.append((token.text, token.pos_))
    return tagged

# 示例
text = "如何购买基金？"
print(tokenize_and_tag(text))
```

### 5.2.2 意图识别
```python
from sklearn.feature_extraction.text import TfidfVectorizer

model = joblib.load('intent_classifier.pkl')

# 示例
```

### 5.2.3 知识图谱匹配

```python
import networkx as nx
import matplotlib.pyplot as plt

def build_knowledge_graph():
    G = nx.Graph()
    G.add_edge("股票", "购买", weight=0.8)
    G.add_edge("购买", "流程", weight=0.7)
    # 绘制图表
    plt.figure(figsize=(3,3))
    nx.draw(G, with_labels=True, edge_labels=True)
    plt.show()

build_knowledge_graph()
```
