## 第一部分: 格雷厄姆特价股票理论与再生金融概述

### 第1章: 格雷厄姆投资理论的核心思想

#### 1.1 格雷厄姆投资理论的起源与核心思想
格雷厄姆是价值投资的鼻祖，他的理论强调以低于内在价值的价格购买股票。其核心思想是通过分析企业的基本面，寻找被市场低估的股票，从而实现长期稳定的收益。格雷厄姆理论的核心在于“安全边际”，即购买价格与内在价值之间的差距，这种差距越大，投资的安全性越高。

#### 1.2 格雷厄姆价值投资的核心思想
1. **安全边际**：购买价格低于内在价值，确保投资的安全性。
2. **低估值股票**：关注市盈率（P/E）和市净率（P/B）等指标，寻找被市场低估的股票。
3. **长期投资**：价值投资注重长期持有的策略，避免短期市场波动的干扰。

### 第2章: 再生金融的定义与特点

#### 2.1 再生金融的定义
再生金融是一种新兴的金融模式，结合了区块链、人工智能等技术，旨在通过技术创新优化金融市场的运作效率。再生金融的核心在于利用分布式账本技术（DLT）和智能合约，实现透明、高效和去中心化的金融服务。

#### 2.2 再生金融的特点
1. **去中心化**：通过区块链技术实现去中心化的金融服务。
2. **透明性**：所有交易记录在区块链上，具有高度的透明性。
3. **高效性**：利用智能合约自动执行交易，减少中间环节，提高效率。
4. **创新性**：结合人工智能和大数据分析，优化金融产品和服务。

### 第3章: 格雷厄姆特价股票理论在再生金融中的应用背景

#### 3.1 再生金融中的价值投资机会
再生金融市场的快速发展带来了大量的投资机会，尤其是那些具有低估值的股票。通过格雷厄姆理论，投资者可以在再生金融市场中找到那些被低估的企业，进行长期投资。

#### 3.2 格雷厄姆理论在再生金融中的适用性
格雷厄姆理论强调低估值和安全边际，这在再生金融市场中尤为重要。由于再生金融市场的波动性较大，低估值股票的投资机会更为显著。

#### 3.3 再生金融市场的特点与挑战
再生金融市场虽然具有创新性，但也面临监管不完善、市场波动性大等挑战。格雷厄姆理论可以帮助投资者在这样的市场中找到稳定的投资机会。

## 第二部分: 格雷厄姆特价股票理论的核心概念与分析

### 第4章: 格雷厄姆特价股票理论的核心概念

#### 4.1 企业内在价值
企业内在价值是企业未来现金流的现值，是衡量股票是否被低估的重要指标。格雷厄姆认为，内在价值是决定股票价格的唯一标准。

#### 4.2 市盈率与市净率
- **市盈率（P/E）**：股票价格与每股收益的比率。P/E低的股票通常被认为是低估的。
- **市净率（P/B）**：股票价格与每股净资产的比率。P/B低的股票通常被认为是低估的。

#### 4.3 低估值股票的定义
低估值股票是指那些市盈率、市净率等指标低于行业平均水平的股票。这些股票通常具有较大的安全边际，是价值投资者的首选。

def screen_cheap_stocks(stocks, threshold):
    cheap_stocks = []

        if stock['P/E'] < threshold:
            cheap_stocks.append(stock['股票名称'])
    return cheap_stocks
