### 第4章：数学模型与公式

#### 4.1 常用估值指标公式
- 市盈率（P/E）：$$P/E = \frac{\text{股价}}{\text{每股收益}}$$
- 市净率（P/B）：$$P/B = \frac{\text{股价}}{\text{每股净资产}}$$
- 市销率（P/S）：$$P/S = \frac{\text{股价}}{\text{每股收入}}$$

#### 4.2 增长率的计算
- 收入增长率：$$\text{增长率} = \frac{\text{当年收入} - \text{上年收入}}{\text{上年收入}} \times 100\%$$
- 净利润增长率：$$\text{净利润增长率} = \frac{\text{当年净利润} - \text{上年净利润}}{\text{上年净利润}} \times 100\%$$

#### 4.3 结合高增长与低估值的筛选公式
- 低估值筛选：$$\text{P/E} < 市场平均P/E$$ 或 $$\text{P/B} < 市场平均P/B$$
- 高增长筛选：$$\text{收入增长率} > 市场平均收入增长率$$ 或 $$\text{净利润增长率} > 市场平均净利润增长率$$

#### 4.4 示例计算
- 假设某公司过去两年收入分别为1000万元和1500万元，计算收入增长率：$$\text{增长率} = \frac{1500 - 1000}{1000} \times 100\% = 50\%$$
- 假设当前股价为20元，每股收益为2元，则P/E = 10，低于市场平均P/E 15。

#### 6.2 核心实现代码
```python
import pandas as pd
import numpy as np

# 数据获取
data = pd.read_csv('company_data.csv')

# 计算估值指标
data['PE'] = data['股价'] / data['每股收益']
data['PB'] = data['股价'] / data['每股净资产']

# 计算增长率
data['收入增长率'] = (data['收入'] - data['收入'].shift(1)) / data['收入'].shift(1) * 100
data['净利润增长率'] = (data['净利润'] - data['净利润'].shift(1)) / data['净利润'].shift(1) * 100

# 筛选条件
筛选条件：PE < 市场平均PE 且 收入增长率 > 市场平均收入增长率
符合条件的公司 = data[(data['PE'] < 市场平均PE) & (data['收入增长率'] > 市场平均收入增长率)]
```
