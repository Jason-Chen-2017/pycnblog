## 第三部分：算法原理

### 第3章：线性回归与Lasso回归

#### 3.1 线性回归
- 损失函数：$$L = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$
- 梯度下降优化：$$\theta := \theta - \alpha \frac{\partial L}{\partial \theta}$$

#### 3.2 Lasso回归
- 正则化项：$$\lambda \sum_{j=1}^{p} |β_j|$$
- 用于特征选择，简化风险分解模型。

## 第四部分：数学模型

### 第4章：投资组合风险分解的数学公式

#### 4.1 协方差矩阵
- 定义：$$C = [c_{ij}]$$，其中$$c_{ij} = \text{Cov}(R_i, R_j)$$
- 用途：量化资产间风险的相关性。

#### 4.2 方差分解
- 分解式：$$\text{Var}(R_p) = \sum_{i=1}^{n} w_i^2 \text{Var}(R_i) + 2 \sum_{i < j} w_i w_j \text{Cov}(R_i, R_j)$$

## 第六部分：项目实战

### 第6章：Python实现案例

#### 6.1 环境配置
- 安装必要的库：numpy、pandas、scikit-learn。

#### 6.2 核心实现代码
```python
import numpy as np
from sklearn.linear_model import Lasso
from sklearn.metrics import mean_squared_error

# 示例数据
X = np.random.rand(100, 10)
y = np.random.rand(100, 1)

# 训练模型
model = Lasso(alpha=0.1)
model.fit(X, y)

# 预测结果
y_pred = model.predict(X)
print("均方误差:", mean_squared_error(y, y_pred))
```

#### 6.3 结果分析
- 模型解释：系数表示特征对目标变量的影响程度。
