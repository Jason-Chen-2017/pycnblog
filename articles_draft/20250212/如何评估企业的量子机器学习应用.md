# 第1章: 量子机器学习的背景与概念

## 1.1 量子计算的基本概念

### 1.1.1 量子位与经典位的对比
- **经典位**：二进制，只能表示0或1。
- **量子位(qubit)**：可以处于0和1的叠加态，表示更多的信息。

### 1.1.2 量子叠加与量子纠缠
- **量子叠加**：qubit可以同时处于多个状态的叠加，提高计算效率。
- **量子纠缠**：多个qubit之间相互关联，信息传递速度快。

### 1.1.3 量子计算的优势
- 并行计算能力强。
- 解决特定问题（如因式分解、优化）效率远超经典计算机。

---

## 1.2 机器学习的基础概念

### 1.2.1 机器学习的定义与分类
- **监督学习**：基于标记数据进行预测。
- **无监督学习**：发现数据中的结构。
- **强化学习**：通过奖励机制优化决策。

### 1.2.2 传统机器学习的核心算法
- 线性回归、支持向量机（SVM）、随机森林、神经网络等。

---

## 1.3 量子机器学习的核心原理

### 1.3.1 量子叠加在特征表示中的应用
- 通过量子叠加，特征可以同时表示多种可能性，提高模型的表达能力。

### 1.3.2 量子纠缠在数据关联中的作用
- 数据之间的纠缠关系使得模型能够捕捉到更深层次的关联性。

### 1.3.3 量子测量与模型训练的关系
- 量子测量将量子态转换为可读的测量结果，用于模型优化。

from qiskit import QuantumCircuit, Aer, execute
from qiskit.circuit import QuantumRegister, ClassicalRegister

def quantum_feature_extraction(data):
    n = len(data)
    q = QuantumRegister(n)
    c = ClassicalRegister(n)
    qc = QuantumCircuit(q, c)
    
    # 加入量子叠加
    for i in range(n):
        qc.h(q[i])
        qc.measure(q[i], c[i])
    
    return qc
