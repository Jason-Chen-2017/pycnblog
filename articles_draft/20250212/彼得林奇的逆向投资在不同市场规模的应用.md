## 第一部分：逆向投资的定义与核心理念

### 第1章：逆向投资的定义与核心理念

#### 1.1 逆向投资的定义

逆向投资是一种投资策略，强调在市场低迷或被低估时买入资产，在市场高涨或被高估时卖出资产。与传统投资策略不同，逆向投资关注市场的非理性波动，寻找价格与价值的偏离点。

- **投资的基本概念**：投资是通过购买资产，以期在未来获得收益的行为。资产可以是股票、债券、房地产等。
- **逆向投资的定义与特点**：逆向投资强调在市场低谷时买入，在市场高点时卖出。其特点是反周期性、逆向思维和长期视角。
- **彼得·林奇的投资理念**：彼得·林奇是逆向投资的代表人物之一，他主张在市场恐慌时寻找优质资产，在市场狂热时保持冷静。

#### 1.2 彼得·林奇的投资策略

彼得·林奇的投资策略以逆向投资为核心，注重基本面分析和长期价值。他的策略包括以下几点：

- **选股方法**：彼得·林奇注重分析公司的基本面，寻找那些被市场低估的优质企业。
- **逆向投资的核心思想**：在市场恐慌时买入，在市场狂热时卖出。
- **逆向投资与价值投资的区别**：逆向投资更关注市场的短期波动，而价值投资更关注企业的长期价值。

## 第2章：不同市场规模的特点

### 2.1 小盘股市场的特点

小盘股市场是指市值较小的公司股票组成的市场，通常具有较高的波动性和不确定性。

- **小盘股市场的定义**：市值在1亿到20亿美元之间的公司股票。
- **小盘股市场的波动性**：小盘股市场波动较大，容易受到市场情绪的影响。
- **小盘股市场的投资机会**：小盘股市场中存在许多被低估的优质企业，适合逆向投资。

### 2.2 大盘股市场的特点

大盘股市场是指市值较大的公司股票组成的市场，通常具有较高的稳定性和流动性。

- **大盘股市场的定义**：市值在20亿美元以上的公司股票。
- **大盘股市场的稳定性**：大盘股市场的波动较小，受市场情绪影响较小。
- **大盘股市场的投资机会**：大盘股市场中存在许多被低估的优质企业，适合逆向投资。

### 2.3 中盘股市场的特点

中盘股市场是指市值介于小盘股和大盘股之间的公司股票组成的市场，通常具有较高的风险和收益平衡。

- **中盘股市场的定义**：市值在2亿到20亿美元之间的公司股票。
- **中盘股市场的波动性**：中盘股市场的波动性介于小盘股和大盘股之间。
- **中盘股市场的投资机会**：中盘股市场中存在许多被低估的优质企业，适合逆向投资。

import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

def reverse_investing(ticker):
    # 数据采集
    data = pd.read_csv(f"{ticker}.csv")
    # 数据处理
    features = data[['market_cap', 'financial_health', 'market_sentiment']]
    target = data['price']
    # 模型训练
    model = LinearRegression()
    model.fit(features, target)
    # 预测结果
    prediction = model.predict(features)
    # 判断逆向投资时机
    if prediction[-1] < data['price'].mean() and data['market_sentiment'].mean() < 30:
        return "买入"
    elif prediction[-1] > data['price'].mean() and data['market_sentiment'].mean() > 70:
        return "卖出"
    else:
        return "观望"
