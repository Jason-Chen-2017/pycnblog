### 第二部分：Stoicism 基础

#### 2.1 Stoicism 概述

##### 2.1.1 Stoicism 的定义与发展

Stoicism 是古希腊哲学的重要流派，起源于公元前3世纪，由塞涅卡、爱比克泰德和马可·奥勒留等哲学家发展完善。这一哲学强调理性、情感控制和道德责任，成为古罗马时期最具影响力的思想之一。

##### 2.1.2 Stoicism 的主要理念

- **理性思考**：通过理性分析，理解世界的本质，摆脱情感干扰。
- **情感控制**：通过自律和自我反省，管理负面情绪，实现内心平静。
- **道德责任**：强调个人和社会的责任，认为道德行为是幸福的基础。

#### 2.2 Stoicism 的核心概念

##### 2.2.1 内心的自由

内心的自由是 Stoicism 的核心，强调通过理性思考和情感控制，实现内心的平静。以下是实现内心自由的关键步骤：

1. **理性思考**：分析问题，区分控制范围内的和无法控制的因素。
2. **情感控制**：通过练习，减少负面情绪的影响。
3. **接受现实**：专注于可控制的部分，减少焦虑。

##### 2.2.2 道德责任

道德责任强调个人在社会中的义务。实现方法包括：

1. **自我反省**：定期审视行为，确保符合道德标准。
2. **服务社会**：参与公益活动，帮助他人。
3. **正直行事**：坚持诚实和正直，面对诱惑时保持原则。

#### 2.3 Stoicism 的历史影响

Stoicism 在历史上影响深远，影响了西方哲学、宗教和现代心理学的发展。以下是其主要影响：

- **哲学影响**：影响了斯宾诺莎和康德等哲学家。
- **宗教影响**：基督教吸收了部分 Stoicism 思想，特别是在道德和个人修养方面。
- **心理学影响**：与认知行为疗法（CBT）有诸多相似之处，为现代心理治疗提供了基础。

#### 2.4 Stoicism 的现代应用

Stoicism 的理念在现代社会中依然具有重要意义。以下是其现代应用的几个方面：

- **压力管理**：通过接受不可控因素，减少焦虑。
- **情绪控制**：通过理性思考，避免情绪化决策。
- **决策制定**：专注于可控制的因素，做出更理性的选择。

class StoicismApp:
    def __init__(self):
        self.thoughts = []
        self.emotions = []
    
    def add_thought(self, thought):
        self.thoughts.append(thought)
    
    def add_emotion(self, emotion):
        self.emotions.append(emotion)
    
    def analyze_thoughts(self):
        negative_thoughts = [t for t in self.thoughts if t.is_negative()]
        return negative_thoughts

# 示例用法
