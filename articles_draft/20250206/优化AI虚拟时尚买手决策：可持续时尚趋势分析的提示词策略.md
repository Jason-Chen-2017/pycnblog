### 3.2 Python代码示例

```python
import numpy as np

def generate_prompts(data):
    prompts = []
    for item in data:
        prompt = f"推荐{item}，因为它使用了环保材料。"
        prompts.append(prompt)
    return prompts

data = ["有机棉T恤", "再生聚酯纤维连衣裙"]
prompts = generate_prompts(data)
print(prompts)
```

### 3.3 数学模型

模型使用协同过滤算法，公式如下：

$$sim(i,j) = \frac{\sum_{k=1}^{n} r_{ik} r_{jk}}}{\sqrt{\sum_{k=1}^{n} r_{ik}^2} \sqrt{\sum_{k=1}^{n} r_{jk}^2}}$$
