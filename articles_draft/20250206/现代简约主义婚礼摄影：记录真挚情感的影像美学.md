## 第二部分：简约主义婚礼摄影技术

### 第3章：摄影设备与器材

#### 3.1 摄影器材的选择
- **相机**：全画幅单反或无反相机（如Canon EOS R5、 Nikon Z6 II）。  
- **镜头**：定焦镜头（如50mm f/1.8）或标准变焦镜头（如24-70mm f/2.8）。  
- **三脚架**：用于稳定拍摄和长时间曝光。  
- **反光板/闪光灯**：辅助光线调节。

#### 3.2 摄影镜头的使用
- 定焦镜头：50mm适合人像，85mm适合全身像。  
- 变焦镜头：24mm适合广角场景，70mm适合人像。

#### 3.3 其他辅助设备
- 快门线：减少震动。  
- 镜头清洁布：保持镜头干净。  
- 存储卡：大容量高速存储卡。

---

### 第4章：摄影技巧与构图

#### 4.1 曝光与测光技巧
- **测光模式**：优先使用 Evaluative（评价测光）或 Spot（点测光）。  
- **曝光补偿**：根据场景调整EV值，避免高光或阴影过曝或欠曝。

#### 4.2 焦距与景深控制
- **景深**：使用大光圈（如f/1.8）可虚化背景，突出主体。  
- **焦距**：85mm适合人像，24mm适合广角场景。

#### 4.3 构图原则与实践
- **三分法**：将主体置于画面三分之一处。  
- **对称与平衡**：利用场景对称性增强画面美感。

### 第5章：光影与色彩处理

#### 5.1 光影的运用
- **黄金时刻**：日出或日落时分，光线柔和，色彩丰富。  
- **逆光**：营造戏剧性效果，突出主体轮廓。

#### 5.2 色彩的搭配与处理
- **冷暖对比**：白色与暖色搭配，增强画面层次感。  
- **后期调整**：使用RAW格式，后期软件调整白平衡、色调。

#### 5.3 后期处理软件与技巧
- **软件推荐**：Adobe Lightroom、Capture One。  
- **技巧**：适度调整饱和度，避免过度矫正。

```python
import os
from PIL import Image

def process_raw_files(raw_folder, output_folder):
    for filename in os.listdir(raw_folder):
        if filename.endswith('.NEF'):
            img = Image.open(os.path.join(raw_folder, filename))
            img.convert('RGB').save(os.path.join(output_folder, filename[:-4] + '.jpeg'), 'JPEG', quality=85)
    return

process_raw_files('raw_images', 'processed_images')
```
