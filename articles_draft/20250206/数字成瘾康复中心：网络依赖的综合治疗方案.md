#### 3.2 Python 源代码
```python
def assess_addiction(symptoms):
    score = 0
    for s in symptoms:
        if s in ['过度使用网络', '忽视重要事务']:
            score += 2
        elif s == '情绪波动':
            score += 1
    return score

symptoms = ['过度使用网络', '情绪波动']
print(assess_addiction(symptoms))  # 输出：3
```

#### 3.3 数学模型和公式
评估模型基于症状的加权得分：
$$ \text{总分} = \sum_{i=1}^{n} w_i \times s_i $$
其中，\( w_i \) 是症状 \( s_i \) 的权重。

#### 3.4 详细讲解和举例说明
例如，症状“过度使用网络”权重为2，“情绪波动”权重为1，总分3表示中度依赖。
