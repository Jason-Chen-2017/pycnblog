```python
import random

def crowdfunding(target_amount, days):
    collected_amount = 0
    for day in range(days):
        collected_amount += simulate_donation()
        if collected_amount >= target_amount:
            return "成功"
    return "失败"

def simulate_donation():
    return random.randint(0, 1000)

print(crowdfunding(5000, 30))
```

### 3.1.3 算法原理的数学模型和公式

成功率 \( S \) 的计算公式：
$$
S = \frac{C}{T} \times 100\%
$$

其中，\( C \) 是筹集资金，\( T \) 是目标资金。另一个公式用于预测每日筹款成功率：
$$
S = \frac{1}{1 + e^{-\lambda t}}
$$
其中，\( \lambda \) 是每日筹款率，\( t \) 是筹资天数。
