#### 4.2 算法原理与数学模型  
ChatGPT基于Transformer架构，通过自注意力机制捕捉文本中的上下文关系。其核心数学模型如下：  
- 输入嵌入：$x_i = E[x_i]$，其中$E$为嵌入矩阵。  
- 自注意力机制：  
  $$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$  
  其中$Q$为查询向量，$K$为键向量，$V$为值向量。  
- 输出结果：模型根据上下文生成主题标签。

#### 6.2 系统核心实现源代码  
```python
import openai

def extract_topics(text, model="gpt-3.5-turbo"):
    # 初始化OpenAI客户端
    client = openai.Client()
    # 调用ChatGPT模型
    response = client.chat.completions.create(
        model=model,
        messages=[{
            "role": "user",
            "content": f"Extract main themes from this text: {text}"
        }],
        temperature=0.3
    )
    return response.choices[0].message.content

# 示例：提取西班牙语小说的主题
text = "El Quijote cabalga hacia su destino..."
topics = extract_topics(text)
print(topics)
```
