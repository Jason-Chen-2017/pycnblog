## 第1章 背景介绍

### 1.1 核心概念与术语

提示词设计（Prompt Design）是指通过精心设计提示词，引导AI生成符合特定需求的内容。在广告领域，提示词设计直接影响AI生成创意广告的质量和效果。


#### Python代码实现

```python
import torch
import torch.nn as nn

class Generator(nn.Module):
    def __init__(self, vocab_size):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, 512)
        self.decoder = nn.Linear(512, vocab_size)

    def forward(self, input_ids):
        embed = self.embedding(input_ids)
        output = self.decoder(embed)
        return output

# 示例提示词
prompt = "Generate an advertisement for a new smartphone"
```

### 3.2 数学模型与公式

生成式模型的目标函数通常采用交叉熵损失：

$$ L = -\sum_{i=1}^{n} y_i \log(p(y_i|x)) $$

其中，\( y_i \) 是真实标签，\( p(y_i|x) \) 是模型预测的概率。

### 5.2 核心代码实现

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer

tokenizer = GPT2Tokenizer.from_pretrained('gpt2')
model = GPT2LMHeadModel.from_pretrained('gpt2')

def generate_advertisement(prompt):
    inputs = tokenizer.encode(prompt, return_tensors='pt')
    outputs = model.generate(inputs, max_length=50)
    return tokenizer.decode(outputs[0], skip_special_tokens=True)
```
