## 核心概念与联系

### 核心概念

1. **线上烹饪比赛**：通过视频直播、实时互动等形式进行。
2. **线下烹饪比赛**：在实体厨房中进行实际操作。
3. **混合模式**：线上与线下相结合，实现互动与实际操作的统一。

### 概念对比表格

| 比较维度       | 线上模式               | 线下模式               | 混合模式               |
|----------------|-----------------------|-----------------------|-----------------------|
| 参与方式       | 在线报名、远程参与     | 现场报名、现场参与     | 综合线上报名、线下参与 |
| 操作方式       | 理论展示、视频演示     | 实际操作、现场烹饪     | 线上展示与线下实际操作 |
| 互动性         | 评论互动、点赞         | 观众现场互动           | 线上线下双向互动       |
| 传播范围       | 全球范围               | 局限于现场参与人数       | 更广的传播范围         |

### 数学模型

参与者的最终得分由线上和线下两部分组成：

$$
\text{总分} = \alpha \times (\text{线上得分}) + (1-\alpha) \times (\text{线下得分})
$$

其中，$\alpha$ 是线上得分的权重，通常 $\alpha \in [0,1]$。

```python
class OnlineRegistration:
    def __init__(self, server):
        self.server = server

    def register(self, user):
        # 验证和注册逻辑
        if user.email and user.name:
            self.server.add_user(user)
            return True
        return False

# 线下参与系统
class Venue:
    def __init__(self, location, capacity):
        self.location = location
        self.capacity = capacity

class OfflineParticipation:
    def __init__(self, venue):
        self.venue = venue

    def register(self, user):
        if self.venue.capacity > 0:
            self.venue.capacity -= 1
            return True
        return False
```
