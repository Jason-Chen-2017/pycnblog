**3.2 数学模型与公式**

- **3.2.1 主观性权重计算公式**：
  $$ w_{\text{主观}} = \frac{\sum_{i=1}^{n} s_i}{n} $$
  其中，$s_i$ 是第 $i$ 个主观性评分，$n$ 是总评分数。

- **3.2.2 客观性校正公式**：
  $$ o_{\text{校正}} = o_{\text{原始}} + \alpha \cdot w_{\text{主观}} $$
  其中，$\alpha$ 是校正系数。

**5.1 环境安装**

**5.2 系统核心实现源代码**

```python
import spacy

nlp = spacy.load("en_core_web_sm")

def analyze_subjectivity(text):
    doc = nlp(text)
    # 提取情感
    subjectivity_scores = [token.sentiment for token in doc]
    return subjectivity_scores

def extract_objectivity(text):
    doc = nlp(text)
    # 提取实体和事实
    objective_entities = [ent.label_ for ent in doc.ents]
    return objective_entities

# 示例
text = "The red flower is beautiful."
subjectivity = analyze_subjectivity(text)
objectivity = extract_objectivity(text)
print(f"Subjectivity: {subjectivity}")
print(f"Objectivity: {objectivity}")
```

**5.3 代码应用解读**

- `analyze_subjectivity` 函数使用spaCy的情感分析功能提取文本的主观性评分。
- `extract_objectivity` 函数提取文本中的实体和事实，用于客观性分析。
