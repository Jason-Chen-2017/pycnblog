- **身心结合**：冥想舞蹈强调身心结合，通过呼吸和肢体动作的协调，使身心得到放松和提升。

正念练习是一种提高自我意识、专注力和自我调节能力的方法，其基本原理包括：
- **专注当下**：通过集中注意力，使思维不受到外界干扰，达到内心的平静。
- **身体扫描**：通过扫描身体的感觉，提高对身体各部分的觉察和敏感度。

### 2.2 正念练习的基本原理

正念练习是一种通过专注当下、提高自我意识的方法，有助于缓解压力和提升生活质量。其基本原理包括：
- **专注当下**：通过集中注意力，使思维不受到外界干扰，达到内心的平静。

```python
def calculate_progress(user_id):
    sessions = Session.objects.filter(user_id=user_id)
    total_time = sum((session.end_time - session.start_time).total_seconds() for session in sessions)
    progress = int((total_time / 60) / 10)
    return progress
```
