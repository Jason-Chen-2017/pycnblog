### 3.2 Python代码实现  
以下代码实现了一个简单的书店数字化转型功能，包括书籍的添加和销售流程：

```python
class BookStore:
    def __init__(self, name):
        self.name = name
        self.books = []

    def add_book(self, book):
        """ 添加书籍到书店库存 """
        self.books.append(book)
        return f"书籍 '{book}' 已添加到 {self.name} 书店。"

    def sell_book(self, book):
        """ 销售书籍并更新库存 """
        if book in self.books:
            self.books.remove(book)
            return f"书籍 '{book}' 已售出，剩余库存：{len(self.books)}。"
        return f"书籍 '{book}' 不在库存中，无法售出。"

# 示例用法
store = BookStore("智慧书房")
store.add_book("《数字时代的阅读空间》")
store.add_book("《Python编程基础》")
print(store.sell_book("《数字时代的阅读空间》"))
```

### 3.3 数学模型与公式  
在分析数字化转型的效益时，我们可以使用以下数学公式来评估顾客满意度和运营效率：

$$
\text{效益} = f(\text{顾客满意度}, \text{运营效率})
$$

其中，顾客满意度可以通过以下公式计算：

$$
\text{顾客满意度} = \frac{\text{积极评价数}}{\text{总评价数}} \times 100\%
$$

而运营效率可以通过以下公式提升：

$$
\text{运营效率} = \frac{\text{处理订单数量}}{\text{时间}} 
$$
