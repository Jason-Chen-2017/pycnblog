## 2. 分子美食学的核心原理

### 2.1 凝胶化作用
凝胶化是指通过加入凝胶剂（如琼脂、明胶）使液体形成半固态凝胶的过程。这一过程的关键在于控制凝胶剂的浓度和温度。

| 凝胶剂类型 | 特性 | 应用 |
|------------|------|------|
| 琼脂        | 耐高温，可逆可溶 | 制作果冻、慕斯 |
| 明胶        | 不耐高温，不可逆 | 制作果冻、布丁 |

### 2.2 球化技术
球化技术通过将液体或半固态物质包裹在特定介质中，形成规则的球形结构。这一技术在冰淇淋制作中常用于创造出独特的球状甜品。

## 3. 冰淇淋制作的基础知识

### 3.1 冷冻原理
冷冻是通过降低温度使物质中的水分形成冰晶的过程。在冰淇淋制作中，关键在于控制冰晶的大小和分布，以确保口感的细腻。

### 3.2 冷凝过程
冷凝是指物质从气态转化为液态的过程。在冰淇淋制作中，冷凝过程主要用于制冷系统中。

### 3.3 温度控制与结晶
温度控制是冰淇淋制作的关键因素。通常，冰淇淋的最佳冷冻温度为-18°C。

    import math
    x = []
    y = []
    z = []
    for theta in range(0, 360):
        for phi in range(0, 180):
            x.append(r * math.sin(phi) * math.cos(theta))
            y.append(r * math.sin(phi) * math.sin(theta))
