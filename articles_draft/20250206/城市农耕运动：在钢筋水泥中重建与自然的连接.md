### 3.2 Python源代码

```python
import numpy as np
import pandas as pd

def calculate_optimal_plants(area, water, sunlight):
    # 计算最佳种植作物
    crops = ['蔬菜', '水果', '草药']
    # 根据面积和光照计算适合的作物
    optimal = []
    for crop in crops:
        if area > 5 and sunlight >= 6:
            optimal.append(crop)
    return optimal

# 示例数据
area = 10
water = 8
sunlight = 7

optimal_crops = calculate_optimal_plants(area, water, sunlight)
print("最佳种植作物:", optimal_crops)
```

### 3.3 数学模型和公式

$$ \text{种植面积} = \frac{\text{可用空间}}{\text{每株植物所需空间}} $$

$$ \text{水量} = \text{种植面积} \times \text{每单位面积的需水量} $$

### 3.4 详细讲解与举例说明
例如，假设一个屋顶面积为10平方米，每株植物需要1平方米，那么最多可以种植10株植物。根据光照和水资源的限制，选择适合的作物进行种植。
