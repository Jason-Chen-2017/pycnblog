#### 2.1.2 Python代码与LaTeX公式讲解

以下是基于HRV的冥想指导算法的Python代码：

```python
import numpy as np
from scipy import signal

# 示例心率数据（单位：ms）
heart_rate = np.array([700, 680, 720, 710, 700, 690, 730, 720])

# 计算心率变异性（HRV）
def calculate_hrv(hr_data):
    # 转换为RR间隔（单位：秒）
    rr_intervals = np.diff(hr_data) / 1000
    # 计算NN50（相邻50ms的差异）
    nn50 = sum([abs(rr_intervals[i] - rr_intervals[i-1]) for i in range(1, len(rr_intervals))]) / len(rr_intervals)
    return nn50

nn50 = calculate_hrv(heart_rate)
print(f"NN50: {nn50}")
```

公式解释：

$$ \text{NN50} = \frac{\sum_{i=1}^{n} |RR_i - RR_{i-1}|}{n} $$

其中，$RR_i$ 表示第 $i$ 个RR间隔，$n$ 为总间隔数。

#### 3.1.2 系统核心实现

以下是基于HRV的冥想指导算法的核心代码：

```python
import numpy as np
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/calculate_hrv', methods=['POST'])
def calculate_hrv():
    data = request.json['heart_rate']
    rr_intervals = np.diff(data) / 1000
    nn50 = sum(abs(rr_intervals[i] - rr_intervals[i-1]) for i in range(1, len(rr_intervals))) / len(rr_intervals)
    return jsonify({'nn50': nn50})

if __name__ == '__main__':
    app.run(debug=True)
```
