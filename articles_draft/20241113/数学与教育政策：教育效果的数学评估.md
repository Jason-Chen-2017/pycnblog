### A.2 核心算法的伪代码展示

以下是一个简单的线性回归模型的伪代码：

```plaintext
输入：X（自变量矩阵），Y（因变量向量）
输出：β（回归系数向量）

初始化：β = [0, 0, ..., 0]

对于每个特征 j：
    Σ = 0
    for i = 1 to n：
        Σ = Σ + (X[i, j] - mean(X[:, j])) * (Y[i] - mean(Y))
    β[j] = Σ / (n - 1)

返回：β
```

### A.3 代码实战案例与解读

在本附录中，我们将展示一个简单的线性回归模型的 Python 代码实现，并提供详细的解读。

```python
import numpy as np
import matplotlib.pyplot as plt

# 数据集：X（自变量矩阵），Y（因变量向量）
X = np.array([[1, 2], [2, 3], [3, 4], [4, 5]])
Y = np.array([3, 4, 5, 6])

# 模型构建
def linear_regression(X, Y):
    X_transpose = np.transpose(X)
    XTX = X_transpose.dot(X)
    XTY = X_transpose.dot(Y)
    β = np.linalg.inv(XTX).dot(XTY)
    return β

# 数据拟合
β = linear_regression(X, Y)

# 结果分析
print("回归系数：", β)

# 可视化
plt.scatter(X[:, 0], Y)
plt.plot(X[:, 0], X[:, 0].dot(β), color='red')
plt.xlabel("X1")
plt.ylabel("Y")
plt.show()

# 项目小结
"""
通过线性回归模型，我们成功地评估了自变量 X1 对因变量 Y 的影响。可视化结果展示了拟合直线与实际数据的拟合情况。虽然这个例子相对简单，但线性回归模型在教育政策评估中具有广泛的应用潜力。
"""
```
