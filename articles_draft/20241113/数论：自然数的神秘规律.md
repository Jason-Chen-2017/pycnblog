## 第一部分：数论基础

### 第1章：数论基本概念

#### 1.1.1 自然数的基本性质
自然数是从1开始的正整数集合，包括1, 2, 3, ...。它们具有以下基本性质：
- 增量性：每个自然数都比前一个自然数大1。
- 无限性：自然数集合是无限的，不存在最大的自然数。

#### 1.1.2 整除与最大公约数
整除是指一个整数可以被另一个非零整数整除，没有余数。例如，6可以整除3，因为6除以3等于2，没有余数。

最大公约数（GCD）是指两个或多个整数共有约数中最大的一个。例如，6和8的最大公约数是2。

#### 1.1.3 质数与合数
质数是指只能被1和自身整除的大于1的自然数。例如，2, 3, 5, 7都是质数。

合数是指除了1和自身外，还能被其他数整除的自然数。例如，4, 6, 8, 9都是合数。

### 第2章：数论基本定理

#### 2.1.1 偶数与奇数定理
偶数是可以被2整除的整数，奇数则不能被2整除。偶数与奇数之间存在以下规律：
- 偶数加偶数等于偶数。
- 偶数加奇数等于奇数。
- 奇数加奇数等于偶数。

#### 2.1.2 费马小定理
费马小定理是数论中的一个重要定理，它指出：如果p是一个质数，那么对于任何整数a，a的p次方减去a的结果可以被p整除。即，a^p ≡ a (mod p)。

#### 2.1.3 欧拉定理
欧拉定理是费马小定理的推广，它指出：如果a和n是两个互质的整数（即它们的最大公约数为1），那么a的欧拉函数φ(n)次方减去a的结果可以被n整除。即，a^φ(n) ≡ 1 (mod n)。

### 第3章：数论重要性质

#### 3.1.1 模运算的基本性质
模运算是一种在整数集合上的运算，通常表示为 a ≡ b (mod n)，意味着a和b在除以n后的余数相同。

模运算具有以下基本性质：
- 结合律：a ≡ b (mod n) 且 b ≡ c (mod n) 等价于 a ≡ c (mod n)。
- 分配律：a ≡ b (mod n) 且 c ≡ d (mod n) 等价于 a+c ≡ b+d (mod n)。
- 吸收律：a ≡ b (mod n) 且 n ≡ 0 (mod n) 等价于 a ≡ b (mod n)。

#### 3.1.2 同余的基本性质
同余是模运算的一个概念，表示两个整数在除以某个数后的余数相同。同余具有以下基本性质：
- 反身律：对于任何整数a，a ≡ a (mod n)。
- 对称律：如果a ≡ b (mod n)，则b ≡ a (mod n)。
- 传递律：如果a ≡ b (mod n)且b ≡ c (mod n)，则a ≡ c (mod n)。

#### 3.1.3 模意义下的乘法与除法
在模意义下，乘法和除法可以像在整数集合中一样进行。例如，如果a ≡ b (mod n)，c ≡ d (mod n)，则a*c ≡ b*d (mod n)。同样，如果a ≡ b (mod n)，且b不等于0，则存在唯一的整数x，使得a*x ≡ 1 (mod n)，即x是b在模n下的逆元。

### 第4章：数论核心算法

#### 4.1.1 欧几里得算法（求最大公约数）
欧几里得算法是一种用于求最大公约数的算法。它基于以下原理：两个整数的最大公约数等于其中较小数与较大数对较小数的余数的最大公约数。

伪代码如下：

```python
function gcd(a, b)
    while b ≠ 0
        temp = b
        b = a % b
        a = temp
    return a
```

#### 4.1.2 扩展欧几里得算法（求逆元）
扩展欧几里得算法是欧几里得算法的扩展，它可以用来求两个整数a和b的最大公约数，同时求出a在模b下的逆元。

伪代码如下：

```python
function extendedGcd(a, b)
    if b = 0
        return (1, 0, a)
    else
        (x, y, gcd) = extendedGcd(b, a % b)
        (temp, y) = (y, x - (a // b) * y)
        return (x, y, gcd)
```

#### 4.1.3 米勒-拉宾素性检验算法
米勒-拉宾素性检验算法是一种用于检测大整数是否为质数的算法。它利用质数的性质，通过一系列的模运算来判断一个数是否为质数。

伪代码如下：

```python
function millerRabin(n, k)
    if n = 2 or n = 3
        return true
    if n < 2 or n % 2 = 0
        return false

    r = 0
    s = n - 1
    while s % 2 = 0
        r += 1
        s /= 2

    for i = 1 to k
        a = random(2 to n - 2)
        x = pow(a, s, n)
        if x = 1 or x = n - 1
            continue

        for j = 1 to r - 1
            x = pow(x, 2, n)
            if x = n - 1
                continue
            else
                return false

        return false

    return true
```
