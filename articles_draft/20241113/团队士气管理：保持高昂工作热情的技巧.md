### 数学模型和公式

在团队士气管理中，可以使用以下数学模型来量化团队士气：

1. **士气指数**：士气指数是评估团队士气的重要指标。计算公式如下：
   $$士气指数 = \frac{满意度指数 + 动力指数 + 忠诚度指数}{3}$$

2. **士气波动度**：士气波动度反映了团队士气的变化幅度。计算公式如下：
   $$士气波动度 = \frac{当前士气指数 - 上次士气指数}{上次士气指数} \times 100\%$$

### 详细讲解与举例说明

**士气指数**是衡量团队士气的基础指标。通过计算士气指数，可以快速了解团队士气的高低。例如，如果士气指数在 7-10 分之间，说明团队士气较高；如果在 4-6 分之间，则说明团队士气一般；如果在 3 分以下，则表明团队士气较低。

**士气波动度**则反映了团队士气的变化情况。例如，如果一个团队的士气指数从上次的 8 分下降到当前的 6 分，士气波动度为 -25%，说明团队士气出现了明显下降。

import pandas as pd

# 读取数据
data = pd.read_csv('team_data.csv')

# 计算士气指数
satisfaction_index = data['satisfaction'].mean()

if morale_index < 5:
