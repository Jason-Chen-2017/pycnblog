#### 最小二乘法

最小二乘法是一种常用的数据拟合方法，用于求解数据点的最佳拟合线或面。该方法通过最小化误差平方和来确定参数的值。

**伪代码**：
```
function leastSquares(x, y):
    n = length(x)
    X = matrix([x, ones(n)])
    y = [y; 1]
    w = X'X
    v = X'y
    theta = inv(w)'v
    return theta
```

马尔可夫链蒙特卡洛方法是一种基于概率统计的数值计算方法，用于从复杂概率分布中抽样。该方法在宇宙学中用于模拟宇宙的随机过程，如宇宙大爆炸后的演化。

**伪代码**：
```
function MCMC(sampleFunction, proposalFunction, parameters, iterations):
    currentSample = sampleFunction(parameters)
    for i from 1 to iterations:
        proposedSample = proposalFunction(currentSample, parameters)
        acceptanceProbability = min(1, likelihood(proposedSample) / likelihood(currentSample))
        if random() < acceptanceProbability:
            currentSample = proposedSample
    return currentSample
```
