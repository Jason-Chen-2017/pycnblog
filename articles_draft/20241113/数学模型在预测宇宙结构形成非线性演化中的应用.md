#### 6.2 源代码实现

以下是一个简单的宇宙膨胀模型数值模拟的源代码实现：

```python
import numpy as np
import matplotlib.pyplot as plt

# 宇宙膨胀模型参数
H0 = 70  # 初始膨胀率
OmegaM = 0.3  # 暗物质密度比例
OmegaL = 0.7  # 暗能量密度比例
t_final = 14  # 演化时间
dt = 0.1  # 时间步长

# 计算宇宙膨胀率
def H(t):
    return H0 / np.sqrt(OmegaM * (1 + t)**3 + OmegaL)

# 演化过程
t = np.arange(0, t_final + dt, dt)
Ht = H(t)

# 绘制宇宙膨胀率曲线
plt.plot(t, Ht)
plt.xlabel("时间 (Gy)")
plt.ylabel("膨胀率 (km/s/Mpc)")
plt.title("宇宙膨胀率随时间变化")
plt.grid()
plt.show()
```

#### 6.3 代码解读

在上面的代码中，我们首先导入了必要的Python库，包括NumPy、SciPy和matplotlib。然后，我们定义了宇宙膨胀模型的参数，如初始膨胀率$H0$、暗物质密度比例$OmegaM$和暗能量密度比例$OmegaL$。

接着，我们定义了一个计算宇宙膨胀率的函数$H(t)$，它根据宇宙膨胀模型公式计算给定时间$t$的膨胀率。

在演化过程中，我们使用NumPy的`arange`函数生成一个时间序列数组，并使用`H`函数计算每个时间点的膨胀率。最后，我们使用matplotlib库绘制了宇宙膨胀率随时间变化的曲线。
