## 数学模型和公式讲解

### 牛顿的万有引力定律

$$ F = G\frac{m_1m_2}{r^2} $$

其中，$F$ 是两个物体之间的引力，$G$ 是引力常数，$m_1$ 和 $m_2$ 是两个物体的质量，$r$ 是两个物体之间的距离。

举例：

假设地球质量为 $5.972 \times 10^{24}$ 千克，月球质量为 $7.342 \times 10^{22}$ 千克，地球与月球之间的距离为 384,400 千米。那么地球对月球的引力为：

$$ F = G\frac{(5.972 \times 10^{24})(7.342 \times 10^{22})}{(384,400 \times 10^3)^2} \approx 1.986 \times 10^{20} \text{牛顿} $$

```python
import numpy as np
import matplotlib.pyplot as plt

def simulate_planet(mass, distance, velocity, time):
    acceleration = -G * mass / distance**2
    displacement = velocity * time + 0.5 * acceleration * time**2
    return displacement

# 模拟地球和月球的运动
earth_mass = 5.972 * 10**24
moon_mass = 7.342 * 10**22
earth_orbit = simulate_planet(earth_mass, 384400 * 10**3, 3070, 86400)
moon_orbit = simulate_planet(moon_mass, 384400 * 10**3, 1022, 27.3 * 24 * 3600)

# 绘制行星轨道
plt.plot(earth_orbit, label="Earth")
plt.plot(moon_orbit, label="Moon")
plt.xlabel("Time (days)")
plt.ylabel("Distance (km)")
plt.legend()
plt.show()
```

### 代码解读

这段代码定义了一个 `simulate_planet` 函数，用于模拟行星在引力作用下的运动。我们使用牛顿的万有引力定律计算行星的加速度，并使用运动学公式计算行星的位移。最后，我们使用matplotlib绘制行星轨道图。
