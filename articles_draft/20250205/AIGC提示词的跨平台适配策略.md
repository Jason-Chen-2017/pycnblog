#### 2.1.3 GPT模型的Python源代码解释

```python
class GPTModel:
    def __init__(self, vocab_size, embedding_dim, num_heads, feedforward_dim):
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.attention = MultiHeadAttention(embedding_dim, num_heads)
        self.feedforward = nn.Sequential(
            nn.Linear(embedding_dim, feedforward_dim),
            nn.ReLU(),
            nn.Linear(feedforward_dim, embedding_dim)
        )
    
    def forward(self, input, mask=None):
        embedded = self.embedding(input)
        attn_output = self.attention(embedded, embedded, mask)
        output = self.feedforward(attn_output)
        return output
```

#### 2.2 数学模型与公式解释

- **自注意力机制公式**：
  $$
  \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
  $$
  
- **GPT模型的数学公式**：
  $$
  \text{GPT}(x) = \text{softmax}\left(\text{W}_\text{out}\text{Tanh}\left(\text{MLP}(\text{Norm}(xW_\text{hidden})))\right)\right)
  $$
