## 第2章 核心概念与术语

### 2.1 零样本CoT的定义
零样本CoT是一种无监督学习方法，通过对比学习提升数据表示能力，尤其适用于小样本或零样本场景。

### 2.2 对比学习与传统学习对比

| 对比学习 | 传统监督学习 |
|----------|----------------|
| 数据无标签或部分标签 | 数据有标签 |
| 适用于小样本场景 | 适用于大数据场景 |
| 利用对比损失优化表示 | 利用分类损失优化分类 |

### 2.3 核心术语
- 对比损失（Contrastive Loss）
- 算法正则化（Algorithm Regularization）
- 表示学习（Representation Learning）

## 第3章 零样本CoT的基本原理

### 3.1 对比学习框架
通过最大化正样本相似性，最小化负样本相似性，构建数据的高质量表示。

### 3.2 对比损失函数

$$ \mathcal{L}(\theta) = -\frac{1}{N}\sum_{i=1}^{N}[\log(\text{sim}_+(x_i, y_i)) - \log(\text{sim}_-(x_i, y_j))] $$

其中，sim表示相似性函数，$\theta$为模型参数，N为样本数。

### 3.4 对比学习的优势
通过对比损失优化，提升模型在小样本场景下的泛化能力，减少对大量标注数据的依赖。

### 5.2 核心代码实现

```python
import torch
import torch.nn as nn

class ContrastiveLoss(nn.Module):
    def __init__(self, temperature=0.1):
        super(ContrastiveLoss, self).__init__()
        self.temperature = temperature

    def forward(self, features, labels):
        # 正样本对齐
        same_class = torch.eq(labels, labels.unsqueeze(1)).float()
        # 计算相似性
        sim = torch.mm(features, features.T) / self.temperature
        # 计算正样本和负样本损失
        positive_loss = (same_class * sim).sum(dim=1).mean()
        negative_loss = ((1 - same_class) * sim).sum(dim=1).mean()
        # 对比损失
        loss = -torch.mean(torch.log(torch.sigmoid(positive_loss - negative_loss)))
        return loss

# 示例使用
features = torch.randn(100, 512)
labels = torch.randint(0, 10, (100,))
loss = ContrastiveLoss()(features, labels)
print(loss.item())
```
