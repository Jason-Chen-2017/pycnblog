```python
def explain_model(model, input_features):
    # 特征提取
    coefficients = model.coef_
    # 解释生成
    feature_importance = dict(zip(input_features.columns, coefficients))
    return feature_importance
```

10.2 功能模块实现：

```python
class ModelExplainabilityFramework:
    def __init__(self, model, input_features):
        self.model = model
        self.input_features = input_features

    def generate_explanation(self):
        # 计算特征重要性
        coefficients = self.model.coef_
        # 生成解释
        explanation = {}
        for feature, coef in zip(self.input_features.columns, coefficients):
            explanation[feature] = coef
        return explanation
```
