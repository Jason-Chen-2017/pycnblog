#### 1.3 AI角色扮演能力的应用领域  
AI角色扮演能力广泛应用于以下几个领域：

def role_play(prompt):
    # 解析提示词
    role, behavior = prompt.split(':')
    # 生成角色行为
    response = f"{role}：{behavior}"
    return response

# 示例调用

### 第6章：项目实战

#### 6.1 环境安装

#### 6.2 系统核心实现源代码  
以下是实现AI角色扮演能力的核心代码：  

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

class RolePlayer:
    def __init__(self, model_name):
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModelForCausalLM.from_pretrained(model_name)
    
    def play_role(self, prompt):
        inputs = self.tokenizer.encode(prompt, return_tensors="pt")
        outputs = self.model.generate(inputs, max_length=50, do_sample=True)
        response = self.tokenizer.decode(outputs[0], skip_special_tokens=True)
        return response

# 示例调用
role_player = RolePlayer("gpt2")
print(role_player.play_role("医生：您感觉哪里不舒服？"))  # 输出："医生：我感到头痛。"
```

上述代码实现了基于预训练语言模型的角色扮演能力。通过传递提示词，AI可以生成符合特定角色的文本。
