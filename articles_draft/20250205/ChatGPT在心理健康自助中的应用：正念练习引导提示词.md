以下是系统核心功能的Python代码示例：

```python
import openai

openai.api_key = "your-api-key"

def generate_meditation_prompt(user_input):
    response = openai.Completion.create(
        engine="text-davinci-003",
        prompt=f"基于用户的输入：{user_input}\n生成一个正念练习的提示词，帮助用户放松身心。",
        max_tokens=150
    )
    return response.choices[0].text.strip()

# 示例用户输入
user_input = "我感到焦虑，难以入睡。"

# 生成提示词
prompt = generate_meditation_prompt(user_input)
print("生成的提示词：", prompt)
```
