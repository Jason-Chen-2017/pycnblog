#### 3.3 Python代码与算法实现

以下是算法的Python实现代码：

```python
def match_resource(family_demand, community_resource):
    # 需求与资源的匹配逻辑
    matched_resource = {}
    for demand in family_demand:
        for resource in community_resource:
            if demand['type'] == resource['type'] and demand['quantity'] <= resource['quantity']:
                matched_resource[demand['id']] = resource['id']
                break
    return matched_resource

# 示例输入
family_demand = [
    {'id': 1, 'type': '婴儿车', 'quantity': 1},
    {'id': 2, 'type': '奶粉', 'quantity': 5}
]
community_resource = [
    {'id': 1, 'type': '婴儿车', 'quantity': 2},
    {'id': 2, 'type': '奶粉', 'quantity': 10}
]

# 调用匹配函数
result = match_resource(family_demand, community_resource)
print(result)
```

#### 3.4 数学模型与公式解析

以下是资源匹配的优化模型：

$$
\text{最大化} \quad \sum_{i=1}^{n} x_i
$$

$$
\text{约束条件} \quad \sum_{i=1}^{n} a_i x_i \leq b_i \quad \forall i
$$

其中，$x_i$ 表示是否分配资源 $i$，$a_i$ 表示资源 $i$ 的可用数量，$b_i$ 表示资源 $i$ 的需求上限。
