## 第2章 量子计算基础

### 2.1 量子位与量子计算原理

#### 2.1.1 量子位的定义

量子位（qubit）是量子计算的基本单位，与经典计算中的比特（bit）类似。然而，量子位具有叠加态和纠缠态的特性，使其能够同时表示多种状态。以下是一个简单的量子位叠加态表达式：

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$

其中，$\alpha$ 和 $\beta$ 是复数，满足 $|\alpha|^2 + |\beta|^2 = 1$。

#### 2.1.2 量子叠加与量子纠缠

量子叠加是指量子位可以同时处于多个状态的叠加态。例如，两个量子位的叠加态可以表示为：

$$|\psi\rangle = \alpha|00\rangle + \beta|01\rangle + \gamma|10\rangle + \delta|11\rangle$$

量子纠缠是指两个或多个量子位之间的状态相互依赖，无法单独描述其中一个量子位的状态。例如，两个纠缠的量子位可以表示为：

$$|\psi\rangle = \frac{1}{\sqrt{2}}(|01\rangle + |10\rangle)$$
