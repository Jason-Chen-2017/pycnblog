# 第二部分: 核心概念与联系

## 第2章: 敏捷开发方法论与C侧LLM

### 2.1.1 敏捷开发方法论概述

敏捷开发方法论是一种以人为核心、迭代、增量的软件开发方法。其核心理念包括：快速响应变化、持续交付价值、强调团队合作等。常见的敏捷开发框架有Scrum、Kanban等。

### 2.1.2 敏捷开发方法论与C侧LLM的联系

敏捷开发方法论在C侧LLM开发中的应用具有重要意义。一方面，它可以提高开发效率，缩短项目周期；另一方面，它可以更好地适应需求变化，确保模型迭代与实际需求紧密贴合。

### 2.1.3 敏捷开发方法论的关键要素

1. 用户故事（User Story）：用户故事是敏捷开发的核心要素，它描述了用户的需求和期望。在C侧LLM开发中，用户故事可以帮助开发团队明确模型的功能和性能要求。
2. 眩光周期（Sprint）：眩光周期是敏捷开发中的一个迭代周期，通常为2-4周。在C侧LLM开发中，每个眩光周期可以完成一个或多个模型迭代。
3. 演示与回顾：演示是敏捷开发中的关键环节，用于展示迭代成果并获得用户反馈。回顾则是对迭代过程的反思和总结，有助于不断改进开发流程。
