## 2.1 量子计算的核心算法原理

### 2.1.1 量子位与量子态

量子位（qubit）是量子计算的基本单元，它具有叠加态和纠缠态等特性。量子态可以用波函数表示，例如：$$\left| \psi \right\rangle = \alpha \left| 0 \right\rangle + \beta \left| 1 \right\rangle$$，其中$\alpha$和$\beta$是复数系数，$\left| 0 \right\rangle$和$\left| 1 \right\rangle$是量子位的基础状态。

### 2.1.2 量子逻辑门

量子逻辑门是量子计算的核心操作，用于对量子态进行变换。常见的量子逻辑门包括 Hadamard 门（H）、Pauli X 门（X）、Pauli Z 门（Z）和 Controlled-NOT 门（CNOT）。以下是一个简单的量子逻辑门操作示例：

```markdown
$$X \left| \psi \right\rangle = \left| \psi \right\rangle_X = \begin{bmatrix}

\end{bmatrix} \left| \psi \right\rangle$$
```
