### 1.1 图数据库简介

#### 核心概念与联系

图数据库是一种用于存储和查询复杂关系网络的数据管理系统。在图数据库中，数据以图的形式存储，每个节点代表实体，每条边代表实体之间的关系。以下是一个简单的Mermaid流程图，展示了图数据库的核心概念和联系：


#### 图数据库的分类

根据存储模型的不同，图数据库可以分为以下几类：

- **邻接矩阵**：用二维数组表示图，适用于稀疏图和小规模图。
- **邻接表**：用链表表示图的每个节点及其邻接节点，适用于稀疏图。
- **哈希表**：通过哈希函数快速查找节点及其邻接节点，适用于大规模图。

### 1.3 图模型的基本算法

#### 图论基础

图模型的基本算法基于图论的基础知识，包括：

- **图的表示**：如何表示图，如邻接矩阵、邻接表等。
- **图的性质**：如连通性、路径长度等。
- **算法**：如最短路径算法、图遍历算法等。

#### 核心算法原理讲解

以下是两个常用的图算法：

- **最短路径算法**：用于计算图中两点之间的最短路径。

  - **迪杰斯特拉算法**（Dijkstra's algorithm）：适用于权值非负的图。
    ```pseudo
    function Dijkstra(G, start):
        initialize distances with infinity for all vertices
        distances[start] = 0
        for each vertex v in G:
            if v is not start:
                distances[v] = infinity
        for each edge (u, v) in G:
            if v is not start:
                distances[v] = min(distances[v], distance(u, v))
        return distances
    ```
  - **贝尔曼-福特算法**（Bellman-Ford algorithm）：适用于权值可以为负的图。
    ```pseudo
    function BellmanFord(G, start):
        initialize distances with infinity for all vertices
        distances[start] = 0
        for i from 1 to n-1:
            for each edge (u, v) in G:
                if distances[v] > distances[u] + weight(u, v):
                    distances[v] = distances[u] + weight(u, v)
        return distances
    ```

- **图遍历算法**：用于遍历图中的所有节点。

  - **深度优先搜索算法**（Depth-First Search, DFS）：用于寻找图的深度优先遍历路径。
    ```pseudo
    function DFS(G, start):
        mark start as visited
        for each unvisited neighbor v of start:
            DFS(G, v)
    ```
  - **广度优先搜索算法**（Breadth-First Search, BFS）：用于寻找图中的广度优先遍历路径。
    ```pseudo
    function BFS(G, start):
        initialize queue with start
        mark start as visited
        while queue is not empty:
            v = dequeue(queue)
            for each unvisited neighbor u of v:
                mark u as visited
                enqueue(u)
    ```
