#### 1.1 图的基本概念

**背景介绍**

- 图论起源于19世纪末，由欧拉解决哥尼斯堡七桥问题开始。
- 图论在计算机科学、网络工程、社会网络分析等多个领域有着广泛的应用。

**核心概念与联系**

- **节点（Vertex）**：图中的基本元素，表示实体。
- **边（Edge）**：连接节点的线段，表示节点间的关系。
- **无向图（Undirected Graph）**：边无方向，如社交网络。
- **有向图（Directed Graph）**：边有方向，如交通网络。

**核心算法原理讲解**

**伪代码**

```
// 初始化图
Graph G = new Graph();

// 添加节点
G.addVertex(A);
G.addVertex(B);
G.addVertex(C);
G.addVertex(D);

// 添加边
G.addEdge(A, B);
G.addEdge(B, C);
G.addEdge(C, D);
```

**数学模型和公式**

$$
度数(k) = \sum_{i=1}^{n} \text{边与节点 } i \text{ 相连的数量}
$$

**举例说明**

- **无向图**：表示朋友关系，边无方向。
- **有向图**：表示电子邮件发送，边有方向。

- **源代码详细实现和代码解读**
    ```python
    class Graph:
        def __init__(self):
            self.vertices = {}
        
        def addVertex(self, vertex):
            if vertex not in self.vertices:
                self.vertices[vertex] = []
        
        def addEdge(self, vertex1, vertex2):
            self.vertices[vertex1].append(vertex2)
            self.vertices[vertex2].append(vertex1)
    ```
