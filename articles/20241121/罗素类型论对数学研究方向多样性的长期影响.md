```python
class TypeJudge:
    def __init__(self):
        self.types = {
            "IntegerType": "整数类型",
            "StringType": "字符串类型",
            "ListType": "列表类型",
            "FunctionType": "函数类型",
            "UnknownType": "未知类型"
        }
    
    def typeJudge(self, value):
        if isinstance(value, int):
            return self.types["IntegerType"]
        elif isinstance(value, str):
            return self.types["StringType"]
        elif isinstance(value, list):
            return self.types["ListType"]
        elif callable(value):
            return self.types["FunctionType"]
        else:
            return self.types["UnknownType"]
```

### 罗素类型论的概述与历史背景

#### 罗素类型论的起源

罗素类型论（Russell's theory of types）起源于20世纪初，由英国哲学家和数学家伯特兰·罗素（Bertrand Russell）提出。罗素在其哲学和数学研究中，特别是面对集合论中的悖论时，开始思考如何构建一个无悖论的数学系统。这种思考导致了罗素类型论的诞生。

#### 罗素类型论的基本概念

罗素类型论的核心思想是区分不同类型的对象，以避免逻辑悖论。罗素认为，所有的数学对象都可以分为五类：

1. **第一类对象**：个体（Individuals），如自然数、物体等。
2. **第二类对象**：性质（Properties），如“是红色的”、“是大于2的”等。
3. **第三类对象**：集合（Sets），如“所有的偶数”、“所有的无理数”等。
4. **第四类对象**：函数（Functions），如“求和函数”、“判定函数”等。
5. **第五类对象**：类（Classes），如“所有的集合”、“所有的自然数”等。
