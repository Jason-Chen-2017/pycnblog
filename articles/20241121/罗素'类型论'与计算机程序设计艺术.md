1. **原子类型**：不可再分的对象，如数字和字母。
2. **复合类型**：由原子类型组成的复合对象，如函数和集合。
3. **函数类型**：定义了操作和参数的类型。

罗素通过引入类型论，区分了不同类型的对象，防止了悖论的产生。他的这一理论对后来的逻辑哲学和数学产生了深远的影响。

```java
public class Rectangle {

    private int height;

    public Rectangle(int width, int height) {
        if (width <= 0 || height <= 0) {
            throw new IllegalArgumentException("Width and height must be positive.");
        }
        this.width = width;
        this.height = height;
    }

        return width * height;
    }
}

public class Main {
    public static void main(String[] args) {
        try {
            Rectangle rectangle = new Rectangle(-1, 5);
            int area = rectangle.calculateArea();
            System.out.println("Area: " + area);
        } catch (IllegalArgumentException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

在上面的示例中，`Rectangle`类的构造函数通过检查参数的合法性来确保对象的正确性。如果宽度或高度为负数，将抛出`IllegalArgumentException`，从而防止创建不合法的对象。
