#### 类型类的定义

#### 类型类的语法
在 Haskell 中，类型类通过类（class）关键字定义。类定义了类型需要实现的方法，这些方法被称为类方法。

```haskell
class Eq a where

  (/=) :: a -> a -> Bool
```

#### 类型类的层次结构
类型类之间存在层次关系。子类继承了父类的所有方法，同时可以定义自己的方法。这种层次结构使得类型类系统更加灵活和强大。

#### 类型类的实例化
类型类实例化是指为某个具体类型实现类型类的所有方法。一旦一个类型被实例化，它就可以使用类型类中定义的所有操作。

```haskell
instance Eq Integer where
```
