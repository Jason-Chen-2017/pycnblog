## 第2章 椭圆曲线密码学基础理论

### 2.1 椭圆曲线定义与性质

椭圆曲线是一种特殊的数学曲线，其定义在有限域上。一个椭圆曲线可以表示为：

$$
E: y^2 = x^3 + ax + b \quad (a, b \in \mathbb{F}_p)
$$

其中，$\mathbb{F}_p$ 是一个素数域，$a$ 和 $b$ 是常数。椭圆曲线上的点包括无穷远点 $O$ 和有限点 $(x, y)$，其中满足上述方程。

椭圆曲线具有以下重要性质：

1. **封闭性**：椭圆曲线上的点集合构成一个阿贝尔群。
2. **双射性**：对于椭圆曲线上的任意两个点，都存在一条直线将它们连接起来。
3. **代数性质**：椭圆曲线上的点的运算满足交换律、结合律和单位元。

### 2.2 椭圆曲线离散对数问题

椭圆曲线离散对数问题（Elliptic Curve Discrete Logarithm Problem，ECDLP）是椭圆曲线密码学中的核心问题。它要求给定椭圆曲线 $E$ 上的两个点 $P$ 和 $Q$，找到整数 $k$ 使得 $Q = kP$。

ECDLP 的困难性是椭圆曲线密码学安全性的基础。在实际应用中，尽管存在高效的求解算法，但至今仍没有找到可以在多项式时间内解决 ECDLP 的算法。

### 2.3 椭圆曲线密码算法

椭圆曲线密码算法主要包括椭圆曲线数字签名算法（Elliptic Curve Digital Signature Algorithm，ECDSA）和椭圆曲线加密算法（Elliptic Curve Cryptography，ECC）。

#### 2.3.1 椭圆曲线数字签名算法（ECDSA）

ECDSA 是一种基于椭圆曲线离散对数问题的数字签名算法。其基本步骤如下：

1. **密钥生成**：选择一个大素数 $p$ 和一个素数 $a$，构造椭圆曲线 $E: y^2 = x^3 + ax + b$。然后，随机选择一个整数 $d$ 作为私钥，计算公钥 $Q = dG$，其中 $G$ 是椭圆曲线上的一个基点。
2. **签名生成**：给定消息 $m$，计算签名 $(r, s)$：
    ```mermaid
    graph TB
    A[m] --> B[h(m)]
    B --> C[k]
    C --> D[r]
    C --> E[s]
    ```

    其中，$h(m)$ 是消息的哈希值，$k$ 是随机数，$r = kG$，$s = (r + d \cdot h(m))^{-1} \mod n$，$n = (p - 1) \cdot q$，$q$ 是椭圆曲线的阶。

3. **签名验证**：验证签名 $(r, s)$ 的有效性：
    ```mermaid
    graph TB
    A[r] --> B[r']
    A[r] --> C[s']
    B --> D[h(m)]
    C --> D[h(m)]
    D --> E[V]
    ```

    其中，$r' = (h(m) + qs')^{-1} \mod n$，$V = r'P$。如果 $V = O$，则签名有效。

#### 2.3.2 椭圆曲线加密算法（ECC）

ECC 是一种公钥加密算法，其安全性基于椭圆曲线离散对数问题。ECC 的基本步骤如下：

1. **密钥生成**：选择一个大素数 $p$ 和一个素数 $a$，构造椭圆曲线 $E: y^2 = x^3 + ax + b$。然后，随机选择一个整数 $d$ 作为私钥，计算公钥 $Q = dG$，其中 $G$ 是椭圆曲线上的一个基点。
2. **加密**：给定明文 $m$ 和公钥 $Q$，计算密文 $c$：
    ```mermaid
    graph TB
    A[m] --> B[k]
    B --> C[r]
    B --> D[s]
    D --> E[c]
    ```

    其中，$k$ 是随机数，$r = kG$，$s = m + dr$，$c = (r, s)$。
3. **解密**：给定密文 $c$ 和私钥 $d$，计算明文 $m$：
    ```mermaid
    graph TB
    A[c] --> B[r]
    A[c] --> C[s]
    B --> D[r']
    C --> D[s']
    D --> E[m]
    ```

    其中，$r' = s'd^{-1} \mod n$，$s' = (r - m) \mod n$，$m = s'r^{-1} \mod n$。

通过上述步骤，我们可以看到椭圆曲线密码算法在实现高效加密和解密的同时，保持了较高的安全性。
