### 第1章：算法基础与数据结构

算法与数据结构是计算机科学的基础，掌握这些基础是解决复杂问题的前提。本章节将介绍算法的基本概念与分类，以及常见的数据结构及其时间复杂度分析，为后续面试题的解答奠定基础。

### 1.1 算法概述

算法可以理解为解决问题的一系列明确指令，具有输入、输出和步骤三个基本组成部分。算法可以根据不同的标准进行分类，常见的分类方法包括：

- **按功能分类**：基础算法、排序算法、搜索算法、图算法、数学算法等。
- **按实现方式分类**：递归算法、迭代算法、贪心算法、分治算法等。
- **按时间复杂度分类**：线性算法、对数算法、多项式算法等。

### 1.2 数据结构基础

数据结构是算法的基础，合理选择和使用数据结构可以显著影响算法的性能。常见的数据结构包括：

- **数组**：用于存储固定大小的数据集合，支持随机访问。
- **链表**：由节点组成的数据结构，支持动态扩容和插入删除操作。
- **栈**：后进先出（LIFO）的数据结构，常见于深度优先搜索等。
- **队列**：先进先出（FIFO）的数据结构，常见于广度优先搜索等。
- **哈希表**：通过哈希函数快速查找元素的数据结构，支持快速的插入、删除和查找操作。

每种数据结构都有其优缺点，选择合适的数据结构可以显著提高算法的性能。

### 1.3 算法分析与优化

算法分析是评估算法性能的重要方法，主要包括时间复杂度和空间复杂度。时间复杂度表示算法执行时间与数据规模的关系，常用大O符号表示。例如，线性查找算法的时间复杂度为O(n)，二分查找算法的时间复杂度为O(logn)。

算法优化的目标是提高算法的效率，常见的方法包括：

- **降低时间复杂度**：通过改进算法逻辑或选择更高效的数据结构。
- **空间复杂度优化**：减少算法执行过程中所需的空间，如使用原地算法。
- **贪心算法**：在每一步选择最优解，适用于某些特定问题。
- **动态规划**：通过保存中间结果避免重复计算，适用于具有重叠子问题的优化问题。

### 2.1 排序算法面试题

排序算法是算法面试中的常见题目，包括冒泡排序、选择排序、插入排序等。

#### 冒泡排序

冒泡排序是一种简单的排序算法，通过重复交换相邻的未排序元素，直到整个序列有序。其时间复杂度为O(n^2)，适用于小规模数据的排序。

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr
```

#### 选择排序

选择排序是一种简单的选择算法，每次从剩余未排序的元素中选出最小（或最大）的元素放到序列的起始位置。其时间复杂度同样为O(n^2)，但比冒泡排序略优。

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```

#### 插入排序

插入排序是一种插入元素的排序算法，通过将未排序元素插入到已排序序列中的合适位置，直到整个序列有序。其时间复杂度为O(n^2)，但在数据基本有序的情况下性能很好。

```python
def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]
        j = i-1
        while j >= 0 and arr[j] > key:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key
    return arr
```

### 2.2 搜索算法面试题

搜索算法是算法面试中的常见题目，包括二分查找、深度优先搜索、广度优先搜索等。

#### 二分查找

二分查找是一种高效的查找算法，通过将有序数组分为两部分，不断缩小查找范围，直到找到目标元素或确定不存在。其时间复杂度为O(logn)。

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

#### 深度优先搜索

深度优先搜索是一种遍历或搜索树的算法，通过不断深入树的分支，直到找到目标或到达树的叶节点。其时间复杂度为O(n)。

```python
def dfs(graph, node, target):
    visited = set()
    stack = [node]
    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            if node == target:
                return True
            for neighbor in graph[node]:
                stack.append(neighbor)
    return False
```

#### 广度优先搜索

广度优先搜索是一种遍历或搜索树的算法，通过逐层遍历树的节点，直到找到目标或到达树的叶节点。其时间复杂度为O(n)。

```python
from collections import deque

def bfs(graph, start, target):
    visited = set()
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            if node == target:
                return True
            for neighbor in graph[node]:
                queue.append(neighbor)
    return False
```

### 2.3 动态规划面试题

动态规划是一种解决最优化问题的算法方法，通过保存子问题的解，避免重复计算。常见的动态规划问题包括最长公共子序列、最长上升子序列和背包问题等。

#### 最长公共子序列

最长公共子序列（Longest Common Subsequence, LCS）问题是寻找两个序列的最长公共子序列。

```python
def lcs(X, Y):
    m = len(X)
    n = len(Y)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if X[i-1] == Y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

#### 最长上升子序列

最长上升子序列（Longest Increasing Subsequence, LIS）问题是寻找一个序列的最长递增子序列。

```python
def lis(nums):
    dp = [1] * len(nums)
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[i] > nums[j]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

#### 背包问题

背包问题是一种常见的动态规划问题，给定一组物品和它们的重量及价值，求解在背包容量限制下如何选取物品以获得最大价值。

```python
def knapsack(W, wt, val, n):
    dp = [[0] * (W+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for w in range(1, W+1):
            if wt[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], dp[i-1][w-wt[i-1]] + val[i-1])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][W]
```

### 2.4 图算法面试题

图算法是计算机科学中重要的算法类别，包括图的遍历、最短路径问题和最小生成树等。

#### 图的遍历

图的遍历算法包括深度优先搜索（DFS）和广度优先搜索（BFS）。

```python
def dfs(graph, node, visited):
    visited.add(node)
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            for neighbor in graph[node]:
                queue.append(neighbor)
    return visited
```

#### 最短路径问题

最短路径问题有多种算法可以求解，包括迪杰斯特拉算法（Dijkstra）和贝尔曼-福特算法（Bellman-Ford）。

```python
def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]
    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        if current_distance > distances[current_node]:
            continue
        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    return distances

def bellman_ford(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    for _ in range(len(graph) - 1):
        for u in graph:
            for v in graph[u]:
                if distances[u] + graph[u][v] < distances[v]:
                    distances[v] = distances[u] + graph[u][v]
    for u in graph:
        for v in graph[u]:
            if distances[u] + graph[u][v] < distances[v]:
                return "Negative cycle detected"
    return distances
```

#### 最小生成树

最小生成树（Minimum Spanning Tree, MST）是连接图中所有节点的边权之和最小的树。常见的算法包括普里姆算法（Prim）和克鲁斯卡尔算法（Kruskal）。

```python
def prim(graph):
    mst = []
    visited = set()
    start = next(iter(graph))
    visited.add(start)
    while len(visited) < len(graph):
        min_edge = None
        for node in visited:
            for neighbor, weight in graph[node].items():
                if neighbor not in visited and (min_edge is None or weight < min_edge[1]):
                    min_edge = (node, neighbor, weight)
        if min_edge:
            mst.append(min_edge)
            visited.add(min_edge[1])
    return mst
```

#### 概率问题

概率问题在算法面试中经常出现，常见的题型包括条件概率、独立事件和期望等。

```python
def conditional_probability(A, B):
    return A and B / A

def independence(A, B):
    return conditional_probability(A and B, A) == conditional_probability(B, A)

def expected_value(values, probabilities):
    return sum(value * probability for value, probability in zip(values, probabilities))
```

```python
def solve_linear_equation(a, b, c):
    return (-b + sqrt(b**2 - 4*a*c)) / (2*a), (-b - sqrt(b**2 - 4*a*c)) / (2*a)

def derivative(function, x):

def integral(function, a, b):
```

#### 5.2 实战题目二：商品搜索优化

商品搜索优化是一种基于搜索引擎优化技术提高商品搜索质量和用户体验的方法。以下是一个简单的商品搜索优化实现。

```python
import re
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 加载数据
data = pd.read_csv("ecommerce_data.csv")

# 预处理数据
data["search_query"] = data["title"] + " " + data["description"]

# 创建TF-IDF向量器
vectorizer = TfidfVectorizer()

# 计算文档矩阵
X = vectorizer.fit_transform(data["search_query"])

# 创建查询向量
query = "搜索关键词"
query_vector = vectorizer.transform([query])

# 计算余弦相似度
similarity = cosine_similarity(query_vector, X)

# 获取相似度最高的商品
top_indices = similarity.argsort()[0][-5:][::-1]
top_products = data.iloc[top_indices]

print(top_products)
```
