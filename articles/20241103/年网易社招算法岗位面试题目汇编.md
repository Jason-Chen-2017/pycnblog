##### 1.2 常见算法分析
- **时间复杂度和空间复杂度**
  - 时间复杂度是指算法执行时间与数据规模的关系，通常用大O符号表示。
  - 空间复杂度是指算法执行过程中所需的额外内存空间。
  
- **常见排序算法**（冒泡排序、选择排序、插入排序、快速排序、归并排序等）
  - **冒泡排序**：每次比较相邻的两个元素，如果它们的顺序错误就把它们交换过来。
  - **选择排序**：每次从未排序的元素中找到最小（或最大）的元素，将其放到已排序序列的末尾。
  - **插入排序**：通过构建有序序列，对于未排序数据，在已排序序列中从后向前扫描，找到相应位置并插入。
  - **快速排序**：通过一趟排序将数据分割成独立的两部分，其中一部分的所有数据都比另一部分的所有数据要小。
  - **归并排序**：将两个或两个以上的有序表合并成一个新的有序表。

##### 1.3 算法思维与解题技巧
- **算法设计的常用策略**（递归、分治、动态规划等）
  - **递归**：函数调用自身，适用于解决许多问题，如递归求解斐波那契数列。
  - **分治**：将问题分解成更小的子问题，然后递归解决每个子问题，最后合并子问题的解。
  - **动态规划**：通过保存子问题的解来避免重复计算，适用于求解最优子结构问题。

##### 2.1 排序算法原理讲解
- **伪代码**：冒泡排序、选择排序、插入排序、快速排序、归并排序等
  - **冒泡排序**：
    ```pseudo
    function bubbleSort(arr):
        n = length(arr)
        for i from 0 to n-1:
            for j from 0 to n-i-1:
                if arr[j] > arr[j+1]:
                    swap(arr[j], arr[j+1])
    ```
  - **选择排序**：
    ```pseudo
    function selectionSort(arr):
        n = length(arr)
        for i from 0 to n-1:
            minIndex = i
            for j from i+1 to n:
                if arr[j] < arr[minIndex]:
                    minIndex = j
            swap(arr[i], arr[minIndex])
    ```
  - **插入排序**：
    ```pseudo
    function insertionSort(arr):
        n = length(arr)
        for i from 1 to n:
            key = arr[i]
            j = i - 1
            while j >= 0 and arr[j] > key:
                arr[j+1] = arr[j]
                j = j - 1
            arr[j+1] = key
    ```
  - **快速排序**：
    ```pseudo
    function quickSort(arr, low, high):
        if low < high:
            pi = partition(arr, low, high)
            quickSort(arr, low, pi-1)
            quickSort(arr, pi+1, high)

    function partition(arr, low, high):
        pivot = arr[high]
        i = low - 1
        for j from low to high-1:
            if arr[j] < pivot:
                i = i + 1
                swap(arr[i], arr[j])
        swap(arr[i+1], arr[high])
        return i+1
    ```
  - **归并排序**：
    ```pseudo
    function mergeSort(arr, low, high):
        if low < high:
            mid = low + (high - low) / 2
            mergeSort(arr, low, mid)
            mergeSort(arr, mid+1, high)
            merge(arr, low, mid, high)

    function merge(arr, low, mid, high):
        n1 = mid - low + 1
        n2 = high - mid
        left = arr[low:mid+1]
        right = arr[mid+1:high+1]

        i = 0
        j = 0
        k = low
        while i < n1 and j < n2:
            if left[i] <= right[j]:
                arr[k] = left[i]
                i = i + 1
            else:
                arr[k] = right[j]
                j = j + 1
            k = k + 1

        while i < n1:
            arr[k] = left[i]
            i = i + 1
            k = k + 1

        while j < n2:
            arr[k] = right[j]
            j = j + 1
            k = k + 1
    ```

##### 2.2 搜索算法原理讲解
- **二分查找**：在有序数组中查找某个元素的过程，通过比较中间元素和目标元素的大小，逐步缩小查找范围。
- **深度优先搜索（DFS）**：通过栈或递归来实现，从一个起点开始，沿着一个路径走到底，然后再回溯。
- **广度优先搜索（BFS）**：使用队列来实现，从一个起点开始，逐层遍历所有相邻节点。

- **伪代码**：深度优先搜索实现及分析
  ```pseudo
  function dfs(graph, start):
      visited = set()
      stack = []
      stack.append(start)
      while stack is not empty:
          vertex = stack.pop()
          if vertex not in visited:
              visited.add(vertex)
              for neighbor in graph[vertex]:
                  stack.append(neighbor)
      return visited

  function bfs(graph, start):
      visited = set()
      queue = []
      queue.append(start)
      while queue is not empty:
          vertex = queue.pop(0)
          if vertex not in visited:
              visited.add(vertex)
              for neighbor in graph[vertex]:
                  queue.append(neighbor)
      return visited
  ```

##### 3.1 字符串匹配算法
- **KMP算法**：通过预先计算最长公共前后缀数组（next数组），减少重复匹配过程。
- **Rabin-Karp算法**：使用哈希函数来快速查找模式串在主串中的出现位置。

- **伪代码**：KMP算法实现及分析
  ```pseudo
  function KMP(mainString, pattern):
      next = computeNextArray(pattern)
      i = 0 // index for mainString
      j = 0 // index for pattern
      while i < length(mainString):
          if mainString[i] == pattern[j]:
              i = i + 1
              j = j + 1
              if j == length(pattern):
                  return i - j
          else:
              if j != 0:
                  j = next[j - 1]
              else:
                  i = i + 1
      return -1

  function computeNextArray(pattern):
      next = array of length(pattern)
      next[0] = -1
      j = 0
      k = -1
      while j < length(pattern) - 1:
          if k == -1 or pattern[j] == pattern[k]:
              k = k + 1
              j = j + 1
              next[j] = k
          else:
              k = next[k - 1]
      return next
  ```

#### 第4章：动态规划算法

##### 4.1 动态规划基本概念
- **动态规划的核心思想**：通过保存子问题的解来避免重复计算，适用于求解最优子结构问题。
- **常用方法**（自底向上、自顶向下）
  - **自底向上**：从最简单的子问题开始，逐步构建复杂子问题的解。
  - **自顶向下**：从最复杂的子问题开始，使用递归来解决子问题。

##### 4.2 常见动态规划问题
- **最长递增子序列**：给定一个数组，找出最长递增子序列的长度。
- **最短路径问题**：在加权图中找出从起点到终点的最短路径。
- **背包问题**：给定一组物品和其重量和价值，求解在总重量不超过给定限制的情况下，如何选择物品以最大化总价值。

- **伪代码**：最长递增子序列算法实现及分析
  ```pseudo
  function longestIncreasingSubsequence(nums):
      n = length(nums)
      dp = array of length n filled with 1
      for i from 1 to n:
          for j from 0 to i-1:
              if nums[j] < nums[i]:
                  dp[i] = max(dp[i], dp[j] + 1)
      return max(dp)

  function LCS(X[1..m], Y[1..n]):
      Let dp[i][j] be the length of LCS of X[1..i] and Y[1..j].
      Create a 2-dimensional array dp[0..m][0..n].

      for i = 0 to m:
          for j = 0 to n:
              if i = 0 or j = 0:
                  dp[i][j] = 0
              else if X[i] = Y[j]:
                  dp[i][j] = dp[i-1][j-1] + 1
              else:
                  dp[i][j] = max(dp[i-1][j], dp[i][j-1])
      return dp[m][n]
  ```

##### 4.3 动态规划实战
- **实战案例**：最长公共子序列、最小编辑距离等。
  - **最长公共子序列**：
    ```python
    def longest_common_subsequence(X, Y):
        m, n = len(X), len(Y)
        dp = [[0] * (n+1) for _ in range(m+1)]

        for i in range(1, m+1):
            for j in range(1, n+1):
                if X[i-1] == Y[j-1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])

        return dp[m][n]

    X = "ABCD"
    Y = "ACDF"
    print(longest_common_subsequence(X, Y))
    ```
  - **最小编辑距离**：
    ```python
    def min_edit_distance(str1, str2):
        m, n = len(str1), len(str2)
        dp = [[0] * (n+1) for _ in range(m+1)]

        for i in range(m+1):
            for j in range(n+1):
                if i == 0:
                    dp[i][j] = j
                elif j == 0:
                    dp[i][j] = i
                elif str1[i-1] == str2[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                else:
                    dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])

        return dp[m][n]

    str1 = "kitten"
    str2 = "sitting"
    print(min_edit_distance(str1, str2))
    ```

#### 第5章：贪心算法

##### 5.1 贪心算法原理讲解
- **贪心策略的基本概念**：在每一步选择时都做出当前看来最好的选择，希望由此导致结果是全局最优的。
- **应用场景**：适合于具有最优子结构性质的问题，如背包问题、活动选择问题等。

##### 5.2 常见贪心算法问题
- **背包问题**：给定一组物品和其重量和价值，求解在总重量不超过给定限制的情况下，如何选择物品以最大化总价值。
- **最小生成树问题**：在连通无向图中选择若干条边，使得这些边构成一个树，且边的权重之和最小。

- **伪代码**：背包问题算法实现及分析
  ```pseudo
  function knapsack(values, weights, capacity):
      n = length(values)
      dp = array of length n filled with 0
      for i from 1 to n:
          if weights[i] <= capacity:
              dp[i] = max(dp[i-1], dp[i-1] + values[i])
          else:
              dp[i] = dp[i-1]
      return dp[n]
  ```

##### 5.3 贪心算法实战
- **实战案例**：活动选择问题、背包问题等。
  - **活动选择问题**：给定一系列活动，每个活动有开始时间和结束时间，选择最多的不相交活动。
    ```python
    def activity_selection(s, f):
        n = len(s)
        activities = []
        for i in range(n):
            for j in range(i + 1, n):
                if f[i] <= s[j]:
                    break
                activities.append((s[i], f[i]))
        return activities

    s = [1, 3, 0, 5, 8, 5]
    f = [2, 4, 6, 7, 9, 9]
    print(activity_selection(s, f))
    ```

  def knapsack(values, weights, capacity):
      n = len(values)
      dp = [0] * (capacity + 1)
      for i in range(n):
          for w in range(capacity, weights[i] - 1, -1):
              dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
      return dp[capacity]
