### 3.2 Python源代码

```python
import torch
import torch.nn as nn

class ZeroShotModel(nn.Module):
    def __init__(self, input_dim, latent_dim, output_dim):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, latent_dim),
            nn.ReLU(),
            nn.Linear(latent_dim, latent_dim),
            nn.ReLU()
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, output_dim),
            nn.Sigmoid()
        )

    def forward(self, x):
        z = self.encoder(x)
        return self.decoder(z)

# 示例数据
input_dim = 10
latent_dim = 5
output_dim = 5

model = ZeroShotModel(input_dim, latent_dim, output_dim)
```

### 3.3 数学模型和公式

模型的数学表达式如下：

- **潜在向量生成**：
  $$ z = f_{\theta}(x) $$
  其中，$x$ 是输入材料数据，$f_{\theta}$ 是编码器网络。

- **属性预测**：
  $$ y = g_{\phi}(z) $$
  其中，$g_{\phi}$ 是解码器网络，输出材料特性预测值。
