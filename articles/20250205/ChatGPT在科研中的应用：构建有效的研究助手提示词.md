### 第2章：自然语言处理基础

#### 2.1 语言模型与统计语言模型

语言模型预测下一个词的概率，统计模型依赖词频统计，如n-gram模型。

#### 2.2 递归神经网络（RNN）

RNN处理序列数据，通过循环层处理序列，但存在梯度消失问题。

#### 2.3 Transformer模型详解

Transformer由编码器和解码器组成，使用自注意力机制处理长序列，计算公式如下：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

```python
import openai

def generate_paper_summary(prompt):
    client = openai.Client()
    response = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[{"role": "user", "content": prompt}]
    )
    return response.choices[0].message.content
```
