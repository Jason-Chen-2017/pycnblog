## 2.4 零样本学习数学模型与公式

### 2.4.1 数学模型介绍
- 基于特征的零样本分类模型：通过计算测试样本与各类别的距离进行分类。

### 2.4.2 公式讲解
- 假设类别数为C，测试样本x，类别标签y属于{1,2,...,C}。
- 分类概率：P(y|x) = exp(d(x,y)) / sum_{k=1到C} exp(d(x,k))，其中d(x,y)是距离函数。

- 示例：在图像分类中，计算测试图像与各类别的平均距离，选择距离最小的类别。

#### 基于对比学习的零样本分类代码示例
```python
import torch
import torch.nn as nn
import torch.optim as optim

class ZeroShotClassifier(nn.Module):
    def __init__(self, feature_dim, num_classes):
        super().__init__()
        self.feature_dim = feature_dim
        self.num_classes = num_classes
        self.prototype = nn.Parameter(torch.randn(feature_dim, num_classes))

    def forward(self, x):
        x = x.view(-1, x.size(-1))
        cosine = torch.mm(x, self.prototype)
        return cosine / x.size(-1)

def contrastive_loss(x, y, margin=0.5):
    # 计算对比损失
    loss = (1 - torch.mm(x, y.T))**2
    return loss.mean()

# 示例训练
model = ZeroShotClassifier(512, 10)
optimizer = optim.Adam(model.parameters(), lr=1e-4)
criterion = contrastive_loss()
```
