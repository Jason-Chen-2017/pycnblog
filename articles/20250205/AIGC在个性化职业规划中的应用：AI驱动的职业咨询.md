## 第二部分：AIGC 基础概念与原理

### 2.1 AIGC 概念

#### 2.1.1 定义

生成式AI（AIGC）是一种基于深度学习的技术，能够生成与人类创作的作品相似的内容，如文本、图像和音乐。

#### 2.1.2 发展历程

从2014年的VAE到2017年的GAN，生成式AI经历了从简单到复杂的演变。近年来，基于Transformer架构的模型（如GPT）进一步推动了AIGC的发展。

#### 2.1.3 特点与应用场景

AIGC具有生成多样性、可定制化和高效性等特点，广泛应用于内容生成、图像设计和个性化推荐等领域。

### 2.2 AIGC 技术原理

#### 2.2.1 生成对抗网络（GAN）

##### 2.2.1.1 GAN 的基本架构

GAN由生成器和判别器组成，生成器通过不断优化生成内容，使其欺骗判别器。这一过程形成对抗训练，使生成器能力不断提升。

##### 2.2.1.2 GAN 的工作原理

判别器通过概率评估输入是否为真实数据，生成器则通过最小化判别器的损失函数，生成与真实数据相似的内容。

##### 2.2.1.3 GAN 在个性化职业规划中的应用

GAN可以用于生成职业建议文本，帮助用户探索不同职业路径的可能性。

##### 2.2.1.4 GAN 的优缺点

优点：生成内容具有多样性和创造性；缺点：训练过程不稳定，生成质量不稳定。

##### 2.2.1.5 GAN 的数学模型

判别器损失函数：
$$ L_d = -\mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] - \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))] $$
生成器损失函数：
$$ L_g = -\mathbb{E}_{z \sim p_z}[\log D(G(z))] $$

import torch

class Discriminator(nn.Module):

#### 2.2.2 变分自编码器（VAE）

##### 2.2.2.1 VAE 的基本架构

VAE由编码器和解码器组成，编码器将输入数据压缩为隐变量，解码器将隐变量还原为生成数据。

##### 2.2.2.2 VAE 的工作原理

VAE通过最大化似然和正则化KL散度，实现数据的高效编码和生成。

##### 2.2.2.3 VAE 在个性化职业规划中的应用

VAE可以用于职业兴趣的生成和分类，帮助用户识别潜在的职业兴趣。

##### 2.2.2.4 VAE 的优缺点

优点：生成数据具有良好的语义结构；缺点：生成内容缺乏多样性和创造性。

##### 2.2.2.5 VAE 的数学模型

VAE的目标函数：
$$ \mathcal{L} = \mathbb{E}_{x}[ \mathbb{E}_{z}[ \log p(x|z) ] ] + KL(q(z|x)||p(z)) $$

##### 2.2.2.6 VAE 的代码实现示例

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, latent_dim=100, input_dim=784):
        super(VAE, self).__init__()
        self.latent_dim = latent_dim
        self.input_dim = input_dim
        
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, latent_dim * 2)
        )
        
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, input_dim),
            nn.Sigmoid()
        )
    
    def encode(self, x):
        h = self.encoder(x)
        mu, log_var = h[:, :self.latent_dim], h[:, self.latent_dim:]
        return mu, log_var
    
    def reparameterize(self, mu, log_var):
        eps = torch.randn_like(log_var)
        return mu + eps * torch.exp(0.5 * log_var)
    
    def decode(self, z):
        return self.decoder(z)
    
    def forward(self, x):
        mu, log_var = self.encode(x)
        z = self.reparameterize(mu, log_var)
        return self.decode(z), mu, log_var
```
