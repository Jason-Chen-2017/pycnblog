#### 1.1 文化遗产保护的现状与挑战

- **数字化需求**：文化遗产的保存、传播和研究需要数字化手段，但传统方法效率低下，难以满足需求。

- **生成式AI**：基于深度学习模型（如GPT、Diffusion等）生成内容。  
- **提示词设计**：通过设计提示词（prompt）引导AI生成符合特定需求的内容。

```python
import numpy as np

def calculate_similarity(word_vector1, word_vector2):
    dot_product = np.dot(word_vector1, word_vector2)
    magnitude_product = np.linalg.norm(word_vector1) * np.linalg.norm(word_vector2)
    similarity = dot_product / magnitude_product
    return similarity

# 示例：计算两个词向量的相似度
word_vector1 = np.random.rand(1, 100)
word_vector2 = np.random.rand(1, 100)
similarity = calculate_similarity(word_vector1, word_vector2)
print(f"相似度：{similarity}")
```

#### 5.2 核心代码实现  
以下是提示词设计的核心代码：  

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

def generate_content(prompt):
    inputs = tokenizer.encode(prompt, return_tensors="np")
    outputs = model.generate(inputs, max_length=500, do_sample=True)
    return tokenizer.decode(outputs[0], skip_special_tokens=True)

# 示例：生成历史解释内容
prompt = "解释一下唐朝的文化特点。"
result = generate_content(prompt)
print(result)
```
