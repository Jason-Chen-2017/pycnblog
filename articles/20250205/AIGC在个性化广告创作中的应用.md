# 第三部分：算法原理讲解

## 3.1 AIGC的核心算法

### 3.1.1 生成对抗网络（GAN）

生成对抗网络是一种由生成器和判别器组成的深度学习模型。生成器的目标是生成与真实数据相似的内容，而判别器则试图区分生成内容和真实内容。通过不断迭代，生成器能够生成越来越逼真的内容。

#### GAN的数学模型

生成器的损失函数：
$$ L_{G} = -\log(D(G(z))) $$
判别器的损失函数：
$$ L_{D} = -\log(D(x)) - \log(1 - D(G(z))) $$

其中，$x$ 是真实数据，$z$ 是随机噪声，$G$ 是生成器，$D$ 是判别器。

### 3.1.2 变体自编码器（VAE）

变体自编码器是一种生成模型，通过将输入数据映射到潜在空间，然后从潜在空间生成新的数据。VAE通过最大化似然函数和KL散度来优化模型。

#### VAE的数学模型

编码器：
$$ q(z|x) = \mathcal{N}(\mu(x), \sigma(x)^2) $$
解码器：
$$ p(x|z) = \mathcal{N}(x|\mu(z), \sigma(z)^2) $$
损失函数：
$$ \mathcal{L} = -\mathbb{E}_{x,z}[ \log p(x|z) ] + \text{KL}(q(z|x) || p(z)) $$

```python
class VAE(nn.Module):
    def __init__(self, input_dim, latent_dim):
        super(VAE, self).__init__()
        self latent_dim = latent_dim
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 512),
            nn.ReLU(),
            nn.Linear(512, latent_dim * 2)
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 512),
            nn.ReLU(),
            nn.Linear(512, input_dim)
        )

    def encode(self, x):
        h = self.encoder(x)
        mu, log_var = torch.chunk(h, 2, dim=-1)
        return mu, log_var

    def reparameterize(self, mu, log_var):
        std = torch.exp(0.5 * log_var)
        eps = torch.randn_like(std)
        return eps * std + mu

    def decode(self, z):
        return self.decoder(z)

    def forward(self, x):
        mu, log_var = self.encode(x)
        z = self.reparameterize(mu, log_var)
        return self.decode(z), mu, log_var
```
