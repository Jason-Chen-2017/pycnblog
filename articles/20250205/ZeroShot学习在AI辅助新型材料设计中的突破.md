## 第2章：核心概念与联系

### 2.1 Zero-Shot学习定义

Zero-Shot学习是指模型在没有任务特定训练数据的情况下，能够直接预测目标输出的能力。

### 2.2 Zero-Shot学习的特点

- **零样本适应**：无需任务特定数据。
- **泛化能力**：适用于未知领域。
- **高效性**：减少数据需求。

### 2.3 与其他机器学习方法的对比

| 方法       | 数据需求 | 是否需要标注 | 适用场景         |
|------------|----------|-------------|------------------|
| 监督学习     | 高       | 是          | 已知领域         |
| 非监督学习   | 高       | 否          | 数据探索         |
| 半监督学习   | 中       | 部分        | 部分未知领域     |
| Zero-Shot学习 | 低       | 否          | 未知领域         |

### 2.4 Zero-Shot学习在材料设计中的应用

- **材料属性预测**：无需大量实验数据，直接预测材料性能。

## 第3章：算法原理讲解

### 3.1 Zero-Shot学习算法原理

Zero-Shot学习通过共享特征空间，将不同任务映射到同一语义空间，实现零样本分类。

### 3.2 算法流程图


### 3.3 数学模型与公式

模型假设输入数据 $x$ 和任务描述 $t$，输出类别概率 $p(y|x,t)$。共享嵌入层将输入和任务映射到同一空间：

$$ z_x = f(x) $$
$$ z_t = g(t) $$
预测概率为：
$$ p(y|x,t) = \frac{\exp(z_x \cdot z_t)}{\sum_{y'} \exp(z_x \cdot z_{t'})} $$

### 3.4 算法举例说明

基于度量的Zero-Shot学习：

1. 输入数据 $x$ 和任务描述 $t$。
2. 生成特征向量 $z_x$ 和 $z_t$。
3. 计算相似度，输出预测结果。

### 5.2 系统核心实现源代码

```python
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

def feature_extractor(x):
    return x.reshape(-1)

def task_embedder(t):
    return t.reshape(-1)

def zero_shot_classifier(x, t, feature_extractor, task_embedder):
    z_x = feature_extractor(x)
    z_t = task_embedder(t)
    similarity = cosine_similarity(z_x.reshape(1, -1), z_t.reshape(1, -1))
    return similarity[0][0]

# 示例用法
x = np.array([1, 2, 3])
t = np.array([4, 5, 6])
print(zero_shot_classifier(x, t, feature_extractor, task_embedder))
```
