以下是一个简单的基于协同过滤的推荐算法实现：

```python
import numpy as np

def compute_similarity(matrix):
    n_users, n_items = matrix.shape
    user_avg = np.zeros(n_users)
    item_avg = np.zeros(n_items)
    
    for i in range(n_users):
        user_avg[i] = np.mean(matrix[i])
    for j in range(n_items):
        item_avg[j] = np.mean(matrix[:, j])
    
    diff = matrix - np.outer(user_avg, np.ones(n_items)) - np.outer(np.ones(n_users), item_avg) + np.mean(user_avg) + np.mean(item_avg)
    
    similarity = np.zeros((n_items, n_items))
    for i in range(n_items):
        for j in range(n_items):
            if i == j:
                similarity[i, j] = 0
            else:
                numerator = np.sum(diff[i] * diff[j])
                denominator = np.sqrt(np.sum(diff[i]**2)) * np.sqrt(np.sum(diff[j]**2))
                similarity[i, j] = numerator / denominator if denominator != 0 else 0
    return similarity
```

上述代码实现了基于协同过滤的推荐算法，能够计算出学习者之间的相似性。通过相似性矩阵，系统可以推荐适合学习者的学习资源。
