#### 2.1 ChatGPT概述

- **定义与特点**:
  - ChatGPT是一种基于Transformer架构的大型语言模型，由OpenAI开发。

    - 多任务学习能力。

- **工作原理**:
  - 输入提示词后，模型通过自注意力机制（Self-Attention）捕捉上下文信息。
  - 基于概率分布生成目标文本。

- **提示词**:

- **数据集**:
  - 数据收集：从公开语料库、爬取数据或人工标注数据中获取。
  - 数据处理：清洗、分词、去停用词等预处理步骤。

- **模型训练与优化**:
  - 训练方法：使用监督学习，通过调整模型参数最小化生成文本的损失函数。
  - 优化策略：通过调整学习率、增加正则化项、优化损失函数等方法提升生成质量。

  ```python
  import torch
  import torch.nn as nn

  class ChatGPT(nn.Module):
      def __init__(self, vocab_size, embedding_dim):
          super().__init__()
          self.embedding = nn.Embedding(vocab_size, embedding_dim)
          self.transformer = nn.Transformer(embedding_dim, num_heads=8, d_model=512)
          self.linear = nn.Linear(512, vocab_size)

      def forward(self, input_ids):
          embed = self.embedding(input_ids)
          output = self.transformer(embed, embed)
          output = self.linear(output)
          return output
  ```
