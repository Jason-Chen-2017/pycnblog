def build_generator(input_dim):
    generator = layers.Dense(256, activation='relu')(input_layer)

    return Model(input_layer, generator)

def build_discriminator(input_dim):
    discriminator = layers.Dense(256, activation='relu')(input_layer)
    discriminator = layers.Dense(1, activation='sigmoid')(discriminator)
    return Model(input_layer, discriminator)

# 示例使用

#### 3.4 数学模型和公式

生成模型的损失函数为：
$$ L = -\mathbb{E}[\log(D(x))] - \mathbb{E}[\log(1 - D(G(z)))] $$
其中，$D$为判别器，$G$为生成器，$z$为噪声输入。

其中，$t_i$为实际流量，$\hat{t}_i$为预测流量。
