### 2.2 零样本学习的核心算法

#### 2.2.1 Prototypical Networks

##### 2.2.1.1 算法原理  
Prototypical Networks通过计算支持向量的原型，生成新的样本特征。

##### 2.2.1.2 数学模型  
$$
f(x) = \argmin_{y \in Y} \frac{||x - \mu_y||^2}{2}
$$  
其中，$\mu_y$ 是类别 $y$ 的原型向量。

##### 2.2.1.3 Mermaid算法流程图  
```mermaid
graph TD
    A[输入样本x] --> B[计算每个类别的原型μ_y]
    B --> C[计算x与每个μ_y的距离]
    C --> D[选择距离最小的类别]
    D --> E[输出预测类别]
```

##### 2.2.1.4 Python源代码示例  
```python
import torch
import torch.nn as nn

class PrototypicalNetworks(nn.Module):
    def __init__(self, embedding_dim, hidden_dim):
        super().__init__()
        self.encoder = nn.Linear(embedding_dim, hidden_dim)
        self.prototypes = nn.Parameter(torch.randn(hidden_dim, 1))

    def forward(self, x):
        x_embed = self.encoder(x)
        prototypes = self.prototypes.repeat(x_embed.size(0), 1)
        distances = torch.norm(x_embed.unsqueeze(1) - prototypes.unsqueeze(0), dim=2)
        return distances
```

#### 2.2.2 Matching Networks

##### 2.2.2.1 算法原理  
Matching Networks通过匹配查询样本与支持集中的样本，生成相似性权重。

##### 2.2.2.2 数学模型  
$$
s(x, y) = \frac{\exp(\text{sim}(x,y))}{\sum_{k} \exp(\text{sim}(x,k))}
$$  
其中，$\text{sim}(x,y)$ 是样本 $x$ 和 $y$ 的相似度。

##### 2.2.2.3 Mermaid算法流程图  
```mermaid
graph TD
    A[输入样本x] --> B[计算x与支持集样本的相似度]
    B --> C[生成相似性权重s(x,y)]
    C --> D[预测类别y]
```

##### 2.2.2.4 Python源代码示例  
```python
def matching_networks(x, support_set):
    similarities = []
    for y in support_set:
        sim = torch.cosine_similarity(x, y)
        similarities.append(sim)
    similarities = torch.stack(similarities)
    probs = torch.softmax(similarities, dim=0)
    return probs
```

#### 2.2.3 Relation Network

##### 2.2.3.1 算法原理  
Relation Network通过关系函数生成样本间的相似性矩阵。

##### 2.2.3.2 数学模型  
$$
S = R(x_i, x_j) = \frac{e^{x_i^T x_j}}{e^{x_i^T x_j} + e^{x_j^T x_i}}
$$  
其中，$R$ 是关系函数。

##### 2.2.3.3 Mermaid算法流程图  
```mermaid
graph TD
    A[输入样本x_i和x_j] --> B[计算相似性矩阵S]
    B --> C[预测类别y]
```

##### 2.2.3.4 Python源代码示例  
```python
def relation_network(x_i, x_j):
    similarity = torch.mm(x_i, x_j.T)
    similarity = torch.softmax(similarity, dim=1)
    return similarity
```

import torch
import torch.nn as nn

class ZeroShotModel(nn.Module):
    def __init__(self, input_dim, hidden_dim):
        super().__init__()
        self.encoder = nn.Linear(input_dim, hidden_dim)
        self.classifier = nn.Linear(hidden_dim, 1)

    def forward(self, x):
        x_embed = self.encoder(x)
        output = self.classifier(x_embed)
        return output

# 示例数据
X = torch.randn(100, input_dim)
y = torch.randn(100, 1)

# 模型训练
model = ZeroShotModel(input_dim, hidden_dim)
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(100):
    outputs = model(X)
    loss = criterion(outputs, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

# 预测
new_X = torch.randn(10, input_dim)
predicted = model(new_X)
print(predicted)
