#### 3.2 Python源代码与算法原理  

```python
def reconstruct_network(data):
    nodes = list(set([d['source'] for d in data] + [d['target'] for d in data]))
    edges = {}
    for d in data:
        source = d['source']
        target = d['target']
        weight = d.get('weight', 1)
        if source not in edges:
            edges[source] = {}
        if target not in edges[source]:
            edges[source][target] = 0
        edges[source][target] += weight
    return nodes, edges

data = [
    {'source': '古埃及', 'target': '古希腊', 'weight': 5},
    {'source': '古希腊', 'target': '罗马', 'weight': 4},
    {'source': '罗马', 'target': '中世纪欧洲', 'weight': 3}
]
nodes, edges = reconstruct_network(data)
```

#### 3.3 数学模型与公式讲解  

节点间的权重计算公式：  
$$
\text{weight}(u, v) = \frac{\sum_{i=1}^{n} |C_i(u) - C_i(v)|}{n}
$$  

其中，$C_i$表示第i个文化特征，$u$和$v$是节点。  

#### 3.4 举例说明  
以古埃及、古希腊和罗马为例，计算它们的权重。  

$$
\text{weight}(古埃及, 古希腊) = \frac{|C_1(古埃及) - C_1(古希腊)| + \cdots}{n}
$$

import networkx as nx

def visualize_network(nodes, edges):
    G = nx.DiGraph()
    for node in nodes:
        G.add_node(node)
    for source, targets in edges.items():
        for target, weight in targets.items():
            G.add_edge(source, target, weight=weight)
    nx.draw(G, with_labels=True, edge_labels=True)
    plt.show()

visualize_network(nodes, edges)
