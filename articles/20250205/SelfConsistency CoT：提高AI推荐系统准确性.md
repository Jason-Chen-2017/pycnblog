其中，\(C\) 是一致性评分，\(w_{ij}\) 是特征 \(i\) 和 \(j\) 的权重，\(s_{ij}\) 是特征一致性评分。

### 4.2 数学公式与详细讲解

$$

$$

其中，\(w_{ij}\) 表示特征 \(i\) 和 \(j\) 的相关性权重，\(s_{ij}\) 表示特征一致性评分。

### 7.2 系统核心实现源代码
```python
import numpy as np
import pandas as pd
from sklearn.metrics import pairwise

def calculate_consistency_score(user_data, item_data):
    # 数据预处理
    user_features = user_data.drop(columns=['id'])
    item_features = item_data.drop(columns=['id'])
    
    # 特征归一化
    user_features_norm = (user_features - user_features.mean()) / user_features.std()
    item_features_norm = (item_features - item_features.mean()) / item_features.std()
    
    # 计算一致性评分
    similarity_matrix = pairwise.cosine_similarity(user_features_norm, item_features_norm)
    consistency_score = np.mean(similarity_matrix)
    
    return consistency_score

# 示例数据
user_data = pd.DataFrame({
    'id': [1, 2, 3],
    'feature1': [0.5, 0.6, 0.4],
    'feature2': [0.7, 0.3, 0.8]
})

item_data = pd.DataFrame({
    'id': [101, 102, 103],
    'feature1': [0.6, 0.5, 0.7],
    'feature2': [0.4, 0.8, 0.2]
})

# 计算一致性评分
score = calculate_consistency_score(user_data, item_data)
print(f"一致性评分: {score}")
```
