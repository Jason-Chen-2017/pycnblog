## 第二章：认知语言学的理论基础

### 2.1 认知语言学的基本概念  
认知语言学研究语言与人类认知的关系，强调语言是认知的工具。语言的理解依赖于人类的认知结构，包括概念、经验、记忆和推理。

### 2.2 语言的三层次模型  
认知语言学将语言分为三个层次：  
1. **词汇层**：词语的语义和语用信息。  
2. **语法层**：句子的结构和关系。  
3. **语义层**：语句的深层含义和逻辑关系。  

### 2.3 提示词的认知特征  
提示词具有以下认知特征：  
- **明确性**：提示词通常包含用户的核心意图。  
- **隐含性**：提示词可能包含未明说的背景信息。  
- **多样性**：提示词可以是句子、短语或单个词语。

```python
    # 分词
```

### 6.2 核心代码实现  
以下是提示词识别的核心代码：

```python
import numpy as np
from nltk.tokenize import word_tokenize

def tokenize(text):
    return word_tokenize(text)

def semantic_analysis(tokens):
    return [token.lower() for token in tokens]

def extract_prompts(semantics):
    return semantics[:2]

text = "写一篇关于环保的文章"
tokens = tokenize(text)
semantics = semantic_analysis(tokens)
prompts = extract_prompts(semantics)
print(prompts)  # 输出：['写', '关于']
```
