## 设计原则

### 3.1 核心设计原则
- **目标明确性**：提示词应明确指向情感智能的目标，如“请描述你的感受”。
- **情感导向性**：通过提示词引导生成内容的情感倾向，如“以一种温暖的语气回答”。
- **上下文相关性**：提示词应考虑生成内容的上下文背景，如“假设你刚刚经历了一次失败，请描述你的感受”。
- **简洁性**：提示词应简洁明了，避免冗长复杂的表达。

### 3.2 情感表达设计
- **开放性**：使用开放性问题引导用户表达情感，如“你最近有什么让你感到开心的事情吗？”。
- **具体性**：提供具体的场景或问题，如“假设你刚刚失去了一份工作，你会感到怎样？”。
- **情感强度**：通过提示词调整情感表达的强度，如“请用最强烈的语气表达你的愤怒”。

### 3.3 情感识别设计
- **情感分类**：将情感分为高兴、悲伤、愤怒、惊讶、厌恶等基本类别。
- **情感特征提取**：识别文本中的情感关键词和语调特征。
- **情感语料库**：建立情感标注的语料库，用于训练情感识别模型。

```python
from transformers import pipeline

# 初始化情感分析管道
emotional_analysis = pipeline("sentiment-analysis", model="facebook/roberta-base")

# 示例提示词设计
def design_prompt(emotion):
    if emotion == "happy":
        return "请描述一件让你感到非常开心的事情。"
    elif emotion == "sad":
        return "请描述一件让你感到悲伤的事情。"
    elif emotion == "angry":
        return "请描述一件让你感到愤怒的事情。"
    else:
        return "请描述一件让你感到惊讶的事情。"

# 测试情感识别
def test_emotional_recognition(prompt):
    result = emotional_analysis(prompt)
    return result[0]['label']

# 示例应用
if __name__ == "__main__":
    test_prompts = [
        design_prompt("happy"),
        design_prompt("sad"),
        design_prompt("angry")
    ]
    for prompt in test_prompts:
        print(f"Prompt: {prompt}")
        print(f"Emotion Recognized: {test_emotional_recognition(prompt)}")
        print("-" * 50)
```
