#### 4.2 算法实现（Python代码示例）

```python
def generate_prompt(tasks):
    # 提取任务关键词
    keywords = [task['name'] for task in tasks]
    # 计算权重
    weights = [task['priority'] for task in tasks]
    # 生成提示词
    prompt = f"Please prioritize tasks: {', '.join(keywords)} with weights {weights}."
    return prompt

# 示例调用
tasks = [
    {'name': '完成报告', 'priority': 0.9},
    {'name': '回复邮件', 'priority': 0.7}
]
prompt = generate_prompt(tasks)
print(prompt)
```

#### 4.3 数学模型与公式解析

优化任务优先级涉及加权公式：
$$ \text{优先级} = \sum_{i=1}^{n} w_i \times t_i $$
其中，$$w_i$$ 是任务权重，$$t_i$$ 是任务特征。
