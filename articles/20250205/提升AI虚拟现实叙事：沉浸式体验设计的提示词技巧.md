```python
def generate_prompt(demand):
    import random
    # 随机选择提示词模板
    prompt_templates = [
        "生成一个关于{}的详细描述。",
        "请以{}为关键词，创作一个短故事。",
        "{}，请详细描述其特点。"
    ]
    # 随机选择一个模板并填充关键词
    prompt = random.choice(prompt_templates).format(demand)
    return prompt

# 示例使用
demand = "未来城市"
print(generate_prompt(demand))
```

#### 4.4 LaTeX数学模型和公式讲解

提示词技巧的优化可以通过概率模型进行。假设提示词的生成概率为P(w_i)，则提示词序列的概率为：

$$ P(w_1, w_2, ..., w_n) = \prod_{i=1}^{n} P(w_i | w_{i-1}) $$

其中，$w_i$ 表示第i个提示词，$P(w_i | w_{i-1})$ 表示在前一个提示词的情况下，生成当前提示词的概率。

import openai

def generate_content(prompt):
    client = openai.Client()
    response = client.completions.create(
        model="gpt-3.5-turbo",
        prompt=prompt,
        max_tokens=500,
        temperature=0.7
    )
    return response.choices[0].message.content

# 示例使用
prompt = "生成一个关于未来城市的详细描述。"
print(generate_content(prompt))
