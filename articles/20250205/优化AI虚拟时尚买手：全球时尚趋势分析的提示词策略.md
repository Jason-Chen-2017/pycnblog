### 3.2 Python源代码  

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor

# 数据加载
data = pd.read_csv('时尚数据.csv')

# 特征提取
features = data[['颜色', '风格', '材质']]
target = data['销量']

# 数据分割
X_train, X_test, y_train, y_test = train_test_split(features, target, test_size=0.2)

# 模型训练
model = RandomForestRegressor()
model.fit(X_train, y_train)

# 生成提示词
def generate_prompts(model, test_features):
    predictions = model.predict(test_features)
    prompts = []
    for i in range(len(predictions)):
        if predictions[i] > 0.7:
            prompts.append(f"推荐产品{i+1}")
    return prompts

prompts = generate_prompts(model, X_test)
print(prompts)
```

### 3.3 数学模型和公式  

时尚趋势预测模型基于时间序列分析：

$$
\hat{y}_t = \alpha y_{t-1} + (1-\alpha) \hat{y}_{t-1}
$$

其中，$\alpha$为平滑系数，$y_t$为实际值，$\hat{y}_t$为预测值。

### 3.4 详细讲解和举例说明  
通过训练数据，模型学习历史销售数据，预测未来趋势。例如，预测秋冬季的服装需求，模型会生成“推荐羽绒服”等提示词。

### 5.2 核心实现源代码  

```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier

data = pd.read_csv('时尚数据.csv')
X = data.drop('销量', axis=1)
y = data['销量']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = RandomForestClassifier()
model.fit(X_train, y_train)

def generate_prompts(model, X_test):
    predictions = model.predict(X_test)
    prompts = []
    for i in range(len(predictions)):
        if predictions[i] == 1:
            prompts.append(f"推荐产品{i+1}")
    return prompts

prompts = generate_prompts(model, X_test)
print(prompts)
```
