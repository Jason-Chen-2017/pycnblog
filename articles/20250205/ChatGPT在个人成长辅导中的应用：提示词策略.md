### 第4章: 提示词策略设计

#### 4.1 提示词类型

根据ChatGPT的应用场景，可以将提示词分为以下几类：
- **知识获取类**：用于获取学术知识、技能教程等。
- **目标设定类**：用于设定成长目标、制定成长计划等。
- **时间管理类**：用于安排日程、制定任务列表等。
- **心理素质提升类**：用于心理疏导、情绪调节等。

#### 4.2 提示词设计原则

设计提示词时，应遵循以下原则：
- **明确性**：提示词应清晰明确，避免歧义。
- **个性化**：根据用户需求，设计有针对性的提示词。
- **可扩展性**：提示词应具备一定的通用性，便于拓展应用。

#### 4.3 提示词策略实例

以下为几个典型的提示词策略实例：

**知识获取类**：
- 用户提问：“请解释一下量子计算的基本原理。”
- ChatGPT回答：“量子计算是一种基于量子力学原理的计算方式，其核心概念包括量子位、叠加态和纠缠态。与经典计算机的二进制位不同，量子计算机的量子位可以同时表示0和1，从而在某些情况下显著提高计算速度。”

**目标设定类**：
- 用户输入：“我想在三个月内完成一场马拉松。”
- ChatGPT生成目标建议：
  - 每周制定训练计划，逐步增加跑步距离。
  - 每周进行一次力量训练，增强肌肉耐力。
  - 每天记录训练日志，跟踪进展。

**时间管理类**：
- 用户提问：“如何高效完成我的工作计划？”
- ChatGPT回答：
  - 使用优先级排序，将任务分为重要且紧急、重要但不紧急、紧急但不重要、既不重要也不紧急四类。
  - 为每个任务分配具体的时间段，避免任务之间的干扰。

**心理素质提升类**：
- 用户输入：“我最近感到压力很大，如何缓解？”
- ChatGPT回答：
  - 建立每日放松时间，尝试冥想或深呼吸练习。
  - 与朋友或家人分享您的感受，寻求支持和建议。
  - 设定小目标，逐步建立自信。

import openai

class ChatGPTAssistant:
    def __init__(self, api_key):
        self.client = openai.Client(api_key)
    
    def generate_response(self, prompt):
        response = self.client.chat.completions.create(
            model="gpt-3.5-turbo",
            messages=[{"role": "user", "content": prompt}]
        )
        return response.choices[0].message.content

# 示例用法
api_key = "your-api-key"
assistant = ChatGPTAssistant(api_key)
response = assistant.generate_response("如何学习Python编程？")
print(response)
