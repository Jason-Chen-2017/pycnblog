### 2.2 Python源代码示例

以下是生成创意内容的Python代码示例：

```python
import torch
from transformers import pipeline

# 初始化模型
model = pipeline('text-generation', model='deepseek/gpt2')

# 生成创意内容
def generate_content(prompt):
    return model(prompt, max_length=50, num_return_sequences=1)

# 示例提示词
prompt = "描述一种全新的香水气味，结合海洋和花香元素。"
result = generate_content(prompt)
print(result[0]['generated_text'])
```

### 2.3 数学模型与公式讲解

AI创意生成的核心算法之一是Transformer模型，其注意力机制如下：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

其中，$Q$、$K$、$V$分别是查询、键和值向量，$d_k$是键的维度。
