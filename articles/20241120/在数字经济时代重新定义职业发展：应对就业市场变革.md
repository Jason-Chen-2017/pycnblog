#### 职业竞争力模型

假设个体 \(I\) 的职业竞争力由以下三个因素决定：技能水平 \(S\)、工作经验 \(E\) 和软技能 \(R\)。

职业竞争力 \(C = f(S, E, R)\)

- **技能水平 \(S\)**：反映个体在特定领域的专业能力，可以使用数学公式 \(S = K \cdot L\) 来表示，其中 \(K\) 是知识水平，\(L\) 是应用能力。
- **工作经验 \(E\)**：反映个体在职业生涯中的积累和经验，可以使用数学公式 \(E = T \cdot M\) 来表示，其中 \(T\) 是工作时间，\(M\) 是工作效率。
- **软技能 \(R\)**：反映个体在沟通、团队合作等方面的能力，可以使用数学公式 \(R = C \cdot G\) 来表示，其中 \(C\) 是沟通能力，\(G\) 是团队合作能力。

#### 举例说明

假设个体 \(I\) 的技能水平 \(S = 5 \cdot 8 = 40\)、工作经验 \(E = 10 \cdot 6 = 60\)、软技能 \(R = 7 \cdot 9 = 63\)。

根据职业竞争力模型，个体 \(I\) 的职业竞争力 \(C = f(40, 60, 63)\)。

- 如果 \(C = 40 + 60 + 63 = 163\)，则个体 \(I\) 的职业竞争力较强。
- 如果 \(C = 20 + 30 + 40 = 90\)，则个体 \(I\) 的职业竞争力较弱。

#### 源代码实现

```python
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///career_plan.db'
db = SQLAlchemy(app)

class CareerPlan(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    goal = db.Column(db.String(100), nullable=False)
    steps = db.Column(db.Text, nullable=False)

@app.route('/api/career_plans', methods=['POST'])
def add_career_plan():
    data = request.get_json()
    plan = CareerPlan(name=data['name'], goal=data['goal'], steps=data['steps'])
    db.session.add(plan)
    db.session.commit()
    return jsonify({"message": "Career plan added successfully."})

@app.route('/api/career_plans', methods=['GET'])
def get_career_plans():
    plans = CareerPlan.query.all()
    return jsonify([{"id": plan.id, "name": plan.name, "goal": plan.goal, "steps": plan.steps} for plan in plans])

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```
