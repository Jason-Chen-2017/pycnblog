**数学模型和公式讲解**：

**环境评估指数模型**：

$$
EAI = \alpha \cdot PEI + \beta \cdot SEI + \gamma \cdot MEI
$$

其中：
- $EAI$：环境评估指数（Environment Assessment Index）
- $\alpha$、$\beta$、$\gamma$：权重系数，用于平衡物理环境、社会环境和心理环境的重要性
- $PEI$：物理环境指数（Physical Environment Index）
- $SEI$：社会环境指数（Social Environment Index）
- $MEI$：心理环境指数（Mental Environment Index）

**权重系数确定**：

权重系数可以根据个人的需求和目标进行动态调整，例如：

$$
\alpha = 0.4, \beta = 0.3, \gamma = 0.3
$$

**举例说明**：

假设一个人的环境评估数据如下：

- **物理环境**：空间布局满意度为80%，硬件设备满意度为75%
- **社会环境**：社交网络满意度为85%，组织文化满意度为70%
- **心理环境**：情绪管理满意度为90%，心理健康满意度为85%

根据上述数据，计算环境评估指数：

$$
EAI = 0.4 \cdot (0.8 + 0.75) + 0.3 \cdot (0.85 + 0.7) + 0.3 \cdot (0.9 + 0.85)
$$

$$
EAI = 0.4 \cdot 1.55 + 0.3 \cdot 1.55 + 0.3 \cdot 1.75
$$

$$
EAI = 0.62 + 0.465 + 0.525
$$

$$
EAI = 1.6
$$

通过计算得出的环境评估指数为1.6，这表明该人的个人发展环境整体处于良好水平。

```python
class User(db.Model):

    physical_score = db.Column(db.Integer)

```

**routes.py**：

```python
from flask import render_template, request, redirect, url_for
from app import app, db
from app.models import User

@app.route('/')
def index():
    return render_template('index.html')

@app.route('/submit', methods=['POST'])
def submit():
    username = request.form['username']
    physical_score = int(request.form['physical_score'])
    social_score = int(request.form['social_score'])
    mental_score = int(request.form['mental_score'])

    user = User(username=username, physical_score=physical_score, social_score=social_score, mental_score=mental_score)
    db.session.add(user)
    db.session.commit()

    return redirect(url_for('results', username=username))
```

## 第1章 环境建设的核心概念

### 1.1 个人发展环境的定义

### 1.3 环境建设的关键因素

- **物理环境**：包括住房、工作场所的设计和布局，以及所需的硬件设备。
- **社会环境**：涉及人际交往、社会支持和网络资源。
- **心理环境**：包括个人的情绪调节能力、心理健康水平和价值观。
