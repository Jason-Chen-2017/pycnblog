#### Chapter 2: Core Concepts and Architectures of Language Models

**2.1 Core Concepts of Language Models**
- **Neural network fundamentals:**
  - **Backpropagation:** An algorithm used to calculate gradients for optimizing network weights.
  - **Activation functions:** Used to introduce non-linearities into the network.
- **Attention mechanisms:**
  - **Self-attention:** Allows the model to weigh different parts of the input sequence differently.
  - **External attention:** Allows the model to attend to external information, such as context vectors.
- **Sequence-to-sequence models:**
  - **Encoder-decoder framework:** An approach where the encoder processes the input sequence and the decoder generates the output sequence.

**2.2 Architectural Details of Language Models**
- **Transformer architecture:**
  - **Multi-head attention:** A way to combine different attention mechanisms to improve performance.
  - **Positional encoding:** A technique to add information about the position of tokens in the sequence.
- **BERT, GPT, and T5 models:**
  - **BERT:** Pre-training on both forward and backward contexts.
  - **GPT:** Unidirectional language model trained to predict the next token.
  - **T5:** Treats all tasks as a text-to-text problem.

- **Probability spaces:** A set of all possible outcomes and a function that assigns probabilities to these outcomes.
- **Random variables and probability distributions:** Random variables represent numerical outcomes of random experiments, and probability distributions describe the likelihood of different outcomes.
- **Entropy and information:** Entropy measures the uncertainty of a random variable, while information measures the amount of information gained when the outcome is known.
