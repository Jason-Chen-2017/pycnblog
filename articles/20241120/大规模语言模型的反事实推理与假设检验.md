### 第2章：反事实推理基础

#### 2.1 反事实推理的定义与类型

##### 2.1.1 反事实推理的概念

**核心概念与联系**
- **反事实推理**是一种基于假设进行逻辑推理的方法，旨在推断与已知事实相反的情景或结果。
- **事实**：真实发生的事件或情况。
- **假设**：基于某种前提条件提出的可能性情景。
- **Mermaid流程图**：
  ```mermaid
  graph TD
  A[事实] --> B[假设]
  B --> C{反事实推理}
  C --> D[结论]
  ```
- **核心算法原理讲解**
  - **基于逻辑的算法**：利用逻辑推理规则，从事实和假设中推导出反事实。
  - **基于统计的算法**：通过大量语料学习，推断事实和假设的概率分布，进而进行推理。
  - **伪代码**：
    ```python
    def 反事实推理(事实，假设):
        # 基于逻辑的推理
        if 逻辑算法:
            结论 = 推导反事实(事实，假设)
        # 基于统计的推理
        else:
            结论 = 统计概率分布(事实，假设)
        return 结论
    ```

##### 2.1.2 反事实推理的类型

**核心概念与联系**
- **可能性反事实**：根据已知事实和假设，推断出可能发生的反事实情景。
- **必然性反事实**：基于已知事实和假设，确定地推断出必然发生的反事实情景。
- **Mermaid流程图**：
  ```mermaid
  graph TD
  A[可能性反事实] --> B[必然性反事实]
  B --> C[应用场景]
  C --> D[决策支持]
  ```

**数学模型和公式**
- **可能性反事实概率**：
  $$ P(\neg F|H) = \frac{P(H|\neg F)P(\neg F)}{P(H)} $$
- **必然性反事实概率**：
  $$ P(\neg F|H) = 1 $$

**详细讲解与举例说明**
- **可能性反事实举例**：
  假设今天下雨（事实），如果天气预报说今天可能会下雨（假设），则反事实推理可能是“今天不会下雨”。
- **必然性反事实举例**：
  如果一个数学等式是正确的（事实），则必然的反事实是不可能的，即“这个数学等式是错误的”。
