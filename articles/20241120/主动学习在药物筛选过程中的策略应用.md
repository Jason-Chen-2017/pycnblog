## 第一部分：主动学习基础

### 第1章：主动学习的概述

#### 1.1.1 主动学习的定义

主动学习是一种迭代式的机器学习方法，它通过选择最具代表性的样本进行学习，从而在有限的样本数量下达到较好的学习效果。与传统学习方式相比，主动学习具有以下特点：

- **主动选择样本**：主动学习不是随机选择样本进行学习，而是根据一定的策略选择最具信息价值的样本。
- **减少标记成本**：通过选择最具代表性的样本，可以有效地减少标记样本的成本。
- **提高模型泛化能力**：主动学习能够更好地捕捉数据中的信息，从而提高模型的泛化能力。

#### 1.1.2 主动学习与传统学习的比较

传统学习方式主要依赖于大量的标记数据，而主动学习则通过有选择地获取样本进行学习，从而在样本数量有限的情况下，能够达到更好的学习效果。

| 特征         | 传统学习                 | 主动学习               |
| ------------ | ------------------------ | ---------------------- |
| 样本选择     | 随机选择样本             | 选择最具信息价值的样本 |
| 标记成本     | 高                      | 低                     |
| 泛化能力     | 受到样本数量的限制       | 更好地捕捉数据特征     |

#### 1.1.3 主动学习在药物筛选中的重要性

在药物筛选过程中，主动学习具有以下重要作用：

- **提高筛选效率**：通过优化样本选择策略，可以更快地筛选出潜在的药物候选分子。
- **降低实验成本**：减少不必要的实验，降低实验成本。
- **提高模型可靠性**：通过有选择地获取样本，可以提高模型的预测准确性和可靠性。

### 第3章：主动学习算法

#### 3.1.1 采样策略

采样策略是主动学习的核心。常见的采样策略包括不确定性采样（Uncertainty Sampling）和查询委员会（Query-by-Committee）。

- **不确定性采样**：不确定性采样基于模型的预测不确定性选择样本。具体算法如下：
    ```python
    function UncertaintySampling(dataset, model, queryBudget):
        uncertainData = []
        for data in dataset:
            uncertainty = model.estimateUncertainty(data)
            if uncertainty > threshold:
                uncertainData.append(data)
        return selectRandomly(uncertainData, queryBudget)
    ```

#### 3.1.2 特征工程

特征工程是主动学习中的重要环节。通过有效的特征提取和选择，可以提高模型的学习效果。

- **特征提取**：特征提取是将原始数据转换为可用于训练的特征表示。常见的特征提取方法包括主成分分析（PCA）、线性判别分析（LDA）等。
- **特征选择**：特征选择是从提取的特征中选出最有用的特征。常见的特征选择方法包括基于信息增益的筛选、基于模型评估的筛选等。

#### 3.1.3 模型评估与调整

模型评估与调整是保证主动学习效果的重要手段。通过评估和调整模型，可以优化学习过程。

- **评估指标**：评估指标是衡量模型效果的重要标准。常见的评估指标包括准确率（Accuracy）、召回率（Recall）、F1值（F1 Score）等。
- **调整策略**：调整策略是通过调整模型参数来优化模型效果。常见的调整策略包括基于验证集的调整、基于交叉验证的调整等。
