### 3.4 数学模型与公式

在跨年龄友谊匹配算法中，常用的数学模型和公式包括：

1. **余弦相似度**：

\[ \text{cosine\_similarity} = \frac{\text{user\_A} \cdot \text{user\_B}}{\|\text{user\_A}\| \|\text{user\_B}\|} \]

其中，\( \text{user\_A} \) 和 \( \text{user\_B} \) 分别为用户A和用户B的向量表示，\( \|\text{user\_A}\| \) 和 \( \|\text{user\_B}\| \) 分别为用户A和用户B的向量模长。

2. **皮尔逊相关系数**：

\[ \text{pearson\_correlation} = \frac{\sum_{i=1}^{n}(\text{x\_i} - \bar{x})(\text{y\_i} - \bar{y})}{\sqrt{\sum_{i=1}^{n}(\text{x\_i} - \bar{x})^2} \sqrt{\sum_{i=1}^{n}(\text{y\_i} - \bar{y})^2}} \]

其中，\( \text{x\_i} \) 和 \( \text{y\_i} \) 分别为第i个用户在特征1和特征2上的取值，\( \bar{x} \) 和 \( \bar{y} \) 分别为所有用户在特征1和特征2上的平均值。

user_interests = user_data[['user_id', 'interests']]

# 4.2.1.3.2 构建用户兴趣向量
def vectorize_interests(interests):
    # 使用One-Hot编码将兴趣转换为向量
    interest_vector = [0] * num_interests
    for interest in interests.split(','):
        interest_vector[int(interest)] = 1
    return interest_vector

num_interests = 10  # 假设有10个兴趣标签

import networkx as nx

# 4.2.2.3.1 加载社交网络数据
graph = nx.read_gml('social_network.gml')

# 4.2.2.3.2 计算用户之间的相似性
def calculate_similarity(graph):
    # 使用PageRank算法计算节点之间的相似性
    pagerank = nx.pagerank(graph)
    similarity_matrix = np.zeros((len(graph), len(graph)))
    for i, node_i in enumerate(graph.nodes()):
        for j, node_j in enumerate(graph.nodes()):
            similarity_matrix[i][j] = pagerank[node_i] * pagerank[node_j]
    return similarity_matrix

similarity_matrix = calculate_similarity(graph)

# 4.2.2.3.3 为用户推荐潜在的朋友
def recommend_friends(user_id, similarity_threshold=0.5):
    # 根据相似度阈值筛选潜在朋友
    similar_users = similarity_matrix[user_id]
    potential_friends = [user_id for user_id, similarity in enumerate(similar_users) if similarity > similarity_threshold]
    return potential_friends

# 测试推荐算法
user_id = 0  # 测试用户ID

print("Potential friends for user", user_id, ":", potential_friends)
