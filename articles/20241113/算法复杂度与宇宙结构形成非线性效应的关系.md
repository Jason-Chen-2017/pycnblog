### 伪代码

为了更好地理解算法复杂度，我们首先来看一个简单的排序算法——冒泡排序。

```pseudocode
procedure bubbleSort( A : list of sortable items )
    n = length(A)
    for i = 1 to n-1 do
        for j = 1 to n-i do
            if A[j] > A[j+1] then
                swap(A[j], A[j+1])
            end if
        end for
    end for
end procedure
```

在这个伪代码中，`bubbleSort` 算法通过两个嵌套循环进行排序。外层循环 `i` 从 1 到 `n-1`，内层循环 `j` 从 1 到 `n-i`。每次内层循环都会比较相邻的元素并交换它们，如果它们不符合排序顺序。

时间复杂度分析：
- 在最坏的情况下，每个元素都需要被比较和交换，因此总共有 $\frac{n(n-1)}{2}$ 次比较和交换操作。
- 因此，冒泡排序的时间复杂度为 $O(n^2)$。

空间复杂度分析：
- 冒泡排序是一个原地排序算法，不需要额外的存储空间，因此空间复杂度为 $O(1)$。
