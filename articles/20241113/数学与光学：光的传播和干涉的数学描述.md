## **光的传播**

### **1. 光的波动性**

光的波动性是光学中的基本概念。根据波动理论，光是一种电磁波，具有波动性质。光的波动性可以通过波动方程来描述。波动方程是一个偏微分方程，描述了光波在空间和时间上的变化规律。

\[ \nabla^2 \psi - \mu^2 c^2 \frac{\partial^2 \psi}{\partial t^2} = 0 \]

其中，\(\psi\) 是电场或磁场的振幅，\(\mu\) 是介质的磁导率，\(c\) 是光速。通过解波动方程，可以计算光波的传播路径和特性。

### **1.2 光的几何传播**

在几何光学中，光被视为直线传播。光的几何传播可以用光线模型来描述。光线模型通过假设光线在空间中沿直线传播，可以方便地计算光线路径和光束传播特性。光线模型的核心算法是光线追踪，用于计算光线与物体表面的交点。

\[ \text{ray}(s) = \text{source} + \text{direction} \cdot s \]

其中，\(s\) 是光线传播的距离，\(\text{source}\) 是光源位置，\(\text{direction}\) 是光线传播方向。

### **1.3 蒙版与光学传输**

光学传输是指光在不同介质间的传播过程。蒙版是光学传输中的一个重要概念，用于描述光在传输过程中受到的衰减和反射。光学传输可以通过菲涅尔公式来描述。菲涅尔公式描述了光在界面上的反射和透射特性。

\[ R = \frac{n_2 \cos \theta_2 - n_1 \cos \theta_1}{n_2 \cos \theta_2 + n_1 \cos \theta_1} \]
\[ T = \frac{2 n_1 \cos \theta_1}{n_2 \cos \theta_2 + n_1 \cos \theta_1} \]

其中，\(R\) 是反射率，\(T\) 是透射率，\(n_1\) 和 \(n_2\) 分别是两种介质的折射率，\(\theta_1\) 和 \(\theta_2\) 分别是入射角和折射角。

## **光的干涉**

### **2. 干涉原理与实验**

干涉现象是光的波动性质的重要体现。干涉原理可以通过两个或多个光波叠加产生的干涉条纹来解释。干涉实验中最常见的现象是双缝干涉和薄膜干涉。

### **2.1 双缝干涉**

双缝干涉实验展示了光波的干涉现象。在双缝实验中，两个狭缝作为光源，产生两束相干光波。这两束光波在屏幕上相遇，产生干涉条纹。

\[ \psi(x,t) = \psi_1(x,t) + \psi_2(x,t) \]

其中，\(\psi_1\) 和 \(\psi_2\) 分别是两束光波的振幅，\(x\) 是空间位置，\(t\) 是时间。通过测量干涉条纹的位置和强度，可以分析光波的相位和振幅。

### **2.2 薄膜干涉**

薄膜干涉是另一个常见的干涉现象。在薄膜干涉中，光在薄膜的两个界面反射，产生相干光波，形成干涉条纹。薄膜干涉可以用于检测薄膜厚度和光学特性。

\[ \psi(x,t) = \psi_r(x,t) + \psi_t(x,t) \]

其中，\(\psi_r\) 和 \(\psi_t\) 分别是反射光和透射光的振幅。

## **项目实战**

### **3. 光学传输模拟**

为了深入理解光的传播和干涉现象，我们可以通过编写代码来模拟光学传输过程。以下是一个简单的光学传输模拟示例，使用 Python 代码实现。

```python
# 导入必要的库
import numpy as np
import matplotlib.pyplot as plt

# 设置参数
n1 = 1.0  # 空气的折射率
n2 = 1.5  # 玻璃的折射率
L = 10.0  # 光程长度
d = 0.1   # 蒙版厚度

# 计算反射率
R = (n2 * np.cos(np.deg2rad(0)) - n1 * np.cos(np.deg2rad(90))) / (n2 * np.cos(np.deg2rad(0)) + n1 * np.cos(np.deg2rad(90)))

# 计算透射率
T = (2 * n1 * np.cos(np.deg2rad(90))) / (n2 * np.cos(np.deg2rad(0)) + n1 * np.cos(np.deg2rad(90)))

# 计算光程差
delta = 2 * n2 * d * np.cos(np.deg2rad(0))

# 计算干涉条纹
psi = R * np.cos(2 * np.pi * delta / L)

# 绘制干涉条纹
plt.plot(psi)
plt.xlabel('Position')
plt.ylabel('Amplitude')
plt.title('Interference Fringes')
plt.show()
```

通过运行这段代码，我们可以得到干涉条纹的图像，直观地展示光在传输过程中的干涉现象。
