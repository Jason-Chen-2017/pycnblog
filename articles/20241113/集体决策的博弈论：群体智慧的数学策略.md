**博弈论的核心算法**：

博弈论中的核心算法包括纳什均衡、博弈树搜索、混合策略等。下面，我们使用伪代码来解释纳什均衡的概念。

```pseudo
Function NashEquilibrium(Players):
    For each player i in Players:
        For each possible strategy si of player i:
            For each possible strategy sj of all other players:
                Calculate the expected payoff of player i when choosing strategy si and other players choose strategy sj.
                Update the strategy choice of player i to the one that maximizes the expected payoff.
    Return the set of strategies that each player chooses such that no player can improve their payoff by changing their strategy unilaterally.
```

**集体决策的核心算法**：

在集体决策中，常用的算法包括投票机制、协商算法、博弈均衡等。以下是一个简单的投票机制的伪代码。

```pseudo
Function VotingMechanism(Voters, Issues):
    For each issue in Issues:
        For each voter in Voters:
            Collect the preference of each voter for the current issue.
        Calculate the aggregate preference for each issue.
        Identify the issue with the highest aggregate preference as the decision.
    Return the decision made by the collective.
```
