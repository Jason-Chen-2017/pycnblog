### 程序设计模式概述

程序设计模式是一套经过时间验证的解决方案，它们被广泛用于软件开发中。这些模式提供了一种标准的模板，用于解决特定类型的软件设计问题。程序设计模式可以大致分为以下三类：

1. **创建型模式**：这些模式主要关注对象的创建过程。它们通过封装对象创建细节，提供了一种更灵活、可扩展的创建对象方式。常见的创建型模式包括单例模式、工厂模式、抽象工厂模式、建造者模式和原型模式。

2. **结构型模式**：这些模式关注类和对象的组合，用于创建更大的结构。它们通过将接口与实现解耦，使得系统更易于理解和维护。常见的结构型模式包括适配器模式、桥接模式、组合模式、装饰模式、外观模式和代理模式。

3. **行为型模式**：这些模式关注对象之间的通信，主要用于实现对象之间的协作。它们通过定义对象之间的交互方式，提高了系统的模块化性和灵活性。常见的行为型模式包括策略模式、职责链模式、命令模式、迭代器模式、中介者模式、备忘录模式、观察者模式、状态模式和模板方法模式。

### 宇宙基本相互作用概述

宇宙基本相互作用是物理学的基础，它们解释了物质和能量的行为。根据现代物理学的认识，宇宙存在四种基本相互作用：引力、电磁力、强相互作用和弱相互作用。

1. **引力**：引力是质量之间的相互吸引力。它是由质量引起的，并且随着距离的增加而减弱。引力是四种相互作用中最弱的一种，但它对宏观宇宙的结构和演化起着决定性作用。例如，地球围绕太阳运动，恒星和星系的形成和演化都依赖于引力。

2. **电磁力**：电磁力是带电粒子之间的相互作用。它包括电磁场的传播和电荷之间的相互作用。电磁力是四种相互作用中最强大的一种，它在日常生活中起着重要作用，如电流、磁场和电磁波的传播。

3. **强相互作用**：强相互作用是粒子之间的相互作用，用于保持原子核的稳定。它是一种短程力，仅限于原子核内的粒子之间。强相互作用非常强大，足以克服电磁力的排斥作用，使质子和中子紧密结合在一起。

4. **弱相互作用**：弱相互作用是一种短程力，主要负责粒子的衰变过程。例如，它导致中子衰变成质子、电子和反中微子。弱相互作用在宇宙中扮演着重要角色，但相比其他相互作用，它的作用范围非常有限。

2. **电磁力**：电磁力的证据来自于日常生活中的各种现象，如电流、磁场和电磁波的传播。此外，粒子物理学实验，如正负电子对撞实验，也证实了电磁力的存在。

3. **强相互作用**：强相互作用的证据来自于原子核物理实验。通过测量原子核的结合能和质子、中子的相互作用，科学家们确认了强相互作用的存在。

**程序设计模式中的工厂模式**

工厂模式是一种创建型模式，它提供了一种创建对象的标准方法。以下是一个简单的工厂模式示例：

```python
class Pizza:
    def __init__(self, name):
        self.name = name

    def prepare(self):
        print(f"Preparing {self.name} pizza.")

class PizzaFactory:
    def create_pizza(self, type):
        if type == "cheese":
            return CheesePizza()
        elif type == "pepperoni":
            return PepperoniPizza()

class CheesePizza(Pizza):
    def __init__(self):
        super().__init__("Cheese")

    def prepare(self):
        print(f"Preparing Cheese Pizza.")

class PepperoniPizza(Pizza):
    def __init__(self):
        super().__init__("Pepperoni")

    def prepare(self):
        print(f"Preparing Pepperoni Pizza.")

if __name__ == "__main__":
    factory = PizzaFactory()
    pizza = factory.create_pizza("cheese")
    pizza.prepare()
```

在这个示例中，`PizzaFactory` 类负责创建不同的`Pizza` 子类。当调用`create_pizza` 方法时，根据传入的类型参数，创建相应的`Pizza` 子类实例。这个模式使得我们能够灵活地创建对象，而无需直接创建具体子类的实例。

import threading
import time

class Planet:
    def __init__(self, name, mass, position, velocity):
        self.name = name
        self.mass = mass
        self.position = position
        self.velocity = velocity

    def move(self, other, time_step):
        distance = (other.position - self.position) ** 2
        force = G * (self.mass * other.mass) / distance
        acceleration = force / self.mass
        self.velocity += acceleration * time_step
        self.position += self.velocity * time_step

G = 6.674 * 10^-11  # 万有引力常数

earth = Planet("Earth", 5.972 * 10^24, (0, 0), (0, 0))
moon = Planet("Moon", 7.342 * 10^22, (3.84 * 10^8, 0), (0, 2 * 10^3))

def simulate():
    while True:
        earth.move(moon, 1)
        moon.move(earth, 1)
        time.sleep(0.1)

thread1 = threading.Thread(target=earth.move, args=(moon, 1))
thread2 = threading.Thread(target=moon.move, args=(earth, 1))

thread1.start()
thread2.start()

thread1.join()
thread2.join()

print(f"Earth position: {earth.position}")
