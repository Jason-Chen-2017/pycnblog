**1.1.2 经典逻辑的基本概念**

- **Mermaid流程图**：逻辑学核心概念关系图

    ```mermaid
    graph TB
    A(命题逻辑) --> B(谓词逻辑)
    B --> C(演绎推理)
    C --> D(归纳推理)
    ```

    - **命题逻辑**：研究命题之间的关系，包括命题的表示、推理规则等。

- **数学模型与公式**：演绎推理的基本法则

    ```latex
    \begin{aligned}
    &\text{前提1: } P \rightarrow Q \\
    &\text{前提2: } P \\
    &\therefore \text{结论: } Q
    \end{aligned}
    ```

    - **演绎推理**：从前提得出结论的过程。
    - **命题逻辑**：命题之间的关系，如蕴含（→）、否定（¬）、合取（∧）、析取（∨）等。
    - **谓词逻辑**：谓词之间的关系，如全称量词（∀）、存在量词（∃）、关系等。

**1.2.2 逻辑悖论**

- **伪代码**：罗素悖论的产生与解决

    ```python
    class RussellSet:
        def __init__(self):
            self.contains = []

        def add(self, item):
            if item not in self.contains:
                self.contains.append(item)

        def is_russell_set(self):
            return self in self.contains
    ```

    - **罗素悖论**：集合的成员可以是自身，导致逻辑不一致。
    - **解决方法**：通过限制集合的定义，避免自我引用。
