**概率分布**描述了随机变量在不同取值上的概率分布情况。常见的概率分布有正态分布、泊松分布和二项分布。正态分布用于描述大多数数据遵循的分布规律，而泊松分布和二项分布则用于计算离散事件的发生概率。

**均值与方差**是衡量随机变量波动性的重要指标。均值表示随机变量的平均水平，而方差表示随机变量的波动性。在保险风险评估中，均值和方差用于计算损失的大小和风险的程度。

**统计量**是从样本数据中计算得出的统计量，用于估计总体参数。常见的统计量有样本均值和样本方差。统计量可以帮助我们理解样本数据背后的总体情况，从而更准确地评估风险。

**风险**指的是可能发生的不利事件及其可能造成的损失。在保险中，风险是指保单持有人可能面临的损失。例如，一场火灾可能导致的财产损失。

**概率**是描述某一事件发生可能性的度量。在保险风险评估中，概率用于计算风险事件发生的可能性。例如，计算某一地区在一定时期内发生火灾的概率。

风险与概率之间的关系可以通过以下公式表示：

\[ \text{风险} = \text{概率} \times \text{损失} \]

**连续型随机变量**是指在特定条件下可以取无限多个值的随机变量。例如，一个人的身高就是一个连续型随机变量。

### 贝叶斯网络

贝叶斯网络（Bayesian network）是一种概率模型，它用有向无环图（DAG）表示变量之间的条件依赖关系。贝叶斯网络在保险风险评估中非常有用，因为它可以用于计算变量之间的条件概率。

#### 算法原理

1. **定义变量**：首先，我们需要定义所有相关的变量。例如，在保险风险评估中，可能包括风险事件（如火灾、洪水）、保险赔付金额等。

2. **构建有向图**：使用有向无环图表示变量之间的条件依赖关系。例如，风险事件可能导致保险赔付金额的变化。

3. **设定先验概率**：为网络中的每个变量设定先验概率分布。这些先验概率是基于历史数据和专家经验的估计。

4. **计算条件概率**：使用贝叶斯定理计算变量之间的条件概率。贝叶斯定理描述了如何根据先验概率和观测数据来更新概率分布。

#### 伪代码

```python
# 贝叶斯网络
class BayesianNetwork:
    def __init__(self, variables, prior_probabilities):
        self.variables = variables
        self.prior_probabilities = prior_probabilities

    def calculate_probability(self, variable, value):
        # 假设变量之间是条件独立的
        probability = self.prior_probabilities[variable][value]
        for parent in self.variables[variable].parents:
            probability *= self.prior_probabilities[parent][variable[value]]
        return probability

# 定义变量

prior_probabilities = {
    "火灾": {"发生": 0.1, "未发生": 0.9},
    "赔付金额": {"高": 0.2, "低": 0.8}
}

# 构建贝叶斯网络
bayesian_network = BayesianNetwork(variables, prior_probabilities)

# 计算条件概率
probability = bayesian_network.calculate_probability("赔付金额", "高")
```
