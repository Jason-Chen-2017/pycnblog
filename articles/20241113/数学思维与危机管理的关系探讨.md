**## 案例一：应急物资分配**

假设某个城市发生了自然灾害，需要紧急分配救援物资。现有以下物资和需求信息：

- 物资种类：食物、水、帐篷、药品
- 物资供应量：1000吨、1000吨、500顶、500盒
- 需求量：食物1500吨、水1500吨、帐篷800顶、药品600盒
- 物资分配成本：食物100元/吨、水100元/吨、帐篷200元/顶、药品300元/盒

我们需要求解最优的物资分配方案，使得总成本最小。

**### 代码实现**

```python
# 引入线性规划库
import cvxpy as cp

# 定义变量
x = cp.Variable(nonnegative=True)  # 食物分配量
y = cp.Variable(nonnegative=True)  # 水分配量
z = cp.Variable(nonnegative=True)  # 帐篷分配量
w = cp.Variable(nonnegative=True)  # 药品分配量

# 定义目标函数
objective = cp.Minimize(100 * x + 100 * y + 200 * z + 300 * w)

# 定义约束条件
constraints = [
    x + y + z + w == 1500,  # 总需求量
    x <= 1000,             # 食物供应量
    y <= 1000,             # 水供应量
    z <= 500,              # 帐篷供应量
    w <= 500               # 药品供应量
]

# 求解线性规划问题
problem = cp.Problem(objective, constraints)
problem.solve()

# 输出结果
print(f"食物分配量：{x.value}")
print(f"水分配量：{y.value}")
print(f"帐篷分配量：{z.value}")
print(f"药品分配量：{w.value}")
```

**### 结果解析**

运行代码后，我们可以得到最优的物资分配方案：

- 食物分配量：1000吨
- 水分配量：1000吨
- 帐篷分配量：500顶
- 药品分配量：500盒

总成本为：1000 * 100 + 1000 * 100 + 500 * 200 + 500 * 300 = 100,000 + 100,000 + 100,000 + 150,000 = 450,000元。

通过这个案例，我们可以看到数学优化方法在危机管理中的应用。在这个案例中，我们使用了线性规划来求解最优的物资分配方案，从而最大限度地降低总成本。
