## 数据结构基础

### 2.1 线性结构

线性结构是数据结构中最基本的一种类型，包括数组、链表、栈和队列等。

#### 2.1.1 数组

数组是一种集合数据类型，它包含固定数量的变量，这些变量都是同一类型，使用相同的名称。数组中的变量按照顺序排列，可以通过下标访问。例如，以下是一个包含 5 个整数的数组：

```python
arr = [1, 2, 3, 4, 5]
```

数组的特点是访问速度快，但是大小固定，不适合动态扩展。

#### 2.1.2 链表

链表是一种由节点组成的线性结构，每个节点包含数据和指向下一个节点的指针。链表可以动态扩展，适合存储大量数据。以下是一个简单的单向链表示例：

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

head = Node(1)
head.next = Node(2)
head.next.next = Node(3)
```

链表的优点是插入和删除操作效率高，但访问速度相对较慢。

#### 2.1.3 栈与队列

栈是一种后进先出（LIFO）的线性结构，而队列是一种先进先出（FIFO）的线性结构。栈和队列都可以使用数组或链表实现。

```python
class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        return self.items.pop()

class Queue:
    def __init__(self):
        self.items = []

    def enqueue(self, item):
        self.items.append(item)

    def dequeue(self):
        return self.items.pop(0)
```

栈和队列在数据处理中非常有用，例如在模拟宇宙暗物质湍流时，可以用来管理模拟过程中的事件。

#### 2.2.1 二叉树

#### 2.2.2 堆

堆是一种特殊的树形数据结构，通常用于实现优先队列。堆分为最大堆和最小堆，其中每个父节点的值都不大于或不小于其子节点的值。

#### 2.2.3 散列表

散列表是一种通过计算散列值来快速访问数据的结构。散列表通常使用数组作为底层存储结构，并通过散列函数来计算键值的索引。

```python
class HashTable:
    def __init__(self, size):
        self.size = size
        self.table = [None] * size

    def hash_function(self, key):
        return key % self.size

    def insert(self, key, value):
        index = self.hash_function(key)
        if self.table[index] is None:
            self.table[index] = [(key, value)]
        else:
            self.table[index].append((key, value))
```

### 2.3 图形结构

#### 2.3.1 图的基本概念

图是由节点和边组成的集合，节点表示实体，边表示节点之间的关系。图可以分为有向图和无向图，也可以按照边的数量分为简单图和多重图。

```python
class Graph:

    def add_node(self, node):
        self.nodes[node] = []

    def add_edge(self, node1, node2):

        self.nodes[node1].append(node2)
        self.nodes[node2].append(node1)
```

```python
def dfs(graph, start):
```

N-Body Simulation的基本原理可以概括为以下几个步骤：

1. **初始化**：设定初始粒子集合，每个粒子具有位置和速度。
2. **计算引力**：对于每对粒子，计算它们之间的引力，根据引力公式更新粒子的加速度。
3. **更新位置和速度**：使用新的加速度更新粒子的位置和速度。
4. **重复计算**：重复步骤2和3，直到达到预设的时间步数或停止条件。

引力计算公式如下：

\[ F = G \frac{m_1 m_2}{r^2} \]

其中，\( F \) 是引力，\( G \) 是引力常数，\( m_1 \) 和 \( m_2 \) 是两个粒子的质量，\( r \) 是两个粒子之间的距离。

##### 5.1.2 伪代码

```python
# 初始化粒子集合
particles = [
    [x1, y1, z1, v1x, v1y, v1z],
    [x2, y2, z2, v2x, v2y, v2z],
    ...
]

# 引力常数
G = 6.674 * 10^-11

# 时间步长
dt = 0.01

# 模拟循环
while True:
    # 计算引力
    for i in range(len(particles)):
        for j in range(i + 1, len(particles)):
            dx = particles[i][0] - particles[j][0]
            dy = particles[i][1] - particles[j][1]
            dz = particles[i][2] - particles[j][2]
            distance = np.sqrt(dx**2 + dy**2 + dz**2)
            force = G * particles[i][3] * particles[j][3] / distance**2
            # 更新加速度
            particles[i][4] += force[0] / particles[i][3]
            particles[i][5] += force[1] / particles[i][3]
            particles[i][6] += force[2] / particles[i][3]
            # 更新加速度
            particles[j][4] -= force[0] / particles[j][3]
            particles[j][5] -= force[1] / particles[j][3]
            particles[j][6] -= force[2] / particles[j][3]
    
    # 更新位置和速度
    for particle in particles:
        particle[0] += particle[4] * dt
        particle[1] += particle[5] * dt
        particle[2] += particle[6] * dt
        particle[4] *= (1 - dt * drag)
        particle[5] *= (1 - dt * drag)
        particle[6] *= (1 - dt * drag)

    # 输出结果
    if (t > max_time):
        break
```

#### 5.2 Particle-Particle (P-P) Algorithm

Particle-Particle (P-P) Algorithm是一种N-Body Simulation的优化方法，它通过将所有粒子分成若干个子群，只计算子群内的相互作用，从而减少计算量。

##### 5.2.1 基本原理

P-P Algorithm的基本原理可以概括为以下几个步骤：

1. **初始化**：设定初始粒子集合，将粒子划分为若干个子群。
2. **计算子群内引力**：对于每个子群，计算子群内各粒子之间的引力。
3. **计算子群间引力**：对于每个子群，计算它与所有其他子群之间的引力。
4. **更新位置和速度**：使用新的加速度更新粒子的位置和速度。

##### 5.2.2 伪代码

```python
# 初始化粒子集合和子群
particles = [
    [x1, y1, z1, v1x, v1y, v1z],
    [x2, y2, z2, v2x, v2y, v2z],
    ...
]
subgroups = partition_particles(particles)

# 引力常数
G = 6.674 * 10^-11

# 时间步长

# 模拟循环

    for subgroup in subgroups:

                subgroup[i][5] += force[1] / subgroup[i][3]
                subgroup[i][6] += force[2] / subgroup[i][3]
                # 更新加速度
                subgroup[j][4] -= force[0] / subgroup[j][3]
                subgroup[j][5] -= force[1] / subgroup[j][3]
                subgroup[j][6] -= force[2] / subgroup[j][3]

    # 计算子群间引力
    for i in range(len(subgroups)):
        for j in range(i + 1, len(subgroups)):
            for particle_i in subgroups[i]:
                for particle_j in subgroups[j]:
                    dx = particle_i[0] - particle_j[0]
                    dy = particle_i[1] - particle_j[1]
                    dz = particle_i[2] - particle_j[2]
                    distance = np.sqrt(dx**2 + dy**2 + dz**2)
                    force = G * particle_i[3] * particle_j[3] / distance**2
                    # 更新加速度
                    particle_i[4] += force[0] / particle_i[3]
                    particle_i[5] += force[1] / particle_i[3]
                    particle_i[6] += force[2] / particle_i[3]
                    # 更新加速度
                    particle_j[4] -= force[0] / particle_j[3]
                    particle_j[5] -= force[1] / particle_j[3]
                    particle_j[6] -= force[2] / particle_j[3]

    # 更新位置和速度
    for subgroup in subgroups:
        for particle in subgroup:
            particle[0] += particle[4] * dt
            particle[1] += particle[5] * dt
            particle[2] += particle[6] * dt
            particle[4] *= (1 - dt * drag)
            particle[5] *= (1 - dt * drag)
            particle[6] *= (1 - dt * drag)

    # 输出结果
    if (t > max_time):
        break
```

#### 5.3 Particle-Mesh (P-M) Algorithm

Particle-Mesh (P-M) Algorithm是另一种N-Body Simulation的优化方法，它结合了粒子模拟和网格模拟的优点。

##### 5.3.1 基本原理

P-M Algorithm的基本原理可以概括为以下几个步骤：

1. **初始化**：设定初始粒子集合，将空间划分为网格。
2. **粒子插值**：将粒子属性插值到网格节点上。
3. **计算网格间引力**：使用网格节点计算网格间的引力。
4. **更新网格节点**：根据引力计算更新网格节点的位置和属性。
5. **更新粒子位置和速度**：使用网格节点更新粒子的位置和速度。

##### 5.3.2 伪代码

```python
# 初始化粒子集合和网格
particles = [
    [x1, y1, z1, v1x, v1y, v1z],
    [x2, y2, z2, v2x, v2y, v2z],
    ...
]
mesh = create_mesh(particles)

# 引力常数
G = 6.674 * 10^-11

# 时间步长
dt = 0.01

# 模拟循环
while True:
    # 粒子插值到网格节点
    for particle in particles:
        interpolate_particle_to_mesh(particle, mesh)

    # 计算网格间引力
    for i in range(len(mesh)):
        for j in range(i + 1, len(mesh)):
            dx = mesh[i][0] - mesh[j][0]
            dy = mesh[i][1] - mesh[j][1]
            dz = mesh[i][2] - mesh[j][2]
            distance = np.sqrt(dx**2 + dy**2 + dz**2)
            force = G * mesh[i][3] * mesh[j][3] / distance**2
            # 更新加速度
            mesh[i][4] += force[0] / mesh[i][3]
            mesh[i][5] += force[1] / mesh[i][3]
            mesh[i][6] += force[2] / mesh[i][3]
            # 更新加速度
            mesh[j][4] -= force[0] / mesh[j][3]
            mesh[j][5] -= force[1] / mesh[j][3]
            mesh[j][6] -= force[2] / mesh[j][3]

    # 更新网格节点
    for node in mesh:
        node[0] += node[4] * dt
        node[1] += node[5] * dt
        node[2] += node[6] * dt
        node[4] *= (1 - dt * drag)
        node[5] *= (1 - dt * drag)
        node[6] *= (1 - dt * drag)

    # 更新粒子位置和速度
    for particle in particles:
        particle[0] = interpolate_mesh_to_particle(mesh, particle)
        particle[1] = interpolate_mesh_to_particle(mesh, particle)
        particle[2] = interpolate_mesh_to_particle(mesh, particle)
        particle[4] *= (1 - dt * drag)
        particle[5] *= (1 - dt * drag)
        particle[6] *= (1 - dt * drag)

    # 输出结果
    if (t > max_time):
        break
```

### 数学模型与公式

在模拟宇宙暗物质湍流的过程中，数学模型和公式是理解和分析这一复杂现象的关键工具。以下将详细讲解用于描述暗物质湍流的几个关键数学模型和公式。

#### 1. 暗物质粒子的分布

暗物质在宇宙中的分布通常可以用一个概率密度函数 \( \rho(\mathbf{x}) \) 来描述，其中 \( \mathbf{x} \) 表示粒子的位置。一个常见的暗物质分布模型是高斯分布：

\[ \rho(\mathbf{x}) = \frac{1}{(2\pi\sigma^2)} e^{-\frac{|\mathbf{x} - \mathbf{m}|^2}{2\sigma^2}} \]

其中，\( \mathbf{m} \) 是分布的中心，\( \sigma \) 是分布的宽度。

#### 2. 粒子间的引力相互作用

粒子间的引力相互作用可以用牛顿万有引力定律来描述。对于两个粒子 \( i \) 和 \( j \)，它们之间的引力 \( F_{ij} \) 可以表示为：

\[ F_{ij} = -G \frac{m_i m_j}{|\mathbf{r}_i - \mathbf{r}_j|^2} \mathbf{n}_{ij} \]

其中，\( G \) 是引力常数，\( m_i \) 和 \( m_j \) 是两个粒子的质量，\( \mathbf{r}_i \) 和 \( \mathbf{r}_j \) 是两个粒子的位置，\( \mathbf{n}_{ij} \) 是从粒子 \( i \) 指向粒子 \( j \) 的单位向量。

#### 3. 粒子的运动方程

粒子在引力作用下的运动可以用牛顿第二定律来描述。对于单个粒子 \( i \)，它的加速度 \( \mathbf{a}_i \) 可以表示为：

\[ \mathbf{a}_i = \frac{F_{ij}}{m_i} = -G \frac{m_j}{|\mathbf{r}_i - \mathbf{r}_j|^2} \mathbf{n}_{ij} \]

粒子的速度 \( \mathbf{v}_i \) 和位置 \( \mathbf{r}_i \) 随时间的变化可以表示为：

\[ \mathbf{v}_i(t) = \mathbf{v}_i(t_0) + \int_{t_0}^{t} \mathbf{a}_i(\tau) d\tau \]

\[ \mathbf{r}_i(t) = \mathbf{r}_i(t_0) + \mathbf{v}_i(t_0) (t - t_0) + \int_{t_0}^{t} \int_{t_0}^{\tau} \mathbf{a}_i(\tau') d\tau' d\tau \]

#### 4. 湍流速度功率谱

湍流速度功率谱 \( P(k) \) 描述了湍流中速度波动的强度分布，其中 \( k \) 是波数。湍流速度功率谱通常可以用以下公式表示：

\[ P(k) = C_s^4 k^{-3} \left( 1 + \frac{1.08 k^2}{k_s^2} \right) \]

其中，\( C_s \) 是声速，\( k_s \) 是湍流尺度的波数。

#### 5. 湍流能量密度

湍流能量密度 \( E(\mathbf{k}) \) 描述了湍流中能量分布，其中 \( \mathbf{k} \) 是波矢。湍流能量密度可以用以下公式表示：

\[ E(\mathbf{k}) = \frac{1}{2} \int \left| \mathbf{v}(\mathbf{k}) \right|^2 d^3\mathbf{k} \]

其中，\( \mathbf{v}(\mathbf{k}) \) 是湍流速度场的波数分布。

### 举例说明

首先，我们使用高斯分布公式来初始化粒子位置：

\[ \mathbf{r}_i \sim \mathcal{N}(\mathbf{m}, \sigma^2 \mathbf{I}) \]

其中，\( \mathbf{m} \) 是分布的中心，\( \sigma \) 是分布的宽度，\( \mathbf{I} \) 是单位矩阵。

然后，我们计算每对粒子之间的引力，并使用牛顿第二定律来更新粒子的速度和位置。以下是一个简化的伪代码示例：

```python
    positions += velocities * dt
```

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint

# 引力常数
G = 6.674 * 10 ** -11

# 初始化粒子
def initialize_particles(num_particles, position_range, velocity_range):
    positions = np.random.uniform(-position_range, position_range, (num_particles, 3))
    velocities = np.random.uniform(-velocity_range, velocity_range, (num_particles, 3))
    return positions, velocities

# 计算粒子间引力
def compute_gravity(positions, velocities, masses):
    forces = np.zeros((len(positions), 3))
    for i in range(len(positions)):
        for j in range(i + 1, len(positions)):
            dx = positions[i] - positions[j]
            distance = np.linalg.norm(dx)
            force = G * masses[i] * masses[j] / distance ** 2
            force_vector = force * dx / distance
            forces[i] += force_vector
            forces[j] -= force_vector
    return forces

# 模拟粒子运动
def simulate_particles(positions, velocities, masses, time_steps, dt):
    results = []
    for t in range(time_steps):
        forces = compute_gravity(positions, velocities, masses)
        accelerations = forces / masses
        velocities += accelerations * dt
        positions += velocities * dt
        results.append((positions, velocities))
    return results

# 可视化结果
def visualize_results(results):
    positions, velocities = zip(*results)
    for pos, vel in zip(positions, velocities):
        plt.plot(pos[0], pos[1], 'o')
        plt.quiver(pos[0], pos[1], vel[0], vel[1])
    plt.xlabel('X-position')
    plt.ylabel('Y-position')
    plt.title('Dark Matter Particle Simulation')
    plt.show()
```
