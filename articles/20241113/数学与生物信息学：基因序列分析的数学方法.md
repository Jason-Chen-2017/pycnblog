## 数学基础

### 概率论基础

概率论是基因序列分析的基础。在基因序列中，每个位点都有可能发生突变，这些突变事件可以用概率来描述。例如，我们可以计算一个基因位点突变到另一个特定位点的概率，从而预测可能的突变情况。

**核心概念与联系**

$$
P(A) = \frac{n(A)}{n(S)}
$$

其中，$P(A)$ 表示事件 $A$ 发生的概率，$n(A)$ 表示事件 $A$ 发生的次数，$n(S)$ 表示样本空间中所有可能事件的总数。

**核心算法原理**

$$
H_0: \mu = \mu_0 \\
H_1: \mu \neq \mu_0
$$

其中，$H_0$ 表示原假设，$H_1$ 表示备择假设，$\mu$ 表示总体均值，$\mu_0$ 表示原假设下的总体均值。

### 图论

图论在基因序列分析中用于描述基因之间的相互作用。图由节点（基因）和边（相互作用）组成。

**核心算法原理**

$$
Dijkstra's Algorithm
$$

**伪代码**

```python
def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    visited = set()
    while True:
        unvisited = {node: distance for node, distance in graph.items() if node not in visited}
        if not unvisited:
            break
        closest = min(unvisited, key=unvisited.get)
        visited.add(closest)
        for neighbor, weight in graph[closest].items():
            distance = distances[closest] + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
    return distances
```

### 序列比对

序列比对是基因序列分析的重要步骤，用于比较两个或多个基因序列的相似性。

**核心算法原理**

$$
Score = \sum_{i,j} s_{ij}
$$

其中，$s_{ij}$ 表示比对得分，$i$ 和 $j$ 分别表示两个序列的索引。

**伪代码**

```python
def sequence_alignment(seq1, seq2):
    matrix = [[0 for _ in range(len(seq2) + 1)] for _ in range(len(seq1) + 1)]
    for i in range(1, len(seq1) + 1):
        for j in range(1, len(seq2) + 1):
            match = matrix[i - 1][j - 1] + s[seq1[i - 1], seq2[j - 1]]
            delete1 = matrix[i - 1][j] - gap_penalty
            delete2 = matrix[i][j - 1] - gap_penalty
            matrix[i][j] = max(match, delete1, delete2)
    return matrix[len(seq1)][len(seq2)]
```

## 基因序列分析核心算法

### BLAST算法

BLAST（Basic Local Alignment Search Tool）是一种用于序列比对的高效算法，常用于基因序列的相似性搜索。

**核心算法原理**

$$
Similarity = \sum_{i,j} s_{ij} \cdot p_{ij}
$$

其中，$s_{ij}$ 表示比对得分，$p_{ij}$ 表示匹配概率。

**伪代码**

```python
def blast(seq1, seq2, k):
    matrix = [[0 for _ in range(len(seq2) + 1)] for _ in range(len(seq1) + 1)]
    for i in range(1, len(seq1) + 1):
        for j in range(1, len(seq2) + 1):
            match = matrix[i - 1][j - 1] + s[seq1[i - 1], seq2[j - 1]]
            delete1 = matrix[i - 1][j] - gap_penalty
            delete2 = matrix[i][j - 1] - gap_penalty
            matrix[i][j] = max(match, delete1, delete2)
    score = matrix[len(seq1)][len(seq2)]
    if score >= k:
        return True
    else:
        return False
```

### Smith-Waterman算法

Smith-Waterman算法是一种用于局部序列比对的算法，常用于基因序列的相似性搜索。

**核心算法原理**

$$
Score = \sum_{i,j} s_{ij} \cdot p_{ij}
$$

其中，$s_{ij}$ 表示比对得分，$p_{ij}$ 表示匹配概率。

**伪代码**

```python
def smith_waterman(seq1, seq2, k):
    matrix = [[0 for _ in range(len(seq2) + 1)] for _ in range(len(seq1) + 1)]
    for i in range(1, len(seq1) + 1):
        for j in range(1, len(seq2) + 1):
            match = matrix[i - 1][j - 1] + s[seq1[i - 1], seq2[j - 1]]
            delete1 = matrix[i - 1][j] - gap_penalty
            delete2 = matrix[i][j - 1] - gap_penalty
            matrix[i][j] = max(0, match, delete1, delete2)
    score = matrix[len(seq1)][len(seq2)]
    if score >= k:
        return True
    else:
        return False
```
