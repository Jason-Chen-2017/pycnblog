### 第1章：和声学基本概念

和声学是音乐理论的一个分支，它关注音乐中的声部组合、和弦结构和和声进行。和声学的基本概念包括音的构成、音程、音阶、和弦以及和声的功能等。这些概念是理解音乐创作和演奏的基础。

#### 1.1 音的构成

音是音乐的基本元素，它由频率决定。在音乐中，音高的概念非常重要。音高由声波的振动频率决定，频率越高，音高越高。例如，C音的频率约为261.63赫兹。

音程是指两个音在音高上的关系。音程可以分为大小、纯、增、减等类型。例如，C到E是一个小二度音程，C到G是一个纯五度音程。

#### 1.2 音阶与和弦

音阶是按照一定的音程关系排列的一组音。常见的音阶有大小音阶。大音阶由全音和半音组成，小音阶则由半音和全音组成。

和弦是由三个或更多个音同时演奏而形成的一种音乐结构。三和弦是最基本的和弦类型，它由三个音按三度关系排列而成。七和弦是三和弦的扩展，它包含根音、三音、五音和七音。

#### 1.3 和声的功能

和声的功能指的是和弦在音乐进行中的作用。和声的功能可以分为根音功能、三音功能和五音功能等。不同的和声功能在音乐中承担着不同的作用，如推动音乐发展、提供和声支持等。

#### 1.4 和声的连接与过渡

和声的连接与过渡是指和弦之间的转换。和声进行的基本原则包括和弦的连接规则和和弦进行的常见模式。和弦的转换需要注意和声的流畅性和音乐的连贯性。

音程关系分为自然音程和变化音程。自然音程是指音阶中的音程，如大二度、小二度、大三度等。变化音程是指通过升降半音得到的音程，如增四度、减五度等。

音程的计算与识别是理解音程关系的关键。音程的计算基于半音和全音的概念。例如，从C音到E音是一个小二度，而从C音到G音是一个纯五度。

- 调性与旋律的数学模型：例如，调性中心可以表示为旋律的核心音，旋律的发展可以基于调性中心进行。

```python
def construct_triad(root_note, quality):
    if quality == 'major':
        third = root_note + 4
        fifth = root_note + 7
    elif quality == 'minor':
        third = root_note + 3
        fifth = root_note + 7
    chord = [root_note, third, fifth]
    return chord
```
