```pseudocode
function buildMaxHeap(arr):
    n = length(arr)
    for i from n/2 downto 1:
        heapify(arr, i, n)

// 调整堆
function heapify(arr, i, n):
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left

    if right < n and arr[right] > arr[largest]:
        largest = right

    if largest != i:
        swap(arr[i], arr[largest])
        heapify(arr, largest, n)

// 堆排序
function heapSort(arr):
    buildMaxHeap(arr)
    n = length(arr)

    for i from n downto 2:
        swap(arr[1], arr[i])
        heapify(arr, 1, i - 1)
```

$$

$$

其中，\( r \) 是事件视界的半径，\( G \) 是引力常数，\( M \) 是黑洞质量，\( c \) 是光速，\( \tau \) 是坐标时间，\( v \) 是物体速度。

推导过程：
- 首先，利用广义相对论中的引力势能公式 \( U = -\frac{GMm}{r} \)，其中 \( m \) 是物体的质量。

- 最后，通过代数变换得到光锥展开公式。

举例说明：

$$

$$

若 \( v = 0 \)，则 \( \frac{dr}{d\tau} = \frac{1}{\sqrt{1 - \frac{2GM}{rc^2}}} \approx 0.528 \)。
