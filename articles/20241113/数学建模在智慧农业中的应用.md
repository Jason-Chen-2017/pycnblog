```
// 作物生长模型构建伪代码

// 输入：
// initial_growth_rate: 初始生长速率
// maturity_time: 成熟时间
// growth_phase1_time: 第一个生长阶段时间
// growth_phase2_time: 第二个生长阶段时间
// growth_phase3_time: 第三个生长阶段时间

// 输出：
// growth_curve: 作物生长曲线

function build_growth_model(initial_growth_rate, maturity_time, growth_phase1_time, growth_phase2_time, growth_phase3_time):
    growth_curve = []

    // 第一个生长阶段
    for time in range(0, growth_phase1_time):
        growth_curve.append(initial_growth_rate)

    // 第二个生长阶段
    for time in range(growth_phase1_time, growth_phase1_time + growth_phase2_time):
        growth_rate = initial_growth_rate * (1 - (time - growth_phase1_time) / maturity_time)
        growth_curve.append(growth_rate)

    // 第三个生长阶段
    for time in range(growth_phase1_time + growth_phase2_time, growth_phase1_time + growth_phase2_time + growth_phase3_time):
        growth_rate = initial_growth_rate * (1 - (time - growth_phase1_time - growth_phase2_time) / maturity_time)
        growth_curve.append(growth_rate)

    return growth_curve
```

通过这个伪代码，我们可以清晰地看到作物生长模型的构建过程，包括初始生长速率、成熟时间、各生长阶段时间等参数。这样的伪代码不仅有助于理解算法原理，还可以作为编程实现的基础。
