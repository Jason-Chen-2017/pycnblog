## 基础理论

### 2.1 数据结构概述

数据结构是程序设计中的重要概念，它定义了数据组织和存储的方式。数据结构可以分为两大类：线性结构和非线性结构。线性结构包括数组、链表、栈和队列，而非线性结构包括树和图。

**线性结构**：
- **数组**：一种固定大小的数据集合，元素按顺序存储。
- **链表**：由节点组成的序列，每个节点包含数据和指向下一个节点的指针。
- **栈**：后进先出（LIFO）的数据结构，用于存储临时数据。
- **队列**：先进先出（FIFO）的数据结构，用于处理排队任务。

**非线性结构**：
- **树**：层次结构，节点有且仅有一个父节点，除了根节点。
- **图**：由节点和边组成，表示复杂的关系网络。

### 2.2 算法基础

算法是一系列解决问题的步骤，通常包括输入、处理和输出。算法的设计原则包括正确性、效率、健壮性和可扩展性。

**算法分析**：
- **时间复杂度**：评估算法执行时间与输入规模的关系。
- **空间复杂度**：评估算法所需存储空间与输入规模的关系。

**算法设计**：
- **分治策略**：将问题分解为较小的子问题，递归解决。
- **贪心算法**：每一步选择最优解，期望整体最优。
- **动态规划**：利用历史信息做出最优决策。

**数学模型**：
- **公式**：描述算法的基本关系和计算方法。
- **数学模型应用**：在算法设计和分析中使用数学模型，如概率论和线性代数。

## 核心算法原理

在程序设计中，算法的效率和适用性是关键。本节将详细讲解常见的排序算法和查找算法，包括冒泡排序、选择排序、插入排序、快速排序、二分查找和哈希查找。

### 3.1 常见排序算法

排序算法是数据结构中的基本操作之一，用于将数据按特定顺序排列。以下是一些常见的排序算法：

#### 3.1.1 冒泡排序

冒泡排序是一种简单的排序算法，其基本思想是通过多次遍历列表，比较相邻元素并交换它们，使得较大的元素逐渐“冒泡”到数组的末尾。

**伪代码**：
```markdown
function bubbleSort(array)
    n = length(array)
    for i from 0 to n-1
        for j from 0 to n-i-1
            if array[j] > array[j+1]
                swap(array[j], array[j+1])
```

**时间复杂度**：\(O(n^2)\)

#### 3.1.2 选择排序

选择排序是一种简单但效率较低的排序算法，其基本思想是每次遍历列表，找到最小元素并将其放置在当前排序序列的末尾。

**伪代码**：
```markdown
function selectionSort(array)
    n = length(array)
    for i from 0 to n-1
        minIndex = i
        for j from i+1 to n
            if array[j] < array[minIndex]
                minIndex = j
        swap(array[i], array[minIndex])
```

**时间复杂度**：\(O(n^2)\)

#### 3.1.3 插入排序

插入排序是一种简单的排序算法，其基本思想是将未排序的数据插入到已排序的序列中，从而实现整个序列的排序。

**伪代码**：
```markdown
function insertionSort(array)
    n = length(array)
    for i from 1 to n
        key = array[i]
        j = i - 1
        while j >= 0 and array[j] > key
            array[j+1] = array[j]
            j = j - 1
        array[j+1] = key
```

**时间复杂度**：\(O(n^2)\)

#### 3.1.4 快速排序

快速排序是一种高效的排序算法，其基本思想是通过选取一个基准元素，将数组划分为两个子数组，一个包含小于基准元素的元素，另一个包含大于基准元素的元素。

**伪代码**：
```markdown
function quickSort(array, low, high)
    if low < high
        pi = partition(array, low, high)
        quickSort(array, low, pi-1)
        quickSort(array, pi+1, high)

function partition(array, low, high)
    pivot = array[high]
    i = low - 1
    for j from low to high-1
        if array[j] < pivot
            i = i + 1
            swap(array[i], array[j])
    swap(array[i+1], array[high])
    return i + 1
```

**时间复杂度**：\(O(n \log n)\)

### 3.2 查找算法

查找算法用于在数据结构中查找特定元素。以下是一些常见的查找算法：

#### 3.2.1 二分查找

二分查找是一种高效的查找算法，其基本思想是在有序数组中通过重复分裂查找区域，直到找到目标元素或确定其不存在。

**伪代码**：
```markdown
function binarySearch(array, target)
    low = 0
    high = length(array) - 1
    while low <= high
        mid = (low + high) / 2
        if array[mid] == target
            return mid
        elif array[mid] < target
            low = mid + 1
        else
            high = mid - 1
    return -1
```

**时间复杂度**：\(O(\log n)\)

#### 3.2.2 哈希查找

哈希查找是一种基于哈希表的查找算法，其基本思想是通过哈希函数将关键字映射到哈希表中，从而实现快速查找。

**伪代码**：
```markdown
function hashSearch(hashTable, key)
    index = hashFunction(key)
    if hashTable[index] == key
        return index
    else
        return -1
```

**时间复杂度**：\(O(1)\)

#### 4.1.1 链表应用

链表在程序设计中广泛使用，尤其在动态数据集合中。以下是一个使用链表实现的简单任务队列。

**伪代码**：
```markdown
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        newNode = Node(data)
        if not self.head:
            self.head = newNode
        else:
            current = self.head
            while current.next:
                current = current.next
            current.next = newNode

    def printList(self):
        current = self.head
        while current:
            print(current.data, end=" -> ")
            current = current.next
        print("None")

# 实例化链表

queue.append(1)
queue.append(2)
queue.append(3)
queue.printList()  # 输出：1 -> 2 -> 3 -> None
```

#### 4.1.2 栈和队列应用

栈和队列是常用的线性数据结构，广泛应用于各种场景。以下是一个使用栈实现的后缀表达式计算器。

**伪代码**：
```markdown
class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        return self.items.pop()

    def isEmpty(self):
        return len(self.items) == 0

def evaluatePostfix(expression):
    stack = Stack()
    for char in expression:
        if char.isdigit():
            stack.push(int(char))
        else:
            operand2 = stack.pop()
            operand1 = stack.pop()
            if char == '+':
                stack.push(operand1 + operand2)
            elif char == '-':
                stack.push(operand1 - operand2)
            elif char == '*':
                stack.push(operand1 * operand2)
            elif char == '/':
                stack.push(operand1 / operand2)
    return stack.pop()

expression = "123+*45-"
result = evaluatePostfix(expression)
print("Result:", result)  # 输出：Result: 7
```

### 4.2 算法应用

#### 4.2.1 排序算法实战

以下是一个使用快速排序算法对数组进行排序的实例。

**伪代码**：
```markdown
def quickSort(array, low, high):
    if low < high:
        pi = partition(array, low, high)
        quickSort(array, low, pi - 1)
        quickSort(array, pi + 1, high)

def partition(array, low, high):
    pivot = array[high]
    i = low - 1
    for j in range(low, high):
        if array[j] < pivot:
            i += 1
            array[i], array[j] = array[j], array[i]
    array[i + 1], array[high] = array[high], array[i + 1]
    return i + 1

# 示例数组
array = [10, 7, 8, 9, 1, 5]
n = len(array)
quickSort(array, 0, n - 1)
print("Sorted array:", array)  # 输出：Sorted array: [1, 5, 7, 8, 9, 10]
```

#### 4.2.2 查找算法实战

**伪代码**：

```markdown
def binarySearch(array, target):
    low = 0
    high = len(array) - 1
    while low <= high:
        mid = (low + high) // 2
        if array[mid] == target:
            return mid
        elif array[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

# 示例数组
array = [1, 3, 5, 7, 9, 10]
target = 7
result = binarySearch(array, target)
if result != -1:
    print("Element found at index:", result)
else:
    print("Element not found")  # 输出：Element found at index: 3
```
