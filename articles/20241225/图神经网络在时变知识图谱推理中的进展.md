#### 3.4 数学模型和数学公式

在深入探讨图神经网络（GNN）在时变知识图谱（TKG）推理中的应用时，了解其背后的数学模型和公式是非常重要的。以下是GNN在TKG推理中的数学模型和公式的详细讲解。

**3.4.1 节点特征更新**

GNN的核心机制之一是通过聚合邻居节点的特征来更新当前节点的特征。这个过程可以用以下数学公式表示：

$$
\text{h}_{t}^{(n)} = \sigma(W_n \cdot (\text{h}_{t-1}^{(n)} + \sum_{i \in \text{N}(n)} \text{h}_{t-1}^{(i)} + \text{b}_n))
$$

其中：
- \( \text{h}_{t}^{(n)} \) 表示节点 \( n \) 在时间 \( t \) 的特征向量。
- \( \text{N}(n) \) 表示节点 \( n \) 的邻居节点集合。
- \( \text{h}_{t-1}^{(n)} \) 和 \( \text{h}_{t-1}^{(i)} \) 分别表示节点 \( n \) 和其邻居节点 \( i \) 在时间 \( t-1 \) 的特征向量。
- \( W_n \) 是节点特征更新的权重矩阵。

```python
    def __init__(self, entity_dim, relation_dim, hidden_dim):
        super(GNNModel, self).__init__()

        self.fc = nn.Linear(hidden_dim * 3, hidden_dim)
```

```python
import torch
import torch.nn as nn

class GNNModel(nn.Module):
    def __init__(self, num_entities, hidden_dim):
        super(GNNModel, self).__init__()
        self.embedding = nn.Embedding(num_entities, hidden_dim)
```
