### 核心算法原理讲解：
- **反向传播算法**：用于训练神经网络的算法，通过不断调整网络的权重和偏置，使网络能够更好地拟合数据。
  ```python
  def backward_propagation(inputs, targets, outputs, weights):
      for layer in reversed(layers):
          error = targets - outputs
          delta = error * activation_derivative(outputs)
          weights[layer] -= learning_rate * dot(inputs, delta)
  ```
