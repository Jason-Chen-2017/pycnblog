### Step 2: Historical Context and Evolution

**1. The Evolution of Programming Languages**

- **Early Days:**
  - **Assembly Language (1940s-1950s):** Low-level language that provided direct control over hardware.
  - **High-Level Languages (1950s-1960s):** Fortran, COBOL, and others aimed at improving productivity.

- **Mid-20th Century:**
  - **Structured Programming (1960s-1970s):** Emphasized clear and logical control flow structures.
  - **Object-Oriented Programming (1970s-1980s):** C++, Java, and others introduced modularity and reusability.

- **Recent Trends:**
  - **Functional Programming (1990s-present):** Haskell, Scala, and others focus on immutability and higher-order functions.
  - **Domain-Specific Languages (1990s-present):** Designed for specific problem domains, e.g., SQL for databases, MATLAB for math and engineering.
