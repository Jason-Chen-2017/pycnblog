#### 1.1 AI时代的新挑战

随着人工智能（AI）技术的不断突破，我们正逐步进入一个全新的时代。这个时代不仅带来了前所未有的技术革新，也提出了诸多新的挑战。首先，数据安全问题变得尤为重要。AI系统高度依赖大量数据来训练模型，而这些数据往往涉及个人隐私和商业机密。如何在保证数据安全的前提下，充分利用这些数据成为AI时代的一大挑战。

其次，AI系统的透明性和可解释性也备受关注。传统的AI系统，如深度神经网络，通常被视为“黑箱”，其内部运作机制难以理解。然而，在许多实际应用场景中，用户和决策者需要了解AI系统的决策过程和依据，以确保其公正性和可靠性。因此，提高AI系统的透明性和可解释性成为AI时代的一个重要挑战。

此外，AI技术的伦理问题也日益凸显。随着AI在各个领域的应用逐渐深入，其可能带来的道德风险和负面影响也引起了广泛关注。例如，AI在招聘、贷款、医疗等领域的决策过程中，是否存在歧视现象？如何确保AI系统的决策符合道德规范，成为AI时代亟需解决的新挑战。

#### 1.2 AI时代的新方向

面对这些新挑战，AI技术也在不断探索新的发展方向。首先，增强学习（Reinforcement Learning）成为AI研究的重要方向之一。增强学习通过让智能体在与环境交互的过程中不断调整策略，以实现最佳决策。这种学习方式不仅在游戏领域取得了显著成果，还在自动驾驶、机器人控制等实际应用中展现出巨大潜力。

其次，联邦学习（Federated Learning）成为解决数据安全问题的有效途径。联邦学习通过将数据分散存储在多个设备或服务器上，只传输模型参数而非原始数据，从而实现了在保护用户隐私的前提下，进行大规模的机器学习训练。这一方向在移动设备、物联网等领域具有广泛的应用前景。

此外，可解释AI（Explainable AI，XAI）也成为AI研究的重要目标。可解释AI旨在提高AI系统的透明性和可解释性，使其决策过程和依据能够被用户和决策者理解。通过开发可解释的算法和工具，我们可以更好地应对AI系统的伦理问题，提高其在实际应用中的可信度和接受度。

### 第2章：AI的基本概念

#### 2.1 机器学习与深度学习

机器学习和深度学习是人工智能（AI）领域的两个核心概念。它们之间的关系可以比作整体与部分，或者母体与子集。机器学习是AI的基础，涵盖了各种方法和技术，包括监督学习、无监督学习和强化学习。而深度学习则是机器学习的一个分支，专注于通过多层神经网络来模拟人脑的神经元连接和功能。

##### 机器学习

机器学习（Machine Learning，ML）是一种利用数据、算法和统计模型，使计算机系统能够从数据中学习并做出决策或预测的技术。机器学习的关键在于“学习”，即通过训练模型来捕捉数据中的规律和模式，然后利用这些规律来解决具体问题。

机器学习可以分为以下几类：

1. **监督学习（Supervised Learning）**：在监督学习中，训练数据集包括输入和相应的输出标签。模型通过学习这些输入输出对，能够在新的数据上做出预测。常见的监督学习算法包括线性回归、逻辑回归、支持向量机（SVM）和神经网络等。

2. **无监督学习（Unsupervised Learning）**：无监督学习不需要输出标签，主要关注如何从未标记的数据中自动发现结构和模式。常见的无监督学习算法包括聚类、降维（如PCA）和关联规则学习等。

3. **强化学习（Reinforcement Learning）**：强化学习通过智能体与环境的交互，不断调整策略以实现最佳决策。智能体在每一步根据当前状态和奖励信号，更新策略以最大化长期奖励。常见的强化学习算法包括Q学习、SARSA和深度强化学习（DRL）等。

##### 深度学习

深度学习（Deep Learning，DL）是机器学习的一个重要分支，主要基于多层神经网络（Deep Neural Networks，DNN）进行学习。与传统的单层神经网络相比，深度学习通过增加网络层数，提高了模型的表达能力，使其能够自动提取更为复杂和抽象的特征。

深度学习的主要特点包括：

1. **多层网络结构**：深度学习模型通常由多层神经元组成，每一层都能提取不同级别的特征。输入经过多层网络的层层传递和变换，最终输出预测结果。

2. **自动特征提取**：与传统的机器学习方法不同，深度学习模型能够自动从数据中学习并提取特征。这使得深度学习在处理复杂问题时，能够避免人工特征工程，提高模型的泛化能力。

3. **大规模并行计算**：深度学习模型的训练需要大量计算资源。通过利用图形处理器（GPU）和 Tensor Processing Units（TPU）等专用硬件，深度学习能够在短时间内完成大规模训练任务。

深度学习在许多领域都取得了显著成果，例如：

- **图像识别**：通过卷积神经网络（CNN），深度学习在图像分类和物体检测等任务中取得了优异的性能。
- **自然语言处理**：深度学习模型，如循环神经网络（RNN）和变换器（Transformer），在语言建模、机器翻译和文本分类等方面表现出色。
- **语音识别**：结合深度神经网络和循环神经网络，深度学习在语音识别领域取得了突破性进展。
- **推荐系统**：深度学习能够从用户行为和物品属性中提取有效特征，为推荐系统提供精准的推荐结果。

#### 2.2 神经网络与激活函数

神经网络（Neural Networks，NN）是深度学习的基础构件。它由一系列神经元组成，通过相互连接和传递信息，实现数据的处理和分类。每个神经元都包含一个输入层、一个输出层和一个激活函数。

##### 神经元结构

一个简单的神经元可以看作是一个线性函数，接受多个输入，并通过权重（weights）进行加权求和，最后加上一个偏置项（bias），得到一个中间结果。这个中间结果通过激活函数（activation function）进行非线性变换，得到最终的输出。

\[ z = \sum_{i} w_i x_i + b \]
\[ a = f(z) \]

其中，\( z \) 是中间结果，\( w_i \) 是第 \( i \) 个输入的权重，\( x_i \) 是第 \( i \) 个输入，\( b \) 是偏置项，\( a \) 是输出。

##### 激活函数

激活函数是神经网络中的一个关键组件，用于引入非线性特性。常见的激活函数包括：

1. **Sigmoid函数**：Sigmoid函数是一种常用的激活函数，其表达式为：

\[ f(x) = \frac{1}{1 + e^{-x}} \]

Sigmoid函数的输出范围在 0 到 1 之间，可以看作是概率分布。然而，Sigmoid函数在训练过程中存在梯度消失的问题，即当输入值较大时，梯度接近于0，导致训练过程变得缓慢。

2. **ReLU函数**：ReLU（Rectified Linear Unit）函数是一种简单的线性激活函数，其表达式为：

\[ f(x) = \max(0, x) \]

ReLU函数在训练过程中表现出良好的性能，可以有效避免梯度消失问题。此外，ReLU函数的计算效率较高，使其在深度学习模型中得到广泛应用。

3. **Tanh函数**：Tanh函数是另一种常用的激活函数，其表达式为：

\[ f(x) = \frac{2}{1 + e^{-2x}} - 1 \]

Tanh函数的输出范围在 -1 到 1 之间，可以看作是 Sigmoid 函数的扩展。与 Sigmoid 函数类似，Tanh 函数在训练过程中也存在梯度消失问题。

4. **Leaky ReLU函数**：Leaky ReLU函数是ReLU函数的改进版本，其表达式为：

\[ f(x) = \max(0.01x, x) \]

Leaky ReLU函数通过引入一个较小的正值斜率（0.01），避免了ReLU函数在输入为负值时梯度为0的问题，从而提高了模型的训练稳定性。

##### 神经网络模型

一个典型的神经网络模型通常包括以下几个层次：

1. **输入层（Input Layer）**：输入层接收外部数据，并将其传递给下一层。

2. **隐藏层（Hidden Layers）**：隐藏层是神经网络的核心部分，通过多层堆叠，实现数据的特征提取和变换。

3. **输出层（Output Layer）**：输出层负责将处理后的数据转化为最终的预测结果或分类标签。

4. **损失函数（Loss Function）**：损失函数用于衡量模型预测结果与真实标签之间的差距。常见的损失函数包括均方误差（MSE）、交叉熵损失（Cross Entropy Loss）和Hinge损失等。

5. **优化算法（Optimization Algorithm）**：优化算法用于调整模型参数，以最小化损失函数。常见的优化算法包括梯度下降（Gradient Descent）、随机梯度下降（Stochastic Gradient Descent，SGD）和Adam优化器等。

#### 2.3 神经网络与激活函数的关系架构

为了更好地理解神经网络与激活函数之间的关系，我们可以通过Mermaid流程图来展示它们的核心架构和互动机制。

```mermaid

B --> C[隐藏层1]
C --> D[激活函数1]
D --> E[隐藏层2]
E --> F[激活函数2]
F --> G[隐藏层3]
G --> H[激活函数3]

```

在上面的流程图中，我们首先将输入数据传递给输入层（B）。然后，数据经过隐藏层1（C）、隐藏层2（E）和隐藏层3（G），并在每个隐藏层之后应用相应的激活函数（D、F、H）。最终，数据通过输出层（I）生成预测结果。在预测结果与真实标签之间，我们使用损失函数（J）来计算误差。接着，优化算法（K）根据损失函数的梯度，调整模型参数（L），并重复迭代优化过程（M），直到达到预设的训练目标（N）。

这个流程图清晰地展示了神经网络中各部分之间的交互关系，为理解神经网络的工作原理提供了直观的图示。

#### 2.4 核心算法原理讲解

为了深入理解神经网络的核心算法原理，我们将通过伪代码详细阐述其主要组成部分，包括前向传播、反向传播和梯度下降等过程。

##### 2.4.1 前向传播

前向传播是神经网络训练过程中的第一步，用于计算输入数据在神经网络中的输出。以下是一个简单的伪代码示例：

```python
# 初始化模型参数
W1, b1 = 初始化权重和偏置
W2, b2 = 初始化权重和偏置

# 前向传播
z1 = X * W1 + b1
a1 = 激活函数(z1) # 例如 Sigmoid 或 ReLU
z2 = a1 * W2 + b2
a2 = 激活函数(z2) # 例如 Sigmoid 或 ReLU
y_pred = a2
```

在上面的伪代码中，`X`代表输入数据，`W1`和`b1`分别是第一层的权重和偏置，`W2`和`b2`分别是第二层的权重和偏置。前向传播过程通过输入层、隐藏层和输出层，逐层计算中间结果和输出结果。

##### 2.4.2 反向传播

反向传播是神经网络训练过程中的第二步，用于计算损失函数关于模型参数的梯度。以下是一个简单的伪代码示例：

```python
# 计算损失函数
loss = 损失函数(y_pred, y_true)

# 计算输出层的梯度
delta2 = (y_pred - y_true) * 激活函数导数(a2)

# 计算隐藏层的梯度
delta1 = (z2 * 激活函数导数(a1)) * W2.T * delta2

# 更新模型参数
W1 += 学习率 * X.T * delta1
b1 += 学习率 * delta1
W2 += 学习率 * a1.T * delta2
b2 += 学习率 * delta2
```

在上面的伪代码中，`y_true`代表真实标签，`y_pred`代表预测结果，`损失函数`用于计算预测结果与真实标签之间的差距。反向传播过程从输出层开始，通过计算梯度，逐层反向传播到输入层，并更新模型参数。

##### 2.4.3 梯度下降

梯度下降是一种常用的优化算法，用于调整模型参数以最小化损失函数。以下是一个简单的伪代码示例：

```python
# 初始化模型参数
W1, b1 = 初始化权重和偏置
W2, b2 = 初始化权重和偏置

# 设置学习率
learning_rate = 0.01

# 迭代过程
for epoch in range(num_epochs):
    # 前向传播
    z1 = X * W1 + b1
    a1 = 激活函数(z1)
    z2 = a1 * W2 + b2
    a2 = 激活函数(z2)
    y_pred = a2
    
    # 计算损失函数
    loss = 损失函数(y_pred, y_true)
    
    # 反向传播
    delta2 = (y_pred - y_true) * 激活函数导数(a2)
    delta1 = (z2 * 激活函数导数(a1)) * W2.T * delta2
    
    # 更新模型参数
    W1 -= learning_rate * X.T * delta1
    b1 -= learning_rate * delta1
    W2 -= learning_rate * a1.T * delta2
    b2 -= learning_rate * delta2

    # 输出当前epoch的损失函数值
    print(f"Epoch {epoch}: Loss = {loss}")
```

在上面的伪代码中，`num_epochs`表示训练迭代的次数，`learning_rate`表示学习率。在每次迭代过程中，模型通过前向传播计算预测结果，通过反向传播计算损失函数的梯度，并利用梯度下降更新模型参数。这个过程不断重复，直到达到预设的训练目标或损失函数值收敛。

通过以上对前向传播、反向传播和梯度下降的详细讲解，我们能够更好地理解神经网络的核心算法原理。这些原理为后续章节的提示词工程实践提供了坚实的理论基础。在下一章中，我们将进一步探讨神经网络在各类AI应用中的具体实现和案例分析。

#### 2.5 数学模型和公式详细讲解

为了更好地理解神经网络的核心算法原理，我们需要深入探讨其背后的数学模型和公式。以下是对神经网络中常用的一些数学模型和公式的详细讲解。

##### 损失函数

损失函数是神经网络训练过程中用于衡量预测结果与真实标签之间差距的关键工具。常用的损失函数包括均方误差（MSE）、交叉熵损失（Cross Entropy Loss）和Hinge损失等。

1. **均方误差（MSE）**

均方误差是最常见的损失函数之一，其公式如下：

\[ \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 \]

其中，\( y_i \) 代表真实标签，\( \hat{y}_i \) 代表预测结果，\( n \) 表示样本数量。

2. **交叉熵损失（Cross Entropy Loss）**

交叉熵损失函数常用于分类问题，其公式如下：

\[ \text{Cross Entropy Loss} = -\frac{1}{n} \sum_{i=1}^{n} y_i \log(\hat{y}_i) \]

其中，\( y_i \) 为真实标签（0或1），\( \hat{y}_i \) 为预测概率。

3. **Hinge损失**

Hinge损失函数常用于支持向量机（SVM）等分类问题，其公式如下：

\[ \text{Hinge Loss} = \max(0, 1 - y_i \cdot \hat{y}_i) \]

其中，\( y_i \) 为真实标签（-1或1），\( \hat{y}_i \) 为预测结果。

##### 激活函数

激活函数是神经网络中的一个关键组件，用于引入非线性特性。以下是几种常用的激活函数及其公式：

1. **Sigmoid函数**

\[ f(x) = \frac{1}{1 + e^{-x}} \]

2. **ReLU函数**

\[ f(x) = \max(0, x) \]

3. **Tanh函数**

\[ f(x) = \frac{2}{1 + e^{-2x}} - 1 \]

4. **Leaky ReLU函数**

\[ f(x) = \max(0.01x, x) \]

##### 梯度下降

梯度下降是一种常用的优化算法，用于调整模型参数以最小化损失函数。其基本思路是计算损失函数关于模型参数的梯度，并沿着梯度的反方向更新参数。

1. **梯度下降公式**

\[ \theta_{\text{new}} = \theta_{\text{old}} - \alpha \cdot \nabla_{\theta} J(\theta) \]

其中，\( \theta \) 表示模型参数，\( \alpha \) 表示学习率，\( \nabla_{\theta} J(\theta) \) 表示损失函数关于模型参数的梯度。

2. **批量梯度下降**

\[ \theta_{\text{new}} = \theta_{\text{old}} - \alpha \cdot \frac{1}{n} \sum_{i=1}^{n} \nabla_{\theta} J(\theta) \]

其中，\( n \) 表示样本数量。

3. **随机梯度下降（SGD）**

\[ \theta_{\text{new}} = \theta_{\text{old}} - \alpha \cdot \nabla_{\theta} J(\theta) \]

其中，\( \theta \) 表示模型参数，\( \alpha \) 表示学习率，\( \nabla_{\theta} J(\theta) \) 表示在单个样本上的损失函数梯度。

4. **动量梯度下降**

\[ \theta_{\text{new}} = \theta_{\text{old}} - \alpha \cdot (\nabla_{\theta} J(\theta) + \beta \cdot \nabla_{\theta} J(\theta)_{\text{prev}}) \]

其中，\( \beta \) 表示动量参数，\( \nabla_{\theta} J(\theta)_{\text{prev}} \) 表示上一次迭代的梯度。

通过以上对神经网络中常用数学模型和公式的详细讲解，我们为理解神经网络的工作原理和训练过程提供了坚实的理论基础。在下一章中，我们将通过实际案例来展示神经网络在各类AI应用中的具体实现和效果。

### 第3章：AI的发展历程

#### 3.1 从符号主义到连接主义

人工智能的发展历程可以分为两个主要阶段：符号主义和连接主义。符号主义（Symbolic AI）起源于20世纪50年代，其核心思想是通过逻辑推理和符号运算来模拟人类智能。这一阶段的代表性工作包括逻辑推理系统、专家系统和知识表示方法。符号主义在理论构建、问题求解和规划领域取得了显著成果，但其在处理复杂任务时，面临计算效率和知识表示的挑战。

随着计算机性能的不断提升，连接主义（Connectionist AI）在20世纪80年代逐渐崛起。连接主义基于神经网络的架构，通过模拟人脑神经元之间的相互连接和交互来处理信息。这一阶段的代表性工作包括人工神经网络、深度学习和机器学习。连接主义在图像识别、语音识别和自然语言处理等领域取得了突破性进展，逐渐成为人工智能的主流方向。

#### 3.2 深度学习的崛起

深度学习（Deep Learning）是连接主义的一个重要分支，通过多层神经网络结构，实现了对复杂数据特征的高效提取和表示。深度学习的崛起可以追溯到20世纪90年代，但随着计算能力和算法优化的提升，它在21世纪取得了飞速发展。

2006年，加拿大科学家杰弗里·辛顿（Geoffrey Hinton）等提出了深度信念网络（Deep Belief Network，DBN），标志着深度学习的重新兴起。随后，2012年，谷歌团队开发的深度卷积神经网络（Deep Convolutional Neural Network，CNN）在ImageNet图像识别比赛中取得了优异成绩，引起了全球的关注。这一事件被视为深度学习发展的里程碑，标志着其在计算机视觉领域的重要突破。

除了图像识别，深度学习在语音识别、自然语言处理等领域也取得了显著成果。通过循环神经网络（Recurrent Neural Network，RNN）和其变种长短期记忆网络（Long Short-Term Memory，LSTM），深度学习能够处理序列数据，实现语音识别、机器翻译和文本生成等功能。近年来，基于注意力机制（Attention Mechanism）和变换器（Transformer）的模型，如BERT（Bidirectional Encoder Representations from Transformers）、GPT（Generative Pre-trained Transformer），在自然语言处理领域取得了重大突破，推动了人工智能技术的进步。

#### 第4章：提示词工程的核心算法原理

#### 4.1 提示词的定义与作用

提示词（Prompt）是提示词工程（Prompt Engineering）的核心概念。它通常是一个简短的文本或短语，用于引导人工智能系统（如聊天机器人、自然语言生成模型）生成更具体、更有针对性的响应。提示词的定义和作用可以从以下几个方面进行阐述：

1. **文本引导**：提示词通过向AI系统提供明确的上下文信息，帮助其更好地理解和生成相关内容。例如，在一个聊天机器人中，用户输入的语句可以被视为提示词，引导机器人生成相应的回复。

2. **优化生成质量**：通过使用适当的提示词，可以提高AI生成文本的质量和相关性。提示词可以引导AI聚焦于特定的主题或任务，从而生成更符合用户需求和期望的内容。

3. **交互式学习**：在对话系统中，提示词还可以作为交互式学习的触发器。通过不断调整和优化提示词，我们可以训练AI系统更好地理解和应对不同用户和场景的需求。

4. **控制生成方向**：提示词可以帮助AI系统避免生成无关或不合适的文本。通过精心设计的提示词，我们可以引导AI生成更具逻辑性和一致性的内容。

#### 4.2 提示词生成算法

提示词生成算法是提示词工程的关键技术，用于自动生成高质量的提示词。以下是一些常见的提示词生成算法：

1. **基于模板的方法**：基于模板的方法通过预先定义的模板，将用户输入与模板进行匹配，生成相应的提示词。这种方法简单直观，但生成结果可能较为固定，缺乏灵活性。

   ```python
   def generate_prompt_template(input_text):
       if "weather" in input_text:
           return "请问您想了解哪里的天气？"
       elif "restaurant" in input_text:
           return "您想吃什么类型的餐厅？"
       else:
           return "请问您需要帮助什么？"
   ```

2. **基于统计的方法**：基于统计的方法通过分析大量对话数据，利用统计模型（如朴素贝叶斯、长短时记忆网络等）生成提示词。这种方法具有较高的灵活性和适应性，但需要对大量数据进行训练。

   ```python
   from sklearn.feature_extraction.text import CountVectorizer
   from sklearn.naive_bayes import MultinomialNB

   def generate_prompt_statistical(input_text, corpus, labels):
       vectorizer = CountVectorizer()
       X_train = vectorizer.fit_transform(corpus)
       clf = MultinomialNB()
       clf.fit(X_train, labels)

       prompt_probabilities = clf.predict_proba(vectorizer.transform([input_text]))
       top_prompt = max(prompt_probabilities[0], key=prompt_probabilities[0].index)
       return top_prompt
   ```

3. **基于神经的方法**：基于神经的方法通过深度学习模型（如循环神经网络、变换器等）生成提示词。这种方法具有强大的建模能力，能够生成更加自然、多样化的提示词。

   ```python
   from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

   def generate_prompt_neural(input_text, model_name="t5-small"):
       tokenizer = AutoTokenizer.from_pretrained(model_name)
       model = AutoModelForSeq2SeqLM.from_pretrained(model_name)

       prompt_input = tokenizer.encode("COPY FROM PROMPT:", return_tensors="pt")
       input_text = tokenizer.encode(input_text, return_tensors="pt")

       output = model(prompt_input, input_text, max_length=50, num_return_sequences=1)
       generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
       return generated_text.strip()
   ```

通过以上方法，我们可以根据具体需求和场景，选择合适的提示词生成算法，从而提高AI系统的交互质量和用户体验。

#### 4.3 提示词优化的策略

提示词优化是提升AI系统性能和用户体验的关键环节。以下是一些常见的提示词优化策略：

1. **相关性优化**：通过分析用户输入和生成文本的相关性，调整提示词以使其更加贴合用户需求。例如，使用TF-IDF（Term Frequency-Inverse Document Frequency）等方法，对提示词进行关键词提取和权重调整。

2. **多样性优化**：通过增加提示词的多样性，提高AI生成文本的丰富性和创新性。可以使用启发式方法（如随机插入、替换、删除等）或基于模型的策略（如生成对抗网络、变换器等）来实现多样性优化。

3. **上下文感知优化**：利用上下文信息，调整提示词以更好地引导AI系统理解和生成相关内容。例如，在对话系统中，可以根据用户的历史提问和回答，动态调整提示词。

4. **用户反馈优化**：通过收集用户对生成文本的反馈，调整提示词以提高用户满意度。可以使用用户评价、点击率、停留时间等指标，对提示词进行优化。

5. **自动优化算法**：利用机器学习算法，通过训练大量数据，自动学习最佳的提示词组合和调整策略。例如，可以使用强化学习、迁移学习等技术，实现自动提示词优化。

通过以上策略，我们可以不断调整和优化提示词，提高AI系统的交互质量和用户体验。在下一章中，我们将通过实际案例，展示如何将提示词工程应用于自然语言处理、计算机视觉等领域，进一步提升AI系统的性能。

提示词生成模块使用预训练模型生成提示词。在本案例中，我们使用T5模型，其默认的输出格式为“`{}`中的内容是提示词”。

```python
def generate_prompt(input_text, model=model, tokenizer=tokenizer, max_length=20):
    inputs = tokenizer.encode("写一个关于{}的提示词：", return_tensors="pt")
    inputs = inputs.append(input_text)
    outputs = model.generate(inputs, max_length=max_length, num_return_sequences=1)
    prompt = tokenizer.decode(outputs[0], skip_special_tokens=True)
    return prompt.strip()
```

```python
import sqlite3

def init_db():

                      (id INTEGER PRIMARY KEY AUTOINCREMENT,
                      input_text TEXT,
                      prompt TEXT)''')
    conn.commit()
    conn.close()

def store_prompt(input_text, prompt):
    conn = sqlite3.connect("prompt_db.sqlite")
    cursor = conn.cursor()
    cursor.execute("INSERT INTO prompts (input_text, prompt) VALUES (?, ?)", (input_text, prompt))
    conn.commit()
    conn.close()

def retrieve_prompts():
    conn = sqlite3.connect("prompt_db.sqlite")
    cursor = conn.cursor()
    cursor.execute("SELECT * FROM prompts")
    rows = cursor.fetchall()
    conn.close()
    return rows
```
