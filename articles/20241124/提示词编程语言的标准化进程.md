##### 源代码实现

以下是一个简单的提示词生成器的源代码实现：

```python
from nltk.tokenize import word_tokenize
from nltk import pos_tag
from sklearn.feature_extraction.text import CountVectorizer

def preprocessText(text):
    # 去除标点符号和停用词
    words = word_tokenize(text)
    words = [word for word in words if word.isalpha()]
    return words

def posTagging(text):
    # 词性标注
    words = pos_tag(text)
    return words

def generatePromptWords(text):
    # 文本预处理
    text = preprocessText(text)
    # 词性标注
    words = pos_tag(text)
    # 提示词生成
    prompts = []
    for word in words:
        if word[1].startswith('VB'):
            prompts.append(word[0])
    return prompts

# 测试
text = "我想打开一个Python文件并运行它。"
prompts = generatePromptWords(text)
print(prompts)
```

2. **词性标注**：词性标注用于识别文本中的动词和名词，这些词更有可能成为有效的提示词。
3. **提示词生成**：根据词性标注结果，选择动词作为提示词，因为动词通常表示具体的操作指令。
