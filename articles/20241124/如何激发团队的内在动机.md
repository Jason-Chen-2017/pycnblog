#### 背景介绍

团队在现代组织中扮演着至关重要的角色。然而，团队协作不仅仅是任务分配和目标达成，更重要的是如何激发团队成员的内在动机。内在动机是指个体参与活动时，出于对活动本身的兴趣、热情和内在价值的驱动，而非仅仅为了外在奖励或避免惩罚。在团队环境中，内在动机能够提高员工的参与度、创造力和满意度，从而促进团队的整体绩效。

### 步骤三：核心概念与联系

在这一部分，我们将介绍内在动机的核心概念，并使用Mermaid流程图来展示这些概念之间的关系。

#### 核心概念

- **内在动机（Intrinsic Motivation）**：个体参与活动时，出于对活动本身的兴趣、热情和内在价值的驱动。
- **外在动机（Extrinsic Motivation）**：个体参与活动时，出于对活动结果的奖励或避免惩罚的驱动。
- **自我决定（Autonomy）**：个体在决策和行动中的自由度和自主性。
- **自我效能（Self-Efficacy）**：个体对自己完成特定任务的信心。
- **心理需求（Psychological Needs）**：包括自主性、能力感、归属感等。

#### 伪代码

```pseudo
function inspireTeamIntrinsicMotivation(teamMembers, goals, autonomy):
    for each member in teamMembers:
        set member's intrinsicMotivation to 0
        if goal is meaningful for member:
            increase member's intrinsicMotivation by 20%
        if autonomy is provided:
            increase member's intrinsicMotivation by 15%
        end if
        if member's self-efficacy is high:
            increase member's intrinsicMotivation by 10%
        end if
        end for
        return average intrinsicMotivation of teamMembers
    end function
```
