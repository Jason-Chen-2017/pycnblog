### 3.1 标识符与关键字

标识符（identifier）是编程语言中用于命名变量、函数、类等元素的名字。关键字（keyword）则是编程语言内部预定义的具有特殊含义的标识符，不能被用作普通标识符。

#### 3.1.1 标识符的规则

设计标识符的规则时，需要考虑到易记性和一致性。以下是一些常见的标识符规则：

- **长度限制**：标识符的长度通常有限制，如大多数编程语言限制标识符长度不超过255个字符。
- **字符集**：标识符通常由字母（包括大小写）、数字和下划线组成，不允许使用特殊字符。
- **大写规则**：标识符通常不区分大小写，例如，`variable`和`Variable`被视为相同。

#### 3.1.2 关键字的定义

关键字是编程语言中具有特殊含义的标识符，用于表示语言的基本结构和控制流程。以下是一些常见的关键字：

- **定义和控制流程**：`IF`、`ELSE`、`WHILE`、`DO`、`SWITCH`、`CASE`、`FOR`等。
- **数据操作**：`SET`、`COPY`、`CONVERT`、`RETURN`、`NEW`等。
- **类型定义**：`INT`、`FLOAT`、`STRING`、`BOOLEAN`等。
- **函数和对象**：`FUNCTION`、`CLASS`、`THIS`、`SUPER`等。

#### 3.1.3 预定义标识符

除了关键字之外，编程语言还预定义了一些特殊的标识符，如系统变量、函数等。这些标识符通常具有固定的用途，不能被重定义。

### 3.2 数据类型与变量

数据类型是编程语言中用于定义变量可以存储的数据种类。变量是存储数据的容器，它具有名称和数据类型。

#### 3.2.1 数据类型

提示词编程语言通常支持以下常见数据类型：

- **基础类型**：`INT`（整数）、`FLOAT`（浮点数）、`STRING`（字符串）、`BOOLEAN`（布尔值）。
- **复合类型**：`ARRAY`（数组）、`MAP`（映射，类似于字典）、`STRUCT`（结构体）。
- **引用类型**：`FUNCTION`（函数）、`CLASS`（类）。

```plaintext

```

- **类型检查**：在编译时，编程语言会检查变量的类型是否与操作相匹配。

### 3.3 表达式与运算符

表达式是编程语言中用于计算值的一组符号和操作符。运算符是用于操作数据的符号。

```plaintext

```

在这个表达式中，`x`和`y`是操作数，`+`和`*`是运算符。

- **位运算符**：`&`（按位与）、`|`（按位或）、`^`（按位异或）、`<<`（左移）、`>>`（右移）。

#### 3.3.3 运算符的优先级和结合性

运算符的优先级决定了表达式中运算的顺序。一般来说，算术运算符的优先级高于比较运算符，比较运算符的优先级高于逻辑运算符。以下是一个运算符优先级的示例：

```plaintext
x + y * z  // 先计算 y * z，然后加上 x
```

运算符的结合性决定了相同优先级的运算符在表达式中从左到右还是从右到左进行计算。大多数运算符具有左结合性，如加法和乘法。但是，逻辑运算符`AND`和`OR`通常具有右结合性。

### 3.4 控制结构

控制结构用于控制程序的执行流程，包括条件语句、循环语句和异常处理等。

#### 3.4.1 条件语句

条件语句用于根据条件的真假来执行不同的代码块。以下是一个简单的条件语句示例：

```plaintext
IF (x > y) {
    PRINT("x is greater than y");
} ELSE {
    PRINT("y is greater than x");
}
```

在这个示例中，如果`x`大于`y`，则执行第一个代码块，否则执行第二个代码块。

#### 3.4.2 循环语句

循环语句用于重复执行一段代码，直到满足特定的条件。常见的循环语句包括`FOR`循环和`WHILE`循环。

- **`FOR`循环**：`FOR`循环通常用于迭代一定次数的代码执行。以下是一个`FOR`循环的示例：

    ```plaintext
    FOR (INT i = 0; i < 10; i++) {
        PRINT(i);
    }
    ```

- **`WHILE`循环**：`WHILE`循环用于当条件为真时重复执行代码块。以下是一个`WHILE`循环的示例：

    ```plaintext
    WHILE (x > 0) {
        PRINT(x);
        x--;
    }
    ```

#### 3.4.3 异常处理

异常处理用于处理程序运行时出现的错误和异常情况。以下是一个简单的异常处理示例：

```plaintext
TRY {
```

在这个示例中，如果`divide`函数出现异常，则执行`CATCH`代码块，并打印错误信息。

### 3.5 嵌套与作用域

嵌套是指在代码中可以定义内部代码块，这些内部代码块可以访问外部代码块中的变量和函数。作用域则决定了变量的可见性和可访问性。

- **局部作用域**：在函数或代码块内部声明的变量只能在该函数或代码块内部访问。
- **全局作用域**：在函数或代码块外部声明的变量可以在整个程序中访问。

以下是一个嵌套和作用域的示例：

```plaintext
INT x = 10;

FUNCTION main() {
    INT y = 20;
    FUNCTION printSum() {
        PRINT(x + y);  // 可以访问外部变量 x 和 y
    }
    printSum();
}
```

在这个示例中，`printSum`函数可以访问外部变量`x`和`y`，因为它们处于局部作用域。

### 3.6 格式与注释

## 第4章 函数与对象

在编程语言中，函数和对象是两个核心概念，它们提供了组织和复用代码的机制。本章将深入探讨函数和对象的概念、定义与实现，以及其在提示词编程语言中的具体应用。

### 4.1 函数的定义与调用

函数（function）是编程语言中的一个基本构造块，用于封装一组相关的操作。在提示词编程语言中，函数定义了如何执行某个任务，并可以接受输入参数，返回输出结果。

#### 4.1.1 函数的基本概念

函数是一种具有名称的代码块，它可以在程序中调用并执行其内部定义的操作。函数的基本特点包括：

- **可重用性**：函数可以重复调用，从而避免了重复编写相同代码的需求。
- **模块化**：通过将代码组织成函数，可以使程序结构更加清晰和易于维护。
- **参数传递**：函数可以通过参数传递数据，使得函数可以处理不同的输入数据。

#### 4.1.2 函数的声明与实现

在提示词编程语言中，函数的声明和实现通常遵循以下格式：

- **声明**：声明一个函数时，需要指定函数的名称、返回类型、参数列表等。以下是一个简单的函数声明示例：

    ```plaintext
    FUNCTION add(INT a, INT b) RETURNS INT {
        // 函数实现
        RETURN a + b;
    }
    ```

- **实现**：函数实现是函数体内部的具体代码，它定义了函数的行为。在上面的示例中，函数`add`接受两个整数参数`a`和`b`，并返回它们的和。

#### 4.1.3 函数的调用与参数传递

调用函数时，需要按照函数的参数列表提供相应的参数值。以下是一个调用函数`add`的示例：

```plaintext
INT result = add(3, 4);  // 调用 add 函数，传递参数 3 和 4
PRINT(result);  // 打印函数返回的结果 7
```

在函数调用中，参数可以通过值传递（按值传递）或引用传递（按引用传递）：

- **值传递**：在值传递中，函数接收的是参数值的副本，函数内部对参数的修改不会影响外部变量。以下是一个值传递的示例：

    ```plaintext
    FUNCTION modifyValue(INT value) {
        value = value * 2;  // 修改函数内的参数值
    }

    INT originalValue = 5;
    modifyValue(originalValue);  // 调用 modifyValue 函数
    PRINT(originalValue);  // 打印 originalValue，仍然是 5
    ```

- **引用传递**：在引用传递中，函数接收的是参数的实际地址，函数内部对参数的修改会直接影响外部变量。以下是一个引用传递的示例：

    ```plaintext
    FUNCTION modifyReference(INT* value) {
        *value = *value * 2;  // 修改函数内的参数值
    }

    INT originalValue = 5;
    modifyReference(&originalValue);  // 调用 modifyReference 函数
    PRINT(originalValue);  // 打印 originalValue，现在是 10
    ```

### 4.2 对象与类

对象（object）是函数和数据的封装体，它根据类的定义创建。类（class）是定义对象属性和行为的数据类型。在提示词编程语言中，类提供了定义对象的蓝图。

#### 4.2.1 对象的基本概念

对象是类的实例，它封装了数据（属性）和行为（方法）。每个对象都有其唯一的内存地址，可以通过属性访问其数据，通过方法调用其行为。以下是一个简单的对象示例：

```plaintext
CLASS Person {
    STRING name;
    INT age;

    FUNCTION greet() {
        PRINT("Hello, my name is " + name + " and I am " + age + " years old.");
    }
}

PERSON person = NEW Person;  // 创建一个 Person 类的实例
person.name = "John Doe";  // 设置 person 的 name 属性
person.age = 30;  // 设置 person 的 age 属性
person.greet();  // 调用 person 的 greet 方法
```

在这个示例中，`Person`类定义了两个属性（`name`和`age`）和一个方法（`greet`），通过创建`Person`类的实例并设置属性，可以访问和操作对象的属性和方法。

#### 4.2.2 类的定义与创建

在提示词编程语言中，类的定义通常遵循以下格式：

- **定义**：类定义使用`CLASS`关键字，后面跟随类的名称和属性、方法的声明。以下是一个简单的类定义示例：

    ```plaintext

        INT age;
    }
    ```

- **创建**：创建类的实例时，使用`NEW`关键字和类名称。以下是一个创建`Person`类实例的示例：

    ```plaintext
    PERSON person = NEW Person;
    ```

#### 4.2.3 继承与多态

继承和多态是面向对象编程的两个重要特性，它们提供了代码复用和灵活性。

- **继承**：继承允许一个类继承另一个类的属性和方法。子类继承了父类的所有非私有属性和方法，并可以添加自己的属性和方法。以下是一个继承的示例：

    ```plaintext
    CLASS Student extends Person {
        STRING school;
    }

    STUDENT student = NEW Student;
    student.name = "Alice Smith";
    student.age = 20;
    student.school = "MIT";
    student.greet();  // 调用 Student 类的 greet 方法
    ```

- **多态**：多态允许使用同一个接口调用不同类的实现。通过继承和接口，可以定义一个通用接口，然后让不同的类实现该接口。以下是一个多态的示例：

    ```plaintext
    INTERFACE Animal {
        FUNCTION makeSound();
    }

    CLASS Dog implements Animal {
        FUNCTION makeSound() {
            PRINT("Woof!");
        }
    }

    CLASS Cat implements Animal {
        FUNCTION makeSound() {
            PRINT("Meow!");
        }
    }

    ANIMAL animal = NEW Dog;
    animal.makeSound();  // 调用 Dog 类的 makeSound 方法，输出 "Woof!"

    animal = NEW Cat;
    animal.makeSound();  // 调用 Cat 类的 makeSound 方法，输出 "Meow!"
    ```

### 4.3 函数与对象的比较

函数和对象是编程中的两个重要概念，它们各有特点和用途。

```plaintext
        RETURN a * b;
    }

    FLOAT divide(FLOAT a, FLOAT b) RETURNS FLOAT {
        IF (b == 0) {

        RETURN a / b;
```

在这个实例中，`Calculator`类封装了四个基本的算术操作函数（`add`、`subtract`、`multiply`和`divide`）。通过创建`Calculator`类的实例，可以调用这些函数进行计算，并处理可能出现的异常。

### 6.1 异常处理机制

异常处理是编程语言中的一个重要特性，它用于处理程序运行时出现的错误和异常情况。异常处理机制通常包括以下几个核心组成部分：

#### 6.1.1 异常的基本概念

异常（exception）是一种在程序运行过程中发生的、意外的、非预期的错误。异常可以由编程错误、逻辑错误、资源不足或其他问题引起。常见的异常类型包括：

- **运行时异常**：在程序运行过程中出现的错误，如数组越界、空指针引用等。
- **语法错误**：在编写代码时出现的语法错误，如拼写错误、缺少括号等。
- **编译时异常**：在编译代码时出现的错误，如类型不匹配、方法未定义等。

#### 6.1.2 异常的处理方式

异常处理通常通过`TRY`、`CATCH`和`FINALLY`块来实现。以下是一个简单的异常处理示例：

```plaintext
TRY {
    // 可能出现异常的代码
    INT result = divide(10, 0);
    PRINT("Result: " + result);
} CATCH (ERROR e) {
    PRINT("Error: " + e.getMessage());
} FINALLY {
    // 无论是否出现异常，都会执行的代码
}
```

- **`TRY`块**：用于包含可能出现异常的代码。
- **`CATCH`块**：用于处理捕获到的异常。在`CATCH`块中，可以指定如何处理异常，如打印错误信息、记录日志等。
- **`FINALLY`块**：用于包含无论是否出现异常都会执行的代码。`FINALLY`块通常用于释放资源、清理代码等。

#### 6.1.3 异常传播

当异常在一个代码块中未得到处理时，它会沿着调用栈向上传播，直到找到一个能够处理的`CATCH`块。如果调用栈中没有找到能够处理的异常，程序通常会退出并抛出未处理的异常。
