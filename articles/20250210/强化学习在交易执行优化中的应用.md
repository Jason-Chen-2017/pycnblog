## 第2章 强化学习的核心概念与原理

### 2.1 强化学习的基本原理

#### 2.1.1 贝尔曼方程
贝尔曼方程是强化学习的基础，表示状态价值函数的递归关系：
$$ V(s) = \max_{a} [ r(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s') ] $$

#### 2.1.2 Q值的更新公式
Q-learning算法通过更新Q值来学习最优策略：
$$ Q(s,a) \leftarrow Q(s,a) + \alpha [ r + \gamma \max Q(s',a') - Q(s,a) ] $$

#### 2.1.3 探索与利用策略
平衡探索新状态和利用已知最佳策略，常用ε-greedy策略：
$$ \text{选择动作概率} = \begin{cases} \epsilon & \text{随机动作} \\ 1-\epsilon & \text{最佳动作} \end{cases} $$

### 2.2 马尔可夫决策过程（MDP）

#### 2.2.1 MDP的组成部分
- 状态空间（State Space）
- 动作空间（Action Space）
- 奖励函数（Reward Function）
- 转移概率（Transition Probability）

#### 2.2.2 MDP的结构
使用Mermaid图表示MDP的交互过程：
```mermaid

    S --> R
    R --> A
    A --> S'
```

### 2.3 强化学习的核心算法

#### 2.3.1 Q-learning算法
- 通过Q表存储状态-动作对的期望奖励
- 使用Q-learning更新规则：
  $$ Q(s,a) = Q(s,a) + \alpha (r + \gamma \max Q(s',a') - Q(s,a)) $$

#### 2.3.2 Deep Q-Networks（DQN）
- 使用深度神经网络近似Q值函数
- 包括经验回放和目标网络

#### 2.3.3 策略梯度方法
- 直接优化策略，如策略梯度算法：
  $$ \nabla \theta \leftarrow \frac{1}{n} \sum \nabla \log \pi_\theta(a|s) Q(s,a) $$

#### 6.2.1 DQN算法实现
```python
import numpy as np
import tensorflow as tf

class DQN:
    def __init__(self, state_dim, action_dim):
        self.state_dim = state_dim
        self.action_dim = action_dim
        self.memory = []
        self.gamma = 0.99
        self.epsilon = 0.1
        self.model = self.build_model()

    def build_model(self):
        model = tf.keras.Sequential([
            tf.keras.layers.Dense(64, activation='relu', input_dim=self.state_dim),
            tf.keras.layers.Dense(self.action_dim)
        ])
        model.compile(optimizer='adam', loss='mean_squared_error')
        return model

    def remember(self, state, action, reward, next_state):
        self.memory.append((state, action, reward, next_state))

    def act(self, state):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.action_dim)
        q_values = self.model.predict(state.reshape(1, -1))[0]
        return np.argmax(q_values)

    def replay(self, batch_size):
        if len(self.memory) < batch_size:
            return
        mini_batch = np.random.choice(self.memory, batch_size)
        states = np.array([m[0] for m in mini_batch])
        actions = np.array([m[1] for m in mini_batch])
        rewards = np.array([m[2] for m in mini_batch])
        next_states = np.array([m[3] for m in mini_batch])
        targets = self.model.predict(states)
        next_q = self.model.predict(next_states)
        targets[range(batch_size), actions] = rewards + self.gamma * np.max(next_q, axis=1)
        self.model.fit(states, targets, epochs=1, verbose=0)
```

```python
import gym
from gym import spaces

class TradingEnv(gym.Env):
    def __init__(self, price_data):
        self.prices = price_data
        self.episode = 0
        self.current_step = 0
        self.observation_space = spaces.Box(low=0, high=1, shape=(1,))
        self.action_space = spaces.Discrete(3)  # 0: sell, 1: hold, 2: buy

    def _get_state(self):
        return self.prices[self.current_step]

    def _get_reward(self, action, price, next_price):
        if action == 0:  # sell
            return (price - next_price) * 100
        elif action == 2:  # buy
            return (next_price - price) * 100
        else:
            return 0

    def step(self, action):
        state = self._get_state()
        next_state = self.prices[self.current_step + 1]
        reward = self._get_reward(action, state, next_state)
        self.current_step += 1
        return next_state, reward, self.current_step >= len(self.prices) - 1, {}

    def reset(self):
        self.episode += 1
        self.current_step = 0
        return self._get_state()

    def render(self):
        pass
```

```python
    total_reward = 0

        action = agent.act(state)
        next_state, reward, done, _ = env.step(action)

        total_reward += reward
        state = next_state
        if done:
            break
```
