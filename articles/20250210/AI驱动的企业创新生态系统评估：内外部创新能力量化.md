#### 1.2.3 内外部创新能力的关系

### 5.2 基于AI的创新能力评估算法实现

#### 5.2.1 算法的数学模型
$$
\text{创新能力指数} = \sum_{i=1}^{n} w_i \times x_i
$$
其中，\( w_i \) 是权重，\( x_i \) 是输入特征。

#### 5.2.2 算法的Python代码实现

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 示例数据
X = np.array([[1, 2], [3, 4], [5, 6]])
y = np.array([7, 8, 9])

# 训练模型
model = LinearRegression()
model.fit(X, y)

# 预测结果
predicted = model.predict(X)
print(predicted)
```

```python
import numpy as np
from sklearn.linear_model import LinearRegression

def calculate_innovation_index(internal, external):
    X = np.array([internal, external]).reshape(-1, 2)
    y = np.array([10, 20, 30])  # 示例数据
    model = LinearRegression()
    model.fit(X, y)
    predicted = model.predict([[internal, external]])
    return predicted[0]

# 示例调用
print(calculate_innovation_index(5, 10))
```
