#### 2.1 全球股市估值与小型模块化核反应堆安全技术的核心原理
- 全球股市估值的数学模型
  - 常见模型：CAPM（资本资产定价模型）、股利贴现模型（DDM）。
  - 例如：CAPM公式为：
    $$ E(R_i) = R_f + \beta_i (E(R_m) - R_f) $$
    其中，\( E(R_i) \) 是股票的预期收益率，\( R_f \) 是无风险利率，\( \beta_i \) 是股票的贝塔系数，\( E(R_m) \) 是市场预期收益率。
- 小型模块化核反应堆安全技术的核心原理
  - 概率论与风险评估：使用贝叶斯网络评估核泄漏概率。
  - 例如：贝叶斯公式：
    $$ P(A|B) = \frac{P(B|A)P(A)}{P(B)} $$
    其中，\( P(A|B) \) 是在B发生的条件下，A发生的概率。

#### 3.1 全球股市估值算法

##### 3.1.1 传统估值方法
- 市盈率法：\( PE = \frac{股价}{每股收益} \)
- 市净率法：\( PB = \frac{股价}{每股净资产} \)

##### 3.1.2 现代机器学习方法
- 随机森林回归模型：通过训练历史数据预测未来股价。
- LSTM网络：捕捉时间序列中的复杂模式。

y = data['target_price']

# 模型训练

import numpy as np

def simulate_reliability(n_simulations=1000):
    successes = 0
    for _ in range(n_simulations):
        # 模拟一次系统运行
        if np.random.rand() < 0.999:
            successes += 1
    return successes / n_simulations

reliability = simulate_reliability()
print(f"系统可靠性：{reliability}")
