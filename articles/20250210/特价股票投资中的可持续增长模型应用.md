#### 2.1 可持续增长模型的核心概念
- **2.1.1 可持续增长模型的核心要素**

- **2.1.2 可持续增长模型的数学表达式**
  $$ g = \frac{ROE \times (1 - \frac{D}{E})}{1 - ROE \times (1 - \frac{D}{E})} $$

- **2.1.3 可持续增长模型的假设条件**
  - 企业保持稳定的再投资率
  - 资本成本不变

## 第三部分：可持续增长模型的算法原理

### 第3章：算法原理

#### 3.1 可持续增长模型的算法流程
- **3.1.1 数据输入与预处理**
  - 收集企业的财务数据（ROE、D/E）
  - 数据清洗与标准化

- **3.1.2 模型参数计算**
  - 计算增长率（g）
  - 确定股票的内在价值

- **3.1.3 投资价值评估**
  - 比较市场价格与内在价值
  - 确定是否低估

- **3.1.4 投资决策输出**
  - 生成投资建议

#### 3.2 可持续增长模型的数学模型与公式
- **3.2.1 可持续增长模型的基本公式**
  $$ g = \frac{ROE \times (1 - \frac{D}{E})}{1 - ROE \times (1 - \frac{D}{E})} $$

- **3.2.2 计算示例**
  假设ROE=15%，D/E=0.5，则：
  $$ g = \frac{0.15 \times (1 - 0.5)}{1 - 0.15 \times (1 - 0.5)} = \frac{0.075}{1 - 0.075} = 8.16\% $$

#### 3.3 算法实现
- **3.3.1 Python代码实现**
  ```python
  def sustainable_growth_rate(ROE, D_E):
      numerator = ROE * (1 - D_E)
      denominator = 1 - ROE * (1 - D_E)
      return numerator / denominator

  # 示例计算
  ROE = 0.15
  D_E = 0.5
  g = sustainable_growth_rate(ROE, D_E)
  print(f"可持续增长率: {g:.2%}")
  ```

  import pandas as pd

  def calculate_sustainable_growth(roes, d_es):
      growth_rates = []
      for roe, d_e in zip(roes, d_es):
          numerator = roe * (1 - d_e)
          denominator = 1 - roe * (1 - d_e)
          growth_rates.append(numerator / denominator)
      return pd.Series(growth_rates)

  growth_rates = calculate_sustainable_growth(roes, d_es)
