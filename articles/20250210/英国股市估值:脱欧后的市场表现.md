# 第1章: 脱欧对英国股市的影响概述

## 1.1 脱欧的背景与英国股市的关系

### 1.1.1 脱欧的定义与历史背景
英国脱欧是指英国脱离欧盟的过程，正式名称为“英国退出欧盟”。2016年6月23日，英国通过公投决定脱欧，2017年3月，英国正式通知欧盟其脱欧决定，2020年1月31日正式退出欧盟。这一事件对英国的经济、政治和社会产生了深远影响，其中股市是受影响最大的领域之一。

### 1.1.2 英国股市的历史表现
英国股市的主要指数是富时100指数（FTSE 100），该指数涵盖英国最大的100家上市公司。自1984年创建以来，富时100指数经历了多次波动，但整体呈上升趋势。2016年脱欧公投前，英国股市表现稳定，富时100指数在2016年初约为6,800点。

### 1.1.3 脱欧对英国经济的影响
脱欧对英国经济的影响是多方面的。短期来看，英镑贬值导致进口成本上升，但出口竞争力增强；长期来看，英国可能面临外资撤离、企业投资下降等问题。这些因素直接影响了英国股市的表现。

# 第2章: 英国股市估值的核心概念与方法

## 2.1 股市估值的基本原理

### 2.1.1 股票估值的定义与意义
股票估值是通过对公司财务数据和市场因素的分析，确定股票的内在价值。准确的估值可以帮助投资者做出更明智的投资决策。

### 2.1.2 股票估值的主要方法
股票估值的主要方法包括相对估值法和绝对估值法。相对估值法基于市场数据，如市盈率（PE）、市净率（PB）等；绝对估值法基于现金流折现模型（DCF）。

### 2.1.3 脱欧对估值方法的影响
脱欧导致市场不确定性增加，传统的估值方法可能不再适用。投资者需要根据脱欧后的市场环境调整估值策略。

---

## 2.2 常用的股票估值指标

### 2.2.1 市盈率（PE）的计算与应用
市盈率=股票价格/每股收益。脱欧后，英国股市的市盈率普遍下降，表明市场估值较低。

### 2.2.2 市净率（PB）的计算与应用
市净率=股票价格/每股净资产。市净率可以帮助投资者评估股票的估值是否合理。

### 2.2.3 市盈率与市净率的对比分析
市盈率适用于盈利稳定的公司，而市净率适用于净资产较多的公司。脱欧后，市盈率和市净率的变化可以帮助投资者判断市场的估值趋势。

# 第3章: 英国股市估值的数学模型与公式

## 3.1 常用股票估值模型

### 3.1.1 市盈率模型
$$\text{市盈率} = \frac{\text{股票价格}}{\text{每股收益}}$$

### 3.1.2 市净率模型
$$\text{市净率} = \frac{\text{股票价格}}{\text{每股净资产}}$$

### 3.1.3 现金流折现模型（DCF）
DCF模型通过预测公司的未来现金流，折现到现值来确定股票的内在价值。

---

## 3.2 脱欧对估值模型的影响

### 3.2.2 脱欧对市盈率模型的影响
脱欧可能导致市盈率的波动，投资者需要根据市场变化调整市盈率的预期值。

### 3.2.3 脱欧对市净率模型的影响
脱欧可能导致净资产的变化，影响市净率的计算和应用。

## 3.3 脱欧后的英国股市估值公式

$$\text{脱欧后市盈率} = \frac{\text{脱欧后股票价格}}{\text{脱欧后每股收益}}$$

### 3.3.2 脱欧后的市净率计算公式
