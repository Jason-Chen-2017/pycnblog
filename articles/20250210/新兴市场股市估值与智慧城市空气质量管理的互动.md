# 第二部分: 核心概念与联系

## 第2章: 核心概念原理

### 2.1 股市估值的核心原理
#### 2.1.1 股市估值的基本方法
- 市盈率（P/E）：股价与每股收益的比率。
- 市净率（P/B）：股价与每股净资产的比率。

#### 2.1.2 影响股市估值的主要因素
- 经济指标：GDP增长率、利率。
- 公司业绩：利润、营收增长。
- 市场情绪：投资者信心、市场流动性。

#### 2.1.3 新兴市场的特殊性
- 波动性高：受政策和外部因素影响大。
- 结构不完善：市场机制和监管可能存在缺陷。

### 2.2 智慧城市空气质量管理的核心原理
#### 2.2.1 空气质量管理的定义
通过监测和管理，确保空气质量达标，保护居民健康。

#### 2.2.2 智慧城市中空气质量管理的关键技术
- IoT传感器：实时监测空气质量。
- 数据分析：预测污染趋势，优化管理策略。

#### 2.2.3 空气质量对经济活动的影响
- 健康影响：降低劳动效率，增加医疗支出。
- 经济影响：影响企业生产成本和城市形象。

### 3.3 Python核心代码实现
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载
data = pd.read_csv('emerging_market_data.csv')

# 特征选择
features = ['PM2.5', 'GDP']
target = 'Stock_Index'

# 模型训练
model = LinearRegression()
model.fit(data[features], data[target])

# 预测与评估
predictions = model.predict(data[features])
print("R² Score:", r2_score(data[target], predictions))
```
