### 第1章：宏观经济趋势的基本概念

#### 1.1 宏观经济趋势的定义与特征

- **1.1.1 宏观经济的定义**
  宏观经济研究整体经济系统，包括GDP、通货膨胀、利率等宏观变量。

- **1.1.2 宏观经济趋势的特征**
  - 广泛性：影响整个经济体系。
  - 长期性：趋势持续时间较长。
  - 可预测性：通过模型和数据分析预测。

- **1.1.3 宏观经济与投资的关系**
  宏观经济状况直接影响市场表现，投资者需关注主要指标以优化资产配置。

#### 1.2 宏观经济指标与分析工具

- **主要宏观经济指标**
  - GDP：衡量经济总量。
  - 通货膨胀率：影响购买力。
  - 利率：影响借贷成本和资产价格。

- **宏观经济分析工具**
  - 时间序列分析：识别趋势和周期。
  - 经济计量模型：预测经济变量。

#### 1.3 宏观经济趋势对投资的影响

- **影响机制**
  - 利率上升：债券价格上涨，股票可能下跌。
  - 通货膨胀：实际收益下降，但通胀保值资产受益。

- **不同经济周期的投资策略**
  - 经济衰退：增加防御性资产，如债券。
  - 经济复苏：增加股票配置。

- **投资组合优化代码**
  ```python
  import numpy as np
  from scipy.optimize import minimize

  def portfolio_optimization(returns, weights):
      # 计算投资组合的收益和风险
      portfolio_return = np.dot(returns.mean(), weights)
      portfolio_risk = np.sqrt(np.dot(weights.T, np.dot(returns.cov(), weights)))

      return -portfolio_risk

  # 使用遗传算法优化权重
  def objective(weights, returns):
      return portfolio_optimization(returns, weights)

  # 约束条件：权重之和为1
  constraints = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1})

  # 初始猜测
  n_assets = returns.shape[1]
  initial_guess = np.ones(n_assets) / n_assets

  # 使用SLSQP求解器
  result = minimize(objective, initial_guess, args=(returns,), constraints=constraints)
  optimal_weights = result.x
  ```
