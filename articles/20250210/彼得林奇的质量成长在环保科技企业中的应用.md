## 第5章: 质量成长策略的数学模型  

### 5.1 质量成长评分模型  
- **模型定义**：通过对企业质量、成长潜力和技术能力等多个维度进行评分，综合计算得出企业的质量成长评分。  
- **公式**：$$ \text{质量成长评分} = \sum (\text{指标} \times \text{权重}) $$  
  其中，指标包括收入增长率（权重30%）、净利润增长率（权重20%）、研发投入占比（权重20%）、资产负债率（权重15%）、管理团队能力（权重15%）。  

### 5.2 案例分析  
- **案例**：某环保科技企业的质量成长评分计算。  
  - 收入增长率：25%（权重30%） → 25% × 30% = 7.5  
  - 净利润增长率：20%（权重20%） → 20% × 20% = 4  
  - 研发投入占比：10%（权重20%） → 10% × 20% = 2  
  - 资产负债率：50%（权重15%） → 50% × 15% = 7.5  
  - 管理团队能力：80%（权重15%） → 80% × 15% = 12  
  - 总分：7.5 + 4 + 2 + 7.5 + 12 = 33

### 7.2 核心代码实现  
```python
import pandas as pd
import matplotlib.pyplot as plt

# 示例数据
data = {
    '企业': ['A', 'B', 'C'],
    '收入增长率': [25, 20, 15],
    '净利润增长率': [20, 15, 10],
    '研发投入占比': [10, 8, 6],
    '资产负债率': [50, 40, 30],
    '管理团队能力': [80, 70, 60]
}

df = pd.DataFrame(data)

# 计算质量成长评分
def calculate_score(row):
    weights = [0.3, 0.2, 0.2, 0.15, 0.15]
    scores = []
    for i in range(len(row)):
        scores.append(row[i] * weights[i])
    return sum(scores)

df['质量成长评分'] = df.apply(lambda row: calculate_score(row), axis=1)

print(df)
```
