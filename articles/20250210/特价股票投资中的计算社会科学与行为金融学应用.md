## 第一部分：背景与基础

### 第1章：特价股票投资概述

#### 1.1 特价股票投资的定义与特点
- 特价股票：市场价格远低于其内在价值的股票，常见于市场忽视或低估的企业。
- 特价股票投资：通过分析挖掘这些被低估的股票，寻找潜在收益。

#### 1.2 行为金融学与计算社会科学
- 行为金融学：研究心理因素对投资者决策的影响，挑战传统有效市场假说。
- 计算社会科学：利用大数据和计算方法分析社会现象，应用于金融市场研究。

#### 1.3 结合行为金融学的特价股票投资
- 识别市场情绪波动，捕捉投资机会。
- 分析投资者行为偏差，避免决策错误。

## 第二部分：行为金融学的核心理论

### 第2章：基础行为理论

#### 2.1 心理账户理论
- 心理账户：投资者将资金分为不同账户，影响决策。
- 实例：投资者可能将股票投资与存款分开处理，影响风险偏好。

#### 2.2 过度自信效应
- 投资者倾向于过度自信，高估自己分析能力。
- 影响：可能导致过度交易和错误决策。

#### 2.3 损失厌恶理论
- 损失厌恶：人们对损失的敏感度高于收益。
- 影响：投资者可能因害怕亏损而错失投资机会。

### 第3章：Prospect理论

#### 3.1 基本概念
- Prospect理论：描述决策者如何评估风险和收益。
- 曲线分析：收益和损失的概率权重函数。

#### 3.2 应用实例
- 投资者在面对收益和损失时的决策差异。
- 通过Prospect理论预测投资者行为。

import pandas as pd

def analyze_sentiment(text):
    blob = TextBlob(text)
    return blob.sentiment.polarity

data = pd.read_csv('stock_reviews.csv')
data['sentiment'] = data['review'].apply(analyze_sentiment)
