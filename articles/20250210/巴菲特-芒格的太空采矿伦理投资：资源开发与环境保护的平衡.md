# 第3章：伦理投资的核心要素

## 3.1 伦理投资的定义与特征

### 3.1.1 伦理投资的定义
伦理投资是一种注重社会责任和环境保护的投资策略，强调在追求经济效益的同时，兼顾社会和环境的可持续发展。

### 3.1.2 伦理投资与传统投资的区别
传统投资主要关注财务回报，而伦理投资还需考虑企业的社会责任和环境影响。两者在决策标准上有显著差异。

### 3.1.3 伦理投资的三大支柱
伦理投资的三大支柱包括经济可行性、社会责任和环境影响。这三者共同决定了投资的伦理性和可持续性。

## 3.2 伦理投资的框架体系

### 3.2.1 经济可行性分析
经济可行性分析包括成本预测、收益评估和投资回报率计算。确保投资在经济上是可行的，是伦理投资的基础。

### 3.2.2 社会责任评估
社会责任评估包括企业对员工、社区和环境的贡献。评估企业是否符合社会道德标准，是伦理投资的重要组成部分。

### 3.2.3 环境影响评价
环境影响评价分析投资对环境的影响，确保开发活动不会破坏生态平衡。这是伦理投资的核心要素之一。
