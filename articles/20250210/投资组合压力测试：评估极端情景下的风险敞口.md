### 第1章: 投资组合压力测试的背景与重要性

#### 1.1 压力测试的基本概念
压力测试是一种评估投资组合在极端市场条件下的表现和风险的方法。它帮助投资者和机构识别潜在风险，制定应对策略。

## 第二部分: 投资组合压力测试的数学模型与算法

### 第3章: 风险度量的数学模型

#### 3.1 VaR的计算公式
$$ VaR = \mu + z \times \sigma $$
其中，$\mu$ 是平均值，$z$ 是标准正态分布的分位数，$\sigma$ 是标准差。

#### 3.2 CVaR的计算公式
$$ CVaR = \frac{1}{\alpha} \int_{-\infty}^{VaR} (x - VaR) f(x) dx $$
其中，$\alpha$ 是置信水平，$f(x)$ 是概率密度函数。

#### 3.3 VaR与CVaR的对比
- VaR仅提供在某一置信水平下的潜在损失，而CVaR考虑了超过VaR的平均损失。

```python
import numpy as np

def calculate_VaR(data, confidence_level=0.95):
    sorted_data = np.sort(data)
    VaR = np.quantile(sorted_data, confidence_level)
    return VaR

def calculate_CVaR(data, confidence_level=0.95):
    VaR = calculate_VaR(data, confidence_level)
    mask = data <= VaR
    CVaR = np.mean(data[mask] - VaR)
    return CVaR

# 示例数据
data = np.random.normal(0, 1, 1000)
VaR = calculate_VaR(data)
CVaR = calculate_CVaR(data)
print(f"VaR: {VaR}, CVaR: {CVaR}")
```

import numpy as np

def stress_test(portfolio, scenarios):
    results = []
    for scenario in scenarios:
        returns = portfolio.dot(scenario)
        VaR = np.quantile(returns, 0.95)
        CVaR = np.mean(returns[returns <= VaR] - VaR)
        results.append({'VaR': VaR, 'CVaR': CVaR})
    return results

# 示例投资组合和情景
portfolio = np.array([0.3, 0.2, 0.5])
scenarios = np.array([
    [1.0, -0.2, 0.1],
    [-0.5, 0.4, 0.3],
    [0.2, -0.1, 0.6]
])

results = stress_test(portfolio, scenarios)
print(results)
