## 第二部分：核心概念与分析方法

### 第2章：定性分析的核心要素

#### 2.1 企业的竞争优势分析
- **核心竞争力**：企业是否有独特的竞争优势，如技术壁垒、品牌影响力等。
- **管理层分析**：管理层的诚信、能力和战略眼光对企业价值的影响。

#### 2.2 商业模式分析
- **收入来源**：企业的主要收入来源及其稳定性。
- **成本结构**：企业的成本构成及其对利润的影响。

### 第3章：定量分析的关键指标

#### 3.1 财务指标分析
- **盈利能力**：净利润率、ROE（净资产收益率）等指标。
- **成长能力**：收入和利润的增速。
- **财务健康性**：资产负债率、流动比率等。

#### 3.2 市场估值分析
- **市盈率（P/E）**：股价与每股收益的比率。
- **市净率（P/B）**：股价与每股净资产的比率。
- **股息率**：股息与股价的比率。

### 第4章：双轨分析的理论基础

#### 4.1 价值投资的核心理念
- **内在价值**：企业未来现金流的现值。
- **安全边际**：买入价格低于内在价值，以确保安全空间。

#### 4.2 技术分析与基本面分析的结合
- **技术分析**：通过价格和成交量的图表分析，预测短期价格走势。
- **基本面分析**：通过企业的财务报表分析，评估企业的内在价值。
- **结合方法**：双轨分析将技术分析作为辅助工具，基本面分析作为主要依据。

import pandas as pd
import numpy as np

# 定量分析部分
def calculate_pe_ratio(stock_data):
    pe_ratio = stock_data['股价'] / stock_data['每股收益']
    return pe_ratio

# 定性分析部分
def calculate_competitive_advantage(stock_data):
    advantage_score = 0
    if stock_data['净利润增长率'].mean() > 10:
        advantage_score += 1
    if stock_data['ROE'].mean() > 15:
        advantage_score += 1
    return advantage_score

# 双轨分析综合评分
def dual_track_analysis(stock_data):
    pe_ratio = calculate_pe_ratio(stock_data)
    advantage_score = calculate_competitive_advantage(stock_data)
    total_score = (pe_ratio.mean() + advantage_score) / 2
    return total_score
