## 第1章：全球供应链重构的背景

### 1.1 供应链重构的驱动因素

#### 1.1.1 全球化与地缘政治的影响  
全球化进程的放缓和地缘政治冲突（如中美贸易摩擦）对全球供应链产生了深远影响，企业开始寻求更加灵活和多元化的供应链布局。

#### 1.1.2 技术进步与产业变革  
技术进步（如自动化生产和智能制造）推动了供应链的优化，但也带来了新的挑战，如技术依赖和数据安全问题。

#### 1.1.3 疫情对供应链的冲击  
新冠疫情暴露了全球供应链的脆弱性，许多企业因供应链中断而面临生产停滞的风险。

### 1.2 供应链重构的核心问题

#### 1.2.1 供应链断裂的风险  
供应链中断可能导致企业生产停滞、库存积压或原材料短缺，从而影响企业的经营稳定性。

#### 1.2.2 企业运营的不确定性  
供应链重构使得企业的运营环境更加复杂，企业需要具备更强的应变能力和风险管理能力。

#### 1.2.3 全球化与本地化的平衡  
企业需要在全球化与本地化之间找到平衡，以应对供应链重构带来的挑战。

## 第3章：特价股票的定义与特点

### 3.1 特价股票的定义

#### 3.1.1 特价股票的定义  
特价股票是指价格相对较低的股票，通常具有较高的波动性和潜在的高回报率。

#### 3.1.2 特价股票的分类  
特价股票可以分为周期性股票、成长型股票和价值型股票等。

### 3.2 特价股票的特点

#### 3.2.1 价格波动性  
特价股票的价格波动较大，具有较高的风险和潜在回报。

#### 3.2.2 市场流动性  
特价股票的市场流动性较低，可能影响其交易的便捷性。

#### 3.2.3 投资风险  
特价股票的投资风险较高，需要投资者具备较强的风险承受能力。

import numpy as np

def process_data(data):
    data['SMA_20'] = data['Close'].rolling(20).mean()
    data['SMA_50'] = data['Close'].rolling(50).mean()
    data['RSI'] = (100 * (data['Close'] - data['Close'].shift(1)).apply(lambda x: (x.rolling(14).mean() / (data['Close'].std()) + 1))) 
    return data
