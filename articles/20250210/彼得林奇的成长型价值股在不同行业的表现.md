## 第1章：彼得·林奇与成长型价值股概述

### 1.1 彼得·林奇及其投资理念  
彼得·林奇是美国著名的投资家和基金经理，以其独特的成长型价值股投资策略闻名。他的投资理念强调长期持有优质股票，注重公司的基本面和成长性。林奇认为，投资成功的关键在于找到那些具有强大竞争优势、良好管理团队和持续增长潜力的公司。  

#### 1.1.1 成长型价值股的定义  
成长型价值股是指那些具有较高成长性，但当前估值相对较低的股票。这类股票通常属于处于成长阶段的公司，具有较高的盈利能力和市场扩展潜力。  

#### 1.1.2 成长型价值股的特征  
- **高成长性**：公司收入和利润持续增长，且增长速度高于行业平均水平。  
- **合理估值**：市盈率（P/E）、市净率（P/B）等估值指标低于行业平均水平。  
- **竞争优势**：公司在行业内具有独特的竞争优势，如技术优势、成本优势等。  
- **财务健康**：公司财务状况稳健，负债率低，现金流充足。

import pandas as pd
import numpy as np

# 数据加载
df = pd.read_csv('stock_data.csv')

# 数据清洗
df.dropna(inplace=True)

# 基于市盈率和收入增长率的筛选
df['P/E'] = df['股价'] / df['每股净利润']
df['收入增长率'] = (df['收入'] / df['上期收入']) - 1

# 筛选成长型价值股
成长型价值股 = df[(df['P/E'] < df['P/E'].mean()) & (df['收入增长率'] > 0.2)]
