### 第1章: 价值投资与低估值股票的基本概念

#### 1.1 价值投资的定义与核心理念

##### 1.1.1 价值投资的起源与发展
价值投资是一种长期投资策略，起源于20世纪初，由本杰明·格雷厄姆和戴维德·多德共同提出。格雷厄姆是价值投资的奠基人，他的理念强调以低于内在价值的价格购买股票，以确保投资的安全性。

##### 1.1.2 价值投资的核心原则
格雷厄姆的价值投资理论基于以下核心原则：
1. **安全边际**：以低于内在价值的价格购买股票，确保投资的安全性。
2. **内在价值**：股票的真正价值是其未来现金流的现值，而非市场的市价。
3. **市场先生**：市场的波动性是投资机会的来源，而非投资决策的依据。

##### 1.1.3 低估值股票的定义与特点
低估值股票是指市场价格低于其内在价值的股票。这类股票通常具有以下特点：
- 市盈率（P/E）和市净率（P/B）低于行业平均水平。
- 股票价格在市场波动中被低估，具有较大的上涨潜力。

#### 1.2 本杰明·格雷厄姆的生平与贡献

##### 1.2.1 格雷厄姆的学术背景
格雷厄姆是哥伦比亚大学的教授，他的教学和研究为价值投资理论奠定了基础。

##### 1.2.2 格雷厄姆的投资理论
格雷厄姆提出了以下核心投资理论：
1. **安全边际**：买入价格低于内在价值的股票，以确保投资的安全性。

##### 1.2.3 格雷厄姆的学生与影响

## 第二部分: 格雷厄姆投资理论的核心概念

### 第2章: 格雷厄姆投资理论的核心概念

#### 2.1 安全边际的概念

##### 2.1.1 安全边际的定义
安全边际是指股票的市场价格低于其内在价值的部分，确保投资的安全性。

##### 2.1.2 安全边际的重要性
安全边际的存在使得投资者在市场波动中能够避免重大损失。

##### 2.1.3 安全边际的计算方法
安全边际 = 内在价值 - 市场价格

#### 2.2 内在价值的计算

##### 2.2.1 内在价值的定义
内在价值是股票未来现金流的现值，是股票的真正价值。

##### 2.2.2 内在价值的计算公式
$$
\text{内在价值} = \sum_{t=1}^{n} \frac{\text{CF}_t}{(1+r)^t} + \frac{\text{TV}}{(1+r)^n}
$$
其中，CF_t是第t年的现金流，r是折现率，TV是终值。

##### 2.2.3 内在价值与市场价格的关系
当市场价格低于内在价值时，股票具有投资价值。

#### 2.3 股票估值的基本方法

##### 2.3.1 市盈率法
市盈率（P/E）= 股价 / 每股收益
- 低市盈率通常意味着股票被低估。

##### 2.3.2 市净率法
市净率（P/B）= 股价 / 每股净资产
- 低市净率通常意味着股票被低估。

##### 2.3.3 现金流折现法
现金流折现法通过将未来现金流折现到现值来计算股票的内在价值。

import pandas as pd

def calculate_intrinsic_value(stock_data, discount_rate):
    cash_flows = stock_data['cash_flows'].tolist()
    terminal_value = stock_data['terminal_value']
    intrinsic_value = 0
    for t in range(len(cash_flows)):
        intrinsic_value += cash_flows[t] / (1 + discount_rate) ** t
    intrinsic_value += terminal_value / (1 + discount_rate) ** len(cash_flows)
    return intrinsic_value

def screen_low_valuation_stocks(stock_data, max_pe, max_pb):
    low_valuation_stocks = []
    for stock in stock_data:
        if (stock['pe'] <= max_pe) and (stock['pb'] <= max_pb):
            low_valuation_stocks.append(stock)
    return low_valuation_stocks

# 示例数据
stock_data = [
    {'name': '股票A', 'pe': 10, 'pb': 1.5, 'cash_flows': [100, 120, 140], 'terminal_value': 200},
    {'name': '股票B', 'pe': 12, 'pb': 1.8, 'cash_flows': [80, 90, 100], 'terminal_value': 150}
]

# 计算内在价值
discount_rate = 0.1
for stock in stock_data:
    iv = calculate_intrinsic_value(stock, discount_rate)
    print(f"{stock['name']}的内在价值为：{iv}")

# 筛选低估值股票
max_pe = 12
max_pb = 1.8
low_valuation_stocks = screen_low_valuation_stocks(stock_data, max_pe, max_pb)
print("低估值股票为：", [stock['name'] for stock in low_valuation_stocks])
