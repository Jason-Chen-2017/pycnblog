# 第2章: 法国股市估值的核心概念与联系

## 2.1 宏观经济指标对股市的影响

### 2.1.1 GDP、失业率、通胀率等宏观经济指标的定义与作用  
GDP反映经济总量，失业率影响劳动力市场，通胀率影响货币政策。

### 2.1.2 宏观经济指标与股市估值的关系  
经济增长带动企业盈利，进而影响股价。

### 2.1.3 欧元区宏观经济环境对法国股市的影响  
欧元区的经济政策直接影响法国股市的表现。

## 2.2 公司基本面分析与估值方法

### 2.2.1 公司基本面分析的核心要素  
包括盈利能力、成长能力、财务状况等。

### 2.2.2 市盈率、市净率等常见估值指标的计算与应用  
市盈率公式：$$P/E = \frac{股价}{每股收益}$$  
市净率公式：$$P/B = \frac{股价}{每股净资产}$$

### 2.2.3 股东权益、现金流等财务指标对估值的影响  
现金流折现模型（DCF）用于评估公司内在价值。

## 2.3 股票估值模型与公式

### 2.3.1 常见股票估值模型的对比分析  
市盈率模型适用于成长型企业，DCF模型适用于成熟企业。

### 2.3.2 市盈率模型：$$P/E = \frac{股价}{每股收益}$$  
例如，某公司股价为50欧元，每股收益为5欧元，则$$P/E = 10$$。

### 2.3.3 市净率模型：$$P/B = \frac{股价}{每股净资产}$$  
例如，某公司股价为40欧元，每股净资产为20欧元，则$$P/B = 2$$。

### 2.3.4 现金流折现模型（DCF）：$$DCF = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n}$$  
其中，CF_t为第t年的现金流，r为折现率，TV为终值。
