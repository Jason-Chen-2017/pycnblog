# 第2章：股市估值的核心概念与技术

## 2.1 股市估值的关键指标与方法

### 2.1.1 市盈率（P/E）与市净率（P/B）
- 市盈率 = 股价 / 每股收益
- 市净率 = 股价 / 每股净资产

### 2.1.2 股东权益收益率（ROE）与资本回报率（ROCE）
- ROE = 净利润 / 股东权益
- ROCE = 净利润 / 总资本

### 2.1.3 现金流分析与股息率
- 现金流健康指标：自由现金流（FCF）
- 股息率 = 每股股息 / 股价

## 2.2 股市估值的算法与模型

### 2.2.1 时间序列分析模型（ARIMA）
ARIMA模型用于预测股票价格的时间序列数据，通过识别趋势和周期性来优化预测结果。

### 2.2.2 机器学习在股市预测中的应用
- 算法：随机森林、XGBoost
- 数据特征：历史价格、技术指标、市场情绪

### 2.2.3 股市估值的数学公式与模型推导
$$ ARIMA(p, d, q) = \phi(B)^p (1 - B)^d (1 - \theta(B)) $$
