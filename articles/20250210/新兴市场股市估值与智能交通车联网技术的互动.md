# 第2章: 新兴市场股市估值的方法与模型

## 2.1 传统估值方法

### 2.1.1 市盈率（P/E）模型
- 公式：$$P/E = \frac{股价}{每股收益}$$
- 适用场景：成熟市场中稳定增长的企业
- 优缺点：
  - 优点：简单易懂
  - 缺点：在新兴市场中波动性高，可能不准确

### 2.1.2 市净率（P/B）模型
- 公式：$$P/B = \frac{股价}{每股净资产}$$
- 适用场景：金融、房地产等行业
- 优缺点：
  - 优点：适用于净资产驱动型的企业
  - 缺点：新兴市场中信息不对称可能影响准确性

---

## 2.2 现代估值方法

### 2.2.1 股权自由现金流模型
- 公式：$$FCF = \text{净利润} + \text{非现金费用} - \text{资本支出}$$
- 适用场景：成长型企业
- 优缺点：
  - 优点：考虑了企业的真实现金流
  - 缺点：需要较长的历史数据和对未来的预测

### 2.2.2 市场情绪与行为金融学模型
- 核心思想：市场情绪会影响股票价格
- 模型：基于行为金融学的修正估值模型
- 示例：$$\text{修正股价} = \text{基础估值} \times (1 + \alpha \times \text{市场情绪})$$
  - 其中，$\alpha$ 是情绪影响系数
