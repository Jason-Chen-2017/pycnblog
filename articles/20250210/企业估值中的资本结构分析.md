#### 3.3 资本结构优化算法
- 资本结构优化的数学模型
$$ \text{优化目标：} \min WACC = \frac{D}{D+E} \times r_d \times (1 - t) + \frac{E}{D+E} \times r_e $$
- 算法实现的Python代码示例
```python
def calculate_wacc(d, e, rd, re, t):
    wacc = (d / (d + e)) * rd * (1 - t) + (e / (d + e)) * re
    return wacc
```
