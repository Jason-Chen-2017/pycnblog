# 第1章：特价股票与公司盈利能力的背景介绍

## 1.1 特价股票的定义与特征

### 1.1.1 特价股票的定义
特价股票是指低于面值发行的股票，通常反映公司财务健康状况不佳或市场对其未来盈利能力的担忧。这种股票在市场中可能被视为高风险投资，但也可能提供高回报的机会。

### 1.1.2 特价股票的特征
1. **发行价格低于面值**：公司可能因财务困境或市场低迷而选择低价发行股票。
2. **潜在高回报**：如果公司扭亏为盈，股价可能回升，带来丰厚收益。
3. **高波动性**：特价股票的价格波动较大，受市场情绪和公司业绩影响显著。

### 1.1.3 特价股票的分类
1. **优先股**：享有优先分红和清偿权，风险较低。
2. **普通股**：风险较高，但回报潜力更大。
3. **认股权证**：附带购买公司新股的权利，具有杠杆效应。

## 1.2 公司盈利能力的核心指标

### 1.2.1 净利润的定义与计算
净利润是公司营业收入减去所有费用后的利润，反映公司整体盈利能力。计算公式为：
$$
\text{净利润} = \text{营业收入} - \text{总费用}
$$

### 1.2.2 毛利率的定义与计算
毛利率是衡量公司产品盈利能力的指标，计算公式为：
$$
\text{毛利率} = \frac{\text{营业收入} - \text{营业成本}}{\text{营业收入}} \times 100\%
$$

### 1.2.3 净资产收益率的定义与计算
净资产收益率（ROE）是衡量公司使用股东资产效率的重要指标，计算公式为：
$$
\text{ROE} = \frac{\text{净利润}}{\text{净资产}} \times 100\%
$$

## 1.3 特价股票与公司盈利能力的关系背景

### 1.3.1 特价股票的市场现象
- 特价股票通常出现在市场低迷或公司业绩不佳时期。
- 投资者可能因公司重组或新产品推出而购买特价股票，期望未来股价回升。

### 1.3.2 公司盈利能力的市场表现
- 盈利能力强的公司通常股价较高，反之则股价较低。
- 特价股票的公司可能因盈利能力下降导致股价持续低迷。

### 1.3.3 两者关系的初步探讨
- 特价股票反映市场对公司盈利能力的负面预期。
- 公司通过改善盈利能力可能使股价回升，脱离特价范围。

## 3.3 回归分析法

### 3.3.1 回归模型构建
建立净利润与股价之间的回归模型：
$$
R_i = \beta_0 + \beta_1 P_i + \epsilon_i
$$
其中，$R_i$为净利润，$P_i$为股价，$\epsilon_i$为误差项。

### 3.3.2 回归分析步骤
1. 收集数据：获取公司过去5年的净利润和股价数据。
2. 数据预处理：处理缺失值和异常值。
3. 建立模型：使用最小二乘法估计系数。
4. 模型验证：计算R²值，判断模型拟合度。

### 3.3.3 Python代码实现
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载
data = pd.read_csv('stock_profit.csv')

# 特征和目标变量
X = data[['股价']]
y = data['净利润']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 模型预测
predictions = model.predict(X)

# 模型评估
r2 = r2_score(y, predictions)
print(f"R² = {r2}")
```
