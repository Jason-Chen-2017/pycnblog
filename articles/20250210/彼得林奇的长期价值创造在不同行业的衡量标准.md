**3.3 Python代码实现**

示例代码：

```python
def calculate_long_term_value(company_data, weights):
    """
    计算企业的长期价值评分
    Args:
        company_data: 包含企业各项指标的数据字典
        weights: 各指标的权重向量
    Returns:
        长期价值评分
    """
    # 确保输入数据和权重的维度一致
    if len(company_data) != len(weights):
        raise ValueError("数据和权重维度不匹配")
    
    # 计算加权评分
    weighted_scores = {k: v * weights[i] for i, (k, v) in enumerate(company_data.items())}
    total_score = sum(weighted_scores.values())
    
    return total_score

# 示例数据
company_data = {
    '净利润增长率': 0.15,
    'ROE': 0.2,
    '研发投入占比': 0.1,
    '员工满意度': 0.05
}

weights = [0.4, 0.3, 0.2, 0.1]

# 调用函数
ltv_score = calculate_long_term_value(company_data, weights)
print(f"长期价值评分: {ltv_score}")
```
