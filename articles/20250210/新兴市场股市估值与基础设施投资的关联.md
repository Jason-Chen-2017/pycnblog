### 第3章: 回归分析模型

#### 3.1 线性回归模型
- **3.1.1 简单线性回归**
  - 模型：$y = \beta_0 + \beta_1x + \epsilon$。
  - 使用最小二乘法估计系数。
- **3.1.2 多元线性回归**
  - 模型：$y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \ldots + \beta_nx_n + \epsilon$。
  - 解释多个自变量的影响。
- **3.1.3 模型假设与检验**
  - 检验假设：正态性、线性、方差齐性、独立性。
- **3.1.4 模型的优缺点**
  - 优点：简单易懂。
  - 缺点：假设严格，可能不成立。

#### 3.2 逻辑回归模型
- **3.2.1 二元逻辑回归**
  - 模型：$\ln(p/(1-p)) = \beta_0 + \beta_1x$。
  - 用于分类问题。
- **3.2.2 多分类逻辑回归**
  - 扩展到多类别。
- **3.2.3 模型适用场景**
  - 适用于二分类问题。
- **3.2.4 模型评估指标**
  - 准确率、召回率、F1分数。

#### 3.3 时间序列分析
- **3.3.1 ARIMA模型**
  - 用于预测未来值。
  - 模型：ARIMA(p, d, q)。
- **3.3.2 GARCH模型**
  - 模型：$r_t = \alpha_0 + \alpha_1r_{t-1} + \beta_1\sigma_{t-1}^2 + \epsilon_t$。
  - 用于预测波动性。
- **3.3.3 模型参数选择**
  - 使用AIC、BIC准则。
- **3.3.4 模型应用实例**
