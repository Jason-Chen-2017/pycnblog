```python
import numpy as np
from numpy import matrix, diagflat, ones, identity

def portfolio_optimization(cov_matrix, returns):
    n = len(returns)
    ones_vec = ones(n)
    inv_cov = inv(cov_matrix)
    weights = inv_cov @ ones_vec / (ones_vec.T @ inv_cov @ ones_vec)
    return weights
```

#### 5.3 算法的数学模型和公式

- 5.3.1 投资组合优化的数学模型
  $$ \text{目标函数：} \min_w Cov(w) = w^T \Sigma w $$

- 5.3.2 约束条件
  $$ \sum_{i=1}^{n} w_i = 1 $$

- 5.3.3 优化过程
