## 第1章: 全球股市估值的基本概念与现状

### 1.1 全球股市估值的定义与特点

#### 1.1.1 股市估值的基本概念
股市估值是指通过对公司财务数据、市场表现和行业趋势的分析，评估上市公司股票的内在价值。其目的是帮助投资者判断股票价格是否被高估或低估。

#### 1.1.2 全球股市估值的核心特点
- 数据驱动：依赖财务报表和市场数据进行分析。
- 动态变化：受经济环境、政策变化和市场情绪的影响。
- 多维度评估：结合市盈率、市净率等指标进行综合判断。

#### 1.1.3 全球股市估值的现状与趋势
当前，全球股市估值呈现多样化趋势，投资者 increasingly consider可持续性因素（如碳排放、环保表现）作为估值的重要组成部分。

### 1.2 可持续建筑智能材料的定义与特点

#### 1.2.1 可持续建筑的定义
可持续建筑是指在全生命周期内，最大限度地减少资源消耗和环境影响，同时提供健康舒适的工作和生活环境的建筑。

#### 1.2.2 智能材料的定义与属性
智能材料是指能够感知环境变化并做出响应的材料，例如：
- 智能窗户：根据光照自动调节透明度。
- 自修复材料：在受损后能够自行修复。

#### 1.2.3 可持续建筑智能材料的优势与挑战
优势：
- 节能减排，降低运营成本。
- 提高建筑舒适性和安全性。
挑战：
- 成本较高，技术成熟度有待提高。
- 市场认知度有限。

from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载
data = pd.read_csv('stock_data.csv')

# 特征选择
X = data[['S', 'M', 'C']]
y = data['V']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 模型预测
predictions = model.predict(X)
print("R-squared:", r2_score(y, predictions))
