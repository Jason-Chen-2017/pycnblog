## 第三部分：数学模型与算法实现

### 第3章：收益法的数学模型与代码实现

#### 3.1 收益法的数学推导
- 自由现金流的计算公式
- 折现率的确定方法
- 现金流的贴现与汇总

#### 3.2 收益法的Python代码实现
```python
def discounted_cash_flow(fcf, r, n):
    return sum(fcf / (1 + r) ** t for t in range(1, n+1))
```
