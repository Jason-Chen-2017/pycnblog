# 第1章: 格雷厄姆特价股票策略的基本原理

## 1.1 格雷厄姆投资理论的核心概念

### 1.1.1 格雷厄姆投资理论的起源与发展

格雷厄姆（Benjamin Graham）是价值投资的鼻祖，他的投资理论强调以低于内在价值的价格购买优质股票。格雷厄姆的策略主要关注企业的基本面，尤其是市盈率（P/E）和市净率（P/B）等指标，认为这些指标可以帮助投资者找到被市场低估的股票。

格雷厄姆的投资理念在20世纪30年代经济大萧条时期形成，并在之后的几十年中被广泛应用于股票投资。他的核心思想是：市场短期是投票机，长期是称重机。这意味着，虽然短期内市场情绪可能会影响股价，但长期来看，股票价格会回归其内在价值。

### 1.1.2 特价股票的定义与特征

格雷厄姆将“特价股票”定义为市场价格低于其内在价值的股票。以下是特价股票的几个关键特征：

1. **低市盈率（P/E）**：市盈率低于行业平均水平，通常被视为价值被低估的信号。
2. **低市净率（P/B）**：市净率低于1，表明股价低于账面价值。
3. **高股息率**：股息收益率远高于行业平均水平，通常意味着企业盈利稳定，但股价被低估。
4. **财务健康**：资产负债表健康，债务水平低，现金流稳定。

### 1.1.3 格雷厄姆策略在现代投资中的应用

格雷厄姆策略在现代投资中依然被广泛应用，尤其是在寻找价值被低估的股票时。然而，随着市场环境的变化，投资者需要对策略进行适当调整。例如，在科技行业，市盈率可能远高于传统行业，因此需要结合行业特点进行调整。
