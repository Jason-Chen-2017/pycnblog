# 第一部分: 芒格的"铁锤人综合征"概述

## 第1章: 芒格"铁锤人综合征"的核心概念

### 1.1 问题背景与定义
芒格的“铁锤人综合征”是指投资者只依赖一种工具或方法进行决策，导致视野受限。跨维度投资涉及多个维度，如技术、市场、政策，因此这种偏差尤其危险。

### 1.2 心理偏差的成因
投资者可能因过度自信或知识局限，仅依赖单一方法，忽视其他因素。跨维度投资的复杂性加剧了这种偏差的影响。

### 1.3 跨维度投资的特点
跨维度投资需要综合考虑多因素，单一工具无法全面分析，容易陷入“铁锤人综合征”。
