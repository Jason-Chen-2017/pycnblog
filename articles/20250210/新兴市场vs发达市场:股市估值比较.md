## 第一部分：新兴市场与发达市场的背景与基础

### 第1章：新兴市场与发达市场的定义与特点

#### 1.1 新兴市场的定义与特点
- **1.1.1 新兴市场的定义**  
  新兴市场是指那些经济快速增长但尚未完全成熟的国家或地区的股市。这些市场通常具有较高的增长潜力，但也伴随着较高的风险。

- **1.1.2 新兴市场的特点**  
  - 经济结构多元化，但多以制造业和出口导向型经济为主。  
  - 投资者结构以散户为主，机构投资者比例较低。  
  - 市场波动较大，受政策和外部环境影响显著。

- **1.1.3 新兴市场的代表国家与市场**  
  - 代表国家：中国、印度、巴西、墨西哥、韩国等。  
  - 代表市场：沪深股市（中国）、孟买股市（印度）、圣保罗股市（巴西）。

#### 1.2 发达市场的定义与特点
- **1.2.1 发达市场的定义**  
  发达市场是指那些经济成熟、市场结构完善、投资者成熟的国家或地区的股市。这些市场通常具有较高的流动性和稳定性。

- **1.2.2 发达市场的特点**  
  - 经济结构以服务业为主，制造业高度发达。  
  - 投资者结构以机构投资者为主，散户比例较低。  
  - 市场波动较小，受政策和外部环境影响相对稳定。

- **1.2.3 发达市场的代表国家与市场**  
  - 代表国家：美国、英国、日本、德国等。  
  - 代表市场：纽约证券交易所（美国）、伦敦金融时报（英国）、东京证券交易所（日本）。

#### 1.3 新兴市场与发达市场的核心区别
- **1.3.1 市场成熟度的差异**  
  新兴市场通常处于发展的初级阶段，市场机制尚不完善；发达市场则已经经历了长期的发展，市场机制较为成熟。

- **1.3.2 经济结构的差异**  
  新兴市场多以制造业和出口为导向；发达市场则以服务业为主，经济结构多元化且高度发达。

- **1.3.3 投资者结构的差异**  
  新兴市场以散户为主，机构投资者比例较低；发达市场以机构投资者为主，散户比例较低。

### 第3章：新兴市场与发达市场的估值指标对比

#### 3.1 估值指标的定义与作用
- **3.1.1 常见的估值指标**  
  - 市盈率（P/E Ratio）  
  - 市净率（P/B Ratio）  
  - 市销率（P/S Ratio）  
  - 股息率（Dividend Yield）  

- **3.1.2 估值指标的作用**  
  - 帮助投资者评估股票的相对价值。  
  - 为投资决策提供参考依据。

#### 3.2 新兴市场与发达市场的市盈率对比
- **3.2.1 市盈率的计算公式**  
  $$ P/E = \frac{股票价格}{每股净利润} $$

- **3.2.2 新兴市场与发达市场的市盈率差异**  
  - 新兴市场的市盈率通常较高，因为市场预期未来增长潜力大。  
  - 发达市场的市盈率相对较低，因为市场成熟，增长预期较为稳定。

#### 3.3 新兴市场与发达市场的市净率对比
- **3.3.1 市净率的计算公式**  
  $$ P/B = \frac{股票价格}{每股净资产} $$

- **3.3.2 新兴市场与发达市场的市净率差异**  
  - 新兴市场的市净率通常较高，因为市场预期未来资产增值潜力大。  
  - 发达市场的市净率相对较低，因为市场成熟，资产增值预期较为稳定。

#### 3.4 其他估值指标的对比
- **3.4.1 市销率（P/S Ratio）**  
  $$ P/S = \frac{股票价格}{每股收入} $$  
  - 新兴市场的市销率通常较高，因为市场预期未来收入增长潜力大。  
  - 发达市场的市销率相对较低，因为市场成熟，收入增长预期较为稳定。

- **3.4.2 股息率（Dividend Yield）**  
  $$ Dividend Yield = \frac{每股股息}{股票价格} $$  
  - 新兴市场的股息率通常较低，因为公司更倾向于将利润用于再投资。  
  - 发达市场的股息率通常较高，因为公司更倾向于回馈股东。

```python
import pandas as pd
from pandas_datareader import data as pdr
import matplotlib.pyplot as plt

# 获取新兴市场数据（以中国为例）
emerging_market = pdr.get_data_yahoo("SHanghai Composite", start="2020-01-01", end="2023-01-01")

# 获取发达市场数据（以美国为例）
developed_market = pdr.get_data_yahoo("IXIC", start="2020-01-01", end="2023-01-01")
  ```

  ```python
# 处理缺失值
emerging_market = emerging_market.dropna()
developed_market = developed_market.dropna()

# 处理异常值
emerging_market = emerging_market[emerging_market['Adj Close'] > 2000]
developed_market = developed_market[developed_market['Adj Close'] > 5000]
  ```

  ```python
# 计算市盈率
def calculate_pe_ratio(data):
    pe_ratio = data['Adj Close'] / data['EPS']
    return pe_ratio

# 计算市净率
def calculate_pb_ratio(data):
    pb_ratio = data['Adj Close'] / data['Book Value Per Share']
    return pb_ratio

emerging_pe = calculate_pe_ratio(emerging_market)
developed_pe = calculate_pe_ratio(developed_market)

emerging_pb = calculate_pb_ratio(emerging_market)
developed_pb = calculate_pb_ratio(developed_market)
  ```

  ```python
# 绘制市盈率对比图
plt.figure(figsize=(10, 6))
plt.plot(emerging_pe, label='Emerging Market PE Ratio', color='red')
plt.plot(developed_pe, label='Developed Market PE Ratio', color='blue')
plt.title('PE Ratio Comparison')
plt.xlabel('Date')
plt.ylabel('PE Ratio')
plt.legend()
plt.show()

# 绘制市净率对比图
plt.figure(figsize=(10, 6))
plt.plot(emerging_pb, label='Emerging Market PB Ratio', color='red')
plt.plot(developed_pb, label='Developed Market PB Ratio', color='blue')
plt.title('PB Ratio Comparison')
plt.xlabel('Date')
plt.ylabel('PB Ratio')
plt.legend()
plt.show()
  ```

  ```python
# 绘制长期趋势图

plt.title('Market Index Comparison')
plt.xlabel('Date')
plt.ylabel('Index Value')
plt.legend()
plt.show()
  ```
