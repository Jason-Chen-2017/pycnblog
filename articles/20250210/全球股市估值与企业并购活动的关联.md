## 第2章: 全球股市估值与企业并购活动的关联理论

### 2.1 理论基础

#### 2.1.1 股市估值理论
- 市盈率（P/E）= 股价 / 每股收益
- 市净率（P/B）= 股价 / 每股净资产

#### 2.1.2 企业并购理论
- 并购溢价 = 支付价格 - 目标企业市值
- 并购动因：战略协同、资源获取

#### 2.1.3 两者关联的理论基础
股市估值影响并购定价，高估值可能引发并购溢价。

### 2.2 理论模型构建

#### 2.2.1 理论模型构建过程
构建回归模型，分析股市估值与并购活动的相关性。

#### 2.2.2 模型的数学表达
$$ \text{并购活动} = \beta_0 + \beta_1 \times \text{股市估值} + \epsilon $$

#### 3.2.2 Python源代码实现
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据加载与处理
data = pd.read_csv('stock_market并购.csv')
X = data[['市盈率', '市净率']]
y = data['并购活动']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 输出系数
print('回归系数:', model.coef_)
print('截距:', model.intercept_)
```
