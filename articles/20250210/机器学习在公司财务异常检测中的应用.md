# 第二部分：算法原理

## 第3章：常见算法及其原理

### 3.1 逻辑回归
- **原理**：通过sigmoid函数将线性回归的输出映射到概率空间。
- **公式**：
  $$ P(y=1|x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x)}} $$
- **应用场景**：适合二分类问题，如欺诈 detection。

### 3.2 随机森林
- **原理**：通过构建多棵决策树，利用投票机制进行预测。
- **优势**：能够处理高维数据，具有较强的抗过拟合能力。
- **代码示例**：
  ```python
  from sklearn.ensemble import RandomForestClassifier
  model = RandomForestClassifier(n_estimators=100)
  model.fit(X_train, y_train)
  ```

### 3.3 神经网络
- **原理**：通过多层神经元网络模拟人脑的决策过程。
- **公式**：
  $$ a^{(l+1)} = g(a^{(l)}w + b) $$
  其中，$g$ 是激活函数，如ReLU或sigmoid。

## 第4章：数学模型与公式

### 4.1 逻辑回归模型
- **概率函数**：
  $$ P(y=1|x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x)}} $$
- **损失函数**：
  $$ L = -\sum_{i=1}^{n} [y_i \ln h(x_i) + (1 - y_i) \ln (1 - h(x_i))] $$

### 4.2 支持向量机模型
- **超平面方程**：
  $$ w \cdot x + b = 0 $$
- **软边距最大化**：
  $$ \max \xi_i \geq 0 $$

## 第7章：环境安装与代码实现

### 7.1 环境安装
- **Python**：3.8+
- **库**：numpy、pandas、scikit-learn、matplotlib。

### 7.2 核心代码实现
#### **数据预处理**
```python
import pandas as pd
import numpy as np

# 示例数据
data = {
    '收入': [100, 200, 300, 400],
    '支出': [50, 100, 150, 200],
    '利润': [50, 100, 150, 200]
}
df = pd.DataFrame(data)
```

#### **特征提取**
```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
scaled_data = scaler.fit_transform(df)
```

#### **模型训练**
```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression()
model.fit(scaled_data, df['利润'])
```

#### **异常检测**
```python
preds = model.predict(scaled_data)
print(preds)
```
