# 第1章: 全球股市估值的基本概念

## 1.1 股市估值的核心概念

### 1.1.1 股市估值的定义  
股市估值是指通过对企业的财务数据、市场环境和行业趋势等多方面因素的分析，对上市公司股票的内在价值进行评估的过程。常见的估值方法包括市盈率（P/E）、市净率（P/B）、股息率等。  

### 1.1.2 股市估值的主要指标  
1. **市盈率（P/E）**：市盈率 = 股票价格 / 每股净利润。  
2. **市净率（P/B）**：市净率 = 股票价格 / 每股净资产。  
3. **股息率**：股息率 = 每股股息 / 股票价格。  

### 1.1.3 股市估值的计算方法  
以市盈率为例，假设某公司每股净利润为2元，股票价格为40元，则市盈率为20倍。

## 1.2 可持续时尚供应链的定义与特点

### 1.2.1 可持续时尚供应链的定义  
可持续时尚供应链是指在服装、鞋类和配饰等时尚产品的设计、生产、分销和回收过程中，注重环境保护、社会责任和经济效益的综合供应链管理模式。  

### 1.2.2 可持续时尚供应链的核心要素  
1. **环境保护**：减少资源消耗、降低碳排放、避免环境污染。  
2. **社会责任**：公平贸易、保障劳工权益、反对童工和强迫劳动。  
3. **经济效益**：通过优化供应链流程降低成本，提高效率。  

### 1.2.3 可持续时尚供应链与传统供应链的区别  
| 特性               | 可持续供应链         | 传统供应链       |  
|--------------------|----------------------|------------------|  
| 环境影响           | 低                   | 高               |  
| 社会责任           | 强                   | 弱               |  
| 经济效率           | 高                   | 中               |
