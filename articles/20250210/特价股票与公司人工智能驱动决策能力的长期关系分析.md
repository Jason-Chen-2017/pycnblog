```python
import numpy as np

# 数据加载
data = pd.read_csv('stock.csv')

# 数据清洗
data = data.dropna()
data = data.reset_index(drop=True)

# 数据分割
train_data = data[:80]
test_data = data[80:]
```

### 6.2.2 模型训练代码
```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

model = LinearRegression()
model.fit(train_data[['open', 'high']], train_data['close'])
```

### 6.2.3 模型预测代码
```python
predictions = model.predict(test_data[['open', 'high']])
print(mean_squared_error(test_data['close'], predictions))
```
