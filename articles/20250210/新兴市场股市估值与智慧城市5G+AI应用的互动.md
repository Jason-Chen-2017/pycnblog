# 第2章：新兴市场股市估值的核心概念与原理

## 2.1 股市估值的主要方法

### 2.1.1 市盈率法

$$\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}$$

### 2.1.2 市净率法

$$\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}$$

### 2.1.3 现金流折现法

$$\text{股票价值} = \sum_{t=1}^{n} \frac{\text{现金流}}{(1+r)^t}$$

## 2.2 5G+AI技术对股市估值的影响

### 2.2.1 数据量的增加

5G提升数据传输速度，AI增强数据分析能力，提供更多维度的估值依据。

### 2.2.2 数据处理能力的提升

AI算法优化数据处理，提升估值模型的准确性和实时性。
