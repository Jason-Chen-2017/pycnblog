# 第一部分: 特价股票策略与投资组合构建基础

## 第1章: 特价股票策略概述

### 1.1 什么是特价股票策略
#### 1.1.1 特价股票的定义
特价股票是指价格相对较低的股票，通常具有较高的上涨潜力。这种策略关注于在市场低估时买入，等待价格上涨后卖出。

#### 1.1.2 特价股票的分类
- 垃圾股：基本面较差，但价格低廉的股票。
- 潜力股：基本面良好，但当前价格被低估的股票。
- 周期性股票：受经济周期影响较大的股票，如能源、材料等行业。

#### 1.1.3 特价股票与普通股票的区别
| 特性 | 特价股票 | 普通股票 |
|------|----------|----------|
| 价格 | 较低     | 无特定要求 |
| 潜力 | 较高     | 一般     |
| 风险 | 较高     | 较低     |
| 适用场景 | 市场低迷期 | 市场稳定期 |

### 1.2 投资组合构建的基本原理
#### 1.2.1 投资组合的定义
投资组合是将多种资产按一定比例组合在一起，以分散风险并优化收益。

#### 1.2.2 投资组合的目标
- 最大化收益
- 最小化风险
- 适应不同市场环境

#### 1.2.3 投资组合的风险与收益
- 风险：波动性、流动性风险
- 收益：资本收益、股息收益

### 1.3 特价股票策略的优势与劣势
#### 1.3.1 优势分析
- 成本低：适合资金有限的投资者
- 潜力大：在市场复苏时可能带来高回报
- 抗跌性：在市场下跌时可能表现相对稳定

#### 1.3.2 劣势分析
- 风险高：基本面差的股票可能继续下跌
- 流动性差：部分特价股票交易量小，变现困难
- 需要选股能力：需要较强的选股能力

#### 1.3.3 适用场景
- 市场低迷期：寻找被低估的股票
- 长期投资：通过持有特价股票实现资产增值

本章介绍了特价股票策略的基本概念、优势与劣势，以及其在投资组合构建中的适用场景。

```python
import numpy as np

def optimize_portfolio(returns):
    n = len(returns)
    ones = np.ones(n)
    covariance = np.cov(returns)
    inv_covar = np.linalg.inv(covariance)
    weights = inv_covar.dot(ones) / (ones.T.dot(inv_covar.dot(ones)))
    return weights
```
