## 3.3 算法实现代码

```python
import networkx as nx

def calculate_topo(data):
    G = nx.Graph()
    for node in data.nodes:
        G.add_node(node)
    for edge in data.edges:
        G.add_edge(edge[0], edge[1])
    degrees = nx.degree_centrality(G)
    betweenness = nx.betweenness_centrality(G)
    return degrees, betweenness
```

# 第4章 数学模型与公式推导

## 4.1 网络拓扑评估的数学模型

### 4.1.1 邻接矩阵的定义

$$
A = [a_{ij}] \quad \text{其中} \quad a_{ij} = 1 \quad \text{如果节点i与j相连，否则0}
$$

### 4.1.2 度中心性的公式

$$
C_d(i) = \frac{d_i}{n-1}
$$

其中，$d_i$为节点i的度数，$n$为节点总数。

### 4.1.3 介数中心性的公式

$$
C_b(i) = \sum_{j≠i,k≠i} \frac{number\_of\_shortest\_paths(j,k) \text{经过}i}{number\_of\_shortest\_paths(j,k)}
$$

---

## 4.2 网络优化的数学模型

### 4.2.1 拉普拉斯矩阵的定义

$$
L = D - A
$$

其中，$D$为度矩阵，$A$为邻接矩阵。

### 4.2.2 模体识别的公式

$$
Q = \sum_{i=1}^{n} \sum_{j=1}^{m} (a_{ij} - E[a_{ij}])^2
$$
