## 第二部分：彼得林奇逆向思维的背景介绍

### 2.1 彼得林奇的生平简介

彼得·林奇是美国著名投资经理人，以其在共同基金领域的卓越表现闻名。他在任职富达麦哲伦基金期间，创造了辉煌的投资业绩，平均年回报率超过29%。林奇的成功部分归功于他独特的逆向思维策略，即在市场低迷时寻找被低估的投资机会。

### 2.2 逆向思维的起源与发展

逆向思维并非林奇首创，但他在实践中将其系统化。逆向思维的核心在于识别市场周期中的低估资产，避免随市场情绪盲目投资。这一策略在20世纪80年代的美国市场中尤为有效，当时许多企业因杠杆收购和管理层过度扩张而陷入困境，为逆向投资者提供了丰厚的回报。

### 2.3 新股投资的基本概念

新股投资涉及购买新上市公司的一部分股权，通常伴随着较高的波动性和不确定性。与成熟企业相比，新股的未来表现更具变数，但也可能带来超额收益。逆向思维在新股投资中尤为重要，因为市场往往对新股给予过高的估值，而忽视了其潜在风险。

### 7.2 核心代码实现

```python
import pandas as pd

def 评估新股(公司数据):
    行业平均市盈率 = 公司数据['行业市盈率'].mean()
    低估公司 = 公司数据[公司数据['市盈率'] < 行业平均市盈率]
    return 低估公司

数据 = {
    '公司': ['A', 'B', 'C'],
    '市盈率': [15, 25, 30],
    '行业市盈率': [20, 20, 20]
}
df = pd.DataFrame(数据)
评估结果 = 评估新股(df)
print(评估结果)
```
