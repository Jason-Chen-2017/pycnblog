# 第1章：客户留存率的基本概念与重要性

## 1.1 客户留存率的定义与意义

### 1.1.1 客户留存率的定义
客户留存率是指在一定时间内，企业能够保留现有客户的比例。它通过比较客户的入会率和流失率来衡量客户忠诚度和产品吸引力。

$$客户留存率 = \frac{重复购买的客户数量}{总客户数量} \times 100\%$$

### 1.1.2 客户留存率的重要性
客户留存率是企业长期盈利能力的关键指标。高留存率意味着客户对产品或服务的满意度高，企业的市场稳定性强。

### 1.1.3 客户留存率与企业收入的关系
$$收入 = 客户数量 \times 平均消费金额 \times 留存率$$

import pandas as pd

def calculate_retention_rate(customers, period=1):
    current_customers = customers[customers['period'] == period]
    previous_customers = customers[customers['period'] == period-1]
    retention_rate = len(current_customers[current_customers['customer_id'].isin(previous_customers['customer_id'])]) / len(previous_customers)
    return retention_rate

data = pd.read_csv('customer.csv')
