# 第1章: 市场情绪指标的核心概念

## 1.1 市场情绪的定义与分类

市场情绪是指投资者在特定市场环境下的情感倾向，通常分为贪婪、恐慌、乐观和悲观四种类型。这些情绪通过投资者的行为反映到市场价格中。在跨资产类别中，市场情绪的表现形式有所不同，股票市场可能表现为波动性增加，而债券市场则可能表现出收益率的变化。

彼得林奇提出了一种基于市场情绪的指标，用于预测资产价格的变化。其数学模型可以表示为：

import pandas as pd
import numpy as np

def calculate_market_mood(data):
    # 计算平均收益率
    returns = data['close'].pct_change().dropna()
    avg_return = np.mean(returns)
    
    # 计算波动率
    volatility = np.std(returns)
    
    # 市场情绪指标：波动率标准化后的值
    mood_index = (avg_return - np.mean(returns)) / np.std(returns)
    return mood_index

# 示例数据
data = pd.DataFrame({
    'close': [100, 105, 98, 102, 104]
})

mood = calculate_market_mood(data)
