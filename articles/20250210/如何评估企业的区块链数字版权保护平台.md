  Python代码实现：
  ```python
  import hashlib

  def compute_hash(block):
      # 将区块内容转换为字符串
      block_string = str(block)
      # 计算哈希值
      hash_hex = hashlib.sha256(block_string.encode()).hexdigest()
      return hash_hex

  # 示例

      'timestamp': '2023-10-01',
      'transactions': []
  }
  print(compute_hash(block))
  ```
