## 第1章: 股票投资的基本概念

### 1.1 股票投资的定义与分类
股票投资是指通过购买公司股份，以期获得资本增值和股息收益的投资方式。股票投资可以分为主动投资和被动投资两大类。

- **主动投资**：投资者主动选择股票，积极管理投资组合，追求超额收益。
- **被动投资**：通过跟踪指数或市场整体表现，长期持有投资标的，追求市场平均收益。

### 1.2 主动投资与被动投资的定义
- **主动投资**：投资者通过基本面分析、技术分析等方法，精选个股，追求超越市场平均收益的投资方式。
- **被动投资**：通过投资指数基金或ETF等工具，复制市场指数的表现，追求与市场同步的收益。

### 1.3 价值投资的基本概念
价值投资是一种以低于内在价值的价格买入优质股票的投资策略，核心在于寻找市场低估的标的。

- **内在价值**：股票的真正价值，不完全取决于市场波动，而取决于公司的基本面。
- **安全边际**：买入价格与内在价值之间的差距，用以降低投资风险。

## 第2章: 格雷厄姆投资策略概述

### 2.1 格雷厄姆的投资理念
本杰明·格雷厄姆是价值投资的鼻祖，其投资理念强调安全性和稳健性。

- **安全边际**：买入价格低于内在价值，确保投资的安全性。
- **低市盈率策略**：选择市盈率低于市场平均水平的股票，寻找被市场低估的标的。
- **高股息率策略**：关注高股息率的股票，注重现金流的安全性。

### 2.2 格雷厄姆特价股票策略的核心原则
格雷厄姆策略的核心在于寻找那些价格低于其内在价值的股票，重点关注低市盈率、低市净率和高股息率的股票。

- **低市盈率（P/E）**：市盈率低于市场平均水平，通常为10倍以下。
- **低市净率（P/B）**：市净率低于2倍，表示资产被低估。
- **高股息率（D/P）**：股息率高于市场平均水平，通常为5%以上。

### 2.3 格雷厄姆策略的优缺点分析
#### 优点
- **风险低**：通过安全边际降低投资风险。
- **收益稳定**：长期来看，价值回归带来的收益较为稳定。
- **易于理解**：策略简单，适合长期投资者。

#### 缺点
- **操作难度大**：需要精确计算内在价值，对投资者的能力要求较高。
- **短期波动大**：市场可能长期低估优质股票，导致短期收益不明显。
- **市场适应性差**：在市场泡沫较多时，格雷厄姆策略可能表现不佳。

## 第3章: 被动投资策略的核心原理

### 3.1 被动投资的理论基础
被动投资基于有效市场假说，认为市场价格反映了所有可获取的信息，因此，主动投资难以持续跑赢市场。

- **有效市场假说**：市场价格反映了所有信息，主动投资难以获得超额收益。
- **被动投资的逻辑**：通过投资指数基金，获取市场平均收益。

### 3.2 被动投资的主要策略
- **指数基金投资**：通过投资标普500等指数基金，复制市场表现。
- **定期定额投资**：通过定期定额买入指数基金，分散投资风险。
- **低成本投资**：被动投资的管理费用较低，长期成本优势明显。

### 3.3 被动投资的优缺点分析
#### 优点
- **低成本**：管理费用低，长期复利效应显著。
- **分散风险**：通过投资指数基金，分散了个股风险。
- **操作简单**：无需频繁交易，适合长期投资者。

#### 缺点
- **收益有限**：只能获取市场平均收益，无法超越市场。
- **短期波动大**：市场波动可能影响短期收益。
- **缺乏个性化**：无法根据市场变化调整投资组合。

## 第4章: 格雷厄姆策略与被动投资的比较分析

### 4.1 战略目标的比较
- **格雷厄姆策略**：追求长期稳定的超额收益，注重安全边际。
- **被动投资**：追求市场平均收益，注重分散风险。

### 4.2 风险承受能力的比较
- **格雷厄姆策略**：适合风险承受能力较高的投资者，因为需要长期持有低估股票。
- **被动投资**：适合风险承受能力较低的投资者，因为通过分散投资降低了个股风险。

### 4.3 交易频率的比较
- **格雷厄姆策略**：交易频率低，通常长期持有股票。
- **被动投资**：交易频率也低，但通过定期定额投资实现。

### 4.4 成本与收益的比较
- **格雷厄姆策略**：初期研究和分析成本较高，但长期收益潜力大。
- **被动投资**：管理成本低，但收益受制于市场平均收益。

## 第5章: 数学模型与公式

### 5.1 格雷厄姆策略的数学模型
- **内在价值计算公式**：
  $$ \text{内在价值} = \text{净利润} \times (5 \times \text{保留率}) $$
  其中，保留率是公司净利润的留存比例。

- **安全边际计算公式**：
  $$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

### 5.2 被动投资的数学模型
- **指数基金收益计算公式**：
  $$ \text{收益} = \text{指数涨幅} \times \text{投资金额} $$

- **CAPM模型**：
  $$ \text{预期收益} = r_f + \beta (r_m - r_f) $$
  其中，\( r_f \) 是无风险利率，\( \beta \) 是贝塔系数，\( r_m \) 是市场预期收益率。

# 示例代码：计算股票的市盈率和市净率
def calculate_valuation_ratios(df):
    df['PE'] = df['Price'] / df['Earnings per Share']
    df['PB'] = df['Price'] / df['Book Value per Share']
    return df

# 示例代码：绘制市盈率分布图

    plt.hist(df['PE'], bins=20)

    plt.ylabel('Frequency')

    plt.show()

# 示例代码：寻找低估股票

    return undervalued
