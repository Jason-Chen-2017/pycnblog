#### 3.2 注意力权重的计算

  $$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$
- **注意力权重的计算步骤**：计算相似性，归一化，加权聚合。

#### 3.3 聚合与传播

  $$ h_i^{(l+1)} = \sum_{j=1}^{N} \alpha_{i,j} h_j^{(l)} $$
- **传播过程的数学模型**：通过多层传播，捕捉节点之间的间接影响。

#### 3.4 图注意力网络的损失函数
- **损失函数的定义**：使用交叉熵损失或均方误差，根据任务调整。

  ```python
  import torch
  import torch.nn as nn
  import torch.nn.functional as F

  class GraphAttention(nn.Module):
      def __init__(self, in_features, out_features):
          super(GraphAttention, self).__init__()
          self.in_features = in_features
          self.out_features = out_features
          self.W_q = nn.Linear(in_features, out_features)
          self.W_k = nn.Linear(in_features, out_features)
          self.W_v = nn.Linear(in_features, out_features)
          self.softmax = nn.Softmax(dim=-1)

      def forward(self, inputs, adj_matrix):
          Q = self.W_q(inputs)
          K = self.W_k(inputs)
          V = self.W_v(inputs)
          attention = (Q @ K.permute(0, 2, 1)) / self.out_features**0.5
          attention = self.softmax(attention)
          output = (attention @ V).sum(dim=1)
          return output
  ```
