## 第1章 全球股市估值概述

### 1.1 股票市场的基本概念

股票市场是企业融资和投资者进行股票交易的重要场所。以下是股票市场的基本概念：

- **股票市场的定义与运作机制**：股票市场是一个允许公司和个人通过发行和交易股票来融资和投资的市场。股票代表了公司的一部分所有权，投资者通过购买股票成为公司的股东，享有分红和投票权。

- **估值的基本概念与意义**：估值是指对资产或公司未来现金流的现值进行评估。股票的估值帮助投资者判断其价格是否合理，是否值得投资。

### 1.2 主要股票估值方法

以下是几种常用的股票估值方法：

- **市盈率（P/E）估值法**：市盈率是股票价格与每股收益的比值。公式为：P/E = 股价 / 每股收益。市盈率反映了投资者对公司的未来盈利预期。
- **市净率（P/B）估值法**：市净率是股票价格与每股净资产的比值。公式为：P/B = 股价 / 每股净资产。市净率适用于评估资产密集型企业的价值。
- **现金流折现法（DCF）**：现金流折现法是通过将未来现金流折现到现值来评估公司价值的方法。公式为：公司价值 = ∑(CF_t / (1 + r)^t)，其中CF_t是第t年的现金流，r是折现率。

- **区别于核裂变**：核裂变是将重核裂分成轻核，释放能量；核聚变是将轻核聚合成重核，释放能量。
- **聚变反应的基本过程**：主要包括燃料准备、加热到高温、约束和聚变反应发生。
- **聚变能的优势与挑战**：优势包括清洁、可持续、资源丰富；挑战包括高温 Plasma 的控制、反应堆的设计和材料的耐久性。

### 附录2：现金流折现法

假设公司未来三年的现金流分别为100万、150万、200万，折现率为10%。

代码示例：
```python
def calculate_ndv(cash_flows, discount_rate):
    return sum(cash_flow / (1 + discount_rate) ** t for t, cash_flow in enumerate(cash_flows))

cash_flows = [100, 150, 200]
discount_rate = 0.10
ndv = calculate_ndv(cash_flows, discount_rate)
print(ndv)  # 输出：385.505
