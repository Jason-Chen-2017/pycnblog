# 第4章: 基于价值网络的股票评分算法

## 4.1 算法原理
### 4.1.1 节点评分公式
$$ \text{节点评分} = \alpha \times \text{财务指标} + \beta \times \text{市场指标} + \gamma \times \text{技术指标} $$

### 4.1.2 边权重计算公式
$$ \text{边权重} = \frac{\text{交易价值}}{\text{网络密度}} $$

### 4.1.3 网络影响力计算公式
$$ \text{网络影响力} = \frac{\text{中心性} + \text{聚类性}}{2} $$

## 4.2 算法实现

### 4.2.2 核心代码实现
```python
import networkx as nx
import matplotlib.pyplot as plt
import numpy as np

# 创建网络
G = nx.Graph()

# 添加节点
G.add_nodes_from([1, 2, 3, 4])

# 添加边
G.add_edges_from([(1, 2), (2, 3), (3, 4), (1, 4)])

# 计算节点评分
def calculate_node_score(G):
    # 财务指标、市场指标、技术指标评分
    financial_score = [0.8, 0.6, 0.9, 0.7]
    market_score = [0.7, 0.5, 0.8, 0.6]
    technical_score = [0.6, 0.4, 0.7, 0.5]
    
    alpha = 0.5
    beta = 0.3
    gamma = 0.2
    
    node_scores = []
    for i in range(len(financial_score)):
        score = alpha * financial_score[i] + beta * market_score[i] + gamma * technical_score[i]
        node_scores.append(score)
    return node_scores

node_scores = calculate_node_score(G)

# 计算边权重
def calculate_edge_weight(G, node_scores):
    edge_weights = []
    for edge in G.edges():
        node1, node2 = edge
        weight = abs(node_scores[node1-1] - node_scores[node2-1])
        edge_weights.append((edge, weight))
    return edge_weights

edge_weights = calculate_edge_weight(G, node_scores)

# 网络可视化
nx.draw(G, node_color=node_scores, edge_color=[w for (edge, w) in edge_weights], edge_cmap=plt.cm.coolwarm)
plt.show()
```

# 第5章: 数学模型与公式

## 5.1 数学模型
### 5.1.1 节点评分模型
$$ S_i = \alpha \cdot F_i + \beta \cdot M_i + \gamma \cdot T_i $$

其中：
- $S_i$ 是第 $i$ 个节点的评分
- $F_i$ 是第 $i$ 个节点的财务指标
- $M_i$ 是第 $i$ 个节点的市场指标
- $T_i$ 是第 $i$ 个节点的技术指标
- $\alpha$, $\beta$, $\gamma$ 是权重系数

### 5.1.2 边权重计算公式
$$ W_{ij} = \frac{S_i \cdot S_j}{\sum_{k=1}^{n} S_k} $$

其中：
- $W_{ij}$ 是第 $i$ 和第 $j$ 个节点之间的边权重
- $S_i$, $S_j$ 是第 $i$ 和第 $j$ 个节点的评分
- $\sum_{k=1}^{n} S_k$ 是所有节点评分的总和

### 5.1.3 网络影响力公式
$$ I_i = \frac{C_i + C_c}{2} $$

其中：
- $I_i$ 是第 $i$ 个节点的网络影响力
- $C_i$ 是第 $i$ 个节点的中心性
- $C_c$ 是第 $i$ 个节点的聚类性

## 5.2 公式举例
### 5.2.1 节点评分计算
假设某企业的财务指标得分为0.8，市场指标得分为0.7，技术指标得分为0.6，且 $\alpha=0.5$, $\beta=0.3$, $\gamma=0.2$，则：
$$ S_i = 0.5 \cdot 0.8 + 0.3 \cdot 0.7 + 0.2 \cdot 0.6 = 0.4 + 0.21 + 0.12 = 0.73 $$

### 5.2.2 边权重计算
假设节点1和节点2的评分为0.73和0.62，所有节点的总评分为2.5，则：
$$ W_{12} = \frac{0.73 \cdot 0.62}{2.5} = \frac{0.4526}{2.5} = 0.181 $$

import networkx as nx
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np
from sklearn.metrics import pairwise_distances

# 示例数据
companies = ['A', 'B', 'C', 'D']
financial_scores = [0.8, 0.6, 0.9, 0.7]
market_scores = [0.7, 0.5, 0.8, 0.6]
technical_scores = [0.6, 0.4, 0.7, 0.5]

# 创建网络
G = nx.Graph()

# 添加节点
G.add_nodes_from(companies)

# 计算边权重
def calculate_edge_weights(G, financial_scores, market_scores, technical_scores):
    scores = list(zip(financial_scores, market_scores, technical_scores))
    distances = pairwise_distances(scores)
    edge_weights = {}
    for i in range(len(distances)):
        for j in range(len(distances[i])):
            if i != j:
                weight = distances[i][j]
                node1 = companies[i]
                node2 = companies[j]
                edge_weights[(node1, node2)] = weight
    return edge_weights

edge_weights = calculate_edge_weights(G, financial_scores, market_scores, technical_scores)

# 添加边
for edge, weight in edge_weights.items():
    G.add_edge(edge[0], edge[1], weight=weight)

# 网络可视化
pos = nx.spring_layout(G)
nx.draw(G, pos, edge_labels=True, edge_color='red', edge_cmap=plt.cm.coolwarm)
plt.show()
