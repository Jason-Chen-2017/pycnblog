## 第3章: 支持向量机在合同分类中的应用

### 3.1 支持向量机的基本原理

#### 3.1.1 SVM的定义
SVM是一种监督学习算法，用于分类和回归。

#### 3.1.2 SVM的数学模型
$$\text{目标函数: } \min_{w,b} \frac{1}{2}||w||^2 + C \sum_{i=1}^n \xi_i$$
$$\text{约束条件: } y_i(w \cdot x_i + b) \geq 1 - \xi_i, \xi_i \geq 0$$

#### 3.1.3 SVM的优化问题
通过拉格朗日乘数法，将问题转化为求解对偶问题。

### 3.2 基于SVM的合同分类实现

### 5.2 核心代码实现

#### 5.2.1 合同分类代码

```python
from sklearn.svm import SVC
from sklearn.feature_extraction.text import TfidfVectorizer
import spacy

nlp = spacy.load("en_core_web_sm")
vectorizer = TfidfVectorizer()
model = SVC()

def preprocess(text):
    return [nlp(text).vector]

def train_model(X, y):
    X_vec = vectorizer.fit_transform(X).toarray()
    model.fit(X_vec, y)

def predict(X_test):
    X_test_vec = vectorizer.transform(X_test).toarray()
    return model.predict(X_test_vec)
```

#### 5.2.2 条款识别代码

```python
import spacy

nlp = spacy.load("en_core_web_sm")

def extract_terms(text):
    doc = nlp(text)
    terms = []
    for token in doc:
        if token.ent_type_ == "TERM":
            terms.append(token.text)
    return terms
```
