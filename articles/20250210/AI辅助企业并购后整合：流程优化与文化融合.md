### 3.3 代码实现  
```python
from sklearn.cluster import KMeans
import numpy as np

# 示例数据
X = np.array([[1, 2], [3, 4], [5, 6], [7, 8]])

# 聚类算法实现
kmeans = KMeans(n_clusters=2)
kmeans.fit(X)
labels = kmeans.labels_
print(labels)
```

### 3.4 数学公式  
- **k-means算法的损失函数**  
  $$ J = \sum_{i=1}^{k} \sum_{j=1}^{n_i} ||x_j - c_i||^2 $$  
  其中，$k$ 是聚类数，$n_i$ 是第 $i$ 个聚类的样本数，$c_i$ 是第 $i$ 个聚类的中心。
