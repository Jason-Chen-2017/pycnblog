## 第二部分：财务报表分析的基础知识

### # 第2章：资产负债表分析

#### ## 2.1 资产负债表分析

- **2.1.1 资产、负债、所有者权益的定义与分类**
  - 资产：企业资源，分为流动资产和非流动资产。
  - 负债：企业债务，分为流动负债和非流动负债。
  - 所有者权益：净资产，资产减去负债。

- **2.1.2 资产负债表的结构与解读方法**
  - 表结构：资产=负债+所有者权益。
  - 重点科目：货币资金、应收账款、存货、应付账款、长期借款。

- **2.1.3 资产负债表分析的常见指标**
  - 偿债能力：流动比率、速动比率。
  - 财务杠杆：资产负债率。

#### ## 2.2 利润表分析

- **2.2.1 收入、成本与利润的关系**
  - 收入：企业营业收入。
  - 成本：生产成本。
  - 利润：收入减去成本。

- **2.2.2 利润表的结构与解读方法**
  - 利润构成：营业收入、营业成本、税前利润、净利润。

- **2.2.3 利润表分析的常见指标**
  - 净利率：净利润/营业收入。
  - 毛利率：毛利/营业收入。

#### ## 2.3 现金流量表分析

- **2.3.1 现金流的分类与构成**
  - 经营活动现金流：企业经营产生的现金流。
  - 投资活动现金流：投资产生的现金流。
  - 筹资活动现金流：筹资产生的现金流。

- **2.3.2 现金流量表的结构与解读方法**
  - 现金流入和流出的分析。

- **2.3.3 现金流量表分析的常见指标**
  - 现金净流量：经营活动现金流净额。
  - 现金覆盖率：经营活动现金流净额/利息支出。

## 第三部分：巴菲特的选股标准与投资策略

### # 第3章：巴菲特选股的核心标准

#### ## 3.1 企业盈利能力的衡量

- **ROE（净资产收益率）**
  - 公式：ROE = 净利润 / 平均净资产。
  - 重要性：衡量企业运用股东资产的效率。

- **ROA（资产净利率）**
  - 公式：ROA = 净利润 / 平均资产总额。
  - 重要性：衡量资产的使用效率。

#### ## 3.2 企业财务状况的评估

- **债务比率**
  - 公式：债务比率 = 总负债 / 总资产。
  - 重要性：评估企业杠杆风险。

- **流动比率**
  - 公式：流动比率 = 流动资产 / 流动负债。
  - 重要性：评估企业短期偿债能力。

#### ## 3.3 企业成长性的判断

- **收入增长率**
  - 公式：收入增长率 = (本年收入 - 去年收入) / 去年收入 × 100%。
  - 重要性：反映企业市场扩展能力。

- **净利润增长率**
  - 公式：净利润增长率 = (本年净利润 - 去年净利润) / 去年净利润 × 100%。
  - 重要性：反映企业盈利能力增长。

#### ## 3.4 企业核心竞争力的分析

- **竞争优势分析**
  - 技术优势：技术创新能力。
  - 市场地位：市场份额和品牌影响力。
  - 经济护城河：成本优势、专利、网络效应。
