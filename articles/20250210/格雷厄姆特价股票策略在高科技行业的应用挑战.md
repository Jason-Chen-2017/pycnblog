### 第1章: 格雷厄姆特价股票策略的核心概念

#### 1.1 格雷厄姆投资理论的起源与核心思想
格雷厄姆是价值投资的鼻祖，他提出的核心思想是寻找市场低估的股票进行投资。其核心概念包括：
- **安全边际**：买入价格低于内在价值，确保投资的安全性。
- **低市盈率**：选择市盈率低于市场平均水平的股票，认为这些股票具有更高的投资价值。

#### 1.2 高科技行业的特点与投资挑战
高科技行业具有以下特点：
- **高成长性**：行业增长速度快，但波动性也大。
- **高研发投入**：企业的研发投入占比较高，影响短期利润。
- **技术更新快**：技术变革迅速，企业面临较大的不确定性。

#### 1.3 格雷厄姆策略与高科技行业的结合
格雷厄姆策略在高科技行业的应用需要考虑以下几点：
- **高成长性企业的筛选**：选择那些具有持续增长潜力但市场价格被低估的企业。
- **研发投入的考量**：在评估内在价值时，需考虑企业的研发投入对未来的贡献。

import numpy as np
import pandas as pd

def calculate_intrinsic_value(df, growth_rate):
    df['Intrinsic Value'] = df['Enterprise Value'] / (1 - growth_rate)
    return df

# 示例数据
data = {
    'Enterprise Value': [100, 200, 300],
    'growth_rate': [0.1, 0.15, 0.2]
