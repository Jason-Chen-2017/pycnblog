# 第四部分：算法原理讲解

## 第4章：算法原理讲解

### 4.1 算法原理
特价股票策略的核心算法包括移动平均线（MA）和相对强弱指数（RSI）的计算。当股价低于MA且RSI处于超卖状态时，触发买入信号；当股价高于MA且RSI处于超买状态时，触发卖出信号。

#### 移动平均线（MA）
移动平均线是通过计算一定时期内的平均价格，用来平滑价格波动。常用的方法是简单移动平均线（SMA）和指数移动平均线（EMA）。

#### 相对强弱指数（RSI）
RSI用于衡量股票的超买或超卖状态。RSI的计算公式为：
$$ RSI = \frac{\text{上涨天数}}{\text{上涨天数} + \text{下跌天数}} \times 100 $$

### 4.2 Python代码实现
以下是实现特价股票策略的Python代码：

```python
import pandas as pd
import matplotlib.pyplot as plt
import pandas_datareader as pdr

# 获取股票数据
data = pdr.get_data_yahoo('AAPL', start='2020-01-01', end='2023-12-31')

# 计算移动平均线
data['MA'] = data['Close'].rolling(window=20).mean()

# 计算RSI
data['RSI'] = data['Close'].diff().apply(lambda x: x if x >= 0 else -x)
data['RSI'] = data['RSI'].rolling(window=14).mean()
data['RSI'] = data['RSI'].apply(lambda x: 100 - x)

# 生成信号
data['Signal'] = 0
data['Signal'] = data.apply(lambda row: 
    1 if row['Close'] < row['MA'] and row['RSI'] < 30 else 0, axis=1)

# 绘制图表
plt.figure(figsize=(12, 6))
plt.plot(data['Close'], label='Close Price')
plt.plot(data['MA'], label='MA(20)')
plt.scatter(data.index, data['Close'], color='red', alpha=0.5, label='Buy Signal')
plt.legend()
plt.show()
```
