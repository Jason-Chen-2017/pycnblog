## 第2章：图卷积网络的数学基础

### 2.1 图卷积网络的基本原理
图数据由节点（vertices）和边（edges）组成，通常表示为图 $G = (V, E)$，其中 $V$ 是节点集合，$E$ 是边集合。GCNs通过聚合节点及其邻居的特征信息，生成节点的高层次表示。

#### 2.1.1 图的表示与邻接矩阵
- **邻接矩阵**：一个 $n \times n$ 的矩阵 $A$，其中 $A_{i,j} = 1$ 表示节点 $i$ 和节点 $j$ 之间存在边，否则为0。
- **归一化邻接矩阵**：为了方便计算，通常将邻接矩阵进行归一化处理，得到 $\hat{A} = D^{-1/2} A D^{-1/2}$，其中 $D$ 是度矩阵。

#### 2.1.2 图卷积操作的数学表达
GCNs的基本操作是将节点的特征与其邻居的特征进行聚合。假设输入特征为 $X \in \mathbb{R}^{n \times d}$，其中 $n$ 是节点数，$d$ 是特征维度。图卷积操作可以表示为：
$$
Y = A X X^T X$$
其中 $A$ 是归一化邻接矩阵，$X$ 是输入特征矩阵，$Y$ 是输出特征矩阵。

#### 2.1.3 图卷积网络的前向传播公式
GCNs的前向传播公式为：
$$
h^{(l+1)} = \sigma(A h^{(l)} W^{(l)} + b^{(l)})
$$
其中 $h^{(l)}$ 是第 $l$ 层的节点表示，$\sigma$ 是激活函数，$W^{(l)}$ 和 $b^{(l)}$ 是权重和偏置。

### 2.2 图卷积网络的核心算法

#### 2.2.1 GCN的数学模型
GCN的数学模型可以表示为：
$$
Z = A X W + b
$$
其中 $Z$ 是输出特征矩阵，$A$ 是归一化邻接矩阵，$X$ 是输入特征矩阵，$W$ 和 $b$ 是模型参数。

#### 2.2.2 GAT的注意力机制
GAT（Graph Attention Networks）通过引入注意力机制，动态地调整节点之间的连接权重。注意力机制的计算公式为：
$$
\alpha_{i,j} = \frac{e^{f(h_i, h_j)}}{\sum_{k} e^{f(h_i, h_k)}}
$$
其中 $f$ 是注意力分数计算函数。

#### 2.2.3 图嵌入的计算方法
图嵌入的计算方法包括：
1. **节点嵌入**：通过GCNs提取节点的高层次特征表示。
2. **图嵌入**：将图的整体结构信息编码为低维向量。

import torch
import torch.nn as nn
import torch.nn.functional as F

class GCN(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GCN, self).__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)
    
    def forward(self, x, A):
        x = F.relu(A @ x @ self.fc1.weight)
        x = F.relu(A @ x @ self.fc2.weight)
        return x

# 初始化模型
