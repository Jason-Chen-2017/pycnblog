## 第二部分：核心概念与联系

### 第2章：核心概念原理

#### 2.1 股市估值的基本原理
- **市盈率与市净率**：市盈率（P/E）=股价/每股收益，市净率（P/B）=股价/每股净资产，衡量企业价值。
- **股票价格的决定因素**：包括盈利能力、行业地位、宏观经济环境等。
- **股市波动的分析方法**：使用技术分析和基本面分析预测股市走势。

#### 2.2 NFT市场的核心机制
- **NFT的定义与特点**：非同质化代币，唯一性、不可分割性。
- **NFT交易的流程**：上架、竞拍、智能合约交割。
- **NFT估值的影响因素**：艺术价值、创作者声誉、市场需求。

from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 特征选择
features = ['stock_price', 'market_cap']

#### 6.2 核心代码实现
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 数据加载
data = pd.read_csv('nft_stock.csv')

# 数据清洗
data = data.dropna()

# 特征选择
X = data[['stock_price', 'market_cap']]
y = data['nft_valuation']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测与评估
predictions = model.predict(X)
mse = mean_squared_error(y, predictions)
r2 = r2_score(y, predictions)

print(f'MSE: {mse}')
print(f'R²: {r2}')

# 可视化
import matplotlib.pyplot as plt
plt.scatter(y, predictions)
plt.xlabel('真实值')
plt.ylabel('预测值')
plt.title('NFT估值预测')
plt.show()
```
