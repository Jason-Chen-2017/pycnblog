# 第二章: 全球股市估值基础

## 2.1 股市估值的基本概念

### 2.1.1 股票价值的定义  
股票价值是投资者对公司的未来盈利能力的预期，通常通过财务指标和市场因素评估。

### 2.1.2 市盈率与市净率分析  
市盈率（P/E）= 股价 / 每股净利润，市净率（P/B）= 股价 / 每股净资产。

### 2.1.3 影响股市估值的主要因素  
市场情绪、宏观经济指标、公司基本面等。

## 2.2 股市估值模型

### 2.2.1 现金流折现模型（DCF）  
$$DCF = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n}$$  
其中，CF_t为第t年的现金流，r为折现率，TV为终值。

### 2.2.2 市盈率与市净率分析  
市盈率反映了市场对公司盈利能力的预期，市净率反映了市场对公司资产价值的评估。

## 2.3 数据采集与处理

### 2.3.1 数据来源  
股票价格、财务报表、宏观经济数据。

### 2.3.2 数据清洗与预处理  
去除缺失值、异常值，标准化处理。

### 2.3.3 特征提取  
提取股价趋势、波动率、成交量等特征。
