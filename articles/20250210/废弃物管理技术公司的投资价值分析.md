##### 7.2.1 核心算法实现

以下是DCF模型的Python实现：

```python
import numpy as np

def discounted_cash_flow(cash_flows, discount_rate, terminal_value):
    n = len(cash_flows)
    present_value = 0
    for t in range(n):
        present_value += cash_flows[t] / (1 + discount_rate) ** t
    present_value += terminal_value / (1 + discount_rate) ** n
    return present_value

# 示例数据
cash_flows = [100, 150, 200, 250]
discount_rate = 0.1
terminal_value = 500

value = discounted_cash_flow(cash_flows, discount_rate, terminal_value)
print(f"公司价值: {value}")
```
