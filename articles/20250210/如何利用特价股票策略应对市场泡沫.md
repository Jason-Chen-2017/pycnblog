## 第一章：市场泡沫的形成机制

### 1.1 市场泡沫的定义与特征
市场泡沫是指资产价格在短时间内迅速上涨，远远超出其实际价值的现象。这种现象通常由投资者的非理性行为、市场情绪过热以及资金过度流入等因素引发。

- **市场泡沫的定义**：资产价格与实际价值严重脱节，价格波动剧烈。
- **市场泡沫的特征**：
  - 价格波动剧烈。
  - 投资者情绪化，盲目跟风。
  - 市场参与者过多，资金过度集中。

### 1.2 市场泡沫的形成机制
市场泡沫的形成是一个复杂的过程，涉及多方面的因素：

- **投资者心理因素**：贪婪和恐惧情绪的交替作用。
- **市场情绪过热**：投资者对短期收益的过度追求。
- **资金过度流入**：大量资金涌入特定资产，推高价格。
- **信息不对称**：市场信息的不透明导致价格波动。

## 第二章：特价股票策略的核心要素

### 2.1 特价股票的定义与特点
特价股票是指市场价格低于其内在价值的股票，通常被视为被市场低估的资产。

- **定义**：市场价格 < 内在价值。
- **特点**：
  - 价格波动较小。
  - 投资价值较高。
  - 市场关注度较低。

### 2.2 特价股票策略的核心要素
特价股票策略的核心在于识别被市场低估的股票，并在适当的时候买入，等待其价值回归。

- **识别方法**：
  - 市盈率（PE）：股价 / 每股收益。
  - 市净率（PB）：股价 / 每股净资产。
  - 股息率：股息 / 股价。

### 2.3 特价股票策略的优势
- **风险较低**：价格被低估，下跌空间有限。
- **收益潜力大**：价值回归时，股价上涨空间较大。
- **抗跌性强**：在市场下跌时，特价股票的跌幅相对较小。

### 5.2 核心代码实现

```python
import pandas as pd
import numpy as np

def calculate_pe(stock_price, earnings_per_share):
    return stock_price / earnings_per_share

def calculate_pb(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

def is_cheap_stock(stock_data, industry_pe_avg, industry_pb_avg):
    pe = calculate_pe(stock_data['price'], stock_data['earnings_per_share'])
    pb = calculate_pb(stock_data['price'], stock_data['book_value_per_share'])
    return pe < industry_pe_avg and pb < industry_pb_avg

# 示例数据
data = {
    'stock': ['A', 'B', 'C'],
    'price': [10, 15, 20],
    'earnings_per_share': [5, 10, 8],
    'book_value_per_share': [2, 3, 4]
}

df = pd.DataFrame(data)

# 行业平均PE和PB
industry_pe_avg = 15
industry_pb_avg = 1.5

# 筛选特价股票
cheap_stocks = []
for stock in df['stock']:
    stock_data = df[df['stock'] == stock]
    if is_cheap_stock(stock_data, industry_pe_avg, industry_pb_avg):
        cheap_stocks.append(stock)

print("特价股票列表:", cheap_stocks)
```
