### 第1章：芒格的"极端后果"思维概述

#### 1.1 芒格的思维理念
芒格的“极端后果”思维是一种以反向思考为核心的投资策略，强调考虑最坏情况下的结果，从而在决策中避免重大风险。这种思维不仅关注表面现象，还深入分析潜在的负面影响和机会成本，帮助投资者在复杂环境中做出更明智的选择。

#### 1.2 气候适应性技术的基本概念
气候适应性技术是指能够有效应对气候变化影响的技术，如太阳能、风能、储能系统和智能电网等。这些技术通过减少温室气体排放、提高资源利用效率和增强系统韧性，帮助社会适应气候变化带来的挑战。

#### 1.3 问题背景与研究意义

```python
import numpy as np
import pandas as pd

def calculate_risk_assessment(projects):
    risks = []
    for proj in projects:
        risk = 0
        for scenario in proj['scenarios']:
            risk += scenario['probability'] * scenario['impact']
        risks.append({'name': proj['name'], 'risk': risk})
    return risks

def calculate_net_present_value(projects, discount_rate):
    npvs = []
    for proj in projects:
        npv = 0
        for year in range(proj['duration']):
            cash_flow = proj['cash_flows'][year]
            npv += cash_flow / (1 + discount_rate) ** year
        npvs.append({'name': proj['name'], 'npv': npv})
    return npvs

# 示例项目数据
projects = [

        'duration': 10,
        'cash_flows': [100, 80, 60, 40, 20, 10, 5, 3, 2, 1]
    },
    # 添加更多项目...
]
```
