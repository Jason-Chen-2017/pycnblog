## 第一部分: 特价股票策略的基本概念

### 第1章: 特价股票策略的定义与特点

#### 1.1 特价股票的定义
特价股票是指在特定市场条件下，价格被低估的股票。这些股票通常具有较高的安全边际，能够在市场波动中为投资者提供超额收益。

#### 1.2 特价股票策略的核心特点
- **低估值**：股票价格低于其内在价值。
- **高波动性**：价格波动较大，但波动中存在套利机会。
- **逆周期性**：在市场低迷时更容易出现特价股票。

#### 1.3 特价股票策略的优缺点
| 优点 | 缺点 |
|------|------|
| 高收益潜力 | 市场波动大，风险较高 |
| 低估值股票具有安全边际 | 需要较强的技术分析能力 |
| 适合长期投资 | 短期波动可能对资金流动性造成压力 |

### 第2章: 特价股票策略与其他投资策略的关系

#### 2.1 投资策略的分类
- **技术分析**：通过价格和成交量数据预测未来走势。
- **基本面分析**：通过公司财务数据评估其内在价值。
- **套利策略**：利用市场价差获利。
- **量化分析**：通过算法和模型进行投资决策。

#### 2.2 特价股票策略在投资组合中的地位
- 特价股票策略通常作为投资组合中的防御性策略，能够在市场下跌时提供保护。

#### 2.3 特价股票策略与其他策略的协同效应
- **技术分析与基本面分析的结合**：通过技术指标筛选潜在的特价股票，再结合基本面分析确认其价值。
- **套利策略的结合**：利用市场价差，在低价买入高价卖出，套取利润。
- **量化分析的结合**：通过量化模型筛选出具有低估特性的股票，再结合机器学习进行预测。

## 第二部分: 特价股票策略的核心原理

### 第3章: 特价股票策略的核心原理

#### 3.1 技术分析基础
- **移动平均线（MA）**：用于判断价格趋势。
- **相对强弱指数（RSI）**：用于判断超买超卖状态。
- **成交量分析**：用于判断价格变动的动能。

#### 3.2 基本面分析基础
- **市盈率（P/E）**：评估股票的估值水平。
- **市净率（P/B）**：评估股票相对于账面价值的高低。
- **股息率**：评估股票的分红能力。

#### 3.3 市场情绪与行为分析
- **投资者情绪**：市场恐慌时更容易出现特价股票。
- **行为金融学**：投资者非理性行为可能导致价格偏离内在价值。

### 第4章: 特价股票策略的关键要素

#### 4.1 市场周期分析
- **牛市**：市场整体上涨，特价股票机会较少。
- **熊市**：市场整体下跌，特价股票机会较多。
- **震荡市**：适合通过套利策略获利。

#### 4.2 股票估值方法
- **DCF模型**：通过现金流折现法评估公司价值。
- **PEG指标**：通过市盈率与盈利增长的比率评估股票价值。

#### 4.3 风险管理策略
- **止损策略**：设定止损点，控制亏损幅度。
- **分散投资**：通过投资多只股票分散风险。
- **仓位管理**：根据市场情况动态调整仓位。

### 第5章: 技术分析与基本面分析的结合

#### 5.1 技术指标的应用
- **MACD指标**：通过黄金交叉和死亡交叉判断趋势。
- **KDJ指标**：通过超买超卖信号指导买卖决策。

#### 5.2 基本面数据的筛选
- **筛选低P/E股票**：寻找市盈率低于行业平均水平的股票。
- **筛选低P/B股票**：寻找市净率低于行业平均水平的股票。

#### 5.3 结合应用的案例分析
- 某公司股票的P/E和P/B均低于行业平均水平，且技术指标显示超卖状态，结合市场情绪分析，判断该股票为潜在的特价股票。

### 第6章: 套利策略与特价股票策略的结合

#### 6.1 套利的基本原理
- **价差套利**：利用同一股票在不同市场或不同时间点的价格差异获利。
- **跨市场套利**：利用不同市场之间的价格差异获利。

#### 6.2 特价股票策略在套利中的应用
- **低价买入高价卖出**：在市场低估时买入，市场高估时卖出。
- **跨市场套利**：利用国内外市场价格差异，低价买入高价卖出。

#### 6.3 套利风险的控制
- **市场流动性风险**：选择流动性高的股票进行套利。
- **市场波动风险**：设置止损点，控制套利风险。

def screen_stocks(df):
    # 筛选P/E < 行业平均P/E 且 P/B < 行业平均P/B的股票
    industry_avg_pe = df['pe'].mean()

    rsi = pd.Series(prices).diff().apply(lambda x: x if x > 0 else -x)
    rsi = rsi.ewm(com=n, adjust=False).mean()
    rsi = 100 - (rsi / prices.std() * 100)
