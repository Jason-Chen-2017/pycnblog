## 1.1 格雷厄姆投资理论的核心概念

### 1.1.1 价值投资的定义与核心原则

价值投资是一种长期投资策略，主要关注于购买那些市场价格低于其内在价值的股票。核心原则包括：

- **安全性**：投资于那些具有安全边际的股票，即市场价格远低于其内在价值。
- **长期视角**：关注企业的长期盈利能力，而非短期市场波动。
- **深入分析**：通过基本面分析，评估企业的财务状况和未来前景。

### 1.1.2 格雷厄姆的安全边际概念

安全边际是指市场价格与内在价值之间的差距。通过购买那些市场价格远低于内在价值的股票，投资者能够在市场波动中获得保护，降低投资风险。

### 1.1.3 特价股票的定义与识别标准

特价股票是指那些市场价格远低于其内在价值的股票。识别标准包括：

- **低市盈率（P/E）**：市盈率远低于行业平均水平。
- **低市净率（P/B）**：市净率远低于行业平均水平。
- **高股息率**：股息收益率远高于行业平均水平。

## 1.2 数字市场信息效率的定义与层次

### 1.2.1 信息效率的基本概念

信息效率指的是信息在市场中的传播和处理速度。高效的信息效率意味着市场能够快速反映所有相关信息，低效的信息效率则意味着市场反应较慢。

### 1.2.2 数字市场的信息传播特点

数字市场中，信息传播速度快、范围广。投资者可以通过各种渠道（如新闻、社交媒体、交易平台）快速获取信息，从而影响市场价格。

### 1.2.3 信息效率的衡量标准

信息效率可以通过以下指标衡量：

- **信息传播速度**：信息从生成到市场反应的时间。
- **信息覆盖范围**：信息在多大范围内被传播。
- **市场反应速度**：市场对信息的反应速度和程度。

### 3.1.1 内在价值计算算法

以下是一个计算内在价值的Python算法示例：

```python
def calculate_intrinsic_value(cash_flows, discount_rate):
    intrinsic_value = 0
    for t in range(len(cash_flows)):
        intrinsic_value += cash_flows[t] / (1 + discount_rate) ** t
    return intrinsic_value
```

def calculate_intrinsic_value(ticker):

    intrinsic_value = calculate_intrinsic_value(ticker)
    market_price = data['Adj Close'][-1]
    return intrinsic_value - market_price
