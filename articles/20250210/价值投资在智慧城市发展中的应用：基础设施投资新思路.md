## 第二部分：价值投资的核心概念与原理

### 第2章：价值投资的核心原理

#### 2.1 价值投资的核心理念
- **2.1.1 资产的内在价值与市场价值**  
  内在价值是资产在未来现金流的现值，而市场价值是资产在市场上的交易价格。价值投资者关注资产的内在价值，寻找市场价值低于内在价值的投资机会。

- **2.1.2 资本资产定价模型（CAPM）**  
  CAPM 是一种用于评估资产合理预期收益的模型，公式如下：  
  $$ E(R_i) = R_f + \beta_i (E(R_m) - R_f) $$  
  其中，$E(R_i)$ 是资产的预期收益率，$R_f$ 是无风险利率，$\beta_i$ 是资产的贝塔系数，$E(R_m)$ 是市场预期收益率。

- **2.1.3 投资组合的优化与风险管理**  
  价值投资者注重分散投资以降低风险，同时通过长期持有优质资产实现收益。

#### 2.2 投资评估的三大核心要素
- **2.2.1 资产的收益与风险评估**  
  收益是资产的未来现金流，风险是现金流波动的可能性。价值投资者通过分析收益和风险的匹配关系，选择具有合理风险收益比的资产。

- **2.2.2 现金流的预测与折现**  
  现金流预测是价值评估的基础，通过将未来现金流折现到现值，计算资产的内在价值。常用的折现方法包括净现值（NPV）和内部收益率（IRR）。

- **2.2.3 资产的生命周期与价值波动**  
  资产的价值会随着其生命周期的变化而波动，价值投资者需要关注资产在不同生命周期阶段的估值变化。

## 第四部分：智慧城市基础设施投资的数学模型与算法

### 第4章：投资评估的数学模型

#### 4.1 净现值（NPV）模型
- **4.1.1 NPV的定义与计算公式**  
  $$ NPV = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$  
  其中，$CF_t$ 是第$t$年的现金流，$r$ 是折现率，$n$ 是项目寿命。

- **4.1.2 NPV模型的优缺点**  
  优点：能够反映项目的真实价值，考虑了时间价值。缺点：对折现率的敏感性较高。

#### 4.2 内部收益率（IRR）模型
- **4.2.1 IRR的定义与计算公式**  
  IRR 是使净现值为零的折现率，公式如下：  
  $$ NPV = \sum_{t=1}^{n} \frac{CF_t}{(1 + IRR)^t} = 0 $$  

- **4.2.2 IRR模型的应用场景**  
  适用于单一项目的评估，但不适用于多个项目的比较。

#### 4.3 资本预算模型
- **4.3.1 资本预算模型的定义**  
  资本预算模型用于评估大型项目的投资可行性，通常包括初始投资、现金流预测和折现率确定。

- **4.3.2 资本预算模型的步骤**  
  1. 确定初始投资和未来现金流。  
  2. 确定折现率。  
  3. 计算净现值（NPV）或内部收益率（IRR）。  
  4. 根据结果做出投资决策。

```python
def calculate_npv(cash_flows, discount_rate):
    return sum(cash_flow / (1 + discount_rate) ** t for t, cash_flow in enumerate(cash_flows))

cash_flows = [ -100, 50, 60, 70 ]
discount_rate = 0.10
npv = calculate_npv(cash_flows, discount_rate)
print(f"净现值为：{npv}")
```
