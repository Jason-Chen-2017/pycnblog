## 第2章：彼得林奇价值投资的核心概念与数学模型

### 2.1 价值投资的核心概念

#### 2.1.1 安全边际的定义与计算  
安全边际是彼得林奇选股的重要考量因素，它是指买入价格低于内在价值的部分。计算公式为：  
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$  

#### 2.1.2 内在价值的定义与计算  
内在价值是股票的未来现金流的现值。计算公式为：  
$$ \text{内在价值} = \frac{\text{现金流}}{\text{折现率}} $$  

#### 2.1.3 市场价值与内在价值的关系  
市场价值是股票的市场价格，而内在价值是股票的真实价值。当市场价格低于内在价值时，股票具有投资价值。

#### 2.1.4 核心概念对比表  
| 概念       | 定义                                                                 |
|------------|----------------------------------------------------------------------|
| 内在价值    | 股票未来现金流的现值，反映公司的真实价值。                  |
| 市场价值    | 股票的市场价格，受市场供需关系影响。                        |
| 安全边际    | 内在价值与市场价格的差额，反映投资的安全性。                |

### 2.2 价值投资的数学模型

#### 2.2.1 内在价值计算公式  
$$ \text{内在价值} = \frac{\text{现金流}}{\text{折现率}} $$  

#### 2.2.2 安全边际计算公式  
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$  

#### 2.2.3 市盈率与市净率的计算公式  
市盈率（P/E）= 股价 / 每股净利润  
市净率（P/B）= 股价 / 每股净资产

#### 3.3.2 核心代码实现

```python
import pandas as pd
import matplotlib.pyplot as plt

# 示例数据
data = {
    '公司': ['A', 'B', 'C'],
    '市盈率': [15, 20, 12],
    '市净率': [2, 3, 1],
    '股息率': [5, 4, 6]
}

df = pd.DataFrame(data)

# 计算内在价值（简化）
def calculate_intrinsic_value(row):
    pe = row['市盈率']
    pb = row['市净率']
    dividend_yield = row['股息率']
    return (pe + pb + dividend_yield) / 3

df['内在价值'] = df.apply(calculate_intrinsic_value, axis=1)

# 可视化
plt.figure(figsize=(10,6))
plt.plot(df['公司'], df['内在价值'], 'ro-')
plt.title('内在价值分析')
plt.xlabel('公司')
plt.ylabel('内在价值')
plt.show()
```
