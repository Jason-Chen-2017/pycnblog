- **1.1.1 数学期望的定义与计算**
  数学期望，也称为期望值，是概率论中用来度量一个随机变量的平均值。对于一个离散型随机变量 \( X \)，其数学期望 \( E[X] \) 可以表示为：
  $$ E[X] = \sum_{i=1}^{n} P(X = x_i) \cdot x_i $$
  其中，\( P(X = x_i) \) 是 \( X = x_i \) 的概率。

  在投资中，数学期望常用于评估投资的预期收益。例如，假设一个投资有三种可能的结果，分别对应收益 \( x_1, x_2, x_3 \)，其概率分别为 \( p_1, p_2, p_3 \)，则该投资的数学期望收益为：
  $$ E[R] = p_1 x_1 + p_2 x_2 + p_3 x_3 $$

- **1.1.2 芒格投资哲学的核心理念**

#### 2.1 量子概率的数学框架

量子概率的数学框架基于量子力学的基本原理。在量子力学中，系统的状态可以用一个向量在复数空间中表示，而概率则由内积决定。

- **2.1.1 量子态的表示**
  量子态可以用一个单位向量在复数空间中表示。例如，在一个两维空间中，量子态可以表示为：
  $$ | \psi \rangle = a |0\rangle + b |1\rangle $$
  其中，\( |a|^2 + |b|^2 = 1 \)。

- **2.1.2 概率幅与概率密度**
  量子态的系数 \( a \) 和 \( b \) 称为概率幅，其模长的平方即为对应状态的概率。例如，状态 \( |0\rangle \) 的概率为 \( |a|^2 \)。

- **2.1.3 量子测量的数学描述**
  在量子测量中，测量结果的概率由量子态与测量基的内积决定。例如，测量基为 \( |0\rangle \) 和 \( |1\rangle \)，则测量结果为 \( |0\rangle \) 的概率为 \( |a|^2 \)。

```python
from qiskit import QuantumCircuit, Aer, execute
from qiskit.circuit import Gate
import numpy as np

# 定义量子概率模型
def quantum_probability_model(n_qubits, shots=1000):
    # 初始化量子电路
    qc = QuantumCircuit(n_qubits)
    
    # 添加量子态
    qc += Gate('x', n_qubits)
    
    # 添加测量
    qc.measure_all()
    
    # 执行量子模拟
    backend = Aer.get_backend('qasm_simulator')
    job = execute(qc, backend, shots=shots)
    result = job.result()
    probabilities = result.get_counts().values()
    
    return probabilities

# 计算数学期望
def calculate_expectation(values, probabilities):
    return np.sum(values * probabilities)

# 示例计算
n_qubits = 2
expectation = calculate_expectation(np.arange(2**n_qubits), quantum_probability_model(n_qubits))
print(f"数学期望为: {expectation}")
```
