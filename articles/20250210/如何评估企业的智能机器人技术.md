### 4.2.2 Python代码实现

```python
import numpy as np

def calculate_weights(matrix):
    # 计算特征向量
    n = len(matrix)
    total = np.sum(matrix, axis=1)
    weights = matrix[0] / total
    return weights

# 示例判断矩阵
matrix = np.array([
    [1, 3, 2],
    [2, 1, 4],
    [3, 4, 1]
])

weights = calculate_weights(matrix)
print(weights)
```

### 4.2.3 算法实现的数学模型
$$
w_i = \frac{a_{i1}}{\sum_{j=1}^{n} a_{j1}}
$$
