### 2.1 情绪分析的核心原理

#### 2.1.1 基于规则的情绪分析
- 使用情感词典和规则匹配文本中的情感倾向
- 优点：简单易实现，适合小规模数据
- 缺点：难以处理复杂语境和讽刺语气

#### 2.1.2 机器学习的情绪分析
- 使用训练数据训练模型，自动分类文本情绪
- 常见算法：支持向量机（SVM）、随机森林
- 优点：准确率高，可扩展性强
- 缺点：需要大量标注数据

#### 2.1.3 深度学习的情绪分析
- 使用神经网络模型（如LSTM、BERT）捕捉文本深层语义
- 优点：处理复杂语境，效果更优
- 缺点：计算资源消耗大，训练时间长

# 第二部分: 算法与数学模型

## 第3章: 基于规则的情绪分析算法

### 3.1 算法原理

#### 3.1.1 基于规则的流程

```mermaid
graph TD
    A[开始] --> B[选择情感词典]
    B --> C[匹配文本关键词]
    C --> D[计算情感得分]
    D --> E[输出情感结果]
    E --> 结束
```

#### 3.1.2 Python实现

```python
# 情感词典加载
from collections import defaultdict

positive_words = defaultdict(list)
negative_words = defaultdict(list)

# 示例词典加载
positive_words['happy'] = 1
positive_words['excited'] = 1
negative_words['sad'] = -1
negative_words['frustrated'] = -1

def get_sentiment(text):
    score = 0
    words = text.split()
    for word in words:
        if word in positive_words:
            score += 1
        elif word in negative_words:
            score -= 1
    return 'positive' if score > 0 else 'negative' if score < 0 else 'neutral'

text = "I love this product!"
print(get_sentiment(text))  # 输出 'positive'
```

### 3.2 数学模型

#### 3.2.1 情感得分计算公式

$$ \text{情感得分} = \sum_{i=1}^{n} w_i \times v_i $$

其中，\( w_i \) 是词袋模型中的词权重，\( v_i \) 是词语的情感值。

## 第4章: 机器学习情绪分析算法

### 4.1 支持向量机（SVM）算法

#### 4.1.1 算法原理

SVM通过构建超平面将数据点分为不同类别，解决线性可分问题。

$$ \text{优化目标} = \min_{w,b} \frac{1}{2}||w||^2 + C \sum_{i=1}^{n} \xi_i $$

#### 4.1.2 Python实现

```python
from sklearn import svm

# 训练数据
X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 0, 1, 1]

# 创建SVM模型并训练
model = svm.SVC()
model.fit(X, y)

# 预测
print(model.predict([[0.5, 0.5]]))  # 输出 [1]
```

## 第5章: 深度学习情绪分析算法

### 5.1 长短期记忆网络（LSTM）

#### 5.1.1 算法原理

LSTM通过门控机制处理序列数据，捕捉长距离依赖关系。

$$ f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) $$

#### 5.1.2 Python实现

```python
import tensorflow as tf

# 定义LSTM模型
model = tf.keras.Sequential()
model.add(tf.keras.layers.LSTM(128, input_shape=(None, 100)))
model.add(tf.keras.layers.Dense(3, activation='softmax'))
model.compile(loss='sparse_categorical_crossentropy', optimizer='adam', metrics=['accuracy'])
model.summary()
```

```python
import pandas as pd

df = pd.read_csv('data.csv')
df['text'] = df['text'].apply(lambda x: x.lower())
df['text'] = df['text'].replace('[^\w\s]', '', regex=True)
```

#### 7.2.2 模型训练

```python
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC

X_train, X_test, y_train, y_test = train_test_split(df['text'], df['label'], test_size=0.2)
vectorizer = TfidfVectorizer()
X_train_vec = vectorizer.fit_transform(X_train)
X_test_vec = vectorizer.transform(X_test)

model = SVC()
model.fit(X_train_vec, y_train)
print(model.score(X_test_vec, y_test))
```
