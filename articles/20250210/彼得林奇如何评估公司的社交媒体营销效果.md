# 第3章: 社交媒体营销效果的关键指标分析

## 3.1 影响力指标

### 3.1.1 粉丝数量与活跃度

粉丝数量反映品牌关注度，活跃度衡量用户互动频率。

- **粉丝数量**：关注企业的用户数。
- **活跃度**：粉丝的互动频率和活跃程度。

### 3.1.2 内容互动率

互动率越高，内容越受用户欢迎。

- **互动率** = （点赞 + 评论 + 分享次数） / （发布内容次数 × 粉丝数） × 100%

### 3.1.3 品牌知名度

通过品牌提及量和搜索量评估品牌认知度。

---

## 3.2 转化率指标

### 3.2.1 点击率

点击率反映用户对内容的兴趣程度。

- **点击率** = （点击次数 / 展现次数） × 100%

### 3.2.2 订单转化率

从点击到下单的比例，衡量内容的商业价值。

- **订单转化率** = （下单用户数 / 点击用户数） × 100%

### 3.2.3 客户留存率

客户留存率反映用户的忠诚度。

- **客户留存率** = （重复购买用户数 / 总购买用户数） × 100%

---

## 3.3 效益指标

### 3.3.1 投资回报率（ROI）

衡量营销活动的盈利能力。

- **ROI** = （营销活动带来的利润 / 营销投入成本） × 100%

### 3.3.2 成本效率

单位成本能带来的用户增长或销售额提升。

- **成本效率** = 销售额 / 营销支出
