## 第2章 提示词工程基础

### 2.1 文本数据

文本数据是提示词工程的基础，包括医疗记录、病历、临床试验报告、医生笔记等。这些数据包含了丰富的信息，是制定个性化医疗方案的重要依据。

### 2.2 特征提取

特征提取是将原始文本数据转化为计算机可以处理的形式。常用的特征提取方法包括词袋模型、TF-IDF、词嵌入等。

- **词袋模型**：将文本数据表示为一个词的集合，不考虑词的顺序和语法结构。
- **TF-IDF**：基于词频和逆文档频率的权重计算，用于评估一个词在文档中的重要程度。
- **词嵌入**：将文本中的每个词映射为一个高维向量，用于捕捉词与词之间的语义关系。

### 2.3 关键词提取

关键词提取是提示词工程的核心步骤，旨在从大量文本数据中提取出最有价值的信息。常用的关键词提取方法包括TF-IDF、TextRank、LDA等。

- **TF-IDF**：基于词频和逆文档频率的权重计算，用于评估一个词在文档中的重要程度。
- **TextRank**：基于图模型的关键词提取方法，通过构建文本的词向量图，利用图算法提取关键词。
- **LDA**： latent Dirichlet Allocation，是一种主题模型，通过将文档的主题分布和词的主题分布联系起来，提取关键词。

### 2.4 语义理解

语义理解是提示词工程的高级阶段，旨在理解文本数据的含义和关系。常用的语义理解方法包括词嵌入、词性标注、依存句法分析等。

- **词嵌入**：将文本中的每个词映射为一个高维向量，用于捕捉词与词之间的语义关系。
- **词性标注**：对文本中的每个词进行词性分类，如名词、动词、形容词等。
- **依存句法分析**：分析句子中词语之间的依存关系，如主谓关系、修饰关系等。

### 附录C：Python源代码示例

以下是使用Python实现提示词工程的一个简单示例：

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer

# 文本数据
texts = [
    "患者A患有高血压，需要控制血压。",
    "医生建议患者A服用ACE抑制剂来控制血压。",
    "临床试验显示，ACE抑制剂对高血压患者有显著疗效。"
]

# 初始化TF-IDF向量器
vectorizer = TfidfVectorizer()

# 提取特征
X = vectorizer.fit_transform(texts)

# 提取关键词
feature_names = vectorizer.get_feature_names_out()
top_k = 5
top_indices = np.argsort(X.toarray(), axis=1)[:, -top_k:]
top_keywords = [feature_names[i] for i in top_indices]

# 打印关键词
for text, keywords in zip(texts, top_keywords):
    print(f"文本：{text}\n关键词：{', '.join(keywords)}\n")
```

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from gensim.models import Word2Vec

# 文本数据
texts = [
    "患者A患有高血压，需要控制血压。",
    "医生建议患者A服用ACE抑制剂来控制血压。",
    "临床试验显示，ACE抑制剂对高血压患者有显著疗效。"
]

# 初始化TF-IDF向量器
vectorizer = TfidfVectorizer()

# 提取TF-IDF特征
X = vectorizer.fit_transform(texts)

# 打印TF-IDF特征
print("TF-IDF特征：")
print(X.toarray())

# 初始化Word2Vec模型
model = Word2Vec(texts, vector_size=100, window=5, min_count=1, workers=4)

# 打印Word2Vec向量
print("Word2Vec向量：")
print(model.wv.vectors)

# 关键词提取
top_k = 5
top_indices = np.argsort(X.toarray(), axis=1)[:, -top_k:]
top_keywords = [vectorizer.get_feature_names_out()[i] for i in top_indices]

# 打印关键词
print("关键词提取结果：")
for text, keywords in zip(texts, top_keywords):
    print(f"文本：{text}\n关键词：{', '.join(keywords)}\n")
```
