#### **2.2.3 Python代码实现**

以下是一个简单的线性回归算法的Python代码实现。

```python
import numpy as np

def linear_regression(X, y):
    w = np.linalg.inv(X.T @ X) @ X.T @ y
    return w

X = np.array([[1, 2], [2, 3], [3, 4]])
y = np.array([3, 4, 5])

w = linear_regression(X, y)
print(w)
```

#### **2.2.4 数学模型与公式讲解**

线性回归的数学模型如下：

$$
y = X \cdot w + b
$$

其中，$X$ 是输入特征矩阵，$w$ 是权重矩阵，$b$ 是偏置项。
