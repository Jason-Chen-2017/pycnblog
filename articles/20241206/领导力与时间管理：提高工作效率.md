```python
class Task:
    def __init__(self, name, deadline, priority):
        self.name = name
        self.deadline = deadline
        self.priority = priority

    def is_urgent(self):
        return self.priority == "high" and self.deadline < datetime.now()

class TimeManager:
    def __init__(self):
        self.tasks = []

    def add_task(self, task):
        self.tasks.append(task)

    def get_urgent_tasks(self):
        return [task for task in self.tasks if task.is_urgent()]

# 示例：添加任务和获取紧急任务
time_manager = TimeManager()
time_manager.add_task(Task("完成报告", datetime(2023, 12, 15), "high"))
urgent_tasks = time_manager.get_urgent_tasks()
print("紧急任务：", urgent_tasks)
```

2. **方法定义**：`is_urgent` 方法用于判断任务是否紧急。
3. **类定义**：`TimeManager` 类用于管理任务，包括添加任务和获取紧急任务。
