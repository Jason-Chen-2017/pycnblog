##### 3.1.3 算法举例

下面我们以动态规划为例，使用 Python 源代码详细阐述动态规划算法原理，并给出一个具体的例子。

```python
def dynamic_programming_example():
    # 动态规划算法的伪代码
    # 设 n 为问题的规模，dp[i] 表示前 i 个元素的最大子序列和
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = max(dp[i - 1], dp[i - 1] + arr[i - 1])
    return dp[n]
```

在这个例子中，我们考虑一个数组 `arr`，动态规划的目标是求出数组的前 `n` 个元素的最大子序列和。动态规划的原理是通过子问题的最优解推导出原问题的最优解。
