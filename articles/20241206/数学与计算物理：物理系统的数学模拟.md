```python
# Python代码示例：有限差分法求解一维热传导方程
import numpy as np
import matplotlib.pyplot as plt

# 初始化参数
N = 100
L = 1.0
dx = L / N
dt = 0.01 * dx**2
T = np.zeros((N+1, N+1))

# 边界条件
T[0, :] = 100
T[-1, :] = 0

# 算法实现
for i in range(N+1):
    for j in range(N+1):
        if i > 0 and i < N and j > 0 and j < N:
            T[i, j] = (T[i-1, j] + T[i+1, j] + T[i, j-1] + T[i, j+1] - 4 * T[i, j]) / 4

# 结果分析
plt.plot(T[:, int(N/2)], label='Time Step: ' + str(i))
plt.xlabel('Position')
plt.ylabel('Temperature')
plt.legend()
plt.show()
```

### 3.3 算法原理的数学模型和公式

热传导方程的数学模型为：

$$
\frac{\partial T}{\partial t} = \alpha \frac{\partial^2 T}{\partial x^2}
$$

其中，\(T\) 为温度，\(\alpha\) 为热扩散系数。有限差分法的公式为：

$$
T_{i,j}^{n+1} = \frac{T_{i-1,j}^{n} + T_{i+1,j}^{n} + T_{i,j-1}^{n} + T_{i,j+1}^{n} - 4T_{i,j}^{n}}{4dx^2}
$$
