#### 1. Machine Learning (ML)

Machine learning (ML) is a foundational technique in AI that enables systems to learn from data and improve their performance over time without being explicitly programmed. ML algorithms can be broadly categorized into two types: supervised learning and unsupervised learning.

**Supervised Learning**

Supervised learning algorithms are trained on labeled data, where the correct output is provided for each input. This allows the algorithm to learn the relationship between inputs and outputs, enabling it to make predictions on new, unseen data.

**Example: Linear Regression**

Linear regression is a supervised learning algorithm used to model the relationship between a dependent variable (output) and one or more independent variables (inputs). The goal is to find the best-fitting linear equation that can predict the output based on the inputs.

**Mathematical Model:**

$$ y = \beta_0 + \beta_1x + \epsilon $$

where \( y \) is the output, \( x \) is the input, \( \beta_0 \) and \( \beta_1 \) are the coefficients, and \( \epsilon \) is the error term.

**Application: Predicting House Prices**

Consider a dataset containing information about houses, such as the number of rooms, square footage, and location, along with the corresponding sale prices. By training a linear regression model on this data, we can predict the price of a new house based on its features.

**Python Code Example:**

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# Load dataset
X = np.array([[1, 2], [2, 3], [3, 4], [4, 5]])
y = np.array([2, 3, 4, 5])

# Create and train the linear regression model
model = LinearRegression()
model.fit(X, y)

# Predict the price of a new house
new_house = np.array([[5, 6]])
predicted_price = model.predict(new_house)
print(f"The predicted price of the new house is: {predicted_price[0]}")
```

**Output:**

```
The predicted price of the new house is: 6.0
```

**Unsupervised Learning**

Unsupervised learning algorithms do not rely on labeled data and instead focus on finding patterns and structures within the data. These algorithms are particularly useful for exploratory data analysis and data clustering.

**Example: K-Means Clustering**

K-means clustering is an unsupervised learning algorithm that groups data points into K clusters based on their proximity to the centroid of each cluster.

**Mathematical Model:**

1. Initialize K centroids randomly.
2. Assign each data point to the nearest centroid.
3. Update the centroids as the average of the assigned data points.
4. Repeat steps 2 and 3 until convergence (i.e., the centroids no longer change significantly).

**Application: Customer Segmentation**

Consider a dataset containing information about customers, such as age, income, and spending habits. By applying K-means clustering, we can segment customers into distinct groups based on their characteristics.

**Python Code Example:**

```python
import numpy as np
from sklearn.cluster import KMeans

# Load dataset
X = np.array([[1, 2], [2, 2], [3, 4], [4, 3], [5, 5], [6, 7]])

# Create and train the K-means model
model = KMeans(n_clusters=2)
model.fit(X)

# Predict the cluster labels for the dataset
labels = model.predict(X)

# Print the cluster labels
print(f"Cluster labels: {labels}")
```

**Output:**

```
Cluster labels: [1 1 0 0 1 0]
```

#### 3. Reinforcement Learning (RL)

Reinforcement learning is a type of machine learning where an agent learns to make decisions by interacting with an environment and receiving feedback in the form of rewards or penalties. RL is particularly effective in scenarios where the agent must learn a policy that maximizes cumulative rewards over time.

**Example: Q-Learning**

Q-learning is a popular RL algorithm that learns the optimal action-value function, representing the expected utility of taking a specific action in a given state.

**Mathematical Model:**

$$ Q(s, a) = r + \gamma \max_{a'} Q(s', a') $$

where \( s \) is the state, \( a \) is the action, \( r \) is the reward, \( \gamma \) is the discount factor, and \( s' \) and \( a' \) are the next state and action, respectively.

**Application: Game Playing**

Consider a game like chess or Go, where an agent must learn to play optimally by receiving feedback in the form of rewards or penalties based on the game outcome. Q-learning can be used to train the agent to make better decisions over time.

**Python Code Example:**

```python
import numpy as np
import gym

# Create the environment
env = gym.make("CartPole-v0")

# Initialize the Q-table
Q = np.zeros([env.observation_space.n, env.action_space.n])

# Hyperparameters
alpha = 0.1
gamma = 0.9
epsilon = 0.1

# Training loop
for episode in range(1000):
    state = env.reset()
    done = False
    total_reward = 0
    
    while not done:
        if np.random.rand() < epsilon:
            action = env.action_space.sample()
        else:
            action = np.argmax(Q[state])
        
        next_state, reward, done, _ = env.step(action)
        total_reward += reward
        
        # Update the Q-value
        Q[state, action] = Q[state, action] + alpha * (reward + gamma * np.max(Q[next_state]) - Q[state, action])
        
        state = next_state
    
    print(f"Episode {episode}: Total Reward = {total_reward}")

# Close the environment
env.close()
```

```
Episode 1: Total Reward = 204
Episode 2: Total Reward = 207
...
```

#### 4. Natural Language Processing (NLP)

Natural Language Processing (NLP) is a subfield of AI that focuses on the interaction between computers and human language. NLP techniques enable machines to understand, process, and generate human language, making them invaluable for applications like sentiment analysis, machine translation, and text summarization.

**Example: Sentiment Analysis**

Sentiment analysis is the process of identifying the sentiment expressed in a piece of text, classifying it as positive, negative, or neutral.

**Mathematical Model:**

Sentiment analysis typically involves training a machine learning model on labeled data, where the sentiment of each text is known. The model learns to predict the sentiment of new, unseen text based on its features.

**Application: Customer Feedback Analysis**

Consider a dataset containing customer reviews, where each review is labeled with its sentiment (positive, negative, or neutral). By applying sentiment analysis, we can analyze customer feedback and identify areas for improvement.

**Python Code Example:**

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB

# Load dataset
X = np.array(["I love this product!", "This is the worst purchase I've ever made.", "It's okay, not great, not terrible."])
y = np.array([1, 0, 0])

# Create and train the sentiment analysis model
vectorizer = TfidfVectorizer()
X_vectorized = vectorizer.fit_transform(X)

model = MultinomialNB()
model.fit(X_vectorized, y)

# Predict the sentiment of a new review
new_review = ["This is a great product!"]
new_review_vectorized = vectorizer.transform(new_review)
predicted_sentiment = model.predict(new_review_vectorized)
print(f"The predicted sentiment of the new review is: {'Positive' if predicted_sentiment[0] == 1 else 'Negative'}")
```

**Output:**

```
The predicted sentiment of the new review is: Positive
```

By analyzing historical sales data, customer behavior, and market trends, AI can generate a predictive model that accurately forecasts future sales. This enables the company to optimize its inventory levels, plan marketing campaigns, and allocate resources effectively.

**Technique: Time Series Forecasting**

Time series forecasting is a key technique used in predictive analytics. It involves analyzing time-based data to predict future values based on past trends and patterns. AI algorithms like Long Short-Term Memory (LSTM) networks, which are a type of recurrent neural network (RNN), are particularly effective for time series forecasting.

**Mathematical Model:**

$$ y_t = \sum_{i=1}^n w_i h_t [x_t - i] + b $$

where \( y_t \) is the predicted value at time \( t \), \( w_i \) are the weights, \( h_t \) is the hidden state at time \( t \), \( x_t \) is the input at time \( t \), and \( b \) is the bias term.

**Python Code Example:**

```python
import numpy as np
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense

# Load time series data
X = np.array([[1], [2], [3], [4], [5], [6]])
y = np.array([2, 4, 6, 8, 10, 12])

# Create and train the LSTM model
model = Sequential([
    LSTM(50, activation='relu', input_shape=(1, 1)),
    Dense(1)
])

model.compile(optimizer='adam', loss='mse')
model.fit(X, y, epochs=200)

# Predict future values
```
