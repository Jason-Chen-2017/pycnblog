#### 3.3 监测算法案例

通过Python代码示例，详细阐述一个简单的情感分析算法，并使用LaTeX公式来表示其数学模型。

```python
# Python 示例代码：情感分析算法
def sentiment_analysis(text):
    # 简单的情感分析算法：判断文本中正面词汇的比例
    positive_words = ["好", "棒", "优秀"]
    positive_count = 0
    
    for word in text.split():
        if word in positive_words:
            positive_count += 1
            
    return "正面" if (positive_count / len(text.split())) > 0.5 else "负面"

# 测试文本
text = "这个产品非常好，性价比高，非常棒！但是价格有点贵。"
result = sentiment_analysis(text)
print(result)
```
