#### 2.1 智能材料

##### 2.1.1 定义与特点

智能材料是指能够感知环境变化，并根据环境变化自动调整其物理、化学或力学特性的材料。这些材料具有感知、响应和自适应的特性，可以用于自动控制、自适应结构、可穿戴设备、生物医疗等多个领域。

**定义**：智能材料是一类具有特定功能的材料，它们在特定的外界刺激（如光、电、热、力、磁等）下能够改变其形状、结构、光学、电学、磁学等特性。

**特点**：
1. **感知性**：智能材料能够感知外部环境的变化。
2. **响应性**：材料能够对感知到的外部刺激做出响应，调整其物理或化学特性。
3. **自适应性和自修复性**：材料能够根据外部刺激自适应调整，并在受到损伤后自我修复。

**属性特征对比表格**：

| 特性        | 智能材料                | 传统材料                |
| ----------- | ---------------------- | ---------------------- |
| 感知性      | 能够感知外部环境变化    | 无感知能力              |
| 响应性      | 对外部刺激有响应        | 无响应能力              |
| 自适应性     | 能够根据环境变化调整特性 | 不能调整，固定特性      |
| 自修复性     | 能够自我修复损伤        | 需外部修复              |

##### 2.1.2 智能材料的基本分类

智能材料可以按照其感知和响应特性进行分类：

1. **基于物理效应的智能材料**：这类材料通过物理变化（如形状、体积、颜色等）来响应外部刺激。例如，形状记忆合金、电致变色材料等。
2. **基于化学效应的智能材料**：这类材料通过化学反应来响应外部刺激，如pH敏感材料、溶剂响应性材料等。
3. **基于生物效应的智能材料**：这类材料通过与生物体的相互作用来响应外部刺激，如生物相容性材料、生物降解材料等。

##### 2.1.3 智能材料的发展历程

智能材料的研究可以追溯到20世纪60年代。自那时以来，随着材料科学、微电子技术、计算机技术和生物技术的快速发展，智能材料的研究得到了极大的推动。以下是智能材料的发展历程：

1. **初创阶段（20世纪60年代-70年代）**：在这个阶段，研究人员开始探索材料的响应性，如形状记忆合金和电致变色材料。
2. **发展阶段（20世纪80年代-90年代）**：随着传感器技术的进步，智能材料的应用领域开始扩展，包括自适应结构、柔性电子、可穿戴设备等。
3. **成熟阶段（21世纪以来）**：智能材料的应用研究不断深入，其性能和功能得到了显著提升，例如，智能涂层、智能纺织品、智能生物医学材料等。

#### 2.2 自修复材料

##### 2.2.1 定义与特点

自修复材料是指能够在受到损伤后自动恢复其原有性能的材料。这种修复过程可以是化学的、物理的或生物的，修复机制可以是内源性的或外源性的。

**定义**：自修复材料是一类具有自我修复损伤能力的材料，它们能够在没有外部干预的情况下，通过内在的化学、物理或生物过程修复其损伤。

**特点**：
1. **自修复性**：材料能够在损伤发生后自动修复。
2. **自诊断性**：材料能够检测到损伤的发生。
3. **自适应性**：材料能够根据损伤的性质和程度调整修复策略。

**属性特征对比表格**：

| 特性        | 自修复材料                | 传统材料                |
| ----------- | ---------------------- | ---------------------- |
| 自修复性     | 能够自我修复损伤        | 需外部修复              |
| 自诊断性     | 能够检测到损伤发生      | 无法检测损伤            |
| 自适应性     | 能够根据损伤调整修复策略 | 无法调整，固定修复策略 |

##### 2.2.2 自修复材料的种类

自修复材料可以按照修复机制和材料类型进行分类：

1. **基于化学机理的自修复材料**：这类材料通过化学反应来修复损伤。例如，环氧树脂-胺基固化体系。
2. **基于物理机理的自修复材料**：这类材料通过物理过程（如熔融、结晶等）来修复损伤。例如，形状记忆合金。
3. **基于生物机理的自修复材料**：这类材料模仿生物组织的自我修复机制，利用生物分子进行修复。例如，生物凝胶。

##### 2.2.3 自修复材料的发展现状

自修复材料的研究在过去几十年中取得了显著进展。目前，自修复材料已经广泛应用于航空航天、汽车制造、建筑、生物医疗等领域。然而，自修复材料的实际应用还面临着一些挑战，如修复效率、成本、持久性等问题。

1. **技术突破**：近年来，随着纳米技术、高分子材料、复合材料等领域的快速发展，自修复材料的性能得到了显著提升。
2. **应用拓展**：自修复材料在航空航天领域的应用逐渐增多，如飞机外壳的自修复涂层；在汽车制造领域的应用也逐渐显现，如轮胎的自修复技术。
3. **研究热点**：目前，自修复材料的研究热点包括提高自修复效率、降低成本、实现多功能化等。
