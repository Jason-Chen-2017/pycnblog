\text{Attention}(Q, K, V) = \frac{QK^T}{\sqrt{d_k}} \odot V

**3.4.2 自适应学习率公式**

$$
\alpha(t) = \frac{\alpha(0)}{(1 - \beta_1)(1 - \beta_2)t^{1 - \beta_2}}
$$

其中，$\alpha(t)$表示第$t$个时间步的自适应学习率，$\alpha(0)$表示初始学习率，$\beta_1$和$\beta_2$分别表示一阶和二阶矩估计的指数衰减率。

**3.4.3 多任务学习公式**

$$
J(\theta) = \frac{1}{N} \sum_{i=1}^N \left[ -y_i \log(\hat{y}_i) - (1 - y_i) \log(1 - \hat{y}_i) \right]
$$

其中，$J(\theta)$表示多任务损失函数，$\theta$表示模型参数，$N$表示样本数量，$y_i$和$\hat{y}_i$分别表示第$i$个样本的真实标签和预测标签。

**3.4.4 LSTM模型公式**

$$
i_t = \sigma(W_{xi}x_t + W_{hi}h_{t-1} + b_i)
$$

$$
f_t = \sigma(W_{xf}x_t + W_{hf}h_{t-1} + b_f)
$$

$$
\hat{c}_t = f_t \odot c_{t-1} + i_t \odot \tanh(W_{xc}x_t + W_{hc}h_{t-1} + b_c)
$$

$$
o_t = \sigma(W_{xo}x_t + W_{ho}h_{t-1} + b_o)
$$

$$
h_t = o_t \odot \tanh(\hat{c}_t)
$$

其中，$x_t$、$h_{t-1}$和$c_{t-1}$分别表示当前时间步的输入、隐藏状态和细胞状态，$i_t$、$f_t$、$\hat{c}_t$和$o_t$分别表示输入门、遗忘门、更新门和输出门的状态，$\sigma$表示sigmoid函数，$\odot$表示点积运算。

**3.4.5 词向量公式**

$$
\text{Word2Vec} = \sum_{i=1}^V w_i v_i
$$

其中，$V$表示词汇表大小，$w_i$和$v_i$分别表示第$i$个单词的权重和向量表示。

    model = Sequential()
    model.add(Embedding(10000, 256))
    model.add(LSTM(256, return_sequences=True))
    model.add(Dense(256, activation='relu'))
    model.add(Dense(10000, activation='softmax'))
    model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])
    model.fit(padded_sequences, padded_sequences, epochs=epochs, batch_size=batch_size)
    return model

# 文本生成

    input_seq = [tokenizer.word_index.get(word) for word in tokenizer.texts_to_sequences(['I love programming'])[0]]
    input_seq = pad_sequences([input_seq], maxlen=max_length-1, padding='pre')
    predictions = model.predict(input_seq, verbose=0)
    output_seq = []
    for i in range(max_length):
        if np.argmax(predictions[i]) == tokenizer.word_index['<PAD>']:
            break
        output_seq.append(tokenizer.index_word[np.argmax(predictions[i])])
        predictions[i] = np.zeros(10000) + (1 / (i + 1))
    return ' '.join(output_seq)

# 主函数
def main():
    text_data = ['I love programming', 'I enjoy coding', 'Coding is fun', 'Programming is exciting']
    padded_sequences, tokenizer = preprocess_text(text_data)
    model = train_model(padded_sequences, epochs=10, batch_size=64)
    generated_text = generate_text(model, tokenizer)
    print("Generated text:", generated_text)

if __name__ == '__main__':
    main()
