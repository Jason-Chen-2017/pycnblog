以下是一个简单的Python代码示例，用于模拟心率监测的数据处理过程：

```python
import numpy as np
from scipy.signal import find_peaks

def calculate_heart_rate(signal):
    # 模拟采集到的心率信号
    signal = np.random.normal(0.5, 0.1, 1000)
    # 滤波和放大
    filtered_signal = np.mean(signal, axis=0)
    # 找到信号峰值
    peaks, _ = find_peaks(filtered_signal)
    # 计算心率
    heart_rate = len(peaks) / (1000 / 60)  # 转换为每分钟的心率
    return heart_rate
```
