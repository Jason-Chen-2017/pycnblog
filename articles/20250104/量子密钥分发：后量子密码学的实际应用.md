## 量子密钥分发原理

### 2.1 量子态与量子纠缠

#### 2.1.1 量子态的基本概念
量子态是量子系统的一种状态描述，它可以用波函数或态向量表示。在量子通信中，量子态的编码是实现量子密钥分发的基础。

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle
$$

其中，$|\psi\rangle$ 表示量子态，$|0\rangle$ 和 $|1\rangle$ 分别表示基态和激发态，$\alpha$ 和 $\beta$ 是复数系数。

#### 2.1.2 量子态的表示与操作
量子态可以通过量子比特（qubit）来表示，量子比特是量子信息的基本单位，它有两个叠加态：

$$
|q\rangle = \frac{1}{\sqrt{2}} (|0\rangle + |1\rangle)
$$

量子态的操作包括量子门（quantum gate）的应用，量子门是用于操纵量子比特的线性算符。

#### 2.1.3 量子纠缠的基本特性
量子纠缠是量子系统中两个或多个粒子之间的特殊关联关系，它表现为量子态的不可分割性和远程作用。量子纠缠是量子密钥分发技术实现安全性的关键。

$$
|\psi_{AB}\rangle = \frac{1}{\sqrt{2}} (|00\rangle + |11\rangle)
$$

#### 2.1.4 量子态与量子纠缠的应用
量子态与量子纠缠在量子密钥分发中起着至关重要的作用。它们被用于实现量子密钥的编码、传输和检测，确保密钥的分发过程安全可靠。

### 2.2 量子密钥分发协议

#### 2.2.1 BB84协议
BB84协议是第一个被提出的量子密钥分发协议，它基于量子态的不可克隆性和量子纠缠。协议的基本原理如下：

1. 发送方生成一对量子纠缠光子对。
2. 发送方对其中一个光子进行随机基底变换，并将其发送给接收方。
3. 接收方对收到的光子进行相同的基底测量，并记录结果。
4. 发送方和接收方通过经典通信渠道比较测量结果，确定共享的密钥。

#### 2.2.2 E91协议
E91协议是基于量子纠缠和量子不确定关系的另一种量子密钥分发协议。与BB84协议相比，E91协议在安全性和传输距离上有一定的优势。

协议的基本原理如下：

1. 发送方生成一对量子纠缠光子对。
2. 发送方对其中一个光子进行随机极化旋转，并将其发送给接收方。
3. 接收方对收到的光子进行相同的极化旋转，并记录结果。
4. 发送方和接收方通过经典通信渠道比较测量结果，确定共享的密钥。

```python
from pyqkd import QuantumKeyGenerator

def generate_quantum_key():
    qkg = QuantumKeyGenerator()
    qubits = qkg.generate_quantum_bits(100)  # 生成100个量子比特
    key = qkg.encode_quantum_bits(qubits)  # 编码量子比特为密钥
    return key

key = generate_quantum_key()
print("生成的量子密钥：", key)
```
