# 第3章：数学模型与数学公式

## 3.1 损失函数
知识蒸馏算法中的损失函数通常包括两部分：教师模型输出与学生模型输出之间的损失，以及学生模型输出与真实标签之间的损失。

### 3.1.1 软标签损失函数
软标签损失函数可以表示为：

$$
L_{soft} = -\sum_{i=1}^{N} \sum_{j=1}^{C} y_{ij} \log(\hat{y}_{ij})
$$

其中，$y_{ij}$ 表示真实标签，$\hat{y}_{ij}$ 表示学生模型的输出概率。

### 3.1.2 平方损失函数
平方损失函数可以表示为：

$$
L_{square} = \frac{1}{2} \sum_{i=1}^{N} \sum_{j=1}^{C} (\hat{y}_{ij} - y_{ij})^2
$$

其中，$y_{ij}$ 表示真实标签，$\hat{y}_{ij}$ 表示学生模型的输出概率。

## 3.2 优化算法
在知识蒸馏算法中，常用的优化算法包括梯度下降法（Gradient Descent）和随机梯度下降法（Stochastic Gradient Descent）。

### 3.2.1 梯度下降法
梯度下降法的更新规则可以表示为：

$$
\theta_{t+1} = \theta_{t} - \alpha \nabla_{\theta} J(\theta)
$$

其中，$\theta$ 表示模型参数，$\alpha$ 表示学习率，$J(\theta)$ 表示损失函数。

### 3.2.2 随机梯度下降法
随机梯度下降法的更新规则可以表示为：

$$
\theta_{t+1} = \theta_{t} - \alpha \nabla_{\theta} J(\theta; x_i, y_i)
$$

其中，$\theta$ 表示模型参数，$\alpha$ 表示学习率，$J(\theta; x_i, y_i)$ 表示在单个样本上的损失函数。

## 3.1 损失函数
知识蒸馏算法中的损失函数通常包括两部分：教师模型输出与学生模型输出之间的损失，以及学生模型输出与真实标签之间的损失。

### 3.1.1 软标签损失函数
软标签损失函数可以表示为：

$$
L_{soft} = -\sum_{i=1}^{N} \sum_{j=1}^{C} y_{ij} \log(\hat{y}_{ij})
$$

其中，$y_{ij}$ 表示真实标签，$\hat{y}_{ij}$ 表示学生模型的输出概率。

### 3.1.2 平方损失函数
平方损失函数可以表示为：

$$
L_{square} = \frac{1}{2} \sum_{i=1}^{N} \sum_{j=1}^{C} (\hat{y}_{ij} - y_{ij})^2
$$

其中，$y_{ij}$ 表示真实标签，$\hat{y}_{ij}$ 表示学生模型的输出概率。

## 3.2 优化算法
在知识蒸馏算法中，常用的优化算法包括梯度下降法（Gradient Descent）和随机梯度下降法（Stochastic Gradient Descent）。

### 3.2.1 梯度下降法
梯度下降法的更新规则可以表示为：

$$
\theta_{t+1} = \theta_{t} - \alpha \nabla_{\theta} J(\theta)
$$

其中，$\theta$ 表示模型参数，$\alpha$ 表示学习率，$J(\theta)$ 表示损失函数。

### 3.2.2 随机梯度下降法
随机梯度下降法的更新规则可以表示为：

$$
\theta_{t+1} = \theta_{t} - \alpha \nabla_{\theta} J(\theta; x_i, y_i)
$$

其中，$\theta$ 表示模型参数，$\alpha$ 表示学习率，$J(\theta; x_i, y_i)$ 表示在单个样本上的损失函数。

    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

train_dataset = datasets.ImageFolder(root='train', transform=transform)
train_loader = torch.utils.data.DataLoader(dataset=train_dataset, batch_size=batch_size, shuffle=True)

### 4.4.2 模型训练

在训练过程中，我们使用教师模型的软标签来训练学生模型，以实现轻量级评测模型的设计。

```python
# 模型训练
for epoch in range(num_epochs):
    for batch in train_loader:
        # 前向传播
        teacher_output = teacher_model(batch)
        soft_labels = torch.nn.functional.softmax(teacher_output, dim=1)
        
        # 前向传播学生模型
        student_output = student_model(batch)
        
        # 计算损失函数
        loss = torch.nn.functional.mse_loss(student_output, soft_labels)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```
