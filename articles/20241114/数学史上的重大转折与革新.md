#### 1.3 数学史上的重大转折与革新

数学史上的重大转折与革新包括：

1. **阿基米德的贡献**：在几何学和流体力学方面的开创性工作，特别是在面积和体积的计算以及浮力原理方面的贡献。
2. **牛顿和莱布尼茨的微积分**：微积分的发明是数学史上的一次重大飞跃，它不仅推动了物理学和工程学的发展，也改变了数学本身。
3. **复数的诞生**：复数解决了实数范围内无法解决的问题，使得数学理论更加完善。
4. **集合论的奠基**：集合论为数学提供了坚实的基础，解决了数学基础问题。

**数学公式与详细讲解**：

$$
// 牛顿-莱布尼茨公式：微积分基本定理
\int_{a}^{b} f(x) \, dx = F(b) - F(a)
$$

其中，\( f(x) \) 是被积函数，\( F(x) \) 是其原函数，\( a \) 和 \( b \) 是积分区间。

**举例说明**：计算函数 \( f(x) = x^2 \) 在区间 \([1, 3]\) 上的定积分。

$$
\int_{1}^{3} x^2 \, dx = \left[ \frac{x^3}{3} \right]_{1}^{3} = \frac{3^3}{3} - \frac{1^3}{3} = 9 - \frac{1}{3} = \frac{26}{3}
$$

**项目实战**：构建一个简单的微积分计算器，使用牛顿-莱布尼茨公式计算定积分。

**源代码实现**：
```python
import numpy as np

def integral(f, a, b):
    return np.integrate.quad(f, a, b)[0]

def main():
    f = lambda x: x**2
    a = 1
    b = 3
    result = integral(f, a, b)
    print(f"Integral of {f} from {a} to {b} is {result}")

if __name__ == "__main__":
    main()
```

**代码解读**：
- 使用 NumPy 库的 `integrate.quad` 函数计算定积分。
- `integral` 函数接受被积函数 `f`、积分区间起点 `a` 和终点 `b`，并返回积分结果。
- `main` 函数定义了一个二次函数，设置了积分区间，并调用 `integral` 函数计算积分。

**实际案例分析**：使用这个微积分计算器计算不同函数的定积分，并验证结果。
