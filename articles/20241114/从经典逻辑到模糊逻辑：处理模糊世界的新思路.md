## 第一部分 经典逻辑基础

### 2.1 经典逻辑的基本概念

#### 2.1.1 经典逻辑的定义

经典逻辑，也称为形式逻辑，是研究命题、推理和证明的数学分支。它主要包括命题逻辑、谓词逻辑和数理逻辑。

#### 2.1.2 经典逻辑的基本原理

- **命题逻辑**：命题逻辑是研究命题和命题之间的逻辑关系的学科。命题是具有真假值的陈述，通常用大写字母表示。联结词（如“与”、“或”、“非”）用于组合命题，形成更复杂的命题。
  
  **真值表**：真值表是用于表示命题逻辑中各个命题的真值情况的表格。例如，对于命题“p且q”（记作$p \land q$），其真值表如下：
  
  ```  
  | p | q | p ∧ q |
  |---|---|-------|
  | T | T |   T  |
  | T | F |   F  |
  | F | T |   F  |
  | F | F |   F  |
  ```

- **谓词逻辑**：谓词逻辑是研究谓词和谓词之间关系的学科。谓词是关于个体的陈述，通常用小写字母表示。量化符号（如全称量词$\forall$和存在量词$\exists$）用于表示谓词的普遍性或存在性。

  **例子**：谓词逻辑中的一个例子是“所有的猫都会飞”。用谓词表示为$\forall x (P(x))$，其中$P(x)$表示“x会飞”，$x$表示猫。

- **数理逻辑**：数理逻辑是研究数学对象和数学证明的学科。形式系统是一种数学模型，用于表示逻辑语言中的命题和推理规则。证明理论是研究如何从一个或多个前提出出结论的学科。

  **例子**：在形式系统中，一个命题可以用符号表示，并通过推理规则进行证明。例如，命题$p \land q \Rightarrow q$可以通过以下推理规则证明：
  
  ```  
  1.  p ∧ q    （前提）
  2.  q        （1简化）
  3.  p ∧ q \Rightarrow q    （2蕴含）
  ```

### 2.2 经典逻辑的数学模型

#### 2.2.1 真值表

真值表是用于表示命题逻辑中各个命题的真值情况的表格。例如，对于命题“p且q”（记作$p \land q$），其真值表如下：

```

|---|---|-------|

```

#### 2.2.2 推理规则

推理规则是用于从已知命题推导出新命题的规则。常见的推理规则包括：
- **简化规则**：如果命题$p \land q$为真，则$p$和$q$都为真。
- **蕴含规则**：如果命题$p \land q$为真，则$q$蕴含$p$。
- **逆否规则**：如果命题$p \Rightarrow q$为真，则$\neg q \Rightarrow \neg p$也为真。

#### 2.2.3 真值函数

真值函数是一种数学函数，它将命题逻辑中的各个命题映射到它们的真值。例如，命题“p且q”（记作$p \land q$）的真值函数如下：

        return True
    else:
        return False

- **命题逻辑**：命题逻辑是研究命题和命题之间的逻辑关系的学科。命题是具有真假值的陈述，通常用大写字母表示。联结词（如“与”、“或”、“非”）用于组合命题，形成更复杂的命题。

  **真值表**：真值表是用于表示命题逻辑中各个命题的真值情况的表格。例如，对于命题“p且q”（记作$p \land q$），其真值表如下：

  ```  
  | p | q | p ∧ q |
  |---|---|-------|
  | T | T |   T  |
  | T | F |   F  |
  | F | T |   F  |
  | F | F |   F  |
  ```

- **谓词逻辑**：谓词逻辑是研究谓词和谓词之间关系的学科。谓词是关于个体的陈述，通常用小写字母表示。量化符号（如全称量词$\forall$和存在量词$\exists$）用于表示谓词的普遍性或存在性。

  **例子**：谓词逻辑中的一个例子是“所有的猫都会飞”。用谓词表示为$\forall x (P(x))$，其中$P(x)$表示“x会飞”，$x$表示猫。

- **数理逻辑**：数理逻辑是研究数学对象和数学证明的学科。形式系统是一种数学模型，用于表示逻辑语言中的命题和推理规则。证明理论是研究如何从一个或多个前提出出结论的学科。

  **例子**：在形式系统中，一个命题可以用符号表示，并通过推理规则进行证明。例如，命题$p \land q \Rightarrow q$可以通过以下推理规则证明：

  ```  
  1.  p ∧ q    （前提）
  2.  q        （1简化）
  3.  p ∧ q \Rightarrow q    （2蕴含）
  ```

#### 2.2.1 真值表

#### 2.2.2 推理规则

推理规则是用于从已知命题推导出新命题的规则。常见的推理规则包括：
- **简化规则**：如果命题$p \land q$为真，则$p$和$q$都为真。
- **蕴含规则**：如果命题$p \land q$为真，则$q$蕴含$p$。
- **逆否规则**：如果命题$p \Rightarrow q$为真，则$\neg q \Rightarrow \neg p$也为真。

#### 2.2.3 真值函数

真值函数是一种数学函数，它将命题逻辑中的各个命题映射到它们的真值。例如，命题“p且q”（记作$p \land q$）的真值函数如下：
