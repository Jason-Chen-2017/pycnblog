### 5.1 伽利略的自由落体实验

伽利略通过设想和实验，提出了自由落体运动的规律。他的实验表明，在真空中，所有物体下落的加速度是相同的，与物体的质量无关。这一规律可以用以下数学公式表示：

$$ a = g $$

其中，`a` 代表加速度，`g` 代表重力加速度（在地球表面约为 9.8 m/s²）。

#### 5.1.1 数学公式解析

这个公式表示，在自由落体过程中，加速度 `a` 是恒定的，并且等于重力加速度 `g`。这意味着，不论物体的质量大小，它们在相同高度下自由落体的时间是相同的。

#### 5.1.2 实例说明

假设一个物体从高度 `h` 自由落体，要计算它落地所需的时间 `t`，可以使用以下公式：

$$ t = \sqrt{\frac{2h}{g}} $$

例如，如果物体从高度 100 米自由落体，落地所需时间约为：

$$ t = \sqrt{\frac{2 \times 100}{9.8}} \approx 4.52 秒 $$

### 5.2 牛顿的万有引力定律

牛顿通过设想行星运动，提出了万有引力定律，描述了两个物体之间的引力关系。这一定律可以用以下数学公式表示：

$$ F = G \frac{m1 \times m2}{r^2} $$

其中，`F` 是引力的大小，`G` 是引力常数，`m1` 和 `m2` 是两个物体的质量，`r` 是它们之间的距离。

#### 5.2.1 数学公式解析

这个公式表示，两个物体之间的引力与它们的质量的乘积成正比，与它们之间距离的平方成反比。这揭示了引力作为一种远程作用力的性质。

#### 5.2.2 实例说明

例如，计算地球和月球之间的引力大小。已知地球质量 `M1` 为 \(5.972 \times 10^{24} kg\)，月球质量 `M2` 为 \(7.348 \times 10^{22} kg\)，地月距离 `R` 为 \(3.844 \times 10^{8} m\)，则引力大小 `F` 可以通过以下公式计算：

$$ F = G \frac{M1 \times M2}{R^2} = 6.674 \times 10^{-11} \frac{5.972 \times 10^{24} \times 7.348 \times 10^{22}}{(3.844 \times 10^{8})^2} \approx 1.989 \times 10^{20} N $$

### 5.3 爱因斯坦的广义相对论

爱因斯坦的广义相对论提出了引力不是物体之间的相互作用，而是物质对时空的弯曲。这一理论可以用以下数学公式表示：

$$ g_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu} $$

其中，`g_{\mu\nu}` 是度规张量，`$\Lambda$` 是宇宙学常数，`G` 是引力常数，`c` 是光速，`T_{\mu\nu}` 是能量-动量张量。

#### 5.3.1 数学公式解析

这个公式是爱因斯坦场方程的核心，它描述了物质和能量如何影响时空的几何结构。度规张量 `g_{\mu\nu}` 描述了时空的曲率，而能量-动量张量 `T_{\mu\nu}` 描述了物质和能量在时空中的分布。

#### 5.3.2 实例说明

例如，计算地球附近的空间时间弯曲。已知地球质量 `M` 为 \(5.972 \times 10^{24} kg\)，地球半径 `R` 为 \(6.371 \times 10^{6} m\)，可以使用以下公式估计引力引起的时空弯曲：

$$ \Delta g_{tt} = -\frac{2GM}{R c^2} $$

代入数据计算得到：

$$ \Delta g_{tt} = -\frac{2 \times 6.674 \times 10^{-11} \times 5.972 \times 10^{24}}{6.371 \times 10^{6} \times (3 \times 10^{8})^2} \approx -5.93 \times 10^{-11} s^{-2} $$

这意味着地球的引力使得时空在地球表面附近弯曲了 \(5.93 \times 10^{-11} s^{-2}\)。

### 6.3 源代码实现

以下是实现牛顿万有引力模拟的Python源代码：

```python
import numpy as np
import matplotlib.pyplot as plt

# 引力常数
G = 6.674 * 10^-11

# 物体属性
m1 = 5.972 * 10^24  # 地球质量
m2 = 7.348 * 10^22  # 月球质量
r0 = 3.844 * 10^8   # 地月距离

# 初始条件
x1 = 0
y1 = 0
vx1 = 0
vy1 = 30 * 1000    # 月球绕地球的初始速度

x2 = r0
y2 = 0
vx2 = -vx1
vy2 = vy1

# 时间步长和总时间
dt = 1000
t_max = 1000000

# 运动方程
def gravity_force(x1, y1, x2, y2, m1, m2):
    r = np.sqrt((x2 - x1)**2 + (y2 - y1)**2)
    F = G * m1 * m2 / r**2
    return F

def update_position(x1, y1, vx1, vy1, x2, y2, vx2, vy2, dt):
    F1x, F1y = 0, 0
    F2x, F2y = 0, 0
    
    F = gravity_force(x1, y1, x2, y2, m1, m2)
    F1x += F * (x2 - x1) / r
    F1y += F * (y2 - y1) / r
    
    F = gravity_force(x2, y2, x1, y1, m2, m1)
    F2x += F * (x1 - x2) / r
    F2y += F * (y1 - y2) / r
    
    vx1 -= F1x / m1 * dt
    vy1 -= F1y / m1 * dt
    x1 += vx1 * dt
    y1 += vy1 * dt
    
    vx2 -= F2x / m2 * dt
    vy2 -= F2y / m2 * dt
    x2 += vx2 * dt
    y2 += vy2 * dt

# 模拟运行
times = []
x1s = []
y1s = []
x2s = []
y2s = []

for t in range(int(t_max / dt)):
    times.append(t * dt)
    x1s.append(x1)
    y1s.append(y1)
    x2s.append(x2)
    y2s.append(y2)
    
    update_position(x1, y1, vx1, vy1, x2, y2, vx2, vy2, dt)

# 绘制结果
plt.plot(times, x1s, label="Moon")
plt.plot(times, x2s, label="Earth")
plt.xlabel("Time (s)")
plt.ylabel("Position (m)")
plt.legend()
plt.show()
```

### 6.4 代码解读

1. **引力计算**：`gravity_force` 函数计算两个物体之间的引力大小。根据牛顿的万有引力定律，引力与物体质量乘积成正比，与它们之间距离的平方成反比。
2. **位置更新**：`update_position` 函数根据引力和物体的初始条件更新物体的位置和速度。这个函数使用了数值积分方法，每次迭代都根据力的变化来更新速度和位置。
3. **模拟运行**：主程序通过循环调用`update_position` 函数来模拟物体的运动，并记录每次迭代的时间和位置。
