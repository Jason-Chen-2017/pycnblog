## 第一部分：咖啡文化概述

### 第1章：咖啡文化概述

咖啡文化的起源可以追溯到中东地区，特别是在也门。传说在9世纪的也门，一位名叫卡尔丁的僧侣在漫步时，注意到僧侣们在饮用一种神秘的植物饮品后显得格外精神。这种植物就是咖啡豆。随着时间的推移，咖啡逐渐传播到世界各地，成为了一种普遍的饮品。

#### 1.1 咖啡的起源与传播

咖啡的起源地被认为是非洲的埃塞俄比亚。据传说，当地的牧羊人注意到他们的羊在食用了特定种类的果实后变得异常活跃。这些果实后来被发现是咖啡豆。公元9世纪，阿拉伯的商人将咖啡豆带到了中东，并迅速在阿拉伯世界流行起来。在阿拉伯，咖啡不仅成为了一种饮品，更成为一种社交活动，咖啡馆成为了人们聚集交流的场所。

随着时间的推移，咖啡逐渐传播到了欧洲。16世纪的土耳其是欧洲最早引入咖啡的国家之一。随后，咖啡文化传入意大利，并在17世纪迅速传播到整个欧洲。到了18世纪，咖啡已经成为欧洲人生活中不可或缺的一部分。

#### 1.2 咖啡文化的影响

咖啡文化的传播对全球社会产生了深远的影响。首先，咖啡馆的兴起改变了人们的社交习惯。在咖啡馆里，人们不仅可以品尝到美味的咖啡，还可以进行社交活动，这种文化方式至今仍然流行。

其次，咖啡文化也促进了全球化的发展。咖啡贸易成为了一种重要的经济活动，推动了全球贸易和文化的交流。咖啡豆的运输和销售使得不同的文化相互影响，促进了文化交流和融合。

此外，咖啡文化也影响了饮食文化。咖啡的普及使得人们开始尝试不同的咖啡饮用方式和烘焙技巧，促进了咖啡文化和饮食文化的多样化。

## 第二部分：手工咖啡烘焙技术

### 第2章：咖啡生豆的选择与处理

#### 2.1 咖啡生豆的品种与产地

咖啡豆的种类繁多，不同品种的咖啡豆有着不同的特性。以下是一些主要的咖啡豆品种及其产地：

- **阿拉比卡（Arabica）**：阿拉比卡咖啡豆是市面上最常见的咖啡豆品种，产于埃塞俄比亚、哥伦比亚、巴西等国家。阿拉比卡咖啡豆味道较为丰富，口感柔和，酸度适中。
- **罗布斯塔（Robusta）**：罗布斯塔咖啡豆产量较高，耐寒性强，主要产于非洲和亚洲地区。罗布斯塔咖啡豆口感较为强烈，苦味较重。
- **蓝山（Blue Mountain）**：蓝山咖啡豆产于牙买加，是世界上品质最高的咖啡豆之一。蓝山咖啡豆味道独特，酸度较低，口感柔和。
- **耶加雪菲（Yirgacheffe）**：耶加雪菲咖啡豆产于埃塞俄比亚，以其鲜明的花香和柑橘味道而闻名。

每种咖啡豆都有其独特的风味和特性，选择适合的咖啡豆是手工咖啡烘焙的第一步。

#### 2.2 咖啡生豆的处理方法

咖啡生豆的处理方法主要包括水洗法、坚果法、日晒法等。每种方法都有其独特的步骤和特点：

- **水洗法**：水洗法是一种较为常见的处理方法，主要步骤包括去果肉、浸泡、脱皮、晾干等。水洗法处理的咖啡豆酸度较高，口感清新。
- **坚果法**：坚果法也称为干法处理，主要步骤包括将咖啡豆与果肉一起晾干。坚果法处理的咖啡豆口感较为浓郁，带有坚果味。
- **日晒法**：日晒法是一种传统的处理方法，主要步骤包括将咖啡豆摊放在晒场上晾干。日晒法处理的咖啡豆酸度适中，口感柔和。

不同的处理方法会直接影响咖啡豆的风味和品质，因此在烘焙过程中需要根据处理方法进行适当的调整。

### 第3章：烘焙工具与设备

#### 3.1 烘焙设备的选择

选择适合的烘焙设备对于烘焙咖啡豆至关重要。以下是一些常见的烘焙设备及其特点：

- **热风烘焙机**：热风烘焙机通过高速热风将咖啡豆均匀加热，操作简单，适合初学者使用。
- **热盘烘焙机**：热盘烘焙机通过加热盘将咖啡豆直接加热，烘焙速度较快，但需要一定经验来控制。
- **真空烘焙机**：真空烘焙机通过真空环境减少咖啡豆的氧化，烘焙效果较好，但价格较高。

每种烘焙设备都有其优缺点，选择时应根据个人需求和预算进行。

#### 3.2 烘焙设备的维护与保养

烘焙设备的维护与保养对于延长设备寿命和保证烘焙质量至关重要。以下是一些常见的维护和保养方法：

- **定期清洁**：定期清洁烘焙机，包括去除残留咖啡豆、清理通风口等。
- **检查设备状态**：定期检查设备的电路和功能，确保设备运行正常。
- **存储设备**：将烘焙设备存放在干燥通风的环境中，避免受潮和阳光直射。

通过正确的维护和保养，可以延长烘焙设备的使用寿命，保证烘焙质量。

### 第4章：烘焙原理与参数

#### 4.1 烘焙过程中的物理变化

烘焙过程中的物理变化主要包括热传导、水分蒸发、化学变化等。以下是对这些物理变化的详细解释：

- **热传导**：在烘焙过程中，热量通过传导进入咖啡豆内部，使咖啡豆的温度逐渐升高。
- **水分蒸发**：咖啡豆中的水分在高温下蒸发，减少了咖啡豆的含水量，影响了咖啡豆的口感和风味。
- **化学变化**：在烘焙过程中，咖啡豆中的糖分和脂肪发生化学反应，产生了新的化合物，这些化合物赋予了咖啡豆特有的香气和口感。

#### 4.2 烘焙参数的设置与调整

烘焙参数的设置和调整对于烘焙效果至关重要。以下是一些重要的烘焙参数及其调整方法：

- **温度**：温度是烘焙过程中最重要的参数之一。合适的温度可以确保咖啡豆充分烘焙，避免过度或不足烘焙。
- **时间**：烘焙时间决定了咖啡豆的烘焙程度。过长或过短的烘焙时间都会影响咖啡豆的口感和风味。
- **风量**：风量决定了热风的速度和力度，影响了咖啡豆的热传导速度和烘焙均匀度。

通过调整这些参数，可以控制烘焙过程，实现理想烘焙效果。

#### 系统核心实现源代码

以下是一个简单的Flask Web接口代码，用于实现烘焙系统的核心功能：

```python
from flask import Flask, request, jsonify
import pymysql

app = Flask(__name__)

# 连接数据库
def connect_db():
    connection = pymysql.connect(
        host='localhost',
        user='root',
        password='',
        database='烘焙系统',
        charset='utf8mb4'
    )
    return connection

@app.route('/set_parameters', methods=['POST'])
def set_parameters():
    data = request.json
    temperature = data['temperature']
    time = data['time']
    coffee_seed = data['coffee_seed']
    
    connection = connect_db()
    cursor = connection.cursor()
    
    # 插入参数
    sql = "INSERT INTO parameters (temperature, time, coffee_seed) VALUES (%s, %s, %s)"
    cursor.execute(sql, (temperature, time, coffee_seed))
    
    connection.commit()
    cursor.close()
    connection.close()
    
    return jsonify({"status": "success"})

@app.route('/start_baking', methods=['POST'])
def start_baking():
    data = request.json
    temperature = data['temperature']
    time = data['time']
    coffee_seed = data['coffee_seed']
    
    connection = connect_db()
    cursor = connection.cursor()
    
    # 插入数据
    sql = "INSERT INTO data (temperature, time, coffee_seed, result) VALUES (%s, %s, %s, %s)"
    cursor.execute(sql, (temperature, time, coffee_seed, "baking"))
    
    connection.commit()
    cursor.close()
    connection.close()
    
    return jsonify({"status": "success"})

@app.route('/get_baking_result', methods=['GET'])
def get_baking_result():
    connection = connect_db()
    cursor = connection.cursor()
    
    # 查询数据
    sql = "SELECT * FROM data WHERE result = 'baking'"
    cursor.execute(sql)
    result = cursor.fetchall()
    
    cursor.close()
    connection.close()
    
    return jsonify(result)

if __name__ == '__main__':
    app.run(debug=True)
```
