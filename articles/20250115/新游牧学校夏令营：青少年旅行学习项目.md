## 第2章 核心概念与联系

### 2.1 游牧学校与普通学校

#### 2.1.1 游牧学校的定义

游牧学校是指以旅行、体验和实践为核心教育方式的一种学校形式。其特点在于将课堂延伸至户外，通过实地体验和实践活动，帮助学生更好地理解和应用所学知识。

#### 2.1.2 普通学校的定义

普通学校是指以课堂教学为主要方式，以传授知识为主要目的的学校。其特点在于在固定的教室和课程安排下，通过教师讲授和学生学习，实现知识的传递和积累。

#### 2.1.3 对比与联系

游牧学校和普通学校在教育方式、目标和学习体验上存在显著差异，但两者也存在一定的联系。例如，普通学校可以通过引入游牧学校的教学理念，开展更多的实践活动，以提高学生的学习兴趣和实际能力。

### 2.2 夏令营与研学旅行

#### 2.2.1 夏令营的定义

夏令营是指一种有组织的、在特定时间内进行的集体活动，通常以户外活动、游戏和社交为主。其目的是通过集体生活和团队合作，培养学生的独立性和团队合作精神。

#### 2.2.2 研学旅行的定义

研学旅行是指以学习、探索、实践为主要目的的旅行活动。其特点在于将学习和旅行相结合，通过实地考察和实践活动，提高学生的知识水平和实际能力。

#### 2.2.3 对比与联系

夏令营和研学旅行在活动形式和目的上有所区别，但两者都具有较强的教育意义和体验性。夏令营更注重学生的综合素质培养，而研学旅行则更侧重于知识的获取和应用。

#### 5.4.1 前端架构

前端采用 React 框架，实现用户界面的展示和交互。前端主要包括以下组件：

- **导航栏**：提供用户登录、注册、个人中心等入口。
- **课程列表**：展示所有课程的列表。
- **活动列表**：展示所有活动的列表。

- **评估结果**：展示学生的评估结果。

#### 5.4.2 后端架构

后端采用 Spring Boot 框架，实现业务逻辑和数据存储。后端主要包括以下模块：

- **用户模块**：处理用户注册、登录、个人信息管理等业务逻辑。
- **课程模块**：处理课程创建、编辑、删除等业务逻辑。
- **活动模块**：处理活动创建、编辑、删除等业务逻辑。
- **学生模块**：处理学生注册、信息管理、活动参与记录等业务逻辑。
- **评估模块**：处理学生评估、教师评估、总体评估等业务逻辑。
- **统计模块**：处理数据统计和分析等业务逻辑。

### 5.5 系统接口设计和系统交互

游牧学校夏令营管理平台通过 RESTful API 提供接口服务，支持前后端的数据交互。

#### 5.5.1 用户接口

- **注册**：POST `/users/register`，接收用户名、密码、邮箱等参数。
- **登录**：POST `/users/login`，接收用户名、密码等参数。
- **个人信息管理**：GET `/users/profile`，获取用户个人信息；PUT `/users/profile`，更新用户个人信息。

#### 5.5.2 课程接口

- **创建课程**：POST `/courses`，接收课程名称、描述、时间等参数。
- **编辑课程**：PUT `/courses/{id}`，更新课程信息。
- **删除课程**：DELETE `/courses/{id}`，删除课程。

#### 5.5.3 活动接口

- **创建活动**：POST `/events`，接收活动名称、描述、时间等参数。
- **编辑活动**：PUT `/events/{id}`，更新活动信息。
- **删除活动**：DELETE `/events/{id}`，删除活动。

#### 5.5.4 学生接口

- **注册学生**：POST `/students/register`，接收学生姓名、年龄、班级等参数。
- **信息管理**：GET `/students/profile`，获取学生个人信息；PUT `/students/profile`，更新学生个人信息。

#### 5.5.5 评估接口

- **学生评估**：POST `/assessments/students/{id}`，提交学生对活动的评估。
- **教师评估**：POST `/assessments/teachers/{id}`，提交教师对学生的评估。

#### 5.5.6 统计接口

- **学生参与情况**：GET `/stats/students`，获取学生参与活动的统计数据。
- **活动效果**：GET `/stats/events`，获取活动的效果统计数据。
- **资源利用**：GET `/stats/resources`，获取资源利用的统计数据。
