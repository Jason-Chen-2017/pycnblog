人际网络是指个体之间基于相互关系所形成的社交结构。它不仅包括直接的人际关系，如亲戚、朋友、同事，还包括间接的人际关系，如通过朋友的朋友建立的社交联系。

- **定义**：

  - **直接人际关系**：指直接认识并建立联系的人，例如家庭成员、朋友、同事等。
  - **间接人际关系**：通过朋友或朋友的熟人建立的联系，如“朋友的朋友”。

- **特点**：

  - **社交多样性**：人际网络中的成员可以来自不同的背景和领域，这种多样性使得信息交流和资源共享更加丰富。
  - **动态性**：人际网络是动态变化的，个体可以在不同的时间和场合建立或断裂联系。
  - **层次性**：人际网络可以划分为多个层次，如核心层、外围层等，每个层次的人际关系强度和密度不同。

- **类型**：

  - **强关系**：指关系紧密、相互信任的社交联系，如亲朋好友。
  - **弱关系**：指关系较疏远、但仍然有互动和信息的交换，如同事、熟人。

### 第2章：核心概念与联系

**2.1 社群动力学**

社群动力学是研究社群形成、演变及其内部成员互动机制的科学。它关注社群内部的结构变化、成员行为模式以及这些因素如何影响社群的稳定性和发展。

- **社群的形成与演变**：

  - **形成过程**：社群的形成通常源于共同兴趣、目标或需求，成员通过线上或线下的互动逐渐建立联系，形成稳定的社交网络。
  - **演变过程**：社群会随着时间、环境变化和成员动态而不断演变。例如，社群可能经历从初创阶段到成长阶段，再到成熟阶段的演变。

- **社群成员互动的机制**：

  - **互动机制**：社群成员之间的互动包括信息交换、情感支持、资源共享等多种形式。这些互动通过社交平台、活动、聚会等渠道实现。
  - **互动模式**：互动模式可以是正式的，如会议、讲座，也可以是非正式的，如聊天、聚会。

- **社群凝聚力的构建**：

  - **凝聚力定义**：社群凝聚力是指成员之间相互吸引、共同归属的感觉，以及为了共同目标而努力的程度。
  - **凝聚力来源**：凝聚力来源于共同的价值观、目标、兴趣以及成员之间的相互信任和支持。
  - **凝聚力提升方法**：可以通过加强社群内部沟通、举办活动、奖励机制等方式来提升社群凝聚力。

**2.2 社交网络分析**

社交网络分析是一种用于研究社交网络结构、性质和行为的分析方法。它关注社交网络中的节点（个体）和边（关系）之间的复杂关系，以揭示社交网络中的规律和特征。

- **社交网络的结构**：

  - **节点和边**：社交网络由个体（节点）及其之间的关系（边）组成。节点代表个体，边代表个体之间的联系。
  - **网络密度**：网络密度是描述网络中节点连接程度的指标，通常用边的数量与可能的最大边数的比值来表示。
  - **聚类系数**：聚类系数描述的是网络中节点的紧密程度，即一个节点周围节点的连接情况。

- **社交网络的测量**：

  - **节点中心性**：节点中心性是衡量节点在社交网络中的重要性的指标，常用的中心性指标包括度中心性、紧密中心性和介数中心性。
  - **社区发现**：社区发现是识别社交网络中具有高凝聚力的子结构的方法。常用的算法有基于模块度优化和基于聚类系数的方法。
  - **网络稳定性**：网络稳定性是衡量社交网络在面对外部扰动时抵抗能力的一个指标。

- **社交网络的应用**：

  - **推荐系统**：利用社交网络分析可以设计推荐系统，为用户提供个性化推荐。
  - **社交风险管理**：通过分析社交网络的结构和特性，可以识别潜在的社交风险，并制定相应的风险管理策略。
  - **社交网络效应**：社交网络效应是指个体通过参与社交网络获得正外部性的现象，如病毒式营销、信息传播等。

**附录4：算法原理讲解**

**算法：社交网络分析中的社区发现算法**

**流程图：**

```
graph {
  rankdir=TB;

  subgraph cluster1 {
    label = "社区发现算法";
    color = grey;
    A [label="初始化"];
    B [label="计算聚类系数"];
    C [label="迭代优化"];
    D [label="输出结果"];
    A -> B -> C -> D;
  }

  subgraph cluster2 {
    label = "流程图说明";
    color = grey;
    A1 [label="初始化社区列表"];
    A2 [label="计算每个节点的聚类系数"];
    B1 [label="选择高聚类系数节点作为种子"];
    B2 [label="扩展种子节点社区"];
    C1 [label="更新社区列表"];
    D1 [label="结束迭代"];
    A1 -> A2 -> B1 -> B2 -> C1 -> D1;
  }
}
```

**算法原理**：

- **初始化**：初始化社区列表，通常选择随机节点作为种子。
- **计算聚类系数**：计算每个节点的聚类系数，以评估节点的社区倾向性。
- **迭代优化**：选择高聚类系数节点作为种子，扩展种子节点社区，并更新社区列表。
- **输出结果**：迭代结束，输出最终社区划分结果。

**数学模型和公式**：

- **聚类系数**：$C(i) = \frac{|\{j | j \text{是 } i \text{ 的邻居，且 } j \text{ 与 } i \text{ 之外的邻居数}|\}}{N(i) - 1}$

其中，$C(i)$ 表示节点 $i$ 的聚类系数，$N(i)$ 表示节点 $i$ 的邻居数。

**举例说明**：

假设节点 $i$ 有两个邻居 $j$ 和 $k$，且 $j$ 和 $k$ 互为邻居，$i$ 与 $j$ 和 $k$ 之外的邻居数为 1，则节点 $i$ 的聚类系数为：

$$C(i) = \frac{|2 - 1|}{2 - 1} = 1$$

from flask import Flask, render_template, request, redirect, url_for, flash
from flask_sqlalchemy import SQLAlchemy

from flask_wtf import FlaskForm

app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///site.db'
app.config['SECRET_KEY'] = 'your_secret_key'

login_manager.login_view = 'login'

    id = db.Column(db.Integer, primary_key=True)

    url = db.Column(db.String(255), nullable=False)
    activity_id = db.Column(db.Integer, db.ForeignKey('activity.id'))

class LoginForm(FlaskForm):
    email = StringField('Email', validators=[DataRequired(), EmailValidator()])
    password = PasswordField('Password', validators=[DataRequired()])
    remember = BooleanField('Remember me')
    submit = SubmitField('Login')

@app.route('/')
def home():
    return render_template('home.html')

@app.route('/login', methods=['GET', 'POST'])
def login():
    form = LoginForm()
    if form.validate_on_submit():
        user = User.query.filter_by(email=form.email.data).first()
        if user and user.check_password(form.password.data):
            login_user(user, remember=form.remember.data)
            return redirect(url_for('dashboard'))
        else:
            flash('Invalid email or password', 'danger')
    return render_template('login.html', form=form)

@app.route('/logout')
def logout():
    logout_user()
    return redirect(url_for('home'))

@app.route('/dashboard')
@login_required
def dashboard():
    return render_template('dashboard.html')

if __name__ == '__main__':
    app.run(debug=True)
