```python
def calculate_mean(data):
    return sum(data) / len(data)

def calculate_variance(data, mean):
    return sum([(x - mean) ** 2 for x in data]) / len(data)

data = [10, 20, 30, 40, 50]
mean = calculate_mean(data)
variance = calculate_variance(data, mean)
print("Mean:", mean)
print("Variance:", variance)
```

**数学模型和公式**

在算法实现过程中，经常需要用到一些数学模型和公式，例如：

1. **平均值**：$$\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}$$
2. **方差**：$$\sigma^2 = \frac{\sum_{i=1}^{n} (x_i - \bar{x})^2}{n}$$

**算法原理讲解**

以上算法通过计算用户数据的平均值和方差，可以评估用户冥想效果的稳定性。具体步骤如下：

1. **计算平均值**：将所有用户冥想数据相加，然后除以用户数量，得到平均值。
2. **计算方差**：将每个用户冥想数据与平均值的差的平方相加，然后除以用户数量，得到方差。

**举例说明**

假设有5个用户，他们的冥想数据如下：

```
用户1：10分钟
用户2：20分钟
用户3：30分钟
用户4：40分钟
用户5：50分钟
```

计算平均值和方差：

```
平均值 = (10 + 20 + 30 + 40 + 50) / 5 = 30
方差 = [(10 - 30)^2 + (20 - 30)^2 + (30 - 30)^2 + (40 - 30)^2 + (50 - 30)^2] / 5 = 50
```

通过这个例子，我们可以看到，平均值和方差可以帮助我们评估用户冥想效果的稳定性。平均值越接近30分钟，说明用户冥想效果越好；方差越小，说明用户冥想效果越稳定。
