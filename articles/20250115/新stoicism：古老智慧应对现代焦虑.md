### 1.1 现代社会的压力与挑战

在现代社会，人们面临着各种压力和挑战。工作、家庭、社交关系、财务状况等各个方面，似乎都在不断地考验着人们的耐力和意志。据统计，焦虑症已经成为全球范围内最常见的心理健康问题之一，尤其在年轻人群中更为普遍。现代社会的快节奏、高度竞争和不确定性，使得焦虑成为了许多人生活中无法避免的伴侣。

### 1.2 Stoicism的核心观念

Stoicism，即斯多葛主义，起源于古希腊，是一种强调理性、自制和内心平和的哲学思想。Stoicism的核心观念包括道德美德、逻辑推理、意志力和沉着。这种哲学主张人们应该通过理性思考来面对生活中的困难和挑战，而不是让情绪和欲望主导自己的生活。

### 1.3 Stoicism在当代的适用性

尽管Stoicism起源于古希腊，但其在当代社会中的应用却十分广泛。许多成功人士和企业家，如美国总统比尔·克林顿、苹果公司CEO蒂姆·库克等，都公开表示自己受益于Stoicism。Stoicism不仅能够帮助人们更好地应对焦虑，还能提升个人的心理韧性和抗压能力。

Stoicism的核心原则包括道德美德、逻辑推理、意志力和沉着。道德美德强调人们应该追求内在的善良和正义；逻辑推理强调理性思考和批判性思维；意志力强调个人的自制力和决心；沉着强调在困难和挑战面前保持冷静和镇定。

```python
from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, BooleanField
from wtforms.validators import DataRequired, EmailValidator, EqualTo

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///anxiety_management.db'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(100), unique=True, nullable=False)
    password = db.Column(db.String(100), nullable=False)
    is_active = db.Column(db.Boolean, default=True)

class AnxietyPlan(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    title = db.Column(db.String(100), nullable=False)
    description = db.Column(db.Text, nullable=False)
    is_completed = db.Column(db.Boolean, default=False)

class AnxietyFeedback(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    content = db.Column(db.Text, nullable=False)
    rating = db.Column(db.Integer, nullable=False)

class LoginForm(FlaskForm):
    username = StringField('Username', validators=[DataRequired()])
    password = PasswordField('Password', validators=[DataRequired()])

class RegisterForm(FlaskForm):
    username = StringField('Username', validators=[DataRequired(), EmailValidator()])
    password = PasswordField('Password', validators=[DataRequired()])
    confirm_password = PasswordField('Confirm Password', validators=[DataRequired(), EqualTo('password')])

@app.route('/register', methods=['POST'])
def register():
    form = RegisterForm(request.form)
    if form.validate_on_submit():
        new_user = User(username=form.username.data, password=form.password.data)
        db.session.add(new_user)
        db.session.commit()
        return jsonify({'message': 'User registered successfully.'})
    return jsonify({'errors': form.errors})

@app.route('/login', methods=['POST'])
def login():
    form = LoginForm(request.form)
    if form.validate_on_submit():
        user = User.query.filter_by(username=form.username.data, password=form.password.data, is_active=True).first()
        if user:
            return jsonify({'message': 'Login successful.'})
        else:
            return jsonify({'message': 'Invalid credentials.'})
    return jsonify({'errors': form.errors})

@app.route('/anxiety_plan', methods=['POST'])
def create_anxiety_plan():
    form = FlaskForm(request.form)
    if form.validate_on_submit():
        new_plan = AnxietyPlan(user_id=form.user_id.data, title=form.title.data, description=form.description.data, is_completed=form.is_completed.data)
        db.session.add(new_plan)
        db.session.commit()
        return jsonify({'message': 'Anxiety plan created successfully.'})
    return jsonify({'errors': form.errors})

@app.route('/anxiety_feedback', methods=['POST'])
def submit_anxiety_feedback():
    form = FlaskForm(request.form)
    if form.validate_on_submit():
        new_feedback = AnxietyFeedback(user_id=form.user_id.data, content=form.content.data, rating=form.rating.data)
        db.session.add(new_feedback)
        db.session.commit()
        return jsonify({'message': 'Anxiety feedback submitted successfully.'})
    return jsonify({'errors': form.errors})

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```

3. **用户登录**：`login`函数负责处理用户登录请求。首先，我们创建一个`LoginForm`表单，用于验证用户输入。如果表单验证通过，我们查询数据库，查找与用户输入的用户名和密码匹配的用户。如果找到匹配的用户，我们返回登录成功的信息。

4. **焦虑管理计划制定**：`create_anxiety_plan`函数负责处理焦虑管理计划的创建请求。首先，我们创建一个`FlaskForm`表单，用于验证用户输入。如果表单验证通过，我们创建一个新的`AnxietyPlan`对象，并将其添加到数据库中。

5. **焦虑反馈提交**：`submit_anxiety_feedback`函数负责处理焦虑反馈的提交请求。首先，我们创建一个`FlaskForm`表单，用于验证用户输入。如果表单验证通过，我们创建一个新的`AnxietyFeedback`对象，并将其添加到数据库中。
