### 第2章：核心概念与联系

#### 2.1.1 果酱定义

果酱是一种果肉与糖浆混合的凝胶状食品，通常用作涂抹面包、糕点或烹饪的调味料。

#### 2.1.2 果酱分类

果酱可分为传统果酱和现代果酱。传统果酱主要以水果为主，现代果酱则更注重添加果汁、香精等调味品。

#### 2.1.3 果酱制作原理

果酱制作主要涉及以下过程：水果处理、糖浆配制、加热熬制、冷却成型。

#### 2.1.4 果酱属性特征对比表格

| 分类       | 传统果酱       | 现代果酱       |
| ---------- | -------------- | -------------- |
| 成分       | 纯水果        | 水果+果汁、香精 |
| 口感       | 甘甜、浓厚     | 清爽、多样化    |
| 储存条件   | 需冷藏        | 可常温保存     |
| 制作难度   | 较高          | 较低          |

### 第3章：果酱制作流程

#### 3.1.1 原料准备

- **水果**：新鲜、成熟、无病变的水果。
- **糖**：白砂糖、黄糖、蜂蜜等。
- **工具**：榨汁机、搅拌机、锅、量杯、漏网等。

#### 3.1.2 制作过程

1. **水果处理**：清洗、去皮、去籽、切块。
2. **糖浆配制**：按照一定比例配制糖浆。
3. **加热熬制**：将水果和糖浆放入锅中，不断搅拌，加热至煮沸。
4. **冷却成型**：将熬制好的果酱倒入容器中，冷却后即可成型。
