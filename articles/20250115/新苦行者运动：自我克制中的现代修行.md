#### 5.2 系统核心实现源代码

以下是新苦行者运动系统的核心实现源代码：

```python
# app.py

from flask import Flask, request, jsonify
from sqlalchemy import create_engine
from models import User, Goal

app = Flask(__name__)

# 创建数据库引擎
engine = create_engine('mysql+pymysql://root:password@localhost:3306/new_ascetic')

# 创建表
engine.execute('''CREATE TABLE IF NOT EXISTS users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    password VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL
)''')

engine.execute('''CREATE TABLE IF NOT EXISTS goals (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    goal VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
)''')

# 用户注册
@app.route('/register', methods=['POST'])
def register():
    username = request.form['username']
    password = request.form['password']
    email = request.form['email']
    user = User(username=username, password=password, email=email)
    user.save()
    return jsonify({'message': '注册成功'})

# 用户登录
@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({'message': '登录成功'})
    else:
        return jsonify({'message': '登录失败'})

# 添加目标
@app.route('/add_goal', methods=['POST'])
def add_goal():
    user_id = request.form['user_id']
    goal = request.form['goal']
    goal = Goal(user_id=user_id, goal=goal)
    goal.save()
    return jsonify({'message': '添加目标成功'})

# 获取目标列表
@app.route('/goals', methods=['GET'])
def get_goals():
    user_id = request.args.get('user_id')
    goals = Goal.query.filter_by(user_id=user_id).all()
    return jsonify({'goals': [goal.to_dict() for goal in goals]})

if __name__ == '__main__':
    app.run(debug=True)
```

2. **用户登录**：通过`/login`接口接收用户名和密码，查询数据库验证用户信息，返回登录结果。
3. **添加目标**：通过`/add_goal`接口接收用户ID和目标信息，创建目标对象并保存到数据库。
4. **获取目标列表**：通过`/goals`接口接收用户ID，查询数据库获取用户的目标列表，返回JSON格式数据。
