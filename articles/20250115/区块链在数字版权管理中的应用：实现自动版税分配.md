### 第2章: 区块链基础知识

#### 2.1 区块链的定义与特点

区块链（Blockchain）是一种分布式数据库技术，由多个区块（Block）按照特定顺序链接而成。每个区块包含一定数量的交易记录，并通过密码学算法链接在一起，形成一个连续的、不可篡改的链式数据结构。区块链具有以下特点：

1. **去中心化**：区块链不需要中心化的中介机构，所有节点都可以参与区块链网络，并通过分布式的方式共同维护区块链的完整性和可靠性。
2. **透明性**：区块链上的所有交易记录都是公开透明的，任何参与者都可以查看和验证这些记录。
3. **不可篡改性**：区块链上的数据一旦记录，就无法被篡改或删除，保证了数据的完整性和可靠性。

#### 2.2 区块链的基本结构

区块链的基本结构包括以下关键组成部分：

1. **区块**：区块是区块链的基本单元，包含一定数量的交易记录。每个区块都有一个唯一的标识符，称为“区块头”，其中包括了上一个区块的哈希值、时间戳、随机数等。
2. **链**：链是由多个区块按照特定顺序链接而成的数据结构。区块链上的每一个区块都通过其区块头中的上一个区块哈希值与上一个区块链接起来，形成了一个连续的、不可篡改的数据结构。
3. **节点**：节点是区块链网络中的计算设备，负责存储、验证和传播区块。每个节点都维护一份完整的区块链副本，并通过网络与其他节点进行通信。
4. **挖矿**：挖矿是区块链网络中节点通过计算获取新区块的过程。节点通过解决数学难题来验证和添加新的交易记录到区块链上，从而获得奖励。
5. **共识机制**：共识机制是区块链网络中节点达成共识的算法，确保区块链的可靠性和安全性。常见的共识机制包括工作量证明（Proof of Work，PoW）、权益证明（Proof of Stake，PoS）等。

#### 2.3 智能合约

智能合约（Smart Contract）是一种运行在区块链上的自执行合约，能够自动执行预定的协议。智能合约通过代码定义了一系列条件和行动，当条件满足时，自动执行相应的行动。智能合约的核心优势在于其自动化和不可篡改性，可以减少中介机构的需求，降低交易成本，提高交易的效率和透明度。

#### 2.4 区块链的应用场景

区块链技术在多个领域具有广泛的应用，包括但不限于以下场景：

1. **数字货币**：比特币（Bitcoin）和以太坊（Ethereum）是最著名的区块链应用，它们通过区块链技术实现了去中心化的数字货币系统。
2. **供应链管理**：区块链技术可以用于记录和跟踪供应链中的交易和物流信息，确保供应链的透明性和可追溯性。
3. **医疗健康**：区块链技术可以用于记录和存储医疗记录，提高医疗数据的安全性和可靠性。
4. **版权管理**：区块链技术可以用于数字版权管理，确保版权的透明性和不可篡改性。
5. **金融交易**：区块链技术可以用于去中心化的金融交易，减少中介机构的参与，降低交易成本。

// 定义版权信息结构体
struct CopyrightInfo {
    string workTitle;
    address creator;
    address owner;
    uint256 royaltyPercentage;
}

// 定义版权信息映射
mapping(string => CopyrightInfo) public copyrightInfos;

// 定义版税分配事件
event RoyaltyDistributed(string workTitle, address owner, uint256 amount);

// 分配版税
function distributeRoyalty(string memory workTitle, uint256 amount) public {

    uint256 royaltyAmount = amount * copyrightInfos[workTitle].royaltyPercentage / 100;
    
    payable(copyrightInfos[workTitle].owner).transfer(royaltyAmount);
    
    emit RoyaltyDistributed(workTitle, copyrightInfos[workTitle].owner, royaltyAmount);
}

// 设置版税分配规则
function setRoyaltyPercentage(string memory workTitle, uint256 percentage) public {
    require(percentage <= 100, "Invalid royalty percentage");
    require(copyrightInfos[workTitle].royaltyPercentage == 0, "Royalty percentage already set");
    
    copyrightInfos[workTitle].royaltyPercentage = percentage;
}
