## 第二部分：区块链技术原理讲解

### 4. 区块链技术原理

#### 4.1 工作原理

区块链技术的工作原理基于分布式账本和共识机制。以下是区块链技术的工作原理Mermaid流程图：

```mermaid
graph TD
    A[发起交易] --> B[打包交易]
    B --> C[添加区块]
    C --> D[传播区块]
    D --> E[共识验证]
    E --> F[区块确认]
    F --> G[记录在链]
```

在这个流程中，交易由发起人提交，经过打包后添加到区块中，并通过网络传播。共识机制确保区块的合法性，一旦验证通过，区块将记录在区块链上，形成永久链。

#### 4.2 算法原理

区块链技术的核心算法包括加密算法和共识算法。以下是加密算法和共识算法的Mermaid流程图：

##### 4.2.1 加密算法

```mermaid
graph TD
    A[明文] --> B[加密算法]
    B --> C[密文]
    C --> D[解密算法]
    D --> E[明文]
```

在这个流程中，明文通过加密算法转换为密文，密文在传输过程中无法被篡改。接收方通过解密算法将密文还原为明文。

##### 4.2.2 共识算法

```mermaid
graph TD
    A[区块] --> B[验证节点]
    B --> C[共识结果]
    C --> D[区块添加]
    D --> E[区块传播]
```

在这个流程中，验证节点对区块进行验证，通过共识算法达成共识后，将区块添加到区块链中，并传播给其他节点。

```python
from选举委员会 import ElectionCommittee
from投票系统 import VotingSystem
from结果公示系统 import ResultDisplaySystem
from审计系统 import AuditSystem

# 初始化区块链
blockchain = Blockchain()

# 初始化选举委员会、投票系统、结果公示系统和审计系统
election_committee = ElectionCommittee(blockchain)
voting_system = VotingSystem(blockchain)

audit_system = AuditSystem(blockchain)

# 用户注册
def register_user(username, password):
    election_committee.register_user(username, password)

# 投票

    voting_system.vote(username, password, candidate)

# 查看结果
def view_results():
    result_display_system.view_results()

# 审计
def audit():
    audit_system.audit()

# 执行操作
register_user("user1", "password1")
vote("user1", "password1", "candidate1")
view_results()
audit()
```
