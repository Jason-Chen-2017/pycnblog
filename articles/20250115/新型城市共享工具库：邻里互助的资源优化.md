**3.2 Python源代码与算法数学模型**

接下来，我们将通过Python源代码详细阐述需求匹配算法的数学模型和公式。

```python
import numpy as np

# 初始化资源信息
resources = {'R1': 10, 'R2': 5, 'R3': 8}

# 初始化用户需求
demands = {'U1': {'R1': 5, 'R2': 3}, 'U2': {'R1': 7, 'R3': 2}}

# 定义需求匹配函数
def match_resources(resources, demands):
    matched_resources = {}
    for user, user_demand in demands.items():
        for resource, quantity in user_demand.items():
            if resources[resource] >= quantity:
                matched_resources[user] = {resource: quantity}
                resources[resource] -= quantity
                break
    return matched_resources

# 运行需求匹配算法
matched_resources = match_resources(resources, demands)

# 输出匹配结果
print(matched_resources)
```
