#### 算法原理讲解

在这个系统中，核心算法是任务优先级排序和时间分配。以下是具体的算法原理：

1. **任务优先级排序**：我们使用快速排序算法，根据任务优先级对任务进行排序。这个算法的时间复杂度为O(n log n)，非常适合处理大量的任务。
2. **时间分配**：我们使用贪心算法，每次分配时间给优先级最高的任务，直到时间用尽或所有任务分配完成。

以下是具体的Python代码实现：

```python
# 快速排序算法
def quick_sort(tasks):
    if len(tasks) <= 1:
        return tasks
    pivot = tasks[len(tasks) // 2].priority
    left = [x for x in tasks if x.priority > pivot]
    middle = [x for x in tasks if x.priority == pivot]
    right = [x for x in tasks if x.priority < pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 时间分配算法
def allocate_time(tasks, available_hours):
    sorted_tasks = quick_sort(tasks)
    allocated_time = []
    for task in sorted_tasks:
        if task.duration <= available_hours:
            allocated_time.append(task.name)
            available_hours -= task.duration
        else:
            print(f"Not enough time for task: {task.name}")
            break
    return allocated_time
```

**2. 后端服务**

```python
from flask import Flask, request, jsonify
import sqlite3

app = Flask(__name__)

# 数据库连接
def get_db_connection():
    conn = sqlite3.connect('tasks.db')
    conn.row_factory = sqlite3.Row
    return conn

# 创建数据库表
def init_db():
    conn = get_db_connection()
    c = conn.cursor()
    c.execute('''CREATE TABLE IF NOT EXISTS tasks
                 (id INTEGER PRIMARY KEY AUTOINCREMENT,
                  name TEXT NOT NULL,
                  priority INTEGER NOT NULL)''')
    conn.commit()
    conn.close()

init_db()

# 添加任务
@app.route('/add_task', methods=['POST'])
def add_task():
    data = request.json
    conn = get_db_connection()
    c = conn.cursor()
    c.execute('INSERT INTO tasks (name, priority) VALUES (?, ?)',
              (data['name'], data['priority']))
    conn.commit()
    conn.close()
    return jsonify({'status': 'success'})

# 获取任务列表
@app.route('/tasks', methods=['GET'])
def get_tasks():
    conn = get_db_connection()
    c = conn.cursor()
    c.execute('SELECT * FROM tasks')
    tasks = c.fetchall()
    conn.close()
    return jsonify({'tasks': tasks})

if __name__ == '__main__':
    app.run(debug=True)
```
