    end
    A note right of A
        这是一个备注。
    end
```

在这个示例中，我们为角色1（A）和角色2（B）的事件分别添加了右边的备注。

#### 5. 高级特性

- **条件事件**：我们可以为事件添加条件。

```mermaid
sequenceDiagram
    participant A as 角色1
    participant B as 角色2
    A->>B: 发送消息
    alt 条件1
        B->>A: 条件回复1
    else 条件2
        B->>A: 条件回复2
    end
```

在这个示例中，如果条件1为真，角色2（B）会回复角色1（A）“条件回复1”；否则，角色2（B）会回复角色1（A）“条件回复2”。

- **循环事件**：我们可以为事件添加循环。

```mermaid
sequenceDiagram
    participant A as 角色1
    participant B as 角色2
    A->>B: 发送消息
    loop 每次循环
        B->>A: 循环回复
    end
```

在这个示例中，角色2（B）会每次循环向角色1（A）发送“循环回复”消息。

在Markdown中，我们可以使用Mermaid语法来绘制流程图，它是一种用于表示业务流程、数据处理流程等过程的图形表示方法。以下是一个基本的Mermaid流程图示例：

```mermaid
graph TD
    A[开始] --> B{判断条件}
    B -->|是| C[执行操作]
    B -->|否| D[执行其他操作]
    C --> E[结束]
    D --> E
```

下面，我们将逐步解释这个流程图的组成部分和语法：

#### 1. 定义图形

```mermaid
graph TD
```

这是Mermaid的基本语法，用于定义图形的类型为流程图（graph TD），其中`TD`表示布局方向从上到下。

#### 2. 定义节点

节点是流程图中的核心元素，表示流程中的步骤或决策点。使用`[节点名称]`来定义节点。

```mermaid
graph TD
    A[开始]
    B{判断条件}
    C[执行操作]
    D[执行其他操作]
    E[结束]
```

在这个示例中，我们定义了五个节点：开始、判断条件、执行操作、执行其他操作和结束。

#### 3. 定义连接线

使用`-->`或`->>`来定义节点之间的连接线。

```mermaid
graph TD
    A[开始] --> B{判断条件}
    B -->|是| C[执行操作]
    B -->|否| D[执行其他操作]
    C --> E[结束]
    D --> E
```

在这个示例中，我们定义了从开始节点到判断条件节点、从判断条件节点到执行操作节点（如果条件为“是”）、从判断条件节点到执行其他操作节点（如果条件为“否”），以及从执行操作节点和执行其他操作节点到结束节点的连接线。

#### 4. 添加条件连接线

在流程图中，我们可以为决策点添加条件连接线，表示不同的决策路径。使用`--if>`来定义条件连接线。

```mermaid
graph TD
    A[开始]
    B{判断条件} -->|是| C[执行操作]
    B -->|否| D[执行其他操作]
    C --> E[结束]
    D --> E
```

在这个示例中，我们为判断条件节点添加了两个条件连接线，分别连接到执行操作节点和执行其他操作节点。
