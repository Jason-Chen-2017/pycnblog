### 4.1 模型参数优化

#### 4.1.1 梯度下降法

梯度下降法是一种常用的优化算法，用于最小化损失函数。在多粒度因果网络构建过程中，我们需要优化网络参数以准确地进行因果推理。以下是梯度下降法的实现步骤：

1. 初始化参数：
   - 初始化权重 \(w\) 和偏置 \(b\)。
   - 选择学习率 \(\alpha\)，用于控制参数更新的步长。

2. 计算损失函数的梯度：
   - 对于每个输入数据 \(x_i\)，计算损失函数 \(L(\theta)\) 对权重 \(w\) 和偏置 \(b\) 的偏导数。

3. 更新参数：
   - 根据梯度信息更新权重 \(w\) 和偏置 \(b\)。

4. 重复步骤 2 和 3，直到满足停止条件（如损失函数收敛或迭代次数达到阈值）。

Python 代码实现示例如下：

```python
import numpy as np

def gradient_descent(X, y, w, b, alpha, epochs):
    n_samples, n_features = X.shape
    for _ in range(epochs):
        gradients_w = 2/n_samples * X.T.dot((y - sigmoid(X.dot(w) + b)))
        gradients_b = 2/n_samples * (y - sigmoid(X.dot(w) + b))
        w -= alpha * gradients_w
        b -= alpha * gradients_b
    return w, b

def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```

#### 4.1.2 随机梯度下降法

随机梯度下降法（SGD）是一种改进的梯度下降法，通过随机选择样本进行参数更新，以加快收敛速度并减少局部最小值的影响。以下是随机梯度下降法的实现步骤：

1. 从数据集中随机选择一个样本 \((x_i, y_i)\)。

2. 计算损失函数的梯度：

   $$\nabla_w L(w) = \frac{\partial L(w)}{\partial w} = X_i^T(y - \sigma(wX_i + b))$$

   $$\nabla_b L(b) = \frac{\partial L(b)}{\partial b} = y - \sigma(wX_i + b)$$

   其中，\(\sigma\) 是 sigmoid 函数。

3. 更新参数：

   $$w := w - \alpha \nabla_w L(w)$$

   $$b := b - \alpha \nabla_b L(b)$$

Python 代码实现示例如下：

```python
import numpy as np

def stochastic_gradient_descent(X, y, w, b, alpha, epochs):
    n_samples = X.shape[0]
    for _ in range(epochs):
        for i in range(n_samples):
            xi = X[i].reshape(1, -1)
            yi = y[i].reshape(1, -1)
            gradients_w = xi.T.dot(yi - sigmoid(xi.dot(w) + b))
            gradients_b = yi - sigmoid(xi.dot(w) + b)
            w -= alpha * gradients_w
            b -= alpha * gradients_b
    return w, b

def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```

```python
import tensorflow as tf
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# 梯度下降法优化器
class GradientDescentOptimizer(tf.keras.optimizers.Optimizer):
    def __init__(self, learning_rate=0.01, name="GradientDescentOptimizer", **kwargs):
        super().__init__(name, **kwargs)
        self.learning_rate = learning_rate

    def get_updates(self, loss, params):
        grads = self.get_gradients(loss, params)
        updates = []
        for p, g in zip(params, grads):
            updates.append(p.assign_sub(self.learning_rate * g))
        return updates

# 网络构建
def build_model(input_shape):
    inputs = tf.keras.layers.Input(shape=input_shape)
    x = tf.keras.layers.Dense(10, activation='relu')(inputs)
    outputs = tf.keras.layers.Dense(1, activation='sigmoid')(x)
    model = tf.keras.Model(inputs=inputs, outputs=outputs)
    return model

# 模型训练
def train_model(model, X, y, epochs=100, batch_size=10):
    optimizer = GradientDescentOptimizer(learning_rate=0.01)
    model.compile(optimizer=optimizer, loss='binary_crossentropy', metrics=['accuracy'])
    model.fit(X, y, epochs=epochs, batch_size=batch_size)
    return model

# 数据预处理
X = np.random.rand(100, 2)
y = np.random.randint(0, 2, 100)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# 构建模型
model = build_model(input_shape=(2,))
model = train_model(model, X_train, y_train, epochs=100)

# 预测
y_pred = model.predict(X_test)
accuracy = (y_pred.round() == y_test).mean()
print("Accuracy:", accuracy)
```
