### 第二部分：背景与问题阐述

**2.1 个人主义的起源与发展**

个人主义作为一种思想，起源于西方哲学的启蒙时代，特别是在17世纪和18世纪的英国。其主要代表人物包括托马斯·霍布斯（Thomas Hobbes）、约翰·洛克（John Locke）和让-雅克·卢梭（Jean-Jacques Rousseau）。霍布斯认为，在没有政府和社会秩序的情况下，人类社会将陷入“每个人对每个人的战争”。为了防止这种状态，洛克提出了社会契约论，认为人们通过自愿合作形成社会契约，以保障个人自由和安全。卢梭则强调个人的自然权利和道德责任。

个人主义的核心原则包括个人自由、自我决定和追求个人利益。在个人主义看来，个人是社会的原子，个体的利益和幸福是最重要的。这种思想在资本主义经济体系中得到了充分体现，市场经济鼓励个人创业和自由竞争，个人成为经济活动的基本单位。

**2.2 社会责任的概念与内涵**

社会责任是指个人或组织对社会和环境的义务和责任。它超越了法律和经济的范畴，涉及道德、伦理和公共利益。社会责任的概念可以追溯到古希腊和罗马时期，但在现代，它得到了更广泛的关注和应用。

社会责任的理论基础主要包括功利主义、义务论和美德伦理学。功利主义者认为，个人应该做出能够带来最大幸福的行为；义务论者则强调个人应该履行特定的道德义务；而美德伦理学则关注个人道德品质的培养。

在现代社会，社会责任的具体体现包括环境保护、慈善捐赠、员工福利和社区服务。企业常常通过社会责任报告和可持续发展计划来展示其对社会的贡献。政府和非营利组织也在推动社会责任的实践，通过立法和政策引导企业和个人履行社会责任。

**2.3 个人主义与社会责任的冲突**

个人主义与社会责任的冲突主要体现在以下几个方面：

**社会问题与个人责任：** 在面对诸如环境污染、贫困和社会不公等社会问题时，个人主义强调个体的自由选择和权利，而社会责任则要求个人主动承担起解决这些问题的责任。这种冲突常常导致个人逃避责任，将问题归咎于外部环境。

**个人自由与社会规范的矛盾：** 个人主义倡导个人自由和独立，但社会责任要求个人遵守社会规范和道德准则。这种矛盾在现代社会尤为突出，例如在言论自由和隐私保护之间、个人利益和社会整体利益之间寻找平衡。

**个人权利与社会福祉：** 个人主义强调个人权利和利益的最大化，而社会责任则强调社会整体福祉和公平。这种冲突在资源分配、福利政策等方面表现得尤为明显。

这些冲突不仅影响个人的行为和决策，也对社会结构和政策制定产生深远的影响。如何在个人主义和社会责任之间找到平衡，成为现代社会亟待解决的问题。

```python
# app.py
from flask import Flask, request, jsonify
from pymongo import MongoClient
import redis

app = Flask(__name__)

# MongoDB 客户端连接
client = MongoClient("mongodb://localhost:27017/")
db = client["eco_community"]

# Redis 客户端连接
redis_client = redis.StrictRedis(host='localhost', port=6379, db=0)

@app.route("/api/sensors/data", methods=["POST"])
def collect_sensor_data():
    data = request.get_json()
    sensor_type = data["type"]
    sensor_data = data["data"]

    # 存储数据到MongoDB
    db[sensor_type].insert_one(sensor_data)

    # 存储数据到Redis
    redis_client.set(sensor_type, json.dumps(sensor_data))

    return jsonify({"status": "success", "message": "Sensor data collected."})

@app.route("/api/sensors/data", methods=["GET"])
def get_sensor_data():
    sensor_type = request.args.get("type")
    if sensor_type:
        # 从Redis中获取数据
        sensor_data = redis_client.get(sensor_type)
        if sensor_data:
            return jsonify(json.loads(sensor_data))
        else:
            return jsonify({"status": "error", "message": "No data found."})
    else:
        return jsonify({"status": "error", "message": "Type is required."})

if __name__ == "__main__":
    app.run(debug=True)
```

这段代码定义了两个API端点：

- `/api/sensors/data`（POST方法）：接收传感器数据，并将其存储在MongoDB和Redis中。
