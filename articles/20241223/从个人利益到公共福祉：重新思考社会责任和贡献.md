```python
scores = data['score'].mean()

# 结果输出

```

**4.4 数学模型和公式**

社会责任和贡献评估算法的数学模型如下：

$$
\text{得分} = \frac{\text{贡献}}{\text{努力}}
$$

其中，贡献和努力是两个重要的指标。贡献表示个人或组织在社会责任方面的表现，努力表示个人或组织在承担责任过程中的投入。

**4.5 举例说明**

假设有如下数据：

| 姓名 | 贡献 | 努力 |
| ---- | ---- | ---- |
| 张三 | 80   | 100  |
| 李四 | 120  | 150  |
| 王五 | 160  | 200  |

使用社会责任和贡献评估算法计算得分：

$$
\text{张三得分} = \frac{80}{100} = 0.8 \\
\text{李四得分} = \frac{120}{150} = 0.8 \\
\text{王五得分} = \frac{160}{200} = 0.8
$$

根据得分计算，三人的平均社会责任和贡献得分为 0.8。这个结果表明，三人在社会责任和贡献方面的表现相当。

```python
import pandas as pd
import mermaid
from flask import Flask, render_template

app = Flask(__name__)

# 数据收集模块
def data_collection():
    data = pd.read_csv('responsibility_data.csv')
    return data

# 数据处理模块
def data_processing(data):
    data['score'] = data['contribution'] / data['effort']
    return data

# 指标计算模块
def score_calculation(data):
    scores = data['score'].mean()
    return scores

# 结果输出模块
def result_output(scores):
    mermaid_graph = mermaid.Mermaid()
    mermaid_graph.set_code('''graph TD
        A[开始] --> B[数据收集]
        B --> C{是否完成}
        C -->|是| D[数据处理]
        C -->|否| B
        D --> E[指标计算]
        E --> F{是否完成}
        F -->|是| G[结果输出]
        F -->|否| E
        G --> H[结束]
    ''')
    return mermaid_graph.get_code()

@app.route('/')
def index():
    data = data_collection()
    processed_data = data_processing(data)
    scores = score_calculation(processed_data)
    graph_code = result_output(scores)
    return render_template('index.html', scores=scores, graph_code=graph_code)

if __name__ == '__main__':
    app.run(debug=True)
```
