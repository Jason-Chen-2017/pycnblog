## 第2章：集合论基础

### 2.1 集合的基本概念

集合是集合论中的基本概念，它是某些确定对象的总体。这些对象称为集合的元素。集合可以用大括号{}表示，元素之间用逗号分隔。例如，集合A可以表示为：

$$A = \{1, 2, 3, 4\}$$

#### 元素

集合中的每一个对象称为元素。例如，在集合A中，1、2、3和4都是A的元素。

#### 集合的表示方法

集合的表示方法主要有两种：枚举法和描述法。

1. **枚举法**：将集合中的所有元素一一列出。例如，集合A可以用枚举法表示为：

   $$A = \{1, 2, 3, 4\}$$

2. **描述法**：用条件语句来描述集合中的元素。例如，集合B可以表示为：

   $$B = \{x \in \mathbb{N} \mid x > 2\}$$

   这表示集合B是所有大于2的自然数的集合。

#### 集合的属性

集合具有以下基本属性：

1. **确定性**：集合中的元素必须是确定的，即每个元素是否属于集合是可以明确判断的。
2. **互异性**：集合中的元素是互异的，即集合中的每个元素都是唯一的。
3. **无序性**：集合中的元素没有固定的顺序。

### 2.2 集合运算

集合论中的基本运算包括交集、并集、补集和差集等。这些运算在数据结构设计中有着广泛的应用。

#### 2.2.1 交集

交集是指两个集合中共有的元素组成的集合。交集运算可以用符号∩表示。例如，集合A和集合B的交集可以表示为：

$$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$$

例如，集合A={1, 2, 3}和集合B={2, 3, 4}的交集为：

$$A \cap B = \{2, 3\}$$

#### 2.2.2 并集

并集是指两个集合中所有元素组成的集合。并集运算可以用符号∪表示。例如，集合A和集合B的并集可以表示为：

$$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$$

例如，集合A={1, 2, 3}和集合B={2, 3, 4}的并集为：

$$A \cup B = \{1, 2, 3, 4\}$$

#### 2.2.3 补集

补集是指不属于某个集合的元素组成的集合。补集运算可以用符号'或∪表示。例如，集合A的补集可以表示为：

$$A' = \{x \mid x \notin A\}$$

例如，集合A={1, 2, 3}的补集为：

$$A' = \{4, 5, 6, \ldots\}$$

#### 2.2.4 差集

差集是指属于集合A但不属于集合B的元素组成的集合。差集运算可以用符号∖表示。例如，集合A和集合B的差集可以表示为：

$$A \setminus B = \{x \mid x \in A \text{ 且 } x \notin B\}$$

例如，集合A={1, 2, 3}和集合B={2, 3, 4}的差集为：

$$A \setminus B = \{1\}$$

### 2.3 集合的基本性质

集合具有以下基本性质：

1. **交换律**：对于任意两个集合A和B，有A ∩ B = B ∩ A和A ∪ B = B ∪ A。
2. **结合律**：对于任意三个集合A、B和C，有(A ∩ B) ∩ C = A ∩ (B ∩ C)和(A ∪ B) ∪ C = A ∪ (B ∪ C)。
3. **分配律**：对于任意三个集合A、B和C，有A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)和A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)。
4. **德摩根律**：对于任意两个集合A和B，有(A ∩ B)' = A' ∪ B'和(A ∪ B)' = A' ∩ B'。

**详细讲解与举例说明：**

在这个例子中，集合A中的元素1不在集合B中，因此不添加到集合C中。集合A中的元素2和3在集合B中，因此将它们添加到集合C中。集合A中的元素4不在集合B中，因此也不添加到集合C中。最终，集合C={2, 3}，即为集合A和集合B的交集。

#### 2.2.2 并集

$$A \cup B = \{x | x \in A \text{ 或 } x \in B\}$$

#### 2.2.3 补集

补集是指不属于某个集合的元素组成的集合。用符号∪'或∁表示。例如，A'表示集合A的补集。

**运算公式**：

$$A' = \{x | x \notin A\}$$

#### 2.2.4 差集

差集是指属于集合A但不属于集合B的元素组成的集合。用符号∖表示。例如，A ∖ B表示集合A和集合B的差集。

**运算公式**：

$$A \setminus B = \{x | x \in A \text{ 且 } x \notin B\}$$

### 2.3 集合的基本性质

集合具有以下基本性质：

1. **交换律**：对于任意两个集合A和B，有A ∩ B = B ∩ A和A ∪ B = B ∪ A。
2. **结合律**：对于任意三个集合A、B和C，有(A ∩ B) ∩ C = A ∩ (B ∩ C)和(A ∪ B) ∪ C = A ∪ (B ∪ C)。
3. **分配律**：对于任意三个集合A、B和C，有A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)和A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)。
4. **德摩根律**：对于任意两个集合A和B，有(A ∩ B)' = A' ∪ B'和(A ∪ B)' = A' ∩ B'。

#### 4.1 集合交集算法

集合交集算法用于找出两个集合中共同的元素。其基本原理是基于集合的交集运算，即找出两个集合A和B中的共同元素，组成一个新的集合。

$$A \cap B = \{x | x \in A \text{ 且 } x \in B\}$$

**详细讲解与举例说明：**

假设集合A={1, 2, 3, 4}和集合B={2, 3, 5, 6}，我们希望找到这两个集合的交集。首先，我们初始化一个空集合C。然后，遍历集合A中的每个元素，判断该元素是否在集合B中。如果元素在集合B中，则将其添加到集合C中。最后，输出集合C，即为集合A和集合B的交集。

在这个例子中，集合A中的元素1不在集合B中，因此不添加到集合C中。集合A中的元素2和3在集合B中，因此将它们添加到集合C中。集合A中的元素4不在集合B中，因此也不添加到集合C中。最终，集合C={2, 3}，即为集合A和集合B的交集。

### 2.2 集合运算

#### 2.2.1 交集

交集是指两个集合中共有的元素组成的集合。用符号∩表示。例如，A ∩ B表示集合A和集合B的交集。

**运算公式**：

$$A \cap B = \{x | x \in A \text{ 且 } x \in B\}$$

#### 2.2.2 并集

并集是指两个集合中所有元素组成的集合。用符号∪表示。例如，A ∪ B表示集合A和集合B的并集。

**运算公式**：

$$A \cup B = \{x | x \in A \text{ 或 } x \in B\}$$

#### 2.2.3 补集

补集是指不属于某个集合的元素组成的集合。用符号∪'或∁表示。例如，A'表示集合A的补集。

**运算公式**：

$$A' = \{x | x \notin A\}$$

#### 2.2.4 差集

差集是指属于集合A但不属于集合B的元素组成的集合。用符号∖表示。例如，A ∖ B表示集合A和集合B的差集。

**运算公式**：

$$A \setminus B = \{x | x \in A \text{ 且 } x \notin B\}$$

### 2.3 集合的基本性质

集合具有以下基本性质：

1. **交换律**：对于任意两个集合A和B，有A ∩ B = B ∩ A和A ∪ B = B ∪ A。
2. **结合律**：对于任意三个集合A、B和C，有(A ∩ B) ∩ C = A ∩ (B ∩ C)和(A ∪ B) ∪ C = A ∪ (B ∪ C)。
3. **分配律**：对于任意三个集合A、B和C，有A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)和A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)。
4. **德摩根律**：对于任意两个集合A和B，有(A ∩ B)' = A' ∪ B'和(A ∪ B)' = A' ∩ B'。

#### 4.1 集合交集算法

集合交集算法用于找出两个集合中共同的元素。其基本原理是基于集合的交集运算，即找出两个集合A和B中的共同元素，组成一个新的集合。

def intersection(A, B):

**数学模型和公式：**

集合交集可以用数学公式表示为：

$$A \cap B = \{x | x \in A \text{ 且 } x \in B\}$$

其中，$A \cap B$ 表示集合A和集合B的交集。

**详细讲解与举例说明：**

假设集合A={1, 2, 3, 4}和集合B={2, 3, 5, 6}，我们希望找到这两个集合的交集。首先，我们初始化一个空集合C。然后，遍历集合A中的每个元素，判断该元素是否在集合B中。如果元素在集合B中，则将其添加到集合C中。最后，输出集合C，即为集合A和集合B的交集。

在这个例子中，集合A中的元素1不在集合B中，因此不添加到集合C中。集合A中的元素2和3在集合B中，因此将它们添加到集合C中。集合A中的元素4不在集合B中，因此也不添加到集合C中。最终，集合C={2, 3}，即为集合A和集合B的交集。

#### 4.2 集合并集算法
