### Step 3: 算法原理讲解

#### 3.1 量子傅里叶变换（QFT）

**3.1.1 Mermaid 流程图：**

```mermaid
sequenceDiagram
    participant Q as Quantum Computer
    participant F as Quantum Fourier Transform
    Q->>F: Prepare initial state
    F->>Q: Apply Hadamard Gate
    F->>Q: Apply Quantum Circuit
    Q->>F: Measure final state
```

**3.1.2 Python 源代码：**

```python
from qiskit import QuantumCircuit, Aer, execute
from qiskit.visualization import plot_bloch_multivector

# 创建量子电路
qc = QuantumCircuit(2)

# 准备初始状态
qc.h(0)
qc.h(1)

# 应用量子傅里叶变换
qc.append(QFTGate().to_gate().inv(), [0, 1])

# 测量最终状态
qc.measure_all()

# 执行量子电路
backend = Aer.get_backend('qasm_simulator')
result = execute(qc, backend, shots=1024).result()

# 可视化结果
plot_bloch_multivector(result.get_counts(qc))
```

**3.1.3 算法原理：**

量子傅里叶变换是一种将量子状态从量子位表示转换为振幅表示的算法。在量子计算中，量子位可以处于多种叠加状态，而量子傅里叶变换可以将这种叠加状态转换为振幅表示，从而实现并行计算。

$$
QFT = \sum_{k=0}^{n-1} \frac{1}{\sqrt{n}} H^k CNOT^{k,n}
$$

其中，$H$ 是哈达玛门，$CNOT$ 是控制非门，$n$ 是量子位的数量。
