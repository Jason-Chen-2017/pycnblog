## 第一部分：巴菲特与芒格的投资理念

### 第1章：巴菲特与芒格的投资哲学

#### 1.1 巴菲特的价值投资理念
##### 1.1.1 价值投资的定义与核心原则
价值投资是一种长期投资策略，强调购买低于其内在价值的股票。其核心原则包括：
1. **安全边际**：购买价格远低于内在价值的资产。
2. **长期视角**：关注企业的长期盈利能力，而非短期波动。
3. **企业质量**：投资具有强大竞争优势和良好管理的企业。

##### 1.1.2 巴菲特的投资策略与成功案例
巴菲特的投资策略以价值投资为核心，成功案例包括可口可乐、IBM和比亚迪。他偏好具有持续增长潜力和高ROE（净资产收益率）的企业。

##### 1.1.3 芒格的多元思维模型
芒格的多元思维模型强调跨学科思考，将多个领域的基本原理结合起来，以做出更明智的决策。他认为，投资的成功不仅依赖于财务数据，还需要对人类心理、经济趋势等有深刻理解。

#### 1.2 能源转型的背景与投资机会
##### 1.2.1 全球能源转型的现状与趋势
全球能源转型正从化石能源向可再生能源转变，推动这一转变的因素包括气候变化、技术进步和政策支持。

##### 1.2.2 新能源革命对传统能源行业的冲击
新能源技术的快速发展导致传统能源行业的利润下降，但同时也创造了新的投资机会。

##### 1.2.3 巴菲特与芒格对新能源投资的重视
巴菲特和芒格认识到新能源行业的巨大潜力，认为其具备长期增长的条件，尤其是太阳能和风能等领域。

### 第7章：数学模型与系统设计

#### 7.1 投资回报分析模型
##### 7.1.1 内部收益率（IRR）计算
IRR是评估投资项目盈利能力的重要指标，公式为：
$$
IRR = r \text{ 满足 } \sum_{t=0}^{n} \frac{C_t}{(1+r)^t} = 0
$$

##### 7.1.2 净现值（NPV）计算
NPV是将未来现金流按折扣率折现后的总和，公式为：
$$
NPV = \sum_{t=0}^{n} \frac{C_t}{(1+r)^t}
$$

#### 8.2 核心实现源代码
##### 8.2.1 计算IRR和NPV的Python代码
```python
import numpy as np

def calculate_irr(cash_flows):
    try:
        irr = np.irr(cash_flows)
        return irr
    except ValueError:
        return None

def calculate_npv(r, cash_flows):
    npv = np.npv(r, cash_flows)
    return npv

# 示例现金流
cash_flows = [-1000000, 300000, 400000, 500000, 400000]
discount_rate = 0.08

irr = calculate_irr(cash_flows)
npv = calculate_npv(discount_rate, cash_flows)

print(f"IRR: {irr}")
print(f"NPV: {npv}")
```
