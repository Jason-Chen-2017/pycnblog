#### 1.1.1 安全边际的定义与作用
安全边际是投资学中的一个核心概念，指资产的市场价格与其内在价值之间的差异。当市场价格低于内在价值时，两者之间的差额即为安全边际。安全边际的作用在于降低投资风险，为投资者提供一个“缓冲区”，避免因市场价格波动而遭受损失。

#### 1.1.2 安全边际在投资决策中的重要性
安全边际是格雷厄姆投资策略的核心，它帮助投资者在市场波动中保持稳健的投资组合。通过计算安全边际，投资者可以识别低估的资产，从而在市场下跌时减少损失，在市场上涨时获得超额收益。

#### 1.1.3 格雷厄姆投资策略的核心思想
格雷厄姆的投资策略强调安全边际的重要性，主张以低于内在价值的价格买入优质资产，并长期持有。这种方法尤其适合防御性投资者，能够在市场低迷时保护资本，同时在市场繁荣时获得收益。

#### 5.3.2 核心代码实现
以下是基于线性回归的安全边际预测模型的代码示例：
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 数据加载
data = pd.read_csv('market_data.csv')

# 特征与目标变量分离
X = data[['price', 'volume', 'pe_ratio']]
y = data['margin']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 模型预测
y_pred = model.predict(X)

# 模型评估
 mse = mean_squared_error(y, y_pred)
 print(f'均方误差: {mse}')
```

- 模型评估：计算均方误差，评估模型的预测性能。
