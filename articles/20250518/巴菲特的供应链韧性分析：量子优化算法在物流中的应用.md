# 第2章: 量子优化算法的基础

## 2.1 量子计算的基本概念

### 2.1.1 量子位与经典位的区别

经典位（bit）只能取0或1，而量子位（qubit）可以同时处于多个状态的叠加态。例如，两个量子位可以表示四种可能的状态：00、01、10、11。

### 2.1.2 量子叠加与量子纠缠

量子叠加是指量子位可以处于多个状态的叠加态，而量子纠缠则是指两个或多个量子位之间存在关联，其中一个量子位的状态会直接影响另一个量子位的状态。

### 2.1.3 量子计算的优势与挑战

优势：
- 处理复杂问题的能力远超经典计算机。
- 在某些特定领域（如优化问题）表现出色。

挑战：
- 量子计算技术尚不成熟，实际应用有限。
- 对环境干扰极为敏感，容易出错。

```python
from qiskit import QuantumCircuit, Aer, execute

def quantum_optimization(n_qubits):
    circuit = QuantumCircuit(n_qubits)
    # 初始化量子状态
    circuit.h(range(n_qubits))
    # 量子叠加
    circuit.measure_all()
    # 执行量子计算
    backend = Aer.get_backend('qasm_simulator')
    result = execute(circuit, backend).result()
    # 获取优化结果
    return result.get_counts()

# 示例：优化3个量子位
result = quantum_optimization(3)
print(result)
```
