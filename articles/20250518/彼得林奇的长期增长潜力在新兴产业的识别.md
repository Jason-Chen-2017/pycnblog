5.2 核心代码实现：
```python
import pandas as pd
import matplotlib.pyplot as plt

def calculate_profit_growth(profits):
    return ((profits[-1] - profits[0]) / profits[0]) * 100

data = pd.read_csv('company_data.csv')
profits = data['利润'].values
growth = calculate_profit_growth(profits)
print(f"利润增长率：{growth}%")

plt.plot(data['年份'], data['利润'])
plt.title('利润增长趋势')
plt.show()
```
