### 第4章：数学模型与公式

#### 4.1 核心数学模型

##### 4.1.1 投资回报率（ROE）公式

$$ROE = \frac{净利润}{平均股东权益}$$

##### 4.1.2 资产回报率（ROA）公式

$$ROA = \frac{净利润}{平均总资产}$$

#### 4.2 详细讲解与举例说明

##### 4.2.1 投资回报率的计算

假设某公司净利润为100万元，平均股东权益为500万元，则：

$$ROE = \frac{100}{500} = 20\%$$

##### 4.2.2 资产回报率的计算

假设某公司净利润为80万元，平均总资产为400万元，则：

$$ROA = \frac{80}{400} = 20\%$$

def analyze(data):
    # 计算ROE
    roe = data['Profit'] / data['Equity']
    # 计算ROA
    roa = data['Profit'] / data['Assets']
    return pd.DataFrame({'ROE': roe, 'ROA': roa})

result = analyze(processed_data)
print(result)
