## 附录A：量子纠错算法的Python代码实现
```python
import numpy as np
from qiskit import QuantumCircuit, Aer, execute

def create_surface_code():
    # 创建量子电路
    circuit = QuantumCircuit(4, 2)
    # 添加H门和CNOT门
    circuit.h(range(4))
    circuit.cnot(0, 1)
    circuit.cnot(1, 2)
    circuit.cnot(2, 3)
    return circuit

# 执行量子模拟
simulator = Aer.get_backend('qasm_simulator')
result = execute(create_surface_code(), simulator).result()
print(result)
```
