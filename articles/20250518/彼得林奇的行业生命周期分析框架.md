## 第1章：行业生命周期的基本概念

### 1.1 行业生命周期的定义
行业生命周期是指一个行业从诞生到成熟，再到衰退的整个发展过程。它类似于企业生命周期，但更宏观地反映了整个行业的发展阶段。

### 1.2 行业生命周期的阶段划分
行业生命周期通常分为四个阶段：
1. **导入期**：行业刚刚起步，市场需求较低，竞争者较少。
2. **成长期**：市场需求快速增长，行业规模扩大，竞争加剧。
3. **成熟期**：市场需求趋于饱和，行业规模稳定，竞争格局基本确定。
4. **衰退期**：市场需求下降，行业规模缩小，竞争者逐渐退出。

### 1.3 行业生命周期分析的意义
行业生命周期分析能够帮助投资者识别行业所处的发展阶段，从而制定相应的投资策略。例如，在成长期投资高增长行业，在衰退期避免投资夕阳行业。

## 第4章：行业生命周期的数学模型与算法原理

### 4.1 行业生命周期的量化指标
常用量化指标包括：
- 市场增长率（Market Growth Rate）：反映市场需求的变化趋势。
- 行业集中度（Market Concentration）：反映行业竞争格局。
- 利润率（Profitability）：反映行业盈利能力。

### 4.2 行业生命周期的数学模型
$$
\text{市场增长率} = \frac{\text{当年销售额} - \text{前年销售额}}{\text{前年销售额}} \times 100\%
$$

$$
\text{行业集中度} = \frac{\text{前几大企业的市场份额之和}}{\text{行业总市场份额}} \times 100\%
$$

### 4.3 行业生命周期的算法实现
以下是基于市场增长率和行业集中度的行业生命周期判断算法：

```python
def determine_industry_stage(growth_rate, concentration):
    if growth_rate > 20 and concentration < 40:
        return "导入期"
    elif growth_rate > 10 and concentration < 60:
        return "成长期"
    elif growth_rate < 5 and concentration > 60:
        return "成熟期"
    else:
        return "衰退期"
```
