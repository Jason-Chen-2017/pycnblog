# 第1章 全球股市估值的基本概念

## 1.1 股市估值的定义与特点
### 1.1.1 股市估值的基本概念
股市估值是通过股票价格和相关指标计算市场整体价值的过程，反映经济健康状况。主要指标包括市盈率（P/E）和市净率（P/B）。

### 1.1.2 全球股市估值的核心特点
- 受经济指标影响：GDP、利率、汇率等。
- 反映市场情绪：投资者信心影响股市波动。
- 全球化特征：国际事件对全球股市产生连锁反应。

### 1.1.3 股市估值与经济指标的关系
股市估值通过P/E等指标反映经济状况，经济繁荣时股市估值上升，反之则下降。

## 1.2 可持续城市地下物流系统的定义与特点
### 1.2.1 地下物流系统的定义
地下物流系统指在城市地下空间中，通过专用通道进行物资运输和配送的系统，减少交通拥堵和环境污染。

### 1.2.2 可持续物流的核心要素
- 环境友好：减少碳排放。
- 经济高效：优化运输成本。
- 社会效益：提升城市生活质量。

### 1.2.3 地下物流系统与城市发展的关系
地下物流系统是城市基础设施的重要组成部分，支持城市经济活动，提升物流效率。

## 1.3 本章小结
本章介绍了全球股市估值和可持续城市地下物流系统的定义及特点，为后续分析奠定了基础。

- 绘图库：Matplotlib、Seaborn
- Mermaid支持工具：Visual Studio Code、Jupyter Notebook

## 6.2 系统核心实现源代码
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载
data = pd.read_csv('logistics_stock.csv')

# 数据预处理
# 假设'logistics_cost'、'gdp'、'interest_rate'为自变量，'stock_value'为目标变量
X = data[['logistics_cost', 'gdp', 'interest_rate']]
y = data['stock_value']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 模型预测
y_pred = model.predict(X)

# 模型评估
print(f"R² Score: {r2_score(y, y_pred)}")
print(f"回归系数：{model.coef_}")
```
