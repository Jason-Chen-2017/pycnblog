## 第一部分：格雷厄姆特价股票策略概述

### 第1章：价值投资与格雷厄姆策略背景

#### 1.1 价值投资的起源与发展

##### 1.1.1 价值投资的定义与核心理念
价值投资是一种投资策略，强调以低于内在价值的价格购买优质资产。其核心理念是通过深入分析企业的基本面，寻找市场低估的机会。格雷厄姆是价值投资的鼻祖，他提出了“安全边际”概念，即以低于估算价值的价格购买资产，以降低风险。

##### 1.1.2 格雷厄姆投资理论的贡献
格雷厄姆在《 Intelligent Investor》中系统阐述了价值投资理论，提出了多项筛选指标，如市盈率（P/E）、市净率（P/B）等，为后续投资者提供了重要参考。他的理论强调长期投资和安全边际，至今仍是价值投资的核心。

##### 1.1.3 格雷厄姆策略在现代投资中的地位
尽管市场环境变化，格雷厄姆策略仍被广泛应用于股票筛选中，尤其是寻找低估股票。然而，不同市值公司的特点可能会影响策略的有效性，因此需要深入比较。

#### 1.2 格雷厄姆特价股票策略的核心概念

##### 1.2.1 安全边际的定义与计算
安全边际 = 股票市场价格 < 内在价值 × 安全边际比例（通常为 20%-30%）。公式为：
$$ \text{安全边际} = \text{内在价值} \times (1 - \text{安全边际比例}) $$

##### 1.2.2 内在价值的评估方法
内在价值是公司未来现金流的现值，可通过DCF模型计算：
$$ \text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} + \frac{\text{残值}}{(1 + r)^n} $$

##### 1.2.3 稀有低价股票的筛选标准
格雷厄姆筛选标准包括低市盈率（<15）、低市净率（<1.5）和高股息率（>5%）。表格对比不同市值公司的筛选标准：

| 市值规模 | 筛选标准 |
|---------|----------|
| 小盘股 | P/E <10, P/B <1.2, 股息率>6% |
| 中盘股 | P/E <12, P/B <1.5, 股息率>5% |
| 大盘股 | P/E <15, P/B <2, 股息率>4% |

## 第二部分：格雷厄姆策略的数学模型与算法原理

### 第3章：格雷厄姆策略的数学模型

#### 3.1 格雷厄姆策略的核心公式

##### 3.1.1 市盈率（P/E）计算公式
$$ \text{市盈率} = \frac{\text{股价}}{\text{每股收益}} $$

##### 3.1.2 市净率（P/B）计算公式
$$ \text{市净率} = \frac{\text{股价}}{\text{每股净资产}} $$

##### 3.1.3 内在价值计算公式
$$ \text{内在价值} = \text{股息率} \times \text{市盈率} $$

#### 3.2 格雷厄姆策略的筛选标准

##### 3.2.1 稀有低价股票的筛选条件
$$ \text{股价} < \text{内在价值} \times (1 - \text{安全边际比例}) $$

##### 3.2.2 安全边际的计算公式
$$ \text{安全边际} = \text{内在价值} \times \text{安全边际比例} $$

##### 3.2.3 市场波动对策略的影响
格雷厄姆策略在市场波动较大时更具优势，但需动态调整筛选标准。

#### 4.2 Python实现代码

```python
import pandas as pd

def graham_screen(data, market_cap):
    # 计算P/E和P/B
    data['P/E'] = data['股价'] / data['每股收益']
    data['P/B'] = data['股价'] / data['每股净资产']
    
    # 根据市值规模筛选
    if market_cap == '小盘股':
        data = data[data['P/E'] < 10]
        data = data[data['P/B'] < 1.2]
        data = data[data['股息率'] > 6]
    elif market_cap == '中盘股':
        data = data[data['P/E'] < 12]
        data = data[data['P/B'] < 1.5]
        data = data[data['股息率'] > 5]
    else:
        data = data[data['P/E'] < 15]
        data = data[data['P/B'] < 2]
        data = data[data['股息率'] > 4]
        
    return data
```
