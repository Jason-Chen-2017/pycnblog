## 第二部分: 格雷厄姆特价股票理论的核心公式与模型

### 第3章: 格雷厄姆多步价值评估法

#### 3.1 内在价值公式
$$
\text{内在价值} = \frac{\text{净利润} \times (5 + 长期债务)}{\text{权益资本成本}}
$$

#### 3.2 市盈率与市净率分析
$$
\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}
$$
$$
\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}
$$

### 第4章: 数字平台经济的估值模型

#### 4.1 用户价值模型
$$
\text{用户价值} = \text{用户生命周期价值} \times \text{用户留存率}
$$

#### 4.2 收入驱动模型
$$
\text{收入驱动价值} = \frac{\text{未来自由现金流的现值}}{\text{折现率}}
$$

#### 4.3 市场领导地位模型
$$
\text{市场领导地位价值} = \text{市场份额} \times \text{行业增长潜力}
$$

- 2. 当市场价格接近内在价值时，持有  
- 3. 当市场价格 > 内在价值时，卖出  

### 第6章: 算法实现代码

#### 6.2 核心代码实现
```python
import numpy as np
import pandas as pd

def calculate_intrinsic_value(eps, peg, book_value):
    return (eps * (5 + peg)) / book_value

def investment_decision(stock_price, intrinsic_value):
    if stock_price < intrinsic_value:
        return "买入"
    elif stock_price == intrinsic_value:
        return "持有"
    else:
        return "卖出"

# 示例数据
data = {
    'eps': [10, 15, 20],
    'peg': [2.5, 3.0, 3.5],
    'book_value': [50, 60, 70],
    'stock_price': [100, 120, 150]
}

df = pd.DataFrame(data)

# 计算内在价值
df['intrinsic_value'] = df.apply(lambda x: calculate_intrinsic_value(x['eps'], x['peg'], x['book_value']), axis=1)

# 投资决策
df['decision'] = df.apply(lambda x: investment_decision(x['stock_price'], x['intrinsic_value']), axis=1)

print(df)
```
