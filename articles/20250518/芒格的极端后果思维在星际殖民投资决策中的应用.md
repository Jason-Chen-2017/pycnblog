2. **数据分析**：识别关键风险因素。
3. **模型训练**：使用历史数据训练模型。

### 4.3 数学模型

风险评估公式：
$$ R = \sum_{i=1}^{n} (P_i \times I_i) $$
其中，\( R \) 是总风险，\( P_i \) 是第 \( i \) 个后果的概率，\( I_i \) 是影响程度。

import numpy as np
import matplotlib.pyplot as plt

def calculate_risk(factors):
    # 计算每个因素的风险值
    risks = []
    for factor in factors:
        p = np.random.uniform(0, 1)
        i = np.random.uniform(0, 1)
        risks.append(p * i)
    return sum(risks)

factors = ['设备故障', '人员健康', '资金不足']
result = calculate_risk(factors)
print(f"总风险值为：{result}")
