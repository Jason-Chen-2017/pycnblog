## 第1章 格雷厄姆特价股票理论概述

### 1.1 格雷厄姆投资理论的核心理念

#### 1.1.1 价值投资的基本原则
- **内在价值**：股票的真正价值是其未来现金流的现值。
- **安全边际**：以低于内在价值的价格买入股票，以降低投资风险。

#### 1.1.2 格雷厄姆的"安全边际"概念
- 安全边际 = 内在价值 - 市场价格
- 通过安全边际，投资者可以在市场波动中保持投资的稳定性。

#### 1.1.3 投资组合的构建与管理
- 投资组合分散化：避免过度集中，降低风险。
- 定期调整：根据市场变化和公司情况，动态优化投资组合。

### 1.2 特价股票的定义与特征

#### 1.2.1 特价股票的定义
- 特价股票是指市场价格低于其内在价值的股票。
- 具备长期增长潜力，但当前市场价格被低估。

#### 1.2.2 特价股票的市场特征
- 市场价格波动大，但内在价值稳定。
- 投资者可以通过深入分析发现潜在价值。

#### 1.2.3 特价股票的投资机会与风险
- 机会：低价买入，高价卖出，获取超额收益。
- 风险：市场波动可能导致短期亏损，需要耐心和长期持有。

### 1.3 格雷厄姆理论在现代投资中的应用

#### 1.3.1 格雷厄姆理论的演变
- 从格雷厄姆的经典理论到现代价值投资的演变。
- 结合现代金融工具和市场环境，理论的应用更加多样化。

#### 1.3.2 格雷厄姆理论在机构投资中的应用
- 机构投资者利用格雷厄姆理论构建稳健的投资组合。
- 结合量化分析和基本面分析，提高投资决策的科学性。

#### 1.3.3 格雷厄姆理论与个人投资者的结合
- 个人投资者可以通过格雷厄姆理论，实现理性投资。
- 理解安全边际和内在价值，避免盲目跟风。

## 第2章 社会影响力投资的背景与现状

### 2.1 社会影响力投资的定义与特征

#### 2.1.1 社会影响力投资的定义
- 社会影响力投资是指将资金投资于能够产生社会价值和经济回报的项目或企业。

#### 2.1.2 社会影响力投资的核心特征
- **双重目标**：追求财务回报和社会价值。
- **长期性**：注重长期的社会影响力，而非短期收益。
- **多样性**：覆盖多个行业和领域，具有较高的灵活性。

#### 2.1.3 社会影响力投资的分类
- 慈善投资（Philanthropy）：以慈善为目的，不追求财务回报。
- 社会责任投资（SRI）：关注企业社会责任，结合财务回报。
- 可持续投资（Sustainable Investment）：注重环境保护和可持续发展。

#### 2.2.2 社会影响力投资的全球发展趋势

#### 2.2.3 社会影响力投资的未来展望
- 随着技术的进步和社会的发展，社会影响力投资将更加多元化和专业化。

#### 2.3.1 投资目标的差异
- 传统投资：以财务回报为主要目标。
- 社会影响力投资：以双重目标为核心。

    social_contribution = company_data['社会贡献']
    environmental_impact = company_data['环境影响']
    csr = company_data['企业社会责任']

#### 7.2.3 筛选特价股票

def screen_special_stocks(stocks, discount_rate):
    special_stocks = []
    for stock in stocks:
        intrinsic_value = calculate_intrinsic_value(stock['现金流'], discount_rate)
        market_price = stock['市场价格']
        social_impact_score = calculate_social_impact_score(stock['公司数据'])
        if market_price < intrinsic_value and social_impact_score > 0.7:
            special_stocks.append(stock)
    return special_stocks
