#### 4.1 决策一致性分析的数学模型

决策一致性指数是用来衡量管理层决策一致性的指标。

##### 4.1.2 决策一致性指数的计算公式
$$
\text{决策一致性指数} = \frac{\sum_{i=1}^{n} |D_i - D_{i-1}|}{n-1}
$$
其中，$D_i$ 表示第 $i$ 个决策，$D_{i-1}$ 表示第 $i-1$ 个决策。

##### 4.1.3 决策一致性指数的权重分配

- **可预测性权重**：0.3

##### 4.2.1 决策一致性指数的数学表达式

```python
def calculate_consistency_index(data):
    # 计算决策一致性指数
    decisions = data['Decision'].values
    n = len(decisions)
    total = 0
    for i in range(1, n):
        total += abs(decisions[i] - decisions[i-1])
    consistency_index = total / (n-1)
    return consistency_index
```
