## 第一部分：价值投资的背景与基础

### 1.1 价值投资的核心概念

#### 1.1.1 价值投资的定义与核心要素

价值投资是一种以基本面分析为基础的投资策略，强调以低于资产内在价值的价格买入优质资产，长期持有，获得超额收益。其核心要素包括：

- **内在价值**：资产在合理估值下的实际价值，与市场波动无关。
- **市场价值**：资产在市场上的交易价格，受情绪和市场波动影响。
- **安全边际**：买入价格与内在价值的差距，提供风险缓冲。

#### 1.1.2 费雪与格雷厄姆的理论背景

- **费雪的成长型投资理论**：
  - 提出者：菲利普·费雪（Philip Fisher）
  - 核心思想：投资于具有持续增长潜力的企业，关注成长股。
  - 分析方法：注重企业盈利能力、管理团队和行业地位。

- **格雷厄姆的深度价值投资理论**：
  - 提出者：本杰明·格雷厄姆（Benjamin Graham）
  - 核心思想：寻找市场价格低于内在价值的股票，注重安全边际。
  - 分析方法：关注市盈率、市净率等估值指标，寻找被低估的资产。

## 第二部分：费雪的成长型价值投资

### 2.1 费雪投资理论的核心要素

#### 2.1.1 成长型投资的定义与特点

- **定义**：成长型投资是一种以企业成长潜力为核心的投资策略，注重长期收益而非短期价格波动。
- **特点**：
  - 高成长性：企业收入和利润持续增长。
  - 高市盈率：通常高于行业平均水平。
  - 长期投资：注重企业的长期价值，而非短期价格波动。

#### 2.1.2 费雪的投资策略

- **选股标准**：
  - 高ROE（净资产收益率）：ROE > 行业平均水平。
  - 高利润增长率：利润增长率 > 行业平均水平。
  - 行业龙头：选择行业内的领先企业。

- **投资组合构建**：
  - 集中投资：将大部分资金投资于少数优质企业。
  - 长期持有：避免频繁交易，降低交易成本。

- **数学模型**：
  $$\text{成长性评估公式} = \frac{\text{净利润增长率}}{\text{行业平均增长率}}$$
  - 举例：某企业净利润增长率为20%，行业平均为10%，则成长性评估为2。

## 第三部分：格雷厄姆的深度价值投资

### 3.1 格雷厄姆投资理论的核心要素

#### 3.1.1 深度价值投资的定义与特点

- **定义**：深度价值投资是一种以低于内在价值的价格买入优质资产的投资策略，注重安全边际。
- **特点**：
  - 低市盈率：市盈率低于行业平均水平。
  - 低市净率：市净率低于行业平均水平。
  - 高股息率：股息收益率较高。

#### 3.1.2 格雷厄姆的投资策略

- **选股标准**：
  - 低市盈率：市盈率 < 行业平均水平。
  - 低市净率：市净率 < 行业平均水平。
  - 高股息率：股息收益率 > 行业平均水平。

- **投资组合构建**：
  - 分散投资：通过分散投资降低风险。
  - 逆向投资：在市场恐慌时买入低估资产。

- **数学模型**：
  $$\text{内在价值} = \frac{\text{未来现金流}}{\text{折现率}}$$
  - 举例：某企业未来现金流为100万元，折现率为5%，则内在价值为2000万元。

## 第四部分：费雪与格雷厄姆的比较分析

### 4.1 费雪与格雷厄姆的核心区别

| 对比维度 | 费雪的成长型投资 | 格雷厄姆的深度价值投资 |
|----------|------------------|-------------------------|
| 投资目标 | 追求长期成长收益 | 追求安全边际和低估资产 |
| 分析方法 | 关注成长性指标 | 关注估值指标 |
| 适用场景 | 市场增长阶段 | 市场下跌或低估阶段 |

### 4.2 费雪与格雷厄姆的共同点

- 都强调基本面分析。
- 都注重长期投资。
- 都强调安全边际。

## 第五部分：投资策略与实战

### 5.1 费雪投资策略的实战应用

#### 5.1.1 选股标准

- 选取ROE > 15%，净利润增长率 > 10%的企业。
- 例如：某科技公司ROE为20%，净利润增长率为15%，符合成长型投资标准。

#### 5.1.2 投资组合构建

- 集中投资于3-5家优质成长型企业。
- 持股期限：5年以上。

### 5.2 格雷厄姆投资策略的实战应用

#### 5.2.1 选股标准

- 选取市盈率 < 15倍，市净率 < 2倍的企业。
- 例如：某银行股市盈率为12倍，市净率为1.8倍，符合深度价值投资标准。

#### 5.2.2 投资组合构建

- 分散投资于10-15家低估企业。
- 持股期限：1-3年。

# 费雪成长型投资筛选
def fisher_growth_screen(df, industry_avg_growth):
    df['growth_score'] = df['净利润增长率'] / industry_avg_growth
    return df[df['growth_score'] > 1]

# 格雷厄姆深度价值投资筛选
def graham_value_screen(df, industry_avg_pe, industry_avg_pb):
    df['value_score'] = (df['市盈率'] < industry_avg_pe) & (df['市净率'] < industry_avg_pb)
    return df[df['value_score']]
