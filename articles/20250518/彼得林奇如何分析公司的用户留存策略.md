  - 留存概率计算的Python代码
    ```python
    import numpy as np
    import matplotlib.pyplot as plt

    # 示例数据
    d = 0.1  # 流失概率
    t = 10   # 时间单位

    # 计算留存概率
    retention_probs = [(1 - d) ** i for i in range(1, t + 1)]

    # 可视化
    plt.plot(retention_probs)
    plt.xlabel('时间单位')
    plt.ylabel('留存概率')
    plt.title('用户留存概率曲线')
    plt.show()
    ```

  - 马尔可夫链模型的实现
    ```python
    def markov_chain(states, transition_matrix):
        # states: 状态列表
        # transition_matrix: 状态转移矩阵
        current_state = states[0]
        while True:
            print(current_state)
            next_state = np.random.choice(states, p=transition_matrix[states.index(current_state)])
            current_state = next_state

    states = ['活跃', '流失']
    transition_matrix = [
        [0.8, 0.2],
        [0, 1]
    ]
    markov_chain(states, transition_matrix)
    ```
