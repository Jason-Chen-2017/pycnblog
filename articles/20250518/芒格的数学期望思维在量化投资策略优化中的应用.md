## 第二部分：数学期望的基本概念与应用

### 2.1 数学期望的定义与性质

#### 2.1.1 期望值的定义
数学期望是随机变量可能取值的加权平均，权重为相应的概率。例如，掷骰子的期望值为3.5。

#### 2.1.2 期望值的性质与特点
- 线性性质：期望值是线性的，不受变量之间依赖关系的影响。
- 非负性：若所有可能的取值非负，则期望值也非负。

#### 2.1.3 期望值在概率论中的地位
期望值是概率论的核心工具，用于评估随机变量的长期平均表现。

### 2.2 数学期望在投资决策中的作用

#### 2.2.1 投资决策中的期望收益
通过计算资产的期望收益，投资者可以评估其风险调整后的收益。

#### 2.2.2 期望值与风险评估的关系
风险越高，资产的期望收益可能越高，但实际结果可能偏离期望值。

#### 2.2.3 期望值在资产配置中的应用
通过优化资产配置，投资者可以最大化期望收益，同时最小化风险。

### 5.1 蒙特卡洛模拟

#### 5.1.1 算法原理
通过模拟大量随机场景，计算资产的期望收益和风险，评估投资策略的可行性。

#### 5.1.2 实现步骤
1. 确定变量分布
2. 生成随机数
3. 计算期望值
4. 分析结果

#### 5.1.3 代码实现

```python
import numpy as np

# 定义随机变量
np.random.seed(42)
n_samples = 1000
returns = np.random.normal(0.05, 0.15, n_samples)

# 计算期望值

```

### 5.2 马科维茨投资组合理论

#### 5.2.1 理论基础
通过优化投资组合，最大化期望收益，最小化风险。

#### 5.2.2 数学模型
$$ \text{目标函数：} \quad \min_w \frac{1}{2} w^T \Sigma w $$
$$ \text{约束条件：} \quad w^T \mu = \text{目标收益}, \quad \sum_{i=1}^n w_i = 1, \quad w_i \geq 0 $$

#### 5.2.3 实现步骤
1. 计算资产收益和协方差矩阵
2. 构建优化问题
3. 解决优化问题
4. 确定最优权重

#### 5.2.4 代码实现
```python
import numpy as np
from scipy.optimize import minimize

# 定义优化函数
def optimize_portfolio(weights, returns, covariance_matrix, target_return):
    # 目标函数：最小化方差
    def objective(weights):
        return np.dot(weights, np.dot(covariance_matrix, weights))
    
    # 约束条件
    constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
                   {'type': 'eq', 'fun': lambda w: np.dot(weights, returns) - target_return}]
    
    # 解决优化问题
    result = minimize(objective, np.ones(len(weights)), method='SLSQP', constraints=constraints)
    return result.x

# 示例数据
n_assets = 3
returns = np.array([0.05, 0.10, 0.08])
covariance_matrix = np.array([
    [0.02, 0.01, 0.01],
    [0.01, 0.03, 0.02],
    [0.01, 0.02, 0.03]
])
weights = np.ones(n_assets) / n_assets

target_return = 0.08
optimal_weights = optimize_portfolio(weights, returns, covariance_matrix, target_return)
print(f"最优权重：{optimal_weights}")
```
