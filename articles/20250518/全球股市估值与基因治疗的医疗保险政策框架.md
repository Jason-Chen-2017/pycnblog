## 第二部分：全球股市估值基础

### 第2章：全球股市估值理论

#### 2.1 股市估值的基本原理
股市估值是通过对公司财务数据和市场趋势的分析，确定股票的内在价值。常用的方法包括：

- **市盈率（P/E）**：$$\text{P/E} = \frac{\text{股价}}{\text{每股收益}}$$
- **市净率（P/B）**：$$\text{P/B} = \frac{\text{股价}}{\text{每股净资产}}$$

#### 2.2 股市估值模型
以下是一个简单的股票估值模型：

```mermaid
graph TD
    A[开始] --> B[收集财务数据]
    B --> C[计算关键指标]
    C --> D[应用估值模型]
    D --> E[得出估值]
```

Python代码示例：

```python
def calculate_pe_ratio(price, earnings):
    return price / earnings

# 示例数据
price = 100
earnings = 10
pe_ratio = calculate_pe_ratio(price, earnings)
print(f"市盈率为：{pe_ratio}")
```
