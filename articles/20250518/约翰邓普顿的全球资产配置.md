## 第三部分: 资产配置的数学模型与公式

### 第4章: 资产配置的数学模型

#### 4.1 现代投资组合理论的优化公式
- **目标函数**：最小化投资组合的方差（风险）。
$$ \text{目标函数：} \quad \min_w \, w^T \Sigma w $$
- **约束条件**：投资权重之和为1。
$$ \sum_{i=1}^n w_i = 1 $$

#### 4.2 资产配置的风险-收益权衡公式
- **收益**：投资组合的预期收益。
$$ \text{收益} = \sum_{i=1}^n w_i r_i $$
- **风险**：投资组合的风险，通常用标准差衡量。
$$ \text{风险} = \sqrt{\sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij}} $$

#### 6.2 核心代码实现
```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def portfolio_variance(weights, covariance_matrix):
    return np.dot(weights.T, np.dot(covariance_matrix, weights))

def portfolio_optimization(returns, covariance_matrix, target_return):
    n = len(weights)
    constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
    result = minimize(portfolio_variance, np.ones(n)/n, args=covariance_matrix, method='SLSQP', constraints=constraints)
    return result.x

# 示例数据
returns = pd.DataFrame({
    '股票': [0.1, 0.05, 0.07],
    '债券': [0.03, 0.04, 0.06],
    '房地产': [0.08, 0.05, 0.09]
})

covariance_matrix = returns.cov()
weights = portfolio_optimization(returns, covariance_matrix, target_return=0.06)
print("最优权重：", weights)
```

- **案例背景**：假设投资者希望获得6%的预期收益，风险承受能力中等。
- **分析步骤**：计算不同资产类别的预期收益和风险，优化资产配置比例。
- **结果解读**：根据优化结果，建议投资者将资金分配到股票、债券和房地产的不同比例。
