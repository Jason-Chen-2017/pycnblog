### 附录B: 代码实现示例

#### B.1 股息率计算的Python代码
```python
import pandas as pd

# 示例数据
data = {
    '公司': ['A', 'B', 'C'],
    '股价': [100, 150, 200],
    '每股股息': [2, 3, 4]
}
df = pd.DataFrame(data)

# 计算股息率
df['股息率'] = (df['每股股息'] / df['股价']) * 100
print(df)
```

#### B.2 股息增长预测的线性回归模型
```python
import statsmodels.api as sm

# 示例数据
x = [1, 2, 3, 4, 5]
y = [2, 3, 5, 6, 7]

# 添加截距项
x = sm.add_constant(x)

# 建立模型
model = sm.OLS(y, x)
results = model.fit()

# 输出结果
print(results.summary())
```
