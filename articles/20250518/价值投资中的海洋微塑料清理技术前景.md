## 第2章：海洋微塑料清理技术的背景与问题描述  

### 2.1 海洋微塑料的定义与现状  
微塑料指直径小于5毫米的塑料颗粒，广泛存在于海洋中，来源包括工业排放、垃圾处理等。  

### 2.2 微塑料对环境与生态的影响  
微塑料破坏海洋生态系统，影响生物多样性和食物链，威胁人类健康。  

### 2.3 清理技术的必要性与挑战  
现有技术如机械筛选、化学分解等各有优劣，但成本高、效率低，亟需创新解决方案。

import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据预处理
data = pd.read_csv('data.csv')
X = data[['demand', 'cost']]
y = data['value']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测
new_data = pd.DataFrame({'demand': [100], 'cost': [50]})
predicted_value = model.predict(new_data)
print(predicted_value)
