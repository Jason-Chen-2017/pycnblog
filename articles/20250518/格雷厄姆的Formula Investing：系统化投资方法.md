## 第2章: 核心概念与联系

### 2.1 价值投资的核心概念

#### 2.1.1 内在价值的定义与计算
- 内在价值（Intrinsic Value）：企业未来现金流的现值。
- 计算公式：
  $$ V = \frac{E}{P} $$
  其中，E为未来现金流，P为折现率。

#### 2.1.2 安全边际的原理与应用
- 安全边际：内在价值与市场价格之间的差额，提供缓冲以应对市场波动。
- 应用：选择市场价格低于内在价值的企业进行投资。

#### 2.1.3 股票与企业价值的关系
- 股票是企业的部分所有权，其价值取决于企业的盈利能力。
- 企业价值 = 股权价值 + 债务价值。

### 2.2 格雷厄姆的公式分析

#### 2.2.1 内在价值公式
- 格雷厄姆的内在价值公式：
  $$ V = \frac{E}{P} $$
  其中，E为预期收益，P为折现率。

#### 2.2.2 市盈率与市净率的比较
- 市盈率（P/E）：股价与每股收益的比率。
- 市净率（P/B）：股价与每股净资产的比率。
- 比较：市盈率适用于盈利稳定的公司，市净率适用于净资产较多的公司。

#### 2.2.3 其他相关公式与应用
- 总资产周转率：
  $$ \text{总资产周转率} = \frac{\text{营业收入}}{\text{平均总资产}} $$
- 净利润率：
  $$ \text{利润率} = \frac{\text{净利润}}{\text{营业收入}} $$

### 2.3 核心概念的联系与对比

#### 2.3.1 价值投资与成长投资的对比
| 对比维度 | 价值投资 | 成长投资 |

### 5.2 核心代码实现

#### 5.2.1 内在价值计算
```python
import pandas as pd

def calculate_intrinsic_value(earnings, discount_rate):
    return earnings / discount_rate

# 示例数据
df = pd.DataFrame({'Earnings': [100, 200, 300], 'Discount Rate': [0.1, 0.12, 0.08]})
df['Intrinsic Value'] = df.apply(lambda x: calculate_intrinsic_value(x['Earnings'], x['Discount Rate']), axis=1)
print(df)
```

#### 5.2.2 安全边际计算
```python
def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
iv = [150, 250, 350]
mp = [120, 200, 300]
df = pd.DataFrame({'Intrinsic Value': iv, 'Market Price': mp})
df['Margin of Safety'] = df.apply(lambda x: calculate_margin_of_safety(x['Intrinsic Value'], x['Market Price']), axis=1)
print(df)
```
