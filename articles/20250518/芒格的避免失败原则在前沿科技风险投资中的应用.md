## 第3章：芒格“避免失败”原则的数学模型

### 3.1 决策树模型的构建  
芒格的“避免失败”原则可以通过决策树模型来表示。决策树帮助投资者在不同决策节点上评估可能的结果，选择最优路径。  
- **节点定义**：每个节点代表一个决策点，边代表可能的结果，权重代表概率。  
- **决策树构建**：通过分析每个决策点的可能结果和概率，构建决策树并进行剪枝，选择概率最高的路径。  

### 3.2 概率分析模型  
芒格的概率分析模型通过计算每个投资标的成功的概率，帮助投资者做出决策。  
- **成功概率公式**：  
  $$ P(\text{成功}) = \frac{\text{成功案例数}}{\text{总案例数}} $$  
- **风险调整后的期望值公式**：  
  $$ E = \sum (P_i \times R_i) $$  

### 3.3 决策树与概率分析的结合  
通过结合决策树和概率分析，投资者可以在每个决策点评估不同路径的概率和收益，最终选择风险最小、收益最大的路径。

### 5.2 系统核心实现代码  
```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('tech_invest.csv')

# 成功概率计算
def calculate_success_probability(data):
    success = data[data['result'] == 'success']
    probability = len(success) / len(data)
    return probability

# 风险评估
def risk_assessment(probability):
    if probability > 0.7:
        return 'high'
    elif probability > 0.4:
        return 'medium'
    else:
        return 'low'

# 投资决策
def investment_decision(probability, risk):
    if risk == 'high' and probability > 0.6:
        return 'invest'
    else:
        return 'avoid'

# 示例分析
prob = calculate_success_probability(data)
risk = risk_assessment(prob)
decision = investment_decision(prob, risk)
print(f"成功概率：{prob}, 风险等级：{risk}, 投资决策：{decision}")
```
