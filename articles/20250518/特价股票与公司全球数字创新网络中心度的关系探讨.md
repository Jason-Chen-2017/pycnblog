## 第1章: 特价股票与数字创新网络中心度的背景介绍

### 1.1 特价股票的基本概念
#### 1.1.1 特价股票的定义
- 特价股票是指价格相对较低，具有较大上涨潜力的股票。
- 它通常属于中小盘股，市场波动较大，但投资回报可能较高。

#### 1.1.2 特价股票的分类与特点
- 按行业分类：科技、消费、制造等。
- 特点：价格波动大、流动性适中、投资者情绪影响显著。

#### 1.1.3 特价股票在金融市场中的地位与作用
- 特价股票是中小投资者的主要投资对象。
- 在市场波动中，特价股票往往具有较大的反弹潜力。

### 1.2 公司全球数字创新网络的概念
#### 1.2.1 数字创新网络的定义
- 数字创新网络是指由公司、技术、数据等构成的数字化创新生态系统。
- 它通过数字化技术连接不同创新主体，形成协同效应。

#### 1.2.2 数字创新网络的核心要素
| 要素 | 描述 |
|------|------|
| 公司 | 参与创新的核心主体 |
| 技术 | 创新过程中的关键工具 |
| 数据 | 创新决策的基础 |
| 网络 | 连接各要素的平台 |

#### 1.2.3 全球数字创新网络的构建与特征
- 构建特征：数据驱动、技术支撑、网络协同。
- 特征：开放性、动态性、高度互联性。

### 1.3 数字创新网络中心度的定义与意义
#### 1.3.1 中心度在图论中的基本概念
- 中心度：衡量网络中节点的重要程度的指标。
- 主要类型：度中心度、中间中心度、接近中心度。

#### 1.3.2 数字创新网络中心度的特殊性
- 在数字创新网络中，中心度反映了公司在创新网络中的影响力。
- 中心度高的公司更容易获取资源和创新机会。

#### 1.3.3 中心度在公司全球数字创新网络中的应用价值
- 识别关键创新节点。
- 分析创新网络的结构特征。
- 评估公司的创新影响力。

### 1.4 特价股票与数字创新网络中心度关系的初步探讨
#### 1.4.1 问题背景与研究意义
- 背景：数字技术对企业创新的影响日益显著。

### 2.1 特价股票的特征分析

### 2.2 数字创新网络中心度的属性特征
#### 2.2.1 中心度的度量指标
- 度中心度：节点的直接连接数量。
- 中间中心度：节点在最短路径中的作用程度。
- 接近中心度：节点到其他节点的平均距离。

#### 2.2.2 数字创新网络中心度的计算方法
- 度中心度公式：$$C_d(v) = \sum_{u} A_{v,u}$$

- 接近中心度公式：$$C_a(v) = \frac{1}{\sum_{u} d(v, u)}$$

#### 2.2.3 数字创新网络中心度的网络位置特征
- 高中心度节点是网络的关键节点，具有较大的影响力。
- 中心度分布反映网络的结构特征。

### 2.3 特价股票与数字创新网络中心度的关系模型
#### 2.3.1 关系模型的构建逻辑
- 中心度高的公司更容易吸引投资者关注。
- 投资者情绪和市场行为会影响特价股票的价格。

#### 2.3.2 关系模型的数学表达式
- 中心度与股价的关系：$$P(t) = \alpha C(v) + \beta E(t) + \gamma$$

#### 2.3.3 模型的假设条件与限制
