## 第一部分：格雷厄姆特价股票理论基础

### 第1章：格雷厄姆特价股票理论概述

#### 1.1 价值投资的鼻祖：本杰明·格雷厄姆

- 格雷厄姆是价值投资的奠基人，其核心理念在于寻找市场价格低于内在价值的股票。
- 他强调安全性，主张以低于合理价值的价格买入股票，以确保本金的安全。
- 格雷厄姆的学生彼得·林奇和沃伦·巴菲特继承并发扬了他的投资理念。

#### 1.2 格雷厄姆的投资哲学

- **安全边际**：买入价格远低于内在价值的股票，以降低风险。
- **市场先生**：将市场波动视为机会，而非风险。
- **逆向思维**：在市场恐慌时寻找机会，避免追涨杀跌。

#### 1.3 格雷厄姆廉价股的核心指标

- **市盈率（P/E）**：股价与每股收益的比率，低市盈率可能意味着低估。
- **市净率（P/B）**：股价与每股净资产的比率，低市净率通常表示资产被低估。
- **股息率**：股息与股价的比率，高股息率可能意味着收益稳定。

#### 2.2 格雷厄姆理论的现代诠释

- **自动化筛选**：通过算法快速扫描市场，寻找符合格雷厄姆标准的股票。
- **量化分析**：将基本面指标转化为数学模型，结合技术分析。
- **防御性投资**：在市场波动中保持投资组合的稳定性。

#### 2.3 理论的局限性与改进

- **市场有效性**：在有效市场中，价值投资可能失效。
- **短期波动**：格雷厄姆的长期视角可能与算法交易的短期目标冲突。

## 第三部分：格雷厄姆理论与算法交易的结合

### 第4章：格雷厄姆指标的量化分析

#### 4.1 市盈率与市净率的量化分析

- **市盈率模型**：$$ P/E = \frac{Price}{Earnings} $$
  - 低市盈率可能意味着低估，但需考虑行业特性。
- **市净率模型**：$$ P/B = \frac{Price}{Book\ Value} $$
  - 低市净率通常意味着资产被低估，尤其在金融和制造业。

#### 4.2 股息率与股息支付率的量化分析

- **股息率模型**：$$ Dividend\ Yield = \frac{Dividend}{Price} $$
  - 高股息率可能表示收益稳定，但需警惕高股息率可能隐藏财务困境。
- **股息支付率模型**：$$ Dividend\ Payout\ Ratio = \frac{Dividend}{Earnings} $$
  - 高股息支付率可能意味着公司愿意将利润分配给股东。

#### 4.3 格雷厄姆多因模型

- **多因素模型**：结合市盈率、市净率、股息率等多个指标，构建综合评分模型。
- **权重分配**：根据市场环境和公司特性，动态调整各指标的权重。

import numpy as np

# 数据获取
data = pd.read_csv('stock_data.csv')

# 格雷厄姆筛选条件
def graham_screen(data):
    # 计算市盈率
    pe = data['Close'] / data['Earnings']
    # 计算市净率
    pb = data['Close'] / data['Book Value']
    # 筛选条件：市盈率 < 15，市净率 < 2，股息率 > 3%
    screening = (pe < 15) & (pb < 2) & (data['Dividend Yield'] > 0.03)

# 应用筛选
