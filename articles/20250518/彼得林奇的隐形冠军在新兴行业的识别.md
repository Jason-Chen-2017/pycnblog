### 3.4 代码实现
```python
def identify_invisible_champion(company_data):
    # 公司数据处理
    scores = []
    for company in company_data:
        market_share = company['market_share']
        innovation = company['innovation']
        financial_health = company['financial_health']
        score = (market_share + innovation + financial_health) / 3
        scores.append(score)
    return scores
```
