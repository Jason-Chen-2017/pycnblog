# 第一部分: 约翰·邓普顿投资理念与危机投资概述

## 第1章: 约翰·邓普顿的生平与投资哲学

### 1.1 约翰·邓普顿的生平简介

#### 1.1.1 约翰·邓普顿的早年经历
约翰·邓普顿（John Templeton）于1912年出生于加拿大，早年在英国接受教育，后移居美国。他在1930年代开始投资生涯，初期专注于股票市场，并在1939年建立了自己的投资公司。

#### 1.1.2 约翰·邓普顿的投资生涯
邓普顿以其独特的投资策略闻名，尤其是在市场危机时期。他主张寻找被市场低估的股票，并在市场恐慌时进行投资。他的投资风格以价值投资为核心，注重安全边际和长期回报。

#### 1.1.3 约翰·邓普顿的声誉与成就
邓普顿被认为是20世纪最伟大的投资者之一，他的投资理念影响了后来的许多投资者。他的成功案例包括在1930年代大萧条时期的投资，以及在1970年代石油危机期间的投资。

### 1.2 约翰·邓普顿的投资哲学

#### 1.2.1 价值投资的核心理念
邓普顿的价值投资理念强调购买被市场低估的股票，并在市场恐慌时进行逆向投资。他认为，市场的波动性为投资者提供了廉价买入的机会。

#### 1.2.2 约翰·邓普顿的投资策略
邓普顿的投资策略包括：
1. 寻找具有强大基本面但被市场低估的公司。
2. 在市场恐慌时进行投资，利用市场的非理性定价。
3. 分散投资，降低风险。

#### 1.2.3 约翰·邓普顿的成功案例
邓普顿在1930年代大萧条时期投资于被低估的股票，获得了高额回报。他还成功地在1970年代石油危机期间投资于能源公司，进一步巩固了他的声誉。

## 第2章: 危机投资的背景与定义

### 2.1 危机投资的定义与特征

#### 2.1.1 危机的定义
危机是指市场或经济中的重大负面事件，如经济衰退、市场崩盘或行业危机。这些事件通常导致市场的剧烈波动和资产价格的大幅下跌。

#### 2.1.2 危机投资的特点
危机投资的特点包括：
1. 市场恐慌导致资产价格低估。
2. 投资者情绪低落，市场流动性下降。
3. 危机中的投资机会通常具有高风险和高回报。

#### 2.1.3 危机投资的类型
危机投资可以分为以下几种类型：
- 市场危机投资：如经济衰退或市场崩盘。
- 行业危机投资：如能源危机或科技泡沫破裂。
- 地缘政治危机投资：如战争或政治动荡。

### 2.2 危机投资的机会与风险

#### 2.2.1 危机投资的机会
- 低估的资产价格为投资者提供了廉价买入的机会。
- 市场恐慌导致的投资机会可以带来高回报。

#### 2.2.2 危机投资的风险
- 市场波动性高，投资风险大。
- 危机中的投资机会可能具有高度不确定性。
- 投资者可能因市场恐慌而做出错误决策。

#### 2.2.3 危机投资的边界与外延
危机投资的边界包括市场波动、投资者情绪和市场流动性。其外延包括不同类型的投资机会，如股票、债券和房地产。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 从数据库获取股票数据

# 计算市盈率和市净率

df['市净率'] = df['股价'] / df['每股净资产']

# 找出市盈率和市净率低于行业平均值的股票
mean_pe = df['市盈率'].mean()
mean_pb = df['市净率'].mean()

undervalued_stocks = df[(df['市盈率'] < mean_pe) & (df['市净率'] < mean_pb)]

# 输出投资建议
print("以下股票被低估：")
print(undervalued_stocks['股票名称'])
```
