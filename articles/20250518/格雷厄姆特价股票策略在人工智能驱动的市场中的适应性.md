# 第1章: 格雷厄姆价值投资策略概述

## 1.1 价值投资的核心理念

价值投资是一种以基本面分析为基础的投资策略，其核心理念是寻找市场低估的股票进行长期投资。格雷厄姆在《 Intelligent Investor》中提出的核心思想是：市场先生是错误的，市场波动为理性投资者提供了套利机会。

- 格雷厄姆的安全边际概念：买入价格低于内在价值的股票，确保投资的安全性。
- 价值投资的核心指标：市盈率（P/E）、市净率（P/B）、股息率等。

## 1.2 人工智能驱动市场的现状

- 数据驱动投资的兴起：大数据分析、机器学习算法在金融市场的广泛应用。
- 人工智能在金融领域的应用：算法交易、风险管理、预测分析等。

## 1.3 格雷厄姆策略在现代市场中的挑战

- 市场波动性增加：高频交易和算法交易改变了市场的传统运作方式。
- 数据量的爆炸性增长：传统基本面分析难以应对海量数据。

# 第4章: 项目实战

## 4.1 项目背景与目标

- 项目目标：构建一个基于AI的价值投资策略选股系统。
- 数据来源：股票历史数据、财务报表、新闻情绪。

## 4.2 系统设计与实现

- 数据采集：使用Yahoo Finance API获取数据。
- 数据预处理：清洗、特征工程。
- 模型训练：使用随机森林算法进行分类。
- 模型评估：准确率、召回率、F1分数。

## 4.3 代码实现

```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 数据加载
data = pd.read_csv('stock_data.csv')

# 特征选择
features = ['PE', 'PB', 'dividend_yield']
target = 'undervalued'

# 模型训练
model = RandomForestClassifier()
model.fit(data[features], data[target])

# 模型预测
predictions = model.predict(data[features])

# 模型评估
print(f'Accuracy: {accuracy_score(data[target], predictions)}')
```
