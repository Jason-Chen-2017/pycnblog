# 第1章: 格雷厄姆特价股票理论概述

## 1.1 格雷厄姆特价股票理论的核心概念
### 1.1.1 价值投资的基本原理
- **内在价值**：股票的真正价值是其未来现金流的现值，与市场波动无关。
- **安全边际**：买入价格低于内在价值，以降低风险。

### 1.1.2 格雷厄姆投资策略的关键要素
- **低市盈率**：市盈率低于市场平均水平，确保合理估值。
- **高股息率**：稳定的股息收入，增强投资回报。

### 1.1.3 特价股票的定义与特征
- **特价股票**：价格远低于内在价值的股票。
- **特征**：低估值、高分红、稳定增长。

## 1.2 数字社会与影响力投资的背景
### 1.2.1 数字社会的特征与发展趋势
- **数字化转型**：企业和社会活动的数字化，提升效率和透明度。
- **技术驱动**：大数据、人工智能等技术推动社会进步。

### 1.2.2 影响力投资的定义与目标
- **影响力投资**：投资于解决社会和环境问题的企业，同时追求财务回报。
- **目标**：实现可持续发展，创造社会价值。

### 1.2.3 数字技术对影响力投资的推动作用
- **数据驱动**：利用大数据分析企业影响力，提高评估准确性。
- **智能工具**：人工智能优化投资决策，提升效率。

## 1.3 格雷厄姆理论与影响力投资的结合
### 1.3.1 价值投资与社会影响力的内在联系
- **内在价值**：企业不仅创造经济价值，还解决社会问题。
- **影响力评估**：将社会影响力纳入企业价值评估体系。

### 1.3.2 数字化工具在影响力评估中的应用

- **智能评估**：使用人工智能优化影响力评估模型。

### 1.3.3 格雷厄姆理论在现代投资中的新角色
- **传统价值投资**：提供基础理论。
- **现代应用**：结合影响力投资，拓展应用场景。

```python

# 预测结果
predicted_E = model.predict(scaled_data)
```

### 5.2.3 模型评估

mse = mean_squared_error(data['E'], predicted_E)
