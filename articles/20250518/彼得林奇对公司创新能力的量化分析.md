### 3.1 层次分析法（AHP）的应用

#### 3.1.1 AHP的基本原理
- 将复杂问题分解为层次结构，通过比较判断矩阵计算权重。

#### 3.1.2 指标权重计算公式
$$ w_i = \frac{\sum_{j} a_{ij}}{\sum_{j} a_{ij}} $$

#### 3.1.3 代码实现
```python
import numpy as np

def calculate_weights(matrix):
    # 计算判断矩阵的特征向量
    eigvals, eigvecs = np.linalg.eig(matrix)
    # 计算特征向量的归一化权重
    weights = eigvecs[:, np.argmax(eigvals)] / np.sum(eigvecs[:, np.argmax(eigvals)])
    return weights
```
