## 第4章：决策一致性评估算法

### 4.1 算法原理
#### 4.1.1 算法概述
使用层次分析法（AHP）评估决策一致性。

#### 4.1.2 算法的数学模型
层次分析法通过构建判断矩阵，计算权重和一致性指数。

#### 4.1.3 算法的实现步骤
1. 构建判断矩阵。
2. 计算权重向量。
3. 检查一致性。
4. 评估一致性指数。

### 4.2 算法流程图
```mermaid

    A[开始] --> B[构建判断矩阵]
    B --> C[计算权重向量]

    E --> F[结束]
```

### 4.3 算法的Python代码实现
```python
import numpy as np

def calculate_consistency(matrix):
    # 计算权重向量
    eigvals, eigvecs = np.linalg.eig(matrix)
    weight = eigvecs[:, 0].T
    # 计算一致性指数
    ci = (eigvals[0] - len(matrix)) / (len(matrix) * (len(matrix)-1))
    return ci

# 示例矩阵
matrix = np.array([[1, 2, 3],
                   [1/2, 1, 2],
                   [1/3, 1/2, 1]])

ci = calculate_consistency(matrix)
print(f"一致性指数: {ci}")
```

### 4.4 数学模型与公式
一致性指数计算公式：
$$ CI = \frac{\lambda_{max} - n}{n(n-1)} $$

其中，$ \lambda_{max} $是判断矩阵的最大特征值，$ n $是矩阵阶数。
