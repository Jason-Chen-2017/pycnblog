## 第1章 价值投资的核心概念与背景

### 1.1 价值投资的起源与发展

#### 1.1.1 价值投资的起源
价值投资起源于20世纪初，由本杰明·格雷厄姆和戴维·多德提出，强调以低于内在价值的价格购买优质股票，长期持有，等待市场回归理性。

#### 1.1.2 格雷厄姆的贡献与影响
格雷厄姆通过《证券分析》和《聪明的投资者》奠定了价值投资的基础，强调安全边际和长期投资。

#### 1.1.3 价值投资与其他投资理念的区别
不同于技术分析和趋势投资，价值投资侧重于基本面分析和长期持有。

---

### 1.2 价值投资的基本原理

#### 1.2.1 安全边际的概念与重要性
安全边际是股票价格与内在价值的差距，确保即使市场波动，投资者仍有获利空间。

#### 1.2.2 内在价值的定义与计算
内在价值是基于未来现金流的现值，通过DCF模型计算。

#### 1.2.3 市场先生与投资者心理
格雷厄姆将市场波动比作情绪化的市场先生，投资者应避免随市场波动做出决策。

### 2.1 核心概念原理

#### 2.1.1 安全边际的数学模型
安全边际 = 市场价格 × 安全边际比例

#### 2.1.2 内在价值的计算公式
$$\text{内在价值} = \frac{\text{年现金流}}{\text{折现率}}$$

#### 2.1.3 市场波动与投资者行为

## 第3章 价值投资的算法原理讲解

### 3.1 算法原理概述

#### 3.1.1 价值投资的量化分析方法
通过量化指标筛选低估股票，如低市盈率、低市净率等。

#### 3.1.2 现金流折现法的数学模型
$$\text{DCF} = \sum_{t=1}^{n} \frac{\text{CF}_t}{(1 + r)^t}$$

#### 3.1.3 投资组合优化的算法流程
1. 计算各股票的内在价值。
2. 确定各股票的安全边际。
3. 根据风险承受能力分配权重。

### 3.3 Python源代码实现

#### 3.3.1 现金流折现法的Python代码

```python
def calculate_dcf(cash_flows, discount_rate):
    dcf = sum(flow / (1 + discount_rate)**t for t, flow in enumerate(cash_flows))
    return dcf
```

#### 3.3.2 投资组合优化的Python代码

```python
def optimize_portfolio(stocks, weights):
    portfolio_value = sum(stocks[i] * weights[i] for i in range(len(stocks)))
    return portfolio_value
```
