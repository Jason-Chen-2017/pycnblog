### 第4章：智慧城市的评估模型

#### 4.1 现金流贴现模型（DCF）
用于评估智慧城市项目的未来现金流，计算其现值。

#### 4.2 算法流程图
```mermaid

    A[开始] --> B[评估现金流]

```

#### 4.3 Python代码实现
```python
def discounted_cash_flow(cash_flows, discount_rate):
    return sum(cf / (1 + discount_rate)**i for i, cf in enumerate(cash_flows))

# 示例
cash_flows = [100, 200, 300]
discount_rate = 0.1
print(discounted_cash_flow(cash_flows, discount_rate))
```

### 第5章：数学模型详细分析

#### 5.1 现金流贴现模型公式
$$DCF = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$
其中，CF_t是第t年的现金流，r是贴现率。

#### 5.2 内部收益率公式
$$IRR = r \text{ 使得 } \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} = 0$$
