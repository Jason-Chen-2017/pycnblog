## 第1章: 背景介绍

### 1.1 什么是管理层决策一致性
#### 1.1.1 决策一致性的定义
决策一致性是指在决策过程中，决策者在不同情境下对目标和行动的一致性程度。简单来说，就是决策者在面对类似问题时，是否会做出相似的决策。

#### 1.1.2 决策一致性的核心要素
- **决策主体**：决策者（个人或团队）。
- **决策目标**：决策的目标和期望的结果。
- **决策过程**：决策的制定、执行和反馈过程。
- **决策结果**：最终的决策输出。

#### 1.1.3 决策一致性的边界与外延
- **边界**：决策一致性不关注决策的正确性，只关注决策的连贯性和稳定性。
- **外延**：涉及个体决策和团队决策，适用于短期和长期决策。

### 1.2 彼得林奇与管理层决策一致性研究

彼得·林奇是全球著名投资专家，以其对管理层决策的深入研究闻名。他认为，管理层决策的一致性是评估公司长期表现的重要指标。

#### 1.2.2 彼得林奇对管理层决策一致性的研究方法

- 决策一致性可能会影响决策效率，因为一致的决策可能需要更多的时间和资源。

## 第5章: 管理层决策一致性评估的数学模型

### 5.1 基础模型
#### 5.1.1 决策一致性指数
$$ C = \frac{\sum_{i=1}^{n} |d_i - \overline{d}|}{n \times \text{max}(d_i - \overline{d})} $$
其中，$C$ 是一致性指数，$d_i$ 是各个决策的值，$\overline{d}$ 是平均值。

#### 5.1.2 决策一致性指数的计算步骤
1. 计算每个决策的值 $d_i$。
2. 计算所有决策的平均值 $\overline{d}$。
3. 计算每个决策与平均值的绝对差值。
4. 计算所有差值的总和。
5. 计算最大差值。
6. 计算一致性指数 $C$。

### 5.2 加权模型
#### 5.2.1 基于决策重要性的加权
$$ W = \sum_{j=1}^{m} w_j \times C_j $$
其中，$W$ 是加权一致性指数，$w_j$ 是决策 $j$ 的权重，$C_j$ 是决策 $j$ 的一致性指数。

def calculate_consistency_index(decisions):
    n = len(decisions)
    if n == 0:
        return 0
    average = sum(decisions) / n
    total_diff = sum(abs(d - average) for d in decisions)
    max_diff = max(abs(d - average) for d in decisions)
    return total_diff / (n * max_diff)

# 示例数据
decisions = [5, 6, 7, 4, 5]
index = calculate_consistency_index(decisions)
