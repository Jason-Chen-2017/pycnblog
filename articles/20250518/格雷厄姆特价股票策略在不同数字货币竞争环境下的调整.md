# 第3章 数字货币市场的技术分析与量化策略

## 3.1 技术分析在数字货币交易中的应用

### 3.1.1 移动平均线（MA）的使用
- 短期MA（如5日、10日）用于判断短期趋势。
- 长期MA（如50日、200日）用于判断长期趋势。
- 通过MA交叉寻找买卖信号。

### 3.1.2 相对强弱指数（RSI）的解读
- RSI指标用于判断超买超卖状态。
- 当RSI低于30时，可能为买入信号；当RSI高于70时，可能为卖出信号。

### 3.1.3 布林带（Bollinger Bands）的应用
- Bollinger Bands用于判断价格波动性。
- 当价格接近布林带上轨时，可能为卖出信号；当价格接近布林带下轨时，可能为买入信号。

## 3.2 量化交易策略的构建

### 3.2.1 数据收集与清洗
- 使用API获取历史价格和交易量数据。
- 清洗数据，处理缺失值和异常值。

### 3.2.2 特征提取与选择
- 提取技术指标（如RSI、MACD）和市场情绪指标（如社交媒体 sentiment）。
- 使用主成分分析（PCA）降维，减少特征数量。

### 3.2.3 策略回测与优化
- 使用回测平台（如Backtrader）进行策略测试。
- 调整参数，优化策略表现。

## 3.3 格雷厄姆策略与技术分析的结合

### 3.3.1 结合基本面和技术分析筛选投资标的
- 首先通过基本面分析筛选出有潜力的项目。
- 结合技术分析确认入场点和离场点。

### 3.3.2 动态调整投资组合
- 根据技术分析信号，动态调整持仓比例。
- 结合市场情绪变化，优化投资组合。

```python
from backtrader import Strategy

class RsiStrategy(Strategy):
    def __init__(self):
        self.rsi = self.I(rsi, self.data.close, period=14)
        self.buy_threshold = 30
        self.sell_threshold = 70

    def next(self):
        if self.rsi < self.buy_threshold:
            self.buy()
        elif self.rsi > self.sell_threshold:
            self.sell()
```
