### 5.2 核心代码实现
```python
def calculate_rsi(data, n=14):
    # 计算相对强度指数(RSI)
    close = data['Close']
    delta = close.diff()
    up = delta.where(delta > 0, 0)
    down = delta.where(delta < 0, 0)
    avg_up = up.rolling(n).mean()
    avg_down = down.rolling(n).mean()
    rsi = 100 - (100 - (avg_up / avg_down))
    return rsi
```
