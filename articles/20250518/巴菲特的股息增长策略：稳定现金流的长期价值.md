##### 4.3 股息增长模型的数学公式

- 股息增长率的计算：
  $$ g = (D_{t+1} / D_t) - 1 $$
- 内在价值的计算：
  $$ V = \frac{D_1}{k - g} $$
  其中，\( D_1 \) 是下一期的股息，\( k \) 是折现率，\( g \) 是股息增长率。

##### 6.2 核心代码实现

- 数据收集与处理：
  ```python
  import pandas as pd
  import numpy as np

  # 假设我们有一个包含历史股息数据的DataFrame df
  df = pd.DataFrame({
      'Year': [2017, 2018, 2019, 2020, 2021],
      'Dividends': [1.0, 1.04, 1.08, 1.12, 1.16]
  })

  # 计算股息增长率
  df['Dividend Growth'] = df['Dividends'].pct_change()
  ```

- 模型训练：
  ```python
  from sklearn.linear_model import LinearRegression

  # 假设我们有一个特征矩阵X和目标向量y
  X = df[['Year']]
  y = df['Dividend Growth']

  model = LinearRegression()
  model.fit(X, y)
  ```

- 预测与评估：
  ```python
  # 预测未来一年的股息增长率
  future_year = 2022
  future_X = pd.DataFrame({'Year': [future_year]})
  predicted_growth = model.predict(future_X)
  ```
