## 第3章: 街头智慧的数学模型与算法原理

### 3.1 市场情绪指数模型

市场情绪指数（Market Sentiment Index, MSI）用于衡量市场的乐观或悲观程度，公式如下：

$$ MSI = \frac{\text{上涨股票数量} - \text{下跌股票数量}}{\text{总股票数量}} $$

当MSI > 0时，市场情绪乐观；当MSI < 0时，市场情绪悲观。

### 3.2 公司基本面评估模型

彼得林奇强调对公司基本面的深入分析，常用以下指标：

1. **市盈率（P/E）**：用于评估股票的相对价值。
2. **ROE（净资产收益率）**：衡量公司的盈利能力。
3. **债务与 equity ratio**：评估公司的财务杠杆风险。

### 5.3 Python代码实现

```python
import pandas as pd

def calculate_msi(data):
    up = data['收盘价'] > data['开盘价']
    down = data['收盘价'] < data['开盘价']
    return (up.sum() - down.sum()) / len(data)

# 示例数据
data = pd.DataFrame({
    '开盘价': [100, 98, 102, 95],
    '收盘价': [110, 90, 105, 98]
})

msi = calculate_msi(data)
print(f"Market Sentiment Index: {msi}")
```
