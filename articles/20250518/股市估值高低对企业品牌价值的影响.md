  多元线性回归模型通过建立自变量（如品牌价值、市场环境）与因变量（股市估值）之间的线性关系，分析各因素的影响力。

```python
  import pandas as pd
```

  ```python
  df = pd.read_csv('stock_data.csv')

  # 数据清洗
  df.dropna(inplace=True)
  df['brand_value'] = df['brand_value'].apply(lambda x: np.log(x) if x > 0 else 0)
  ```

- **5.2.2 模型训练代码**  
  ```python
  from sklearn.model_selection import train_test_split
  from sklearn.linear_model import LinearRegression

  # 划分训练集与测试集
  X_train, X_test, y_train, y_test = train_test_split(df[['brand_value']], df['stock_valuation'], test_size=0.2)

  # 模型训练
  model = LinearRegression()
  model.fit(X_train, y_train)

  # 模型预测
  y_pred = model.predict(X_test)
  ```

- **5.2.3 结果展示代码**

  ```python
  plt.show()
  ```
