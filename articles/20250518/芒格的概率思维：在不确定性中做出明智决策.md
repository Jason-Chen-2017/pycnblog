# 第2章: 概率思维的核心概念与数学基础

## 2.1 概率的基本原理

### 2.1.1 概率空间的定义

概率空间由样本空间、事件和概率测度组成。样本空间是所有可能结果的集合，事件是样本空间的子集，概率测度将概率分配给每个事件。

### 2.1.2 独立事件与条件概率

独立事件是指一个事件的发生不影响另一个事件的概率。条件概率是指在给定某个事件发生的条件下，另一个事件发生的概率。

### 2.1.3 贝叶斯定理的数学公式

贝叶斯定理描述了在已知条件下，事件的后验概率如何计算。其公式为：

$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

其中，$P(A|B)$ 是在事件B发生的条件下，事件A发生的概率。

## 2.2 概率思维的核心要素

### 2.2.1 概率分布的类型

概率分布可以分为离散型和连续型。离散型分布如二项分布，连续型分布如正态分布。

### 2.2.2 随机变量与概率密度函数

随机变量是概率空间中的函数，概率密度函数描述了随机变量的概率分布。

### 2.2.3 芝诺悖论与概率的哲学思考

芝诺悖论通过无限分割的距离，提出了概率的哲学问题，即如何在无限可能性中做出决策。

# 第4章: 概率思维的算法实现与代码解析

## 4.1 蒙特卡洛模拟的实现

### 4.1.1 蒙特卡洛模拟的原理

蒙特卡洛模拟是一种通过随机采样来估计概率分布的方法，常用于复杂系统的建模。

### 4.1.2 蒙特卡洛模拟的Python代码实现

以下是一个简单的蒙特卡洛模拟代码示例：

```python
import random

def monte_carlo_simulation(n):
    heads = 0
    for _ in range(n):
        if random.random() < 0.5:
            heads += 1
    return heads / n

print(monte_carlo_simulation(1000))
```

### 4.1.3 蒙特卡洛模拟的应用案例

蒙特卡洛模拟广泛应用于金融、物理等领域，用于估计系统的概率分布和风险评估。

## 4.2 贝叶斯定理的代码实现

### 4.2.1 贝叶斯定理的数学推导

贝叶斯定理通过已知条件概率计算后验概率，公式为：

$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

### 4.2.2 贝叶斯定理的Python代码实现

以下是一个简单的贝叶斯定理实现示例：

```python
def bayes_theorem(P_A, P_B_given_A, P_B):
    return (P_B_given_A * P_A) / P_B

P_A = 0.3
P_B_given_A = 0.7
P_B = 0.5

print(bayes_theorem(P_A, P_B_given_A, P_B))
```

### 4.2.3 贝叶斯定理的实际应用

贝叶斯定理广泛应用于机器学习、数据分析等领域，用于分类和预测。
