##### 5.3 数学模型与公式
- 均值-方差优化公式：
  $$
  \text{minimize } \sigma^2 = x^T \Sigma x \text{ 在约束条件下 }
  $$
  其中：
  - $x$ 是投资组合权重向量
  - $\Sigma$ 是资产之间的协方差矩阵

##### 7.2 核心代码实现

```python
import numpy as np
import pandas as pd

# 示例数据
data = pd.DataFrame({'returns': [0.05, 0.03, -0.02, 0.01, 0.04]})

# 计算协方差矩阵
cov_matrix = data.cov()

# 均值-方差优化
def mean_variance_optimization(data):
    returns = data.returns
    n = len(returns)
    # 构建优化问题
    # 这里简化为最小方差问题，权重之和为1，无其他约束
    w = np.ones(n) / n
    variance = w.T.dot(cov_matrix).dot(w)
    return variance

# 计算并展示结果
opt_var = mean_variance_optimization(data)
print(f"优化后的方差为: {opt_var}")
```
