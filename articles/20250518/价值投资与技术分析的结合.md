## 第一部分：价值投资与技术分析的核心概念

### 第1章：价值投资的定义与背景

#### 1.1 价值投资的基本概念
- 价值投资是一种长期投资策略，强调购买被市场低估的资产，等待其价值回归。
- 核心在于分析公司的基本面，包括盈利能力、财务状况和行业地位。

#### 1.2 价值投资的起源与发展
- 起源于本杰明·格雷厄姆的“烟丝理论”，强调安全边际。
- 后由巴菲特发扬光大，成为价值投资的重要代表。

#### 1.3 价值投资的核心要素
| 要素 | 描述 |
|------|------|
| 内在价值 | 公司未来现金流的现值，计算公式：$$ V = \frac{CF}{r - g} $$
| 安全边际 | 投资价格低于内在价值的程度，确保投资的安全性。

### 第2章：技术分析的定义与背景

#### 2.1 技术分析的基本概念
- 技术分析通过分析价格和成交量来预测未来走势。
- 强调市场行为反映所有信息，价格走势具有可预测性。

#### 2.2 技术分析的起源与发展
- 起源于道琼斯工业指数，后发展出多种技术指标和图表形态。

#### 2.3 技术分析的核心要素
| 指标 | 描述 |
|------|------|
| 移动平均线（MA） | 平滑价格走势，识别趋势方向，计算公式：$$ MA_n = \frac{1}{n} \sum_{i=1}^{n} P_i $$
| 相对强度指数（RSI） | 衡量超买或超卖状态，计算公式：$$ RSI = \frac{100 - \frac{S}{K}}{1 + \frac{S}{K}} $$

### 第3章：价值投资与技术分析的联系与区别

#### 3.1 联系
- 价值投资提供长期投资目标，技术分析帮助捕捉最佳入场时机。
- 结合两者可以优化投资决策，减少单一方法的风险。

#### 3.2 区别
- 价值投资侧重基本面，技术分析侧重价格走势。
- 价值投资注重长期，技术分析注重短期。

#### 3.3 综合应用的可能性
- 通过筛选基本面优秀且技术形态良好的股票，结合两者的优点。

### 第4章：结合价值投资与技术分析的策略框架

#### 4.1 筛选价值投资标的
- 计算内在价值，筛选价格低于内在价值的公司。
- 通过财务指标（如ROE、负债率）评估公司基本面。

#### 4.2 技术分析信号确认
- 使用RSI、MA等指标确认买入信号。
- 分析K线图识别趋势和支撑阻力位。

#### 4.3 结合策略的具体步骤
1. 计算公司内在价值，确定潜在投资标的。
2. 分析技术指标，确认买入信号。
3. 结合两者，制定买卖决策。

### 第6章：项目实战与案例分析

#### 6.1 项目环境安装

#### 6.2 核心代码实现
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

def calculate_intrinsic_value(earnings, growth_rate, discount_rate):
    return earnings / (discount_rate - growth_rate)

def calculate_rsi(data, period=14):
    diff = data['close'].diff()
    up = diff.where(diff > 0, 0)
    down = abs(diff.where(diff < 0, 0))
    rs = up.rolling(period).mean() / down.rolling(period).mean()
    return 100 - (100 - rs.rolling(period).mean())

# 示例数据
data = pd.DataFrame({
    'close': [100, 105, 110, 108, 115]
})

# 计算内在价值
iv = calculate_intrinsic_value(10, 0.05, 0.1)
print(f"内 在 价 值: {iv}")

# 计算RSI
rsi = calculate_rsi(data)
print(f"RSI: {rsi.iloc[-1]}")
```
