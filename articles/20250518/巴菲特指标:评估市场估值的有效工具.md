- 4.2.2 指标计算模块
```python
def calculate_pe(ticker):
    data = yf.download(ticker, start='2020-01-01', end='2023-12-31')
    pe = data['Close'] / data['EPS']
    return pe.mean()

pe_aapl = calculate_pe('AAPL')
```
