## 第三部分：赢家的诅咒的算法原理

### 第3章：估值指标与算法

#### 3.1 估值指标的定义与计算
- 3.1.1 市盈率（P/E）的计算
  $$\text{P/E} = \frac{\text{股票价格}}{\text{每股收益}}$$
- 3.1.2 市净率（P/B）的计算
  $$\text{P/B} = \frac{\text{股票价格}}{\text{每股净资产}}$$
- 3.1.3 其他相关指标（如股息率）

#### 3.2 估值算法的实现
- 3.2.1 使用Python计算市盈率和市净率
  ```python
  import pandas as pd

  # 假设df是包含股票数据的DataFrame
  df['PE'] = df['Price'] / df['Earnings Per Share']
  df['PB'] = df['Price'] / df['Book Value Per Share']
  ```
