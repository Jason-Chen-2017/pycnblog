## 第三部分：芒格思维模型的算法原理

### 第3章：芒格思维模型的算法实现

#### 3.1 机会成本分析算法

机会成本是选择一种投资方案而放弃其他可能获得的收益。通过算法计算不同投资选择的机会成本，帮助投资者做出更明智的决策。

#### 3.2 机会成本的计算公式

$$\text{机会成本} = \sum_{i=1}^{n} w_i \times c_i$$

其中，\(w_i\) 是第i个投资的权重，\(c_i\) 是第i个投资的机会成本。

#### 3.3 机会成本分析的Python实现代码

```python
def calculate_opportunity_cost(investments):
    total = 0
    for investment in investments:
        total += investment['weight'] * investment['cost']
    return total

investments = [
    {'name': '股票', 'weight': 0.6, 'cost': 0.15},
    {'name': '债券', 'weight': 0.3, 'cost': 0.05},
    {'name': '房地产', 'weight': 0.1, 'cost': 0.20}
]

opportunity_cost = calculate_opportunity_cost(investments)
print(f"机会成本为: {opportunity_cost}")
```
