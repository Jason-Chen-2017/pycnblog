## 第三部分：社交媒体环境下的心理倾向分析

### 第3章：社交媒体对心理倾向的影响

#### 3.1 社交媒体的特性与心理倾向的关系
- 社交媒体的信息传播速度快，容易引发从众心理。
- 情感化的信息更容易引发投资者的心理偏差。

#### 3.2 社交媒体中的信息偏差与心理倾向
- 信息偏差是指社交媒体上的信息不完全或误导性，容易引发投资者的贪婪或恐惧。
- 本文通过实例分析，展示信息偏差如何影响投资决策。

#### 3.3 社交媒体中的从众心理与羊群效应
- 从众心理在社交媒体中表现得尤为明显，投资者容易跟随大众意见，忽视独立思考。
- 羊群效应会导致市场波动加剧，投资者需要警惕这种心理倾向。

from textblob import TextBlob

def analyze_sentiment(text):
    blob = TextBlob(text)
    return blob.sentiment.polarity

data = pd.DataFrame({'文本': ['Positive', 'Negative', 'Neutral']})
