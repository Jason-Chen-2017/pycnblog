## 第2章: 数学期望与量子金融模型的核心概念

### 2.1 数学期望的理论基础
数学期望的计算公式为：
$$ E[X] = \sum_{i=1}^{n} x_i P(x_i) $$
其中，$x_i$ 是随机变量的取值，$P(x_i)$ 是对应的概率。

### 2.2 量子概率的计算
量子概率基于量子态的内积，公式为：
$$ P(i) = |\langle i | \psi \rangle|^2 $$
其中，$| \psi \rangle$ 是量子态，$|i\rangle$ 是基态。

### 3.1 量子算法的基本原理
量子蒙特卡洛模拟的步骤包括初始化量子态、施加量子运算和测量结果。代码实现如下：

```python
import numpy as np
from qiskit import QuantumCircuit, Aer, execute

def quantum_monte_carlo(n):
    qc = QuantumCircuit(n)
    # 初始化量子态
    qc.h(range(n))
    # 施加测量操作
    qc.measure(range(n), range(n))
    # 模拟器执行
    backend = Aer.get_backend('qasm_simulator')
    job = execute(qc, backend, shots=1000)
    result = job.result()
    probabilities = result.get_counts().values()
    return probabilities
```
