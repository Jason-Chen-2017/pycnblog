## 第一部分：全球股市估值

### 第1章：全球股市估值的基本概念

#### 1.1 股市估值的定义与重要性
股市估值是指对上市公司股票价格的合理评估，以确定其内在价值。它不仅是投资者决策的核心依据，也是市场运行的重要机制。

- **定义**：股市估值是通过分析公司的财务数据、行业地位和市场环境，判断其股票价格是否被高估或低估。
- **重要性**：帮助投资者做出理性的投资决策，优化资源配置，促进市场的健康发展。

#### 1.2 股市估值的主要方法
以下是几种常用的股市估值方法：

1. **市盈率（PE）估值法**：
   - **公式**：PE = 股价 / 每股净利润
   - **用途**：衡量股票的相对价值，常用于判断股票是否被高估或低估。

2. **市净率（PB）估值法**：
   - **公式**：PB = 股价 / 每股净资产
   - **用途**：适用于资产密集型行业，如银行和制造业。

3. **现金流折现法（DCF）**：
   - **原理**：通过将未来现金流折现，计算其现值。
   - **公式**：DCF = Σ (CF_t / (1 + r)^t) + 终值

   ```python
   def calculate_dcf(cash_flows, discount_rate, terminal_value):
       dcf = 0
       for t, cf in enumerate(cash_flows):
           dcf += cf / (1 + discount_rate) ** t
       dcf += terminal_value / (1 + discount_rate) ** len(cash_flows)
       return dcf
   ```

### 第2章：全球股市估值的影响因素

#### 2.1 宏观经济因素
- **经济周期**：经济繁荣期通常伴随着股市的高估值。

#### 2.2 行业因素
- **行业生命周期**：朝阳行业通常具有较高的成长性溢价。
- **行业政策**：政府政策对行业估值有直接影响。

#### 2.3 公司基本面因素
- **盈利能力**：ROE（净资产收益率）是衡量公司盈利能力的重要指标。
- **债务水平**：高负债公司通常面临更高的财务风险。
