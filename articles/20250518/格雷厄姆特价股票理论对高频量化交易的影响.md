# 第2章 格雷厄姆特价股票理论的核心原理

## 2.1 格雷厄姆投资理论的数学模型

### 2.1.1 市盈率（P/E）计算
$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$

### 2.1.2 市净率（P/B）计算
$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

### 2.1.3 股息率计算
$$ \text{股息率} = \frac{\text{每股股息}}{\text{股价}} \times 100\% $$

---

## 2.2 格雷厄姆投资策略的优缺点

### 2.2.1 优点
- 风险较低，安全边际高。
- 适合长期投资。

### 2.2.2 缺点
- 短期可能跑输市场。
- 过滤掉部分高成长性股票。

## 6.2 核心代码实现

### 6.2.1 数据获取与筛选
```python
import pandas as pd
import yfinance as yf

# 获取数据
data = yf.download(tickers='AAPL', period='5d', interval='1h')

# 筛选指标
def grayham_screen(df):
    pe = df['Close'] / df[' earnings per share']
    pb = df['Close'] / df[' book value per share']
    return pe < 15 and pb < 1.5

selected = data[grayham_screen(data)]
```
