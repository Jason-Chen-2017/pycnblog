# 第一部分: 格雷厄姆净净股策略的背景与基础

## 第1章: 格雷厄姆的价值投资理念

### 1.1 格雷厄姆的生平与投资思想
#### 1.1.1 格雷厄姆的生平简介
本杰明·格雷厄姆（Benjamin Graham）是20世纪著名的投资学家，被誉为“价值投资之父”。他出生于1894年，早年通过投资股市积累了巨额财富，但后来在1929年股市崩盘中损失惨重。这次经历使他形成了独特的价值投资理念，强调安全边际和长期投资。

#### 1.1.2 格雷厄姆的价值投资理念
格雷厄姆提出的价值投资理念以“安全边际”为核心，强调以低于内在价值的价格买入优质股票。他认为市场先生（Mr. Market）的情绪波动为投资者提供了低价买入的机会。

#### 1.1.3 格雷厄姆投资理论的核心思想
格雷厄姆的核心思想包括：
1. **安全边际**：买入价格远低于内在价值的股票，以降低投资风险。
2. **内在价值**：股票的真实价值，与市场波动无关。
3. **长期投资**：避免短期市场波动，关注企业的长期价值。

### 1.2 净净股策略的定义与特点
#### 1.2.1 净净股的定义
净净股（Net-Net）是格雷厄姆提出的一种投资策略，指以低于企业净流动资产价值的价格买入股票。具体计算公式为：
$$ \text{净流动资产价值} = \text{流动资产} - \text{流动负债} $$

#### 1.2.2 净净股策略的核心特点
1. **低估值**：买入价格远低于企业净流动资产价值。
2. **高安全边际**：通过安全边际降低投资风险。
3. **逆向投资**：在市场恐慌时寻找低估机会。

#### 1.2.3 净净股与传统投资策略的区别
| 对比维度 | 净净股策略 | 传统市盈率策略 |
|----------|------------|----------------|
| 估值依据 | 净流动资产 | 市盈率或市净率 |
| 适用场景 | 低估值企业 | 高成长企业     |
| 风险偏好 | 低风险偏好 | 高风险偏好     |

### 1.3 净净股策略的核心概念
#### 1.3.1 安全边际
安全边际是格雷厄姆投资理念的核心，指买入价格与内在价值的差距。公式为：
$$ \text{安全边际} = \text{内在价值} - \text{买入价格} $$

#### 1.3.2 内在价值
内在价值是企业未来现金流的现值，计算公式为：
$$ \text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$
其中，\( CF_t \) 是第 \( t \) 年的现金流，\( r \) 是折现率。

#### 1.3.3 市场先生
市场先生是格雷厄姆用来形容市场波动的比喻，强调投资者应独立于市场情绪，专注于企业内在价值。

### 1.4 净净股策略的应用场景
#### 1.4.1 适用于哪些类型的企业
1. **低增长企业**：企业增长缓慢，但具有稳定的现金流。
2. **低估企业**：市场价远低于净流动资产价值。
3. **周期性企业**：在市场底部时买入，避免周期性波动。

#### 1.4.2 净净股策略的优缺点
| 优点 | 缺点 |
|------|------|
| 高安全边际 | 适合低成长企业 |
| 低估值策略 | 不适合高成长企业 |
| 风险低 | 市场波动可能影响短期收益 |

#### 1.4.3 净净股策略的适用市场环境
1. **市场恐慌**：市场恐慌时容易找到低估机会。
2. **经济衰退**：经济衰退时企业价值可能被低估。
3. **低利率环境**：低利率环境下企业估值可能上升。

### 1.5 本章小结
本章介绍了格雷厄姆的价值投资理念，重点讲解了净净股策略的定义、特点和核心概念，为后续分析奠定了基础。

## 第2章: 净净股策略的核心原理

### 2.1 净净股的计算方法
#### 2.1.1 净净股的定义公式
$$ \text{净流动资产价值} = \text{流动资产} - \text{流动负债} $$

#### 2.1.2 净净股的计算步骤
1. 收集目标企业的流动资产和流动负债数据。
2. 计算净流动资产价值。
3. 将净流动资产价值除以企业总股数，得到每股净流动资产价值。

#### 2.1.3 净净股的评估方法
1. 比较市场价与每股净流动资产价值。
2. 买入价格低于净流动资产价值的企业。

### 2.2 净净股策略的数学模型
#### 2.2.1 内在价值的计算公式
$$ \text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$

#### 2.2.2 净净股价值与市场价的比较
$$ \text{安全边际} = \text{内在价值} - \text{市场价} $$

#### 2.2.3 净净股策略的数学推导
假设某企业未来5年的现金流分别为100万、120万、140万、160万、180万，折现率为10%。计算内在价值：
$$ \text{内在价值} = \frac{100}{1.1} + \frac{120}{1.1^2} + \frac{140}{1.1^3} + \frac{160}{1.1^4} + \frac{180}{1.1^5} \approx 469.83 \text{万元} $$

### 2.3 净净股策略的算法实现
#### 2.3.1 净净股价值计算的Python代码实现
```python
def calculate_net_net_value(equity, liabilities):
    return equity - liabilities
```

#### 2.3.2 内在价值计算的Python代码实现
```python
def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(cash_flow / (1 + discount_rate) ** t for t, cash_flow in enumerate(cash_flows))
```
