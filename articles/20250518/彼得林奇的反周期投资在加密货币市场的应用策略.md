# 第1章：反周期投资的核心概念

## 1.1 什么是反周期投资

反周期投资是一种在市场周期性波动中，通过逆向思维寻找投资机会的策略。其核心在于在市场低谷时买入，在市场高点时卖出，从而在周期性波动中获得超额收益。

### 1.1.1 投资周期的基本定义

- **周期性波动**：市场会经历周期性的涨跌，包括牛市和熊市。
- **市场低谷**：市场处于最低点，投资者情绪低落，价格被低估。
- **市场高峰**：市场处于最高点，投资者情绪高涨，价格被高估。

### 1.1.2 反周期投资的定义与特征

- **定义**：反周期投资是在市场低谷时进行投资，而在市场高峰时退出。
- **特征**：逆向思维、长期视角、风险承受能力较高。

### 1.1.3 反周期投资的核心要素

- **市场周期识别**：准确识别市场周期是反周期投资的关键。
- **逆向思维**：在市场恐慌时寻找机会，避免随波逐流。
- **风险管理**：合理控制风险，避免在市场崩盘时承受过大损失。

## 1.2 彼得·林奇投资策略的背景

### 1.2.1 彼得·林奇的生平简介

彼得·林奇是美国著名投资经理人，以其在共同基金领域的卓越表现闻名。他管理的麦哲伦基金在任期内取得了年均29%的回报率。

### 1.2.2 林奇投资哲学的核心理念

- **价值投资**：寻找被市场低估的优质资产。
- **逆向思维**：在市场低谷时买入，在市场高点时卖出。
- **长期视角**：注重资产的长期价值，而非短期波动。

### 1.2.3 林奇反周期策略的形成背景

- **20世纪70年代的经济危机**：林奇在经济危机期间积累了丰富的反周期投资经验。
- **市场周期的波动性**：通过对市场周期的深入研究，林奇总结出了反周期投资的策略。

### 6.2.3 代码实现

```python
import pandas as pd
import numpy as np

# 加载数据
data = pd.read_csv('bitcoin_price.csv')

# 计算RSI
def calculate_rsi(data, period=14):
    delta = data['收盘价'] - data['收盘价'].shift(1)
    up = delta.where(delta > 0, 0)
    down = delta.where(delta < 0, 0)
    ma_up = up.rolling(period).mean()
    ma_down = down.rolling(period).mean()
    rsi = 100 - (ma_down / (ma_up + ma_down)) * 100
    return rsi

data['RSI'] = calculate_rsi(data)

# 判断买卖信号
data['信号'] = '持有'
data.loc[data['RSI'] > 70, '信号'] = '卖出'
data.loc[data['RSI'] < 30, '信号'] = '买入'
```
