## 第2章: 市场情绪指标的核心要素

### 2.1 市场情绪指标的核心属性

#### 2.1.1 情绪强度
情绪强度反映市场的热情程度，分为高、中、低。

#### 2.1.2 情绪方向
情绪方向表明市场是乐观还是悲观，分为正向、负向、中性。

#### 2.1.3 情绪周期
情绪周期展示情绪波动的时间规律，通常分为长期、中期、短期。

### 2.2 市场情绪指标的构成要素

#### 2.2.1 投资者情绪
投资者情绪是指标的基础，包括个体和整体情绪。

#### 2.2.2 市场波动性
市场波动性反映情绪的剧烈程度，波动越大，情绪越极端。

#### 2.2.3 市场参与度
市场参与度衡量投资者活跃程度，高参与度表明情绪高涨。

### 2.3 市场情绪指标的数学模型

#### 2.3.1 情绪指数的计算公式
$$ E = \frac{V}{A} $$
其中，E为情绪指数，V为成交量，A为平均价格。

#### 2.3.2 情绪周期的数学表达
$$ C = \frac{E}{T} $$
其中，C为情绪周期，E为情绪指数，T为时间窗口。

```python
def calculate_emotion_index(data):
    emotion_index = data['volume'] / data['price']
    return emotion_index.mean()

def calculate_emotion_cycle(emotion_index, window=30):
    return emotion_index.rolling(window).mean()
```
