## 第一部分：投资哲学的背景与基础

### 第1章：投资的基本原理

#### 1.1 投资的基本概念
- **投资的定义与分类**  
  投资是将资金投入到能够产生收益的资产中，常见的资产类别包括股票、债券、房地产等。股票代表企业所有权，债券是债权债务关系，房地产则是实物资产。  
  $$投资 = 资金 \times 资产类别$$  

- **资本市场的运作机制**  
  资本市场是连接资金供需双方的平台，通过价格机制（如供需关系）决定资产价格。股票价格反映市场的预期，债券价格受利率影响，房地产价格受供需和经济周期影响。  

- **简单明了投资哲学的逻辑基础**  
  彼得林奇认为，复杂的投资策略容易受到市场情绪的干扰，而简单的策略更易于理解和执行。简单明了的投资哲学强调回归基本面，专注于企业内在价值的分析，而不是市场的短期波动。

#### 2.2 彼得林奇与价值投资的结合

#### 2.3 简单明了投资哲学的核心理念

- **与复杂投资策略的对比**

- **管理团队的稳定性与能力**

- **代码示例：计算市盈率和市净率**

  ```python
  import pandas as pd

  # 示例数据：假设我们有一个股票的财务数据
  data = {
      '公司名称': ['公司A', '公司B'],
      '净利润': [100, 200],
      '股价': [50, 100]
  }
  df = pd.DataFrame(data)

  # 计算市盈率
  df['市盈率'] = df['股价'] / df['净利润']
  # 计算市净率
  df['市净率'] = df['股价'] / df['股价'].apply(lambda x: x/10)
  print(df)
  ```
