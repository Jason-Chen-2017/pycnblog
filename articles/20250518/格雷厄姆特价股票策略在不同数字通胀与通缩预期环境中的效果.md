## 第一部分：背景介绍

### 第1章：数字通胀与通缩的基本概念

#### 1.1 数字通胀的定义与特征
- 数字通胀是指由于技术进步和数字化转型导致货币供应增加，引发物价上涨的现象。
- 主要特征包括货币供应增长、技术驱动和全球化影响。

#### 1.2 通缩的定义与特征
- 通缩是物价持续下降的现象，通常由需求减少或生产过剩引起。
- 特征包括需求萎缩、货币紧缩和市场信心不足。

#### 1.3 格雷厄姆特价股票策略的基本原理
- 格雷厄姆强调以低于内在价值的价格购买股票，注重安全边际。
- 特价股票是指市场价格远低于内在价值的股票。

### 第2章：数字通胀与通缩对股票市场的影响机制

#### 2.1 数字通胀对股票市场的影响
- 数字通胀通过增加流动性推高股价。
- 技术进步提升企业价值，吸引更多投资。

#### 2.2 通缩对股票市场的影响
- 通缩导致企业利润下降，股价承压。
- 投资者信心下降，资金流向减少。

#### 2.3 数字通胀与通缩对股票市场的对比分析
- 通胀环境适合高增长股票，通缩环境适合防御性股票。

def calculate_intrinsic_value(stock_price, growth_rate, discount_rate):
    return stock_price * (1 + growth_rate) / (1 + discount_rate)

def graham_strategy(stock_data, economic_condition):
    inflation = economic_condition['inflation']
    discount = economic_condition['discount']
    intrinsic_values = []
    for stock in stock_data:
        iv = calculate_intrinsic_value(stock['price'], stock['growth'], discount)
        intrinsic_values.append(iv)
    return intrinsic_values
