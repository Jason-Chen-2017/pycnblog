# 第一部分: 格雷厄姆特价股票策略概述

## 第1章: 格雷厄姆投资策略的核心理念

### 1.1 投资的基本原理
- 投资定义与分类：资产配置、股票、债券等。
- 格雷厄姆的价值投资理念：买入低于内在价值的股票。
- 投资与投机的区分：基于基本面分析 vs. 市场情绪。

### 1.2 特价股票的定义与特征
- 特价股票定义：市场价格低于内在价值的股票。
- 特价股票特征：低市盈率、低市净率、高股息率等。
- 市场表现：长期收益稳定，短期波动较大。

## 第2章: 格雷厄姆特价股票策略的数学模型与估值方法

### 2.1 格雷厄姆投资模型的数学表达
- 格雷厄姆模型：股票价值 = 股东权益 + 债务 - 现金。
- 安全边际计算公式：内在价值 / 市场价格 > 20%。
- 模型假设：公司财务稳定，无重大变化。

### 2.2 市盈率与市净率的计算方法
- 市盈率（P/E）= 股价 / 每股收益。
- 市净率（P/B）= 股价 / 每股净资产。
- 估值指标对比：P/E适用于成长股，P/B适用于成熟股。

### 2.3 格雷厄姆安全边际的计算
- 安全边际定义：内在价值与市场价格的差异。
- 计算公式：安全边际率 = (内在价值 - 市场价格) / 市场价格。
- 实际应用：避免市场波动带来的损失。

## 第3章: 经济体制对股票市场的基本影响

### 3.1 不同经济体制的分类
- 计划经济：政府主导，市场机制受限。
- 市场经济：市场主导，政府调节。

### 3.2 不同经济体制下的市场表现
- 计划经济：股票市场波动小，但效率低。
- 市场经济：股票市场波动大，但效率高。

### 3.3 政府政策对股票市场的影响
- 财政政策：税收、补贴影响企业盈利。
- 货币政策：利率影响市场流动性。

## 第4章: 格雷厄姆策略在不同经济体制下的应用

### 4.1 计划经济体制下的策略应用
