## 第二部分: 成长股筛选的核心标准

### 第2章: 财务指标分析

#### 2.1 营收与利润增长
- 营收增长率计算公式：
  $$(\text{本年营收} - \text{上年营收}) / \text{上年营收} \times 100\%$$
- 净利润增长率：
  $$\text{净利润增长率} = (\text{本年净利润} - \text{上年净利润}) / \text{上年净利润} \times 100\%$$

#### 2.2 资产负债结构
- 资产负债率计算公式：
  $$\text{资产负债率} = \text{总负债} / \text{总资产} \times 100\%$$

#### 2.3 现金流状况
- 自由现金流计算公式：
  $$\text{自由现金流} = \text{净利润} + \text{折旧} + \text{摊销} - \text{资本支出}$$

#### 6.2 核心实现代码
```python
import pandas as pd

def calculate_growth_rate(data):
    return (data['current'] - data['previous']) / data['previous'] * 100

def is_profitable(data, threshold=10):
    return calculate_growth_rate(data) > threshold

def main():
    data = {'revenue': [100, 150, 200],
            'net_profit': [20, 30, 40]}
    df = pd.DataFrame(data)
    growth_rates = df.apply(calculate_growth_rate)
    profitable = is_profitable(growth_rates)
    print("Profitable:", profitable)

if __name__ == "__main__":
    main()
```
