## 第3章: 算法原理讲解

### 3.1 基于PageRank的影响力评估
#### 3.1.1 PageRank算法的原理
PageRank算法通过计算节点的pagerank值，评估节点的重要性。pagerank值越高，节点的影响力越大。

#### 3.1.2 PageRank的数学模型
$$
PR(i) = \frac{1 - d}{N} + d \sum_{j} \frac{PR(j)}{OutDegree(j)}
$$

其中，\( d \) 是阻尼因子，\( N \) 是节点总数，\( OutDegree(j) \) 是节点 \( j \) 的出度。

#### 3.1.3 PageRank的Python实现
```python
def compute_pagerank(matrix, d=0.8):
    N = len(matrix)
    pr = [1.0] * N
    for _ in range(100):
        new_pr = [0.0] * N
        for i in range(N):
            for j in range(N):
                if matrix[j][i] > 0:
                    new_pr[i] += pr[j] * matrix[j][i]
        new_pr = [(x * d) + (1 - d) for x in new_pr]
        pr = new_pr
    return pr
```
