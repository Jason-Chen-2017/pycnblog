## 第3章: 金融衍生品的基本原理

### 3.1 金融衍生品的定义与分类

#### 3.1.1 期权
期权是一种合约，赋予买方在特定时间内以特定价格买入或卖出标的资产的权利。看涨期权和看跌期权是两种主要类型。

#### 3.1.2 期货
期货是一种标准化合约，约定在未来特定时间以特定价格买入或卖出标的资产。期货通常用于对冲价格波动风险。

#### 3.1.3 资产互换
资产互换是一种协议，双方同意交换不同资产的现金流。这种工具常用于风险管理或信用风险转移。

### 3.2 金融衍生品的定价模型

#### 3.2.1 Black-Scholes模型
Black-Scholes模型是期权定价的核心模型，公式如下：

$$ C = S_0 \cdot N(d_1) - K \cdot e^{-rT} \cdot N(d_2) $$

其中：
- \( S_0 \) 是标的资产当前价格，
- \( K \) 是行权价，
- \( r \) 是无风险利率，
- \( T \) 是到期时间，
- \( N(d) \) 是标准正态分布的累积分布函数，
- \( d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma \sqrt{T}} \),
- \( d_2 = d_1 - \sigma \sqrt{T} \).

#### 3.2.2 风险中性定价
风险中性定价假设市场参与者对风险持中性态度。在这种假设下，衍生品的期望收益等于其未来现金流的现值。

### 7.2 核心代码实现

#### 7.2.1 期权定价模型
使用Black-Scholes公式计算期权价格。

```python
import numpy as np

def black_scholes(S, K, r, sigma, T):
    d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)
    N = lambda x: 0.5*(1 + np.erf(x/np.sqrt(2)))
    C = S*N(d1) - K*np.exp(-r*T)*N(d2)
    return C

# 示例：计算看涨期权价格
S = 100
K = 105
r = 0.05
sigma = 0.3
T = 1
price = black_scholes(S, K, r, sigma, T)
print(f"期权价格为：{price}")
```
