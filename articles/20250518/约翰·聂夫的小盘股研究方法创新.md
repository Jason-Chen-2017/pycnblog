### 第1章：小盘股投资的背景与意义

#### 1.1 小盘股投资的定义与特点

小盘股是指市值较小的公司股票，通常具有较高的增长潜力。小盘股投资的核心特点包括高波动性、高风险和高回报。与大盘股相比，小盘股的市场关注度较低，但潜在的收益空间更大。

#### 1.2 约翰·聂夫的投资理念

## 第三部分：数学模型与决策支持

### 第5章：小盘股估值的数学模型

#### 5.1 现金流折现模型（DCF）

DCF模型通过预测企业未来现金流，计算其现值，从而确定其内在价值。公式如下：

$$ \text{DCF} = \sum_{t=1}^{n} \frac{\text{CF}_t}{(1+r)^t} + \frac{TV}{(1+r)^n} $$

其中，CFt为第t年的现金流，r为折现率，TV为终值。

#### 7.2 估值模型的实现

使用Python代码实现DCF模型：

```python
def calculate_dcf(cash_flows, discount_rate, terminal_value):
    dcf = 0
    for t, cf in enumerate(cash_flows):
        dcf += cf / (1 + discount_rate) ** t
    dcf += terminal_value / (1 + discount_rate) ** len(cash_flows)
    return dcf

# 示例数据
cash_flows = [100, 150, 200]
discount_rate = 0.1
terminal_value = 500

print(calculate_dcf(cash_flows, discount_rate, terminal_value))
```
