##### 3.1 移动平均线（MA）算法
- 3.1.1 算法原理
```mermaid
graph TD
    A[数据输入] --> B[计算平均值]
    B --> C[生成MA曲线]
    C --> D[识别趋势]
```

- 3.1.2 数学公式
$$ MA_n = \frac{1}{n} \sum_{i=1}^{n} P_i $$
其中，\( P_i \) 表示第 \( i \) 天的价格。

##### 3.2 相对强弱指数（RSI）算法
- 3.2.1 算法原理
```mermaid
graph TD

```

- 3.2.2 数学公式
$$ RSI = \frac{100}{1 + \frac{A}{B}} $$
其中，\( A \) 是上涨幅度，\( B \) 是下跌幅度。

```python
def calculate_ma(data, window):

# 示例代码：计算相对强弱指数
def calculate_rsi(data, window):
    delta = data['Close'] - data['Close'].shift(1)
    up = delta.where(delta > 0, 0)
    down = delta.where(delta < 0, 0)
    rs = up.rolling(window).mean() / down.rolling(window).mean()
    rsi = 100 - (100 - (rs / (rs + 1)))
    return rsi
```
