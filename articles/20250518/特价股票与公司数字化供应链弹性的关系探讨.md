## 第1章: 特价股票与供应链弹性的背景介绍

### 1.1 特价股票的定义与特点
#### 1.1.1 特价股票的定义
特价股票指的是价格相对较低的股票，通常属于中小型企业或新兴行业，具有较高的增长潜力和波动性。

#### 1.1.2 特价股票的核心特点
| 特性 | 描述 |
|------|------|
| 价格低 | 相对于大盘股，价格较低，适合中小投资者 |
| 波动性高 | 价格波动较大，受市场情绪影响显著 |
| 成长性高 | 具备较高的增长潜力，长期收益可能较高 |

#### 1.1.3 特价股票与普通股票的区别
- **风险性**：特价股票风险较高，普通股票风险相对较低。
- **流动性**：特价股票流动性可能较差，普通股票流动性较好。
- **投资者门槛**：特价股票对投资者的门槛较低，普通股票则较高。

### 1.2 供应链弹性的定义与特点
#### 1.2.1 供应链弹性的定义
供应链弹性是指企业在面对外部环境变化时，能够灵活调整供应链策略，确保业务连续性的能力。

#### 1.2.2 供应链弹性的核心特点
| 特性 | 描述 |
|------|------|
| 反应速度 | 快速响应市场变化和供应链中断 |
| 多样性 | 通过多元化供应商和资源来源增强弹性 |
| 预测能力 | 准确预测供应链风险，提前制定应对策略 |

#### 1.2.3 供应链弹性与供应链韧性的区别
- **供应链弹性**：强调灵活性和快速调整能力。
- **供应链韧性**：强调在面对冲击时的恢复能力。

### 1.3 特价股票与供应链弹性之间的关系
#### 1.3.1 特价股票波动对供应链的影响
- 特价股票价格波动可能导致企业资金链紧张，影响供应链稳定性。
- 供应链弹性强的企业能够更好地应对股价波动带来的资金压力。

#### 1.3.2 供应链弹性对特价股票的影响
- 强大的供应链弹性可以降低企业运营风险，提升投资者信心，进而影响股价。
- 供应链弹性弱的企业可能因运营问题导致股价进一步下跌。

#### 1.3.3 两者关系的理论框架
- **模型构建**：通过构建回归模型，分析供应链弹性对企业股价的影响。
- **数学表达**：$$ E = \beta \cdot S + \epsilon $$，其中E为股价弹性，S为供应链弹性指数。

### 1.4 本章小结
本章介绍了特价股票和供应链弹性的基本概念，分析了两者之间的相互影响，并提出了初步的理论框架。
