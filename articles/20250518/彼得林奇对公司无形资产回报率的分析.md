## 第二部分：无形资产的基本概念

### 第2章：无形资产的定义与类型

#### 2.1 无形资产的定义
无形资产是企业拥有的非实物资产，具有长期性和战略性的特点，能够为企业创造持续价值。

#### 2.2 无形资产的类型
- **品牌价值**：品牌知名度和美誉度直接影响市场占有率和定价能力。
- **专利与技术**：技术专利保护企业的创新成果，防止竞争。
- **客户关系**：稳定的客户基础为企业带来持续收入。

#### 2.3 无形资产的评估方法
| 类别        | 方法         | 优点                     |
|-------------|--------------|--------------------------|
| 市场法       | 可比公司法     | 数据来源广泛，易于操作   |
| 收益法       | 贴现现金流法   | 考虑未来收益，结果更准确   |
| 成本法       | 历史成本法     | 计算简单，但可能低估价值 |

## 第五部分：项目实战

### 第6章：项目实战

#### 6.1 环境配置
安装Python和相关库，如Pandas和Matplotlib。

#### 6.2 核心代码实现
```python
import pandas as pd
import matplotlib.pyplot as plt

# 数据收集
data = pd.DataFrame({
    'Year': [2018, 2019, 2020],
    'Net Profit': [1000000, 1200000, 1500000],
    'Total Assets': [5000000, 6000000, 7000000]
})

# 计算平均资产
data['Average Assets'] = (data['Total Assets'] + data.shift(1)['Total Assets']) / 2

# 计算ROA
data['ROA'] = data['Net Profit'] / data['Average Assets']

# 绘制图表
plt.figure(figsize=(10,6))
plt.plot(data['Year'], data['ROA'], 'b-', marker='o')
plt.title('无形资产回报率分析')
plt.xlabel('年份')
plt.ylabel('ROA')
plt.show()
```
