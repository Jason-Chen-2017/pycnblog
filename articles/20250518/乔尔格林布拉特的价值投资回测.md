#### 1.1 价值投资的定义与核心理念

- **价值投资的定义**：价值投资是一种长期投资策略，强调以低于内在价值的价格购买优质资产。其核心在于寻找市场低估的股票，通过长期持有实现收益。

- **格林布拉特的价值投资策略**：乔尔·格林布拉特在《股市漫步》中提出“格雷厄姆-多德数学”，即通过计算“内在价值”来选择被低估的股票。其策略包括关注低市盈率、低市净率和高股息率的股票。

- **价值投资的核心理念与哲学**：价值投资强调安全边际、长期视角和逆人性操作。投资者需要在市场恐慌时买入，在市场狂热时卖出，避免情绪化决策。

- **价值投资回测的目的与目标**：通过回测验证格林布拉特策略的有效性，评估其在不同市场周期下的收益与风险。

```python
def screen_stocks(df, threshold_pe=15, threshold_pb=2):
    # 计算市盈率和市净率
    df['PE'] = df['Price'] / df['Earnings Per Share']
    df['PB'] = df['Price'] / df['Book Value Per Share']
    
    # 筛选满足条件的股票
    selected = df[(df['PE'] < threshold_pe) & (df['PB'] < threshold_pb)]
    return selected
```

```python
import numpy as np

def sharpe_ratio(returns, risk_free_rate=0.02):
    # 计算收益与风险
    excess_returns = returns - risk_free_rate
    std = np.std(excess_returns, ddof=1)
    if std == 0:
        return 0
    return np.mean(excess_returns) / std

def max_drawdown(returns):
    # 计算最大回撤
    max_drawdown = 0
    current_max = 0
    for r in returns:
        current_max = max(current_max, r)
        drawdown = (r - current_max) / current_max
        if drawdown < max_drawdown:
            max_drawdown = drawdown
    return max_drawdown
```
