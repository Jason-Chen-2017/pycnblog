## 第二部分：核心概念与联系

### 第2章：股市估值的基本概念

#### 2.1 股市估值的核心指标

股市估值主要通过市盈率（P/E）、市净率（P/B）和股息率（Dividend Yield）等指标进行。这些指标帮助投资者评估股票的内在价值。

- **市盈率（P/E）**：衡量股价相对于每股收益的高低，计算公式为：P/E = 股价 / 每股收益。低P/E可能意味着低估，而高P/E可能表明高估或高成长潜力。
  
- **市净率（P/B）**：股价与每股净资产的比率，公式：P/B = 股价 / 每股净资产。适用于评估银行、制造业等重资产行业。

- **股息率（Dividend Yield）**：股息与股价的比率，公式：股息率 = 每股股息 / 股价。高股息率可能意味着收益稳定，但过高的股息可能不可持续。

#### 2.2 核心概念对比表格

| 指标    | 公式                          | 主要适用行业       | 优点                     | 缺点                     |
|---------|-------------------------------|-------------------|--------------------------|--------------------------|
| P/E     | 股价 / 每股收益              | 高增长企业         | 反映盈利能力               | 高P/E可能过高估值         |
| P/B     | 股价 / 每股净资产            | 银行、制造业       | 适用于评估重资产公司       | 不反映收益能力             |
| 股息率   | 每股股息 / 股价              | 稳定收益企业       | 收益稳定                   | 高股息可能不可持续         |

## 第三部分：算法原理讲解

### 第3章：股票估值的算法原理

#### 3.1 基于历史数据的估值方法

##### 3.1.1 数据收集与处理

使用印尼股市的历史数据，包括股价、收益和净资产等。数据清洗包括处理缺失值和异常值。

##### 3.1.2 市盈率计算

根据公式，计算每只股票的P/E比，与行业平均水平对比，判断估值高低。

##### 3.1.3 市净率计算

同样使用P/B公式，适用于重资产行业。

#### 3.2 用Python计算股票估值

##### 3.2.1 数据获取与清洗

```python
import pandas as pd
import numpy as np

# 数据获取
data = pd.read_csv('indonesia_stocks.csv')

# 数据清洗
data.dropna(inplace=True)
data = data[~data['price'].isin([np.nan])]
```

##### 3.2.2 估值指标计算

```python
data['PE'] = data['price'] / data['eps']
data['PB'] = data['price'] / data['book_value']
data['DIV_YIELD'] = data['dividend'] / data['price']
```

##### 3.2.3 代码实现与解释

通过上述代码，我们可以计算每只股票的PE、PB和DIV_YIELD，从而进行估值分类。例如，若PE低于行业平均，则可能低估。
