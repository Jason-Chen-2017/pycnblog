## 第一部分: 逆向投资的背景与核心概念

### 第1章: 逆向投资的定义与背景

#### 1.1 逆向投资的定义
##### 1.1.1 逆向投资的基本概念
逆向投资是一种在市场低迷时买入，市场高涨时卖出的投资策略，强调避开 crowd 的投资行为。

##### 1.1.2 逆向投资的特点
- 逆周期性：在市场低谷时买入，高点时卖出。
- 价值导向：寻找被市场低估的资产。
- 长期视角：注重资产的长期价值而非短期波动。

##### 1.1.3 逆向投资与传统投资的区别
| 投资策略 | 逆向投资 | 传统投资 |
|----------|----------|----------|
| 时间选择 | 市场低谷 | 市场高点 |
| 价格关注 | 低价位   | 高价位   |
| 风险态度 | 追求风险 | 风险厌恶 |

#### 1.2 彼得·林奇的逆向投资思想
##### 1.2.1 彼得·林奇的选股标准
- 高质量公司：具备持续盈利能力。
- 合理估值：市盈率低于行业平均水平。
- 长期潜力：公司具有竞争优势。

##### 1.2.2 逆向投资的哲学基础
- 市场情绪与理性分析的对立统一。
- 投资者心理：贪婪与恐惧的交替驱动市场波动。

### 第2章: 逆向投资的核心概念与联系

#### 2.1 核心概念原理
##### 2.1.1 市场情绪与投资决策的关系
市场情绪（贪婪与恐惧）直接影响投资者的决策，逆向投资强调在市场情绪低落时介入。

##### 2.1.2 逆向投资的逻辑框架
- 识别市场周期：从低谷到高点再到低谷。
- 判断市场情绪：通过市场指标和公司估值。
- 执行投资策略：买入低估资产，卖出高估资产。

##### 2.1.3 投资者心理与逆向投资策略
- 避免从众心理：不跟随市场潮流。
- 独立思考：基于基本面分析做出决策。

```python
import pandas as pd
import requests

def get_market_data(ticker):
    # 获取股票数据
    url = f'https://query1.finance.yahoo.com/...{ticker}'
    response = requests.get(url)
    data = response.json()
    return pd.DataFrame(data['chart'])

def calculate_market_sentiment(stocks):
    up = sum(1 for stock in stocks if stock['price_change'] > 0)
    down = len(stocks) - up
    return (up - down) / len(stocks)

def inverse_investment_strategy(stocks):
    sentiment = calculate_market_sentiment(stocks)
    if sentiment < -0.5:
        return '买入'
    elif sentiment > 0.5:
        return '卖出'
    else:
        return '观望'

# 示例使用
stocks = get_market_data('AAPL')
signal = inverse_investment_strategy(stocks)
print(f'投资信号：{signal}')
```
