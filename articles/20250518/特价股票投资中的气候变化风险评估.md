## 第1章: 气候变化对金融市场的潜在影响

### 1.1 气候变化与金融市场的关联性

#### 1.1.1 气候变化的定义与特征
- 气候变化是指长期的天气模式发生显著变化，包括温度上升、极端天气事件增多等。
- 气候变化具有长期性、全球性和不可逆性特征。

#### 1.1.2 金融市场中的气候变化风险
- 气候变化可能导致企业运营成本上升、利润下降，进而影响股价。
- 气候政策变化也可能对相关行业产生重大影响。

### 1.2 特价股票投资的基本概念

#### 1.2.1 特价股票的定义与特点
- 特价股票是指市盈率、市净率等估值指标低于行业平均水平的股票。
- 这类股票通常被认为具有较高的投资价值，但可能面临较高的风险。

#### 1.2.2 特价股票与气候变化风险的关联
- 气候变化可能影响企业的运营环境，进而影响股价。
- 特价股票由于估值较低，可能对气候变化的敏感性较高。

### 5.2 核心代码实现

#### 5.2.1 回归模型实现
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 假设我们有气候变化指标和股价数据
climate_data = pd.DataFrame({'temp_change': [1.2, 1.5, 1.3, 1.4], 'stock_price': [50, 55, 52, 53]})
model = LinearRegression()
model.fit(climate_data[['temp_change']], climate_data['stock_price'])
print(model.coef_)
```

#### 5.2.2 贝叶斯网络实现

from pgmpy.models import BayesianNetwork

# 构建贝叶斯网络模型
model = BayesianNetwork([('temp_change', 'stock_price')])
model.fit(climate_data, estimator=MaximumLikelihoodEstimator)
