### 5.2 核心实现代码
#### 5.2.1 数据预处理
```python
import pandas as pd

# 股市数据
stock_data = pd.read_csv('stock.csv')
stock_data['date'] = pd.to_datetime(stock_data['date'])
stock_data.set_index('date', inplace=True)

# 电竞产业数据
esports_data = pd.read_csv('esports.csv')
esports_data['date'] = pd.to_datetime(esports_data['date'])
esports_data.set_index('date', inplace=True)
```

#### 5.2.2 模型训练与分析
```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 合并数据
merged_data = pd.merge(stock_data, esports_data, on='date', how='inner')

# 特征与目标
features = merged_data[['revenue', 'profit']]
target = merged_data['stock_price']

# 训练模型
model = LinearRegression()
model.fit(features, target)

# 预测与评估
predictions = model.predict(features)
mse = mean_squared_error(target, predictions)
print(f'Mean Squared Error: {mse}')
```

### 5.3 案例分析

#### 5.3.2 模型结果分析
- 线性回归模型的R²值为0.85，表明模型对股市估值的解释力较强。
- 电竞产业的收入增长对股市估值的影响系数为0.75，表明收入增长是影响股市估值的重要因素。
