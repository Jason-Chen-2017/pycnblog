# 第1章: 央行数字货币(CBDC)的基础知识

## 1.1 央行数字货币(CBDC)的定义与特点

### 1.1.1 央行数字货币的定义

央行数字货币（Central Bank Digital Currency, CBDC）是由国家中央银行发行的数字化货币，具有法律背书，旨在替代或补充传统纸质货币。CBDC结合了区块链等现代技术，具有高效、安全和可追溯的特点。

**背景介绍：**
- **核心概念**：CBDC是国家信用的数字化形式，具有与传统货币相同的价值和功能。
- **问题背景**：随着数字化支付的普及，传统货币体系面临效率低下、成本高昂的问题，CBDC作为一种新型货币形态，旨在解决这些问题。

### 1.1.2 央行数字货币的核心特点

| 特性 | 描述 |
|------|------|
| 法定性 | 由国家中央银行发行，具有法律效力 |
| 数字化 | 基于数字技术，支持电子支付和智能合约 |
| 可追溯性 | 具备交易记录功能，便于监管和反洗钱 |
| 安全性 | 采用区块链等技术，确保交易安全 |

### 1.1.3 央行数字货币与传统货币的对比

**对比表格：**

| 特性 | 传统货币 | CBDC |
|------|----------|------|
| 载体 | 实体货币（纸币、硬币） | 数字货币 |
| 支付效率 | 低效，依赖中介机构 | 高效，支持点对点交易 |
| 成本 | 高昂的印制和流通成本 | 低成本，数字化发行 |

## 1.2 央行数字货币的分类与应用场景

### 1.2.1 零售型央行数字货币

**背景介绍：**
- **核心概念**：零售型CBDC面向公众，用于日常支付和消费。
- **应用场景**：个人之间的转账、零售支付、小额交易。

### 1.2.2 批发型央行数字货币

**背景介绍：**
- **核心概念**：批发型CBDC用于金融机构之间的大额交易和结算。
- **应用场景**：银行间结算、跨境支付、大额交易。

### 1.2.3 央行数字货币在金融体系中的作用

**背景介绍：**
- **核心概念**：CBDC作为金融基础设施的一部分，能够提升支付效率、降低交易成本，并增强金融监管能力。
- **作用机制**：通过数字化支付体系，CBDC可以实时监控交易数据，提高金融透明度。

## 1.3 央行数字货币对金融体系的影响

### 1.3.1 对传统银行体系的冲击

**背景介绍：**
- **核心概念**：CBDC可能改变传统银行的存款和贷款业务模式。
- **影响分析**：银行可能面临客户流失风险，但CBDC也可能为银行提供新的数字化服务机会。

### 1.3.2 对支付清算体系的改变

**背景介绍：**
- **核心概念**：CBDC将推动支付清算体系的数字化转型。
- **影响分析**：支付清算效率提高，交易成本降低，支付方式更加多样化。

### 1.3.3 对货币政策传导机制的影响

**背景介绍：**
- **核心概念**：CBDC将增强中央银行对货币政策的控制能力。
- **影响分析**：货币政策可以更精准地传导到实体经济，减少中间环节的损耗。
