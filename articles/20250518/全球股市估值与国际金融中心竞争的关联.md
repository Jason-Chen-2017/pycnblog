## 第1章: 全球股市估值与国际金融中心竞争的概述

### 1.1 全球股市估值的基本概念

#### 1.1.1 什么是全球股市估值
全球股市估值是指对全球范围内股票市场的整体价值进行评估的过程。它通常通过市盈率（P/E ratio）、市净率（P/B ratio）、市值（Market Capitalization）等指标来衡量市场的健康状况和投资价值。股市估值不仅反映了市场的当前状况，还为投资者提供了决策依据。

#### 1.1.2 全球股市估值的指标与方法
- **市盈率（P/E）**：市盈率=股票价格/每股收益（EPS）。它反映了投资者对股票未来收益的预期。
- **市净率（P/B）**：市净率=股票价格/每股净资产。主要用于评估股票相对于其账面价值的高低。
- **市值（Market Cap）**：市值=股价×发行股数。反映一家公司的规模和市场地位。

#### 1.1.3 全球股市估值的市场影响
股市估值的变化会影响投资者的信心、资金流动和市场参与度。例如，高市盈率可能表明市场对未来增长的乐观预期，而低市盈率可能意味着市场低估或缺乏信心。

### 1.2 国际金融中心的定义与作用

#### 1.2.1 国际金融中心的定义
国际金融中心（IFC）是指在全球金融市场中具有重要地位的城市或地区，如纽约、伦敦、香港、新加坡等。这些中心通常拥有发达的金融基础设施、完善的法律体系和国际化的市场环境。

#### 1.2.2 国际金融中心的核心功能
- 资金融通：为企业和个人提供融资服务。
- 市场交易：提供股票、债券、外汇等金融产品的交易场所。
- 金融监管：确保市场的公平、透明和安全。

#### 1.2.3 全球主要国际金融中心的分布
- 纽约：全球最大的金融市场，美元的中心。
- 伦敦：全球最重要的外汇市场和欧洲股市中心。
- 香港：连接中国内地与国际市场的桥梁。
- 新加坡：亚洲重要的金融和贸易中心。

### 1.3 全球股市估值与国际金融中心竞争的关联性

#### 1.3.1 问题背景与问题描述
- 全球股市估值的变化直接影响金融中心的市场地位。
- 不同金融中心的估值差异反映了其竞争力的差异。

#### 1.3.2 问题解决的路径与方法

- 研究金融中心的竞争策略。

#### 1.3.3 问题的边界与外延

#### 1.3.4 核心概念与核心要素

### 4.2 核心实现源代码
```python
import pandas as pd
import numpy as np

def calculate_pe(stock_price, eps):
    return stock_price / eps

def calculate_pb(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

def main():
    # 示例数据
    stock_prices = pd.Series([100, 150, 75, 200], index=['AAPL', 'GOOGL', 'MSFT', 'AMZN'])
    eps_values = pd.Series([10, 20, 15, 30], index=['AAPL', 'GOOGL', 'MSFT', 'AMZN'])
    
    pe_values = stock_prices.apply(lambda x: calculate_pe(x, eps_values[x.name]))
    pb_values = stock_prices.apply(lambda x: calculate_pb(x, book_value_per_share[x.name]))
    
    print("市盈率：", pe_values)
    print("市净率：", pb_values)

if __name__ == "__main__":
    main()
```
