## 第二部分：圈子理论的核心概念

### 第2章：圈子理论的定义与特点

#### 2.1 圈子理论的定义
- 圈子理论将人际网络视为一种资源，用于支持投资决策。
- 通过分析网络结构，识别关键人物和潜在机会。

#### 2.2 圈子理论的核心特点
- **节点化**：每个人被视为网络中的一个节点。
- **关系化**：节点之间的关系强度决定网络的连通性。
- **层次化**：网络结构具有层次，中心节点具有更高的影响力。

#### 2.3 圈子理论与传统投资理论的区别
| 特性       | 圈子理论                          | 传统投资理论                        |
|------------|-----------------------------------|-------------------------------------|
| 核心要素   | 人际网络、关系强度                | 财务指标、市场趋势                   |
| 分析方法   | 图论、社会网络分析                | 财务分析、技术分析                   |
| 应用范围   | 人际网络驱动投资决策              | 市场分析驱动投资决策                 |

### 第3章：圈子理论的数学模型

#### 3.1 圈子理论的图论模型
- **节点与边**：节点代表人物，边代表关系。
- **网络密度**：边的数量与节点数量的比值，反映网络的紧密程度。
- **中心性分析**：通过计算节点的度数和介数，识别关键人物。

#### 3.2 圈子理论的数学表达式
- **度数公式**：$$degree(i) = \sum_{j} a_{ij}$$，其中$a_{ij}$表示节点$i$与$j$之间的关系强度。
- **介数公式**：$$betweenness(i) = \sum_{j < k} \frac{\sigma(j,k|i)}{\sigma(j,k)}$$，其中$\sigma(j,k|i)$表示在移除$i$后$j$到$k$的最短路径数量，$\sigma(j,k)$表示原始最短路径数量。

## 第四部分：项目实战

### 第6章：项目实战分析

#### 6.1 分析巴菲特的核心圈子
- 使用Python代码分析巴菲特的核心圈子结构。
- 代码示例：
```python
import networkx as nx

# 创建图
G = nx.Graph()

# 添加节点
G.add_nodes_from(["巴菲特", "芒格", "甲骨文", "苹果"])

# 添加边
G.add_edges_from([("巴菲特", "芒格"), ("芒格", "甲骨文"), ("巴菲特", "苹果")])

# 计算中心性
centrality = nx.betweenness_centrality(G)

# 打印结果
print(centrality)
```

#### 6.2 结果解读
- 巴菲特的中心性最高，是网络的核心节点。
- 芒格和甲骨文位于中间层，是关键的桥梁节点。
- 苹果是巴菲特的重点投资对象，连接了核心网络。
