## 第一部分: 格雷厄姆特价股票理论概述

### 第1章: 格雷厄姆特价股票理论的核心概念

#### 1.1 格雷厄姆投资理论的背景与起源

格雷厄姆（Benjamin Graham）是价值投资的鼻祖，被誉为“现代证券分析之父”。他在20世纪初提出了价值投资的理念，强调以低于内在价值的价格买入股票，从而在市场波动中实现长期稳定的收益。格雷厄姆的理论核心在于“安全边际”和“内在价值”的概念，为投资者提供了一种理性、系统的方法来评估股票的价值。

#### 1.2 格雷厄姆投资理论的核心原则

格雷厄姆的价值投资理论主要包括以下几个核心原则：

1. **安全边际**：买入价格低于股票内在价值的一定折扣，以确保投资的安全性。
2. **内在价值**：通过基本面分析（如市盈率、市净率、股息率等指标）计算股票的真实价值。
3. **分散投资**：通过构建多元化的投资组合来降低风险，避免过度依赖单一股票或行业。

#### 1.3 特价股票的定义与特征

格雷厄姆提出的“特价股票”是指市场价格低于其内在价值的股票。这类股票通常具有以下特征：
- **低估性**：市场价格低于同类股票的平均价格。
- **稳定性**：公司具有稳定的财务状况和持续的盈利能力。
- **防御性**：公司具备较强的抗风险能力和防御性特征。

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(stock_data):
    # 计算市盈率（P/E）
    pe_ratio = stock_data['price'] / stock_data['eps']
    # 计算市净率（P/B）
    pb_ratio = stock_data['price'] / stock_data['book_value_per_share']
    # 计算股息率（Dividend Yield）
    dividend_yield = stock_data['dividend_per_share'] / stock_data['price']
    
    # 综合评估内在价值（简化版）
    intrinsic_value = stock_data['price'] * (1 / (pe_ratio * 0.5 + pb_ratio * 0.3 + dividend_yield * 0.2))
    return intrinsic_value

# 示例数据
stock_data = {
    'price': [100, 80, 90],
    'eps': [20, 25, 30],
    'book_value_per_share': [5, 6, 7],
    'dividend_per_share': [2, 3, 4]
}

# 计算内在价值
intrinsic_values = calculate_intrinsic_value(stock_data)
print(intrinsic_values)
```

#### 5.2 实战代码实现

```python
import numpy as np
from sklearn.datasets import make_spd_matrix

def optimize_portfolio(weights, returns, covariance_matrix):
    # 定义优化目标：最大化夏普比率
    def objective(weights):
        return -(weights.T @ returns) / np.sqrt(weights.T @ covariance_matrix @ weights)

    # 定义约束条件
    constraints = [
        ('sum', weights, 1.0),
        ('>=', weights, 0.0)
    ]

    # 使用优化算法求解
    from scipy.optimize import minimize
    result = minimize(objective, weights, constraints=constraints)
    return result.x

# 示例数据
n_assets = 5
returns = np.random.normal(0, 0.2, n_assets)
covariance_matrix = make_spd_matrix(n_assets)
initial_weights = np.array([1/n_assets] * n_assets)

# 优化投资组合
optimal_weights = optimize_portfolio(initial_weights, returns, covariance_matrix)
print(optimal_weights)
```
