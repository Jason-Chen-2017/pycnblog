## 第1章：格雷厄姆特价股票策略的核心概念

### 1.1 格雷厄姆投资理论的起源与发展

格雷厄姆是价值投资之父，提出“安全边际”和“内在价值”概念，主张寻找市场低估的股票进行长期投资。

### 1.2 特价股票的定义与核心要素

特价股票指市场价格低于内在价值的股票，核心要素包括低市盈率、低市净率和高股息率。

### 1.3 格雷厄姆策略在投资中的优势与局限性

优势：长期稳定收益，风险较低。局限性：适应性差，应对市场波动能力有限。

import pandas as pd

def calculate_intrinsic_value(net_profit, roe):
    return net_profit / roe

# 示例数据
data = {'净利润': [100, 200, 300], 'ROE': [15, 20, 25]}
df = pd.DataFrame(data)
df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['净利润'], x['ROE']), axis=1)
print(df)
