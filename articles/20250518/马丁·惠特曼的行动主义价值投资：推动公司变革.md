# 第3章: 行动主义价值投资的核心原则与策略

## 3.1 核心原则
### 3.1.1 企业基本面分析
- 通过财务指标（如市盈率、市净率）评估企业的内在价值。
- 分析企业的盈利能力和成长潜力。

### 3.1.2 公司治理结构评估
- 评估董事会的独立性和透明度。
- 关注股东权益保护和公司治理的完善性。

### 3.1.3 行动主义投资的长期性
- 强调长期持有的理念，避免短期波动的干扰。
- 通过长期投资实现企业价值的提升。

## 3.2 投资策略
### 3.2.1 选股标准
- 寻找低估值、高潜力的企业。
- 关注行业龙头和具有竞争优势的公司。

### 3.2.2 投资组合构建
- 根据风险偏好和投资目标构建多元化投资组合。
- 通过分散投资降低风险。

### 3.2.3 风险管理
- 设置止损点，控制单个投资的风险敞口。
- 定期评估投资组合的波动性和潜在风险。

import pandas as pd
import numpy as np

# 数据采集
def collect_data(tickers):
    data = {}
    for ticker in tickers:
        df = pd.DataFrame({'Ticker': [ticker]})
        data[ticker] = df
    return data

# 数据清洗
def preprocess_data(data):
    cleaned_data = {}
    for ticker, df in data.items():
        # 删除缺失值
        df.dropna(inplace=True)
        # 标准化处理
        df = (df - df.mean()) / df.std()
        cleaned_data[ticker] = df
    return cleaned_data
```

from sklearn.metrics import pairwise_distances

def portfolio_optimization(tickers, returns, covariance_matrix):
    n = len(tickers)
    # 使用均值-方差优化
    mu = np.mean(returns)
    sigma = np.sqrt(np.diag(covariance_matrix))
    # 计算最优权重
    Sigma = covariance_matrix
    mu_vec = mu.reshape(-1, 1)
    inv_Sigma = np.linalg.inv(Sigma)
    w = inv_Sigma.dot(mu_vec)
    w = w / np.sum(w)
    return w
```
