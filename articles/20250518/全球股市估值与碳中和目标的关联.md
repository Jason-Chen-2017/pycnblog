# 第一部分：全球股市估值与碳中和目标的背景与概念

## 第1章：全球股市估值的现状与趋势

### 1.1 全球股市估值的基本概念

#### 1.1.1 股市估值的定义与计算方法
股市估值是通过对上市公司股票价格的评估，反映其市场价值。常用指标包括市盈率（P/E）、市净率（P/B）和市值等。例如，市盈率 = 股价 / 每股收益。

#### 1.1.2 全球主要股市的估值指标
全球主要股市包括纽约证券交易所、纳斯达克、伦敦证交所等，其估值指标展示了不同市场的表现和风险偏好。

#### 1.1.3 股市估值的影响因素分析
影响股市估值的因素包括宏观经济指标、企业盈利、政策变化等。例如，经济增长率和利率水平直接影响市场整体估值。

### 1.2 碳中和目标的全球进展

#### 1.2.1 碳中和的定义
碳中和是指通过减少温室气体排放和增加碳汇，使净碳排放量为零。

#### 1.2.2 全球碳中和目标的现状
许多国家和地区已设定碳中和目标，如欧盟计划在2050年实现碳中和，中国则计划在2060年实现。

#### 1.2.3 碳中和对经济和产业的影响
碳中和目标推动了能源结构转型，促进了可再生能源和绿色技术的发展。
