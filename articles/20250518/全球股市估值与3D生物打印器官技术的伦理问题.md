# 第一部分: 全球股市估值的背景与方法

## 第1章: 全球股市估值的基本概念

### 1.1 股市估值的定义与作用

股市估值是通过对公司财务数据的分析，评估其股票的内在价值，为投资者提供参考依据。其作用包括指导投资决策、评估公司财务健康状况和发现市场异常波动。

- **核心要素**：包括市盈率（PE）、市净率（PB）、股息率等。
- **边界**：仅适用于上市公司，需考虑宏观经济环境。

### 1.2 股市估值与经济的影响

股市估值不仅反映公司价值，还影响整体经济状况。例如，股市波动可能引发金融危机。

## 第2章: 股市估值的主要方法

### 2.1 常用估值方法概述

#### 2.1.1 市盈率（PE）法

PE=股价/每股收益。通过比较PE值，判断股票是否被高估或低估。

- **mermaid流程图**：
  ```mermaid
  graph TD
      A[股价] --> B[每股收益]
      B --> C[PE值]
      C --> D[估值结果]
  ```

#### 2.1.2 市净率（PB）法

PB=股价/每股净资产。适用于评估银行等净资产较高的行业。

#### 2.1.3 现金流折现法（DCF）

DCF通过未来现金流的现值计算企业价值，公式为：
$$
\text{企业价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t}
$$

### 2.2 各种估值方法的优缺点对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| PE | 简单易用 | 受市场波动影响大 |
| PB | 考虑资产价值 | 适用于特定行业 |
| DCF | 准确性高 | 计算复杂 |

## 第3章: 影响股市估值的主要因素

#### 3.1.1 利率水平对股市估值的影响

### 3.2 行业状况

行业周期性影响公司业绩，从而影响股市估值。

### 3.3 公司基本面

包括收入、利润、资产负债表等因素。
