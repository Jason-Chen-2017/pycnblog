# 第5章: 投资组合管理的数学模型与算法优化

## 5.1 投资组合管理的数学模型

### 5.1.1 现代投资组合理论（MPT）
- 均值-方差优化
- 投资者效用函数

### 5.1.2 数学公式
$$\text{目标函数：} \min_w \sigma^2(w)$$
$$\text{约束条件：} \sum_{i=1}^n w_i = 1, \quad w_i \geq 0$$

### 5.1.3 模型对比
| 模型 | 输入 | 输出 | 优势 |
|------|------|------|------|
| MPT  | 预期收益、协方差矩阵 | 最小方差组合 | 理论基础强 |
| 简单平均 | 无 | 等权重组合 | 易实现 |

```python
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def objective(weights, covariance_matrix):
    return np.dot(weights.T, np.dot(covariance_matrix, weights))

# 约束条件
def constraint(weights, risk_asset):
    return weights[0] - risk_asset

# 求解优化问题
def portfolio_optimization(returns, covariance_matrix, risk_asset=0.5):
    n = len(weights)
    init_weights = np.array([1.0/n]*n)
    result = minimize(objective, init_weights, 
                     constraints={'type': 'eq', 'fun': constraint, 'args': (risk_asset,)},
                     bounds=[(0, 1) for _ in range(n)])
    return result.x

# 示例数据
returns = np.array([0.1, 0.12, 0.08])
covariance_matrix = np.array([[0.02, 0.01, 0.01],
                              [0.01, 0.03, 0.02],
                              [0.01, 0.02, 0.03]])
weights = portfolio_optimization(returns, covariance_matrix)
print(weights)
