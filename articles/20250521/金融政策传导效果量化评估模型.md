### 第一部分：背景介绍

#### 第1章：金融政策传导效果评估的背景与问题

##### 1.1 问题背景
- 金融政策是调节经济的关键工具，但其效果受多种因素影响，难以直接量化。
- 传统评估方法依赖专家判断，存在主观性和片面性。

##### 1.2 问题描述
- 金融政策传导路径复杂，涉及多个经济主体和市场。
- 评估效果时，难以量化各因素的贡献度。

##### 1.3 问题解决思路
- 建立系统动力学模型，模拟政策传导过程。
- 使用计量经济学方法，量化政策效果。

##### 1.4 边界与外延
- 研究范围：宏观金融政策。
- 不考虑微观个体差异。
- 模型适用于中短期政策评估。

##### 1.5 概念结构与核心要素
- 核心概念：金融政策、传导机制、经济指标。
- 关键要素：政策工具、传导路径、效果指标。

##### 5.2 核心代码实现
```python
import numpy as np
import pandas as pd
from pyguro import Model

def policy_effect(policy, params):
    # 定义政策传导模型
    model = Model()
    model.add_var('P', value=policy)
    model.add_var('r', equation='P * params[0]')
    model.add_var('I', equation='params[1] * P + params[2] * r')
    model.add_var('C', equation='params[3] * Y - params[4] * r')
    model.add_var('Y', equation='I + C')
    model.run()
    return model.get_var('Y')

# 参数设置
params = [0.5, 0.2, 0.3, 0.8, 0.1]
policy = 0.1

# 计算效果
effect = policy_effect(policy, params)
print(f"政策效果：{effect}")
```
