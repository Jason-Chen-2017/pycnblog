### 第4章: 算法原理

#### 4.1 现代投资组合理论的数学模型
现代投资组合理论通过优化投资组合的均值-方差，实现风险与收益的最佳平衡。

$$\text{目标函数：} \quad \min_w \sigma^2 \quad \text{subject to} \quad \mu^T w = \text{目标收益}$$

其中，\( w \) 是投资权重向量，\( \mu \) 是资产收益均值，\( \sigma^2 \) 是投资组合的方差。

#### 4.2 均值-方差优化算法
使用Python的优化库，实现均值-方差模型，选择最优资产配置。

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns):
    n = len(returns.columns)
    mu = returns.mean().values
    sigma = returns.cov().values

    def objective(w):
        return np.dot(w.T, np.dot(sigma, w))

    constraints = [
        ('sum', w, 1),
        ('eq', np.dot(mu, w), 0.1)
    ]

    bounds = [(0, 1) for _ in range(n)]

    result = minimize(objective, np.ones(n)/n, method='SLSQP', bounds=bounds, constraints=constraints)
    return result.x

# 示例数据：returns为资产收益矩阵
```

#### 4.3 风险调整后的收益评估
使用夏普比率评估投资组合的超额收益风险比。

$$\text{夏普比率} = \frac{E[r_p - r_f]}{\sigma_p}$$

其中，\( E[r_p] \) 是投资组合的期望收益，\( r_f \) 是无风险利率，\( \sigma_p \) 是投资组合的波动率。

import pandas as pd
import numpy as np

def main():
    # 示例数据
    returns = pd.DataFrame({
        '股票': [0.1, 0.05, 0.08, 0.02, 0.06],
        '债券': [0.05, 0.04, 0.03, 0.02, 0.01],
        '房地产': [0.08, 0.06, 0.07, 0.05, 0.04]
    })
    
    # 资产配置优化
    weights = portfolio_optimization(returns)
    print("最优资产权重:", weights)
    
    # 风险评估
    expected_return = np.dot(weights, returns.mean())
    volatility = np.sqrt(weights.dot(returns.cov()).dot(weights))
    sharpe_ratio = (expected_return - 0.02) / volatility  # 假设无风险利率为2%
    print("夏普比率:", sharpe_ratio)

if __name__ == "__main__":
    main()
```
