### 5.3.2 系统架构设计的类图
```mermaid
classDiagram
    class 创意生成模块 {
        + 输入创意：idea
        + 输出评估指标：evaluation指标
        + 生成创意：generate_creativity()
    }
    class 创新评估模块 {
        + 输入评估指标：evaluation指标
        + 输出评估结果：assessment结果
        + 评估创意：assess_creativity()
    }
    class 创新实施模块 {
        + 输入创意：idea
        + 输入评估结果：assessment结果
        + 输出实施计划：implementation计划
        + 制定实施计划：create_implementation_plan()
    }
    创意生成模块 --> 创新评估模块: 提交评估指标
    创新评估模块 --> 创新实施模块: 提交评估结果
```

```mermaid
graph TD

```

```mermaid
sequenceDiagram
```
