## 第3章：脱敏算法的原理与实现

### 3.1 数据脱敏算法的分类与流程
- 随机替换算法
  - 原理：随机选择一个与原数据相似的值进行替换
  - 示例：将“张三”替换为“李四”
  - 代码实现：
```python
import random
def random_replace(sensitive_data, candidate_list):
    return random.choice(candidate_list)
```

- 同态加密算法
  - 原理：对数据进行加密处理，确保脱敏后数据仍可进行数学运算
  - 示例：对金额数据进行加密脱敏
  - 代码实现：
```python
def homomorphic_encrypt(value, key):
    return value * key % mod
```

- 差分隐私算法
  - 原理：在数据中添加噪声，保护个体隐私
  - 示例：对地理位置数据进行模糊处理
  - 代码实现：
```python
import random
def differential_privacy(location, epsilon):
    return location + random.laplace(0, 1/epsilon)
```

### 3.2 脱敏算法的数学模型
- 随机替换模型
  $$ P(x) = \sum_{i=1}^{n} p_i \cdot \delta(x - x_i) $$
  其中，$p_i$ 是替换概率，$\delta$ 是狄拉克函数。

- 同态加密模型
  $$ E(x) = x \cdot k \mod m $$
  其中，$k$ 是加密密钥，$m$ 是模数。
