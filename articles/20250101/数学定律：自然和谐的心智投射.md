### 系统核心实现与代码分析

以下是订单管理的核心实现代码：

```python
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'postgresql://username:password@localhost:5432/mydatabase'
db = SQLAlchemy(app)

class Order(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, nullable=False)
    total_price = db.Column(db.Float, nullable=False)
    status = db.Column(db.String(50), nullable=False)

@app.route('/order', methods=['POST'])
def create_order():
    data = request.get_json()
    user_id = data['user_id']
    total_price = data['total_price']
    status = 'pending'

    new_order = Order(user_id=user_id, total_price=total_price, status=status)
    db.session.add(new_order)
    db.session.commit()

    return jsonify({'message': 'Order created successfully', 'order_id': new_order.id})

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```

这段代码定义了一个订单模型 `Order`，并实现了创建订单的 API 接口。具体步骤如下：

1. 导入所需的库和模块。
2. 配置数据库连接。
3. 定义订单模型，包括 `id`、`user_id`、`total_price` 和 `status` 字段。
4. 创建 `Order` 表。
5. 实现 `/order` 接口，用于接收 JSON 格式的订单数据，创建订单并保存到数据库。
