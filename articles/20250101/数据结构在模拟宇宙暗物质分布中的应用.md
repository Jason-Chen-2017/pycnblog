## 数据结构与宇宙模拟概述

### 2.1 数据结构基础

数据结构是计算机科学的核心概念，用于组织和管理数据。在宇宙模拟中，数据结构的选择至关重要。常见的线性数据结构包括数组、链表和栈，而非线性数据结构包括树、图和哈希表。

#### 数组

数组是一种线性数据结构，用于存储相同类型的数据元素。它在计算机内存中连续分配空间，因此访问速度较快。

#### 链表

链表也是一种线性数据结构，但与数组不同，它的元素在内存中不连续。每个元素包含数据和指向下一个元素的指针。

#### 栈

栈是一种后进先出（LIFO）的数据结构，常用于递归和深度优先搜索。

#### 树

树是一种非线性数据结构，由节点组成，每个节点可以有零个或多个子节点。常见的树结构包括二叉树、平衡树和堆。

#### 图

图是一种由节点和边组成的数据结构，用于表示复杂的关系。在宇宙模拟中，图可以用来表示星系、星系团等复杂结构。

#### 2. 观测模拟

观测模拟基于现有的观测数据，模拟宇宙的演化过程，以预测未来可能的观测结果。这种方法有助于科学家们预测暗物质分布的演变。

#### 3. 理论模拟

理论模拟基于理论模型，如冷暗物质模型，模拟宇宙的演化过程。这种方法有助于科学家们研究暗物质与宇宙背景辐射的相互作用。

假设我们有一个包含100个暗物质粒子的宇宙模拟系统。我们使用以下数学模型来计算每个粒子的位置：

$$
\frac{d^2x}{dt^2} = -\frac{Gm_1m_2}{r^2}
$$

其中，$x$ 是粒子位置，$t$ 是时间，$G$ 是引力常数，$m_1$ 和 $m_2$ 是两个粒子的质量，$r$ 是它们之间的距离。

import numpy as np

acceleration = -G * m1 * m2 / r**2

```python
import numpy as np
import matplotlib.pyplot as plt

# 初始化参数
G = 6.6743e-11  # 引力常数
m1 = 1.989e30   # 粒子1的质量
m2 = 1.989e30   # 粒子2的质量
r = 1e13        # 粒子之间的距离
time_step = 1e8 # 时间步长

# 初始化粒子位置
x = np.random.uniform(-1e13, 1e13, size=100)
y = np.random.uniform(-1e13, 1e13, size=100)

# 模拟过程
for _ in range(int(time_step)):
    # 计算加速度
    acceleration_x = -G * m1 * m2 / (x**2 + y**2)
    acceleration_y = -G * m1 * m2 / (x**2 + y**2)

    # 更新位置
    x += acceleration_x * time_step
    y += acceleration_y * time_step

# 可视化结果
plt.scatter(x, y)
plt.xlabel('X Position')
plt.ylabel('Y Position')
plt.show()
```
