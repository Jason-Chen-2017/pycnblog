#### 第2章: AIGC的核心技术

##### 2.1 生成对抗网络（GAN）

GAN（Generative Adversarial Network）是AIGC的核心技术之一，由生成器和判别器组成。生成器生成数据，判别器判断数据的真实性。GAN的目的是通过博弈的方式训练生成器，使其生成更加逼真的数据。以下是一个简单的GAN模型：

```
# 伪代码

Generator:
  Input: Z (随机噪声)
  Output: G(z)

Discriminator:
  Input: X (真实数据), G(z) (生成数据)
  Output: D(x), D(g(z))
```

##### 2.2 变分自编码器（VAE）

VAE（Variational Autoencoder）是一种概率生成模型，通过编码器和解码器实现数据的生成和重建。编码器将输入数据编码为潜在空间中的点，解码器将潜在空间中的点解码为生成数据。以下是一个简单的VAE模型：

```
# 伪代码

Encoder:
  Input: X
  Output: z, log(q(z|x))

Decoder:
  Input: z
  Output: X'
```
