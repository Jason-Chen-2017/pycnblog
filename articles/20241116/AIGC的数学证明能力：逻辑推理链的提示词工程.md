形式逻辑证明是数学证明的一个重要分支，它通过符号化语言和逻辑规则来推导结论。以下是一个形式逻辑证明的例子：

**问题**：证明如果一个数是偶数，那么它的平方也是偶数。

**证明**：

设 \( n \) 是一个偶数，则存在一个整数 \( k \)，使得 \( n = 2k \)。

那么 \( n^2 = (2k)^2 = 4k^2 = 2(2k^2) \)。

由于 \( 2k^2 \) 是一个整数，设 \( m = 2k^2 \)，则 \( n^2 = 2m \)。

因此，\( n^2 \) 是一个偶数。

**伪代码**：

```python
def prove_even_square(n):
    k = n / 2  # 假设 n 是偶数，所以可以整除 2
    m = k * k * 2  # 计算 2k^2
    if n == m / 2:  # 验证 n^2 是偶数
        return True
    else:
        return False
```

**数学公式**：

$$
n = 2k \\
n^2 = (2k)^2 = 4k^2 = 2(2k^2) = 2m
$$

**举例说明**：

假设 \( n = 4 \)，则 \( k = 2 \)，\( m = 2^2 * 2 = 8 \)。我们可以看到 \( n^2 = 16 \)，确实是一个偶数。

通过这个例子，我们可以看出形式逻辑证明是如何通过定义、假设和推理步骤来证明一个数学命题的。
