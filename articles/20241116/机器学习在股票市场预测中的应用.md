## 第二部分：机器学习基础

### 2.1 机器学习基本概念

#### 2.1.1 机器学习的定义

机器学习是一门研究如何让计算机从数据中学习并做出决策或预测的人工智能领域。

#### 2.1.2 监督学习、无监督学习和强化学习

- **监督学习**：有标注的数据，预测结果对输入数据的映射。
- **无监督学习**：没有标注的数据，发现数据中的结构或模式。
- **强化学习**：通过与环境的交互学习，以最大化长期回报。

### 2.2 机器学习算法

#### 2.2.1 线性回归

线性回归是一种简单而强大的预测算法，其数学模型如下：

$$
y = \beta_0 + \beta_1x
$$

#### 2.2.2 决策树

决策树通过一系列的规则对数据进行划分，其伪代码如下：

```
if x <= v then
    y = \beta_0 + \beta_1x
else
    y = \beta_0 + \beta_2x
```

### 2.3 机器学习模型

#### 2.3.1 支持向量机

支持向量机是一种二分类模型，其目标是将数据分为两个类别。其优化目标如下：

$$
\text{minimize } \frac{1}{2} ||w||^2 \\
\text{subject to } y_i (w \cdot x_i + b) \geq 1
$$

#### 2.3.2 神经网络

神经网络通过多层神经元进行数据传递和变换，其基本结构如下：

```
input layer --> hidden layer(s) --> output layer
```
