```python
        return "请生成这篇文章的摘要。"
    elif input == "翻译":
        return "将这段英文翻译成中文。"
    else:
        return "我不理解您的需求，请重新说明。"
```

###### 2.1.2 基于机器学习的方法

基于机器学习的方法通过大量训练数据学习生成提示词的规律。这种方法具有较好的灵活性和泛化能力，但需要大量的训练数据和计算资源。
