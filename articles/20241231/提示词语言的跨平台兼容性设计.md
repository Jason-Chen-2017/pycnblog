```python
class PlatformAbstract:
    def execute(self):
        raise NotImplementedError()

class WindowsAdapter(PlatformAbstract):
    def execute(self):
        # Windows平台特有实现
        print("执行Windows操作")

class LinuxAdapter(PlatformAbstract):
    def execute(self):
        # Linux平台特有实现
        print("执行Linux操作")

class MacOSAdapter(PlatformAbstract):
    def execute(self):
        # macOS平台特有实现
        print("执行macOS操作")

class CommonInterface:
    def call(self, adapter):
        adapter.execute()

def main():
    # 检测操作系统并选择适配器
    if platform.system() == "Windows":
        adapter = WindowsAdapter()
    elif platform.system() == "Linux":
        adapter = LinuxAdapter()
    elif platform.system() == "Darwin":
        adapter = MacOSAdapter()
    else:
        raise PlatformNotSupportedError()

    # 调用通用接口
    common_interface = CommonInterface()
    common_interface.call(adapter)

if __name__ == "__main__":
    main()
```

在这个示例中，`PlatformAbstract` 类定义了一个抽象类，`WindowsAdapter`、`LinuxAdapter` 和 `MacOSAdapter` 分别实现了Windows、Linux和macOS的适配器。`CommonInterface` 类定义了一个通用接口，`call` 方法用于调用适配器的 `execute` 方法。`main` 函数用于检测操作系统并选择适配器，然后通过通用接口调用适配器的 `execute` 方法。
