#### 2.2.3 Python 代码实现

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

# 测试
```

### 2.3 算法2：二分查找算法

#### 2.3.1 算法描述

二分查找算法是一种在有序数组中查找特定元素的算法。它通过不断将查找范围缩小一半来提高搜索效率。

#### 2.3.2 算法流程图

**图2.3.1 二分查找算法**

```mermaid
graph TD
A[开始] --> B[初始化变量]
B --> C{计算中间索引}
C --> D{比较中间值与目标值}
D -->|相等| E[结束]
D -->|不等| F{更新查找范围}
F --> G{循环直到找到或范围缩小为0}
G --> H[输出结果]
H --> I[结束]
```

#### 2.3.3 Python 代码实现

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

# 测试
arr = [1, 3, 5, 7, 9, 11, 13, 15]
target = 7
result = binary_search(arr, target)
if result != -1:
    print(f"元素在索引 {result} 处")
else:
    print("元素不在数组中")
```

T(n) = O(\log n)
$$

其中，$T(n)$ 表示算法的运行时间，$n$ 表示数组的长度。

#### 2.3.5 举例说明

假设我们有一个有序数组 `[1, 3, 5, 7, 9, 11, 13, 15]`，要查找元素 `7`。通过二分查找算法，我们可以在第4个位置找到该元素。
