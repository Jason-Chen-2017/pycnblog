```python
import tensorflow as tf

from tensorflow.keras.models import Model

# 定义输入层
input_layer = Input(shape=(input_shape))

# 感知阶段：提取特征
perception_layer = Dense(128, activation='relu')(input_layer)
```

#### 数学模型与公式

该模型基于以下数学模型：

$$
\begin{aligned}

\text{推理阶段：} \quad &y = \sigma(W_3 \cdot h + b_3)
\end{aligned}
$$

其中，$W_1$、$W_2$和$W_3$分别为权重矩阵，$b_1$、$b_2$和$b_3$分别为偏置项，$\sigma$为sigmoid激活函数。
