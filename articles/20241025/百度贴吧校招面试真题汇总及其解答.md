#### 第二部分：算法与数据结构面试题解析

**第2章：算法基础**

1. 排序算法

   - 冒泡排序

     - 伪代码

       ```
       for i = 0 to n - 1
         for j = 0 to n - i - 1
           if arr[j] > arr[j+1]
             swap(arr[j], arr[j+1])
       ```

   - 选择排序

     - 伪代码

       ```
       for i = 0 to n - 1
         min = i
         for j = i + 1 to n
           if arr[j] < arr[min]
             min = j
         swap(arr[i], arr[min])
       ```

2. 搜索算法

   - 二分搜索

     - 伪代码

       ```
       low = 0, high = n - 1
       while low <= high
         mid = (low + high) / 2
         if arr[mid] == x
           return mid
         else if arr[mid] < x
           low = mid + 1
         else
           high = mid - 1
       return -1
       ```
