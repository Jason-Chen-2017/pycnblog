#### 1.1 数学与音乐的联系

1. **音高与频率的关系**：音高与频率密切相关。在音乐中，音高是由声波的频率决定的。频率越高，音高就越高。数学上，频率可以用赫兹（Hz）来表示，即每秒钟振动的次数。

    $$ f = \frac{1}{T} $$

    其中，\( f \) 是频率（赫兹），\( T \) 是声波的周期（秒）。

2. **和弦与音程**：和弦是音乐中常见的基本结构之一。和弦的构成依赖于音程的关系。音程是指两个音符之间的距离，可以分为全音、半音等。数学上，音程可以用度数来表示，例如大三度和三全音。

    $$ C - E = 大三度 (3半音) $$
    $$ C - G = 大三度 (3半音) $$

3. **节奏与拍子**：节奏是音乐中时间感的体现，而拍子则是节奏的组织形式。拍子可以用分数来表示，其中分子表示每小节的拍数，分母表示每拍的单位。

    $$ 4/4 拍 = 每小节4拍，每拍为四分音符 $$

音阶是音乐中最基本的元素之一，它由一系列按照特定顺序排列的音符组成。常见的音阶有大调音阶和小调音阶，它们在数学上可以用半音和全音的序列来表示。

1. **大调音阶**：大调音阶由七个音符组成，其半音和全音的序列为：全音、全音、半音、全音、全音、全音、半音。可以用以下数学公式表示：

    $$ W W H W W W H $$

    其中，\( W \) 表示全音，\( H \) 表示半音。

2. **小调音阶**：小调音阶同样由七个音符组成，其半音和全音的序列为：全音、半音、全音、全音、半音、全音、全音。可以用以下数学公式表示：

    $$ W H W W H W W $$

    其中，\( W \) 表示全音，\( H \) 表示半音。

和弦是音乐中的另一个重要元素，它由三个或更多的音符组成，这些音符在数学上按照三度关系排列。大三和弦和小三和弦是常见的和弦类型。

节奏是音乐中时间感的体现，它通过不同的音符时值和拍子的组织来传达音乐的动态和情感。拍子是节奏的组织形式，它用数字来表示每小节的拍数和每拍的单位。

import numpy as np
import matplotlib.pyplot as plt
from pydub import AudioSegment
from pydub.playback import play

# 斐波那契数列生成旋律
def fibonacci_melody(duration, frequencies):
    melody = []
    for i in range(duration):
        freq = frequencies[i % len(frequencies)]
        note = np.sin(2 * np.pi * freq * i / duration)
        melody.append(note)
    return melody

# 微积分生成动态音高
def dynamic_melody(melody, speed):
    dynamic_melody = []
    for note in melody:
        if np.random.rand() > 0.5:
            note *= 1.05 ** speed
        else:
            note *= 0.95 ** speed
        dynamic_melody.append(note)
    return dynamic_melody

# 线性代数生成对称和弦
def symmetrical_chord(frequencies):
    matrix = np.array([[0, 4, 7], [4, 0, 7], [7, 4, 0]])
    transformed_frequencies = matrix @ frequencies
    chord = transformed_frequencies.astype(int)
    return chord

# 概率论生成节奏
def random_rhythm(duration, probabilities):
    rhythm = []
    for _ in range(duration):
        probability = np.random.choice(a=probabilities, size=1, p=probabilities)
        rhythm.append(probability)
    return rhythm

# 参数设置
duration = 8000  # 总时长（毫秒）
frequencies = [261.63, 293.66, 329.63, 349.23, 392.00]  # 音频频率
speed = 0.1  # 动态变化速度
probabilities = [0.2, 0.3, 0.2, 0.2, 0.1]  # 节奏概率分布

# 生成旋律
fibonacci_melody = fibonacci_melody(duration, frequencies)

# 动态变化
dynamic_melody = dynamic_melody(fibonacci_melody, speed)

# 生成和弦
chord = symmetrical_chord(frequencies)

# 生成节奏
rhythm = random_rhythm(duration, probabilities)

# 将旋律、和弦和节奏组合成音频
audio = AudioSegment.empty()
for i in range(len(dynamic_melody)):
    if rhythm[i] == 1:
        audio = audio + AudioSegment.silent(duration=100)
    note = np.sin(2 * np.pi * chord[i] * i / duration)
    audio = audio + AudioSegment(

plt.show()
