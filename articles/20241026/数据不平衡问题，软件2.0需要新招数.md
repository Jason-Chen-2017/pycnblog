### 第2章：数据不平衡问题解析

#### 2.1 数据不平衡的定义与影响

数据不平衡是指数据集中不同类别的样本数量不均衡。在机器学习任务中，数据不平衡会影响模型的性能，导致模型对某些类别的预测准确性较低。

#### 2.2 数据不平衡的分类

数据不平衡可以分为以下几种类型：

1. **类别不平衡**：不同类别的样本数量差异较大。
2. **值域不平衡**：不同特征的值域差异较大。
3. **时间不平衡**：不同时间段的数据量差异较大。

#### 2.3 数据不平衡的原因分析

数据不平衡的原因主要包括：

1. **数据来源差异**：不同类别的数据来源存在差异，导致样本数量不均衡。
2. **数据采集过程**：数据采集过程中可能存在漏采或误采，导致数据不平衡。
3. **业务需求变化**：业务需求的变化可能导致数据分布发生变化，导致数据不平衡。

## 第二部分：解决数据不平衡的方法

### 第3章：传统数据处理方法

#### 3.1 数据采样

数据采样是指从原始数据集中选取一部分样本作为训练数据集。常用的采样方法包括简单随机采样、系统采样和分层采样等。

#### 3.2 特征工程

特征工程是指通过对原始数据进行处理和转换，提取出有助于模型训练的特征。特征工程包括特征选择、特征变换和特征构造等。

#### 3.3 模型选择与调参

选择合适的模型并调整模型参数是解决数据不平衡的重要手段。常用的模型包括逻辑回归、决策树、随机森林和梯度提升树等。

### 第4章：平衡数据集的先进技术

#### 4.1 集成学习

集成学习是指将多个基学习器进行组合，以提高模型的预测性能。常用的集成学习方法包括Bagging、Boosting和Stacking等。

#### 4.2 过采样

过采样是指增加少数类别的样本数量，以平衡数据集。常用的过采样方法包括复制采样、SMOTE和ADASYN等。

#### 4.3 前采样

前采样是指只对少数类别的样本进行训练，以减少模型对多数类别的依赖。常用的前采样方法包括删除采样和随机前采样等。

#### 4.4 生成对抗网络（GAN）

生成对抗网络（GAN）是一种生成模型，通过对抗性训练生成与真实数据相似的样本，从而平衡数据集。

#### D.3 生成对抗网络（GAN）代码实战与解析

```python
import tensorflow as tf
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense, Reshape, Flatten
import numpy as np

# 生成器模型
latent_dim = 100
input_shape = (latent_dim,)
z = Input(shape=input_shape)
x = Dense(128, activation='relu')(z)
x = Dense(64, activation='relu')(x)
x = Reshape((1, 1, 1, 128))(x)
generator = Model(z, x)
generator.summary()

# 判别器模型
input_shape = (1, 1, 1, 128)
x = Input(shape=input_shape)
x = Dense(128, activation='relu')(x)
x = Flatten()(x)
y = Dense(1, activation='sigmoid')(x)
discriminator = Model(x, y)
discriminator.compile(loss='binary_crossentropy', optimizer='adam')
discriminator.summary()

# GAN模型
z = Input(shape=input_shape)
x = generator(z)
y = discriminator(x)
gan = Model(z, y)
gan.compile(loss='binary_crossentropy', optimizer='adam')
gan.summary()

# 训练GAN
num_epochs = 100
batch_size = 32
z_batch = np.random.normal(size=(batch_size, latent_dim))

for epoch in range(num_epochs):
    # 训练判别器
    x_batch, y_batch = generate_synthetic_samples(generator, z_batch)
    d_loss_real = discriminator.train_on_batch(x_batch, np.ones((batch_size, 1)))
    d_loss_fake = discriminator.train_on_batch(x, np.zeros((batch_size, 1)))
    d_loss = 0.5 * np.add(d_loss_real, d_loss_fake)

    # 训练生成器
    g_loss = gan.train_on_batch(z_batch, np.ones((batch_size, 1)))

    print(f"Epoch {epoch+1}/{num_epochs}, D_loss: {d_loss}, G_loss: {g_loss}")
```

在上述GAN代码实战中，我们首先定义了生成器和判别器模型，并分别编译。接着，我们定义了GAN模型，并编译。在训练过程中，我们首先训练判别器，然后训练生成器。通过这种方式，我们可以逐步生成与真实数据相似的样本，从而平衡数据集。

### 第2章：数据不平衡问题解析

#### 2.1 数据不平衡的定义与影响

数据不平衡是指数据集中不同类别的样本数量不均衡，常见于分类任务中。数据不平衡对模型性能产生显著影响，可能导致模型对某些类别的预测准确性较低。数据不平衡问题主要体现在以下几个层面：

1. **预测准确性下降**：由于数据不平衡，模型容易过度拟合多数类别的数据，导致对少数类别的预测准确性较低。这种情况称为“偏向性”问题。

2. **模型泛化能力减弱**：数据不平衡使得模型无法充分学习到少数类别的特征，影响模型的泛化能力。当模型面对新的数据时，可能无法准确预测。

3. **业务决策失效**：在金融风控、医疗诊断等场景中，数据不平衡可能导致业务决策失效。例如，在金融风控中，如果模型对欺诈行为的预测准确性较低，将可能导致金融机构损失严重。

#### 2.2 数据不平衡的分类

数据不平衡可以分为以下几种类型：

1. **类别不平衡**：不同类别的样本数量差异较大，例如，正常交易和欺诈交易的数据不平衡。

2. **值域不平衡**：不同特征的值域差异较大，例如，年龄特征的值域可能从0到100不等，而收入特征的值域可能从0到数百万不等。

3. **时间不平衡**：不同时间段的数据量差异较大，例如，电商数据在节假日和平时的时间段存在显著的不平衡。

#### 2.3 数据不平衡的原因分析

数据不平衡的原因主要包括以下几个方面：

1. **数据来源差异**：不同类别的数据来源存在差异，导致样本数量不均衡。例如，在医疗数据中，疾病样本和健康样本的数据量差异可能很大。

2. **数据采集过程**：在数据采集过程中可能存在漏采或误采，导致数据不平衡。例如，在金融风控中，可能由于技术限制或资源限制，导致欺诈行为的样本数据较少。

3. **业务需求变化**：业务需求的变化可能导致数据分布发生变化，导致数据不平衡。例如，在电商领域，节假日和促销期间的用户行为数据量可能显著增加。

### 第3章：传统数据处理方法

#### 3.1 数据采样

数据采样是一种常用的数据处理方法，通过从原始数据集中选取一部分样本作为训练数据集，以解决数据不平衡问题。常用的采样方法包括简单随机采样、系统采样和分层采样等。

1. **简单随机采样**：从原始数据集中随机选取一定数量的样本，保证每个样本被选中的概率相等。这种方法简单有效，但在样本数量较少时，可能导致采样误差较大。

2. **系统采样**：将数据集分成若干个固定大小的子集，从每个子集中随机选取一个样本。这种方法适用于数据量较大且数据有规律的情况。

3. **分层采样**：将数据集按照某种特征分层，从每个层中随机选取一定数量的样本。这种方法适用于类别不平衡较为明显的情况，可以保证每个类别都有足够的样本用于训练。

#### 3.2 特征工程

特征工程是指通过对原始数据进行处理和转换，提取出有助于模型训练的特征。特征工程包括特征选择、特征变换和特征构造等。

1. **特征选择**：从原始数据中选取对模型性能有显著影响的特征，去除冗余和噪声特征。常用的特征选择方法包括卡方检验、互信息、基于模型的特征选择等。

2. **特征变换**：对原始数据进行变换，提高数据的质量和模型的性能。常用的特征变换方法包括归一化、标准化、离散化和二值化等。

3. **特征构造**：通过组合原始特征，构造新的特征。这种方法可以增加数据的信息量和模型的解释性。

#### 3.3 模型选择与调参

选择合适的模型并调整模型参数是解决数据不平衡问题的重要手段。常用的模型包括逻辑回归、决策树、随机森林和梯度提升树等。

1. **模型选择**：根据问题的性质和数据特点，选择合适的模型。逻辑回归适用于线性可分的问题，决策树和随机森林适用于非线性问题，梯度提升树适用于大规模数据和高维数据。

2. **参数调参**：通过调整模型的参数，优化模型性能。常用的调参方法包括网格搜索、随机搜索和贝叶斯优化等。

### 第4章：平衡数据集的先进技术

#### 4.1 集成学习

集成学习是一种通过组合多个基学习器以提高模型性能的方法。集成学习包括Bagging、Boosting和Stacking等策略，每种策略都有其独特的优势和适用场景。

1. **Bagging（袋装法）**：Bagging通过从原始数据集多次随机抽样，生成多个子数据集，然后在每个子数据集上训练独立的基学习器，最后将多个基学习器的预测结果进行平均或投票，得到最终的预测结果。Bagging可以降低模型的方差，提高模型的泛化能力。

2. **Boosting（提升法）**：Boosting通过将多个基学习器按照权重进行组合，每个基学习器专注于纠正前一个基学习器的错误。Boosting方法包括Adaboost和XGBoost等，它们通过调整基学习器的权重，优化模型对少数类别的预测性能。

3. **Stacking（堆叠法）**：Stacking通过将多个模型进行堆叠，将低层次的模型作为基础模型，将高层次的模型作为堆叠模型。高层次的模型使用低层次模型的预测结果作为输入，从而提高模型的复杂度和预测性能。

#### 4.2 过采样

过采样是指增加少数类别的样本数量，以平衡数据集。过采样包括复制采样、SMOTE和ADASYN等方法，每种方法都有其特定的实现方式和适用场景。

1. **复制采样**：复制采样是最简单的一种过采样方法，通过直接复制少数类别的样本，增加其数量。这种方法容易实现，但可能导致数据集的噪声增加，影响模型性能。

2. **SMOTE（合成少数类过采样技术）**：SMOTE通过生成合成样本来平衡数据集。SMOTE基于K最近邻算法，对于每个少数类别的样本，找到其K个最近邻样本，然后在样本之间生成新的合成样本。这种方法可以有效地增加少数类别的样本数量，同时保持数据集的分布。

3. **ADASYN（自适应合成样本过采样）**：ADASYN是一种基于密度差异的过采样方法。ADASYN通过分析样本的密度差异，优先生成那些在少数类别中密度较低的合成样本。这种方法可以更有效地平衡数据集，提高模型的预测性能。

#### 4.3 前采样

前采样是指只对少数类别的样本进行训练，以减少模型对多数类别的依赖。前采样包括删除采样和随机前采样等方法。

1. **删除采样**：删除采样通过删除多数类别的样本，减少数据集中多数类别的样本数量，以达到平衡数据集的目的。这种方法简单有效，但可能导致数据丢失和模型性能下降。

2. **随机前采样**：随机前采样通过随机选择少数类别的样本进行训练，减少模型对多数类别的依赖。这种方法适用于数据量较大的场景，可以有效提高模型的泛化能力。

#### 4.4 生成对抗网络（GAN）

生成对抗网络（GAN）是一种生成模型，通过生成器和判别器的对抗性训练，生成与真实数据相似的样本，从而平衡数据集。GAN的核心思想是生成器和判别器的博弈过程：

1. **生成器（Generator）**：生成器的目标是生成与真实数据相似的样本。生成器从随机噪声中生成数据，并通过不断优化，使其生成的数据越来越接近真实数据。

2. **判别器（Discriminator）**：判别器的目标是区分真实数据和生成数据。判别器通过训练，提高对真实数据和生成数据的辨别能力。

3. **对抗性训练**：在训练过程中，生成器和判别器相互对抗。生成器试图生成更真实的数据，而判别器则试图识别生成数据。通过这种对抗性训练，生成器和判别器共同优化，最终生成器能够生成高质量的数据，判别器能够准确区分真实数据和生成数据。

通过集成学习、过采样、前采样和生成对抗网络等先进技术，可以有效平衡数据集，提高模型的预测性能和泛化能力。这些方法在不同场景和数据集上具有不同的效果和适用性，需要根据具体问题进行选择和调整。

#### D.3 生成对抗网络（GAN）代码实战与解析

```python
import tensorflow as tf
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense, Reshape, Flatten
import numpy as np

# 生成器模型
latent_dim = 100
input_shape = (latent_dim,)
z = Input(shape=input_shape)
x = Dense(128, activation='relu')(z)
x = Dense(64, activation='relu')(x)
x = Reshape((1, 1, 1, 128))(x)
generator = Model(z, x)
generator.summary()

# 判别器模型
input_shape = (1, 1, 1, 128)
x = Input(shape=input_shape)
x = Dense(128, activation='relu')(x)
x = Flatten()(x)
y = Dense(1, activation='sigmoid')(x)
discriminator = Model(x, y)
discriminator.compile(loss='binary_crossentropy', optimizer='adam')
discriminator.summary()

# GAN模型
z = Input(shape=input_shape)
x = generator(z)
y = discriminator(x)
gan = Model(z, y)
gan.compile(loss='binary_crossentropy', optimizer='adam')
gan.summary()

# 训练GAN
num_epochs = 100
batch_size = 32
z_batch = np.random.normal(size=(batch_size, latent_dim))

for epoch in range(num_epochs):
    # 训练判别器
    x_batch, y_batch = generate_synthetic_samples(generator, z_batch)
    d_loss_real = discriminator.train_on_batch(x_batch, np.ones((batch_size, 1)))
    d_loss_fake = discriminator.train_on_batch(x, np.zeros((batch_size, 1)))
    d_loss = 0.5 * np.add(d_loss_real, d_loss_fake)

    # 训练生成器
    g_loss = gan.train_on_batch(z_batch, np.ones((batch_size, 1)))

    print(f"Epoch {epoch+1}/{num_epochs}, D_loss: {d_loss}, G_loss: {g_loss}")
```

### 第2章：数据不平衡问题解析

#### 2.1 数据不平衡的定义与影响

数据不平衡是指数据集中不同类别的样本数量不均衡，常见于分类任务中。数据不平衡对模型性能产生显著影响，可能导致模型对某些类别的预测准确性较低。数据不平衡问题主要体现在以下几个层面：

1. **预测准确性下降**：由于数据不平衡，模型容易过度拟合多数类别的数据，导致对少数类别的预测准确性较低。这种情况称为“偏向性”问题。

2. **模型泛化能力减弱**：数据不平衡使得模型无法充分学习到少数类别的特征，影响模型的泛化能力。当模型面对新的数据时，可能无法准确预测。

3. **业务决策失效**：在金融风控、医疗诊断等场景中，数据不平衡可能导致业务决策失效。例如，在金融风控中，如果模型对欺诈行为的预测准确性较低，将可能导致金融机构损失严重。

#### 2.2 数据不平衡的分类

数据不平衡可以分为以下几种类型：

1. **类别不平衡**：不同类别的样本数量差异较大，例如，正常交易和欺诈交易的数据不平衡。

2. **值域不平衡**：不同特征的值域差异较大，例如，年龄特征的值域可能从0到100不等，而收入特征的值域可能从0到数百万不等。

3. **时间不平衡**：不同时间段的数据量差异较大，例如，电商数据在节假日和平时的时间段存在显著的不平衡。

#### 2.3 数据不平衡的原因分析

数据不平衡的原因主要包括以下几个方面：

1. **数据来源差异**：不同类别的数据来源存在差异，导致样本数量不均衡。例如，在医疗数据中，疾病样本和健康样本的数据量差异可能很大。

2. **数据采集过程**：在数据采集过程中可能存在漏采或误采，导致数据不平衡。例如，在金融风控中，可能由于技术限制或资源限制，导致欺诈行为的样本数据较少。

3. **业务需求变化**：业务需求的变化可能导致数据分布发生变化，导致数据不平衡。例如，在电商领域，节假日和促销期间的用户行为数据量可能显著增加。

### 第3章：传统数据处理方法

#### 3.1 数据采样

数据采样是一种常用的数据处理方法，通过从原始数据集中选取一部分样本作为训练数据集，以解决数据不平衡问题。常用的采样方法包括简单随机采样、系统采样和分层采样等。

1. **简单随机采样**：从原始数据集中随机选取一定数量的样本，保证每个样本被选中的概率相等。这种方法简单有效，但在样本数量较少时，可能导致采样误差较大。

2. **系统采样**：将数据集分成若干个固定大小的子集，从每个子集中随机选取一个样本。这种方法适用于数据量较大且数据有规律的情况。

3. **分层采样**：将数据集按照某种特征分层，从每个层中随机选取一定数量的样本。这种方法适用于类别不平衡较为明显的情况，可以保证每个类别都有足够的样本用于训练。

#### 3.2 特征工程

特征工程是指通过对原始数据进行处理和转换，提取出有助于模型训练的特征。特征工程包括特征选择、特征变换和特征构造等。

1. **特征选择**：从原始数据中选取对模型性能有显著影响的特征，去除冗余和噪声特征。常用的特征选择方法包括卡方检验、互信息、基于模型的特征选择等。

2. **特征变换**：对原始数据进行变换，提高数据的质量和模型的性能。常用的特征变换方法包括归一化、标准化、离散化和二值化等。

3. **特征构造**：通过组合原始特征，构造新的特征。这种方法可以增加数据的信息量和模型的解释性。

#### 3.3 模型选择与调参

选择合适的模型并调整模型参数是解决数据不平衡问题的重要手段。常用的模型包括逻辑回归、决策树、随机森林和梯度提升树等。

1. **模型选择**：根据问题的性质和数据特点，选择合适的模型。逻辑回归适用于线性可分的问题，决策树和随机森林适用于非线性问题，梯度提升树适用于大规模数据和高维数据。

2. **参数调参**：通过调整模型的参数，优化模型性能。常用的调参方法包括网格搜索、随机搜索和贝叶斯优化等。

通过上述传统数据处理方法，可以缓解数据不平衡问题，提高模型的性能和可靠性。然而，随着数据规模的扩大和数据复杂性的增加，传统方法可能面临挑战，需要更先进的技术手段来应对。接下来，我们将介绍一些先进的平衡数据集技术，包括集成学习、过采样、前采样和生成对抗网络等。

### 第4章：平衡数据集的先进技术

#### 4.1 集成学习

集成学习是一种通过组合多个基学习器以提高模型性能的方法。集成学习包括Bagging、Boosting和Stacking等策略，每种策略都有其独特的优势和适用场景。

1. **Bagging（袋装法）**：Bagging通过从原始数据集多次随机抽样，生成多个子数据集，然后在每个子数据集上训练独立的基学习器，最后将多个基学习器的预测结果进行平均或投票，得到最终的预测结果。Bagging可以降低模型的方差，提高模型的泛化能力。

2. **Boosting（提升法）**：Boosting通过将多个基学习器按照权重进行组合，每个基学习器专注于纠正前一个基学习器的错误。Boosting方法包括Adaboost和XGBoost等，它们通过调整基学习器的权重，优化模型对少数类别的预测性能。

3. **Stacking（堆叠法）**：Stacking通过将多个模型进行堆叠，将低层次的模型作为基础模型，将高层次的模型作为堆叠模型。高层次的模型使用低层次模型的预测结果作为输入，从而提高模型的复杂度和预测性能。

#### 4.2 过采样

过采样是指增加少数类别的样本数量，以平衡数据集。过采样包括复制采样、SMOTE和ADASYN等方法，每种方法都有其特定的实现方式和适用场景。

1. **复制采样**：复制采样是最简单的一种过采样方法，通过直接复制少数类别的样本，增加其数量。这种方法容易实现，但可能导致数据集的噪声增加，影响模型性能。

2. **SMOTE（合成少数类过采样技术）**：SMOTE通过生成合成样本来平衡数据集。SMOTE基于K最近邻算法，对于每个少数类别的样本，找到其K个最近邻样本，然后在样本之间生成新的合成样本。这种方法可以有效地增加少数类别的样本数量，同时保持数据集的分布。

3. **ADASYN（自适应合成样本过采样）**：ADASYN是一种基于密度差异的过采样方法。ADASYN通过分析样本的密度差异，优先生成那些在少数类别中密度较低的合成样本。这种方法可以更有效地平衡数据集，提高模型的预测性能。

#### 4.3 前采样

前采样是指只对少数类别的样本进行训练，以减少模型对多数类别的依赖。前采样包括删除采样和随机前采样等方法。

1. **删除采样**：删除采样通过删除多数类别的样本，减少数据集中多数类别的样本数量，以达到平衡数据集的目的。这种方法简单有效，但可能导致数据丢失和模型性能下降。

2. **随机前采样**：随机前采样通过随机选择少数类别的样本进行训练，减少模型对多数类别的依赖。这种方法适用于数据量较大的场景，可以有效提高模型的泛化能力。

#### 4.4 生成对抗网络（GAN）

生成对抗网络（GAN）是一种生成模型，通过生成器和判别器的对抗性训练，生成与真实数据相似的样本，从而平衡数据集。GAN的核心思想是生成器和判别器的博弈过程：

1. **生成器（Generator）**：生成器的目标是生成与真实数据相似的样本。生成器从随机噪声中生成数据，并通过不断优化，使其生成的数据越来越接近真实数据。

2. **判别器（Discriminator）**：判别器的目标是区分真实数据和生成数据。判别器通过训练，提高对真实数据和生成数据的辨别能力。

3. **对抗性训练**：在训练过程中，生成器和判别器相互对抗。生成器试图生成更真实的数据，而判别器则试图识别生成数据。通过这种对抗性训练，生成器和判别器共同优化，最终生成器能够生成高质量的数据，判别器能够准确区分真实数据和生成数据。

通过集成学习、过采样、前采样和生成对抗网络等先进技术，可以有效平衡数据集，提高模型的预测性能和泛化能力。这些方法在不同场景和数据集上具有不同的效果和适用性，需要根据具体问题进行选择和调整。

#### C.3 生成对抗网络（GAN）的数学模型与伪代码

生成对抗网络（GAN）由生成器和判别器组成。生成器的目标是生成与真实数据相似的样本，判别器的目标是区分真实数据和生成数据。

**生成器数学模型：**

$$
G(z) = \Phi_G(\mathbf{z})
$$

**判别器数学模型：**

$$
D(x) = \sigma(W_Dx + b_D)
$$

**生成对抗网络训练过程伪代码：**

```python
def train_GAN(G, D, real_data, batch_size):

        x = real_data(batch_size)

        D_loss_real = compute_loss(D, x)
        D_loss_fake = compute_loss(D, G(z))
        D_loss = 0.5 * (D_loss_real + D_loss_fake)
        update_D(D, D_loss)
        
        # 训练生成器
        G_loss = compute_loss(D, G(z))
        update_G(G, G_loss)
```

#### D.3 生成对抗网络（GAN）代码实战与解析

```python
import tensorflow as tf
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense, Reshape, Flatten
import numpy as np

# 生成器模型
latent_dim = 100
input_shape = (latent_dim,)
z = Input(shape=input_shape)
x = Dense(128, activation='relu')(z)
x = Dense(64, activation='relu')(x)
x = Reshape((1, 1, 1, 128))(x)
generator = Model(z, x)
generator.summary()

# 判别器模型
input_shape = (1, 1, 1, 128)
x = Input(shape=input_shape)
x = Dense(128, activation='relu')(x)
x = Flatten()(x)
y = Dense(1, activation='sigmoid')(x)
discriminator = Model(x, y)
discriminator.compile(loss='binary_crossentropy', optimizer='adam')
discriminator.summary()

# GAN模型
z = Input(shape=input_shape)
x = generator(z)
y = discriminator(x)
gan = Model(z, y)
gan.compile(loss='binary_crossentropy', optimizer='adam')
gan.summary()

# 训练GAN
num_epochs = 100
batch_size = 32
z_batch = np.random.normal(size=(batch_size, latent_dim))

for epoch in range(num_epochs):
    # 训练判别器
    x_batch, y_batch = generate_synthetic_samples(generator, z_batch)
    d_loss_real = discriminator.train_on_batch(x_batch, np.ones((batch_size, 1)))
    d_loss_fake = discriminator.train_on_batch(x, np.zeros((batch_size, 1)))
    d_loss = 0.5 * np.add(d_loss_real, d_loss_fake)

    # 训练生成器
    g_loss = gan.train_on_batch(z_batch, np.ones((batch_size, 1)))

    print(f"Epoch {epoch+1}/{num_epochs}, D_loss: {d_loss}, G_loss: {g_loss}")
```

### 附录C：算法与数学模型

在解决数据不平衡问题时，理解相关的算法和数学模型非常重要。以下是一些常用的算法和数学模型及其简要说明：

#### C.1 采样技术

**1. 简单随机采样**：
- 原理：随机从数据集中选取样本，每个样本被选中的概率相等。
- 数学模型：$$ X_i \sim \text{Random}(D) $$，其中 $X_i$ 表示第 $i$ 个采样样本，$D$ 表示数据集。

**2. 系统采样**：
- 原理：将数据集分成若干个子集，从每个子集中随机选取一个样本。
- 数学模型：$$ X_i = D[j] $$，其中 $D[j]$ 表示第 $j$ 个子集中的任意一个样本，$j$ 为随机索引。

**3. 分层采样**：
- 原理：将数据集按照某个特征分层，然后从每个层中随机选取一定数量的样本。
- 数学模型：$$ X_i = D[l] \text{，其中 } l \sim \text{Random}(\text{Categories}) $$，$D[l]$ 表示第 $l$ 层中的任意一个样本，$l$ 为随机层索引。

#### C.2 过采样技术

**1. SMOTE（合成少数类过采样技术）**：
- 原理：基于 K 最近邻算法，对于每个少数类别的样本，生成合成样本。
- 数学模型：
  $$ 
  \text{For each minority class sample } x: \\
  \text{Select K nearest neighbors } \{y_1, y_2, ..., y_K\} \\
  \text{Generate synthetic sample } x_{syn} = x + \alpha (y_1 - x) + \alpha (y_2 - x) + ... + \alpha (y_K - x) \\
  \text{where } \alpha \text{ is a random value between 0 and 1}
  $$

**2. ADASYN（自适应合成样本过采样）**：
- 原理：基于样本密度的差异，优先生成那些在少数类别中密度较低的合成样本。
- 数学模型：
  $$ 
  \text{For each minority class sample } x: \\
  \text{Calculate the density of } x \\
  \text{If the density is low, generate multiple synthetic samples } x_{syn} \\
  \text{Else, do not generate synthetic samples}
  $$

#### C.3 前采样技术

**1. 删除采样**：
- 原理：删除多数类别的样本，以减少数据集中的多数类别样本数量。
- 数学模型：
  $$ 
  \text{For each majority class sample } x: \\
  \text{If the number of samples in the minority class is greater than the majority class, delete } x \\
  \text{Else, keep } x
  $$

**2. 随机前采样**：
- 原理：随机选择多数类别的样本进行训练，以减少模型对多数类别的依赖。
- 数学模型：
  $$ 
  \text{For each majority class sample } x: \\
  \text{With probability } p, \text{include } x \text{ in the training set} \\
  \text{With probability } 1 - p, \text{exclude } x \text{ from the training set}
  $$
