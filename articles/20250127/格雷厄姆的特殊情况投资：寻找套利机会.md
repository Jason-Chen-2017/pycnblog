## 附录：Python源代码示例

以下是一个简单的Python源代码示例，用于计算一家公司的估值：

```python
import pandas as pd

# 假设我们有一家制药公司的财务数据
financial_data = {
    '营业收入': [100000, 150000, 200000],
    '净利润': [20000, 30000, 40000],
    '市盈率': [10, 12, 15]
}

# 创建DataFrame
df = pd.DataFrame(financial_data)

# 使用折现现金流模型进行估值
discount_rate = 0.1
predicted_future_value = df['净利润'].iloc[-1] / (1 + discount_rate)
current_value = predicted_future_value / (1 + discount_rate)**2

print(f"公司的当前估值：{current_value:.2f}")
```
