**3.2 Python源代码与算法解释**

```python
def graham_value(S, r, g):
    """
    根据格雷厄姆的保守估值方法计算股票的内在价值。

    :param S: 当前市价
    :param r: 永久性增长率
    :param g: 永久性增长率的折现率
    :return: 股票的内在价值
    """
    return S * (r / (g - r))

current_price = 50
growth_rate = 0.05
discount_rate = 0.1

graham_val = graham_value(current_price, growth_rate, discount_rate)
print(f"格雷厄姆估值方法得到的股票内在价值为：{graham_val}")
```

**3.3 算法原理的数学模型与公式**

格雷厄姆估值法的数学模型如下：

$$
V = S \times \frac{r}{g - r}
$$

其中，\(V\) 是股票的内在价值，\(S\) 是当前市价，\(r\) 是永久性增长率，\(g\) 是永久性增长率的折现率。

**3.4 举例说明**

假设一家公司的当前市价为50美元，永久性增长率为5%，永久性增长率的折现率为10%。根据格雷厄姆估值法，该股票的内在价值为：

$$
V = 50 \times \frac{0.05}{0.10 - 0.05} = 50 \times \frac{0.05}{0.05} = 50 \times 1 = 50
$$

这意味着，在负利率环境下，该股票的内在价值为50美元。
