### 第2章 衍生品基础知识

#### 2.1 衍生品的定义

衍生品是一种金融合约，其价值依赖于一个或多个基本资产。基本资产可以是股票、债券、货币、商品等。衍生品的主要类型包括以下几种：

- 期权（Options）：赋予持有人在未来某个时间以特定价格购买或出售基本资产的权利。
- 期货（Futures）：在未来某个时间以约定价格买卖某种商品或金融工具的合约。
- 互换（Swaps）：两个交易对手方之间交换现金流流的合约。
- 远期合约（Forward Contracts）：在未来的某一特定时间以事先约定的价格买卖资产的合约。

#### 2.2 主要衍生品类型

衍生品根据其结构、交易机制和风险特性可以分为多种类型：

- 等待型衍生品：如看涨期权、看跌期权，其收益与基本资产价格变动方向有关。
- 等量型衍生品：如期货、互换，其收益与基本资产价格变动幅度有关。
- 风险管理型衍生品：如信用违约互换（CDS），用于转移信用风险。

#### 2.3 衍生品的定价原则

衍生品的定价基于基本资产的当前价格、到期期限、无风险利率、波动率等因素。主要定价原则包括：

- 期权的定价：基于Black-Scholes模型或二叉树模型。
- 期货的定价：基于供需关系和成本加成。
- 互换的定价：基于市场利率和信用风险。

### 第3章 定价模型基本理论

#### 3.1 黑色Scholes模型

Black-Scholes模型是期权定价理论的基础，由Fischer Black和Myron Scholes于1973年提出。该模型假设：

- 基本资产价格遵循几何布朗运动。
- 期权交易者能够以无风险利率借入和贷出资金。
- 不存在交易成本和税收。
- 市场不存在套利机会。

Black-Scholes模型的数学公式为：

$$
C(S,t) = S_0N(d_1) - Ke^{-r(T-t)}N(d_2)
$$

其中，$C(S,t)$是欧式看涨期权的价格，$S_0$是当前股票价格，$K$是执行价格，$r$是无风险利率，$T-t$是期权剩余期限，$N(\cdot)$是标准正态分布的累积分布函数。

#### 3.2 二叉树模型

二叉树模型是一种离散时间模型，用于期权等金融衍生品的定价。该模型假设：

- 基本资产价格在每个时间点上只可能上涨或下跌两种情况。
- 起始价格和上涨/下跌的概率已知。

二叉树模型的算法流程包括：

1. 初始化股票价格和概率。
2. 递归计算每个时间点上的股票价格。
3. 根据到期时的股票价格计算期权价值。
4. 使用回溯法计算期权当前价格。

下面是二叉树模型的Python实现示例：

```python
import numpy as np

def binomial_tree_price(S0, u, d, r, T):
    """
    二叉树模型期权定价。

    :param S0: 起始股票价格
    :param u: 上涨概率
    :param d: 下跌概率
    :param r: 无风险利率
    :param T: 期权剩余期限
    :return: 期权价格
    """
    # 计算上涨和下跌的股票价格
    Su = S0 * u
    Sd = S0 * d

    # 计算每个时间点的期权价格
    v = np.zeros((T+1, 2))
    v[0, 0] = 0
    v[0, 1] = max(0, Su - K)
    v[-1, 0] = 0
    v[-1, 1] = max(0, Sd - K)

    for t in range(T-1, -1, -1):
        v[t, 0] = (u * v[t+1, 0] + d * v[t+1, 1]) / (1 + r)
        v[t, 1] = (u * v[t+1, 1] + d * v[t+1, 0]) / (1 + r)

    return v[0, 1]

# 示例参数
S0 = 100  # 起始股票价格
u = 1.1   # 上涨概率
d = 0.9   # 下跌概率
K = 100   # 执行价格
r = 0.05  # 无风险利率
T = 1     # 期权剩余期限

# 计算期权价格
option_price = binomial_tree_price(S0, u, d, r, T)
print("期权价格：", option_price)
```

### 第4章 常见定价模型比较

在金融衍生品定价中，常用的模型包括Black-Scholes模型、二叉树模型、蒙特卡罗模拟等。每种模型都有其独特的原理、适用场景和优缺点。

#### 4.1 Black-Scholes模型

- **原理**：基于假设股票价格遵循几何布朗运动，期权价格可以通过数学公式计算。
- **适用场景**：适用于欧式期权定价，特别是无股息股票。
- **优点**：计算简单，适用于大规模计算。
- **缺点**：假设过于简化，不能准确反映现实市场。

#### 4.2 二叉树模型

- **原理**：通过构建二叉树来模拟股票价格的运动，期权价格通过回溯计算得出。
- **适用场景**：适用于美式期权和欧式期权。
- **优点**：模拟过程直观，可以灵活调整参数。
- **缺点**：计算复杂度较高，不能处理大规模数据。

#### 4.3 蒙特卡罗模拟

- **原理**：通过大量随机模拟来估计期权价格，蒙特卡罗模拟不依赖于特定模型。
- **适用场景**：适用于复杂期权和结构化衍生品定价。
- **优点**：灵活性高，适用于各种市场情况。
- **缺点**：计算量大，计算时间较长。

#### 模型实现

使用Python实现蒙特卡罗模拟，代码如下：

```python
import numpy as np

def montecarlo_simulation(S0, K, r, sigma, T, n_simulations):
    """
    蒙特卡罗模拟期权定价。

    :param S0: 起始股票价格
    :param K: 执行价格
    :param r: 无风险利率
    :param sigma: 波动率
    :param T: 期权剩余期限
    :param n_simulations: 模拟次数
    :return: 期权价格
    """
    # 计算模拟参数
    dt = T / n_simulations
    drift = (r - 0.5 * sigma**2) * dt
    sigma_sqrt_dt = sigma * np.sqrt(dt)

    # 进行模拟
    S = [S0]
    for _ in range(n_simulations):
        z = np.random.normal(0, 1)
        S.append(S[-1] * np.exp(drift + sigma_sqrt_dt * z))

    # 计算期权价格
    option_prices = [max(S[-1] - K, 0) for S in S]
    return np.mean(option_prices)

# 示例参数
S0 = 110  # 起始股票价格
K = 100    # 执行价格
r = 0.04   # 无风险利率
sigma = 0.2  # 波动率
T = 0.25    # 期权剩余期限
n_simulations = 10000  # 模拟次数

# 计算期权价格
option_price = montecarlo_simulation(S0, K, r, sigma, T, n_simulations)
print("期权价格：", option_price)
```

#### 3.1 Black-Scholes模型

Black-Scholes模型是期权定价理论的基础，由Fischer Black和Myron Scholes于1973年提出。该模型假设股票价格遵循几何布朗运动，并基于以下数学公式：

$$
C(S,t) = S_0N(d_1) - Ke^{-r(T-t)}N(d_2)
$$

其中，$C(S,t)$是欧式看涨期权的价格，$S_0$是当前股票价格，$K$是执行价格，$r$是无风险利率，$T-t$是期权剩余期限，$N(\cdot)$是标准正态分布的累积分布函数。

**Black-Scholes模型的假设**：

1. 股票价格遵循几何布朗运动。
2. 期权交易者能够以无风险利率借入和贷出资金。
3. 不存在交易成本和税收。
4. 市场不存在套利机会。

**数学推导**：

为了推导Black-Scholes模型，我们首先考虑股票价格的过程：

$$
dS_t = \mu S_t dt + \sigma S_t dW_t
$$

其中，$W_t$是维纳过程，$\mu$是股票收益的期望，$\sigma$是股票收益的波动率。通过Ito公式，我们可以得到期权价格的偏微分方程：

$$
\frac{\partial C}{\partial t} + \frac{1}{2} \sigma^2 S^2 \frac{\partial^2 C}{\partial S^2} + rK e^{-r(T-t)} \frac{\partial C}{\partial K} - rC = 0
$$

边界条件为：

$$
C(S_T, t) = \max(S_T - K, 0)
$$

通过求解这个偏微分方程，我们可以得到Black-Scholes模型的解析解。

**Python实现示例**：

```python
import numpy as np
import scipy.stats as si

def black_scholes(S0, K, r, T, sigma):
    d1 = (np.log(S0 / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    C = S0 * si.norm.cdf(d1) - K * np.exp(-r * T) * si.norm.cdf(d2)
    return C

# 示例参数
S0 = 100  # 股票价格
K = 100    # 执行价格
r = 0.05   # 无风险利率
T = 1      # 期权剩余期限
sigma = 0.2  # 波动率

# 计算期权价格
option_price = black_scholes(S0, K, r, T, sigma)
print("期权价格：", option_price)
```

#### 3.2 二叉树模型

二叉树模型是一种离散时间模型，通过构建二叉树来模拟股票价格的变动，从而计算期权的价值。二叉树模型的算法流程如下：

1. **初始化**：设定初始股票价格$S_0$，上涨概率$u$，下跌概率$d=1-u$，以及时间步长$\Delta t$。

2. **递归计算**：从最后一步开始，向前递归计算每个时间点的股票价格。

3. **计算期权价值**：根据到期时的股票价格，计算期权价值。

4. **回溯计算**：从最后一步开始，回溯计算每个时间点的期权价值。

**Python实现示例**：

```python
import numpy as np

def binomial_tree_price(S0, u, d, r, T):
    """
    二叉树模型期权定价。

    :param S0: 起始股票价格
    :param u: 上涨概率
    :param d: 下跌概率
    :param r: 无风险利率
    :param T: 期权剩余期限
    :return: 期权价格
    """
    # 计算上涨和下跌的股票价格
    Su = S0 * u
    Sd = S0 * d

    # 计算每个时间点的期权价格
    v = np.zeros((T+1, 2))
    v[0, 0] = 0
    v[0, 1] = max(0, Su - K)
    v[-1, 0] = 0
    v[-1, 1] = max(0, Sd - K)

    for t in range(T-1, -1, -1):
        v[t, 0] = (u * v[t+1, 0] + d * v[t+1, 1]) / (1 + r)
        v[t, 1] = (u * v[t+1, 1] + d * v[t+1, 0]) / (1 + r)

    return v[0, 1]

# 示例参数
S0 = 100  # 起始股票价格
u = 1.1   # 上涨概率
d = 0.9   # 下跌概率
K = 100   # 执行价格
r = 0.05  # 无风险利率
T = 1     # 期权剩余期限

# 计算期权价格
option_price = binomial_tree_price(S0, u, d, r, T)
print("期权价格：", option_price)
```

#### 3.3 蒙特卡罗模拟

蒙特卡罗模拟是一种基于随机模拟的期权定价方法。通过模拟大量基本资产价格路径，计算期权的期望价值。蒙特卡罗模拟的原理如下：

1. **设定初始值**：设定股票价格的起始值和概率分布，例如假设股票价格服从对数正态分布。

2. **随机模拟**：进行大量随机模拟，记录每次模拟的股票价格路径。

3. **计算期权价值**：根据每次模拟的股票价格路径，计算期权的期望价值。

4. **结果估计**：计算期权价值的平均值，作为期权价格的估计值。

**Python实现示例**：

```python
import numpy as np

def montecarlo_simulation(S0, K, r, sigma, T, n_simulations):
    """
    蒙特卡罗模拟期权定价。

    :param S0: 起始股票价格
    :param K: 执行价格
    :param r: 无风险利率
    :param sigma: 波动率
    :param T: 期权剩余期限
    :param n_simulations: 模拟次数
    :return: 期权价格
    """
    # 计算模拟参数
    dt = T / n_simulations
    drift = (r - 0.5 * sigma**2) * dt
    sigma_sqrt_dt = sigma * np.sqrt(dt)

    # 进行模拟
    S = [S0]
    for _ in range(n_simulations):
        z = np.random.normal(0, 1)
        S.append(S[-1] * np.exp(drift + sigma_sqrt_dt * z))

    # 计算期权价格
    option_prices = [max(S[-1] - K, 0) for S in S]
    return np.mean(option_prices)

# 示例参数
S0 = 100  # 起始股票价格
K = 100    # 执行价格
r = 0.04   # 无风险利率
sigma = 0.2  # 波动率
T = 0.25    # 期权剩余期限
n_simulations = 10000  # 模拟次数

# 计算期权价格
option_price = montecarlo_simulation(S0, K, r, sigma, T, n_simulations)
print("期权价格：", option_price)
```

#### 4.1 Black-Scholes模型

**原理**：Black-Scholes模型是期权定价理论的基础，由Fischer Black和Myron Scholes于1973年提出。该模型假设股票价格遵循几何布朗运动，并基于以下数学公式：

$$
C(S,t) = S_0N(d_1) - Ke^{-r(T-t)}N(d_2)
$$

**适用场景**：Black-Scholes模型适用于欧式期权定价，特别是无股息股票。它假设市场不存在套利机会，期权交易者能够以无风险利率借入和贷出资金。

**优点**：
- 计算简单，适用于大规模计算。
- 能够快速得到解析解。

**缺点**：
- 假设过于简化，不能准确反映现实市场。
- 不适用于美式期权。

#### 4.2 二叉树模型

**原理**：二叉树模型通过构建二叉树来模拟股票价格的变动，从而计算期权的价值。二叉树模型的算法流程包括：
1. 初始化股票价格和概率。
2. 递归计算每个时间点上的股票价格。
3. 根据到期时的股票价格计算期权价值。
4. 使用回溯法计算期权当前价格。

**适用场景**：二叉树模型适用于美式期权和欧式期权。

**优点**：
- 模拟过程直观，可以灵活调整参数。
- 适用于各种市场情况。

**缺点**：
- 计算复杂度较高，不能处理大规模数据。

#### 4.3 蒙特卡罗模拟

**原理**：蒙特卡罗模拟通过大量随机模拟来估计期权价格，不依赖于特定模型。其原理如下：
1. 设定股票价格的起始值和概率分布。

**适用场景**：蒙特卡罗模拟适用于复杂期权和结构化衍生品定价。

**优点**：
- 灵活性高，适用于各种市场情况。
- 不依赖于特定模型，适用于复杂期权。

**缺点**：

#### 3.1 Black-Scholes模型

Black-Scholes模型是期权定价理论的基础，由Fischer Black和Myron Scholes于1973年提出。该模型假设股票价格遵循几何布朗运动，并基于以下数学公式：

$$
C(S,t) = S_0N(d_1) - Ke^{-r(T-t)}N(d_2)
$$

其中，$C(S,t)$是欧式看涨期权的价格，$S_0$是当前股票价格，$K$是执行价格，$r$是无风险利率，$T-t$是期权剩余期限，$N(\cdot)$是标准正态分布的累积分布函数。

**Black-Scholes模型的假设**：

1. 股票价格遵循几何布朗运动。
2. 期权交易者能够以无风险利率借入和贷出资金。
3. 不存在交易成本和税收。
4. 市场不存在套利机会。

**数学推导**：

为了推导Black-Scholes模型，我们首先考虑股票价格的过程：

$$
dS_t = \mu S_t dt + \sigma S_t dW_t
$$

其中，$W_t$是维纳过程，$\mu$是股票收益的期望，$\sigma$是股票收益的波动率。通过Ito公式，我们可以得到期权价格的偏微分方程：

$$
\frac{\partial C}{\partial t} + \frac{1}{2} \sigma^2 S^2 \frac{\partial^2 C}{\partial S^2} + rK e^{-r(T-t)} \frac{\partial C}{\partial K} - rC = 0
$$

边界条件为：

$$
C(S_T, t) = \max(S_T - K, 0)
$$

通过求解这个偏微分方程，我们可以得到Black-Scholes模型的解析解。

**Python实现示例**：

```python
def black_scholes(S0, K, r, T, sigma):

    d2 = d1 - sigma * np.sqrt(T)
    C = S0 * si.norm.cdf(d1) - K * np.exp(-r * T) * si.norm.cdf(d2)
    return C
```

#### 3.2 二叉树模型

二叉树模型是一种离散时间模型，通过构建二叉树来模拟股票价格的变动，从而计算期权的价值。二叉树模型的算法流程如下：

1. **初始化**：设定初始股票价格$S_0$，上涨概率$u$，下跌概率$d=1-u$，以及时间步长$\Delta t$。

2. **递归计算**：从最后一步开始，向前递归计算每个时间点上的股票价格。

3. **计算期权价值**：根据到期时的股票价格，计算期权价值。

4. **回溯计算**：从最后一步开始，回溯计算每个时间点的期权价值。

**算法流程图**：

**Python实现示例**：

```python
import numpy as np

def binomial_tree_price(S0, u, d, r, T):
    """
    二叉树模型期权定价。

    :param S0: 起始股票价格
    :param u: 上涨概率
    :param d: 下跌概率
    :param r: 无风险利率
    :param T: 期权剩余期限
    :return: 期权价格
    """
    # 计算上涨和下跌的股票价格
    Su = S0 * u
    Sd = S0 * d

    # 计算每个时间点的期权价格
    v = np.zeros((T+1, 2))
    v[0, 0] = 0
    v[0, 1] = max(0, Su - K)
    v[-1, 0] = 0
    v[-1, 1] = max(0, Sd - K)

    for t in range(T-1, -1, -1):
        v[t, 0] = (u * v[t+1, 0] + d * v[t+1, 1]) / (1 + r)
        v[t, 1] = (u * v[t+1, 1] + d * v[t+1, 0]) / (1 + r)

    return v[0, 1]

# 示例参数
S0 = 100  # 起始股票价格
u = 1.1   # 上涨概率
d = 0.9   # 下跌概率
K = 100   # 执行价格
r = 0.05  # 无风险利率
T = 1     # 期权剩余期限

# 计算期权价格
option_price = binomial_tree_price(S0, u, d, r, T)
print("期权价格：", option_price)
```

#### 3.3 蒙特卡罗模拟

蒙特卡罗模拟是一种基于随机模拟的期权定价方法。通过模拟大量基本资产价格路径，计算期权的期望价值。蒙特卡罗模拟的原理如下：

1. **设定初始值**：设定股票价格的起始值和概率分布，例如假设股票价格服从对数正态分布。

2. **随机模拟**：进行大量随机模拟，记录每次模拟的股票价格路径。

3. **计算期权价值**：根据每次模拟的股票价格路径，计算期权的期望价值。

4. **结果估计**：计算期权价值的平均值，作为期权价格的估计值。

**Python实现示例**：

```python
import numpy as np

def montecarlo_simulation(S0, K, r, sigma, T, n_simulations):
    """
    蒙特卡罗模拟期权定价。

    :param S0: 起始股票价格
    :param K: 执行价格
    :param r: 无风险利率
    :param sigma: 波动率
    :param T: 期权剩余期限
    :param n_simulations: 模拟次数
    :return: 期权价格
    """
    # 计算模拟参数
    dt = T / n_simulations
    drift = (r - 0.5 * sigma**2) * dt
    sigma_sqrt_dt = sigma * np.sqrt(dt)

    # 进行模拟
    S = [S0]
    for _ in range(n_simulations):
        z = np.random.normal(0, 1)
        S.append(S[-1] * np.exp(drift + sigma_sqrt_dt * z))

    # 计算期权价格
    option_prices = [max(S[-1] - K, 0) for S in S]
    return np.mean(option_prices)

# 示例参数
S0 = 100  # 起始股票价格
K = 100    # 执行价格
r = 0.04   # 无风险利率
sigma = 0.2  # 波动率
T = 0.25    # 期权剩余期限
n_simulations = 10000  # 模拟次数

# 计算期权价格

print("期权价格：", option_price)
```

### 第4章 常见定价模型比较

在金融衍生品定价中，常用的模型包括Black-Scholes模型、二叉树模型、蒙特卡罗模拟等。每种模型都有其独特的原理、适用场景和优缺点。

#### 4.1 Black-Scholes模型

**原理**：Black-Scholes模型是由Fischer Black和Myron Scholes于1973年提出的期权定价模型。该模型假设股票价格遵循几何布朗运动，并基于以下数学公式：

$$
C(S,t) = S_0N(d_1) - Ke^{-r(T-t)}N(d_2)
$$

其中，$C(S,t)$是欧式看涨期权的价格，$S_0$是当前股票价格，$K$是执行价格，$r$是无风险利率，$T-t$是期权剩余期限，$N(\cdot)$是标准正态分布的累积分布函数。

**适用场景**：Black-Scholes模型适用于欧式期权定价，特别是无股息股票。该模型假设市场不存在套利机会，期权交易者能够以无风险利率借入和贷出资金。

**优点**：

- **计算简单**：Black-Scholes模型能够快速得到解析解，适用于大规模计算。
- **理论基础**：该模型是期权定价理论的基础，为后续的期权定价模型提供了理论基础。

**缺点**：

- **假设过于简化**：Black-Scholes模型假设股票价格遵循几何布朗运动，忽略了实际市场的复杂性。
- **不适用于美式期权**：美式期权具有提前行权特性，Black-Scholes模型无法准确反映这一特性。

#### 4.2 二叉树模型

**原理**：二叉树模型通过构建二叉树来模拟股票价格的变动，从而计算期权的价值。二叉树模型的算法流程包括：
1. 初始化股票价格和概率。
2. 递归计算每个时间点上的股票价格。
3. 根据到期时的股票价格计算期权价值。
4. 使用回溯法计算期权当前价格。

**适用场景**：二叉树模型适用于美式期权和欧式期权。该模型可以灵活调整参数，适用于不同市场情况。

**优点**：

- **直观易理解**：二叉树模型通过树状结构模拟股票价格变动，易于理解和实现。
- **灵活性**：二叉树模型可以调整时间步长和上涨/下跌概率，适用于不同市场环境。

**缺点**：

- **计算复杂度高**：二叉树模型需要递归计算每个时间点的期权价值，计算复杂度较高。
- **不适用于大规模数据**：对于大规模数据，二叉树模型的计算效率较低。

#### 4.3 蒙特卡罗模拟

**原理**：蒙特卡罗模拟通过大量随机模拟来估计期权价格，不依赖于特定模型。其原理如下：
1. 设定股票价格的起始值和概率分布，例如假设股票价格服从对数正态分布。
2. 进行大量随机模拟，记录每次模拟的股票价格路径。
3. 计算每次模拟的期权价值，并取其平均值作为期权的期望价值。

**适用场景**：蒙特卡罗模拟适用于复杂期权和结构化衍生品定价。该模型可以模拟各种市场情况，适用于风险管理和投资策略。

**优点**：

- **灵活性**：蒙特卡罗模拟不依赖于特定模型，可以模拟各种市场情况。
- **准确度高**：通过大量随机模拟，蒙特卡罗模拟能够得到较为准确的期权价格估计。

**缺点**：

- **计算量大**：蒙特卡罗模拟需要大量随机模拟，计算时间较长。
- **计算资源消耗大**：蒙特卡罗模拟需要大量的计算资源和内存。

#### A. 衍生品定价模型的数学推导

为了更深入地理解衍生品定价模型，以下是Black-Scholes模型的详细推导：

**假设**：
- 股票价格遵循几何布朗运动（GBM）。
- 不存在套利机会。
- 期权交易者可以以无风险利率借入和贷出资金。

**股票价格过程**：

$$
dS_t = \mu S_t dt + \sigma S_t dW_t
$$

其中：
- $S_t$：时间t的股票价格。
- $\mu$：股票收益的期望。
- $\sigma$：股票收益的波动率。
- $W_t$：维纳过程。

**期权价格过程**：

假设期权价格 $C_t$ 满足以下偏微分方程（PDE）：

$$
\frac{\partial C}{\partial t} + \frac{1}{2} \sigma^2 S^2 \frac{\partial^2 C}{\partial S^2} + rK e^{-r(T-t)} \frac{\partial C}{\partial K} - rC = 0
$$

边界条件为：

$$
C(S_T, t) = \max(S_T - K, 0)
$$

**解析解**：

通过对上述PDE进行求解，我们得到Black-Scholes模型的解析解：

$$
C(S,t) = S_0N(d_1) - Ke^{-r(T-t)}N(d_2)
$$

其中：
- $N(d)$：标准正态分布的累积分布函数。
- $d_1 = \frac{\ln(S_0/K) + (r + \frac{\sigma^2}{2})(T-t)}{\sigma \sqrt{T-t}}$。
- $d_2 = d_1 - \sigma \sqrt{T-t}$。

#### B. 衍生品定价模型的计算示例

以下是使用Python实现Black-Scholes模型的示例代码：

```python
import numpy as np
from scipy.stats import norm

def black_scholes(S0, K, r, T, sigma):
    """
    根据Black-Scholes模型计算欧式期权的价格。
    """
    d1 = (np.log(S0 / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    C = S0 * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    return C

# 示例参数
S0 = 100  # 股票价格
K = 100    # 执行价格
r = 0.05   # 无风险利率
T = 1      # 期权剩余期限（以年为单位）
sigma = 0.2  # 波动率

# 计算期权价格
option_price = black_scholes(S0, K, r, T, sigma)
print("期权价格：", option_price)
```

```python
def binomial_tree_price(S0, u, d, r, T):
```
