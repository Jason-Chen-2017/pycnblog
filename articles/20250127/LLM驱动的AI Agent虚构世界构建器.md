```markdown
## 1.3 LLM基础理论

### 1.3.1 LLM的原理与工作流程

LLM的原理基于深度学习和自然语言处理（NLP）技术。它们通过大量的文本数据进行训练，学习语言的模式和结构。LLM的核心是变压器（Transformer）架构，特别是注意力机制（Attention Mechanism），它允许模型在处理文本时关注关键信息。

#### LLM的注意力机制

$$
\text{Attention} = \frac{\exp(\text{scores})}{\sum_{i=1}^{N} \exp(\text{scores}_i)}
$$

这个公式描述了如何通过计算分数来分配注意力权重，其中 $N$ 是输入序列的长度。

### 1.3.2 常见的LLM模型及其特点

- **GPT**:
  - A language model that uses a Transformer architecture to predict the next word in a sentence.
  - Suitable for text generation and language understanding tasks.

- **BERT**:
  - A bidirectional encoder representation model that processes text in both directions.
  - Used for tasks like question answering and sentiment analysis.

- **T5**:
  - A text-to-text transformer model that can be applied to a wide range of NLP tasks.
  - Simplifies the task of training models for specific NLP tasks.
```
