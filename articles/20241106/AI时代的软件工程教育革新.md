```python
model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(filters=32, kernel_size=(3, 3), activation='relu', input_shape=(28, 28, 1)),
    tf.keras.layers.MaxPooling2D(pool_size=(2, 2)),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(units=128, activation='relu'),
    tf.keras.layers.Dense(units=10, activation='softmax')
])

# 编译模型
model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])

# 训练模型
model.fit(x_train, y_train, epochs=10, batch_size=32, validation_data=(x_val, y_val))

# 评估模型
test_loss, test_accuracy = model.evaluate(x_test, y_test)
print(f"Test accuracy: {test_accuracy}")
```

**4. 代码解读**

- **模型定义**：使用TensorFlow的Sequential模型定义了一个简单的卷积神经网络，包括卷积层（Conv2D）、池化层（MaxPooling2D）、全连接层（Dense）。
- **模型编译**：指定优化器（optimizer）、损失函数（loss）和评价指标（metrics）。
- **模型训练**：使用fit方法训练模型，输入训练数据（x_train和y_train），指定训练周期（epochs）和批次大小（batch_size）。
- **模型评估**：使用evaluate方法评估模型在测试数据上的表现，输出测试准确率（test_accuracy）。

**5. 应用解读**

通过上述代码，学生可以学习到以下关键知识：

- **深度学习框架的使用**：如何定义、编译和训练深度学习模型。
- **卷积神经网络的工作原理**：卷积层和池化层的作用，以及如何使用全连接层进行分类。
- **模型评估的方法**：如何使用损失函数和准确率评估模型性能。
