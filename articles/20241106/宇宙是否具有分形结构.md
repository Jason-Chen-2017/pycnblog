#### 1.2 分形理论概述

分形理论是20世纪中期发展起来的一门数学分支，由法国数学家曼德尔布罗特（Benoit Mandelbrot）提出。分形理论的核心概念是“自相似性”和“无限细节”，即一个分形结构在任何尺度上都具有相似的结构特征。

分形的基本特征包括：

1. **自相似性**：分形结构在不同尺度上具有相似性，即大尺度上的结构在小尺度上也能找到相似的副本。这种自相似性使得分形结构具有无穷的层次和细节。

2. **无限细节**：分形结构在任何尺度上都有无穷多的细节，无法通过简单的几何形状来描述。这使得分形结构在几何上具有高度复杂性和不规则性。

3. **分数维数**：分形的维数不是整数，而是分数。例如，海岸线的分形维数通常在1.25到1.3之间，这意味着海岸线在几何上既不是一条直线，也不是一个平面。

分形理论在自然界的广泛存在和众多应用中得到了验证。例如，在自然界中，海岸线、云彩、树木、血管网络等都表现出分形特征。此外，分形理论在物理学、经济学、生态学、计算机科学等领域也有着重要的应用。

分形理论为研究宇宙结构提供了一种新的视角。通过分形理论，我们可以探索宇宙中存在的复杂结构，理解宇宙的起源与演化，以及宇宙可能具有的分形特征。

分形几何是分形理论的基础，涉及分形集的构造、分形维数和分形测度等基本概念。

科赫曲线是一种著名的分形集，其构造方法如下：首先，画一条线段，然后将线段等分为三部分，删除中间部分，并在每个端点向外延伸出等长的线段。重复这个过程，可以得到科赫曲线。科赫曲线具有无限长度，但其面积为有限值，这体现了分形集的无限细节和有限测度的特性。

谢尔宾斯基三角形也是一种常见的分形集，其构造方法如下：首先，画一个正三角形，然后将每个顶点与中心点连接，形成一个新的三角形。接着，删除中心三角形，重复这个过程，可以得到谢尔宾斯基三角形。谢尔宾斯基三角形具有自相似性，其边长和面积随构造次数增加而不断缩小，但数量不断增加，形成复杂的分形结构。

其次，分形维数是描述分形集复杂性的重要指标。分形维数通常不是整数，而是分数。分形维数的计算方法包括box-counting法、覆盖法等。

box-counting法是一种常用的分形维数计算方法。该方法的基本思想是将分形集划分为多个大小不同的盒子，然后计算每个盒子中包含的分形集部分的大小。通过统计不同盒子大小的分形集部分大小，可以计算出分形维数。分形维数的计算公式如下：

$$

覆盖法是另一种常用的分形维数计算方法。该方法的基本思想是用不同大小的盒子逐步覆盖分形集，然后计算所需的盒子数量。通过统计不同盒子大小的覆盖次数，可以计算出分形维数。分形维数的计算公式如下：

$$

其中，$S$表示分形集，$n$表示分形集的部分数量，$\lambda_i$表示第$i$个部分的大小，$D$表示分形维数。

function calculateDimension(data):
    # 使用box-counting法计算分形维数
    D = 0
    for ε in range(minBoxSize, maxBoxSize):
        S = countBoxes(data, ε)
        logS = log(S)
        log1_over_ε = log(1/ε)
        D += logS / log1_over_ε
    
    D = D / (maxBoxSize - minBoxSize)
    return D

function countBoxes(data, ε):
    # 计算覆盖数据所需的最小盒子大小
    count = 0
    for each box of size ε in data:
        if box contains any data:
            count += 1
    return count

import matplotlib.pyplot as plt

def preprocess_data(data):

    data = data[data != 0]  # 清洗数据
    data = data / np.max(data)  # 归一化数据
    return data

def calculate_dimension(data, min_box_size=0.1, max_box_size=1.0):
    dimensions = []
    for ε in np.linspace(min_box_size, max_box_size, 100):
        S = count_boxes(data, ε)
        logS = np.log(S)
        log1_over_ε = np.log(1 / ε)
        dimension = logS / log1_over_ε
        dimensions.append(dimension)
    return np.mean(dimensions)

def count_boxes(data, ε):
    count = 0
    data_shape = data.shape
    for i in range(0, data_shape[0] - int(ε), int(ε)):
        for j in range(0, data_shape[1] - int(ε), int(ε)):
            box = data[i:i+int(ε), j:j+int(ε)]
            if np.any(box):
                count += 1
    return count
