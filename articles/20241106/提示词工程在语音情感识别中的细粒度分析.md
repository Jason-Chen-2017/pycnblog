### Step 4: Present mathematical models and explanations

In this chapter, we will introduce the mathematical models used in fine-grained speech emotion recognition. We will use LaTeX to format the equations and provide detailed explanations with examples.

#### Mathematical Model

$$
\text{Classifier} = f(\text{Features}, \text{Model Parameters})
$$

**Explanation**: The classifier is a function that maps the extracted features and model parameters to the predicted emotion class. The specific form of the function `f` depends on the chosen machine learning model.

#### Example

$$
\text{SVM Classifier} = \text{sign}(\sum_{i=1}^{n} \alpha_i y_i \langle \phi(x_i), \phi(x) \rangle)
$$

**Explanation**: For an SVM classifier, the equation represents a linear combination of the support vectors and their corresponding labels, transformed by the kernel function `\phi`. This example demonstrates how the classifier function can be defined for a specific model.
