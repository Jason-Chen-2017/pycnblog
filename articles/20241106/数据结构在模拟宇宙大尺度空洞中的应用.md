#### 3.1 图论的基本概念

图是由节点（或称为顶点）和边组成的集合。节点表示图中的元素，边表示节点之间的关系。图可以分为无向图和有向图，也可以根据节点的度（连接到该节点的边的数量）进行分类。

- **无向图**：无向图的边没有方向，例如，如果节点A和节点B之间存在一条边，那么节点B和节点A之间也必定存在一条相同的边。

- **有向图**：有向图的边具有方向，从起点指向终点。例如，如果从节点A到节点B有一条边，则从节点B到节点A没有这条边。

图的基本性质包括连通性、路径和圈等。连通性指的是图中任意两个节点之间都存在路径，路径是指节点之间的有序序列，圈是指节点的循环序列。

##### **6.1.1 快速排序**

快速排序是一种高效的比较类排序算法，其基本思想是通过一趟排序将待排序的数据分割成独立的两部分，其中一部分的所有数据都比另一部分的所有数据要小。快速排序使用一个基准元素（通常是数组的中间元素），将数组分为两个子数组，然后递归地排序这两个子数组。

快速排序的伪代码如下：

```python
def quicksort(arr, low, high):
    if low < high:
        pi = partition(arr, low, high)
        quicksort(arr, low, pi - 1)
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```

快速排序的时间复杂度为O(n log n)，在平均情况下表现良好，但在最坏情况下（如输入数据已经有序）会退化到O(n^2)。为避免最坏情况，可以使用随机化选择基准元素，或者使用三数取中等方法。

##### **6.1.2 堆排序**

堆排序是基于堆数据结构的排序算法。堆是一种特殊的树形数据结构，可以看作是完全二叉树的一种扩展。堆分为最大堆和最小堆，其中每个父节点的值都不小于（或不超过）其子节点的值。堆排序的基本思想是通过构造最大堆（或最小堆），将堆顶元素与最后一个元素交换，然后重新调整堆结构，直至整个数组有序。

堆排序的伪代码如下：

```python

    n = len(arr)
    build_max_heap(arr)
    for i in range(n - 1, 0, -1):
        arr[i], arr[0] = arr[0], arr[i]
        max_heapify(arr, i, 0)

def build_max_heap(arr):
    n = len(arr)
    for i in range(n // 2 - 1, -1, -1):
        max_heapify(arr, n, i)

def max_heapify(arr, n, i):
    largest = i
    l = 2 * i + 1
    r = 2 * i + 2
    if l < n and arr[l] > arr[largest]:
        largest = l
    if r < n and arr[r] > arr[largest]:
        largest = r
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        max_heapify(arr, n, largest)
```

##### **6.1.3 希尔排序**

希尔排序（又称缩小增量排序）是插入排序的改进版本。基本思想是先将整个数据集合分割成若干子集合，分别进行插入排序，然后逐渐缩小子集合的间隔，重复该过程直至所有元素都顺序排列。

希尔排序的伪代码如下：

```python
def shellsort(arr):
    n = len(arr)
    gap = n // 2
    while gap > 0:
        for i in range(gap, n):
            temp = arr[i]
            j = i
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        gap //= 2
```

希尔排序的时间复杂度依赖于增量序列的选择，通常在O(n^(1.3)～O(n^(2)))之间，适用于中等规模数据的排序。
