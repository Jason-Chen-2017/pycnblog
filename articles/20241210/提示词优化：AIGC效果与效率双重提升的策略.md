    "NP": [["Det", "N"]],
    "VP": [["V", "NP"]],
    "Det": ["the", "a"],
    "N": ["book", "table", "chair"],
    "V": ["sit", "read", "write"]
}

# 定义词汇表
vocabulary = ["the", "book", "table", "chair", "sit", "read", "write"]

# 生成提示词
def generate_sentence(grammar_rules, vocabulary, sentence_length):
    sentence = []
    stack = ["S"]

    while stack:
        symbol = stack.pop()

        if symbol in vocabulary:
            sentence.append(symbol)
        elif symbol in grammar_rules:
            for rule in grammar_rules[symbol]:
                stack.extend(rule)
        else:
            print(f"Unknown symbol: {symbol}")
            return None

    return " ".join(sentence[:sentence_length])

# 示例

7. **语法规则（Syntax Rules）**：语法规则是用于指导文本生成的方法，通过分析语法结构，生成符合语法规范的文本。

8. **语义规则（Semantic Rules）**：语义规则是用于指导文本生成的方法，通过分析语义信息，生成具有特定语义的文本。

9. **常识规则（Commonsense Rules）**：常识规则是用于指导文本生成的方法，通过引入常识知识，生成符合常识的文本。

10. **评估指标（Evaluation Metrics）**：评估指标是用于衡量模型性能的指标，如准确性、创造性、可解释性等。
