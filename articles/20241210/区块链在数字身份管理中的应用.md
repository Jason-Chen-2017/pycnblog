```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract DigitalIdentity {

    // 用户身份结构体
    struct User {
        string id;
        string name;
        string email;
    }

    // 用户身份映射表
    mapping(string => User) private users;

    // 添加用户身份
    function addUser(string memory _id, string memory _name, string memory _email) public {
        require(bytes(users[_id].id).length == 0, "User already exists");
        users[_id] = User(_id, _name, _email);
    }

    // 获取用户身份
    function getUser(string memory _id) public view returns (User memory) {
        return users[_id];
    }
}
```

这个智能合约定义了一个`DigitalIdentity`合约，包含一个`User`结构体和一个用户身份的映射表。通过`addUser`函数，我们可以添加新的用户身份，而`getUser`函数则用于获取用户身份信息。

3. **users映射表**：存储所有用户身份信息，通过用户ID作为键进行访问。
4. **addUser函数**：添加新的用户身份。通过`require`语句检查用户是否已存在，确保数据的唯一性。
5. **getUser函数**：获取指定用户的身份信息。

这个智能合约提供了一个简单的接口，用于添加和查询用户身份。在实际应用中，我们可以通过前端应用程序与这个智能合约进行交互，从而实现数字身份管理。
