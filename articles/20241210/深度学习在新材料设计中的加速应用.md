### 核心概念与联系

#### 2.1 深度学习模型原理

深度学习模型由多层神经元组成，通过前向传播和反向传播进行学习。激活函数用于引入非线性变换，使模型具有学习复杂函数的能力。损失函数用于评估模型预测与真实值之间的差距，指导模型调整参数。

| 层次   | 功能                    | 激活函数        | 损失函数         |
| :----: | :--------------------- | :------------- | :-------------- |
| 输入层 | 输入特征数据            | 无             | 无              |
| 隐藏层 | 对输入特征进行变换和提取 | ReLU、Sigmoid  | 交叉熵、均方误差 |
| 输出层 | 输出预测结果            | Softmax        | 交叉熵、均方误差 |

#### 2.2 新材料属性特征对比表格

| 材料属性 | 特征值 | 说明 |
| :--: | :--: | :--: |
| 机械强度 | 高    | 提高材料的承载能力 |
| 电导率   | 低    | 减少材料的热量损失 |
| 热稳定性 | 高    | 提高材料的使用寿命 |
