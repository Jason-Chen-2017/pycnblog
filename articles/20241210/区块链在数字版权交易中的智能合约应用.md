## 背景和核心概念

### 区块链技术概述
区块链是一种分布式数据库技术，通过多个节点之间的共识机制来维护数据的一致性。区块链的主要特点是去中心化、不可篡改和透明性，这些特性使其成为数字版权交易的理想选择。

#### 核心概念术语
- **区块链（Blockchain）**：一种去中心化的分布式账本技术。
- **区块（Block）**：数据记录的基本单位，包含一系列交易信息。
- **链（Chain）**：由多个区块按照时间顺序连接而成的数据结构。
- **节点（Node）**：参与区块链网络并维护账本完整性的计算机。

### 数字版权
数字版权指的是数字内容（如音乐、电影、文学作品等）的版权保护。随着数字技术的普及，数字版权交易成为一个日益活跃的市场。然而，传统的版权管理方法存在诸多问题，如版权归属不清晰、交易流程繁琐等。

```solidity
pragma solidity ^0.8.0;

contract CopyrightRegistration {
    mapping (address => bool) public registrations;

    function registerCopyright() public {
        require(!registrations[msg.sender], "Copyright already registered");
        registrations[msg.sender] = true;
    }
}
```

2. **映射（mapping）**：用于存储版权所有者的注册状态。
3. **registerCopyright 函数**：用于注册版权。函数中使用了 `require` 语句来检查版权是否已经注册，若已注册则抛出异常。
