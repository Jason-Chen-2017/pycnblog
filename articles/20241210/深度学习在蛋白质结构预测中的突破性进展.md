#### 第6章：深度学习数学基础

**6.1 神经元模型**

神经元模型是神经网络的基本组成部分，其计算过程可以表示为：

\[ z = \sum_{i} w_i * x_i + b \]

其中，\( w_i \) 是权重，\( x_i \) 是输入特征，\( b \) 是偏置。激活函数通常用于引入非线性，常见的激活函数包括Sigmoid函数和ReLU函数：

\[ a = \sigma(z) = \frac{1}{1 + e^{-z}} \]
\[ a = \text{ReLU}(z) = \max(0, z) \]

**6.2 损失函数**

损失函数用于衡量预测值和真实值之间的差距，常见损失函数包括均方误差（MSE）和交叉熵（Cross Entropy）：

\[ \text{MSE}(y, \hat{y}) = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 \]
\[ \text{Cross Entropy}(y, \hat{y}) = -\sum_{i=1}^{n} y_i \log(\hat{y}_i) \]

**6.3 优化算法**

优化算法用于调整模型参数以最小化损失函数，常见的优化算法包括随机梯度下降（SGD）和Adam优化器：

\[ \theta_{t+1} = \theta_t - \alpha \nabla_\theta J(\theta_t) \]
\[ \theta_{t+1} = \theta_t - \frac{\alpha}{\sqrt{1 + \beta_1 t} } \nabla_\theta J(\theta_t) \]

def one_hot_encoding(sequence):
    amino_acids = 'ACDEFGHIKLMNPQRSTVWY'
    encoding_dict = {aa: np.zeros(20) for aa in amino_acids}
    for i, aa in enumerate(sequence):
        encoding_dict[aa][i] = 1
    return np.array(list(encoding_dict.values()))
