## 第1章 区块链技术基础

### 1.1 区块链的起源与发展

#### 1.1.1 区块链的概念

区块链是一种分布式数据库技术，其核心思想是去中心化。在传统的中心化系统中，所有数据都存储在一个中央服务器上，一旦服务器出现问题，整个系统都会瘫痪。而区块链技术通过将数据分散存储在多个节点上，实现了去中心化。每个节点都保存着完整的区块链数据，任何一条数据只有在所有节点上都得到确认后才能被添加到区块链上。

#### 1.1.2 区块链的工作原理

区块链的工作原理可以概括为以下步骤：

1. **交易**：当一个用户向另一个用户转账时，会生成一个交易。
2. **区块**：交易被多个节点收集起来，形成一个区块。
3. **挖矿**：节点通过计算生成一个新的区块，这个过程称为挖矿。
4. **共识机制**：其他节点验证新产生的区块是否有效，如果验证通过，新区块就会被添加到区块链上。
5. **分布式存储**：每个节点都保存着完整的区块链数据。

### 1.2 区块链的核心原理

#### 1.2.1 哈希函数

哈希函数是一种将任意长度的输入数据映射为固定长度的输出数据的函数。区块链技术中的哈希函数用于确保数据的唯一性和不可篡改性。例如，在比特币中，每个交易都会生成一个唯一的哈希值，这个哈希值就是交易的身份标识。

#### 1.2.2 加密技术

加密技术用于确保区块链数据的隐私性和安全性。在区块链中，每个交易都使用公钥和私钥进行加密。公钥可以公开，私钥只有用户本人知道。通过这种方式，用户可以确保自己的交易不会被未经授权的人看到。

#### 1.2.3 分布式账本技术

分布式账本技术是区块链技术的核心。它通过将数据分散存储在多个节点上，实现了去中心化。每个节点都保存着完整的区块链数据，确保了数据的可靠性和安全性。

3. **不可篡改性**：NFTs的所有权和转移都是不可篡改的，确保了数字艺术品的真实性和合法性。

def create_sell_order(art_id, price):
    # 构建交易数据
    tx_data = contract.functions.createSellOrder(art_id, price).buildTransaction({
        'chainId': 1,
        'gas': 2000000,
        'gasPrice': w3.toWei('50', 'gwei'),
        'nonce': w3.eth.getTransactionCount(contract_address)
    })
    
    # 签名交易
    signed_tx = w3.eth.account.sign_transaction(tx_data, private_key='your_private_key')

    receipt = w3.eth.waitForTransactionReceipt(tx_hash)
