### 3.3 Python代码示例

下面是一个简单的Python代码示例，展示了如何使用ChatGPT生成文本并进行验证：

```python
import openai

# 设置API密钥
openai.api_key = "your-api-key"

# 定义输入文本
input_text = "根据语言学理论，名词通常有单数和复数形式。"

# 调用ChatGPT API生成文本
response = openai.Completion.create(
  engine="text-davinci-003",
  prompt=input_text,
  max_tokens=50
)

# 输出生成的文本
print(response.choices[0].text.strip())
```

openai.api_key = "your-api-key"

# 获取文本数据

response = requests.get(url)
text_data = response.text

# 解析文本数据

text_list = [tag.text for tag in soup.find_all("p")]

# 文本生成
for text in text_list:

    response = openai.Completion.create(
      engine="text-davinci-003",

      max_tokens=50
    )
