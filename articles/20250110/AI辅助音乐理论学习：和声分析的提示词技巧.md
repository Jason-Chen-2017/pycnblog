## Core Concepts in Harmony Analysis (Chapters 4-5)

### Chapter 4: Fundamental Concepts of Harmony

#### 4.1 Harmony in Music Theory

Harmony in music theory refers to the combination of notes that produce a pleasing sound when played together. It is an essential aspect of music, allowing composers and musicians to create complex and expressive compositions. Harmony is based on the relationship between different notes and their frequencies.

#### 4.2 Triadic Harmony

Triadic harmony is a fundamental type of harmony in Western music theory. It is based on three notes, called a triad, which form the basis of most chords. Triads can be classified into four types: major, minor, augmented, and diminished. Each type of triad has a unique sound and character.

#### 4.3 Seventh Chords

Seventh chords are a more advanced type of harmony that adds a seventh note to a triad. This additional note creates a richer and more complex sound. Seventh chords can be classified into three types: major seventh, minor seventh, and dominant seventh.

#### 4.4 Advanced Harmony Concepts

Beyond triadic and seventh chords, there are many advanced harmony concepts and techniques, including:

- **Chord Inversions**: Reordering the notes of a chord to create different sounds.
- **Chord Extensions**: Adding additional notes to a chord to create richer and more complex harmonies.
- **Chromatic Harmony**: Using non-harmonic tones, such as accidentals, to create unique and expressive harmonies.

### Chapter 5: Techniques for Generating Harmonies Using AI

#### 5.1 Overview of Prompt Techniques

Prompt techniques are methods for generating harmonies using AI. These techniques involve providing AI systems with input data, such as musical compositions or chord progressions, and asking the AI to generate new harmonies based on that input.

#### 5.2 Data-Driven Techniques

Data-driven techniques use large datasets of musical compositions to train machine learning models. These models can then be used to generate new harmonies by analyzing and learning from the data. Some common data-driven techniques include:

- **Pattern Recognition**: Identifying and replicating common harmonic patterns found in musical compositions.
- **Chord Progression Prediction**: Predicting the next chord in a chord progression based on previous chords.

#### 5.3 Generative Techniques

Generative techniques involve generating new harmonies from scratch, without relying on existing musical compositions. These techniques use machine learning models to generate harmonies based on random or semi-random input data. Some common generative techniques include:

- **Markov Chains**: A probabilistic model that predicts the next event based on the current state.
- **Generative Adversarial Networks (GANs)**: A type of neural network that learns to generate new harmonies by competing against a discriminator network.

#### 项目简介

该项目使用 Python 和 TensorFlow 库，构建一个简单的和谐分析系统。该系统可以接受用户输入的音乐文件，分析其和弦结构，并生成新的和弦序列。

#### 系统核心实现

以下是该项目的主要实现代码：

```python
import tensorflow as tf
import librosa
import numpy as np

# 加载音频文件
audio_file = 'path/to/audio/file.wav'
y, sr = librosa.load(audio_file)

# 提取音频特征
mfccs = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)

# 初始化卷积神经网络模型
model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(filters=64, kernel_size=(3, 3), activation='relu', input_shape=(None, 13, 1)),
    tf.keras.layers.MaxPooling2D(pool_size=(2, 2)),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(units=128, activation='relu'),
    tf.keras.layers.Dense(units=1, activation='sigmoid')
])

# 编译模型
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

# 训练模型
model.fit(mfccs, np.ones((len(mfccs), 1)), epochs=10, batch_size=32, validation_split=0.2)

# 预测和弦
predictions = model.predict(mfccs)

# 打印预测结果
for prediction in predictions:
    print(prediction)

```

#### 代码应用解读与分析

1. **音频文件加载**：使用 `librosa.load()` 函数加载音频文件，并获取音频样本和采样率。
2. **音频特征提取**：使用 `librosa.feature.mfcc()` 函数提取梅尔频率倒谱系数（MFCCs），这是用于和谐分析的重要特征。
3. **模型构建**：使用 `tf.keras.Sequential()` 函数构建卷积神经网络模型，包括卷积层、池化层、全连接层等。
4. **模型编译**：使用 `model.compile()` 函数编译模型，指定优化器和损失函数。
5. **模型训练**：使用 `model.fit()` 函数训练模型，使用提取的特征和标签数据进行训练。
6. **预测和弦**：使用 `model.predict()` 函数对新的音频特征进行预测，并打印预测结果。
