### 3.3 Python代码阐述

```python
import jieba
import numpy as np
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

# 文本预处理
def preprocess_text(text):
    return jieba.lcut(text)

# 情感分析
def sentiment_analysis(text):
    vectorizer = CountVectorizer()
    X = vectorizer.fit_transform([text])
    classifier = MultinomialNB()
    classifier.fit(X, [1])
    return classifier.predict(X)[0]

# 提取提示词
def extract_keywords(text):
    return jieba.get_top_words(preprocess_text(text), topK=10)

# 生成回应
def generate_response(sentiment):
    if sentiment == 1:
        return "感谢您的分享，我很高兴听到这个好消息。"
    else:
        return "听起来您有些烦恼，请告诉我更多细节，我会尽力帮助您。"

# 测试
text = "我今天考试得了满分，太开心了！"
sentiment = sentiment_analysis(text)
print(generate_response(sentiment))
```

## 第4章：数学模型和数学公式

### 4.1 数学模型介绍

提示词工程的数学模型主要包括词向量模型、情感分类模型等。这些模型通过数学公式和算法，实现文本的情感分析和关键词提取。

### 4.2 公式讲解

- 词向量模型：$$ word\_vector = \sum_{i=1}^{n} w_i * v_i $$
- 情感分类模型：$$ P(y|X) = \frac{e^{\theta^T x}}{\sum_{y'} e^{\theta^T x'}} $$

### 4.3 举例说明

假设我们有以下文本数据：

- positive.txt: "我很高兴，今天天气很好。"
- negative.txt: "我很伤心，今天天气很糟糕。"

使用词向量模型，我们可以得到：

- positive\_vector: (0.5, 0.2, -0.3)
- negative\_vector: (-0.3, 0.4, 0.1)

使用情感分类模型，我们可以得到：

$$ P(y=1|X) = \frac{e^{0.8}}{e^{0.8} + e^{-0.8}} \approx 0.946 $$

这意味着文本的正情感概率为94.6%。
