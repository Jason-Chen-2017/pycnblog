## 核心算法原理讲解

### 冥想音乐的核心算法原理

冥想音乐的核心算法原理基于声音频率的调节。通过改变声音的频率，可以影响大脑波频，从而调节情绪。以下是一个简单的Python源代码示例，用于生成不同频率的声音：

```python
import numpy as np
import sounddevice as sd
import scipy.io.wavfile as wav

def generate_sine_wave(frequency, duration, filename):
    t = np.linspace(0, duration, duration * frequency)
    wave = np.sin(2 * np.pi * frequency * t)
    sd.play(wave, frequency)
    wav.write(filename, frequency, wave)

generate_sine_wave(440, 5, 'sine_440.wav')  # 生成频率为440Hz的声音
