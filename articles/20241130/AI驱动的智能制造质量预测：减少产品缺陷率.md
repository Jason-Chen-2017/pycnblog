### 附录A：常用质量预测算法介绍

#### A.1 线性回归
线性回归是一种常用的质量预测算法，其基本原理是通过线性模型预测产品质量。

##### A.1.1 基本原理
线性回归模型通常表示为：$$y = wx + b$$，其中y是预测值，x是输入特征，w是权重，b是偏置。

##### A.1.2 伪代码实现
```python
def linear_regression(x, y):
    n = len(x)
    w = (sum(x * y) - n * mean(x) * mean(y)) / (sum(x**2) - n * mean(x)**2)
    b = mean(y) - w * mean(x)
    return w, b
```

##### A.1.3 应用实例
线性回归可以用于预测汽车发动机的磨损情况。
