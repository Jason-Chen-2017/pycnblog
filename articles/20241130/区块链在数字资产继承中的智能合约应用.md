## 第1章 区块链与数字资产概述

### 1.1 区块链技术基础

区块链是一种分布式数据库技术，通过密码学和共识算法确保数据的完整性和不可篡改性。其基础概念包括区块、链、节点、挖矿和共识算法等。

**区块**是区块链的基本单元，包含一定数量的交易记录和时间戳等信息。

**链**是由一系列按时间顺序排列的区块组成的，每个区块都通过密码学哈希函数与前一个区块相连，形成一个链条。

**节点**是区块链网络中的计算机，负责维护和更新区块链账本。

**挖矿**是节点通过解决数学难题来验证和记录交易，从而获得区块链网络的奖励。

**共识算法**是一种决策机制，用于确保区块链网络中的所有节点对账本的一致性。

### 1.2 数字资产的概念与类型

数字资产是指以数字形式存在的资产，如加密货币、代币、数字债券等。它们在区块链上具有独特的属性和转移方式。

**加密货币**是一种数字货币，使用密码学技术确保交易的安全性和匿名性。

**代币**是一种数字资产，用于表示某种权益或价值，常用于去中心化应用（DApps）的激励机制。

**数字债券**是发行者通过区块链平台发行的债券，具有透明、高效和低成本的特点。

```solidity
contract DigitalAssetInheritance {
    address owner;
    mapping(address => Asset) assets;

    struct Asset {
        string name;
        uint quantity;
        address owner;
    }

    constructor() {
        owner = msg.sender;
    }

    function addAsset(string memory name, uint quantity, address owner) public {
        require(msg.sender == owner, "Only asset owner can add assets.");
        assets[owner].name = name;
        assets[owner].quantity = quantity;
        assets[owner].owner = owner;
    }

    function distributeAssets() public {
        require(msg.sender == owner, "Only owner can distribute assets.");
        require(assets[owner].quantity > 0, "No assets to distribute.");
        uint totalBTC = assets[owner].quantity / 3;
        uint totalETH = assets[owner].quantity / 3;
        uint totalTokensA = assets[owner].quantity / 3;

        assets[address(0x1234567890123456789012345678901234567890)].quantity += totalBTC;
        assets[address(0xabcdef0123456789012345678901234567890abcdef)].quantity += totalETH;
        assets[address(0x0123456789012345678901234567890abcdef0123)].quantity += totalTokensA;

        assets[owner].quantity = 0;
    }
}
```

   - `addAsset()`：添加数字资产，只有资产所有者才能调用。

**智能合约工作原理**：

1. **添加数字资产**：

   张先生通过调用`addAsset()`函数添加其数字资产到智能合约中。每个资产都被记录为一个`Asset`结构体，存储在映射中。
