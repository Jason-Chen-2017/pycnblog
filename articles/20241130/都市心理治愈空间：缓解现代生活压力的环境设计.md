## Python代码示例

### 举例说明如何使用Python进行环境设计参数的计算

```python
import numpy as np

def calculate_light_intensity(percentage, distance):
    """
    计算光线强度
    :param percentage: 光线百分比
    :param distance: 距离
    :return: 光线强度
    """
    intensity = percentage * (1 - distance/100)
    return intensity

# 示例计算
light_intensity = calculate_light_intensity(50, 70)
print(f"光线强度：{light_intensity}")
```

## 数学模型与公式

### 心理治愈空间的光照质量评估模型

$$
Q = \frac{1}{2} \left( 1 - \frac{d}{r} \right)
$$

其中，$Q$ 表示光照质量，$d$ 表示光线距离，$r$ 表示光线百分比。

### 详细讲解与举例

假设光线距离为 50 米，光线百分比为 30%，代入公式计算光照质量：

$$
Q = \frac{1}{2} \left( 1 - \frac{50}{100} \right) = \frac{1}{2} \left( 1 - 0.5 \right) = 0.25
$$

因此，该空间的光照质量为 0.25。
