### 第1章：古希腊哲学的起源与演变

古希腊哲学是西方哲学的源头，其起源可以追溯到公元前6世纪。当时的希腊城邦，如雅典和斯巴达，经历了政治、社会和文化的重大变革，为哲学的诞生提供了肥沃的土壤。古希腊哲学的兴起，不仅为人类思考宇宙、生命和道德等问题提供了新的视角，而且对后世哲学的发展产生了深远的影响。

#### 1.1 古希腊哲学的起源背景

古希腊哲学的起源背景主要包括以下几个方面：

1. **经济基础**：古希腊城邦的小农经济和商业活动为哲学思想的产生提供了物质基础。这种经济结构促进了思想交流和社会互动，为哲学的诞生创造了条件。

2. **政治制度**：古希腊的民主制度和城邦制度为哲学家们提供了独立思考和发表意见的空间。雅典的民主制度尤其为哲学家们提供了展示自己思想的机会。

3. **文化传统**：古希腊神话和祭祀活动为哲学思考提供了丰富的素材。哲学家们通过对神话的解读，探索了宇宙、生命和灵魂的本质。

4. **教育体系**：古希腊的教育体系培养了大量的哲学家。柏拉图和亚里士多德就是其中的佼佼者，他们的思想影响了整个西方哲学的发展。

#### 1.2 古希腊哲学的初期发展

古希腊哲学的初期发展主要分为以下几个阶段：

1. **前苏格拉底哲学**：这一阶段主要包括泰勒斯、阿那克西曼德、阿那克西美尼等自然哲学家。他们试图通过自然现象来解释宇宙和生命的起源。

2. **苏格拉底哲学**：苏格拉底是古希腊哲学的转折点，他不再关注自然现象，而是将哲学的目光转向人类自身。苏格拉底认为，通过自我反思和对话，人们可以获得智慧和道德的真理。

3. **柏拉图哲学**：柏拉图是苏格拉底的学生，他的哲学思想进一步发展了苏格拉底的思想。柏拉图创立了学园，强调通过教育和哲学思考来追求真理和美。

4. **亚里士多德哲学**：亚里士多德是柏拉图的学生，他的哲学思想与柏拉图有所不同。亚里士多德更关注实证研究和自然科学，他的思想对后世的科学和哲学发展产生了深远的影响。

#### 1.3 古希腊哲学的主要流派

古希腊哲学的主要流派包括：

1. **唯物主义**：唯物主义哲学家如泰勒斯认为，宇宙和生命都是物质的产物。他们试图通过自然现象来解释宇宙和生命的起源。

2. **唯心主义**：唯心主义哲学家如柏拉图认为，宇宙和生命都是精神的产物。他们强调理念、形式和美的本质。

3. **辩证法**：辩证法哲学家如黑格尔认为，事物的发展是通过对立的统一和斗争。辩证法强调事物的矛盾和变化。

4. **经验主义**：经验主义哲学家如洛克认为，知识和真理来源于经验。他们主张通过观察和实验来获取知识。

5. **理性主义**：理性主义哲学家如笛卡尔认为，知识和真理可以通过理性思考和推理来获取。他们强调思维和理性的重要性。

#### 1.4 古希腊哲学的演变过程

古希腊哲学的演变过程可以分为以下几个阶段：

1. **早期哲学**：早期哲学主要关注自然和宇宙的本质，试图通过自然现象来解释世界。

2. **中世纪哲学**：中世纪哲学受到基督教思想的影响，哲学与神学紧密相连。哲学家们试图在神学和哲学之间建立联系。

3. **现代哲学**：现代哲学在17世纪和18世纪发展起来，强调理性和科学方法。现代哲学家如康德、黑格尔和尼采对后来的哲学发展产生了深远的影响。

```python
    def __init__(self, anger, joy, sadness):
        self.anger = anger
        self.joy = joy
        self.sadness = sadness
    
    # 根据情绪状态计算总分
    def score(self):
        return self.anger + self.joy + self.sadness

# 定义一个决策类
class Decision:
    def __init__(self, action, consequence):
        self.action = action
        self.consequence = consequence

def rational_think(mood, decision):
    # 计算当前情绪状态
    current_score = mood.score()
    
    # 根据情绪状态调整决策
    if current_score > 0:
        # 情绪积极，选择行动
        return Decision("行动", "积极后果")
    elif current_score < 0:
        # 情绪消极，选择不行动
        return Decision("不行动", "消极后果")
    else:
        # 情绪中性，根据后果选择行动
        if decision.consequence > 0:
            return Decision("行动", "积极后果")
        else:
            return Decision("不行动", "消极后果")

# 创建一个情绪状态实例

# 创建一个决策实例

# 使用理性思考和自我控制函数

# 输出结果

```

在这个示例中，我们首先定义了情绪状态和决策类，然后创建了一个理性思考和自我控制的函数。该函数根据当前情绪状态和决策后果来决定是否采取行动。通过这个简单的示例，我们可以看到新斯多葛哲学中的理性思考和自我控制如何应用于实际生活中。
