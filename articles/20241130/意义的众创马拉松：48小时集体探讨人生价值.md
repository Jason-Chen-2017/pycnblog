#### 1. 价值度量算法

价值度量是评估参与者在意义共创过程中贡献的重要手段。本文提出的价值度量算法通过三个核心指标：参与度、影响力和创新性，综合评估参与者的价值。

##### 参与度

参与度反映了参与者在整个活动中的参与程度。我们使用以下公式计算参与度：

$$
\text{参与度} = \frac{\text{贡献量}}{\text{总贡献量}}
$$

其中，贡献量是指参与者提出的观点、建议或解决方案的数量。总贡献量是所有参与者贡献量的总和。

##### 影响力

影响力衡量的是参与者的观点或建议被接受和传播的程度。影响力计算公式如下：

$$
\text{影响力} = \frac{\text{观点传播}}{\text{总观点数}}
$$

观点传播是指参与者的观点被其他参与者讨论、支持或引用的次数。总观点数是所有参与者提出的观点的总和。

##### 创新性

创新性评估的是参与者的观点或建议的创新程度。计算公式如下：

$$
\text{创新性} = \frac{\text{新观点数量}}{\text{总观点数量}}
$$

新观点数量是指具有原创性的观点或建议的数量，总观点数量是所有参与者提出的观点的总和。

##### 价值度量公式

综合以上三个指标，我们使用以下公式计算总价值度量：

$$
\text{价值度量} = f(\text{参与度}, \text{影响力}, \text{创新性})
$$

其中，\( f \) 是一个权重函数，用于根据具体情况调整不同指标的权重。在实际应用中，可以根据具体需求和情境调整 \( f \) 的形式。

```python
def calculate_contribution(contribution, total_contribution):
    return contribution / total_contribution

def calculate_influence(views_shared, total_views):
    return views_shared / total_views

def calculate_innovativeness(new_views, total_views):
    return new_views / total_views

def calculate_value_depth(contribution, views_shared, new_views, total_contribution, total_views):
    participation = calculate_contribution(contribution, total_contribution)
    influence = calculate_influence(views_shared, total_views)
    innovativeness = calculate_innovativeness(new_views, total_views)
    
    # 假设权重为：参与度0.4，影响力0.3，创新性0.3
    weight_participation = 0.4
    weight_influence = 0.3
    weight_innovativeness = 0.3
    
    value_depth = (participation * weight_participation) + (influence * weight_influence) + (innovativeness * weight_innovativeness)
    return value_depth

# 示例数据

new_views = 5

total_views = 100
```
