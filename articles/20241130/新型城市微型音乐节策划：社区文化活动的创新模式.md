### 3.2 Python 源代码示例：观众行为预测

以下是一个简单的 Python 源代码示例，用于观众行为预测。这个示例使用决策树算法，根据观众的历史数据，预测其可能参与的音乐节活动。

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

# 加载数据
data = pd.read_csv('viewer_data.csv')

# 数据预处理
X = data.drop(['target'], axis=1)
y = data['target']

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 建立模型
model = DecisionTreeClassifier()

# 训练模型
model.fit(X_train, y_train)

# 预测结果
y_pred = model.predict(X_test)

# 计算准确率
accuracy = accuracy_score(y_test, y_pred)
print(f"Accuracy: {accuracy}")

```

在这个示例中，我们首先加载数据，然后进行预处理，包括划分训练集和测试集。接着，我们使用决策树算法建立模型，并进行训练。最后，我们使用测试集进行预测，并计算准确率。
