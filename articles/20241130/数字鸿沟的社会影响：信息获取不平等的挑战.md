### 数学模型和数学公式讲解及举例

#### 社会经济影响模型

社会经济影响模型主要涉及以下几个方面的数学公式：

1. **帕累托效率**：$$P(E) = \frac{1}{N}\sum_{i=1}^{N} w_i E_i$$
   其中，\(N\) 表示总人数，\(w_i\) 表示第 \(i\) 个个体的权重，\(E_i\) 表示第 \(i\) 个个体的经济收益。

2. **基尼系数**：$$G = \frac{\sum_{i=1}^{N} (w_i - \bar{w})^2}{N-1}$$
   其中，\(\bar{w}\) 表示平均权重，\(G\) 表示基尼系数，用于衡量经济不平等程度。

#### 社会不平等模型

社会不平等模型主要涉及以下几个方面的数学公式：

1. **洛伦茨曲线**：$$L(y) = \frac{\sum_{i=1}^{N} w_i y_i}{\sum_{i=1}^{N} w_i}$$
   其中，\(N\) 表示总人数，\(w_i\) 表示第 \(i\) 个个体的权重，\(y_i\) 表示第 \(i\) 个个体的收入。

2. **泰尔指数**：$$T = \sum_{i=1}^{N} w_i \left( \frac{y_i}{\bar{y}} - 1 \right)^2$$
   其中，\(\bar{y}\) 表示平均收入，\(T\) 表示泰尔指数，用于衡量社会不平等程度。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 加载数据
data = pd.read_csv('digital_divide_data.csv')

# 数据预处理
data['income'] = data['income'].replace('high', 1)
data['income'] = data['income'].replace('medium', 0.5)
data['income'] = data['income'].replace('low', 0)

# 计算洛伦茨曲线
income = data['income'].value_counts().sort_index()
cumulative_income = income.cumsum()
cumulative_population = income.index.cumsum()

# 绘制洛伦茨曲线
plt.plot(cumulative_population, cumulative_income, marker='o')
plt.xlabel('Cumulative Population')
plt.ylabel('Cumulative Income')
plt.title('Lorenz Curve')
plt.show()

# 计算基尼系数
gini_coefficient = 2 * (np.sum(income) - np.sum(cumulative_income)) / (len(income) - 1)
print(f'Gini Coefficient: {gini_coefficient}')
```
