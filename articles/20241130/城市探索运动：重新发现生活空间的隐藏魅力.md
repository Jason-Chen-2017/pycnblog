**5.1 城市探索运动中的GPS技术**

全球定位系统（GPS）是城市探索运动中不可或缺的科技工具。GPS技术通过卫星信号，实时定位探索者的位置，提供精确的导航服务。在探索过程中，GPS设备可以帮助参与者准确了解自己的地理位置，避免迷路，提高探索效率。

Python代码示例：

```python
import numpy as np
import matplotlib.pyplot as plt

# 假设我们有一个包含经纬度的列表
coordinates = [
    [35.6895, 139.6917],  # 东京
    [51.5074, -0.1278],  # 伦敦
    [48.8566, 2.3522],  # 巴黎
]

# 绘制坐标点
plt.scatter(*zip(*coordinates), label='Coordinates')
plt.xlabel('Longitude')
plt.ylabel('Latitude')
plt.legend()
plt.title('GPS Coordinates for City Exploration')
plt.show()
```

此代码使用Python的matplotlib库，根据给定的经纬度列表绘制了坐标点，从而帮助探索者可视化自己的位置。
