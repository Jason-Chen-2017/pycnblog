def calculate_design_score(beauty, functionality, sustainability):
    # 设置权重
    weights = {'beauty': 0.4, 'functionality': 0.3, 'sustainability': 0.3}
    
    # 计算总分
    score = sum(weight * value for weight, value in zip(weights.values(), [beauty, functionality, sustainability]))
    
    # 返回评分
    return score
```

通过这个函数，我们可以根据给定的评分计算设计原则的综合得分。

    # 设置颜色和纹理的匹配规则
    color_rules = {
        '节日': ['红色', '金色'],
        '生日': ['粉色', '金色'],
        '日常': ['白色', '灰色']
    }
    
    texture_rules = {
        '传统': ['棉纸', '棉布'],
        '现代': ['镜面纸', '金属质感纸']
    }
    
    # 根据规则选择合适的色彩和纹理
    chosen_color = color_rules.get(color, ['白色', '灰色'])
    chosen_texture = texture_rules.get(texture, ['棉纸', '棉布'])
    
    # 返回选择结果
    return chosen_color, chosen_texture
```

通过这个函数，我们可以根据给定的场景和风格选择合适的色彩和纹理。
