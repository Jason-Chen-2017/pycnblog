### 量子密码技术基础

#### 量子比特与经典比特的对比

量子密码学建立在量子力学的基石之上，而量子比特（qubit）是量子信息处理的基本单元。与经典比特（bit）不同，量子比特可以同时存在于0和1两种状态的叠加态，这种特性称为量子叠加。量子叠加态使得量子比特具有独特的并行处理能力，可以在同一时间处理大量信息。

经典比特的表示形式是明确的0或1状态，而量子比特则可以表示为 $|\psi\rangle = a|0\rangle + b|1\rangle$，其中$a$和$b$是复数系数，且满足$|a|^2 + |b|^2 = 1$。这意味着量子比特可以处于多种状态的组合，直到被测量时才确定其状态。

此外，量子比特还具有量子纠缠特性。当两个量子比特处于纠缠态时，一个量子比特的状态会立即影响另一个量子比特的状态，无论它们之间的距离有多远。这一特性为量子密码通信提供了高度的安全性，因为任何试图窃听的行为都会破坏量子纠缠态，导致信息泄露。

#### 量子纠缠与量子通信

量子纠缠是量子力学中一个极为重要的现象，它指的是两个或多个量子系统之间的强关联。当两个量子比特处于纠缠态时，对其中一个量子比特的操作会立即影响到另一个量子比特的状态。这种现象无法用经典物理学的概念来解释，是量子力学中特有的特性。

量子纠缠在量子通信中扮演着关键角色。通过量子纠缠，可以实现量子密钥分发（Quantum Key Distribution, QKD）。QKD是一种基于量子力学原理的密钥分配协议，它确保了密钥在传输过程中的绝对安全性。在QKD过程中，发送方和接收方通过量子通信信道共享纠缠的量子比特对，然后利用经典通信信道交换测量结果。如果双方测量结果一致，则共享的量子密钥是安全的，否则密钥被判定为不安全。

#### 量子密钥分发

量子密钥分发（QKD）是量子密码学中最为重要的应用之一。它利用量子纠缠和量子测量的不可克隆性，实现密钥的安全传输。QKD的基本过程如下：

1. **量子密钥生成**：发送方（Alice）使用一个随机数生成器生成一个随机比特序列，并将其与一个量子比特（例如光子）纠缠。生成的纠缠比特对通过量子通信信道传输到接收方（Bob）。

2. **量子态传输**：传输过程中，Bob对收到的量子比特进行测量，并根据测量结果生成自己的随机比特序列。

3. **经典通信**：Alice和Bob使用经典通信信道交换各自的随机比特序列。

4. **密钥筛选**：双方对交换的比特序列进行匹配，排除由于量子信道噪声和可能的窃听导致的错误比特，筛选出高质量的密钥。

5. **密钥验证**：Alice和Bob可以进一步使用哈希函数或MAC（消息认证码）来验证密钥的完整性。

量子密钥分发的安全性基于量子力学的基本原理。首先，量子态的任何测量都会不可避免地改变量子态，这一特性称为量子测量的不可克隆性。这意味着即使敌手Eve试图窃听量子信道，她也无法完全复制量子态，从而无法获得完整的密钥。其次，量子纠缠确保了发送方和接收方之间的通信是同步的，任何窃听行为都会导致纠缠态的破坏，从而被发现。

### 量子密码算法与协议

量子密码学涉及多种算法和协议，其中最为重要的是Shor算法、BB84协议和E91协议。这些算法和协议在量子密码通信中发挥着关键作用，确保了通信的安全性和可靠性。

#### Shor算法与因子分解

Shor算法是量子计算中的一个里程碑，它展示了量子计算机在解决某些问题上的巨大优势。Shor算法能够高效地解决大整数因子分解问题，这对于许多加密算法，如RSA加密，构成了威胁。

Shor算法的基本思想是利用量子并行性和量子叠加态，将大整数分解问题转化为模运算。具体过程如下：

1. **初始状态**：将一个n位的整数N表示为二进制形式，并构造一个量子态，其中每个元素都是一个叠加态，表示所有小于N的整数的模N运算结果。

2. **量子迭代**：对量子态进行一系列量子门操作，使得量子态逐渐聚集在特定的态上，这些态对应着N的因子。

3. **测量**：对量子态进行测量，得到一个特定的结果，该结果即为N的因子。

Shor算法的核心优势在于其利用了量子并行性，能够在多项式时间内解决大整数分解问题。这对于传统密码学构成了巨大挑战，因为传统算法需要指数级时间才能分解大整数。

#### BB84量子密钥分配协议

BB84协议是第一个被提出的量子密钥分配协议，由Charles H. Bennett和Garrett D. Clarke于1984年提出。BB84协议基于量子叠加态和量子纠缠态，通过量子通信信道实现安全密钥的分发。

BB84协议的基本过程如下：

1. **量子态选择**：Alice随机选择一个量子态，可以是基态（水平或垂直偏振）或纠缠态。

2. **量子态传输**：Alice将选择的量子态通过量子通信信道发送给Bob。

3. **量子态测量**：Bob接收到量子态后，随机选择一个测量基，对量子态进行测量。

4. **经典通信**：Alice和Bob通过经典通信信道交换测量基和测量结果。

5. **密钥筛选**：Alice和Bob对交换的测量基和结果进行匹配，筛选出一致的比特，得到共享的密钥。

BB84协议的安全性基于量子测量的不可克隆性和量子纠缠的特性。任何试图窃听的行为都会导致量子态的破坏，从而被发现。

#### E91量子密钥分配协议

E91协议是另一种重要的量子密钥分配协议，基于量子纠缠态的Bell状态。E91协议由H. J. Kim和S. L. Lee于1991年提出，是对BB84协议的改进。

E91协议的基本过程如下：

1. **量子纠缠态生成**：Alice和Bob通过量子通信信道共享一组Bell态的量子纠缠对。

2. **量子态测量**：Alice和Bob分别对收到的量子纠缠对进行测量，选择不同的测量基。

3. **经典通信**：Alice和Bob通过经典通信信道交换测量基和结果。

4. **密钥筛选**：Alice和Bob对交换的测量基和结果进行匹配，筛选出一致的比特，得到共享的密钥。

E91协议在量子信道质量较差的情况下仍然具有较好的性能，因为其利用了量子纠缠态的物理特性，提高了通信的可靠性。

import numpy as np
from qiskit import QuantumCircuit, Aer, execute
from qiskit.visualization import plot_bloch_vector

def shor(n):
    """Shor's algorithm for factoring a number n."""
    # Prepare the quantum register
    q = QuantumRegister(2 * n)
    qc = QuantumCircuit(q)
    
    # Initial state |+>
    qc.h(q[0])
    
    # Create the superposition of states
    qc.barrier(q[0])
    qc.h(q[0])
    qc.barrier(q[0])
    qc.cnot(q[0], q[1])
    qc.barrier(q[0])
    qc.h(q[0])
    
    # Iterate n-1 times
    for i in range(n-1):
        qc.barrier(q[0])
        qc.h(q[0])
        qc.barrier(q[0])
        qc.cnot(q[0], q[1])
        qc.barrier(q[0])
        qc.h(q[0])
    
    # Measurement
    qc.barrier(q[0])
    qc.measure(q[0], 0)
    qc.measure(q[1], 1)
    
    # Execute the circuit
    backend = Aer.get_backend('qasm_simulator')
    result = execute(qc, backend, shots=1024)
    counts = result.get_counts()
    
    # Extract the factor
    factor = extract_factor(counts, n)
    return factor

def extract_factor(counts, n):
    """Extract a factor of n from the measurement results."""
    for bit_string in counts:
        decimal = int(bit_string, 2)
        if pow(decimal, 2) % n == 1:
            return decimal
    return None

# Example usage
n = 21
