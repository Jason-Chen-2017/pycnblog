**2.1 LLM的定义与起源**

大型语言模型（LLM，Large Language Model）是一种基于深度学习技术的自然语言处理模型，主要用于文本数据的理解和生成。LLM的起源可以追溯到20世纪90年代，当时研究人员开始探索基于神经网络的方法来处理自然语言。随着计算能力的提升和大数据技术的发展，LLM在21世纪取得了显著的进展，尤其在2018年后，随着Transformer架构的提出，LLM的发展进入了一个新的阶段。

**2.2 LLM的核心组件**

LLM的核心组件主要包括以下几部分：

1. **输入层**：接收文本数据，将其转换为模型可以处理的格式。
2. **编码器**：将输入文本编码为高维向量表示，这一过程通常使用多层循环神经网络（RNN）或Transformer模型实现。
3. **解码器**：根据编码器的输出生成文本输出，解码器通常也是基于多层循环神经网络或Transformer结构。
4. **预训练与微调**：LLM通常通过大规模语料库进行预训练，然后在特定任务上进行微调，以适应具体应用场景。

**2.3 LLM的特点**

LLM具有以下几个显著特点：

1. **强大的文本理解能力**：LLM能够理解文本中的语义和上下文信息，从而生成与输入文本相关的输出。
2. **高度的可扩展性**：通过预训练和微调，LLM可以应用于各种自然语言处理任务，如文本分类、机器翻译、问答系统等。
3. **自适应能力**：LLM能够根据输入文本的不同，灵活地调整其生成的内容，使其适应不同的语境和需求。
4. **高效的计算性能**：现代LLM模型采用了高效的神经网络架构，能够在较短的的时间内处理大量的文本数据。

**2.4 LLM的应用场景**

LLM在智能城市管理系统中具有广泛的应用场景：

1. **文本挖掘与分析**：利用LLM对大量城市相关的文本数据进行分析，提取出有价值的信息和知识，如城市舆情分析、政策文本解读等。
2. **智能对话与交互**：构建智能对话系统，为市民提供便捷的公共服务，如在线咨询、智能客服等。
3. **自然语言生成**：生成自然流畅的文本，用于城市管理的各种公告、报告和通知，提高信息传播效果。
4. **智能推荐与预测**：基于历史数据和实时数据，利用LLM进行交通流量预测、环保措施建议等，为城市管理提供决策支持。

from sklearn.metrics import accuracy_score, precision_score, recall_score

# 评估模型
def evaluate_model(model, encodings, labels):
    model.eval()
    with torch.no_grad():
        predictions = []
        for batch in encodings:
            inputs = {
                'input_ids': batch['input_ids'].to(device),
                'attention_mask': batch['attention_mask'].to(device)
            }
            outputs = model(**inputs)
            logits = outputs.logits
            predictions.extend(torch.argmax(logits, dim=-1).cpu().numpy())
        predictions = np.array(predictions)
        labels = np.array(labels)
        accuracy = accuracy_score(labels, predictions)
        precision = precision_score(labels, predictions, average='weighted')
        recall = recall_score(labels, predictions, average='weighted')
    return accuracy, precision, recall

# 评估结果
