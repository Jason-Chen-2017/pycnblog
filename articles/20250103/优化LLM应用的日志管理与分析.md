### 第2章：LLM的工作原理

#### 2.1.1 LLM的架构

**Transformer模型：**
- **自注意力机制（Self-Attention）：** Transformer模型的核心机制，通过计算文本中每个单词与其他单词之间的关联性来生成表示。
- **编码器和解码器：** Transformer模型通常由编码器和解码器组成，编码器负责将输入文本编码为向量表示，解码器负责生成输出文本。

**堆叠与预训练：**
- **堆叠（Stacking）：** 将多个较小的模型堆叠在一起，形成一个大的模型。
- **预训练（Pre-training）：** 在大规模数据集上对模型进行预训练，然后再在特定任务上进行微调。

#### 2.1.2 LLM的数学模型

**自注意力机制：**
$$
\text{Attention}(Q, K, V) = \frac{softmax(\frac{QK^T}{\sqrt{d_k}})}{V}
$$

其中，Q、K、V分别为查询向量、关键向量、值向量，d_k为关键向量的维度。

**计算复杂度分析：**
- **时间复杂度：** $O(n^2d)$
- **空间复杂度：** $O(n^2d)$

**Python代码实例：**

```python
import torch
import torch.nn as nn

class TransformerModel(nn.Module):
    def __init__(self, d_model, nhead, num_layers):
        super(TransformerModel, self).__init__()
        self.transformer = nn.Transformer(d_model, nhead, num_layers)
    
    def forward(self, src, tgt):
        output = self.transformer(src, tgt)
        return output
```
