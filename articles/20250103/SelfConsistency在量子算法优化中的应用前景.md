#### 6.1.1 数学模型简介

量子算法的核心在于量子态的叠加和纠缠。量子态可以用一个复数向量表示，其模平方代表了量子态的概率分布。量子算法的数学模型主要涉及以下概念：

1. **量子态**：量子态是一个复数向量，表示量子系统可能的状态。一个量子态可以用矩阵形式表示，例如，一个两量子比特系统的量子态可以表示为：
   $$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$
   其中，$|\alpha|^2 + |\beta|^2 = 1$。

2. **叠加态**：量子态的叠加是指一个量子系统可以同时处于多个状态的组合。例如，上述两量子比特系统的叠加态可以表示为：
   $$|\psi\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$$

3. **纠缠态**：量子纠缠是指两个或多个量子系统之间存在一种不可分割的相互依赖关系。纠缠态的一个典型例子是Bell态：
   $$|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$$

4. **量子门**：量子门是作用于量子态的线性变换，类似于经典计算中的逻辑门。常见的量子门包括Hadamard门、Pauli门和控制非门（CNOT门）。
