## 第四部分：算法原理讲解

### 第5章：LLM算法原理

#### 6.1 算法介绍
LLM通常基于Transformer架构，通过预训练和微调来提高语言理解能力和生成能力。

#### 6.2 算法原理讲解
Transformer模型的核心是自注意力机制（Self-Attention），通过计算输入序列中每个词与所有词的关联度，生成新的表示。

```mermaid

B --> C[Decoder]

```

#### 6.3 算法流程图
```mermaid

B --> C(Evaluation)
C --> D(Feedback Loop)
```

#### 6.4 数学模型与公式
自注意力机制的数学模型如下：
$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$
其中，$Q, K, V$分别为查询向量、键向量和值向量，$d_k$为键向量的维度。

#### 6.5 举例说明
假设我们有一个简化的句子“我今天去了公园”，我们可以用自注意力机制来计算句子中每个词的权重。

```python
# 假设词向量为3维
word_vectors = {
    "我": [1, 0, 0],
    "今": [0, 1, 0],
    "天": [0, 0, 1],
    "去": [1, 1, 0],
    "了": [0, 1, 1],
    "公": [1, 0, 1],
    "园": [0, 1, 1]
}

# 计算自注意力权重
query_vector = word_vectors["去"]
keys_vector = word_vectors["今天"]
values_vector = word_vectors["公园"]

attention_weights = softmax((query_vector @ keys_vector.T) / sqrt(len(keys_vector)))
print(attention_weights)
```

输出结果为：
```
[0.5 0.5]
```
这表明“去”和“今天”在句子中的重要性相当。
