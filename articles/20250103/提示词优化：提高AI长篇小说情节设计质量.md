    doc = nlp(text)
    keywords = []
    for token in doc:
        if token.is_alpha and token.is_stop and token.text.lower() not in stop_words:
            keywords.append(token.text.lower())
    return keywords

def adjust_word_meaning(word, meaning_dict):
    return meaning_dict.get(word, word)

def optimize_grammar(text):
    doc = nlp(text)
    optimized_text = []
    for token in doc:
        if token.is_alpha:
            optimized_text.append(token.text)
    return " ".join(optimized_text)

# 定义情感融入函数
def add_emotion(text, emotion):
    return text + "（带有" + emotion + "情感）"

### 第六部分：最佳实践 tips

#### 6.1 提示词优化的最佳实践

**6.1.1 提示词选择技巧**

1. **明确主题和情感**：在选取提示词时，首先要明确故事的主题和情感，确保提示词能够引导AI生成符合预期情节。
2. **多样化关键词**：尽量选取多样化的关键词，以丰富故事情节的内容和风格。
3. **避免重复**：避免在提示词中重复使用相同或类似的关键词，以免影响AI生成独特、有创意的情节。
4. **考虑受众需求**：根据目标受众的特点和喜好，选择适合他们的关键词，以提高故事情节的吸引力和认同感。

**6.1.2 优化策略应用**

1. **逻辑性优化**：在优化提示词时，注意保持情节的逻辑性，避免出现矛盾或不合理的地方。
2. **情感表达优化**：通过调整关键词的词义和语法，增强情节的情感表达，使故事更加生动和感人。
3. **创意性优化**：尝试使用新的表达方式和组合，激发AI生成创意丰富的情节，使故事更具吸引力。
4. **个性化优化**：根据用户的个性化需求，调整提示词，使其生成的情节更加符合用户口味。

#### 6.2 注意事项

**6.2.1 提示词优化过程中需要注意的问题**

1. **数据依赖**：提示词优化需要大量高质量的训练数据支持，确保AI能够从中学习到有效的模式和规律。
2. **算法限制**：当前的AI技术仍然存在一定的局限性，特别是在情感表达和创意生成方面。需要根据实际情况合理设置优化策略。
3. **时间成本**：提示词优化过程可能需要消耗大量时间和计算资源，需要提前规划好时间和资源安排。

**6.2.2 避免的常见错误**

1. **过度优化**：避免过度优化提示词，导致情节失去自然感和真实性。
2. **忽视用户需求**：在优化过程中，要充分考虑用户需求，避免只关注技术实现而忽视用户体验。
