```python
def present_example(example):
    print(f"Example: {example['description']}")
    user_input = input("Have you understood the example? (yes/no): ")
    return user_input.lower() == 'yes'

def process_example(example, user_input):
    if user_input == 'no':
        print(f"Let's try again: {example['description']}")
        return False
    else:
        return True

def example_based_cues(examples, num_examples):
    for i in range(num_examples):
        example = random.choice(examples)
        print(f"\nExample {i+1}:")
        if not present_example(example):
            continue
        print(f"Processing example {i+1}...")
        process_example(example, 'yes')

examples = [
    {'description': 'Solve the equation: 2 + 3 = ?'},
    {'description': 'What is the capital of France?'},
    {'description': 'Arrange the following words in alphabetical order: apple, banana, cherry'}
]

example_based_cues(examples, 3)
```

#### 2.4 Mathematical Model and Formula Explanation

In cognitive load theory, there are three types of cognitive load: intrinsic, extrinsic, and germane. The formula to calculate the total cognitive load is:

$$
Total\ Cognitive\ Load = Intrinsic\ Cognitive\ Load + Extrinsic\ Cognitive\ Load + Germane\ Cognitive\ Load
$$

##### 2.4.1 Basic Mathematical Model

The intrinsic cognitive load is inherent to the task itself and cannot be reduced by instructional strategies. The extrinsic cognitive load is the cognitive load imposed by the instructional materials. The germane cognitive load is the cognitive load that contributes to the construction of knowledge structures.

$$
Intrinsic\ Cognitive\ Load = f(TASK\ COMPLEXITY)
$$

$$
Extrinsic\ Cognitive\ Load = f(INSTRUCTIONAL\ MATERIALS)
$$

$$
Germane\ Cognitive\ Load = f(KNOWLEDGE\ CONSTRUCTION)
$$
