#### 4. Mathematical Model and Formulas

The Neural Network Algorithm is based on complex mathematical models and formulas. The core components of these models include the activation function, the weight matrix, and the bias term. The activation function determines the output of a neuron, while the weight matrix and bias term define the strength of the connections between neurons.

One common activation function used in neural networks is the Rectified Linear Unit (ReLU), which is defined as follows:

$$
\text{ReLU}(x) =
\begin{cases}
0 & \text{if } x < 0 \\
x & \text{if } x \ge 0
\end{cases}
$$

The weight matrix (W) and bias term (b) are represented as follows:

$$
a_{j}^{l} = \sigma(W_{ij}^{l} x_{i}^{l} + b_{j}^{l})
$$

where \(a_{j}^{l}\) is the activation of the j-th neuron in the l-th layer, \(\sigma\) is the activation function, \(W_{ij}^{l}\) is the weight matrix, and \(b_{j}^{l}\) is the bias term.
