| 数据点 | 温度 | 湿度 | 风速 |
| ------ | ---- | ---- | ---- |
| 1      | 0.5  | 0.8  | 0.1  |

| 3      | 0.4  | 0.7  | 0.1  |

```
        [温度]
       /     \
     [25]   [28]
        |     |
     [22]   [22]
```

在自一致性上下文树中，我们使用一致性得分来衡量每个节点的一致性。一致性得分是通过计算相邻节点之间的相似度得到的。例如，对于温度节点，我们可以使用平均绝对误差（MAE）来计算相邻节点的一致性得分。MAE的公式如下：

其中，$X_i$ 是每个数据点的温度值，$\bar{X}$ 是所有数据点的温度值的平均值，$N$ 是数据点的数量。

其中，$S_h$ 是湿度节点的一致性得分，$S_w$ 是风速节点的一致性得分。

from sklearn.cluster import KMeans

def build_context_tree(data, num_clusters):
    # 使用K-means算法进行聚类，构建上下文树

    }

def check_consistency(context_tree):
