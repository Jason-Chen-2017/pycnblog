## 第二部分：资产配置的核心原理

### 第2章：现代投资组合理论（MPT）

#### 2.1 MPT的核心概念
  - **定义**：MPT由哈里·马科维茨提出，强调通过分散投资降低风险。
  - **有效前沿曲线**：通过图形化展示最优投资组合的收益与风险权衡。

#### 2.2 MPT的数学模型
  - **公式**：
    - 投资组合的期望收益：$$E(r_p) = \sum w_i E(r_i)$$
    - 投资组合的风险：$$\sigma_p^2 = \sum \sum w_i w_j \sigma_i \sigma_j \rho_{ij}$$

#### 2.3 MPT与伯格理论的联系
  - 伯格将MPT应用于实践，提出具体的资产配置策略。

### 第3章：风险与收益的平衡

#### 3.1 风险的分类与度量
  - **系统性风险**：市场波动带来的风险。
  - **非系统性风险**：特定资产或行业的风险。

#### 3.2 收益的来源
  - 股票收益：资本增值和股息收入。
  - 债券收益：固定利息收入。

#### 3.3 平衡策略
  - **资产类别选择**：根据风险承受能力和投资目标选择资产。
  - **再平衡**：定期调整投资组合以维持目标配置。

#### 4.2 算法实现
  - 使用Python实现MPT模型，计算最优投资组合。
  - 代码示例：

```python
import numpy as np

def mpt_optimizer(risk_parity):
    # 计算协方差矩阵
    covariance_matrix = np.array([[0.02, 0.01], [0.01, 0.03]])
    # 计算风险平价权重
    weights = np.linalg.solve(covariance_matrix, np.ones(2)) / np.sum(np.linalg.solve(covariance_matrix, np.ones(2)))
    return weights

print(mpt_optimizer(0.5))
```
