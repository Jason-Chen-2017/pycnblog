### 第3章："智者圈"理论的算法原理与数学模型

#### 3.1 "智者圈"理论的算法原理
- **算法目标**：通过分析网络结构，识别关键节点和关系。
- **流程**：
  1. 数据收集：获取投资者和投资目标的关系数据。
  2. 网络构建：构建图结构。
  3. 关系强度计算：使用加权边表示关系强度。
  4. 中心性分析：计算节点的中心性指标。
  5. 投资决策：基于中心性结果选择投资目标。

#### 3.2 "智者圈"理论的数学模型与公式
- **关系强度公式**：
  $$ \text{关系强度} = \frac{\text{共同投资次数}}{\text{总投资次数}} $$
- **中心性公式**：
  $$ \text{度中心性} = \frac{\text{节点度数}}{\text{网络总节点数}} $$
  $$ \text{接近中心性} = \frac{1}{\text{平均最短路径长度}} $$

#### 3.3 算法实现
```python
import networkx as nx

def compute centrality(graph):
    degree_centrality = nx.degree_centrality(graph)
    betweenness_centrality = nx.betweenness_centrality(graph)
    return degree_centrality, betweenness_centrality

graph = nx.Graph()
graph.add_nodes_from([1, 2, 3, 4])
graph.add_edges_from([(1, 2), (2, 3), (3, 4)])
degree, betweenness = compute centrality(graph)
print(degree)
print(betweenness)
```

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建投资网络
graph = nx.Graph()
graph.add_nodes_from(['A', 'B', 'C', 'D'])
graph.add_edges_from([('A', 'B'), ('B', 'C'), ('C', 'D')])

# 计算中心性
degree_centrality = nx.degree_centrality(graph)
betweenness_centrality = nx.betweenness_centrality(graph)

# 可视化网络
nx.draw(graph, with_labels=True)
plt.show()

# 输出中心性结果
print("度中心性：", degree_centrality)
print("中间中心性：", betweenness_centrality)
```
