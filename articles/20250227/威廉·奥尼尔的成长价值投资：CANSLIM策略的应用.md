### 第一部分: 威廉·奥尼尔的成长价值投资概述

#### 第1章: 投资的基本概念与威廉·奥尼尔的背景

##### 1.1 投资的基本概念  
投资是指将资金投入到某个资产或项目中，以期获得未来收益的行为。投资的核心目标是通过资产配置和风险管理，实现财富的保值与增值。投资可以分为股票、债券、基金等多种形式，每种形式都有其独特的风险和收益特征。  

##### 1.2 威廉·奥尼尔的生平与投资理念  
威廉·奥尼尔是美国著名投资专家，以其独特的成长价值投资理念闻名。他提出的CANSLIM策略是一种基于技术分析和基本面分析相结合的投资方法，旨在通过筛选具有高成长潜力的股票来实现长期收益。奥尼尔的投资哲学强调市场趋势的判断和股票内在价值的分析，注重长期持有的投资策略。  

##### 1.3 CANSLIM策略的起源与发展  
CANSLIM策略诞生于20世纪70年代，是奥尼尔在长期的投资实践中总结出的一种股票筛选方法。该策略的核心在于通过分析股票的市场表现、财务指标和技术形态，筛选出具有高成长潜力的股票。与传统的价值投资不同，CANSLIM策略更注重股票的市场表现和趋势分析，强调在合适的时机买入和卖出股票。

#### 第2章: CANSLIM策略的起源与发展

##### 2.1 CANSLIM策略的定义  
CANSLIM策略是一种基于技术分析和基本面分析的投资方法，旨在通过筛选具有高成长潜力的股票来实现超额收益。该策略的核心在于分析股票的市场表现、财务指标和技术形态，重点关注股票的市场强度、相对强度、市盈率等指标。  

##### 2.2 CANSLIM策略的核心思想  
CANSLIM策略的核心思想是：  
1. **市场趋势**：投资应关注市场整体趋势，避免逆势操作。  
2. **股票筛选**：通过筛选具有高市场强度、低市盈率、高内部强度等特征的股票，找到具有成长潜力的投资标的。  
3. **风险管理**：通过技术分析和市场趋势判断，制定合理的买入和卖出策略，降低投资风险。  

##### 2.3 CANSLIM策略的适用场景  
CANSLIM策略适用于成长型股票的投资，尤其适合长期投资者和机构投资者。该策略在市场上涨周期中表现尤为突出，但在市场下跌周期中需要结合其他策略进行风险管理。

### 第二部分: CANSLIM策略的核心要素与分析

#### 第3章: CANSLIM策略的核心要素

##### 3.1 C - 当前市场环境（Current Market Environment）  
当前市场环境是CANSLIM策略的第一个核心要素，用于判断市场整体趋势。投资者需要分析市场的牛熊周期，判断当前市场处于上升趋势还是下降趋势。  

##### 3.2 A - 年线（Annual Line）  
年线是指股票价格在过去一年中的平均价格，用于判断股票的长期趋势。如果股票价格在年线上方，说明股票处于上升趋势；反之，则说明股票处于下降趋势。  

##### 3.3 N - 接近高点（Near High）  
接近高点是指股票价格接近历史最高点的区域。当股票价格接近历史高点时，投资者需要警惕市场可能出现反转的风险。  

##### 3.4 S - 市盈率（P/E Ratio）  
市盈率是衡量股票价值的重要指标，用于判断股票的估值水平。市盈率越低，股票的估值越低，投资价值越大。  

##### 3.5 L - 市净率（P/B Ratio）  
市净率是衡量股票价值的另一个重要指标，用于判断股票的资产估值水平。市净率越低，股票的资产价值越高，投资风险越小。  

##### 3.6 I - 内部强度（Internal Strength）  
内部强度是指股票相对于市场的表现，用于判断股票的市场强度。内部强度越高的股票，市场表现越强，投资价值越大。  

##### 3.7 M - 市场宽度（Market Breadth）  
市场宽度是指市场中股票的平均表现，用于判断市场的整体强度。市场宽度越宽，市场整体表现越强，投资机会越多。

### 第三部分: CANSLIM策略的算法原理

#### 第4章: CANSLIM策略的算法实现

##### 4.1 CANSLIM策略的算法流程  
1. **市场环境分析**：判断当前市场是否处于上升趋势。  
2. **股票筛选**：根据CANSLIM策略的核心要素，筛选出符合条件的股票。  
3. **投资决策**：根据筛选结果制定买入和卖出策略。  

##### 4.2 CANSLIM策略的数学模型  
股票筛选的数学模型如下：  
$$ \text{筛选条件} = \begin{cases}  
\text{当前市场环境为上升趋势} & \text{且} \\  
\text{市盈率低于行业平均水平} & \text{且} \\  
\text{市净率低于行业平均水平} & \text{且} \\  
\text{内部强度高于行业平均水平} & \text{且} \\  
\text{市场宽度为强市}  
\end{cases} $$

class Investor:
    def __init__(self, name, strategy):
        self.name = name
        self.strategy = strategy

class Stock:
    def __init__(self, symbol, price, pe, pb, internal_strength):
        self.symbol = symbol
        self.price = price
        self.pe = pe
        self.pb = pb
        self.internal_strength = internal_strength

class Market:
    def __init__(self, index, trend, width):
        self.index = index
        self.trend = trend
        self.width = width

class CanSlmStrategy:
    def screen_stocks(self, stocks, market):
        screened = []
        for stock in stocks:
            if (market.trend == 'up' and 
                stock.pe < 15 and 
                stock.pb < 2 and 
                stock.internal_strength > 60 and 
                market.width == 'strong'):
                screened.append(stock)
        return screened

# 示例使用
investor = Investor("John", CanSlmStrategy())
market = Market("DJI", "up", "strong")
stocks = [
    Stock("AAPL", 150, 14, 1.8, 70),
    Stock("MSFT", 100, 12, 1.5, 65),
    Stock("GOOGL", 250, 16, 2.0, 60)
]

screened = investor.strategy.screen_stocks(stocks, market)

import pandas as pd
import numpy as np

def calculate_pe(stock_price, earnings_per_share):

def calculate_pb(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

# 示例数据

    'price': [150, 100, 250],
    'earnings_per_share': [4.5, 3.5, 7.5],
