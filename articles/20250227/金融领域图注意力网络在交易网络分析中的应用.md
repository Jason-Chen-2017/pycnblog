### 3.2.2 核心代码
```python
import dgl
import torch

def compute_attention(graph, h):
    # 计算注意力权重
    Q = h
    K = h
    attention_weights = torch.softmax(torch.mm(Q, K.T), dim=-1)
    return attention_weights
```
