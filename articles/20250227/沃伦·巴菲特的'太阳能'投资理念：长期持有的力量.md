### 第4章: 数学模型与公式

#### 4.1 价值评估公式
- 4.1.1 市盈率的计算
  - 公式：市盈率 = 市场价 / 每股收益（Earnings Per Share, EPS）
  - 示例：某企业股票价格为50元，每股收益为5元，则市盈率为10倍。
- 4.1.2 市净率的计算
  - 公式：市净率 = 市场价 / 每股净资产（Book Value Per Share, BVPS）
  - 示例：某企业股票价格为40元，每股净资产为20元，则市净率为2倍。
- 4.1.3 股息率的计算
  - 公式：股息率 = 每股股息（Dividends Per Share, DPS） / 市场价
  - 示例：某企业股息为2元，股票价格为50元，则股息率为4%。

#### 4.2 投资决策模型
- 4.2.1 现金流折现模型
  - 公式：内含价值 = 现金流的现值之和
  - 示例：假设某企业未来5年的现金流分别为100, 120, 140, 160, 180万元，折现率8%，计算内含价值：
    - PV1 = 100 / (1.08)^1 = 92.59
    - PV2 = 120 / (1.08)^2 = 102.08
    - PV3 = 140 / (1.08)^3 = 113.43
    - PV4 = 160 / (1.08)^4 = 124.34
    - PV5 = 180 / (1.08)^5 = 134.89
    - 内含价值 = 92.59 + 102.08 + 113.43 + 124.34 + 134.89 = 567.33万元
- 4.2.2 内部收益率的计算
  - 公式：内部收益率（IRR）是使净现值为零的折现率。
  - 示例：某项目初始投资100万元，未来5年的现金流分别为20, 30, 40, 50, 60万元，计算IRR。
- 4.2.3 净现值的计算
  - 公式：净现值（NPV）= 现金流入的现值之和 - 初始投资
  - 示例：某项目初始投资500万元，未来5年的现金流分别为150, 180, 200, 220, 240万元，折现率10%，计算NPV。
    - PV1 = 150 / (1.10)^1 = 136.36
    - PV2 = 180 / (1.10)^2 = 149.79
    - PV3 = 200 / (1.10)^3 = 150.26
    - PV4 = 220 / (1.10)^4 = 151.46
    - PV5 = 240 / (1.10)^5 = 147.28
    - 总现值 = 136.36 + 149.79 + 150.26 + 151.46 + 147.28 = 735.15万元
    - NPV = 735.15 - 500 = 235.15万元
