## 第三部分: 算法原理讲解

### 第5章: LLM与搜索算法的数学模型

#### 5.1 LLM的数学模型
- **Transformer模型结构**：包含编码器和解码器，处理序列数据。
- **注意力机制公式**：计算词与词之间的相关性。
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

#### 5.2 高级搜索算法的数学模型
- **向量空间模型**：将文本转换为向量表示。
- **BM25算法公式**：
$$\text{score}(d, q) = \log\left(1 + \frac{\text{freq}(q, d)}{\text{avgdl}}\right) \times \text{IDF}(q)$$

#### 6.2 核心代码实现
```python
def bm25_score(query, doc):
    import math
    k = 1.5
    b = 0.75
    avgdl = 100  # 假设平均文档长度
    freq = doc.count(query)
    return (math.log(1 + (freq / avgdl) * k)) * (1 - b + b * len(doc) / avgdl)
```
