### 第2章: 宏观经济分析的核心概念与模型

#### 2.1 宏观经济指标与分析方法
- **2.1.1 GDP、CPI、失业率等核心指标**
  - GDP：衡量一个国家或地区的经济规模。
  - CPI：衡量通货膨胀水平。
  - 失业率：反映就业市场的情况。
- **2.1.2 宏观经济分析的主要方法**
  - 横截面分析：比较不同经济体在同一时间点的经济表现。
  - 时间序列分析：研究经济指标随时间的变化趋势。

#### 2.2 宏观经济模型与理论
- **2.2.1 IS-LM模型**
  - IS曲线：产品市场均衡时的利率与收入关系。
  - LM曲线：货币市场均衡时的利率与收入关系。
  - $$ IS: Y = C + I + G + X - M $$
  - $$ LM: M = L(i) = kY - hi $$
- **2.2.2 AD-AS模型**
  - AD曲线：总需求曲线。
  - AS曲线：总供给曲线。
  - $$ AD: Y = Y_d $$
  - $$ AS: Y = Y_s $$

  import requests
  from bs4 import BeautifulSoup

  def fetch_data(url):
      response = requests.get(url)
      soup = BeautifulSoup(response.text, 'html.parser')
      data = []
      for item in soup.find_all('div', class_='data-item'):
          data.append({
              'indicator': item.find('span', class_='indicator').text,
              'value': float(item.find('span', class_='value').text)
          })
      return data
  ```

- **5.2.2 知识图谱构建代码实现**

  from networkx import Graph

  def build_knowledge_graph(data):
      graph = Graph()
      for item in data:
          graph.add_node(item['indicator'])
          graph.add_node(str(item['value']))
          graph.add_edge(item['indicator'], str(item['value']))
      return graph
  ```
