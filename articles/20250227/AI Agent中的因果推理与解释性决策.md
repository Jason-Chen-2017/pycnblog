#### 4.3 因果推理的算法流程
- 4.3.1 因果推理的步骤

- 4.3.3 因果推理的代码实现
  - Python代码示例：
  ```python
  def causal_inference(data, treatment, outcome):
      treated = data[data[treatment] == 1][outcome].mean()
      control = data[data[treatment] == 0][outcome].mean()
      ate = treated - control
      return ate
  ```
