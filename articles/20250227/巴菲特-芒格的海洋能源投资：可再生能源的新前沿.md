### 第1章：巴菲特与芒格的投资理念

#### 1.1 巴菲特与芒格的投资哲学

##### 1.1.1 巴菲特的价值投资理念
巴菲特的价值投资理念强调长期持有优质资产，注重公司的基本面分析，寻找具有持续竞争优势和良好管理团队的企业。他的投资哲学可以用以下几点概括：
1. **安全边际**：买入价格低于内在价值的股票，确保有足够的安全空间。
2. **长期视角**：关注企业的长期盈利能力，而非短期市场波动。
3. **集中投资**：将资金集中在少数优质资产上，以减少风险并提高回报。

##### 1.1.2 芒格的多元思维模型
芒格提倡多元思维模型，强调通过多个学科的交叉视角来理解问题。他的投资哲学包括以下几个关键点：
1. **逆向思维**：寻找市场上的非共识机会，避免 crowd-think。
2. **风险管理**：优先考虑如何避免重大损失，而不是追求最大收益。
3. **长期视角**：与巴菲特相似，芒格也强调长期投资，注重企业的持续价值创造。

##### 1.1.3 两人投资理念的结合与互补
巴菲特和芒格的投资理念在多个方面是互补的。巴菲特注重企业的内在价值和安全边际，而芒格则强调风险管理和社会系统的复杂性。两者的结合使他们能够在复杂多变的市场中做出更明智的投资决策。

#### 1.2 海洋能源的潜力与挑战

##### 1.2.1 海洋能源的定义与分类
海洋能源是指从海洋环境中获取的能量，主要包括以下几种类型：
- **潮汐能**：利用潮汐的涨落产生的能量。
- **波浪能**：利用海浪的运动产生的能量。
- **海流能**：利用海水的流动产生的能量。
- **温差能**：利用海洋表层和深层水温差异产生的能量。

##### 1.2.2 海洋能源的优势与劣势
海洋能源的优势在于其可预测性、分布广泛性和环保性。然而，其劣势也显而易见，包括技术难度大、成本高、市场接受度低等问题。

##### 1.2.3 可再生能源市场的未来趋势
随着全球能源需求的增长和对气候变化的关注，可再生能源市场正以惊人的速度增长。海洋能源作为可再生能源的重要组成部分，其市场潜力巨大。

### 第3章：海洋能源的投资评估模型

#### 3.1 投资评估的核心指标

##### 3.1.1 项目收益率的计算
项目收益率是衡量投资回报的重要指标。常用的收益率指标包括内部收益率（IRR）和净现值（NPV）。

##### 3.1.2 项目风险的评估
项目风险包括技术风险、市场风险和政策风险。投资者需要综合考虑这些因素，制定合理的风险管理策略。

##### 3.1.3 项目周期与回报周期的分析
项目周期和回报周期是评估投资的重要维度。长期项目需要考虑资金的时间价值和政策变化的影响。

#### 3.2 海洋能源投资的数学模型

##### 3.2.1 净现值（NPV）公式
$$
NPV = \sum_{t=0}^{n} \frac{CF_t}{(1+r)^t}
$$
其中，$CF_t$是第$t$年的现金流，$r$是折现率，$n$是项目周期。

##### 3.2.2 内部收益率（IRR）公式
$$
IRR = r \text{ 使得 } NPV = 0
$$
内部收益率是使净现值为零的折现率，反映了项目的盈利能力。

#### 5.2 核心实现源代码
以下是投资评估的Python代码示例：
```python
import numpy as np
import pandas as pd

def calculate_npv(cash_flows, discount_rate):
    return np.npv(discount_rate, *cash_flows)

def calculate_irr(cash_flows):
    return np.irr(cash_flows)

# 示例数据
cash_flows = [-1000, 500, 600, 700]
discount_rate = 0.1

npv = calculate_npv(cash_flows, discount_rate)
irr = calculate_irr(cash_flows)

print(f"NPV: {npv}")
print(f"IRR: {irr}")
```
