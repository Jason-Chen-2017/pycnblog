## 第一部分：系统性风险与图神经网络概述

### 第1章：系统性风险的定义与特征

#### 1.1 系统性风险的定义与特征

系统性风险是指由于金融系统中某些关键机构或市场的失败，可能导致整个金融体系崩溃的风险。其核心特征包括：

- **系统性**：影响范围广泛，波及整个金融体系。
- **传染性**：风险从一个机构或市场传导至另一个机构或市场。
- **复杂性**：涉及多层次、多维度的关联关系。

#### 1.2 图神经网络的定义与特点

图神经网络（Graph Neural Networks, GNNs）是一种能够处理图结构数据的深度学习模型。其特点包括：

- **节点表示**：通过聚合节点及其邻居的信息，生成节点的低维表示。
- **全局视角**：能够捕捉图中节点之间的复杂关系。
- **可解释性**：模型的输出可以通过图结构进行解释。

#### 1.3 系统性风险与图神经网络的结合

图神经网络在金融领域的优势在于其能够处理复杂的金融网络结构，并通过深度学习技术捕捉系统性风险的潜在传播路径。

## 第二部分：图神经网络的基本原理

### 第2章：图论基础与神经网络原理

#### 2.1 图论基础

图由节点（顶点）和边组成，边表示节点之间的关系。在金融领域，节点可以表示为金融机构或资产，边可以表示为它们之间的交易或关联。

#### 2.2 神经网络基础

神经网络是一种模拟人脑结构和功能的计算模型，包含输入层、隐藏层和输出层。其核心是通过权重调整和激活函数，实现数据的非线性变换。

#### 2.3 图神经网络的核心原理

图神经网络通过聚合节点及其邻居的信息，生成节点的表示。其数学模型可以表示为：

$$ h_i^{(l+1)} = \sigma(A h_i^{(l)} + b) $$

其中，$A$ 是图的邻接矩阵，$h_i^{(l)}$ 是节点 $i$ 在第 $l$ 层的表示，$\sigma$ 是激活函数。

import numpy as np
from tensorflow.keras import layers, Model

def build_graph_net(input_dim):
    input_layer = layers.Input(shape=(input_dim,))
    dense_layer = layers.Dense(16, activation='relu')(input_layer)
    output_layer = layers.Dense(1, activation='sigmoid')(dense_layer)
    model = Model(inputs=input_layer, outputs=output_layer)
    model.compile(optimizer='adam', loss='binary_crossentropy')
    return model

model = build_graph_net(input_dim=100)
model.summary()
