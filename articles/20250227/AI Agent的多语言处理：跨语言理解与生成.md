### 5.2 系统核心实现

#### 5.2.1 多语言翻译实现
- **代码示例**：
  ```python
  from transformers import MarianMTModel, MarianTokenizer

  # 初始化翻译器
  tokenizer = MarianTokenizer.from_pretrained("Helsinki-NLP/marian-en-de")
  model = MarianMTModel.from_pretrained("Helsinki-NLP/marian-en-de")

  # 翻译函数
  def translate(text):
      inputs = tokenizer(text, return_tensors="pt")
      outputs = model.generate(**inputs)
      return tokenizer.decode(outputs[0], skip_special_tokens=True)
  ```

#### 5.2.2 跨语言生成实现
- **代码示例**：
  ```python
  from transformers import AutoTokenizer, AutoModelForCausalLM

  # 初始化生成器
  tokenizer = AutoTokenizer.from_pretrained("facebook/m2o-chat")
  model = AutoModelForCausalLM.from_pretrained("facebook/m2o-chat")

  # 生成函数
  def generate(text, target_lang):
      inputs = tokenizer(text, return_tensors="pt", language=target_lang)
      outputs = model.generate(**inputs)
      return tokenizer.decode(outputs[0], skip_special_tokens=True)
  ```
