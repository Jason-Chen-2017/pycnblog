### 第1章：经济周期与投资概述

#### 1.1 经济周期的基本概念

经济周期是经济活动波动的规律性表现，通常包括繁荣、衰退、萧条和复苏四个阶段。每个阶段的特点和投资机会不同，投资者需根据周期变化调整策略。

#### 1.2 巴菲特投资理念的核心要素

巴菲特的价值投资理念强调长期持有优质资产，关注企业的基本面，寻找具有持续竞争优势和合理估值的企业。

#### 1.3 数字经济周期的特点

数字经济周期与传统经济周期不同，其波动性更大，受技术进步和创新的影响更深。投资者需关注数字化转型带来的机会和挑战。

```python
import pandas as pd
import numpy as np

# 示例：计算企业的价值
def calculate_intrinsic_value(ticker):
    # 获取财务数据
    data = pd.read_csv(f'{ticker}.csv')
    # 计算ROE
    roe = data['ROE'].mean()
    # 计算市盈率
    pe = data['PE'].mean()
    # 计算内在价值
    intrinsic_value = (roe * 10) / (pe / 20)
    return intrinsic_value

print(calculate_intrinsic_value('AAPL'))
```
