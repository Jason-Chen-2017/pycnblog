### 3.2.2 Python代码实现
```python
import numpy as np

# 定义状态转移矩阵
transition_matrix = np.array([
    [0.3, 0.5, 0.2],
    [0.4, 0.2, 0.4],
    [0.1, 0.3, 0.6]
])

# 初始化当前状态概率分布
current_state = np.array([1, 0, 0])

# 计算下一步状态
next_state = np.dot(current_state, transition_matrix)

print("当前状态:", current_state)
print("下一步状态:", next_state)
```

### 3.2.3 数学模型与公式
$$ P_{n+1} = P_n \times T $$

其中，$P_n$ 是当前状态概率向量，$T$ 是状态转移矩阵。
