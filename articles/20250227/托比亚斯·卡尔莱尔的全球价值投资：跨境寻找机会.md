## 第一部分：价值投资的全球视角

### 第1章：价值投资概述

#### 1.1 价值投资的定义与核心理念

- **价值投资的定义**
  价值投资是一种以基本面分析为基础的投资策略，旨在通过识别市场定价低于其内在价值的证券来实现长期收益。

- **价值投资的核心理念**
  托比亚斯·卡尔莱尔强调购买低于内在价值的资产，关注企业的长期竞争优势和可持续盈利能力。核心理念包括：
  1. 安全边际：购买价格远低于内在价值，以降低风险。
  2. 时间的朋友们：长期持有优质资产，复利效应带来收益。

- **价值投资的历史发展**
  价值投资起源于20世纪初，代表人物包括本杰明·格雷厄姆和戴维·多德。卡尔莱尔继承并发展了这一理念，强调全球视角下的投资机会。

#### 1.2 全球投资环境分析

- **全球经济与市场的多样性**
  全球市场包括发达国家和发展中国家，各市场特点不同，投资者需根据经济周期和市场特性调整策略。

- **跨国投资的机会与挑战**
  跨国投资可以分散风险，但需应对汇率波动、法律差异和文化差异等挑战。

- **价值投资在不同市场的适用性**
  某些市场可能被低估，提供价值投资机会。例如，新兴市场可能存在更多低价优质资产。

#### 1.3 价值投资与其他投资策略的对比

- **对比技术分析与基本面分析**
  技术分析侧重价格和成交量，而价值投资关注基本面，适合长期投资者。

## 第二部分：核心概念与分析框架

### 第2章：核心概念与分析框架

#### 2.1 核心概念解析

- **内在价值**
  内在价值是基于企业基本面计算的理论价值，与市场定价无关。公式：$IV = \sum_{t=1}^{\infty} \frac{CF_t}{(1 + r)^t}$，其中CF_t为第t年的现金流，r为折现率。

- **安全边际**
  安全边际=内在价值-市场价格，确保投资的安全性。例如，若内在价值为$50，市场价格为$40，安全边际为$10。

- **竞争优势**
  企业竞争优势包括成本优势、技术壁垒和品牌效应等，决定其长期盈利能力。

#### 2.2 概念对比表格

| 概念         | 特征                           |
|--------------|--------------------------------|
| 内在价值     | 理论价值，需通过分析计算       |
| 安全边际     | 市场价格与内在价值的差额       |
| 竞争优势     | 影响企业长期盈利能力           |

## 第三部分：数学模型与算法原理

### 第3章：数学模型与算法原理

#### 3.1 DCF模型的讲解

- **DCF模型简介**
  DCF模型通过将未来现金流折现计算内在价值。公式：$$IV = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$，其中TV为终值。

- **DCF模型的应用**
  以某公司为例，假设未来5年现金流分别为100、120、140、160、180万元，折现率r=10%。计算每一年的现值并求和。

#### 3.2 其他估值模型的对比

- **对比PE、PB和EV/EBITDA**
  PE=股价/每股收益，PB=股价/每股净资产，EV/EBITDA=企业价值/息税折旧及摊销前利润。每种模型适用于不同情况。

#### 3.3 Python代码实现

- **DCF模型代码示例**
  ```python
  def dcf_valuation(cash_flows, discount_rate, terminal_value):
      present_value = 0
      for t, cf in enumerate(cash_flows):
          if t == 0:
              continue
          present_value += cf / (1 + discount_rate) ** t
      present_value += terminal_value / (1 + discount_rate) ** len(cash_flows)
      return present_value

  cash_flows = [100, 120, 140, 160, 180]
  discount_rate = 0.10
  terminal_value = 200
  iv = dcf_valuation(cash_flows, discount_rate, terminal_value)
  print(f"内在价值为：${iv:.2f}")
  ```
