## 第一部分：行为金融学与价值投资的背景介绍

### 第1章：行为金融学的起源与发展

#### 1.1 行为金融学的起源
- 传统金融学的局限性：假设投资者是理性的，但现实中投资者常常受情绪影响。
- 行为金融学的提出：结合心理学和金融学，研究投资者行为偏差。
- 核心假设：投资者是有限理性的，且存在认知和情绪偏差。

#### 1.2 价值投资的基本概念
- 价值投资：寻找被市场低估的股票，长期持有，等待价值回归。
- 核心理念：安全边际，即购买价格低于内在价值。
- 历史发展：格雷厄姆和多德的理论，巴菲特的实践。

#### 1.3 行为金融学与价值投资的结合
- 行为偏差如何影响价值投资：投资者可能低估或高估股票，导致错误决策。
- 情绪对价值投资策略的影响：市场恐慌时买入低估股票，贪婪时卖出高估股票。
- 行为金融学对价值投资策略的启示：利用行为偏差，寻找市场错误定价的机会。

```python
import pandas as pd

def calculate_emotion_index(data):
    buy_signals = data['buy'].sum()
    sell_signals = data['sell'].sum()
    total_signals = buy_signals + sell_signals
    if total_signals == 0:
        return 0
    emotion_index = (buy_signals - sell_signals) / total_signals
    return emotion_index

# 示例数据
data = pd.DataFrame({
    'buy': [100, 200],
    'sell': [50, 30]
})
index = calculate_emotion_index(data)
print(f"情绪指数为：{index}")
```
