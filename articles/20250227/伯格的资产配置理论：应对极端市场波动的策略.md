## 第一部分: 伯格的资产配置理论基础

### 第1章: 资产配置与伯格的理论概述

#### 1.1 资产配置的基本概念

##### 1.1.1 资产配置的定义
资产配置是指将资金分配到不同资产类别（如股票、债券、房地产等）以实现投资目标的过程。它是投资组合管理的核心，旨在平衡风险与收益。

##### 1.1.2 资产配置的重要性
资产配置帮助投资者分散风险，避免过度依赖单一资产类别，同时优化投资回报。在不同市场环境下，合理的资产配置能够稳定投资组合的表现。

##### 1.1.3 资产配置的分类与特点
资产配置主要分为战略配置和战术配置。战略配置注重长期目标，而战术配置则根据市场变化进行短期调整。

#### 1.2 伯格的资产配置理论

##### 1.2.1 理论的提出背景
20世纪70年代，伯格在《机构投资者与基金组合管理》中提出资产配置理论，强调长期投资和分散化的重要性。

##### 1.2.2 理论的核心思想
伯格认为，资产配置应基于长期的经济周期，通过分散化投资降低风险。他提出的核心公式为：

$$ \text{预期收益} = \sum_{i=1}^{n} w_i \times r_i $$

其中，\( w_i \) 是资产 \( i \) 的权重，\( r_i \) 是其预期收益率。

##### 1.2.3 理论的适用范围与边界
伯格理论适用于机构投资者和个人投资者，特别适合长期投资策略。但在极端市场波动下，需结合战术调整。

### 第2章: 伯格理论的核心概念与联系

#### 2.1 核心概念原理

##### 2.1.1 风险调整后收益
风险调整后收益通过夏普比率衡量：

$$ \text{夏普比率} = \frac{E[r_i - r_f]}{\sigma_i} $$

其中，\( E[r_i - r_f] \) 是资产的超额预期收益，\( \sigma_i \) 是其标准差。

##### 2.1.2 分散化投资
分散化通过投资不同资产降低非系统性风险。根据现代投资组合理论，最优组合由有效前沿界定。

##### 2.1.3 资产类别选择
伯格强调选择具有长期增长潜力的资产类别，如股票和债券，而非频繁交易。

#### 3.2 算法实现代码

```python
import numpy as np

def calculate_sharpe_ratio(expected_returns, volatility):
    risk_free_rate = 0.05
    excess_returns = expected_returns - risk_free_rate
    sharpe_ratio = excess_returns / volatility
    return sharpe_ratio

# 示例数据
assets = ['股票', '债券', '房地产']
weights = [0.6, 0.3, 0.1]
returns = [0.12, 0.08, 0.06]
volatilities = [0.2, 0.1, 0.15]

# 计算夏普比率
sharpe_ratios = {}
for i in range(len(assets)):
    sr = calculate_sharpe_ratio(returns[i], volatilities[i])
    sharpe_ratios[assets[i]] = sr

print("夏普比率:", sharpe_ratios)
```

import numpy as np

def optimize_portfolio(returns, cov_matrix):
    n = len(returns)
    inv_cov = np.linalg.inv(cov_matrix)
    weights = inv_cov @ np.ones(n) / (np.ones(n) @ inv_cov @ np.ones(n))
    return weights

# 示例数据
returns = np.array([0.12, 0.08, 0.06])
cov_matrix = np.array([
    [0.04, 0.01, 0.02],
    [0.01, 0.01, 0.01],
    [0.02, 0.01, 0.04]
])
weights = optimize_portfolio(returns, cov_matrix)
print("最优权重:", weights)
