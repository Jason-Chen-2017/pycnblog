## 第2章: 数学期望的基本原理

### 2.1 概率论基础

#### 2.1.1 概率的基本概念

概率是衡量某件事情发生的可能性，范围在0到1之间。例如，掷一枚公平的硬币，正面向上的概率为0.5。

#### 2.1.2 概率的加法法则与乘法法则

概率的加法法则：互斥事件的概率相加。例如，事件A和事件B互斥，P(A或B) = P(A) + P(B)。

概率的乘法法则：独立事件的概率相乘。例如，事件A和事件B独立，P(A且B) = P(A) * P(B)。

#### 2.1.3 条件概率与贝叶斯定理

条件概率是指在已知某个事件发生的条件下，另一个事件发生的概率。贝叶斯定理用于更新基于新信息的概率，公式为：

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

---

### 2.2 数学期望的定义与计算

#### 2.2.1 数学期望的定义

数学期望是概率分布中各个可能值乘以其概率的和，用于衡量随机变量的平均值。公式为：

$$E[X] = \sum_{i=1}^{n} x_i \cdot P(X = x_i)$$

#### 2.2.2 离散型随机变量的期望计算

例如，掷骰子的期望值为：

$$E[X] = \frac{1 + 2 + 3 + 4 + 5 + 6}{6} = 3.5$$

#### 2.2.3 连续型随机变量的期望计算

对于正态分布，期望值即为分布的均值。

---

### 2.3 投资决策中的概率分布

#### 2.3.1 常见的概率分布类型

- **正态分布**：常用于描述资产的收益率。
- **二项分布**：适用于只有两种结果的情况，如成功或失败。
- **泊松分布**：适用于事件发生的次数，如违约次数。

#### 2.3.2 正态分布与投资收益的关系

正态分布常用于描述资产收益率，但实际市场中可能存在“肥尾”现象，即极端事件的概率高于正态分布的预测。

#### 2.3.3 偏态分布与投资风险的评估

右偏分布（正偏态）表示存在较大的上行风险，左偏分布（负偏态）表示存在较大的下行风险。

## 第4章: 数学期望在投资中的实际应用

### 4.1 蒙特卡洛模拟

#### 4.1.1 蒙特卡洛模拟的原理

通过随机采样和统计分析，模拟资产在不同市场条件下的表现。

#### 4.1.2 蒙特卡洛模拟的步骤

1. 定义概率分布
2. 生成随机数
3. 计算资产收益
4. 统计结果

#### 4.1.3 Python代码实现

```python
import numpy as np

# 定义参数
n_simulations = 1000
mean_return = 0.1
std_dev = 0.2

# 生成随机数
returns = np.random.normal(mean_return, std_dev, n_simulations)

# 计算期望值
expected_return = np.mean(returns)
print(f"Expected Return: {expected_return:.2f}")
```

## 第5章: 数学模型与公式推导

### 5.1 投资组合的期望收益与风险模型

#### 5.1.1 投资组合的期望收益

$$E[R_p] = \sum_{i=1}^{n} w_i \cdot E[R_i]$$

其中，$w_i$是资产i的权重，$E[R_i]$是资产i的期望收益。

#### 5.1.2 投资组合的风险（方差）

$$Var(R_p) = \sum_{i=1}^{n} \sum_{j=1}^{n} w_i w_j Cov(R_i, R_j)$$
