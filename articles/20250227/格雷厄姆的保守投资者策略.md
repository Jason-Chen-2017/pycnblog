## 第一部分：背景与基础

### 第1章：投资的基本概念

#### 1.1 投资的基本概念

- **1.1.1 投资的定义与分类**
  - 投资是指将资金投入某种资产以期望在未来获得收益的行为。
  - 分类：股票、债券、房地产、货币市场工具等。

- **1.1.2 保守投资的定义与特点**
  - 保守投资强调本金安全和稳定收益。
  - 特点：低风险、注重价值评估、长期持有。

- **1.1.3 投资与投机的区别**
  - 投资：基于基本面分析，追求长期稳定收益。
  - 投机：基于市场波动，追求短期价差。

#### 1.2 股票市场的基本分析

- **1.2.1 股票市场的运作机制**
  - 买方和卖方在交易所进行交易，价格由供需决定。

- **1.2.2 市场波动的原因分析**
  - 经济数据、公司财报、政策变化、市场情绪等。

- **1.2.3 投资者心理**
  - 羊群效应、非理性决策、市场情绪对价格的影响。

### 第2章：保守投资者策略的背景

#### 2.1 投资者的分类

- **2.1.1 保守型投资者**
  - 低风险承受能力，追求稳定收益。

- **2.1.2 激进型投资者**
  - 高风险承受能力，追求高收益。

#### 2.2 股票市场的有效性和效率

- **2.2.1 有效市场假说**
  - 市场价格反映所有可获取的信息。

- **2.2.2 弱有效市场**
  - 价格反映历史信息，但未来信息无法预测。

## 第二部分：格雷厄姆的投资理念

### 第3章：价值投资的核心理念

#### 3.1 安全边际

- **3.1.1 安全边际的定义**
  - 购买价格低于内在价值的部分，确保投资的安全性。

- **3.1.2 安全边际的计算**
  - 使用公式：安全边际 = 内在价值 - 购买价格。

#### 3.2 防御性投资

- **3.2.1 防御性投资的定义**
  - 通过投资优质资产避免重大损失。

- **3.2.2 投资优质资产的标准**
  - 高质量公司、低市盈率、高股息率。

#### 3.3 低市盈率策略

- **3.3.1 市盈率的计算**
  - 市盈率 = 股价 / 每股收益。

- **3.3.2 低市盈率的优势**
  - 反映低估，潜在上涨空间。

#### 3.4 高股息率策略

- **3.4.1 股息率的计算**
  - 股息率 = 每股股息 / 股价。

- **3.4.2 高股息率的优势**
  - 稳定现金流，降低市场波动影响。

## 第三部分：风险管理与保守投资

### 第4章：投资组合的风险管理

#### 4.1 投资组合的风险评估

- **4.1.1 风险的来源**
  - 市场风险、流动性风险、信用风险。

- **4.1.2 风险的度量**
  - 方差、标准差、贝塔系数。

#### 4.2 分散投资的重要性

- **4.2.1 分散投资的原理**
  - 将资金分配到不同资产或行业，降低风险。

- **4.2.2 分散投资的实施**
  - 通过投资组合多样化降低特定风险。

#### 4.3 应对市场波动的策略

- **4.3.1 调整投资组合**
  - 定期重新评估和调整持仓。

- **4.3.2 保持长期视角**
  - 忽略短期波动，关注长期趋势。

  import pandas as pd
  import numpy as np
  import matplotlib.pyplot as plt

  # 下载数据
  tickers = ['AAPL', 'MSFT', 'GOOGL']
  df = yf.download(tickers, start='2020-01-01', end='2023-12-31')

  # 计算市盈率
  def calculate_pe(data):
      pe = data['Close'] / data['EPS'].mean()
      return pe.mean()

  # 筛选低市盈率股票
  low_pe = []
  for ticker in tickers:
      pe = calculate_pe(df[df['Ticker'] == ticker])
      if pe < 15:
          low_pe.append(ticker)

  # 可视化
  df['Adj Close'].plot(kind='line')
  plt.title('股价走势')
  plt.xlabel('日期')
  plt.ylabel('股价')
  plt.show()
