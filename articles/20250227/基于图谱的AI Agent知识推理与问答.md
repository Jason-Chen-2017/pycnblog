# 第3章: 算法原理

## 3.1 图遍历算法

### 3.1.1 深度优先搜索（DFS）

深度优先搜索是一种遍历算法，通过不断地深入探索一条路径，直到无法深入为止，然后回溯到上一节点，继续探索其他路径。

```python
def dfs(node):
    visited.add(node)
    for neighbor in node.neighbors:
        if neighbor not in visited:
            dfs(neighbor)
```

### 3.1.2 广度优先搜索（BFS）

广度优先搜索是一种遍历算法，通过逐层扩展节点，探索所有可能的路径。

```python
def bfs(start):
    queue = deque([start])
    visited = {start}
    while queue:
        node = queue.popleft()
        for neighbor in node.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return visited
```

### 3.1.3 图遍历算法的优化

图遍历算法的优化可以通过剪枝、缓存和并行计算等技术实现。

### 5.2.2 知识推理的实现

```python
def dfs(start, target):
    stack = [(start, [start])]
    while stack:
        node, path = stack.pop()
        if node == target:
            return path
        for neighbor in G.neighbors(node):
            if neighbor not in path:
                stack.append((neighbor, path + [neighbor]))
    return None
```
