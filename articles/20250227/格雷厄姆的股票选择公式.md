# 第一部分: 格雷厄姆的股票选择公式概述

## 第1章: 背景介绍

### 1.1 价值投资的起源

#### 1.1.1 投资的基本概念与定义

投资是指将资金投入某一领域，期望在未来获得超过初始投入的收益。投资可以分为股票、债券、房地产等多种形式，其中股票投资因其高回报潜力而备受关注。

#### 1.1.2 价值投资的兴起与发展

价值投资是一种通过深入分析企业的基本面，寻找市场价格低于其内在价值的股票的投资策略。该理念由本杰明·格雷厄姆和戴维·多德在20世纪初提出，强调安全边际和长期投资。

#### 1.1.3 格雷厄姆与巴菲特的价值投资理念

本杰明·格雷厄姆是价值投资的鼻祖，他提出了“市场先生”理论，认为市场情绪波动会影响股价，但长期来看，股价应回归其内在价值。沃伦·巴菲特师承格雷厄姆，进一步发展了价值投资理念，强调企业内在价值和长期盈利能力。

## 第2章: 核心概念与公式

### 2.1 格雷厄姆股票选择公式的核心要素

#### 2.1.1 市盈率（P/E Ratio）

市盈率是衡量股票价格是否合理的重要指标，计算公式为：
$$ \text{市盈率} = \frac{\text{股价}}{\text{每股收益}} $$

#### 2.1.2 市净率（P/B Ratio）

市净率是股价与每股净资产的比率，公式为：
$$ \text{市净率} = \frac{\text{股价}}{\text{每股净资产}} $$

#### 2.1.3 股息率（Dividend Yield）

股息率是衡量股票分红能力的指标，计算为：
$$ \text{股息率} = \frac{\text{股息支付额}}{\text{股价}} $$

#### 2.1.4 预估合理股价（Intrinsic Value）

合理股价是基于企业内在价值的评估，格雷厄姆提出：
$$ \text{合理股价} = \frac{2.5 \times \text{EPS}}{\text{长期国债收益率}} $$

---

### 2.2 格雷厄姆公式的核心公式

#### 2.2.1 公式的基本形式

格雷厄姆的股票选择公式：
$$ \text{合理股价} = \frac{2.5 \times \text{EPS}}{\text{长期国债收益率}} $$

其中，EPS为每股收益，长期国债收益率代表无风险利率。

#### 2.2.2 公式的变量解释与计算步骤

- EPS计算：净利润除以普通股股数。
- 长期国债收益率：反映市场无风险利率，通常选取长期国债的收益率。

#### 2.2.3 实例分析

假设某公司EPS为5元，长期国债收益率为4%，则合理股价为：
$$ \frac{2.5 \times 5}{0.04} = 31.25 \text{元} $$

### 5.2 核心实现源代码

```python
import pandas as pd

def calculate_intrinsic_value(df):
    df['EPS'] = df['净利润'] / df['普通股股数']
    df['合理股价'] = (2.5 * df['EPS']) / df['长期国债收益率']
    return df

# 示例数据
data = {
    '股票代码': ['A', 'B', 'C'],
    '净利润': [10, 15, 20],
    '普通股股数': [100, 200, 250],
    '长期国债收益率': [0.04, 0.05, 0.06]
}

df = pd.DataFrame(data)
result = calculate_intrinsic_value(df)
print(result)
```
