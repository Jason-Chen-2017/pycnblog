## 第一部分：芒格的"复利思维"概述

### 第1章：复利思维的核心概念

#### 1.1 复利思维的定义与特点
- 复利思维是一种通过时间和复利效应实现价值指数型增长的思维方式。
- 复利效应的核心公式：$$A = P(1 + r)^t$$，其中：
  - \( A \) 是终值
  - \( P \) 是本金
  - \( r \) 是年化增长率
  - \( t \) 是时间（年）

#### 1.2 复利思维与传统投资的区别
- **单利**：$$I = P \times r \times t$$
- **复利**：$$A = P(1 + r)^t$$

#### 1.3 复利思维在投资中的应用
- 投资的复利公式：$$A = P(1 + r)^t$$
- 投资时间越长，复利效应越显著。

### 第2章：复利思维的数学模型与公式

#### 2.1 复利计算的基本公式
- 年金公式：$$A = P \times \frac{(1 + r)^t - 1}{r}$$
- 终值公式：$$FV = PV \times (1 + r)^t$$

    amount = principal * (1 + rate) ** time
    return amount

#### 4.2 核心代码实现
```python
import numpy as np
import pandas as pd

def compound_interest_analysis(principal, rate, time):
    years = np.arange(1, time + 1)
    amounts = principal * (1 + rate) ** years
    df = pd.DataFrame({'年份': years, '金额': amounts})
    return df

# 示例
P = 10000
r = 0.05
t = 10
result = compound_interest_analysis(P, r, t)
print(result)
```

## 第五部分：复利思维的最佳实践与小结

### 第5章：最佳实践与小结

#### 5.1 复利思维的应用策略
- 长期投资：$$t \rightarrow \infty$$，复利效应最大化。
- 选择优质资产：$$r \rightarrow 最大化$$
- 风险控制：$$P \rightarrow 本金安全第一$$

#### 5.2 复利思维的注意事项
- 复利效应需要时间积累，不能急于求成。
- 风险控制是复利思维的重要组成部分。
