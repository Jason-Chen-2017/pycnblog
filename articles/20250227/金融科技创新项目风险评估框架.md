# 第3章: 风险评估算法原理

## 3.1 层次分析法（AHP）原理

层次分析法是一种常用的决策分析方法，适用于多因素决策问题。

### 3.1.1 层次分析法的步骤

1. **建立层次结构模型**：将问题分解为目标层、准则层和方案层。
2. **构造比较矩阵**：根据专家意见构造各层次的比较矩阵。
3. **计算权重**：通过一致性检验计算各层次的权重。
4. **计算综合得分**：根据权重计算各方案的综合得分，选择最优方案。

### 3.1.2 层次分析法的流程图

```mermaid
graph TD
    A(目标层) --> B(准则层)
    B --> C(方案层)
    A --> C
```

### 3.1.3 层次分析法的数学模型

$$ A = \{a_{ij}\} \quad (i,j=1,2,...,n) $$

其中，$a_{ij}$ 表示第 $i$ 个准则对第 $j$ 个方案的相对重要性。

## 3.2 层次分析法的Python实现

```python
import numpy as np

def ahp(matrix, weights):
    normalized = matrix / matrix.sum(axis=0)
    weighted = normalized * weights
    total = weighted.sum(axis=1)
    return total

# 示例
matrix = np.array([
    [1, 3, 2],
    [2, 1, 3],
    [3, 2, 1]
])
weights = np.array([0.5, 0.3, 0.2])
result = ahp(matrix, weights)
print(result)
```
