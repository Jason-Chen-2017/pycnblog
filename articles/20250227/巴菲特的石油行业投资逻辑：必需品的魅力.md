#### 1.1 石油的定义与性质
石油是一种不可再生的自然资源，广泛应用于能源、化工、交通等多个领域。其性质包括高需求弹性、价格波动大、市场集中度高等特点。

#### 1.3 石油作为必需品的战略意义
石油是全球能源的重要组成部分，具有不可替代性。其需求稳定，价格波动受多种因素影响，但长期来看，石油是必需品，具有投资价值。

### 第5章：现金流折现法的数学模型

#### 5.1 现金流折现的基本公式
$$ PV = \frac{CF}{(1 + r)^n} $$
其中，CF为现金流，r为折现率，n为时间。

#### 5.2 现金流折现的应用步骤
1. 预测未来现金流。
2. 确定折现率。
3. 计算各期现金流的现值。
4. 求和得到企业内在价值。

def calculate_intrinsic_value(cash_flow, discount_rate, period):
    iv = 0
    for i in range(period):
        iv += cash_flow[i] / (1 + discount_rate) ** (i + 1)
    return iv

# 示例数据

discount_rate = 0.1
