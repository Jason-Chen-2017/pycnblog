#### 3.2 算法实现
- 通过Python代码实现线性回归模型，预测资源价格。
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  # 示例数据
  x = np.array([1, 2, 3, 4, 5])
  y = np.array([2, 3, 5, 6, 8])

  # 训练模型
  A = np.vstack([x, np.ones(5)]).T
  θ = np.linalg.inv(A.T.dot(A)).dot(A.T.dot(y))

  # 预测结果
  y_pred = θ[0] * x + θ[1]

  # 可视化
  plt.scatter(x, y)
  plt.plot(x, y_pred, 'r')
  plt.show()
  ```

  - 通过最小二乘法优化参数，最小化预测误差平方和。
