#### 1.1.1 背景介绍
- **核心概念**：价值投资是一种以低于内在价值的价格买入优质资产的投资策略。

- **问题解决**：通过深入分析资产的内在价值，识别市场低估的机会。

## 第6章 经典案例分析

### 6.1 马克斯的债券投资案例

#### 6.1.1 案例分析

- **环境安装**：假设2008年金融危机期间，马克斯如何识别低估债券。
- **代码实现**：计算债券的内在价值与市场价格。

```python
def calculate_intrinsic_value(face_value, coupon_rate, years, discount_rate):
    present_value = 0
    for i in range(years):
        cash_flow = face_value * coupon_rate
        present_value += cash_flow / (1 + discount_rate) ** (i + 1)
    present_value += face_value / (1 + discount_rate) ** years
    return present_value

# 示例计算
face_value = 1000
coupon_rate = 0.05
years = 10
discount_rate = 0.03

intrinsic_value = calculate_intrinsic_value(face_value, coupon_rate, years, discount_rate)
print(f"内在价值：{intrinsic_value}")
```
