## 第3章: 投资成本计算的算法原理

### 3.1 约翰伯格投资成本计算算法概述

#### 3.1.1 算法的基本思想
通过分解投资成本的各个构成部分，动态调整权重，实现精准计算。

#### 3.1.2 算法的输入输出
- 输入：投资金额、投资期限、市场利率等
- 输出：总成本、各分项成本

#### 3.1.3 算法的数学模型
$$C_{total} = \sum_{i=1}^{n} w_i \cdot C_i$$
其中，$w_i$是第i项成本的权重。

### 3.3 算法实现的Python代码

#### 3.3.1 核心代码
```python
def john_berg_cost_calculation(investment, period, rate):
    initial_cost = investment
    maintenance_cost = initial_cost * 0.05 * period
    transaction_cost = initial_cost * 0.02
    opportunity_cost = initial_cost * (1 + rate/100)**period - initial_cost
    total_cost = initial_cost + maintenance_cost + transaction_cost + opportunity_cost
    return total_cost
```

#### 3.3.2 代码解读
- `investment`：初始投资金额
- `period`：投资期限（年）
- `rate`：年化利率
- `initial_cost`：初始投资成本
- `maintenance_cost`：维护成本
- `transaction_cost`：交易成本
- `opportunity_cost`：机会成本
- `total_cost`：总成本

```python
import pandas as pd

def calculate_investment_cost(investment, period, rate):
    initial_cost = investment
    maintenance_cost = initial_cost * 0.05 * period
    transaction_cost = initial_cost * 0.02
    opportunity_cost = initial_cost * ((1 + rate/100)**period - 1)
    total_cost = initial_cost + maintenance_cost + transaction_cost + opportunity_cost
    return total_cost
```
