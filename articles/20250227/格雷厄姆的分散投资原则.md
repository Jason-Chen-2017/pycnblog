## 4.1 投资组合优化算法

### 4.1.1 基于现代投资组合理论的优化算法

#### 4.1.1.1 均值-方差优化算法

##### 4.1.1.1.1 算法流程图（使用mermaid）

```mermaid
graph TD
A[开始] --> B[输入期望收益率和协方差矩阵]
B --> C[计算最优权重]
C --> D[输出最优投资组合]
D --> E[结束]
```

##### 4.1.1.1.2 算法数学模型

$$ \text{目标函数：} \quad \min_w \sigma^2(w) $$
$$ \text{约束条件：} \quad \sum_{i=1}^n w_i = 1, \quad w_i \geq 0 $$

##### 4.1.1.1.3 Python代码实现

```python
import numpy as np
from scipy.optimize import minimize

# 示例数据
n_assets = 3
returns = np.array([0.1, 0.15, 0.08])
cov_matrix = np.array([[0.04, 0.01, 0.02],
                        [0.01, 0.06, 0.015],
                        [0.02, 0.015, 0.03]])

# 定义目标函数
def portfolio_variance(weights, returns, cov_matrix):
    return (weights.T @ cov_matrix @ weights)[0, 0]

# 定义约束条件
def weight_sum(weights):
    return np.sum(weights) - 1

# 初始猜测权重
initial_weights = np.array([1/3, 1/3, 1/3])

# 使用scipy.optimize.minimize进行优化
constraints = [{'type': 'eq', 'fun': weight_sum}]
result = minimize(portfolio_variance, initial_weights, args=(returns, cov_matrix), constraints=constraints)

# 输出结果
print("最优权重：", result.x)
print("最小方差：", result.fun)
```

### 4.1.2 风险中性组合优化算法

#### 4.1.2.1 风险中性组合的概念

风险中性组合是指在给定风险水平下，预期收益最高的投资组合。

#### 4.1.2.2 风险中性组合的数学模型

$$ \max_w \mu^T w $$
$$ \text{s.t.} \quad w^T \Sigma w = \text{风险目标} $$
$$ \sum_{i=1}^n w_i = 1, \quad w_i \geq 0 $$

#### 4.1.2.3 Python代码实现

```python
import numpy as np
from scipy.optimize import minimize

# 示例数据
n_assets = 3
mu = np.array([0.1, 0.15, 0.08])
Sigma = np.array([[0.04, 0.01, 0.02],
                  [0.01, 0.06, 0.015],
                  [0.02, 0.015, 0.03]])

# 定义目标函数
def portfolio_return(weights, mu):
    return -mu.T @ weights  # 最小化负收益即最大化收益

# 定义约束条件
def portfolio_variance(weights, Sigma):
    return weights.T @ Sigma @ weights

# 初始猜测权重
initial_weights = np.array([1/3, 1/3, 1/3])

# 风险目标（例如，设定方差为0.03）
target_variance = 0.03

# 约束条件
constraints = [
    {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
    {'type': 'eq', 'fun': lambda w: portfolio_variance(w, Sigma) - target_variance}
]

# 使用scipy.optimize.minimize进行优化
result = minimize(portfolio_return, initial_weights, args=(mu,), constraints=constraints)

# 输出结果
print("最优权重：", result.x)
print("最大预期收益：", -result.fun)
```

## 4.2 分散投资组合的多目标优化

### 4.2.1 多目标优化的概念

多目标优化是指在多个目标函数之间寻找折中的最优解，例如在风险和收益之间寻找平衡点。

### 4.2.2 分散投资中的多目标优化问题

$$ \min_w \sigma^2(w) $$
$$ \max_w \mu^T w $$
$$ \text{s.t.} \quad \sum_{i=1}^n w_i = 1, \quad w_i \geq 0 $$

### 4.2.3 分散投资多目标优化的Python代码实现

```python
import numpy as np
from scipy.optimize import minimize

# 示例数据
n_assets = 3
mu = np.array([0.1, 0.15, 0.08])
Sigma = np.array([[0.04, 0.01, 0.02],
                  [0.01, 0.06, 0.015],
                  [0.02, 0.015, 0.03]])

# 定义目标函数（使用加权和）
def weighted_objective(weights, mu, Sigma, risk_weight=0.5):
    return risk_weight * (weights.T @ Sigma @ weights)[0,0] + (1 - risk_weight) * (-mu.T @ weights)

# 初始猜测权重
initial_weights = np.array([1/3, 1/3, 1/3])

# 约束条件
constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]

# 使用scipy.optimize.minimize进行优化
result = minimize(weighted_objective, initial_weights, args=(mu, Sigma, 0.5), constraints=constraints)

# 输出结果
print("最优权重：", result.x)
print("最优加权目标值：", result.fun)
```
