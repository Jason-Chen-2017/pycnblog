## 第一部分：相对价值投资的背景与基础

### 第1章：相对价值投资的概述

#### 1.1 相对价值投资的基本概念

- **投资的基本概念**：投资是通过购买资产以期望在未来获得收益或资本增值的行为。资产可以是股票、债券、房地产等。投资的核心在于识别低估或高估的资产，并在合适的价格点进行买卖。

- **相对价值投资的定义**：相对价值投资是一种投资策略，旨在通过比较同一行业或相似资产之间的相对价值，寻找被市场低估或高估的投资标的。其核心在于利用资产之间的相对定价差异，而非预测市场整体走势。

- **相对价值投资的核心要素**：
  1. **可比性**：选择在同一行业中具有可比性的资产，确保比较的合理性。
  2. **相对定价**：通过分析资产的估值指标（如市盈率、市净率等）来判断其相对价值。
  3. **市场效率**：假设市场在一定程度上是有效的，但存在短期偏差，提供套利机会。

## 第二部分：相对价值投资的核心概念与联系

### 第2章：相对价值投资的定价模型

#### 2.1 基本定价模型

- **市盈率模型（P/E Ratio）**：
  - 公式：$P/E = \frac{股票价格}{每股收益}$
  - 解释：市盈率反映了投资者对每股收益的支付意愿。低市盈率可能意味着低估，高市盈率可能意味着高估。

- **市净率模型（P/B Ratio）**：
  - 公式：$P/B = \frac{股票价格}{每股净资产}$
  - 解释：市净率适用于评估资产密集型行业（如银行、房地产），反映资产的实际价值。

- **股息率模型（Dividend Yield）**：
  - 公式：$股息率 = \frac{每股股息}{股票价格} \times 100\%$
  - 解释：股息率高的股票可能具有吸引力，但需考虑公司的盈利能力和股息支付能力。

---

#### 2.2 相对价值比率分析

- **相对市盈率分析**：
  - 比较同一行业内的公司，寻找市盈率低于行业平均水平的公司。
  - 示例：假设行业平均市盈率为15，某公司市盈率为12，可能被低估。

- **相对市净率分析**：
  - 比较同一行业的市净率，寻找市净率低于行业平均值的公司。
  - 示例：行业平均市净率为2，某公司市净率为1.8，可能被低估。

- **相对股息率分析**：
  - 比较股息率，寻找股息率显著高于行业平均水平的公司。
  - 示例：行业平均股息率为3%，某公司股息率为4%，具有吸引力。

## 第四部分：相对价值投资的数学模型

### 第4章：数学模型与公式

#### 4.1 资本资产定价模型（CAPM）

- **公式**：$$ E(r_i) = r_f + \beta_i (E(r_m) - r_f) $$
  - 解释：CAPM用于估计资产的预期收益，其中$\beta_i$是资产的系统性风险系数。

#### 4.2 阿尔法模型（APT）

- **公式**：$$ P_i = \sum \lambda_j F_j + \alpha_i $$
  - 解释：APT模型考虑多个因素对资产价格的影响，$\alpha_i$为资产的特异风险溢价。

import pandas as pd
import numpy as np

# 假设data是包含股票数据的DataFrame，columns为股票代码
def calculate_relative_value(data):
    # 计算市盈率
    pe = data['股价'] / data['每股收益']
    # 计算市净率
    pb = data['股价'] / data['每股净资产']
    # 计算股息率
    dividend_yield = data['每股股息'] / data['股价'] * 100
    # 综合评分：市盈率、市净率、股息率加权评分
    score = 0.4 * (pe.rank().min() / pe.rank().count()) + \
            0.3 * (pb.rank().min() / pb.rank().count()) + \
            0.3 * (dividend_yield.rank().min() / dividend_yield.rank().count())
    return score

# 示例应用
data = pd.read_csv('stocks.csv')
scores = calculate_relative_value(data)
top_stocks = data[scores > np.percentile(scores, 75)]
print("推荐投资标的：", top_stocks.index)
