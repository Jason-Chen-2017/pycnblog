### 第4章：资产定价模型

#### 4.1 CAPM模型

CAPM模型通过公式描述资产的预期回报率，帮助投资者评估资产的定价是否合理。

$$ E(R_i) = R_f + \beta_i (E(R_m) - R_f) $$

#### 4.2 投资组合优化

使用均值-方差优化模型构建最优投资组合，平衡风险与收益。

$$ \text{Minimize } \sigma^2 \text{ subject to } \mathbb{E}[R] = \text{Target Return} $$

                    [0.12, 0.10, 0.11]])

# 计算协方差矩阵
cov_matrix = np.cov(returns)

# 使用均值-方差优化
from scipy.optimize import minimize

def portfolio_variance(weights, covariance):
    return np.dot(weights.T, np.dot(covariance, weights))

weights = np.array([1/3, 1/3, 1/3])
minimization = minimize(portfolio_variance, weights, args=(cov_matrix,))
optimal_weights = minimization.x
