### 第3章：投资决策的数学模型

#### 3.1 资产定价模型
- **3.1.1 CAPM模型的原理与应用**
  CAPM（资本资产定价模型）用于计算股票的理论价格，公式如下：
  $$ E(R_i) = R_f + \beta_i (E(R_m) - R_f) $$
  其中，$R_f$为无风险利率，$\beta_i$为股票的贝塔系数，$E(R_m)$为市场预期回报率。
- **3.1.2 WACC的计算方法**
  WACC（加权平均成本资本）用于评估企业整体价值，公式如下：
  $$ WACC = \left( \frac{D}{V} \times W_d \times r_d \right) + \left( \frac{E}{V} \times W_e \times r_e \right) $$
  其中，$D$和$E$分别为债务和股权，$V$为企业价值，$W_d$和$W_e$分别为债务和股权的权重，$r_d$和$r_e$分别为债务和股权的成本。

#### 3.2 现金流折现模型（DCF）
- **3.2.1 自由现金流的计算**
  自由现金流公式：
  $$ FCFF = NI + NDT + DTL - WC \Delta $$
  其中，$NI$为净利润，$NDT$为非现金费用，$DTL$为折旧与摊销，$WC \Delta$为营运资本变化。
- **3.2.2 折现率的确定与影响**
  折现率通常采用WACC或资本成本，公式同上。
- **3.2.3 企业价值的评估公式**
  企业价值公式：
  $$ V = \sum_{t=1}^{n} \frac{FCFF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n} $$
  其中，$r$为折现率，$TV$为终值。

import numpy as np
import pandas as pd

def calculate_capm(rf, beta, rm):
    return rf + beta * (rm - rf)

def calculate_wacc(d, e, rd, re, tax_rate):
    wacc = (d / (d + e)) * rd * (1 - tax_rate) + (e / (d + e)) * re
    return wacc

# 示例数据
rf = 0.05
beta = 1.2
rm = 0.1
d = 50
e = 150
rd = 0.06
re = 0.12
tax_rate = 0.2

capm_return = calculate_capm(rf, beta, rm)
wacc = calculate_wacc(d, e, rd, re, tax_rate)

print(f"CAPM预期回报率: {capm_return:.2f}%")
print(f"WACC: {wacc:.2f}%")
