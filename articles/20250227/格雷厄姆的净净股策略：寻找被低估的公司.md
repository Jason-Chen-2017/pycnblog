# 第1章: 价值投资的起源与核心理念

## 1.1 价值投资的定义与特点

### 1.1.1 价值投资的定义
价值投资是一种投资策略，强调以低于资产内在价值的价格买入股票。其核心在于寻找市场价格低于内在价值的公司，长期持有，等待价值回归。

### 1.1.2 价值投资的核心特点
- **长期视角**：关注企业的长期价值，而非短期价格波动。
- **安全边际**：买入价格低于内在价值，确保有一定的安全边际。
- **逆向思维**：在市场恐慌时寻找机会，在市场疯狂时保持冷静。

### 1.1.3 价值投资与其他投资策略的区别
- **区别于成长型投资**：成长型投资注重未来增长潜力，而价值投资注重当前的低估状态。
- **区别于股息率投资**：股息率投资关注股息收益，而价值投资关注整体价值。

## 1.2 格雷厄姆与净净股策略的背景

### 1.2.1 格雷厄姆的生平简介
本杰明·格雷厄姆（Benjamin Graham）是价值投资的鼻祖，被誉为“价值投资之父”。他通过研究市场波动，提出了许多投资理论，其中包括净净股策略。

### 1.2.2 净净股策略的提出背景
在20世纪20年代，格雷厄姆发现许多公司因市场恐慌或行业低迷导致股价被低估，这为投资者提供了低价买入的机会。净净股策略应运而生，旨在通过计算公司净值，寻找市场价格低于净值的公司。

### 1.2.3 净净股策略的基本框架
- 计算公司资产净值（Net Worth）。
- 比较市场价格与净值，寻找价格低于净值的股票。

# 第2章: 净净股策略的核心概念

## 2.1 净净股策略的定义

### 2.1.1 净值计算的数学模型
$$\text{净值} = \text{资产} - \text{负债}$$

### 2.1.2 内在价值计算公式
$$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t}$$
其中，\( r \) 是折现率，\( \text{现金流}_t \) 是第 \( t \) 年的现金流。

### 2.1.3 净值比率的计算
$$\text{净值比率} = \frac{\text{市场价格}}{\text{净值}}$$

---

## 2.2 净净股策略的核心要素

### 2.2.1 股票的内在价值
内在价值是公司未来现金流的现值，是股票的合理价格。

### 2.2.2 市场价格与内在价值的差异
市场价格围绕内在价值波动，当市场价格低于内在价值时，股票被低估。

### 2.2.3 净值比率的计算公式
$$\text{净值比率} = \frac{\text{市场价格}}{\text{净值}}$$

### 2.3.1 与成长型投资的对比

### 2.3.2 与股息率投资的对比
- 股息率投资关注股息收益，而净净股策略关注整体价值。

# 第5章: 净净股策略的项目实战

## 5.1 环境安装
- 安装Python和相关库（Pandas、NumPy、Matplotlib）。
- 使用Yahoo Finance API获取股票数据。

## 5.2 核心实现源代码
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 示例数据
data = {
    '公司': ['A', 'B', 'C'],
    '资产': [100, 200, 150],
    '负债': [50, 80, 70],
    '现金流': [20, 30, 25],
    '市场价格': [50, 100, 80]
}

df = pd.DataFrame(data)

# 计算净值
df['净值'] = df['资产'] - df['负债']

# 计算内在价值（简化模型）
r = 0.1  # 折现率
df['内在价值'] = df['现金流'] / (1 + r)

# 计算净值比率
df['净值比率'] = df['市场价格'] / df['净值']

print(df)
```

## 5.3 实际案例分析
假设某公司数据如下：
- 资产：1000万元
- 负债：400万元
- 现金流：200万元
- 市场价格：300元

计算得：
- 净值 = 1000 - 400 = 600万元
- 内在价值 = 200 / 1.1 ≈ 181.82万元
- 净值比率 = 300 / 600 = 0.5

由于净值比率 < 1，该股票被低估。
