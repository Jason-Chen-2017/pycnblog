### 5.2.1 碳风险评估模型

```python
import pandas as pd

def carbon_risk_score(enterprise_data):
    # 计算碳排放强度
    emissions = enterprise_data['carbon_emissions']
    revenue = enterprise_data['revenue']
    intensity = emissions / revenue
    # 碳风险评分
    score = (intensity - intensity.min()) / (intensity.max() - intensity.min())
    return score
```
