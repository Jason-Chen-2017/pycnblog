### 2.1 价值投资的定义与特点

- **价值投资与成长投资的区别**：价值投资关注低估的价值，成长投资关注高增长的潜力。

### 2.2 格雷厄姆的价值投资体系

- **内在价值的计算方法**：通过对企业未来现金流的折现来计算内在价值。
- **股票分析的三要素**：价格、价值、市场情绪。

### 2.3 价值投资的实践原则

- **耐心与纪律在投资中的作用**：坚持投资计划，避免情绪化决策。

## 第5章: 价值投资的数学模型与算法实现

### 5.1 价值投资的数学模型
- **内在价值的计算公式**：$$ V = \frac{CF}{r - g} $$
  其中，\( V \) 为内在价值，\( CF \) 为未来现金流，\( r \) 为贴现率，\( g \) 为增长率。
- **安全边际的计算方法**：$$ \text{安全边际} = V - P $$
  其中，\( P \) 为市场价格。

### 5.2 价值投资的算法实现
```python
def calculate_intrinsic_value(cash_flows, discount_rate, growth_rate):
    return sum(cash_flows) / (discount_rate - growth_rate)

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price
```

### 5.3 投资组合优化的数学模型
- **马科维茨有效前沿模型**：通过优化投资组合的收益和风险，找到最优资产配置。
- **投资组合优化的Python实现**：
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, covariance_matrix, target_return):
    n = len(returns)
    # 目标是最小化风险
    objective = {'type': 'min', 'fun': lambda x: np.dot(x.T, np.dot(covariance_matrix, x))}
    # 约束条件：收益等于目标收益
    constraint = {'type': 'eq', 'fun': lambda x: np.dot(x.T, returns) - target_return}
    bounds = [(0, 1) for _ in range(n)]
    result = minimize(objective['fun'], np.ones(n)/n, constraints=[objective, constraint], bounds=bounds)
    return result.x
```
