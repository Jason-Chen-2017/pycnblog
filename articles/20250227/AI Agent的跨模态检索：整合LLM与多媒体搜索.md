# 第一部分: LLM与多媒体搜索的核心原理

## 2.1 大语言模型（LLM）的原理与实现
LLM基于深度学习，通过 transformer 模型处理自然语言。概率论和注意力机制是其核心，例如：

$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

## 2.2 多媒体搜索的技术基础
多媒体数据包括图像、视频和音频，其特征提取方法各异。例如，图像的特征提取使用CNN，而音频则使用STFT。
