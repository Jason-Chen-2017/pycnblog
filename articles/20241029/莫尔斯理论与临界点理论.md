##### 4.1.1 拓扑空间的基本概念

拓扑空间是一个具有拓扑性质的数学结构，它用于描述系统的几何性质。

- **定义**：设X是一个集合，T是一个包含X的子集族，如果T满足以下条件：

  - **传递性**：∀A, B, C ⊆ X，如果A ∈ T 且 B ⊆ A，则B ∈ T 且 C ⊆ B，则C ∈ T。
  - **可结合性**：∀A, B, C ⊆ X，如果A ∈ T 且 B ∈ T，则A ∪ B ∈ T。
  则称(T, X)是一个拓扑空间。

##### 4.1.2 同伦理论的基本概念

同伦理论是用于研究映射在连续变形过程中的性质。

- **定义**：设X和Y是两个拓扑空间，f和g是X到Y的两个映射，如果存在一个连续映射h:[0,1] × X → Y，满足以下条件：
  - h(0,x) = f(x)，
  - h(1,x) = g(x)，
  - h(t,x)是f和g之间的连续变形，
  则称f和g是同伦的。

##### 4.1.3 同伦映射与同伦类

同伦映射是一类保持同伦关系的映射，同伦类是同伦映射的分类。

- **定义**：设X和Y是两个拓扑空间，f和g是X到Y的两个映射，如果存在一个同伦映射h:[0,1] × X → Y，使得h(t,x)是f和g之间的连续变形，则称f和g是同伦的。
- **同伦类**：对于给定的映射f:X → Y，所有与f同伦的映射构成的集合称为f的同伦类，记为[f]。

##### 4.1.4 同伦群

同伦群是用于分类同伦映射的工具。

- **定义**：设X和Y是两个拓扑空间，H(X,Y)是由所有从X到Y的同伦映射构成的集合，对于任意两个同伦映射f, g ∈ H(X,Y)，定义它们之间的运算为：

- **同伦群**：同伦群是指H(X,Y)在加法运算下的结构，记为H(X,Y)。

##### 4.1.5 同伦序列

同伦序列是用于描述同伦映射的序列。
