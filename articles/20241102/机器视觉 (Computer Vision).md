### 数学公式示例

```markdown
## 数学模型

机器视觉中的特征提取通常涉及以下数学模型：

$$
特征向量 = W \cdot 输入图像 + b
$$

其中，$W$ 为权重矩阵，$b$ 为偏置项。

在卷积神经网络中，卷积操作可以表示为：

$$
特征图 = \sum_{i=1}^{k} (W_i \cdot 输入特征图) + b_i
$$

这里，$W_i$ 和 $b_i$ 分别表示卷积核权重和偏置项。
```

## 项目实战：实时行人检测系统

### 开发环境搭建

- 操作系统：Ubuntu 20.04
- 编程语言：Python 3.8
- 深度学习框架：TensorFlow 2.5
- 其他依赖：OpenCV 4.5.3, NumPy 1.21.2

### 源代码实现

```python
import cv2
import numpy as np
import tensorflow as tf

# 加载预训练的行人检测模型
model = tf.keras.models.load_model('path/to/行人检测模型')

# 定义视频流
cap = cv2.VideoCapture(0)

while True:
    # 读取视频帧
    ret, frame = cap.read()

    # 将帧缩放到模型期望的大小
    input_size = (224, 224)
    frame = cv2.resize(frame, input_size)

    # 将帧转换为模型可接受的格式
    frame = frame / 255.0
    frame = np.expand_dims(frame, axis=0)

    # 进行行人检测
    predictions = model.predict(frame)

    # 提取行人区域
    for i in range(predictions.shape[1]):
        if predictions[0, i] > 0.5:
            # 获取行人边界框
            xmin, ymin, xmax, ymax = i

            # 在原图上绘制边界框
            cv2.rectangle(frame, (xmin, ymin), (xmax, ymax), (0, 0, 255), 2)

    # 显示结果
    cv2.imshow('行人检测', frame)

    # 按下 'q' 键退出
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

# 释放视频流
cap.release()
cv2.destroyAllWindows()
```

### 代码解读与分析

- 模型加载与预处理：使用 TensorFlow 加载预训练的行人检测模型，并将视频帧缩放到模型期望的大小。
- 预测与边界框提取：对每个输入帧进行行人检测，提取行人区域，并在原图上绘制边界框。
- 实时展示与交互：通过 OpenCV 显示实时行人检测结果，并在按下 'q' 键时退出程序。

该系统可以实现实时行人检测，有助于监控和安防等领域。
