### 核心算法原理讲解

#### 集体智慧与深空探测任务的规划与优化

##### 算法原理

1. **任务规划与优化算法**：
   - **目标函数**：最小化任务完成时间，最大化任务成功率。
   - **约束条件**：任务之间资源冲突、时间限制、探测目标优先级等。

2. **多目标优化算法**：
   - **加权求和法**：将多个目标合并为一个综合目标函数。
   - **Pareto前端法**：寻找Pareto最优解集，平衡多个目标之间的冲突。

3. **遗传算法**：
   - **编码方式**：使用二进制编码、实数编码等。
   - **适应度函数**：根据任务完成情况计算个体的适应度。
   - **交叉、变异操作**：产生新的个体，用于迭代优化。

4. **粒子群优化算法**：
   - **个体速度和位置更新**：基于个体历史最优解和全局最优解进行更新。
   - **全局搜索和局部搜索的平衡**：通过调整惯性权重实现。

### 数学模型和数学公式

#### 集体智慧在探测任务优化中的数学模型

##### 公式与推导

1. **目标函数**：
   $$\min T(S) = \sum_{i=1}^{n} t_i$$
   - $T(S)$：任务完成时间
   - $t_i$：任务$i$的完成时间

2. **约束条件**：
   $$\begin{cases}
   R_j \geq r_j(S) & \text{资源约束} \\
   S_j \leq s_j(S) & \text{时间约束} \\
   P_i \geq p_i(S) & \text{优先级约束}
   \end{cases}$$
   - $R_j$：资源总量
   - $r_j(S)$：任务$i$对资源$j$的需求
   - $S_j$：任务开始时间
   - $s_j(S)$：任务$i$的时间限制
   - $P_i$：任务优先级
   - $p_i(S)$：任务$i$的优先级值

3. **适应度函数**：
   $$f(S) = \frac{T(S)}{\sum_{i=1}^{n} t_i \cdot w_i}$$
   - $w_i$：任务$i$的权重

##### 2. 代码实现

```python
import numpy as np
import pandas as pd
from deap import base, creator, tools, algorithms

# 初始化参数
n_tasks = 3
task_data = [
    {'name': 'A', 'cpu_time': 5, 'mem': 10, 'priority': 1},
    {'name': 'B', 'cpu_time': 10, 'mem': 30, 'priority': 2},
    {'name': 'C', 'cpu_time': 15, 'mem': 50, 'priority': 3}
]
resource_limit = {'cpu_time': 1000, 'mem': 200}
time_limit = [10, 15, 20]

# 定义适应度函数
def fitness_function(individual):
    total_time = sum(individual)
    resource_usage = sum([task['cpu_time'] * individual[i] for i, task in enumerate(task_data)]) + sum([task['mem'] * individual[i] for i, task in enumerate(task_data)])
    return -(total_time + resource_usage),

creator.create("FitnessMax", base.Fitness, weights=(-1.0,))  # 最小化适应度
creator.create("Individual", list, fitness=creator.FitnessMax)

toolbox = base.Toolbox()
toolbox.register("attr_bool", np.random.randint, 0, 2)
toolbox.register("individual", tools.initRepeat, creator.Individual, toolbox.attr_bool, n_tasks)
toolbox.register("population", tools.initRepeat, list, toolbox.individual)
toolbox.register("evaluate", fitness_function)
toolbox.register("mate", tools.cxTwoPoint)
toolbox.register("mutate", tools.mutFlipBit, indpb=0.05)
toolbox.register("select", tools.selTournament, tournsize=3)

# 运行算法
pop = toolbox.population(n=50)
NGEN = 100
for gen in range(NGEN):
    offspring = algorithms.varAnd(pop, toolbox, cxpb=0.5, mutpb=0.2)
    fits = toolbox.map(toolbox.evaluate, offspring)
    for fit, ind in zip(fits, offspring):
        ind.fitness.values = fit
    pop = toolbox.select(offspring, k=len(pop))
    top_fitness = max(ind.fitness.values for ind in pop)
    print(f"Generation {gen}: Best Fitness = {top_fitness}")

# 输出最优解
best_ind = tools.selBest(pop, k=1)[0]
print("Best individual is:", best_ind)
print("Fitness:", best_ind.fitness.values[0])

# 可视化
import matplotlib.pyplot as plt

plt.scatter([ind.fitness.values[0] for ind in pop], [gen for gen in range(NGEN)])
plt.xlabel('Fitness')
plt.ylabel('Generation')
plt.title('Fitness evolution over generations')
plt.show()
```
