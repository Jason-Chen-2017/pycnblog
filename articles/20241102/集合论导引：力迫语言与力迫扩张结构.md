### 第2章 集合论基础

#### 2.1 集合的基本性质

集合论的基础在于理解集合的基本性质。集合的互异性、确定性和无序性是集合论中的核心概念。

**互异性**：一个集合中的元素是唯一的，即同一个元素不能在集合中出现两次。这可以形式化地表示为：对于任意两个元素\( a \)和\( b \)，如果\( a \in A \)和\( b \in A \)，则\( a = b \)。

**确定性**：给定一个集合\( A \)，其元素是确定的，即对于任意元素\( x \)，要么\( x \in A \)，要么\( x \notin A \)，不存在既不属于集合又不属于集合的情况。

**无序性**：集合中的元素没有固定的顺序，这意味着交换集合中任意两个元素的位置不会改变集合的本质。例如，集合\( A = \{1, 2, 3\} \)与集合\( B = \{3, 2, 1\} \)是相同的集合。

#### 2.2 集合的运算

集合的运算在集合论中起着至关重要的作用。基本的集合运算包括并集、交集、补集和差集。

**并集**：两个集合\( A \)和\( B \)的并集是一个包含所有属于\( A \)或属于\( B \)的元素的集合。形式化地表示为：

$$
C = A \cup B = \{x | x \in A \text{ 或 } x \in B\}
$$

**交集**：两个集合\( A \)和\( B \)的交集是一个包含所有既属于\( A \)又属于\( B \)的元素的集合。形式化地表示为：

$$
C = A \cap B = \{x | x \in A \text{ 且 } x \in B\}
$$

**补集**：一个集合\( A \)的补集是包含所有不在\( A \)中的元素的集合。形式化地表示为：

$$
C = A' = \{x | x \notin A\}
$$

**差集**：两个集合\( A \)和\( B \)的差集是一个包含所有属于\( A \)但不属于\( B \)的元素的集合。形式化地表示为：

$$
C = A \setminus B = \{x | x \in A \text{ 且 } x \notin B\}
$$

#### 2.3 集合的表示方法

集合可以用不同的方法来表示，包括列举法、描述法和集合的表示法。

**列举法**：通过列举集合中的所有元素来表示集合。例如，集合\( A = \{1, 2, 3\} \)。

**描述法**：通过条件来定义集合的元素。例如，集合\( A = \{x | x \text{ 是自然数}\} \)。

**集合的表示法**：通过其他集合的运算来表示一个新的集合。例如，集合\( A = \{x | x \in \mathbb{N} \setminus \{1, 2\}\} \)。
