# 核心算法原理讲解

## 自注意力机制（Self-Attention）

自注意力机制是Transformer模型的核心组件，它允许模型在处理序列中的每个单词时，考虑其他单词的影响。其原理如下：

### 伪代码：

```python
for each word in sequence:
    Calculate query, key, value for each word
    Compute self-attention scores using the formula:
    attention_scores = softmax((query * key)^T / sqrt(d_k))
    Compute the weighted sum of values using attention_scores
    Append the weighted sum to the output sequence
```

### 详细解释：

自注意力机制通过计算每个单词的查询（query）、关键（key）和值（value）向量，来衡量它们之间的相关性。然后，通过softmax函数计算每个单词与其他单词的相关性得分，
