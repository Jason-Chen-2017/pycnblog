## 第一部分：引言

### 第1章：价值投资的背景与概念

#### 1.1 价值投资的定义与核心理念
价值投资是一种以基本面分析为基础的投资策略，旨在通过识别市场低估的证券进行长期投资，追求超额收益。其核心理念包括：
1. **内在价值**：证券的真实价值由其未来现金流的现值决定。
2. **安全边际**：买入价格应低于内在价值，以降低投资风险。
3. **市场先生**：市场情绪波动会影响价格，但不会长期影响价值。

#### 1.2 价值投资的历史背景
20世纪初的华尔街经历了多次市场崩盘，投资者对短期投机行为的反思促使格雷厄姆提出价值投资理论。通过分析市场波动和投资者心理，格雷厄姆强调安全边际和防御性投资策略。

#### 1.3 格雷厄姆与巴菲特的传承
格雷厄姆的学生巴菲特继承并发展了价值投资理论，提出了“护城河”、“安全边际”等概念，并将投资策略扩展到企业长期竞争优势的分析。

## 第二部分：格雷厄姆的价值投资理论

### 第2章：格雷厄姆的投资策略

#### 2.1 安全边际的概念
安全边际是买入价格与内在价值的差额，确保在市场波动中不会遭受本金损失。数学模型如下：
$$ \text{安全边际} = \text{内在价值} - \text{买入价格} $$

#### 2.2 防御性投资策略
防御性投资强调分散化和低风险投资，通过避免本金损失来确保长期收益。格雷厄姆建议投资于具有稳定收益和良好财务状况的公司。

#### 2.3 股票估值的基本方法
格雷厄姆提出了多种估值方法，包括市盈率（P/E）和市净率（P/B）模型。例如，内在价值公式：
$$ \text{内在价值} = \frac{\text{未来现金流}}{(1 + r)^n} $$
其中，r为折现率，n为时间期限。

## 第三部分：巴菲特的投资策略

### 第3章：巴菲特的投资哲学

#### 3.1 长期投资与护城河
巴菲特强调长期投资和企业竞争优势，特别是“护城河”（经济护城河）的概念。企业通过成本优势、品牌忠诚度和技术壁垒建立竞争优势。

#### 3.2 股东价值分析
巴菲特将企业视为一系列现金流的来源，通过分析自由现金流和ROE（净资产收益率）来评估企业价值。

#### 3.3 集中投资与风险控制
巴菲特提倡集中投资，将大部分资金投向少数优质企业，以降低风险并最大化收益。

```python
import pandas as pd
import numpy as np

# 计算内在价值
def calculate_intrinsic_value(eps, growth_rate, discount_rate):
    return eps / (1 - growth_rate / (1 + discount_rate))

# 计算安全边际
def calculate_margin_of_safety(price, intrinsic_value):
    return (intrinsic_value - price) / intrinsic_value * 100

# 示例数据
eps = 10
growth_rate = 0.05
discount_rate = 0.08
price = 50

iv = calculate_intrinsic_value(eps, growth_rate, discount_rate)
mos = calculate_margin_of_safety(price, iv)

print(f"内在价值: {iv:.2f}")
print(f"安全边际: {mos:.2f}%")
```
