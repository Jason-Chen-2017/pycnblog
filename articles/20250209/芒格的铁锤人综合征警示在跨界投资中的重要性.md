## 第1章：芒格"铁锤人综合征"的背景与核心概念

### 1.1 芒格"铁锤人综合征"概述

芒格（Charlie Munger）作为巴菲特的合伙人，以其独特的投资理念和思维方式闻名于世。他提出的"铁锤人综合征"（Hammer Man Syndrome）是一种比喻，用来形容投资者只依赖一种投资工具或方法，导致思维僵化、视角单一的倾向。这种思维方式在跨界投资中尤为危险，因为跨界投资涉及多个领域，单一的思维模式往往会导致决策失误。

#### 1.1.1 芒格的生平简介
查理·芒格是伯克希尔哈撒韦公司的副主席，也是沃伦·巴菲特的长期合作伙伴。芒格以其跨学科的思维方式和深刻的投资哲学闻名。他的"铁锤人综合征"概念源于他对人类认知局限性的深刻理解。

#### 1.1.2 "铁锤人综合征"的定义与核心概念
"铁锤人综合征"是指投资者在面对复杂的决策时，只依赖单一的思维方式或工具，忽视其他可能性。这种思维方式类似于只会使用锤子的人，看到任何问题都试图用锤子来解决。

#### 1.1.3 跨界投资中的"铁锤人综合征"现象
跨界投资涉及不同领域的知识和风险，投资者若只依赖单一的分析工具或方法，容易忽略其他重要的因素，导致决策失误。

#### 3.1.2 贝叶斯分类器的原理与应用

```python
def naive_bayes_classifier(train_data, test_data):
    from collections import defaultdict
    # 训练数据统计
    class_distribution = defaultdict(float)
    feature_distribution = defaultdict(lambda: defaultdict(float))
    
    # 训练
    for data_point in train_data:
        class_dist = data_point['class']
        class_distribution[class_dist] += 1
        for feature, value in data_point['features'].items():
            feature_distribution[class_dist][feature][value] += 1
    
    # 标准化
    total = len(train_data)
    for cls in class_distribution:
        class_distribution[cls] /= total
        for feature in feature_distribution[cls]:
            total_feature = sum(feature_distribution[cls][feature].values())
            for val in feature_distribution[cls][feature]:
                feature_distribution[cls][feature][val] /= total_feature
    
    # 测试
    predictions = []
    for data_point in test_data:
        max_prob = -1
        best_cls = None
        for cls in class_distribution:
            prob = class_distribution[cls]
            for feature, value in data_point['features'].items():
                prob *= feature_distribution[cls][feature].get(value, 0)
            if prob > max_prob:
                max_prob = prob
                best_cls = cls
        predictions.append(best_cls)
    
    return predictions
```

### 3.2 数学模型与公式

#### 3.2.1 投资决策的数学模型

$$
\text{投资回报} = \sum_{i=1}^{n} w_i \times r_i
$$

其中，\( w_i \) 是投资组合中资产 \( i \) 的权重，\( r_i \) 是资产 \( i \) 的回报率。

#### 3.2.2 风险评估的数学公式

$$
\text{风险值} = \sqrt{\sum_{i=1}^{n} (r_i - \bar{r})^2}
$$

其中，\( \bar{r} \) 是回报率的平均值。

def main():
    import numpy as np
    import pandas as pd
    from sklearn.tree import DecisionTreeClassifier
    from sklearn.model_selection import train_test_split
    from sklearn.metrics import accuracy_score

    # 数据加载
    data = pd.read_csv('investment.csv')
    X = data.drop('target', axis=1)
    y = data['target']
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

    # 模型训练
    clf = DecisionTreeClassifier()
    clf.fit(X_train, y_train)

    # 预测与评估
    y_pred = clf.predict(X_test)
    print("准确率：", accuracy_score(y_test, y_pred))

if __name__ == "__main__":
    main()
