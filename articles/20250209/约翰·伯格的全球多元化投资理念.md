## 第一部分：投资的演变与约翰·伯格的全球多元化投资理念

### 第1章：投资的演变与伯格的投资理念

#### 1.1 投资的演变历程

##### 1.1.1 传统投资与现代投资的分水岭

投资从早期的个股选择和市场投机，逐渐发展为基于数据和模型的系统化投资。20世纪中期，机构投资者开始采用多元化策略，以降低风险并提高收益稳定性。

##### 1.1.2 约翰·伯格的生平与投资理念的形成

约翰·伯格（John C. Bogle）是指数基金之父，他在1975年创立了第一只指数基金（Vanguard 500 Index Fund），并倡导长期、分散化的投资策略。他的理念源于对市场波动和投资者情绪的研究。

##### 1.1.3 多元化投资的背景与重要性

随着全球市场的波动加剧，投资者意识到通过多元化配置资产可以有效分散风险，同时捕捉全球经济增长的机会。伯格的理念在全球化背景下显得尤为重要。

### 第2章：多元化投资的核心概念

#### 2.1 投资的基本概念

##### 2.1.1 资产配置的定义与作用

资产配置是将资金分配到不同资产类别（股票、债券、房地产等）以实现风险与收益的平衡。通过资产配置，投资者可以在不同市场环境下优化收益。

##### 2.1.2 风险与收益的关系

风险与收益成正比，但通过多元化可以降低特定资产的风险，提高整体投资组合的稳定性。

##### 2.1.3 投资组合的构成要素

一个典型的投资组合包括股票、债券、现金等资产，每种资产的比例根据风险偏好和投资目标而定。

#### 2.2 现代投资组合理论

##### 2.2.1 马科维茨的有效前沿模型

马科维茨提出的投资组合理论是基于均值-方差模型，通过优化资产组合的收益和风险，找到最优投资组合。下图展示了有效前沿的概念：

```mermaid

    A[投资组合] --> B[收益]
    A --> C[风险]

```

##### 2.2.2 资产分配的数学模型

均值-方差优化的公式为：

$$
\text{Minimize } \sigma^2 \text{ subject to } E(r) = \text{target return}
$$

其中，$\sigma^2$是投资组合的方差，$E(r)$是预期收益。

```python
from scipy.optimize import minimize

# 定义目标函数
def portfolio_optimization(weights, returns):
    return np.var(weights.dot(returns))

# 约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 最优化问题
result = minimize(portfolio_optimization, [1/len(returns)], 
                 method='SLSQP', constraints={'type': 'eq', 'fun': constraint})
```
