#### 2.2 股票内在价值的计算

##### 2.2.1 内在价值的公式推导

- **内在价值公式**：$$ V = \frac{D}{k} + \frac{P}{(1 - \gamma)} $$
  - D：预期股息
  - k：折现率
  - P：残值
  - γ：增长率

##### 2.2.2 股息贴现模型（DDM）的详细解释

- **DDM公式**：$$ V = \frac{D_1}{k - g} $$
  - D1：第一年股息
  - k：折现率
  - g：股息增长率

##### 2.2.3 使用Python计算内在价值的代码示例

```python
def calculate_intrinsic_value(dividend, growth_rate, discount_rate):
    # DDM模型计算内在价值
    if discount_rate <= growth_rate:
        return 0  # 避免除以零或负数
    intrinsic_value = dividend / (discount_rate - growth_rate)
    return intrinsic_value

# 示例计算
dividend = 2  # 预期第一年股息
growth_rate = 0.05  # 股息增长率
discount_rate = 0.10  # 折现率
iv = calculate_intrinsic_value(dividend, growth_rate, discount_rate)
print(f"内在价值: {iv:.2f}")
```
