# 第1章 患者资本理论的背景与核心概念

## 1.1 患者资本理论的起源与发展

### 1.1.1 投资理论的演变历程
现代投资理论起源于20世纪初，经历了从基本面分析到量化分析的演变。玛丽·巴芙达的患者资本理论在此基础上，强调长期持有优质资产，注重企业内在价值。

### 1.1.2 玛丽·巴芙达的贡献与影响
玛丽·巴芙达通过长期持有优质股票，创造了卓越的投资业绩，她的理论影响了全球投资者，并成为价值投资的典范。

### 1.1.3 患者资本理论的核心理念
该理论强调通过深入分析企业基本面，选择具有持续竞争优势和合理估值的企业进行长期投资。

## 1.2 患者资本理论的核心概念

### 1.2.1 价值投资的定义与特征
价值投资是指以低于内在价值的价格购买优质资产，长期持有以获得超额收益。

### 1.2.2 长期投资策略的内涵
长期投资注重企业的持续盈利能力，避免短期市场波动的干扰，追求长期稳健增长。

### 1.2.3 企业基本面分析的关键要素
包括财务状况、行业地位、管理团队和竞争优势等方面，评估企业的内在价值。

## 1.3 患者资本理论与其他投资策略的对比

### 1.3.1 价值投资与成长投资的区别
价值投资注重低估值，而成长投资关注高增长，两者在选股标准和风险承受上有差异。

### 1.3.2 长期投资与短期交易的优劣势
长期投资风险较低，收益稳定，但流动性差；短期交易灵活性高，但风险和交易成本较大。

### 1.3.3 患者资本理论的独特性与适用性
结合了价值投资和长期投资的优点，适合追求稳健收益的投资者。

# 第2章 患者资本理论的核心要素与数学模型

## 2.1 核心要素分析

### 2.1.1 企业价值的评估方法
使用DCF模型评估企业内在价值，考虑未来现金流的现值。

### 2.1.2 股东权益与内在价值的关系
股东权益代表企业的所有权，内在价值是企业未来现金流的折现值。

### 2.1.3 风险与收益的平衡机制
通过分散投资和风险调整折现率，平衡风险与收益。

## 2.2 数学模型与公式

### 2.2.1 内在价值计算公式
$$ V = \frac{CF}{r - g} $$
其中，\( V \) 是内在价值，\( CF \) 是现金流，\( r \) 是折现率，\( g \) 是增长率。

### 2.2.2 风险调整折现率模型
$$ r = R_f + \beta \times (R_m - R_f) $$
其中，\( R_f \) 是无风险利率，\( R_m \) 是市场平均收益率，\( \beta \) 是股票的贝塔系数。

### 4.2.2 风险调整折现率计算代码

```python
import numpy as np

def calculate_beta(returns, market_returns):
    covariance = np.cov(returns, market_returns)[0, 1]
    variance_market = np.var(market_returns)
    beta = covariance / variance_market
    return beta

# 示例数据
returns = [0.1, 0.05, -0.02, 0.08, 0.02]
market_returns = [0.08, 0.06, -0.01, 0.12, 0.04]

beta = calculate_beta(returns, market_returns)
print(f"贝塔系数：{beta:.2f}")
```
