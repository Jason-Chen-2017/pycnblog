## 第二部分: 长期资本配置的算法原理

### 第3章: 现代投资组合理论与算法原理

#### 3.1 现代投资组合理论的数学模型

- **均值-方差优化模型**：  
  $$\text{Minimize } \sigma^2 \text{ subject to } \mu^T w = T$$  
  其中，$\sigma^2$是投资组合的方差，$\mu$是资产的期望收益向量，$w$是投资权重，$T$是目标收益。

- **马科维茨有效前沿理论**：通过优化风险和收益的关系，找到最优投资组合。

#### 3.2 算法实现与代码分析

- Python代码实现均值-方差优化：

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def optimize_portfolio(returns):
    # 定义目标函数
    def objective(weights):
        return np.dot(weights.T, np.dot(returns.cov(), weights))
    
    # 约束条件：权重之和为1
    def constraint(weights):
        return np.sum(weights) - 1
    
    # 初始猜测：等权分配
    n = len(returns.columns)
    initial_guess = np.array([1.0/n]*n)
    
    # 优化
    result = minimize(objective, initial_guess, method='SLSQP', 
                      constraints={'type': 'eq', 'fun': constraint})
    
    return result.x

# 示例数据
returns = pd.DataFrame({'A': [0.1, 0.2, 0.15], 
                         'B': [0.05, 0.1, 0.08], 
                         'C': [0.12, 0.08, 0.1]})
weights = optimize_portfolio(returns)
print(weights)
```

```python
import numpy as np
import pandas as pd

def calculate_efficient_frontier(returns, num_portfolios=1000):
    # 计算所有可能的组合
    n = len(returns.columns)
    returns = pd.DataFrame(returns.values.T, columns=returns.columns)
    all_weights = []
    all_returns = []
    all_vols = []
    
    for _ in range(num_portfolios):
        weights = np.random.dirichlet([1]*n)
        portfolio_return = np.dot(weights, returns.mean())
        portfolio_volatility = np.sqrt(np.dot(weights.T, 
                                              np.dot(returns.cov(), weights)))
        all_weights.append(weights)
        all_returns.append(portfolio_return)
        all_vols.append(portfolio_volatility)
    
    # 找到有效前沿
    ef = pd.DataFrame({'Return': all_returns, 'Volatility': all_vols})
    ef = ef.sort_values('Volatility')
    ef['Efficient'] = ef['Volatility'] == ef['Volatility'].min()
    
    return ef

# 示例数据
returns = pd.DataFrame({'A': [0.1, 0.2, 0.15], 
                         'B': [0.05, 0.1, 0.08], 
                         'C': [0.12, 0.08, 0.1]})
frontier = calculate_efficient_frontier(returns)
print(frontier.head())
```
