# 第一部分：行为经济学与价值投资的背景

## 第1章：行为经济学的基本概念

### 1.1 行为经济学的定义与核心理论
#### 1.1.1 行为经济学的起源与发展
行为经济学是研究人类决策行为的学科，结合心理学和经济学，挑战传统理性假设，强调有限理性和认知偏差。丹尼尔·卡尼曼是这一领域的先驱，提出了前景理论（prospect theory）和有限理性理论。

#### 1.1.2 丹尼尔·卡尼曼的贡献
卡尼曼的主要贡献包括：
- **前景理论**：解释了人们对风险和收益的非对称感知。
- **有限理性**：提出人类决策受认知能力和信息处理能力的限制。
- **心理账户**：描述了人们如何在大脑中构建隐含的账户来管理资源。

#### 1.1.3 行为经济学的核心假设
行为经济学认为，人类决策受情感、认知偏差和环境因素的影响，而非完全理性。

## 第2章：价值投资的基本原理

### 2.1 价值投资的定义与特点
#### 2.1.1 价值投资的定义
价值投资是通过深入分析企业基本面，寻找市场价格低于内在价值的投资机会。

#### 2.1.2 价值投资的核心理念
- 价格波动是投资机会。
- 市场先生是情绪化的，长期来看，市场会反映企业的真实价值。

#### 2.1.3 价值投资与其它投资策略的区别
- **技术分析**：基于价格波动，忽视基本面。
- **基本面分析**：注重财务数据，但缺乏行为因素考量。
- **价值投资**：结合价格与价值，强调安全边际。

## 第3章：卡尼曼行为经济学理论对投资决策的影响

### 3.1 有限理性与投资决策
#### 3.1.1 有限理性的概念
有限理性是指人类在决策过程中受到认知能力和信息处理能力的限制，无法完全理性。

#### 3.1.2 有限理性在投资中的表现
- 投资者倾向于简化复杂问题，导致决策偏差。
- 过度自信，低估市场风险。

#### 3.1.3 有限理性对价值投资策略的影响
价值投资者需认识到市场定价的非理性，寻找市场忽视的低估企业。

### 3.2 前视性理论与投资决策
#### 3.2.1 前视性理论的定义
前视性理论强调决策者基于未来期望值做出选择。

#### 3.2.2 前视性理论在投资中的应用
- 价值投资者预测企业未来现金流，评估内在价值。
- 市场情绪影响定价，需识别价格与价值的偏差。

#### 3.2.3 前视性理论对价值投资策略的启示
投资者应关注长期价值，而非短期价格波动。

### 3.3 心理账户与投资决策
#### 3.3.1 心理账户的定义
心理账户是大脑中用于分类和管理资金的隐含账户。

#### 3.3.2 心理账户在投资中的应用
- 投资者将资金分为不同账户，影响投资决策。
- 心理账户影响风险承受能力和收益预期。

#### 3.3.3 心理账户对价值投资策略的影响
价值投资者需警惕心理账户导致的决策偏差，保持理性判断。

def calculate_intrinsic_value(financials):
    cash_flow = financials['free_cash_flow']
    discount_rate = financials['wacc']
    horizon = financials['time_horizon']
    intrinsic_value = sum(cash_flow / (1 + discount_rate)**t for t in range(horizon))
    return intrinsic_value

financials = {
    'free_cash_flow': [100, 120, 150],
    'wacc': 0.1,
    'time_horizon': 3
}

iv = calculate_intrinsic_value(financials)
print(f"内 在 价 值：{iv}")
