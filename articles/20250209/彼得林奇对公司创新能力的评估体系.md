```python
import pandas as pd

def preprocess(data):
    # 数据清洗和预处理
    processed_data = data.dropna()
    return processed_data

def compute_capability(processed_data):
    # 计算创新能力指标
    capability = processed_data['创新成果'] / processed_data['创新投入']
    return capability.mean()

# 示例数据
data = pd.DataFrame({
    '创新意识': [8, 7, 9],
    '创新能力': [6, 8, 7],
    '创新成果': [10, 9, 12],
    '创新投入': [5, 6, 7]
})

processed_data = preprocess(data)
capability = compute_capability(processed_data)
print(f"创新能力评估结果：{capability}")
```

#### 7.3 案例分析  

假设我们有一家科技公司，其创新意识、能力和成果分别为8、7、9。根据上述代码，计算出的创新能力评估结果为：  
$$ 创新能力评估结果 = 9 / 6 = 1.5 $$
