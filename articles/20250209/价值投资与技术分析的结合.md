## 第一部分：价值投资与技术分析的概述

### 第1章：价值投资的定义与核心理念

#### 1.1 价值投资的起源与发展
- 1.1.1 价值投资的起源：起源于20世纪初，由本杰明·格雷厄姆和戴维·多德提出，强调股票的内在价值。
- 1.1.2 核心理念：购买低于内在价值的股票，长期持有，关注公司的基本面。
- 1.1.3 主要倡导者：本杰明·格雷厄姆、沃伦·巴菲特。

#### 1.2 价值投资的核心策略
- 1.2.1 股票内在价值计算：DCF模型，市盈率、市净率。
- 1.2.2 安全边际：买入价低于内在价值，降低风险。
- 1.2.3 与成长型投资对比：价值投资注重低估，成长型注重高增长。

#### 1.3 适用场景与局限性
- 1.3.1 适用场景：市场恐慌、低估股票。
- 1.3.2 局限性：忽视短期市场波动，需长期持有。

### 第2章：技术分析的原理与方法

#### 2.1 技术分析的起源与发展
- 起源于期货交易，基于价格与成交量的研究。
- 技术分析假设市场反映所有信息，趋势可预测。

#### 2.2 核心指标与方法
- 移动平均线（MA）、相对强弱指数（RSI）、MACD。

#### 2.3 技术分析的优势与不足
- 优势：捕捉短期趋势，适合短线交易。
- 不足：忽视基本面，长期趋势不稳定。

## 第三部分：算法原理与数学模型

### 第4章：价值投资中的算法原理

#### 4.1 DCF模型
- 介绍：通过自由现金流折现计算内在价值。
- 计算步骤：估计现金流，选择贴现率，计算现值。

#### 4.2 Python代码示例
```python
def dcf_model(fcf, wacc, growth):
    pv = sum(fcf * (1 + growth) ** i / (1 + wacc) ** i for i in range(10))
    return pv
```

### 第5章：技术分析中的算法原理

#### 5.1 MACD指标
- 计算公式：MACD = EMA(12) - EMA(26)，信号线 = EMA(9)。
- 代码示例：
```python
def compute_macd(close_prices, n=12, m=26, signal_n=9):
    ema_n = close_prices.ewm(n).mean()
    ema_m = close_prices.ewm(m).mean()
    macd = ema_n - ema_m
    signal = macd.ewm(signal_n).mean()
    return macd, signal
```

#### 5.2 技术分析的数学模型
- 公式：MACD = EMA12 - EMA26，Signal = EMA9(MACD)。
- 使用场景：识别趋势和潜在反转点。
