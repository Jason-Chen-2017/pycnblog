## 1. 资本回报率的基本概念与行业分析基础

### 1.1 资本回报率的核心概念

资本回报率（Return on Equity，ROE）是衡量企业盈利能力的重要指标，计算公式为：

$$ROE = \frac{\text{净利润}}{\text{股东权益}}$$

ROE越高，表明企业利用股东资产创造利润的能力越强。行业差异显著，例如科技行业通常ROE较高，而制造业可能较低。

### 1.2 彼得·林奇的资本回报率分析方法

彼得·林奇强调通过行业对标分析企业ROE的合理性。他选择行业内的标杆企业，比较目标企业的ROE是否具备竞争力。

### 3.2 核心功能实现

#### 数据采集模块

```python
import requests
import pandas as pd

def get_data():
    url = "https://example.com/api/stock_data"
    response = requests.get(url)
    data = response.json()
    df = pd.DataFrame(data)
    return df
```

#### 分析计算模块

```python
def calculate_roe(df):
    df['ROE'] = df['净利润'] / df['股东权益']
    return df
```

#### 结果展示模块

```python
def display_results(df):
    print("行业ROE分析结果：")
    print(df[['公司名称', 'ROE']].head())
```

### 3.3 项目实战：科技行业动态分析

#### 数据采集

```python
data = get_data()

```

#### 计算ROE

```python
ro_data = calculate_roe(data)
print(ro_data[['公司名称', 'ROE']].head())
```

#### 结果展示

```python
display_results(ro_data)
```
