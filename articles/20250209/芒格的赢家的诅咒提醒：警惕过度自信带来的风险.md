“赢家的诅咒”是指成功者因过度自信而忽视潜在风险，导致决策失误的现象。它源于成功带来的心理偏差，如确认偏见和过度自信。

在投资和商业领域，成功者常因过去的成绩而过于相信自己的判断，忽视市场变化和潜在风险。这种过度自信可能导致决策失误，最终引发失败。

过度自信是“赢家的诅咒”的核心因素。成功者往往过高估计自己的能力，忽视外部环境的变化，从而陷入决策陷阱。

def calculate_probability(data):
    probabilities = {}
    total = len(data)
    for outcome in data:
        probabilities[outcome] = probabilities.get(outcome, 0) + 1
    for outcome in probabilities:
        probabilities[outcome] /= total
    return probabilities

data = [1, 2, 3, 4, 5]
