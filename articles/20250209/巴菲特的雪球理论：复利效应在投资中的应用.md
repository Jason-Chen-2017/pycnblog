# 第一部分：背景介绍

## 第1章：雪球理论的基本概念

### 1.1 什么是雪球理论

- **雪球理论的定义**：雪球理论由巴菲特提出，强调通过长期投资和复利效应，使财富呈指数增长。
- **雪球理论的核心要素**：
  - 高质量企业：具备长期增长潜力、竞争优势和稳定收益。
  - 长期投资：通过时间的积累，复利效应放大收益。
  - 集中投资：将资金集中在少数优质企业中，降低风险并提高收益。

### 1.2 巴菲特的投资哲学

- **价值投资的理念**：寻找市场低估的优质企业，长期持有，获得超额收益。
- **长期投资的重要性**：复利效应在长期投资中表现更为显著，时间是价值投资最好的朋友。
- **安全边际的概念**：在投资中留有安全边际，避免因市场价格波动带来的损失。

# 第二部分：复利效应的数学模型

## 第2章：复利效应的原理与公式

### 2.1 复利效应的基本原理

- **复利的定义**：复利是指在一定时间段内，投资收益再投资，从而产生更多的收益，形成滚雪球效应。
- **复利的计算公式**：
  - 单利计算：$A = P \times (1 + rt)$
  - 复利计算：$A = P \times (1 + r)^t$
  - 其中，$P$ 是本金，$r$ 是年利率，$t$ 是时间（年），$A$ 是最终金额。

### 2.2 复利效应与雪球理论的关系

- **雪球理论的数学模型**：将复利效应应用到投资中，通过选择优质企业，获得稳定且较高的收益率，从而实现财富的指数增长。
- **复利的指数增长特性**：在长期投资中，复利效应使财富增长呈指数级，远超过单利增长。

def compound_interest(principal, rate, time):
