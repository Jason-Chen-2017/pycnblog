## 第一部分：资源稀缺性投资理论的背景与核心概念

### 第1章：资源稀缺性投资理论概述

#### 1.1 资源稀缺性的定义与背景
- **资源稀缺性**：指资源供给无法满足需求的状态，具有供给刚性、需求弹性、价格波动大等特征。
- **资源稀缺性的重要性**：作为投资理论的核心，影响资产价格、市场供需和投资决策。
- **当前资源稀缺性现状**：全球范围内资源枯竭加剧，供需失衡问题突出。

#### 1.2 资源稀缺性与投资的关系
- 资源稀缺性对市场的影响：供需失衡导致资产价格上涨，投资机会增加。
- 投资者如何利用资源稀缺性获利：通过资产配置、风险对冲和长期投资策略。
- 格兰瑟姆理论的核心观点：资源稀缺性是资产定价的重要因素，需结合市场供需和政策因素。

#### 1.3 格兰瑟姆投资理论的核心观点
- 资源稀缺性与资产价格的关系：供给不足推高资产价格，投资机会增加。
- 格兰瑟姆理论的演变：从早期的市场分析到资源稀缺性驱动的长期投资策略。

### 第2章：资源稀缺性投资理论的核心概念

#### 2.1 资源稀缺性与短缺经济学
- 短缺经济学的基本原理：价格弹性低、市场干预多、分配不均。
- 资源稀缺性与市场供需的关系：供给不足导致价格上升，需求刚性加剧市场失衡。
- 短缺经济学在投资中的应用：分析价格波动、政策干预和市场分配问题。

#### 2.2 资源稀缺性与可持续发展

- 环境保护对资源稀缺性的影响：政策干预、技术进步和替代资源开发。
- 可持续投资策略：长期视角、风险控制和社会责任。

#### 2.3 资源稀缺性与资产定价

## 第二部分：资源稀缺性投资理论的算法与数学模型

### 第3章：资源稀缺性指数模型

#### 3.1 资源稀缺性指数模型的构建
- 模型目标：量化资源稀缺性，提供投资参考。
- 模型输入：资源供给、需求、价格和库存。
- 模型输出：资源稀缺性指数。

#### 3.2 资源稀缺性指数的计算公式
$$
\text{资源稀缺性指数} = \frac{\text{需求} - \text{供给}}{\text{需求} + \text{供给}}
$$

#### 3.3 模型的实现步骤
1. 数据采集：收集资源供给、需求和价格数据。
2. 数据预处理：清洗和标准化数据。
3. 模型计算：计算资源稀缺性指数。
4. 结果分析：解读指数并制定投资策略。

#### 3.4 代码实现
```python
import pandas as pd

# 数据预处理
data = pd.read_csv('resource_data.csv')
data['需求'] = data['需求'].astype(float)
data['供给'] = data['供给'].astype(float)

# 计算资源稀缺性指数
data['稀缺性指数'] = (data['需求'] - data['供给']) / (data['需求'] + data['供给'])

# 结果分析
print(data[['时间', '稀缺性指数']])
```

### 第4章：投资决策支持系统模型

#### 4.1 投资决策支持系统模型的构建
- 模型目标：基于资源稀缺性指数，提供投资建议。
- 模型输入：资源稀缺性指数、市场趋势、政策因素。
- 模型输出：投资策略建议。

#### 4.2 投资策略的分类
- 买入信号：稀缺性指数 > 0.5，市场趋势上升。
- 卖出信号：稀缺性指数 < -0.5，市场趋势下降。
- 中立信号：稀缺性指数在 -0.5 到 0.5 之间。

#### 4.3 模型的实现步骤
1. 数据采集：收集资源稀缺性指数和市场趋势数据。
2. 数据预处理：清洗和标准化数据。
3. 模型计算：计算投资策略建议。
4. 结果分析：解读投资建议并制定投资策略。

#### 4.4 代码实现
```python
import pandas as pd

# 数据预处理
data = pd.read_csv('investment_data.csv')
data['稀缺性指数'] = data['稀缺性指数'].astype(float)
data['市场趋势'] = data['市场趋势'].astype(float)

# 计算投资策略建议
data['投资建议'] = ''
data.loc[data['稀缺性指数'] > 0.5, '投资建议'] = '买入'
data.loc[data['稀缺性指数'] < -0.5, '投资建议'] = '卖出'
data.loc[(data['稀缺性指数'] >= -0.5) & (data['稀缺性指数'] <= 0.5), '投资建议'] = '中立'

# 结果分析
print(data[['时间', '投资建议']])
```
