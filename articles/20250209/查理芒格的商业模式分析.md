#### 3.2 芒格数学模型

- **3.2.1 芒格数学模型的定义**
  芒格数学模型是指通过数学公式对企业价值进行评估的模型，主要用于价值投资决策。

- **3.2.2 芒格数学模型的公式**
  $$ V = \text{DCF} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n} $$

  其中，$V$ 是企业价值，$CF_t$ 是第 $t$ 年的现金流，$r$ 是折现率，$TV$ 是终值。

- **3.2.3 芒格数学模型的举例说明**
  假设某企业未来5年的现金流分别为100万、120万、150万、180万、200万，终值为300万，折现率为10%。计算其现值：
  $$
  PV = \frac{100}{1.1} + \frac{120}{1.1^2} + \frac{150}{1.1^3} + \frac{180}{1.1^4} + \frac{200}{1.1^5} + \frac{300}{1.1^5}
  $$

#### 5.1 项目实战

- **5.1.1 环境安装**

- **5.1.2 核心实现源代码**
  ```python
  import pandas as pd
  import numpy as np

  def dcf_model(cash_flows, discount_rate, terminal_value):
      return sum([cf / (1 + discount_rate)**t for t, cf in enumerate(cash_flows)]) + terminal_value / (1 + discount_rate)**len(cash_flows)

  cash_flows = [100, 120, 150, 180, 200]
  terminal_value = 300
  discount_rate = 0.1
  value = dcf_model(cash_flows, discount_rate, terminal_value)
  print(f"企业价值：{value}")
  ```
