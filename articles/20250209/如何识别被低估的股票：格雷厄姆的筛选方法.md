## 第一部分: 价值投资与低估股票概述

### 第1章: 价值投资的起源与理论基础

#### 1.1 价值投资的定义与核心理念
价值投资是一种以基本面分析为基础的投资策略，强调购买价格低于其内在价值的股票。其核心理念是寻找市场先生的错误定价。

#### 1.2 格雷厄姆的价值投资理论
本杰明·格雷厄姆是价值投资的鼻祖，他提出防御性投资策略，强调安全边际和低风险投资。格雷厄姆认为，市场波动反映了短期情绪，而内在价值则是长期稳定的基础。

#### 1.3 价值投资与基本面分析的关系
价值投资依赖于基本面分析，通过研究公司的财务状况、盈利能力、成长性和行业地位来评估其内在价值。

### 第2章: 识别低估股票的重要性

#### 2.1 什么是低估股票
低估股票是指市场价格低于其内在价值的股票。这类股票通常被市场忽视或低估，具有较大的上涨潜力。

#### 2.2 为什么识别低估股票重要
识别低估股票有助于投资者获得超额收益，同时降低投资风险。通过筛选低估股票，投资者可以找到具有长期增长潜力的企业。

#### 2.3 低估股票的特点
低估股票通常具有低市盈率、低市净率和高股息率，且公司财务状况稳健，具备竞争优势。

## 第二部分: 格雷厄姆的筛选方法

### 第3章: 格雷厄姆的防御性投资者策略

#### 3.1 格雷厄姆的防御性投资理念
格雷厄姆强调防御性投资，避免高风险和高波动性。他建议投资者选择那些具有安全边际的股票，即市场价格远低于其内在价值。

#### 3.2 格雷厄姆的选股标准
格雷厄姆提出了具体的选股标准，包括低市盈率、低市净率、高股息率和稳健的财务状况。

### 第4章: 格雷厄姆筛选方法的具体指标

#### 4.1 市盈率（P/E）的计算与应用
市盈率是衡量股票价值的重要指标，计算公式为：

$$\text{市盈率} = \frac{\text{股价}}{\text{每股净利润}}$$

#### 4.2 市净率（P/B）的计算与应用
市净率是另一个重要的筛选指标，计算公式为：

$$\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}$$

#### 4.3 其他筛选指标
格雷厄姆还关注股息率、净利润增长率和负债率等指标。

### 第10章: 核心实现源代码
```python
import pandas as pd

def calculate_pe_ratio(df):
    df['PE Ratio'] = df['股价'] / df['每股净利润']
    return df

def calculate_pb_ratio(df):
    df['PB Ratio'] = df['股价'] / df['每股净资产']
    return df

def screen_undervalued_stocks(df, max_pe=15, min_pb=1):
    df = calculate_pe_ratio(df)
    df = calculate_pb_ratio(df)
    df = df[df['PE Ratio'] <= max_pe]
    df = df[df['PB Ratio'] >= min_pb]
    return df

# 示例数据
data = {
    '股票代码': ['AAPL', 'MSFT', 'GOOGL', 'AMZN'],
    '股价': [150, 300, 120, 100],
    '每股净利润': [10, 15, 20, 5],
    '每股净资产': [50, 60, 70, 30]
}

df = pd.DataFrame(data)
result = screen_undervalued_stocks(df)
print(result)
```
