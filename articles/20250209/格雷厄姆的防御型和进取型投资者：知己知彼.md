## 第一部分：防御型和进取型投资者概述

### 第1章：投资的基本概念与分类

#### 1.1 投资的基本概念

投资是指将资金投入特定资产以期获得收益的行为。其基本原则包括分散投资、长期持有和风险与收益的平衡。投资目标通常分为本金安全、保值增值和追求超额收益三类。

#### 1.2 防御型与进取型投资者的定义

- **防御型投资者**：以本金安全为核心目标，注重长期稳健收益，风险承受能力较低。
- **进取型投资者**：追求高回报，愿意承担更高的风险，适合市场条件较好时。

#### 1.3 知己知彼在投资中的重要性

知己知彼是指投资者需明确自身风险承受能力和收益目标，同时了解市场环境和资产特性，从而制定合理的投资策略。它是投资成功的关键，帮助投资者避免盲目决策。

### 第2章：防御型投资者的策略与实践

#### 2.1 防御型投资的核心理念

防御型投资强调本金安全和稳定收益，注重基本面分析和风险控制。其长期性使投资者能够在市场波动中保持稳定。

#### 2.2 防御型投资的具体策略

- **价值投资策略**：寻找被低估的资产，长期持有。
- **分散投资策略**：通过多样化降低风险。
- **定期投资策略**：定期投入固定金额，平滑市场波动。

#### 2.3 防御型投资的数学模型

防御型投资的数学模型包括风险评估和收益预测：

- 风险评估：$$ \text{风险} = \text{标准差} = \sqrt{\sum_{i=1}^{n} (x_i - \bar{x})^2 / (n-1)} $$
- 投资组合优化：$$ \text{最优组合} = \text{最小化方差} $$

### 第3章：投资组合优化的数学模型

#### 3.1 投资组合优化的均值-方差模型

均值-方差模型用于优化投资组合的风险与收益：

- 数学公式：
  - $$ \text{收益} = w^T \cdot \mu $$
  - $$ \text{风险} = w^T \cdot \Sigma \cdot w $$

代码示例：

import numpy as np

def portfolio_optimization(returns):
    n = len(returns)
    cov_matrix = np.cov(returns)
    mu = np.mean(returns)
    
    # 最优化目标：最小化方差
    def objective(w):
        return np.dot(w.T, np.dot(cov_matrix, w))
    
    # 约束条件：权重和为1
    cons = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1})
    
    from scipy.optimize import minimize
    result = minimize(objective, np.ones(n)/n, constraints=cons)
    return result.x
```

import numpy as np

def calculate_optimal_portfolio(returns):
    n = len(returns)
    mu = np.mean(returns)
    cov = np.cov(returns)
    
    def portfolio_variance(weights):
        return np.dot(weights.T, np.dot(cov, weights))
    
    def portfolio_return(weights):
        return np.dot(weights, mu)
    
    # 最优化问题：最大化收益，最小化风险
    from scipy.optimize import minimize
    initial_guess = np.array([1.0 / n] * n)
    results = minimize(lambda w: -portfolio_return(w), initial_guess, 
                       bounds=([(0,1) for _ in range(n)],),
                       method='SLSQP')
    return results.x, -portfolio_return(results.x)
```
