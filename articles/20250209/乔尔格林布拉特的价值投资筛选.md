## 第一部分: 价值投资与格林布拉特筛选法基础

### 第1章: 价值投资与格林布拉特筛选法概述

#### 1.1 价值投资的核心理念

##### 1.1.1 价值投资的定义与特点
价值投资是一种以基本面分析为基础的投资策略，旨在通过识别市场低估的优质资产来实现长期收益。其核心理念是购买价格低于内在价值的资产，耐心持有，等待市场重新评估其价值。

##### 1.1.2 格林布拉特投资方法的起源
乔尔·格林布拉特（Joel Greenblatt）是价值投资领域的传奇人物，他的投资方法以“神奇公式”闻名。他在《股市稳赚》一书中提出了这一方法，强调通过量化指标筛选具有高收益潜力的股票。

##### 1.1.3 格林布拉特筛选法的核心思想
格林布拉特筛选法的核心思想是：通过基本面分析和合理估值，找到那些具有高回报潜力且价格被市场低估的股票。这种方法结合了成长性和估值指标，旨在平衡短期风险与长期收益。

#### 1.2 格林布拉特筛选法的背景与现状

##### 1.2.1 价值投资的市场环境
价值投资在市场低迷或震荡期表现尤为突出，因为这些时期更容易出现被低估的资产。格林布拉特的方法在不同市场环境下的表现已被广泛验证。

##### 1.2.2 格林布拉特筛选法的应用场景
格林布拉特筛选法适用于多种市场环境，尤其适合中长期投资者。其量化指标使其易于复制和应用，但同时也需要结合市场环境进行动态调整。

##### 1.2.3 格林布拉特筛选法的优缺点
优点：量化指标简单易懂，适合普通投资者；历史表现优异，长期回报稳定。缺点：过于依赖历史数据，可能无法完全适应市场变化；对短期市场波动的敏感性较高。

#### 1.3 格林布拉特筛选法的数学模型

##### 1.3.1 核心公式与计算方法
格林布拉特的“神奇公式”可以简化为以下两个步骤：
1. 计算企业的“内在价值”：基于息税前利润（EBIT）和资本支出（CapEx）。
2. 确定市场的“合理估值”：基于市盈率（P/E）和市净率（P/B）等指标。

##### 1.3.2 格林布拉特筛选法的量化指标
- **企业价值（EV）**：EV = 市盈率 × 净利润
- **可承受价格（FP）**：FP = EV ÷ (EBIT - CapEx)

##### 1.3.3 公式推导与数学基础
格林布拉特的筛选公式可以通过以下步骤推导：
1. 计算企业的EBIT和CapEx。
2. 计算企业的内在价值（EV）：EV = EBIT - CapEx。
3. 计算企业的合理估值（FP）：FP = EV ÷ (EBIT - CapEx)。

## 第二部分: 格林布拉特筛选法的核心指标

### 第2章: 格林布拉特筛选法的核心指标

#### 2.1 格林布拉特筛选法的三大核心指标

##### 2.1.1 市盈率（P/E）
市盈率（P/E）= 股价 ÷ 每股收益（EPS）。低市盈率通常意味着股票价格被低估。

##### 2.1.2 市净率（P/B）
市净率（P/B）= 股价 ÷ 每股净资产（BPS）。低市净率通常意味着资产被低估。

##### 2.1.3 股息率（Dividend Yield）
股息率（Dividend Yield）= 每股股息（DIV） ÷ 股价。高股息率意味着较高的分红回报。

#### 2.2 核心指标的计算与应用

##### 2.2.1 市盈率的计算与行业对比
- **公式**：P/E = 股价 ÷ EPS
- **应用**：通过与行业平均P/E对比，判断股票是否被低估或高估。

##### 2.2.2 市净率的计算与资产评估
- **公式**：P/B = 股价 ÷ BPS
- **应用**：用于评估银行、房地产等资产密集型行业的股票。

##### 2.2.3 股息率的计算与收益分析
- **公式**：股息率 = 每股股息 ÷ 股价
- **应用**：高股息率股票通常适合追求稳定收益的投资者。

#### 2.3 核心指标的综合应用

##### 2.3.1 核心指标的权重分配
- 市盈率和市净率各占40%，股息率占20%。

##### 2.3.2 核心指标的动态调整
根据市场环境和行业特点，动态调整各指标的权重。

##### 2.3.3 核心指标的组合优化
通过优化指标组合，提高筛选的准确性和稳定性。

#### 3.3 算法的数学模型与公式

- 市盈率（P/E）= 股价 ÷ EPS

```python
import pandas as pd
import requests

def get_stock_data(api_key, stock_ticker):
    url = f"https://api.yfinance.com/stock/{stock_ticker}/data"
    headers = {"x-api-key": api_key}
    response = requests.get(url, headers=headers)
    data = response.json()
    df = pd.DataFrame(data)
    return df
```

##### 5.2.2 数据处理模块
```python
def calculate_metrics(df):
    df['P/E'] = df['Close'] / df['EPS']
    df['P/B'] = df['Close'] / df['BPS']
    df['Dividend Yield'] = df['Dividend'] / df['Close']
    return df
```

##### 5.2.3 筛选模块
```python
def greenblatt_screen(df):
    df['Score'] = df['P/E'] * df['P/B'] + df['Dividend Yield']
    top_stocks = df.sort_values('Score').head(10)
    return top_stocks
```
