## 第三部分: 机器学习算法原理与数学模型

### 第3章: 常用机器学习算法介绍

#### 3.1 线性回归

- **3.1.1 线性回归的原理**
  通过最小化预测值与实际值的差的平方和，找到最佳拟合直线。

- **3.1.2 线性回归的数学公式**
  $$y = wx + b$$
  其中，$w$ 是权重，$b$ 是截距。

- **3.1.3 线性回归的优缺点**
  优点：简单易懂，计算高效。缺点：仅适合线性关系。

#### 3.2 支持向量机（SVM）

- **3.2.1 SVM的原理**
  将数据映射到高维空间，找到最佳分割超平面。

- **3.2.2 SVM的数学公式**
  $$y = sign(\sum_{i} \alpha_i y_i x_i \cdot x + b)$$
  其中，$\alpha_i$ 是拉格朗日乘子，$y_i$ 是标签。

- **3.2.3 SVM的优缺点**
  优点：适合非线性分类。缺点：计算复杂度高。

#### 3.3 随机森林

- **3.3.1 随机森林的原理**
  通过构建多棵决策树，集成预测结果。

- **3.3.2 随机森林的数学公式**
  预测结果是各棵树预测结果的投票或平均。

- **3.3.3 随机森林的优缺点**
  优点：抗过拟合，适合复杂数据。缺点：计算资源消耗大。

#### 3.4 神经网络

- **3.4.1 神经网络的原理**
  模拟人脑神经网络，通过多层处理数据。

- **3.4.2 神经网络的数学公式**
  $$y = \sigma(w x + b)$$
  其中，$\sigma$ 是激活函数，如ReLU。

- **3.4.3 神经网络的优缺点**
  优点：适合复杂非线性关系。缺点：训练时间长，参数调整复杂。

#### 5.2 核心代码实现

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.ensemble import RandomForestRegressor
from sklearn.svm import SVC
from keras.models import Sequential
from keras.layers import Dense

# 数据加载
data = pd.read_csv('growth_stocks.csv')

# 数据预处理
X = data[['收入增长率', '净利润增长率', '股东权益增长率']]
y = data['股价']

# 模型训练
model_lr = LinearRegression()
model_lr.fit(X, y)

model_rf = RandomForestRegressor()
model_rf.fit(X, y)

model_svm = SVC()
model_svm.fit(X, y)

model_nn = Sequential()
model_nn.add(Dense(64, input_dim=3, activation='relu'))
model_nn.add(Dense(1, activation='sigmoid'))
model_nn.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
model_nn.fit(X, y, epochs=100, batch_size=32)
```

#### 5.3 实际案例分析

```python
# 预测新股票的价格
new_stock = np.array([[0.2, 0.15, 0.1]])
print("线性回归预测价格：", model_lr.predict(new_stock))
print("随机森林预测价格：", model_rf.predict(new_stock))
print("支持向量机预测价格：", model_svm.predict(new_stock))
print("神经网络预测价格：", model_nn.predict(new_stock))
```
