### 3.2 数学模型与公式  
3.2.1 概率计算公式：  
$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$  

3.2.2 损失函数：  
$$L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$  

3.2.3 优化算法：梯度下降示例代码  
```python
def gradient_descent(X, y, theta, alpha, iterations):
    m = len(y)
    for _ in range(iterations):
        h = X.dot(theta)
        loss = h - y
        theta -= (X.T.dot(loss) * alpha) / m
    return theta
```
