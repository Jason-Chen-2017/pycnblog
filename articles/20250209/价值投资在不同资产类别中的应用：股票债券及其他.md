## 第一部分：价值投资的背景与核心概念

### # 第1章：价值投资概述

#### 1.1 价值投资的基本概念

- **1.1.1 价值投资的定义**
  价值投资是一种以基本面分析为基础的投资策略，旨在通过识别市场定价偏差，投资于内在价值被低估的资产。

- **1.1.2 价值投资的核心理念**
  - **内在价值**：资产的真实价值，与市场波动无关。
  - **安全边际**：买入价格低于内在价值，以降低风险。
  - **长期视角**：关注长期收益，而非短期波动。

- **1.1.3 价值投资的目标与边界**
  - 目标：通过长期持有低估资产，实现超额收益。
  - 边界：避免过度杠杆、高频交易和非理性决策。

#### 1.2 价值投资的历史与发展

- **1.2.1 价值投资的起源**
  - 20世纪初，本杰明·格雷厄姆和戴维·多德提出价值投资理论。

- **1.2.2 价值投资的发展历程**
  - 从基本面分析到量化模型的演变。

- **1.2.3 价值投资在现代金融中的地位**
  - 价值投资与现代资产组合理论的结合。

#### 1.3 价值投资与其他投资策略的对比

- **1.3.1 股票投资策略的分类**
  - 技术分析、成长投资、价值投资。

- **1.3.2 债券投资策略的分类**
  - 利率风险、信用风险、久期策略。

- **1.3.3 其他资产类别投资策略的分类**
  - 房地产、商品、私募股权等。

## 第二部分：价值投资在股票中的应用

### # 第2章：股票投资的基本原理

#### 2.1 股票投资的核心概念

- **2.1.1 股票的内在价值评估**
  - 基于DCF模型（贴现现金流模型）。
  - 企业价值公式：$EV = \frac{FCF}{WACC}$。

- **2.1.2 股票的估值模型**
  - 市盈率（P/E）、市净率（P/B）、股息率。

- **2.1.3 股票市场的波动性与价值发现**
  - 市场恐慌时的买入机会。

#### 2.2 价值投资在股票中的具体策略

- **2.2.1 股票的选股标准**
  - 低市盈率、低市净率、高股息率。
  - 具体代码示例：
    ```python
    def filter_stocks(df, max_pe=15, max_pb=2, min_dividend=0.02):
        filtered = df[(df['PE'] <= max_pe) & (df['PB'] <= max_pb) & (df['Dividend Yield'] >= min_dividend)]
        return filtered
    ```

- **2.2.2 股票投资组合的构建**
  - 分散投资以降低风险。
  - 使用Python计算夏普比率：
    ```python
    import numpy as np
    def sharpe_ratio(returns, risk_free_rate):
        excess_returns = returns - risk_free_rate
        return np.mean(excess_returns) / np.std(excess_returns)
    ```

#### 2.3 股票投资中的风险与收益

- **2.3.1 股票投资的主要风险**
  - 市场风险、流动性风险、企业特有风险。

- **2.3.2 股票投资的预期收益**
  - 历史平均回报率为7%-10%。

- **2.3.3 风险控制与投资组合优化**
  - 使用现代投资组合理论优化资产配置。

- **3.1.1 债券的内在价值评估**

- **3.2.1 债券的评级分析**

  - 利息覆盖率（CFO/Interest Expense）。

- **3.2.2 债券投资组合的构建**
  - 根据风险偏好选择债券类型。
  - 使用Python计算债券的到期收益率：
    ```python
    def bond_yield(price, coupon_rate, face_value, years):
        return (coupon_rate * face_value / price)
    ```

#### 3.3 债券投资中的风险与收益

- **3.3.2 债券投资的预期收益**
