## 第1章: 查理·芒格及其投资哲学概述

### 1.1 查理·芒格的生平与思想  
查理·芒格（Charlie Munger）是世界著名投资者、伯克希尔哈撒韦公司副主席，以独特的投资哲学和思维方式闻名。他的多元思维模型（mental models）是其分析商业模式的核心工具，强调通过跨学科的视角理解商业的本质。

#### 1.1.1 查理·芒格的生平简介  
查理·芒格于1924年出生在美国密歇根州，毕业于密歇根大学法学院，后转入哈佛法学院，师从著名法理学教授哈罗德·伯尔格。1950年代，他开始接触投资领域，并逐渐形成了自己的投资哲学。  

#### 1.1.2 芒格的投资哲学与思维方式  
芒格的投资哲学强调“逆向思维”（invert, always invert），即从反方向思考问题。他认为，成功的商业模式源于对行业本质的深刻理解，而非简单的财务指标。  

#### 1.1.3 芒格的多元思维模型  
多元思维模型是芒格分析商业模式的核心工具，其特点如下：  
1. **跨学科视角**：整合物理学、心理学、经济学等多学科的思维方式。  
2. **动态性**：模型之间的相互作用形成动态平衡，而非静态结构。  
3. **实践性**：通过实际案例验证模型的有效性。

### 1.3 芒格的商业模式分析框架  

#### 1.3.1 商业模式分析的核心概念与问题背景  
商业模式分析的核心在于理解企业如何创造价值、传递价值和获取价值。芒格的框架强调从多维度审视企业的商业模式，包括：  
1. 企业的核心竞争力。  
2. 行业的生命周期。  
3. 竞争格局与市场定位。

- 企业处于稳定增长阶段。

### 2.2 多元思维模型的Python实现  

```python
# 定义多元思维模型的类
class MentalModel:
    def __init__(self, factors):
        self.factors = factors  # 多元思维模型的因子

    def calculate(self):
        # 计算模型结果
        result = {}
        for factor in self.factors:
            result[factor] = self._compute(factor)
        return result

    def _compute(self, factor):
        # 根据因子选择计算方法
        if factor == 'physics':
            return self._physics()
        elif factor == 'psychology':
            return self._psychology()
        elif factor == 'economics':
            return self._economics()
        else:
            return 0

    def _physics(self):
        # 物理学模型计算
        return 1

    def _psychology(self):
        # 心理学模型计算
        return 2

    def _economics(self):
        # 经济学模型计算
        return 3

# 创建多元思维模型实例
model = MentalModel(['physics', 'psychology', 'economics'])
# 计算模型结果
result = model.calculate()
print(result)  # 输出：{'physics': 1, 'psychology': 2, 'economics': 3}
```
