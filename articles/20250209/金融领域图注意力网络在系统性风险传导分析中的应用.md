- **定义与特征**：系统性风险是指由于金融系统中某些关键机构或市场的波动，导致整个系统发生连锁反应的风险。其特点包括传染性、全局性和不可分割性。  
- **来源与影响**：系统性风险的主要来源包括市场波动、金融机构的相互依赖性以及外部冲击。其影响表现为系统性金融危机的发生，可能导致经济衰退和社会不稳定。  
- **度量方法**：常用的系统性风险度量方法包括基于VaR（Value at Risk）的模型、网络风险度量模型以及压力测试方法。

#### 1.2 金融网络与风险传导机制

- **系统性风险的传导路径**：系统性风险可以通过直接关联、间接关联和系统性传染三种路径进行传导。

- **注意力机制的核心思想**：注意力机制通过计算输入数据中各个部分的重要性权重，将注意力权重与原始数据进行加权求和，从而提取出重要的特征信息。  
- **注意力机制在不同领域的应用**：在自然语言处理中，注意力机制用于序列建模；在计算机视觉中，注意力机制用于目标检测和图像分割。

### 第5章: 图注意力网络的算法实现  

#### 5.1 图注意力网络的数学模型  
- **图注意力网络的节点表示公式**：节点表示公式为 $h_i = \sum_{j} \alpha_{ij} h_j$，其中 $\alpha_{ij}$ 是节点 $i$ 和节点 $j$ 之间的注意力权重。  
- **注意力权重的计算方法**：注意力权重 $\alpha_{ij}$ 可以通过节点特征和边权重的点积计算得到，具体公式为 $\alpha_{ij} = \text{softmax}(e^{q^T k})$，其中 $q$ 是查询向量，$k$ 是键向量。  
- **图注意力网络的损失函数与优化方法**：损失函数可以使用交叉熵损失函数，优化方法可以使用Adam优化器。

- **模型评估**：通过测试数据评估模型的性能，包括准确率、召回率和F1值。

#### 5.3 图注意力网络的实现代码

```python
import tensorflow as tf
from tensorflow.keras import layers

class GraphAttentionLayer(layers.Layer):
    def __init__(self, input_dim, attention_dim):
        super(GraphAttentionLayer, self).__init__()
        self.W = layers.Dense(attention_dim, input_shape=(input_dim,))
        self.u = layers.Dense(1, input_shape=(attention_dim,))
    
    def call(self, inputs):
        # inputs shape: (batch_size, nodes, input_dim)
        attention_scores = self.u(tf.nn.relu(self.W(inputs)))
        attention_weights = tf.nn.softmax(attention_scores, axis=1)
        outputs = tf.reduce_sum(inputs * attention_weights, axis=1)
        return outputs

# 示例用法
input_dim = 10
attention_dim = 5
model = GraphAttentionLayer(input_dim, attention_dim)
inputs = tf.random.normal((1, 10, input_dim))
outputs = model(inputs)
print(outputs.shape)  # 输出形状：(1, attention_dim)
```
