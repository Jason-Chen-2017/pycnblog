## 第一部分：投资组合再平衡策略的背景与意义

### 第1章：投资组合再平衡策略概述

#### 1.1 投资组合再平衡的背景与意义
- **背景**  
  投资组合管理是实现长期投资目标的核心，而投资组合再平衡是确保投资组合按目标权重分配的关键策略。随着市场波动和资产表现的变化，投资组合的实际权重会偏离目标权重，导致风险和收益的不均衡。再平衡通过调整资产权重，维持投资组合的稳定性，降低风险并优化收益。

- **意义**  
  再平衡策略能够有效应对市场波动，降低投资组合的下行风险，同时捕捉市场机会。通过定期或不定期的再平衡，投资者可以避免过度集中在表现不佳的资产，从而提升整体投资组合的收益。

- **约翰·伯格的贡献**  
  约翰·伯格是投资组合再平衡领域的先驱，他提出了一套系统化的再平衡策略，强调定期审视和调整投资组合，以保持目标资产配置。伯格的策略不仅理论严谨，还在实践中得到了广泛应用，成为投资领域的重要参考。

#### 1.2 投资组合再平衡的核心概念
- **定义**  
  投资组合再平衡是指根据设定的目标资产配置比例，定期或不定期地调整投资组合的资产权重，以应对市场波动和资产表现变化的过程。

- **再平衡的原理与机制**  
  再平衡的核心是通过调整资产权重，使投资组合的风险和收益保持在目标范围内。当某类资产的表现优于其他资产时，其权重会增加，反之则减少。

- **再平衡与投资目标的关系**  
  再平衡策略紧密围绕投资目标展开，确保投资组合的结构与目标一致，同时适应市场变化。

#### 1.3 投资组合再平衡的分类与特点
- **分类**  
  再平衡可以分为定期再平衡和事件驱动再平衡。定期再平衡按固定时间间隔进行，如季度或半年；事件驱动再平衡则根据特定事件触发，如资产权重偏离目标超过一定阈值。

- **特点**  
  再平衡策略具有灵活性和系统性，能够根据市场变化和投资者风险承受能力进行调整。定期再平衡策略简单易行，而事件驱动再平衡则更具针对性。

#### 1.4 约翰·伯格再平衡策略的独特性
- **核心思想**  
  伯格强调长期投资和定期再平衡的重要性，认为市场波动是投资机会，而不是风险。

- **与其他策略的对比**  
  与被动投资策略不同，伯格的再平衡策略结合了主动管理的思想，定期审视和调整投资组合，以适应市场变化。

- **实际应用案例**  
  伯格通过实际案例展示了再平衡策略的有效性，尤其是在市场波动较大时，再平衡能够显著降低风险并提高收益。

#### 1.5 本章小结
本章介绍了投资组合再平衡的背景和意义，详细阐述了再平衡的核心概念和分类，并对比了伯格策略的独特性。再平衡策略在投资组合管理中扮演着重要角色，是实现长期投资目标的关键工具。

def calculate_weights(prices, initial_weights):
    current_weights = initial_weights * prices / prices.sum()
    return current_weights

def rebalance_portfolio(target_weights, current_weights, prices):
    rebalance_amount = target_weights - current_weights
    return rebalance_amount
