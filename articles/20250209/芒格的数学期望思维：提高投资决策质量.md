## 1.2 数学期望的基本概念

### 1.2.1 数学期望的定义

数学期望（Mathematical Expectation）是概率论中的一个基本概念，用于描述一个随机变量的长期平均值。公式为：
$$
E[X] = \sum_{i=1}^{n} P(x_i) \cdot x_i
$$

其中，$P(x_i)$ 是结果 $x_i$ 的概率。

### 1.2.2 数学期望的计算方法

数学期望的计算方法包括离散型随机变量和连续型随机变量的期望值计算。对于离散型随机变量，期望值是每个可能结果乘以其概率的和；对于连续型随机变量，则是概率密度函数的积分。

### 1.2.3 数学期望在投资中的应用

在投资中，数学期望用于评估资产的预期收益和风险。例如，股票投资者可以通过计算股票的期望收益和波动率，来评估其潜在的收益和风险。

### 1.3.2 投资中的概率分布

# 第2章: 数学期望的原理与应用

## 2.1 数学期望的原理

### 2.1.1 随机变量的期望值

随机变量可以是离散型或连续型。离散型随机变量的期望值是各个可能结果乘以其概率的和，而连续型随机变量的期望值是概率密度函数的积分。

### 2.1.2 期望值的线性性质

期望值具有线性性质，即对于任意两个随机变量X和Y，以及常数a和b：
$$
E[aX + bY] = aE[X] + bE[Y]
$$

### 2.1.3 期望值的条件概率

条件概率是指在给定某些条件下，事件发生的概率。期望值的条件概率用于在特定条件下评估随机变量的期望值。

---

## 2.2 数学期望在投资中的应用

### 2.2.1 股票投资的期望收益计算

股票投资者可以通过计算股票的期望收益来评估其潜在收益。假设某股票有三种可能的收益：10%、15%和20%，对应的概率分别为0.3、0.5和0.2。则期望收益为：
$$
E[R] = 0.3 \times 10\% + 0.5 \times 15\% + 0.2 \times 20\% = 13.5\%
$$

### 2.2.2 债券投资的期望收益计算

债券的期望收益可以通过计算债券的票面利率和可能的违约风险来评估。假设债券的票面利率为8%，违约概率为10%，则期望收益为：
$$
E[R] = 0.9 \times 8\% + 0.1 \times 0\% = 7.2\%
$$

### 2.2.3 组合投资的期望收益计算

组合投资的期望收益是各资产期望收益的加权平均值。假设投资组合由股票和债券组成，权重分别为60%和40%，股票的期望收益为13.5%，债券的期望收益为7.2%，则组合投资的期望收益为：
$$
E[R_{\text{组合}}] = 0.6 \times 13.5\% + 0.4 \times 7.2\% = 11.1\%
$$

---

## 2.3 投资中的风险与期望值

### 2.3.1 风险的定义与衡量

风险是投资回报的不确定性，通常用标准差或方差来衡量。方差是期望值的平方与平方的期望值的差：
$$
\text{Var}(X) = E[X^2] - (E[X])^2
$$

标准差是方差的平方根：
$$
\sigma = \sqrt{\text{Var}(X)}
$$

### 2.3.2 风险与期望值的关系

高风险通常伴随着高期望收益，但并非所有高风险投资都能带来高收益。投资者需要在风险和收益之间找到平衡点。

### 2.3.3 如何通过期望值优化投资决策

投资者可以通过计算不同投资的期望收益和风险，选择具有更高期望收益且风险可接受的投资。

import numpy as np
import pandas as pd

returns = [0.1, 0.15, 0.2]

## 5.3 案例三: 组合投资决策

### 5.3.1 案例背景介绍

假设某投资者有100万元资金，计划投资于股票和债券组合。目标是通过优化资产配置，实现收益最大化和风险最小化。

### 5.3.2 数学期望在组合投资中的具体应用

通过计算股票和债券的期望收益和风险，以及组合投资的期望收益和风险，投资者可以选择最优的资产配置比例。

### 5.3.3 实战代码实现

以下是组合投资决策的Python代码实现：

```python
import numpy as np
import pandas as pd

# 假设股票和债券的收益数据
stock_returns = [0.135, 0.135, 0.135]
bond_returns = [0.072, 0.072, 0.072]

# 计算股票和债券的期望收益
expected_stock = np.mean(stock_returns)
expected_bond = np.mean(bond_returns)

# 计算股票和债券的标准差
std_stock = np.std(stock_returns)
std_bond = np.std(bond_returns)

# 计算组合的期望收益
weight_stock = 0.6
weight_bond = 0.4
expected_portfolio = weight_stock * expected_stock + weight_bond * expected_bond

# 计算组合的标准差
covariance = 0.02  # 假设相关系数为0.2，标准差为股票和债券的标准差
std_portfolio = np.sqrt((weight_stock ** 2 * std_stock ** 2) + (weight_bond ** 2 * std_bond ** 2) + 2 * weight_stock * weight_bond * covariance)

print(f"组合期望收益: {expected_portfolio:.2f}%")
print(f"组合标准差: {std_portfolio:.2f}%")
```

### 5.3.4 实战结果分析

运行上述代码，可以得到组合投资的期望收益和标准差。投资者可以根据这些结果，评估组合投资的潜在收益和风险，并做出投资决策。
