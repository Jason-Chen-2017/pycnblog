## 第1章：循环经济与价值投资的背景

### 1.1 循环经济的定义与特征

#### 1.1.1 循环经济的定义  
循环经济是一种以资源高效利用和循环利用为核心的发展模式，强调通过减少资源消耗、延长产品生命周期以及废弃物资源化，实现经济与环境的可持续发展。其核心在于“从摇篮到摇篮”的理念，即从原材料提取到产品最终报废的全生命周期中，最大限度地减少资源消耗和环境污染。

#### 1.1.2 循环经济的核心特征  
- **资源效率**：循环经济通过优化资源利用，减少对自然资源的依赖。  
- **闭环模式**：强调废弃物的再利用，形成资源的闭环流动。  
- **可持续性**：通过减少环境污染和资源消耗，实现经济与环境的平衡发展。  

#### 1.1.3 循环经济的背景与发展趋势  
随着全球资源枯竭和环境问题的加剧，循环经济已成为全球关注的焦点。各国政府和企业都在积极推动循环经济的发展，相关政策和法规也不断完善。循环经济不仅有助于减少环境压力，还能为企业创造新的经济增长点。

### 1.2 巴菲特与芒格的价值投资理念

#### 1.2.1 巴菲特的价值投资理论  
巴菲特的价值投资理念强调以合理的价格买入具有持续竞争优势的企业。他注重企业的内在价值，即企业未来现金流的现值，而非市场的短期波动。他的投资策略基于对企业基本面的深入分析，包括盈利能力、财务状况和行业地位等。

#### 1.2.2 芒格的多元思维模型  
芒格提倡多元思维模型，认为投资者需要从多个角度（如经济学、心理学、物理学等）分析问题。这种思维方式帮助投资者避免认知偏差，做出更明智的决策。芒格强调长期主义，认为投资不仅仅是购买股票，而是购买企业的一部分。

#### 1.2.3 价值投资与长期主义  
价值投资的核心在于寻找那些被市场低估的企业，并长期持有。长期主义不仅是投资策略，更是对社会和环境负责的态度。在循环经济中，长期主义尤为重要，因为循环经济的成功需要时间和持续的努力。

### 1.3 循环经济与价值投资的结合

#### 1.3.1 循环经济中的投资机会  
循环经济涉及多个领域，如废物资源化、绿色能源、可持续材料等。这些领域不仅具有巨大的市场潜力，还能为投资者带来长期收益。例如，新能源汽车、可再生能源和循环经济服务等都是潜力巨大的投资领域。

#### 1.3.2 价值投资在循环经济中的应用

import pandas as pd
import numpy as np

# 定义企业评估函数
def calculate_intrinsic_value(enterprise):
    # 计算现金流
    CF_t = enterprise.profitability * (1 + enterprise.growth_rate)
    # 计算折现率
    r = 0.1
    # 计算内在价值
    V = sum(CF_t / (1 + r)**t for t in range(1, 5))
    return V

# 定义投资机会评估函数
def evaluate_investment_opportunity(opportunity):
    # 计算投资回报率
    ROI = (opportunity.net_profit / opportunity.cost) * 100
    return ROI

# 示例企业数据
class Enterprise:
    def __init__(self, name, industry, profitability, financial_health, competitive_advantage):

        self.industry = industry
        self.profitability = profitability
        self.financial_health = financial_health
        self.competitive_advantage = competitive_advantage

# 示例投资机会数据
class InvestmentOpportunity:
    def __init__(self, name, industry, resource_utilization, environmental_impact, sustainability_performance):
        self.name = name
        self.industry = industry
        self.resource_utilization = resource_utilization
        self.environmental_impact = environmental_impact
        self.sustainability_performance = sustainability_performance
