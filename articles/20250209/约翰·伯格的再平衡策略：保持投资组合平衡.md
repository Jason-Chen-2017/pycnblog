## 第1章: 投资组合再平衡策略概述

### 1.1 投资组合管理的基本概念

#### 1.1.1 投资组合的定义与特点

- 投资组合是将资金分配到多种资产（股票、债券、现金等）的集合。
- 特点：分散风险，优化收益，动态调整。

#### 1.1.2 投资组合管理的目标与意义

- 目标：最大化收益，最小化风险。
- 意义：通过科学配置，平衡风险与收益。

#### 1.1.3 再平衡策略的定义与作用

- 定义：定期调整资产权重，使组合符合预定目标。
- 作用：防范风险，抓住机会。

### 1.2 约翰·伯格的再平衡策略背景

#### 1.2.1 投资组合失衡的常见原因

- 市场波动，资产表现差异。
- 资金流入流出，影响权重。

#### 1.2.2 约翰·伯格再平衡策略的提出背景

- 基于长期投资理念，强调定期调整。

#### 1.2.3 再平衡策略在现代投资中的重要性

- 适应市场变化，保持资产配置。

### 1.3 再平衡策略的核心概念

#### 1.3.1 资产配置的基本原理

- 确定目标，选择资产类别。
- 分配权重，定期调整。

#### 1.3.2 投资组合权重的动态调整

- 权重偏离目标时，进行调整。
- 调整频率：定期或不定期。

#### 1.3.3 再平衡策略的分类与特点

- 定期再平衡：固定时间调整。
- 门槛再平衡：偏离超过阈值时调整。

## 第2章: 再平衡策略的数学模型与算法

### 2.1 再平衡策略的数学模型

#### 2.1.1 投资组合权重调整的数学公式

- 权重调整公式：$w_{target} = (w_1, w_2, ..., w_n)$。
- 偏差计算：$w_{target} - w_{current}$。

#### 2.1.2 再平衡策略的优化模型

- 线性规划模型：最小化调整成本。
- 均衡模型：优化权重分布。

import pandas as pd
def calculate_current_weights(portfolio_value, asset_prices, quantities):
    current_weights = {}
    total = sum(asset_prices * quantities)
    for i in range(len(asset_prices)):
        current_weights[i] = (asset_prices[i] * quantities[i]) / total
    return current_weights

def calculate_target_weights(risk_tolerance):
    target_weights = {}

    target_weights['债券'] = risk_tolerance
