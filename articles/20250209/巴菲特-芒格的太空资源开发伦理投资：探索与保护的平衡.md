### 第4章: 太空资源开发的伦理投资算法与模型

#### 4.1 伦理投资评估算法
- 4.1.1 算法原理与流程
  - 输入：项目的基本信息、伦理影响因素。
  - 输出：伦理评分与投资建议。
  - 流程：数据采集 → 伦理影响评估 → 综合评分 → 投资决策。
- 4.1.2 算法的数学模型
  - 综合评分公式：
    $$ S = \alpha E + \beta S + \gamma G $$
    其中，$E$、$S$、$G$分别为环境、社会、治理评分，$\alpha$、$\beta$、$\gamma$为权重系数。
- 4.1.3 算法的实现步骤
  1. 收集项目的基本信息。
  2. 评估环境、社会、治理评分。
  3. 计算综合评分。
  4. 根据评分制定投资建议。

#### 6.4 项目实现代码

  import numpy as np
  
  # 数据加载
  data = pd.read_csv('space_resources.csv')
  
  # 数据预处理
  data.dropna(inplace=True)
  
  # 计算综合评分
  alpha = 0.5
  beta = 0.3
  gamma = 0.2
  scores = []
  for index, row in data.iterrows():
      E = row['Environment']
      S = row['Social']
      G = row['Governance']
      score = alpha * E + beta * S + gamma * G
      scores.append(score)
  
  # 结果保存
  data['Score'] = scores
  data.to_csv('result.csv', index=False)
