### 3.1 常见算法概述

#### 3.1.1 机器学习算法
- **线性回归**：用于预测债券收益率。
- **支持向量机（SVM）**：用于分类债券信用等级。

### 3.2 算法实现与代码示例

#### 3.2.1 线性回归实现

# 示例数据

### 3.3 数学模型与公式

#### 3.3.1 投资组合优化的数学模型
$$ \text{目标函数：} \min_w \frac{1}{2}w^T \Sigma w $$
$$ \text{约束条件：} \mathbf{1}^T w = 1, \quad w \geq 0 $$

其中，$\Sigma$ 是协方差矩阵，$w$ 是投资权重向量。

#### 3.3.2 风险调整后的收益公式
$$ \text{夏普比率} = \frac{E[r_p] - r_f}{\sigma_p} $$

其中，$E[r_p]$ 是投资组合的期望收益，$r_f$ 是无风险利率，$\sigma_p$ 是投资组合的标准差。

import numpy as np
from scipy.optimize import minimize

# 定义优化函数
def optimize_portfolio(weights, returns, covariance):
    return (weights.T @ covariance @ weights).item()

# 约束条件
cons = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1})

# 最优化
result = minimize(optimize_portfolio, np.array([0.5, 0.5]), args=(returns, covariance), constraints=cons)
