## 格雷厄姆的核心投资理念

### 1. 安全边际的概念与计算

#### 1.1 安全边际的定义
安全边际是格雷厄姆提出的核心概念，指股票的市场价格低于其内在价值的部分。通过安全边际，投资者可以降低风险，确保投资的稳健性。

#### 1.2 安全边际的计算方法
使用格雷厄姆的公式：
$$ \text{内在价值} = \text{每股收益} \times (市盈率 + 贷款利息/资本成本) $$

通过代码实现安全边际计算：
```python
def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price
```

### 2. 市场先生与投资者心理

#### 2.1 市场先生的比喻
格雷厄姆用市场先生来描述市场的波动性，提醒投资者不要受短期市场情绪影响。

#### 2.2 投资者心理对决策的影响
分析行为偏差，如过度自信和损失厌恶，帮助投资者做出理性决策。

### 3. 股票的价值评估

#### 3.1 内在价值评估方法
使用格雷厄姆的方法评估企业价值：
$$ \text{内在价值} = \text{净利润} \times (1 + \text{长期增长率}) / (\text{资本成本} - \text{增长率}) $$
