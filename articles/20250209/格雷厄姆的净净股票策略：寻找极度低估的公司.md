# 第1章: 价值投资与净净股票策略的背景

## 1.1 价值投资的起源与发展

### 1.1.1 价值投资的定义与核心理念

价值投资是一种以公司基本面分析为基础的投资策略，强调以低于公司内在价值的价格购买股票。其核心理念是市场先生的非理性定价和安全边际的重要性。格雷厄姆是价值投资的鼻祖，他提出的“安全边际”概念成为该策略的核心。

$$\text{安全边际} = \text{内在价值} - \text{市场价格}$$

### 1.1.2 格雷厄姆与巴菲特的价值投资体系

格雷厄姆的学生巴菲特进一步发展了价值投资理论，强调长期持有和分散投资。格雷厄姆的净净股票策略是价值投资的重要组成部分，巴菲特早期的投资哲学深受其影响。

### 1.1.3 净净股票策略的提出与演变

净净股票策略的核心是通过筛选低市盈率、低市净率和高股息率的股票，寻找市场估值远低于公司内在价值的公司。

---

## 1.2 净净股票策略的核心思想

### 1.2.1 净净股票的定义与特征

净净股票是指那些市场价格远低于其内在价值的股票，通常表现为低市盈率（P/E）、低市净率（P/B）和高股息率（Dividend Yield）。这些股票往往被市场忽视或低估，但具有稳定的盈利能力和发展潜力。

### 1.2.2 安全边际与市场价格波动

市场价格波动是价值投资中的一个重要因素。当市场价格远低于内在价值时，股票具有较高的安全边际，投资者可以以较低的风险买入并长期持有。

### 1.2.3 净净股票策略的适用场景与边界

净净股票策略适用于那些具有稳定财务状况和良好盈利能力的公司，但通常不适用于高增长行业或新兴行业。此外，该策略在市场低迷时期表现更为优异。

---

## 1.3 价值投资的决策框架

### 1.3.1 投资决策的三要素

1. **内在价值**：公司未来现金流的现值。
2. **市场价格**：股票的当前市场价格。
3. **安全边际**：内在价值与市场价格的差额。

### 1.3.2 投资组合的构建逻辑

1. **分散投资**：避免过度集中。
2. **长期持有**：等待价值回归。
3. **定期调整**：根据市场变化和公司基本面进行调整。

# 第2章: 净净股票的筛选标准

## 2.1 净净股票的筛选标准

### 2.1.1 低市盈率与低市净率

市盈率（P/E）和市净率（P/B）是衡量股票估值的重要指标。通常，格雷厄姆建议选择市盈率低于15，市净率低于1.5的股票。

$$\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}$$
$$\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}$$

### 2.1.2 高股息率与稳定的股息支付

股息率（Dividend Yield）是衡量股票收益能力的重要指标。格雷厄姆建议选择股息率较高的股票，但同时需要确保公司能够持续支付股息。

$$\text{股息率} = \frac{\text{每股股息}}{\text{股价}}$$

### 2.1.3 强大的财务状况与盈利能力

公司财务状况包括资产负债表和利润表。强大的财务状况表现为低负债率、高净资产收益率（ROE）和稳定的收入来源。

$$\text{ROE} = \frac{\text{净利润}}{\text{股东权益}}$$

## 2.3 净净股票筛选的实战技巧

### 2.3.1 如何避免价值陷阱

1. **分析公司基本面**：确保公司具有稳定的盈利能力。

import numpy as np
