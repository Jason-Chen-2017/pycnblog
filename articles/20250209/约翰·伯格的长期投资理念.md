## 第一部分: 投资理念的背景与起源

### 第1章: 投资理念的背景

#### 1.1 投资理念的背景

现代投资理论经历了从早期的简单分析到复杂模型的演变。20世纪中叶，价值投资逐渐成为主流，约翰·伯格作为该领域的先驱，提出了长期投资理念，强调基本面分析和长期持有优质资产。

#### 1.2 约翰·伯格的投资理念起源

约翰·伯格的投资理念起源于对市场有效性的质疑，他认为市场并非总是有效，优质资产长期表现稳定。这种理念结合了基本面分析和风险管理，形成了一套独特的方法论。

#### 1.3 长期投资理念的核心价值

长期投资理念强调时间复利效应，通过长期持有优质资产，降低短期波动风险，实现财富稳步增长。

### 第2章: 长期投资理念的核心概念

#### 2.1 价值投资的定义与特点

价值投资是寻找市场价格低于内在价值的资产。其特点包括注重基本面分析、长期持有、逆向投资和安全边际。

| 投资类型 | 短期投资 | 长期投资 |
|----------|-----------|-----------|
| 时间跨度 | 短于一年 | 超过五年 |
| 风险 | 高 | 低 |
| 目标 | 短期收益 | 长期增值 |

#### 2.2 约翰·伯格的投资策略

约翰·伯格的投资策略包括分散投资、集中投资、长期持有和定期再平衡。

### 第3章: 长期投资理念的数学模型与公式

#### 3.1 投资组合优化的数学模型

均值-方差优化模型用于构建最优投资组合：

$$ E(r_p) = \sum_{i=1}^n w_i E(r_i) $$

$$ Var(r_p) = \sum_{i=1}^n w_i^2 Var(r_i) + 2\sum_{i=1}^{n-1} \sum_{j=i+1}^n w_i w_j Cov(r_i, r_j) $$

其中，$w_i$为资产i的权重，$E(r_i)$为期望收益，$Var(r_i)$为方差，$Cov(r_i, r_j)$为协方差。

import numpy as np

def portfolio_optimization(returns):
    n = len(returns.columns)
    cov_matrix = returns.cov()
    returns_mean = returns.mean()
    weights = np.linalg.inv(cov_matrix) @ returns_mean
    weights = weights / weights.sum()
    return weights
