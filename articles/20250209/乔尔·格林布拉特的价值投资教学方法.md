# 第一部分：价值投资的基础与核心理念

## 第1章：价值投资概述

### 1.1 价值投资的定义与历史发展
- 价值投资的起源：始于20世纪初，由本杰明·格雷厄姆和戴维·多德提出。
- 核心理念：寻找市场价格低于内在价值的股票，长期持有，等待市场回归。

### 1.2 价值投资的核心原则
- 内在价值的计算：$$ V = \frac{E}{(r - g)} $$
- 安全边际：买入价格低于内在价值的一定折扣。
- 长期视角：复利效应的重要性。

## 第2章：乔尔·格林布拉特的价值投资理念

### 2.2 格林布拉特的选股标准

# 第二部分：格林布拉特的价值投资模型

## 第3章：格林布拉特模型的数学基础

### 3.1 内在价值的计算
- 格林布拉特模型：$$ V = \frac{E}{(r - g)} $$
- 参数解释：
  - \( E \)：企业未来现金流的现值。
  - \( r \)：期望回报率。
  - \( g \)：增长率。

### 3.2 实例计算
- 假设某公司净利润为$100万，股东权益为$500万，ROE=20%，期望回报率r=10%，增长率g=5%。
- 计算内在价值：
  $$ V = \frac{100}{(0.1 - 0.05)} = \frac{100}{0.05} = 2000万 $$

### 3.3 代码实现
```python
def calculate_intrinsic_value(net_profit, equity, roe, r, g):
    return net_profit / (r - g)

# 示例
net_profit = 100  # 单位：万元
equity = 500      # 单位：万元
roe = 0.2         # ROE = 20%
r = 0.1           # 期望回报率 = 10%
g = 0.05          # 增长率 = 5%

intrinsic_value = calculate_intrinsic_value(net_profit, equity, roe, r, g)
print(f"内在价值为：{intrinsic_value}万元")
```
