# 第3章 算法原理讲解

## 3.1 常见算法及其流程

### 3.1.1 线性回归

#### 3.1.1.1 算法流程图
```mermaid
graph TD
    X(特征) --> Y(预测值)
    Y --> O(优化目标)
    O --> S(损失函数)
    S --> G(梯度下降)
    G --> W(权重更新)
```

#### 3.1.1.2 Python代码实现
```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 示例数据
X = np.array([[1], [2], [3], [4]])
y = np.array([2, 4, 6, 8])

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测
print(model.predict([[5]]))  # 输出：[[10]]
```

#### 3.1.1.3 数学模型
$$ y = \beta_0 + \beta_1 x + \epsilon $$

### 3.1.2 随机森林

#### 3.1.2.1 算法流程图
```mermaid
graph TD
    D(数据) --> T(决策树)
    T --> F(特征选择)
    F --> M(模型集成)
    M --> P(预测结果)
```

#### 3.1.2.2 Python代码实现
```python
from sklearn.ensemble import RandomForestRegressor

# 示例数据
X = np.array([[1, 2], [3, 4], [5, 6]])
y = np.array([3, 7, 11])

# 模型训练
model = RandomForestRegressor(n_estimators=100)
model.fit(X, y)

# 预测
print(model.predict([[7, 8]]))  # 输出：[15.]
```

#### 3.1.2.3 数学模型
随机森林通过集成多个决策树进行投票或平均，公式表示为：
$$ \hat{y} = \frac{1}{N} \sum_{i=1}^{N} T_i(x) $$

# 第4章 数学模型与公式

## 4.1 回归模型

### 4.1.1 线性回归
$$ y = \beta_0 + \beta_1 x + \epsilon $$

### 4.1.2岭回归
$$ \hat{\beta} = (X^T X + \lambda I)^{-1} X^T y $$

## 4.2 分类模型

### 4.2.1 逻辑回归
$$ P(Y=1|X) = \frac{1}{1 + e^{- (w \cdot X + b)}} $$

### 4.2.2 支持向量机
$$ \text{目标函数} = \sum_{i=1}^{n} C_i y_i (w \cdot x_i + b) + \sum_{i=1}^{n} \lambda \alpha_i (\alpha_j - \alpha_i)(y_j y_i - 1) $$

## 4.3 时间序列模型

### 4.3.1 ARIMA
$$ \phi(\theta(B)) Z_t = \theta(B) \phi(B) W_t $$

## 4.4 集成学习模型

### 4.4.1 Bootstrap aggregating (Bagging)
$$ \hat{f}(x) = \frac{1}{n} \sum_{i=1}^{n} f_{b_i}(x) $$
