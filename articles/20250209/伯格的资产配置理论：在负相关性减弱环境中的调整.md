## 第1章: 资产配置的基本概念与背景

### 1.1 资产配置的定义与作用

资产配置是投资过程中至关重要的一环，涉及将资金分配到不同资产类别（如股票、债券、房地产等）以实现风险与收益的平衡。资产配置不仅决定了投资组合的整体表现，还影响着组合的波动性和潜在回报。

#### 1.1.1 资产配置的基本概念

资产配置的核心在于分散投资，通过将资金分配到不同的资产类别中，降低单一资产价格波动对整体组合的影响。这种分散化策略是降低风险的有效手段。

#### 1.1.2 资产配置在投资组合中的作用

资产配置不仅是投资策略的起点，更是实现投资目标的关键。通过科学的资产配置，投资者可以在不同市场环境下优化组合的收益与风险比。

#### 1.1.3 资产配置与风险控制的关系

资产配置与风险控制密不可分。通过合理分配资产权重，投资者可以有效降低组合的整体风险，同时捕捉不同资产类别的收益机会。

### 1.2 伯格的资产配置理论概述

伯格的资产配置理论基于现代投资组合理论（MPT），强调通过数学模型优化投资组合的收益与风险比。

import numpy as np
import pandas as pd

# 定义优化函数
def optimize_portfolio(weights, returns):
    # 计算组合收益
    portfolio_return = np.dot(weights, returns)
    # 计算组合风险
    portfolio_variance = np.dot(weights.T, np.dot(returns.cov(), weights))
    return -portfolio_return + 0.05 * portfolio_variance

# 优化权重
from scipy.optimize import minimize

# 初始权重
initial_weights = np.array([0.5, 0.5])
# 优化结果
result = minimize(optimize_portfolio, initial_weights, args=(returns,))
# 最优权重
optimal_weights = result.x
