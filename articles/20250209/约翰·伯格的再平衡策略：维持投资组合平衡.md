## 第二部分: 投资组合再平衡的算法原理

### 第3章: 投资组合再平衡的算法原理

#### 3.1 再平衡算法的数学模型
- **权重计算公式**：
  $$ w_i = \frac{v_i}{\sum_{j=1}^{n} v_j} $$
  其中，\( w_i \) 是第i个资产的权重，\( v_i \) 是第i个资产的价值，\( n \) 是资产总数。

#### 3.2 动态再平衡算法流程

#### 3.3 Python实现
```python
def rebalance_portfolio(current_weights, target_weights, tolerance=0.05):
    # 计算差异
    differences = {asset: current - target for asset, current, target in zip(
        current_weights.index, current_weights, target_weights)}
    
    # 执行交易
    for asset, diff in differences.items():
        if abs(diff) > tolerance:
            trade(asset, -diff)
    
    return current_weights.rebalance()
```

import pandas as pd
import numpy as np

def calculate_rebalanced_weights(weights, target_weights, tolerance=0.05):
    # 计算差异
    differences = weights - target_weights
    # 过滤差异超过容忍度的资产
    rebalanced_assets = [asset for asset in weights.index if abs(differences[asset]) > tolerance]
    # 计算调整后的权重
    new_weights = pd.Series(index=rebalanced_assets, data=np.ones(len(rebalanced_assets)) / len(rebalanced_assets))
    return new_weights

# 示例数据
current_weights = pd.Series({'股票':0.6, '债券':0.3, '现金':0.1})
target_weights = pd.Series({'股票':0.5, '债券':0.3, '现金':0.2})

# 执行再平衡
rebalanced_weights = calculate_rebalanced_weights(current_weights, target_weights)
print(rebalanced_weights)
```
