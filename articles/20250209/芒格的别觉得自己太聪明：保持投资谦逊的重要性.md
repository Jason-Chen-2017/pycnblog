## 第一部分：引言

### 第1章：芒格的智慧与投资哲学

#### 1.1 芒格的生平简介

查理·芒格（Charlie Munger）是美国著名投资者、巴菲特的长期合作伙伴，以其深刻的投资智慧和格栅理论闻名。芒格不仅是一位成功的投资者，更是一位心理学家，他的投资哲学深刻影响了全球投资界。

#### 1.2 投资中的智慧

芒格的投资理念强调“逆向思考”和“多学科思维模型”。他认为，投资者应避免过度自信，保持谦逊，认识到自身知识的局限性。这种谦逊态度是投资成功的关键。

#### 1.3 谦逊在投资中的重要性

在投资中，谦逊帮助投资者避免过度自信，从而减少错误决策。芒格指出，投资者应不断学习，承认自己的无知，并通过分散投资降低风险。

## 第二部分：芒格的“别觉得自己太聪明”理念

### 第2章：芒格理念的核心概念

#### 2.1 谦逊的定义与内涵

谦逊在投资中意味着承认自己的局限性，避免过度自信。芒格认为，投资者应认识到市场的不可预测性，保持开放心态，不断学习。

#### 2.2 谦逊的重要性

谦逊帮助投资者避免认知偏差，如过度自信、确认偏差等，从而做出更理性的决策。芒格强调，投资成功的关键是避免重大错误，而非追求完美。

#### 2.3 谦逊与其他投资原则的关系

谦逊与价值投资、风险管理等原则密切相关。芒格认为，价值投资需要谦逊，避免低估市场的复杂性。风险管理方面，谦逊帮助投资者制定更稳健的策略。

## 第三部分：行为心理学与投资决策

### 第3章：认知偏差与投资决策

#### 3.1 认知偏差的定义与类型

认知偏差是指人们在处理信息时产生的系统性错误。常见类型包括确认偏差、过度自信、损失厌恶等。

#### 3.2 认知偏差对投资决策的影响

认知偏差导致投资者做出错误决策，如过度交易、追涨杀跌等。芒格强调，认知偏差是投资失败的主要原因。

#### 3.3 谦逊如何帮助克服认知偏差

谦逊心态使投资者意识到自身局限性，愿意倾听他人意见，从而减少认知偏差的影响。

## 第四部分：投资策略与风险管理

### 第4章：基于谦逊的投资策略

#### 4.1 价值投资策略

价值投资强调寻找被市场低估的优质股票。芒格的谦逊态度使他更注重安全边际，避免过度乐观。

#### 4.2 分散投资策略

分散投资降低风险，芒格认为，通过分散投资，投资者可以减少单一投资的风险，保持谦逊心态。

#### 4.3 风险管理策略

芒格建议投资者制定严格的风险管理计划，设定止损点，避免重大损失。

import pandas as pd
import numpy as np

def value_investment_analysis(stock_data, industry_avg):
    # 计算市盈率
    stock_data['PE'] = stock_data['Price'] / stock_data['Earnings']
    # 比较市盈率与行业平均
    stock_data['Undervalued'] = stock_data['PE'] < industry_avg['PE']
    return stock_data

# 示例数据
industry_avg = {'PE': 15}
stock_data = pd.DataFrame({
    'Stock': ['A', 'B', 'C'],
    'Price': [100, 80, 120],
    'Earnings': [10, 8, 12]
})

result = value_investment_analysis(stock_data, industry_avg)
print(result)
