## 第三部分：算法原理讲解

### 第3章：基于上下文的注意力机制

#### 3.1 算法原理

- **注意力机制的定义**  
  注意力机制是一种用于处理序列数据的方法，通过计算数据中各部分的重要性来聚焦关键信息。

- **上下文感知的注意力机制**  
  在传统的注意力机制基础上，引入上下文信息，进一步提升模型的感知能力。

- **算法实现步骤**  
  1. 输入序列数据和上下文信息。  
  2. 计算每个位置的注意力权重。  
  3. 根据权重生成最终的感知结果。

#### 3.2 数学模型与公式

- **注意力权重计算公式**  
  $$\alpha_i = \text{softmax}(W_q x_i + b_q)$$

- **最终感知结果公式**  
  $$y_i = \sum_{j=1}^{n} \alpha_j x_j$$

#### 3.3 代码实现

```python
def attentionWithContext(x, context):
    # x: 输入序列，context: 上下文信息
    # 计算查询向量
    q = x.dot(W_q) + b_q
    # 计算注意力权重
    alpha = softmax(q)
    # 加权求和
    y = alpha.dot(x)
    return y
```
