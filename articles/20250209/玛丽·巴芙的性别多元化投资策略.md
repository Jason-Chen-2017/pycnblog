- **女性领导力评估**：评估女性领导者在企业中的影响力和决策能力。  
- **社会影响力**：关注企业对性别平等的贡献和社会责任感。  

#### 1.1.3 性别多元化投资的背景与重要性

## 第3章：性别多元化投资的算法与数学模型

### 3.1 性别多元化投资的算法与数学模型

#### 3.1.1 性别多样性指数计算  
性别多样性指数（GDI）用于量化企业的性别多样性表现，公式如下：  
$$ GDI = \frac{\text{女性高管比例} + \text{女性董事会比例}}{2} $$  

#### 3.1.2 投资组合优化模型  
构建性别多元化投资组合的优化模型：  
$$ \text{最大化收益} = \sum_{i=1}^{n} w_i r_i $$  
$$ \text{约束条件} = \sum_{i=1}^{n} w_i = 1, \quad \sum_{i=1}^{n} w_i GDI_i \geq 0.5 $$  

其中，$w_i$为投资权重，$r_i$为投资回报率，$GDI_i$为企业的性别多样性指数。

#### 3.1.3 投资组合优化的实现  
使用Python实现投资组合优化：

```python
import numpy as np
from scipy.optimize import minimize

# 示例数据
GDI = [0.7, 0.6, 0.8, 0.5]  # 性别多样性指数
returns = [0.1, 0.15, 0.12, 0.08]  # 投资回报率

# 定义目标函数
def objective(weights):
    return -sum(weights * returns)

# 定义约束条件
constraints = [
    {'type': 'eq', 'fun': lambda w: sum(w) - 1},
    {'type': 'geq', 'fun': lambda w: sum(w * GDI) - 0.5}
]

# 优化求解
result = minimize(objective, np.ones(len(returns))/len(returns), constraints=constraints)

print("最优权重：", result.x)
```
