##### 1.1 投资背景
- 1.1.1 现代投资学的发展
现代投资学自20世纪初以来，经历了从基本面分析到量化分析的转变。彼得·林奇作为价值投资的代表人物，强调对公司基本面的深入研究。

- 1.1.2 成长型投资的兴起
成长型投资在20世纪70年代兴起，强调投资于具有高增长潜力的公司，而非仅仅追求低市盈率的股票。

- 1.1.3 彼得·林奇的筛选标准
林奇提出，成长型价值股应具备稳定的收入和利润增长，良好的财务状况，以及强大的市场地位。

##### 1.2 成长型与价值型股票的对比
- 1.2.1 价值型股票的特点
价值型股票通常市盈率较低，被认为价格被低估，适合风险厌恶型投资者。

- 1.2.2 成长型股票的特点
成长型股票具有较高的收入和利润增长率，适合长期投资者，愿意承担较高风险以获取更高回报。

#### 1.3 彼得·林奇的筛选标准
- 1.3.1 财务指标的重要性
林奇认为，收入和利润增长率是衡量成长型公司的关键指标。他倾向于选择那些过去5年收入和利润持续增长的公司。

- 1.3.2 市场地位的影响
强大的市场地位和较高的市场份额是公司长期增长的保障。林奇偏好行业龙头或具有竞争优势的公司。

import pandas as pd
import numpy as np

def calculate_growth_rate(revenue):
    growth_rates = []
    for i in range(1, len(revenue)):
        growth = (revenue[i] - revenue[i-1]) / revenue[i-1]
        growth_rates.append(growth)
    return np.mean(growth_rates)

# 示例数据
revenue = [100, 150, 200, 250, 300]
growth_rate = calculate_growth_rate(revenue)
print(f"收入增长率：{growth_rate}%")
