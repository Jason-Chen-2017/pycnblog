### 第2章：投资策略的核心原理与数学模型

#### 2.1 投资策略的数学模型

- **资产定价模型（CAPM）**
  $$ E(r_i) = r_f + \beta_i (E(r_m) - r_f) $$
  - 示例：计算股票的期望回报率。

- **投资组合理论的数学表达**
  $$ \sigma_p^2 = \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} $$
  - 计算投资组合的方差。

#### 2.2 现代投资组合理论的优化模型

- **均值-方差优化**
  - 最小化方差，最大化收益。

- **风险调整后的收益优化**
  - 使用夏普比率评估。

- **约束条件下的优化问题**
  - 包含流动性约束和行业权重限制。

#### 3.2 算法实现的Python代码示例

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(expected_returns, covariance_matrix):
    n = len(expected_returns)
    # 目标函数：最小化投资组合的方差
    def objective(weights):
        return np.dot(weights.T, np.dot(covariance_matrix, weights))
    # 约束条件：权重之和为1
    constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
    # 求解优化问题
    result = minimize(objective, np.ones(n)/n, constraints=constraints)
    return result.x

# 示例数据
n = 5
expected_returns = np.random.rand(n)
covariance_matrix = np.random.randn(n, n) @ np.random.randn(n, n).T
weights = portfolio_optimization(expected_returns, covariance_matrix)
print(weights)
```

      # 计算夏普比率
      mu = expected_returns.mean()
      sigma = np.sqrt(np.dot(expected_returns, covariance_matrix @ expected_returns))
