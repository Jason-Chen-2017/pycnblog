### 5.2 系统核心实现源代码
以下是一个简单的评估模型实现代码示例：

```python
import pandas as pd
import numpy as np

# 数据录入
data = {
    '市场潜力': [0.8, 0.7, 0.9],
    '财务健康': [0.6, 0.8, 0.7],
    '管理团队': [0.7, 0.6, 0.8]
}

df = pd.DataFrame(data)

# 权重分配
weights = {'市场潜力': 0.4, '财务健康': 0.3, '管理团队': 0.3}

# 综合评分计算
def calculate_score(row, weights):
    return sum(row[i] * weights[i] for i in row.index)

df['综合评分'] = df.apply(lambda x: calculate_score(x, weights), axis=1)
print(df)
```
