## 第一部分: 价值投资心理学的背景与基础

### 第1章: 价值投资与心理学概述

#### 1.1 价值投资的核心概念
##### 1.1.1 价值投资的定义与内涵
价值投资是一种长期投资策略，强调以低于内在价值的价格购买优质资产。其核心在于识别市场的非理性定价，通过深入分析企业基本面，寻找具有长期竞争优势的企业。

##### 1.1.2 投资者的心理基础
投资者的心理特征和认知偏差直接影响决策过程。情绪波动、过度自信等心理因素可能导致非理性决策，影响投资结果。

##### 1.1.3 詹姆斯·蒙蒂尔的理论体系
蒙蒂尔强调安全边际和逆向思维。他提出，市场先生的情绪波动为投资者提供了以合理价格买入优质资产的机会。通过分析市场情绪和企业基本面，投资者可以在市场恐慌时寻找低估资产。

#### 1.2 投资者心理与行为分析
##### 1.2.1 投资者的心理特征
投资者通常具有风险偏好、风险厌恶和风险中立三种类型。不同心理特征影响其对风险和收益的权衡。

##### 1.2.2 常见的心理偏差
1. **过度自信**：投资者倾向于高估自己的能力，忽视不确定性。
2. **确认偏差**：倾向于寻找支持已有观点的信息，忽略反面证据。
3. **损失厌恶**：对损失的厌恶程度远超过对收益的追求，导致卖出优质资产。

##### 1.2.3 心理因素对投资决策的影响
心理偏差可能导致误判市场趋势和企业价值，引发非理性交易行为。例如，恐慌性抛售或贪婪性追涨。

## 第二部分: 价值投资心理学的核心概念与联系

### 第3章: 投资决策中的心理偏差与行为偏差

#### 3.1 常见心理偏差的分类与对比
| **心理偏差类型** | **描述** | **影响** |
|------------------|----------|----------|
| 认知偏差          | 对信息处理的偏差 | 导致误判企业价值 |
| 情绪偏差          | 情绪影响决策 | 造成非理性交易 |
| 社会偏差          | 受市场情绪影响 | 影响投资判断 |

#### 3.2 心理偏差对投资决策的影响
心理偏差可能导致以下行为：
- 追涨杀跌：市场上涨时买入，下跌时卖出。
- 过度交易：频繁买卖以追求短期收益，增加成本。
- 从众心理：跟随市场趋势，忽视独立分析。

import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, weights):
    n = len(weights)
    def objective(weights):
        return (weights.T @ returns @ weights) * 0.5
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    result = minimize(objective, np.ones(n)/n, constraints)
    return result.x
