## 第1章：工作资本分析的背景与重要性

### 1.1 工作资本分析的定义与核心概念

#### 1.1.1 工作资本的定义
工作资本（Working Capital）是企业经营活动中流动资产与流动负债的差额，反映了企业的短期偿债能力和运营效率。其公式为：
$$
\text{工作资本} = \text{流动资产} - \text{流动负债}
$$

其中，流动资产包括现金、应收账款、存货等，流动负债包括应付账款、短期借款等。

#### 1.1.2 工作资本分析的核心要素
工作资本分析的核心要素包括：
1. **流动资产**：企业的短期资源，支持日常运营。
2. **流动负债**：企业的短期债务，需在一年内偿还。
3. **净流动资产**：流动资产减去流动负债，反映企业的短期财务健康状况。

#### 1.1.3 工作资本分析的边界与外延
工作资本分析的边界主要集中在流动资产和流动负债的范围内，而其外延则涉及企业整体估值、财务健康状况、投资决策等多个方面。

### 1.2 格雷厄姆工作资本分析的理论基础

#### 1.2.2 工作资本分析的数学模型与公式
格雷厄姆的工作资本分析模型可以表示为：
$$
\text{工作资本} = \text{流动资产} - \text{流动负债}
$$

其中，流动资产和流动负债的具体组成可以通过以下公式计算：

```python
def calculate_working_capital(current_assets, current_liabilities):
    return current_assets - current_liabilities

# 示例数据
data = {
    '企业': ['企业A', '企业B', '企业C'],
    '流动资产': [500000, 600000, 700000],
    '流动负债': [300000, 250000, 280000]
}

df = pd.DataFrame(data)
df['工作资本'] = df.apply(lambda x: calculate_working_capital(x['流动资产'], x['流动负债']), axis=1)
print(df)
```
