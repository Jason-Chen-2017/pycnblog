# 引言：认知偏差与投资决策

## 1. 认知偏差概述

### 1.1 认知偏差的定义与分类  
认知偏差是指人们在信息处理和决策过程中，由于心理、环境等因素的影响，导致系统性偏离理性思考的错误判断。常见的认知偏差包括确认偏差、损失厌恶、从众心理等。  

| 偏差类型      | 定义与特征                                                                 |
|---------------|---------------------------------------------------------------------------|
| 确认偏差      | 倾向于寻找支持已知结论的信息，忽略相反证据。                             |
| 损失厌恶      | 对损失的恐惧超过对收益的追求，导致风险厌恶。                             |
| 从众心理      | 因随大流而做出与个人判断相悖的决策。                                       |

### 1.2 芒格的认知偏差理论  
芒格是巴菲特的长期合作伙伴，他提出的认知偏差理论强调，投资者的心理偏差是导致错误决策的主要原因。芒格认为，克服这些偏差需要建立系统的决策框架和心理账户管理。

### 1.3 投资中的心理陷阱  
在投资中，认知偏差表现为从众投资、过度自信、 anchoring effect（ anchoring effect）等。这些偏差可能导致投资者做出非理性的决策，如盲目跟风或过度交易。

# 第二部分：认知偏差的核心概念与算法原理

## 2. 确认偏差

### 2.1 确认偏差的定义与特征  
确认偏差是指投资者倾向于寻找支持自己已有观点的信息，而忽略或排斥与之相悖的证据。这种偏差可能导致投资者坚持错误的投资决策，错过调整的机会。

### 2.2 确认偏差的算法原理  
确认偏差可以通过信息过滤和选择性关注来解释。投资者会优先选择支持自己观点的信息源，并忽视相反的证据。这种选择性关注可以看作是一种过滤机制，导致信息处理的偏差。

### 2.3 确认偏差的数学模型  
确认偏差可以通过概率论中的贝叶斯定理进行分析。假设投资者已经有一个信念，他们可能会过度权重支持该信念的证据，而低估相反证据的概率。

$$ P(B|E) = \frac{P(E|B)P(B)}{P(E)} $$

其中，P(B|E)是信念B在证据E下的概率，P(E|B)是证据E在信念B下的概率，P(B)是先验概率，P(E)是证据E的全概率。

## 3. 损失厌恶

### 3.1 损失厌恶的定义与特征  
损失厌恶是指人们对损失的恐惧程度远超过对收益的追求。这种偏差导致投资者在面对损失时过度保守，甚至拒绝合理的机会。

### 3.2 损失厌恶的算法原理  
损失厌恶可以通过风险厌恶模型来解释。投资者在决策时，倾向于选择风险较低但收益较低的选项，而不是风险较高但潜在收益更高的选项。

### 3.3 损失厌恶的数学模型  
损失厌恶可以用效用函数来建模。效用函数将收益和损失转化为效用值，反映了投资者对风险的敏感性。

$$ U(r) = \ln(1 - r) $$

其中，U(r)是效用函数，r是收益率。ln函数的凹性反映了损失厌恶。

# 计算确认偏差的影响
import pandas as pd

def calculate_confirmation_bias(portfolio, actual_return):
    # 计算预期收益
    expected_return = portfolio.mean()
    # 计算偏差
    bias = actual_return - expected_return
    return bias

# 示例数据
portfolio = [10, 20, 30, 40]
actual_return = 25
print(calculate_confirmation_bias(portfolio, actual_return))
