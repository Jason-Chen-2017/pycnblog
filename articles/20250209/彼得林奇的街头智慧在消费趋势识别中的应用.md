## 3.3 数学模型

### 3.3.1 时间序列模型
$$ ARIMA(p, d, q) $$
其中，p为自回归阶数，d为差分阶数，q为移动平均阶数。

### 3.3.2 LSTM模型
$$ LSTMCell(x_t, h_{t-1}, c_{t-1}) = (f_t, i_t, o_t) $$
其中，$f_t$为遗忘门，$i_t$为输入门，$o_t$为输出门。

## 3.4 代码实现

### 3.4.1 数据加载与预处理

```python
import pandas as pd
data = pd.read_csv('consumption.csv')
data = data.dropna().diff().dropna()
```

### 3.4.2 特征提取

```python
features = data[['feature1', 'feature2', 'feature3']]
```

### 3.4.3 模型训练

```python
from sklearn.model_selection import train_test_split
from statsmodels.tsa.arima.model import ARIMA

train, test = train_test_split(features, test_size=0.2)
model = ARIMA(train, order=(1, 1, 1))
model_fit = model.fit()
```

### 3.4.4 趋势预测

```python
from sklearn.metrics import mean_squared_error

forecast = model_fit.forecast(len(test))
mse = mean_squared_error(test, forecast)
print(f'MSE: {mse}')
```
