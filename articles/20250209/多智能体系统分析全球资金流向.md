# 第1章：多智能体系统概述

## 1.1 多智能体系统的定义与特点

### 1.1.1 多智能体系统的定义  
多智能体系统（Multi-Agent System, MAS）是由多个智能体（Agent）组成的分布式系统，这些智能体能够通过感知环境、自主决策和协作完成复杂任务。与传统单智能体系统相比，MAS具有更强的适应性和协作能力。

### 1.1.2 多智能体系统的核心特点  
- **分布式**：智能体独立运作，无中央控制。  
- **协作性**：智能体之间通过协作完成共同目标。  
- **反应性**：能够实时感知环境变化并做出反应。  
- **适应性**：智能体能够根据环境变化调整行为。  

### 1.1.3 多智能体系统与传统单智能体系统的区别  
传统单智能体系统依赖中心化决策，而多智能体系统通过去中心化实现协作，能够处理更复杂的任务。

```python
class Agent:
    def __init__(self, initial_funds):
        self.funds = initial_funds
        self.portfolio = {}
    
    def buy_asset(self, asset, asset_price, asset_amount):
        cost = asset_price * asset_amount
        if self.funds >= cost:
            self.funds -= cost
            if asset in self.portfolio:
                self.portfolio[asset] += asset_amount
            else:
                self.portfolio[asset] = asset_amount
    
    def sell_asset(self, asset, asset_price, asset_amount):
        if asset in self.portfolio and self.portfolio[asset] >= asset_amount:
            proceeds = asset_price * asset_amount
            self.funds += proceeds
            self.portfolio[asset] -= asset_amount
            if self.portfolio[asset] == 0:
                del self.portfolio[asset]
```
