## 第一部分：背景介绍

### 第1章：价值投资的起源与格雷厄姆的投资理念

#### 1.1 价值投资的起源

价值投资起源于20世纪初，由本杰明·格雷厄姆和大卫·多德提出。他们主张以低于内在价值的价格购买股票，长期持有，等待市场回归理性。这一理念强调安全边际和对公司基本面的深入分析。

**表格：价值投资与其他投资策略的对比**

| 指标 | 价值投资 | 技术分析 | 股票投机 |
|------|----------|----------|----------|
| 基础 | 公司基本面 | 价格走势 | 市场情绪 |
| 方法 | 买入低估股票 | 通过价格形态交易 | 短期获利 |
| 风险 | 中低 | 中高 | 高 |

#### 1.2 格雷厄姆的投资理念

格雷厄姆提出“安全边际”概念，建议投资者以低于清算价值的价格购买股票，确保投资的安全性。他认为市场先生的情绪波动为投资者提供了机会。

**公式：安全边际 = 股票价格 < 清算价值 × 折扣率**

#### 1.3 股票选择的基本原则

格雷厄姆强调低市盈率、低市净率和高股息率，认为这些指标反映了股票的低估状态。

**表格：格雷厄姆筛选条件**

| 条件 | 标准 |
|------|------|
| 市盈率（P/E） | <15 |
| 市净率（P/B） | <1.5 |
| 股息率 | >5% |

#### 1.4 投资策略与现代投资理论的结合

格雷厄姆公式为现代投资组合理论提供了基础，强调分散投资和风险控制。结合现代量化分析，投资者可以优化投资组合。

## 第二部分：核心概念与公式解析

### 第2章：格雷厄姆股票选择公式的详细解析

#### 2.1 核心概念与公式

格雷厄姆公式通过筛选低市盈率、低市净率和高股息率的股票，识别具有投资价值的企业。

**公式：**

$$
\text{筛选条件} = \begin{cases}
\text{P/E} < 15 \\
\text{P/B} < 1.5 \\
\text{股息率} > 5\%
\end{cases}
$$

**表格：指标解释与计算公式**

| 指标 | 公式 | 解释 |
|------|------|------|
| 市盈率（P/E） | $\frac{\text{股价}}{\text{每股收益}}$ | 衡量股价相对于 earnings 的高低 |
| 市净率（P/B） | $\frac{\text{股价}}{\text{每股净资产}}$ | 衡量股价相对于 book value 的高低 |
| 股息率 | $\frac{\text{每股股息}}{\text{股价}} \times 100\%$ | 衡量股票的分红能力 |

#### 2.2 公式的优缺点

**优点：**

- 简单易懂，适合初学者。
- 筛选出具有安全边际的股票，降低投资风险。

**缺点：**

- 忽略了企业的成长性，可能错过高增长股票。
- 无法适应市场周期性变化，需动态调整。

#### 4.2 核心代码实现

```python
import yfinance as yf

def get_undervalued_stocks(tickers):
    undervalued = []
    for ticker in tickers:
        stock = yf.Ticker(ticker)
        info = stock.info
        try:
            pe = info['forwardPE']
            pb = info['forwardPb']
            dividend_yield = (info['dividendRate'] / info['currentPrice']) * 100
            if pe < 15 and pb < 1.5 and dividend_yield > 5:
                undervalued.append(ticker)
        except KeyError:
            continue
    return undervalued

tickers = ['AAPL', 'MSFT', 'GOOGL']
print(get_undervalued_stocks(tickers))
```

#### 4.3 案例分析

以2023年为例，筛选符合格雷厄姆公式的股票：

```python
print(get_undervalued_stocks(['PG', 'KO', 'PEP']))
```

结果：`['KO', 'PEP']`
