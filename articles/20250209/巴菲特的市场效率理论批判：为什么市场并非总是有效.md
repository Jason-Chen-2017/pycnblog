## 第1章：背景介绍

### 1.1 有效市场假说的提出与核心观点

#### 1.1.1 有效市场假说的定义
有效市场假说（Efficient Market Hypothesis, EMH）是金融学中的一个核心理论，认为市场价格反映了所有可用信息，使得投资者无法通过分析股票价格来获得超额收益。该假说由Fischer Black在1970年代提出，假设市场是完全有效的。

#### 1.1.2 有效市场假说的三种形式
1. **弱有效市场假说**：仅反映历史价格信息。
2. **半强有效市场假说**：反映所有公开可获得的信息。
3. **强有效市场假说**：反映所有内部和外部信息，包括未公开的信息。

#### 1.1.3 有效市场假说的核心假设
1. 市场参与者是理性的。
2. 信息传播是迅速且充分的。
3. 市场不存在显著的结构性缺陷。

### 1.2 巴菲特的市场效率理论

#### 1.2.1 巴菲特对有效市场假说的批判
巴菲特认为市场并非总是有效，尤其是短期市场波动往往偏离其内在价值。他认为，市场的无效性为价值投资者提供了套利机会。

#### 1.2.2 巴菲特的价值投资理念
巴菲特强调长期投资和内在价值的重要性，认为市场短期波动不可预测，但长期趋势与企业基本面密切相关。

#### 1.2.3 巴菲特对市场非有效性的实证分析
通过分析市场波动和企业基本面，巴菲特证明了市场短期波动的非理性，支持市场非有效性的观点。

### 1.3 市场效率理论的局限性与缺陷

#### 1.3.1 市场效率理论的假设前提
1. 市场参与者行为是理性的。
2. 信息传播是完全的。
3. 市场结构不存在重大缺陷。

#### 1.3.2 市场效率理论的适用范围
仅适用于成熟的金融市场，且假设条件严格，实际市场中难以满足。

#### 1.3.3 市场效率理论的局限性与缺陷
1. 忽略了市场参与者的非理性行为。
2. 未能考虑信息不对称和交易成本。
3. 未充分考虑市场结构和制度性缺陷。

## 第2章：市场效率理论的核心概念与联系

### 2.1 有效市场假说的原理

#### 2.1.1 市场效率的定义
市场效率指市场价格反映所有相关信息的程度。

#### 2.1.2 市场效率的衡量指标
1. 市场价格与内在价值的偏离程度。
2. 市场波动的可预测性。
3. 市场参与者收益的分布情况。

#### 2.1.3 市场效率与市场参与者的互动关系
市场参与者的理性行为和信息处理能力直接影响市场效率。

### 2.2 市场效率的属性特征对比

#### 6.2.1 数据收集与处理

```python
import pandas as pd
import numpy as np
import statsmodels.api as sm

# 数据收集
data = pd.read_csv('market_data.csv')

# 数据清洗
data.dropna(inplace=True)
data = data.iloc[:100]

# 特征提取
X = data[['open', 'high', 'low', 'close']]
X = sm.add_constant(X)

# 建立回归模型
model = sm.OLS(data['close'], X)
results = model.fit()
print(results.summary())
```
