# 第一部分: 投资组合再平衡的基础理论

## 第1章: 投资组合再平衡的基本概念

### 1.1 投资组合再平衡的定义与重要性
#### 1.1.1 投资组合再平衡的定义
投资组合再平衡是指根据设定的目标资产配置比例，定期或不定期调整投资组合中各资产的权重，以保持组合的最优状态。通过再平衡，投资者可以在市场波动或资产表现变化时，维持风险与收益的平衡。

#### 1.1.2 再平衡在投资组合管理中的重要性
再平衡确保投资组合的资产配置与初始目标一致，避免某一资产类别权重过大带来的超额风险。同时，它帮助投资者在市场波动中捕捉收益机会，优化长期回报。

#### 1.1.3 再平衡的核心目标与原则
- **目标**：维持预期的资产配置比例，优化风险调整后收益。
- **原则**：定期评估，及时调整，最小化交易成本，最大化收益。

### 1.2 投资组合再平衡的类型
#### 1.2.1 定期再平衡
按照固定的时间间隔（如季度、半年）进行调整，适用于目标资产配置长期稳定的投资者。

#### 1.2.2 永久性再平衡
根据市场变化和投资者目标调整资产配置，不设定固定时间，更具灵活性。

#### 1.2.3 动态再平衡
根据市场变化频繁调整，适合波动较大的市场环境，但交易成本较高。

### 1.3 投资组合再平衡的适用场景
#### 1.3.1 市场波动对投资组合的影响
市场波动可能导致资产权重偏离目标，需要及时调整。

#### 1.3.2 投资目标变化的应对
投资目标如风险承受能力、收益目标的变化需要通过再平衡来调整资产配置。

#### 1.3.3 不同投资策略下的再平衡需求
不同策略（如被动投资、主动投资）对再平衡的需求不同，需根据策略特点制定调整计划。

# 第三部分: 投资组合再平衡的数学模型与算法

## 第3章: 投资组合再平衡的数学模型

### 3.1 现代投资组合理论的数学公式
#### 3.1.1 投资组合的期望收益与方差公式
$$ E(r_p) = \sum_{i=1}^n w_i E(r_i) $$
$$ \sigma_p^2 = \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} $$

#### 3.1.2 解释
$E(r_p)$为投资组合的期望收益，$w_i$为资产i的权重，$E(r_i)$为资产i的期望收益，$\sigma_{ij}$为资产i和j的协方差。

### 3.2 均值-方差优化的数学模型
#### 3.2.1 优化目标函数
$$ \min_w \sigma_p^2 $$
$$ \text{约束条件：} \sum_{i=1}^n w_i = 1 $$

#### 3.2.2 解释
目标是最小化投资组合的方差，同时满足权重和为1的约束。

### 3.3 再平衡算法的数学实现
#### 3.3.1 投资组合权重调整的数学表达
$$ w_i' = \frac{w_i \cdot P_i}{\sum_{j=1}^n w_j \cdot P_j} $$
其中，$P_i$是资产i的当前价格，$w_i$是目标权重。

#### 3.3.2 解释
该公式用于计算调整后的权重，确保总权重为1。

import pandas as pd
import requests

def get_data(tickers):
    data = pd.DataFrame()
    for t in tickers:
        url = f"https://query1.finance.yahoo.com/ws/v7/finance/spQuotes?lang=en-US&region=US&symbol={t}"
        response = requests.get(url)
        if response.status_code == 200:
            data[t] = response.json()['quoteResponse']['result'][0]['regularMarketPrice']
    return data
```

def rebalance(weights, current_prices):
    total = sum(weights * current_prices)
    new_weights = weights * current_prices / total
    return new_weights
```
