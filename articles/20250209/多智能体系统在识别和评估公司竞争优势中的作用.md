# 第一章：多智能体系统的基本概念

## 1.1 多智能体系统的定义与特征

多智能体系统是由多个智能体组成的分布式系统，具备以下特征：
- **自主性**：智能体能够自主决策。
- **反应性**：能感知环境并实时响应。
- **协作性**：通过协作完成复杂任务。
- **分布式性**：各智能体独立运行，无集中控制。

## 1.2 多智能体系统的组成与结构

### 1.2.1 智能体的分类

| 类型     | 描述                         |
|----------|------------------------------|
| 反应式   | 基于当前感知做出反应           |
| 规划式   | 基于目标规划行动             |
| 学习式   | 通过学习提升性能             |

### 1.2.2 多智能体系统的组成要素

- **智能体**：系统的基本单元。
- **通信机制**：智能体间信息交换的方式。
- **协作协议**：定义智能体间的合作规则。
