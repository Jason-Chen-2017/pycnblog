#### 9.1 案例分析

- **案例背景**：假设我们有一个包含五只股票的投资组合，通过蒙特卡洛模拟，评估不同权重下的投资组合收益和风险，选择最优投资组合。
- **案例实现**：
  ```python
  import numpy as np
  import pandas as pd
  import matplotlib.pyplot as plt

  # 假设我们有五只股票的收益率数据
  stock_returns = np.array([
      [0.1, 0.05, 0.15, 0.08, 0.12],
      [0.08, 0.12, 0.07, 0.15, 0.09],
      [0.15, 0.1, 0.2, 0.05, 0.1],
      [0.07, 0.15, 0.08, 0.12, 0.18],
      [0.1, 0.08, 0.1, 0.1, 0.2]
  ])

  # 生成随机权重
  np.random.seed(42)
  weights = np.random.dirichlet(np.ones(5), size=1)[0]

  # 计算投资组合收益和风险
  portfolio_returns = np.dot(stock_returns, weights)
  portfolio_risk = np.std(portfolio_returns)

  print(f"投资组合平均收益：{np.mean(portfolio_returns)}")
  print(f"投资组合风险：{portfolio_risk}")
  ```
