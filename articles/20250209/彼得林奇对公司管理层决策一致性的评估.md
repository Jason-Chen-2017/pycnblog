## 第一部分：背景介绍

### 第1章：决策一致性概述

#### 1.1 什么是决策一致性

- **1.1.1 决策一致性的定义**
  决策一致性是指公司在不同时间、不同情境下做出的决策是否符合其战略目标和长期价值创造的逻辑。简单来说，决策一致性衡量的是管理层决策的连贯性和稳定性。

- **1.1.2 决策一致性的核心要素**
  | 核心要素       | 描述                             |
  |----------------|----------------------------------|
  | 战略连贯性     | 决策是否与公司战略目标一致       |
  | 时间一致性     | 长期决策与短期决策的协调性       |
  | 行为一致性     | 决策是否与公司历史行为模式一致   |
  | 逻辑一致性     | 决策是否符合商业逻辑和行业规律   |

- **1.1.3 决策一致性与投资决策的关系**
  决策一致性是投资者评估公司管理层能力的重要指标。一致的决策表明管理层具备清晰的战略眼光和稳定的决策风格，这通常意味着公司具有更高的投资价值。

### 第3章：决策一致性模型

#### 3.1 决策一致性的核心原理

- **3.1.1 决策一致性评估模型**
  决策一致性评估模型通过分析公司历史决策数据，判断这些决策是否符合一致的逻辑和战略目标。

- **3.1.2 决策一致性评估的数学模型**
  $$ 决策一致性指数 = \frac{\sum_{i=1}^{n} w_i \cdot d_i}{\sum_{i=1}^{n} w_i} $$
  其中，$w_i$ 是决策 $i$ 的权重，$d_i$ 是决策 $i$ 的一致性评分。

```python
def decision_consistency_score(decision_data, weights):
    """
    计算决策一致性指数
    Args:
        decision_data: 决策数据列表
        weights: 决策权重列表
    Returns:
        决策一致性指数
    """
    weighted_sum = 0
    total_weight = sum(weights)
    for i in range(len(decision_data)):
        weighted_sum += weights[i] * decision_data[i]
    return weighted_sum / total_weight
```

#### 6.2 核心代码实现

```python
import pandas as pd

# 示例数据
data = {
    '决策': [1, 2, 3, 4, 5],
    '权重': [0.1, 0.2, 0.3, 0.2, 0.2]
}
df = pd.DataFrame(data)

# 计算决策一致性指数
def calculate_consistency_index(df):
    weights = df['权重'].tolist()
    decisions = df['决策'].tolist()
    total_weight = sum(weights)
    weighted_sum = sum(w * d for w, d in zip(weights, decisions))
    return weighted_sum / total_weight

index = calculate_consistency_index(df)
print(f"决策一致性指数: {index}")
```
