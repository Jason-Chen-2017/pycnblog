#### 4.2.2 数据处理模块

##### 代码实现

```python
import pandas as pd

def process_data(data):
    df = pd.read_html(data)[0]
    df['日期'] = pd.to_datetime(df['日期'])
    df.set_index('日期', inplace=True)
    df['存货周转率'] = df['存货'] / df['平均存货']
    return df

# 示例：处理数据
data = open(f"{company_code}_financial_data.html", 'r').read()
processed_df = process_data(data)
processed_df.head()
```
