### 第1章: 特价股票的定义与背景

#### 1.1 特价股票的定义

- **特征**：
  - 价格低于公允价值
  - 低估值可能导致短期波动，但长期潜力大
  - 可能处于困境或被市场忽视
- **分类**：
  - 按行业：金融、科技等
  - 按市值：小盘股、大盘股
  - 按原因：价值型、成长型

#### 1.2 特价股票的市场表现

#### 1.3 特价股票的投资价值与风险

### 第8章: 特价股票与公司环境责任表现的项目实战

#### 8.1 环境安装
- **工具**：
  - Python：数据分析
  - Pandas：数据处理
  - Scikit-learn：回归分析
  - Matplotlib：数据可视化

#### 8.2 核心实现
- **代码示例**：
  ```python
  import pandas as pd
  import numpy as np
  from sklearn.linear_model import LinearRegression
  import matplotlib.pyplot as plt

  # 数据加载
  df = pd.read_csv('stock_data.csv')

  # 数据预处理
  X = df[['ESG评分', '公司规模']]
  y = df['股价波动']

  # 模型训练
  model = LinearRegression()
  model.fit(X, y)

  # 预测与评估
  predictions = model.predict(X)
  print('回归系数:', model.coef_)
  print('决定系数:', model.score(X, y))

  # 可视化
  plt.scatter(X['ESG评分'], y)
  plt.plot(X['ESG评分'], predictions, color='red')
  plt.xlabel('ESG评分')
  plt.ylabel('股价波动')
  plt.title('ESG评分对股价波动的影响')
  plt.show()
  ```

- **解读**：
