### 第1章：价值投资的起源与发展

#### 1.1 本杰明·格雷厄姆的背景

**背景介绍**：
- 本杰明·格雷厄姆是20世纪的投资大师，被誉为“价值投资之父”。
- 他在1924年与戴维·多德合著的《证券分析》奠定了价值投资的基础。
- 他的投资哲学强调安全边际和内在价值，注重长期稳健的投资策略。

**问题背景**：
- 投资者在市场波动中如何保持理性，避免情绪化决策？
- 如何通过基本面分析发现被低估的投资标的？

**问题解决**：
- 强调安全边际：买入价格低于内在价值，确保投资的安全性。
- 以长期视角看待投资，关注企业的内在价值而非短期市场波动。

**概念结构与核心要素**：
- 核心要素：内在价值、安全边际、资产质量。
- 概念关系：内在价值是评估的基础，安全边际是保护投资者的屏障，资产质量决定企业的长期盈利能力。

**属性对比**：

| 定义 | 资产在最佳条件下的价值 | 购买价格与内在价值的差距 |
| 作用 | 评估标准 | 风险控制 |

### 第2章：价值投资的核心概念

#### 2.1 安全边际与内在价值

**内在价值的计算**：
- **现金流折现模型（DCF）**：
  $$ V = \frac{CF_1}{(1+r)^1} + \frac{CF_2}{(1+r)^2} + \dots + \frac{CF_n}{(1+r)^n} $$
  其中，CF为现金流，r为折现率，n为期限。

**安全边际的应用**：
- 买入价格低于内在价值的20%或更多，以确保投资的安全性。
- 例如，某资产的内在价值为100，若买入价为80，则安全边际为20%。

#### 2.2 资产评估的关键要素

**资产质量分析**：
- 企业的盈利能力：ROE（净资产收益率）、净利润率。
- 财务状况：资产负债率、流动比率。
- 行业地位：市场占有率、竞争优势。

**与其它投资方法的对比**：
- 技术分析：侧重价格走势，忽视内在价值。
- 随机漫步理论：认为价格无法预测，与价值投资强调的内在价值不同。

### 第3章：价值投资的数学模型

#### 3.1 现金流折现模型（DCF）

**模型原理**：
DCF模型通过将未来现金流折现为现值，计算资产的内在价值。
- 现金流预测：需考虑企业的增长潜力和行业前景。
- 折现率确定：通常使用WACC（加权平均资本成本）。

**Python代码实现**：
```python
def calculateDCF(cash_flows, discount_rate):
    present_value = 0
    for year, cf in enumerate(cash_flows):
        if year == 0:
            present_value += cf
        else:
            present_value += cf / (1 + discount_rate) ** year
    return present_value

# 示例数据
cash_flows = [100, 150, 200, 250]
discount_rate = 0.10

intrinsic_value = calculateDCF(cash_flows, discount_rate)
print(f"内在价值：{intrinsic_value:.2f}")
```

**案例分析**：
某企业未来五年的现金流分别为100、120、150、180、200万元，折现率为10%。计算其DCF内在价值：
$$ V = 100 + \frac{120}{1.1} + \frac{150}{1.1^2} + \frac{180}{1.1^3} + \frac{200}{1.1^4} ≈ 471.68 \text{万元} $$

#### 3.2 市盈率与市净率分析

**市盈率（P/E）**：
$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
- 低P/E值可能意味着低估，但需考虑行业特性。

**市净率（P/B）**：
$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$
- 适用于银行、房地产等资产密集型行业。

**对比分析**：
| 指标 | 优点 | 缺点 |
|------|------|------|
| P/E | 简单易用 | 不适合亏损企业 |
| P/B | 适用于净资产高的行业 | 受资产质量影响大 |
