# 第3章: 行为金融学中的数学模型与算法原理

## 3.1 基于行为偏差的数学模型

### 3.1.1 前景理论（Prospect Theory）

#### 前景理论的核心假设
- 人们对收益和损失的敏感度不同。
- 损失厌恶：对损失的恐惧大于对收益的追求。

#### 前景理论的数学公式
$$
V = \text{max}(p \cdot u(r), l \cdot u(r))
$$

#### 前景理论的实现代码
```python
def prospect_theory(gains, losses, utility_func):
    pt = []
    for g in gains:
        pt.append(max(p * utility_func(g), l * utility_func(g)))
    for l in losses:
        pt.append(min(p * utility_func(l), l * utility_func(l)))
    return pt
```

### 3.1.2 后悔理论（Regret Theory）

#### 后悔理论的核心假设
- 投资者决策基于对后悔的规避。

#### 后悔理论的数学公式
$$
R = \text{max}(g - l, 0)
$$

#### 后悔理论的实现代码
```python
def regret_theory(profits, losses):
    regret = []
    for p in profits:
        regret.append(max(p - l, 0))
    return regret
```

### 3.1.3 基于概率的决策模型

#### 概率决策模型的核心假设
- 投资者基于概率评估风险。

#### 概率决策模型的数学公式
$$
E = \sum p_i \cdot x_i
$$

#### 概率决策模型的实现代码

def probabilistic_model(probabilities, returns):
    expected_return = sum(p * r for p, r in zip(probabilities, returns))
