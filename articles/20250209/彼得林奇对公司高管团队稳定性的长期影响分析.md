### 4.1 高管团队稳定性指数模型

#### 4.1.1 模型的构建与假设

稳定性指数模型基于高管团队稳定性评估维度构建，假设各维度对稳定性的影响权重相同。

#### 4.1.2 模型的数学表达式

$$ S = \sum_{i=1}^{n} w_i x_i $$

其中，$S$ 表示稳定性指数，$w_i$ 表示第 $i$ 个因素的权重，$x_i$ 表示第 $i$ 个因素的评分。

def calculate_stability_index(data, weights):
    # 计算各维度评分
    scores = {}
    for i in range(len(weights)):
        scores[i] = data[i] * weights[i]
    # 计算稳定性指数
    stability_index = sum(scores.values())
    return stability_index

# 示例数据
data = [0.8, 0.7, 0.9, 0.6]
weights = [0.25, 0.25, 0.25, 0.25]

stability_index = calculate_stability_index(data, weights)
print("稳定性指数:", stability_index)
