# 第3章: 优化引擎的算法原理

## 3.1 强化学习算法

### 3.1.1 强化学习的基本概念
- 强化学习是一种通过试错学习的方法，通过与环境的交互获得奖励，从而优化决策策略。
- 在优化引擎中，强化学习用于动态环境下的产品优化。

### 3.1.2 强化学习的数学模型
$$ Q-learning: Q(s,a) = r + \gamma \max_{a'} Q(s',a') $$
$$ 策略评估: V(s) = \max_a Q(s,a) $$

### 3.1.3 强化学习的Python实现
```python
import numpy as np

class QLearning:
    def __init__(self, state_space, action_space, gamma=0.99):
        self.state_space = state_space
        self.action_space = action_space
        self.gamma = gamma
        self.q_table = np.zeros((state_space, action_space))

    def choose_action(self, state):
        return np.argmax(self.q_table[state])

    def update_q_table(self, state, action, reward, next_state):
        self.q_table[state][action] = reward + self.gamma * np.max(self.q_table[next_state])
```

## 3.2 遗传算法

### 3.2.1 遗传算法的基本概念
- 遗传算法是一种模拟生物进化的过程，通过选择、交叉和变异操作生成新的解。
- 在优化引擎中，遗传算法用于复杂问题的全局优化。

### 3.2.2 遗传算法的数学模型
$$ 适应度函数: f(x) = \sum_{i=1}^n w_i x_i $$
$$ 选择概率: P(x) = \frac{f(x)}{\sum f(x)} $$

### 3.2.3 遗传算法的Python实现
```python
import random

class GeneticAlgorithm:
    def __init__(self, population_size, chromosome_length):
        self.population_size = population_size
        self.chromosome_length = chromosome_length
        self.population = [random.choices([0,1], k=chromosome_length) for _ in range(population_size)]

    def evaluate(self, fitness_function):
        self.fitness = [fitness_function(ind) for ind in self.population]

    def select(self):
        # 轮盘赌选择
        total = sum(self.fitness)
        probabilities = [f/total for f in self.fitness]
        new_population = []
        for _ in range(self.population_size):
            r = random.uniform(0,1)
            for i in range(len(probabilities)):
                if r < probabilities[i]:
                    new_population.append(self.population[i])
                    break
        self.population = new_population

    def crossover(self, crossover_rate=0.8):
        # 单点交叉
        for i in range(0, self.population_size, 2):
            if random.random() < crossover_rate:
                point = random.randint(1, self.chromosome_length-1)
                self.population[i], self.population[i+1] = self.population[i+1][:point], self.population[i][:point] + self.population[i+1][point:]

    def mutate(self, mutation_rate=0.1):
        for i in range(self.population_size):
            for j in range(self.chromosome_length):
                if random.random() < mutation_rate:
                    self.population[i][j] = 1 - self.population[i][j]
```
