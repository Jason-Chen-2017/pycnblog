                 



# 第3章: 深度学习基础

## 3.1 神经网络基础

### 3.1.1 神经网络的结构
神经网络由输入层、隐藏层和输出层组成。每个层由多个神经元组成，通过权重连接。神经网络的结构可以通过以下Mermaid图表示：

```mermaid
graph LR
    InputLayer[输入层]
    HiddenLayer[隐藏层]
    OutputLayer[输出层]
    InputLayer --> HiddenLayer
    HiddenLayer --> OutputLayer
```

### 3.1.2 激活函数
激活函数用于引入非线性，使神经网络能够学习复杂模式。常见的激活函数包括：

- **Sigmoid**：$f(x) = \frac{1}{1 + e^{-x}}$
- **ReLU**：$f(x) = \max(0, x)$
- **Tanh**：$f(x) = \tanh(x)$

### 3.1.3 损失函数
损失函数衡量预测值与真实值之间的差异。常用的损失函数包括：

- **均方误差（MSE）**：$$L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$
- **交叉熵损失**：$$L = -\frac{1}{n}\sum_{i=1}^{n} y_i \log(\hat{y}_i) + (1 - y_i)\log(1 - \hat{y}_i)$$

### 3.1.4 神经网络训练过程
神经网络的训练包括前向传播和反向传播两个步骤：

1. **前向传播**：输入数据通过网络计算出输出。
2. **反向传播**：计算损失，更新权重。

例如，在MNIST手写数字识别任务中，神经网络通过前向传播预测数字，然后通过反向传播调整权重以减少预测误差。

## 3.2 深度学习的训练过程

### 3.2.1 前向传播
输入数据通过神经网络的层，计算得到输出。例如，给定输入向量$x$，经过权重矩阵$W$和激活函数$f$，输出为$f(Wx)$。

### 3.2.2 反向传播
计算损失函数关于权重的梯度，并使用梯度下降方法更新权重。损失函数$L$对权重$W$的梯度为$\frac{\partial L}{\partial W}$，更新规则为：

$$W = W - \eta \frac{\partial L}{\partial W}$$

其中，$\eta$是学习率。

例如，在MNIST任务中，假设真实标签为$y=5$，预测输出为$\hat{y}=0.1$，损失函数为交叉熵损失。通过反向传播计算梯度并更新权重，使预测值更接近真实值。

## 3.3 深度学习的数学基础

### 3.3.1 线性代数
矩阵乘法用于表示层与层之间的连接。例如，输入向量$x$与权重矩阵$W$相乘：

$$z = Wx$$

### 3.3.2 微积分
梯度下降用于优化权重，涉及导数的计算。例如，损失函数$L$对权重$w$的导数为：

$$\frac{\partial L}{\partial w} = 2(w - x)(x \cdot w - y)$$

### 3.3.3 概率论
概率论用于模型的不确定性分析。例如，使用概率分布建模输出类别概率。

### 3.3.4 优化算法
除了梯度下降，还可以使用Adam优化算法，结合动量和自适应学习率：

$$m_t = \beta_1 m_{t-1} + (1 - \beta_1) \frac{\partial L}{\partial w}$$
$$v_t = \beta_2 v_{t-1} + (1 - \beta_2) (\frac{\partial L}{\partial w})^2$$
$$w = w - \alpha \frac{m_t}{\sqrt{v_t} + \epsilon}$$

其中，$\alpha$是学习率，$\beta_1$和$\beta_2$是动量参数，$\epsilon$是防止除以零的常数。

### 3.3.5 正则化
正则化用于防止过拟合，常用的有L2正则化：

$$L_{\text{正则化}} = L + \lambda \frac{1}{2} \|W\|^2$$

其中，$\lambda$是正则化强度。
