## 第一部分: 价值投资的背景与起源

### 第1章: 价值投资的定义与核心概念

#### 1.1 价值投资的起源与发展

价值投资是一种以基本面分析为基础的投资策略，旨在通过识别市场价格与内在价值之间的差异来获取超额收益。本杰明·格雷厄姆是现代价值投资的奠基人，他的投资哲学深刻影响了包括沃伦·巴菲特在内的众多投资者。

**核心概念**:
- **内在价值**: 股票的真正价值是其未来现金流的现值，与市场价格无关。
- **安全边际**: 在购买股票时，以低于其内在价值的价格买入，以降低风险并确保收益。

**历史背景**:
- 格雷厄姆在20世纪初开始研究投资，当时市场波动剧烈，投资者普遍追求短期收益，忽视了长期价值。

### 第2章: 格雷厄姆对投资学的贡献

#### 2.1 投资市场的基本问题与挑战

**问题背景**:
- 投资者在市场中面临的主要问题是信息不对称和情绪化决策，导致投资决策的非理性。

**挑战分析**:
- 投资者往往过度关注短期市场波动，忽视了企业的长期价值。

**格雷厄姆的解决方案**:
- 强调长期投资和价值挖掘，通过基本面分析寻找被市场低估的股票。

## 第二部分: 格雷厄姆的投资策略

### 第3章: 安全边际与防御性投资

#### 3.1 安全边际的概念与应用

**定义与计算**:
- 安全边际 = 内在价值 - 市场价格。
- 通过计算安全边际，投资者可以识别出具有足够安全空间的股票。

**案例分析**:
- 假设某股票的内在价值为100元，市场价格为80元，安全边际为20元，此时买入该股票的风险较低。

## 第三部分: 投资心理学与行为学

### 第5章: 投资者心理的常见偏差

#### 5.1 过度自信与从众心理

**过度自信**:
- 投资者往往高估自己的能力，认为自己能够准确预测市场走势。
- 这种心态可能导致盲目追涨杀跌。

**从众心理**:
- 投资者倾向于跟随市场的趋势，而非基于基本面的分析。
- 这种行为在市场泡沫形成时尤为明显。

## 第四部分: 数学模型与评估方法

### 第6章: 资产评估的核心公式

#### 6.1 内在价值计算公式

$$ \text{内在价值} = \sum_{t=1}^{\infty} \frac{CF_t}{(1 + r)^t} $$

其中，\( CF_t \) 是第 \( t \) 年的现金流，\( r \) 是折现率。

import pandas as pd

def calculate_intrinsic_value(enterprise_value, free_cash_flow, discount_rate):
    # 计算未来现金流的现值
    present_value = free_cash_flow / (1 + discount_rate)
    return present_value

# 示例数据
enterprise_value = 1000000
free_cash_flow = 500000
discount_rate = 0.1

# 计算内在价值
