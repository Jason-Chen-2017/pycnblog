# 第4章: 长期主义的数学模型

## 4.1 复利计算的数学公式
### 4.1.1 复利的基本公式
$$ A = P \times (1 + r)^t $$
其中：
- \( A \) 是终值，
- \( P \) 是本金，
- \( r \) 是年利率，
- \( t \) 是时间（年）。

### 4.1.2 复利与长期投资的关系
- 复利是长期投资的“加速器”。
- 通过复利效应，长期投资能够实现财富的指数级增长。

### 4.1.3 复利的计算案例
- 例如，本金100元，年利率10%，经过30年，终值为：
$$ A = 100 \times (1 + 0.1)^{30} = 100 \times 1.1^{30} \approx 1980.69 $$

## 4.2 时间价值的数学模型
### 4.2.1 时间价值的基本概念
时间价值是指资金在时间推移中的价值变化，主要体现在复利计算中。

### 4.2.2 时间价值的数学公式
$$ FV = PV \times (1 + r)^t $$
其中：
- \( FV \) 是未来价值，
- \( PV \) 是现值，
- \( r \) 是利率，
- \( t \) 是时间。

### 4.2.3 时间价值在长期投资中的应用
- 通过时间价值模型，投资者能够更好地理解长期投资的价值。

```python
import numpy as np
import pandas as pd

# 读取数据
data = pd.read_csv('stock_data.csv')

# 计算复利
def compound_interest(principal, rate, time):
    return principal * (1 + rate) ** time

# 应用复利计算
results = []
for index, row in data.iterrows():
    A = compound_interest(row['principal'], row['rate'], row['time'])
    results.append(A)

# 输出结果
print(results)
```
