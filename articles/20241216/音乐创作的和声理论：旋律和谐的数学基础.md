## 和声理论的基本概念

和声理论是音乐理论的重要组成部分，它研究音与音之间的相互关系，以及如何通过这些关系创造出和谐的音乐效果。以下是和声理论中的一些基本概念：

### 音程

音程是两个音之间的高低关系。音程分为大小、增减、纯等类型。例如，C和E之间是一个大三度（C-E），C和D之间是一个小二度（C-D）。

$$
C - D = 小二度, C - E = 大三度
$$

### 和弦

和弦是由三个或三个以上音同时演奏组成的。常见的和弦有大小三和弦、大小七和弦、增和弦和减和弦等。

$$
C - E - G = 大三和弦, A - C - E = 大七和弦
$$

### 和弦功能

和弦功能描述了和弦在音乐中的功能和作用，常见的和弦功能有主和弦、属和弦和下属和弦等。

$$
I - V - I = 主 - 属 - 主
$$

### 音阶

音阶是构成旋律的音的排列顺序。常见的音阶有大调音阶、小调音阶等。

$$
C - D - E - F - G - A - B = 大调音阶, A - B - C - D - E - F - G = 小调音阶
$$

### 和声与旋律的关系

和声是旋律的背景和支撑，而旋律则是和声的展示和表现。和声与旋律的关系密切，二者相辅相成，共同创造出音乐的美感。

$$
旋律 + 和声 = 和谐的音乐
$$

音高可以用频率来表示。例如，中央C的频率大约为261.6 Hz。音高的变化可以通过频率的变化来描述。

$$

$$

其中，n是半音的数目。

### 音程的数学表示

音程可以用音差来表示。音差是两个频率之比，通常用开平方根表示。例如，大三度的音差约为1.2599。

$$
音程 = \sqrt{频率比}
$$

### 和弦的数学表示

和弦可以看作是频率的集合。例如，大三和弦的频率比为1:1.5:2.25。

$$

### 和声的数学模型

```python
import numpy as np
import matplotlib.pyplot as plt

# 音高频率表
A4_FREQUENCY = 440.0
FREQUENCY_TABLE = {note: A4_FREQUENCY * (2 ** (n / 12.0)) for n, note in enumerate(range(-9, 10))}

# 音程计算
def calculate_interval(frequency1, frequency2):
    return 12 * np.log2(frequency1 / frequency2)

# 和弦生成
def generate_chord(root_note, chord_type='major'):
    root_frequency = FREQUENCY_TABLE[root_note]
    if chord_type == 'major':
        return [root_frequency * (2 ** (1 / 12.0)), root_frequency * (2 ** (7 / 12.0))]
    elif chord_type == 'minor':
        return [root_frequency * (2 ** (1 / 12.0)), root_frequency * (2 ** (6 / 12.0))]

# 旋律生成
def generate_melody(root_note, chord_type='major', duration=1.0):
    root_frequency = FREQUENCY_TABLE[root_note]
    chord_frequencies = generate_chord(root_note, chord_type)
    melody = []
    for i in range(int(duration * 1000)):  # 转换为毫秒
        note_frequency = root_frequency
        if i % 100 < 50:
            note_frequency = chord_frequencies[0]
        elif i % 100 < 75:
            note_frequency = chord_frequencies[1]
        melody.append(note_frequency)
    return melody

# 绘制旋律
def plot_melody(melody, title='Melody'):
    times = np.arange(len(melody)) / 1000
    frequencies = [A4_FREQUENCY * (2 ** (n / 12.0)) for n in range(-9, 10)]
    plt.plot(times, frequencies[melody])
    plt.title(title)
    plt.xlabel('Time (s)')
    plt.ylabel('Frequency (Hz)')
    plt.show()

# 示例
root_note = 'C4'
chord_type = 'major'
melody = generate_melody(root_note, chord_type)
plot_melody(melody, 'Melody with Major Chord')
```

3. **和弦生成**：根据输入的根音和和弦类型（大小三和弦、小三四和弦等），生成相应的和弦频率。
