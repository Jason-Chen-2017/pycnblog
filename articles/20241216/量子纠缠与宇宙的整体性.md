#### 1.2 量子纠缠的原理与数学模型

量子纠缠的原理源于量子力学的核心概念——波函数。量子系统的波函数描述了系统的状态，当两个或多个量子系统发生纠缠时，它们的波函数会合并成一个整体的纠缠波函数。

$$\psi_1 = \frac{1}{\sqrt{2}}(|\uparrow\rangle - |\downarrow\rangle)$$

$$\psi_2 = \frac{1}{\sqrt{2}}(|\uparrow\rangle + |\downarrow\rangle)$$

当这两个粒子发生纠缠后，它们的整体波函数可以表示为：

$$\psi_{12} = \frac{1}{\sqrt{2}}(|\uparrow\rangle|\uparrow\rangle - |\downarrow\rangle|\downarrow\rangle)$$

这个纠缠波函数描述了两个粒子之间的奇特关联性。当我们对其中一个粒子进行测量时，另一个粒子的状态会立即确定，并且两个粒子的测量结果会呈现出一种固定的关联性，如自旋向上与自旋向下总是成对出现。

量子纠缠的数学描述通常使用量子态的密度矩阵来表示。对于两个粒子的系统，其密度矩阵可以表示为：

$$\rho_{12} = \frac{1}{2}(|\psi_{12}\rangle\langle\psi_{12}| + |\psi_{12}\rangle\langle\psi_{12}|)$$

这个密度矩阵描述了两个粒子整体的量子状态，其中$\langle\psi_{12}|$表示纠缠态的期望值。
