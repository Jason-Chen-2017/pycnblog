## 第二部分：张量分解技术

### 第3章：张量分解简介

**核心概念：**
- 张量分解：将高维数据分解为多个低维张量的过程。

**数学背景：**
- 张量：多维数组，用于表示高维数据。
- 因子分解：将高维数据分解为多个低维张量的数学方法。

**张量分解的意义：**
- 张量分解能够降低数据维度，提高数据处理效率。
- 张量分解能够捕捉数据的多维结构，提高模型解释性。

**张量分解过程：**
```mermaid

    A[高维数据] --> B[张量分解]
    B --> C[低维张量]
```

### 第4章：张量分解算法

**算法类型：**
- CANDECOMP/PARAFAC (CP)：将张量分解为多个矩阵的乘积。
- Tucker：将张量分解为多个低维张量的乘积。

**算法原理：**
- CP算法：通过迭代优化方法求解张量分解问题。
- Tucker算法：通过最小二乘法求解张量分解问题。

**Python代码示例：**
```python
import numpy as np
from numpy.linalg import svd

# 张量数据
tensor = np.array([[1, 2], [3, 4]])

# CP分解
U, Sigma, V = np.linalg.svd(tensor, full_matrices=False)

# Tucker分解
low_rank_tensor = np.matmul(U, np.diag(Sigma))
high_rank_tensor = np.matmul(V, np.diag(Sigma))
```

**数学模型：**
- CP分解：$$T = U \times V$$
- Tucker分解：$$T = A \times B \times C$$
