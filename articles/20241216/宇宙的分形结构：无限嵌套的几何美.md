## 1.2 核心概念与联系

### 1.2.1 分形的基本概念

分形是一种几何形状，它具有以下几个基本特性：

1. **无限嵌套：** 分形形状可以无限分割，每一部分都与整体具有相似的结构。
2. **自相似性：** 分形的每一个局部都与整体相似。
3. **不规则性：** 分形的边界通常是不规则的，没有明显的直线或曲线。

在数学上，分形可以用递归方法生成，即通过重复应用一个简单的规则，生成复杂的形状。

### 1.2.2 分形的特性及其在宇宙中的表现

分形的特性使其在宇宙中具有广泛的应用。以下是分形在宇宙中的一些表现：

1. **星系分布：** 宇宙中的星系分布呈现出分形结构，例如，星系团和超星系团的分布具有自相似性。
2. **星际介质：** 星际介质中存在着复杂的结构，如分子云和星际丝，这些结构也具有分形特性。
3. **地球表面：** 地球表面地形的高低起伏也呈现出分形结构，例如，山脉和河流的分布具有自相似性。

## 1.3 算法原理讲解

### 1.3.1 科赫曲线

科赫曲线是一种著名的分形结构，由数学家科赫（Helge von Koch）在1904年提出。科赫曲线通过递归方法生成，其生成过程如下：

1. **第一步：** 画一个等边三角形。
2. **第二步：** 在每个等边三角形的中点，向外各画一个1/3长度的小等边三角形，然后删除原来的边。
3. **第三步：** 对每个小等边三角形，重复第二步。

通过递归操作，科赫曲线的复杂度逐渐增加，形成了一个无限细分的结构。

### 1.3.2 谢尔宾斯基地毯

谢尔宾斯基地毯是由俄国数学家谢尔宾斯基（Wacław Sierpiński）在1915年提出的分形结构。谢尔宾斯基地毯的生成方法如下：

1. **第一步：** 画一个正三角形。
2. **第二步：** 在每个正三角形的中心，画一个更小的正三角形，并将其原来的三角形删除。
3. **第三步：** 对每个小正三角形，重复第二步。

通过递归操作，谢尔宾斯基地毯逐渐形成了一个具有无限嵌套结构的图案。

### 1.3.3 费波那契序列

费波那契序列是一种著名的数列，其递推公式为：

$$ F(n) = F(n-1) + F(n-2) $$

其中，$ F(0) = 0 $，$ F(1) = 1 $。

费波那契序列在宇宙中有着广泛的应用，如星系分布、生命演化等。其生成过程如下：

1. **第一步：** 画一条直线。
2. **第二步：** 在直线的两端各画一条1/2长度的直线，与原直线相交成直角。
3. **第三步：** 对每条新画的直线，重复第二步。

通过递归操作，费波那契序列逐渐形成了一个具有自相似结构的图案。

import matplotlib.pyplot as plt
import numpy as np

def cohen_curve(n):
    points = []
    for i in range(n):
        theta = 2 * np.pi / n
        x = (3 / 4) * np.cos(i * theta)
        y = (3 / 4) * np.sin(i * theta)
        points.append([x, y])
    return points

def sierpinski_carpet(n):
    points = []
    for i in range(n):
        for j in range(n):
            if (i % 2 == 0 and j % 2 == 0):
                continue
            x = (2 * j + 1) / n
            y = (2 * i + 1) / n
            points.append([x, y])
    return points

def fibonacci_sequence(n):
    points = []
    for i in range(n):
        x = i / n
        y = (1 / (1 + np.sqrt(5))) ** i
        points.append([x, y])
    return points

def plot_points(points):
    x = [p[0] for p in points]
    y = [p[1] for p in points]
    plt.scatter(x, y)
    plt.show()

# 生成并绘制科赫曲线
cohen_points = cohen_curve(3)
plot_points(cohen_points)

# 生成并绘制谢尔宾斯基地毯

plot_points(sierpinski_points)

### 1.3.6 数学模型和数学公式

在分形结构的研究中，常用的数学模型和公式包括：

1. **分形维度的计算：** 分形维度是描述分形复杂度的一个重要指标。分形维度的计算公式为：

$$ D = \ln(N) / \ln(L) $$

其中，$N$ 是分形结构的复杂度，$L$ 是分形结构的长度。

2. **科赫曲线的分形维度：** 科赫曲线的分形维度为：

$$ D = \ln(4) / \ln(3) $$

3. **谢尔宾斯基地毯的分形维度：** 谢尔宾斯基地毯的分形维度为：

$$ D = \ln(2) / \ln(3) $$

4. **费波那契序列的分形维度：** 费波那契序列的分形维度为：

$$ D = \ln(\phi) / \ln(\phi - 1) $$

其中，$\phi$ 是费波那契数列的黄金比例，$\phi = (1 + \sqrt{5}) / 2$。

### 1.3.7 详细讲解和举例说明

为了更好地理解这些数学模型和公式，我们可以通过以下例子进行详细讲解：

1. **科赫曲线的分形维度：** 假设我们有一条长度为1的科赫曲线，其复杂度为4（因为经过3次递归操作后，曲线长度变为原来的1/3的四次方）。则科赫曲线的分形维度为：

$$ D = \ln(4) / \ln(3) \approx 1.26186 $$

这意味着科赫曲线的复杂度介于1维和2维之间。

2. **谢尔宾斯基地毯的分形维度：** 假设我们有一条长度为1的谢尔宾斯基地毯，其复杂度为2（因为经过2次递归操作后，地毯长度变为原来的1/2的两次方）。则谢尔宾斯基地毯的分形维度为：

$$ D = \ln(2) / \ln(3) \approx 0.63182 $$

这意味着谢尔宾斯基地毯的复杂度介于0维和1维之间。

3. **费波那契序列的分形维度：** 假设我们有一条长度为1的费波那契序列，其复杂度为$\phi$（因为经过一次递归操作后，序列长度变为原来的$\phi - 1$）。则费波那契序列的分形维度为：

$$ D = \ln(\phi) / \ln(\phi - 1) \approx 0.61803 $$

这意味着费波那契序列的复杂度介于0维和1维之间。

通过以上例子，我们可以看到不同分形结构的分形维度不同，它们在宇宙中的表现也有所不同。

import matplotlib.pyplot as plt

def cohen_curve(n):
    points = []
    for i in range(n):
        theta = 2 * np.pi / n
        x = (3 / 4) * np.cos(i * theta)
        y = (3 / 4) * np.sin(i * theta)
        points.append([x, y])
    return points

def sierpinski_carpet(n):
    points = []
    for i in range(n):
        for j in range(n):
            if (i % 2 == 0 and j % 2 == 0):
                continue
            x = (2 * j + 1) / n
            y = (2 * i + 1) / n
            points.append([x, y])
    return points

def fibonacci_sequence(n):
    points = []
    for i in range(n):
        x = i / n
        y = (1 / (1 + np.sqrt(5))) ** i
        points.append([x, y])
    return points

def generate_fractal_structure(fractal_type: str, iterations: int, length: float) -> list:
    if fractal_type == "cohen_curve":
