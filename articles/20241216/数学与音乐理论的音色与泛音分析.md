数论是研究整数及其性质的数学分支。在音乐理论中，数论用于分析音律和音高。

#### 2.1.1 整数与素数

整数包括正整数、负整数和零。素数是大于1的自然数，且只能被1和自身整除。在音乐中，素数关系用于分析音律，例如，五度相生律中的每个音都是前一个音的素数倍。

圆是几何中的基本形状。在音乐中，圆可以用于表示音高的循环。

### 2.3 概率论基础

概率论是研究随机事件及其概率的数学分支。在音乐理论中，概率论用于分析音色的随机性和复杂性。

#### 2.3.1 随机事件与概率

随机事件是指在特定条件下可能发生也可能不发生的事件。概率是描述随机事件发生可能性的数值。

#### 2.3.2 条件概率与独立性

条件概率是指在某个事件发生的条件下，另一个事件发生的概率。独立性是指两个事件之间互不影响。

泊松分布和正态分布是两种常见的概率分布。在音乐中，它们可以用于分析音色的分布特性。

音高可以用频率来表示。频率是单位时间内振动的次数，单位是赫兹（Hz）。不同的音律体系有不同的音高计算方法。例如，在五度相生律中，每个音的频率是前一个音的频率的约1.2599倍。

#### 3.2.2 泛音的产生与特性

   \[

以下是一个简单的音色与泛音分析系统的核心实现：

```python
import numpy as np
import scipy.signal as signal
import matplotlib.pyplot as plt
import midiutil

def audio_input(file_path):
    # 读取音频文件
    audio = midiutil.MidiFile(file_path)
    channels = audio.tracks[0].getChannels()
    frames = channels[0].frames()
    return frames

def fourier_transform(frames, sample_rate):
    # 傅里叶变换
    n = len(frames)
    T = 1/sample_rate
    frequencies = np.fft.rfft(frames)
    return frequencies, T

def freq_analysis(frequencies, T):
    # 频率分析
    n = len(frequencies)
    freqs = np.fft.rfftfreq(n, T)
    return freqs, np.abs(frequencies)

def plot_spectrogram(freqs, frequencies):
    # 绘制频谱图
    plt.specgram(frames, NFFT=1024, Fs=sample_rate, scale='dB')
    plt.xlabel('Time [s]')
    plt.ylabel('Frequency [Hz]')
    plt.title('Spectrogram')
    plt.show()

if __name__ == "__main__":
    file_path = "example.mid"
    frames = audio_input(file_path)
    frequencies, T = fourier_transform(frames, sample_rate=44100)
    freqs, amplitude = freq_analysis(frequencies, T)
    plot_spectrogram(freqs, amplitude)
```

这段代码首先读取MIDI文件中的音频数据，然后使用傅里叶变换提取频率成分，最后绘制频谱图。这里使用了`midiutil`库来读取MIDI文件，`numpy`库进行数学运算，`matplotlib`库进行数据可视化。
