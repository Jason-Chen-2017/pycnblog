## 非线性动力学

### 基本概念

非线性动力学是研究复杂系统动态行为的数学理论。在非线性动力学中，系统的行为不仅受到初始条件的影响，还受到系统内部各种非线性相互作用的影响。这种相互作用可能导致系统出现混沌、分岔和突跃等现象。

### 原理

非线性动力学的基本原理包括：

1. **非线性相互作用**：系统内部的各种非线性相互作用会导致系统的行为偏离线性预测，产生复杂的行为模式。
2. **相空间**：相空间是描述系统动态行为的一种数学工具，通过分析相空间中的轨迹，可以理解系统的长期行为和稳定性。
3. **分岔与突跃**：在非线性系统中，参数的变化可能导致系统行为的突变，这种现象称为分岔与突跃。
4. **混沌现象**：混沌是非线性动力学中的一种特殊现象，表现为系统在初始条件的微小变化下产生长期的、不可预测的行为。

### 应用领域

非线性动力学在多个领域有广泛应用，包括：

1. **物理学**：研究混沌现象、分岔行为和复杂系统的稳定性。
2. **工程学**：分析非线性系统的动态响应和控制策略。
3. **经济学**：研究市场波动、金融系统和宏观经济行为。
4. **生物学**：理解生态系统的动态行为和物种相互作用。

$$

\frac{dx_2}{dt} &= c \cdot (1 - x_3) - d \cdot x_2, \\
\frac{dx_3}{dt} &= e \cdot x_1 - f \cdot x_3, \\

import numpy as np
from scipy.integrate import solve_ivp

def dynamic_equation(t, y, params):
    a, b, c, d = params
    dydt = [a * y[0] - b * y[1],
            c * (1 - y[2]) - d * y[1],
            e * y[0] - f * y[2]]
    return dydt

initial_conditions = data.loc[data['年份'] == 2022, ['亮度', '饱和度', '深度']].values.flatten()
t_span = (0, 180)
t_eval = np.linspace(0, 180, 1000)

sol = solve_ivp(dynamic_equation, t_span, initial_conditions, args=(params,), t_eval=t_eval)
predicted_colors = sol.y

predicted_colors = np.vstack((predicted_colors.T, t_eval)).T
predicted_colors
