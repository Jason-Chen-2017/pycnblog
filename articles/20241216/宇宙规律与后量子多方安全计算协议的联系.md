```python
# 创建量子密钥分发电路

# 输出量子密钥
print(state)
```

**核心要素**

- **参与方**：多方安全计算涉及多个参与方，每个参与方都拥有部分输入数据和计算目标。
- **安全通信**：参与方之间需要通过安全通道进行通信，确保传输的数据不被窃听或篡改。
- **隐私保护**：各方在计算过程中只能获得必要的信息，而不能获取其他参与方的隐私数据。
- **计算效率**：多方安全计算需要高效地处理大量数据，同时保证计算结果的准确性。
