### 3.2 模型训练与部署
- 3.2.1 模型训练的流程
- 使用 Mermaid 绘制的流程图：
  ```
  graph TD
      A[训练数据] --> B[特征提取]
  ```

- 3.2.2 模型训练的数学公式
  - 损失函数：$$L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y_i})^2$$
  - 优化算法：$$\theta = \theta - \alpha \frac{\partial L}{\partial \theta}$$
- 3.2.3 模型部署的代码示例：
  ```python
  import numpy as np
  from sklearn.linear_model import LinearRegression

  # 训练好的模型
  model = LinearRegression()

  # 预测
  X_new = np.array([[2.5], [3.0]])
  y_pred = model.predict(X_new)
  print(y_pred)
  ```
