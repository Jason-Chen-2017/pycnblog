### 2.1.1 DNA分子的存储特性
DNA分子具有高存储密度、稳定性和可扩展性。每个核苷酸（A、T、C、G）可以表示2位二进制数据。

### 2.1.2 数据编码的数学模型
DNA编码的核心是将二进制数据转换为四进制序列。编码公式如下：
$$
\text{DNA序列} = f(\text{二进制数据})
$$
其中，$f$是一个编码函数，将每个二进制位转换为DNA碱基。

### 2.1.3 解码算法的实现原理
解码过程是编码的逆过程，通过DNA测序技术还原原始数据。解码算法需要处理测序误差和数据纠错问题。

```python
def encode_data(data):
    # 将二进制数据转换为DNA序列
    mapping = {'0': 'A', '1': 'T', '2': 'C', '3': 'G'}
    dna_sequence = ''.join([mapping[str(bit)] for bit in data])
    return dna_sequence

def decode_data(dna_sequence):
    # 将DNA序列解码为二进制数据
    mapping = {'A': '0', 'T': '1', 'C': '2', 'G': '3'}
    binary_data = [mapping[base] for base in dna_sequence]
    return ''.join(binary_data)

# 示例
data = [0, 1, 2, 3]
dna = encode_data(data)
print(f"Encoded DNA sequence: {dna}")
decoded_data = decode_data(dna)
print(f"Decoded data: {decoded_data}")
```
