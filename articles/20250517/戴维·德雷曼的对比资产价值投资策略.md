- **6.2 数学模型的详细推导**
  - 市盈率模型：$P/E = \frac{股票价格}{每股收益}$
  - 市净率模型：$P/B = \frac{股票价格}{每股净资产}$
  - 股息率模型：$D/R = \frac{年股息}{股价}$
- **6.3 算法实现的Python代码**
  ```python
  def calculate_valuation_models(prices, eps, bvps, dividends):
      pe = prices / eps
      pb = prices / bvps
      dr = dividends / prices
      return pe, pb, dr

  # 示例数据
  prices = [100, 90, 110]
  eps = [10, 9, 11]
  bvps = [50, 45, 55]
  dividends = [2, 3, 4]

  pe, pb, dr = calculate_valuation_models(prices, eps, bvps, dividends)
  print("市盈率:", pe)
  print("市净率:", pb)
  print("股息率:", dr)
  ```
