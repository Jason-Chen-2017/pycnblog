# 第1章 高超音速飞行技术概述

## 1.1 高超音速飞行技术的定义与特点

### 1.1.1 高超音速飞行技术的定义
高超音速飞行技术是指飞行速度超过5马赫（即5倍音速）的技术，涉及航空航天领域的先进推进系统、空气动力学和材料科学。这种技术主要用于军事和商业目的，例如导弹、卫星发射和下一代战斗机。

### 1.1.2 高超音速飞行技术的核心特点
- **高速性**：飞行速度超过5马赫，显著缩短飞行时间。
- **技术复杂性**：涉及高温材料、空气动力学和推进系统等多个领域的高度集成。
- **应用场景广泛**：军事领域（导弹）、商业领域（高超音速客机）。

### 1.1.3 高超音速飞行技术的应用领域
- **军事领域**：用于导弹和无人机，提升打击速度和精确度。
- **商业领域**：探索高超音速客机，大幅缩短洲际飞行时间。
- **航天领域**：用于卫星发射和深空探索。

高超音速飞行器通常采用冲压发动机或 scramjet（高超音速冲压发动机），能够在高速飞行中提供足够的推力。

### 3.1.3 材料科学原理
高超音速飞行器需要耐高温、高强度的材料，以应对高速飞行中的高温和压力。
