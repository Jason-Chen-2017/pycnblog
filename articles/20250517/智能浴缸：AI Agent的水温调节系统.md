## 第三部分: 算法原理

### 第3章: 强化学习算法详解

#### 3.1 算法原理
- **3.1.1 强化学习的基本概念**
  强化学习通过智能体与环境的交互，学习最优策略以最大化累积奖励。
- **3.1.2 Q-learning算法的数学模型**
  $$ Q(s, a) = r + \gamma \max Q(s', a') $$
  其中，$Q(s, a)$表示状态-动作对的值，$\gamma$为折扣因子。

## 第五部分: 项目实战

### 第5章: 项目实现与案例分析

#### 5.1 环境安装与核心代码
```python
import numpy as np
import random

class Agent:
    def __init__(self, learning_rate=0.1, gamma=0.9):
        self.learning_rate = learning_rate
        self.gamma = gamma
        self.q_table = {}

    def get_action(self, state):
        if state not in self.q_table:
            self.q_table[state] = random.uniform(0, 1)
        actions = [0, 1]  # 0: 冷却, 1: 加热
        return random.choice(actions)

    def update_q_table(self, state, action, reward, next_state):
        current_q = self.q_table[state]
        next_max_q = max(self.q_table.get(next_state, 0), 0.5)
        new_q = reward + self.gamma * next_max_q
        self.q_table[state] = current_q + self.learning_rate * (new_q - current_q)
```
