# 第4章：算法原理与数学模型

## 4.1 算法原理与流程图  
- 4.1.1 基于向量空间模型的检索算法  
  - TF-IDF、BM25算法  
- 4.1.2 基于协同过滤的推荐算法  
  - UserCF、ItemCF  
- 4.1.3 基于深度学习的推荐算法  
  - Word2Vec、BERT、GPT  

## 4.2 数学模型与公式  
- 4.2.1 TF-IDF公式  
  $$TF-IDF = \frac{\text{词频}}{\text{文档数}}$$  
- 4.2.2 BM25公式  
  $$BM25 = \frac{\text{B} \times \text{M} \times \text{log}(TF + 1)}{\text{log}(N - TF) + 1}$$  
- 4.2.3 协同过滤公式  
  $$\text{相似度} = \frac{\sum_{i=1}^{n} (u_i - \bar{u})(v_i - \bar{v})}{\sqrt{\sum_{i=1}^{n} (u_i - \bar{u})^2} \times \sqrt{\sum_{i=1}^{n} (v_i - \bar{v})^2}}$$
