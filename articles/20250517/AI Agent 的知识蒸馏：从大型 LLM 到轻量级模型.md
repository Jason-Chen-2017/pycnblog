### 第3章：知识蒸馏的算法原理

#### 3.1 知识蒸馏的核心算法
- 3.1.1 KL散度的定义与计算
  - KL散度衡量两个概率分布的差异
  - 公式：$$D_{KL}(P||Q) = \sum P(x) \log \frac{P(x)}{Q(x)}$$
- 3.1.2 知识蒸馏的损失函数
  - 蒸馏损失：$$L_{distill} = D_{KL}(P||Q)$$
  - 原始任务损失：$$L_{task} = \text{分类损失}$$
- 3.1.3 知识蒸馏的优化策略
  - 温度调节：$$T$$
  - 权重分配：$$\alpha L_{distill} + (1-\alpha) L_{task}$$

#### 3.2 知识蒸馏的算法流程
- 3.2.1 算法的输入与输出
  - 输入：教师模型、学生模型、数据集
  - 输出：优化后的学生模型
- 3.2.2 算法的详细步骤
  - 数据预处理
  - 知识蒸馏过程
  - 模型微调

#### 3.3 知识蒸馏的数学模型
- 3.3.1 KL散度的公式推导
  - $$D_{KL}(P||Q) = \sum P(x) \log \frac{P(x)}{Q(x)}$$

- 知识蒸馏代码示例
  ```python
  import tensorflow as tf
  from tensorflow import keras

  # 定义教师模型
  def teacher_model():
      model = keras.Sequential([
          keras.layers.Dense(128, activation='relu'),
          keras.layers.Dense(10, activation='softmax')
      ])
      return model

  # 定义学生模型
  def student_model():
      model = keras.Sequential([
          keras.layers.Dense(64, activation='relu'),
          keras.layers.Dense(10, activation='softmax')
      ])
      return model

  # 知识蒸馏
  def distill(teacher, student, X, y, T=2, alpha=0.5):
      teacher_pred = teacher.predict(X)
      student_pred = student.predict(X)
      loss_distill = tf.keras.losses.KLDivergence()(teacher_pred, student_pred) * T
      loss_task = tf.keras.losses.sparse_categorical_crossentropy(y, student_pred)
      total_loss = alpha * loss_distill + (1 - alpha) * loss_task
      return total_loss

  # 模型优化
  def train(teacher, student, X, y, epochs=100, T=2, alpha=0.5):
      for epoch in range(epochs):
          loss = distill(teacher, student, X, y, T, alpha)
          student trainable层的梯度
          optimizer = tf.keras.optimizers.Adam()
          optimizer.minimize(loss, student.trainable_weights)
      return student
  ```
