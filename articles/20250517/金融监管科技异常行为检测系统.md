#### 3.3 算法实现代码
- 3.3.1 LOF算法的Python实现
```python
import numpy as np
from sklearn.neighbors import NearestNeighbors

def compute_lof(X, n_neighbors=5):
    clf = NearestNeighbors(n_neighbors)
    clf.fit(X)
    lof = []
    for i in range(len(X)):
        kn = clf.kneighbors(X[i].reshape(1, -1), return_distance=False)
        kn_size = len(kn[0])
        lof.append(kn_size)
    return np.array(lof)
```
