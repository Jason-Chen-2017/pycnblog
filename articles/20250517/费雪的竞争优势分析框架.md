## 3.2 竞争优势评分模型的数学公式

### 3.2.1 资源分配效率的计算公式

$$\text{资源分配效率} = \frac{\text{实际产出}}{\text{资源投入}}$$

### 3.2.2 资源杠杆效应的计算公式

$$\text{杠杆效应} = \frac{\text{杠杆资源}}{\text{非杠杆资源}}$$

### 3.2.3 资源协同效应的计算公式

$$\text{协同效应} = \frac{\text{协同产出}}{\text{各部分产出之和}}$$

## 3.3 算法实现的Python代码示例

```python
def calculate_competitive_edge(resources, costs, outputs):
    efficiency = outputs / resources
    leverage = resources['leveraged'] / resources['non-leveraged']
    synergy = (outputs['total'] - outputs['individual_sum']) / resources['total']
    return efficiency, leverage, synergy

# 示例数据
resources = {'leveraged': 100, 'non-leveraged': 50, 'total': 150}
costs = 50
outputs = {'total': 200, 'individual_sum': 150}

efficiency, leverage, synergy = calculate_competitive_edge(resources, costs, outputs)
print(f"Efficiency: {efficiency}, Leverage: {leverage}, Synergy: {synergy}")
```
