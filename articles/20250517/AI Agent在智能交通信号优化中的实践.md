## 第三部分: 算法原理讲解

### 第3章: 强化学习算法在交通信号优化中的应用

#### 3.1 强化学习的基本原理
- **3.1.1 强化学习的定义**
  - 通过试错学习，智能体在环境中通过交互获得奖励，优化策略。

- **3.1.2 算法流程**
  - 状态空间、动作空间、奖励函数。
  - Q-learning算法：$Q(s, a) = r + \gamma \max Q(s', a')$。

#### 3.2 强化学习在交通信号优化中的实现
- **3.2.1 状态表示**
  - 当前交通状态：各方向车流量、等待时间等。

- **3.2.2 动作空间**
  - 信号灯配时方案：绿灯时长、黄灯时长等。

- **3.2.3 奖励函数设计**
  - 基于通行效率：$r = \text{流量} \times \text{速度}$。
  - 基于拥堵缓解：$r = -\text{拥堵时间}$。

#### 3.3 强化学习算法的实现代码
```python
import numpy as np

# 状态空间：各方向车流量
# 动作空间：绿灯时长
class Agent:
    def __init__(self, state_size, action_size):
        self.state_size = state_size
        self.action_size = action_size
        self.gamma = 0.99
        self.epsilon = 1.0
        self.q_table = np.zeros((state_size, action_size))

    def act(self, state):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.action_size)
        else:
            return np.argmax(self.q_table[state])

    def reward(self, state, action, reward, next_state):
        self.q_table[state, action] = reward + self.gamma * np.max(self.q_table[next_state])

    def decay_epsilon(self):
        self.epsilon = max(0.01, self.epsilon * 0.99)
```
