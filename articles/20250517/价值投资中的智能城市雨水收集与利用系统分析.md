- 平衡经济效益与生态效益  

## 3.2 优化算法原理  
- 线性规划模型：最大化收益函数  
  $$ \text{Maximize } Z = \sum (收入 - 成本) $$
- 动态规划模型：分阶段优化决策  
  $$ \text{Stage } t: 状态变量 } S_t \text{，决策变量 } D_t \text{，状态转移方程 } S_{t+1} = f(S_t, D_t) $$  
- 遗传算法：适应度函数设计  
  $$ \text{Fitness Function } F = \text{水资源利用率} \times \text{经济效益} $$
