# 第一部分：价值投资的背景与核心概念

## 第1章：价值投资的定义与核心要素

### 1.1 价值投资的定义
价值投资是一种以低于市场价购买优质资产的投资策略，核心在于寻找市场低估的投资标的。与其他投资策略相比，价值投资强调安全边际和长期持有。

### 1.2 核心要素
- **安全边际**：买入价格低于内在价值的部分，确保投资的安全性。
- **内在价值**：资产在未来现金流的现值，需通过DCF模型计算。
- **市场先生**：市场的波动性和非理性为价值投资者提供了机会。

### 2.1 格雷厄姆的生平与贡献
