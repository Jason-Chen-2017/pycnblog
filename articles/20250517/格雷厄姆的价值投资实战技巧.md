#### 4.2 实战案例分析

##### 4.2.1 基本面分析
基本面分析是价值投资的核心，主要关注公司的财务状况和行业地位。以下是基本面分析的关键指标：

1. **市盈率（P/E）**：
   - 计算公式：`P/E = 市场价 / 每股收益（EPS）`
   - 低P/E比率通常意味着股票被低估。

2. **市净率（P/B）**：
   - 计算公式：`P/B = 市场价 / 每股净资产（BPS）`
   - 低P/B比率可能表明股票价格低于其资产价值。

3. **股息率**：
   - 计算公式：`股息率 = 每股股息（DIV） / 市场价`
   - 高股息率可能意味着股票提供稳定的收益。

##### 4.2.2 安全边际计算
安全边际是价值投资中的关键概念，用于衡量股票价格与内在价值之间的差异。以下是计算安全边际的步骤：

1. **计算内在价值**：
   - 使用现金流折现法（DCF）或其他方法估算公司的真实价值。

2. **确定市场价格**：
   - 获取当前股票的市场价格。

3. **计算安全边际**：
   - 公式：`安全边际 = 内在价值 - 市场价格`

##### 4.3.2 系统实现代码
以下是实现投资决策系统的Python代码示例：

```python
import yfinance as yf
import pandas as pd
import numpy as np

def calculate_intrinsic_value(stock_data):
    # 简单的现金流折现法示例
    free_cash_flow = stock_data['Free Cash Flow'].iloc[-1]
    discount_rate = 0.1  # 假设折现率为10%
    intrinsic_value = free_cash_flow / (1 + discount_rate)
    return intrinsic_value

def calculate_margin_of_safety(stock_data, intrinsic_value):
    market_price = stock_data['Adj Close'].iloc[-1]
    margin_of_safety = intrinsic_value - market_price
    return margin_of_safety

# 获取股票数据
aapl = yf.download('AAPL', start='2020-01-01', end='2023-12-31')

# 计算内在价值
iv = calculate_intrinsic_value(aapl)
print(f"内在价值: ${iv:.2f}")

# 计算安全边际
mos = calculate_margin_of_safety(aapl, iv)
print(f"安全边际: ${mos:.2f}")

if mos > 0:
    print("投资建议：买入")
elif mos == 0:
    print("投资建议：持有")
else:
    print("投资建议：卖出")
```
