### 第7章: 数学模型与公式

#### 7.1 协同过滤的相似度计算
$$ \text{相似度}(u_i, u_j) = \frac{\sum_{k} (r_{ik} - \bar{r_i})(r_{jk} - \bar{r_j})}{\sqrt{\sum_{k} (r_{ik} - \bar{r_i})^2} \sqrt{\sum_{k} (r_{jk} - \bar{r_j})^2}} $$

#### 7.2 基于内容的推荐相似度计算
$$ \text{相似度}(p_i, p_j) = \frac{\sum_{f} w_f (f_i - f_j)^2}{\sum_{f} w_f} $$

#### 7.3 深度学习模型的损失函数
$$ \mathcal{L} = -\sum_{i=1}^{N} \sum_{j=1}^{M} y_{ij} \log p(y_{ij}|x_i) + (1 - y_{ij}) \log (1 - p(y_{ij}|x_i)) $$

from sklearn.metrics.pairwise import cosine_similarity

# 数据预处理
def preprocess_data(users, products):
    # 特征提取
    user_features = extract_features(users)
    product_features = extract_features(products)
    # 计算相似度
    similarity_matrix = cosine_similarity(user_features, product_features)
    return similarity_matrix

# 协同过滤推荐
def collaborative_filtering_recommendation(similarity_matrix, user_id):
    user_index = user_id
    top_recommendations = []
    for product_index in range(len(similarity_matrix[user_index])):
        if product_index != user_index:
            top_recommendations.append(product_index)
    return top_recommendations[:10]
