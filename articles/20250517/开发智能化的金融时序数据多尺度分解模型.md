## 3.2 算法数学模型

### 3.2.1 分解模型的数学表达

$$ y_t = \sum_{i=1}^{n} w_i x_i $$

其中，$y_t$ 是分解后的成分，$w_i$ 是权重，$x_i$ 是输入特征。

### 3.2.2 预测模型的数学表达

$$ \hat{y}_{t+1} = \sigma(W x_t + b) $$

其中，$\sigma$ 是激活函数，$W$ 是权重矩阵，$b$ 是偏置项。

## 5.2 核心代码实现

```python
import pandas as pd
import numpy as np
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout

# 数据加载
data = pd.read_csv('stock_data.csv')
X = data.values.reshape(-1, 1, len(data.columns))
y = data['close'].values

# 模型构建
model = Sequential()
model.add(LSTM(64, input_shape=(1, len(data.columns))))
model.add(Dropout(0.2))
model.add(Dense(1))
model.compile(optimizer='adam', loss='mean_squared_error')

# 训练
model.fit(X, y, epochs=100, batch_size=32)
```
