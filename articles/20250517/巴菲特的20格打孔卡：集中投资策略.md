## 第一部分：投资基础知识

### 第1章：投资的基本概念

#### 1.1 投资的基本定义
投资是将资源（如资金）投入到某个项目或企业，以期获得未来收益的行为。投资的核心在于资产的配置和风险的控制。

#### 1.2 投资的分类与特点
投资可以分为股票、债券、房地产等多种形式，每种投资都有其特点和风险。股票投资具有较高的风险和回报潜力，而债券则相对保守。

#### 1.3 投资的基本原则
- 分散投资：避免将所有资金投入单一资产。
- 长期视角：投资不是短期交易，而是长期价值的积累。
- 风险控制：评估并控制投资中的潜在风险。

### 第2章：巴菲特的投资理念

#### 2.1 巴菲特的投资哲学
巴菲特强调价值投资，即购买具有持续竞争优势、良好管理层和稳定财务状况的企业股票。

#### 2.2 巴菲特的价值投资理论
价值投资的核心在于寻找市场价格低于内在价值的股票。巴菲特定义了五项筛选标准：管理层质量、财务状况、竞争优势、行业地位和发展潜力。

#### 2.3 巴菲特的成功案例分析
通过分析可口可乐和美国运通等案例，展示巴菲特如何通过长期持有优质企业实现财富增长。

#### 3.2 20格打孔卡的核心要素
- 管理层质量：诚实、有能力。
- 财务状况：ROE高、负债低。

- 行业地位：龙头地位。
- 发展潜力：增长空间大。

#### 3.3 20格打孔卡的使用方法
通过打孔标记企业是否符合各项标准，最终筛选出少数优质企业。

### 第6章：数学模型与公式

#### 6.1 常用财务指标公式
- ROE（净资产收益率）：
  $$ROE = \frac{净利润}{平均股东权益}$$
- 毛利率：
  $$毛利率 = \frac{（营业收入 - 营业成本）}{营业收入} \times 100\%$$

#### 6.2 财务指标的权重分配
根据重要性分配权重，ROE和毛利率占比较高。

#### 6.3 数学模型的实际应用
通过公式计算企业财务指标，评估是否符合筛选标准。

#### 9.2 核心实现代码

```python
import pandas as pd

def calculate_roe(net_profit, avg_equity):
    return net_profit / avg_equity

data = pd.read_csv('企业数据.csv')
data['ROE'] = calculate_roe(data['净利润'], data['平均股东权益'])
data['毛利率'] = (data['营业收入'] - data['营业成本']) / data['营业收入'] * 100
# 筛选条件：ROE > 15%，毛利率 > 20%
筛选结果 = data[(data['ROE'] > 15) & (data['毛利率'] > 20)]
print(筛选结果)
```
