## 第1章 价值投资的背景与发展

### 1.1 价值投资的起源与发展
价值投资是一种以基本面分析为基础的投资策略，起源于20世纪初。本节将介绍价值投资的起源，分析其发展历程，并重点阐述玛丽·巴芙在这一领域中的贡献。

- 19世纪末至20世纪初，现代投资学逐步形成。

- 以低于内在价值的价格买入优质资产。

## 第4章 价值投资的核心概念

### 4.1 内在价值与市场价值
本节将详细讲解内在价值与市场价值的概念及其关系。

#### 4.1.1 内在价值的定义
- 内在价值是企业未来现金流的现值。
- 通过DCF模型计算内在价值。

#### 4.1.2 市场价值的波动性
- 市场价值受情绪和短期因素影响。
- 内在价值是长期投资的依据。

#### 4.1.3 安全边际的计算方法
- 计算安全边际：买入价格 ≤ 内在价值 × (1 - 安全边际率)。
- 安全边际率通常为10%~20%。

## 第10章 价值投资的算法与数学模型

### 10.1 价值投资的数学模型
本节将介绍价值投资中常用的数学模型。

#### 10.1.1 内在价值计算公式
$$ \text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} $$
其中，\( r \) 是折现率，\( \text{现金流}_t \) 是第 \( t \) 年的现金流。

#### 10.1.2 安全边际计算方法
$$ \text{安全边际} = \text{内在价值} \times (1 - \text{安全边际率}) $$
$$ \text{买入价格} \leq \text{安全边际} $$

#### 10.1.3 投资组合优化模型
$$ \text{夏普比率} = \frac{\text{投资组合收益} - \text{无风险利率}}{\text{投资组合标准差}} $$

import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, covariance, weights):
    def objective(weights, returns, covariance):
        return -np.sum(weights * returns)
    
    constraints = [
        ('sum', weights, 1),
        ('sum', weights, 0)
    ]
    
    result = minimize(objective, weights, args=(returns, covariance), constraints=constraints)
    return result.x
```
