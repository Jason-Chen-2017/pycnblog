### 3.2 数学模型与公式
#### 3.2.1 综合评分公式
$$
\text{综合评分} = \sum (\text{创新维度权重} \times \text{创新维度评分}) + \sum (\text{风险维度权重} \times \text{风险维度评分})
$$

#### 3.2.2 风险概率计算
$$
P(\text{风险发生}) = \frac{\text{高风险评分}}{\text{总评分}}
$$

#### 3.2.3 风险影响评估
$$
I(\text{风险影响}) = \text{风险评分} \times \text{影响系数}
$$

### 3.3 代码实现
```python
def risk_assessment(innovation, risk):
    # 创新维度评分
    innov_scores = [0.8, 0.6, 0.9]
    # 风险维度评分
    risk_scores = [0.7, 0.5, 0.8]
    # 计算综合评分
    total_score = sum(innov_scores) + sum(risk_scores)
    return total_score

# 示例调用
print(risk_assessment(0.7, 0.6))

import numpy as np

def build_matrix(dimensions, weights):
    matrix = np.zeros((len(dimensions), len(weights)))
    for i, dim in enumerate(dimensions):
        for j, weight in enumerate(weights):
            matrix[i, j] = weight * dim
    return matrix

# 示例
dimensions = [0.8, 0.6, 0.9]
weights = [0.4, 0.3, 0.3]
print(build_matrix(dimensions, weights))
```

#### 5.2.2 风险评估代码

def assess_risk(matrix, product_info):
    # 计算综合评分
    total = np.dot(matrix, product_info)
    return total

# 示例
product_info = [0.7, 0.5, 0.8]
print(assess_risk(matrix, product_info))
