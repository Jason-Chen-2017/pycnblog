## 3.3 算法实现
### 3.3.1 决策树算法实现
```python
from sklearn.tree import DecisionTreeClassifier
import pandas as pd

# 数据加载与预处理
data = pd.read_csv('insurance.csv')
X = data[['age', 'income', 'job']]
y = data['insurance_type']

# 模型训练
model = DecisionTreeClassifier()
model.fit(X, y)

# 预测
new_user = [[30, 50000, 'employee']]
print(model.predict(new_user))
```

### 3.3.2 支持向量机算法
```python
from sklearn.svm import SVC

# 模型训练
model = SVC()
model.fit(X, y)

# 预测
print(model.predict(new_user))
```

## 3.4 数学公式
### 3.4.1 决策树的信息增益计算
$$ \text{信息增益} = \text{熵}(S) - \sum \text{分支} \times \text{熵}(S_i) $$

### 3.4.2 支持向量机的目标函数
$$ \text{minimize} \frac{1}{2} \|w\|^2 + C \sum \xi_i $$
$$ \text{subject to} \ y_i(w \cdot x_i + b) \geq 1 - \xi_i $$
$$ \xi_i \geq 0 $$

```python
import pandas as pd

data = pd.read_csv('insurance.csv')

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```

### 5.2.2 模型训练与评估
```python
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.2)
model = DecisionTreeClassifier()
model.fit(X_train, y_train)
print(accuracy_score(model.predict(X_test), y_test))
```
