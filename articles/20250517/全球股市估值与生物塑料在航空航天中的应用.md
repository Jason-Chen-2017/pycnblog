# 第2章 全球股市估值的核心原理

## 2.1 股市估值的基本概念
### 2.1.1 股票估值的定义
- 通过分析公司财务指标评估股票价值。

### 2.1.2 股票估值的主要方法
- 市盈率（P/E）、市净率（P/B）、股息率。

### 2.1.3 股票估值的影响因素
- 宏观经济、行业状况、公司业绩。

## 2.2 股市估值的数学模型
### 2.2.1 市盈率模型
- 公式：P/E = 市场价 / 每股收益。
- 通过案例分析股票的合理价格。

### 2.2.2 市净率模型
- 公式：P/B = 市场价 / 每股净资产。
- 适用于评估银行等资产密集型企业。

### 2.2.3 股息率模型
- 公式：股息率 = 每股股息 / 市场价。
- 适用于高分红股票的估值。

## 2.3 股市估值的算法原理
### 2.3.1 股票估值的流程图
```mermaid
graph TD
    A[开始] --> B[选择估值模型]
    B --> C[收集数据]
    C --> D[计算指标]
    D --> E[得出结论]
    E --> F[结束]
```

### 2.3.2 股票估值的数学公式
- $$P = E \times (1 + g)^n$$，其中P为股票价值，E为当前收益，g为增长率，n为时间。

# 第3章 生物塑料在航空航天中的应用

## 3.1 生物塑料的基本概念
### 3.1.1 生物塑料的定义
- 可生物降解的高分子材料。

### 3.1.2 生物塑料的分类
- 淀粉基塑料、聚乳酸（PLA）、聚羟基脂肪酸酯（PHA）。

### 3.1.3 生物塑料的优势与劣势
- 优势：环保、可降解；劣势：成本高、性能限制。

## 3.2 生物塑料在航空航天中的应用
### 3.2.1 生物塑料在飞机制造中的应用
- 用于内饰、座椅和结构部件。

### 3.2.2 生物塑料在航天器制造中的应用
- 用于卫星和火箭部件。

### 3.2.3 生物塑料在航空材料中的应用
- 用于轻质复合材料。

## 3.3 生物塑料在航空航天中的技术挑战
### 3.3.1 材料性能的限制
- 强度和耐温性不足。

### 3.3.2 制造工艺的复杂性
- 高成本和复杂性。

### 3.3.3 成本与效率的平衡
- 生物塑料的成本高于传统塑料。
