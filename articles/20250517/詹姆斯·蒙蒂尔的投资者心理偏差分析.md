## 第3章: 心理偏差的核心概念与联系

### 3.1 心理偏差的核心概念原理
- **确认偏差**：倾向于寻找支持已有观点的信息，导致投资决策失误。
- **损失厌恶**：对损失的厌恶影响投资组合选择。
- **过度自信**：高估自身能力，增加投资风险。

- **属性对比表**：

| 损失厌恶 | 厌恶损失 | 避险倾向 | 投资组合保守 |

```python
import numpy as np

def confirm_bias_detection(data):
    # 计算支持和反对比例
    support = np.mean(data['支持'])
    oppose = np.mean(data['反对'])
    return support - oppose
```

#### 6.2.2 损失厌恶模型
```python
def loss_aversion_model(profits, losses, lambda_val):
    # 计算效用
    utility = np.sum(profits ** (1 - lambda_val)) - np.sum(losses ** (1 - lambda_val))
    return utility
```
