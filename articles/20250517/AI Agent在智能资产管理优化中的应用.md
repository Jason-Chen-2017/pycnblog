#### 3.1.2 Q-learning算法
通过状态、动作和奖励优化策略，代码示例：

```python
import numpy as np

class QLearning:
    def __init__(self, state_space, action_space):
        self.Q = np.zeros((state_space, action_space))
    
    def choose_action(self, state, epsilon=0.1):
        if np.random.random() < epsilon:
            return np.random.randint(0, action_space)
        return np.argmax(self.Q[state])
    
    def update(self, state, action, reward, learning_rate=0.1, gamma=0.9):
        self.Q[state, action] = self.Q[state, action] + learning_rate * (reward + gamma * np.max(self.Q[state]))
```
