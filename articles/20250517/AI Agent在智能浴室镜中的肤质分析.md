### 3.2.2 使用CNN进行特征提取  
代码示例：
```python
import torch
import torch.nn as nn
import torch.optim as optim

class SkinFeatureExtractor(nn.Module):
    def __init__(self):
        super(SkinFeatureExtractor, self).__init__()
        self.conv1 = nn.Conv2d(3, 64, kernel_size=3, padding=1)
        self.relu = nn.ReLU()
        self.pool = nn.MaxPool2d(2, 2)

    def forward(self, x):
        x = self.conv1(x)
        x = self.relu(x)
        x = self.pool(x)
        return x
```
