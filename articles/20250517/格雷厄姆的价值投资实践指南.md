## 第一部分: 格雷厄姆价值投资的核心理念与背景

### 第1章: 价值投资的起源与发展

#### 1.1 价值投资的起源
价值投资是投资领域的重要流派之一，由本杰明·格雷厄姆在20世纪初提出。它强调以低于内在价值的价格买入优质资产，追求长期稳健的回报。随着市场的波动，价值投资在不同的经济周期中展现出其独特的优势。

#### 1.2 价值投资的核心理念
价值投资的核心在于“买入低于内在价值的资产”。格雷厄姆提出了“安全边际”的概念，即买入价格与内在价值之间的差距，用以降低投资风险。这种理念与现代投资组合理论有所不同，更注重长期价值而非短期波动。

#### 1.3 价值投资的适用范围
价值投资不仅适用于股票投资，也适用于房地产、债券等多种资产类别。然而，其核心在于基本面分析，强调对公司的财务状况、行业地位和未来前景的深入研究。

### 第2章: 核心概念与联系

#### 2.1 核心概念对比分析
通过对比分析，我们展示了安全边际、内在价值和市场价格之间的关系。

| 概念 | 定义 | 作用 |
|------|------|------|
| 安全边际 | 购买价格与内在价值的差额 | 提供投资的安全性，降低风险 |
| 内在价值 | 资产的真实价值，基于基本面分析 | 作为价格评估的基础 |
| 市场价格 | 当前市场上的交易价格 | 受市场情绪影响较大 |

#### 2.3 核心概念的数学模型
我们可以通过以下公式计算内在价值和安全边际：

$$ V = \frac{CF}{r - g} $$
$$ Margin\ of\ Safety = P - V $$

其中，$V$ 是内在价值，$CF$ 是现金流，$r$ 是折现率，$g$ 是增长率，$P$ 是市场价格。

#### 3.2 内在价值计算的Python实现
以下是计算内在价值的Python代码示例：

```python
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate, growth_rate):
    if discount_rate <= growth_rate:
        return 0  # 避免除以零或负数
    terminal_value = cash_flows[-1] * (1 + growth_rate) / (discount_rate - growth_rate)
    present_value = np.npv(discount_rate, cash_flows)
    return present_value + terminal_value

# 示例数据
cash_flows = [100, 120, 130, 140]
discount_rate = 0.1
growth_rate = 0.05

iv = calculate_intrinsic_value(cash_flows, discount_rate, growth_rate)
print(f"内在价值: {iv:.2f}")
```

#### 5.2 核心代码实现

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate, growth_rate):
    if discount_rate <= growth_rate:
        return 0
    terminal_value = cash_flows[-1] * (1 + growth_rate) / (discount_rate - growth_rate)
    present_value = np.npv(discount_rate, cash_flows)
    return present_value + terminal_value

# 示例数据
data = {
    '收入': [100, 120, 130, 140],
    '净利润': [20, 25, 30, 35],
    '现金流': [50, 60, 70, 80]
}

df = pd.DataFrame(data)

# 计算内在价值
iv = calculate_intrinsic_value(df['现金流'], 0.1, 0.05)
print(f"内在价值: {iv:.2f}")
```

#### 5.3 实际案例分析
以苹果公司为例，假设其现金流为1000亿美元，折现率为10%，增长率为5%，计算其内在价值：

$$ V = \frac{1000}{0.1 - 0.05} = 20,000 \text{亿美元} $$

如果当前市场价格为15,000亿美元，则安全边际为5,000亿美元，具有较高的投资价值。
