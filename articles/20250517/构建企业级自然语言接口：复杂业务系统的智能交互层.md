## 3.3 模型训练的数学模型
### 3.3.1 交叉熵损失函数的数学表达式

$$ \text{Loss} = -\sum_{i=1}^{n} \sum_{j=1}^{m} y_{i,j} \log(p_{i,j}) $$

其中，$y_{i,j}$ 是真实标签，$p_{i,j}$ 是预测概率。

### 5.2.2 NLG模块实现

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained('gpt2')
model = AutoModelForCausalLM.from_pretrained('gpt2')

def generate_response(query):
    inputs = tokenizer.encode(query, return_tensors="pt")
    outputs = model.generate(inputs, max_length=50)
    response = tokenizer.decode(outputs[0], skip_special_tokens=True)
    return response
```

## 5.3 代码实现与解读
### 5.3.1 FastAPI接口实现

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Query(BaseModel):
    query: str

@app.post("/api/v1/nlu")
async def process_nlu(query: Query):
    result = process_query(query.query)
    return {"intent": result[0]['label'], "score": result[0]['score']}

@app.post("/api/v1/nlg")
async def generate_response(query: Query):
    response = generate_response(query.query)
    return {"response": response}
```
