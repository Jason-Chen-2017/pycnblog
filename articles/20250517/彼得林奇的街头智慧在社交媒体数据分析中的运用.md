## 第1章：彼得林奇的"街头智慧"概述

彼得·林奇是全球著名投资专家，他的“街头智慧”投资哲学强调以下三个原则：

1. **长期投资**：避免频繁交易，选择优质企业长期持有。

### 1.2 社交媒体数据分析的重要性

## 第3章：自然语言处理技术在社交媒体数据分析中的应用

### 3.1 自然语言处理基础

自然语言处理（NLP）技术是分析社交媒体数据的核心工具，主要包括：

- **词干提取**：将单词还原为基本形式。
- **TF-IDF**：计算关键词的重要性。
- **深度学习模型**：如LSTM用于捕捉长文本的情感。

### 3.2 情感分析算法

情感分析是将文本分为积极、消极或中性情感的过程。常用方法包括：

- **基于规则的方法**：通过关键词匹配判断情感。
- **机器学习模型**：训练分类器进行情感分类。
- **深度学习模型**：如卷积神经网络（CNN）和长短期记忆网络（LSTM）。

### 5.2 项目实战

#### 5.2.1 环境配置

#### 5.2.2 数据获取与清洗

从Twitter获取数据并进行清洗：

```python
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC

# 数据获取与清洗
data = pd.read_csv('tweets.csv')
data = data.dropna()
data['text'] = data['text'].str.lower().str.replace(r'[^\w\s]', '')
```

#### 5.2.3 特征提取与模型训练

使用TF-IDF提取特征并训练SVM模型：

```python
vectorizer = TfidfVectorizer(max_features=500)
X = vectorizer.fit_transform(data['text'])
y = data['sentiment']

model = SVC(C=1.0, gamma=0.001)
model.fit(X, y)
```

#### 5.2.4 模型评估与优化

评估模型性能并进行调优：

```python
from sklearn.metrics import accuracy_score, classification_report

y_pred = model.predict(X)
print(accuracy_score(y, y_pred))
print(classification_report(y, y_pred))
```
