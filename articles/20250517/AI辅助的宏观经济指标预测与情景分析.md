## 第三部分：算法原理与数学模型

### 第3章：宏观经济预测的常用算法

#### 3.1 线性回归模型
- **原理**：线性回归通过最小化预测值与实际值的平方差，拟合最佳直线。
- **数学模型**：$$y = \beta_0 + \beta_1x + \epsilon$$
- **优缺点**：简单易懂，但仅适用于线性关系，无法捕捉复杂模式。

#### 3.2 时间序列预测模型
- **ARIMA模型**：通过自相关性和偏自相关性分析，建立自回归和移动平均模型。
- **LSTM网络**：使用长短期记忆单元，有效处理时间序列的长时依赖。
- **LSTM结构**：包括输入门、遗忘门和输出门，公式如下：
  - 输入门：$$i = \sigma(W_i x + U_i h_{prev})$$
  - 遗忘门：$$f = \sigma(W_f x + U_f h_{prev})$$
  - 输出门：$$o = \sigma(W_o x + U_o h_{prev})$$
  - 隐层状态：$$h = o \cdot \cosh(W_c x + U_c h_{prev})$$

#### 3.3 XGBoost算法
- **优势**：树模型的集成方法，具有高准确性和鲁棒性。
- **训练流程**：通过梯度提升，逐层优化预测结果。
- **代码示例**：
  ```python
  import xgboost as xgb
  model = xgb.XGBRegressor(n_estimators=100, learning_rate=0.1)
  model.fit(X_train, y_train)
  ```
