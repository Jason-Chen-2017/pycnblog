## 第5章 算法原理

### 5.1 神经网络模型
- **模型结构**：输入层、隐藏层、输出层。
- **激活函数**：sigmoid、ReLU、tanh。

### 5.2 强化学习
- **策略优化**：通过奖励机制调整动作选择。
- **价值函数**：评估状态的价值。

### 5.3 注意力机制
- **注意力分配**：在输入数据中分配权重。
- **计算公式**：
  $$
  \text{注意力权重} = \frac{\exp(a_i)}{\sum_{j} \exp(a_j)}
  $$

### 5.4 算法流程图
```mermaid

    A[输入] --> B(神经网络处理)
    B --> C[激活函数]
    C --> D[输出]
```

### 5.5 代码实现
```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

x = np.array([0.5, 1.0, -0.3])
y = sigmoid(x)
print(y)
```
