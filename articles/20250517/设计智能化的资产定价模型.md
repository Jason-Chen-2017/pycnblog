### 3.1 线性回归模型
- 3.1.1 线性回归的基本原理：最小二乘法的数学推导
  $$ \hat{\beta} = \arg \min_{\beta} \sum_{i=1}^n (y_i - \beta x_i)^2 $$
- 3.1.2 线性回归的实现代码
  ```python
  import numpy as np
  x = np.array([1, 2, 3, 4, 5])
  y = np.array([2, 3, 5, 6, 8])
  beta = np.linalg.lstsq(x[:, np.newaxis], y, rcond=None)[0]
  print(beta)
  ```
