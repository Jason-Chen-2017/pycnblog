# 第二章：强化学习的基础理论

## 2.1 强化学习的核心概念
### 2.1.1 状态、动作、奖励
- **状态 (State)**：市场情况、资产配置等。
- **动作 (Action)**：买入、卖出等操作。
- **奖励 (Reward)**：收益或损失。

### 2.1.2 策略与价值函数
- **策略 (Policy)**：决定动作的函数。
- **价值函数 (Value Function)**：评估状态价值。

### 2.1.3 探索与利用
平衡探索新策略和利用已知最优策略，以提高学习效率。

## 2.2 马尔可夫决策过程 (MDP)
- **MDP模型**：定义状态、动作、转移概率和奖励函数。
- **动态规划**：通过迭代方法优化策略。

## 2.3 强化学习算法的分类
- **值函数方法**：如Q-learning。
- **策略梯度方法**：如PG和Actor-Critic。

# 第三章：强化学习在金融中的数学模型与算法原理

## 3.1 Q-learning算法
### 3.1.1 原理与实现
- **Q-learning公式**：
  $$ Q(s, a) \leftarrow Q(s, a) + \alpha [r + \max Q(s', a') - Q(s, a)] $$
- **步骤**：
  1. 初始化Q表。
  2. 选择动作。
  3. 更新Q值。

### 3.1.2 应用实例
- 案例：资产配置问题，通过Q-learning优化投资组合。

## 3.2 Deep Q-Network (DQN)
### 3.2.1 网络结构
- 使用神经网络近似Q值函数。
- **DQN流程图**：


### 3.2.2 实现细节
- 经验回放：存储历史经验，减少相关性。
- 深度网络：输入状态，输出Q值。
