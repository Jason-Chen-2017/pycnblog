## 第一部分：背景与概述

### 第1章：员工满意度的重要性

#### 1.1 员工满意度的定义与内涵

员工满意度是指员工对其工作环境、薪酬、职业发展、工作与生活平衡等方面的满意程度。它是员工对工作整体感知的结果，直接影响员工的工作态度、表现和忠诚度。

- **定义**：员工满意度是员工对工作条件和环境的主观评价。
- **内涵**：包括薪酬、工作环境、职业发展、管理风格等多个方面。

#### 1.2 彼得·林奇与员工满意度

彼得·林奇是著名投资家，他关注员工满意度作为公司基本面的重要组成部分。他认为满意的员工是公司价值的创造者，因此在投资决策中，他会评估公司的员工满意度，以预测公司的长期表现。

## 第六部分：数学模型与算法

### 第6章：员工满意度指数模型

#### 6.1 模型构建

员工满意度指数（ESI）计算公式：

$$ ESI = \frac{\sum_{i=1}^{n} (s_i \times w_i)}{\sum_{i=1}^{n} w_i} $$

其中，$s_i$ 是第 $i$ 个指标的满意度评分，$w_i$ 是权重。

#### 6.2 算法实现

使用Python实现员工满意度计算：

```python
def calculate_esm(scores, weights):
    total = sum(scores[i] * weights[i] for i in range(len(scores)))
    weight_sum = sum(weights)
    return total / weight_sum

scores = [4, 3, 5, 2, 4]
weights = [0.3, 0.2, 0.25, 0.1, 0.15]
esi = calculate_esm(scores, weights)
print(f"员工满意度指数：{esi}")
```
