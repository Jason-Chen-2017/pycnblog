## 第三部分：算法原理讲解

### 第3章：资源评估与投资分析

#### 3.1 资源评估算法
- 3.1.1 资源潜力计算
  - 公式：$$\text{资源潜力} = \text{资源密度} \times \text{区域面积} \times \text{转化效率}$$
  - 步骤：
    1. 收集海洋生物质资源的分布数据
    2. 估算资源密度
    3. 计算区域面积
    4. 考虑技术转化效率
  - 流程图：
    ```mermaid
    graph TD
      A[收集数据] --> B[估算密度]
      B --> C[计算面积]
      C --> D[考虑效率]
      D --> E[输出潜力]
    ```

  - Python代码示例：
    ```python
    def calculate_resource_potential(density, area, efficiency):
        return density * area * efficiency

    # 示例数据
    density = 10  # 单位：吨/平方公里
    area = 1000    # 单位：平方公里
    efficiency = 0.8  # 转化效率
    potential = calculate_resource_potential(density, area, efficiency)
    print(f"资源潜力为：{potential} 吨")
    ```

#### 3.2 投资分析算法
- 3.2.1 投资可行性分析
  - 公式：$$\text{净现值（NPV）} = \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t}$$
    - $CF_t$：第 $t$ 年的现金流
    - $r$：折现率
    - $n$：项目周期
  - 步骤：
    1. 确定初始投资与年现金流
    2. 选择合适的折现率
    3. 计算净现值
  - 流程图：
    ```mermaid
    graph TD
      A[确定现金流] --> B[选择折现率]
      B --> C[计算NPV]
      C --> D[输出结果]
    ```

  - Python代码示例：
    ```python
    def calculate_npv(cash_flows, discount_rate):
        npv = 0
        for t, cf in enumerate(cash_flows):
            npv += cf / (1 + discount_rate) ** t
        return npv

    # 示例数据
    cash_flows = [-100, 50, 60, 70]
    discount_rate = 0.1
    npv = calculate_npv(cash_flows, discount_rate)
    print(f"净现值为：{npv:.2f}")
    ```
