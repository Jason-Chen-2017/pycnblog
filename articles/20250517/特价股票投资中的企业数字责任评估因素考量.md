# 第一章: 特价股票投资的背景与现状

## 1.1 特价股票投资的定义与特点  
### 1.1.1 特价股票的定义  
特价股票是指以低于市场价或内在价值的价格购买的股票。其核心在于“低价”，即市场价格低于其实际价值，通常被认为是一种投资机会。  

### 1.1.2 特价股票投资的特点  
- **价格优势**：特价股票的价格通常低于市场平均水平，为投资者提供了较高的安全边际。  
- **风险与收益并存**：特价股票可能隐藏着较高的风险，但也可能带来超额收益。  
- **周期性**：特价股票的投资机会往往与市场周期密切相关，通常在市场低迷时出现较多。  

### 1.1.3 特价股票与传统股票投资的区别  
- **投资策略**：传统股票投资注重长期价值，而特价股票投资更注重短期价格优势。  
- **风险偏好**：特价股票投资风险较高，适合风险承受能力较强的投资者。

import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 数据加载
data = pd.read_csv('企业数字责任数据.csv')

# 数据清洗
data.dropna(inplace=True)

# 特征提取
X = data.drop('数字责任评分', axis=1)
y = data['数字责任评分']

# 模型训练
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X, y)

# 模型预测
y_pred = model.predict(X)
print("模型准确率:", accuracy_score(y, y_pred))
