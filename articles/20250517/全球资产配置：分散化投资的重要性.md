### 第4章: 现代投资组合理论

#### 4.1 投资组合理论的基本原理
- 有效前沿理论：在给定风险下，找到收益最高的组合。
- 马科维茨的有效前沿理论。

#### 4.2 投资组合的数学模型
- 方差计算：$$\text{方差} = \sigma^2$$
- 协方差矩阵：用于计算资产之间的相关性。

#### 4.3 投资组合优化的算法
- 均值-方差优化：$$\min \sum w_i^2 \sigma_i^2 + 2w_i w_j \sigma_{ij}$$

### 第5章: 分散化投资的数学模型

#### 5.1 方差计算
- 单个资产的方差：$$\sigma^2$$
- 投资组合的方差：$$\mathbf{w}^T \Sigma \mathbf{w}$$

#### 5.2 协方差矩阵
- 用于衡量资产之间的相关性：$$\Sigma = \text{协方差矩阵}$$

#### 5.3 优化问题的数学表达
- 最优化目标：$$\min \mathbf{w}^T \Sigma \mathbf{w}$$
- 约束条件：$$\sum w_i = 1$$

import numpy as np
import scipy.optimize as optimize

def portfolio_optimization(returns):
    n = len(returns.columns)
    cov_matrix = returns.cov()
    
    def objective(weights):
        return np.dot(weights.T, np.dot(cov_matrix, weights))
    
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    bounds = [(0, 1) for _ in range(n)]
    
    result = optimize.minimize(objective, np.ones(n)/n, method='SLSQP', bounds=bounds, constraints=constraints)
    return result.x
```
