## 3.2 算法实现代码

### 3.2.1 文本预处理

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer

def preprocess(text):
    # 分词
    words = text.split()
    # 转换为小写
    words_lower = [word.lower() for word in words]
    return ' '.join(words_lower)
```

### 3.2.2 特征提取

```python
vectorizer = TfidfVectorizer()

```


```python
y_pred = model.predict(X_test)

```

## 3.3 算法的数学模型和公式

### 3.3.1 TF-IDF计算公式
$$
TF-IDF = TF \times IDF
$$

其中，
$$
TF = \frac{\text{词项在文档中的出现次数}}{\text{文档总词数}}
$$

$$
IDF = \log\left(1 + \frac{\text{总文档数}}{\text{词项出现的文档数}}\right)
$$

### 3.3.2 支持向量机模型
$$
\text{目标函数: } \min \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \xi_i
$$

### 3.3.3 朴素贝叶斯分类
$$
P(y|X) = \frac{P(X|y)P(y)}{P(X)}
$$
