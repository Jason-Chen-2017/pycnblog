## 第1章: 知识图谱与金融咨询的背景与概念

### 1.1 知识图谱的定义与特点

#### 1.1.1 知识图谱的定义
知识图谱是一种以图结构形式表示知识的语义网络，由节点（实体）和边（关系）组成，能够描述实体之间的关系及其属性。知识图谱通过将分散的数据进行结构化和语义化，提供了一种统一的知识表示方式。

#### 1.1.2 知识图谱的核心特点
知识图谱具有以下特点：
- **语义性**：通过实体和关系描述，提供语义化的知识表示。
- **可扩展性**：支持大规模数据的整合和扩展。
- **动态性**：能够实时更新和维护，适应数据的变化。
- **关联性**：通过关联实体之间的关系，提供深度的语义理解。

#### 1.1.3 知识图谱与传统数据库的区别
| 特性         | 传统数据库       | 知识图谱       |
|--------------|------------------|---------------|
| 数据结构     | 行列式结构       | 图结构         |
| 关系表示     | 通过外键表示     | 显式表示       |
| 查询方式     | 基于记录的查询   | 基于图的查询   |
| 复杂性       | 低               | 高             |

## 第2章: 知识图谱与金融咨询的核心概念

### 2.1 知识图谱的核心概念

#### 2.1.1 实体与属性
- **实体**：知识图谱中的基本单位，代表现实世界中的具体事物，如“公司”、“股票”等。
- **属性**：描述实体的特征或状态，如“公司名称”、“成立时间”等。

#### 2.1.2 关系与事实
- **关系**：描述实体之间的关联，如“投资于”、“隶属于”等。
- **事实**：由头实体、关系和尾实体组成的三元组，如（公司A，投资于，项目B）。

#### 2.1.3 知识图谱的构建流程
知识图谱的构建流程包括：
1. 数据收集：从多种数据源获取数据。
2. 数据清洗：去除冗余和噪声数据。
3. 实体识别：识别数据中的实体。
4. 关系抽取：提取实体之间的关系。
5. 知识融合：整合多个数据源的信息。
6. 知识存储：将构建的知识图谱存储起来。

def extract_entities(text):
    doc = nlp(text)
    entities = []
    for ent in doc.ents:
        entities.append((ent.text, ent.label_))
    return entities
