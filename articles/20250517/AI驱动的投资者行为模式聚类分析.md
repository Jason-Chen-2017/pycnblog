### 第三章：聚类分析的核心概念与算法

#### 3.1 聚类分析的基本原理
聚类分析是将数据点划分到不同组别中的技术，每个组别内的数据点具有相似性，而不同组别之间则有显著差异。

#### 3.2 常见聚类算法的原理与实现
##### K-means算法
- 原理：将数据划分为K个簇，通过迭代优化簇中心。
- 代码示例：
  ```python
  from sklearn.cluster import KMeans

  # 初始化模型
  kmeans = KMeans(n_clusters=3)
  # 训练模型
  kmeans.fit(X)
  # 预测簇标签
  labels = kmeans.predict(X)
  ```

##### DBSCAN算法
- 原理：基于密度的聚类，识别高密度区域。
- 代码示例：
  ```python
  from sklearn.cluster import DBSCAN

  dbSCAN = DBSCAN(eps=0.5, min_samples=5)
  dbSCAN.fit(X)
  ```

#### 3.3 算法选择与优化
选择合适的算法需考虑数据分布、簇的形状以及计算资源。K-means适用于球形簇，DBSCAN适用于任意形状簇。

#### 5.2 核心代码实现
##### 数据预处理
```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('investor_data.csv')

# 删除异常值
data = data[(np.abs(data - data.mean()) <= 3 * data.std()).all(axis=1)]

# 标准化
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
data_scaled = scaler.fit_transform(data)
```

##### 聚类分析
```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

# 模型训练
kmeans = KMeans(n_clusters=3)
kmeans.fit(data_scaled)

# 评估指标
print(silhouette_score(data_scaled, kmeans.labels_))
```
