## 1.2 小盘股价值投资的核心概念

### 1.2.1 小盘股的定义与特点

小盘股通常指市值在1亿至10亿美元之间的公司股票。这些公司往往处于成长阶段，具有较高的增长潜力，但同时也面临较高的风险。小盘股的特点包括流动性较低、波动性较大、市场关注度较低等。

### 1.2.2 价值投资的基本原理

价值投资的核心在于寻找市场价格低于内在价值的股票。内在价值是基于公司基本面的评估，包括盈利能力、财务状况、行业地位等因素。投资者通过深入分析这些因素，找到被市场低估的投资机会。

### 1.2.3 小盘股投资的独特优势

小盘股投资的优势在于其较高的增长潜力和较低的估值。由于小盘股通常被市场忽视，其内在价值可能远高于市场价格。此外，小盘股的投资门槛较低，适合个人投资者参与。

## 3.2 算法原理的数学模型

### 3.2.1 市盈率计算公式

$$ P/E = \frac{Price}{Earnings} $$

### 3.2.2 市净率计算公式

$$ P/B = \frac{Price}{Book\ Value} $$

### 3.2.3 股息率计算公式

$$ Dividend\ Yield = \frac{Dividend}{Price} \times 100\% $$

## 3.3 算法实现的Python代码示例

```python
def calculate_pe_ratio(price, earnings):
    return price / earnings

def calculate_pb_ratio(price, book_value):
    return price / book_value

def calculate_dividend_yield(dividend, price):
    return (dividend / price) * 100

# 示例数据
price = 10
earnings = 2
book_value = 5
dividend = 0.5

pe_ratio = calculate_pe_ratio(price, earnings)
pb_ratio = calculate_pb_ratio(price, book_value)
dividend_yield = calculate_dividend_yield(dividend, price)

print(f"市盈率: {pe_ratio}")
print(f"市净率: {pb_ratio}")
print(f"股息率: {dividend_yield}%")
```

import numpy as np

# 投资决策
data.sort_values('value_rating', ascending=False, inplace=True)
top_stocks = data.head(10)
