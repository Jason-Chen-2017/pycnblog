## 第1章：蒙特卡洛模拟的核心概念

### 1.1 概率分布分析的定义与背景
#### 1.1.1 概率分布的定义
概率分布描述了随机变量在不同取值下的概率。例如，股票价格的变化可以用概率分布来建模。

#### 1.1.2 蒙特卡洛模拟的历史与发展
蒙特卡洛模拟由John von Neumann等科学家在20世纪40年代提出，最初用于核物理研究，后来扩展到金融、工程等领域。

#### 1.1.3 蒙特卡洛模拟的应用领域
在投资分析中，蒙特卡洛模拟用于评估资产组合的风险、定价金融衍生品以及模拟市场波动。

### 1.2 投资结果的不确定性分析
#### 1.2.1 投资结果的概率分布
投资结果（如股票收益）可以用概率分布来描述，帮助投资者理解可能的收益范围和风险。

#### 1.2.2 随机变量与随机过程
随机变量（如股票价格）和随机过程（如布朗运动）是蒙特卡洛模拟的基础。

# 第二部分：蒙特卡洛模拟的数学基础

## 第2章：概率论基础

### 2.1 随机变量与概率分布
#### 2.1.1 随机变量的定义
随机变量是映射到实数的函数，如股票价格的变化。

#### 2.1.2 常用概率分布模型
- 正态分布：描述资产收益。
- 均匀分布：简单模拟工具。

#### 2.1.3 概率密度函数（PDF）和累积分布函数（CDF）
数学公式：
$$ PDF = f(x) $$
$$ CDF = F(x) = P(X \leq x) $$

### 2.2 随机数生成方法
#### 2.2.1 均匀分布的随机数生成
使用箱庭法或逆变换法生成均匀分布随机数。

#### 2.2.2 其他分布的随机数生成
- 正态分布：使用Ziggurat算法。
- 指数分布：使用拒绝法。

### 2.3 蒙特卡洛积分原理
#### 2.3.1 蒙特卡洛积分的基本思想
通过随机采样估计积分值，公式：
$$ \int_{a}^{b} f(x) dx \approx \frac{1}{N} \sum_{i=1}^{N} f(x_i) $$

#### 2.3.2 蒙特卡洛积分的收敛性分析
收敛速度与维度有关，通常在低维空间表现良好。

### 5.2 核心代码实现
实现蒙特卡洛模拟代码，如模拟股票价格波动。

#### 5.2.1 核心代码示例
```python
import numpy as np
import matplotlib.pyplot as plt

def stock_price_simulation(S0, mu, sigma, T, N=1000):
    np.random.seed(42)
    dt = T / N
    prices = np.zeros(N+1)
    prices[0] = S0
    for i in range(N):
        drift = mu * dt
        diffusion = sigma * np.sqrt(dt) * np.random.standard_normal()
        prices[i+1] = prices[i] * np.exp(drift + diffusion)
    return prices

# 参数设置
S0 = 100  # 初始价格
mu = 0.05  # 期望回报率
sigma = 0.2  # 波动率
T = 1  # 时间长度
N = 1000  # 采样次数

# 运行模拟
prices = stock_price_simulation(S0, mu, sigma, T, N)
plt.plot(prices)
plt.xlabel('时间')
plt.ylabel('股价')
plt.title('股票价格蒙特卡洛模拟')
plt.show()
```
