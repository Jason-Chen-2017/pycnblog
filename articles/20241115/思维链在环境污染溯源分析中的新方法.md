#### 1.1 环境污染溯源分析概述

环境污染溯源分析是指通过科学的方法和手段，确定环境污染物的来源、扩散路径和影响范围，以便采取有效的治理措施，减轻环境污染的影响。其核心目标是找出污染物的“源头”，从而为污染治理提供科学依据。环境污染溯源分析不仅涉及到环境科学、化学、生物学等多学科的知识，还要求具备一定的数据分析、模型构建和推理能力。

#### 1.2 环境污染溯源分析的重要性

环境污染溯源分析在环境保护和治理中具有至关重要的意义。首先，通过溯源分析，可以明确污染物的来源和扩散路径，有助于制定针对性的治理方案，提高治理效果。其次，溯源分析可以为环境保护部门提供科学决策依据，例如在分配环保资源、制定环保政策时，可以基于溯源分析的结果进行合理规划。此外，溯源分析对于法律责任的追究也具有重要意义。通过确定污染物的来源，可以依法追究污染者的责任，维护社会公平正义。

#### 1.3 环境污染溯源分析的传统方法

在环境污染溯源分析领域，传统方法主要包括物理化学分析方法、模拟模型方法和统计分析技术。

1. **物理化学分析方法**
   物理化学分析方法主要通过实验室检测和现场采样，分析污染物的成分、浓度和变化规律。这种方法通常需要对大量样品进行复杂的化学分析，包括气相色谱、液相色谱、质谱等仪器分析技术。物理化学分析方法具有直观、准确的特点，但操作过程复杂，耗时较长，且对实验设备和人员技术水平要求较高。

2. **模拟模型方法**
   模拟模型方法通过构建环境流动、化学反应等模型，模拟污染物在环境中的扩散和转化过程。这种方法依赖于高精度的输入参数和计算模型，可以模拟复杂的污染过程，为污染治理提供指导。然而，模拟模型方法存在一定的不确定性，例如输入参数的误差和模型本身的简化，可能导致模拟结果与实际情况存在偏差。

3. **统计分析技术**
   统计分析技术通过分析污染数据之间的相关性、趋势和模式，揭示污染物的来源和扩散路径。常用的统计分析方法包括相关性分析、回归分析、聚类分析等。统计分析技术具有数据处理能力强、计算效率高的特点，但结果往往缺乏直观性和确定性，难以直接用于决策。

#### 1.4 传统方法的局限性

尽管传统方法在环境污染溯源分析中发挥了重要作用，但它们也存在一些局限性。首先，物理化学分析方法操作复杂，耗时较长，难以满足快速响应的需求；模拟模型方法对输入参数和计算模型依赖较大，容易受到噪声和数据缺失的影响；统计分析技术结果缺乏直观性和确定性，难以提供明确的治理方案。此外，这些方法往往只能针对单一污染物或单一污染过程进行分析，难以全面、系统地揭示污染问题的全貌。

def detect_anomalies(data, threshold=3):

    :param threshold: 3sigma阈值
    :return: 异常值索引列表

    relations = []
    for row in data:

            if key != 'timestamp':  # 假设时间戳不作为实体
                relations.append((key, value))
    return entities, relations

def create_knowledge_graph(entities, relations):
