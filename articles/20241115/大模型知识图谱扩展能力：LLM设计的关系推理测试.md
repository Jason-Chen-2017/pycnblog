### 5.3 代码实现与解析

以下是项目实现的核心代码片段：

```python
import spacy
import torch

nlp = spacy.load("en_core_web_sm")

# 伪代码，具体实现需要依赖LLM库
def infer_relationships(text, knowledge_graph):
    doc = nlp(text)
    entities = [ent.text for ent in doc.ents]
    relationships = []

    for ent in entities:
        relationships.extend(extract_relationships(ent, knowledge_graph))

    return relationships

# 伪代码，具体实现需要依赖知识图谱库
def extract_relationships(entity, knowledge_graph):
    relationships = []
    for relation in knowledge_graph.relations:
        if relation.entity == entity:
            relationships.append(relation)
    return relationships
```
