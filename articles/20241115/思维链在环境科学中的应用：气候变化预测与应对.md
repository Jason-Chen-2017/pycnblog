## 数学模型与公式

### 1. 能量平衡方程

能量平衡方程描述了地面吸收的太阳辐射与地面辐射之间的关系：

$$
Q = SW - LG
$$

其中，$Q$ 表示能量平衡，$SW$ 表示地面吸收的太阳辐射，$LG$ 表示地面辐射。

### 2. 气温变化方程

气温变化方程描述了气温随时间的变化：

$$
dT/dt = Q/Cp
$$

其中，$dT/dt$ 表示气温的变化率，$Q$ 表示能量平衡，$Cp$ 表示比热容。

### 3. 降水方程

降水方程描述了降水与气温之间的关系：

$$
P = f(T)
$$

其中，$P$ 表示降水，$T$ 表示气温，$f(T)$ 表示降水函数。

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 输入数据
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([2, 4, 5, 4, 5])

# 创建线性回归模型
model = LinearRegression()

# 训练模型
model.fit(X, y)

# 预测
predictions = model.predict(X)

# 打印预测结果
print(predictions)
```
