### 4.3 数学模型与公式

在深度学习模型中，我们通常使用神经网络来模拟人类大脑的思考方式。神经网络的核心是神经元（Neuron），神经元通过激活函数（Activation Function）将输入转化为输出。以下是神经网络中的几个关键数学模型和公式：

1. **前向传播（Forward Propagation）**

   前向传播是神经网络处理数据的过程。给定输入 \( x \)，前向传播通过神经元的加权连接来计算输出。

   \[
   z = \sum_{i} w_i x_i + b
   \]

   其中，\( w_i \) 是权重，\( x_i \) 是输入，\( b \) 是偏置。

2. **激活函数（Activation Function）**

   激活函数用于引入非线性，使得神经网络能够学习复杂函数。常用的激活函数包括 sigmoid、ReLU 和 tanh。

   \[
   \sigma(z) = \frac{1}{1 + e^{-z}}
   \]
   \[
   \text{ReLU}(z) = \max(0, z)
   \]
   \[
   \text{tanh}(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}
   \]

3. **反向传播（Back Propagation）**

   反向传播用于计算损失函数关于模型参数的梯度，以更新模型参数。

   \[
   \delta = \frac{\partial L}{\partial z}
   \]
   \[
   \frac{\partial z}{\partial w} = x
   \]
   \[
   \frac{\partial z}{\partial b} = 1
   \]

   其中，\( \delta \) 是误差梯度，\( L \) 是损失函数，\( w \) 是权重，\( b \) 是偏置。

4. **损失函数（Loss Function）**

   损失函数用于衡量模型预测值与实际值之间的差距。常用的损失函数包括均方误差（MSE）和交叉熵（Cross Entropy）。

   \[
   \text{MSE}(y, \hat{y}) = \frac{1}{2} \sum_{i} (y_i - \hat{y}_i)^2
   \]
   \[
   \text{CE}(y, \hat{y}) = -\sum_{i} y_i \log(\hat{y}_i)
   \]

### 4.4 通俗易懂的举例说明

假设我们有一个简单的神经网络，用于对二分类问题进行预测。输入是一个向量 \( x = [1, 2, 3] \)，目标是 \( y = 1 \)。

1. **前向传播**

   假设我们的神经网络有两个神经元，权重 \( w_1 = [1, 1] \)，权重 \( w_2 = [1, 0.5] \)，偏置 \( b_1 = 0 \)，偏置 \( b_2 = 1 \)。

   \[
   z_1 = w_1 \cdot x + b_1 = [1, 1] \cdot [1, 2, 3] + 0 = [1, 2, 3]
   \]
   \[
   a_1 = \sigma(z_1) = \frac{1}{1 + e^{-z_1}} = [0.54, 0.65, 0.75]
   \]
   \[
   z_2 = w_2 \cdot a_1 + b_2 = [1, 0.5] \cdot [0.54, 0.65, 0.75] + 1 = [1.29, 1.34, 1.43]
   \]
   \[
   a_2 = \sigma(z_2) = \frac{1}{1 + e^{-z_2}} = [0.36, 0.46, 0.54]
   \]

   最后的输出是 \( a_2 \) 的最大值，即 \( \hat{y} = 0.54 \)。

2. **反向传播**

   假设实际的标签 \( y = 0 \)，损失函数为交叉熵。

   \[
   L = -y \log(\hat{y}) - (1 - y) \log(1 - \hat{y}) = -1 \cdot \log(0.54) - 0 \cdot \log(0.46) = \log(1.85)
   \]

   梯度计算如下：

   \[
   \delta_a = \frac{\partial L}{\partial a_2} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a_2} = (0.54 - 0.46) \cdot (1 - 0.54) = 0.16
   \]
   \[
   \delta_z = \frac{\partial L}{\partial z_2} = \frac{\partial L}{\partial a_2} \cdot \frac{\partial a_2}{\partial z_2} = 0.16 \cdot (1 - 0.54) = 0.07
   \]
   \[
   \frac{\partial z_2}{\partial w_2} = x = [1, 2, 3]
   \]
   \[
   \frac{\partial z_2}{\partial b_2} = 1
   \]
   \[
   \frac{\partial L}{\partial w_2} = \delta_z \cdot x = 0.07 \cdot [1, 2, 3] = [0.07, 0.14, 0.21]
   \]
   \[
   \frac{\partial L}{\partial b_2} = \delta_z = 0.07
   \]

   同样的步骤可以用于计算 \( w_1 \) 和 \( b_1 \) 的梯度。

通过这个简单的例子，我们可以看到神经网络如何通过前向传播和反向传播来学习数据。在金融监管报告生成中，我们使用类似的原理来处理复杂的金融数据，并生成高质量的监管报告。# 第5章：系统分析与架构设计

from torch.optim import Adam
from torch.utils.data import DataLoader

# 模型训练
def train_model(model, train_data, test_data, num_epochs, learning_rate):
    criterion = nn.CrossEntropyLoss()
    optimizer = Adam(model.parameters(), lr=learning_rate)

    train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
    test_loader = DataLoader(test_data, batch_size=64, shuffle=False)

    for epoch in range(num_epochs):
        model.train()
        for batch in train_loader:
            optimizer.zero_grad()
            output = model(batch.text).view(-1)
            loss = criterion(output, batch.label)
            loss.backward()
            optimizer.step()

        model.eval()
        with torch.no_grad():
            correct = 0
            total = 0
            for batch in test_loader:
                output = model(batch.text).view(-1)
                _, predicted = torch.max(output, 1)
                total += batch.label.size(0)
                correct += (predicted == batch.label).sum().item()

    print(f'准确率: {100 * correct / total}%')
```

### 2.1 大模型概述

### 4.3 数学模型与公式

在深度学习模型中，我们通常使用神经网络来模拟人类大脑的思考方式。神经网络的核心是神经元（Neuron），神经元通过激活函数（Activation Function）将输入转化为输出。以下是神经网络中的几个关键数学模型和公式：

1. **前向传播（Forward Propagation）**

   前向传播是神经网络处理数据的过程。给定输入 \( x \)，前向传播通过神经元的加权连接来计算输出。

   \[
   z = \sum_{i} w_i x_i + b
   \]

   其中，\( w_i \) 是权重，\( x_i \) 是输入，\( b \) 是偏置。

2. **激活函数（Activation Function）**

   激活函数用于引入非线性，使得神经网络能够学习复杂函数。常用的激活函数包括 sigmoid、ReLU 和 tanh。

   \[
   \sigma(z) = \frac{1}{1 + e^{-z}}
   \]
   \[
   \text{ReLU}(z) = \max(0, z)
   \]
   \[
   \text{tanh}(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}
   \]

3. **反向传播（Back Propagation）**

   反向传播用于计算损失函数关于模型参数的梯度，以更新模型参数。

   \[
   \delta = \frac{\partial L}{\partial z}
   \]
   \[
   \frac{\partial z}{\partial w} = x
   \]
   \[
   \frac{\partial z}{\partial b} = 1
   \]

   其中，\( \delta \) 是误差梯度，\( L \) 是损失函数，\( w \) 是权重，\( b \) 是偏置。

4. **损失函数（Loss Function）**

   损失函数用于衡量模型预测值与实际值之间的差距。常用的损失函数包括均方误差（MSE）和交叉熵（Cross Entropy）。

   \[
   \text{MSE}(y, \hat{y}) = \frac{1}{2} \sum_{i} (y_i - \hat{y}_i)^2
   \]
   \[
   \text{CE}(y, \hat{y}) = -\sum_{i} y_i \log(\hat{y}_i)
   \]

### 4.4 通俗易懂的举例说明

假设我们有一个简单的神经网络，用于对二分类问题进行预测。输入是一个向量 \( x = [1, 2, 3] \)，目标是 \( y = 1 \)。

1. **前向传播**

   假设我们的神经网络有两个神经元，权重 \( w_1 = [1, 1] \)，权重 \( w_2 = [1, 0.5] \)，偏置 \( b_1 = 0 \)，偏置 \( b_2 = 1 \)。

   \[
   z_1 = w_1 \cdot x + b_1 = [1, 1] \cdot [1, 2, 3] + 0 = [1, 2, 3]
   \]
   \[
   a_1 = \sigma(z_1) = \frac{1}{1 + e^{-z_1}} = [0.54, 0.65, 0.75]
   \]
   \[
   z_2 = w_2 \cdot a_1 + b_2 = [1, 0.5] \cdot [0.54, 0.65, 0.75] + 1 = [1.29, 1.34, 1.43]
   \]
   \[
   a_2 = \sigma(z_2) = \frac{1}{1 + e^{-z_2}} = [0.36, 0.46, 0.54]
   \]

   最后的输出是 \( a_2 \) 的最大值，即 \( \hat{y} = 0.54 \)。

2. **反向传播**

   假设实际的标签 \( y = 0 \)，损失函数为交叉熵。

   \[
   L = -y \log(\hat{y}) - (1 - y) \log(1 - \hat{y}) = -1 \cdot \log(0.54) - 0 \cdot \log(0.46) = \log(1.85)
   \]

   梯度计算如下：

   \[
   \delta_a = \frac{\partial L}{\partial a_2} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a_2} = (0.54 - 0.46) \cdot (1 - 0.54) = 0.16
   \]
   \[
   \delta_z = \frac{\partial L}{\partial z_2} = \frac{\partial L}{\partial a_2} \cdot \frac{\partial a_2}{\partial z_2} = 0.16 \cdot (1 - 0.54) = 0.07
   \]
   \[
   \frac{\partial z_2}{\partial w_2} = x = [1, 2, 3]
   \]
   \[
   \frac{\partial z_2}{\partial b_2} = 1
   \]
   \[
   \frac{\partial L}{\partial w_2} = \delta_z \cdot x = 0.07 \cdot [1, 2, 3] = [0.07, 0.14, 0.21]
   \]
   \[
   \frac{\partial L}{\partial b_2} = \delta_z = 0.07
   \]

   同样的步骤可以用于计算 \( w_1 \) 和 \( b_1 \) 的梯度。

通过这个简单的例子，我们可以看到神经网络如何通过前向传播和反向传播来学习数据。在金融监管报告生成中，我们使用类似的原理来处理复杂的金融数据，并生成高质量的监管报告。

def train_model(model, train_data, test_data, num_epochs, learning_rate):
    criterion = nn.CrossEntropyLoss()
    optimizer = Adam(model.parameters(), lr=learning_rate)

    train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
    test_loader = DataLoader(test_data, batch_size=64, shuffle=False)

    for epoch in range(num_epochs):
        model.train()
        for batch in train_loader:
            optimizer.zero_grad()
            output = model(batch.text).view(-1)
            loss = criterion(output, batch.label)
            loss.backward()
            optimizer.step()

        model.eval()
        with torch.no_grad():
            correct = 0
            total = 0
            for batch in test_loader:
                output = model(batch.text).view(-1)
                _, predicted = torch.max(output, 1)
                total += batch.label.size(0)
                correct += (predicted == batch.label).sum().item()

### 4.3 数学模型与公式

在深度学习模型中，我们通常使用神经网络来模拟人类大脑的思考方式。神经网络的核心是神经元（Neuron），神经元通过激活函数（Activation Function）将输入转化为输出。以下是神经网络中的几个关键数学模型和公式：

1. **前向传播（Forward Propagation）**

   前向传播是神经网络处理数据的过程。给定输入 \( x \)，前向传播通过神经元的加权连接来计算输出。

   \[
   z = \sum_{i} w_i x_i + b
   \]

   其中，\( w_i \) 是权重，\( x_i \) 是输入，\( b \) 是偏置。

2. **激活函数（Activation Function）**

   激活函数用于引入非线性，使得神经网络能够学习复杂函数。常用的激活函数包括 sigmoid、ReLU 和 tanh。

   \[
   \sigma(z) = \frac{1}{1 + e^{-z}}
   \]
   \[
   \text{ReLU}(z) = \max(0, z)
   \]
   \[
   \text{tanh}(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}
   \]

3. **反向传播（Back Propagation）**

   反向传播用于计算损失函数关于模型参数的梯度，以更新模型参数。

   \[
   \delta = \frac{\partial L}{\partial z}
   \]
   \[
   \frac{\partial z}{\partial w} = x
   \]
   \[
   \frac{\partial z}{\partial b} = 1
   \]

   其中，\( \delta \) 是误差梯度，\( L \) 是损失函数，\( w \) 是权重，\( b \) 是偏置。

4. **损失函数（Loss Function）**

   损失函数用于衡量模型预测值与实际值之间的差距。常用的损失函数包括均方误差（MSE）和交叉熵（Cross Entropy）。

   \[
   \text{MSE}(y, \hat{y}) = \frac{1}{2} \sum_{i} (y_i - \hat{y}_i)^2
   \]
   \[
   \text{CE}(y, \hat{y}) = -\sum_{i} y_i \log(\hat{y}_i)
   \]

### 4.4 通俗易懂的举例说明

假设我们有一个简单的神经网络，用于对二分类问题进行预测。输入是一个向量 \( x = [1, 2, 3] \)，目标是 \( y = 1 \)。

1. **前向传播**

   假设我们的神经网络有两个神经元，权重 \( w_1 = [1, 1] \)，权重 \( w_2 = [1, 0.5] \)，偏置 \( b_1 = 0 \)，偏置 \( b_2 = 1 \)。

   \[
   z_1 = w_1 \cdot x + b_1 = [1, 1] \cdot [1, 2, 3] + 0 = [1, 2, 3]
   \]
   \[
   a_1 = \sigma(z_1) = \frac{1}{1 + e^{-z_1}} = [0.54, 0.65, 0.75]
   \]
   \[
   z_2 = w_2 \cdot a_1 + b_2 = [1, 0.5] \cdot [0.54, 0.65, 0.75] + 1 = [1.29, 1.34, 1.43]
   \]
   \[
   a_2 = \sigma(z_2) = \frac{1}{1 + e^{-z_2}} = [0.36, 0.46, 0.54]
   \]

   最后的输出是 \( a_2 \) 的最大值，即 \( \hat{y} = 0.54 \)。

2. **反向传播**

   假设实际的标签 \( y = 0 \)，损失函数为交叉熵。

   \[
   L = -y \log(\hat{y}) - (1 - y) \log(1 - \hat{y}) = -1 \cdot \log(0.54) - 0 \cdot \log(0.46) = \log(1.85)
   \]

   梯度计算如下：

   \[
   \delta_a = \frac{\partial L}{\partial a_2} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a_2} = (0.54 - 0.46) \cdot (1 - 0.54) = 0.16
   \]
   \[
   \delta_z = \frac{\partial L}{\partial z_2} = \frac{\partial L}{\partial a_2} \cdot \frac{\partial a_2}{\partial z_2} = 0.16 \cdot (1 - 0.54) = 0.07
   \]
   \[
   \frac{\partial z_2}{\partial w_2} = x = [1, 2, 3]
   \]
   \[
   \frac{\partial z_2}{\partial b_2} = 1
   \]
   \[
   \frac{\partial L}{\partial w_2} = \delta_z \cdot x = 0.07 \cdot [1, 2, 3] = [0.07, 0.14, 0.21]
   \]
   \[
   \frac{\partial L}{\partial b_2} = \delta_z = 0.07
   \]

   同样的步骤可以用于计算 \( w_1 \) 和 \( b_1 \) 的梯度。

通过这个简单的例子，我们可以看到神经网络如何通过前向传播和反向传播来学习数据。在金融监管报告生成中，我们使用类似的原理来处理复杂的金融数据，并生成高质量的监管报告。

### 4.3 数学模型与公式

在深度学习模型中，我们通常使用神经网络来模拟人类大脑的思考方式。神经网络的核心是神经元（Neuron），神经元通过激活函数（Activation Function）将输入转化为输出。以下是神经网络中的几个关键数学模型和公式：

1. **前向传播（Forward Propagation）**

   前向传播是神经网络处理数据的过程。给定输入 \( x \)，前向传播通过神经元的加权连接来计算输出。

   \[
   z = \sum_{i} w_i x_i + b
   \]

   其中，\( w_i \) 是权重，\( x_i \) 是输入，\( b \) 是偏置。

2. **激活函数（Activation Function）**

   激活函数用于引入非线性，使得神经网络能够学习复杂函数。常用的激活函数包括 sigmoid、ReLU 和 tanh。

   \[
   \sigma(z) = \frac{1}{1 + e^{-z}}
   \]
   \[
   \text{ReLU}(z) = \max(0, z)
   \]
   \[
   \text{tanh}(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}
   \]

3. **反向传播（Back Propagation）**

   反向传播用于计算损失函数关于模型参数的梯度，以更新模型参数。

   \[
   \delta = \frac{\partial L}{\partial z}
   \]
   \[
   \frac{\partial z}{\partial w} = x
   \]
   \[
   \frac{\partial z}{\partial b} = 1
   \]

   其中，\( \delta \) 是误差梯度，\( L \) 是损失函数，\( w \) 是权重，\( b \) 是偏置。

4. **损失函数（Loss Function）**

   损失函数用于衡量模型预测值与实际值之间的差距。常用的损失函数包括均方误差（MSE）和交叉熵（Cross Entropy）。

   \[
   \text{MSE}(y, \hat{y}) = \frac{1}{2} \sum_{i} (y_i - \hat{y}_i)^2
   \]
   \[
   \text{CE}(y, \hat{y}) = -\sum_{i} y_i \log(\hat{y}_i)
   \]

### 4.4 通俗易懂的举例说明

假设我们有一个简单的神经网络，用于对二分类问题进行预测。输入是一个向量 \( x = [1, 2, 3] \)，目标是 \( y = 1 \)。

1. **前向传播**

   假设我们的神经网络有两个神经元，权重 \( w_1 = [1, 1] \)，权重 \( w_2 = [1, 0.5] \)，偏置 \( b_1 = 0 \)，偏置 \( b_2 = 1 \)。

   \[
   z_1 = w_1 \cdot x + b_1 = [1, 1] \cdot [1, 2, 3] + 0 = [1, 2, 3]
   \]
   \[
   a_1 = \sigma(z_1) = \frac{1}{1 + e^{-z_1}} = [0.54, 0.65, 0.75]
   \]
   \[
   z_2 = w_2 \cdot a_1 + b_2 = [1, 0.5] \cdot [0.54, 0.65, 0.75] + 1 = [1.29, 1.34, 1.43]
   \]
   \[
   a_2 = \sigma(z_2) = \frac{1}{1 + e^{-z_2}} = [0.36, 0.46, 0.54]
   \]

   最后的输出是 \( a_2 \) 的最大值，即 \( \hat{y} = 0.54 \)。

2. **反向传播**

   假设实际的标签 \( y = 0 \)，损失函数为交叉熵。

   \[
   L = -y \log(\hat{y}) - (1 - y) \log(1 - \hat{y}) = -1 \cdot \log(0.54) - 0 \cdot \log(0.46) = \log(1.85)
   \]

   梯度计算如下：

   \[
   \delta_a = \frac{\partial L}{\partial a_2} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a_2} = (0.54 - 0.46) \cdot (1 - 0.54) = 0.16
   \]
   \[
   \delta_z = \frac{\partial L}{\partial z_2} = \frac{\partial L}{\partial a_2} \cdot \frac{\partial a_2}{\partial z_2} = 0.16 \cdot (1 - 0.54) = 0.07
   \]
   \[
   \frac{\partial z_2}{\partial w_2} = x = [1, 2, 3]
   \]
   \[
   \frac{\partial z_2}{\partial b_2} = 1
   \]
   \[
   \frac{\partial L}{\partial w_2} = \delta_z \cdot x = 0.07 \cdot [1, 2, 3] = [0.07, 0.14, 0.21]
   \]
   \[
   \frac{\partial L}{\partial b_2} = \delta_z = 0.07
   \]

   同样的步骤可以用于计算 \( w_1 \) 和 \( b_1 \) 的梯度。

通过这个简单的例子，我们可以看到神经网络如何通过前向传播和反向传播来学习数据。在金融监管报告生成中，我们使用类似的原理来处理复杂的金融数据，并生成高质量的监管报告。

import torch
import torch.nn as nn

# 模型定义
class RegulatoryReportModel(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, report_length):
        super(RegulatoryReportModel, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim)
        self.fc = nn.Linear(hidden_dim, report_length)

    def forward(self, input_seq):
        embedded = self.embedding(input_seq)
        output, (hidden, cell) = self.lstm(embedded)
        report = self.fc(hidden[-1, :, :])
        return report
```

```python
from torch.optim import Adam
from torch.utils.data import DataLoader

# 模型训练
def train_model(model, train_data, test_data, num_epochs, learning_rate):
    criterion = nn.CrossEntropyLoss()
    optimizer = Adam(model.parameters(), lr=learning_rate)

    train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
    test_loader = DataLoader(test_data, batch_size=64, shuffle=False)

    for epoch in range(num_epochs):
        model.train()
        for batch in train_loader:
            optimizer.zero_grad()
            output = model(batch.text).view(-1)
            loss = criterion(output, batch.label)
            loss.backward()
            optimizer.step()

        model.eval()
        with torch.no_grad():
            correct = 0
            total = 0
            for batch in test_loader:
                output = model(batch.text).view(-1)
                _, predicted = torch.max(output, 1)
                total += batch.label.size(0)
                correct += (predicted == batch.label).sum().item()

    print(f'准确率: {100 * correct / total}%')
```
