### 2.2 法律文本分类算法

法律文本分类是将法律文本按照其内容分类到预定义的类别中，如合同、判决书、法律意见书等。分类算法是AI Agent在法律文本分析中的重要组成部分。

#### 2.2.1 分类算法概述

1. **朴素贝叶斯分类器**：基于贝叶斯定理，通过计算文本特征的概率分布，预测文本的类别。

2. **支持向量机（SVM）**：通过寻找最优超平面，将不同类别的文本分隔开。

3. **随机森林**：通过构建多棵决策树，并汇总投票结果进行分类。

4. **深度学习分类器**：如卷积神经网络（CNN）和循环神经网络（RNN），通过神经网络结构学习文本特征。

#### 2.2.2 词袋模型

1. **算法原理**：将文本转换为向量表示，其中每个维度对应一个词汇，向量中1表示词汇出现在文本中，0表示未出现。

2. **Python代码实现**：

```python
from sklearn.feature_extraction.text import CountVectorizer

# 示例文本
corpus = [
    "这是一份合同文本。",
    "这是一份判决书文本。",
    "这是一份法律意见书文本。"
]

# 创建词袋模型
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(corpus)

print(X.toarray())
```

#### 2.2.3 主题模型

1. **算法原理**：通过降维技术，将高维的词袋模型转换为一个低维的潜在主题空间，每个主题表示一组词汇。

2. **LDA模型实现**：

```python
from sklearn.decomposition import LatentDirichletAllocation

# 训练词袋模型
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(corpus)

# 创建LDA模型
lda = LatentDirichletAllocation(n_components=3, random_state=0)
lda.fit(X)

# 输出主题词
print(lda.components_)
```
