#### 代码高亮

以下是一个Python代码示例，以及如何在Markdown中使用`pygments`插件进行代码高亮：

```python
# Python 代码示例

def recommend_products(user_profile, products):
    # 伪代码：为用户推荐产品
    recommended_items = []
    for product in products:
        if is_relevant(user_profile, product):
            recommended_items.append(product)
    return recommended_items

def is_relevant(user_profile, product):
    # 判断产品是否与用户偏好相关
    return len(set(user_profile) & set(product['tags'])) > 0

# 示例数据
user_profile = ["electronics", "books", "tech"]
products = [
    {"name": "Smartphone", "tags": ["electronics", "mobile"]},
    {"name": "Novel", "tags": ["books", "fiction"]},
    {"name": "Laptop", "tags": ["electronics", "computer"]},
]

# 调用推荐函数
recommended_products = recommend_products(user_profile, products)
print(recommended_products)
```

在Markdown中，为了使代码段高亮显示，可以使用`highlight.py`脚本和`pygments`库。以下是如何进行代码高亮的步骤：

1. 安装`pygments`库：
   ```bash
   pip install pygments
   ```

2. 使用`highlight.py`进行代码高亮：
   ```bash
   python -m pygments.cmd.pygment -l python -o example_code.html example_code.py
   ```

3. 在Markdown中引用高亮后的代码文件：
   ```markdown
   ```python
   @import "example_code.html"
   ```

这样，Markdown文件中就会嵌入高亮显示的代码。
