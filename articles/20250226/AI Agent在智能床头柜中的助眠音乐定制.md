### 2.1 AI Agent的基本概念
AI Agent是一种智能代理，能够感知环境、理解用户需求，并根据需求做出决策和行动。在助眠音乐定制中，AI Agent主要负责接收用户输入、分析数据、推荐音乐。

## 第3章：基于AI Agent的音乐推荐算法

### 3.1 协同过滤算法
协同过滤是一种基于用户相似性的推荐算法。通过分析用户的听音乐历史，找到与目标用户相似的用户，推荐他们喜欢的音乐。

#### 3.1.1 协同过滤的实现步骤
1. **构建用户-音乐矩阵**：记录用户对音乐的评分。
2. **计算相似度**：使用余弦相似度计算用户之间的相似度。
3. **生成推荐列表**：根据相似用户的评分，生成推荐列表。

#### 3.1.2 协同过滤的代码实现
```python
import numpy as np

# 用户-音乐矩阵
user_music_matrix = np.array([
    [5, 3, 0, 1],
    [4, 0, 2, 1],
    [3, 4, 5, 0],
    [2, 3, 1, 5]
])

# 计算余弦相似度
def cosine_similarity(matrix):
    norm = np.linalg.norm(matrix, axis=1).reshape(-1, 1)
    normalized_matrix = matrix / norm
    similarity = np.dot(normalized_matrix, normalized_matrix.T)
    return similarity

similarity_matrix = cosine_similarity(user_music_matrix)
print(similarity_matrix)
```
