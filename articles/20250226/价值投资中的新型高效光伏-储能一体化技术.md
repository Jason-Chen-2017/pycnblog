## 第2章: 光伏-储能一体化技术的核心概念与联系

### 2.1 光伏技术的核心原理

#### 2.1.1 太阳能的转换原理
- **光生伏特效应**：半导体材料在光照下产生电动势的现象，是光伏技术的核心原理。  
- **能量转换流程**：  
  1. 太阳光照射到光伏电池，产生电子-空穴对。  
  2. 外部电路将电子和空穴分开，形成电流。  
  3. 电流通过负载做功。  

#### 2.1.2 光伏电池的工作原理
- **光伏电池结构**：包括扩散层、耗尽层、欧姆接触层等。  
- **光电转换效率**：影响因素包括材料特性、光照条件、温度等。  

#### 2.1.3 光伏系统的组成部分
- **组件**：光伏电池组件、逆变器、支架等。  
- **系统功能**：将太阳能转化为电能，并接入电网或直接使用。

## 第3章: 光伏-储能一体化技术的算法原理

### 3.1 最大功率点跟踪算法（MPPT）

#### 3.1.1 算法原理
- **目标**：在变化的光照条件下，找到光伏系统的最大功率点。  
- **方法**：通过调整光伏系统的运行参数，使其输出功率最大化。  

#### 3.1.2 算法实现
```python
def mppt_algorithm(voltage, current, irradiance):
    # 根据光照强度调整电压
    if irradiance > 1000:  # 高光照强度
        voltage = voltage + 5
    elif irradiance < 500:  # 低光照强度
        voltage = voltage - 2
    # 计算功率
    power = voltage * current
    return power
```

#### 3.1.3 优化策略
- **扰动观察法**：通过小幅度扰动电压，观察功率变化，找到最大值。  
- **爬山法**：逐步调整电压，直到功率不再增加。

def main():
    import serial
    import time

    ser = serial.Serial('COM1', 9600)

        data = ser.readline().decode('utf-8')
        voltage = float(data.split(',')[0])
        current = float(data.split(',')[1])
        print(f"电压: {voltage}, 电流: {current}")

if __name__ == "__main__":
