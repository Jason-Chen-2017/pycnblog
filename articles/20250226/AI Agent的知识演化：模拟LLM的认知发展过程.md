### 第4章: 知识演化与LLM的数学模型

#### 4.1 知识表示的数学模型
- **4.1.1 符号逻辑模型**
  - 命题逻辑公式：
    $$P \land Q \rightarrow R$$
  - 一阶逻辑公式：
    $$\forall x (P(x) \rightarrow Q(x))$$

- **4.1.2 概率图模型**
  - 贝叶斯网络：
    $$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$
  - 马尔可夫链：
    $$P(A|B) = P(A|B, C) \cdot P(C)$$

- **4.1.3 知识图谱的向量表示**
  - 词嵌入：如Word2Vec的训练目标：
    $$\text{minimize} \sum (\text{context}_i - \text{target}_i)^2$$
  - 图嵌入：如GraphSAGE的聚合操作：
    $$h_i = \sigma(A h_i + b)$$

#### 4.2 LLM的认知模型
- **4.2.1 变量与函数定义**
  - 输入变量：$x = (x_1, x_2, ..., x_n)$
  - 输出变量：$y = (y_1, y_2, ..., y_m)$
  - 概率分布：$P(y|x)$

- **4.2.2 注意力机制的数学公式**
  - 查询（Q）、键（K）、值（V）的线性变换：
    $$Q = W_q x, K = W_k x, V = W_v x$$
  - 注意力权重计算：
    $$\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)$$
  - 加权求和：
    $$\text{Attention}(Q, K, V) = \text{softmax}(QK^T)V$$

- **4.2.3 损失函数与优化算法**
  - 交叉熵损失：
    $$\mathcal{L} = -\sum_{i=1}^n y_i \log p_i$$
  - 优化算法：如Adam优化器：
    $$\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}$$
