## 第1章：数字艺术品的定义与特性

### 1.1 数字艺术品的定义与特性

数字艺术品是指以数字形式存在的艺术作品，包括数字绘画、数字音乐、数字视频、数字雕塑等。数字艺术品的核心特性如下：

- **虚拟性**：数字艺术品仅以数字形式存在，没有实体形态。
- **可复制性**：数字艺术品可以被无限复制和传播，这导致其版权和真伪难以验证。
- **版权归属复杂性**：数字艺术品的版权归属容易被篡改或丢失。

### 1.2 区块链技术的基本概念

区块链是一种去中心化的分布式账本技术，具有以下核心特性：

- **去中心化**：区块链不依赖于中心化机构，数据通过分布式节点网络进行存储和验证。
- **不可篡改性**：区块链上的数据一旦写入，无法被修改或删除。
- **透明性**：区块链上的交易记录公开透明，所有参与者都可以查看。

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract DigitalArtwork {
    struct Artwork {
        string metadata;
        address payable owner;
        uint256 timestamp;
    }

    mapping(uint256 => Artwork) private artworks;

    function registerArtwork(uint256 tokenId, string memory metadata) public {
        require(tokenId > 0, "Token ID must be greater than 0");
        require(!isTokenExists(tokenId), "Token already exists");

        Artwork memory artwork = Artwork({
            metadata: metadata,
            owner: payable(msg.sender),
            timestamp: block.timestamp
        });

        artworks[tokenId] = artwork;
    }

    function getArtwork(uint256 tokenId) public view returns (string memory, address payable, uint256) {
        Artwork memory artwork = artworks[tokenId];
        return (artwork.metadata, artwork.owner, artwork.timestamp);
    }

    function isTokenExists(uint256 tokenId) private view returns (bool) {
        return artworks[tokenId].metadata != "";
    }
}
```
