## 第一部分：主动学习背景与概念

### 第1章：主动学习的基本概念

#### 1.1 什么是主动学习
- **定义**：主动学习是一种机器学习方法，模型主动选择对学习最有帮助的样本。
- **与被动学习的区别**：被动学习随机抽取样本，主动学习基于策略选择最优样本。
- **核心思想**：通过高效样本选择提升模型性能。

#### 1.2 问题背景与挑战
- **数据获取的局限性**：标注数据昂贵，主动选择可降低成本。
- **学习效率的提升需求**：有限数据下最大化性能提升。
- **现有方法的不足**：被动学习效率低，主动学习策略需优化。

### 第2章：主动学习的核心概念

#### 2.1 核心概念解析
- **样本选择策略**：不确定性抽样、查询学习等。
- **查询策略**：模型指导样本选择。
- **知识蒸馏**：利用教师模型指导学生模型。

## 第二部分：主动学习的算法原理

### 第3章：主动学习的算法流程

#### 3.1 算法流程概述
- **初始数据集**：少量标记数据+大量未标记数据。
- **样本选择策略**：选择最有帮助的样本。
- **模型迭代优化**：更新模型并重复选择。

#### 3.2 核心算法实现
- **不确定性抽样**：选择预测概率最低的样本。
- **查询学习**：询问领域专家意见。
- **增量式学习**：逐步学习避免遗忘。

### 第4章：主动学习的数学模型

#### 4.1 样本选择的数学表达
- **概率分布模型**：样本选择基于概率分布。
- **信息增益计算公式**：$$ I(y|x) = H(y) - H(y|x) $$
- **熵值计算方法**：$$ H(y|x) = -\sum p(y|x)\log p(y|x) $$

#### 4.2 模型优化的数学推导
- **梯度下降法**：$$ \theta = \theta - \eta \nabla L(\theta) $$
- **贝叶斯优化方法**：$$ p(\theta|D) = \frac{p(D|\theta)p(\theta)}{p(D)} $$

#### 6.2 核心代码实现
```python
import numpy as np
from sklearn.metrics import entropy

def select_samples(X, model):
    predictions = model.predict(X)
    uncertainties = np.apply_along_axis(entropy, 1, predictions)
    return np.argsort(-uncertainties)[:10]
```

#### 6.3 代码解读
- 计算预测概率的熵值，选择熵值最高的10个样本。
