## 第三部分：算法原理

### 第3章：基于机器学习的信用卡额度优化算法

#### 3.1 算法原理

- **机器学习模型选择**  
  使用线性回归模型预测信用额度。  
  $$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n $$  
  其中，$y$ 是预测的信用额度，$x_i$ 是特征变量。

- **特征选择与工程**  
  选择关键特征：收入、信用评分、消费习惯、还款记录等。

- **模型训练与优化**  
  使用梯度下降法优化模型参数，最小化预测误差。  
  $$ \text{损失函数} = \sum_{i=1}^{n}(y_i - \hat{y_i})^2 $$

#### 3.2 算法实现

- **Python代码实现**  
  ```python
  import numpy as np
  from sklearn.linear_model import LinearRegression

  # 数据预处理
  X = np.array([[50000, 750], [60000, 800], [45000, 600]])  # 收入、信用评分
  y = np.array([5000, 6000, 4000])  # 目标额度

  # 模型训练
  model = LinearRegression()
  model.fit(X, y)

  # 预测
  new_X = np.array([[55000, 700]])
  predicted_y = model.predict(new_X)
  print(predicted_y)  # 输出预测额度
  ```

- **模型解释**  
  线性回归模型根据输入特征预测信用额度，银行可以根据预测结果动态调整客户的信用额度。
