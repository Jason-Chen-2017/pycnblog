## 第三章: 算法原理讲解

### 5.1 遗传算法

#### 5.1.1 遗传算法的原理
遗传算法模拟自然选择的过程，通过变异、交叉和选择操作，逐步优化解。

#### 5.1.2 遗传算法的实现步骤
1. 初始化种群。
2. 计算适应度。
3. 选择父代。
4. 交叉和变异。
5. 生成新种群。
6. 重复直到收敛。

#### 5.1.3 遗传算法的优缺点
优点：全局搜索能力强。缺点：收敛速度慢，参数设置敏感。

### 5.2 模拟退火算法

#### 5.2.1 模拟退火算法的原理
模拟退火算法通过模拟金属退火的过程，逐步降低温度，找到全局最优解。

#### 5.2.2 模拟退火算法的实现步骤
1. 初始化当前解。
2. 计算目标函数。
3. 随机选择下一个解。
4. 根据温度接受或拒绝解。
5. 降温。
6. 重复直到收敛。

#### 5.2.3 模拟退火算法的优缺点
优点：可以跳出局部最优。缺点：计算复杂度高。

### 5.2 系统核心实现源代码

#### 5.2.1 遗传算法实现
```python
import random

def fitness(x):
    return -x**2 + 4*x

def mutate(x):
    return x + random.gauss(0, 1)

def crossover(x, y):
    return (x + y)/2

def genetic_algorithm(pop_size, iters):
    population = [random.uniform(0,4) for _ in range(pop_size)]
    best = min(population, key=fitness)
    for _ in range(iters):
        new_population = []
        for _ in range(pop_size):
            parent1 = random.choice(population)
            parent2 = random.choice(population)
            child = crossover(parent1, parent2)
            child = mutate(child)
            new_population.append(child)
        population = new_population
        best = min(population, key=fitness)
    return best

print(genetic_algorithm(10, 10))
```
