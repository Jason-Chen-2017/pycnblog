## 2.1 核心概念原理

### 2.1.1 债券久期的计算方法
债券久期的计算公式为：
$$ D = \frac{1}{(1 + r)} \sum_{t=1}^{n} \frac{C}{(1 + r)^t} + \frac{F}{(1 + r)^n} $$
其中，D为久期，r为市场利率，C为每年的利息，F为面值，n为债券期限。

### 2.1.2 智能投资系统的算法原理

## 3.3 算法实现代码

```python
import numpy as np
import pandas as pd
from sklearn import svm

# 数据预处理
data = pd.read_csv('bond_data.csv')
X = data[['interest_rate', 'bond_price']]
y = data['duration']

# 模型训练
model = svm.SVR()
model.fit(X, y)

# 模型预测
new_data = np.array([[2.5, 100]])
predicted_duration = model.predict(new_data)
print(predicted_duration)
```
