# 第二部分: 股票组合优化的核心概念与原理

## 第2章: 现代投资组合理论与AI算法的结合

### 2.1 现代投资组合理论（MPT）基础  
MPT的核心目标是通过资产配置来优化投资组合的收益与风险比。其数学模型通常以均值-方差模型为基础，目标函数为：  
$$ \min \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} $$  
其中，$w_i$为资产$i$的权重，$\sigma_{ij}$为资产$i$和$j$之间的协方差。

### 2.2 AI算法在股票组合优化中的应用  
AI算法的引入弥补了传统MPT的不足，尤其是其在处理非线性关系和大数据分析方面的能力。常见的AI算法包括遗传算法、神经网络和强化学习等。  

| 算法类型 | 核心特点 | 适用场景 |
|----------|----------|----------|
| 遗传算法 | 全局搜索能力强 | 复杂约束优化 |
| 神经网络 | 数据驱动，非线性拟合 | 复杂市场行为预测 |
| 强化学习 | 动态环境适应性高 | 实时交易策略优化 |

## 第3章: 基于遗传算法的股票组合优化

### 3.1 遗传算法的基本原理  
遗传算法是一种模拟生物进化过程的优化算法，主要包括以下步骤：  
1. 初始化种群：随机生成一组初始解（权重分配）。  
2. 适应度评估：计算每个解的目标函数值（收益与风险比）。  
3. 选择：筛选适应度高的解进行繁殖。  
4. 交叉与变异：生成新的解并引入随机变异。  
5. 重复迭代：直到满足终止条件。

### 3.2 遗传算法的实现  
以下是一个遗传算法的Python实现示例：

通过遗传算法优化的投资组合通常具有以下特点：

```python
import numpy as np

def calculate_variance(weights, returns):
    return np.dot(weights.T, np.dot(returns, weights))

def genetic_algorithm(returns, population_size=100, generations=100):
    n = returns.shape[1]
    for _ in range(generations):
        population = np.random.random((population_size, n))
        population = population / np.sum(population, axis=1)[:, None]
        variances = [calculate_variance(weights, returns) for weights in population]
        min_variance = min(variances)
        best_weights = population[np.argmin(variances)]
        # 变异操作
        mutation_rate = 0.1
        for i in range(population_size):
            if np.random.random() < mutation_rate:
                population[i] += np.random.normal(0, 0.1, n)
        population = population / np.sum(population, axis=1)[:, None]
    return best_weights
```
