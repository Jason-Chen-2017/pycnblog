#### 3.3.1 GCN的数学模型

$$
h^{(l+1)}_i = \sum_{j \in N(i)} \frac{1}{d_j} h^{(l)}_j
$$

#### 3.3.2 GAT的数学模型

$$
\alpha_{ij} = \frac{e^{f_{\theta}(h_i, h_j)}}{\sum_{k \in N(i)} e^{f_{\theta}(h_i, h_k)}}
$$

### 3.4 图神经网络的实现代码

提供Python代码实现GCN和GAT算法。

#### 3.4.1 GCN的Python实现

```python
import torch
from torch import nn
import torch.nn.functional as F

class GCN(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GCN, self).__init__()
        self.W1 = nn.Parameter(torch.randn(input_dim, hidden_dim))
        self.W2 = nn.Parameter(torch.randn(hidden_dim, output_dim))

    def forward(self, x, A):
        x = torch.bmm(x.unsqueeze(0), A.unsqueeze(0))
        x = x.squeeze(0)
        x = F.relu(torch.mm(x, self.W1))
        x = torch.mm(x, self.W2)
        return x
```

#### 3.4.2 GAT的Python实现

```python
class GAT(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GAT, self).__init__()
        self.W = nn.Parameter(torch.randn(input_dim, hidden_dim))
        self.att = nn.Parameter(torch.randn(hidden_dim, hidden_dim))

    def forward(self, x, A):
        x = x @ self.W
        att = F.softmax((x @ self.att.T), dim=1)
        x = (x.unsqueeze(1) * att.unsqueeze(0)).sum(dim=2)
        return x
```
