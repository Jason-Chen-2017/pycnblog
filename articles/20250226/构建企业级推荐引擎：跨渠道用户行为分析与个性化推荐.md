### 3.4 数学公式与算法实现
- 协同过滤的数学模型：
  $$\text{相似度} = \frac{\sum_{i=1}^{n} (r_{ui} - \bar{r_u})(r_{vi} - \bar{r_v})}{\sqrt{\sum_{i=1}^{n} (r_{ui} - \bar{r_u})^2} \cdot \sqrt{\sum_{i=1}^{n} (r_{vi} - \bar{r_v})^2}}$$
- 基于内容的推荐模型：
  $$\text{相似度} = \frac{\sum_{i=1}^{m} w_i \cdot f_i(x_i, y_i)}{\sum_{i=1}^{m} w_i}$$

```python
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

def train_model(data_matrix):
    # 计算相似度矩阵
    similarity_matrix = cosine_similarity(data_matrix)
    return similarity_matrix

def make_recommendation(user_id, similarity_matrix, data_matrix):
    # 获取用户相似度最高的用户的商品偏好
    user_similarities = similarity_matrix[user_id]
    # 找到相似度最高的用户
    similar_user = np.argmax(user_similarities)
    # 返回该用户的推荐列表
    return data_matrix[similar_user]
```
