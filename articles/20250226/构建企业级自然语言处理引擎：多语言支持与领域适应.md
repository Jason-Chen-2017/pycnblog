## 第三部分: 算法原理与数学模型

### 第4章: 词嵌入算法原理

#### 4.1 Word2Vec算法原理
- **CBOW模型**：通过上下文预测词。
- **Skip-Gram模型**：通过词预测上下文。
- **训练目标**：最小化预测误差，优化词向量。

#### 4.2 Word2Vec的实现
```python
import numpy as np

class Word2Vec:
    def __init__(self, vocab_size, embedding_dim):
        self.W = np.random.randn(vocab_size, embedding_dim)
        self.b = np.zeros(embedding_dim)
    
    def forward(self, input_idx):
        return self.W[input_idx] + self.b
    
    def backward(self, dE, input_idx):
        dE = dE.reshape(-1, 1)
        self.W[input_idx] -= dE
```

#### 4.3 词嵌入的数学模型
$$ E(w_i) = W_{i} $$  
其中，$W_{i}$ 是词 $w_i$ 的词向量。

### 第5章: 序列模型与语言模型

#### 5.1 循环神经网络（RNN）原理
- **RNN结构**：通过循环处理序列数据，维护隐藏状态。
- **训练目标**：最小化预测错误，优化权重参数。

#### 5.2 Transformer模型原理
- **自注意力机制**：计算词与词之间的相关性，生成注意力权重。
- **多头注意力**：通过多个子空间的注意力，提升模型表达能力。

#### 5.3 Transformer的数学模型
$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$
