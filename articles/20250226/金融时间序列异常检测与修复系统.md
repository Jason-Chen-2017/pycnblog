# 第2章：金融时间序列数据的特性

## 2.1 时间序列数据的特点
时间序列数据具有以下特点：
1. **有序性**：数据按时间顺序排列。
2. **趋势性**：数据可能呈现上升或下降的趋势。
3. **周期性**：数据可能受到季节性或周期性因素的影响。
4. **随机性**：数据中可能包含随机噪声。

## 2.2 金融时间序列的应用场景
- 股票价格预测
- 交易量分析
- 市场风险评估
- 欺诈检测

## 2.3 异常检测的定义与分类
### 2.3.1 基于统计的异常检测
使用统计方法（如Z-score、标准差）检测偏离均值的异常值。

### 2.3.2 基于机器学习的异常检测
利用监督或无监督学习算法（如随机森林、神经网络）识别异常模式。

### 2.3.3 基于深度学习的异常检测
使用循环神经网络（RNN）、长短期记忆网络（LSTM）等深度学习模型捕捉复杂的时间序列模式。

## 2.4 修复系统的目标
修复系统的目标包括：
1. 自动识别异常数据。
2. 提供修复建议或自动修复策略。
3. 保持数据的连续性和完整性。

## 2.5 系统的边界与外延
系统边界包括数据输入、异常检测和修复建议生成。外延部分涉及数据存储、用户界面和修复后的数据验证。

# 第3章：时间序列分析的数学模型

## 3.1 自回归模型（ARIMA）
ARIMA模型适用于非平稳时间序列数据的预测。模型由以下三个参数组成：
- **p**：自回归阶数
- **d**：差分阶数
- **q**：移动平均阶数

### 3.1.1 ARIMA模型的数学公式
$$ ARIMA(p, d, q) = y_t - \phi_1 y_{t-1} - \phi_2 y_{t-2} - \dots - \phi_p y_{t-p} = \theta_1 \epsilon_{t-1} + \theta_2 \epsilon_{t-2} + \dots + \theta_q \epsilon_{t-q} + \epsilon_t $$

### 3.1.2 ARIMA模型的优缺点
- **优点**：适合处理具有趋势和季节性的数据。
- **缺点**：对异常值敏感，需要先进行数据预处理。

## 3.2 广义自回归条件异方差模型（GARCH）
GARCH模型用于估计时间序列的波动性，特别适用于金融时间序列的 volatility 建模。

### 3.2.1 GARCH模型的数学公式
$$ GARCH(p, q)： ARCH_p(\epsilon_t) = \alpha_0 + \alpha_1 \epsilon_{t-1}^2 + \dots + \alpha_p \epsilon_{t-p}^2 $$

### 3.2.2 GARCH模型的应用场景
- 金融市场的波动性分析
- 风险管理

### 3.2.3 GARCH模型的优缺点
- **优点**：能够捕捉到金融时间序列中的波动性。
- **缺点**：模型参数较多，计算复杂。

## 3.3 时间序列分解模型
时间序列分解模型将数据分解为趋势、季节性和随机性三部分。

### 3.3.1 加性模型（Additive Model）
$$ Y_t = T_t + S_t + R_t $$

### 3.3.2 乘性模型（Multiplicative Model）
$$ Y_t = T_t \times S_t \times R_t $$

# 第4章：异常检测的核心原理

## 4.1 基于统计的方法
### 4.1.1 Z-score方法
$$ Z = \frac{x - \mu}{\sigma} $$
其中，$\mu$ 是均值，$\sigma$ 是标准差。

### 4.1.2 标准差法
将数据点与均值的偏差与标准差进行比较，判断是否为异常值。

### 4.1.3 Grubbs检验
Grubbs检验用于检测单个异常值，适用于小样本数据。

## 4.2 基于机器学习的方法
### 4.2.1 基于聚类的异常检测
使用K-means或DBSCAN算法将数据点聚类，检测远离主要簇的异常点。

### 4.2.2 基于分类的异常检测
使用监督学习算法（如SVM、随机森林）对正常和异常样本进行分类。

### 4.2.3 基于深度学习的异常检测
使用循环神经网络（RNN）或变体（如LSTM）捕捉时间序列中的复杂模式。

## 4.3 基于时间序列的异常检测算法对比
### 4.3.1 各种算法的优缺点对比
| 算法类型 | 优点 | 缺点 |
|----------|------|------|
| 基于统计 | 简单易实现 | 对复杂模式敏感度低 |
| 基于聚类 | 发现数据分布中的自然群集 | 计算复杂度高 |
| 基于分类 | 高准确性 | 需要大量标注数据 |
| 基于深度学习 | 捕捉复杂模式 | 训练时间长 |

### 4.3.2 适用场景分析
- 基于统计方法适用于简单的时间序列数据。
- 基于聚类方法适用于发现未知的异常模式。
- 基于深度学习方法适用于复杂且非线性的金融时间序列。

### 4.3.3 算法选择的建议
根据数据特征和应用场景选择合适的算法。例如，对于高维金融数据，可以结合统计方法和深度学习方法进行联合检测。

import requests

def get_data(ticker, start_date, end_date):
    url = f"https://query1.finance.yahoo.com/ws"
    params = {
        "period1": start_date,
        "period2": end_date,
        "interval": "1d",
        "symbol": ticker
    }
    response = requests.get(url, params=params)
    data = response.json()
    df = pd.DataFrame(data['chart']['result'][0]['prices'])
    df['Date'] = pd.to_datetime(df[0])
    df = df.set_index('Date')
