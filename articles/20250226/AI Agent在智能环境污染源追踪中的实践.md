# 第2章 AI Agent的核心技术

## 2.1 AI Agent的感知能力

### 2.1.1 数据采集与处理技术
AI Agent的感知能力主要依赖于数据采集与处理技术。通过传感器网络实时采集环境数据，并进行预处理，消除噪声，提取有用信息。

#### 代码示例
```python
import numpy as np

# 采集传感器数据
def collect_data(sensor_ids):
    data = []
    for id in sensor_ids:
        # 模拟传感器数据
        sensor_data = np.random.normal(0, 1, 100)
        data.append(sensor_data)
    return data

# 数据预处理
def preprocess_data(data):
    processed_data = []
    for d in data:
        # 去除异常值
        filtered = d[np.abs(d - np.mean(d)) < 2*np.std(d)]
        processed_data.append(filtered)
    return processed_data
```

### 2.1.2 多源数据融合技术
多源数据融合技术是指将来自不同传感器或数据源的数据进行融合，以提高感知精度。常用的方法包括加权融合和特征融合。

# 模拟污染扩散过程
def simulate_diffusion(x0, t_steps):
    x = np.linspace(0, 10, 100)
    c = np.zeros(len(x))
    c[x == x0] = 1
    for t in range(t_steps):
        c_new = np.zeros(len(x))
        for i in range(len(x)):
            c_new[i] = 0.5 * (c[i-1] + c[i+1])

    return c
