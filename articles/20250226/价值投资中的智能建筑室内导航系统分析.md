## 第3章: 智能建筑室内导航系统的算法原理

### 3.1 路径规划算法
- **3.1.1 Dijkstra算法**
  - 算法原理：通过优先队列选择距离最近的节点，逐步扩展到目标节点。
  - mermaid流程图：
  ```mermaid
  graph TD
    A[起点] --> B[节点1]
    B --> C[节点2]
    C --> D[终点]
  ```
  - Python代码实现：
  ```python
  import heapq

  def dijkstra(graph, start, end):
      distances = {node: float('infinity') for node in graph}
      distances[start] = 0
      visited = set()
      heap = [(0, start)]
      
      while heap:
          current_dist, current_node = heapq.heappop(heap)
          if current_node in visited:
              continue
          visited.add(current_node)
          if current_node == end:
              break
          for neighbor, weight in graph[current_node].items():
              if distances[neighbor] > current_dist + weight:
                  distances[neighbor] = current_dist + weight
                  heapq.heappush(heap, (distances[neighbor], neighbor))
      return distances[end]
  ```
  - 数学公式：
  $$ \text{distance}(u, v) = \text{min}( \text{distance}(u, k) + \text{distance}(k, v) ) $$

- **3.1.2 A*算法**
  - 算法原理：在Dijkstra算法的基础上，加入启发式函数，优先探索最有希望的节点。
  - mermaid流程图：
  ```mermaid
  graph TD
    A[起点] --> B[节点1]
    B --> C[节点2]
    C --> D[终点]
  ```
  - Python代码实现：
  ```python
  import heapq

  def a_star(graph, start, end, heuristic):
      distances = {node: float('infinity') for node in graph}
      distances[start] = 0
      visited = set()
      heap = [(0, start)]
      
      while heap:
          current_cost, current_node = heapq.heappop(heap)
          if current_node == end:
              break
          if current_node in visited:
              continue
          visited.add(current_node)
          for neighbor, weight in graph[current_node].items():
              new_cost = current_cost + weight
              if new_cost < distances[neighbor]:
                  distances[neighbor] = new_cost
                  heapq.heappush(heap, (new_cost + heuristic(neighbor, end), neighbor))
      return distances[end]
  ```
  - 数学公式：
  $$ f(n) = g(n) + h(n) $$

### 3.2 数据处理算法
- **3.2.1 传感器数据融合算法**
  - 算法原理：结合多种传感器数据，提高定位精度。
  - mermaid流程图：
  ```mermaid
  graph TD
    A[传感器数据] --> B[数据融合] --> C[定位结果]
  ```
  - Python代码实现：
  ```python
  def fuse_data(sensor1, sensor2):
      # 假设传感器1和传感器2的数据分别为0-100的数值
      return (sensor1 + sensor2) / 2
  ```
- **3.2.2 数据清洗算法**
  - 算法原理：去除异常值，确保数据质量。
  - Python代码实现：
  ```python
  def clean_data(data):
      # 假设data为一个数据列表
      cleaned = []
      for d in data:
          if d > 0:
              cleaned.append(d)
      return cleaned
  ```
