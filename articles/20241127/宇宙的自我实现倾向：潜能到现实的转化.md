```python
import numpy as np

# 设定宇宙的初始半径为10个光年，膨胀速率为1光年/年
```

其中，$v$ 是宇宙膨胀速率，$H_0$ 是哈勃常数，$D$ 是宇宙的尺度。

$$

### 源代码实现

接下来，我们编写一个Python脚本，用于模拟宇宙的膨胀过程。以下是示例代码：

```python
import numpy as np
import matplotlib.pyplot as plt

# 设定宇宙的初始半径为10个光年，膨胀速率为1光年/年
initial_radius = 10
expansion_rate = 1

# 模拟宇宙膨胀100年
years = 100
radii = [initial_radius]

for year in range(1, years + 1):
    radii.append(radii[-1] + expansion_rate)

# 绘制宇宙膨胀过程
plt.plot(np.arange(years + 1), radii, marker='o')
plt.xlabel('Years')
plt.ylabel('Universe Radius (light years)')
plt.title('Universe Expansion Simulation')
plt.grid(True)
plt.show()
```

这段代码首先导入了NumPy和Matplotlib库。然后，设定了宇宙的初始半径和膨胀速率。接下来，使用一个简单的循环来模拟宇宙的膨胀过程，并将每一年宇宙的半径存储在一个列表中。最后，使用Matplotlib绘制了宇宙膨胀过程的图表。
