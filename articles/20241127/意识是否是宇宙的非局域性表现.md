**量子纠缠（Quantum Entanglement）**

量子纠缠是量子力学中的一种非局域性现象，描述了两个或多个量子系统之间的一种特殊关联。当两个量子系统发生纠缠后，它们的状态将不可分割地相互关联，即使它们相隔很远。这种关联可以通过量子态的联合概率分布来描述。

**数学公式：**

$$|\psi\rangle = \frac{1}{\sqrt{2}} (|01\rangle + |10\rangle)$$

其中，$|01\rangle$和$|10\rangle$分别表示两个量子系统处于不同状态的基础态。

**Python源代码：**

```python
import numpy as np

# 定义量子态向量
state_01 = np.array([[1], [0]])
state_10 = np.array([[0], [1]])

# 创建纠缠态
entangled_state = 1 / np.sqrt(2) * (state_01 + state_10)

# 打印纠缠态
print("纠缠态：", entangled_state)
```

在上述代码中，我们首先导入了numpy库来处理数学运算。然后，我们定义了两个量子态向量$|01\rangle$和$|10\rangle$，并创建了一个纠缠态。最后，我们打印出了纠缠态的结果。

在这个代码中，我们首先创建了一个量子电路，然后使用H门创建一个量子纠缠态。接着，我们使用状态向量模拟器（Statevector Simulator）来执行电路，并打印出量子纠缠态的结果。最后，我们对量子纠缠态进行测量，并打印出测量结果。
