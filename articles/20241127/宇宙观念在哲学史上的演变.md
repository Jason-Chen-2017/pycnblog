#### 背景介绍
牛顿力学是近代宇宙观念的重要基础，其提出的力学定律改变了人类对宇宙的理解。

#### 核心概念与联系
1. **牛顿力学的基本原理**：牛顿三大定律和万有引力定律构成了近代宇宙观念的力学基础。
2. **牛顿力学对宇宙观念的影响**：牛顿力学为宇宙提供了定量描述，使宇宙观念从定性描述向定量描述转变。

#### 核心算法原理讲解
```python
# 牛顿三大定律
class NewtonLaws:
    def __init__(self, force, mass, acceleration):
        self.force = force
        self.mass = mass
        self.acceleration = acceleration

    def motion(self):
        print(f"物体质量为{self.mass}，受力{self.force}，加速度为{self.acceleration}。")

# 万有引力定律
def universal_gravitation(m1, m2, r):
    G = 6.674 * 10**-11  # 万有引力常数
    F = G * (m1 * m2) / r**2
    return F

# 创建牛顿力学模型
newton_model = NewtonLaws(9.81, 5, 10)

# 运行模型
newton_model.motion()

# 计算万有引力
print(f"两个质量分别为5kg和10kg的物体，相距10m的万有引力为：{universal_gravitation(5, 10, 10)}N。")
```
