### 西方哲学中的宇宙观念

#### 3.1 古希腊哲学中的宇宙观念

古希腊哲学对宇宙观念的诠释主要来源于两位哲学家：柏拉图和亚里士多德。

##### 柏拉图的理念论

柏拉图的理念论认为，宇宙中存在着一个永恒不变的理念世界，现实世界只是理念世界的投影。这个理念世界是真理和美的源泉。

```python
# 柏拉图的理念论Python代码示例
class IdeaWorld:
    def __init__(self, forms, objects):
        self.forms = forms
        self.objects = objects

    def show_idea(self):
        print("现实世界中的物体对应理念世界的形式：")
        for obj in self.objects:
            print(f"{obj} corresponds to {self.forms[obj]}")

# 示例
idea_world = IdeaWorld({"tree": "form_of_beauty", "mountain": "form_of_greatness"}, ["tree", "mountain"])
idea_world.show_idea()
```

##### 亚里士多德的形而上学

亚里士多德的形而上学认为，宇宙的本质是物质和运动。他认为，现实世界是由物质和运动构成的，而理念世界只是现实世界的抽象反映。

```python
# 亚里士多德的形而上学Python代码示例
class Metaphysics:
    def __init__(self, matter, motion):
        self.matter = matter
        self.motion = motion

    def explain_universe(self):
        print("宇宙由物质和运动构成：")
        print(f"Matter: {self.matter}")
        print(f"Motion: {self.motion}")

# 示例
metaphysics = Metaphysics("物质", "运动")
metaphysics.explain_universe()
```
