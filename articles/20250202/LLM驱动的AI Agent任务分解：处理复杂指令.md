LLAMA Agent使用预训练的LLAMA模型对用户指令进行解析，并将其分解为一系列任务。

```python
import openai

def decompose_task(instruction):
    response = openai.Completion.create(
        engine="text-davinci-002",
        prompt=instruction,
        max_tokens=50
    )
    return response.choices[0].text.strip()
```

##### 4.2.3 执行任务

系统根据分解后的任务执行相应的操作。

```python
import subprocess

def execute_task(task):
    if "open website" in task:
        url = task.split(" ")[-1]
        subprocess.run(["open", url])
    elif "send email" in task:
        recipient = task.split(" ")[-2]
        subject = task.split(" ")[-1]
        subprocess.run(["osascript", "-e", f"""
            tell application "Mail"
                make new message with properties {{subject:"{subject}"}, to:{recipient}}
            end tell
        """])
```
