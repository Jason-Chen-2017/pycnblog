### 第2章 手工啤酒基础知识

#### 2.1 手工啤酒与工业化啤酒的区别
手工啤酒与工业化啤酒在生产规模、原料选择、酿造工艺等方面存在显著差异。手工啤酒强调个性化和独特性，而工业化啤酒则追求大规模生产和低成本。

| 特征 | 手工啤酒 | 工业化啤酒 |
| ---- | ---- | ---- |
| 生产规模 | 小批量 | 大批量 |
| 原料选择 | 优质且多样 | 标准化 |
| 酿造工艺 | 手工制作 | 自动化 |

#### 2.2 手工啤酒的原料与工艺
手工啤酒的原料包括水、麦芽、啤酒花和酵母。麦芽是手工啤酒的核心原料，通过发芽、烘干等工艺制成。啤酒花则用于调味和防腐，酵母则负责发酵过程。手工啤酒的酿造工艺复杂且讲究，需要经过多道工序，包括麦芽糖化、发酵、成熟等。

#### 2.3 手工啤酒的分类与风格
手工啤酒可以根据原料、酿造工艺和风味特点进行分类。常见的分类方法包括：

- 按原料分类：拉格、艾尔、维滋、世涛等。
- 按风味分类：淡色、浓色、苦味、甜味等。
- 按地区分类：比利时风格、德国风格、美国风格等。

### 第3章 手工啤酒品鉴技巧

#### 3.1 品鉴的基本步骤
品鉴手工啤酒需要遵循一定的步骤，包括观察、闻香、品尝和记录。

1. **观察**：观察啤酒的颜色和清澈度，判断其新鲜度和品质。
2. **闻香**：轻轻闻香，感受啤酒的香气和风味特点。
3. **品尝**：小口品尝，感受啤酒的口感和余味。
4. **记录**：记录品鉴过程中的感受和印象，有助于提高品鉴水平。

#### 3.2 观察啤酒的颜色和清澈度
啤酒的颜色和清澈度是判断其新鲜度和品质的重要指标。新鲜的手工啤酒通常具有清澈透明的颜色，而陈年或变质的啤酒则可能呈现出浑浊或发暗的颜色。

#### 3.3 闻香和品尝技巧
闻香和品尝是手工啤酒品鉴的核心环节。通过轻轻嗅闻，可以感受到啤酒的香气和风味。品尝时，小口饮用，让啤酒在口中停留一段时间，感受其口感和余味。
