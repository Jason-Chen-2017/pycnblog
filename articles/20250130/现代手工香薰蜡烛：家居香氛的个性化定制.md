## 手工香薰蜡烛的基本原理和材料

### 蜡烛油

蜡烛油是手工香薰蜡烛的核心成分，其质量直接影响到蜡烛的燃烧性能和香味持久度。目前市面上常见的蜡烛油主要有以下几种：

1. **蜂蜡**：由蜜蜂分泌的蜡质制成，具有天然、环保的特点，燃烧时火焰稳定，适合制作高品质的香薰蜡烛。
2. **棕榈蜡**：来源于棕榈树的树干，具有较好的燃烧性能和保湿性，价格适中，适合大规模生产。
3. **微晶蜡**：一种合成蜡，具有高透明度和良好的燃烧性能，适合制作各种色彩和形状的香薰蜡烛。

### 香精

香精是赋予香薰蜡烛独特香味的重要成分。市场上的香精种类繁多，包括天然植物香精和合成香精。选择香精时，需要考虑以下几个方面：

1. **香味持久度**：不同的香精具有不同的香味持久度，消费者通常希望选择香味持久度较高的香精。
2. **香气层次**：一些香精具有丰富的香气层次，能够在不同的燃烧阶段释放不同的香味，为消费者带来更加丰富的体验。
3. **安全性**：选择符合国家安全标准的香精，确保消费者的使用安全。

### 蜡芯

蜡芯是支撑蜡烛燃烧的关键部分，常见的蜡芯材料有棉芯、纸芯和木芯等。选择蜡芯时，需要考虑以下因素：

1. **燃烧稳定性**：棉芯和纸芯的燃烧稳定性较好，适合制作各种形状和尺寸的香薰蜡烛。
2. **耐高温性**：木芯的耐高温性较好，适合制作大型和高温燃烧的香薰蜡烛。
3. **环保性**：一些天然材料制成的蜡芯更加环保，符合可持续发展的要求。

### 模具

模具是决定香薰蜡烛形状和外观的重要因素。市面上常见的模具材料有硅胶、塑料和金属等。选择模具时，需要考虑以下几个方面：

1. **耐用性**：硅胶模具具有较好的耐用性，适合长期使用。
2. **灵活性**：塑料模具的灵活性较好，适合制作复杂形状的蜡烛。
3. **清洁性**：金属模具的清洁性较好，不易滋生细菌。

### 工具和材料

除了上述核心材料外，制作手工香薰蜡烛还需要一些辅助工具和材料，如：

- **温度计**：用于测量蜡烛油的温度，确保制作过程的稳定性。
- **蜡烛切割刀**：用于切割蜡烛模具，方便取出蜡烛。
- **调色板**：用于调配蜡烛的颜色，增加视觉吸引力。
- **烛台**：用于展示和点燃香薰蜡烛，增加美观度。

### 制作流程

手工香薰蜡烛的制作流程包括以下步骤：

1. **准备材料**：根据所需香薰蜡烛的种类和尺寸，准备相应的蜡烛油、香精、蜡芯和模具等材料。
2. **熔化蜡烛油**：将蜡烛油倒入容器中，加热至适当的温度（通常在60°C-80°C之间），确保蜡烛油充分熔化。
3. **添加香精**：将香精均匀地倒入熔化的蜡烛油中，搅拌均匀，使香精充分溶解。
4. **倒入模具**：将搅拌好的蜡烛油倒入模具中，注意均匀分布，避免气泡产生。
5. **插入蜡芯**：将蜡芯插入模具中心，确保蜡芯稳固，避免蜡烛成型后蜡芯歪斜。
6. **冷却**：将模具放置在通风干燥处，待蜡烛油冷却凝固后，取出香薰蜡烛。
7. **修剪蜡芯**：用剪刀修剪蜡芯，使其整齐并保持合适的长度。

通过以上步骤，读者可以初步掌握手工香薰蜡烛的基本制作方法。接下来，我们将进一步探讨手工香薰蜡烛的个性化定制方法，以满足不同消费者的需求。

## 手工香薰蜡烛的制作工艺

### 蜡烛的制作流程

#### 熔化蜡烛油

首先，我们需要准备一定量的蜡烛油，并将其倒入一个耐高温的容器中。接下来，使用电炉或者煤气炉等加热设备对蜡烛油进行加热，使其熔化。在加热过程中，需要密切关注温度变化，通常保持在60°C-80°C之间。过高的温度可能会导致蜡烛油分解，影响香薰蜡烛的质量。

```mermaid
flowchart LR
A[熔化蜡烛油] --> B[加热设备]
B --> C[温度控制]
C --> D[熔化完成]
D --> E[搅拌香精]
```

#### 搅拌香精

当蜡烛油完全熔化后，我们需要在其中添加适量的香精。将香精倒入蜡烛油中，使用搅拌棒或木棒进行充分搅拌，确保香精均匀分布。在搅拌过程中，需要注意不要产生气泡，以免影响蜡烛的质量。

```mermaid
flowchart LR
A[搅拌香精] --> B[倒入香精]
B --> C[均匀搅拌]
C --> D[避免气泡]
D --> E[搅拌完成]
```

#### 倒入模具

在香精均匀分布后，我们将蜡烛油倒入模具中。根据不同的模具形状和大小，倒入的蜡烛油量也会有所不同。为了确保蜡烛油分布均匀，我们可以使用一根长棍或搅拌棒在模具中轻轻搅拌。同时，为了避免气泡的产生，倒入过程中应尽量减少搅拌。

```mermaid
flowchart LR
A[倒入模具] --> B[倒入蜡烛油]
B --> C[轻轻搅拌]
C --> D[避免气泡]
D --> E[倒入完成]
```

#### 插入蜡芯

在倒入蜡烛油后，我们需要将蜡芯插入模具中心。首先，将蜡芯固定在模具上，确保其不会在倒入蜡烛油的过程中移位。然后，将蜡烛油填满模具，确保蜡芯周围没有空隙。这样，在蜡烛凝固后，蜡芯就会保持稳定，不会歪斜。

```mermaid
flowchart LR
A[插入蜡芯] --> B[固定蜡芯]
B --> C[填满模具]
C --> D[确保稳定]
D --> E[插入完成]
```

#### 冷却与取出

在插入蜡芯后，我们需要将模具放置在通风干燥的地方，让蜡烛油慢慢冷却和凝固。通常需要等待数小时至一天时间，具体时间取决于蜡烛油量和环境温度。当蜡烛完全凝固后，我们可以轻轻取出模具，取出香薰蜡烛。

```mermaid
flowchart LR
A[冷却与取出] --> B[放置通风处]
B --> C[等待凝固]
C --> D[取出模具]
D --> E[取出香薰蜡烛]
```

#### 修剪蜡芯

最后，我们需要对香薰蜡烛的蜡芯进行修剪，使其保持整齐和适当的长度。使用剪刀或剪刀将蜡芯修剪到合适的长度，以便在点燃时能够方便地握持。

```mermaid
flowchart LR
A[修剪蜡芯] --> B[使用剪刀]
B --> C[修剪到合适长度]
C --> D[修剪完成]
```

### 案例一：薰衣草香薰蜡烛的定制制作

#### 背景介绍

一位客户希望在睡前放松时能够享受到薰衣草香薰蜡烛的舒缓效果，同时希望这款香薰蜡烛的外观能够与她的卧室氛围相协调。

#### 制作步骤

1. **选择材料**：
   - 蜡烛油：选用纯净的蜂蜡，确保燃烧稳定且香味纯正。
   - 香精：选择薰衣草香精，以确保香味的纯正和持久。
   - 蜡芯：选用棉质蜡芯，便于点燃和稳定燃烧。
   - 模具：选用白色硅胶模具，以便制作出透明且美观的蜡烛。

2. **熔化蜡烛油**：
   - 将蜂蜡块放入耐高温容器中，加热至70°C左右，确保蜡烛油完全熔化。
   - 在加热过程中，使用温度计监控温度，避免过热导致蜡烛油分解。

3. **添加香精**：
   - 将薰衣草香精缓慢倒入熔化的蜡烛油中，搅拌均匀，使香精充分溶解在蜡烛油中。
   - 搅拌时注意不要产生气泡，以免影响蜡烛的透明度。

4. **倒入模具**：
   - 将搅拌好的蜡烛油倒入白色硅胶模具中，确保蜡烛油分布均匀，无气泡。
   - 倒入过程中，可以使用一根长棍轻轻搅拌，以确保蜡烛油充分填满模具。

5. **插入蜡芯**：
   - 将棉质蜡芯插入模具中心，确保蜡芯稳固，不会在蜡烛成型后歪斜。
   - 将蜡烛油填满模具后，确保蜡芯周围没有空隙。

6. **冷却**：
   - 将模具放置在通风干燥的地方，等待蜡烛油冷却凝固。通常需要4-6小时。

7. **取出蜡烛**：
   - 当蜡烛完全凝固后，轻轻取出模具，取出香薰蜡烛。
   - 用剪刀修剪蜡芯，使其保持整齐并保持适当的长度。

#### 实际效果

定制完成的薰衣草香薰蜡烛具有以下特点：

- **香味**：薰衣草香味纯正，持久且不易散失。
- **外观**：透明且美观，与卧室氛围相协调。
- **燃烧性能**：蜡烛燃烧稳定，火焰明亮且燃烧时间较长。

from db import connect_db

def quality_check(order_id):
    connection = pika.BlockingConnection(pika.ConnectionParameters('localhost'))
    channel = connection.channel()
    
    channel.queue_declare(queue='quality_check')
    
    def callback(ch, method, properties, body):

        if body.decode() == 'pass':
            connection.close()
        else:
            print("Quality check failed. Rejected order.")
    
    channel.basic_consume(queue='quality_check', on_message_callback=callback, auto_ack=True)
