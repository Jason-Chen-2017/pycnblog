### 2.1 历史与文化背景

#### 2.1.1 瑜伽的起源与发展

瑜伽起源于古印度，其历史可以追溯到公元前3000年左右。瑜伽在印度被视为一种传统的修行方式，旨在通过身体、心理和精神的练习，达到身心的平衡与健康。瑜伽的起源与发展与印度古代的哲学思想和宗教信仰密切相关。

**古印度瑜伽的起源**：

1. **梵文文献**：瑜伽最早出现在古印度梵文的文献中，如《梵书》、《森林书》和《奥义书》等。这些文献记录了瑜伽的基本理念和实践方法。
2. **瑜伽的起源人物**：据传，瑜伽的起源人物是古代印度的一位智者帕坦伽利（Patanjali）。他被认为是瑜伽之父，其著作《瑜伽经》是瑜伽的重要经典之一。

**瑜伽在世界范围内的传播**：

瑜伽在印度本土以外的地方传播主要发生在19世纪末至20世纪初。以下是一些重要的传播过程：

1. **西方世界的传播**：19世纪末，瑜伽开始传入西方，最初是由西方传教士和旅行者带到欧洲和美洲。随着瑜伽在西方世界的传播，许多瑜伽大师和学者开始研究瑜伽，并将瑜伽理念与西方哲学、心理学相结合。
2. **全球化的传播**：20世纪中叶，随着全球化的进程，瑜伽逐渐传播到世界各地。瑜伽成为一种国际化的健身和生活方式，受到了全球范围内的关注和推崇。

**中国瑜伽的现状与发展**：

瑜伽在中国也有着广泛的影响。以下是中国瑜伽发展的一些特点：

1. **瑜伽的传入**：瑜伽在20世纪初传入中国，起初主要是在一些大城市，如北京、上海等地传播。
2. **瑜伽的普及**：随着中国社会的发展和人们对健康意识的提高，瑜伽在中国逐渐普及。瑜伽课程、瑜伽用品和瑜伽文化在中国市场上越来越受欢迎。
3. **瑜伽产业的发展**：中国瑜伽产业逐渐兴起，包括瑜伽俱乐部、瑜伽用品店、瑜伽培训学院等。瑜伽作为一种健康生活方式，在中国得到了广泛的认可和应用。

```python
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql://username:password@localhost/db_name'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password = db.Column(db.String(120), nullable=False)

@app.route('/register', methods=['POST'])
def register():
    username = request.form['username']
    password = request.form['password']
    new_user = User(username=username, password=password)
    db.session.add(new_user)
    db.session.commit()
    return jsonify({'message': '注册成功'})

@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({'message': '登录成功'})
    else:
        return jsonify({'message': '用户名或密码错误'})

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```
