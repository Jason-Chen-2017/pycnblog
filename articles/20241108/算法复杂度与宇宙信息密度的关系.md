## 2. 算法复杂度

### 2.1 时间复杂度

时间复杂度描述了一个算法执行时间的增长速度，通常用大O符号（O）来表示。一个算法的时间复杂度反映了其效率，是评估算法性能的重要指标。

#### 示例：线性查找

以下是一个线性查找算法的伪代码示例：

```python
def linear_search(arr, x):
    for i in range(len(arr)):
        if arr[i] == x:
            return i
    return -1
```

该算法的时间复杂度为O(n)，其中n是数组长度。

### 2.2 空间复杂度

空间复杂度描述了一个算法所需内存的增长速度。与时间复杂度类似，空间复杂度也使用大O符号来表示。

#### 示例：递归算法

以下是一个递归算法的伪代码示例：

```python
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)
```

该算法的空间复杂度为O(n)，因为在递归调用过程中会使用到n个栈帧。

### 2.3 算法分析方法

算法分析方法包括渐进分析法和精确分析法。渐进分析法通过近似估计算法性能，而精确分析法则通过具体计算算法性能。
