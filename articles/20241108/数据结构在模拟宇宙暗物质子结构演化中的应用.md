#### 2.1 线性数据结构

线性数据结构是数据结构中最基础和常用的一种，其特点是数据元素在内存中按线性顺序排列。线性数据结构包括数组、链表、栈和队列等。

##### 2.1.1 数组

数组是一种固定大小、线性排列的数据结构，它通过一个连续的内存区域来存储元素。数组在访问和操作数据时具有很高的效率，因为可以直接通过索引访问元素，时间复杂度为O(1)。

```plaintext
// 伪代码：数组定义和初始化
array = [0, 1, 2, 3, 4]
```

数组的缺点是大小固定，无法动态调整。当数组满时，需要创建一个新的数组并将原有数据复制到新数组中，这会带来一定的性能开销。

##### 2.1.2 链表

链表是一种动态数据结构，它由一系列节点组成，每个节点包含数据和指向下一个节点的指针。链表可以通过插入和删除操作来动态调整大小，时间复杂度为O(1)。

```plaintext
// 伪代码：链表定义和初始化
node1 = {data: 1, next: null}
node2 = {data: 2, next: node1}
head = node2
```

链表的优点在于动态性，可以灵活地插入和删除节点。但链表在访问特定节点时需要遍历整个链表，时间复杂度为O(n)。

##### 2.1.3 栈

栈是一种后进先出（LIFO）的数据结构，它通过一个指针指向栈顶元素。栈的操作包括入栈、出栈和查看栈顶元素，时间复杂度为O(1)。

```plaintext
// 伪代码：栈定义和初始化
stack = []
// 入栈
push(1)
push(2)
// 出栈
pop()
```

栈在处理递归、表达式求值等问题中非常有用。

##### 2.1.4 队列

队列是一种先进先出（FIFO）的数据结构，它有两个指针，一个指向队头，一个指向队尾。队列的操作包括入队、出队和查看队头元素，时间复杂度为O(1)。

```plaintext
// 伪代码：队列定义和初始化
queue = []
// 入队
enqueue(1)
enqueue(2)
// 出队
dequeue()
```

队列在处理任务调度、缓冲区管理等问题中非常有用。

#### 2.2 树状数据结构

树状数据结构是一种具有层次关系的数据结构，它通过节点和边来组织数据。树状数据结构包括二叉树、哈夫曼树和B树等。

##### 2.2.3 B树

B树是一种多路平衡搜索树，它通过多个节点来存储数据，每个节点可以有多个子节点。B树广泛应用于数据库和文件系统中。

```plaintext
// 伪代码：B树定义和初始化
```

#### 2.3 图形数据结构

图形数据结构是一种用于表示实体之间复杂关系的数据结构，它包括节点和边。图形数据结构广泛应用于网络分析、社会网络和物理系统建模等领域。

##### 2.3.1 图的基本概念

图由节点（也称为顶点）和边组成，节点表示实体，边表示实体之间的关系。图可以分为无向图和有向图，也可以根据边的类型分为加权图和无权图。

```plaintext
// 伪代码：图定义和初始化

```

##### 2.3.2 图的遍历算法

图的遍历算法包括深度优先搜索（DFS）和广度优先搜索（BFS）。遍历算法用于访问图中的所有节点，并确定节点之间的关系。

```plaintext
// 伪代码：DFS遍历
DFS(graph, node) {
    visited[node] = true
    for (each neighbor in neighbors(node)) {
        if (!visited[neighbor]) {
            DFS(graph, neighbor)
        }
    }
}

// 伪代码：BFS遍历
BFS(graph, startNode) {
    queue = []
    visited = {}
    queue.enqueue(startNode)
    while (!queue.isEmpty()) {
        currentNode = queue.dequeue()
        visited[currentNode] = true
        for (each neighbor in neighbors(currentNode)) {
            if (!visited[neighbor]) {
                queue.enqueue(neighbor)
            }
        }
    }
}
```

##### 2.3.3 最短路径算法

最短路径算法用于计算图中两点之间的最短路径。常见的最短路径算法包括迪杰斯特拉算法（Dijkstra）和弗洛伊德算法（Floyd）。

```plaintext
// 伪代码：Dijkstra算法
Dijkstra(graph, startNode) {
    distances = {node: Infinity}
    distances[startNode] = 0
    visited = {}
    while (visited.size() < graph.nodes.size()) {
        unvisited = graph.nodes - visited
        currentNode = min(unvisited, key=lambda node: distances[node])
        visited[currentNode] = true
        for (each neighbor in graph.neighbors(currentNode)) {
            if (distances[currentNode] + graph.edgeWeight(currentNode, neighbor) < distances[neighbor]) {
                distances[neighbor] = distances[currentNode] + graph.edgeWeight(currentNode, neighbor)
            }
        }
    }
    return distances
}
```

引力势是描述引力场的一种数学工具，它可以用来计算引力作用下的粒子运动。引力势$\Phi$由以下公式给出：

$$
\Phi(\mathbf{r}) = -\frac{G \sum_{i=1}^N m_i}{r_i}
$$

其中，$G$是引力常数，$m_i$是第$i$个粒子的质量，$r_i$是第$i$个粒子到参考点的距离。

引力场$\mathbf{F}$是引力势的梯度，由以下公式给出：

$$
\mathbf{F}(\mathbf{r}) = -\nabla \Phi(\mathbf{r})
$$

**粒子运动方程**

在引力场中，粒子的运动可以用牛顿第二定律描述，即：

$$
\mathbf{F}(\mathbf{r}) = m \mathbf{a}
$$

其中，$m$是粒子的质量，$\mathbf{a}$是粒子的加速度。

结合引力势和引力场，可以得到粒子的运动方程：

$$
m \mathbf{a} = -\nabla \Phi(\mathbf{r})
$$

在数值模拟中，粒子的运动通常通过数值积分方法来计算，如欧拉方法或龙格-库塔方法。
