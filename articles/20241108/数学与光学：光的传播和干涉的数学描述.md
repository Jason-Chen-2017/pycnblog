## 第1章 光的传播基础

### 1.1 光的本质和波动特性

光是一种电磁波，具有粒子性和波动性两种特性。粒子性表现为光子的存在，波动性则体现在光的干涉、衍射和偏振等现象中。麦克斯韦方程组为光的波动性提供了数学基础，描述了电磁波在空间中的传播规律。

### 1.2 光的传播原理

光的传播速度在真空中为 \(3 \times 10^8 \text{ m/s}\)，在介质中则会降低。光的传播方向与介质表面的法线之间的夹角称为入射角，折射定律描述了光在不同介质中传播时的折射现象。光的反射定律则描述了光线在反射时的规律。

## 第2章 光的干涉现象

### 2.1 干涉现象的基本原理

干涉现象是指两束或多束相干光波在相遇时，产生增强或减弱的现象。双缝干涉实验是研究干涉现象的经典实验，通过观察干涉条纹可以了解光的波动性。

- 干涉

### 2.2 干涉的数学描述

干涉现象的数学描述主要通过干涉图样的数学模型来实现。菲涅尔衍射公式和惠更斯-菲涅尔原理是描述干涉现象的重要工具，可以用来计算干涉图样的强度分布。

**核心概念与联系：**
- 干涉图样
- 菲涅尔衍射公式
- 惠更斯-菲涅尔原理

**伪代码：**
```
// 计算干涉图样强度分布
function calculate干涉图样(A1, A2, d, x, y):
    I = A1^2 + A2^2 + 2 * A1 * A2 * cos(2 * pi * k * d * x) * cos(2 * pi * k * y)
    return I
```

**公式与举例：**
$$ I = A_1^2 + A_2^2 + 2A_1A_2\cos(2\pi kdx)\cos(2\pi kdy) $$

当 \( A_1 = A_2 \)，干涉条纹为等间距的亮暗相间的直线。

### 2.3 干涉现象的应用

干涉现象在光学测量和成像中有着广泛的应用。例如，迈克耳孙干涉仪利用干涉原理来测量物体表面的微小形变和厚度。干涉图样还可以用于光学成像系统中的相位恢复和图像增强。

**核心概念与联系：**
- 光学测量
- 光学成像
- 迈克耳孙干涉仪

**应用实例：**
- 迈克耳孙干涉仪测量光学玻璃厚度。
- 干涉法在光学显微镜中实现高分辨率成像。

衍射现象是指光波在传播过程中遇到障碍物时，会发生偏离直线传播路径的现象。单缝衍射、圆孔衍射和圆屏衍射是常见的衍射现象。

### 3.2 衍射的数学描述

衍射的数学描述主要通过库仑波函数、福廷波函数和菲涅尔积分来实现。这些数学工具可以用来计算衍射图样的强度分布。

**核心概念与联系：**
- 库仑波函数
- 福廷波函数
- 菲涅尔积分

**伪代码：**
```
// 计算单缝衍射强度分布
function calculate衍射图样(A, a, x, y):
    k = 2 * pi / lambda
    I = (A^2) * sin^2(k * a * x) / (a^2)
    return I
```

**公式与举例：**
$$ I = \frac{A^2 \sin^2(kax)}{a^2} $$

当 \( a = \lambda \) 时，衍射图样呈现明显的中央亮条纹和两侧的暗条纹。

### 3.3 衍射现象的应用

衍射现象在光学成像和光谱分析中有着重要的应用。单缝衍射可以用于测量光的波长，圆孔衍射可以用于制作光学元件，如透镜和反射镜。圆屏衍射则可以用于研究光的波动性。

**核心概念与联系：**
