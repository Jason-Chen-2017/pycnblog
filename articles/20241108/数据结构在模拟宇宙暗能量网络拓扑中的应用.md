### 第2章 数据结构基础

#### 2.1 数据结构与算法概述

数据结构是计算机科学中用于存储和组织数据的方法，它为数据操作提供了一种有效的组织形式。数据结构的选择对程序的效率和性能有着重要影响。算法是解决特定问题的步骤序列，它通过操作数据结构来处理数据。数据结构与算法紧密相连，一个有效的算法通常依赖于合适的数据结构。

在数据结构的选择上，我们需要考虑以下几个关键因素：

- **存储效率**：数据结构在存储数据时需要占用一定的内存空间，我们需要选择能够有效利用内存的数据结构。
- **访问速度**：不同的数据结构在访问数据时有着不同的速度。例如，数组提供了快速的随机访问，而链表则提供了高效的插入和删除操作。
- **操作复杂度**：数据结构的操作复杂度决定了程序运行的效率。例如，二分搜索的时间复杂度为O(log n)，而线性搜索的时间复杂度为O(n)。

常见的几种基本数据结构如下：

1. **数组与链表**：数组是一种固定大小的数据结构，提供了快速的随机访问。链表则是通过节点链接的方式存储数据，提供了高效的插入和删除操作。

2. **栈与队列**：栈是一种后进先出（LIFO）的数据结构，常用于处理递归和回溯问题。队列是一种先进先出（FIFO）的数据结构，常用于任务调度和缓冲管理。

3. **树与二叉树**：树是一种层次结构，用于表示具有层次关系的数据。二叉树是一种特殊的树，每个节点最多有两个子节点。二叉树广泛应用于搜索、排序和遍历等问题。

4. **图**：图是一种由节点和边组成的数据结构，用于表示复杂的关系网络。图广泛用于网络设计、社交网络分析等领域。

#### 2.2 基础数据结构

**数组与链表**

**数组**是一种线性数据结构，它通过连续的内存空间来存储数据。数组提供了快速的随机访问，时间复杂度为O(1)。但是，数组的长度在创建时就已经确定，无法动态扩展。以下是一个数组的基本操作：

```python
# 创建数组
array = [1, 2, 3, 4, 5]

# 访问数组元素
print(array[0])  # 输出：1

# 修改数组元素
array[0] = 0

# 添加数组元素
array.append(6)

# 删除数组元素
del array[0]
```

**链表**是由节点组成的线性数据结构，每个节点包含数据和指向下一个节点的指针。链表提供了高效的插入和删除操作，时间复杂度为O(1)。以下是一个链表的基本操作：

```python
# 创建链表节点
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

# 创建链表
head = Node(1)
node2 = Node(2)
node3 = Node(3)
head.next = node2
node2.next = node3

# 访问链表元素
current = head
while current:
    print(current.data)
    current = current.next

# 修改链表元素
node2.data = 4

# 添加链表元素
new_node = Node(5)
current = head
while current.next:
    current = current.next
current.next = new_node

# 删除链表元素
current = head
while current.next != new_node:
    current = current.next
current.next = None
```

**栈与队列**

**栈**是一种后进先出（LIFO）的数据结构，常用于处理递归和回溯问题。以下是一个栈的基本操作：

```python
# 创建栈
class Stack:
    def __init__(self):
        self.items = []

    # 入栈
    def push(self, item):
        self.items.append(item)

    # 出栈
    def pop(self):
        return self.items.pop()

    # 查看栈顶元素
    def peek(self):
        return self.items[-1]

# 使用栈
stack = Stack()
stack.push(1)
stack.push(2)
stack.push(3)
print(stack.peek())  # 输出：3
print(stack.pop())  # 输出：3
```

**队列**是一种先进先出（FIFO）的数据结构，常用于任务调度和缓冲管理。以下是一个队列的基本操作：

```python
# 创建队列
class Queue:
    def __init__(self):
        self.items = []

    # 入队
    def enqueue(self, item):
        self.items.append(item)

    # 出队
    def dequeue(self):
        return self.items.pop(0)

    # 查看队列头部元素
    def front(self):
        return self.items[0]

# 使用队列

queue.enqueue(1)
queue.enqueue(2)
queue.enqueue(3)

print(queue.dequeue())  # 输出：1
```

**树与二叉树**

**树**是一种层次结构，用于表示具有层次关系的数据。树由节点组成，每个节点可以有零个或多个子节点。以下是一个树的基本操作：

```python

```

**二叉树**是一种特殊的树，每个节点最多有两个子节点。二叉树广泛应用于搜索、排序和遍历等问题。以下是一个二叉树的基本操作：

```python

        self.left = None
        self.right = None
```

#### 3.2 数据结构与宇宙网络拓扑算法

在宇宙网络拓扑分析中，算法起着至关重要的作用。算法能够帮助我们高效地处理和解析宇宙网络中的大量数据，从而提取出有用的信息。数据结构与算法密不可分，合理选择数据结构可以显著提升算法的性能。以下是几种常见的算法及其与数据结构的结合方式。

**搜索算法**：

搜索算法用于在宇宙网络拓扑中查找特定的节点或路径。常用的搜索算法包括广度优先搜索（BFS）和深度优先搜索（DFS）。

**广度优先搜索（BFS）**：

广度优先搜索是一种无回溯的搜索算法，它从源节点开始，逐层遍历网络，直到找到目标节点或确定不存在路径。在广度优先搜索中，我们可以使用队列这种数据结构来存储待访问的节点。

**伪代码**：

```python
// 广度优先搜索（BFS）
def bfs(graph, start, target):
    visited = set()
    queue = Queue()
    queue.enqueue((start, []))
    
    while not queue.isEmpty():
        node, path = queue.dequeue()
        if node not in visited:
            visited.add(node)
            path.append(node)
            if node == target:
                return path
            for neighbor in graph[node]:
                if neighbor not in visited:
                    queue.enqueue((neighbor, path.copy()))
    
    return None
```

**深度优先搜索（DFS）**：

深度优先搜索是一种有回溯的搜索算法，它从源节点开始，尽可能深地搜索网络，直到找到目标节点或确定不存在路径。在深度优先搜索中，我们可以使用栈这种数据结构来存储待访问的节点。

**伪代码**：

```python
// 深度优先搜索（DFS）
def dfs(graph, start, target):
    visited = set()
    stack = Stack()
    stack.push((start, []))
    
    while not stack.isEmpty():
        node, path = stack.pop()
        if node not in visited:
            visited.add(node)
            path.append(node)
            if node == target:
                return path
            for neighbor in graph[node]:
                if neighbor not in visited:
                    stack.push((neighbor, path.copy()))
    
    return None
```

**路径规划算法**：

路径规划算法用于在宇宙网络拓扑中寻找从源节点到目标节点的最优路径。常用的路径规划算法包括迪杰斯特拉算法（Dijkstra）和A*算法。

**迪杰斯特拉算法（Dijkstra）**：

迪杰斯特拉算法是一种基于优先级的搜索算法，它从源节点开始，逐步扩展网络，计算每个节点到源节点的最短路径。

**伪代码**：

```python
// 迪杰斯特拉算法（Dijkstra）
def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    visited = set()
    priority_queue = PriorityQueue()
    priority_queue.enqueue((start, 0))
    
    while not priority_queue.isEmpty():
        current, _ = priority_queue.dequeue()
        if current not in visited:
            visited.add(current)
            for neighbor, weight in graph[current].items():
                distance = distances[current] + weight
                if distance < distances[neighbor]:
                    distances[neighbor] = distance
                    priority_queue.enqueue((neighbor, distance))
    
    return distances
```

**A*算法**：

A*算法是一种启发式搜索算法，它利用目标节点的估计距离（启发函数）来优化搜索过程。A*算法能够快速找到从源节点到目标节点的最优路径。

**伪代码**：

```python
// A*算法
def a_star(graph, start, target, heuristic):
    open_set = PriorityQueue()
    open_set.enqueue((start, heuristic(start, target)))
    came_from = {}
    g_score = {node: float('infinity') for node in graph}
    g_score[start] = 0
    
    while not open_set.isEmpty():
        current, _ = open_set.dequeue()
        
        if current == target:
            path = []
            while current in came_from:
                path.append(current)
                current = came_from[current]
            path.reverse()
            return path
        
        for neighbor, weight in graph[current].items():
            tentative_g_score = g_score[current] + weight
            if tentative_g_score < g_score[neighbor]:
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g_score
                f_score = tentative_g_score + heuristic(neighbor, target)
                open_set.enqueue((neighbor, f_score))
    
    return None
```

**网络优化算法**：

网络优化算法用于在宇宙网络拓扑中优化网络性能，如最小生成树、最短路径和最大流等问题。这些算法通常基于图论中的算法，如普里姆算法、克鲁斯卡尔算法和福特-富克森算法。

**普里姆算法**：

普里姆算法用于构建最小生成树，它从某个节点开始，逐步扩展生成树，直到包含所有节点。

**伪代码**：

```python
// 普里姆算法
def prim(graph, start):
    tree = []
    visited = set()
    visited.add(start)
    
    while len(visited) < len(graph):
        min_edge = None
        min_weight = float('infinity')
        
        for node in visited:
            for neighbor, weight in graph[node].items():
                if neighbor not in visited and weight < min_weight:
                    min_edge = (node, neighbor)
                    min_weight = weight
        
        tree.append(min_edge)
        node, neighbor = min_edge
        visited.add(neighbor)
    
    return tree
```

**克鲁斯卡尔算法**：

克鲁斯卡尔算法也用于构建最小生成树，它从所有边开始，逐步选择权重最小的边，直到形成最小生成树。

**伪代码**：

```python
def kruskal(graph):
    tree = []
    edges = sorted(graph.keys(), key=lambda x: graph[x])
    union = UnionFind(len(graph))
    
    for edge in edges:
        node1, node2 = edge
        if not union.find(node1) == union.find(node2):
            tree.append(edge)
            union.union(node1, node2)
    
    return tree
```
