### 第2章：信息熵基本概念

#### 2.1 信息熵的定义与性质

信息熵是描述随机变量不确定性大小的度量。在概率论中，信息熵通常用熵函数（Entropy Function）来表示。对于一个离散随机变量\( X \)，其熵定义为：

$$
H(X) = -\sum_{i} p_i \log_2 p_i
$$

其中，\( p_i \)是\( X \)取第\( i \)个值的概率。信息熵的性质包括：

1. **非负性**：信息熵总是非负的，即\( H(X) \geq 0 \)。
2. **最大值**：当随机变量是均匀分布时，信息熵达到最大值。
3. **加性**：对于两个随机变量\( X \)和\( Y \)，有\( H(X, Y) = H(X) + H(Y | X) \)。

#### 2.2 信息熵的应用领域

信息熵在多个领域有着广泛的应用。在通信领域，信息熵被用来衡量信号传输中的信息损失。在机器学习领域，信息熵被用来评估模型对于数据的拟合程度。在密码学中，信息熵被用来评估密码系统的安全性。以下是一个信息熵在通信领域的应用案例：

假设一个通信系统传输的信号包含两种状态，状态A和状态B。通过观测，发现状态A和状态B的概率分别为0.7和0.3。我们可以计算该信号的信息熵：

$$
H(\text{信号}) = -0.7 \log_2 0.7 - 0.3 \log_2 0.3 \approx 0.918
$$

这个结果表明，该信号具有较高的不确定性，适合用于通信。

```python
qc = QuantumCircuit(qubits, classical_bits)

qc.h(qubits[0])
qc.h(qubits[1])
qc.h(qubits[2])

# 执行搜索过程
qc.cx(qubits[0], qubits[1])
qc.cx(qubits[1], qubits[2])

# 测量量子态
qc.measure(qubits, classical_bits)

# 执行量子电路
backend = Aer.get_backend('qasm_simulator')
result = execute(qc, backend, shots=1000)

# 输出结果
print(result.get_counts(qc))
```
