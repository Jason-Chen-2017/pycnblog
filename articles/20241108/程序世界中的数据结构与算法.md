## 第一部分：数据结构与算法基础

### 1.1 数据结构与算法概述

#### 1.1.1 数据结构的基本概念

数据结构是计算机存储、组织数据的方式。它不仅影响程序的执行效率，还决定了程序的可维护性和扩展性。常见的线性数据结构包括数组、链表、栈和队列，而树形数据结构则包括二叉树、堆和平衡树。图形数据结构则用于表示复杂的关系，如网络和社交图。

#### 1.1.2 算法的定义与特性

算法是解决问题的步骤集合，其核心在于有效性、可读性和可扩展性。一个良好的算法应具有较低的复杂度，即能够在合理的时间内解决问题，同时占用较少的内存空间。

#### 1.1.3 数据结构与算法的关系

数据结构与算法相辅相成。选择合适的数据结构可以显著提高算法的效率，而设计高效的算法也可以充分利用数据结构的特性。

### 1.2 算法分析

#### 1.2.1 时间复杂度分析

时间复杂度用于衡量算法执行时间的增长速率。常见的复杂度表示方法包括O、Ω和θ。例如，一个线性搜索算法的时间复杂度为O(n)，而二分搜索算法的时间复杂度为O(log n)。

#### 1.2.2 空间复杂度分析

空间复杂度用于衡量算法占用内存的增长速率。类似于时间复杂度，空间复杂度也使用O、Ω和θ来表示。了解算法的空间复杂度有助于我们在设计程序时做出更优的内存管理决策。

### 1.3 数据结构分类

#### 1.3.1 线性数据结构

- **数组**：固定大小的数据集合，支持随机访问。
- **链表**：由节点组成的线性结构，支持快速插入和删除。
- **栈**：后进先出（LIFO）的数据结构，常用于函数调用和递归。
- **队列**：先进先出（FIFO）的数据结构，常用于任务调度和缓冲区管理。

#### 1.3.2 树形数据结构

- **二叉树**：每个节点最多有两个子节点，用于快速查找和排序。
- **堆**：一种特殊的树形结构，用于优先队列和排序。
- **平衡树**：如AVL树和红黑树，用于保证查询和操作的时间复杂度。

#### 1.3.3 图形数据结构

- **图的基本概念**：图由节点和边组成，用于表示复杂的关系。
- **图的算法**：包括遍历算法（DFS和BFS）、最短路径算法（Dijkstra和Floyd）等。

## 第二部分：核心算法原理讲解

### 2.1 排序算法

#### 2.1.1 冒泡排序

```pseudocode
for i = 0 to n-1
    for j = 0 to n-i-1
        if arr[j] > arr[j+1]
            swap arr[j] and arr[j+1]
```

#### 2.1.2 选择排序

```pseudocode
for i = 0 to n-1
    minIndex = i
    for j = i+1 to n
        if arr[j] < arr[minIndex]
            minIndex = j
    swap arr[i] and arr[minIndex]
```

#### 2.1.3 插入排序

```pseudocode
for i = 1 to n-1
    key = arr[i]
    j = i - 1
    while j >= 0 and arr[j] > key
        arr[j+1] = arr[j]
        j = j - 1
    arr[j+1] = key
```

### 2.2 搜索算法

#### 2.2.1 二分查找

```pseudocode
low = 0
high = n - 1
while low <= high
    mid = (low + high) / 2
    if arr[mid] == target
        return mid
    elif arr[mid] < target
        low = mid + 1
    else
        high = mid - 1
return -1
```

#### 2.2.2 广度优先搜索

```pseudocode
queue = empty queue
enqueue root node
while queue is not empty
    dequeue a node
    visit the node
    enqueue all its unvisited neighbors
```

#### 2.2.3 深度优先搜索

```pseudocode
visited = empty set
function dfs(node)
    if node is not visited
        mark node as visited
        visit node
        for each neighbor of node
            dfs(neighbor)
```
