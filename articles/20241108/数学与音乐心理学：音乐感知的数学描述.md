### 音高感知的数学描述

音高感知可以通过频率和波长来描述。频率是指每秒振动的次数，以赫兹（Hz）为单位。波长是指声波在单位时间内传播的距离。

- **频率**：音高与频率的关系可以用以下公式表示：
  $$ f = \frac{c}{\lambda} $$
  其中，f是频率，c是声速，λ是波长。

  $$ \lambda = \frac{c}{f} $$

例如，如果声速为340 m/s，那么频率为440 Hz的音高的波长为：

  $$ T = \frac{1}{f} $$

$$ T = \frac{1}{120 \text{ bpm}} = 0.5 \text{ s} $$

#### 源代码实现

```python
import librosa
import numpy as np

def identify_pitch(y, sr):
    y_fificados = librosa.effects.pitch.yield_vibrato(y, sr)
    pitches, magnitudes = librosa.piptrack(y_fificados, sr)
    return np.argmax(magnitudes), librosa.hz2note(pitches[np.argmax(magnitudes)])

# 读取音频文件
y, sr = librosa.load('example_audio.wav')

# 音高识别
pitch_class, pitch_name = identify_pitch(y, sr)
print(f"The identified pitch is {pitch_name} ({pitch_class})")
```
