### 2. 基础理论

#### 2.1 时间复杂度

时间复杂度是衡量算法执行时间与输入数据规模之间关系的指标。我们通常用大O符号（O-notation）来表示时间复杂度。时间复杂度的计算方法如下：

1. 找出算法中所有基本操作的数量，记为$f(n)$。
2. 计算算法执行时间与$f(n)$之间的比例关系，记为$T(n) = O(f(n))$。

常见的时间复杂度包括：

- 常数复杂度：$O(1)$，算法执行时间与输入数据规模无关。
- 线性复杂度：$O(n)$，算法执行时间与输入数据规模成线性关系。
- 平方复杂度：$O(n^2)$，算法执行时间与输入数据规模的平方成正比。
- 对数复杂度：$O(log(n))$，算法执行时间与输入数据规模的对数成正比。

#### 2.2 空间复杂度

空间复杂度是衡量算法在运行过程中所需内存空间与输入数据规模之间关系的指标。同样，我们使用大O符号来表示空间复杂度。空间复杂度的计算方法如下：

1. 找出算法所需存储空间的最大值，记为$S(n)$。
2. 计算算法所需空间与$S(n)$之间的比例关系，记为$M(n) = O(S(n))$。

常见空间复杂度包括：

- 常数复杂度：$O(1)$，算法所需空间与输入数据规模无关。
- 线性复杂度：$O(n)$，算法所需空间与输入数据规模成线性关系。
- 平方复杂度：$O(n^2)$，算法所需空间与输入数据规模的平方成正比。
- 对数复杂度：$O(log(n))$，算法所需空间与输入数据规模的对数成正比。

这个例子中，算法只使用了常数空间来存储结果，即空间复杂度为$O(1)$。

### 3. 信息熵的基本概念

#### 3.1 信息熵的定义

信息熵是衡量信息不确定性的物理量。在概率论和信息论中，信息熵定义为：

$$
H(X) = -\sum_{i=1}^{n} p(x_i) \log_2 p(x_i)
$$

其中，$H(X)$表示随机变量$X$的信息熵，$p(x_i)$表示随机变量$X$取值为$x_i$的概率，$\log_2$表示以2为底的对数。

#### 3.2 信息熵的计算

信息熵的计算公式可以帮助我们计算任意随机变量的信息熵。例如，假设有一个二进制随机变量$X$，其取值为0和1的概率分别为$p_0$和$p_1$，则其信息熵为：

$$
H(X) = -p_0 \log_2 p_0 - p_1 \log_2 p_1
$$

#### 3.3 信息熵的变体

信息熵有多种变体，如条件熵、联合熵等。条件熵$H(X|Y)$表示在给定随机变量$Y$的条件下，随机变量$X$的信息熵。联合熵$H(X,Y)$表示随机变量$X$和$Y$同时发生的概率分布。

宇宙信息处理熵增速率是指宇宙在信息处理过程中，信息熵随时间增加的速率。根据熵增定理，宇宙的总熵随时间不断增长，这意味着宇宙中的信息处理能力在不断下降。

宇宙信息处理熵增速率的推导可以从基本的热力学第二定律出发。热力学第二定律指出，一个孤立系统的熵随时间增加。在宇宙这个大尺度上，我们可以将宇宙视为一个孤立系统，因此宇宙的熵也随时间增加。

```python

import json
from hashlib import sha256

class Block:
    def __init__(self, index, transactions, timestamp, previous_hash):
        self.index = index
        self.transactions = transactions
        self.timestamp = timestamp
        self.previous_hash = previous_hash
        self.hash = self.compute_hash()

    def compute_hash(self):
        block_string = json.dumps(self.__dict__, sort_keys=True)
        return sha256(block_string.encode()).hexdigest()

class Blockchain:
    def __init__(self):
        self.unconfirmed_transactions = []
        self.chain = []
        self.create_genesis_block()

    def create_genesis_block(self):
        genesis_block = Block(0, [], timestamp.time(), "0")
        genesis_block.hash = genesis_block.compute_hash()
        self.chain.append(genesis_block)

    def add_new_transaction(self, transaction):
        self.unconfirmed_transactions.append(transaction)

    def mine(self):
        if not self.unconfirmed_transactions:
            return None

        last_block = self.chain[-1]
        new_block = Block(len(self.chain), self.unconfirmed_transactions, timestamp.time(), last_block.hash)
        new_block.hash = new_block.compute_hash()
        self.chain.append(new_block)
        self.unconfirmed_transactions = []

    def is_chain_valid(self):
        for i in range(1, len(self.chain)):
            current = self.chain[i]
            previous = self.chain[i - 1]
            if current.hash != current.compute_hash():
                return False
            if current.previous_hash != previous.hash:
                return False
        return True

    }
    node.add_new_transaction(transaction)

def consensus():
    longest_chain = None
    max_length = len(node.chain)

    for peer in peers:
        response = requests.get(f'http://{peer}/chain')
        chain = response.json()["chain"]
        if len(chain) > max_length:
            max_length = len(chain)
            longest_chain = chain

    if longest_chain:
        node.chain = longest_chain
        node.unconfirmed_transactions = []

def start_miner():
    while True:
        node.mine()
        consensus()
```
