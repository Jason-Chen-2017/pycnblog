##### 2.1 宇宙常数概述

宇宙常数通常表示为 \( \Lambda \)，是一个在物理学中用于描述宇宙膨胀速率的参数。在广义相对论中，宇宙常数被引入到爱因斯坦场方程中，用于描述宇宙的整体行为。宇宙常数的值是一个常数，约为 \( 10^{-122} \)，这个极小的数值表明宇宙的膨胀速度非常缓慢。

宇宙常数最早由爱因斯坦在20世纪初提出，用于解决广义相对论中宇宙静态模型的不稳定性问题。然而，随着宇宙膨胀的发现，爱因斯坦将宇宙常数视为一个“最大错误”，并称之为“万有引力之死敌”。

宇宙常数的测量是一个复杂的任务，需要使用各种观测方法和数据分析技术。目前，科学家们主要通过两种方法来测量宇宙常数：一种是观测宇宙背景辐射，另一种是观测 distant supernovae。

宇宙背景辐射的测量可以通过观测宇宙微波背景辐射（CMB）来实现。CMB是宇宙早期的大爆炸时期遗留下来的辐射，通过对它的观测可以推测出宇宙的膨胀历史。

Distant supernovae的观测则是通过测量它们的亮度来确定宇宙的膨胀速率。科学家们通过分析 distant supernovae的光谱，可以计算出它们的距离，从而推断出宇宙的膨胀速度。

##### 2.4 宇宙常数与物理学的关系

宇宙常数在物理学中有着广泛的应用。例如，在宇宙学中，宇宙常数用于描述宇宙的膨胀速率和密度。在粒子物理学中，宇宙常数可能与暗能量有关，暗能量是驱动宇宙加速膨胀的一种神秘力量。

### 第3章 程序时间复杂度基础

##### 3.1 时间复杂度定义

程序时间复杂度是指一个算法在处理输入数据时所需时间的增长速率。时间复杂度通常用大O符号（\(O\)）来表示，它描述了一个算法在最坏情况下的性能。

例如，一个线性搜索算法的时间复杂度为 \(O(n)\)，意味着随着输入数据量 \(n\) 的增加，算法所需的时间呈线性增长。而一个二分搜索算法的时间复杂度为 \(O(\log n)\)，意味着随着输入数据量 \(n\) 的增加，算法所需的时间呈对数增长。

##### 3.2 时间复杂度分类

时间复杂度可以根据算法在不同情况下的性能进行分类。常见的时间复杂度分类包括：

- **常数时间复杂度 \(O(1)\)**：算法执行时间不随输入数据量变化，例如一个简单的赋值操作。
- **线性时间复杂度 \(O(n)\)**：算法执行时间与输入数据量 \(n\) 成正比，例如线性搜索和遍历数组。
- **对数时间复杂度 \(O(\log n)\)**：算法执行时间与输入数据量 \(n\) 的对数成反比，例如二分搜索算法。
- **多项式时间复杂度 \(O(n^k)\)**：算法执行时间与输入数据量的某个多项式成比例，例如排序算法中的快速排序。

##### 3.3 时间复杂度计算方法

计算程序的时间复杂度通常需要分析算法的结构和逻辑。以下是一些常见的时间复杂度计算方法：

- **递归分析**：通过递归关系来计算算法的时间复杂度。例如，快速排序算法的时间复杂度可以通过递归分析来计算。
- **计数方法**：通过计数算法中的基本操作（如比较、赋值和递归调用）来计算时间复杂度。例如，一个线性搜索算法的时间复杂度可以通过计数比较次数来计算。
- **归纳法**：通过归纳假设和归纳步骤来证明算法的时间复杂度。例如，可以使用归纳法证明二分搜索算法的时间复杂度为 \(O(\log n)\)。

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = random.choice(arr)
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
```

```python
import time

def time_func(func, *args, **kwargs):
    start_time = time.time()
    result = func(*args, **kwargs)
    end_time = time.time()
    return end_time - start_time, result

# 测试
```

## 程序时间复杂度基础

### 3.1 时间复杂度定义

程序时间复杂度是指一个算法在处理输入数据时所需时间的增长速率。时间复杂度通常用大O符号（\(O\)）来表示，它描述了一个算法在最坏情况下的性能。

例如，一个线性搜索算法的时间复杂度为 \(O(n)\)，意味着随着输入数据量 \(n\) 的增加，算法所需的时间呈线性增长。而一个二分搜索算法的时间复杂度为 \(O(\log n)\)，意味着随着输入数据量 \(n\) 的增加，算法所需的时间呈对数增长。

### 3.2 时间复杂度分类

时间复杂度可以根据算法在不同情况下的性能进行分类。常见的时间复杂度分类包括：

- **常数时间复杂度 \(O(1)\)**：算法执行时间不随输入数据量变化，例如一个简单的赋值操作。
- **线性时间复杂度 \(O(n)\)**：算法执行时间与输入数据量 \(n\) 成正比，例如线性搜索和遍历数组。
- **对数时间复杂度 \(O(\log n)\)**：算法执行时间与输入数据量 \(n\) 的对数成反比，例如二分搜索算法。
- **多项式时间复杂度 \(O(n^k)\)**：算法执行时间与输入数据量的某个多项式成比例，例如排序算法中的快速排序。

### 3.3 时间复杂度计算方法

计算程序的时间复杂度通常需要分析算法的结构和逻辑。以下是一些常见的时间复杂度计算方法：

- **递归分析**：通过递归关系来计算算法的时间复杂度。例如，快速排序算法的时间复杂度可以通过递归分析来计算。
- **计数方法**：通过计数算法中的基本操作（如比较、赋值和递归调用）来计算时间复杂度。例如，一个线性搜索算法的时间复杂度可以通过计数比较次数来计算。
- **归纳法**：通过归纳假设和归纳步骤来证明算法的时间复杂度。例如，可以使用归纳法证明二分搜索算法的时间复杂度为 \(O(\log n)\)。

```python
import random

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = random.choice(arr)
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

# 测试

sorted_arr = quicksort(arr)
```
