等离子体是物质的第四态，与固态、液态和气态不同，等离子体由自由电子和正离子组成。其基本特性包括高电离度、高热能和电荷中性。等离子体的电离度越高，自由电子和正离子的数量越多，其物理性质也越复杂。

rho0 = 1.0
v0 = 0.0
p0 = 1.0

# 初始条件

p[:] = p0

    # 计算电流密度

        J[i] = -np.diff(v)[i-1] / dx

    # 更新速度
    v -= (B/p) * dt
