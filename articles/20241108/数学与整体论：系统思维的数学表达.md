# 伪代码：Dijkstra算法

function Dijkstra(Graph, source):
    for each vertex V in Graph:
        V.dist = INFINITY
        V.prev = UNDEFINED
        if V == source:
            V.dist = 0
    vertices = list(Graph.vertices())
    sorted_vertices = sort(vertices, by V.dist)
    while sorted_vertices is not empty:
        current = sorted_vertices.pop()
        for neighbor in current.neighbors():
            distance = current.dist + Graph.get_edge_weight(current, neighbor)

                neighbor.dist = distance
                neighbor.prev = current
        sorted_vertices = sort(vertices, by V.dist)
    return the calculated distances and paths
```
