这些公式通过物理定律（如牛顿第二定律和连续性方程）推导得出，反映了地震波在不同介质中的传播特性。

  ```python
  import numpy as np

  # 定义地震波传播模型参数
  rho = 2700  # 密度
  K = 200e9   # 体积模量
  S = 80e9    # 剪切模量
  mu = 40e9   # 拉梅常数

  # 计算地震波速度
  vP = rho * K / mu
  vS = rho * S / mu

  # 传播路径计算
  path = np.linspace(0, 100, 1000)  # 距离路径
  tP = path / vP
  tS = path / vS

  # 绘制波前时间序列
  plt.plot(path, tP, label="P波")
  plt.plot(path, tS, label="S波")
  plt.legend()
  plt.show()
  ```
