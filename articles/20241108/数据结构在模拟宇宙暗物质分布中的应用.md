#### 1.1 宇宙暗物质简介

宇宙暗物质，顾名思义，是指宇宙中我们无法直接观测到的物质。根据现代宇宙学的理论，宇宙暗物质占据了宇宙总质量的约 27%，而普通物质（如恒星、星系、行星等）仅占约 5%，剩余的 68% 被认为是暗能量。暗物质与暗能量共同构成了现代宇宙学的标准模型——ΛCDM（Lambda Cold Dark Matter）模型。

**1.1.1 暗物质的概念**

暗物质最早是在20世纪30年代通过天文学家对星系旋转速度的研究中提出的。在观测中发现，星系的旋转速度与其可见质量不成正比，这表明存在一种无法直接观测到的物质，通过引力效应影响星系的运动。这种物质被称为暗物质。

**1.1.2 暗物质的性质与作用**

暗物质的性质非常特殊，它不发光、不发热、也不吸收电磁波，因此难以直接探测。然而，通过观测宇宙的大尺度结构和宇宙微波背景辐射，我们可以推断出暗物质的一些性质：

- **质量巨大**：暗物质的质量非常庞大，是普通物质的数十倍甚至上百倍。
- **无结构**：暗物质似乎没有形成结构，它不是由原子或分子组成的，而是一种全新的物质形态。
- **引力作用**：暗物质通过引力与普通物质相互作用，影响宇宙的大尺度结构形成和演化。

**1.1.3 暗物质研究的意义**

暗物质研究在宇宙学、粒子物理学和天文学等多个领域都有重要意义：

- **天文学**：了解暗物质的性质和分布，有助于我们更深入地理解宇宙的组成和演化。

### 模拟宇宙暗物质分布的核心算法原理讲解

#### 3.1 N-Body算法

N-Body算法是一种用于模拟宇宙中物体相互之间引力作用的基本算法。它的核心思想是使用牛顿的万有引力定律来计算每个物体之间的引力相互作用，并根据这些引力计算物体的加速度，从而预测它们的运动轨迹。以下是N-Body算法的基本原理、伪代码和执行流程。

**3.1.1 N-Body算法概述**

N-Body算法的基本原理可以概括为以下步骤：

1. **初始化**：设定初始条件，包括所有物体的初始位置和速度。
2. **计算引力**：使用万有引力定律计算每个物体与其他物体之间的引力。
3. **计算加速度**：根据引力大小和方向，计算每个物体的加速度。
4. **更新位置和速度**：根据加速度更新物体的位置和速度。
5. **迭代**：重复步骤2到4，直到满足终止条件（如达到最大迭代次数或物体的位置变化非常小）。

**3.1.2 N-Body算法伪代码**

以下是一个简化的N-Body算法伪代码：

```plaintext
初始化物体位置和速度
计算最大迭代次数或终止条件
while (未达到终止条件) {
    for 每个物体 i {
        清零加速度
        for 每个其他物体 j != i {
            计算距离 r = |位置_i - 位置_j|
            计算引力 F = G * (质量_i * 质量_j) / r^2
            更新加速度_i += F / 质量_i
        }
    }
    更新位置和速度
}
```

**3.1.3 N-Body算法的执行流程**

N-Body算法的执行流程可以分为以下几个步骤：

1. **初始化**：设定初始条件，包括物体的初始位置和速度。这些初始条件可以根据宇宙模型和模拟的需求进行设置。
2. **计算引力**：算法通过迭代计算每个物体与其他物体之间的引力。这个过程是算法的核心，也是计算量最大的部分。通过使用有效的空间划分数据结构（如四叉树或八叉树），可以显著减少计算次数，提高效率。
3. **计算加速度**：根据引力的大小和方向，计算每个物体的加速度。加速度是矢量，因此需要分别计算每个坐标方向的分量。
4. **更新位置和速度**：根据加速度更新物体的位置和速度。这个步骤是模拟时间推进的关键，决定了物体在未来时间点的位置和速度。
5. **迭代**：重复计算引力和更新位置和速度的过程，直到满足终止条件。终止条件可以是迭代次数达到最大值，或者物体的位置变化非常小，表明已达到动态平衡。

#### 3.2 PM算法

PM（Particle-Mesh）算法是一种基于网格结构的模拟算法，用于模拟宇宙中粒子的相互作用。与N-Body算法直接计算每个粒子之间的相互作用不同，PM算法通过将宇宙划分为多个网格点，将计算任务分解为粒子阶段和网格阶段。以下是PM算法的基本原理、伪代码和执行流程。

**3.2.1 PM算法概述**

PM算法的基本原理可以概括为以下步骤：

1. **初始化**：设定初始条件，包括所有粒子的初始位置和速度。
2. **粒子阶段**：计算每个粒子的位置和速度，并将其分配到相应的网格点上。
3. **网格阶段**：计算每个网格点的质量分布和引力势能。
4. **迭代**：重复粒子阶段和网格阶段，逐步推进时间，直到满足终止条件。

**3.2.2 PM算法伪代码**

以下是一个简化的PM算法伪代码：

```plaintext
初始化粒子位置和速度
计算最大迭代次数或终止条件
while (未达到终止条件) {
    粒子阶段：
    for 每个粒子 i {
        计算位置和速度
        分配到网格点
    }
    
    网格阶段：
    for 每个网格点 j {
        计算质量分布和引力势能
    }
    更新网格点信息
    更新粒子位置和速度
}
```

**3.2.3 PM算法的执行流程**

PM算法的执行流程可以分为以下几个步骤：

1. **初始化**：设定初始条件，包括粒子的初始位置和速度。这些初始条件可以根据宇宙模型和模拟的需求进行设置。
2. **粒子阶段**：计算每个粒子的位置和速度，并将其分配到相应的网格点上。这个过程包括粒子运动的计算和粒子的空间划分。
3. **网格阶段**：计算每个网格点的质量分布和引力势能。网格点上的质量分布是通过积分粒子质量得到的，而引力势能是通过插值网格点上的引力场计算得到的。

**4.1.1 暗物质分布密度函数**

密度函数描述了宇宙中暗物质的空间分布。一个常用的密度函数是高斯分布，其表达式如下：

\[ \rho(\mathbf{x}, t) = \frac{\rho_0}{(1 + \alpha t)^3} \exp\left(-\frac{r^2}{\sigma^2}\right) \]

其中，\(\rho(\mathbf{x}, t)\)表示在位置\(\mathbf{x}\)和时间\(t\)的暗物质密度，\(\rho_0\)是初始密度，\(\alpha\)是时间衰减系数，\(r\)是距离原点的距离，\(\sigma\)是高斯分布的宽度。

**实例**：假设我们有一个暗物质球体，其中心位置为\((0, 0, 0)\)，初始密度为\(\rho_0 = 10\ \text{g/cm}^3\)，衰减系数\(\alpha = 0.1\)，宽度\(\sigma = 1\ \text{cm}\)。我们可以计算在位置\((1, 1, 1)\)的暗物质密度：

暗物质势能函数描述了宇宙中暗物质间的相互作用。一个常用的势能函数是引力势能函数，其表达式如下：

**实例**：假设我们有两个质量分别为\(M = 10\ \text{M}_\odot\)和\(m = 1\ \text{M}_\odot\)的暗物质粒子，它们之间的距离为\(r = 1\ \text{pc}\)。我们可以计算它们之间的引力势能：

\[ V = -\frac{6.674 \times 10^{-11}\ \text{Nm}^2/\text{kg}^2 \times 10 \times 10^6\ \text{kg} \times 1 \times 10^6\ \text{kg}}{1 \times 10^{13}\ \text{m}} = -6.674 \times 10^{-8}\ \text{J} \]

暗物质运动方程描述了暗物质粒子在引力作用下的运动。一个常用的运动方程是牛顿第二定律，其表达式如下：

\[ \mathbf{a} = \frac{(1\ \text{N}, 0, 0)}{1\ \text{kg}} = (1\ \text{m/s}^2, 0, 0) \]

#### 4.2 算法中的数学公式

在模拟宇宙暗物质分布的算法中，常用的数学公式包括引力计算公式、流体动力学公式等。以下是对这些公式的详细描述。

**4.2.1 N-Body算法中的引力计算公式**

N-Body算法中，引力计算公式是核心的数学公式，用于计算每个粒子之间的引力。其表达式如下：

\[ \mathbf{F}_i = \sum_{j \neq i} \frac{G m_i m_j (\mathbf{r}_i - \mathbf{r}_j)}{|\mathbf{r}_i - \mathbf{r}_j|^3} \]

其中，\(\mathbf{F}_i\)是作用在第\(i\)个粒子上的引力，\(G\)是万有引力常数，\(m_i\)和\(m_j\)是第\(i\)个和第\(j\)个粒子的质量，\(\mathbf{r}_i\)和\(\mathbf{r}_j\)是第\(i\)个和第\(j\)个粒子的位置，\(|\mathbf{r}_i - \mathbf{r}_j|\)是两粒子间的距离。

**实例**：假设我们有两个质量分别为\(m_1 = 1\ \text{kg}\)和\(m_2 = 2\ \text{kg}\)的粒子，它们的位置分别为\(\mathbf{r}_1 = (1\ \text{m}, 0, 0)\)和\(\mathbf{r}_2 = (2\ \text{m}, 0, 0)\)。我们可以计算它们之间的引力：

\[ \mathbf{F}_1 = \sum_{j \neq i} \frac{6.674 \times 10^{-11}\ \text{Nm}^2/\text{kg}^2 \times 1 \times 2 (\mathbf{r}_1 - \mathbf{r}_2)}{|\mathbf{r}_1 - \mathbf{r}_2|^3} = \frac{6.674 \times 10^{-11}\ \text{Nm}^2/\text{kg}^2 \times 2 (1\ \text{m} - 2\ \text{m})}{1\ \text{m}^3} = -1.3378 \times 10^{-11}\ \text{N} \]

**4.2.2 PM算法中的流体动力学公式**

PM算法中，流体动力学公式用于描述粒子的运动和流体场的变化。以下是一些常用的流体动力学公式：

\[ \mathbf{u}_i = \frac{\partial \rho}{\partial t} + \frac{\partial \mathbf{v}_i}{\partial x} \]
\[ \mathbf{v}_i = \frac{\nabla p - \rho \mathbf{g}}{\rho} \]

其中，\(\mathbf{u}_i\)是粒子\(i\)的速度，\(\rho\)是流体密度，\(\mathbf{v}_i\)是粒子的速度，\(p\)是流体压强，\(\mathbf{g}\)是重力加速度。

**实例**：假设一个粒子的质量为\(m = 1\ \text{kg}\)，它在一个恒定压强为\(p = 1\ \text{Pa}\)的流体中运动，其速度为\(\mathbf{v}_i = (1\ \text{m/s}, 0, 0)\)。我们可以计算粒子的加速度：

\[ \mathbf{a}_i = \frac{\nabla p - \rho \mathbf{g}}{\rho} = \frac{1\ \text{Pa} - 1\ \text{kg/m}^3 \cdot 9.81\ \text{m/s}^2}{1\ \text{kg/m}^3} = (0.01981\ \text{m/s}^2, 0, 0) \]

void compute_gravity(particle_t particles[], int N, double G) {
    // 计算每个粒子之间的引力
    for (int i = 0; i < N; i++) {
        particle_t *p1 = &particles[i];
        for (int j = i + 1; j < N; j++) {
            particle_t *p2 = &particles[j];
            double dx = p2->x - p1->x;
            double dy = p2->y - p1->y;
            double dz = p2->z - p1->z;

            p1->vy -= Fy / p1->mass;
            p1->vz -= Fz / p1->mass;

            p2->vy += Fy / p2->mass;
