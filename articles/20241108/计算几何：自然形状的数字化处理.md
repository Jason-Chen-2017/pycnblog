距离和角度是计算几何中常用的度量标准，它们在几何图形的分析和计算中起着重要作用。

1. **距离的计算**：在二维空间中，两点 \( P_1(x_1, y_1) \) 和 \( P_2(x_2, y_2) \) 之间的距离可以用欧几里得距离公式计算：
   \[
   d(P_1, P_2) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}

2. **角度的计算**：在二维空间中，两条线段之间的角度可以通过向量的点积和模长计算。假设有两条线段 \( \overrightarrow{AB} \) 和 \( \overrightarrow{AC} \)，它们之间的角度 \( \theta \) 可以通过以下公式计算：
   \[
   \cos(\theta) = \frac{\overrightarrow{AB} \cdot \overrightarrow{AC}}{|\overrightarrow{AB}| |\overrightarrow{AC}|}
   \]

### 第3章：点、线和多边形的表示

在计算几何中，点、线和多边形是基本几何形状，它们的表示方法直接影响几何算法的效率和准确性。本节将详细介绍这些基本几何形状的数学表示、属性以及常用的表示方法。

#### 点的表示

点在二维空间中是最简单的几何形状，通常用其横坐标 \( x \) 和纵坐标 \( y \) 来表示。一个点可以用一个坐标对 \( (x, y) \) 来表示，其中 \( x \) 和 \( y \) 分别是该点在水平轴和垂直轴上的位置。

1. **数学表示**：
   \[
   P(x, y)
   \]
   其中 \( P \) 代表点，\( x \) 和 \( y \) 分别为点的横坐标和纵坐标。

2. **属性**：
   - 坐标值唯一确定一个点。
   - 点可以表示在直角坐标系中的任何位置。

3. **表示方法**：
   - 在二维图形系统中，点通常用像素点表示。

#### 线段的表示

线段是由两个端点确定的几何形状，是连接两个点的最短路径。线段的表示方法通常使用端点的坐标。

1. **数学表示**：
   \[
   \{P_1, P_2\}
   \]
   其中 \( P_1 \) 和 \( P_2 \) 分别为线段的两个端点。

2. **属性**：
   - 线段有两个端点，端点坐标唯一确定线段。
   - 线段的长度由两个端点之间的距离决定。

3. **表示方法**：
   - 在二维图形系统中，线段通常用直线段表示，可以通过两个端点的坐标来确定其位置和长度。

#### 直线的表示

直线在二维空间中是无限延伸的，可以通过两点确定或用斜率和截距表示。

1. **两点式**：
   \[
   y - y_1 = m(x - x_1)
   \]
   其中 \( (x_1, y_1) \) 为直线上的一点，\( m \) 为直线的斜率。

2. **点斜式**：
   \[
   y - y_1 = m(x - x_1)
   \]
   其中 \( m \) 为直线的斜率，\( (x_1, y_1) \) 为直线上的一点。

3. **斜截式**：
   \[
   y = mx + b
   \]
   其中 \( m \) 为直线的斜率，\( b \) 为直线在 \( y \) 轴上的截距。

4. **属性**：
   - 直线由斜率和截距或两点唯一确定。
   - 直线可以无限延伸。

5. **表示方法**：
   - 在二维图形系统中，直线通常用直线段表示。

#### 多边形的表示

多边形是由多个线段组成的闭合几何形状，通常是凸的或凹的。多边形的表示方法通常使用顶点序列。

1. **数学表示**：
   \[
   \{V_1, V_2, ..., V_n\}
   \]
   其中 \( V_1, V_2, ..., V_n \) 分别为多边形的顶点。

2. **属性**：
   - 多边形的顶点数决定多边形的边数。
   - 多边形的形状和大小由顶点的坐标决定。
   - 多边形可以是凸的或凹的。

3. **表示方法**：
   - 在二维图形系统中，多边形通常通过顶点序列绘制。

#### 多边形的顶点表示

多边形的顶点序列可以用来唯一确定多边形的形状和大小。顶点序列通常以顺时针或逆时针方向排列。

1. **顶点序列**：
   \[
   V_1, V_2, ..., V_n
   \]
   其中 \( V_1, V_2, ..., V_n \) 分别为多边形的顶点。

2. **属性**：
   - 顶点序列决定多边形的形状和方向。
   - 顶点坐标唯一确定多边形的每个顶点。

3. **表示方法**：
   - 在二维图形系统中，顶点序列可以通过顶点坐标来绘制多边形。

#### 多边形的边界表示

多边形的边界由一系列线段组成，可以通过端点坐标来表示。边界表示是计算几何中常用的方法，特别是在算法设计和图形处理中。

1. **数学表示**：
   \[
   \{(P_1, P_2), (P_2, P_3), ..., (P_n, P_1)\}
   \]
   其中 \( P_1, P_2, ..., P_n \) 分别为多边形的顶点。

2. **属性**：
   - 边界由多个线段组成，每个线段由两个顶点确定。
   - 边界表示可以用来计算多边形的面积和周长。

3. **表示方法**：
   - 在二维图形系统中，边界表示通常通过绘制线段来实现。

#### 多边形的顶点连通性

多边形的顶点连通性是指多边形中顶点之间的连接关系。顶点连通性可以通过邻接矩阵或邻接表来表示。

1. **邻接矩阵**：
   \[
   A = \begin{bmatrix}
   0 & 1 & 0 & \ldots & 0 \\
   1 & 0 & 1 & \ldots & 0 \\
   0 & 1 & 0 & \ldots & 1 \\
   \vdots & \vdots & \vdots & \ddots & \vdots \\
   0 & 0 & 1 & \ldots & 0
   \end{bmatrix}
   \]
   其中，矩阵中的元素 \( A[i][j] \) 表示顶点 \( i \) 和顶点 \( j \) 是否相连。

2. **邻接表**：
   \[
   Adj(V_i) = \{V_j | V_iV_j 是多边形的一条边\}
   \]
   其中，\( Adj(V_i) \) 是顶点 \( V_i \) 的邻接表，包含与 \( V_i \) 相连的所有顶点。

3. **属性**：
   - 顶点连通性可以用来判断多边形中是否存在特定的边或路径。
   - 顶点连通性可以影响多边形的简化算法。

4. **表示方法**：
   - 在二维图形系统中，顶点连通性通常通过邻接矩阵或邻接表来表示和存储。

点、线和多边形是计算几何中最基本的几何形状，它们的表示方法直接影响几何算法的设计和实现。通过数学表示、属性和表示方法的详细介绍，我们可以更好地理解这些基本几何形状在计算几何中的应用。掌握这些基础知识，将为我们在计算几何领域的研究和应用提供坚实的基础。

### 第4章：距离与角度的计算

在计算几何中，距离和角度是两个重要的度量标准，它们在几何图形的分析和计算中起着关键作用。本章将详细介绍距离和角度的计算方法，以及它们在几何图形中的实际应用。

#### 距离的计算

距离是指两点之间的间隔，是计算几何中最基本的度量之一。在二维空间中，两点 \( P_1(x_1, y_1) \) 和 \( P_2(x_2, y_2) \) 之间的距离可以用欧几里得距离公式计算：

1. **欧几里得距离公式**：
   \[
   d(P_1, P_2) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
   \]

   **示例**：计算点 \( P_1(2, 3) \) 和 \( P_2(5, 7) \) 之间的距离：

   ```python
   x1, y1 = 2, 3
   x2, y2 = 5, 7
   distance = sqrt((x2 - x1)**2 + (y2 - y1)**2)
   print(distance)  # 输出：5.0
   ```

2. **曼哈顿距离**：
   \[
   d_M(P_1, P_2) = |x_2 - x_1| + |y_2 - y_1|
   \]

   **示例**：计算点 \( P_1(2, 3) \) 和 \( P_2(5, 7) \) 之间的曼哈顿距离：

   ```python
   distance = abs(x2 - x1) + abs(y2 - y1)
   print(distance)  # 输出：9
   ```

3. **切比雪夫距离**：
   \[
   d_T(P_1, P_2) = \max(|x_2 - x_1|, |y_2 - y_1|)
   \]

   **示例**：计算点 \( P_1(2, 3) \) 和 \( P_2(5, 7) \) 之间的切比雪夫距离：

   ```python
   distance = max(abs(x2 - x1), abs(y2 - y1))
   print(distance)  # 输出：3
   ```

#### 角度的计算

角度是指两条射线或线段之间的夹角，通常以度或弧度表示。在二维空间中，角度的计算可以通过向量的点积和模长来实现。

1. **点积法**：
   \[
   \cos(\theta) = \frac{\overrightarrow{AB} \cdot \overrightarrow{AC}}{|\overrightarrow{AB}| |\overrightarrow{AC}|}
   \]
   其中，\( \overrightarrow{AB} \) 和 \( \overrightarrow{AC} \) 是两条线段的向量表示，\( \theta \) 是它们之间的夹角。

   **示例**：计算线段 \( \overrightarrow{AB} \) 和 \( \overrightarrow{AC} \) 之间的夹角：

   ```python
   def dot_product(v1, v2):
       return v1.x * v2.x + v1.y * v2.y

   def magnitude(v):
       return sqrt(v.x**2 + v.y**2)

   def angleBetween(v1, v2):
       dot = dot_product(v1, v2)
       mag1 = magnitude(v1)
       mag2 = magnitude(v2)
       cos_theta = dot / (mag1 * mag2)
       theta = arccos(cos_theta)
       return theta

   v1 = Vector(3, 4)
   v2 = Vector(1, 2)
   angle = angleBetween(v1, v2)
   print(angle)  # 输出：0.7854 radians
   ```

2. **反正切函数法**：
   \[
   \theta = \arctan\left(\frac{y_2 - y_1}{x_2 - x_1}\right)
   \]
   其中，\( (x_1, y_1) \) 和 \( (x_2, y_2) \) 是两点的坐标。

   **示例**：计算点 \( P_1(1, 2) \) 和 \( P_2(3, 4) \) 之间的连线与水平轴的夹角：

   ```python
   def angleFromYIntercept(y_intercept):
       theta = atan(y_intercept)
       return theta

   y_intercept = (4 - 2) / (3 - 1)
   angle = angleFromYIntercept(y_intercept)
   print(angle)  # 输出：0.7854 radians
   ```

3. **正弦和余弦法**：
   \[
   \sin(\theta) = \frac{y}{r}, \quad \cos(\theta) = \frac{x}{r}
   \]
   其中，\( r \) 是线段的长度，\( x \) 和 \( y \) 分别是线段在水平和垂直方向上的分量。

   **示例**：计算线段 \( \overrightarrow{AB} \) 的长度和角度：

   ```python
   def magnitude(v):
       return sqrt(v.x**2 + v.y**2)

   def angleFromComponents(x, y):
       r = magnitude((x, y))
       theta = atan2(y, x)
       return theta

   v = Vector(3, 4)
   length = magnitude(v)
   angle = angleFromComponents(v.x, v.y)
   print(length)  # 输出：5.0
   print(angle)  # 输出：0.7854 radians
   ```

#### 实际应用

距离和角度的计算在计算几何中有广泛的应用，例如：

1. **几何图形的裁剪**：在图形裁剪算法中，需要计算图形边界与裁剪面的距离和夹角，以便确定裁剪区域。

3. **计算机视觉**：在计算机视觉中，如目标检测和跟踪，需要计算物体之间的距离和角度，以便确定物体的位置和运动状态。

4. **路径规划**：在机器人路径规划中，需要计算机器人当前位置与目标位置的距离和角度，以便选择最优路径。

距离和角度是计算几何中重要的度量标准，通过欧几里得距离公式、点积法、反正切函数法和正弦余弦法等多种方法，可以计算两点间的距离和两条线段间的角度。这些计算方法在几何图形的裁剪、变换、计算机视觉和路径规划等实际应用中发挥着重要作用。掌握距离和角度的计算方法，对于理解和应用计算几何具有重要意义。

### 第5章：几何图形的裁剪

几何图形的裁剪是将一个几何图形分割成几个部分的过程，这在图形学、图像处理和计算机辅助设计等领域有着广泛的应用。本章将详细介绍几何图形裁剪的基本概念、算法及其实现。

#### 裁剪的基本概念

裁剪的基本概念涉及裁剪面和裁剪区域。裁剪面是一个平面，它可以是一个平面坐标系中的直线或一个三维空间中的平面。裁剪区域是指通过裁剪面分割出的几何图形部分。

1. **二维裁剪**：在二维空间中，裁剪面通常是水平或垂直的直线，裁剪后的几何图形部分可能是多个多边形。
2. **三维裁剪**：在三维空间中，裁剪面是一个平面，裁剪后的几何图形可能是一个多面体。

#### 裁剪算法的实现

常见的裁剪算法包括线段裁剪和多边形裁剪。以下分别介绍这些算法的实现。

1. **线段裁剪算法**：

   线段裁剪算法用于将一条线段与一个裁剪面相交的部分裁剪下来。裁剪面通常是一个平面，可以通过两条平行线或一个顶点坐标和法向量来表示。

   **算法原理**：
   - 计算线段端点与裁剪面的距离。
   - 根据距离的正负判断端点是否在裁剪面的一侧。
   - 如果线段的一个端点在裁剪面的一侧，另一个端点在另一侧，则计算交点。

   **示例伪代码**：

   ```python
   function clipSegment(segment, plane):
       p1, p2 = segment
       normal = plane.normal
       d1 = dotProduct(normal, p1)
       d2 = dotProduct(normal, p2)

       if (d1 < 0 and d2 < 0) or (d1 > 0 and d2 > 0):
           return []  # 线段完全在裁剪面的一侧，裁剪后无结果

       if d1 * d2 < 0:
           t = (d2 - d1) / (d2 - d1)
           intersection = p1 + t * (p2 - p1)
           return [intersection]  # 裁剪出交点

       return [p1, p2]  # 线段未裁剪
   ```

2. **多边形裁剪算法**：

   多边形裁剪算法用于将一个多边形与一个裁剪面相交的部分裁剪下来。多边形的裁剪可以通过递归或扫描线算法实现。

   **算法原理**：
   - 将多边形和裁剪面分解为线段。
   - 对每条线段进行裁剪，保留与裁剪面相交的部分。
   - 将裁剪后的线段连接起来，形成新的多边形。

   **示例伪代码**：

   ```python
   function clipPolygon(polygon, plane):
       clipped_poly = []
       for segment in polygon:
           clipped_segment = clipSegment(segment, plane)
           if clipped_segment:
               clipped_poly.extend(clipped_segment)
       return clipped_poly
   ```

### 第6章：几何图形的变换

#### 变换的基本概念

1. **平移**：平移是指将几何图形沿着一个方向移动一定的距离。平移不会改变图形的形状和大小，只会改变其位置。
2. **旋转**：旋转是指将几何图形围绕某个点或轴旋转一定角度。旋转会改变图形的方向和位置，但不会改变其大小。
3. **缩放**：缩放是指将几何图形按照一定的比例因子放大或缩小。缩放会改变图形的大小，但不会改变其形状。
4. **反射**：反射是指将几何图形围绕某个轴进行镜像。反射会改变图形的方向，但不会改变其大小和形状。

#### 变换的实现方法

1. **二维空间中的变换**：

   在二维空间中，几何图形的变换通常通过矩阵运算实现。一个二维图形可以通过一个顶点集合 \( V = \{V_1, V_2, ..., V_n\} \) 来表示。变换可以通过以下矩阵运算实现：

   \[

   **平移**：

   \[
   M_{\text{translate}} = \begin{bmatrix}
   1 & 0 & 5 \\
   0 & 1 & 3 \\
   0 & 0 & 1
   \end{bmatrix}

   **旋转**：

   \[
   M_{\text{rotate}} = \begin{bmatrix}
   \cos(\theta) & -\sin(\theta) \\
   \sin(\theta) & \cos(\theta)
   \end{bmatrix}
   \]

   **缩放**：

   缩放可以通过乘以一个比例因子实现。例如，将图形 \( V \) 沿 x 轴和 y 轴分别放大 2 倍，可以使用以下矩阵：

   \[
   M_{\text{scale}} = \begin{bmatrix}
   2 & 0 \\
   0 & 2
   \end{bmatrix}
   \]

   **反射**：

   反射可以通过乘以一个反射矩阵实现。例如，将图形 \( V \) 关于 x 轴反射，可以使用以下矩阵：

   \[
   M_{\text{reflect}} = \begin{bmatrix}
   1 & 0 \\
   0 & -1
   \end{bmatrix}
   \]

2. **三维空间中的变换**：

   在三维空间中，几何图形的变换可以通过 4x4 矩阵实现。三维变换包括平移、旋转、缩放和反射等。以下是一个三维旋转矩阵的示例：

   \]

   **平移**：

   三维平移矩阵如下：

#### 术语解释

1. **计算几何**：研究几何形状的表示、计算和分析的数学分支。
2. **点**：二维空间中的基本几何形状，用坐标对表示。
3. **线段**：由两个端点确定的几何形状。
4. **多边形**：由一系列顶点连接形成的闭合几何形状。
5. **欧几里得距离**：两点之间的距离，通过欧几里得公式计算。
6. **向量**：表示大小和方向的量，在几何计算中用于表示形状和变换。
7. **矩阵**：用于表示和操作几何形状的数学工具。
8. **裁剪**：将几何图形分割成几个部分的过程。
9. **变换**：将几何图形按照一定规则进行移动、旋转、缩放等操作。
10. **简化**：将复杂的几何图形转换成更简单的形式。
