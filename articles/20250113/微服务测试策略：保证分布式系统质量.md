### Introduction to Markdown Formatting

Before we start, let's ensure we understand the markdown formatting requirements. Here are some key points:

- **Headers**: Use `#` symbols before text to create headers. The number of `#` symbols determines the level of the header (e.g., `##` for a sub-header under the main `#` header).
- **Lists**: Use `-` (for bullet points) or `1.` (for numbered lists).
- **Code Blocks**: Indent four spaces or one tab for code blocks.
- **Equations**: Use `$$` for equations that appear as separate paragraphs and `$` for inline equations.
- **References**: Use the standard markdown syntax for references and citations.
