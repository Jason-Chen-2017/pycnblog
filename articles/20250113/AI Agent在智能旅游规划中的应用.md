#### 1. K-Means Clustering Algorithm

K-Means is a popular unsupervised learning algorithm used for clustering data points into distinct groups. This algorithm is particularly useful for segmenting tourists based on their preferences and behavior patterns. Here is a step-by-step explanation of the K-Means algorithm:

**Algorithm Workflow:**

1. **Initialization:** Choose the number of clusters `k` and randomly initialize `k` centroids.
2. **Assignment:** Assign each data point to the nearest centroid based on Euclidean distance.
3. **Update:** Recompute the centroids as the mean of all points assigned to them.
4. **Iteration:** Repeat steps 2 and 3 until convergence (i.e., centroids do not change significantly).

**Mathematical Model:**

For a data point `x_i`, the distance to a centroid `c_j` is calculated using the Euclidean distance formula:

$$
d(x_i, c_j) = \sqrt{\sum_{i=1}^n (x_i - c_j)^2}
$$

**Python Code Implementation:**

```python
import numpy as np

def k_means(data, k, max_iterations):
    centroids = data[np.random.choice(data.shape[0], k, replace=False)]
    for _ in range(max_iterations):
        # Assign each data point to the nearest centroid
        distances = np.linalg.norm(data - centroids, axis=1)
        labels = np.argmin(distances, axis=1)
        
        # Update centroids
        new_centroids = np.array([data[labels == i].mean(axis=0) for i in range(k)])
        
        # Check for convergence
        if np.linalg.norm(centroids - new_centroids) < 1e-6:
            break
        
        centroids = new_centroids
    
    return centroids, labels

# Example usage
data = np.random.rand(100, 2)
centroids, labels = k_means(data, k=3, max_iterations=100)
```

#### 2. Collaborative Filtering Algorithm

Collaborative Filtering is an algorithm used for making personalized recommendations based on the preferences of similar users. In the context of smart tourism, this algorithm can be used to recommend tourist attractions based on the preferences of similar travelers. Here is a step-by-step explanation of the collaborative filtering algorithm:

**Algorithm Workflow:**

1. **User-Item Matrix:** Construct a user-item matrix representing user interactions with items (e.g., tourist attractions).
2. **Similarity Computation:** Compute the similarity between users or items using a distance metric (e.g., cosine similarity).
3. **Recommendation Generation:** Generate recommendations by predicting the user's preference for items based on the preferences of similar users or items.

**Mathematical Model:**

Cosine similarity between two users `u` and `v` is defined as:

$$
sim(u, v) = \frac{u^T v}{\lVert u \rVert \lVert v \rVert}
$$

**Python Code Implementation:**

```python
from sklearn.metrics.pairwise import cosine_similarity

def collaborative_filter(user_item_matrix, user_index, k=5):
    # Compute similarity matrix
    similarity_matrix = cosine_similarity(user_item_matrix)
    
    # Get top-k similar users
    similar_users = np.argsort(similarity_matrix[user_index])[1:k+1]
    
    # Compute weighted average of preferences of similar users
    preferences = user_item_matrix[similar_users].mean(axis=0)
    recommendation_score = np.dot(preferences, user_item_matrix.T)
    
    # Get top recommendations
    recommended_items = np.argsort(recommendation_score)[::-1]
    return recommended_items

# Example usage
user_item_matrix = np.random.rand(10, 20)  # 10 users and 20 attractions
recommended_items = collaborative_filter(user_item_matrix, user_index=0)
```

#### 3. Reinforcement Learning Algorithm

Reinforcement Learning is a type of machine learning where an agent learns to make decisions by interacting with an environment and receiving feedback in the form of rewards or penalties. This algorithm can be used to optimize tourist itineraries based on feedback from tourists. Here is a step-by-step explanation of the Q-Learning algorithm:

**Algorithm Workflow:**

1. **Initialization:** Initialize the Q-table with random values.
2. **Interaction:** The agent takes an action in the environment, resulting in a reward or penalty.
3. **Update:** Update the Q-table using the following equation:

$$
Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max(Q(s', a')) - Q(s, a)]
$$

where:
- `s` is the state,
- `a` is the action,
- `r` is the reward,
- `s'` is the next state,
- `a'` is the next action,
- `\alpha` is the learning rate, and
- `\gamma` is the discount factor.

**Mathematical Model:**

**Python Code Implementation:**

```python
import numpy as np

def q_learning(q_table, state, action, reward, next_state, next_action, alpha, gamma):
    q_table[state, action] = q_table[state, action] + alpha * (reward + gamma * q_table[next_state, next_action] - q_table[state, action])
    return q_table

# Example usage
q_table = np.random.rand(10, 5)  # 10 states and 5 actions
state = 0
action = 1
reward = 1
next_state = 1
next_action = 0
alpha = 0.1
gamma = 0.9
q_table = q_learning(q_table, state, action, reward, next_state, next_action, alpha, gamma)
```
