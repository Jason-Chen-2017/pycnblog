### 第1章：区块链概述

#### 1.1 区块链的基本原理

区块链是一种分布式数据库，其数据存储在多个节点上，每个节点都保存一份完整的账本。区块链的基本单位是“区块”，每个区块包含一定数量的交易记录。这些区块通过加密算法和时间戳按顺序链接在一起，形成区块链。

区块链的运作基于以下几个核心概念：

1. **共识算法**：共识算法是一种用于确定区块链上数据的真实性和完整性的方法。常见的共识算法包括工作量证明（PoW）、权益证明（PoS）和授权股权证明（DPoS）等。
2. **加密算法**：加密算法用于保护区块链上的数据和隐私。常见的加密算法包括哈希算法、公钥加密算法和数字签名等。
3. **去中心化**：去中心化意味着区块链上没有中心化的控制机构，所有节点都具有平等的地位，共同维护区块链的运行。

1. **数字身份验证**：区块链可以为数字艺术品创建唯一的数字身份，确保作品的真实性和唯一性。

pragma solidity ^0.8.0;

contract Artwork溯源 {
    // 艺术品结构体
    struct Artwork {
        string name;
        string creator;
        string timestamp;
        string currentOwner;
    }

    // 艺术品映射
    mapping(string => Artwork) public artworks;

    // 上传艺术品
    function uploadArtwork(
        string memory _name,
        string memory _creator,
        string memory _timestamp

        artworks[_name] = Artwork({
            name: _name,
            creator: _creator,
            timestamp: _timestamp,
            currentOwner: msg.sender
        });
    }

    // 更改艺术品所有权
    function changeOwnership(string memory _name, string memory _newOwner) public {
        require(artworks[_name].currentOwner == msg.sender, "Not authorized");
        artworks[_name].currentOwner = _newOwner;
    }

    // 查询艺术品信息
    function getArtworkInfo(string memory _name) public view returns (Artwork memory) {
        return artworks[_name];
    }
}
