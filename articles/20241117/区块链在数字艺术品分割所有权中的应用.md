### 区块链基础

#### 区块链概述

区块链是一种分布式数据库技术，通过多个节点共同维护一个统一的账本，实现了数据的去中心化和不可篡改。区块链的核心理念是共识机制，通过节点之间的相互验证，确保数据的真实性和完整性。

#### 区块链技术原理

区块链由多个区块组成，每个区块包含一定数量的交易记录。区块通过哈希函数与时间戳技术，与前一个区块链接形成一个链式数据结构。每个区块都包含了前一个区块的哈希值，从而形成一个全局的关联性。当一个新的区块生成时，节点之间会通过共识算法验证区块的有效性，然后将区块添加到区块链上。

#### 区块链的架构与运行机制

区块链的架构通常包括三层：数据层、网络层、共识层。数据层负责存储交易数据；网络层负责节点之间的通信和同步；共识层负责维护区块链的一致性和安全性。

#### 区块链的安全特性

区块链的安全特性主要包括：

1. **去中心化**：区块链的去中心化结构使其具有高度的容错性和抗攻击性。
2. **不可篡改**：区块链的数据一旦记录，将无法被篡改，保证了数据的真实性和完整性。
3. **透明性**：区块链的数据对所有节点都是透明的，任何用户都可以查看区块链上的交易记录。

contract ArtworkSplit {
    address owner;
    mapping(address => uint256) shares;

    constructor() {
        owner = msg.sender;
    }

    function splitOwnership(address buyer, uint256 percentage) public {
        require(msg.sender == owner, "Only the owner can split ownership");
        require(percentage <= 100, "Percentage must be less than or equal to 100");
        require(shares[buyer] == 0, "Buyer already owns a share");
