#### 隐私保护模型

区块链在数字身份隐私保护中使用的隐私保护模型主要包括同态加密和多方计算。同态加密允许在加密数据上进行计算，而不需要解密。多方计算允许多个参与方在共享数据的同时，保护各自的隐私。

1. **同态加密模型**：

   - 输入：明文数据 \( m \) 和加密密钥 \( k \)。
   - 过程：使用同态加密算法 \( HE(m) \)，将明文数据 \( m \) 加密为密文 \( c \)。
   - 输出：密文 \( c \)。

   伪代码：

   ```
   function HE(m, k):
       c = encrypt(m, k)
       return c
   ```

2. **多方计算模型**：

   - 输入：多个参与方的数据 \( m_1, m_2, ..., m_n \) 和计算密钥 \( k \)。
   - 过程：使用多方计算算法，将多个参与方的数据进行加密和计算。
   - 输出：加密后的计算结果 \( c \)。

   伪代码：

   ```
   function MPC(m_1, m_2, ..., m_n, k):
       c = encrypt(m_1, k)
       for i from 2 to n:
           c = compute(c, encrypt(m_i, k))
       return c
   ```

#### 加密算法数学公式

1. **非对称加密**：

   - 加密公式：\( E_{pub}(m) = c \)，其中 \( E_{pub} \) 是公钥加密函数，\( m \) 是明文，\( c \) 是密文。
   - 解密公式：\( D_{priv}(c) = m \)，其中 \( D_{priv} \) 是私钥解密函数。

2. **对称加密**：

   - 加密公式：\( c = E_{k}(m) \)，其中 \( E_{k} \) 是密钥加密函数，\( k \) 是密钥，\( m \) 是明文，\( c \) 是密文。
   - 解密公式：\( m = D_{k}(c) \)，其中 \( D_{k} \) 是密钥解密函数。

3. **同态加密**：

   - 加密公式：\( c' = HE(m') \)，其中 \( HE \) 是同态加密函数，\( m' \) 是明文，\( c' \) 是密文。
   - 解密公式：\( m' = D_H(c') \)，其中 \( D_H \) 是同态解密函数。
