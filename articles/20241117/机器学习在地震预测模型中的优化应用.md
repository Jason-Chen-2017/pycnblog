**项目实战**：

在监督学习中，线性回归是一种常见的算法。下面是一个简单的线性回归算法的伪代码：

```python
# 线性回归伪代码
def linear_regression(x, y):
    n = len(x)
    x_mean = sum(x) / n
    y_mean = sum(y) / n
    beta_1 = (sum(x * y) - n * x_mean * y_mean) / (sum(x**2) - n * x_mean**2)
    beta_0 = y_mean - beta_1 * x_mean
    return beta_0, beta_1
```
