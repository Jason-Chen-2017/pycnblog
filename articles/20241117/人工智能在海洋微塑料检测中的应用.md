### 3.1 海洋微塑料的定义与来源

海洋微塑料（Microplastics）是指直径小于5毫米的塑料颗粒。这些微塑料主要来源于陆地上的生活污水排放、工业生产、以及海上废弃物倾倒等活动。微塑料一旦进入海洋，就会随着海流扩散，逐渐形成复杂的分布模式。

海洋微塑料的来源可以分为以下几类：

1. **直接排放**：包括城市污水、工业废水以及农业径流等。
2. **大块塑料分解**：大块塑料在海洋环境中受到紫外线、波浪和海流的作用，逐渐分解成较小的塑料碎片。

### 3.2 海洋微塑料的危害

海洋微塑料对海洋生态环境和人类健康造成了严重的危害。首先，微塑料对海洋生物构成了直接的物理伤害，例如被海洋生物误食、缠绕在身体上等。其次，微塑料在海洋生物体内积累，可能导致生物体内毒素浓度升高，影响其生长和繁殖。此外，微塑料中的化学物质可能会释放到水体中，进一步污染海洋环境。

### 4.1 卷积神经网络（CNN）原理

卷积神经网络（Convolutional Neural Network，CNN）是一种专门用于处理图像数据的深度学习模型。它通过模拟人眼视网膜的感知机制，利用卷积层和池化层提取图像特征，从而实现图像分类、目标检测等任务。

#### 4.1.1 卷积层

卷积层是CNN的核心组成部分，它通过卷积操作提取图像中的局部特征。卷积操作可以看作是在图像上滑动一个小的过滤器（卷积核），计算每个位置上的局部特征和滤波器之间的点积。

伪代码：

```python
# 输入图像 I 和卷积核 K
for each location (i, j) in I:
    feature_map[i, j] = sum(K * I[i:i+k, j:j+k])
```

#### 4.1.2 池化层

池化层用于降低特征图的维度，提高模型的泛化能力。常见的池化操作包括最大池化和平均池化。最大池化在窗口内的最大值作为输出，而平均池化则是计算窗口内所有值的平均值。

伪代码：

```python
# 输入特征图 F 和窗口大小 k
for each location (i, j) in F:
    pooled_value[i, j] = max(F[i:i+k, j:j+k])
```

#### 4.1.3 完整的CNN模型

完整的CNN模型通常包含多个卷积层和池化层，以及全连接层。卷积层和池化层用于提取图像特征，而全连接层则用于分类。


### 4.2 循环神经网络（RNN）原理

循环神经网络（Recurrent Neural Network，RNN）是一种专门用于处理序列数据的神经网络。与传统的前馈神经网络不同，RNN具有循环结构，能够记忆和处理历史信息，使其在处理时间序列数据方面表现出色。

#### 4.2.1 基本结构

RNN的基本结构包括输入层、隐藏层和输出层。隐藏层通过循环连接将当前时刻的信息传递到下一个时刻，从而实现记忆功能。

伪代码：

```python
# 输入序列 X，隐藏状态 H，权重 W
for each time step t:
    H[t] = tanh(W * [X[t], H[t-1]])
```

#### 4.2.2 长短期记忆网络（LSTM）

为了解决传统RNN在处理长序列数据时的梯度消失和梯度爆炸问题，Long Short-Term Memory（LSTM）网络被提出。LSTM通过引入门控机制，有效地控制信息的流动，使得网络能够记忆长序列信息。

LSTM的基本结构包括输入门、遗忘门和输出门。

伪代码：

```python
# 输入 X，隐藏状态 H，遗忘门 f，输入门 i，输出门 o，权重 W
for each time step t:
    f[t] = sigmoid(W_f * [X[t], H[t-1]])
    i[t] = sigmoid(W_i * [X[t], H[t-1]])
    o[t] = sigmoid(W_o * [X[t], H[t-1]])
    g[t] = tanh(W_g * [X[t], i[t] * H[t-1]])
    H[t] = o[t] * tanh(g[t])
```

### 5.3 循环神经网络（RNN）的数学模型

循环神经网络（RNN）中的循环结构可以看作是输入序列的递归函数，其数学模型如下：

#### 5.3.1 基本RNN模型

基本RNN模型的数学模型可以用以下公式表示：

```latex
H_t = \tanh(W_h * [X_t, H_{t-1}])
Y_t = \sigma(W_y * H_t)
```

其中，\(H_t\) 表示第 \(t\) 个时间步的隐藏状态，\(X_t\) 表示第 \(t\) 个时间步的输入，\(Y_t\) 表示第 \(t\) 个时间步的输出，\(\tanh\) 表示双曲正切函数，\(\sigma\) 表示sigmoid函数，\(W_h\) 和 \(W_y\) 分别表示权重矩阵。

#### 5.3.2 LSTM模型

LSTM的数学模型更加复杂，其核心是引入了门控机制，包括输入门、遗忘门和输出门。LSTM的数学模型如下：

```latex
f_t = \sigma(W_f * [X_t, H_{t-1}])
i_t = \sigma(W_i * [X_t, H_{t-1}])
o_t = \sigma(W_o * [X_t, H_{t-1}])
g_t = \tanh(W_g * [X_t, i_t * H_{t-1}])
C_t = f_t * C_{t-1} + i_t * g_t
H_t = o_t * \tanh(C_t)
```

其中，\(f_t\)、\(i_t\)、\(o_t\) 分别表示遗忘门、输入门和输出门的输出，\(C_t\) 和 \(H_t\) 分别表示第 \(t\) 个时间步的细胞状态和隐藏状态，其他参数的含义与基本RNN模型相同。

### 5.4 模型训练与优化

在模型训练过程中，我们需要最小化损失函数，以优化模型参数。常见的损失函数包括均方误差（MSE）、交叉熵损失等。

#### 5.4.1 均方误差（MSE）

均方误差（MSE）用于回归问题，其数学模型如下：

```latex
MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
```

其中，\(y_i\) 表示第 \(i\) 个样本的真实值，\(\hat{y}_i\) 表示第 \(i\) 个样本的预测值。

#### 5.4.2 交叉熵损失

交叉熵损失用于分类问题，其数学模型如下：

```latex
CE = -\frac{1}{n} \sum_{i=1}^{n} \sum_{j=1}^{C} y_{ij} \log(\hat{y}_{ij})
```

其中，\(y_{ij}\) 表示第 \(i\) 个样本属于第 \(j\) 个类别的概率，\(\hat{y}_{ij}\) 表示第 \(i\) 个样本属于第 \(j\) 个类别的预测概率。

### 5.5 梯度下降法

在训练过程中，我们通常使用梯度下降法来优化模型参数。梯度下降法的核心思想是沿着损失函数的梯度方向更新参数，以最小化损失函数。

伪代码：

```python
for each parameter W:
    gradient = dL/dW
    W = W - learning_rate * gradient
```
