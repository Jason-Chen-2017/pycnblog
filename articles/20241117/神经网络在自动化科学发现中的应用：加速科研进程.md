#### 神经网络激活函数

神经网络中的激活函数通常用来将线性组合的神经元输出映射到非负区间。以下是一些常用的激活函数：

1. **Sigmoid函数**：
   $$\sigma(x) = \frac{1}{1 + e^{-x}}$$
   
   示例：假设输入$x = 2$，则$\sigma(2) = \frac{1}{1 + e^{-2}} \approx 0.866$。

2. **ReLU函数**：
   $$\text{ReLU}(x) = \max(0, x)$$
   
   示例：假设输入$x = -2$，则$\text{ReLU}(-2) = 0$；假设输入$x = 2$，则$\text{ReLU}(2) = 2$。

3. **Tanh函数**：
   $$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$
   
   示例：假设输入$x = 2$，则$\tanh(2) \approx 0.96$。

#### 交叉熵损失函数

交叉熵损失函数常用于分类问题，用于衡量预测分布与真实分布之间的差异。其公式如下：

$$L(y, \hat{y}) = -\sum_{i} y_i \log(\hat{y}_i)$$

其中，$y$是真实分布，$\hat{y}$是预测分布。

示例：假设真实分布$y = [0.5, 0.5]$，预测分布$\hat{y} = [0.6, 0.4]$，则交叉熵损失$L = -0.5 \log(0.6) - 0.5 \log(0.4) \approx 0.169$。
