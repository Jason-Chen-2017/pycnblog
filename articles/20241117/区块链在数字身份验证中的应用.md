#### 第4章：非对称加密算法

##### 4.1 非对称加密算法的基本概念

非对称加密算法是一种加密方式，它使用一对密钥（公钥和私钥）。公钥用于加密，私钥用于解密。

**伪代码：**
```python
# 公钥加密
def encrypt(message, public_key):
    return RSA_encrypt(message, public_key)

# 私钥解密
def decrypt(encrypted_message, private_key):
    return RSA_decrypt(encrypted_message, private_key)
```

**数学模型和公式：**
$$
c = RSA_encrypt(m, e)
$$
$$
m = RSA_decrypt(c, d)
$$
其中，\( m \) 是明文，\( c \) 是密文，\( e \) 是公钥指数，\( d \) 是私钥指数。

##### 4.2 非对称加密算法的工作原理

非对称加密算法的工作原理包括：
1. **密钥生成**：生成一对公钥和私钥。
2. **加密**：使用公钥加密信息。
3. **解密**：使用私钥解密信息。

#### 第5章：数字签名算法

##### 5.1 数字签名算法的基本概念

数字签名算法是一种用于验证消息完整性和真实性的加密技术。它使用私钥对消息进行签名，公钥用于验证签名。

**伪代码：**
```python
# 签名
def sign(message, private_key):
    return RSA_sign(message, private_key)

# 验证
def verify(message, signature, public_key):
    return RSA_verify(message, signature, public_key)
```

**数学模型和公式：**
$$
s = RSA_sign(m, d)
$$
$$
\text{valid} = RSA_verify(m, s, e)
$$
其中，\( s \) 是签名，\( \text{valid} \) 是验证结果。

##### 5.2 数字签名算法的工作原理

数字签名算法的工作原理包括：
1. **签名生成**：使用私钥对消息进行签名。
