#### 2.1.1 核心概念

垂直城市是指利用城市中高层建筑的空间，通过垂直开发来扩展城市空间的一种城市发展模式。垂直城市不仅可以提高土地利用率，还可以提供多样化的城市功能，如商业、居住、办公、运动等。

### 2.1 核心概念与原理

#### 2.1.1 垂直城市

垂直城市是一种城市发展模式，它通过高层建筑的垂直开发，最大限度地利用有限的城市空间。这种模式起源于20世纪中叶的纽约，随后在全球范围内得到广泛推广。垂直城市的核心在于通过垂直方向上的建筑布局，将居住、商业、办公等功能集成在高层建筑中，从而提高土地利用效率，缓解城市土地资源紧张的问题。

垂直城市的原理可以概括为以下几点：

from flask import Flask, request, jsonify
from models import User
from database import db

app = Flask(__name__)

@app.route('/register', methods=['POST'])
def register():
    data = request.get_json()
    username = data.get('username')
    password = data.get('password')

    if not username or not password:
        return jsonify({'error': 'Missing required fields'}), 400

    user = User.query.filter_by(username=username).first()
    if user:
        return jsonify({'error': 'User already exists'}), 409

    new_user = User(username=username, password=password)
    db.session.add(new_user)
    db.session.commit()

    return jsonify({'message': 'User registered successfully'}), 201
