### 描述性评估指标

3. **语法复杂度（Grammar Complexity）**：语法复杂度是指文本中使用的语法结构和规则复杂程度。较高的语法复杂度可能表明生成内容具有较高的语言表达能力和逻辑性。
4. **语义丰富度（Semantic Richness）**：语义丰富度是指提示词所涵盖的语义信息量和多样性。高语义丰富度的提示词可以生成更为丰富和多样化的内容。

1. **描述性评估指标**

描述性评估指标包括词频、句子长度、语法复杂度和语义丰富度。以下是一个示例代码，用于计算这些指标：

```python
import nltk
from nltk.tokenize import word_tokenize, sent_tokenize
from nltk.corpus import stopwords
from nltk.probability import FreqDist
import spacy

# 加载spacy模型
nlp = spacy.load("en_core_web_sm")

def calculate_description_metrics(content):
    # 初始化指标
    result = {
        'word_frequency': {},
        'sentence_length': 0,
        'grammar_complexity': 0,
        'semantic_richness': 0
    }

    # 计算词频
    words = word_tokenize(content)
    stop_words = set(stopwords.words('english'))
    filtered_words = [word for word in words if word.lower() not in stop_words]
    freq_dist = FreqDist(filtered_words)
    result['word_frequency'] = freq_dist

    # 计算句子长度
    sentences = sent_tokenize(content)
    result['sentence_length'] = sum(len(sentence.strip()) for sentence in sentences)

    # 计算语法复杂度
    doc = nlp(content)
    grammar_complexity = 0
    for token in doc:
        if token.dep_ in ['ROOT', 'VERB']:
            grammar_complexity += 1
    result['grammar_complexity'] = grammar_complexity

    # 计算语义丰富度
    semantic_richness = 0
    for token in doc:
        if token.dep_ == 'NOUN':
            semantic_richness += 1
    result['semantic_richness'] = semantic_richness

    return result
```
