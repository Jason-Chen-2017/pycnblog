$$C = B \log_2(1 + \frac{S}{N})$$
其中，\(C\) 是信息传输速率（以比特每秒计），\(B\) 是信道的带宽（以赫兹计），\(S\) 是信号的功率，\(N\) 是噪声的功率。

#### 4.1.2 宇宙信息压缩的数学公式和推导

宇宙信息压缩的目标是通过降低信息的熵，使其更简洁、更易处理。以下是一些用于宇宙信息压缩的基本数学公式和推导：

**熵降低公式（Entropy Reduction Formula）：**
假设有两个随机变量 \(X\) 和 \(Y\)，且 \(X\) 是 \(Y\) 的条件熵 \(H(Y|X)\)。根据信息论中的熵降低定理，有：
$$H(Y) = H(Y|X) + H(X)$$
其中，\(H(Y)\) 是 \(Y\) 的熵，\(H(Y|X)\) 是在知道 \(X\) 的条件下 \(Y\) 的熵。

**例：**
假设我们有一段由0和1组成的二进制序列 \(X\)，其中0和1的出现概率分别为 \(p_0\) 和 \(p_1\)。现在，我们引入一个随机变量 \(Y\)，它是在知道 \(X\) 的条件下，\(X\) 的熵。根据熵降低公式，有：
$$H(X) = H(Y|X) + H(X)$$
由于 \(Y\) 是在知道 \(X\) 的条件下，所以 \(H(Y|X) = 0\)，因此：
$$H(X) = H(X)$$
这意味着，如果我们能够知道 \(X\) 的具体值，那么 \(X\) 的熵将降低到0。

**数据压缩公式（Data Compression Formula）：**
在数据压缩中，我们通常使用熵编码（Entropy Coding）来降低数据的熵。熵编码的基本思想是根据数据出现的概率来编码，概率高的符号使用较短的编码，概率低的符号使用较长的编码。

**Huffman编码（Huffman Coding）：**
Huffman编码是一种常见的熵编码方法，它基于贪心算法构建一个最优的前缀编码树。对于一组符号，Huffman编码的步骤如下：

1. 计算每个符号的概率 \(p(x_i)\)。
2. 构建一个概率倒排树，其中概率高的符号在上层，概率低的符号在下层。
3. 递归地将两个概率最小的节点合并，并计算新节点的概率。
4. 继续合并，直到所有节点合并为一个根节点。
5. 根据构建的树，为每个符号分配一个二进制编码。

**Huffman编码的伪代码：**
```

    # 计算每个符号的概率
    probabilities = computeProbabilities(inputSymbols)

    tree = buildProbabilityTree(probabilities)
    
    # 构建编码树
    codingTree = buildEncodingTree(tree)
    
    # 为每个符号分配编码
    encodings = assignEncodings(codingTree)
    
    # 编码输入符号
    compressedData = encode(inputSymbols, encodings)
    
    return compressedData
```

**例：**
假设我们有一组符号 {A, B, C, D}，其概率分别为 {0.4, 0.2, 0.2, 0.2}。通过Huffman编码，我们可以得到以下编码树：

```
    *
   / \
  A   *
     / \
    B   C
     \ /
      D
```

编码结果为：A: 00, B: 01, C: 10, D: 11。这样，我们可以用4个比特来表示这组符号，比原始的8个比特更紧凑。

#### 7.1.2 宇宙信息压缩算法的类型

**1. Huffman编码：**
Huffman编码是一种基于贪心算法的熵编码方法。它通过构建一个最优的前缀编码树，为出现概率高的符号分配较短的编码，为出现概率低的符号分配较长的编码。Huffman编码具有压缩效果好、实现简单等优点，但缺点是编码和解码的时间复杂度较高。

LZ78编码是LZ77编码的改进版本，它通过构建一个预测器，更好地预测后续数据的模式。LZ78编码具有压缩效果好、实现简单等优点，但缺点是解码时间较长。

        hi = heapq.heappop(heap)
        for pair in lo[1:]:
            pair[1] = '0' + pair[1]
        for pair in hi[1:]:
            pair[1] = '1' + pair[1]
