```python
import numpy as np

def hamiltonian(qubit_state):
    # 定义哈密顿量
    ham = np.array([[1, 0], [0, -1]])
    return np.dot(ham, qubit_state)

def evolve(state, hamiltonian, time):
    # 计算演化
    return np.linalg.expm(-1j * hamiltonian * time) @ state
```

#### 代码解读

- **哈密顿量**：定义了粒子的能量结构。
- **演化**：计算了粒子的时间演化。
