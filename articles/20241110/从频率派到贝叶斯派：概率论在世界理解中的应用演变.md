## 第二部分：核心概念与联系

### 概率论的基本概念

概率论的基本概念包括概率、随机变量、概率分布等。

- **概率**：表示事件发生的可能性，通常用0到1之间的数值表示。概率可以通过频率估计，也可以通过贝叶斯定理计算。
- **随机变量**：是一个从样本空间到实数的函数，用来描述随机现象的结果。随机变量可以是离散的，也可以是连续的。
- **概率分布**：描述随机变量的概率分布情况。常见的概率分布包括正态分布、泊松分布、二项分布等。

### 频率派的核心概念

频率派的核心概念基于大量实验数据的频率来估计概率。以下是一些频率派概率论的关键概念：

- **样本空间**：所有可能结果的集合。
- **频率**：某个结果在大量实验中出现的次数与实验总次数的比值。
- **概率分布**：通过频率估计的随机变量的概率分布。
- **参数估计**：通过样本数据估计概率分布的参数，如均值、方差等。

### 贝叶斯派的核心概念

贝叶斯派的核心概念基于先验概率和观测数据来更新概率。以下是一些贝叶斯派概率论的关键概念：

- **先验概率**：基于个体知识和经验，对事件发生的可能性进行的主观估计。
- **后验概率**：在观测到新的数据后，对事件发生可能性进行的新估计。
- **贝叶斯定理**：用于计算后验概率的公式，将先验概率和观测数据结合起来。
- **贝叶斯估计**：通过贝叶斯定理进行参数估计，通常使用最大化后验概率（MAP）或贝叶斯风险（Bayes risk）。

```python
def t_test(x, y):
    # 计算均值差异
    mean_diff = sum(x) / len(x) - sum(y) / len(y)

    # 计算标准差
    std_x = sqrt(sum((x - x_mean) ** 2) / (len(x) - 1))
```

```python
# 朴素贝叶斯分类器伪代码
def naive_bayes(train_data, test_data):
    # 计算先验概率
    prior_probabilities = {class_label: len(train_data[class_label]) / len(train_data) for class_label in train_data}

    # 计算条件概率
    for feature in train_data:
        for class_label in train_data[feature]:
            conditional_probabilities[class_label][feature] = (train_data[feature][class_label] + 1) / (len(train_data) + len(train_data[feature]))

    # 分类测试数据
    for test_data_point in test_data:
        probabilities = {class_label: prior_probabilities[class_label] * product(conditional_probabilities[class_label][feature] for feature in test_data_point) for class_label in train_data}
        predicted_class = max(probabilities, key=probabilities.get)
        predicted_classes.append(predicted_class)

    return predicted_classes
```

```markdown
### 常用概率分布

1. **正态分布（Gaussian Distribution）**
   正态分布是最常见的概率分布，其概率密度函数为：
   $$ f(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} $$

2. **泊松分布（Poisson Distribution）**
   泊松分布用于描述在一定时间内发生某个事件次数的概率分布，其概率质量函数为：
   $$ P(X = k) = \frac{e^{-\lambda} \lambda^k}{k!} $$

3. **二项分布（Binomial Distribution）**
   二项分布描述了在一系列独立试验中成功次数的概率分布，其概率质量函数为：
   $$ P(X = k) = C_n^k p^k (1-p)^{n-k} $$
   其中，$n$ 是试验次数，$p$ 是每次试验成功的概率。

### 贝叶斯定理

贝叶斯定理是贝叶斯派概率论的核心公式，用于计算后验概率。其形式为：
$$ P(A|B) = \frac{P(B|A)P(A)}{P(B)} $$
其中，$P(A|B)$ 表示在事件$B$发生的条件下事件$A$的概率，$P(B|A)$ 表示在事件$A$发生的条件下事件$B$的概率，$P(A)$ 和 $P(B)$ 分别表示事件$A$和事件$B$的概率。

### 最大似然估计

最大似然估计是一种参数估计方法，通过找到使观测数据概率最大的参数值来估计参数。其形式为：
$$ \hat{\theta} = \arg\max_{\theta} P(\text{data}|\theta) $$
其中，$\hat{\theta}$ 是估计的参数值，$\theta$ 是真实的参数值。
```

1. **标准正态分布表**

2. **泊松分布表**

   - 累积分布函数：$F(X \leq k) = \sum_{i=0}^{k} P(X = i)$

3. **二项分布表**

#### 附录二：常用概率统计公式

在本文中，我们介绍了一些常用的概率统计公式，包括贝叶斯定理、最大似然估计和最小二乘法。以下是一些常用的公式及其解释：

1. **贝叶斯定理**
   - 公式：$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
   - 解释：贝叶斯定理用于计算在给定某个条件下另一个事件发生的概率。

2. **最大似然估计**
   - 公式：$\hat{\theta} = \arg\max_{\theta} P(\text{data}|\theta)$
   - 解释：最大似然估计用于估计参数值，使得观测数据的概率最大。

3. **最小二乘法**
   - 公式：$\min \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$
   - 解释：最小二乘法用于线性回归模型的参数估计，使得预测值与实际值的误差平方和最小。
