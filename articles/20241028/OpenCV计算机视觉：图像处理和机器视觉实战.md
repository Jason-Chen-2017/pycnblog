### 附录 L：实际应用案例与代码解读

- **人脸识别系统**
  - **代码实现**：
    ```python
    import cv2
    import numpy as np

    face_cascade = cv2.CascadeClassifier('haarcascade_frontalface_default.xml')

    def detect_face(image):
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
        faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5, minSize=(30, 30))
        for (x, y, w, h) in faces:
            cv2.rectangle(image, (x, y), (x+w, y+h), (255, 0, 0), 2)
            roi_gray = gray[y:y+h, x:x+w]
            roi_color = image[y:y+h, x:x+w]
        return image

    image = cv2.imread('face.jpg')
    result = detect_face(image)
    cv2.imshow('Face Detection', result)
    cv2.waitKey(0)
    cv2.destroyAllWindows()
    ```

  - **代码解读**：
    - **加载Haar级联分类器文件**：使用`CascadeClassifier`加载预训练的Haar级联分类器。
    - **将BGR图像转换为灰度图像**：使用`cvtColor`函数将图像从BGR转换为灰度图像。
    - **使用`detectMultiScale`方法检测人脸**：该方法会检测图像中的人脸区域。
    - **使用`rectangle`方法绘制人脸框**：在检测结果上绘制矩形框以标注人脸。

- **图像分类器**
  - **代码实现**：
    ```python
    import cv2
    import numpy as np

    def classify_image(image):
        hog = cv2.HOGDescriptor()
        svm = cv2.SVM_create()

        hog_features = hog.compute(image)
        svm.predict(hog_features)

        if svm.label == 1:
            return "正面"
        else:
            return "侧面"

    image = cv2.imread('face.jpg')
    result = classify_image(image)
    print("分类结果：", result)
    ```

  - **代码解读**：
    - **加载HOG描述子和SVM分类器**：使用`HOGDescriptor`和`SVM_create`加载相应的模块。
    - **计算图像的HOG特征**：使用`compute`方法提取图像的HOG特征。
    - **使用SVM分类器进行分类**：使用`predict`方法对特征进行分类。
    - **输出分类结果**：根据分类器的预测结果，输出图像的分类结果。
