AI Agent是一种能够感知环境并自主决策的智能体，能够帮助智能垃圾桶实现自动分类功能。

#### 1.2.3 AI Agent在智能垃圾桶中的作用

### 5.2 核心代码实现
以下是垃圾分类系统的Python代码示例：
```python
import cv2
import tensorflow as tf

# 数据预处理
def preprocess_image(image_path):
    image = cv2.imread(image_path)
    image = cv2.resize(image, (224, 224))
    image = image / 255.0
    return image

# 分类模型加载
model = tf.keras.models.load_model('garbage_classifier.h5')

# 图像分类
def classify_garbage(image_path):
    preprocessed_image = preprocess_image(image_path)
    prediction = model.predict(tf.expand_dims(preprocessed_image, axis=0))
    return prediction.argmax(axis=-1)[0]

# 示例
classify_garbage('garbage_image.jpg')
```
