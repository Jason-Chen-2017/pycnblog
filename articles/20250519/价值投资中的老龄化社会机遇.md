### 第1章：老龄化社会的现状与趋势

#### 1.1 老龄化社会的定义与特征
- **1.1.1 老龄化社会的定义**  
  老龄化社会是指65岁及以上人口占总人口比例超过7%的社会状态。这一趋势在全球范围内加速，尤其在发达国家和发展中国家中表现明显。

- **1.1.2 老龄化社会的特征与表现**  
  包括人口结构变化、劳动年龄人口减少、社会保障压力增加、医疗需求上升等。

- **1.1.3 全球老龄化趋势分析**  
  通过数据和图表展示全球主要国家的老龄化趋势，分析其对经济和社会的影响。

#### 1.2 老龄化社会的经济影响
- **1.2.1 老龄化对劳动力市场的冲击**  
  劳动力供给减少，导致企业用工成本上升，影响经济增长。

- **1.2.2 老龄化对社会保障体系的压力**  
  养老金支出增加，社会保障基金面临收支平衡压力。

- **1.2.3 老龄化带来的消费结构变化**  
  老年人口增加，医疗、养老和生活服务需求上升，推动相关行业增长。

#### 1.3 价值投资的基本概念
- **1.3.1 价值投资的定义与核心理念**  
  价值投资强调以低于内在价值的价格买入优质资产，长期持有，追求稳定收益。

- **1.3.2 价值投资与老龄化社会的联系**  
  老龄化社会中，医疗、养老等行业的长期需求稳定，适合价值投资。

- **1.3.3 价值投资的基本原则与方法**  
  包括基本面分析、安全边际、长期持有等。

### 第4章：价值投资的核心方法与实践

#### 4.1 价值投资的核心原理
- **4.1.1 股票内在价值的计算**  
  使用现金流折现法（DCF）计算公司股票的内在价值，公式为：
  $$
  V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}
  $$
  其中，$CF_t$ 是第t年的现金流，$r$ 是折现率，$TV$ 是终值。

- **4.1.2 财务指标分析**  
  关注市盈率（P/E）、市净率（P/B）、股息率等指标，评估股票的估值是否合理。

- **4.1.3 安全边际的确定**  
  确保买入价格低于内在价值，留有安全边际，减少投资风险。

  import pandas as pd
  def calculate_intrinsic_value(free_cash_flow, discount_rate,永续增长率):
      present_value = free_cash_flow / (1 + discount_rate)
      terminal_value = free_cash_flow * (1 +永续增长率) / (1 + discount_rate)
