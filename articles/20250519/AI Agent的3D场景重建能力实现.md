# 第4章: 3D场景重建的算法原理

## 4.1 点云处理算法

### 4.1.1 点云配准

将不同视角的点云对齐。

#### ICP算法

$$
\text{ICP}(P, Q) = \argmin_{T} \sum_{p \in P} \sum_{q \in Q} \|T(p) - q\|^2
$$

## 6.2 核心代码实现

### 6.2.1 点云配准代码

```python
import numpy as np

def icp(p, q, max_iterations=100, tolerance=1e-4):
    for _ in range(max_iterations):
        # 找最近点
        distances = np.sqrt((p[:, 0]-q[:, 0])**2 + (p[:, 1]-q[:, 1])**2)
        closest_point = q[np.argmin(distances)]
        # 计算变换矩阵
        rotation = np.array([[1, 0], [0, 1]])
        translation = closest_point - np.mean(p, axis=0)
        # 更新点云
        p = np.dot(p, rotation.T) + translation
        if np.sum(distances) < tolerance:
            break
    return p, rotation, translation
```

class DepthEstimator(nn.Module):
    def __init__(self):
        super(DepthEstimator, self).__init__()

            nn.Conv2d(3, 64, 3, padding=1),
