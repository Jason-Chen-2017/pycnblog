### 5.2 核心代码实现
```python
import numpy as np
import pandas as pd
from sklearn import svm
from sklearn.linear_model import LinearRegression

# 数据预处理
data = pd.read_csv('market_data.csv')
data = data.dropna()
data = (data - data.mean()) / data.std()

# 模型训练
X = data.iloc[:, :-1]
y = data.iloc[:, -1]

model_lr = LinearRegression()
model_lr.fit(X, y)

model_svm = svm.SVR(kernel='rbf')
model_svm.fit(X, y)
```
