## 第一部分：价值投资与智能办公空间的背景介绍

### 第1章：价值投资的基本概念

#### 1.1 价值投资的定义与核心理念
价值投资是一种以企业的内在价值为基础的投资策略，强调长期持有优质资产，寻找市场价格低于内在价值的投资机会。核心理念包括安全边际、企业的财务健康状况和管理层质量等。这种投资策略在长期表现出色，尤其在市场波动中表现稳定。

#### 1.2 智能办公空间的定义与发展趋势
智能办公空间是利用物联网、人工智能和大数据等技术构建的智能化办公环境。发展趋势包括智能化、个性化、绿色化和远程办公支持。智能办公空间通过自动化管理、能源优化和提升员工效率，显著影响企业的运营成本和员工生产力。

#### 1.3 价值投资与智能办公空间的结合
价值投资与智能办公空间的结合体现在通过技术手段评估办公空间的价值，寻找具备长期增值潜力的智能办公项目。这种结合不仅改变了传统的办公模式，也为投资者提供了新的价值增长点。

from sklearn.linear_model import LinearRegression

# 数据加载
data = pd.read_csv('office_space.csv')

# 特征与目标分离

y = data['value']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测

prediction = model.predict(new_office)
print("预测价值：", prediction[0])
