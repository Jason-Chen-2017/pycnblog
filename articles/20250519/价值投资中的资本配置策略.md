### 第一部分: 资本配置的理论基础

#### 第1章: 现代投资组合理论（MPT）

##### 1.1 现代投资组合理论的起源与发展
现代投资组合理论（Modern Portfolio Theory, MPT）由哈里·马科维茨（Harry Markowitz）在1952年提出，是资本配置的重要理论基础。MPT的核心思想是通过合理分配资金到不同的资产类别，构建一个在给定风险水平下收益最大化的投资组合，或在给定收益下风险最小化的投资组合。

**核心概念：**
- **有效前沿曲线**：表示在给定风险水平下，能够提供最高预期收益的投资组合的集合。
- **风险与收益的权衡**：投资者可以通过调整资产配置来平衡风险和收益。

**数学模型：**
MPT的核心公式是均值-方差优化模型：
$$\text{目标函数：} \quad \min_w \left( \sigma^2(w) \right) \quad \text{或} \quad \max_w \left( \mu^T w \right)$$  
$$\text{约束条件：} \quad w^T \mathbf{1} = 1, \quad w \geq 0$$  
其中，\(w\) 是权重向量，\(\mu\) 是资产的期望收益向量，\(\sigma^2(w)\) 是投资组合的方差。

##### 1.2 风险与收益的平衡
风险与收益是资本配置的核心考量因素。投资者需要在两者之间找到平衡点，以实现长期的超额收益。

**夏普比率**：衡量投资组合相对于无风险收益率的超额收益能力：
$$\text{夏普比率} = \frac{E[r_p] - r_f}{\sigma_p}$$  
其中，\(E[r_p]\) 是投资组合的预期收益，\(r_f\) 是无风险收益率，\(\sigma_p\) 是投资组合的收益标准差。

**特雷诺比率**：衡量投资组合在给定风险下的超额收益：
$$\text{特雷诺比率} = \frac{E[r_p] - r_f}{\sqrt{\text{VaR}_p^2}}$$  
其中，\(\text{VaR}_p\) 是投资组合的风险价值（Value at Risk）。

##### 3.2 核心实现源代码
以下是资本配置的核心实现代码：

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

# 示例数据：资产的期望收益和协方差矩阵
mu = np.array([0.1, 0.15, 0.08])
cov_matrix = np.array([[0.16, 0.05, 0.02],
                        [0.05, 0.20, 0.01],
                        [0.02, 0.01, 0.10]])

# 目标函数：最小化风险（方差）
def portfolio_variance(weights):
    return np.dot(weights.T, np.dot(cov_matrix, weights))

# 约束条件：权重之和为1
def constraint(weights):
    return np.sum(weights) - 1

# 解决优化问题
initial_guess = np.array([1/3, 1/3, 1/3])
results = minimize(portfolio_variance, initial_guess, 
                   method='SLSQP', 
                   constraints={'type': 'eq', 'fun': constraint})

# 输出最优权重
print("最优权重：", results.x)
print("最小方差：", results.fun)
```

### 最佳实践 Tips：
- **定期回顾**：市场环境不断变化，资本配置需要定期调整。
- **分散投资**：避免过度集中于某一资产类别，降低风险。
- **长期视角**：价值投资注重长期收益，避免短期波动的干扰。
