## 第一部分: 高通胀环境下的经济与投资背景

### 第1章: 高通胀环境的经济基础

#### 1.1 高通胀的定义与特征
高通胀是指物价水平在短时间内持续快速上涨，通常由货币供应增加、需求拉动或成本推动等因素引发。其主要特征包括：
- 物价上涨速度快，货币购买力下降。
- 经济不确定性增加，市场情绪波动加剧。
- 利率上升，企业融资成本增加。

#### 1.2 格雷厄姆投资策略概述
格雷厄姆的价值投资理念强调寻找被市场低估的股票，其核心是通过分析企业的基本面，寻找安全边际（即市场价格远低于其内在价值）。

- **安全边际**：通过比较市场价格与内在价值，确保投资的安全性。
- **内在价值**：通过对企业盈利能力、资产状况和未来现金流的分析，估算股票的真正价值。

#### 1.3 高通胀对股市的影响
高通胀对股市的影响是多方面的：
- 企业盈利下降：成本上升，利润率减少。
- 股价波动加剧：市场情绪不稳定，价格波动大。
- 资金流向改变：资金可能从股市流向其他避险资产。

## 第三部分: 格雷厄姆策略的算法原理

### 第4章: 格雷厄姆策略的数学模型

#### 4.1 内在价值计算公式
内在价值的计算公式：
$$
\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t}
$$
其中，\( r \) 是折现率，\( \text{现金流}_t \) 是第 \( t \) 年的现金流。

#### 4.2 安全边际计算公式
安全边际的计算公式：
$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

#### 4.3 投资决策标准
- 如果 \( \text{安全边际} > 0 \)，则投资。
- 如果 \( \text{安全边际} \leq 0 \)，则避免投资。

#### 6.2 核心代码实现

import pandas as pd
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate):
    return np.sum(cash_flows / (1 + discount_rate) ** np.arange(len(cash_flows)))

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
cash_flows = [100, 120, 150, 200]
discount_rate = 0.08
market_price = 100

# 计算内在价值
intrinsic_value = calculate_intrinsic_value(cash_flows, discount_rate)

# 计算安全边际
margin_of_safety = calculate_margin_of_safety(intrinsic_value, market_price)

print(f"内在价值: {intrinsic_value:.2f}")
print(f"安全边际: {margin_of_safety:.2f}")
