# 第2章: 时间序列分析的核心原理

## 2.1 时间序列的基本特征

时间序列数据通常具有趋势性、周期性和随机性。趋势性指数据整体上升或下降；周期性指数据呈现固定周期的波动；随机性指无规律的波动。例如，季度销售额可能有季节性趋势。

## 2.2 时间序列的分解模型

时间序列分解模型将数据分为趋势、周期、季节性和噪声四个部分。常用模型包括加法模型和乘法模型。加法模型假设各成分相互独立，乘法模型假设各成分相互影响。例如，加法模型：$y_t = T_t + S_t + R_t + e_t$。

## 2.3 时间序列的预测方法

时间序列预测方法包括传统统计方法（如移动平均法）和机器学习方法（如ARIMA、LSTM）。统计方法适用于简单场景，机器学习方法适用于复杂场景。例如，ARIMA模型通过自相关性和偏自相关性分析数据特征。

## 2.4 时间序列的异常检测

时间序列异常检测方法包括基于统计的方法（如Z-score）和基于机器学习的方法（如Isolation Forest）。统计方法简单，但可能漏检复杂异常；机器学习方法捕捉复杂模式。例如，Z-score方法检测偏离均值的异常值。

## 2.5 本章小结

本章详细讲解了时间序列的基本特征和分解模型，介绍了预测与异常检测的方法，为后续章节的算法讲解奠定基础。

# 第4章: 时间序列分析的经典算法

## 4.1 ARIMA模型

ARIMA（自回归积分滑动平均模型）适用于线性时间序列数据。模型由自回归（AR）部分、积分（I）部分和滑动平均（MA）部分组成。ARIMA模型的公式为：

$$ ARIMA(p, d, q) = y_t = c + \sum_{i=1}^p \phi_i y_{t-i} + \sum_{j=1}^d \theta_j e_{t-j} + \epsilon_t $$

ARIMA模型适用于平稳时间序列数据，如月度销售数据。

## 4.2 LSTM网络

LSTM（长短期记忆网络）通过细胞状态和门控机制捕捉时间序列的长期依赖。LSTM结构包括输入门、遗忘门和输出门。LSTM模型适用于非平稳时间序列数据，如股票价格预测。

## 4.3 Prophet模型

Prophet模型由Facebook开源，适用于具有明确时间依赖性的数据。模型结合了回归和时间序列分析，公式为：

$$ y_{t+h} = \beta_0 + \beta_1 h + g(y_t, h) $$

Prophet模型适用于日志数据和销售预测。

## 4.4 本章小结

本章介绍了时间序列分析的三种经典算法，包括ARIMA、LSTM和Prophet模型，为后续章节的AI Agent实现提供理论基础。

# 第6章: 时间序列异常检测算法

## 6.1 基于统计的方法

基于统计的异常检测方法包括Z-score和t检验。Z-score方法通过计算数据点与均值的距离判断异常值。例如，Z-score > 3或Z-score < -3时，判断为异常值。

## 6.2 基于深度学习的方法

基于深度学习的异常检测方法包括AE（自编码器）和VAE（变分自编码器）。AE通过重构损失判断异常值，VAE通过KL散度判断异常值。例如，AE模型用于网络流量异常检测。

## 6.3 基于AI Agent的异常检测

基于AI Agent的异常检测方法结合统计和深度学习方法，实现自动化检测。AI Agent实时监控数据流，自动触发报警。例如，AI Agent可以检测生产线中的异常设备状态。
