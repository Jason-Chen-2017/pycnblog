# 第3章：算法原理讲解

## 3.1 股市估值算法

### 3.1.1 市盈率模型

市盈率（P/E）是衡量股票价值的重要指标，公式为：

$$P/E = \frac{Price}{Earnings}$$

其中，Price为股票价格，Earnings为每股收益。

### 3.1.2 现金流折现模型（DCF）

DCF模型通过折现未来现金流来评估公司价值：

$$DCF = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n}$$

其中，CF_t为第t年的现金流，r为折现率，TV为终值。
