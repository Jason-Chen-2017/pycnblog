- **1.1.1 全球股市估值的现状与挑战**
  - 股市估值受多种因素影响，包括经济指标、政策变化和环境因素。

- **1.1.2 海洋塑料污染的严重性与影响**
  - 海洋塑料污染对生态系统造成威胁，影响渔业和旅游业。
  - 环境问题对企业声誉和运营成本有直接影响。

- **1.1.3 两者的潜在关联性**
  - 降解技术可减少环境影响，间接提升企业估值。
  - 投资者关注可持续发展，环保技术可能成为投资新方向。

##### 1.2 核心概念的定义与外延
- **1.2.1 全球股市估值的核心要素**
  - 包括市盈率、市净率等指标。
  - 企业财务状况和行业趋势影响估值。

- **1.2.2 海洋塑料降解技术的关键特征**
  - 技术效率、成本效益、环境影响。
  - 包括生物降解、化学降解和机械处理方法。

- **1.2.3 两者关系的边界与外延**
  - 环境因素是连接两者的桥梁。
  - 降解技术可能影响企业估值，但需考虑市场反应。

from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载

# 特征与目标变量分离
X = data[['plastic_pollution', 'economic_factors']]
y = data['stock_valuation']

# 模型训练

model.fit(X, y)

# 模型预测
predictions = model.predict(X)

# 模型评估
print('R² Score:', r2_score(y, predictions))
