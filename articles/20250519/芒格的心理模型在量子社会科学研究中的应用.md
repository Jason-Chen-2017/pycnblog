## 第3章：算法原理

### 3.1 量子概率模型
量子概率模型利用量子态的叠加特性，表示个体行为的概率分布。通过构建概率幅，可以计算出观测概率，捕捉个体决策中的量子效应。

### 3.2 算法步骤
1. 初始化量子态。
2. 应用操作算符。
3. 测量结果，计算概率。

### 3.3 Python代码示例
```python
import numpy as np

# 定义量子态
state = np.array([1, 0])
# 应用哈密顿算符
H = np.array([[0.5, 0.5], [0.5, 0.5]])
new_state = np.dot(H, state)
# 测量
prob = np.abs(new_state[0])**2
print("测量概率为:", prob)
```

### 3.4 数学模型
量子态的叠加表示为：
$$
|\psi\rangle = a|0\rangle + b|1\rangle
$$
其中，$a^2 + b^2 = 1$，概率幅$a$和$b$决定了测量结果的概率。
