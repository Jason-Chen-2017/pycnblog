### 2.1.2 数学模型

**概率模型与贝叶斯公式**

1. **贝叶斯公式**：用于计算垃圾类型出现的概率。
   
   $$P(H|E) = \frac{P(E|H) \cdot P(H)}{P(E)}$$

   其中，$P(H|E)$ 是在已知证据 $E$ 下，假设 $H$ 为真的概率；$P(E|H)$ 是在假设 $H$ 为真的情况下，证据 $E$ 出现的概率；$P(H)$ 是假设 $H$ 的先验概率；$P(E)$ 是证据 $E$ 的总概率。

**支持向量机（SVM）模型**

1. **SVM公式**：用于求解最优分类超平面。

   $$w \cdot x - b = 0$$

   其中，$w$ 是分类超平面法向量；$x$ 是样本特征向量；$b$ 是偏置项。

### 2.1.3 算法优化

**支持向量机优化**

1. **核函数选择**：选择合适的核函数，如线性核、多项式核、径向基核等，提高分类效果。
2. **参数调整**：调整SVM模型的参数，如惩罚参数 $C$、核参数等，优化模型性能。

**决策树与随机森林**

2. **随机森林**：集成多个决策树，提高分类准确率和泛化能力。

### 3.1.3 代码实现

**Python代码实现垃圾分类算法**

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC
from sklearn.pipeline import make_pipeline

# 数据集加载
data = load_data('garbage_data.csv')

# 特征提取与模型训练
model = make_pipeline(TfidfVectorizer(), SVC(kernel='linear'))
model.fit(data['text'], data['label'])

# 垃圾识别
input_word = '塑料瓶'
result = model.predict([input_word])

print('分类结果：', result)
```
