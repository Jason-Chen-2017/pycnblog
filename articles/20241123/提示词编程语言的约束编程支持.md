```python
function constraintSolve(constraintExpression):
    solutionSpace = initializeSolutionSpace(constraintExpression)
    while solutionSpace is not empty:
        constraint = selectConstraint(solutionSpace)
        solutionSpace = applyConstraintPropagation(solutionSpace, constraint)
        if solutionSpace is empty:
            return "No solution found"
        else:
            return solutionSpace
```
