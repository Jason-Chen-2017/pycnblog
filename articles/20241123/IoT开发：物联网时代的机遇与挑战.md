#### 1.1 物联网（IoT）的起源与发展

物联网（Internet of Things，简称IoT）的概念最早可以追溯到20世纪80年代。当时，美国卡内基梅隆大学的教授凯文·阿什顿（Kevin Ashton）首次提出了物联网的概念。他将物联网描述为一种将各种物品通过传感器、互联网等技术连接起来，实现智能化管理和控制的新型网络体系。然而，真正意义上的物联网发展始于21世纪初，随着无线通信技术、传感器技术和互联网技术的快速发展，物联网逐步成为信息技术领域的重要方向。

物联网技术的发展历程可以分为三个阶段：

**1.1.1 物联网的概念**

物联网的概念包含两层含义：第一层是将各种物品通过网络连接起来，实现信息的互联互通；第二层是在此基础上，通过数据分析和智能化处理，实现对物品的智能管理和控制。物联网的核心在于“物”与“网”的结合，通过信息的传递和处理，实现物理世界的数字映射和智能化管理。

**1.1.2 物联网技术的发展历程**

- **第一阶段（1990年代-2000年初期）：初步探索阶段**：这一阶段主要是一些高校和研究机构对物联网技术进行初步的探索和研究，提出了许多关于物联网的概念和设想。

- **第二阶段（2000年初期-2010年）：技术成熟与商业化阶段**：随着无线通信技术、传感器技术、云计算等技术的发展，物联网技术逐渐成熟，开始进入商业化阶段。这个时期，物联网技术开始在一些特定的领域得到应用，如智能家居、智能交通、智能医疗等。

- **第三阶段（2010年至今）：大规模应用与普及阶段**：物联网技术在这一阶段得到了飞速发展，各种应用场景不断扩展，应用领域也逐渐多元化。特别是在5G技术的推动下，物联网的应用场景得到了极大的扩展，如工业物联网、智慧城市、智能农业等。

**1.1.3 物联网的关键技术**

物联网的实现离不开以下几个关键技术：

- **通信技术**：物联网的通信技术是实现设备互联和数据传输的基础。目前，物联网的通信技术主要包括无线通信技术和有线通信技术。无线通信技术如Wi-Fi、蓝牙、Zigbee、NFC等，而有线通信技术则包括以太网、光纤等。

- **传感器技术**：传感器是物联网系统的感知器官，用于采集物理世界中的各种信息。传感器技术包括温度传感器、湿度传感器、光传感器、压力传感器等，这些传感器能够将物理信号转化为电信号，为数据处理提供基础。

- **数据处理技术**：物联网产生的数据量非常庞大，如何高效地处理这些数据是物联网技术发展的重要方向。数据处理技术包括数据采集、传输、存储、分析等环节。

- **安全技术**：随着物联网应用的广泛普及，安全问题变得越来越重要。物联网的安全技术包括数据加密、身份认证、访问控制等，用于保护物联网系统的安全。

#### 1.2 物联网时代的机遇与挑战

**1.2.1 物联网带来的商业机遇**

物联网技术的快速发展带来了巨大的商业机遇。首先，物联网技术可以提升企业的生产效率和管理水平，降低生产成本。其次，物联网技术可以创造新的商业模式，如智能硬件、云服务、数据分析等。此外，物联网技术还可以推动产业升级和转型，为经济发展注入新的活力。

**1.2.2 物联网面临的挑战**

尽管物联网带来了巨大的商业机遇，但同时也面临着诸多挑战。首先，物联网系统的复杂性高，涉及多个技术领域，如通信、传感器、数据处理等，如何整合这些技术，实现系统的协同运作是一个重要问题。其次，物联网数据的安全问题也是一个严峻的挑战，如何保护数据的安全和隐私，防止数据泄露和恶意攻击，需要采取有效的安全措施。

## 第二部分 物联网核心技术

### 2.1 物联网通信技术

物联网通信技术是物联网系统的关键组成部分，负责实现设备之间的互联互通和数据传输。物联网通信技术可以分为无线通信技术和有线通信技术。在本节中，我们将详细探讨无线通信技术中的主要技术，包括蜂窝网络、低功耗广域网（LPWAN）以及其他无线通信技术，以及有线通信技术中的传统有线网络和电力线通信（PLC）。

#### 2.1.1 无线通信技术

无线通信技术是物联网通信技术中的核心，它通过无线信号实现数据传输，具有灵活性强、部署便捷等优点。

**2.1.1.1 蜂窝网络**

蜂窝网络是一种基于蜂窝结构进行通信的网络，它通过基站和移动设备之间的无线信号传输实现数据传输。蜂窝网络包括2G、3G、4G和5G等多种标准，其中5G技术是目前最先进的蜂窝网络技术。

- **2G**：2G是第二代移动通信技术，它支持语音和数据传输，但数据传输速率较低，主要用于语音通信。

- **3G**：3G是第三代移动通信技术，它支持高速数据传输，可以提供更高质量的语音和视频通信。

- **4G**：4G是第四代移动通信技术，它支持更高的数据传输速率，可以提供稳定的高速网络连接，是移动互联网的重要基础。

- **5G**：5G是第五代移动通信技术，它具有更高的数据传输速率、更低的延迟和更大的网络容量。5G技术在物联网中的应用具有重要意义，它可以为海量物联网设备提供稳定、高效的通信服务。

**2.1.1.2 低功耗广域网（LPWAN）**

低功耗广域网（LPWAN）是一种专门为物联网应用设计的无线通信技术，它具有低功耗、长距离传输、低成本等特点，适用于广泛分布的物联网设备。LPWAN技术包括以下几种：

- **LoRa**：LoRa（Long Range）是一种基于扩频技术的LPWAN技术，具有长距离、低功耗、低成本的特点，适用于低速率数据传输。

- **NB-IoT**：NB-IoT（Narrow Band Internet of Things）是一种基于蜂窝网络的新型LPWAN技术，它通过利用现有的2G、3G、4G网络频谱，实现低功耗、广覆盖的物联网通信。

- **eMTC**：eMTC（Enhanced Machine Type Communication）是另一种基于蜂窝网络的LPWAN技术，它通过增强LTE技术，提供更高的数据传输速率和更低的功耗。

**2.1.1.3 其他无线通信技术**

除了蜂窝网络和LPWAN技术外，物联网中还使用其他一些无线通信技术，如Wi-Fi、蓝牙、Zigbee等。

- **Wi-Fi**：Wi-Fi是一种无线局域网技术，通过无线信号实现高速数据传输。Wi-Fi技术适用于家庭、办公室等局域范围内的物联网设备连接。

- **蓝牙**：蓝牙是一种短距离无线通信技术，通过蓝牙模块实现设备之间的通信。蓝牙技术适用于智能家居、智能穿戴设备等短距离物联网应用。

- **Zigbee**：Zigbee是一种低功耗、短距离的无线通信技术，通过Zigbee模块实现设备之间的通信。Zigbee技术适用于家庭自动化、智能照明等物联网应用。

#### 2.1.2 有线通信技术

有线通信技术是通过物理线路实现数据传输的技术，具有传输速率高、稳定性好等优点。在物联网通信中，有线通信技术主要用于连接传感器、控制器等设备。

**2.1.2.1 传统有线网络**

传统有线网络包括以太网、光纤等，它们通过物理线路实现数据传输。

- **以太网**：以太网是一种常用的局域网通信技术，通过双绞线或光纤实现数据传输。以太网技术适用于办公室、家庭等局域范围内的物联网设备连接。

- **光纤**：光纤是一种通过光纤传输数据的通信技术，具有高速、稳定的优点。光纤技术适用于大型园区、城市等广域范围内的物联网设备连接。

**2.1.2.2 电力线通信（PLC）**

电力线通信（Power Line Communication，PLC）是一种利用电力线路进行数据传输的技术。PLC技术通过调制电力线路中的信号，实现数据传输。

- **PLC技术原理**：PLC技术通过在电力线路中注入高频信号，将数据调制到高频信号上，然后通过电力线路传输到接收端，接收端通过解调信号，还原数据。

- **PLC应用场景**：PLC技术适用于智能家居、智能照明、智能电力设备等物联网应用，可以实现设备之间的互联互通。

#### 2.1.3 物联网通信技术的选择

在选择物联网通信技术时，需要根据应用场景、设备数量、传输距离、功耗要求等因素进行综合考虑。

- **应用场景**：根据应用场景选择合适的通信技术。例如，在智能家居应用中，可以使用Wi-Fi或蓝牙技术；在远程监控应用中，可以使用LoRa或NB-IoT技术。

- **设备数量**：设备数量是选择通信技术的重要依据。对于设备数量较多的应用场景，需要选择支持大量设备接入的通信技术，如LoRa或NB-IoT。

- **传输距离**：传输距离是选择通信技术的重要因素。对于需要长距离传输的应用场景，需要选择具有长距离传输能力的通信技术，如LoRa或光纤。

- **功耗要求**：功耗要求是选择通信技术的重要依据。对于功耗要求较低的应用场景，需要选择低功耗通信技术，如蓝牙或Zigbee。

通过综合考虑以上因素，可以选择合适的物联网通信技术，实现设备之间的互联互通和数据传输。

总之，物联网通信技术是实现物联网系统互联互通和数据传输的基础。通过合理选择和应用物联网通信技术，可以实现物联网系统的可靠、高效运行，为物联网应用提供坚实的技术保障。

## 2.2 物联网数据处理与存储技术

物联网数据处理与存储技术是物联网系统的重要组成部分，负责处理和管理从传感器和设备收集的大量数据。在本节中，我们将深入探讨物联网数据处理与存储技术的各个方面，包括数据采集与传输、数据处理、数据存储，以及相关的技术细节和最佳实践。

#### 2.2.1 数据采集与传输

物联网系统的数据采集与传输是整个数据处理过程的基础。数据采集是指通过各种传感器和设备收集环境中的物理信息，如温度、湿度、光照、运动等。这些传感器采集到的数据通常以数字信号或模拟信号的形式存在。

**2.2.1.1 传感器与采集设备**

传感器的选择和部署是数据采集的关键。不同类型的传感器适用于不同的环境，如温度传感器、湿度传感器、光照传感器等。传感器通常连接到采集设备，如数据采集器或网关，这些设备负责将传感器数据转换为数字信号，并进行初步处理。

**2.2.1.2 数据格式与传输协议**

物联网数据在传输过程中需要遵循一定的格式和协议。常用的数据格式包括JSON、XML、CSV等，它们可以方便地表示和解析数据。数据传输协议如HTTP、MQTT、CoAP等，用于在网络中传输数据。

- **HTTP**：超文本传输协议（HTTP）是一种常用的网络协议，适用于请求-响应模型的数据传输。

- **MQTT**：消息队列遥测传输（MQTT）是一种轻量级的消息传输协议，适用于低带宽、不可靠的网络环境，非常适合物联网应用。

- **CoAP**：约束应用协议（CoAP）是一种基于HTTP协议的物联网协议，适用于资源受限的设备。

#### 2.2.2 数据处理

物联网数据的处理是指对采集到的原始数据进行清洗、转换、分析和挖掘，以提取有价值的信息。数据处理通常包括以下几个步骤：

**2.2.2.1 数据清洗与预处理**

数据清洗是数据处理的第一步，目的是去除数据中的错误、重复和异常值，提高数据质量。数据预处理包括数据转换、归一化、标准化等操作，以适应后续的分析和存储。

**2.2.2.2 数据分析**

数据分析是对处理后的数据进行统计和分析，以发现数据中的模式、趋势和关联关系。数据分析可以采用各种算法和工具，如回归分析、聚类分析、时间序列分析等。

**2.2.2.3 数据挖掘**

数据挖掘是更深层次的数据分析，旨在从大量数据中自动发现隐藏的规律和知识。数据挖掘可以使用机器学习和人工智能技术，如决策树、神经网络、支持向量机等。

#### 2.2.3 数据存储

物联网数据的存储是数据处理的关键环节，需要考虑数据量、数据类型、数据访问速度等因素。常用的数据存储技术包括数据库、缓存、文件系统等。

**2.2.3.1 数据库选择**

物联网数据存储通常采用数据库技术，常用的数据库类型包括关系型数据库（如MySQL、PostgreSQL）和NoSQL数据库（如MongoDB、Cassandra）。

- **关系型数据库**：关系型数据库适用于结构化数据存储，具有事务处理能力，适用于需要复杂查询的场景。

- **NoSQL数据库**：NoSQL数据库适用于非结构化或半结构化数据存储，具有高扩展性和高性能，适用于大数据场景。

**2.2.3.2 数据库优化**

为了提高数据存储和访问的性能，需要对数据库进行优化。数据库优化包括索引设计、查询优化、缓存策略等。

- **索引设计**：索引是加快数据库查询速度的重要手段，适用于频繁查询的字段。

- **查询优化**：查询优化是通过优化SQL语句和数据库结构，提高查询性能。

- **缓存策略**：缓存是将数据临时存储在内存中，以减少数据库访问频率，提高系统性能。

#### 2.2.4 最佳实践

在实际的物联网数据处理与存储中，最佳实践包括以下几个方面：

- **数据分层存储**：将数据按重要性和访问频率分层存储，重要数据存储在高速存储设备中，不经常访问的数据存储在低速存储设备中。

- **数据压缩与加密**：数据压缩可以减少存储空间和传输带宽，数据加密可以提高数据安全性。

- **数据备份与恢复**：定期备份数据，并确保备份的完整性和可用性，以便在数据丢失或损坏时进行恢复。

- **性能监控与优化**：实时监控系统的性能指标，及时发现和解决性能瓶颈。

通过遵循这些最佳实践，可以确保物联网数据处理的效率和数据存储的安全性。

#### 2.2.5 项目实战

以下是一个简单的物联网数据处理与存储项目实战案例：

**项目背景**：一个智能家居系统需要收集并处理各种传感器数据，如温度、湿度、光照等，以便实现智能调控。

4. **数据存储**：将处理后的数据存储在MySQL数据库中。

5. **数据查询与分析**：通过SQL语句查询数据，使用数据分析工具进行进一步分析。

通过这个项目，可以深入了解物联网数据处理与存储的各个环节，掌握相关技术细节和最佳实践。

总之，物联网数据处理与存储技术是物联网系统的重要组成部分，通过合理的数据采集、传输、处理和存储，可以实现物联网系统的智能化管理和控制。随着物联网技术的不断发展，数据处理与存储技术也将不断演进，为物联网应用提供更高效、更安全、更可靠的支持。

## 2.3 物联网安全技术

物联网技术的广泛应用带来了诸多便利，但同时也伴随着一系列的安全挑战。物联网系统由于其庞大的设备数量、复杂的网络结构和多样化的应用场景，使得其安全性问题尤为突出。在本节中，我们将深入探讨物联网安全技术，包括物联网安全威胁与挑战、物联网安全防护措施等内容。

#### 2.3.1 物联网安全威胁与挑战

物联网安全威胁可以分为网络层安全威胁、应用层安全威胁和物理层安全威胁。

**2.3.1.1 网络层安全威胁**

网络层安全威胁主要涉及物联网设备的通信过程。以下是一些常见的网络层安全威胁：

- **DDoS攻击**：分布式拒绝服务（DDoS）攻击是一种常见的网络层攻击方式，攻击者通过控制大量僵尸设备向目标服务器发送大量请求，导致服务器瘫痪。

- **中间人攻击（MITM）**：中间人攻击是一种拦截和篡改通信数据的安全威胁，攻击者插入自己作为通信的第三方，窃取敏感信息或进行恶意操作。

- **网络嗅探**：网络嗅探是指攻击者使用工具捕获网络中的数据包，以获取敏感信息，如用户名、密码等。

- **恶意软件传播**：恶意软件如病毒、木马等可以在物联网设备中传播，导致设备失控或数据泄露。

**2.3.1.2 应用层安全威胁**

应用层安全威胁主要涉及物联网设备的应用程序和用户数据。以下是一些常见的应用层安全威胁：

- **数据泄露**：物联网设备处理和存储的大量敏感数据，如用户个人信息、隐私数据等，容易成为数据泄露的目标。

- **应用漏洞**：物联网设备中的应用程序可能存在漏洞，如代码缺陷、配置错误等，这些漏洞可以被攻击者利用进行攻击。

- **身份验证攻击**：攻击者通过伪造身份验证信息，如用户名和密码，非法访问物联网设备或系统。

- **业务流程攻击**：攻击者通过伪造请求或篡改业务流程，如虚假订单、恶意交易等，破坏物联网设备的正常运行。

**2.3.1.3 物理层安全威胁**

物理层安全威胁主要涉及物联网设备的物理安全。以下是一些常见的物理层安全威胁：

- **设备丢失或被盗**：物联网设备如传感器、控制器等，容易成为盗窃目标，一旦丢失或被盗，可能导致敏感数据泄露或设备功能失控。

- **设备损坏**：物联网设备在物理环境下可能受到损坏，如火灾、水灾等，导致设备无法正常运行。

- **电磁干扰**：物联网设备可能受到电磁干扰，导致通信中断或数据丢失。

#### 2.3.2 物联网安全防护措施

为了应对物联网安全威胁，需要采取一系列安全防护措施，包括防火墙与入侵检测、加密与认证等。

**2.3.2.1 防火墙与入侵检测**

防火墙是物联网安全防护的第一道防线，它可以阻止未经授权的访问和恶意流量。入侵检测系统（IDS）可以监控网络流量，检测异常行为和潜在攻击。

- **防火墙**：防火墙可以根据设定的安全策略，过滤网络流量，阻止恶意流量进入物联网系统。

- **入侵检测系统（IDS）**：入侵检测系统可以实时监控网络流量，检测异常行为和潜在攻击，如DDoS攻击、中间人攻击等。

**2.3.2.2 加密与认证**

加密与认证是保护物联网设备通信和数据安全的重要手段。

- **数据加密**：数据加密可以将敏感数据转换为密文，防止数据在传输和存储过程中被窃取和篡改。常用的加密算法包括AES、RSA等。

- **认证**：认证用于验证通信双方的合法身份。认证机制包括用户认证、设备认证等。常用的认证协议有OAuth、OpenID等。

- **数字签名**：数字签名用于验证数据的完整性和真实性，防止数据被篡改或伪造。常用的签名算法有SHA、RSA等。

**2.3.2.3 安全更新与补丁管理**

物联网设备通常需要定期进行安全更新和补丁管理，以修复已知漏洞和增强系统安全性。

- **安全更新**：安全更新可以修复已知的漏洞，提高系统的安全性。

- **补丁管理**：补丁管理是确保物联网设备安装最新安全补丁的过程，以防止攻击者利用已知漏洞进行攻击。

**2.3.2.4 安全审计与监控**

安全审计与监控是物联网安全的重要环节，通过记录和监控系统的操作日志，可以及时发现异常行为和潜在攻击。

- **安全审计**：安全审计是对系统操作日志的记录和分析，以发现潜在的安全问题和异常行为。

- **监控**：监控系统可以实时监控物联网设备的状态和性能，及时发现异常情况并采取措施。

通过以上安全防护措施，可以有效提高物联网系统的安全性，保护设备和数据的安全。

总之，物联网安全技术是保障物联网系统安全运行的重要手段。在物联网时代，安全挑战日益严峻，只有采取全面、有效的安全防护措施，才能确保物联网系统的安全、可靠运行。

### 3.1 智能家居

智能家居是物联网技术在家庭环境中的典型应用，通过将家庭中的各种设备通过网络连接起来，实现自动化管理和控制，提高生活质量。

#### 3.1.1 智能家居系统架构

智能家居系统通常由以下几个层次组成：

**1. 硬件设备层**

硬件设备层包括各种智能设备，如智能电视、智能空调、智能灯具、智能门锁、智能摄像头等。这些设备通过内置的传感器和通信模块，能够收集环境信息并进行数据传输。

**2. 软件平台层**

软件平台层是智能家居系统的核心，包括智能控制中心、应用程序接口（API）和用户界面（UI）。智能控制中心负责处理数据、执行用户指令和协调设备之间的通信。应用程序接口（API）为开发者提供了接口，便于开发第三方应用程序。用户界面（UI）则为用户提供了一个直观的操作界面，方便用户进行设备控制。

**3. 网络通信层**

网络通信层是连接硬件设备和软件平台的关键，负责数据传输。智能家居系统通常采用Wi-Fi、蓝牙、Zigbee等无线通信技术，实现设备之间的互联互通。

**4. 云平台层**

云平台层提供了数据存储、分析和云计算服务，智能家居系统可以将收集到的数据上传到云平台，进行进一步的处理和分析，实现智能决策和优化。

#### 3.1.2 智能家居应用案例

智能家居的应用案例非常丰富，以下是一些典型的应用场景：

**1. 智能照明系统**

智能照明系统可以通过手机APP或语音控制，实现对家庭中灯具的远程开关和亮度调节。系统可以根据环境光线自动调节灯光亮度，节省能源，提高舒适度。

**2. 智能安防系统**

智能安防系统包括智能门锁、智能摄像头、烟雾报警器等，通过这些设备可以实现对家庭安全的实时监控和报警。一旦检测到异常情况，系统会自动发送报警信息到用户的手机，提高家庭的安全性。

**3. 智能家电联动**

智能家电联动是指通过智能家居系统，实现家电设备之间的联动控制。例如，用户可以通过智能音箱控制智能空调、智能电视等家电设备，实现一键式操作，提高生活便捷性。

### 3.2 智能交通

智能交通是物联网技术在交通领域的应用，通过集成各种传感器和智能系统，实现对交通流量、车辆运行状态和道路设施的管理，提高交通效率和安全性。

#### 3.2.1 智能交通系统架构

智能交通系统通常由以下几个层次组成：

**1. 数据采集层**

数据采集层包括各种传感器，如交通流量传感器、车速传感器、道路状况传感器等，用于收集交通信息。

**2. 数据传输层**

数据传输层负责将采集到的数据传输到处理中心。数据传输通常采用无线通信技术，如Wi-Fi、LoRa、5G等。

**3. 数据处理与分析层**

数据处理与分析层是智能交通系统的核心，负责对传输来的数据进行处理、分析和存储。通过大数据分析和机器学习算法，可以实现交通流量预测、道路优化和事故预警等功能。

**4. 决策与控制层**

决策与控制层根据分析结果，对交通信号灯、交通诱导屏等设施进行控制，实现交通流量的优化和管理。

**5. 用户服务层**

用户服务层为交通参与者提供信息和服务，如实时路况信息、出行建议、车辆调度等。

#### 3.2.2 智能交通应用案例

智能交通的应用案例在多个城市得到了实践，以下是一些典型的应用场景：

**1. 智能交通信号灯系统**

智能交通信号灯系统可以根据实时交通流量数据，动态调整信号灯的时长和相位，优化交通流量，减少拥堵和事故。

**2. 智能车载系统**

智能车载系统包括车载传感器、GPS定位和车辆通信模块，可以实现车辆的实时监控、导航和远程控制。通过智能车载系统，可以提高行车安全性，减少交通事故。

**3. 智慧停车系统**

智慧停车系统通过传感器和摄像头实时监控停车位使用情况，为驾驶员提供停车导航和空闲车位信息，提高停车效率。

```cpp
#include <ESP8266WiFi.h>
#include <PubSubClient.h>

// Wi-Fi配置
const char* ssid = "yourSSID";
const char* password = "yourPASSWORD";

// MQTT服务器配置
const char* mqtt_server = "yourMQTT_SERVER";
const char* mqtt_user = "yourMQTT_USER";
const char* mqtt_password = "yourMQTT_PASSWORD";

WiFiClient espClient;
PubSubClient client(espClient);

void setup() {
  Serial.begin(115200);
  connectWiFi();
  client.setServer(mqtt_server, 1883);
  client.setCallback(callback);
}

void loop() {
  if (!client.connected()) {
    reconnect();
  }
  client.loop();

  // 读取传感器数据
  sensors.requestTemperatures();
  float temperature = sensors.getTempCByIndex(0);
  float humidity = dht.readHumidity();
  int light = lightSensor.readLightLevel();

  // 发布数据
  char tempTopic[50];
  sprintf(tempTopic, "sensors/temperature");
  client.publish(tempTopic, String(temperature).c_str());

  char humidityTopic[50];
  sprintf(humidityTopic, "sensors/humidity");
  client.publish(humidityTopic, String(humidity).c_str());

  char lightTopic[50];
  sprintf(lightTopic, "sensors/light");
  client.publish(lightTopic, String(light).c_str());

  delay(10000);
}

void connectWiFi() {
  Serial.println();
  Serial.print("Connecting to ");
  Serial.println(ssid);

  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("");
  Serial.println("WiFi connected");
  Serial.println("IP address: ");
  Serial.println(WiFi.localIP());
}

void reconnect() {
  while (!client.connected()) {
    Serial.print("Attempting to connect to MQTT server...");
    if (client.connect("ESP8266Client", mqtt_user, mqtt_password)) {
      Serial.println("connected");
      client.subscribe(" sensors/#");
    } else {
      Serial.print("failed, rc=");
      Serial.print(client.state());
      Serial.println(" try again in 5 seconds");
      delay(5000);
    }
  }
}

void callback(char* topic, byte* payload, unsigned int length) {
  Serial.print("Message arrived on topic: ");
  Serial.println(topic);
  Serial.print("Message: ");
  for (int i = 0; i < length; i++) {
    Serial.print((char)payload[i]);
  }
  Serial.println();
}
```
