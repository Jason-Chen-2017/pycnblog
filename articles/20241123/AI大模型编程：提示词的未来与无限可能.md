  ```python
  # 伪代码：反向传播算法
  for each layer in reverse order:

      weights += learning_rate * delta * input
      bias += learning_rate * delta
  ```

  $$ \theta_{new} = \theta_{old} - \alpha \nabla_\theta J(\theta) $$
