#### 3.3 数学模型和公式

在科技禁食日活动中，我们可以使用以下数学模型和公式来评估活动效果：

- **参与度指数（Involvement Index）**：
  $$ I = \frac{E - D}{E + D} $$
  其中，\( I \) 表示参与度指数，\( E \) 表示实际参与时间，\( D \) 表示未参与时间。

- **反馈满意度（Feedback Satisfaction）**：
  $$ S = \frac{F - N}{F + N} $$
  其中，\( S \) 表示反馈满意度，\( F \) 表示正面反馈次数，\( N \) 表示负面反馈次数。

- 实际参与时间：\( E = 8 \) 小时
- 未参与时间：\( D = 4 \) 小时
- 正面反馈次数：\( F = 7 \) 次
- 负面反馈次数：\( N = 3 \) 次

我们可以使用上述数学模型和公式来计算参与度指数和反馈满意度：

- **参与度指数**：
  $$ I = \frac{8 - 4}{8 + 4} = \frac{4}{12} = \frac{1}{3} $$
  参与度指数为 \( \frac{1}{3} \)，表明参与者的参与度相对较高。

- **反馈满意度**：
  $$ S = \frac{7 - 3}{7 + 3} = \frac{4}{10} = 0.4 $$
  反馈满意度为 0.4，表明参与者对活动的总体满意度较高。

通过这些数据，我们可以对科技禁食日活动进行初步的评估，并根据参与度和反馈满意度来调整和优化未来的活动。

#### 5.2 系统核心实现源代码

```python
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql+pymysql://username:password@localhost/tech_fast_day'
db = SQLAlchemy(app)

class Participant(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50))
    contact = db.Column(db.String(50))
    participation_history = db.Column(db.Text)

class Device(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    type = db.Column(db.String(50))
    usage_time = db.Column(db.Integer)
    disabled = db.Column(db.Boolean)

class Activity(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    fasting_date = db.Column(db.Date)
    plan = db.Column(db.Text)
    participants = db.relationship('Participant', backref='activity')
    devices = db.relationship('Device', backref='activity')
    evaluations = db.relationship('Evaluation', backref='activity')
    feedbacks = db.relationship('Feedback', backref='activity')

class Evaluation(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    involvement_index = db.Column(db.Float)
    satisfaction_rate = db.Column(db.Float)
    activity_id = db.Column(db.Integer, db.ForeignKey('activity.id'))

class Feedback(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    content = db.Column(db.Text)
    type = db.Column(db.String(50))
    evaluation_id = db.Column(db.Integer, db.ForeignKey('evaluation.id'))

@app.route('/participants', methods=['POST'])
def add_participant():
    data = request.get_json()
    participant = Participant(
        name=data['name'],
        contact=data['contact'],
        participation_history=data['participation_history']
    )
    db.session.add(participant)
    db.session.commit()
    return jsonify({'message': 'Participant added successfully.'})

@app.route('/devices', methods=['POST'])
def add_device():
    data = request.get_json()
    device = Device(
        type=data['type'],
        usage_time=data['usage_time'],
        disabled=data['disabled']
    )
    db.session.add(device)
    db.session.commit()
    return jsonify({'message': 'Device added successfully.'})

@app.route('/activities', methods=['POST'])
def add_activity():
    data = request.get_json()
    activity = Activity(
        fasting_date=data['fasting_date'],
        plan=data['plan']
    )
    db.session.add(activity)
    db.session.commit()
    return jsonify({'message': 'Activity added successfully.'})

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```
