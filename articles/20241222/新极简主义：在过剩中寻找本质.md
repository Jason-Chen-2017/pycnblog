#### 2.1 减少物质消费

减少物质消费是极简主义的核心原则之一。在现代社会，人们往往被物质消费的诱惑所困扰，导致不必要的物品堆积，占据空间和内心。通过减少物质消费，人们可以摒弃不必要的物品，减轻生活负担，创造一个更加整洁、有序的环境。

具体来说，减少物质消费可以通过以下几个方面实现：

- **理性购物**：在购物前，人们应该明确自己的需求和价值观，避免冲动消费。通过制定购物清单，有意识地购买真正需要的物品，减少不必要的购买。
- **淘汰无用物品**：定期对物品进行清理，淘汰那些长时间未使用、不再需要的物品。这不仅能够减少物品的堆积，还能释放空间，提高生活品质。
- **环保消费**：选择环保、可持续的商品，减少对环境的负面影响。例如，购买二手商品、使用可重复利用的物品等。

```python
import requests
from datetime import datetime

# 设备控制函数
def control_device(device_id, command):
    url = f"http://192.168.1.10:8080/api/devices/{device_id}/control"
    headers = {'Content-Type': 'application/json'}
    response = requests.post(url, json={'command': command}, headers=headers)
    return response.json()

# 能源管理函数
def manage_energy(device_id, current_time):
    url = f"http://192.168.1.10:8080/api/devices/{device_id}/energy"
    headers = {'Content-Type': 'application/json'}
    data = {
        'start_time': current_time.strftime('%Y-%m-%d %H:%M:%S'),
        'end_time': (current_time + timedelta(hours=2)).strftime('%Y-%m-%d %H:%M:%S')
    }
    response = requests.post(url, json=data, headers=headers)
    return response.json()

# 主函数
def main():
    device_id = '001'
    current_time = datetime.now()

    # 控制设备
    response = control_device(device_id, 'turn_on')
    print(response)

    # 管理能源
    response = manage_energy(device_id, current_time)
    print(response)

if __name__ == '__main__':
    main()
```

在这个示例中，我们定义了两个函数，分别用于控制设备和能源管理。主函数中调用这两个函数，实现了设备的开启和能源的管理。
