6. **发送确认通知**：系统向用户发送预订确认通知，包括预订详情和支付信息。

#### Python源代码实现

```python
import psycopg2
from psycopg2 import sql

# 连接数据库
conn = psycopg2.connect(
    dbname="digital detox booking",
    user="your_user",
    password="your_password",
    host="your_host",
    port="your_port"
)

# 预订逻辑
def create_booking(user_id, activity_id, reserve_date, quantity):
    cursor = conn.cursor()

    # 查询活动可用性
    cursor.execute(sql.SQL("""
        SELECT available_slots 
        FROM activities 
        WHERE activity_id = %s;
    """), (activity_id,))

    result = cursor.fetchone()
    if result is None or result[0] < quantity:
        return "活动不可用或预订数量超出限制"

    # 创建预订记录
    cursor.execute(sql.SQL("""
        INSERT INTO reserves (user_id, activity_id, reserve_date, quantity, status) 
        VALUES (%s, %s, %s, %s, '待确认');
    """), (user_id, activity_id, reserve_date, quantity))

    conn.commit()

    # 更新活动可用性
    new_slots = result[0] - quantity
    cursor.execute(sql.SQL("""
        UPDATE activities 
        SET available_slots = %s 
        WHERE activity_id = %s;
    """), (new_slots, activity_id))

    conn.commit()

    return "预订成功，请等待确认"

# 示例调用
print(create_booking(1, 101, '2023-12-25', 2))
```

在这段代码中，我们首先连接到数据库，然后定义了一个`create_booking`函数来处理预订请求。函数接收用户ID、活动ID、预订日期和预订数量作为参数，首先查询活动可用性，然后创建预订记录并更新活动可用性。
