     import heapq

     def shortest_path(graph, start, end):
         visited = set()
         queue = [(0, start)]
         while queue:
             (cost, node) = heapq.heappop(queue)
             if node not in visited:
                 visited.add(node)
                 if node == end:
                     return cost
                 for neighbor, edge_cost in graph[node].items():
                     new_cost = cost + edge_cost
                     heapq.heappush(queue, (new_cost, neighbor))
         return float('inf')

### **4.2 自助图书馆的数学公式**

自助图书馆的数学公式主要涉及以下几个方面：

1. **路径优化公式**：
   $$ d(i, j) = \min \left\{ \sum_{k=1}^{n} w_{ik} x_{kj} : x_{ij} = 1 \right\} $$
   其中，$d(i, j)$ 表示从节点 $i$ 到节点 $j$ 的最短路径长度，$w_{ik}$ 表示节点 $i$ 到节点 $k$ 的权重，$x_{ij}$ 表示路径 $i$ 到节点 $j$ 是否存在。

2. **设备维护公式**：
   $$ p(t) = 1 - \prod_{i=1}^{n} (1 - f_i(t)) $$
   其中，$p(t)$ 表示设备在时间 $t$ 的故障概率，$f_i(t)$ 表示设备 $i$ 在时间 $t$ 的故障概率。

3. **用户满意度公式**：
   $$ s = \frac{1}{n} \sum_{i=1}^{n} \frac{r_i}{r_i + b_i} $$
   其中，$s$ 表示用户满意度，$r_i$ 表示用户对第 $i$ 个服务的评分，$b_i$ 表示用户对第 $i$ 个服务的评价次数。

**2. 智能推荐系统实现：**
```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 加载书籍数据
books = [
    {"id": 1, "title": "Python编程：从入门到实践", "content": "这是一本适合初学者的Python入门书籍。"},
    {"id": 2, "title": "深度学习"，"content": "深度学习是一种人工智能方法，广泛应用于计算机视觉和自然语言处理等领域。"},
    {"id": 3, "title": "算法导论"，"content": "这是一本经典的算法教材，涵盖了各种算法的设计和分析。"},
]

# 构建TF-IDF模型
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform([book["content"] for book in books])

# 计算相似度
def calculate_similarity(tfidf_matrix, book_index):
    similarity = cosine_similarity([tfidf_matrix[book_index]], tfidf_matrix)[0]
    return similarity

# 推荐书籍
def recommend_books(book_index, top_n=3):
    similarity = calculate_similarity(tfidf_matrix, book_index)
    sorted_indices = sorted(range(len(similarity)), key=similarity.__getitem__, reverse=True)
    recommended_indices = sorted_indices[1:top_n+1]
    recommended_books = [books[i] for i in recommended_indices]
    return recommended_books

# 示例操作
book_index = 0
recommended_books = recommend_books(book_index)
print("Recommended books:")
for book in recommended_books:
    print(f"ID: {book['id']}, Title: {book['title']}")
```
