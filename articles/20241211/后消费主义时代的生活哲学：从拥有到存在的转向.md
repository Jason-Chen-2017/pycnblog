## 第1章: 问题背景与核心概念

### 1.1 问题背景

#### 1.1.1 消费主义时代的特征

消费主义时代，是20世纪后半叶至21世纪初的一个时代特征，它以人们对物质消费的极度追求为标志。在这个时代，经济增长成为社会发展的主要目标，人们通过购买商品和服务来提升自己的社会地位和幸福感。以下是对消费主义时代特征的具体分析：

1. **物质消费的泛滥**：消费主义时代，商品和服务层出不穷，广告和促销活动无孔不入，人们被引导不断购买新产品、新服务。
2. **消费文化的形成**：消费主义时代，消费行为不仅仅是为了满足基本需求，更是一种生活方式和身份认同的体现。通过购买特定品牌或产品，人们表达自己的价值观和社会地位。
3. **人们为物质而奔波**：为了购买更多的物质商品，人们努力工作、加班加点，甚至牺牲了健康和家庭。

#### 1.1.2 后消费主义时代的兴起

随着消费主义时代的物质繁荣，人们逐渐意识到，单纯的物质追求并不能带来真正的满足感和幸福感。这一认识促使后消费主义时代的兴起，人们开始追求更深层次的生活方式。以下是对后消费主义时代兴起的具体分析：

1. **对物质需求的减少**：后消费主义时代，人们对物质需求开始减少，不再盲目追求更多、更好、更昂贵的商品。
2. **对精神需求的增加**：后消费主义时代，人们开始关注内心的满足和成长，追求精神层面的提升和丰富。
3. **生活方式的改变**：后消费主义时代，人们开始反思自己的生活方式，追求简约、环保、健康的生活。
4. **社会价值观的转变**：后消费主义时代，人们开始关注社会和环境问题，追求社会责任和可持续发展。

#### 1.1.3 生活哲学的意义与转变

**生活哲学**，是指人们对生活本质的理解和思考，包括价值观、生活方式、人生意义等方面。在后消费主义时代，生活哲学的意义和转变体现在以下几个方面：

1. **从拥有到存在的转变**：后消费主义时代，人们不再将物质拥有作为生活的主要目标，而是追求内心的存在和精神的富足。
2. **自我探索**：后消费主义时代，人们开始重视自我探索，通过学习、旅行、修行等方式，寻找内心的平静和满足。
3. **内心修养**：后消费主义时代，人们开始注重内心修养，通过冥想、阅读、艺术等方式，提升自己的精神层次。
4. **精神追求**：后消费主义时代，人们开始追求精神层面的提升，通过哲学、宗教、心理治疗等方式，探索生命的意义和目的。

### 1.2 核心概念介绍

#### 1.2.1 后消费主义时代的定义

后消费主义时代，是指一个社会或经济体在消费主义时代之后，逐渐从对物质的极度追求转向对内在精神的探索和追求的时代。这个时代的特点包括：

1. **物质消费的减少**：人们开始减少对物质商品的购买，不再盲目追求奢侈品和名牌。
2. **精神需求的增加**：人们开始关注内心的满足和成长，追求精神层面的提升和丰富。
3. **生活方式的转变**：人们开始追求简约、环保、健康的生活方式。
4. **价值观的改变**：人们开始重视社会责任和可持续发展，追求公正、平等、和谐的社会环境。

#### 1.2.2 生活哲学的基本原理

生活哲学，是指人们对于生活本质的理解和思考，包括价值观、生活方式、人生意义等方面。生活哲学的基本原理包括：

1. **自我探索**：生活哲学强调自我探索，通过了解自己的内心世界，找到自己的价值观和目标。

4. **社会责任**：生活哲学强调社会责任，通过参与社会活动、关注社会问题，为社会做出贡献。

#### 1.2.3 从拥有到存在的转向

从拥有到存在的转向，是指人们在后消费主义时代，从追求物质拥有转向追求精神存在的过程。这个转向的意义和路径包括：

1. **意义**：
   - **内心的满足**：通过追求精神存在，人们可以找到内心的满足和幸福感，摆脱物质追求的空虚感。
   - **自我实现**：通过追求精神存在，人们可以实现自我价值的提升，达到自我实现的目标。
   - **社会进步**：从拥有到存在的转向，有助于构建一个更加和谐、可持续发展的社会。

2. **路径**：
   - **自我探索**：通过自我探索，了解自己的内心需求和价值观，找到适合自己的生活方式。
   - **内心修养**：通过内心修养，提升自己的精神层次，增强内心的平静和自信。
   - **精神追求**：通过精神追求，探索生命的意义和目的，找到自己存在的价值和意义。
   - **社会责任**：通过社会责任，参与社会活动，为社会做出贡献，实现自我价值。

# evaluations/utils.py
from evaluations.models import Evaluation
from surveys.models import Survey

def calculate_evaluation(survey):
    philosophy_score = survey.philosophy_score
    lifestyle_score = survey.lifestyle_score
    mindfulness_score = survey.mindfulness_score
    spirituality_score = survey.spirituality_score

    philosophy_weight = 0.4
    lifestyle_weight = 0.3
    mindfulness_weight = 0.2
    spirituality_weight = 0.1

    evaluation = Evaluation(survey=survey)
    evaluation.philosophy_score = philosophy_weight * philosophy_score + lifestyle_weight * lifestyle_score + mindfulness_weight * mindfulness_score + spirituality_weight * spirituality_score
    evaluation.satisfaction_index = 0.5 * survey.philosophy_score + 0.3 * survey.lifestyle_score + 0.2 * survey.mindfulness_score
    evaluation.save()
    return evaluation
