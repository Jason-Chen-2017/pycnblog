#### 3.3 算法原理讲解与举例说明

**监督学习算法讲解与例子**

以线性回归算法为例，线性回归是一种简单的监督学习算法，用于预测连续值输出。以下是一个简单的线性回归算法的例子：

```python
import numpy as np

# 输入特征和标签
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([1, 2, 2.5, 4, 5])

# 初始化模型参数
theta = np.zeros((2, 1))

# 训练模型
for epoch in range(1000):
    # 计算预测值
    y_pred = X.dot(theta)
    
    # 计算损失函数
    cost = (1/2) * (y_pred - y).dot(y_pred - y)
    
    # 计算梯度
    gradient = X.T.dot(y_pred - y)
    
    # 更新模型参数
    theta -= gradient

# 输出模型参数
print("模型参数：", theta)
```

通过上述代码，我们可以训练一个线性回归模型，用于预测输入特征对应的连续值输出。模型参数 $\theta$ 是通过梯度下降算法进行优化的。

**深度学习算法讲解与例子**

以卷积神经网络（CNN）为例，CNN 是一种深度学习算法，用于图像处理任务。以下是一个简单的 CNN 算法的例子：

```python
import tensorflow as tf

# 输入特征和标签
X = tf.placeholder(tf.float32, [None, 28, 28, 1])
y = tf.placeholder(tf.float32, [None, 10])

# 卷积层
conv1 = tf.layers.conv2d(inputs=X, filters=32, kernel_size=[5, 5], padding="same", activation=tf.nn.relu)

# 池化层
pool1 = tf.layers.max_pooling2d(inputs=conv1, pool_size=[2, 2], strides=2)

# 全连接层
dense = tf.layers.dense(inputs=pool1, units=128, activation=tf.nn.relu)

# 输出层
outputs = tf.layers.dense(inputs=dense, units=10)

# 训练模型
optimizer = tf.train.AdamOptimizer().minimize(tf.reduce_mean(tf.nn.softmax_cross_entropy_with_logits(logits=outputs, labels=y)))

# 模型评估
correct_prediction = tf.equal(tf.argmax(outputs, 1), tf.argmax(y, 1))
accuracy = tf.reduce_mean(tf.cast(correct_prediction, tf.float32))

# 训练过程
with tf.Session() as sess:
    sess.run(tf.global_variables_initializer())
    for epoch in range(1000):
        sess.run(optimizer, feed_dict={X: X_train, y: y_train})
        if epoch % 100 == 0:
            acc_train = accuracy.eval(feed_dict={X: X_train, y: y_train})
            acc_test = accuracy.eval(feed_dict={X: X_test, y: y_test})
            print("Epoch", epoch, "Train Accuracy:", acc_train, "Test Accuracy:", acc_test)
```

通过上述代码，我们可以训练一个简单的 CNN 模型，用于图像分类任务。模型通过卷积层、池化层和全连接层等结构进行特征提取和分类。
