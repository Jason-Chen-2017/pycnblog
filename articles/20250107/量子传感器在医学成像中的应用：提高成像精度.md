#### 1.1 问题背景

**量子传感器概述**  
量子传感器是一种基于量子力学原理设计的精密测量设备。它能够利用量子态的相干性和量子纠缠等现象，实现对极微弱物理信号的精确检测。与传统的成像传感器相比，量子传感器具有更高的灵敏度、分辨率和稳定性。

```python
import numpy as np

# 信号采集
def collect_signal():
    # 模拟量子传感器采集的信号
    signal = np.random.normal(size=1000)
    return signal

# 信号处理
def process_signal(signal):
    # 模拟信号处理过程
    processed_signal = signal * 2
    return processed_signal

# 图像重建
def reconstruct_image(processed_signal):
    # 模拟图像重建过程
    image = processed_signal.reshape((100, 100))
    return image

# 主程序
if __name__ == "__main__":
    signal = collect_signal()
    processed_signal = process_signal(signal)
    image = reconstruct_image(processed_signal)
    print(image)
```

**图像重建**
