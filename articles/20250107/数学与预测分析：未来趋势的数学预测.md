## 数学基础

### 概率论基础

概率论是预测分析的基础，它研究随机事件发生的可能性。概率论的基本概念包括：

- **随机实验**：一次可能产生多种结果的试验。
- **样本空间**：试验所有可能结果的集合。
- **事件**：样本空间的一个子集。

概率论的核心公式是：

$$P(A) = \frac{n(A)}{n(S)}$$

其中，$P(A)$ 是事件 $A$ 发生的概率，$n(A)$ 是事件 $A$ 包含的样本点数，$n(S)$ 是样本空间包含的样本点数。

### 统计学基本概念

统计学是处理数据的科学，它包括数据收集、数据分析、结果解释等步骤。以下是几个核心统计学概念：

- **数据类型**：定性数据（分类变量）和定量数据（数值变量）。
- **分布**：描述数据集特征的函数，如正态分布、泊松分布等。
- **均值和方差**：描述数据集的中心位置和离散程度的统计量。

统计学的基本公式包括：

- **均值**：$\mu = \frac{\sum X_i}{N}$
- **方差**：$\sigma^2 = \frac{\sum (X_i - \mu)^2}{N}$

### 数学模型简介

数学模型是使用数学语言描述现实世界的抽象。预测分析中的数学模型包括：

- **线性回归**：通过拟合一条直线来预测因变量的值。
- **神经网络**：模拟人脑神经元连接的复杂模型。

## 预测分析技术

### 线性回归

线性回归是一种最常见的预测方法，它通过拟合一条直线来预测因变量的值。线性回归的基本公式为：

$$Y = \beta_0 + \beta_1X + \epsilon$$

其中，$Y$ 是因变量，$X$ 是自变量，$\beta_0$ 和 $\beta_1$ 是回归系数，$\epsilon$ 是误差项。

### 神经网络与机器学习

神经网络是一种模拟人脑神经元连接的复杂模型，它可以用于非线性预测。神经网络的基本结构包括输入层、隐藏层和输出层。机器学习是神经网络的基础，它通过训练数据集来调整网络参数，使其能够进行有效的预测。

### 时间序列分析

时间序列分析是一种分析时间序列数据中的趋势和周期性的方法。常见的时间序列模型包括ARIMA（自回归积分滑动平均模型）和AR（自回归模型）。时间序列分析的基本公式为：

$$X_t = c + \phi_1X_{t-1} + \phi_2X_{t-2} + ... + \phi_pX_{t-p} + \varepsilon_t$$

其中，$X_t$ 是时间序列的当前值，$c$ 是常数项，$\phi_1, \phi_2, ..., \phi_p$ 是自回归系数，$\varepsilon_t$ 是误差项。

    model = ARIMA(processed_data['electricity_demand'], order=(1, 1, 1))
    model_fit = model.fit()
    return model_fit

# 预测
def predict(model, X_test):
    Y_pred = model.predict(X_test)
    return Y_pred

# 评估
def evaluate(Y_test, Y_pred):
    mse = np.mean((Y_test - Y_pred) ** 2)
    rmse = np.sqrt(mse)
    return mse, rmse

# 可视化
def plot_results(Y_test, Y_pred):
    plt.scatter(Y_test, Y_pred)
    plt.xlabel('Actual Electricity Demand')
    plt.ylabel('Predicted Electricity Demand')
    plt.title('Electricity Demand Prediction')
    plt.show()

# 主函数
def main():
    file_path = 'electricity_demand.csv'
    data = collect_data(file_path)
    processed_data = process_data(data)
    linear_model, X_test = train_linear_regression(processed_data)
    arima_model = train_arima(processed_data)
    Y_pred_linear = predict(linear_model, X_test)
    Y_pred_arima = predict(arima_model, X_test)
    mse_linear, rmse_linear = evaluate(data['electricity_demand'], Y_pred_linear)
    mse_arima, rmse_arima = evaluate(data['electricity_demand'], Y_pred_arima)
    print(f"Linear Regression - MSE: {mse_linear}, RMSE: {rmse_linear}")
    print(f"ARIMA - MSE: {mse_arima}, RMSE: {rmse_arima}")
    plot_results(data['electricity_demand'], Y_pred_linear)

if __name__ == '__main__':
    main()
