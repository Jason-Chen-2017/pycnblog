#### 代码示例：时间管理工具

以下是一个简单的Python脚本，用于管理员工的工作时间和休息时间。

```python
import datetime

class TimeManager:
    def __init__(self, start_time, end_time):
        self.start_time = start_time
        self.end_time = end_time

    def is_within_work_hours(self, current_time):
        return self.start_time <= current_time <= self.end_time

    def calculate_rest_time(self, work_time):
        work_duration = (self.end_time - self.start_time).total_seconds()
        rest_duration = (work_duration * 0.3)  # 假设休息时间是工作时间的30%
        rest_end_time = self.start_time + datetime.timedelta(seconds=work_duration + rest_duration)
        return rest_end_time

# 设置工作时间和休息时间
start_time = datetime.time(9, 0)  # 早上9点开始工作
end_time = datetime.time(18, 0)   # 晚上6点结束工作

# 创建时间管理对象
time_manager = TimeManager(start_time, end_time)

# 检查当前时间是否在正常工作时间内
current_time = datetime.time(10, 30)  # 当前时间为早上10点半
if time_manager.is_within_work_hours(current_time):
    print("当前时间在正常工作时间内。")
else:
    print("当前时间不在正常工作时间内。")

# 计算休息结束时间
rest_end_time = time_manager.calculate_rest_time(current_time)
print(f"休息结束时间：{rest_end_time}")
```

   - `__init__`：初始化时间管理对象，设置开始工作和结束工作的时间。
   - `is_within_work_hours`：检查当前时间是否在正常工作时间内。
   - `calculate_rest_time`：计算休息结束时间。

2. **设置工作时间和休息时间**：在本示例中，我们设置早上9点开始工作，晚上6点结束工作。

3. **创建时间管理对象**：使用定义的TimeManager类创建一个时间管理对象。

4. **检查当前时间是否在正常工作时间内**：使用`is_within_work_hours`方法检查当前时间是否在正常工作时间内。

5. **计算休息结束时间**：使用`calculate_rest_time`方法计算休息结束时间。
