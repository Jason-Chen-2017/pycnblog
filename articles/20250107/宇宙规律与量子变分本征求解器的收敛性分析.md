## 4. 数学模型与公式

量子变分本征求解器的数学模型是量子力学中的变分法，其核心思想是通过构造一个变分函数来逼近系统的基态波函数，然后计算变分函数的期望值，进而得到基态能量。

### 4.1 数学模型

设哈密顿量为 \(H\)，基态波函数为 \(|\psi_0\rangle\)，则系统的基态能量为：

\[E_0 = \langle\psi_0 | H | \psi_0 \rangle\]

为了求解 \(E_0\)，我们可以构造一个变分函数 \(|\phi\rangle = \sum_{i} c_i |i\rangle\)，其中 \(c_i\) 为变分系数，\(|i\rangle\) 为系统的基态波函数。

### 4.2 数学公式

构造变分函数后，我们需要计算其期望值：

\[E(\theta) = \langle\phi | H | \phi \rangle = \sum_{i} c_i^* c_j H_{ij}\]

其中，\(H_{ij}\) 为哈密顿量的矩阵元。

为了优化变分系数 \(c_i\)，我们需要计算梯度：

\[\frac{\partial E(\theta)}{\partial c_i} = \sum_{j} c_j^* H_{ij}\]

通过梯度下降法，我们可以迭代优化变分系数，进而求解系统的基态能量。

### 4.3 算法举例

假设我们有一个简单的量子系统，其哈密顿量为 \(H = \omega \sigma_z\)，其中 \(\omega\) 为常数，\(\sigma_z\) 为 Pauli 矩阵。我们可以构造一个变分函数 \(|\phi\rangle = \cos(\theta) |0\rangle + \sin(\theta) |1\rangle\)，其中 \(\theta\) 为变分系数。

根据变分法的数学模型，我们可以计算出基态能量：

\[E(\theta) = \langle\phi | H | \phi \rangle = \cos^2(\theta) \omega + \sin^2(\theta) \omega = \omega\]

当 \(\theta = \frac{\pi}{2}\) 时，基态能量 \(E(\theta)\) 取得最小值，此时系统的基态波函数为 \(|\psi_0\rangle = \sin(\theta) |0\rangle + \cos(\theta) |1\rangle\)。

### 6.2 系统核心实现

接下来，我们将实现一个简单的量子变分本征求解器，用于求解一个二能级系统的基态能量。

```python
import qiskit
from qiskit.aqua.algorithms import VQE
from qiskit.circuit import QuantumCircuit
from qiskit.aqua.operators import PauliSumOp
from qiskit.aqua.components.initial_states import CustomInitialState
from qiskit.aqua.components.optimizers import Adam

# 构建量子电路
qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)

# 构建哈密顿量
paulis = {'pauli': {'I': 1.0, 'Z': -1.0}}
hamiltonian = PauliSumOp.from_dict(paulis)

# 初始化参数
num_particles = 2
num_qubits = 2
initial_state = CustomInitialState(pauli_expansion=hamiltonian.to_pauli_sum().pauli_terms,
                                  num_qubits=num_qubits,
                                  num_particles=num_particles).run()

# 实例化 VQE 算法
vqe = VQE(target=hamiltonian,
           initial_state=initial_state,
           optimizer=Adam(maxiter=1000))

# 执行 VQE 算法
result = vqe.run()

# 输出结果
print("Base state energy:", result['result']['energy'])
print("Base state wave function:", result['result']['state'])
```
