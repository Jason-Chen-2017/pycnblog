### 数学模型

动态规划的核心是定义一个状态转移方程，用于递推求解子问题的解。例如，对于最短路径问题，状态转移方程可以表示为：

$$
f(i, j) = \min(f(i-1, j), f(i, j-1)) + w(i, j)
$$

其中，\(f(i, j)\)表示从起点到点\(i, j\)的最短路径长度，\(w(i, j)\)表示从点\(i, j\)到下一个点的权值。

### 举例说明

假设有一个网格图，需要从左上角（0, 0）走到右下角（3, 3），网格中每个点的权重如下：

```
0 1 2 3
0 0 0 0
1 0 0 0
2 0 0 0
3 0 0 0
```

使用动态规划求解最短路径，可以得到：

```
f(0, 0) = 0
f(0, 1) = f(0, 0) + 1 = 1
f(1, 0) = f(1, 1) = f(0, 1) + 1 = 2
...
f(3, 3) = f(2, 2) + 0 = 5
```

最终，从左上角到右下角的最短路径长度为5。
