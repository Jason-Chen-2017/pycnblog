```python
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats

# 问卷调查数据
data = {
    '姓名': ['张三', '李四', '王五', '赵六', '钱七'],
    '虚无主义倾向': [3, 4, 2, 5, 3],
    '焦虑水平': [2, 3, 1, 4, 2],
    '抑郁水平': [2, 3, 2, 3, 2]
}

# 创建数据框
df = pd.DataFrame(data)

# 计算虚无主义倾向的平均值
mean_nihilism = df['虚无主义倾向'].mean()

# 计算虚无主义倾向的标准差
std_nihilism = df['虚无主义倾向'].std()

# 绘制虚无主义倾向的直方图
plt.hist(df['虚无主义倾向'], bins=5, color='blue', alpha=0.7)
plt.axvline(mean_nihilism, color='red', linestyle='dashed', label='平均值')
plt.axvline(mean_nihilism - std_nihilism, color='green', linestyle='dotted', label='平均值 - 标准差')
plt.axvline(mean_nihilism + std_nihilism, color='green', linestyle='dotted', label='平均值 + 标准差')
plt.title('虚无主义倾向分布')
plt.xlabel('虚无主义倾向得分')
plt.ylabel('频率')
plt.legend()
plt.show()

# 计算皮尔逊相关系数
correlation_anxiety = stats.pearsonr(df['虚无主义倾向'], df['焦虑水平'])
correlation_depression = stats.pearsonr(df['虚无主义倾向'], df['抑郁水平'])

print(f"虚无主义倾向与焦虑水平的相关系数：{correlation_anxiety[0]}")
print(f"虚无主义倾向与抑郁水平的相关系数：{correlation_depression[0]}")

# 分析结果解读
if correlation_anxiety[0] > 0.5:
    print("虚无主义倾向与焦虑水平呈显著正相关。")
if correlation_depression[0] > 0.5:
    print("虚无主义倾向与抑郁水平呈显著正相关。")
```

这段代码首先创建了一个包含问卷调查数据的DataFrame，然后计算了虚无主义倾向的平均值和标准差，并绘制了直方图来展示数据的分布情况。接着，使用皮尔逊相关系数来分析虚无主义倾向与焦虑水平、抑郁水平之间的关系。

通过这段代码，我们可以直观地看到虚无主义倾向在个体中的分布情况，以及它与焦虑、抑郁等心理状态之间的关系。这有助于我们更好地理解虚无主义对个体的心理影响，为进一步的心理干预和研究提供数据支持。
