**1.2 Shannon熵的数学模型**

- **核心概念：** Shannon熵是信息论中的基本概念，用于衡量信息的无序度。
- **数学公式：** $$H(X) = -\sum_{i} p(x_i) \log_2 p(x_i)$$
- **示例解释：** 我们可以用Shannon熵来计算一个信息源的平均信息量。

**1.3 Python实现Shannon熵**

- **代码示例：** 
  ```python
  import math

  def shannon_entropy(p):
      return -sum(p[i] * math.log2(p[i]) for i in range(len(p)))

  # 示例：一个概率分布
  probabilities = [0.1, 0.2, 0.3, 0.4]
  print(shannon_entropy(probabilities))
  ```
