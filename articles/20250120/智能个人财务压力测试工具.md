### 3.3 财务健康指数评估算法

#### 3.3.1 财务健康指数计算公式

财务健康指数（Financial Health Index，FHI）是评估用户财务状况的重要指标。其计算公式如下：

$$
FHI = \frac{1}{N} \sum_{i=1}^{N} w_i \cdot s_i
$$

其中，$N$ 为财务指标的个数，$w_i$ 为第 $i$ 个财务指标的权重，$s_i$ 为第 $i$ 个财务指标的具体值。

#### 3.3.2 财务健康指数评估流程

以下是财务健康指数评估的详细步骤：

1. 数据预处理：同3.1.2节。
2. 财务指标提取：提取与财务健康相关的指标，如储蓄率、投资收益率、支出比例等。
3. 权重分配：根据财务指标的重要性，为每个指标分配权重。
4. 计算财务健康指数：根据公式计算财务健康指数。

以下是财务健康指数评估流程的Mermaid流程图：

import pandas as pd

class DataCollector:
    def __init__(self):

    def add_data(self, income, expense, savings, investment):

    def get_data(self):
        return self.data

3. **添加数据方法**：`add_data`方法用于添加用户的财务信息。
