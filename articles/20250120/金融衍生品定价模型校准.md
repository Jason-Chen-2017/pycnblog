## 第二部分：核心概念与联系

### 2.1 布莱克-舒尔斯模型

#### 定义与特点

布莱克-舒尔斯模型（Black-Scholes Model），也称为Black-Scholes-Merton模型，是1973年由Fischer Black、Myron Scholes和Robert Merton提出的期权定价模型。该模型假设市场不存在套利机会，股票价格遵循几何布朗运动，并假设投资者可以以无风险利率自由借贷。

#### 数学公式

布莱克-舒尔斯模型的核心公式如下：

$$
C(S, t) = S_0 N(d_1) - K e^{-rT} N(d_2)
$$

其中：
- \(C(S, t)\) 是欧式看涨期权的当前价格。
- \(S_0\) 是当前股票价格。
- \(K\) 是执行价格。
- \(T\) 是期权到期时间。
- \(r\) 是无风险利率。
- \(N(d_1)\) 和 \(N(d_2)\) 是标准正态分布的累积分布函数。
- \(d_1 = \frac{1}{\sigma \sqrt{T}} \left[ \ln\left(\frac{S_0}{K}\right) + (r + \frac{\sigma^2}{2})T \right]\)
- \(d_2 = d_1 - \sigma \sqrt{T}\)

#### 适用场景

布莱克-舒尔斯模型主要适用于欧式期权，包括看涨期权和看跌期权。该模型在金融市场中得到了广泛的应用，是期权交易和风险管理的重要工具。

### 2.2 二叉树模型

#### 定义与特点

二叉树模型（Binomial Tree Model）是一种基于离散时间的期权定价模型，通过构建股票价格的未来路径来计算期权的价格。二叉树模型假设股票价格在未来一段时间内会向上或向下运动，每个节点代表一个时间点，每个分支代表一个可能的股票价格变化。

#### 数学公式

二叉树模型的核心公式如下：

$$
C_t = max(S_t - X, 0)
$$

其中：
- \(C_t\) 是第 \(t\) 时刻期权的价格。
- \(S_t\) 是第 \(t\) 时刻股票的价格。
- \(X\) 是执行价格。

#### 适用场景

二叉树模型适用于美式期权和欧式期权，尤其适用于股票价格波动较大的情况。该模型在金融工程领域得到了广泛的应用，是期权定价和风险评估的重要工具。

### 2.3 蒙特卡洛模拟

#### 定义与特点

蒙特卡洛模拟（Monte Carlo Simulation）是一种基于概率统计的数值计算方法，通过模拟大量的随机样本来估计期望值和概率分布。蒙特卡洛模拟适用于复杂金融衍生品的定价，可以处理多因素、非线性、随机性等复杂问题。

#### 数学公式

蒙特卡洛模拟的核心公式如下：

$$
\bar{X} = \frac{1}{N} \sum_{i=1}^{N} X_i
$$

其中：
- \(\bar{X}\) 是估计的期望值。
- \(N\) 是模拟次数。
- \(X_i\) 是第 \(i\) 次模拟的结果。

#### 适用场景

蒙特卡洛模拟适用于期权定价、信用风险计算、市场风险分析等场景。该模型在金融工程和风险管理领域具有广泛的应用。

### 3.2 布莱克-舒尔斯模型Python代码实现

```python
import math
import scipy.stats as si

def black_scholes(S, K, T, r, sigma):
    d1 = (math.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * math.sqrt(T))
    d2 = d1 - sigma * math.sqrt(T)
    price = S * si.norm.pdf(d1) * (K / math.exp(r * T)) * si.norm.cdf(d2)
    return price
```

### 5.2 系统核心实现

```python
import numpy as np
import scipy.stats as si
import matplotlib.pyplot as plt

def black_scholes(S, K, T, r, sigma):
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    price = S * si.norm.pdf(d1) * (K / np.exp(r * T)) * si.norm.cdf(d2)
    return price

def binomial_tree(S, K, T, r, sigma, N):
    dt = T / N
    p = (np.exp(r * dt) - (1 - sigma**2 * dt)) / (sigma * np.sqrt(dt))
    price = [0] * (N + 1)
    price[0] = S
    for i in range(1, N + 1):
        price[i] = K if np.random.rand() < p else 0
    return np.mean(price)

def monte_carlo_simulation(S, K, T, r, sigma, N):
    paths = np.random.lognormal(mean=(r - 0.5 * sigma**2) * T, sigma=sigma * np.sqrt(T), size=N)
    price = np.mean(paths) - K * np.exp(-r * T)
    return price

# 测试
S = 100
K = 100
T = 1
r = 0.05
sigma = 0.2
N = 1000

print("Black-Scholes模型定价结果：", black_scholes(S, K, T, r, sigma))
print("二叉树模型定价结果：", binomial_tree(S, K, T, r, sigma, N))
print("蒙特卡洛模拟定价结果：", monte_carlo_simulation(S, K, T, r, sigma, N))
```
