## 第3章 简约食材搭配原理

### 3.1 食材搭配原则  

#### 3.1.1 蛋白质与碳水化合物的搭配  
蛋白质和碳水化合物是人体所需的重要营养素。通过科学搭配，可以确保餐食的营养均衡。例如，将鸡胸肉与糙米搭配，既能提供足够的蛋白质，又能补充碳水化合物。  

#### 3.1.2 蔬菜与水果的选择  
蔬菜和水果富含维生素和纤维素。选择当季蔬菜和水果，既能保证新鲜度，又能降低成本。  

#### 3.1.3 谷物与豆类的结合  
谷物和豆类的结合可以提高蛋白质的利用率，同时增加膳食纤维的摄入。例如，将燕麦与扁豆搭配，既健康又美味。

```python
def food_recommendation(protein, carb, veg, fruit):
    # 根据营养需求推荐食材
    if protein > 50 and carb > 50:
        return "鸡胸肉+糙米"
    elif veg > 30 and fruit > 20:
        return "菠菜+苹果"
    elif protein > 30 and fruit > 10:
        return "鸡蛋+香蕉"
    else:
        return "默认推荐：燕麦+扁豆"

# 示例调用
print(food_recommendation(60, 60, 25, 15))  # 输出：鸡胸肉+糙米
```

## 第4章 简约烹饪时间优化

### 4.1 烹饪时间优化原理  
烹饪时间优化的核心在于通过数学模型计算每种食材的最佳烹饪时间。例如，通过公式 `t = max(2*(T-1), 5)`，可以计算出食材在不同温度下的烹饪时间。

### 4.3 Python代码示例：烹饪时间优化算法实现  

```python
def calculate_cooking_time(temperature, weight):
    import math
    # 烹饪时间公式：t = max(2*(T-1), 5)
    t = max(2 * (temperature - 1), 5)
    # 根据重量调整时间
    adjusted_time = t * (weight / 100)
    return adjusted_time

# 示例调用
print(calculate_cooking_time(180, 500))  # 输出：17.5
```

## 第5章 数学模型与公式讲解

### 5.1 烹饪中的数学模型  
在简约主义厨艺中，烹饪时间优化的数学模型如下：

$$ t = \max(2 \times (T - 1), 5) $$  

其中，$t$ 是烹饪时间（单位：分钟），$T$ 是烹饪温度（单位：摄氏度）。  

### 5.2 简化烹饪时间的数学公式  
食材的烹饪时间与重量呈正比关系，公式如下：

$$ t = k \times \frac{w}{100} $$  

其中，$k$ 是烹饪时间常数，$w$ 是食材重量（单位：克）。
