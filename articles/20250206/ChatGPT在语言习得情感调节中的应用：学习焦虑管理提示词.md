## 第一章：学习焦虑的定义与特征

### 1.1 什么是学习焦虑？
学习焦虑是学生在学习过程中因压力、不确定性或自我效能感不足而产生的负面情绪。常见症状包括注意力分散、记忆力减退和过度紧张。

### 1.2 学习焦虑的表现形式
- **情绪方面**：紧张、易怒。
- **认知方面**：思维迟缓、过度担忧。
- **行为方面**：回避任务、效率低下。

### 1.3 学习焦虑的分类
| 类型       | 描述                           |
|------------|--------------------------------|
| 习得性焦虑 | 对特定任务的担忧               |
| 状态性焦虑 | 瞬间的担忧                     |
| 特异性焦虑 | 对特定科目或场景的担忧         |

### 1.4 学习焦虑的成因分析
- **外部因素**：教师压力、考试压力。
- **内部因素**：自我效能感低、完美主义倾向。

### 5.2 核心代码实现
```python
import openai

def generate_prompt(user_input):
    # 初始化ChatGPT客户端
    client = openai.Client()
    # 调用API生成提示词
    response = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[{
            "role": "user",
            "content": f"基于以下学习焦虑情境，生成一个情感支持型提示词：{user_input}"
        }]
    )
    return response.choices[0].message.content

# 示例使用
user_input = "我总是担心自己无法完成作业"
print(generate_prompt(user_input))
```

### 5.3 案例分析
- **输入**：学生感到考试压力。
- **输出**：提示词：“深呼吸，一步步来，你能行的。”
