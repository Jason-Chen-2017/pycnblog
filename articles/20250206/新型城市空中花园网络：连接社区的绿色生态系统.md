### 7.1 环境监测系统实现

#### 7.1.1 环境监测系统代码实现

```python
import sensors
import environment_controller

class GardenSystem:
    def __init__(self):
        self.sensors = sensors.Sensors()
        self.controller = environment_controller.EnvironmentController()

    def monitor_environment(self):
        temperature = self.sensors.read_temperature()
        humidity = self.sensors.read_humidity()
        light = self.sensors.read_light()

        self.controller.adjust_climate(temperature, humidity, light)

    def display_data(self):
        print(f"Temperature: {temperature}°C")
        print(f"Humidity: {humidity}%")
        print(f"Light: {light} lux")
```
