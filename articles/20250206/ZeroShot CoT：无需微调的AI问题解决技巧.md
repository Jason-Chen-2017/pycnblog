### 第2章：核心概念与联系

#### 2.1 核心概念原理
- **零样本学习的定义**：无需微调模型即可在未见过的任务或数据上进行学习。
- **对比学习（Contrastive Learning）**：通过最大化正样本对的相似性来增强模型的区分能力。
- **Few-Shot Learning**：仅需少量标注数据即可进行学习，是零样本学习的延伸。

#### 2.2 概念属性特征对比
| 概念        | 零样本学习         | 对比学习               | Few-Shot Learning |
|-------------|--------------------|-----------------------|------------------|
| 数据需求     | 无标注或少量标注   | 需要正样本对           | 需要少量标注     |
| 任务类型     | 多任务             | 对比任务               | 少量样本任务     |
| 优势         | 无需微调           | 增强特征表达能力       | 适用于数据稀缺场景 |
| 应用场景     | 无监督学习         | 图像检索、推荐系统     | 医疗图像分类     |

```python
import tensorflow as tf
from tensorflow import keras
import numpy as np

# 构建对比学习模型
class ContrastiveModel:
    def __init__(self, embedding_dim=128):
        self.embedding_dim = embedding_dim
        self.encoder = self.build_encoder()
        self.temperature = 0.1

    def build_encoder(self):
        inputs = keras.Input(shape=(28, 28, 1))
        x = keras.layers.Conv2D(64, (3,3), activation='relu')(inputs)
        x = keras.layers.MaxPooling2D((2,2))(x)
        x = keras.layers.Conv2D(128, (3,3), activation='relu')(x)
        x = keras.layers.MaxPooling2D((2,2))(x)
        x = keras.layers.Flatten()(x)
        x = keras.layers.Dense(256, activation='relu')(x)
        x = keras.layers.Dense(self.embedding_dim)(x)
        return keras.Model(inputs=inputs, outputs=x)

    def call(self, inputs):
        embeddings = self.encoder(inputs)
        return embeddings

# 对比学习损失函数
def contrastive_loss(y_true, y_pred, temperature=0.1):
    y_true = tf.cast(y_true, tf.int32)
    y_true = tf.reshape(y_true, (-1, 2))
    y_true = tf.one_hot(tf.reshape(y_true[:, 0], (-1,)), 10)
    y_true = tf.stop_gradient(y_true)
    y_pred = tf.reshape(y_pred, (-1, 2, 128))
    y_pred_1 = tf.expand_dims(y_pred[:, 0], 1)
    y_pred_2 = tf.expand_dims(y_pred[:, 1], 1)
    similarity = tf.reduce_sum((y_pred_1 - y_pred_2) ** 2, axis=2)
    similarity = similarity / (128 * temperature)
    loss = tf.nn.softmax_cross_entropy_with_logits(y_true, similarity)
    return loss
```
