## 第一部分: 引言与背景

### 第1章: 后真相时代的媒体责任概述

#### 1.1 问题背景

##### 1.1.1 后真相时代的定义  
后真相时代是指在信息传播高度便捷的环境下，公众更依赖情感和信念，而非事实本身。虚假信息和“标题党”现象泛滥，导致公众信任危机。

##### 1.1.2 媒体责任的重要性  
媒体作为信息传播的主体，承担着传递准确信息、引导公众舆论的责任。在后真相时代，媒体的信誉直接影响公众的信任和信息的准确性。

##### 1.1.3 媒体责任的挑战  
虚假信息的扩散速度快，媒体核实信息的资源和能力有限，公众对媒体的信任逐渐下降。

#### 1.2 事实核查与公众信任重建

##### 1.2.1 事实核查的概念与作用  
事实核查是通过技术手段验证信息的准确性，帮助公众辨别真假信息。其作用在于提高信息的可信度，减少虚假信息的传播。

##### 1.2.2 公众信任重建的策略  
通过透明的信息来源、及时的更正机制和权威的事实核查，逐步重建公众对媒体的信任。


```python
from sklearn.metrics import accuracy_score, recall_score

print(f"Recall: {recall_score(y_test, y_pred)}")
```
