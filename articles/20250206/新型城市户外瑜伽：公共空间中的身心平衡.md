## 第二章 核心概念与原理

### 2.1 瑜伽的核心原理

瑜伽是一种结合了身体、呼吸和冥想的综合性练习方式。其核心在于通过体式（Asana）、呼吸（Pranayama）和冥想（Dhyana）来达到身心的和谐统一。

### 2.2 城市户外瑜伽的特点

- **自然环境的利用**：在公园、广场等公共空间中进行瑜伽练习，利用自然光线和空气。
- **社交属性**：户外瑜伽通常以群体形式进行，具有较强的社交属性。
- **灵活性**：不受场地限制，适合不同时间段和人群。

### 2.3 核心要素对比表

| 核心要素 | 室内瑜伽 | 城市户外瑜伽 |
|----------|----------|--------------|
| 练习环境 | 封闭空间 | 公共开放空间 |
| 设备需求 | 高（垫子、砖块等） | 低（仅需 mats） |
| 社交属性 | 低 | 高 |

| 空气质量 | 人工调节 | 自然清新 |

### 3.2 心理健康

- **压力缓解**：瑜伽通过冥想和深呼吸帮助人们放松身心，缓解压力。

$$

from rest_framework.decorators import api_view

@api_view(['POST'])
def enroll_course(request):
    data = request.data
    course = YogaCourse.objects.get(id=data['course_id'])
    course.participants.add(request.user)
    return Response({'status': 'success'})
