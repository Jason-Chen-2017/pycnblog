## 背景介绍：虚无主义的起源与演变

### 问题背景

虚无主义起源于古希腊哲学，但在19世纪末至20世纪初的欧洲经历工业革命和两次世界大战后，逐渐成为主流思想。这一时期，人们开始质疑传统价值体系，寻找生命的意义。

### 问题描述

虚无主义质疑生命的意义，认为世界无意义，人类存在无目的。它挑战了宗教、社会和文化的根基，促使人们重新思考存在的本质。

### 问题解决

哲学家如尼采提出“上帝已死”，认为传统价值不再适用，倡导重新定义意义。萨特的存在主义则强调个体自由和责任，试图超越虚无主义的绝望。

### 边界与外延

虚无主义涵盖多种形式，从悲观主义到反抗精神，影响了文学、艺术和心理学。它并非单一思想，而是一个复杂的现象。

### 核心要素组成

1. **无意义论**：世界缺乏固有意义。
2. **价值相对论**：价值主观，无绝对标准。
3. **悲观主义**：对人类前途的悲观看法。

```python
def calculate_concepts(years):
    concepts = {'无意义论': 0, '价值相对论': 0, '悲观主义': 0}
    for year in years:
        if year < 1800:
            continue
        if year < 1900:
            concepts['无意义论'] += 1
            concepts['价值相对论'] += 0.5
            concepts['悲观主义'] += 0.2
        else:
            concepts['无意义论'] += 2
            concepts['价值相对论'] += 1
            concepts['悲观主义'] += 1.5
    return concepts

years = range(1800, 2001)
result = calculate_concepts(years)
print(result)
```
