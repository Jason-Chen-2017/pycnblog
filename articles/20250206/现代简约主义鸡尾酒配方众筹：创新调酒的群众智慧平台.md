## 算法原理讲解

### 推荐系统

为了提升用户体验，平台采用协同过滤推荐算法，基于用户行为推荐配方。流程如下：

```mermaid

```

### 数学模型

协同过滤的相似度计算公式为：

$$ \text{相似度}(u_1, u_2) = \frac{\sum_{i} (r_{u1,i} - \bar{r}_{u1}) \times (r_{u2,i} - \bar{r}_{u2})}{\sqrt{\sum_{i} (r_{u1,i} - \bar{r}_{u1})^2} \times \sqrt{\sum_{i} (r_{u2,i} - \bar{r}_{u2})^2}}} $$

其中，$r_{u,i}$ 表示用户 u 对物品 i 的评分，$\bar{r}_u$ 是用户的平均评分。

### 代码实现

```python
import numpy as np

def cosine_similarity(user_matrix):
    user_matrix = np.array(user_matrix)
    mean = np.mean(user_matrix, axis=1).reshape(-1, 1)
    centered = user_matrix - mean
    dot_product = centered.dot(centered.T)
    norms = np.sqrt(np.diagonal(dot_product))
    similarity = dot_product / norms
    return similarity
```

```python
from django.contrib.auth.models import User
from django.db import models

class Recipe(models.Model):
    name = models.CharField(max_length=100)
    ingredients = models.TextField()
    description = models.TextField()
    likes = models.IntegerField(default=0)
    comments = models.TextField(default="")
    backers = models.ManyToManyField(User)

class Campaign(models.Model):
    title = models.CharField(max_length=200)
    goal = models.DecimalField(max_digits=10, decimal_places=2)
    duration = models.IntegerField()
    backers = models.ManyToManyField(User)
    funds = models.DecimalField(max_digits=10, decimal_places=2)
    status = models.CharField(max_length=50)
```
