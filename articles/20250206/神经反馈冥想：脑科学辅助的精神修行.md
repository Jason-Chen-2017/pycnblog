### 第1章：神经反馈冥想的起源与发展

#### 1.1.1 神经反馈技术的起源

神经反馈技术起源于20世纪中叶，由美国心理学家Ernst Hartmann提出。Hartmann通过监测个体的生理信号，如脑电信号和心率，并将其反馈给个体，帮助他们调节心理和生理状态。这种方法为现代神经反馈技术奠定了基础。

#### 1.1.2 神经反馈冥想的现代发展

随着脑科学和神经技术的进步，神经反馈冥想在21世纪逐渐兴起。现代神经反馈冥想结合了传统的冥想方法，通过实时监测和反馈生理信号，帮助个体更好地控制情绪和身体状态。这种结合不仅应用于心理健康领域，还扩展到身体健康和教育等多个领域。

#### 1.1.3 神经反馈冥想的重要性

神经反馈冥想的重要性体现在以下几个方面：

1. **心理调节**：通过反馈调节情绪，缓解焦虑和抑郁。

#### 2.1.2 反馈循环的概念

反馈循环是神经反馈冥想的核心机制。通过实时监测生理信号（如EEG）并将其转化为反馈（如声音或视觉信号），个体可以意识到自己的生理状态，并通过调整行为来优化信号。

### 核心代码实现

```python
import numpy as np
import matplotlib.pyplot as plt

# 模拟EEG数据
def generate_eeg_data():
    fs = 256  # 采样频率
    t = np.arange(0, 10, 1/fs)  # 时间范围
    eeg = np.sin(2 * np.pi * 5 * t) + np.random.normal(0, 0.5, len(t))
    return t, eeg

# 实时反馈函数
def feedback_loop():
    t, eeg = generate_eeg_data()
    plt.figure(figsize=(10, 6))
    plt.plot(t, eeg)
    plt.title('实时EEG反馈')
    plt.xlabel('时间（秒）')
    plt.ylabel('EEG信号（微伏）')
    plt.show()

# 运行反馈循环
if __name__ == "__main__":
    feedback_loop()
```
