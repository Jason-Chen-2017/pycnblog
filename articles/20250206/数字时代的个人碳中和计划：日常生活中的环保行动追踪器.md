### 3.3 算法原理数学模型
碳足迹计算公式：
$$ \text{碳足迹} = \sum (\text{活动} \times \text{碳排放因子}) $$

### 3.4 Python代码实现

```python
def calculate_carbon_footprint(actions):
    carbon_factors = {
        '乘坐公交车': 0.1,
        '步行': 0,
        '开车': 0.2
    }
    total = 0
    for action in actions:
        total += carbon_factors[action]
    return total

actions = ['乘坐公交车', '开车', '步行']
print(calculate_carbon_footprint(actions))
```
