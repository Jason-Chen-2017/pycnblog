### 附录B：心理治疗算法Python代码示例

```python
def diagnose(symptoms, risk_factors):
    # 症状评估
    symptom_score = sum(symptoms) / len(symptoms)
    # 风险因素分析
    risk_score = sum(risk_factors) / len(risk_factors)
    # 诊断确认
    if symptom_score > 0.7 or risk_score > 0.6:
        return "Positive"
    else:
        return "Negative"

# 示例输入
symptoms = [0.8, 0.7, 0.6]
risk_factors = [0.7, 0.8, 0.5]
result = diagnose(symptoms, risk_factors)
print(result)
```
