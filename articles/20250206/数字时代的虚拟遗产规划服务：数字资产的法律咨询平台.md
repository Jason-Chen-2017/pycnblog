### 3.1 系统设计与功能模块

数字遗产规划平台的设计基于模块化架构，确保功能清晰且易于扩展。以下是主要功能模块及其详细功能描述：

1. **用户模块**
   - 用户注册与登录：用户通过邮箱或第三方账号（如Google、微信）注册，并进行身份验证。
   - 用户信息管理：管理个人信息，如姓名、联系方式、紧急联系人等。
   - 遗嘱管理：创建、编辑和查看遗嘱，指定数字资产继承人。

2. **法律咨询模块**

   - 在线咨询：用户可以提交问题，由专业律师团队提供实时或延迟回复。

   - 资产上传：用户上传数字资产，如电子文档、照片、视频等，并进行加密存储。

4. **继承认证模块**
   - 继承人认证：用户去世后，继承人需通过身份验证和法律审查，确认其继承资格。

5. **数据分析模块**

   - 风险评估：识别潜在风险，如账户未授权访问、数据泄露等。

6. **安全防护模块**
   - 数据加密：使用AES算法加密存储数据，确保数据安全性。
   - 访问控制：通过RBAC模型（基于角色的访问控制）管理用户权限，防止未授权访问。

2. **资产上传与加密：**
   ```python
   import os
   from Crypto.Cipher import AES

   def encrypt_file(key, file_path):
       key = key.encode('utf-8')
       mode = AES.MODE_CBC
       iv = os.urandom(16)
       cipher = AES.new(key, mode, iv)
       with open(file_path, 'rb') as infile:
           data = infile.read()
       encrypted_data = cipher.encrypt(pad_data(data))
       with open(file_path + '.encrypted', 'wb') as outfile:
           outfile.write(iv + encrypted_data)

   def pad_data(data):
       # 实现PKCS7 padding
       length = 16 - (len(data) % 16)
       return data + bytes([length] * length)
   ```
