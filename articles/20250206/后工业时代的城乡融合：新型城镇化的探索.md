### 3.2 Python源代码详解  
```python
import numpy as np
import pandas as pd

# 数据加载
data = pd.read_csv('urban_rural.csv')

# 数据预处理
data = data.dropna()
X = data[['城市人口', '乡村人口']].values
y = data['GDP'].values

# 算法实现
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X, y)

# 预测结果
y_pred = model.predict(X)
print('预测GDP:', y_pred)
```

### 3.3 算法原理的数学模型和公式  
模型基于线性回归：  
$$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \epsilon $$  
其中，$y$ 是目标变量，$x_1$ 和 $x_2$ 是特征变量，$\beta_0, \beta_1, \beta_2$ 是系数，$\epsilon$ 是误差项。

### 3.4 举例说明  
假设城市人口为100万，乡村人口为50万，预测GDP为多少？运行代码后，模型给出预测结果。

## 第四部分：数学模型和数学公式 & 详细讲解 & 举例说明

### 4.1 数学公式  
$$ \text{城镇化率} = \frac{\text{城市人口}}{\text{总人口}} \times 100\% $$  
$$ \text{城乡差距} = \text{城市收入} - \text{乡村收入} $$

### 4.2 详细讲解  
城镇化率衡量城市化进程，城乡差距反映经济差异。通过公式分析，制定政策优化资源分配。

### 4.3 举例说明  
某地区总人口1000万，城市人口600万，城镇化率为60%。若乡村收入为1万元，城市收入为3万元，城乡差距为2万元。
