终身学习策略选择的数学模型可以用以下公式表示：

$$
S = w_1 \cdot I + w_2 \cdot T + w_3 \cdot P
$$

其中：
- $S$ 表示学习策略选择结果
- $I$ 表示兴趣权重
- $T$ 表示目标权重
- $P$ 表示问题权重

```python
def main():
    # 数据库连接
    import pymysql
    conn = pymysql.connect(host='localhost', user='root', password='password', db='learning_system')
    cursor = conn.cursor()

    # 读取用户需求
    cursor.execute("SELECT * FROM user_requirements")
    results = cursor.fetchall()

    # 推荐学习策略
    for row in results:
        interest = row[1]
        target = row[2]
        problem = row[3]
        # 计算策略权重
        strategy_score = 0.4 * interest + 0.5 * target + 0.1 * problem
        print(f"用户{row[0]}的学习策略得分为：{strategy_score}")

    conn.close()

if __name__ == "__main__":
    main()
```
