### 1.1 自然语言推理任务简介

自然语言推理（Natural Language Inference, NLI）是自然语言处理（Natural Language Processing, NLP）领域的一个重要研究方向，它旨在理解和模拟人类在阅读和理解文本时所进行的推理过程。NLI的任务是判断一个给定的句子对（ premise 和 hypothesis ）之间的逻辑关系，通常包括三种基本类型：肯定推理（Entailment）、否定推理（Contradiction）和中立推理（Neutral）。

#### 问题背景

自然语言推理任务的研究源于人类在交流过程中需要不断进行推理和判断的需求。传统的自然语言处理技术主要关注文本的生成、分类、摘要和情感分析等，而NLI则进一步探讨了文本之间的逻辑关系，为构建更加智能化的人工智能系统提供了重要支持。

#### 问题描述

自然语言推理任务的核心问题是：给定一个前提（premise）和一个假设（hypothesis），判断假设是否可以从前提中逻辑推导出来。具体来说，NLI任务可以形式化为：

$$
P \rightarrow Q
$$

其中，$P$ 是前提，$Q$ 是假设。NLI系统需要判断 $Q$ 是否成立。

#### 问题解决方法

解决NLI问题的方法通常包括以下几类：

1. **基于规则的方法**：通过定义一系列的规则来匹配前提和假设中的短语，从而判断假设是否成立。这种方法依赖于领域知识和人工编写的规则，因此具有一定的局限性。

2. **基于统计的方法**：通过大量训练数据学习文本之间的逻辑关系，使用机器学习算法（如逻辑回归、支持向量机等）来预测假设的成立情况。

3. **基于神经网络的方法**：利用深度学习模型（如循环神经网络RNN、Transformer等）来捕捉文本中的长距离依赖关系和复杂语义。这种方法在近年来取得了显著的进展，已经成为了NLI任务的主流解决方案。

#### 边界与外延

自然语言推理任务的边界包括：

- **上下文依赖**：NLI的判断结果往往依赖于上下文信息，如何有效地引入上下文信息是NLI研究的一个重要方向。

- **歧义处理**：自然语言中存在大量的歧义现象，NLI系统需要能够处理这些歧义，给出合理的推理结果。

- **跨语言推理**：虽然NLI任务主要关注的是同一语言内的推理，但跨语言推理也是一个重要的研究方向，旨在实现不同语言之间的逻辑关系推断。

NLI的外延则包括：

- **语义理解**：NLI任务不仅涉及语义匹配，还需要理解文本中的深层含义和逻辑结构。

- **常识推理**：在推理过程中，NLI系统需要利用常识知识来辅助判断，例如常识判断“如果今天下雨，那么地面是湿的”。

- **多模态推理**：随着多模态数据的普及，如何结合文本、图像、音频等多模态信息进行NLI推理，是一个具有挑战性的研究方向。

#### 概念结构与核心要素组成

自然语言推理任务的核心概念结构包括：

- **前提（Premise）**：提供信息的句子，是推理的起点。
- **假设（Hypothesis）**：需要验证的句子，是推理的目标。
- **逻辑关系（Logical Relationship）**：前提与假设之间的逻辑联系，包括肯定推理、否定推理和中立推理。
- **上下文（Context）**：影响推理结果的环境信息。

核心要素组成包括：

- **数据集**：用于训练和测试NLI模型的文本数据集，例如SNLI、MNLI等。
- **特征提取**：从文本中提取用于模型训练的特征，如词向量、句嵌入等。
- **模型训练**：使用机器学习算法或深度学习模型对NLI任务进行训练。
- **推理评估**：通过评价指标（如准确率、F1值等）评估NLI模型的性能。

通过以上分析，我们可以看到自然语言推理任务在自然语言处理领域的重要地位和复杂性。接下来，我们将进一步探讨自然语言处理的基础理论和提示词工程的概念与应用。### 1.2 自然语言处理基础

在深入探讨自然语言推理（NLI）任务之前，我们需要了解一些自然语言处理（NLP）的基础概念和技术。自然语言处理是人工智能领域的一个重要分支，其目标是使计算机能够理解、生成和处理人类语言。以下是自然语言处理的一些关键组成部分：

#### 文本预处理

文本预处理是自然语言处理的第一步，其目的是将原始的文本数据转换为适合模型处理的形式。文本预处理通常包括以下步骤：

- **分词（Tokenization）**：将文本分割成单词、短语或符号等基本元素，即“token”。
- **去除停用词（Stopword Removal）**：移除对语义贡献较小的常见单词，如“的”、“是”、“和”等。
- **词形还原（Lemmatization）**：将不同形态的单词转换为基词形式，如“running”还原为“run”。
- **词干提取（Stemming）**：将单词缩减为词干或词根，如“words”、“wording”、“worded”均缩减为“word”。

#### 词向量表示

词向量（Word Embedding）是将单词映射到高维空间中的向量表示，以捕捉单词的语义信息。以下是一些常见的词向量表示方法：

- **词袋模型（Bag-of-Words, BoW）**：将文本表示为单词的频率向量，忽略单词的顺序信息。
- **连续词袋（Continuous Bag-of-Words, CBOW）**：通过上下文词的聚合来预测中心词。
- **Skip-Gram**：通过预测中心词的上下文词来学习词向量，与CBOW相反。
- **Word2Vec**：基于神经网络学习词向量，是目前最常用的词向量表示方法之一。
- **GloVe（Global Vectors for Word Representation）**：通过矩阵分解学习全局的词向量表示，具有较好的性能。

#### 语义分析

语义分析是自然语言处理的高级任务，旨在理解和模拟人类对语言的理解过程。以下是一些重要的语义分析方法：

- **词性标注（Part-of-Speech Tagging）**：为文本中的每个词分配一个词性标签，如名词、动词、形容词等。
- **命名实体识别（Named Entity Recognition, NER）**：识别文本中的特定实体，如人名、组织名、地点名等。
- **情感分析（Sentiment Analysis）**：判断文本中的情感倾向，如正面、负面或中立。
- **语义角色标注（Semantic Role Labeling, SRL）**：识别句子中的动作、参与者及其关系。
- **语义解析（Semantic Parsing）**：将自然语言文本转换为结构化数据或代码。

#### 提示词工程的概念与作用

提示词工程（Prompt Engineering）是近年来兴起的一个领域，旨在通过设计有效的提示来提高模型在自然语言处理任务中的性能。提示词工程的核心思想是利用外部信息（如关键词、问题、指导性语句等）来引导模型进行更好的学习。

- **提示词（Prompt）**：提示词是指用于引导模型预测的一组关键字或短语，它可以是问题、指令或指导性语句。
- **作用**：提示词可以帮助模型更好地理解输入文本的上下文信息，从而提高模型在NLI等任务中的表现。

#### 提示词工程的基本原理

提示词工程的基本原理包括以下几个关键步骤：

1. **数据预处理**：收集和清洗相关的数据集，包括问题和答案对。
2. **提示设计**：设计有效的提示词，使模型能够更好地理解和利用上下文信息。
3. **模型训练**：使用提示词和训练数据集对模型进行训练，以优化模型性能。
4. **评估与调优**：通过测试数据集评估模型的性能，并进行必要的调优。

通过上述分析，我们可以看到自然语言处理基础在自然语言推理任务中的重要性。理解这些基础概念和技巧，将有助于我们更深入地研究和应用自然语言推理技术。在接下来的章节中，我们将进一步探讨提示词工程的具体应用和实现。### 2.1 提示词类型与特点

提示词工程在自然语言处理中发挥着重要作用，不同类型的提示词在应用场景上各有特色。以下是几种常见的提示词类型及其特点：

#### 问题型提示词

**定义**：问题型提示词是一种直接提出问题的提示，用于引导模型进行推断和回答。

**特点**：
- **引导性**：通过提问明确模型的任务方向。
- **适应性**：适用于多种不同类型的推理任务。
- **灵活性**：可以根据具体任务进行调整和优化。

**应用场景**：
- **问答系统**：例如，智能客服系统中使用问题型提示词来引导用户提问。
- **文本生成**：通过提问来引导生成特定的文本内容。

#### 指令型提示词

**定义**：指令型提示词是一种给出具体操作指令的提示，用于指导模型执行特定操作。

**特点**：
- **具体性**：提供明确的操作步骤和目标。
- **控制性**：通过指令控制模型的决策过程。
- **高效率**：适用于需要快速执行的任务。

**应用场景**：
- **自动化流程**：例如，自动化测试脚本中使用指令型提示词来执行特定操作。
- **任务导向系统**：例如，教育系统中使用指令型提示词来指导学生完成特定任务。

#### 指导性提示词

**定义**：指导性提示词是一种提供方向性指导和提示的提示，用于辅助模型理解上下文和目标。

**特点**：
- **辅助性**：在不确定情境下提供参考。
- **启发性**：激发模型产生新的推理路径。
- **灵活性**：可以根据上下文进行调整。

**应用场景**：
- **文本摘要**：例如，在提取长文本摘要时，使用指导性提示词来引导模型关注关键信息。
- **知识图谱构建**：使用指导性提示词来指导模型学习特定领域的知识。

#### 结论型提示词

**定义**：结论型提示词是一种直接给出结论的提示，用于引导模型验证或反驳结论。

**特点**：
- **结论性**：提供明确的预测结果。
- **验证性**：用于模型验证和评估。
- **简洁性**：简化推理过程。

**应用场景**：
- **逻辑推理**：例如，在逻辑推理任务中使用结论型提示词来验证假设的正确性。
- **文本分类**：例如，在分类任务中通过结论型提示词给出分类结果。

#### 对比型提示词

**定义**：对比型提示词是一种通过比较两种或多种情况来引导模型推理的提示。

**特点**：
- **对比性**：突出不同情况之间的差异。
- **分析性**：帮助模型分析多种情况下的结果。
- **指导性**：提供决策依据。

**应用场景**：
- **决策支持系统**：例如，在医疗诊断系统中使用对比型提示词来比较不同治疗方案的效果。
- **市场分析**：例如，在市场调研中使用对比型提示词来分析不同产品的市场表现。

通过上述分析，我们可以看到不同类型的提示词在自然语言处理中的应用特点。了解并合理选择和使用这些提示词，可以显著提高自然语言处理任务的效果和性能。接下来，我们将通过一个表格对比这些提示词的属性特征，进一步探讨它们在具体任务中的应用。#### 2.2 提示词工程的属性特征对比表格

#### 3.1 提示词生成算法

提示词生成算法的核心任务是自动生成能够有效引导模型进行推理的提示词。以下是几种常见的提示词生成算法：

1. **基于规则的生成算法**：
   - **定义**：通过预定义的规则和模板，生成符合特定逻辑关系的提示词。
   - **实现流程**：
     - **规则定义**：根据任务需求定义一系列逻辑规则。
     - **模板填充**：将输入文本和规则模板结合，生成提示词。
   - **示例**：例如，在问答系统中，可以使用规则“如果前提是‘A’，那么提示词是‘A是否正确？’”。

2. **基于统计的生成算法**：
   - **定义**：利用大规模语料库中的统计信息，自动生成提示词。
   - **实现流程**：
     - **数据收集**：收集大量的问题和答案对。
     - **统计模型训练**：使用统计模型（如朴素贝叶斯、决策树等）学习提示词生成的模式。
     - **提示词生成**：根据输入文本和统计模型，生成提示词。
   - **示例**：例如，在情感分析任务中，可以使用统计模型生成提示词来引导情感分类。

3. **基于神经网络的生成算法**：
   - **定义**：利用深度学习模型，通过学习文本特征自动生成提示词。
   - **实现流程**：
     - **模型架构**：通常采用序列到序列（Seq2Seq）模型或Transformer模型。
     - **训练数据**：使用大量的问题和答案对作为训练数据。
     - **生成过程**：模型接收输入文本，通过解码器生成提示词。
   - **示例**：例如，在文本生成任务中，可以使用Transformer模型生成与输入文本相关的问题或指导性提示。

提示词生成算法的核心是利用数学模型从输入文本中推导出具有指导意义的提示词。以下是几种常见提示词生成算法的数学模型：

#### 3.4.1 基于规则的生成算法

**模型公式**：
$$
P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}
$$

**解释**：
- **P(A|B)**：在给定前提B的情况下，生成提示词A的概率。
- **P(B|A)**：在提示词A已知的情况下，前提B成立的概率。
- **P(A)**：提示词A的概率。
- **P(B)**：前提B的概率。

**应用示例**：
假设我们需要从文本“今天天气很好”中生成提示词。使用上述公式，我们可以计算不同提示词（如“天气好吗？”和“今天适合户外活动吗？”）的概率，然后选择概率较高的提示词。

#### 3.4.2 基于统计的生成算法

**模型公式**：
$$
P(\text{Prompt}) = \frac{N(\text{Prompt}, \text{Context})}{N(\text{Context})}
$$

**解释**：
- **P(Prompt)**：生成提示词Prompt的概率。
- **N(Prompt, Context)**：在特定上下文Context中出现提示词Prompt的次数。
- **N(Context)**：在特定上下文Context中出现的所有提示词的总次数。

**应用示例**：
在情感分析任务中，我们可以使用统计模型计算不同提示词（如“很开心”和“很难过”）在文本中的出现频率，然后根据出现频率选择最合适的提示词。

#### 3.4.3 基于神经网络的生成算法

**模型公式**：
$$
\text{Logits} = \text{Model}(\text{Input}, \text{Prompt})
$$

**解释**：
- **Logits**：提示词的预测概率分布。
- **Model**：神经网络模型。
- **Input**：输入文本。
- **Prompt**：提示词。

**应用示例**：
在问答系统中，可以使用Transformer模型或BERT模型来生成提示词。模型接收输入文本并输出提示词的Logits，然后通过softmax函数将Logits转换为概率分布。

以下是基于神经网络的生成算法的Python代码实现示例：

```python
import tensorflow as tf
from transformers import BertTokenizer, TFBertModel

# 加载预训练的BERT模型和分词器
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = TFBertModel.from_pretrained('bert-base-uncased')

# 输入文本
input_text = "What is the weather like today?"

# 预处理输入文本
input_ids = tokenizer.encode(input_text, add_special_tokens=True, return_tensors='tf')

# 通过BERT模型得到文本嵌入向量
outputs = model(input_ids)

# 输出Logits
logits = outputs.logits

# 使用softmax函数得到概率分布
probabilities = tf.nn.softmax(logits, axis=-1)

# 输出生成的提示词
prompt = tokenizer.decode([probabilities.argmax(axis=-1).numpy()])

print(prompt)
```

提示词筛选算法的目标是从生成的多个提示词中选择最优的提示词，以提高自然语言推理任务的性能。以下是几种常见提示词筛选算法的数学模型：

#### 3.5.1 基于频率的筛选算法

**模型公式**：
$$
f(P) = \frac{c(P)}{N}
$$

**解释**：
- **f(P)**：提示词P的频率。
- **c(P)**：提示词P在训练数据中出现的次数。
- **N**：训练数据中所有提示词的出现次数总和。

**应用示例**：
在文本分类任务中，我们可以计算每个提示词的频率，然后选择频率最高的提示词。例如，假设有一个训练数据集，其中提示词“A”出现了100次，总共有500个不同的提示词，那么提示词“A”的频率为0.2，我们可以选择频率最高的几个提示词进行筛选。

#### 3.5.2 基于相关性的筛选算法

**模型公式**：
$$
r(P, T) = \frac{\sum_{i=1}^{n} w_i \cdot \text{sim}(p_i, t_i)}{n}
$$

**解释**：
- **r(P, T)**：提示词P与目标答案T的相关性。
- **w_i**：权重，用于调整不同词语的重要性。
- **sim(p_i, t_i)**：提示词P中第i个词与目标答案T中第i个词的相似度。
- **n**：提示词P中词的数量。

**应用示例**：
在问答系统中，我们可以计算每个提示词与目标答案的相似度，然后选择相关性最高的提示词。例如，假设提示词“今天是星期几？”与目标答案“星期三”的相似度为0.8，而其他提示词的相似度较低，那么我们可以选择“今天是星期几？”作为最优提示词。

#### 3.5.3 基于模型的筛选算法

**模型公式**：
$$
P(S|P) = \frac{P(P|S) \cdot P(S)}{P(P)}
$$

**解释**：
- **P(S|P)**：在给定提示词P的情况下，选择标准S的概率。
- **P(P|S)**：在标准S已知的情况下，提示词P的概率。
- **P(S)**：标准S的概率。
- **P(P)**：提示词P的概率。

**应用示例**：
在自然语言推理任务中，我们可以使用机器学习模型预测每个提示词的性能，然后选择预测性能最高的提示词。例如，假设有一个预测模型，提示词“A”在标准“准确性”下的概率为0.9，而其他提示词的概率较低，那么我们可以选择“准确性”最高的提示词。

以下是基于模型的筛选算法的Python代码实现示例：

```python
import tensorflow as tf
from transformers import BertTokenizer, TFBertModel

# 加载预训练的BERT模型和分词器
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = TFBertModel.from_pretrained('bert-base-uncased')

# 提示词和标准
prompts = ["What is the weather like today?", "Is it sunny outside?", "How is the weather?"]
standards = ["sunny", "weather"]

# 预处理输入文本
input_ids = tokenizer.encode(standards[0], add_special_tokens=True, return_tensors='tf')

# 通过BERT模型得到文本嵌入向量
outputs = model(input_ids)

# 获取目标答案的嵌入向量
answer_embedding = outputs.last_hidden_state[:, 0, :]

# 预处理提示词
prompt_ids = [tokenizer.encode(prompt, add_special_tokens=True, return_tensors='tf') for prompt in prompts]

# 计算提示词与答案的相似度
similarity_scores = []
for prompt_id in prompt_ids:
    prompt_embedding = model(prompt_id).last_hidden_state[:, 0, :]
    similarity_score = tf.reduce_sum(prompt_embedding * answer_embedding, axis=1)
    similarity_scores.append(similarity_score)

# 使用softmax函数得到概率分布
probabilities = tf.nn.softmax(tf.stack(similarity_scores), axis=0)

# 输出生成的提示词
best_prompt = tokenizer.decode([probabilities.argmax(axis=0).numpy()])

print(best_prompt)
```

提示词优化算法的核心目的是通过调整和优化提示词，提高其在特定任务中的性能。以下是几种常见提示词优化算法的数学模型：

#### 3.6.1 基于贪心的优化算法

**模型公式**：
$$
\Delta P(P') = \max \left\{ \sum_{i=1}^{n} w_i \cdot \text{similarity}(p_i', t_i) - \sum_{i=1}^{n} w_i \cdot \text{similarity}(p_i, t_i) \right\}
$$

**解释**：
- **$\Delta P(P')$**：提示词P'相对于原始提示词P的性能提升。
- **$w_i$**：权重，用于调整不同词语的重要性。
- **$\text{similarity}(p_i', t_i)$**：提示词P'中第i个词与目标答案t_i的相似度。
- **$\text{similarity}(p_i, t_i)$**：原始提示词P中第i个词与目标答案t_i的相似度。
- **$n$**：提示词中词的数量。

**应用示例**：
在问答系统中，我们可以通过计算每个词对性能的提升，然后选择提升最大的词进行替换或调整。例如，假设提示词“今天天气好吗？”中的一个词“今天”的相似度提升最大，那么我们可以将其替换为更具体的日期词，如“明天”。

#### 3.6.2 基于遗传算法的优化算法

**模型公式**：
$$
P(S') = \frac{1}{N} \sum_{i=1}^{N} \left[ 2 \cdot \left( f(S') \right)^2 + \frac{1}{2} \cdot \left( 1 - f(S') \right)^2 \right]
$$

**解释**：
- **$P(S')$**：标准S'的适应度。
- **$f(S')$**：标准S'的适应度函数值。
- **$N$**：种群中标准的数量。

**应用示例**：
在文本生成任务中，我们可以使用遗传算法不断调整提示词，直到找到最优的提示词组合。例如，通过计算每个提示词组合的适应度，我们可以选择适应度最高的组合。

#### 3.6.3 基于强化学习的优化算法

**模型公式**：
$$
Q(S, A) = r(S, A) + \gamma \max_{A'} Q(S, A')
$$

**解释**：
- **$Q(S, A)$**：状态S下动作A的预期回报。
- **$r(S, A)$**：状态S下动作A的即时回报。
- **$\gamma$**：折扣因子，用于考虑未来回报。
- **$Q(S, A')$**：状态S下其他动作A'的预期回报。

**应用示例**：
在问答系统中，我们可以使用强化学习算法不断调整提示词，使其在交互过程中获得更高的用户满意度。例如，通过计算每次交互的即时回报，我们可以调整提示词，使其更符合用户的需求。

以下是基于贪心优化算法的Python代码实现示例：

```python
import numpy as np

# 假设我们有一个提示词列表和权重列表
prompts = ["今天天气好吗？", "明天天气如何？", "这个季节的天气怎么样？"]
weights = [0.4, 0.3, 0.3]

# 定义相似度计算函数
def similarity(p, t):
    return np.dot(p, t) / (np.linalg.norm(p) * np.linalg.norm(t))

# 初始提示词
current_prompt = "今天天气好吗？"

# 定义贪心优化函数
def greedy_optimization(prompts, weights):
    max_similarity = -1
    best_prompt = None
    
    # 遍历所有可能的提示词
    for prompt in prompts:
        if prompt != current_prompt:
            # 计算性能提升
            similarity_score = similarity(weights, np.array([similarity(current_prompt, prompt)]))
            if similarity_score > max_similarity:
                max_similarity = similarity_score
                best_prompt = prompt
                
    return best_prompt

# 优化提示词
current_prompt = greedy_optimization(prompts, weights)
print("优化后的提示词：", current_prompt)
```

##### 8.1.1 文本预处理

文本预处理是自然语言处理的基础步骤，包括分词、去除停用词和词形还原等。以下是文本预处理的Python代码实现：

```python
import nltk
from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize
from nltk.stem import PorterStemmer

# 加载NLTK资源
nltk.download('punkt')
nltk.download('stopwords')

# 初始化停用词和词形还原器
stop_words = set(stopwords.words('english'))
stemmer = PorterStemmer()

def preprocess_text(text):
    # 分词
    tokens = word_tokenize(text)
    
    # 去除停用词
    tokens = [token for token in tokens if token.lower() not in stop_words]
    
    # 词形还原
    tokens = [stemmer.stem(token) for token in tokens]
    
    return ' '.join(tokens)

# 测试文本预处理

preprocessed_text = preprocess_text(sample_text)
print("Preprocessed Text:", preprocessed_text)
```

##### 8.1.2 提示词生成

提示词生成是提示词工程的关键步骤。我们使用基于统计的方法来生成提示词，即通过计算词频来生成常见的提示词。以下是提示词生成的Python代码实现：

```python
from collections import Counter

def generate_prompt(preprocessed_text):
    # 计算词频
    word_freq = Counter(preprocessed_text.split())
    
    # 选择高频词汇作为提示词
    top_words = [word for word, freq in word_freq.most_common(5)]
    
    # 生成提示词
    prompt = "What is the most important information in this text?"
    if top_words:
        prompt += " Based on the words: " + ", ".join(top_words)
    
    return prompt

# 测试提示词生成
prompt = generate_prompt(preprocessed_text)
print("Generated Prompt:", prompt)
```

##### 8.1.3 自然语言推理模型

自然语言推理模型用于处理提示词，并进行逻辑推理以得到推理结果。我们使用预训练的BERT模型来实现自然语言推理模型。以下是自然语言推理模型的Python代码实现：

```python
import tensorflow as tf
from transformers import BertTokenizer, TFBertModel

# 加载BERT模型和分词器
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = TFBertModel.from_pretrained('bert-base-uncased')

def nli_model(prompt):
    # 预处理提示词
    inputs = tokenizer(prompt, return_tensors='tf')
    
    # 获取BERT模型的嵌入向量
    outputs = model(inputs)
    last_hidden_state = outputs.last_hidden_state
    
    # 计算推理结果
    result = tokenizer.decode(last_hidden_state[:, 0, :].numpy())
    
    return result

# 测试自然语言推理模型
result = nli_model(prompt)
print("NLI Result:", result)
```

```python
import nltk
from nltk.corpus import snli
from nltk.tokenize import word_tokenize

# 加载SNLI数据集
snli_data = snliCorpus()

def preprocess_data(data):
    prompts = []
    hypotheses = []
    labels = []

    for item in data:
        prompt = word_tokenize(item['premise'])
        hypothesis = word_tokenize(item['hypothesis'])
        label = item['label']

        prompts.append(prompt)
        hypotheses.append(hypothesis)
        labels.append(label)

    return prompts, hypotheses, labels

prompts, hypotheses, labels = preprocess_data(snli_data)
```
