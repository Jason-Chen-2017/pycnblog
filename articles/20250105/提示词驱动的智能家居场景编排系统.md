### 2. 背景与核心概念

#### 2.1 问题背景

智能家居系统的发展已经取得了一定的成果，然而在实际应用中，用户仍然面临以下问题：

- 场景编排复杂：用户需要手动设置场景，操作繁琐。
- 智能度不高：现有系统无法根据用户行为和需求自动调整场景。
- 设备兼容性问题：不同品牌的设备之间难以实现无缝连接和协同工作。

#### 2.2 核心概念

- 提示词（Prompt）：用于描述用户需求的关键词或短语。
- 场景（Scene）：由一组设备组成的自动化场景。
- 场景编排（Scene Composition）：根据用户需求自动调整场景的过程。

### 3. 提示词驱动的系统原理

#### 3.1 概念与工作原理

提示词驱动的智能家居场景编排系统通过以下步骤实现：

1. 用户输入提示词。
2. 系统分析提示词，理解用户需求。
3. 根据用户需求，系统自动编排场景。
4. 设备根据场景指令执行相应的操作。

#### 3.2 提示词类型

- 指令型提示词：如“打开空调”。
- 条件型提示词：如“晚上10点后，打开客厅灯”。
- 关联型提示词：如“天气冷，加热水器加热”。

#### 3.3 场景编排算法

场景编排算法根据用户输入的提示词，将用户需求转化为具体的设备控制指令。以下是一个简单的算法流程：

```python
class SceneCompositionSystem:
    def __init__(self):
        self.devices = []
        self.scenes = []

    def add_device(self, device):
        self.devices.append(device)

    def create_scene(self, name, devices):
        scene = Scene(name, devices)
        self.scenes.append(scene)

    def execute_scene(self, name):
        for scene in self.scenes:
            if scene.name == name:
                for device in scene.devices:
                    device.execute()
```

```python
    scene_data = request.get_json()
```
