## 强化学习基础理论

### 2.1 强化学习的基本概念

强化学习由三部分组成：智能体（Agent）、环境（Environment）和策略（Policy）。智能体是执行动作的实体，环境是智能体所处的情境，策略是智能体根据当前状态选择动作的规则。

### 2.1.1 强化学习的目标

强化学习的目标是通过不断与环境交互，学习出一个最优策略，使得智能体能够在长期内获得最大的累计奖励。

### 2.1.2 强化学习的环境与状态

环境是一个五元组（S, A, R, P, Γ），其中S是状态空间，A是动作空间，R是奖励函数，P是状态转移概率分布函数，Γ是奖励函数。

### 2.1.3 动作与奖励

动作是智能体在特定状态下执行的行为，奖励是环境对智能体动作的反馈。奖励可以激励智能体采取有利于目标的行为。

### 2.2 基本强化学习算法

强化学习算法分为两类：值函数方法（Value-based Methods）和策略优化方法（Policy-based Methods）。

#### 2.2.1 Q-Learning算法

Q-Learning算法是一种基于值函数的强化学习算法，其核心思想是学习状态-动作值函数Q(s, a)，即执行动作a在状态s下的最大预期奖励。以下是Q-Learning算法的数学模型：

$$ Q(s, a) = \sum_{s'} p(s' | s, a) \cdot [r(s, a, s') + \gamma \cdot \max_{a'} Q(s', a')] $$

其中，$p(s' | s, a)$是状态转移概率，$r(s, a, s')$是奖励值，$\gamma$是折扣因子。

Python代码实现：

```python
import numpy as np

def q_learning(env, num_episodes, learning_rate, discount_factor):
    Q = np.zeros((env.nS, env.nA))
    
    for episode in range(num_episodes):
        state = env.reset()
        done = False
        while not done:
            action = np.argmax(Q[state])
            next_state, reward, done, _ = env.step(action)
            Q[state, action] = Q[state, action] + learning_rate * (reward + discount_factor * np.max(Q[next_state]) - Q[state, action])
            state = next_state
    
    return Q
```

#### 2.2.2 SARSA算法

SARSA（同步优势估计）算法是一种基于策略的强化学习算法，其核心思想是同时考虑当前状态和下一个状态的值。以下是SARSA算法的数学模型：

$$ \pi(s, a) = \begin{cases} 
1 & \text{if } a = \arg\max_a Q(s, a) \\
0 & \text{otherwise} 
\end{cases} $$

Python代码实现：

```python
import numpy as np

def sarsa(env, num_episodes, learning_rate, discount_factor):
    Q = np.zeros((env.nS, env.nA))
    
    for episode in range(num_episodes):
        state = env.reset()
        done = False
        while not done:
            action = np.random.choice(env.nA)
            next_state, reward, done, _ = env.step(action)
            Q[state, action] = Q[state, action] + learning_rate * (reward + discount_factor * Q[next_state, action] - Q[state, action])
            state = next_state
    
    return Q
```
