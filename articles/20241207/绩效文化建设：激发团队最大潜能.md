**3.2 Python源代码**

```python
# 定义目标达成情况评估函数
def evaluate_performance(target, actual):
    if actual >= target:
        return "达成"
    else:
        return "未达成"

# 定义奖励团队函数
def reward_team(performance):
    if performance == "达成":
        print("奖励团队")
    else:
        print("需要改进")

# 应用算法
target = 100  # 设定目标值为100
actual = 120  # 实际完成值为120

performance = evaluate_performance(target, actual)
reward_team(performance)
```

**3.3 数学模型和公式**

$$
绩效 = f(目标达成率, 团队合作度, 创新能力)
$$

其中，目标达成率、团队合作度和创新能力分别用以下公式表示：

$$
目标达成率 = \frac{实际完成值}{目标值}
$$

$$
团队合作度 = \frac{团队总贡献}{个体贡献之和}
$$

$$
创新能力 = \frac{创新项目数量}{总项目数量}
$$

**3.4 详细讲解与举例说明**

假设一个团队的目标是完成100个任务，实际完成了120个任务，同时团队合作度和创新能力都很高。根据上述公式，我们可以计算出该团队的绩效。

$$
目标达成率 = \frac{120}{100} = 1.2
$$

$$
团队合作度 = \frac{120}{100} = 1.2
$$

$$
创新能力 = \frac{10}{100} = 0.1
$$

$$
绩效 = 1.2 \times 1.2 \times 0.1 = 0.144
$$

因此，该团队的绩效得分为0.144，表明团队在目标达成、团队合作和创新能力方面都有出色的表现。
