## 第2章：涌现模型的基本原理

### 2.1 涌现模型的概念

涌现模型（Emergence Model）起源于复杂系统和自组织理论，是研究复杂系统中个体元素相互作用导致宏观现象生成的一种理论框架。涌现现象（Emergence）是指在一个复杂系统中，个体的简单行为通过相互作用和集体行为规则，可以产生出系统层面的复杂结构和功能。这种从简单到复杂、从微观到宏观的转变，被称为涌现。

涌现模型的核心概念包括：

1. **个体元素**：这是系统中的基本组成部分，可以是单个个体（如蚂蚁、神经元）或抽象元素（如用户、像素）。

2. **相互作用**：个体元素之间的相互作用是涌现现象的基础。这些相互作用可以是直接的物理接触、信息的传递，或是更抽象的规则和约束。

3. **宏观现象**：通过个体元素的相互作用，系统可以表现出新的、复杂的宏观结构和功能。例如，蚂蚁的集体觅食行为是每个蚂蚁个体简单行为的涌现结果。

4. **自组织**：涌现模型的一个重要特征是系统的自组织性。自组织指的是系统在无外部控制的情况下，通过个体元素之间的相互作用，自发形成有序的结构和功能。这种现象在自然界和社会系统中普遍存在，如市场的供需关系、城市交通的流量分布等。

涌现模型与复杂系统理论、自组织理论等密切相关，它们共同构成了理解复杂系统的理论框架。

1. **复杂系统理论**：复杂系统理论强调系统的复杂性和层次性。复杂系统通常具有大量的组成部分和相互作用，这些组成部分可以是物理实体、抽象概念或规则。涌现模型是复杂系统理论的一个重要组成部分，它通过研究个体元素之间的相互作用，揭示了复杂系统从微观到宏观的转变过程。

import matplotlib.pyplot as plt
from collections import defaultdict

# 个体状态类
class Individual:
    def __init__(self, state):
        self.state = state
        self.neighbors = []

    def update_state(self, neighbors):
        average_state = np.mean([neighbor.state for neighbor in neighbors])
        self.state = average_state

    def add_neighbor(self, neighbor):
        self.neighbors.append(neighbor)

# 邻居选择函数
def select_neighbors(individuals, k):
    return np.random.choice(individuals, k, replace=False)

# 迭代计算函数
def iterate(individuals, k, iterations):
    for _ in range(iterations):
        new_individuals = []
        for individual in individuals:
            neighbors = select_neighbors(individuals, k)
            individual.update_state(neighbors)
            new_individuals.append(individual)
        individuals = new_individuals
    return individuals

# 数据可视化函数
def visualize(individuals):
    states = [individual.state for individual in individuals]
    plt.plot(states)
    plt.xlabel('Iteration')

    n_individuals = 100  # 个体数量

    # 运行迭代计算
