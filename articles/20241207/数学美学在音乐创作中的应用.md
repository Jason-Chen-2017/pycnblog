以下是一个简单的Python代码示例，用于生成一个基于斐波那契数列的旋律：

```python
import numpy as np

# 定义斐波那契数列
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

# 生成旋律
def generate_melody(length):
    melody = []
    for i in range(length):
        note = 440 * 2 ** (fibonacci(i) / 12)
        melody.append(note)
    return melody

# 生成并打印旋律
print(generate_melody(10))
```
