### 2.1 团队目标

团队目标是指团队共同追求的长期愿景和短期目标。设定清晰的团队目标有助于统一团队成员的努力方向，提高团队的凝聚力和工作效率。以下是团队目标的核心原理和特征：

#### 2.1.1 团队目标的设定方法

1. **SMART原则**：团队目标应具备具体（Specific）、可衡量（Measurable）、可达成（Achievable）、相关性（Relevant）和时限性（Time-bound）的特点。
2. **共识性**：团队目标应得到团队成员的一致认同，确保每个人都清楚目标的意义和自己的责任。
3. **可调整性**：在实现团队目标的过程中，应根据实际情况调整目标和策略。

#### 2.1.2 团队目标的重要性

1. **明确方向**：团队目标为团队成员提供了明确的方向，有助于集中精力实现共同目标。
2. **激励员工**：明确的团队目标可以激发员工的积极性和创造力，提高工作满意度。
3. **优化资源分配**：团队目标有助于优化资源分配，确保团队在资源有限的情况下实现最大化产出。

#### 3.1.5 数学模型和公式

团队绩效评估的数学模型通常涉及以下公式：

1. **综合绩效指数**：$P = \frac{\sum_{i=1}^{n} w_i \cdot P_i}{n}$
   - $P$：综合绩效指数
   - $w_i$：第$i$个指标的权重
   - $P_i$：第$i$个指标的得分

2. **加权平均得分**：$\bar{P} = \frac{\sum_{i=1}^{n} P_i}{n}$
   - $\bar{P}$：加权平均得分
   - $P_i$：第$i$个指标的得分

通过这些数学模型，我们可以对团队绩效进行量化评估，以便更好地了解团队的整体表现。

from flask import Flask, request, jsonify
from sqlalchemy import create_engine

app = Flask(__name__)

DATABASE_URL = "mysql+pymysql://username:password@localhost:3306/db_name"
engine = create_engine(DATABASE_URL)

@app.route('/tasks', methods=['POST'])
def create_task():
    data = request.json
    task = {
        'title': data['title'],
        'description': data['description'],
        'status': 'pending'
    }
    with engine.connect() as conn:
        conn.execute('INSERT INTO tasks (title, description, status) VALUES (:title, :description, :status)', task)
    return jsonify({'message': 'Task created successfully'}), 201

@app.route('/tasks', methods=['GET'])
def get_tasks():
    with engine.connect() as conn:
        result = conn.execute('SELECT * FROM tasks')
        tasks = [{'id': row.id, 'title': row.title, 'description': row.description, 'status': row.status} for row in result]
    return jsonify(tasks), 200

if __name__ == '__main__':
    app.run(debug=True)
