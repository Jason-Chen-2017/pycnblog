##### 2.2 数学模型与公式

**数学公式**：

$$
\frac{dJ}{dx} = 0
$$

**详细讲解**：

上述公式表示在给定初始和末状态的情况下，要找到使作用量 \( J \) 取极小值的 \( x \) 值。其中，\( J \) 表示作用量，\( x \) 表示变量。

**举例说明**：

假设我们有一个程序，其输入为 \( x \)，输出为 \( y \)。我们的目标是找到 \( x \) 的最优值，使得程序执行时间 \( J \) 最小。

import numpy as np

    # 模拟程序执行时间
    return np.sqrt(x)

x = 4

在这个例子中，我们使用牛顿法来求解最小作用量问题。

```python
def newton_method(f, x0, tol=1e-6, max_iter=100):
    x = x0
    for _ in range(max_iter):
        f_prime = np.gradient(f(x))
        x -= f(x) / f_prime
        if np.abs(f(x)) < tol:
            return x
    return None

x_min = newton_method(program_time, x)
print(x_min)
```
