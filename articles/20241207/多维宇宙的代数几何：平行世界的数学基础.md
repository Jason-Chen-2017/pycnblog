## 第2章：代数几何基础

### 2.1 代数几何的基本概念

代数几何是一门研究代数方程的几何性质的数学分支，它结合了代数和几何两个领域。在代数几何中，我们关注的是由代数方程定义的几何对象，以及这些对象之间的相互关系。

首先，我们需要了解一些基本概念：

- **代数集合**：代数集合是由一组满足某个代数方程的点构成的集合。例如，方程 $x^2 + y^2 = 1$ 定义了一个代数集合，即单位圆。
- **代数簇**：代数簇是代数集合的一种扩展，它是由一组代数方程定义的几何对象。代数簇可以是零维的（如单个点或一条线），一维的（如圆或椭圆），二维的（如圆锥曲线），甚至是高维的（如超平面或高维流形）。
- **维数**：代数簇的维数是指其几何对象的最大线性无关向量空间的维数。例如，一条直线是一维的，一个平面是二维的。
- **次数**：代数簇的次数是指定义该簇的最高的多项式的次数。例如，方程 $x^3 + y^3 - z^3 = 0$ 定义了一个三次代数簇。

### 2.2 代数几何的基本结构

代数几何中的基本结构包括线性空间、向量空间和线性映射等。

- **线性空间**：线性空间是一组向量的集合，这些向量可以线性组合。线性空间满足以下性质：
  - 封闭性：对于任意两个向量 $v_1$ 和 $v_2$，它们的线性组合 $a_1v_1 + a_2v_2$ 也属于该线性空间。
  - 加法交换律：$v_1 + v_2 = v_2 + v_1$。
  - 加法结合律：$(v_1 + v_2) + v_3 = v_1 + (v_2 + v_3)$。
  - 存在零向量：存在一个零向量 $0$，使得对于任意向量 $v$，有 $v + 0 = v$。
  - 存在加法逆元：对于任意非零向量 $v$，存在一个向量 $-v$，使得 $v + (-v) = 0$。
- **向量空间**：向量空间是线性空间的进一步扩展，它包括零向量，并且满足向量加法和标量乘法的运算。向量空间中的标量可以是实数、复数等。

- **线性映射**：线性映射是指将一个线性空间映射到另一个线性空间的函数，它满足以下性质：
  - 线性组合保持：对于任意向量 $v_1, v_2$ 和标量 $a_1, a_2$，有 $L(a_1v_1 + a_2v_2) = a_1L(v_1) + a_2L(v_2)$。
  - 常数乘法保持：对于任意向量 $v$ 和标量 $a$，有 $L(av) = aL(v)$。

### 2.3 代数几何的基本性质

代数几何的基本性质包括封闭性、连通性、维数等。

- **封闭性**：代数簇在其定义域内是封闭的，即如果点 $P$ 在代数簇上，那么通过 $P$ 的任意直线也完全位于代数簇上。
- **连通性**：代数簇是连通的，即代数簇中的任意两点都可以通过一条连续的路径连接。
- **维数**：代数簇的维数是其最基本的结构特征，它决定了代数簇的几何性质。例如，一维代数簇是曲线，二维代数簇是曲面，而三维代数簇是三维流形。
