```python
def optimal_compression(data):
    # 初始化压缩结果
    compressed_result = []

    # 循环处理数据
    while data:
        # 找到最长的相同子串
        longest_substring = find_longest_substring(data)

        # 将相同子串添加到压缩结果中
        compressed_result.append(longest_substring)

        # 删除已压缩的子串
        data = data.replace(longest_substring, '')

    return compressed_result

def find_longest_substring(data):
    # 寻找最长的相同子串
    longest_substring = ""
    for i in range(len(data)):
        for j in range(i+1, len(data)+1):
            substring = data[i:j]
            if substring == data:
                longest_substring = substring
                break
    return longest_substring
```

- **计算复杂度分析**：
  - 假设输入数据长度为n，则找到最长相同子串的时间复杂度为O(n^2)。
  - 压缩算法的总时间复杂度为O(n^3)，因为在每次循环中，都需要寻找最长相同子串。

- **优化策略**：
  - 可以通过改进算法来降低时间复杂度，例如使用哈希表或动态规划算法来优化寻找最长相同子串的过程。
