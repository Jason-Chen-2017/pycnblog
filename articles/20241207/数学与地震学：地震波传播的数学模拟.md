#### 地震波类型

地震波根据传播方式和特性可以分为多种类型，主要包括体波和面波。体波包括纵波（P波）和横波（S波），它们在固体、液体和气体中均能传播。纵波是压缩波，质点沿着波的传播方向振动；横波是剪切波，质点垂直于波的传播方向振动。面波则包括瑞雷波（Rayleigh波）和勒夫波（Love波），它们只能在固体表面附近传播，具有较大的破坏性。

P波和S波的传播速度不同，通常情况下，P波速度大于S波速度。这是因为P波是压缩波，需要较小的能量就能传播；而S波是剪切波，需要较大的能量才能传播。这种速度差异导致了地震波传播过程中的波形畸变和干涉现象。

#### 数值求解方法

波动方程的求解通常需要借助数值方法。常见的数值求解方法包括有限差分法、有限元素法、有限体积法等。这些方法通过将连续的波动方程转化为离散的方程组，从而在计算机上进行求解。

有限差分法是一种常见的一维数值求解方法，其基本思想是将空间和时间离散化，将连续的波动方程转化为离散的差分方程。例如，对于一维波动方程：

$$
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}

$$
u_{i+1,n+1} - 2u_{i,n+1} + u_{i-1,n+1} = c^2 (u_{i+1,n} - 2u_{i,n} + u_{i-1,n})
$$

其中，$u_{i,n}$ 表示在位置 $i$ 和时间 $n$ 的位移，$c$ 是地震波在介质中的传播速度。

有限元素法和有限体积法则是适用于二维和三维问题的数值求解方法。有限元素法通过将空间划分为有限个元素，在每个元素内部采用线性函数或高阶函数近似地震波，从而得到一个线性方程组。有限体积法则通过将空间划分为有限个控制体积，利用守恒定律将波动方程转化为离散的守恒方程。

#### 有限差分法（Finite Difference Method, FDM）

有限差分法是一种常用的数值求解方法，适用于一维和二维问题。其基本思想是将空间和时间离散化，用差分近似代替微分，从而将波动方程转化为离散的代数方程。

**一维波动方程的离散化**：

对于一维波动方程：

$$
\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}
$$

其中，$u(x,t)$ 表示地震波在位置 $x$ 和时间 $t$ 的位移，$c$ 是地震波在介质中的传播速度。

我们可以将其离散化为：

$$
u_{i+1,n+1} - 2u_{i,n+1} + u_{i-1,n+1} = c^2 (u_{i+1,n} - 2u_{i,n} + u_{i-1,n})
$$

其中，$u_{i,n}$ 表示在位置 $i$ 和时间 $n$ 的位移。

#### 有限元素法（Finite Element Method, FEM）

有限元素法是一种更为通用的数值求解方法，适用于复杂几何形状和三维问题。其基本思想是将求解区域划分为有限个元素，在每个元素内部采用线性函数或高阶函数近似地震波。

**二维波动方程的离散化**：

对于二维波动方程：

$$
\frac{\partial^2 u}{\partial t^2} = c^2 \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} \right)
$$

我们可以采用有限元素法将其离散化为：

$$
\sum_{j=1}^{N} (u_j(t) - u_j(0)) \phi_j(x, y) = \frac{c^2}{dt} \sum_{j=1}^{N} \phi_j(x, y) \int_{\Omega} u(x, y) \phi_j(x, y) dxdy
$$

其中，$u_j(t)$ 是在第 $j$ 个节点上的位移，$\phi_j(x, y)$ 是第 $j$ 个元素上的基函数，$\Omega$ 是求解区域。

**mermaid流程图**：

```mermaid

    A[建立有限元模型] --> B[划分元素]
    B --> C[定义基函数]
    C --> D[建立方程组]
    D --> E[求解方程组]
    E --> F[输出结果]
```

**Python代码示例**：

```python
import numpy as np
from scipy.sparse import spdiags
from scipy.sparse.linalg import spsolve

# 定义求解区域
x = np.linspace(0, 10, 100)
y = np.linspace(0, 10, 100)
X, Y = np.meshgrid(x, y)

# 初始化参数
c = 3000  # 地震波传播速度
dt = 0.01 # 时间步长

# 划分元素
N = len(x)
elements = [[(i, j), (i+1, j), (i+1, j+1), (i, j+1)] for i in range(N-1) for j in range(N-1)]

# 定义基函数
def basis(x, y):
    return np.array([1, x, y, x*y])

# 建立方程组
A = np.zeros((N*N, N*N))
b = np.zeros(N*N)

for element in elements:
    for i in range(N):
        for j in range(N):
            x_i, y_i = X[element[i][0], element[i][1]], Y[element[i][0], element[i][1]]
            A += basis(x_i, y_i) * basis(x_i, y_i).T

    for i in range(N):
        x_i, y_i = X[element[i][0], element[i][1]], Y[element[i][0], element[i][1]]
        b += basis(x_i, y_i) * c**2 * (X[element[i][0], element[i][1]] - X[element[i][0], element[i][1]-1])

# 求解方程组
u = spsolve(A, b)

# 输出结果
plt.imshow(u.reshape(N, N), extent=[0, 10, 0, 10], origin='lower')
plt.colorbar()
plt.show()
```

$$
$$
u_{i+1,j-1,n+1} - 2u_{i,j-1,n+1} + u_{i-1,j-1,n+1} = c^2 \left( u_{i+1,j,n+1} - 2u_{i,j,n+1} + u_{i-1,j,n+1} \right)
$$

#### 有限元素法

有限元素法通过将求解区域划分为有限个元素，并在每个元素内部采用线性函数或高阶函数近似地震波。以下给出二维波动方程的离散化形式。

$$
\sum_{j=1}^{N} (u_j(t) - u_j(0)) \phi_j(x, y) = \frac{c^2}{dt} \sum_{j=1}^{N} \phi_j(x, y) \int_{\Omega} u(x, y) \phi_j(x, y) dxdy
$$

其中，$u_j(t)$ 是在第 $j$ 个节点上的位移，$\phi_j(x, y)$ 是第 $j$ 个元素上的基函数，$\Omega$ 是求解区域。

#### 测试示例

以下是一个简单的测试示例，用于验证波动方程的数学公式。

**示例**：考虑一维波动方程，其初始条件和边界条件如下：

- 初始条件：$u(x, 0) = \sin(\pi x)$
- 边界条件：$u(0, t) = 0$，$u(L, t) = 0$

我们需要求解在时间 $t = 1$ 时的位移 $u(x, 1)$。

**解**：

通过数值求解波动方程，我们可以得到：

$$
u(x, 1) = \sin(\pi x) - \frac{\pi^2}{4} \sin(\pi x) \cos(\pi x)
$$

             self.y = y
             self.density = density
             self.elasticity = elasticity

             self.geomedia_model = geomedia_model

             t = np.linspace(0, self.input_params.t_length, self.input_params.t_length)

             for i in range(len(x)):

             for n in range(1, len(t)):
