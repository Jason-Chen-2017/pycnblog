#### 2.2.1 词法分析

词法分析是提示词语言构建的第一步，其目标是识别输入字符串中的单词或标记，并将其转换成标记流。词法分析器通常遵循以下步骤：

1. **初始化**：读取输入字符串，初始化词法分析器状态。

2. **扫描**：从输入字符串中逐个字符进行扫描，根据字符组合判断单词的边界。

3. **标记分类**：将扫描到的单词或字符序列分类成标记，如关键字、标识符、操作符等。

4. **生成标记流**：将分类后的标记放入标记流中，以便后续语法分析。

以下是一个简单的Python代码示例，用于实现词法分析：

```python
import re

class Lexer:
    def __init__(self, text):
        self.text = text
        self.tokens = []

    def tokenize(self):
        pattern = r'\b\w+\b'
        for match in re.finditer(pattern, self.text):
            self.tokens.append(match.group())
        return self.tokens

lexer = Lexer("hello world")
print(lexer.tokenize())
```

#### 2.2.2 语法分析

语法分析是提示词语言构建的核心步骤，其目标是根据预设的语法规则，将词法分析器生成的标记序列转换成抽象语法树。常见的语法分析方法包括递归下降分析和LL(1)分析。

1. **递归下降分析**：递归下降分析是一种自顶向下的语法分析方法，它通过定义一系列递归下降规则，将标记序列转换成抽象语法树。

2. **LL(1)分析**：LL(1)分析是一种自顶向下的语法分析方法，它使用预测分析表来决定下一个产生式的选择。

以下是一个简单的递归下降分析器的Python代码示例：

```python
class Parser:
    def __init__(self, tokens):
        self.tokens = tokens
        self.current = 0

    def parse(self):
        ast = self.expression()
        return ast

    def expression(self):
        node = {'type': 'expression'}
        node['left'] = self.term()
        while self.current < len(self.tokens) and self.tokens[self.current] == '+':
            node['ops'].append('+')
            self.current += 1
            node['right'] = self.term()
        return node

    def term(self):
        node = {'type': 'term'}
        node['value'] = self.tokens[self.current]
        self.current += 1
        return node

parser = Parser(lexer.tokenize())
print(parser.parse())
```

#### 2.2.3 语义分析

语义分析是提示词语言构建的第三步，其目标是对抽象语法树进行语义检查和解释。语义分析通常包括以下任务：

2. **变量作用域解析**：解析变量名的作用域，确保在正确的上下文中引用变量。

3. **语义动作执行**：根据语义规则执行特定的动作，如定义变量、创建对象等。

以下是一个简单的语义分析器的Python代码示例：

class SemanticAnalyzer:
    def __init__(self, ast):
        self.ast = ast
        self.env = {}

    def analyze(self):
        self.visit(self.ast)

            self.visit(node['left'])

            self.visit(node['right'])

            self.env[node['value']] = 'int'

import re

class Lexer:
    def __init__(self, text):

#### 3.3.2 语法分析器

语法分析器负责将标记序列转换成抽象语法树。以下是一个简单的递归下降语法分析器实现：

```python
class Parser:
    def __init__(self, tokens):
        self.tokens = tokens
        self.current = 0

    def parse(self):
        ast = self.expression()
        return ast

    def expression(self):
        node = {'type': 'expression'}
        node['left'] = self.term()
        while self.current < len(self.tokens) and self.tokens[self.current] in ('+', '-'):
            node['ops'].append(self.tokens[self.current])
            self.current += 1
            node['right'] = self.term()
        return node

    def term(self):
        node = {'type': 'term'}
        if self.tokens[self.current].isdigit():
            node['value'] = int(self.tokens[self.current])
            self.current += 1
        elif self.tokens[self.current] == '(':
            self.current += 1
            node['value'] = self.expression()
            self.current += 1
        return node

# 示例
parser = Parser(lexer.tokenize())
print(parser.parse())
```

这个语法分析器使用递归下降法，根据预设的文法规则，将标记序列转换成抽象语法树。

#### 3.3.3 语义分析器

语义分析器负责检查抽象语法树的语义正确性。以下是一个简单的Python语义分析器实现：

```python
class SemanticAnalyzer:
    def __init__(self, ast):
        self.ast = ast

    def analyze(self):
        self.visit(self.ast)

    def visit(self, node):
        if node['type'] == 'expression':
            self.visit(node['left'])
            for op in node['ops']:
                if op not in ('+', '-'):
                    raise SyntaxError(f"Unsupported operator: {op}")
                self.visit(node['right'])
        elif node['type'] == 'term':
            if not isinstance(node['value'], int):
                raise TypeError(f"Expected integer, got {node['value']}")

# 示例
analyzer = SemanticAnalyzer(parser.parse())
analyzer.analyze()
```

这个语义分析器检查抽象语法树中的每个节点，确保它们的类型和操作都是合法的。
