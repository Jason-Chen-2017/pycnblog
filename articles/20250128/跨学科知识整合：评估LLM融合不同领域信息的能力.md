### 5.2 系统核心实现源代码

以下是智能问答系统的核心实现源代码：

```python
import tensorflow as tf
import pytorch_lightning as pl
from nltk.tokenize import word_tokenize
from sklearn.metrics.pairwise import cosine_similarity

class QASystem(pl.LightningModule):
    def __init__(self, model_name):
        super().__init__()
        self.model = tf.keras.models.load_model(model_name)
    
    def forward(self, question, answer):
        question_embedding = self.model(question)
        answer_embedding = self.model(answer)
        similarity = cosine_similarity([question_embedding], [answer_embedding])
        return similarity[0][0]

def preprocess_text(text):
    tokens = word_tokenize(text)
    return ' '.join(tokens)

def main():
    question = preprocess_text("什么是机器学习？")
    answer = preprocess_text("机器学习是一门人工智能领域的研究学科，主要研究如何通过算法让计算机从数据中学习并做出决策。")
    qasystem = QASystem("model.h5")
    similarity = qasystem(question, answer)
    print("相似度：", similarity)

if __name__ == "__main__":
    main()
```

### 5.3 代码应用解读与分析

3. 在__init__方法中，加载预训练的LLM模型。
4. 在forward方法中，接收question和answer，计算它们之间的相似度。
5. 定义preprocess_text函数，用于对输入文本进行预处理，包括分词和去停用词。
6. 定义main函数，实现主程序入口。首先对输入问题进行预处理，然后创建QASystem实例，并计算问题与答案之间的相似度。
7. 在主程序中，调用main函数，执行问答过程。
