### 4.2 Algorithm Principle Explanation

#### Mathematical Model and Formulas

$$
\text{Fitness}(x) = f(x) + \alpha \cdot g(x)
$$

Where:
- \( f(x) \) is the objective function value.
- \( g(x) \) is a penalty function to handle constraints.

#### Python Code Example

```python
import numpy as np

def fitness_function(x):
    # Objective function
    f_x = np.sum(x ** 2)
    
    # Penalty function for constraints
    g_x = 0
    if x[0] < 0 or x[1] > 1:
        g_x = 10
    
    return f_x + alpha * g_x

alpha = 0.1
x = np.array([0.5, 0.5])
print(fitness_function(x))
```
