## 冥想与脑电图

### 冥想的基本概念

冥想是一种通过训练注意力和意识来达到心理宁静和精神集中的实践。根据不同的文化和传统，冥想的形式和目标各有不同，但通常可以分为两大类：专注冥想和开放监测冥想。

- **专注冥想**：这种形式的冥想要求个体将注意力集中在某个特定的对象上，如呼吸、声音、图像或身体感觉。专注冥想的目的是培养注意力和专注力，从而提高个体的心理稳定性和情绪调节能力。

- **开放监测冥想**：与专注冥想不同，开放监测冥想不要求个体将注意力集中在某个特定对象上，而是鼓励个体保持意识，对内心和周围环境的各种体验保持开放和接受。这种冥想形式有助于提高个体的心理灵活性和情绪适应能力。

### 脑电图的基础知识

脑电图（EEG）是一种通过记录大脑的电活动来研究脑功能的技术。EEG信号是由大脑神经元群发放的电冲动产生的，这些电冲动以波形的形式记录下来，可以用来反映大脑在不同状态下的活动模式。

- **EEG信号的采集**：EEG信号的采集通常使用贴在头皮上的电极，这些电极连接到EEG记录仪。记录仪可以捕捉到大脑的电活动，并将其转化为可分析的信号。

- **EEG信号的特点**：EEG信号具有高频率、低电压和复杂的波形特点。根据波形和频率的不同，EEG信号可以划分为不同的频段，如δ波（0.5-3.5 Hz）、θ波（4-7.5 Hz）、α波（8-12.5 Hz）、β波（13-30 Hz）和γ波（30-100 Hz）。这些频段的波形变化与大脑的不同功能和意识状态有关。

```python
import numpy as np
import mne
from mne import io
from mne.preprocessing import ICA
from mne.time_frequency import psd_multitaper

# 读取脑电图数据
raw_file = 'your_data_path/your_eeg_data_raw.fif'
raw = mne.io.read_raw_fif(raw_file, verbose=False)

# 预处理：去噪和滤波
ica = ICA(n_components=20, random_state=42)
ica.fit(raw)
raw = ica.apply(raw)

filtered_raw = raw.filter(low=1, high=30)  # 滤波范围设定

# 频域分析：计算功率谱密度
psds, freqs = psd_multitaper(filtered_raw, fmin=1, fmax=30, tapers='long', n_jobs=1)

# 可视化功率谱密度
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 6))
plt.semilogy(freqs, psds.mean(axis=0), label='Filtered PSD')
plt.xlabel('Frequency (Hz)')
plt.ylabel('Power (dB)')
plt.title('EEG Power Spectrum')
plt.legend()
plt.show()
```
