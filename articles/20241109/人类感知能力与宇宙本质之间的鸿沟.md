#### 1.2.1 感知偏差

感知偏差的例子有很多，例如：

- **视觉错觉**：人们在观察某些图形或图像时，可能会产生错误的感知。例如，巴纳姆效应（Barnum Effect）就是一种常见的视觉错觉，人们往往会将自己的名字或其他个人信息与描述相符，从而认为自己被准确预测。

- **认知失调**：当人们的信念与感知到的信息不一致时，会产生认知失调（Cognitive Dissonance）。为了缓解这种不适感，人们可能会改变自己的信念，以使它们与感知到的信息相符。

#### 1.2.2 幻觉

幻觉是指人们在没有外部刺激的情况下产生的感知体验。幻觉可能是由于大脑的生理或心理因素引起的，也可能是由于感知偏差导致的。

- **内视觉（Phantoms）**：当人们闭上眼睛时，可能会出现视觉幻觉，如看到光点、线条或形状。

- **听觉幻觉**：人们在安静的环境中可能会听到不存在的声音，如低语、音乐或敲击声。

import numpy as np
import matplotlib.pyplot as plt

# 定义宇宙模拟器的参数
G = 6.674 * 10**-11  # 引力常数
c = 299792458        # 光速

# 定义天体的类
class CelestialBody:
    def __init__(self, mass, position, velocity):
        self.mass = mass
        self.position = position
        self.velocity = velocity

    def update_position(self, time_step):
        self.position += self.velocity * time_step

    def update_velocity(self, other_body, time_step):
        distance = np.linalg.norm(np.array(self.position) - np.array(other_body.position))
        force = G * self.mass * other_body.mass / distance**2
        direction = (other_body.position - self.position) / distance
        acceleration = force / self.mass
        self.velocity += direction * acceleration * time_step

# 创建天体实例
sun = CelestialBody(mass=1.989 * 10**30, position=np.zeros(3), velocity=np.zeros(3))
earth = CelestialBody(mass=5.972 * 10**24, position=np.array([1, 0, 0]), velocity=np.array([-29780, 0, 0]))

# 模拟宇宙中的天体运动
def simulate_orbit(sun, earth, time_steps, time_step_size):
    positions = []
    for _ in range(time_steps):
        earth.update_position(time_step_size)
        earth.update_velocity(sun, time_step_size)
        positions.append([sun.position, earth.position])
    return positions

# 绘制天体运动的轨迹
def plot_orbit(positions):
    sun_positions = [pos[0] for pos in positions]
    earth_positions = [pos[1] for pos in positions]

    plt.plot([pos[0] for pos in sun_positions], [pos[2] for pos in sun_positions], 'r-', linewidth=2)
    plt.plot([pos[0] for pos in earth_positions], [pos[2] for pos in earth_positions], 'b-', linewidth=1)
    plt.xlabel('X position')
    plt.ylabel('Z position')
    plt.title('Orbit of Earth around the Sun')
    plt.show()

# 模拟并绘制地球绕太阳的轨道

plot_orbit(positions)
