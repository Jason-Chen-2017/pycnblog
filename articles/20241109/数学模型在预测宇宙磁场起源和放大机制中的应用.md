#### 2.2 机器学习算法原理讲解

**线性回归**

线性回归是一种简单但有效的机器学习方法。它通过建立输入变量和输出变量之间的线性关系来预测未知数据。

**算法流程**

1. 建立线性模型：$y = wx + b$。
2. 计算损失函数：$J(w, b) = \frac{1}{2m} \sum_{i=1}^{m} (y_i - wx_i - b)^2$。
3. 梯度下降：迭代更新权重和偏置，以最小化损失函数。

**伪代码**

以下是线性回归的伪代码表示：

```python

w = 0
b = 0

# 训练模型
for epoch in range(num_epochs):
    for sample in dataset:
        y_pred = w * sample.x + b
        loss = (y_pred - sample.y) ** 2

        # 计算梯度
        dw = 2 * (y_pred - sample.y) * sample.x
        db = 2 * (y_pred - sample.y)

        # 更新权重和偏置
        w -= learning_rate * dw
        b -= learning_rate * db
```
