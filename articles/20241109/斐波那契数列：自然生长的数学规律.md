```python
def fibonacci_matrix(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        def multiply_matrices(a, b):
            result = [[0, 0], [0, 0]]
            for i in range(2):
                for j in range(2):
                    for k in range(2):
                        result[i][j] += a[i][k] * b[k][j]
            return result

        matrix = [[1, 1], [1, 0]]
        result_matrix = [[1, 0], [0, 1]]  # 初始矩阵
        while n > 0:
            if n % 2 == 1:
                result_matrix = multiply_matrices(result_matrix, matrix)
            matrix = multiply_matrices(matrix, matrix)
            n //= 2

        return result_matrix[0][1]
```

在这个实现中，我们定义了一个辅助函数 `multiply_matrices` 用于计算两个矩阵的乘积。通过迭代将矩阵 \( \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix} \) 进行快速幂运算，最终得到斐波那契数列的第 \( n \) 项。这种方法的时间复杂度为 \( O(\log n) \)，远优于递归和动态规划算法。
