#### 遗传算法（Genetic Algorithm，GA）

遗传算法是一种基于自然选择和遗传学的全局优化算法，通过模拟生物进化过程来寻找最优解。遗传算法在香水配方优化中，通过模拟气味分子组合的遗传、交叉和变异，来生成新的配方并逐步逼近最优解。

**基本原理：**

遗传算法的核心在于对种群的操作。种群中的每个个体代表一个香水配方，通过评估每个个体的适应度，选择适应性较强的个体进行交叉和变异，生成新的个体，从而不断优化香水配方。

**步骤：**

1. **初始化种群**：随机生成初始种群，每个个体由气味分子浓度或比例组成。
2. **评估适应度**：根据目标函数计算每个个体的适应度。
3. **选择**：选择适应度较高的个体进行交叉和变异。
4. **交叉**：将两个父代个体进行交叉，生成新的子代个体。
5. **变异**：对某些个体进行随机变异，增加种群的多样性。
6. **替换**：用子代个体替换种群中的原有个体。
7. **迭代**：重复上述步骤，直到满足停止条件（如达到最大迭代次数或找到满意解）。

**步骤：**

1. **初始化粒子群**：随机初始化粒子的位置和速度。
2. **评估适应度**：根据目标函数计算每个粒子的适应度。
3. **更新粒子位置和速度**：根据个体最佳位置和全局最佳位置，更新每个粒子的位置和速度。
4. **迭代**：重复上述步骤，直到满足停止条件（如达到最大迭代次数或找到满意解）。

    # 根据个体基因计算目标函数值
    strength = sum(individual)  # 香气强度
    duration = 1 - sum(individual)  # 持久性
    return -strength, duration

# 初始化种群
def initialize_population(size, lower_bound, upper_bound):
    population = []
    for _ in range(size):
        individual = [random.uniform(lower_bound, upper_bound) for _ in range(3)]
        population.append(individual)
    return population

# 主函数
def main():
    # 设置参数
    population_size = 100
    lower_bound = 0
    upper_bound = 1
    generations = 100

    # 初始化算法
    creator.create("FitnessMin", base.Fitness, weights=(-1.0, 1.0))
    toolbox = base.Toolbox()
    toolbox.register("individual", tools.initUniform, lower_bound, upper_bound, n=3)
    toolbox.register("population", tools.initRepeat, list, toolbox.individual)
    toolbox.register("evaluate", objective_function)
    toolbox.register("select", tools.selTournament, tournsize=3)
    toolbox.register("mate", tools.cxBlend, alpha=0.5)
    toolbox.register("mutate", tools.mutUniform, lower_bound, upper_bound, indpb=0.1)
    toolbox.register("update", tools.selBest, k=1)

    # 初始化种群
    population = toolbox.initializePopulation(population_size)

    # 优化过程
    for generation in range(generations):
        offspring = algorithms.varAnd(population, toolbox, cxpb=0.5, mutpb=0.2)
        fits = toolbox.evaluate(offspring)
        offspring = list(map(toolbox.update, offspring, fits))
        population = offspring

    # 输出最优解
    best_individual = tools.selBest(population, k=1)[0]
    best_fitness = toolbox.evaluate(best_individual)
    print(f"Best individual: {best_individual}, Fitness: {best_fitness}")

if __name__ == "__main__":
    main()
