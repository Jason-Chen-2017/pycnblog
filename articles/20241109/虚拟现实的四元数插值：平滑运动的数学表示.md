### 四元数插值基础

#### 四元数插值原理

四元数插值是指通过两个四元数来计算它们之间的中间状态，使得运动路径更加平滑。给定两个四元数 \( q_0 \) 和 \( q_1 \)，四元数插值公式为：

\[ q_t = (1 - t)q_0 + tq_1 \]

其中，\( t \) 是插值参数，取值范围为 \( [0, 1] \)。当 \( t = 0 \) 时，得到 \( q_0 \)；当 \( t = 1 \) 时，得到 \( q_1 \)。通过调整 \( t \) 的值，可以计算出 \( q_0 \) 和 \( q_1 \) 之间的任意中间状态。

#### 四元数插值的几何意义

从几何角度来看，四元数插值可以理解为在四元数空间中画一条线段，连接 \( q_0 \) 和 \( q_1 \)。这条线段上的每个点都表示一个中间状态。四元数插值的优势在于：

1. **平滑性**：线段上的点不会产生尖角，因此插值结果更加平滑。
2. **旋转连续性**：每个中间状态的旋转方向和角度都是连续的，不会出现突变。

#### 四元数插值算法

线性插值是最简单的一种四元数插值算法，其公式为：

\[ q_t = (1 - t)q_0 + tq_1 \]

线性插值计算简单，但可能不够平滑。为了提高平滑性，可以使用更复杂的插值算法，如Slerp（Sphere Linear Interpolation）和Nlerp（Normal Linear Interpolation）。

##### Slerp算法

Slerp算法是一种基于球面插值的四元数插值方法，其公式为：

\[ q_t = \frac{\sin((1 - t)\theta)}{\sin(\theta)}q_0 + \frac{\sin(t\theta)}{\sin(\theta)}q_1 \]

其中，\( \theta \) 是 \( q_0 \) 和 \( q_1 \) 之间的夹角。Slerp算法的优点是能够保证插值过程中的旋转方向始终与初始和结束旋转的方向一致。

##### Nlerp算法

Nlerp算法是一种基于标准化线性插值的四元数插值方法，其公式为：

\[ q_t = \frac{(1 - t)q_0 + tq_1}{\| (1 - t)q_0 + tq_1 \|} \]

Nlerp算法简单，计算效率高，适用于大多数实时应用场景。

```javascript
class Quaternion {
  constructor(w, x, y, z) {
    this.w = w;
    this.x = x;
    this.y = y;
    this.z = z;
  }

  // 四元数乘法
  multiply(q) {
    return new Quaternion(
      this.w * q.w - this.x * q.x - this.y * q.y - this.z * q.z,
      this.w * q.x + this.x * q.w + this.y * q.z - this.z * q.y,
      this.w * q.y - this.x * q.z + this.y * q.w + this.z * q.x,
      this.w * q.z + this.x * q.y - this.y * q.x + this.z * q.w
    );
  }

  // 四元数插值
  slerp(q1, q2, t) {
    // 计算夹角和归一化四元数
    let dot = this.dot(q1);
    let cosTheta = Math.acos(2 * dot * dot - 1);
    let halfTheta = cosTheta / 2;
    let sinTheta = Math.sin(halfTheta);

    // 计算插值
    let weight0 = Math.cos(halfTheta - t * cosTheta) / sinTheta;
    let weight1 = Math.cos(halfTheta + t * cosTheta) / sinTheta;

    return new Quaternion(
      weight0 * q1.w + weight1 * q2.w,
      weight0 * q1.x + weight1 * q2.x,
      weight0 * q1.y + weight1 * q2.y,
      weight0 * q1.z + weight1 * q2.z
    );
  }

  // 计算四元数点积
  dot(q) {
    return this.w * q.w + this.x * q.x + this.y * q.y + this.z * q.z;
  }

  // 输出字符串表示
  toString() {
    return `(${this.w}, ${this.x}, ${this.y}, ${this.z})`;
  }
}
```

线性插值计算简单，但可能不够平滑。为了提高平滑性，可以使用更复杂的插值算法，如Slerp（Sphere Linear Interpolation）和Nlerp（Normal Linear Interpolation）。

#### Slerp算法

Slerp算法是一种基于球面插值的四元数插值方法，其公式为：

\[ q_t = \frac{\sin((1 - t)\theta)}{\sin(\theta)}q_0 + \frac{\sin(t\theta)}{\sin(\theta)}q_1 \]

其中，\( \theta \) 是 \( q_0 \) 和 \( q_1 \) 之间的夹角。Slerp算法的优点是能够保证插值过程中的旋转方向始终与初始和结束旋转的方向一致。

#### Nlerp算法

Nlerp算法是一种基于标准化线性插值的四元数插值方法，其公式为：

\[ q_t = \frac{(1 - t)q_0 + tq_1}{\| (1 - t)q_0 + tq_1 \|} \]

Nlerp算法简单，计算效率高，适用于大多数实时应用场景。

```javascript
class Quaternion {
  constructor(w, x, y, z) {
    this.w = w;
    this.x = x;
    this.y = y;
    this.z = z;
  }

  // 四元数乘法
  multiply(q) {
    return new Quaternion(
      this.w * q.w - this.x * q.x - this.y * q.y - this.z * q.z,
      this.w * q.x + this.x * q.w + this.y * q.z - this.z * q.y,
      this.w * q.y - this.x * q.z + this.y * q.w + this.z * q.x,
      this.w * q.z + this.x * q.y - this.y * q.x + this.z * q.w
    );
  }

  // 四元数插值
  slerp(q1, q2, t) {
    // 计算夹角和归一化四元数
    let dot = this.dot(q1);
    let cosTheta = Math.acos(2 * dot * dot - 1);
    let halfTheta = cosTheta / 2;
    let sinTheta = Math.sin(halfTheta);

    // 计算插值
    let weight0 = Math.cos(halfTheta - t * cosTheta) / sinTheta;
    let weight1 = Math.cos(halfTheta + t * cosTheta) / sinTheta;

    return new Quaternion(
      weight0 * q1.w + weight1 * q2.w,
      weight0 * q1.x + weight1 * q2.x,
      weight0 * q1.y + weight1 * q2.y,
      weight0 * q1.z + weight1 * q2.z
    );
  }

  // 计算四元数点积
  dot(q) {
    return this.w * q.w + this.x * q.x + this.y * q.y + this.z * q.z;
  }

  // 输出字符串表示
  toString() {
    return `(${this.w}, ${this.x}, ${this.y}, ${this.z})`;
  }
}
```
