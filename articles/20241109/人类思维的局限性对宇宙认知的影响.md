### 第3章：人类思维的记忆局限

#### 3.1 工作记忆的局限

工作记忆（也称为短期记忆）是人类在短时间内处理和存储信息的能力。它是执行复杂任务和解决问题的重要基础。然而，工作记忆的容量有限，通常只能同时处理7±2个信息单元。这意味着人类在工作记忆中无法同时处理大量信息，这限制了我们在复杂情况下进行思考和分析的能力。

- **Mermaid 流程图**：

```
graph TD
A[工作记忆局限] --> B[信息单元容量]
B --> C[7±2个信息单元]
```

这种局限导致我们在面对复杂问题时，往往需要将信息分批次处理，或者依赖外部工具来辅助记忆。例如，在解决一个复杂的数学问题时，我们可能需要将问题分解成几个部分，逐一解决，而不是一次性处理整个问题。

- **伪代码**：


情绪记忆是指与情绪相关的信息记忆。这种记忆类型通常比其他类型的记忆更持久，因为它与我们的情感体验紧密相关。然而，情绪记忆也可能导致偏见和错误的记忆。例如，当我们回忆一个令人愉快的经历时，我们可能会夸大其美好之处；而当我们回忆一个令人痛苦的经历时，我们可能会夸大其痛苦程度。这种偏见会影响我们对事件的客观理解和分析。
