## 2. 核心概念与联系

### 定义与特性

分形几何的基本概念包括分形的定义和其特性。分形是指那些无论怎样放大或缩小，其形状都保持不变的几何图形。这些图形具有以下特性：

- **自相似性**：分形在不同尺度上具有相似性，即局部与整体之间具有相似的结构。
- **不规则性**：分形形状通常不是规则的几何图形，而是具有无限细节的复杂结构。
- **分数维度**：分形的测度通常不是整数，而是分数，例如，海岸线的分形维度介于1和2之间。

以下是一个简单的Python代码示例，用于生成Cantor集：

```python
import numpy as np
import matplotlib.pyplot as plt

def cantor_set(x, y, iterations):
    if iterations == 0:
        return x, y
    if y < 0:
        return cantor_set(x, -y, iterations)
    x_left = 0.5 * x
    x_right = 1.5 * x - 1
    if x < 0.5:
        return cantor_set(x_left, cantor_set(y, iterations - 1), iterations)
    else:
        return cantor_set(x_right, cantor_set(y, iterations - 1), iterations)

def plot_cantor_set(iterations):
    points = []
    for y in np.linspace(-1, 1, 1000):
        for x in np.linspace(-1, 1, 1000):
            points.append(cantor_set(x, y, iterations))
    x = [p[0] for p in points]
    y = [p[1] for p in points]
    plt.scatter(x, y)
    plt.axis('equal')
    plt.show()

if __name__ == "__main__":
    plot_cantor_set(5)
```

在这个代码中，`cantor_set` 函数是一个递归函数，用于生成Cantor集的每个点。`plot_cantor_set` 函数则用于绘制Cantor集。
