### 2.5 数学公式和详细讲解

在音乐中，频率与音高的关系可以用以下公式表示：

$$f = \frac{1}{2\pi}\sqrt{\frac{h}{m}}$$

其中，$f$ 是频率，$h$ 是高度，$m$ 是质量。

这个公式表明，频率与高度和质量的平方根成正比。也就是说，当高度增加或质量减小时，频率会增加。

这意味着这个吉他弦的基频是 7.85 Hz。

3. **和弦**：和弦是三个或更多音符同时演奏时形成的和谐效果。

#### 源代码详细实现

```python
import pygame
import numpy as np

# 音符类
class Note:
    def __init__(self, frequency, duration):
        self.frequency = frequency
        self.duration = duration

# 音乐生成器函数
def generateMusic(frequencyList, durationList):
    pygame.init()
    freq = 440.0  # 基准频率
    size = 2 ** 12  # 样本大小
    channels = 2  # 双通道
    buffer = size * channels  # 缓冲区大小

    # 创建声音对象
    sound = pygame.mixer.Sound(buffer)

    # 创建一个空的音频缓冲区
    audioBuffer = np.zeros(int(buffer))

    # 生成每个音符的音频信号
    for i in range(len(frequencyList)):
        amp = 0.5
        freq = freq * frequencyList[i]
        duration = durationList[i]
        t = np.linspace(0, duration, int(size * duration), False)
        wave = amp * np.sin(2 * np.pi * freq * t)

        # 添加音频信号到缓冲区
        audioBuffer += wave

    # 规范化音频缓冲区
    audioBuffer = audioBuffer / np.max(np.abs(audioBuffer))

    # 将音频缓冲区添加到声音对象
    sound.set_buffer(audioBuffer.astype(np.int16))

    # 播放音乐
    sound.play()

    # 等待音乐播放完毕
    while pygame.mixer.get_busy():
        pygame.time.Clock().tick(30)

    pygame.quit()

# 测试
if __name__ == "__main__":
    frequencyList = [1, 1.25, 1.5, 1.75, 2]
    durationList = [1, 1, 1, 1, 1]
    generateMusic(frequencyList, durationList)
```

1. **音程公式**：音程是指两个音符之间的音高差异。在音乐理论中，音程可以用整数来表示。例如，半音可以用 1 表示，全音可以用 2 表示。音程的计算公式为：

   $$p = \log_2(\frac{f_1}{f_0})$$

   其中，$p$ 是音程，$f_1$ 是高音的频率，$f_0$ 是低音的频率。

   例如，如果低音的频率是 440 Hz，高音的频率是 880 Hz，则音程为：

   $$p = \log_2(\frac{880}{440}) = \log_2(2) = 1$$

   这意味着高音比低音高一个半音。

2. **和弦公式**：和弦是由三个或更多音符同时演奏时形成的和谐效果。在音乐理论中，和弦可以用向量来表示。例如，大三和弦可以用向量 $(4, 7, 9)$ 来表示。和弦的计算公式为：

   $$C = [c_1, c_2, c_3, ..., c_n]$$

   其中，$C$ 是和弦，$c_1, c_2, c_3, ..., c_n$ 是和弦中的音符。

   例如，大三和弦可以用以下公式表示：

   $$C = [4, 7, 9]$$

   这意味着和弦中的音符分别是 $4$ 度、$7$ 度和 $9$ 度。

3. **节奏公式**：节奏是指音乐中的时间结构，它由音符的长短、强弱和速度等决定。在音乐理论中，节奏可以用分数、小数或整数来表示。例如，四分音符可以用 $\frac{1}{4}$ 表示，八分音符可以用 $\frac{1}{8}$ 表示。节奏的计算公式为：

   $$r = \frac{t}{n}$$

   其中，$r$ 是节奏，$t$ 是时间，$n$ 是音符的数量。

   例如，如果时间是 4 秒，音符数量是 4，则节奏为：

   $$r = \frac{4}{4} = 1$$

   这意味着每个音符持续 1 秒。

1. **冒泡排序**：冒泡排序是一种简单的排序算法，它的基本思想是通过重复交换相邻的未按顺序排列的元素，使得每个循环结束时最大元素被移到数组的末端。

   ```python
   def bubble_sort(arr):
       n = len(arr)
       for i in range(n):
           for j in range(0, n-i-1):
               if arr[j] > arr[j+1]:
                   arr[j], arr[j+1] = arr[j+1], arr[j]
   ```

   这个算法中的每个循环都可以看作是一个节奏单位，每次循环都会使未排序部分的最大元素移动到正确位置。

2. **插入排序**：插入排序是一种更复杂的排序算法，它的基本思想是将未排序部分的数据插入到已排序部分正确的位置。

   ```python
   def insertion_sort(arr):
       n = len(arr)
       for i in range(1, n):
           key = arr[i]
           j = i-1
           while j >= 0 and key < arr[j]:
               arr[j+1] = arr[j]
               j -= 1
           arr[j+1] = key
   ```

   这个算法中的每个插入操作都可以看作是一个节奏单位，每次插入都会使未排序部分的数据有序。

import mido
from PyQt5 import QtWidgets, QtGui

# 生成音乐
def generate_music(formula, duration):
    midi_file = mido.MidiFile()
    for note in formula:
        note_on = mido.Message('note_on', note=note, velocity=100)
        note_off = mido.Message('note_off', note=note, velocity=100)
        delta = duration * 1000  # 将持续时间转换为毫秒
        midi_file.append(note_on)
        midi_file.append(mido.MetaMessage('set_tempo', tempo=120000))
        midi_file.append(mido.MetaMessage('time_signature', numerator=4, denominator=4))
        midi_file.append(note_off)
        delta = duration * 1000  # 将持续时间转换为毫秒
    midi_file.save('generated_music.mid')

# 主窗口类
class MainWindow(QtWidgets.QMainWindow):
    def __init__(self):
        super().__init__()
        self.init_ui()

    def init_ui(self):

        self.setGeometry(100, 100, 800, 600)

        self.central_widget = QtWidgets.QWidget()

        self.formula_input = QtWidgets.QLineEdit()
        self.duration_input = QtWidgets.QSpinBox()

        self.layout.addWidget(self.formula_input)

        self.layout.addWidget(self.generate_button)

        self.central_widget.setLayout(self.layout)

    def generate_music(self):
        formula = self.formula_input.text().split(',')
        duration = self.duration_input.value()
