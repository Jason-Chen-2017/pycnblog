## 第2章 数值表示方法

### 2.1 位运算与数值表示

位运算是计算机中用于操作二进制数的运算。位运算包括与、或、异或、取反、左移和右移等操作。位运算在数值表示中起着至关重要的作用。例如，通过位与操作，我们可以获取一个数的特定位；通过位或操作，我们可以设置一个数的特定位；通过位异或操作，我们可以对两个数的特定位进行交替设置。

位运算与数值表示的紧密联系在于，位运算可以实现对二进制数的直接操作，从而高效地进行数值表示和处理。以下是一个简单的示例：

```python
# 左移操作：将数值x左移n位
def left_shift(x, n):
    return x << n

# 右移操作：将数值x右移n位
def right_shift(x, n):
    return x >> n

# 与操作：将数值x和y进行位与操作
def bitwise_and(x, y):
    return x & y

# 或操作：将数值x和y进行位或操作
def bitwise_or(x, y):
    return x | y

# 异或操作：将数值x和y进行位异或操作
def bitwise_xor(x, y):
    return x ^ y

# 取反操作：将数值x进行位取反操作
def bitwise_not(x):
    return ~x
```

通过上述示例，我们可以看到位运算在数值表示中的作用。位运算不仅可以用于实现基本的数值操作，还可以用于更复杂的数值处理，如整数到浮点数的转换等。

### 2.2 常见的数值类型

在计算机中，常见的数值类型包括整数类型、浮点数类型和复数类型。每种数值类型都有其独特的特点和适用场景。

#### 2.2.1 整数类型

整数类型是计算机中最基本的数值类型，用于表示整数。整数类型分为有符号整数和无符号整数。有符号整数可以表示正数、负数和零，无符号整数只能表示非负数。


浮点数类型用于表示近似实数。浮点数分为单精度浮点数（float）和双精度浮点数（double）。单精度浮点数占用32位，双精度浮点数占用64位。



### 2.3 数值类型转换

在编程中，数值类型之间的转换是常见操作。数值类型转换包括自动类型转换、显式类型转换和异构类型转换。

#### 2.3.1 自动类型转换

自动类型转换是指编译器或解释器自动进行类型转换，以避免数据丢失或精度降低。例如，将整数类型转换为浮点数类型时，自动类型转换会将整数类型的值扩展为浮点数类型。


#### 2.3.2 显式类型转换

显式类型转换是指程序员明确指定类型转换，以确保转换的准确性和一致性。显式类型转换通常使用类型转换运算符或函数进行。


#### 2.3.3 异构类型转换

异构类型转换是指将不同类型的数值转换为同一类型的数值。例如，将浮点数转换为整数时，异构类型转换会舍弃浮点数的尾数，只保留整数部分。


类型级数字的实现依赖于静态类型系统和动态类型系统。以下分别介绍这两种系统的特点和应用。

静态类型系统在编译时确定变量的类型，并在运行时保持类型不变。静态类型系统的优点是类型检查早，代码运行效率高。常见的静态类型编程语言有C、C++和Java。


#### 3.3.2 动态类型系统

动态类型系统在编译时不确定变量的类型，而是在运行时根据上下文动态确定。动态类型系统的优点是代码灵活，易于实现。常见的动态类型编程语言有Python、JavaScript和Ruby。


#### 3.3.3 静态与动态类型系统的比较

静态类型系统和动态类型系统各有优缺点。静态类型系统的优点是类型检查早，代码运行效率高；缺点是代码编写相对繁琐，灵活性较差。动态类型系统的优点是代码灵活，易于实现；缺点是类型检查晚，代码运行效率较低。

在实际应用中，我们可以根据需求和场景选择合适的类型系统。例如，在性能要求较高的场景下，可以选择静态类型系统；在灵活性要求较高的场景下，可以选择动态类型系统。

#### 4.3.1 排序算法

排序算法中的类型级数字主要用于对数值数据进行排序。常见的排序算法有冒泡排序、选择排序、插入排序和快速排序等。这些算法通过对数值数据进行比较和交换，实现对数值数据的排序。

```python
# Python示例
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]

arr = [64, 34, 25, 12, 22, 11, 90]
```

```python
# Python示例
def binary_search(arr, x):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == x:
            return mid
        elif arr[mid] < x:
            low = mid + 1
        else:
            high = mid - 1
    return -1

arr = [2, 3, 4, 10, 40]
x = 10
result = binary_search(arr, x)
if result != -1:
    print("元素在数组中的索引：", result)

    print("元素不在数组中")
```

```python
# Python示例
from collections import defaultdict

class Graph:
    def __init__(self):
        self.graph = defaultdict(list)

    def add_edge(self, u, v):
        self.graph[u].append(v)

    def dfs(self, v, visited):
        visited.add(v)
        print(v, end=" ")
        for neighbour in self.graph[v]:
            if neighbour not in visited:
                self.dfs(neighbour, visited)

g = Graph()
g.add_edge(0, 1)
g.add_edge(0, 2)
g.add_edge(1, 2)
g.add_edge(2, 0)
g.add_edge(2, 3)

visited = set()
print("DFS遍历结果：")
g.dfs(2, visited)
```

在快速排序算法中，我们可以将整数类型、浮点数类型和复数类型等数值类型的数据进行排序。以下是一个简单的快速排序算法示例：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 应用实例：排序整数类型数据
```
