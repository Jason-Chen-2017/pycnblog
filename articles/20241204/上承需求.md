#### TF-IDF模型

TF-IDF（Term Frequency-Inverse Document Frequency）是一种常用在文本分析中的统计模型，用于评估一个词对于一个文件集或一个语料库中的其中一份文件的重要程度。在上承需求中，TF-IDF模型可以用于分析用户需求，找出关键词并进行分类。

#### 公式：

$$
TF(t, d) = \frac{f(t, d)}{f_S(d)}
$$

$$
IDF(t, D) = \log \left( \frac{N}{df(t, D)} \right)
$$

$$
TF-IDF(t, d, D) = TF(t, d) \times IDF(t, D)
$$

其中，\( f(t, d) \)表示词\( t \)在文档\( d \)中的词频，\( f_S(d) \)表示文档\( d \)中的总词频，\( N \)表示文档总数，\( df(t, D) \)表示词\( t \)在整个语料库中的文档频率。

#### 举例说明

1. 用户需要查看历史订单记录。
2. 用户需要添加新订单。
3. 用户需要删除订单。

我们可以使用TF-IDF模型来分析这些句子，找出关键词并进行分类。例如，将句子转化为词袋模型，计算TF-IDF值，可以得到：

- “查看”的TF-IDF值为3.32。
- “添加”的TF-IDF值为2.76。
- “删除”的TF-IDF值为2.76。

根据TF-IDF值，我们可以将关键词分为“查看”、“添加”和“删除”三类，分别对应查看历史订单、添加新订单和删除订单的需求。

### 数学公式详细讲解

在上承需求中，TF-IDF模型主要用于需求分析和分类。下面我们将详细讲解TF-IDF模型的原理和计算方法。

#### TF（Term Frequency）

TF表示词在文档中的频率，计算公式为：

$$
TF(t, d) = \frac{f(t, d)}{f_S(d)}
$$

其中，\( f(t, d) \)表示词\( t \)在文档\( d \)中的词频，\( f_S(d) \)表示文档\( d \)中的总词频。

TF反映了词在文档中的重要程度，词频越高，TF值越大。然而，仅仅考虑词频可能导致某些常见词（如“的”、“和”等）在计算中占据主导地位。因此，需要引入IDF来平衡词的重要性。

#### IDF（Inverse Document Frequency）

IDF表示词在整个语料库中的稀疏程度，计算公式为：

$$
IDF(t, D) = \log \left( \frac{N}{df(t, D)} \right)
$$

其中，\( N \)表示文档总数，\( df(t, D) \)表示词\( t \)在整个语料库中的文档频率。

IDF反映了词在语料库中的重要性，文档频率越低，IDF值越大。词在语料库中越稀疏，表示其重要性越高。

#### TF-IDF（Term Frequency-Inverse Document Frequency）

TF-IDF表示词在文档中的重要程度，计算公式为：

$$
TF-IDF(t, d, D) = TF(t, d) \times IDF(t, D)
$$

TF-IDF综合考虑了词在文档中的词频和词在语料库中的稀疏程度，能够更准确地反映词的重要性。

### 举例说明

假设有两个文档：

文档1：“用户需要查看历史订单记录。”

文档2：“用户需要添加新订单，并删除已完成的订单。”

使用TF-IDF模型分析这两个文档，可以得到以下关键词及其TF-IDF值：

- 查看：\( TF-IDF(查看, 文档1, \{文档1, 文档2\}) = 1 \times \log \left( \frac{2}{1} \right) = 0.693 \)
- 添加：\( TF-IDF(添加, 文档2, \{文档1, 文档2\}) = 1 \times \log \left( \frac{2}{1} \right) = 0.693 \)
- 删除：\( TF-IDF(删除, 文档2, \{文档1, 文档2\}) = 1 \times \log \left( \frac{2}{1} \right) = 0.693 \)

根据TF-IDF值，我们可以将关键词分为“查看”、“添加”和“删除”三类，分别对应查看历史订单、添加新订单和删除订单的需求。

```python
# requirements.py
from flask import Flask, request, jsonify
from models import User, Order
from database import Database

app = Flask(__name__)

# 用户注册
@app.route('/register', methods=['POST'])
def register():
    username = request.form['username']
    password = request.form['password']
    email = request.form['email']
    user = User(username=username, password=password, email=email)
    Database.save_user(user)
    return jsonify({'message': '注册成功！'})

# 用户登录
@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    user = Database.find_user_by_username(username)
    if user and user.password == password:
        return jsonify({'token': user.token})
    else:
        return jsonify({'error': '用户名或密码错误！'})

# 查看历史订单
@app.route('/orders', methods=['GET'])
def get_orders():
    user = Database.get_user_by_token(request.headers.get('Authorization'))
    orders = Database.get_orders_by_user(user.id)
    return jsonify(orders)

# 添加新订单
@app.route('/orders', methods=['POST'])
def create_order():
    user = Database.get_user_by_token(request.headers.get('Authorization'))
    order = Order(user=user, status='待发货')
    Database.save_order(order)
    return jsonify({'message': '添加订单成功！'})

# 删除订单
@app.route('/orders/<int:order_id>', methods=['DELETE'])
def delete_order(order_id):
    user = Database.get_user_by_token(request.headers.get('Authorization'))
    order = Database.find_order_by_id(order_id)
    if order and order.user == user:
        Database.delete_order(order_id)
        return jsonify({'message': '删除订单成功！'})
    else:
        return jsonify({'error': '订单不存在或权限不足！'})

if __name__ == '__main__':
    app.run(debug=True)
```
