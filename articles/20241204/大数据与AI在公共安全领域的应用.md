#### Machine Learning Models

**1. Linear Regression**

Linear regression is a fundamental machine learning algorithm used for predictive modeling. It establishes a relationship between a dependent variable and one or more independent variables.

$$ y = \beta_0 + \beta_1x + \epsilon $$

Where:
- \( y \): Dependent variable
- \( x \): Independent variable
- \( \beta_0 \): Intercept
- \( \beta_1 \): Slope
- \( \epsilon \): Error term

**Example: Predicting Crime Rates**

In public safety, linear regression can be used to predict crime rates based on various factors such as population density and unemployment rates.

$$ \text{Crime Rate} = 10 + 0.5 \times \text{Population Density} - 0.3 \times \text{Unemployment Rate} $$

#### Supervised Learning Models

**2. Decision Trees**

Decision trees are a popular machine learning model used for classification and regression tasks. They work by recursively splitting the data into subsets based on the value of a feature.

$$ \text{Predicted Class} = \text{node}_\text{root} \left[ \text{if} \ x > \text{threshold} \ \text{then} \ \text{node}_\text{left} \ \text{else} \ \text{node}_\text{right} \ \right] $$

Where:
- \( \text{node}_\text{root} \): Root node of the decision tree
- \( x \): Feature value
- \( \text{threshold} \): Threshold value for splitting

**Example: Classifying Types of Crimes**

A decision tree can be used to classify types of crimes based on features such as time of day and location.

$$ \text{Type of Crime} = \text{node}_\text{root} \left[ \text{if} \ \text{Time} > 22:00 \ \text{then} \ \text{Theft} \ \text{else} \ \text{node}_\text{left} \ \right] $$

#### Deep Learning Models

**3. Convolutional Neural Networks (CNNs)**

CNNs are a type of deep learning model designed for processing and analyzing visual data. They utilize convolutional layers to detect spatial hierarchies in images.

$$ \text{Output} = \text{ConvLayer}(\text{Input}) + \text{Bias} + \text{Activation Function} $$

Where:
- \( \text{ConvLayer} \): Convolutional layer
- \( \text{Bias} \): Bias term
- \( \text{Activation Function} \): Function such as ReLU (Rectified Linear Unit)

**Example: Facial Recognition**

CNNs can be used for facial recognition by extracting features from images and comparing them to a database of known faces.

$$ \text{Facial Features} = \text{ConvLayer}(\text{Input Image}) + \text{Bias} + \text{ReLU} $$

#### Recurrent Neural Networks (RNNs)

RNNs are a type of deep learning model designed for processing sequential data. They use recurrent connections to retain information from previous inputs.

$$ \text{Hidden State} = \text{Activation Function}(\text{Weight} \cdot [\text{Input} \ \text{Hidden State}] + \text{Bias}) $$

Where:
- \( \text{Hidden State} \): Hidden state of the RNN
- \( \text{Input} \): Input at the current time step
- \( \text{Weight} \): Weight matrix
- \( \text{Bias} \): Bias term
- \( \text{Activation Function} \): Function such as tanh (hyperbolic tangent)

**Example: Sentiment Analysis**

RNNs can be used for sentiment analysis by processing text sequences to predict the sentiment of a given statement.

$$ \text{Sentiment} = \text{Activation Function}(\text{Weight} \cdot [\text{Input} \ \text{Hidden State}] + \text{Bias}) $$

#### Transformer Models

**4. Transformer Models**

Transformer models, such as BERT and GPT, are a type of deep learning model designed for processing and generating text. They use self-attention mechanisms to weigh the importance of different words in the input sequence.

$$ \text{Output} = \text{Attention}(\text{Query}, \text{Key}, \text{Value}) + \text{Feed Forward}(\text{Input}, \text{Hidden State}) $$

Where:
- \( \text{Query}, \text{Key}, \text{Value} \): Inputs to the attention mechanism
- \( \text{Feed Forward} \): Feed forward neural network

**Example: Natural Language Processing**

Transformer models can be used for natural language processing tasks, such as question answering and text generation.

$$ \text{Answer} = \text{Attention}(\text{Query}=\text{Question}, \text{Key}=\text{Context}, \text{Value}=\text{Context}) + \text{Feed Forward}(\text{Input}=\text{Context}, \text{Hidden State}=\text{Answer}) $$

```python
from sklearn.preprocessing import StandardScaler

# Preprocess the data
def preprocess_data(data):
    # Drop unnecessary columns
    data = data.drop(['unnecessary_column'], axis=1)
    # Handle missing values
    data = data.fillna(data.mean())
    # Scale the data
    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data)
    return data_scaled

preprocessed_data = preprocess_data(crime_data)
```

**Feature Engineering**

```python
from sklearn.feature_selection import SelectKBest
from sklearn.feature_selection import chi2

# Feature engineering
def feature_engineering(data, labels):
    selector = SelectKBest(score_func=chi2, k=10)
    selected_data = selector.fit_transform(data, labels)
    return selected_data

X, y = feature_engineering(preprocessed_data, crime_data['crime_type'])
```

**Model Training**

```python
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

# Evaluate the model
accuracy = model.score(X_test, y_test)
print(f"Model accuracy: {accuracy:.2f}")
```
