为了推导传播子，我们考虑一个经典的变分法。假设我们有一个变分函数 \(\phi(x)\)，则传播子可以表示为：

\[ K(x_f, x_i) = \int_{-\infty}^{\infty} \phi(x) e^{-iS[x] / \hbar} \, dx \]

通过变分法，我们可以最小化作用量来找到最佳的传播子。具体来说，我们通过求解变分方程来找到最优的变分函数：

\[ \frac{\delta}{\delta \phi} \left[ \phi(x) e^{-iS[x] / \hbar} \right] = 0 \]

\[ K(x_f, x_i) = \sqrt{\frac{e^{iS[x_f, x_i] / \hbar}}{2\pi \hbar \sqrt{1 - 2V(x) / \hbar^2}}} \]

import numpy as np
from dask.distributed import Client

# 初始化Dask客户端
client = Client()

# 定义作用量函数
def action(x, t, potential_func):
    return 0.5 * (x.dot(np.linalg.inv(t)) @ x) + potential_func(x)

# 定义传播子函数
def propagator(x_f, x_i, t, potential_func):
    S = action(x_f, t, potential_func) - action(x_i, t, potential_func)
    return np.exp(1j * S / np.hbar)

# 路径积分函数
def path_integral(x_i, x_f, t, potential_func):
    K = client.submit(propagator, x_f, x_i, t, potential_func, pure=True)
    Psi = client.submit(np.mean, K, pure=True)
    return Psi.compute()

# 定义势能函数
def potential(x):
    return 0.5 * x**2

# 定义时间步长
t = np.array([[1, 0], [0, 1]])

# 计算路径积分
x_i = np.array([[0], [0]])
x_f = np.array([[1], [0]])
Psi = path_integral(x_i, x_f, t, potential)

print("波函数：", Psi)
