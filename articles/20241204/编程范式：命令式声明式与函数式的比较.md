## 1.1 编程范式简介

编程范式（Programming Paradigm）是指导程序员编写程序的不同策略和思维方式。不同的编程范式反映了不同的编程理念，旨在解决特定类型的问题或优化特定类型的程序。常见的编程范式包括命令式编程、声明式编程和函数式编程。

### 1.1.1 什么是编程范式

编程范式是一种抽象的模型，用于描述程序结构和程序设计风格。它指导程序员如何组织代码、如何表达逻辑和如何处理数据。不同的编程范式适用于不同的应用场景，程序员需要根据具体需求选择合适的范式。

### 1.1.2 编程范式的演进

编程范式的发展与计算机科学的发展紧密相关。早期的编程范式主要是命令式编程，如机器语言和汇编语言。随着编程语言的发展，声明式编程和函数式编程逐渐兴起，为解决复杂问题和提高程序可读性提供了新的思路。

### 1.1.3 编程范式的重要性

编程范式对于程序设计的质量和效率具有重要影响。选择合适的编程范式可以提高代码的可维护性、可扩展性和性能。不同的范式适用于不同的应用场景，了解和掌握多种编程范式有助于程序员应对复杂问题。

## 1.2 命令式编程范式

命令式编程（Imperative Programming）是最传统的编程范式，强调通过一系列指令来改变程序状态。命令式编程的核心是变量和状态，通过赋值和循环等操作来控制程序执行。

### 1.2.1 命令式编程基础

命令式编程的基本概念包括变量、赋值、条件判断、循环和函数等。这些概念允许程序员描述程序的执行过程和状态变化。

### 1.2.2 命令式编程特点

命令式编程的特点是：
- 状态驱动的：程序通过改变变量和状态来控制执行流程。
- 顺序执行：程序按照预设的顺序执行指令。
- 易于理解：命令式编程的语法和结构相对直观，易于初学者上手。

### 1.2.3 命令式编程示例

以下是一个简单的命令式编程示例，使用Python语言实现一个求和函数：

```python
def sum_numbers(n):
    result = 0
    for i in range(1, n+1):
        result += i
    return result

print(sum_numbers(10))
```

## 1.3 声明式编程范式

声明式编程（Declarative Programming）强调描述程序的行为和结果，而非具体的执行过程。声明式编程通常通过逻辑表达式、规则和模式匹配来实现。

### 1.3.1 声明式编程基础

声明式编程的基本概念包括逻辑表达式、规则和模式匹配。这些概念允许程序员定义程序的行为和规则。

### 1.3.2 声明式编程特点

声明式编程的特点是：
- 行为驱动的：程序通过描述行为和结果来控制执行流程。
- 可组合性：声明式编程组件可以轻松组合，形成复杂的程序。
- 高级抽象：声明式编程提供高级抽象，使程序员可以专注于问题域，而非底层实现。

### 1.3.3 声明式编程示例

以下是一个简单的声明式编程示例，使用Prolog语言实现一个数列求和：

```prolog
sum([H|T], Sum) :-
    sum(T, Rest),
    Sum is H + Rest.

sum([], 0).

?- sum([1, 2, 3, 4, 5], Sum).
Sum = 15 ?
```

## 1.4 函数式编程范式

函数式编程（Functional Programming）是一种以函数为核心编程范式。函数式编程强调不可变数据和纯函数，避免了状态变化和副作用。

### 1.4.1 函数式编程基础

函数式编程的基本概念包括纯函数、不可变数据和高阶函数。这些概念允许程序员以函数为中心组织代码。

### 1.4.2 函数式编程特点

函数式编程的特点是：
- 纯函数：函数的输出仅取决于输入，无副作用。
- 不可变数据：数据不可变，避免状态变化和副作用。
- 高阶函数：函数可以接受其他函数作为参数或返回函数。

### 1.4.3 函数式编程示例

以下是一个简单的函数式编程示例，使用Haskell语言实现一个求和函数：

```haskell
sum :: [Int] -> Int
sum [] = 0
sum (x:xs) = x + sum xs

main :: IO ()
main = print (sum [1, 2, 3, 4, 5])
```

## 1.5 范式之间的联系与比较

命令式、声明式和函数式编程范式各有其特点和应用场景。以下是对这三种范式之间的联系与比较：

### 1.5.1 范式间的异同点分析

- **命令式编程**：强调状态和变量，顺序执行，适合处理状态密集型问题。

- **函数式编程**：强调纯函数和不可变数据，无副作用，适合处理数据密集型问题。

### 1.5.2 不同范式在实际应用中的选择

根据应用场景选择合适的编程范式：
- **命令式编程**：适用于低级系统编程、游戏开发等。
- **声明式编程**：适用于业务逻辑处理、规则引擎等。
- **函数式编程**：适用于数据分析和处理、并发编程等。

## 2.1 命令式编程基础

命令式编程是一种以变量和状态为核心，通过一系列指令来描述程序执行过程的编程范式。它强调状态的变化和顺序执行，是计算机科学中最传统的编程范式之一。本节将介绍命令式编程的基本概念、语法结构和常见模式。

### 2.1.1 命令式编程语言概述

命令式编程语言包括多种编程语言，如C、Java、Python等。这些语言提供了丰富的命令式编程功能，允许程序员通过变量赋值、条件判断、循环控制等指令来描述程序行为。

### 2.1.2 命令式编程基本概念

命令式编程的基本概念包括：

- **变量**：用于存储数据的容器，可以是基本数据类型（如整数、浮点数、布尔值）或复杂数据类型（如数组、结构体）。
- **赋值**：将一个值赋给变量，改变变量的状态。
- **条件判断**：通过比较操作符（如==、<、>等）进行条件判断，决定程序执行路径。
- **循环控制**：通过循环结构（如for、while等）重复执行特定代码块。

### 2.1.3 命令式编程常见模式

命令式编程常见的编程模式包括：

- **顺序结构**：程序按照预设的顺序执行指令。
- **条件结构**：根据条件判断执行不同代码块。
- **循环结构**：重复执行特定代码块，直到满足特定条件。
- **函数**：将一组指令封装成函数，便于代码复用和模块化。

以下是一个简单的命令式编程示例，使用Python语言实现一个计算两个数之和的函数：

```python
def add(a, b):
    return a + b

result = add(3, 4)
print("The sum is:", result)
```

在这个示例中，我们定义了一个名为`add`的函数，它接受两个参数`a`和`b`，返回它们的和。然后调用`add`函数，将两个数相加的结果赋值给变量`result`，并打印输出。

### 2.1.4 命令式编程的特点

命令式编程具有以下特点：

- **顺序执行**：程序按照预设的顺序执行指令，易于理解和调试。
- **状态驱动**：程序通过改变变量和状态来控制执行流程，适合处理复杂问题。
- **可维护性**：命令式编程的代码结构相对直观，易于维护和扩展。

命令式编程由于其直观和易用性，在计算机科学中得到了广泛的应用。然而，它也存在一些局限性，如代码重复性较高、可扩展性较差等。这些局限性促使了其他编程范式的出现和发展。

## 2.2 命令式编程算法与数据结构

命令式编程以其直观的语法和强大的控制结构，广泛应用于算法设计和数据结构实现。在这一节中，我们将介绍一些常见的算法与数据结构，并探讨它们在命令式编程中的具体实现。

### 2.2.1 常用算法与数据结构介绍

**算法**：
1. **排序算法**：如冒泡排序、选择排序、插入排序等。
2. **查找算法**：如线性查找、二分查找等。
3. **图算法**：如深度优先搜索、广度优先搜索等。

**数据结构**：

4. **队列**：一种先进先出（FIFO）的数据结构。

### 2.2.2 算法与数据结构的命令式实现

**冒泡排序**（Bubble Sort）是一种简单的排序算法，通过反复交换相邻的未按顺序排列的元素，直到整个数组有序。以下是使用Python实现的冒泡排序：

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = bubble_sort(arr)
print("Sorted array:", sorted_arr)
```

**二分查找**（Binary Search）是一种高效的查找算法，适用于有序数组。以下是使用Python实现的二分查找：

```python
def binary_search(arr, x):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == x:
            return mid
        elif arr[mid] < x:
            low = mid + 1
        else:
            high = mid - 1
    return -1

arr = [2, 3, 4, 10, 40]
x = 10
result = binary_search(arr, x)
if result != -1:
    print("Element is present at index", result)
else:
    print("Element is not present in array")
```

**链表**（Linked List）是一种常用的数据结构，用于存储元素序列。以下是使用Python实现的链表：

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
        else:
            current = self.head
            while current.next:
                current = current.next
            current.next = new_node

    def display(self):
        current = self.head
        while current:
            print(current.data, end=" ")
            current = current.next
        print()

ll = LinkedList()
ll.append(1)
ll.append(2)
ll.append(3)
ll.append(4)
ll.display()
```

### 2.2.3 命令式编程算法分析

命令式编程算法的分析主要关注时间复杂度和空间复杂度。以下是对冒泡排序和二分查找的时间复杂度分析：

- **冒泡排序**：
  - **最好情况**：数组已经有序，时间复杂度为 \(O(n)\)。
  - **最坏情况**：数组完全逆序，时间复杂度为 \(O(n^2)\)。
  - **平均情况**：时间复杂度为 \(O(n^2)\)。

- **二分查找**：
  - **最好情况**：目标元素在数组中间，时间复杂度为 \(O(1)\)。
  - **最坏情况**：目标元素不在数组中，时间复杂度为 \(O(log n)\)。
  - **平均情况**：时间复杂度为 \(O(log n)\)。

通过命令式编程实现的算法和数据结构具有直观的代码结构和良好的可读性，但可能存在效率较低的问题。在实际应用中，需要根据具体需求选择合适的算法和数据结构。

## 2.3 命令式编程最佳实践

命令式编程因其直观的语法和强大的控制结构，在计算机科学中得到了广泛的应用。然而，为了编写高效、可维护和可扩展的命令式代码，我们需要遵循一些最佳实践。以下是一些常见的命令式编程最佳实践：

### 2.3.1 编写高效命令式代码

1. **避免全局变量**：全局变量容易导致命名冲突和难以追踪，应该尽量避免使用全局变量。
2. **使用局部变量**：在函数内部使用局部变量，可以减少命名冲突和提高代码的可读性。
3. **优化循环结构**：减少循环次数，使用嵌套循环时注意嵌套深度，避免不必要的嵌套。
4. **避免重复代码**：重复代码不仅影响代码的可读性，还可能导致维护困难。使用函数或模块来复用代码。
5. **使用缓存**：对于计算密集型操作，使用缓存可以减少重复计算，提高程序性能。

### 2.3.2 命令式编程常见问题与解决方案

1. **性能问题**：
   - **解决方案**：使用高效的算法和数据结构，优化循环和递归，避免不必要的计算和内存分配。

2. **可维护性问题**：
   - **解决方案**：编写清晰、简洁的代码，使用有意义的变量名，注释关键部分，遵循代码风格指南。

3. **并发问题**：
   - **解决方案**：避免使用全局变量和静态变量，使用线程安全的数据结构，同步访问共享资源。

4. **内存泄漏问题**：
   - **解决方案**：及时释放不再使用的内存，避免创建大量临时对象，使用垃圾回收机制。

### 2.3.3 命令式编程的设计模式

设计模式是一套预定义的解决方案，用于解决常见的问题。以下是一些适用于命令式编程的设计模式：

1. **单例模式**：确保一个类只有一个实例，并提供一个全局访问点。
2. **工厂模式**：根据参数或条件创建对象，隐藏对象创建的具体实现。
3. **策略模式**：将算法的实现封装成对象，以便在运行时切换算法。
4. **模板方法模式**：定义一个操作框架，将一些具体操作延迟到子类实现。

以下是一个使用工厂模式的命令式编程示例，用于创建不同类型的对象：

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return "Bark!"

class Cat(Animal):
    def speak(self):
        return "Meow!"

class AnimalFactory:
    @staticmethod
    def create_animal(name):
        if name == "dog":
            return Dog(name)
        elif name == "cat":
            return Cat(name)
        else:
            raise ValueError("Unknown animal type")

dog = AnimalFactory.create_animal("dog")
cat = AnimalFactory.create_animal("cat")
print(dog.speak())
print(cat.speak())
```

通过遵循这些最佳实践，我们可以编写高效、可维护和可扩展的命令式代码，提高程序的性能和可靠性。

## 2.4 命令式编程案例

在本节中，我们将通过一个实际案例来展示命令式编程在开发中的应用，并详细解析其实现过程。

### 2.4.1 命令式编程实际应用场景

假设我们需要开发一个简单的图书管理系统，支持以下功能：
- 添加图书
- 删除图书
- 查找图书
- 列出所有图书

### 2.4.2 命令式编程案例解析

我们将使用Python语言实现这个图书管理系统，并详细解析每个功能模块的实现。

**1. 数据模型设计**

首先，我们设计一个图书数据模型，用于存储图书的基本信息：

```python
class Book:
    def __init__(self, id, title, author, price):
        self.id = id
        self.title = title
        self.author = author
        self.price = price
```

**2. 管理器设计**

接下来，我们设计一个图书管理器类，用于实现添加、删除、查找和列出图书的功能：

```python
class BookManager:
    def __init__(self):
        self.books = []

    def add_book(self, book):
        self.books.append(book)

    def remove_book(self, book_id):
        for book in self.books:
            if book.id == book_id:
                self.books.remove(book)
                return True
        return False

    def find_book(self, book_id):
        for book in self.books:
            if book.id == book_id:
                return book
        return None

    def list_books(self):
        for book in self.books:
            print(f"ID: {book.id}, Title: {book.title}, Author: {book.author}, Price: {book.price}")
```

**3. 程序主入口**

最后，我们实现一个主入口程序，用于测试图书管理系统的功能：

```python
def main():
    manager = BookManager()

    # 添加图书
    manager.add_book(Book(1, "算法导论", "Thomas H. Cormen", 88.00))
    manager.add_book(Book(2, "计算机组成原理", "David A. Patterson", 129.00))
    manager.add_book(Book(3, "人工智能", "Stuart Russell", 119.00))

    # 删除图书
    manager.remove_book(2)

    # 查找图书
    book = manager.find_book(1)
    if book:
        print(f"Found book: {book.title} by {book.author}")
    else:
        print("Book not found")

    # 列出所有图书
    manager.list_books()

if __name__ == "__main__":
    main()
```

```python
        self.size = size
        self.table = [None] * size

        return key % self.size

    def insert(self, key, value):

        if self.table[index] is None:
            self.table[index] = [(key, value)]
        else:
            self.table[index].append((key, value))

        index = self.hash_function(key)
        if self.table[index] is None:
            return None
        for k, v in self.table[index]:
            if k == key:
                return v
        return None
```

```python
class Calculator:
    def __init__(self):

            "+": lambda x, y: x + y,
            "-": lambda x, y: x - y,
            "*": lambda x, y: x * y,
            "/": lambda x, y: x / y
        }

    def evaluate(self, expression):

        result = int(tokens[0])
        for token in tokens[1:]:
            op = token[0]
            value = int(token[1:])
            operation = self.rules[op]
            result = operation(result, value)
        return result
```

## 4.1 函数式编程基础

函数式编程（Functional Programming，FP）是一种以函数为核心，注重不可变数据和纯函数的编程范式。它与命令式编程和声明式编程有所不同，强调通过定义和组合函数来表达程序逻辑，而非通过状态改变和条件判断。在这一节中，我们将介绍函数式编程的基本概念、特点和应用。

### 4.1.1 函数式编程语言概述

函数式编程语言包括多种编程语言，如Haskell、Scala、Erlang和Clojure等。这些语言提供了丰富的函数式编程功能，使得程序员可以更加简洁和高效地编写代码。函数式编程语言通常支持不可变数据、高阶函数、递归和模式匹配等特性。

### 4.1.2 函数式编程基本概念

函数式编程的基本概念包括：

- **纯函数**：纯函数是一种无副作用的函数，其输出仅取决于输入，不会修改外部状态。例如，`sum([1, 2, 3])` 是一个纯函数，因为它仅返回列表 [1, 2, 3] 的和，而不改变任何外部状态。
- **不可变数据**：不可变数据是一种一旦创建后就不能修改的数据。在函数式编程中，数据通常是不可变的，这样可以避免状态改变和副作用。
- **高阶函数**：高阶函数是一种可以接受其他函数作为参数或返回函数的函数。例如，`map` 和 `filter` 是常用的高阶函数，用于对列表中的每个元素进行操作。
- **递归**：递归是一种通过调用自身来解决问题的编程技术。在函数式编程中，递归是一种常见的编程模式，用于处理复杂的问题。

### 4.1.3 函数式编程常见模式

函数式编程常见的编程模式包括：

- **函数组合**：通过将多个函数组合在一起，实现更复杂的逻辑。
- **柯里化**：将一个多参数函数转换为一个接受部分参数的函数，用于提高代码的可复用性和灵活性。
- **惰性计算**：在需要时才进行计算，避免不必要的计算开销。
- **类型推导**：自动推导函数和数据的类型，提高代码的可读性和可靠性。

```haskell

sum (x:xs) = x + sum xs

```

在这个示例中，我们定义了一个名为`sum`的纯函数，它接受一个整数列表并返回其和。函数使用递归实现，通过模式匹配将列表分解为头部和尾部，然后计算头部元素与尾部和的和。

### 4.1.4 函数式编程的特点

函数式编程具有以下特点：

- **纯函数**：纯函数避免了副作用，使得代码更易于理解和测试。
- **不可变数据**：不可变数据减少了状态变化和副作用，提高了代码的可维护性和可扩展性。

2. **链表**：一种线性数据结构，由一系列节点组成，每个节点包含数据和指向下一个节点的指针。
3. **栈**：一种后进先出（LIFO）的数据结构。
4. **队列**：一种先进先出（FIFO）的数据结构。

### 4.2.2 算法与数据结构的函数式实现

**快速排序**（Quick Sort）是一种高效的排序算法，通过划分子数组并递归排序来实现。以下是使用Haskell实现的快速排序：

```haskell
quickSort :: (Ord a) => [a] -> [a]
quickSort [] = []
quickSort (x:xs) =
    let smaller = [a | a <- xs, a < x]
        bigger = [a | a <- xs, a >= x]
    in quickSort smaller ++ [x] ++ quickSort bigger

main :: IO ()
main = print (quickSort [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5])
```

**二分查找**（Binary Search）是一种高效的查找算法，适用于有序数组。以下是使用Haskell实现的二分查找：

```haskell
binarySearch :: (Ord a) => [a] -> a -> Int
binarySearch _ _ = -1
binarySearch xs x =
    let (low, high) = (0, length xs - 1)
    in if low > high
       then -1
       else let mid = low + (high - low) `div` 2
            in if xs !! mid == x
               then mid
               else if x < xs !! mid
                     then binarySearch (take mid xs) x
                     else binarySearch (drop mid xs) x

main :: IO ()
main = print (binarySearch [1, 3, 5, 7, 9] 5)
```

**链表**（Linked List）是一种常用的数据结构，用于存储元素序列。以下是使用Haskell实现的链表：

```haskell
data List a = Nil | Cons a (List a)

-- 创建链表
createList :: [Int] -> List Int
createList [] = Nil
createList (x:xs) = Cons x (createList xs)

-- 显示链表
displayList :: List Int -> String
displayList Nil = "[]"
displayList (Cons x xs) = x ++ " -> " ++ displayList xs

main :: IO ()
main = print (displayList (createList [1, 2, 3, 4, 5]))
```

### 4.2.3 函数式编程算法分析

函数式编程算法的分析主要关注其纯函数性和高效的数据处理能力。以下是对快速排序和二分查找的时间复杂度分析：

## 4.3 函数式编程最佳实践

函数式编程以其简洁的语法、高效的性能和强大的抽象能力，在处理复杂问题和数据密集型任务方面具有显著优势。然而，为了编写高效、可维护和可扩展的函数式代码，我们需要遵循一些最佳实践。以下是一些常见的函数式编程最佳实践：

### 4.3.1 编写高效函数式代码

1. **使用纯函数**：纯函数避免了副作用，使得代码更易于理解和测试。尽量使用纯函数来组织代码。
2. **避免全局变量**：全局变量可能导致状态改变和难以追踪的问题。尽量使用局部变量和参数传递数据。
3. **利用递归**：递归是一种强大的编程技术，用于处理复杂的问题。但要注意递归的效率，避免过多的递归调用。
4. **使用高阶函数**：高阶函数提高了代码的可复用性和灵活性。通过组合高阶函数，可以简化复杂的逻辑。

### 4.3.2 函数式编程常见问题与解决方案

1. **性能问题**：
   - **解决方案**：分析代码的性能瓶颈，使用高效的算法和数据结构，避免不必要的计算和内存分配。
   - **示例**：在实现递归时，可以使用尾递归优化来提高性能。

2. **可维护性问题**：
   - **解决方案**：编写清晰、简洁的代码，使用有意义的变量名和函数名，注释关键部分，遵循代码风格指南。
   - **示例**：在实现数据处理函数时，可以分解复杂的逻辑，使用小而独立的函数。

3. **并发问题**：
   - **解决方案**：避免在共享变量上使用锁，使用并发编程模型（如Actor模型）来避免锁竞争。
   - **示例**：在实现并发计算时，可以使用并行处理库（如Python的`multiprocessing`模块）来提高性能。

### 4.3.3 函数式编程的设计模式

设计模式是一套预定义的解决方案，用于解决常见的问题。以下是一些适用于函数式编程的设计模式：

1. **组合模式**：通过组合多个函数，实现更复杂的逻辑，提高代码的可复用性和灵活性。
2. **策略模式**：将算法的实现封装成对象，便于在运行时切换算法。
3. **模板方法模式**：定义一个操作框架，将一些具体操作延迟到子类实现。

以下是一个使用组合模式的函数式编程示例，用于计算不同类型的数值操作：

```python
def add(x, y):
    return x + y

def subtract(x, y):
    return x - y

def multiply(x, y):
    return x * y

def divide(x, y):
    if y == 0:
        raise ValueError("Cannot divide by zero")
    return x / y

# 组合操作
def calculate_expression(x, y, op):
    if op == "add":
        return add(x, y)
    elif op == "subtract":
        return subtract(x, y)
    elif op == "multiply":
        return multiply(x, y)
    elif op == "divide":
        return divide(x, y)
    else:
        raise ValueError("Unknown operation")

# 测试
print(calculate_expression(5, 3, "add"))  # Output: 8
print(calculate_expression(5, 3, "subtract"))  # Output: 2
print(calculate_expression(5, 3, "multiply"))  # Output: 15
print(calculate_expression(5, 3, "divide"))  # Output: 1.6666666666666667
```

通过遵循这些最佳实践，我们可以编写高效、可维护和可扩展的函数式代码，提高程序的性能和可靠性。

### 4.4.2 函数式编程案例解析

我们将使用Python语言实现这个待办事项应用，并详细解析每个功能模块的实现。

**1. 数据模型设计**

首先，我们设计一个待办事项数据模型，用于存储待办事项的基本信息：

```python
class Todo:
    def __init__(self, id, title, completed=False):
        self.id = id
        self.title = title
        self.completed = completed
```

**2. 管理器设计**

接下来，我们设计一个待办事项管理器类，用于实现添加、删除、标记和列出待办事项的功能：

```python
class TodoManager:
    def __init__(self):
        self.todos = []

    def add_todo(self, todo):
        self.todos.append(todo)

    def remove_todo(self, todo_id):
        for todo in self.todos:
            if todo.id == todo_id:
                self.todos.remove(todo)
                return True
        return False

    def mark_completed(self, todo_id):
        for todo in self.todos:
            if todo.id == todo_id:
                todo.completed = True
                return True
        return False

    def list_todos(self):
        for todo in self.todos:
            completed_str = "completed" if todo.completed else "pending"
            print(f"ID: {todo.id}, Title: {todo.title}, Status: {completed_str}")
```

**3. 程序主入口**

最后，我们实现一个主入口程序，用于测试待办事项管理器的功能：

```python
def main():
    manager = TodoManager()

    # 添加待办事项
    manager.add_todo(Todo(1, "Buy groceries"))
    manager.add_todo(Todo(2, "Read book"))
    manager.add_todo(Todo(3, "Go for a run"))

    # 删除待办事项
    manager.remove_todo(2)

    # 标记待办事项为已完成
    manager.mark_completed(1)
    manager.mark_completed(3)

    # 列出所有待办事项
    manager.list_todos()

if __name__ == "__main__":
    main()
```

函数式编程在这个案例中的应用体现了其强大的抽象能力和简洁的语法。通过使用纯函数和不可变数据，我们能够编写出易于理解、测试和维护的代码。虽然函数式编程在某些情况下可能不如命令式编程和声明式编程高效，但其在处理复杂问题和数据密集型任务方面具有明显优势。
