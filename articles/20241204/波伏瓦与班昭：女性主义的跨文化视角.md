## 第1章：波伏瓦与班昭：两位女性主义者的介绍

### 1.1 波伏瓦：生平与思想

西蒙娜·德·波伏瓦（1908-1986）是20世纪最具影响力的法国哲学家、作家和女性主义者。她与让-保罗·萨特共同创立了存在主义哲学，并在其著作《第二性》中系统阐述了女性主义思想。波伏瓦认为，女性在社会和历史上是被压迫和客体化的，女性解放的实质是重新定义性别，赋予女性自由和自我决定权。

### 1.2 班昭：生平与贡献

班昭（约49-120），东汉时期著名女学者，被誉为“班婕妤之弟”。她以卓越的文学才能和深刻的儒家思想影响了一代人。班昭在其作品中提倡女性教育，主张女性参与社会和政治事务，是女性主义思想在中国古代的重要代表。

跨文化女性主义是指在全球范围内，不同文化背景下的女性主义者共同探讨性别平等、女性权利和自我实现的问题。它超越了单一文化的局限，试图在全球范围内寻找共同点和差异性，以推动全球女性权益的提升。

跨文化女性主义的重要意义在于，它不仅关注女性在社会中的地位和权利，还关注文化、政治、经济等因素对女性影响。通过跨文化比较，可以更好地理解女性主义在不同文化背景下的演变和发展。

西方女性主义则更加关注个人权利和自由，强调女性的自我解放和自我实现。存在主义和自由主义是西方女性主义的重要理论基础。

```python
import random

def calculate_probability(event, trials):
    occurrences = 0
    for _ in range(trials):
        if random.choice([True, False]) == event:
            occurrences += 1
    return occurrences / trials

event = True
trials = 1000
probability = calculate_probability(event, trials)
print(f"The probability of event {event} is {probability}")
```
