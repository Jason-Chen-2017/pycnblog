```python
import numpy as np

def calculate_variance(data):
    """
    计算数据的方差
    """
    mean = np.mean(data)
    variance = np.mean((data - mean) ** 2)
    return variance

# 示例数据
data = np.array([1, 2, 3, 4, 5])

# 计算方差
variance = calculate_variance(data)

print("数据方差：", variance)
```

这段代码定义了一个名为`calculate_variance`的函数，用于计算数据的方差。方差是衡量数据分散程度的重要指标。在代码中，首先计算数据的平均值，然后计算每个数据点与平均值的差的平方，并求和，最后计算平均值。示例数据为 `[1, 2, 3, 4, 5]`，调用函数后输出数据方差。
