#### 1.3 柏格森对时间与空间的独特理解

柏格森认为，时间是一种内在的、动态的过程，它反映了事物的本质特征。他提出了“自由意志”的概念，认为时间是自由意志的产物，而非机械决定论的产物。空间则是一种内在的、相互联系的质性，它不是独立存在的，而是与其他事物相互影响。

### 柏格森的质性多元论

柏格森的质性多元论强调时间与空间的质性特征。以下是一个简单的Python示例，用于计算时间序列数据的质性多元性指标。

```python
def qualitative_diversity(time_series):
    """
    质性多元性分析函数。
    
    参数：
    time_series: 时间序列数据。
    
    返回：
    质性多元性指标。
    """
    diversity_index = 0
    for i in range(len(time_series)):
        diversity_index += (time_series[i] - sum(time_series) / len(time_series)) ** 2
    diversity_index /= len(time_series)
    return diversity_index

# 示例数据
time_series = [1, 2, 3, 4, 5]

# 计算质性多元性
diversity_index = qualitative_diversity(time_series)

print("质性多元性指标：", diversity_index)
```
