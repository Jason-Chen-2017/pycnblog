### 1.1 小型核反应堆的定义与特点

1.1.1 小型核反应堆的定义  
小型核反应堆是指功率输出相对较小的核反应堆，通常在几十兆瓦到几百兆瓦之间。与传统大型核反应堆相比，小型核反应堆具有模块化设计、建造周期短、部署灵活等特点。

1.1.2 小型核反应堆的核心特点  
- 模块化设计：便于批量生产，降低建造成本。
- 建造周期短：从设计到投运周期较短，适合快速能源需求。
- 部署灵活：适用于偏远地区、工业园区等场景。

1.1.3 小型核反应堆与传统核反应堆的区别  
| 特性               | 小型核反应堆       | 传统大型核反应堆     |
|--------------------|--------------------|----------------------|
| 功率输出           | 低至几百兆瓦       | 高至千兆瓦           |
| 建造周期           | 短（2-5年）        | 长（5-10年）          |
| 部署场景           | 灵活，适应多种需求 | 主要用于大型电网      |

## 第3章: 小型核反应堆技术的核心原理

### 3.1 核反应堆的基本原理

3.1.1 核裂变反应的基本过程  
核裂变是指重核吸收一个中子后分裂成两个较轻的核，同时释放出更多的中子和能量。这一过程在核反应堆中持续进行，产生热量。

3.1.2 核反应堆的组成部分  
- 核燃料：通常使用铀-235或铀-238。
- 准备：常用的冷却剂包括轻水、重水和液态金属钠。
- 保护层：用于吸收泄漏的中子，防止临界条件的出现。

3.1.3 核反应堆的冷却系统  
- 水冷系统：利用水作为冷却剂，带走热量并转化为蒸汽。
- 气冷系统：使用气体（如氦气）作为冷却剂，适用于高温反应堆。

4.1.1 投资回报率的计算公式  
$$ ROI = \frac{（投资收益 - 投资成本）}{投资成本} \times 100\% $$

```python
import numpy as np
import scipy.stats as stats

def risk_assessment(data):
    # 计算每个变量的均值和标准差
    mean = np.mean(data)
    std = np.std(data)
    # 计算风险评分
    risk_score = stats.norm.sf(mean + 2*std)
    return risk_score
```
