- 推荐算法实现
```python
def get_recommendations(user_id, similarity_matrix):
    # 获取用户相似度排名
    user_index = user_id
    sorted_indices = similarity_matrix[user_index].argsort()[::-1]
    recommendations = []
    for i in sorted_indices:
        if i != user_index:
            recommendations.append(i)
            if len(recommendations) == 5:
                break
    return recommendations
```
