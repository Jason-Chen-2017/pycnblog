#### 5.2 系统核心实现

在本节中，我们将使用 Python 编写城市农耕社区项目的主要代码，包括数据库模型、视图函数和路由。

```python
# 导入 Flask 框架和 SQLAlchemy 库
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

# 创建 Flask 应用对象
app = Flask(__name__)

# 配置数据库 URI
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///garden.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

# 创建 SQLAlchemy 实例
db = SQLAlchemy(app)

# 定义 Garden 模型
class Garden(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    plants = db.relationship('Plant', backref='garden', lazy=True)

# 定义 Plant 模型
class Plant(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    garden_id = db.Column(db.Integer, db.ForeignKey('garden.id'), nullable=False)

# 创建数据库表
db.create_all()

# 创建园区接口
@app.route('/garden', methods=['POST'])
def create_garden():
    garden_name = request.json['name']
    new_garden = Garden(name=garden_name)
    db.session.add(new_garden)
    db.session.commit()
    return jsonify({'id': new_garden.id, 'name': new_garden.name})

# 创建植物接口
@app.route('/plant', methods=['POST'])
def create_plant():
    plant_name = request.json['name']
    garden_id = request.json['garden_id']
    new_plant = Plant(name=plant_name, garden_id=garden_id)
    db.session.add(new_plant)
    db.session.commit()
    return jsonify({'id': new_plant.id, 'name': new_plant.name})

# 启动 Flask 应用
if __name__ == '__main__':
    app.run(debug=True)
```

在本节中，我们将对上述代码进行解读和分析，解释每个部分的功能和实现原理。

- **视图函数**：`create_garden` 和 `create_plant` 函数分别处理创建园区和植物的 HTTP 请求，将数据存储到数据库中。
- **路由**：使用 Flask 的路由系统将 URL 路径映射到对应的视图函数。
