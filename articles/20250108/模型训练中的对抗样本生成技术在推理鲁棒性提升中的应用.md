                 

### 第1章: 问题背景与核心概念

#### 1.1 问题背景

在人工智能领域，尤其是深度学习应用中，模型训练与推理过程至关重要。模型训练的目的是让机器学习算法从大量数据中学习到有用的模式和规律，而推理阶段则是应用这些学习到的规律来做出预测或决策。然而，随着模型的复杂性和数据多样性的增加，模型在推理阶段的鲁棒性变得越来越重要。

模型鲁棒性指的是模型在面对异常输入或恶意攻击时的表现能力。一个鲁棒性强的模型能够在各种不同的场景下稳定地工作，而不会因为微小的变化或恶意攻击而失效。特别是在安全敏感的应用场景中，如自动驾驶、医疗诊断和金融交易等，模型的鲁棒性直接关系到系统的安全性和可靠性。

对抗样本（Adversarial Examples）是一种经过特殊设计的输入样本，旨在欺骗机器学习模型，使其输出错误的结果。对抗样本通常是通过在原始样本上添加微小的扰动生成的，这些扰动对于人类感知来说几乎不可察觉，但足以导致模型产生显著的错误。

近年来，对抗样本生成技术（Adversarial Attack Techniques）得到了广泛关注，因为它们揭示了机器学习模型的脆弱性，同时也为提升模型的鲁棒性提供了研究方向。在模型训练过程中，通过引入对抗样本，可以帮助模型学习到更多的模式和规律，从而提高其在推理阶段的鲁棒性。

#### 1.2 核心概念

##### 1.2.1 对抗样本

对抗样本是专门为欺骗机器学习模型而设计的输入样本。这些样本通常在视觉、音频或文本数据中引入微小的扰动，使得模型无法正确分类或识别。对抗样本的生成方法包括：

- **基于梯度的攻击（Gradient-Based Attack）**：通过计算模型梯度，找到能够最小化模型预测误差的扰动。
- **不变性攻击（Invariant Attack）**：设计扰动，使得模型对原始样本和对抗样本的预测结果相同。
- **生成对抗网络（GAN）攻击**：利用生成对抗网络生成对抗样本。

##### 1.2.2 生成对抗网络（GAN）

生成对抗网络（GAN）是由生成器（Generator）和判别器（Discriminator）组成的模型，旨在通过竞争和对抗的过程生成逼真的数据。GAN的核心思想是生成器试图生成与真实数据相似的数据，而判别器则试图区分真实数据和生成数据。

- **生成器（Generator）**：接受随机噪声作为输入，生成与真实数据相似的数据。
- **判别器（Discriminator）**：接收真实数据和生成数据的输入，并尝试判断其真实性。

在训练过程中，生成器和判别器通过对抗的方式不断更新权重，最终生成器生成的数据质量越来越高，判别器的判断能力越来越强。

##### 1.2.3 模型鲁棒性

模型鲁棒性是指模型在面对异常输入或恶意攻击时的稳定性和准确性。提升模型鲁棒性的方法包括：

- **对抗训练（Adversarial Training）**：在训练过程中引入对抗样本，帮助模型学习到对抗攻击的规律。
- **数据增强（Data Augmentation）**：通过数据变换和扩展，增加训练数据的多样性。
- **模型正则化（Model Regularization）**：通过添加正则化项，减少模型过拟合的风险。

#### 1.3 对抗样本在推理阶段的鲁棒性提升

在推理阶段，模型的鲁棒性同样重要。对抗样本生成技术可以帮助提升模型在推理阶段的鲁棒性，主要方法包括：

- **实时对抗样本检测**：在推理过程中检测输入样本是否为对抗样本，并采取相应的措施。
- **对抗样本防御机制**：通过算法改进和模型调整，提高模型对对抗样本的抵抗力。
- **结合多模型推理**：通过多个模型同时进行推理，降低单一模型被对抗样本攻击的风险。

综上所述，对抗样本生成技术在模型训练和推理阶段的鲁棒性提升中发挥着重要作用。接下来，我们将详细探讨对抗样本生成的算法原理和实现，以及如何在实践中应用这些技术来提高模型的鲁棒性。

## 第3章: 对抗样本生成算法原理

### 3.1 算法概述

对抗样本生成算法的目的是创建能够欺骗机器学习模型的输入样本。这些样本通过在原始数据上引入微小的扰动，使得模型难以区分原始数据和对抗样本。这类算法的核心思想是利用机器学习模型自身的特性，找到使其产生错误的“漏洞”，并通过这些漏洞生成对抗样本。

对抗样本生成算法可以分为基于梯度的攻击、不变性攻击和生成对抗网络（GAN）攻击等几类。每一种算法都有其特定的应用场景和优缺点。

#### 3.1.1 基于梯度的攻击

基于梯度的攻击（Gradient-Based Attack）是当前最为流行的一种对抗样本生成方法。该方法通过计算模型梯度，找到能够在输入空间中产生最大扰动的方向，从而生成对抗样本。

#### 3.1.2 不变性攻击

不变性攻击（Invariant Attack）的目标是生成对抗样本，使得模型在原始样本和对抗样本上的输出结果一致。这类攻击方法通常基于对模型不变性的理解，通过设计特定的扰动来实现。

#### 3.1.3 生成对抗网络（GAN）攻击

生成对抗网络（GAN）攻击是利用GAN模型生成对抗样本的一种方法。通过训练生成器和判别器，生成器生成的样本越来越接近真实数据，而判别器则越来越难以区分生成数据和真实数据。这种对抗过程使得生成的对抗样本具有较高的欺骗性。

### 3.2 生成对抗网络（GAN）算法原理

生成对抗网络（GAN）是由生成器（Generator）和判别器（Discriminator）组成的模型，其核心思想是通过生成器和判别器之间的对抗训练来生成高质量的数据。

#### 3.2.1 生成器与判别器的基本概念

- **生成器（Generator）**：生成器接收随机噪声作为输入，通过神经网络将噪声映射成类似真实数据的输出。生成器的目标是生成尽可能逼真的数据，使其能够欺骗判别器。

- **判别器（Discriminator）**：判别器接收真实数据和生成数据的输入，并尝试判断其真实性。判别器的目标是准确地区分真实数据和生成数据。

#### 3.2.2 GAN的优化过程

GAN的训练过程可以看作是一个零和博弈。生成器和判别器通过交替训练，不断优化自己的性能。

- **生成器的优化目标**：生成器试图生成尽可能逼真的数据，使得判别器无法准确地区分真实数据和生成数据。生成器的损失函数通常为：

  $$\text{Generator Loss} = -\text{log}(D(G(z)))$$

  其中，\(D(G(z))\) 是判别器对生成数据的评分。

- **判别器的优化目标**：判别器试图准确地区分真实数据和生成数据。判别器的损失函数通常为：

  $$\text{Discriminator Loss} = -[\text{log}(D(x)) + \text{log}(1 - D(G(z)))]$$

  其中，\(D(x)\) 是判别器对真实数据的评分，\(D(G(z))\) 是判别器对生成数据的评分。

#### 3.2.3 GAN在对抗样本生成中的应用

在对抗样本生成中，生成器和判别器的训练过程如下：

1. **生成器训练**：生成器根据当前判别器的权重生成数据，然后判别器对这些数据进行分类。生成器不断优化其参数，使其生成的数据更接近真实数据，从而使得判别器的分类准确率下降。

2. **判别器训练**：判别器根据真实数据和生成数据进行分类，并调整其参数以改善分类效果。通过这种对抗训练，判别器逐渐能够更好地区分真实数据和生成数据。

3. **对抗样本生成**：当生成器和判别器达到一定的训练效果后，可以使用生成器生成对抗样本。这些对抗样本可以通过对真实数据进行微小的扰动得到，扰动的大小可以通过生成器的参数来控制。

通过这种生成器和判别器的对抗训练，GAN模型可以生成具有高欺骗性的对抗样本，从而提升模型的鲁棒性。

```python
from tensorflow.keras.layers import Dense, Flatten, Conv2D, Conv2DTranspose
from tensorflow.keras.models import Sequential

# 生成器模型
def build_generator(z_dim):
    model = Sequential()
    model.add(Dense(128 * 7 * 7, input_dim=z_dim, activation='tanh'))
    model.add(Conv2DTranspose(128, 5, strides=2, padding='same'))
    model.add(Conv2DTranspose(128, 5, strides=2, padding='same'))
    model.add(Conv2D(1, 7, padding='same', activation='sigmoid'))
    return model

def build_discriminator(img_shape):
    model = Sequential()
    model.add(Conv2D(128, 5, strides=2, padding='same', input_shape=img_shape))

    model.add(Conv2D(128, 5, strides=2, padding='same'))

def build_gan(generator, discriminator):

    model.add(generator)

gan = build_gan(generator, discriminator)
```

### 4.1 GAN的数学模型

生成对抗网络（GAN）的核心在于生成器（Generator）和判别器（Discriminator）之间的对抗训练过程。为了更深入地理解GAN的工作原理，我们需要从数学模型的角度来分析其各个组成部分。

#### 4.1.1 生成器和判别器的损失函数

在GAN中，生成器和判别器的损失函数是设计训练过程的基础。生成器试图生成与真实数据相近的数据，而判别器则试图准确区分真实数据和生成数据。

- **生成器的损失函数**：

  $$\text{Generator Loss} = -\text{log}(D(G(z)))$$

  这里，\(D(G(z))\) 是判别器对生成数据的评分。由于生成器希望生成的数据能够欺骗判别器，使得判别器认为这些数据是真实的，因此生成器的目标是最大化判别器对生成数据的评分。

- **判别器的损失函数**：

  $$\text{Discriminator Loss} = -[\text{log}(D(x)) + \text{log}(1 - D(G(z)))]$$

  其中，\(D(x)\) 是判别器对真实数据的评分，\(D(G(z))\) 是判别器对生成数据的评分。判别器的目标是最大化判别真实数据和生成数据的差距，因此它希望对真实数据的评分接近1，而对生成数据的评分接近0。

#### 4.1.2 GAN的训练过程

GAN的训练过程是一个交替优化的过程，即生成器和判别器分别根据对方的损失函数进行参数更新。

1. **生成器的训练**：

   在每次训练迭代中，生成器根据当前判别器的权重生成数据，然后判别器对这些数据进行分类。生成器不断优化其参数，使其生成的数据更接近真实数据，从而使得判别器的分类准确率下降。

   更新公式为：

   $$\theta_{\text{generator}} \leftarrow \theta_{\text{generator}} - \alpha \frac{\partial L_{\text{generator}}}{\partial \theta_{\text{generator}}}$$

   其中，\(\theta_{\text{generator}}\) 是生成器的参数，\(L_{\text{generator}}\) 是生成器的损失函数，\(\alpha\) 是学习率。

2. **判别器的训练**：

   判别器在每次训练迭代中接收真实数据和生成数据，并尝试对其进行分类。判别器不断优化其参数，以提高对真实数据和生成数据的分类能力。

   更新公式为：

   $$\theta_{\text{discriminator}} \leftarrow \theta_{\text{discriminator}} - \alpha \frac{\partial L_{\text{discriminator}}}{\partial \theta_{\text{discriminator}}}$$

   其中，\(\theta_{\text{discriminator}}\) 是判别器的参数，\(L_{\text{discriminator}}\) 是判别器的损失函数，\(\alpha\) 是学习率。

通过这种交替优化的过程，生成器和判别器不断互相挑战，最终生成器生成的数据质量越来越高，判别器的判断能力也越来越强。

#### 4.1.3 模型训练过程中的优化

在GAN的训练过程中，优化目标是使生成器生成的数据尽可能地逼真，同时使判别器能够准确地区分真实数据和生成数据。为了实现这一目标，GAN模型通常采用以下优化策略：

1. **平衡损失函数**：

   为了避免生成器或判别器过度训练，通常需要在损失函数中加入平衡项，使两者的损失函数权重相等。这样可以确保两者在训练过程中得到平等的优化。

2. **学习率调整**：

   由于生成器和判别器的优化目标是相反的，因此它们的学习率通常不同。生成器通常使用较小的学习率，以避免过度调整，而判别器使用较大的学习率，以提高分类能力。

3. **批量大小**：

   批量大小对GAN的训练过程也有重要影响。较小的批量大小可以提高模型的泛化能力，但可能导致训练过程不稳定。较大的批量大小可以提高训练过程的稳定性，但可能导致模型过拟合。

通过上述优化策略，GAN模型能够在生成器和判别器之间建立一种动态平衡，从而实现高质量数据的生成。

### 4.3 GAN在对抗样本生成中的应用

GAN在对抗样本生成中的应用主要基于其强大的数据生成能力。通过GAN生成的对抗样本具有以下优点：

```python
import tensorflow as tf
from tensorflow.keras.layers import Dense, Flatten, Conv2D, Conv2DTranspose
from tensorflow.keras.models import Sequential

# 设置随机种子以确保结果可重复
tf.random.set_seed(42)

# 定义生成器模型
def build_generator(z_dim=100):
    model = Sequential()
    model.add(Dense(128 * 7 * 7, input_dim=z_dim, activation='tanh'))
    model.add(Conv2DTranspose(128, 5, strides=2, padding='same'))
    model.add(Conv2DTranspose(128, 5, strides=2, padding='same'))
    model.add(Conv2D(1, 7, padding='same', activation='sigmoid'))
    return model

# 定义判别器模型
def build_discriminator(img_shape=(28, 28, 1)):
    model = Sequential()
    model.add(Conv2D(128, 5, strides=2, padding='same', input_shape=img_shape))
    model.add(tf.keras.layers.LeakyReLU(alpha=0.2))
    model.add(Conv2D(128, 5, strides=2, padding='same'))
    model.add(tf.keras.layers.LeakyReLU(alpha=0.2))
    model.add(Flatten())
    model.add(Dense(1, activation='sigmoid'))
    return model

# 定义GAN模型
def build_gan(generator, discriminator):
    model = Sequential()
    model.add(generator)
    model.add(discriminator)
    return model

# 构建和编译模型
z_dim = 100
img_shape = (28, 28, 1)

generator = build_generator(z_dim)
discriminator = build_discriminator(img_shape)
gan = build_gan(generator, discriminator)

discriminator.compile(loss='binary_crossentropy', optimizer=tf.keras.optimizers.Adam(0.0001))
gan.compile(loss='binary_crossentropy', optimizer=tf.keras.optimizers.Adam(0.0001, beta_1=0.5))

# 生成器训练过程
def train_generator(generator, latent_dim, n_samples, n_critic=2):
    noise = np.random.normal(0, 1, size=(n_samples, latent_dim))
    gen_samples = generator.predict(noise)
    d_loss_gen = 0

    for _ in range(n_critic):
        noise = np.random.normal(0, 1, size=(n_samples, latent_dim))
        gen_samples = generator.predict(noise)
        d_loss_gen += discriminator.train_on_batch(gen_samples, np.ones((n_samples, 1)))

    d_loss_gen /= n_critic

    return d_loss_gen

# 判别器训练过程
def train_discriminator(discriminator, real_images, fake_images, batch_size=32):
    real_labels = np.ones((batch_size, 1))
    fake_labels = np.zeros((batch_size, 1))

    real_images = real_images / 255.0
    fake_images = fake_images / 255.0

    d_loss_real = discriminator.train_on_batch(real_images, real_labels)
    d_loss_fake = discriminator.train_on_batch(fake_images, fake_labels)
    d_loss = 0.5 * np.add(d_loss_real, d_loss_fake)

    return d_loss

# 训练GAN模型
n_epochs = 50
batch_size = 32
n_samples = 16

for epoch in range(n_epochs):
    for _ in range(batch_size // n_samples):
        # 准备真实样本
        real_images = np.random.rand(batch_size, *img_shape)

        # 生成对抗样本
        noise = np.random.rand(batch_size, z_dim)
        fake_images = generator.predict(noise)

        # 训练判别器
        d_loss = train_discriminator(discriminator, real_images, fake_images, batch_size)

        # 训练生成器
        g_loss = train_generator(generator, z_dim, n_samples)

    print(f"Epoch {epoch+1}/{n_epochs}, D_loss: {d_loss}, G_loss: {g_loss}")

# 保存模型
generator.save('generator_model.h5')
discriminator.save('discriminator_model.h5')
```

### 6.3 代码应用解读与分析

#### 6.3.1 生成器和判别器模型

生成器和判别器模型是GAN的核心组成部分。生成器的目标是生成逼真的图像，而判别器的目标是区分真实图像和生成图像。

- **生成器**：使用全连接层和卷积转置层（Conv2DTranspose）来生成图像。生成器首先接收一个随机噪声向量作为输入，通过全连接层将其映射到一个中间层，然后通过卷积转置层逐层生成图像。
  
- **判别器**：使用卷积层和漏激活函数（LeakyReLU）来处理图像。判别器通过多个卷积层提取图像特征，并最终输出一个二分类结果，表示图像是真实的还是生成的。

#### 6.3.2 训练过程

GAN的训练过程是一个复杂的循环过程，包括判别器和生成器的交替训练。

- **判别器训练**：判别器接收一批真实图像和生成图像，并尝试区分它们。判别器的损失函数是二元交叉熵（binary cross-entropy），目标是使真实图像的预测结果接近1，生成图像的预测结果接近0。
  
- **生成器训练**：生成器接收随机噪声向量，并生成假图像。生成器的目标是使判别器无法区分真实图像和生成图像。生成器的损失函数是判别器对生成图像的预测结果的负对数。

#### 6.3.3 对抗样本生成

在训练过程中，生成器不断生成对抗样本，以欺骗判别器。这些对抗样本在训练模型的鲁棒性方面发挥着重要作用。

#### A.1 GAN相关术语解释

1. **生成器（Generator）**：生成器是GAN中的一个模型，其主要任务是生成与真实数据相似的数据。
2. **判别器（Discriminator）**：判别器是GAN中的另一个模型，其主要任务是区分真实数据和生成数据。
3. **对抗训练（Adversarial Training）**：对抗训练是一种训练方法，通过让生成器和判别器互相竞争来优化模型的参数。
4. **对抗样本（Adversarial Example）**：对抗样本是一种经过特殊设计的输入样本，旨在欺骗机器学习模型，使其输出错误的结果。
5. **梯度惩罚（Gradient Penalty）**：梯度惩罚是一种用于稳定GAN训练的技术，通过惩罚生成器和判别器的梯度差异来提高模型的稳定性。

#### A.2 常见GAN模型介绍

1. **原始GAN（Original GAN）**：由Ian Goodfellow等人提出的原始GAN模型，包括生成器和判别器，通过对抗训练生成高质量的数据。
2. **条件GAN（cGAN）**：条件GAN引入了条件信息，如标签或类别信息，使得生成器能够根据特定条件生成数据。
3. **混合GAN（hGAN）**：混合GAN结合了多个GAN模型，通过混合训练提高生成质量和模型稳定性。
4. **感知GAN（Perceptual GAN）**：感知GAN引入了感知损失函数，通过比较生成数据和真实数据的感知特征来提高生成质量。

```python
from tensorflow.keras.models import Sequential

# 设置随机种子以确保结果可重复
tf.random.set_seed(42)

# 定义生成器模型
def build_generator(z_dim=100):
    model = Sequential()
    model.add(Dense(128 * 7 * 7, input_dim=z_dim, activation='tanh'))
    model.add(Conv2DTranspose(128, 5, strides=2, padding='same'))
    model.add(Conv2DTranspose(128, 5, strides=2, padding='same'))
    model.add(Conv2D(1, 7, padding='same', activation='sigmoid'))
    return model

# 定义判别器模型
def build_discriminator(img_shape=(28, 28, 1)):
    model = Sequential()
    model.add(Conv2D(128, 5, strides=2, padding='same', input_shape=img_shape))
    model.add(tf.keras.layers.LeakyReLU(alpha=0.2))
    model.add(Conv2D(128, 5, strides=2, padding='same'))
    model.add(tf.keras.layers.LeakyReLU(alpha=0.2))
    model.add(Flatten())
    model.add(Dense(1, activation='sigmoid'))
    return model

# 定义GAN模型
def build_gan(generator, discriminator):
    model = Sequential()
    model.add(generator)
    model.add(discriminator)
    return model

# 构建和编译模型
z_dim = 100
img_shape = (28, 28, 1)

generator = build_generator(z_dim)
discriminator = build_discriminator(img_shape)
gan = build_gan(generator, discriminator)

discriminator.compile(loss='binary_crossentropy', optimizer=tf.keras.optimizers.Adam(0.0001))
gan.compile(loss='binary_crossentropy', optimizer=tf.keras.optimizers.Adam(0.0001, beta_1=0.5))

# 训练GAN模型
n_epochs = 50
batch_size = 32
n_samples = 16

for epoch in range(n_epochs):
    for _ in range(batch_size // n_samples):
        # 准备真实样本
        real_images = np.random.rand(batch_size, *img_shape)

        # 生成对抗样本
        noise = np.random.rand(batch_size, z_dim)
        fake_images = generator.predict(noise)

        # 训练判别器
        d_loss = train_discriminator(discriminator, real_images, fake_images, batch_size)

        # 训练生成器
        g_loss = train_generator(generator, z_dim, n_samples)

    print(f"Epoch {epoch+1}/{n_epochs}, D_loss: {d_loss}, G_loss: {g_loss}")

discriminator.save('discriminator_model.h5')
```

### A.5 常见问题解答

1. **Q：GAN为什么需要对抗训练？**
   **A**：GAN需要对抗训练是因为生成器和判别器之间存在着相互制约的关系。生成器试图生成逼真的数据来欺骗判别器，而判别器则试图准确地区分真实数据和生成数据。通过这种对抗过程，生成器和判别器都能够不断优化，从而实现高质量的数据生成。
   
2. **Q：GAN训练过程中为什么会出现模式崩溃？**

3. **Q：如何评估GAN生成的数据质量？**

#### A.1 GAN相关术语解释

1. **生成器（Generator）**：生成器是GAN中的一个模型，其主要任务是生成与真实数据相似的数据。
2. **判别器（Discriminator）**：判别器是GAN中的另一个模型，其主要任务是区分真实数据和生成数据。
3. **对抗训练（Adversarial Training）**：对抗训练是一种训练方法，通过让生成器和判别器互相竞争来优化模型的参数。
4. **对抗样本（Adversarial Example）**：对抗样本是一种经过特殊设计的输入样本，旨在欺骗机器学习模型，使其输出错误的结果。
5. **梯度惩罚（Gradient Penalty）**：梯度惩罚是一种用于稳定GAN训练的技术，通过惩罚生成器和判别器的梯度差异来提高模型的稳定性。

#### A.2 常见GAN模型介绍

1. **原始GAN（Original GAN）**：由Ian Goodfellow等人提出的原始GAN模型，包括生成器和判别器，通过对抗训练生成高质量的数据。
2. **条件GAN（cGAN）**：条件GAN引入了条件信息，如标签或类别信息，使得生成器能够根据特定条件生成数据。
3. **混合GAN（hGAN）**：混合GAN结合了多个GAN模型，通过混合训练提高生成质量和模型稳定性。
4. **感知GAN（Perceptual GAN）**：感知GAN引入了感知损失函数，通过比较生成数据和真实数据的感知特征来提高生成质量。

#### A.3 Python代码示例

以下是一个简单的GAN模型实现示例，用于生成对抗样本。

```python
import tensorflow as tf
from tensorflow.keras.layers import Dense, Flatten, Conv2D, Conv2DTranspose
from tensorflow.keras.models import Sequential

# 设置随机种子以确保结果可重复
tf.random.set_seed(42)

# 定义生成器模型
def build_generator(z_dim=100):
    model = Sequential()
    model.add(Dense(128 * 7 * 7, input_dim=z_dim, activation='tanh'))
    model.add(Conv2DTranspose(128, 5, strides=2, padding='same'))
    model.add(Conv2DTranspose(128, 5, strides=2, padding='same'))
    model.add(Conv2D(1, 7, padding='same', activation='sigmoid'))
    return model

# 定义判别器模型
def build_discriminator(img_shape=(28, 28, 1)):
    model = Sequential()
    model.add(Conv2D(128, 5, strides=2, padding='same', input_shape=img_shape))
    model.add(tf.keras.layers.LeakyReLU(alpha=0.2))
    model.add(Conv2D(128, 5, strides=2, padding='same'))
    model.add(tf.keras.layers.LeakyReLU(alpha=0.2))
    model.add(Flatten())
    model.add(Dense(1, activation='sigmoid'))
    return model

# 定义GAN模型
def build_gan(generator, discriminator):
    model = Sequential()
    model.add(generator)
    model.add(discriminator)
    return model

# 构建和编译模型
z_dim = 100
img_shape = (28, 28, 1)

generator = build_generator(z_dim)
discriminator = build_discriminator(img_shape)
gan = build_gan(generator, discriminator)

discriminator.compile(loss='binary_crossentropy', optimizer=tf.keras.optimizers.Adam(0.0001))
gan.compile(loss='binary_crossentropy', optimizer=tf.keras.optimizers.Adam(0.0001, beta_1=0.5))

# 训练GAN模型
n_epochs = 50
batch_size = 32
n_samples = 16

for epoch in range(n_epochs):
    for _ in range(batch_size // n_samples):
        # 准备真实样本
        real_images = np.random.rand(batch_size, *img_shape)

        # 生成对抗样本
        noise = np.random.rand(batch_size, z_dim)
        fake_images = generator.predict(noise)

        # 训练判别器
        d_loss = train_discriminator(discriminator, real_images, fake_images, batch_size)

        # 训练生成器
        g_loss = train_generator(generator, z_dim, n_samples)

    print(f"Epoch {epoch+1}/{n_epochs}, D_loss: {d_loss}, G_loss: {g_loss}")

# 保存模型
generator.save('generator_model.h5')
discriminator.save('discriminator_model.h5')
```
