#### 第1章：区块链技术基础

##### 1.1 区块链的定义与核心特性

区块链是一种分布式数据库技术，通过加密算法和共识机制，实现了数据的不可篡改和去中心化存储。其核心特性包括：

- **去中心化**：区块链不存在中央服务器，所有参与节点都具有相同的权限。
- **数据透明**：区块链上的数据对所有节点公开，确保透明度。
- **安全性**：使用加密技术保护数据不被篡改和盗取。
- **不可篡改**：一旦数据被记录，将无法更改。

##### 1.2 区块链的工作原理

区块链的工作原理可以分为以下几个步骤：

1. **数据采集**：将交易信息记录在区块中。
2. **区块生成**：节点通过挖矿或共识算法生成新的区块。
3. **区块验证**：其他节点验证新区块的合法性。
4. **区块添加**：将验证通过的区块添加到区块链中。

# 智能合约源代码
contract_source_code = """
pragma solidity ^0.8.0;

contract SimpleContract {
    mapping(address => uint256) public balances;

    function deposit() public payable {
        balances[msg.sender()] += msg.value;
    }

    function withdraw(uint256 amount) public {
        require(balances[msg.sender()] >= amount, "Insufficient balance");
        balances[msg.sender()] -= amount;
        payable(msg.sender()).transfer(amount);
    }
}
"""

# 部署智能合约
web3 = Web3(Web3.HTTPProvider('http://127.0.0.1:8545'))
contract = web3.eth.contract(abi=web3.eth.contract().abi_from_lifecycle bytecode=web3.eth.contract().bytecode_from_lifecycle(source=contract_source_code))
tx_hash = contract.deploy(transaction({'from': web3.eth.account[0] }))
tx = web3.eth.waitForTransaction(tx_hash)
contract_address = tx.contractAddress
