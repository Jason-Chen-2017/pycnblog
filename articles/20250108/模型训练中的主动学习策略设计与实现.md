### Introduction to Active Learning in Model Training

#### Background and Definition of Active Learning

##### 1.1.1 Origin and Development of Active Learning

Active Learning is a branch of machine learning that aims to improve learning efficiency by selectively choosing the most informative data points to be labeled. The concept was first introduced by David C. Park in the early 1980s as an alternative to passive learning, where the learner has no control over the data distribution. Since then, active learning has evolved significantly and is now recognized as a powerful tool for addressing the challenges of data scarcity and labeling cost.

The development of active learning can be traced through several key milestones. In the 1990s, research focused on the development of query strategies, such as uncertainty sampling and query-by-committee. The early 2000s saw the introduction of cost-sensitive sampling and the integration of active learning with Bayesian models. In recent years, the rapid advancement of deep learning has spurred the development of deep active learning methods, which have shown great promise in various applications.

##### 1.1.2 Core Concepts and Importance of Active Learning

The core concepts of active learning revolve around the idea of information gain and uncertainty reduction. Active learning algorithms make informed decisions about which data points to query based on the current state of the learner. This is achieved by evaluating the utility of each data point, which quantifies its potential to improve the learner's performance.

The importance of active learning lies in its ability to significantly reduce the amount of labeled data required to achieve a given level of performance. This is particularly valuable in scenarios where labeled data is scarce or expensive to obtain, such as in medical diagnosis, natural language processing, and computer vision. Active learning not only saves time and resources but also leads to more robust and generalizable models.

##### 1.1.3 Comparison with Traditional Machine Learning Approaches

Active learning differs fundamentally from traditional machine learning approaches in its interaction with the environment. In traditional machine learning, the learner is given a fixed dataset and is expected to learn from it. In contrast, active learning allows the learner to actively query the environment for new data points, making it a more dynamic and adaptable approach.

One key difference is in the data distribution. In traditional learning, the data distribution is typically assumed to be known and static. Active learning, on the other hand, deals with uncertain and evolving data distributions, making it more suitable for real-world applications where data is constantly changing.

Another difference is the role of labels. In traditional learning, all data points are labeled before training. In active learning, only a small subset of data points is labeled, with the learner making queries to obtain labels for the most informative points. This selective labeling process ensures that the learner focuses on the most relevant data, leading to more efficient learning.

#### Challenges and Opportunities in Model Training

##### 1.2.1 Common Challenges in Model Training

Model training is a complex and resource-intensive process, fraught with several challenges:

1. **Data Scarcity**: In many domains, labeled data is scarce, making it difficult to train robust models.
2. **Labeling Cost**: Obtaining high-quality labeled data can be expensive, both in terms of time and money.
3. **Data Quality**: Imperfect data quality can lead to biased or inaccurate models.
4. **Overfitting**: Models may overfit to the training data, performing poorly on unseen data.
5. **Computational Resources**: Training large models requires significant computational resources and time.

##### 1.2.2 How Active Learning Addresses These Challenges

Active learning offers several strategies to address these challenges:

1. **Reducing Data Requirements**: Active learning selectively queries the most informative data points, reducing the overall amount of labeled data needed.
2. **Optimizing Labeling Efficiency**: By focusing on the most relevant data, active learning ensures that the labeling process is efficient and cost-effective.
3. **Improving Data Quality**: Active learning can be used to iteratively refine data quality by querying for additional labels on the most uncertain or problematic data points.
4. **Preventing Overfitting**: Active learning encourages the learner to query diverse and representative data points, helping to prevent overfitting.
5. **Resource Management**: Active learning can be designed to minimize computational resources by focusing on the most critical data points.

##### 1.2.3 Current Research Trends and Applications

Current research in active learning is driven by the need to develop more efficient and effective strategies for various applications. Some of the key trends include:

1. **Deep Active Learning**: The integration of active learning with deep learning models has shown great promise in applications such as image classification and natural language processing.
2. **Transfer Learning**: Active learning strategies are being explored for transfer learning scenarios, where a model is trained on a source domain with labeled data and then adapted to a target domain with limited labeled data.
3. **Uncertainty Estimation**: The use of uncertainty estimation techniques in active learning to guide the selection of the most informative data points.
4. **Interactive Multi-Agent Systems**: The development of multi-agent active learning systems that can collaborate and communicate to improve learning efficiency.

Applications of active learning span across various domains, including medical diagnosis, fraud detection, autonomous driving, and recommendation systems.

### Core Concepts and Principles of Active Learning

#### 2.1 Core Concepts of Active Learning

##### 2.1.1 Information Theoretic Framework

The foundation of active learning lies in the information theoretic framework, which provides a mathematical basis for evaluating the utility of data points. In this framework, the learner's goal is to maximize the amount of information gained from each query. This is quantified using measures such as entropy and information gain.

Entropy is a measure of the uncertainty or randomness of a random variable. In the context of active learning, entropy is used to quantify the uncertainty in the learner's model. Higher entropy indicates higher uncertainty, suggesting that querying the data point can provide more information.

Information gain measures the reduction in entropy after a particular data point is queried. A higher information gain indicates that the data point is more informative and should be prioritized for querying.

##### 2.1.2 Query Strategy and Utility

The query strategy is the mechanism by which the learner selects the most informative data points to query. The goal of the query strategy is to maximize the utility of the queried data points, which is a measure of their potential to improve the learner's performance.

There are two main types of query strategies:

1. **Uncertainty Sampling**: This strategy queries data points based on their uncertainty, as measured by the entropy or information gain. High-entropy or high-information-gain data points are prioritized for querying.
2. **Query-by-Committee**: This strategy involves a committee of models that predict the labels of the data points. The data points with the highest disagreement among the committee members are queried, as they are most likely to provide useful information.

##### 2.1.3 Interactive and Non-Interactive Approaches

Active learning can be classified into two broad categories: interactive and non-interactive.

**Interactive Approaches** involve an interactive loop between the learner and the environment, where the learner queries the environment for labels and updates its model based on the new information. This iterative process continues until a stopping criterion is met.

**Non-Interactive Approaches**, also known as batch active learning, do not involve direct interaction with the environment. Instead, the learner queries a fixed set of data points upfront and then trains the model on the entire dataset. This approach is less resource-intensive but may not be as efficient as interactive approaches in scenarios where the data distribution evolves over time.

#### 2.2 Information Theoretic Principles

##### 2.2.1 Information Gain and Uncertainty Reduction

Information gain is a central concept in the information theoretic framework of active learning. It quantifies the reduction in uncertainty or entropy of a model after a data point is queried. Mathematically, information gain can be defined as:

$$IG(D, y) = H(D) - H(D|y)$$

where \(H(D)\) is the entropy of the data distribution, and \(H(D|y)\) is the conditional entropy of the data distribution given the labels.

High information gain indicates that querying a particular data point will significantly reduce the uncertainty in the model's predictions, making it a valuable candidate for labeling.

##### 2.2.2 Entropy and Cross-Entropy

Entropy is a measure of the uncertainty or randomness of a random variable. In the context of active learning, entropy is used to quantify the uncertainty in the learner's model. The entropy of a probability distribution \(P\) is defined as:

$$H(P) = -\sum_{i} P(i) \log P(i)$$

Cross-entropy, on the other hand, measures the difference between two probability distributions \(P\) and \(Q\). It is defined as:

$$H(P, Q) = -\sum_{i} P(i) \log Q(i)$$

In active learning, cross-entropy is often used to measure the discrepancy between the predicted labels and the true labels. A low cross-entropy value indicates that the model's predictions are close to the true labels, suggesting that the model has learned the underlying data distribution effectively.

##### 2.2.3 Information Theoretic Measures for Active Learning

Information theoretic measures are essential for designing efficient active learning strategies. Two key measures are:

1. **Mutual Information (MI)**: Mutual information quantifies the amount of information shared between two random variables. It is defined as:

$$MI(X, Y) = H(X) - H(X|Y)$$

In active learning, mutual information can be used to measure the relevance of a data point to the learner's model. High mutual information indicates that the data point is highly informative and should be prioritized for labeling.

2. **Kullback-Leibler Divergence (KLD)**: Kullback-Leibler divergence measures the difference between two probability distributions. It is defined as:

$$D_{KL}(P||Q) = \sum_{i} P(i) \log \frac{P(i)}{Q(i)}$$

In active learning, Kullback-Leibler divergence can be used to measure the discrepancy between the model's predictions and the true labels. A low KLD value indicates that the model's predictions are close to the true labels.

These information theoretic measures provide a quantitative basis for evaluating the utility of data points and designing efficient active learning strategies.

#### 2.3 Utility Functions and Optimization

##### 2.3.1 Definition and Classification of Utility Functions

A utility function is a function that quantifies the potential usefulness of a data point for the learner. The goal of an active learning algorithm is to maximize the expected utility of the queried data points. Utility functions can be classified into several categories based on their mathematical form and the information they use:

1. **Uncertainty-Based Utility Functions**: These functions quantify the uncertainty or entropy in the learner's model. The most common form is the entropy-based utility function:

$$u(x) = H(\hat{p}(x))$$

where \(\hat{p}(x)\) is the predicted probability distribution for the data point \(x\).

2. **Error-Based Utility Functions**: These functions measure the potential reduction in the error rate of the learner. The most common form is the variance-based utility function:

$$u(x) = \text{Var}(\hat{y}(x))$$

where \(\hat{y}(x)\) is the predicted label for the data point \(x\).

3. **Committee-Based Utility Functions**: These functions use the uncertainty of a committee of models to evaluate the utility of data points. The most common form is the query-by-committee utility function:

$$u(x) = 1 - \frac{1}{C}\sum_{i=1}^{C} \hat{p}_i(x)$$

where \(\hat{p}_i(x)\) is the predicted probability for the data point \(x\) by the \(i\)-th model in the committee.

4. **Cost-Sensitive Utility Functions**: These functions take into account the cost associated with labeling data points. The most common form is the cost-sensitive uncertainty sampling utility function:

$$u(x) = \frac{H(\hat{p}(x))}{c(x)}$$

where \(c(x)\) is the cost associated with labeling the data point \(x\).

##### 2.3.2 Optimization Algorithms in Active Learning

Optimizing the utility function is a key component of active learning. The goal is to find the data points that maximize the expected utility. This can be challenging due to the non-convex nature of many utility functions and the high-dimensional data spaces involved.

Several optimization algorithms have been developed for active learning:

1. **Gradient-Based Optimization**: Gradient-based optimization methods, such as gradient descent and its variants, can be used to optimize utility functions. These methods require the computation of the gradients of the utility function with respect to the model parameters. Gradient-based methods are powerful but can be sensitive to local optima and require careful tuning of hyperparameters.

2. **Heuristic Optimization**: Heuristic optimization methods, such as genetic algorithms and simulated annealing, can be used to escape local optima and find global optima. These methods do not require the computation of gradients and are more robust to the non-convex nature of utility functions.

3. **Uncertainty Sampling**: Uncertainty sampling is a simple but effective heuristic optimization method that queries the data points with the highest uncertainty. This method is often used as a baseline in active learning.

4. **Model-Based Optimization**: Model-based optimization methods use surrogate models to approximate the utility function and find optimal data points. These methods can be more efficient than direct optimization but require careful choice of the surrogate model.

##### 2.3.3 Case Studies of Utility Function Optimization

Several case studies demonstrate the effectiveness of different utility functions and optimization methods in active learning:

1. **Image Classification**: In image classification tasks, uncertainty-based and error-based utility functions have been shown to be effective. For example, in the task of object detection in images, uncertainty sampling has been used to query the most uncertain regions, leading to significant improvements in performance with a small number of labeled examples.

2. **Medical Diagnosis**: In medical diagnosis, cost-sensitive utility functions are particularly important due to the high cost of obtaining patient data. For example, in the task of cancer diagnosis, cost-sensitive uncertainty sampling has been used to reduce the number of required patient samples while maintaining high diagnostic accuracy.

3. **Natural Language Processing**: In natural language processing tasks, committee-based utility functions have been used to leverage the predictions of multiple models to select the most informative data points. For example, in the task of named entity recognition, query-by-committee has been used to improve the performance of named entity recognition models with limited labeled data.

These case studies illustrate the versatility and effectiveness of active learning strategies in various domains, highlighting the importance of choosing appropriate utility functions and optimization methods.

### Design and Implementation of Active Learning Strategies

#### 3.1 Query Strategy Design

The query strategy is a crucial component of active learning, determining which data points to query in order to maximize the learner's performance. There are several types of query strategies, each with its own strengths and weaknesses. In this section, we will discuss some common query strategies and their applications.

##### 3.1.1 Sampling Methods

Sampling methods are one of the most fundamental approaches to query strategy design. These methods select data points based on specific criteria to maximize the information gain or utility of the selected points.

**Uncertainty Sampling**

Uncertainty sampling, also known as uncertainty sampling with query-by-committee, is one of the most widely used query strategies in active learning. This method selects data points based on the uncertainty of the learner's model predictions.

The uncertainty of a data point \(x\) is typically measured using the entropy or variance of the predicted probability distribution. High-entropy or high-variance data points are more uncertain and, therefore, more informative. The uncertainty sampling utility function is defined as:

$$u(x) = H(\hat{p}(x)) = -\sum_{i} \hat{p}_i(x) \log \hat{p}_i(x)$$

where \(\hat{p}(x)\) is the predicted probability distribution for the data point \(x\).

**Certainty Sampling**

Certainty sampling is the opposite of uncertainty sampling. It selects data points with the lowest uncertainty, aiming to query the data points where the model is most confident. This strategy is less common in active learning because it may lead to overfitting and miss out on the most informative data points.

**Query-by-Committee**

Query-by-committee is a popular variant of uncertainty sampling that uses multiple models to predict the label of a data point. The idea is that if the models disagree on the label, the data point is more informative and should be queried. The utility function for query-by-committee is defined as:

$$u(x) = 1 - \frac{1}{C}\sum_{i=1}^{C} \hat{p}_i(x)$$

where \(C\) is the number of models in the committee, and \(\hat{p}_i(x)\) is the predicted probability for the data point \(x\) by the \(i\)-th model.

**Entropy Sampling**

Entropy sampling is a simple form of uncertainty sampling that directly uses the entropy of the predicted probability distribution as the utility function. It is often used as a baseline in active learning studies.

**Variance Sampling**

Variance sampling selects data points based on the variance of the predicted labels. Data points with high variance are more informative because they indicate a higher degree of uncertainty in the model's predictions. The utility function for variance sampling is defined as:

$$u(x) = \text{Var}(\hat{y}(x))$$

where \(\hat{y}(x)\) is the predicted label for the data point \(x\).

##### 3.1.2 Cost-Sensitive Sampling

In many real-world applications, the cost of labeling data points can vary significantly. For example, in medical diagnosis, obtaining a patient's medical history might be cheaper than conducting a physical examination. In such cases, it is essential to design query strategies that consider the cost of labeling when selecting data points.

**Cost-Sensitive Uncertainty Sampling**

Cost-sensitive uncertainty sampling is an extension of standard uncertainty sampling that incorporates the cost of labeling into the utility function. The utility function for cost-sensitive uncertainty sampling is defined as:

$$u(x) = \frac{H(\hat{p}(x))}{c(x)}$$

where \(c(x)\) is the cost associated with labeling the data point \(x\).

**Cost-Sensitive Query-by-Committee**

Cost-sensitive query-by-committee is similar to cost-sensitive uncertainty sampling but uses the query-by-committee framework. The utility function for cost-sensitive query-by-committee is defined as:

$$u(x) = \frac{1 - \frac{1}{C}\sum_{i=1}^{C} \hat{p}_i(x)}{c(x)}$$

**Cost-Sensitive Variance Sampling**

Cost-sensitive variance sampling is an extension of standard variance sampling that considers the cost of labeling. The utility function for cost-sensitive variance sampling is defined as:

$$u(x) = \frac{\text{Var}(\hat{y}(x))}{c(x)}$$

##### 3.1.3 Contextual Bandit Methods

Contextual bandit methods are another class of query strategies that are particularly well-suited for scenarios where the learner operates in an uncertain and dynamic environment. In contrast to traditional active learning, where the learner queries the environment for labels, contextual bandits involve making decisions based on a fixed set of actions while observing the context and the resulting rewards.

**Contextual Bandit Framework**

In a contextual bandit framework, the learner faces a sequence of tasks, each defined by a context \(c_t\) and a set of actions \(A\). The learner must choose an action \(a_t\) based on the current context and then receive a reward \(r_t\) that depends on both the action and the context. The goal of the learner is to maximize the cumulative reward over time.

**Regret Minimization**

The primary objective of contextual bandit algorithms is to minimize the cumulative regret, which is defined as the difference between the cumulative reward achieved by the learner and the maximum possible cumulative reward that could have been achieved if the optimal action had been chosen in every step.

**epsilon-Greedy**

epsilon-greedy is one of the simplest contextual bandit algorithms. It works by choosing the best action with probability \(1 - \epsilon\) and a random action with probability \(\epsilon\). The parameter \(\epsilon\) controls the balance between exploration (trying new actions) and exploitation (using the best-known action).

$$P(a_t | c_t) = \begin{cases} 
1 - \epsilon & \text{if } a_t = \arg\max_a \hat{r}_a(c_t) \\
\epsilon & \text{otherwise}
\end{cases}$$

where \(\hat{r}_a(c_t)\) is the estimated reward for action \(a\) in context \(c_t\).

**UCB (Upper Confidence Bound)**

UCB is a more sophisticated contextual bandit algorithm that uses an upper confidence bound to balance exploration and exploitation. The algorithm maintains an estimate of the mean reward for each action and a confidence interval for this estimate. The action with the highest upper confidence bound is chosen.

$$\hat{r}_a(c_t) = \frac{\sum_{i=1}^{T} r_{i,t} }{n_{a,t}} + \sqrt{\frac{2 \log T}{n_{a,t}}}$$

where \(T\) is the number of time steps, \(n_{a,t}\) is the number of times action \(a\) has been chosen in context \(c_t\), and \(r_{i,t}\) is the reward received in time step \(i\).

**Thompson Sampling**

Thompson sampling is another contextual bandit algorithm that uses Bayesian inference to balance exploration and exploitation. It works by sampling from the posterior distribution of the mean rewards for each action and choosing the action with the highest sample mean.

### Selective Sampling Methods

#### 3.2.1 Query-by-Histogram

Query-by-histogram (QbH) is an active learning strategy that utilizes a histogram-based approach to identify informative samples. The method involves constructing a histogram of model predictions, where each bin represents a range of predicted probabilities or class labels. The goal is to query samples that are either predicted with high confidence or near the decision boundary.

**Histogram Construction**

The first step in QbH is to construct a histogram of the model's predictions. This is typically done by converting the predicted probabilities into discrete bins. For example, in a binary classification problem, the predicted probabilities can be binned into several ranges, such as 0-0.1, 0.1-0.2, ..., 0.9-1.0.

**Query Selection**

Once the histogram is constructed, the next step is to identify bins with high uncertainty. These bins represent samples that the model is less confident about, which are likely to be informative. The query selection process can be based on various criteria, such as:

- Bins with the lowest average predicted probability: These bins represent samples that the model is most uncertain about.
- Bins with the highest entropy: High entropy bins indicate a high degree of uncertainty and, therefore, potential informativeness.

**Advantages and Disadvantages**

The main advantage of QbH is its simplicity and effectiveness in identifying uncertain samples. However, it may not be suitable for problems with a large number of classes or when the decision boundary is not well-defined. Additionally, QbH does not explicitly consider the cost of labeling or the distribution of samples, which can be important factors in practical scenarios.

#### 3.2.2 Diversity-Promoting Sampling

Diversity-promoting sampling (DPS) is an active learning strategy designed to select a diverse set of samples to query, aiming to improve the generalization performance of the model. The core idea is that a diverse set of samples can help the model capture a broader range of patterns in the data, leading to better performance.

**Diversity Metrics**

To promote diversity, DPS relies on diversity metrics that quantify the similarity between samples. Common diversity metrics include:

- **Jaccard Index**: Measures the similarity between two samples based on the proportion of common attributes.
- **Cosine Similarity**: Measures the similarity between two samples based on the angle between their feature vectors in a high-dimensional space.
- **Pairwise Distance**: Measures the distance between two samples in a feature space.

**Query Selection**

In DPS, the query selection process involves identifying samples that maximize the diversity metric with respect to the already labeled samples. This can be achieved through optimization algorithms that balance diversity and informativeness. The optimization problem can be formulated as follows:

minimize \(D(S_l, S_q)\)

subject to:

- \(S_q\) is a subset of the unlabeled data \(S_u\)
- \(S_l\) is the set of already labeled data

where \(D(S_l, S_q)\) is the diversity metric between \(S_l\) and \(S_q\).

**Advantages and Disadvantages**

The main advantage of DPS is its ability to improve the generalization performance of the model by ensuring a diverse set of samples. However, the diversity-promoting process can be computationally expensive, especially for large datasets. Additionally, DPS may not be suitable for problems with a small number of labeled samples, as it relies on the existence of a diverse set of labeled data.

#### 3.2.3 Ensemble-based Approaches

Ensemble-based active learning strategies leverage the power of multiple models to improve the performance of the learning algorithm. By combining the predictions of multiple models, ensemble-based approaches can provide more robust and accurate predictions, which can be particularly beneficial in scenarios with limited labeled data.

**Ensemble Methods**

There are several ensemble methods that can be used in active learning:

- **Bagging**: Bagging (Bootstrap Aggregating) involves training multiple models on different subsets of the data and then averaging their predictions. This method helps to reduce overfitting and improve the generalization performance of the ensemble.

- **Boosting**: Boosting focuses on training multiple models sequentially, where each model attempts to correct the errors made by the previous models. The predictions of all models are combined to form the final prediction. Boosting methods, such as AdaBoost and Gradient Boosting, have been shown to be highly effective in improving the performance of the ensemble.

- **Stacking**: Stacking involves training multiple base models and then training a meta-model to combine their predictions. The meta-model is trained on the predictions of the base models, allowing the ensemble to leverage the strengths of different models.

**Query-by-Committee**

Query-by-committee (QBC) is a specific ensemble-based active learning strategy that uses multiple models to make predictions and select queries. In QBC, each model in the committee predicts the label for each data point, and the committee votes on the final label. The query selection process then focuses on data points where the committee's votes are most divided, indicating uncertainty and potential informativeness.

**Utility Function**

The utility function in QBC can be defined based on the disagreement among the committee members. One common approach is to use the majority vote probability:

$$u(x) = 1 - \frac{1}{C}\sum_{i=1}^{C} \hat{p}_i(x)$$

where \(C\) is the number of models in the committee, and \(\hat{p}_i(x)\) is the predicted probability for the data point \(x\) by the \(i\)-th model.

**Advantages and Disadvantages**

The main advantage of ensemble-based approaches is their ability to improve the performance of the learning algorithm by leveraging the strengths of multiple models. However, ensemble methods can be computationally expensive, especially for large datasets and complex models. Additionally, the success of ensemble-based approaches depends on the quality and diversity of the base models, which can be challenging to achieve in practice.

### Model Selection and Validation

#### 3.3.1 Model Selection Criteria

Selecting the appropriate model for active learning is a critical step that can significantly impact the effectiveness of the learning process. Several criteria can be used to evaluate and select the best model for active learning:

**Performance on Validation Data**

The primary criterion for model selection is the performance of the model on a validation dataset. The validation dataset should be representative of the target population and should not be used for any form of training or hyperparameter tuning. The model's performance on the validation dataset can be evaluated using metrics such as accuracy, precision, recall, and F1-score. The model that achieves the highest performance on the validation dataset is typically selected for active learning.

**Generalization Ability**

In addition to performance on the validation dataset, the generalization ability of the model is also important. A model that performs well on the validation dataset but fails to generalize to new, unseen data may not be suitable for active learning. Cross-validation is a common technique used to assess the generalization ability of a model. Cross-validation involves dividing the data into multiple subsets and training and validating the model on each subset. The model's performance is averaged across all subsets to obtain an estimate of its generalization ability.

**Computation Time**

The computational complexity of the model is another important criterion for model selection. Active learning involves multiple iterations of model training and validation, so it is crucial to choose a model that can be trained and validated efficiently. Models with high computational complexity may not be suitable for active learning, especially in scenarios with limited computational resources.

**Scalability**

The scalability of the model is also a key consideration. Active learning is often used in large-scale applications where the dataset is too large to be processed by a single model. Therefore, it is important to choose a model that can be distributed across multiple machines or can leverage parallel processing to improve scalability.

**Simplicity**

Finally, the simplicity of the model is an important criterion. Simpler models are often more interpretable and easier to debug. They also tend to be more robust to overfitting and can be more efficient to train and validate.

**Model Selection Process**

The process of selecting the best model for active learning involves evaluating multiple models based on the criteria mentioned above. This can be a time-consuming process, especially when dealing with a large number of models. To streamline the process, it is common to use a grid search or random search approach. In grid search, a predefined set of hyperparameters is used to train and evaluate multiple models. In random search, a random set of hyperparameters is chosen for each model. The best model is then selected based on its performance on the validation dataset.
