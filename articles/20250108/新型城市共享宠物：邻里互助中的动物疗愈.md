    public ResponseEntity<Pet> updatePet(@PathVariable Long id, @RequestBody Pet pet) {
        return ResponseEntity.ok(petService.updatePet(id, pet));
    }

    @DeleteMapping("/pets/{id}")
    public ResponseEntity<Void> deletePet(@PathVariable Long id) {
        petService.deletePet(id);
        return ResponseEntity.status(HttpStatus.NO_CONTENT).build();
    }
}

#### 数据库操作（基于Hibernate）

```java
@Entity
@Table(name = "pets")
public class Pet {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String name;

    @Column(nullable = false)
    private String breed;

    // Getters and setters
}

@Service
public class PetService {

    @Autowired
    private PetRepository petRepository;

    public List<Pet> getAllPets() {
        return petRepository.findAll();
    }

    public Pet createPet(Pet pet) {
        return petRepository.save(pet);
    }

    public Pet getPetById(Long id) {
        return petRepository.findById(id).orElseThrow(() -> new RuntimeException("Pet not found"));
    }

    public Pet updatePet(Long id, Pet pet) {
        Pet existingPet = getPetById(id);
        existingPet.setName(pet.getName());
        existingPet.setBreed(pet.getBreed());
        return petRepository.save(existingPet);
    }

    public void deletePet(Long id) {
        Pet existingPet = getPetById(id);
        petRepository.delete(existingPet);
    }
}
```

### 实际案例分析和详细讲解

#### 案例一：创建新宠物

假设有一个用户希望通过平台创建一只新宠物。以下是具体步骤：

1. 用户在前端提交宠物信息，包括宠物的名称和品种。
2. 前端将宠物信息转换为JSON格式，并使用HTTP POST请求发送到后端API接口`/api/pets`。
3. 后端API接收请求，将JSON数据解析为`Pet`对象。
4. 后端API调用`PetService`的`createPet()`方法，将`Pet`对象保存到数据库。
5. `PetService`通过Hibernate框架与数据库交互，执行插入操作，并将新创建的宠物ID返回给前端。
6. 前端接收到新宠物的ID，更新用户界面，显示新宠物的信息。

#### 案例二：更新宠物信息

假设用户希望更新其宠物的信息，例如更改宠物的品种。以下是具体步骤：

5. `PetService`通过Hibernate框架与数据库交互，执行更新操作。
6. 前端接收到更新成功的响应，更新用户界面，显示更新后的宠物信息。
