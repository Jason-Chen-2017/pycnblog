### 第3章：数学模型和数学公式

#### 3.1 自我认知的数学模型

自我认知的数学模型旨在将复杂的心理现象转化为可量化的数学表达式，从而便于分析和理解。一个常见的自我认知数学模型是自我评价模型。该模型通过计算个体对自己的评价与实际表现之间的差距，来衡量自我认知的水平。

**自我评价模型的基本公式**：

$$
SC = \frac{E - P}{E + P}
$$

其中，$SC$ 表示自我认知水平（Self-Cognition Level），$E$ 表示个体对自己的期望（Expected Self），$P$ 表示个体的实际表现（Performance）。

**模型解释**：

- 当 $SC$ 的值为 1 时，表示个体对自己的评价与实际表现完全一致，即自我认知水平最高。
- 当 $SC$ 的值为 -1 时，表示个体对自己的评价与实际表现完全相反，即自我认知水平最低。
- 当 $SC$ 的值为 0 时，表示个体对自己的评价与实际表现没有差距，即自我认知水平中等。

**实际应用**：

假设一个学生在考试前的期望得分是 90 分，而实际得分是 85 分。根据自我评价模型，可以计算其自我认知水平：

$$
SC = \frac{90 - 85}{90 + 85} = \frac{5}{175} = \frac{1}{35} \approx 0.0286
$$

这意味着该学生的自我认知水平较高，他对自己有较为合理的期望，并且能够较为准确地评估自己的实际表现。

#### 3.2 数学公式的讲解与举例

除了自我评价模型，自我认知还可以通过其他数学公式进行量化和分析。以下是一些常见的数学公式及其应用：

**1. 自我效能感模型（Self-Efficacy Model）**：

$$
SE = \frac{TPR + TNR}{TPR + FPR + TNR + FNR}
$$

其中，$SE$ 表示自我效能感（Self-Efficacy），$TPR$ 表示真阳性率（True Positive Rate），$TNR$ 表示真阴性率（True Negative Rate），$FPR$ 表示假阳性率（False Positive Rate），$FNR$ 表示假阴性率（False Negative Rate）。

**模型解释**：

- 自我效能感是衡量个体对自己能否成功完成特定任务的信心。
- 真阳性率和真阴性率反映了个体在自我效能感评估中的准确性。
- 通过计算自我效能感，个体可以更好地了解自己的信心水平。

**实际应用**：

假设一个运动员的自我效能感评估如下：

- 真阳性率：80%
- 真阴性率：60%
- 假阳性率：20%
- 假阴性率：10%

根据自我效能感模型，可以计算其自我效能感：

$$
SE = \frac{0.8 + 0.6}{0.8 + 0.2 + 0.6 + 0.1} = \frac{1.4}{2.1} \approx 0.667
$$

这意味着该运动员的自我效能感较高，他对自己的运动表现有较高的信心。

**2. 负面情绪指数模型（Negative Emotion Index Model）**：

$$
NEI = \frac{N}{N + P}
$$

其中，$NEI$ 表示负面情绪指数（Negative Emotion Index），$N$ 表示负面情绪的频率（Negative Emotions Frequency），$P$ 表示正面情绪的频率（Positive Emotions Frequency）。

**模型解释**：

- 负面情绪指数反映了个体在一段时间内负面情绪的占比。
- 通过计算负面情绪指数，个体可以了解自己的情绪状态。

**实际应用**：

假设一个员工在一个月内记录了如下情绪频率：

- 负面情绪频率：15次
- 正面情绪频率：35次

根据负面情绪指数模型，可以计算其负面情绪指数：

$$
NEI = \frac{15}{15 + 35} = \frac{15}{50} = 0.3
$$

这意味着该员工的负面情绪指数为 30%，说明其情绪状态较为稳定。

通过以上数学模型和公式的讲解，我们可以更科学地分析和理解自我认知的过程。这些模型和公式不仅有助于个体自我评估，还可以为心理健康专业人士提供诊断和治疗的依据。

```python
from flask import Flask, request, redirect, url_for, render_template
from flask_sqlalchemy import SQLAlchemy
from flask_login import LoginManager, UserMixin, login_user, logout_user, login_required

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///users.db'
app.config['SECRET_KEY'] = 'your_secret_key'

db = SQLAlchemy(app)
login_manager = LoginManager(app)

class User(UserMixin, db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(100), unique=True, nullable=False)
    password = db.Column(db.String(100), nullable=False)

@login_manager.user_loader
def load_user(user_id):
    return User.query.get(int(user_id))

@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        username = request.form['username']
        password = request.form['password']
        user = User.query.filter_by(username=username).first()
        if user and user.password == password:
            login_user(user)
            return redirect(url_for('dashboard'))
        return 'Invalid credentials'
    return render_template('login.html')

@app.route('/logout')
def logout():
    logout_user()
    return redirect(url_for('login'))

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```
