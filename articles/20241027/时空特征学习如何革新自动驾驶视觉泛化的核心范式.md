#### 2.1 时空卷积神经网络（ST-CNN）

时空卷积神经网络（ST-CNN）是基于卷积神经网络（CNN）的一种扩展，它能够同时处理时间和空间维度上的特征信息。ST-CNN通过卷积操作提取图像序列中的时空特征，具有强大的特征提取能力。

##### 2.1.1 ST-CNN的架构与原理

ST-CNN的架构主要包括以下几个部分：

1. **时空特征提取层**：该层通过卷积操作提取图像序列中的时空特征。时空特征提取层通常包括多个卷积核，每个卷积核都能够提取不同的时空特征。
2. **池化层**：池化层用于降低特征图的维度，减少计算复杂度。常用的池化方法包括最大池化和平均池化。
3. **激活函数层**：激活函数层用于引入非线性特性，增强模型的表达能力。常用的激活函数包括ReLU函数和Sigmoid函数。
4. **全连接层**：全连接层用于将时空特征映射到具体的任务输出，如行人检测、车辆分类等。

ST-CNN的工作原理是通过卷积操作从图像序列中提取时空特征，然后通过池化和激活函数处理这些特征，最后通过全连接层得到任务输出。其伪代码实现如下：

```python
def st_cnn(input_sequence):
    # 输入：图像序列，维度为（T, H, W, C）
    # 输出：时空特征图，维度为（T', H', W', C'）
    
    # 时空特征提取层
    conv1 = conv2d(input_sequence, filters=32, kernel_size=(3, 3), stride=(1, 1))
    pool1 = max_pooling(conv1, pool_size=(2, 2))
    
    # 激活函数层
    relu1 = activation(pool1, activation_function='ReLU')
    
    # 时空特征提取层
    conv2 = conv2d(relu1, filters=64, kernel_size=(3, 3), stride=(1, 1))
    pool2 = max_pooling(conv2, pool_size=(2, 2))
    
    # 激活函数层
    relu2 = activation(pool2, activation_function='ReLU')
    
    # 全连接层
    output = fully_connected(relu2, units=num_classes)
    
    return output
```

#### 2.2 时空循环神经网络（ST-RNN）

时空循环神经网络（ST-RNN）是基于循环神经网络（RNN）的一种扩展，它通过循环结构处理图像序列中的时空特征，能够捕捉到时间序列中的长期依赖关系。

##### 2.2.1 ST-RNN的架构与原理

ST-RNN的架构主要包括以下几个部分：

1. **输入层**：输入层接收图像序列作为输入，图像序列的维度为（T, H, W, C），其中T表示时间步数，H、W、C分别表示图像的高度、宽度和通道数。
2. **隐藏层**：隐藏层包含一个或多个循环单元，每个循环单元都包含一个门控单元（gate unit）和一个线性变换单元。门控单元用于控制信息的传递，线性变换单元用于更新隐藏状态。
3. **输出层**：输出层将隐藏状态映射到具体的任务输出，如行人检测、车辆分类等。

ST-RNN的工作原理是通过循环结构处理图像序列中的时空特征，更新隐藏状态，并最终得到任务输出。其伪代码实现如下：

```python
def st_rnn(input_sequence):
    # 输入：图像序列，维度为（T, H, W, C）
    # 输出：隐藏状态序列，维度为（T, H', W', C'）
    
    # 初始化隐藏状态
    hidden_state = zeros((T, hidden_size))
    
    # 遍历时间步
    for t in range(T):
        # 获取当前时间步的输入
        input_t = input_sequence[t]
        
        # 通过门控单元更新隐藏状态
        hidden_state[t] = gate_unit(hidden_state[t-1], input_t)
        
        # 通过线性变换单元更新隐藏状态
        hidden_state[t] = linear_transform(hidden_state[t])
        
    # 输出隐藏状态序列
    return hidden_state
```

import torchvision.transforms as transforms
from torch.utils.data import DataLoader
from torchvision.datasets import ImageFolder

# 数据预处理
transform = transforms.Compose([
    transforms.Resize((224, 224)),  # 将图像调整为固定大小
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

# 加载数据
train_dataset = ImageFolder(root='train_data', transform=transform)
val_dataset = ImageFolder(root='val_data', transform=transform)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=64, shuffle=False)

# 定义模型
class STCNNSeg(nn.Module):
    def __init__(self):
        super(STCNNSeg, self).__init__()
        self.conv1 = nn.Conv2d(3, 64, 3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.conv2 = nn.Conv2d(64, 128, 3, padding=1)
        self.fc1 = nn.Linear(128 * 56 * 56, 1024)
