## 第1章：组合结构与枚举基础

### 1.1 组合与枚举的基本概念

#### 1.1.1 组合的定义及特点

组合是指在给定n个不同元素中，取出m（m≤n）个元素进行排列的情况。组合的数学表示方法为$C_n^k = \frac{n!}{k!(n-k)!}$。

- **组合的特点**：
  - 无顺序依赖，即排列中的顺序不重要。
  - 组合数是整数，不会出现小数。

#### 1.1.2 枚举的定义及特点

枚举是一种通过列举所有可能的情况来解决问题的方法。

- **枚举的特点**：
  - 可以用于求解组合问题。
  - 可以用于搜索问题。
  - 可以用于决策问题。

### 1.2 组合与枚举的应用场景

#### 1.2.1 组合的应用场景

- **分组**：将一组元素按照一定规则进行分组。
- **选择**：从一组元素中选择若干个元素。
- **排列组合**：计算从一组元素中取出若干个元素的所有可能组合。

#### 1.2.2 枚举的应用场景

- **排查**：通过遍历所有可能性来排查问题。
- **搜索**：在所有可能的情况中寻找目标。
- **决策**：根据所有可能的结果来做出最优决策。

### 1.3 组合与枚举的基本方法

#### 1.3.1 组合的基本方法

- **排列组合**：计算从n个不同元素中，取出m个元素的排列组合数。
- **子集枚举**：列举一个集合的所有子集。
- **背包问题**：在限制条件下，选择若干个元素以最大化总价值。

#### 1.3.2 枚举的基本方法

- **暴力枚举**：直接遍历所有可能的情况。
- **状态压缩**：将状态进行压缩以减少空间复杂度。
- **动态规划**：将大问题分解为小问题，避免重复计算。

### 1.4 组合结构与枚举的联系与区别

- **联系**：
  - 组合与枚举都可以用于解决分类问题。
  - 枚举是组合的扩展，组合是枚举的一个特例。

- **区别**：
  - 组合关注组合的个数，而枚举关注具体的每一种组合。
  - 枚举通常比组合更复杂，因为枚举需要考虑顺序。

### 1.5 组合结构与枚举在计算机科学中的应用

- **组合结构**：
  - 在设计模式中，如单例模式、策略模式、模板方法模式等。
  - 在数据结构中，如二叉树、图等。

- **枚举**：
  - 在编程中，用于定义常量、类型等。
  - 在算法中，用于状态压缩、动态规划等。

## 第2章：组合结构设计模式

### 2.1 单例模式

单例模式是一种设计模式，用于确保一个类只有一个实例，并提供一个全局访问点。

#### 2.1.1 单例模式的概念

- **单例模式**：确保一个类只有一个实例，并提供一个访问它的全局访问点。
- **优点**：
  - 简化了资源的访问。
  - 避免了创建多个实例带来的资源浪费。

#### 2.1.2 单例模式的实现

- **饿汉式**：在类加载时，就创建实例。
- **懒汉式**：在第一次使用时，才创建实例。
- **双重检查锁**：结合懒汉式和同步机制，保证线程安全。

```java
// 饿汉式
public class Singleton {
    private static Singleton instance = new Singleton();
    
    private Singleton() {
    }
    
    public static Singleton getInstance() {
        return instance;
    }
}

// 懒汉式
public class Singleton {
    private static Singleton instance;
    
    private Singleton() {
    }
    
    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

#### 2.1.3 单例模式的应用场景

- **资源管理**：如数据库连接、网络连接等。
- **控制全局状态**：如游戏中的玩家状态管理。

### 2.2 策略模式

策略模式是一种设计模式，它定义了一系列的算法策略，将每个算法策略封装起来，并使它们可以相互替换。

#### 2.2.1 策略模式的概念

- **策略模式**：定义一系列算法策略，将每个算法策略封装起来，并使它们可以相互替换。
- **优点**：
  - 提高代码的复用性。
  - 简化算法的替换和扩展。

#### 2.2.2 策略模式的实现

- **策略接口**：定义一个策略接口，包含所有算法策略的公共方法。
- **具体策略类**：实现策略接口，定义具体的算法策略。
- **策略环境类**：使用策略接口，根据需要切换不同的策略。

```java
// 策略接口
public interface Strategy {
    void execute();
}

// 具体策略类
public class ConcreteStrategyA implements Strategy {
    @Override
    public void execute() {
        // 策略A的实现
    }
}

public class ConcreteStrategyB implements Strategy {
    @Override
    public void execute() {
        // 策略B的实现
    }
}

// 策略环境类
public class Context {
    private Strategy strategy;

    public Context(Strategy strategy) {
        this.strategy = strategy;
    }

    public void setStrategy(Strategy strategy) {
        this.strategy = strategy;
    }

    public void executeStrategy() {
        strategy.execute();
    }
}
```

#### 2.2.3 策略模式的应用场景

- **算法策略的替换**：如排序算法的选择。
- **行为策略的替换**：如支付方式的替换。

### 2.3 模板方法模式

模板方法模式是一种设计模式，它定义一个操作中的算法的骨架，而将一些步骤延迟到子类中。

#### 2.3.1 模板方法模式的概念

- **模板方法模式**：定义一个操作中的算法的骨架，而将一些步骤延迟到子类中。
- **优点**：
  - 提高代码的复用性。
  - 简化子类的编写。

#### 2.3.2 模板方法模式的实现

- **抽象类**：定义一个模板方法，包含所有步骤的抽象方法。
- **具体子类**：实现模板方法，定义具体的步骤。

```java
// 抽象类
public abstract class AbstractClass {
    public void templateMethod() {
        primitiveOperation1();
        primitiveOperation2();
        // 留给子类实现的方法
        methodToOverride();
    }

    public void primitiveOperation1() {
        // 基本操作1
    }

    public void primitiveOperation2() {
        // 基本操作2
    }

    protected abstract void methodToOverride();
}

// 具体子类
public class ConcreteClassA extends AbstractClass {
    @Override
    protected void methodToOverride() {
        // 子类实现的方法A
    }
}

public class ConcreteClassB extends AbstractClass {
    @Override
    protected void methodToOverride() {
        // 子类实现的方法B
    }
}
```

#### 2.3.3 模板方法模式的应用场景

- **算法模板**：如排序算法的模板。
- **业务流程**：如订单处理流程。

```java
public class StateMachine {

}
```

## 第4章：经典组合问题

### 4.1 子集问题

子集问题是一个组合问题，涉及到从一个集合中获取所有可能的子集。

#### 4.1.1 子集问题的概念

子集是指一个集合的所有元素的部分组合。

#### 4.1.2 子集问题的算法

- **递归算法**：

```java
public void subsets(List<List<Integer>> res, List<Integer> tempList, int[] nums) {
    res.add(new ArrayList<>(tempList));
    for (int i = 0; i < nums.length; i++) {
        tempList.add(nums[i]);
        subsets(res, tempList, nums);
        tempList.remove(tempList.size() - 1);
    }
}
```

- **回溯算法**：

```java
public void subsets(List<List<Integer>> res, List<Integer> tempList, int[] nums) {
    res.add(new ArrayList<>(tempList));
    for (int i = 0; i < nums.length; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        tempList.add(nums[i]);
        subsets(res, tempList, nums);
        tempList.remove(tempList.size() - 1);
    }
}
```

### 4.2 排列问题

排列问题是一个从一组元素中取出部分元素并按一定顺序排列的问题。

#### 4.2.1 排列问题的概念

排列是指从一组元素中取出部分元素并按照一定的顺序排列。

#### 4.2.2 排列问题的算法

- **递归算法**：

```java
public void permute(int[] nums, int start, List<List<Integer>> res) {
    if (start == nums.length) {
        List<Integer> temp = new ArrayList<>();
        for (int num : nums) {
            temp.add(num);
        }
        res.add(new ArrayList<>(temp));
        return;
    }
    for (int i = start; i < nums.length; i++) {
        swap(nums, start, i);
        permute(nums, start + 1, res);
        swap(nums, start, i);
    }
}

private void swap(int[] nums, int i, int j) {
    int temp = nums[i];
    nums[i] = nums[j];
    nums[j] = temp;
}
```

### 4.3 组合问题

组合问题是一个从一组元素中取出若干元素的问题，元素可以有重复。

#### 4.3.1 组合问题的概念

组合问题是指在给定一组元素中，取出若干个元素进行组合的问题。

#### 4.3.2 组合问题的算法

- **递归算法**：

```java
public void combine(int[] candidates, int target, List<List<Integer>> res, int start, List<Integer> tempList) {
    if (target == 0) {
        res.add(new ArrayList<>(tempList));
        return;
    }
    for (int i = start; i < candidates.length; i++) {
        if (i > start && candidates[i] == candidates[i - 1]) {
            continue;
        }
        if (candidates[i] > target) {
            break;
        }
        tempList.add(candidates[i]);
        combine(candidates, target - candidates[i], res, i + 1, tempList);
        tempList.remove(tempList.size() - 1);
    }
}
```

## 第5章：经典枚举问题

### 5.1 枚举搜索问题

枚举搜索问题是一个通过遍历所有可能的情况来找到目标的问题。

#### 5.1.1 枚举搜索问题的概念

枚举搜索是指通过遍历所有可能的情况来找到目标元素。

#### 5.1.2 枚举搜索问题的算法

- **暴力枚举算法**：

```java
public boolean search(int[] nums, int target) {
    for (int num : nums) {
        if (num == target) {
            return true;
        }
    }
    return false;
}
```

- **状态压缩算法**：

```java
public boolean search(int[] nums, int target) {
    int n = nums.length;
    int mask = 0;
    for (int i = 0; i < n; i++) {
        mask |= (nums[i] == target ? 1 : 0) << i;
    }
    return (mask & (mask - 1)) == 0;
}
```

### 5.2 背包问题

背包问题是一个在给定的物品和价值下，如何选择物品以最大化价值的问题。

```java
public int knapsack(int[] weights, int[] values, int W) {
    int n = weights.length;
    int[][] dp = new int[n + 1][W + 1];
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= W; j++) {
            if (j >= weights[i - 1]) {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - weights[i - 1]] + values[i - 1]);
            } else {
                dp[i][j] = dp[i - 1][j];
            }
        }
    }
    return dp[n][W];
}
```

```java
public int solve(int[] nums) {
    int n = nums.length;
    int mask = 0;
    for (int i = 0; i < n; i++) {
        mask |= (1 << nums[i]);
    }
    int[] dp = new int[mask + 1];
    for (int i = 1; i <= mask; i++) {
        dp[i] = i >> 1;
        for (int j = 0; j < n; j++) {
            if (((i >> nums[j]) & 1) == 1) {
                dp[i] = Math.min(dp[i], dp[i ^ (1 << nums[j])]);
            }
        }
    }
    return dp[mask];
}
```

```java
public int coinChange(int[] coins, int amount) {
    Arrays.sort(coins);
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, Integer.MAX_VALUE);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int j = 0; j < coins.length; j++) {
            if (coins[j] <= i) {
                if (dp[i - coins[j]] != Integer.MAX_VALUE) {
                    dp[i] = Math.min(dp[i], dp[i - coins[j]] + 1);
                }
            } else {
                break;
            }
        }
    }
    return dp[amount] == Integer.MAX_VALUE ? -1 : dp[amount];
}
```

```java
public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(res, new ArrayList<>(), 1, n, k);
    return res;
}

private void backtrack(List<List<Integer>> res, List<Integer> tempList, int start, int n, int k) {
    if (tempList.size() == k) {
        res.add(new ArrayList<>(tempList));
        return;
    }
    for (int i = start; i <= n; i++) {
        tempList.add(i);
        backtrack(res, tempList, i + 1, n, k);
        tempList.remove(tempList.size() - 1);
    }
}
```
