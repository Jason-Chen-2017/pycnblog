# 第一部分: 格雷厄姆特价股票策略的背景与基础

## 第1章: 价值投资策略的起源与发展

### 1.1 格雷厄姆投资理论的起源

格雷厄姆的价值投资理论起源于20世纪30年代，他在《证券分析》一书中提出了“安全边际”和“内在价值”的概念。他认为，股票价格经常偏离其内在价值，投资者应寻找被市场低估的股票进行长期投资。

#### 格雷厄姆的投资哲学

格雷厄姆强调：
1. **安全边际**：买入价格低于内在价值的股票，以降低风险。
2. **长期视角**：关注企业的基本面，而非短期市场波动。
3. **逆周期投资**：在市场低迷时寻找低估股票。

#### 价值投资与现代投资理论的对比

| 理论 | 格雷厄姆价值投资 | 现代投资组合理论 |
|------|------------------|------------------|
| 核心 | 内在价值与安全边际 | 分散投资与风险调整收益 |
| 方法 | 选股基于低估 | 通过资产配置优化收益 |
| 目标 | 长期稳定收益 | 追求超额收益 |

## 第2章: 格雷厄姆特价股票策略的核心概念

### 2.1 价值投资的核心要素

#### 内在价值的计算

**公式**：  
$$ V = \frac{E}{k} $$  
其中，\( V \) 为内在价值，\( E \) 为企业未来现金流的现值，\( k \) 为折现率。

#### 安全边际

安全边际 = 内在价值 - 市场价格。

## 第3章: 不同规模经济体的经济特点

### 3.1 不同经济体的市场结构

#### 发达经济体

- **市场特点**：流动性高，监管严格，企业透明度高。
- **例子**：美国、英国、日本。

#### 新兴经济体

- **市场特点**：增长快，波动大，监管相对宽松。
- **例子**：中国、印度。

#### 转型经济体

- **市场特点**：经济结构调整，政策变化频繁。
- **例子**：俄罗斯、巴西。

### 3.2 经济周期对股票市场的影响

#### 经济周期的阶段划分

1. **衰退期**：企业盈利下降，股票价格波动。
2. **复苏期**：经济逐渐恢复，价值股表现较好。
3. **过热期**：通胀上升，市场波动加剧。
4. **滞胀期**：经济增长停滞，通胀上升，价值股表现不佳。

### 7.2 核心代码实现

```python
import pandas as pd
import yfinance as yf

def get_data(ticker):
    data = yf.download(ticker, start='2020-01-01', end='2023-12-31')
    return data['Adj Close']
```

#### 内在价值计算

```python
def calculate_intrinsic_value(eps, growth_rate, required_return):
    return eps * (1 + growth_rate) / required_return
```

### 7.3 代码解读与分析

#### 筛选股票逻辑

```python
tickers = ['AAPL', 'MSFT', 'GOOGL']
for ticker in tickers:
    data = get_data(ticker)
    eps = data['eps']
    iv = calculate_intrinsic_value(eps, 0.05, 0.1)
    margin = iv - data['price']
    if margin > 0:
        print(f"{ticker} is undervalued with margin {margin}")
```
