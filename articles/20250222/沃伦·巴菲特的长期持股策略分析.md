## 第2章: 长期持股策略的数学模型与算法原理

### 2.1 投资组合优化的数学模型

#### 2.1.1 投资组合优化的数学公式
最大化收益和最小化风险的目标函数：
$$
\text{目标函数：} \quad \max \left( \sum_{i=1}^{n} w_i r_i - \lambda \sum_{i=1}^{n} w_i^2 \right)
$$

#### 2.1.2 投资组合优化的约束条件
权重之和为1：
$$
\sum_{i=1}^{n} w_i = 1
$$

### 2.2 风险与收益的平衡算法

#### 2.2.1 风险调整后的收益计算公式
夏普比率：
$$
\text{夏普比率 } = \frac{E[r - r_f]}{\sigma}
$$

#### 2.2.2 马科维茨均值-方差模型
最小方差组合：
$$
\text{再平衡权重 } = \frac{\text{当前权重}}{\text{目标权重}}
$$

### 2.3 投资组合再平衡算法

#### 2.3.1 投资组合再平衡的步骤
1. 计算当前权重
2. 对比目标权重
3. 调整权重

### 4.2 项目核心实现

#### 4.2.1 系统核心实现源代码
```python
import pandas as pd
import numpy as np

# 示例数据：股票财务指标
data = {
    '股票': ['AAPL', 'MSFT', 'GOOGL'],
    '市盈率': [15, 16, 20],
    'ROE': [25, 18, 22],
    '收入增长率': [8, 6, 7]
}
df = pd.DataFrame(data)

# 计算价值评分
def calculate_score(row):
    score = row['市盈率'] * 0.3 + row['ROE'] * 0.4 + row['收入增长率'] * 0.3
    return score

df['价值评分'] = df.apply(calculate_score, axis=1)
print(df)
```

#### 4.2.2 代码应用解读与分析
根据财务指标计算价值评分，选择高评分企业。
