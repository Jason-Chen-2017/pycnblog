## 第1章: 引言

### 1.1 资源稀缺性的背景与重要性

#### 1.1.1 资源稀缺性的定义
资源稀缺性指的是地球上可利用的自然资源（如石油、天然气、矿产、水资源等）的有限性，随着人类需求的增加，这些资源的供应可能无法满足未来的需求，从而导致价格波动和市场不确定性。

#### 1.1.2 资源稀缺性与经济发展的关系
资源是经济活动的基础，稀缺性会直接影响生产成本、产品价格和市场供给。当某种资源变得稀缺时，其价格通常会上涨，从而影响整个产业链和经济结构。

#### 1.1.3 格兰瑟姆理论的核心贡献
杰里米·格兰瑟姆在他的著作《The New Depression》中提出，资源稀缺性是导致经济周期波动的重要因素。他认为，资源的有限性会导致通胀压力和资产价格波动，从而影响投资决策。

#### 2.3.2 资源稀缺性对投资策略的影响
稀缺资源的投资价值通常较高，投资者应关注这些资源的供应和需求变化。

import numpy as np

def resource_scarcity_index(supply, demand):
    return np.where(demand > supply, (demand - supply)/supply, 0)

supply = np.array([100, 200, 150])
demand = np.array([150, 250, 180])

scarcity_index = resource_scarcity_index(supply, demand)
print("Scarcity Index:", scarcity_index)
