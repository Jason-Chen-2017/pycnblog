## 第1章：引言

## 第2章：核心概念

### 2.1 格雷厄姆投资理论

格雷厄姆策略的核心在于寻找被市场低估的股票，主要通过市盈率（P/E）和市净率（P/B）等指标筛选。以下是两种指标的计算公式：

- 市盈率（P/E）= 股价 / 每股收益
- 市净率（P/B）= 股价 / 每股净资产

### 2.2 市场流动性周期

市场流动性周期分为牛市、熊市和震荡市。流动性对股票估值的影响如下：

- **牛市**：流动性充裕，股票估值上升。
- **熊市**：流动性下降，股票估值被压低。
- **震荡市**：流动性波动，股票估值波动加剧。

## 第3章：数学模型与算法

### 3.1 量化分析模型

构建流动性指数（LI）：

$$ LI = \alpha \times (1 - P/E) + \beta \times (1 - P/B) $$

其中，$\alpha$ 和 $\beta$ 是权重系数。

### 3.2 动态调整算法

1. **数据采集**：收集历史数据，包括价格、成交量等。
2. **计算流动性指数**：使用上述公式计算LI。
3. **策略调整**：根据LI值调整筛选标准，如动态调整市盈率和市净率的阈值。

### 4.2 代码实现

以下是Python代码示例：

```python
import pandas as pd
import numpy as np

# 数据采集
data = pd.read_csv('stock_data.csv')

# 计算流动性指数
def calculate_li(pe, pb):
    return 0.5 * (1 - pe) + 0.5 * (1 - pb)

data['LI'] = calculate_li(data['PE'], data['PB'])

# 动态调整策略
threshold = np.percentile(data['LI'], 20)
data['select'] = data['LI'] > threshold
```
