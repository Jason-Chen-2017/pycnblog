## 第一部分: 认知偏差与投资心理学基础

### 第1章: 认知偏差的基本概念

#### 1.1 认知偏差的定义与分类

认知偏差是指人在信息处理和决策过程中，由于主观因素的影响，导致偏离客观事实的系统性偏差。认知偏差可以分为以下几类：

- **确认偏差**：倾向于寻找支持已有观点的信息，忽略相反证据。
- **从众心理**：由于社会压力，盲目跟随群体决策。
- **过度自信**：过高估计自己的判断能力，忽视不确定性。

#### 1.2 投资中的心理陷阱

在投资领域，认知偏差常常导致投资者做出非理性的决策。例如：

- **确认偏差**：投资者倾向于寻找支持自己投资决策的信息，忽视潜在风险。
- **从众心理**：盲目跟随市场趋势，导致追涨杀跌。
- **过度自信**：过度依赖自己的判断，忽视外部环境变化。

#### 1.3 芒格投资哲学中的认知偏差视角

芒格强调价值投资的核心在于避免认知偏差的影响。他认为，投资者应通过长期学习和理性分析，克服心理陷阱，做出明智的投资决策。

#### 4.1 确认偏差的算法实现

```python
def confirm_bias_analysis(data):
    # 计算支持和反对证据的比例
    support = sum(1 for d in data if d > 0)
    oppose = len(data) - support
    return support / (support + oppose)
```

```python
    import pandas as pd
    # 数据预处理
    df = pd.DataFrame(data)
```
