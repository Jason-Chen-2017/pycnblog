- **代码示例：内在价值计算**

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(financial_data, discount_rate):
    """
    计算企业的内在价值，使用DCF模型。
    financial_data: 包含企业财务数据的DataFrame。
    discount_rate: 折现率。
    """
    # 提取自由现金流
    free_cash_flow = financial_data['free_cash_flow'].iloc[-1]
    # 计算永续增长率
    perpetual_growth_rate = financial_data['perpetual_growth_rate'].iloc[-1]
    # 计算终端价值
    terminal_value = free_cash_flow / (1 + perpetual_growth_rate)
    # 计算DCF估值
    dcf_valuation = terminal_value * (1 + discount_rate) ** (-1)
    return dcf_valuation
```
