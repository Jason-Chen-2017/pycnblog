# 第1章: 价值投资与格林布拉特方法概述

## 1.1 价值投资的基本概念  
### 1.1.1 价值投资的定义  
价值投资是一种投资策略，强调以低于内在价值的价格购买优质资产。其核心在于识别市场低估的公司，并长期持有，等待其价值回归。  

### 1.1.2 价值投资的核心理念  
- 市场先生理论：市场情绪波动导致价格与价值分离。  
- 安全边际：买入价格低于内在价值，以降低风险并提高安全边际。  

### 1.1.3 格林布拉特方法的起源  
乔尔·格林布拉特是将价值投资与量化分析结合的先驱。他在《 stocks for the long run》中提出了一套量化筛选模型，强调通过基本面指标筛选低估股票。  

---

## 1.2 格林布拉特方法的基本框架  
### 1.2.1 格林布拉特方法的简介  
格林布拉特的方法基于以下核心假设：  
- 股票的内在价值可以通过基本面指标估算。  
- 市场波动为投资者提供了以低于内在价值买入股票的机会。  

### 1.2.2 方法的核心思想  
- 通过量化指标筛选具有吸引力的股票。  
- 结合估值指标和质量指标，构建多因子模型。  

### 1.2.3 方法的适用场景  
- 长期投资策略。  
- 理性分析驱动的投资决策。

# 第2章: 核心概念与联系

## 2.1 核心概念与模型  
### 2.1.1 格林布拉特模型的定义  
格林布拉特模型通过量化指标筛选股票，主要基于以下指标：  
- 市盈率（P/E）。  
- 市净率（P/B）。  
- 股息率。  

### 2.1.2 模型的输入变量  
- 财务数据：收入、利润、资产等。  
- 市场数据：股价、成交量等。  

### 2.1.3 模型的输出结果  
- 股票的内在价值估算。  
- 买入信号与卖出信号。  

---

## 2.2 核心概念属性对比  
### 2.2.1 财务指标对比表  

| 指标类型 | 指标名称 | 计算公式 | 核心作用 |
|----------|----------|----------|----------|
| 资产 | 总资产 | 资产总计 | 衡量公司规模 |
| 利润 | 净利润 | 净利润 | 衡量盈利能力 |
| 估值 | 市盈率 | P/E = 价格/每股收益 | 衡量估值水平 |

### 2.2.2 估值方法对比表  

| 估值方法 | 描述 | 优点 | 缺点 |
|----------|------|------|------|
| 市盈率法 | 基于P/E比值 | 简单易用 | 不适用于亏损公司 |
| 市净率法 | 基于P/B比值 | 适用于银行等资产密集型行业 | 低估成长型企业 |

### 2.2.3 风险评估对比表  

| 风险指标 | 描述 | 计算公式 | 作用 |
|----------|------|----------|------|
| 贝塔值 | 股票波动性 | β = 协方差(股票收益率, 市场收益率) / 方差(市场收益率) | 衡量市场风险 |
| 夏普比率 | 风险调整后的收益 | Sharpe Ratio = (收益 - 无风险利率) / 标准差 | 衡量风险调整收益 |

## 3.2 算法实现代码  

```python
import pandas as pd

def calculate_value_signals(df):
    # 计算市盈率
    df['pe'] = df['price'] / df['eps']
    # 计算市净率
    df['pb'] = df['price'] / df['book_value_per_share']
    # 计算股息率
    df['dividend_yield'] = df['dividends'] / df['price']
    # 生成买入信号
    df['buy_signal'] = (df['pe'] < 15) & (df['pb'] < 2) & (df['dividend_yield'] > 3)
    # 生成卖出信号
    df['sell_signal'] = df['pe'] > 25
    return df

# 示例数据
data = {
    'price': [50, 60, 70],
    'eps': [10, 15, 20],
    'book_value_per_share': [5, 6, 7],
    'dividends': [2, 3, 4]
}
df = pd.DataFrame(data)
result = calculate_value_signals(df)
print(result)
```

## 3.3 数学模型与公式  
格林布拉特模型的核心公式为：  

$$ \text{内在价值} = \text{净利润} \times (1 + g) / (r - g) $$  

其中，$g$ 是净利润增长率，$r$ 是折现率。

### 5.2.2 算法实现代码  

```python
import pandas as pd
import numpy as np

def calculate_signals(data):
    # 计算市盈率
    pe = data['price'] / data['eps']
    # 计算市净率
    pb = data['price'] / data['book_value']
    # 计算股息率
    dividend_yield = data['dividends'] / data['price']
    # 生成买入信号
    buy_signal = (pe < 15) & (pb < 2) & (dividend_yield > 3)
    # 生成卖出信号
    sell_signal = pe > 25
    return buy_signal, sell_signal

# 示例数据
data = {
    'price': [50, 60, 70],
    'eps': [10, 15, 20],
    'book_value': [5, 6, 7],
    'dividends': [2, 3, 4]
}
df = pd.DataFrame(data)
buy, sell = calculate_signals(df)
print("Buy Signal:", buy)
print("Sell Signal:", sell)
```
