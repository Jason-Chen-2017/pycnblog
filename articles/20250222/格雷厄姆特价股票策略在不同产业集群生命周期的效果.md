## 第一部分：背景介绍

### 第1章：格雷厄姆特价股票策略概述

#### 1.1 格雷厄姆投资理论的核心概念

- **价值投资**：寻找市场低估的股票，长期持有，等待价值回归。
- **特价股票**：市盈率和市净率低于行业平均水平的股票。
- **安全边际**：以低于内在价值的价格买入股票，降低风险。

#### 1.2 产业集群生命周期的概念

- **产业集群**：相关企业在地理和产业上的集中，如硅谷的科技企业集群。
- **生命周期阶段**：导入期、成长期、成熟期、衰退期。
- **阶段特征**：
  - 导入期：技术创新，市场拓展。
  - 成长期：市场需求增长，企业扩张。
  - 成熟期：市场饱和，竞争加剧。
  - 衰退期：技术落后，需求下降。

## 第二部分：核心概念与联系

### 第2章：格雷厄姆策略与产业集群生命周期的关系

#### 2.1 核心概念的原理分析

- **格雷厄姆策略的数学模型**：
  - 市盈率：$$PE = \frac{股票价格}{每股收益}$$
  - 市净率：$$PB = \frac{股票价格}{每股净资产}$$
  - 标准：$PE < 行业平均PE$ 且 $PB < 行业平均PB$。

- **产业集群生命周期阶段**：
  - 导入期：技术创新，股票可能低估。
  - 成长期：增长潜力大，但估值可能偏高。
  - 成熟期：稳定增长，估值合理。
  - 衰退期：估值可能低估，但行业前景黯淡。

#### 2.2 核心概念的属性对比

| 阶段       | 格雷厄姆策略适用性 | 特点                                   |
|------------|--------------------|---------------------------------------|
| 导入期     | 高                | 技术创新，股票可能低估                 |
| 成长期     | 中                | 增长快，估值可能偏高                   |
| 成熟期     | 中                | 稳定，估值合理                         |
| 衰退期     | 低                | 估值可能低估，但前景差                 |

#### 3.2 Python代码实现

```python
def calculate_pe(stock_price, earnings_per_share):
    return stock_price / earnings_per_share

def calculate_pb(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

def graham_strategy(stocks, industry_pe, industry_pb):
    undervalued_stocks = []
    for stock in stocks:
        pe = calculate_pe(stock['price'], stock['eps'])
        pb = calculate_pb(stock['price'], stock['book_value'])
        if pe < industry_pe and pb < industry_pb:
            undervalued_stocks.append(stock)
    return undervalued_stocks
```
