### 第1章：巴菲特的价值投资理论

#### 1.1 价值投资的核心理念
- **1.1.1 投资的本质与目标**
  - 投资是通过购买低于内在价值的资产，实现财富增长。
  - 目标：长期稳定的复利增长，而非短期收益。

- **1.1.2 价值投资的定义与特点**
  - 价值投资：寻找市场价格低于内在价值的股票。
  - 特点：注重安全边际，追求长期稳定回报。

- **1.1.3 巴菲特投资理念的形成与发展**
  - 受 mentor Benjamin Graham 影响，形成价值投资理念。
  - 强调安全边际和企业内在价值。

#### 1.2 巴菲特的投资原则
- **1.2.1 长期投资与复利效应**
  - 长期持有优质股票，利用复利效应实现财富增长。
  - 示例：100元投资，年收益10%，10年后变为259元。

- **1.2.2 安全边际的概念与应用**
  - 安全边际：市场价格远低于内在价值。
  - 应用：减少投资风险，确保收益的可靠性。

- **1.2.3 股票与企业价值的关系**
  - 股票是企业的一部分所有权。
  - 企业价值 = 净资产 + 未来现金流的现值。

#### 1.3 巴菲特投资体系的构建
- **1.3.1 股票分析的框架**
  - 企业基本面分析：财务状况、行业地位、竞争优势。
  - 管理层评估：管理层能力与道德。

- **1.3.2 投资决策的逻辑**
  - 确定投资目标：寻找具备持续竞争优势的企业。
  - 评估安全边际：市场价格远低于内在价值。

- **1.3.3 投资心态与风险管理**
  - 长期思维，避免短期波动干扰。
  - 风险管理：分散投资，控制仓位。

#### 2.1 选股流程的系统化

#### 2.2 选股 Checklist 的核心指标
- **2.2.1 财务指标分析**
  - 营业利润增长率：评估企业盈利能力。
  - 净利润率：衡量利润水平。
  - 股东权益回报率（ROE）：评估资金使用效率。

- **2.2.2 行业地位与竞争优势**
  - 行业龙头：市场份额，竞争优势。

- **2.2.3 管理层评估**
  - 管理层能力：经营历史，决策能力。
  - 管理层道德：避免财务造假。

#### 2.3 Checklist 的应用与调整
- **2.3.1 不同市场环境下的 Checklist 调整**
  - 牛市：更严格筛选，避免高估。
  - 熊市：寻找被低估机会。

- **2.3.2 个股分析中的 Checklist 应用**
  - 逐一评估 checklist 指标，排除不符合企业。
  - 结合市场环境，调整筛选标准。

- **2.3.3 组合优化与动态调整**

  - 动态调整：根据变化，增减仓位。

### 第3章：巴菲特投资策略的数学模型

#### 3.1 股票估值的数学模型
- **3.1.1 股息贴现模型（DDM）**
  - 公式：股票价值 = Σ(股息 / (1 + r)^t)
  - 示例：股息稳定增长企业适用。

- **3.1.2 内在价值计算公式**
  - 公式：内在价值 = 净资产 + 未来现金流的现值。
  - 示例：计算企业未来现金流，折现至当前价值。

- **3.1.3 市盈率与市净率分析**
  - 市盈率（P/E）= 价格 / 每股收益。
  - 市净率（P/B）= 价格 / 每股净资产。
  - 应用：判断股票是否被低估或高估。

#### 3.2 投资组合优化的数学模型
- **3.2.1 马科维茨投资组合理论**
  - 均值-方差优化：最小方差，最大收益。
  - 示例：根据风险偏好，构建最优投资组合。

- **3.2.2 投资组合的风险与收益平衡**
  - 风险调整后收益（RAR）= (收益 - 无风险利率) / 标准差。
  - 示例：比较不同投资组合的风险调整后收益。

- **3.2.3 股票权重的计算与分配**
  - 根据企业内在价值，分配投资比例。
  - 示例：企业 A 内在价值高，分配较大权重。

#### 5.2 核心算法实现
- **5.2.1 代码实现**
  ```python
  import pandas as pd
  import requests
  from bs4 import BeautifulSoup

  # 爬取股票数据
  def fetch_data(ticker):
      url = f'https://finance.yahoo.com/quote/{ticker}'
      response = requests.get(url)
      soup = BeautifulSoup(response.text, 'html.parser')
      price = soup.find('div', {'class': 'price'}).text
      return float(price)

  # 计算市盈率
  def calculate_pe(ticker):
      price = fetch_data(ticker)
      # 假设 eps 已知
      eps = 5  # 示例数据
      return price / eps

  print(calculate_pe('AAPL'))  # 示例：AAPL的市盈率
  ```
