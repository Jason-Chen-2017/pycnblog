## 第1章: 资本回报率的基本概念与重要性

### 1.1 资本回报率的定义与背景
资本回报率（ROE，Return on Equity）是衡量公司盈利能力的重要指标，表示每单位股东权益所创造的净利润。ROE = 净利润 / 股东权益。

### 1.2 资本回报率的核心要素
- **净利润**：公司税后利润，反映公司整体盈利能力。
- **股东权益**：公司净资产，包括股本、资本公积和未分配利润等。
- **ROE的计算公式**：  
  $$ROE = \frac{\text{净利润}}{\text{股东权益}}$$

## 第6章: 项目实战

### 6.1 项目背景与目标
选择科技行业，分析某公司过去5年的ROE变化。

### 6.2 代码实现
```python
import pandas as pd

# 假设df是包含财务数据的DataFrame
def calculate_roe(df):
    df['ROE'] = df['净利润'] / df['股东权益']
    return df

# 示例数据
data = {
    '年份': [2018, 2019, 2020, 2021, 2022],
    '净利润': [100, 120, 150, 180, 200],
    '股东权益': [500, 550, 600, 650, 700]
}
df = pd.DataFrame(data)
df = calculate_roe(df)
print(df)
```

### 6.3 结果分析
- ROE逐年上升，表明公司盈利能力增强。
- 结合行业趋势，预测未来ROE将继续增长。
