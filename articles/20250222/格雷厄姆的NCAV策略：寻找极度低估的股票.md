## 第一部分: 格雷厄姆的NCAV策略背景与基础

### 第1章: 价值投资与NCAV策略概述

#### 1.1 价值投资的起源与发展
- 1.1.1 价值投资的定义与核心理念
  - 价值投资是一种长期投资策略，关注于购买价格低于内在价值的资产。
  - 格雷厄姆的学生彼得·林奇曾总结价值投资的核心是寻找“烟屁股”股票，即那些被市场遗忘但具有强大基本面的公司。

- 1.1.2 格雷厄姆的投资哲学
  - 格雷厄姆是现代价值投资之父，提出“市场先生”的概念，认为市场情绪波动会影响股票价格，但长期来看，价格回归价值是必然的。
  - 他强调安全边际的重要性，即以低于内在价值的价格购买资产，以降低投资风险。

- 1.1.3 NCAV策略的提出与意义
  - NCAV策略是格雷厄姆在《 Intelligent Investor》中提出的一种寻找低估股票的方法，特别适用于那些资产主要由流动资产组成的公司。

#### 1.2 NCAV策略的基本概念
- 1.2.1 NCAV的定义与计算公式
  - NCAV（Net Current Asset Value）= (流动资产总额 - 流动负债总额) / 流通股数
  - 通过计算NCAV，投资者可以评估公司每股的净流动资产价值，从而判断股票是否被低估。

- 1.2.2 NCAV与股票估值的关系
  - 当市场价格低于NCAV时，股票具有投资价值。
  - NCAV策略关注的是公司基本面，而非市场趋势，因此适合长期投资者。

- 1.2.3 NCAV策略的核心假设
  - 市场价格最终会回归内在价值。
  - 公司的基本面（如资产状况）是决定股票价值的关键因素。

### 第2章: NCAV策略的核心概念与原理

#### 2.1 核心概念与联系
- 2.1.1 NCAV策略的数学模型与公式
  - $$NCAV = \frac{净资产}{流通股数}$$
  - 该公式计算出每股的净流动资产价值，用于判断股票是否被低估。

- 2.1.2 NCAV与股票价格的关系
  - 当市场价格低于NCAV时，股票具有投资价值。
  - 通过比较NCAV和当前股价，投资者可以识别低估股票。

- 2.1.3 NCAV策略与其他估值方法的对比
  - 表1：NCAV与其他估值方法的对比
  | 估值方法 | 定义 | 优点 | 缺点 |
  |----------|------|------|------|
  | 市盈率（P/E） | 市价/每股收益 | 简单易用 | 受收益波动影响大 |
  | 市净率（P/B） | 市价/每股净资产 | 考虑了资产价值 | 适用于资产密集型行业 |
  | NCAV | 净流动资产/流通股数 | 考虑了流动资产的安全性 | 适用于特定行业 |

- 2.1.4 NCAV策略的适用场景
  - 适用于流动资产占比高的公司，如制造业、批发业等。
  - 适用于市场恐慌或低迷时期，当市场低估资产价值时。

#### 2.2 算法原理讲解
- 2.2.1 NCAV策略的算法流程图

- 2.2.2 算法实现步骤
  1. 收集目标公司的财务报表数据。
  2. 计算流动资产总额和流动负债总额。
  3. 计算净流动资产：流动资产 - 流动负债。
  4. 计算NCAV：净流动资产 / 流通股数。
  5. 比较NCAV与当前股价，判断是否低估。

- 2.2.3 算法优化与改进
  - 使用加权平均法计算流动资产价值。
  - 考虑公司未来的盈利能力，动态调整NCAV计算。

- 3.2.2 核心代码实现
```python
import pandas as pd

def calculate_ncav(stock_code):
    # 获取财务数据
    df = pd.read_csv(f'data/{stock_code}.csv')
    current_assets = df['流动资产'].sum()
    current_liabilities = df['流动负债'].sum()
    net_current_assets = current_assets - current_liabilities
    shares_outstanding = df['流通股数'].sum()
    ncav = net_current_assets / shares_outstanding
    return ncav

# 示例
stock_code = 'AAPL'
ncav = calculate_ncav(stock_code)
print(f'NCAV for {stock_code} is {ncav:.2f}')
```

- 3.2.3 代码解读与分析
  - 该代码从CSV文件中读取目标公司的财务数据。
  - 计算流动资产和流动负债，得出净流动资产。
  - 计算每股NCAV，与当前股价进行比较，判断是否低估。

#### 3.3 项目实战
- 3.3.1 案例分析
  - 以苹果公司为例，计算其NCAV，并与当前股价进行比较。
  - 假设苹果公司某年的流动资产为1000亿美元，流动负债为500亿美元，流通股数为10亿股。
  - NCAV = (1000 - 500) / 10 = 50美元/股。
  - 如果当前股价为40美元，NCAV > 股价，说明股票被低估，值得投资。
