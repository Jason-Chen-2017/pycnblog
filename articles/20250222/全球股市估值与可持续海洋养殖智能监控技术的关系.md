import numpy as np
from sklearn.linear_model import LinearRegression

# 数据加载
data = pd.read_csv('data.csv')

# 数据预处理
X = data[['温度', '盐度', '氧气']]
y = data['股市估值']

# 建立模型
model = LinearRegression()
model.fit(X, y)

# 预测
predictions = model.predict(X)

## 第4章: 数学模型与公式

### 4.1 数学模型概述
#### 4.1.1 模型的构建过程
通过回归分析，建立股市估值与海洋养殖环境数据的关系模型。

#### 4.1.2 模型的假设条件
假设数据线性相关，且无显著多重共线性。

#### 4.1.3 模型的适用范围
适用于海洋养殖环境数据与股市估值相关性较高的场景。

### 4.2 数学公式
#### 4.2.1 核心公式展示
$$ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3 + \epsilon $$

其中：
- $y$ 是股市估值
- $x_1, x_2, x_3$ 是温度、盐度、氧气等环境数据
- $\beta_0, \beta_1, \beta_2, \beta_3$ 是回归系数
- $\epsilon$ 是误差项

#### 4.2.2 公式的详细推导
通过最小二乘法估计回归系数，最小化预测值与实际值之间的残差平方和。

#### 4.2.3 公式的应用示例
假设温度、盐度、氧气分别为20℃、30ppt、5mg/L，预测股市估值为：
$$ y = 100 + 2 \times 20 + 3 \times 30 + 4 \times 5 = 200 $$
