## 第一部分：格雷厄姆特价股票理论基础

### 第1章：格雷厄姆投资理论概述

#### 1.1 格雷厄姆的价值投资理念

格雷厄姆的价值投资理论强调以低于内在价值的价格购买优质股票。其核心在于识别市场低估的股票，通过计算内在价值来判断投资机会。

#### 1.2 安全边际的重要性

格雷厄姆提出安全边际的概念，即买入价格低于内在价值，以降低投资风险并确保收益。

#### 1.3 选股策略

格雷厄姆建议投资者关注那些基本面稳定、盈利能力强且估值合理的公司，尤其是那些市场价格低于内在价值的股票。

### 第2章：分数化所有权证券的概念与应用

#### 2.1 分数化所有权证券的定义

分数化所有权证券允许投资者以小部分资金投资优质资产，通过分割所有权来降低投资门槛。

#### 2.2 分数化所有权证券的优势

- **降低投资门槛**：允许小资金投资者参与。
- **风险分散**：投资多样化资产，降低风险。
- **提高流动性**：更容易买卖和调整投资组合。

#### 2.3 分数化所有权与传统证券的对比

| 特性               | 分数化所有权证券 | 传统证券       |
|--------------------|------------------|----------------|
| 投资门槛           | 低               | 高             |
| 风险分散           | 高               | 低             |
| 流动性             | 高               | 中             |

### 第3章：格雷厄姆理论与分数化证券的结合

#### 3.1 理论应用

通过分数化证券，投资者可以将格雷厄姆的选股策略应用于更多股票，利用安全边际实现长期收益。

## 第二部分：数学模型与算法

### 第4章：内在价值计算模型

#### 4.1 计算公式

$$内在价值 = \frac{EPS \times (1 + g)}{k}$$

其中，EPS为每股收益，g为增长率，k为贴现率。

#### 4.2 案例分析

以公司A为例，EPS=5，g=5%，k=10%：

$$内在价值 = \frac{5 \times 1.05}{0.10} = 52.5$$

若市场价格为40，存在投资机会。

### 第5章：分数化证券定价算法

#### 5.1 定价模型

$$价格 = \frac{内在价值}{分割比例}$$

#### 5.2 算法实现

```python
def calculate_price(intrinsic_value, split_ratio):
    return intrinsic_value / split_ratio

# 示例
iv = 52.5
split = 10
price = calculate_price(iv, split)
print(price)  # 输出：5.25
```
