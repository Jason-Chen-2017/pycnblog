# 数据预处理

# 模型训练
model = RandomForestClassifier()
model.fit(data[:, 0].reshape(-1, 1), data[:, 1].reshape(-1, 1))

def get_status(T, H):

## 第四部分: 项目实战

### 第6章: 项目实战

#### 6.1 环境安装
- Python 3.8+
- 安装库：pip install numpy pandas scikit-learn

#### 6.2 核心代码实现
```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 数据采集
X = np.array([[20, 60], [22, 65], [25, 70], [30, 75]])
y = np.array([0, 1, 1, 0])  # 0表示新鲜，1表示不新鲜

# 模型训练
model = RandomForestClassifier()
model.fit(X[:, 0].reshape(-1, 1), y)

# 测试案例
test_X = [[20], [22], [25], [30]]
test_y = [0, 1, 1, 0]

# 预测与评估
y_pred = model.predict(test_X)
print("准确率:", accuracy_score(test_y, y_pred))

# 状态判断
def get_status(T):
    prediction = model.predict([[T]])
    return "新鲜" if prediction[0] == 0 else "不新鲜"

print(get_status(20))  # 输出：新鲜
print(get_status(25))  # 输出：不新鲜
```

#### 6.3 代码解读与分析
- 数据采集：从传感器获取温度和湿度数据。
- 模型训练：使用随机森林算法训练分类模型。
- 测试案例：验证模型的准确率。
- 状态判断：根据模型预测结果输出反馈。

#### 6.4 实际案例分析
