# 第3章: 投资组合优化模型的算法实现

## 3.1 均值-方差模型的算法实现
### 3.1.1 模型的数学公式
$$ \text{目标：} \min_w w^T \Sigma w $$
$$ \text{约束：} w^T \mu = \mu_{target}, \sum_{i=1}^n w_i = 1 $$

### 3.1.2 算法的步骤分解
1. 输入参数：预期收益、协方差矩阵
2. 构建优化问题
3. 使用优化算法求解
4. 输出结果：最优权重

### 3.1.3 代码实现与案例分析
```python
import numpy as np
from scipy.optimize import minimize

# 示例数据
mu = np.array([0.1, 0.2])
Sigma = np.array([[0.05, 0.02], [0.02, 0.1]])
target_return = 0.15

def objective(w):
    return np.dot(w.T, Sigma.dot(w))[0, 0]

def constraint1(w, mu, target_return):
    return np.dot(w, mu) - target_return

# 初始权重
initial_guess = np.array([0.5, 0.5])

# 约束条件
constraints = {'type': 'eq', 'fun': constraint1, 'args': (mu, target_return)}

# 约束权重的和为1
bounds = [(0, None), (0, None)]
sum_constraint = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}

# 优化问题
result = minimize(objective, initial_guess, method='SLSQP', constraints=[constraints, sum_constraint], bounds=bounds)

print(result.x)
```

### 5.2.1 均值-方差模型的代码实现
```python
# 示例代码：均值-方差模型
import numpy as np
from scipy.optimize import minimize

def portfolio_variance(weights, covariance_matrix):
    return np.dot(weights.T, np.dot(covariance_matrix, weights))[0, 0]

def target_return(weights, expected_returns):
    return np.dot(weights, expected_returns)

# 示例数据
n_assets = 3
expected_returns = np.array([0.05, 0.1, 0.15])
covariance_matrix = np.array([
    [0.02, 0.01, 0.01],
    [0.01, 0.03, 0.02],
    [0.01, 0.02, 0.04]
])

# 约束条件
constraints = [
    {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
    {'type': 'eq', 'fun': lambda w: target_return(w, expected_returns) - 0.1}
]

# 初始猜测
initial_guess = np.array([1/3, 1/3, 1/3])

# 优化问题
result = minimize(portfolio_variance, initial_guess, method='SLSQP', constraints=constraints)

# 输出结果
print("Optimal weights:", result.x)
```

### 5.2.2 风险调整后的收益模型的代码实现
```python
# 示例代码：风险调整后的收益模型
import numpy as np
from scipy.optimize import minimize

def sharpe_ratio(weights, expected_returns, covariance_matrix, risk_free_rate):
    portfolio_variance = np.dot(weights.T, np.dot(covariance_matrix, weights))[0, 0]
    portfolio_std = np.sqrt(portfolio_variance)
    sharpe = (np.dot(weights, expected_returns) - risk_free_rate) / portfolio_std
    return -sharpe  # 最小化问题中最大化夏普比率

# 示例数据
n_assets = 3
expected_returns = np.array([0.05, 0.1, 0.15])
covariance_matrix = np.array([
    [0.02, 0.01, 0.01],
    [0.01, 0.03, 0.02],
    [0.01, 0.02, 0.04]
])
risk_free_rate = 0.02

# 约束条件
constraints = [
    {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
    {'type': 'eq', 'fun': lambda w: np.dot(w, expected_returns) - 0.1}
]

# 初始猜测
initial_guess = np.array([1/3, 1/3, 1/3])

# 优化问题
result = minimize(sharpe_ratio, initial_guess, method='SLSQP', constraints=constraints, args=(expected_returns, covariance_matrix, risk_free_rate))

# 输出结果
print("Optimal weights:", result.x)
```
