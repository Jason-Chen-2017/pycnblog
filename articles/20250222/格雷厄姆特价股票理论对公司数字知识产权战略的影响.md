## 第1章：格雷厄姆特价股票理论概述

### 1.1 格雷厄姆特价股票的定义与特点

格雷厄姆的特价股票是指价格低于其内在价值的股票，通常被认为具有投资价值。其特点包括：

- **低估性**：市场价格低于内在价值。
- **稳定性**：公司具有稳定的盈利能力和财务状况。
- **安全性**：投资风险较低，回报潜力大。

### 1.2 数字知识产权的基本概念

数字知识产权（Digital Intellectual Property, DIP）是指在数字环境下产生的知识产权，包括软件、数据、算法、设计等。其类型包括版权、专利、商标和商业秘密。

- **版权**：保护文学、艺术作品。
- **专利**：保护技术发明。
- **商标**：区分商品或服务的标识。
- **商业秘密**：未公开的商业信息。

数字知识产权的价值评估涉及市场潜力、技术复杂性和法律保护等因素。

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(cash_flows / (1 + discount_rate)**i for i in range(len(cash_flows)))

# 示例数据
cash_flows = [100, 200, 300]  # 未来现金流
discount_rate = 0.1  # 折现率

iv = calculate_intrinsic_value(cash_flows, discount_rate)
```
