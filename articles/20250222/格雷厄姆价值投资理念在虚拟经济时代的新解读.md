## 第1章: 价值投资的基本原理

### 1.1 价值投资的核心概念

价值投资是一种以内在价值为核心的投资策略，强调购买价格低于内在价值的资产。格雷厄姆的价值投资体系强调安全边际、质价理论和内在价值评估。

### 1.2 投资者心态与行为

投资者的心理波动和行为模式对投资决策有重要影响。理性决策与非理性决策的对比，以及如何在虚拟经济中保持理性的投资心态，是价值投资成功的关键。

### 1.3 虚拟经济的基本情况

虚拟经济以数字货币和NFT为代表，具有去中心化、高波动性和技术驱动等特点。与传统经济相比，虚拟经济的评估体系需要重新构建。

## 第3章: 格雷厄姆理念的虚拟经济应用

### 3.1 内在价值评估

使用格雷厄姆的贴现现金流模型，评估虚拟资产的内在价值。公式如下：

$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} $$

其中，$CF_t$为自由现金流，$r$为折现率，$n$为项目周期。

### 3.2 安全边际

计算安全边际以确保投资的安全性：

$$ \text{安全边际} = \frac{\text{内在价值} - \text{市场价格}}{\text{市场价格}} $$

### 3.3 投资策略

制定长期投资策略，强调分散投资和风险管理。通过系统设计优化投资组合。

```python
def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(cf / (1 + discount_rate) ** t for t, cf in enumerate(cash_flows))

market_price = 100
intrinsic_value = calculate_intrinsic_value([50, 60, 70], 0.1)
safety_margin = (intrinsic_value - market_price) / market_price
```
