## 第一部分：格雷厄姆投资理念基础

### 第1章：格雷厄姆投资理念概述

#### 1.1 格雷厄姆投资理念的核心概念

##### 1.1.1 价值投资的定义与核心思想
- 价值投资是一种以低于内在价值的价格买入优质股票的投资策略。
- 格雷厄姆强调以安全边际为核心，寻找市场价格低于内在价值的股票。

##### 1.1.2 格雷厄姆的投资哲学与方法论
- 格雷厄姆认为市场是不理性的，价格波动为投资者提供了机会。
- 他主张通过基本面分析寻找低估的股票，而非依赖市场情绪。

##### 1.1.3 价值投资与成长投资的区别与联系
- 价值投资关注低估的价格和稳定的收益，而成长投资关注高增长的潜力。
- 两者都注重基本面分析，但侧重点不同。

#### 1.2 格雷厄姆的选股原则

##### 1.2.1 低估值股票的定义与特征
- 低估值股票是指市场价格低于其内在价值的股票。
- 典型特征包括低市盈率、低市净率和高股息率。

##### 1.2.2 格雷厄姆的选股标准与公式
- 格雷厄姆提出了著名的“内在价值”公式：
$$
\text{内在价值} = \frac{\text{收益} \times (5 + \text{市盈率})}{\text{市盈率}}
$$

##### 1.2.3 安全边际的概念与重要性
- 安全边际 = 内在价值 - 市场价格。
- 通过预留安全边际降低投资风险。

#### 1.3 格雷厄姆投资理念的现代应用

### 第2章：格雷厄姆的低估值股票分析方法

#### 2.1 基本面分析的核心要素

##### 2.1.1 财务报表分析的基础知识
- 利润表、资产负债表和现金流量表的解读。
- 关键指标包括净利润、营业收入、资产负债率等。

##### 2.1.2 估值指标的计算与应用
- 市盈率（P/E）：
$$
P/E = \frac{\text{股价}}{\text{每股收益}}
$$
- 市净率（P/B）：
$$
P/B = \frac{\text{股价}}{\text{每股净资产}}
$$
- 股息率：
$$
\text{股息率} = \frac{\text{每股股息}}{\text{股价}} \times 100\%
$$

##### 2.1.3 市盈率、市净率与股息率的综合分析
- 低市盈率和低市净率通常意味着低估。
- 高股息率可能表明股票具有吸引力。

#### 2.2 格雷厄姆的内在价值计算方法

##### 2.2.1 内在价值的定义与计算公式
- 内在价值是公司未来现金流的现值。
- 格雷厄姆公式：
$$
\text{内在价值} = \frac{\text{收益} \times (5 + \text{市盈率})}{\text{市盈率}}
$$

##### 2.2.2 股票价值的多因素分析模型
- 结合收益、成长性、财务健康等多个因素。

##### 2.2.3 市场价格与内在价值的偏离分析
- 当市场价格低于内在价值时，股票具有投资价值。

#### 2.3 安全边际的量化与应用

##### 2.3.1 安全边际的计算公式
$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

##### 2.3.2 安全边际在选股中的实际应用
- 安全边际越高，投资风险越小。

##### 2.3.3 安全边际与投资风险的平衡
- 在高安全边际和高收益之间找到平衡点。

#### 10.1 格雷厄姆选股模型的Python实现
```python
import pandas as pd

def calculate_intrinsic_value(revenue, pe_ratio):
    return (revenue * (5 + pe_ratio)) / pe_ratio

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
data = {
    '股票代码': ['AAPL', 'MSFT', 'GOOGL'],
    '收入': [3943.84, 1900.82, 181.54],
    '市盈率': [28.12, 22.92, 33.37]
}

df = pd.DataFrame(data)

# 计算内在价值和安全边际
df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['收入'], x['市盈率']), axis=1)
df['安全边际'] = df.apply(lambda x: calculate_margin_of_safety(x['内在价值'], x['股价']), axis=1)
```
