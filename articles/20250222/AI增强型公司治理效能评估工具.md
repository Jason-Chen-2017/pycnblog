## 5.3 数学公式与模型

### 5.3.1 层次分析法（AHP）  
- 权重计算公式：$$ A_{weight} = \frac{A_{score}}{\sum A_{score}} $$  
- 综合评分公式：$$ S = \sum w_i \cdot x_i $$  

### 5.3.2 示例代码  
```python
def calculate_weights(matrix):
    # 计算权重
    total = sum(matrix)
    weights = [score / total for score in matrix]
    return weights
```
