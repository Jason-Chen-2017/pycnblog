##### 3.2 数学模型与公式
- **收益计算公式**  
  收益率 = (投资收益 / 投资成本) × 100%  
  其中，投资收益 = 终值 - 初始值

- **风险评估公式**  
  风险 = 标准差(收益率序列)  
  标准差的计算公式为：  
  $$ \sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \mu)^2} $$  
  其中，\( \mu \) 是平均收益率，\( n \) 是数据点的数量。

##### 3.3 Python代码实现

```python
import numpy as np

def compute_yield(initial_capital, final_value):
    return ((final_value - initial_capital) / initial_capital) * 100

def compute_risk(yields):
    mu = np.mean(yields)
    variance = np.sum((y - mu)**2 for y in yields) / len(yields)
    return np.sqrt(variance)

# 示例数据
initial_capital = 10000
final_value = 10500
yields = [5, -2, 3, 8, -1]

# 计算
yield_percentage = compute_yield(initial_capital, final_value)
risk = compute_risk(yields)

print(f"收益率：{yield_percentage}%")
print(f"风险：{risk}")
```

import numpy as np
import pandas as pd

def process_market_data(data):
    # 数据预处理
    processed_data = data.apply(lambda x: x.fillna(method='ffill'))
    return processed_data

def generate_signals(processed_data):
    # 生成投资信号
    signals = []
    for i in range(len(processed_data)):
        if processed_data.iloc[i]['Price'] > processed_data.iloc[i-1]['Price']:
            signals.append(1)
        else:
            signals.append(0)
    return signals

# 示例数据加载
data = pd.read_csv('market_data.csv')
processed_data = process_market_data(data)
signals = generate_signals(processed_data)
