# 第一部分: 人口老龄化与投资背景

## 第1章: 人口老龄化与投资背景

### 1.1 人口老龄化的基本概念
#### 1.1.1 人口老龄化定义
- 人口老龄化是指65岁及以上人口占总人口比例不断上升的趋势。
- 老龄化社会的划分标准：65岁以上人口占比达到7%即为老龄化社会，达到14%为深度老龄化社会。

#### 1.1.2 人口老龄化的原因与趋势
- 社会发展：医疗进步、生育率下降导致人口结构变化。
- 全球趋势：发达国家已进入深度老龄化，发展中国家老龄化速度加快。
- 预测数据：联合国数据显示，全球65岁以上人口将从2020年的10%增长到2050年的16%。

#### 1.1.3 人口老龄化对经济的影响
- 消费模式：从年轻人为主转向中老年人为主。
- 劳动力市场：劳动力供给减少，用工成本上升。
- 经济结构：医疗、养老、科技等领域需求增加。

### 1.2 巴菲特与芒格的投资理念
#### 1.2.1 巴菲特的价值投资理论

# 第三部分: 数学模型与投资算法

## 第4章: 投资数学模型

### 4.1 现金流贴现模型（DCF）
#### 4.1.1 模型的基本原理
- 将未来现金流折现，评估企业当前价值。
- 公式：$$DCF = \frac{CF}{(r - g)}$$
  - CF：未来现金流
  - r：折现率
  - g：增长率

#### 4.1.2 模型的公式推导
- 通过时间价值理论推导DCF模型。
- 通过实际案例展示模型的应用。

#### 4.1.3 模型的优缺点
- 优点：能够准确评估企业内在价值。
- 缺点：假设条件严格，实际操作中难以满足。

### 4.2 市盈率与市净率分析
#### 4.2.1 市盈率的计算与应用
- 公式：$$市盈率 = \frac{股价}{每股收益}$$
- 应用：评估股票的估值水平。

#### 4.2.2 市净率的计算与应用
- 公式：$$市净率 = \frac{股价}{每股净资产}$$
- 应用：评估股票的资产价值。

#### 4.2.3 两者的综合运用
- 结合市盈率和市净率评估股票的内在价值。
- 通过多维度分析降低投资风险。

```python
import pandas as pd
import numpy as np

# 示例：计算DCF模型
def calculate_dcf(future_cash_flows, discount_rate, growth_rate):
    return future_cash_flows / (discount_rate - growth_rate)

# 示例：计算市盈率
def calculate_pe_ratio(stock_price, eps):
    return stock_price / eps

# 示例：计算市净率
def calculate_pb_ratio(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

# 数据分析
data = pd.DataFrame({
    '股价': [100, 80, 90],
    '每股收益': [20, 15, 25],
    '每股净资产': [50, 40, 60]
})

data['市盈率'] = data.apply(lambda x: calculate_pe_ratio(x['股价'], x['每股收益']), axis=1)
data['市净率'] = data.apply(lambda x: calculate_pb_ratio(x['股价'], x['每股净资产']), axis=1)
print(data)
```
