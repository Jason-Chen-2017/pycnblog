# 第二章 格雷厄姆特价股票理论的核心概念

## 2.1 价值投资的核心思想

### 2.1.1 什么是价值投资？

价值投资是一种以企业内在价值为基础的投资策略，强调以低于内在价值的价格买入优质资产。

### 2.1.2 格雷厄姆的安全边际概念

安全边际是指股票的内在价值与市场价格之间的差值，确保投资者在市场波动中能够获得超额收益。

$$ 安全边际 = 股票内在价值 - 市场价格 $$

### 2.1.3 格雷厄姆的内在价值公式

$$ 内在价值 = \frac{收益 + 股息}{利率} $$

## 2.2 格雷厄姆的投资策略

### 2.2.1 避免情绪化投资

格雷厄姆强调理性投资，避免因市场情绪波动而做出错误决策。

### 2.2.2 分散投资风险

通过分散投资降低风险，同时关注具有安全边际的股票。

### 2.2.3 长期投资策略

价值投资强调长期持有优质资产，等待市场回归其内在价值。

### 5.2.2 核心代码实现

```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('stock_data.csv')

# 计算内在价值
data['内在价值'] = (data['收益'] + data['股息']) / data['利率']

# 计算安全边际
data['安全边际'] = data['内在价值'] - data['市场价格']

# 可视化
import matplotlib.pyplot as plt

plt.plot(data['公司'], data['安全边际'])
plt.title('安全边际分析')
plt.xlabel('公司')
plt.ylabel('安全边际')
plt.show()
```
