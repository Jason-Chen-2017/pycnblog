#### 2.2 主要估值指标与公式
- 市盈率（P/E）的计算与应用
  - 公式：$P/E = \frac{P}{E}$
  - 估值方法：相对估值法
- 市净率（P/B）的计算与应用
  - 公式：$P/B = \frac{P}{B}$
  - 估值方法：绝对估值法
- 股息率的计算与应用
  - 公式：$Dividend Yield = \frac{D}{P}$
  - 估值方法：股息贴现模型（DDM）
- 内在价值的估算公式
  - 公式：$$V = \frac{CF}{(1+r)^n}$$
  - 股权自由现金流折现模型（DCF）

#### 3.3 数据分析与案例研究
- 使用Python进行数据筛选的代码示例
  ```python
  import pandas as pd
  import yfinance as yf

  # 下载数据
  df = yf.download(tickers='AAPL MSFT', start='2020-01-01', end='2023-01-01')

  # 计算市盈率
  df['PE'] = df['Close'] / df['EPS'].shift(1)
  # 筛选低估公司
  undervalued = df[df['PE'] < df['PE'].mean()]
  print(undervalued)
  ```
