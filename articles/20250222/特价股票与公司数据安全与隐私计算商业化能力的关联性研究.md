## 第三部分：算法原理讲解

### 第3章：算法与数学模型

#### 3.1 同态加密算法

- 原理：允许在加密状态下进行计算，结果正确。
- Mermaid流程图展示加密过程：

```mermaid
graph TD
    Start --> Encrypt[加密]
    Encrypt --> Compute[计算]
    Compute --> Decrypt[解密]
    Decrypt --> End
```

- Python代码示例：

```python
def encrypt(data, key):
    return data ^ key

def decrypt(encrypted_data, key):
    return encrypted_data ^ key

# 示例
key = 0b1010
data = 0b0101
encrypted = encrypt(data, key)
decrypted = decrypt(encrypted, key)
print("加密数据:", encrypted)
print("解密数据:", decrypted)
```

- 数学公式：

$$
\text{加密} = x \oplus k \\
\text{解密} = (x \oplus k) \oplus k = x
$$
