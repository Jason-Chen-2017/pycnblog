### 1.1 约翰·邓普顿的生平与投资理念

#### 1.1.1 约翰·邓普顿的生平简介

约翰·邓普顿（John Templeton，1912年-2008年）是20世纪最著名的职业投资者之一，被誉为“邓巴顿”。他出生于加拿大，后来移居美国，并在投资界取得了卓越成就。邓普顿的职业生涯跨越了70年，期间他成功地预测并利用了多次市场危机，成为价值投资的代表人物。

#### 1.1.2 约翰·邓普顿的投资理念

邓普顿的投资理念以价值投资为核心，强调在市场恐慌时买入被低估的资产，在市场狂热时卖出。他的投资策略注重安全边际，即买入价格远低于内在价值的资产。此外，他还认为市场是波动的，危机时期往往隐藏着巨大的投资机会。

#### 1.1.3 邓普顿投资方法的核心思想

邓普顿的投资方法可以总结为以下几点：

1. **价值投资**：寻找市场价格低于内在价值的资产。
2. **逆向投资**：在市场恐慌时买入，在市场狂热时卖出。
3. **安全边际**：买入价格与内在价值之间的差距作为安全边际。
4. **分散投资**：避免过度集中投资，降低风险。

### 1.2 危机投资机会的背景分析

#### 1.2.1 经济危机的定义与特征

经济危机是指经济系统中出现严重的衰退、失业率上升、企业倒闭等一系列问题，通常伴随着资产价格的大幅下跌。危机时期的市场往往被恐慌情绪主导，投资者情绪低落，市场流动性下降。

#### 1.2.2 危机时期的投资机会

在危机时期，许多优质资产的价格被市场恐慌情绪打压到极低水平，这为长期投资者提供了难得的投资机会。邓普顿认为，危机时期是寻找被低估资产的最佳时机。

#### 1.2.3 邓普顿视角下的危机投资机会

邓普顿认为，危机时期的投资机会主要体现在以下几个方面：

1. **价格低估**：许多资产的价格远低于其内在价值。
2. **市场流动性下降**：市场流动性下降导致价格被低估。
3. **投资者情绪低落**：恐慌情绪导致投资者做出非理性决策，进一步低估资产价值。

### 5.3 投资策略的代码实现

```python
import pandas as pd
import requests

def get_data(ticker):
    url = f"https://api.example.com/{ticker}"
    response = requests.get(url)
    data = response.json()
    df = pd.DataFrame(data)
    return df

def process_data(df):
    df = df.dropna()
    df = df[["price", "eps", "book_value", "dividend_yield"]]
    return df

def calculate_value(df):
    df["fair_value"] = df["price"] / df["eps"] * 0.8
    return df

def investment_decision(df):
    recommendation = []
    for index, row in df.iterrows():
        if row["price"] < row["fair_value"]:
            recommendation.append("Buy")
        else:
            recommendation.append("Sell")
    return recommendation

# 示例代码
ticker = "AAPL"
df = get_data(ticker)
df = process_data(df)
df = calculate_value(df)
recommendation = investment_decision(df)
print(recommendation)
```
