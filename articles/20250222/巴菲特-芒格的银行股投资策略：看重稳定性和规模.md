# 第3章 算法原理讲解

## 3.1 算法概述  
巴菲特和芒格的价值投资策略可以看作是一种基于基本面分析的投资算法。核心在于通过数学模型计算股票的内在价值，再结合安全边际进行投资决策。

## 3.2 算法流程图

---

## 3.3 数学模型与公式

### 3.3.1 股票内在价值计算  
$$ V = \frac{CF}{r - g} $$  
其中：  
- \( V \)：股票的内在价值  
- \( CF \)：未来现金流  
- \( r \)：折现率  
- \( g \)：现金流增长率  

### 3.3.2 安全边际计算  
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$  

### 3.3.3 实例计算  
假设某银行股的内在价值为 $50，市场价格为 $40，则安全边际为 $10。此时，巴菲特和芒格会认为这是一个值得投资的机会。

# 第5章 项目实战

## 5.1 环境安装  
需要安装Python和相关金融分析库（如Pandas、NumPy）。  

## 5.2 核心实现代码  

```python
import pandas as pd

def calculate_intrinsic_value(cash_flows, discount_rate, growth_rate):
    return cash_flows / (discount_rate - growth_rate)

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
cash_flows = 100
discount_rate = 0.1
growth_rate = 0.05
market_price = 90

# 计算内在价值
iv = calculate_intrinsic_value(cash_flows, discount_rate, growth_rate)
mos = calculate_margin_of_safety(iv, market_price)

print(f"内在价值: {iv:.2f}")
print(f"安全边际: {mos:.2f}")
```

## 5.3 代码解读与分析  
- `calculate_intrinsic_value`函数用于计算股票的内在价值。  
- `calculate_margin_of_safety`函数用于计算安全边际。  
- 示例数据中，内在价值为 $100，市场价格为 $90，安全边际为 $10。此时，巴菲特和芒格会认为这是一个值得投资的机会。
