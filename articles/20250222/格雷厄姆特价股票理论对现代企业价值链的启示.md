## 第一部分：格雷厄姆投资理论概述

### 第1章：格雷厄姆投资理论的核心概念

#### 1.1 价值投资的定义与起源
- **1.1.1 价值投资的定义**  
  价值投资是一种投资策略，强调以低于内在价值的价格购买优质资产。其核心在于识别市场价格低于内在价值的股票。
  
- **1.1.2 格雷厄姆的安全边际理论**  
  安全边际是指市场价格与内在价值之间的差距。通过购买具有较大安全边际的股票，投资者可以降低投资风险。

- **1.1.3 内在价值与市场价值的对比**  
  内在价值是基于企业基本面分析得出的理论价值，而市场价值是市场价格，通常受市场情绪影响。

#### 1.2 特价股票的定义与特征
- **1.2.1 特价股票的定义**  
  特价股票是指市场价格低于内在价值的股票。

- **1.2.2 特价股票的识别标准**  
  包括低市盈率、低市净率、高股息率等指标。

- **1.2.3 特价股票与成长股的区别**  
  特价股票注重安全性和稳定性，而成长股注重未来的增长潜力。

#### 1.3 格雷厄姆投资策略的适用场景
- **1.3.1 牛市与熊市中的策略差异**  
  在牛市中，投资者应谨慎选择，避免追高；在熊市中，廉价股票更容易出现。

- **1.3.2 不同行业中的应用**  
  在周期性行业中，安全边际更为重要；在成长性行业中，需关注未来的增长潜力。

- **1.3.3 个人投资者与机构投资者的策略差异**  
  个人投资者适合长期价值投资，机构投资者则需考虑资金规模和流动性需求。

### 第2章：格雷厄姆投资理论的数学模型与公式

#### 2.1 内在价值计算模型
- **2.1.1 现金流折现模型（DCF）**  
  内在价值 = ∑(CF_t / (1 + r)^t)  
  其中，CF_t为第t年的现金流，r为折现率。

- **2.1.2 格雷厄姆的简化估值法**  
  内在价值 = (每股收益 × 市净率) / 市盈率

- **2.1.3 市盈率与市净率的应用**  
  市盈率 = 价格 / 每股收益  
  市净率 = 价格 / 每股净资产

#### 2.2 安全边际计算公式
- **2.2.1 安全边际的定义**  
  安全边际 = 内在价值 - 市场价格

- **2.2.2 安全边际的计算方法**  
  安全边际率 = (内在价值 - 市场价格) / 市场价格

- **2.2.3 安全边际与投资风险的关系**  
  安全边际越大，投资风险越小。

#### 2.3 投资组合优化模型
- **2.3.1 马科维茨投资组合理论**  
  投资组合的最优风险收益比是通过调整资产配置实现的。

- **2.3.2 格雷厄姆投资组合的优化策略**  
  通过分散投资降低风险，同时选择具有较大安全边际的股票。

- **2.3.3 投资组合的风险调整收益分析**  
  使用夏普比率衡量投资组合的风险调整收益。

  def find_cheap_stocks(data, threshold=0.2):
      data['intrinsic_value'] = data['earnings'] * data['price_to_earnings'].mean()
