#### 3.1.2 基于FFT的频域分析
使用傅里叶变换将时域信号转换为频域信号，提取特定频段的功率谱。

#### 3.1.3 基于机器学习的分类算法
使用支持向量机（SVM）或随机森林（RF）对特征进行分类，识别大脑状态。

#### 3.1.4 Python 实现代码
```python
import numpy as np
from scipy.fft import fft

def process_eeg_signal(signal, sampling_rate):
    # 傅里叶变换
    fft_result = fft(signal)
    # 提取特定频段的功率谱
    power_spectrum = np.abs(fft_result) ** 2
    return power_spectrum
```
