# 第二部分：格雷厄姆理论的核心概念与量化分析基础

## 第2章：格雷厄姆投资理论的核心要素

### 2.1 安全边际
**定义**：安全边际是格雷厄姆提出的核心概念，指股票的市场价格低于其内在价值的部分。  
**数学表达**：  
$$ 安全边际 = 内在价值 - 市场价格 $$  
**属性**：  
- 安全边际越大，投资风险越低。  
- 安全边际为正时，投资具有防御性。

### 2.2 内在价值
**定义**：内在价值是基于公司基本面分析得出的股票真实价值，不随市场波动而变化。  
**计算公式**：  
$$ 内在价值 = \frac{预期自由现金流}{折现率} $$  

### 2.3 量化分析的基础
量化投资依赖于数据处理、统计分析和算法交易，而格雷厄姆的理论为量化模型提供了基本面分析的基础。通过将安全边际和内在价值转化为可量化的指标，投资者可以利用量化方法筛选出具有投资价值的股票。

## 第3章：格雷厄姆价值评估方法的数学模型

### 3.1 安全边际的计算
通过量化模型计算股票的安全边际，投资者可以在市场中找到低估的股票。  
**步骤**：  
1. **数据获取**：收集目标股票的财务数据。  
2. **计算内在价值**：使用格雷厄姆模型或其他方法估算内在价值。  
3. **计算市场价格**：获取当前市场价格。  
4. **计算安全边际**：$安全边际 = 内在价值 - 市场价格$。  
5. **筛选股票**：选择安全边际为正的股票。

### 3.2 内在价值的估算
以苹果公司为例，假设其预期自由现金流为$100亿，折现率为8%。  
$$ 内在价值 = \frac{100}{0.08} = 1250 \text{亿美元} $$  
如果当前市场价格为$1200亿美元，则安全边际为$50亿美元，具有投资价值。

### 5.2 格雷厄姆安全边际算法
```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(fcf, discount_rate):
    return fcf / discount_rate

def calculate_market_price(data):
    return data['close'].iloc[-1]

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
data = pd.DataFrame({
    'close': [100, 105, 110, 115],
    'fcf': [100, 120, 130, 140]
})

discount_rate = 0.08

intrinsic_value = calculate_intrinsic_value(data['fcf'].iloc[-1], discount_rate)
market_price = calculate_market_price(data)
margin_of_safety = calculate_margin_of_safety(intrinsic_value, market_price)

print(f"内 在 价 值: {intrinsic_value}")
print(f"市 场 价 格: {market_price}")
print(f"安全边际: {margin_of_safety}")
```
