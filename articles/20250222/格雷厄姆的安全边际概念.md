### 第2章: 安全边际的数学模型与公式

#### 2.1 内在价值的计算公式  
- $$内在价值 = \frac{股息率 \times 市盈率}{市净率}$$  
  - 示例：某公司股息率为5%，市盈率为15，市净率为3，计算其内在价值  

- $$内在价值 = \frac{营业收入 \times 净利润 \times 市销率}{市盈率}$$  
  - 示例：某公司营业收入为1000万，净利润为200万，市销率为1.5，市盈率为10，计算其内在价值  

#### 2.2 安全边际的计算公式  
- $$安全边际 = 内在价值 - 市场价格$$  
  - 示例：某公司内在价值为50元，市场价格为35元，计算安全边际  

- $$安全边际率 = \frac{(内在价值 - 市场价格)}{市场价格}$$  
  - 示例：安全边际率为35%，表示市场价格低于内在价值35%

  - 数据输入：市场价格

  - 输出：安全边际  

#### 3.2 安全边际算法的Python实现  
```python  
def calculate_intrinsic_value(earnings, revenue, dividend_yield, price_to_earnings, price_to_book, price_to_sales):  
    intrinsic_value1 = (dividend_yield * price_to_earnings) / price_to_book  
    intrinsic_value2 = (revenue * earnings * price_to_sales) / price_to_earnings  
    return (intrinsic_value1 + intrinsic_value2) / 2  

def calculate_margin_of_safety(intrinsic_value, market_price):  
    margin_of_safety = intrinsic_value - market_price  
    return margin_of_safety / market_price * 100  

# 示例计算  
intrinsic_value = calculate_intrinsic_value(200000, 1000000, 0.05, 15, 3, 1.5)  
market_price = 35  
margin_of_safety_rate = calculate_margin_of_safety(intrinsic_value, market_price)  
print(f"安全边际率为：{margin_of_safety_rate}%")  
```

#### 3.3 安全边际算法的数学模型  
- $$ intrinsic\_value = \frac{dividend\_yield \times price\_to\_earnings}{price\_to\_book} $$  
- $$ intrinsic\_value = \frac{revenue \times earnings \times price\_to\_sales}{price\_to\_earnings} $$  
- $$ margin\_of\_safety = intrinsic\_value - market\_price $$  
- $$ margin\_of\_safety\_rate = \frac{margin\_of\_safety}{market\_price} \times 100 $$
