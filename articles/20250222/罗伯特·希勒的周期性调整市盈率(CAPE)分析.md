## 第1章: 什么是周期性调整市盈率（CAPE）

### 1.1 市场估值与市盈率的局限性

#### 1.1.1 传统市盈率的定义与局限性
市盈率（Price-to-Earnings Ratio，P/E）是衡量股票估值的重要指标，计算公式为：

$$P/E = \frac{\text{股价}}{\text{每股净利润}}$$

然而，传统市盈率存在以下局限性：
1. **周期性波动**：净利润会受到经济周期的影响，导致市盈率在短期内波动较大。
2. **短期导向**：市盈率仅考虑最近一个会计年度的净利润，无法反映长期盈利能力。
3. **行业差异**：不同行业的净利润率差异较大，市盈率的可比性有限。

#### 1.1.2 市场估值与投资者决策的关联
市场估值是投资者在进行资产配置时的重要参考，它反映了市场整体的盈利能力与价格水平之间的关系。然而，传统的市盈率指标由于其短期性和行业差异性，难以满足投资者对长期市场估值的需求。

#### 1.1.3 罗伯特·希勒的学术贡献与研究背景
罗伯特·希勒（Robert Shiller）是耶鲁大学的著名经济学家，他在《金融学杂志》上提出了周期性调整市盈率（CAPE）的概念。希勒的研究主要关注市场周期与投资者心理对资产价格的影响，他的研究成果为CAPE指标的提出奠定了理论基础。

### 1.2 周期性调整市盈率（CAPE）的定义与特点

#### 1.2.1 CAPE的定义与计算公式
CAPE（Cyclically Adjusted Price-Earnings Ratio）是将市盈率扩展到10年平均收益的指标，其计算公式为：

$$CAPE = \frac{\text{股价}}{\text{10年平均每股净利润}}$$

CAPE的核心思想是通过平滑周期性波动，反映市场在长期视角下的估值水平。

#### 1.2.2 CAPE与传统市盈率的对比分析
| 指标 | 市盈率（P/E） | 周期性调整市盈率（CAPE） |
|------|----------------|--------------------------|
| 数据窗口 | 最近一个会计年度净利润 | 近10年平均净利润       |
| 时间维度 | 短期导向       | 长期导向                 |
| 应用场景 | 单一公司估值   | 整体市场估值             |

CAPE相较于传统市盈率的优势在于其长期性和稳定性，能够更好地反映市场的整体估值水平。

#### 1.2.3 CAPE的周期性调整机制与实际应用
CAPE通过将股价与10年平均净利润进行对比，消除了短期经济周期对市场估值的影响。这种调整机制使得CAPE在预测市场泡沫和判断市场拐点方面具有重要意义。

### 1.3 CAPE的核心概念与理论基础

#### 1.3.1 周期性调整收益的定义与计算
周期性调整收益是指将过去10年的净利润进行几何平均，从而消除短期波动对收益的影响。其计算公式为：

$$\text{周期性调整收益} = \left(\prod_{i=1}^{10} \text{每股净利润}_i\right)^{1/10}$$

#### 1.3.2 通货膨胀调整与实际收益的关系
CAPE在计算过程中需要考虑通货膨胀的影响，通过实际收益（剔除通货膨胀影响的净利润）进行调整，以确保估值的准确性。

#### 1.3.3 市场情绪与长期投资价值的关联
市场情绪对资产价格具有重要影响，而CAPE通过长期收益的平均值，能够更准确地反映市场情绪对估值的影响。

### 1.4 CAPE在投资决策中的作用

#### 1.4.1 CAPE作为市场估值指标的适用场景
CAPE适用于整体市场估值分析，尤其是在判断市场是否被高估或低估时具有重要作用。

#### 1.4.2 CAPE在资产配置中的应用
投资者可以通过CAPE指标来优化资产配置策略，例如在市场估值过高的情况下减少股票配置。

#### 1.4.3 CAPE与投资周期的关系
CAPE能够帮助投资者识别投资周期中的拐点，从而做出更科学的投资决策。

### 1.5 本章小结
本章主要介绍了周期性调整市盈率（CAPE）的基本概念、理论基础及其在投资决策中的作用。CAPE通过长期收益的平均值，克服了传统市盈率的短期性和行业差异性，为投资者提供了更全面的市场估值工具。

## 第3章: CAPE的算法原理与实现

### 3.1 CAPE的计算步骤与流程

#### 3.1.1 数据收集与准备
需要收集过去10年的每股净利润数据。

#### 3.1.2 周期性调整收益的计算
通过几何平均计算过去10年的平均净利润。

#### 3.1.3 CAPE指标的最终计算
将股价与10年平均净利润进行对比，计算出CAPE值。

### 3.2 CAPE算法的Python实现

#### 3.2.1 数据获取与清洗
使用Python的pandas库获取股票数据并进行清洗。

#### 3.2.2 周期性调整收益的计算代码
```python
import pandas as pd

# 假设df为包含股价和净利润的DataFrame
# 计算过去10年的平均净利润
def calculate_cagr(df):
    net_income = df['净利润'].values
    cagr = (net_income.prod() ** (1/10))
    return cagr

cagr = calculate_cagr(df)
```

#### 3.2.3 CAPE指标的计算与可视化
```python
import matplotlib.pyplot as plt

# 计算CAPE值
cape = df['股价'] / cagr

# 绘制CAPE曲线图
plt.plot(cape.index, cape.values, label='CAPE')
plt.xlabel('时间')
plt.ylabel('CAPE值')
plt.legend()
plt.show()
```
