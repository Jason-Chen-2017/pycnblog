#### 5.2.1 图像分割代码

使用U-Net模型进行图像分割，代码示例如下：

```python
import tensorflow as tf
from tensorflow import keras

def unet_model(input_size=(256,256,3)):
    inputs = keras.Input(input_size)
    # 编码器部分
    conv1 = keras.layers.Conv2D(64, (3,3), padding='same', activation='relu')(inputs)
    conv2 = keras.layers.Conv2D(128, (3,3), padding='same', activation='relu')(conv1)
    # 解码器部分
    up3 = keras.layers.UpSampling2D((2,2))(conv2)
    conv3 = keras.layers.Conv2D(64, (3,3), padding='same', activation='relu')(up3)
    outputs = keras.layers.Conv2D(1, (1,1), activation='sigmoid')(conv3)
    return keras.Model(inputs=inputs, outputs=outputs)
```
