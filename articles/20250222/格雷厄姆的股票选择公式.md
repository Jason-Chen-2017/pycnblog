# 第1章: 价值投资的起源与格雷厄姆的投资理念

## 1.1 价值投资的起源
### 1.1.1 投资理论的演变
- 17世纪至19世纪：早期投资理论的萌芽，如复利思想。
- 20世纪初：本杰明·格雷厄姆提出价值投资理论，强调安全边际和内在价值。
- 20世纪中叶：巴菲特将格雷厄姆的理念发扬光大，使其成为现代投资的重要流派。

### 1.1.2 格雷厄姆与巴菲特的师徒关系
- 格雷厄姆是巴菲特的导师，两人共同撰写《证券分析》。
- 格雷厄姆的投资理念深刻影响了巴菲特的长期价值投资策略。

### 1.1.3 价值投资的核心理念
- 买入低于内在价值的股票，长期持有。
- 强调安全边际，即以低于内在价值的价格买入股票。

## 1.2 格雷厄姆的投资策略
### 1.2.1 格雷厄姆的选股标准
- 低市盈率：市盈率低于市场平均水平。
- 低市净率：市净率低于市场平均水平。
- 高股息率：股息率高于市场平均水平。
- 安全边际：买入价格低于内在价值。

### 1.2.2 安全边际的概念
- 安全边际=内在价值-买入价格。
- 安全边际越大，投资风险越小。

### 1.2.3 投资组合的构建原则
- 分散投资：避免过度集中。
- 长期持有：耐心等待价值回归。
- 定期调整：根据市场变化进行优化。

## 1.3 股票选择公式的背景与意义
### 1.3.1 传统选股方法的局限性
- 市场情绪波动影响短期股价。
- 传统技术分析难以捕捉长期价值。
- 短期指标波动无法反映企业真实价值。

### 1.3.2 格雷厄姆公式的核心思想
- 通过量化分析筛选出低估股票。
- 强调安全边际，降低投资风险。

### 1.3.3 公式在现代投资中的应用价值
- 为投资者提供了一套科学的选股方法。
- 适合长期价值投资者参考。

# 第2章: 格雷厄姆股票选择公式的原理与核心概念

## 2.1 格雷厄姆公式的基本原理
### 2.1.1 市盈率与市净率的定义
- 市盈率（P/E）= 股票价格/每股净利润。
- 市净率（P/B）= 股票价格/每股净资产。

### 2.1.2 格雷厄姆公式的核心要素
- 内在价值：企业未来现金流的现值。
- 市场价格：当前股票市价。
- 安全边际：内在价值与市场价格的差额。

### 2.1.3 公式的数学模型与计算方法
- 格雷厄姆公式：$$\text{安全边际} = \text{内在价值} \times \text{安全边际系数}$$
- 安全边际系数通常为1.5，即买入价格为内在价值的2/3。

## 2.2 核心概念与联系
### 2.2.1 格雷厄姆公式的核心概念属性对比表

| 指标 | 定义 | 重要性 | 计算公式 |
|------|------|--------|----------|
| 市盈率 | 股价/每股净利润 | 评估企业盈利能力 | $$P/E = \frac{P}{E}$$ |
| 市净率 | 股价/每股净资产 | 评估企业资产质量 | $$P/B = \frac{P}{B}$$ |
| 股息率 | 每股股息/股价 | 评估分红能力 | $$D/P = \frac{D}{P}$$ |
| 内在价值 | 未来现金流现值 | 核心评估指标 | $$V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}$$ |
| 安全边际 | 内在价值 - 买入价 | 投资安全指标 | $$\text{Margin of Safety} = V - P$$ |

# 第3章: 格雷厄姆股票选择公式的算法原理

## 3.1 算法原理讲解
### 3.1.1 公式的数学模型与公式推导
- 格雷厄姆公式：$$\text{安全边际} = \text{内在价值} \times \text{安全边际系数}$$
- 安全边际系数通常为1.5，即$$\text{安全边际} = 1.5 \times \text{内在价值}$$

### 3.1.2 用Python实现的算法代码示例
```python
import pandas as pd
import numpy as np

# 示例数据：股票列表
stocks = pd.DataFrame({
    '股价': [50, 60, 70, 80],
    '每股净利润': [10, 15, 20, 25],
    '每股净资产': [20, 25, 30, 35],
    '股息率': [0.05, 0.06, 0.07, 0.08]
})

# 计算市盈率
stocks['市盈率'] = stocks['股价'] / stocks['每股净利润']

# 计算市净率
stocks['市净率'] = stocks['股价'] / stocks['每股净资产']

# 计算内在价值（简化模型）
stocks['内在价值'] = (stocks['股价'] * 4) / stocks['市盈率']

# 计算安全边际
stocks['安全边际'] = stocks['内在价值'] * 1.5

print(stocks)
```

### 3.1.3 公式的实际应用案例分析
- 案例：假设某股票的股价为50元，每股净利润为10元，每股净资产为20元，股息率为5%。
- 市盈率=50/10=5，低于市场平均水平。
- 市净率=50/20=2.5，低于市场平均水平。
- 内在价值= (50*4)/5=40元。
- 安全边际=40*1.5=60元。
- 结论：当股价低于60元时，该股票具有安全边际。

## 3.2 数学模型与公式
### 3.2.1 市盈率计算公式
$$\text{市盈率} = \frac{\text{股价}}{\text{每股净利润}}$$

### 3.2.2 市净率计算公式
$$\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}$$

### 3.2.3 格雷厄姆公式综合评价模型
$$\text{安全边际} = \text{内在价值} \times \text{安全边际系数}$$

```python
import pandas as pd
import numpy as np

# 获取股票数据（示例）
data = {
    '股票代码': ['AAPL', 'MSFT', 'GOOGL', 'AMZN'],
    '股价': [300, 350, 250, 400],
    '每股净利润': [10, 15, 8, 12],
```

```python
# 计算市盈率和市净率

df['内在价值'] = (df['股价'] * 4) / df['市盈率']
df['安全边际'] = df['内在价值'] * 1.5
```
