## 第5章: 算法原理与数学模型

### 5.1 算法原理的数学模型

#### 技术质量评估模型
$$
\text{技术质量评分} = w_1 \times \text{创新性} + w_2 \times \text{实用性} + w_3 \times \text{法律稳定性}
$$

其中，$$w_1 + w_2 + w_3 = 1$$

#### 组合防御性评估模型
$$
\text{防御性评分} = \sum_{i=1}^{n} (\text{专利i的法律稳定性} \times \text{专利i的覆盖范围})
$$

### 5.2 算法实现的Python代码

```python
def assess_technical_quality(patents):
    scores = []
    for patent in patents:
        innovation = patent['创新性']
        utility = patent['实用性']
        legal_stability = patent['法律稳定性']
        score = 0.4 * innovation + 0.3 * utility + 0.3 * legal_stability
        scores.append(score)
    return scores

def assess_defensive_quality(patents):
    defensive_score = 0
    for patent in patents:
        legal_stability = patent['法律稳定性']
        coverage = patent['覆盖范围']
        defensive_score += legal_stability * coverage
    return defensive_score
```
