### 3.2 均值-方差优化算法

#### 3.2.1 均值-方差优化的定义
均值-方差优化是一种通过优化组合的期望收益和方差来实现最优配置的算法。

#### 3.2.2 均值-方差优化的实现步骤
1. 确定各资产的期望收益和协方差矩阵。
2. 建立优化模型。
3. 通过求解优化问题得到最优权重。

#### 3.2.3 均值-方差优化的Python实现

```python
import numpy as np
import scipy.optimize as optimize

def portfolio_optimization(returns):
    n = len(returns.columns)
    cov_matrix = returns.cov()
    mu = returns.mean()
    
    # 定义优化目标函数
    def objective(weights):
        return (weights.T @ mu) * 100 - 0.5 * (weights.T @ cov_matrix @ weights)
    
    # 约束条件
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    
    # 初始权重
    init_weights = np.array([1.0/n]*n)
    
    # 使用scipy.optimize求解
    result = optimize.minimize(objective, init_weights, method='SLSQP', constraints=constraints)
    
    return result.x

# 示例数据
returns = pd.DataFrame({
    '股票': [0.1, 0.05, 0.02, -0.03],
    '债券': [0.03, 0.02, 0.04, 0.01]
})
weights = portfolio_optimization(returns)
print("最优权重:", weights)
```

#### 5.2.1 资产配置优化代码
```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

# 示例数据
returns = pd.DataFrame({
    '股票': [0.1, 0.05, 0.02, -0.03],
    '债券': [0.03, 0.02, 0.04, 0.01]
})

# 定义优化函数
def objective(weights, returns):
    return -weights.T @ returns.mean() + 0.5 * weights.T @ returns.cov() @ weights

# 约束条件
constraints = [
    {'type': 'eq', 'fun': lambda w: sum(w) - 1},
    {'type': 'ineq', 'fun': lambda w: w - 0}
]

# 初始权重
init_weights = np.array([0.5, 0.5])

# 使用SLSQP求解
result = minimize(objective, init_weights, method='SLSQP', constraints=constraints)

# 输出结果
print("最优权重:", result.x)
```
