# 第一部分: 全球股市估值的背景与核心概念

## 第1章: 全球股市估值的背景介绍

### 1.1 股票市场的基本概念
股票市场是投资者交易公司股份的场所，反映了企业的市场价值。股市估值是评估企业价值的重要手段，通常通过市盈率（P/E）、市净率（P/B）等指标进行衡量。

### 1.2 股市估值的重要性
准确的估值有助于投资者做出明智的投资决策，避免因高估或低估企业价值而造成的损失。

### 1.3 全球化视角下的股市估值
随着全球经济一体化，投资者需要关注全球市场的动态，包括宏观经济指标、行业趋势和公司基本面。

## 第2章: 全球股市估值的核心概念与联系

### 2.1 股市估值的核心要素
- **市盈率（P/E）**：衡量股价相对于每股收益的比率，公式为$$P/E = \frac{Price}{Earnings}$$。
- **市净率（P/B）**：衡量股价相对于每股净资产的比率，公式为$$P/B = \frac{Price}{Book\ Value}$$。
- **股息率**：衡量股票的分红能力，公式为$$Dividend\ Yield = \frac{Dividend}{Price}$$。

### 2.2 生物塑料在医疗器械中的应用潜力
生物塑料是一种可生物降解的材料，广泛应用于医疗器械领域，如手术器械、包装材料等，具有环保和可持续的优势。
