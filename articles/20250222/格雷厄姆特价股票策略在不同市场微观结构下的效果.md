## 第3章: 格雷厄姆特价股票策略的核心原理

### 3.1 格雷厄姆投资策略的数学模型
- 格雷厄姆策略的核心公式
  - 内在价值公式：$$内在价值 = \frac{E}{P} + \frac{D}{P}$$
  - 其中，E为息税前利润，P为价格，D为债务
- 安全边际的计算
  - 安全边际 = 内在价值 - 市场价格
  - 安全边际率 = 安全边际 / 内在价值

### 3.2 特价股票的识别方法
- 特价股票的识别标准
  - 市盈率（P/E）低于行业平均水平
  - 市净率（P/B）低于1
  - 股息率高于行业平均水平
- 特价股票的识别指标
  - 市场价格低于清算价值
  - 市盈率和市净率双低
  - 股票价格波动性低

### 3.3 市场微观结构对策略的影响
- 市场流动性对策略的影响
  - 流动性不足可能导致低估股票难以变现
  - 流动性充裕时，低估股票更容易被发现
- 市场深度对策略的影响
  - 深度不足时，策略风险增加
  - 深度充足时，策略收益更稳定
- 市场参与者行为对策略的影响
  - 机构投资者对低估股票的挖掘
  - 散户投资者的非理性行为

  import pandas as pd
  import numpy as np

  def calculate_intrinsic_value(e, p, d):
      return (e + d) / p

  def calculate_margin(v, p):
      return v - p

  # 示例数据
  df = pd.DataFrame({
      'E': [100, 200, 300],
      'P': [50, 60, 70],
      'D': [50, 60, 70]
  })
  
  # 计算内在价值
  df['V'] = df.apply(lambda x: calculate_intrinsic_value(x['E'], x['P'], x['D']), axis=1)
  # 计算安全边际
  df['Margin'] = df.apply(lambda x: calculate_margin(x['V'], x['P']), axis=1)
  print(df)
