投资组合优化通过合理分配资金，降低投资组合的整体风险，同时最大化收益。现代投资组合理论是投资组合优化的重要理论基础。

##### 5.2.2 投资组合优化的实现步骤  
1. 确定可选投资标的；  
2. 计算各标的的预期收益和风险；  
3. 使用优化算法确定最优投资组合。

##### 5.2.3 投资组合优化的代码实现  

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, covariance, target_return):
    n = len(returns)
    # 目标函数：最小化风险（方差）
    def objective(x):
        return np.dot(x.T, np.dot(covariance, x))

    # 约束条件：收益等于目标收益
    def constraint(x):
        return np.sum(x * returns) - target_return

    # 初始猜测
    x0 = np.array([1.0 / n] * n)

    # 求解
    result = minimize(objective, x0, constraints=[{'type': 'eq', 'fun': constraint}], bounds=[(0, 1)] * n)

    return result.x
```
