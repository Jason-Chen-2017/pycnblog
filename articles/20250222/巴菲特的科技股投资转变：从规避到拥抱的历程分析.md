巴菲特的价值投资理念强调购买价格低于内在价值的股票，寻找具有强大竞争优势和持续盈利能力的企业。他早期主要投资于传统行业，如制造业和零售业，偏好那些财务稳定、股息稳定的公司。

科技行业以其高波动性和高风险著称，巴菲特早期认为科技公司的盈利能力不稳定，难以预测，且技术变革可能导致企业快速过时。因此，他倾向于避免投资科技股。

##### 1.1.3 早期投资案例分析

例如，巴菲特投资的可口可乐和富国银行，这些企业具有稳定的财务状况和长期的增长潜力，符合他早期的价值投资标准。

#### 1.2 科技股投资的兴起

##### 1.2.1 科技行业的快速发展

20世纪末至21世纪初，科技行业经历了互联网革命和数字化转型，科技公司如微软、苹果和亚马逊等开始展现出强大的增长潜力和市场影响力。

##### 1.2.2 巴菲特对科技股的规避原因

他认为科技股的高增长伴随着高风险，且科技公司的盈利能力不稳定，难以满足他对于确定性和稳定性的要求。

##### 1.2.3 市场变化与投资策略的调整

随着科技行业的重要性日益凸显，巴菲特意识到科技股在现代经济中的核心地位，逐步调整投资策略，开始关注具有强大护城河和长期增长潜力的科技公司。

##### 7.2.3 风险评估

```python
import numpy as np
import pandas as pd

def calculate_risk(ticker):
    df = yf.download(ticker, start='2020-01-01', end='2023-12-31')
    returns = df['Close'].pct_change().dropna()
    volatility = returns.std() * np.sqrt(252)
    return volatility

# 计算苹果的风险
risk_aapl = calculate_risk('AAPL')
print(f"Apple的波动率：{risk_aapl}")
```

##### 7.3.1 构建投资组合

```python
import pandas as pd
import numpy as np

tickers = ['AAPL', 'AMZN', 'MSFT']
weights = [0.4, 0.3, 0.3]

portfolios = []
for i in range(len(tickers)):
    data = yf.download(tickers[i], start='2020-01-01', end='2023-12-31')
    portfolios.append(data['Close'])

portfolio_df = pd.DataFrame(portfolios).T
portfolio_df.columns = tickers

# 计算投资组合的回报
portfolio_return = (portfolio_df.pct_change().mean() * weights).sum()
```

##### 7.3.2 风险调整

```python
def portfolio_risk(weights, returns):
    covariance_matrix = np.cov(returns)
    portfolio_variance = np.dot(weights.T, np.dot(covariance_matrix, weights))
    return np.sqrt(portfolio_variance)

# 计算投资组合的波动率
returns = portfolio_df.pct_change().dropna().values
risk = portfolio_risk(weights, returns)
print(f"投资组合的波动率：{risk}")
```
