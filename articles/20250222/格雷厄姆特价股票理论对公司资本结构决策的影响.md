## 第一部分: 格雷厄姆投资理论的背景与核心概念

### 第1章: 格雷厄姆投资理论概述

#### 1.1 价值投资的鼻祖：本杰明·格雷厄姆
- **定义**：格雷厄姆是20世纪最著名的价值投资者之一，强调以低于内在价值的价格购买股票。
- **核心思想**：投资应基于企业的内在价值，而非市场波动。
- **影响**：巴菲特、彼得·林奇等投资者深受其影响。

#### 1.2 特价股票的定义与特征
- **定义**：价格远低于内在价值的股票，具有较高的安全边际。
- **特征**：
  - 低市盈率或低市净率。
  - 高股息率。
  - 企业盈利能力稳定。

### 第2章: 格雷厄姆投资理论的核心概念

#### 2.1 安全边际
- **定义**：购买价格与内在价值之间的差距，确保投资的安全性。
- **计算**：
  \[
  \text{安全边际} = \text{内在价值} - \text{市场价格}
  \]
- **作用**：减少市场波动对企业资本结构的影响。

#### 2.2 内在价值
- **定义**：企业未来现金流的现值，反映其真实价值。
- **计算模型**：
  \[
  \text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t}
  \]
  其中，\( r \) 为折现率。

#### 2.3 市场先生
- **定义**：比喻市场情绪，投资者应避免受其短期波动影响。
- **影响**：资本结构决策需考虑市场情绪的长期影响。

## 第二部分: 格雷厄姆理论与资本结构的联系

### 第3章: 资本结构的基本概念

#### 3.1 资本结构的定义
- 资本结构指企业债务与 equity 的比例，影响资本成本和风险。

#### 3.2 资本成本的计算
- 债务成本：考虑税盾效应。
  \[
  \text{债务成本} = \text{借款利率} \times (1 - \text{税率})
  \]
- 股权成本：使用CAPM模型计算。
  \[
  \text{股权成本} = r_f + \beta \times (r_m - r_f)
  \]

#### 3.3 资本结构与企业价值的关系
- 企业价值最大化是资本结构优化的目标。

### 第4章: 格雷厄姆理论对资本结构的影响

#### 4.1 安全边际对资本结构的保护作用
- 通过安全边际降低市场波动对资本结构的影响。

#### 4.2 内在价值对资本结构的指导意义
- 内在价值指导企业融资决策，避免过度杠杆。

#### 4.3 市场情绪对资本结构的动态影响
- 市场情绪波动影响资本成本，需动态调整资本结构。

#### 6.1 基于Python的内在价值计算
```python
def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(flow / (1 + discount_rate) ** t for t, flow in enumerate(cash_flows))
```

def calculate_margin_of_safety(intrinsic_value, market_price):
