## 第1章: 投资成本的基本概念

### 1.1 投资成本的定义与分类

#### 1.1.1 投资成本的定义
投资成本是指在投资活动中所涉及的所有费用，包括显性成本和隐性成本。显性成本是直接可见的支出，如资金的时间价值、管理费用等；隐性成本则是间接产生的费用，如机会成本、风险成本等。

#### 1.1.2 投资成本的分类
投资成本可以分为以下几类：
- **显性成本**：直接支出，如购买资产的本金、交易费用、管理费用等。
- **隐性成本**：间接支出，如机会成本、时间成本、风险成本等。
- **固定成本**：在一定范围内不变的成本，如租金、 salaries。
- **可变成本**：随业务量变化的成本，如原材料、劳动力成本。

#### 1.1.3 投资成本的核心要素
投资成本的核心要素包括：
- 资金的时间价值
- 交易费用
- 管理费用
- 风险成本
- 机会成本

### 1.2 投资成本计算的基本原理

#### 1.2.1 投资成本计算的基本方法
投资成本计算的基本方法包括：

#### 1.2.2 投资成本与投资收益的关系
投资成本与投资收益密切相关。高成本不一定带来高收益，但成本是收益的必要条件。通过合理控制成本，可以提高投资收益。

#### 1.2.3 投资成本计算的边界与外延
投资成本的边界包括直接相关费用，而外延则包括间接相关费用，如税收、通货膨胀等。

## 第2章: 投资成本计算的算法原理

### 2.1 投资成本计算的数学模型

#### 2.1.1 投资成本的基本公式
投资成本的计算公式：
$$ C = \sum_{i=1}^{n} c_i $$
其中，$C$ 表示总成本，$c_i$ 表示第 $i$ 项成本。

#### 2.1.2 投资成本的加权计算
加权计算公式：
$$ C_{weighted} = \sum_{i=1}^{n} w_i \cdot c_i $$
其中，$w_i$ 是第 $i$ 项成本的权重。

#### 2.1.3 投资成本的净现值计算
净现值（NPV）公式：
$$ NPV = \sum_{t=1}^{T} \frac{CF_t}{(1 + r)^t} $$
其中，$CF_t$ 是第 $t$ 期的现金流，$r$ 是折现率。

#### 2.2.3 投资成本计算的Python实现
```python
def calculate_investment_cost(costs, weights=None):
    if weights is not None:
        weighted_costs = [cost * weight for cost, weight in zip(costs, weights)]
        total_cost = sum(weighted_costs)
    else:
        total_cost = sum(costs)
    return total_cost

# 示例输入
costs = [100, 200, 300]
weights = [0.3, 0.4, 0.3]
# 计算加权总成本
total_cost = calculate_investment_cost(costs, weights)
print(f"加权总成本为: {total_cost}")
```
