### 第3章: 格雷厄姆理论在社会影响力债券中的算法原理

#### 3.1 算法原理讲解
- **3.1.1 评估流程图**  
  ```mermaid
  graph LR
  A[开始] --> B[收集债券数据]
  B --> C[计算内在价值]
  C --> D[评估社会影响力]
  D --> E[计算安全边际]
  E --> F[得出综合评分]
  F --> G[结束]
  ```
- **3.1.2 核心算法代码**  
  ```python
  def calculate_intrinsic_value(bond_data):
      E = bond_data['enterprise_value']
      n = bond_data['shareholder_equity']
      return E / n

  def social_impact_score(bond_data):
      projects = bond_data['project_types']
      impact_rating = 0
      for p in projects:
          impact_rating += p['impact_score']
      return impact_rating / len(projects)

  def bond_assessment(bond_data):
      IV = calculate_intrinsic_value(bond_data)
      SIS = social_impact_score(bond_data)
      market_price = bond_data['market_price']
      safety_margin = (IV - market_price) / IV * 100
      return {'intrinsic_value': IV, 'social_impact_score': SIS, 'safety_margin': safety_margin}
  ```

#### 3.2 算法数学模型
- **3.2.1 内在价值公式**  
  $$ V = \frac{E}{n} $$
- **3.2.2 社会影响力评分公式**  
  $$ SIS = \frac{\sum_{i=1}^{m} impact\_score_i}{m} $$
- **3.2.3 安全边际公式**  
  $$ SM = \frac{V - P}{V} \times 100\% $$
  其中$P$是债券的市场价格。

#### 3.3 算法实现与解读
- **3.3.1 内在价值计算**  
  通过企业价值与股东权益的比率计算债券的内在价值。
- **3.3.2 社会影响力评分**  
  根据债券支持的项目类型和影响力评分加权平均，得出社会影响力评分。
- **3.3.3 综合评估**  
  结合内在价值、社会影响力评分和市场价格，计算安全边际，得出综合评分。
