## 第一部分: 背景介绍与核心概念

### 第1章: 市场情绪与彼得·林奇的投资理念

#### 1.1 市场情绪的定义与背景
- **市场情绪**：投资者对市场未来走势的心理预期，影响资产价格波动。
- **彼得·林奇的理论**：市场情绪是投资决策的关键因素，尤其在资产配置中至关重要。

#### 1.2 彼得·林奇的投资理念
- **长期投资**：关注公司基本面，避免短期市场波动干扰。
- **市场情绪的重要性**：通过分析市场情绪，识别投资机会和风险。

### 第2章: 不同资产类别的概述

#### 2.1 股票市场
- **市场情绪表现**：牛市中的过度乐观和熊市中的过度悲观。
- **彼得·林奇的观点**：市场情绪波动会影响股价，但长期价值取决于公司基本面。

#### 2.2 债券市场
- **市场情绪表现**：债券价格受利率影响，市场情绪影响债券收益率。
- **彼得·林奇的观点**：债券是股票的补充，市场情绪波动较小。

#### 2.3 其他资产类别
- **市场情绪表现**：如房地产和黄金，市场情绪影响其价格波动。
- **彼得·林奇的观点**：多样化投资，降低市场情绪波动的影响。

      positive_words = ['positive', 'good']
      negative_words = ['negative', 'bad']
      count_positive = sum(1 for word in sentences if word in positive_words)
      count_negative = sum(1 for word in sentences if word in negative_words)
      return (count_positive - count_negative) / (count_positive + count_negative) * 100
