```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 股市估值模型
def stock_valuation_model(data):
    model = LinearRegression()
    model.fit(data[['revenue', 'profit']], data['valuation'])
    return model.predict(data[['revenue', 'profit']])

# 水资源分配模型
def water_allocation_model(data):
    total_water = data['total_water'].sum()
    allocation = {}
    for region in data['region']:
        allocation[region] = total_water * data[data['region'] == region]['weight'].iloc[0]
    return allocation
```

# 第4章 数学模型与公式

## 4.1 数学模型概述

### 4.1.1 股市估值模型
$$ P = \alpha E + \beta D $$
其中，\( P \) 是股票价格，\( E \) 是企业盈利，\( D \) 是股息率，\(\alpha\) 和 \(\beta\) 是回归系数。

### 4.1.2 水资源分配模型
$$ W = \frac{\sum w_i x_i}{\sum x_i} $$
其中，\( W \) 是分配水量，\( w_i \) 是地区权重，\( x_i \) 是地区需求。

### 4.1.3 关联模型
$$ C = \gamma P + \delta W $$
其中，\( C \) 是综合成本，\( P \) 是股市估值，\( W \) 是水资源分配，\(\gamma\) 和 \(\delta\) 是系数。

## 4.2 公式举例说明

### 4.2.1 股市估值举例
$$ P = 1.5E + 0.8D $$

### 4.2.2 水资源分配举例
$$ W = \frac{100 \times 0.6}{100} = 60 $$
