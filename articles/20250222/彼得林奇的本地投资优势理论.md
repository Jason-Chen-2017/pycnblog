### 第1章: 投资理论的背景

#### 1.1 现代投资学的演进

现代投资学经历了从传统金融学到行为金融学的演变。传统金融学强调市场有效性和理性决策，而行为金融学则关注投资者的心理偏差和非理性行为。彼得林奇的本地投资优势理论结合了两者的优点，强调在本地市场中挖掘投资机会，通过深入分析市场结构和竞争优势来制定投资策略。

#### 1.2 本地投资优势理论的提出

彼得林奇提出，本地市场具有独特的优势，尤其是在区域经济、产业结构和市场参与者行为方面。与全国或全球市场相比，本地市场更易于理解和预测，投资者可以利用对本地市场的熟悉度来获取超额收益。

#### 1.3 理论的核心问题与目标

理论的核心问题是：如何在本地市场中识别竞争优势，并通过投资策略实现超额回报。目标是帮助投资者在本地市场中找到具有持续竞争优势的企业，并通过长期持有实现价值增长。

3. **市场参与者行为**：本地市场的参与者可能具有特定的行为模式，便于投资者预测和利用。

#### 3.2 本地市场的特殊性

3. **政策影响**：地方政府的政策对本地市场的影响更为直接。

### 第8章: 项目实战

#### 8.2 核心实现源代码

```python
import pandas as pd
import matplotlib.pyplot as plt

# 假设我们有一个本地市场的数据
data = {
    '本地市场增长率': [0.1, 0.12, 0.08, 0.15],
    '全国市场增长率': [0.05, 0.06, 0.07, 0.08]
}

df = pd.DataFrame(data)

# 计算竞争优势指数
df['竞争优势指数'] = df['本地市场增长率'] / df['全国市场增长率']

# 绘制竞争优势指数图表
plt.plot(df.index, df['竞争优势指数'], marker='o')
plt.title('竞争优势指数')
plt.xlabel('样本点')
plt.ylabel('竞争优势指数')
plt.show()
```
