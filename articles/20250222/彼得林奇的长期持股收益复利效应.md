## 第1章: 长期持股与复利效应的背景介绍

### 1.1 长期持股的核心概念

#### 1.1.1 长期持股的定义
长期持股是指投资者将资金投入优质资产，并长期持有，以获得资产增值的策略。其核心在于选择优秀的公司或资产，避免频繁交易，从而降低交易成本和税务负担。

#### 1.1.2 复利效应的数学模型
复利效应是指投资收益的再投资产生的额外收益。数学上，复利的公式为：

$$
A = P \times (1 + r)^t
$$

其中：
- \(A\) 是最终金额
- \(P\) 是本金
- \(r\) 是年化收益率
- \(t\) 是投资时间（年）

#### 1.1.3 长期持股与复利效应的关系
长期持股为复利效应提供了时间杠杆，使收益呈指数级增长。通过长期持有优质资产，投资者可以最大化复利的效果。

### 1.2 投资中的复利效应

#### 1.2.1 复利的定义与公式
复利是一种投资增长方式，与单利不同，复利会将每期的收益再投资，从而产生滚雪球效应。例如，投资1元，年化收益率10%，10年后的复利收益为：

$$
1 \times (1 + 0.1)^{10} = 2.5937
$$

#### 1.2.2 复利的计算方法
复利计算需要考虑本金、收益率和投资时间。通过公式：

$$
\text{最终收益} = P \times (1 + r)^t
$$

可以快速计算出投资收益。

#### 1.2.3 复利在投资中的应用
复利效应在股票、基金等长期投资中尤为重要。通过长期持有优质资产，投资者可以最大化复利收益。

### 3.2 长期持股的收益预测算法

#### 3.2.1 收益预测的数学模型
使用几何平均收益率进行预测：

$$
\text{几何平均收益率} = \left( \prod_{i=1}^{n} (1 + r_i) \right)^{1/n} - 1
$$

#### 3.2.2 收益预测的算法实现

```python
def geometric_mean_return(returns):
    product = 1
    for r in returns:
        product *= (1 + r)
    return (product ** (1/len(returns))) - 1

# 示例：收益率分别为0.1, 0.05, 0.08
returns = [0.1, 0.05, 0.08]
print(geometric_mean_return(returns))  # 输出：0.0756
```

#### 3.2.3 收益预测的案例分析
通过对历史收益率的几何平均计算，预测未来收益，帮助投资者制定长期持股策略。

def build_portfolio(stocks, weights):
    portfolio = pd.DataFrame(columns=['Stock', 'Weight'])
