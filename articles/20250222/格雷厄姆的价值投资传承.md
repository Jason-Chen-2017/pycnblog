## 摘要：  
《格雷厄姆的价值投资传承》一书深入探讨了价值投资之父本杰明·格雷厄姆的投资理念，并分析了这些理念如何在现代投资实践中得到传承和发展。文章通过逻辑清晰的结构，结合技术语言和专业分析，详细阐述了价值投资的核心概念、算法原理、系统设计以及实际项目案例。本书旨在为投资者提供一种基于格雷厄姆思想的科学投资方法，帮助读者在复杂多变的市场环境中实现稳健投资。

  - 3.3.1 现代投资组合理论（MPT）的简要介绍  
  - 3.3.2 使用 Python 实现 MPT 的代码示例  
  ```python  
  import numpy as np  
  import pandas as pd  

  # 示例数据  
  returns = np.array([[0.1, 0.2, 0.15],  
                      [0.05, 0.1, 0.08],  
                      [0.15, 0.25, 0.2]])  

  # 计算协方差矩阵  
  cov_matrix = np.cov(returns)  

  # 计算最优投资组合  
  weights = np.linalg.inv(cov_matrix).sum()  
  weights = weights / sum(weights)  
  ```
