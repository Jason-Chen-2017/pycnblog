#### 1.1 巴菲特的投资哲学

沃伦·巴菲特是世界上最著名的投资者之一，他的投资理念深受两位导师的影响：本杰明·格雷厄姆和查理·芒格。巴菲特的投资哲学以价值投资为核心，强调安全边际、长期投资和内在价值的计算。他的成功不仅在于对市场的理解，更在于他对人性的深刻洞察。

## 第二部分：格雷厄姆的价值投资理论

### 第2章：格雷厄姆的生平与主要贡献

#### 2.1 格雷厄姆的生平简介

本杰明·格雷厄姆（1897-1976）是20世纪最著名的投资思想家之一。他出生于纽约，早年经历了经济大萧条的冲击，这使他形成了稳健的投资理念。他在哥伦比亚大学教授证券分析，培养了包括巴菲特在内的众多投资人才。

#### 2.2 格雷厄姆的投资理念

格雷厄姆的价值投资理论强调安全边际和内在价值的计算。他认为，股票的内在价值是其未来现金流的现值，而市场价格经常偏离这一价值。投资者应买入被市场低估的股票，并在市场恐慌时加仓。

#### 2.3 格雷厄姆的核心观点

- **安全边际**：买入价格低于内在价值的股票，以降低风险。
- **逆市场思维**：在市场下跌时寻找机会，而不是随市场波动。
- **价值评估**：强调对公司基本面的深入分析，尤其是资产负债表。

#### 3.1 格雷厄姆的安全边际理论

格雷厄姆的安全边际理论要求投资者在买入股票时留有余地，确保即使价格波动，也能保证本金安全。这一理论在巴菲特的投资中得到充分体现，尤其是在他投资可口可乐和苹果公司时，他始终坚持安全边际的原则。

#### 3.2 格雷厄姆的价值评估方法

格雷厄姆的内在价值计算方法是巴菲特的基础。他强调通过分析财务报表，尤其是现金流和资产净值，来评估公司的真正价值。这种方法帮助巴菲特识别出那些被市场低估的优秀企业。

芒格的决策框架强调理性思考和避免情绪化决策。他提倡在决策前列出所有可能的后果，并通过逆向思维寻找问题的解决方案。

#### 8.2 核心实现源代码

以下是计算股票内在价值的Python代码示例：

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(stock_data):
    # 假设stock_data是一个包含财务数据的DataFrame
    # 计算自由现金流
    free_cash_flow = stock_data['自由现金流']
    # 计算加权平均资本成本
    wacc = stock_data['WACC']
    # 计算永续增长率
    perpetual_growth_rate = stock_data['永续增长率']
    
    # 计算内在价值
    intrinsic_value = (free_cash_flow * (1 + perpetual_growth_rate)) / (wacc - perpetual_growth_rate)
    return intrinsic_value

# 示例数据
data = {
    '自由现金流': [100, 150, 200],
    'WACC': [8%, 8%, 8%],
    '永续增长率': [3%, 3%, 3%]
}
stock_data = pd.DataFrame(data)

# 计算内在价值
intrinsic_value = calculate_intrinsic_value(stock_data)
print(intrinsic_value)
```

#### 8.3 案例分析

以巴菲特投资可口可乐为例，我们可以通过上述代码计算其内在价值。假设可口可乐的自由现金流为100亿美元，WACC为8%，永续增长率为3%，则其内在价值为：

$$
\text{内在价值} = \frac{100 \times (1 + 0.03)}{0.08 - 0.03} = \frac{103}{0.05} = 2060 \text{亿美元}
$$

如果市场价格低于2060亿美元，巴菲特可能会考虑买入。
