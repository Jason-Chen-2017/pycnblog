## 第三章: 投资组合优化的数学模型

### 3.1 现代投资组合理论（MPT）
- MPT的核心假设
  - 投资者是理性的，市场是有效的
- 投资组合的期望收益和方差计算
  - 期望收益公式：$$E(r_p) = \sum w_i E(r_i)$$
  - 方差公式：$$Var(r_p) = \sum w_i w_j Cov(r_i, r_j)$$
- 马科维茨的有效前沿理论
  - 有效前沿的定义与绘制方法

### 3.2 投资组合优化的算法实现
- 使用拉格朗日乘数法求解优化问题
  - 建立目标函数与约束条件
- 使用Python代码实现投资组合优化（示例）
  ```python
  import numpy as np
  from scipy.optimize import minimize
  
  # 示例：最小方差投资组合优化
  def portfolio_variance(weights, covariance_matrix):
      return np.dot(weights.T, np.dot(covariance_matrix, weights))
  
  covariance_matrix = np.array([[0.01, 0.005], [0.005, 0.02]])
  initial_weights = [0.5, 0.5]
  
  result = minimize(portfolio_variance, initial_weights, args=covariance_matrix, 
                   method='SLSQP', bounds=[(0,1), (0,1)])
  print(result.x)
  ```

### 3.3 投资组合优化的数学公式
- 如何通过优化算法找到最优投资组合
  - 使用均值-方差优化模型
  - 示例：$$\text{最小化 } \sum_{i,j} w_i w_j \sigma_{i,j}$$
  - 约束条件：$$\sum w_i = 1$$

### 5.2 核心代码实现
- 代码实现：投资组合优化算法
  ```python
  import numpy as np
  from scipy.optimize import minimize
  
  def portfolio_variance(weights, covariance_matrix):
      return np.dot(weights.T, np.dot(covariance_matrix, weights))
  
  def constraint(weights):
      return np.sum(weights) - 1
  
  # 示例数据：两只资产的协方差矩阵
  covariance_matrix = np.array([[0.01, 0.005], [0.005, 0.02]])
  
  # 使用SLSQP方法求解最小方差问题
  result = minimize(portfolio_variance, [0.5, 0.5], args=covariance_matrix, 
                   method='SLSQP', constraints={'type': 'eq', 'fun': constraint})
  
  print("最优权重为:", result.x)
  ```
