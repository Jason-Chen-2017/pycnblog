#### 第1章：芒格"远离"策略的背景与核心理念

##### 1.1 问题背景：为什么知道自己不懂什么很重要？

在投资和决策领域，知识的边界是一个关键因素。芒格的“远离”策略强调识别自己的知识盲区，避免在不了解的领域进行决策。这种策略的重要性在于，错误的决策往往源于对未知领域的过度自信。

- **1.1.1 投资与决策中的知识边界问题**  
  投资者常常倾向于超出自己的知识范围进行决策，这可能导致重大损失。芒格强调，识别能力圈的边界是成功的基石。

- **1.1.2 知识的局限性与决策风险**  
  人的知识是有限的，超出能力范围的决策往往伴随着高风险。芒格通过“远离”策略，帮助投资者避免这些风险。

- **1.1.3 芒格策略的哲学基础**  
  芒格的策略基于对人类认知局限性的深刻理解，强调谦逊和谨慎。

##### 1.2 问题描述：芒格"远离"策略的核心要素

芒格的策略不仅仅是避免错误，还包括构建一个稳健的知识框架。

- **1.2.1 知识的边界与能力圈的定义**  
  能力圈是指个人在知识和经验上的优势领域，超出这个范围的决策应尽量避免。

- **1.2.2 避免决策中的认知偏差**  
  认知偏差如过度自信会导致错误决策，芒格策略通过限制决策范围减少这种偏差。

- **1.2.3 谨慎与风险控制的内在联系**  
  谨慎是风险控制的核心，芒格策略通过谨慎避免重大风险。

##### 1.3 问题解决：芒格策略的实际应用

芒格策略在投资和其他决策中的应用实例。

- **1.3.1 投资中的"远离"策略**  
  避免投资于看不懂的公司或行业，专注于熟悉领域。

- **1.3.2 日常决策中的"远离"策略**  
  在生活中，避免做出超出知识范围的决策。

- **1.3.3 芒格策略与其他决策模型的对比**  
  对比传统投资模型，芒格策略更注重风险控制。

##### 1.4 边界与外延：芒格策略的适用范围

芒格策略的应用场景和局限性。

- **1.4.1 芒格策略的适用场景**  
  适用于投资、决策等领域，帮助降低风险。

def calculate_risk_probability(knowledge_boundary):
    if knowledge_boundary == "明确":
        return 0.1
