## 第1章 心理倾向理论的背景与核心概念

### 1.1 心理倾向的定义与背景

芒格的“心理倾向”理论是行为心理学与投资决策结合的重要成果。心理倾向指个体在特定情境下表现出的稳定心理特征或行为模式，这些倾向在金融市场中往往导致非理性决策。

- **定义**：心理倾向是影响投资者决策的核心因素，包括贪婪、恐惧、从众心理等。
- **背景**：金融市场中，投资者的非理性行为导致市场波动，芒格通过研究这些行为模式提出了心理倾向理论。

### 1.2 心理倾向的核心要素

心理倾向的核心要素包括：

| 倾向类型 | 特征描述 | 示例场景 |
|----------|----------|----------|
| 贪婪     | 过度追求收益 | 投资者在牛市中盲目追涨 |
| 恐惧     | 过度规避风险 | 投资者在熊市中恐慌抛售 |
| 从众心理 | 跟随市场趋势 | 投资者盲目跟随市场热点 |

## 第2章 心理倾向理论的核心模型

### 2.1 心理倾向的分类与特征

心理倾向可以分为九种主要类型：

1. **贪婪**：追求短期收益，忽视长期风险。
2. **恐惧**：过度担忧市场下跌，错过投资机会。
3. **从众心理**：跟随市场主流，忽视独立判断。
4. **确认偏差**：倾向于寻找支持自己观点的证据。
5. **过度自信**：高估自己的判断能力。
6. **损失厌恶**：对损失的厌恶大于对收益的追求。
7. **锚定效应**：依赖于初始信息做决策。
8. **社会认同**：因群体影响改变决策。
9. **心理账户**：将资金分割管理，影响决策。

### 2.2 心理倾向与市场行为的关系

心理倾向通过影响投资者情绪，进而影响市场价格。例如，贪婪导致股价泡沫，恐惧引发市场崩盘。

import pandas as pd
import numpy as np

def calculate_emotion_index(data):
    weights = np.array([0.3, 0.2, 0.1, 0.4])
    tendencies = data[['greed', 'fear', 'herd', 'confidence']]
    emotion_index = np.dot(weights, tendencies.T)
    return emotion_index

# 示例数据
data = pd.DataFrame({
    'greed': [0.8, 0.5, 0.3],
    'fear': [0.2, 0.4, 0.6],
    'herd': [0.7, 0.3, 0.2],
    'confidence': [0.5, 0.6, 0.8]
})

emotion_index = calculate_emotion_index(data)
print(emotion_index)
