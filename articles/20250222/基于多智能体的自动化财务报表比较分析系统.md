### 3.1.2 代码实现
```python
class Agent:
    def __init__(self, id):
        self.id = id
        self.data = None

    def process(self):
        if self.data is not None:
            return self.data.processed
        return None

    def receive_data(self, data):
        self.data = data

# 多智能体协作
agents = [Agent(i) for i in range(4)]
data = FinancialData()
for agent in agents:
    agent.receive_data(data)
results = [agent.process() for agent in agents]
```

## 5.2 系统核心实现

### 5.2.1 核心代码
```python
class MultiAgentSystem:
    def __init__(self, num_agents):
        self.agents = [Agent(i) for i in range(num_agents)]

    def process_data(self, data):
        for agent in self.agents:
            agent.receive_data(data)
        results = [agent.process() for agent in self.agents]
        return results

# 使用示例
system = MultiAgentSystem(4)
data = FinancialData()
results = system.process_data(data)
```

### 5.2.2 代码解读
- `Agent` 类：表示一个智能体，负责接收数据并处理
- `MultiAgentSystem` 类：管理多个智能体，分配任务
