### 第1章：积极价值投资的定义与背景

#### 1.1 积极价值投资的定义
积极价值投资是一种以创造和实现投资价值为核心的投资策略，强调通过主动管理和优化投资组合来实现超额收益。它不同于被动投资，更注重对市场趋势、公司基本面和投资机会的主动分析与选择。

#### 1.3 积极价值投资的核心要素

- **投资策略**：包括资产配置、个股选择和市场时机选择等多方面的策略。
- **投资组合优化**：通过优化投资组合的结构和权重，实现风险与收益的最优平衡。

## 第二部分：积极价值投资的算法与数学模型

### 第3章：积极价值投资的数学模型

#### 3.1 投资组合优化的数学模型
Markowitz有效前沿模型是投资组合优化的核心模型，通过数学公式实现风险与收益的最优平衡。

$$ \text{目标函数：} \quad \min \sum_{i=1}^{n} w_i^2 \sigma_i^2 $$

$$ \text{约束条件：} \quad \sum_{i=1}^{n} w_i r_i = r_p $$

$$ \sum_{i=1}^{n} w_i = 1 $$

#### 3.2 投资组合风险与收益的数学关系
通过夏普比率量化投资组合的收益与风险关系。

$$ \text{夏普比率} = \frac{E(r_p) - r_f}{\sigma_p} $$

通过Python代码实现投资组合优化的算法。

```python
import numpy as np
import pandas as pd

# 示例数据
returns = np.array([[0.1, 0.2, 0.15],
                     [0.05, 0.1, 0.08],
                     [0.15, 0.25, 0.2]])

# 计算协方差矩阵
cov_matrix = np.cov(returns)

# 优化目标函数
def portfolio_variance(weights, cov_matrix):
    return (weights.T @ cov_matrix @ weights)[0, 0]

# 约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 使用优化算法求解
from scipy.optimize import minimize

initial_weights = [1/3, 1/3, 1/3]
result = minimize(portfolio_variance, initial_weights, args=cov_matrix, method='SLSQP', constraints={'type': 'eq', 'fun': constraint})

print(result.x)
```
