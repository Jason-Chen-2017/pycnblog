# 第二部分：全球股市估值的核心概念与方法

## 第2章：股票估值的理论基础

### 2.1 股票估值的基本原理
股票的内在价值是公司未来现金流的现值，市场价值则受供需关系影响。估值方法包括市盈率（P/E）、市净率（P/B）和现金流折现法（DCF）。

### 2.2 主要股票估值方法
- **市盈率法**：P/E = 股价 / 每股净利润。反映市场对公司的盈利预期。
- **市净率法**：P/B = 股价 / 每股净资产。适用于净资产驱动型行业。
- **现金流折现法**：DCF模型通过预测未来现金流折现，计算股票的内在价值。

### 2.3 全球股市估值的影响因素
宏观经济因素（如GDP增长率、利率）、行业发展趋势（如技术进步、政策支持）和公司基本面（如盈利能力、财务状况）共同影响股市估值。

### 3.2 小型模块化核反应堆的设计与优势
小型模块化核反应堆采用模块化设计，具有建造周期短、灵活性高、安全性好等特点，适用于分布式能源供应和工业应用。
