## 第1章: 彼得林奇的"质量成长"与"价值重估"概述

### 1.1 彼得林奇投资策略的背景

#### 1.1.1 彼得林奇及其投资理念  
彼得·林奇是全球著名投资专家，曾管理富达麦哲伦基金，创造了辉煌的投资业绩。他的投资理念强调长期价值与公司质量，主张通过深入研究企业基本面来选择投资标的。

#### 1.1.2 "质量成长"与"价值重估"的定义  
- **质量成长**：选择具备持续增长潜力、良好管理团队和竞争优势的公司，关注ROE、增长速度等指标。
- **价值重估**：寻找市场价格低于内在价值的公司，关注低市盈率、低市净率等估值指标。

#### 1.1.3 两种策略在投资中的应用  
质量成长适合长期成长型投资，价值重估适合寻找被低估的投资机会。两者结合可平衡短期与长期、成长与估值。

### 1.2 新经济环境下的投资挑战

#### 1.2.1 新经济的特点与变化  
新经济强调技术创新、数字化转型和商业模式创新，企业价值波动大，传统估值方法面临挑战。

#### 1.2.2 传统投资策略的局限性  
- 质量成长可能忽视短期波动。
- 价值重估可能错过新兴成长企业。

#### 1.2.3 质量成长与价值重估的平衡之道  
在新经济中，投资者需结合企业质量、成长潜力与估值水平，动态调整策略。

# 第二部分: 核心概念与联系

## 第2章: 质量成长与价值重估的核心概念

### 2.1 质量成长的原理与特征

#### 2.1.1 质量成长的定义与特点  
- 长期投资，关注企业质量。
- 选择ROE高、管理优秀的企业。
- 适合长期持有，耐心等待价值显现。

#### 2.1.2 质量成长的核心要素  
- 企业盈利能力：ROE > 15%。
- 管理团队稳定性。
- 行业竞争优势。

#### 2.1.3 质量成长与传统成长投资的区别  
质量成长注重质量和可持续性，传统成长投资更关注短期增长。

### 2.2 价值重估的原理与特征

#### 2.2.1 价值重估的定义与特点  
- 寻找被低估的股票。
- 低市盈率、低市净率。
- 适合长期持有，等待价值回归。

#### 2.2.2 价值重估的核心要素  
- 市盈率 < 市盈率均值。
- 市净率 < 市净率均值。
- 财务健康状况。

#### 2.2.3 价值重估与传统价值投资的区别  
价值重估更注重动态估值，传统价值投资更注重静态估值。

### 2.3 质量成长与价值重估的对比分析

#### 2.3.1 对比表格：质量成长 vs 价值重估  

| 特性            | 质量成长           | 价值重估          |
|-----------------|-------------------|-------------------|
| 核心关注点       | 企业质量与成长    | 市场估值与价值    |
| 适合场景         | 长期成长股       | 低估股票          |
| 估值方法         | 相对估值           | 绝对估值          |
| 投资期限         | 长期              | 中长期           |

# 第三部分: 算法原理

## 第3章: 算法原理

### 3.1 质量成长的数学模型

#### 3.1.1 质量成长模型  
$$ \text{质量成长评分} = 0.5 \times \text{ROE} + 0.3 \times \text{收入增长率} + 0.2 \times \text{竞争优势} $$

#### 3.1.2 成长潜力预测  
$$ \text{未来股价} = \text{当前股价} \times (1 + \text{ROE})^n $$

### 3.2 价值重估的数学模型

#### 3.2.1 价值重估模型  
$$ \text{内在价值} = \text{净利润} \times (1 + g)^{-n} $$

#### 3.2.2 估值差异分析  
$$ \text{估值差异} = \text{内在价值} - \text{市场价格} $$

import pandas as pd

def calculate_scores(df):
    # 质量成长评分
    df['质量成长评分'] = 0.5 * df['ROE'] + 0.3 * df['收入增长率'] + 0.2 * df['竞争优势']
    # 价值重估评分
    df['价值重估评分'] = 0.4 * (df['市盈率'] < df['市盈率均值']) + 0.4 * (df['市净率'] < df['市净率均值']) + 0.2 * (df['净利润'] > 0)
    return df

# 示例数据
data = {
    'ROE': [0.2, 0.3, 0.1],
    '收入增长率': [0.2, 0.1, 0.3],
    '竞争优势': [0.8, 0.6, 0.7],
    '市盈率': [15, 20, 12],
    '市净率': [2, 3, 1],
    '净利润': [10, 8, 12]
}
df = pd.DataFrame(data)
df['市盈率均值'] = df['市盈率'].mean()
df['市净率均值'] = df['市净率'].mean()

result = calculate_scores(df)
print(result)
