# 第1章 长期主义的定义与核心理念

## 1.1 长期主义的定义与内涵  
长期主义是一种以时间复利为核心的投资策略，强调通过长期持有优质资产，利用复利效应实现财富的指数级增长。与短期交易相比，长期主义更注重企业的基本面和内在价值，而非市场的短期波动。

## 1.2 长期主义在投资中的重要性  
长期主义的核心在于通过时间的积累，最大化复利效应。巴菲特曾说过：“时间是伟大企业的朋友”，这正是长期主义的核心思想。通过长期持有优质资产，投资者可以避免频繁交易中的摩擦成本和情绪干扰，从而实现更稳定的收益。

## 1.3 长期主义与其他投资策略的对比  
### 1.3.1 与短期交易的对比  
- 短期交易：频繁买卖，依赖市场情绪和短期波动。  
- 长期主义：长期持有，关注企业基本面。  

### 1.3.2 与趋势投资的对比  
- 趋势投资：依赖市场趋势和技术分析。  
- 长期主义：依赖企业内在价值和时间复利。

# 第2章 长期主义的核心概念与联系

## 2.1 长期主义的核心概念  

### 2.1.1 安全边际  
安全边际是巴菲特投资理念中的核心概念之一，指股票的市场价格低于其内在价值时的差额。通过安全边际，投资者可以在市场波动中避免损失，并在低估时买入优质资产。  

### 2.1.2 企业护城河  
企业护城河是衡量企业竞争优势的重要指标，包括成本优势、品牌优势、技术壁垒等。具备强大护城河的企业能够在长期竞争中保持优势地位，从而为投资者提供稳定的收益。  

### 2.1.3 内在价值  
内在价值是企业未来现金流的现值，是衡量企业价值的核心指标。巴菲特强调，投资者应以内在价值为基准，而非市场价格为依据进行投资决策。  

## 2.2 核心概念之间的联系  
通过以下对比表格，可以更清晰地理解长期主义的核心概念：

|----------------|--------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| 安全边际       | 股票价格低于其内在价值的差额。                                             | 通过安全边际，确保投资的本金安全，避免短期波动带来的损失。                     |
| 企业护城河     | 企业竞争优势的体现，包括成本优势、品牌优势等。                           | 具备强大护城河的企业能够长期保持竞争优势，为投资者创造持续价值。               |
| 内在价值       | 企业未来现金流的现值。                                                     | 投资者应以内在价值为基准，选择低估的资产进行长期持有。                         |

# 第3章 长期主义的数学模型与公式

## 3.1 时间复利的数学模型  
时间复利是长期主义的核心驱动力，其数学公式如下：  

$$ FV = PV \times (1 + r)^n $$  

其中，$FV$ 表示终值，$PV$ 表示现值，$r$ 表示年化收益率，$n$ 表示投资时间。  

### 3.1.1 内在价值的计算公式  
内在价值的计算公式为：  

$$ IV = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$  

其中，$CF_t$ 表示第 $t$ 年的现金流，$r$ 表示折现率，$n$ 表示预测年数。  

### 3.1.2 内在价值与市场价格的关系  
通过比较内在价值与市场价格，投资者可以判断资产是否低估。当市场价格低于内在价值时，投资机会出现。

    iv = 0
    for t in range(years):
        iv += cash_flow[t] / (1 + discount_rate) ** t
    return iv

def main():
    import pandas as pd
    import numpy as np

    # 获取企业财务数据
    def get_financial_data(ticker):

        return pd.DataFrame({'Revenue': [100, 110, 120], 'Profit': [20, 25, 30]})

    # 计算内在价值
    def calculate_intrinsic_value(financial_data, discount_rate):
        cash_flows = financial_data['Profit']
        n = len(cash_flows)
