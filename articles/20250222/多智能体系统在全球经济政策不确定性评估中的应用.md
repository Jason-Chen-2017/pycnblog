## 第一部分：多智能体系统与全球经济政策不确定性概述

### 第1章：多智能体系统概述

#### 1.1 多智能体系统的定义与特点
- **多智能体系统的定义**：MAS由多个自主智能体组成，通过交互协作完成复杂任务。
- **属性特征对比表格**：
  | 特性 | 多智能体系统 | 单一智能体系统 |
  |------|--------------|----------------|
  | 协作性 | 高            | 无              |
  | 适应性 | 强            | 弱              |
  | 分布式 | 是            | 否              |
- **与传统单智能体系统的区别**：MAS强调协作和分布式决策，单智能体系统独立运行。
- **应用场景**：经济建模、交通控制、智能城市等复杂领域。

#### 1.2 全球经济政策不确定性概述
- **定义**：政策变化带来的经济波动风险。
- **表现形式**：汇率波动、市场信心下降、投资减少。
- **成因分析**：政策变动、国际局势、经济数据波动。
- **影响**：企业决策困难，经济波动加剧。

#### 1.3 多智能体系统在经济政策不确定性评估中的应用背景
- **必要性**：传统模型难以捕捉复杂互动。
- **优势**：MAS模拟多方互动，提供动态评估。
- **边界与外延**：聚焦政策影响，涵盖微观与宏观层面。

import numpy as np

class PolicyUncertaintyModel(Model):
    def __init__(self):

        self.policies = Normal('policies', mu=0, sigma=1)

    def predict(self, params):
        return self.uncertainty.logp(params)
