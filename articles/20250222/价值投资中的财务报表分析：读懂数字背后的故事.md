## 第一部分：价值投资与财务报表分析的背景

### 第1章：价值投资与财务报表分析概述

#### 1.1 价值投资的基本概念
- **1.1.1 价值投资的定义与核心理念**
  - 价值投资是一种长期投资策略，关注企业的内在价值而非市场波动。
  - 核心理念：寻找市场定价低于内在价值的企业。

- **1.1.2 财务报表分析在价值投资中的重要性**
  - 财务报表是评估企业财务状况和经营成果的主要依据。
  - 通过分析财务报表，投资者可以识别企业的盈利能力、成长潜力和风险水平。

- **1.1.3 数字背后的故事：财务数据如何揭示企业价值**
  - 财务数据是企业经营的记录，通过分析这些数据，可以发现企业的优势和潜在问题。

#### 1.2 财务报表分析的基本方法
- **1.2.1 财务报表的构成与作用**
  - 资产负债表：反映企业资产、负债和所有者权益的状况。
  - 利润表：展示企业在一定期间内的收入、费用和利润情况。
  - 现金流量表：记录企业现金流入和流出的动态。

- **1.2.2 三大财务报表的核心内容**
  - 资产负债表：资产=负债+所有者权益。
  - 利润表：收入-费用=利润。
  - 现金流量表：经营活动、投资活动和筹资活动的现金流。

- **1.2.3 财务报表分析的常见指标**
  - 盈利能力指标：净利率、ROE（净资产收益率）。
  - 偿债能力指标：流动比率、速动比率。
  - 成长能力指标：收入增长率、净利润增长率。

## 第二部分：财务报表的核心要素与分析框架

### 第2章：资产负债表深度解析

#### 2.1 资产负债表的结构与内容
- **2.1.1 资产的分类与评估**
  - 流动资产：现金、应收账款、存货等。
  - 非流动资产：固定资产、无形资产、长期投资等。

- **2.1.2 负债的构成与偿债能力**
  - 流动负债：短期借款、应付账款、应付工资等。
  - 非流动负债：长期借款、债券等。

- **2.1.3 所有者权益的变动与分析**
  - 所有者权益包括股本、资本公积、盈余公积和未分配利润等。

#### 2.2 资产负债表的比率分析
- **2.2.1 流动比率与速动比率**
  - 流动比率 = 流动资产 / 流动负债。
  - 速动比率 = (流动资产 - 存货) / 流动负债。

- **2.2.2 负债率与资产负债率**
  - 负债率 = 负债总额 / 资产总额。
  - 资产负债率 = 负债总额 / 净资产。

- **2.2.3 产权比率与权益乘数**
  - 产权比率 = 负债总额 / 所有者权益。
  - 权益乘数 = 资产总额 / 所有者权益。

### 第3章：利润表与现金流量表分析

#### 3.1 利润表的核心要素
- **3.1.1 收入与成本的构成**
  - 收入：主营业务收入和其他业务收入。
  - 成本：主营业务成本和其他业务成本。

- **3.1.2 毛利润与净利润的计算**
  - 毛利润 = 收入 - 成本。
  - 净利润 = 毛利润 - 费用 - 税费。

- **3.1.3 赢利能力的综合评估**
  - 净利率 = 净利润 / 收入。
  - 每股收益（EPS）= 净利润 / 总股本。

#### 3.2 现金流量表分析
- **3.2.1 经营活动现金流**
  - 经营活动现金流反映企业日常经营的现金流情况。

- **3.2.2 投资活动现金流**
  - 投资活动现金流反映企业投资活动的现金流情况。

- **3.2.3 筹资活动现金流**
  - 筹资活动现金流反映企业筹资活动的现金流情况。

### 第5章：投资策略与风险管理

#### 5.1 投资策略的核心要素
- **5.1.1 长期投资策略**
  - 长期投资关注企业的内在价值。

- **5.1.2 短期投资策略**
  - 短期投资关注市场波动和交易机会。
