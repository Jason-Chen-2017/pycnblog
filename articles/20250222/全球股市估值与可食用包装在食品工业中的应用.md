### 第3章: 全球股市估值的算法原理
- 3.1 股市估值的数学模型
  - 3.1.1 市盈率模型
    - 公式：$$市盈率 = \frac{股价}{每股收益}$$
  - 3.1.2 市净率模型
    - 公式：$$市净率 = \frac{股价}{每股净资产}$$
  - 3.1.3 资本资产定价模型（CAPM）
    - 公式：$$R_i = R_f + \beta_i (R_m - R_f)$$

- 3.2 股市估值的算法流程图
  ```mermaid
  flowchart TD
      A[开始] --> B[收集数据]
  ```

- 3.3 Python实现示例
  ```python
  import pandas as pd
  data = pd.read_csv('stock_data.csv')
  def calculate_valuation(data):
      data['市盈率'] = data['股价'] / data['每股收益']
      return data
  result = calculate_valuation(data)
  ```
