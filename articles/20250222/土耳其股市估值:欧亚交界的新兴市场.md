# 第2章 股市估值的核心概念与方法

## 2.1 股市估值的基本原理

### 2.1.1 股市估值的定义与目的

股市估值是通过分析股票的价格、收益、风险等因素，评估其合理价值的过程。其目的是帮助投资者做出科学的投资决策。

### 2.1.2 股市估值的基本方法

股市估值的基本方法包括 **相对估值法** 和 **绝对估值法**。相对估值法基于市场指标，如市盈率、市净率等；绝对估值法基于公司基本面，如现金流折现法（DCF）。

### 2.1.3 股市估值的核心指标

股市估值的核心指标包括：

1. **市盈率（P/E）**：股票价格与每股收益的比率。
2. **市净率（P/B）**：股票价格与每股净资产的比率。
3. **股息率**：每股股息与股票价格的比率。
4. **EV/EBITDA**：企业价值与息税折旧及摊销前利润的比率。

## 2.2 常用的估值指标与公式

### 2.2.1 市盈率（P/E）的计算与应用

市盈率 = 股票价格 / 每股收益

例如，某公司股票价格为10元，每股收益为2元，则市盈率为5倍。

### 2.2.2 市净率（P/B）的计算与应用

市净率 = 股票价格 / 每股净资产

例如，某公司股票价格为10元，每股净资产为5元，则市净率为2倍。

### 2.2.3 股息率的计算与应用

股息率 = 每股股息 / 股票价格

例如，某公司每股股息为1元，股票价格为10元，则股息率为10%。

### 2.2.4 EV/EBITDA的计算与应用

EV/EBITDA = 企业价值 / 息税折旧及摊销前利润

例如，某公司企业价值为100亿元，EBITDA为20亿元，则EV/EBITDA为5倍。

## 2.3 估值指标的对比分析

### 2.3.1 不同估值指标的优缺点对比

| 指标   | 优点                   | 缺点                   |
|--------|------------------------|------------------------|
| P/E    | 反映盈利能力           | 易受利润波动影响       |
| P/B    | 反映资产价值           | 不考虑收益能力         |
| 股息率 | 反映分红能力           | 不反映资产或收益       |
| EV/EBITDA | 综合反映企业价值       | 计算复杂               |

### 2.3.2 不同市场环境下的指标适用性

在高增长市场，市盈率和EV/EBITDA可能更适用；在稳定市场，市净率和股息率可能更适用。

### 2.3.3 综合指标分析方法

综合使用多个估值指标，可以更全面地评估股票的价值。例如，结合P/E和P/B，可以更好地评估股票的估值。

## 3.1 宏观经济指标对股市的影响

### 3.1.1 国内生产总值（GDP）与股市的关系

GDP增长通常会带动股市上涨，因为企业盈利增加。反之，GDP下降可能导致股市下跌。

### 3.1.2 利率政策对股市的影响

低利率环境通常会推高股市，因为资金成本降低，企业盈利增加。高利率环境则可能抑制股市，因为资金流向债券等固定收益产品。

### 3.1.3 通货膨胀对股市的影响

适度通胀有助于股市增长，但高通胀可能导致股市下跌，因为企业盈利被侵蚀，货币购买力下降。

### 3.1.4 汇率波动对股市的影响

汇率波动会影响出口型企业盈利，从而影响股市。本币贬值通常会刺激出口，推高股市；本币升值则可能抑制出口，打压股市。

## 3.2 土耳其宏观经济环境的特殊性
