## 第2章 供应链韧性定量评估的核心模型

### 2.1 供应链韧性评估的数学模型

#### 2.1.1 波动性分析模型
波动性是衡量供应链弹性的重要指标。公式为：
$$ \text{波动性} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \mu)^2} $$
其中，\( x_i \) 是数据点，\( \mu \) 是平均值。

#### 2.1.2 恢复力指数模型
恢复力指数衡量供应链在中断后的恢复速度：
$$ \text{恢复力指数} = \frac{\text{恢复时间}}{\text{中断时间}} $$

#### 2.1.3 冗余度评估模型
冗余度通过备用供应商和库存水平来衡量。

import numpy as np

def calculate_fluctuation(data):
    mu = np.mean(data)
    variance = np.mean((data - mu)**2)
    return np.sqrt(variance)

data = [10, 20, 30, 40, 50]
fluctuation = calculate_fluctuation(data)
print(fluctuation)
