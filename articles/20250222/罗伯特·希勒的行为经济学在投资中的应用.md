## 第1章：行为经济学的基本概念

### 1.1 行为经济学的定义与核心概念

#### 1.1.1 行为经济学的定义
行为经济学是研究个体在决策过程中如何受心理因素影响的学科。与传统经济学假设个体完全理性不同，行为经济学承认人类的有限理性和认知偏差。

#### 1.1.2 核心概念
- **有限理性：** 人类在决策时受到信息处理能力的限制，无法总是做出最优选择。
- **心理账户：** 人们将资金分配到不同的心理账户中，影响投资决策。
- **框架效应：** 同一问题的不同表述方式会影响决策结果。

#### 1.1.3 与传统经济学的对比
| 方面         | 行为经济学                  | 传统经济学                  |
|--------------|-----------------------------|-----------------------------|
| 假设         | 人类有限理性                | 人类完全理性                |
| 方法         | 结合心理学和经济学          | 基于数学模型和假设          |
| 应用领域     | 投资、消费、风险管理        | 市场均衡、资源配置            |

### 1.2 行为经济学在投资中的应用背景

#### 1.2.1 投资决策中的非理性行为
投资者常因情绪波动和认知偏差做出错误决策，如过度交易和 herd effect。

#### 1.2.2 传统经济学的局限性
传统经济学假设市场是理性的，但实际上市场参与者的行为复杂多样。

#### 1.2.3 行为经济学的研究方向
研究投资者心理、市场情绪波动及其对资产定价的影响。

## 第2章：罗伯特·希勒的行为经济学理论

### 2.1 希勒的主要理论贡献

#### 2.1.1 市场情绪与投资者心理
希勒认为市场波动部分源于投资者情绪，而非 purely rational factors。

#### 2.1.2 认知偏差与投资决策
投资者常见的认知偏差包括过度自信和确认偏差，影响投资决策。

#### 2.1.3 市场波动与行为因素
市场波动不仅由基本面驱动，还与投资者心理和行为密切相关。

### 2.2 希勒对市场非理性行为的分析

#### 2.2.1 市场情绪的周期性
市场情绪呈现周期性波动，影响资产价格。

#### 2.2.2 herd effect
投资者跟随市场趋势，导致价格泡沫和崩盘。

#### 2.2.3 市场泡沫与崩盘的机制
过度乐观和羊群效应导致资产价格偏离 fundamentals。

## 第4章：行为经济学在投资中的算法原理

### 4.1 希勒投资模型的算法原理

#### 4.1.1 模型概述
基于投资者情绪和认知偏差预测资产价格波动。

#### 4.1.2 代码实现

```python
# 希勒投资模型示例代码
import pandas as pd
import numpy as np

def hirle_investment_model(data):
    # 计算市场情绪指数
    mood_index = data['returns'].apply(lambda x: 1 if x > 0 else -1)
    # 预测未来价格
    predicted_price = data['current_price'] * (1 + mood_index.mean())
    return predicted_price

# 示例数据
data = {'current_price': [100, 105, 98, 102], 'returns': [0.01, -0.03, 0.02, 0.05]}
df = pd.DataFrame(data)
result = hirle_investment_model(df)
print("预测价格：", result)
```
