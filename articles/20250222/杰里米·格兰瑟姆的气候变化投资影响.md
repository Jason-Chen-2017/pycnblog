假设投资组合包含股票和债券：

```python
import numpy as np
import pandas as pd

# 示例数据
returns = pd.DataFrame({
    '股票': [0.1, 0.05, -0.02],
    '债券': [0.02, 0.03, 0.05]
})

# 优化模型
weights = np.array([0.6, 0.4])
expected_return = np.sum(weights * returns.mean())
risk = np.std(np.dot(weights, returns.values))
print(f"预期收益：{expected_return:.2f}%，风险：{risk:.2f}")
```
