### 3.1 税收敏感投资的数学模型
#### 3.1.1 投资回报的数学表达式

### 3.3 税收敏感投资的算法实现
#### 3.3.1 算法的Python实现
```python
import numpy as np

def tax_sensitive_investment():
    # 模拟数据：资产回报率和税率
    assets = ['股票', '债券', '房地产']
    returns = [0.1, 0.05, 0.08]
    tax_rates = [0.15, 0.10, 0.05]
    
    # 计算净回报
    net_returns = [(r * (1 - t)) for r, t in zip(returns, tax_rates)]
    
    # 找到最优资产
    max_net_return = max(net_returns)
    optimal_asset = assets[net_returns.index(max_net_return)]
    
    return optimal_asset, max_net_return

optimal_asset, max_net_return = tax_sensitive_investment()
print(f"最优资产：{optimal_asset}，最大净回报：{max_net_return}")
```
