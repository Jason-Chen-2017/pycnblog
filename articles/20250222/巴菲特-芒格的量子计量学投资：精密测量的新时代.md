# 第2章: 量子计量学基础

## 2.1 量子力学的基本概念

### 2.1.1 量子力学的定义

量子力学是研究微观粒子运动规律的物理学分支，其核心是波函数和量子态的描述。

### 2.1.2 量子力学的核心原理

1. **波函数的叠加原理**：量子态可以叠加，形成新的量子态。
2. **测不准原理**：无法同时精确测量粒子的位置和动量。
3. **量子纠缠**：两个或多个粒子之间存在纠缠状态，测量其中一个会立即影响另一个。

### 2.1.3 量子测量的定义与特点

量子测量是对量子态进行观测的过程，其特点包括：

1. 测量会破坏量子态。
2. 测量结果具有概率性。

---

## 2.2 量子计量学的数学基础

### 2.2.1 量子态的表达

量子态可以用复数向量表示，例如：

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle
$$

其中，$\alpha$ 和 $\beta$ 是复数，且满足 $|\alpha|^2 + |\beta|^2 = 1$。

### 2.2.2 线性代数与量子力学

量子力学的核心是线性代数，通过矩阵和向量空间描述物理系统。

### 2.2.3 量子测量的数学表达

量子测量可以用投影算符表示：

$$
P_i = |i\rangle\langle i|
$$

其中，$i$ 表示测量结果的状态。

```python
from qiskit import QuantumCircuit, execute, Aer

def quantum_measurement():
    qc = QuantumCircuit(1,1)
    qc.h(0)
    qc.measure(0,0)
    simulator = Aer.get_backend('qasm_simulator')
    result = execute(qc, simulator).result()
    probabilities = result.get_counts(qc)
    return probabilities
```
