## 第6章：项目实战

### 6.1 环境配置

```python
# 环境配置代码
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
import matplotlib.pyplot as plt
```

### 6.2 核心实现

```python
# 数据处理
data = pd.DataFrame({
    '纳米材料性能': [0.8, 0.9, 0.7, 0.6, 0.5],
    '市场价格': [100, 110, 90, 80, 70]
})

# 模型构建
model = LinearRegression()
model.fit(data[['纳米材料性能']], data['市场价格'])

# 预测结果
predictions = model.predict(data[['纳米材料性能']])
print('预测值:', predictions)
print('均方误差:', mean_squared_error(data['市场价格'], predictions))

# 结果可视化
plt.scatter(data['纳米材料性能'], data['市场价格'])
plt.plot(data['纳米材料性能'], predictions, color='red')
plt.show()
```
