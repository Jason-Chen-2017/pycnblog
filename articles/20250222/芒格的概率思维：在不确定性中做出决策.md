### 第2章: 概率论基础

#### 2.1 概率的基本原理

##### 2.1.1 概率的定义与性质  
概率是对某一事件发生的可能性的度量，范围在0（不可能发生）到1（必然发生）之间。概率具有可加性、条件性和独立性等性质。

##### 2.1.2 概率的加法法则  
如果两个事件互斥，则它们的概率可以相加。例如，P(A ∨ B) = P(A) + P(B)，前提是A和B互斥。

##### 2.1.3 条件概率与独立事件  
条件概率P(A|B)表示在B发生的情况下，A发生的概率。如果两个事件独立，则P(A|B) = P(A)。

#### 2.2 概率分布与随机变量

##### 2.2.1 离散型随机变量  
离散型随机变量取值为可数个，例如掷骰子的结果。其概率分布可以用概率质量函数表示。

##### 2.2.2 连续型随机变量  
连续型随机变量取值为不可数个，例如身高、体重。其概率分布可以用概率密度函数表示。

##### 2.2.3 常见的概率分布  
- 正态分布：描述对称数据，如身高、考试成绩。
- 二项分布：描述成功或失败的次数，如抛硬币出现正面的次数。

### 第3章: 芒格概率思维的数学模型

#### 3.1 贝叶斯定理

##### 3.1.1 贝叶斯定理的公式  
贝叶斯定理用于更新基于新证据的概率。公式为：
$$
P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}
$$  
其中，P(A)是先验概率，P(B|A)是似然度，P(B)是边际概率。

##### 3.1.2 贝叶斯定理的应用场景  
贝叶斯定理常用于医疗诊断、垃圾邮件分类、信用评分等领域。例如，在医疗诊断中，可以根据症状和检测结果更新疾病概率。

##### 3.1.3 贝叶斯定理的案例分析  
假设我们想知道某人有癌症的概率，已知检测方法的准确率和误诊率。通过贝叶斯定理，我们可以结合检测结果和先验概率，计算出后验概率。

#### 3.2 蒙特卡洛模拟

##### 3.2.1 蒙特卡洛模拟的原理  
蒙特卡洛模拟是一种通过随机采样来估计概率分布的方法。它适用于复杂系统中难以直接计算概率的情况。

##### 3.2.2 蒙特卡洛模拟的步骤  
1. 确定输入变量及其分布。
2. 生成随机样本。
3. 计算输出变量。
4. 统计分析结果。

##### 3.2.3 蒙特卡洛模拟的案例分析  
例如，在投资决策中，我们可以用蒙特卡洛模拟评估不同市场条件下的投资回报率。

#### 6.2 核心实现

##### 6.2.1 贝叶斯定理的Python实现  
```python
def bayesian_probability(A, B, P_A, P_B_given_A, P_B_given_not_A):
    P_A_not = 1 - P_A
    P_B_given_not_A = 1 - P_B_given_A
    P_B = P_B_given_A * P_A + P_B_given_not_A * P_A_not
    return (P_B_given_A * P_A) / P_B

# 示例
P_A = 0.3  # P(A)
P_B_given_A = 0.8  # P(B|A)
P_B_given_not_A = 0.2  # P(B|~A)

result = bayesian_probability(A, B, P_A, P_B_given_A, P_B_given_not_A)
print(f"后验概率 P(A|B) = {result}")
```

##### 6.2.2 蒙特卡洛模拟的Python实现  
```python
import numpy as np
import matplotlib.pyplot as plt

def monte_carlo_simulation(trials, success_prob):
    outcomes = np.random.binomial(1, success_prob, trials)
    success_rate = np.mean(outcomes)
    plt.hist(outcomes, bins=[0, 1], rwidth=0.5)
    plt.show()
    return success_rate

# 示例
trials = 1000
success_prob = 0.3

result = monte_carlo_simulation(trials, success_prob)
print(f"成功概率估计值：{result}")
```
