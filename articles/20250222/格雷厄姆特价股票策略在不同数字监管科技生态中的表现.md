#### 1.1 价值投资的起源
- **1.1.1 本杰明·格雷厄姆的贡献**  
  本杰明·格雷厄姆是价值投资理论的奠基人，其核心思想是“以合理的价格买入优秀的公司”。他的投资策略强调安全边际和内在价值的评估。

#### 1.2 格雷厄姆策略的核心理念
- **1.2.1 安全边际**  
  安全边际是格雷厄姆策略的关键，指股票价格与内在价值之间的差距，确保投资者在市场波动中不会遭受重大损失。

- **1.2.2 内在价值评估**  
  内在价值是公司未来现金流的现值，计算方法通常涉及折现率和预期收益。

#### 7.3 系统实现代码

```python
import pandas as pd
import numpy as np

# 示例数据
data = {
    '公司名称': ['公司A', '公司B'],
    '收入': [100, 150],
    '净利润': [20, 30]
}

df = pd.DataFrame(data)

# 计算内在价值
def calculate_intrinsic_value(revenue, net_profit, discount_rate=0.1):
    return (revenue + net_profit) / (1 + discount_rate)

# 应用计算
df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['收入'], x['净利润']), axis=1)
print(df)
```
