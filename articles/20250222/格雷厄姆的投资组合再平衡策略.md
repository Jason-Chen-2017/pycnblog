## 第一部分: 投资组合再平衡的背景与基础

### 第1章: 投资组合与再平衡概述

#### 1.1 投资组合的基本概念
- **投资组合的定义**：投资组合是将资金分配到不同资产（如股票、债券、房地产等）的一种方式，旨在通过分散投资降低风险并实现收益最大化。
- **投资组合的特点**：
  - 分散性：通过多样化投资降低特定资产的风险。
  - 风险-收益平衡：根据不同投资者的风险承受能力调整资产配置。
  - 动态调整：根据市场变化和个人目标进行优化。

#### 1.2 再平衡策略的定义与目的
- **再平衡的定义**：再平衡是指定期调整投资组合的资产配置，使其恢复到预定的目标比例，以应对市场波动和实现长期投资目标。
- **再平衡的目的**：
  - 维持资产配置：确保投资组合的结构与最初设定的目标一致。
  - 降低风险：通过调整避免某类资产权重过大带来的风险。
  - 抓住市场机会：在市场变化中进行资产调整以捕捉收益。

#### 1.3 格雷厄姆投资理念的核心要素
- **价值投资**：格雷厄姆强调以低于内在价值的价格买入优质资产，长期持有。
- **防御性投资**：注重安全性和稳定性，避免过度冒险。
- **长期视角**：再平衡策略帮助投资者在长期投资中保持纪律性，避免情绪化决策。

### 1.4 本章小结
- 投资组合再平衡是投资管理中的关键策略。
- 格雷厄姆的价值投资理念为再平衡策略提供了理论基础。

## 第二部分: 投资组合再平衡的核心概念与原理

### 第2章: 投资组合再平衡的原理与机制

#### 2.1 再平衡的数学模型与公式
- **资产权重计算**：
  $$ w_i = \frac{a_i}{\sum_{j=1}^{n} a_j} $$
  其中，$w_i$ 是第 $i$ 个资产的权重，$a_i$ 是第 $i$ 个资产的金额，$n$ 是资产总数。
  
- **再平衡优化模型**：
  $$ \text{目标函数：} \min \sum_{i=1}^{n} (w_i^{target} - w_i)^2 $$
  $$ \text{约束条件：} \sum_{i=1}^{n} w_i = 1 $$

#### 2.2 再平衡的触发条件与策略
- **定期再平衡**：按固定时间（如每年一次）进行调整。
- **动态再平衡**：根据市场波动或资产表现随时调整。
- **基于阈值的再平衡**：当某类资产偏离目标权重超过设定阈值时进行调整。

#### 2.3 再平衡的成本与收益分析
- **成本构成**：
  - 交易成本：买卖资产的佣金和税费。
  - 机会成本：频繁调整可能导致的收益损失。
- **收益来源**：
  - 通过调整避免过度集中风险。
  - 抓住市场变化带来的收益机会。

#### 2.4 本章小结
- 再平衡策略的数学模型和触发条件是实现有效投资组合管理的关键。
- 成本与收益的平衡是制定再平衡策略时需要考虑的重要因素。

- 计算当前权重：
  ```python
  import pandas as pd
  import numpy as np

  assets = [100000, 50000, 75000]
  weights = np.array(assets) / np.sum(assets)
  print("当前权重:", weights)
  ```

- 生成再平衡方案：
  ```python
  target_weights = [0.6, 0.3, 0.1]
  current_weights = np.array([0.65, 0.25, 0.1])
  threshold = 0.05

  # 检查是否需要再平衡
  rebalance = False
  for i in range(len(current_weights)):
      if abs(current_weights[i] - target_weights[i]) > threshold:
          rebalance = True
          break

  if rebalance:
      print("需要再平衡")
  else:
      print("无需再平衡")
  ```
