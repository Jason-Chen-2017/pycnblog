#### 第2章: 特殊情况投资的核心概念

**2.1 价值评估与市场定价**

- **2.1.1 价值评估的基本原理**

  价值评估是特殊情况投资的核心，通过分析公司的基本面数据，如收入、利润、资产等，确定其内在价值。塞思·卡拉曼的价值评估模型基于 discounted cash flow (DCF) 方法，计算公司的未来现金流的现值。

  ```python
  def calculate_intrinsic_value(company_data):
      # 计算自由现金流
      free_cash_flow = company_data['收入'] - company_data['支出']
      # 计算加权平均资本成本
      wacc = (company_data['债务成本'] * company_data['债务比例']) + (company_data['股权成本'] * company_data['股权比例'])
      # 计算终值
      terminal_value = free_cash_flow / (wacc - company_data['增长率'])
      # 计算内在价值
      intrinsic_value = terminal_value + company_data['现有价值']
      return intrinsic_value
  ```

  其中，$DCF = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$，其中$CF_t$是第t年的现金流，$r$是折现率，$TV$是终值，$n$是期限。

- **2.1.2 市场定价的偏差与机会**

  市场价格与内在价值的差异是投资机会的来源。当市场价格低于内在价值时，可能是投资的好时机。

  表2.1：市场价格与内在价值的比较

  | 公司A    | $50      | $60      | 买入     |
  | 公司B    | $80      | $70      | 卖出     |
