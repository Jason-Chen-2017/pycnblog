# 第一部分: 巴菲特-芒格策略概述

## 1.1 巴菲特与芒格的投资理念

### 1.1.1 巴菲特的价值投资原则
巴菲特的价值投资基于以下原则：
1. **安全边际**：购买价格低于内在价值。
2. **长期视角**：关注企业的长期盈利能力。
3. **竞争优势**：投资具有护城河的企业。

### 1.1.2 芒格的多元思维模型
芒格强调跨学科思维，将多个领域的知识整合，形成决策优势。

### 1.1.3 核心要素
- **安全边际**：确保投资的安全性。
- **竞争优势**：识别具有持续竞争优势的企业。
- **长期视角**：投资于能够持续增长的企业。

## 1.2 价值投资的定义与特点

### 1.2.1 定义
价值投资是通过分析企业的内在价值，寻找市场价格低于内在价值的投资机会。

### 1.2.2 核心特点
- **安全边际**：价格低于价值。
- **逆向思维**：在市场恐慌时买入。
- **长期持有**：耐心等待价值实现。

### 1.2.3 与其他策略的对比
| 战略       | 价值投资       | 投机交易       |
|------------|----------------|----------------|
| 标的       | 具体企业       | 市场波动       |
| 时间框架   | 长期           | 短期           |
| 风险       | 较低           | 较高           |

## 1.3 理论基础

### 1.3.1 经济学基础
基于市场有效性和无效性，寻找价格错配的机会。

### 1.3.2 行为金融学视角
解释市场非理性行为，利用认知偏差获利。

### 1.3.3 历史案例
历史案例分析展示了价值投资在不同经济周期中的表现。

### 4.2.1 计算内在价值（DCF模型）
```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(revenue, growth_rate, discount_rate, margin):
    cash_flow = revenue * margin
    terminal_value = cash_flow * (1 + growth_rate) / (discount_rate - growth_rate)
    present_value = (terminal_value) / (1 + discount_rate)
    return present_value
```
