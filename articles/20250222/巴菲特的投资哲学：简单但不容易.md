##### 3.2 投资哲学的数学模型与公式

###### 3.2.1 企业内在价值计算公式
$$ V = \frac{CF}{r - g} $$
其中，CF为自由现金流，r为折现率，g为增长率

###### 3.2.2 安全边际计算公式
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

###### 3.2.3 投资组合收益计算公式
$$ R = \sum (w_i \times r_i) $$
其中，w_i为资产权重，r_i为资产收益率

###### 6.1.2.2 数据分析模块
```python
def analyze_data(data):
    # 计算内在价值
    def calculate_intrinsic_value(eps, growth_rate, discount_rate):
        return eps / (discount_rate - growth_rate)
    
    # 计算安全边际
    def calculate_margin_of_safety(price, intrinsic_value):
        return intrinsic_value - price
    
    # 执行分析
    eps = data['EPS'].mean()
    growth_rate = 0.05
    discount_rate = 0.1
    intrinsic_value = calculate_intrinsic_value(eps, growth_rate, discount_rate)
    price = data['Close'].mean()
    margin_of_safety = calculate_margin_of_safety(price, intrinsic_value)
    return margin_of_safety
```

###### 6.1.2.3 投资决策模块

```python
def investment_decision(margin_of_safety):
    if margin_of_safety > 0:
        return "买入"
    elif margin_of_safety < 0:
        return "卖出"
    else:
        return "持有"
```
