# 第3章: 投资者行为分析的算法原理

## 3.1 技术指标分析方法
### 3.1.1 常用技术指标
- **移动平均线（MA）**：用于判断趋势方向。
- **相对强弱指数（RSI）**：用于判断超买超卖状态。

### 3.1.2 技术指标的计算公式
#### 移动平均线的计算
$$ MA_n = \frac{1}{n} \sum_{i=1}^{n} p_i $$
其中，$p_i$ 是第i天的收盘价，$n$ 是天数。

#### 相对强弱指数的计算
$$ RSI = \frac{100}{1 + \frac{d}{(H - L)} \times 100} $$
其中，$d$ 是涨跌差，$H$ 是最高价，$L$ 是最低价。

### 3.1.3 技术指标的应用场景
技术指标常用于趋势判断和买卖信号的生成。

## 3.2 机器学习算法在行为分析中的应用

## 3.4 技术实现代码示例
```python
# 移动平均线计算
import pandas as pd
import numpy as np

def calculate_MA(data, window):
    return data['close'].rolling(window).mean()

# 相对强弱指数计算
def calculate_RSI(data, window):
    diff = data['close'].diff()
    up = diff.where(diff > 0, 0)
    down = -diff.where(diff < 0, 0)
    rs = up.rolling(window).sum() / down.rolling(window).sum()
    rsi = 100 - (100 / (1 + rs))
    return rsi
```
