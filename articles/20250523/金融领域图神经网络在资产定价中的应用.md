# 第1章: 背景介绍

## 1.1 问题背景

### 1.1.1 传统资产定价模型的局限性

- **传统资产定价模型的不足**：
  - 线性假设的局限性：CAPM和APT等模型假设资产收益与市场收益呈线性关系，难以捕捉非线性关系。
  - 忽略网络效应：传统模型未能有效建模资产之间的相互影响关系。
  - 数据维度不足：传统模型难以处理高维金融数据。

### 1.1.2 图神经网络的优势与潜力

- **图神经网络的核心优势**：
  - 能够处理图结构数据，捕捉复杂关系。
  - 自然处理非线性关系，适合金融领域的复杂场景。
  - 可解释性较强，适合金融领域对解释性要求较高的场景。

### 1.1.3 金融领域中非结构化数据的挑战

- **金融数据的特点**：
  - 高维性：资产、市场、投资者等多维度数据。
  - 动态性：金融市场数据实时变化。
  - 复杂性：资产之间存在复杂的相互作用。

## 2.1 图神经网络的原理

## 2.2 资产定价的基本原理

### 2.2.1 资产定价模型的分类

- **分类**：
  - 单因素模型：如CAPM。
  - 多因素模型：如APT。
  - 行为模型：基于投资者心理。

### 2.2.2 资产定价的核心公式

- **CAPM公式**：
  $$E(R_i) = R_f + \beta_i (R_m - R_f)$$
  其中，$E(R_i)$是资产$i$的预期收益，$R_f$是无风险利率，$\beta_i$是资产$i$的贝塔系数，$R_m$是市场预期收益。

### 2.2.3 资产定价的市场假设

- **市场假设**：
  - � 弱有效市场：价格反映所有可用信息。
  - 强有效市场：价格反映所有内部和外部信息。
  - 半强有效市场：价格反映公开信息。

# 第3章: 图神经网络算法原理

## 3.1 图神经网络的核心算法

### 3.1.1 GCN（Graph Convolutional Networks）

- **GCN的核心思想**：
  - 在图结构中传播信息，捕捉节点之间的关系。
  - 通过邻接矩阵和节点特征矩阵进行卷积操作。

### 3.1.2 GAT（Graph Attention Networks）

- **GAT的核心思想**：
  - 引入注意力机制，动态调整节点之间的连接权重。
  - 能够捕捉节点之间的长距离依赖关系。

### 3.1.3 GNN（Graph Neural Networks）

- **GNN的核心思想**：
  - 通过多层图传播操作，逐步聚合节点信息。
  - 最终得到每个节点的表示，用于分类或回归任务。

## 3.2 算法原理的数学模型

### 3.2.1 GCN的数学公式

$$y = \theta (X, A)$$
其中，$X$是节点特征矩阵，$A$是邻接矩阵。

### 3.2.2 GAT的注意力机制

$$\alpha_{ij} = \text{softmax}(e^{f(x_i, x_j)})$$

```python
import pandas as pd
import numpy as np

# 读取数据
data = pd.read_csv('assets.csv')

data = data.drop_duplicates()
```

### 5.2.2 图结构构建代码

```python
import networkx as nx

# 创建图
G = nx.Graph()

# 添加节点
nodes = data['资产'].tolist()
G.add_nodes_from(nodes)

# 添加边
for i in range(len(nodes)):
    for j in range(i+1, len(nodes)):
        G.add_edge(nodes[i], nodes[j], weight=np.random.rand())
```

### 5.2.3 模型训练代码

```python
import torch
from torch_geometric.data import Data
from torch_geometric.nn import GCN

# 数据转换为图数据
x = torch.randn(len(nodes), 64)  # 节点特征
edge_index = torch.tensor(list(G.edges()), dtype=torch.long)
edge_index = edge_index.t().contiguous()

data = Data(x=x, edge_index=edge_index)
model = GCN(data.num_features, 64)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
criterion = torch.nn.MSELoss()

# 训练模型
for epoch in range(100):
    model.train()
    out = model(data)
    loss = criterion(out, data.y)
    loss.backward()
    optimizer.step()
```

### 5.2.4 资产定价预测代码

```python
# 预测资产价格
```
