# 第二部分：因果推断的理论基础

## 第2章：因果关系的基本原理

### 2.1 因果关系的定义与特征
- **定义**：因果关系是指一个事件的发生导致另一个事件发生的必然联系。
- **特征**：时间顺序、相关性、排除其他变量的干扰。

### 2.2 因果关系与相关关系的区别
| 特性         | 相关关系                | 因果关系                |
|--------------|-------------------------|-------------------------|
| **方向性**   | 非方向性                | 具有方向性               |
| **干预性**   | 无法通过干预改变         | 可通过干预改变            |
| **外生性**   | 仅反映变量间的关联      | 包含变量间的因果作用     |

### 2.3 因果关系的数学表示
- **公式**：$Y = \beta X + \epsilon$，其中$\epsilon$表示其他因素的影响。

### 2.4 因果推断的基本假设
- **条件独立性假设**：在给定的条件下，变量X和Y独立。
- **无隐藏共谋者**：不存在未观测到的变量同时影响X和Y。

---

## 第3章：因果推断的主要方法

### 3.1 调整法（Backdoor Criterion）
- **定义**：通过调整混杂变量，识别因果效应。
- **步骤**：
  1. 确定混杂变量。
  2. 调整混杂变量，计算条件概率。
- **公式**：$P(Y|do(X)) = P(Y|X, Z)P(Z)$，其中Z为混杂变量。

### 3.2 切断法（Do-terior）
- **定义**：通过切断因果图中的后门路径，识别因果效应。
- **步骤**：
  1. 构建因果图。
  2. 切断后门路径，计算因果效应。
- **公式**：$P(Y|do(X)) = \sum_{x} P(Y|X=x, Z)P(X=x)$。

### 3.3 隐变量方法
- **定义**：通过引入隐变量，简化因果关系的分析。
- **步骤**：
  1. 假设存在隐变量。
  2. 通过观测数据估计隐变量的影响。
- **公式**：$P(Y|X) = P(Y|X, Z)P(Z|X)$。

### 3.4 高维数据的因果推断方法
- **定义**：适用于大数据环境下的因果推断。
- **工具**：使用机器学习算法，如随机森林、神经网络等。

## 第4章：货币政策传导机制的因果图模型

### 4.1 因果图的构建
- **步骤**：
  1. 确定变量：货币政策工具（如利率）、中间变量（如信贷、资产价格）、最终变量（如GDP、通胀）。
  2. 确定因果关系：利率影响信贷，信贷影响资产价格，资产价格影响GDP。
- **Mermaid图**：
```mermaid
graph TD
    A[货币政策工具] --> B[中间变量]
    B --> C[最终变量]
```

### 4.2 货币政策传导机制的路径分解
- **路径分解**：从货币政策工具到中间变量再到最终变量。
- **公式**：$P(C|do(A)) = P(C|A, B)P(B|A)$。

### 4.3 因果效应的估计
- **公式**：$P(C|do(A=a)) = \sum_{b} P(C|A=a, B=b)P(B=b)$。

```python
import pandas as pd
import numpy as np
from causallearn.causal_model import CausalModel
from causallearn.estimator import DoWhy

# 数据加载
data = pd.read_csv('data.csv')

# 构建因果图
cm = CausalModel()
cm.add_edge('A', 'B')
cm.add_edge('B', 'C')

# 因果效应估计
estimator = DoWhy()
effect = estimator.estimate_effect(cm, data, 'A', 'C')
print(effect)
```
