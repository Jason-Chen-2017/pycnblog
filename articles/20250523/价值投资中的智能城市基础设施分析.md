### 第1章: 价值投资的基本原理
#### 1.1 价值投资的起源与发展
##### 1.1.1 价值投资的起源
价值投资起源于20世纪初，由本杰明·格雷厄姆和戴维·多德提出，强调以低于内在价值的价格购买股票，长期持有以实现收益。

##### 1.1.2 价值投资的核心理念
- 市场先生理论：市场情绪波动，投资者应独立思考，寻找被低估的投资标的。
- 安全边际：买入价格低于内在价值，以降低风险。

##### 1.1.3 价值投资在现代金融中的地位
价值投资与现代金融理论（如CAPM）相结合，成为机构投资者的重要策略。

## 第二部分: 智能城市基础设施的价值评估方法

### 第3章: 智能城市基础设施的价值评估模型
#### 3.1 现金流折现模型（DCF模型）
##### 3.1.1 DCF模型的定义与特点
DCF模型通过预测未来现金流，折现至当前价值，评估投资标的的内在价值。

##### 3.1.2 DCF模型的数学公式
$$DCF = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n}$$

其中：
- \(CF_t\)：第t年的现金流。
- \(r\)：折现率。
- \(TV\)：终值。

##### 3.1.3 DCF模型在智能城市基础设施中的应用
- 交通项目：地铁线路的建设和运营。
- 能源项目：智能电网的投资回报。

#### 3.2 资产定价模型（CAPM）
##### 3.2.1 CAPM的定义与特点
CAPM用于估计资产的预期收益，基于其系统性风险。

##### 3.2.2 CAPM的数学公式
$$E(R_i) = R_f + \beta_i (R_m - R_f)$$

其中：
- \(E(R_i)\)：资产i的预期收益率。
- \(R_f\)：无风险利率。
- \(\beta_i\)：资产i的贝塔系数。
- \(R_m\)：市场预期收益率。

##### 3.2.3 CAPM在智能城市基础设施中的应用
- 评估能源项目的风险与收益。
- 评估信息通信技术项目的价值。

##### 6.2.1 DCF模型实现
```python
def calculate_dcf(cash_flows, discount_rate, terminal_value):
    npv = 0
    for t in range(len(cash_flows)):
        npv += cash_flows[t] / (1 + discount_rate) ** t
    npv += terminal_value / (1 + discount_rate) ** len(cash_flows)
    return npv

# 示例数据
cash_flows = [100, 200, 300]
discount_rate = 0.08
terminal_value = 500

print(f"DCF Value: {calculate_dcf(cash_flows, discount_rate, terminal_value):.2f}")
```

##### 6.2.2 CAPM实现
```python
def calculate_capm(risk_free_rate, beta, market_return, risk_premium):
    return risk_free_rate + beta * (market_return - risk_free_rate + risk_premium)

# 示例数据
risk_free_rate = 0.05
beta = 1.2
market_return = 0.12
risk_premium = 0.03

print(f"CAPM Expected Return: {calculate_capm(risk_free_rate, beta, market_return, risk_premium):.2f}")
```
