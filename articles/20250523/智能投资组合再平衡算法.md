# 第3章: 智能再平衡算法的数学模型

## 3.1 投资组合优化的数学基础
### 3.1.1 投资组合优化的目标函数
$$
\text{目标函数：} \quad \min_{w} \quad w^T \Sigma w
$$
其中，$w$ 是资产权重向量，$\Sigma$ 是资产之间的协方差矩阵。

### 3.1.2 约束条件的数学表达
$$
\sum_{i=1}^{n} w_i = 1
$$
$$
w_i \geq 0 \quad \text{对于所有} \quad i
$$

### 3.1.3 优化问题的求解方法
- 均值-方差优化
- 风险平价优化
- 距离最小化方法

## 3.2 均值-方差优化模型
### 3.2.1 均值-方差模型的数学公式
$$
\min_{w} \quad w^T \Sigma w \quad \text{subject to} \quad w^T \mu = \text{target return}
$$

### 3.2.2 优化过程的步骤分解
1. 计算资产的期望收益和协方差矩阵
2. 建立优化模型
3. 求解优化问题
4. 验证解的合理性

### 3.2.3 模型的优缺点分析
- 优点：风险最小化
- 缺点：对输入参数敏感

## 3.3 风险平价优化模型
### 3.3.1 风险平价的定义与公式
$$
\min_{w} \quad \sum_{i=1}^{n} \left( \frac{w_i^2 \sigma_i^2}{(w^T \Sigma w)} \right)
$$

### 3.3.2 模型的实现步骤
1. 计算资产的波动率
2. 建立优化模型
3. 求解优化问题
4. 验证模型的有效性

### 3.3.3 模型的适用场景与限制
- 适用场景：风险分散化需求高的投资组合
- 限制：对输入参数敏感

### 6.2.2 权重计算模块实现
```python
import numpy as np

def compute_weights(cov_matrix, target_return):
    # 均值-方差优化
    n = cov_matrix.shape[0]
    ones = np.ones(n)
    G = np.zeros((2*n, n))
    G[0:n] = np.diag(1.0 / np.sqrt(np.diag(cov_matrix)))
    G[n:2*n] = ones
    q = np.zeros(2*n)
    q[n] = target_return
    A = np.zeros(n)
    b = np.zeros(n)
    H = np.bmat([[cov_matrix, np.zeros((n, n))], [np.zeros((n, n)), ones]])
    d = np.zeros(n)
    result = scipy.optimize.lsq_linear(H, d, A, b, bounds=(0, 1))
    return result.x
```
