#### 第5章：环境安装与核心代码实现

- **5.1 环境安装**

- **5.2 核心代码实现**
  ```python
  import pandas as pd
  import numpy as np

  def calculate_intrinsic_value(net_profit, growth_rate, required_return):
      return (net_profit * (1 + growth_rate)) / (required_return - growth_rate)

  def calculate_pe_ratio(price, eps):
      return price / eps

  def calculate_pb_ratio(price, book_value_per_share):
      return price / book_value_per_share

  # 示例数据
  data = {
      '公司名称': ['A', 'B', 'C'],
      '净利润': [100, 150, 200],
      '每股收益': [5, 6, 7],
      '每股净资产': [10, 12, 15],
      '预期增长率': [0.05, 0.06, 0.07],
      '要求回报率': [0.10, 0.11, 0.12]
  }

  df = pd.DataFrame(data)

  # 计算内在价值
  df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['净利润'], x['预期增长率'], x['要求回报率']), axis=1)

  # 计算市盈率和市净率
  df['市盈率'] = df.apply(lambda x: calculate_pe_ratio(x['股价'], x['每股收益']), axis=1)
  df['市净率'] = df.apply(lambda x: calculate_pb_ratio(x['股价'], x['每股净资产']), axis=1)

  print(df)
  ```
