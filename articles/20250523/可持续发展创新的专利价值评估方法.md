### 第4章: 可持续发展创新的专利价值评估模型

#### 4.1 评估模型的核心算法
- **层次分析法（AHP）**  
  通过构建层次结构，计算各指标的权重，最终得出综合评估得分。

#### 4.2 算法原理讲解

##### 4.2.1 算法流程图
```mermaid
graph TD
    A(目标层) --> B(准则层)
    B --> C(指标层)
    C --> D(方案层)
```

##### 4.2.2 算法实现代码
```python
def calculate_weights(matrix):
    # 计算权重
    n = len(matrix)
    total = sum(matrix[i][n-1] for i in range(n))
    return [matrix[i][n-1] / total for i in range(n)]

# 示例矩阵
matrix = [
    [1, 2, 3],
    [2, 1, 1],
    [3, 3, 2]
]

weights = calculate_weights(matrix)
print(weights)
```

#### 4.3 数学模型与公式
- **层次分析法的数学模型**  
  设 $A$ 为目标层，$B$ 为准则层，$C$ 为指标层，$D$ 为方案层。权重计算公式为：
  $$
  w_i = \frac{a_{i,n}}{\sum_{j=1}^{m} a_{i,j}}
  $$
  其中，$a_{i,j}$ 是指标层的权重，$m$ 是指标数量。

import numpy as np

def ahp_evaluation(matrix):
    # 计算权重
    n = len(matrix)
    total = sum(matrix[i][n-1] for i in range(n))
    weights = [matrix[i][n-1] / total for i in range(n)]
    return weights

# 示例数据

    [1, 2, 3],
