# 第1章 全球股市估值的基础

## 1.1 股市估值的基本概念

### 1.1.1 股票估值的定义与意义
股票估值是通过分析公司财务数据、市场环境等因素，对股票的内在价值进行评估的过程。准确的估值有助于投资者做出明智的投资决策。

### 1.1.2 市场估值与个股估值的区别
市场估值关注整体市场的表现，如道琼斯指数或标普500，而个股估值则针对特定股票的价值评估。

### 1.1.3 估值在投资决策中的作用
估值帮助投资者识别被低估或高估的股票，指导买入或卖出的时机。

## 1.2 股市估值的主要方法

### 1.2.1 市盈率（P/E）法
市盈率=股价/每股收益。低市盈率可能表示股票被低估，但需结合行业和公司盈利能力分析。

### 1.2.2 市净率（P/B）法
市净率=股价/每股净资产。适用于评估银行等资产密集型行业。

### 1.2.3 股息率法
股息率=每股股息/股价。高股息率可能表示股票收益稳定，但需考虑公司的分红能力。

### 1.2.4 内在价值法
通过DCF模型评估公司未来现金流的现值，确定其合理股价。

## 1.3 全球股市估值的特点与挑战

### 1.3.1 全球市场的多样性与复杂性
不同国家的经济政策、税率和市场环境差异影响估值结果。

### 1.3.2 经济周期对估值的影响
经济波动会导致市盈率、市净率等指标的变化，影响估值的准确性。

### 1.3.3 跨市场比较与联动效应
全球市场的联动性使得单一市场的估值需考虑全球宏观经济因素。

# 第7章 项目实战与应用案例

## 7.1 项目背景与目标
基于历史股价数据，构建LSTM模型预测股票价格走势。

## 7.2 核心代码实现

### 7.2.1 数据加载与预处理
```python
import pandas as pd
import numpy as np

# 加载数据
data = pd.read_csv('stock_data.csv')
# 划分训练集和测试集
train_data = data.iloc[:1000]
test_data = data.iloc[1000:]
```

### 7.2.2 模型构建
```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense

model = Sequential()
model.add(LSTM(64, input_shape=(None, 1)))
model.add(Dense(1))
model.compile(optimizer='adam', loss='mean_squared_error')
```

### 7.2.3 模型训练
```python
# 数据准备
train_sequences = train_data['close'].values.reshape(-1, 1)
test_sequences = test_data['close'].values.reshape(-1, 1)

# 训练模型
model.fit(train_sequences, epochs=50, batch_size=32, verbose=1)
```

### 7.2.4 结果预测与分析
```python
# 预测测试数据
predicted_prices = model.predict(test_sequences)
# 可视化结果
plt.plot(test_data.index, test_data['close'], label='Actual Price')
plt.plot(test_data.index, predicted_prices.reshape(-1), label='Predicted Price')
plt.legend()
plt.show()
```

## 7.3 项目总结与优化方向
模型在测试集上的表现良好，但存在预测精度不足的问题，未来可以尝试引入更多的特征和优化模型结构。
