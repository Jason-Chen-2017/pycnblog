#### 7.2.1 算法原理

- 通过因子分析法确定各因素的权重。

#### 7.2.2 核心代码实现
```python
import pandas as pd
from sklearn.metrics import r2_score
from sklearn.linear_model import LinearRegression

# 数据预处理
data = pd.read_csv('创业生态系统.csv')
X = data[['市场流动性', '投资者情绪', '经济政策']]
y = data['估值差异']

# 建立线性回归模型
model = LinearRegression()
model.fit(X, y)

# 模型评估
print(r2_score(y, model.predict(X)))
```
