### 第3章：投资组合优化算法

#### 3.1 投资组合优化的数学模型
- 现代投资组合理论（MPT）：通过优化风险和收益，构建最优投资组合。
- 数学公式：$$ \text{目标函数} = \min \sigma^2, \quad \text{约束条件} = \sum w_i = 1 $$

#### 3.2 投资组合优化的实现
- 使用Python实现投资组合优化：
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  # 示例数据
  returns = np.array([0.1, 0.12, 0.08])
  weights = np.array([1/3, 1/3, 1/3])

  # 计算投资组合的预期收益和方差
  expected_return = np.sum(returns * weights)
  portfolio_variance = np.dot(weights.T, np.dot(np.cov(returns), weights))
  ```

### 第4章：风险评估与管理算法

#### 4.1 风险评估模型
- 值-at-风险（VaR）：计算投资在一定置信水平下的潜在损失。
- 公式：$$ VaR = \mu + z \cdot \sigma $$，其中 $z$ 是标准正态分布的分位数。
