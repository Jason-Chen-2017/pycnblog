## 第一部分：注意力机制与AI Agent基础

### 第1章：注意力机制的核心概念

#### 1.1 注意力机制的定义与原理
- **1.1.1 注意力机制的定义**  
  注意力机制是一种模拟人类注意力的选择性关注机制，用于在信息处理中聚焦关键信息，忽略次要信息。
- **1.1.2 注意力机制的核心思想**  
  通过计算输入数据中各部分的重要性权重，实现对关键信息的增强和次要信息的抑制。
- **1.1.3 注意力机制的发展历程**  
  从早期的关键词匹配到基于神经网络的自注意力机制，详细梳理了注意力机制的发展脉络。

#### 1.2 AI Agent的基本概念
- **1.2.1 AI Agent的定义**  
  AI Agent是一种能够感知环境、自主决策并执行任务的智能实体。
- **1.2.2 AI Agent的核心特征**  
  包括自主性、反应性、目标导向和社会能力。
- **1.2.3 AI Agent的应用场景**  
  包括智能助手、推荐系统、机器人控制等领域。

#### 1.3 基于注意力机制的AI Agent信息过滤的背景
- **1.3.1 信息过滤的定义与重要性**  
  信息过滤是指从海量信息中筛选出相关或重要的信息，广泛应用于搜索引擎、推荐系统等领域。
- **1.3.2 注意力机制在信息过滤中的作用**  
  通过关注输入信息的关键部分，提高信息处理的效率和准确性。
- **1.3.3 当前信息过滤技术的挑战**  
  包括信息过载、噪声干扰、实时性要求高等问题。

#### 1.4 本章小结
- 本章介绍了注意力机制和AI Agent的基本概念，分析了基于注意力机制的信息过滤技术的背景和重要性，为后续内容奠定了基础。

## 第二部分：注意力机制的数学模型与算法实现

### 第2章：注意力机制的数学模型与实现

#### 2.1 注意力机制的数学公式
- **2.1.1 注意力机制的计算公式**  
  $$ Attention(q, k, v) = softmax\left(\frac{qk^T}{\sqrt{d}}\right)v $$
  其中，$q$、$k$、$v$分别为查询、键和值，$d$为嵌入维度。
- **2.1.2 查询、键、值的概念与作用**  
  查询用于表示输入，键用于匹配输入中的关键部分，值用于提供上下文信息。
- **2.1.3 自注意力机制的计算流程**  
  包括线性变换、相似度计算、权重归一化和加权求和四个步骤。

#### 2.2 基于注意力机制的信息过滤算法
- **2.2.1 基于Transformer的注意力机制**  
  Transformer模型通过自注意力机制实现了高效的序列建模，广泛应用于自然语言处理领域。
- **2.2.2 多头注意力机制的原理**  
  多头注意力机制通过并行计算多个子空间的注意力，提高了模型的表达能力。
- **2.2.3 注意力机制在信息过滤中的应用**  
  通过注意力机制筛选出重要信息，实现高效的过滤效果。

#### 2.3 注意力机制与传统信息过滤方法的对比
- **2.3.1 传统信息过滤方法的优缺点**  
  传统方法如基于关键词匹配的过滤，优点是简单高效，缺点是难以处理语义信息。
- **2.3.2 注意力机制的优势与创新点**  
  注意力机制能够捕捉语义信息，适用于复杂场景下的信息过滤。
- **2.3.3 两种方法的对比分析**  
  从准确率、效率和适应性三个维度进行对比，分析注意力机制的优劣。

#### 2.4 本章小结
- 本章详细推导了注意力机制的数学公式，分析了其在信息过滤中的实现和应用，为后续的系统设计奠定了理论基础。

#### 4.2 核心代码实现
- **4.2.1 注意力机制的实现**  
  ```python
  def scaled_dot_product_attention(query, key, value, mask=None):
      """
      计算缩放点积注意力。
      Args:
          query: 查询矩阵，形状为 (batch_size, max_length, d_model)
          key: 键矩阵，形状为 (batch_size, max_length, d_model)
          value: 值矩阵，形状为 (batch_size, max_length, d_model)
          mask: 掩码，形状为 (batch_size, max_length, max_length)
      Returns:
          输出矩阵，形状为 (batch_size, max_length, d_model)
      """
      # 计算点积
      attention_scores = (query @ key.transpose(-2, -1)) / (query.shape[-1] ** 0.5)
      # 应用掩码
      if mask is not None:
          attention_scores += (-float('inf')) * (1 - mask)
      # 计算Softmax
      attention_weights = torch.softmax(attention_scores, dim=-1)
      # 加权求和
      output = attention_weights @ value
      return output
  ```

  def filter_information(input_text):
