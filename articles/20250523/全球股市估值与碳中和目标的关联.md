# 第1章: 全球股市估值与碳中和目标的背景介绍

## 1.1 全球股市估值的基本概念

### 1.1.1 什么是全球股市估值

全球股市估值是指对全球范围内股票市场的整体价值进行评估，通常通过股票价格指数、市盈率（P/E ratio）和市净率（P/B ratio）等指标来衡量市场的整体表现和投资价值。

### 1.1.2 全球股市估值的计算方法

股票市场的估值可以通过以下方法进行计算：
- **市场资本化率**：总市值 / 国民生产总值（GDP）。
- **市盈率（P/E ratio）**：股价 / 每股收益（EPS）。
- **市净率（P/B ratio）**：股价 / 每股净资产（BPS）。

### 1.1.3 全球股市估值的重要性

股市估值是投资者评估市场整体风险和收益的重要指标，也是政策制定者和企业制定战略的重要参考。

## 1.2 碳中和目标的背景与意义

### 1.2.1 碳中和的定义与目标

碳中和是指在一定时期内，通过减少温室气体排放和增加碳汇，使二氧化碳的净排放量为零。碳中和目标的核心是实现低碳经济转型，减少对化石能源的依赖。

### 1.2.2 碳中和对全球经济的影响

碳中和目标将推动全球经济向低碳方向转型，促进新能源行业的发展，同时对传统高碳行业（如化石能源、钢铁、水泥等）构成巨大挑战。

### 1.2.3 碳中和与股市的关联性

碳中和目标通过政策、技术和市场机制直接影响企业的盈利能力、行业结构和投资者的决策。
