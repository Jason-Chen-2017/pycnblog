## # 第4章: 专利价值评估的数学模型

### 4.1 层次分析法（AHP）的应用

#### 4.1.1 层次分析法（AHP）的基本原理

层次分析法是一种系统性决策分析方法，适用于多因素决策问题。其基本原理是将复杂问题分解为多个层次的结构，通过比较各因素的重要性，确定每个因素的权重，最终得出综合评分。

#### 4.1.2 AHP在专利价值评估中的应用步骤

1. **构建层次结构模型**  
   将专利价值评估的因素分解为不同的层次，例如：
   - 上层：目标（专利价值评估）
   - 中层：准则（技术价值、法律风险、市场潜力）
   - 下层：指标（专利技术的创新性、专利的法律稳定性、专利的市场应用性）

2. **确定各因素的权重**  
   通过专家评分法，确定每个因素相对于目标层的重要程度，得到各因素的权重。

3. **一致性检验**  
   检验层次分析结果的一致性，确保评估结果的合理性。

4. **计算综合评分**  
   根据各因素的权重，计算专利组合的综合评分，得出其价值。

#### 4.1.3 AHP算法实现代码示例

```python
import numpy as np

def ahp_analysis(criteria, alternatives, matrix):
    """
    层次分析法（AHP）用于专利价值评估
    :param criteria: 评估准则列表
    :param alternatives: 评估对象列表
    :param matrix: 成对比较矩阵
    :return: 各因素的权重
    """
    n = len(criteria)
    # 计算矩阵的最大特征值及其对应的特征向量
    eigenvalues, eigenvectors = np.linalg.eig(matrix)
    max_eigen = max(eigenvalues)
    max_eigen_idx = np.argmax(eigenvalues)
    weight = eigenvectors[:, max_eigen_idx] / np.sum(eigenvectors[:, max_eigen_idx])
    
    # 计算一致性检验
    consistency = np.sum(matrix - np.eye(n)) / (n-1)
    return weight, consistency

# 示例数据
criteria = ['技术价值', '法律风险', '市场潜力']
alternatives = ['专利A', '专利B', '专利C']
matrix = [
    [1, 2, 3],
    [0.5, 1, 2],
    [0.33, 0.5, 1]
]

weights, consistency = ahp_analysis(criteria, alternatives, matrix)
print("各因素的权重为:", weights)
print("一致性检验结果为:", consistency)
```

#### 4.1.4 AHP模型的实际案例分析

以某公司拥有的三个专利为例，评估其技术价值、法律风险和市场潜力。

1. **构建比较矩阵**  
   例如，技术价值（T）与法律风险（L）相比更重要，权重为2:1，即矩阵中T > L的位置填写2，反之填写1/2。

2. **计算权重**  
   通过AHP算法计算出各因素的权重，例如：技术价值权重为0.5，法律风险权重为0.3，市场潜力权重为0.2。

3. **计算综合评分**  
   根据每个专利在各因素上的得分，乘以相应权重，求和得到综合评分。

### 4.2 模糊评价法的实现

#### 4.2.1 模糊评价法的基本原理

模糊评价法是将评估对象的属性进行模糊化处理，通过构建模糊集和隶属度函数，计算每个对象的综合隶属度，从而得到评估结果。

#### 4.2.2 模糊评价法在专利价值评估中的应用

1. **构建模糊集**  
   将专利价值的评估指标进行模糊化，例如：技术价值分为“高”、“中”、“低”三个等级。

2. **计算隶属度**  
   根据专利的具体情况，计算其在每个等级上的隶属度。

3. **综合评价**  
   使用模糊综合评价方法，得出专利的综合价值等级。

#### 4.2.3 模糊评价法实现代码示例

```python
def fuzzy_evaluation(criteria, alternatives, fuzzy_matrix):
    """
    模糊评价法用于专利价值评估
    :param criteria: 评估准则列表
    :param alternatives: 评估对象列表
    :param fuzzy_matrix: 模糊评价矩阵
    :return: 各专利的综合评价结果
    """
    n = len(criteria)
    m = len(alternatives)
    
    # 计算模糊加权平均
    result = np.zeros(m)
    for i in range(m):
        total = 0
        for j in range(n):
            total += fuzzy_matrix[i][j] * criteria[j]
        result[i] = total / n
    
    return result

# 示例数据
criteria = ['技术价值', '法律风险', '市场潜力']
alternatives = ['专利A', '专利B', '专利C']
fuzzy_matrix = [
    [0.8, 0.6, 0.7],
    [0.5, 0.9, 0.6],
    [0.7, 0.4, 0.8]
]

result = fuzzy_evaluation(criteria, alternatives, fuzzy_matrix)
print("各专利的综合评价结果为:", result)
```

### 4.3 专利价值评估的数学模型

#### 4.3.1 基于层次分析法的数学模型

$$
\text{综合评分} = \sum_{i=1}^{n} w_i \cdot x_i
$$

其中，$w_i$ 是第 $i$ 个因素的权重，$x_i$ 是第 $i$ 个因素的评分。

#### 4.3.2 基于模糊评价法的数学模型

$$
D(x) = \sum_{j=1}^{m} w_j \cdot \mu_j(x)
$$

其中，$D(x)$ 是评估对象 $x$ 的综合隶属度，$w_j$ 是第 $j$ 个准则的权重，$\mu_j(x)$ 是第 $j$ 个准则下 $x$ 的隶属度。

import numpy as np

from sklearn.metrics import pairwise_distances

class PatentPortfolioAssessment:
    def __init__(self, patents):
        self.patents = patents

    def calculate_technical_value(self, patent):
        """
        计算单个专利的技术价值
        """
        # 假设专利的技术价值与发明时间、引用次数相关
        technical_value = 1 + patent.publication_year * 0.01 + patent.citation_count * 0.005
        return technical_value

    def calculate_legal_risk(self, patent):
        """
        计算单个专利的法律风险
        """
        # 假设法律风险与专利的法律状态、无效率相关
        legal_risk = 0.2 * (1 - patent.legal_status) + 0.3 * (1 - patent.invalidate_rate)
        return legal_risk

    def calculate_market_potential(self, patent):
        """
        计算单个专利的市场潜力
        """
        # 假设市场潜力与专利的应用领域、市场规模相关
        market_potential = 0.4 * patent.application_field + 0.6 * patent.market_size
        return market_potential

    def assess_portfolio_value(self):
        """
        评估专利组合的整体价值
        """
        total_value = 0
        for patent in self.patents:
            technical = self.calculate_technical_value(patent)
            legal = self.calculate_legal_risk(patent)
            market = self.calculate_market_potential(patent)
            total_value += (technical + legal + market) / 3
        return total_value

        self.invalidate_rate = invalidate_rate
