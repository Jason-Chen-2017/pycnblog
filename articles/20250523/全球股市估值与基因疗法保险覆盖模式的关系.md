# 第2章：全球股市估值的背景分析

## 2.1 全球股市估值的定义与指标
- **定义**：股市估值是指通过市盈率（P/E）、市净率（P/B）等指标评估市场整体或个股的价值。
- **主要指标**：
  - 市盈率（P/E）：反映市场对公司的盈利预期。
  - 市净率（P/B）：衡量股价与账面价值的关系。
  - 其他指标：如股息率、PEG比率等。

## 2.2 影响股市估值的主要因素
- **宏观经济因素**：GDP增长率、通货膨胀、利率水平等。
- **行业趋势**：科技、医疗等行业的增长潜力影响股市估值。
- **公司基本面**：利润、管理团队、竞争优势等。

## 5.2 数学模型
- **线性回归模型**：
  $$ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \epsilon $$

- **Python代码示例**：

  # 特征与目标变量
