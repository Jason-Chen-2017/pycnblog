### 4.2.1 多目标优化模型
$$ \text{min} \quad f_1(x) $$

### 4.2.2 基于遗传算法的优化模型

### 4.2.3 基于粒子群算法的优化模型
$$ v_i = w \cdot v_i + c_1 \cdot r_1 \cdot (p_i - x_i) + c_2 \cdot r_2 \cdot (p_g - x_i) $$

### 7.2.3 多目标优化算法实现
```python
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def objective(x):
    return (x[0] + x[1])**2

# 约束条件
def constraint(x):
    return x[0] + x[1] - 1 <= 0

# 求解
cons = {'type': 'ineq', 'fun': constraint}
solution = minimize(objective, [0.5, 0.5], constraints=cons)
```
