### 3.1 雨水收集效率的数学模型

雨水收集效率的计算公式为：
$$ \text{收集效率} = \frac{\text{收集的雨水量}}{\text{降雨总量}} \times 100\% $$

```python
import numpy as np
import pandas as pd

def calculate_efficiency(rainfall, collected_rain):
    efficiency = (collected_rain / rainfall) * 100
    return efficiency

rainfall = np.array([10, 20, 30])  # 单位：毫米
collected_rain = np.array([5, 10, 15])
efficiency = calculate_efficiency(rainfall, collected_rain)
print("收集效率为：", efficiency)
```
