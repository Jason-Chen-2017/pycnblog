# 第4章：空间回归分析与数学模型

## 4.1 空间距离计算公式

### 4.1.1 欧几里得距离
$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

### 4.1.2 曼哈顿距离
$$d = |x_2 - x_1| + |y_2 - y_1|$$

### 4.1.3 切比雪夫距离
$$d = \max(|x_2 - x_1|, |y_2 - y_1|)$$

## 4.2 空间回归分析

### 4.2.1 线性回归模型
$$y = \beta_0 + \beta_1x + \epsilon$$

### 4.2.2 逻辑回归模型
$$P(Y=1|X) = \frac{e^{\beta_0 + \beta_1x}}{1 + e^{\beta_0 + \beta_1x}}$$

### 4.2.3 支持向量回归模型
通过支持向量构建回归模型，处理非线性关系。
