### 1.2 AI Agent的基本概念

#### 1.2.1 什么是AI Agent
AI Agent（人工智能代理）是一种能够感知环境、执行任务以实现目标的智能系统。它通过数据输入、分析和决策，提供自动化解决方案。

#### 1.2.2 AI Agent的核心特征
- 智能性：能够理解并处理复杂信息
- 自适应性：能够根据反馈优化行为
- 主动性：无需外部指令即可执行任务

#### 1.2.3 AI Agent与传统软件的区别
- AI Agent具备学习和推理能力
- 能够处理非结构化数据
- 具有自主决策能力

### 3.2 投资组合优化的数学模型

#### 3.2.1 基于均值-方差模型的投资组合优化
公式：
$$
\text{minimize } \sigma^2 \quad \text{subject to } E[r] \geq r_{\text{min}}
$$

#### 3.2.2 使用Python实现投资组合优化
代码示例：
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns):
    n = len(returns.columns)
    def objective(w):
        return (w.dot(returns.mean()) - w.dot(returns.std()) ** 2).sum()
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    result = minimize(objective, np.ones(n)/n, constraints)
    return result.x
```
