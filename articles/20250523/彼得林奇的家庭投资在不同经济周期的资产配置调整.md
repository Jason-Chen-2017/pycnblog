# 2. 家庭投资的背景与核心概念

## 2.1 家庭投资的基本概念
- 家庭投资是通过分散投资实现财务目标。
- 突出稳健性和风险控制。

## 2.2 彼得·林奇的投资理念
- 长期投资，选择优秀公司。
- 分散投资，降低风险。

## 2.3 经济周期与资产配置
- 经济周期分为复苏、繁荣、衰退、萧条四阶段。
- 每个阶段适合的资产类型不同。

# 4. 资产配置的算法原理

## 4.1 现代投资组合理论（MPT）
- 基本原理：通过分散投资降低风险。
- 均值-方差优化模型：
  $$ \text{min} \left( \sigma^2 \right) \text{ s.t. } \sum w_i = 1 $$
- 马科维茨的有效前沿：展示最优风险收益组合。

## 4.2 经济周期驱动的资产配置算法

## 4.3 算法实现与代码示例
```python
import numpy as np
import pandas as pd

def economic_cycle_asset_allocation(economic_phase):
    if economic_phase == 'recession':
        return {'cash': 0.4, 'fixed_income': 0.3, 'equity': 0.2, 'realestate': 0.1}
    elif economic_phase == 'recovery':
        return {'cash': 0.2, 'fixed_income': 0.1, 'equity': 0.6, 'realestate': 0.1}
    else:
        return {'cash': 0.1, 'fixed_income': 0.2, 'equity': 0.6, 'realestate': 0.1}
```
