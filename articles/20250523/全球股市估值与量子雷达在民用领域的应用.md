# 第一部分: 全球股市估值概述

## 第1章: 股市估值的核心方法

### 1.1 股市估值的基本概念

#### 1.1.1 股市估值的定义

股市估值是指通过对公司财务数据、市场环境和行业趋势的分析，确定公司股票的内在价值或市场价格合理性的过程。它是投资者做出投资决策的重要依据。

#### 1.1.2 股市估值的核心要素

- 公司财务状况：包括收入、利润、资产和负债等。
- 市场环境：宏观经济政策、行业竞争状况等。
- 市场情绪：投资者的心理预期和行为。

#### 1.1.3 股市估值的分类与特点

股市估值主要分为相对估值和绝对估值两类。相对估值方法（如市盈率、市净率）基于市场可比数据，而绝对估值方法（如现金流折现法）则基于未来现金流的现值。

---

### 1.2 股市估值的主要方法

#### 1.2.1 市盈率（P/E）法

市盈率 = 股票价格 / 每股净利润。该方法适用于盈利稳定的公司，尤其在成熟行业中应用广泛。

#### 1.2.2 市净率（P/B）法

市净率 = 股票价格 / 每股净资产。该方法适用于净资产驱动的行业，如银行和制造业。

#### 1.2.3 现金流折现法（DCF）

DCF模型通过预测公司未来现金流并贴现，计算其现值。该方法适用于高成长性公司。

#### 1.2.4 其他估值方法对比

下表对比了市盈率、市净率和DCF的主要优缺点：

| 方法   | 优点                           | 缺点                           |
|--------|--------------------------------|---------------------------------|
| P/E    | 简单易懂，适用于盈利稳定公司    | 依赖历史数据，不适用于亏损公司  |
| P/B    | 考虑资产价值，适合净资产驱动行业 | 忽略了收入和利润因素             |
| DCF    | 考虑未来现金流，适合高成长公司  | 预测难度大，计算复杂             |
