# 第3章 算法原理讲解

## 3.1 推荐算法

### 3.1.1 协同过滤推荐算法
基于用户行为数据，找到相似用户的偏好，推荐资源。

### 3.1.2 基于内容的推荐算法
基于资源的属性特征，推荐相似资源。

### 3.1.3 混合推荐算法
结合协同过滤和基于内容的推荐，提高推荐精度。

## 3.3 Python源代码实现

### 协同过滤推荐算法代码

```python
def collaborative_filtering(user_id, user_dict):
    # 找到与目标用户相似的用户
    similar_users = [u for u in user_dict if u != user_id]
    # 计算相似用户的评分均值
    avg_ratings = {}
    for u in similar_users:
        avg_ratings[u] = sum(user_dict[u].values()) / len(user_dict[u])
    # 为目标用户推荐资源
    recommendations = {}
    for u in similar_users:
        for resource in user_dict[u]:
            if resource not in recommendations:
                recommendations[resource] = user_dict[u][resource]
    # 按评分排序
    sorted_recommendations = sorted(recommendations.items(), key=lambda x: x[1], reverse=True)
    return sorted_recommendations
```

### 基于内容的推荐算法代码

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

def content_based_recommendation(resources, target_resource):
    # 提取资源特征向量
    vectorizer = TfidfVectorizer()
    resource_features = vectorizer.fit_transform([r.description for r in resources])
    # 计算余弦相似度
    similarity = cosine_similarity(resource_features)
    # 找到最相似的资源
    similar_resources = sorted(range(len(similarity[target_resource])), key=lambda i: similarity[target_resource][i], reverse=True)
    return [resources[i] for i in similar_resources[:5]]
```

## 3.4 算法优缺点对比

| 算法类型       | 优点                               | 缺点                               |
|----------------|------------------------------------|------------------------------------|
| 协同过滤       | 考虑了用户行为数据，推荐结果精准    | 对新用户（cold start）处理不好   |
| 基于内容的     | 对资源属性分析深入，推荐结果丰富   | 忽略了用户行为数据                |
| 混合推荐        | 结合了两种算法的优点，推荐效果好   | 实现复杂，计算成本高             |

# 第4章 数学模型与公式

## 4.1 收益预测模型

### 4.1.1 线性回归模型
$$ \text{收益} = \beta_0 + \beta_1 \times \text{资源利用率} + \epsilon $$

### 4.1.2 逻辑回归模型
$$ P(\text{投资成功}) = \frac{1}{1 + e^{- (\beta_0 + \beta_1 \times \text{市场风险})}} $$

### 4.1.3 时间序列模型
$$ \text{预测收益}_t = \alpha \times \text{历史收益}_{t-1} + \beta \times \text{市场趋势}_{t-1} + \gamma \times \epsilon_t $$
