### 第1章: 全球股市估值与货币政策关系的背景介绍

#### 1.1 问题背景与定义
股票市场估值是衡量市场整体价值的重要指标，通常通过市盈率（P/E）、市净率（P/B）等指标来衡量。货币政策是政府通过调整利率、货币供应量等工具来影响经济活动的政策。两者之间的关系复杂，但货币政策的变化往往会影响股市估值。

#### 1.2 核心概念的结构与组成
股市估值的核心指标包括：
- 市盈率（P/E）：股价与每股收益的比率。
- 市净率（P/B）：股价与每股净资产的比率。
- 市值：所有流通股的总市值。

货币政策的核心工具包括：
- 利率：中央银行调整基准利率。
- 货币供应量：通过货币政策工具调节货币流通量。
- 汇率：本国货币与外国货币的兑换比率。

#### 1.3 问题解决的边界与外延
本文研究的边界包括主要经济体（如美国、欧洲、日本）的股市估值和货币政策，外延则不包括新兴市场或区域市场的特殊情况。

#### 5.2 核心实现源代码
实现多元回归模型的代码：
```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 数据准备
data = pd.DataFrame({
    'M': [1, 2, 3, 4, 5],
    'E': [6, 7, 8, 9, 10],
    'R': [11, 12, 13, 14, 15],
    'V': [200, 250, 300, 350, 400]
})

# 模型训练
model = LinearRegression()
model.fit(data[['M', 'E', 'R']], data['V'])

# 预测与评估
predictions = model.predict(data[['M', 'E', 'R']])
mse = mean_squared_error(data['V'], predictions)
print(f'MSE: {mse}')
print(f'R-squared: {model.score(data[['M', 'E', 'R']], data['V'])}')
```
