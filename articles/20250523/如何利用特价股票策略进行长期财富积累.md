#### 3.3 算法的数学模型
- 3.3.1 市盈率（P/E）计算公式
  $$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
- 3.3.2 市净率（P/B）计算公式
  $$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$
- 3.3.3 预测模型（简单线性回归）
  $$ y = a + bx $$

#### 3.4 算法的Python实现
```python
import pandas as pd

def filter_cheap_stocks(dataframe):
    # 计算市盈率和市净率
    dataframe['PE'] = dataframe['股价'] / dataframe['每股收益']
    dataframe['PB'] = dataframe['股价'] / dataframe['每股净资产']
    
    # 筛选低估值股票
    cheap_stocks = dataframe[(dataframe['PE'] < dataframe['PE'].mean()) &
                              (dataframe['PB'] < dataframe['PB'].mean())]
    
    return cheap_stocks

# 示例数据
data = {
    '股票代码': ['A', 'B', 'C', 'D'],
    '股价': [10, 20, 15, 25],
    '每股收益': [2, 5, 3, 6],
    '每股净资产': [5, 8, 4, 10]
}

df = pd.DataFrame(data)
result = filter_cheap_stocks(df)
print(result)
```
