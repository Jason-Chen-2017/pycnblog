# 第2章: 投资组合管理的理论基础

## 2.1 现代投资组合理论（MPT）

### 2.1.1 MPT的核心思想
- 风险与收益的平衡：通过优化资产配置，实现收益最大化和风险最小化。
- 有效前沿：所有可能的投资组合中，收益最高、风险最低的组合构成有效前沿。

### 2.1.2 风险与收益的权衡
- 风险调整后的收益：通过夏普比率衡量投资组合的风险调整后收益。
- 风险溢价：投资者因承担额外风险而要求的额外收益。

### 2.1.3 有效前沿的概念与应用
- 有效前沿：所有有效投资组合的集合，构成一条曲线。
- 应用：通过选择位于有效前沿上的组合，实现最优投资。

## 2.2 均值-方差模型

### 2.2.1 均值-方差模型的数学公式
$$ \text{目标函数：} \min_w \frac{1}{2}w^T \Sigma w $$
- \( w \)：权重向量。
- \( \Sigma \)：资产之间的协方差矩阵。

### 2.2.2 约束条件
$$ \text{权重约束：} \sum_{i=1}^n w_i = 1 $$
- 权重之和为1。

### 2.2.3 模型的局限性
- 假设资产收益符合正态分布。
- 无法处理非线性关系。

## 2.3 马科维茨优化模型

### 2.3.1 优化目标
$$ \text{目标函数：} \min_w \frac{1}{2}w^T \Sigma w $$
- 最小化投资组合的方差。

### 2.3.2 约束条件
$$ \text{收益约束：} w^T \mu \geq \mu_{target} $$
- 确保投资组合的预期收益不低于目标收益。

### 2.3.3 模型的扩展与改进
- 引入风险厌恶系数，调整优化目标。

```python
import numpy as np
from sklearn.metrics import mean_squared_error

def optimize_portfolio(weights, returns):
    # 计算投资组合的收益和风险
    portfolio_return = np.dot(weights, returns.mean())
    portfolio_risk = np.sqrt(np.dot(weights.T, np.dot(returns.cov(), weights)))
    return -portfolio_return + 0.01 * portfolio_risk
```

#### 2.2.2 约束条件
$$ \text{权重约束：} \sum_{i=1}^n w_i = 1 $$
- 权重之和为1。

#### 2.2.3 模型的局限性
- 假设资产收益符合正态分布。
- 无法处理非线性关系。

### 2.3 马科维茨优化模型

#### 2.3.1 优化目标
$$ \text{目标函数：} \min_w \frac{1}{2}w^T \Sigma w $$
- 最小化投资组合的方差。

#### 2.3.2 约束条件
$$ \text{收益约束：} w^T \mu \geq \mu_{target} $$
- 确保投资组合的预期收益不低于目标收益。

#### 2.3.3 模型的扩展与改进
- 引入风险厌恶系数，调整优化目标。

```python
import numpy as np
from sklearn.metrics import mean_squared_error

def optimize_portfolio(weights, returns):
    # 计算投资组合的收益和风险
    portfolio_return = np.dot(weights, returns.mean())
    portfolio_risk = np.sqrt(np.dot(weights.T, np.dot(returns.cov(), weights)))
    return -portfolio_return + 0.01 * portfolio_risk
```
