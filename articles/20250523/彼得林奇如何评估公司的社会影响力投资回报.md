## 第二部分：社会影响力投资的评估方法与模型

### 第3章：社会影响力投资的评估方法与模型

#### 3.1 评估方法的原理
- **指标选取**：选择能反映社会影响力的指标，如碳排放、员工福利。
- **财务指标**：如ROE、现金流。
- **结合方法**：通过加权评分综合评估。

#### 3.2 数学模型与公式
- **社会影响力评分模型**
  $$ S = \sum_{i=1}^{n} w_i \cdot s_i $$
  其中，$S$ 是总评分，$w_i$ 是权重，$s_i$ 是指标评分。

- **投资回报评分模型**
  $$ R = \sum_{j=1}^{m} w'_j \cdot r_j $$
  其中，$R$ 是总回报评分，$w'_j$ 是权重，$r_j$ 是回报指标评分。

- **综合评估模型**
  $$ F = \alpha S + (1-\alpha) R $$
  其中，$\alpha$ 是社会影响力权重，范围0到1。

#### 3.3 案例分析
假设某公司有三个社会影响力指标，权重分别为0.4、0.3、0.3，评分分别为8、7、9。计算得：
$$ S = 0.4*8 + 0.3*7 + 0.3*9 = 7.9 $$

```python
def calculate_social_impact(enterprise_data):
    weights = [0.4, 0.3, 0.3]
    scores = [enterprise_data['carbon_emission'], 
              enterprise_data['employee_welfare'], 
              enterprise_data['community_investment']]
    return sum(w * s for w, s in zip(weights, scores))

def calculate_return_on_equity(enterprise_data):
    return enterprise_data['net_profit'] / enterprise_data['total_equity']

enterprise_data = {
    'carbon_emission': 8,
    'employee_welfare': 7,
    'community_investment': 9,
    'net_profit': 10,
    'total_equity': 5
}

si_score = calculate_social_impact(enterprise_data)
roq = calculate_return_on_equity(enterprise_data)
print(f"Social Impact Score: {si_score}")
print(f"Return on Equity: {roq}")
```
