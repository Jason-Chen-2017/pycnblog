使用Python代码实现Modbus协议的传感器数据采集。

```python
import minimalmodbus

def read_sensor_data(slave_id):
    try:
        bus = minimalmodbus.ModbusClient(host='localhost', port=502)
        bus.connect()
        return bus.read_input_registers(slave_id, 0, 1)
    except Exception as e:
        print(f"Error reading sensor data: {e}")
        return None
```
