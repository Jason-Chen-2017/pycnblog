##### 3.1 财务健康评分的加权评分法
$$
\text{评分} = \sum_{i=1}^{n} (w_i \times f_i)
$$
其中，\( w_i \) 是第 \( i \) 个要素的权重，\( f_i \) 是第 \( i \) 个要素的评分。

##### 4.2 Python实现代码

```python
def calculate_score(income, expenditure, assets, liabilities):
    # 收入与支出评分（权重30%）
    income_score = (income / expenditure) * 0.3
    # 资产与负债评分（权重40%）
    asset_score = (assets / liabilities) * 0.4
    # 风险评分（权重30%）
    risk_score = (income + assets) / (expenditure + liabilities) * 0.3
    total_score = income_score + asset_score + risk_score
    return total_score

# 示例数据
income = 50000
expenditure = 30000
assets = 100000
liabilities = 50000

score = calculate_score(income, expenditure, assets, liabilities)
print(f"财务健康评分为：{score}")
```
