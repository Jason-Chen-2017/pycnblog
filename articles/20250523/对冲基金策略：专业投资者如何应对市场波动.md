- **均值回归策略代码示例（Python）**
  ```python
  import pandas as pd
  import numpy as np
  from sklearn.linear_model import LinearRegression

  # 示例数据
  data = pd.DataFrame({
      'price': [10, 12, 11, 13, 14, 15],
      'volume': [100, 200, 150, 250, 300, 350]
  })

  # 均值回归模型
  model = LinearRegression()
  model.fit(data[['volume']], data['price'])

  # 预测价格
  predicted_price = model.predict(data[['volume']])
  print(predicted_price)
  ```

- **风险指标公式（使用 LaTeX）**
  - VaR（Value at Risk）：$$VaR = \mu + z \cdot \sigma$$
  - 回撤（Drawdown）：$$Drawdown = \frac{峰值 - 当前值}{峰值} \times 100\%$$
