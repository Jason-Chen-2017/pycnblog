### 5.2 核心代码实现

#### 5.2.1 数据处理代码
- 读取数据
- 计算收益率、协方差矩阵
```python
import pandas as pd
import numpy as np

# 读取数据
data = pd.read_csv('assets.csv')

# 计算收益率
returns = data.pct_change().dropna()

# 计算协方差矩阵
cov_matrix = returns.cov()
```

#### 5.2.2 优化算法实现
- 均值-方差优化
```python
import cvxopt
from cvxopt import matrix, solvers

# 定义目标函数和约束条件
n = returns.shape[1]
m = returns.shape[0]

mu = returns.mean(axis=0)
Sigma = returns.cov()

# 均值-方差优化
solvers.options['maxit'] = 100
solvers.options['disp'] = False

# 矩阵转换
mu = matrix(mu.values)
Sigma = matrix(cov_matrix.values)

# 解决优化问题
sol = cvxopt.solvers.qp(Sigma, mu, None, None, None, None, 'loqo')
weights = sol['x']
```

#### 5.2.3 结果分析代码
- 输出最优权重
- 计算组合收益与风险
```python
optimal_weights = weights / weights.sum()
print("Optimal Weights:", optimal_weights)
print("Expected Return:", optimal_weights.T * mu)
print("Risk:", np.sqrt(optimal_weights.T * Sigma * optimal_weights))
```
