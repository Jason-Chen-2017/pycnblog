### 3.4 算法实现的代码示例
#### Python代码示例
```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier

# 数据预处理
data = np.array([[1, 2, 3], [4, 5, 6]])
X = data[:, :-1]
y = data[:, -1]

# 模型训练
model = DecisionTreeClassifier()
model.fit(X, y)

# 预测结果
result = model.predict([[7, 8, 9]])
print(result)
```
