### A.1 ARIMA模型代码

```python
from statsmodels.tsa.arima_model import ARIMA
import pandas as pd
import numpy as np

# 假设我们有一个时间序列数据集df，其中包含'price'列
# 创建ARIMA模型
model = ARIMA(df['price'], order=(5, 1, 0))
model_fit = model.fit()

# 预测未来的价格
future_forecast = model_fit.forecast(steps=10)
print(future_forecast)
```
