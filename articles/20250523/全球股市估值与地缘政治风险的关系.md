## 第三部分：股市估值的理论与方法

### 第3章：股市估值的基本理论

#### 3.1 股市估值的定义与方法
- 3.1.1 市盈率（P/E）模型
  - 公式：P/E = 市场价格 / 每股收益
  - 示例：股票价格为100元，每股收益为10元，P/E = 10。
- 3.1.2 市净率（P/B）模型
  - 公式：P/B = 市场价格 / 每股净资产
  - 示例：股票价格为50元，每股净资产为20元，P/B = 2.5。
- 3.1.3 现金流折现模型（DCF）
  - 公式：股票价值 = 现金流的现值
  - 示例：预测未来现金流，贴现率5%，计算现值。

#### 3.2 影响股市估值的主要因素
- 3.2.1 宏观经济指标
  - GDP、通胀率、利率等。
- 3.2.2 行业周期与公司基本面
  - 公司业绩、行业前景等。
- 3.2.3 市场情绪与投资者预期
  - 市场情绪指标：恐慌指数、投资者信心指数。
