- **1.1.2 神经网络架构搜索的发展历程**

  - 自动化方法的出现：基于遗传算法和强化学习的NAS方法逐渐兴起。

- **1.2.2 AI Agent的核心功能**

# 第三部分：算法原理与数学模型

## 第3章：算法原理与数学模型

### 3.1 神经网络架构搜索的算法框架
- **3.1.1 强化学习方法**
  - 使用强化学习代理（如策略梯度）来选择网络结构。
  - 算法流程：定义搜索空间，训练强化学习代理，评估候选模型，更新搜索策略。

- **3.1.2 遗传算法方法**
  - 通过模拟进化过程，逐步优化网络结构。
  - 算法流程：初始化种群，评估个体适应度，选择优秀个体，进行交叉和变异操作，生成新种群。

- **3.1.3 混合方法**
  - 结合强化学习和遗传算法的优势，提升搜索效率。
  - 算法流程：使用强化学习选择候选结构，利用遗传算法进一步优化。

### 3.2 算法原理的数学模型

#### 3.2.1 强化学习方法的数学模型
- **策略梯度方法**：
  - 状态空间：S，动作空间：A。
  - 策略函数：π(a|s)，表示在状态s下选择动作a的概率。
  - 目标函数：J(π) = E_{s,a} [π(a|s) r(s,a)]，其中r(s,a)是奖励函数。
  - 梯度计算：∇J = E_{s,a} [∇ log π(a|s) r(s,a)]。

#### 3.2.2 遗传算法方法的数学模型
- **适应度函数**：f(s)，表示个体适应度。
- **选择操作**：根据适应度值选择优秀个体。
- **交叉操作**：将两个个体的结构进行交叉，生成新的个体。
- **变异操作**：随机改变个体的某些结构参数，增加多样性。

### 3.3 算法的优化与改进
- **3.3.1 强化学习方法的优化**
  - 使用更高效的策略搜索方法，如随机网络搜索（Random Network Search）。
  - 引入记忆机制，记录优秀结构，避免重复搜索。

- **3.3.2 遗传算法方法的改进**
  - 增加变异概率，防止过早收敛。
  - 使用精英保留策略，保留优秀个体。

- **3.3.3 混合方法的优化**
  - 组合强化学习和遗传算法的优势，如先使用强化学习进行粗略搜索，再用遗传算法进行精细优化。
