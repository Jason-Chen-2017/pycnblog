tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertForSequenceClassification.from_pretrained('bert-base-uncased')

# 用户输入

# 预处理文本
inputs = tokenizer(user_input, return_tensors='pt')

# 进行意图识别

    logits = model(**inputs).logits

# 获取意图标签
intent_labels = ['查询订单', '支付问题', '售后服务', '其他']
predicted_label = intent_labels[torch.argmax(logits).item()]

print(predicted_label)  # 输出预测的意图

from transformers import BertTokenizer, BertForSequenceClassification
import torch

# 加载预训练的BERT模型和分词器
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertForSequenceClassification.from_pretrained('bert-base-uncased')

# 用户输入
user_input = "我想查询我的订单状态"

# 预处理文本
inputs = tokenizer(user_input, return_tensors='pt')

# 进行意图识别
with torch.no_grad():
    logits = model(**inputs).logits

# 获取意图标签
intent_labels = ['查询订单', '支付问题', '售后服务', '其他']
predicted_label = intent_labels[torch.argmax(logits).item()]

print(predicted_label)  # 输出预测的意图
```

这段代码首先加载预训练的BERT模型和分词器，然后对用户输入进行预处理，最后使用模型进行意图识别并输出预测结果。

```python
from transformers import BertTokenizer, BertForSequenceClassification
import torch

# 加载预训练的BERT模型和分词器
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertForSequenceClassification.from_pretrained('bert-base-uncased')

# 用户输入
user_input = "我想查询我的订单状态"

# 预处理文本
inputs = tokenizer(user_input, return_tensors='pt')

# 进行意图识别
with torch.no_grad():
    logits = model(**inputs).logits

# 获取意图标签
intent_labels = ['查询订单', '支付问题', '售后服务', '其他']
predicted_label = intent_labels[torch.argmax(logits).item()]

print(predicted_label)  # 输出预测的意图
```

这段代码首先加载预训练的BERT模型和分词器，然后对用户输入进行预处理，最后使用模型进行意图识别并输出预测结果。
