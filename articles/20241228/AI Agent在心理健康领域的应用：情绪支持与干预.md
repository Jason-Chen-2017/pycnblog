### 2.1 自然语言处理基础

#### 自然语言处理概述

自然语言处理（NLP）是人工智能领域的一个重要分支，旨在使计算机能够理解和处理人类语言。NLP涉及多个层面，包括文本预处理、语言理解、语言生成等。在心理健康领域的AI Agent应用中，NLP是实现用户与系统之间有效交流的关键技术。

#### 语言理解

语言理解是指计算机理解和解释人类语言的能力。在NLP中，语言理解通常分为两个层次：语法理解和语义理解。

- **语法理解**：语法理解涉及句法分析和句法解析，旨在理解句子的结构。常用的工具包括句法树和依存句法图。句法树展示了句子中各个成分的层级关系，而依存句法图则展示了句子中各个成分之间的依赖关系。
  
  $$ \text{句法树示例:} $$
  ```mermaid
  graph LR
  A[主语] --> B[谓语]
  B --> C[宾语]
  ```

- **语义理解**：语义理解涉及理解句子中的词汇意义和整体语义。语义理解包括词义消歧、实体识别和关系提取等任务。词义消歧是指确定词汇在特定上下文中的含义，实体识别是指识别句子中的命名实体（如人名、地名等），关系提取是指识别实体之间的关系。

  $$ \text{实体关系图示例:} $$
  ```mermaid
  graph LR
  A[张三](Person) --> B[工作](Job)
  B --> C[程序员](Programmer)
  ```

#### 文本分类

文本分类是指将文本数据按照预定的类别进行分类。在心理健康领域的AI Agent应用中，文本分类可以用于情绪识别、用户需求分类等任务。

- **情绪识别**：情绪识别是指通过文本分类技术识别文本中的情感极性。常用的方法包括朴素贝叶斯分类器、支持向量机（SVM）和深度学习模型。

  $$ \text{情绪识别示例:} $$
  ```python
  from sklearn.feature_extraction.text import TfidfVectorizer
  from sklearn.naive_bayes import MultinomialNB

  # 文本数据
  texts = ["我很开心！", "我感到很难过。"]

  # 文本向量化
  vectorizer = TfidfVectorizer()
  X = vectorizer.fit_transform(texts)

  # 情感标签
  y = ["positive", "negative"]

  # 训练模型
  classifier = MultinomialNB()
  classifier.fit(X, y)

  # 预测
  test_text = ["我今天过得很糟糕。"]
  test_vector = vectorizer.transform(test_text)
  prediction = classifier.predict(test_vector)

  print(prediction)  # 输出：['negative']
  ```

- **用户需求分类**：用户需求分类是指将用户的文本消息按照预定的类别进行分类，以便AI Agent能够提供相应的服务。例如，可以将用户的文本消息分为咨询、求助、投诉等类别。

  $$ \text{用户需求分类示例:} $$
  ```python

  X = vectorizer.fit_transform(texts)

  # 需求标签

  # 训练模型
  classifier = RandomForestClassifier()
  classifier.fit(X, y)

  # 预测

  test_vector = vectorizer.transform(test_text)

       else:
           return "neutral"
   ```
