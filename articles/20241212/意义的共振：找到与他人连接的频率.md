```python
import numpy as np
import matplotlib.pyplot as plt

def resonance_simulation(frequency, damping=0.05, t_max=100, dt=0.01):
    """
    模拟共振现象。

    参数:
    frequency: 振动的频率 (Hz)
    damping: 阻尼系数 (0-1), 越大共振效果越不明显
    t_max: 模拟的总时间 (秒)
    dt: 时间步长 (秒)
    
    返回:
    times: 时间数组
    amplitudes: 振幅数组
    """
    times = np.arange(0, t_max, dt)
    amplitudes = np.zeros(times.shape)
    
    omega = 2 * np.pi * frequency  # 角频率

    for t in times:
        # 阻尼项
        damping_term = damping * amplitudes[t-1]
        # 受迫振动项
        forced_term = np.sin(omega * t)
        # 计算新的振幅
        amplitudes[t] = (1 - damping) * amplitudes[t-1] + forced_term
    
    return times, amplitudes

# 设置参数
frequency = 5  # 频率为5Hz
damping = 0.05  # 阻尼系数为0.05
t_max = 100  # 模拟时间为100秒
dt = 0.01  # 时间步长为0.01秒

# 模拟共振现象
times, amplitudes = resonance_simulation(frequency, damping, t_max, dt)

# 绘制振幅-时间图

plt.xlabel('Time (s)')
plt.ylabel('Amplitude')
plt.title('Resonance Simulation')
plt.grid(True)
plt.show()
```

### 算法原理讲解

1. **振动的数学模型**：
   振动的振幅随时间的变化可以用以下微分方程描述：
   $$ m\frac{d^2x(t)}{dt^2} + c\frac{dx(t)}{dt} + kx(t) = F_0 \sin(\omega t) $$
   其中，$m$是质量，$c$是阻尼系数，$k$是弹簧系数，$F_0$是外部驱动力，$\omega$是角频率。

2. **阻尼效应**：
   阻尼系数$d$影响振动的衰减速度。阻尼系数越大，振动衰减越快。

3. **受迫振动**：
   外部驱动力$F_0 \sin(\omega t)$导致系统产生受迫振动，即系统的振动频率与外部驱动力的频率相同。

4. **递推关系**：
   使用递推关系来计算每个时间点的振幅。这个关系考虑了阻尼效应和受迫振动项，从而更新振幅。

以下是本文中使用的Python代码实现共振现象模拟的完整示例。

```python
import numpy as np
import matplotlib.pyplot as plt

def resonance_simulation(f1, f2, damping=0.05, t_max=100, dt=0.01):
    """
    模拟两个频率的共振现象。
    
    参数:
    f1: 第一个频率 (Hz)
    f2: 第二个频率 (Hz)
    damping: 阻尼系数 (0-1)
    t_max: 模拟时间 (秒)
    dt: 时间步长 (秒)
    
    返回:
    times: 时间数组
    amplitudes: 振幅数组
    """
    times = np.arange(0, t_max, dt)
    amplitudes = np.zeros(times.shape)
    
    omega1 = 2 * np.pi * f1
    omega2 = 2 * np.pi * f2
    
    for t in times:
        amplitude = (1 - damping) * np.sin(omega1 * t + omega2 * t)
        amplitudes[t] = amplitude
    
    return times, amplitudes

# 设置参数
f1 = 5  # 第一个频率为5Hz
f2 = 4  # 第二个频率为4Hz
damping = 0.05  # 阻尼系数为0.05
t_max = 20  # 模拟时间最大值为20秒
dt = 0.01  # 时间步长为0.01秒

# 模拟共振现象
times, amplitudes = resonance_simulation(f1, f2, damping, t_max, dt)

# 绘制共振曲线
plt.plot(times, amplitudes)
plt.xlabel('Time (s)')
plt.ylabel('Amplitude')
plt.title('Resonance Simulation')
plt.grid(True)
plt.show()
```
