   ```python
   def generate_prompt_words(text):
       vectorizer = TfidfVectorizer()
       tfidf_matrix = vectorizer.fit_transform([text])
       feature_names = vectorizer.get_feature_names_out()
       scores = tfidf_matrix.toarray().sum(axis=0)
       top_words = [feature_names[i] for i in scores.argsort()[::-1]]
       return top_words[:10]
   ```

### 数学模型与公式讲解

#### 第4章：数学模型与公式讲解

##### 4.1 数学模型基本概念

在提示词工程中，数学模型主要用于评估和优化提示词的质量。常见的数学模型包括：

1. **相关性模型**：用于评估提示词与问题的相关性。
2. **多样性模型**：用于评估提示词的多样性。
3. **启发性模型**：用于评估提示词的启发性。

##### 4.2 数学公式讲解

1. **相关性模型**

   相关性模型可以使用余弦相似度来计算提示词与问题的相似度。公式如下：

   $$\text{相关性} = \frac{\text{提示词与问题的相似度}}{\text{最大相似度}}$$

   其中，提示词与问题的相似度可以通过以下公式计算：

   $$\text{相似度} = \frac{\text{提示词的向量表示} \cdot \text{问题的向量表示}}{\|\text{提示词的向量表示}\| \|\text{问题的向量表示}\|}$$

2. **多样性模型**

   多样性模型可以使用词汇丰富度来评估提示词的多样性。公式如下：

   $$\text{多样性} = \frac{\text{提示词的词汇数}}{\text{最大词汇数}}$$

   其中，提示词的词汇数可以通过以下公式计算：

   $$\text{词汇数} = \text{提示词的词频之和}$$

3. **启发性模型**

   启发性模型可以使用提示词的关联性来评估其启发性。公式如下：

   $$\text{启发性} = \frac{\text{提示词的关联度}}{\text{最大关联度}}$$

   其中，提示词的关联度可以通过以下公式计算：

   $$\text{关联度} = \frac{\text{提示词与其他词的共现次数}}{\text{最大共现次数}}$$

1. **相关性模型应用举例**

   假设提示词为“人工智能、未来、发展”，问题为“人工智能技术在未来的发展前景如何？”。我们可以计算以下相关性的示例：

   $$\text{相关性} = \frac{\text{（人工智能的向量表示} \cdot \text{问题的向量表示）}}{\|\text{人工智能的向量表示}\| \|\text{问题的向量表示}\|} = \frac{0.9}{1} = 0.9$$

   因此，提示词与问题的相关性为0.9。

2. **多样性模型应用举例**

   假设提示词为“人工智能、未来、发展”，我们可以计算以下多样性的示例：

   $$\text{多样性} = \frac{\text{提示词的词汇数}}{\text{最大词汇数}} = \frac{3}{5} = 0.6$$

   因此，提示词的多样性为0.6。

3. **启发性模型应用举例**
