   - 定义：模型正确执行指令的比例。

2. **召回率**：
   - 定义：模型召回用户期望的指令比例。
   - 公式：召回率 = (召回用户期望指令数 / 用户期望指令总数) * 100%
   - 分析：召回率越高，说明模型能够更好地理解用户指令。

3. **F1值**：
   - 定义：准确率和召回率的调和平均值。
   - 公式：F1值 = 2 * (准确率 * 召回率) / (准确率 + 召回率)
   - 分析：F1值越高，说明模型的性能越好。

4. **响应时间**：
   - 定义：模型处理指令所需的时间。
   - 公式：响应时间 = 模型处理指令时间 / 指令总数
   - 分析：响应时间越短，说明模型的性能越好。

5. **资源消耗**：
   - 定义：模型在执行指令过程中消耗的资源，如CPU、内存、网络带宽等。
   - 公式：资源消耗 = 模型消耗资源总量 / 指令总数
   - 分析：资源消耗越低，说明模型的性能越好。
