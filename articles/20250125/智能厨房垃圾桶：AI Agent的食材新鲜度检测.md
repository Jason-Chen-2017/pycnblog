### 6.2 核心代码实现

智能厨房垃圾桶的核心代码主要包括传感器数据采集、数据处理、机器学习模型训练和预测等几个部分。以下是一个简单的示例：

```python
import RPi.GPIO as GPIO
import Adafruit_DHT
import time
import pandas as pd
from sklearn.ensemble import RandomForestClassifier

# 传感器配置
DHT_SENSOR = Adafruit_DHT.DHT11
DHT_PIN = 4
SENSOR_INTERVAL = 10

# 初始化GPIO
GPIO.setmode(GPIO.BCM)
GPIO.setup(DHT_PIN, GPIO.OUT)

def read_dht_sensor():
    """
    读取DHT11传感器的湿度、温度数据。
    """
    humidity, temperature = Adafruit_DHT.read(DHT_SENSOR, DHT_PIN)
    if humidity is not None and temperature is not None:
        return humidity, temperature
    else:
        return None, None

def preprocess_data(humidity, temperature):
    """
    对传感器数据进行预处理。
    """
    # 数据清洗
    if humidity is None or temperature is None:
        return None
    
    # 特征提取
    features = [humidity, temperature]
    return features

def train_model(data):
    """
    训练机器学习模型。
    """
    X = data[:, :-1]
    y = data[:, -1]
    model = RandomForestClassifier()
    model.fit(X, y)
    return model

def predict_newness(model, humidity, temperature):
    """
    预测食材的新鲜度。
    """
    features = preprocess_data(humidity, temperature)
    if features is None:
        return None
    prediction = model.predict([features])
    return prediction[0]

# 主程序
if __name__ == "__main__":
    data = []
    while True:
        humidity, temperature = read_dht_sensor()
        features = preprocess_data(humidity, temperature)
        if features is not None:
            data.append([humidity, temperature])
        
        if len(data) >= 100:
            model = train_model(pd.DataFrame(data))
            print("Model trained.")
            break
        
        time.sleep(SENSOR_INTERVAL)

    # 测试模型
    test_data = [[30, 20], [35, 22], [40, 25]]
    for data in test_data:
        humidity, temperature = data
        prediction = predict_newness(model, humidity, temperature)
        print(f"Humidity: {humidity}, Temperature: {temperature}, Prediction: {prediction}")
```

1. **传感器数据采集**：使用`Adafruit_DHT`库读取DHT11传感器的湿度、温度数据。通过`read_dht_sensor`函数实现数据的读取。

2. **数据处理**：对采集到的传感器数据进行预处理，包括数据清洗和特征提取。在`preprocess_data`函数中，首先对数据进行校验，确保数据的准确性。然后提取湿度、温度等特征，形成特征向量。

3. **机器学习模型训练**：使用`sklearn.ensemble.RandomForestClassifier`实现随机森林分类器。在`train_model`函数中，将预处理后的数据划分为特征矩阵`X`和标签向量`y`，然后使用随机森林分类器进行训练。

4. **预测食材新鲜度**：在`predict_newness`函数中，对新的传感器数据进行预处理，然后使用训练好的模型进行预测，返回食材的新鲜度预测结果。
