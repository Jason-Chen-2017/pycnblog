**3.3 Python代码示例**

- **K-means算法Python代码**：

```python
from sklearn.cluster import KMeans
import numpy as np

# 数据准备
data = np.array([[1, 2], [1, 4], [1, 0]])

# 初始化KMeans模型
kmeans = KMeans(n_clusters=2, random_state=0).fit(data)

# 输出聚类结果
print(kmeans.labels_)
```

- **SVM算法Python代码**：

```python
from sklearn.svm import SVC
import numpy as np

# 数据准备
X = np.array([[1, 2], [2, 3], [4, 3], [5, 7]])
y = np.array([0, 0, 1, 1])

# 初始化SVM模型
clf = SVC(kernel='linear')

# 训练模型
clf.fit(X, y)

# 预测新数据
print(clf.predict([[3, 2]]))
```

**3.4 算法原理数学模型与公式**

- **K-means算法数学模型**：

$$
\text{Cost} = \sum_{i=1}^{n} \sum_{j=1}^{k} \min_{x_i} \| x_i - \mu_j \|^2
$$

- **SVM算法数学模型**：

$$
\text{最大间隔分类面} W \text{和偏移量} b:
\begin{cases}
\min_{w,b}\frac{1}{2}||w||^2 \\
s.t. \ y_i(\textbf{w} \cdot \textbf{x}_i + b) \geq 1
\end{cases}
$$

**3.5 通俗易懂的举例说明**

- **K-means算法举例**：

假设有四组数据点 (1, 2), (1, 4), (1, 0), (4, 3)。通过K-means算法将这些数据点分为两个簇。

- **SVM算法举例**：

有一组数据点，其中两个类别。使用SVM算法找到一条分类线，使得两个类别间隔最大化。

- **逻辑回归模型**：预测概率。

**4.2 数学公式讲解**

- **线性回归模型**：

$$
\text{最小化目标函数} \ \min_{\theta} \ \sum_{i=1}^{m} (\theta^T \textbf{x}_i - y_i)^2
$$

- **逻辑回归模型**：

$$
\text{概率分布} \ P(y=1 | \textbf{x}; \ \theta) = \frac{1}{1 + e^{-(\theta^T \textbf{x})}}
$$
