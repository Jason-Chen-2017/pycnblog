#### 3.3.1 损失函数

在深度学习中，常用的损失函数包括交叉熵损失函数（Cross-Entropy Loss）和二元交叉熵损失函数（Binary Cross-Entropy Loss）。以下是其latex表示和解释：

```latex
\begin{equation}
J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} [y^{(i)} \log(a^{(i)}_1) + (1 - y^{(i)}) \log(1 - a^{(i)}_1)]
\end{equation}
```

这里的$J(\theta)$表示损失函数，$m$表示样本数量，$y^{(i)}$表示第$i$个样本的真实标签，$a^{(i)}_1$表示模型对第$i$个样本的预测概率。

#### 3.3.2 优化算法

```latex

\theta_{\text{new}} = \theta_{\text{old}} - \alpha \nabla_{\theta} J(\theta)
\end{equation}
```

```latex
\begin{equation}
m_t = \beta_1 m_{t-1} + (1 - \beta_1) \nabla_{\theta} J(\theta) \\
v_t = \beta_2 v_{t-1} + (1 - \beta_2) \frac{\nabla_{\theta}^2 J(\theta)}{m_t}
\end{equation}
```

这里的$\theta$表示模型参数，$\alpha$表示学习率，$m_t$和$v_t$分别表示一阶和二阶矩估计。

#### 3.3.3 评价指标

```latex
\begin{equation}
\text{Accuracy} = \frac{TP + TN}{TP + FN + FP + TN}

```

```latex

\text{F1 Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
\end{equation}
```

这里的$TP$表示真正例（True Positive），$TN$表示真负例（True Negative），$FP$表示假正例（False Positive），$FN$表示假负例（False Negative）。
