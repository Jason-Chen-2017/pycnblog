## 第1章：智能水资源管理决策的背景介绍

### 1.1.1 问题背景

随着全球人口的增长和城市化的快速发展，水资源短缺和污染问题日益严重。许多地区面临水资源供需矛盾，农业灌溉用水不足，工业用水质量不达标，城市供水紧张等问题。水资源管理决策成为解决这些问题的关键环节，而智能水资源管理决策技术的出现为这一挑战带来了新的希望。

智能水资源管理决策是指利用人工智能技术，特别是AI Agent，对水资源进行自动化监测、分析和决策支持的过程。通过收集和分析大量的实时数据，AI Agent能够对水资源状况进行预测和评估，从而为管理者提供科学的决策依据。这种方法可以显著提高水资源管理的效率和质量，减少人为干预，降低水资源浪费和污染的风险。

### 1.1.2 问题描述

水资源管理决策过程中主要面临以下几个问题：

1. **数据多样性**：水资源数据包括水文数据、气象数据、水质数据等多个方面，这些数据的种类和来源各异，需要有效的整合和分析。
2. **动态变化**：水资源状况是动态变化的，不同时间、不同地点的水资源状况可能存在显著差异，需要实时监测和快速响应。
3. **不确定性**：水资源系统受到自然因素和人为活动的干扰，存在很大的不确定性，这使得传统的确定性方法难以有效应对。
4. **复杂约束**：水资源管理需要考虑多方面的约束，如用水量限制、水质标准、生态保护要求等，如何平衡这些约束是一个重要的挑战。

### 1.1.3 问题解决方法

为了解决上述问题，智能水资源管理决策提出了一系列创新方法：

1. **数据整合**：通过数据挖掘、数据融合等技术，将不同来源、不同类型的数据进行整合，形成一个全面、统一的水资源数据视图。
2. **实时监测**：利用物联网技术、传感器网络等技术，实现对水资源的实时监测和采集，确保数据的实时性和准确性。
3. **机器学习与预测**：利用机器学习算法，对历史数据进行分析和建模，预测水资源的变化趋势和需求，为决策提供科学依据。
4. **多目标优化**：采用多目标优化算法，综合考虑水资源管理的多个约束和目标，找到最优的解决方案。

### 1.1.4 边界与外延

智能水资源管理决策的边界主要涉及以下几个方面：

1. **技术范围**：主要技术包括数据采集、数据分析、算法模型、决策支持系统等。
2. **应用领域**：主要应用于水资源规划、水资源调配、水资源保护、水资源污染监测等领域。
3. **环境因素**：需要考虑水文地质条件、气象条件、生态环境等因素。

智能水资源管理决策的外延包括以下几个方面：

1. **跨学科合作**：涉及水资源学、环境科学、计算机科学、数学等多个学科。
2. **国际合作**：全球水资源短缺问题需要国际合作和共享经验。
3. **可持续发展**：智能水资源管理决策需要考虑水资源的可持续利用和生态环境保护。

### 1.1.5 概念结构与核心要素组成

智能水资源管理决策的核心概念结构包括以下几个要素：

1. **数据采集**：通过传感器、监测站等方式，实时采集水资源相关数据。
2. **数据分析**：利用数据挖掘、机器学习等技术，对采集的数据进行预处理和分析。
3. **决策模型**：建立水资源管理决策模型，包括预测模型、优化模型等。
4. **决策支持系统**：开发决策支持系统，为水资源管理者提供实时、科学的决策支持。
5. **执行反馈**：根据决策支持系统的建议，执行相应的管理措施，并对效果进行评估和反馈。

通过以上核心要素的相互作用，智能水资源管理决策能够实现自动化、智能化、高效化的水资源管理。本章介绍了智能水资源管理决策的背景、问题描述、问题解决方法以及边界与外延，为后续章节的深入探讨奠定了基础。

## 第2章：核心概念与联系

### 2.1 AI Agent的定义与特点

AI Agent，即人工智能代理，是指能够自主感知环境、制定计划并采取行动的智能实体。它具有以下基本特点：

1. **自主性**：AI Agent可以独立进行决策和行动，无需人为干预。
2. **适应性**：AI Agent能够根据环境的变化，自适应地调整其行为和策略。
3. **学习性**：AI Agent通过学习历史数据和经验，不断改进其性能。
4. **协作性**：AI Agent可以与其他Agent协作，共同完成任务。
5. **预测性**：AI Agent能够预测未来事件的发生，为决策提供依据。

### 2.2 AI Agent在水资源管理中的重要性

在水资源管理中，AI Agent的重要性主要体现在以下几个方面：

1. **优化水资源分配**：AI Agent可以基于实时数据，对水资源分配进行动态调整，实现水资源的优化利用。
2. **预测水资源需求**：AI Agent可以通过数据分析，预测未来水资源的需求趋势，帮助管理者提前做好准备。
3. **水资源污染监测**：AI Agent可以实时监测水质指标，及时发现污染问题，并采取措施进行治理。
4. **决策支持**：AI Agent可以为水资源管理者提供科学的决策支持，减少决策的主观性和不确定性。
5. **提高管理效率**：AI Agent可以自动化完成大量重复性工作，提高水资源管理的效率和准确性。

### 2.3 AI Agent与传统水资源管理技术的对比

传统水资源管理技术主要依赖于人工监测和经验判断，存在以下不足：

1. **实时性不足**：传统方法难以实现实时监测和数据更新，导致决策滞后。
2. **数据依赖性高**：传统方法对数据的依赖性较高，数据处理和分析能力有限。
3. **适应性差**：传统方法难以应对水资源系统复杂性和动态变化。
4. **决策准确性低**：传统方法基于经验判断，难以保证决策的准确性和科学性。

相比之下，AI Agent具有以下优势：

|--------------------|-------------------|-----------------------------|
| 自适应性           | 高                | 低                          |
| 学习能力           | 强                | 弱                          |
| 鲁棒性             | 强                | 弱                          |
| 预测能力           | 高                | 低                          |

### 2.4 AI Agent的基本架构与工作原理

AI Agent的基本架构通常包括以下几个部分：

1. **感知模块**：用于采集环境数据，如水质、水量、气象等。
2. **知识库**：存储与水资源管理相关的知识、规则和模型。
3. **推理引擎**：用于处理感知模块收集到的数据，结合知识库中的信息，生成决策建议。
4. **行动模块**：根据推理引擎生成的决策建议，执行相应的管理措施。
5. **反馈模块**：收集执行结果，对AI Agent的行为进行评估和调整。

AI Agent的工作原理如下：

1. **感知**：AI Agent通过传感器等设备收集环境数据。
2. **分析**：AI Agent对感知到的数据进行分析和处理，提取有用信息。
3. **决策**：AI Agent结合知识库中的信息，利用推理引擎生成决策建议。
4. **执行**：AI Agent根据决策建议，执行相应的管理措施。
5. **反馈**：AI Agent收集执行结果，进行评估和调整，以优化后续决策。

通过以上工作流程，AI Agent能够实现对水资源的自动化、智能化管理，为水资源管理者提供有力的支持。

## 第4章：水资源管理中的AI Agent应用案例

### 4.1 案例一：智能灌溉系统的AI Agent应用

智能灌溉系统是一种利用AI Agent进行水资源管理的技术，旨在通过自动化和智能化的手段，优化农业灌溉过程，实现节水、增产和环境保护。以下是一个具体的案例：

**背景**：某农业公司拥有一个大面积的农场，种植了多种农作物。由于地理位置和气候条件的变化，农场的灌溉需求不断波动，导致水资源浪费和作物生长不均。

**解决方案**：该公司引入了一套智能灌溉系统，其中包括AI Agent、传感器网络和灌溉设备。AI Agent作为系统的核心组件，负责分析农场的环境数据，制定灌溉策略。

**工作流程**：

1. **数据采集**：传感器网络分布在农田的各个角落，实时监测土壤湿度、降水量、气温等环境参数。
2. **数据预处理**：AI Agent接收传感器数据，进行预处理，包括数据清洗、去噪、特征提取等。
3. **模型训练**：AI Agent利用历史数据和机器学习算法，建立土壤湿度与灌溉量之间的关系模型。
4. **实时灌溉**：根据实时监测数据和模型预测，AI Agent自动调整灌溉设备的运行状态，实现精准灌溉。
5. **反馈优化**：AI Agent收集灌溉效果数据，结合历史数据，不断优化模型，提高灌溉效率。

**效果评估**：

- **节水效果**：通过智能灌溉，农场的用水量减少了30%以上，达到了显著节水效果。
- **作物产量**：智能灌溉使得农作物生长更加均衡，产量提高了20%。
- **环境污染**：减少了过量灌溉导致的水资源浪费和土壤污染。

### 4.2 案例二：水资源调配优化中的AI Agent应用

水资源调配优化是智能水资源管理中的关键环节，AI Agent在水资源调配优化中的应用能够显著提高水资源的利用效率和调配效果。以下是一个具体的案例：

**背景**：某城市的水资源调配系统面临供水需求不均衡、水资源利用效率低的问题。该城市的水资源主要来自河流、水库和地下水，供水管网复杂，不同区域的水需求差异较大。

**解决方案**：该城市引入了AI Agent，通过优化水资源调配策略，提高水资源利用效率。

**工作流程**：

1. **数据采集**：AI Agent接入城市的水资源监测系统，实时获取河流流量、水库水位、地下水水位、供水管网压力等数据。

#### 6.1.1 决策树算法的基本原理

决策树（Decision Tree）是一种常用的机器学习算法，它通过一系列规则（即节点）来表示决策过程，每个节点对应一个特征，每个分支对应一个可能的值。决策树的目的是根据输入特征，将数据集中的实例分配到不同的类别或进行数值预测。

决策树的基本原理如下：

1. **根节点**：从整个数据集开始，选择一个最佳特征进行划分。
2. **划分**：根据选定的特征，将数据集划分为多个子集。
3. **递归**：对每个子集继续划分，直到满足停止条件（如最大深度、最小样本量等）。
4. **叶节点**：最终每个子集都会形成一个叶节点，叶节点代表一个具体的类别或数值。

#### 6.1.2 决策树算法的实现

决策树算法的实现主要包括以下几个步骤：

1. **选择特征**：利用信息增益（Information Gain）或基尼不纯度（Gini Impurity）等指标，选择具有最高划分能力的特征。
2. **划分数据集**：根据选定的特征，将数据集划分为多个子集。
3. **递归构建**：对每个子集继续划分，直到满足停止条件。
4. **剪枝**：为了避免过拟合，可以对决策树进行剪枝，减少树的复杂度。

#### 6.3.1 神经网络的基本原理

神经网络（Neural Network）是一种模拟生物神经元之间相互连接的数学模型，具有自适应学习和预测能力。神经网络通过多层神经元之间的连接，实现数据的输入、处理和输出。

神经网络的基本原理如下：

1. **输入层**：接收外部输入数据。
2. **隐藏层**：对输入数据进行处理和变换。
3. **输出层**：输出最终的结果。

神经网络的训练过程包括以下几个步骤：

1. **前向传播**：将输入数据通过隐藏层，逐层传递到输出层，计算输出结果。
2. **反向传播**：根据输出结果与真实值的误差，反向传播误差，更新网络权重和偏置。
3. **迭代训练**：重复前向传播和反向传播，逐步减小误差，直到满足停止条件。

Python代码示例：

```python
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split

# 生成月亮形数据集
X, y = make_moons(n_samples=100, noise=0.1, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 初始化神经网络参数
input_size = X_train.shape[1]
hidden_size = 64
output_size = 1

w1 = np.random.randn(input_size, hidden_size)
b1 = np.random.randn(hidden_size)
w2 = np.random.randn(hidden_size, output_size)
b2 = np.random.randn(output_size)

# 定义激活函数
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 定义前向传播
def forward(x):
    z1 = np.dot(x, w1) + b1
    a1 = sigmoid(z1)
    z2 = np.dot(a1, w2) + b2
    a2 = sigmoid(z2)
    return a2

# 定义反向传播
def backward(a2, y):
    error = a2 - y
    d2 = error * sigmoid_derivative(a2)
    d1 = np.dot(d2, w2.T) * sigmoid_derivative(a1)

    dw2 = np.dot(a1.T, d2)
    db2 = np.sum(d2, axis=0)
    dw1 = np.dot(x.T, d1)
    db1 = np.sum(d1, axis=0)

    return dw1, dw2, db1, db2

# 定义学习率
learning_rate = 0.1

# 训练神经网络
for epoch in range(1000):
    # 前向传播
    a2 = forward(X_train)

    # 反向传播
    dw1, dw2, db1, db2 = backward(a2, y_train)

    # 更新参数
    w1 -= learning_rate * dw1
    b1 -= learning_rate * db1
    w2 -= learning_rate * dw2
    b2 -= learning_rate * db2

# 测试模型性能
a2 = forward(X_test)
print("Accuracy:", np.mean((a2 > 0.5) == y_test))
```

## 第7章：算法原理的数学模型和公式

### 7.1 决策树算法的数学模型

决策树的数学模型主要涉及信息增益（Information Gain）和信息增益率（Gain Ratio）等概念。

#### 7.1.1 决策树的基本概念

- **信息增益**（Information Gain）：表示一个特征对数据集的划分能力。计算公式如下：

  $$
  IG(D, A) = H(D) - \sum_{v \in A} \frac{|D_v|}{|D|} H(D_v)
  $$

  其中，$H(D)$表示数据集$D$的熵（Entropy），$D_v$表示数据集$D$按特征$A$划分后的子集，$|D|$和$|D_v|$分别表示数据集$D$和子集$D_v$的样本数。

- **信息增益率**（Gain Ratio）：考虑特征划分后数据集的均匀性，计算公式如下：

  $$
  GR(D, A) = \frac{IG(D, A)}{\log_2(|D|)}
  $$

  其中，$\log_2(|D|)$表示数据集$D$的样本数。

#### 7.1.2 信息增益与增益率

信息增益和信息增益率是选择最佳特征的标准。信息增益越大，特征对数据集的划分能力越强；信息增益率越大，特征的划分能力越均匀。在决策树构建过程中，通常选择具有最大信息增益或信息增益率的特征进行划分。

#### 7.1.3 决策树剪枝

决策树剪枝（Pruning）是一种防止过拟合（Overfitting）的方法，通过删除决策树中不必要的分支，简化模型，提高泛化能力。

剪枝方法主要包括以下两种：

1. **预剪枝**（Pre-pruning）：在决策树生成过程中，提前停止进一步划分，以避免生成过于复杂的树。常用的预剪枝方法包括最小深度限制、最小叶节点样本数限制等。

2. **后剪枝**（Post-pruning）：在决策树生成完成后，删除部分子节点，以简化模型。常用的后剪枝方法包括减少错误剪枝、成本复杂度剪枝等。

### 7.2 支持向量机的数学模型

支持向量机（Support Vector Machine，SVM）的数学模型主要涉及硬间隔（Hard Margin）和软间隔（Soft Margin）等概念。

#### 7.2.1 支持向量机的定义

支持向量机是一种通过找到一个最优超平面，将不同类别的数据点分隔开的机器学习算法。硬间隔（Hard Margin）和软间隔（Soft Margin）是SVM的两种主要形式。

1. **硬间隔**（Hard Margin）：当数据集线性可分时，SVM试图找到一个最优超平面，使得分类边界最大化，即最大化两个类别的分类边界距离。硬间隔的优化问题如下：

   $$
   \begin{align*}
   \min_{\boldsymbol{w}, b} & \quad \frac{1}{2}||\boldsymbol{w}||^2 \\
   \text{subject to} & \quad y^{(i)}(\boldsymbol{w}^T\boldsymbol{x}^{(i)} + b) \geq 1
   \end{align*}
   $$

   其中，$\boldsymbol{w}$是超平面的法向量，$b$是超平面的偏置，$y^{(i)}$是第$i$个样本的标签，$\boldsymbol{x}^{(i)}$是第$i$个样本的特征向量。

2. **软间隔**（Soft Margin）：当数据集线性不可分时，SVM引入软间隔（Soft Margin），允许一定数量的错误分类，并利用惩罚项（Penalty）平衡分类边界和错误分类。软间隔的优化问题如下：

   $$
   \begin{align*}
   \min_{\boldsymbol{w}, b, \xi} & \quad \frac{1}{2}||\boldsymbol{w}||^2 + C \sum_{i=1}^n \xi_i \\
   \text{subject to} & \quad y^{(i)}(\boldsymbol{w}^T\boldsymbol{x}^{(i)} + b) \geq 1 - \xi_i \\
   & \quad \xi_i \geq 0, \quad i = 1, 2, \ldots, n
   \end{align*}
   $$

   其中，$C$是惩罚参数，用于控制错误分类的容忍度，$\xi_i$是第$i$个样本的松弛变量。

#### 7.2.2 核函数的选择

核函数（Kernel Function）是SVM中的关键组成部分，用于将低维数据映射到高维特征空间，从而实现线性可分。常见的核函数包括线性核、多项式核、径向基核（RBF）等。

1. **线性核**（Linear Kernel）：

   $$
   K(\boldsymbol{x}^{(i)}, \boldsymbol{x}^{(j)}) = \boldsymbol{x}^{(i)} \cdot \boldsymbol{x}^{(j)}
   $$

2. **多项式核**（Polynomial Kernel）：

   $$
   K(\boldsymbol{x}^{(i)}, \boldsymbol{x}^{(j)}) = (\boldsymbol{x}^{(i)} \cdot \boldsymbol{x}^{(j)} + 1)^d
   $$

   其中，$d$是多项式的度。

3. **径向基核**（RBF Kernel）：

   $$
   K(\boldsymbol{x}^{(i)}, \boldsymbol{x}^{(j)}) = \exp(-\gamma ||\boldsymbol{x}^{(i)} - \boldsymbol{x}^{(j)}||^2)
   $$

   其中，$\gamma$是调节核函数的宽度。

#### 7.2.3 最大边界超平面

最大边界超平面（Maximum Margin Hyperplane）是SVM的核心目标，即找到一个最优超平面，使得分类边界最大化。在硬间隔情况下，最大边界超平面可以表示为：

$$
\boldsymbol{w}^* = \arg\min_{\boldsymbol{w}, b} \frac{1}{2}||\boldsymbol{w}||^2 \quad \text{subject to} \quad y^{(i)}(\boldsymbol{w}^T\boldsymbol{x}^{(i)} + b) \geq 1
$$

在软间隔情况下，最大边界超平面可以表示为：

$$
\boldsymbol{w}^* = \arg\min_{\boldsymbol{w}, b, \xi} \frac{1}{2}||\boldsymbol{w}||^2 + C \sum_{i=1}^n \xi_i \quad \text{subject to} \quad y^{(i)}(\boldsymbol{w}^T\boldsymbol{x}^{(i)} + b) \geq 1 - \xi_i, \quad \xi_i \geq 0
$$

### 7.3 神经网络的数学模型

神经网络（Neural Network）的数学模型主要涉及神经元模型、激活函数和反向传播算法等概念。

#### 7.3.1 神经元模型

神经网络中的神经元可以表示为：

$$
a_i(\theta) = \sigma(\theta_0 + \sum_{j=1}^n \theta_j x_j)
$$

其中，$a_i$是第$i$个神经元的输出，$\theta_j$是连接权重，$x_j$是输入特征，$\sigma$是激活函数。

#### 7.3.2 激活函数

激活函数（Activation Function）用于引入非线性特性，常见的激活函数包括：

1. ** sigmoid函数**：

   $$
   \sigma(x) = \frac{1}{1 + \exp(-x)}
   $$

2. **ReLU函数**：

   $$
   \sigma(x) = \max(0, x)
   $$

3. **Tanh函数**：

   $$
   \sigma(x) = \frac{2}{1 + \exp(-2x)} - 1
   $$

#### 7.3.3 反向传播算法

反向传播算法（Backpropagation Algorithm）是神经网络训练的核心算法，用于更新网络权重和偏置。

反向传播算法包括以下步骤：

1. **前向传播**：计算网络输出，计算实际输出与期望输出的误差。
2. **计算梯度**：计算每个权重的梯度，即误差对每个权重的偏导数。
3. **更新权重**：利用梯度下降算法，更新网络权重和偏置。

具体步骤如下：

1. **前向传播**：

   $$
   z_l = \theta_l^T a_{l-1}
   $$
   $$
   a_l = \sigma(z_l)
   $$

2. **计算梯度**：

   $$
   \delta_l = (a_l - t_l) \odot \sigma'(z_l)
   $$
   $$
   \frac{\partial L}{\partial \theta_l} = a_{l-1}^T \delta_l
   $$
   $$
   \frac{\partial L}{\partial b_l} = \delta_l
   $$

3. **更新权重和偏置**：

   $$
   \theta_l := \theta_l - \alpha \frac{\partial L}{\partial \theta_l}
   $$
   $$
   b_l := b_l - \alpha \frac{\partial L}{\partial b_l}
   $$

通过以上步骤，反向传播算法不断更新网络参数，逐步减小误差，提高网络性能。

### 8.1 决策树算法举例

假设我们有一个简单的决策树模型，用于预测灌溉量。特征包括降水量（P）和水库水位（W），目标值是灌溉量（I）。我们希望找到最佳划分规则，以最小化预测误差。

**步骤 1：计算信息增益**

对于特征P，信息增益的计算如下：

$$
IG(P, I) = H(I) - \sum_{v \in P} \frac{|I_v|}{|I|} H(I_v)
$$

其中，$H(I)$是灌溉量的熵，$I_v$是按降水量划分后的子集。

假设灌溉量的熵为$H(I) = 0.897$，按降水量划分的子集为$P_1$和$P_2$，灌溉量分别为$I_1$和$I_2$，子集的熵分别为$H(I_1) = 0.5$和$H(I_2) = 0.9$。

$$
IG(P, I) = 0.897 - \frac{0.3}{0.5} \cdot 0.5 - \frac{0.7}{0.5} \cdot 0.9 = 0.098
$$

对于特征W，信息增益的计算如下：

$$
IG(W, I) = H(I) - \sum_{v \in W} \frac{|I_v|}{|I|} H(I_v)
$$

其中，$H(I)$是灌溉量的熵，$I_v$是按水库水位划分后的子集。

假设灌溉量的熵为$H(I) = 0.897$，按水库水位划分的子集为$W_1$和$W_2$，灌溉量分别为$I_1$和$I_2$，子集的熵分别为$H(I_1) = 0.5$和$H(I_2) = 0.9$。

$$
IG(W, I) = 0.897 - \frac{0.3}{0.5} \cdot 0.5 - \frac{0.7}{0.5} \cdot 0.9 = 0.098
$$

**步骤 2：选择最佳特征**

比较信息增益，选择信息增益最大的特征作为划分特征。在本例中，特征P和W的信息增益相同，我们可以选择任意一个作为划分特征。

**步骤 3：划分数据集**

选择特征P作为划分特征，根据降水量的不同划分数据集。假设划分为$P_1$（降水量小于50 mm）和$P_2$（降水量大于等于50 mm）。

对于$P_1$，继续选择水库水位作为划分特征。假设水库水位划分为$W_1$（水库水位小于1 m）和$W_2$（水库水位大于等于1 m）。

对于$W_1$，灌溉量全部为50 L/h。

对于$W_2$，灌溉量全部为100 L/h。

对于$P_2$，继续选择水库水位作为划分特征。假设水库水位划分为$W_3$（水库水位小于1 m）和$W_4$（水库水位大于等于1 m）。

对于$W_3$，灌溉量全部为100 L/h。

对于$W_4$，灌溉量全部为150 L/h。

**步骤 4：构建决策树模型**

根据划分结果，构建决策树模型如下：

```
 irrigation(I)
   /        \
  50       100
 /   \     /   \
P1    P2  W1    W2
|     |    |     |
50    100  50    100
```

**步骤 5：预测灌溉量**

根据决策树模型，我们可以预测任意给定降水量和水库水位下的灌溉量。例如，当降水量为60 mm，水库水位为1.2 m时，根据决策树模型，灌溉量为100 L/h。

### 8.3 神经网络举例

假设我们有一个简单的神经网络模型，用于预测未来24小时的降水量。输入层包含3个神经元，隐藏层包含10个神经元，输出层包含1个神经元。

**步骤 1：初始化网络参数**

初始化网络参数，包括输入层、隐藏层和输出层的权重和偏置。

```python
import numpy as np

# 初始化网络参数
input_size = 3
hidden_size = 10
output_size = 1

w1 = np.random.randn(input_size, hidden_size)
b1 = np.random.randn(hidden_size)
w2 = np.random.randn(hidden_size, output_size)
b2 = np.random.randn(output_size)
```

**步骤 2：定义激活函数**

定义sigmoid激活函数。

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```

**步骤 3：定义前向传播**

定义前向传播函数，计算神经网络输出。

```python
def forward(x):
    z1 = np.dot(x, w1) + b1
    a1 = sigmoid(z1)
    z2 = np.dot(a1, w2) + b2
    a2 = sigmoid(z2)
    return a2
```

**步骤 4：定义反向传播**

定义反向传播函数，计算误差和梯度。

```python
def backward(a2, y):
    error = a2 - y
    d2 = error * sigmoid_derivative(a2)
    d1 = np.dot(d2, w2.T) * sigmoid_derivative(a1)

    dw2 = np.dot(a1.T, d2)
    db2 = np.sum(d2, axis=0)
    dw1 = np.dot(x.T, d1)
    db1 = np.sum(d1, axis=0)

    return dw1, dw2, db1, db2
```

**步骤 5：定义学习率**

定义学习率。

```python
learning_rate = 0.1
```

**步骤 6：训练神经网络**

训练神经网络，不断更新参数，减小误差。

```python
# 训练神经网络
for epoch in range(1000):
    # 前向传播
    a2 = forward(x)

    # 反向传播
    dw1, dw2, db1, db2 = backward(a2, y)

    # 更新参数
    w1 -= learning_rate * dw1
    b1 -= learning_rate * db1
    w2 -= learning_rate * dw2
    b2 -= learning_rate * db2
```

**步骤 7：评估模型性能**

评估训练好的神经网络模型，计算预测误差。

```python
# 评估模型性能
predicted_output = forward(x)
error = predicted_output - y
print("Error:", error)
```
