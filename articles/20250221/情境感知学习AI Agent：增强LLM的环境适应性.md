**代码示例：**

```python

def analyze_intention(input_text):
    response = openai.Completion.create(
        model="gpt-3.5-turbo",
        prompt=f"请分析以下文本的意图：{input_text}",
        max_tokens=100
    )
    return response.choices[0].message.content
```
