## 第三部分：算法原理

### 第3章：算法原理

#### 3.1 Granger因果检验
- **定义**：通过回归分析检验变量间是否存在因果关系。
- **步骤**：构建回归模型，计算F统计量和p值。
- **代码示例**：
  ```python
  import statsmodels.api as sm

  def granger_causality_test(data, max_lag=1):
      results = {}
      for lag in range(1, max_lag+1):
          model = sm.tsa.VAR(data).fit(maxlags=lag)
          results[lag] = model.rsquared
      return results
  ```
- **数学模型**：
  $$ F = \frac{(R^2_{full} - R^2_{restricted}) / lag}{(1 - R^2_{full}) / (n - lag - 1)} $$
