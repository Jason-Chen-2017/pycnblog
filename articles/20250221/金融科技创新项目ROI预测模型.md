### 第3章: ROI预测模型的数学基础

#### 3.1 基础数学概念与公式
- 3.1.1 ROI计算公式
  $$ ROI = \frac{\text{净收益}}{\text{投资成本}} \times 100\% $$
- 3.1.2 时间价值与贴现率
  $$ PV = \frac{CF}{(1 + r)^n} $$
  - PV：现值
  - CF：未来现金流
  - r：贴现率
  - n：时间周期

#### 3.2 概率论与统计学基础
- 3.2.1 概率分布与期望值
  $$ E[X] = \sum_{i=1}^{n} P_i X_i $$
- 3.2.2 回归分析与相关性
  $$ Y = \beta_0 + \beta_1 X + \epsilon $$
  - Y：因变量
  - X：自变量
  - β0：截距
  - β1：回归系数
  - ε：误差项

#### 3.3 数据预处理与特征工程

### 第4章: ROI预测模型的算法原理

#### 4.1 常见算法选择与对比
- 4.1.1 线性回归
  - 优点：简单易懂，计算速度快。
  - 缺点：假设变量间线性关系，可能不适用于复杂场景。
- 4.1.2 支持向量机（SVM）
  - 优点：适合小样本数据，泛化能力强。
  - 缺点：计算复杂，参数选择敏感。
- 4.1.3 随机森林与集成学习
  - 优点：适合高维数据，抗过拟合。
  - 缺点：解释性较差，计算资源消耗大。
- 4.1.4 神经网络与深度学习
  - 优点：适合复杂非线性关系，模型容量大。
  - 缺点：计算复杂，需要大量数据。

  - 模型训练：使用训练数据训练模型。

- 4.2.3 模型评估与验证
  - 模型评估：使用测试数据评估模型性能。
  - 评估指标：准确率、召回率、F1值、ROC-AUC。

import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error

# 数据加载
data = pd.read_csv('financial_projects.csv')

# 特征与标签分离
X = data.drop('ROI', axis=1)
y = data['ROI']

# 模型训练
model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(X, y)

# 模型预测
predicted ROI = model.predict(X)

# 模型评估
 mse = mean_squared_error(y, predicted ROI)
 print(f'MSE: {mse}')
