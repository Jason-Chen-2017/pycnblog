## 第1章: 多智能体系统基础

### 1.1 多智能体系统的基本概念

#### 1.1.1 多智能体系统的定义
多智能体系统（Multi-Agent System, MAS）是由多个独立但协作的智能体组成的系统。这些智能体通过交互和协同完成复杂任务，通常用于模拟现实世界中的分布式问题。

#### 1.1.2 多智能体系统的结构与特点
- **结构**：由多个智能体、环境、通信机制和任务目标组成。
- **特点**：
  - 分布式计算
  - 异步性
  - 自适应性
  - 协作性

#### 1.1.3 多智能体系统与传统单智能体的区别
- **计算方式**：单智能体集中处理，多智能体分布式处理。
- **协作性**：单智能体独立，多智能体需要协作。
- **动态性**：多智能体系统更具动态性和适应性。

### 1.2 经济周期指标的基本概念

#### 1.2.1 经济周期的定义与特征
经济周期是指经济活动的波动，通常包括复苏、繁荣、衰退和萧条四个阶段。

#### 1.2.2 常见经济周期指标
- **GDP**：国内生产总值。
- **失业率**：劳动力市场的指标。
- **通胀率**：物价水平的指标。
- **PMI**：采购经理指数。

#### 1.2.3 经济周期指标的动态变化特征
经济指标会随着经济周期的变化而波动，具有动态性和复杂性。

### 14.2 核心代码实现

```python
import numpy as np
import pandas as pd
from sklearn.metrics import pairwise_distances

def adaptive_economic_indicator(data, window_size=10):
    # 计算移动平均值
    moving_avg = data.rolling(window_size).mean()
    # 计算动态时间 warping
    dtw = pairwise_distances(moving_avg.values, moving_avg.values)
    return dtw

# 示例数据
data = pd.DataFrame({
    'GDP': [2, 3, 5, 4, 6, 7, 8, 9, 10, 11],
    '失业率': [5, 4, 3, 2, 1, 2, 3, 4, 5, 6]
})

# 调用函数
result = adaptive_economic_indicator(data)
print(result)
```

- **数据处理**：使用pandas进行数据处理。
- **算法实现**：使用scikit-learn中的动态时间 warping 算法。
- **结果分析**：根据结果调整经济指标。
