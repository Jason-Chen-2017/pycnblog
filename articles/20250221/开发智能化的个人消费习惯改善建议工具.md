## 第3章: 推荐算法与消费行为分析

### 3.1 协同过滤算法
- **原理**：基于用户历史行为相似性推荐。
- **实现步骤**：
  1. 数据预处理：归一化和缺失值处理。
  2. 相似性计算：使用余弦相似度或欧氏距离。
  3. 推荐生成：基于相似用户的平均评分或加权评分。
- **代码示例**：

### 3.2 基于内容的推荐算法
- **原理**：基于商品或服务本身的特征进行推荐。
- **实现步骤**：
  1. 商品特征提取：使用TF-IDF或Word2Vec。
  2. 相似性计算：基于商品特征向量的相似度。
  3. 推荐生成：基于商品特征的加权推荐。

- **原理**：结合协同过滤和基于内容的推荐，提升推荐效果。
- **实现步骤**：
  1. 分别生成协同过滤和基于内容的推荐列表。

### 5.2 核心功能实现

- **结果展示**：通过可视化展示消费建议。

### 5.3 代码实现
```python
import numpy as np
import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity

def load_data():
    # 加载消费数据
    data = pd.read_csv('consumption.csv')
    return data

def preprocess_data(data):
    # 数据清洗和归一化
    data.dropna(inplace=True)
    data['amount'] = data['amount'].apply(lambda x: x / max(data['amount']))
    return data

def train_model(data):
    # 训练协同过滤模型
    user_matrix = data.pivot('user_id', 'category', 'amount').fillna(0)
    similarity_matrix = cosine_similarity(user_matrix)
    return similarity_matrix

def generate_recommendations(user_id, similarity_matrix, data):
    # 生成推荐结果
    user_index = user_matrix.index.get_loc(user_id)
    similar_users = np.argsort(similarity_matrix[user_index])[::-1]
    top_users = similar_users[:5]
    recommendations = []
    for user in top_users:
        for item in user_matrix.iloc[user].nonzero()[0]:
            recommendations.append(item)
    return recommendations

if __name__ == "__main__":
    data = load_data()
    processed_data = preprocess_data(data)
    similarity_matrix = train_model(processed_data)
    recommendations = generate_recommendations(1, similarity_matrix, processed_data)
    print("推荐结果：", recommendations)
```
