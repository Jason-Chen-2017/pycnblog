# 第一部分：价值投资中的风险评估基础

## 第1章：价值投资与风险评估概述

### 1.1 价值投资的基本概念

#### 1.1.1 价值投资的定义与核心理念
价值投资是一种以基本面分析为基础的投资策略，强调以低于内在价值的价格购买优质资产。其核心理念包括：
- **长期视角**：关注企业的长期盈利能力，而非短期价格波动。
- **安全边际**：买入价格低于内在价值，以降低风险。
- **价值发现**：寻找市场低估的优质企业。

#### 1.1.2 价值投资与其它投资策略的对比
- **与趋势投资的区别**：趋势投资关注价格走势，而价值投资关注内在价值。
- **与成长投资的区别**：成长投资侧重高增长企业，而价值投资侧重低估企业。

### 1.2 风险评估的核心概念

#### 1.2.1 风险的定义与分类
- **市场风险**：整体市场波动带来的风险。
- **流动性风险**：资产难以快速变现的风险。
- **信用风险**：债券发行人违约的风险。
- **操作风险**：投资决策失误或操作失误带来的风险。

#### 1.2.2 风险与收益的关系
- 风险与收益呈正相关关系，但高风险并不一定带来高收益。
- 风险调整后收益（RAR）是衡量投资回报的重要指标。

### 1.3 超越波动性的投资策略

#### 1.3.1 股票波动性的定义与特征
- **波动性**：衡量资产价格短期波动程度的指标。
- **波动性对投资决策的影响**：短期波动可能导致投资者恐慌性抛售，影响长期收益。

#### 1.3.2 为什么需要超越波动性
- 股票价格的短期波动受市场情绪影响，但长期表现取决于企业基本面。
- 价值投资者应关注长期趋势，避免被短期波动干扰。

## 第2章：现代风险评估的算法原理

### 2.1 马科维茨的有效投资组合理论

#### 2.1.1 理论概述
- **马科维茨理论**：通过优化投资组合的收益与风险，找到最优风险收益比。
- **数学模型**：
  - 目标函数：最大化收益或最小化风险。
  - 约束条件：投资组合的权重之和为1。

#### 2.1.2 实例分析
假设我们有两只股票A和B，预期收益率分别为10%和15%，波动率分别为15%和20%，相关系数为0.5。计算最优投资组合的权重。

### 2.2 CAPM模型与风险评估

#### 2.2.1 CAPM模型
- **CAPM公式**：
  \[
  E(R_i) = R_f + \beta_i (E(R_m) - R_f)
  \]
  其中，\( R_f \) 是无风险利率，\( \beta_i \) 是股票的贝塔系数，\( E(R_m) \) 是市场预期收益率。

#### 2.2.2 贝塔系数的计算
- 贝塔系数衡量股票相对于市场的波动性，系数大于1表示比市场波动大，小于1则相反。

## 第4章：项目实战

### 4.1 环境安装与代码实现

#### 4.1.1 Python环境安装
- 安装Python、Pandas、NumPy、Matplotlib。

#### 4.1.2 代码实现
```python
import pandas as pd
import numpy as np

# 示例数据
data = {'price': [100, 105, 98, 102, 104]}
df = pd.DataFrame(data)

# 计算波动率
volatility = df['price'].std() / df['price'].mean() * 100
print(f'波动率：{volatility}%')
```
