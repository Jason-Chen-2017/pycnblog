- **3.1.3 蒙特卡洛模拟的Python实现**
  ```python
  import numpy as np

  def monte_carlo_simulation(S, K, T, r, sigma, steps=10000):
      np.random.seed(42)
      dt = T / steps
      prices = S * np.exp(
          (r - 0.5 * sigma**2) * dt + sigma * np.sqrt(dt) * np.random.randn(steps)
      )
      payoff = np.maximum(prices[-1] - K, 0)
      return np.mean(payoff) * np.exp(-r * T)

  # 示例
  S = 100
  K = 105
  T = 1
  r = 0.05
  sigma = 0.2
  print(monte_carlo_simulation(S, K, T, r, sigma))
  ```

### 3.2 Black-Scholes模型的数学推导
- **3.2.1 Black-Scholes公式**
  $$ C = S_0 N(d_1) - K e^{-rT} N(d_2) $$
  $$ d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma \sqrt{T}} $$
  $$ d_2 = d_1 - \sigma \sqrt{T} $$

- **3.2.2 Black-Scholes模型的Python实现**
  ```python
  import numpy as np
  from scipy.stats import norm

  def black_scholes(S, K, T, r, sigma):
      d1 = (np.log(S/K) + (r + sigma**2/2)*T) / (sigma * np.sqrt(T))
      d2 = d1 - sigma * np.sqrt(T)
      return S * norm.cdf(d1) - K * np.exp(-r*T) * norm.cdf(d2)

  # 示例
  S = 100
  K = 105
  T = 1
  r = 0.05
  sigma = 0.2
  print(black_scholes(S, K, T, r, sigma))
  ```
