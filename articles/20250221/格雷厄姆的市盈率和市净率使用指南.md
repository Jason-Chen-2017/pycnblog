# 第一部分：背景介绍

## 第1章：背景介绍

### 1.1 价值投资的起源与发展

- **价值投资的起源**：价值投资起源于20世纪20年代，由本杰明·格雷厄姆和他的学生大卫·多德共同提出。他们认为市场会在短期波动中被情绪左右，但长期来看，股票的价值应基于其基本面。
- **格雷厄姆的投资理念**：格雷厄姆强调安全边际和内在价值，主张以低于内在价值的价格买入股票，从而在长期获得收益。
- **市盈率与市净率的提出**：格雷厄姆在分析股票时，提出了市盈率（P/E）和市净率（P/B）作为衡量股票价值的重要指标。

### 1.2 市盈率与市净率的核心概念

- **市盈率的定义与计算公式**：市盈率是股票价格除以每股收益（EPS），公式为：
  $$市盈率 = \frac{股价}{每股收益}$$
- **市净率的定义与计算公式**：市净率是股票价格除以每股净资产（BPS），公式为：
  $$市净率 = \frac{股价}{每股净资产}$$
- **优缺点对比**：
  | 指标 | 优点 | 缺点 |
  |------|------|------|
  | 市盈率 | 易于计算，反映盈利能力 | 受企业盈利周期影响较大 |
  | 市净率 | 更稳定，反映资产价值 | 受资产质量影响 |

### 1.3 市盈率与市净率的联系与区别

- **联系**：两者都用于衡量股票价格与基本面指标之间的关系，帮助投资者判断股票是否被高估或低估。
- **区别**：市盈率关注盈利能力，市净率关注资产价值；市盈率适用于盈利稳定的公司，市净率适用于资产密集型行业。

## 第2章：核心概念与联系

### 2.1 市盈率与市净率的数学模型

- **市盈率公式**：
  $$市盈率 = \frac{股价}{每股收益}$$
  - 示例：某股票价格为50元，每股收益为5元，则市盈率为10倍。
- **市净率公式**：
  $$市净率 = \frac{股价}{每股净资产}$$
  - 示例：某股票价格为50元，每股净资产为10元，则市净率为5倍。

### 2.2 市盈率与市净率的属性特征对比

  | 适用场景 | 判断盈利能力 | 判断资产价值 |

- **库安装**：安装pandas、numpy、matplotlib用于数据处理和可视化。

### 5.2 核心实现源代码

```python
import pandas as pd
import matplotlib.pyplot as plt

def calculate_pe_ratio(price, eps):
    return price / eps

def calculate_pb_ratio(price, book_value_per_share):
    return price / book_value_per_share

# 示例数据
data = {
    '股票代码': ['AAPL', 'MSFT', 'GOOGL'],
    '股价': [300, 250, 150],
    '每股收益': [10, 12, 8],
    '每股净资产': [50, 40, 30]
}

df = pd.DataFrame(data)

# 计算市盈率和市净率
df['市盈率'] = df['股价'] / df['每股收益']
df['市净率'] = df['股价'] / df['每股净资产']

print(df)

# 可视化
df.plot(kind='bar', y=['市盈率', '市净率'], stacked=True)
plt.title('市盈率和市净率对比')
plt.show()
```
