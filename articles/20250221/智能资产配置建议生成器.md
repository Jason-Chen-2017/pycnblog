## 第3章：算法原理

### 3.1 基于规则的资产配置算法

#### 3.1.1 均值-方差模型

目标：最小化投资组合的方差，同时满足收益目标。

数学模型：
$$
\min_w \quad w^T \Sigma w \\
\text{s.t.} \quad w^T \mu \geq \mu_{target}, \quad 1^T w = 1
$$

Python代码实现：
```python
import numpy as np

def mean_variance_optimization(returns, mu, Sigma):
    n = returns.shape[1]
    Sigma_inv = np.linalg.inv(Sigma)
    w_ml = Sigma_inv @ mu / (mu.T @ Sigma_inv @ mu)
    return w_ml
```

### 3.2 基于机器学习的资产配置算法

### 5.2 核心代码实现

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据获取与预处理
def get_market_data():
    # 示例代码，实际应从API获取
    return pd.DataFrame({'return': [0.01, 0.02, 0.015, 0.03]})

# 模型训练
def train_model(X, y):
    model = LinearRegression()
    model.fit(X, y)
    return model

# 优化计算
def optimize_portfolio(predicted_returns):
    n = predicted_returns.shape[1]
    mu = predicted_returns.mean(axis=0)
    Sigma = predicted_returns.cov()
    inv_Sigma = np.linalg.inv(Sigma)
    w_ml = inv_Sigma @ mu / (mu.T @ inv_Sigma @ mu)
    return w_ml

# 主函数
def main():
    data = get_market_data()
    X = data.iloc[:, :-1]
    y = data.iloc[:, -1]
    model = train_model(X, y)
    predicted_returns = model.predict(X)
    weights = optimize_portfolio(predicted_returns)
    print("配置建议权重：", weights)

if __name__ == '__main__':
    main()
```
