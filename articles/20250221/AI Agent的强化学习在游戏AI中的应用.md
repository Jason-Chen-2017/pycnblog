# 第1章 AI Agent与强化学习概述

## 1.1 AI Agent的基本概念

### 1.1.1 什么是AI Agent
AI Agent（智能体）是能够感知环境并采取行动以实现目标的实体。在游戏AI中，Agent可以控制角色，做出决策，如移动、攻击或互动。

### 1.1.2 AI Agent的核心特征
- **自主性**：无需外部干预，自主决策。
- **反应性**：实时感知环境并响应。
- **目标导向**：根据目标选择行动。
- **学习能力**：通过经验改进性能。

### 1.1.3 AI Agent在游戏中的应用场景
- NPC行为控制
- 自动决策系统
- 竞技游戏AI

## 1.2 强化学习的基本概念

### 1.2.1 强化学习的定义
强化学习（Reinforcement Learning, RL）是通过试错，智能体在环境中学习策略以最大化累积奖励。

### 1.2.2 强化学习的核心要素
- **环境**：智能体所在的场景。
- **状态**：环境的实时信息。
- **动作**：智能体的行动。
- **奖励**：对行动的反馈。

### 1.2.3 强化学习与监督学习的区别
- **监督学习**：基于正确答案的学习。
- **强化学习**：基于奖励的学习，具有探索性。

## 1.3 游戏AI中的强化学习应用

### 1.3.1 游戏AI的基本类型
- **简单脚本**：固定逻辑，如巡逻。
- **有限状态机**：基于状态切换的行为。
- **强化学习AI**：通过试错学习策略。

### 1.3.2 强化学习在游戏AI中的优势
- **自适应性**：能根据环境调整策略。
- **复杂决策**：处理多步骤决策问题。
- **可扩展性**：适用于不同规模的游戏。

### 1.3.3 实际案例分析
- 游戏《星际争霸II》中的AI，通过强化学习掌握复杂的战术。

# 第2章 强化学习的核心算法

## 2.1 Q-Learning算法

### 2.1.1 Q-Learning的基本原理
Q-Learning通过学习状态-动作值函数，选择使累积奖励最大的动作。

### 2.1.2 Q-Learning的数学模型
$$ Q(s,a) = Q(s,a) + \alpha (r + \gamma \max Q(s',a') - Q(s,a)) $$
其中：
- $Q(s,a)$：当前状态s下动作a的值。
- $\alpha$：学习率。
- $\gamma$：折扣因子。
- $r$：奖励。

### 2.1.3 Q-Learning的优缺点
- **优点**：简单易实现。
- **缺点**：难以处理高维状态空间。

### 2.1.4 Q-Learning的流程图
```mermaid
graph TD
    S(状态) --> A(动作)
    A --> R(奖励)
    R --> S'(新状态)
    S' --> Q(S,A)
```

## 2.2 Deep Q-Networks (DQN)

### 2.2.1 DQN的基本原理
DQN结合深度学习，使用神经网络近似Q值函数，解决高维状态问题。

### 2.2.2 DQN的网络结构
- **输入层**：接收状态信息。
- **隐藏层**：处理数据。
- **输出层**：输出Q值。

### 2.2.3 DQN在游戏AI中的应用
例如，在Atari游戏中，DQN通过神经网络学习策略，实现人类水平的 gameplay。

### 2.2.4 DQN的代码示例
```python
import numpy as np
import torch
import torch.nn as nn

class DQN(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(DQN, self).__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)
    
    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x
```

## 2.3 Actor-Critic算法

### 2.3.1 Actor-Critic的基本原理
Actor-Critic同时学习策略（Actor）和价值函数（Critic），通过两者协作优化。

### 2.3.2 Actor-Critic的网络结构
- **Actor**：生成动作。
- **Critic**：评估状态值。

### 2.3.3 Actor-Critic的优势
- **稳定性**：同时优化策略和价值函数。
- **实时反馈**：Actor根据Critic的反馈调整策略。

### 2.3.4 Actor-Critic的流程图
```mermaid
graph TD
    S(状态) --> Actor
    Actor --> 动作
    动作 --> R(奖励)
    R --> Critic
    Critic --> 优化Actor
```

```python
    for episode in range(num_episodes):
        state = env.reset()
        while not done:
            action = agent.act(state)
            next_state, reward, done = env.step(action)
            agent.memorize(state, action, reward, next_state)
            agent.replay()
```
