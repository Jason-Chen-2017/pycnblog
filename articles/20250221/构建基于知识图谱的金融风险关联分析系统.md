## 第3章 算法原理与实现

### 3.1 关联规则挖掘算法

#### 3.1.1 算法原理
- 关联规则挖掘用于发现数据中的频繁项集，生成关联规则。

#### 3.1.2 算法实现

```python
def apriori(data, min_support):
    # Step 1: 生成所有单个项的频繁项集
    items = list(set([item for sublist in data for item in sublist]))
    L = {}
    for item in items:
        count = 0
        for transaction in data:
            if item in transaction:
                count += 1
        if count >= min_support:
            L[item] = count
    # Step 2: 递归生成更长的项集
    k = 1
    while True:
        candidates = list(itertools.combinations(L.keys(), k))
        new_L = {}
        for candidate in candidates:
            count = 0
            for transaction in data:
                if all(item in transaction for item in candidate):
                    count += 1
            if count >= min_support:
                new_L[candidate] = count
        if not new_L:
            break
        L = new_L
        k += 1
    # 生成关联规则
    rules = []
    for item_set, support in L.items():
        for subset in item_set[:-1]:
            confidence = support / L[tuple(subset + item_set[-1])]
            rules.append((subset, item_set[-1], confidence))
    return rules
```

#### 3.1.3 优缺点分析
- 优点：简单易懂，适用于小规模数据。
- 缺点：对于大规模数据，效率较低。

### 3.2 图嵌入算法

#### 3.2.1 算法原理
- 图嵌入算法将图中的节点表示为低维向量，保留图的结构信息。

#### 3.2.2 算法实现

```python
def node2vec(edge_list, num_walks, walk_length):
    # Step 1: 随机游走生成
    walks = []
    for node in range(len(edge_list)):
        for _ in range(num_walks):
            walk = [node]
            current_node = node
            for _ in range(walk_length):
                neighbors = [neighbor for neighbor, _ in edge_list[current_node]]
                if not neighbors:
                    break
                next_node = random.choice(neighbors)
                walk.append(next_node)
                current_node = next_node
            walks.append(walk)
    # Step 2: 使用Word2Vec进行训练
    model = Word2Vec(vector_size=100, window=5, min_count=1, workers=4)
    model.build_vocab(walks)
    model.train(walks, total_examples=model.corpus_count, epochs=10)
    return model
```

#### 3.2.3 优缺点分析
- 优点：适用于大规模数据，捕捉图的结构信息。
- 缺点：需要大量计算资源。
