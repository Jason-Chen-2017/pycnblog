## 第3章: 聚类分析基础与方法

### 3.1 聚类分析的基本原理

聚类分析通过数据相似性将样本分组。常用的距离度量公式为：

$$d(x_i, x_j) = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$$

### 3.2 常见聚类算法概述

- **K-means算法**：迭代优化质心。
- **层次聚类**：基于层次结构划分。
- **DBSCAN算法**：基于密度的聚类。

## 第4章: 投资者行为模式聚类的数学模型与算法实现

### 4.1 聚类分析的数学模型

目标函数为：

$$J = \sum_{i=1}^{k} \sum_{j=1}^{n_i} (x_j - c_i)^2$$

### 4.2 K-means算法实现

流程如下：
```
初始化质心
计算每个样本的最近质心
更新质心
重复直到收敛
```

优化方法包括K-means++初始化和肘部法则确定聚类数。

## 第6章: 项目实战

### 6.1 项目背景与目标

以股票投资者行为分析为例，目标是识别不同投资者群体的行为特征。

### 6.2 系统实现

代码实现：

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# 数据预处理
data = ...  # 加载数据
scaler = StandardScaler()
scaled_data = scaler.fit_transform(data)

# K-means聚类
kmeans = KMeans(n_clusters=3, random_state=42)
clusters = kmeans.fit_predict(scaled_data)

# 结果分析
print("聚类中心：", kmeans.cluster_centers_)
print("聚类标签：", clusters)
```
