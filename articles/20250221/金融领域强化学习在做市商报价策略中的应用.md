# 第一章：强化学习的基本概念与应用

## 1.1 强化学习的定义与特点
### 1.1.1 强化学习的定义
强化学习是一种通过智能体与环境交互来学习策略的机器学习方法，目标是通过最大化累积奖励来优化决策过程。

### 1.1.2 强化学习的核心特点
- **长期性**：强化学习关注长期累积奖励，而非单次决策的优化。
- **探索与利用**：智能体需要在探索新策略和利用已知策略之间找到平衡。
- **环境动态性**：环境通常是动态变化的，智能体需要适应这种变化。

### 1.1.3 强化学习与传统机器学习的区别
| 特性 | 监督学习 | 强化学习 |
|------|----------|----------|
| 数据来源 | 标签化数据 | 环境反馈（奖励或惩罚） |
| 目标 | 最小化预测误差 | 最大化累积奖励 |
| 交互方式 | 非实时交互 | 实时交互 |

# 第三章：强化学习算法的核心原理

## 3.1 强化学习的基本原理
### 3.1.1 状态、动作、奖励的定义
- 状态：智能体所处的环境状态。
- 动作：智能体在状态下的决策。
- 奖励：环境对智能体决策的反馈。

### 3.1.2 强化学习的基本框架
- 环境与智能体的交互
- 状态转移概率
- 奖励函数

### 3.1.3 策略与价值函数的定义
- 策略：智能体在状态下的动作选择概率分布。
- 价值函数：状态或状态-动作对的预期累积奖励。

---

## 3.2 常见的强化学习算法
### 3.2.1 Q-Learning算法
Q-Learning是一种基于值函数的强化学习算法，通过更新Q表来学习最优策略。

- **算法步骤**：
  1. 初始化Q表。
  2. 环境提供当前状态。
  3. 智能体选择动作并执行。
  4. 环境返回奖励和下一个状态。
  5. 更新Q表：$Q(s,a) = Q(s,a) + \alpha (r + \gamma Q(s',a') - Q(s,a))$。

### 3.2.2 Deep Q-Learning算法
Deep Q-Learning将Q-Learning与深度学习结合，通过神经网络近似Q函数。

- **算法步骤**：
  1. 初始化神经网络。
  2. 环境提供当前状态。
  3. 智能体选择动作并执行。
  4. 环境返回奖励和下一个状态。
  5. 训练神经网络：最小化预测Q值与实际Q值的误差。

### 3.2.3 Policy Gradient算法
Policy Gradient通过优化策略的参数来直接最大化累积奖励。

- **算法步骤**：
  1. 初始化策略参数。
  2. 环境提供当前状态。
  3. 智能体根据策略选择动作并执行。
  4. 环境返回奖励和下一个状态。
  5. 训练策略参数：最大化累积奖励。

## 5.2 核心代码实现
### 5.2.1 Q-Learning算法实现
```python
import numpy as np

class QLearning:
    def __init__(self, state_space_size, action_space_size):
        self.q_table = np.zeros((state_space_size, action_space_size))
    
    def choose_action(self, state, epsilon=0.1):
        if np.random.random() < epsilon:
            return np.random.randint(0, action_space_size)
        else:
            return np.argmax(self.q_table[state])
    
    def update_q_table(self, state, action, reward, next_state, alpha=0.1, gamma=0.9):
        self.q_table[state, action] = self.q_table[state, action] + alpha * (reward + gamma * np.max(self.q_table[next_state]) - self.q_table[state, action])
```

### 5.2.2 Deep Q-Learning算法实现
```python
import tensorflow as tf

class DeepQNetwork:
    def __init__(self, state_space_size, action_space_size):
        self.model = self.build_model(state_space_size, action_space_size)
    
    def build_model(self, state_space_size, action_space_size):
        model = tf.keras.Sequential([
            tf.keras.layers.Dense(64, activation='relu', input_dim=state_space_size),
            tf.keras.layers.Dense(32, activation='relu'),
            tf.keras.layers.Dense(action_space_size, activation='linear')
        ])
        model.compile(optimizer='adam', loss='mse')
        return model
    
    def choose_action(self, state, epsilon=0.1):
        if np.random.random() < epsilon:
            return np.random.randint(0, action_space_size)
        else:
            predictions = self.model.predict(np.array([state]))
            return np.argmax(predictions[0])
    
    def update_model(self, states, actions, rewards, next_states, gamma=0.9):
        next_preds = self.model.predict(np.array(next_states))
        targets = rewards + gamma * np.max(next_preds, axis=1)
        self.model.fit(np.array(states), targets, epochs=1, verbose=0)
```
