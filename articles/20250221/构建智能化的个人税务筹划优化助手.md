# 第三章: 优化算法原理

## 3.1 遗传算法

### 3.1.1 遗传算法的基本原理

遗传算法是一种模拟生物进化过程的优化算法，通过模拟自然选择和遗传机制，逐步优化解的质量。其核心思想包括以下几点：

1. **适应度函数**：定义一个函数，用于评估每个解的优劣。
2. **选择**：根据适应度值选择较优的解作为父代。
3. **交叉**：将父代的解进行交叉，生成新的子代。
4. **变异**：对子代的解进行随机变异，增加解的多样性。
5. **迭代**：重复选择、交叉和变异的过程，直到达到收敛条件。

### 3.1.2 遗传算法的流程图

```mermaid
graph TD
    A[开始] --> B[初始化种群]
    B --> C[计算适应度]
    C --> D[选择]
    D --> E[交叉]
    E --> F[变异]
    F --> G[新种群]
    G --> H[检查收敛条件]
    H --> I[收敛] --> J[结束]
    H --> K[未收敛] --> B
```

### 3.1.3 遗传算法的数学模型

适应度函数是遗传算法的核心，通常表示为：

$$ f(x) = \sum_{i=1}^{n} w_i x_i $$

其中，$w_i$ 是权重，$x_i$ 是决策变量。

### 3.1.4 遗传算法的Python实现示例

```python
import random

def fitness(individual):
    # 计算适应度函数
    return sum(gene * 10 for gene in individual)

def mutate(individual):
    # 随机选择一个基因进行变异
    idx = random.randint(0, len(individual)-1)
    individual[idx] = 1 - individual[idx]
    return individual

def crossover(parent1, parent2):
    # 单点交叉
    point = random.randint(1, len(parent1)-1)
    return parent1[:point] + parent2[point:], parent2[:point] + parent1[point:]

# 初始化种群
population = [[random.randint(0,1) for _ in range(10)] for _ in range(100)]

for _ in range(100):
    # 计算适应度
    fitness_list = [fitness(individual) for individual in population]
    # 选择
    selected = [population[i] for i in sorted(range(len(fitness_list)), key=lambda x: -fitness_list[x])[:50]]
    # 交叉和变异
    new_population = []
    for i in range(0, len(selected), 2):
        p1, p2 = selected[i], selected[i+1]
        child1, child2 = crossover(p1, p2)
        child1 = mutate(child1)
        child2 = mutate(child2)
        new_population.extend([child1, child2])
    population = new_population
```

## 3.2 模拟退火算法

### 3.2.1 模拟退火算法的基本原理

模拟退火是一种全局优化算法，通过模拟金属冷却的过程，逐步降低解的能垒，找到全局最优解。其核心步骤包括：

1. **初始解**：随机生成一个初始解。
2. **计算能量**：计算当前解的能量（适应度）。
3. **随机扰动**：随机改变解的一部分，生成新解。
4. **接受或拒绝**：根据能量变化和温度参数决定是否接受新解。
5. **降温**：逐渐降低温度，直到达到终止条件。

### 3.2.2 模拟退火算法的流程图

```mermaid
graph TD
    A[开始] --> B[初始解]
    B --> C[计算能量]
    C --> D[随机扰动]
    D --> E[接受或拒绝]
    E --> F[降温]
    F --> G[检查温度]
    G --> H[温度未达目标] --> B
    G --> I[温度达目标] --> J[结束]
```

### 3.2.3 模拟退火算法的数学模型

能量函数通常表示为：

$$ E(x) = \sum_{i=1}^{n} w_i (x_i - x_i^*)^2 $$

其中，$x_i^*$ 是理想值，$x_i$ 是当前解的值。

### 3.2.4 模拟退火算法的Python实现示例

```python
import random
import math

def fitness(individual):
    # 计算适应度函数
    return sum(gene * 10 for gene in individual)

def disturb(individual):
    # 随机扰动一个基因
    idx = random.randint(0, len(individual)-1)
    individual[idx] += 0.1
    return individual

def annealing(iterations=1000, initial_temp=1000):
    current = [random.randint(0,1) for _ in range(10)]
    best = current.copy()
    best_fitness = fitness(best)
    
    for step in range(iterations):
        temp = initial_temp / (1 + step)
        candidate = disturb(current)
        current_fitness = fitness(candidate)
        best_fitness = min(best_fitness, current_fitness)
        if current_fitness < best_fitness:
            current = candidate.copy()
        if step % 100 == 0:
            print(f"Step {step}: Temperature={temp}, Best Fitness={best_fitness}")
    return best

# 示例运行
best = annealing()
print("Best solution:", best)
print("Best fitness:", best_fitness)
```
