#### 3.3.2 Python代码实现
```python
import numpy as np
from sklearn.cluster import KMeans

def optimize_portfolio(weights, returns):
    # 使用K均值算法优化资产权重
    kmeans = KMeans(n_clusters=3).fit(returns)
    optimized_weights = kmeans.cluster_centers_
    return optimized_weights

# 示例数据
weights = np.array([0.2, 0.3, 0.5])
returns = np.array([0.1, 0.2, 0.15])

optimized_weights = optimize_portfolio(weights, returns)
print("Optimized Weights:", optimized_weights)
```

#### 3.3.3 代码的功能解读与优化建议
代码使用K均值算法优化资产配置，根据市场变化动态调整权重，提升收益。
