## 第一部分: 行为金融学与价值投资的理论基础

### 第1章: 行为金融学的起源与发展

#### 1.1 行为金融学的定义与核心概念

- **1.1.1 传统金融学的局限性**
  - 传统金融学假设市场的理性与有效，但实际市场中存在大量非理性行为。
  - 传统模型无法解释市场异效现象，如股票溢价 puzzles。

- **1.1.2 行为金融学的起源与演变**
  - 起源于心理学与经济学的交叉研究。
  - 20世纪60年代开始， Kahneman 和 Tversky 的 prospect theory 标志着行为金融学的诞生。

- **1.1.3 行为金融学的核心假设与研究方法**
  - 核心假设：投资者是有限理性的，情绪与认知偏差影响决策。
  - 研究方法：基于心理学实验与数据驱动的实证分析。

#### 1.2 罗伯特·席勒与行为金融学

- **1.2.1 罗伯特·席勒的学术贡献**
  - 提出市场异效现象（market anomalies）的存在。
  - 发展了情绪指标（如心理账户）对资产定价的影响。

- **1.2.2 席勒对行为金融学的创新与发展**
  - 强调情绪周期对市场波动的影响。
  - 提出“叙事理论”解释投资者行为。

- **1.2.3 席勒的诺贝尔经济学奖及其影响**
  - 2013年诺贝尔经济学奖得主。
  - 影响：行为金融学成为主流金融学的重要分支。

### 第2章: 行为金融学的核心理论与模型

#### 2.1 前景理论（Prospect Theory）

- **2.1.1 前景理论的基本框架**
  - **价值函数**：描述决策者对收益和损失的感知。
  - **概率权重函数**：描述决策者对概率的感知。

- **2.1.2 前景理论的核心假设与特征**
  - **损失厌恶**：损失带来的痛苦大于同等收益带来的快乐。
  - **非线性概率加权**：小概率事件被过度重视。

- **2.1.3 前景理论的数学模型与公式**
  - 价值函数：$$v(x) = \begin{cases} 
      \sqrt{x} & \text{if } x > 0 \\
      - \sqrt{-x} & \text{if } x < 0 
   \end{cases}$$
  - 概率权重函数：$$w(p) = \begin{cases} 
      p^\alpha & \text{if } p > 0.5 \\
      (1 - p)^\beta & \text{if } p < 0.5 
   \end{cases}$$

#### 2.2 情绪与认知偏差对投资决策的影响

- **2.2.1 情绪在投资决策中的作用**
  - 情绪周期：贪婪与恐惧交替驱动市场波动。
  - 情绪指标：如投资者信心指数、媒体情绪分析。

- **2.2.2 常见的认知偏差及其对投资的影响**
  - 表格对比：认知偏差与具体影响
  | 认知偏差       | 投资影响                     |
  |----------------|------------------------------|
  | 过度自信       | 高估自身判断能力             |
  | 沉没成本效应    | 继续投入已亏损项目             |
  | 羊群效应        | 跟随市场趋势而非独立判断       |

- **2.2.3 情绪与认知偏差的数学模型**
  - 情绪指数模型：$$S_t = \alpha \times E_t + \beta \times M_t + \epsilon$$
  - 其中，$E_t$为情绪指标，$M_t$为市场数据。

#### 2.3 市场异效现象与行为金融学解释

- **2.3.1 市场异效现象的定义与分类**
  - 分类：股票溢价、小公司效应、动量效应等。

- **2.3.2 行为金融学对市场异效现象的解释**
  - 动量效应：投资者情绪惯性导致价格延续趋势。
  - 小公司效应：投资者认知偏差导致低估小公司价值。

- **2.3.3 市场异效现象的数学模型**
  - 动量效应模型：$$P_t = \gamma \times P_{t-1} + \epsilon$$
  - 小公司效应模型：$$R_t = \beta \times (SMB_t) + \epsilon$$

### 第3章: 价值投资与行为金融学的结合

#### 3.1 价值投资的基本原理

- **3.1.1 价值投资的定义与核心理念**
  - 核心理念：寻找市场价格低于内在价值的资产。
  - 关键原则：安全边际、长期投资、逆向思维。

#### 3.2 行为金融学视角下的价值投资

- **3.2.1 行为金融学对价值投资的启示**
  - 情绪周期：在市场恐慌时买入低估资产。
  - 认知偏差：避免过度自信，理性评估。

- **3.2.2 情绪与市场非理性对价值投资的影响**
  - 市场恐慌时，价值投资者可以利用情绪低谷买入。
  - 市场狂热时，价值投资者需要抵制过度乐观的诱惑。

- **3.2.3 价值投资中的情绪与认知偏差分析**
  - 投资者容易陷入乐观陷阱，高估未来收益。
  - 投资者容易忽视长期价值，关注短期波动。

#### 3.3 席勒对价值投资的贡献

- **3.3.1 席勒对价值投资理论的创新**
  - 强调情绪指标在价值评估中的作用。
  - 提出叙事理论解释投资者行为。

- **3.3.2 席勒对价值投资实践的启示**
  - 建立情绪指标体系，辅助价值评估。
  - 结合长期趋势，制定投资策略。

- **3.3.3 席勒与价值投资的未来发展方向**

- **5.2.1 情绪指标计算算法**
  ```python
  import pandas as pd
  import numpy as np

  def calculate_emotion_index(sentences):
      positive_words = ['good', 'positive', 'bullish']
      negative_words = ['bad', 'negative', 'bearish']
      count = 0
      for sentence in sentences:
          words = sentence.split()
          for word in words:
              if word in positive_words:
                  count += 1
              elif word in negative_words:
                  count -= 1
      return count
  ```

- **5.2.2 市场异效现象分析算法**
  ```python
  def analyze_market_anomalies(prices):
      returns = prices.pct_change().dropna()
      mean_return = returns.mean()
      std_return = returns.std()
      z_scores = (prices - mean_return) / std_return
      return z_scores
  ```
