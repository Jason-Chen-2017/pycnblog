- 4.1.2 Q-learning算法
  - 算法流程：
    1. 初始化Q表
    2. 选择动作
    3. 执行动作，获取奖励
    4. 更新Q值
  - 数学公式：
    $$ Q(s, a) = Q(s, a) + \alpha (r + \gamma \max Q(s', a') - Q(s, a)) $$

- 6.1.2 知识抽取工具安装

#### 6.2 知识抽取与构建
- 6.2.1 知识抽取核心代码
  ```python
  import spacy
  nlp = spacy.load("zh_core_web_sm")
  text = "人工智能是研究如何使计算机能够模拟人类的智能行为，包括学习、推理、问题求解等。"
  doc = nlp(text)
  entities = [(ent.text, ent.label_) for ent in doc.ents]
  print(entities)
  ```
- 6.2.2 知识图谱构建
  ```python
  from networkx import *
  G = nx.DiGraph()
  G.add_edge("人工智能", "学习")
  G.add_edge("人工智能", "推理")
  nx.draw(G, with_labels=True, edge_color='blue', node_color='white')
  plt.show()
  ```
