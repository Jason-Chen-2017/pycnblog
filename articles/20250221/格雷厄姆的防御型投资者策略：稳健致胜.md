## 第1章：防御型投资概述

### 1.1 投资的基本概念

#### 1.1.1 投资的定义与分类
投资是指将资金投入某一项目或资产，以期获得未来收益的行为。根据投资目标的不同，可以分为短期投资、中期投资和长期投资。

- **短期投资**：目标是通过快速交易获利，通常在几周或几个月内完成。
- **中期投资**：目标是在几个月到几年内获得稳定收益。
- **长期投资**：目标是通过持有优质资产，获得长期稳定的收益。

#### 1.1.2 主动投资与被动投资的对比
- **主动投资**：投资者积极选择股票，试图通过市场波动获利。风险较高，收益不稳定。
- **被动投资**：通过指数基金等工具，长期持有，收益相对稳定。

#### 1.1.3 防御型投资的定义与特点
防御型投资是一种稳健的投资策略，强调安全边际和长期稳定收益。其特点包括：
- 重视基本面分析
- 注重安全边际
- 低风险，高收益

### 1.2 格雷厄姆的投资理念

#### 1.2.1 价值投资的起源与发展
本杰明·格雷厄姆是价值投资的鼻祖，他提出的防御型投资策略奠定了现代投资学的基础。

#### 1.2.2 安全边际的概念与重要性
安全边际是指股票价格与实际价值之间的差距。通过购买低于内在价值的股票，降低投资风险。

$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

#### 1.2.3 边际安全与投资决策的关系
边际安全是指每增加一单位投资的风险变化。格雷厄姆强调在边际安全为正时进行投资。

### 1.3 防御型投资的核心要素

#### 1.3.1 财务报表分析基础
分析资产负债表、利润表和现金流量表，评估企业的财务健康状况。

#### 1.3.2 估值方法的初步介绍
- **市盈率（P/E）**：股价与每股收益的比率。
- **市净率（P/B）**：股价与每股净资产的比率。

#### 1.3.3 风险与收益的平衡
通过分散投资和风险控制，平衡收益与风险。

## 第2章：防御型投资者的选股策略

### 2.1 安全边际的计算与应用

#### 2.1.1 安全边际的数学模型
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

#### 2.1.2 通过市盈率、市净率评估安全边际
- **市盈率低于行业平均水平**：表明股票价格被低估。
- **市净率低于行业平均水平**：同样表明股票价格被低估。

### 2.2 防御型投资者的选股标准

#### 2.2.1 企业财务健康状况分析
- **资产负债表**：评估企业的资产、负债和所有者权益。
- **利润表**：评估企业的收入、成本和利润。

#### 2.2.2 企业盈利能力与成长性评估
- **净利润率**：衡量企业的盈利能力。
- **收入增长率**：衡量企业的成长性。

#### 2.2.3 行业地位与竞争优势
选择行业龙头，具有竞争优势的企业。

### 2.3 避免常见错误

#### 2.3.1 过度关注短期波动
防御型投资注重长期，避免受短期波动影响。

#### 2.3.2 忽视企业基本面
全面分析企业的基本面，避免仅关注价格。

#### 2.3.3 追逐市场热点
避免盲目跟风，注重基本面分析。

## 第3章：风险管理与心理建设

### 3.1 投资组合的分散化

#### 3.1.1 分散化投资的原理与实践
通过投资不同行业、不同地区的资产，降低风险。

#### 3.1.2 不同资产类别的配置比例
- **股票**：不超过60%
- **债券**：不低于30%
- **现金**：不低于10%

### 3.2 仓位管理与止损策略

#### 3.2.1 如何设定止损点
根据技术分析或估值变化，设定止损点。

#### 3.2.2 动态调整投资仓位
根据市场变化和个人风险承受能力，动态调整仓位。

#### 3.2.3 技术分析在风险管理中的应用
使用均线、MACD等技术指标，辅助决策。

### 3.3 心理风险管理

#### 3.3.1 避免情绪化决策
保持理性，避免贪婪和恐惧影响决策。

#### 3.3.2 建立长期投资心态
耐心持有优质资产，避免频繁交易。

#### 3.3.3 应对市场恐慌的有效方法
保持冷静，利用市场恐慌寻找投资机会。

import pandas as pd
import requests

def get_stock_data(ticker):
    url = f"https://query1.finance.yahoo.com/v7/finance/quote/{ticker}"

    data = response.json()
    return data

def calculate_pe(ticker):
    data = get_stock_data(ticker)
    pe = data[0]['PE Ratio']

print(calculate_pe("AAPL"))
