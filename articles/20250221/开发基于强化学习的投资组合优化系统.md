## 1.1 强化学习的基本概念

### 1.1.1 强化学习的定义与特点

强化学习是一种机器学习范式，通过智能体在环境中采取动作以最大化累积奖励。其核心特点包括：基于经验学习、目标导向、策略优化。

### 1.1.2 强化学习的核心要素

- 状态空间（State Space）
- 动作空间（Action Space）
- 奖励函数（Reward Function）
- 策略（Policy）
- Q-值函数（Q-value Function）

## 1.2 投资组合优化的基本概念

### 1.2.1 投资组合优化的定义与目标

投资组合优化是指在给定风险偏好下，通过调整资产配置以实现收益最大化的过程。

### 1.2.2 马科维茨现代投资组合理论

- 均值-方差模型
- 资产分配与风险控制

## 1.3 强化学习在投资组合优化中的应用背景

### 1.3.1 传统投资组合优化的局限性

- 假设过于简化
- 无法处理非线性问题
- 忽略交易成本和滑点

### 1.3.2 强化学习在投资组合优化中的优势

- 能够处理非线性关系
- 适合动态市场环境
- 可以同时优化多个目标

## 3.1 Q-learning算法原理

### 3.1.1 Q-learning的基本原理

- Q值更新公式：
$$ Q(s, a) = Q(s, a) + \alpha (r + \gamma \max Q(s', a) - Q(s, a)) $$

### 3.1.2 Q-learning在投资组合优化中的应用

- 状态空间：市场状态
- 动作空间：投资动作
- 奖励函数：投资收益

## 3.4 算法

### 3.4.1 Q-learning代码示例

```python
import numpy as np

class QLearner:
    def __init__(self, state_space, action_space, learning_rate=0.1, gamma=0.9):
        self.state_space = state_space
        self.action_space = action_space
        self.lr = learning_rate
        self.gamma = gamma
        self.Q = np.zeros((state_space, action_space))

    def choose_action(self, state):
        return np.argmax(self.Q[state])

    def update_Q(self, state, action, reward, next_state):
        self.Q[state, action] += self.lr * (reward + self.gamma * np.max(self.Q[next_state]) - self.Q[state, action])
```

### 3.4.2 DQN代码示例

import torch

class DQN(nn.Module):
    def __init__(self, input_dim, output_dim):
        super(DQN, self).__init__()

        self.fc2 = nn.Linear(64, output_dim)

    def forward(self, x):
        x = torch.relu(self.fc1(x))
