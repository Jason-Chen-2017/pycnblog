# 第一章：跨市场风险传导的背景与挑战

## 1.1 跨市場風險傳導的定義與特征  
跨市場風險傳導是指金融市場之間由于經濟、金融等因素的相互影響，導致風險在不同市場之間傳播和擴散。其主要特征包括：  
1. **傳播性**：風險從一個市場傳導到其他市場。  
2. **系統性**：風險傳導可能引發系統性風險。  
3. **多樣性**：風險傳導途徑多樣化，包括直接和間接傳導。  

## 1.2 金融市場中的風險傳導機制  
風險傳導主要通過以下途徑進行：  
1. **市場價格傳導**：股價波動引發風險傳導。  
2. **傳染效應**：某一市場的崩潰引發其他市場的崩潰。  
3. **金融紐帶**：通過金融機構的相互投資和借貸實現風險傳導。  

## 1.3 現有風險評估方法的局限性  
 traditional methods often fail to capture the complex and dynamic relationships between markets, leading to inaccurate risk assessments.

# 第二章：图卷积网络（GCN）的基本原理  

## 2.1 图论的基本概念  
**圖**是由節點（VERTEX）和邊（EDGE）組成的數據結構。邊可以帶權重，表示市場之間的關聯程度。  

## 2.2 GCN的數學模型  
GCN的數學模型可以表示為：  
$$ H = \theta (X, A) $$  
其中，$X$ 是特徵矩陣，$A$ 是鄰接矩陣，$\theta$ 是模型參數。  

## 2.3 GCN的核心優勢  
1. **局部性原理**：模型可以捕捉局部市場之間的關聯性。  
2. **幾何穩定性原理**：模型具有良好的泛化能力。  
3. **跨市場傳導的可視化能力**：GCN可以幫助我們可視化風險傳導的路徑。

## 5.2 核心代碼實現  
以下是GCN模型的具體實現：  

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

class GCN(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GCN, self).__init__()
        self.conv1 = nn.Conv2d(input_dim, hidden_dim, kernel_size=1)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(hidden_dim, output_dim, kernel_size=1)
    
    def forward(self, x):
        x = self.conv1(x)
        x = self.relu(x)
        x = self.conv2(x)
        return x

# 初始化模型
input_dim = 64
hidden_dim = 32
output_dim = 10
model = GCN(input_dim, hidden_dim, output_dim)
```

## 5.3 案例分析  
以下是一個簡單的案例分析：  

```python
# 生產數據
data = np.random.randn(100, input_dim)
labels = np.random.randint(0, output_dim, 100)

# 訓練模型
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)
for epoch in range(10):
    outputs = model(torch.FloatTensor(data))
    loss = criterion(outputs, torch.LongTensor(labels))
    loss.backward()
    optimizer.step()
```
