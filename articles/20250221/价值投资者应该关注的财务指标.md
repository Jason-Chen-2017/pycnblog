## 第一部分: 价值投资与财务指标基础

### 第1章: 价值投资的基本概念

#### 1.1 价值投资的定义与核心理念
- **1.1.1 价值投资的起源与发展**
  价值投资起源于20世纪20年代，由本杰明·格雷厄姆和戴维·多德提出，强调以低于内在价值的价格买入优质股票，长期持有。

- **1.1.2 价值投资的核心理念**
  价值投资的核心是寻找市场低估的公司，关注公司的基本面，而非短期市场波动。通过分析财务报表，评估公司的内在价值。

- **1.1.3 价值投资与成长投资的区别**
  价值投资注重安全边际和低估值，而成长投资则关注公司的高增长潜力。两者在选股标准上有明显差异，但都追求长期收益。

#### 1.2 财务分析的基础知识
- **1.2.1 财务报表的基本构成**
  财务报表包括资产负债表、利润表和现金流量表，分别反映企业的财务状况、经营成果和现金流量。

- **1.2.2 财务指标的分类与作用**
  财务指标分为盈利能力、成长能力、财务健康和现金流四大类，帮助投资者全面评估公司。

- **1.2.3 财务分析的方法与流程**
  财务分析通常包括数据收集、指标计算、趋势分析和估值判断四个步骤，帮助投资者识别投资机会。

### 第2章: 财务指标的核心概念与联系

#### 2.1 核心概念与原理
- **2.1.1 财务指标的定义与分类**
  财务指标是对公司财务状况的量化衡量，分为盈利能力、成长能力、财务健康和现金流四类，每类指标各有侧重。

- **2.1.2 财务指标之间的相互关系**
  比如，盈利能力高的公司通常具有较强的现金流，但过高的负债可能影响财务健康。各指标之间相互影响，需综合分析。

- **2.1.3 财务指标与企业价值的关系**
  企业价值取决于盈利能力、成长潜力和财务健康，而财务指标是衡量这些因素的关键工具。

#### 2.2 核心概念对比分析
- **2.2.1 盈利能力指标对比**
  净利润衡量整体盈利能力，ROE反映股东投资回报，EPS显示每股收益，不同指标从不同角度评估公司盈利能力。

- **2.2.2 成长能力指标对比**
  营收增长率和净利润增长率分别从收入和利润角度评估成长性，不同行业的增长指标标准不同。

- **2.2.3 财务健康状况指标对比**
  资产负债率和速动比率分别从负债和流动性角度评估财务健康，需结合行业特点分析。

### 第3章: 财务指标的数学模型与公式

#### 3.1 盈利能力指标
- **3.1.1 净利润公式:**
  $$净利润 = 收入 - 成本 - 费用$$
  净利润是衡量公司盈利能力的核心指标，反映公司经营效率。

- **3.1.2 净资产收益率(ROE):**
  $$ROE = \frac{净利润}{所有者权益}$$
  ROE衡量股东资金的使用效率，高ROE通常意味着公司管理高效。

- **3.1.3 每股收益(EPS):**
  $$EPS = \frac{净利润}{流通股数}$$
  EPS是每股的盈利能力指标，常用于评估股票的投资价值。

#### 3.2 成长能力指标
- **3.2.1 营业收入增长率:**
  $$\text{增长率} = \frac{\text{本年收入} - \text{上年收入}}{\text{上年收入}}$$
  评估公司收入增长潜力，高增长率可能意味着未来高收益。

- **3.2.2 净利润增长率:**
  $$\text{增长率} = \frac{\text{本年净利润} - \text{上年净利润}}{\text{上年净利润}}$$
  利润增长反映公司盈利能力提升，需结合收入增长分析。

#### 3.3 财务健康状况指标
- **3.3.1 资产负债率:**
  $$\text{资产负债率} = \frac{\text{总负债}}{\text{总资产}}$$
  低资产负债率通常意味着公司财务风险较低，还款能力较强。

- **3.3.2 速动比率:**
  $$\text{速动比率} = \frac{\text{流动资产} - \text{存货}}{\text{流动负债}}$$
  速动比率衡量公司短期偿债能力，速动比率越高，财务健康状况越好。

import pandas as pd

def calculate_profitability Metrics(df):
    df['ROE'] = df['净利润'] / df['所有者权益']
    df['EPS'] = df['净利润'] / df['流通股数']
    return df

def calculate_growth_metrics(df):
    df['营收增长率'] = (df['收入'] - df.shift(1)['收入']) / df.shift(1)['收入']
    df['净利润增长率'] = (df['净利润'] - df.shift(1)['净利润']) / df.shift(1)['净利润']
    return df

def calculate_health_metrics(df):
