## 第一部分：格雷厄姆的净净股策略概述

### 第1章：格雷厄姆与净净股策略的背景介绍

#### 1.1 格雷厄姆的投资理念
##### 1.1.1 价值投资的起源
- 价值投资的定义：寻找市场价格低于其内在价值的资产。
- 格雷厄姆的学术背景： Columbia University，导师 Benjamin Graham。
- 格雷厄姆的投资哲学：安全边际与防御性投资。

##### 1.1.2 格雷厄姆的净净股策略背景
- 20世纪30年代经济大萧条的背景：市场恐慌导致股票价格被低估。
- 格雷厄姆提出“净净股”概念：寻找市场价格低于其净资产价值的公司。

##### 1.1.3 净净股策略的定义与目标
- 净净股的定义：市场价格低于其净资产价值的股票。
- 策略目标：通过寻找被市场低估的公司，实现长期稳定的投资收益。

#### 1.2 净净股策略的核心概念
##### 1.2.1 净净价值的计算
- 净净价值的公式：  
  $$ \text{内在价值} = \text{净资产价值} - \text{债务} $$
- 净净价值与市场价格的关系：  
  $$ \text{市场价格} < \text{内在价值} $$

##### 1.2.2 低估公司的识别标准
- 净净股的筛选标准：  
  - 市场价格低于净资产价值。
  - 市盈率低于行业平均水平。
  - 偿债能力较强，资产负债率低于行业平均水平。

##### 1.2.3 净净股策略的适用场景
- 市场恐慌：投资者情绪低落，股票价格被低估。
- 经济低迷：整体市场估值偏低，容易找到净净股。

#### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(assets, liabilities):
    return assets - liabilities

def is_net_net_stock(price, intrinsic_value):
    return price < intrinsic_value

# 示例数据
assets = 1000
liabilities = 800
price = 200

intrinsic_value = calculate_intrinsic_value(assets, liabilities)
result = is_net_net_stock(price, intrinsic_value)

print(f"内在价值: {intrinsic_value}")
print(f"是否为净净股: {result}")
```

#### 5.3 案例分析
- 案例1：假设某公司总资产为1000万元，总负债为800万元，市场价格为200万元。
