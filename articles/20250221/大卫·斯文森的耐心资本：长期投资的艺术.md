### 第2章：长期投资的策略与实践

#### 2.1 资产配置与投资组合管理

##### 2.1.1 资产配置的数学模型

$$
\text{最优资产配置} = \arg \max_{w} \left( \mu \cdot w - \frac{1}{2} \sigma^2 \cdot w \cdot w^T \right)
$$

##### 2.1.2 资产配置的实现代码

```python
import numpy as np

def optimal_asset_allocation(returns, covariance):
    # 计算最优权重
    n = returns.shape[1]
    inv_cov = np.linalg.inv(covariance)
    weights = inv_cov @ returns.mean(axis=0)
    weights = weights / np.sum(weights)
    return weights
```

### 第3章：耐心资本的核心原则

#### 3.1 价值投资与长期持有

##### 3.1.1 价值投资的数学模型

$$
\text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}
$$

##### 3.1.2 长期持有的实现代码

```python
import pandas as pd

def calculate_intrinsic_value(cash_flows, discount_rate):
    n = len(cash_flows)
    present_value = 0
    for t in range(n):
        present_value += cash_flows[t] / (1 + discount_rate) ** t
    return present_value
```
