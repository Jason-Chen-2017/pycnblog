## 第1章：智能债券投资组合免疫策略的背景与概念

### 1.1 智能债券投资的背景

随着金融市场的复杂化，传统债券投资依赖经验判断，面临效率低下和风险难以控制的问题。智能投资通过机器学习等技术，提升了决策的科学性和效率。

### 1.2 投资组合免疫的基本原理

债券价格受利率变化影响，久期衡量利率变动对价格的影响，凸性则描述价格变化的非线性特征。免疫策略通过匹配资产和负债的久期，抵消利率变动带来的影响。

## 第5章：智能免疫策略的实战应用

### 5.1 项目环境安装

安装Python、NumPy、scikit-learn和TensorFlow。

### 5.2 核心代码实现

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据预处理
data = np.array([[1, 2], [3, 4], [5, 6]])
X = data[:, 0]
Y = data[:, 1]

# 模型训练
model = LinearRegression()
model.fit(X.reshape(-1, 1), Y)

# 预测
predict = model.predict(X.reshape(-1, 1))
print(predict)
```
