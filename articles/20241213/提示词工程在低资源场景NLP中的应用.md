#### 3.4 提示词工程算法的Python源代码实现

以下是一个基于词嵌入的提示词生成算法的Python源代码实现：

```python
import jieba
import gensim

def generate_prompt_word(text):
    # 分词
    words = jieba.cut(text)
    
    # 加载词嵌入模型
    model = gensim.models.Word2Vec.load("word2vec.model")
    
    # 生成提示词
    prompt_words = [model[word] for word in words if word in model.wv]
    
    return prompt_words

text = "人工智能是未来的发展方向"
prompt_words = generate_prompt_word(text)
print(prompt_words)
```
