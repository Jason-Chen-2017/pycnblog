| ---- | ---- |
| **多样性** | 提示词可以有多种形式，如图文、语音等。 |
| **灵活性** | 提示词可以根据需求灵活调整。 |
| **准确性** | 提示词需要准确表达用户的意图。 |
| **效率** | 有效的提示词可以提高模型推理的效率。 |

```bash

```

接下来，安装Jupyter Notebook：

```bash
# 安装Jupyter Notebook
pip3 install notebook
```

配置Python环境，我们可以使用虚拟环境，以避免不同项目之间的依赖冲突：

```bash

python3 -m venv myenv

# 激活虚拟环境
source myenv/bin/activate
```
