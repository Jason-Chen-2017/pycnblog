#### **3.3 数学模型与公式**

在提示词工程中，常用的数学模型包括逻辑回归、支持向量机（SVM）和深度神经网络（DNN）等。以下分别介绍这些模型的数学模型和公式：

1. **逻辑回归（Logistic Regression）**：

   逻辑回归是一种用于二分类问题的线性模型，其输出为概率分布。假设输入特征为\( X = [x_1, x_2, ..., x_n] \)，则逻辑回归的输出概率为：

   $$ 
   P(Y=1|X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n)}) 
   $$

   其中，\( \beta_0, \beta_1, \beta_2, ..., \beta_n \)为模型参数，通过最小化损失函数（如交叉熵损失函数）进行训练。

2. **支持向量机（Support Vector Machine, SVM）**：

   支持向量机是一种基于最大间隔分类的模型，其目标是找到最佳分类边界，使得分类间隔最大化。假设输入特征为\( X = [x_1, x_2, ..., x_n] \)，则支持向量机的输出为：

   $$
   f(X) = \text{sign}(\omega \cdot x + b)
   $$

   其中，\( \omega \)为权重向量，\( b \)为偏置项，通过求解最优化问题（如拉格朗日乘子法）进行训练。

3. **深度神经网络（Deep Neural Network, DNN）**：

   深度神经网络是一种多层神经网络，通过非线性变换和多层堆叠来模拟人脑的神经网络结构。假设输入特征为\( X = [x_1, x_2, ..., x_n] \)，则深度神经网络的输出为：

   $$
   \hat{y} = \sigma(\sigma(...\sigma(W_1 \cdot x + b_1) + b_2) + ... + b_n)
   $$

   其中，\( W_1, W_2, ..., W_n \)为权重矩阵，\( b_1, b_2, ..., b_n \)为偏置项，\( \sigma \)为激活函数（如ReLU、Sigmoid、Tanh等），通过反向传播算法进行训练。

4. **词干提取**：将单词还原为基本形式，如将“playing”还原为“play”。
