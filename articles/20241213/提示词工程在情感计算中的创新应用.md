### 3.2 Python源代码

```python
# 导入相关库
import jieba
import nltk
from nltk.tokenize import word_tokenize
from nltk.corpus import stopwords
from textblob import TextBlob

# 输入文本
text = "我很高兴看到你。"

# 预处理
text = text.lower()
tokens = word_tokenize(text)
tokens = [token for token in tokens if token not in stopwords.words('english')]

# 情感分析
polarity = TextBlob(text).sentiment.polarity
if polarity > 0:
    emotion = "正面"
elif polarity < 0:
    emotion = "负面"
else:
    emotion = "中性"

# 输出结果
print(f"文本：{text}")
print(f"情感：{emotion}")
```

### 3.3 数学模型与公式

情感计算的数学模型主要包括：

1. 情感极性模型：用于计算文本的情感极性，通常使用以下公式：

   $$polarity = \frac{sum(positive\_words) - sum(negative\_words)}{number\_of\_words}$$

   其中，$positive\_words$ 表示文本中的正面词汇，$negative\_words$ 表示文本中的负面词汇，$number\_of\_words$ 表示文本中的总词汇数。

2. 情感强度模型：用于计算文本的情感强度，通常使用以下公式：

   $$strength = \frac{max(positive\_words) - min(negative\_words)}{number\_of\_words}$$

   其中，$max(positive\_words)$ 表示文本中正面词汇的最大值，$min(negative\_words)$ 表示文本中负面词汇的最小值。

### 3.4 举例说明

假设有一段文本：“我很高兴看到你。”，通过情感计算，我们可以得到以下结果：

1. 情感极性：$$polarity = \frac{sum(positive\_words) - sum(negative\_words)}{number\_of\_words} = \frac{1 - 0}{2} = 0.5$$，即文本的情感极性为中性。
2. 情感强度：$$strength = \frac{max(positive\_words) - min(negative\_words)}{number\_of\_words} = \frac{1 - 0}{2} = 0.5$$，即文本的情感强度也为中性。
