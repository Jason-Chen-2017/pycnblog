#### 预测模型评估指标

| 指标         | 描述                                                         |
|--------------|--------------------------------------------------------------|
| 准确率       | 预测结果与实际结果相符的比例。                             |
| 召回率       | 预测结果中正确识别出的正例比例。                         |
| F1 分数      | 准确率和召回率的加权平均值，用于综合评估模型性能。        |
| 调用次数     | 模型被调用的次数。                                         |
| 准确率@K     | 在K个最相关预测中，准确率最高的预测比例。               |
| 平均绝对误差 | 预测结果与实际结果之间的平均绝对差异。                   |
| 均方根误差   | 预测结果与实际结果之间差异的均方根。                     |
