4. **执行控制**：中央控制器根据决策结果，控制窗户执行相应的开合动作。

**算法原理与数学模型**

室内温度自动调节算法的数学模型主要包括以下三个方面：

1. **环境参数模型**：
   $$T_{out}(t) = T_{0} + a_{1}t + a_{2}\sin(\omega t + \phi)$$
   其中，$T_{out}(t)$为室外温度，$T_{0}$为初始温度，$a_{1}$为线性温度变化率，$a_{2}$为周期性温度变化率，$\omega$为周期性温度变化的角频率，$\phi$为初始相位。

2. **室内温度模型**：
   $$T_{in}(t) = T_{0} + b_{1}t + b_{2}\sin(\omega t + \phi)$$

3. **窗户开合模型**：
   $$\theta(t) = \theta_{0} + c_{1}T_{out}(t) + c_{2}T_{in}(t)$$

def indoor_temp(t, T0, b1, b2, phi):
    return T0 + b1 * t + b2 * np.sin(phi * t)

# 窗户开合模型
def window_angle(t, theta0, c1, c2, T_out, T_in):

    T_in = indoor_temp(t, T0, b1, b2, 0)
    theta = window_angle(t, theta0, c1, c2, T_out, T_in)
    return theta

# 执行控制

    if theta > 35:
        print("窗户应关闭")
    elif theta < 25:
        print("窗户应打开")
    else:
        print("窗户保持当前状态")

# 主函数

    t = 0
