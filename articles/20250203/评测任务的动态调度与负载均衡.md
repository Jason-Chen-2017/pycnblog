import random
import heapq
from collections import deque

class Scheduler:
    def __init__(self, num_resources):
        self.resources = ['Resource' + str(i) for i in range(num_resources)]
        self.task_queue = deque()
        self.resource_queues = {resource: deque() for resource in self.resources}

    def add_task(self, task):
        self.task_queue.append(task)

    def assign_task(self):
        if not self.task_queue:
            return None
        task = self.task_queue.popleft()
        resource = self.resources[random.randint(0, len(self.resources) - 1)]
        self.resource_queues[resource].append(task)
        return resource

    def execute_task(self, resource):
        if self.resource_queues[resource]:
            task = self.resource_queues[resource].popleft()
            # 执行任务...
            print(f"Executing task {task} on {resource}")
        else:
            print(f"No tasks to execute on {resource}")

    def update_queue(self):
        while self.task_queue:
            self.execute_task(self.assign_task())

#### 数学模型

假设有 \(N\) 个任务和一个资源池包含 \(M\) 个资源，每个资源可以同时处理 \(C\) 个任务。任务到达的时间服从泊松分布，任务执行时间为指数分布。调度算法的目标是最小化系统的平均响应时间和最大化资源利用率。

1. **平均响应时间（\(T_r\)）**:

   $$ T_r = \frac{1}{N} \sum_{i=1}^{N} T_i $$
   
   其中，\(T_i\) 是任务 \(i\) 的响应时间。

2. **资源利用率（\(U\)）**:

   $$ U = \frac{C \times T}{M \times T_c} $$
   
   其中，\(T\) 是所有任务执行时间之和，\(T_c\) 是每个资源的平均处理时间。

#### 示例说明

假设我们有3个任务（\(T_1, T_2, T_3\)）和2个资源（\(Resource1, Resource2\)）。每个资源可以同时处理1个任务，任务到达时间和执行时间均为均匀分布。

- **任务到达时间**：\(T_1 = 2\)，\(T_2 = 5\)，\(T_3 = 10\)
- **资源处理时间**：\(T_{c1} = 1\)，\(T_{c2} = 1\)

根据上述数学模型，我们可以计算出平均响应时间和资源利用率：

- **平均响应时间**:

  $$ T_r = \frac{1}{3} (2 + 5 + 10) = 4.67 $$
  
- **资源利用率**:

  $$ U = \frac{2 \times (2 + 5 + 10)}{2 \times 1} = 3 $$

这个结果表明，在当前任务分配和执行策略下，系统的平均响应时间为4.67，资源利用率为3。接下来，我们将进一步探讨如何通过优化调度算法和负载均衡策略来提高系统性能。

以下是关键代码的详细解释：

```python
import random
import heapq
from collections import deque
from threading import Thread

class TaskQueue:
    def __init__(self):
        self.tasks = deque()

    def add_task(self, task):
        heapq.heappush(self.tasks, task)

    def get_task(self):
        if self.tasks:
            return heapq.heappop(self.tasks)
        return None

class ResourcePool:
    def __init__(self, num_resources):
        self.resources = [f"Resource_{i}" for i in range(num_resources)]
        self.resource_queues = {resource: deque() for resource in self.resources}

    def add_resource(self, resource):
        self.resource_queues[resource].append(None)

    def get_resource(self):
        for resource in self.resources:
            if self.resource_queues[resource]:
                self.resource_queues[resource].popleft()
                return resource
        return None

    def release_resource(self, resource):
        self.resource_queues[resource].append(None)

class Scheduler:
    def __init__(self, task_queue, resource_pool):
        self.task_queue = task_queue
        self.resource_pool = resource_pool
        self.thread_pool = []

    def start(self):
        for _ in range(10):  # 创建10个线程
            thread = Thread(target=self.work)
            thread.start()
            self.thread_pool.append(thread)

    def work(self):
        while True:
            task = self.task_queue.get_task()
            if task is None:
                break
            resource = self.resource_pool.get_resource()
            if resource is not None:
                self.execute_task(task, resource)

    def execute_task(self, task, resource):
        print(f"Executing task {task} on {resource}")
        # 执行任务...
        self.resource_pool.release_resource(resource)

def main():
    task_queue = TaskQueue()
    resource_pool = ResourcePool(5)
    scheduler = Scheduler(task_queue, resource_pool)
    scheduler.start()

    # 添加任务
    for i in range(20):
        task_queue.add_task(f"Task_{i}")

if __name__ == "__main__":
    main()
```

#### 代码应用解读与分析

1. **任务队列**：使用`deque`实现了一个高效的任务队列，提供了`add_task`和`get_task`方法，分别用于添加和获取任务。`heappush`和`heappop`方法确保了队列的先进先出（FIFO）特性。
2. **资源池**：使用字典存储资源，并为每个资源分配一个队列，用于存放等待执行的任务。`get_resource`和`release_resource`方法用于获取和释放资源。
3. **调度器**：调度器创建了一个线程池，每个线程负责从任务队列中获取任务并执行。`work`方法实现了任务的调度逻辑。
4. **执行任务**：`execute_task`方法用于执行任务，并模拟了任务的执行过程。

通过以上实现，我们构建了一个简单的动态调度与负载均衡系统。在实际应用中，可以根据具体需求进一步优化和扩展。

#### 实际案例分析

1. **任务分类与特征**

   根据模型的复杂度和数据量，我们将任务分为以下三类：

   - **低优先级任务**：执行时间短，资源需求少。
   - **中优先级任务**：执行时间中等，资源需求适中。
   - **高优先级任务**：执行时间长，资源需求大。

   特征如下表所示：

   | 任务类型 | 执行时间 | 资源需求 | 优先级 |
   | --- | --- | --- | --- |
   | 低优先级 | 10秒 | 0.5 CPU | 低 |
   | 中优先级 | 30秒 | 1 CPU | 中 |
   | 高优先级 | 60秒 | 2 CPU | 高 |

2. **调度策略**

   为了满足不同类型任务的执行需求，我们采用了以下调度策略：

   - **动态优先级调度**：根据任务执行时间和资源需求动态调整任务的优先级。
   - **负载均衡调度**：根据系统当前负载情况，将任务分配到负载较低的资源上。

   具体实现如下：

   ```python
   def dynamic_priority_scheduler(task):
       if task.execution_time < 20:
           return 'LOW'
       elif task.execution_time < 40:
           return 'MEDIUM'
       else:
           return 'HIGH'

   def load_balancer(resource_pool, task_queue):
       while True:
           for resource in resource_pool.resources:
               if len(resource.task_queue) < resource.capacity:
                   task = task_queue.get_task()
                   if task:
                       resource.task_queue.append(task)
                       task.priority = dynamic_priority_scheduler(task)
                   else:
                       break
           break
   ```
