- **衰退期**：经济活动减缓，就业率下降，消费者支出减少，经济增长放缓甚至出现负增长。
- **复苏期**：经济活动开始回暖，就业率逐渐上升，消费者支出增加，经济增长逐渐恢复。
- **萧条期**：经济活动极度低迷，就业率极低，消费者支出大幅度减少，经济增长停滞甚至出现负增长。

经济周期的变化受到多种因素的影响，包括货币政策、财政政策、国际经济形势、技术创新、消费者信心等。

**5.1 经济周期预测模型**

经济周期预测模型是利用历史数据和统计方法，预测未来经济周期变化趋势的数学模型。常见的经济周期预测模型包括时间序列模型、回归模型和机器学习模型等。

1. **时间序列模型**：时间序列模型基于历史时间序列数据，通过统计方法分析数据序列的规律，预测未来的趋势。常见的时间序列模型有移动平均模型、指数平滑模型和ARIMA模型。

   - **移动平均模型（MA）**：通过计算一定时间窗口内的平均值来预测未来值。
     $$ \hat{y}_t = \frac{1}{n} \sum_{i=1}^{n} y_{t-i} $$
   - **指数平滑模型（ES）**：在移动平均模型的基础上，对近期数据赋予更高的权重。
     $$ \hat{y}_t = \alpha y_{t-1} + (1-\alpha) \hat{y}_{t-1} $$
   - **ARIMA模型**：自回归积分滑动平均模型，结合自回归（AR）、差分（I）和移动平均（MA）三种方法。
     $$ \hat{y}_t = c + \phi_1 \hat{y}_{t-1} + \phi_2 \hat{y}_{t-2} + ... + \phi_p \hat{y}_{t-p} + \theta_1 e_{t-1} + \theta_2 e_{t-2} + ... + \theta_q e_{t-q} $$

2. **回归模型**：回归模型通过建立自变量和因变量之间的关系，预测因变量的未来值。常见的回归模型有线性回归和多元回归。

   - **线性回归模型**：
     $$ \hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n $$
   - **多元回归模型**：在自变量多个的情况下，通过多个系数来预测因变量。
     $$ \hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n $$

3. **机器学习模型**：机器学习模型通过训练大量历史数据，建立预测模型。常见的机器学习模型有决策树、随机森林、支持向量机和神经网络等。

   - **决策树模型**：通过分类树结构来预测目标变量。
     $$ y = g(\theta) $$
   - **随机森林模型**：通过集成多棵决策树来提高预测准确率。
     $$ y = \sum_{i=1}^{n} w_i g(\theta_i) $$
   - **支持向量机模型**：通过寻找最佳分割超平面来预测目标变量。
     $$ \hat{y} = \text{sign}(\sum_{i=1}^{n} \alpha_i y_i \phi(x_i, x)) $$
   - **神经网络模型**：通过多层神经元的非线性组合来预测目标变量。
     $$ \hat{y} = \sigma(\sum_{i=1}^{n} \theta_i \phi(x_i, x)) $$

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
import matplotlib.pyplot as plt

# 1. 数据准备
data = pd.read_csv('economic_data.csv')  # 假设数据集已准备好
data = data[['GDP_growth']]  # 取GDP增长率为目标变量

# 2. 数据预处理
# 填充缺失值
data['GDP_growth'].fillna(method='ffill', inplace=True)
# 数据标准化
data['GDP_growth_normalized'] = (data['GDP_growth'] - data['GDP_growth'].mean()) / data['GDP_growth'].std()

# 3. 特征提取
# 这里直接使用原始的GDP增长率作为特征

# 4. 模型训练
# 选择ARIMA模型
model = ARIMA(data['GDP_growth_normalized'], order=(5, 1, 2))
model_fit = model.fit()

# 5. 预测分析
# 使用模型进行预测
forecast = model_fit.forecast(steps=6)  # 预测未来6个时间点的值

# 6. 结果可视化
plt.plot(data.index, data['GDP_growth_normalized'], label='Actual')
plt.plot(pd.date_range(data.index[-1], periods=6, freq='M'), forecast, label='Forecast')
plt.legend()
plt.show()
```
