### 第二部分：核心概念与联系

#### 2.1 智能体定义与特性
智能体是指具备一定智能、能够在复杂环境中自主决策和执行任务的实体。智能体具有以下特性：
- **自主性**：智能体能够独立完成决策任务，不受外界干预。
- **适应性**：智能体能够根据环境和目标的变化，调整自身行为。
- **协同性**：智能体之间能够通过信息共享和策略协调，实现共同目标。

#### 2.2 群体决策机制
群体决策是指多个智能体之间通过协同合作，共同完成决策任务的过程。群体决策机制主要包括以下内容：
- **信息共享**：智能体之间通过共享信息，实现对整体环境的了解。
- **策略协调**：智能体之间通过策略协调，实现共同决策的最优结果。
- **反馈调整**：智能体根据执行结果，调整自身策略，提高决策效率。

#### 2.3 资产配置策略
资产配置策略是指根据投资目标和风险偏好，将资金分配到不同资产类别中的方法。常见的资产配置策略包括：
- **战略性资产配置**：根据长期投资目标和风险偏好，制定资产配置策略。
- **战术性资产配置**：根据市场波动和短期投资机会，调整资产配置策略。
- **动态资产配置**：根据市场变化和投资目标，动态调整资产配置策略。

#### 2.4 优化投资组合方法
优化投资组合方法是指通过优化算法，调整投资组合结构，实现风险与收益的最优平衡。常见的优化投资组合方法包括：
- **均值-方差模型**：通过最小化方差，最大化预期收益，实现投资组合的最优化。
- **风险平价模型**：通过平衡不同资产类别的风险贡献，实现投资组合的风险控制。
- **目标风险模型**：通过设定目标风险水平，优化投资组合的收益水平。

# 计算最优资产配置比例
def cvxopt_matrix(expected_returns, cov_matrix, target_risk):
    # 使用cvxopt求解最优化问题
    p = cvxopt.matrix(expected_returns)
    q = cvxopt.matrix(-1 * np.eye(len(expected_returns)))
    G = cvxopt.matrix(np.concatenate((-cov_matrix, np.zeros((cov_matrix.shape[0], cov_matrix.shape[0]))), axis=1))
    h = cvxopt.matrix(np.concatenate((np.zeros(cov_matrix.shape[0]), target_risk * np.eye(cov_matrix.shape[0])), axis=1))
    A = cvxopt.matrix(np.eye(len(expected_returns)))
    b = cvxopt.matrix(1.0)
    
    solution = cvxopt.solvers.qp(P=G.T*G, q=q.T*p, G=G, h=h, A=A, b=b)
    w = solution['x'][:-1]
    
    return w

import pandas as pd
from cvxopt import matrix, solvers

def read_market_data(file_path):
    data = pd.read_csv(file_path)
    return data

# 计算预期收益和协方差矩阵
def calculate_stats(data):
    expected_returns = np.mean(data, axis=0)
    cov_matrix = np.cov(data, ddof=1)
    return expected_returns, cov_matrix

# 计算最优资产配置比例
def calculate_portfolio_weights(expected_returns, cov_matrix, target_risk):
    p = matrix(expected_returns)
    q = matrix(-1 * np.eye(len(expected_returns)))
    G = matrix(np.concatenate((-cov_matrix, np.zeros((cov_matrix.shape[0], cov_matrix.shape[0]))), axis=1))

    b = matrix(1.0)
    
    solution = solvers.qp(P=G.T*G, q=q.T*p, G=G, h=h, A=A, b=b)
    w = solution['x'][:-1]
    
    return w

# 调用核心实现
