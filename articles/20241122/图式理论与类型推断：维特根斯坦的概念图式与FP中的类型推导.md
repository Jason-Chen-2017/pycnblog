#### 第3章 FP语言与类型系统

#### 3.1 FP语言的概述

函数式编程（Functional Programming，简称FP）是一种编程范式，它强调使用函数来组织代码和操作数据。FP语言，如Haskell、Scala和Erlang，与传统的面向对象语言（如Java和C++）有所不同。在FP语言中，函数是一等公民，意味着函数可以作为参数传递，也可以作为返回值返回。这使得FP语言在处理复杂的数据结构和计算时具有很大的灵活性。

FP语言中的类型系统是其核心特征之一。类型系统用于定义变量、函数和表达式的类型，并确保程序在运行时不会出现类型错误。FP语言通常支持静态类型和动态类型，其中静态类型在编译时检查类型错误，而动态类型在运行时检查类型错误。

#### 3.2 FP中的类型系统

FP语言中的类型系统通常包括以下几种类型：

- **基本类型**：如整数（Integer）、浮点数（Float）、字符（Character）和布尔值（Boolean）等。
- **复合类型**：如数组（Array）、列表（List）和元组（Tuple）等。
- **函数类型**：表示一个函数，如`Int -> Int`表示一个接收整数参数并返回整数结果的函数。
- **抽象类型**：用于定义自定义类型，如`Person`表示一个人。

FP语言中的类型系统通常支持以下几种类型推导机制：

- **显式类型推导**：程序员显式地指定变量的类型，如`x : Int`表示`x`是一个整数。
- **隐式类型推导**：编译器根据上下文自动推导变量的类型，如`x = 10`，编译器会自动将`x`的类型推导为整数。
- **类型推断**：编译器在编译过程中自动推导函数的参数类型和返回类型，如`add(x, y) : Int`，编译器会自动推断`x`和`y`的类型。

#### 3.3 类型推导的基本规则

类型推导是FP语言中的一个重要机制，它用于确保程序在运行时不会出现类型错误。以下是一些类型推导的基本规则：

- **函数类型推导**：如果一个函数的参数类型和返回类型都已给出，编译器可以自动推导函数的类型。例如，如果`add(x : Int, y : Int) : Int`，则函数`add`的类型为`Int -> Int`。
- **类型兼容性**：如果一个表达式的实际类型与期望类型兼容，则类型推导成功。例如，如果`x : Int`，则`x + 1 : Int`。
- **类型错误**：如果类型推导失败，则编译器会报错。例如，如果`x : Int`，则`x + "hello" : String`会导致类型错误。
