## 引言

在计算机科学中，泛型编程是一种重要的编程范式，它允许我们编写可重用的代码，同时确保类型安全。泛型编程的核心是类型参数，这些参数在编译时被替换为具体类型。然而，仅仅使用类型参数并不能满足所有类型转换的需求。这就引出了协变与逆变这两种类型转换规则。

协变（Covariance）与逆变（Contravariance）是泛型编程中用来处理类型层次结构中子类型与父类型之间转换的关键机制。协变允许我们将一个子类型的实例赋值给一个父类型引用，而逆变则允许我们将一个父类型的实例赋值给一个子类型引用。这两种机制在保持类型安全的同时，提供了灵活的类型转换能力。

### 核心概念与联系

协变与逆变是处理类型层次结构中类型转换的两个相反的概念。为了更好地理解这两个概念，我们首先需要了解泛型编程中的几个基本概念。

#### 泛型编程

泛型编程是一种通过使用类型参数来编写可重用代码的编程范式。类型参数类似于占位符，它们在编译时被替换为具体类型。泛型编程的一个关键特性是类型安全，这意味着编译器在编译代码时会检查类型是否兼容。

#### 类型层次结构

类型层次结构是一种描述类型之间关系的结构。在Java中，类型层次结构是基于继承的。每个类型都有一个直接的超类型，直到到达Object类为止。子类型是父类型的一个特化，因此子类型的实例可以赋值给父类型的引用。

#### 协变

协变是指将子类型的实例赋值给父类型的引用。在泛型中，协变可以通过类型参数的协变注解来实现。例如，在Java中，`List<Number>`是`List<Object>`的协变类型。

#### 逆变

逆变是指将父类型的实例赋值给子类型的引用。在泛型中，逆变可以通过类型参数的逆变注解来实现。例如，在Java中，`Iterable<Object>`是`Iterable<Number>`的逆变类型。

#### 源代码实现

```java
import java.util.ArrayList;
import java.util.List;

public class TypeConversionDemo {
    public static void main(String[] args) {
        List<Number> numbers = new ArrayList<>();
        numbers.add(1);
        numbers.add(2);
        numbers.add(3);

        List<Object> objects = new ArrayList<>(numbers);

        for (Object obj : objects) {
            if (obj instanceof Integer) {
                System.out.println(obj);
            }
        }
    }
}
```

在这个例子中，我们定义了一个`TypeConversionDemo`类，并在其中定义了一个`main`方法。在这个方法中，我们创建了一个`List<Number>`的实例`numbers`，并添加了一些`Number`类型的对象。然后，我们使用协变将`numbers`转换为`List<Object>`的实例`objects`。

#### 代码解读

- `List<Number>`与`List<Object>`之间的关系：`List<Number>`是`List<Object>`的协变类型，因此我们可以将`numbers`转换为`objects`。
- 类型安全：在循环中，我们使用`instanceof`检查每个对象的类型，确保我们只处理`Integer`类型的对象。这保证了类型安全。
