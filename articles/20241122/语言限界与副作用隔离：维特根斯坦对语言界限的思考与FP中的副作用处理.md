#### 函数作为值

函数在FP中是一等公民，这意味着函数可以被赋值给变量、作为参数传递、返回作为结果。以下是一个简单的Python示例：

```python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)  # 输出：7
```

#### 高阶函数

高阶函数是能够接受函数作为参数或返回函数的函数。以下是一个Haskell示例：

```haskell
-- 柯里化函数
curryAdd :: Int -> Int -> Int
curryAdd x y = x + y

-- 应用高阶函数
applyFunction :: (Int -> Int -> Int) -> Int -> Int
applyFunction f x = f x

result = applyFunction curryAdd 3
print(result)  # 输出：6
```

### 2.2.2 模式匹配

模式匹配是FP中的一个重要特性，它允许我们根据变量的值进行分支处理。以下是一个Scala示例：

```scala
def matchExample(x: Any): String = x match {
  case 1 => "One"
  case "two" => "Two"
  case _ => "Other"
}

print(matchExample(1))  // 输出："One"
print(matchExample("two"))  // 输出："Two"
print(matchExample("other"))  // 输出："Other"
```
