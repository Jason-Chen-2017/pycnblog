### 柏格森的持续理论

亨利·柏格森（Henri Bergson）是20世纪初法国著名的哲学家，他的持续理论（Duration Theory）对后来的文学批评和艺术理论产生了深远影响。柏格森的持续理论主张，时间并不是一种均匀流逝的线性过程，而是充满间断和差异的持续流动。这一理论的核心观点包括：

1. **时间与空间的区别**：柏格森认为，时间和空间是两种截然不同的概念。时间是一种连续的、流动的过程，是一种“持续的现在”（Duration）；而空间则是静态的、离散的，是一种“瞬间”的存在。

   ```mermaid

   A[时间] --> B[持续]
   B --> C[空间]
   C --> D[瞬间]
   ```

2. **直觉与理性的对立**：柏格森认为，直觉是理解持续的关键，而理性则是对持续的破坏。直觉能够捕捉到时间的流动和变化的本质，而理性则倾向于将时间分割成可量化的部分，从而丧失了时间的连续性。

   ```mermaid
   flowchart LR
   A[直觉] --> B[时间感知]
   B --> C[理性]
   C --> D[时间分割]
   ```

3. **生命的创造力**：柏格森强调生命的创造力，认为这种创造力是持续的本质。生命不断地创造新的可能性，从而推动时间向前发展。

   ```mermaid

   A[生命] --> B[创造力]
   B --> C[时间流动]
   ```
