**4.1 最短路径算法**

**定义**：最短路径算法是指寻找图中两点之间路径长度最短的算法。

**基本原理**：

- **迪杰斯特拉算法（Dijkstra算法）**：用于求解无权图和有权图中两点之间的最短路径。
- **弗洛伊德算法（Floyd算法）**：用于求解加权图中任意两点之间的最短路径。

**伪代码**：

```python
Dijkstra(G, s):
    dist[s] = 0
    for each vertex v in G:
        if v != s:
            dist[v] = infinity
    prev[s] = null
    for each edge (u, v) in G:
        if dist[u] + weight(u, v) < dist[v]:
            dist[v] = dist[u] + weight(u, v)
            prev[v] = u
    return dist, prev
```

**举例说明**：假设有一个城市交通网络，包含5个节点（A、B、C、D、E）和相应的边权重，使用Dijkstra算法求解从节点A到节点E的最短路径。
