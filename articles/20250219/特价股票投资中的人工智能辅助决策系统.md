## 第四部分：系统分析与架构设计

### 第4章：系统的数学模型与公式

#### 4.1 线性回归模型
- 4.1.1 线性回归的基本公式
  - 单变量线性回归：$y = \theta_0 + \theta_1 x$。
  - 多变量线性回归：$y = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \dots + \theta_n x_n$。
- 4.1.2 最小二乘法的数学推导
  - 损失函数：$L = \sum_{i=1}^{m}(y_i - \hat{y}_i)^2$。
  - 最优化：$\frac{\partial L}{\partial \theta_j} = 0$。

#### 4.2 LSTM 网络模型
- 4.2.1 LSTM 的基本结构
  - 输入门：$i_t = \sigma(w_i x_t + u_i h_{t-1} + b_i)$。
  - 遗忘门：$f_t = \sigma(w_f x_t + u_f h_{t-1} + b_f)$。
  - 输出门：$o_t = \sigma(w_o x_t + u_o h_{t-1} + b_o)$。
  - 细胞状态：$c_t = f_t c_{t-1} + i_t tanh(w_c x_t + u_c h_{t-1} + b_c)$。
  - 隐藏层：$h_t = o_t tanh(c_t)$。
