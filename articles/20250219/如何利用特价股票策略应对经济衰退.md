## 第一部分：经济衰退与特价股票策略概述

### 第1章：经济衰退的背景与影响

#### 1.1 经济衰退的定义与特征

- **经济衰退的定义**：经济衰退是指经济活动的显著下降，通常表现为GDP连续两个季度负增长，伴随着失业率上升和消费者信心下降。
- **经济衰退的主要特征**：
  - 经济增长放缓或停滞。
  - 失业率上升，企业裁员或倒闭。
  - 消费者和企业信心下降，投资意愿减弱。
  - 金融机构面临压力，信贷紧缩。
- **经济衰退对股市的影响**：
  - 股市大幅波动，投资者信心受挫。
  - 股价下跌，尤其是高杠杆和高风险股票。
  - 市场流动性下降，交易量减少。

#### 1.2 特价股票的定义与优势

- **特价股票的定义**：特价股票是指市场价格低于其内在价值的股票，通常因为市场恐慌或公司特定问题导致股价被低估。
- **特价股票的优势**：
  - 低估值，潜在上涨空间大。
  - 抗跌性强，波动性小。
  - 分红收益率高，适合长期投资。
- **特价股票在经济衰退中的作用**：
  - 在市场低迷时，特价股票可能成为避风港。
  - 投资者可以在低价时买入，等待市场复苏时获利。

## 第二部分：特价股票策略的核心概念

### 第2章：特价股票策略的原理与方法

#### 2.1 特价股票识别方法

- **市盈率分析**：
  - 市盈率（P/E）= 股价 / 每股收益。
  - 低市盈率（低于行业平均水平）可能意味着股票被低估。
- **市净率分析**：
  - 市净率（P/B）= 股价 / 每股净资产。
  - 低市净率通常意味着股票价值被低估。
- **股息率分析**：
  - 股息率 = 每股股息 / 股价 × 100%。
  - 高股息率股票在市场低迷时提供稳定的现金流。

#### 2.2 市场趋势分析

- **趋势分析方法**：
  - 使用移动平均线、趋势线等技术指标识别市场趋势。
- **技术分析工具**：
  - K线图、MACD、RSI等工具帮助判断市场超买超卖状态。
- **市场情绪分析**：
  - 通过新闻、社交媒体和投资者情绪指标判断市场情绪。

### 第6章：项目实战

#### 6.1 环境配置

- **数据源**：使用Yahoo Finance API获取股票数据。
- **开发工具**：Python、Pandas、NumPy、Matplotlib。

#### 6.2 核心代码实现

```python
import pandas as pd
import numpy as np
import requests
import matplotlib.pyplot as plt

# 获取股票数据
def get_stock_data(ticker):
    url = f"https://query1.finance.yahoo.com/..."
    response = requests.get(url)
    data = response.json()
    df = pd.DataFrame(data['rows'])
    return df

# 计算市盈率和市净率
def calculate_valuationMetrics(df):
    df['市盈率'] = df['股价'] / df['每股收益']
    df['市净率'] = df['股价'] / df['每股净资产']
    return df

# 筛选特价股票
def screen_penny_stocks(df, threshold_pe=15, threshold_pb=2):
    df = calculate_valuationMetrics(df)
    df = df[df['市盈率'] < threshold_pe]
    df = df[df['市净率'] < threshold_pb]
    return df

# 可视化
def visualize_stocks(df):
    plt.figure(figsize=(10,6))
    plt.plot(df['股价'], label='股价')
    plt.xlabel('时间')
    plt.ylabel('股价')
    plt.legend()
    plt.show()

# 主程序
if __name__ == "__main__":
    df = get_stock_data("AAPL")
    filtered_df = screen_penny_stocks(df)
    visualize_stocks(filtered_df)
```
