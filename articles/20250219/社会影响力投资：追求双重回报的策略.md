### 第2章: 社会影响力投资的理论基础

#### 2.1 社会价值的定义与测量
- **社会价值的内涵**：
  - 社会价值是指投资于社会企业或公益项目所创造的社会效益，包括环境保护、教育、医疗、就业等方面。
- **社会价值的测量指标**：
  - 环境影响：如碳排放减少量。
  - 社会影响：如就业机会、贫困减少等。
  - 治理效果：如企业合规性、透明度等。

#### 2.2 双重回报的实现机制
- **财务回报与社会回报的平衡**：
  - 投资者需要在追求财务回报的同时，关注社会价值的实现。
  - 社会影响力投资的收益分配需要平衡各方利益，确保社会价值的实现。

import numpy as np

def social_influence_investment():
    # 定义目标函数
    def objective(x):
        return -x[0] - x[1]

    # 约束条件
    constraints = [{'type': 'ineq', 'fun': lambda x: x[0] + x[1] - 1}]

    # 使用 scipy.optimize 求解
    from scipy.optimize import minimize
    res = minimize(objective, [0.5, 0.5], constraints=constraints)
