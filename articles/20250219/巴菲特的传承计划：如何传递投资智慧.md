# 第一部分：巴菲特的生平与投资哲学

## 第1章：巴菲特的生平与投资哲学

### 1.1 巴菲特的早年经历
- **1934年出生**：巴菲特出生于美国内布拉斯州，早年展现出对数字和投资的浓厚兴趣。
- **合伙企业**：20世纪50年代，巴菲特创立合伙企业，采用合伙人制度，为后来的传承计划奠定基础。
- **导师影响**：受本杰明·格雷厄姆的影响，确立价值投资理念。

### 1.2 巴菲特的投资哲学
- **价值投资**：寻找市场低估的企业，注重安全边际。
- **长期投资**：避免短期波动，注重企业长期价值。
- **安全边际**：通过低估价格和高利润率确保投资安全。

### 1.3 传承计划的意义
- **家族传承**：通过合伙企业模式，将投资理念传递给后代。
- **知识传递**：通过著作和演讲，分享投资智慧。
- **心理建设**：培养耐心和纪律，确保投资体系的延续。

- **起源**：20世纪初由格雷厄姆提出，强调寻找市场低估的价值。

- **计算公式**：安全边际 = 内在价值 - 市场价格。
- **实际应用**：通过分析财务报表，评估企业盈利能力。

### 2.3 巴菲特的选股标准

- **竞争优势**：成本优势、品牌影响力。

  import numpy as np

  # 示例：计算投资组合的期望收益和风险
  weights = np.array([0.6, 0.4])
  returns = np.array([0.1, 0.2])
  covariance = np.array([[0.01, 0.005], [0.005, 0.02]])

  expected_return = np.dot(weights, returns)
  portfolio_variance = np.dot(weights, np.dot(covariance, weights))
  portfolio_volatility = np.sqrt(portfolio_variance)

  print("期望收益:", expected_return)
  print("风险:", portfolio_volatility)
