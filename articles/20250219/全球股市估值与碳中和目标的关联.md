##### 3.3 Python代码实现

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 示例数据加载
data = pd.DataFrame({
    '政策支持': [0.8, 0.6, 0.7, 0.9],
    '企业转型能力': [0.5, 0.7, 0.6, 0.8],
    '股市估值': [1500, 1300, 1400, 1600]
})

# 模型训练
X = data[['政策支持', '企业转型能力']]
y = data['股市估值']

model = LinearRegression()
model.fit(X, y)

# 模型预测
y_pred = model.predict(X)

# 模型评估
r2 = r2_score(y, y_pred)
print(f"R²: {r2}")
```

##### 3.4 数学模型与公式

- **多元回归模型**：  
  $$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \epsilon $$  
  其中，$y$为股市估值，$x_1$为政策支持，$x_2$为企业转型能力，$\beta$为回归系数，$\epsilon$为误差项。

- **时间序列模型**：  
  $$ y_t = \alpha y_{t-1} + \beta x_t + \gamma $$  
  其中，$y_t$为当前股市估值，$x_t$为当前政策支持，$\alpha$为自回归系数，$\beta$为政策支持的影响系数，$\gamma$为常数项。
