### 3.2.2 算法实现步骤（Python源代码）

```python
import pandas as pd

# 数据收集与处理
data = pd.DataFrame({
    '指标': ['市场占有率', '客户满意度', '产品质量'],
    '权重': [0.4, 0.3, 0.3]
})

# 计算加权分数
weighted_scores = data['权重'].apply(lambda x: x * 100)
data['加权分数'] = weighted_scores

print(data)
```

### 3.2.3 数学公式与详细讲解  
加权分数计算公式：  
$$ \text{加权分数} = \sum (\text{权重}_i \times \text{指标值}_i) $$

## 5.2 核心实现源代码

### 5.2.1 数据处理代码

```python
import pandas as pd

data = pd.DataFrame({
    '市场占有率': [20, 25, 30],
    '客户满意度': [85, 90, 75],
    '产品质量': [90, 80, 85]
})

weights = pd.Series([0.4, 0.3, 0.3], index=data.columns)

weighted_data = data.apply(lambda x: x * weights)
total_scores = weighted_data.sum(axis=1)

print(total_scores)
```

### 5.2.2 评估模型实现

```python
def calculate_scores(data, weights):
    return data.dot(weights)

market_share = [20, 25, 30]
customer_satisfaction = [85, 90, 75]
product_quality = [90, 80, 85]

weights = {'市场占有率': 0.4, '客户满意度': 0.3, '产品质量': 0.3}

data = {'市场占有率': market_share, '客户满意度': customer_satisfaction, '产品质量': product_quality}
df = pd.DataFrame(data)

scores = calculate_scores(df, weights)
print(scores)
```
