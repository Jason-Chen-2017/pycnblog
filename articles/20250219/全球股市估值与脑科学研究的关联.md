## 第3章: 行为金融学中的认知偏差与股市估值

### 3.1 行为金融学的基本原理
#### 3.1.1 理性人假设的局限性
传统金融学假设投资者是理性的，但现实中投资者往往受情绪影响，导致认知偏差。

#### 3.1.2 行为金融学的核心理论
行为金融学结合心理学，研究投资者行为，发现价格与价值偏离的现象。

#### 3.1.3 理性与非理性决策的对比
| 属性 | 理性决策 | 非理性决策 |
|------|---------|-----------|
| 基础 | 理性模型 | 行为偏差 |
| 表现 | 稳定 | 不稳定 |
| 应用 | 理论模型 | 实际市场 |

### 3.2 认知偏差对股市估值的影响
#### 3.2.1 过度自信偏差
投资者高估自身判断能力，导致错误决策。

#### 3.2.2 从众心理
投资者跟随市场趋势，忽视独立分析。

#### 3.2.3 损失厌恶
投资者对损失的敏感性高于收益，影响投资决策。

### 3.3 投资者情绪与股市波动的关系
#### 3.3.1 情绪指数模型
通过投资者情绪预测市场波动，如恐慌指数。

### 4.1 神经网络的基本原理

### 4.2 神经网络在股市预测中的应用
#### 4.2.1 LSTM网络
处理时间序列数据，预测股价波动。

#### 4.2.2 网络结构
输入层：历史数据，隐藏层：特征提取，输出层：预测值。

### 4.3 算法实现
```python
import numpy as np
from sklearn.datasets import make_regression
from sklearn.metrics import mean_squared_error
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

# 生成数据
X, y = make_regression(n_samples=100, n_features=10, noise=0.1)

# 模型构建
model = Sequential()
model.add(Dense(64, activation='relu', input_dim=X.shape[1]))
model.add(Dense(1, activation='linear'))

model.compile(optimizer='adam', loss='mean_squared_error')

# 训练模型
model.fit(X, y, epochs=100, batch_size=32)

# 预测
y_pred = model.predict(X)
print(mean_squared_error(y, y_pred))
```
