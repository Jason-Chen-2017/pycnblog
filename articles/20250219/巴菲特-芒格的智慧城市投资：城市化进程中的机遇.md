### 第6章：项目实战

#### 6.1 案例分析：智慧交通系统投资
- **项目背景**：分析某城市智慧交通系统的投资可行性。
- **环境分析**：评估政策支持、市场需求和技术可行性。
- **代码实现**：
  ```python
  # 计算投资回报率
  initial_investment = 1000000  # 初始投资
  annual_return = 0.15  # 年回报率
  years = 5

  # 内部收益率计算
  def calculateIRR():
    cash_flows = [-initial_investment] + [initial_investment*(1+annual_return)**i for i in range(1, years+1)]
    return round(((sum(cash_flows) ** (1/years)) - 1) * 100, 2)

  irr = calculateIRR()
  print(f"内部收益率：{irr}%")
  ```
