# 第2章: 什么是市场份额

## 2.1 市场份额的定义与分类

### 2.1.1 市场份额的定义

市场份额是公司产品或服务在特定市场中的销售比例，反映公司在市场中的地位和竞争力。公式为：市场份额 = (公司销售额 / 行业销售额) × 100%。

### 2.1.2 市场份额的分类与特点

市场份额可分为绝对市场份额和相对市场份额。绝对市场份额是公司在整个市场中的占比，而相对市场份额是公司在某一区域或细分市场中的占比。

### 2.1.3 市场份额的核心要素与属性对比表格

| 要素         | 描述                                       |
|--------------|--------------------------------------------|
| 销售额       | 公司的销售额与行业销售额                   |
| 行业结构     | 市场集中度，寡头垄断或分散市场             |
| 竞争对手     | 主要竞争对手的市场份额                   |
| 市场增长率   | 行业整体增长趋势                         |
