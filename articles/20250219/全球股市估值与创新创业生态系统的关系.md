## 第二章：全球股市估值的分析与模型

### 2.1 股市估值的基本方法

#### 2.1.1 市盈率（PE）模型
市盈率是衡量股票价值的重要指标，公式为：

$$ PE = \frac{Price}{Earnings} $$

其中，Price为股票价格，Earnings为每股收益。

#### 2.1.2 市净率（PB）模型
市净率是股票价格与每股净资产的比率，公式为：

$$ PB = \frac{Price}{Book\ Value\ Per\ Share} $$

#### 2.1.3 现金流折现模型（DCF）
DCF模型通过将未来现金流折现到现值，评估企业的内在价值。公式为：

$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n} $$

其中，\( CF_t \) 为第t年的现金流，\( r \) 为折现率，\( TV \) 为终值。

### 2.2 股市估值的数学模型

#### 2.2.1 PE模型公式
$$ PE = \frac{Price}{Earnings} $$

#### 2.2.2 DCF模型公式
$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n} $$

#### 2.2.3 模型的优缺点对比（表格）

| 模型       | 优点                     | 缺点                     |
|------------|--------------------------|--------------------------|
| PE模型     | 简单易懂，适用于盈利稳定的企业 | 无法反映资产质量，适用于亏损企业时效果不佳 |
| PB模型     | 考虑了资产价值，适用于资产密集型企业 | 不能反映盈利能力，适用于亏损企业时效果不佳 |
| DCF模型     | 能够全面反映企业未来现金流，适合长期估值 | 计算复杂，需要准确预测未来现金流 |

```python
import pandas as pd
import numpy as np

# 示例代码：计算市盈率
def calculate_pe(stock_price, earnings_per_share):
    return stock_price / earnings_per_share

# 示例代码：计算市净率
def calculate_pb(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

# 示例代码：计算现金流折现模型
def calculate_dcf(cash_flows, discount_rate, terminal_value):
    return sum(cash_flows / (1 + discount_rate)**t for t in range(len(cash_flows))) + terminal_value / (1 + discount_rate)**len(cash_flows)
```
