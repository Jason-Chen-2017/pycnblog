### 第2章：股市估值算法与数学模型

#### 2.1 股市估值算法原理

- **CAPM模型**：计算预期回报率，公式为：$$R_i = R_f + β_i (R_m - R_f)$$
  其中，\(R_i\) 是股票的预期回报率，\(R_f\) 是无风险利率，\(β_i\) 是股票的贝塔值，\(R_m\) 是市场预期回报率。

#### 2.2 数学模型与公式

- **市盈率（P/E）**：$$\text{P/E} = \frac{\text{股价}}{\text{每股收益}}$$
- **市净率（P/B）**：$$\text{P/B} = \frac{\text{股价}}{\text{每股净资产}}$$

#### 2.3 算法实现

```python
def calculate_capm(risk_free_rate, beta, market_return):
    return risk_free_rate + beta * (market_return - risk_free_rate)
```

        address supplier;
        string status;
    }

    Product[] products;

    function addProduct(uint pid, address supplier) public {
        products.push(Product(pid, supplier, "in progress"));
    }

    function updateStatus(uint pid, string memory newStatus) public {
        for (uint i = 0; i < products.length; i++) {

        }

}
