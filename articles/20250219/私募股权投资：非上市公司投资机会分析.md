# 第1章: 私募股权投资概述

## 1.1 私募股权投资的定义与特点

### 1.1.1 私募股权投资的定义
私募股权投资（Private Equity Investment，简称PEI）是指通过私募基金或其他私人投资工具，对非上市公司进行权益性投资的行为。其核心目标是通过投资优质企业，实现资本增值。

### 1.1.2 私募股权投资的核心特点
- **低流动性**：非上市公司股权无法像公开市场股票那样随时买卖。
- **高风险性**：非上市公司经营不确定性较高，投资风险较大。
- **高回报潜力**：通过价值挖掘和增值，私募股权投资可能带来远超公开市场的回报。
- **专业性**：私募股权投资需要专业的团队和知识支持。

### 1.1.3 私募股权投资与公开市场的区别
- **市场流动性**：公开市场流动性高，私募市场流动性低。
- **信息透明度**：公开市场信息透明，私募市场信息相对封闭。
- **投资者门槛**：公开市场对所有投资者开放，私募市场通常对合格投资者开放。

## 1.2 私募股权投资的基本流程

### 1.2.1 投资前的尽职调查
尽职调查是私募股权投资的核心步骤，包括对企业财务状况、管理团队、市场竞争力等方面进行详细评估。

### 1.2.2 投资协议的签订
在尽职调查的基础上，投资者与目标企业签订投资协议，明确投资金额、股权比例、退出机制等关键条款。

### 1.2.3 投资后管理与退出策略
投资完成后，投资者需要对被投资企业进行持续监控和管理，确保企业按计划发展。退出策略包括上市、并购或股权转让等方式。

## 1.3 私募股权投资的主要类型

### 1.3.1 风险投资（VC）
风险投资主要针对初创企业，通过提供资金支持企业成长，期望通过高增长实现高回报。

### 1.3.2 私募股权基金（PE）
私募股权基金通常投资于中后期企业，通过企业重组、管理优化等方式实现增值。

### 1.3.3 并购投资（M&A）
并购投资是指通过收购目标企业部分或全部股权，实现企业战略整合和价值提升。

## 1.4 本章小结
本章介绍了私募股权投资的基本概念、特点、流程及主要类型，为后续分析奠定了基础。

### 4.1.2 投资组合优化的目标函数

### 4.1.3 投资组合优化的约束条件

## 4.2 马科维茨均值-方差模型

### 4.2.1 模型假设

$$ \text{目标函数：} \min_w \frac{1}{2} w^T \Sigma w $$
$$ \text{约束条件：} \sum_{i=1}^n w_i = 1 $$

### 4.2.3 模型实现

import numpy as np

def portfolio_optimization(returns):
    # 计算协方差矩阵
    covariance_matrix = np.cov(returns)
    # 计算权重
    w, _, _ = np.linalg.svd(covariance_matrix)
    return w
