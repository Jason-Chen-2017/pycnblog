  - 风险管理：分散投资，控制仓位，降低风险。
- **1.1.3 耐心资本与传统投资的区别**

#### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 数据处理
data = pd.read_csv('stock_data.csv')
returns = data['return'].values

# 耐心资本算法
def patience_capital_strategy(returns, window=5):
    positions = []
    for i in range(len(returns)):
        if i < window:
            positions.append(1)
        else:
            # 简单的动量策略
            if returns[i-1] > returns[i-2] and returns[i-2] > returns[i-3]:
                positions.append(1)
            else:
                positions.append(0)
    return positions

# 策略回测
positions = patience_capital_strategy(returns)
returns_strat = returns * positions
cumulative_return = np.cumprod(1 + returns_strat) - 1
plt.plot(cumulative_return)
plt.title('Patience Capital Strategy Cumulative Returns')
plt.show()
```

- 数据处理：读取股票数据，计算收益率。
- 策略实现：基于动量策略，选择持有优质资产。
- 图表展示：绘制累积收益曲线，验证策略的有效性。
