### 第2章: 全球股市估值的核心概念与原理

#### 2.1 全球股市估值的定义与特点

##### 2.1.1 股市估值的定义
股市估值是通过对股票价格和相关财务指标的分析，评估企业的内在价值。

##### 2.1.2 股市估值的核心特点
- 动态性：随市场变化而波动
- 综合性：涉及多因素分析
- 预测性：帮助投资者预测未来趋势

#### 2.2 全球股市估值的计算方法

##### 2.2.1 市盈率法
市盈率（P/E）= 股价 / 每股收益（EPS）

##### 2.2.2 市净率法
市净率（P/B）= 股价 / 每股净资产（BPS）

##### 2.2.3 股息率法
股息率 = 每股股息 / 股价

#### 2.3 全球股市估值的驱动因素

##### 2.3.1 经济因素
- 宏观经济政策
- 利率水平

##### 2.3.2 行业因素

- 竞争格局

##### 2.3.3 公司基本面因素
- 盈利能力
- 财务状况

##### 5.2.1 股市估值预测模型
```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据预处理
data = pd.read_csv('stock_data.csv')
X = data[['PE', 'PB', 'Dividend_Yield']]
y = data['Stock_Price']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测
new_data = pd.DataFrame({
    'PE': [15],
    'PB': [2],
    'Dividend_Yield': [0.05]
})
prediction = model.predict(new_data)
print(f'预测股价为: {prediction[0]:.2f}')
```
