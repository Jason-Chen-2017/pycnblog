## 第一部分：背景介绍

### 第1章：影响投资的定义与背景

#### 1.1 影响力投资的定义
- 影响力投资是指投资者在追求财务回报的同时，投资于那些在社会、环境或治理方面具有积极影响的企业。这种投资不仅关注企业盈利能力，还关注其对社会和环境的贡献。
- 与传统投资相比，影响力投资更注重长期价值和社会价值的结合。

#### 1.2 格雷厄姆特价股票理论概述
- 本杰明·格雷厄姆是价值投资的鼻祖，他提出的特价股票理论强调以低于内在价值的价格买入股票。
- 格雷厄姆的筛选标准包括低市盈率（P/E < 15）、低市净率（P/B < 1.5）和高股息率（股息率 > 3%）。

### 第2章：影响投资的核心概念与问题背景

#### 2.1 核心概念
- 影响力投资的核心在于企业对社会和环境的积极影响，这包括环境保护、社会责任和治理结构等方面。
- 格雷厄姆理论的核心在于寻找市场低估的股票，这些股票通常具有较高的安全边际。

#### 2.2 问题背景
- 传统投资往往忽视企业的社会和环境表现，导致投资决策可能对社会和环境产生负面影响。
- 影响力投资的需求日益增长，但缺乏有效的筛选方法，难以将社会影响力与财务回报结合起来。

### 第4章：格雷厄姆特价股票筛选算法

#### 4.1 算法流程图
- 格雷厄姆筛选算法的步骤：
  ```mermaid
  graph TD
    A[数据获取] --> B[计算P/E]
  ```

#### 4.2 Python代码实现
  ```python
  import pandas as pd

  def get_cheap_stocks(data):
      cheap_stocks = data[(data['PE'] < 15) & (data['PB'] < 1.5) & (data['Dividend_Yield'] > 0.03)]
      return cheap_stocks

  # 示例数据
  data = pd.DataFrame({
      'PE': [12, 20, 10],
      'PB': [1.2, 2.0, 0.8],
      'Dividend_Yield': [0.04, 0.02, 0.05]
  })

  result = get_cheap_stocks(data)
  print(result)
  ```

#### 4.3 数学模型
- 市盈率（P/E）公式：
  $$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
- 市净率（P/B）公式：
  $$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$
- 股息率公式：
  $$ \text{股息率} = \frac{\text{每股股息}}{\text{股价}} $$
