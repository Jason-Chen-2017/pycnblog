其中：
- 财务评分范围：1-5分
- 市场评分范围：1-5分
- 研发评分范围：1-5分

##### 3.3 算法实现与代码解读

###### 核心代码实现
```python
def calculate_potential(financial_score, market_score, r_d_score):
    weight_financial = 0.4
    weight_market = 0.3
    weight_r_d = 0.3
    total_score = weight_financial * financial_score + weight_market * market_score + weight_r_d * r_d_score
    return total_score

# 示例数据
financial_score = 4
market_score = 3
r_d_score = 4

potential = calculate_potential(financial_score, market_score, r_d_score)
print(f"长期增长潜力评分：{potential}")
```

###### 代码解读与分析
- 函数 `calculate_potential` 接收三个评分参数
- 计算总评分，权重分别为0.4、0.3、0.3
- 示例计算得出潜力评分为3.4
