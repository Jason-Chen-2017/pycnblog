## 第3章: 专利组合价值评估的算法原理与数学模型

### 3.1 专利组合价值评估的主要方法

#### 3.1.1 层次分析法（AHP）

- **层次分析法的基本原理**：将复杂的决策问题分解为多个因素，通过层次结构进行分析和评估。
- **层次分析法的应用步骤**：
  1. 构建层次结构模型。
  2. 确定各因素的权重。
  3. 进行综合评估。

- **层次分析法的数学模型**：
  $$ A = \sum_{i=1}^{n} w_i x_i $$
  其中，\( A \) 是综合评估值，\( w_i \) 是各因素的权重，\( x_i \) 是各因素的评估值。

#### 3.1.2 模糊综合评价法

- **模糊综合评价法的基本原理**：将评估对象转化为模糊集合，通过模糊运算进行综合评价。
- **模糊综合评价法的应用步骤**：
  1. 确定模糊评估指标。
  2. 建立模糊评估矩阵。
  3. 进行模糊合成和综合评价。

- **模糊综合评价法的数学模型**：
  $$ V = \sum_{i=1}^{n} w_i f_i(x) $$
  其中，\( V \) 是综合评估值，\( w_i \) 是各因素的权重，\( f_i(x) \) 是各因素的评估函数。

#### 3.1.3 熵值法

- **熵值法的基本原理**：基于信息论中的熵值概念，通过计算各因素的信息量来确定其权重。
- **熵值法的应用步骤**：
  1. 收集各因素的数据。
  2. 计算各因素的熵值。
  3. 确定各因素的权重。
  4. 进行综合评估。

- **熵值法的数学模型**：
  $$ C_i = \frac{\sum_{j=1}^{m} f_{ij}}{\sum_{j=1}^{m} f_{jj}}} $$
  其中，\( C_i \) 是第 \( i \) 个因素的权重，\( f_{ij} \) 是第 \( i \) 个因素在第 \( j \) 个样本的值，\( f_{jj} \) 是第 \( j \) 个样本的总值。

### 3.2 算法实现与代码示例

#### 3.2.1 层次分析法的Python实现

```python
import numpy as np

def calculate_weights(matrix):
    # 计算权重
    n = len(matrix)
    # 计算一致性检验
    a = np.array(matrix)
    # 计算一致性指标
    CI = 0
    for i in range(n):
        for j in range(n):
            if i == j:
                a[i][j] = 1
            else:
                a[i][j] = min(a[i][j], a[j][i])
    # 计算一致性检验
    max_eig = np.linalg.eigvals(a).max()
    CI = (max_eig - n) / (n - 1)
    # 如果一致性指标小于0.1，则认为一致性良好
    if CI < 0.1:
        return True
    else:
        return False

# 示例数据矩阵
matrix = [
    [1, 2, 3],
    [1/2, 1, 2],
    [1/3, 1/2, 1]
]

# 计算权重
weights = calculate_weights(matrix)
print(weights)
```

```python
def fuzzy_comprehensive_evaluation(factors, weights):
    # 模糊综合评价
    n = len(factors)
    m = len(weights)
    # 建立模糊评估矩阵
    matrix = []
    for i in range(n):
        row = []
        for j in range(m):
            row.append(factors[i][j] * weights[j])
        matrix.append(row)
    # 进行模糊合成
    result = []
    for i in range(n):
        total = sum(matrix[i])
        result.append(total)
    return result

# 示例数据
factors = [
    [1, 2, 3],
    [2, 1, 4],
    [3, 4, 2]
]
weights = [0.4, 0.3, 0.3]

# 进行模糊综合评价
evaluation = fuzzy_comprehensive_evaluation(factors, weights)
print(evaluation)
```

#### 3.2.3 熵值法的Python实现

```python
def entropy_method(data):
    # 熵值法
    n = len(data)
    m = len(data[0])
    # 计算每列的熵值
    entropy = []
    for j in range(m):
        # 计算第j列的熵值
        column = [data[i][j] for i in range(n)]
        # 标准化
        total = sum(column)
        if total == 0:
            entropy.append(0)
            continue
        prob = [x / total for x in column]
        H = -sum(p * np.log2(p) for p in prob)
        entropy.append(H)
    # 计算各列的权重
    weights = []
    for j in range(m):
        weights.append(entropy[j])
    # 归一化权重
    total_weight = sum(weights)
    normalized_weights = [w / total_weight for w in weights]
    return normalized_weights

# 示例数据
data = [
    [1, 2, 3],
    [2, 3, 4],
    [3, 4, 5]
]

# 计算熵值
weights = entropy_method(data)
print(weights)
```
