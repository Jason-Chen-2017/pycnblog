### 第2章：格雷厄姆策略的核心原理

#### 2.1 核心原理
- 2.1.1 内在价值的计算方法  
  内在价值 = 股票未来现金流的现值，公式：$$ V = \sum_{t=1}^{\infty} \frac{CF_t}{(1+r)^t} $$  
- 2.1.2 安全边际的概念与应用  
  安全边际 = 内在价值 - 市场价格，确保投资的安全性。  
- 2.1.3 市场先生的波动性分析  
  市场波动性影响股票价格，投资者需在市场恐慌时寻找低估机会。

#### 2.2 核心概念对比分析
- 2.2.1 不同市场信息效率下的策略差异  
  信息效率低的市场中，传统策略更易获利；信息效率高的市场中，机会窗口缩短。  
- 2.2.2 信息延迟与信息过载的影响  
  信息延迟可能导致错失机会，信息过载则可能引发决策疲劳。  
- 2.2.3 策略在低效与高效市场中的表现对比  
  在低效市场中，格雷厄姆策略表现优异；在高效市场中，需结合量化指标优化。

## 第三部分：算法原理讲解

### 第3章：格雷厄姆策略的算法实现

#### 3.1 算法流程
- 3.1.1 格雷厄姆策略的基本步骤  
  1. 筛选低估值股票：市盈率 < 15，市净率 < 1.5。  
  2. 计算内在价值：基于未来现金流折现。  
  3. 评估安全边际：内在价值与市场价格差额。  
- 3.1.2 内在价值计算算法  
  ```python
  def calculate_intrinsic_value(enterprise_value, free_cash_flow, discount_rate):
      present_value = 0
      for t in range(1, 10):
          cf = free_cash_flow * (1 + growth_rate)**t
          present_value += cf / (1 + discount_rate)**t
      return present_value
  ```
- 3.1.3 安全边际评估算法  
  ```python
  def calculate_margin_of_safety(intrinsic_value, market_price):
      return intrinsic_value - market_price
  ```

#### 3.3 Python代码实现
- 3.3.1 环境安装与配置  
  需要安装numpy和pandas库。  
- 3.3.2 核心算法实现代码  
  ```python
  import numpy as np
  import pandas as pd

  def calculate_intrinsic_value(fcf, discount_rate, growth_rate):
      pv = 0
      for year in range(1, 10):
          cash_flow = fcf * (1 + growth_rate) ** year
          pv += cash_flow / (1 + discount_rate) ** year
      return pv

  def calculate_margin_of_safety(iv, price):
      return iv - price

  data = {
      '公司': ['A', 'B', 'C'],
      'FCF': [100, 150, 200],
      'discount_rate': [0.1, 0.12, 0.08],
      'growth_rate': [0.05, 0.03, 0.07]
  }
  df = pd.DataFrame(data)

  ivs = []
  for i in range(len(df)):
      iv = calculate_intrinsic_value(df.loc[i, 'FCF'], df.loc[i, 'discount_rate'], df.loc[i, 'growth_rate'])
      ivs.append(iv)
  df['内在价值'] = ivs
  df['安全边际'] = df['内在价值'] - df['价格']  # 假设'价格'列已存在
  ```

## 第四部分：数学模型与公式

### 第4章：数学模型与公式解析

#### 4.1 内在价值公式
- 4.1.1 内在价值计算公式  
  $$ V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} $$
  其中，\( CF_t \) 是第t年的自由现金流，\( r \) 是折现率。  
- 4.1.2 相关变量的定义与计算  
  - 现金流折现模型：$$ DCF = \frac{CF_1}{1+r} + \frac{CF_2}{(1+r)^2} + \cdots + \frac{CF_n}{(1+r)^n} $$
  - 内在价值与市场价格比较：$$ MOI = V - P $$

#### 4.2 安全边际公式
- 4.2.1 安全边际计算公式  
  $$ MOI = V - P $$
  其中，\( V \) 是内在价值，\( P \) 是市场价格。  
- 4.2.2 安全边际与投资决策  
  当 \( MOI > 0 \) 时，股票被低估，值得买入。
