## 第1章 敏感性分析概述

### 1.1 敏感性分析的定义与背景

#### 1.1.1 什么是敏感性分析  
敏感性分析是一种用于评估模型中各输入变量对输出结果影响程度的方法。在企业估值中，这可以帮助识别哪些因素（如收入、成本、增长率等）对企业价值的影响最大。

#### 1.1.2 敏感性分析在企业估值中的作用  
- 量化关键变量的不确定性。
- 识别对估值结果影响最大的变量。
- 支持决策优化和风险管理。

#### 1.1.3 敏感性分析的边界与外延  
- 边界：聚焦于关键变量，忽略次要因素。
- 外延：结合其他分析方法（如情景分析）提升分析深度。

### 1.2 企业估值的基本概念

#### 1.2.1 企业估值的核心要素  
- 收入预测
- 成本结构
- 资本结构
- 增长率

#### 1.2.2 估值模型的分类与特点  
- 现金流量折现模型（DCF）
- 市盈率法
- 市净率法

#### 1.2.3 敏感性分析与估值模型的关系  
敏感性分析是企业估值模型的重要补充，用于评估模型的稳健性。

### 1.3 敏感性分析的原理与方法

#### 1.3.1 敏感性分析的基本原理  
通过改变输入变量的值，观察输出结果的变化，从而确定变量的重要性。

#### 1.3.2 常用的敏感性分析方法  
- 线性回归法
- 蒙特卡洛模拟
- 方差分解法

#### 1.3.3 敏感性分析的步骤与流程  
1. 确定目标变量（企业价值）。
2. 选择影响目标变量的输入变量。
3. 分析各变量对目标变量的影响程度。

### 2.3 敏感性分析的数学模型

#### 2.3.1 线性回归模型  
$$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \cdots + \beta_nx_n + \epsilon $$  
其中，$\beta_i$为变量$x_i$的敏感性系数。

#### 2.3.2 方差分析模型  
$$ F = \frac{SSR}{SSE} $$  
其中，SSR为回归平方和，SSE为残差平方和。

#### 2.3.3 蒙特卡洛模拟方法  
- 生成随机变量。
- 计算目标变量的分布。
- 统计变量对结果的影响。

### 5.3 案例分析：某制造企业估值

#### 5.3.1 数据准备  
- 收入预测：$100 million
- 成本预测：$60 million
- 税率：20%
- 折现率：8%

#### 5.3.2 计算净现值（NPV）

```python
def calculate_npv(revenue, cost, tax_rate, discount_rate, years):
    npv = 0
    for year in range(years):
        cash_flow = (revenue - cost) * (1 - tax_rate)
        npv += cash_flow / (1 + discount_rate) ** year
    return npv

# 示例计算
print("NPV:", calculate_npv(100, 60, 0.2, 0.08, 5))
```

#### 5.3.3 分析敏感性  

```python
import numpy as np

# 输入变量
revenue = 100
cost = 60
tax_rate = 0.2
discount_rate = 0.08

# 变化范围
changes = np.linspace(0.8, 1.2, 5)

# 计算敏感性
sensitivity = []
for change in changes:
    npv = calculate_npv(revenue * change, cost * change, tax_rate, discount_rate, 5)
    sensitivity.append(npv)

# 可视化
plt.plot(changes, sensitivity)
plt.xlabel('变化比例')
plt.ylabel('NPV')
plt.title('NPV对收入变化的敏感性')
plt.show()
```
