### 第1章: 利率的定义与分类

#### 1.1 利率的基本定义
- 利率是借贷资金的价格，表示单位时间内货币的时间价值。
- 利率由资金供需、通胀预期和货币政策共同决定。

#### 1.2 利率的分类
- 名义利率与实际利率
- 短期利率与长期利率
- 中央银行基准利率与市场利率

#### 1.3 利率与宏观经济的关系
- 利率是货币政策的核心工具
- 利率影响消费、投资和整体经济活动

### 第2章: 利率的影响因素

#### 2.3 市场供需
- 资金供需变化决定市场利率

## 第二部分: 利率环境对各类资产的影响机制

### 第3章: 股票市场

#### 3.1 利率对股票市场的影响路径
- 利率上升增加企业融资成本，降低企业盈利
- 利率下降降低企业融资成本，提升企业盈利

#### 3.2 利率上升对股票估值的影响
- 股票的相对吸引力下降
- 高分红股票的吸引力上升

#### 3.3 利率下降对股票市场的驱动作用
- 低利率环境推动股票价格上涨
- 股票的再估值效应

### 第4章: 债券市场

#### 4.1 利率与债券价格的反向关系
- 利率上升导致债券价格下降
- 利率下降导致债券价格上升

#### 4.2 债券市场的久期与凸性分析
- 久期衡量债券价格对利率变化的敏感度
- 凸性衡量久期在不同利率水平的变化

#### 4.3 债券收益率的计算公式
$$ y = \frac{C}{P} + \frac{F - P}{T} $$
其中，\( y \) 是债券收益率，\( C \) 是每年的利息，\( P \) 是债券价格，\( F \) 是面值，\( T \) 是剩余期限。

### 第5章: 房地产市场

#### 5.1 利率对房地产贷款成本的影响
- 利率上升增加购房贷款成本
- 利率下降降低购房贷款成本

#### 5.2 利率变化对房地产价格的传导机制
- 利率影响购房需求，进而影响房地产价格
- 利率影响建筑成本，间接影响房地产价格

#### 5.3 房地产市场的周期性与利率的关系
- 利率周期与房地产市场的周期性波动

## 第三部分: 利率周期与资产配置策略

### 第6章: 利率周期的定义与阶段划分

#### 6.1 利率周期的四个阶段

#### 7.1 资产配置的理论基础
- 马科维茨的有效投资组合理论
- 资产配置的目标是分散风险和优化收益

#### 7.2 不同资产类别在不同利率环境下的表现
- 股票、债券、房地产等资产在不同利率环境下的收益表现

#### 7.3 资产配置的动态调整策略

### 第8章: 基于利率周期的资产配置策略

#### 8.1 上升周期中的资产配置
- 降低债券配置比例，增加股票配置比例
- 选择高收益股票和周期性股票

#### 8.2 下降周期中的资产配置
- 增加债券配置比例，降低股票配置比例
- 选择防御性股票和高分红股票

#### 8.3 稳定周期中的资产配置
- 维持均衡的资产配置比例
- 适当增加现金类资产配置

#### 14.2 核心代码实现
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 示例代码：计算债券价格与利率的关系
def bond_price(face_value, coupon_rate, years, market_rate):
    return (face_value * coupon_rate * np.pv(market_rate, years, when='期末')) + face_value * (1 + coupon_rate * years) / (1 + market_rate) ** years

# 示例代码：计算股票的久期
def stock_duration(stock_price, interest_rate, delta_rate):
    return stock_price * delta_rate / (stock_price * (1 + interest_rate) - stock_price)

# 示例代码：绘制利率与资产价格的关系图
def plot_interest_impact():
    rates = np.arange(2, 12, 0.5)
    bond_prices = [bond_price(100, 0.05, 10, r) for r in rates]
    stock_prices = [100 * (1 + 0.05) ** (-i) for i in range(1, 11)]
    plt.figure(figsize=(10, 6))
    plt.plot(rates, bond_prices, label='Bond Prices')
    plt.plot(rates, stock_prices, label='Stock Prices')
    plt.xlabel('Interest Rate (%)')
    plt.ylabel('Price')
    plt.legend()
    plt.show()
```
