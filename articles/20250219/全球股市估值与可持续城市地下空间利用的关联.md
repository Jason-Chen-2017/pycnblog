### 1.1 问题背景与问题描述

#### 1.1.1 全球股市估值的现状与挑战
全球股市估值是反映经济健康状况的重要指标。随着全球经济一体化的深入，股市的波动性增加，投资者对风险管理和资产配置的需求日益增长。然而，传统估值方法面临数据复杂性和模型局限性的挑战。

#### 1.1.2 可持续城市地下空间利用的重要性
随着城市化进程的加快，城市土地资源日益紧张。地下空间的开发不仅是解决土地不足的重要途径，也是实现可持续城市发展的重要组成部分。地下空间的合理利用能够提升城市的承载力和生活质量，同时减少对环境的影响。

本研究旨在通过分析全球股市估值与可持续城市地下空间利用的关联性，探索如何通过经济模型优化城市地下空间的开发和管理，从而实现经济与环境的双重目标。

```python
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 数据加载与预处理
data = pd.read_csv('data.csv')
data_cleaned = data.dropna()

# 特征提取
features = data_cleaned[['GDP', '失业率', '地价']]
target = data_cleaned['股市估值']

# 模型训练
model = LinearRegression()
model.fit(features, target)

# 模型验证
predictions = model.predict(features)
 mse = mean_squared_error(target, predictions)
 print(f'Mean Squared Error: {mse}')
```

- 模型训练：使用线性回归模型进行训练。
