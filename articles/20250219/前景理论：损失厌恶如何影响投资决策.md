## 第一部分: 前景理论的背景与基础

### 第1章: 前景理论的基本概念

#### 1.1 什么是前景理论

##### 1.1.1 传统决策理论的局限性
传统决策理论（如期望效用理论）假设投资者是理性的，决策基于对概率和收益的期望值。然而，实际投资行为中，投资者往往表现出非理性行为，如对损失的过度厌恶。

##### 1.1.2 前景理论的核心思想
前景理论由Kahneman和Tversky提出，认为投资者在决策时更关注损失和收益的相对变化，而非绝对值。损失厌恶是其核心，即人们对损失的敏感程度高于收益。

##### 1.1.3 前景理论与损失厌恶的关系
损失厌恶是前景理论的关键，它导致投资者在决策时更倾向于避免损失，而非追求收益最大化。

#### 1.2 前景理论的历史发展

##### 1.2.1 前景理论的提出背景
20世纪70年代，Kahneman和Tversky通过实验证实了传统决策理论的不足，提出了前景理论。

##### 1.2.2 前景理论的主要贡献者
Kahneman和Tversky是主要贡献者，他们通过大量实验验证了前景理论的适用性。

##### 1.2.3 前景理论的演变与扩展
前景理论不断扩展，引入了时间因素、社会偏好等，形成了更完善的决策框架。

#### 1.3 前景理论的数学基础

##### 1.3.1 前景函数的定义与公式
前景函数描述了决策结果的效用，公式为：$$ V(x) = \frac{x^{k}}{k} $$，其中k是风险厌恶参数。

##### 1.3.2 决策权重函数的数学表达
决策权重函数描述了概率的非线性变换，公式为：$$ w(p) = p^{\alpha}(1-p)^{\beta} $$，其中α和β是参数。

##### 1.3.3 前景理论的核心公式推导
综合前景函数和决策权重函数，整体效用为：$$ U = \sum w(p_i) \cdot V(x_i) $$。

### 第2章: 损失厌恶与投资决策的关系

#### 2.1 损失厌恶的定义与特征

##### 2.1.1 什么是损失厌恶
损失厌恶指投资者对损失的敏感程度高于收益，导致他们在决策时更倾向于避免损失。

##### 2.1.2 损失厌恶的测量方法
通过实验和问卷调查，测量投资者在不同损失和收益情况下的选择偏好。

##### 2.1.3 损失厌恶与风险偏好的对比
损失厌恶与风险偏好不同，后者关注总体风险水平，而前者关注损失的具体情况。

#### 2.2 前景理论中的损失厌恶模型

##### 2.2.1 前景函数中的损失厌恶体现
前景函数在损失时更陡峭，表现出对损失的更敏感。

##### 2.2.2 决策权重函数中的损失厌恶特征
决策权重函数在小概率损失时权重更高，导致投资者更关注小概率损失。

##### 2.2.3 损失厌恶对投资决策的影响
损失厌恶导致投资者在决策时更保守，可能错过高收益机会。

#### 3.1 前景函数的原理

##### 3.1.1 前景函数的非线性特征

##### 3.2.2 决策权重函数的参数化模型

##### 3.2.3 决策权重函数的适用范围
适用于描述小概率事件的决策权重。

#### 3.3 前景理论的综合应用

##### 3.3.1 前景理论的决策框架
通过前景函数和决策权重函数，构建完整的决策框架。

##### 3.3.2 前景理论的优缺点分析
优点：符合实际决策行为；缺点：复杂性较高。

##### 3.3.3 前景理论的适用场景
适用于小概率事件和损失厌恶明显的决策场景。

在损失时，决策权重更高；在收益时，决策权重更低。

#### 5.2.2 不对称性对投资决策的影响
导致投资者在损失时更保守，收益时更激进。

```python
def prospect_value(x, k):

```

##### 9.2.2 决策权重函数实现
```python
def decision_weight(p, alpha, beta):
    return (p ** alpha) * ((1 - p) ** beta)
```

##### 9.2.3 资产定价模型
```python
def asset_pricing(returns, probabilities, alpha, beta):
    utility = 0
    for p, r in zip(probabilities, returns):
        utility += decision_weight(p, alpha, beta) * prospect_value(r, 1)
    return utility
```
