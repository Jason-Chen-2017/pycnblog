## 第2章: 全球股市估值的基本概念与现状

### 2.1 股市估值的定义与核心指标
#### 2.1.1 股市估值的定义
股市估值是指对上市公司股票价格的合理评估，通常通过市盈率（P/E）、市净率（P/B）等指标衡量。

#### 2.1.2 常用估值指标
- 市盈率（P/E）：股票价格与每股收益的比值。
- 市净率（P/B）：股票价格与每股净资产的比值。
- 市销率（P/S）：股票价格与每股营业收入的比值。

空气质量改善措施是指通过政府政策、技术创新等手段，减少空气污染物排放，提升空气质量的措施。

#### 2.2.2 常见空气质量改善措施
- 政府政策：如排放标准、环保补贴等。
- 技术升级：如清洁能源技术的应用、废气处理技术的改进。

### 6.2 系统核心实现源代码
#### 6.2.1 数据分析代码
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import statsmodels.api as sm

# 数据加载
df = pd.read_csv('stock_valuation.csv')
aqi_df = pd.read_csv('air_quality.csv')

# 数据合并与预处理
merged_df = pd.merge(df, aqi_df, on='date')

# 回归分析
X = merged_df[['AQI', 'GDP']]
X = sm.add_constant(X)
y = merged_df['市盈率']

model = sm.OLS(y, X).fit()
print(model.summary())
```

#### 6.2.2 模型预测代码
```python
# 模型预测
predicted_valuation = model.predict(X)
plt.plot(predicted_valuation, label='预测估值')

plt.xlabel('日期')
plt.ylabel('市盈率')
plt.legend()
plt.show()
```
