### 3.3 核心算法代码
```python
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import r2_score

# 示例数据
data = pd.DataFrame({
    '创新指标': [0.5, 0.6, 0.4, 0.7],
    '市盈率': [15, 20, 18, 22],
    '市净率': [2, 3, 2.5, 3.5]
})

# 模型训练
model = RandomForestRegressor()
model.fit(data[['创新指标', '市盈率']], data['市净率'])

# 预测与评估
predictions = model.predict([[0.5, 16]])
print(r2_score(data['市净率'], model.predict(data[['创新指标', '市盈率']])))

print("预测结果:", predictions)
```
