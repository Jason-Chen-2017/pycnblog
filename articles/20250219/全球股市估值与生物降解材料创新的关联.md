# 第二章: 全球股市估值基础

## 2.1 全球股市估值的基本概念

### 2.1.1 市盈率与市净率的定义
- 市盈率（P/E）= 股价 / 每股收益。
- 市净率（P/B）= 股价 / 每股净资产。

### 2.1.2 市值与流通市值的计算
- 市值 = 股价 × 总股本。
- 流通市值 = 股价 × 流通股本。

### 2.1.3 股东权益与每股收益的关系
- 股东权益 = 资产 - 负债。
- 每股收益 = 净利润 / 总股本。

## 2.2 影响股市估值的主要因素

### 2.2.1 宏观经济指标
- GDP增长率、通货膨胀率、利率水平等。

### 2.2.2 行业发展趋势
- 行业周期、政策支持、技术进步等。

### 2.2.3 公司基本面分析
- 收入、利润、资产负债情况、管理层能力等。

## 2.3 股市估值的分析方法

### 2.3.1 市盈率法
- 通过比较市盈率与行业平均水平，判断股票估值高低。

### 2.3.2 市净率法
- 适用于资产密集型行业，如银行、房地产。

### 2.3.3 股息率法
- 通过股息率与国债收益率比较，判断投资价值。

$$

# 第七章: 项目实战

## 7.1 环境安装

### 7.1.1 安装Python环境

### 7.1.2 数据获取
- 使用Yahoo Finance API获取股票数据。

## 7.2 核心实现

### 7.2.1 数据清洗与预处理
```python
import pandas as pd
import numpy as np

# 示例数据
df = pd.DataFrame({
    'PE': [15, 20, 25, 30],
    'Innovation': [5, 8, 12, 15],
    'GDP': [2.5, 3.0, 2.8, 3.2]
})

# 数据清洗
df.dropna()  # 假设数据中没有缺失值
df = df.astype(float)
```

### 7.2.2 模型实现
```python
import statsmodels.api as sm

# 构建多元回归模型
model = sm.OLS(df['PE'], df[['Innovation', 'GDP']], hasconst=True)
result = model.fit()

# 查看结果
print(result.summary())
```

### 7.2.3 结果分析
- 回归系数：Innovation的系数为0.8，p值小于0.05，显著正相关。
- R²值：0.85，说明模型解释力较高。
