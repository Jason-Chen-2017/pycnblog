- 价值投资的长期视角：关注企业的基本面而非市场波动

#### 2.2 格雷厄姆选股策略的系统化分析

#### 4.2 算法实现步骤
1. **数据预处理**：清洗和整合多源数据
2. **安全边际计算**：$$ 安全边际 = 股价 \div 内在价值 $$
3. **内在价值评估**：$$ 内在价值 = 股东权益 \div 普通股股数 $$
4. **客户筛选**：基于安全边际和内在价值的双指标筛选
5. **风险评估**：$$ 风险评分 = 安全边际 \times 内在价值 \times 信用评分 $$

#### 4.3 算法实现的Python代码
```python
import pandas as pd

def calculate_margin_of_safety(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

def calculate_intrinsic_value(equity, shares_outstanding):
    return equity / shares_outstanding

def screen_clients(customers, stock_data):
    selected_clients = []
    for client in customers:
        stock_price = stock_data[client['stock_ticker']]
        intrinsic_value = calculate_intrinsic_value(client['equity'], client['shares_outstanding'])
        margin_of_safety = calculate_margin_of_safety(stock_price, intrinsic_value)
        if margin_of_safety > 1.5:
            selected_clients.append(client)
    return selected_clients

# 示例数据
customers = [
    {'name': 'Client A', 'stock_ticker': 'AAPL', 'equity': 100000, 'shares_outstanding': 100000},
    {'name': 'Client B', 'stock_ticker': 'MSFT', 'equity': 80000, 'shares_outstanding': 80000}
]

stock_data = {
    'AAPL': 100,
    'MSFT': 80
}

selected_clients = screen_clients(customers, stock_data)
print(selected_clients)
```
