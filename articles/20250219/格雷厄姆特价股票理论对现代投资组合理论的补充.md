## 第1章: 格雷厄姆特价股票理论概述

### 1.1 格雷厄姆投资理论的核心概念

#### 1.1.1 价值投资的定义与核心理念
价值投资是一种投资策略，强调以低于内在价值的价格购买优质资产。核心理念是寻找市场低估的股票，通过安全边际降低风险。安全边际是格雷厄姆理论的核心，它通过比较市场价格与内在价值，确保以折扣价买入资产。

#### 1.1.2 安全边际的概念与计算方法
安全边际=内在价值 - 市场价格。例如，若内在价值为50元，市场价格为40元，安全边际为10元，意味着有20%的安全空间。计算时，需分析企业的盈利能力、资产状况和行业地位。

#### 1.1.3 格雷厄姆筛选法的基本步骤
格雷厄姆筛选法通过多 criteria筛选股票，包括：
1. 低市盈率（P/E < 15）
2. 低市净率（P/B < 1.5）
3. 高股息率（股息率 > 5%）
4. 强健的财务状况（如流动比率 > 2）

### 1.2 现代投资组合理论（MPT）概述

#### 1.2.1 MPT的核心概念与数学模型
MPT由哈里·马科维茨提出，强调分散投资以降低系统性风险。均值-方差模型通过优化投资组合的收益和风险，寻找最优风险调整收益。

均值-方差模型公式：
$$
\text{min}_w \sum_{i=1}^n w_i^2 \sigma_i^2 + 2 w_i w_j \sigma_{ij}$$
在约束条件：
$$\sum_{i=1}^n w_i = 1$$

#### 1.2.2 夏普比率的计算与应用
夏普比率衡量投资组合的风险调整收益，公式为：
$$
\text{夏普比率} = \frac{E(r_p) - r_f}{\sigma_p}$$

### 1.3 格雷厄姆理论与MPT的联系与区别

#### 1.3.1 核心差异对比
| **方面**       | **格雷厄姆理论**                     | **MPT**                           |
|----------------|------------------------------------|------------------------------------|
| **目标**         | 最大化安全边际和内在价值           | 最小化风险调整收益                 |
| **策略**         | 选择低估股票                       | 分散投资以降低风险                 |
| **工具**         | 格雷厄姆筛选法                     | 均值-方差模型                       |

#### 1.3.2 格雷厄姆理论对MPT的补充作用
1. **安全边际降低风险**：通过选择具有安全边际的股票，减少投资组合的整体风险。
2. **价值投资与分散投资结合**：在MPT框架下，利用价值投资策略选择股票，优化投资组合。
3. **特价股票的应用**：将格雷厄姆的筛选法应用于MPT的分散投资中，提高收益并降低风险。

## 第2章: 核心概念的对比分析

### 2.1 格雷厄姆理论与MPT的核心概念对比

#### 2.1.1 价值与价格的对比
价值是内在价值，价格是市场定价。价值投资关注价格低于价值的股票，而MPT关注价格波动和相关性。

#### 2.1.2 安全边际与风险调整收益的对比
安全边际是价值投资的风险管理工具，风险调整收益是MPT的核心目标。两者都关注风险，但方法不同。

#### 2.1.3 投资策略的对比
价值投资强调长期持有低估股票，MPT强调分散投资和动态调整。

### 2.2 核心概念的联系与整合

#### 2.2.1 格雷厄姆筛选法与MPT的结合
通过筛选低估股票，构建一个分散的投资组合，优化夏普比率。

#### 2.2.2 安全边际在投资组合优化中的应用
在MPT框架下，安全边际作为筛选条件，确保投资组合中的股票具有足够的安全空间。

# 定义优化目标函数
def portfolio_variance(weights, returns, cov_matrix):
    return (weights.T @ cov_matrix @ weights)[0,0]

# 约束条件
cons = ({'type': 'eq', 'fun': lambda w: sum(w) - 1},
        {'type': 'ineq', 'fun': lambda w: w >= 0})

# 优化
result = minimize(portfolio_variance, np.array([1/3, 1/3, 1/3]), 
                 constraints=cons, method='SLSQP')
