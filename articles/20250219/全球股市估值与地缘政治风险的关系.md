### 2.2 股市估值的关键指标

#### 2.2.1 市盈率（P/E）

计算公式：P/E = 市场价/每股收益。解释其在不同风险环境下的表现。

#### 2.2.2 市净率（P/B）

计算公式：P/B = 市场价/每股净资产。用于评估市场是否被高估或低估。

#### 2.2.3 股息率

计算公式：股息率 = 每股股息/股价。反映市场收益能力。

### 3.1 事件影响分析

#### 3.1.1 事件权重计算

根据事件的严重性和发生频率，赋予不同权重。例如，战争的权重高于贸易争端。

#### 3.1.2 事件影响指数

计算公式：影响指数 = Σ(权重 × 影响程度)。

### 6.2 核心实现代码

```python
import pandas as pd
import numpy as np

def calculate_risk_index(events):
    weights = {'经济制裁': 0.3, '贸易争端': 0.4, '战争': 0.3}
    risk_index = 0
    for event in events:
        weight = weights.get(event, 0)
        risk_index += weight * events[event]
    return risk_index

events = {'经济制裁': 0.6, '贸易争端': 0.8, '战争': 0.7}
risk_index = calculate_risk_index(events)
print(f"风险指数：{risk_index}")
```
