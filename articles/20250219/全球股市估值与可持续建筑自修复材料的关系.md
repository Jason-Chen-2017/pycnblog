## # 第2章: 核心概念的原理与属性对比

### 2.1 股市估值的核心原理

#### 2.1.1 市盈率与市净率的计算公式

市盈率（P/E）= 股价 / 每股收益  
市净率（P/B）= 股价 / 每股净资产

#### 2.1.2 股东权益与企业价值的评估方法

股东权益 = 资产 - 负债  
企业价值 = 股东权益 + 付息负债

#### 2.1.3 股市波动与宏观经济指标的关系

股市波动受 GDP、利率、通货膨胀等因素影响，需通过回归分析等方法进行建模。

### 2.2 自修复材料的特性分析

#### 2.2.1 材料的自愈合机理

自修复材料通过化学反应或物理修复机制，实现损伤后的自我修复。

#### 2.2.2 材料的耐久性与环保性

自修复材料的耐久性较长，减少维护需求，同时环保性高，降低对环境的影响。

#### 2.2.3 材料的成本与性能对比

材料成本较高，但性能优越，需在实际应用中权衡成本与效益。

### 3.3 数据驱动的关联性分析

#### 3.3.1 关联性分析的数学模型

$$\text{相关系数} = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \sum (y_i - \bar{y})^2}}$$

#### 3.3.2 关联性分析的步骤

1. 数据清洗与标准化  
2. 计算相关系数  
3. 可视化展示

### 3.4 时间序列分析的实现代码

```python
import pandas as pd
from statsmodels.tsa.arima_model import ARIMA
import matplotlib.pyplot as plt

# 加载数据
data = pd.read_csv('stock_data.csv')

# 时间序列分析
model = ARIMA(data['value'], order=(5,1,0))
model_fit = model.fit()

# 预测
forecast = model_fit.forecast(steps=5)

# 可视化
plt.plot(data['value'], label='实际值')
plt.plot(forecast[0], label='预测值')
plt.legend()
plt.show()
```

## # 第5章: 项目实战

### 5.1 环境安装

安装Python、Pandas、NumPy、Scikit-learn、TensorFlow、Plotly等库。

### 5.2 核心实现代码

```python
import pandas as pd
import numpy as np
from sklearn.metrics import mean_squared_error
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense

# 数据预处理
data = pd.read_csv('stock_data.csv')
data = data[['date', 'value']]
data = data.set_index('date')
data = data.resample('D').mean().ffill()

# 划分训练集和测试集
train = data.iloc[:-30]
test = data.iloc[-30:]

# 数据标准化
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
train_scaled = scaler.fit_transform(train)
test_scaled = scaler.transform(test)

# LSTM模型构建
model = Sequential()
model.add(LSTM(50, return_sequences=True, input_shape=(None, 1)))
model.add(LSTM(50, return_sequences=False))
model.add(Dense(1))
model.compile(loss='mean_squared_error', optimizer='adam')

# 训练模型
train_x = np.array(train_scaled).reshape((train.shape[0], 1, 1))
train_y = train_scaled[:, 0]
model.fit(train_x, train_y, epochs=50, batch_size=32)

# 预测
test_x = np.array(test_scaled).reshape((test.shape[0], 1, 1))
predictions = model.predict(test_x)
predictions = scaler.inverse_transform(predictions)

# 计算均方误差
mse = mean_squared_error(test['value'].values, predictions.flatten())
print(f'均方误差: {mse}')
```
