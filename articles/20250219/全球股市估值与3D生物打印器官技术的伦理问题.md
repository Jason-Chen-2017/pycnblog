# 第1章: 全球股市估值概述

## 1.1 股市估值的核心概念

### 1.1.1 股市估值的基本定义
股市估值是指对上市公司股票价值的评估，通常通过市盈率（P/E）、市净率（P/B）等指标来衡量。这些指标反映了市场的预期与实际表现之间的关系。

### 1.1.2 股市估值的主要指标与方法
- **市盈率（P/E）**：市盈率=股价/每股收益。反映市场对公司的盈利预期。
- **市净率（P/B）**：市净率=股价/每股净资产。适用于评估资产密集型行业。
- **市销率（P/S）**：市销率=股价/每股收入。适用于亏损公司或新兴行业。

### 1.1.3 股市估值的边界与外延
股市估值不仅关注企业的财务表现，还需考虑宏观经济环境、政策法规及市场情绪等外部因素。

## 1.2 3D生物打印技术的基本原理

### 1.2.1 3D生物打印技术的定义
3D生物打印是通过逐层添加生物材料（如细胞、胶原蛋白）构建三维结构的技术，用于制造组织或器官。

### 1.2.2 3D生物打印技术的核心要素
- **生物墨水**：由细胞、生长因子和支架材料组成。
- **打印精度**：决定打印结构的复杂性和功能性。
- **生物相容性**：材料需与人体组织兼容。

### 1.2.3 3D生物打印技术的伦理问题
- **伦理争议**：涉及生命伦理、隐私保护等问题。
- **技术公平性**：技术可能仅适用于富裕国家或人群。
