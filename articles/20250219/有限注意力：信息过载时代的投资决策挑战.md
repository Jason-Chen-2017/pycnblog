## 第一部分：有限注意力与信息过载的背景

### 第1章：有限注意力与信息过载概述

#### 1.1 有限注意力的定义与特征
- **注意力资源的有限性**：人类的注意力是有限的，每个人每天能有效处理的信息量是有限的，这被称为注意力资源的稀缺性。  
- **信息过载的现状与挑战**：现代社会中，信息来源呈现爆炸性增长，投资者每天需要处理的信息量远超其注意力容量，导致决策疲劳和效率下降。  
- **有限注意力对决策的影响**：注意力分配不当可能导致投资者忽略重要信息或过度关注无关信息，从而影响决策质量。

#### 1.2 投资决策中的信息过载问题
- **投资信息的爆炸性增长**：股票市场、基金、新闻、社交媒体等多方面信息不断涌现，投资者需要筛选大量信息以做出决策。  
- **信息过载对决策效率的负面影响**：信息过多导致决策时间延长，且容易因信息干扰而做出错误判断。  
- **投资者的时间与精力限制**：投资者通常需要在有限的时间内完成决策，信息过载进一步加剧了这一挑战。

#### 1.3 有限注意力与投资决策的关系
- **注意力分配的基本原理**：注意力是稀缺资源，投资者需要合理分配注意力以最大化决策收益。  
- **信息筛选与注意力分配的优化**：通过优化注意力分配策略，投资者可以更高效地筛选关键信息，提升决策质量。  
- **有限注意力对投资结果的影响**：注意力分配不当可能导致投资决策失误，而优化注意力分配则能提升投资收益。

### 第2章：注意力经济与信息处理理论

#### 2.1 注意力经济的核心概念
- **注意力经济的定义**：注意力经济是指通过争夺注意力资源来实现经济价值的理论。在投资领域，注意力经济体现在投资者如何分配注意力以获取最大投资收益。  
- **注意力经济与信息过载的关系**：信息过载加剧了注意力资源的稀缺性，而注意力经济则强调了注意力分配的重要性。  
- **注意力经济在投资领域的应用**：投资者需要通过合理分配注意力来筛选关键信息，优化投资决策。

#### 2.2 信息处理的过滤机制
- **过滤泡理论**：信息过滤泡是指个体因接触的信息受限而形成的观点局限。在投资决策中，过滤泡可能导致投资者忽略重要信息或过度依赖有限信息。  
- **信息筛选的优先级模型**：优先级模型是基于信息重要性对信息进行排序的理论，帮助投资者在有限注意力下优先处理关键信息。  
- **过滤机制对投资决策的影响**：有效的过滤机制可以提升投资决策效率，而无效的过滤机制可能导致决策失误。

#### 2.3 有限注意力与决策疲劳
- **决策疲劳的定义与表现**：决策疲劳是指因连续决策而导致决策质量下降的现象。在信息过载时代，投资者因信息过多而容易出现决策疲劳。  
- **信息过载对决策疲劳的影响**：信息过多导致投资者需要处理的信息量超出其注意力容量，加剧了决策疲劳。  
- **缓解决策疲劳的策略**：通过优化信息筛选和注意力分配，投资者可以有效缓解决策疲劳。

  import numpy as np

  def calculate_attention_weights(information_list):
      weights = []
      for info in information_list:
          # 假设信息的重要性由其相关指标决定
          weight = np.exp(-np.abs(info - np.mean(information_list)))

      return weights
