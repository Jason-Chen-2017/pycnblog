# 第五章: 项目实战

## 5.1 环境安装与数据准备

### 5.1.1 Python环境配置

安装Python 3.8及以上版本，确保环境支持数据分析库，如pandas、numpy、matplotlib和seaborn。

### 5.1.2 数据源获取与清洗

从可靠的数据源（如Yahoo Finance或Alpha Vantage）获取股票数据，清洗数据并转换为适合分析的格式。

### 5.1.3 数据清洗与预处理

```python
import pandas as pd
import numpy as np

# 示例数据
data = {
    '股票代码': ['AAPL', 'GOOGL', 'MSFT', 'AMZN'],
    '公司名称': ['Apple', 'Alphabet', 'Microsoft', 'Amazon'],
    '净利润': [100, 200, 150, 250],
    '股东权益': [500, 600, 400, 700],
    '流通股数': [10, 20, 15, 25]
}

df = pd.DataFrame(data)
df.head()
```

## 5.2 核心代码实现

### 5.2.1 计算ROE和EPS

```python
# 计算股东权益收益率(ROE)
df['ROE'] = df['净利润'] / df['股东权益']

# 计算每股收益(EPS)
df['EPS'] = df['净利润'] / df['流通股数']

# 输出结果
print(df[['股票代码', 'ROE', 'EPS']].head())
```

### 5.2.2 应用筛选标准

```python
# 筛选标准：ROE > 0.15，EPS > 前一年的平均EPS
mean_eps = df['EPS'].mean()
selected_stocks = df[(df['ROE'] > 0.15) & (df['EPS'] > mean_eps)]

print(selected_stocks['股票代码'])
```
