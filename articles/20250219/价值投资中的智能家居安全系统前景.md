### 3.1 数据加密算法

数据加密算法用于保护智能家居设备的数据传输安全，防止数据被篡改或窃取。常用的加密算法包括AES、RSA等。

#### 3.1.1 AES加密算法

AES（高级加密标准）是一种广泛使用的加密算法，支持128、192和256位密钥长度。其加密流程如下：

```mermaid
graph TD
    A[明文] --> B[密钥] --> C[加密] --> D[密文]
```

代码实现：

```python
import hashlib

def aes_encrypt(plaintext, key):
    # 使用AES加密算法
    key = key.encode('utf-8')
    plaintext = plaintext.encode('utf-8')
    cipher = hashlib.new('aes', key=key)
    ciphertext = cipher.encrypt(plaintext)
    return ciphertext

# 示例
plaintext = "Hello, World!"
key = "secretkey1234"
encrypted = aes_encrypt(plaintext, key)
print("Encrypted:", encrypted)
```
