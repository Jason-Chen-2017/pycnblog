## 第二部分：格雷厄姆特价股票策略的核心概念

### 2.1 格雷厄姆投资理论基础
#### 2.1.1 价值投资的起源与发展
- 格雷厄姆是价值投资的创始人，其核心理念是通过寻找市场价格低于内在价值的股票，实现长期收益。
- 格雷厄姆强调安全边际的重要性，即市场价格与内在价值之间的差距越大，投资的安全性越高。

#### 2.1.2 格雷厄姆策略的核心指标
- 市盈率（P/E）：市场价格与每股收益的比率。
- 市净率（P/B）：市场价格与每股净资产的比率。
- 股息率：股票的股息与市场价格的比率。

#### 2.1.3 特价股票的定义与特征
- 特价股票：市场价格低于内在价值的股票。
- 特征：低市盈率、低市净率、高股息率。

### 2.2 格雷厄姆策略的实施方法
#### 2.2.1 特价股票的筛选标准
- 市盈率低于行业平均水平。
- 市净率低于行业平均水平。
- 股息率高于行业平均水平。

#### 2.2.2 投资组合的构建
- 分散投资：避免过度集中于单一行业或股票。
- 定期调整：根据市场变化和公司基本面调整投资组合。

#### 2.2.3 风险控制
- 设置止损点：当股价跌破某一阈值时，立即卖出。
- 定期评估：定期重新评估股票的内在价值和市场价格。

## 第三部分：通胀的基本概念与类型

### 3.1 通胀的定义与衡量指标
#### 3.1.1 通胀的经济学定义
- 通胀：物价总水平在一段时间内持续上涨。
- 衡量指标：消费者价格指数（CPI）、生产者价格指数（PPI）。

#### 3.1.2 通胀的类型
- 需求拉动型通胀：总需求超过总供给导致的价格上涨。
- 成本推动型通胀：生产成本上升导致的价格上涨。
- 货币供应增加型通胀：货币供给增加导致的价格上涨。

### 3.2 不同类型的通胀环境
#### 3.2.1 低通胀环境
- 特征：物价温和上涨，市场预期稳定。
- 对股市的影响：企业盈利增长，股价温和上升。

#### 3.2.2 高通胀环境
- 特征：物价快速上涨，市场预期不稳定。
- 对股市的影响：企业盈利被通胀侵蚀，股价波动加剧。

#### 3.2.3 通缩环境
- 特征：物价普遍下降，市场预期悲观。
- 对股市的影响：企业盈利下降，股价普遍下跌。

```python
def greaham_strategy(stock_data, inflation_data):
    # 计算市盈率
    pe = stock_data['price'] / stock_data['eps']
    # 计算市净率
    pb = stock_data['price'] / stock_data['book_value']
    # 计算股息率
    dividend_yield = stock_data['dividend'] / stock_data['price']
    # 筛选条件
    condition = (pe < stock_data['industry_pe']) & (pb < stock_data['industry_pb']) & (dividend_yield > stock_data['industry_dividend_yield'])
    # 返回符合条件的股票
    return stock_data[condition]
```

import pandas as pd
import numpy as np
import statsmodels.api as sm

def main():
    # 读取数据

    # 数据预处理
    stock_data.dropna(inplace=True)
    inflation_data.dropna(inplace=True)
    
    # 计算市盈率
    pe = stock_data['price'] / stock_data['eps']
    # 计算市净率
    pb = stock_data['price'] / stock_data['book_value']
    # 计算股息率
    dividend_yield = stock_data['dividend'] / stock_data['price']
    
    # 筛选条件
    condition = (pe < stock_data['industry_pe']) & (pb < stock_data['industry_pb']) & (dividend_yield > stock_data['industry_dividend_yield'])
    greaham_stocks = stock_data[condition]
    
    # 实证分析
    greaham_returns = greaham_stocks['return'].mean()
    non_greaham_returns = stock_data[~condition]['return'].mean()
    
    # 回归分析
    model = sm.OLS(greaham_returns, inflation_data).fit()
    print(model.summary())
