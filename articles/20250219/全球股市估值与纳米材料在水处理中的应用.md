# 第1章: 全球股市估值的基础与现状

## 1.1 股市估值的基本概念

### 1.1.1 股市估值的定义与重要性
股市估值是通过分析企业的财务数据和市场环境，对其股票的合理价格进行评估的过程。它是投资者做出投资决策的重要依据。在传统金融学中，估值方法主要依赖市盈率（P/E）、市净率（P/B）等指标。

**公式：**
$$市盈率 = \frac{股票价格}{每股净利润}$$
$$市净率 = \frac{股票价格}{每股净资产}$$

### 1.1.2 股市估值的核心指标
以下是常见的估值指标对比：

| 指标       | 计算公式                          | 适用场景                     |
|------------|-----------------------------------|------------------------------|
| 市盈率（P/E） | 股价 / 每股净利润                | 成长型企业，关注盈利能力     |
| 市净率（P/B） | 股价 / 每股净资产                | 价值型企业，关注资产质量     |
| 市销率（P/S） | 股价 / 每股收入                  | 周期型企业，关注收入能力     |
| 股息率      | 每股股息 / 股价                  | 稳定收益型企业               |

### 1.1.3 股市估值与经济周期的关系
股市估值受经济周期影响显著。例如，在经济衰退期，低市盈率企业可能更具吸引力，而在经济扩张期，高市盈率企业可能被市场热捧。
