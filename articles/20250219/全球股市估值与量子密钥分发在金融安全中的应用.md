# 第1章：全球股市估值概述

## 1.1 股市估值的基本概念

股市估值是通过对公司财务数据的分析，评估其股票的内在价值。这一过程帮助投资者判断股票是否被高估或低估。常见的估值指标包括市盈率（P/E）和市净率（P/B）等。

- **市盈率（P/E）**：公式为 `P/E = 股价 / 每股净利润`。例如，若某股票价格为 $50，每股净利润为 $5，则 P/E = 10。

- **市净率（P/B）**：公式为 `P/B = 股价 / 每股净资产`。例如，若某股票价格为 $40，每股净资产为 $10，则 P/B = 4。

## 1.2 股市估值的核心指标

除了市盈率和市净率，投资者还常用股息率（Dividend Yield）来评估股票的吸引力。公式为 `股息率 = 每股股息 / 股票价格`。例如，若某股票每股股息为 $2，股价为 $40，则股息率为5%。

## 1.3 股市估值的主要模型

现金流折现模型（DCF）是常用的估值方法之一。其基本原理是将未来现金流折现到现值，计算公司的真实价值。公式为：

$$
DCF = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}
$$

其中，$CF_t$ 是第 $t$ 年的现金流，$r$ 是折现率，$TV$ 是终值。

# 第2章：量子密钥分发（QKD）原理与应用

## 2.1 量子密钥分发的基本原理

量子密钥分发利用量子态的不可克隆性和测量扰动性，确保密钥的安全传输。BB84协议是最早提出的量子密钥分发协议，其流程如下：

1. **密钥生成**：Alice 和 Bob 分别生成随机的量子密钥，并选择不同的编码基。
2. **量子传输**：Alice 将量子态传输给 Bob。
3. **基比对**：双方公开使用的基，保留相同的基的测量结果作为密钥。
4. **纠错与隐私放大**：通过公开通信纠错，并使用信息理论方法进一步增强密钥安全性。

## 2.2 量子密钥分发在金融安全中的应用

### 2.2.1 金融数据的加密传输

量子密钥分发可以用于保护金融数据的传输安全。例如，在股票交易中，敏感数据如交易指令和股价数据可以通过量子密钥加密后传输，确保数据的机密性和完整性。

### 2.2.2 金融交易的安全保护

量子密钥分发技术可以防止金融交易中的数据篡改和窃听。通过在交易过程中使用量子密钥加密，确保交易数据的不可抵赖性和真实性。

以下是一个简单的量子密钥分发模拟代码：

import random

def generate_key():
    key = []
    for _ in range(10):
        bit = random.choice([0, 1])
        key.append(bit)
    return key

def compare_bases(alice_basis, bob_basis):
    common_basis = [i for i in range(len(alice_basis)) if alice_basis[i] == bob_basis[i]]
    return common_basis

# 示例
alice_basis = [random.choice(['+','x']) for _ in range(10)]
bob_basis = [random.choice(['+','x']) for _ in range(10)]
