## 第一部分：了解手工芝士制作

### 第1章：手工芝士概述

#### 1.1 芝士的起源与发展

芝士，又称奶酪，是一种源于古老食品工艺的乳制品。其起源可以追溯到公元前5000年的中东地区，当时人类开始利用动物乳汁保存食物。随着时间推移，芝士的加工技术逐渐成熟，并在世界各地形成了独特的制作方法和风味。

在中国，芝士的制作历史悠久，最早的记载可以追溯到西汉时期。《神农本草经》中就有关于“乳腐”的描述，这可以看作是中国芝士的雏形。然而，现代意义上的手工芝士制作主要是在20世纪后期传入中国，随着饮食文化的多元化，芝士逐渐成为都市生活中的时尚食品。

#### 1.2 手工芝士与工业化芝士的区别

手工芝士与工业化芝士在生产方式、风味和营养价值上有着显著区别。手工芝士通常由经验丰富的奶酪匠人手工制作，注重天然发酵和传统工艺，因此每一块手工芝士都有独特的风味和口感。而工业化芝士则采用大规模生产流程，以机械化生产为主，追求产量和标准化。

首先，在材料选择上，手工芝士更注重天然和新鲜，使用未经巴氏消毒的牛奶，而工业化芝士则可能使用巴氏消毒牛奶，并添加防腐剂和稳定剂。

其次，在生产工艺上，手工芝士需要经过多道复杂的工序，包括凝乳、切割、发酵、成熟等，这些步骤都需要匠人的细心操作和长时间等待。工业化芝士则通过标准化生产线完成，从凝乳到包装，各个环节都在严格控制的条件下进行。

最后，在风味和营养价值上，手工芝士因其天然发酵和长时间的成熟过程，风味更加浓郁，营养价值也更高。而工业化芝士则在口感和风味上较为单调，营养价值相对较低。

#### 1.3 手工芝士在餐饮行业的重要性

手工芝士在餐饮行业中具有极高的重要性，其不仅丰富了餐饮产品的种类，也提升了餐饮体验的层次。首先，手工芝士作为食材，可以应用于多种菜肴的制作，如芝士汉堡、披萨、意大利面等，这些菜肴在全球范围内广受欢迎。

其次，手工芝士的独特风味和质感为餐饮提供了新的可能。其浓郁的风味可以为菜肴增添层次感，而其丝滑的质感则带来独特的口感体验。这不仅满足了食客的味蕾需求，也提升了餐饮的附加值。

此外，随着健康饮食理念的普及，手工芝士因其天然、无添加的特点，越来越受到消费者的青睐。手工芝士不仅提供了优质的蛋白质和钙质，还富含益生菌，有助于肠道健康。

总的来说，手工芝士在餐饮行业中的重要性不言而喻。其不仅丰富了餐饮产品的种类，提升了餐饮体验，还满足了消费者对健康饮食的需求。随着手工芝士制作的普及和消费者认知的提升，其在未来的餐饮市场中的地位将愈发重要。

### 第2章：手工芝士制作基础

#### 2.1 芝士制作的基本材料

手工芝士的制作离不开以下基本材料：

1. **牛奶**：牛奶是芝士制作的核心原料，其质量直接影响芝士的风味和品质。一般来说，手工芝士制作采用未经巴氏消毒的新鲜牛奶，以保证其天然和纯净。

2. **凝乳酶**：凝乳酶是一种酶制剂，用于将牛奶中的蛋白质凝固成凝乳。手工芝士制作中常用的凝乳酶有动物性凝乳酶和微生物凝乳酶，前者来自动物胃液，后者来自特定微生物发酵。

3. **盐**：盐用于调节芝士的口味和质地，同时有助于抑制细菌的生长。不同种类的芝士对盐的用量和种类有不同的要求，通常使用海盐或岩盐。

4. **发酵剂**：发酵剂用于促进牛奶的发酵过程，使其中的乳糖转化为乳酸，从而增加芝士的风味和质地。常用的发酵剂包括乳酸菌和酵母。

5. **添加剂**：根据不同的芝士种类，可能需要添加一些特定的添加剂，如乳清、奶油、凝乳酶等，以改善芝士的口感和质地。

#### 2.2 芝士制作的工具与设备

手工芝士的制作需要一系列专业工具和设备，以下是一些常用的工具和设备：

1. **奶酪模具**：奶酪模具用于成型和压榨芝士。根据芝士的形状和硬度，选择不同的模具，如圆形、方形、柱形等。

2. **割刀**：割刀用于在牛奶中切割凝乳，使其更容易排出水分。割刀的刀片需要锋利，以便轻松切割。

3. **压榨器**：压榨器用于在芝士成型后排除多余水分，增加芝士的硬度和质感。压榨器通常由金属框架和布袋组成。

4. **发酵箱**：发酵箱用于控制芝士发酵的温度和湿度，使其在适宜的环境下成熟。发酵箱可以是专业的设备，也可以是家庭烤箱或冰箱改造。

5. **冰箱**：冰箱用于储存芝士，使其在成熟过程中保持稳定的环境。成熟时间越长，芝士的风味和质地越丰富。

#### 2.3 芝士发酵的原理

芝士发酵是一个复杂的生物化学过程，主要包括以下几个步骤：

1. **凝乳**：在加入凝乳酶后，牛奶中的蛋白质开始凝固，形成凝乳。这一过程需要适宜的温度和pH值。

2. **切割和搅拌**：在凝乳形成后，使用割刀将其切割成小块，并进行搅拌。这一步骤有助于排出水分，使芝士结构更加紧密。

3. **排乳清**：在切割和搅拌过程中，乳清会从凝乳中排出。乳清含有大量的水分和乳糖，需要通过压榨器排出，以减少芝士的水分含量。

4. **盐渍**：在排乳清后，将盐均匀地撒在凝乳上，进行盐渍。盐不仅能够调味，还能抑制细菌的生长，保持芝士的新鲜度。

5. **发酵**：将盐渍后的芝士放入发酵箱中，进行发酵。发酵过程中，乳酸菌和酵母等微生物会将乳糖转化为乳酸和酒精，这些代谢产物不仅赋予芝士独特的风味，还能改善其质地。

6. **成熟**：发酵后的芝士需要放置在冰箱中成熟，成熟时间根据芝士的种类和硬度而定，通常需要几个月甚至几年。在成熟过程中，芝士的口感和风味会不断变化，逐渐达到最佳状态。

通过这些步骤，手工芝士得以从新鲜的牛奶中发酵、成熟，最终成为一块美味的奶酪。这一过程不仅需要专业的技术和设备，更需要耐心和经验，以确保芝士的质量和风味。

### 第3章：奶酪基础知识

#### 3.1 奶酪的分类

奶酪，作为一种历史悠久且多样化的乳制品，根据不同的分类标准，可以划分为多个种类。以下是一些常见的奶酪分类方法和代表品种：

1. **按质地分类**：

   - **软质奶酪**：软质奶酪质地柔软，通常不需要成熟或只需短时间成熟。代表品种有卡蒙贝尔（Camembert）和布里（Brie）。
   - **中等硬度奶酪**：这类奶酪的质地介于软质和硬质之间，既不软也不硬，适合直接食用或作为烹饪材料。代表品种有切达（Cheddar）和莫扎瑞拉（Mozzarella）。
   - **硬质奶酪**：硬质奶酪质地坚硬，通常需要长时间成熟，风味浓郁。代表品种有帕尔马干酪（Parmesan）和埃曼塔尔（Emmental）。

2. **按制作工艺分类**：

   - **天然发酵奶酪**：这种奶酪使用天然的乳酸菌进行发酵，不添加任何人工添加剂，如达洛米塔（Dolomiti）和切达（Cheddar）。
   - **添加发酵剂奶酪**：这类奶酪在发酵过程中添加了特定的发酵剂，如酵母或凝乳酶，以改善风味和质地，如卡门贝尔（Camembert）和布里（Brie）。

3. **按风味分类**：

   - **清淡奶酪**：这类奶酪口感柔和，适合直接食用或搭配水果和糕点。代表品种有摩泽尔（Mozzarella）和羊奶酪（Feta）。
   - **浓郁奶酪**：这类奶酪风味浓郁，适合烹饪或作为奶酪火锅的原料。代表品种有帕尔马干酪（Parmesan）和蓝纹奶酪（Blue Cheese）。

4. **按形状和包装分类**：

   - **块状奶酪**：常见的块状奶酪有切达（Cheddar）和帕尔马干酪（Parmesan）。
   - **球状奶酪**：如卡门贝尔（Camembert）和布里（Brie）。
   - **片状奶酪**：常用于比萨和汉堡的薄片奶酪，如莫扎瑞拉（Mozzarella）。

每种奶酪都有其独特的风味和制作工艺，不同类别的奶酪在口感和用途上也有所区别。了解这些分类，有助于我们更好地选择和享用各种美味的奶酪。

#### 3.2 奶酪的口感与风味

奶酪的口感和风味是其区别于其他乳制品的显著特点，这种独特的品质主要来源于其制作工艺和成熟过程。以下是对几种常见奶酪口感和风味的描述：

1. **卡蒙贝尔（Camembert）**：
   - **口感**：卡蒙贝尔奶酪质地柔软，内部呈奶油状，外表覆盖着一层白色霉斑。切开后，奶酪内部会散发出淡淡的香气，入口即化，丝滑细腻。
   - **风味**：卡蒙贝尔的口感柔和，带有微妙的酸味和奶油味，霉斑带来的微苦味为整体风味增添复杂性。

2. **布里（Brie）**：
   - **口感**：布里奶酪质地柔软，内部也呈奶油状，但比卡蒙贝尔略硬一些。外表通常覆盖着一层白色的霉斑，切开后有明显的香气散发。
   - **风味**：布里奶酪的风味比卡蒙贝尔更加浓郁，有轻微的酸味和果香，霉斑的微苦味与甜味交织，使其风味丰富。

3. **切达（Cheddar）**：
   - **口感**：切达奶酪质地坚硬，切开后内部呈现出黄色或橙色，口感较为紧实，咬下去有明显的嚼劲。
   - **风味**：切达奶酪的风味浓郁，带有强烈的乳香味和微妙的酸味，随着成熟时间的增加，风味会变得更加丰富和复杂。

4. **帕尔马干酪（Parmesan）**：
   - **口感**：帕尔马干酪质地坚硬，呈金黄色，研磨后散发出浓郁的香味，口感细腻而略带咸味。
   - **风味**：帕尔马干酪的风味浓郁，具有强烈的奶酪味和微妙的酸味，适合用于烹饪，如意大利面和披萨。

5. **莫扎瑞拉（Mozzarella）**：
   - **口感**：莫扎瑞拉奶酪质地柔软，入口即化，有一种丝滑的口感，常用于比萨和意大利面。
   - **风味**：莫扎瑞拉奶酪风味较为清淡，带有轻微的酸味和奶香味，适合直接食用或作为烹饪材料。

6. **蓝纹奶酪（Blue Cheese）**：
   - **口感**：蓝纹奶酪质地坚硬，内部布满蓝色或绿色的霉斑，切开后会有明显的霉味和香气，口感较为紧实，咬下去有明显的嚼劲。
   - **风味**：蓝纹奶酪的风味独特，带有强烈的霉味和酸味，风味浓郁，适合搭配水果或红葡萄酒。

每种奶酪的口感和风味都各具特色，不同种类的奶酪在制作过程中经过不同的发酵、成熟和处理，形成了独特的口感和风味。了解这些特点，有助于我们更好地选择和享用各种美味的奶酪。

#### 3.3 奶酪的储存与保鲜

奶酪的储存与保鲜是确保其品质和风味的关键。以下是一些关于奶酪储存和保鲜的基本原则和方法：

1. **温度控制**：大多数奶酪的最佳储存温度在4℃到8℃之间。硬质奶酪可以储存在冰箱的冷藏室，而软质奶酪则更适合储存在冰箱的冷冻室，以保持其质地和风味。

2. **湿度控制**：奶酪在储存过程中需要一定的湿度，以防止干燥或过度潮湿。可以放置在带有湿度调节功能的冰箱中，或者使用保鲜膜包裹后放入冰箱。

3. **包装方式**：适当的包装可以延长奶酪的保鲜期。硬质奶酪可以采用真空包装或密封塑料袋保存，而软质奶酪则更适合用带有小孔的保鲜膜包裹，以保持其湿润度。

4. **避免交叉污染**：奶酪在储存时应与其他食物分开，以避免异味污染。建议将奶酪放在专门的冷藏盒或分隔架上。

5. **定期检查**：定期检查奶酪的状态，一旦发现变质或发霉的迹象，应立即丢弃，以免影响其他储存的奶酪。

6. **避免直接冷冻**：虽然软质奶酪可以放入冷冻室，但硬质奶酪不建议直接冷冻，因为冷冻会破坏其质地和风味。

7. **成熟时间**：某些奶酪需要一定的时间才能达到最佳风味，储存时可以根据成熟时间来安排食用计划。

通过遵循上述原则和方法，我们可以更好地保持奶酪的新鲜度和品质，享受其独特的风味。

### 第4章：经典手工芝士制作

#### 4.1 蓝纹芝士

蓝纹芝士因其内部布满蓝色或绿色的霉斑而得名，这种霉菌赋予了蓝纹芝士独特的风味和口感。以下是蓝纹芝士的制作流程、核心工艺以及成熟时间与风味变化。

##### 4.1.1 蓝纹芝士的制作流程

1. **原料准备**：蓝纹芝士的主要原料包括新鲜牛奶、凝乳酶、盐和蓝霉菌种。新鲜牛奶需要保证质量，以确保芝士的口感和营养价值。

2. **凝乳**：将新鲜牛奶加热至摄氏43度左右，然后加入凝乳酶，搅拌至牛奶开始凝固成小块。

3. **切割和搅拌**：将凝固的牛奶切割成小块，进行搅拌，以排出多余水分。这一过程需要严格控制温度，保持在摄氏43度左右。

4. **盐渍**：将搅拌后的芝士块放入盐水中浸泡，以增加风味和防止细菌生长。浸泡时间根据芝士的硬度而定，通常需要几个小时到一天。

5. **接种蓝霉菌**：在盐渍后的芝士表面接种蓝霉菌种。接种后，将芝士放入发酵箱中，保持温度在摄氏15度到18度，湿度在90%以上。

6. **发酵与成熟**：蓝霉菌会在适宜的温度和湿度下生长，形成蓝色或绿色的霉斑。发酵时间通常需要几个月，甚至几年，以使蓝纹芝士的风味和质地达到最佳状态。

7. **包装与储存**：发酵成熟后的蓝纹芝士需要进行包装，以保持其新鲜度和风味。通常采用真空包装或密封塑料袋，储存在冰箱中。

##### 4.1.2 蓝纹芝士的核心工艺

1. **凝乳与切割**：凝乳和切割是蓝纹芝士制作的关键步骤，决定了芝士的质地和水分含量。正确的温度控制和切割技术是保证芝士品质的基础。

2. **盐渍**：盐渍不仅能调味，还能抑制细菌的生长，保持芝士的新鲜度。盐渍的时间和方法直接影响芝士的风味和质地。

3. **接种蓝霉菌**：蓝霉菌的接种和发酵是蓝纹芝士独特风味的关键。接种的时机、温度和湿度对蓝霉菌的生长和霉斑的形成至关重要。

4. **成熟时间**：蓝纹芝士的成熟时间较长，通常需要几个月到几年。在这期间，蓝霉菌会不断代谢，赋予芝士复杂的风味和丰富的层次感。

##### 4.1.3 蓝纹芝士的成熟时间与风味变化

蓝纹芝士的成熟时间对其风味变化至关重要。以下是蓝纹芝士在不同成熟阶段的风味变化：

1. **初级成熟（1-3个月）**：在这个阶段，蓝霉菌开始生长，芝士表面出现蓝色或绿色霉斑。此时，芝士的风味较为清新，带有轻微的霉味和酸味。

2. **中级成熟（3-6个月）**：随着成熟时间的增加，蓝霉菌的代谢活动增强，芝士的风味变得更加浓郁。此时，蓝纹芝士的霉味和酸味更加明显，口感略微紧实。
