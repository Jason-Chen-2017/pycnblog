### **极简电子音乐的核心算法原理**

极简电子音乐是一种追求简约、纯净声音的音乐流派，其核心在于对声音的精炼和处理。以下是极简电子音乐的核心算法原理，包括基本的音频处理技术和音频合成方法。

**1. 音频信号处理技术**

**1.1 声波的基本概念**

- **声波传播：** 声波是通过介质（如空气、水等）传播的振动波。声波由频率、振幅和相位三个基本参数描述。
- **声波频率：** 频率表示声波每秒振动的次数，单位为赫兹（Hz）。人耳能听到的频率范围大约在20 Hz到20 kHz之间。
- **声波振幅：** 振幅表示声波的最大位移，决定了声音的响度。
- **声波相位：** 相位表示声波在时间轴上的位置，决定了声音的稳定性。

**1.2 数字音频信号处理**

- **采样与量化：** 数字音频是将模拟信号（如声波）转换为数字信号的过程。采样是指以固定的时间间隔记录声波振幅，量化是指将连续的振幅值转换为离散的数字值。
- **信号滤波：** 滤波是音频处理中常用的技术，用于去除不需要的频率成分。常见的滤波器有低通滤波器、高通滤波器、带通滤波器和带阻滤波器。
- **动态处理：** 动态处理用于调整音频信号的响度和音量。压缩器可以限制音频信号的动态范围，而扩音器可以增加音量。

**2. 音频合成方法**

**2.1 波表合成**

- **波表（Wave Table）：** 波表是一种存储了声音样本的数据表。每个样本代表一个特定的音符或声音。
- **波表合成器：** 波表合成器通过查找波表中的样本，并使用交叉 fading 技术来合成声音。它适用于合成简单的电子乐器声音。

**2.2 物理建模合成**

- **物理建模：** 物理建模是一种基于声学原理的音频合成方法，通过模拟乐器或声音的物理特性来生成声音。
- **声源模型：** 声源模型包括弦振动模型、空气柱振动模型等，用于模拟乐器或声音的振动特性。
- **共振器模型：** 共振器模型用于模拟乐器中的共鸣体，如吉他箱体或木管乐器中的共鸣管。
- **合成过程：** 通过控制声源模型和共振器模型的各种参数，可以生成各种不同类型的音乐声音。

**3. 极简电子音乐的创作方法**

### **极简电子音乐的数学模型与公式**

极简电子音乐的制作离不开数学模型和公式，这些模型和公式帮助音乐制作者理解声音的本质和如何创造不同的音效。以下是极简电子音乐中常用的数学模型与公式，包括基本的声音参数、振动模型以及合成公式。

**1. 声音参数**

- **频率（Frequency, f）：** 频率是每秒振动的次数，单位是赫兹（Hz）。它是声音的核心特性，决定了声音的音高。
  
  $$ f = \frac{1}{T} $$

  其中，T 是周期，即完成一次完整振动所需的时间。

- **振幅（Amplitude, A）：** 振幅是声波的最大位移，决定了声音的响度。通常用分贝（dB）来衡量。

  $$ \text{Sound Pressure Level (SPL)} = 20 \times \log_{10}\left(\frac{P}{P_0}\right) $$
  
  其中，P 是声压，P0 是参考声压，通常取值为 20 μPa。

- **相位（Phase）：** 相位描述了声波在时间轴上的位置，通常用角度（°）或弧度（rad）表示。

  $$ \phi = 2\pi ft + \phi_0 $$
  
  其中，ft 是时间，φ0 是初始相位。

**2. 振动模型**

- **弦振动模型（String Vibration Model）：** 弦振动模型描述了弦乐器（如吉他、小提琴）的振动特性。

  $$ y(x,t) = A \sin(kx - \omega t + \phi) $$
  
  其中，y 是弦的位移，A 是振幅，k 是波数，ω 是角频率，φ 是相位。

- **空气柱振动模型（Air Column Vibration Model）：** 空气柱振动模型描述了管乐器（如长笛、萨克斯）的振动特性。

  $$ y(x,t) = A \sin\left(\frac{\pi x}{L} - \omega t + \phi\right) $$
  
  其中，y 是空气柱的位移，A 是振幅，L 是空气柱的长度，ω 是角频率，φ 是相位。

**3. 合成公式**

- **波表合成公式（Wavetable Synthesis Formula）：** 波表合成是一种通过查找预定义的声波样本（波表）来生成声音的方法。

  $$ x(n) = \sum_{i=1}^{N} A_i \sin(2\pi f_i n + \phi_i) $$
  
  其中，x(n) 是合成声音的样本，Ai 是第 i 个声波样本的振幅，fi 是第 i 个声波样本的频率，φi 是第 i 个声波样本的相位，N 是声波样本的数量。

- **物理建模合成公式（Physical Modeling Synthesis Formula）：** 物理建模合成是一种通过模拟乐器或声音的物理特性来生成声音的方法。

  $$ x(n) = \sum_{i=1}^{N} A_i \cos(2\pi f_i n + \phi_i) $$
  
  其中，x(n) 是合成声音的样本，Ai 是第 i 个声波样本的振幅，fi 是第 i 个声波样本的频率，φi 是第 i 个声波样本的相位，N 是声波样本的数量。

**举例说明：**

假设我们要合成一个简单的三声音调，每个音调的频率分别为 440 Hz、550 Hz 和 660 Hz，振幅均为 0.5，相位均为 0。

- **波表合成示例：**

  $$ x(n) = 0.5 \sin(2\pi \times 440 \times n) + 0.5 \sin(2\pi \times 550 \times n) + 0.5 \sin(2\pi \times 660 \times n) $$
  
- **物理建模合成示例：**

  $$ x(n) = 0.5 \cos(2\pi \times 440 \times n) + 0.5 \cos(2\pi \times 550 \times n) + 0.5 \cos(2\pi \times 660 \times n) $$

通过这些数学模型和公式，音乐制作者可以精确地控制声音的参数，创造出独特的音效和音乐作品。这些理论和实践的结合，为极简电子音乐的发展提供了坚实的基础。

2. **音频信号处理**

```python
from scipy.signal import butter, filtfilt
from numpy.fft import fft, ifft

# 低通滤波
def lowpass_filter(x, cutoff_frequency, sample_rate):
    nyq = 0.5 * sample_rate
    normal_cutoff = cutoff_frequency / nyq
    b, a = butter(5, normal_cutoff, btype='low')
    filtered_x = filtfilt(b, a, x)
    return filtered_x

# 压缩
def compress(x, ratio):
    max_val = np.max(x)
    min_val = np.min(x)
    range_val = max_val - min_val
    compressed_x = x.copy()
    for i in range(len(x)):
        compressed_x[i] = (x[i] - min_val) / range_val * (max_val - min_val) / ratio + min_val
    return compressed_x

# 扩展
def expand(x, ratio):
    max_val = np.max(x)
    min_val = np.min(x)
    range_val = max_val - min_val
    expanded_x = x.copy()
    for i in range(len(x)):
        expanded_x[i] = (x[i] - min_val) / range_val * (max_val - min_val) / ratio + min_val
    return expanded_x

# 应用滤波
filtered_x = lowpass_filter(x, 22050, sample_rate)

# 应用压缩
compressed_x = compress(filtered_x, 2)

# 应用扩展
expanded_x = expand(compressed_x, 2)

# 绘制处理后的信号
fig, axes = plt.subplots(3, 1, sharex=True)
axes[0].plot(n / sample_rate, x)
axes[0].set_title('Original Signal')
axes[1].plot(n / sample_rate, filtered_x)
axes[1].set_title('Filtered Signal')
axes[2].plot(n / sample_rate, expanded_x)
axes[2].set_title('Expanded Signal')
plt.tight_layout()
plt.show()
```
