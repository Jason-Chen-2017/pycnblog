### 5.2 系统核心实现源代码

以下是一个简单的星系演化模拟的Python源代码示例：

```python
import numpy as np
import matplotlib.pyplot as plt

# 初始化星系模型
N = 100
x = np.linspace(0, 1, N)
v = np.zeros(N)

# 引力计算
def calculate_gravity(x):
    G = 6.674 * 10**-11  # 万有引力常数
    M = 5.972 * 10**24  # 地球质量
    r = np.abs(x[1:] - x[:-1])
    F = -G * M * np.diff(v) / r**2
    return F

# 演化模拟
dt = 0.01
t_max = 10
t_steps = int(t_max / dt)

for i in range(t_steps):
    F = calculate_gravity(x)
    v += F * dt
    x += v * dt

# 输出结果
plt.plot(x, v)
plt.xlabel('Position')
plt.ylabel('Velocity')
plt.show()
```
