#### 4.3 Python源代码与详细讲解

```python
# 导入所需库
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def objective(x):
    return (x[0] - 3)**2 + (x[1] - 2)**2

# 定义约束条件
constraints = ({'type': 'ineq', 'fun': lambda x: x[0] + x[1] - 5})

# 初始化参数
x0 = np.array([0, 0])

# 选择优化算法
result = minimize(objective, x0, method='SLSQP', constraints=constraints)

# 输出优化结果
print("最优解：", result.x)
```

### 5. 数学优化公式与举例说明

#### 5.1 公式讲解

数学优化问题通常可以用以下数学模型来描述：

$$
\min_{x} f(x)
$$

其中，$f(x)$ 是目标函数，$x$ 是变量。为了求解最优解，我们需要对目标函数进行求导，找到导数为零的点，即可能的最优解。

#### 5.2 举例说明

假设我们有一个线性目标函数：

$$
\min_{x} (x - 3)^2 + (x - 2)^2
$$

我们可以对其进行求导：

$$
\frac{d}{dx} [(x - 3)^2 + (x - 2)^2] = 2(x - 3) + 2(x - 2)
$$

令导数等于零，解得：

$$
x = \frac{3 + 2}{2} = 2.5
$$

此时，目标函数取得最小值。
