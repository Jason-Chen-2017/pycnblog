##### 3.1 经典相变模型

经典相变模型是研究相变现象的基础，其中最著名的包括Ising模型、Heisenberg模型和mean-field理论。

**Ising模型**是一种用于描述磁性材料的模型，由沃尔夫冈·泡利在1925年提出。在Ising模型中，每个磁原子可以处于两种状态之一（如+1和-1），相邻的磁原子之间存在相互作用。当系统达到平衡状态时，整个系统的磁化方向趋于一致。Ising模型的数学表述为：

$$
E = -J \sum_{i<j} s_i s_j
$$

其中，$E$ 是系统的能量，$J$ 是相邻原子间的相互作用强度，$s_i$ 是原子$i$的状态。

**Heisenberg模型**是在Ising模型的基础上进一步考虑了磁原子之间的角度依赖性。在Heisenberg模型中，相互作用能量不仅依赖于相邻原子之间的相对状态，还依赖于它们的相对角度。Heisenberg模型的数学表述为：

$$
E = -J \sum_{i<j} \cos(\theta_{ij})
$$

其中，$\theta_{ij}$ 是原子$i$和原子$j$之间的相对角度。

**mean-field理论**是一种简化的相变模型，通过引入一个平均场来描述系统的行为。在mean-field理论中，系统的每个原子都受到一个全局的平均场影响，而忽略原子间的直接相互作用。mean-field理论的数学表述为：

$$
E = -J \langle s_i s_j \rangle
$$

其中，$\langle s_i s_j \rangle$ 是原子$i$和原子$j$之间的平均相互作用。

这些经典相变模型为理解宇宙相变提供了重要的基础，并且在实际应用中得到了广泛的应用。

# 定义微分方程
def model(Y, t, params):
    y, z = Y
    alpha, beta = params
    dydt = alpha * (1 - y - z)
    dzdt = beta * (y - z)
    return [dydt, dzdt]

# 参数设置
alpha = 0.1
beta = 0.1

# 初始条件
Y0 = [1, 0]

# 时间范围
t = np.linspace(0, 10, 1000)

# 求解微分方程
result = odeint(model, Y0, t, args=(alpha, beta))

# 绘制结果
plt.plot(t, result[:, 0], label='y(t)')
plt.plot(t, result[:, 1], label='z(t)')
plt.legend()
plt.xlabel('Time')
plt.ylabel('Value')
plt.show()
