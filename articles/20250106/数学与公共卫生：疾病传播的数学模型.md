## 第1章：核心概念与联系

### 1.1 传染病模型概述

#### 1.1.1 基本组成部分
传染病模型通常包括以下几个基本组成部分：

- **易感者（Susceptible, S）**：指那些尚未感染疾病但有可能被感染的人群。
- **感染者（Infected, I）**：指已经感染疾病且具有传染性的人群。
- **康复者（Recovered, R）**：指已经康复且不再具有传染性的人群。

#### 1.1.2 模型参数及其含义
传染病模型的参数通常包括以下几种：

- **传染率（Transmission rate, β）**：指单位时间内感染者传染给易感者的平均数量。
- **恢复率（Recovery rate, μ）**：指单位时间内感染者康复的比例。

### 1.2 模型属性特征对比

#### 1.2.1 SIR模型
SIR模型是最常见的传染病模型之一，它基于以下微分方程：

$$
\frac{dS}{dt} = -\beta \cdot S \cdot I
$$

$$
\frac{dI}{dt} = \beta \cdot S \cdot I - \mu \cdot I
$$

$$
\frac{dR}{dt} = \mu \cdot I
$$

#### 1.2.2 SIRS模型
SIRS模型在SIR模型的基础上增加了再次感染的可能性，其微分方程如下：

$$
\frac{dS}{dt} = \mu \cdot R - \beta \cdot S \cdot I
$$

$$
\frac{dI}{dt} = \beta \cdot S \cdot I - \mu \cdot I - \gamma \cdot I
$$

$$
\frac{dR}{dt} = \mu \cdot I + \gamma \cdot I - \beta \cdot S \cdot I
$$

#### 1.2.3 其他常见模型
除了SIR和SIRS模型，还有许多其他传染病模型，如SEIR模型、SIRSAS模型等。这些模型在参数设置和方程形式上有所不同，但核心思想都是基于传染率、恢复率和感染者的传播能力。

### 2.2 Python代码实现

#### 2.2.1 SIR模型代码

```python
import numpy as np
import matplotlib.pyplot as plt

# 初始化参数
S0 = 1000
I0 = 1
R0 = 0
N = S0 + I0 + R0
beta = 0.3
mu = 0.1
t_max = 100
dt = 0.1

# 初始化变量
S = np.zeros(int(t_max/dt))
I = np.zeros(int(t_max/dt))
R = np.zeros(int(t_max/dt))
S[0] = S0
I[0] = I0
R[0] = R0

# 计算SIR变量
for i in range(1, int(t_max/dt)):
    dSdt = -beta * S[i-1] * I[i-1]
    dIdt = beta * S[i-1] * I[i-1] - mu * I[i-1]
    dRdt = mu * I[i-1]
    
    S[i] = S[i-1] + dSdt * dt
    I[i] = I[i-1] + dIdt * dt
    R[i] = R[i-1] + dRdt * dt

# 绘制结果
plt.plot(S, label='Susceptible')
plt.plot(I, label='Infected')
plt.plot(R, label='Recovered')
plt.xlabel('Time')
plt.ylabel('Population')
plt.legend()
plt.show()
```

## 第3章：数学模型与公式讲解

### 3.1 SIR模型数学公式

#### 3.1.1 SIR模型公式
SIR模型基于以下微分方程：

$$
\frac{dS}{dt} = -\beta \cdot S \cdot I
$$

$$
\frac{dI}{dt} = \beta \cdot S \cdot I - \mu \cdot I
$$

$$
\frac{dR}{dt} = \mu \cdot I
$$

#### 3.1.2 公式详细讲解
- 第一个公式表示易感者人数随时间的变化率，即易感者因感染而减少的速率。
- 第二个公式表示感染者人数随时间的变化率，即感染者因传染和康复而变化的速率。
- 第三个公式表示康复者人数随时间的变化率，即感染者康复并转化为康复者的速率。

### 3.2 例子说明

#### 3.2.1 例子1
假设一个社区有1000人，其中1人感染了疾病，传染率为0.3，康复率为0.1。使用SIR模型计算感染者在10天内的变化情况。

$$
\frac{dI}{dt} = 0.3 \cdot 999 \cdot 1 - 0.1 \cdot 1 = 299.7 - 0.1 = 299.6
$$

#### 3.2.2 例子2
假设另一个社区有1000人，其中5人感染了疾病，传染率为0.5，康复率为0.2。使用SIR模型计算感染者在5天内的变化情况。

$$
\frac{dI}{dt} = 0.5 \cdot 995 \cdot 5 - 0.2 \cdot 5 = 124.375 - 1 = 123.375
$$

### 5.2 核心代码实现

#### 5.2.1 SIR模型代码

```python
import numpy as np
import matplotlib.pyplot as plt

class SIRModel:
    def __init__(self, N, beta, mu):
        self.N = N
        self.beta = beta
        self.mu = mu
        self.S = N
        self.I = 1
        self.R = 0

    def update(self, dt):
        dSdt = -self.beta * self.S * self.I
        dIdt = self.beta * self.S * self.I - self.mu * self.I
        dRdt = self.mu * self.I
        
        self.S += dSdt * dt
        self.I += dIdt * dt
        self.R += dRdt * dt

    def simulate(self, days, dt=0.1):
        t = np.arange(0, days, dt)
        S = [self.S]
        I = [self.I]
        R = [self.R]

        for _ in range(int(days / dt)):
            self.update(dt)
            S.append(self.S)
            I.append(self.I)
            R.append(self.R)

        return t, S, I, R

    def plot(self, t, S, I, R):
        plt.plot(t, S, label='Susceptible')
        plt.plot(t, I, label='Infected')
        plt.plot(t, R, label='Recovered')
        plt.xlabel('Time')
        plt.ylabel('Population')
        plt.legend()
        plt.show()

# 测试代码
model = SIRModel(N=1000, beta=0.3, mu=0.1)
t, S, I, R = model.simulate(days=100)
model.plot(t, S, I, R)
```

import numpy as np
import matplotlib.pyplot as plt

class SIRSModel:
    def __init__(self, N, beta, mu, gamma):
        self.N = N
        self.beta = beta
        self.mu = mu
        self.gamma = gamma
        self.S = N
        self.I = 1
        self.R = 0

    def update(self, dt):
        dSdt = -self.beta * self.S * self.I + self.mu * self.R
        dIdt = self.beta * self.S * self.I - self.mu * self.I - self.gamma * self.I
        dRdt = self.mu * self.I + self.gamma * self.I
        
        self.S += dSdt * dt
        self.I += dIdt * dt
        self.R += dRdt * dt

    def simulate(self, days, dt=0.1):
        t = np.arange(0, days, dt)
        S = [self.S]
        I = [self.I]
        R = [self.R]

        for _ in range(int(days / dt)):
            self.update(dt)
            S.append(self.S)
            I.append(self.I)
            R.append(self.R)

        return t, S, I, R

    def plot(self, t, S, I, R):
        plt.plot(t, S, label='Susceptible')
        plt.plot(t, I, label='Infected')
        plt.plot(t, R, label='Recovered')
        plt.xlabel('Time')
        plt.ylabel('Population')
        plt.legend()
        plt.show()

# 测试代码
