import pandas as pd

# 活动设计
def design_activity(team_size):
    # 随机生成活动方案

    satisfaction = sum(feedbacks) / len(feedbacks)

satisfaction, average_performance = evaluate_activity(feedbacks, performance_metrics)
print("活动满意度：", satisfaction)
print("平均绩效：", average_performance)

### 4.1 凝聚力评估模型

团队凝聚力是团队建设活动中的一个核心指标。我们可以使用以下数学模型来评估团队凝聚力：

$$
CP = \alpha \cdot C + \beta \cdot T + \gamma \cdot M
$$

其中：
- \( CP \) 表示团队凝聚力得分。
- \( C \) 表示共同目标的认同度，取值范围在0到1之间。
- \( T \) 表示团队成员之间的信任程度，取值范围在0到1之间。
- \( M \) 表示团队成员之间的沟通频率，取值范围在0到1之间。
- \( \alpha \)、\( \beta \) 和 \( \gamma \) 分别是权重系数，用于反映每个因素的重要性。

db = SQLAlchemy()

class Activity(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(120), nullable=False)
    description = db.Column(db.Text, nullable=False)

    @staticmethod
    def create_activity(title, description):
        activity = Activity(title=title, description=description)
        db.session.add(activity)
        db.session.commit()
        return activity

    @staticmethod
    def get_all_activities():
        return Activity.query.all()

    def to_dict(self):
        return {
            'id': self.id,
            'title': self.title,
            'description': self.description
        }

class Member(db.Model):
    id = db.Column(db.Integer, primary_key=True)

2. **参与度**：设计参与度高的活动，鼓励所有团队成员积极参与。可以通过小组活动、角色扮演、游戏等方式来提高参与度。
3. **多样性和包容性**：考虑到团队成员的多样性，设计能够满足不同需求和兴趣的活动。同时，确保活动包容性，让每位成员都能感到被尊重和接受。
4. **反馈机制**：在活动结束后，及时收集参与者的反馈，了解他们对活动的看法和建议，以便进行改进。
5. **持续跟进**：团队建设是一个持续的过程，活动结束后，需要跟进活动的效果，并根据反馈进行持续优化。

### 7.2 团队建设活动注意事项

1. **时间安排**：合理安排活动时间，避免与工作冲突，确保团队成员有足够的时间参与。
2. **资源分配**：确保活动所需的资源（如场地、设备、材料等）充足，以便活动顺利进行。
3. **安全措施**：对于户外活动或高风险活动，制定相应的安全措施，确保团队成员的安全。
4. **公平性**：在活动设计和实施过程中，确保公平性，避免歧视和排斥现象。
5. **隐私保护**：在收集参与者信息时，注意保护个人隐私，遵守相关法律法规。

### 7.3 小结

通过本章的最佳实践和建议，我们可以看到团队建设活动不仅仅是简单的集体活动，它需要科学的策划、合理的组织和有效的执行。有效的团队建设活动能够显著提高团队凝聚力和协作效率，从而推动组织绩效的提升。
