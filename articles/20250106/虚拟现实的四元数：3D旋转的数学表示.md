与复数 \( z = a + bi \) 相似，四元数也有实部和虚部。实部 \( a \) 表示四元数的实值部分，而虚部由 \( bi + cj + dk \) 组成。四元数的单位虚数 \( i, j, k \) 满足以下运算规则：

- \( i^2 = j^2 = k^2 = ijk = -1 \)
- \( ij = k \), \( ji = -k \)
- \( jk = i \), \( kj = -i \)
- \( ki = j \), \( ik = -j \)

这些规则确保了四元数之间的运算具有一致性和闭合性。

**2.1.2 四元数的表示方法**

四元数的表示方法可以通过向量和矩阵两种形式进行。向量形式直接将四元数表示为三维空间中的向量加上一个实数部分：

\[ \vec{q} = (b, c, d) \quad \text{和} \quad a \]

矩阵形式则通过一个四行四列的矩阵来表示四元数：

\[ 
Q = \begin{bmatrix}
a & -d & -c & -b \\
d & a & -b & -c \\
c & b & a & -d \\
-b & c & d & a
\end{bmatrix}
\]

这两种表示方法在不同的计算场景中各有优势。向量形式在几何运算中更加直观，而矩阵形式则便于进行线性代数的运算。

**2.1.3 四元数的运算规则**

四元数的运算包括加法、减法、乘法和除法。以下是四元数的基本运算规则：

1. **加法和减法**：四元数的加法和减法与复数的运算类似，只需将对应部分相加或相减：

\[ q_1 + q_2 = (a_1 + a_2) + (b_1 + b_2)i + (c_1 + c_2)j + (d_1 + d_2)k \]
\[ q_1 - q_2 = (a_1 - a_2) + (b_1 - b_2)i + (c_1 - c_2)j + (d_1 - d_2)k \]

2. **乘法**：四元数的乘法较为复杂，遵循以下规则：

\[ (a_1 + b_1i + c_1j + d_1k)(a_2 + b_2i + c_2j + d_2k) \]
\[ = (a_1a_2 - b_1b_2 - c_1c_2 - d_1d_2) + (a_1b_2 + b_1a_2 + c_1d_2 - d_1c_2)i + (a_1c_2 - b_1d_2 + c_1a_2 + d_1b_2)j + (a_1d_2 + b_1c_2 - c_1b_2 + d_1a_2)k \]

3. **除法**：四元数的除法可以通过乘以其共轭四元数来实现：

\[ \frac{q_1}{q_2} = q_1 \cdot q_2^{-1} \]

共轭四元数的计算方法是将原四元数的虚部取相反数，即 \( \overline{q} = a - bi - cj - dk \)。

**4.1.1 3D旋转的基本概念**

3D旋转涉及三个关键元素：旋转轴、旋转角度和旋转中心。旋转轴是一个向量，表示旋转操作的轴线；旋转角度是旋转的幅度；旋转中心则是旋转操作的起点。在三维空间中，一个物体可以绕任意轴旋转，形成一个旋转体。

**4.1.2 3D旋转的数学表示方法**

1. **旋转矩阵**：旋转矩阵是一种常用的表示3D旋转的数学工具，通过矩阵乘法实现旋转操作。旋转矩阵具有如下形式：

$$
R = \begin{bmatrix}
cos(\theta) & -sin(\theta) & 0 \\
sin(\theta) & cos(\theta) & 0 \\
0 & 0 & 1

$$

其中，\( \theta \) 是旋转角度。旋转矩阵的优点是计算简单，但存在“万向锁”问题，即当旋转角度接近 \( \pm 180^\circ \) 时，矩阵的行列式为零，导致旋转失效。

2. **欧拉角**：欧拉角是一种基于三个连续旋转的表示方法，分别绕X轴、Y轴和Z轴旋转。欧拉角的优势在于直观性和易理解性，但其缺点是同样存在“万向锁”问题，并且不同顺序的旋转会导致不同的结果。

3. **四元数**：四元数是一种更高效的数学表示方法，能够精确地表示任意三维旋转，避免“万向锁”问题。四元数旋转的数学模型如下：

其中，\( q \) 和 \( q' \) 分别表示原始和旋转后的四元数，旋转四元数表示为：

$$
\text{旋转四元数} = \cos(\theta/2) + \sin(\theta/2) \cdot \vec{n}
$$

\( \vec{n} \) 是旋转轴，\( \theta \) 是旋转角度。

#### 6.2 系统核心实现源代码

以下是实现四元数旋转功能的核心 Python 源代码。该代码实现了四元数的构造、旋转、和归一化操作，并在虚拟现实场景中进行了应用。

```python
import numpy as np

# 定义四元数
class Quaternion:
    def __init__(self, a, b, c, d):
        self.a = a
        self.b = b
        self.c = c
        self.d = d
    
    def __mul__(self, other):
        a = self.a * other.a - self.b * other.b - self.c * other.c - self.d * other.d
        b = self.a * other.b + self.b * other.a + self.c * other.d - self.d * other.c
        c = self.a * other.c - self.b * other.d + self.c * other.a + self.d * other.b
        d = self.a * other.d + self.b * other.c - self.c * other.b + self.d * other.a
        return Quaternion(a, b, c, d)

    def conjugate(self):
        return Quaternion(self.a, -self.b, -self.c, -self.d)

    def norm(self):
        return np.sqrt(self.a**2 + self.b**2 + self.c**2 + self.d**2)

    def normalize(self):
        n = self.norm()
        return Quaternion(self.a / n, self.b / n, self.c / n, self.d / n)

# 定义旋转四元数
def rotation_quaternion(axis, angle):
    sin_half_angle = np.sin(angle / 2)
    return Quaternion(np.cos(angle / 2), sin_half_angle * axis[0], sin_half_angle * axis[1], sin_half_angle * axis[2])

# 示例：旋转虚拟现实场景中的物体
def rotate_object(object_quaternion, rotation_axis, rotation_angle):
    rotation_q = rotation_quaternion(rotation_axis, rotation_angle)
    object_q_prime = object_quaternion * rotation_q * object_quaternion.conjugate()
    return object_q_prime

# 测试旋转
q = Quaternion(1, 0, 0, 0)
q_prime = rotate_object(q, np.array([0, 0, 1]), np.pi / 2)
print(q_prime)
```
