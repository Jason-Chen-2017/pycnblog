#### 详细讲解和举例说明

假设有一个待排序的数组\[4, 2, 9, 1, 5\]，我们可以使用排序算法（如快速排序）对其进行排序。快速排序的基本原理是将数组划分为两部分，一部分包含小于基准值的元素，另一部分包含大于基准值的元素。然后递归地对这两部分进行排序。通过这种划分和递归排序，最终得到一个有序的数组。

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    left = [x for x in arr[1:] if x < pivot]
    right = [x for x in arr[1:] if x >= pivot]
    return quicksort(left) + [pivot] + quicksort(right)

# 测试
arr = [4, 2, 9, 1, 5]
sorted_arr = quicksort(arr)
print(sorted_arr)
```

输出结果：

```
[1, 2, 4, 5, 9]
```

通过上述示例，我们可以看到快速排序算法的基本原理和实现过程。快速排序算法的时间复杂度为 \(O(n \log n)\)，空间复杂度为 \(O(n)\)。这表明快速排序算法在处理大规模数据时具有较高的效率。

假设有一个待排序的数组\[4, 2, 9, 1, 5\]，我们可以使用排序算法（如快速排序）对其进行排序。快速排序的基本原理是将数组划分为两部分，一部分包含小于基准值的元素，另一部分包含大于基准值的元素。然后递归地对这两部分进行排序。通过这种划分和递归排序，最终得到一个有序的数组。

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    left = [x for x in arr[1:] if x < pivot]
    right = [x for x in arr[1:] if x >= pivot]
    return quicksort(left) + [pivot] + quicksort(right)

# 测试
arr = [4, 2, 9, 1, 5]
sorted_arr = quicksort(arr)
print(sorted_arr)
```

输出结果：

```
[1, 2, 4, 5, 9]
```

通过上述示例，我们可以看到快速排序算法的基本原理和实现过程。快速排序算法的时间复杂度为 \(O(n \log n)\)，空间复杂度为 \(O(n)\)。这表明快速排序算法在处理大规模数据时具有较高的效率。
