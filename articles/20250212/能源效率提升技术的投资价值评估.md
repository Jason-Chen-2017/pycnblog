### 1.1 能源效率的基本概念

#### 1.1.1 能源效率的定义
能源效率是指在能源生产和使用过程中，转化为有用功的比例。简单来说，能源效率越高，单位能源产出的效益越大。

#### 1.1.2 能源效率的重要性
在全球能源需求不断增长的背景下，提升能源效率是减少能源浪费、降低碳排放、应对气候变化的关键手段。

## 第3章：能源效率提升技术的投资价值评估方法

### 3.1 投资价值评估的算法原理

#### 3.1.1 净现值法（NPV）
净现值法是评估投资项目收益的主要方法，公式为：
$$ NPV = \sum_{t=0}^{n} \frac{C_t}{(1 + r)^t} $$
其中，$C_t$是第t年的现金流，$r$是折现率。

#### 3.1.2 内部收益率法（IRR）
内部收益率是使净现值为零的折现率，公式为：
$$ IRR = r \text{ 使得 } NPV = 0 $$

#### 3.1.3 投资回收期法（Payback Period）
投资回收期是投资回收原始投资额所需的时间，通常用于评估项目的风险。

---

### 3.3 实际案例分析与讲解

#### 3.3.1 某能源项目投资价值评估案例
假设某节能改造项目，初始投资为100万元，年节约成本20万元，折现率为10%。

计算净现值：
$$ NPV = \frac{20}{1.1} + \frac{20}{1.1^2} + \cdots + \frac{20}{1.1^5} - 100 $$

#### 6.1.2 核心代码实现

import pandas as pd
import matplotlib.pyplot as plt

# 计算净现值
def calculate_npv(cash_flows, discount_rate):
    return sum([cf / (1 + discount_rate)**t for t, cf in enumerate(cash_flows)])

# 示例数据
cash_flows = [100, -50, -50, 200, 200]
discount_rate = 0.1

npv = calculate_npv(cash_flows, discount_rate)
print(f"净现值为：{npv}")
