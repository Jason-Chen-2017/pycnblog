# 第一章：引言

## 1.1 彼得林奇的"耐心投资"理念
### 1.1.1 彼得林奇投资哲学概述
彼得林奇是美国著名的投资专家，以其长期投资策略闻名。他强调选择优质企业长期持有，避免频繁交易。这种“耐心投资”理念认为，市场的短期波动不应影响长期投资决策。

### 1.1.2 耐心投资的核心原则
1. **长期视角**：关注企业的基本面，而非短期市场波动。
2. **分散投资**：通过多样化降低风险。
3. **避免情绪化交易**：不受市场短期波动影响。

### 1.1.3 耐心投资在市场高波动中的表现
高波动期可能导致投资组合的价值大幅波动，考验投资者的耐心。此时，耐心投资的策略可能面临挑战，需要进行优化。

## 1.2 市场高波动期的特征与挑战
### 1.2.1 市场波动的定义与分类
市场波动是价格在短时间内剧烈波动的现象，通常由市场情绪、突发事件等因素引发。高波动期意味着波动幅度大、频率高。

### 1.2.2 高波动期对投资策略的影响
高波动可能导致投资组合的短期亏损，增加心理压力，影响决策。投资者可能被迫卖出优质资产，错过长期收益。

### 1.2.3 投资者在高波动期的常见误区
1. **过度反应**：基于短期波动做出决策。
2. **恐慌性抛售**：在市场下跌时急于卖出。
3. **忽视长期目标**：短期波动干扰长期投资计划。

import numpy as np
from scipy.optimize import minimize

def optimize_portfolio(returns, weights):
    # 定义目标函数（最小化风险）
    def objective(weights):
        return np.dot(weights.T, np.dot(returns.cov(), weights))
    # 约束条件：权重之和为1，权重非负
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1},
                   {'type': 'ineq', 'fun': lambda w: w[i] >= 0 for i in range(len(weights))}]
    result = minimize(objective, weights, constraints)
    return result.x

weights = np.array([0.2, 0.3, 0.5])
optimized_weights = optimize_portfolio(returns, weights)
