#### 4.1 数学模型

- **社会不平等模型**：基尼系数模型。
- **关联模型**：线性回归模型。

#### 4.2 数学公式
- **股市估值公式**：$$ P = \frac{E}{r} $$
- **社会不平等公式**：$$ Gini = \sum_{i=1}^{n} (2i - n - 1) \cdot x_i $$
- **关联公式**：$$ R = \beta_1 + \beta_2 X + \epsilon $$

#### 6.2 系统核心实现源代码
- **数据处理代码**：

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载
data = pd.read_csv('stock_social.csv')

# 数据预处理
data = data.dropna()
X = data[['market_value', 'dividend_yield']]
y = data['gini_coeff']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 结果分析
predictions = model.predict(X)
print("R-squared:", r2_score(y, predictions))
```
