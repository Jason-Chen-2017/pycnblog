### 5.2 算法实现

以下是一个简单的概率模型实现示例：

```python
import numpy as np
from sklearn.naive_bayes import GaussianNB

# 数据预处理
X = np.array([[1, 2], [2, 3], [3, 4], [4, 5]])
y = np.array([0, 1, 0, 1])

# 模型训练
model = GaussianNB()
model.fit(X, y)

# 预测
new_data = np.array([[2.5, 3.5]])
prediction = model.predict(new_data)
print("预测结果:", prediction)
```
