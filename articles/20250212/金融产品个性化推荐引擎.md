## 4.2 推荐算法的实现
### 4.2.1 协同过滤算法的实现
```python
from sklearn.metrics.pairwise import cosine_similarity

# 假设 ratings 是一个用户-产品评分矩阵
cosine_sim = cosine_similarity(ratings)
# 找出与目标用户最相似的k个用户
def get_recommendations(user_id, k=5):
    user_sim = cosine_sim[user_id]
    indices = [i for i in range(len(user_sim)) if i != user_id]
    indices.sort(key=lambda x: user_sim[x], reverse=True)
    return indices[:k]
```
