#### 3.2 贴现现金流模型（DCF模型）

- **模型概述**
  - DCF模型用于评估公司的未来现金流，折现到现值以确定其价值

- **公式与计算步骤**

  1. 未来现金流预测：
     $$ \text{现金流} = \text{收入} - \text{成本} - \text{税金} $$
  
  2. 折现率计算：
     $$ r = \text{无风险利率} + \text{风险溢价} $$

  3. 现值计算：
     $$ PV = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} $$

- **应用示例**
  - 假设年现金流为100万，折现率为10%，计算3年的现值：
    $$ PV = \frac{100}{1.1} + \frac{100}{1.21} + \frac{100}{1.331} \approx 90.91 + 82.64 + 75.13 = 248.68 \text{万} $$

- **代码实现**

  ```python
  def discounted_cash_flow(cash_flows, discount_rate):
      present_value = 0
      for year, cash_flow in enumerate(cash_flows):
          discount_factor = (1 + discount_rate) ** year
          present_value += cash_flow / discount_factor
      return present_value
  
  # 示例
  cash_flows = [100, 100, 100]
  discount_rate = 0.1
  print(discounted_cash_flow(cash_flows, discount_rate))
  ```

import numpy as np

def discounted_cash_flow(cash_flows, discount_rate):

discount_rate = 0.1

result = discounted_cash_flow(cash_flows, discount_rate)
