# 第1章: 小型核反应堆概述

## 1.1 小型核反应堆的定义与特点

### 1.1.1 小型核反应堆的定义

小型核反应堆是一种功率相对较低的核能发电装置，通常指功率在10 MW到300 MW之间的反应堆。与传统的大型核反应堆相比，小型核反应堆具有模块化、灵活性强、建造周期短等优势。

### 1.1.2 小型核反应堆的核心特点

| 特性 | 描述 |
|------|------|
| 模块化设计 | 小型核反应堆通常采用模块化设计，便于运输和安装。 |
| 安全性高 | 设计上注重安全冗余，降低事故风险。 |
| 投资成本低 | 相对于大型核反应堆，小型反应堆的建设和运营成本较低。 |
| 可扩展性 | 可根据能源需求逐步扩展容量，灵活性强。 |

### 1.1.3 小型核反应堆的优势与局限性

- **优势**：
  - 成本低，适合中小型能源需求。
  - 安装灵活，适应不同地理环境。
- **局限性**：
  - 单位功率成本可能高于大型反应堆。
  - 技术成熟度有待进一步验证。

# 第2章: 小型核反应堆的核心技术

## 2.1 核反应堆的基本原理

### 2.1.1 核裂变的基本概念

核裂变是指重核在吸收一个中子后分裂成两个或更多较轻的核，并释放出大量能量的过程。

### 2.1.2 核反应堆的链式反应原理

- **链式反应**：一个中子撞击铀-235原子核后，释放出更多中子，引发连锁反应。
- **临界条件**：反应堆的链式反应需要满足临界条件，通常通过控制棒调节。

### 2.1.3 核反应堆的临界条件

- **临界体积**：反应堆的体积达到一定值时，链式反应可以持续。
- **临界浓度**：燃料中 fissile 核的数量达到一定比例。

- **燃料组件**：使用低 enriched uranium 或其他核燃料。
