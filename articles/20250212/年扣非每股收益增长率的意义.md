## 第1章 扣非每股收益增长率的背景与意义

### 1.1 扣非每股收益的定义与背景

#### 1.1.1 每股收益的基本概念
每股收益（EPS）是衡量上市公司盈利能力的重要指标，计算公式为：
$$ \text{EPS} = \frac{\text{净利润}}{\text{总股本}} $$

然而，净利润中可能包含非经常性损益，如资产处置收益或法律诉讼赔偿，这些因素可能扭曲企业的实际经营状况。因此，扣除非经常性损益后的每股收益（Non-GAAP EPS）更能反映企业主营业务的盈利能力。

#### 1.1.2 扣除非经常性损益的必要性
非经常性损益通常不影响企业的持续经营，扣除这些项目后，投资者可以更清晰地看到企业核心业务的盈利能力。

#### 1.1.3 扣非每股收益增长率的计算公式
扣非每股收益增长率的计算公式为：
$$ \text{扣非每股收益增长率} = \frac{\text{本期扣非每股收益} - \text{上期扣非每股收益}}{\text{上期扣非每股收益}} \times 100\% $$

### 3.2 扣非每股收益增长率的数学模型

#### 3.2.1 基本公式
$$ \text{扣非每股收益增长率} = \frac{\text{本期扣非EPS} - \text{上期扣非EPS}}{\text{上期扣非EPS}} \times 100\% $$

#### 3.2.2 增长率的累积计算
$$ \text{累积增长率} = \prod_{i=1}^{n} (1 + \text{年增长率}_i) - 1 $$

### 3.3 扣非每股收益增长率的算法实现

#### 3.3.1 Python代码实现
```python
import pandas as pd

def calculate_non_recurring_eps_growth(data):
    data['净利润'] = data['净利润'] - data['非经常性损益']
    data['扣非EPS'] = data['净利润'] / data['总股本']
    growth_rates = []
    for i in range(1, len(data)):
        growth_rate = ((data['扣非EPS'].iloc[i] - data['扣非EPS'].iloc[i-1]) / 
                       data['扣非EPS'].iloc[i-1]) * 100
        growth_rates.append(round(growth_rate, 2))
    return growth_rates

# 示例数据
data = {
    '年份': [2013, 2014, 2015, 2016, 2017],
    '净利润': [100, 120, 150, 180, 200],
    '非经常性损益': [20, 10, 0, 15, 5],
    '总股本': [1000, 1000, 1000, 1000, 1000]
}

growth_rates = calculate_non_recurring_eps_growth(data)
print(growth_rates)
```
