## 第1章：CANSLIM选股系统的背景与核心理念

### 1.1 传统选股方法的局限性

### 1.3 CANSLIM系统的核心目标  
CANSLIM系统的目的是通过筛选出那些具有高增长潜力的股票，帮助投资者在市场中获得超额收益。该系统强调股票的相对强度、市场宽度和领导力等因素。

CANSLIM是一种基于技术分析的选股系统，通过量化股票的价格走势、成交量、相对强度等指标，筛选出具有上涨潜力的股票。

### 2.2 CANSLIM的核心特点  
- **量化分析**：通过数学模型量化股票的走势和市场环境。
- **多指标筛选**：综合考虑价格、成交量、相对强度等多个指标。
- **动态调整**：根据市场变化动态调整筛选标准。

### 2.3 CANSLIM与传统选股方法的区别

## 第3章：CANSLIM选股系统的核心要素

### 3.1 C: 股价创新高  
股价创新高是CANSLIM系统的核心指标之一。如果一只股票在近期创下了历史新高，说明该股票可能具有较高的上涨潜力。

### 3.2 A: 相对强度  
相对强度是指某只股票相对于市场指数的表现。相对强度高的股票通常表现出更强的上涨动力。

### 3.3 N: 新高成交量  
新高成交量是指在股价创新高的过程中，成交量是否也创下了新高。成交量的增加表明市场参与者对这只股票的信心增强。

### 3.4 S: 股价与成交量的关系  
股价与成交量的关系是技术分析中的重要指标。在股价上涨过程中，成交量应该同步增加，否则可能表明上涨动力不足。

### 3.5 L: 市场宽度  
市场宽度是指市场上上涨股票的数量占总股票数量的比例。市场宽度高的市场通常意味着整体市场情绪乐观。

### 3.6 I: 领导力  
领导力是指某只股票在市场中表现是否具有领先性。具有领导力的股票通常能够引领市场的上涨趋势。

### 3.7 M: 市场趋势  
市场趋势是CANSLIM系统中的另一个重要指标。如果市场整体处于上升趋势，那么筛选出的股票更容易获得超额收益。

## 第4章：CANSLIM选股系统的核心原理

### 4.1 股票筛选的基本逻辑  
CANSLIM系统通过综合分析股票的价格走势、成交量、相对强度等多个指标，筛选出那些具有上涨潜力的股票。

### 4.2 相对强度的概念与计算  
相对强度是衡量某只股票相对于市场指数表现的重要指标。计算公式如下：
$$相对强度 = \frac{股票涨幅}{市场指数涨幅}$$

### 4.3 市场宽度的衡量指标  
市场宽度是衡量市场整体情绪的重要指标。计算公式如下：
$$市场宽度 = \frac{上涨股票数量}{总股票数量}$$

### 4.4 领导力的定义与作用  
领导力是指某只股票在市场中的表现是否具有领先性。具有领导力的股票通常能够引领市场的上涨趋势。

import pandas as pd
import numpy as np

def calculate_relative_strength(stock_data, market_data):
    stock_return = stock_data['收盘价'].pct_change()
    market_return = market_data['指数收盘价'].pct_change()
    relative_strength = stock_return / market_return
    return relative_strength

def calculate_market_width(stock_data):
    up_days = stock_data['收盘价'].diff().fillna(0).gt(0).sum()
    total_days = len(stock_data)
    market_width = up_days / total_days
    return market_width

def calculate_can_slim_score(stock_data, market_data):
    relative_strength = calculate_relative_strength(stock_data, market_data)
    market_width = calculate_market_width(stock_data)
    score = relative_strength * 0.6 + market_width * 0.4
    return score
