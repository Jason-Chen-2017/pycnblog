#### 5.3 算法实现
```python
import numpy as np

def calculate_VaR(data, confidence_level):
    return np.percentile(data, confidence_level)

def calculate_CVaR(data, confidence_level):
    VaR = calculate_VaR(data, confidence_level)
    filtered_data = data[data <= VaR]
    return np.mean(filtered_data)

# 示例数据
data = np.random.normal(0, 1, 1000)
confidence_level = 95

VaR = calculate_VaR(data, confidence_level)
CVaR = calculate_CVaR(data, confidence_level)
```

#### 5.4 数学模型
- VaR公式：$$VaR = \alpha \cdot \sigma$$
- CVaR公式：$$CVaR = \frac{1}{1 - \alpha} \sum_{i=1}^{n} (x_i - VaR)$$
