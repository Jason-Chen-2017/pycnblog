# 第二部分：全球股市估值的核心算法与实现

## 第2章：全球股市估值的核心算法

### 2.1 算法原理

#### 2.1.1 市盈率与市净率的计算
- **市盈率（P/E）**：股票价格除以每股收益。
  $$ P/E = \frac{股票价格}{每股收益} $$
- **市净率（P/B）**：股票价格除以每股净资产。
  $$ P/B = \frac{股票价格}{每股净资产} $$

#### 2.1.2 现金流折现模型
现金流折现模型（DCF）用于评估企业未来现金流的现值。
$$ \text{企业价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} $$

### 2.2 算法实现

#### 2.2.1 Python代码实现
```python
import pandas as pd
import numpy as np

# 示例数据
data = {
    '公司': ['公司A', '公司B', '公司C'],
    '股价': [100, 150, 200],
    '每股收益': [10, 15, 20],
    '每股净资产': [50, 60, 70],
    '现金流': [1000, 1500, 2000],
    '折现率': [0.1, 0.1, 0.1]
}

df = pd.DataFrame(data)

# 计算市盈率和市净率
df['市盈率'] = df['股价'] / df['每股收益']
df['市净率'] = df['股价'] / df['每股净资产']
# 计算DCF
def dcf_value(cash_flow, discount_rate):
    return sum(cash_flow / (1 + discount_rate)**t for t in range(1, len(cash_flow)+1))

df['DCF价值'] = df['现金流'].apply(lambda x: dcf_value(x, df['折现率']))
print(df)
```
