## 第3章: AI辅助客户细分的算法原理

### 3.1 常见算法概述

#### 3.1.1 K-means聚类算法
适用于无监督学习，常用于客户聚类。

#### 3.1.2 决策树分类算法
适用于有标签数据的分类，如客户 churn 预测。

#### 3.1.3 线性回归分析
适用于预测性分析，如销售预测。

### 3.2 算法原理与流程

#### 3.2.1 K-means算法流程
1. 初始化质心。
2. 计算每个数据点到质心的距离。
3. 聚类并更新质心。
4. 重复直到收敛。

```mermaid
graph TD
    A[开始] --> B[初始化质心]
    B --> C[计算距离]
    C --> D[聚类]
    D --> E[更新质心]
    E --> F[是否收敛？]
    F -->|否| C
    F -->|是| 结束
```

#### 3.2.2 K-means算法实现代码
```python
import numpy as np
from sklearn.cluster import KMeans

# 示例数据
X = np.array([[1, 2], [3, 4], [5, 6], [7, 8]])

# 初始化模型
kmeans = KMeans(n_clusters=2, random_state=0)

# 训练模型
kmeans.fit(X)

# 获取聚类结果
labels = kmeans.labels_
print(labels)
```

#### 3.2.3 K-means算法数学公式
距离计算公式：
$$d(x_i, c_j) = \sqrt{(x_i - c_j)^2}$$
