## 第三章：逆向思维在新股投资中的核心策略

### 3.1 逆向思维的核心策略

#### 3.1.1 市场情绪分析与逆向思维

市场情绪是投资者决策的重要因素。逆向思维要求投资者在市场情绪高涨时保持冷静，在市场恐慌时寻找机会。我们可以通过分析市场情绪指标，如成交量、波动率等，来判断市场的冷暖。

##### 使用Python进行市场情绪分析

```python
import pandas as pd
import numpy as np

# 示例数据：市场情绪指标，假设数据来自数据库
market_data = {
    'date': ['2023-01-01', '2023-01-02', '2023-01-03'],
    'sentiment_score': [0.8, 0.6, 0.4]
}

df = pd.DataFrame(market_data)

# 计算市场情绪指数
def calculate_sentiment_index(df):
    return df['sentiment_score'].mean()

sentiment_index = calculate_sentiment_index(df)
print(f"市场情绪指数：{sentiment_index}")
```
