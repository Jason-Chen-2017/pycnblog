# 第3章: 自动化设备的路径规划算法

## 3.1 路径规划算法概述

### 3.1.1 A*算法原理
A*算法通过评估节点的优先级，找到最短路径。其公式为：
$$ f(n) = g(n) + h(n) $$
其中，$g(n)$是已走距离，$h(n)$是估计的剩余距离。

### 3.1.2 Dijkstra算法
Dijkstra算法适用于所有节点非负权重的情况，公式为：
$$ d(n) = \min_{m} (d(m) + w(m,n)) $$

### 3.1.3 RRT算法
RRT（Rapidly-exploring Random Tree）适用于高维空间的路径规划，通过随机采样和树状结构扩展路径。

## 3.2 路径规划算法的实现与优化

def heuristic(a, b):
    return abs(a.x - b.x) + abs(a.y - b.y)
