#### 1.1 去全球化的概念与现状
- 1.1.1 去全球化的定义与特征
  - 去全球化是指全球化进程的逆转，表现为跨国贸易减少、供应链本地化、地缘政治冲突加剧等。
  - 去全球化的特征包括：贸易保护主义抬头、供应链区域化、国际分工体系松动、跨国公司本地化运营加强。

- 1.1.2 去全球化的主要驱动因素
  - 地缘政治冲突：如中美贸易摩擦、俄乌战争等。
  - 经济利益驱动：各国为了保护本国产业，采取关税壁垒、贸易限制等措施。
  - 供应链风险：新冠疫情暴露了全球供应链的脆弱性，各国开始寻求供应链的本地化和多元化。

- 1.1.3 去全球化对全球经济的深远影响
  - 对国际贸易的影响：全球贸易增速放缓，区域贸易协定增多。
  - 对企业运营的影响：跨国企业面临更高的运营成本和不确定性。
  - 对金融市场的影响：地缘政治风险上升，金融市场波动加剧。

#### 1.2 特价股票策略的定义与核心要素
- 1.2.1 特价股票的定义
  - 特价股票是指那些价格显著低于其内在价值的股票。这些股票通常被市场低估，具有较大的反弹空间。

- 1.2.2 特价股票的核心要素分析
  - 市场波动性：市场波动是特价股票出现的必要条件。
  - 公司基本面：公司基本面良好，但市场情绪不佳导致股价下跌。
  - 估值指标：市盈率、市净率等估值指标远低于行业平均水平。

- 1.2.3 特价股票与去全球化趋势的关系
  - 去全球化导致市场波动加剧，为特价股票的出现提供了更多机会。

## 第二部分: 特价股票策略的核心概念与原理

### 第3章: 特价股票策略的核心概念

#### 3.1 特价股票的定义与分类
- 3.1.1 特价股票的定义
  - 特价股票是指那些价格显著低于其内在价值的股票。

- 3.1.2 特价股票的分类与特点
  - 按行业分类：如能源、科技、制造业等。
  - 按市值分类：小盘股、中盘股、大盘股。

- 3.1.3 特价股票与普通股票的对比分析
  - 特价股票通常具有较高的波动性和较大的反弹空间。
  - 普通股票价格相对稳定，波动性较小。

#### 3.2 特价股票策略的原理
- 3.2.1 市场波动与价格偏离
  - 市场波动导致股票价格偏离其内在价值。
  - 投资者可以通过识别价格偏离的股票进行投资。

- 3.2.2 投资者情绪与市场机会
  - 市场恐慌导致股票价格被低估，为特价股票策略提供机会。
  - 市场乐观导致股票价格被高估，不利于特价股票策略。

- 3.2.3 价值回归理论与特价股票策略
  - 价值回归理论认为，股票价格最终会回归其内在价值。
  - 特价股票策略基于价值回归理论，寻找被低估的股票进行投资。

### 第6章: 特价股票策略的数学模型

#### 6.1 价值评估模型
- 6.1.1 市盈率模型
  - 市盈率（P/E）= 股价 / 每股净利润。
  - 低市盈率股票通常被认为是低估股票。

- 6.1.2 市净率模型
  - 市净率（P/B）= 股价 / 每股净资产。
  - 低市净率股票通常被认为是低估股票。

- 6.1.3 股息率模型
  - 股息率 = 每股股息 / 股价。
  - 高股息率股票通常被认为是价值型股票。

#### 6.2 市场波动模型
- 6.2.1 市场波动的数学描述
  - 股价波动可以用随机游走模型或 ARCH 模型描述。

- 6.2.2 基于时间序列的波动预测
  - 使用 ARIMA 模型或 GARCH 模型预测股价波动。

- 6.2.3 基于随机过程的波动建模
  - 股价波动可以用布朗运动或马尔可夫链模型描述。
