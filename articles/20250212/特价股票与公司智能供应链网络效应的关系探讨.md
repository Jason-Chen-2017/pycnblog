##### 6.2.2 网络效应的算法实现

#### 6.3 算法实现的Python代码示例
```python
import numpy as np
import pandas as pd

# 数据预处理
data = pd.read_csv('supply_chain_data.csv')
X = data.iloc[:, :-1].values
y = data.iloc[:, -1].values

# 训练模型
from sklearn.linear_model import LinearRegression
regressor = LinearRegression()
regressor.fit(X, y)

# 预测结果
y_pred = regressor.predict(X)
print('预测结果:', y_pred)
```
