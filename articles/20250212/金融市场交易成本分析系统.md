### 3.2 蒙特卡洛模拟的算法实现
- 3.2.1 算法步骤
  - 确定输入参数、模拟交易过程、计算期望成本
- 3.2.2 Python代码实现
  ```python
  import numpy as np

  def monte_carlo_simulation(nsim=1000):
      costs = []
      for _ in range(nsim):
          # 模拟交易成本
          cost = np.random.normal(loc=0.005, scale=0.002)
          costs.append(cost)
      return np.mean(costs), np.std(costs)

  mean_cost, std_cost = monte_carlo_simulation()
  print(f"Mean cost: {mean_cost}, Std cost: {std_cost}")
  ```
