我们可以使用贝叶斯定理来分析投资者的决策过程。假设投资者的成功概率为p，那么在连续k次成功后，p的后验概率为：

$$P(k|p) = \binom{k}{k} p^k (1-p)^{0}$$

### 6.2 核心代码实现

#### 6.2.1 Python代码示例

以下是实现“赢家的诅咒”算法的Python代码：

```python
import numpy as np
import matplotlib.pyplot as plt

# 生成随机数据
np.random.seed(42)
success_prob = 0.6
n_experiments = 1000
results = np.random.binomial(1, success_prob, n_experiments)

# 计算实际成功概率
actual_success_rate = np.mean(results)

# 评估过度自信程度
estimated_success_rate = 0.8  # 假设投资者估计的成功概率
overconfidence = actual_success_rate / estimated_success_rate

print(f"实际成功概率：{actual_success_rate}")
print(f"估计成功概率：{estimated_success_rate}")
print(f"过度自信程度：{overconfidence}")
```
