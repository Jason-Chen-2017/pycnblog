# 第1章 核聚变能源技术概述

## 1.1 核聚变的基本概念

### 1.1.1 核聚变的定义与基本原理
核聚变是指两个轻核在高温高压条件下结合成一个较重核的过程，同时释放出巨大的能量。与核裂变不同，核聚变不产生长期放射性废料，是一种更安全的能源技术。其基本原理可以表示为：

$$
A + B \rightarrow C + D + \text{能量}
$$

其中，A和B是两个轻核，C和D是较重的核或粒子。

### 1.1.2 核聚变与核裂变的区别
| 特性 | 核聚变 | 核裂变 |
|------|--------|--------|
| 反应类型 | 轻核结合 | 重核分裂 |
| 放射性废料 | 较少 | 较多 |
| 能量释放 | 中等 | 高 |
| 安全性 | 较高 | 较低 |

### 1.1.3 核聚变能源的优势与挑战
- **优势**：清洁能源，几乎无限的燃料来源（氘和氚），能量密度高。
- **挑战**：技术难度大，成本高，商业化周期长。

### 1.2.1 当前主要的核聚变研究方向
目前，核聚变技术主要分为磁约束聚变和惯性约束聚变两大类：

| 技术方向 | 磁约束聚变 | 惯性约束聚变 |
|----------|------------|------------|

目前，国际上最著名的核聚变实验装置是国际热核聚变实验堆（ITER）。ITER的目标是通过磁约束聚变技术，实现可控的核聚变反应。
