# 第一部分: 格雷厄姆投资理论与数字市场背景

## 第1章: 格雷厄姆投资理论的核心原理

### 1.1 价值投资的定义与原则

- **价值投资的核心理念**：寻找市场价格低于内在价值的股票，长期持有，等待市场重新评估。
- **安全边际的概念**：买入价格与内在价值之间的差距，作为抵御市场波动的保护屏障。
- **格雷厄姆的选股标准**：关注基本面稳定、财务健康、估值合理的公司。

### 1.2 数字市场的特点与挑战

- **数字市场的定义**：指通过电子交易平台进行的金融资产交易，包括股票、加密货币、ETF等。
- **数字市场的波动性**：高波动性源于算法交易、高频交易和市场参与者的多样性。
- **信息传播的即时性**：数字市场中的信息传播速度快，影响市场情绪和价格波动。

# 第二部分: 格雷厄姆策略的动态调整方法

## 第3章: 微观结构周期的分析与预测

### 3.1 微观结构周期的阶段划分

- **上升周期**：市场情绪乐观，价格持续上涨，投资者信心增强。
- **下降周期**：市场情绪转向悲观，价格下跌，投资者信心下降。
- **平衡周期**：市场处于震荡状态，价格波动幅度较小，投资者情绪趋于中性。

### 3.2 周期分析的技术方法

- **技术分析工具**：
  - 移动平均线（MA）：用于判断价格趋势。
  - 相对强弱指数（RSI）：用于判断超买超卖状态。
  - 成交量分析：用于验证价格趋势的强度。

### 3.3 周期预测的数学模型

- **模型简介**：基于时间序列分析的ARIMA模型，用于预测价格走势。
- **公式示例**：
  $$ ARIMA(p, d, q) $$
  其中，p为自回归阶数，d为差分阶数，q为移动平均阶数。
