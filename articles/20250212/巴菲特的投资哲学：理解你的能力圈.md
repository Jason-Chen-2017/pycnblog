  ```python
  def calculate_ability_circle(portfolio):
      total_assets = sum(portfolio.values())
      correct_decisions = 0
      for asset in portfolio:
          if asset.risk < 0.2:
              correct_decisions += 1
      return correct_decisions / len(portfolio)
  ```
