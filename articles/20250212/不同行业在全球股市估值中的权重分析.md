## 第2章：行业权重分析的核心概念

### 2.1 行业权重的定义与计算方法

#### 2.1.1 行业权重的定义

行业权重是指某个行业在股票市场指数中的市值占比。计算公式为：

$$
\text{行业权重} = \frac{\text{行业总市值}}{\text{市场总市值}}
$$

行业权重反映了该行业对市场整体表现的影响力。权重越高的行业，对市场指数的影响越大。

#### 2.1.2 行业权重的分类与特点

行业可以按多种标准分类，如行业类型（科技、金融、消费等）和市场区域（美国、欧洲、亚洲）。以下是不同行业的特点对比：

| 行业类型   | 特点                          | 权重特征                     |
|------------|-------------------------------|------------------------------|
| 科技       | 市值高，增长快                 | 权重通常较高                 |
| 金融       | 市值稳定，收益依赖利息收入     | 权重较高，尤其是在发达市场   |
| 消费       | 与日常生活密切相关             | 权重较为分散，波动较小       |
| 能源       | 受能源价格影响较大             | 权重波动较大，周期性明显     |

## 第3章：行业权重分析的数学模型与算法

### 3.1 行业权重分析的数学模型

#### 3.1.1 行业权重的加权平均模型

行业权重的计算基于加权平均数模型。假设市场中有 $n$ 个行业，每个行业的市值为 $S_i$，市场总市值为 $S_{\text{total}}$，则行业权重 $w_i$ 为：

$$
w_i = \frac{S_i}{S_{\text{total}}}
$$

#### 3.1.2 行业权重的动态调整模型

考虑到市场波动，行业权重需要动态调整。动态调整模型如下：

$$
w_i(t+1) = w_i(t) \times (1 + \alpha \times \Delta S_i)
$$

其中，$\alpha$ 是调整系数，$\Delta S_i$ 是行业市值的变化率。

#### 3.2.2 行业权重分析的Python代码实现

以下是基于上述算法的Python代码实现：

```python
import pandas as pd

# 假设df为行业数据，包含行业名称和市值
def calculate_sector_weights(df):
    total_market_cap = df['市值'].sum()
    sector_weights = {}
    for sector in df['行业名称'].unique():
        sector_cap = df[df['行业名称'] == sector]['市值'].sum()
        sector_weights[sector] = sector_cap / total_market_cap
    return sector_weights

# 示例数据
data = {
    '行业名称': ['科技', '金融', '消费', '能源'],
    '市值': [500, 300, 200, 100]
}
df = pd.DataFrame(data)

# 计算权重
weights = calculate_sector_weights(df)
print(weights)
```

### 5.1 实战案例：科技行业的权重分析

#### 5.1.2 核心代码实现

以下是科技行业权重分析的代码：

```python
import pandas as pd
import matplotlib.pyplot as plt

# 示例数据
data = {
    '行业名称': ['科技', '金融', '消费', '能源'],
    '市值': [500, 300, 200, 100]
}
df = pd.DataFrame(data)

# 计算权重
def calculate_sector_weights(df):
    total_market_cap = df['市值'].sum()
    sector_weights = {}
    for sector in df['行业名称'].unique():
        sector_cap = df[df['行业名称'] == sector]['市值'].sum()
        sector_weights[sector] = sector_cap / total_market_cap
    return sector_weights

weights = calculate_sector_weights(df)

# 可视化
sectors = list(weights.keys())
values = [weights[sector] for sector in sectors]

plt.bar(sectors, values)
plt.title('行业权重分布')
plt.ylabel('权重')
plt.show()
```
