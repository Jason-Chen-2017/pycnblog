### 第2章：核心概念分析

#### 2.1 区块链技术的核心原理
区块链的基本概念  
区块链是一种分布式账本技术，通过去中心化的方式记录数据，确保数据的不可篡改性和可追溯性。每个区块包含数据和哈希指针，确保数据链的完整性。

分布式账本与共识机制  
分布式账本由多个节点维护，共识机制（如PoW、PoS）确保所有节点达成一致，避免数据冲突。共识机制是区块链安全性和可靠性的基石。

智能合约的工作原理  
智能合约是区块链上的自动执行程序，用于在满足特定条件时自动触发操作。在医疗数据交换中，智能合约可以用于自动化数据传输和权限管理。

#### 5.2 核心代码实现
以下是核心代码实现：

```python
from hashlib import sha256
from time import time

class Block:
    def __init__(self, index, timestamp, data, prev_hash):
        self.index = index
        self.timestamp = timestamp
        self.data = data
        self.prev_hash = prev_hash
        self.hash = self.calculate_hash()

    def calculate_hash(self):
        return sha256(str(self.index) + str(self.timestamp) + str(self.data) + str(self.prev_hash)).hexdigest()

class Blockchain:
    def __init__(self):
        self.blocks = []
        self.create_genesis_block()

    def create_genesis_block(self):
        genesis_block = Block(0, time(), "Initial Block", "0")
        self.blocks.append(genesis_block)

    def add_block(self, data):
        last_block = self.blocks[-1]
        new_block = Block(last_block.index + 1, time(), data, last_block.hash)
        self.blocks.append(new_block)
```

代码解读与分析  
上述代码定义了一个简单的区块链结构，包括区块类和区块链类。区块类包含索引、时间戳、数据和哈希值，而区块链类负责创建初始区块和添加新区块。通过这种方式，我们可以实现数据的不可篡改性和可追溯性。
