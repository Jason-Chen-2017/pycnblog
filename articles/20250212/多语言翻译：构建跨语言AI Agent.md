```python
from transformers import AutoTokenizer, AutoModelForSeq2Seq
tokenizer = AutoTokenizer.from_pretrained("facebook/m2m-large-4m")
model = AutoModelForSeq2Seq.from_pretrained("facebook/m2m-large-4m")
```

#### 5.2.2 翻译函数的实现
```python
def translate(source_text, target_lang):
    inputs = tokenizer(source_text, return_tensors="pt")
    outputs = model.generate(**inputs, forced_bos_token_id=tokenizer.get_lang_id(target_lang))
    return tokenizer.decode(outputs[0], skip_special_tokens=True)
```

#### 5.2.3 系统交互界面的实现
```python
def main():
    while True:
        source_lang = input("请输入源语言：")
        target_lang = input("请输入目标语言：")
        text = input("请输入要翻译的文本：")
        translated = translate(text, target_lang)
        print(f"翻译结果：{translated}")
```
