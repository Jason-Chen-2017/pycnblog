### 2.1 量子密钥分发协议

1. **密钥生成**：Alice向Bob发送一系列量子态，Bob进行测量。
2. **基选择**：Alice和Bob分别选择测量基，并进行比较。
3. **密钥筛选**：仅保留使用相同基测量的结果。
4. **误差检测**：通过对比部分密钥检测潜在的窃听。

BB84协议的数学模型可以用量子态的叠加和纠缠来描述：

$$ | \psi \rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) $$

#### 2.3.2 量子加密算法的代码实现
以下是量子加密算法的简单代码实现示例（Python）：

```python
import random

def generate_key():
    # 生成随机密钥
    key = random.choice([0, 1])
    return key

def encrypt(message, key):
    # 简单的加密算法
    encrypted = []
    for bit in message:
        encrypted_bit = bit ^ key
        encrypted.append(encrypted_bit)
    return encrypted

def decrypt(encrypted, key):
    # 解密算法
    decrypted = []
    for bit in encrypted:
        decrypted_bit = bit ^ key
        decrypted.append(decrypted_bit)
    return decrypted
```
