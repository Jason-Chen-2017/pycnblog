## 1.1 AI Agent的基本概念

### 1.1.1 AI Agent的定义与特点

AI Agent（人工智能代理）是一种能够感知环境、自主决策并执行任务的智能实体。其特点包括自主性、反应性、目标导向和社交能力。

### 1.1.2 智能餐桌的定义与应用场景

智能餐桌是一种结合物联网和AI技术的餐桌系统，能够通过传感器和AI算法分析用餐者的饮食习惯、偏好和健康状况，提供个性化的用餐建议和餐厅优化方案。

### 1.1.3 用餐行为分析的重要性

用餐行为分析通过收集和分析用餐者的行为数据，帮助餐厅优化服务流程、提升客户满意度并降低成本。

#### 代码实现

```python
from sklearn.neighbors import KNeighborsClassifier
import numpy as np

# 示例数据
X = np.array([[1, 2], [2, 3], [3, 4], [4, 5]])
y = np.array([0, 0, 1, 1])

# 模型训练
knn = KNeighborsClassifier(n_neighbors=3)
knn.fit(X, y)

# 预测
new_data = np.array([[2, 2]])
print(knn.predict(new_data))  # 输出预测结果
```

#### 数学公式

$$
\text{距离} = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}
