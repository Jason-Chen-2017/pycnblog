## 第一部分: 格雷厄姆投资理念概述

### 第1章: 格雷厄姆及其投资哲学

#### 1.1 格雷厄姆的生平简介
本杰明·格雷厄姆（Benjamin Graham）是20世纪著名的投资大师，被誉为“价值投资之父”。他在1929年美国股市大崩盘后，发展出一套稳健的价值投资理论，强调以低于内在价值的价格购买优质资产。

#### 1.2 格雷厄姆的投资哲学核心
格雷厄姆的核心理念是“安全边际”，即买入价格远低于内在价值的资产，以降低风险并确保收益。

#### 1.3 格雷厄姆与价值投资的关系
格雷厄姆是价值投资的鼻祖，其方法影响了包括巴菲特在内的众多投资者。他强调深入分析和安全边际的重要性。

### 第2章: 优先股的基本概念

#### 2.1 优先股的定义与特点
优先股是混合型证券，具有固定股息率和优先的股息分配权。与普通股相比，优先股风险较低，回报稳定。

#### 2.2 优先股与普通股的对比
| 特性      | 优先股                 | 普通股                 |
|-----------|------------------------|------------------------|
| 股息      | 固定，优先分配          | 不固定，后分配          |
| 权益      | 优先                   | 次优先                |
| 风险      | 较低                   | 较高                   |

#### 2.3 优先股的投资价值
优先股的稳定收益和较高的股息率使其成为保守投资者的理想选择，尤其适合追求稳定收入的投资者。

### 第3章: 格雷厄姆优先股投资策略的核心原理

#### 3.1 安全边际的数学模型
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$
安全边际是衡量投资风险的重要指标，确保在市场波动中仍能获得正收益。

#### 3.2 内在价值的计算方法
使用股息折现法：
$$ \text{内在价值} = \frac{\text{股息}}{\text{折现率}} $$

#### 3.3 优先股投资的决策流程
1. 确定投资目标
2. 选择优质优先股
3. 估值与安全边际计算
4. 构建投资组合

#### 5.2 核心实现代码
```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(dividend, discount_rate):
    return dividend / discount_rate

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
dividend = 5
discount_rate = 0.05
market_price = 40

iv = calculate_intrinsic_value(dividend, discount_rate)
mos = calculate_margin_of_safety(iv, market_price)

print(f"内在价值: {iv:.2f}")
print(f"安全边际: {mos:.2f}")
```
