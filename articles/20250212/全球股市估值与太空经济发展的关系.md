# 第2章：全球股市估值的核心原理

## 2.1 核心原理

### 2.1.1 股市估值的基本原理
股市估值是通过对股票价格的评估，判断市场的整体价值。常用指标包括市盈率（P/E）和市净率（P/B），反映了市场的盈利能力和资产价值。

### 2.1.2 主要估值指标与方法
- 市盈率（P/E）：衡量股票价格与每股收益的比例。
- 市净率（P/B）：衡量股票价格与每股净资产的比例。

## 2.2 核心概念的数学模型

### 2.2.1 市盈率（P/E）公式
$$ P/E = \frac{Stock Price}{Earnings Per Share} $$

### 2.2.2 市净率（P/B）公式
$$ P/B = \frac{Stock Price}{Book Value Per Share} $$

# 第6章：项目实战

## 6.1 项目介绍

### 6.1.1 环境安装
使用Python 3.8及以上版本，安装Pandas、NumPy、Matplotlib和Scikit-learn库。

### 6.1.2 系统核心实现源代码

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# 数据加载
df_stock = pd.read_csv('stock_data.csv')
df太空经济 = pd.read_csv('space_economy.csv')

# 数据预处理
df_stock['Date'] = pd.to_datetime(df_stock['Date'])
df_经济 = df太空经济.set_index('Date')

# 合并数据
merged_data = pd.merge(df_stock['Close'], df_经济['Revenue'], on='Date')

# 回归分析
model = LinearRegression()
X = merged_data[['Revenue']]
y = merged_data['Close']
model.fit(X, y)

# 预测
predicted_close = model.predict(X)
plt.plot(y, color='blue', label='Actual')
plt.plot(predicted_close, color='red', label='Predicted')
plt.xlabel('Date')
plt.ylabel('Stock Close Price')
plt.legend()
plt.show()
```
