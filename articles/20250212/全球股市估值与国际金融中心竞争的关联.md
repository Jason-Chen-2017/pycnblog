## 第4章: 数学模型

### 4.1 CAPM模型
$$E(r_i) = r_f + \beta_i (E(r_m) - r_f)$$

### 4.2 应用示例
假设无风险利率 \( r_f = 3\% \)，市场预期回报率 \( E(r_m) = 8\% \)，贝塔系数 \( \beta_i = 1.5 \)，则：
$$E(r_i) = 0.03 + 1.5 \times (0.08 - 0.03) = 0.095 = 9.5\%$$

import pandas as pd
from sklearn.metrics import mean_squared_error

# 加载数据
data = pd.read_csv('financial_data.csv')

# 划分训练集和测试集
train = data[:-30]

# 训练模型

# 预测与评估

print(mean_squared_error(test['Stock_Valuation'], predictions))
