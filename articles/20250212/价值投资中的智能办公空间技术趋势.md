# 6. 项目实战

## 6.1 环境安装
安装Python和相关库，如pandas、numpy。

## 6.2 核心代码实现
```python
import pandas as pd

def calculate_value(revenue, cost):
    return revenue / cost

data = pd.DataFrame({
    '收益': [100000, 80000],
    '成本': [50000, 40000]
})

data['价值'] = data.apply(lambda x: calculate_value(x['收益'], x['成本']), axis=1)
print(data)
```
