- Python代码示例：
```python
from sklearn.cluster import KMeans
import pandas as pd
data = pd.read_csv('emergency_data.csv')
features = data[['lat', 'lon']]
model = KMeans(n_clusters=5)
model.fit(features)
```

#### 4.2 数学模型

$$ R = \sum_{i=1}^{n} (p_i \times c_i) $$
