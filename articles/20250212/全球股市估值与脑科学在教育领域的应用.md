### 5.2 核心代码实现

#### 5.2.1 数据预处理
```python
import pandas as pd
from sklearn.preprocessing import StandardScaler

# 加载数据
df = pd.read_csv('stock_data.csv')

# 数据清洗
df.dropna(inplace=True)

# 特征提取
features = df[['open', 'high', 'low', 'volume']]
labels = df['close']

# 数据标准化
scaler = StandardScaler()
features_scaled = scaler.fit_transform(features)
```

#### 5.2.2 模型训练
```python
from sklearn.linear_model import LinearRegression
from sklearn.neural_networks import MLPRegressor

# 线性回归模型
lr_model = LinearRegression()
lr_model.fit(features_scaled, labels)

# 多层感知机模型
mlp_model = MLPRegressor(hidden_layer_sizes=(100, 2))
mlp_model.fit(features_scaled, labels)
```

#### 5.2.3 模型预测
```python
import numpy as np

# 预测股票价格
predicted_prices_lr = lr_model.predict(new_features_scaled)
predicted_prices_mlp = mlp_model.predict(new_features_scaled)
```
