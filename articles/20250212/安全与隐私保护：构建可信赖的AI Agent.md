## 第3章 安全与隐私保护的核心技术原理

### 3.1 数据加密与隐私保护

#### 3.1.1 同态加密原理
同态加密允许在密文上进行计算，确保数据加密状态下仍能处理。

#### 3.1.2 隐私保护的数学模型
$$ E(x) = x \cdot e \mod p $$
$$ D(E(x)) = x \cdot e^{-1} \mod p $$

#### 3.1.3 数据加密的实现流程
1. 数据加密：使用公钥加密数据。
2. 数据处理：在密文上进行计算。
3. 结果解密：还原明文结果。

#### 3.1.4 同态加密的Python实现
```python
class HomomorphicEncryption:
    def __init__(self, p, e):
        self.p = p
        self.e = e

    def encrypt(self, x):
        return (x * self.e) % self.p

    def decrypt(self, enc):
        return (enc * pow(self.e, -1, self.p)) % self.p
```

### 3.2 差分隐私与数据脱敏

#### 3.2.1 差分隐私的定义与原理
差分隐私通过在数据中添加噪声，确保查询结果无法推断单个数据点。

#### 3.2.2 数据脱敏技术的实现
对敏感数据进行变形处理，如替换、遮盖等，防止数据泄露。

#### 3.2.3 差分隐私与数据脱敏的对比
| 技术 | 差分隐私 | 数据脱敏 |
|------|-----------|----------|
| 目标 | 防止数据推断 | 防止数据泄露 |
| 方法 | 添加噪声 | 数据变形 |

#### 3.2.4 差分隐私的Python实现
```python
import numpy as np

def add_noise(data, noise_level):
    noise = np.random.laplace(0, noise_level, data.shape)
    return data + noise
```
