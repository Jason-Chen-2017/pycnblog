#### 4.1.3 量子算法的实现代码
```python
import numpy as np
from qiskit import QuantumCircuit, execute, Aer

def quantum_algorithm():
    circuit = QuantumCircuit(2)
    circuit.h(0)
    circuit.cnot(0, 1)
    circuit.measure_all()
    return circuit

algorithm = quantum_algorithm()
backend = Aer.get_backend('qasm_simulator')
job = execute(algorithm, backend)
result = job.result()
print(result.counts)
```
