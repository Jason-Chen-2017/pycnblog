```

import pandas as pd

df = pd.DataFrame(data)

df = df.astype('float')
```

##### 5.2.3 数据分析模块
```python
from sklearn.cluster import KMeans

X = df[['revenue', 'profit']]
model = KMeans(n_clusters=3)
model.fit(X)
clusters = model.labels_
```

##### 5.2.4 可视化模块
```python
import matplotlib.pyplot as plt

```
