# 第二部分：全球股市估值理论与模型

## 2.1 股市估值的核心概念
### 2.1.1 股票估值的基本原理
股票估值是基于公司财务状况、行业地位和市场前景的评估，常用市盈率（P/E）和现金流折现模型（DCF）等方法。

### 2.1.2 主要估值方法对比
| 方法 | 描述 | 优缺点 |
|------|------|--------|
| P/E | 市盈率 | 简单直观，但受市场波动影响大 | 
| P/B | 市净率 | 更适合评估资产-heavy行业，但忽略收益能力 | 
| DCF | 现金流折现模型 | 精确但计算复杂，需准确预测现金流 |

### 2.1.3 影响股市估值的关键因素
- 宏观经济指标（GDP、利率）
- 公司财务数据（收入、利润）
- 市场情绪和投资者行为

## 2.2 常用的股市估值模型
### 2.2.1 市盈率模型（P/E）
$$ P/E = \frac{股价}{每股收益} $$
- 优点：简单易懂，适用于周期性行业。
- 缺点：受市场波动影响较大。

### 2.2.2 市净率模型（P/B）
$$ P/B = \frac{股价}{每股净资产} $$
- 适用于银行、房地产等资产-heavy行业。

### 2.2.3 现金流折现模型（DCF）
$$ DCF = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n} $$
- 优点：精确预测未来现金流。
- 缺点：计算复杂，依赖假设。

### 6.2.2 估值模型实现
```python
# 现金流折现模型
def dcf_model(data, discount_rate=0.05):
    dcf = []
    for i in range(len(data)):
        if i < 5:
            dcf.append(data.iloc[i]['Close'])
        else:
            dcf.append(data.iloc[i]['Close'] / (1 + discount_rate)**i)
    return np.sum(dcf)
```
