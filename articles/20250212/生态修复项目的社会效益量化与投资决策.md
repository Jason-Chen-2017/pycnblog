## 第一部分：生态修复项目背景与概念

### 第1章：生态修复的基本概念

#### 1.1 生态修复的定义与内涵

生态修复是指通过人为干预，恢复被破坏的生态系统，使其达到或接近自然状态的过程。它包括土地恢复、水资源修复、生物多样性保护等多个方面。

**1.1.1 生态修复的定义**

生态修复不仅仅是环境治理，更是一个系统工程，涉及技术、经济和社会等多个维度。通过生态修复，可以改善生态环境，提升生态系统服务功能。

**1.1.2 生态修复的核心内涵**

- **生态功能恢复**：修复生态系统的生产功能、调节功能和文化功能。
- **可持续性**：确保修复后的生态系统能够自我维持，具备抗干扰能力。
- **多目标性**：生态修复通常涉及多个目标，如防洪、固碳、提供栖息地等。

**1.1.3 生态修复的分类与特点**

生态修复可以分为土地修复、水资源修复、生物多样性修复等类型。其特点包括：区域性、长期性、综合性和经济性。

### 第2章：社会效益量化的核心概念

#### 2.1 社会效益量化的基本原理

社会效益量化是将生态修复项目对社会产生的正面影响转化为可测量的指标，以便进行比较和决策。

**2.1.1 量化的基本概念**

社会效益量化通过设定指标体系，将生态修复的环境、社会和经济影响进行量化评估。

**2.1.2 量化的方法与步骤**

1. **指标体系设计**：选择关键指标，如就业机会、健康改善、生态服务价值等。
2. **数据收集**：通过问卷调查、文献分析等方式获取数据。
3. **权重确定**：根据指标的重要性赋予权重，通常使用层次分析法（AHP）。

**2.1.3 量化模型的选择与应用**

选择合适的模型是关键。层次分析法（AHP）因其科学性和可操作性，被广泛应用于社会效益量化。

### 第4章：层次分析法（AHP）的应用

#### 4.1 层次分析法的基本原理

层次分析法是一种定性和定量相结合的决策分析方法，适用于多目标决策问题。

**4.1.1 层次分析法的步骤**

1. **构建层次结构模型**：将问题分解为目标层、准则层和方案层。
2. **构造判断矩阵**：根据专家意见，确定各准则的权重。
3. **计算权重**：通过一致性检验，确定各准则的权重。

**4.1.2 层次分析法的优缺点**

- **优点**：直观、易于理解，适用于复杂问题。
- **缺点**：依赖专家判断，可能引入主观因素。

**层次分析法的Python实现**

```python
import numpy as np

def calculate_weights(matrix):
    # 计算权重向量
    n = matrix.shape[0]
    weights = np.zeros(n)
    for i in range(n):
        row = matrix[i]
        total = sum(row)
        weights[i] = sum([row[j] / total for j in range(n)]) / n
    return weights

# 示例判断矩阵
matrix = np.array([
    [1, 3, 2],
    [1/3, 1, 2/3],
    [1/2, 3/2, 1]
])

weights = calculate_weights(matrix)
print("权重向量为：", weights)
```
