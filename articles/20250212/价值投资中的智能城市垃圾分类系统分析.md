# 第5章: 算法原理讲解

## 5.1 支持向量机分类算法  

### 5.1.1 算法流程图  

```mermaid
graph TD
    A[数据预处理] --> B[特征提取]
    B --> C[模型训练]
    C --> D[分类预测]
    D --> E[结果输出]
```

### 5.1.2 算法实现代码  

```python
import numpy as np
from sklearn import svm

# 数据预处理
X = np.array([[0, 0], [1, 1], [2, 2], [3, 3]])
y = [0, 1, 1, 0]

# 模型训练
model = svm.SVC()
model.fit(X, y)

# 分类预测
new_data = np.array([[2.5, 2.5]])
print(model.predict(new_data))
```

## 5.2 聚类分析算法  

### 5.2.1 算法流程图  

```mermaid

    B --> C[聚类分析]
```

### 5.2.2 算法实现代码  

```python
from sklearn.cluster import KMeans

# 数据预处理
X = np.array([[1, 2], [3, 4], [5, 6], [7, 8]])

# 模型训练
model = KMeans(n_clusters=2)
model.fit(X)

# 分类预测
print(model.labels_)
```
