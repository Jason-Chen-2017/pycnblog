## 第一部分：格雷厄姆特价股票策略的背景与理论基础

### 第1章：格雷厄姆的投资理念

#### 1.1 投资的基本原理

格雷厄姆的价值投资理念强调安全边际和内在价值。他认为，股票不仅是企业的一部分权益，更是可以计算的数字。通过分析企业的财务数据，投资者可以找到市场价格低于其真实价值的股票，即特价股票。

#### 1.2 格雷厄姆特价股票策略的核心要素

- **安全边际**：安全边际是市场价格与内在价值之间的差距，公式为：
  $$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$
  当安全边际为正时，股票具有投资价值。

- **内在价值**：格雷厄姆提出了内在价值的计算公式：
  $$ \text{内在价值} = \frac{\text{每股收益} \times (5 + \text{长期增长率})}{\text{资本成本}} $$
  该公式考虑了企业的盈利能力、成长性和资本成本。

- **市场情绪与周期**：格雷厄姆认为市场情绪会影响股票价格，投资者应关注市场周期，避免受短期波动影响。

#### 1.3 理论基础

格雷厄姆的价值投资理论基于以下几点：
1. **安全边际的重要性**：通过购买低于内在价值的股票，降低投资风险。
2. **内在价值的计算**：通过基本面分析评估企业的真实价值。
3. **市场情绪的影响**：市场恐慌或狂热时，价格与价值脱节，提供投资机会。

### 第2章：格雷厄姆特价股票策略的理论基础

#### 2.1 安全边际的数学模型

安全边际是格雷厄姆策略的核心，公式为：
$$ \text{安全边际} = \frac{\text{内在价值}}{\text{市场价格}} - 1 $$

当安全边际超过20%时，股票具有投资吸引力。

#### 2.2 内在价值的评估方法

格雷厄姆采用保守的估值方法，主要考虑企业的账面价值和未来盈利能力。内在价值公式为：
$$ \text{内在价值} = \text{每股账面价值} \times (1 + \text{预期增长率}) $$

#### 2.3 市场情绪与周期分析

格雷厄姆强调长期投资，避免短期市场波动。他将市场周期分为四个阶段：
1. **复苏阶段**：市场逐渐恢复，价值股开始反弹。
2. **牛市阶段**：市场情绪高涨，股价高于内在价值。
3. **熊市阶段**：市场恐慌，股价低于内在价值。
4. **震荡阶段**：市场波动不定，投资者应保持谨慎。

#### 4.1 牛市环境下的表现

- **优势**：在牛市中，格雷厄姆策略可能错过部分高增长股，但在市场顶部时，其防御性较强。

- **优势**：熊市中，许多股票价格大幅下跌，价值股往往被低估，提供投资机会。
- **风险**：需警惕市场恐慌导致的过度抛售，避免错杀优质股。

import numpy as np

def calculate_intrinsic_value(df):
    df['Intrinsic Value'] = df['Earnings Per Share'] * (5 + df['Growth Rate']) / df['Cost of Capital']
    return df

    df['Margin of Safety'] = df['Intrinsic Value'] - df['Price']
    return df
