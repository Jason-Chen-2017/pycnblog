# 第1章: 特价股票投资概述

## 1.1 特价股票投资的基本概念

### 1.1.1 特价股票的定义与特点
特价股票是指价格相对较低、具有投资潜力的股票。其特点包括：
- 价格低廉：通常指股价低于市场平均水平的股票。
- 投资潜力大：这些股票可能因为市场低估或公司基本面改善而具有上涨空间。
- 风险较高：低价股票往往伴随着较高的波动性和不确定性。

### 1.1.2 特价股票投资的背景与现状
随着金融市场的发展，投资者对低价股票的兴趣逐渐增加。深度学习技术的兴起为特价股票投资提供了新的可能性。当前，深度学习在金融领域的应用已经取得了显著成果，尤其是在股票价格预测和投资决策方面。

### 1.1.3 特价股票投资的核心问题与目标
核心问题包括数据噪声大、市场波动剧烈、投资策略复杂等。目标是通过深度学习模型，优化投资策略，提高收益并降低风险。

# 第2章: 深度学习模型的基础

## 2.1 神经网络的基本原理

### 2.1.1 神经网络的定义与组成
神经网络由输入层、隐藏层和输出层组成，通过多层非线性变换模拟人类神经网络的结构。

### 2.1.2 神经网络的训练过程
训练过程包括前向传播和反向传播，通过损失函数优化模型参数。

### 2.1.3 激活函数与损失函数
常用的激活函数包括ReLU、Sigmoid和Tanh。损失函数如均方误差（MSE）和交叉熵损失用于衡量预测值与真实值的差异。
