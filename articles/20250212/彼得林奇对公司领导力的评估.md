## 3.2 彼得林奇领导力评估模型

### 3.2.1 模型构建

#### 3.2.1.1 层次分析法（AHP）
使用层次分析法来评估领导力的各个维度，权重计算公式：
$$
w_i = \frac{\sum \lambda_{ij}}{\sum \lambda_{ik}}
$$

#### 3.2.1.2 模型构建流程
1. 确定评估维度。
2. 构建评估指标体系。
3. 计算各维度权重。
4. 综合评估得分。

#### 3.2.1.3 模型的数学表达
领导力评估模型的综合得分计算公式：
$$
S = \sum_{i=1}^{n} w_i x_i
$$
其中，\( w_i \) 为第i个维度的权重，\( x_i \) 为第i个维度的评估得分。

### 3.2.2 模型实现

#### 3.2.2.2 核心代码实现
```python
import numpy as np
from sklearn.preprocessing import normalize

# 定义评估指标
criteria = ['战略思维', '团队协作', '问题解决']

# 计算权重
weights = np.array([0.4, 0.3, 0.3])
weights = normalize(weights)

# 计算综合得分
def calculate_score(leader_scores):
    return np.dot(leader_scores, weights)

# 示例数据
leader_scores = np.array([0.8, 0.7, 0.9])
score = calculate_score(leader_scores)
print("综合得分:", score)
```

### 5.2.1 评估模型实现

```python
import numpy as np
from sklearn.preprocessing import normalize

# 定义评估指标
criteria = ['战略思维', '团队协作', '问题解决']

# 计算权重
weights = np.array([0.4, 0.3, 0.3])
weights_normalized = normalize(weights)

# 计算综合得分
def calculate_score(leaders_scores):
    return np.dot(leaders_scores, weights_normalized)

# 示例数据
leaders = ['CEO1', 'CEO2', 'CEO3']
leaders_scores = np.array([
    [0.8, 0.7, 0.9],
    [0.6, 0.8, 0.8],
    [0.7, 0.6, 0.9]
])

# 计算综合得分
scores = calculate_score(leaders_scores.T)
print("综合得分:", scores)
```
