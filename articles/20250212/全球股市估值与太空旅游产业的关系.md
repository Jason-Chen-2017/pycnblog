# 第1章: 全球股市估值的基本概念

## 1.1 股市估值的定义与影响因素

### 1.1.1 股市估值的定义  
股市估值是指通过一定方法对上市公司股票的内在价值进行评估，以确定其合理的价格区间。常见的估值方法包括市盈率（P/E）、市净率（P/B）等。

### 1.1.2 影响股市估值的主要因素  
1. **宏观经济因素**：GDP增速、利率、通货膨胀等。  
2. **企业基本面**：盈利能力、成长性、财务状况。  
3. **市场情绪**：投资者信心、市场流动性。  
4. **政策因素**：政府政策、行业监管。  

### 1.1.3 股市估值的主要指标与方法  
- **市盈率（P/E）**：股价/每股净利润。  
- **市净率（P/B）**：股价/每股净资产。  
- **股息率**：每股股息/股价。  

## 1.2 太空旅游产业的定义与现状

### 1.2.1 太空旅游的定义  
太空旅游是指普通人乘坐航天器进入太空进行观光或科研活动，目前主要由商业公司推动。

### 1.2.2 太空旅游产业的现状与发展趋势  
- **现状**：SpaceX、Blue Origin等公司主导，市场仍处起步阶段。  
- **趋势**：技术进步、成本下降、市场需求增加。  

### 1.2.3 太空旅游的主要参与者与商业模式  
- **参与者**：SpaceX、Blue Origin、 Virgin Galactic等。  
- **商业模式**：门票销售、政府合作、技术授权。
