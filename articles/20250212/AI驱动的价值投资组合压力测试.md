## 第1章: 价值投资组合压力测试概述

### 1.1 问题背景

#### 1.1.1 投资组合风险评估的重要性  
在金融市场中，投资组合的价值受多种因素影响，包括市场波动、经济指标、公司基本面等。准确评估投资组合在极端情况下的表现，对于投资者和机构至关重要。传统的方法依赖于历史数据和统计模型，但其局限性日益显现。

### 3.3 算法实现代码

```python
import numpy as np
import pandas as pd
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout
from sklearn.preprocessing import MinMaxScaler

# 数据预处理
data = pd.read_csv('stock_data.csv')
data = data['Close'].values
data = data.reshape(-1, 1)

# 特征提取
window_size = 30
X = []
y = []
for i in range(len(data) - window_size):
    X.append(data[i:i+window_size])
    y.append(data[i+window_size])
X = np.array(X)
y = np.array(y)

# 数据标准化
scaler = MinMaxScaler()
X_scaled = scaler.fit_transform(X)
X_scaled = X_scaled.reshape(X_scaled.shape[0], X_scaled.shape[1], 1)
y_scaled = scaler.fit_transform(y.reshape(-1, 1))

# 模型训练
model = Sequential()
model.add(LSTM(64, input_shape=(window_size, 1)))
model.add(Dropout(0.2))
model.add(Dense(1))
model.compile(loss='mean_squared_error', optimizer='adam')
model.fit(X_scaled, y_scaled, epochs=50, batch_size=32)

# 模型评估
预测值 = model.predict(X_scaled)
```
