### 第一部分：背景介绍

#### 第1章：大卫·斯文森及其投资理念

##### 1.1 大卫·斯文森的背景与成就

- **教育背景**：斯文森于1986年获得麻省理工学院（MIT）物理学博士学位。
- **职业成就**：1986年加入耶鲁大学，负责管理捐赠基金，将耶鲁的捐赠基金从1.3亿美元增长至60亿美元，年均回报率超过10%。

##### 1.2 基金会投资模式的起源

- **背景**：20世纪80年代，斯文森加入耶鲁大学时，捐赠基金规模较小，投资策略保守。
- **改革**：斯文森引入了新的投资策略，包括长期持有、价值投资和多样化资产配置。

##### 1.3 长期价值投资的核心理念

- **长期投资**：避免短期波动，注重长期价值。
- **价值投资**：寻找被市场低估的资产，长期持有，等待价值回归。

### 第三部分：算法原理与数学模型

#### 第3章：现代投资组合理论与应用

##### 3.1 现代投资组合理论（MPT）概述

- **核心假设**：投资者是理性的，追求收益最大化，厌恶风险。
- **有效前沿**：所有可能的投资组合中，收益最高、风险最低的组合。

##### 3.2 风险调整后的收益评估

- **夏普比率**：衡量投资组合的超额收益与风险之比。
  - 公式：$$夏普比率 = \frac{E[r_p] - r_f}{\sigma_p}$$
  - 其中，$E[r_p]$为投资组合的期望收益，$r_f$为无风险利率，$\sigma_p$为投资组合的波动率。

##### 5.2 核心实现源代码

```python
import pandas as pd
import numpy as np

# 示例数据：假设我们有股票A和股票B的回报率
returns = pd.DataFrame({
    '股票A': [0.1, 0.05, -0.02],
    '股票B': [0.08, 0.0, 0.03]
})

# 计算投资组合的期望收益和波动率
weights = [0.5, 0.5]
expected_return = (returns.mean() * weights).sum()
covariance_matrix = returns.cov()
portfolio_variance = (weights.T.dot(covariance_matrix)).dot(weights)
portfolio_volatility = np.sqrt(portfolio_variance)

print(f'期望收益: {expected_return:.2%}')
print(f'波动率: {portfolio_volatility:.2%}')
```

- **代码功能**：计算投资组合的期望收益和波动率，展示如何优化资产配置。
