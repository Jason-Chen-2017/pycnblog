## 第一部分：股票估值模型的背景与基础

### 第1章：股票估值模型的背景介绍

#### 1.1 什么是股票估值

股票估值是确定股票内在价值的过程，旨在通过分析公司的财务状况、行业地位、盈利能力等因素，评估其股票的合理价格。格雷厄姆作为价值投资的鼻祖，提出了基于内在价值和安全边际的股票估值方法，为投资者提供了科学的指导。

#### 1.2 股票估值的重要性

- **投资决策的基础**：准确的估值帮助投资者判断股票是否被高估或低估。
- **风险控制的关键**：通过估值确定安全边际，降低投资风险。
- **长期收益的保障**：格雷厄姆的防御性投资策略强调长期持有优质股票，避免短期波动的影响。

### 第2章：格雷厄姆的防御性投资策略

#### 2.1 防御性投资的基本原则

格雷厄姆倡导防御性投资，强调以下原则：

- **长期投资**：避免频繁交易，降低交易成本和税务负担。
- **安全边际**：买入价格低于内在价值，确保足够的安全空间。
- **价值导向**：关注企业的基本面，而非市场情绪。

#### 2.2 格雷厄姆的内在价值计算方法

格雷厄姆提出了现金流折现法（DCF）来计算内在价值。通过预测未来现金流并将其折现到现值，确定股票的合理价格。

**公式：**
$$
DCF = \sum_{i=1}^{n} \frac{CF_i}{(1 + r)^i}
$$
其中，$CF_i$为第i年的现金流，$r$为折现率，$n$为预测年数。

import pandas as pd
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(cash_flows / (1 + discount_rate)**i for i in range(len(cash_flows)))

# 示例数据
