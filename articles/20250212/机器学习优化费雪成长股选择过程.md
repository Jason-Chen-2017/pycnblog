# 第3章: 机器学习算法原理与数学模型

## 3.1 常用机器学习算法概述
### 3.1.1 线性回归
- 简单线性回归模型：$$y = \beta_0 + \beta_1x + \epsilon$$
- 多重线性回归模型：$$y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon$$

### 3.1.2 支持向量机
- 分类问题：将数据映射到高维空间，寻找最优分割超平面。
- $$C$$ 是惩罚系数，$$\gamma$$ 是核函数参数。

### 3.1.3 随机森林
- 集成学习方法，通过投票或平均的方式提高模型准确性。
- 每棵树的特征选择方式为随机采样。

### 3.1.4 XGBoost
- 增量决策树模型，通过贪心算法选择最优分割特征。
- 使用二阶导数作为损失函数的优化目标。

## 3.3 随机森林算法实现
### 3.3.1 随机森林算法原理
- 通过随机采样构建多棵决策树。
- 最终结果通过投票或平均得到。

### 3.3.2 随机森林的数学模型
- 特征重要性评分公式：$$importance_i = \sum_{j=1}^{n} (node\_impurity\_reduction \times frequency)$$
- 其中，$$n$$ 是树的数量，$$node\_impurity\_reduction$$ 是每棵树中该特征带来的信息增益。

### 3.3.3 特征重要性评分
- 特征重要性评分可以用于筛选关键特征。

## 3.4 XGBoost算法实现
### 3.4.1 XGBoost算法原理
- 使用二阶导数作为损失函数的优化目标。
- 每一步优化目标函数：$$L_i = \sum_{i=1}^{n} [(-g_i h_i) + \frac{1}{2} (h_i)^2]$$
- 其中，$$g_i$$ 是一阶导数，$$h_i$$ 是二阶导数。

### 3.4.2 XGBoost的数学模型
- 增量决策树模型，通过贪心算法选择最优分割特征。
- 每一步优化目标函数为：$$\text{loss} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
- $$\hat{y}_i$$ 是模型预测值，$$y_i$$ 是真实值。

### 3.4.3 模型调优
- 参数包括：学习率（$$\eta$$）、树的深度（$$max\_depth$$）、正则化系数（$$lambda$$）等。

### 5.2.1 数据预处理

```python
import pandas as pd
import numpy as np

# 加载数据
df = pd.read_csv('stocks.csv')

# 处理缺失值
df.dropna(inplace=True)

# 标准化处理
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
df[['revenue', 'net_profit', 'roe']] = scaler.fit_transform(df[['revenue', 'net_profit', 'roe']])
```

### 5.2.2 特征选择
```python
from sklearn.feature_selection import SelectFromModel
from sklearn.ensemble import RandomForestClassifier

# 选择重要特征
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(df[['revenue', 'net_profit', 'roe', 'market_share']], df['target'])

selector = SelectFromModel(model, threshold='median')
selected_features = selector.transform(df)
```

### 5.2.3 模型训练与评估
```python
from xgboost import XGBClassifier

# 训练模型
model = XGBClassifier(n_estimators=100, learning_rate=0.1, max_depth=3)
model.fit(selected_features, df['target'])

# 评估模型
from sklearn.metrics import accuracy_score
y_pred = model.predict(selected_features)
print("Accuracy:", accuracy_score(df['target'], y_pred))
```
