- 5.2.1 数据加载与特征工程
  ```python
  import pandas as pd
  data = pd.read_csv('credit_swap_data.csv')
  features = data[['credit_rating', 'market_spread', 'issuer_size']]
  target = data['default_probability']
  ```

- 5.2.2 模型训练与参数估计
  ```python
  from sklearn.linear_model import LinearRegression
  model = LinearRegression()
  model.fit(features, target)
  ```

- 5.2.3 模型验证与优化
  ```python
  import numpy as np
  predicted = model.predict(features)
  rmse = np.sqrt(np.mean((predicted - target)**2))
  print(f'RMSE: {rmse}')
  ```
