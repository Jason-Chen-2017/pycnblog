##### 2.1 核心概念的定义与原理
- 2.1.1 目标函数
  - 收益函数：$f(x) = \sum w_i r_i$
  - 风险函数：$g(x) = \sum w_i^2 \sigma_i^2$
  - 多目标优化函数：$h(x) = \alpha f(x) + (1-\alpha) g(x)$
- 2.1.2 约束条件
  - 资产权重约束：$\sum w_i = 1$, $w_i \geq 0$
  - 风险约束：$\text{VaR} \leq \text{threshold}$
  - 收益约束：$\text{Return} \geq \text{target}$
- 2.1.3 优化变量
  - 资产权重：$w_1, w_2, ..., w_n$
  - 资产选择：选与不选的二进制变量

##### 2.2 核心概念的对比分析
- 2.2.1 传统优化方法与智能优化方法的对比
  | 方法       | 优点                     | 缺点                     |
  |------------|--------------------------|--------------------------|

#### 第3章：优化算法的原理与流程

##### 3.1 优化算法的原理与流程
- 3.1.1 遗传算法的原理
  - 初始化种群
  - 计算适应度
  - 选择、交叉、变异

- 3.1.2 模拟退火算法的原理

  - 扰动状态

- 3.1.3 粒子群优化算法的原理
  - 初始化粒子群
  - 计算个体最优
  - 更新全局最优
  - 更新粒子位置与速度

##### 3.3 优化算法的数学模型
- 遗传算法：
  - 适应度函数：$f(x) = \sum w_i r_i$
  - 交叉操作：$w_{new} = w_i \times \alpha + w_j \times (1-\alpha)$
- 模拟退火：
  - 能量函数：$E(x) = \sum w_i^2 \sigma_i^2$
  - 转移概率：$P = \exp(-\Delta E / T)$
- 粒子群优化：
  - 速度更新：$v_{i} = v_{i} \times \alpha + \beta_1 r_1 \times (p_{best} - x_i) + \beta_2 r_2 \times (g_{best} - x_i)$
  - 位置更新：$x_{i} = x_{i} + v_{i}$

##### 3.4 优化算法的Python实现示例
```python
def genetic_algorithm():
    # 初始化种群
    population = initialize_population()
    while not terminate:
        # 计算适应度
        fitness = calculate_fitness(population)
        # 选择
        selected = selection(population, fitness)
        # 交叉

        # 变异

        population = crossed + mutated
```
