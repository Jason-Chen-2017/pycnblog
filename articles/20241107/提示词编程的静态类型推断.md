## 8. 案例分析
### 8.1 实际案例
考虑一个电商平台的购物车系统，其中包含商品类型和数量。使用静态类型推断可以帮助我们确保数据的正确性。

```typescript
class ShoppingCart {
    private items: Map<string, number>;

    constructor() {
        this.items = new Map();
    }

    add(item: string, quantity: number): void {
        this.items.set(item, quantity);
    }

    getTotalPrice(): number {
        return Array.from(this.items.values()).reduce((acc, quantity) => acc + quantity, 0);
    }
}

const cart = new ShoppingCart();
cart.add("Apple", 10);
cart.add("Banana", 5);

console.log(cart.getTotalPrice()); // 输出：15
```

在这个例子中，`add`方法的参数`item`被推断为字符串类型，`quantity`被推断为数字类型。这确保了购物车中的商品类型和数量的正确性。
