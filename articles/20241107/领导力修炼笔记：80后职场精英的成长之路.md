#### 领导力的基本理论
领导力并非天生具备，而是可以通过学习和实践不断培养的。以下是几个关键的领导力理论和模型：

**1. 领导风格**
领导风格是领导者与下属互动的方式。根据情境的不同，领导风格可以分为以下几种：
- **独裁式领导**：领导者做出所有决策，下属执行。
  ```pseudo
  function autocraticLeadership() {
    leaderMakesAllDecisions();
    subordinatesExecute();
  }
  ```
- **民主式领导**：领导者与下属共同参与决策。
  ```pseudo
  function democraticLeadership() {
    leaderProposesDecisions();
    subordinatesDiscussAndContribute();
  }
  ```

**2. 领导力模型**
- **领导力冰山模型**：领导力由三个层次构成：知识技能、自我认知和外部行为。
  $$
  \text{领导力} = (\text{知识技能} + \text{自我认知}) - \text{外部行为}
  $$
- **情境领导模型**：领导者的风格应根据下属的能力和情境进行灵活调整。
  ```pseudo
  function situationalLeadership() {
    if (subordinatesAreHighlyCompetent()) {
      leaderUsesSupportiveStyle();
    } else if (subordinatesAreLessCompetent()) {
      leaderUsesDirectingStyle();
    }
  }
  ```
