$$\text{韵律分布} = \frac{\text{满足特定韵律的音步数}}{\text{总音步数}}$$

该公式用于计算特定韵律模式在整首诗中的出现频率。

**5.2 系统核心实现源代码**

以下是系统核心实现的源代码示例：

```python
import numpy as np
from mermaid import Mermaid

def preprocess_text(verse):
    """
    对诗歌文本进行预处理
    """
    # 去除标点符号
    verse = verse.replace(".", "")
    verse = verse.replace(",", "")
    verse = verse.replace("?", "")
    return verse

def extract_rhyme_features(processed_verse):
    """
    提取诗歌的韵律特征
    """
    # 以空格分隔文本
    words = processed_verse.split(" ")
    
    # 计算每个音步的长度
    syllable_lengths = [len(word) for word in words]
    rhythm_scheme = np.diff(syllable_lengths)
    
    return rhythm_scheme

def build_rhyme_model(rhyme_features):
    """
    建立韵律模型
    """
    # 计算平均音步长度
    avg_rhythm_length = np.mean(rhyme_features)
    
    # 计算标准差
    std_rhythm_length = np.std(rhyme_features)
    
    return avg_rhythm_length, std_rhythm_length

def analyze_rhyme_scheme(rhyme_model):
    """
    分析韵律模式
    """
    avg_rhythm_length, std_rhythm_length = rhyme_model
    
    # 输出分析结果
    result = f"平均音步长度：{avg_rhythm_length}\n标准差：{std_rhythm_length}"
    return result

def main():
    verse = "这是一首美丽的诗歌，每一行都有它独特的韵律。"
    processed_verse = preprocess_text(verse)
    rhyme_features = extract_rhyme_features(processed_verse)
    rhyme_model = build_rhyme_model(rhyme_features)
    analysis_result = analyze_rhyme_scheme(rhyme_model)
    print(analysis_result)

if __name__ == "__main__":
    main()
```

**5.3 代码应用解读与分析**

在上面的代码中，我们首先对诗歌文本进行预处理，去除标点符号，然后提取每个音步的长度。接着，我们计算平均音步长度和标准差，建立韵律模型。最后，我们分析韵律模式，输出分析结果。
