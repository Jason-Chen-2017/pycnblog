```python
import numpy as np
import matplotlib.pyplot as plt

# 定义反应扩散方程
def reaction_diffusion(x, y, dx, dy, dt, k):
    u = np.zeros((x.shape[0], y.shape[0]))
    u[1:-1, 1:-1] = (1 / (dx * dy)) * (k * (x[1:-1, 1:-1] * y[1:-1, 1:-1] - x[1:-1, 1:-1] * y[1:-1, 2:] - x[2:, 1:-1] * y[1:-1, 1:-1] + x[2:, 1:-1] * y[1:-1, 2:] + x[1:-1, 2:] * y[2:, 1:-1] - x[1:-1, 2:] * y[2:, 2:] + x[2:, 2:] * y[1:-1, 1:-1] - x[2:, 2:] * y[1:-1, 2:] + x[2:, 2:] * y[2:, 2:] - x[1:-1, 2:] * y[2:, 2:] + x[2:, 1:-1] * y[2:, 2:]))
    return u

# 求解反应扩散方程
def solve_reaction_diffusion(x, y, dx, dy, dt, k, t_max):
    t = 0
    while t < t_max:
        u = reaction_diffusion(x, y, dx, dy, dt, k)
        x += dx * dt
        y += dy * dt
        t += dt
    return u

# 画图
def plot_solution(u):
    plt.imshow(u, cmap='hot', interpolation='nearest')
    plt.colorbar()
    plt.show()

# 参数设置
x = np.linspace(0, 1, 100)
y = np.linspace(0, 1, 100)
dx = dy = 0.01
dt = 0.001
t_max = 1
k = 0.1

# 求解并画图
u = solve_reaction_diffusion(x, y, dx, dy, dt, k, t_max)
plot_solution(u)
```

**算法原理**：
反应扩散方程描述了物质在空间中的扩散和反应过程。本文使用有限差分法来求解反应扩散方程，通过迭代计算得到物质浓度分布。求解过程包括以下几个步骤：
1. 初始化物质浓度。
2. 利用有限差分公式计算下一个时间步的物质浓度。
3. 更新物质浓度。
4. 重复步骤2和3直到达到最大时间步。

**数学模型和公式**：

$$
u_t = D \nabla^2 u + f(u)
$$

其中，$u$表示物质浓度，$D$表示扩散系数，$\nabla^2$表示拉普拉斯算子，$f(u)$表示反应项。

**举例说明**：
假设一个水体受到污染物A的影响，我们使用反应扩散方程来模拟污染物A在水体中的扩散过程。通过求解反应扩散方程，可以得到污染物A在不同时间和空间位置的浓度分布。这有助于预测污染物对生态系统的影响。
