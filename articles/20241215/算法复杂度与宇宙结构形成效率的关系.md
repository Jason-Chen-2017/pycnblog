算法复杂度是评估算法性能的关键指标，它帮助我们理解算法在处理不同规模输入数据时的时间消耗和空间占用。算法复杂度分为时间复杂度和空间复杂度两大类。

### 时间复杂度

时间复杂度描述了算法执行时间与输入规模之间的关系。通常，我们使用大O符号（\(O\)）来表示时间复杂度。常见的表示方式有：

- **\(O(n)\)**：线性时间复杂度，表示算法执行时间与输入规模成正比。
- **\(O(n^2)\)**：平方时间复杂度，表示算法执行时间与输入规模的平方成正比。
- **\(O(2^n)\)**：指数时间复杂度，表示算法执行时间随输入规模呈指数增长。

例如，一个简单的冒泡排序算法的时间复杂度为\(O(n^2)\)，因为算法需要遍历输入数组两次，每次比较相邻元素，时间复杂度随着输入规模的增加而急剧增长。

### 空间复杂度

空间复杂度描述了算法在执行过程中所需存储空间的增长速度。与时间复杂度类似，我们使用大O符号来表示空间复杂度。常见的表示方式有：

- **\(O(n)\)**：线性空间复杂度，表示算法所需存储空间与输入规模成正比。
- **\(O(n^2)\)**：平方空间复杂度，表示算法所需存储空间与输入规模的平方成正比。
- **\(O(1)\)**：常数空间复杂度，表示算法所需存储空间不随输入规模变化。

例如，一个简单的线性查找算法的空间复杂度为\(O(1)\)，因为它只需要一个常数大小的存储空间来保存当前比较的元素。

### 算法复杂度的计算

算法复杂度的计算通常基于算法的基本操作次数。我们可以通过以下步骤来计算算法的时间复杂度和空间复杂度：

1. **基本操作定义**：确定算法中的基本操作，例如比较、赋值、递归调用等。
2. **操作次数估计**：估计每个基本操作在算法中执行的次数，通常基于输入规模。
3. **总操作次数计算**：将每个基本操作的次数相加，得到算法的总操作次数。
4. **复杂度表示**：使用大O符号表示总操作次数与输入规模的关系。

例如，对于冒泡排序算法，基本操作为比较和交换，每个元素需要与其他元素比较\(n-1\)次，总共有\(n\)个元素，因此总比较次数为\(n(n-1)/2\)，时间复杂度为\(O(n^2)\)。

### 宇宙结构形成效率概述

宇宙结构形成效率是指在宇宙膨胀过程中，物质和能量在空间中分布和聚集的速率和效率。这一概念对于理解宇宙的演化过程至关重要，它涵盖了从宇宙大爆炸以来，星系、星团、甚至超星团的形成过程。

#### 定义

宇宙结构形成效率通常被定义为特定区域内物质和能量聚集的速度与该区域内的引力相互作用速率之比。用数学语言描述，可以表示为：

\[ \text{效率} = \frac{\text{聚集速度}}{\text{引力相互作用速率}} \]

其中，聚集速度是指物质和能量在空间中聚集的速度，而引力相互作用速率则是指区域内物质和能量之间由于引力而产生的相互作用速度。

2. **星系分布**：通过观测星系的分布和运动，可以推断出宇宙结构形成的历史和当前状态。
3. **引力透镜效应**：引力透镜效应是由于大质量物体（如星系团）对光线的弯曲作用，通过分析引力透镜效应，可以测量宇宙中暗物质的存在和分布。

宇宙结构形成效率受到多种因素的影响，包括：

1. **初始条件**：宇宙的初始密度波动是结构形成的基础，这些波动决定了物质在空间中的分布。
2. **暗物质**：暗物质不发光，但通过引力作用影响宇宙结构形成，其分布对宇宙结构形成效率有重要影响。
3. **引力相互作用**：宇宙中的引力相互作用是物质聚集的主要驱动力，其速率和强度直接影响结构形成效率。
4. **宇宙膨胀**：宇宙膨胀改变了物质之间的距离和相互作用，对结构形成效率产生重要影响。

#### 关键过程

宇宙结构形成的关键过程包括：

1. **星系形成**：星系是在宇宙膨胀过程中由气体和尘埃聚集形成的，这些物质在引力作用下逐渐聚集形成星系。

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = bubble_sort(arr)
print(sorted_arr)
```

#### 时间复杂度公式

首先，让我们回顾一下时间复杂度的基本公式。时间复杂度通常用于衡量算法执行时间与输入规模之间的关系。以下是一个常见的时间复杂度公式：

$$
T(n) = O(n^2)
$$

这个公式表示，算法的执行时间与输入规模的平方成正比。例如，如果我们考虑一个简单的冒泡排序算法，其基本操作包括比较和交换两个元素。在每次迭代中，未排序部分的最大元素将被移动到最后，因此需要进行\(n-1\)次迭代。每次迭代需要比较相邻的元素，共需要比较\((n-1) + (n-2) + ... + 1 = \frac{n(n-1)}{2}\)次。这可以表示为：

$$
T(n) = \frac{n(n-1)}{2}
$$

当 \(n\) 增加时，\(T(n)\) 的增长速度将非常快。这意味着随着输入规模的增加，算法的执行时间将急剧增加。

#### 空间复杂度公式

除了时间复杂度，我们还需要考虑空间复杂度。空间复杂度衡量的是算法在执行过程中所需存储空间的大小。以下是一个常见的空间复杂度公式：

$$
S(n) = O(n)
$$

这个公式表示，算法所需存储空间与输入规模成正比。例如，考虑一个简单的线性查找算法，它需要存储一个数组来存储待查找的元素。假设数组的大小为 \(n\)，那么所需的存储空间即为 \(n\) 个元素的大小。
