#### 2.1.1 拓扑空间的概念

拓扑空间是拓扑学中的基本概念，可以看作是连续变换下的不变集合。一个拓扑空间由一个集合和定义在这个集合上的一个拓扑结构组成。拓扑结构通过一组开集来定义，这些开集需要满足以下性质：

- 空集和整个集合是开集。
- 开集的任意并集是开集。
- 开集的任意有限交集是开集。

在宇宙拓扑缺陷的研究中，拓扑空间的概念帮助我们描述和分类宇宙中的复杂结构。

#### 2.1.2 连通性与紧致性

连通性是拓扑空间的一个基本性质，描述了空间中的两点是否可以通过连续路径相互连接。具体来说，一个拓扑空间是连通的，如果它不能被分割为两个非空不相交的闭集。连通性在描述宇宙拓扑缺陷的连接性方面非常重要。

紧致性是另一个重要的拓扑性质，描述了空间中的点是否密集排列。在拓扑空间中，一个集合是紧致的，如果它的任意开覆盖都有有限子覆盖。紧致性在宇宙拓扑缺陷的研究中帮助我们理解这些结构的稳定性和演化行为。

```python
import networkx as nx
import numpy as np

def update_node_position(graph):
    """
    根据引力规则更新图中的节点位置。
    """
    positions = nx.get_node_attributes(graph, 'pos')
    # 计算节点之间的引力中心
    new_positions = {}
    for node in graph.nodes():
        forces = []
        for neighbor in graph.neighbors(node):
            distance = np.linalg.norm(np.array(positions[node]) - np.array(positions[neighbor]))
            force = 1 / distance  # 假设引力与距离成反比
            forces.append(force * (np.array(positions[neighbor]) - np.array(positions[node])))
        if forces:
            # 计算引力中心
            new_position = np.sum(np.array(forces), axis=0) / len(forces)
            new_positions[node] = new_position
        else:
            new_positions[node] = positions[node]
    nx.set_node_attributes(graph, new_positions, 'pos')
    return graph
```

在这个示例中，`detect_defects`函数使用Kuratowski定理检测图中的连通性，以确定是否存在拓扑缺陷。`simulate_dynamics`函数模拟拓扑缺陷的动力学演化，通过更新节点位置来模拟引力作用。`update_node_position`函数根据引力规则更新节点位置，用于动力学模拟。
