##### 3.2 Decision-Making Skills

Decision-making is a critical skill for leaders. It involves evaluating options, weighing potential outcomes, and making choices that align with organizational goals.

**Python Code Example: Decision-Making Algorithm**

```python
def make_decision(options, criteria, weights):
    scores = {}
    for option in options:
        score = 0
        for criterion in criteria:
            score += option[criterion] * weights[criterion]
        scores[option] = score
    return max(scores, key=scores.get)

# Example usage
options = ["Option A", "Option B", "Option C"]
criteria = ["Cost", "Time", "Quality"]
weights = {"Cost": 0.2, "Time": 0.3, "Quality": 0.5}

decision = make_decision(options, criteria, weights)
print(f"The best decision is {decision}.")
```

This code provides a simple algorithm for decision-making, taking into account various criteria and their relative importance.
