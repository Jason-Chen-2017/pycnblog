## 第2章：光学系统的核心概念与联系

### 2.1 波前与光学传递函数

#### 2.1.1 波前的定义与特征

波前是指光波在传播过程中，相位相同的点所组成的面。波前是描述光波空间和时间分布的重要物理量。波前的形状和相位决定了光波的性质，如光的强度分布、干涉和衍射等。

波前的特征包括：

1. **形状**：波前的形状可以用数学函数描述，如Zernike多项式。
2. **相位**：波前的相位决定了光波的干涉和衍射行为。
3. **频率**：波前的频率与光的波长相关，决定了光的颜色。

#### 2.1.2 光学传递函数的基本概念

光学传递函数（OTF）是描述光学系统对光波传输能力的数学函数。它反映了光学系统对光波的空间频率响应，即系统对光波频率的传递特性。

光学传递函数的主要特性包括：

1. **频率响应**：光学传递函数描述了光学系统对不同频率的光波的传输能力。
2. **幅值响应**：光学传递函数的幅值响应决定了光学系统的能量传递效率。
3. **相位响应**：光学传递函数的相位响应决定了光波的相位变化。

#### 2.1.3 波前与光学传递函数的关系

波前与光学传递函数之间存在密切的联系。波前可以通过光学传递函数来描述，而光学传递函数又可以通过波前来确定。具体来说：

1. **波前的傅里叶变换**：波前可以通过傅里叶变换得到光学传递函数。
2. **光学传递函数的逆傅里叶变换**：光学传递函数可以通过逆傅里叶变换得到波前。

波前与光学传递函数的关系可以用以下公式表示：

$$ OTF(\omega) = \mathcal{F} \{ W(x,y) \} $$

$$ W(x,y) = \mathcal{F}^{-1} \{ OTF(\omega) \} $$

其中，$OTF(\omega)$ 是光学传递函数，$W(x,y)$ 是波前，$\omega$ 是空间频率。

### 2.2 光学像差与Zernike多项式

#### 2.2.1 光学像差的定义与分类

光学像差是指光学系统在成像过程中，由于波前的畸变，导致成像质量下降的现象。光学像差可以分为以下几类：

1. **球面像差**：由于球面镜或透镜的球面形状，导致光线的聚焦点不在理想位置。
2. **彗差**：由于光学系统边缘部分的光线没有正确聚焦，导致成像中心出现彗星形状。
3. **像散**：由于光学系统的不同部分对光线的聚焦能力不一致，导致成像出现散斑。
4. **畸变**：光学系统的非球面形状导致的成像畸变，如桶形畸变和枕形畸变。

#### 2.2.2 Zernike多项式的概念与性质

Zernike多项式是一组正交多项式，用于描述光学系统的像差。Zernike多项式的表达式如下：

$$ P_{mn}(x,y) = R_{mn}(\rho) \exp(i\phi_{mn}(\rho)) $$

其中，$R_{mn}(\rho)$ 是径向多项式，$\phi_{mn}(\rho)$ 是角度多项式。

Zernike多项式的性质包括：

1. **正交性**：Zernike多项式在单位圆内是正交的，即内积为零。
2. **完备性**：Zernike多项式可以表示任何在单位圆内连续的光学像差函数。
3. **旋转不变性**：Zernike多项式对于旋转操作是不变的。

#### 2.2.3 Zernike多项式在光学像差分析中的应用

Zernike多项式在光学像差分析中的应用非常广泛。通过将光学系统的波前用Zernike多项式展开，可以方便地分析和优化光学系统的成像质量。

具体应用包括：

1. **像差测量**：利用Zernike多项式，可以将光学系统的波前分解为各个Zernike项，从而测量出光学像差。
2. **像差校正**：通过调整光学系统的参数，使Zernike多项式的系数最小，从而校正光学像差。
3. **性能评估**：利用Zernike多项式，可以评估光学系统的成像质量，如调制传递函数（MTF）。

#### 3.1 Zernike多项式

Zernike多项式是一组正交多项式，用于描述光学系统的像差。在光学系统设计中，Zernike多项式被广泛应用于像差分析、像差校正和性能评估。

**Zernike多项式的定义：**

Zernike多项式可以表示为：

$$ P_{mn}(x,y) = R_{mn}(\rho) \exp(i\phi_{mn}(\rho)) $$

其中，$R_{mn}(\rho)$ 是径向多项式，$\phi_{mn}(\rho)$ 是角度多项式。

**Zernike多项式的性质：**

1. **正交性：**Zernike多项式在单位圆内是正交的，即内积为零。
2. **完备性：**Zernike多项式可以表示任何在单位圆内连续的光学像差函数。
3. **旋转不变性：**Zernike多项式对于旋转操作是不变的。

**Zernike多项式在光学系统设计中的应用：**

1. **像差分析：**利用Zernike多项式，可以将光学系统的波前分解为各个Zernike项，从而测量出光学像差。
2. **像差校正：**通过调整光学系统的参数，使Zernike多项式的系数最小，从而校正光学像差。
3. **性能评估：**利用Zernike多项式，可以评估光学系统的成像质量，如调制传递函数（MTF）。

**Python代码示例：**

```python
import numpy as np
from scipy.special import sph herbs
from matplotlib import pyplot as plt

# Zernike多项式定义
def zernike_moments(m, n, radius):
    r = np.arange(0, radius + 1)
    theta = np.pi * np.arange(0, radius) / radius
    Pmn = (1 / (2 * np.pi)) * (sph herbs.mv(2 * np.pi * r / radius, n) * np.cos(m * theta) + sph herbs.mv(2 * np.pi * r / radius, n) * np.sin(m * theta))
    return Pmn

# 计算并绘制Zernike多项式
radius = 4
m = 0
n = 2
Pmn = zernike_moments(m, n, radius)
x = np.linspace(-radius, radius, 100)
y = np.linspace(-radius, radius, 100)
X, Y = np.meshgrid(x, y)
Z = Pmn(X**2 + Y**2)

plt.imshow(Z, extent=(-radius, radius, -radius, radius), origin='lower')
plt.colorbar()
plt.title(f'Zernike Polynomial P_{m+n}({m},{n})')
plt.xlabel('x')
plt.ylabel('y')
plt.show()
```

#### 3.2 最小二乘法

最小二乘法是一种常见的优化方法，用于求解数据拟合问题。在光学系统设计中，最小二乘法可以用于优化光学系统的参数，使其满足特定的设计要求。

**最小二乘法的基本原理：**

最小二乘法的目标是找到一组参数，使得测量值与理论值之间的误差平方和最小。具体来说，给定一组数据点$(x_i, y_i)$，我们需要找到一组参数$(\theta_1, \theta_2, \ldots, \theta_n)$，使得目标函数：

$$ J(\theta) = \sum_{i=1}^n (y_i - f(x_i; \theta))^2 $$

取最小值。

**最小二乘法的求解步骤：**

3. **求解线性方程组：**利用雅可比矩阵，求解线性方程组，得到最优参数。
4. **迭代优化：**利用迭代算法，如梯度下降法，进一步优化参数。

#### 4.1 光学系统设计的数学模型

光学系统的数学模型主要包括波前模型、光学传递函数模型和像差模型。这些模型描述了光学系统的波前特性、成像质量和光学像差。

**波前模型：**

波前模型描述了光波的相位分布和振幅分布。常用的波前模型包括Zernike多项式和Seidel多项式。

**Zernike多项式模型：**

$$ W(x,y) = \sum_{m=0}^M \sum_{n=0}^N C_{mn} P_{mn}(x,y) $$

其中，$C_{mn}$ 是Zernike系数，$P_{mn}(x,y)$ 是Zernike多项式。

**光学传递函数模型：**

光学传递函数（OTF）描述了光学系统对空间频率的响应。

$$ OTF(\omega_x, \omega_y) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} W(x,y) e^{-i2\pi(\omega_x x + \omega_y y)} dx dy $$

**像差模型：**

像差模型描述了光学系统在成像过程中产生的像差，如球面像差、彗差、像散和畸变。

#### 4.2 主要数学公式介绍
