## 核心概念

### 期望效用理论

期望效用理论（Expected Utility Theory）是经济学和心理学中用于分析决策过程的经典模型。该理论假设，个体在面临多个选择时，会根据每个选择的可能结果及其概率，计算出期望效用，并选择期望效用最高的选项。

#### 概念属性特征对比表格

| 特征        | 期望效用理论       | 最大化收益理论       |
| ----------- | ----------------- | ----------------- |
| 基础概念    | 效用和概率         | 收益和成本         |
| 前提假设    | 个体是理性决策者   | 个体是最大化收益者   |
| 适用范围    | 风险决策          | 非风险决策          |
| 决策过程    | 考虑不确定性       | 考虑确定性          |

## 数学模型

### 概率模型

概率模型（Probability Model）是用于描述随机事件及其发生可能性的数学模型。在购买决策中，概率模型可以帮助我们分析消费者对不同产品的偏好程度，并预测其购买概率。

#### 算法原理讲解

概率模型的核心在于概率分布函数（Probability Distribution Function, PDF），它描述了随机变量在某个区间内取值的概率。常见的概率分布包括正态分布、伯努利分布等。

#### Python源代码

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义概率分布函数
def probability_distribution(x, mean, std):
    return (1 / (np.sqrt(2 * np.pi) * std)) * np.exp(-((x - mean) ** 2) / (2 * std ** 2))

# 示例数据
mean = 0
std = 1

# 计算概率分布
x = np.linspace(mean - 3 * std, mean + 3 * std, 100)
pdf = probability_distribution(x, mean, std)

# 绘制概率分布图
plt.plot(x, pdf)
plt.title("Normal Distribution")
plt.xlabel("x")
plt.ylabel("PDF")
plt.show()
```

#### 数学模型和公式

概率模型中的核心公式是概率质量函数（Probability Mass Function, PMF）或概率密度函数（Probability Density Function, PDF）。以正态分布为例：

$$
PDF(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

其中，$\mu$ 是均值，$\sigma^2$ 是方差。

### 效用理论

效用理论（Utility Theory）是经济学中用于描述个体偏好和决策行为的理论。在购买决策中，效用理论可以帮助我们量化消费者的偏好，并预测其购买行为。

#### 算法原理讲解

效用理论的核心是期望效用（Expected Utility, EU），它通过加权求和的方法，将不同结果的效用转化为一个综合得分。

#### Mermaid流程图

```mermaid

    A[Start] --> B[Define Utility Function]
    B --> C[Calculate Expected Utility]
    C --> D[Make Decision]
    D --> E[End]
```

#### Python源代码

```python
import numpy as np

# 定义效用函数
def utility(x):
    return max(0, 1 - abs(x))

# 示例数据
probabilities = [0.2, 0.5, 0.3]
outcomes = [-10, 0, 10]

# 计算期望效用
expected_utility = np.sum([p * utility(o) for p, o in zip(probabilities, outcomes)])

# 输出结果
print("Expected Utility:", expected_utility)
```

#### 数学模型和公式

期望效用的计算公式为：

$$
EU = \sum_{i=1}^{n} p_i \cdot u_i
$$

其中，$p_i$ 是第 $i$ 个结果的概率，$u_i$ 是第 $i$ 个结果的效用值。

## 心理因素

### 情感与购买决策

情感是消费者在购买决策过程中不可或缺的一部分。研究表明，情感可以显著影响消费者的购买决策，使其偏离理性选择。

#### 数学模型应用

通过引入情感因素，我们可以对期望效用模型进行扩展。例如，可以考虑使用情感强度来调整效用值，从而更准确地反映消费者的真实偏好。

#### 数学模型和公式

扩展后的期望效用公式为：

$$
EU = \sum_{i=1}^{n} p_i \cdot (u_i + \alpha \cdot e_i)
$$

其中，$e_i$ 表示第 $i$ 个结果的情感强度，$\alpha$ 是情感权重系数。

### 社会影响力与购买决策

社会影响力，如群体效应和名人效应，对消费者的购买决策也有显著影响。社会影响力可以通过数学模型进行量化，从而更好地理解其在购买决策中的作用。

#### 数学模型应用

社会影响力可以被视为一种外部因素，通过调整概率模型中的概率分布，我们可以模拟社会影响力对消费者购买决策的影响。

#### 数学模型和公式

考虑社会影响力的概率模型可以表示为：

$$
p_i' = p_i \cdot (1 + \beta \cdot s_i)
$$

其中，$s_i$ 是社会影响力的强度，$\beta$ 是社会影响力的权重系数。
