#### 3.2 数学模型和公式

磁单极子分布的数学模型通常基于概率密度函数（PDF）来描述。以下是一个基本的概率密度函数示例：

$$ P(x) = \frac{1}{Z} \int_{-\infty}^{\infty} f(x') dx' $$

其中，\( P(x) \) 是位置 \( x \) 处的磁单极子概率，\( Z \) 是归一化常数，\( f(x') \) 是磁单极子密度函数。

在具体实现中，我们可以使用高斯分布或其他合适的分布模型来近似磁单极子的分布。以下是一个高斯分布的数学模型：

$$ P(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} $$

其中，\( \mu \) 是均值，\( \sigma \) 是标准差。

```python
import numpy as np
import matplotlib.pyplot as plt

# 初始化磁单极子位置
def initialize_particles(num_particles, bounds):
    x = np.random.uniform(bounds[0], bounds[1], num_particles)
    y = np.random.uniform(bounds[0], bounds[1], num_particles)
    return x, y

# 计算高斯分布概率密度
def calculate_gaussian_pdf(x, mu, sigma):
    return (1 / (np.sqrt(2 * np.pi * sigma**2))) * np.exp(-((x - mu)**2) / (2 * sigma**2))

# 计算分布概率
def calculate_distribution(x, mu, sigma):
    probabilities = [calculate_gaussian_pdf(xi, mu, sigma) for xi in x]
    return probabilities

# 生成分布图表
def generate_distribution_chart(x, probabilities):
    plt.bar(x, probabilities)
    plt.xlabel('X坐标')
    plt.ylabel('概率密度')
    plt.title('磁单极子分布示例')
    plt.show()

# 主函数
def main():
    num_particles = 1000
    bounds = (0, 10)
    mu = 5
    sigma = 2

    x, y = initialize_particles(num_particles, bounds)
    probabilities = calculate_distribution(x, mu, sigma)
    generate_distribution_chart(x, probabilities)

if __name__ == "__main__":
    main()
```

3. **计算分布概率**：`calculate_distribution` 函数使用`calculate_gaussian_pdf` 函数计算每个粒子的概率密度，并将其汇总为一个概率列表。
