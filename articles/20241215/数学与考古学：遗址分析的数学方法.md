#### 3.2 数学模型

数学模型是描述考古现象的数学表达式，用于揭示考古数据中的内在规律。以下是一些常用的数学模型：

##### 3.2.1 模型公式

一个常见的数学模型是线性回归模型，用于分析考古变量之间的关系。其公式如下：

$$
Y = \beta_0 + \beta_1X + \epsilon
$$

其中，$Y$表示因变量，$X$表示自变量，$\beta_0$和$\beta_1$是模型的参数，$\epsilon$是误差项。

##### 3.2.2 模型特性

1. **线性**：线性回归模型假设因变量和自变量之间存在线性关系。
2. **最小二乘法**：模型参数通过最小化误差平方和来确定。
3. **可解释性**：模型的参数具有明确的物理或文化意义。

##### 3.2.3 模型推导

线性回归模型的推导基于最小二乘法。具体推导过程如下：

1. **假设**：假设因变量$Y$和自变量$X$之间满足线性关系。
2. **建立目标函数**：目标函数为误差平方和，即
$$
J(\beta_0, \beta_1) = \sum_{i=1}^n (Y_i - (\beta_0 + \beta_1X_i))^2
$$
3. **求导**：对目标函数求导，并令导数为零，得到：
$$
\frac{\partial J}{\partial \beta_0} = -2\sum_{i=1}^n (Y_i - (\beta_0 + \beta_1X_i)) = 0
$$
$$
\frac{\partial J}{\partial \beta_1} = -2\sum_{i=1}^n (X_i(Y_i - (\beta_0 + \beta_1X_i))) = 0
$$
4. **解方程**：解上述方程，得到模型参数$\beta_0$和$\beta_1$。

   - 下载 MySQL 安装包（如 `mysql-8.0.23-linux-glibc2.12-x86_64.tar.gz`）。

##### 6.2.2 处理层实现

处理层实现数据处理和分析功能，以下是一个简单的 Python 代码示例：

```python
import pymysql
import numpy as np
from sklearn.cluster import KMeans

# 连接数据库
connection = pymysql.connect(host='localhost', user='root', password='password', database='Archaeology')

# 获取遗址数据
with connection.cursor() as cursor:
    cursor.execute("SELECT id, name, location FROM Sites")
    sites = cursor.fetchall()

# 提取遗址位置坐标
coords = []
for site in sites:
    cursor.execute(f"SELECT ST_AsText(location) FROM Sites WHERE id = {site[0]}")
    geom = cursor.fetchone()
    coords.append(eval(geom[0]))

# 使用 KMeans 算法进行聚类
kmeans = KMeans(n_clusters=3)
kmeans.fit(coords)

# 存储聚类结果
for i, label in enumerate(kmeans.labels_):
    with connection.cursor() as cursor:
        cursor.execute(f"UPDATE Sites SET cluster = {label} WHERE id = {sites[i][0]}")

connection.commit()
```
