```python
# app.py

from flask import Flask, render_template, request, redirect, url_for
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///community.db'
db = SQLAlchemy(app)

class Member(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)

@app.route('/')
def index():
    members = Member.query.all()
    return render_template('index.html', members=members)

@app.route('/add_member', methods=['POST'])
def add_member():
    username = request.form['username']
    email = request.form['email']
    new_member = Member(username=username, email=email)
    db.session.add(new_member)
    db.session.commit()
    return redirect(url_for('index'))

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```

- 我们首先从 Flask 和 SQLAlchemy 导入必要的模块。

- `db = SQLAlchemy(app)` 创建了 SQLAlchemy 实例。
- `Member` 类是成员的数据模型，包含 `id`、`username` 和 `email` 字段。
- `index()` 函数是网站的首页路由，它查询数据库中的所有成员，并将结果传递给模板。
- `add_member()` 函数处理添加新成员的表单提交，将新成员的信息保存到数据库。
