在旋律创作中，音律是基础。音律指的是音乐中的音高关系。在音乐理论中，音律通常以半音、全音等概念来描述。Python 中可以通过计算音程关系来实现音律。

```python
import numpy as np

# 半音关系

def compute_pitch_difference(pitch1, pitch2):
    return np.log2(pitch2 / pitch1)
```

### 数学模型与公式

在旋律创作中，数学模型和公式是不可或缺的工具。以下是一些常用的数学模型和公式：

1. **音高变换**：

   音高变换是旋律创作中的重要技巧，可以通过频率变换来实现。常用的公式有：

   $$f_2 = f_1 \times (2^{(n/12)})$$

   其中，\(f_1\) 和 \(f_2\) 分别表示原始音高和变换后的音高，\(n\) 表示半音数。

2. **节奏模式生成**：

   节奏模式生成可以通过随机生成或规则生成来实现。常用的规则有：

   - **固定节奏模式**：如全音符、二分音符、四分音符等。
   - **动态节奏模式**：如随机节奏、渐快渐慢等。

   常用的数学模型有马尔可夫链和生成对抗网络（GAN）。

3. **情感分析**：

   情感分析是旋律创作中的一项重要任务，可以通过音高、节奏和和声等元素来分析旋律的情感。常用的模型有：

   - **情感分类模型**：如支持向量机（SVM）、卷积神经网络（CNN）等。
   - **情感回归模型**：如线性回归、多项式回归等。

4. **听众反馈**：在创作过程中，可以征求他人的反馈，特别是音乐专业人士的建议，以改进旋律。
