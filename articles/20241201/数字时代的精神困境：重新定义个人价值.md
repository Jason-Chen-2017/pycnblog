### Core Algorithm and Python Code Explanation
#### Decision Tree Example
```python
# Python code for a simple decision tree

from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split
from sklearn import tree

# Load dataset
iris = load_iris()
X, y = iris.data, iris.target

# Split data into training and test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=1)

# Build decision tree model
clf = DecisionTreeClassifier()
clf.fit(X_train, y_train)

# Visualize the decision tree
tree.plot_tree(clf)
```

### Mathematical Model and Formulas
#### Expected Utility Function for Decision Models:
$$
\text{EU} = \sum_{i=1}^{n} p_i u_i(x_i)
$$
where \( p_i \) is the probability of choosing \( x_i \) and \( u_i(x_i) \) is the utility value associated with choosing \( x_i \).
