#### 2.1 科技依赖的表现

1. **手机成瘾**：手机成瘾是指个体过度使用手机，无法控制自己对手机的依赖。这种现象在现代社会中尤为普遍，许多人每天花费数小时在手机上，包括浏览社交媒体、玩游戏、观看视频等。

2. **社交媒体成瘾**：社交媒体成瘾是指个体对社交媒体平台（如Facebook、Instagram、Twitter等）的过度使用。用户可能不断刷屏，以获取新的信息和社交互动，这会导致时间管理问题、焦虑和社交隔离。

3. **电子邮件依赖**：电子邮件依赖是指个体对电子邮件的过度依赖，包括频繁检查邮件、对未读邮件的焦虑感以及对回复邮件的高度责任感。这可能导致工作效率降低、压力增加和心理健康问题。

#### 2.2 科技依赖对心理健康的影响

1. **焦虑与压力**：科技依赖可能导致焦虑和压力的增加。例如，手机成瘾者可能会因为错过通知或未及时回复消息而感到焦虑。社交媒体成瘾者可能会因为社交比较或负面评论而感到压力。

```python
import random

# 数字排毒度假村的基本设置
DORMITORY_CAPACITY = 100
DORMITORY_FEE = 500  # 每天的费用（单位：美元）

# 活动设置
ACTIVITIES = [
    "瑜伽",
    "徒步",
    "冥想",
    "阅读",
    "手工制作"
]

# 客户信息结构
class Customer:
    def __init__(self, name, arrival_time, stay_days):
        self.name = name
        self.arrival_time = arrival_time
        self.stay_days = stay_days

# 模拟一天的经营情况
def simulate_day():
    print("正在模拟一天的经营情况...")
    # 随机生成客户到达时间和预订天数
    customers = [Customer(f"客户{index}", random.randint(1, 24), random.randint(1, 7)) for index in range(DORMITORY_CAPACITY)]

    # 计算当天的收入和活动安排
    total_revenue = 0
    daily_activities = {activity: 0 for activity in ACTIVITIES}

    for customer in customers:
        if customer.arrival_time <= 24 and customer.stay_days > 0:
            total_revenue += DORMITORY_FEE * customer.stay_days
            daily_activities[random.choice(ACTIVITIES)] += 1
            customer.stay_days -= 1

    print(f"总收入：${total_revenue}")
    print("活动安排：")
    for activity, count in daily_activities.items():
        print(f"{activity}: {count}次")

# 模拟多天经营情况
def simulate_multiple_days(days):
    print(f"正在模拟{days}天的经营情况...")
    for day in range(1, days + 1):
        simulate_day()
        print(f"--------------------------------- Day {day} 结束 ---------------------------------")

# 运行模拟
simulate_multiple_days(10)
```

这段代码模拟了一个数字排毒度假村在10天内的经营情况。它随机生成客户信息，并计算当天的收入和活动安排。通过运行这段代码，我们可以得到每一天的模拟结果，从而分析数字排毒度假村的运营情况。
