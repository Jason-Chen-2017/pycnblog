在日常美学实践中，常用的数学模型包括色彩空间模型、空间布局模型等。以下是一个简单的色彩空间模型：

$$
L = \frac{1}{1 + e^{-k(L_\infty - L_0)}}
$$

其中，$L$ 表示亮度，$L_\infty$ 和 $L_0$ 分别表示白色和黑色的亮度值，$k$ 是调节亮度的参数。

通过调整参数 $k$，我们可以得到不同的亮度效果，从而实现色彩搭配的美学效果。

# 导入所需库
import matplotlib.pyplot as plt
import numpy as np

# 定义颜色空间模型
def color_space_model(L, L_inf, L_0, k):
    return (L - L_0) / (L_inf - L_0) * (1 / (1 + np.exp(-k * (L_inf - L))))

# 设置参数
L_inf = 255  # 最大亮度值
L_0 = 0     # 最小亮度值
k = 0.1    # 调节参数

# 生成亮度值
L = np.linspace(L_0, L_inf, 256)

# 计算色彩空间值
color_values = color_space_model(L, L_inf, L_0, k)

# 绘制色彩空间图
plt.plot(L, color_values)
plt.title('Color Space Model')
plt.xlabel('Brightness')
plt.ylabel('Color Value')
plt.grid(True)
plt.show()
