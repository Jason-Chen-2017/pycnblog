## 第一部分：社会正义的理论框架

### 第1章：社会正义的基本概念

### 1.1 社会正义的定义

社会正义是指社会分配公平、机会均等、权利平等的原则。它关乎社会资源的分配，包括财富、权力和机会的公平分配，以及社会成员权利的保障。

### 1.2 社会正义的重要性

社会正义关乎社会的稳定与和谐。一个缺乏社会正义的社会往往伴随着社会冲突、不平等和不满情绪，从而影响社会的整体发展。社会正义是构建和谐社会的基础。

### 1.3 社会正义的几种理论

社会正义的理论有多种，包括公平理论、公共选择理论、平等理论、产权理论和伦理学探讨。

1. **公平理论**：认为资源分配应基于个人的贡献和需求，确保每个人都能够获得公平的机会和资源。
2. **公共选择理论**：关注政府决策和市场机制对社会正义的影响，探讨如何通过制度和政策来实现社会正义。
3. **平等理论**：强调所有人应享有平等的权利和机会，不受种族、性别、阶级等因素的歧视。
4. **产权理论**：认为资源分配应基于产权的明确和保障，产权的明确和保障有助于促进资源的有效利用。
5. **伦理学探讨**：从道德和伦理的角度探讨社会正义的问题，探讨如何通过道德原则来指导社会正义的实现。

        self.wealthDistribution = wealthDistribution
        self.powerDistribution = powerDistribution
        self.opportunityDistribution = opportunityDistribution

    def evaluateInequality(self):
        if max(self.wealthDistribution) - min(self.wealthDistribution) > 0 and \
           max(self.powerDistribution) - min(self.powerDistribution) > 0 and \
           max(self.opportunityDistribution) - min(self.opportunityDistribution) > 0:

        else:
            return False
