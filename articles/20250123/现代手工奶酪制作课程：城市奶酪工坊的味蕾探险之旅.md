### 第2章：奶酪原料的选择与处理

#### 2.1 奶酪的主要原料

**背景介绍**

奶酪的制作离不开优质的原料，其中牛奶是最常见的原料。此外，羊奶、山羊奶、犬奶和马奶等也在某些奶酪品种中发挥着重要作用。

**核心概念与联系**

不同种类的奶，其营养成分和风味特点有所不同，因此在选择原料时需要考虑这些因素。

| 奶类  | 营养成分 | 风味特点 |
|-------|----------|----------|
| 牛奶  | 蛋白质、脂肪、钙 | 丰富、浓郁 |
| 羊奶  | 蛋白质、脂肪、维生素A | 较浓、略酸 |
| 山羊奶 | 蛋白质、脂肪、维生素A | 较浓、柔和 |
| 犬奶  | 蛋白质、脂肪、维生素A | 特殊、稀有 |
| 马奶  | 蛋白质、脂肪、维生素A | 特殊、浓稠 |

$$
\text{奶类营养成分} = \text{蛋白质} + \text{脂肪} + \text{维生素A}
$$

#### 2.2 原料的选择标准

**核心概念与联系**

选择原料时，除了考虑营养成分和风味特点外，还需要关注以下几点：

- **新鲜度**：原料越新鲜，品质越高。
- **来源**：来自有机牧场或认证牧场的原料更受欢迎。
- **口感**：不同的奶酪品种对原料的口感要求不同。

**数学公式使用latex格式**

$$

#### 4.1 奶酪的保存方法

**核心概念与联系**

奶酪的保存方法直接影响其风味和保质期。以下是几种常见的保存方法：

- **冷藏**：将奶酪放在冰箱中，保持低温。
- **冷冻**：适用于长时间保存，但会影响口感。

**数学公式使用latex格式**

$$
\text{保存方法} = \text{冷藏} + \text{冷冻}
$$

**算法原理讲解**

使用Python代码示例展示冷藏保存方法：

```python
def store_cheese(temperature):
    if temperature < 4:
        return "Cheese stored in the refrigerator."
    elif temperature < -18:
        return "Cheese stored in the freezer."
    else:
        return "Invalid temperature for cheese storage."

print(store_cheese(2))
```
