```python
from textblob import TextBlob

def sentiment_analysis(text):
    """
    分析文本的情感，返回情感极性
    :param text: 文本内容
    :return: 情感极性（'positive', 'neutral', 'negative'）
    """
    analysis = TextBlob(text)
    if analysis.sentiment.polarity > 0:
        return 'positive'
    elif analysis.sentiment.polarity == 0:
        return 'neutral'
    else:
        return 'negative'
```

# 附录三：算法原理讲解与流程图

### 算法原理

情感劳动中的关键步骤包括情感识别、情感分析和情感反馈。以下是这些步骤的详细解释：

1. **情感识别**：通过自然语言处理（NLP）技术，识别文本中的情感极性（积极、消极或中性）。
2. **情感分析**：对情感极性进行定量分析，评估情感强度，并将其与预设的情感阈值进行比较。
3. **情感反馈**：根据情感分析和阈值判断结果，向用户发送相应的情感反馈。

### Python源代码

以下是一个简单的情感劳动算法实现的示例代码：

```python
from textblob import TextBlob

def sentiment_analysis(text):
    """
    分析文本的情感，返回情感极性
    :param text: 文本内容
    :return: 情感极性（'positive', 'neutral', 'negative'）
    """
    analysis = TextBlob(text)
    if analysis.sentiment.polarity > 0.1:
        return 'positive'
    elif analysis.sentiment.polarity < -0.1:
        return 'negative'
    else:
        return 'neutral'

def emotional_labour():
    # 示例文本
    text = "我今天过得很开心，因为我完成了一个重要项目。"
    sentiment = sentiment_analysis(text)
    
    if sentiment == 'positive':
        print("您的情感状态是积极，请继续保持！")
    elif sentiment == 'negative':
        print("您的情感状态是消极，我们需要帮助。")
    else:
        print("您的情感状态是中性，建议调整情绪。")

emotional_labour()
```

### 算法原理详细讲解

1. **情感识别**：首先，我们使用TextBlob库对输入的文本进行情感极性分析。TextBlob库提供了一个简单的接口，用于情感分析，其返回的极性值（polarity）介于-1到1之间，正数表示积极，负数表示消极，0表示中性。

2. **情感分析**：根据情感识别的结果，我们进一步对情感极性进行分析。在本例中，我们设定了一个阈值（0.1和-0.1），当情感极性大于0.1时，视为积极；当情感极性小于-0.1时，视为消极；其他情况视为中性。

3. **情感反馈**：根据情感分析的结果，程序会向用户发送相应的情感反馈。如果情感状态为积极，则反馈积极的建议；如果情感状态为消极，则反馈需要帮助的信息；如果情感状态为中性，则建议用户调整情绪。
