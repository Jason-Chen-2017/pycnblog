## 第1章: 项目成功的背景与重要性

### 1.1 问题背景

在现代企业中，IT项目已经成为了企业运营的关键组成部分。无论是软件开发、系统升级还是新技术的引入，项目的成功与否直接关系到企业的竞争力和发展。然而，许多项目在实际执行过程中面临诸多挑战，如进度延误、预算超支、质量低下等。这些问题的存在使得项目成功成为了一个复杂而重要的课题。

### 1.2 项目成功的定义

项目成功通常被定义为项目在预定的范围内，按时、按预算、按质量完成所有既定的目标。这个定义包括三个关键维度：

- **范围**：项目必须完成所有预定的任务和功能。
- **时间**：项目必须在预定的时间内完成。
- **预算**：项目必须在预算范围内完成。
- **质量**：项目必须达到预定的质量标准。

### 1.3 项目成功的意义

项目成功对企业具有重要意义：

- **提高竞争力**：成功的项目能够为企业带来竞争优势，提升市场地位。
- **提升效率**：通过有效的项目管理，可以提高项目执行效率，降低运营成本。
- **增强团队凝聚力**：成功的项目能够增强团队成员的自信心和团队凝聚力。
- **积累经验**：成功的项目为团队积累了宝贵的经验和知识，为未来的项目提供了指导。

### 1.4 问题解决

为了实现项目成功，我们需要从以下几个方面进行解决：

- **明确目标和范围**：确保项目目标和范围明确，避免项目中途变更。
- **合理规划时间和预算**：通过详细的规划和监控，确保项目按时、按预算完成。
- **选择合适的方法论**：选择适合项目的方法论，如敏捷开发、精益项目管理等。
- **系统分析**：通过系统分析，找出项目的瓶颈和关键因素，制定相应的解决方案。
- **持续改进**：通过持续改进，不断优化项目管理和执行过程。

### 1.5 边界与外延

- **边界**：项目成功的研究主要关注在项目范围内，如项目范围、时间、预算和质量等方面。
- **外延**：项目成功的研究还可以扩展到项目管理方法论、团队管理、组织文化等方面。

### 1.6 概念结构与核心要素组成

项目成功包括以下核心要素：

- **项目目标**：明确项目的目标，确保项目方向的正确性。
- **资源管理**：合理分配资源，确保项目所需的人力、物力和财力。
- **风险管理**：识别和应对项目中的风险，降低风险对项目的影响。
- **质量管理**：确保项目达到预定的质量标准，满足客户需求。
- **进度控制**：监控项目进度，确保项目按时完成。

## 第2章: 项目成功的核心概念

### 2.1 关键绩效指标（KPI）

#### 2.1.1 KPI的选取

KPI是衡量项目成功的重要指标。选择合适的KPI需要考虑以下因素：

- **项目目标**：KPI应该与项目目标密切相关。
- **可衡量性**：KPI应该是可以量化的，以便进行监控和评估。
- **相关性**：KPI应该与项目成功的关键因素相关。
- **及时性**：KPI应该能够及时反映项目的状态。

#### 2.1.2 KPI的测量

KPI的测量需要定期进行，以确保项目状态的真实反映。测量方法包括：

- **定量测量**：通过数字和数据来衡量KPI，如进度完成率、成本控制率等。
- **定性测量**：通过描述性语言来衡量KPI，如项目团队满意度、客户满意度等。

#### 2.1.3 KPI的管理

KPI的管理包括以下方面：

- **制定KPI计划**：确定KPI的目标值、测量方法和时间表。
- **监控KPI执行**：定期监控KPI的执行情况，及时发现并解决问题。
- **评估KPI效果**：根据KPI的测量结果，评估项目的执行效果，制定改进措施。

### 2.2 项目管理方法论

#### 2.2.1 传统项目管理

传统项目管理强调计划和控制，以瀑布模型为基础。优点是结构清晰，缺点是灵活性不足。

#### 2.2.2 精益项目管理

精益项目管理强调持续改进和客户价值，以敏捷开发为基础。优点是灵活性强，缺点是管理复杂度高。

#### 2.2.3 领导力与团队管理

领导力与团队管理是项目成功的关键因素。领导力包括以下方面：

- **愿景和目标**：明确项目的愿景和目标，激发团队成员的积极性。
- **沟通和协作**：建立有效的沟通机制，促进团队协作。
- **激励和反馈**：通过激励和反馈机制，提升团队成员的工作动力和绩效。

### 2.3 系统性分析方法

#### 2.3.1 系统性分析方法概述

系统性分析方法是一种综合性的思考方法，旨在通过分析和整合不同因素，解决复杂问题。特点包括：

- **系统性**：将问题视为一个整体，分析各个部分之间的相互作用。
- **层次性**：从宏观到微观，逐步分析问题的各个方面。
- **动态性**：考虑问题的变化和发展趋势。

#### 2.3.2 系统性分析方法的应用范围

系统性分析方法广泛应用于各个领域，如项目管理、软件工程、企业管理等。在项目成功中，系统性分析方法可以帮助：

- **明确项目目标**：通过系统性分析，明确项目的目标和范围。
- **识别风险**：通过系统性分析，识别项目中的潜在风险。
- **优化项目过程**：通过系统性分析，优化项目的执行过程，提高效率和质量。

#### 3.1.1 系统性分析方法的特点

系统性分析方法具有以下特点：

- **整体性**：考虑系统的整体性和各个部分之间的相互作用。

#### 3.1.2 系统性分析方法的应用范围

系统性分析方法广泛应用于各个领域，如项目管理、软件工程、企业管理等。在项目成功中，系统性分析方法可以帮助：

- **识别风险**：通过系统性分析，识别项目中的潜在风险。
- **优化项目过程**：通过系统性分析，优化项目的执行过程，提高效率和质量。

### 3.2 ER模型与数据库设计

#### 3.2.1 ER模型的基本概念

ER模型（Entity-Relationship Model）是一种用于描述实体及其关系的模型。它包括以下基本概念：

- **实体**：现实世界中具有独立存在的个体，如学生、员工等。
- **属性**：实体的特征，如学生的姓名、年龄等。
- **关系**：实体之间的关联，如学生与课程之间的关系。

#### 3.2.2 ER模型的构建

构建ER模型需要以下步骤：

1. **确定实体**：根据项目需求，确定需要建模的实体。
2. **确定属性**：为每个实体确定属性。
3. **确定关系**：确定实体之间的关系，并定义关系的类型（如一对一、一对多、多对多）。

#### 3.2.3 数据库设计的实施

数据库设计是系统性分析的重要环节。实施步骤包括：

1. **ER模型转换**：将ER模型转换为数据库模式。
2. **表设计**：根据数据库模式，设计具体的表结构。
3. **索引设计**：为表设计适当的索引，提高查询效率。
4. **数据验证**：确保数据的完整性和一致性。

## 第4章: 算法原理与数学模型讲解

### 4.1 算法原理讲解

#### 4.1.1 算法基本流程

算法的基本流程包括以下几个步骤：

1. **输入**：输入算法所需的初始数据。
2. **初始化**：初始化算法所需的数据结构和变量。
3. **循环**：执行算法的核心操作，直到满足终止条件。
4. **输出**：输出算法的结果。

#### 4.1.2 算法性能分析

算法性能分析包括以下几个方面：

1. **时间复杂度**：描述算法执行时间与输入规模的关系。
2. **空间复杂度**：描述算法所需存储空间与输入规模的关系。
3. **正确性**：验证算法是否能够正确地解决问题。
4. **效率**：评估算法的执行效率。

#### 4.1.3 算法优缺点对比

不同算法在时间复杂度、空间复杂度、正确性和效率等方面存在差异。通过对比不同算法的优缺点，可以选择适合项目需求的算法。

### 4.2 数学模型与公式

数学模型是算法设计的基础。以下是一个简单的线性回归模型：

$$
y = \beta_0 + \beta_1x
$$

其中，$y$是因变量，$x$是自变量，$\beta_0$和$\beta_1$是模型参数。这个模型描述了因变量$y$与自变量$x$之间的线性关系。

#### 4.2.1 模型参数优化

模型参数优化是提高算法性能的关键。常用的参数优化方法包括：

1. **最小二乘法**：通过最小化残差平方和来优化模型参数。
2. **梯度下降法**：通过迭代更新模型参数，使其逐渐逼近最优解。
3. **随机梯度下降法**：在梯度下降法的基础上，引入随机性，提高算法的收敛速度。

#### 4.2.2 数学公式在项目中的应用

数学公式在项目中的应用非常广泛，如：

1. **数据挖掘**：使用数学模型进行特征提取和预测。
2. **优化算法**：使用数学模型进行优化，提高算法性能。
3. **人工智能**：使用数学模型构建神经网络和机器学习模型。

### 1.1 问题背景

在现代企业的运营中，IT项目已经成为了企业竞争力的关键组成部分。从软件开发到系统升级，从新技术的引入到数字化转型，项目的成功与否直接关系到企业的战略目标和商业成功。然而，在项目执行过程中，许多团队面临着各种挑战，如进度延误、成本超支、质量低下等。这些问题不仅影响了项目的交付质量，还严重损害了企业的声誉和资源。

### 1.2 项目成功的定义

项目成功的定义并不是单一的，而是多维度的。通常，项目成功可以概括为以下几个核心维度：

- **范围**：项目必须按照预定的范围完成所有既定的目标和任务。
- **时间**：项目必须在预定的期限内完成。
- **预算**：项目必须在预算范围内完成。
- **质量**：项目必须达到预定的质量标准，满足客户需求。

这四个维度共同构成了项目成功的评价标准。然而，在实际操作中，项目成功还涉及到其他多个方面，如项目团队的合作、风险管理、沟通协调等。

### 1.3 项目成功的意义

项目成功对企业具有重要意义，具体体现在以下几个方面：

- **提高竞争力**：成功的项目能够为企业带来竞争优势，帮助企业在市场中占据有利地位。
- **提升效率**：通过有效的项目管理和执行，可以提高企业的运营效率，降低成本。
- **增强团队凝聚力**：成功的项目可以增强团队成员的自信心和团队凝聚力，促进团队的合作与发展。
- **积累经验**：成功的项目为团队积累了宝贵的经验，这些经验将有助于未来项目的执行和管理。

### 1.4 问题解决

为了实现项目成功，我们需要从以下几个方面进行解决：

- **明确目标和范围**：确保项目目标和范围明确，避免项目中途变更，影响项目的稳定性和可持续性。
- **合理规划时间和预算**：通过详细的规划和监控，确保项目按时、按预算完成。合理的时间规划和预算控制是项目成功的关键。
- **选择合适的方法论**：选择适合项目的方法论，如敏捷开发、精益项目管理等。不同的方法论适用于不同类型的项目，选择合适的方法论可以显著提高项目的成功率。
- **系统分析**：通过系统分析，找出项目的瓶颈和关键因素，制定相应的解决方案。系统分析可以帮助我们全面了解项目的各个方面，从而制定更有效的策略。
- **持续改进**：通过持续改进，不断优化项目管理和执行过程。项目成功不是一次性的，而是需要不断调整和优化的过程。

### 1.5 边界与外延

- **边界**：项目成功的研究主要关注在项目范围内，如项目范围、时间、预算和质量等方面。
- **外延**：项目成功的研究还可以扩展到项目管理方法论、团队管理、组织文化等方面。一个成功的项目不仅仅是技术层面的成功，还包括团队协作、企业文化等多方面的因素。

### 1.6 概念结构与核心要素组成

项目成功包括以下几个核心要素：

- **项目目标**：明确项目的目标和范围，确保项目方向的正确性。
- **资源管理**：合理分配资源，确保项目所需的人力、物力和财力。
- **风险管理**：识别和应对项目中的风险，降低风险对项目的影响。
- **质量管理**：确保项目达到预定的质量标准，满足客户需求。
- **进度控制**：监控项目进度，确保项目按时完成。

这些核心要素相互关联，共同构成了项目成功的基础。只有综合考虑这些要素，才能实现项目的成功。

## 第2章: 项目成功的核心概念

### 2.1 关键绩效指标（KPI）

#### 2.1.1 KPI的选取

关键绩效指标（Key Performance Indicators, KPI）是衡量项目成功的重要工具。选择合适的KPI对于项目管理的成功至关重要。以下是一些选取KPI的考虑因素：

- **项目目标**：KPI应与项目目标密切相关，确保能够衡量项目是否达成预期目标。
- **可衡量性**：KPI应具有可量化的属性，使其易于测量和监控。
- **相关性**：KPI应与项目的关键成功因素相关，能够反映项目的实际表现。
- **时效性**：KPI应能够及时反映项目的进展情况，以便及时调整和优化。

常见的KPI包括但不限于：

- **进度完成率**：已完成的工作量与总计划工作量的比值。
- **成本控制率**：实际成本与预算成本的比值。
- **客户满意度**：通过客户调查和反馈获得的满意度评分。
- **缺陷率**：项目中发现的缺陷数量与总工作量的比值。

#### 2.1.2 KPI的测量

KPI的测量是确保项目成功的关键步骤。以下是一些测量KPI的方法：

- **定量测量**：使用具体的数据和指标进行测量，如进度完成率、成本控制率等。
- **定性测量**：使用描述性语言和主观评价进行测量，如客户满意度、团队士气等。
- **定期测量**：定期收集和更新KPI数据，以便及时监控项目的进展。

#### 2.1.3 KPI的管理

有效的KPI管理包括以下方面：

- **制定KPI计划**：明确每个KPI的目标值、测量方法和时间表。
- **监控KPI执行**：定期监控KPI的执行情况，及时发现并解决问题。
- **评估KPI效果**：根据KPI的测量结果，评估项目的执行效果，制定改进措施。
- **报告与沟通**：定期向项目相关方报告KPI的结果，确保信息的透明和沟通的有效性。

### 2.2 项目管理方法论

项目管理方法论是指导项目执行和管理的重要工具。不同的方法论适用于不同类型的项目和环境。以下是一些常见的方法论：

#### 2.2.1 传统项目管理

传统项目管理方法，如瀑布模型（Waterfall Model），是一种线性顺序的开发方法。其主要特点是：

- **阶段分明**：项目分为需求分析、设计、开发、测试等阶段，每个阶段有明确的交付物和验收标准。
- **文档驱动**：强调文档的编写和审批，确保项目进度的可追踪性。
- **严格计划**：项目开始前制定详细的项目计划，包括时间表、资源分配和预算。

传统项目管理方法的优点是结构清晰、责任明确，缺点是灵活性不足，难以应对需求变化。

#### 2.2.2 精益项目管理

精益项目管理（Lean Project Management）是一种以客户价值为中心的管理方法。其主要特点是：

- **持续改进**：强调不断优化项目过程，提高效率和客户满意度。
- **快速迭代**：通过快速迭代和迭代评审，确保项目能够及时响应变化。
- **资源优化**：注重资源的合理利用，避免浪费。

精益项目管理适用于需求变化频繁的项目，其优点是灵活性高、响应快，缺点是管理复杂度较高。

#### 2.2.3 领导力与团队管理

领导力与团队管理是项目成功的关键因素。有效的领导力包括以下几个方面：

- **愿景和目标**：明确项目的愿景和目标，激发团队成员的积极性。
- **沟通和协作**：建立有效的沟通机制，促进团队协作。
- **激励和反馈**：通过激励和反馈机制，提升团队成员的工作动力和绩效。

团队管理方面，需要注重以下几个方面：

- **角色分工**：明确团队成员的角色和职责，确保任务分配合理。
- **技能提升**：为团队成员提供培训和发展机会，提升团队整体技能水平。
- **团队建设**：通过团队建设活动，增强团队成员之间的信任和合作。

### 2.3 系统性分析方法

系统性分析方法（Systematic Analysis Method）是一种综合性的思考方法，旨在通过分析和整合不同因素，解决复杂问题。以下是一些系统性分析方法的特点和步骤：

#### 2.3.1 系统性分析方法的特点

- **整体性**：将问题视为一个整体，分析各个部分之间的相互作用。
- **层次性**：从宏观到微观，逐步分析问题的各个方面。
- **动态性**：考虑问题的变化和发展趋势。
- **综合性和系统性**：综合运用各种分析方法，形成完整的分析框架。

#### 2.3.2 系统性分析方法的应用范围

系统性分析方法广泛应用于各个领域，如项目管理、软件工程、企业管理等。在项目成功中，系统性分析方法可以帮助：

- **明确项目目标**：通过系统性分析，明确项目的目标和范围。
- **识别风险**：通过系统性分析，识别项目中的潜在风险。
- **优化项目过程**：通过系统性分析，优化项目的执行过程，提高效率和质量。

### 2.4 系统性分析方法的应用

系统性分析方法在项目中的应用包括以下几个方面：

- **需求分析**：通过系统性分析，明确项目的需求，确保项目满足客户和业务需求。
- **风险评估**：通过系统性分析，识别项目中的风险，并制定相应的应对措施。
- **过程优化**：通过系统性分析，找出项目过程中的瓶颈和问题，并提出改进措施。

#### 2.4.1 需求分析

需求分析是项目成功的关键步骤。系统性需求分析方法包括以下几个方面：

- **需求收集**：通过与客户、业务团队和项目团队成员的沟通，收集项目的需求。
- **需求分类**：将收集到的需求进行分类，区分功能需求、非功能需求和优先级。
- **需求验证**：通过原型设计、评审会议等方式，验证需求的准确性和可行性。

#### 2.4.2 风险评估

风险评估是项目管理的重要环节。系统性风险评估方法包括以下几个方面：

- **风险识别**：通过头脑风暴、专家评审等方法，识别项目中的潜在风险。
- **风险分析**：对识别的风险进行定量和定性分析，评估风险的影响程度和发生概率。
- **风险应对**：根据风险评估结果，制定相应的风险应对措施，降低风险对项目的影响。

#### 2.4.3 过程优化

过程优化是提高项目效率和质量的重要手段。系统性过程优化方法包括以下几个方面：

- **过程分析**：通过流程图、因果图等方法，分析项目的过程和流程。
- **过程改进**：根据过程分析的结果，找出过程中的瓶颈和问题，并提出改进措施。
- **过程监控**：建立过程监控机制，确保改进措施的有效实施，并持续优化项目过程。

### 2.5 系统性分析方法在项目中的应用案例

以下是一个系统性分析方法在项目中的应用案例：

- **项目背景**：一家企业计划开发一款新的客户关系管理（CRM）系统，以提高客户满意度和销售业绩。
- **需求分析**：通过系统性需求分析，确定了系统的功能模块，包括客户信息管理、销售机会管理、营销活动管理等。
- **风险评估**：通过系统性风险评估，识别了项目的技术风险、市场风险和资源风险，并制定了相应的应对措施。
- **过程优化**：通过系统性过程优化，确定了项目的主要流程和关键里程碑，并制定了详细的计划和时间表。

通过系统性分析方法的应用，该项目成功地按时、按预算、按质量完成了所有既定的目标，为企业带来了显著的效益。

## 第3章: 系统性分析方法的原理与实践

### 3.1 系统性分析方法概述

系统性分析方法（Systematic Analysis Method）是一种基于逻辑推理和系统性思考的方法，用于分析和解决复杂问题。该方法通过逐步分解问题、识别关键因素、建立模型和进行综合评估，帮助项目团队全面理解问题，制定有效的解决方案。

#### 3.1.1 系统性分析方法的特点

- **系统性**：将问题视为一个整体，分析各个部分之间的相互作用。
- **逻辑性**：通过逻辑推理，逐步揭示问题的本质和关键因素。
- **全面性**：综合考虑问题的各个方面，确保分析的全面性和准确性。
- **动态性**：考虑问题的变化和发展趋势，及时调整和优化解决方案。

#### 3.1.2 系统性分析方法的应用范围

系统性分析方法广泛应用于各个领域，如项目管理、软件工程、企业管理、市场营销等。在项目成功中，系统性分析方法可以帮助：

- **明确项目目标和范围**：通过系统性分析，明确项目的目标和范围，确保项目方向的正确性。
- **识别风险**：通过系统性分析，识别项目中的潜在风险，制定相应的应对措施。
- **优化项目过程**：通过系统性分析，优化项目的执行过程，提高效率和质量。

### 3.2 系统性分析方法的步骤

系统性分析方法的步骤可以分为以下几个阶段：

#### 3.2.1 问题定义

问题定义是分析过程的第一步，目的是明确问题的性质和范围。具体步骤包括：

- **问题描述**：清晰、准确地描述问题的现象和影响。
- **问题分类**：将问题归类，以便更好地理解和解决。
- **问题分析**：分析问题的原因和影响，确定问题的优先级。

#### 3.2.2 信息收集

信息收集是进行系统性分析的基础。具体步骤包括：

- **数据收集**：收集与问题相关的数据和信息，包括定量数据和定性数据。
- **信息整理**：对收集到的信息进行整理和分析，提取关键信息和关联关系。
- **数据验证**：验证收集到的数据的准确性和可靠性。

#### 3.2.3 建立模型

建立模型是系统性分析的核心步骤。通过建立模型，可以直观地表示问题的各个方面和相互关系。具体步骤包括：

- **定义变量**：确定影响问题的关键因素，并定义相应的变量。
- **建立关系**：通过变量之间的关系，建立问题的数学模型或概念模型。
- **模型验证**：验证模型的准确性和适用性，确保模型能够真实反映问题。

#### 3.2.4 模拟和优化

模拟和优化是系统性分析的进一步步骤。通过模拟，可以预测问题的变化和结果，并通过优化，提出改进方案。具体步骤包括：

- **模型模拟**：使用计算机模拟或实验方法，模拟问题的变化和结果。
- **方案评估**：评估不同方案的优劣，选择最优方案。
- **模型优化**：根据评估结果，对模型进行优化，提高模型的预测准确性。

#### 3.2.5 决策和实施

决策和实施是系统性分析的最后一步。通过决策，确定最终的解决方案，并通过实施，将方案转化为实际行动。具体步骤包括：

3. **核心算法**：执行算法的核心逻辑，根据输入数据产生输出结果。

这个模型描述了因变量$y$与自变量$x$之间的线性关系，其中$\beta_0$是截距，$\beta_1$是斜率。

#### 4.4.1 模型参数优化

模型参数优化是提高算法性能的关键。以下是一些常用的参数优化方法：

1. **最小二乘法**：通过最小化残差平方和来优化模型参数。具体公式如下：

$$
\min_{\beta_0, \beta_1} \sum_{i=1}^{n} (y_i - (\beta_0 + \beta_1x_i))^2
$$

2. **梯度下降法**：通过迭代更新模型参数，使其逐渐逼近最优解。具体公式如下：

$$
\beta_0 = \beta_0 - \alpha \frac{\partial}{\partial \beta_0} \sum_{i=1}^{n} (y_i - (\beta_0 + \beta_1x_i))^2
$$

$$
\beta_1 = \beta_1 - \alpha \frac{\partial}{\partial \beta_1} \sum_{i=1}^{n} (y_i - (\beta_0 + \beta_1x_i))^2
$$

其中，$\alpha$是学习率。

3. **随机梯度下降法**：在梯度下降法的基础上，引入随机性，提高算法的收敛速度。具体公式如下：

$$
\beta_0 = \beta_0 - \alpha \frac{\partial}{\partial \beta_0} J(\beta_0, \beta_1)
$$

$$
\beta_1 = \beta_1 - \alpha \frac{\partial}{\partial \beta_1} J(\beta_0, \beta_1)
$$

其中，$J(\beta_0, \beta_1)$是损失函数。

def linear_regression(x, y):
    # 数据预处理：添加截距项
    X = np.column_stack((np.ones(len(x)), x))
    # 初始化参数
    theta = np.zeros(len(X[0]))
    # 设置迭代次数和步长
    iterations = 1000
    alpha = 0.01
    # 迭代计算
    for i in range(iterations):
        # 前向传播
        h = np.dot(X, theta)
        # 计算损失函数
        loss = np.sum((h - y)**2) / 2
        # 反向传播

        # 更新参数
        theta -= alpha * dtheta
    return theta

# 示例数据

import numpy as np

def linear_regression(x, y):
    # 数据预处理：添加截距项
    X = np.column_stack((np.ones(len(x)), x))
    # 初始化参数
    theta = np.zeros(len(X[0]))
    # 设置迭代次数和步长
    iterations = 1000
    alpha = 0.01
    # 迭代计算
    for i in range(iterations):
        # 前向传播
        h = np.dot(X, theta)
        # 计算损失函数
        loss = np.sum((h - y)**2) / 2
        # 反向传播
        dtheta = np.dot(X.T, (h - y)) / len(x)
        # 更新参数
        theta -= alpha * dtheta
    return theta

# 示例数据

y = np.array([2, 4, 5, 4, 5])

print("截距:", theta[0])

    if User.query.filter_by(username=username).first():
        return jsonify({'error': 'User already exists'}), 400

    db.session.commit()

@app.route('/users', methods=['GET'])

from flask_sqlalchemy import SQLAlchemy

app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql+pymysql://username:password@localhost/db_name'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password = db.Column(db.String(120), nullable=False)

@app.route('/register', methods=['POST'])
def register():
    username = request.form['username']
    password = request.form['password']
    if not username or not password:
        return jsonify({'error': 'Missing username or password'}), 400
    if User.query.filter_by(username=username).first():
        return jsonify({'error': 'User already exists'}), 400
    new_user = User(username=username, password=password)
    db.session.add(new_user)
    db.session.commit()
    return jsonify({'message': 'User registered successfully'}), 201

@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    user = User.query.filter_by(username=username).first()
    if not user or user.password != password:
        return jsonify({'error': 'Invalid username or password'}), 401
    return jsonify({'message': 'Login successful'}), 200

@app.route('/users', methods=['GET'])
def get_users():
    users = User.query.all()
    user_list = [{'id': user.id, 'username': user.username} for user in users]
    return jsonify(user_list), 200

if __name__ == '__main__':
    db.create_all()
