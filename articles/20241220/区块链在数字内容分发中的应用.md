##### 1.1 区块链的核心概念

区块链是一种去中心化的分布式账本技术，它通过加密算法和共识机制确保数据的完整性和安全性。区块链由一系列按时间顺序排列的区块组成，每个区块包含一定数量的交易记录，并通过加密技术链接起来，形成一个不可篡改的链式数据结构。

##### 1.1.1 区块链的基本原理

区块链的基本原理包括三个关键组成部分：区块链节点、加密算法和共识机制。区块链节点负责存储和验证数据，加密算法确保数据传输的隐私和安全性，共识机制则保证节点间的数据一致性。

##### 1.1.2 区块链的关键特征

区块链具有以下几个关键特征：

1. **去中心化**：区块链不需要中心化的管理机构，所有节点共同维护数据，提高了系统的容错性和抗攻击能力。
2. **不可篡改性**：区块链采用加密技术确保数据的不可篡改性，任何篡改都会被其他节点检测并拒绝。
3. **透明性**：区块链的所有交易记录都是公开透明的，任何人都可以查看和验证。
4. **安全性和隐私保护**：区块链采用加密算法保护数据的隐私和安全，同时确保交易记录的真实性。

##### 1.1.3 区块链技术的发展历程

```python
import hashlib
import json
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.backends import default_backend

def encrypt_content(content):
    # 使用AES加密内容
    # 这里仅用于示例，实际应用中需要更复杂的加密算法
    key = hashlib.sha256(content.encode()).digest()
    iv = b'\x00' * 16
    cipher = AES.new(key, AES.MODE_CBC, iv)
    ct_bytes = cipher.encrypt(content.encode())
    return iv + ct_bytes

def sign_content(content, private_key):
    # 使用RSA签名内容
    signature = private_key.sign(
        content,
        padding.PSS(
            mgf=padding.MGF1(hashes.SHA256()),
            salt_length=padding.PSS.MAX_LENGTH
        ),
        hashes.SHA256()
    )
    return signature

def verify_signature(content, signature, public_key):

    try:
        public_key.verify(
            signature,
            content,
            padding.PSS(
                mgf=padding.MGF1(hashes.SHA256()),
                salt_length=padding.PSS.MAX_LENGTH
            ),
            hashes.SHA256()
        )
        return True
    except Exception as e:
        return False
```

```javascript
pragma solidity ^0.8.0;

contract Content {
    struct ContentItem {
        string title;
        string content;
        address creator;
        uint256 timestamp;
    }

    mapping (uint256 => ContentItem) public contentItems;
    uint256 public contentItemCount;

    function createContent(string memory title, string memory content) public {
        contentItems[contentItemCount] = ContentItem({
            title: title,
            content: content,
            creator: msg.sender,
            timestamp: block.timestamp
        });
        contentItemCount++;
    }

    function getContent(uint256 id) public view returns (string memory, string memory, address, uint256) {
        require(id < contentItemCount, "Content not found");
        return (
            contentItems[id].title,
            contentItems[id].content,
            contentItems[id].creator,
            contentItems[id].timestamp
        );
    }
}

// content_server.js
const express = require('express');
const Web3 = require('web3');
const EthTx = require('eth-tx');
const ContentContractJSON = require('./build/Content.json');

const app = express();
const port = 3000;

const web3 = new Web3('http://127.0.0.1:8545');

const contractAddress = ContentContractJSON.networks[5777].address;
const contractABI = ContentContractJSON.abi;

const contentContract = new web3.eth.Contract(contractABI, contractAddress);

app.post('/content/create', async (req, res) => {
    const { title, content } = req.body;
    const tx = {
        from: web3.utils.toChecksumAddress('0xYourAddress'),
        to: contractAddress,
        data: contentContract.methods.createContent(title, content).encodeABI(),
        gas: 3000000,
        gasPrice: web3.utils.toWei('10', 'gwei')
    };

    const signedTx = await web3.eth.accounts.signTransaction(tx);
    const receipt = await web3.eth.sendSignedTransaction(signedTx.rawTransaction);

    res.json({ message: 'Content created successfully', txHash: receipt.transactionHash });
});

app.get('/content/query', async (req, res) => {
    const { id } = req.query;
    const content = await contentContract.methods.getContent(id).call();
    res.json({ content });
});

app.listen(port, () => {
    console.log(`Server listening at http://localhost:${port}`);
});
```
