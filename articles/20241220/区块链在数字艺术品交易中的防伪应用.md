在Python中，简化版的工作量证明算法可以表示为：

```python
import hashlib
import random

def mine_block(last_hash, target_difficulty):
    nonce = 0
    while True:
        hash = hashlib.sha256(f"{last_hash}{nonce}".encode()).hexdigest()
        if hash.startswith('0' * target_difficulty):
            return nonce, hash
        nonce += 1

last_hash = "InitialHash"
target_difficulty = 4

nonce, hash = mine_block(last_hash, target_difficulty)
print(f"Found a new block with nonce: {nonce} and hash: {hash}")
```

通过这段代码，矿工会不断尝试计算新的哈希值，直到找到一个满足难度要求的哈希值。
