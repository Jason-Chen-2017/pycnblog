决策树是一种常用的分类算法，通过一系列规则将数据分为不同的类别。在创新评估中，决策树可以用于对项目进行分类，判断其潜在价值。

- **算法原理**：决策树通过一系列的判断节点来分割数据集，每个节点对应一个特征，分支代表不同特征的取值。叶节点代表分类结果。

- **示例代码（Python）**：
  ```python
  from sklearn import tree
  
  # 特征和标签
  X = [[0, 0], [1, 1]]
  y = [0, 1]
  
  # 建立决策树模型
  clf = tree.DecisionTreeClassifier()
  
  # 模型训练
  clf.fit(X, y)
  
  # 预测
  print(clf.predict([[1, 1]]))
  ```

支持向量机是一种常用的分类和回归算法，通过找到最优的超平面来分割数据集。在创新评估中，SVM可以用于对项目进行分类，判断其潜在价值。

- **算法原理**：SVM通过最大化分类边界，找到能够将不同类别数据分开的最优超平面。支持向量是位于超平面边缘的数据点。

- **示例代码（Python）**：
  ```python
  from sklearn import svm
  
  # 特征和标签
  X = [[0, 0], [1, 1]]
  y = [0, 1]
  
  # 建立SVM模型
  clf = svm.SVC()
  
  # 模型训练
  clf.fit(X, y)
  
  # 预测
  print(clf.predict([[1, 1]]))
  ```
