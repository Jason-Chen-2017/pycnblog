#### 3.1 区块链中的加密算法

**哈希算法**

哈希算法是区块链技术中至关重要的一环，用于确保数据的完整性和安全性。哈希算法的基本原理是将输入数据通过一定的算法变换，输出一个固定长度的字符串，这个字符串被称为哈希值。

**Python代码示例：**

```python
import hashlib

def hash_function(data):
    hash_object = hashlib.sha256(data.encode())
    hex_dig = hash_object.hexdigest()
    return hex_dig

data = "Hello, Blockchain!"
print(hash_function(data))
```

**LaTeX数学公式解释：**

$$
H(D) = \text{SHA-256}(D)
$$

其中，$H(D)$表示输入数据$D$的哈希值，$\text{SHA-256}$表示SHA-256哈希算法。

**示例说明：**

假设输入数据为“Hello, Blockchain!”，通过SHA-256算法计算其哈希值，输出结果为一个固定长度的字符串，如：
