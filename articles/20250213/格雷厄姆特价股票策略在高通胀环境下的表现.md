### 第2章: 格雷厄姆特价股票策略的核心概念与数学模型

#### 2.1 格雷厄姆策略的关键指标
- 2.1.1 市盈率（P/E）的定义与计算
  - 市盈率 = 股价 / 每股净利润。
  - 公式：$$ P/E = \frac{P}{E} $$
  - 低市盈率意味着股价可能被低估。

- 2.1.2 市净率（P/B）的定义与计算
  - 市净率 = 股价 / 每股净资产。
  - 公式：$$ P/B = \frac{P}{B} $$
  - 低市净率可能表明股票价格低于其资产价值。

- 2.1.3 股息率的定义与计算
  - 股息率 = 每股股息 / 股价。
  - 公式：$$ \text{股息率} = \frac{\text{股息}}{P} $$
  - 高股息率可能意味着股票具有较高的分红能力。

#### 2.2 格雷厄姆安全边际的概念
- 2.2.1 安全边际的定义
  - 安全边际 = 股票市场价格 - 股票的内在价值。
  - 公式：$$ \text{安全边际} = P - V $$
  - 安全边际越大，投资风险越小。

- 2.2.2 安全边际的计算公式
  - 内在价值计算公式：
    $$ V = \frac{E}{k} $$
    其中，E是企业的盈利，k是资本成本。

- 2.2.3 安全边际与投资决策
  - 格雷厄姆建议以低于内在价值的价格购买股票，确保安全边际的存在。
  - 在高通胀环境下，内在价值的计算需要考虑通胀对资产价格的影响。

#### 2.3 内在价值的计算方法
- 2.3.1 内在价值的定义
  - 内在价值是基于企业未来现金流的现值。
  - 计算公式：
    $$ V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$
    其中，CF_t是第t年的现金流，r是贴现率。

- 2.3.2 内在价值的计算步骤
  1. 预测未来现金流。
  2. 确定合适的贴现率。
  3. 计算未来现金流的现值。

- 2.3.3 内在价值与市场价值的比较
  - 如果市场价格低于内在价值，股票可能被低估。
  - 高通胀环境下，内在价值的计算需要调整贴现率。

  import pandas as pd

  def calculate_pe(ticker):
      # 获取股票数据
      df = pd.read_csv(f'data/{ticker}.csv')
      pe = df['股价'] / df['每股净利润']
      return pe.mean()

- 6.2.2 内在价值计算算法实现
  ```python
  def calculate_intrinsic_value(ticker, discount_rate):
      # 获取股票数据
      df = pd.read_csv(f'data/{ticker}.csv')
      # 预测未来现金流
      cf = df['现金流'].tolist()
      # 计算内在价值
      iv = sum([cf_t / (1 + discount_rate) ** t for t, cf_t in enumerate(cf)])
      return iv

  # 示例：计算某只股票的内在价值
  iv = calculate_intrinsic_value('AAPL', 0.1)
  print(f'内在价值：{iv}')
  ```

  def calculate_margin_of_safety(ticker):
