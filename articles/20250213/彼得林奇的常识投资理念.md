# 第一部分：常识投资概述

## # 第1章：什么是常识投资

### 1.1 投资的基本概念
- **投资定义**：将资金投入特定资产以获取未来收益的行为。
- **投资目标**：实现资产增值，分散风险，获得稳定收益。
- **投资工具**：股票、债券、基金、房地产等。

### 1.2 常识投资的定义
- **基本面分析**：通过分析公司的财务状况、行业地位和管理层能力来评估其价值。
- **长期持有**：不频繁交易，长期持有优质资产以获得复利效应。
- **分散投资**：通过投资不同资产或行业降低风险。

### 1.3 常识投资的特点
- **简单易懂**：避免复杂的技术分析，注重基本逻辑。
- **避免跟风**：不盲目追随市场潮流，坚持独立判断。
- **注重长期**：关注企业的持续盈利能力，而非短期波动。

### 1.4 彼得·林奇的背景
- **生平简介**：彼得·林奇是富达基金的传奇经理人，管理麦哲伦基金长达13年，创造了卓越的投资业绩。
- **投资理念**：强调常识和基本面分析，倡导长期投资。

## # 第3章：常识投资的算法原理

### 3.1 常识投资的基本原理
- **基本面分析**：通过分析公司财务数据、行业地位和管理层能力，筛选出具有竞争优势的企业。
- **市场情绪分析**：识别市场的非理性波动，寻找被低估的投资机会。
- **投资组合优化**：通过分散投资降低风险，同时提高收益。

### 3.2 常识投资的数学模型
- **期望收益计算**：
  $$E(r) = \sum p_i r_i$$
  其中，\( p_i \) 是各资产的权重，\( r_i \) 是各资产的预期收益。

- **风险评估模型**：
  $$\sigma = \sqrt{\sum p_i (r_i - E(r))^2}$$
  其中，\( \sigma \) 表示投资组合的标准差，衡量风险。

### 5.2 核心实现代码
```python
def calculate_expected_return(assets, probabilities, returns):
    return sum(p * r for p, r in zip(probabilities, returns))

def calculate_risk(assets, probabilities, expected_return):
    variance = sum(p * (r - expected_return)**2 for p, r in zip(probabilities, assets))
    return variance ** 0.5

# 示例数据
assets = [10, 20, 30]
probabilities = [0.3, 0.4, 0.3]
returns = [0.05, 0.10, 0.15]

expected_return = calculate_expected_return(assets, probabilities, returns)
risk = calculate_risk(assets, probabilities, expected_return)

print(f"期望收益: {expected_return}")
print(f"风险: {risk}")
```
