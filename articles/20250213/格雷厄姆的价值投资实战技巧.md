# 第一部分：价值投资的背景与核心概念

## 第1章：价值投资的起源与发展

### 1.1 价值投资的起源
价值投资是投资学中的一个重要流派，起源于20世纪初。本章将介绍价值投资的起源、发展历程以及其在现代金融中的地位。

#### 1.1.1 投资学的起源与发展
投资学作为一门科学，其起源可以追溯到古代的贸易和借贷活动。然而，现代投资学的形成离不开19世纪末和20世纪初的金融理论发展。早期的金融理论主要关注资产的定价和风险分析，为价值投资的诞生奠定了基础。

#### 1.1.2 格雷厄姆与价值投资的诞生
本菲德·格雷厄姆（Benjamin Graham）是价值投资的创始人之一。他在20世纪初提出了“安全边际”的概念，并通过分析企业的基本面，如财务报表和现金流，来评估股票的内在价值。格雷厄姆的学生大卫·多德（David Dodd）进一步发展了这些理论，使得价值投资成为一种系统化的方法。

#### 1.1.3 价值投资在现代金融中的地位
尽管现代金融学发展了如CAPM、APT等理论，但价值投资依然在投资实践中占据重要地位。许多机构投资者和散户投资者都采用格雷厄姆的理论来指导投资决策。

### 1.2 格雷厄姆的价值投资理论

#### 1.2.1 格雷厄姆的核心理念
格雷厄姆认为，股票的价格波动与其内在价值无关，而内在价值可以通过对企业财务状况的分析来估算。投资者应该寻找市场价格低于内在价值的股票，即具有安全边际的股票。

#### 1.2.2 安全边际的概念
安全边际是格雷厄姆理论中的核心概念，指股票的市场价格与其内在价值之间的差距。通过购买具有足够安全边际的股票，投资者可以降低市场波动带来的风险。

#### 1.2.3 内在价值的定义与计算
内在价值是股票在企业未来现金流的现值基础上的评估价值。格雷厄姆通过分析企业的盈利能力、资产状况和行业地位来估算内在价值。

### 1.3 价值投资的哲学与心理

#### 1.3.1 投资者的心理因素
投资不仅仅是对市场的分析，更是对人性的洞察。格雷厄姆强调，投资者需要克服贪婪和恐惧的情绪，避免情绪化决策。

#### 1.3.2 长期投资的重要性
格雷厄姆主张长期投资，认为短期市场的波动无法预测，而长期来看，股票的价格会回归其内在价值。通过长期持有优质股票，投资者可以实现财富的稳步增长。

### 2.1 核心概念的数学模型

#### 2.1.1 安全边际的计算公式
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

#### 2.1.2 内在价值的评估公式
$$ \text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} $$

其中，\( r \) 是折现率，\( \text{现金流}_t \) 是第 \( t \) 年的现金流。

#### 2.3.2 算法实现代码

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(fcf, discount_rate):
    # 计算未来现金流的现值
    return np.sum(fcf / (1 + discount_rate)**np.arange(len(fcf)))

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
fcf = [100, 120, 150, 180]  # 未来四年的自由现金流
discount_rate = 0.08
market_price = 50

iv = calculate_intrinsic_value(fcf, discount_rate)
mos = calculate_margin_of_safety(iv, market_price)

print(f"内在价值: {iv:.2f}")
print(f"安全边际: {mos:.2f}")
```

```python
def screen_stocks(data, margin_of_safety=0.2):
    # 计算内在价值（简化）
    data['IV'] = data['Close'] / (1 - data['PE']/100)
    data['MOS'] = data['IV'] * margin_of_safety
    return data[data['Close'] < data['IV'] * (1 - data['MOS'])]

# 应用筛选
screened = screen_stocks(data)
print(screened)
```
