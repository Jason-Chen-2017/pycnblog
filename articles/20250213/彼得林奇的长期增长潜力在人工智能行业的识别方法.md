## 第2章：彼得·林奇的长期增长投资理念

### 2.1 长期增长公司的定义与特征
长期增长公司具备以下特征：
1. **持续的收入增长**：收入年增长率稳定且高于行业平均水平。
2. **强大的盈利能力**：净利润率较高且持续增长。
3. **竞争优势明显**：具备技术、品牌或市场等竞争优势。
4. **管理团队优秀**：管理团队经验丰富且稳定。

### 2.2 彼得·林奇的投资方法论
林奇提出了五项核心标准：
1. **竞争优势明显**：公司具备独特的竞争优势。
2. **财务健康**：财务数据健康，无重大财务风险。
3. **管理层优秀**：管理层具备良好的道德和管理能力。
4. **成长性良好**：公司具备持续增长的潜力。
5. **估值合理**：股价与内在价值相符。

import pandas as pd
import numpy as np

def calculate_growth(company_data):
    growth = (company_data['revenue'].pct_change() * 100).mean()
    return f"收入增长率：{growth:.2f}%"

def assess_competitive Advantage(company_data):
    competitors = company_data['competitors'].tolist()
    company_technology = company_data['technology']
    advantage = 0
    for competitor in competitors:
        if competitor['technology'] < company_technology:
            advantage += 1
    return f"竞争优势得分：{advantage}"

# 示例数据
data = {
    'revenue': [100, 120, 150, 180],
    'profit': [20, 25, 30, 35],
    'technology': ['AI', 'ML', 'NLP', 'CV'],
    'competitors': [{'technology': 'ML'}, {'technology': 'CV'}, {'technology': 'NLP'}, {'technology': 'AI'}]
}

df = pd.DataFrame(data)
print(calculate_growth(df))
print(assess_competitive_Advantage(df))
