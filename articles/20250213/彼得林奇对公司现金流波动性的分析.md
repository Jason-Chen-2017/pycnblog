#### 3.2 现金流波动性分析的Python实现

以下是现金流波动性分析的Python代码实现：

```python
import pandas as pd
import numpy as np

# 假设我们有一个现金流数据集
data = {
    '现金流': [100, 120, 90, 110, 130, 80, 100]
}

df = pd.DataFrame(data)

# 计算平均值
mu = df['现金流'].mean()

# 计算方差
variance = np.sum((df['现金流'] - mu) ** 2) / len(df)

# 计算标准差
std_dev = np.sqrt(variance)

print(f"平均值: {mu}")
print(f"方差: {variance}")
print(f"标准差: {std_dev}")
```
