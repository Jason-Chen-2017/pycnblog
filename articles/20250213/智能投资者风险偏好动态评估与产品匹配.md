## 第3章: 智能投资者风险偏好动态评估与产品匹配的核心算法

### 3.1 层次分析法（AHP）评估风险偏好

#### 3.1.1 AHP的基本原理
通过构建判断矩阵，计算权重，评估风险偏好。

#### 3.1.2 计算步骤
1. 构建判断矩阵。
2. 计算一致性检验。
3. 计算权重并归一化。

#### 3.1.3 算法流程图

```mermaid
graph TD
A[投资者数据] --> B[构建判断矩阵]
B --> C[一致性检验]
C --> D[计算权重]
D --> E[归一化处理]
E --> F[风险偏好评估结果]
```

### 3.2 协同过滤推荐系统

#### 3.2.1 协同过滤的原理
基于用户行为数据，计算相似性，推荐产品。

#### 3.2.2 相似度计算
使用余弦相似度。

#### 3.2.3 推荐算法流程图

```mermaid
graph TD
A[投资者数据] --> B[数据预处理]
B --> C[计算相似度]
C --> D[生成推荐列表]
D --> E[输出推荐产品]
```

### 3.3 算法实现的Python代码

```python
import numpy as np

def calculate_preference(matrix):
    # 计算一致性检验
    n = len(matrix)
    max_values = np.max(matrix, axis=1)
    consistency = np.sum(max_values) / n
    return consistency

# 示例判断矩阵
preference_matrix = np.array([[1, 2, 3],
                                [1/2, 1, 2],
                                [1/3, 1/2, 1]])

consistency = calculate_preference(preference_matrix)
print("一致性检验结果:", consistency)
```
