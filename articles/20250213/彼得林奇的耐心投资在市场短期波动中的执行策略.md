### 第1章：彼得林奇的投资哲学

#### 1.1 耐心投资的核心理念

耐心投资的核心理念是基于长期价值，而非短期价格波动。彼得林奇强调选择优质企业进行长期投资，而非频繁交易。他的策略要求投资者具备耐心，等待市场波动中的机会。

- **长期投资与价值投资的结合**：彼得林奇认为，市场波动为长期投资者提供了以合理价格买入优质资产的机会。
- **投资中的耐心与纪律**：耐心投资需要纪律，避免短期波动的干扰，坚持长期投资策略。
- **成功案例**：如购买并持有优质企业的股票，市场波动反而提供了更低的买入价。

#### 1.2 长期投资策略的短期波动应对

长期投资策略在短期波动中面临挑战，但可以通过调整投资组合和风险管理来应对。

- **短期波动对长期投资的影响**：波动可能导致短期亏损，但长期来看，优质资产的价值会回归。
- **如何在波动中保持耐心**：通过制定投资计划，避免情绪化决策，坚持长期策略。
- **投资组合的动态调整策略**：定期审视投资组合，根据市场变化调整配置，但避免频繁交易。

- **核心特征对比分析**：与短期交易相比，耐心投资更注重资产质量、长期增长潜力和风险管理。

| 特征 | 耐心投资 | 短期交易 |

- **耐心投资与短期波动的关系**：市场波动为长期投资者提供了以更低价格买入优质资产的机会，而耐心投资则通过长期持有，忽略短期波动的影响。

### 第3章：耐心投资策略的数学模型与公式

#### 3.1 投资组合波动率计算

波动率是衡量投资组合风险的重要指标，计算公式如下：

$$\text{波动率} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(r_i - \bar{r})^2}$$

其中，$r_i$为每期的收益率，$\bar{r}$为平均收益率，$n$为数据点数。

#### 3.2 资产配置模型

资产配置模型用于优化投资组合，平衡风险和收益。

$$\text{最优权重} = \frac{w_i \times r_i}{\sum_{j=1}^{n} w_j \times r_j}$$

其中，$w_i$为权重，$r_i$为收益率。

2. **波动率分析与风险评估**：计算波动率，评估市场风险。
3. **投资组合优化与调整**：根据波动率调整资产配置，优化组合。

#### 4.2 Python代码实现

```python
import numpy as np

def calculate_volatility(prices):
    returns = np.log(prices / prices.shift(1)).dropna()
    avg_return = np.mean(returns)
    variance = np.mean((returns - avg_return) ** 2)
    volatility = np.sqrt(variance)
    return volatility

prices = [100, 110, 98, 120, 115]
volatility = calculate_volatility(prices)
print("波动率:", volatility)
```
