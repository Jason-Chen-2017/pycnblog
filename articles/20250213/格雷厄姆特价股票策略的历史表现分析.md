# 第一部分：格雷厄姆特价股票策略概述

## 第1章：格雷厄姆与特价股票策略的背景

### 1.1 本杰明·格雷厄姆的生平简介
本杰明·格雷厄姆（Benjamin Graham）是20世纪最具影响力的价值投资者之一，被誉为“价值投资之父”。他于1894年出生在美国纽约，1920年代开始涉足投资领域，并在1934年出版了经典著作《安全的勇气》（*The Intelligent Investor*），奠定了价值投资的基础。

### 1.2 格雷厄姆的价值投资理论
格雷厄姆的投资理念以“安全边际”为核心，主张通过分析企业的内在价值，寻找市场低估的股票进行投资。他认为，市场情绪波动会导致股票价格与实际价值偏离，投资者应利用这种偏离的机会。

### 1.3 特价股票的定义
格雷厄姆将“特价股票”定义为市场价格显著低于其内在价值的股票。具体而言，当市场价格低于内在价值的一定比例时，该股票即被视为“特价股票”。

## 第2章：特价股票策略的核心概念

### 2.1 安全边际的定义与计算
安全边际是格雷厄姆策略的核心概念，它衡量的是市场价格与内在价值之间的差距。计算公式如下：

$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

当安全边际为正时，股票被视为低估，具有投资价值。

### 2.2 内在价值的评估方法
格雷厄姆认为，内在价值是企业未来现金流的现值。计算公式如下：

$$ V = \frac{E}{1 + r} $$

其中，\( V \) 表示内在价值，\( E \) 表示未来现金流，\( r \) 表示折现率。

### 2.3 市场情绪与投资者心理
格雷厄姆强调市场情绪对企业价值的影响。他认为，市场先生（Mr. Market）是投资者的合作伙伴，而非对手。投资者应以理性的态度看待市场波动，避免被市场情绪左右。

### 6.2 核心代码实现
```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(earnings, discount_rate):
    return earnings / (1 + discount_rate)

def calculate_margin_of_safety(market_price, intrinsic_value):
    return intrinsic_value - market_price

# 示例数据
earnings = 100
discount_rate = 0.1
market_price = 80

intrinsic_value = calculate_intrinsic_value(earnings, discount_rate)
margin_of_safety = calculate_margin_of_safety(market_price, intrinsic_value)

print(f"内在价值: {intrinsic_value}")
print(f"安全边际: {margin_of_safety}")
```
