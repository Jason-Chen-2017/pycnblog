## 第2章：石油行业的背景与现状

### 2.1 石油行业的产业链与价值链
- **上游**：勘探与开采，决定石油的供应量。
- **中游**：炼油与化工，将原油转化为成品。
- **下游**：销售与分销，直接面向消费者。

#### 图2-1：石油行业产业链图（Mermaid图）
```mermaid
graph TD
A[上游：勘探与开采] --> B[中游：炼油与化工]
B --> C[下游：销售与分销]
```

### 2.2 石油行业的财务指标分析
- **关键指标**：市盈率（P/E）、市净率（P/B）、股息率、ROE（净资产收益率）。
- **公式**：
  - 市盈率 = 股价 / 每股收益
  - 市净率 = 股价 / 每股净资产
  - 股息率 = 每股股息 / 股价

### 2.3 石油行业的竞争优势分析
- **成本优势**：低成本开采和炼油能力。
- **资源储备**：拥有丰富石油储备的公司更具竞争力。
- **品牌与市场地位**：知名品牌在市场中更具优势。

## 第3章：巴菲特的投资理念与策略

### 3.1 价值投资的核心要素
- **安全边际**：买入价格低于内在价值，确保投资的安全性。
- **竞争优势**：寻找具有持续竞争优势的公司，如低成本、高市场占有率。

#### 图3-1：价值投资模型（Mermaid图）
```mermaid
graph TD
A[内在价值] --> B[安全边际]
A --> C[竞争优势]
```

### 3.2 巴菲特的长期投资策略
- **集中投资**：将资金集中在少数优质公司，而非分散投资。
- **长期持有**：买入后长期持有，避免频繁交易。

### 3.3 投资决策的数学模型
- **内在价值计算**：
  内在价值 = 净利润 × 股东权益回报率 / 股东权益回报率
  - 示例：假设某公司净利润为100亿，股东权益回报率为15%，则内在价值为 \( 100亿 / 0.15 = 666.67亿 \)。

### 4.2 投资评估的步骤
