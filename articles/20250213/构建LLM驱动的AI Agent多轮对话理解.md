# 第二章: 对话系统的基本架构

## 2.1 对话系统的组成与功能

### 2.1.1 用户输入处理模块
- **输入预处理**：文本清洗、分词、实体识别。
- **输入解析**：意图识别、槽位填充。
- **输入验证**：合法性检查、语义理解。

### 2.1.2 对话历史管理模块
- **对话记录存储**：历史对话的存储与检索。
- **对话上下文管理**：对话状态的维护与更新。
- **对话历史编码**：将对话历史转化为模型可处理的向量表示。

### 2.1.3 响应生成模块
- **生成策略**：基于规则、基于模板、基于模型的生成。
- **生成优化**：多轮对话中的上下文一致性、生成结果的多样性。
- **生成评估**：BLEU、ROUGE、人类评价等生成质量评估方法。

---

## 2.2 LLM在对话系统中的角色

### 2.2.1 LLM作为对话生成器
- **文本生成模型**：GPT系列模型、BERT系列模型。
- **生成策略**：贪心搜索、随机采样、束搜索。
- **生成控制**：温度参数、重复抑制、惩罚项。

### 2.2.2 LLM作为对话理解器
- **文本理解模型**：意图识别、实体识别、情感分析。
- **上下文理解**：对话历史分析、语境推理。
- **多模态理解**：结合视觉、听觉信息的多模态对话理解。

### 2.2.3 LLM与其他NLP技术的结合
- **结合情感分析**：情感驱动的对话生成。
- **结合文本摘要**：基于摘要的对话生成。
- **结合知识图谱**：基于知识图谱的对话生成。
