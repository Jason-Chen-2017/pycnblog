#### 4.1 指标体系构建
- 战略规划能力：$S = \sum_{i=1}^{n} w_i \cdot s_i$
- 执行能力：$E = \sum_{j=1}^{m} w_j \cdot e_j$
- 创新能力：$I = \sum_{k=1}^{l} w_k \cdot i_k$

```python
import pandas as pd
from sklearn.metrics import mean_squared_error
import matplotlib.pyplot as plt

# 数据加载与预处理
data = pd.read_csv('management_exec.csv')
data.dropna(inplace=True)

# 特征与目标分离
X = data[['revenue_growth', 'profit_margin', 'employee_retention']]
y = data['execution_score']

# 模型训练与评估
model = LinearRegression()
model.fit(X, y)
y_pred = model.predict(X)
print('均方误差:', mean_squared_error(y, y_pred))

# 可视化
plt.scatter(y, y_pred)
plt.xlabel('真实值')
plt.ylabel('预测值')
plt.show()
```
