## 第二部分：核心概念与联系

### 第2章：反向思考投资方法的核心概念

#### 2.1 反向思考的定义与特点
- **定义**：反向思考是相对于市场趋势的逆向投资策略，寻找被市场低估的资产。
- **特点**：注重逆周期性，关注市场恐慌时期的低估机会，强调长期持有。

#### 2.2 反向思考与传统投资的对比
- **对比表格**：
| 投资方法 | 传统投资 | 反向思考 |
|----------|----------|----------|
| 策略 | 追踪趋势，顺势而为 | 逆市场趋势，寻找低估 |
| 风险 | 高波动性，可能追高 | 低波动性，风险较低 |
| 适用场景 | 市场繁荣 | 市场恐慌或低迷 |

## 第三部分：算法原理

### 第3章：反向思考的数学模型与公式

#### 3.1 市场估值模型
- **市盈率计算**：
  $$市盈率 = \frac{股价}{每股收益}$$
- **市净率计算**：
  $$市净率 = \frac{股价}{每股净资产}$$

#### 3.2 股票内在价值评估
- **现金流折现模型（DCF）**：
  $$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$
  其中，CF_t为第t年的现金流，r为折现率，TV为终值。

#### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np

def calculate_pe(stock_price, eps):
    return stock_price / eps

def calculate_pfv(stock_price, free_cash_flow, discount_rate, years):
    pv = 0
    for t in range(years):
        cash_flow = free_cash_flow * (1 + 0.05)**t
        pv += cash_flow / (1 + discount_rate)**t
    return pv

# 示例数据
stock_price = 100
eps = 25
free_cash_flow = 1000000
discount_rate = 0.08
years = 5

pe = calculate_pe(stock_price, eps)
pv = calculate_pfv(stock_price, free_cash_flow, discount_rate, years)

print(f"市盈率：{pe}\n现值：{pv}")
```
