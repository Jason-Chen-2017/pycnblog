## 第2章: 股息投资的核心概念与联系

### 2.1 股息投资的核心原理

**股息支付率的计算公式**：股息支付率 = (股息总额 / 净利润) × 100%

**股息增长模型的数学表达**：股息增长模型的公式为：

$$ V = \frac{D_1}{r - g} $$

其中，V是股票的内在价值，D1是下一年度的股息，r是折现率，g是股息增长率。

**股息与股票价值的关系**：股息是股票价值的重要组成部分，稳定的股息支付能力能够提升股票的内在价值。

---

### 2.2 核心概念对比分析

**股息投资与资本增值的对比**：股息投资注重稳定的现金流，资本增值注重股价的上涨。

**股息率与市盈率的对比**：股息率是股息与股价的比率，市盈率是股价与每股收益的比率。

**股息支付率与股息增长的对比**：股息支付率反映企业股息支付能力，股息增长反映企业股息增长能力。

### 5.1 环境安装

### 5.2 核心代码实现

```python
import pandas as pd
import numpy as np

def calculate_dividend_growth(dividends, growth_rate, discount_rate):
    return dividends * (1 + growth_rate) / (discount_rate - growth_rate)

data = pd.read_csv('stock_data.csv')
dividends = data['dividends'].values
growth_rate = 0.05
discount_rate = 0.10

intrinsic_value = calculate_dividend_growth(dividends, growth_rate, discount_rate)
print(intrinsic_value)
```

### 5.3 实际案例分析

$$ V = \frac{2 \times (1 + 0.05)}{0.10 - 0.05} = 44元 $$
