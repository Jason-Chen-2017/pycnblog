### 第2章：股票组合投资的基本原理

#### 2.1 股票组合的概念与作用

- **2.1.1 股票组合的定义**
  - 股票组合：将资金分配到多个股票，以降低风险并提高收益。

- **2.1.2 股票组合的优势**
  - 分散风险：避免单一股票波动带来的损失。
  - 稳定收益：通过多样化投资平滑市场波动。

- **2.1.3 投资组合的风险管理**
  - 风险调整后的收益：考虑风险后的实际收益。
  - 风险分散：通过不同行业和公司的选择，降低特定风险。

#### 2.2 彼得·林奇的25只股票组合策略

- **2.2.1 25只股票组合的背景与目标**
  - 构建一个包含25只股票的组合，涵盖多个行业和市场，以实现长期稳健的收益。
  - 目标：分散风险，捕捉长期增长机会。

- **2.2.2 组合中的股票类型与比例分配**

- **2.2.3 组合的长期与短期目标**
  - 长期目标：实现资本增值，跑赢市场。
  - 短期目标：保持稳定性，减少波动性。

### 第3章：彼得·林奇的投资策略分析

#### 3.1 股票选择标准

- **3.1.1 公司基本面分析**
  - 财务健康：关注利润、收入、负债等指标。
  - 竞争优势：公司是否在行业中具备独特优势。

- **3.1.2 财务指标评估**
  - 市盈率（P/E）：股价与每股收益的比率。
  - 市净率（P/B）：股价与每股净资产的比率。
  - 股息率：每年派发的股息与股价的比率。

- **3.1.3 行业地位与竞争优势**
  - 是否是行业龙头。
  - 是否具备可持续的竞争优势（如专利、品牌等）。

#### 3.2 投资组合的分散化策略

- **3.2.1 分散化投资的原理**
  - 不将所有资金投入到单一股票或行业。
  - 通过多样化降低特定风险。

- **3.2.2 不同行业与市场的分布**
  - 行业分散：涵盖多个行业，避免行业周期性风险。
  - 地区分散：投资于不同地区的市场，降低区域风险。

- **3.2.3 如何平衡风险与收益**
  - 通过权重分配控制风险。
  - 定期评估和调整组合。

#### 3.3 定期评估与调整策略

- **3.3.1 定期评估的必要性**
  - 市场变化：行业趋势、经济周期等。
  - 股票表现：个别股票的涨跌。

- **3.3.2 调整股票的时机与方法**
  - 时机：定期（如季度末）评估组合。
  - 方法：替换表现不佳的股票，增加表现好的股票。

- **3.3.3 调整后的效果评估**
  - 组合收益与风险的变化。
  - 是否偏离初始目标。

### 第4章：数学模型与投资决策

#### 4.1 投资组合的数学模型

- **4.1.1 CAPM模型的介绍与应用**
  - CAPM（资本资产定价模型）：确定资产的预期收益。
  - 公式：$$ E(r_i) = r_f + \beta_i (E(r_m) - r_f) $$
    - \( E(r_i) \)：股票i的预期收益。
    - \( r_f \)：无风险利率。
    - \( \beta_i \)：股票i的贝塔系数（衡量系统性风险）。
    - \( E(r_m) \)：市场预期收益。

- **4.1.2 马科维茨的有效前沿理论**
  - 通过优化投资组合的收益与风险，找到最优组合。

- **4.1.3 如何用数学模型优化投资组合**
  - 使用优化算法（如二次规划）求解最优权重。
  - 结合实际投资目标调整模型。

#### 4.2 投资组合的风险与收益分析

- **4.2.1 风险的度量方法**
  - 方差：衡量收益波动性。

  from scipy.optimize import minimize

  def optimize_portfolio(returns):
      n = len(returns.columns)
      # 初始化权重
      initial_weights = np.array([1/n]*n)
      # 定义优化目标函数
      def objective(weights):
          return - (weights.T @ returns.mean(axis=1))
      # 约束条件：权重之和为1
      constraints = {'type': 'eq', 'fun': lambda w: sum(w) - 1}
      # 求解优化问题
      result = minimize(objective, initial_weights, constraints=constraints)
      return result.x
