## 第3章: 需求预测模型的算法原理

### 3.1 常见的预测算法

#### 3.1.1 线性回归

##### 3.1.1.1 线性回归的原理
线性回归通过最小化预测值与实际值的平方差，建立变量之间的线性关系。

##### 3.1.1.2 线性回归的数学公式
$$ y = \beta_0 + \beta_1x + \epsilon $$

##### 3.1.1.3 线性回归的流程图
```mermaid
graph LR
    A[输入数据] --> B[计算预测值]
    B --> C[计算误差]
    C --> D[更新参数]
    D --> E[是否收敛？]
    E --> F[是则结束，否则返回B]
```

##### 3.1.1.4 Python实现示例
```python
import numpy as np
from sklearn.linear_model import LinearRegression

X = np.array([[1], [2], [3], [4]])
y = np.array([2, 4, 5, 4])
model = LinearRegression()
model.fit(X, y)
print(model.predict([[5]]))
```

#### 3.1.2 随机森林

##### 3.1.2.1 随机森林的原理
随机森林通过构建多个决策树并行集成，提高预测准确性和鲁棒性。

##### 3.1.2.2 随机森林的流程图
```mermaid
graph LR
    A[输入数据] --> B[生成样本集]
    B --> C[构建决策树]
    C --> D[集成预测结果]
    D --> E[输出最终预测]
```

##### 3.1.2.3 Python实现示例
```python
from sklearn.ensemble import RandomForestRegressor

X = np.array([[1, 2], [3, 4], [5, 6]])
y = np.array([3, 5, 7])
model = RandomForestRegressor(n_estimators=100)
model.fit(X, y)
print(model.predict([[7, 8]]))
```

### 3.2 深度学习模型

#### 3.2.1 神经网络

##### 3.2.1.1 神经网络的原理
神经网络通过多层感知机模拟人脑神经网络，学习数据的非线性关系。

##### 3.2.1.2 神经网络的数学公式
$$ y = \sigma(wx + b) $$

##### 3.2.1.3 神经网络的流程图
```mermaid
graph LR
    A[输入层] --> B[隐藏层]
    B --> C[输出层]
    C --> D[预测结果]
```

##### 3.2.1.4 Python实现示例
```python
import tensorflow as tf
import numpy as np

X = np.array([[0.0], [1.0], [2.0], [3.0]])
y = np.array([[0.0], [1.0], [2.0], [3.0]])

model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(1)
])
model.compile(optimizer='adam', loss='mean_squared_error')
model.fit(X, y, epochs=100)
print(model.predict([[4.0]]))
```
