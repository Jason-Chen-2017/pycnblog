## 第7章：安全边际的数学模型与算法实现

### 7.1 安全边际的数学模型

#### 7.1.1 安全边际的定义公式
$$\text{安全边际} = \text{市场价格} - \text{内在价值}$$

#### 7.1.2 内在价值的计算公式
$$\text{内在价值} = \frac{\text{每股收益} \times (1 + g)}{r - g}$$
其中，$g$ 是增长率，$r$ 是期望回报率。

#### 7.1.3 安全边际的计算步骤
1. 计算目标公司的内在价值。
2. 比较市场价格与内在价值。
3. 确定安全边际的大小。

### 7.2 安全边际的算法实现

#### 7.2.1 Python代码实现
```python
def calculate_margin_of_safety(price, intrinsic_value):
    return price - intrinsic_value

# 示例计算
price = 50
intrinsic_value = 40
margin_of_safety = calculate_margin_of_safety(price, intrinsic_value)
print(f"安全边际为: {margin_of_safety}")
```

def calculate_intrinsic_value(eps, growth_rate, required_return):
