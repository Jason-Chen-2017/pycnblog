## 第三章：供应商调研方法

### 3.1 数据收集与清洗
- 数据来源：供应商的历史交易数据、财务报表、市场报告。
- 数据清洗：去除重复、错误和不完整数据。

### 3.2 供应商评估指标
| 指标 | 描述 |
|------|------|
| 成本 | 供应商报价的竞争力。 |
| 质量 | 产品的一致性和可靠性。 |
| 交货时间 | 供应商按时交付的能力。 |
| 售后服务 | 供应商的售后服务质量。 |

### 3.3 供应商调研的数学模型
- **供应商评分模型**：
  $$ S = w_1 \cdot C + w_2 \cdot Q + w_3 \cdot T + w_4 \cdot S $$
  其中，\( w \) 表示各指标的权重，\( C \)、\( Q \)、\( T \)、\( S \) 表示各指标的评分。

### 3.4 算法实现
- 使用Python构建供应商评分系统：
  ```python
  import pandas as pd

  # 数据读取
  data = pd.read_csv('supplier.csv')

  # 加权计算
  weights = [0.4, 0.3, 0.2, 0.1]
  scores = []
  for row in data.itertuples():
      score = sum(weights[i] * getattr(row, col) for i, col in enumerate(['C', 'Q', 'T', 'S']))
      scores.append(score)

  # 结果输出
  data['Total Score'] = scores
  print(data.head())
  ```

## 第四章：客户调研方法

### 4.1 数据收集与清洗
- 数据来源：客户反馈、销售记录、市场调研。
- 数据清洗：处理缺失值和异常值。

### 4.2 客户评估指标
| 指标 | 描述 |
|------|------|
| 满意度 | 客户对产品或服务的满意程度。 |
| 忠诚度 | 客户重复购买的可能性。 |
| 反馈频率 | 客户提供反馈的频率。 |

### 4.3 客户调研的数学模型
- **客户满意度模型**：
  $$ S = w_1 \cdot F + w_2 \cdot L + w_3 \cdot R $$
  其中，\( F \) 表示反馈频率，\( L \) 表示忠诚度，\( R \) 表示推荐率。

### 4.4 算法实现
- 使用Python构建客户满意度系统：
  ```python
  import pandas as pd

  # 数据读取
  data = pd.read_csv('customer.csv')

  # 加权计算
  weights = [0.5, 0.3, 0.2]
  scores = []
  for row in data.itertuples():
      score = sum(weights[i] * getattr(row, col) for i, col in enumerate(['F', 'L', 'R']))
      scores.append(score)

  # 结果输出
  data['Total Score'] = scores
  print(data.head())
  ```

## 第六章：项目实战与最佳实践

### 6.1 项目环境安装
- 安装必要的库：`pip install pandas matplotlib`

### 6.2 核心代码实现
```python
import pandas as pd
import matplotlib.pyplot as plt

# 供应商评分
def supplier_score(data, weights):
    scores = []
    for row in data.itertuples():
        score = sum(weights[i] * getattr(row, col) for i, col in enumerate(['C', 'Q', 'T', 'S']))
        scores.append(score)
    return scores

# 客户满意度
def customer_satisfaction(data, weights):
    scores = []
    for row in data.itertuples():
        score = sum(weights[i] * getattr(row, col) for i, col in enumerate(['F', 'L', 'R']))
        scores.append(score)
    return scores

# 可视化
def visualize(data, scores, title):
    plt.figure(figsize=(10, 6))
    plt.bar(data['id'], scores)
    plt.title(title)
    plt.xlabel('ID')
    plt.ylabel('Score')
    plt.show()

# 主程序
if __name__ == "__main__":
    # 供应商数据
    data_supplier = pd.read_csv('supplier.csv')
    weights_supplier = [0.4, 0.3, 0.2, 0.1]
    scores_supplier = supplier_score(data_supplier, weights_supplier)
    visualize(data_supplier['id'], scores_supplier, '供应商评分')

    # 客户数据
    data_customer = pd.read_csv('customer.csv')
    weights_customer = [0.5, 0.3, 0.2]
    scores_customer = customer_satisfaction(data_customer, weights_customer)
    visualize(data_customer['id'], scores_customer, '客户满意度')
```
