## 第一部分：引言

### 第1章：问题背景与核心概念

#### 1.1 问题背景

当前，全球面临粮食安全和环境保护的双重挑战。传统农业模式导致资源枯竭、环境污染，可持续农业成为解决这些问题的关键。

#### 1.2 问题描述

传统农业过度依赖化肥和农药，导致土壤退化、水资源污染，同时加剧气候变化。这些问题威胁全球粮食安全。

#### 1.3 问题解决

可持续农业通过生态种植、有机农业等方法，减少环境影响，提高资源利用效率。

#### 1.4 核心概念

- **核心概念：** 可持续农业强调环境、经济和社会三者的平衡，采用生态友好的生产方式。
- **对比表格：**

## 第三部分：投资策略与分析方法

### 第3章：可持续农业的投资评估

#### 3.1 数学模型

**净现值计算公式：**

$$ NPV = \sum_{t=0}^{n} \frac{C_t}{(1+r)^t} $$

其中，$C_t$为第$t$年的现金流，$r$为折现率。

import numpy as np
import pandas as pd

# 净现值计算
def calculate_npv(cash_flows, discount_rate):
    return np.npv(discount_rate, *cash_flows)

# 示例数据
cash_flows = [-100, 30, 30, 30]
discount_rate = 0.1

npv = calculate_npv(cash_flows, discount_rate)
