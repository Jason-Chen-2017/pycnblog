## 核心概念与联系

### 安全边际的定义与内涵

安全边际是指股票的市场价格低于其内在价值的差额。这一差额为投资者提供了缓冲区，即使市场波动或公司基本面发生变化，也能在一定程度上保护投资者免受损失。

| 核心概念 | 定义 | 作用 |
|----------|------|------|
| 内在价值 | 公司未来现金流的现值 | 作为评估股票价值的基础 |
| 市场价格 | 当前股票的交易价格 | 反映市场对公司的估值 |
| 安全边际 | 内在价值 - 市场价格 | 提供保护投资者的缓冲空间 |

### 格雷厄姆安全边际公式

$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

---

## 安全边际的计算与评估

### 安全边际计算的数学模型

格雷厄姆的安全边际计算公式：

$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

其中，内在价值可以通过DCF模型计算：

$$ \text{内在价值} = \frac{\text{现金流}}{\text{折现率}} $$

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(enterprise_value, free_cash_flow, discount_rate):
    return enterprise_value / discount_rate

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
market_price = 50
enterprise_value = 200
free_cash_flow = 100
discount_rate = 0.1

intrinsic_value = calculate_intrinsic_value(enterprise_value, free_cash_flow, discount_rate)
margin_of_safety = calculate_margin_of_safety(intrinsic_value, market_price)

print(f"内在价值: {intrinsic_value}")
print(f"安全边际: {margin_of_safety}")
```
