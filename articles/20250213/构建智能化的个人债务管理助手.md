#### 3.3 债务优化建议算法
- 3.3.1 贪心算法
  ```python
  def greedy_algorithm(debts):
      while True:
          max_debt = max(debts, key=lambda x: x['amount'])
          max_debt['amount'] -= 1
          if all(d['amount'] == 0 for d in debts):
              break
      return debts
  ```

- 3.3.2 动态规划算法
  ```python
  def dynamic_planning(debts):
      n = len(debts)
      dp = [[0] * (n+1) for _ in range(n+1)]
      for i in range(1, n+1):
          for j in range(1, n+1):
              if i == j:
                  dp[i][j] = 0
              else:
                  dp[i][j] = max(dp[i-1][j], dp[i][j-1] + debts[j-1]['amount'])
      return dp[n][n]
  ```
