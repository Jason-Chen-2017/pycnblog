# 第1章: 巴菲特护城河理论的背景与核心概念

## 1.1 护城河理论的起源与演变  
### 1.1.1 护城河理论的起源  
护城河理论由巴菲特提出，核心思想是企业通过构建独特的竞争优势（如成本优势、网络效应等），防止竞争对手侵蚀其市场份额。这些竞争优势就像中世纪城堡的护城河，为企业提供长期的防御能力。

### 1.1.2 护城河理论的演变历程  
1. **1.0版本**：基于财务指标和成本优势。  
2. **2.0版本**：引入网络效应和品牌忠诚度。  
3. **3.0版本**：加入技术创新和知识产权。  
4. **4.0版本**：数据驱动的决策优势逐渐崛起。  
5. **5.0版本**：数据主权成为核心竞争优势。  

### 1.1.3 护城河理论的核心思想  
- 企业竞争优势是动态变化的。  
- 护城河的核心是不可复制的资源和能力。  
- 数据主权是未来竞争优势的关键。

---

## 1.2 数据主权时代的竞争优势  
### 1.2.1 数据主权的定义与内涵  
数据主权是指企业在数据的生成、存储、处理和使用过程中，对数据的控制权和使用权的合法权利。它包括数据的法律主权、技术主权和生态主权。

### 1.2.2 数据主权与企业竞争优势的关系  
- 数据主权是企业构建护城河的核心资源。  
- 数据驱动的决策优势让企业能够在竞争中占据先机。  
- 数据主权的生态系统让企业能够形成协同效应。

### 1.2.3 护城河理论5.0的核心特征  
- 数据主权是护城河的核心要素。  
- 数据驱动的决策能力成为竞争优势的关键。  
- 技术创新与数据主权的结合是未来发展的方向。

def calculate_shielding_strength(data, weights):
    # 计算数据主权指数
    numerator = sum(w * d for w, d in zip(weights, data))
    denominator = sum(weights)
    shielding_strength = numerator / denominator
    return shielding_strength

# 示例数据和权重
