## 第三部分：算法原理讲解

### 第3章：创新能力评估的算法原理

#### 3.1 层次分析法（AHP）概述  
层次分析法（AHP）是一种用于多指标决策的定量分析方法。其基本原理是将复杂问题分解为多个层次，通过比较各层次要素的重要性，确定其权重。  

#### 3.2 算法实现  
以下是层次分析法的Python实现代码示例：

```python
import numpy as np

def ahp(matrix, n_criterias, nalternatives):
    # 计算一致性检验
    n = len(matrix)
    # 计算权重向量
    weights = np.mean(matrix, axis=0)
    # 归一化权重向量
    weights = weights / np.sum(weights)
    # 计算一致性比率
    CR = 0
    return weights, CR

# 示例矩阵（判断矩阵）
matrix = [
    [1, 2, 3],
    [1/2, 1, 4],
    [1/3, 1/4, 1]
]

n_criterias = 3
nalternatives = 3

weights, CR = ahp(matrix, n_criterias, nalternatives)
print("权重向量：", weights)
```

#### 3.3 数学模型与公式  
层次分析法的数学模型如下：

$$
\text{判断矩阵} = \begin{bmatrix}
1 & a_{12} & a_{13} \\
a_{21} & 1 & a_{23} \\
a_{31} & a_{32} & 1
\end{bmatrix}
$$

权重计算公式：

$$
w_i = \frac{\sum_{j=1}^{n} a_{ij}}{\sum_{i=1}^{n} \sum_{j=1}^{n} a_{ij}}
$$

一致性检验公式：

$$
CR = \frac{\lambda_{max} - n}{n - 1} \times \frac{0.116}{\sqrt{n}}
$$
