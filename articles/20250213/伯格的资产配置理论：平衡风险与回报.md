# 第1章: 资产配置理论基础

## 1.1 资产配置的基本概念与背景

### 1.1.1 资产配置的定义与背景
- **定义**：资产配置是指将投资资金分配到不同资产类别（如股票、债券、现金等）中的过程，以实现风险与回报的最佳平衡。
- **背景**：现代投资组合理论（MPT）由哈里·马科维茨提出，为伯格理论奠定了基础。
- **重要性**：资产配置是投资成功的关键，帮助投资者在不同市场环境下优化收益。

### 1.1.2 资产配置的核心要素
- **投资目标**：明确投资目的，如保值、增值或追求高回报。
- **风险承受能力**：评估投资者对本金波动的容忍度，决定资产分配比例。
- **资产类别**：选择股票、债券、房地产等不同类别，分散风险。

## 1.2 资产配置与投资回报的关系
- **风险与回报的权衡**：高风险资产可能带来高回报，但需谨慎评估。
- **分散化效应**：通过多样化投资降低风险，提升整体回报。

## 1.3 资产配置的核心要素对比表格
| 要素       | 定义                                | 重要性       | 示例               |
|------------|-----------------------------------|--------------|--------------------|
| 投资目标   | 投资者希望通过投资实现的目标        | 核心要素     | 退休资金增值       |
| 风险承受能力 | 投资者对本金波动的容忍度          | 关键因素     | 高风险承受能力     |
| 资产类别   | 不同类型的资产（股票、债券、现金等） | 核心要素     | 股票、债券、房地产 |

# 第2章: 伯格的资产配置理论概述

## 2.1 伯格理论的核心思想
- **现代投资组合理论（MPT）**：伯格的理论基于MPT，强调通过分散投资降低风险。
- **有效前沿**：投资组合在给定风险下提供最高回报，或在给定回报下具有最低风险。

## 2.2 伯格理论的数学模型
### 2.2.1 数学模型
伯格理论的核心是优化投资组合的均值-方差。公式如下：
$$
\text{Minimize } \sigma^2 \text{ subject to } \mathbf{w}^T\mathbf{r} = R
$$
其中，$\mathbf{w}$是权重向量，$\mathbf{r}$是收益向量，$R$是目标收益。

### 2.2.2 Python实现
```python
import numpy as np

def mean_variance_optimization(r, cov, target_return):
    n = len(r)
    # 构建优化问题
    G = np.zeros(n)
    h = 0
    A = -np.ones(n)
    b = -target_return
    # 求解
    w = np.linalg.solve(cov, G)
    w = w / np.sum(w)
    return w
```
