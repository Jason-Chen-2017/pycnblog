## 第一部分：价值投资概述

### 第1章：价值投资的起源与核心理念

#### 1.1 价值投资的起源
- **1.1.1 价值投资的定义与核心理念**  
  价值投资是一种基于对企业内在价值评估的投资策略，强调以低于内在价值的价格买入优质资产，长期持有，等待价值的实现。其核心理念包括：企业基本面分析、安全边际、长期持有。

- **1.1.2 价值投资与基本面分析的关系**  
  价值投资的本质是通过基本面分析，识别出那些具有竞争优势、财务健康、良好管理的企业，并以合理的价格买入，长期持有。

- **1.1.3 价值投资与其他投资策略的对比**  
  与短线交易、成长投资等策略相比，价值投资更注重企业的内在价值，强调长期持有的纪律性。

#### 1.2 约翰·汤普金斯的贡献
- **1.2.1 约翰·汤普金斯的生平简介**  
  约翰·汤普金斯是价值投资领域的权威，以其对耐心型价值投资的深入研究而闻名。他强调长期持有优质资产，通过时间的积累实现财富增长。

- **1.2.2 耐心型价值投资的提出背景**  
  在市场波动加剧、短期交易盛行的背景下，汤普金斯提出耐心型价值投资，倡导投资者回归基本面，避免短期市场干扰。

- **1.2.3 耐心型价值投资的核心思想**  
  通过长期持有优质资产，利用复利效应，实现财富的稳步增长。强调安全边际和对企业内在价值的深刻理解。

## 第二部分：耐心型价值投资的核心理念

### 第2章：耐心型价值投资的定义与特点

#### 2.1 耐心型价值投资的定义
- **2.1.1 耐心型价值投资的定义**  
  耐心型价值投资是一种以长期持有优质资产为核心策略的投资方式，强调对企业内在价值的深刻理解，避免短期市场波动的干扰。

- **2.1.2 耐心型价值投资的核心要素**  
  包括对企业基本面的深入分析、安全边际的设定、长期持有纪律的执行。

#### 2.2 耐心型价值投资的特点
- **2.2.1 长期持有的投资策略**  
  耐心型价值投资强调长期持有，避免频繁交易，利用复利效应实现财富增长。

- **2.2.2 选择优质企业的标准**  
  优质企业具有强大的竞争优势、稳定的财务状况、良好的管理团队和可持续的盈利能力。

- **2.2.3 风险控制与安全边际**  
  通过设定安全边际（即买入价格低于内在价值），降低投资风险，确保投资的安全性。

### 第3章：价值投资的核心概念与联系

#### 3.1 核心概念原理
- **3.1.1 企业价值的评估方法**  
  企业价值=净利润×（1+再投资率）/资本成本。  
  企业价值的评估需要考虑企业的盈利能力、成长性、竞争优势等因素。

- **3.1.2 股票内在价值的计算公式**  
  内在价值=企业价值/发行在外的普通股数量。  
  其中，企业价值=息税前利润×（1 - 税率）/加权平均资本成本。

- **3.1.3 股东权益与企业盈利的关系**  
  股东权益是企业价值的重要组成部分，股东权益的增加意味着企业盈利能力的提升，进而影响股票的内在价值。

#### 3.2 核心概念属性特征对比表格
| 核心概念       | 价值投资                | 成长投资                |
|----------------|-------------------------|-------------------------|
| 核心目标       | 寻找低估的优质企业      | 寻找高成长的潜力企业    |
| 投资期限       | 长期持有                | 短期持有                |
| 风险控制       | 强调安全边际            | 更注重成长性            |
| 估值方法       | 基于内在价值            | 基于未来增长率          |

### 第4章：价值评估模型的构建与分析

#### 4.1 算法原理讲解
- **4.1.1 算法流程图：价值评估模型的构建步骤**  
  ```mermaid
  graph TD
      A[开始] --> B[收集企业基本面数据]
      B --> C[计算企业价值]
      C --> D[确定安全边际]
      D --> E[得出买入建议]
      E --> F[结束]
  ```

- **4.1.2 价值评估模型的数学公式**  
  内在价值计算公式：  
  $$ \text{内在价值} = \frac{\text{自由现金流}}{\text{资本成本}} $$  
  其中，自由现金流=净利润 - 投资支出，资本成本=加权平均资本成本。

- **4.1.3 价值评估模型的实现代码**  
  ```python
  def calculate_intrinsic_value(enterprise_value, shares_outstanding):
      intrinsic_value = enterprise_value / shares_outstanding
      return intrinsic_value

  # 示例数据
  enterprise_value = 1000000000  # 企业价值（美元）
  shares_outstanding = 100000000  # 发行在外的普通股数量
  print(f"内在价值：{calculate_intrinsic_value(enterprise_value, shares_outstanding)}美元")
  ```

#### 4.2 数学模型与公式
- **4.2.1 内在价值的计算公式**  
  $$ \text{内在价值} = \frac{\text{企业价值}}{\text{发行在外的普通股数量}} $$  
  其中，企业价值=息税前利润×（1 - 税率）/加权平均资本成本。

- **4.2.2 企业价值的计算公式**  
  $$ \text{企业价值} = \frac{\text{净利润}}{\text{资本成本}} \times (1 + \text{再投资率}) $$
