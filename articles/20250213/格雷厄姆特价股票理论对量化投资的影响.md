# 第一部分: 格雷厄姆特价股票理论概述

## 第1章: 格雷厄姆特价股票理论的核心思想

### 1.1 格雷厄姆投资理论的起源与发展

#### 1.1.1 投资理论的演变历程
- **早期投资理论**：从基本面分析到技术分析的发展。
- **格雷厄姆的贡献**：提出价值投资理念，强调股票的内在价值。

#### 1.1.2 格雷厄姆的价值投资理念
- **内在价值**：股票的真正价值是其未来现金流的现值。
- **安全边际**：以低于内在价值的价格买入股票，降低风险。

#### 1.1.3 特价股票的概念与特点
- **特价股票**：价格低于内在价值的股票。
- **特点**：低估、高分红、低波动性。

### 1.2 格雷厄姆投资策略的核心要素

#### 1.2.1 股票的内在价值计算
- **公式**：$V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}$
  - $V$：内在价值
  - $CF_t$：第t年的现金流
  - $r$：折现率

#### 1.2.2 安全边际的定义与作用
- **安全边际**：买入价格与内在价值的差距。
- **作用**：降低市场波动带来的风险。

#### 1.2.3 高质量企业的筛选标准
- **标准**：稳定的收益、低负债、高利润率。

### 1.3 格雷厄姆投资哲学的现代意义

#### 1.3.1 价值投资与市场波动的关系
- **价值投资**：市场波动是机会，而非风险。

#### 1.3.2 长期投资与短期交易的平衡
- **长期视角**：注重内在价值，忽略短期波动。

#### 1.3.3 格雷厄姆理论对投资者心态的影响
- **心态管理**：克服贪婪与恐惧，坚持长期策略。

#### 5.2.1 均值回归策略的实现
- **代码示例**：
  ```python
  def calculate_intrinsic_value(stock_data):
      # 计算现金流
      cash_flows = stock_data['earnings'].sum()
      # 折现率
      r = 0.1
      # 内在价值
      intrinsic_value = cash_flows / (1 + r)
      return intrinsic_value
  ```
