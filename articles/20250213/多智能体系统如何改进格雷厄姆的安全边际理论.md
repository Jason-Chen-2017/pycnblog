## 第1章: 多智能体系统概述

### 1.1 多智能体系统的定义与特点

#### 1.1.1 多智能体系统的定义
多智能体系统（Multi-Agent System, MAS）是由多个智能体组成的系统，这些智能体能够自主决策、协作和竞争，共同完成复杂任务。

#### 1.1.2 多智能体系统的核心特点
1. 分布式：多个智能体独立运行。
2. 协作性：智能体之间通过通信协作。
3. 反应性：能实时感知环境并做出反应。
4. 社会性：智能体之间有明确的社会角色。

#### 1.1.3 多智能体系统与传统单体系统的区别
| 特性         | 多智能体系统                | 单体系统                  |
|--------------|---------------------------|--------------------------|
| 结构         | 分布式结构                | 集中式结构              |
| 通信         | 智能体之间通信            | 单体内部处理             |
| 决策         | 分布式决策                | 中央决策                 |

### 1.2 安全边际理论概述

#### 1.2.1 安全边际的定义
安全边际是投资学中的一个重要概念，指的是资产的内在价值与市场价格之间的差额。

#### 1.2.2 格雷厄姆的安全边际理论
格雷厄姆强调，在投资时应选择市场价格低于内在价值的资产，以确保安全边际的存在。

#### 1.2.3 安全边际在投资中的应用
通过计算安全边际，投资者可以评估投资的风险和收益，做出更稳健的投资决策。

```python
class Agent:
    def __init__(self, id):
        self.id = id
        self.value = 0
        self.price = 0

    def calculate_margin(self):
        return self.value - self.price

agents = [Agent(i) for i in range(5)]
for agent in agents:
    agent.value = 100
    agent.price = 90
    print(f"Agent {agent.id}: 安全边际为 {agent.calculate_margin()}")
```
