#### 2.2 极端后果思维的数学模型

#### 5.2 核心实现源代码  
以下是一个简单的极端后果思维的Python实现代码：

```python
import numpy as np

def extreme_consequences_analysis(portfolio):
    # 计算每种投资标的的极端后果概率
    probabilities = {}
    for asset in portfolio:
        probabilities[asset] = np.random.uniform(0, 1)
    # 返回最高概率的极端后果
    return max(probabilities, key=probabilities.get)

portfolio = ["股票A", "债券B", "基金C"]
result = extreme_consequences_analysis(portfolio)
print(result)
```
