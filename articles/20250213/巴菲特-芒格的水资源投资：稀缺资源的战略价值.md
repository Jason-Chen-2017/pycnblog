## 第四部分: 水资源投资的技术方法

### 第6章: 水资源投资的数学模型与算法

#### 6.1 水资源投资的数学模型
- 现值法（Present Value Method）
  $$ PV = \frac{CF}{(1 + r)^n} $$
- 净现值法（Net Present Value Method）
  $$ NPV = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$
- 内部收益率法（Internal Rate of Return Method）
  $$ IRR = r \text{ 使得 } NPV = 0 $$

#### 6.2 水资源投资的算法实现
- 时间序列分析：预测水资源需求的变化趋势。

      # 使用简单平均法预测

  predicted = [train_data[0]] * len(test_data)
