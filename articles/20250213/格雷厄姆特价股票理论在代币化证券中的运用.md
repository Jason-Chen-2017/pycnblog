## 第一部分: 格雷厄姆投资理论与代币化证券的背景介绍

### 第1章: 格雷厄姆投资理论概述

#### 1.1 格雷厄姆投资理论的核心概念
格雷厄姆价值投资理论是现代投资学的重要基石，其核心理念是寻找市场价格低于其内在价值的证券进行投资。以下是格雷厄姆理论的关键点：

- **安全边际**：格雷厄姆强调在投资时，市场价格应显著低于内在价值，以确保投资的安全性。
- **低市盈率与低市净率**：格雷厄姆倾向于投资市盈率和市净率较低的股票，认为这些股票更有可能被市场低估。
- **价值评估**：格雷厄姆提出了多种方法来评估证券的内在价值，包括股息贴现模型和资产重置价值评估。

#### 1.2 格雷厄姆投资理论的数学模型
格雷厄姆的价值评估方法可以用以下公式表示：
$$
\text{内在价值} = \text{股息} \times (1 + \text{增长率})^{-1}
$$

### 第2章: 代币化证券的基本概念

#### 2.1 代币化证券的定义与特征
代币化证券是指通过区块链技术将传统证券（如股票、债券等）数字化，使其以代币形式存在于区块链上。以下是代币化证券的主要特征：

- **可分割性**：代币化证券可以被分割成更小的单位，提高流动性。
- **透明性**：区块链技术确保了代币化证券的交易记录公开、透明。
- **智能合约**：代币化证券可以通过智能合约自动执行交易和结算，减少中间人和交易成本。

#### 2.2 代币化证券的优势与挑战
- **优势**：
  - 提高交易效率
  - 降低交易成本
  - 增强透明度和信任
- **挑战**：
  - 技术复杂性
  - 法律与监管不确定性
  - 市场波动性

格雷厄姆的安全边际计算方法如下：
$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

#### 5.2 低市盈率与低市净率的计算公式
- 市盈率公式：
$$
\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}

- 市净率公式：
$$
\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}

def calculate_intrinsic_value(stock_price, earnings_per_share):
    pe_ratio = stock_price / earnings_per_share
    if pe_ratio < 15:  # 假设格雷厄姆的低市盈率标准为15
        return "低估"
    else:
        return "高估"

# 示例数据

}
