## 第三部分：算法原理讲解

### 第3章：动态任务规划算法

#### 3.1 Dijkstra算法
- 算法原理：
  Dijkstra算法用于单源最短路径问题，通过优先队列选择当前最短路径，逐步扩展到目标节点。
- 算法流程：
  1. 初始化起点，设置距离为0，其他节点距离为无穷大。
  2. 使用优先队列选择距离最小的节点，扩展其邻居节点。
  3. 更新邻居节点的距离，重复直到队列为空或找到目标节点。
- 算法实现：
  ```python
  import heapq

  def dijkstra(graph, start, end):
      dist = {node: float('inf') for node in graph}
      dist[start] = 0
      heap = [(0, start)]
      visited = set()

      while heap:
          current_dist, current_node = heapq.heappop(heap)
          if current_node in visited:
              continue
          visited.add(current_node)
          if current_node == end:
              break
          for neighbor, weight in graph[current_node].items():
              if dist[neighbor] > current_dist + weight:
                  dist[neighbor] = current_dist + weight
                  heapq.heappush(heap, (dist[neighbor], neighbor))
      return dist[end]
  ```
- 示例：
  ```mermaid
  graph LR
      A[起点] --> B[邻居节点]
      B --> C[邻居节点]
      C --> D[终点]
  ```
  ```latex
  $$\text{起点到终点的最短路径权重} = 4$$
  ```

#### 3.2 A*算法
- 算法原理：
  A*算法结合了Dijkstra和最佳优先搜索，使用启发式函数评估节点优先级。
- 算法流程：
  1. 初始化起点，设置距离为0，优先级函数为0。
  2. 选择优先级最高的节点，扩展其邻居节点。
  3. 更新邻居节点的距离和优先级，重复直到找到目标节点。
- 算法实现：
  ```python
  import heapq

  def a_star(graph, start, end, heuristic):
      dist = {node: float('inf') for node in graph}
      dist[start] = 0
      heap = [(0, start)]
      visited = set()

      while heap:
          current_priority, current_node = heapq.heappop(heap)
          if current_node in visited:
              continue
          visited.add(current_node)
          if current_node == end:
              break
          for neighbor, weight in graph[current_node].items():
              new_dist = dist[current_node] + weight
              if new_dist < dist[neighbor]:
                  dist[neighbor] = new_dist
                  heuristic_val = heuristic(neighbor, end)
                  heapq.heappush(heap, (new_dist + heuristic_val, neighbor))
      return dist[end]
  ```
- 示例：

      A[起点] --> B[邻居节点]
      B --> C[邻居节点]
      C --> D[终点]
  ```

  $$g(n) \text{：当前节点到起点的实际距离}$$
  $$h(n) \text{：当前节点到终点的估计距离}$$
  ```
