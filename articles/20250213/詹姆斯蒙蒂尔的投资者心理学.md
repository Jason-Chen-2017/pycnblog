## 第二部分：投资者心理学的核心概念与联系

### 第2章：认知偏差与投资者决策

#### 2.1 认知偏差的定义与分类

- **2.1.1 认知偏差的定义**
  认知偏差是指投资者在信息处理过程中，由于主观认知的局限性而导致的逻辑推理错误。

- **2.1.2 常见认知偏差的分类与特征对比**

  | 偏差类型 | 定义 | 特征 |
  |----------|------|------|
  | 确认偏差  | 过度依赖支持已知假设的证据 | 选择性信息处理 |
  | 过度自信 | 高估自身知识与能力 | 风险误判 |
  | 框架效应  | 不同表述方式导致决策变化 | 情境依赖性 |
  | 锚定效应  | 过度依赖初始信息 | 初始值影响判断 |

- **2.1.3 认知偏差的ER实体关系图**

```mermaid
erDiagram
  class 认知偏差 {
    确认偏差
    过度自信
    框架效应
    锚定效应
  }
```

#### 2.2 认知偏差对投资者决策的影响

- **2.2.1 认知偏差对投资决策的正向影响**
  - 提供快速决策的捷径
  - 有助于应对不确定性

- **2.2.2 认知偏差对投资决策的负向影响**
  - 导致判断失误和决策偏差
  - 增加投资风险

- **2.2.3 认知偏差的双重作用机制**
  认知偏差在特定情境下可能具有正向或负向的影响，关键在于投资者能否识别和调整偏差。
