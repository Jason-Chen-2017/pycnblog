## 5.2 核心代码实现

### 5.2.1 数据处理代码
```python
import pandas as pd
import numpy as np

# 数据加载
df = pd.read_csv('industry_data.csv')

# 数据清洗
df.dropna(inplace=True)
df = df[~df['行业'].isnull()]
```

### 5.2.2 行业分析代码
```python
from sklearn.linear_model import LinearRegression

# 行业趋势预测
model = LinearRegression()
X = df[['GDP增速', '行业政策指数']]
y = df['行业增长率']
model.fit(X, y)

# 预测结果
predicted = model.predict(X)
```

### 5.2.3 投资组合优化代码
```python
import matplotlib.pyplot as plt

# 可视化投资组合
plt.figure(figsize=(10, 6))
plt.plot(predicted, label='预测增长率')
plt.plot(y, label='实际增长率')
plt.xlabel('时间')
plt.ylabel('增长率')
plt.legend()
plt.show()
```
