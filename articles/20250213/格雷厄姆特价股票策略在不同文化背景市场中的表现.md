## 第1章 格雷厄姆特价股票策略的核心理论

### 1.1 价值投资的起源与发展

#### 1.1.1 投资理论的演变
- **早期投资理论**：从道琼斯指数到凯道斯主义。
- **格雷厄姆的贡献**：价值投资的奠基人，强调安全边际和内在价值。
- **现代发展**：巴菲特、彼得·林奇等继承与发展。

#### 1.1.2 格雷厄姆的投资理念
- **安全边际**：买入价格低于内在价值的股票。
- **逆向投资**：在市场恐慌时寻找机会。
- **长期视角**：关注公司的基本面而非短期波动。

#### 1.1.3 特价股票的定义与特征
- **定义**：价格远低于内在价值的股票。
- **特征**：低市盈率、高股息率、稳定的财务状况。

### 1.2 分析框架与数学模型

#### 1.2.1 格雷厄姆的内在价值计算
- **公式**: 
  $$ V = \frac{P}{E} $$
  其中，\( P \) 是股票价格，\( E \) 是每股收益。
- **安全边际**: 
  $$ \text{安全价} = V \times (1 - \frac{1}{n}) $$
  \( n \) 是安全系数，通常为4.5。

#### 1.2.2 格雷厄姆的过滤筛选法
- **步骤**: 
  1. 计算市盈率。
  2. 筛选市盈率低于某个阈值（如15）的股票。
  3. 进一步分析财务状况和行业地位。

#### 1.2.3 投资组合管理
- **分散投资**: 将资金分配到多个股票，降低风险。
- **定期再平衡**: 定期调整投资组合，保持安全边际。

### 1.3 格雷厄姆策略的历史表现

#### 1.3.1 美国市场的实证分析
- **数据来源**: 标普500指数。
- **结果**: 长期表现优异，尤其在市场低迷时期。

#### 1.3.2 全球市场的适用性
- **案例分析**: 英国、日本市场中的应用。
- **挑战**: 不同市场的监管和经济周期差异。

#### 1.3.3 策略的有效性与局限性
- **优点**: 长期稳定收益。
- **缺点**: 短期可能跑输市场，需要较长持有期。

## 第2章 不同文化背景市场的特点与投资环境

### 2.1 西方市场（如美国、欧洲）的特点

#### 2.1.1 投资者行为
- **短期导向**: 投资者更关注短期收益。
- **高度透明**: 信息披露充分，市场机制成熟。

#### 2.1.2 市场结构
- **成熟市场**: 机构投资者主导，交易量大。
- **监管严格**: 有完善的市场监管体系。

### 2.2 东方市场（如中国、日本）的特点

#### 2.2.1 投资者行为
- **长期导向**: 更关注公司基本面和长期增长。
- **散户主导**: 投资者更倾向于个人决策。

#### 2.2.2 市场结构
- **新兴市场**: 交易量波动大，市场流动性不稳定。
- **监管差异**: 监管力度和透明度与西方市场不同。

### 2.3 市场监管与制度差异

#### 2.3.1 各国的市场监管体系
- **美国**: SEC监管严格。
- **中国**: 证监会监管，政策影响较大。

#### 2.3.2 法律法规对投资策略的影响
- **美国**: 强调信息公开，便于估值。
- **中国**: 政策导向影响市场，需考虑宏观调控。

### 4.2 算法实现与代码

#### 4.2.1 Python代码实现
```python
import pandas as pd
import numpy as np

def graham_strategy(data, threshold=15):
    # 计算市盈率
    data['PE'] = data['Price'] / data['Earnings']
    # 筛选市盈率低于阈值的股票
    filtered = data[data['PE'] < threshold]
    return filtered

# 示例数据
data = {'Price': [100, 50, 30, 20, 15],
        'Earnings': [10, 5, 3, 2, 1]
       }
df = pd.DataFrame(data)
result = graham_strategy(df)
print(result)
```
