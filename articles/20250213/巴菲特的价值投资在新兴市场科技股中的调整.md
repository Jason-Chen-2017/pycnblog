## 第1章: 价值投资的基本原理

### 1.1 价值投资的核心概念
#### 1.1.1 投资的本质与长期主义
投资的本质是通过购买优质资产，实现长期稳定的收益。长期主义强调关注企业的长期价值，而非短期波动。

#### 1.1.2 股票的内在价值与市场价值
股票的内在价值是基于企业基本面的评估，而市场价值则是由市场情绪和投资者行为决定的。价值投资的核心在于寻找内在价值高于市场价值的企业。

#### 1.1.3 安全边际与风险控制
安全边际是指内在价值与市场价格之间的差距，用于控制投资风险。通过安全边际，投资者可以在市场波动中降低风险。

### 1.2 巴菲特投资策略的关键要素
#### 1.2.1 企业基本面分析
基本面分析包括对企业财务状况、盈利能力、竞争优势和管理团队的评估。

#### 1.2.2 财务报表解读与关键指标
关键财务指标包括市盈率（P/E）、市净率（P/B）、ROE（净资产收益率）等，用于评估企业的财务健康状况。

#### 1.2.3 管理层能力和企业竞争优势
管理层能力和企业竞争优势是评估企业长期发展潜力的重要因素。

def optimize_portfolio(returns, weights):
    returns = np.array(returns)
    weights = np.array(weights)
    portfolio_return = np.sum(returns * weights)
    portfolio_risk = np.sqrt(np.dot(weights.T, np.dot(returns.cov(), weights)))
    return portfolio_return, portfolio_risk
