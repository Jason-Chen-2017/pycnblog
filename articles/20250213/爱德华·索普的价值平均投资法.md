### 3.3 价值平均法的Python实现
3.3.1 环境安装与配置  
- 安装Python和相关库（numpy, pandas, matplotlib）。  

3.3.2 核心代码实现  
```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

def value_average Strategy(prices, window=20):
    # 计算滑动平均价值
    avg_price = prices.rolling(window=window).mean()
    # 判断买入和卖出信号
    buy_signal = (prices < avg_price)
    sell_signal = (prices > avg_price)
    return buy_signal, sell_signal

# 示例数据
prices = pd.DataFrame({
    '价格': [100, 105, 98, 102, 104, 101]
})
buy, sell = value_averageStrategy(prices, window=3)
print("买入信号:", buy)
print("卖出信号:", sell)
```
