## 第一部分：特价股票与市场效率假说的背景介绍

### 第1章：特价股票的基本概念

#### 1.1 特价股票的定义与分类
- **特价股票的定义**：指股价低于面值的股票，通常反映公司财务困境或治理问题。
- **特价股票的分类**：
  - 按原因分类：财务困境型、重组型、治理问题型。
  - 按市场反应分类：超跌股、壳资源股、重组股。

#### 1.2 特价股票的市场特征
- 低估值：股价低于资产净值或行业平均水平。
- 高波动性：受市场情绪影响较大，价格波动剧烈。
- 投资风险高：信息不对称严重，投资者面临较高的市场和信用风险。

### 第2章：市场效率假说的基本概念

#### 2.1 市场效率的定义
- **强有效市场假说**：所有信息已反映在股价中，无法通过历史价格获利。
- **弱有效市场假说**：股价反映历史信息，但未来信息未完全反映。
- **半强有效市场假说**：股价反映所有公开信息，但未反映内幕信息。

#### 2.2 市场效率的衡量指标
- **信息传播速度**：信息公布后市场反应的时间。
- **股价对新信息的反应**：股价变动与信息相关性。

## 第二部分：特价股票与市场效率假说的核心概念

### 第3章：特价股票与市场效率的关系

#### 3.1 特价股票对市场效率的影响
- **信息传递作用**：特价股票可能是公司困境的信号，促进市场信息传播。
- **市场定价影响**：特价股票的存在可能反映市场对公司的负面预期，影响整体市场定价效率。

#### 3.2 市场效率对特价股票的影响
- **交易量与效率**：高市场效率下，特价股票可能更快被市场发现和交易。
- **价格波动与效率**：市场效率高时，特价股票的价格波动可能更小，因信息被快速消化。

### 第4章：信息不对称与市场效率

#### 4.1 信息不对称的定义
- **内部信息与外部信息**：内部人员掌握的未公开信息与公开信息。
- **信息不对称的来源**：信息掌握不平等、信息传递滞后等。

#### 4.2 信息不对称对市场效率的影响
- **市场失灵**：信息不对称导致定价扭曲，影响市场效率。
- **缓解机制**：市场机制如信息披露、监管等减少信息不对称。

## 第三部分：市场效率假说的算法与数学模型

### 第5章：市场效率的算法分析

#### 5.1 市场效率的衡量方法
- **事件研究法**：研究特定事件（如并购、重组）对股价的影响。
- **股价反应模型**：通过回归分析股价对事件的反应。

#### 5.2 事件研究法的步骤
1. 选择事件窗口：确定事件发生前后的时段。
2. 数据收集：收集事件期间的股价数据。
3. 计算超额收益：比较事件前后股价变化。
4. 统计检验：使用t检验或F检验判断超额收益是否显著。

#### 5.3 事件研究法的实现
```python
import pandas as pd
import numpy as np
from statsmodels.stats import ttest_ind

# 假设data是包含股价数据的DataFrame，event_date是事件发生日期
# 计算事件前后的收益
pre_event = data[data.date < event_date]['return'].values
post_event = data[data.date >= event_date]['return'].values

# 进行t检验
t_stat, p_val = ttest_ind(pre_event, post_event)
```

### 第6章：数学模型与公式

#### 6.1 事件研究法的公式
$$ R_i = \alpha + \beta (R_m - R_f) + \epsilon $$

其中：
- \( R_i \)：个股超额收益。
- \( R_m \)：市场平均收益。
- \( R_f \)：无风险利率。
- \( \epsilon \)：误差项。

#### 6.2 特价股票的定价模型
$$ P = \frac{D}{k} $$
其中：
- \( D \)：未来现金流。
- \( k \)：贴现率。

### 第8章：项目实战

# 数据加载
data = pd.read_csv('stock_data.csv')
