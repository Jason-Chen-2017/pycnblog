# 第1章: 金融市场微观结构与流动性概述

## 1.1 金融市场微观结构的基本概念

### 1.1.1 金融市场的定义与分类  
金融市场是资金供需双方进行交易的场所，可分为场内市场和场外市场。场内市场如交易所，场外市场如OTC市场。  

### 1.1.2 微观结构的定义与研究意义  
微观结构指金融市场的运行机制，包括参与者行为、订单簿、市场深度等。研究微观结构有助于理解市场流动性波动的根源。  

### 1.1.3 流动性的定义与衡量标准  
流动性指资产迅速转化为现金的能力，常用买卖价差、市场深度、订单簿深度等指标衡量。  

## 1.2 金融市场微观结构的核心要素  

### 1.2.1 市场参与者的角色与行为  
市场参与者包括机构投资者、散户、做市商等，其行为直接影响市场微观结构。  

### 1.2.2 订单簿与市场深度  
订单簿记录所有未成交订单，市场深度是订单簿中买方和卖方订单的总和，反映市场的买卖力量。  

### 1.2.3 买卖价差与市场摩擦  
买卖价差是买入价与卖出价的差额，市场摩擦包括交易成本、信息不对称等，影响流动性。  

## 1.3 微观结构变化对流动性的影响  

### 1.3.1 微观结构变化的定义  
微观结构变化指市场参与者行为、订单簿状态、市场深度等的变化。  

### 1.3.2 微观结构变化对流动性的直接影响  
例如，订单簿深度减少会导致买卖价差扩大，降低流动性。  

### 1.3.3 微观结构变化对流动性间接影响  
例如，信息不对称增加会导致市场深度下降，间接影响流动性。  

## 1.4 本章小结  
本章介绍了金融市场微观结构的核心概念和流动性影响的机制，为后续分析奠定基础。
