# 第1章: 费雪投资法的背景与核心理念

## 1.1 投资学的演进与费雪的贡献

### 1.1.1 传统投资学的局限性
传统投资学（如股利增长模型）在实践中存在以下问题：
- 无法有效预测市场波动
- 忽略了公司管理对投资价值的影响
- 缺乏对行业领导地位的关注

### 1.1.2 费雪投资法的提出与核心思想
费雪提出：
- 投资成功的前提是选择行业领导者
- 公司的盈利能力与管理效率密切相关
- 长期投资应关注公司的成长性

### 1.1.3 费雪投资法与现代投资理论的联系
- 与现代投资组合理论（MPT）的结合
- 为价值投资提供了新的视角

### 2.1.1 行业领导者的定义

# 第3章: 费雪投资法的数学模型与算法

## 3.1 费雪投资法的核心公式

### 3.1.1 投资回报率的计算公式
$$ 投资回报率 = \frac{（期末资产 - 初期资产）}{初期资产} \times 100\% $$

### 3.1.2 行业领导者的评估公式
$$ 费雪评分 = 0.5 \times ROE + 0.3 \times 市场份额 + 0.2 \times 管理效率 $$

### 3.1.3 投资组合优化的数学模型
$$ Maximize: \sum w_i r_i $$
$$ Subject to: \sum w_i = 1, w_i \geq 0 $$

### 5.2.2 投资组合优化算法
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, weights):
    def objective(weights):
        return -np.dot(returns, weights)
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    result = minimize(objective, weights, constraints)
    return result.x
```
