# 第一章：巴菲特的市场泡沫识别背景

## 1.1 巴菲特的投资哲学

### 1.1.1 价值投资的核心理念

巴菲特的价值投资理念是市场中长期表现的基础。他强调，市场的短期波动难以预测，但长期趋势可以通过基本面分析来把握。核心思想是购买价格低于内在价值的股票，长期持有，等待市场的合理反映。

$$\text{内在价值} = \text{未来现金流的现值}$$

### 1.1.2 市场与价值：巴菲的双重视角

巴菲特认为，市场和内在价值是两个不同的概念。市场价格会因市场情绪波动而上下波动，而内在价值则基于企业的实际经营情况。投资者的任务是找到价格低于内在价值的股票。

### 1.1.3 巴菲特投资体系的框架

巴菲特的投资体系包括以下几个方面：

1. **企业分析**：研究企业的财务状况、盈利能力、竞争优势等。
2. **市场分析**：关注市场的整体走势和周期性变化。
3. **估值方法**：计算股票的内在价值，确定安全边际。
4. **投资策略**：长期持有优质股票，避免短期波动的影响。
