# 第三部分：量子纠缠通信的基本原理

## 3.1 量子纠缠的概念与特性

### 3.1.1 量子纠缠的定义

量子纠缠是指两个或多个粒子之间存在的特殊关联，其中一个粒子的状态会立即影响另一个粒子的状态。

### 3.1.2 量子纠缠的核心特性

1. **不可分割性**：纠缠态无法被分割为独立的两个部分。
2. **超距性**：纠缠粒子之间的关联可以超越空间距离。
3. **非局域性**：纠缠态的测量会影响另一个粒子的状态。

### 3.1.3 量子纠缠与经典纠缠的对比

| 特性 | 量子纠缠 | 经典纠缠 |
|------|----------|----------|
| 不可分割性 | 是       | 否       |
| 超距性 | 是       | 否       |
| 非局域性 | 是       | 否       |
