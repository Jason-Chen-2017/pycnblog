## 第三部分：价值投资的估值方法

### 第5章：估值方法的数学模型

#### 5.1 市盈率（P/E）分析
- 市盈率公式：$$P/E = \frac{股价}{每股收益}$$
- 应用案例：假设某公司股价为10元，每股收益为2元，P/E = 5，低于行业平均值10，可能被低估。

#### 5.2 市净率（P/B）分析
- 市净率公式：$$P/B = \frac{股价}{每股净资产}$$
- 应用案例：某公司股价为15元，每股净资产为5元，P/B = 3，低于行业平均值5，可能被低估。

#### 5.3 股息率分析
- 股息率公式：$$股息率 = \frac{每股股息}{股价} \times 100\%$$
- 应用案例：某公司股息率为5%，高于行业平均值3%，具备吸引力。

### 第6章：现金流贴现模型（DCF）

#### 6.1 DCF模型的核心公式
- 企业自由现金流公式：$$FCF = 净利润 + 折旧 - 资本支出$$
- 终值计算公式：$$TV = \frac{FCF \times (1 + g)}{r - g}$$
- 整体企业价值公式：$$EV = \sum_{t=1}^{n} \frac{FCF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$

#### 6.2 应用案例
- 假设某公司未来5年的自由现金流分别为5, 6, 7, 8, 9亿元，贴现率r=10%，永续增长率g=2%。
- 计算终值：$$TV = \frac{9 \times (1 + 0.02)}{0.10 - 0.02} = 100.25亿元$$
- 计算整体企业价值：$$EV = \sum_{t=1}^{5} \frac{FCF_t}{(1 + 0.10)^t} + \frac{100.25}{(1 + 0.10)^5} ≈ 30.65亿元$$
