### 第2章：丹尼尔·卡尼曼的行为经济学理论

#### 2.1 期望效用理论与prospect theory

##### 2.1.1 期望效用理论的局限性

- 无法解释损失厌恶
- 无法解释概率加权函数
- 无法解释非线性效用函数

##### 2.1.2 prospect theory的核心假设

- 价值函数：线性递减的收益函数与非线性的损失函数
- 概率权重函数：凸函数与损失厌恶曲线

##### 2.1.3 概率权重函数与损失厌恶曲线

- 概率权重函数：$w(p) = p^{\alpha}(1-p)^{\beta}$
- 损失厌恶曲线：$V = \begin{cases} 
  k \cdot \sqrt{x} & \text{if } x > 0 \\
  -\sqrt{-x} & \text{if } x < 0 
\end{cases}$

#### 2.2 偏好与决策权重

##### 2.2.1 偏好的递减性

- 价值函数的递减性：$V(x) = \sqrt{x}$

##### 2.2.2 决策权重的非线性特征

- 概率权重函数：$w(p) = p^{\alpha}(1-p)^{\beta}$

##### 2.2.3 价值函数的数学模型

- 综合价值函数：$V(x, p) = \sqrt{p \cdot x + (1-p) \cdot (-y)}$

### 第4章：数学模型与行为经济学

#### 4.1 基于prospect theory的数学模型

##### 4.1.1 价值函数的数学表达

- 价值函数：$V(x) = \sqrt{x}$

##### 4.1.2 概率权重函数的数学模型

- 概率权重函数：$w(p) = p^{\alpha}(1-p)^{\beta}$

##### 4.1.3 综合数学模型的构建

- 综合模型：$U(x, p) = \sum_{i=1}^{n} w(p_i) \cdot V(x_i)$

#### 4.2 算法原理讲解

##### 4.2.3 代码实现

```python
import math

def value_function(x):
    return math.sqrt(x)

def probability_weight(p, alpha, beta):
    return (p**alpha) * ((1-p)**beta)

# 示例数据
p = 0.7
x = 100

v = value_function(x)
w = probability_weight(p, 0.5, 0.5)

print(f"Value: {v}, Weight: {w}")
```

## 第六部分：项目实战

### 第6章：项目实战

#### 6.1 环境安装

- Python 3.8+
- NumPy, Pandas, Matplotlib

#### 6.2 核心代码实现

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

def value_function(x):
    return np.sqrt(x)

def probability_weight(p, alpha, beta):
    return (p**alpha) * ((1-p)**beta)

# 示例数据
prices = pd.Series([100, 90, 110, 80], index=['A', 'B', 'C', 'D'])
p = 0.7

# 计算价值函数
values = prices.apply(value_function)

# 计算概率权重
weights = probability_weight(p, 0.5, 0.5)

# 绘制图表
plt.bar(values, weights)
plt.title('Value Function and Probability Weight')
plt.show()
```
