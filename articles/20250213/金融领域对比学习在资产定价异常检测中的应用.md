# 第三章: 对比学习在资产定价中的数学模型与算法

## 3.1 对比学习的数学模型

### 3.1.1 对比函数的定义
对比函数将两个样本映射到一个相似度分数，用于衡量它们之间的相似性。常用的对比函数包括余弦相似度和欧氏距离。

$$\text{余弦相似度} = \frac{\vec{x} \cdot \vec{y}}{\|\vec{x}\| \|\vec{y}\|}$$
$$\text{欧氏距离} = \|x - y\|$$

### 3.1.2 对比损失函数的推导
对比损失函数用于衡量正样本对和负样本对的相似度差异。常用的损失函数包括NT-Xent损失：

$$\text{NT-Xent损失} = -\frac{1}{\log(2)} \left(\log(\text{sim}(x, y))^+ + \log(1 - \text{sim}(x, y))^+\right)$$

其中，$\text{sim}(x, y)$是正样本对的相似度，$(\cdot)^+$表示取正值。

### 3.1.3 对比学习的优化目标
对比学习的目标是最小化正样本对的损失，同时最大化负样本对的损失，以增强模型对异常样本的区分能力。

## 3.2 资产定价模型的数学基础

### 3.2.1 CAPM模型
资本资产定价模型（CAPM）用于估计资产的期望收益：

$$E(r_i) = r_f + \beta_i (r_m - r_f)$$

其中，$r_f$是无风险利率，$r_m$是市场期望收益，$\beta_i$是资产的贝塔系数。

### 3.2.2 Fama-French三因子模型
三因子模型引入规模和价值因子：

$$E(r_i) = r_f + \beta_i (r_m - r_f) + 0.3 \times \text{Size}_i - 0.3 \times \text{Value}_i$$

## 3.3 对比学习的异常检测算法

### 3.3.1 数据预处理
对金融数据进行标准化和归一化处理，消除量纲影响：

$$x_{\text{norm}} = \frac{x - \mu}{\sigma}$$

其中，$\mu$是均值，$\sigma$是标准差。

### 3.3.2 特征提取
使用自注意力机制提取高维特征：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right)V$$

其中，$Q$、$K$、$V$分别为查询、键和值向量，$d$是维度数。

### 3.3.3 对比学习模型
构建对比学习网络，包含编码器和对比损失函数：

$$\mathcal{L} = \text{NT-Xent}(x, x')$$

其中，$x'$是$x$的增强样本。
