## 第二部分: 格雷厄姆企业价值计算的核心原理

### 第2章: 格雷厄姆的企业价值计算模型

#### 2.1 格雷厄姆的内在价值计算方法

格雷厄姆的内在价值计算方法基于以下公式：

$$
\text{内在价值} = \frac{\text{未来现金流的现值}}{折现率}
$$

**股息折现法**  
股息折现法是格雷厄姆常用的一种方法，公式如下：

$$
\text{内在价值} = \sum_{t=1}^{n} \frac{\text{股息}_t}{(1 + r)^t}
$$

其中，\( r \) 是折现率，\( \text{股息}_t \) 是第 \( t \) 年的股息。

#### 2.2 格雷厄姆的安全边际概念

安全边际是格雷厄姆理论中的重要概念，其计算公式为：

$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

安全边际越大，投资风险越小。

#### 6.2 核心代码实现

以下是核心代码实现：

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(dividends, discount_rate):
    return sum(dividend / (1 + discount_rate)**i for i, dividend in enumerate(dividends))

def calculate_safety_margin(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
dividends = [1, 1.05, 1.10, 1.15]
discount_rate = 0.10
market_price = 10

# 计算内在价值
intrinsic_value = calculate_intrinsic_value(dividends, discount_rate)

# 计算安全边际
safety_margin = calculate_safety_margin(intrinsic_value, market_price)

print(f"内在价值: {intrinsic_value:.2f}")
print(f"安全边际: {safety_margin:.2f}")
```

#### 6.3 案例分析

以下是案例分析：

某公司未来四年的股息分别为1元、1.05元、1.10元和1.15元，折现率为10%，市场价格为10元。计算其内在价值和安全边际。

计算结果如下：

$$
\text{内在价值} = 1 + \frac{1.05}{1.10} + \frac{1.10}{(1.10)^2} + \frac{1.15}{(1.10)^3} \approx 4.18 \text{元}
$$

$$
\text{安全边际} = 4.18 - 10 = -5.82 \text{元}
$$
