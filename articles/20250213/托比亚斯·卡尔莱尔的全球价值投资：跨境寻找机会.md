## 第一部分：价值投资的背景与基础

### 第1章：价值投资的定义与背景

#### 1.1 价值投资的定义与核心理念

- **价值投资的基本定义**  
  价值投资是一种以低于公平价值的价格购买优质资产的投资策略。其核心在于识别市场中被低估的股票，通过长期持有实现收益。

- **价值投资的核心理念与原则**  
  价值投资强调安全边际、长期视角和逆向思维。投资者应关注企业的基本面，而非市场的短期波动。

- **价值投资与成长投资的区别**  
  价值投资关注低估值，而成长投资关注高增长。两者在目标和策略上有显著差异，但在实际操作中可以结合使用。

#### 1.2 价值投资的历史与发展

- **价值投资的起源与发展**  
  价值投资起源于20世纪初，由本杰明·格雷厄姆和戴维德·多德提出。其理论在实践中不断完善，逐渐发展为一种成熟的投资方法。

- **全球化背景下的价值投资演变**  
  随着全球化的深入，价值投资从本土市场扩展到全球市场，投资者需要考虑不同地区的经济环境和市场特点。

#### 1.3 价值投资的基本原理

- **市场有效性的探讨**  
  市场并非总是有效，短期波动为价值投资者提供了机会。

- **价值与价格的差异与机会**  
  当市场价格低于内在价值时，投资者可以买入并长期持有，等待市场回归理性。

- **安全边际的概念与重要性**  
  安全边际是投资价格与内在价值之间的差额，确保在市场波动中仍能获得收益。

### 第2章：全球市场中的投资机会

#### 2.1 全球经济与市场的基本分析

- **全球经济格局的现状与趋势**  
  全球化背景下，新兴市场和发达市场的增长潜力各异。投资者需关注宏观经济指标和政策变化。

- **不同地区的市场特点与投资机会**  
  美国市场成熟，欧洲市场稳定，亚洲市场增长迅速。投资者应根据地区特点选择投资标的。

- **经济周期对投资策略的影响**

#### 2.2 跨境投资的核心考量

- **货币与汇率的风险与机会**  
  汇率波动直接影响投资收益。投资者需通过套期保值等手段降低汇率风险。

- **政治经济环境的稳定性分析**  
  政治动荡或经济政策变化可能影响市场表现。投资者需评估目标市场的稳定性。

- **税收政策与监管环境的影响**  
  不同国家的税收政策和监管规定对投资收益有直接影响。投资者需了解并遵守相关法规。

### 第3章：价值投资的量化分析与工具

#### 3.1 价值投资的量化指标

- **市盈率（P/E）分析**  
  P/E比率 = 每股价格 / 每股收益。低P/E比率可能意味着低估。

- **市净率（P/B）分析**  
  P/B比率 = 每股价格 / 每股净资产。低P/B比率可能意味着资产被低估。

- **股息率与股息增长分析**  
  高股息率可能意味着稳定的收益，但需关注股息支付能力。

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from pandas_datareader import data as pdr
import os

# 下载数据
def get_data(ticker, start, end):
    df = pdr.get_data_yahoo(ticker, start, end)
    return df

# 计算价值指标
def calculate_value_ratios(df):
    df['P/E'] = df['Close'] / df['EPS']
    df['P/B'] = df['Close'] / df['Book Value Per Share']
    df['Div Yield'] = df['Div Yield']
    return df

# 筛选低估股票
def screen_stocks(df, threshold=0.8):
    selected = df[df['P/E'] < threshold]
    return selected

# 可视化分析
def visualize_data(df):
    plt.figure(figsize=(10,6))
    df['P/E'].hist(bins=20)
    plt.title('P/E分布')
    plt.show()

# 策略回测
def backtest_strategy(selected_stocks, start, end):
    portfolio = []
    for stock in selected_stocks:
        portfolio.append(stock)
    # 计算组合收益
    returns = []
    for stock in portfolio:
        data = get_data(stock, start, end)
        returns.append(data['Return'])
    total_return = sum(returns)
    return total_return

# 示例代码
start = '2020-01-01'
end = '2023-12-31'
tickers = ['AAPL', 'MSFT', 'GOOGL']  # 示例股票
df = get_data(tickers, start, end)
df = calculate_value_ratios(df)
selected = screen_stocks(df)
backtest_return = backtest_strategy(selected, start, end)
print(f'策略回测收益：{backtest_return}')
visualize_data(df)
