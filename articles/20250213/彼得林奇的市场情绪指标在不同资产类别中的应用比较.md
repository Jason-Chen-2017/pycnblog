## 2. 市场情绪指标的理论基础

### 2.1 投资者情绪指标

投资者情绪指标反映了投资者对市场的看法，常用恐慌指数（VIX）衡量市场的波动性和风险。

### 2.2 市场参与度指标

市场参与度指标通过成交量和持仓量反映投资者的活跃程度，高参与度通常意味着市场情绪高涨。

### 2.3 市场波动性指标

市场波动性指标如标准差和波幅，反映了市场的不稳定性和投资者情绪的波动。

### 2.4 其他相关市场指标

包括市场趋势指标和资金流动指标，与市场情绪指标共同构成完整的市场分析框架。

import pandas as pd
import numpy as np

def calculate_market_mood(data):
    # 计算平均回报率
    returns = data['close'].pct_change().dropna()
    avg_return = returns.mean()
    # 计算波动性
    volatility = returns.std()
    # 计算市场情绪指标
    market_mood = (avg_return - returns.mean()) / volatility
    return market_mood

# 示例数据
data = pd.DataFrame({'close': [100, 105, 110, 108, 112]})
mood = calculate_market_mood(data)
print(mood)
