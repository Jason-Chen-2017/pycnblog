# 引言

## 1.1 问题背景与研究意义
### 1.1.1 效率市场假说与价值投资的矛盾
- **效率市场假说（EMH）**：认为市场价格反映所有可用信息，投资者无法通过分析获得超额收益。
- **价值投资**：强调通过基本面分析寻找被低估的投资标的，追求长期超额收益。
- 表象矛盾：EMH认为市场有效，价值投资却试图在市场中找到低估机会。

### 1.1.2 研究意义
- 理论意义：统一效率与价值的哲学思考。
- 实践意义：为投资者提供新的视角。

# 第一部分：理论基础

## 2.1 效率市场假说
### 2.1.1 定义与核心观点
- 弱有效市场：价格反映历史信息。
- 半强有效市场：价格反映所有公开信息。
- 强有效市场：价格反映所有信息，包括内部信息。

### 2.1.2 优缺点分析
- 优点：市场有效，降低信息不对称。
- 缺点：限制了主动投资的超额收益可能性。

## 2.2 价值投资理论
### 2.2.1 核心理念
- 寻找市场低估的股票，长期持有，等待市场重新定价。

### 2.2.2 历史发展与现状
- 历史案例：格雷厄姆、巴菲特的成功经验。
- 当前挑战：市场信息透明度提高，低估机会减少。

### 7.1.3 代码实现
```python
import pandas as pd
import numpy as np

def calculate_pe_ratio(df):
    df['PE'] = df['Price'] / df['Earnings']
    return df

def main():
    data = pd.read_csv('stock_data.csv')
    data = calculate_pe_ratio(data)
    # 价值投资筛选
    value_portfolio = data[data['PE'] < data['PE'].quantile(0.25)]
    print("价值组合表现:", value_portfolio['Return'].mean())

if __name__ == "__main__":
    main()
```

- 价值组合平均收益：高于市场平均水平。
- 风险控制：波动率低于市场。
