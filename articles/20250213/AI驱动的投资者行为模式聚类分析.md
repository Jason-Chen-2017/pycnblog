## 第2章: 核心概念与联系

### 2.1 聚类分析的基本原理

#### 2.1.1 聚类分析的原理概述
聚类分析的目标是将数据点划分为若干个簇，使得簇内数据点的相似性较高，而簇间数据点的相似性较低。常用的距离度量方法包括欧氏距离、曼哈顿距离和余弦相似度。

#### 2.1.2 聚类分析的核心算法
- K-means：基于距离的聚类算法，适用于球形簇。
- 层次聚类：基于层次结构的聚类方法，适用于任意形状的簇。
- DBSCAN：基于密度的聚类算法，适用于噪声较多的数据集。

#### 2.1.3 聚类分析的特征与优势
- 特征：无监督学习、数据驱动、簇内一致性高。
- 优势：能够发现数据中的潜在结构，适用于复杂场景。

## 第3章: 算法原理与数学模型

### 3.1 聚类分析算法原理

#### 3.1.1 K-means算法原理
K-means算法是一种基于距离的聚类算法，适用于球形簇。算法步骤如下：
1. 初始化聚类中心。
2. 计算每个数据点与聚类中心的距离。
3. 将数据点分配到最近的聚类中心。
4. 更新聚类中心。
5. 重复步骤2-4，直到收敛。

#### 3.1.2 层次聚类算法原理
层次聚类算法是一种基于层次结构的聚类方法，适用于任意形状的簇。算法步骤如下：
1. 计算所有数据点之间的距离。
2. 将距离最近的两个数据点合并成一个簇。
3. 重复步骤2，直到所有数据点合并成一个簇。

#### 3.1.3 DBSCAN算法原理
DBSCAN算法是一种基于密度的聚类算法，适用于噪声较多的数据集。算法步骤如下：
1. 选择一个未访问的数据点作为起点。
2. 找出与起点距离在一定范围内的所有数据点。
3. 将这些数据点合并成一个簇。
4. 重复步骤1-3，直到所有数据点处理完毕。

---

### 3.2 聚类分析的数学模型

#### 3.2.1 K-means算法的数学公式
$$ \text{目标函数} = \sum_{i=1}^{k} \sum_{j=1}^{n_i} \|x_j - c_i\|^2 $$
其中，$k$为聚类数，$n_i$为第$i$个簇中的数据点数，$x_j$为数据点，$c_i$为第$i$个簇的聚类中心。

#### 3.2.2 层次聚类算法的距离计算公式
$$ \text{距离} = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2} $$

import pandas as pd
import numpy as np

# 数据清洗
data = pd.read_csv('investor_behavior.csv')

#### 5.2.2 特征提取
```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer()
tfidf = vectorizer.fit_transform(data['comments'])
```

#### 5.2.3 聚类分析
```python
from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=5, random_state=0)
clusters = kmeans.fit_predict(tfidf)
```
