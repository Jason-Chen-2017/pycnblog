## 第一部分：资产配置理论的背景与基础

### 第1章：资产配置的基本概念

#### 1.1 资产配置的定义与重要性
- **1.1.1 资产配置的定义**
  资产配置是指将投资资金分配到不同资产类别（如股票、债券、房地产等）中，以实现风险最小化和收益最大化的投资策略。
  
- **1.1.2 资产配置的重要性**
  资产配置是投资组合管理的核心，它能够帮助投资者分散风险，避免过度依赖单一资产类别，从而在不同市场环境下保持稳定的收益。

- **1.1.3 资产配置的分类与特点**
  资产配置主要分为战略性资产配置和战术性资产配置。战略性配置注重长期投资目标，而战术性配置则根据市场变化进行短期调整。

#### 1.2 约翰·伯格的理论背景
- **1.2.1 约翰·伯格的学术贡献**
  约翰·伯格是投资组合理论的先驱，他的研究成果为现代资产配置理论奠定了基础。

- **1.2.2 资产配置理论的发展历程**
  资产配置理论从马科维茨的现代投资组合理论发展而来，伯格在这一领域进行了深入的扩展和优化。

- **1.2.3 伯格理论的核心思想**
  伯格强调通过优化资产配置来平衡风险与收益，避免过度集中投资，从而降低整体投资组合的波动性。

## 第二部分：资产配置的核心原理

### 第2章：现代投资组合理论

#### 2.1 马科维茨的现代投资组合理论
- **2.1.1 马科维茨理论的概述**
  马科维茨提出的投资组合理论是资产配置的基础，他通过数学模型证明了最优投资组合的存在。

- **2.1.2 马科维茨理论的数学模型**
  投资组合的收益和风险可以通过以下公式表示：
  $$ E(r_p) = \sum_{i=1}^n w_i E(r_i) $$
  $$ Var(r_p) = \sum_{i=1}^n \sum_{j=1}^n w_i w_j Cov(r_i, r_j) $$
  其中，$w_i$和$w_j$是资产i和j的权重，$E(r_i)$是资产i的期望收益，$Cov(r_i, r_j)$是资产i和j的协方差。

- **2.1.3 伯格理论与马科维茨理论的关系**
  伯格在马科维茨的基础上，进一步提出了优化后的资产配置方法，考虑了更多的实际因素，如交易成本和市场流动性。

#### 2.2 伯格的资产配置优化方法
- **2.2.1 优化模型**
  伯格的优化模型旨在最大化投资组合的夏普比率：
  $$ \text{夏普比率} = \frac{E(r_p) - r_f}{\sigma_p} $$
  其中，$r_f$是无风险利率，$\sigma_p$是投资组合的风险（标准差）。

- **2.2.2 约束条件**
  伯格在优化过程中引入了以下约束条件：
  - 投资组合的总权重为1：$\sum_{i=1}^n w_i = 1$
  - 单个资产的权重不超过一定比例：$w_i \leq k$，其中$k$是限制比例。

- **3.1.1 优化目标**
  最小化投资组合的风险，即最小化方差：
  $$ \min \sum_{i=1}^n \sum_{j=1}^n w_i w_j Cov(r_i, r_j) $$

### 第5章：资产配置的实战案例

#### 5.2 核心代码实现
```python
import numpy as np
from scipy.optimize import minimize

# 示例数据
n_assets = 3
expected_returns = np.array([0.1, 0.15, 0.08])
covariance_matrix = np.array([
    [0.16, 0.05, 0.02],
    [0.05, 0.20, 0.03],
    [0.02, 0.03, 0.12]
])

# 定义目标函数和约束
def portfolio_var(weights, covariance):
    return np.dot(weights.T, np.dot(covariance, weights))

def constraint(weights):
    return np.sum(weights) - 1

# 初始化猜测
init_guess = np.array([1.0/n_assets] * n_assets)

# 优化
result = minimize(portfolio_var, init_guess, args=covariance_matrix, 
                 method='SLSQP', constraints={'type': 'eq', 'fun': constraint})

optimal_weights = result.x
print("Optimal weights:", optimal_weights)
print("Minimum variance:", portfolio_var(optimal_weights, covariance_matrix))
```
