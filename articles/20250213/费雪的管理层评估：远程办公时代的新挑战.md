##### 3.2 算法步骤详细说明
1. **数据收集**：通过问卷、日志等收集管理层的行为数据。
2. **数据分析**：利用统计方法分析数据，识别关键指标。
3. **评估指标计算**：基于权重计算各指标的评分。
4. **评分生成**：综合各指标评分，生成最终评估结果。
5. **结果输出**：以可视化形式输出评估结果。

##### 3.3 数学模型与公式
- **评估指标计算公式**：
  $$
  \text{评估指标} = \sum_{i=1}^{n} w_i \times x_i
  $$
  其中，$w_i$ 是第i个指标的权重，$x_i$ 是该指标的评分。

- **最终评分公式**：
  $$
  \text{最终评分} = \frac{\sum_{j=1}^{m} (\text{指标}_j \times w_j)}{\sum_{j=1}^{m} w_j}
  $$

##### 5.2 核心代码实现

import pandas as pd
import numpy as np

def calculate_assessment_scores(data, weights):
    # 计算每个指标的评分
    scores = data.dot(weights)
    # 生成最终评分
    total_weight = sum(weights)
    if total_weight == 0:
        return 0
    normalized_scores = scores / total_weight
    return normalized_scores

# 示例数据和权重
data = pd.DataFrame({
    '领导力': [85, 90, 78],
    '沟通能力': [75, 85, 88],
    '决策能力': [90, 80, 85]
})
weights = pd.Series([0.4, 0.3, 0.3])

# 计算评估结果
results = calculate_assessment_scores(data, weights)
print(results)
