### 3.1 均值-方差优化模型

#### 3.1.1 模型的公式表示
均值-方差优化模型是资产配置的核心工具，用于在给定风险下寻找最大收益，或在给定收益下寻找最小风险的资产组合。其数学表示为：
$$
\text{Minimize } \sigma^2 \quad \text{subject to } \mu = \text{target return}
$$
其中，$\mu$ 是期望收益，$\sigma^2$ 是收益的方差，表示风险。

#### 3.1.2 优化过程的步骤分解
1. **数据准备**：收集各资产的历史收益数据。
2. **计算均值与方差**：对各资产计算期望收益和协方差矩阵。
3. **设定约束条件**：如总权重为1，权重非负等。
4. **优化求解**：使用二次规划算法求解最优权重。

#### 3.1.3 实例分析与计算
假设我们有两只资产A和B，其期望收益分别为10%和15%，方差分别为0.04和0.09，协方差为0.02。目标是构建一个风险最小的组合，期望收益为12%。

通过公式：
$$
\begin{cases}
w_A \cdot 0.1 + w_B \cdot 0.15 = 0.12 \\
w_A + w_B = 1 \\
\text{Minimize } w_A^2 \cdot 0.04 + 2w_A w_B \cdot 0.02 + w_B^2 \cdot 0.09
\end{cases}
$$
解得：
$$
w_A = 0.6, \quad w_B = 0.4
$$
即投资60%于A，40%于B。

### 3.2 资本资产定价模型（CAPM）

#### 3.2.1 CAPM的基本公式
CAPM用于计算资产的预期收益：
$$
E(R_i) = R_f + \beta_i (R_m - R_f)
$$
其中，$R_f$ 是无风险利率，$R_m$ 是市场预期收益，$\beta_i$ 是资产的系统性风险系数。

#### 3.2.2 市场风险溢价的计算
市场风险溢价为：
$$
R_p = R_m - R_f
$$
例如，若$R_m = 8\%$，$R_f = 2\%$，则$R_p = 6\%$。

#### 3.2.3 个股与市场的协方差分析
计算个股$\beta$：
$$
\beta_i = \frac{\text{Cov}(R_i, R_m)}{\text{Var}(R_m)}
$$
例如，若$\text{Cov}(R_i, R_m) = 0.05$，$\text{Var}(R_m) = 0.09$，则$\beta_i = 0.5556$。

#### 3.3.3 应用优化算法求解最优配置
```python
def portfolio_var(weights, mu, sigma):
    return np.dot(weights.T, np.dot(sigma, weights))

def optimize_portfolio(mu, sigma, target_return=0.12):
    n = len(mu)
    init_guess = np.array([1.0/n]*n)
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1},
                   {'type': 'eq', 'fun': lambda w: np.dot(w, mu) - target_return}]
    result = minimize(portfolio_var, init_guess, args=(mu, sigma), 
                      method='SLSQP', constraints=constraints)
    return result.x

weights = optimize_portfolio(mu, sigma)
```
