# 第1章: 特价股票投资的背景与核心概念

## 1.1 特价股票的定义与特点

### 1.1.1 什么是特价股票
特价股票是指价格低于市场公允价值，具有较大投资潜力的股票。通常，这类股票可能因为市场波动、行业周期或公司特定因素而被低估。

### 1.1.2 特价股票的特点
- 价格低于内在价值
- 高股息率或潜在增长能力
- 行业地位稳固，但暂时被市场忽视

### 1.1.3 特价股票的投资价值
- 低估值带来较高的安全边际
- 潜在的上涨空间
- 抗风险能力强

## 1.2 全球产业链的基本概念

### 1.2.1 产业链的定义
产业链是指从原材料供应、生产加工、分销到最终消费者的完整链条。

### 1.2.2 产业链的分类与特点
- 上游：原材料供应
- 中游：生产加工
- 下游：分销与消费

### 1.2.3 全球化产业链的形成与发展
- 全球分工与合作
- 降低成本与提高效率

## 1.3 特价股票与全球产业链的关联

### 1.3.1 特价股票与产业链的关系
- 特价股票可能位于产业链的某个关键环节
- 产业链波动会影响特价股票的价值

### 1.3.2 产业链波动对特价股票的影响
- 市场需求变化
- 行业周期性
- 政策影响

### 1.3.3 特价股票在全球产业链中的地位
- 作为全球产业链的一部分，特价股票具有国际化特征

### 3.2.1 产业链上下游的协同投资
- 投资产业链上下游相关股票
- 分散投资风险

### 3.2.2 风险分散的投资策略
- 分散投资于不同行业和地区的股票
- 通过组合投资降低风险

### 3.2.3 长期与短期结合的投资策略
- 长期投资低估股票
- 短期波段操作

- 风险可控

### 3.3.2 组合调整策略
