# 第5章 数据安全投资的数学模型和算法

## 5.1 数据安全风险量化模型

### 5.1.1 风险量化公式
$$ R = \sum_{i=1}^{n} (P_i \times I_i) $$
其中，R为总体风险，P_i为风险发生概率，I_i为影响程度。

### 5.1.2 案例分析
假设某企业有两项风险，P1=0.3，I1=50；P2=0.2，I2=80。则总体风险R=0.3×50 + 0.2×80=15+16=31。

---

## 5.2 数据安全投资收益模型

### 5.2.1 收益计算公式
$$ ROI = \frac{收益 - 成本}{成本} \times 100\% $$

### 5.2.2 案例分析
假设投资成本为100万元，预期收益为150万元，则ROI=50%。

def calculate_risk(probability, impact):
    return probability * impact

impacts = [50, 80]
total_risk = sum([calculate_risk(p, i) for p, i in zip(probabilities, impacts)])

### 7.2.2 数据安全投资收益计算代码

def calculate_roi(revenue, cost):
    return (revenue - cost) / cost * 100

# 示例

revenue = 1500000
roi = calculate_roi(revenue, cost)
print(f"ROI: {roi}%")
