## 第六章: 数学模型与分析

### 6.1 投资价值评估的数学模型

#### 6.1.1 市盈率计算公式
市盈率（P/E）是衡量股票价值的重要指标，计算公式如下：
$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$

#### 6.1.2 内在价值计算
邓普顿使用内在价值模型，计算公式如下：
$$ \text{内在价值} = \frac{\text{预期收益}}{\text{折现率}} $$

#### 6.1.3 安全边际计算
安全边际是邓普顿强调的关键因素，公式为：
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

## 第八章: 项目实战

### 8.1 2008年金融危机案例分析

#### 8.1.1 数据处理代码
以下是用于分析2008年金融危机的Python代码示例：
```python
import pandas as pd
import numpy as np

# 数据加载
df = pd.read_csv('financial_crisis_data.csv')

# 计算市盈率
df['P/E'] = df['股价'] / df['每股收益']

# 筛选内在价值高于市场价格的股票
mask = df['内在价值'] > df['市场价格']
selected_stocks = df[mask]

print(selected_stocks)
```

#### 8.1.2 分析结果解读
代码输出结果展示了内在价值高于市场价格的股票，这些股票被视为潜在的投资机会。通过邓普顿的策略，投资者可以在危机中寻找这些被低估的资产。
