## 第一部分：格雷厄姆理论的现代演绎背景介绍

### 第1章：格雷厄姆理论的起源与核心概念

#### 1.1 格雷厄姆理论的起源
- **1.1.1 价值投资的鼻祖——本杰明·格雷厄姆**
  - 格雷厄姆是20世纪最伟大的投资思想家之一，被誉为“价值投资之父”。
  - 他提出了“市场先生”概念，认为市场情绪波动是投资机会的来源。
  - 格雷厄姆的学生戴维·多德共同提出了“净净股票”（Nets）的概念，即通过分析企业的净资产价值来评估其内在价值。
  
- **1.1.2 格雷厄姆理论的核心思想**
  - 股票的价值应基于企业的基本面分析，而非市场情绪。
  - 安全边际：买入价格低于企业内在价值，以降低投资风险。
  - 长期投资：通过持有优质资产获得长期收益，而非频繁交易。

- **1.1.3 格雷厄姆理论在现代投资中的地位**
  - 格雷厄姆的理论是现代价值投资的基石，影响了巴菲特、彼得·林奇等投资大师。
  - 在现代量化投资中，格雷厄姆的理论被重新演绎，融入编程与数据分析技术。

#### 1.2 格雷厄姆理论的核心概念
- **1.2.1 股票的价值评估**
  - 格雷厄姆认为，股票的内在价值是企业的净资产价值，即“每股净资本”（NCAV）。
  - 净资本 = 总资产 - 流动负债 - 无形资产。
  - 投资者应寻找市场价格低于净资本的企业。

- **1.2.2 安全边际的概念**
  - 安全边际 = 内在价值 - 市场价格。
  - 通过安全边际，投资者可以降低市场波动带来的风险。
  - 安全边际的计算公式：$$\text{安全边际} = \text{内在价值} - \text{市场价格}$$

- **1.2.3 股票市场的周期性**
  - 格雷厄姆认为，市场具有周期性，价格会在短期偏离价值。
  - 投资者应利用市场的周期性波动，寻找低估的股票。

#### 2.1 净净股票策略的定义
- **2.1.1 净净股票的定义**
  - 净净股票（Nets）是指市场价格低于每股净资本的股票。

- **2.1.2 净净股票与传统股票的区别**
  - 净净股票强调企业的净资产价值，而非市场表现。

#### 7.2 系统核心实现
- **代码实现：净净股票筛选模型**

```python
import pandas as pd
import numpy as np
import requests

def get_financial_data(ticker):
    # 获取股票财务数据
    url = f"https://api.example.com/financial_data/{ticker}"
    response = requests.get(url)
    data = response.json()
    return {
        "total_assets": data["total_assets"],
        "current_liabilities": data["current_liabilities"],
        "intangible_assets": data["intangible_assets"],
        "total_shares": data["total_shares"],
        "market_price": data["market_price"]
    }

def calculate_net_capital(data):
    # 计算净资本
    net_capital = (data["total_assets"] - data["current_liabilities"] - data["intangible_assets"]) / data["total_shares"]
    return net_capital

def calculate_margin_of_safety(data, net_capital):
    # 计算安全边际
    margin_of_safety = net_capital - data["market_price"]
    return margin_of_safety

def screen_net_net_stocks(tickers):
    # 筛选净净股票
    screened_stocks = []
    for ticker in tickers:
        data = get_financial_data(ticker)
        net_capital = calculate_net_capital(data)
        margin_of_safety = calculate_margin_of_safety(data, net_capital)
        if margin_of_safety > 0:
            screened_stocks.append(ticker)
    return screened_stocks

# 示例代码
tickers = ["AAPL", "MSFT", "GOOGL"]
screened_stocks = screen_net_net_stocks(tickers)
print("符合条件的股票：", screened_stocks)
```
