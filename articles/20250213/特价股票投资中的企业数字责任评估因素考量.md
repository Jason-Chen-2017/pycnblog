### 3.2 数字责任评估的数学模型

#### 3.2.1 数学模型的定义与公式
数字责任评分公式：
$$ DR = \sum_{i=1}^{n} w_i \times f_i $$
其中，$$ w_i $$ 为指标权重，$$ f_i $$ 为指标评分。

#### 3.2.2 数学模型的实现与应用
通过Python代码实现评分模型，应用于实际投资决策中。

#### 3.2.3 数学模型的优缺点分析
优点：计算简便，易于应用；缺点：指标权重可能受主观因素影响。

### 3.3 数字责任评估的算法实现

#### 3.3.1 算法的代码实现
```python
def calculate_drScore(data, weights):
    dr_score = 0
    for i in range(len(weights)):
        dr_score += data[i] * weights[i]
    return dr_score

# 示例
data = [80, 70, 60]
weights = [0.4, 0.3, 0.3]
print(calculate_drScore(data, weights))
```

#### 3.3.2 算法的运行流程
1. 数据采集与预处理；
2. 计算各指标评分；
3. 根据权重计算总评分；
4. 输出结果。

import pandas as pd

def main():
    data = pd.read_csv('input.csv')
    weights = [0.4, 0.3, 0.3]
    results = []
    for row in data.itertuples():
        dr_score = sum([row[i] * weights[i] for i in range(len(weights))])
        results.append(dr_score)
    results_df = pd.DataFrame({'企业': data['企业'], 'DR评分': results})
    results_df.to_csv('output.csv', index=False)

if __name__ == "__main__":
    main()
