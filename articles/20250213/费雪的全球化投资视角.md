### 4.2 投资组合优化的算法与实现

#### 4.2.1 均值-方差模型的数学公式
$$\text{Minimize } \sigma^2 \text{ subject to } \mathbf{w}^T \mathbf{1} = 1$$

约束条件：  
$$\mathbf{w}^T \mathbf{R} \mathbf{w} = \sigma^2$$  
$$\mathbf{w}^T \mathbf{1} = 1$$  

其中，$\mathbf{w}$是权重向量，$\mathbf{R}$是资产收益率的协方差矩阵，$\sigma^2$是投资组合的方差。

#### 4.2.2 投资组合优化的实现步骤
1. 收集相关资产的历史收益率数据。  
2. 计算资产收益率的协方差矩阵。  
3. 使用均值-方差模型求解最优权重。  
4. 验证投资组合的风险和收益是否符合预期。  

#### 4.2.3 全球化视角下的投资组合优化

### 5.2 投资组合优化的代码实现

#### 5.2.1 数据预处理

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 假设我们已经获取了全球市场的历史收益率数据
returns = pd.read_csv('global_returns.csv').set_index('date')

#### 5.2.2 计算协方差矩阵
```python
cov_matrix = returns.cov()
```

#### 5.2.3 使用均值-方差模型优化投资组合
```python
from scipy.optimize import minimize

# 定义目标函数
def objective(weights):
    return np.dot(weights.T, np.dot(cov_matrix, weights))

# 约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 求解优化问题
weights = np.array([1/len(cov_matrix)] * len(cov_matrix))
result = minimize(objective, weights, method='SLSQP', constraints={'type': 'eq', 'fun': constraint})

print(result.x)
```

#### 5.2.4 可视化投资组合的风险-收益曲线
```python
portfolios = []
for w in np.linspace(0, 1, 100):
    # 假设权重分布均匀
    weights = np.array([w, 1 - w])
    portfolio_return = np.dot(weights, returns.mean())
    portfolio_risk = np.sqrt(np.dot(weights.T, np.dot(cov_matrix, weights)))
    portfolios.append((portfolio_return, portfolio_risk))

portfolio_return = [p[0] for p in portfolios]
portfolio_risk = [p[1] for p in portfolios]

plt.plot(portfolio_risk, portfolio_return)
plt.xlabel('Risk')
plt.ylabel('Return')
plt.show()
```
