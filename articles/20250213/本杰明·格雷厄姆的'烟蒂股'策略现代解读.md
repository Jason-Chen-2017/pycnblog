## 第1章：烟蒂股策略的起源与核心思想

### 1.1 本杰明·格雷厄姆与价值投资的起源

#### 1.1.1 本杰明·格雷厄姆的生平简介  
本杰明·格雷厄姆（Benjamin Graham）是20世纪最具影响力的投资思想家之一，被誉为“价值投资之父”。他于1894年出生于英国伦敦，后移居美国，并在哥伦比亚大学获得了经济学博士学位。格雷厄姆的职业生涯始于1920年代，他与戴维·多德（David Dodd）共同开发了价值投资理论，并在1934年出版了经典著作《证券分析》（Security Analysis），奠定了价值投资的基础。

#### 1.1.2 价值投资理念的形成与核心思想  
格雷厄姆的价值投资理念的核心是：股票不仅仅是一个交易工具，而是一个企业的所有权证明。他强调以合理的估值买入股票，并长期持有，直到其内在价值被市场充分反映。这种投资理念与传统的投机性交易形成了鲜明对比，为后来的投资者提供了长期稳健的投资方法。

---

### 1.2 烟蒂股策略的定义与特点

#### 1.2.1 烟蒂股的定义与核心要素  
烟蒂股（Nifty Stock）是指那些被市场忽视、价格远低于其内在价值的股票。这类股票通常具有以下特征：  
- **低估值**：市盈率（P/E）和市净率（P/B）远低于行业平均水平。  
- **市场忽视**：公司基本面良好，但市场关注度低，投资者对其兴趣不大。  
- **竞争优势**：公司在行业内具有一定的竞争优势，但市场对其未来增长潜力缺乏信心。  

#### 1.2.2 烟蒂股与成长股、周期股的对比分析  
- **成长股**：注重高增长潜力，通常市盈率较高，价格远超内在价值。  
- **周期股**：受经济周期影响较大，价格波动剧烈，适合短期投资。  
- **烟蒂股**：价格被低估，适合长期持有，具有较高的安全边际。  

---

### 1.3 烟蒂股策略的核心思想与投资哲学

#### 1.3.1 "市场先生"理论  
格雷厄姆提出的“市场先生”（Mr. Market）理论是烟蒂股策略的重要基础。市场先生代表市场的波动性和不确定性，投资者应以理性和冷静的态度对待市场波动，避免被市场情绪左右。

#### 1.3.2 投资的三重维度：价格、价值与心理因素  
- **价格**：股票的市场价格由供求关系决定，可能偏离其内在价值。  
- **价值**：股票的内在价值是其未来现金流的现值，可通过财务分析估算。  
- **心理因素**：投资者的心理偏差（如过度恐惧或贪婪）可能导致市场定价的扭曲，为烟蒂股策略提供机会。

## 第2章：烟蒂股策略的核心概念与现代解读

### 2.1 烟蒂股的特征与识别方法

#### 2.1.1 烟蒂股的核心特征  
- **低估值**：通过市盈率、市净率等指标判断股票是否被低估。  
- **市场忽视**：公司基本面良好，但市场关注度低，投资者对其兴趣不大。  

#### 2.1.2 烟蒂股的评估标准  
- **ROE（净资产收益率）**：衡量公司盈利能力的重要指标，ROE越高，公司盈利能力越强。  
- **ROA（资产回报率）**：衡量公司资产使用效率的重要指标，ROA越高，资产利用效率越高。  

#### 2.1.3 烟蒂股的行业分布与投资机会  
- **周期性行业**：如能源、材料等，周期性波动较大，但在市场低谷时可能被低估。  
- **防御性行业**：如公用事业、消费品等，具有稳定的收益和较低的波动性。

### 5.2 烟蒂股筛选算法实现

#### 5.2.1 烟蒂股筛选算法的Python实现  
```python
import pandas as pd
import numpy as np

# 数据加载
df = pd.read_csv('stock_data.csv')

# 计算市盈率和市净率
df['PE'] = df['股价'] / df['每股收益']
df['PB'] = df['股价'] / df['每股净资产']

# 烟蒂股筛选条件
low_pe = df[df['PE'] < df['PE'].mean()]
low_pb = low_pe[low_pe['PB'] < low_pe['PB'].mean()]

# 输出结果
print(low_pb.head())
```
