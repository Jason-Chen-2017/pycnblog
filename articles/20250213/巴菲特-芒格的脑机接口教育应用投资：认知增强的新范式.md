## 第2章: 脑机接口技术的概述

### 2.1 脑机接口的基本概念

#### 2.1.1 脑机接口的定义
脑机接口（BCI）是连接人脑与外部设备的接口技术，允许通过脑活动直接控制计算机或其他设备。

#### 2.1.2 脑机接口的工作原理
- **神经信号采集**：通过 EEG、fMRI 等技术采集脑电信号。
- **信号处理**：对采集的信号进行滤波、特征提取和分类。
- **控制输出**：将处理后的信号转化为对设备的控制指令。

#### 2.1.3 脑机接口的分类与特点
- **侵入式 vs 非侵入式**：非侵入式（如 EEG）更适用于教育场景。
- **实时性**：高实时性是教育应用的关键。
- **易用性**：用户友好性是大规模应用的前提。

```python
import numpy as np
from scipy.signal import butterworth

def process_eeg_signal(signal):
    # 滤波器设计
    fs = 250  # 采样频率
    cutoff = 30  # 截止频率
    order = 4  # 滤波器阶数
    b, a = butterworth(order, cutoff, fs=fs)
    filtered_signal = np.convolve(signal, a, mode='full')[:len(signal)]
    return filtered_signal
```
