## 第二部分：算法原理与数学模型

### 第3章：常用算法原理

#### 3.1 监督学习模型
- 3.1.1 决策树模型：通过特征分裂构建树状结构，用于分类或回归。
- 3.1.2 随机森林模型：通过集成多个决策树，提高模型的准确性和鲁棒性。
- 3.1.3 支持向量机模型：通过寻找最优超平面，实现数据的线性或非线性分类。

#### 3.2 无监督学习模型
- 3.2.1 K均值聚类：将员工分成若干类，分析不同类别的满意度特征。
- 3.2.2 DBSCAN算法：基于密度的聚类方法，发现高密度区域的员工群体。
- 3.2.3 层次聚类：通过层次结构的方式，将员工分成不同的满意度层次。

#### 3.3 深度学习模型
- 3.3.1 神经网络模型：通过多层神经网络，提取复杂的员工满意度特征。
- 3.3.2 长短期记忆网络：适用于时间序列数据，分析员工满意度的变化趋势。
- 3.3.3 图神经网络：通过图结构建模员工之间的关系，分析社交网络对满意度的影响。

### 第4章：数学模型与公式

#### 4.1 监督学习模型的数学基础
- 4.1.1 线性回归模型：
  $$ y = \beta_0 + \beta_1x + \epsilon $$
- 4.1.2 逻辑回归模型：
  $$ P(y=1|x) = \frac{1}{1 + e^{-\beta x}} $$
- 4.1.3 随机森林的集成学习原理：通过多棵决策树的投票或平均，提高模型的泛化能力。

#### 4.2 无监督学习模型的数学基础
- 4.2.1 K均值聚类的距离计算：
  $$ \text{距离}(x_i, x_j) = \sqrt{(x_i - x_j)^2} $$
- 4.2.2 DBSCAN算法的密度计算：
  $$ \text{密度} = \sum_{r} \text{在半径} r \text{内的点数} $$
- 4.2.3 层次聚类的相似性计算：
  $$ \text{相似性}(x_i, x_j) = \frac{x_i \cdot x_j}{\|x_i\| \|x_j\|} $$

from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 数据加载
df = pd.read_csv('employee_satisfaction.csv')

# 数据预处理
X = df.drop('satisfaction_score', axis=1)
y = df['satisfaction_score']

# 数据分割
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 模型训练
model = RandomForestClassifier()
model.fit(X_train, y_train)

# 模型预测
y_pred = model.predict(X_test)

# 模型评估
print(accuracy_score(y_test, y_pred))
