### 8.2 算法数学模型

- 约束条件：资产比例限制。

### 8.3 算法代码实现
```python
def rebalance(weights, target_weights, threshold=0.05):
    # 计算当前偏离
    deviations = {asset: weight - target for asset, weight in weights.items()}
    
    # 判断是否需要调整
    if all(abs(d) < threshold for d in deviations.values()):
        return None
    
    # 计算调整后的权重
    adjusted_weights = {asset: target for asset, target in target_weights.items()}
    return adjusted_weights
```
