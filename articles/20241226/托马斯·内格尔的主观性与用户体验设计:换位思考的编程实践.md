#### 3.2 深度优先搜索（DFS）

深度优先搜索是一种用于图搜索的算法，其核心思想是沿着某一路径不断深入，直到路径无法继续为止，然后回溯到上一个节点，再选择另一条路径进行搜索。

##### 3.2.1 算法描述

1. **初始化**：将起点标记为已访问。
2. **搜索**：从起点开始，选择一个未访问的邻接点进行深度搜索。
3. **递归**：对选定的邻接点重复步骤2，直到到达终点或所有路径都已被访问。
4. **回溯**：如果当前路径无法继续，返回到上一个节点，选择另一条未访问的路径继续搜索。

##### 3.2.2 Mermaid图表示

```mermaid

    A[开始] --> B[选择邻接点]
    B -->|递归| C{到达终点？}
    C -->|是| D[结束]
    C -->|否| E[回溯]
    E --> B
```

##### 3.2.3 Python代码实现

```python
def dfs(graph, start, end):
    visited = set()
    path = [start]
    
    def search(node):
        if node == end:
            return path
        if node in visited:
            return None
        
        visited.add(node)
        for neighbor in graph[node]:
            new_path = search(neighbor)
            if new_path:
                return new_path + [node]
        
        return None
    
    return search(start)

# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}

print(dfs(graph, 'A', 'F'))
```

##### 3.2.4 算法性能分析

- **时间复杂度**：O(|V| + |E|)，其中|V|是节点数，|E|是边数。
- **空间复杂度**：O(|V|)，用于存储已访问节点。

#### 3.3 广度优先搜索（BFS）

广度优先搜索与深度优先搜索类似，但其搜索顺序是按照广度（层次）进行。BFS首先访问起点的所有邻接点，然后依次访问下一层的邻接点。

##### 3.3.1 算法描述

1. **初始化**：使用队列（FIFO）存储起点及其邻接点。
2. **搜索**：从队列中取出下一个节点，并访问其未访问的邻接点。
3. **递归**：对每个邻接点重复步骤2，直到找到目标节点或队列为空。

##### 3.3.2 Mermaid图表示

```mermaid

    A[开始] -->|广度| B{访问邻接点}
    B -->|递归| C{队列为空？}
    C -->|否| D{取出下一个节点}
    D -->|是| E[结束]
```

##### 3.3.3 Python代码实现

```python
from collections import deque

def bfs(graph, start, end):
    queue = deque([start])
    visited = set()
    path = []
    
    while queue:
        node = queue.popleft()
        if node == end:
            return path + [node]
        if node not in visited:
            visited.add(node)
            path.append(node)
            for neighbor in graph[node]:
                queue.append(neighbor)
    
    return None

# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}

print(bfs(graph, 'A', 'F'))
```

##### 3.3.4 算法性能分析

- **时间复杂度**：O(|V| + |E|)，与DFS相同。
- **空间复杂度**：O(|V|)，与DFS相同。

#### 3.4 Dijkstra算法

Dijkstra算法是一种用于求解单源最短路径问题的算法，它基于贪心策略，逐步扩展到最短路径上的所有节点。

##### 3.4.1 算法描述

1. **初始化**：设置一个优先队列，将起点加入队列，初始距离设为0。
2. **扩展**：从队列中取出距离最小的节点，并将其邻接点加入队列，并更新距离。
3. **重复**：重复步骤2，直到找到目标节点或队列为空。

##### 3.4.2 Mermaid图表示

```mermaid

    A[起点] --> B{初始化队列}
    B --> C{扩展节点}
    C --> D{更新距离}
    D --> E{目标节点？}
    E --> F[结束]
```

##### 3.4.3 Python代码实现

```python
import heapq

def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]
    
    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        
        if current_distance > distances[current_node]:
            continue
        
        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    
    return distances

# 示例
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1, 'E': 6},
    'D': {'B': 5, 'C': 1, 'E': 2},
    'E': {'C': 6, 'D': 2}
}

print(dijkstra(graph, 'A'))
```

##### 3.4.4 算法性能分析

- **时间复杂度**：O((|V| + |E|) * log|V|)，其中|V|是节点数，|E|是边数。
- **空间复杂度**：O(|V|)，用于存储距离表和优先队列。

#### 3.5 算法比较

- **DFS和 BFS**：DFS适用于解空间树结构，而BFS适用于图的最短路径问题。
- **Dijkstra算法**：适用于求解有向图和加权图的最短路径问题，但其只能处理非负权图。

// 注册

  try {
    const { username, password, email } = req.body;
    const hashedPassword = await bcrypt.hash(password, 10);
    const [result] = await db.execute('INSERT INTO users (username, password, email) VALUES (?, ?, ?)', [username, hashedPassword, email]);

  } catch (error) {
    res.status(500).json({ success: false, message: 'Internal server error.' });
  }
});

  try {
    const { username, password } = req.body;

    if (users.length === 0) {
      return res.status(401).json({ success: false, message: 'Invalid credentials.' });

    const user = users[0];
    const valid = await bcrypt.compare(password, user.password);
    if (!valid) {
      return res.status(401).json({ success: false, message: 'Invalid credentials.' });

    const token = jwt.sign({ userId: user.id }, 'secretKey');
    res.json({ success: true, token });
  } catch (error) {
    res.status(500).json({ success: false, message: 'Internal server error.' });
  }
});

    if (orders.length === 0) {
