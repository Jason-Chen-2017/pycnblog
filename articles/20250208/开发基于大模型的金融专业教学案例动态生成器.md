#### 3.3 算法实现
- 3.3.1 模型训练的数学公式
  - 交叉熵损失函数：
    $$ \mathcal{L} = -\sum_{i=1}^{n} \sum_{j=1}^{m} y_{i,j} \log p(y_{i,j}|y_{i,1}, \ldots, y_{i,j-1}) $$
  - Adam优化器：
    $$ \theta_{t+1} = \theta_t - \eta \frac{\rho_1}{1-\rho_1^{t}} \cdot \frac{\rho_2}{1-\rho_2^{t}} \cdot \nabla \mathcal{L} $$
- 3.3.2 生成过程的代码示例

```python
def generate_case(model, prompt):
    for _ in range(max_length):
        # 生成下一个字符的概率分布
        probabilities = model.predict(prompt)
        # 根据概率分布生成下一个字符
        next_char = sample(probabilities)
        prompt += next_char
    return prompt
```
