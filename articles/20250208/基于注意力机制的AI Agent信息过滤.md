- **2.1.2 注意力机制的数学模型**

    - 查询：表示需要关注的信息类型。
    - 键：表示输入数据中的关键词或特征。
    - 值：表示与键相关联的信息内容。
  - 注意力权重的计算公式：
    $$\text{score}(q, k) = \frac{q \cdot k}{\sqrt{d}}$$
    其中，$d$是向量的维度。

- **2.1.3 注意力机制的计算流程**
  - 输入数据经过嵌入层，转换为向量形式。
  - 计算查询、键、值向量。
  - 计算注意力权重，并对值向量进行加权求和，得到最终的输出。

#### 第3章：注意力机制的数学模型

##### 3.1 注意力机制的数学公式
- **3.1.1 查询、键、值的定义**
  - 查询向量：表示需要关注的目标。
  - 键向量：表示输入数据的特征。
  - 值向量：表示与键相关联的信息内容。

- **3.1.2 注意力权重的计算公式**
  $$\text{score}(q, k) = \frac{q \cdot k}{\sqrt{d}}$$
  其中，$d$是向量的维度。

- **3.1.3 加权求和的最终输出**
  $$\text{output} = \sum_{i=1}^{n} \text{score}(q, k_i) \cdot v_i$$
  其中，$n$是键的数量。

##### 3.2 注意力机制的实现步骤
- **3.2.1 输入数据的处理**
  - 将输入数据转换为向量形式。
  - 确定查询、键、值向量的维度。

- **3.2.2 查询、键、值的计算**
  - 通过线性变换或嵌入层，计算出查询、键、值向量。

- **3.2.3 注意力权重的计算与归一化**
  - 计算每对查询和键的得分。
  - 对得分进行归一化，得到注意力权重。

- **3.2.4 加权求和与输出**
  - 根据注意力权重，对值向量进行加权求和。
  - 输出最终的处理结果。

##### 3.3 注意力机制的代码实现
- **3.3.1 环境安装**
  - 需要安装Python和深度学习框架（如TensorFlow或PyTorch）。

- **3.3.2 代码实现**
  ```python
  import numpy as np

  def compute_attention(query, keys, values):
      # query: (batch_size, d)
      # keys: (batch_size, n, d)
      # values: (batch_size, n, d)
      # 输出: (batch_size, d)
      
      # 计算得分
      scores = np.sum(query[:, np.newaxis] * keys, axis=2)  # (batch_size, n)
      scores = scores / np.sqrt(keys.shape[2])  # 归一化
      
      # 计算注意力权重
      attention_weights = np.exp(scores) / np.sum(np.exp(scores), axis=1)[:, np.newaxis]
      
      # 加权求和
      output = np.sum(attention_weights[:, np.newaxis] * values, axis=2)  # (batch_size, d)
      
      return output, attention_weights
  ```

- **3.3.3 代码解读**
  - 通过矩阵乘法计算查询和键之间的得分。
  - 使用Softmax函数对得分进行归一化，得到注意力权重。
  - 根据权重对值向量进行加权求和，得到最终的输出。

  model = create_model()
