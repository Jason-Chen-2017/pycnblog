#### 3.3 算法实现代码示例

import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据加载与预处理
data = pd.read_csv('insurance_data.csv')
X = data[['age', 'bmi', 'children', 'sex', 'smoker', 'region']]
y = data['charges']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 模型预测
predictions = model.predict(X)
```

#### 3.4 算法的数学模型和公式

- **线性回归模型**：
  $$
  y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon
  $$
  其中，$\epsilon$ 是误差项，$\beta$ 是回归系数。

from sklearn.ensemble import RandomForestRegressor
import pandas as pd

# 数据加载
data = pd.read_csv('insurance_product.csv')

# 特征工程
data['age_range'] = pd.cut(data['age'], 5)
data = pd.get_dummies(data, columns=['age_range', 'sex', 'smoker', 'region'])

# 模型训练
model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(data[['age', 'bmi', 'children', 'sex', 'smoker', 'region']], data['demand'])

# 模型预测
predictions = model.predict(data[['age', 'bmi', 'children', 'sex', 'smoker', 'region']])
```
