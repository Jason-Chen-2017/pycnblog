# 第1章: 问题背景与定义

## 1.1 问题背景介绍  
### 1.1.1 高管言行不一致的定义与表现

- **战略执行受阻**：不一致的言行可能导致战略执行中的混乱和低效。

## 3.3 算法实现代码  
```python  
def preprocess(text):  
    # 分词处理  
    words = text.split()  
    return words  

def extract_features(words):  
    # 提取关键词  
    from sklearn.feature_extraction.text import TfidfVectorizer  
    vectorizer = TfidfVectorizer()  
    X = vectorizer.fit_transform([' '.join(words)])  
    return X  

def train_model(X):  
    # 训练分类模型  
    from sklearn.svm import SVC  
    model = SVC()  
    model.fit(X, [0])  
    return model  

def detect_discrepancy(model, new_text):  
    # 检测不一致  
    new_X = extract_features(new_text.split())  
    prediction = model.predict(new_X)  
    return prediction[0]  

# 示例  
text = "我们致力于创新，但研发投入却在减少。"  
preprocessed = preprocess(text)  
X = extract_features(preprocessed)  
model = train_model(X)  
result = detect_discrepancy(model, text)  
print("不一致检测结果：", result)  
```
