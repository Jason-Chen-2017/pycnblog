# 第一部分：被动投资策略的背景与基础

## 第1章：被动投资策略的概述

### 1.1 被动投资的核心概念

被动投资是一种长期的投资策略，其核心在于遵循市场有效性的假设，通过投资于整个市场或其子市场来分散风险。其核心概念包括：

#### 1.1.1 什么是被动投资
被动投资是通过投资于指数基金或交易所交易基金（ETF）等工具，以跟踪市场指数的表现，而不试图通过择时或选股来获取超额收益。这种策略强调长期持有，避免频繁交易和市场波动的影响。

#### 1.1.2 被动投资与主动投资的对比
| 对比维度 | 被动投资 | 主动投资 |
|----------|----------|----------|
| 管理方式 | 按指数配置 | 主动选股/择时 |
| 成本 | 低 | 高 |
| 风险 | 低 | 高 |
| 收益 | 与市场同步 | 追求超额收益 |

#### 1.1.3 被动投资的哲学基础
被动投资的哲学基础来源于现代投资组合理论（MPT）和有效市场假说（EMH）。MPT认为，通过分散投资可以消除非系统性风险，而EMH则认为市场是有效的，个体难以通过分析获得超额收益。

### 1.2 约翰·伯格与被动投资

#### 1.2.1 约翰·伯格的生平简介
约翰·伯格（John Bogle）是被动投资的倡导者，被誉为“指数基金之父”。他是 Vanguard 集团的创始人，致力于推广低成本、被动型投资工具。

#### 1.2.2 伯格对被动投资的贡献
伯格的主要贡献包括：
1. 创建了第一只低成本指数基金（Vanguard 500 Index Fund）。
2. 推广了以投资者利益为核心的价值投资理念。
3. 提出了“总成本”理论，强调成本对投资回报的影响。

#### 1.2.3 伯格的投资理念与实践
伯格认为，长期来看，市场波动和交易成本会侵蚀收益，因此被动投资是更优的选择。他强调长期持有、低成本和分散投资的重要性。

## 第2章：被动投资策略的数学模型与基础原理

### 2.1 被动投资的数学基础

#### 2.1.1 投资回报率的计算公式
投资回报率是衡量投资收益的重要指标，其计算公式为：
$$ R = \frac{P_{final} - P_{initial}}{P_{initial}} \times 100\% $$
其中，$P_{final}$ 是最终价值，$P_{initial}$ 是初始投资。

#### 2.1.2 复利计算与投资时间价值
复利计算公式：
$$ FV = PV \times (1 + r)^n $$
其中，$FV$ 是未来价值，$PV$ 是现值，$r$ 是年化收益率，$n$ 是投资年数。

### 2.2 现代投资组合理论与被动投资

#### 2.2.1 马科维茨的有效前沿理论
马科维茨的有效前沿理论指出，通过合理配置资产，可以在给定风险下获得最大收益，或者在给定收益下最小化风险。

#### 2.2.2 资产配置与风险分散
被动投资通过广泛分散投资于指数基金，来降低非系统性风险。指数基金的Beta系数为1，意味着其收益与市场同步。

#### 2.2.3 被动投资与市场有效性假设
被动投资基于有效市场假说，认为市场价格反映了所有可获取的信息，因此无法通过分析获得超额收益。

## 第3章：被动投资策略的核心要素

### 3.1 被动投资的三大支柱

#### 3.1.1 指数基金
指数基金是被动投资的核心工具，通过跟踪特定指数（如标普500）来实现收益。其优点包括：
1. 成本低。
2. 分散风险。
3. 简化管理。

#### 3.1.2 成本控制
被动投资强调低成本，因为交易费用和管理费用会侵蚀收益。低成本基金通常具有更高的净回报。

#### 3.1.3 长期投资
长期投资是被动投资的核心策略，避免频繁交易以减少摩擦成本。

### 3.2 被动投资的策略选择

#### 3.2.1 市场指数的选择
选择合适的指数是关键，通常选择流动性好、覆盖面广的指数，如标普500、沪深300等。

#### 3.2.2 投资组合的构建
投资组合应包括多个指数基金，以覆盖不同的资产类别和市场区域。

#### 3.2.3 再平衡策略
定期对投资组合进行再平衡，以保持目标配置比例。

```python
import pandas as pd
import numpy as np

def calculate_return(prices):
    returns = prices.pct_change().dropna()
    return returns.mean() * 100

# 示例数据
data = {'Date': ['2020-01-01', '2020-01-02', '2020-01-03'], 
        'Price': [100, 101, 102]}
df = pd.DataFrame(data)
df.set_index('Date', inplace=True)

print(f"年化收益率：{calculate_return(df)}%")
```

#### 5.2.2 投资组合优化模型

```python
import numpy as np

def portfolio_optimization(weights, returns):
    variance = np.dot(weights.T, np.dot(returns.cov(), weights))
    return np.sqrt(variance)

weights = np.array([0.5, 0.5])
returns = np.array([0.05, 0.07])

print(f"投资组合波动率：{portfolio_optimization(weights, returns)}%")
```
