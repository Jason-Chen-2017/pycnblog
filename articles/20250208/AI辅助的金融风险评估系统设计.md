## 第三部分: AI辅助金融风险评估的算法原理

### 第3章: 常见算法概述

#### 3.1 线性回归模型
- **线性回归的基本原理**
  - 线性回归的数学模型：$$y = \beta_0 + \beta_1x + \epsilon$$
  - 最小二乘法求解系数
- **代码实现示例**
  ```python
  import numpy as np
  from sklearn.linear_model import LinearRegression

  # 示例数据
  X = np.array([[1], [2], [3], [4]])
  y = np.array([2, 4, 6, 8])

  # 创建模型
  model = LinearRegression()
  model.fit(X, y)

  # 预测
  print(model.predict([[5]]))  # 输出：[[7.0]]
  ```

#### 3.2 支持向量机（SVM）
- **SVM的基本原理**
  - 支持向量的定义
  - 软间隔与硬间隔
  - 核函数的选择（如RBF核、线性核）
- **代码实现示例**
  ```python
  from sklearn.svm import SVC

  # 示例数据
  X = [[0, 0], [1, 1], [2, 2], [3, 3]]
  y = [0, 1, 1, 0]

  # 创建模型
  model = SVC(kernel='linear')
  model.fit(X, y)

  # 预测
  print(model.predict([[4, 4]]))  # 输出：[0]
  ```
