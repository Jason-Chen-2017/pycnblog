### 5.2 核心代码实现
```python
import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity

# 数据加载
data = pd.read_csv('transactions.csv')

# 数据预处理
user_product_matrix = data.pivot_table(index='客户ID', columns='产品ID', values='交易金额')

# 计算相似度
similarities = cosine_similarity(user_product_matrix.values)

# 生成推荐
def get_recommendations(user_id, num_recommendations=3):
    user_index = user_product_matrix.index.get_loc(user_id)
    similarities_with_user = similarities[user_index]
    product_recommendations = data['产品ID'].unique()[np.argsort(-similarities_with_user)]
    return product_recommendations[:num_recommendations]

# 应用示例
recommendations = get_recommendations('客户123', 3)
print("推荐产品：", recommendations)
```

- **推荐生成**：基于相似度排序，生成推荐列表。
