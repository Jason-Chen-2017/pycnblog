# 第3章: 算法原理与实现

## 3.1 算法原理概述

### 3.1.1 线性回归模型
线性回归是一种简单而有效的回归算法，适用于预测连续型变量。
$$y = \beta_0 + \beta_1x + \epsilon$$
其中，$y$ 是目标变量，$x$ 是特征变量，$\beta_0$ 和 $\beta_1$ 是模型参数，$\epsilon$ 是误差项。

### 3.1.2 支持向量机
支持向量机（SVM）是一种常用的分类算法，适用于高维数据。
$$\text{maximize} \quad \frac{1}{2} \|\mathbf{w}\|^2$$
$$\text{subject to} \quad y_i(\mathbf{w} \cdot \mathbf{x}_i + b) \geq 1, \forall i$$

### 3.1.3 随机森林
随机森林是一种基于决策树的集成算法，适用于分类和回归问题。
- 通过随机选择特征和样本进行树的构建。
- 最终结果通过投票或平均得到。


### 5.2.2 模型训练与评估
```python

from sklearn.metrics import mean_squared_error

model.fit(X_train, y_train)

# 模型评估
y_pred = model.predict(X_test)
print(mean_squared_error(y_test, y_pred))
```
