## 第1章: 个人财务健康指数的背景与意义

### 1.1 个人财务健康指数的定义与目标

#### 1.1.1 什么是个人财务健康指数

个人财务健康指数（Personal Financial Health Index，PFHI）是衡量个人或家庭财务状况健康程度的一个综合性指标。它通过分析资产、负债、收入和支出等多方面的数据，量化个人的财务健康状况。

公式：
$$
\text{PFHI} = \frac{\text{净资产}}{\text{总资产}}
$$

其中，净资产 = 总资产 - 总负债。

#### 1.1.2 财务健康指数的目标

1. 实时跟踪个人财务状况，及时发现潜在问题。
2. 提供个性化财务建议，帮助用户优化财务结构。
3. 预测未来财务风险，提前做好应对准备。

#### 1.1.3 财务健康指数的计算方法

以资产、负债、收入和支出为基础，结合时间因素，动态计算PFHI。公式如下：

$$
\text{PFHI} = \frac{\text{资产} - \text{负债}}{\text{资产} + \text{负债}}
$$

### 6.2 系统核心实现

#### 6.2.1 后端实现

```python
from flask import Flask, request, jsonify
import pymysql

app = Flask(__name__)

@app.route('/api/financial-health', methods=['GET'])
def get_financial_health():
    # 数据库连接
    conn = pymysql.connect(host='localhost', user='user', password='password', db='financial')
    cursor = conn.cursor()
    # 查询数据
    cursor.execute("SELECT * FROM financial_data")
    data = cursor.fetchone()
    asset = data[1]
    liability = data[2]
    health_index = (asset - liability) / (asset + liability)
    conn.close()
    return jsonify({'health_index': health_index})

if __name__ == '__main__':
    app.run(debug=True)
```

### 6.3 实际案例分析

以一个用户的财务数据为例：

- 资产：10万元
- 负债：5万元
- 计算PFHI：
$$
\text{PFHI} = \frac{100000 - 50000}{100000 + 50000} = \frac{50000}{150000} \approx 0.333
$$

健康指数为0.333，属于健康状态。
