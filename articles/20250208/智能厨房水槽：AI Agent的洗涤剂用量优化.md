### 5.2 系统核心实现

#### 5.2.1 AI Agent代码实现
```python
import gym
import numpy as np

class Agent:
    def __init__(self, env):
        self.env = env
        self.Q = np.zeros((env.observation_space.n, env.action_space.n))

    def act(self, observation):
        if np.max(self.Q[observation, :]) == 0:
            return self.env.action_space.sample()
        else:
            return np.argmax(self.Q[observation, :])

    def learn(self, observation, action, reward):
        self.Q[observation, action] = self.Q[observation, action] + 0.1 * (reward + np.max(self.Q[observation, :]) - self.Q[observation, action])
```

#### 5.2.2 环境模拟代码
```python
env = gym.make('CustomKitchenEnv-v0')
agent = Agent(env)
observation = env.reset()
for _ in range(100):
    action = agent.act(observation)
    new_observation, reward, done, _ = env.step(action)
    agent.learn(observation, action, reward)
    observation = new_observation
    if done:
        break
```
