### 附录A：基于VaR的系统性风险测度模型代码

```python
import numpy as np
import pandas as pd

# 示例数据：假设我们有一个资产组合的收益数据
returns = pd.Series([0.02, -0.01, 0.03, -0.02, 0.01])

# 计算VaR（95%置信水平）
alpha = 0.05
sorted_returns = sorted(returns)
var = sorted_returns[int(len(sorted_returns) * alpha)]
print(f"VaR at {1-alpha} confidence level is: {var}")
```

### 附录B：基于网络分析的系统性风险测度模型代码

```python
import networkx as nx

# 示例数据：假设我们有一个银行间拆借网络的数据
banks = ['Bank1', 'Bank2', 'Bank3', 'Bank4']
edges = [('Bank1', 'Bank2'), ('Bank2', 'Bank3'), ('Bank3', 'Bank4'), ('Bank4', 'Bank1')]

G = nx.Graph()
G.add_nodes_from(banks)
G.add_edges_from(edges)

# 计算每个银行的度数中心性
degree_centralities = nx.degree_centrality(G)
print("Degree centralities:", degree_centralities)

# 计算每个银行的接近中心性
closeness_centralities = nx.closeness_centrality(G)
print("Closeness centralities:", closeness_centralities)
```
