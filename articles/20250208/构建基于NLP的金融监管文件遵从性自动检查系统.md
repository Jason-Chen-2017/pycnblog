### 3.2 算法原理

#### 3.2.1 词嵌入模型（如Word2Vec）
通过Word2Vec将词转换为向量表示，捕捉词义信息。

#### 3.2.2 基于规则的分类
根据预先定义的规则对文本进行分类，适用于规则明确的场景。

#### 3.2.3 基于深度学习的模型（如LSTM、BERT）
使用深度学习模型进行文本处理，能够捕捉复杂的语义信息。

### 3.3 数学模型与公式

#### 3.3.1 词嵌入模型的数学公式
Word2Vec的训练目标函数为：$$\text{minimize} \sum_{i=1}^{n} \text{loss}(w_i, w_{i+1})$$

#### 3.3.2 分类模型的损失函数
使用交叉熵损失函数：$$\text{loss} = -\sum_{i=1}^{m} y_i \log(p_i) + (1 - y_i) \log(1 - p_i)$$

#### 3.3.3 模型训练的优化算法
常用随机梯度下降（SGD）或Adam优化器。

```python
import spacy

nlp = spacy.load("en_core_web_sm")

def preprocess(text):
    doc = nlp(text)
    tokens = [token.text for token in doc]
    return tokens
```

#### 5.2.2 信息抽取代码

```python
from spacy.matcher import Matcher

def extract_entities(doc):
    matcher = Matcher(nlp.vocab)
    patterns = [
        [{"POS": "PROPN"}, {"POS": "NOUN"}]  # 公司名称
    ]
    matcher.add("COMPANY", patterns)
    matches = matcher(doc)
    entities = []
    for match_id, start, end in matches:
        entities.append(doc[start:end].text)
    return entities
```
