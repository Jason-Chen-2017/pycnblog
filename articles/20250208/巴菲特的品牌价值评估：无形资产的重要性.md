### 3.2 贴现现金流模型（DCF）
- 3.2.1 DCF模型的原理：将未来的现金流折现到当前
- 3.2.2 DCF模型的步骤：
  1. 预测未来现金流
  2. 选择适当的折现率
  3. 计算现值
- 3.2.3 DCF模型的数学公式：
$$ \text{企业价值} = \sum_{t=1}^{n} \frac{\text{自由现金流}}{(1 + r)^t} + \frac{\text{终值}}{(1 + r)^n} $$

import pandas as pd
import numpy as np

def brand_value_assessment(revenue, growth_rate, discount_rate, period):
    cash_flows = []
    for year in range(period):
        cash_flow = revenue * (1 + growth_rate) ** year
        cash_flows.append(cash_flow)
    present_value = sum(cash_flows / (1 + discount_rate) ** year for year in range(period))
    return present_value

# 示例数据
revenue = 1000000
growth_rate = 0.05
discount_rate = 0.1
period = 5

# 计算品牌价值
brand_value = brand_value_assessment(revenue, growth_rate, discount_rate, period)
print(f"品牌价值评估结果为：{brand_value}")
```
