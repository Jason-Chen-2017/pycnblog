## 第二部分: 算法原理与数学模型

### 第3章: 信用风险评估的核心算法

#### 3.1 逻辑回归算法
- 3.1.1 算法原理
  - 线性回归的思想、sigmoid函数引入、概率解释
  - ```mermaid
  graph TD
  A[输入特征] --> B[计算线性组合]
  B --> C[应用sigmoid函数]
  C --> D[输出概率]
  ```
  - 逻辑回归的损失函数：$$ J = -\frac{1}{m} \sum_{i=1}^m [y_i \log h(x_i) + (1-y_i)\log(1-h(x_i))] $$
  - 其中，$$ h(x) = \frac{1}{1 + e^{-w^T x - b}} $$

- 3.1.2 代码实现
  ```python
  import numpy as np
  def logistic_regression(X, y, iterations=1000, learning_rate=0.01):
      weights = np.zeros(X.shape[1])
      for _ in range(iterations):
          z = np.dot(X, weights)
          a = 1 / (1 + np.exp(-z))
          gradient = np.dot(X.T, (a - y)) 
          weights -= learning_rate * gradient
      return weights
  ```

- 3.1.3 优点与缺点
  - 优点：简单、可解释性高
  - 缺点：假设数据线性可分、对特征工程依赖较高

#### 3.2 随机森林算法
- 3.2.1 算法原理
  - 集成学习思想、袋装法、随机特征选择
  - ```mermaid
  graph TD
  A[输入数据] --> B[生成多个样本集]
  B --> C[训练决策树]
  C --> D[投票或平均结果]
  ```

- 3.2.2 代码实现
  ```python

  model = RandomForestClassifier(n_estimators=100, max_depth=5)
  model.fit(X_train, y_train)
  ```

- 3.2.3 优点与缺点
  - 优点：高精度、鲁棒性好
  - 缺点：可解释性较低

#### 3.3 神经网络算法
- 3.3.1 算法原理
  - 层次化结构、神经元模型、反向传播
  - ```mermaid
  graph TD
  A[输入层] --> B[隐藏层]
  B --> C[输出层]
  ```

- 3.3.2 代码实现
  ```python
  import torch
  class NeuralNetwork(torch.nn.Module):
      def __init__(self, input_size, hidden_size, output_size):
          super().__init__()
          self.fc1 = torch.nn.Linear(input_size, hidden_size)
          self.fc2 = torch.nn.Linear(hidden_size, output_size)
      def forward(self, x):
          x = torch.relu(self.fc1(x))
          x = torch.sigmoid(self.fc2(x))
          return x
  ```

- 3.3.3 优点与缺点
  - 优点：非线性能力强、适合复杂数据
  - 缺点：训练时间长、容易过拟合
