### 1.1.2 长文本理解的重要性
长文本理解在多个领域具有重要应用，例如：

长文本理解的边界在于如何界定“长”以及理解的深度。外延则包括文本摘要、问答系统、文本分类等任务。

# 第3章: 长文本理解的算法原理

## 3.1 基于Transformer的长文本理解算法

### 3.1.1 Transformer模型的工作原理

```mermaid
graph LR
    A[输入序列] --> B[自注意力机制]
    B --> C[前馈网络]
    C --> D[输出序列]
```

公式：
$$
\text{score}(i, j) = \frac{Q_i \cdot K_j}{\sqrt{d_k}}
$$

代码示例：
```python
import torch
class TransformerLayer(torch.nn.Module):
    def __init__(self, d_model, n_head, d_k):
        super(TransformerLayer, self).__init__()
        self.n_head = n_head
        self.d_k = d_k
        self.Q = torch.nn.Linear(d_model, n_head*d_k, bias=False)
        self.K = torch.nn.Linear(d_model, n_head*d_k, bias=False)
        self.V = torch.nn.Linear(d_model, n_head*d_k, bias=False)
    def forward(self, x):
        # x: [batch_size, seq_len, d_model]
        q = self.Q(x).view(-1, x.size(1), self.n_head, self.d_k)
        k = self.K(x).view(-1, x.size(1), self.n_head, self.d_k)
        v = self.V(x).view(-1, x.size(1), self.n_head, self.d_k)
        # 计算注意力得分
        scores = (q @ k.transpose(-2, -1)) / torch.sqrt(torch.tensor(self.d_k))
        # 应用Softmax
        attention = torch.nn.Softmax(dim=-1)(scores)
        # 加权求和
        output = (attention @ v).view(-1, x.size(1), self.n_head * self.d_k)
        return output
```

### 3.1.2 多头注意力机制的实现

公式：
$$
\text{softmax}(\frac{QK^T}{\sqrt{d_k}})
$$

- 拼接策略：通过注意力机制将分割后的段落拼接起来。

### 3.3.3 Span-based模型的训练与推理

公式：
$$
\text{Loss} = \sum_{i=1}^{n} \text{CrossEntropy}(y_{i,\text{pred}}, y_{i,\text{true}})
$$

代码示例：
```python
class SpanClassifier(torch.nn.Module):
    def __init__(self, d_model, num_classes):
        super(SpanClassifier, self).__init__()
        self.fc_start = torch.nn.Linear(d_model, 1)
        self.fc_end = torch.nn.Linear(d_model, 1)
        self.num_classes = num_classes
    def forward(self, x):
        # x: [batch_size, seq_len, d_model]
        start_logits = self.fc_start(x).squeeze(-1)
        end_logits = self.fc_end(x).squeeze(-1)
        return start_logits, end_logits
```
