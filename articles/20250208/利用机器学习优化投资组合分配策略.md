### 第1章：投资组合优化的背景与意义

#### 1.1 投资组合优化的背景
- 1.1.1 什么是投资组合优化？
  - 投资组合优化是指通过科学的方法选择最优的投资组合，以实现风险和收益的最佳平衡。
  - 投资组合优化的目标是最大化收益、最小化风险或两者之间的平衡。
- 1.1.2 投资组合优化的重要性
  - 在金融市场中，投资组合优化是投资者实现财富增长的重要手段。
  - 通过优化投资组合，投资者可以在不同的市场环境下实现稳健的收益。

#### 1.2 机器学习在投资组合优化中的作用
- 1.2.1 传统投资组合优化方法的局限性
  - 基于均值-方差模型的传统优化方法假设资产收益服从正态分布，但在实际金融市场中，资产收益往往呈现非正态分布，这使得传统方法在实际应用中效果有限。
- 1.2.2 机器学习的优势
  - 机器学习能够处理非线性关系，能够捕捉复杂市场环境中的模式和趋势。
  - 机器学习模型可以根据历史数据自动学习，生成更加准确的预测。

#### 1.3 机器学习与投资组合优化的结合
- 1.3.1 机器学习在投资组合优化中的应用场景
  - 资产配置：根据市场环境和投资者风险偏好，动态调整资产配置比例。
  - 风险管理：通过机器学习模型预测市场风险，优化投资组合的风险暴露。
  - 交易信号：利用机器学习模型生成交易信号，优化交易时机和策略。

### 第2章：投资组合优化的数学模型

#### 2.1 投资组合优化的基本模型
- 2.1.1 均值-方差模型
  - 均值-方差模型是投资组合优化的基础，由Harry Markowitz在1952年提出。
  - 该模型的目标是通过优化资产的收益和风险，找到最优的投资组合。
  - 数学表达式：
    - 目标函数：$\min_w \sigma^2(w)$
    - 约束条件：$\sum_{i=1}^n w_i = 1$, $w_i \geq 0$

- 2.1.2 均值-方差模型的扩展
  - 包括引入风险溢价、考虑交易成本等扩展模型。

#### 2.2 机器学习算法在投资组合优化中的应用
- 2.2.1 线性回归在投资组合优化中的应用
  - 线性回归可以用于预测资产收益，从而优化投资组合的配置。
- 2.2.2 支持向量机（SVM）在投资组合优化中的应用
  - SVM可以用于分类问题，可以将资产分为高风险和低风险两类，从而优化投资组合的风险收益比。
- 2.2.3 随机森林在投资组合优化中的应用
  - 随机森林可以用于资产分类和回归预测，能够捕捉复杂市场环境中的非线性关系。

import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('stock_data.csv')

# 数据清洗
data.dropna(inplace=True)
data = data.iloc[:, 1:]  # 去除第一列（日期）
data = data.pct_change().dropna()  # 计算收益率
data = data.apply(lambda x: (x - x.mean()) / x.std())  # 标准化
```
- 5.2.2 模型训练代码
```python
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split

# 数据分割
X_train, X_test, y_train, y_test = train_test_split(data.drop(columns=['收益']), data['收益'], test_size=0.2)

# 模型训练
model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(X_train, y_train)

# 模型预测
y_pred = model.predict(X_test)
