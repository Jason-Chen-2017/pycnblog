# 第二部分：时间序列预测算法原理

## 第3章：常见时间序列预测算法

### 3.1 ARIMA模型  
ARIMA（自回归积分滑动平均模型）是一种经典的统计模型，适用于线性时间序列数据。

### 3.2 LSTM网络  
长短期记忆网络（LSTM）是一种深度学习模型，能够有效捕捉时间序列中的长期依赖关系。

### 3.3 Prophet模型  
Prophet是一种基于回归的模型，特别适合非平稳的时间序列数据。
