## 第二部分: 智能投资组合税收优化的核心概念与数学模型

### 第2章: 智能投资组合的数学模型

#### 2.1 投资组合优化的数学表达

- **2.1.1 投资组合的收益与风险模型**

  - 收益模型：预期收益、方差、协方差
  - 风险模型：方差、标准差
  - 收益与风险的权衡：风险调整后收益

- **2.1.2 投资组合的优化目标函数**

  - 最大化收益：$ \max \sum_{i=1}^n w_i r_i $
  - 最小化风险：$ \min \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} $
  - 风险收益平衡：$ \min \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} - \lambda \sum_{i=1}^n w_i r_i $

- **2.1.3 投资组合的约束条件**

  - 资产权重之和：$ \sum_{i=1}^n w_i = 1 $
  - 资产权重非负：$ w_i \geq 0 $

#### 2.2 税收优化的数学模型

- **2.2.1 税收对投资收益的影响公式**

  - 税后收益计算：$ r_i^{税后} = r_i - t_i \cdot r_i = r_i (1 - t_i) $
  - 税收对投资组合收益的影响：$ \sum_{i=1}^n w_i r_i^{税后} = \sum_{i=1}^n w_i r_i (1 - t_i) $

- **2.2.2 税收优化的数学表达式**

  - 税收优化目标：$ \min \sum_{i=1}^n w_i t_i r_i $
  - 约束条件：$ \sum_{i=1}^n w_i = 1 $，$ w_i \geq 0 $

- **2.2.3 税收优化与投资组合的结合模型**

  - 综合优化目标：$ \min \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} + \lambda \sum_{i=1}^n w_i t_i r_i $

#### 2.3 智能投资组合税收优化的综合模型

- **2.3.1 综合模型的构建过程**

  - 确定资产池
  - 确定税收政策
  - 构建优化目标函数
  - 设置约束条件

- **2.3.2 综合模型的变量与参数**

  - 变量：$ w_i $（资产权重）
  - 参数：$ r_i $（预期收益）、$ \sigma_{ij} $（协方差）、$ t_i $（税率）、$ \lambda $（风险-税收权衡系数）

- **2.3.3 综合模型的求解方法**

  - 数学优化方法：拉格朗日乘数法
  - 计算步骤：构建拉格朗日函数、求导、解方程组

          return -sum(weights * returns * (1 - tax_rates))

      # 定义约束条件
