- **2.1.4 算法的数学模型与公式**
  - 决策树分类：$C(x) = \arg\min_{c} \sum_{i=1}^{n} w_i x_i$
  - 随机森林：基于决策树的集成学习方法
  - 支持向量机：$y = \text{sign}(w \cdot x + b)$

#### 2.2 投资者决策模型的数学公式

- **2.2.1 投资决策公式**
  $$ P = \sum_{i=1}^{n} w_i x_i $$
  其中，$P$ 表示投资组合的预期收益，$w_i$ 是权重，$x_i$ 是各资产的预期收益。

- **2.2.2 风险评估公式**
  $$ R = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (r_i - \bar{r})^2} $$
  其中，$R$ 表示投资组合的风险（标准差），$r_i$ 是各资产的收益，$\bar{r}$ 是平均收益。

- **2.2.3 投资回报预测公式**
  $$ R_t = a + b \cdot t + \epsilon $$
  其中，$R_t$ 表示第 $t$ 期的回报，$a$ 是截距，$b$ 是斜率，$\epsilon$ 是误差项。

  ```python
  import pandas as pd
  from sklearn.ensemble import RandomForestClassifier
  from sklearn.metrics import classification_report

  # 数据加载
  df = pd.read_csv('investor_behavior.csv')
  features = df[['risk_preference', 'time_preference', 'return_preference']]
  labels = df['behavior_type']

  # 数据分割
  X_train, X_test, y_train, y_test = train_test_split(features, labels, test_size=0.2)

  # 模型训练
  clf = RandomForestClassifier(n_estimators=100, random_state=42)
  clf.fit(X_train, y_train)

  # 模型预测
  y_pred = clf.predict(X_test)

  # 模型评估
  print(classification_report(y_test, y_pred))
  ```
