## 第1章：主动学习的背景与问题描述

### 1.1 主动学习的定义与核心概念

#### 1.1.1 主动学习的背景
主动学习是一种机器学习方法，允许模型主动选择最具代表性的数据点进行学习。其背景包括数据稀缺性问题、计算资源有限性以及学习效率的优化需求。

#### 1.1.2 主动学习的核心概念
- **查询策略**：决定选择哪些数据点进行标注的策略。
- **样本选择方法**：用于从数据集中选择最具信息量的样本。
- **反馈机制**：模型根据新数据更新和优化的过程。

#### 1.1.3 主动学习与被动学习的对比
| 特性 | 主动学习 | 被动学习 |
|------|----------|----------|
| 数据选择 | 主动选择 | 被动接受 |
| 学习效率 | 高 | 一般 |
| 数据需求 | 较少 | 较多 |

## 第2章：主动学习的核心概念与联系

### 2.1 主动学习的原理

#### 2.1.1 样本选择的核心原理
选择最具代表性和信息量的样本，以提高模型的训练效率。

#### 2.1.2 查询策略的作用机制
通过评估样本的不确定性或多样性，选择最有价值的样本。

#### 2.1.3 反馈机制的实现方式
根据模型的反馈，动态调整数据选择策略，优化模型性能。

### 2.2 核心概念对比

#### 2.2.1 不同查询策略的特征对比
| 策略 | 特点 | 适用场景 |
|------|------|----------|
| 不确定性抽样 | 选择不确定性高的样本 | 初期训练 |
| 多样性抽样 | 选择分布均匀的样本 | 避免过拟合 |
| 边界感知抽样 | 选择边界区域的样本 | 提高分类准确性 |

#### 2.2.2 不同样本选择方法的优缺点对比
| 方法 | 优点 | 缺点 |
|------|------|------|
| 熵值法 | 选择信息量大的样本 | 计算复杂 |
| 多样性抽样 | 避免过拟合 | 效率较低 |
| 最小_margin | 提高分类准确性 | 实现复杂 |

#### 2.2.3 主动学习与其他学习范式的联系
- **无监督学习**：主动学习需要少量标注数据，无监督学习则不需要。
- **半监督学习**：结合了主动学习和无监督学习的优势。
- **强化学习**：主动学习中的反馈机制与强化学习的奖励机制有相似之处。

## 第3章：主动学习的算法原理

### 3.1 不确定性抽样

#### 3.1.1 熵值计算方法
$$ H = -\sum p_i \log p_i $$

#### 3.1.2 实现步骤
1. 计算每个样本的预测概率分布。
2. 计算每个样本的熵值。
3. 选择熵值最大的样本进行标注。

#### 3.1.3 代码示例
```python
import numpy as np

def entropy(y_pred):
    return -np.sum(y_pred * np.log(y_pred + 1e-10), axis=1)
```

### 3.2 多样性抽样

#### 3.2.1 原理
选择分布最分散的样本，以提高模型的泛化能力。

#### 3.2.2 实现方式
1. 将数据点嵌入到低维空间。
2. 计算数据点之间的距离矩阵。
3. 选择距离最远的样本作为下一个标注样本。

### 3.3 边界感知抽样

#### 3.3.1 数学模型
$$ f(x) = \argmax_{i} P(y=i|x) $$

#### 3.3.2 实现步骤
1. 训练初始分类器。
2. 找到分类器输出置信度最低的样本。
3. 标注这些样本并重新训练模型。

### 3.4 算法选择策略

#### 3.4.1 不同场景下的选择
- **初期训练**：使用不确定性抽样。
- **后期优化**：使用边界感知抽样。
