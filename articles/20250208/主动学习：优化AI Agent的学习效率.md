## 第3章：主动学习的算法原理

### 3.1 不确定性抽样

#### 3.1.1 熵值计算方法
$$ H = -\sum p_i \log p_i $$

#### 3.1.2 实现步骤
1. 计算每个样本的预测概率分布。
2. 计算每个样本的熵值。
3. 选择熵值最大的样本进行标注。

#### 3.1.3 代码示例
```python
import numpy as np

def entropy(y_pred):
    return -np.sum(y_pred * np.log(y_pred + 1e-10), axis=1)
```

### 3.2 多样性抽样

#### 3.2.1 原理
选择分布最分散的样本，以提高模型的泛化能力。

#### 3.2.2 实现方式
1. 将数据点嵌入到低维空间。
2. 计算数据点之间的距离矩阵。
3. 选择距离最远的样本作为下一个标注样本。

### 3.3 边界感知抽样

#### 3.3.1 数学模型
$$ f(x) = \argmax_{i} P(y=i|x) $$

#### 3.3.2 实现步骤
1. 训练初始分类器。
2. 找到分类器输出置信度最低的样本。
3. 标注这些样本并重新训练模型。

### 3.4 算法选择策略

#### 3.4.1 不同场景下的选择
- **初期训练**：使用不确定性抽样。
- **后期优化**：使用边界感知抽样。
