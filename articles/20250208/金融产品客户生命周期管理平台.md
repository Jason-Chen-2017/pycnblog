##### 3.2 聚类算法的数学模型
- 3.2.1 K-means的数学推导
  - 目标函数：最小化所有点到质心的平方距离之和
  - $$\text{目标函数} = \sum_{i=1}^{k} \sum_{x \in C_i} (x - c_i)^2$$
- 3.2.2 层次聚类的数学基础
  - 相似性计算公式：余弦相似度
  - $$\text{相似度}(x, y) = \frac{x \cdot y}{\|x\| \|y\|}$$
- 3.2.3 算法流程图
  ```mermaid

    A[初始化质心] --> B[分配数据点]
    B --> C[计算质心]
    C --> D[迭代]
    D --> E[停止条件满足]
  ```

##### 3.3 算法实现
- 3.3.1 Python代码实现
  ```python
  from sklearn.cluster import KMeans
  import pandas as pd
  import numpy as np

  # 示例数据
  data = pd.DataFrame({
      'x': np.random.rand(100),
      'y': np.random.rand(100)
  })

  # K-means 聚类
  kmeans = KMeans(n_clusters=3)
  kmeans.fit(data)
  labels = kmeans.labels_

  # 可视化
  import matplotlib.pyplot as plt
  plt.scatter(data.x, data.y, c=labels)
  plt.show()
  ```
