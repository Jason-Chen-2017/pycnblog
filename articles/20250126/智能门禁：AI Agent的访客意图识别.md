#### 3.2 Python代码实现

接下来，我们将提供Python代码示例，展示如何通过编程实现访客意图识别的关键步骤。以下是一个简化的Python代码实现示例：

```python
import cv2
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

# 数据采集
def capture_video():
    cap = cv2.VideoCapture(0)  # 使用内置摄像头
    while True:
        ret, frame = cap.read()
        if ret:
            yield frame
        else:
            break
    cap.release()

# 特征提取
def extract_features(frame):
    face_cascade = cv2.CascadeClassifier('haarcascade_frontalface_default.xml')
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5)
    features = []
    for (x, y, w, h) in faces:
        face_region = gray[y:y+h, x:x+w]
        feature_vector = np.array(face_region).flatten()
        features.append(feature_vector)
    return np.array(features)

# 模式识别
def recognize_intent(features, model_path):
    model = RandomForestClassifier()
    model.load_model(model_path)
    intent = model.predict(features)
    return intent

# 决策生成
def make_decision(intent):
    if intent == 'allowed':
        print("访客被允许进入。")
    else:
        print("访客被拒绝进入。")

# 主程序
if __name__ == '__main__':
    model_path = 'intent_recognition_model.pkl'  # 模型保存路径
    video = capture_video()
    for frame in video:
        features = extract_features(frame)
        intent = recognize_intent(features, model_path)
        make_decision(intent)
```

在这个代码示例中，我们首先通过`capture_video`函数采集视频数据。然后，通过`extract_features`函数从视频帧中提取面部特征。接下来，使用`recognize_intent`函数加载预训练的模型，对提取的特征进行意图识别。最后，通过`make_decision`函数生成决策，根据识别结果允许或拒绝访客进入。
