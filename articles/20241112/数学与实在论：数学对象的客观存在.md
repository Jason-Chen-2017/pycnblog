### 1. 数学与实在论的基本概念

#### 1.1 数学

数学是一门研究数量、结构、变化和空间等概念的抽象科学。其研究对象被称为数学对象，如数、函数、集合、图形等。数学以其严谨的逻辑推理和公理体系而闻名，通过这些逻辑推理，数学能够推导出一系列的定理和公式。

#### 1.2 实在论

实在论是一种哲学观点，认为客观世界存在着独立于人类意识的外在实体。实在论通常分为物质实在论和精神实在论两种，前者认为物质是世界的本质，后者则认为意识或精神是世界的本质。

### 1.3 数学与实在论的关系

数学与实在论之间的关系可以从多个角度进行分析。一方面，数学对象作为抽象的概念，它们的存在性是依赖于人类意识的，这体现了数学的主观性。另一方面，数学对象在自然界和社会生活中有着广泛的应用，这表明数学对象在一定程度上具有客观性。

def multiply(x, y):
    return x * y

def divide(x, y):
    if y != 0:
        return x / y

    x = np.linspace(x_range[0], x_range[1], 1000)

    plt.plot(x, y)
    plt.xlabel('x')
    plt.ylabel('y')
    plt.title(f'{func.__name__} Plot')
    plt.show()
