#### 2.1 微分方程

微分方程是描述物理现象的重要工具，尤其在宇宙学、天体物理学等领域具有广泛应用。微分方程分为常微分方程和偏微分方程。常微分方程涉及一个或多个未知函数及其导数，而偏微分方程涉及多个未知函数及其偏导数。

**核心概念与联系**

微分方程的核心概念包括导数、积分、解的存在性与唯一性等。微分方程的解可以通过解析方法或数值方法得到。其中，数值方法如有限差分法、有限元法、数值积分等在宇宙研究中具有重要应用。

**核心算法原理讲解**

以下是求解一维热传导问题的有限差分法伪代码：

```python
# 初始化参数
N = 100  # 网格点数
dx = 1   # 网格间距
dt = 0.01  # 时间步长
k = 1    # 热传导系数

# 初始化温度分布
T = [0.0] * N
T[0] = 100  # 初始条件
T[-1] = 0   # 边界条件

# 迭代计算
for t in range(1, N):
    for i in range(1, N-1):
        T[i] = T[i] + k * dt / dx^2 * (T[i+1] - 2 * T[i] + T[i-1])

# 输出结果
print(T)
```

**数学模型和公式**

热传导方程可以用以下形式表示：

$$
\frac{\partial T}{\partial t} = k \frac{\partial^2 T}{\partial x^2}
$$

其中，$T(x, t)$ 表示温度分布，$k$ 表示热传导系数。

**详细讲解与举例说明**

以一维热传导为例，我们考虑一个长度为1的棒，其两端温度分别为100°C和0°C，棒内初始温度为0°C。我们使用有限差分法来求解这个问题。

首先，我们将棒划分为100个等间距的小区间，每个小区间的长度为dx=1/N。设第i个小区间的温度为$T_i$，则温度分布可以表示为$T(x)$。

我们假设在时间步t=0时，温度分布为$T_0$。在时间步t=1时，温度分布更新为$T_1$。根据热传导方程，我们有：

$$
T_1[i] = T_0[i] + k \frac{dt}{dx^2} (T_0[i+1] - 2T_0[i] + T_0[i-1])
$$

通过迭代更新，我们可以得到任意时间步的温度分布。

**核心算法原理讲解**

线性方程组的求解是线性代数中的一个基本问题。以下是使用高斯消元法求解线性方程组的伪代码：

```python
# 初始化参数
A = [[1, 2], [3, 4]]  # 矩阵A
b = [1, 2]  # 矩阵b

# 高斯消元法
for i in range(len(A)):
    # 找到最大元素的位置
    max_idx = i + max(range(i, len(A)), key=lambda j: abs(A[j][i]))
    # 交换行
    A[i], A[max_idx] = A[max_idx], A[i]
    b[i], b[max_idx] = b[max_idx], b[i]
    # 消元
    for j in range(i+1, len(A)):
        factor = A[j][i] / A[i][i]
        A[j] = [A[j][k] - factor * A[i][k] for k in range(len(A[j]))]
        b[j] = b[j] - factor * b[i]

# 回代求解
x = [0] * len(A)
for i in reversed(range(len(A))):
    x[i] = (b[i] - sum(A[i][j] * x[j] for j in range(i+1, len(A))) / A[i][i]

# 输出结果
print(x)
```

**数学模型和公式**

线性方程组可以表示为：

$$
Ax = b
$$

其中，$A$ 是系数矩阵，$x$ 是未知向量，$b$ 是常数向量。

**详细讲解与举例说明**

我们考虑一个简单的线性方程组：

$$
\begin{cases}
x + 2y = 1 \\
3x + y = 2
\end{cases}
$$

使用高斯消元法求解这个方程组。

首先，我们写出系数矩阵和常数向量：

$$
A = \begin{pmatrix}
1 & 2 \\
3 & 1
\end{pmatrix}, \quad b = \begin{pmatrix}
1 \\
2
\end{pmatrix}
$$

然后，我们进行高斯消元：

1. 将第二行减去第一行的3倍，得到新的第二行：

$$
\begin{pmatrix}
1 & 2 \\
0 & -5
\end{pmatrix}
$$

2. 解第二个方程得到$y$：

$$
-5y = -1 \Rightarrow y = \frac{1}{5}
$$

3. 将$y$的值代入第一个方程，解得$x$：

$$
x + 2 \cdot \frac{1}{5} = 1 \Rightarrow x = 1 - \frac{2}{5} = \frac{3}{5}
$$

因此，方程组的解为$x = \frac{3}{5}$，$y = \frac{1}{5}$。

**核心算法原理讲解**

参数估计是统计学中的一个基本问题。最大似然估计（Maximum Likelihood Estimation, MLE）是一种常用的参数估计方法。以下是最大似然估计的伪代码：

```python
# 初始化参数
data = [1, 2, 3, 4, 5]  # 观测数据
model = "Normal"  # 模型类型

# 定义概率密度函数
if model == "Normal":
    def pdf(x, mu, sigma):
        return (1 / (sigma * np.sqrt(2 * np.pi))) * np.exp(-((x - mu)^2) / (2 * sigma^2))
elif model == "Exponential":
    def pdf(x, lambda_):
        return lambda_ * np.exp(-lambda_ * x)

# 计算似然函数
likelihood = 1
for x in data:
    likelihood *= pdf(x, mu, sigma)

# 求解参数
# (这里可以使用优化算法如梯度下降、牛顿法等求解参数)

# 输出结果
print(mu, sigma)
```

**数学模型和公式**

假设我们观测到一组数据$x_1, x_2, ..., x_n$，我们想要估计某个参数$\theta$。最大似然估计的目标是找到使得观测数据似然函数最大的参数值。

$$
\theta_{\text{MLE}} = \arg\max_{\theta} \prod_{i=1}^{n} p(x_i | \theta)
$$

**详细讲解与举例说明**

我们考虑一个正态分布的数据集，数据集为$[1, 2, 3, 4, 5]$。我们想要估计这个数据集的均值$\mu$和标准差$\sigma$。

首先，我们定义正态分布的概率密度函数：

$$
p(x | \mu, \sigma) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

然后，我们计算似然函数：

$$
\text{likelihood} = \prod_{i=1}^{5} p(x_i | \mu, \sigma)
$$

为了求解$\mu$和$\sigma$，我们可以使用最大似然估计方法。假设我们通过优化算法得到了$\mu = 3$和$\sigma = 1$，那么这两个值就是数据集的最佳估计。
