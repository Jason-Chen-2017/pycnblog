### 核心概念与联系

程序切片技术是指对程序进行分割，提取出与特定测试目标相关的部分，以便于测试和调试。其核心概念包括：

- 切片点：程序中的一个位置，用于确定切片的范围。
- 切片条件：用于确定切片包含哪些语句的条件。

```python
# 切片点为b = a + 2
def slice_code(source_code, slice_point):
    sliced_code = []
    for line in source_code:
        if line == slice_point:
            sliced_code.append(line)
    return sliced_code

source_code = [
    "a = 1",
    "b = a + 2",
    "c = b * 3"
]

sliced_code = slice_code(source_code, "b = a + 2")
print(sliced_code)
