#### 概率论基础

概率论是研究随机现象的数学分支。在信贷分析中，概率论用于预测借款人的违约风险。

**核心概念**：
- **概率分布**：描述随机变量取值的概率分布。
- **条件概率**：在某个事件已经发生的条件下，另一个事件发生的概率。
- **贝叶斯定理**：用于计算后验概率，即根据已知结果反推原始概率。

**核心算法原理**：
```plaintext
// 伪代码：条件概率计算
P(A|B) = P(A ∩ B) / P(B)
```

**数学公式**：
$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

**核心算法原理**：

// 伪代码：样本均值和标准差计算

### 信贷分析原理

信贷风险是指借款人无法按期偿还贷款本息的可能性。信贷分析是评估借款人信用状况、预测违约风险的过程。

#### 信贷风险定义与分类

**定义**：
- **信贷风险**：借款人因各种原因无法按期偿还贷款本息的风险。

**分类**：
- **违约风险**：借款人无法偿还贷款本息的风险。
- **利率风险**：利率波动导致贷款收益变化的风险。
- **流动性风险**：借款人因流动性问题导致无法偿还贷款的风险。

#### 信用评分模型

信用评分模型是用于评估借款人信用风险的工具。常见的信用评分模型包括：

- **逻辑回归**：将借款人的特征转换为信用评分。
- **决策树**：通过分类决策来评估借款人信用风险。
- **随机森林**：通过集成多个决策树来提高预测准确性。

#### 违约预测模型

违约预测模型是用于预测借款人是否会发生违约的模型。常见的违约预测模型包括：

- **逻辑回归**：通过分析借款人的特征，预测违约概率。
- **支持向量机**：通过建立最优分类边界来预测违约。
- **神经网络**：通过多层神经网络进行非线性预测。

#### 贷款组合风险评估

贷款组合风险评估是用于评估一组贷款整体风险的方法。常见的贷款组合风险评估方法包括：

- **VaR（价值在风险）**：计算贷款组合的最大潜在损失。
- **CVaR（条件价值在风险）**：计算贷款组合的平均损失。
