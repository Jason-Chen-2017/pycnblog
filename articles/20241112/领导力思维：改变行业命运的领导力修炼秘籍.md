```
// 决策算法
function makeDecision(options, criteria):
    scores = []
    for option in options:
        score = 0
        for criterion in criteria:
            weight = getWeight(criterion)
            score += (getOptionScore(option, criterion) * weight)
        scores.append(score)
    maxScore = max(scores)
    bestOption = options[scores.index(maxScore)]
    return bestOption
```

**步骤说明：**

1. **输入参数：** `options` 是一个包含所有可能选项的列表，`criteria` 是一个包含所有决策标准的列表。
2. **初始化：** 创建一个空列表 `scores` 用于存储每个选项的得分。
3. **计算得分：** 遍历每个选项，根据每个决策标准计算得分。每个决策标准的得分乘以其权重，然后求和。
4. **确定最佳选项：** 找到得分最高的选项，返回该选项。

**举例说明：**

假设有四个决策选项：A、B、C、D，决策标准包括成本、效益和时间。权重分别为成本：0.4，效益：0.3，时间：0.3。

```
options = ["A", "B", "C", "D"]
criteria = ["cost", "benefit", "time"]
weights = {"cost": 0.4, "benefit": 0.3, "time": 0.3}

# 假设每个选项的具体得分为：
# A: cost=100, benefit=150, time=20
# B: cost=200, benefit=200, time=30
# C: cost=150, benefit=180, time=25
# D: cost=300, benefit=250, time=35

# 计算得分
scores = []
for option in options:
    score = 0
    for criterion in criteria:
        weight = weights[criterion]
        score += (getOptionScore(option, criterion) * weight)
    scores.append(score)

# 输出最佳选项
bestOption = makeDecision(options, criteria)
print("最佳选项：", bestOption)
```

```
// 问题解决算法
function solveProblem(problem):
    solutions = []
    for potentialSolution in generateSolutions(problem):
        if isValidSolution(potentialSolution):
            solutions.append(potentialSolution)
    bestSolution = selectBestSolution(solutions)
```

**步骤说明：**

2. **生成解决方案：** 通过一系列方法生成可能的解决方案。
3. **验证解决方案：** 对每个解决方案进行验证，确保它是有效的。
4. **选择最佳解决方案：** 从有效的解决方案中选择最佳的一个。

**举例说明：**

假设有一个问题：在一个房间里有5个灯，其中3个灯是开着的，2个灯是关着的。你需要进入房间，通过开关门外的三个开关，将所有灯的状态从开变为关。如何操作？

```

generateSolutions = function(problem):
    solutions = []
    for combination in itertools.combinations([1, 2, 3], 3):
        solutions.append(combination)
    return solutions

# 验证解决方案
isValidSolution = function(solution):
    roomState = [0, 0, 0]
    for switch in solution:
        roomState[switch - 1] = (roomState[switch - 1] + 1) % 2
    return all(state == 0 for state in roomState)

# 选择最佳解决方案
selectBestSolution = function(solutions):
    for solution in solutions:
        if isValidSolution(solution):
            return solution

# 问题解决
problem = ["room light", 3, 2]
solutions = generateSolutions(problem)
bestSolution = solveProblem(problem)
print("最佳解决方案：", bestSolution)
```
