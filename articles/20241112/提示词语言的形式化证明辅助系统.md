证明：
  1. 由 n^2 - 1 = (n + 1)(n - 1) 可知，n^2 - 1 可被 3 整除当且仅当 n + 1 和 n - 1 中至少有一个是 3 的倍数。
  2. 如果 n 是 3 的倍数，则 n + 1 和 n - 1 中至少有一个是 3 的倍数，命题成立。
  3. 如果 n 不是 3 的倍数，则 n 可以被表示为 3k + 1 或 3k - 1，其中 k 是整数。
     a. 当 n = 3k + 1 时，n + 1 = 3k + 2，是 3 的倍数，命题成立。
     b. 当 n = 3k - 1 时，n - 1 = 3k，是 3 的倍数，命题成立。
结论：对于任意正整数 n，n^2 - 1 可被 3 整除。
