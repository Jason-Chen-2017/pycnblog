### 3.5 项目实战

#### 3.5.1 实践项目概述

本文将介绍一个简单的实践项目：情绪日记。通过记录每日的情绪变化，个体可以更好地了解自己的情绪波动，从而进行情绪管理。

#### 3.5.2 环境安装

1. 准备一个文本编辑器，如 Notepad++ 或 Sublime Text。
2. 下载并安装一个日期时间插件，以便自动生成日记日期。

#### 3.5.3 系统核心实现源代码

```python
import datetime

def write_diary():
    current_date = datetime.datetime.now().strftime("%Y-%m-%d")
    with open("diary.txt", "a") as file:
        file.write(f"{current_date}:\n")
        file.write("今天我的情绪是如何的呢？\n")
        file.write("请描述你的情绪状态：\n")
        user_input = input()
        file.write(user_input + "\n")
        file.write("\n")

write_diary()
```

#### 3.5.4 代码应用解读与分析

1. 代码首先导入 `datetime` 模块，用于获取当前日期和时间。
2. 定义一个函数 `write_diary`，用于写入日记。
3. 在函数中，首先获取当前日期，并将其格式化成 `YYYY-MM-DD` 的形式。
4. 打开日记文件 "diary.txt"，以追加模式（"a"）写入日期。
5. 输入提示用户描述当天的情绪状态，并将用户输入写入日记文件。
6. 最后，调用 `write_diary` 函数执行日记记录。

import datetime

def write_diary():
    current_date = datetime.datetime.now().strftime("%Y-%m-%d")
    with open("diary.txt", "a") as file:
        file.write(f"{current_date}:\n")
        file.write("今天我的情绪是如何的呢？\n")
        file.write("请描述你的情绪状态：\n")
        user_input = input()
        file.write(user_input + "\n")
        file.write("\n")

write_diary()
```

3. 在函数中，首先获取当前日期，并将其格式化成 `YYYY-MM-DD` 的形式。
4. 打开日记文件 "diary.txt"，以追加模式（"a"）写入日期。
5. 输入提示用户描述当天的情绪状态，并将用户输入写入日记文件。

#### 3.5.1 实践项目概述

#### 3.5.2 环境安装

1. 准备一个文本编辑器，如 Notepad++ 或 Sublime Text。
2. 下载并安装一个日期时间插件，以便自动生成日记日期。

#### 3.5.3 系统核心实现源代码

```python
import datetime

def write_diary():
    current_date = datetime.datetime.now().strftime("%Y-%m-%d")
    with open("diary.txt", "a") as file:
        file.write(f"{current_date}:\n")
        file.write("今天我的情绪是如何的呢？\n")
        file.write("请描述你的情绪状态：\n")
        user_input = input()
        file.write(user_input + "\n")
        file.write("\n")

write_diary()
```

#### 3.5.4 代码应用解读与分析

1. 代码首先导入 `datetime` 模块，用于获取当前日期和时间。
2. 定义一个函数 `write_diary`，用于写入日记。
3. 在函数中，首先获取当前日期，并将其格式化成 `YYYY-MM-DD` 的形式。
4. 打开日记文件 "diary.txt"，以追加模式（"a"）写入日期。
5. 输入提示用户描述当天的情绪状态，并将用户输入写入日记文件。
6. 最后，调用 `write_diary` 函数执行日记记录。
