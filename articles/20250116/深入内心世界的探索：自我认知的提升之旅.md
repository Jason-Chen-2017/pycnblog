### 第一部分：自我认知的基础

#### 1.1 自我认知概述

**1.1.1 自我认知的定义与重要性**

自我认知是指个体对自己内在和外在特征的认知过程，包括对自我能力、情感、动机、信仰等方面的认识和评价。自我认知的重要性在于它不仅影响个人的行为和决策，还影响着人际关系和社会适应能力。

自我认知的定义可以从多个角度进行理解。首先，它是一种心理过程，涉及个体对自己内在和外在特征的感知和理解。其次，自我认知是一种自我评价，通过对自己的行为、思想和情感进行反思，个体能够更好地了解自己的优点和不足，从而进行自我调整和改进。

在现代社会中，自我认知的重要性日益凸显。随着社会竞争的加剧，个体需要具备更强的自我认知能力，以适应不断变化的环境和挑战。自我认知能力不仅有助于个体的成长和发展，还能提高个人的心理健康和生活质量。

**1.1.2 自我认知的基本概念**

自我认知的基本概念包括自我意识、自我效能感、自我价值感等。

自我意识是指个体对自己存在的认识和感知，包括对自身身体、心理和情感状态的认识。自我意识是个体自我认知的基础，它决定了个体如何理解自己，以及如何与他人互动。

自我效能感是指个体对自己完成特定任务的信心和能力评价。自我效能感的高低会影响个体的行为选择、努力程度和成就水平。高自我效能感的个体更有可能设定挑战性的目标，付出更多的努力，并取得更好的成果。

自我价值感是指个体对自己存在的意义和价值的主观评价。自我价值感是个体心理健康的重要指标，它影响着个体的自尊、自信和幸福感受。

**1.1.3 自我认知的发展历程**

自我认知的发展历程可以分为以下几个阶段：

1. **婴儿期**：婴儿期的自我认知主要依赖于对外部环境的感知和反应，他们开始意识到自己的存在，并通过与他人的互动来认识自己。

2. **幼儿期**：幼儿期的自我认知逐渐从外部转向内部，他们开始通过自我观察和自我反思来认识自己。这一时期的个体通常对自我评价较低，容易受到他人的影响。

3. **儿童期**：儿童期的自我认知逐渐成熟，他们开始形成较为稳定的自我概念，并能够对自己进行客观评价。这一时期的个体开始关注自己的能力、价值和人际关系。

4. **青少年期**：青少年期的自我认知进一步发展，他们开始进行更深入的自我探索，寻找自己的身份和价值观。这一时期的个体常常面临自我认同的挑战。

5. **成年期**：成年期的自我认知逐渐稳定，个体形成了较为稳固的自我概念，并对自我进行持续反思和调整。这一时期的个体更加关注个人的成长和发展。

#### 1.2 自我认知的原理与机制

**1.2.1 自我意识的解析**

自我意识是指个体对自己存在的认识和感知，它是个体自我认知的核心。自我意识的解析可以从以下几个方面进行：

1. **自我意识的形成**：自我意识的形成是个体在成长过程中逐渐建立起来的。通过对外部环境的感知和反应，个体逐渐认识到自己的存在，并形成自我意识。

2. **自我意识的内容**：自我意识的内容包括个体对自己的身体、心理和情感状态的认识。个体通过自我观察和自我反思，能够更深入地了解自己，从而形成全面的自我意识。

3. **自我意识的功能**：自我意识的功能包括自我监控、自我调节和自我评价。自我监控是指个体对自己的行为和思想进行监督和调整，以实现自我目标。自我调节是指个体根据自我意识的内容，调整自己的行为和情绪，以适应环境和实现个人目标。自我评价是指个体对自己的行为和表现进行评价和反思，以促进个人成长和发展。

**1.2.2 自我效能感的影响因素**

自我效能感是指个体对自己完成特定任务的信心和能力评价。影响自我效能感的因素包括：

1. **个人经验**：个人经验是影响自我效能感的重要因素。个体在完成任务的过程中，成功或失败的经历会直接影响自我效能感的水平。成功的经历会增强个体的自我效能感，而失败的经历会削弱个体的自我效能感。

2. **替代经验**：替代经验是指个体通过观察他人的行为和结果来评价自己的能力。当个体观察到他人成功完成任务时，会增强自己的自我效能感。相反，当个体观察到他人失败时，会降低自己的自我效能感。

3. **情绪状态**：情绪状态也会影响个体的自我效能感。积极的情绪状态会增强个体的自我效能感，而消极的情绪状态会削弱个体的自我效能感。

4. **心理暗示**：心理暗示也会影响个体的自我效能感。积极的自我暗示会增强个体的自我效能感，而消极的自我暗示会削弱个体的自我效能感。

**1.2.3 自我价值感的评估方法**

自我价值感是指个体对自己存在的意义和价值的主观评价。评估自我价值感的方法包括：

1. **自我评价法**：自我评价法是指个体通过对自己的行为、表现和成就进行反思和评价，来评估自己的自我价值感。个体可以从多个维度进行自我评价，如能力、成就、人际关系等。

2. **心理测量法**：心理测量法是指使用专业的心理测量工具，如量表、问卷等，来评估个体的自我价值感。这些工具通常包含多个维度，如自我认同、自我满意、自我尊重等。

3. **行为观察法**：行为观察法是指通过观察个体的行为和表现，来评估个体的自我价值感。个体在自我价值感较高时，通常表现出自信、积极、主动的行为。

#### 1.3 自我认知的提升方法

**1.3.1 自我反思的实践**

自我反思是指个体通过对自己过去的行为、思维和情感进行反思和评价，来提升自我认知能力。自我反思的实践包括以下几个步骤：

1. **明确反思目标**：个体需要明确自己反思的目标，如提升自我效能感、改善人际关系等。

2. **回顾过去经历**：个体需要回顾自己的过去经历，包括成功和失败的经历，并思考这些经历对自己的影响。

3. **分析原因和结果**：个体需要分析自己的行为、思维和情感原因，以及这些原因导致的结果。

4. **制定改进计划**：个体需要根据分析结果，制定具体的改进计划，以提升自我认知能力。

5. **持续反思和调整**：个体需要持续进行自我反思，并根据反思结果调整自己的行为和思维。

**1.3.2 目标设定的策略**

目标设定是指个体根据自身需求和目标，制定具体的行动计划。目标设定的策略包括以下几个步骤：

1. **明确目标**：个体需要明确自己的目标，如提升某个技能、实现某个目标等。

2. **分解目标**：个体需要将大目标分解为具体的、可操作的小目标，以便更好地实现目标。

3. **设定时间限制**：个体需要为每个小目标设定时间限制，以推动自己尽快实现目标。

4. **制定行动计划**：个体需要根据目标设定，制定具体的行动计划，包括行动步骤、资源和时间安排等。

5. **监控和调整**：个体需要监控自己的行动计划，并根据实际情况进行调整，以确保目标的实现。

**1.3.3 情绪管理的技巧**

情绪管理是指个体通过调整自己的情绪和行为，来应对各种情绪挑战。情绪管理的技巧包括以下几个步骤：

1. **认识情绪**：个体需要认识自己的情绪，包括情绪的类型、原因和影响。

2. **表达情绪**：个体需要学会表达自己的情绪，以避免情绪的压抑和积压。

3. **调整情绪**：个体需要学会调整自己的情绪，如通过深呼吸、放松技巧等方法来缓解情绪。

4. **情绪宣泄**：个体需要学会适当的情绪宣泄方法，如运动、写日记等，以释放情绪压力。

5. **积极情绪培养**：个体需要培养积极的情绪，如通过欣赏美好事物、与他人交流等方法来提升情绪。

#### 1.4 自我认知提升的工具与技术

**1.4.1 日记法**

日记法是一种常用的自我反思工具，个体可以通过记录自己的日常生活、情感和思考，来提升自我认知能力。日记法的实践步骤包括：

3. **反思与总结**：个体可以在日记中反思自己的行为、思维和情感，并进行总结和归纳。

**1.4.3 心理测评工具**

心理测评工具是一种专业的自我认知评估工具，个体可以通过心理测评来了解自己的心理状态和自我认知能力。常见的心理测评工具包括：

**2.1.1 自我反思的概念与意义**

1. **促进自我成长**：通过自我反思，个体可以深入了解自己的行为和思维模式，识别自己的优点和不足，从而有针对性地进行改进和提升。

2. **提高自我认知**：自我反思有助于个体更全面、准确地了解自己的内心世界，提升自我认知水平，增强自我意识和自我效能感。

3. **优化决策能力**：自我反思可以帮助个体在面临决策时，更加客观地分析各种因素，提高决策的质量和效果。

4. **增强心理韧性**：通过自我反思，个体可以学会从失败中汲取经验，增强心理韧性，更好地应对生活中的挑战。

**2.1.2 自我反思的方法与技巧**

自我反思的方法和技巧主要包括以下几个方面：

1. **情境回顾**：在特定情境下，个体需要回顾自己的行为、思维和情感，思考这些因素如何影响了自己的决策和行为。

2. **自我提问**：个体可以通过自我提问的方式，引导自己深入思考问题，如“我在这个情境下做得怎么样？”“我为什么会做出这样的决策？”“我有哪些地方可以改进？”

3. **记录反思日记**：个体可以每天或定期记录自己的反思日记，将反思过程和思考内容记录下来，以便日后回顾和总结。

4. **寻求他人反馈**：个体可以向亲友或专业人士寻求反馈，了解他们对个体行为的看法和建议，从而更全面地认识自己。

5. **制定改进计划**：在反思过程中，个体需要根据反思结果，制定具体的改进计划，以提升自我认知能力和行为效果。

**2.1.3 自我反思的实践与应用**

#### 2.2 目标设定的科学与艺术

**2.2.1 目标设定的基本原则**

目标设定是指个体根据自身需求和目标，制定具体的行动计划的过程。科学的目标设定需要遵循以下几个基本原则：

1. **明确性原则**：目标需要明确、具体，以便个体可以清晰地了解自己的目标，从而有针对性地制定行动计划。

2. **可行性原则**：目标需要具有可行性，即个体在现有的资源和条件下可以实现。过高的目标会导致个体感到沮丧和无力，过低的目标则难以激发个体的潜力。

3. **阶段性原则**：目标需要分为短期和长期目标，以便个体可以逐步实现目标，并保持动力。

4. **激励性原则**：目标需要具有激励性，能够激发个体的积极性和动力，促使个体为实现目标而努力。

**2.2.2 目标设定的方法与策略**

目标设定的方法和策略主要包括以下几个方面：

1. **SMART目标法**：SMART目标法是一种常见的目标设定方法，它要求目标具有明确性（Specific）、可衡量性（Measurable）、可实现性（Achievable）、相关性（Relevant）和时限性（Time-bound）。

2. **目标分解法**：目标分解法是将大目标分解为具体的、可操作的小目标，以便个体可以逐步实现目标。

3. **任务分解法**：任务分解法是将目标分解为具体的任务，并为每个任务设定时间限制和责任人，以便个体可以有序地推进目标的实现。

4. **优先级排序法**：优先级排序法是将目标按照优先级进行排序，以便个体可以集中精力实现最重要的目标。

**2.2.3 目标设定的实际案例**

以下是一个目标设定的实际案例：

**目标：提升英语口语能力**

1. **明确性原则**：明确目标为提升英语口语能力，具体包括听、说、读、写四个方面。

2. **可行性原则**：根据个人的英语基础和时间安排，制定可行的目标，如每天练习英语口语30分钟。

3. **阶段性原则**：将目标分为短期和长期目标，短期目标为一个月内达到每天练习英语口语30分钟，长期目标为半年内达到能够流利地进行英语口语交流。

4. **激励性原则**：设定激励措施，如每达到一个阶段性目标，就奖励自己一个小礼物或休息一天。

通过以上方法，个体可以有效地设定目标，为实现目标制定具体的行动计划，并保持动力和积极性。

#### 1.1 自我认知概述

**1.1.1 自我认知的定义与重要性**

自我认知是指个体对自己内在和外在特征的认知过程，包括对自我能力、情感、动机、信仰等方面的认识和评价。自我认知的重要性在于它不仅影响个人的行为和决策，还影响着人际关系和社会适应能力。

自我认知的定义可以从多个角度进行理解。首先，它是一种心理过程，涉及个体对自己内在和外在特征的感知和理解。其次，自我认知是一种自我评价，通过对自己的行为、思想和情感进行反思，个体能够更好地了解自己的优点和不足，从而进行自我调整和改进。

在现代社会中，自我认知的重要性日益凸显。随着社会竞争的加剧，个体需要具备更强的自我认知能力，以适应不断变化的环境和挑战。自我认知能力不仅有助于个体的成长和发展，还能提高个人的心理健康和生活质量。

**1.1.2 自我认知的基本概念**

自我认知的基本概念包括自我意识、自我效能感、自我价值感等。

自我意识是指个体对自己存在的认识和感知，包括对自身身体、心理和情感状态的认识。自我意识是个体自我认知的基础，它决定了个体如何理解自己，以及如何与他人互动。

自我效能感是指个体对自己完成特定任务的信心和能力评价。自我效能感的高低会影响个体的行为选择、努力程度和成就水平。高自我效能感的个体更有可能设定挑战性的目标，付出更多的努力，并取得更好的成果。

自我价值感是指个体对自己存在的意义和价值的主观评价。自我价值感是个体心理健康的重要指标，它影响着个体的自尊、自信和幸福感受。

4. **青少年期**：青少年期的自我认知进一步发展，他们开始进行更深入的自我探索，寻找自己的身份和价值观。这一时期的个体常常面临自我认同的挑战。

5. **成年期**：成年期的自我认知逐渐稳定，个体形成了较为稳固的自我概念，并对自我进行持续反思和调整。这一时期的个体更加关注个人的成长和发展。

4. **心理暗示**：心理暗示也会影响个体的自我效能感。积极的自我暗示会增强个体的自我效能感，而消极的自我暗示会削弱个体的自我效能感。

2. **可行性原则**：目标需要具有可行性，即个体在现有的资源和条件下可以实现。过高的目标会导致个体感到沮丧和无力，过低的目标则难以激发个体的潜力。

3. **阶段性原则**：目标需要分为短期和长期目标，以便个体可以逐步实现目标，并保持动力。

4. **激励性原则**：目标需要具有激励性，能够激发个体的积极性和动力，促使个体为实现目标而努力。

**2.2.2 目标设定的方法与策略**

目标设定的方法和策略主要包括以下几个方面：

1. **SMART目标法**：SMART目标法是一种常见的目标设定方法，它要求目标具有明确性（Specific）、可衡量性（Measurable）、可实现性（Achievable）、相关性（Relevant）和时限性（Time-bound）。

2. **目标分解法**：目标分解法是将大目标分解为具体的、可操作的小目标，以便个体可以逐步实现目标。

3. **任务分解法**：任务分解法是将目标分解为具体的任务，并为每个任务设定时间限制和责任人，以便个体可以有序地推进目标的实现。

4. **优先级排序法**：优先级排序法是将目标按照优先级进行排序，以便个体可以集中精力实现最重要的目标。

**2.2.3 目标设定的实际案例**

#### 2.2 目标设定的科学与艺术

**2.2.1 目标设定的基本原则**

目标设定是指个体根据自身需求和目标，制定具体的行动计划的过程。科学的目标设定需要遵循以下几个基本原则：

1. **明确性原则**：目标需要明确、具体，以便个体可以清晰地了解自己的目标，从而有针对性地制定行动计划。

2. **可行性原则**：目标需要具有可行性，即个体在现有的资源和条件下可以实现。过高的目标会导致个体感到沮丧和无力，过低的目标则难以激发个体的潜力。

3. **阶段性原则**：目标需要分为短期和长期目标，以便个体可以逐步实现目标，并保持动力。

4. **激励性原则**：目标需要具有激励性，能够激发个体的积极性和动力，促使个体为实现目标而努力。

**2.2.2 目标设定的方法与策略**

目标设定的方法和策略主要包括以下几个方面：

1. **SMART目标法**：SMART目标法是一种常见的目标设定方法，它要求目标具有明确性（Specific）、可衡量性（Measurable）、可实现性（Achievable）、相关性（Relevant）和时限性（Time-bound）。

2. **目标分解法**：目标分解法是将大目标分解为具体的、可操作的小目标，以便个体可以逐步实现目标。

3. **任务分解法**：任务分解法是将目标分解为具体的任务，并为每个任务设定时间限制和责任人，以便个体可以有序地推进目标的实现。

4. **优先级排序法**：优先级排序法是将目标按照优先级进行排序，以便个体可以集中精力实现最重要的目标。

**2.2.3 目标设定的实际案例**

1. **明确性原则**：明确目标为提升英语口语能力，具体包括听、说、读、写四个方面。

2. **可行性原则**：根据个人的英语基础和时间安排，制定可行的目标，如每天练习英语口语30分钟。

3. **阶段性原则**：将目标分为短期和长期目标，短期目标为一个月内达到每天练习英语口语30分钟，长期目标为半年内达到能够流利地进行英语口语交流。

### 算法原理讲解

在自我认知提升的过程中，算法原理起着关键作用。以下将详细讲解自我反思和目标设定两种常用的算法原理，并结合Python源代码进行说明。

#### 自我反思

自我反思是一种通过深入分析自己的行为、思维和情感来提升自我认知的方法。它可以帮助个体识别问题、改进行为并提高自我效能感。

**算法原理：**

1. **情境回顾**：个体选择一个具体的情境，回顾自己的行为和思考过程。
2. **自我提问**：针对情境中的行为和结果，提出一系列问题，如“我在这个情境下做得怎么样？”“我为什么会做出这样的决策？”“我有哪些地方可以改进？”
3. **记录反思**：将反思过程和思考内容记录下来，以便日后回顾和分析。
4. **制定改进计划**：根据反思结果，制定具体的改进措施，并设定行动计划。

**Python代码示例：**

```python
# 自我反思算法示例

def self_reflection(event, questions):
    """
    自我反思函数
    :param event: 情境描述
    :param questions: 自我提问列表
    :return: 反思记录和改进计划
    """
    reflection_log = []
    improvement_plan = []

    # 情境回顾
    print("情境回顾：")
    print(event)

    # 自我提问
    for question in questions:
        answer = input(question + " ")
        reflection_log.append(answer)

    # 制定改进计划
    print("制定改进计划：")
    improvement_input = input("请输入您的改进计划：")
    improvement_plan.append(improvement_input)

    return reflection_log, improvement_plan

# 示例情境和问题
event_example = "在一次团队会议中，我迟到了，并且在讨论中发言不够积极。"
questions_example = [
    "你在这次会议中的感受是什么？",
    "你认为为什么会迟到？",
    "你希望在下次会议中如何改进自己的表现？"
]

# 执行自我反思
reflection_log, improvement_plan = self_reflection(event_example, questions_example)

# 输出反思记录和改进计划
print("反思记录：", reflection_log)
print("改进计划：", improvement_plan)
```

#### 目标设定

目标设定是一种通过明确、具体和可衡量的方式来指导个体行动的方法。SMART目标法（明确性、可衡量性、可实现性、相关性、时限性）是常用的目标设定方法。

**算法原理：**

1. **明确目标**：设定具体、清晰的目标，避免模糊和抽象。
2. **分解目标**：将大目标分解为小目标，便于逐步实现。
3. **设定时间限制**：为每个小目标设定具体的时间期限，推动行动的执行。
4. **制定行动计划**：根据目标设定，制定具体的行动步骤和时间安排。
5. **监控与调整**：持续监控目标的实现情况，并根据实际情况进行调整。

**Python代码示例：**

```python
# 目标设定算法示例

def set_goals(goal, sub_goals, time_limits, action_plan):
    """
    目标设定函数
    :param goal: 明确的目标
    :param sub_goals: 分解的小目标
    :param time_limits: 小目标的时间限制
    :param action_plan: 行动计划
    :return: 目标设定结果
    """
    goal_plan = {
        'main_goal': goal,
        'sub_goals': {},
        'time_limits': {},
        'action_plan': {}
    }

    for i, sub_goal in enumerate(sub_goals):
        goal_plan['sub_goals'][sub_goal] = sub_goals[sub_goal]
        goal_plan['time_limits'][sub_goal] = time_limits[i]
        goal_plan['action_plan'][sub_goal] = action_plan[i]

    return goal_plan

# 示例目标设定
main_goal = "提升英语口语能力"
sub_goals = {
    "听英语材料": "每天听30分钟英语音频",
    "模仿发音": "每周模仿发音3次",
    "日常交流": "每天进行英语口语练习"
}
time_limits = ["30分钟/天", "3次/周", "每天进行"]
action_plan = ["听英语材料", "模仿发音", "日常交流"]

# 执行目标设定
goal_plan = set_goals(main_goal, sub_goals, time_limits, action_plan)

# 输出目标设定结果
print("目标设定结果：")
print(goal_plan)
```

通过自我反思和目标设定，个体可以更系统地提升自我认知。自我反思帮助个体识别问题和改进行为，而目标设定则提供了明确的行动方向和衡量标准。这两种算法原理相辅相成，共同促进了自我认知的提升。

### 数学模型和数学公式

在自我认知提升的过程中，数学模型和数学公式可以提供量化和分析的工具，帮助个体更深入地理解自我认知的过程和结果。以下将介绍几种常见的数学模型和公式，并给出相应的讲解和举例说明。

#### 1. 心理学模型：情绪调节模型

情绪调节模型描述了个体如何调节和控制自己的情绪。其中一个常见的模型是Thoroughman和Blascovich（2006）提出的情绪调节模型，该模型包括以下要素：

- **情绪状态**：个体当前的情绪状态。
- **情绪调节策略**：个体使用的调节策略，如认知重评、行为调节、情绪表达等。
- **情绪结果**：调节策略对情绪状态的影响。

**数学公式：**
\[ 情绪结果 = f(情绪状态, 情绪调节策略) \]

**例子：**
假设个体当前情绪状态为焦虑，使用认知重评策略进行情绪调节。情绪调节模型可以表示为：
\[ 情绪结果 = f(焦虑, 认知重评) \]

通过认知重评策略，焦虑程度可能会降低，情绪结果变为平静。

#### 2. 自我效能感模型：自我效能感计算公式

自我效能感是指个体对自己完成特定任务的信心和能力评价。Bandura（1997）提出了一个自我效能感的计算公式，该公式综合考虑了个人经验、替代经验、情绪状态和心理暗示等因素。

**数学公式：**
\[ 自我效能感 = \alpha \times 个人经验 + \beta \times 替代经验 + \gamma \times 情绪状态 + \delta \times 心理暗示 \]

其中：
- \(\alpha\)、\(\beta\)、\(\gamma\)、\(\delta\)是权重系数。

**例子：**
假设个体通过多次成功完成任务积累了丰富的个人经验，观察到其他人的成功经验增强了替代经验，当前情绪状态积极，且通过积极的自我暗示提高了自我效能感。可以表示为：
\[ 自我效能感 = 0.5 \times 个人经验 + 0.3 \times 替代经验 + 0.1 \times 情绪状态 + 0.1 \times 心理暗示 \]

通过计算，个体对自己的任务完成能力有一个量化的评估。

#### 3. 自我价值感模型：自我价值感评估公式

自我价值感是指个体对自己存在的意义和价值的主观评价。一个常见的评估公式是基于自我认同、自我满意和自我尊重三个维度的综合评估。

**数学公式：**
\[ 自我价值感 = w_1 \times 自我认同 + w_2 \times 自我满意 + w_3 \times 自我尊重 \]

其中：
- \(w_1\)、\(w_2\)、\(w_3\)是权重系数。

**例子：**
假设个体在自我认同、自我满意和自我尊重三个维度上的评分分别为80、70和85，权重系数分别为0.3、0.4和0.3。可以表示为：
\[ 自我价值感 = 0.3 \times 80 + 0.4 \times 70 + 0.3 \times 85 = 24 + 28 + 25.5 = 77.5 \]

通过计算，个体可以了解自己的总体自我价值感水平。

这些数学模型和公式为自我认知提升提供了量化的工具，帮助个体更深入地理解和评估自己的心理状态和认知水平。通过应用这些模型和公式，个体可以更系统地分析自我认知的提升过程，从而制定更有效的提升策略。

#### 系统核心实现源代码

下面是一个简单的Flask应用，用于实现自我认知提升系统的一部分功能，包括用户注册、登录和自我反思记录。

**app.py**

```python
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql+pymysql://username:password@localhost/db_name'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password = db.Column(db.String(120), nullable=False)

@app.route('/register', methods=['POST'])
def register():
    username = request.json.get('username')
    password = request.json.get('password')
    if User.query.filter_by(username=username).first():
        return jsonify({'error': '用户已存在'})
    new_user = User(username=username, password=password)
    db.session.add(new_user)
    db.session.commit()
    return jsonify({'message': '注册成功'})

@app.route('/login', methods=['POST'])
def login():
    username = request.json.get('username')
    password = request.json.get('password')
    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({'token': user.id})
```
