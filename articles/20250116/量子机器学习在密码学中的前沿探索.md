# 第1章：量子计算与量子机器学习

## 1.1 量子计算基础

量子计算是量子力学在计算领域的一种应用。与经典计算不同，量子计算使用量子位（qubit）作为信息存储的基本单位，而不是传统的二进制位（bit）。量子位可以同时存在于0和1的状态，这被称为叠加态。此外，量子位之间可以存在纠缠态，这使得量子计算能够处理复杂的问题。

### 量子位与经典位的比较

| 特性 | 量子位（qubit） | 经Classic位（bit） |  
| ---- | ---- | ---- |  
| 基本状态 | \(\lvert 0 \rangle\)、\(\lvert 1 \rangle\) | \(\lvert 0 \rangle\)、\(\lvert 1 \rangle\) |  
| 叠加态 | 可以处于0和1的叠加态 | 只能处于0或1的一个状态 |  
| 纠缠态 | 量子位之间可以存在纠缠态 | 经Classic位之间不存在纠缠态 |

$$  
\begin{aligned}  
&\text{量子位（qubit）: } \lvert \psi \rangle = \alpha \lvert 0 \rangle + \beta \lvert 1 \rangle \\  
&\text{经典位（bit）: } b = \lvert 0 \rangle \text{ 或 } \lvert 1 \rangle  
\end{aligned}  
$$

## 1.2 量子门与量子运算

量子门是量子计算中的基本操作，类似于经典计算中的逻辑门。量子门作用于量子位，可以实现量子位的旋转、变换和操作。

### Hadamard门

Hadamard门是最基本的量子门之一，它可以实现量子位的叠加态到等概率混合态的转换。Hadamard门可以用矩阵表示为：

$$  
H = \frac{1}{\sqrt{2}} \begin{pmatrix}  
1 & 1 \\  
1 & -1  
\end{pmatrix}  
$$

### 量子逻辑门

量子逻辑门是具有可逆特性的量子操作，它们将量子比特映射到量子比特。常见的量子逻辑门包括：

- Pauli门（X、Y、Z门）
- Hadamard门（H门）
- 控制非门（CNOT门）
- 控制Z门（CZ门）

$$
\lvert \psi \rangle = \alpha \lvert 0 \rangle + \beta \lvert 1 \rangle
