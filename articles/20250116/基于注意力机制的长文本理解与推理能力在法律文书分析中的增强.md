## 2. 注意力机制算法原理讲解

### 2.1 注意力机制的数学模型

#### 2.1.1 公式

注意力机制的数学模型可以表示为：

$$
\alpha_{ij} = \frac{e^{Q_{k}K_{ij}}}{\sum_{j=1}^{J}e^{Q_{k}K_{ij}}}
$$

其中，$Q_{k}$和$K_{ij}$分别是查询向量和关键向量，$J$表示序列长度，$\alpha_{ij}$表示第$i$个输入和第$j$个输出之间的注意力权重。

#### 2.1.2 源代码实现

```python
# Python 代码示例
def attention(Q, K, V, mask=None):
    """
    注意力函数实现
    Q: 查询向量，形状为[batch_size, hidden_size]
    K: 关键向量，形状为[batch_size, hidden_size, sequence_length]
    V: 值向量，形状为[batch_size, hidden_size, sequence_length]
    mask: 掩码，形状为[batch_size, sequence_length]，用于屏蔽特定位置的输入
    """
    # 计算注意力分数
    scores = Q @ K.transpose(-2, -1)
    
    # 应用掩码
    if mask is not None:
        scores += mask * -1e9

    # 计算softmax概率
    probabilities = torch.softmax(scores, dim=-1)

    # 加权求和
    output = probabilities @ V

    return output, probabilities
```

### 5.2 系统核心实现源代码

以下是法律文书分析系统的核心实现源代码：

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
from torch.utils.tensorboard import SummaryWriter

# 定义神经网络模型
class LegalDocumentAnalysisModel(nn.Module):
    def __init__(self):
        super(LegalDocumentAnalysisModel, self).__init__()
        self.embedding = nn.Embedding(10000, 32)
        self.lstm = nn.LSTM(32, 64)
        self.fc = nn.Linear(64, 10)

    def forward(self, x):
        x = self.embedding(x)
        x, _ = self.lstm(x)
        x = self.fc(x[-1, :, :])
        return x

# 初始化模型、优化器和损失函数
model = LegalDocumentAnalysisModel()
optimizer = optim.Adam(model.parameters(), lr=0.001)
criterion = nn.CrossEntropyLoss()

# 加载训练数据集
train_data = datasets.MNIST(root='./data', train=True, transform=transforms.ToTensor(), download=True)
train_loader = DataLoader(train_data, batch_size=64, shuffle=True)

# 训练模型
writer = SummaryWriter('logs')
for epoch in range(10):
    for i, (x, y) in enumerate(train_loader):
        optimizer.zero_grad()
        output = model(x)
        loss = criterion(output, y)
        loss.backward()
        optimizer.step()
        writer.add_scalar('train/loss', loss, epoch * len(train_loader) + i)
writer.close()

# 测试模型
test_data = datasets.MNIST(root='./data', train=False, transform=transforms.ToTensor())
test_loader = DataLoader(test_data, batch_size=64, shuffle=False)
with torch.no_grad():
    for x, y in test_loader:
        output = model(x)
        pred = torch.argmax(output, dim=1)
        correct = (pred == y).sum().item()
        print(f'Accuracy: {correct / len(test_loader)}')
```
