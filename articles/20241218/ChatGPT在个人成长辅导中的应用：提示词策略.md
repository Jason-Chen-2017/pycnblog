**使用Mermaid语法绘制ER图**：

在Markdown文件中，可以使用Mermaid语法来绘制实体关系图（ER Diagram）。以下是一个简单的例子：

```mermaid
erDiagram
    Person ||--|{ Goal : has
    Goal ||--|{ Action : includes
    Action ||--|{ Feedback : leads_to
    Feedback ||--|{ Adjustment : results_in
```

这个ER图表示了个人、目标、行动、反馈和调整之间的关系。`||--|{ ... }`用于定义实体和关系的属性。
