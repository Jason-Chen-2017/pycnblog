### 附录A：罗素类型论的关键术语表

- **类型（Type）**：对象所属的类别，用来区分不同种类的对象。
- **个体（Individual）**：具体的对象，如原子和集合。
- **原子（Atom）**：不可再分的个体，通常是基本的数学对象。
- **集合（Set）**：由个体组成的对象集合，可以再分。
- **类型区分（Type Distinction）**：通过区分不同类型的对象，避免自引用导致的悖论。
- **类型系统（Type System）**：定义类型规则和对象分类的系统。

$$

```python
def is_even(n):
    return n % 2 == 0

def square(n):
    return n * n

def prove_even_square(n):
    if is_even(n):
        return square(n) % 2 == 0
    else:
        return False
```

在这个示例中，我们定义了三个函数：`is_even` 检查一个数是否为偶数，`square` 计算一个数的平方，`prove_even_square` 证明如果一个数是偶数，则它的平方也是偶数。
