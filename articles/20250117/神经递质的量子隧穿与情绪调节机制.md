**Python源代码：**

```python
import numpy as np

def quantum_tunneling(energy, barrier):
    """
    量子隧穿计算
    :param energy: 粒子能量
    :param barrier: 能量屏障
    :return: 量子隧穿概率
    """
    return np.exp(-2 * barrier / energy)

energy = 1.0
barrier = 2.0
print("量子隧穿概率：", quantum_tunneling(energy, barrier))
```
