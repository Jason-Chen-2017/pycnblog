import numpy as np

# 定义激活函数
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 前向传播
def forward_pass(x, weights, bias):
    z = np.dot(x, weights) + bias
    return sigmoid(z)

# 反向传播
def backward_pass(output, expected_output):
    error = output - expected_output
    return error

# 训练模型
def train_model(x, y, weights, bias, learning_rate):
    for epoch in range(num_epochs):
        output = forward_pass(x, weights, bias)
        error = backward_pass(output, y)
        
        # 更新权重和偏置
        weights -= learning_rate * np.dot(x.T, error)
        bias -= learning_rate * error
        
        # 打印训练进度
        if epoch % 100 == 0:
            print(f"Epoch {epoch}: Error = {error}")

# 测试模型
def test_model(x, y, weights, bias):
    output = forward_pass(x, weights, bias)
    print(f"Predicted output: {output}")
    print(f"Expected output: {y}")

z &= \sum_{i=1}^{n} w_i \cdot x_i + b \\
a &= \frac{1}{1 + e^{-z}}
\end{align*}
$$

其中，\(x_i\) 表示输入特征，\(w_i\) 表示权重，\(b\) 表示偏置，\(z\) 表示网络输出，\(a\) 表示激活值。

通过训练，神经网络可以学习到输入特征和输出特征之间的映射关系，从而实现节点关系的推理和预测。

#### 2.5 举例说明

**模型参数**：

- 权重矩阵：\[w = \begin{bmatrix} 0.5 & 0.3 \\ 0.2 & 0.4 \\ 0.1 & 0.6 \end{bmatrix}\]
- 偏置向量：\[b = \begin{bmatrix} 0.1 \\ 0.2 \end{bmatrix}\]

**前向传播**：

$$
z = \begin{bmatrix} 0.5 & 0.3 \\ 0.2 & 0.4 \\ 0.1 & 0.6 \end{bmatrix} \begin{bmatrix} 1 \\ 0 \end{bmatrix} + \begin{bmatrix} 0.1 \\ 0.2 \end{bmatrix} = \begin{bmatrix} 0.6 \\ 0.7 \\ 0.8 \end{bmatrix}
$$

$$
a = \frac{1}{1 + e^{-z}} = \begin{bmatrix} 0.528 \\ 0.540 \\ 0.548 \end{bmatrix}
$$

根据激活函数的输出，我们可以判断节点A和节点B之间存在一定的关系。

**模型训练**：

### 第3章 神经关系推理算法的优化策略

神经关系推理算法在复杂网络分析中的应用需要高效的性能和准确性，因此优化策略至关重要。本章节将介绍几种常见的优化策略，包括模型结构优化、训练过程优化和推理过程优化。

#### 3.1 模型结构优化

模型结构优化是指通过改进神经网络的架构来提高其性能。以下是一些常见的模型结构优化策略：

1. **深度和宽度的平衡**：深度增加可以提高模型的表示能力，但也会导致过拟合和计算复杂度增加。宽度增加可以提高模型的并行计算能力，但也会导致参数数量增加。因此，需要在深度和宽度之间找到平衡点。

2. **注意力机制**：注意力机制可以通过聚焦于重要的节点和关系来提高模型的性能。例如，图注意力网络（GAT）通过学习节点和边之间的注意力权重来提高节点关系推理的准确性。

3. **多层感知器（MLP）与卷积神经网络（CNN）的结合**：MLP可以捕捉非线性关系，而CNN擅长处理网格结构的数据。将两者结合可以充分利用各自的优势。

4. **残差网络（ResNet）**：残差网络通过引入残差连接来避免梯度消失和梯度爆炸问题，从而提高模型的训练效率。

#### 3.2 训练过程优化

训练过程的优化旨在提高模型的训练速度和收敛速度，同时避免过拟合。以下是一些常见的训练过程优化策略：

1. **数据增强**：通过增加训练数据集的多样性来提高模型的泛化能力。例如，对于图像数据，可以采用旋转、翻转、裁剪等方法进行数据增强。

2. **批量归一化（Batch Normalization）**：批量归一化通过将每个批量中的激活值缩放和移位到标准正态分布，从而加速训练过程并提高模型的稳定性。

3. **学习率调度**：学习率调度是一种动态调整学习率的方法，以加速模型的收敛。例如，可以使用周期性调整学习率（如余弦退火法）或使用自适应学习率算法（如Adam）。

4. **正则化**：正则化技术（如L1、L2正则化）可以通过惩罚模型的复杂度来防止过拟合，从而提高模型的泛化能力。

5. **交叉验证**：交叉验证是一种评估模型性能的方法，通过将数据集划分为多个子集，训练模型并在每个子集上进行评估，从而提高模型的可靠性和泛化能力。

#### 3.3 推理过程优化

推理过程的优化旨在提高模型的推理速度和准确性。以下是一些常见的推理过程优化策略：

1. **模型压缩**：模型压缩技术（如模型剪枝、量化、知识蒸馏）可以通过减少模型参数和计算量来提高推理速度。例如，通过剪枝可以去除不重要的参数，从而减少模型的复杂度。

2. **并行计算**：通过利用多核CPU、GPU或其他并行计算资源，可以提高模型的推理速度。例如，可以使用GPU进行矩阵运算和向量计算，从而加速模型的推理过程。

3. **缓存优化**：通过优化数据缓存策略，可以减少数据读取和传输的时间，从而提高模型的推理速度。例如，可以使用缓存来存储常用的中间结果，以避免重复计算。

4. **分布式推理**：在处理大规模数据时，可以使用分布式推理策略，将数据集划分为多个部分，同时在多个节点上进行并行推理，从而提高整体的推理速度。

5. **模型量化**：模型量化是一种将高精度模型转换为低精度模型的方法，从而减少模型的计算量和存储空间。例如，将32位浮点数转换为8位整数，可以显著减少模型的存储和计算需求。

   - 学习率调度：使用余弦退火法来动态调整学习率。
