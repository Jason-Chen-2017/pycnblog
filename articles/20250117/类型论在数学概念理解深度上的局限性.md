2. **类型规则（Type Rules）**：类型规则是类型系统的一部分，用于定义不同类型之间的转换关系和运算规则。类型规则确保了数学表达式和程序的类型一致性，防止类型错误的发生。

5. **类型等价（Type Equivalence）**：类型等价是指两个表达式在类型上等价，即它们具有相同的类型。类型等价是类型论中的一个重要概念，它可以帮助简化数学表达式的推导和验证。

6. **类型依赖（Type Dependency）**：类型依赖是指不同类型之间的依赖关系。类型依赖可以用于描述复杂的数学概念和编程语言特性，如函数类型、协变和逆变等。

7. **类型系统设计（Type System Design）**：类型系统设计是指设计不同类型的类型系统，以满足特定的数学和编程需求。类型系统设计需要考虑类型系统的复杂性、可扩展性、性能和安全性等因素。

#### 1. 类型检查算法的基本概念

类型检查算法是确保数学表达式和程序在执行过程中遵循类型规则的机制。它的主要任务是自动检查程序中的类型错误，并在编译或运行时报告错误。类型检查算法通常包括以下几个基本概念：

1. **类型上下文（Type Context）**：类型上下文是存储类型信息的结构，用于在类型检查过程中引用和更新类型信息。类型上下文通常包括变量类型、函数类型和类型别名等。

2. **类型推导（Type Inference）**：类型推导是指通过一系列推理规则自动推导变量类型的过程。类型推导可以根据程序中的表达式和类型上下文，推断出表达式的类型。

3. **类型检查（Type Checking）**：类型检查是指检查数学表达式和程序是否满足类型规则的机制。类型检查通过比较实际类型和预期类型，确保程序在执行过程中不会发生类型错误。

4. **类型错误（Type Error）**：类型错误是指违反类型规则的错误。类型错误通常会导致程序崩溃或产生不可预期的结果。

```python
        return self.types.get(var_name)

def infer_type(expression, context):
    if isinstance(expression, str):
        return 'string'
    elif isinstance(expression, int):
        return 'int'
    elif isinstance(expression, float):
        return 'float'
    elif isinstance(expression, bool):
        return 'bool'
    else:
        return None

def check_expression(expression, context):
    inferred_type = infer_type(expression, context)
    if inferred_type is None:
        print("类型错误：无法推导表达式类型")
    else:
        expected_type = context.get_type(expression)
        if expected_type != inferred_type:
            print("类型错误：表达式类型不匹配")
        else:
            print("表达式类型检查通过")

context.declare_type('y', 'float')

expression2 = "hello"

check_expression(expression2, context)
check_expression(expression3, context)
```
