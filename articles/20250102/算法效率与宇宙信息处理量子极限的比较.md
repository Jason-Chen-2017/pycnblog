## 算法效率分析

### 算法效率基本概念

算法效率的基本概念包括时间复杂度和空间复杂度。时间复杂度通常用大O符号表示，如O(n)、O(n^2)、O(log n)等，表示算法运行时间与输入数据规模的关系。空间复杂度同样用大O符号表示，如O(1)、O(n)、O(n^2)等，表示算法运行所需的空间与输入数据规模的关系。

#### 时间复杂度

时间复杂度是衡量算法运行时间的一个重要指标。一个算法的时间复杂度取决于其基本操作（如比较、赋值、递归等）的执行次数，以及输入数据规模n的关系。

常见的算法时间复杂度包括：

- O(1)：算法运行时间与输入数据规模无关，即常数时间。
- O(n)：算法运行时间与输入数据规模成正比，即线性时间。
- O(n^2)：算法运行时间与输入数据规模的平方成正比，即二次时间。
- O(log n)：算法运行时间与输入数据规模的以2为底的对数成正比，即对数时间。

例如，线性搜索算法的时间复杂度为O(n)，而二分搜索算法的时间复杂度为O(log n)。

#### 空间复杂度

空间复杂度是衡量算法运行所需空间的一个重要指标。一个算法的空间复杂度取决于其存储数据的结构（如数组、链表、树等）和输入数据规模n的关系。

常见的算法空间复杂度包括：

- O(1)：算法运行所需空间与输入数据规模无关，即常数空间。
- O(n)：算法运行所需空间与输入数据规模成正比，即线性空间。
- O(n^2)：算法运行所需空间与输入数据规模的平方成正比，即二次空间。

例如，一个简单的数组存储算法的空间复杂度为O(n)，而一个完整的图存储算法的空间复杂度可能为O(n^2)。

#### 线性搜索

线性搜索是一种简单的查找算法，其基本思想是从数组的第一个元素开始，逐个比较，直到找到目标元素或到达数组末尾。线性搜索的时间复杂度为O(n)，因为最坏情况下需要比较n次。

```python
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1
```

#### 二分搜索

二分搜索是一种更高效的查找算法，其基本思想是不断将搜索范围分成两半，然后选择中间的元素进行比较。最坏情况下，二分搜索只需要比较log n次。因此，二分搜索的时间复杂度为O(log n)。

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

#### 冒泡排序

冒泡排序是一种简单的排序算法，其基本思想是通过多次遍历数组，比较相邻元素，并交换它们的顺序，直到整个数组有序。冒泡排序的时间复杂度为O(n^2)，因为最坏情况下需要比较n(n-1)/2次。

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
```

#### 快速排序

快速排序是一种高效的排序算法，其基本思想是通过递归地将数组划分为较小的子数组，并对其排序。快速排序的平均时间复杂度为O(n log n)，最坏情况下的时间复杂度为O(n^2)。

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```
