集合的基本操作包括并集、交集和差集。以下是一些集合论的基本概念：

- 并集（Union）：两个集合 $A$ 和 $B$ 的并集是包含所有属于 $A$ 或属于 $B$ 的元素的集合。用符号表示为 $A \cup B$。
- 交集（Intersection）：两个集合 $A$ 和 $B$ 的交集是同时属于 $A$ 和 $B$ 的元素的集合。用符号表示为 $A \cap B$。

以下是一个简单的选民分布模型，使用正态分布来描述选民的投票行为：

$$
P(X = x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

其中，$X$ 表示选民的投票行为，$\mu$ 表示均值，$\sigma$ 表示标准差。

以下是一个使用Python实现选民分布模型的示例：

```python

def normal_distribution(x, mu, sigma):
    return (1 / (np.sqrt(2 * np.pi * sigma**2))) * np.exp(-((x - mu)**2) / (2 * sigma**2))

x = np.linspace(-5, 5, 1000)
mu = 0
sigma = 1

plt.plot(x, normal_distribution(x, mu, sigma))
plt.xlabel('Vote')
plt.ylabel('Probability')
plt.title('Normal Distribution of Voter Behavior')
plt.show()
```
