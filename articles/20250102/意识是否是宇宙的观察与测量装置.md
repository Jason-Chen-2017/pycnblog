```python
import numpy as np
import matplotlib.pyplot as plt
from astropy.io import fits
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans

# 数据采集
def collect_data():
    print("Collecting astronomical data.")
    # 假设从一个 FITS 文件中读取数据
    with fits.open('example.fits') as hdul:
        data = hdul[0].data
    return data

# 预处理
def preprocess_data(data):
    print("Preprocessing the collected data.")
    # 数据预处理，如去除噪声、填充缺失值等
    # 这里使用简单的均值填充
    data = np.ma.array(data, mask=np.isnan(data))
    data = data.filled(np.mean(data))
    return data

# 特征提取
def extract_features(data):
    print("Extracting relevant features from the preprocessed data.")
    # 使用主成分分析提取主要特征
    pca = PCA(n_components=2)
    features = pca.fit_transform(data)
    return features

# 数据分析
def analyze_data(features):
    print("Analyzing the extracted features.")
    # 使用 K-Means 算法进行聚类分析
    kmeans = KMeans(n_clusters=3, random_state=42)
    kmeans.fit(features)
    labels = kmeans.predict(features)
    return labels

# 结果输出
def output_results(labels):
    print("Outputting the analysis results.")
    # 绘制聚类结果
    plt.scatter(features[:, 0], features[:, 1], c=labels)
    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.title('Cluster Analysis Results')
    plt.show()

# 主函数
def main():
    data = collect_data()
    data_processed = preprocess_data(data)
    features = extract_features(data_processed)
    labels = analyze_data(features)
    output_results(labels)

if __name__ == "__main__":
    main()
```

这段代码首先从FITS文件中采集天文数据，然后进行预处理。预处理后的数据通过主成分分析提取主要特征，接着使用K-Means聚类算法进行分析，并将结果可视化。

### 2.2.3 数学模型与公式

在宇宙观测算法中，我们使用了一些数学模型和公式来描述不同步骤的操作。以下是几个关键步骤的数学模型：

1. **预处理数据（均值填充）**：

   $$ x_{\text{filled}} = \text{mean}(x \text{[~mask~]}) $$

   其中，$x$ 是原始数据，$\text{mask}$ 是缺失值的掩码，$\text{mean}(x \text{[~mask~]})$ 是填充后的数据。

2. **特征提取（主成分分析PCA）**：

   $$ Z = PC $$

   其中，$Z$ 是主成分，$P$ 是特征值矩阵，$C$ 是协方差矩阵。

3. **数据分析（K-Means聚类）**：

   $$ \hat{c}_k = \frac{1}{n_k} \sum_{i=1}^{n_k} (x_i - \bar{x}_k) $$

   其中，$\hat{c}_k$ 是聚类中心，$n_k$ 是第$k$个聚类中的样本数量，$x_i$ 是第$i$个样本，$\bar{x}_k$ 是第$k$个聚类中心。

这些数学模型和公式帮助我们在算法中实现数据预处理、特征提取和数据分析等步骤。

### 3.2.2 系统核心实现源代码

下面是宇宙观测系统的核心实现源代码，包括数据收集、预处理、特征提取和模型训练等步骤。

```python
import numpy as np
import matplotlib.pyplot as plt
from astropy.io import fits
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans

# 数据收集
def collect_data(file_path):
    with fits.open(file_path) as hdul:
        data = hdul[0].data
    return data

# 数据预处理
def preprocess_data(data):
    # 填充缺失值
    data = np.ma.array(data, mask=np.isnan(data))
    data = data.filled(np.mean(data))
    # 归一化
    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data)
    return data_scaled

# 特征提取
def extract_features(data):
    pca = PCA(n_components=2)
    features = pca.fit_transform(data)
    return features

# 模型训练
def train_model(features):
    kmeans = KMeans(n_clusters=3, random_state=42)
    kmeans.fit(features)
    return kmeans

# 结果输出
def output_results(model, features):
    labels = model.predict(features)
    plt.scatter(features[:, 0], features[:, 1], c=labels)
    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.title('Cluster Analysis Results')
    plt.show()

# 主函数
def main():
    file_path = 'example.fits'
    data = collect_data(file_path)
    data_processed = preprocess_data(data)
    features = extract_features(data_processed)
    model = train_model(features)
    output_results(model, features)

if __name__ == "__main__":
    main()
```

这段代码首先从FITS文件中读取数据，然后进行预处理和特征提取。特征提取后，使用K-Means聚类算法训练模型，并输出聚类结果。

数据收集函数`collect_data`从FITS文件中读取数据。FITS（Flexible Image Transport System）是一种用于存储天文图像和光谱数据的标准化格式。`fits.open`函数用于打开FITS文件，`data`属性则用于获取数据数组。

#### 数据预处理

数据预处理函数`preprocess_data`首先创建一个掩码数组，用于标识缺失值。然后使用`filled`方法将这些缺失值填充为均值。接下来，使用`StandardScaler`对数据进行归一化处理，使其均值为0，标准差为1。

```python
data = np.ma.array(data, mask=np.isnan(data))

特征提取函数`extract_features`使用主成分分析（PCA）将预处理后的数据降维到2个主要特征。这有助于简化数据的结构，并保留大部分信息。

```

#### 模型训练

模型训练函数`train_model`使用K-Means聚类算法对特征进行聚类。这里选择3个聚类中心，但实际应用中可以根据数据特点进行调整。
