#### 4.1.2 详细讲解

这个公式表示蛋白质折叠的总能量是由所有氨基酸之间的相互作用能量之和组成的。每个氨基酸与相邻氨基酸之间的相互作用能量都会影响蛋白质的整体结构。

#### 4.1.3 举例说明

假设有一个蛋白质序列为 "ACGTACGT"，我们可以计算其总能量。首先，我们需要定义每个氨基酸之间的相互作用能量，例如，氨基酸 "A" 与 "C" 之间的相互作用能量为 -1，与 "G" 之间的相互作用能量为 1。然后，我们可以计算总能量：

$$
E = (A\_C + A\_G + C\_A + C\_G + G\_A + G\_C + T\_A + T\_G) = (-1 + 1 + -1 + 1 + 1 + -1 + -1 + 1) = 0
$$

这意味着在这个蛋白质序列中，所有氨基酸之间的相互作用能量相互抵消，蛋白质处于稳定状态。
