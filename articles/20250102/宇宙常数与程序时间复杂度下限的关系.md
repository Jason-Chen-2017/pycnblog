### 万有引力常数（G）

万有引力常数是描述物质间引力作用的物理量，它的值约为 \(6.674 \times 10^{-11} \, \text{Nm}^2/\text{kg}^2\)。这个常数决定了两个质点之间的引力大小，其公式为：

\[ F = G \frac{m_1 m_2}{r^2} \]

其中，\( F \) 是引力大小，\( m_1 \) 和 \( m_2 \) 是两个质点的质量，\( r \) 是它们之间的距离。

万有引力常数在宇宙尺度上起着至关重要的作用。它不仅决定了行星、恒星和星系之间的引力相互作用，还影响了宇宙的大尺度结构，如银河系的旋臂形状和宇宙微波背景辐射的分布。

### 光速（c）

光速是光在真空中传播的速度，其值约为 \(3 \times 10^8 \, \text{m/s}\)。光速是一个非常重要的宇宙常数，它不仅决定了电磁波的传播速度，还与时间、长度等基本物理量的关系密切相关。

光速的恒定性是相对论的基础之一。爱因斯坦的狭义相对论指出，光速是宇宙中最快的速度，无论观察者的运动状态如何，光速都是不变的。这一原理打破了经典物理学的速度叠加原理，揭示了时空的相对性。

### 程序时间复杂度的基本概念

程序时间复杂度是计算机科学中用来衡量算法效率的重要指标。一个算法的时间复杂度表示随着输入数据规模的增长，算法所需计算时间的变化趋势。时间复杂度通常用大O符号（\(O(\cdot)\)）来表示。

#### 线性时间复杂度（\(O(n)\)）

线性时间复杂度是最常见的时间复杂度类型之一。它表示算法的时间消耗与输入数据规模成线性关系。公式如下：

\[ T(n) = O(n) \]

例如，一个简单的线性查找算法，其时间复杂度为 \(O(n)\)。

#### 对数时间复杂度（\(O(\log n)\)）

对数时间复杂度表示算法的时间消耗与输入数据规模的以2为底的对数成线性关系。公式如下：

\[ T(n) = O(\log n) \]

例如，二分查找算法的时间复杂度为 \(O(\log n)\)。

#### 多项式时间复杂度（\(O(n^k)\, k > 1\)）

多项式时间复杂度表示算法的时间消耗与输入数据规模的某个多项式关系。常见的多项式时间复杂度包括 \(O(n^2)\) 和 \(O(n^3)\)。

\[ T(n) = O(n^2) \]
\[ T(n) = O(n^3) \]

例如，二项式查找算法的时间复杂度为 \(O(n^2)\)。

#### 非线性时间复杂度

除了上述常见的时间复杂度类型，还有一些非线性时间复杂度，如指数时间复杂度（\(O(2^n)\)）和平方根时间复杂度（\(O(n^{1.5})\)）。

\[ T(n) = O(2^n) \]
\[ T(n) = O(n^{1.5}) \]

指数时间复杂度通常表示算法在处理大规模数据时效率极低，而平方根时间复杂度则表示算法的效率比线性时间复杂度略好，但仍然无法处理非常大规模的数据。

#### 时间复杂度下限

时间复杂度下限是指一个算法所需的最少计算时间，即使该算法的实现方式最优。时间复杂度下限的研究有助于我们了解算法性能的理论极限。

#### 线性查找

线性查找是最简单的查找算法之一。它遍历输入数组，直到找到目标元素或到达数组末尾。线性查找的时间复杂度为 \(O(n)\)。

```python
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1
```

#### 二分查找

二分查找是一种高效的查找算法，它通过不断缩小查找范围来提高效率。二分查找的时间复杂度为 \(O(\log n)\)。

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

#### 冒泡排序

冒泡排序是一种简单的排序算法，它通过多次遍历数组，比较相邻元素并交换它们，直到整个数组有序。冒泡排序的时间复杂度为 \(O(n^2)\)。

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
```

#### 快速排序

快速排序是一种高效的排序算法，它通过递归地将数组划分为较小和较大的子数组，然后对子数组进行排序。快速排序的时间复杂度平均为 \(O(n\log n)\)，最坏情况下为 \(O(n^2)\)。

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```
