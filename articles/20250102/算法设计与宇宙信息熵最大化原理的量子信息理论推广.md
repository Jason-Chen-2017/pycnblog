### 4.2 系统核心实现源代码

以下是系统核心实现的源代码：

```python
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister
from qiskit.visualization import plot_bloch_multivector
from qiskit.quantum_info import state_from_tensor

# 初始化量子设备和量子寄存器
q = QuantumRegister(2)
c = ClassicalRegister(2)
qc = QuantumCircuit(q, c)

# 量子态生成
qc.h(q[0])
qc.cx(q[0], q[1])

# 量子态测量
qc.measure(q, c)

# 运行量子电路
qc.run().result().get_counts()

# 绘制量子态
state_vector = qc.initialize()
state = state_from_tensor(state_vector)
plot_bloch_multivector(state)
```
