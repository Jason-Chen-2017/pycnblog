##### 3.1 微分方程模型

微分方程模型是描述暗物质湮灭现象的常用方法。以下是一个简单的微分方程模型：

$$
\frac{d n_{\chi}}{d t} + \frac{d n_{\bar{\chi}}}{d t} = - \frac{n_{\chi} n_{\bar{\chi}}}{m_{\chi}}
$$

其中，$n_{\chi}$和$n_{\bar{\chi}}$分别表示暗物质粒子和反暗物质粒子的密度，$m_{\chi}$是暗物质粒子的质量。

这个模型假设暗物质和反暗物质粒子在空间中均匀分布，并遵循简单的碰撞过程。通过数值求解这个微分方程，可以预测暗物质湮灭的过程和结果。

##### 3.2 代数模型

代数模型是另一种常用的数学模型，用于描述暗物质湮灭过程中的粒子分布和能量转移。以下是一个简单的代数模型：

$$
\frac{d n_{\chi}}{d t} = - \frac{n_{\chi} n_{\bar{\chi}}}{m_{\chi}}
$$

$$
\frac{d n_{e^-}}{d t} = \frac{n_{\chi} n_{\bar{\chi}}}{m_{\chi}} - \frac{n_{e^-} n_{Z^0}}{m_{e^-}}
$$

其中，$n_{e^-}$和$n_{Z^0}$分别表示电子和中性弱玻色子的密度。

这个模型考虑了湮灭过程中电子和中性弱玻色子的生成和传播。通过求解这个代数模型，可以分析湮灭产生的粒子分布和能量转移。

### 第5章：数学模型求解

##### 5.1 数值方法

求解数学模型是预测暗物质湮灭结果的关键步骤。常用的数值方法包括Euler方法和Runge-Kutta方法。

1. **Euler方法**：Euler方法是一种简单的数值方法，用于求解常微分方程。其基本思想是使用前一点的值来预测下一点的值。以下是一个简单的Euler方法步骤：

   $$ 
   n_{i+1} = n_i + \Delta t f(n_i, t_i) 
   $$

   其中，$n_i$和$n_{i+1}$分别表示第$i$点和第$i+1$点的密度，$\Delta t$是时间步长，$f(n_i, t_i)$是微分方程的右侧。

2. **Runge-Kutta方法**：Runge-Kutta方法是一种更精确的数值方法，用于求解常微分方程。其基本思想是使用前几个点的值来预测下一点的值。以下是一个简单的Runge-Kutta方法步骤：

   $$
   k_1 = f(n_i, t_i)
   $$

   $$
   k_2 = f(n_i + \frac{\Delta t}{2} k_1, t_i + \frac{\Delta t}{2})
   $$

   $$
   k_3 = f(n_i + \frac{\Delta t}{2} k_2, t_i + \frac{\Delta t}{2})
   $$

   $$
   k_4 = f(n_i + \Delta t k_3, t_i + \Delta t)
   $$

   $$
   n_{i+1} = n_i + \frac{\Delta t}{6} (k_1 + 2k_2 + 2k_3 + k_4)
   $$

   通过这个方法，我们可以更精确地预测密度随时间的变化。

##### 5.2 数学模型求解实例

为了展示如何使用数值方法求解暗物质湮灭模型，我们考虑一个简单的例子。假设暗物质粒子的质量为1 GeV，反暗物质粒子的质量为2 GeV，湮灭率为$10^{-9}$ s$^{-1}$。

我们使用Euler方法来求解这个模型。设时间步长为0.1 s，初始条件为$n_{\chi}(0) = n_{\bar{\chi}}(0) = 10^6$ cm$^{-3}$。

以下是一个简单的Euler方法代码示例（使用Python编写）：

```python
import numpy as np

m_chi = 1e-9 # GeV
m_bar_chi = 2e-9 # GeV
annihilation_rate = 1e-9 # s^-1
time_step = 0.1 # s
time_end = 1000 # s
time_points = np.arange(0, time_end, time_step)

n_chi = np.zeros_like(time_points)
n_bar_chi = np.zeros_like(time_points)
n_chi[0] = n_bar_chi[0] = 1e6 # cm^-3

for i in range(1, len(time_points)):
    dndt_chi = -annihilation_rate * n_chi[i-1] * n_bar_chi[i-1]
    dndt_bar_chi = -annihilation_rate * n_chi[i-1] * n_bar_chi[i-1]
    n_chi[i] = n_chi[i-1] + dndt_chi * time_step
    n_bar_chi[i] = n_bar_chi[i-1] + dndt_bar_chi * time_step

import matplotlib.pyplot as plt

plt.plot(time_points, n_chi, label='Dark Matter')
plt.plot(time_points, n_bar_chi, label='Antidark Matter')
plt.xlabel('Time (s)')
plt.ylabel('Density (cm^-3)')
plt.legend()
plt.show()
```

        return True

# 模型构建模块
class ModelBuilder:
    def __init__(self, data_input):
        self.data_input = data_input

    def build_model(self):
        # 构建数学模型
        n_chi = self.data_input.n_chi_0
        n_bar_chi = self.data_input.n_bar_chi_0
        m_chi = self.data_input.m_chi
        m_bar_chi = self.data_input.m_bar_chi
        annihilation_rate = self.data_input.annihilation_rate
        dt = self.data_input.dt

        def model(t, y):
            n_chi, n_bar_chi = y
            dndt_chi = -annihilation_rate * n_chi * n_bar_chi
            dndt_bar_chi = -annihilation_rate * n_chi * n_bar_chi
            return [dndt_chi, dndt_bar_chi]

        return model

        self.model = model

        rmse = np.sqrt(np.mean((n_chi - n_bar_chi)**2))

        ss_res = np.sum((n_chi - n_bar_chi)**2)
