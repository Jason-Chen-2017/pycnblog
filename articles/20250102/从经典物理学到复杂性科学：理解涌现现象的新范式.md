## 数学模型和数学公式讲解

### 4.1 数学模型与公式

复杂性科学中的数学模型包括：

- **线性回归模型**：$$ y = \beta_0 + \beta_1 x $$
- **逻辑回归模型**：$$ P(y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}} $$
- **神经网络模型**：$$ a_{i,j} = \sum_{k=1}^{n} w_{ik} x_k + b_j $$

### 4.2 详细讲解

- **线性回归模型**：用于分析自变量和因变量之间的线性关系。
- **逻辑回归模型**：用于分析因变量的概率分布。
- **神经网络模型**：用于模拟复杂的非线性关系。

### 4.3 举例说明

以下是一个简单的线性回归模型实例：

```python
import numpy as np

# 生成数据
X = np.random.rand(100, 1)
y = 2 * X + 1 + np.random.randn(100, 1)

# 拟合线性回归模型
theta = np.linalg.inv(X.T.dot(X)).dot(X.T).dot(y)

# 输出模型参数
print("theta:", theta)
```
