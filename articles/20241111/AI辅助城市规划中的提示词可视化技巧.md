### 第3章 提示词生成技术

提示词生成技术是AI辅助城市规划中的一个关键环节。它通过从大量城市规划数据中提取关键信息，为城市规划师提供有用的参考和决策支持。本节将介绍提示词生成的基本概念和不同类型的提示词生成方法。

#### 3.1 提示词生成的基本概念

**提示词（Keywords）**：提示词是描述城市规划数据的关键信息，如街道名称、交通流量、人口密度等。它们通常是文本形式的，但在某些情况下也可以是图像或音频等非文本形式。

**提示词生成（Keyword Generation）**：提示词生成是指从大量城市规划数据中自动提取关键信息，生成一组与数据相关的提示词。这一过程通常涉及数据预处理、特征提取和模型训练等步骤。

**目的**：提示词生成的目的是辅助城市规划师更好地理解和分析城市规划数据，从而提高规划效率和准确性。

#### 3.2 基于文本的提示词生成

基于文本的提示词生成是最常见的提示词生成方法。它通过分析文本数据，提取出与数据相关的关键词。

**方法**：

1. **关键词提取（Keyword Extraction）**：从文本数据中提取出一组关键词。常见的方法包括：
   - **基于统计的方法**：如TF-IDF（词频-逆文档频率）和LSA（ latent semantic analysis）等。
   - **基于规则的方法**：如正则表达式和词性标注等。
   - **基于机器学习的方法**：如朴素贝叶斯、支持向量机等。

2. **实体识别（Entity Recognition）**：识别文本中的实体，如人名、地名、组织名等。常见的方法包括：
   - **基于规则的方法**：如命名实体识别（NER）系统。
   - **基于统计的方法**：如条件随机场（CRF）等。
   - **基于机器学习的方法**：如长短期记忆网络（LSTM）等。

**应用**：基于文本的提示词生成可以应用于城市规划中的文本数据分析，如交通报告、环境监测报告等。通过提取关键信息，城市规划师可以快速了解报告的主要内容，并做出相应的决策。

#### 3.3 基于图像的提示词生成

基于图像的提示词生成是通过分析图像数据，提取出与图像相关的关键词。

**方法**：

1. **图像特征提取**：从图像中提取出特征，如边缘、纹理、颜色等。常见的方法包括：
   - **基于传统图像处理的方法**：如SIFT、SURF等。
   - **基于深度学习的方法**：如卷积神经网络（CNN）等。

2. **视觉词汇表生成**：使用提取的图像特征生成视觉词汇表，用于描述图像内容。常见的方法包括：
   - **基于聚类的方法**：如K-means、层次聚类等。
   - **基于深度学习的方法**：如生成对抗网络（GAN）等。

3. **图像文本对应**：将视觉词汇表与文本数据对应，生成提示词。常见的方法包括：
   - **基于匹配的方法**：如字符串匹配、余弦相似度等。
   - **基于机器学习的方法**：如循环神经网络（RNN）等。

**应用**：基于图像的提示词生成可以应用于城市规划中的图像数据分析，如交通监控、环境监测等。通过提取图像中的关键信息，城市规划师可以更好地了解城市规划的现状和问题。

#### 3.4 基于多模态数据的提示词生成

基于多模态数据的提示词生成结合了文本和图像等多种数据类型，通过融合不同类型的数据，生成更丰富的提示词。

**方法**：

1. **数据融合**：将不同类型的数据（如文本、图像、音频等）进行融合，提取出共同的特征。常见的方法包括：
   - **基于特征融合的方法**：如特征加权、特征拼接等。
   - **基于深度学习的方法**：如多模态卷积神经网络（MM-CNN）等。

2. **多模态提示词生成**：使用融合后的数据生成提示词。常见的方法包括：
   - **基于联合模型的方法**：如多任务学习、多标签学习等。
   - **基于对抗网络的方法**：如生成对抗网络（GAN）等。

**应用**：基于多模态数据的提示词生成可以应用于城市规划中的多模态数据分析，如交通监控、环境监测、社区规划等。通过融合多种数据类型，城市规划师可以获得更全面的信息，从而做出更科学的决策。

### 第4章 提示词可视化方法

提示词可视化是将提示词以图形或图像的形式呈现，使其更直观和易于理解。有效的可视化方法可以帮助城市规划师快速识别数据中的关键信息，从而更好地分析和制定规划方案。本节将介绍提示词可视化的基础、不同类型的可视化方法及其在实际应用中的案例。

#### 4.1 可视化基础

**可视化基础**：

- **数据可视化**：数据可视化是指通过图形和图像将数据呈现出来，使数据更容易理解和分析。
- **可视化元素**：包括颜色、形状、大小、位置等，用于表示数据和数据之间的关系。
- **可视化原则**：包括清晰性、一致性、交互性等，以增强可视化的效果。

**可视化工具**：常用的可视化工具有matplotlib、Seaborn、Plotly、Tableau等，这些工具提供了丰富的可视化功能和自定义选项。

#### 4.2 基于二维图形的提示词可视化

**二维图形可视化**：

- **折线图**：用于展示数据的变化趋势，如人口增长、交通流量等。
- **柱状图**：用于比较不同类别的数据，如不同区域的交通拥堵情况。
- **散点图**：用于展示两个变量之间的关系，如人口密度与交通拥堵之间的关系。

**案例**：假设我们有一组城市交通数据，包括每天的早晚高峰交通流量。我们可以使用折线图来展示不同时间段的交通流量变化，使用柱状图来比较不同区域的交通拥堵情况，使用散点图来分析人口密度与交通拥堵之间的关系。

```python
import matplotlib.pyplot as plt

# 假设的交通流量数据
traffic_data = {
    'time': ['早上', '中午', '晚上'],
    'traffic_volume': [500, 300, 800]
}

# 创建折线图
plt.plot(traffic_data['time'], traffic_data['traffic_volume'])
plt.title('每日交通流量变化')
plt.xlabel('时间段')
plt.ylabel('交通流量')
plt.show()

# 创建柱状图
plt.bar(traffic_data['time'], traffic_data['traffic_volume'])
plt.title('不同区域交通拥堵情况')
plt.xlabel('时间段')
plt.ylabel('交通流量')
plt.show()

# 创建散点图
plt.scatter(traffic_data['time'], traffic_data['traffic_volume'])
plt.title('人口密度与交通拥堵关系')
plt.xlabel('时间段')
plt.ylabel('交通流量')
plt.show()
```

#### 4.3 基于三维模型的提示词可视化

**三维模型可视化**：

- **三维散点图**：用于展示三个变量之间的关系，如人口密度、交通流量和污染指数。
- **三维条形图**：用于比较不同类别的数据，如不同区域的交通流量。
- **三维曲面图**：用于展示多变量数据的变化趋势，如地形分析。

**案例**：假设我们有一组包含人口密度、交通流量和污染指数的城市数据。我们可以使用三维散点图来分析这些变量之间的关系，使用三维条形图来比较不同区域的交通流量，使用三维曲面图来展示地形分析结果。

```python
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# 假设的城市数据
city_data = {
    'population_density': [100, 200, 150],
    'traffic_volume': [300, 400, 350],
    'pollution_index': [20, 25, 22]
}

fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')

# 创建三维散点图
ax.scatter(city_data['population_density'], city_data['traffic_volume'], city_data['pollution_index'])
ax.set_xlabel('人口密度')
ax.set_ylabel('交通流量')
ax.set_zlabel('污染指数')
plt.title('城市变量关系分析')
plt.show()

# 创建三维条形图
ax.bar(city_data['population_density'], city_data['traffic_volume'])
ax.set_xlabel('人口密度')
ax.set_ylabel('交通流量')
plt.title('不同区域交通流量比较')
plt.show()

# 创建三维曲面图
x = [100, 200, 300]
y = [100, 200, 300]
z = [10, 20, 30]
ax.plot_surface(x, y, z)
ax.set_xlabel('X Label')
ax.set_ylabel('Y Label')
ax.set_zlabel('Z Label')
plt.title('地形分析')
plt.show()
```

#### 4.4 基于交互的提示词可视化

**交互式可视化**：

- **交互式地图**：如Mapbox、OpenLayers等，用于展示地理位置数据。
- **交互式数据仪表板**：如Tableau、Power BI等，提供综合的可视化和交互功能。

**案例**：使用Plotly创建一个交互式折线图，展示不同时间段的交通流量变化。

```python
import plotly.express as px
```

```javascript
    height = 300;

    .domain(dataset)
    .range(['#98abc5', '#8a89a6', '#7b6888', '#6b486b', '#a05d56', '#d0743c', '#f0e8c2']);

    .value(function(d) { return d; })
    .sort(null);

    .innerRadius(0)
    .outerRadius(radius);

var svg = d3.select("body").append("svg")
    .attr("width", width)
    .attr("height", height)
  .append("g")
    .attr("transform", "translate(" + width / 2 + "," + height / 2 + ")");

var arcPaths = svg.selectAll(".arc")
    .data(pie(dataset))
  .enter().append("g")
    .attr("class", "arc");

arcPaths.append("path")
    .attr("d", arc)
    .style("fill", function(d) { return color(d.data); });

arcPaths.append("text")
    .attr("transform", function(d) { return "translate(" + arc.centroid(d) + ")"; })
    .attr("dy", ".35em")
    .text(function(d) { return d.data; });
```

#### A.2 提示词可视化项目实战代码

以下是提示词可视化的项目实战代码，包括数据收集、数据处理、提示词生成和可视化展示等步骤：

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import linear_kernel

# 数据收集与预处理
data = pd.read_csv('city_planning_data.csv')
data.dropna(inplace=True)

# 提示词生成
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform(data['description'])

# 可视化展示
cosine_sim = linear_kernel(tfidf_matrix, tfidf_matrix)

# 根据相似度排序
sim_scores = list(enumerate(cosine_sim[0]))
sim_scores = sorted(sim_scores, key=lambda x: x[1], reverse=True)
sim_scores = sim_scores[1:11]

# 显示可视化结果
for idx in sim_scores:
    plt.title(f"Top 10 similar descriptions to {data.iloc[idx[0]]['description']}")
    sns.barplot(x=data.iloc[idx[0]]['description'], y=data.iloc[idx[1]]['description'])
    plt.xticks(rotation=45)
    plt.show()
```

#### A.3 提示词可视化数学模型与公式解读

以下是提示词可视化中常用的数学模型与公式解读：

1. **TF-IDF**：
   $$ 
   \text{TF-IDF}(t, d) = \frac{\text{TF}(t, d)}{\text{DF}(t, d)}
   $$
   其中，$TF(t, d)$ 是单词 $t$ 在文档 $d$ 中的词频，$DF(t, d)$ 是单词 $t$ 在文档集合中的文档频率。

2. **余弦相似度**：
   $$
   \text{cosine\_similarity}(v_1, v_2) = \frac{v_1 \cdot v_2}{\|v_1\| \|v_2\|}
   $$
   其中，$v_1$ 和 $v_2$ 是两个向量，$\cdot$ 表示点积，$\|\|$ 表示向量的模长。

3. **K-means聚类**：
   $$
   \text{K-means} \text{ aims to minimize the sum of squared distances between each point and its corresponding centroid.}
   $$
   目标是最小化每个点到其对应质心的平方距离之和。

通过理解这些数学模型和公式，可以更好地设计和优化提示词可视化算法，提高可视化的准确性和可解释性。
