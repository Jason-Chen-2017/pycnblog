### Step 8: Math Models and Formulas

In this section, we'll introduce the mathematical models and formulas used in both large model fine-tuning and prompt engineering.

#### 8.1 Loss Function

The loss function is a critical component in fine-tuning. The most common loss functions are:

$$
\text{Loss} = \frac{1}{N} \sum_{i=1}^{N} (-y_i \log(p_i))
$$

where \(y_i\) is the ground truth label and \(p_i\) is the predicted probability for class \(i\).

#### 8.2 Activation Function

In neural networks, activation functions introduce non-linearity. Common activation functions include:

$$
\text{ReLU}(x) = \begin{cases} 
x & \text{if } x > 0 \\
0 & \text{if } x \leq 0 
\end{cases}
$$

#### 8.3 Regularization Techniques

Regularization techniques like L1 and L2 regularization are used to prevent overfitting:

$$
L1\text{ Regularization} = \lambda \sum_{i} |w_i| \\
L2\text{ Regularization} = \lambda \sum_{i} w_i^2
$$

where \(w_i\) are the model weights and \(\lambda\) is the regularization strength.
