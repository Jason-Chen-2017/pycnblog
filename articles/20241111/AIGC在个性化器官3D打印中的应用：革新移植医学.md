out(x, y) = \frac{1}{c}\sum_{i=1}^{c} \sum_{j=1}^{c} image(i, j) \cdot \delta(x - i, y - j)

```python
    rows, cols = image.shape
    filtered_image = np.zeros_like(image)
    for i in range(rows):
        for j in range(cols):
            window = image[i:i+filter_size, j:j+filter_size]
            filtered_image[i, j] = np.mean(window)
    return filtered_image
```
