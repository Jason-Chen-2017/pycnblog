   class VariableAnalysis(ast.NodeVisitor):
       def visit_Assign(self, node):
           for target in node.targets:
               if isinstance(target, ast.Name):
                   self.visit(target)
                   print(f"Variable {target.id} defined at line {target.lineno}.")

       def visit_Name(self, node):
           if isinstance(node.ctx, ast.Store):
               print(f"Variable {node.id} used at line {node.lineno}.")

       visitor = VariableAnalysis()
       visitor.visit(ast)
   ```

   ast = build_ast(tokens)
   data_flow_analysis(ast)
   ```
