## 第2章: 反向投资的核心概念与数学模型

### 2.1 反向投资的核心概念
#### 2.1.1 市场情绪与投资机会的关系
- 市场情绪与投资机会呈反向关系。
- 在市场恐慌时买入，在市场狂热时卖出。

#### 2.1.2 价值洼地的识别与评估
- 识别市场中价值被低估的行业和企业。
- 通过市盈率、市净率等指标评估企业价值。

#### 2.1.3 投资组合的构建与风险管理
- 构建多元化投资组合。
- 通过分散投资降低风险。
- 定期评估和调整投资组合。

### 2.2 反向投资的数学模型
#### 2.2.1 市盈率与市净率的计算公式
- 市盈率（P/E）= 股价 / 每股收益
- 市净率（P/B）= 股价 / 每股净资产

#### 2.2.2 价值低估的判定模型
- 市盈率低于行业平均水平。
- 市净率低于行业平均水平。
- 企业盈利能力稳定或增长。

#### 2.2.3 投资组合优化的数学方法
- 使用均值-方差模型优化投资组合。
- 利用Markowitz优化理论进行投资组合优化。

### 5.2 系统核心实现源代码
```python
import requests
from bs4 import BeautifulSoup
import pandas as pd

# 数据采集函数
def fetch_data(url):
    response = requests.get(url)
    soup = BeautifulSoup(response.text, 'html.parser')
    data = []
    for row in soup.find_all('tr'):
        company = row.find('td', {'class': 'company'}).text
        pe = float(row.find('td', {'class': 'pe'}).text)
        pb = float(row.find('td', {'class': 'pb'}).text)
        data.append({'公司': company, '市盈率': pe, '市净率': pb})
    return data

# 数据处理函数
def process_data(data):
    df = pd.DataFrame(data)
    avg_pe = df['市盈率'].mean()
    avg_pb = df['市净率'].mean()
    df['低估'] = df['市盈率'] < avg_pe and df['市净率'] < avg_pb
    return df

# 主函数
def main():
    url = 'https://example.com/industry_data'
    data = fetch_data(url)
    df = process_data(data)
    print(df)

if __name__ == '__main__':
    main()
```

- 投资策略生成：根据判断结果生成投资策略。
