# 第一部分: 巴菲特指标的理论基础

## 第1章: 巴菲特指标的基本概念

### 1.1 巴菲特指标的定义与核心要素

#### 1.1.1 巴菲特指标的定义

巴菲特指标是衡量企业财务健康和投资价值的关键指标，包括ROE、ROA、ROS等。

#### 1.1.2 核心要素的构成

- ROE（净资产收益率）
- ROA（资产回报率）
- ROS（销售利润率）

#### 1.1.3 指标的核心逻辑与数学模型

ROE公式：
$$ROE = \frac{\text{净利润}}{\text{净资产}}$$

### 1.2 巴菲特指标的数学模型与公式

ROA公式：
$$ROA = \frac{\text{净利润}}{\text{总资产}}$$

ROS公式：
$$ROS = \frac{\text{净利润}}{\text{营业收入}}$$
