##### 1.2 格雷厄姆特价股票理论的核心概念

- **1.2.1 什么是特价股票**
  - 定义：市场价格低于内在价值的股票。
  - 标准：低市盈率、低市净率、高股息率等。

- **1.2.2 特价股票的定义与特征**
  - 数学定义：P < V（价格 < 内在价值）。
  - 特征：低估值、高分红、稳定收益。

- **1.2.3 格雷厄姆的选股标准**
  - 市盈率低于15倍。
  - 市净率低于1.5倍。
  - 股东权益收益率（ROE）高于7.5%。

- **1.3.2 格雷厄姆理论在量化投资中的应用**
  - 使用量化方法筛选低估值股票。
  - 利用算法优化投资组合。

- **1.3.3 量化投资的优势与局限性**
  - 优势：数据处理能力强、策略一致性高。
  - 局限性：市场变化快、模型过拟合风险。

##### 2.2 量化投资的数学模型

- **2.2.1 市盈率（P/E）计算公式**
  - $$P/E = \frac{Price}{Earnings}$$
  - 低市盈率策略：P/E < 15。

- **2.2.2 市净率（P/B）计算公式**
  - $$P/B = \frac{Price}{Book\ Value}$$
  - 低市净率策略：P/B < 1.5。

- **2.2.3 预测模型的构建**
  - 线性回归：预测股票价格。
  - 支持向量机：分类低估值股票。

##### 2.3 量化投资策略的分类

- **2.3.1 均值回归策略**
  - 投资者认为价格会回归均值。
  - 适用于低市盈率股票。

- **2.3.2 动量策略**
  - 追踪过去表现优秀的股票。
  - 适用于趋势明显的市场。

- **2.3.3 多因子模型**
  - 结合多个因子：价值、动量、质量。
  - 更全面的选股策略。

```python
import backtrader as bt

# 定义策略
class GrahamStrategy(bt.Strategy):
    def __init__(self):
        self.position = None

    def next(self):
        # 筛选符合条件的股票
        selected = self.data.Close < 15 * self.data.Earnings
        if selected:
            if self.position.size == 0:
                self.position.size = 1
        else:
            if self.position.size != 0:
                self.position.size = 0

# 回测设置
cerebro = bt.Cerebro()
cerebro.addstrategy(GrahamStrategy)
cerebro.run()
```
