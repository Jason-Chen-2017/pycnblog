## 第四章: 协同效应实现度的数学模型

### 4.1 协同效应实现度的数学推导

协同效应实现度的计算公式可以表示为：

$$ CE = \frac{(S_t - S_b) \times C}{S_b} $$

其中，\( CE \) 是协同效应实现度，\( S_t \) 是实际协同价值，\( S_b \) 是基准协同价值，\( C \) 是整合成本。通过推导公式，我们可以看到，协同效应实现度不仅依赖于协同价值的提升，还与整合成本密切相关。

### 4.2 协同效应实现度的案例分析

以公司A并购公司B为例，假设并购前的预期协同价值为1000万元，实际协同价值为1200万元，整合成本为200万元。基准协同价值为900万元。

计算协同效应实现度：

$$ CE = \frac{(1200 - 900) \times 200}{900} = \frac{300 \times 200}{900} = \frac{60000}{900} \approx 66.67\% $$

这一结果表明，公司A在并购公司B后的协同效应实现度为66.67%，表明协同效应实现了一部分，但仍有提升空间。

### 6.2 核心代码实现

协同效应计算的Python函数：

```python
def calculate_synergy(merged_value, benchmark_value, integration_cost):
    synergy = (merged_value - benchmark_value) * integration_cost / benchmark_value
    return synergy

# 示例数据
merged_value = 1200  # 实际协同价值
benchmark_value = 900  # 基准协同价值
integration_cost = 200  # 整合成本

ce = calculate_synergy(merged_value, benchmark_value, integration_cost)
print(f"协同效应实现度: {ce}%")
```
