### 第4章：脑机接口技术的关键算法

#### 4.1 基于EEG的脑机接口算法
- 4.1.1 EEG信号的采集与预处理代码示例：
  ```python
  import numpy as np
  from scipy.signal import butterworth
  def preprocess_eeg(eeg_data, sampling_rate):
      # 滤波器设计
      nyquist = sampling_rate / 2
      order = 4
      cutoff = 30  # Hz
      b, a = butterworth(order, cutoff / nyquist, btype='low')
      filtered_data = np.zeros_like(eeg_data)
      for i in range(eeg_data.shape[0]):
          filtered_data[i] = butterworth_filter(eeg_data[i], b, a)
      return filtered_data
  ```

- 4.1.2 基于时频域分析的特征提取：
  - 时域特征：均值、标准差、峰峰值。
  - 频域特征：功率谱密度（PSD）、特定频带的能量。

- 4.1.3 基于机器学习的分类方法：
  - 支持向量机（SVM）：适用于小样本数据。
  - 随机森林（RF）：适用于高维特征。

- 4.3.1 各种算法的优缺点对比：
  | 算法类型 | 优点 | 缺点 |
  |----------|------|------|
  | SVM      | 高精度，适合小样本 | 对高维数据表现不佳 |
  | RF       | 鲁棒性强，适合高维 | 分类速度较慢 |
  | CNN      | 高精度，适合图像数据 | 需大量标注数据 |

- 4.3.2 不同应用场景下的算法选择：
  - 医疗康复：SVM或RF。

- 4.3.3 算法优化的未来方向：

  - 研究更高效的轻量级算法。

#### 6.2 核心算法的实现与优化
- 6.2.1 EEG信号的采集与预处理代码：
  ```python
  import numpy as np
  from scipy.signal import butterworth

  def butterworth_filter(signal, order, cutoff, sampling_rate):
      nyquist = sampling_rate / 2
      b, a = butterworth(order, cutoff / nyquist, btype='low')
      output = np.zeros_like(signal)
      for i in range(signal.shape[0]):
          output[i] = np.convolve(signal[i], b, mode='full')[:len(signal[i])]
      return output

  # 示例数据
  sampling_rate = 250
  eeg_data = np.random.randn(1000, 16)
  filtered_data = butterworth_filter(eeg_data, 4, 30, sampling_rate)
  ```
