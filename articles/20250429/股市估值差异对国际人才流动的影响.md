## 第二部分：核心概念与联系

### 第2章：核心概念原理

#### 2.1 股市估值的原理

- **2.1.1 市盈率（P/E）**
  $$P/E = \frac{\text{股价}}{\text{每股收益}}$$
  反映市场对公司盈利能力的预期。

- **2.1.2 市净率（P/B）**
  $$P/B = \frac{\text{股价}}{\text{每股净资产}}$$
  适用于资产密集型行业。

- **2.1.3 股东权益回报率（ROE）**
  $$ROE = \frac{\text{净利润}}{\text{股东权益}}$$
  衡量公司使用股东资金的效率。

#### 2.2 人才流动的驱动因素

- **2.2.1 薪酬水平**
  包括基本工资和福利。

- **2.2.2 职业发展机会**
  包括晋升和培训机会。

- **2.2.3 工作环境**
  包括企业文化和发展空间。

- **2.2.4 经济与生活成本**
  影响人才流动的净流入。

#### 2.3 股市估值与人才流动的关联机制

- **2.3.1 估值差异影响人才期望**
  高估值企业被认为更具发展潜力，吸引更多人才。

- **2.3.2 反向作用**
  人才流动影响企业业绩，进而影响估值。

- **2.3.3 中介变量**
  包括企业声誉和员工满意度。

#### 5.2 Python实现

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据预处理
data = pd.read_csv('data.csv')
data = data.dropna()
X = data[['P/E', 'P/B', 'ROE']]
y = data['talent_mobility']

# 特征选择与模型训练
model = LinearRegression()
model.fit(X, y)

# 预测与分析
predictions = model.predict(X)
print('预测值:', predictions)
print('系数:', model.coef_)
print('截距:', model.intercept_)
```

#### 7.2 核心代码

```python
import pandas as pd

from sklearn.metrics import r2_score

X = data[['P/E', 'P/B', 'ROE']]
y = data['talent_mobility']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print('R²:', r2_score(y_test, y_pred))
```
