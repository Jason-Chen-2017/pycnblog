# 第1章 特价股票策略与质量因子投资的背景与概念

## 1.1 特价股票策略的定义与特点
### 1.1.1 特价股票的定义
特价股票是指那些市场价格低于其内在价值的股票。通常，这些股票可能被市场低估，或者由于某些短期因素导致价格下跌，但其基本面仍然稳健。

### 1.1.2 特价股票策略的核心特点
1. **低估值**：主要关注市盈率（P/E）和市净率（P/B）等估值指标。
2. **逆向投资**：在市场低迷时寻找被低估的机会。
3. **长期视角**：注重公司基本面的稳定性，而非短期市场波动。

### 1.1.3 特价股票策略的应用场景
适用于市场低迷时期或行业周期性低谷时，寻找具有长期潜力的股票。

## 1.2 质量因子投资的定义与特点
### 1.2.1 质量因子的定义
质量因子是指公司财务健康状况的量化指标，通常包括高收益率、高账面价值等。

### 1.2.2 质量因子的核心特点
1. **高收益率**：公司盈利能力强。
2. **低财务杠杆**：公司负债较低，财务风险小。
3. **高流动性**：股票交易活跃，易于买卖。

### 1.2.3 质量因子投资的应用场景
适用于长期投资，尤其是寻找具有持续盈利能力和财务健康状况的公司。

## 1.3 特价股票策略与质量因子投资的结合意义
### 1.3.1 结合的逻辑与优势
通过结合低估值和高质量因子，可以在市场低迷时筛选出具有长期增长潜力的股票。

### 1.3.2 结合的潜在价值与风险
1. **潜在价值**：能够在市场低谷时找到价值被低估的优质股票。
2. **风险**：可能会遗漏一些短期表现不佳但长期增长潜力大的股票。

### 1.3.3 结合的创新性与实践意义
通过结合两种策略，可以在市场波动中找到平衡点，优化投资组合的风险收益比。

## 1.4 本章小结

# 第2章 特价股票策略的核心原理

## 2.1 特价股票的识别方法
### 2.1.1 市盈率（P/E）分析
市盈率 = 市场价格 / 每股收益  
公式：$$ P/E = \frac{Price}{Earnings} $$

### 2.1.2 市净率（P/B）分析
市净率 = 市场价格 / 每股净资产  
公式：$$ P/B = \frac{Price}{Book\ Value} $$

### 2.1.3 其他估值指标的使用
包括股息率、PEG比率等。

## 2.2 特价股票策略的实施步骤
