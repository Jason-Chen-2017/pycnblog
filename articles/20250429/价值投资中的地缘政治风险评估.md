## 第3章: 地缘政治风险评估的数学模型

### 3.1 层次分析法（AHP）
- 3.1.1 AHP的基本原理
- 3.1.2 权重计算公式：$$ AHP权重 = \frac{a_{ij}}{\sum_{j}a_{ij}} $$
- 3.1.3 应用步骤：构建判断矩阵、计算一致性检验

### 3.2 模糊综合评价法
- 3.2.1 模糊评价的定义
- 3.2.2 隶属度函数：$$ \mu(x) = \frac{1}{1 + e^{-x}} $$
- 3.2.3 综合评价公式：$$ Z = \sum_{i=1}^{n} w_i R_i $$

### 3.3 算法实现
- 3.3.1 Python代码示例
```python
import numpy as np

# 示例：层次分析法计算权重
def ahp_weights(matrix):
    # 计算权重向量
    n = len(matrix)
    sum_rows = np.sum(matrix, axis=1)
    weights = sum_rows / np.sum(sum_rows)
    return weights
```
