## 第1章: 投资组合优化的背景与概念

### 1.1 投资组合优化的基本概念

#### 1.1.1 投资组合的定义与特征
- **投资组合**：由多种资产（如股票、债券、基金等）组成的集合，旨在通过多样化投资降低风险。
- **特征**：
  - 多样性：分散投资以降低风险。
  - 风险与收益的权衡：追求在特定风险水平下的最大收益。
  - 可调整性：根据市场变化动态调整资产配置。

#### 1.1.2 投资组合优化的目标
- 最大化收益：在给定风险下最大化投资回报。
- 最小化风险：在给定收益下最小化投资风险。
- 平衡风险与收益：找到最优风险-收益 trade-off。

#### 1.1.3 均值-方差模型的提出与意义
- **提出者**：Harry Markowitz（1952年）。
- **意义**：首次将数学优化引入投资决策，奠定了现代投资组合理论的基础。

### 1.2 均值-方差模型的背景

#### 1.2.1 马科维茨投资组合理论的提出
- **背景**：20世纪50年代，投资者开始意识到单一资产的风险，需要通过多样化投资来降低风险。
- **理论贡献**：Markowitz 提出，投资者可以通过优化资产配置，在有效前沿上找到最优组合。

#### 1.2.2 均值-方差模型的核心假设
- 资产收益符合正态分布。
- 投资者是理性的，追求效用最大化。
- 市场是有效的，即资产价格反映所有相关信息。

#### 1.2.3 投资组合优化的现实意义
- 为投资者提供科学的资产配置方法。
- 帮助投资者在复杂市场中做出决策。
- 为金融工具（如指数基金）的设计提供理论基础。

### 1.3 投资组合优化的数学基础

#### 1.3.1 随机变量与概率分布
- **随机变量**：资产收益是随机的，可以用概率分布描述。
- **概率分布**：如正态分布、t分布等，用于描述资产收益的可能性。

#### 1.3.2 方差与协方差的定义
- **方差**：衡量资产收益的波动性，公式为 $ \sigma^2 = E[(r - E[r])^2] $。
- **协方差**：衡量两种资产收益的联动性，公式为 $ \text{Cov}(r_i, r_j) = E[(r_i - E[r_i])(r_j - E[r_j])] $。

#### 1.3.3 投资组合收益与风险的数学表达
- **投资组合收益**： $ \mu_p = \sum_{i=1}^n w_i \mu_i $，其中 $ w_i $ 是权重，$ \mu_i $ 是资产i的期望收益。
- **投资组合方差**： $ \sigma_p^2 = \sum_{i=1}^n \sum_{j=1}^n w_i w_j \text{Cov}(r_i, r_j) $。

## 第2章: 均值-方差模型的理论基础

### 2.1 均值-方差模型的数学公式

#### 2.1.1 投资组合的期望收益
$$ \mu_p = \sum_{i=1}^n w_i \mu_i $$

#### 2.1.2 投资组合的方差
$$ \sigma_p^2 = \sum_{i=1}^n \sum_{j=1}^n w_i w_j \text{Cov}(r_i, r_j) $$

#### 2.1.3 最优化目标的数学表达
$$ \min_{w} \sigma_p^2 \quad \text{subject to} \quad \sum_{i=1}^n w_i = 1 $$

### 2.2 均值-方差模型的核心假设

#### 2.2.1 资产收益的正态分布假设
- 资产收益服从正态分布，简化了风险的计算。
- 但现实中，金融资产收益可能呈现肥尾现象。

#### 2.2.2 投资者风险偏好的无差异曲线
- **无差异曲线**：表示投资者在不同风险和收益组合中无差异的点。
- 风险厌恶投资者会选择风险最小的组合。

#### 2.2.3 市场有效性的假设
- 假设市场有效，即资产价格反映所有信息。
- 在有效市场中，均值-方差模型能够找到最优组合。

### 2.3 均值-方差模型的扩展

#### 2.3.1 多阶段优化的考虑
- **多阶段优化**：考虑不同时间段的资产配置。
- **动态调整**：根据市场变化动态优化组合。

#### 2.3.2 约束条件的引入
- **约束条件**：
  - 资金比例约束：$ \sum_{i=1}^n w_i = 1 $。
  - 风险约束：$ \sigma_p^2 \leq \sigma_{\text{max}}^2 $。
  - 收益约束：$ \mu_p \geq \mu_{\text{min}} $。

#### 2.3.3 非线性优化问题的处理
- 均值-方差模型是非线性优化问题，通常需要使用二次规划算法求解。

## 第3章: 均值-方差模型的算法原理

### 3.1 最优化算法概述

#### 3.1.1 线性规划与非线性规划的区别
- **线性规划**：目标函数和约束条件均为线性。
- **非线性规划**：目标函数或约束条件为非线性。

#### 3.1.2 常用优化算法简介
- **梯度下降法**：适用于无约束优化问题。
- **牛顿法**：适用于有良好二阶导数信息的优化问题。
- **内点法**：适用于有约束优化问题。

#### 3.1.3 均值-方差模型的优化方法
- **二次规划**：目标函数和约束条件均为二次型。

### 3.2 均值-方差模型的数学推导

#### 3.2.1 投资组合方差的最小化
$$ \min_{w} \sum_{i=1}^n \sum_{j=1}^n w_i w_j \text{Cov}(r_i, r_j) $$

#### 3.2.2 投资组合收益的最大化
$$ \max_{w} \sum_{i=1}^n w_i \mu_i \quad \text{subject to} \quad \sum_{i=1}^n w_i = 1 $$

#### 3.2.3 约束条件下的优化问题
$$ \min_{w} \sigma_p^2 \quad \text{subject to} \quad \sum_{i=1}^n w_i \mu_i = \mu_p $$

function optimize_portfolio(weights, mu, cov):

#### 3.3.3 具体案例的数学推导
- 假设两只资产，权重分别为 $w_1$ 和 $w_2$。

### 6.2 核心实现

#### 6.2.1 均值-方差模型的实现代码

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_variance(weights, covariance):
    return np.dot(weights.T, np.dot(covariance, weights))

def optimize_portfolio(n_assets, mu, cov, target_return=0.1):
    # 初始权重向量
    initial_weights = np.array([1.0 / n_assets] * n_assets)
    
    # 定义约束条件
    constraints = [
        ('sum', initial_weights @ mu, '==', target_return)
    ]
    
    # 定义目标函数
    def objective(weights):
        return portfolio_variance(weights, cov)
    
    # 求解优化问题
    result = minimize(objective, initial_weights, 
                      constraints=constraints, 
                      method='SLSQP')
    
    return result.x

# 示例数据
n_assets = 2
mu = np.array([0.1, 0.2])
cov = np.array([[0.05, 0.02], [0.02, 0.1]])
weights = optimize_portfolio(n_assets, mu, cov)
print("优化后的权重为：", weights)
```

import numpy as np
from scipy.optimize import minimize

def objective(weights, covariance):
    return np.dot(weights.T, np.dot(covariance, weights))

def constraint(weights, mu, target_return):
    return np.dot(weights, mu) - target_return

n_assets = 2
mu = np.array([0.1, 0.2])
cov = np.array([[0.05, 0.02], [0.02, 0.1]])
target_return = 0.15

initial_weights = np.array([1.0 / n_assets] * n_assets)

result = minimize(objective, initial_weights, 
                 args=(cov,), 
                 method='SLSQP',
                 constraints={'type': 'eq', 'fun': constraint, 'args': (mu, target_return)})

print("优化后的权重为：", result.x)
