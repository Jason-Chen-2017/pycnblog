## 第1章 特价股票与动量投资概述

### 1.1 特价股票的基本概念
特价股票是指那些市场价格低于其内在价值的股票，通常被认为被市场低估。投资者认为这些股票具有潜在的上涨空间。特价股票的筛选通常基于估值指标，如市盈率（P/E）、市净率（P/B）等。

### 1.2 动量投资的基本概念
动量投资是一种基于价格趋势的投资策略，认为价格的上涨趋势会延续一段时间。动量投资的核心在于动量效应，即价格的上涨或下跌趋势会自我强化。

### 1.3 特价股票与动量投资的结合
将特价股票策略与动量投资结合，旨在利用动量效应优化特价股票的选择，同时利用特价股票的低估特性增强动量策略的效果。

## 第2章 动量效应与特价股票策略的核心概念

### 2.1 动量效应的原理
动量效应认为，价格的上涨趋势会持续一段时间。动量指标如相对强弱指数（RSI）和动量指标（MOM）被广泛用于衡量动量效应。

### 2.2 特价股票策略的核心要素
特价股票策略关注于估值指标，通过筛选低估值的股票来寻找投资机会。常用指标包括市盈率、市净率等。

### 2.3 动量效应与特价股票策略的联系
通过结合动量效应和特价股票策略，投资者可以在低估的股票中寻找具有上涨潜力的标的。动量效应可以帮助筛选出具有趋势性特征的特价股票，从而提高投资收益。

## 第3章 动量投资的数学模型

### 3.1 动量效应的数学模型
动量效应可以通过动量指标来衡量，如：
$$ MOM = \frac{P_t - P_{t-n}}{P_{t-n}} $$
其中，$P_t$ 是当前价格，$P_{t-n}$ 是n期前的价格。

### 3.2 特价股票的筛选模型
特价股票的筛选模型基于估值指标，如：
$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

### 3.3 结合动量效应和特价股票的综合模型
综合模型将动量效应和估值指标结合，通过权重分配和优化算法筛选出最优投资组合。

```python
import pandas as pd
import numpy as np

# 动量指标计算
def calculate_momentum(data, window=10):
    return data['close'].shift(window).pct_change().fillna(0)

# 特价股票筛选
def screen_value_stocks(data, window=10):
    momentum = calculate_momentum(data, window)
    pe = data['pe']
    pb = data['pb']
    return data[(pe < pe.quantile(0.2)) & (momentum > 0)]
```
