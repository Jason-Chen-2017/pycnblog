## 第1章: 影响力投资的核心概念

### 1.1 影响力投资的定义与背景
影响力投资是一种关注经济和社会影响力的新型投资方式，旨在通过投资实现经济回报和社会价值的双重目标。与传统投资不同，影响力投资更注重企业在社会、环境和治理方面的贡献。

### 1.2 影响力投资的理论基础
影响力投资的理论基础包括可持续发展理论、环境、社会和治理（ESG）框架，以及社会责任投资（SRI）等。这些理论为影响力投资提供了坚实的学术支持。

### 1.3 影响力投资与长期价值的结合
彼得林奇的长期价值理念强调企业在未来能为股东创造的持续价值。将这一理念应用于影响力投资，意味着投资者需要关注企业在社会和环境方面带来的长期影响，而不仅仅是短期的财务回报。

def calculate_influence_score(company_data):
    social_contribution = company_data['社会贡献']
    environmental_impact = company_data['环境影响']
    governance_structure = company_data['治理结构']
    total_score = (social_contribution + environmental_impact + governance_structure) / 3
    return total_score

# 示例数据

    '社会贡献': 80,
    '环境影响': 70,
    '治理结构': 90
}

print(f"影响力评分为：{score}")
