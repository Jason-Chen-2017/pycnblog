# 第3章: 格雷厄姆策略的算法原理

## 3.1 算法原理
格雷厄姆策略通过筛选低市盈率、低市净率和高股息率的股票，寻找被低估的投资标的。

### 3.1.1 筛选指标
- **市盈率（P/E）**：计算公式为：P/E = 股价 / 每股收益。
- **市净率（P/B）**：计算公式为：P/B = 股价 / 每股净资产。
- **股息率**：计算公式为：股息率 = 每股股息 / 股价 × 100%。

### 3.1.2 筛选流程
1. **数据收集**：获取股票的市盈率、市净率和股息率。
2. **筛选标准**：P/E < 市场平均值，P/B < 市场平均值，股息率 > 市场平均值。
3. **投资组合构建**：选择符合标准的股票，构建投资组合。

### 3.2.3 股息率公式
