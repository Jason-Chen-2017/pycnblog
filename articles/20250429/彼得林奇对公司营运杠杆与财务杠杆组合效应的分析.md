### 第4章：组合效应的数学公式与代码实现

#### 4.1 营运杠杆与财务杠杆的组合公式
- 组合杠杆系数的数学公式
  - 组合杠杆系数 = (EBIT / (EBIT - I)) × ((EBIT - I) / Equity)
  - 其中，EBIT为息税前利润，I为利息支出，Equity为股东权益

#### 4.2 组合效应的数学公式
- 组合效应的数学模型
  - 组合杠杆效应 = 营运杠杆效应 × 财务杠杆效应

#### 4.3 Python代码实现
- 计算营运杠杆系数
```python
def operating_leverage(EBIT, I):
    return EBIT / (EBIT - I)
```

- 计算财务杠杆系数
```python
def financial_leverage(EBIT, I, equity):
    return (EBIT - I) / equity
```

- 计算组合杠杆系数
```python
def combined_leverage(EBIT, I, equity):
    return (EBIT / (EBIT - I)) * ((EBIT - I) / equity)
```
