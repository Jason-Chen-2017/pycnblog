#### 3.1.3 算法原理的数学模型和公式

$$ \text{相关性} = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2} \sqrt{\sum (y_i - \bar{y})^2}} $$

其中，$$x_i$$ 和 $$y_i$$ 分别表示两个变量的观测值，$$\bar{x}$$ 和 $$\bar{y}$$ 分别表示它们的平均值。

### 4.1 数学模型

$$ \text{股市估值影响因素} = \beta_0 + \beta_1 \times \text{自修复材料应用比例} + \beta_2 \times \text{政策支持} + \epsilon $$

### 6.2 核心代码实现

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score
import pandas as pd

# 示例数据
data = {
    '自修复材料应用比例': [10, 15, 20],
    '股市估值': [100, 110, 120]
}

df = pd.DataFrame(data)
X = df[['自修复材料应用比例']]
y = df['股市估值']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测结果
predictions = model.predict(X)
print('R-squared:', r2_score(y, predictions))
```

### 6.3 案例分析与详细解读

假设我们有以下数据：

| 自修复材料应用比例 | 股市估值 |

| 10                | 100      |
| 15                | 110      |
| 20                | 120      |

通过模型训练，我们发现自修复材料应用比例每增加5%，股市估值增加10%。因此，投资者可以据此制定投资策略。
