## 第三部分：算法原理讲解

### 第3章：数学模型与公式

#### 3.1 回归分析模型
- **3.1.1 线性回归模型**
  - 公式：$$ y = \beta_0 + \beta_1x + \epsilon $$
  - 解释：$y$为品牌价值，$x$为特价股票价格，$\beta_0$为截距，$\beta_1$为回归系数，$\epsilon$为误差项。
- **3.1.2 多元回归模型**
  - 公式：$$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon $$
  - 解释：加入更多变量（如公司利润、行业地位）以提高模型准确性。

#### 3.2 聚类分析模型
- **3.2.1 K-means算法**
  - 步骤：
    1. 初始化质心。
    2. 计算每个数据点到质心的距离。
    3. 重新计算质心，直到收敛。
- **3.2.2 层次聚类分析**
  - 步骤：
    1. 构建距离矩阵。
    2. 绘制树状图。
    3. 合并相似的簇。

#### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
import matplotlib.pyplot as plt

# 数据加载
data = pd.read_csv('stock_brand.csv')

# 数据预处理
X = data[['stock_price', 'profit_margin']]
y = data['brand_value']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 模型预测
y_pred = model.predict(X)

# 模型评估
mse = mean_squared_error(y, y_pred)
r_squared = model.score(X, y)

print(f"均方误差：{mse}")
print(f"R²值：{r_squared}")

# 可视化
plt.scatter(y, y_pred)
plt.xlabel('真实品牌价值')
plt.ylabel('预测品牌价值')
plt.title('回归分析结果')
plt.show()
```
