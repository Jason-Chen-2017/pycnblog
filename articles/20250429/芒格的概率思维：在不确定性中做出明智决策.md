### 第二部分: 芒格的概率思维框架

#### 第2章: 概率思维的核心工具

##### 2.1 贝叶斯定理
贝叶斯定理是一种用于更新概率的数学工具，其公式为：
$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$
其中，$P(A|B)$ 表示在事件B发生的情况下，事件A发生的概率。

**应用场景：**
- 医疗诊断：通过症状和测试结果计算疾病的可能性。
- 投资决策：通过历史数据预测未来趋势。

##### 2.2 蒙特卡洛模拟
蒙特卡洛模拟是一种通过随机采样来估计概率分布的方法。其核心步骤如下：
1. 确定输入变量及其概率分布。
2. 生成随机样本。
3. 计算输出变量的分布。

**实现代码示例：**
```python
import numpy as np

# 随机数生成
np.random.seed(42)
samples = np.random.normal(loc=0, scale=1, size=1000)

# 统计分析
mean = np.mean(samples)
std_dev = np.std(samples)
print(f"均值：{mean}，标准差：{std_dev}")
```

##### 2.3 概率树分析
概率树是一种用于展示概率问题的树状图，帮助我们清晰地看到每种可能的结果及其概率。

**案例分析：**
假设我们投资一个项目，有两种可能的结果：成功（概率0.7）和失败（概率0.3）。成功的项目有3种收益情况，失败的项目有2种损失情况。概率树可以帮助我们计算每种结果的期望值。

### 第三部分: 概率思维的实战应用

#### 第3章: 芒格的概率思维决策框架

##### 3.1 芒格决策框架概述
芒格的决策框架包括以下几个步骤：
1. 明确目标。
2. 收集信息。

4. 评估风险与收益。
5. 优化决策。

##### 3.2 决策框架的具体步骤
- **明确目标：** 确定决策的核心目标和关键因素。
- **收集信息：** 获取与问题相关的数据和信息。
- **构建模型：** 使用贝叶斯定理或蒙特卡洛模拟等工具建立概率模型。
- **评估风险：** 计算不同决策路径的风险和收益。
- **优化决策：** 根据评估结果优化决策方案。

##### 3.3 实际案例分析
**投资决策案例：**
假设我们考虑投资两个项目，A和B。项目A的成功概率为0.8，预期收益为100万元；项目B的成功概率为0.6，预期收益为150万元。通过概率树分析，我们可以计算每个项目的期望收益：
$$E(A) = 0.8 \times 100 + 0.2 \times 0 = 80$$
$$E(B) = 0.6 \times 150 + 0.4 \times 0 = 90$$
虽然项目B的期望收益更高，但其风险也更大。因此，需要综合考虑风险偏好和资源情况做出决策。
