## 第4章：耐心资本的数学模型与算法原理  

### 4.1 投资组合优化的数学模型  

#### 4.1.1 现代投资组合理论（MPT）概述  
- MPT的核心思想：通过优化投资组合降低风险。  
- 投资组合的期望收益与风险的关系：  
  $$ E(R_p) = \sum w_i E(R_i) $$  
  $$ \sigma_p^2 = \sum \sum w_i w_j \sigma_{i,j} $$  

#### 4.1.2 均值-方差优化模型  
- 优化目标：最大化期望收益，同时最小化风险。  
- 模型公式：  
  $$ \min_w \sigma_p^2 $$  
  $$ \text{subject to} \quad E(R_p) \geq R_{\text{min}} $$  

#### 4.1.3 资本资产定价模型（CAPM）  
- CAPM公式：  
  $$ E(R_i) = R_f + \beta_i (R_m - R_f) $$  

### 4.2 投资组合优化的算法实现

#### 4.2.2 Python代码实现  

```python
import numpy as np
import scipy.optimize as opt

# 示例数据：资产的期望收益和协方差矩阵
mu = np.array([0.1, 0.15, 0.12])
sigma = np.array([
    [0.05, 0.02, 0.03],
    [0.02, 0.10, 0.04],
    [0.03, 0.04, 0.08]
])

# 定义优化问题
def portfolio_optimization(weights, mu, sigma, target_return):
    n = len(weights)
    if n == 0:
        return 0
    return (weights.dot(mu) - target_return)**2 + (weights.T.dot(sigma).dot(weights)) 

# 约束条件
cons = ({
    'type': 'eq',
    'fun': lambda w: sum(w) - 1
})

# 使用SLSQP求解
result = opt.minimize(portfolio_optimization, np.ones(len(mu))/len(mu), args=(mu, sigma, np.mean(mu)), method='SLSQP', constraints=cons)

# 输出结果
print("最优权重:", result.x)
print("最小方差:", result.fun)
```
