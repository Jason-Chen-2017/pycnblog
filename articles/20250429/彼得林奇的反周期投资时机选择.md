### 第2章：反周期投资的核心概念  

#### 2.1 市场周期的定义与分析  
市场周期分为四个阶段：繁荣、衰退、萧条、复苏。反周期投资关注衰退和复苏阶段，寻找低估资产。  

- **2.1.1 市场周期的阶段划分**  
  - 繁荣期：市场估值偏高，投资者情绪乐观。  
  - 衰退期：经济放缓，企业盈利下降，股价回调。  
  - 萧条期：市场底部，估值处于历史低位。  
  - 复苏期：经济逐步恢复，股价回升。  

- **2.1.2 彼得林奇的市场周期分析法**  
  林奇通过分析市盈率、市净率等指标判断市场所处阶段，尤其关注低市盈率股票。  

#### 2.2 投资时机选择的原理  
投资时机选择是反周期投资的关键，需结合市场估值、行业趋势和宏观经济指标。  

- **2.2.1 市场估值指标**  
  - 市盈率（P/E）：衡量股价与盈利的关系。  
  - 市净率（P/B）：衡量股价与资产净值的关系。  

- **2.2.2 宏观经济指标**  
  - GDP增长率：反映经济整体表现。  
  - 利率水平：影响市场估值和企业融资成本。  

- **2.2.3 低市盈率股票的筛选**  
  林奇偏好市盈率低于市场平均水平的股票，尤其是那些具有稳定盈利的企业。  

#### 2.3 彼得林奇的反周期投资策略  
林奇的策略包括行业选择、投资组合构建和风险管理。  

- **2.3.1 行业选择**  
  在衰退期，选择防御性行业，如公用事业、医疗保健等。  

- **2.3.2 投资组合构建**  
  分散投资，平衡成长股和价值股，降低风险。

#### 6.2 核心算法实现  
- 基于市盈率的筛选算法。  

- **6.2.1 筛选低市盈率股票的代码**  
  ```python
  def get_low_pe_stocks(tickers, pe_threshold=15):
      low_pe = []
      for ticker in tickers:
          data = yf.download(ticker, period='max')
          if 'EPS' in data.columns:
              pe = data['Adj Close'][-1] / data['EPS'][-1]
              if pe < pe_threshold:
                  low_pe.append(ticker)
      return low_pe
  ```
