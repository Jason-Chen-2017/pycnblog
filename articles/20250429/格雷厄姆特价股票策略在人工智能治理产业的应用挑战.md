#### 1.1 格雷厄姆特价股票策略的核心概念

##### 1.1.1 什么是格雷厄姆特价股票策略  
格雷厄姆特价股票策略是由本杰明·格雷厄姆提出的一种投资策略，专注于寻找被市场低估的股票，通过基本面分析和安全边际原则进行投资。其核心在于“买入低于内在价值的股票”，并在市场波动中长期持有，等待价值回归。

##### 1.1.2 格雷厄姆策略的核心要素  
- **安全边际**：买入价格低于内在价值，确保投资的安全性。  
- **低估值股票**：选择市盈率、市净率等指标低于行业平均水平的股票。  
- **长期投资**：避免短期市场波动，关注企业的长期价值。  

##### 1.1.3 格雷厄姆策略在投资中的应用场景  
- **价值投资**：寻找被市场忽视的优质企业。  
- **风险管理**：通过分散投资和安全边际降低风险。  
- **长期财富积累**：通过长期持有优质资产实现财富增长。

- 数据格式：CSV文件，包含股票代码、价格、交易量等信息。  

#### 5.2 系统核心实现

##### 5.2.1 数据预处理  
```python
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('stock_data.csv')

# 数据清洗
df.dropna(inplace=True)
df['date'] = pd.to_datetime(df['date'])
df.set_index('date', inplace=True)

# 特征提取
df['moving_avg'] = df['price'].rolling(5).mean()
df['std_dev'] = df['price'].rolling(5).std()
```

##### 5.2.2 模型训练  
```python
from sklearn.linear_model import LinearRegression

# 训练格雷厄姆策略模型
model = LinearRegression()
model.fit(df[['moving_avg', 'std_dev']], df['price'])

# 预测股票价格
predicted_prices = model.predict(df[['moving_avg', 'std_dev']])
```

##### 5.2.3 模型评估  
```python
from sklearn.metrics import r2_score

r2 = r2_score(df['price'], predicted_prices)
print(f"模型R²值为：{r2}")
```
