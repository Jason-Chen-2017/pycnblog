### 1.1 或有负债的定义与特征

#### 1.1.1 或有负债的定义
或有负债是指公司在未来可能发生的潜在负债，通常源于合同、法律纠纷、担保、诉讼或其他可能的财务承诺。这些负债不一定在资产负债表中直接体现，但可能在特定情况下转化为现实负债。

#### 1.1.2 或有负债的特征
- **潜在性**：或有负债可能尚未实际发生，但存在转化为现实负债的可能性。
- **不确定性**：其发生时间和金额具有不确定性。
- **关联性**：可能与其他财务指标（如流动比率、速动比率）密切相关，影响公司的财务健康。

#### 1.1.3 或有负债与公司财务健康的关系
或有负债过多可能影响公司的信用评级，增加融资难度，并在发生时对财务状况造成重大冲击。

#### 9.1.3 Python 实现代码

```python
def assess_or_liability_risk(liabilities):
    risk_factors = {
        'litigation': {'probability': 0.3, 'amount': 1000000},
        'guarantees': {'probability': 0.2, 'amount': 500000},
        'restructuring': {'probability': 0.4, 'amount': 750000}
    }
    total_risk = 0
    for liab in liabilities:
        if liab in risk_factors:
            prob = risk_factors[liab]['probability']
            amt = risk_factors[liab]['amount']
            total_risk += prob * amt
    return total_risk

# 示例
liabilities = ['litigation', 'guarantees']
print(assess_or_liability_risk(liabilities))  # 输出：350000
```

## 第11章：项目实战

### 11.1 案例分析

#### 11.1.1 公司概况
XYZ公司面临多起诉讼，潜在负债总额为500万美元，其中200万为已决诉讼，300万为未决诉讼。

#### 11.1.2 风险评估
使用概率加权模型，未决诉讼的发生概率为30%，潜在影响为300万 * 0.3 = 90万。

### 11.2 代码实现

```python
def assess_case(company_liabilities):
    # 参数：公司潜在负债列表
    # 返回：风险等级
    risk_factors = {
        'litigation': 0.3,
        'guarantees': 0.2,
        'restructuring': 0.4
    }
    total_risk = 0
    for liab in company_liabilities:
        if liab in risk_factors:
            prob = risk_factors[liab]
            # 假设金额已知，如300万未决诉讼
            amt = 3000000 if liab == 'litigation' else 0
            total_risk += prob * amt
    return total_risk

# 示例
liabilities = ['litigation']
print(assess_case(liabilities))  # 输出：900000
```
