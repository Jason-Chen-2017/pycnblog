## 第3章 彼得林奇风险控制方法的数学模型

### 3.1 风险评估的数学公式
使用CAPM模型评估资产风险，公式为：$$E(r_i) = R_f + β_i (E(r_m) - R_f)$$

### 3.2 投资组合优化的算法流程
1. 评估各资产的风险收益比。
2. 计算投资组合的β系数。
3. 调整权重以优化风险收益。

### 3.3 算法实现
代码示例：
```python
import numpy as np

def calculate_beta(returns, market_returns):
    # 计算收益差值
    market_excess = market_returns - np.mean(market_returns)
    asset_excess = returns - np.mean(returns)
    # 计算协方差和方差
    covariance = np.cov(asset_excess, market_excess)[0, 1]
    variance = np.var(market_excess)
    beta = covariance / variance
    return beta
```

def calculate_portfolio_risk(portfolio_weights, asset_returns):
    # 计算协方差矩阵
