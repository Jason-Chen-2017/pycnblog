# 第二部分: 用户获取成本的背景与概念

## 第2章: 用户获取成本（CAC）的核心概念

### 2.1 什么是用户获取成本  
用户获取成本（CAC）是指企业获取一名新用户的平均成本，包括广告支出、营销费用等。

### 2.2 CAC的重要性  
CAC是衡量企业市场活动效率的重要指标，直接影响企业的盈利能力。

### 2.3 CAC与其他财务指标的关系  
CAC与收入、利润、客户生命周期价值（CLV）等指标密切相关，是企业战略决策的重要依据。

## 第3章: 用户获取成本的计算与分析

### 3.1 CAC的计算公式  
CAC = （广告支出 + 销售费用） / 新客户数量

### 3.2 CAC的分类与特征  
CAC可以根据行业、用户类型等进行分类，不同行业的CAC差异显著。

### 3.3 CAC的行业差异  
互联网行业的CAC通常较低，而B2B行业的CAC较高。
