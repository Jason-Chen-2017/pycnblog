# 第3章: 格雷厄姆廉价股投资的算法原理

## 3.1 价值评估的数学模型

### 3.1.1 内在价值的计算公式
$$内在价值 = \frac{股东权益}{股权资本成本}$$

### 3.1.2 安全边际的计算公式
$$安全边际 = 现价 - 内在价值$$

### 3.1.3 市场先生情绪指数
$$市场情绪指数 = \frac{当前股价}{内在价值}$$

## 3.3 格雷厄姆投资策略的Python实现

```python
def calculate_intrinsic_value(shareholders_equity, cost_of_equity):
    return shareholders_equity / cost_of_equity

def calculate_margin_of_safety(current_price, intrinsic_value):
    return current_price - intrinsic_value

# 示例数据
shareholders_equity = 1000  # 股东权益
cost_of_equity = 0.1         # 股权资本成本
current_price = 50           # 当前股价

intrinsic_value = calculate_intrinsic_value(shareholders_equity, cost_of_equity)
margin_of_safety = calculate_margin_of_safety(current_price, intrinsic_value)

print(f"内在价值: {intrinsic_value}")
print(f"安全边际: {margin_of_safety}")
```
