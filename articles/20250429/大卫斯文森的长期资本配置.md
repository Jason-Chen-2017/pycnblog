# 第3章：长期资本配置的算法原理

## 3.1 算法原理讲解

### 3.1.1 现代投资组合理论（MPT）

#### 3.1.1.1 现代投资组合理论的定义
现代投资组合理论（MPT）由哈里·马科维茨提出，强调通过分散投资降低风险，实现收益最大化。

#### 3.1.1.2 MPT 的数学模型
$$ E[r_p] = \sum w_i E[r_i] $$
$$ \sigma_p^2 = \sum \sum w_i w_j \sigma_{ij} $$

其中，$E[r_p]$ 是投资组合的预期收益，$w_i$ 是资产 $i$ 的权重，$E[r_i]$ 是资产 $i$ 的预期收益，$\sigma_{ij}$ 是资产 $i$ 和 $j$ 的协方差。

### 3.1.2 资本资产定价模型（CAPM）

#### 3.1.2.1 CAPM 的定义
CAPM 用于计算资产的预期收益，公式如下：
$$ E[r_i] = r_f + \beta_i (E[r_m] - r_f) $$

其中，$r_f$ 是无风险利率，$\beta_i$ 是资产 $i$ 的贝塔系数，$E[r_m]$ 是市场预期收益。

### 3.1.3 均值-方差优化的 Mermaid 流程图
```mermaid

    A[目标收益] --> B[最小方差]
    B --> C[优化权重]

```

### 3.1.4 Python 代码实现
```python
import numpy as np
import matplotlib.pyplot as plt

# 示例：两资产投资组合的均值-方差优化
mu = np.array([0.1, 0.2])
sigma = np.array([[0.15, 0.1], [0.1, 0.2]])

weights = np.linspace(0, 1, 100)
port_mu = weights * mu[0] + (1 - weights) * mu[1]
port_sigma = np.sqrt(weights**2 * sigma[0, 0] + (1 - weights)**2 * sigma[1, 1] + 2 * weights * (1 - weights) * sigma[0, 1])

plt.plot(port_sigma, port_mu)
plt.xlabel('标准差')
plt.ylabel('预期收益')
plt.title('投资组合的均值-方差曲线')
plt.show()
```

# 第4章：数学模型与公式详解

## 4.1 数学模型的详细讲解

### 4.1.1 均值-方差优化的数学推导
均值-方差优化的目标是最小化投资组合的风险（方差），在给定收益下，或者最大化收益，在给定风险下。

#### 最优化问题
$$ \min_w \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} $$
$$ \text{subject to } \sum_{i=1}^n w_i = 1 $$

### 4.1.2 风险调整后的收益计算
风险调整后的收益可以通过夏普比率来衡量：
$$ \text{夏普比率} = \frac{E[r_p] - r_f}{\sigma_p} $$

### 6.1.2 核心代码实现

```python
import numpy as np

# 示例：计算最优投资组合权重
def optimize_portfolio(mu, sigma, target_return):
    n = len(mu)
    cov_matrix = sigma
    inv_cov = np.linalg.inv(cov_matrix)
    ones = np.ones(n)
    weight = inv_cov @ ones / (ones.T @ inv_cov @ ones)
    return weight

mu = np.array([0.1, 0.2])
sigma = np.array([[0.15, 0.1], [0.1, 0.2]])
weights = optimize_portfolio(mu, sigma, 0.15)
print(weights)
```
