## 第一部分：巴菲特与芒格的投资理念概述

### 第1章：巴菲特的价值投资理念

#### 1.1 巴菲特的投资原则
- **长期投资**：巴菲特强调长期投资的重要性，认为短期波动不应影响投资决策。
- **价值投资**：寻找具有持续竞争优势和良好管理团队的公司，关注企业的内在价值。
- **安全边际**：在投资中保持安全边际，避免过度冒险。

#### 1.2 巴菲特的选股标准
- **ROE（净资产收益率）**：关注企业的盈利能力，ROE是衡量企业效率的重要指标。
- **护城河**：寻找具有强大竞争优势的公司，如专利、品牌或市场准入壁垒。
- **管理团队**：优秀的管理团队是企业长期成功的关键。

### 第2章：芒格的多元思维模型

#### 2.1 多元思维模型的定义
- 多元思维模型是指通过多个学科的思维方式来分析问题，避免单一视角的局限性。

#### 2.2 多元思维模型的应用
- **跨学科分析**：芒格强调将物理学、心理学、经济学等学科的原理结合起来，形成全面的分析框架。
- **决策框架**：通过多元思维模型，芒格能够更好地识别投资机会和风险。

### 第3章：循环经济的定义与特点

#### 3.1 循环经济的基本概念
- 循环经济是一种以资源高效利用和循环利用为核心，以减少资源消耗和环境污染为目标的经济模式。

#### 3.2 循环经济的特点
- **资源高效利用**：通过延长产品生命周期，提高资源利用率。
- **闭环管理**：将废弃物视为资源，实现资源的闭环循环。
- **可持续发展**：循环经济与可持续发展目标高度契合，有助于实现经济与环境的双赢。

import numpy as np
import matplotlib.pyplot as plt

# 数据加载
df = pd.read_csv('financial_data.csv')

# 计算ROE
df['ROE'] = df['Net Profit'] / df['Equity']

# 筛选高ROE和高ESG评分的企业
selected = df[(df['ROE'] > df['ROE'].mean()) & (df['ESG Score'] > 80)]

# 可视化
selected.plot(kind='bar', x='Company', y='ROE')
plt.title('高ROE和高ESG评分的企业')
plt.show()
