#### 3.2 算法实现
```python
def calculate_influence_score(company_data):
    # 计算影响力评分
    esg_score = company_data['esg']
    market_value = company_data['market_value']
    intrinsic_value = company_data['intrinsic_value']
    # 计算影响力评分：结合esg和价值低估程度
    influence_score = esg_score * (intrinsic_value / market_value)
    return influence_score

# 示例数据
company_data = {
    'esg': 0.85,
    'market_value': 100,
    'intrinsic_value': 120
}

score = calculate_influence_score(company_data)
print(f"影响力评分：{score}")
```

#### 3.3 数学模型
- 格雷厄姆内在价值公式：
  $$ \text{内在价值} = \frac{收益}{利率} + \frac{资本支出}{(1 + 利率)} $$
- 影响力评分公式：
  $$ \text{影响力评分} = ESG \times \left( \frac{\text{内在价值}}{\text{市场价值}} \right) $$

#### 5.2 核心代码实现
```python
import pandas as pd

def main():
    # 示例数据加载
    data = pd.DataFrame({
        '公司': ['A', 'B', 'C'],
        'esg': [0.8, 0.9, 0.7],
        '市场价值': [100, 150, 120],
        '内在价值': [120, 160, 130]
    })
    
    # 计算影响力评分
    data['影响力评分'] = data.apply(lambda x: x['esg'] * (x['内在价值'] / x['市场价值']), axis=1)
    
    print(data)

if __name__ == "__main__":
    main()
```
