## 1.1 什么是“关键变量”识别
### 1.1.1 关键变量的定义
关键变量是指在某一特定问题或系统中，对结果产生决定性影响的少数因素。在投资领域，关键变量识别是指通过分析影响投资结果的各种因素，找到其中最关键、最具有决定性的因素。

关键变量识别在投资决策中至关重要，因为它可以帮助投资者聚焦于影响结果的核心因素，忽略次要因素，从而提高决策的效率和准确性。例如，在分析一家公司的投资价值时，关键变量可能是公司的现金流、竞争优势和管理层质量。

### 1.1.3 关键变量识别的核心要素
- **相关性**：变量与结果之间的关联程度。
- **影响力**：变量对结果的影响程度。
- **可测量性**：变量是否可以通过数据或指标进行量化。

```python
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.feature_selection import RFE

# 假设我们有一个数据集 df，其中 target 是目标变量，features 是自变量
# 使用 RFE（递归特征消除）进行特征选择
model = LinearRegression()
selector = RFE(model, n_features_to_select=5)
selector.fit(df[['feature1', 'feature2', 'feature3', 'feature4', 'feature5']], df['target'])

# 输出特征重要性
feature_importance = selector.ranking_
print("特征重要性：", feature_importance)
```
