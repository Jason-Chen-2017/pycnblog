### 第3章：巴菲特与芒格的投资模型

#### 3.1 巴菲特的DCF模型
- **3.1.1 DCF模型的基本原理**  
  现金流折现法（DCF）是评估企业价值的核心工具，公式如下：
  $$\text{企业价值} = \sum_{t=1}^{n} \frac{\text{现金流}}{(1 + r)^t}$$  
  其中，r为贴现率，n为预测年限。

- **3.1.2 DCF模型的数学公式**  
  使用Excel或Python进行DCF模型的计算，例如：
  ```python
  def calculate_intrinsic_value(cash_flows, discount_rate):
      return sum(cash_flow / (1 + discount_rate)**t for t, cash_flow in enumerate(cash_flows))
  ```

- **6.2.1 DCF模型实现**

```python
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate, periods):
    iv = 0
    for t in range(periods):
        iv += cash_flows[t] / (1 + discount_rate) ** t
    return iv

# 示例数据
cash_flows = [100, 200, 300, 400, 500]
discount_rate = 0.1
periods = 5

iv = calculate_intrinsic_value(cash_flows, discount_rate, periods)
print(f"内在价值为：{iv}")
```
