### 第4章：算法原理与实现

#### 4.1 特价股票与公司全球数字创新网络中心度的算法原理
- **4.1.1 PageRank算法原理**
  - **4.1.1.1 算法描述**  
    PageRank算法通过计算节点的入链数量和权重，评估其在网络中的重要性。  
  - **4.1.1.2 算法公式**  
    $$ PR(i) = \sum_{j} \frac{PR(j)}{OutDegree(j)} \times \alpha $$
    其中，$$PR(i)$$ 是节点 $$i$$ 的 PageRank 值，$$OutDegree(j)$$ 是节点 $$j$$ 的出度，$$\alpha$$ 是阻尼因子，通常取 0.85。

- **4.1.2 TF-IDF 算法原理**
  - **4.1.2.1 算法描述**  
    TF-IDF 算法用于评估词袋模型中词项的重要性，常用于文本挖掘和关键词提取。  
  - **4.1.2.2 算法公式**  
    $$ TF-IDF(i,j) = TF(i,j) \times \log\left(\frac{N}{DF(i)}\right) $$
    其中，$$TF(i,j)$$ 是词项 $$i$$ 在文档 $$j$$ 中的词频，$$DF(i)$$ 是词项 $$i$$ 的文档频率，$$N$$ 是文档总数。

#### 4.2 算法实现与代码解读

- **4.2.1 PageRank算法实现**
  ```python
  def pagerank(matrix, alpha=0.85, epsilon=1e-6):
      n = len(matrix)
      rank = [1.0/n for _ in range(n)]
      while True:
          new_rank = [0.0]*n
          for i in range(n):
              for j in range(n):
                  new_rank[i] += matrix[j][i] * rank[j]
              new_rank[i] *= alpha
              new_rank[i] += (1-alpha)
          if max(abs(new_rank[i] - rank[i]) for i in range(n)) < epsilon:
              break
          rank = new_rank
      return rank
  ```

- **4.2.2 TF-IDF算法实现**
  ```python
  from collections import defaultdict

  def compute_tf_idf(documents):
      tf = defaultdict(lambda: defaultdict(int))
      df = defaultdict(int)
      for doc in documents:
          words = doc.split()
          for word in words:
              tf[doc][word] += 1
              df[word] += 1
      tfidf = defaultdict(lambda: defaultdict(float))
      for doc in documents:
          for word in tf[doc]:
              tfidf[doc][word] = (tf[doc][word] / len(doc)) * math.log(len(documents) / df[word])
      return tfidf
  ```
