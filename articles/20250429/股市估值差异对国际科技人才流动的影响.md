  - 其他辅助数据：宏观经济数据、政策数据

#### 5.2 系统核心实现源代码
- 数据预处理代码
  ```python
  import pandas as pd
  import numpy as np

  # 读取数据
  df_market = pd.read_csv('market_valuation.csv')
  df_talent = pd.read_csv('talent_flow.csv')

  # 数据清洗
  df_market.dropna(inplace=True)
  df_talent.dropna(inplace=True)

  # 数据匹配
  merged_df = pd.merge(df_market, df_talent, on=['year', 'country'], how='inner')
  ```

- 模型构建与估计代码
  ```python
  import statsmodels.api as sm

  # 构建面板数据模型
  exog = sm.add_constant(merged_df['valuation_diff'])
  model = sm.OLS(merged_df['talent_flow'], exog)
  results = model.fit()

  # 输出结果
  print(results.summary())
  ```

- 结果分析代码
  ```python
  # 可视化结果
  plt.scatter(merged_df['valuation_diff'], merged_df['talent_flow'])
  plt.plot(merged_df['valuation_diff'], results.predict(), 'r')
  plt.xlabel('Valuation Difference')
  plt.ylabel('Talent Flow')
  plt.show()
  ```
