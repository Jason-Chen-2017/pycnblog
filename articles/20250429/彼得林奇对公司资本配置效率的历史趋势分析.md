### 第3章: 资本配置效率的核心指标与评估方法

#### 3.1 资本配置效率的核心指标
- 资本回报率（ROE）：
  - 定义：ROE = 净利润 / 平均股东权益。
  - 计算公式：$$ROE = \frac{Net\ Profit}{Average\ Equity}$$
  - 评估标准：ROE越高，资本配置效率越高。
- 净资产收益率（ROA）：
  - 定义：ROA = 净利润 / 平均总资产。
  - 计算公式：$$ROA = \frac{Net\ Profit}{Average\ Total\ Assets}$$
  - 评估标准：ROA越高，资本配置效率越高。
- 股东权益回报率（ROE）：
  - 定义：ROE = 净利润 / 平均股东权益。
  - 计算公式：$$ROE = \frac{Net\ Profit}{Average\ Equity}$$
  - 评估标准：ROE越高，资本配置效率越高。

#### 3.2 资本配置效率的评估方法
- 财务指标评估法：
  - 使用ROE、ROA等财务指标评估资本配置效率。
- 经济价值评估法：
  - 通过市值与账面价值的比较，评估资本配置效率。
- 市场价值评估法：

#### 5.2 资本配置效率的计算步骤

3. 综合评估资本配置效率。

#### 5.3 算法实现
- Python代码实现资本配置效率的计算：
  ```python
  def calculate_roe(net_profit, average_equity):
      return net_profit / average_equity
  
  def calculate_roa(net_profit, average_assets):
      return net_profit / average_assets
  
  def capital_allocation_efficiency(net_profit, average_equity, average_assets):
      roe = calculate_roe(net_profit, average_equity)
      roa = calculate_roa(net_profit, average_assets)
      return (roe + roa) / 2
  ```
