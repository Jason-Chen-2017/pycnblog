### 2.1.1 股市估值的核心模型与方法

- 市净率模型：$P/B = \frac{P}{B}$，其中$B$为每股净资产。

## 3.1 算法原理讲解

$$
\text{预测股价} = a \times \text{当前股价} + b \times \text{前日股价} + c \times \text{公共卫生事件影响}
$$

## 3.2 算法实现代码

```python
import pandas as pd
from sklearn.ensemble import RandomForestRegressor

# 数据准备
data = pd.DataFrame({
    '股价': [100, 105, 110, 115],
    '病例数': [1000, 900, 1200, 1300],
    '预测股价': [102, 107, 112, 117]
})

# 模型训练
model = RandomForestRegressor()
model.fit(data[['股价', '病例数']], data['预测股价'])

# 预测
new_data = pd.DataFrame({
    '股价': [120],
    '病例数': [1400]
})
print(model.predict(new_data))
```
