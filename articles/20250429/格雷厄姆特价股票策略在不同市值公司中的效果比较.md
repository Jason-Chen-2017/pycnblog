## 第1章: 格雷厄姆特价股票策略的背景与核心概念

### 1.1 格雷厄姆投资理论的起源与发展

#### 1.1.1 格雷厄姆投资理论的起源

本杰明·格雷厄姆（Benjamin Graham）是价值投资的鼻祖，他的投资理论在20世纪初奠定了现代价值投资的基础。格雷厄姆在《 Intelligent Investor》一书中提出了“安全边际”和“内在价值”等核心概念，强调以低于内在价值的价格购买优质股票。

#### 1.1.2 格雷厄姆投资理论的核心思想

格雷厄姆的核心思想是：股票的价格波动是随机的，投资者应关注公司的基本面，寻找被市场低估的股票。他提出了“特价股票”的概念，即价格远低于其内在价值的股票。

#### 1.1.3 格雷厄姆投资理论的现代发展

尽管格雷厄姆的投资理论距今已有百年历史，但其核心思想至今仍被广泛应用于价值投资领域。现代投资者在实践中对格雷厄姆的理论进行了改进，结合大数据和算法进行更精确的股票筛选。

---

### 1.2 特价股票的定义与特征

#### 1.2.1 特价股票的定义

特价股票是指市场价格低于其内在价值的股票。格雷厄姆提出，内在价值是基于公司基本面分析得出的合理价格，而市场价格受市场情绪影响，可能出现低估。

#### 1.2.2 特价股票的特征

- **低市盈率（P/E）**：市盈率低于行业平均水平。
- **低市净率（P/B）**：市净率低于行业平均水平。
- **高股息率**：股息率高于行业平均水平。
- **低估值指标（如PEG）**：市盈率与盈利增长率的比值低于1。

#### 1.2.3 特价股票与非特价股票的对比

| 特性 | 特价股票 | 非特价股票 |
|------|----------|------------|
| 市盈率 | 低于行业均值 | 高于或等于行业均值 |
| 市净率 | 低于行业均值 | 高于或等于行业均值 |
| 股息率 | 高于行业均值 | 低于或等于行业均值 |

### 1.3 格雷厄姆特价股票策略的适用范围

#### 1.3.1 小盘股的定义与特征

- **小盘股**：市值在50亿以下的公司。
- **特征**：波动性高，市场关注度低，估值可能被低估。

#### 1.3.2 中盘股的定义与特征

- **中盘股**：市值在50亿至500亿之间的公司。
- **特征**：波动性适中，估值可能被低估，风险较低。

#### 1.3.3 大盘股的定义与特征

- **大盘股**：市值在500亿以上的公司。
- **特征**：波动性低，市场关注度高，估值可能被高估。

---

### 1.4 格雷厄姆特价股票策略的核心要素

#### 1.4.1 价值评估的核心指标

- **市盈率（P/E）**：股价与每股收益的比值。
- **市净率（P/B）**：股价与每股净资产的比值。
- **股息率**：股息与股价的比值。

#### 1.4.2 市场情绪的影响

市场情绪会影响股票价格，但格雷厄姆策略的核心是忽略短期市场波动，专注于长期价值。

#### 1.4.3 公司基本面的分析

公司基本面包括收入、利润、资产负债表等财务数据，是评估内在价值的重要依据。

## 第2章: 格雷厄姆特价股票策略的数学模型与算法原理

### 2.1 格雷厄姆特价股票策略的数学模型

#### 2.1.1 市盈率模型

市盈率（P/E）公式：

$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$

#### 2.1.2 市净率模型

市净率（P/B）公式：

$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

#### 2.1.3 股息率模型

股息率公式：

$$ \text{股息率} = \frac{\text{股息}}{\text{股价}} \times 100\% $$

#### 2.1.4 综合评估模型

综合评估模型公式：

$$ \text{综合得分} = w_1 \times (1 - P/E) + w_2 \times (1 - P/B) + w_3 \times \text{股息率} $$

其中，$w_1, w_2, w_3$为各指标的权重。

### 5.2 核心实现代码

```python
import pandas as pd

def calculate_pe(stock_data):
    return stock_data['股价'] / stock_data['每股收益']

def calculate_pb(stock_data):
    return stock_data['股价'] / stock_data['每股净资产']

def calculate_dividend_yield(stock_data):
    return (stock_data['股息'] / stock_data['股价']) * 100

def calculate_composite_score(stock_data, w1=0.4, w2=0.3, w3=0.3):
    pe = calculate_pe(stock_data)
    pb = calculate_pb(stock_data)
    dy = calculate_dividend_yield(stock_data)
    return w1 * (1 - pe) + w2 * (1 - pb) + w3 * dy

# 示例数据
data = {
    '公司': ['公司A', '公司B', '公司C'],
    '股价': [10, 20, 30],
    '每股收益': [2, 3, 4],
    '每股净资产': [5, 6, 7],
    '股息': [1, 2, 3]
}

stock_data = pd.DataFrame(data)

pe = calculate_pe(stock_data)
pb = calculate_pb(stock_data)
dy = calculate_dividend_yield(stock_data)
score = calculate_composite_score(stock_data)

print("市盈率:", pe)
print("市净率:", pb)
print("股息率:", dy)
print("综合得分:", score)
```
