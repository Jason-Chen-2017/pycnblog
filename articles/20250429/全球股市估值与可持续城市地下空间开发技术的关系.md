## 1.1 全球股市估值的定义与影响因素

### 1.1.1 股市估值的定义

股市估值是指通过一定的方法和模型，对上市公司或股票组合的价值进行评估的过程。常见的股市估值方法包括市盈率（P/E）、市净率（P/B）、股息率等。这些指标反映了市场的整体健康状况和个股的投资价值。

### 1.1.2 影响股市估值的主要因素

1. **宏观经济因素**：如GDP增长率、通货膨胀率、利率水平等。

3. **公司基本面**：如收入、利润、资产负债率等。
4. **市场情绪**：投资者的心理预期和市场流动性。

近年来，全球股市估值呈现波动性增长，但受宏观经济环境和政策影响较大。例如，新冠疫情对全球股市估值造成了短期冲击，但随后逐步恢复。

### 2.1.1 股市估值的理论基础

股市估值的理论基础包括有效市场假说和行为金融学。有效市场假说认为，股票价格反映了所有可获取的信息，而行为金融学则强调投资者心理对市场的影响。

### 2.1.2 股市估值的关键指标与模型

- **市盈率（P/E）**：市盈率 = 股价 / 每股净利润。
- **市净率（P/B）**：市净率 = 股价 / 每股净资产。
- **股息率**：股息率 = 每股股息 / 股价。

### 2.1.3 股市估值与宏观经济的关系

宏观经济指标（如GDP增长率、通货膨胀率）对股市估值有直接影响。例如，经济增长率提高通常会推高股市估值。

其中，$y$ 表示股市估值，$x$ 表示可持续地下空间开发技术的推广程度，$\beta_0$ 和 $\beta_1$ 是回归系数，$\epsilon$ 是误差项。

### 4.1.2 算法实现

```python
import numpy as np

from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载

# 特征与目标变量分离

# 模型训练
```

- **优点**：线性回归模型简单易懂，计算效率高。
- **缺点**：线性回归假设变量之间的线性关系，可能无法捕捉复杂的非线性关系。
