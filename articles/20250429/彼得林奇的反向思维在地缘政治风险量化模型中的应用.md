### 第1章：反向思维的定义与原则

#### 1.1 什么是反向思维
反向思维是指在市场普遍看跌时寻找机会买入，而在市场普遍看涨时考虑卖出的策略。这种思维方式强调逆市场情绪进行投资。

#### 1.2 反向思维的核心原则
- **市场情绪的非理性**：市场参与者往往过于乐观或悲观，导致价格偏离内在价值。
- **长期视角**：反向思维需要投资者保持冷静，避免短期波动的干扰。
- **价值投资**：寻找那些被市场低估的资产，长期持有。

#### 1.3 反向思维在投资中的应用
- **选股策略**：关注那些被市场抛弃但具有潜在价值的公司。
- **时机选择**：在市场恐慌时买入，在市场狂热时卖出。

```python
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error

# 数据加载与预处理
data = pd.read_csv('geopolitical_risk_data.csv')
X = data.drop('risk_score', axis=1)
y = data['risk_score']

# 特征工程
X = X.select_dtypes(exclude=['object'])
X = (X - X.mean()) / X.std()  # 标准化

# 模型训练
model = RandomForestRegressor(n_estimators=100, random_forest=0.1)
model.fit(X, y)

# 预测与评估
y_pred = model.predict(X)
print(f"均方误差: {mean_squared_error(y, y_pred)}")

# 反向思维策略应用
# 通过模型预测，识别市场过度反应
threshold = 0.8
anomalies = np.where(y_pred > threshold, '买入', '卖出')
print(anomalies)
```
