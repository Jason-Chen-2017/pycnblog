# 第1章: 格雷厄姆特价股票理论概述

## 1.1 格雷厄姆投资理论的起源与发展

### 1.1.1 价值投资的起源与发展
价值投资是一种长期投资策略，由本杰明·格雷厄姆在20世纪初提出。其核心理念是寻找市场低估的股票，即“烟蒂股”，通过深入分析企业基本面，等待市场重新评估其价值。

### 1.1.2 格雷厄姆的“烟蒂股”投资策略
格雷厄姆强调购买具有安全边际的股票，即市场价格远低于其内在价值。他提出了多个选股标准，包括低市盈率、低市净率和高股息率等。

### 1.1.3 特价股票的定义与特征
特价股票是指市场价格低于其内在价值的股票。其特征包括低市盈率、低市净率、高股息率和稳定的财务状况。

## 1.2 高频算法交易的基本概念

### 1.2.1 高频交易的定义与特点
高频交易是指在极短时间内进行大量交易，利用价格波动和技术优势获取收益。其特点是速度快、算法驱动和高频执行。

### 1.2.2 算法交易的核心原理
算法交易利用数学模型和统计分析，通过算法自动执行交易决策。其核心在于快速分析市场数据，识别价格波动中的获利机会。

### 1.2.3 高频交易与传统交易的对比
高频交易以技术分析为主，而传统交易以基本面分析为主。高频交易强调速度和算法优化，传统交易注重长期价值。

# 第2章: 格雷厄姆特价股票理论的核心原理

## 2.1 格雷厄姆的选股标准

### 2.1.1 市盈率与市净率的计算公式
$$ P/E = \frac{Price}{Earnings} $$
$$ P/B = \frac{Price}{Book\ Value} $$

### 2.1.2 股票安全边际的计算方法
安全边际 = 内在价值 - 市场价格

### 2.1.3 企业内在价值的评估模型
内在价值 = (净利润 × 折现率) / (折现率 - 增长率)

## 2.2 高频交易中的数学模型

### 2.2.1 时间序列分析的基本原理
时间序列分析用于预测未来价格走势，常用ARIMA模型。

### 2.2.2 马科维茨投资组合理论
$$ \text{收益} = \sum_{i=1}^{n} w_i r_i $$
$$ \text{风险} = \sqrt{\sum_{i=1}^{n} \sum_{j=1}^{n} w_i w_j \sigma_i \sigma_j \rho_{ij}} $$

### 2.2.3 高频交易中的统计套利模型
统计套利模型利用市场价差进行无风险套利，常用均值回归策略。

### 5.2.1 格雷厄姆选股模型代码
```python
import pandas as pd
import numpy as np

def calculate_pe(stock_price, earnings):
    return stock_price / earnings

def calculate_pb(stock_price, book_value):
    return stock_price / book_value

def select_undervalued_stocks(stocks, threshold_pe=15, threshold_pb=2):
    undervalued = []
    for stock in stocks:
        pe = calculate_pe(stock['price'], stock['earnings'])
        pb = calculate_pb(stock['price'], stock['book_value'])
        if pe < threshold_pe and pb < threshold_pb:
            undervalued.append(stock)
    return undervalued
```

### 5.2.2 高频交易算法代码
```python
import numpy as np
import pandas as pd

def mean_reversion_strategy(prices, window=20):
    # 计算短期移动平均线
    short_ma = prices.rolling(window=2).mean()
    # 计算长期移动平均线
    long_ma = prices.rolling(window=10).mean()
    # 生成交易信号
    signal = np.where(short_ma > long_ma, 1, -1)
    return signal
```
