# 第一部分：供应链韧性的核心概念与联系

## 第1章：供应链韧性的核心概念

### 1.1 核心概念原理

供应链韧性是指供应链在面对突发事件（如自然灾害、疫情、供应商问题等）时，能够保持稳定运行、快速恢复并灵活调整的能力。它包括以下几个关键属性：

1. **稳定性**：供应链在正常情况下的运作能力。
2. **可恢复性**：供应链在中断后恢复的速度。
3. **多样性**：供应链中供应商和资源的多样性。
4. **可扩展性**：供应链在需求波动时的调整能力。

# 第二部分：供应链韧性评估的算法原理

## 第2章：算法原理概述

### 2.1 层次分析法（AHP）的应用

层次分析法（AHP）是一种常用的决策分析方法，适用于多指标的综合评价。在供应链韧性评估中，AHP可以用于确定各评估指标的权重。

### 2.2 数学模型与公式

#### 2.2.1 供应链韧性评估的数学模型

$$ \text{韧性指数} = \sum_{i=1}^{n} w_i \cdot x_i $$

其中，\( w_i \) 是第 \( i \) 个指标的权重，\( x_i \) 是第 \( i \) 个指标的评分。

#### 2.2.2 风险评估公式

$$ \text{风险值} = \sum_{j=1}^{m} p_j \cdot l_j $$

其中，\( p_j \) 是第 \( j \) 个风险发生的概率，\( l_j \) 是第 \( j \) 个风险的影响程度。

### 2.3 举例说明

假设某公司有两个供应商，A和B。A的可靠性高，但成本较高；B的可靠性低，但成本低。评估模型中，可靠性权重为0.6，成本权重为0.4。计算韧性指数：

$$ \text{韧性指数 (A)} = 0.6 \times 0.9 + 0.4 \times 0.8 = 0.54 + 0.32 = 0.86 $$

$$ \text{韧性指数 (B)} = 0.6 \times 0.3 + 0.4 \times 0.7 = 0.18 + 0.28 = 0.46 $$

```python
# 供应链韧性评估示例代码

def calculate_resilience(supplier_data, weights):
    resilience_index = 0
    for i in range(len(supplier_data)):
        resilience_index += weights[i] * supplier_data[i]
    return resilience_index

# 示例数据
supplier_data = [0.9, 0.8]
weights = [0.6, 0.4]

# 计算韧性指数
resilience = calculate_resilience(supplier_data, weights)
print(f"韧性指数: {resilience}")
```
