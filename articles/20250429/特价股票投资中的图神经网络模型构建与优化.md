# 第一部分: 特价股票投资与图神经网络概述

## 第1章: 特价股票投资的背景与现状

### 1.1 特价股票的定义与特点

- **特价股票**通常指那些价格被市场低估的股票，具有较高的投资潜力。
- 特点：
  - 价格低廉，适合中小投资者。
  - 市场波动较大，投资风险较高。
  - 常被视为市场底部的信号。

### 1.2 股票市场的现状

- 股票市场是复杂的金融生态系统，受多种因素影响：
  - 宏观经济环境。
  - 行业趋势。
  - 公司基本面。
  - 市场情绪。
- 传统投资方法的局限性：
  - 依赖人工分析，效率低。
  - 易受主观因素影响。
  - 难以捕捉复杂市场关系。

### 1.3 图神经网络在金融领域的应用潜力

- 图神经网络（Graph Neural Network, GNN）是一种处理图结构数据的深度学习模型。
- 优势：
  - 能够捕捉复杂的节点间关系。
  - 适合处理金融市场的多维数据。
  - 可以发现隐藏的市场规律。

## 第2章: 图神经网络的核心概念

### 2.1 图结构与节点关系

- 图的定义：
  - 节点（Nodes）：代表股票、公司、行业等。
  - 边（Edges）：代表节点之间的关系，如交易量、价格波动等。
- 图的表示：
  - 使用邻接矩阵或边列表示节点关系。

### 2.2 图神经网络的基本原理

- 聚合函数（Aggregation）：
  - 将邻居节点的信息聚合到当前节点。
  - 常见方法：平均、最大、加权和。
- 传播机制（Propagation）：
  - 信息在图中传播，更新节点表示。
  - 常见方法：图卷积（GCN）、图注意力（GAT）。

### 2.3 图神经网络与传统神经网络的对比

| 对比维度 | 图神经网络 | 传统神经网络 |
|----------|------------|--------------|
| 数据类型 | 图结构数据 | 结构化数据 |
| 处理关系 | 善于处理复杂关系 | 无法处理复杂关系 |
| 应用场景 | 适合金融、社交网络 | 适合图像、文本 |

# 第二部分: 图神经网络模型的核心原理与算法

## 第3章: 图神经网络的数学模型与算法原理

### 3.1 图结构的数学表示

- 邻接矩阵表示：
  - $A$ 是一个$n \times n$的矩阵，$A_{i,j}=1$表示节点$i$和$j$相连。
- 特征矩阵表示：
  - $X$ 是一个$n \times d$的矩阵，$d$是每个节点的特征维度。

### 3.2 图神经网络的基本算法

#### 图卷积网络（Graph Convolutional Network, GCN）

- GCN的传播规则：
  $$ H^{(l+1)} = \sum_{j} A_{i,j} \frac{H_j^{(l)}}{\sum_j A_{i,j}} } $$
  其中，$H^{(l)}$表示第$l$层的节点表示。

#### 图注意力网络（Graph Attention Network, GAT）

- 注意力机制：
  $$ \alpha_{i,j} = \frac{\exp(\text{score}(X_i, X_j))}{\sum_{k} \exp(\text{score}(X_i, X_k))} $$
  其中，$\text{score}$是节点$X_i$和$X_j$的相似性评分。
