## 第2章: 全球股市估值的核心概念

### 2.1 股市估值的基本原理

#### 2.1.1 股票估值的定义与方法
股票估值是衡量企业价值的过程，常用方法包括市盈率和市净率。

#### 2.1.2 市盈率、市净率等关键指标
市盈率=股价/每股收益，市净率=股价/每股净资产。

#### 2.1.3 影响股市估值的主要因素
宏观经济、企业盈利能力和行业趋势。

### 2.2 可降解电子元件技术的定义与特点

#### 2.2.1 可降解电子元件的定义
可降解电子元件是指在特定条件下能够分解的电子元件。

#### 2.2.2 可降解材料的特性与优势
可降解材料具有环保性、可回收性和低污染性。

#### 2.2.3 可降解电子元件的应用场景
医疗、农业、消费电子等领域。

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据预处理
data = pd.read_csv('data.csv')
X = data[['市盈率', '专利数量']]
y = data['股价']

# 训练模型
model = LinearRegression()
model.fit(X, y)

# 评估结果
y_pred = model.predict(X)
print("R² Score:", r2_score(y, y_pred))
```
