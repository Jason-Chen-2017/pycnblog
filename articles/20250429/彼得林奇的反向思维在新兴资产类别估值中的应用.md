#### 第二章：反向思维的核心概念

**2.1 什么是反向思维**

反向思维是一种投资策略，强调在市场低谷时买入，在市场高点时卖出。其核心在于逆市场情绪操作，寻找被低估的机会。

**2.2 市场周期与反向思维**

市场周期分为上升、下降、底部和顶部阶段。反向思维在市场底部阶段买入，在顶部阶段卖出。

**2.3 反向思维的数学模型**

使用均值回归模型，假设市场价格会回归到其历史平均值。公式：$$ \text{目标价格} = \text{历史平均价格} \times (1 \pm \sigma) $$

import pandas as pd
import numpy as np

def reverse_thinking_strategy(prices, window=20):
    # 计算20日平均价格
    avg_price = prices.rolling(window).mean()
    # 识别低于平均价格的信号
    buy_signals = (prices < avg_price).astype(int)
    return buy_signals

# 示例数据
