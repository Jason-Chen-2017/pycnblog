## 第2章：量子计算的核心原理

### 2.1 量子叠加与量子纠缠

量子叠加和量子纠缠是量子计算的核心原理，以下是它们的具体表现：

1. **量子叠加**：一个量子位可以同时表示0和1的概率，例如，量子位的状态可以表示为：
   $$
   |q\rangle = a|0\rangle + b|1\rangle
   $$
   其中，$a$ 和 $b$ 是复数，且满足 $|a|^2 + |b|^2 = 1$。

2. **量子纠缠**：两个量子位可以形成纠缠态，例如：
   $$
   |q_1 q_2\rangle = \frac{1}{\sqrt{2}}(|01\rangle + |10\rangle)
   $$
   当其中一个量子位的状态确定后，另一个量子位的状态也会立即确定。

### 2.2 量子算法的基本类型

量子算法是量子计算的核心，以下是几种常用的量子算法：

1. **Grover算法**：用于在无序数据库中进行搜索，可以在 $O(\sqrt{N})$ 时间内找到目标元素，而经典算法需要 $O(N)$ 时间。
2. **Shor算法**：用于大整数分解和质因数分解，广泛应用于密码学和金融建模。
3. **量子傅里叶变换**：用于信号处理和模式识别。

```python
from qiskit import QuantumCircuit, execute, Aer
from qiskit.circuit import Grover

def grover_algorithm(n_qubits):
    qc = QuantumCircuit(n_qubits)
    # 构建Grover算法电路
    grover = Grover(n_qubits)
    qc.append(grover, range(n_qubits))
    # 添加测量
    qc.measure(range(n_qubits), range(n_qubits))
    return qc

# 执行量子计算
n_qubits = 3
qc = grover_algorithm(n_qubits)
backend = Aer.get_backend('qasm_simulator')
job = execute(qc, backend)
result = job.result()
print(result.get_counts())
```
