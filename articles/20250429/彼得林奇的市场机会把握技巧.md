## 第4章：市场机会识别的数学模型
### 4.1 市场机会评估的核心公式
$$
\text{内在价值} = \sum_{t=1}^{\infty} \frac{\text{现金流}}{(1 + r)^t}
$$

### 4.2 成长股评估模型
$$
\text{预期收益率} = \frac{\text{净利润增长率} \times \text{当前股价}}{\text{市盈率}}
$$

### 4.3 价值股评估模型
$$
\text{安全边际} = \text{市场价格} - \text{内在价值}
$$

### 5.2 算法实现的Python代码
```python
import pandas as pd

def calculate_intrinsic_value(earnings_growth_rate, discount_rate, free_cash_flow):
    """
    计算内在价值
    """
    # 使用永续年金公式
    iv = free_cash_flow / (discount_rate - earnings_growth_rate)
    return iv

# 示例数据
earnings_growth_rate = 0.08  # 8% 的净利润增长率
discount_rate = 0.12          # 12% 的折现率
free_cash_flow = 100         # 自由现金流

intrinsic_value = calculate_intrinsic_value(earnings_growth_rate, discount_rate, free_cash_flow)
print(f"内在价值: {intrinsic_value}")
```
