## 第3章：高管团队稳定性评估模型

### 3.1 稳定性评估指标体系

#### 3.1.1 高管团队稳定性评估指标  
- **高管任期**：高管在公司服务的时间
- **变动频率**：高管团队成员的变动次数
- **团队协作能力**：高管团队内部的协作能力

#### 3.1.2 指标权重的确定方法  
- 使用层次分析法（AHP）确定各指标的权重
- 示例：
  - 高管任期权重：0.5
  - 变动频率权重：0.3
  - 团队协作能力权重：0.2

#### 3.1.3 指标体系的构建过程  
- 确定评估指标
- 确定指标权重
- 综合各指标计算稳定性指数

### 3.3 稳定性评估模型的数学表达

#### 3.3.1 稳定性指数计算公式  
$$ S = \sum_{i=1}^{n} w_i \cdot x_i $$  
其中，\( w_i \) 是指标 \( i \) 的权重，\( x_i \) 是指标 \( i \) 的得分。

#### 3.3.2 指标权重计算方法  
$$ w_i = \frac{f_i}{\sum_{j=1}^{m} f_j} $$  
其中，\( f_i \) 是指标 \( i \) 的影响程度，\( m \) 是指标总数。

#### 3.3.3 示例计算与分析  
假设某公司高管团队稳定性评估指标如下：
- 高管任期：5年，权重0.5
- 变动频率：0，权重0.3
- 团队协作能力：强，权重0.2

稳定性指数计算：
$$ S = 0.5 \times 5 + 0.3 \times 0 + 0.2 \times 3 = 2.5 + 0 + 0.6 = 3.1 $$  
稳定性指数为3.1，属于较高稳定。

```python
import pandas as pd
import numpy as np

def calculate_stability_index(company_data):
    # 加权计算稳定性指数
    weights = {' tenure': 0.5, ' turnover_rate': 0.3, ' collaboration_strength': 0.2}
    stability_index = 0
    for member in company_data['executive_team']:
        stability_index += weights[' tenure'] * member['tenure'] + \
                           weights[' turnover_rate'] * (1 - member['turnover_rate']) + \
                           weights[' collaboration_strength'] * member['collaboration_strength']
    return stability_index
```
