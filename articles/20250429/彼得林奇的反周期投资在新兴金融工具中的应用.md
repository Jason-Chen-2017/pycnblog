## 第1章: 反周期投资的基本概念

### 1.1 反周期投资的定义与特点
反周期投资是一种逆向投资策略，旨在在市场低谷期买入，市场高峰期卖出。其核心特点包括：
- **低买高卖**：在市场低迷时布局，市场回升时获利。
- **逆向思维**：与市场情绪相反，避免追涨杀跌。
- **长期视角**：注重长期价值，而非短期波动。

### 1.2 彼得·林奇的投资理念
彼得·林奇是反周期投资的代表人物，他强调：
- **价值投资**：寻找被市场低估的资产。
- **分散投资**：通过多样化降低风险。
- **耐心持有**：长期持有优质资产，等待市场回升。

## 第4章: 反周期投资策略在新兴金融工具中的应用

### 4.1 ETF与指数基金的反周期投资策略
- **市场低谷期**：买入指数基金，分散风险。
- **市场高峰期**：卖出ETF，锁定收益。

#### 代码示例：ETF投资组合优化

```python
import pandas as pd
import numpy as np

# 模拟ETF价格数据
prices = pd.DataFrame(np.random.lognormal(mean=0.05, sigma=0.1, size=(100, 5)), columns=['ETF1', 'ETF2', 'ETF3', 'ETF4', 'ETF5'])
# 计算最优投资组合
def optimal_portfolio(prices):
    returns = prices.pct_change().dropna()
    cov_matrix = returns.cov()
    inv_cov = np.linalg.inv(cov_matrix)
    weights = inv_cov.mean(axis=1) / inv_cov.mean(axis=1).sum()
    return weights

weights = optimal_portfolio(prices)
print("最优权重:", weights)
```

### 4.2 期权与衍生品的反周期投资策略
- **对冲风险**：利用期权锁定价格。
- **套利机会**：在价差中获利。

#### 代码示例：期权套利策略

```python
import numpy as np

# 模拟期权价格数据
call_prices = np.random.lognormal(mean=0.02, sigma=0.15, size=100)
put_prices = np.random.lognormal(mean=0.02, sigma=0.15, size=100)

# 计算套利机会
def option_arbitrage(call, put):
    profit = call - put
    return profit > 0

arbitrage_opportunity = option_arbitrage(call_prices, put_prices)
print("套利机会:", arbitrage_opportunity.mean())
```

### 4.3 比特币与加密货币的反周期投资策略
- **低谷期布局**：在比特币价格低点买入。
- **高峰期卖出**：锁定收益。

#### 代码示例：比特币价格预测

### 5.2 风险管理与投资组合优化
- **止损策略**：设定止损点，避免重大损失。
- **分散投资**：通过多样化降低风险。

#### 代码示例：风险管理策略

```python
import numpy as np

# 模拟投资组合收益
returns = np.random.lognormal(mean=0.05, sigma=0.15, size=100)
# 设置止损阈值
stop_loss = -0.15
# 计算止损后的收益
def apply_stop_loss(returns, stop_loss):
    filtered_returns = []
    for r in returns:
        if not filtered_returns:
            filtered_returns.append(r)
        else:
            if filtered_returns[-1] < stop_loss:
                filtered_returns.append(stop_loss)
            else:
                filtered_returns.append(r)
    return filtered_returns

optimized_returns = apply_stop_loss(returns, stop_loss)
print("优化后收益:", optimized_returns)
```
