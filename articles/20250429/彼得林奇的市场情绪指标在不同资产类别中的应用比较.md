### 5.2.2 指标计算代码

```python
def calculate_peter_lynch_indicator(data):
    # 计算市场波动率
    volatility = data['close'].pct_change().std()
    # 计算市场成交量
    volume = data['volume'].mean()
    # 计算彼得林奇情绪指标
    peter_lynnch_indicator = volatility / volume
    return peter_lynnch_indicator

peter_lynnch_indicator = calculate_peter_lynch_indicator(data)
print(peter_lynnch_indicator)
```
