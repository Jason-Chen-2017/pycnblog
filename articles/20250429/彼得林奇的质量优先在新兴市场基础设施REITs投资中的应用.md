## 第一部分：引言

### 1.1 REITs投资概述

#### 1.1.1 REITs的基本概念
房地产投资信托基金（REITs）是通过汇集投资者的资金，投资于房地产及相关资产的一种金融工具。REITs的投资者可以通过购买其股票或债券，间接持有房地产资产并获得收益。

#### 1.1.2 REITs的分类与特点
REITs主要分为两类：股权型REITs和抵押型REITs。股权型REITs直接持有房地产资产，而抵押型REITs则通过发放房地产抵押贷款获得收益。新兴市场中的基础设施REITs通常属于股权型，因其聚焦于基础设施项目而具有较高的增长潜力。

#### 1.1.3 新兴市场中的REITs发展现状
新兴市场（如东南亚、印度和拉丁美洲）的基础设施REITs近年来发展迅速。这些市场通常具有较高的经济增长潜力，但也伴随着较高的风险和不确定性。

```python
import numpy as np

def optimize_portfolio(weights, returns, risk_free_rate):
    # 计算协方差矩阵
    covariance_matrix = np.cov(returns)
    
    # 构建目标函数
    def objective(weights):
        return np.dot(weights.T, covariance_matrix @ weights)
    
    # 约束条件
    constraints = {
        'type': 'eq',
        'fun': lambda w: np.sum(w) - 1
    }
    
    # 最优化求解
    from scipy.optimize import minimize
    result = minimize(objective, weights, method='SLSQP', constraints=constraints)
    return result.x
```
