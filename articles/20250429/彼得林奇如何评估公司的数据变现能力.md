#### 3.3 数据质量评分算法实现  
```python
def data_quality_score(data):
    completeness = len(data.dropna()) / len(data)
    consistency = data.dropna().duplicated().sum() / len(data)
    return completeness * 0.4 + consistency * 0.6
```
