## 第一部分：价值投资与新兴行业概述

### 第1章：价值投资的核心理念

#### 1.1 价值投资的定义与原则
- **价值投资**：一种长期投资策略，强调以低于公平价值的价格购买优质资产。
- **彼得林奇的理念**：寻找那些被市场低估的优秀公司，长期持有，等待其价值回归。
- **核心原则**：
  1. 长期投资，而非短期交易。
  2. 专注于基本面分析。
  3. 风险控制与分散投资。

#### 1.2 新兴行业的特点与挑战
- **新兴行业**：指那些快速成长、技术创新驱动的行业，如科技、医疗、新能源等。
- **行业特点**：
  1. 增长潜力大，但波动性高。
  2. 技术更新快，竞争激烈。
  3. 市场容量大，但不确定性高。
- **挑战**：
  1. 估值困难：新兴行业公司可能尚未盈利，传统估值指标失效。
  2. 风险较高：行业波动大，政策变化快。
  3. 竞争激烈：行业内企业数量多，竞争加剧。

## 第二部分：新兴行业中的价值投资策略

### 第3章：行业分析与投资决策

#### 3.1 行业分析方法
- **行业生命周期分析**：
  - 初创期：高风险，高潜力。
  - 增长期：快速扩张，竞争加剧。
  - 成熟期：稳定增长，估值合理。
  - 衰退期：增长放缓，估值下降。
- **行业竞争结构分析**：
  - 五力分析模型（迈克尔·波特）：
    1. 新进入者的威胁。
    2. 替代品的威胁。
    3. 供应商的议价能力。
    4. 客户的议价能力。
    5. 行业内部竞争。
- **行业财务指标分析**：
  - 增长率：收入和利润的增长情况。
  - 净利率：盈利能力。
  - 负债率：财务风险。

#### 3.2 投资决策模型
- **基于价值的投资决策模型**：
  - 市盈率（P/E）= 股价 / 净利润
  - 市净率（P/B）= 股价 / 净资产
  - 企业价值（EV）= 市价 + 净债务
- **基于成长性的投资决策模型**：
  - 营收增长率 = (本期营收 - 上期营收) / 上期营收
  - 净利润增长率 = (本期净利润 - 上期净利润) / 上期净利润
  - 内部收益率（IRR）：评估投资项目回报率。

#### 4.1 科技行业的价值投资

  - 市场空间大，竞争激烈。
  - 估值波动大，市盈率高。
- **典型案例分析**：
  - 公司A：技术创新领先，市场份额稳步提升。
  - 公司B：财务状况健康，但增长潜力有限。
- **投资经验总结**：
  1. 选择具有持续创新能力的企业。
  2. 关注管理层的战略布局。
  3. 耐心持有，避免短期波动干扰。

#### 4.2 医疗行业的价值投资
- **医疗行业的特点**：
  - 市场需求稳定，政策支持强。
  - 技术门槛高，研发投入大。
  - 行业整合频繁。
- **典型案例分析**：
  - 公司C：专注于创新药物研发，市场前景广阔。
  - 公司D：通过并购快速扩大市场份额。
- **投资经验总结**：
  1. 重点关注创新能力强的企业。
  2. 注意政策风险，避免受政策波动影响。
  3. 关注行业整合机会。

### 第6章：项目实战

#### 6.2 核心代码实现
- **代码实现**：
  ```python
  import pandas as pd
  import numpy as np

  def calculate_pe(stock_price, net_profit):
      return stock_price / net_profit

  def calculate_pb(stock_price, book_value):
      return stock_price / book_value

  def calculate_ev(stock_price, net_debt):
      return stock_price + net_debt

  # 示例数据
  data = {
      '公司': ['A', 'B', 'C'],
      '股价': [100, 80, 120],
      '净利润': [20, 15, 30],
      '净资产': [50, 40, 60],
      '净债务': [10, 20, 15]
  }

  df = pd.DataFrame(data)

  # 计算市盈率和市净率
  df['市盈率'] = df.apply(lambda x: calculate_pe(x['股价'], x['净利润']), axis=1)
  df['市净率'] = df.apply(lambda x: calculate_pb(x['股价'], x['净资产']), axis=1)
  df['企业价值'] = df.apply(lambda x: calculate_ev(x['股价'], x['净债务']), axis=1)

  print(df)
  ```

#### 6.3 代码应用解读
- **代码解读**：
  - `calculate_pe`：计算市盈率。
  - `calculate_pb`：计算市净率。
  - `calculate_ev`：计算企业价值。
  - 数据分析：通过DataFrame计算并展示估值指标。
