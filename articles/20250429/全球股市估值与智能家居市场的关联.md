## 第二部分：核心概念与联系

### 第2章：核心概念分析

#### 2.1 股市估值的核心要素
- **市盈率（P/E Ratio）**
  - 计算公式：P/E = 市价 / 每股收益
  - 反映市场对公司的未来盈利能力的预期
- **市净率（P/B Ratio）**
  - 计算公式：P/B = 市价 / 每股净资产
  - 用于评估股票价格是否合理
- **市值与股价的关系**
  - 市值 = 股价 × 总股本
  - 反映企业的市场价值

#### 2.2 智能家居市场的核心要素
- **市场规模**
  - 全球智能家居市场规模统计（数据来源：权威市场报告）
  - 市场增长的驱动力：技术创新、消费者需求变化
- **市场渗透率**
  - 定义：智能家居产品在目标市场的普及程度
  - 影响因素：价格、技术成熟度、消费者接受度
- **产品生命周期**
  - 不同阶段对市场估值的影响

#### 2.3 股市估值与智能家居市场的关联性
- **正向关联：技术进步推动股市估值上升**
  - 创新企业研发投入与股市表现的关系
- **反向关联：市场饱和导致股市估值下降**
  - 市场竞争加剧的影响
- **动态关联：宏观经济因素的调节作用**
  - 利率变化、通货膨胀对股市和智能家居市场的影响

#### 3.2 特征提取与选择
- **关键特征识别**
  - 股市相关指标：市盈率、市净率、股价波动率
  - 市场相关指标：市场规模、增长率、渗透率
- **特征工程**
  - 组合特征的构建：如市盈率与智能家居市场增长率的结合
  - 特征的重要性评估

#### 3.3 关联性分析方法
- **相关系数分析**
  - 使用皮尔逊相关系数（Pearson correlation）或斯皮尔曼相关系数（Spearman correlation）
  - 计算公式：$$ r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \sum (y_i - \bar{y})^2}} $$
- **回归分析**
  - 线性回归模型：$$ y = \beta_0 + \beta_1 x + \epsilon $$
  - 用于预测股市估值对智能家居市场的依赖程度

#### 3.4 聚类分析
- **K-means聚类**
  - 将数据分为不同的市场阶段，如“增长期”、“成熟期”、“衰退期”
  - 确定每个阶段的特征

#### 3.5 分类分析
- **决策树模型**
  - 分类市场阶段，预测未来市场走势
  - 使用ID3、C4.5或CART算法

import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 示例数据加载
def load_data():
    stock_data = pd.read_csv('stock_data.csv')
    home_appliance_data = pd.read_csv('home_appliance_data.csv')
    return stock_data, home_appliance_data

# 数据预处理
def preprocess(data):
    # 处理缺失值
    data = data.dropna()
    # 标准化处理
    from sklearn.preprocessing import StandardScaler
    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data)
    return data_scaled

# 训练模型
def train_model(X, y):
    model = LinearRegression()
    model.fit(X, y)
    return model, model.score(X, y)

# 预测与评估
def evaluate(model, X_test, y_test):
    y_pred = model.predict(X_test)
    r2 = r2_score(y_test, y_pred)
    print(f"R² Score: {r2}")

# 主函数
def main():
    stock_data, home_appliance_data = load_data()
    # 合并数据
    merged_data = pd.merge(stock_data, home_appliance_data, on='日期')
    # 提取特征与目标变量
    X = merged_data[['市盈率', '智能家居市场规模']]
    y = merged_data['股票指数']
    # 数据预处理
    X_processed = preprocess(X)
    # 训练模型
    model, score = train_model(X_processed, y)
    print(f"模型训练完成，R²: {score}")
    # 预测与评估
    evaluate(model, X_processed, y)

if __name__ == "__main__":
    main()
```
