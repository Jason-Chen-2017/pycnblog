## 第一部分：全球股市估值

### 第1章：全球股市估值概述

#### 1.1 股市估值的基本概念
- 1.1.1 股市估值的定义与重要性
  - 股市估值是通过对公司财务数据和市场因素的分析，确定股票的合理价格。
  - 股票价格反映了企业的价值，是投资者决策的重要依据。
- 1.1.2 股市估值的核心要素
  - 财务数据：收入、利润、现金流等。
  - 市场因素：宏观经济、行业趋势、投资者情绪等。
- 1.1.3 全球股市估值的发展趋势
  - 数据驱动的量化估值方法逐渐取代传统经验判断。
  - 技术进步推动估值模型的创新。

#### 1.2 股市估值的主要方法
- 1.2.1 市盈率（P/E）法
  - 市盈率=股价/每股收益。
  - 适用于盈利稳定的公司。
- 1.2.2 市净率（P/B）法
  - 市净率=股价/每股净资产。
  - 适用于净资产驱动的公司。
- 1.2.3 现金流折现法（DCF）
  - 将未来现金流折现，计算内在价值。
  - 常用于高成长性公司。

### 第2章：股市估值的核心模型

#### 2.1 股票估值的数学模型
- 2.1.1 常用股票估值公式
  - 市盈率公式：$$ P/E = \frac{P}{E} $$
  - 现金流折现公式：$$ DCF = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n} $$
- 2.1.2 模型的优缺点对比
  - 市盈率法简单易懂，但受行业和市场环境影响较大。
  - DCF法精确但计算复杂，需假设未来现金流。

      dcf = 0
      for t in range(len(cash_flows)):
          dcf += cash_flows[t] / (1 + discount_rate) ** t
      dcf += terminal_value / (1 + discount_rate) ** len(cash_flows)
      return dcf

  # 示例计算

  terminal_value = 200
