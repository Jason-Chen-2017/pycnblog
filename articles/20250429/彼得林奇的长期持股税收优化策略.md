## 背景介绍

### 1.1 长期持股策略的基本概念

长期持股策略是指投资者购买优质股票后，长期持有，以获得资本增值。这种策略强调基本面分析和长期价值，避免频繁交易带来的成本和税费。

#### 1.1.1 长期持股的定义与特点

- **定义**：长期持股是指投资者持有股票超过一年，以享受较低的资本利得税税率。
- **特点**：
  - 长期视角：关注企业的长期价值。
  - 低交易成本：减少交易频率，降低成本。
  - 税收优化：享受较低的资本利得税率。

### 1.2 彼得林奇投资理念的核心要素

彼得林奇是著名的投资专家，其长期持股策略强调投资优质企业，长期持有，避免频繁交易。

#### 1.2.1 彼得林奇的投资哲学

- **价值投资**：寻找基本面良好的企业。
- **长期视角**：关注企业的长期增长潜力。
- **分散投资**：通过多样化降低风险。

### 1.3 税收优化的重要性

税收是影响投资回报的重要因素，优化税收可以提升整体收益。

#### 1.3.1 税收对投资回报的影响

- 资本利得税：持有时间影响税率，长期持有享受较低税率。
- 股息税：不同税收政策影响股息收入的税务负担。

import pandas as pd

def calculate_capital_gains(taxable_income, holding_period):
    short_term_tax = 0.3
    long_term_tax = 0.15
    if holding_period < 1:
        return taxable_income * (1 - short_term_tax)
    else:
        return taxable_income * (1 - long_term_tax)
