### 第2章：脑机接口技术的核心原理

#### 2.1 脑机接口技术的定义与原理
- 脑机接口（BCI）：通过采集和分析大脑产生的生物信号，将其转化为可被计算机识别的指令。
- 信号采集：包括EEG（脑电图）、EMG（肌电图）、EDA（皮肤电活动）等。
- 信息解码：通过机器学习算法分析生理数据，识别情绪状态。

#### 2.2 股市估值的核心原理
- 估值模型：基于历史数据和市场行为，预测未来股价。
- 影响股价的因素：市场情绪、宏观经济指标、公司基本面。
- 数据驱动的估值方法：利用大数据和机器学习提升预测精度。

##### 数据预处理
```python
import numpy as np
from scipy.signal import filter_design

# 示例：心率数据的滤波处理
def preprocess_eeg(eeg_signal, sampling_rate=100):
    # 设计带通滤波器
    low = 0.5
    high = 50
    b, a = filter_design.iirfilter(4, [low/sampling_rate*2, high/sampling_rate*2], 
                                    btype='bandpass', ftype='butter')
    # 应用滤波器
    filtered_signal = np.convolve(eeg_signal, a, mode='full')[:len(eeg_signal)]
    return filtered_signal
```
