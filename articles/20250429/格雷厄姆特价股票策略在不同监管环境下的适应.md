## 第1章: 格雷厄姆特价股票策略的核心理论

### 1.1 格雷厄姆投资理论的起源与发展

格雷厄姆投资理论是价值投资的鼻祖，其核心理念是“安全边际”。格雷厄姆认为，股票的价值应基于其内在价值进行评估，而非市场的短期波动。这种理论在20世纪初提出，至今仍被广泛应用于投资领域。

#### 核心概念与联系

**价值投资**与**成长投资**的区别可以通过以下表格对比：

| 比较维度 | 价值投资 | 成长投资 |
|----------|----------|----------|
| 核心理念 | 买入低于内在价值的股票 | 投资于高成长性公司 |
| 估值方法 | 市盈率、市净率等 | 市盈率、预期增长率等 |
| 风险管理 | 强调安全边际 | 更注重长期增长潜力 |

### 1.2 特价股票的定义与特征

特价股票是指市场价格低于其内在价值的股票。其特征包括低市盈率、低市净率、高股息率等。

#### 算法原理讲解

**内在价值计算公式**：

$$ V = \frac{E}{k} $$

其中，\( E \) 是企业的盈利价值，\( k \) 是资本化率。

### 1.3 格雷厄姆策略在现代投资中的应用

格雷厄姆策略在现代投资中依然适用，但需要结合市场环境进行调整。例如，在科技股占主导的市场中，传统价值指标可能不再适用。

#### 监管政策对市场流动性的影响

监管政策会影响市场的流动性和投资者行为。

## 第4章: 格雷厄姆策略的数学模型与算法实现

### 4.1 格雷厄姆策略的数学模型

#### 内在价值计算公式

$$ V = \frac{E}{k} $$

其中，\( E \) 是企业的盈利价值，\( k \) 是资本化率。

#### 市场价格与内在价值的比较

$$ \text{价值比} = \frac{V}{P} $$

其中，\( V \) 是内在价值，\( P \) 是市场价格。

### 4.2 格雷厄姆策略的算法实现

#### Python代码实现

```python
def calculate_intrinsic_value(enterprise_value, capitalization_rate):
    return enterprise_value / capitalization_rate

def graham_strategy(ticker, enterprise_value, capitalization_rate, market_price):
    iv = calculate_intrinsic_value(enterprise_value, capitalization_rate)
    value_ratio = iv / market_price
    if value_ratio > 1.5:
        return "买入"
    else:
        return "观望"

# 示例
enterprise_value = 1000000
capitalization_rate = 0.05
market_price = 50
print(graham_strategy("AAPL", enterprise_value, capitalization_rate, market_price))

import pandas as pd
import numpy as np

def calculate_intrinsic_value(enterprise_value, capitalization_rate):
    return enterprise_value / capitalization_rate

def graham_strategy(ticker, enterprise_value, capitalization_rate, market_price):
    iv = calculate_intrinsic_value(enterprise_value, capitalization_rate)
    value_ratio = iv / market_price
    if value_ratio > 1.5:
        return f"{ticker} - 买入"
    else:
        return f"{ticker} - 观望"

# 示例数据
data = {
    'Ticker': ['AAPL', 'GOOGL', 'MSFT'],
    'Enterprise Value': [1000000, 1500000, 2000000],
    'Capitalization Rate': [0.05, 0.06, 0.04],
    'Market Price': [50, 75, 60]
}

df = pd.DataFrame(data)

# 应用策略
results = []
for index, row in df.iterrows():
    result = graham_strategy(row['Ticker'], row['Enterprise Value'], row['Capitalization Rate'], row['Market Price'])
    results.append(result)

print(results)
```
