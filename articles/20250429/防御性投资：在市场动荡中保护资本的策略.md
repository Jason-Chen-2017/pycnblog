### 第1章：防御性投资的背景与目标

#### 1.1 市场波动与投资风险
- **1.1.1 市场波动的定义与特征**  
  市场波动是指资产价格在短时间内剧烈波动的现象，通常由市场情绪、经济基本面变化或外部事件引发。波动性越高，投资风险越大。

- **1.1.2 投资风险的分类**  
  - 系统性风险：影响整个市场的风险，如经济衰退、通货膨胀等。  
  - 非系统性风险：特定资产或行业的风险，如公司违约、行业政策变化等。  

- **1.1.3 防御性投资的必要性**  
  在市场波动加剧的情况下，防御性投资能够通过分散投资、降低风险敞口等方式，帮助投资者在市场下跌时减少损失，实现资本保值。

#### 1.2 防御性投资的核心目标
- **1.2.1 资本保值的重要性**  
  防御性投资的核心目标是确保资本不受损失或尽量减少损失，而不是追求超额收益。

- **1.2.2 风险控制与收益平衡**  
  防御性投资强调在控制风险的前提下，通过稳定的投资收益实现资本增值。

- **1.2.3 长期投资策略的制定**  
  防御性投资注重长期视角，通过持续优化投资组合，在市场周期中保持稳健收益。

#### 1.3 防御性投资的边界与外延
- **1.3.1 投资范围的界定**  
  防御性投资主要集中在低风险资产，如债券、黄金、房地产等，同时也包括优质股票和ETF。

- **1.3.2 防御性与进攻性投资的区分**  
  - 防御性投资：以资本保值为核心，注重风险控制。  
  - 进攻性投资：以追求超额收益为目标，风险承受能力较高。  

- **1.3.3 防御性投资的适用场景**  
  在市场下行周期或经济不确定性增加时，防御性投资策略尤为重要。

#### 1.4 防御性投资的核心要素
- **1.4.1 资产配置的多样性**  
  通过分散投资不同资产类别，降低投资组合的整体风险。

- **1.4.2 风险管理的系统性**  
  建立完善的风险评估和监控体系，及时调整投资策略。

- **1.4.3 投资纪律的严格性**  
  遵循既定的投资策略和纪律，避免情绪化决策。

#### 1.5 本章小结
本章通过分析市场波动与投资风险的关系，明确了防御性投资的核心目标和实施边界，为后续章节的策略分析奠定了基础。

### 第3章：防御性投资的数学模型与算法原理

#### 3.1 风险评估模型
- **3.1.1 夏普比率**  
  夏普比率衡量投资组合相对于其风险的超额收益能力。  
  $$ \text{夏普比率} = \frac{E[r_i] - r_f}{\sigma_i} $$  
  其中，$E[r_i]$ 是投资组合的预期收益，$r_f$ 是无风险利率，$\sigma_i$ 是投资组合的收益波动率。

- **3.1.2 风险调整后收益**  
  通过夏普比率，投资者可以在不同风险水平下比较不同投资组合的收益表现。

#### 3.2 投资组合优化算法
- **3.2.1 现代投资组合理论（MPT）**  
  MPT通过优化投资组合的收益与风险比，找到最优资产配置。  
  ```mermaid
  graph TD
      I[投资者] --> M[市场]
      M --> P[价格波动]
      P --> R[风险]
      R --> O[优化]
      O --> S[最优组合]
  ```

- **3.2.2 数学公式**  
  投资组合优化的目标是最大化夏普比率：  
  $$ \max \frac{E[r_p] - r_f}{\sigma_p} $$  
  其中，$r_p$ 是投资组合的收益，$\sigma_p$ 是投资组合的波动率。

#### 3.3 数学公式
- **夏普比率计算示例**  
  假设投资组合的预期收益为8%，无风险利率为2%，投资组合的波动率为5%。  
  $$ \text{夏普比率} = \frac{8\% - 2\%}{5\%} = 1.2 $$

#### 5.2 核心实现

```python
import numpy as np
import pandas as pd

# 示例：计算投资组合的夏普比率
def calculate_sharpe_ratio(returns, risk_free_rate):
    excess_returns = returns - risk_free_rate
    sharpe_ratio = excess_returns.mean() / excess_returns.std()
    return sharpe_ratio

# 数据加载与处理
data = pd.read_csv('assets.csv')
returns = data.pct_change().dropna()

# 计算夏普比率
sharpe_ratio = calculate_sharpe_ratio(returns, 0.02)
print(f"夏普比率：{sharpe_ratio}")
```
