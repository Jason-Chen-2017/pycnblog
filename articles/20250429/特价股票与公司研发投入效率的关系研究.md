## 第1章: 特价股票的定义与特征

### 1.1 特价股票的定义
- **特价股票**：指股价低于行业平均水平或历史平均值的股票，通常具有高波动性和高潜在回报。
- **市场特征**：流动性较低、风险较高、可能处于困境或转型期。

### 1.2 公司研发投入效率的定义
- **研发投入**：公司用于产品开发、技术创新的资金投入。
- **效率衡量**：研发投入与收益的比率，如研发投入占销售收入的比例。

import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据处理

X = data[['研发费用率', '销售收入']]

# 模型训练
