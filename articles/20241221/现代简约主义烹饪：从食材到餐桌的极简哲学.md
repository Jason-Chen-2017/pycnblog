#### 案例一：简易蔬菜沙拉

**食材准备**：

- 新鲜生菜：200克
- 番茄：1个
- 洋葱：半个
- 红椒：1个
- 芝麻：适量
- 橄榄油：适量
- 盐：适量
- 胡椒粉：适量

**烹饪过程**：

1. 将生菜洗净，切成小块。
2. 番茄洗净，切成小块。
3. 洋葱去皮，切成细丝。
4. 红椒去籽，切成细丝。
5. 将切好的蔬菜放入大碗中。
6. 加入适量的橄榄油、盐和胡椒粉，搅拌均匀。
7. 最后撒上芝麻，即可享用。

**成果展示**：

这款简易蔬菜沙拉不仅制作简单，而且营养丰富，口感清爽。它适合作为午餐或晚餐的配菜，既能满足口感，又能提供足够的营养。

#### 案例二：烤鸡胸肉配蔬菜

**食材准备**：

- 鸡胸肉：2块
- 胡萝卜：1根
- 菠菜：适量
- 洋葱：1个
- 蒜末：适量
- 盐：适量
- 胡椒粉：适量
- 橄榄油：适量

**烹饪过程**：

1. 鸡胸肉洗净，切成薄片。
2. 胡萝卜去皮，切成薄片。
3. 洋葱去皮，切成薄片。
4. 菠菜洗净，沥干水分。
5. 将切好的胡萝卜和洋葱放入碗中，加入蒜末、盐和胡椒粉，搅拌均匀。
6. 将鸡胸肉放入另一个碗中，加入橄榄油、盐和胡椒粉，搅拌均匀。
7. 将搅拌好的蔬菜铺在烤盘底部，将鸡胸肉放在蔬菜上。
8. 将烤盘放入预热至200度的烤箱中，烤15-20分钟，直到鸡胸肉熟透。
9. 取出烤盘，将菠菜铺在鸡胸肉上，即可享用。

**成果展示**：

这款烤鸡胸肉配蔬菜不仅营养均衡，而且制作简单。烤鸡胸肉香气四溢，搭配清新的蔬菜，口感鲜美，适合作为家庭晚餐或聚会菜品。

食材选择是简约主义烹饪的基础，正确的食材选择不仅能提高烹饪效率，还能确保食物的口感和营养价值。在简约主义烹饪中，选择新鲜、当季、简单处理的食材尤为重要。以下是如何选择适合简约烹饪的食材以及食材的处理方法。

2. **当季**：当季食材不仅口感和营养价值更佳，而且价格也更实惠。选择当季食材，不仅有助于保持饮食的健康，还能减少食物浪费。例如，春季的新鲜蔬菜和水果，秋季的坚果和水果等。

4. **多样化**：在食材选择上，尽量选择多样化的食材，以实现营养均衡。例如，蔬菜、水果、谷物、肉类和豆类的搭配，可以提供丰富的营养素。

#### 3.2 食材的处理方法

在简约主义烹饪中，食材的处理方法同样重要。以下是一些常用的食材处理方法：

1. **蔬菜的处理**：蔬菜通常需要去皮、去籽、切块或切片。在处理蔬菜时，应尽量保留其营养成分，避免过度处理。例如，将胡萝卜切成薄片，将土豆切成块状，将西兰花切成小朵。

2. **水果的处理**：水果通常需要洗净、去皮、切块或切片。在处理水果时，应尽量保留其果肉，以减少营养成分的流失。例如，将苹果切成块状，将香蕉切成片状，将橙子切成薄片。

3. **肉类的处理**：肉类通常需要洗净、切块或切片。在处理肉类时，应尽量去除多余的脂肪，以减少烹饪时间，提高口感。例如，将鸡肉切成薄片，将牛肉切成块状，将猪肉切成薄片。

4. **海鲜的处理**：海鲜需要洗净、去壳、去内脏。在处理海鲜时，应尽量保持其新鲜度，避免长时间浸泡。例如，将虾去壳去头，将螃蟹去壳去内脏。

5. **豆类的处理**：豆类需要提前浸泡，然后煮熟。在烹饪前，将豆类洗净，用温水浸泡几小时或过夜，然后煮熟。例如，将黄豆、黑豆和红豆等。
