### 2.1 数字版权保护的现状与挑战

随着互联网和数字技术的发展，数字内容的创作和传播速度大大加快，数字版权保护的问题也日益凸显。当前，数字版权保护的现状面临以下几个主要挑战：

1. **版权侵权问题严重**：互联网的普及和数字内容的便捷传播，使得版权侵权行为变得更为普遍。盗版、非法传播、未经授权使用等行为频繁发生，给版权持有者带来了巨大的经济损失。

2. **传统保护手段不足**：传统的版权保护手段，如法律诉讼、合同监管等，存在一定的局限性。法律诉讼周期长、成本高，且难以对大规模的侵权行为进行有效打击。合同监管则依赖于双方的诚信合作，但在实际操作中难以确保每个环节都得到严格执行。

3. **版权管理复杂**：数字内容的多样性和复杂性增加了版权管理的难度。版权持有者需要跟踪大量的版权信息，包括版权所有者、授权使用情况、版权期限等，以便进行有效的版权保护。

4. **维权成本高**：维权过程繁琐，涉及取证、法律咨询、诉讼等多个环节，成本高昂。对于小型版权持有者或个人创作者来说，维权成本往往超出其承受范围，导致他们放弃维权。

- **数据块**：包含一定数量的交易记录，并通过哈希函数与前一数据块进行加密连接。
- **节点**：维护区块链的完整性和正常运行，每个节点都有完整的区块链数据。
- **共识算法**：确保所有节点对区块链的当前状态达成一致。

import hashlib
import json

# 创建区块链的类
class BlockChain:
    def __init__(self):
        self.unconfirmed_transactions = []  # 未确认交易
        self.chain = []  # 区块链
        self.create_genesis_block()  # 创建创世区块

    def create_genesis_block(self):
        genesis_block = {
            'previous_hash': 1,
            'timestamp': 1546300800,
            'transactions': [],
            'nonce': 0
        }
        genesis_block['hash'] = self.compute_hash(genesis_block)
        self.chain.append(genesis_block)

    def compute_hash(self, block):
        block_string = json.dumps(block, sort_keys=True)
        return hashlib.sha256(block_string.encode()).hexdigest()

    def add_new_transaction(self, transaction):
        self.unconfirmed_transactions.append(transaction)

    def mine_block(self):
        if not self.unconfirmed_transactions:
            return False
        
        last_block = self.chain[-1]
        new_block = {
            'previous_hash': last_block['hash'],
            'timestamp': int(time.time()),
            'transactions': self.unconfirmed_transactions,
            'nonce': 0
        }
        
        # 计算工作量证明
        new_block['hash'] = self.compute_hash(new_block)
        while new_block['hash'][0] != '0':
            new_block['nonce'] += 1
            new_block['hash'] = self.compute_hash(new_block)
        
        self.chain.append(new_block)
        self.unconfirmed_transactions = []
        return new_block

    def is_chain_valid(self, chain):
        for i in range(1, len(chain)):
            current = chain[i]
            previous = chain[i - 1]
            if current['hash'] != self.compute_hash(current):
                return False
            if current['previous_hash'] != previous['hash']:
                return False
        return True

# 创建区块链实例

# 添加新交易

    'sender': 'Alice',
    'recipient': 'Bob',
    'amount': 50
})

# 挖掘新区块
blockchain.mine_block()

# 验证区块链
