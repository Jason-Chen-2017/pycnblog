### 第一部分：算法面试基础

**第1章：算法与数据结构基础**

算法与数据结构是计算机科学中的核心概念，它们共同构成了算法设计的基石。在这一章中，我们将详细探讨算法与数据结构的基本概念、常见数据结构的实现原理以及如何培养算法思维。

**1.1 算法概述**

**算法基本概念**

算法（Algorithm）是一系列定义明确的步骤，用于解决特定问题。一个算法必须具备以下五个特性：

1. **有穷性**：算法必须在执行有限步之后结束。
2. **确定性**：算法的每一步都必须有明确的定义，不存在歧义。
3. **输入**：一个算法有零个或多个输入。
4. **输出**：一个算法有一个或多个输出。
5. **有效性**：算法中的每一步都是可以被实际执行的。

**算法特性**

除了上述基本概念，算法还具有以下几个重要特性：

- **正确性**：算法能够解决它设计时预定的问题。
- **可读性**：算法的描述应该清晰易懂，便于理解和维护。
- **健壮性**：算法能够处理各种异常情况和非法输入。

**算法设计的策略**

算法设计可以分为以下几个步骤：

1. **问题定义**：明确需要解决的问题是什么。
2. **算法设计**：根据问题的性质选择合适的算法设计策略。
3. **算法分析**：评估算法的性能，包括时间复杂度和空间复杂度。
4. **算法实现**：将算法设计转化为可执行的代码。
5. **测试与优化**：测试算法的正确性和效率，并进行必要的优化。

**1.2 常见数据结构**

数据结构是存储数据的方式，它们决定了数据的操作效率。常见的线性数据结构包括线性表、栈与队列、链表，而树与图是非线性数据结构。

**线性表**

线性表是最基本的数据结构之一，它包含一系列元素，这些元素在内存中连续存储。线性表的基本操作包括：

- **插入**：在表的指定位置插入一个新元素。
- **删除**：从表中删除一个元素。
- **查找**：在表中查找一个元素。
- **遍历**：逐个访问表中的所有元素。

线性表可以分为顺序存储和链式存储两种方式。顺序存储使用数组实现，链式存储使用链表实现。

**栈与队列**

栈（Stack）和队列（Queue）是两种特殊的线性表，分别适用于后进先出（LIFO）和先进先出（FIFO）的操作模式。

- **栈**：栈的基本操作包括入栈、出栈、peek（查看栈顶元素）和isEmpty（检查栈是否为空）。
- **队列**：队列的基本操作包括入队、出队、peek（查看队首元素）和isEmpty（检查队列是否为空）。

栈与队列的数组实现和链表实现都较为简单，但链式存储可以更好地支持动态扩容。

**链表**

链表由一系列节点组成，每个节点包含数据域和指向下一个节点的指针。链表可以分为单链表、双向链表和循环链表。

- **单链表**：每个节点只包含一个指向下一个节点的指针。
- **双向链表**：每个节点包含一个指向下一个节点的指针和一个指向前一个节点的指针。
- **循环链表**：链表的最后一个节点的指针指向第一个节点，形成环状结构。

链表的插入和删除操作在平均情况下比顺序存储的数组实现更高效，因为不需要移动大量元素。

**1.3 算法思维培养**

算法思维是解决算法问题的重要能力，它包括以下几个方面的培养：

- **逻辑思维能力**：培养清晰、严谨的逻辑思维能力，能够从复杂问题中抽象出核心问题。
- **抽象能力**：学会将实际问题抽象为算法问题，理解问题本质。
- **数学建模能力**：掌握数学建模方法，能够将算法问题的解决方案转化为数学公式。
- **编程能力**：通过编写代码实现算法，验证算法的正确性和效率。

**分治策略**、**贪心算法**和**动态规划**是常见的算法思维策略，它们分别适用于不同类型的算法问题。分治策略通过将大问题分解为小问题来解决；贪心算法通过每次选择局部最优解来得到全局最优解；动态规划则通过存储子问题的解来避免重复计算。

**第2章：数学基础**

数学是计算机科学的重要基石，尤其在算法设计和分析中起着关键作用。本章将介绍数学基础知识、常用公式和定理，以及数学在算法中的应用，帮助读者更好地理解和解决算法问题。

**2.1 数学基础知识**

**线性代数基础**

线性代数是研究向量空间和线性映射的数学分支。以下是线性代数中的几个核心概念：

- **向量**：向量是一个有序数组，用于表示物理量的大小和方向。向量的表示通常使用粗体字母或箭头表示，例如 $\vec{a}$ 或 $\overrightarrow{a}$。
- **矩阵**：矩阵是一个二维数组，用于表示线性变换或系统方程。矩阵的表示通常使用小写字母，例如 $A$。
- **行列式**：行列式是矩阵的一种特殊函数，用于计算矩阵的逆或确定线性方程组的解。行列式的表示通常使用大写字母，例如 $D$。
- **矩阵运算**：包括矩阵加法、矩阵乘法、矩阵逆等。

**概率论基础**

概率论是研究随机现象的数学分支。以下是概率论中的几个核心概念：

- **随机事件**：随机事件是可能发生也可能不发生的事件。例如，掷骰子得到6。
- **概率**：概率是描述随机事件发生可能性大小的数值。概率的取值范围在0到1之间，0表示不可能发生，1表示一定会发生。
- **条件概率**：条件概率是指在某个事件已经发生的条件下，另一个事件发生的概率。条件概率表示为 $P(A|B)$，读作“在事件B发生的条件下事件A的概率”。
- **独立性**：两个事件A和B是独立的，如果其中一个事件的发生不影响另一个事件的概率。

**组合数学基础**

组合数学是研究离散对象的计数和分布的数学分支。以下是组合数学中的几个核心概念：

- **排列**：排列是从一组对象中按照一定顺序选取的对象的序列。排列的数量用 $P(n, k)$ 表示，表示从n个不同元素中选取k个元素的排列数。
- **组合**：组合是从一组对象中按照任意顺序选取的对象的序列。组合的数量用 $C(n, k)$ 表示，表示从n个不同元素中选取k个元素的组合数。
- **子集**：子集是从一组对象中选取的部分或全部对象组成的集合。一个集合的子集数量为 $2^n$，其中n是集合中元素的数量。

**2.2 数学公式与定理**

**重要公式回顾**

以下是几个在算法中常用的重要数学公式和定理：

- **二项式定理**：$(a+b)^n = \sum_{k=0}^{n} C(n, k) \cdot a^{n-k} \cdot b^k$，用于计算二项式的展开。
- **斐波那契数列**：$F(n) = F(n-1) + F(n-2)$，其中 $F(0) = 0$，$F(1) = 1$。斐波那契数列在算法设计中常用于递归问题和动态规划。
- **拉格朗日中值定理**：如果函数 $f(x)$ 在闭区间 $[a, b]$ 上连续，在开区间 $(a, b)$ 上可导，那么至少存在一点 $c \in (a, b)$，使得 $f'(c) = \frac{f(b) - f(a)}{b - a}$。这个定理在证明函数的性质和估计函数的极值时非常有用。

**常用定理证明**

以下是几个常用的定理及其证明：

- **二项式定理的证明**：使用数学归纳法。首先验证基础情况 $n=0$ 和 $n=1$。然后假设对于 $n=k$ 时成立，证明对于 $n=k+1$ 时也成立。
- **斐波那契数列的证明**：使用数学归纳法。首先验证基础情况 $F(0) = 0$ 和 $F(1) = 1$。然后假设对于 $n=k$ 时成立，证明对于 $n=k+1$ 时也成立。

**2.3 数学在算法中的应用**

**数论基础**

数论是研究整数的性质和应用的数学分支。以下是一些数论在算法中的应用：

- **质数判断**：使用试除法判断一个数是否为质数。试除法从2开始，依次除以小于等于 $\sqrt{n}$ 的所有质数，如果都无法整除，则该数为质数。
- **最大公约数（GCD）**：使用欧几里得算法计算两个整数的最大公约数。欧几里得算法的基本思想是用较大数除以较小数，然后用余数替换较大数，重复这个过程，直到余数为0，此时较小数即为最大公约数。

**线性规划**

线性规划是解决线性约束优化问题的一种数学方法。以下是一个简单的线性规划问题：

- **目标函数**：最大化 $Z = c_1x_1 + c_2x_2$，其中 $c_1$ 和 $c_2$ 是系数，$x_1$ 和 $x_2$ 是变量。
- **约束条件**：$Ax \leq b$，其中 $A$ 是约束矩阵，$x$ 是变量向量，$b$ 是约束向量。

线性规划问题的求解可以使用单纯形法或内点法。单纯形法是通过迭代寻找最优解的过程，每次迭代都会移动到一个新的顶点，直到达到最优解。内点法则是从可行解的内部开始搜索，逐步逼近最优解。

**3.1 排序算法**

排序算法用于将一组数据按照特定的顺序排列。常见的排序算法包括冒泡排序、快速排序、归并排序和堆排序。

**冒泡排序**

冒泡排序是一种简单的排序算法，它通过重复遍历要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来。遍历数列的工作是重复进行直到没有再需要交换，也就是说该数列已经排序完成。

**伪代码：**
```
function bubbleSort(arr):
    n = length(arr)
    for i from 0 to n-1:
        for j from 0 to n-i-1:
            if arr[j] > arr[j+1]:
                swap(arr[j], arr[j+1])
```

**时间复杂度**：$O(n^2)$

**空间复杂度**：$O(1)$

**适用场景**：数据量较小且基本有序的情况。

**快速排序**

快速排序是一种高效的排序算法，由东尼·霍尔提出。它采用分治策略，通过递归将一个大问题分解为几个小问题来求解。快速排序的关键是选择一个“基准”元素，将数组分为两个子数组，一个包含小于基准的元素，另一个包含大于基准的元素，然后递归地排序两个子数组。

**伪代码：**
```
function quickSort(arr, low, high):
    if low < high:
        pi = partition(arr, low, high)
        quickSort(arr, low, pi-1)
        quickSort(arr, pi+1, high)

function partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j from low to high-1:
        if arr[j] < pivot:
            i = i + 1
            swap(arr[i], arr[j])
    swap(arr[i+1], arr[high])
    return i + 1
```

**时间复杂度**：平均为 $O(n\log n)$，最坏情况下为 $O(n^2)$

**空间复杂度**：$O(\log n)$

**适用场景**：适用于大多数数据类型的排序，尤其适用于大规模数据排序。

**归并排序**

归并排序是一种稳定的排序算法，它通过递归地将数组分成两个子数组，然后递归地对两个子数组进行排序，最后将排序好的子数组合并为一个完整的排序数组。

**伪代码：**
```
function mergeSort(arr, low, high):
    if low < high:
        mid = (low + high) / 2
        mergeSort(arr, low, mid)
        mergeSort(arr, mid + 1, high)
        merge(arr, low, mid, high)

function merge(arr, low, mid, high):
    n1 = mid - low + 1
    n2 = high - mid
    L[] = new array of size n1
    R[] = new array of size n2
    for i = 0 to n1-1:
        L[i] = arr[low + i]
    for j = 0 to n2-1:
        R[j] = arr[mid + 1 + j]
    i = 0
    j = 0
    k = low
    while i < n1 and j < n2:
        if L[i] <= R[j]:
            arr[k] = L[i]
            i = i + 1
        else:
            arr[k] = R[j]
            j = j + 1
        k = k + 1
    while i < n1:
        arr[k] = L[i]
        i = i + 1
        k = k + 1
    while j < n2:
        arr[k] = R[j]
        j = j + 1
        k = k + 1
```

**时间复杂度**：$O(n\log n)$

**空间复杂度**：$O(n)$

**适用场景**：适用于大规模数据的排序，尤其适合链表排序。

**堆排序**

堆排序是一种基于比较的排序算法，它利用堆这种数据结构进行排序。堆是一种特殊的树形数据结构，满足堆性质：每个父节点的值都小于或大于其所有子节点的值。

**伪代码：**
```
function heapify(arr, n, i):
    largest = i
    l = 2*i + 1
    r = 2*i + 2
    if l < n and arr[l] > arr[largest]:
        largest = l
    if r < n and arr[r] > arr[largest]:
        largest = r
    if largest != i:
        swap(arr[i], arr[largest])
        heapify(arr, n, largest)

function heapSort(arr):
    n = length(arr)
    for i = n/2 - 1 to 0:
        heapify(arr, n, i)
    for i = n-1 to 0:
        swap(arr[0], arr[i])
        heapify(arr, i, 0)
```

**时间复杂度**：$O(n\log n)$

**空间复杂度**：$O(1)$

**适用场景**：适用于内部排序和外部排序。

**3.2 搜索算法**

搜索算法用于在数据结构中查找特定元素。常见的搜索算法包括二分查找、深度优先搜索和广度优先搜索。

**二分查找**

二分查找算法是一种在有序数组中查找特定元素的算法。它通过不断将搜索区间缩小一半来快速定位目标元素。

**伪代码：**
```
function binarySearch(arr, low, high, target):
    while low <= high:
        mid = (low + high) / 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

**时间复杂度**：$O(\log n)$

**空间复杂度**：$O(1)$

**适用场景**：适用于有序数组。

**深度优先搜索**

深度优先搜索（DFS）是一种用于遍历或搜索图或树的算法。它通过递归的方式沿着一个路径深入到最远节点，然后回溯到上一个节点继续探索。

**伪代码：**
```
function DFS(graph, vertex, visited):
    visited[vertex] = true
    for each neighbor in graph[vertex]:
        if not visited[neighbor]:
            DFS(graph, neighbor, visited)
```

**时间复杂度**：$O(V+E)$，其中 $V$ 是节点数量，$E$ 是边数量。

**空间复杂度**：$O(V)$

**适用场景**：适用于图和树的遍历。

**广度优先搜索**

广度优先搜索（BFS）是一种用于遍历或搜索图或树的算法。它与深度优先搜索不同，它先访问所有相邻的节点，然后再访问下一层的节点。

**伪代码：**
```
function BFS(graph, start):
    queue = empty queue
    visited = array of size V, initialized to false
    enqueue(start, queue)
    visited[start] = true
    while queue is not empty:
        vertex = dequeue(queue)
        print(vertex)
        for each neighbor in graph[vertex]:
            if not visited[neighbor]:
                enqueue(neighbor, queue)
                visited[neighbor] = true
```

**时间复杂度**：$O(V+E)$

**空间复杂度**：$O(V)$

**适用场景**：适用于图和树的遍历。

### 第四部分：动态规划与贪心算法

#### 第4章：动态规划与贪心算法

动态规划和贪心算法是解决最优化问题的两种重要方法。动态规划通过存储子问题的解来避免重复计算，适用于复杂的最优化问题；贪心算法则通过每次选择局部最优解来得到全局最优解，适用于某些特定类型的问题。本章将详细介绍动态规划与贪心算法的基础知识、应用场景，并提供相关面试题的解析。

**4.1 动态规划基础**

**动态规划基本概念**

动态规划（Dynamic Programming，简称DP）是一种在数学、计算机科学和经济学中用来解决问题的方法，它适合解决最优化问题。动态规划的核心思想是将复杂问题分解为若干个相互重叠的子问题，然后递归地求解这些子问题，并利用子问题的解来构建原问题的解。

**动态规划的特点**

- **最优子结构**：问题的最优解包含了其子问题的最优解。
- **重叠子问题**：子问题空间重叠，即子问题不是独立的，一个子问题在求解过程中多次出现。
- **无后效性**：一旦某个状态确定，它的影响仅限于当前阶段，未来的决策不受其影响。

**动态规划的基本步骤**

1. **定义状态**：确定问题中的状态，以及状态转移关系。
2. **初始化**：初始化边界条件，即初始状态。
3. **状态转移方程**：根据状态转移关系，构建状态转移方程。
4. **求解最优解**：利用状态转移方程，从初始状态开始递归求解，得到最终的最优解。

**动态规划与贪心算法的区别**

- **动态规划**：通过存储子问题的解来避免重复计算，适用于复杂的最优化问题，例如背包问题、最长公共子序列、最长递增子序列等。
- **贪心算法**：每次选择局部最优解，适用于某些特定类型的问题，例如最短路径问题（Dijkstra算法）、活动选择问题等。

**4.2 贪心算法应用**

**贪心算法基本概念**

贪心算法（Greedy Algorithm）是一种在每一步选择中都采取在当前状态下最好或最优的选择，以便逐步获得问题的解的方法。贪心算法的基本思想是：从问题的整体出发，在每一阶段做出最优选择，从而得到全局最优解。

**贪心算法的特点**

- **最优选择原则**：在每一步选择时，选择当前最优解。
- **局部最优解**：每一步选择都是当前状态下的最优解，但并不保证最终得到全局最优解。

**贪心算法的应用**

贪心算法适用于一些特定类型的问题，例如：

- **背包问题**：在给定总重量和物品价值的情况下，选择若干物品装入背包，使总价值最大。
- **最短路径问题**：在加权图中，选择路径使得总权重最小。
- **活动选择问题**：在给定多个活动和它们的时间安排下，选择最多不相交的活动。

**4.3 动态规划与贪心算法题目解析**

**题目1：背包问题**

**问题描述**：给定一组物品，每个物品有一个重量和价值，背包有一个总重量限制。求解如何选择物品，使得总价值最大，且不超过背包的总重量。

**动态规划解法**：

定义状态 $dp[i][j]$ 为在前 $i$ 个物品中选择若干个放入容量为 $j$ 的背包中的最大价值。

状态转移方程为：
$$
dp[i][j] = \max(dp[i-1][j], dp[i-1][j-w_i] + v_i)
$$
其中，$w_i$ 是第 $i$ 个物品的重量，$v_i$ 是第 $i$ 个物品的价值。

初始条件为 $dp[0][j] = 0$。

**贪心算法解法**：

选择价值最大的物品，将其放入背包，直到背包总重量达到限制。贪心算法无法保证得到全局最优解，但在某些情况下能获得近似最优解。

**题目2：最长公共子序列**

**问题描述**：给定两个序列，求它们的最长公共子序列。

**动态规划解法**：

定义状态 $dp[i][j]$ 为前 $i$ 个字符和前 $j$ 个字符的最长公共子序列的长度。

状态转移方程为：
$$
dp[i][j] = \begin{cases}
dp[i-1][j-1] + 1, & \text{如果} a_i = b_j \\
dp[i-1][j], & \text{如果} a_i \neq b_j
\end{cases}
$$
初始条件为 $dp[0][j] = dp[i][0] = 0$。

**贪心算法解法**：此问题不适用贪心算法，因为贪心算法无法保证找到最长公共子序列。

**题目3：活动选择问题**

**问题描述**：给定一系列活动，每个活动有一个开始时间和结束时间，求解最多可参加的活动数量，使得这些活动的开始时间和结束时间不相交。

**贪心算法解法**：

选择最早结束的活动，然后从剩余活动中选择最早结束的活动，直到没有可参加的活动。

伪代码：
```
function activitySelection(activities):
    sort activities by end time
    count = 0
    lastEnd = -infinity
    for each activity in activities:
        if activity.start > lastEnd:
            count += 1
            lastEnd = activity.end
    return count
```

**动态规划解法**：此问题通常不使用动态规划解决，因为贪心算法已经可以有效地解决问题。

### 第五部分：图算法与应用

#### 第5章：图算法与应用

图是一种用于描述对象及其关系的数据结构，广泛应用于网络、社交网络、地图、流程控制等领域。本章将介绍图的基本概念、图算法以及在实际应用中的题目解析。

**5.1 图的基本概念**

**图的定义**

图（Graph）是由节点（Node）和边（Edge）组成的集合。节点表示图中的对象，边表示节点之间的关系。

- **无向图**：边没有方向，节点之间的关系是对等的。
- **有向图**：边有方向，从一个节点指向另一个节点。

**图的表示方法**

图的表示方法包括邻接矩阵和邻接表。

- **邻接矩阵**：使用二维数组表示图，如果节点 $i$ 和节点 $j$ 之间有边，则 $adj_matrix[i][j] = 1$，否则为 $0$。
- **邻接表**：使用数组表示图，每个数组元素对应一个节点，元素中的链表表示与该节点相连的其他节点。

**图的遍历算法**

图的遍历算法用于访问图中的所有节点。常见的遍历算法有深度优先搜索（DFS）和广度优先搜索（BFS）。

- **深度优先搜索（DFS）**：从某个节点开始，沿着一个分支一直深入到不能再深入为止，然后回溯到上一个节点，继续沿着另一条分支深入。
- **广度优先搜索（BFS）**：从某个节点开始，按照层次遍历图中的节点，每次遍历同一层的所有节点。

**5.2 图算法**

**最小生成树**

最小生成树（Minimum Spanning Tree，MST）是连通图的生成树中边的权重之和最小的树。常见的算法有普里姆算法（Prim）和克鲁斯卡尔算法（Kruskal）。

- **普里姆算法**：从某个节点开始，逐步增加新节点和边，直到构成最小生成树。

伪代码：
```
function prim(M, n):
    key[] = array of size n
    mst[] = array of size n
    for i = 1 to n:
        key[i] = infinity
        mst[i] = false
    key[0] = 0
    mst[0] = true
    for i = 1 to n-1:
        min_key = infinity
        min_index = -1
        for j = 1 to n:
            if mst[j] and key[j] < min_key:
                min_key = key[j]
                min_index = j
        mst[min_index] = true
        for each edge (i, j) in M:
            if i in mst and j not in mst and weight[i][j] < key[j]:
                key[j] = weight[i][j]
```

- **克鲁斯卡尔算法**：按边权重递增的顺序选择边，确保新边不会形成环。

伪代码：
```
function kruskal(M, n):
    forest[] = array of size n
    for i = 1 to n:
        forest[i] = makeSet(i)
    edges[] = sorted by weight
    for each edge (i, j) in edges:
        if findSet(forest[i]) != findSet(forest[j]):
            union(forest[i], forest[j])
```

**最短路径算法**

最短路径算法用于计算图中两点之间的最短路径。常见的算法有迪杰斯特拉算法（Dijkstra）和贝尔曼-福特算法（Bellman-Ford）。

- **迪杰斯特拉算法**：适用于权值非负的图，使用优先队列来选择最小权重边。

伪代码：
```
function dijkstra(graph, source):
    dist[] = infinity
    dist[source] = 0
    visited[] = array of size n, initialized to false
    priorityQueue = new MinPriorityQueue()
    for i = 0 to n-1:
        priorityQueue.enqueue(i, dist[i])
    while not priorityQueue.isEmpty():
        u = priorityQueue.dequeue()
        for each edge (u, v) in graph:
            if dist[u] + weight[u][v] < dist[v]:
                dist[v] = dist[u] + weight[u][v]
                priorityQueue.enqueue(v, dist[v])
```

- **贝尔曼-福特算法**：适用于权值可以是负数的图。

伪代码：
```
function bellmanFord(graph, source):
    dist[] = infinity
    dist[source] = 0
    for i = 1 to n-1:
        for each edge (u, v) in graph:
            if dist[u] + weight[u][v] < dist[v]:
                dist[v] = dist[u] + weight[u][v]
    for each edge (u, v) in graph:
        if dist[u] + weight[u][v] < dist[v]:
            return false
    return true
```

**网络流算法**

网络流算法用于计算图中的最大流量。常见的算法有最大流-最小割定理（Max-Flow Min-Cut Theorem）和Ford-Fulkerson算法。

- **最大流-最小割定理**：图中的最大流量等于最小割的容量。

伪代码：
```
function maxFlow(graph, source, sink):
    flow = 0
    while there exists an augmenting path from source to sink:
        path = findAugmentingPath(graph, source, sink)
        bottleneck = min(graph[u][v] for (u, v) in path)
        for each edge (u, v) in path:
            graph[u][v] -= bottleneck
            graph[v][u] += bottleneck
        flow += bottleneck
    return flow
```

### 第六部分：字符串处理算法

#### 第6章：字符串处理算法

字符串处理算法是计算机科学中常见的一类算法，广泛应用于信息检索、文本编辑、模式匹配等领域。本章将详细介绍字符串处理算法的基本操作、核心算法以及实际应用中的题目解析。

**6.1 字符串基础操作**

**字符串基础操作包括但不限于：**

- **子串匹配**：在字符串中查找子串的位置，常见算法有 naive 模式匹配算法、KMP算法等。
- **字符串变换**：包括字符串的反转、字符串的拼接、字符串的分割等。

**Naive 模式匹配算法**

Naive 模式匹配算法是最简单的字符串匹配算法，其思想是从主串的开始位置逐个字符与模式串进行匹配。

**伪代码：**
```
function naiveMatch(s, p):
    n = length(s)
    m = length(p)
    for i = 0 to n - m:
        j = 0
        while j < m:
            if s[i + j] != p[j]:
                break
            if j == m - 1:
                return i
        return -1
```

**时间复杂度**：$O((n-m)m)$，其中 $n$ 是主串长度，$m$ 是模式串长度。

**KMP算法**

KMP算法（Knuth-Morris-Pratt）是一种高效的字符串匹配算法，它利用已匹配的字符信息来避免不必要的比较。

**核心思想**：

- **前缀函数（Partial Match Function）**：计算模式串的前缀集合，以避免重复比较。
- **主串和模式串的比较**：当出现不匹配时，利用前缀函数来确定下一次匹配的起点。

**伪代码：**
```
function computeLPSArray(p, lps):
    len = length(p)
    l = 0
    i = 1
    while i < len:
        if p[i] == p[l]:
            l += 1
            lps[i] = l
            i += 1
        else:
            if l != 0:
                l = lps[l - 1]
            else:
                lps[i] = 0
                i += 1

function KMP(s, p):
    n = length(s)
    m = length(p)
    lps = array of size m
    computeLPSArray(p, lps)
    i = 0  # index for s
    j = 0  # index for p
    while i < n:
        if p[j] == s[i]:
            i += 1
            j += 1
        if j == m:
            return i - j
            j = lps[j - 1]
        else:
            if i < n and p[j] != s[i]:
                if j != 0:
                    j = lps[j - 1]
                else:
                    i += 1
    return -1
```

**时间复杂度**：$O(n + m)$，其中 $n$ 是主串长度，$m$ 是模式串长度。

**6.2 字符串算法**

**回文算法**

回文算法用于判断字符串是否为回文。

**中心扩展法**

中心扩展法是一种用于判断字符串是否为回文的算法，其核心思想是分别以字符串的每个字符为中心，向外扩展比较。

**伪代码：**
```
function isPalindrome(s):
    n = length(s)
    for i = 0 to n//2:
        if s[i] != s[n - i - 1]:
            return false
    return true
```

**时间复杂度**：$O(n)$，其中 $n$ 是字符串长度。

**Manacher算法**

Manacher算法是一种用于找到字符串最长回文子串的高效算法。

**核心思想**：

- **奇数长度回文**：将字符串中的每个字符之间插入一个特殊的字符（例如`#`），将问题转换为奇数长度的回文问题。
- **偶数长度回文**：在字符串首尾添加特殊字符，将问题转换为偶数长度的回文问题。

**伪代码：**
```
function preprocess(s):
    t = "^#".join(s + "#$")
    return t

function Manacher(s):
    t = preprocess(s)
    n = length(t)
    p = array of size n, initialized to 0
    c = r = 0
    for i = 1 to n-1:
        if i < r:
            p[i] = min(r - i, p[2*c - i])
        while i + p[i] < n and t[i + p[i]] == t[i - p[i]]:
            p[i] += 1
        if i + p[i] > r:
            c = i
            r = i + p[i]
    return max(p)
```

**时间复杂度**：$O(n)$，其中 $n$ 是字符串长度。

**正则表达式**

正则表达式（Regular Expression）是一种用于描述字符串模式的语法规则。它广泛应用于文本搜索、数据验证等领域。

**核心概念**：

- **字符匹配**：用于匹配单个字符。
- **选择符**：用于匹配多个可能的字符串。
- **重复符**：用于匹配重复的字符串。

```
function longestCommonPrefix(strs):
```

**贪心算法**

贪心算法通过在每个步骤中选择局部最优解来寻求全局最优解。

**题目1：背包问题**

**问题描述**：给定一组物品，每个物品有重量和价值，背包有一个总重量限制。求解如何选择物品，使得总价值最大，且不超过背包的总重量。

**贪心算法解法**：

选择价值最大的物品，将其放入背包，直到背包总重量达到限制。

**伪代码：**
```
function knapsack(values, weights, W):
    n = length(values)
    index = [0] * n
    total_value = 0
    for i = 0 to n-1:
        if weights[i] <= W:
            W -= weights[i]
            total_value += values[i]
            index[i] = 1
    return total_value, index
```

**时间复杂度**：$O(n)$

**组合算法**

组合算法主要用于求解组合问题，如排列、组合、子集等。

**题目4：最大子序和**

**问题描述**：给定一个整数数组，求解数组中连续子序列的最大和。

**贪心算法解法**：

从左到右遍历数组，维护当前子序列和，如果当前子序列和小于0，则重新开始计算子序列和。

**伪代码：**

```
    max_so_far = nums[0]
    curr_max = nums[0]
    for i = 1 to length(nums) - 1:
        curr_max = max(nums[i], curr_max + nums[i])
        max_so_far = max(max_so_far, curr_max)
    return max_so_far
```

**时间复杂度**：$O(n)$

**题目5：编辑距离**

**问题描述**：给定两个字符串，求解将一个字符串转换成另一个字符串所需的最少编辑操作次数。

**动态规划解法**：

定义状态 $dp[i][j]$ 为字符串 $s_1$ 的前 $i$ 个字符与字符串 $s_2$ 的前 $j$ 个字符的最小编辑距离。

**伪代码：**
```
function minDistance(s1, s2):
    m = length(s1)
    n = length(s2)
    dp = array of size [m+1][n+1]
    for i = 0 to m:
        dp[i][0] = i
    for j = 0 to n:
        dp[0][j] = j
    for i = 1 to m:
        for j = 1 to n:
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]
```

**时间复杂度**：$O(mn)$

**题目1：最长公共子序列**

**问题描述**：给定两个字符串，求它们的最长公共子序列。

**解析**：

使用动态规划方法求解。定义一个二维数组 `dp`，其中 `dp[i][j]` 表示字符串 `s1` 的前 `i` 个字符与字符串 `s2` 的前 `j` 个字符的最长公共子序列的长度。

- **状态转移方程**：
  $$
  dp[i][j] =
  \begin{cases}
  dp[i-1][j-1] + 1, & \text{如果 } s1[i-1] = s2[j-1] \\
  \max(dp[i-1][j], dp[i][j-1]), & \text{其他情况}
  \end{cases}
  $$

- **边界条件**：
  $$
  dp[0][j] = dp[i][0] = 0
  $$

- **代码实现**：
  ```python
  def longestCommonSubsequence(s1, s2):
      m, n = len(s1), len(s2)
      dp = [[0] * (n + 1) for _ in range(m + 1)]
      for i in range(1, m + 1):
          for j in range(1, n + 1):
              if s1[i - 1] == s2[j - 1]:
                  dp[i][j] = dp[i - 1][j - 1] + 1
              else:
                  dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
      return dp[m][n]
  ```

**题目3：最短路径问题**

**问题描述**：给定一个加权图，求解从源点到其他所有节点的最短路径。

**解析**：

使用迪杰斯特拉算法求解。适用于权值非负的图。

- **代码实现**：
  ```python
  import heapq

  def dijkstra(graph, source):
      n = len(graph)
      dist = [float('inf')] * n
      dist[source] = 0
      visited = [False] * n
      priority_queue = [(0, source)]

      while priority_queue:
          curr_dist, curr_node = heapq.heappop(priority_queue)
          visited[curr_node] = True

          if curr_dist > dist[curr_node]:
              continue

          for neighbor, edge_weight in graph[curr_node].items():
              if not visited[neighbor]:
                  new_dist = curr_dist + edge_weight
                  if new_dist < dist[neighbor]:
                      dist[neighbor] = new_dist
                      heapq.heappush(priority_queue, (new_dist, neighbor))

      return dist
  ```

**1. 二分查找**

**问题描述**：在有序数组中查找目标值，如果存在返回其索引，否则返回-1。

**解题思路**：使用二分查找算法，通过不断缩小区间来查找目标值。

**参考答案**：
```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

**2. 快速排序**

**问题描述**：使用快速排序算法对数组进行排序。

**解题思路**：选择一个基准元素，将数组分为两部分，递归地对两部分进行快速排序。

**参考答案**：
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```

**3. 最长公共子序列**

**问题描述**：给定两个序列，求它们的最长公共子序列。

**解题思路**：使用动态规划方法，定义状态 `dp[i][j]` 表示两个序列的前 `i` 和 `j` 个字符的最长公共子序列长度。

**参考答案**：
```python
def longest_common_subsequence(X, Y):
    m = len(X)
    n = len(Y)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if X[i - 1] == Y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

**4. 背包问题**

**问题描述**：给定一组物品，每个物品有重量和价值，背包有一个总重量限制。求解如何选择物品，使得总价值最大，且不超过背包的总重量。

**解题思路**：使用动态规划方法，定义状态 `dp[i][w]` 表示在前 `i` 个物品中选择若干个放入容量为 `w` 的背包中的最大价值。

**参考答案**：
```python
def knapsack(values, weights, W):
    n = len(values)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(1, W + 1):
            if weights[i - 1] <= w:
                dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - weights[i - 1]] + values[i - 1])
            else:
                dp[i][w] = dp[i - 1][w]
    return dp[n][W]
```

**5. 最短路径问题**

**问题描述**：给定一个加权图，求解从源点到其他所有节点的最短路径。

**解题思路**：使用迪杰斯特拉算法，适用于权值非负的图。

**参考答案**：
```python
import heapq

def dijkstra(graph, source):
    n = len(graph)
    dist = [float('inf')] * n
    dist[source] = 0
    visited = [False] * n
    priority_queue = [(0, source)]

    while priority_queue:
        curr_dist, curr_node = heapq.heappop(priority_queue)
        visited[curr_node] = True

        if curr_dist > dist[curr_node]:
            continue

        for neighbor, edge_weight in graph[curr_node].items():
            if not visited[neighbor]:
                new_dist = curr_dist + edge_weight
                if new_dist < dist[neighbor]:
                    dist[neighbor] = new_dist
                    heapq.heappush(priority_queue, (new_dist, neighbor))

    return dist
```
