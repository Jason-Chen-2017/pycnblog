### B.1 词嵌入的数学公式

- **背景介绍**：词嵌入是将单词映射到向量空间的过程，涉及多种数学模型。
- **核心概念与联系**：常见的词嵌入模型包括Word2Vec、GloVe等，下面是这些模型的基本数学公式。

#### Word2Vec

$$
\text{softmax}(z) = \frac{e^z}{\sum_{i=1}^{V} e^z_i}
$$

$$
\text{Gradient} = -\frac{\partial \text{loss}}{\partial \text{weights}}
$$

#### GloVe

$$
\text{loss} = \frac{1}{2} \sum_{i=1}^{V} \sum_{j=1}^{V} \frac{(w_i \cdot w_j - \text{context\_vector\_j})^2}{1 + \sqrt{w_i \cdot w_j} + w_i \cdot w_j}
$$

- **核心概念与联系**：神经网络的基本结构包括输入层、隐藏层和输出层。

```python
class NeuralNetwork:
    def __init__(self, input_size, hidden_size, output_size):
        # 初始化权重和偏置
        self.weights_input_to_hidden = self.initialize_weights(input_size, hidden_size)
        self.bias_input_to_hidden = self.initialize_bias(hidden_size)
        self.weights_hidden_to_output = self.initialize_weights(hidden_size, output_size)
        self.bias_hidden_to_output = self.initialize_bias(output_size)

    def initialize_weights(self, size1, size2):
        # 初始化权重矩阵
        return np.random.randn(size1, size2) * 0.01

    def initialize_bias(self, size):
        # 初始化偏置向量
        return np.zeros((1, size))

    def forward_pass(self, inputs):
        # 前向传播
        hidden_layer_input = np.dot(inputs, self.weights_input_to_hidden) + self.bias_input_to_hidden
        hidden_layer_output = self activation_function(hidden_layer_input)
        output_layer_input = np.dot(hidden_layer_output, self.weights_hidden_to_output) + self.bias_hidden_to_output
        output_layer_output = self.activation_function(output_layer_input)
        return output_layer_output

    def activation_function(self, x):
        # 激活函数（例如：ReLU）
        return np.maximum(0, x)
```
