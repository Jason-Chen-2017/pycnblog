**卷积神经网络（CNN）原理：**

```pseudo
// 输入图像：图像维度（height, width, channels）
// 卷积核：核大小（kernel_size），通道数（num_channels）
// 步长：step
// padding：填充方式（'valid' 或 'same'）

def Conv2D(input_image, weights, bias, stride, padding):
    # 计算卷积
    output = 0
    for i in range(height - kernel_size + 1 + padding):
        for j in range(width - kernel_size + 1 + padding):
            # 求卷积值
            conv_value = sum(weights * input_image[i:i+kernel_size, j:j+kernel_size])
            output += conv_value + bias
    return output
```
