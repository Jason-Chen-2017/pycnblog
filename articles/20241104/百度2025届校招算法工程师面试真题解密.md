#### 1.1 排序算法

1. **冒泡排序**：

   - **原理**：通过重复地遍历待排序的元素列表，比较相邻的两个元素，若它们的顺序错误就交换它们，直到没有需要交换的元素为止。
   - **伪代码**：
     ```python
     for i in range(len(arr)):
         for j in range(len(arr) - i - 1):
             if arr[j] > arr[j + 1]:
                 arr[j], arr[j + 1] = arr[j + 1], arr[j]
     ```

2. **选择排序**：

   - **原理**：首先在未排序序列中找到最小（大）元素，存放到排序序列的起始位置，然后，再从剩余未排序元素中继续寻找最小（大）元素，然后放到已排序序列的末尾。
   - **伪代码**：
     ```python
     for i in range(len(arr)):
         min_idx = i
         for j in range(i+1, len(arr)):
             if arr[min_idx] > arr[j]:
                 min_idx = j
         arr[i], arr[min_idx] = arr[min_idx], arr[i]
     ```

3. **插入排序**：

   - **原理**：将一个记录插入到已经排好序的有序表中，从而得到一个新的、记录数增加1的有序表。
   - **伪代码**：
     ```python
     for i in range(1, len(arr)):
         key = arr[i]
         j = i - 1
         while j >= 0 and key < arr[j]:
             arr[j + 1] = arr[j]
             j -= 1
         arr[j + 1] = key
     ```

4. **快速排序**：

   - **原理**：通过一趟排序将待排序的记录分割成独立的两部分，其中一部分记录的关键字均比另一部分的关键字小，然后分别对这两部分记录继续进行排序，以达到整个序列有序。
   - **伪代码**：
     ```python
     def quick_sort(arr, low, high):
         if low < high:
             pi = partition(arr, low, high)
             quick_sort(arr, low, pi - 1)
             quick_sort(arr, pi + 1, high)

     def partition(arr, low, high):
         pivot = arr[high]
         i = low - 1
         for j in range(low, high):
             if arr[j] < pivot:
                 i += 1
                 arr[i], arr[j] = arr[j], arr[i]
         arr[i + 1], arr[high] = arr[high], arr[i + 1]
         return i + 1
     ```

5. **归并排序**：

   - **原理**：将待排序的序列按照某种方法分割成若干个子序列，分别对各子序列进行排序，然后取个子的子序列合并成一个新的序列。
   - **伪代码**：
     ```python
     def merge_sort(arr):
         if len(arr) > 1:
             mid = len(arr) // 2
             left = arr[:mid]
             right = arr[mid:]

             merge_sort(left)
             merge_sort(right)

             i = j = k = 0
             while i < len(left) and j < len(right):
                 if left[i] < right[j]:
                     arr[k] = left[i]
                     i += 1
                 else:
                     arr[k] = right[j]
                     j += 1
                 k += 1

             while i < len(left):
                 arr[k] = left[i]
                 i += 1
                 k += 1

             while j < len(right):
                 arr[k] = right[j]
                 j += 1
                 k += 1
     ```

#### 1.2 查找算法

1. **二分查找**：

   - **原理**：通过重复将查找区间二分，逐步缩小查找范围，直至找到目标元素或确定元素不存在。
   - **伪代码**：
     ```python
     def binary_search(arr, target):
         low = 0
         high = len(arr) - 1
         while low <= high:
             mid = (low + high) // 2
             if arr[mid] == target:
                 return mid
             elif arr[mid] < target:
                 low = mid + 1
             else:
                 high = mid - 1
         return -1
     ```

#### 1.3 动态规划

1. **最长公共子序列**：

   - **原理**：找到两个序列中最长的公共子序列，使用二维数组存储子问题的解。
   - **伪代码**：
     ```python
     def longest_common_subsequence(X, Y):
         m, n = len(X), len(Y)
         dp = [[0] * (n + 1) for _ in range(m + 1)]

         for i in range(1, m + 1):
             for j in range(1, n + 1):
                 if X[i - 1] == Y[j - 1]:
                     dp[i][j] = dp[i - 1][j - 1] + 1
                 else:
                     dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

         return dp[m][n]
     ```

2. **最长递增子序列**：

   - **原理**：找到序列中最长的递增子序列，使用一维数组存储子问题的解。
   - **伪代码**：
     ```python
     def longest_increasing_subsequence(arr):
         n = len(arr)
         dp = [1] * n

         for i in range(1, n):
             for j in range(i):
                 if arr[i] > arr[j]:
                     dp[i] = max(dp[i], dp[j] + 1)

         return max(dp)
     ```

3. **背包问题**：

   - **原理**：给定一组物品和它们的重量以及价值，求解如何选择其中的若干物品使得总价值最大，同时不超过总重量限制。
   - **伪代码**：
     ```python
     def knapsack(W, wt, val, n):
         dp = [[0] * (W + 1) for _ in range(n + 1)]

         for i in range(1, n + 1):
             for w in range(1, W + 1):
                 if wt[i - 1] <= w:
                     dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - wt[i - 1]] + val[i - 1])
                 else:
                     dp[i][w] = dp[i - 1][w]

         return dp[n][W]
     ```

#### 1.4 图算法

1. **深度优先搜索（DFS）**：

   - **原理**：从初始节点开始，沿着某一方向搜索，当到达一个节点时，沿着该方向继续搜索，直到到达终点或找到目标节点。
   - **伪代码**：
     ```python
     def dfs(graph, node, visited):
         visited.add(node)
         for neighbor in graph[node]:
             if neighbor not in visited:
                 dfs(graph, neighbor, visited)
     ```

2. **广度优先搜索（BFS）**：

   - **原理**：从初始节点开始，按照层次遍历图中的节点，先访问起始节点，然后依次访问它的邻接节点，再访问邻接节点的邻接节点。
   - **伪代码**：
     ```python
     from collections import deque

     def bfs(graph, start):
         visited = set()
         queue = deque([start])
         while queue:
             node = queue.popleft()
             if node not in visited:
                 visited.add(node)
                 for neighbor in graph[node]:
                     queue.append(neighbor)
     ```

3. **拓扑排序**：

   - **原理**：将无环的有向图进行排序，使得每个顶点在排序中只出现一次，且顶点i只排在它的直接后继顶点j之前。
   - **伪代码**：
     ```python
     def topological_sort(DAG):
         in_degree = {node: 0 for node in DAG}
         for node in DAG:
             for neighbor in DAG[node]:
                 in_degree[neighbor] += 1

         queue = deque([node for node in in_degree if in_degree[node] == 0])
         sorted_order = []

         while queue:
             node = queue.popleft()
             sorted_order.append(node)
             for neighbor in DAG[node]:
                 in_degree[neighbor] -= 1
                 if in_degree[neighbor] == 0:
                     queue.append(neighbor)

         return sorted_order
     ```

4. **最短路径算法**：

   - **原理**：求解图中两点之间的最短路径，常用的算法有迪杰斯特拉算法（Dijkstra）和贝尔曼-福特算法（Bellman-Ford）。
   - **伪代码**：
     ```python
     def dijkstra(graph, start):
         distances = {node: float('infinity') for node in graph}
         distances[start] = 0
         visited = set()

         while visited != set(graph):
             unvisited = set(graph) - visited
             min_distance = float('infinity')
             current = None
             for node in unvisited:
                 if distances[node] < min_distance:
                     min_distance = distances[node]
                     current = node
             visited.add(current)
             for neighbor, weight in graph[current].items():
                 if distances[current] + weight < distances[neighbor]:
                     distances[neighbor] = distances[current] + weight

         return distances

     def bellman_ford(graph, start):
         distances = {node: float('infinity') for node in graph}
         distances[start] = 0

         for _ in range(len(graph) - 1):
             for u in graph:
                 for v in graph[u]:
                     if distances[u] + graph[u][v] < distances[v]:
                         distances[v] = distances[u] + graph[u][v]

         for u in graph:
             for v in graph[u]:
                 if distances[u] + graph[u][v] < distances[v]:
                     raise ValueError("Graph contains a negative weight cycle")

         return distances
     ```

   - **应用**：用于实现字典、缓存等数据结构。

2. **哈希冲突解决**：

   - **原理**：当多个关键字映射到同一数组索引时，需要采用某种方法解决冲突。
   - **方法**：链地址法、开放地址法、再哈希法等。

   ```python
   class HashTable:
       def __init__(self, size):
           self.size = size
           self.table = [None] * size

       def hash_function(self, key):
           return key % self.size

       def insert(self, key, value):
           index = self.hash_function(key)
           if self.table[index] is None:
               self.table[index] = [(key, value)]
           else:
               for k, v in self.table[index]:
                   if k == key:
                       self.table[index].remove((k, v))
                       self.table[index].append((key, value))
                       return
               self.table[index].append((key, value))

       def get(self, key):
           index = self.hash_function(key)
           if self.table[index] is None:
               return None
           for k, v in self.table[index]:
               if k == key:
                   return v
           return None
   ```

#### 4.1 监督学习

1. **线性回归**：

   - **原理**：通过拟合一个线性函数来预测连续值。
   - **模型**：
     $$y = w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + \ldots + w_n \cdot x_n$$
   - **优化**：使用梯度下降法求解参数。
   - **示例**：
     ```python
     def linear_regression(X, y):
         m, n = len(X), len(X[0])
         theta = [0] * n
         alpha = 0.01
         num_iterations = 1000

         for _ in range(num_iterations):
             errors = [y[i] - (theta[0] + sum(theta[j] * xij for j, xij in enumerate(X[i]))) for i in range(m)]
             gradients = [-sum(xij * error for xij, error in zip(X[i], errors)) for i in range(m)]

             theta = [theta[i] - alpha * gradients[i] for i in range(n)]

         return theta
     ```

2. **逻辑回归**：

   - **原理**：通过拟合一个逻辑函数来预测二分类问题。
   - **模型**：
     $$\sigma(w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + \ldots + w_n \cdot x_n)$$
   - **优化**：使用梯度下降法求解参数。
   - **示例**：
     ```python
     def logistic_regression(X, y):
         m, n = len(X), len(X[0])
         theta = [0] * n
         alpha = 0.01
         num_iterations = 1000

         for _ in range(num_iterations):
             predictions = [1 / (1 + math.exp(-theta[0] - sum(theta[j] * xij for j, xij in enumerate(X[i]))) for i in range(m)]
             errors = [log(1 - prediction) - log(prediction) for prediction in predictions]

             gradients = [-sum(xij * (prediction - y[i]) for xij, prediction in zip(X[i], predictions)) for i in range(m)]

             theta = [theta[i] - alpha * gradients[i] for i in range(n)]

         return theta
     ```

3. **支持向量机（SVM）**：

     ```python
         max_current = max_global = arr[0]
         for i in range(1, len(arr)):
     ```

     ```python
         while left < right:
             if s[left] != s[right]:
                 return False
             left += 1
             right -= 1
         return True
     ```
