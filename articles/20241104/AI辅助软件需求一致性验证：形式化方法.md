```python
def build_formal_model(requirements):
    # 初始化形式化需求模型
    formal_model = {'requirements': []}
    
    # 遍历提取的需求列表
    for requirement in requirements:
        # 检查需求是否已存在
        existing_requirement = next((r for r in formal_model['requirements'] if r['description'] == requirement['description']), None)
        
        # 如果需求已存在，则更新需求信息
        if existing_requirement:
            existing_requirement['attributes'].update(requirement['attributes'])
        else:
            # 如果需求不存在，则添加新需求
            formal_model['requirements'].append({
                'description': requirement['description'],
                'attributes': requirement['attributes']
            })
    
    return formal_model
```

**代码解读**：
- **初始化形式化需求模型**：创建一个空的形式化需求模型，用于存储提取的需求。
- **遍历提取的需求列表**：对于每个需求，检查其是否已存在于形式化需求模型中。
- **更新需求信息**：如果需求已存在，则更新其属性；如果需求不存在，则将其添加到形式化需求模型中。
