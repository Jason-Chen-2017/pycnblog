### 第6章：算法原理与实现

#### 6.1 排序算法

排序算法是计算机科学中的基本算法，常见的排序算法有冒泡排序、选择排序和插入排序。

#### 6.1.1 冒泡排序

**核心概念**：冒泡排序是一种简单的排序算法，它重复地遍历要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来。

**伪代码**：

```pseudocode
procedure bubbleSort( A : list of sortable items )
    n = length(A)
    repeat 
        swapped = false
        for i = 1 to n-1 inclusive do
            if A[i-1] > A[i] then
                swap(A[i-1], A[i])
                swapped = true
            end if
        end for
        n = n - 1
    until not swapped
end procedure
```

#### 6.1.2 选择排序

**核心概念**：选择排序是一种简单的选择排序算法，它首先在未排序序列中找到最小（大）元素，存放到排序序列的起始位置，然后，再从剩余未排序元素中继续寻找最小（大）元素，然后放到已排序序列的末尾。

**伪代码**：

```pseudocode
procedure selectionSort( A : list of sortable items )
    n = length(A)
    for i = 1 to n-1 do
        minIndex = i
        for j = i+1 to n do
            if A[j] < A[minIndex] then
                minIndex = j
            end if
        end for
        swap(A[i], A[minIndex])
    end for
end procedure
```

#### 6.1.3 插入排序

**核心概念**：插入排序是一种简单的插入排序算法，它通过构建有序序列，对于未排序数据，在已排序序列中从后向前扫描，找到相应位置并插入。

**伪代码**：

```pseudocode
procedure insertionSort( A : list of sortable items )
    n = length(A)
    for i = 2 to n inclusive do
        key = A[i]
        j = i - 1
        while j > 0 and A[j] > key do
            A[j+1] = A[j]
            j = j - 1
        end while
        A[j+1] = key
    end for
end procedure
```

### 第7章：小米算法面试真题实战

#### 7.1 真题1：最大子序和

**题目描述**：给定一个整数数组 nums ，找到一个具有最大和的连续子数组（子数组最少包含一个数），返回其最大和。

**解题思路**：使用动态规划的方法，定义一个 dp 数组，其中 dp[i] 表示以 nums[i] 为结尾的最大子序和。则状态转移方程为：dp[i] = max(dp[i-1] + nums[i], nums[i])。

**伪代码**：

```pseudocode
function maxSubArray(nums : array of integers) -> integer
    n = length(nums)
    dp = array of size n
    dp[0] = nums[0]
    maxSum = dp[0]
    for i = 1 to n-1 do
        dp[i] = max(dp[i-1] + nums[i], nums[i])
        maxSum = max(maxSum, dp[i])
    end for
    return maxSum
end function
```

#### 7.2 真题2：数组中的逆序对

**题目描述**：给定一个整数数组 nums ，返回数组中的逆序对的数量。

**解题思路**：使用归并排序的方法，在排序过程中，统计逆序对的数量。当两个有序数组进行合并时，如果前一个数大于后一个数，那么这两个数构成一个逆序对。

**伪代码**：

```pseudocode
function reversePairs(nums : array of integers) -> integer
    n = length(nums)
    return mergeSort(nums, 0, n-1)
end function

function mergeSort(nums : array of integers, left : integer, right : integer) -> integer
    if left >= right then
        return 0
    end if
    mid = (left + right) / 2
    leftPairs = mergeSort(nums, left, mid)
    rightPairs = mergeSort(nums, mid+1, right)
    mergePairs = merge(nums, left, mid, right)
    return leftPairs + rightPairs + mergePairs
end function

function merge(nums : array of integers, left : integer, mid : integer, right : integer) -> integer
    n1 = mid - left + 1
    n2 = right - mid
    leftArray = array of size n1
    rightArray = array of size n2
    for i = 0 to n1-1 do
        leftArray[i] = nums[left + i]
    end for
    for j = 0 to n2-1 do
        rightArray[j] = nums[mid + 1 + j]
    end for
    i = 0
    j = 0
    k = left
    count = 0
    while i < n1 and j < n2 do
        if leftArray[i] <= rightArray[j] then
            nums[k] = leftArray[i]
            i = i + 1
        else
            nums[k] = rightArray[j]
            j = j + 1
            count = count + (n1 - i)
        end if
        k = k + 1
    end while
    while i < n1 do
        nums[k] = leftArray[i]
        i = i + 1
        k = k + 1
    end while
    while j < n2 do
        nums[k] = rightArray[j]
        j = j + 1
        k = k + 1
    end while
    return count
end function
```

### 第8章：小米校招面试真题全解

#### 8.1 面试题1：字符串匹配算法

**题目描述**：给定一个字符串 needle 和一个字符串 haystack ，请从 haystack 中找出第一个匹配的子串 needle ，返回该子串的起始索引。如果不存在匹配的子串，则返回 -1 。

**解题思路**：使用 KMP 算法进行字符串匹配。KMP 算法的核心思想是避免在匹配过程中出现重复比较，通过计算部分匹配表（next 数组）来跳过部分比较。

**伪代码**：

```pseudocode
function kmp(haystack : string, needle : string) -> integer
    n = length(haystack)
    m = length(needle)
    if m == 0 then
        return 0
    end if
    computeNext(needle)
    j = 0
    for i = 0 to n-m-1 do
        while j > 0 and needle[j] != haystack[i] do
            j = next[j - 1]
        end while
        if needle[j] == haystack[i] then
            j = j + 1
            if j == m then
                return i - m + 1
            end if
        end if
    end for
    return -1
end function

function computeNext(needle : string)
    n = length(needle)
    next = array of size n
    j = 0
    for i = 1 to n-1 do
        while j > 0 and needle[j] != needle[i] do
            j = next[j - 1]
        end while
        if needle[j] == needle[i] then
            j = j + 1
        end if
        next[i] = j
    end for
end function
```

#### 8.2 面试题2：二叉树遍历

**题目描述**：给定一个二叉树，实现其先序遍历、中序遍历和后序遍历。

**解题思路**：使用递归或迭代的方法进行遍历。以下使用递归方法实现三种遍历。

**伪代码**：

```pseudocode
function traverse(node : TreeNode)
    if node == null then
        return
    end if
    // 先序遍历
    visit(node)
    traverse(node.left)
    traverse(node.right)
end function

function inorderTraversal(root : TreeNode) -> array of integers
    result = empty array
    traverse(root, result)
    return result
end function

function preorderTraversal(root : TreeNode) -> array of integers
    result = empty array
    traverse(root, result)
    return result
end function

function postorderTraversal(root : TreeNode) -> array of integers
    result = empty array
    traverse(root, result)
    reverse(result)
    return result
end function
```
