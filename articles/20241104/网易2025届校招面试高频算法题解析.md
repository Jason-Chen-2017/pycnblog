### 附录 B：核心算法原理讲解

#### 动态规划原理

**动态规划（Dynamic Programming，简称 DP）** 是一种在数学、管理科学、计算机科学、经济学和生物信息学中使用的，通过把原问题分解为相对简单的子问题的方式求解复杂问题的方法。动态规划常常用于求解优化问题。

**基本思想：**
1. **将原问题分解为子问题。**
2. **从最简单的子问题开始，自底向上或自顶向下依次求解子问题。**
3. **在子问题求解的过程中，保存子问题的解，避免重复计算。**

**状态转移方程：**
设 `dp[i][j]` 表示求解子问题时第 `i` 个元素和第 `j` 个元素的关系。

**递推关系：**
- **状态转移方程通常写成递推关系，例如：`dp[i] = dp[i-1] + dp[i-2]`**
- **状态转移方程需要满足无后效性，即当前状态只与相邻的前一个状态有关。**

**伪代码示例：**

```plaintext
for i from 1 to n do:
    for j from 1 to n do:
        dp[i][j] = 状态转移方程
```

### 附录 C：数学模型与公式

#### 最短路径算法中的距离公式

$$
d(u, v) = \min\left(\sum_{i=1}^{n} w_i, \sum_{i=1}^{n} w_i \cdot \frac{d(u, v)}{l}\right)
$$

其中，$u$ 和 $v$ 表示顶点，$w_i$ 表示从 $u$ 到 $v$ 的权值，$l$ 表示路径长度。

### 附录 D：代码实际案例

#### 暴力破解最大子序列和问题

```python
def maxSubArray(nums):
    n = len(nums)
    max_sum = float('-inf')
    for i in range(n):
        for j in range(i, n):
            curr_sum = 0
            for k in range(i, j+1):
                curr_sum += nums[k]
            max_sum = max(max_sum, curr_sum)
    return max_sum
```
