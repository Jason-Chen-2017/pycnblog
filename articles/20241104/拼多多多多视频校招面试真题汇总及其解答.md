          if (head == null || head.next == null) {
              return head;
          }

          ListNode curr = head;
          while (curr != null) {
              ListNode nextTemp = curr.next;
              curr.next = prev;
              prev = curr;
              curr = nextTemp;
          }
          return prev;
      }

##### 3.1.1 数据结构与算法面试题案例

**案例一：链表反转**

题目描述：实现一个函数，对链表进行反转。

解题思路：
1. 初始化三个指针：`prev`、`curr` 和 `next`。
2. 遍历链表，将当前节点的`next`指针指向前一个节点。
3. 移动`prev`和`curr`指针，继续遍历。
4. 当遍历到链表末尾时，返回新的头节点。

伪代码：
```plaintext
function reverseList(head):
    prev = null
    curr = head
    next = null

    while curr is not null:
        next = curr.next
        curr.next = prev
        prev = curr
        curr = next

    return prev
```

**案例二：最长公共子序列**

题目描述：给定两个字符串，找出它们的最长公共子序列。

解题思路：
1. 使用二维数组`dp`来存储子序列的长度。
2. 遍历字符串`s1`和`s2`的每个字符，更新`dp`数组。
3. 根据`dp`数组找到最长公共子序列。

伪代码：
```plaintext
function longestCommonSubsequence(s1, s2):
    m = length(s1)
    n = length(s2)

    dp = createMatrix(m+1, n+1)

    for i from 0 to m:
        for j from 0 to n:
            if s1[i] == s2[j]:
                dp[i+1][j+1] = dp[i][j] + 1
            else:
                dp[i+1][j+1] = max(dp[i][j+1], dp[i+1][j])

    return reconstructLCS(dp, s1, s2)

function reconstructLCS(dp, s1, s2):
    result = ""
    i = length(s1)
    j = length(s2)

    while i > 0 and j > 0:
        if s1[i-1] == s2[j-1]:
            result = s1[i-1] + result
            i = i - 1
            j = j - 1
        elif dp[i-1][j] > dp[i][j-1]:
            i = i - 1
        else:
            j = j - 1

    return result
```

**案例三：二分查找**

题目描述：在有序数组中查找一个目标值，并返回其索引。

解题思路：
1. 初始化两个指针：`left`和`right`。
2. 当`left`小于等于`right`时，计算中间索引`mid`。
3. 如果中间元素等于目标值，返回索引`mid`。
4. 如果中间元素大于目标值，将`right`更新为`mid-1`。
5. 如果中间元素小于目标值，将`left`更新为`mid+1`。
6. 如果未找到目标值，返回-1。

伪代码：
```plaintext
function binarySearch(arr, target):
    left = 0
    right = length(arr) - 1

    while left <= right:
        mid = (left + right) / 2

        if arr[mid] == target:
            return mid
        elif arr[mid] > target:
            right = mid - 1
        else:
            left = mid + 1

    return -1
```

##### 3.1.2 编程语言面试题案例

**案例一：Java多线程编程**

题目描述：使用Java实现一个简单的多线程计数器。

解题思路：
1. 创建一个继承`Thread`类的子类，重写`run`方法。
2. 在`run`方法中，使用`synchronized`关键字同步对共享变量的访问。
3. 在主线程中创建并启动多个线程。

伪代码：
```java
class CounterThread extends Thread {
    private int count;

    public void run() {
        synchronized(this) {
            for (int i = 0; i < 100000; i++) {
                count++;
            }
        }
    }

    public int getCount() {
        return count;
    }
}

public class Main {
    public static void main(String[] args) {
        CounterThread counterThread1 = new CounterThread();
        CounterThread counterThread2 = new CounterThread();

        counterThread1.start();
        counterThread2.start();

        try {
            counterThread1.join();
            counterThread2.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        System.out.println("Total count: " + (counterThread1.getCount() + counterThread2.getCount()));
    }
}
```

   - **背景**：简要介绍问题或情景的背景。
