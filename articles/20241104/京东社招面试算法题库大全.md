```plaintext
function reverseLinkedList(head):
    if head is null or head.next is null:
        return head
    
    prev = null
    current = head
    while current is not null:
        next = current.next
        current.next = prev
        prev = current
        current = next
    
    return prev
```

这个算法通过三个指针（prev、current、next）实现了链表的反转。在这个过程中，prev 指针始终指向已反转部分的最后一个节点，current 指针逐步前进，next 指针用来保存 current 的下一个节点，以避免链表在反转过程中的断链。

public ListNode findMiddleNode(ListNode head) {
    ListNode slow = head;

### 2.1 基础数据结构

数据结构是计算机科学中一个重要的概念，它是用于存储和管理数据的各种方式。在算法面试中，数据结构的选择直接影响算法的效率和复杂度。本章将介绍几种常见的基础数据结构，包括数组、链表、栈和队列。

#### 2.1.1 数组

**定义与特性**：

数组是一种线性数据结构，用于存储一系列元素。它具有以下特性：

- **元素类型相同**：数组中的所有元素必须是同一类型的。
- **通过索引访问**：数组中的每个元素都可以通过一个整数索引来访问，索引从0开始。

**基本操作**：

- **访问**：`arr[index]`
- **插入**：`arr[index] = value`
- **删除**：`arr.splice(index, 1)`

**时间复杂度**：

- **访问**：O(1)
- **插入/删除**：O(n)

**应用场景**：

- **实现其他数据结构**：数组是许多高级数据结构（如堆、队列等）的基础。
- **用于存储和访问大量数据**：在需要快速访问数据的情况下，数组是一个很好的选择。

#### 2.1.2 链表

**定义与特性**：

链表由一系列节点组成，每个节点包含数据域和指针域。链表具有以下特性：

- **动态大小**：链表的大小可以根据需要动态扩展或缩减。
- **非连续存储**：链表的节点可以在内存中非连续地分布。

**基本操作**：

- **插入**：在特定位置插入新节点。
- **删除**：删除特定位置的节点。
- **遍历**：从头部或尾部开始遍历整个链表。

**时间复杂度**：

- **插入/删除**：O(n)
- **遍历**：O(n)

**应用场景**：

- **实现其他数据结构**：链表是许多高级数据结构（如栈、队列等）的基础。
- **用于解决动态问题**：在需要频繁插入和删除数据的情况下，链表是一个很好的选择。

#### 2.1.3 栈

**定义与特性**：

栈是一种后进先出（Last In First Out, LIFO）的数据结构。它具有以下特性：

- **只能在一端进行操作**：栈的顶部是唯一的操作点。
- **操作顺序**：最后进入的元素首先被移出。

**基本操作**：

- **压栈**：将元素添加到栈顶。
- **弹栈**：从栈顶移除元素。
- **查看栈顶元素**：获取栈顶元素但不移除。

**时间复杂度**：

- **压栈/弹栈**：O(1)

**应用场景**：

- **函数调用**：在程序中，函数调用的顺序与栈的操作顺序一致。
- **括号匹配**：用于检查代码中的括号是否匹配。

#### 2.1.4 队列

**定义与特性**：

队列是一种先进先出（First In First Out, FIFO）的数据结构。它具有以下特性：

- **只能在两端进行操作**：队列的前端用于添加元素，后端用于移除元素。
- **操作顺序**：最早进入的元素首先被移出。

**基本操作**：

- **入队**：在队列的末尾添加元素。
- **出队**：从队列的前端移除元素。
- **查看队首元素**：获取队首元素但不移除。

**时间复杂度**：

- **入队/出队**：O(1)

**应用场景**：

- **消息队列**：在分布式系统中，消息队列用于处理和传递大量消息。
- **打印任务**：在打印系统中，打印任务通常按照先来先服务的原则进行处理。

**核心算法原理讲解**：

在了解数据结构的基础上，我们需要掌握如何利用这些数据结构来解决实际问题。以下是一个关于链表和栈的算法原理讲解。

#### 链表反转

**伪代码**：

```plaintext
function reverseLinkedList(head):
    if head is null or head.next is null:
        return head
    
    prev = null
    current = head
    while current is not null:
        next = current.next
        current.next = prev
        prev = current
        current = next
    
    return prev
```

**算法原理**：

- **初始化**：使用三个指针（`prev`、`current`、`next`），其中`prev`指向已反转链表的最后一个节点，`current`指向当前节点，`next`指向下一个节点。
- **循环反转**：在循环中，首先保存当前节点的下一个节点（`next`），然后将当前节点的下一个节点指向已反转部分的最后一个节点（`prev`）。接着，将`prev`更新为当前节点，`current`更新为`next`。
- **返回结果**：当`current`变为`null`时，`prev`即为反转后的链表的头节点。

这个算法的时间复杂度为O(n)，因为需要遍历链表一次，空间复杂度为O(1)，因为只需要常数级别的额外空间。

#### 栈与队列的应用

**栈**：用于解决括号匹配问题

**伪代码**：

```plaintext
function isValid(s):
    stack = empty stack
    for char in s:
        if char is '(' or '[' or '{':
            push char to stack
        else:
            if stack.isEmpty():
                return false
            pop top element from stack
            if char != corresponding bracket of the popped element:
                return false
    return stack.isEmpty()
```

**算法原理**：

- **初始化**：使用一个栈来存储括号。
- **遍历字符串**：对于每个字符，如果它是左括号，则将其入栈；如果它是右括号，则检查栈顶元素是否为其对应的左括号。如果是，则将栈顶元素出栈；否则，返回`false`。
- **判断结果**：遍历结束后，如果栈为空，则所有括号均匹配，返回`true`；否则，返回`false`。

这个算法的时间复杂度为O(n)，因为需要遍历字符串一次，空间复杂度为O(n)，因为需要使用栈来存储括号。

#### 3.1.1 等级树遍历

**问题描述**：

给定一个等级树（也称为层次遍历树或广度优先搜索树），按照从上到下、从左到右的顺序遍历树的节点。

**示例**：

```
输入：
   1
  / \
 2   3
 / \
4   5

输出：
[1, 2, 3, 4, 5]
```

**解题思路**：

可以使用广度优先搜索（BFS）算法来遍历等级树。具体步骤如下：

1. 使用一个队列来存储树的节点。
2. 初始化队列，将根节点入队。
3. 进入循环，直到队列为空：
   - 出队一个节点，将其值加入结果列表。
   - 将该节点的左右子节点（如果存在）入队。

**伪代码**：

```plaintext
function levelOrderTraversal(root):
    if root is null:
        return []

    queue = empty queue
    queue.enqueue(root)
    result = empty list

    while queue is not empty:
        node = queue.dequeue()
        result.append(node.value)

        if node.left is not null:
            queue.enqueue(node.left)
        if node.right is not null:
            queue.enqueue(node.right)

    return result
```

**时间复杂度**：O(n)，其中 n 是树的节点数，因为需要遍历所有节点一次。
**空间复杂度**：O(n)，因为队列中最多存储 n 个节点。

#### 3.1.2 单链表反转

**问题描述**：

给定一个单链表，将其反转。例如：

```
输入：
  1 -> 2 -> 3 -> 4 -> 5

输出：
  5 -> 4 -> 3 -> 2 -> 1
```

**解题思路**：

使用三个指针（`prev`、`current`、`next`）来实现链表反转。具体步骤如下：

1. 初始化 `prev` 和 `current` 指针为 `null` 和 `head`（链表的头节点）。
2. 遍历链表，每次循环执行以下操作：
   - 保存当前节点的下一个节点（`next`）。
   - 将当前节点的 `next` 指针指向 `prev`。
   - 将 `prev` 更新为当前节点。
   - 将 `current` 更新为 `next`。
3. 当 `current` 变为 `null` 时，`prev` 即为反转后的链表的头节点。

**伪代码**：

```plaintext
function reverseLinkedList(head):
    if head is null or head.next is null:
        return head
    
    prev = null
    current = head
    while current is not null:
        next = current.next
        current.next = prev
        prev = current
        current = next
    
    return prev
```

**时间复杂度**：O(n)，其中 n 是链表的长度，因为需要遍历链表一次。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 3.1.3 快乐数

**问题描述**：

编写一个算法来判断一个正整数是否为快乐数。

**定义**：

- 一个“快乐数”定义为：对于一个正整数，每一次将该数替换为其每个位置上的数字的平方和，然后重复这个操作直到这个数变为1，也可能是无限循环但不会变为1，这个数就是快乐数。

**示例**：

```
输入：19
输出：true
解释：
1^2 + 9^2 = 82
8^2 + 2^2 = 68
6^2 + 8^2 = 100
1^2 + 0^2 + 0^2 = 1
```

**解题思路**：

使用快慢指针法来判断一个数是否为快乐数。具体步骤如下：

1. 初始化快指针 `fast` 和慢指针 `slow` 都指向当前数。
2. 进入循环，直到快指针移动了两次且快指针不为 `1`：
   - 移动慢指针一次。
   - 移动快指针两次。
   - 在每次移动前，计算当前数的平方和，并更新当前数为平方和。
3. 如果快指针指向 `1`，则当前数是快乐数；否则，不是快乐数。

**伪代码**：

```plaintext
function isHappy(n):
    if n is null:
        return false
    
    slow = n
    fast = n
    
    while fast != 1 and fast.next != 1:
        slow = getSquareSum(slow)
        fast = getSquareSum(getSquareSum(fast))
    
    return fast == 1

function getSquareSum(n):
    sum = 0
    while n > 0:
        digit = n % 10
        sum += digit * digit
        n /= 10
    
    return sum
```

**时间复杂度**：O(log(n)^2)，其中 n 是输入的数字，因为每次计算平方和会减少一位数字，大约需要 O(log(n)) 次，而每次减少一位数字需要 O(log(n)) 次操作。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 4.1.1 判断链表中环的入口节点

**问题描述**：

给定一个链表，判断链表中是否存在环，并找出环的入口节点。例如：

```
输入：
  1 -> 2 -> 3 -> 4 -> 5
        ^    |
        |    |
        ----- 

输出：
  环的入口节点为 3
```

**解题思路**：

使用快慢指针法来检测链表中是否存在环，并找出环的入口节点。具体步骤如下：

1. 初始化快指针 `fast` 和慢指针 `slow` 都指向链表的头节点。
2. 同时移动快指针和慢指针，快指针每次移动两个节点，慢指针每次移动一个节点。
3. 当快指针追上慢指针时，说明链表中存在环。
4. 将慢指针重置为链表的头节点，然后同时移动快指针和慢指针，当它们再次相遇时，相遇点即为环的入口节点。

**伪代码**：

```plaintext
function detectCycle(head):
    if head is null or head.next is null:
        return null
    
    slow = head
    fast = head
    
    while fast is not null and fast.next is not null:
        slow = slow.next
        fast = fast.next.next
        
        if slow == fast:
            slow = head
            while slow != fast:
                slow = slow.next
                fast = fast.next
            return slow
    
    return null
```

**时间复杂度**：O(n)，其中 n 是链表的长度，因为需要遍历链表一次。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 4.1.2 二维数组中的查找

**问题描述**：

在一个二维数组中，给定一个目标值，判断是否存在目标值。例如：

```
输入：
[
  [1,   4,  7, 11, 15],
  [2,   5,  8, 12, 19],
  [3,   6,  9, 16, 22],
  [10, 13, 14, 17, 24],
  [18, 21, 23, 26, 30]
]
目标值：5

输出：
  存在目标值
```

**解题思路**：

从数组的第一行第一列开始，通过比较目标值和当前位置的值来决定下一步的移动方向。具体步骤如下：

1. 设置行索引 `row` 为 0，列索引 `col` 为数组列数减 1。
2. 当 `row` 小于行数或 `col` 小于列数时，执行以下步骤：
   - 如果当前值等于目标值，返回 `true`。
   - 如果当前值小于目标值，将行索引加 1。
   - 如果当前值大于目标值，将列索引减 1。
3. 如果遍历整个数组仍未找到目标值，返回 `false`。

**伪代码**：

```plaintext
function findTarget(matrix, target):
    if matrix is empty:
        return false
    
    rows = matrix.length
    cols = matrix[0].length
    
    row = 0
    col = cols - 1
    
    while row < rows and col >= 0:
        if matrix[row][col] == target:
            return true
        elif matrix[row][col] < target:
            row += 1
        else:
            col -= 1
            
    return false
```

**时间复杂度**：O(m+n)，其中 m 是行数，n 是列数，因为最坏情况下需要遍历整个数组。

2. 创建一个新的字符数组 `newChars`，长度为原字符串长度加上 `spaceCount` * 2。

4. 遍历原字符串，对于每个非空格字符，将其复制到新字符数组中，`i` 和 `j` 同时加 1。
5. 对于每个空格，将 `%20` 复制到新字符数组中，`j` 增加 3。

function replaceSpaces(s, spaceNum):
    if s is null:
        return null
    
    spaceCount = 0
    for char in s:
        if char == ' ':
            spaceCount += 1
    
    newLen = len(s) + spaceCount * 2
    newChars = new array of length newLen
    
    i = 0
    j = 0
    while i < len(s):
        if s[i] != ' ':
            newChars[j] = s[i]
            i += 1
            j += 1
        else:
            newChars[j] = '%'
            newChars[j+1] = '2'
            newChars[j+2] = '0'
            i += 1
            j += 3

#### 5.1.1 短串滚动哈希

**问题描述**：

实现一个函数，用于计算给定字符串的滚动哈希值。滚动哈希是一种用于字符串匹配和数据校验的算法。给定一个字符串 `s` 和一个长度 `k`，计算 `s` 的前 `k` 个字符的哈希值，然后每次滑动一个字符，更新哈希值。

**示例**：

```
输入：
s = "abcabcabc", k = 3
输出：
[150, 44, 100]

解释：
前三个字符 "abc" 的哈希值为 150。
滑动一个字符后，前三个字符为 "bca"，哈希值为 44。
再次滑动一个字符后，前三个字符为 "cab"，哈希值为 100。
```

**解题思路**：

使用Rabin-Karp算法来计算滚动哈希值。Rabin-Karp算法利用大素数来减少哈希冲突。

1. **哈希函数**：选择一个适当的大素数 `p`，计算字符串的前 `k` 个字符的哈希值。
2. **滚动哈希**：每次滑动一个字符，更新哈希值。新哈希值等于旧哈希值减去滑动出字符的哈希值，然后加上新字符的哈希值。

**伪代码**：

```plaintext
function rabinKarpHash(s, k, p):
    n = length(s)
    hashValue = 0
    for i from 0 to k - 1:
        hashValue = (hashValue * 256 + ord(s[i])) % p
    
    pPower = 1
    for i from 0 to k - 1:
        pPower = (pPower * 256) % p
    
    result = [hashValue]
    for i from k to n - 1:
        result.append((result[i - k] * pPower + ord(s[i])) % p)
    
    return result
```

**时间复杂度**：O(n)，其中 n 是字符串的长度。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 5.1.2 字符串匹配

**问题描述**：

**示例**：

```
输入：
s = "ababcabcababc", p = "ababc"
输出：
[2, 7]
```

**解题思路**：

使用KMP（Knuth-Morris-Pratt）算法来高效地搜索模式字符串。

1. **构建部分匹配表（Next数组）**：计算模式字符串 `p` 的部分匹配值，用于跳过不必要的比较。
2. **搜索**：从文本字符串 `s` 的开头开始匹配，如果当前字符匹配成功，继续比较下一个字符；如果不匹配，使用Next数组跳过部分字符，减少不必要的比较。

**伪代码**：

```plaintext
function kmpSearch(s, p):
    n = length(s)
    m = length(p)
    next = buildNextArray(p)
    i = j = 0
    
    while i < n:
        if j == -1 or s[i] == p[j]:
            i += 1
            j += 1
        else:
            j = next[j]
        
        if j == m:
            return [i - j]
            j = next[j]
    
    return []

function buildNextArray(p):
    n = length(p)
    next = [-1] * n
    j = 0
    i = 1
    
    while i < n:
        if p[j] == p[i]:
            next[i] = j + 1
            j += 1
            i += 1
        elif j == -1:
            next[i] = 0
            i += 1
        else:
            j = next[j]
    
    return next
```

**时间复杂度**：O(n + m)，其中 n 是文本字符串的长度，m 是模式字符串的长度。
**空间复杂度**：O(m)，因为需要存储部分匹配值。

#### 5.1.3 有效括号序列

**问题描述**：

给定一个字符串 `s`，判断其是否是一个有效的括号序列。有效的括号序列意味着它必须满足以下条件：

- 左括号必须以相同类型的右括号闭合。
- 左括号必须以正确的顺序闭合。

**示例**：

```
输入：
s = "()()()"
输出：
true
```

**解题思路**：

使用一个栈来跟踪尚未闭合的左括号。

1. 遍历字符串 `s`，对于每个字符：
   - 如果是左括号，将其入栈。
   - 如果是右括号，检查栈顶元素是否为与之匹配的左括号：
     - 如果匹配，弹出栈顶元素。
     - 如果不匹配，返回 `false`。
2. 遍历结束后，如果栈为空，返回 `true`；否则，返回 `false`。

**伪代码**：

```plaintext
function isValid(s):
    stack = empty stack
    
    for char in s:
        if char is '(':
            stack.push(')')
        elif char is ')' and not stack.isEmpty() and stack.peek() == ')':
            stack.pop()
        else:
            return false
    
    return stack.isEmpty()
```

**时间复杂度**：O(n)，其中 n 是字符串的长度。
**空间复杂度**：O(n)，因为最坏情况下，所有字符都是左括号。

### 7.1 数据结构与算法问题

**如何选择合适的数据结构？**

选择合适的数据结构是算法设计的关键。以下是一些常见场景和数据结构的匹配：

- **查找**：对于频繁查找的问题，可以考虑使用哈希表，因为它具有极快的查找时间（O(1)）。
- **排序**：对于需要排序的数据，可以使用数组、链表、二叉树等数据结构。二叉搜索树特别适用于需要频繁查找、插入和删除的排序问题。
- **存储**：对于需要高效插入和删除的元素，可以使用链表。对于需要随机访问的元素，可以使用数组。
- **缓存**：在缓存系统中，常用的数据结构是队列和堆。
- **路径搜索**：在图算法中，常用的数据结构是图本身、栈和队列。

**如何分析算法的时间复杂度？**

分析算法的时间复杂度需要关注算法在输入规模变化时的执行时间增长趋势。以下是一些常见的时间复杂度分析步骤：

1. **确定算法的基本操作**：找出算法中最频繁执行的操作。
2. **分析基本操作的次数**：考虑输入规模变化时，基本操作的执行次数如何变化。
3. **确定时间复杂度**：将基本操作的次数表示为一个关于输入规模的函数，并确定其最高次项。
4. **计算常数系数**：通常省略常数系数，只关注最高次项。

例如，对于冒泡排序，基本操作是交换相邻元素，假设输入规模为 n，则最坏情况下需要交换 \( \frac{n(n-1)}{2} \) 次，因此时间复杂度为 \( O(n^2) \)。

**动态规划与贪心算法的区别是什么？**

动态规划和贪心算法是两种常用的算法设计方法，它们的主要区别如下：

- **动态规划**：动态规划通常用于解决最优子结构问题。它通过递归和 memoization（记忆化搜索）来避免重复计算，从而得到全局最优解。动态规划通常涉及到状态转移方程和状态的初始化。
- **贪心算法**：贪心算法通过在每个步骤中选择当前最优解，从而期望得到全局最优解。贪心算法通常没有递归结构，它基于局部最优解直接得到全局最优解。

例如，求最长公共子序列问题适合使用动态规划，而求最短路径问题中的迪杰斯特拉算法适合使用贪心算法。

#### 8.1.1 反转链表

**问题描述**：

给定一个单链表，将其反转。例如：

```
输入：
1 -> 2 -> 3 -> 4 -> 5

输出：
5 -> 4 -> 3 -> 2 -> 1
```

**解题思路**：

使用三个指针（`prev`、`current`、`next`）来逐步反转链表。具体步骤如下：

1. 初始化 `prev` 为 `null`，`current` 为 `head`。
2. 进入循环，直到 `current` 变为 `null`：
   - 保存当前节点的下一个节点（`next`）。
   - 将当前节点的 `next` 指针指向 `prev`。
   - 将 `prev` 更新为当前节点。
   - 将 `current` 更新为 `next`。
3. 最后返回 `prev`，即反转后的链表的头节点。

**伪代码**：

```plaintext
function reverseLinkedList(head):
    if head is null or head.next is null:
        return head
    
    prev = null
    current = head
    while current is not null:
        next = current.next
        current.next = prev
        prev = current
        current = next
    
    return prev
```

**时间复杂度**：O(n)，其中 n 是链表的长度。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 8.1.2 检测链表循环

**问题描述**：

给定一个链表，判断链表中是否存在循环。例如：

```
输入：
  1 -> 2 -> 3 -> 4 -> 5
        ^       |
        |       |
        ------- 

输出：
  存在循环
```

**解题思路**：

使用快慢指针法来检测链表中是否存在循环。具体步骤如下：

1. 初始化快指针 `fast` 和慢指针 `slow` 都指向链表的头节点。
2. 同时移动快指针和慢指针，快指针每次移动两个节点，慢指针每次移动一个节点。
3. 当快指针追上慢指针时，说明链表中存在循环。
4. 返回 `true`；否则，返回 `false`。

**伪代码**：

```plaintext
function hasCycle(head):
    if head is null:
        return false
    
    slow = head
    fast = head
    
    while fast is not null and fast.next is not null:
        slow = slow.next
        fast = fast.next.next
        
        if slow == fast:
            return true
    
    return false
```

**时间复杂度**：O(n)，其中 n 是链表的长度。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 8.1.3 合并两个有序链表

**问题描述**：

给定两个有序链表，将它们合并为一个有序链表。例如：

```
输入：
  1 -> 3 -> 5
  2 -> 4 -> 6

输出：
  1 -> 2 -> 3 -> 4 -> 5 -> 6
```

**解题思路**：

使用两个指针分别遍历两个有序链表，比较当前节点的值，将较小的节点加入新链表，并移动相应的指针。具体步骤如下：

1. 初始化两个指针 `p1` 和 `p2` 分别指向两个链表的头节点。
2. 创建一个新的链表 `result`，初始化为 `null`。
3. 进入循环，直到 `p1` 或 `p2` 为 `null`：
   - 比较两个节点的值，将较小的节点加入 `result`。
   - 移动对应的指针。
4. 将非空链表的剩余部分连接到 `result` 的尾部。
5. 返回 `result`。

**伪代码**：

```plaintext
function mergeSortedLists(l1, l2):
    if l1 is null:
        return l2
    if l2 is null:
        return l1
    
    if l1.val < l2.val:
        result = l1
        l1 = l1.next
    else:
        result = l2
        l2 = l2.next
    
    current = result
    
    while l1 is not null and l2 is not null:
        if l1.val < l2.val:
            current.next = l1
            l1 = l1.next
        else:
            current.next = l2
            l2 = l2.next
        current = current.next
    
    if l1 is not null:
        current.next = l1
    else:
        current.next = l2
    
    return result
```

**时间复杂度**：O(n + m)，其中 n 和 m 分别是两个链表的长度。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 8.2.1 寻找旋转排序数组中的最小值

**问题描述**：

给定一个旋转排序的数组，找出数组中的最小值。例如：

```
输入：
[4, 5, 6, 7, 0, 1, 2]

输出：
0
```

**解题思路**：

利用二分查找的方法来寻找最小值。具体步骤如下：

1. 初始化 `left` 为 `0`，`right` 为 `nums.length - 1`。
2. 当 `left < right` 时，执行以下步骤：
   - 计算中间索引 `mid = (left + right) / 2`。
   - 如果 `nums[mid] > nums[right]`，说明最小值在 `mid` 的右侧，将 `left = mid + 1`。
   - 否则，最小值在 `mid` 的左侧或就在 `mid`，将 `right = mid`。
3. 循环结束后，`left` 所在的位置即为最小值。

**伪代码**：

```plaintext
function findMin(nums):
    if nums is null or nums.length == 0:
        return -1
    
    left = 0
    right = nums.length - 1
    
    while left < right:
        mid = (left + right) / 2
        
        if nums[mid] > nums[right]:
            left = mid + 1
        else:
            right = mid
            
    return nums[left]
```

**时间复杂度**：O(log(n))，其中 n 是数组的长度。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 8.2.2 螺旋矩阵

**问题描述**：

给定一个 `m x n` 的二维矩阵，按照螺旋顺序返回矩阵中的所有元素。例如：

```
输入：
[
  [ 1, 2, 3 ],
  [ 4, 5, 6 ],
  [ 7, 8, 9 ]
]

输出：
[1, 2, 3, 6, 9, 8, 7, 4, 5]
```

**解题思路**：

按照螺旋顺序遍历矩阵，可以分四步进行：

1. 从左到右遍历顶部行的所有元素。
2. 从上到下遍历右侧列的所有元素。
3. 从右到左遍历底部行的所有元素。
4. 从下到上遍历左侧列的所有元素。
5. 重复上述步骤，直到遍历完整个矩阵。

**伪代码**：

```plaintext
function spiralOrder(matrix):
    if matrix is null or matrix.length == 0:
        return []
    
    result = empty list
    m = matrix.length
    n = matrix[0].length
    
    top = 0
    bottom = m - 1
    left = 0
    right = n - 1
    
    while top <= bottom and left <= right:
        for i from left to right:
            result.append(matrix[top][i])
        top += 1
        
        for i from top to bottom:
            result.append(matrix[i][right])
        right -= 1
        
        if top <= bottom:
            for i from right downto left:
                result.append(matrix[bottom][i])
            bottom -= 1
            
        if left <= right:
            for i from bottom downto top:
                result.append(matrix[i][left])
            left += 1
            
    return result
```

**时间复杂度**：O(m*n)，其中 m 是行数，n 是列数，因为需要遍历所有元素一次。
**空间复杂度**：O(1)，因为只需要常数级别的额外空间。

#### 8.2.3 有效的数独

**问题描述**：

判断一个 `9 x 9` 的数独是否有效。数独规则如下：

- 每行必须包含 1 到 9 的所有数字。
- 每列必须包含 1 到 9 的所有数字。
- 每个 `3 x 3` 子网格必须包含 1 到 9 的所有数字。

**示例**：

```
输入：
[
  [5, 3, 0, 0, 7, 0, 0, 0, 0],
  [6, 0, 0, 1, 9, 5, 0, 0, 0],
  [0, 9, 8, 0, 0, 0, 0, 6, 0],
  [8, 0, 0, 0, 6, 0, 0, 0, 3],
  [4, 0, 0, 8, 0, 3, 0, 0, 1],
  [7, 0, 0, 0, 2, 0, 0, 0, 6],
  [0, 6, 0, 0, 0, 0, 2, 8, 0],
  [0, 0, 0, 4, 1, 9, 0, 0, 5],
  [0, 0, 0, 0, 8, 0, 0, 7, 9]
]

输出：
  true
```

**解题思路**：

使用三个哈希集合来分别存储每行、每列和每个 `3 x 3` 子网格中的数字。

1. 遍历数独矩阵，对于每个元素：
   - 如果该元素为数字且不在当前行的集合中、当前列的集合中和当前 `3 x 3` 子网格的集合中，则添加到相应的集合中。
   - 如果该元素为数字且已存在于当前行的集合中、当前列的集合中或当前 `3 x 3` 子网格的集合中，则说明数独无效，返回 `false`。
2. 遍历结束后，返回 `true`。

**伪代码**：

```plaintext
function isValidSudoku(board):
    rows = [empty set for _ in range(9)]
    cols = [empty set for _ in range(9)]
    boxes = [empty set for _ in range(9)]
    
    for i from 0 to 8:
        for j from 0 to 8:
            num = board[i][j]
            if num != '.':
                rowIdx = i // 3
                colIdx = j // 3
                if num in rows[i] or num in cols[j] or num in boxes[rowIdx * 3 + colIdx]:
                    return false
                rows[i].add(num)
                cols[j].add(num)
                boxes[rowIdx * 3 + colIdx].add(num)
                
    return true
```

**时间复杂度**：O(1)，因为最多处理 \( 9 \times 9 = 81 \) 个元素。
**空间复杂度**：O(1)，因为最多需要存储 \( 9 \times 9 = 81 \) 个元素。

#### 8.3.1 二叉树的遍历

**问题描述**：

实现二叉树的遍历算法，包括先序遍历、中序遍历和后序遍历。例如：

```
给定一棵二叉树：
    1
   / \
  2   3
 / \ / \
4  5 6  7

先序遍历输出：
1, 2, 4, 5, 3, 6, 7

中序遍历输出：
4, 2, 5, 1, 6, 3, 7

后序遍历输出：
4, 5, 2, 6, 7, 3, 1
```

**解题思路**：

二叉树的遍历算法可以通过递归或迭代实现。

- **递归实现**：直接调用自身进行递归遍历。
- **迭代实现**：使用栈或队列进行模拟递归过程。

**递归实现**：

**伪代码**：

```plaintext
// 先序遍历
function preorderTraversal(root):
    if root is null:
        return []
    return [root.val] + preorderTraversal(root.left) + preorderTraversal(root.right)

// 中序遍历
function inorderTraversal(root):
    if root is null:
        return []
    return inorderTraversal(root.left) + [root.val] + inorderTraversal(root.right)

// 后序遍历
function postorderTraversal(root):
    if root is null:
        return []
    return postorderTraversal(root.left) + postorderTraversal(root.right) + [root.val]
```

**迭代实现**：

**伪代码**：

```plaintext
// 先序遍历
function preorderTraversalIterative(root):
    if root is null:
        return []
    stack = [root]
    result = []
    
    while stack is not empty:
        node = stack.pop()
        result.append(node.val)
        
        if node.right is not null:
            stack.append(node.right)
        if node.left is not null:
            stack.append(node.left)
    
    return result

// 中序遍历和后序遍历的实现与先序遍历类似，只需调整遍历顺序。
```

**时间复杂度**：O(n)，其中 n 是二叉树的节点数。
**空间复杂度**：O(n)，因为需要存储节点。

#### 8.3.2 最短路径问题

**问题描述**：

给定一个图和两个节点 `start` 和 `end`，求从 `start` 到 `end` 的最短路径。例如：

```
给定图如下：

  1 --- 2 --- 3
  |   |   |   |
  4 --- 5 --- 6
  |       |   |
  7       8   9

从节点 1 到节点 6 的最短路径为：
1 -> 2 -> 3 -> 6
```

**解题思路**：

常用的最短路径算法包括迪杰斯特拉算法（Dijkstra）和贝尔曼-福特算法（Bellman-Ford）。

- **迪杰斯特拉算法**：适用于非负权图，使用优先队列（小根堆）来选择最小距离的未访问节点。
- **贝尔曼-福特算法**：适用于有负权边的图，通过多次松弛操作来计算最短路径。

**迪杰斯特拉算法**：

**伪代码**：

```plaintext
function dijkstra(graph, start):
    distances = [infinity for _ in range(len(graph))]
    distances[start] = 0
    priorityQueue = new PriorityQueue()
    priorityQueue.insert((0, start))
    
    while not priorityQueue.isEmpty():
        currentDistance, currentNode = priorityQueue.extractMin()
        
        if currentDistance != distances[currentNode]:
            continue
        
        for neighbor, weight in graph[currentNode]:
            distance = currentDistance + weight
            
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                priorityQueue.insert((distance, neighbor))
    
    return distances
```

**时间复杂度**：O((V+E)log(V))，其中 V 是顶点数，E 是边数。
**空间复杂度**：O(V)，因为需要存储距离和优先队列。

#### 8.3.3 图的深度优先搜索

**问题描述**：

使用深度优先搜索（DFS）算法来遍历图，并找出图中所有连通分量。例如：

```
给定图如下：

  1 --- 2
  |     |
  3 --- 4

连通分量有：
1-2-3-4
```

**解题思路**：

深度优先搜索是一种用于遍历或搜索图的算法。具体步骤如下：

1. 从起始节点开始，递归地访问所有未访问的相邻节点。
2. 每次访问一个节点后，将其标记为已访问。
3. 继续递归地访问其相邻节点，直到所有节点都被访问。

**伪代码**：

```plaintext
function dfs(graph, start, visited):
    if start in visited:
        return
    visited.add(start)
    for neighbor in graph[start]:
        dfs(graph, neighbor, visited)
```

**时间复杂度**：O(V+E)，其中 V 是顶点数，E 是边数。
**空间复杂度**：O(V)，因为需要存储已访问的节点。
