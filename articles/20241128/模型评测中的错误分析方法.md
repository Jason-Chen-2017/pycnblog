### Basic Concepts of Model Evaluation Metrics

#### 2.1. Accuracy, Precision, Recall, and F1 Score

**Mermaid Flowchart:**
```mermaid
graph TD
    A[Accuracy] --> B[True Positives + True Negatives]
    B --> C[Total Samples]
    D[Precision] --> E[True Positives / (True Positives + False Positives)]
    F[Recall] --> G[True Positives / (True Positives + False Negatives)]
    H[F1 Score] --> I[2 * Precision * Recall / (Precision + Recall)]
```

**Mathematical Formulas:**
$$
\text{Accuracy} = \frac{\text{True Positives} + \text{True Negatives}}{\text{Total Samples}}
$$
$$
\text{Precision} = \frac{\text{True Positives}}{\text{True Positives} + \text{False Positives}}
$$
$$
\text{Recall} = \frac{\text{True Positives}}{\text{True Positives} + \text{False Negatives}}
$$
$$
\text{F1 Score} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
$$
