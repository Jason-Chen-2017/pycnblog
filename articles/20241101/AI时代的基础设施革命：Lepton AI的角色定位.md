#### 8.3 实际案例：搭建一个简单的Lepton AI项目

以下是一个简单的Lepton AI项目搭建案例：

**项目背景**：开发一个基于Lepton AI的人脸识别项目。

**步骤**：

1. **创建项目目录**：在电脑上创建一个名为`face_recognition`的项目目录。
2. **安装依赖**：在项目目录下，使用pip命令安装人脸识别所需的依赖包，如`pip install opencv-python face_recognition`。
3. **编写代码**：在项目目录下创建一个名为`main.py`的Python文件，编写人脸识别代码。
4. **运行代码**：在命令行中进入项目目录，执行`python main.py`，运行人脸识别项目。

**代码示例**：

```python
import cv2
import face_recognition

# 加载摄像头
video_capture = cv2.VideoCapture(0)

# 加载已知人脸编码
known_face_encodings = face_recognition.face_encodings([face_recognition.load_image_file('test_image.jpg')])

while True:
    # 读取摄像头帧
    ret, frame = video_capture.read()

    # 人脸检测
    face_locations = face_recognition.face_locations(frame)
    face_encodings = face_recognition.face_encodings(frame, face_locations)

    # 人脸识别
    for face_encoding in face_encodings:
        matches = face_recognition.compare_faces(known_face_encodings, face_encoding)
        if True in matches:
            print("Found a match!")

    # 显示视频帧
    cv2.imshow('Video', frame)

    # 按'q'键退出循环
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

# 释放摄像头资源
video_capture.release()
```
