## 第一部分：集合论基础

### 第1章：集合论引论

#### 1.1 集合的基本概念

集合（Set）是数学中最基本的概念之一。简单来说，集合是由确定的元素组成的整体。我们可以用大写字母如\(A\)、\(B\)等来表示集合，而集合中的元素用小写字母如\(a\)、\(b\)等来表示。

**定义**：给定一些明确的元素，将它们组织成一个无序的整体，称为集合。

**例子**：设\(A = \{1, 2, 3\}\)，这是一个包含三个元素的集合。

#### 1.2 集合的表示与运算

集合可以通过列举法或描述法来表示。

**列举法**：直接列出集合中的所有元素。
$$ A = \{1, 2, 3\} $$

**描述法**：用描述性的语言来定义集合。
$$ A = \{x \mid x \text{ 是自然数}\} $$

集合的基本运算包括并集、交集、差集等。

**并集**（\(A \cup B\)）：包含集合\(A\)和集合\(B\)中所有元素的集合。
$$ A \cup B = \{x \mid x \in A \text{ 或 } x \in B\} $$

**交集**（\(A \cap B\)）：同时属于集合\(A\)和集合\(B\)的元素组成的集合。
$$ A \cap B = \{x \mid x \in A \text{ 且 } x \in B\} $$

**差集**（\(A - B\) 或 \(A \setminus B\)）：属于集合\(A\)但不属于集合\(B\)的元素组成的集合。
$$ A - B = \{x \mid x \in A \text{ 且 } x \not\in B\} $$

#### 1.3 集合的性质与关系

集合具有如下基本性质：

1. **确定性**：集合中的元素是确定的。
2. **互异性**：集合中的元素不重复。
3. **无序性**：集合中的元素不考虑顺序。

集合之间存在着包含关系，包括子集和真子集。

**子集**（\(A \subseteq B\)）：集合\(A\)中的所有元素都属于集合\(B\)。
$$ A \subseteq B \Leftrightarrow \forall x (x \in A \Rightarrow x \in B) $$

**真子集**（\(A \subset B\)）：集合\(A\)是集合\(B\)的子集，但\(A\)不等于\(B\)。
$$ A \subset B \Leftrightarrow A \subseteq B \text{ 且 } A \neq B $$

#### 1.4 集合的划分与集合的势

集合的划分是指将一个集合分成若干个互不相交的子集。

**划分**：给定一个集合\(A\)，如果有一组集合\(\{B_1, B_2, ..., B_n\}\)，满足以下条件，则称\(\{B_1, B_2, ..., B_n\}\)为集合\(A\)的一个划分：
1. \(\cup_{i=1}^{n} B_i = A\)
2. \(B_i \cap B_j = \emptyset\) 对于所有\(i \neq j\)

集合的势（Cardinality）是指集合中元素的数量。如果集合是有限集合，其势为一个非负整数；如果集合是无限集合，其势通常用符号\(|A|\)表示。

**定义**：集合\(A\)的势定义为\(n = |A|\)，即集合\(A\)中元素的数量。

### 第2章：集合的基本运算

#### 2.1 并集、交集与差集

我们已经介绍了并集、交集和差集的基本概念，接下来详细讨论它们的性质和运算规则。

**并集的性质**：
1. **交换律**：\(A \cup B = B \cup A\)
2. **结合律**：\(A \cup (B \cup C) = (A \cup B) \cup C\)
3. **分配律**：\(A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\)

**交集的性质**：
1. **交换律**：\(A \cap B = B \cap A\)
2. **结合律**：\(A \cap (B \cap C) = (A \cap B) \cap C\)
3. **分配律**：\(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\)

**差集的性质**：
1. **交换律**：\(A - B = B - A\)
2. **结合律**：\(A - (B - C) = (A - B) - C\)
3. **分配律**：\(A - (B \cup C) = (A - B) \cap (A - C)\)

#### 2.2 补集与对称差集

**补集**：给定一个集合\(A\)，其补集（Complement）是指在全集\(U\)中不属于\(A\)的元素组成的集合，记作\(A^c\)。

**对称差集**（Symmetric Difference）：两个集合\(A\)和\(B\)的对称差集是指属于\(A\)或\(B\)但不同时属于\(A\)和\(B\)的元素组成的集合，记作\(A \Delta B\)。

**定义**：\(A \Delta B = (A \cup B) - (A \cap B)\)

#### 2.3 子集与真子集

我们已经定义了子集和真子集的概念。子集和真子集的关系可以通过补集来表示。

**关系**：如果\(A \subseteq B\)，则\(B^c \subseteq A^c\)。

#### 2.4 集合运算的性质

集合运算具有交换律、结合律和分配律等基本性质，这些性质使得集合运算更加灵活和方便。

### 第3章：集合的势与势的运算

#### 3.1 集合的势的基本概念

集合的势是指集合中元素的数量。对于有限集合，其势是一个非负整数；对于无限集合，其势通常用符号\(|A|\)表示。

**定义**：集合\(A\)的势定义为\(n = |A|\)，即集合\(A\)中元素的数量。

#### 3.2 势的运算规则

集合的势运算包括加法、乘法和除法等。

**加法**：两个集合\(A\)和\(B\)的并集的势等于它们各自势的和。
$$ |A \cup B| = |A| + |B| - |A \cap B| $$

**乘法**：两个集合\(A\)和\(B\)的交集的势等于它们各自势的乘积。
$$ |A \cap B| = |A| \cdot |B| $$

**除法**：两个集合\(A\)和\(B\)的差集的势等于它们各自势的商。
$$ |A - B| = |A| / |B| $$

#### 3.3 可数集与不可数集

集合可以分为可数集和不可数集。

**定义**：一个集合是可数的，如果它的元素可以和自然数集合建立一一对应关系。

**例子**：自然数集合、整数集合和有理数集合都是可数的。

**不可数集**：一个集合是不可数的，如果它的元素无法和自然数集合建立一一对应关系。

**例子**：实数集合和复数集合都是不可数的。

#### 3.4 康托尔定理与势的等价类

康托尔定理是集合论中的一个重要定理，它说明了不同集合的势之间的关系。

**康托尔定理**：对于任何集合\(A\)，存在一个无限可列集\(B\)，使得\(A\)和\(B\)的势相等。

**定义**：两个集合的势相等，如果它们可以建立一一对应关系。

康托尔定理的证明涉及到集合的划分和势的运算规则。通过逐步构造可列集合，我们可以证明康托尔定理。
