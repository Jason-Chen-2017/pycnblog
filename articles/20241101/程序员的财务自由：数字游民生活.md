#### 数学模型和数学公式：投资回报率计算

投资回报率（ROI）是衡量投资效果的重要指标，其计算公式如下：

$$
R = \frac{I_n - I_0}{I_0} \times 100\%
$$

其中：
- **R**：投资回报率（%）
- **I\_n**：投资后的总收益
- **I\_0**：初始投资金额

举例来说，如果某人投资了10,000美元，一年后获得了15,000美元的收益，那么其投资回报率计算如下：

$$
R = \frac{15,000 - 10,000}{10,000} \times 100\% = 50\%
$$

这意味着该投资实现了50%的投资回报率。

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Transaction(BaseModel):
    date: str
    amount: float
    type: str  # 'income' 或 'expense'

transactions = []

@app.post("/transactions/", response_model=list)
def add_transaction(transaction: Transaction):
    transactions.append(transaction)
    return transactions

@app.get("/transactions/", response_model=list)
def get_transactions():
    return transactions
```

**代码解读与分析**：
- **功能**：实现一个简单的财务记录API，用于添加和获取交易记录。
- **输入**：通过POST请求添加交易记录，通过GET请求获取交易记录。
- **输出**：返回添加的交易记录列表。
