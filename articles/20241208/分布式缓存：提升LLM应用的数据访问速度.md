## 第1章：分布式缓存概述

### 1.1.1 分布式缓存的基本概念

#### 1.1.1.1 什么是分布式缓存

分布式缓存是缓存的一种形式，它通过将数据分布存储在多个节点上，从而实现数据的高可用性和高性能访问。分布式缓存与传统的集中式缓存相比，具有更高的扩展性和容错能力。

```mermaid

```

#### 1.1.1.2 分布式缓存的优势

分布式缓存具有多个显著优势：

- **高性能**：通过将数据分布存储在多个节点上，分布式缓存可以提供更快的访问速度。
- **高可用性**：分布式缓存系统中的多个节点可以相互备份，确保系统的高可用性。
- **数据一致性**：分布式缓存通过一致性协议来保证数据的一致性。
- **数据分区和扩展性**：分布式缓存可以支持数据的分区和扩展，以适应不断增长的数据规模。


### 1.1.2 缓存系统的工作原理

#### 1.1.2.1 缓存命中与缓存失效

当请求到达缓存时，系统会先查询缓存。如果缓存中存在该数据，则直接返回，称为缓存命中。如果缓存中不存在该数据，则查询后端存储，并将数据缓存起来以供下次使用。

```mermaid
graph TB
    A[请求到达缓存] --> B[缓存查询]
    B -->|命中| C[返回数据]
    B -->|未命中| D[查询后端存储]
    D --> E[返回数据]
```

#### 1.1.2.2 缓存替换策略

当缓存达到容量上限时，需要选择一种替换策略来替换旧的数据。常见的缓存替换策略包括最近最少使用（LRU）、先进先出（FIFO）和最少访问（LFU）等。

```mermaid
graph TB
    A[缓存满] --> B[缓存替换策略]
    B --> C[最近最少使用(LRU)]
    B --> D[先进先出(FIFO)]
    B --> E[最少访问(LFU)]
```

```python
import redis

class LLMCache:
    def __init__(self, host='localhost', port=6379, db=0):
        self.redis_client = redis.StrictRedis(host=host, port=port, db=db)

    def get(self, key):
        return self.redis_client.get(key)

    def set(self, key, value, expire=3600):
        self.redis_client.set(key, value, ex=expire)

    def delete(self, key):
        self.redis_client.delete(key)
```
