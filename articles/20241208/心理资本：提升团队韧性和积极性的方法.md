**Step 3: Theoretical Foundations of Psychological Capital**

## Theoretical Framework of Psychological Capital

### The Three-Dimensional Model

- **Self-Efficacy**: Encompasses beliefs about one's capabilities to organize and execute the required courses of action needed to manage prospective situations.
- **Hope**: Reflects a set of motivational constructs that include setting goals, developing pathways, and maintaining or reviving the motivation to pursue goals.
- **Optimism**: Involves the anticipation that good things will happen, and a belief that one can influence events to one's advantage.

### Core Implementation and Code Analysis

```python
import pandas as pd
import numpy as np

# Example data
team_data = pd.DataFrame({
    'Self-Efficacy': [3, 4, 5],
    'Hope': [2, 3, 4],
    'Optimism': [4, 5, 6]
})

# Calculate PC score
def calculate_pc_score(team_data):
    cl = 0.5  # Weight for Core Self-Evaluations
    se = 0.3  # Weight for Hope
    ps = 0.2  # Weight for Optimism

    pc_score = (cl * team_data['Core Self-Evaluations'].mean()) + (se * team_data['Hope'].mean()) + (ps * team_data['Optimism'].mean())
    return pc_score

# Example calculation
pc_score = calculate_pc_score(team_data)
print(f"Team's Psychological Capital Score: {pc_score}")
```
