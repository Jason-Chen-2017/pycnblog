**详细讲解与举例说明**：

$$
\text{LLM训练目标函数} = \frac{1}{N} \sum_{i=1}^{N} \sum_{j=1}^{V} (y_{ij} - \hat{y}_{ij})^2
$$

其中，$N$是训练样本数量，$V$是词汇表大小，$y_{ij}$是真实标签，$\hat{y}_{ij}$是模型预测标签。

        super(LLM, self).__init__()
        self.embedding = nn.Embedding(num_words, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim)
        self.fc = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        x = self.embedding(x)
        x, _ = self.lstm(x)
        x = self.fc(x[-1, :, :])
        return x
