**3.4 数学模型和数学公式**

**基本概念**

1. **信息量**：描述一个事件不确定性的量度，用熵（Entropy）表示。

\[ H(X) = -\sum_{x \in X} p(x) \log_2 p(x) \]

其中，\(X\) 是所有可能事件集合，\(p(x)\) 是事件 \(x\) 发生的概率。

2. **信息增益**：系统在产生意识时信息整合程度的度量。

\[ \Delta I = I_{\text{total}} - I_{\text{non-conscious}} \]

其中，\(I_{\text{total}}\) 是系统的总信息量，\(I_{\text{non-conscious}}\) 是系统在不产生意识状态时的信息量。

**数学公式推导**

假设大脑活动数据集为 \(D\)，其中每个数据点表示大脑的一个状态。我们可以将 \(D\) 分为两组：意识状态数据集 \(D_{\text{conscious}}\) 和非意识状态数据集 \(D_{\text{non-conscious}}\)。

**总信息量 \(I_{\text{total}}\)**：

\[ I_{\text{total}} = H(D) = -\sum_{d \in D} p(d) \log_2 p(d) \]

**非意识状态信息量 \(I_{\text{non-conscious}}\)**：

\[ I_{\text{non-conscious}} = H(D_{\text{non-conscious}}) = -\sum_{d \in D_{\text{non-conscious}}} p(d) \log_2 p(d) \]

**信息增益**：

\[ \Delta I = I_{\text{total}} - I_{\text{non-conscious}} = -\sum_{d \in D} p(d) \log_2 p(d) + \sum_{d \in D_{\text{non-conscious}}} p(d) \log_2 p(d) \]

**举例说明**

假设我们有以下数据集：

\[ D = \{1, 2, 2, 3, 3, 3\} \]

其中，状态 1、2 和 3 分别表示不同的意识状态。

1. **总信息量 \(I_{\text{total}}\)**：

\[ I_{\text{total}} = H(D) = -\left( \frac{1}{6} \log_2 \frac{1}{6} + \frac{2}{6} \log_2 \frac{2}{6} + \frac{3}{6} \log_2 \frac{3}{6} \right) \approx 1.55 \]

假设非意识状态数据集为 \(D_{\text{non-conscious}} = \{1, 1, 2, 2\}\)：

\[ I_{\text{non-conscious}} = H(D_{\text{non-conscious}}) = -\left( \frac{1}{2} \log_2 \frac{1}{2} + \frac{1}{2} \log_2 \frac{1}{2} \right) = 1 \]

3. **信息增益**：

\[ \Delta I = I_{\text{total}} - I_{\text{non-conscious}} = 1.55 - 1 = 0.55 \]

```python
import numpy as np
from scipy.signal import butter, filtfilt

def preprocess_data(raw_data, sampling_rate):
    """
    预处理原始数据，包括滤波和去噪。
    :param raw_data: 原始数据数组
    :param sampling_rate: 采样率
    :return: 预处理后的数据
    """
    # 设计低通滤波器
    nyq = 0.5 * sampling_rate
    lowcut = 1.0
    b, a = butter(4, lowcut/nyq, btype='low')
    
    # 应用滤波
    filtered_data = filtfilt(b, a, raw_data)
    
    # 去噪
    noise_level = np.mean(filtered_data)
    noise_std = np.std(filtered_data)
    filtered_data = filtered_data - noise_level
    
    return filtered_data
```

在这个示例中，我们定义了一个名为`preprocess_data`的函数，该函数接受原始数据和采样率作为输入，通过低通滤波去除高频噪声，并计算数据的平均值和标准差以去除背景噪声。
