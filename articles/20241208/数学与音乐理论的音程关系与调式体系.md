## 第2章 基础概念

### 2.1 数学概念

- **自然数与整数**

自然数是指非负整数，包括0、1、2、3等。整数是指包括正整数、负整数和零的集合。

- **有理数与无理数**

有理数是可以表示为两个整数之比的数，包括整数、分数等。无理数是不能表示为两个整数之比的数，如π、√2等。

- **复数**

复数是实数与虚数的组合，可以表示为a+bi的形式，其中a和b是实数，i是虚数单位，满足i²=-1。

### 2.2 音乐理论概念

- **音调与音高**

音调是指声音的高低，由声波的频率决定。音高是指音调的具体数值，通常用C、D、E等字母表示。

- **音程**

音程是指两个音调之间的关系。根据音程的大小，可以分为自然音程、变化音程、增减音程等。

- **调式**

调式是指一组音调的排列方式，决定了音乐的基本风格和调性。常见的调式有大调、小调、五声调式等。

### 2.3 数学与音乐理论的联系

- **音程的数学表示**

音程可以用数学中的比例来表示。例如，大三度和弦可以表示为5:4，小三度和弦可以表示为6:5。

- **调式结构的数学分析**

调式结构可以用数学中的集合和图论来分析。例如，大调式可以用集合{C, D, E, F#, G#, A, B}表示，小调式可以用集合{A, B, C, D, E, F#, G#}表示。

## 第4章 调式体系

### 4.1 调式的定义与结构

调式是指一组音调的排列方式，它决定了音乐的基本风格和调性。常见的调式包括大调、小调、五声调式等。

- **大调**：大调式由七个音组成，其中第三音和第五音是大三度，第一音和第七音是完全五度。例如，C大调的音阶为C-D-E-F-G-A-B。

- **小调**：小调式由七个音组成，其中第三音和第五音是小三度，第一音和第七音是完全五度。例如，A小调的音阶为A-B-C-D-E-F-G。

- **五声调式**：五声调式由五个音组成，常见的有宫、商、角、徵、羽。例如，C五声调式的音阶为C-D-E-G-A。

### 4.2 调式转换与调性分析

调式转换是指将一个调式转换为另一个调式。调式转换可以通过改变音阶中的某些音来实现。例如，将C大调转换为A大调，只需要将C大调中的第一音C改为A即可。

调性分析是指对音乐作品的调性进行分析。调性分析可以帮助音乐家更好地理解音乐的结构和内涵，从而提高音乐创作的技巧和欣赏水平。

### 4.3 调式关系图

## 第5章 音程计算算法

### 5.1 音程计算算法概述

音程计算算法用于计算两个音调之间的距离。常用的音程计算算法包括整数算法和浮点数算法。

- **整数算法**：整数算法通过计算两个音调之间的频率比例来计算音程。例如，大三度可以表示为5:4，小三度可以表示为6:5。

- **浮点数算法**：浮点数算法通过计算两个音调之间的频率差值来计算音程。例如，大三度的频率差值为140Hz，小三度的频率差值为110Hz。

### 5.2 音程计算算法实现

以下是一个使用Python实现的音程计算算法的例子：

```python
def compute_pitch_difference(pitch1, pitch2):
    return pitch2 - pitch1

def compute_interval(interval1, interval2):
    return abs(interval1 - interval2)

# 测试
```

- **时间复杂度**：音程计算算法的时间复杂度为O(1)，即计算时间与输入数据的大小无关。

- **空间复杂度**：音程计算算法的空间复杂度为O(1)，即所需空间与输入数据的大小无关。

- **算法效率分析**：整数算法的效率高于浮点数算法，因为整数算法的计算速度快于浮点数算法。

## 第6章 调式分析算法

### 6.1 调式分析算法概述

调式分析算法用于分析音乐作品的调式结构。常用的调式分析算法包括频谱分析法和音高分析法。

- **频谱分析法**：频谱分析法通过分析音乐信号的频谱特性来识别调式。这种方法适用于复杂音乐信号的分析。

- **音高分析法**：音高分析法通过检测音乐信号的音高变化来识别调式。这种方法适用于简单的音乐信号分析。

### 6.2 调式分析算法实现

以下是一个使用Python实现的调式分析算法的例子：

```python
import numpy as np
from scipy.signal import find_peaks

def analyze_pitch(signal):
    peaks, _ = find_peaks(signal)
    return peaks

def analyze_tuning(signal):
    pitches = []
    for peak in analyze_pitch(signal):
        pitch = 440 * (2 ** (peak / 12))
        pitches.append(pitch)
    return pitches

# 测试
signal = np.array([440, 440, 440, 440, 440, 440, 440, 440, 440, 440, 440, 440])
pitches = analyze_tuning(signal)
print("Pitches:", pitches)
```

### 6.3 算法分析

- **时间复杂度**：调式分析算法的时间复杂度为O(n)，其中n为信号长度。

- **空间复杂度**：调式分析算法的空间复杂度为O(n)，其中n为信号长度。

- **算法效率分析**：频谱分析法适用于复杂音乐信号的分析，效率较高。音高分析法适用于简单音乐信号的分析，效率较低。
