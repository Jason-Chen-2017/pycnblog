## 5.3 核心代码实现

### 5.3.1 数据采集与预处理
```python
import numpy as np
import pandas as pd

# 读取噪声数据
data = pd.read_csv('noise_data.csv')

# 数据预处理
data['noise_level'] = data['noise_level'].fillna(data['noise_level'].mean())
```

### 5.3.2 噪声传播模型建立
```python
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPRegressor

# 划分训练集和测试集
X = data[['distance', 'building_height']]
y = data['noise_level']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 训练神经网络模型
model = MLPRegressor(hidden_layer_sizes=(100, 10))
model.fit(X_train, y_train)

# 预测结果
y_pred = model.predict(X_test)
```

### 5.3.3 地图绘制与可视化
```python
import matplotlib.pyplot as plt

# 绘制噪声地图
plt.figure(figsize=(10, 8))
plt.imshow(y_pred, cmap='hot', interpolation='nearest')
plt.colorbar(label='Noise Level')
plt.title('Noise Map')
plt.show()
```
