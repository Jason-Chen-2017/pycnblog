## 第一部分：巴菲特投资分析方法概述

### 第1章：巴菲特投资哲学与“看穿”式分析

#### 1.1 巴菲特投资哲学的核心思想  
巴菲特的投资哲学以价值投资为核心，强调通过深入分析企业的基本面，寻找具有持续竞争优势和合理估值的企业进行长期投资。其“看穿”式分析方法旨在透过表面数据，洞察企业的内在价值和盈利能力。

#### 1.2 “看穿”式分析的定义与特点  
“看穿”式分析是指通过对企业财务报表、行业地位、竞争优势和管理层能力的全面分析，识别企业的真实盈利能力，并预测其未来的发展潜力。其特点在于注重长期价值、强调企业护城河和管理层质量。

#### 1.3 分析方法的背景与意义  
传统财务分析往往局限于表面数据，难以反映企业的实际经营状况。巴菲特的分析方法通过引入护城河、管理层能力和估值指标，弥补了这一缺陷，为投资者提供了更全面的决策支持。

## 第二部分：企业盈利能力的核心指标

### 第2章：企业盈利能力的定义与分类

#### 2.1 企业盈利能力的定义  
企业盈利能力是指企业在一定时期内通过经营活动获得的利润能力，反映了企业在市场中的竞争力和管理效率。

#### 2.2 核心指标  
- **净利润率（Net Profit Margin）**：净利润与营业收入的比率，衡量企业整体盈利能力。  
- **股东权益收益率（ROE）**：净利润与股东权益的比率，反映股东投资的回报效率。  
- **资产回报率（ROA）**：净利润与总资产的比率，衡量资产的使用效率。

#### 2.3 盈利能力的驱动因素  
- 收入与成本结构  
- 资产周转效率  
- 财务杠杆与资本结构  
- 管理效率与战略执行

## 第三部分：财务报表分析基础

### 第3章：财务报表的构成与作用

#### 3.1 资产负债表的核心内容  
- 资产：流动资产、非流动资产  
- 负债：流动负债、非流动负债  
- 所有者权益：股本、留存收益  

#### 3.2 利润表的主要指标  
- 营业收入：企业核心业务收入  
- 营业成本：直接相关的生产成本  
- 毛利润：营业收入减去营业成本  
- 净利润：最终利润，反映企业盈利能力  

#### 3.3 现金流量表的重要性  
- 经营活动现金流：企业日常经营活动的现金流  
- 投资活动现金流：资本支出和投资活动的现金流  
- 筹资活动现金流：融资活动的现金流

import pandas as pd
import numpy as np

# 示例代码：计算ROE
def calculate_roe(net_profit, equity):
    return net_profit / equity

# 示例数据
data = {
    'net_profit': [100, 200, 300],
    'equity': [500, 600, 700]
}
df = pd.DataFrame(data)
df['roe'] = df.apply(lambda x: calculate_roe(x['net_profit'], x['equity']), axis=1)
print(df)
