## 第一部分：反向投资法基础

### 第1章：反向投资法概述

#### 1.1 反向投资法的定义与核心思想
反向投资法是一种逆市场趋势的投资策略，强调在市场低谷时买入，市场高点时卖出。其核心思想是：当市场恐慌时买入，当市场乐观时卖出。这种方法与传统的顺势投资法相反，需要投资者具备逆向思维和耐心。

#### 1.2 约翰·聂夫的背景与投资理念
约翰·聂夫是反向投资法的代表人物，他以在市场恐慌时买入低估股票而闻名。他的投资理念强调估值分析、基本面研究和风险管理。

#### 1.3 反向投资法的适用场景与边界
反向投资法适用于市场恐慌和低估的阶段，但需注意市场操纵、信息不对称和宏观经济风险。

#### 2.1 估值分析
- 市盈率（P/E）计算与应用：$P/E = \frac{\text{股价}}{\text{每股收益}}$
- 市净率（P/B）计算与应用：$P/B = \frac{\text{股价}}{\text{每股净资产}}$
- 股息率与股息支付率：股息率 = $\frac{\text{每股股息}}{\text{股价}}$

#### 2.2 公司基本面分析

#### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np
import requests

# 获取股票数据
def get_stock_data(ticker):
    url = f"https://query1.finance.yahoo.com/ws"
    params = {
        "period1": 0,
        "period2": 9999999999,
        "interval": "1d",
        "filter": "ticker={}".format(ticker)
    }
    response = requests.get(url, params=params)
    data = response.json()
    df = pd.DataFrame(data['chart']['result'][0]['data'], columns=['Date', 'Open', 'High', 'Low', 'Close', 'Volume'])
    df['Date'] = pd.to_datetime(df['Date'])
    return df

# 计算市盈率
def calculate_pe(ticker):
    df = get_stock_data(ticker)
    df['PE'] = df['Close'] / df[' earnings_per_share ']  # 假设earnings_per_share已知
    return df['PE'].mean()

# 示例：计算AAPL的市盈率
print(calculate_pe('AAPL'))
```
