## 第1章: 价值投资的核心概念

### 1.1 价值投资的定义与背景  
价值投资是一种以低于内在价值的价格买入优质资产的投资策略，其核心在于寻找市场低估的股票。传统价值投资强调对企业基本面的分析，包括财务状况、盈利能力、行业地位等。然而，随着市场环境的变化，传统价值投资的局限性逐渐显现，尤其是在应对高波动性、复杂金融工具和新兴市场时，传统方法显得力不从心。

杰里米·格兰瑟姆作为价值投资领域的权威，提出了价值投资的新定义，强调在传统基本面分析的基础上，引入更多的量化指标和风险管理方法，以适应现代金融市场的复杂性。

## 第2章: 价值投资新定义的核心要素

### 2.1 内在价值的重新定义  
格兰瑟姆的新定义对内在价值的计算进行了优化，结合了更多动态因素，例如：

1. **历史数据分析**：通过长期历史数据，评估企业的盈利能力、成长性和稳定性。
2. **行业周期性**：考虑行业周期对企业价值的影响。
3. **市场情绪**：引入市场情绪指标，调整估值模型。

格兰瑟姆提出了一个改进的内在价值公式：

$$
\text{内在价值} = \text{调整后的净利润} \times \text{动态市盈率}
$$

其中，净利润需要根据行业周期和市场情绪进行调整，动态市盈率则结合了历史平均市盈率和当前市场环境。

## 第3章: 价值投资的数学模型与算法

### 3.1 市盈率模型  
市盈率（P/E）是价值投资中常用的估值指标，其公式为：

$$
\text{市盈率} = \frac{\text{股价}}{\text{每股净利润}}
$$

格兰瑟姆的新定义中，市盈率的计算需要考虑行业平均市盈率和市场情绪指数：

$$
\text{调整后市盈率} = \text{市盈率} \times \text{行业平均市盈率} \times \text{市场情绪指数}
$$

以下是改进的内在价值计算代码：

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(financial_data, industry_avg_pe, market_mood_index):
   净利润 = financial_data['净利润']
   动态市盈率 = industry_avg_pe * market_mood_index
   内在价值 = 净利润 * 动态市盈率
    return 内在价值

# 示例数据
financial_data = {'净利润': 100}
industry_avg_pe = 15
market_mood_index = 1.2

result = calculate_intrinsic_value(financial_data, industry_avg_pe, market_mood_index)
print("内在价值:", result)
```
