# 第一部分: 投资组合管理的背景与基础

## 第1章: 投资组合管理概述

### 1.1 投资组合管理的基本概念

#### 1.1.1 投资组合的定义与特点
- **定义**：投资组合是将多种资产（股票、债券等）按一定比例组合在一起的投资方式。
- **特点**：分散风险、优化收益、降低波动性。
- **核心要素**：资产选择、权重分配、再平衡策略。

#### 1.1.2 投资组合管理的目标与意义
- **目标**：在风险可控的前提下，最大化收益。
- **意义**：通过科学配置，降低投资风险，提高收益稳定性。

#### 1.1.3 投资组合管理的核心要素
- **资产配置**：决定投资组合的主要收益来源。
- **分散投资**：通过多样化降低特定资产的风险。
- **动态调整**：根据市场变化定期优化组合。

### 1.2 格雷厄姆的投资理念

#### 1.2.1 格雷厄姆的生平与贡献
- **生平**：本杰明·格雷厄姆，20世纪初著名投资家，价值投资之父。
- **贡献**：提出了“安全边际”概念，强调买入低于内在价值的股票。

#### 1.2.2 格雷厄姆的价值投资理论
- **核心思想**：买入并持有优质资产，长期获得稳健收益。
- **安全边际**：以低于内在价值的价格买入，降低风险。

#### 1.2.3 格雷厄姆的投资组合管理策略
- **分散投资**：避免过度集中，降低风险。
- **长期持有**：坚持价值投资，避免频繁交易。

### 1.3 投资组合管理的现代发展

#### 1.3.1 现代投资组合理论的演变
- **马科维茨的均值-方差模型**：奠定了现代投资组合理论的基础。
- **夏普比率**：衡量投资组合的风险调整后收益。

#### 1.3.2 格雷厄姆理念与现代投资理论的结合
- **结合点**：价值投资注重安全边际，现代理论强调风险分散。
- **实践应用**：在资产配置中加入格雷厄姆的选股策略。

#### 1.3.3 投资组合管理在实际中的应用
- **机构投资者**：采用多样化策略，结合价值投资。
- **个人投资者**：通过定投和分散化实现稳健收益。

#### 2.2.2 数学模型

$$
\text{收益} = \sum_{i=1}^{n} w_i r_i
$$

$$
\text{风险} = \sqrt{\sum_{i=1}^{n} \sum_{j=1}^{n} w_i w_j \sigma_{ij}}
$$

其中，\( w \) 是权重向量，\( r \) 是收益向量，\( \sigma_{ij} \) 是协方差矩阵。

#### 2.2.3 代码实现

```python
import numpy as np

def calculate_portfolio_return(weights, returns):
    return np.sum(weights * returns)

def calculate_portfolio_variance(weights, covariance_matrix):
    return np.sqrt(np.dot(weights.T, np.dot(covariance_matrix, weights)))

# 示例
assets = ['股票', '债券']
returns = [0.1, 0.05]
covariance_matrix = np.array([[0.2, 0.1], [0.1, 0.15]])
weights = np.array([0.6, 0.4])

print('预期收益:', calculate_portfolio_return(weights, returns))
print('风险:', calculate_portfolio_variance(weights, covariance_matrix))
```

```python
import numpy as np

def gre厄姆投资组合优化(assets, returns, covariance_matrix):
    n = len(assets)
    # 初始化权重
    weights = np.array([1.0/n]*n)
    # 优化权重
    while True:
        # 计算收益和风险
        current_return = np.sum(weights * returns)
        current_risk = np.sqrt(np.dot(weights.T, np.dot(covariance_matrix, weights)))
        # 调整权重以降低风险
        new_weights = weights * (1 - 0.05)
        new_weights = new_weights / np.sum(new_weights)
        if np.allclose(weights, new_weights):
            break
        weights = new_weights
    return weights, current_return, current_risk

# 示例
assets = ['股票', '债券']
returns = [0.1, 0.05]
covariance_matrix = np.array([[0.2, 0.1], [0.1, 0.15]])
weights, return_, risk = gre厄姆投资组合优化(assets, returns, covariance_matrix)
print('最优权重:', weights)
print('预期收益:', return_)
print('风险:', risk)
```
