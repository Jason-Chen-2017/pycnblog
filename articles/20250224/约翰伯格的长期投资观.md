# 第一部分：背景介绍

## 第1章：约翰·伯格与长期投资观的背景

### 1.1 约翰·伯格的生平与投资理念

#### 1.1.1 约翰·伯格的早期经历

约翰·伯格于1934年出生于美国宾夕法尼亚州，曾在宾夕法尼亚大学获得工程学学位，并在随后的岁月里成为了投资界的传奇人物。他在1975年创立了 Vanguard 集团，并在指数基金领域做出了巨大贡献。

#### 1.1.2 伯格的投资哲学与价值观

伯格主张低成本、分散化的投资策略，强调长期持有和价值投资。他认为市场波动是不可预测的，而长期投资能够平滑这些波动，为投资者带来稳定的收益。

#### 1.1.3 伯格对投资行业的贡献

伯格的最大贡献之一是推动指数基金的发展，使得普通投资者能够以低费用投资于广泛的市场组合。他的理念深刻影响了现代投资策略。

### 1.2 长期投资观的背景与意义

#### 1.2.1 长期投资观的定义

长期投资观是指投资者以长期持有资产为目标，不频繁交易，注重资产的内在价值和成长潜力。

#### 1.2.2 长期投资观与短期投资的对比

| 特性       | 长期投资观 | 短期投资观 |
|------------|------------|------------|
| 时间跨度   | 长期       | 短期       |
| 投资策略   | 买入并持有 | 频繁交易   |
| 风险承受   | 较低       | 较高       |

#### 1.2.3 长期投资观在现代投资中的地位

长期投资观在现代投资中占据重要地位，尤其是在机构投资和个人理财领域。它强调纪律性和耐心，避免了短期波动带来的决策错误。

### 1.3 伯格长期投资观的核心要素

#### 1.3.1 价值投资的核心理念

价值投资强调以低于内在价值的价格买入优质资产，并长期持有。伯格认为，市场波动往往导致价格偏离价值，长期持有能够捕捉这种偏差。

#### 1.3.2 长期持有与分散投资的策略

伯格倡导通过分散投资降低风险，并长期持有优质资产，避免频繁交易带来的成本和情绪干扰。

#### 1.3.3 风险管理与投资组合优化

伯格强调风险管理的重要性，建议投资者根据自身风险承受能力构建投资组合，并定期调整以适应市场变化。

import numpy as np

def backtest_strategy(prices, initial_capital):
    portfolio = initial_capital
    positions = {}
    for price in prices:
        if not positions:
            positions[price.index[0]] = initial_capital / price.close
        current_value = sum(positions[price.name] * price.close)
        if current_value < initial_capital * 0.9:
            positions[price.name] = initial_capital / price.close
    return positions
