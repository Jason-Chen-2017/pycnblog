```python
def calculate_intrinsic_value(ticker):
    import pandas as pd
    import yfinance as yf
    data = yf.download(ticker, period='max')
    # 计算自由现金流
    cash_flow = data['Adj Close'].pct_change().cumsum()
    # 计算折现率
    discount_rate = 0.1
    # 计算内在价值
    intrinsic_value = cash_flow / (1 + discount_rate)
    return intrinsic_value
```
