## 第2章：巴菲特投资决策的核心指标与方法

### 2.1 价值投资的核心指标分析

- 2.1.1 市盈率（P/E）的计算与应用  
  - P/E = 市场价 / 每股收益  
  - 低市盈率意味着被低估的潜力  

- 2.1.2 市净率（P/B）的计算与应用  
  - P/B = 市场价 / 每股净资产  
  - 低市净率可能意味着资产被低估  

- 2.1.3 股息率的计算与应用  
  - 股息率 = 每股股息 / 市场价  
  - 高股息率可能意味着稳定的收益  

### 2.2 巴菲特选股的三步法

- 2.2.1 寻找具有持续竞争优势的企业  
  - 企业的核心竞争力分析  
  - 企业的市场地位与竞争优势  

- 2.2.2 确保管理层的诚信与能力  
  - 管理层的诚信与决策能力对企业价值的影响  
  - 如何评估管理层的能力与诚信  

- 2.2.3 评估企业的财务健康状况  
  - 财务报表分析  
  - 现金流分析  

### 2.3 巴菲特对石油行业的独特估值方法

- 2.3.1 石油企业的内在价值计算

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(enterprise, WACC):
    FCF = enterprise['free_cash_flow']
    return FCF / WACC

# 示例数据
data = {
    'free_cash_flow': 1000000,
    'WACC': 0.08
}

enterprise = pd.DataFrame(data)
intrinsic_value = calculate_intrinsic_value(enterprise, enterprise['WACC'].iloc[0])

print(f"企业内在价值: {intrinsic_value}")
```
