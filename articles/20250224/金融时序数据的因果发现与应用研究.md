# 第1章：金融时序数据与因果发现概述

## 1.1 金融时序数据的定义与特点

### 1.1.1 金融时序数据的定义
金融时序数据是指随着时间变化的金融变量的观测值，例如股票价格、指数、利率等。这些数据通常以时间戳为索引，记录了金融市场的动态变化。

### 1.1.2 金融时序数据的主要特点
1. **时间依赖性**：数据的变化往往与过去的状态密切相关。
2. **波动性**：金融市场的波动通常较大，受多种因素影响。
3. **异质性**：不同金融资产的表现可能差异显著。

### 1.1.3 金融时序数据的常见类型
- 股票价格
- 汇率
- 利率
- 经济指标（如GDP、CPI）

## 1.2 因果发现的基本概念

### 1.2.1 因果关系的定义
因果关系指的是变量间的相互作用，其中一个是原因，另一个是结果。例如，利率的变化可能影响股票价格。

### 1.2.2 因果关系与相关关系的区别
- **相关关系**：变量间存在统计上的关联，但不一定存在因果关系。
- **因果关系**：变量间存在直接或间接的影响关系。

### 1.2.3 金融领域因果发现的重要性
在金融领域，因果关系可以帮助我们理解市场机制、制定投资策略和风险评估。

# 第2章：金融时序数据因果关系的数学模型

## 2.1 时间序列分析的基础模型

### 2.1.1 自回归模型（AR）
AR模型假设当前值与过去若干期的值相关。

$$ y_t = \beta_0 + \beta_1 y_{t-1} + \epsilon_t $$

### 2.1.2 移动平均模型（MA）
MA模型假设当前值与过去若干期的误差相关。

$$ y_t = \beta_0 + \beta_1 \epsilon_{t-1} + \beta_2 \epsilon_{t-2} + \epsilon_t $$

### 2.1.3 自回归移动平均模型（ARMA）
ARMA模型结合了AR和MA的特点。

$$ y_t = \beta_0 + \beta_1 y_{t-1} + \beta_2 \epsilon_{t-1} + \epsilon_t $$

## 2.2 Granger因果关系检验

### 2.2.1 Granger因果关系的定义
如果变量X的过去信息有助于预测变量Y的当前值，则认为X是Y的Granger原因。

### 2.2.2 Granger因果关系的检验方法
- 构建回归模型，比较有无X的情况下Y的预测误差。

### 2.2.3 Granger因果关系的数学公式
$$ H_0: \beta = 0 \quad (无因果关系) $$

$$ H_1: \beta \neq 0 \quad (存在因果关系) $$

## 2.3 贝叶斯网络在因果发现中的应用

### 2.3.1 贝叶斯网络的基本概念
贝叶斯网络是一种有向无环图，表示变量间的概率关系。

### 2.3.2 贝叶斯网络的结构学习
通过最大似然估计或MCMC方法学习网络结构。

### 2.3.3 贝叶斯网络的参数估计
估计每个节点的条件概率分布。

### 5.2.1 Granger因果检验代码

```python
import statsmodels.api as sm

def granger_causality_test(data, max_lag=1):
    df = data.values
    for lag in range(1, max_lag+1):
        model = sm.tsa.GrangerCausalityTest(data, lag=lag)
        results = model.perform_test()
        print(f"Granger因果关系检验（滞后阶数={lag}）：p值={results.pvalue}")
```
