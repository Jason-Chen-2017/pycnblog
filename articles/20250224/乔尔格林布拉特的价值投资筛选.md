## 第1章: 价值投资与格林布拉特筛选方法概述

### 1.1 价值投资的核心理念

#### 1.1.1 价值投资的定义与特点

- 价值投资是一种以低于内在价值的价格买入优质股票的投资策略。
- 核心特点：
  - 长期视角：关注企业的内在价值，而非短期市场波动。
  - 安全边际：买入价格低于内在价值，以降低风险。
  - 选股标准：注重企业的基本面，如盈利能力、财务健康和竞争优势。

#### 1.1.2 价值投资与其它投资策略的区别

| 投资策略 | 核心关注点 | 优点 | 缺点 |
|----------|------------|------|------|
| 价值投资 | 内在价值、基本面分析 | 风险较低，长期回报稳定 | 需要深入研究，流动性较低 |
| 技术分析 | 价格走势、成交量 | 短期信号明确 | 易受市场情绪影响，风险较高 |

#### 1.1.3 格林布拉特方法的独特性

格林布拉特的筛选方法结合了价值投资的基本面分析和量化指标，通过数学模型和程序化筛选，将价值投资系统化。其独特性体现在：

1. **量化筛选**：通过具体的估值指标（如市盈率、ROE等）筛选股票。
2. **长期视角**：注重企业的长期盈利能力，而非短期价格波动。
3. **可复制性**：方法具有明确的筛选标准，适合程序化交易和系统化投资。

## 第2章: 格林布拉特筛选方法的核心指标

### 2.1 核心筛选指标

#### 2.1.1 低市盈率（P/E）策略

- **定义**：市盈率是股票价格除以每股收益（EPS）的比率。
- **公式**：$$ P/E = \frac{Price}{Earnings} $$
- **作用**：筛选出被低估的股票。

#### 2.1.2 高股息率（Dividend Yield）策略

- **定义**：股息率是股息与股票价格的比率。
- **公式**：$$ Dividend Yield = \frac{Dividend}{Price} $$
- **作用**：筛选出高分红的股票。

#### 2.1.3 高净资产收益率（ROE）策略

- **定义**：净资产收益率是净利润与股东权益的比率。
- **公式**：$$ ROE = \frac{Net Income}{Total Equity} $$
- **作用**：筛选出盈利能力强的股票。

#### 2.1.4 其他辅助指标

- 市净率（P/B）：$$ P/B = \frac{Price}{Book Value} $$
- 市销率（P/S）：$$ P/S = \frac{Price}{Sales} $$

---

### 2.2 核心指标的数学模型与公式

#### 2.2.1 市盈率的计算

$$ P/E = \frac{Price}{Earnings} $$

例如：某股票价格为$50，每股收益为$5，则P/E = 10。

#### 2.2.2 净资产收益率的计算

$$ ROE = \frac{Net Income}{Total Equity} $$

例如：某公司净利润为$100万，股东权益为$500万，则ROE = 20%。

---

### 2.3 核心指标的对比分析

#### 2.3.1 不同估值指标的优缺点对比

| 指标 | 优点 | 缺点 |
|------|------|------|
| P/E | 简单易用 | 不适合亏损企业 |
| ROE | 衡量盈利能力 | 受会计政策影响 |
| Dividend Yield | 稳定收益 | 高分红可能影响成长性 |

#### 2.3.2 不同行业中的指标适用性分析

例如，在银行业，ROE可能是更好的指标；在科技业，P/S可能是更适合的指标。

#### 2.3.3 综合指标的权重分配

可以根据行业和市场环境调整指标权重，例如在熊市中，更重视P/E；在牛市中，更重视ROE。

import pandas as pd
import requests

# 数据采集
def get_stock_data(ticker):
    url = f"https://query1.finance.yahoo.com/.../{ticker}"
    response = requests.get(url)
    data = response.json()
    return data

# 指标计算
def calculate_pe(data):
    pe = data['price'] / data['earnings']
    return pe

# 筛选策略
def greenblatt_screen(stocks):
    selected = []
    for stock in stocks:
        if stock['pe'] < 15 and stock['roe'] > 10:
            selected.append(stock)
    return selected

# 结果展示
def display_results(selected_stocks):
    for stock in selected_stocks:
        print(f"股票名称：{stock['name']}, 市盈率：{stock['pe']}, 净资产收益率：{stock['roe']}")
