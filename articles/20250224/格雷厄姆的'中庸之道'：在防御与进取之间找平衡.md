## 第一部分：背景介绍

### 第1章：投资学基础与中庸之道的起源

#### 1.1 投资学的基本概念

投资是指将资金投入某一项目或资产，以期在未来获得收益的行为。投资的核心在于通过科学的分析和决策，最大化收益并最小化风险。投资学作为一门研究资金流动、资产定价和投资决策的学科，为投资者提供了理论基础和工具。

#### 1.2 中庸之道的哲学基础

中庸之道是中国传统文化中的一个重要概念，源自儒家思想，强调在事物两端寻找平衡点，避免极端。在投资中，中庸之道体现在避免过于保守或激进，寻找风险与收益的平衡。

#### 1.3 防御与进取的定义与特点

- **防御性投资**：以稳健收益为目标，注重本金安全，风险较低。适合风险厌恶型投资者，如债券、货币市场工具等。
- **进取性投资**：追求高收益，风险较高。适合风险承受能力强的投资者，如股票、高风险债券等。

---

### 第2章：防御与进取的平衡点

#### 2.1 防御与进取的相互关系

防御与进取并非对立，而是相辅相成。在市场波动时，防御性资产可保护本金，而进取性资产则在市场上涨时带来超额收益。平衡点在于根据市场环境调整两者的比例。

#### 2.2 平衡点的定义与意义

平衡点是指在投资组合中，防御与进取资产的配置比例达到最优，既保证本金安全，又追求适度收益。通过动态调整比例，投资者可在不同市场环境中保持稳健投资。

#### 2.3 概念属性特征对比表格

| 概念 | 属性 | 特征 |
|------|------|------|
| 防御 | 稳定性 | 低风险 |
| 进取 | 收益性 | 高风险 |

## 第二部分：算法原理讲解

### 第3章：风险评估与资产配置

#### 3.1 风险评估模型

风险评估是投资决策的关键步骤。通过评估资产的波动性、相关性和市场敏感性，投资者可以量化潜在风险。

- **波动性**：资产价格的波动程度，通常用标准差衡量。
- **相关性**：资产价格变动的相关性，影响投资组合的分散效果。
- **市场敏感性**：资产对市场变动的反应程度，通常用贝塔系数衡量。

#### 3.2 资产配置模型

资产配置是投资组合管理的核心，涉及决定各类资产的权重。常用模型包括现代投资组合理论和风险平价模型。

- **现代投资组合理论（MPT）**：由哈里·马科维茨提出，强调通过分散投资降低风险。
- **风险平价模型**：根据资产的风险贡献进行配置，平衡风险与收益。

## 第四部分：项目实战

### 第5章：投资组合模拟与代码实现

#### 5.1 环境安装

- Python 3.8+

#### 5.2 核心代码实现

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.optimize import minimize

def portfolio_var(weights, covariance_matrix):
    return np.dot(weights.T, np.dot(covariance_matrix, weights))

def min_variance(weights, covariance_matrix):
    return minimize(portfolio_var, weights, args=covariance_matrix, 
                   method='SLSQP', bounds=[(0,1), (0,1)], constraints={'type': 'eq', 'fun': lambda w: np.sum(w)-1})

# 示例数据：两只资产的协方差矩阵
cov_matrix = np.array([[0.01, 0.005], [0.005, 0.02]])
weights = np.array([0.5, 0.5])

result = min_variance(weights, cov_matrix)
print('最小方差权重：', result.x)
```
