# 第1章：行为经济学与投资概述

## 1.1 行为经济学的基本概念  
行为经济学研究人类在经济决策中的心理偏差，挑战了传统经济学的理性人假设。  

## 1.2 行为经济学在投资中的应用  
行为偏差影响投资者决策，导致市场波动。  

## 1.3 罗伯特·希勒的学术贡献  
希勒的研究揭示了市场参与者的心理因素对资产定价的影响。

## 2.1 心理账户

## 2.3 行为偏差与市场波动
