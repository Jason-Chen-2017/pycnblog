### 3.3 数学公式与实现代码
#### 3.3.1 主动学习的数学模型
- 不确定性度量函数：$$ uncertainty = 1 - \text{max}(p(y|x)) $$
- 损失函数：$$ L = \sum_{i=1}^{n} (y_i - \hat{y_i})^2 $$

#### 3.3.2 增量学习的实现代码
```python
def incremental_learning(new_data, model):
    for x, y in new_data:
        model.update(x, y)
        print(f"Updated model with {x}, {y}")
    return model
```

#### 3.3.3 在线学习的实现代码
```python
def online_learning(data_stream, model):
    for x, y in data_stream:
        model.update(x, y)
        print(f"Updated model with {x}, {y}")
    return model
```
