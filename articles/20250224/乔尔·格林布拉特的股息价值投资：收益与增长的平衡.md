## 第一部分: 股息价值投资的理论基础

### 第1章: 股息价值投资的背景与概念  

#### 1.1 股息价值投资的背景  
- 1.1.1 价值投资的起源与发展  
  - 价值投资的定义：寻找被市场低估的股票，长期持有以获得超额收益。  
  - 股息在价值投资中的重要性：股息是投资者的重要收益来源，也是企业稳健的标志。  

- 1.1.2 股息在投资中的重要性  
  - 股息是企业盈利的直接体现，也是投资者现金流的重要来源。  
  - 股息率高的股票通常具有较高的防御性，适合稳健型投资者。  

- 1.1.3 收益与增长的平衡理念  
  - 过高的股息可能意味着企业缺乏增长潜力，而过低的股息可能意味着企业盈利不足。  
  - 收益与增长的平衡是股息价值投资的核心理念。  

#### 1.2 股息价值投资的核心概念  
- 1.2.1 股息率的定义与计算  
  - 股息率 = （股息/每股） / 股票价格 × 100%  
  - 例如：某股票股息为1元，股价为10元，则股息率为10%。  

- 1.2.2 股息增长模型  
  - 戈登股息增长模型：  
  $$P = \frac{D_1}{r - g}$$  
  其中，$D_1$ 是第一期股息，$r$ 是折现率，$g$ 是股息增长率。  

- 1.2.3 股息价值投资的边界与外延  
  - 股息价值投资的适用场景：适合长期稳健型投资者，尤其是对收益有较高需求的投资者。  
  - 股息价值投资的局限性：高股息股票可能在市场波动中表现不佳，且企业可能因分红过多而影响增长。  

#### 1.3 股息价值投资的核心要素  
- 1.3.1 股息率与市盈率的关系  
  - 股息率高但市盈率低的股票可能具有较高的投资价值。  
  - 对比表格：  
  | 指标 | 股息率 | 市盈率 |  
  |------|--------|--------|  
  | 说明 | 收益能力 | 市场估值 |  

- 1.3.2 股息支付率与企业盈利能力  
  - 股息支付率 = 股息 / 净利润 × 100%  
  - 高股息支付率可能意味着企业盈利能力较强，但也可能影响再投资能力。  

- 1.3.3 股息增长的驱动因素  
  - 股息增长的驱动因素包括企业盈利增长、股息政策调整等。  

#### 1.4 本章小结  
- 股息价值投资是一种结合股息收益与企业增长的平衡策略。  
- 股息率、股息增长模型、股息支付率等是股息价值投资的核心要素。

  - 定期再平衡：根据市场变化调整投资组合。

### 第3章: 股息价值投资的数学模型与公式  

#### 3.1 股息增长模型  
- 3.1.1 戈登股息增长模型  
  $$P = \frac{D_1}{r - g}$$  
  其中，$D_1$ 是第一期股息，$r$ 是折现率，$g$ 是股息增长率。  

- 3.1.2 应用实例  
  - 假设某股票股息为1元，股息增长率为5%，折现率为10%。  
  - 则股票的内在价值为：  
  $$P = \frac{1}{0.10 - 0.05} = 20 \text{元}$$  

#### 3.2 股息贴现模型（DDM）  
- 3.2.1 单阶段DDM  
  $$P = \frac{D}{k - g}$$  
  其中，$D$ 是股息，$k$ 是折现率，$g$ 是股息增长率。  

- 3.2.2 多阶段DDM  
  $$P = \sum_{t=1}^{n} \frac{D_t}{(1+k)^t} + \frac{P_n}{(1+k)^n}$$  
  其中，$D_t$ 是第$t$期的股息，$P_n$ 是第$n$阶段的终值。  

#### 3.3 股息率计算公式  
- 股息率 = （股息/每股） / 股票价格 × 100%  

#### 3.4 股权收益率（ROE）公式  
- $$\text{ROE} = \frac{\text{净利润}}{\text{股东权益}}$$
