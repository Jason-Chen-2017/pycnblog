### 1.1 巴菲特的生平简介

#### 1.1.1 巴菲特的早年经历
沃伦·巴菲特（Warren Buffett）于1934年8月30日出生在美国奥马哈市。他从小就展现出了对数字和投资的极大兴趣，12岁时开始投资股票，15岁时完成了人生第一笔大宗投资。

#### 1.1.2 巴菲特的投资理念形成
巴菲特在哥伦比亚大学师从本杰明·格雷厄姆，学习价值投资理论。他提出的“安全边际”概念，即以低于内在价值的价格购买优质资产，成为他投资哲学的核心。

#### 1.1.3 巴菲特的成名事件
1962年，巴菲特收购了保险公司 Berkshire Hathaway，这次收购使他真正开始实践和推广他的投资理念，并逐渐建立起庞大的投资帝国。

#### 1.2.1 伯克希尔哈撒韦的前身
Berkshire Hathaway最初是一家濒临破产的纺织公司。巴菲特通过收购该公司获得了对其命运的控制权，并开始将它转变为一家控股公司。

#### 1.2.2 从保险公司到控股公司的转型
随着巴菲特的加入，Berkshire Hathaway逐步转型为一家多元化的控股公司，投资领域涵盖保险、银行、能源、铁路等多个行业。

#### 1.2.3 伯克希尔哈撒韦的多元化发展
通过不断收购优质企业，伯克希尔哈撒韦形成了一个庞大的企业帝国，旗下子公司在各自领域内都具有强大的竞争力。

## 第2章: 控股公司的定义与特点

### 2.1 控股公司的基本概念

#### 2.1.1 控股公司的定义
控股公司是指通过持有其他公司一定比例的股份，从而对这些公司进行控制的公司。控股公司本身不一定直接参与生产经营活动。

#### 2.1.2 控股公司的主要特征
- 持股比例高
- 控制多个子公司
- 多元化经营
- 通过资本运作实现增长

#### 2.1.3 控股公司与子公司的关系
控股公司与子公司之间的关系是控制与被控制的关系，控股公司通过董事会和股东大会行使控制权。

### 2.2 巴菲特控股模式的独特性

#### 2.2.1 巴菲特控股模式的核心要素
- 高质量的管理层
- 股东利益优先
- 长期价值导向
- 严格的风险控制

#### 2.2.2 巴菲特控股模式与传统控股公司的区别
巴菲特的控股模式注重长期价值和风险管理，而非单纯的资本扩张。

#### 2.2.3 巴菲特控股模式的创新点
通过集中持股优质企业，实现稳健的多元化发展，避免过度风险。

import numpy as np

# 加载投资组合数据
data = pd.read_csv('berkshire_portfolio.csv')

# 计算每种投资的内在价值
def calculate_intrinsic_value(row):
    return row['cash_flow'] / row['discount_rate']

data['intrinsic_value'] = data.apply(calculate_intrinsic_value, axis=1)

# 展示结果
print(data[['investment', 'intrinsic_value']].head())
