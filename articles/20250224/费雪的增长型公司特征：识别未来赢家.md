- 2.3.1 收入增长率公式
  $$ 收入增长率 = \frac{本期收入 - 上期收入}{上期收入} \times 100\% $$
- 2.3.2 净利润率公式
  $$ 净利润率 = \frac{净利润}{营业收入} \times 100\% $$
- 2.3.3 ROE计算公式
  $$ ROE = \frac{净利润}{股东权益} \times 100\% $$

import numpy as np

def calculate_growth_rate(revenue):
    return ((revenue['current'] - revenue['previous']) / revenue['previous']) * 100

    'year': [2018, 2019, 2020, 2021, 2022],
    'revenue': [100, 120, 150, 180, 200]
