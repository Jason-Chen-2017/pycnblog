# 第1章: 防御型投资的起源与背景

## 1.1 防御型投资的核心概念

### 1.1.1 防御型投资的定义与特点
防御型投资是一种以稳健和安全为核心的投资策略，强调通过基本面分析和价值评估来选择被低估的资产。其核心特点是：
- 避免高风险投资
- 注重安全边际
- 以长期持有为目标

### 1.1.2 防御型投资的历史背景
防御型投资理念起源于20世纪，由本杰明·格雷厄姆提出，强调在市场波动中寻找低估资产，避免盲目跟风。

### 1.1.3 格雷厄姆的防御型投资理念
格雷厄姆认为，投资者应关注安全边际，即资产的内在价值与市场价格之间的差距，以确保投资的安全性。

---

## 1.2 防御型投资与现代投资理念的联系

### 1.2.1 防御型投资与价值投资的区别
- 防御型投资注重安全性和稳健性，而价值投资更注重内在价值。
- 防御型投资更保守，而价值投资可能更具进攻性。

### 1.2.2 防御型投资在现代金融体系中的地位
防御型投资为投资者提供了在不确定市场中稳定收益的策略，尤其适合风险厌恶型投资者。

### 1.2.3 防御型投资的适用场景与局限性
- 适用场景：市场波动较大、经济不确定性增加时。
- 局限性：可能在牛市中错失高收益机会。

---

## 1.3 本章小结
防御型投资以安全性和稳健性为核心，通过基本面分析和安全边际选择低估资产，适合风险厌恶型投资者。

# 第3章: 防御型投资策略的核心要素

## 3.1 防御型投资的三大支柱

### 3.1.1 安全边际的计算方法
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

### 3.1.2 内在价值的评估标准
$$ \text{内在价值} = \sum_{t=1}^{n} \frac{C_t}{(1 + r)^t} $$
其中，\( C_t \) 是第 \( t \) 年的现金流，\( r \) 是折现率。

### 3.1.3 风险调整后的收益模型
$$ \text{风险调整后收益} = \text{预期收益} - \text{风险溢价} $$

---

## 3.2 防御型投资组合的构建

### 3.2.1 资产配置的基本原则
- 股票与债券的合理配比
- 行业和地区的分散化

### 3.2.2 股票与债券的配比策略
建议将资产分配为60%股票和40%债券，以平衡风险和收益。

### 3.2.3 定期再平衡的必要性
每季度审视投资组合，根据市场变化进行调整。

### 3.3.3 应急预案的制定与执行
- 设定止损点
- 定期评估和更新应急预案

### 6.2.1 计算内在价值
```python
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate):
    return np.sum(cash_flows / (1 + discount_rate)**np.arange(len(cash_flows)))

# 示例：计算某股票的内在价值
cf = [100, 120, 150]
r = 0.1
iv = calculate_intrinsic_value(cf, r)
print(f"内在价值为: {iv}")
```
