#### 3.2 核心指标计算

计算PEG比率：

```python
def calculate_pe_ratio(price, earnings):
    return price / earnings

def calculate_growth_rate(earnings, previous_earnings):
    return (earnings - previous_earnings) / previous_earnings

def calculate_peg(price, earnings, previous_earnings):
    pe = calculate_pe_ratio(price, earnings)
    growth = calculate_growth_rate(earnings, previous_earnings)
    return pe / growth
```

## 第四部分：数学模型与公式

### 第4章：关键数学模型

#### 4.1 PEG比率公式

$$PEG = \frac{P}{E \times G}$$

其中，$P$是股价，$E$是每股收益，$G$是收益增长率。

#### 4.2 成长股评估模型

$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$

其中，$CF_t$是第$t$年的现金流，$r$是折现率。
