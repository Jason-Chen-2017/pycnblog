##### 3.2 算法原理的数学模型
- 3.2.1 管理质量评估的数学公式
  $$ Q = \sum_{i=1}^{n} w_i \cdot x_i $$
  其中，$Q$ 表示管理质量，$w_i$ 表示第 $i$ 个指标的权重，$x_i$ 表示第 $i$ 个指标的得分。
- 3.2.2 举例说明
  假设一个团队有三个评估指标，权重分别为 $w_1=0.4$，$w_2=0.3$，$w_3=0.3$，得分分别为 $x_1=0.8$，$x_2=0.7$，$x_3=0.9$。则管理质量 $Q$ 为：
  $$ Q = 0.4 \times 0.8 + 0.3 \times 0.7 + 0.3 \times 0.9 = 0.32 + 0.21 + 0.27 = 0.80 $$

- 计算各指标得分
- 综合计算管理质量得分

##### 5.2 核心代码实现
```python
def fisher_management_assessment(team_data, weights):
    # 输入：team_data (列表，每个元素为指标得分)，weights (权重列表)
    # 输出：管理质量得分 Q
    Q = sum(w * x for w, x in zip(weights, team_data))
    return Q

# 示例数据
team_data = [0.8, 0.7, 0.9]
weights = [0.4, 0.3, 0.3]
Q = fisher_management_assessment(team_data, weights)
print("管理质量得分 Q =", Q)
```
