## 第三部分：算法原理

### 第3章：算法原理讲解

#### 3.1 支持向量机（SVM）
- 3.1.1 算法原理
  - 数据映射到高维空间
  - 找到最优超平面
  - 分类问题

- 3.1.2 优化目标
  $$ \text{最小化} \frac{1}{2} ||w||^2 + C \sum_{i=1}^n \xi_i $$
  $$ \text{约束条件} y_i (w \cdot x_i + b) \geq 1 - \xi_i, \xi_i \geq 0 $$

- 3.1.3 对偶问题
  $$ \max_{\alpha} \sum_{i=1}^n \alpha_i - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j y_i y_j K(x_i, x_j) $$
  $$ \text{约束条件} 0 \leq \alpha_i \leq C $$

- 3.1.4 代码实现
  ```python
  from sklearn import svm

  # 创建数据集
  X = [[0, 0], [1, 1], [1, 0], [0, 1]]
  y = [0, 1, 1, 1]

  # 创建SVM分类器
  clf = svm.SVC(kernel='linear')
  clf.fit(X, y)
  ```

#### 3.2 随机森林（Random Forest）
- 3.2.1 算法原理
  - 决策树集成
  - 随机选择特征
  - 袋装法

- 3.2.2 核心算法
  - ID3/C4.5/C5.0
  - 信息增益

- 3.2.3 代码实现
  ```python
  from sklearn.ensemble import RandomForestClassifier

  # 创建数据集
  X = [[0, 0], [1, 1], [1, 0], [0, 1]]
  y = [0, 1, 1, 1]

  # 创建随机森林分类器
  clf = RandomForestClassifier(n_estimators=10)
  clf.fit(X, y)
  ```

#### 3.3 神经网络（Neural Network）
- 3.3.1 算法原理
  - 层次化结构
  - 激活函数
  - 反向传播

- 3.3.2 网络结构
  - 输入层
  - 隐藏层
  - 输出层

- 3.3.3 代码实现
  ```python
  import torch
  import torch.nn as nn

  # 创建神经网络模型
  class Net(nn.Module):
      def __init__(self):
          super(Net, self).__init__()
          self.fc1 = nn.Linear(2, 4)
          self.fc2 = nn.Linear(4, 2)
          self.fc3 = nn.Linear(2, 1)

      def forward(self, x):
          x = torch.relu(self.fc1(x))
          x = torch.relu(self.fc2(x))
          x = torch.sigmoid(self.fc3(x))
          return x

  net = Net()
  ```
