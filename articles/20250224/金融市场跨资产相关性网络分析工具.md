## 第二部分：跨资产相关性网络分析的核心理论

### 第2章：跨资产相关性网络分析的统计基础

#### 2.1 相关性系数的计算方法
- **皮尔逊相关系数**：
  - 定义：衡量两个变量之间的线性相关性。
  - 计算公式：$$r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2} \sqrt{\sum (y_i - \bar{y})^2}}$$
- **斯皮尔曼相关系数**：
  - 定义：衡量两个变量之间的秩相关性。
  - 适用于非线性关系的分析。

#### 2.2 聚类分析与网络构建
- **聚类分析**：
  - 将相关性较高的资产聚类在一起，形成网络中的社区结构。
  - 常用算法：K-means、层次聚类、谱聚类。
- **网络构建**：
  - 基于相关性矩阵构建无向图，边权重表示相关性强度。

#### 2.3 网络密度与中心性分析
- **网络密度**：
  - 定义：网络中边的数量与可能边数的比率。
  - 公式：$$\text{密度} = \frac{\text{边数}}{\binom{n}{2}}$$
- **中心性分析**：
  - 定义：衡量网络中节点的重要程度。
  - 常用指标：度中心性、中间中心性、接近中心性。

#### 4.2 时间序列数据的特征提取
- **移动平均（MA）**：
  - 公式：$$\text{MA}_n = \frac{1}{n} \sum_{i=1}^{n} p_i$$
- **指数移动平均（EMA）**：
  - 公式：$$\text{EMA}_t = \alpha p_t + (1 - \alpha) \text{EMA}_{t-1}$$

  import pandas as pd

  # 计算相关性矩阵
  df = pd.DataFrame(data)
  correlation_matrix = df.corr()

  # 构建网络边列表
  edges = []
  for i in range(len(correlation_matrix)):
      for j in range(i+1, len(correlation_matrix)):
          if abs(correlation_matrix.iloc[i,j]) > 0.3:
