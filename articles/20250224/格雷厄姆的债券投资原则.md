## 第二部分：格雷厄姆的债券投资原则

### 2.1 核心概念与安全边际

格雷厄姆的安全边际理念强调以低于内在价值的价格买入债券，确保在市场波动中获得收益。以下是核心概念的详细解释：

#### 2.1.1 债券的内在价值

债券的内在价值是其未来现金流的现值。计算公式为：

$$ V = \sum_{t=1}^{n} \frac{C}{(1 + r)^t} + \frac{F}{(1 + r)^n} $$

其中，\( C \) 为每年的利息支付，\( F \) 为面值，\( r \) 为折现率，\( n \) 为债券期限。

#### 2.1.2 安全边际的计算

安全边际 = 内在价值 - 市场价格

---

### 2.2 利率风险与债券价格的关系

#### 2.2.1 利率波动的影响

债券价格与利率呈负相关关系。当利率上升时，债券价格下跌，反之亦然。

#### 2.2.2 久期与凸性的数学模型

久期衡量价格对利率变动的敏感性：

$$ D = -\frac{P}{r} \frac{dP}{dr} $$

凸性衡量久期在不同利率水平的变化：

$$ C = \frac{1}{2} \frac{d^2P}{dr^2} $$

## 第三部分：债券定价的数学模型与算法

### 3.1 债券定价的Python实现

```python
def bond_value(C, F, r, n):
    return sum(C/(1+r)**t for t in range(1, n+1)) + F/(1+r)**n

# 示例计算
C = 100
F = 1000
r = 0.05
n = 10
print(bond_value(C, F, r, n))  # 输出: 1124.62
```
