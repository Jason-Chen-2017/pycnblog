## 第2章: 区块链技术原理与核心概念

### 2.1 区块链的核心技术原理

#### 2.1.1 分布式账本

- 分布式账本的结构与存储方式
  - 每个节点都有一份完整的账本副本
  - 数据一致性通过共识机制实现
- 分布式账本的优势
  - 高可用性
  - 数据一致性
  - 抗单点故障

#### 2.1.2 共识机制

- 共识机制的种类与特点
  - 工作量证明（PoW）
  - 权益证明（PoS）
  - 肉币证明（BFT）
- 共识机制的核心作用
  - 确保所有节点达成一致的交易记录
  - 防止双重支付和恶意攻击

- 加密算法的作用
  - 数据完整性验证

  - 基于区块链的可编程性

### 3.2 跨境支付中的智能合约应用

#### 3.2.1 智能合约的实现原理

```python
# 智能合约示例代码（以太坊Solidity语言）
pragma solidity ^0.8.0;

contract CrossborderPayment {
    mapping(address => uint256) public balances;

    function deposit() public payable {
        balances[msg.sender] += msg.value;
    }

    function withdraw(address payable recipient) public {
        require(balances[msg.sender] > 0, "No balance to withdraw");
        recipient.transfer(balances[msg.sender]);
        balances[msg.sender] = 0;
    }
}
```

#### 3.2.2 智能合约的实际应用场景

- 自动化跨境汇款
- 跨境贸易的自动清算
- 跨境支付的条件支付（如货物到达后再支付）
