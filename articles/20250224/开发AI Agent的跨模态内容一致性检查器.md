## 4.4 对比学习的数学模型

### 4.4.1 对比损失函数
$$ L_{\text{contrast}} = -\log\left(\frac{e^{sim(x,y)}}{e^{sim(x,y)} + \sum_{z \neq y} e^{sim(x,z)}}\right) $$

### 4.4.2 对比学习的优势
提升特征的区分度和一致性。

## 4.5 生成对抗网络的数学模型

### 4.5.1 生成器的损失函数
$$ L_{\text{gen}} = \log\left(1 - D(x)\right) $$

### 4.5.2 判别器的损失函数
$$ L_{\text{dis}} = -\log(D(x)) - \log(1 - D(z)) $$

## 4.6 算法的Python实现示例

```python
import torch
import torch.nn as nn

class ContrastiveLoss(nn.Module):
    def __init__(self, temperature=0.1):
        super(ContrastiveLoss, self).__init__()
        self.temperature = temperature

    def forward(self, features):
        # 计算相似度矩阵
        sim_matrix = torch.mm(features, features.t())
        # 计算正向相似度
        positives = torch.diag(sim_matrix)
        # 计算反向相似度
        negatives = torch.sum(sim_matrix) - positives.sum()
        # 计算损失
        loss = -torch.mean(torch.log(positives / (positives + negatives)))
        return loss
```
