# 第一部分: 行为金融学基础与理论框架

## 第1章: 行为金融学概述

### 1.1 行为金融学的起源与发展
- **1.1.1 传统金融学的局限性**
  - 传统金融学假设：理性投资者、有效市场、套利机会消除。
  - 但现实中，投资者往往存在情绪波动、认知偏差，导致市场非理性行为。
- **1.1.2 行为金融学的诞生与核心思想**
  - 行为金融学将心理学引入金融领域，研究投资者决策的非理性因素。
  - 核心思想：市场参与者的心理和行为影响资产价格，需结合心理学分析。
- **1.1.3 行为金融学与心理学的交叉融合**
  - 基础心理学：认知、情感、社会行为。
  - 行为金融学：情绪、认知偏差、群体行为对投资决策的影响。

### 1.2 行为金融学的核心概念
- **1.2.1 心理账户与决策偏见**
  - 心理账户：投资者将资金分为多个账户，每个账户有不同的心理预期。
  - 偏见：损失厌恶、确认偏见、从众心理。
- **1.2.2 框架依赖与损失厌恶**
  - 框架依赖：问题描述方式影响决策。
  - 损失厌恶：损失带来的痛苦大于同等收益带来的快乐。
- **1.2.3 有限理性与启发式决策**
  - 有限理性：决策者无法完全理性，只能基于有限信息和认知进行决策。
  - 启发式：简化决策过程，但可能引入偏差。

### 1.3 行为金融学与传统金融学的区别
- **1.3.1 传统金融学的假设与缺陷**
  - 理性假设：忽视人类情感和认知偏差。
  - 弱有效市场：无法解释市场异常现象。
- **1.3.2 行为金融学的现实基础**
  - 强调心理因素对市场的影响。
  - 解释市场异象：波动性、泡沫、恐慌。
- **1.3.3 两者的融合与互补**
  - 结合行为金融学和传统金融学，形成更全面的分析框架。

### 1.4 本章小结
- 介绍了行为金融学的起源与发展。
- 阐述了行为金融学的核心概念和与传统金融学的区别。
- 为后续分析奠定了基础。

## 第2章: 行为金融学的核心理论

### 2.1 心理学基础
- **2.1.1 心理账户的定义与特征**
  - 心理账户：投资者将资金分配到不同账户，每个账户有特定目标和心理预期。
  - 特征：分割性、独立性、非线性。
- **2.1.2 基础心理偏见与行为模式**
  - 偏见：损失厌恶、确认偏见、从众心理。
  - 行为模式：过度自信、从众投资、羊群效应。
- **2.1.3 情绪与认知的相互作用**
  - 情绪影响认知：积极情绪增加风险偏好，消极情绪降低风险承受。
  - 认知影响情绪：认知偏差导致情绪波动。

### 2.2 行为决策理论
- **2.2.1 prospect theory**
  - 净现值函数：V = √(|P - P0|), P为收益或损失，P0为参考点。
  - 损失厌恶：损失带来的效用损失大于同等收益带来的效用增加。
- **2.2.2 regret theory**
  - 后悔理论：决策者基于未来可能后悔的程度进行决策。
  - 后悔函数：R = max(损失，收益)。
- **2.2.3 有限理性理论**
  - 决策过程：基于有限信息和认知进行简化决策。
  - 启发式：代表性、可得性、调整性。

### 2.3 市场参与者的心理与行为
- **2.3.1 投资者心理分析**
  - 零散投资者：情绪波动大，容易从众。
  - 机构投资者：理性更强，但受情绪影响仍存在。
- **2.3.2 机构投资者的行为特征**
  - 群体决策：机构内部决策受个体情绪影响。
  - 行为传染：机构行为对散户的影响。
- **2.3.3 市场情绪与群体行为**
  - 情绪指数：衡量市场整体情绪。
  - 羊群效应：投资者跟随市场趋势，导致价格偏离基本面。

### 2.4 本章小结
- 探讨了行为决策理论和市场参与者的行为特征。
- 分析了情绪与认知的相互作用，及其对市场的影响。

### 3.1 基于心理账户的决策模型

### 3.2 情绪与认知偏差的数学建模
- **3.2.1 情绪指数的构建与测量**
  - 情绪指数：通过市场数据和新闻情绪分析构建。
  - 情绪分析：使用文本挖掘技术，量化市场情绪。
- **3.2.2 认知偏差的数学表达**
  - 认知偏差函数：D = f(P, C), P为价格，C为认知。
  - 偏差类型：确认偏见、选择性注意。
- **3.2.3 情绪与认知偏差对资产定价的影响**
  - 情绪驱动定价模型：P = f(M, D), M为市场情绪，D为认知偏差。

### 3.3 市场行为的预测模型
- **3.3.1 基于行为金融学的市场预测框架**

- **3.3.2 情绪驱动的资产价格波动模型**
  - 模型：ΔP = α * M + β * D + ε。
  - 参数解释：α为情绪影响系数，β为认知偏差影响系数。
- **3.3.3 市场参与者的互动与反馈机制**
  - 反馈机制：市场行为影响情绪，情绪反过来影响市场行为。
