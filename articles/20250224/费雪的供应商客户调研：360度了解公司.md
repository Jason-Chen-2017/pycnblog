## 第3章 算法原理讲解

### 3.1 算法原理

#### 3.1.1 供应商评分模型

```mermaid
graph TD
    A[供应商数据] --> B[数据清洗]
    B --> C[特征提取]
    C --> D[评分计算]
    D --> E[结果可视化]
```

#### 3.1.2 加权评分公式

$$
\text{供应商评分} = \sum (\text{特征权重} \times \text{特征值})
$$

### 3.2 算法实现

#### 3.2.1 Python代码实现

```python
import pandas as pd

# 数据加载
data = pd.read_csv('供应商客户数据.csv')

# 数据清洗
data = data.dropna()
data = data.drop_duplicates()

# 特征提取
features = ['供应商ID', '交货时间', '质量评分']

# 加权评分计算
weights = {'供应商ID': 0.3, '交货时间': 0.4, '质量评分': 0.3}
supplier_score = data[features].apply(lambda x: sum(weights[f] * x[f] for f in features), axis=1)

# 结果可视化
import matplotlib.pyplot as plt
plt.hist(supplier_score)
plt.show()
```
