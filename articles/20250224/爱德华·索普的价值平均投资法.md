### 第2章: 价值平均投资法的数学模型与公式

#### 2.1 投资组合的数学模型
- 2.1.1 投资组合的期望收益计算
  - 期望收益公式：$$E(r) = \sum w_i \times r_i$$
  - $w_i$为资产i的权重，$r_i$为资产i的预期收益率。
- 2.1.2 投资组合的风险评估
  - 风险公式：$$\sigma^2 = \sum w_i^2 \times \sigma_i^2 + 2 \sum w_i w_j \times \sigma_{ij}$$
  - $\sigma_{ij}$为资产i和j的相关性系数。
- 2.1.3 价值平均法的数学表达式
  - 资产分配公式：$$w_i = \frac{v_i}{\sum v_j}$$
  - $v_i$为资产i的价值评估，$\sum v_j$为所有资产价值的总和。

#### 2.2 价值平均法的公式推导
- 2.2.1 资产分配的数学模型
  - 资产价值评估：$$v_i = \frac{p_i}{E(r_i)}$$
  - $p_i$为资产i的市场价格，$E(r_i)$为预期收益率。
- 2.2.2 投资组合优化的数学公式
  - 优化目标：$$\min \sigma^2$$
  - 约束条件：$$\sum w_i = 1$$
- 2.2.3 价值平均法的公式应用
  - 示例：假设两个资产，A和B，预期收益率分别为10%和15%，价格分别为100和150。
  - 计算价值评估：$$v_A = \frac{100}{0.1} = 1000$$
  - $$v_B = \frac{150}{0.15} = 1000$$
  - 资产分配比例：$$w_A = w_B = 0.5$$

#### 2.3 数学模型的实例分析
- 2.3.1 实际案例中的数学模型应用
  - 案例：投资组合由股票和债券组成，预期收益率分别为8%和5%，相关系数为0.3。
  - 计算投资组合的预期收益率和风险。
- 2.3.2 公式推导的详细步骤
  - 计算协方差矩阵，求解投资组合的方差。
- 2.3.3 投资组合优化的数学证明
  - 使用拉格朗日乘数法证明最优解。

- 4.2.1 投资组合优化的Python代码
  ```python
  import pandas as pd
  import numpy as np
  from sklearn.covariance import MinCovQDA
  import yfinance as yf

  # 下载数据
  aapl = yf.download('AAPL', start='2020-01-01', end='2023-01-01')
  msft = yf.download('MSFT', start='2020-01-01', end='2023-01-01')

  # 计算收益率
  aapl_returns = aapl['Adj Close'].pct_change().dropna()
  msft_returns = msft['Adj Close'].pct_change().dropna()

  # 计算协方差矩阵
  returns = pd.concat([aapl_returns, msft_returns], axis=1)
  cov_matrix = returns.cov()

  # 计算最优权重
  def optimal_weights(cov_matrix, returns):
      n = cov_matrix.shape[0]
      cov = cov_matrix.values
      inv_cov = np.linalg.inv(cov)
      weights = inv_cov @ np.ones(n)
      weights = weights / weights.sum()
      return weights * returns.values

  weights = optimal_weights(cov_matrix, returns)
  ```
