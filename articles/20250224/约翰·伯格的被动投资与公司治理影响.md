4.3 Python代码实现
```python
import pandas as pd
import numpy as np

# 示例代码：计算指数权重
def calculate_weights(index_components):
    returns = pd.Series(np.random.randn(len(index_components)), index=index_components)
    weights = returns.sort_values(ascending=False).cumsum()
    return weights

index_components = ['AAPL', 'GOOGL', 'MSFT', 'AMZN']
weights = calculate_weights(index_components)
print(weights)
```

4.4 数学模型与公式
4.4.1 夏普比率公式：
$$\text{夏普比率} = \frac{E[r_i - r_f]}{\sigma_i}$$
其中，$E[r_i - r_f]$ 是资产的超额收益期望值，$\sigma_i$ 是资产收益的标准差。

4.4.2 CAPM模型：
$$E[r_i] = r_f + \beta_i (E[r_m] - r_f)$$
其中，$r_f$ 是无风险利率，$\beta_i$ 是资产的贝塔系数，$E[r_m]$ 是市场预期回报率。
