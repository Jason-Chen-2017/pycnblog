## 第一部分: 投资成本最小化理论的背景与核心概念

### 第1章: 投资成本最小化理论概述

#### 1.1 投资成本的定义与重要性

投资成本是指在投资过程中产生的各种费用，包括交易成本、管理费用、税收等。这些成本直接影响投资回报，因此最小化投资成本是投资者追求的目标之一。

#### 1.2 投资成本的构成与分类

- **显性成本**：直接可见的费用，如交易佣金、管理费。
- **隐性成本**：间接费用，如市场冲击成本（交易时对市场价格的影响）。
- **机会成本**：由于投资某项目而放弃其他项目的潜在收益。

#### 1.3 约翰·伯格理论的核心思想

约翰·伯格的投资成本最小化理论强调通过优化投资组合的结构和交易策略，降低整体成本，从而提高净收益。其核心在于平衡成本和收益，避免过度交易和不必要的费用。

### 第2章: 投资成本最小化理论的数学模型

#### 2.1 投资组合优化的数学表达

目标是最小化总成本，同时满足收益目标。数学模型如下：

$$
\min_{w} \sum_{i=1}^{n} c_i w_i + \lambda \sum_{i=1}^{n} \sum_{j=1}^{n} w_i w_j |r_i - r_j|
$$

其中，\( w_i \) 是投资比例，\( c_i \) 是显性成本，\( \lambda \) 是市场冲击成本的惩罚系数，\( r_i \) 是资产 \( i \) 的预期收益。

import numpy as np
from scipy.optimize import minimize

def cost_minimization(weights, costs, market_impact):
    # 定义目标函数
    return np.sum(costs * weights) + np.sum(weights[:, np.newaxis] * weights * market_impact)

# 初始权重
weights_initial = np.array([0.3, 0.3, 0.4])
costs = np.array([0.01, 0.02, 0.015])
market_impact = np.array([[0, 0.005, 0.003],
                           [0.005, 0, 0.004],
                           [0.003, 0.004, 0]])

# 使用最小二乘法求解
result = minimize(cost_minimization, weights_initial, args=(costs, market_impact))
print(result.x)

from scipy.optimize import minimize

def objective(weights, costs, market_impact):
    return np.sum(costs * weights) + np.sum(weights[:, np.newaxis] * weights * market_impact)

# 约束条件：权重之和为1
cons = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1})

# 初始权重
weights_initial = np.array([0.3, 0.3, 0.4])

# 最小化问题
result = minimize(objective, weights_initial, args=(costs, market_impact), constraints=cons)
