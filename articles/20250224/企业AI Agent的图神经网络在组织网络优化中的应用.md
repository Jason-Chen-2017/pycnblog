# 第二部分: 图神经网络的核心算法与实现

## 第2章: 图神经网络的核心算法

### 2.1 图卷积网络（GCN）

#### 2.1.1 GCN的基本原理
GCN将图的结构信息与节点特征结合，进行卷积操作。

#### 2.1.2 GCN的数学模型
$$ Y = A X X^T $$
其中，A是邻接矩阵，X是特征矩阵，Y是输出。

#### 2.1.3 GCN的实现步骤
1. **构建邻接矩阵**：表示节点间关系
2. **计算归一化矩阵**：处理权重和度
3. **执行前向传播**：计算节点表示

#### 2.1.4 GCN的Python代码实现
```python
import numpy as np

def compute_gcn(x, adj):
    normalized_adj = adj / (adj.sum(axis=1).reshape(-1, 1))
    output = np.dot(normalized_adj, x)
    return output
```

### 2.2 图注意力网络（GAT）

#### 2.2.1 GAT的基本原理
GAT通过注意力机制，赋予不同邻居节点不同权重。

#### 2.2.2 GAT的数学模型
$$ \alpha_{ij} = \text{softmax}(e^{a^T(x_i - x_j)}) $$
其中，α是注意力权重，a是可学习的参数。

#### 2.2.3 GAT的实现步骤
1. **计算注意力权重**
2. **计算加权和**
3. **前向传播**

#### 2.2.4 GAT的Python代码实现
```python
import torch

class GATLayer(torch.nn.Module):
    def __init__(self, in_features, out_features):
        super(GATLayer, self).__init__()
        self.w = torch.nn.Parameter(torch.zeros(in_features, out_features))
        self.a = torch.nn.Parameter(torch.zeros(1, out_features))

    def forward(self, x, adj):
        x = torch.mm(x, self.w)
        attention = torch.mul(x, self.a)
        attention = torch.sum(attention, dim=1)
        attention = torch.softmax(attention, dim=0)
        output = torch.mm(attention, x)
        return output
```
