## 第一部分：巴菲特投资法则的背景与核心理念

### 第1章：巴菲特投资法则的背景

#### 1.1 巴菲特的投资哲学与方法

- 巴菲特的投资理念：长期价值投资，寻找具有持续竞争优势的企业。
- 巴菲特的选股标准：关注企业的财务健康、盈利能力、管理团队和行业地位。
- 打孔卡的由来：巴菲特曾提到过一种投资筛选方法，形象地称为“20格打孔卡”，用于系统地评估企业。

#### 1.2 打孔卡法则的起源与意义

- 打孔卡法则是一种投资筛选工具，通过设定多个关键指标，对企业进行综合评估。
- 该方法帮助投资者快速筛选出符合投资标准的企业，降低决策风险。

#### 1.3 打孔卡法则的核心目标与适用场景

- 核心目标：通过多维度指标筛选出具有长期投资价值的企业。
- 适用场景：适用于个人投资者和机构投资者，尤其适合长期价值投资策略。

## 第2章：20格打孔卡法则的核心指标与筛选标准

### 2.1 打孔卡法则的核心指标

- **财务指标**：ROE（净资产收益率）、ROA（资产回报率）、净利润率、毛利率。
- **资产质量指标**：资产负债率、流动比率、速动比率。
- **现金流指标**：自由现金流、现金流与净利润比率。
- **市场指标**：市盈率、市净率、股息率。

#### 2.1.1 财务指标

| 指标名称 | 定义 | 重要性 |
|----------|------|--------|
| ROE      | 净利润 / 平均股东权益 | 衡量企业使用股东资金的效率 |
| ROA      | 净利润 / 平均总资产   | 衡量企业资产的使用效率 |
| 净利率    | 净利润 / 收入       | 衡量企业的盈利能力 |
| 毛利率    | 毛利润 / 收入       | 衡量企业的成本控制能力 |

#### 2.1.2 资产质量指标

| 指标名称 | 定义 | 重要性 |
|----------|------|--------|
| 资产负债率 | 负债总额 / 资产总额 | 衡量企业的财务杠杆风险 |
| 流动比率  | 流动资产 / 流动负债 | 衡量企业的短期偿债能力 |
| 速动比率  | (流动资产 - 存货) / 流动负债 | 衡量企业的快速变现能力 |

#### 2.1.3 现金流指标

| 指标名称 | 定义 | 重要性 |
|----------|------|--------|
| 自由现金流 | 净利润 - 非现金支出 | 衡量企业的现金生成能力 |
| 现金流与净利润比率 | 自由现金流 / 净利润 | 衡量现金流与净利润的匹配程度 |

#### 2.1.4 市场指标

| 指标名称 | 定义 | 重要性 |
|----------|------|--------|
| 市盈率    | 股价 / 每股收益 | 衡量股票的估值水平 |
| 市净率    | 股价 / 每股净资产 | 衡量股票相对于账面价值的高低 |
| 股息率    | 每股股息 / 股价 | 衡量股票的分红能力 |

### 2.2 核心指标的筛选标准与权重分配

#### 2.2.1 指标权重的确定方法

- 根据指标的重要性进行权重分配，通常财务指标权重较大，市场指标权重较小。
- 示例权重分配：
  - ROE：30%
  - 净利率：25%
  - 资产负债率：20%
  - 市盈率：15%
  - 股息率：10%

#### 2.2.2 指标筛选的逻辑与优先级

- 优先筛选高ROE和高净利率的企业。
- 排除高负债率和高市盈率的企业。
- 优先选择股息率较高的企业。

### 3.1 打孔卡法则的数学模型

#### 3.1.1 指标评分函数的构建

- 每个指标赋予一定的权重，计算综合评分。
- 评分公式：
  \[
  \text{综合评分} = \sum_{i=1}^{n} w_i \times s_i
  \]
  其中，\( w_i \) 为指标 \( i \) 的权重，\( s_i \) 为指标 \( i \) 的评分。

#### 3.1.2 综合评分模型的建立

- 将20个指标按照权重和评分规则进行综合评分。
- 示例评分规则：
  - 指标评分范围：1-5分，5分为最优。
  - 根据指标实际值与标准值的偏离程度打分。

#### 3.1.3 模型的优化与调整

import pandas as pd

def calculate_indicator_scores(data, target_values):
    scores = {}
    for indicator in data.columns:
        # 示例评分逻辑
        score = 5 - abs(data[indicator] - target_values[indicator]) / target_values[indicator] * 4
        scores[indicator] = score.round(2)
    return scores

# 示例数据
data = pd.DataFrame({
    'ROE': [20, 15, 25],
    'ROA': [12, 10, 15],
    'net_profit_margin': [10, 8, 12],
    'debt_ratio': [0.6, 0.5, 0.7],
    'pe_ratio': [18, 15, 12],
    'dividend_yield': [1.5, 2, 1]
})
target_values = {
    'ROE': 20,
    'ROA': 15,
    'net_profit_margin': 10,
    'debt_ratio': 0.5,
    'pe_ratio': 15,
    'dividend_yield': 1.5
}

scores = calculate_indicator_scores(data, target_values)
print(scores)

#### 5.2.2 综合评分排序代码

def calculate_total_score(indicator_scores, weights):
    total_scores = []
    for index, row in indicator_scores.iterrows():
        total = 0
        for indicator in row.index:
            total += row[indicator] * weights[indicator]
        total_scores.append(total)
    return total_scores

# 示例权重
weights = {
    'ROE': 0.3,
    'ROA': 0.25,
    'net_profit_margin': 0.2,
    'debt_ratio': 0.15,
    'pe_ratio': 0.1,
    'dividend_yield': 0.1
}
