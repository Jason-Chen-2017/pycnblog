## 代码示例

以下是一个简单的多智能体系统模拟市场行为的代码示例：

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义多智能体系统中的智能体数量
num_agents = 100

# 初始化智能体的初始行为
agents = np.random.rand(num_agents)

# 定义智能体的交互规则
def update_agents(agents):
    for i in range(len(agents)):
        # 假设每个智能体的行为受到其他智能体的影响
        agents[i] = np.mean(agents)
    return agents

# 模拟市场行为
steps = 100
market_behavior = np.zeros((steps, num_agents))

for i in range(steps):
    agents = update_agents(agents)
    market_behavior[i] = agents

# 绘制市场行为的动态变化
plt.figure(figsize=(12, 6))
plt.plot(market_behavior.T)
plt.title('Market Behavior Dynamics')
plt.xlabel('Time Steps')
plt.ylabel('Agent Behavior')
plt.show()
```
