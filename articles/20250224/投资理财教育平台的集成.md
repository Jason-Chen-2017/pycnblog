  - 基于均值-方差模型的投资组合优化
  - 算法步骤
  - 示例代码：
    ```python
    import numpy as np
    def optimize_portfolio(returns, weights):
        # 计算协方差矩阵
        covariance = np.cov(returns)
        # 计算最优权重
        inv_cov = np.linalg.inv(covariance)
        weights = inv_cov.dot(weights)
        return weights / np.sum(weights)
    ```
  - 用公式表示：
    $$
    \text{最优权重} = \arg \min_w (w^T \Sigma w) \quad \text{subject to} \quad \sum w_i = 1
    $$
