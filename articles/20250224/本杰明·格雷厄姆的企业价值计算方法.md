## 第一部分: 价值投资与企业价值评估基础

### 第1章: 价值投资的起源与发展

#### 1.1 价值投资的起源
价值投资是一种以企业内在价值为核心的投资策略，起源于20世纪初。本杰明·格雷厄姆是该领域的先驱，他通过深入研究企业的财务数据和市场行为，提出了“安全边际”和“内在价值”等核心概念。

- **投资学的起源与发展**  
  投资学作为一门学科，经历了从早期的投机行为到系统化分析的演变。格雷厄姆的出现标志着价值投资的正式诞生。

- **本杰明·格雷厄姆的生平与贡献**  
  格雷厄姆是美国著名的经济学家和投资家，他在1929年经济大萧条期间提出了价值投资理论，强调通过基本面分析寻找被低估的股票。

- **价值投资的核心理念**  
  价值投资的核心在于寻找市场价格低于内在价值的股票，通过安全边际降低投资风险。

#### 1.2 价值投资与基本面分析
基本面分析是价值投资的基础，它通过对企业财务报表的分析，评估企业的盈利能力、成长性和财务健康状况。

- **基本面分析的定义与作用**  
  基本面分析包括对企业财务状况、行业地位、管理团队等多个方面的综合评估，旨在发现企业的真正价值。

- **价值投资与技术分析的区别**  
  技术分析侧重于价格走势和交易量，而价值投资则关注企业的内在价值和市场定价。

- **价值投资在现代投资学中的地位**  
  尽管现代投资学强调多样化和分散化，但价值投资在长期投资中仍然具有不可替代的作用。

#### 1.3 格雷厄姆的价值投资理论
格雷厄姆的价值投资理论以“安全边际”和“内在价值”为核心，强调长期投资和风险控制。

- **安全边际的定义与作用**  
  安全边际是指市场价格与内在价值之间的差距，它为投资提供了安全保障。

- **内在价值的计算方法**  
  内在价值是企业未来现金流的现值，可以通过股利折现模型或自由现金流折现模型计算。

- **安全边际与投资决策的关系**  
  通过安全边际，投资者可以在市场价格低于内在价值时买入，从而降低投资风险。

#### 1.4 价值投资的适用场景与局限性
价值投资适用于市场波动较大、企业基本面稳定的环境，但在市场过度波动或企业财务状况不透明的情况下，其局限性显现。

- **价值投资的适用场景**  
  在经济衰退或市场低迷时期，价值投资往往能够发现被低估的企业。

- **价值投资的局限性**  
  在市场泡沫或企业财务造假的情况下，价值投资可能无法有效识别风险。

- **价值投资与成长投资的对比**  
  成长投资关注企业的成长性，而价值投资关注企业的安全性。两者在不同市场环境下表现各异。

#### 1.5 本章小结
本章从价值投资的起源、核心理念和实际应用等方面，全面介绍了本杰明·格雷厄姆的投资理论。接下来将深入分析企业价值评估的核心概念和计算方法。

### 第2章: 企业价值评估的核心概念

#### 2.1 企业价值评估的背景与意义
企业价值评估是价值投资的重要组成部分，它通过分析企业的财务状况和市场环境，确定企业的内在价值。

- **企业价值评估的定义**  
  企业价值评估是通过对企业未来现金流的现值计算，确定企业的真实价值。

- **企业价值评估的重要性**  
  企业价值评估是投资者做出投资决策的重要依据，也是企业并购和重组的关键因素。

- **企业价值评估的边界与外延**  
  企业价值评估不仅关注企业的财务数据，还包括企业的市场地位和竞争优势。

#### 2.2 格雷厄姆的企业价值计算模型
格雷厄姆提出了基于市盈率和净收益的企业价值计算公式。

- **格雷厄姆的企业价值公式**  
  $$ \text{企业价值} = \text{净收益} \times \text{安全边际系数} $$

- **净收益的计算公式**  
  $$ \text{净收益} = \text{收入} - \text{成本} - \text{费用} $$

- **安全边际系数的计算公式**  
  $$ \text{安全边际系数} = \frac{\text{市场价格}}{\text{内在价值}} $$

#### 2.3 格雷厄姆模型与现代企业价值评估方法的对比
现代企业价值评估方法在格雷厄姆的基础上，引入了更多的因素和模型。

- **格雷厄姆模型的特点**  
  格雷厄姆模型简单易用，但仅适用于企业财务状况稳定的情况。

- **现代企业价值评估方法的演变**  
  现代方法包括股利折现模型、自由现金流折现模型和相对估值法等。

- **格雷厄姆模型的局限性**  
  格雷厄姆模型忽略了市场波动和宏观经济因素的影响。

#### 2.4 企业价值评估的核心要素对比表

```python
import numpy as np
import pandas as pd

def calculate_intrinsic_value(net_income, market_price):
    safety_margin_coefficient = market_price / net_income
    intrinsic_value = net_income * safety_margin_coefficient
    return intrinsic_value

# 示例数据
data = {'净收益': [100, 200, 300], '市场价格': [50, 100, 150]}
df = pd.DataFrame(data)
df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['净收益'], x['市场价格']), axis=1)
print(df)
```
