## 第一部分: 股票图表分析的背景与基础

### 第1章: 股票市场的基本概念

#### 1.1 股票市场的基本概念
- **1.1.1 股票市场的定义与作用**
  - 股票市场的定义：股票市场是投资者交易公司股份的场所，反映了市场对公司的价值评估。
  - 股票市场的三大作用：融资、价格发现、风险转移。
  - 股票市场的参与者：个人投资者、机构投资者、券商、交易所。

- **1.1.2 股票交易的基本流程**
  - 买空与卖空：买空指买入股票等待价格上涨，卖空指借入股票卖出后等待价格下跌再买回。
  - 交割与清算：交易后的结算过程，确保资金和证券的交割。

- **1.1.3 股票价格波动的规律**
  - 影响股价的因素：宏观经济、行业趋势、公司基本面、市场情绪。
  - 股价波动的周期性：市场波动受政策、经济周期和投资者情绪影响。

- **1.1.4 技术分析与基本面分析的区别**
  - 技术分析：通过历史价格和成交量数据预测未来走势。
  - 基本面分析：研究公司的财务状况、行业地位和盈利能力。

#### 1.2 威廉·欧奈尔的贡献与CAN SLIM系统
- **1.2.1 威廉·欧奈尔的生平简介**

## 第二部分: 图表分析的核心技巧

### 第2章: 支撑线与阻力线的识别

#### 2.1 支撑线的定义与作用
- **2.1.1 支撑线的基本概念**
  - 支撑线：价格在下跌过程中遇到支撑，阻止价格继续下跌的水平线。
  - 支撑线的作用：提供买入机会，确认价格支撑区域。

- **2.1.2 支撑线的类型与特点**
  - 主要支撑线：长期趋势中的关键支撑位。
  - 次级支撑线：主要支撑线之下的支撑位。

- **2.1.3 支撑线在交易中的应用**
  - 确认支撑区域：在价格接近支撑线时买入。
  - 判断趋势反转：突破支撑线可能预示趋势反转。

#### 2.2 阻力线的定义与作用
- **2.2.1 阻力线的基本概念**
  - 阻力线：价格在上涨过程中遇到阻力，阻止价格继续上涨的水平线。
  - 阻力线的作用：提供卖出机会，确认价格阻力区域。

- **2.2.2 阻力线的类型与特点**
  - 主要阻力线：长期趋势中的关键阻力位。
  - 次级阻力线：主要阻力线之上的阻力位。

- **2.2.3 阻力线在交易中的应用**
  - 确认阻力区域：在价格接近阻力线时卖出。
  - 判断趋势反转：突破阻力线可能预示趋势延续。

#### 2.3 趋势线与通道线的分析
- **2.3.1 趋势线的定义与作用**
  - 趋势线：连接价格波动的高点或低点，显示价格趋势的方向。
  - 趋势线的作用：确认价格趋势，判断趋势的强弱。

- **2.3.2 通道线的定义与作用**
  - 通道线：由趋势线和其平行线组成，形成价格波动的通道。
  - 通道线的作用：判断价格波动范围，提供买卖信号。

#### 2.4 支撑线与阻力线的数学模型
- **支撑线与阻力线的计算公式**
  - 支撑线：$S = P_{min}$
  - 阻力线：$R = P_{max}$
  - 其中，$P_{min}$为支撑位价格，$P_{max}$为阻力位价格。

### 第4章: 技术指标的分析与应用

#### 4.1 相对强度指数（RSI）
- **RSI的定义与计算公式**
  - RSI = （平均上涨幅度 / 平均下跌幅度） × 100
  - 计算周期：通常取14天作为计算周期。

- **RSI的应用法则**
  - RSI超买：RSI > 70，考虑卖出。
  - RSI超卖：RSI < 30，考虑买入。
  - RSI背离：价格与RSI指标出现背离，预示趋势反转。

#### 4.2 移动平均线（MA）
- **MA的定义与计算公式**
  - MA = （一段时间内的平均价格）

- **MA的应用法则**
  - 价格站上MA：趋势向上，考虑买入。
  - 价格跌破MA：趋势向下，考虑卖出。

#### 4.3 威廉·欧奈尔的筛选标准
- **筛选标准1：相对强度排名**
  - 相对强度排名：股票价格走势相对于市场的排名。
- **筛选标准2：资金流量**
  - 资金流量：通过技术分析判断资金流入情况。
- **筛选标准3：机构持仓**
  - 机构持仓：机构投资者对股票的持仓情况。

#### 5.2 核心代码实现
- **计算相对强度指数（RSI）**
  ```python
  import pandas as pd
  import numpy as np

  def calculate_rsi(data, period=14):
      # 计算相对强度指数
      delta = data['Close'] - data['Close'].shift(1)
      up = delta.where(delta > 0, 0)
      down = delta.where(delta < 0, 0)
      rs = up.rolling(period).mean() / down.rolling(period).mean().abs()
      rsi = 100 - (100 - rs.rolling(period).mean())
      return rsi.round(2)
  ```

- **绘制趋势线**

  def plot_trend_line(data, window=10):
      # 计算趋势线

      plt.plot(data['Date'], data['Close'], label='Price')
      plt.plot(data['Date'], trend, label='Trend Line')
      plt.legend()
      plt.show()
