## 第4章: 博弈算法的实现与优化

### 4.1 Q-learning算法
- **算法介绍**：通过试错学习最优策略。
- **代码实现**：
```python
class QLearning:
    def __init__(self, states, actions):
        self.q_table = {state: {action: 0 for action in actions} for state in states}
    
    def choose_action(self, state, epsilon=0.1):
        if random.random() < epsilon:
            return random.choice(list(self.q_table[state].keys()))
        max_val = max(self.q_table[state].values())
        actions = [action for action, val in self.q_table[state].items() if val == max_val]
        return random.choice(actions)
    
    def update_q(self, state, action, reward, next_state, alpha=0.1):
        self.q_table[state][action] += alpha * (reward + max(self.q_table[next_state].values()) - self.q_table[state][action])
```
