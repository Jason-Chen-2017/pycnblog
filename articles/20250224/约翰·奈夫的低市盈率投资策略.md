### 第4章：低市盈率投资的数学模型与算法

#### 4.1 市盈率计算公式

- 市盈率的计算公式：
  $$市盈率 = \frac{股价}{每股收益}$$

- 每股收益的计算：
  $$每股收益 = \frac{净利润}{总股本}$$

#### 4.2 内在价值计算公式

- 内在价值的计算：
  $$内在价值 = \frac{净利润}{目标市盈率}$$

- 目标市盈率的选择：
  - 行业平均市盈率
  - 历史市盈率
  - 可比公司市盈率

#### 4.3 股票筛选算法

- 算法步骤：
  1. 收集目标行业的股票数据
  2. 计算每只股票的市盈率
  3. 筛选市盈率低于行业平均水平的股票
  4. 计算每只股票的内在价值
  5. 比较市盈率与内在价值，选择市盈率低于内在价值的股票

  import pandas as pd

  # 读取数据
  df = pd.read_csv('stock_data.csv')

  # 计算市盈率
  df['市盈率'] = df['股价'] / df['每股收益']

  # 筛选低市盈率股票
  low_pe_stocks = df[df['市盈率'] < df['市盈率'].mean()]

  # 计算内在价值
  target_pe = 15  # 假设目标市盈率为15

  # 选择市盈率低于内在价值的股票
