# 1. 背景介绍

## 1.1 问题背景与问题描述

投资者行为心理学研究投资者在金融市场中的决策过程和心理机制。传统金融理论假设投资者是理性的，但实际市场中，投资者的行为常常受到心理因素的影响，导致非理性决策。

## 1.2 投资者行为心理学的定义与外延

投资者行为心理学是心理学与金融学的交叉学科，研究投资者在投资过程中的心理活动及其对决策的影响。
