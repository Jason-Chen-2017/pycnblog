# 第二部分: 算法原理与数学模型

## 第3章: NLP算法原理

### 3.1 文本预处理
#### 3.1.1 分词与分句
使用分词工具（如jieba）将合同文本分割成词语或短语。
```python
import jieba
text = "金融合同条款比较系统"
words = jieba.lcut(text)
print(words)  # 输出: ['金融', '合同', '条款', '比较', '系统']
```

#### 3.1.2 停用词处理
移除常见但无意义的词语，如“的”、“是”等。
```python
stopwords = set(["的", "是", "在"])
filtered_words = [word for word in words if word not in stopwords]
```

#### 3.1.3 向量表示
将词语映射为向量，常用的方法包括TF-IDF和词嵌入。
```python
from sklearn.feature_extraction.text import TfidfVectorizer
vectorizer = TfidfVectorizer()
vectors = vectorizer.fit_transform(["金融合同条款比较系统"])
```

### 3.2 特征提取
#### 3.2.1 TF-IDF计算公式
$$ TF-IDF = \text{TF} \times \text{IDF} $$

其中，TF是词语在文档中的频率，IDF是词语的逆向文件频率。

#### 3.2.2 词嵌入（如Word2Vec）
通过深度学习模型生成词语的向量表示。
```python
from gensim.models import Word2Vec
model = Word2Vec([["金融", "合同", "条款", "比较", "系统"]], vector_size=100, window=2, min_count=1)
```

#### 3.2.3 文本相似度计算
使用余弦相似度计算文本的相似性。
$$ \text{余弦相似度} = \frac{\vec{A} \cdot \vec{B}}{\|\vec{A}\| \|\vec{B}\|} $$

### 3.3 分类算法
#### 3.3.1 基于相似度的分类
计算合同条款与已知分类的相似度，选择最相似的类别。
```python
def compute_similarity(text1, text2):
    return cosine_similarity(text1, text2)[0][0]
```

#### 3.3.2 机器学习模型（如SVM、随机森林）
使用训练好的模型进行分类。
```python
from sklearn.svm import SVC
model = SVC()
model.fit(X_train, y_train)
```

#### 3.3.3 深度学习模型（如BERT）
使用预训练的BERT模型进行文本理解。
```python
import torch
from transformers import BertTokenizer, BertModel
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

### 6.1 系统实现

```

#### 6.1.2 核心代码实现
```python
import jieba
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC

# 文本预处理
def preprocess(text):
    words = jieba.lcut(text)
    return ' '.join(words)

# 特征提取
vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform([preprocess("金融合同条款比较系统")])

# 分类器训练
model = SVC()
model.fit(X, ['合同比较'])

# 预测
new_text = preprocess("比较金融合同条款")
new_X = vectorizer.transform([new_text])
print(model.predict(new_X))  # 输出: ['合同比较']
```
