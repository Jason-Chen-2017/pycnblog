##### 1.1.1 AI Agent的定义

AI Agent，即人工智能代理，是指一种能够感知环境、制定计划并执行行动的智能实体。AI Agent的基本定义包括以下几个方面：

1. **感知环境**：AI Agent需要具备感知环境的能力，通过传感器获取环境中的各种信息。
2. **制定计划**：基于感知到的环境信息，AI Agent需要能够制定相应的计划，确定如何行动以实现目标。
3. **执行行动**：AI Agent根据制定的计划执行行动，并实时调整行动策略以应对环境变化。

AI Agent的核心特点是自主性和智能性，这使得它们能够在复杂环境中进行自主决策和行动，从而实现特定的任务。

AI Agent的基本组成主要包括以下几个方面：

def detect_creases(image):
    # 二值化处理
    _, thresh = cv2.threshold(image, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)

    contours, _ = cv2.findContours(thresh, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)
    # 绘制轮廓
    for contour in contours:
        if cv2.contourArea(contour) > 100:
            cv2.drawContours(image, [contour], -1, (0, 0, 255), 3)
    return image
