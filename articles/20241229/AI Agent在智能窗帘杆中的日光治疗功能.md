### 1.1 AI Agent概述

AI Agent是一种具有自主行动能力、能在环境中自主完成任务的计算实体。它可以根据环境变化，自主做出决策，采取行动。AI Agent可以分为反应式Agent、行为基Agent、模型基Agent和混合式Agent。在智能窗帘杆中，AI Agent主要承担着根据环境光照强度，调节窗帘开口大小的任务。

#### 1.1.1 AI Agent的定义与分类

AI Agent是一种具有自主行动能力、能在环境中自主完成任务的计算实体。它们根据感知到的环境信息，自主做出决策，并采取行动。AI Agent可以分为以下几种类型：

- **反应式Agent**：这种类型的Agent仅根据当前感知的信息做出反应，而不考虑历史信息。例如，一个简单的智能家居灯光系统，当感知到光线过暗时，自动开启灯光。

- **行为基Agent**：这种类型的Agent根据一系列预定义的行为规则来操作。例如，一个智能窗帘系统，根据设定的时间表或天气信息，自动调节窗帘的开合。

- **模型基Agent**：这种类型的Agent通过建立一个环境模型，根据模型来预测未来的情况，并做出决策。例如，自动驾驶汽车，通过传感器收集的数据，建立一个环境模型，并根据模型来决定行车路线。

- **混合式Agent**：这种类型的Agent结合了反应式、行为基和模型基Agent的特点，根据不同情况采取不同的策略。例如，一个智能健康监测系统，在正常情况下，根据预设的行为规则操作，但在检测到异常时，会根据实时收集的数据，做出反应。

# 定义光照强度阈值
LOW_LIGHT_THRESHOLD = 300

# 定义光照强度调节函数
def adjust_lighting(lighting_value):
    if lighting_value < LOW_LIGHT_THRESHOLD:
        return "关闭窗帘"
    elif lighting_value > HIGH_LIGHT_THRESHOLD:
        return "打开窗帘"
    else:
        return "保持当前状态"

# 训练模型
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu', input_shape=(1,)),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(1, activation='sigmoid')
])

model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

# 训练数据
train_data = [[300], [500], [800]]
train_labels = ["关闭窗帘", "保持当前状态", "打开窗帘"]

model.fit(train_data, train_labels, epochs=10)

# 使用模型进行预测
test_lighting_value = 400
prediction = model.predict([[test_lighting_value]])
print(adjust_lighting(prediction[0][0]))
