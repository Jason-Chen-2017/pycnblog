## 2. 时间序列数据分析基础

### 2.1 时间序列数据的定义与特性

时间序列数据（Time Series Data）是指按时间顺序排列的数据序列，反映了一段时间内某一变量或一组变量的变化情况。金融时间序列数据是金融市场中某一指标（如股票价格、利率、货币汇率等）随时间变化的记录。时间序列数据具有以下特性：

1. **非平稳性**：金融时间序列数据通常是非平稳的，即其统计特性（如均值、方差等）随时间变化而变化。这与金融市场的不确定性密切相关。
2. **趋势性**：金融时间序列数据往往呈现出一定的趋势性，如上涨或下跌。趋势性反映了市场的基本走势。
3. **季节性**：金融时间序列数据可能存在季节性波动，如股票价格在年末、季末等特定时间段内表现出规律性的变化。
4. **自相关性**：金融时间序列数据中的各个数据点之间往往存在一定的相关性，即当前时刻的变量值与过去若干时刻的变量值有关。

### 2.2 常见的时间序列模型

金融时间序列数据的建模与分析通常依赖于以下几种常见的统计模型：

#### 2.2.1 自回归模型（AR）

自回归模型（Autoregressive Model，AR）假设当前时刻的变量值只与过去若干时刻的变量值有关。自回归模型的数学表达式如下：

$$Y_t = c + \sum_{i=1}^{p} \phi_i Y_{t-i} + \varepsilon_t$$

其中，$Y_t$ 表示时间序列在第 $t$ 时刻的值，$c$ 为常数项，$\phi_i$ 为自回归系数，$p$ 为自回归项数，$\varepsilon_t$ 为随机误差项。

#### 2.2.2 移动平均模型（MA）

移动平均模型（Moving Average Model，MA）假设当前时刻的变量值只与过去若干时刻的平均值有关。移动平均模型的数学表达式如下：

$$Y_t = \mu + \sum_{i=1}^{q} \theta_i \varepsilon_{t-i}$$

其中，$\mu$ 为常数项，$\theta_i$ 为移动平均系数，$q$ 为移动平均项数，$\varepsilon_t$ 为随机误差项。

#### 2.2.3 自回归移动平均模型（ARMA）

自回归移动平均模型（Autoregressive Moving Average Model，ARMA）结合了AR和MA的特点，适用于非平稳时间序列数据的建模。ARMA模型的数学表达式如下：

$$Y_t = c + \sum_{i=1}^{p} \phi_i Y_{t-i} + \sum_{j=1}^{q} \theta_j \varepsilon_{t-j} + \varepsilon_t$$

其中，$c$ 为常数项，$\phi_i$ 为自回归系数，$\theta_j$ 为移动平均系数，$p$ 和 $q$ 分别为自回归和移动平均项数，$\varepsilon_t$ 为随机误差项。

#### 2.2.4 自回归积分移动平均模型（ARIMA）

自回归积分移动平均模型（Autoregressive Integrated Moving Average Model，ARIMA）在ARMA模型的基础上加入差分操作，适用于具有趋势性和季节性特征的时间序列数据。ARIMA模型的数学表达式如下：

$$Y_t = c + \sum_{i=1}^{p} \phi_i (D^d Y)_{t-i} + \sum_{j=1}^{q} \theta_j \varepsilon_{t-j} + \varepsilon_t$$

其中，$c$ 为常数项，$\phi_i$ 为自回归系数，$\theta_j$ 为移动平均系数，$p$ 和 $q$ 分别为自回归和移动平均项数，$d$ 为差分次数，$\varepsilon_t$ 为随机误差项。

### 2.4 时间序列数据可视化

因果关系网络由节点（Node）和边（Edge）组成。节点表示变量，边表示变量之间的因果关系。每个节点都有一个唯一的标识符，边则用箭头表示，箭头指向被影响的变量。

#### 构建方法

因果关系网络的构建通常分为以下几个步骤：

1. **变量选择**：根据研究目的，选择适当的金融时间序列变量作为节点。
