```python
import tensorflow as tf
from tensorflow.keras.layers import Dense, Flatten, Conv2D
from tensorflow.keras.models import Model

# 定义输入层
input_layer = tf.keras.layers.Input(shape=(28, 28, 1))

# 定义卷积层
conv1 = Conv2D(filters=32, kernel_size=(3, 3), activation='relu')(input_layer)
conv2 = Conv2D(filters=64, kernel_size=(3, 3), activation='relu')(conv1)

# 定义全连接层
flatten = Flatten()(conv2)
dense1 = Dense(units=128, activation='relu')(flatten)
output = Dense(units=10, activation='softmax')(dense1)

# 定义模型
model = Model(inputs=input_layer, outputs=output)

# 编译模型
model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])

# 模型训练
model.fit(x_train, y_train, batch_size=128, epochs=10, validation_data=(x_val, y_val))

# 模型评估
model.evaluate(x_test, y_test)
```

以上代码实现了一个简单的卷积神经网络模型，用于手写数字识别任务。首先，我们定义了输入层，输入数据的形状为28x28x1。然后，我们定义了两个卷积层，分别使用了ReLU激活函数。接下来，我们将卷积层输出的特征图进行全连接，并添加了一个输出层，用于分类。最后，我们编译模型，并使用训练数据对模型进行训练。训练完成后，我们使用测试数据对模型进行评估。
