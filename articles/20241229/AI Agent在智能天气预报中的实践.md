### Predictive Models and Mathematical Formulations

#### Linear Regression

**Principle**: Linear regression is a simple yet powerful algorithm that models the relationship between a single input variable (X) and a continuous output variable (Y) using a straight line.

**Mathematical Formulation**:
$$
Y = \beta_0 + \beta_1X + \epsilon
$$
where $\beta_0$ is the intercept, $\beta_1$ is the slope, and $\epsilon$ is the error term.

**Example**:
Consider a simple linear regression model to predict the temperature (Y) based on the wind speed (X):
$$
\hat{Y} = \beta_0 + \beta_1X
$$

#### Multiple Linear Regression

**Principle**: Multiple linear regression extends the concept of linear regression to include multiple input variables, capturing more complex relationships between predictors and the target variable.

**Mathematical Formulation**:
$$
Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + ... + \beta_nX_n + \epsilon
$$
where $\beta_0$ is the intercept, $\beta_1, \beta_2, ..., \beta_n$ are the slopes for each input variable, and $\epsilon$ is the error term.

**Example**:
Predicting temperature based on multiple input variables (wind speed, humidity, and pressure):
$$
\hat{Y} = \beta_0 + \beta_1X_1 + \beta_2X_2 + \beta_3X_3
$$

#### Polynomial Regression

**Principle**: Polynomial regression uses polynomial functions to model the relationship between input and output variables, allowing for more flexible and complex models.

**Mathematical Formulation**:
$$
Y = \beta_0 + \beta_1X + \beta_2X^2 + ... + \beta_nX^n + \epsilon
$$
where $\beta_0, \beta_1, \beta_2, ..., \beta_n$ are the coefficients of the polynomial terms and $\epsilon$ is the error term.

**Example**:
Predicting temperature using a quadratic polynomial:
$$
\hat{Y} = \beta_0 + \beta_1X + \beta_2X^2
$$

#### Neural Networks

**Principle**: Neural networks are composed of multiple layers of interconnected nodes (neurons) that learn to recognize patterns and make predictions through a process of training and learning.

**Mathematical Formulation**:
$$
\hat{Y} = \sum_{i=1}^{n} w_i \cdot \text{sigmoid}(z_i)
$$
where $w_i$ are the weights, $z_i$ is the weighted sum of inputs, and $\text{sigmoid}$ is the activation function.

**Example**:
A simple neural network for temperature prediction with one input layer, one hidden layer, and one output layer:
$$
z = X \cdot w_1 \\
\hat{Y} = \text{sigmoid}(z)
$$

### Python Code Examples

#### Linear Regression Example

Here's a simple Python code example using scikit-learn to implement a linear regression model:

```python
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

# Load dataset
X, Y = load_data()

# Split dataset into training and testing sets
X_train, X_test, Y_train, Y_test = train_test_split(X, Y, test_size=0.2, random_state=42)

# Create a linear regression model
model = LinearRegression()

# Train the model
model.fit(X_train, Y_train)

# Make predictions
Y_pred = model.predict(X_test)

# Evaluate the model
mse = mean_squared_error(Y_test, Y_pred)
print("Mean Squared Error:", mse)
```
