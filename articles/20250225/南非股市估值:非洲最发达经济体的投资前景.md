- **南非股市的起源与演变**：南非股市的历史可以追溯到 19世纪末，经过多次合并和重组，形成了今天的JSE。  
- **历史上的重大事件对股市的影响**：例如，1994年南非种族隔离政策的结束对股市的影响，2008年全球金融危机对南非股市的冲击等。

- **经济政策对股市的影响**：政府的经济政策，如矿业政策、货币政策和财政政策，对股市有重要影响。

## 第二部分: 南非股市估值方法与模型  

### 第3章: 基本的估值方法与工具  

#### 3.1 市盈率与市净率分析  
市盈率和市净率是常用的估值指标，适用于不同行业的比较和分析。  
- **市盈率的计算与应用**：市盈率 = 股价 / 每股收益。  
- **市净率的计算与应用**：市净率 = 股价 / 每股净资产。  
- **市盈率与市净率的比较**：市盈率适用于盈利稳定的行业，市净率适用于资产密集型行业。

#### 3.2 股息率与股息收益率  
股息率和股息收益率是衡量股票投资回报的重要指标。  
- **股息率的计算方法**：股息率 = 每股股息 / 股价。  
- **股息收益率的分析**：股息收益率 = 每股股息 / 投资成本。  
- **股息率与投资决策的关系**：高股息率的股票通常具有较高的投资吸引力，但需结合行业和公司的财务状况综合分析。

#### 3.3 风险调整后的收益分析  
风险调整后的收益分析是衡量股票投资回报的重要方法。  
- **风险调整后的收益模型**：通过计算股票的超额收益与市场风险的关系，调整收益以反映风险因素。  
- **风险调整后的收益在估值中的应用**：通过比较股票的超额收益与市场风险，判断股票的估值是否合理。

### 第4章: 现金流贴现模型（DCF）的应用  

#### 4.1 DCF模型的基本原理  
现金流贴现模型（DCF）是一种常用的股票估值方法，通过预测未来现金流并将其贴现为现值。  
- **自由现金流的定义与计算**：自由现金流 = 经营活动现金流 - 资本支出。  
- **折现率的确定与应用**：折现率通常采用加权平均资本成本（WACC）或无风险利率加风险溢价。  
- **终值的计算与调整**：终值是将未来现金流按一定增长率（永续增长率）贴现到未来某一时点的现值。

#### 4.2 DCF模型在南非股市中的应用  
- **南非主要行业的DCF模型构建**：以金融行业为例，构建DCF模型，计算其内在价值。  
- **DCF模型在个股估值中的应用**：通过DCF模型计算个股的内在价值，与市场价格进行比较，判断是否低估或高估。  
- **DCF模型的局限性与改进**：DCF模型的假设可能存在偏差，需要结合实际情况进行调整。
