## 第1章：背景介绍

### 1.1 长期持股的定义与特点
长期持股是指投资者长期持有优质股票，避免频繁交易，以获得稳定的复利收益。其核心特点包括：
- 长期性：关注企业的长期价值，而非短期波动。
- 选择性：精选优质企业，避免低质企业。
- 耐心与信心：相信优质企业能持续创造价值。

### 1.2 创新文化的定义与特点
创新文化是指企业在创新方面的价值观、行为准则和制度安排。其特点包括：
- 开放性：鼓励员工提出新想法。
- 风险承担：允许失败，从中学习。
- 持续性：创新是企业的长期战略。

### 1.3 长期持股与创新文化的关联性
长期持股要求企业具备稳定增长的潜力，而创新文化是企业持续增长的核心动力。两者的关系体现在：
- 创新文化促进企业长期增长，符合长期持股的要求。
- 长期持股为创新文化提供了稳定的资金和时间支持。

### 5.2 核心代码实现

import pandas as pd
import numpy as np

def calculate_innovation_index(research_ratio, employee_incentive):
    return (research_ratio + employee_incentive) / 2

# 示例数据
data = {
    '公司': ['公司A', '公司B'],
    '研发投入占比': [0.05, 0.08],
    '员工激励强度': [0.1, 0.15]
}

df = pd.DataFrame(data)
df['创新文化指数'] = df.apply(lambda x: calculate_innovation_index(x['研发投入占比'], x['员工激励强度']), axis=1)
print(df)
