### 1.2 问题描述

- **可持续城市垂直农业的关键特征**：包括能源消耗、水资源利用效率、农产品产量等，体现了农业的可持续性。

## 第2章: 核心概念与联系  

### 2.1 核心概念的原理  
- **全球股市估值的计算方法**：通过市盈率（P/E）公式，$P/E = \frac{\text{股价}}{\text{每股收益}}$，评估企业的投资价值。  
- **可持续城市垂直农业的技术特点**：采用LED照明、垂直种植架和智能温控系统，显著提高了资源利用效率。

| 影响因素 | 经济政策、企业盈利 | 技术创新、资源利用效率 |

### 3.3 算法实现代码  
```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据加载与预处理
data = pd.read_csv('vertical_farming.csv')
X = data[['产量', '能源消耗', '水资源利用']]
y = data['股价']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测与评估
predictions = model.predict(X)
print('预测结果:', predictions)
print('回归系数:', model.coef_)
```
