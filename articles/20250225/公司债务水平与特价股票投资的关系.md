## 第1章: 公司债务与特价股票的基本概念

### 1.1 公司债务的定义与分类

#### 1.1.1 公司债务的定义
公司债务是指公司通过借款或其他方式形成的负债，是公司资本结构的重要组成部分。债务融资具有杠杆效应，能够放大股东收益，但也增加了财务风险。

#### 1.1.2 公司债务的主要分类
1. **短期债务**：如应付账款、短期贷款等，通常用于满足公司短期资金需求。
2. **长期债务**：如长期债券、银行贷款等，用于支持公司长期项目或资本支出。
3. **无息债务**：如应付账款、应付票据等，不产生利息支出。
4. **有息债务**：如银行贷款、债券等，需要定期支付利息。

#### 1.1.3 公司债务的特征与优势
1. **杠杆效应**：债务融资可以放大股东收益，但同时也增加了财务风险。
2. **资本成本低**：通常债务融资的成本低于股权融资。
3. **税务优势**：债务利息可以在税前扣除，降低税后成本。

### 1.2 特价股票的定义与特点

#### 1.2.1 特价股票的定义
特价股票是指价格低于其内在价值，具有较大上涨潜力的股票。通常，这类股票可能被市场低估，或公司处于困境中，但具有扭亏为盈的潜力。

#### 1.2.2 特价股票的主要类型
1. **困境股**：公司财务状况不佳，但具有重组或复苏的潜力。
2. **价值股**：市场价格低于其内在价值，通常为低估值的蓝筹股。
3. **成长股**：公司具有较高的成长性，但市场价格尚未反映其未来增长潜力。

#### 1.2.3 特价股票的投资价值与风险
1. **投资价值**：价格低廉，上涨空间大，具有较高的潜在回报。
2. **投资风险**：公司基本面可能存在问题，股价波动较大。

### 1.3 公司债务与特价股票的关系

#### 1.3.1 公司债务对股价的影响
公司债务水平影响公司的财务健康状况，进而影响股价。高债务可能导致公司财务风险增加，股价波动加剧。

#### 1.3.2 特价股票与公司债务水平的关联性
1. **高债务公司**：可能更容易成为特价股票，因为市场可能低估其价值。
2. **低债务公司**：通常财务更加稳健，股价波动较小，不太可能成为特价股票。

#### 1.3.3 债务水平对投资决策的影响
1. **高债务公司**：适合风险承受能力强的投资者。
2. **低债务公司**：适合风险厌恶型投资者。

## 第2章: 公司债务水平与股票投资的理论基础

### 2.1 资本结构理论

#### 2.1.1 资本结构的定义与组成
资本结构是指公司资本中股权和债务的比例。合理的资本结构能够降低资本成本，提高公司价值。

#### 2.1.2 资本结构与公司价值的关系
资本结构影响公司价值，杠杆原理可能导致公司价值最大化或最小化。

#### 2.1.3 Modigliani-Miller定理的简介
Modigliani-Miller定理指出，在无摩擦市场中，公司价值与资本结构无关。但在现实市场中，债务融资成本低于股权融资成本，因此资本结构会影响公司价值。

### 2.2 资产定价模型

#### 2.2.1 CAPM模型的原理与应用
CAPM模型用于估计资产的预期收益，考虑了系统性风险和非系统性风险。

$$ E(R_i) = R_f + \beta_i (R_m - R_f) $$

其中：
- \( E(R_i) \)：资产的预期收益
- \( R_f \)：无风险利率
- \( \beta_i \)：资产的beta系数
- \( R_m \)：市场预期收益
- \( R_f \)：无风险利率

#### 2.2.2 WACC（加权平均资本成本）的计算公式
$$ WACC = \left( \frac{D}{V} \right) \times cost\_debt \times (1 - t) + \left( \frac{E}{V} \right) \times cost\_equity $$

其中：
- \( D \)：债务总额
- \( E \)：股权总额
- \( V \)：公司总价值
- \( cost\_debt \)：债务成本
- \( cost\_equity \)：股权成本
- \( t \)：税率

#### 2.2.3 债务与股权在资产定价中的作用
债务成本和股权成本共同影响公司的加权平均资本成本，进而影响资产定价。

### 2.3 债务与股票投资的理论联系

#### 2.3.1 债务对公司价值的影响
高债务可能导致公司财务风险增加，但可能通过杠杆效应提高股东收益。

#### 2.3.2 债务对股票价格波动的影响
高债务公司股价波动较大，因为市场对债务风险更加敏感。

#### 2.3.3 债务与股票投资风险的平衡
投资者需要在债务风险和收益之间找到平衡点，制定合适的投资策略。

```python
import pandas as pd
import numpy as np

# 计算WACC
def calculate_wacc(df):
    debt = df['debt'].sum()
    equity = df['equity'].sum()
    value = debt + equity
    cost_debt = df['cost_debt'].mean()
    cost_equity = df['cost_equity'].mean()
    tax_rate = df['tax_rate'].mean()
    wacc = (debt / value) * cost_debt * (1 - tax_rate) + (equity / value) * cost_equity
    return wacc

wacc = calculate_wacc(df)
print(f"WACC: {wacc}")
```
