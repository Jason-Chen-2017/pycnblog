# 第一章: 价值投资的背景与核心理念

## 1.1 价值投资的定义与背景

### 1.1.1 价值投资的定义  
价值投资是一种基于对企业内在价值分析的投资策略，旨在通过购买价格低于内在价值的股票，实现长期收益。其核心在于寻找市场低估的优质企业。

### 1.1.2 价值投资的核心理念  
1. **安全边际**：买入价格远低于内在价值的股票，以降低投资风险。  
2. **长期视角**：关注企业的长期盈利能力，而非短期市场波动。  
3. **逆向思维**：在市场恐慌时寻找机会，避免追涨杀跌。

### 1.1.3 价值投资与其他投资策略的区别  
- **技术分析**：依赖价格和成交量的短期波动，而非企业基本面。  
- **趋势投资**：基于市场趋势进行投资，风险较高且波动性大。  
- **价值投资**：注重企业的内在价值，强调长期稳健的回报。

## 1.2 价值投资的历史演变

### 1.2.1 价值投资的起源与发展  
价值投资起源于20世纪初，由本杰明·格雷厄姆和戴维·多德提出，强调购买低于清算价值的股票。  

### 1.2.2 格林布拉特价值投资方法的形成  
乔尔·格林布拉特在格雷厄姆的基础上，结合现代金融理论，提出了一套更系统化、量化的价值投资方法。

## 1.3 价值投资的核心要素

### 1.3.1 企业基本面分析  
1. **财务指标**：市盈率（P/E）、市净率（P/B）、股息率等。  
2. **盈利能力**：ROE（净资产收益率）、净利润增长率等。  

### 1.3.2 安全边际的概念  
安全边际 = 内在价值 - 市场价格。安全边际越大，投资风险越小。

### 1.3.3 市场情绪与估值的关系  
市场恐慌时，股票价格可能被低估，此时是买入的好时机。

# 第二章: 格林布拉特价值投资方法的核心框架

## 2.1 格林布拉特投资模型的构成

### 2.1.1 核心要素的识别与权重分配  
格林布拉特模型将企业的财务指标、行业地位、管理团队等因素纳入考量。

### 2.1.2 模型的数学表达式  
内在价值的计算公式如下：

$$ V = \frac{E}{P} + \frac{R}{C} $$  

其中：  
- \( V \) 为内在价值  
- \( E \) 为企业的盈利预期  
- \( P \) 为市盈率  
- \( R \) 为股息率  
- \( C \) 为市净率  

---

## 2.2 格林布拉特模型的优缺点分析

### 2.2.1 模型的优点  
1. **量化分析**：通过数学模型量化企业的内在价值。  
2. **易于操作**：适合普通投资者进行分析。  

### 2.2.2 模型的局限性  
1. **过于简化**：忽略了宏观经济和行业风险。  
2. **数据依赖**：依赖于准确的财务数据，数据误差可能影响结果。  

---

## 2.3 格林布拉特模型与其他价值投资模型的对比

### 2.3.1 市盈率模型  
基于市盈率（P/E）评估企业的内在价值，简单但不够全面。  

### 2.3.2 现金流折现模型  
通过现金流折现计算企业的未来现金流，较为复杂但准确。  

### 2.3.3 市净率模型  
基于市净率（P/B）评估企业价值，适用于资产密集型行业。  

---

## 2.4 本章小结  
格林布拉特模型结合了量化分析和基本面研究，为投资者提供了一种系统化、可操作的价值投资方法。

import pandas as pd
import numpy as np

# 假设df为包含股票数据的DataFrame
def calculate_intrinsic_value(df):
    df['内在价值'] = df['净利润'] / df['市盈率']
    df['安全边际'] = df['内在价值'] - df['股价']
    return df

# 示例数据

    '净利润': [10, 15, 8],
    '市盈率': [15, 10, 12]
}

import pandas as pd
import numpy as np

def main():
    # 示例数据
    data = {
        '公司名称': ['A', 'B', 'C'],
        '股价': [50, 60, 40],

        print(f"{row['公司名称']} | {row['股价']} | {row['净利润']} | {row['市盈率']} | {row['内在价值']:.2f} | {row['安全边际']:.2f}")

    main()
