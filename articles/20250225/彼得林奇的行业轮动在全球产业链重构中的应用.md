### 1.1 行业轮动的定义与背景

行业轮动的概念源于20世纪70年代的美国经济波动，彼得林奇在这一背景下提出了行业轮动的投资策略，强调行业间的轮动机会。

#### 1.1.3 行业轮动的经济意义
行业轮动帮助投资者在经济周期变化中捕捉行业增长潜力，分散投资风险，优化资产配置。

### 1.2 彼得林奇与行业轮动

#### 1.2.1 彼得林奇的投资理念
彼得林奇强调长期投资和价值发现，认为行业轮动是捕捉市场机会的有效工具。

## 第6章: 行业轮动的算法实现

### 6.1 行业轮动算法的数学模型

#### 6.1.1 行业轮动指数的计算
$$ R_i = \sum_{j=1}^{n} (w_j \times P_j) $$
其中，$R_i$为行业轮动指数，$w_j$为权重，$P_j$为行业表现指标。

#### 6.1.2 轮动时机的判断
$$ S_i = \frac{R_i - \mu}{\sigma} $$
其中，$S_i$为行业轮动强度，$\mu$为均值，$\sigma$为标准差。

### 6.2 Python实现代码示例

```python
import pandas as pd
import numpy as np

# 示例数据：行业表现
data = {
    '行业A': [1.2, 1.3, 1.1, 1.4],
    '行业B': [0.8, 0.9, 1.0, 1.1],
    '行业C': [1.5, 1.6, 1.4, 1.7]
}
df = pd.DataFrame(data)

# 计算行业轮动指数
weights = [0.4, 0.3, 0.3]
industry_rotation = df.dot(weights)

# 判断轮动时机
def get_rotation_strength(r):
    mu = np.mean(r)
    std = np.std(r)
    return (r - mu) / std

rotation_strength = get_rotation_strength(industry_rotation)
```
