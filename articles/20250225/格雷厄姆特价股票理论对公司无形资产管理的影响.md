### 第1章: 格雷厄姆特价股票理论概述

#### 1.1 格雷厄姆投资理论的核心观点
- **价值投资的基本原则**：格雷厄姆主张以低于内在价值的价格购买股票，长期持有，避免短期波动。
- **安全边际的概念**：通过购买价格低于内在价值的股票，降低投资风险。
- **历史背景**：20世纪初，市场波动剧烈，格雷厄姆提出价值投资以应对不确定性。

#### 1.2 格雷厄姆理论与无形资产的关系
- **无形资产的重要性**：品牌、专利等无形资产对企业的长期价值影响显著。
- **理论的适用性**：格雷厄姆的安全边际概念可应用于无形资产的风险评估。

### 第2章: 公司无形资产的概念与分类

#### 2.1 无形资产的定义与特征
- **定义**：无法实物化，但能为企业带来长期经济利益的资产。
- **分类**：包括商誉、专利、商标、特许经营权等。
- **价值评估**：无形资产的价值受市场环境和企业战略的影响。

#### 2.2 格雷厄姆理论对无形资产管理的启示
- **价值评估**：通过历史成本与市场价值对比，寻找低估的无形资产。
- **风险控制**：利用安全边际，降低无形资产贬值风险。

### 第3章: 格雷厄姆理论的核心模型与数学公式

#### 3.1 安全边际模型
- **公式**：安全边际 = 内在价值 - 市场价格。
- **应用**：通过计算安全边际，选择具有较大安全边际的股票或无形资产。

#### 3.2 无形资产价值评估模型
- **公式**：无形资产价值 = 未来现金流的现值。
- **方法**：使用折现率进行评估，考虑市场风险和企业特有风险。

import pandas as pd

def calculate_margin(value, price):
    return value - price

# 示例数据
df = pd.DataFrame({
    '内在价值': [100, 200, 150],
    '市场价格': [80, 180, 130]
})

# 计算安全边际
df['安全边际'] = df.apply(lambda x: calculate_margin(x['内在价值'], x['市场价格']), axis=1)
print(df)
```
