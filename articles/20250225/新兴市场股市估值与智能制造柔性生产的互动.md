# 第2章: 股市估值的核心理论与方法

## 2.1 股市估值的基本原理

### 2.1.1 股票价值的决定因素
- 财务状况：收入、利润、资产负债。
- 行业地位：市场占有率、竞争能力。
- 宏观经济：GDP、利率、通货膨胀。

### 2.1.2 股票价格与内在价值的关系
- 内在价值：企业的实际价值。
- 市场价格：供需关系决定。
- 价格波动：受市场情绪影响。

### 2.1.3 股票市场的波动性分析
- 市场波动：短期价格偏离内在价值。
- 影响因素：新闻、政策、经济数据。

## 2.2 主要估值方法

### 2.2.1 市盈率法
- 公式：市盈率 = 股价 / 每股收益。
- 适用场景：盈利稳定的公司。

### 2.2.2 市净率法
- 公式：市净率 = 股价 / 每股净资产。
- 适用场景：资产密集型行业。

### 2.2.3 现金流折现法
- 公式：企业价值 = 未来现金流的现值。
- 适用场景：高成长性企业。

### 2.2.4 市场比较法
- 方法：对比同类公司，寻找估值差异。

## 2.3 新兴市场的特殊性

### 2.3.1 新兴市场的估值挑战
- 数据不全：新兴市场公司信息披露不完善。
- 市场波动大：受政策和经济环境影响大。

### 2.3.2 新兴市场与发达市场的差异
- 发达市场：数据透明，估值模型成熟。
- 新兴市场：数据不透明，需调整模型。

### 2.3.3 新兴市场中的行业估值差异
- 不同行业：估值方法和标准不同。

## 5.1 股市估值模型

### 5.1.1 CAPM模型
- 公式：$R_i = R_f + \beta_i (R_m - R_f)$。
- 解释：计算预期回报率，评估股票价值。

### 5.1.2 现金流折现模型
- 公式：$DCF = \sum_{t=1}^n \frac{CF_t}{(1+r)^t}$。
- 解释：估算企业未来现金流的现值，评估企业价值。
