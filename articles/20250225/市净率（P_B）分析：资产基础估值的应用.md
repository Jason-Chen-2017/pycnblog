## 第2章 背景介绍

### 2.1 核心概念术语说明

- **市净率（P/B）**：股价与每股净资产的比率，计算公式为：
  $$P/B = \frac{\text{股价}}{\text{每股净资产}}$$
- **资产基础估值**：基于资产负债表中的资产价值进行的估值方法。
- **资产质量**：资产的流动性、变现能力及账面价值与市场价值的差异。

### 2.2 问题描述

市净率分析的核心在于理解资产基础估值的合理性，但许多投资者忽视了资产质量对估值的影响，导致误判。本文将探讨如何通过资产质量分析修正市净率估值。

### 2.3 问题解决

通过分析资产质量对市净率的影响，提出一种基于资产质量调整的市净率分析方法，帮助投资者更准确地评估企业价值。

### 2.4 边界与外延

市净率分析适用于资产密集型行业，如银行、地产等，但不适用于资产较轻的行业，如科技公司。本文主要聚焦于资产密集型行业的市净率分析。

### 2.5 概念结构与核心要素组成

- **核心要素**：
  - 市场价格（P）
  - 每股净资产（B）
  - 资产质量（包括流动性、变现能力等）

## 第3章 资产基础估值的理论基础

### 3.1 资产基础估值的核心思想

资产基础估值基于资产负债表中的资产价值，认为企业价值应反映其资产的账面价值。市净率分析通过比较市场价格与资产价值，评估企业是否被高估或低估。

### 3.2 资产基础估值的公式推导

市净率公式：
$$P/B = \frac{P}{B}$$

其中：
- $P$：股票市场价格
- $B$：每股净资产，计算公式为：
$$B = \frac{\text{净资产}}{\text{总股本}}$$

### 3.3 资产基础估值与市场价值的关系

资产基础估值与市场价值的关系可以用以下mermaid图表示：
```mermaid

    A[资产基础估值] --> B[市场价格]
    B --> C[企业价值]
```

## 第4章 市净率分析的数学模型

### 4.1 市净率的数学模型

市净率计算公式：
$$P/B = \frac{P}{B}$$

### 4.2 市净率的资产质量调整模型

考虑资产质量对市净率的影响，提出以下调整模型：
$$\text{调整后市净率} = \frac{P}{B \times Q}$$

其中：
- $Q$：资产质量调整因子（0 < Q ≤ 1）
