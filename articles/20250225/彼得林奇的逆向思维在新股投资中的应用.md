## 第一部分：逆向思维概述

### 第1章：逆向思维的基本概念

#### 1.1 逆向思维的定义与特点
- **逆向思维的定义**：逆向思维是指在投资中寻找市场忽视但具有潜在价值的机会。  
- **特点**：
  - 寻找市场低估的资产
  - 抵制市场情绪的干扰
  - 长期投资策略
- **与传统投资思维的区别**：
  - 传统投资随市场波动，逆向投资逆市场而行
  - 传统投资追求短期收益，逆向投资注重长期价值

#### 1.2 彼得·林奇的逆向思维理论
- **彼得·林奇简介**：著名基金经理，投资业绩卓越，强调长期投资和逆向思维。
- **核心思想**：
  - 投资于被市场忽视但基本面良好的公司
  - 在市场恐慌时寻找机会
- **理论体系**：
  - 价值投资：寻找低于内在价值的股票
  - 避免短期波动，关注长期趋势

#### 1.3 逆向思维在投资中的重要性
- **发现低估机会**：逆向思维帮助投资者识别市场未充分定价的股票。
- **对抗羊群效应**：避免随波逐流，独立思考。
- **风险管理**：通过逆向思维分散风险，降低投资组合的波动性。

## 第三部分：数学模型与指标分析

### 第5章：数学模型与投资指标

#### 5.1 常用投资指标
- **市盈率（P/E）**：
  - 定义：股价除以每股收益。
  - 公式：$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$
  - 应用：寻找低于行业平均的股票。
- **市净率（P/B）**：
  - 定义：股价除以每股净资产。
  - 公式：$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$
  - 应用：识别低估的金融和制造企业。
- **市销率（P/S）**：
  - 定义：股价除以每股收入。
  - 公式：$$ P/S = \frac{\text{股价}}{\text{每股收入}} $$
  - 应用：评估成长型企业的估值。

#### 5.2 数学模型的应用
- **价值评估模型**：使用DCF模型评估企业内在价值。
- **风险评估模型**：计算波动率，评估投资风险。

```python
# 示例：计算超卖指标
def calculate_rsi(stock_data, period=14):
    # 计算RSI
    delta = stock_data['收盘价'].diff()
    up = delta.where(delta > 0, 0)
    down = delta.where(delta < 0, 0)
    sma_up = up.rolling(period).mean()
    sma_down = down.rolling(period).mean()
    rsi = 100 - (100 - (sma_up / sma_down))
    return rsi
```
