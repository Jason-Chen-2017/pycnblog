# 第1章: 动量策略概述

## 1.1 动量策略的定义与背景

### 1.1.1 动量效应的定义  
动量效应是指资产价格的变动会延续其趋势，即“强者恒强，弱者恒弱”。这种现象在金融市场中广泛存在，尤其是在股票和期货市场中。

### 1.1.2 动量效应的背景与发现  
动量效应最早由Fama和French提出，后经大量实证研究证实其存在。动量策略通过捕捉价格趋势，利用市场的惯性特征，为投资者提供超额收益。

### 1.1.3 动量效应在量化投资中的应用  
量化投资通过算法和模型系统化地捕捉动量效应，避免人为情绪干扰，提高投资效率。

## 1.2 动量策略的核心概念

### 1.2.1 动量因子的定义  
动量因子衡量资产价格的动量效应，通常通过过去一段时间的收益增长率计算。

### 1.2.2 动量因子的特征  
- 价格趋势的延续性：动量因子高的资产未来可能继续上涨。
- 时间窗口的选择：通常选择3个月到1年的时间窗口。

### 1.2.3 动量策略的分类  
- 单一动量策略：仅基于动量因子进行投资。
- 多因子动量策略：结合其他因子（如价值、波动率）进行综合评估。

## 1.3 动量策略的有效性

### 1.3.1 动量效应的实证研究  
大量研究表明，动量策略在不同市场中均能产生超额收益。

### 1.3.2 动量策略的优势与劣势  
优势：系统化、可量化、避免情绪干扰；劣势：动量反转风险、交易成本高。

### 1.3.3 动量策略的适用场景  
适用于趋势明显的市场环境，如股票、期货等。

## 1.4 本章小结  
本章介绍了动量策略的基本概念和核心理论，为后续分析奠定了基础。

import numpy as np

def compute_momentum_factor(prices, window=3):
