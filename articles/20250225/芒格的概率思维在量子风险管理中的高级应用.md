#### 1.1 芒格的"概率思维"概述

##### 1.1.1 概率思维的定义与核心要素

概率思维是一种基于概率论的思维方式，通过分析事件发生的可能性来辅助决策。其核心要素包括：

1. **概率分布**：描述事件发生的可能性。
2. **条件概率**：在已知某些条件下，事件发生的概率。
3. **贝叶斯定理**：用于更新基于新证据的概率。
4. **蒙特卡洛模拟**：通过随机采样方法模拟系统行为。

##### 1.1.2 芒格概率思维的特点与优势

芒格的概率思维以实用性著称，强调通过简化和近似来解决复杂问题。其特点包括：

1. **简化模型**：避免复杂的数学推导，专注于关键因素。
2. **经验驱动**：结合实际经验，修正概率估计。
3. **保守估计**：倾向于低估有利概率，避免乐观偏差。

##### 1.1.3 概率思维在决策中的重要性

概率思维在决策中起着关键作用，尤其是在不确定性和复杂性较高的环境中。它帮助决策者量化风险，评估可能的后果，并制定应对策略。

from qiskit import QuantumCircuit, execute, Aer

def quantum_risk_assessment(n=1):
    circuit = QuantumCircuit(n)
    circuit.h(range(n))
    circuit.measure_all()
    backend = Aer.get_backend('qasm_simulator')
    job = execute(circuit, backend, shots=1000)
    result = job.result()
    probabilities = result.get_counts().values()
    return probabilities

quantum_risk_assessment()
