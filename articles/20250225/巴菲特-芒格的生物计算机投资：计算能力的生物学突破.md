# 第4章 生物计算机的算法原理

## 4.1 遗传算法在投资中的应用
### 4.1.1 遗传算法流程
1. 初始化：随机生成初始种群。
2. 适应度评估：计算每个个体的适应度（如收益与风险比）。
3. 选择：根据适应度值选择优秀个体。
4. 交叉与变异：生成新个体。
5. 迭代：重复评估、选择、交叉和变异，直到满足终止条件。

### 4.1.2 代码实现
```python
import numpy as np

def fitness(individual):
    # 计算收益与风险比
    return np.mean(individual) / np.std(individual)

def crossover(parent1, parent2):
    # 单点交叉
    point = np.random.randint(len(parent1))
    return parent1[:point] + parent2[point:], parent2[:point] + parent1[point:]

# 初始化种群
population = np.random.rand(100, 30)  # 100个个体，30个基因

# 迭代优化
for _ in range(50):
    fitness_values = np.apply_along_axis(fitness, 1, population)
    selected = population[np.argsort(-fitness_values)[:10]]  # 选择前10优秀个体
    # 交叉
    new_population = []
    while len(new_population) < 100:
        p1, p2 = np.random.choice(selected, 2)
        child1, child2 = crossover(p1, p2)
        new_population.append(child1)
        new_population.append(child2)
    population = np.array(new_population)
```
