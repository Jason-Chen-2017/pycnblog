## 第一部分：低市净率投资的背景与核心概念

### 第1章：低市净率投资的起源与发展

#### 1.1 低市净率投资的起源

低市净率投资是一种基于价值投资的理念，旨在寻找市场低估的股票。起源于20世纪，约翰·聂夫是该策略的代表人物，他在1970年代至2000年代管理的富达逆向策略基金取得了卓越的业绩。

#### 1.2 低市净率投资与其他价值投资策略的对比

| 指标 | 定义 | 适用场景 | 优点 | 缺点 |
|------|------|----------|------|------|
| 市盈率 | P/E = 价格/每股收益 | 高增长行业 | 反映盈利能力 | 收益波动大 |
| 市净率 | P/B = 价格/每股净资产 | 资产密集型行业 | 评估资产价值 | 忽略收益质量 |
| 市销率 | P/S = 价格/每股营收 | 服务行业 | 反映收入能力 | 受营销影响 |

#### 1.3 约翰·聂夫的投资理念

- **投资策略**：长期持有，注重安全边际。
- **核心思想**：寻找低市净率且基本面良好的公司。
- **投资组合管理**：分散投资，定期调整。

### 第2章：市净率的定义与计算

#### 2.1 市净率的定义

市净率（P/B）= 股票价格 / 每股净资产。

#### 2.2 市净率与其他指标的对比

**优缺点对比**：

- **优点**：评估资产价值，避免高估。
- **缺点**：忽视收益质量，可能错过高增长公司。

#### 5.2 核心代码实现

```python
import pandas as pd

def calculate_p_b_ratio(data):
    data['P/B'] = data['Price'] / data['Book Value per Share']
    return data

def filter_low_p_b(data, threshold=1.5):
    return data[data['P/B'] < threshold]

# 示例数据
data = {
    'Stock': ['A', 'B', 'C'],
    'Price': [50, 30, 40],
    'Book Value per Share': [20, 15, 25]
}
df = pd.DataFrame(data)
df = calculate_p_b_ratio(df)
filtered = filter_low_p_b(df)

print(filtered)
```

#### 5.3 代码解读

- `calculate_p_b_ratio`：计算市净率。
- `filter_low_p_b`：筛选低市净率股票。
