## 第一部分: 价值投资的理论基础

### 第1章: 价值投资与乔尔·格林布拉特的投资理念

#### 1.1 价值投资的定义与核心思想

- **1.1.1 价值投资的定义**  
  价值投资是一种以基本面分析为基础的投资方法，旨在通过识别市场中被低估的资产，实现长期稳定的超额收益。其核心在于寻找“价格低于内在价值”的投资标的。

- **1.1.2 乔尔·格林布拉特的投资理念**  
  乔尔·格林布拉特是价值投资领域的代表性人物，他提出了著名的“格雷厄姆-多德公式”，强调安全边际和长期投资的重要性。他认为，市场短期波动不可预测，但长期趋势可以通过基本面分析来把握。

- **1.1.3 价值投资的核心要素**  
  - 安全边际：买入价格低于内在价值，以降低投资风险。  
  - 内在价值：通过财务指标（如市盈率、市净率等）估算企业的长期价值。  
  - 长期视角：忽略短期市场波动，关注企业的长期盈利能力。

#### 1.2 乔尔·格林布拉特的投资方法

- **1.2.1 格雷厄姆-多德公式**  
  格林布拉特的投资模型基于格雷厄姆-多德公式，该公式通过企业的基本面指标（如 earnings、book value、cash flow 等）计算其内在价值，并与市场价格进行对比，寻找低估的投资机会。公式如下：

  $$ \text{内在价值} = \frac{\text{每股收益} \times (8.5 + 2.5 \times \text{ROE})}{\text{市盈率}} $$

- **1.2.2 安全边际的概念**  
  安全边际是格林布拉特策略的核心，它要求投资者以低于内在价值的价格买入资产，以应对市场波动和潜在的不确定性。安全边际的计算公式为：

  $$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

- **1.2.3 价值投资与成长投资的区别**  
  价值投资注重低估值和高安全边际，而成长投资则侧重于企业的高增长潜力。格林布拉特的策略介于两者之间，既关注企业的估值，也关注其盈利能力。

#### 1.3 价值投资的哲学与心理

- **1.3.1 投资中的心理因素**  
  投资者常常受到情绪影响，如贪婪和恐惧，这可能导致非理性决策。价值投资者需要克服情绪干扰，坚持长期视角。

- **1.3.2 理性与非理性的平衡**  
  理性分析是价值投资的基础，但市场波动往往由非理性因素驱动。格林布拉特提醒投资者，既要理性分析，也要灵活应对市场变化。

- **1.3.3 长期投资与市场的短期波动**  
  市场短期波动不可预测，但长期趋势可以通过基本面分析来把握。格林布拉特强调，价值投资者应专注于长期目标，避免被短期波动干扰。

#### 1.4 本章小结

本章介绍了价值投资的核心理念和格林布拉特的投资方法，重点分析了他的安全边际概念和投资策略。下一章将探讨如何通过实证研究验证这些理论。

#### 6.2 核心代码实现

```python
import pandas as pd
import numpy as np

class Security:
    def __init__(self, ticker, price, pe, pb, dividend):
        self.ticker = ticker
        self.price = price
        self.pe = pe
        self.pb = pb
        self.dividend = dividend

class Strategy:
    def __init__(self, margin=0.2):
        self.margin = margin

    def intrinsic_value(self, security):
        # 示例：简单计算内在价值
        return security.pe * security.price * 0.5

    def screen(self, security):
        iv = self.intrinsic_value(security)
        return iv > security.price * (1 + self.margin)

# 示例数据
data = {
    'ticker': ['AAPL', 'GOOGL', 'MSFT'],
    'price': [150, 130, 300],
    'pe': [15, 20, 25],
    'pb': [3, 2, 1],
    'dividend': [0.5, 0.4, 0.6]
}

df = pd.DataFrame(data)
strategies = Strategy(0.2)

selected = []
for index, row in df.iterrows():
    security = Security(
        ticker=row['ticker'],
        price=row['price'],
        pe=row['pe'],
        pb=row['pb'],
        dividend=row['dividend']
    )
    if strategies.screen(security):
        selected.append(security.ticker)

print("Selected stocks:", selected)
```
