## 第一部分：全球股市估值分析

### 第1章：全球股市估值概述

#### 1.1 股市估值的基本概念

股市估值是评估股票内在价值的过程，帮助投资者决定是否购买或出售股票。核心概念包括市盈率（P/E）、市净率（P/B）和股息率等。

#### 1.2 股市估值的主要方法

- **市盈率（P/E）**：公式为$$P/E = \frac{\text{股价}}{\text{每股收益}}$$，衡量股票价格相对于收益的高低。
- **市净率（P/B）**：公式为$$P/B = \frac{\text{股价}}{\text{每股净资产}$$，适用于评估资产密集型公司。
- **股息率**：公式为$$\text{股息率} = \frac{\text{股息/每股}}{\text{股价/每股}} \times 100\%$$，反映分红回报率。

#### 1.3 影响股市估值的关键因素

包括宏观经济指标、行业周期、市场情绪和政策因素。例如，GDP增长率和利率直接影响股市估值。

### 第2章：全球股市估值的数学模型与算法

#### 2.1 常用估值模型

- **DCF模型**：通过现金流折现计算企业价值，公式为$$\text{企业价值} = \sum_{t=1}^{n} \frac{\text{现金流}}{(1 + r)^t}$$，其中r为折现率。

#### 2.2 算法实现

```python
def calculate_dcf(cash_flows, discount_rate, period):
    return sum(cash_flows[i] / (1 + discount_rate)**i for i in range(period))
```
