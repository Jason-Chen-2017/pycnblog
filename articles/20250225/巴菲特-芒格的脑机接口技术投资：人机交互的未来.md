### 第2章：脑机接口技术的基础

#### 2.1 脑机接口技术的定义与分类

##### 2.1.1 脑机接口技术的定义
- 脑机接口（BCI）是一种连接人脑与外部设备的接口技术，通过采集和解析神经信号，实现人脑与机器之间的信息交互。

##### 2.1.2 脑机接口技术的分类
- **侵入式**：直接植入大脑，如深部脑刺激技术。
- **非侵入式**：通过头皮电极采集脑电信号。

##### 2.1.3 脑机接口技术的关键技术指标
- 信号采集精度：EEG、fMRI等技术的对比。
- 信号处理算法：滤波、特征提取、分类算法。

#### 2.2 脑机接口技术的发展历程

##### 2.2.1 脑机接口技术的历史回顾
- 20世纪50年代：EEG技术的初步应用。
- 21世纪：脑机接口技术的快速发展。

##### 2.2.2 脑机接口技术的现状
- 临床应用：神经康复、疾病诊断。
- 消费市场：游戏、教育。

##### 2.2.3 脑机接口技术的未来趋势
- 高精度、低延迟、可穿戴设备的普及。

#### 2.3 脑机接口技术的核心算法

##### 2.3.1 神经信号处理算法

##### 2.3.2 信号识别与分类算法

```python
import numpy as np
from scipy.signal import butterworth

def butterworth_filter(data, fs, cutoff_freq, order=4):
    nyq = 0.5 * fs
    normal_cutoff = cutoff_freq / nyq
    b, a = butterworth(order, normal_cutoff, btype='low', analog=False)
    filtered_data = np.convolve(data, a, mode='full')[:len(data)]
    return filtered_data

# 示例数据
data = np.random.normal(size=1000)
fs = 100
cutoff_freq = 30
filtered_data = butterworth_filter(data, fs, cutoff_freq)
```
