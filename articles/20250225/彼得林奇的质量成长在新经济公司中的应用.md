# 第1章: 背景与基础

## 1.1 质量成长投资的定义与核心要素
质量成长投资关注那些具有强大财务健康、竞争优势和持续盈利能力的公司。其核心在于在合理估值下投资于优质企业，注重ROE、现金流和市场地位等指标。

## 1.2 彼得林奇的贡献与投资理念
彼得林奇作为传奇基金经理，强调长期投资于优质公司，避免短期波动干扰。其质量成长策略注重企业基本面，避免过度关注市场情绪。

## 1.3 新经济公司的特点与挑战
新经济公司以科技、互联网为主，具有高增长、高波动性，同时面临技术迭代快、竞争激烈等挑战，这些特点对质量成长策略的应用提出更高要求。

# 第3章: 算法原理与数学模型

## 3.1 质量成长投资的评估指标
- ROE：衡量企业盈利能力，公式：$$ROE = \frac{净利润}{平均股东权益}$$
- 市盈率：衡量估值，公式：$$P/E = \frac{股价}{每股收益}$$
- 现金流：评估企业财务健康，公式：$$FCF = \text{现金流}$$

## 3.2 投资组合评分算法
```python
def calculate_roe(financial_data):
    net_profit = financial_data['net_profit']
    average_equity = financial_data['average_equity']
    return net_profit / average_equity

def calculate_pe_ttm(stock_price, financial_data):
    eps_ttm = financial_data['eps_ttm']
    return stock_price / eps_ttm

def quality_growth_score(stock_data):
    roe = calculate_roe(stock_data)
    pe = calculate_pe_ttm(stock_data)
    cash_flow = stock_data['cash_flow']
    score = 0.4 * roe + 0.3 * (1 / pe) + 0.3 * cash_flow
    return score
```

```python
import pandas as pd

def main():
    stock_data = pd.read_csv('stocks.csv')
    scores = []
    for stock in stock_data['symbol']:
        data = stock_data[stock_data['symbol'] == stock]
        roe = calculate_roe(data)
        pe = calculate_pe_ttm(data)
        cash_flow = data['cash_flow'].values[0]
        score = 0.4 * roe + 0.3 * (1 / pe) + 0.3 * cash_flow
        scores.append((stock, score))
    scores_df = pd.DataFrame(scores, columns=['symbol', 'score'])
    scores_df.to_csv('scores.csv', index=False)

if __name__ == "__main__":
    main()
```
