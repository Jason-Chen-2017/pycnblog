## 第1章：资本支出的背景与定义

### 1.1 资本支出的定义与特点

资本支出（CapEx）是企业在长期资产上的投资，包括购买设备、建筑物和无形资产等。其特点包括长期性、高价值和战略性，与运营费用（OpEx）不同，后者是日常运营中的支出。

### 1.2 彼得·林奇的投资理念

彼得·林奇强调投资于具备持续增长潜力的公司，关注其资本支出是否合理。他认为有效的资本支出应提高公司竞争力和未来收益。

## 第2章：资本支出的核心概念与联系

### 2.1 资本支出的构成与影响因素

资本支出包括设备、厂房和研发投入等，其影响因素有市场需求、技术进步和竞争环境等。

### 2.2 资本支出与公司财务健康的关系

资本支出与公司盈利能力、成长性密切相关。合理的资本支出能提升效率，过高的支出可能影响短期利润。

## 第3章：资本支出的算法原理

### 3.1 资本支出评估的算法原理

#### 净现值（NPV）计算

$$ NPV = \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t} $$

其中，CF_t是第t年的现金流，r是贴现率。

#### 内部收益率（IRR）计算

$$ IRR = r \text{ 使得 } NPV = 0 $$

### 6.2 核心实现源代码

```python
import numpy as np
import pandas as pd

def calculate_npv(cash_flows, discount_rate):
    return np.npv(discount_rate, cash_flows)

def calculate_irr(cash_flows):
    return np.irr(cash_flows)

# 示例数据
cash_flows = [-100, 30, 30, 30]
discount_rate = 0.1

npv = calculate_npv(cash_flows, discount_rate)
irr = calculate_irr(cash_flows)

print(f"净现值：{npv:.2f}")
print(f"内部收益率：{irr:.2%}")
```
