## 第1章：引言

### 1.1 耐心资本与深科技投资概述

#### 1.1.1 耐心资本的定义与特点

耐心资本是一种长期投资策略，强调持有资产的时间跨度较长，通常超过5年。其特点包括：

- **长期性**：投资者愿意等待多年，以实现资本的增值。
- **稳定性**：耐心资本注重资产的稳定性，避免短期波动的影响。
- **低流动性需求**：投资者在持有期间较少进行交易，降低交易成本和税务负担。

#### 1.1.2 深科技投资的定义与特点

深科技投资是指投资于高科技创新领域的行为，其特点包括：

- **高技术门槛**：涉及人工智能、量子计算、生物技术等领域。
- **高风险**：技术创新不确定，市场波动大。
- **高回报**：成功的深科技投资可能带来超额收益。

#### 1.1.3 耐心资本与深科技投资的联系与区别

- **联系**：耐心资本的长期性与深科技投资的高风险、高回报特性相契合。
- **区别**：耐心资本更注重资本的稳定增长，而深科技投资更关注技术创新带来的超额收益。

import pandas as pd

def calculate_valuation_ratios(df):
    df['市盈率'] = df['股价'] / df['每股收益']
    df['市净率'] = df['股价'] / df['每股净资产']
    return df

# 示例数据
data = {
    '公司': ['公司A', '公司B', '公司C'],
    '股价': [100, 80, 120],
    '每股收益': [5, 4, 6],
    '每股净资产': [20, 15, 25]
}

df = pd.DataFrame(data)
result = calculate_valuation_ratios(df)
print(result)
