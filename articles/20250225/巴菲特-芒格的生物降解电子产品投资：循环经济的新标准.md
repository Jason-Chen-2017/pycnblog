## 第二部分: 巴菲特-芒格投资逻辑的数学模型与算法原理

### 第3章: 投资评估的核心算法

#### 3.1 净现值（NPV）计算公式

$$ \text{NPV} = \sum_{t=0}^{n} \frac{C_t}{(1+r)^t} $$

其中：
- $C_t$：第 $t$ 年的现金流
- $r$：贴现率
- $n$：项目周期

#### 3.2 内部收益率（IRR）的定义

$$ \text{IRR 是使 NPV=0 的折现率} $$

#### 3.3 实例分析与算法实现

```python
def calculate_npv(cash_flows, discount_rate):
    npv = 0
    for t, cash_flow in enumerate(cash_flows):
        npv += cash_flow / (1 + discount_rate) ** t
    return npv

cash_flows = [100, -50, 50, 50]
discount_rate = 0.1
print(calculate_npv(cash_flows, discount_rate))
```
