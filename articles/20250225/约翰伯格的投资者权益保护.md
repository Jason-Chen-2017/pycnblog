#### 5.2 核心实现源代码
- **投资组合优化代码示例**
```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

# 示例数据
returns = np.array([0.1, 0.2, 0.15, 0.05, 0.3])

# 定义优化目标函数
def objective(weights):
    return np.dot(weights, returns)

# 约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 初始化权重
initial_guess = np.array([1/5, 1/5, 1/5, 1/5, 1/5])

# 使用SLSQP求解器优化
result = minimize(objective, initial_guess, method='SLSQP', constraints={'type': 'eq', 'fun': constraint})

# 输出结果
print("最优权重:", result.x)
print("最优收益:", objective(result.x))
```

- **代码实现**：使用上述代码优化权重，计算最优投资组合。
- **结果解读**：解释优化后的权重分布，分析各资产对总收益的贡献。
