## 第二部分: 核心概念与联系

### 第2章: 股市估值的核心原理

#### 2.1 股市估值的基本原理
- **市盈率法**：通过比较可比公司的市盈率，评估企业的市场价值。
- **市净率法**：基于资产账面价值进行估值。
- **股息率法**：评估股票的分红收益。

#### 2.2 技术许可定价的核心原理
- **成本加成定价**：基于技术开发成本加成一定比例。
- **市场定价**：根据市场需求和竞争情况制定价格。
- **协商定价**：通过谈判确定最终价格。

#### 4.3 Python代码实现
```python
import pandas as pd
import numpy as np

# 数据收集
data = {'公司ID': ['1', '2', '3'], 
        '市盈率': [15, 20, 25],
        '市净率': [2, 3, 4]}
df = pd.DataFrame(data)

# 市盈率计算
def calculate_pe_ratio(data):
    return data['市盈率'].mean()

pe_ratio = calculate_pe_ratio(df)
print(f'平均市盈率为: {pe_ratio}')

# 市净率计算
def calculate_p_b_ratio(data):
    return data['市净率'].mean()

pb_ratio = calculate_p_b_ratio(df)
print(f'平均市净率为: {pb_ratio}')
```

#### 4.4 数学模型与公式
- 市盈率公式：$PE = \frac{股价}{每股收益}$
- 市净率公式：$PB = \frac{股价}{每股净资产}$
