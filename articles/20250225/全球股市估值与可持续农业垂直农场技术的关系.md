# 第2章: 核心概念与联系

## 2.1 全球股市估值的原理

### 2.1.1 股市估值的基本方法
- 市盈率（P/E ratio）：$$ P/E = \frac{股价}{每股收益} $$
- 市净率（P/B ratio）：$$ P/B = \frac{股价}{每股净资产} $$
- 市销率（P/S ratio）：$$ P/S = \frac{股价}{每股收入} $$

### 2.1.2 影响股市估值的主要因素
- 企业盈利：核心驱动因素
- 宏观经济：外部环境影响
- 投资者情绪：市场波动的关键因素

---

## 2.2 可持续农业与垂直农场技术的原理

### 2.2.1 可持续农业的核心理念
- 减少资源消耗
- 降低环境污染
- 提高生产效率

### 2.2.2 垂直农场技术的关键特征
- 多层立体种植
- 精准农业技术
- 节能环控系统

### 2.2.3 垂直农场技术的经济效益与环境效益
- 经济效益：$$ 经济效益 = 收入 - 成本 $$
- 环境效益：$$ 环境效益 = 节能减排量 $$

## 5.2 核心代码实现

### 5.2.1 数据处理
```python
import pandas as pd
import numpy as np

# 数据加载
df = pd.read_csv('market_data.csv')

# 数据清洗
df.dropna(inplace=True)
df = df[ df['revenue'] > 0 ]
```

### 5.2.2 模型训练
```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 训练数据
X = df[['revenue', 'profit']]
y = df['stock_price']

model = LinearRegression()
model.fit(X, y)

# 模型评估
y_pred = model.predict(X)
print(mean_squared_error(y, y_pred))
```

### 5.2.3 可视化
```python
import matplotlib.pyplot as plt

plt.scatter(X['revenue'], y)
plt.plot(X['revenue'], y_pred, color='red')
plt.xlabel('Revenue')
plt.ylabel('Stock Price')
plt.show()
```
