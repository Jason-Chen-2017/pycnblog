#### 4.2.1 投资组合优化算法的实现
```python
import numpy as np
def optimize_portfolio(cost_matrix):
    n = cost_matrix.shape[0]
    # 初始化权重向量
    w = np.ones(n) / n
    # 迭代优化
    while True:
        # 计算成本
        cost = w.T.dot(cost_matrix.dot(w))
        # 检查收敛条件
        if np.allclose(cost, w.T.dot(cost_matrix.dot(w))):
            break
        # 更新权重
        w = w * (1 - cost)
    return w
```

#### 4.2.2 代码应用解读与分析
通过迭代优化权重，找到成本最小化或回报最大化的组合。
