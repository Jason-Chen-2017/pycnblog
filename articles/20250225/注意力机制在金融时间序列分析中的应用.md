## 第2章：注意力机制的核心原理

### 2.1 自注意力机制的数学模型
自注意力机制通过计算序列中每个位置与其他位置的权重来生成新的表示。其数学公式如下：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

其中：
- $Q$、$K$、$V$分别为查询、键和值矩阵。
- $d_k$为键的维度。

### 2.2 多头注意力机制的扩展
为了增强模型的表达能力，多头注意力机制将序列划分为多个子序列，分别计算注意力权重：

$$
\text{Multi-head}(Q, K, V) = \text{Concat}(\text{Attention}_1(Q, K, V), \text{Attention}_2(Q, K, V), \dots, \text{Attention}_n(Q, K, V))
$$

### 2.3 位置编码与时间序列的结合
为了保持时间序列的位置信息，通常在模型中引入位置编码（Positional Encoding，PE）。常见的位置编码方法包括基于指数函数的编码：

$$
PE(i, j) = \sum_{k=0}^{n-1} \sin(10000^{j/(2n)} i)
$$

### 5.2 核心代码实现
```python
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

class TransformerBlock(layers.Layer):
    def __init__(self, embed_dim, num_heads, **kwargs):
        super().__init__(**kwargs)
        self.embed_dim = embed_dim
        self.num_heads = num_heads
        self.head_size = embed_dim // num_heads
        self.scaling = tf.constant(self.head_size ** -0.5, dtype=tf.float32)
        
    def call(self, inputs):
        Q = K = V = inputs
        # 计算键-查询点积
        attention_scores = tf.matmul(Q, K, transpose_b=True) * self.scaling
        attention_weights = tf.nn.softmax(attention_scores)
        # 加权求和
        output = tf.matmul(attention_weights, V)
        return output
```
