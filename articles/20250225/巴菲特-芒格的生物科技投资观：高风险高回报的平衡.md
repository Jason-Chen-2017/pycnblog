## 第三部分：巴菲特-芒格的生物科技投资策略

### 第3章：投资策略与分析框架

#### 3.1 价值评估方法

- **3.1.1 生物科技公司的估值方法**
  - 使用现金流折现法（DCF）评估公司的未来价值。
  - 公式：$$DCF = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$**
  - 其中，CF_t为第t年的现金流，r为折现率，TV为终值。

- **3.1.2 关键财务指标**
  - 营业收入增长率。
  - 净利润率。
  - 研发投入比例。

#### 3.2 风险管理策略

- **3.2.1 风险识别**
  - 技术风险：产品研发失败。
  - 市场风险：市场竞争加剧。
  - 政策风险：法规变化。

- **3.2.2 风险控制**
  - 分散投资：通过投资不同领域的公司降低风险。
  - 设置止损点：在投资组合中设定止损线，避免重大损失。

#### 3.3 投资组合构建

- **3.3.1 投资组合的构成**
  - 组合中包含不同阶段的公司：早期公司和成熟公司。
  - 行业分散：涵盖医药、医疗设备等领域。

- **3.3.2 投资组合的风险调整回报**
  - 使用夏普比率评估投资组合的风险调整回报。
  - 公式：$$夏普比率 = \frac{E[R_p - R_f]}{stddev[R_p - R_f]}$$**
  - 其中，E[R_p - R_f]为投资组合超额收益的期望值，stddev为标准差。

## 第四部分：数学模型与算法应用

### 第4章：数学模型与估值方法

#### 4.1 内在价值计算公式

- **4.1.1 现金流折现模型**
  - 使用DCF模型计算公司的内在价值。
  - 示例：假设公司未来5年的现金流分别为100万、120万、150万、180万、200万，折现率为10%。
  - 计算现值：$$PV = \frac{100}{1.1} + \frac{120}{1.1^2} + \frac{150}{1.1^3} + \frac{180}{1.1^4} + \frac{200}{1.1^5}$$

#### 4.2 财务指标分析

- **4.2.1 市盈率（P/E）**
  - 公式：$$P/E = \frac{股价}{每股收益}$$
  - 低市盈率可能意味着低估，高市盈率可能意味着高增长或高风险。

- **4.2.2 市净率（P/B）**
  - 公式：$$P/B = \frac{股价}{每股净资产}$$
  - 用于评估股票相对于其账面价值的高低。

#### 4.3 模型的优缺点

- **优点**
  - 提供量化评估，帮助识别低估公司。
  - 适用于长期投资策略。

- **缺点**
  - 假设未来现金流可预测，实际中可能波动较大。
  - 忽略了市场情绪和宏观经济因素的影响。

  def calculateDCF(cash_flows, discount_rate, terminal_value):
      present_value = 0
      for year, cf in enumerate(cash_flows, 1):
          present_value += cf / (1 + discount_rate) ** year
      present_value += terminal_value / (1 + discount_rate) ** len(cash_flows)
      return present_value

  # 示例数据
