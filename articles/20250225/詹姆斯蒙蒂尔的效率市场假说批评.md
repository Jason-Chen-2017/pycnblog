## 第一章: 有效市场假说的背景与发展

### 1.1 有效市场假说的起源
现代金融学的奠基者如哈里·马科维茨和威廉·夏普为有效市场假说奠定了基础。蒙蒂尔在20世纪60年代提出了理性预期假说，认为市场价格反映了所有可获得的信息。这一理论在70年代得到广泛应用，成为金融学的核心框架。

### 1.2 蒙蒂尔的学术贡献
蒙蒂尔通过实证研究验证了有效市场假说，并提出了理性预期与市场效率的关系。他认为，市场参与者基于理性预期做出决策，导致市场价格反映了所有相关信息。

## 第二章: 有效市场假说的核心概念

### 2.1 市场效率的定义
市场效率是指市场价格能够快速反映所有相关信息的状态。蒙蒂尔将市场效率分为弱、半强和强三种形式，并通过Fama的三重测试进行验证。

### 2.2 核心概念与联系
理性预期是有效市场假说的核心，蒙蒂尔认为市场参与者能够基于所有可用信息做出理性决策。通过对比表格和ER图，展示了理性预期与市场效率的关系。

### 3.2 算法实现
用Python代码实现CAPM模型，计算预期收益。

```python
def capm(risk_free_rate, market_return, beta, market_risk_premium):
    return risk_free_rate + beta * (market_return + market_risk_premium)
```

## 第四章: 有效市场假说的数学模型

### 4.1 CAPM模型
CAPM公式为：$$ R_i = R_f + \beta_i (R_m - R_f) $$，其中$R_i$是资产的预期收益，$R_f$是无风险利率，$\beta_i$是贝塔系数，$R_m$是市场预期收益。

### 4.2 Fama的三重测试
Fama的三重测试用于验证资产定价模型的有效性，包括横截面回归、时间序列回归和三因子回归。
