# 第二部分: 宏观经济指标的基础知识

## 第2章: 宏观经济指标的分类与分析

### 2.1 GDP（国内生产总值）

- **2.1.1 GDP的定义与计算方法**
  - GDP是衡量经济活动的重要指标，计算公式为：
    $$ GDP = C + I + G + (X - M) $$

### 2.2 失业率

- **2.2.1 失业率的计算与影响**
  - 失业率 = 失业人数 / 劳动力总数 × 100%

### 2.3 消费者价格指数（CPI）

- **2.3.1 CPI的定义与作用**
  - 衡量通货膨胀的重要指标，影响货币政策。

### 2.4 利率与货币政策

- **2.4.1 利率对经济的影响**
  - 利率下降通常刺激投资和消费。

### 2.5 财政政策与政府支出

- **2.5.1 财政政策的作用**
  - 政府通过调整支出和税收影响经济。

2. 数据分析：识别异常值。
3. 决策：逆向投资。

### 4.2 Python代码实现

```python
import pandas as pd
import numpy as np

# 示例数据
data = {'GDP': [5, 4.8, 4.5, 4.3],
        '失业率': [6.5, 6.2, 6.8, 7.0]}
df = pd.DataFrame(data)

# 识别异常值
outliers = df[df['GDP'] < np.percentile(df['GDP'], 10)]
print(outliers)
```

### 4.3 数学模型

- **线性回归模型**用于预测GDP：
  $$ GDP = a \times 失业率 + b $$
