## 第1章：背景与基础

### 1.1 格雷厄姆特价股票理论概述

#### 1.1.1 格雷厄姆投资理论的核心概念
格雷厄姆是价值投资的鼻祖，其理论强调寻找市场低估的股票。核心概念包括：
- **内在价值**：企业未来现金流的现值，与市场价格比较决定投资价值。
- **安全边际**：买入价格低于内在价值，以降低风险。

#### 1.1.2 特价股票的定义与筛选标准
格雷厄姆推荐的筛选标准包括：
- 低市盈率（P/E < 15）
- 低市净率（P/B < 1.5）
- 高股息率（股息率 > 5%）
- 强大的财务状况（如债务/资本 < 0.5）

#### 1.1.3 格雷厄姆理论在现代投资中的应用
现代投资者利用格雷厄姆理论结合技术分析和大数据，筛选出具有长期投资价值的股票。

### 1.2 行为经济学基础

#### 1.2.1 行为经济学的基本概念
行为经济学研究心理因素如何影响经济决策，认为市场参与者并非完全理性。

#### 1.2.2 市场参与者心理偏差对投资决策的影响
常见偏差包括：
- **过度自信**：投资者高估自己判断市场的能力。
- **羊群效应**：跟随市场趋势而非独立判断。

#### 1.2.3 行为经济学与传统经济学的对比
行为经济学更关注实际心理因素，而传统经济学假设参与者完全理性。

#### 3.1.3 算法实现代码
```python
import pandas as pd
from sklearn.linear_model import LinearRegression

def calculate_intrinsic_value(financials):
    return financials['净利润'] / (1 + financials['贴现率'])

def market_sentiment(index_prices):
    model = LinearRegression()
    model.fit(pd.DataFrame(index_prices), range(len(index_prices)))
    return model.coef_

# 示例数据
financials = pd.DataFrame({'净利润': [100, 200], '贴现率': [0.1, 0.15]})
index_prices = [100, 110, 105]

# 计算
iv = calculate_intrinsic_value(financials)
sentiment = market_sentiment(index_prices)
print("内在价值:", iv)
print("市场情绪:", sentiment)
```
