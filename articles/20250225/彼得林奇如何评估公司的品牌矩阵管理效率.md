#### 3.1.2 品牌矩阵管理效率的算法实现
```python
def calculate_brand_matrix_efficiency(brand_data):
    # 假设brand_data是一个包含品牌强度和市场份额的字典
    brand_efficiency = {}
    for brand in brand_data:
        strength = brand_data[brand]['strength']
        market_share = brand_data[brand]['market_share']
        efficiency = (strength * market_share) / (strength + market_share)
        brand_efficiency[brand] = efficiency
    return brand_efficiency
```
