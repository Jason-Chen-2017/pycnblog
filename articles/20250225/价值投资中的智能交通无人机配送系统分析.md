# 第三部分：算法原理

## 第3章：无人机配送系统的路径规划算法

### 3.1 基于Dijkstra算法的路径优化
#### 3.1.1 Dijkstra算法的数学模型
$$
\text{目标函数：} \quad \min_{x} \sum_{i} c_i x_i
$$
$$
\text{约束条件：} \quad \sum_{i} x_i = 1
$$
其中，\( c_i \) 为各路径的成本，\( x_i \) 为选择路径的变量。

#### 3.1.2 算法流程
```mermaid
graph TD
    A[开始] --> B[初始化起点]
    B --> C[计算各节点的最短距离]
    C --> D[更新距离和路径]
    D --> E[检查所有节点]
    E --> F[结束]
```

#### 3.1.3 Python代码实现
```python
import heapq

def dijkstra(start, end, graph):
    dist = {node: float('infinity') for node in graph}
    dist[start] = 0
    heap = [(0, start)]
    heapq.heapify(heap)
    
    while heap:
        current_dist, u = heapq.heappop(heap)
        if u == end:
            break
        if current_dist > dist[u]:
            continue
        for v, weight in graph[u].items():
            if dist[v] > dist[u] + weight:
                dist[v] = dist[u] + weight
                heapq.heappush(heap, (dist[v], v))
    return dist[end]

# 示例图结构
graph = {
    'A': {'B': 1, 'C': 3},
    'B': {'A': 1, 'D': 2},
    'C': {'A': 3, 'D': 4},
    'D': {}
}

print(dijkstra('A', 'D', graph))  # 输出：3
```

## 第4章：基于遗传算法的路径优化

### 4.1 遗传算法的基本原理
#### 4.1.1 初始化种群
随机生成一定数量的路径方案作为初始种群。

#### 4.1.2 适应度评估
计算各路径的配送成本，作为适应度值。

#### 4.1.3 选择与交叉
根据适应度值选择高适应度的路径，进行交叉操作生成新种群。

#### 4.1.4 变异与迭代
对新种群进行变异操作，优化路径，重复迭代直到满足条件。

### 4.2 遗传算法在无人机配送中的应用
#### 4.2.1 遗传算法的数学模型
$$
\text{适应度函数：} \quad f(x) = \sum_{i} c_i x_i
$$
其中，\( c_i \) 为各路径的成本，\( x_i \) 为选择路径的变量。

#### 4.2.2 算法流程
```mermaid
graph TD
    A[开始] --> B[初始化种群]
    B --> C[计算适应度]
    C --> D[选择与交叉]
    D --> E[变异与优化]
    E --> F[检查终止条件]
    F --> G[结束]
```

#### 4.2.3 Python代码实现
```python
import random

def generate_path(cities):
    return random.sample(cities, len(cities))

def calculate_cost(path, graph):
    total = 0
    for i in range(len(path)-1):
        total += graph[path[i]][path[i+1]]
    return total

def genetic_algorithm(cities, graph, population_size=100, generations=50):
    population = [generate_path(cities, graph) for _ in range(population_size)]
    for _ in range(generations):
        population = sorted(population, key=lambda x: calculate_cost(x, graph))
        population = population[:population_size//2]
        new_population = []
        for i in range(len(population)):
            if i % 2 == 0:
                parent1 = population[i]
                parent2 = population[i+1]
                child = parent1[:len(parent1)//2] + parent2[len(parent1)//2:]
                new_population.append(child)
        population = new_population
    best_path = min(population, key=lambda x: calculate_cost(x, graph))
    return best_path

cities = ['A', 'B', 'C', 'D']
graph = {
    'A': {'B': 1, 'C': 3},
    'B': {'A': 1, 'D': 2},
    'C': {'A': 3, 'D': 4},
    'D': {}
}

best_path = genetic_algorithm(cities, graph)
print(best_path)  # 输出：['A', 'B', 'D']
```
