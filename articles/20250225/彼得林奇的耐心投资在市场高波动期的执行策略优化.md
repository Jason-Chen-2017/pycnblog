## 第三部分: 算法与数学模型

### 第5章: 技术分析与数学模型

#### 5.1 技术分析的数学模型
- **移动平均线（MA）**：计算N日移动平均线，用于判断趋势。
  $$ MA_{n}(t) = \frac{1}{n} \sum_{i=1}^{n} P(t-i+1) $$
- **相对强弱指数（RSI）**：衡量超买或超卖状态。
  $$ RSI(t) = \frac{100}{1 + \frac{A}{B}} $$
  其中，A为上涨幅度，B为下跌幅度。

#### 5.2 算法实现
```python
def calculate_RSI(prices, n=14):
    # 计算上涨幅度和下跌幅度
    up = [max(0, prices[i] - prices[i-1]) for i in range(1, len(prices))]
    down = [max(0, prices[i-1] - prices[i]) for i in range(1, len(prices))]
    
    # 计算平均上涨和平均下跌
    avg_up = []
    avg_down = []
    for i in range(len(up)):
        if i < n-1:
            avg_up.append(up[:i+1].mean())
            avg_down.append(down[:i+1].mean())
        else:
            avg_up.append(up[i-n+1:i+1].mean())
            avg_down.append(down[i-n+1:i+1].mean())
    
    # 计算RSI
    rsi = []
    for i in range(len(avg_up)):
        if avg_down[i] == 0:
            rsi_val = 100
        else:
            rsi_val = 100 - (100 / (1 + (avg_up[i] / avg_down[i])))
        rsi.append(rsi_val)
    return rsi
```
