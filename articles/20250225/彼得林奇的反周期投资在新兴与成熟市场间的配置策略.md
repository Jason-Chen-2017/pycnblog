# 引言

## 1.1 反周期投资的基本概念

### 1.1.1 投资周期的基本定义  
经济周期分为复苏、繁荣、衰退和萧条四个阶段，反周期投资是指在周期低谷时买入，在周期高峰时卖出的投资策略。

### 1.1.2 反周期投资的定义与特点  
反周期投资强调逆向思维，追求在市场低估时布局，避免市场高估时介入。

### 1.1.3 彼得林奇投资策略的核心思想  
彼得林奇主张长期投资优质资产，在市场恐慌时寻找被低估的投资标的。

# 第三部分：反周期投资策略的数学模型

## 3.1 市场周期判断模型

### 3.1.1 市场估值指标  
$$P/E = \frac{Price}{Earnings}$$

### 3.1.2 市场状态判断  
$$状态 = \begin{cases} 
低估 & \text{若 } P/E < 历史均值 \\
高估 & \text{若 } P/E > 历史均值 
\end{cases}$$

---

## 3.2 资产配置模型

### 3.2.1 新兴市场权重计算  
$$新兴市场权重 = \max(0, 1 - \frac{新兴市场估值}{历史均值})$$

### 3.2.2 成熟市场权重计算  
$$成熟市场权重 = \max(0, 1 - \frac{成熟市场估值}{历史均值})$$

```python
import pandas as pd
import numpy as np

# 数据获取与处理
data = pd.read_csv('market_data.csv')
data['低估指标'] = data['P/E'] < data['P/E'].mean()

# 市场状态判断
def 判断市场状态(数据):
    if 数据['P/E'] < 数据['P/E'].mean():
        return '低估'
    else:
        return '高估'

# 资产配置
新兴市场权重 = np.max(0, 1 - (data['新兴市场P/E'] / data['新兴市场P/E'].mean()))
成熟市场权重 = np.max(0, 1 - (data['成熟市场P/E'] / data['成熟市场P/E'].mean()))
```
