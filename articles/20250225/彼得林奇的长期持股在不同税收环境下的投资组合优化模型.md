## 第三部分: 投资组合优化算法原理

### 3.1 算法原理

为了在不同税收环境下优化投资组合，我们需要结合彼得林奇的长期持股策略与现代投资组合理论（MPT）。以下是优化算法的核心思想：

1. **目标函数**：最大化投资组合的预期收益，同时最小化风险（方差）。
   $$
   \text{目标函数} = \text{最大化} \left( \sum_{i=1}^n w_i r_i - \lambda \sum_{i=1}^n w_i^2 \sigma_i^2 \right)
   $$
   其中，\(w_i\) 是第i只股票的投资权重，\(r_i\) 是期望收益率，\(\sigma_i^2\) 是风险（方差），\(\lambda\) 是风险厌恶系数。

2. **考虑税收的影响**：在目标函数中加入税收因素，调整后的目标函数为：
   $$
   \text{调整后的目标函数} = \sum_{i=1}^n w_i r_i (1 - t_i) - \lambda \sum_{i=1}^n w_i^2 \sigma_i^2
   $$
   其中，\(t_i\) 是第i种资产的税率。

3. **优化过程**：使用优化算法（如遗传算法或梯度下降）求解上述目标函数，得到最优的投资权重。

### 3.2 Python实现

以下是实现上述优化模型的Python代码示例：

```python
import numpy as np
import pandas as pd
import pyportfolioopt as ppo

# 示例数据
returns = pd.DataFrame({
    '资产1': [0.05, 0.03, 0.04],
    '资产2': [0.02, 0.06, 0.01],
    '资产3': [0.03, 0.05, 0.06]
})

# 定义税率
tax_rates = {'资产1': 0.15, '资产2': 0.20, '资产3': 0.25}

# 计算调整后的收益率
adjusted_returns = returns.apply(lambda x: x * (1 - x.index.map(tax_rates)[0]))

# 使用MPT模型优化
model = ppo.MeanVarianceOptimization(adjusted_returns)
weights, _ = model.optimize()

print("最优权重:", weights)
```
