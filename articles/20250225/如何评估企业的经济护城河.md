### ## 第4章: 经济护城河的数学模型

#### ### 4.1 护城河强度评分模型
- 理论基础：基于多因素分析的评分模型。
- 数学公式：
  $$ S = \sum_{i=1}^{n} w_i \times f_i $$
  其中，$w_i$为第$i$个因素的权重，$f_i$为第$i$个因素的评分。

#### ### 4.2 案例分析
- 案例：某互联网企业的护城河评估。
- 数据：成本优势、网络效应、技术壁垒等指标。
- 计算步骤：
  1. 数据清洗：处理缺失值。
  2. 指标评分：对每个因素进行评分（1-5分）。
  3. 权重分配：根据行业特点分配权重。
  4. 计算护城河强度：
    $$ S = 0.3 \times 4.5 + 0.4 \times 3.8 + 0.3 \times 4.2 = 3.87 $$

#### ### 6.2 核心实现
```python
import pandas as pd
import numpy as np

def calculate_moorhouse_score(cost_advantage, network_effect, technology_barriers):
    # 计算护城河强度
    score = 0.3 * cost_advantage + 0.4 * network_effect + 0.3 * technology_barriers
    return score

# 数据加载
data = pd.read_csv("enterprise_data.csv")

# 数据清洗
data.dropna(inplace=True)

# 计算护城河强度
data['护城河强度'] = data.apply(lambda x: calculate_moorhouse_score(x['成本优势'], x['网络效应'], x['技术壁垒']), axis=1)

# 可视化
import matplotlib.pyplot as plt

plt.scatter(data['成本优势'], data['护城河强度'])
plt.xlabel('成本优势')
plt.ylabel('护城河强度')
plt.title('护城河强度分布')
plt.show()
```
