# 第一章：芒格的数学期望思维与量子金融模型概述

## 1.1 数学期望的定义与特点
数学期望是概率论中的核心概念，表示随机变量在所有可能结果中的加权平均值。其特点包括：
- 线性性：$E(aX + bY) = aE(X) + bE(Y)$
- 稳定性：不受极端值影响
- 预测性：用于预测未来结果

## 1.2 量子金融模型的基本概念
量子金融模型是基于量子力学原理构建的金融分析工具，主要应用于投资组合优化和风险评估。

# 第二章：数学期望与量子概率论

## 2.1 数学期望的量子化解释
在量子系统中，数学期望对应于观测值的期望值，满足 $E(\hat{O}) = \langle \psi | \hat{O} | \psi \rangle$，其中 $\hat{O}$ 是观测算符，$|\psi\rangle$ 是量子态。
