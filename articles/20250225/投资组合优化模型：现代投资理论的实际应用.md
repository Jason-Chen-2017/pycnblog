## 3.1 投资组合优化的数学模型

### 3.1.1 均值-方差模型的数学表达

在投资组合优化中，马科维茨的均值-方差模型是最经典的模型之一。该模型的目标是通过最小化投资组合的方差（即风险）来优化投资组合。其数学表达如下：

$$ 
\text{目标函数：} \min \sigma^2 = \min \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} 
$$

其中，$w_i$ 是第 $i$ 个资产的投资权重，$\sigma_{ij}$ 是资产 $i$ 和资产 $j$ 的协方差。

约束条件包括：
1. 投资组合的权重之和为1：
$$ \sum_{i=1}^n w_i = 1 $$
2. 投资组合的期望收益等于给定的收益目标：
$$ \sum_{i=1}^n w_i \mu_i = \mu_p $$
其中，$\mu_i$ 是资产 $i$ 的期望收益，$\mu_p$ 是投资组合的期望收益目标。

### 3.1.2 线性规划与二次规划的对比

投资组合优化问题可以分为两类：线性规划和二次规划。在线性规划中，目标函数和约束条件都是线性的，而二次规划的目标函数是二次的，约束条件可以是线性的或二次的。

均值-方差模型属于二次规划问题，因为它涉及到方差和协方差的计算。

### 3.1.3 数学模型的优化方法

为了求解均值-方差模型，可以使用拉格朗日乘数法。通过引入拉格朗日乘数，将约束条件整合到目标函数中，形成一个无约束优化问题。具体步骤如下：

1. 构建拉格朗日函数：
$$ 
L = \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} + \lambda_1 \left( \sum_{i=1}^n w_i - 1 \right) + \lambda_2 \left( \sum_{i=1}^n w_i \mu_i - \mu_p \right)
$$

2. 对每个 $w_k$ 求偏导并设为0：
$$ 
\frac{\partial L}{\partial w_k} = 2 \sum_{i=1}^n w_i \sigma_{ki} + \lambda_1 + \lambda_2 \mu_k = 0
$$

3. 解方程组得到最优权重 $w^*$。

## 3.2 投资组合优化的算法实现

### 3.2.1 拉格朗日乘数法的原理

拉格朗日乘数法是一种优化技术，用于在有约束的条件下寻找函数的极值。通过引入拉格朗日乘数，将约束条件转化为目标函数的一部分，从而将问题转化为无约束优化问题。

### 3.2.2 均值-方差模型的实现步骤

1. **输入参数**：资产的收益率、协方差矩阵、目标收益。
2. **构建目标函数**：方差最小化。
3. **构建约束条件**：权重之和为1，期望收益为目标收益。
4. **求解优化问题**：使用拉格朗日乘数法或二次规划算法求解。

### 3.2.3 Python代码实现

以下是一个使用SciPy库求解均值-方差模型的Python代码示例：

```python
import numpy as np
from scipy.optimize import minimize

# 假设已经计算得到协方差矩阵、期望收益
n_assets = 5
cov_matrix = np.array([[0.01, 0.005, 0.008, ...], ...])  # 示例协方差矩阵
mu = np.array([0.1, 0.12, 0.08, ...])  # 资产期望收益
target_return = 0.1  # 目标收益

# 定义目标函数
def portfolio_variance(weights):
    return np.dot(weights.T, np.dot(cov_matrix, weights))

# 定义约束条件
def constraint1(weights):
    return np.sum(weights) - 1

def constraint2(weights):
    return np.dot(weights, mu) - target_return

# 初始化权重（例如，等权）
initial_weights = np.array([1.0 / n_assets] * n_assets)

# 使用SciPy的minimize函数求解
result = minimize(portfolio_variance, initial_weights, 
                 method='SLSQP', 
                 constraints=[{'type': 'eq', 'fun': constraint1},
                              {'type': 'eq', 'fun': constraint2}])

# 最优权重
optimal_weights = result.x

print("最优权重：", optimal_weights)
```

## 5.3 案例分析

### 5.3.1 数据准备

假设我们有两只资产：股票A和债券B，其历史收益率如下：

| 资产 | 收益率 |
|------|--------|
| A    | 0.12    |
| B    | 0.08    |

协方差矩阵：
$$ 
\begin{bmatrix}
0.0144 & 0.0096 \\
0.0096 & 0.0064 \\
\end{bmatrix}
$$

目标收益：10%

### 5.3.2 优化过程

调用优化函数，得到最优权重：
$$ 
w_A = 0.6, \quad w_B = 0.4
$$

### 5.3.3 结果分析

投资组合的预期收益：
$$ 
0.6 \times 0.12 + 0.4 \times 0.08 = 0.10
$$

投资组合的方差：
$$ 
0.6^2 \times 0.0144 + 0.4^2 \times 0.0064 + 2 \times 0.6 \times 0.4 \times 0.0096 = 0.0072
$$

标准差：
$$ 
\sqrt{0.0072} \approx 0.0849
$$
