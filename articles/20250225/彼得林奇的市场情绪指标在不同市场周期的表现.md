情绪周期与市场周期密切相关，情绪高涨时市场可能进入牛市，情绪低落时可能进入熊市。

#### 5.2.2 数据处理代码
```python
import pandas as pd
import matplotlib.pyplot as plt

# 读取数据
data = pd.read_csv('market_data.csv')

# 计算情绪指数
def calculate_emotion_index(data):
    buy_strength = data['buy_volume']
    sell_strength = data['sell_volume']
    emotion_index = (buy_strength - sell_strength) / (buy_strength + sell_strength)
    return emotion_index

emotion_index = calculate_emotion_index(data)
```
