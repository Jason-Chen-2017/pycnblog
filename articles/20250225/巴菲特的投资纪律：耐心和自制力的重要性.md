## 第1章：巴菲特的投资理念与纪律

### 1.1 巴菲特的投资哲学

#### 1.1.1 价值投资的定义与核心理念
价值投资是一种以内在价值为导向的投资方法，旨在通过深入分析企业的基本面，寻找被市场低估的投资标的。巴菲特的哲学强调长期投资、安全边际和企业内在价值的计算。

#### 1.1.2 巴菲特投资成功的三大核心要素
1. **能力圈**：专注于自己熟悉的企业和行业。
2. **安全边际**：以低于内在价值的价格买入，确保安全空间。
3. **长期视角**：耐心等待合适的机会，不被短期波动干扰。

#### 1.1.3 投资纪律在巴菲特体系中的地位
投资纪律是巴菲特成功的关键，它包括严格遵守投资原则、坚持长期视角以及在市场恐慌时逆势投资。

## 第2章：耐心与自制力的核心概念

### 2.1 耐心的哲学与心理学分析

#### 2.1.1 耐心的哲学意义
耐心是一种美德，它使投资者能够在市场波动中保持冷静，避免冲动决策。巴菲特定义：耐心是等待好机会的能力，而不是等待机会的能力。

#### 2.1.2 耐心的心理学特征
- 耐心需要强大的心理韧性。
- 耐心与情绪管理密切相关，能够减少因恐惧或贪婪导致的错误决策。

#### 2.1.3 耐心与投资决策的关系
耐心使投资者能够在市场低迷时坚持持有优质资产，避免在恐慌中割肉，从而捕捉长期收益。

### 2.2 自制力的定义与属性

#### 2.2.1 自制力的定义
自制力是指在面对诱惑或压力时，能够控制自己的行为，做出理性决策的能力。

#### 2.2.2 自制力的核心特征对比表
| 特征 | 自制力 | 缺乏自制力 |
|------|--------|------------|
| 行为控制 | 能够抑制冲动 | 容易被情绪驱动 |
| 决策质量 | 理性决策 | 可能犯错决策 |
| 长期效果 | 稳定收益 | 不稳定或亏损 |

## 第3章：耐心与自制力的数学模型

### 3.1 耐心的数学模型

#### 3.1.1 耐心的量化公式
耐心可以通过时间窗口来量化，公式为：
$$ \text{耐心} = \frac{\text{目标投资期限}}{\text{当前投资周期}} $$

#### 3.1.2 耐心与投资回报的关系
长期耐心投资的回报可以用几何平均回报率来衡量，公式为：
$$ R_{\text{几何}} = \left( \prod_{i=1}^{n} (1 + R_i) \right)^{1/n} - 1 $$

#### 3.1.3 耐心的数学推导与实例分析
假设投资回报率为10%（年化），经过10年投资，几何平均回报率为：
$$ R_{\text{几何}} = \left( (1 + 0.1)^{10} \right)^{1/10} - 1 \approx 0.1 $$

import pandas as pd
import numpy as np

def calculate_patience(target_period, current_period):
    return target_period / current_period

def calculate_return(returns):
    geometric_mean = np.prod(1 + returns) ** (1/len(returns)) - 1
    return geometric_mean

# 示例数据

print(f"耐心系数: {patience}")
print(f"几何平均回报率: {calculate_return(returns)}")
