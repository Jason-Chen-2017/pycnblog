## 第一部分：背景介绍

### 第1章：去全球化趋势的定义与背景

#### 1.1 什么是去全球化
- 去全球化指全球化进程的逆转，表现为跨国贸易减少、供应链本地化、地缘政治紧张加剧等。

#### 1.2 去全球化的驱动因素
- 技术进步：供应链优化和数字化转型减少了对全球化的依赖。
- 地缘政治冲突：贸易壁垒增加，如中美贸易摩擦。
- 经济政策变化：各国政府推动本地生产，减少对外依赖。

#### 1.3 去全球化对全球经济的影响
- 贸易流量下降，企业成本上升。
- 供应链本地化，推动区域经济一体化。
- 货币政策和财政政策的调整对全球经济稳定性的影响。

## 第二部分：核心概念与联系

### 第2章：宏观经济分析的核心概念

#### 2.1 宏观经济指标分析
- **GDP**：衡量经济总量，反映国家经济状况。
- **通货膨胀率**：影响货币政策和消费者购买力。
- **失业率**：反映就业市场健康状况。

#### 2.2 经济周期与投资决策
- **经济周期的四个阶段**：衰退、复苏、繁荣、衰退。
- **投资策略在不同阶段的调整**：衰退期寻找防御性资产，复苏期投资周期性股票。

#### 2.3 巴菲特的宏观经济视角
- 通过分析宏观经济指标预测企业盈利能力。
- 关注长期趋势，如人口结构变化和技术进步对经济的影响。

## 第三部分：算法原理

### 第3章：巴菲特投资模型的算法原理

#### 3.1 DCF模型的工作原理
- **定义**：通过现金流折现计算企业内在价值。
- **公式**：
  $$
  \text{企业价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} + \frac{\text{残值}}{(1 + r)^{n+1}}
  $$
  其中，r为折现率，n为预测年数。

#### 3.2 竞争优势分析
- **核心竞争力**：企业独特的能力或资源，如品牌、技术、成本优势。
- **护城河**：阻止竞争对手进入市场的障碍，如专利、网络效应。

### 第5章：DCF模型的实现

#### 5.2 核心代码实现
- **DCF模型代码**：
  ```python
  def discounted_cash_flow(free_cash_flow, discount_rate, growth_rate, terminal_growth_rate, years):
      dcf = 0
      for i in range(years):
          cash_flow = free_cash_flow * (1 + growth_rate)
          dcf += cash_flow / (1 + discount_rate)**(i+1)
      terminal_value = free_cash_flow * (1 + terminal_growth_rate) / (discount_rate - terminal_growth_rate)
      dcf += terminal_value / (1 + discount_rate)**years
      return dcf
  ```

#### 5.3 代码解读与分析
- **输入参数**：自由现金流、折现率、增长率、终值增长率、年数。
- **计算过程**：逐年现金流折现，计算终值并加总。
