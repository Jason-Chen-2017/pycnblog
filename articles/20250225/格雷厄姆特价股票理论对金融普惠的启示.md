# 第一部分：背景介绍

## 第1章：格雷厄姆特价股票理论的理论基础

### 1.1 价值投资的起源与发展

#### 1.1.1 价值投资的起源  
价值投资作为一种投资策略，起源于20世纪初。本杰明·格雷厄姆（Benjamin Graham）是该领域的先驱，他提出了“安全边际”和“内在价值”等核心概念，为价值投资奠定了理论基础。

#### 1.1.2 格雷厄姆的学术贡献  
格雷厄姆不仅是价值投资的创始人之一，还与戴维·多德（David Dodd）共同开发了基本面分析方法。他的著作《股票分析的艺术》和《聪明的投资者》成为投资领域的经典。

#### 1.1.3 特价股票理论的核心思想  
格雷厄姆提出的特价股票理论强调以低于内在价值的价格购买股票，通过安全边际来降低投资风险。他认为，市场的短期波动性为投资者提供了以折扣价买入优质股票的机会。

### 2.1 金融普惠的定义

#### 2.1.1 金融普惠的内涵  
金融普惠是指通过降低门槛和提高可及性，让更多人能够享受到金融服务和投资机会。它强调公平和包容性，旨在缩小贫富差距。

#### 2.1.2 金融普惠的目标  
金融普惠的目标是让所有人都能以合理成本获得必要的金融服务，包括储蓄、信贷、保险和投资。

#### 2.1.3 金融普惠的实现路径  
通过技术创新、政策支持和教育普及，降低金融门槛，扩大金融服务的覆盖范围。

# 第二部分：核心概念与联系

## 第4章：格雷厄姆特价股票理论的核心概念

### 4.1 安全边际的概念与计算

#### 4.1.1 安全边际的定义  
安全边际是指股票的市场价格低于其内在价值的部分，用于缓冲市场波动带来的风险。

#### 4.1.2 安全边际的计算公式  
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

#### 4.1.3 安全边际与投资风险的关系  
安全边际越高，投资风险越低。通过安全边际，投资者可以在市场波动中保持稳健的投资回报。

### 4.2 低市盈率与低市净率的比较

#### 4.2.1 市盈率与市净率的定义  
- 市盈率（P/E）= 股价 / 每股净利润  
- 市净率（P/B）= 股价 / 每股净资产  

#### 4.2.2 低市盈率与低市净率的优缺点对比  

| 指标 | 优点 | 缺点 |
|------|------|------|
| 市盈率 | 反映盈利能力 | 受行业和企业规模影响较大 |
| 市净率 | 反映资产质量 | 受资产重企业影响较大 |

#### 4.2.3 低市盈率与低市净率的适用场景  
- 低市盈率适用于盈利稳定的成熟企业。  
- 低市净率适用于资产密集型行业，如银行和制造业。

# 第三部分：理论分析与数学模型

## 第5章：格雷厄姆特价股票理论的数学模型

### 5.1 安全边际的数学公式

#### 5.1.1 内在价值的估算  
$$ \text{内在价值} = \frac{\text{净利润} \times (1 + g)}{r - g} $$  
其中，$g$为净利润增长率，$r$为折现率。

#### 5.1.2 安全边际的计算  
$$ \text{安全边际} = \frac{\text{内在价值}}{\text{市场价格}} $$

### 5.2 市盈率与市净率的比较公式

#### 5.2.1 市盈率与市净率的对比  
$$ \text{P/E} < \text{行业平均P/E} \quad \text{且} \quad \text{P/B} < \text{行业平均P/B} $$

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(eps, growth_rate, discount_rate):
    return eps * (1 + growth_rate) / (discount_rate - growth_rate)

def calculate_security_margin(intrinsic_value, market_price):
    return intrinsic_value / market_price

# 示例数据
data = {
    'symbol': ['AAPL', 'GOOGL', 'MSFT'],
    'eps': [4.09, 31.01, 6.09],
    'growth_rate': [0.05, 0.03, 0.04],
    'discount_rate': [0.08, 0.07, 0.09]
}

df = pd.DataFrame(data)

# 计算内在价值和安全边际
df['intrinsic_value'] = df.apply(lambda x: calculate_intrinsic_value(x['eps'], x['growth_rate'], x['discount_rate']), axis=1)
df['market_price'] = df['symbol'].apply(lambda x: get_market_price(x))  # 假设get_market_price函数已实现
df['security_margin'] = df.apply(lambda x: calculate_security_margin(x['intrinsic_value'], x['market_price']), axis=1)

print(df)
```

$$ \text{安全边际} = \frac{140.33}{150} = 0.9355 $$
