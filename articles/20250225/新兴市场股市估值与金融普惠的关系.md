- 3.3 Python代码实现
  ```python
  import pandas as pd

  # 示例数据
  stock_data = {
      '公司': ['A', 'B', 'C'],
      '价格': [100, 200, 150],
      '盈利': [20, 30, 25]
  }
  df = pd.DataFrame(stock_data)

  # 计算市盈率（PE）
  df['PE'] = df['价格'] / df['盈利']

  # 计算市净率（PB）
  df['PB'] = df['价格'] / (df['价格'] / 2)  # 假设账面价值为价格的一半

  print(df)
  ```
- 3.4 数学模型
  - 市盈率公式：$PE = \frac{\text{股价}}{\text{每股收益}}$
  - 市净率公式：$PB = \frac{\text{股价}}{\text{每股净资产}}$
  - CAPM模型：$$ R = R_f + \beta (R_m - R_f) $$
