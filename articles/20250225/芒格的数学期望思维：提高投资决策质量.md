- 2.2.2 数学期望的计算公式：$$E[X] = \sum_{i=1}^{n} p_i x_i$$，其中$p_i$是第$i$个结果的概率，$x_i$是第$i$个结果的值。

# 第3章: 数学期望与投资决策的结合

## 3.1 投资中的期望收益  
- 3.1.1 期望收益的计算公式：$$E[R] = \sum_{i=1}^{n} p_i R_i$$，其中$R_i$是第$i$种资产的收益，$p_i$是其概率。  
- 3.1.2 投资组合的期望收益：通过权重和期望收益计算投资组合的期望收益。  
- 3.1.3 期望收益与实际收益的关系：期望收益是理论值，实际收益受市场波动影响。  

## 3.2 风险与方差  
- 3.2.1 方差的定义与计算：方差是收益与期望收益的平方差的期望值，公式为$$Var(X) = E[(X - E[X])^2]$$。  
- 3.2.2 标准差的意义：标准差是方差的平方根，表示收益的波动性。  
- 3.2.3 风险与收益的权衡：高期望收益通常伴随着高风险，投资者需在两者之间找到平衡点。  

## 3.3 数学期望在资产配置中的应用  
- 3.3.1 资产配置的基本原理：通过分配资金到不同资产类别，降低风险，提高收益。  
- 3.3.2 数学期望在组合优化中的作用：通过计算各资产的期望收益和方差，优化投资组合。  
- 3.3.3 长期视角的资产配置：芒格强调长期投资，通过时间分散风险，提高期望收益。

# 第4章: 数学期望的原理与属性

## 4.1 数学期望的原理  
- 4.1.1 线性性：数学期望满足线性性质，即$$E[aX + b] = aE[X] + b$$。  
- 4.1.2 乘积的期望：$$E[XY] \neq E[X]E[Y]$$，除非$X$和$Y$独立。  

## 4.2 数学期望的属性特征对比  
| 属性       | 期望收益 | 方差 | 标准差 |  
|------------|----------|------|--------|  
| 定义       | 各结果的加权平均收益 | 各结果与期望收益的平方差的期望值 | 方差的平方根 |  
| 作用       | 衡量投资的预期收益 | 衡量投资的波动性和风险 | 衡量收益的离散程度 |

# 第5章: 算法原理讲解

## 5.1 期望值的计算算法  
- 5.1.1 算法流程图：  

- 5.1.2 Python代码实现：  
```python
def compute_expectation(values, probabilities):
    return sum(v * p for v, p in zip(values, probabilities))
```

## 5.2 方差的计算算法  
- 5.2.1 算法流程图：  
```mermaid
graph TD
    Start --> InputData
    InputData --> ComputeMean
    ComputeMean --> ComputeSquaredDiffs
    ComputeSquaredDiffs --> ComputeVariance
    ComputeVariance --> OutputResult
    OutputResult --> End
```

- 5.2.2 Python代码实现：  
```python
def compute_variance(values, probabilities, mean):
    return sum((v - mean) ** 2 * p for v, p in zip(values, probabilities))
```

## 5.3 数学模型与公式  
- 期望值公式：$$E[X] = \sum_{i=1}^{n} p_i x_i$$  
- 方差公式：$$Var(X) = \sum_{i=1}^{n} p_i (x_i - E[X])^2$$  
- 标准差公式：$$\sigma = \sqrt{Var(X)}$$
