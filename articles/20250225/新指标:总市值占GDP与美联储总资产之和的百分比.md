## 第一部分: 新指标的背景与概念

### 第1章: 新指标的背景与问题背景

#### 1.1 经济指标的重要性
经济指标是分析和理解经济运行状况的关键工具。它们帮助政策制定者、投资者和研究机构评估经济表现、预测趋势并做出决策。然而，现有的经济指标在某些情况下可能不够全面，无法捕捉复杂的经济动态。

#### 1.2 新指标的定义与问题描述
新指标定义为总市值占GDP与美联储总资产之和的百分比。该指标旨在综合反映市场价值、经济产出和货币政策之间的关系。通过整合这三个关键因素，新指标能够提供更全面的经济视角。

#### 1.3 新指标的边界与外延
新指标适用于分析宏观经济状况，特别是在货币政策和市场价值对经济的影响方面。它不仅适用于美国，还可推广到其他国家的类似分析。

## 第三部分: 算法原理讲解

### 第3章: 算法原理与数学模型

#### 3.1 计算公式
新指标的计算公式如下：

$$
\text{新指标} = \frac{\text{总市值}}{\text{GDP} + \text{美联储总资产}} \times 100\%
$$

#### 3.2 算法流程
计算步骤如下：

1. 收集总市值、GDP和美联储总资产的数据。
2. 计算GDP与美联储总资产的总和。
3. 计算总市值占该总和的百分比。

以下为计算过程的Mermaid图：

```mermaid
graph TD
    A[收集数据] --> B[计算总和]
    B --> C[计算百分比]
    C --> D[输出结果]
```

#### 3.3 代码实现
以下是Python代码实现：

```python
def calculate_new_indicator(market_cap, gdp, fed_assets):
    total = gdp + fed_assets
    new_indicator = (market_cap / total) * 100
    return new_indicator

# 示例数据
market_cap = 1000  # 总市值
gdp = 500  # GDP
fed_assets = 300  # 美联储总资产

result = calculate_new_indicator(market_cap, gdp, fed_assets)
print(f"新指标百分比: {result}%")
```
