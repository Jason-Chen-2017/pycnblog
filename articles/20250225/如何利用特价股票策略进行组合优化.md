#### 3.2 数学模型与公式
- 均值-方差模型
$$\text{目标函数：} \min \sigma^2 \text{在} \mu \text{固定}$$
- 约束条件：投资权重之和为1，权重非负

#### 3.3 Python实现
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns):
    n = len(returns.columns)
    initial_weights = np.array([1/n]*n)
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1},
                   {'type': 'ineq', 'fun': lambda w: w >= 0}]
    result = minimize(lambda w: np.dot(w.T, np.dot(returns.cov(), w)),
                      initial_weights, constraints)
    return result.x
```

#### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np
from scipy.optimize import minimize

# 数据预处理
data = pd.read_csv('stock_data.csv')
returns = data.pct_change().dropna()

# 优化函数
def portfolioOptimizer(returns):
    n = len(returns.columns)
    initial_guess = np.array([1.0/n]*n)
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1},
                   {'type': 'ineq', 'fun': lambda w: w >= 0}]
    result = minimize(lambda w: np.dot(w.T, returns.cov() @ w),
                      initial_guess, constraints)
    return result.x

# 应用优化
weights = portfolioOptimizer(returns)
print("优化权重:", weights)
```
