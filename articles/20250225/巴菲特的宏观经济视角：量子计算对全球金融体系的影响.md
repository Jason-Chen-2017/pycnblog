## 第2章：量子计算的基本原理

### 2.1 量子位与叠加原理
量子位是量子计算的核心单元，与经典计算机中的二进制位不同，量子位可以同时处于多个状态的叠加态。这种特性使得量子计算机在处理复杂问题时具有潜在的优势。

### 2.2 量子纠缠与通信
量子纠缠是指两个或多个量子位之间形成的一种特殊关联，使得其中一个量子位的状态能够瞬间影响另一个量子位的状态，无论它们相距多远。这种特性在量子通信和分布式计算中具有重要应用。

## 第6章：量子计算在金融中的实际案例

### 6.1 投资组合优化的量子算法实现
以下是使用量子退火算法优化投资组合的Python代码示例：

```python
from qiskit import QuantumCircuit, Aer, execute
from qiskit.optimization import QuadraticProgram

# 定义问题
qp = QuadraticProgram()
qp.binary_vars('x')
qp.minimize(linear=[1])
qp.add_constraint('x <= 0.5')

# 解决问题
backend = Aer.get_backend('qasm_simulator')
result = execute(QuadraticProgramToQiskit().convert(qp), backend).result()
optimal_solution = result.x

print(optimal_solution)
```
