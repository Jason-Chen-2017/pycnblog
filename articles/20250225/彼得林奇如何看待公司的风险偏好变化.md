# 第五部分：项目实战

## 第5章：项目实战：苹果公司的风险偏好分析

### 5.1 环境配置
- **工具**：Python、Pandas、Matplotlib。

### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 示例数据
data = {
    'Year': [2018, 2019, 2020, 2021],
    'Revenue': [269, 278, 290, 394],
    'NetIncome': [59, 61, 64, 100]
}

df = pd.DataFrame(data)
df['ROE'] = df['NetIncome'] / df['Revenue'] * 100

print(df)
plt.plot(df['Year'], df['ROE'])
plt.xlabel('Year')
plt.ylabel('ROE (%)')
plt.show()
```

### 5.3 案例分析
- **分析**：苹果的高ROE和增长潜力反映了进取型风险偏好。
- **结论**：投资决策应考虑行业地位和管理层能力。
