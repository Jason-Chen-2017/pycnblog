## 第一部分：格雷厄姆特价股票理论与社会企业家投资的背景

### 第1章：格雷厄姆特价股票理论概述

#### 1.1 格雷厄姆投资理论的核心理念

- **1.1.1 价值投资的基本原则**
  - 投资的本质是寻找“烟屁股”，即价格远低于内在价值的股票。
  - 价值投资强调安全边际，即买入价格应低于内在价值的一定折扣。
  - 长期投资是价值投资的核心，市场的短期波动不应影响长期决策。

- **1.1.2 特价股票的定义与特征**
  - 特价股票是指市场价格低于其内在价值的股票。
  - 具有低市盈率、低市净率和高股息率的特点。
  - 通常出现在市场低迷或企业困境时期。

- **1.1.3 格雷厄姆投资策略的历史演变**
  - 格雷厄姆的投资策略起源于20世纪初，经历了从“捡烟蒂”到更注重企业基本面的演变。
  - 他的理论对巴菲特等现代投资者产生了深远影响。

#### 1.2 社会企业家与投资的结合

- **1.2.1 社会企业的定义与特点**
  - 社会企业是以追求社会价值为目标的企业，其核心目标是解决社会问题。
  - 社会企业的特点是兼顾经济效益和社会影响力。

- **1.2.2 社会企业家投资的动机与目标**
  - 投资者可能出于社会责任感，希望通过投资实现社会价值。
  - 社会企业家投资的目标是支持社会企业发展，同时获取财务回报。

- **1.2.3 社会投资与传统投资的差异**
  - 社会投资更注重社会影响力，而传统投资更关注财务回报。
  - 社会投资的风险和回报结构可能更为复杂。

### 第3章：格雷厄姆理论的核心概念解析

#### 3.1 格雷厄姆理论的主要原理

- **3.1.1 内在价值的计算方法**
  - 内在价值是企业未来现金流的现值。
  - 使用格雷厄姆的公式：内在价值 = (年收益 × 4.25) ÷ 8.5
  - 例如，假设一家企业年收益为100万元，其内在价值为 $42.5万元。

- **3.1.2 安全边际的重要性**
  - 安全边际 = 内在价值 - 市场价格
  - 例如，如果内在价值为100万元，市场价格为80万元，安全边际为20万元。

- **3.1.3 股票投资的长期视角**
  - 长期投资是价值投资的核心，避免短期波动的影响。
  - 通过长期持有优质股票，投资者可以获得稳定的回报。

#### 3.2 格雷厄姆理论与现代投资理论的对比

- **3.2.1 主要投资策略的对比分析**
  | 理论 | 格雷厄姆价值投资 | 现代投资组合理论 |
  |------|------------------|------------------|
  | 核心 | 内在价值评估     | 分散化投资       |
  | 重点 | 个股选择         | 组合优化         |

- **3.2.2 格雷厄姆理论的独特性**
  - 重视个股的内在价值，而非市场趋势。
  - 强调安全边际和长期投资。

- **3.2.3 理论的局限性与改进方向**
  - 格雷厄姆理论适用于稳定的市场环境，但在动荡时期可能表现不佳。
  - 需要结合现代投资理论，如风险管理，进行优化。

#### 7.2 核心代码实现

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(revenue):
    return (revenue * 4.25) / 8.5

def calculate_margin_of_safety(current_price, intrinsic_value):
    return intrinsic_value - current_price

# 示例数据
data = {
    '公司名称': ['公司A', '公司B', '公司C'],
    '年收益': [100, 150, 200],
    '当前价格': [50, 60, 70]
}

df = pd.DataFrame(data)

# 计算内在价值和安全边际
df['内在价值'] = df['年收益'].apply(lambda x: calculate_intrinsic_value(x))
df['安全边际'] = df.apply(lambda row: calculate_margin_of_safety(row['当前价格'], row['内在价值']), axis=1)

print(df)
```
