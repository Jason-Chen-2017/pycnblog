# 第2章: 营运杠杆的基本概念

## 2.1 营运杠杆的定义与特征

### 2.1.1 营运杠杆的定义  
营运杠杆（Operating Leverage）是指企业通过固定成本和可变成本的比例，影响净利润变动与营业收入变动之间的关系。高营运杠杆意味着固定成本较高，净利润受营业收入波动的影响较大。

### 2.1.2 营运杠杆的核心特征  
- 固定成本占比高：如租金、工资等。
- 变动成本占比低：如原材料成本。
- 净利润波动较大：营业收入小幅度变化可能导致净利润大幅波动。

### 2.1.3 营运杠杆与财务杠杆的区别  
营运杠杆关注企业内部成本结构，而财务杠杆关注企业资本结构中的债务比例。两者共同影响企业的资本成本和风险。

## 2.2 营运杠杆的类型

### 2.2.1 固定成本与可变成本  
- 固定成本：不随产量变化而变化的成本。
- 可变成本：随产量变化而变化的成本。

### 2.2.2 营业杠杆系数  
营业杠杆系数（Degree of Operating Leverage, DOL）= %变动后的净利润变动 / %变动后的营业收入变动。

### 2.2.3 不同行业中的营运杠杆差异  
- 高营运杠杆行业：如制造业、零售业。
- 低营运杠杆行业：如软件服务行业。

## 2.3 营运杠杆对投资决策的影响

### 2.3.1 营运杠杆与企业盈利能力的关系  
高营运杠杆可能导致企业净利润波动大，影响盈利能力的稳定性。

### 2.3.2 营运杠杆与企业风险的关系  
高营运杠杆企业风险较高，因为净利润对营业收入变化更敏感。

### 2.3.3 投资者如何利用营运杠杆进行决策  
投资者应评估企业的成本结构和行业特点，选择具有稳定盈利能力的公司。

import pandas as pd

def calculate_operating_leverage(revenue, net_profit):
    dol = (revenue - (revenue - net_profit)) / net_profit
    return dol

# 示例数据
data = {'营业收入': [1000, 2000, 3000],
        '净利润': [100, 200, 300]}
df = pd.DataFrame(data)

# 计算营业杠杆系数
dol = calculate_operating_leverage(df['营业收入'], df['净利润'])
print("营业杠杆系数:", dol)
