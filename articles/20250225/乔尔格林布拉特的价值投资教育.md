## 第一部分：价值投资的背景与基础

### 第1章：价值投资的概述

#### 1.1 价值投资的定义与核心理念

价值投资是一种以基本面分析为基础的投资策略，强调购买被市场低估的资产。其核心理念包括寻找安全边际、长期持有和追求内在价值。

#### 1.2 投资市场的基本结构

股票市场由上市公司、投资者和中介机构构成。投资者分为机构和个人，价值投资适用于寻找低估标的的市场环境。

#### 1.3 价值投资与其他投资策略的对比

价值投资与成长投资的区别在于对内在价值和成长性的侧重。投机关注短期价格波动，而投资注重长期价值。

### 第3章：价值投资的评估方法

#### 3.1 财务报表分析基础

通过分析资产负债表、利润表和现金流，计算关键估值指标如PE、PB和ROE，帮助识别低估股票。

#### 3.2 内在价值的计算方法

使用DCF模型评估企业价值，步骤包括预测现金流、计算折现率和求和现值。代码示例如下：

```python
def dcf_cerner(revenue, growth_rate, discount_rate, period):
    cash_flows = []
    for i in range(period):
        cash_flows.append(revenue * (1 + growth_rate)**i)
    present_value = sum([cf / (1 + discount_rate)**i for i, cf in enumerate(cash_flows)])
    return present_value
```
