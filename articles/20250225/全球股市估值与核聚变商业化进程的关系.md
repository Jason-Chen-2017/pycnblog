# 第2章：全球股市估值基础

## 2.1 股市估值的基本概念

股市估值是指对上市公司价值的评估，常用的估值方法包括市盈率（P/E）、市净率（P/B）等。这些指标反映了市场的预期和企业的真实价值。

## 2.2 全球主要股市的估值特点

以美国股市为例，科技股的高估值现象普遍存在，而传统行业则相对估值较低。这种差异反映了市场对技术创新的高度关注。

## 2.3 股市估值与经济周期的关系

经济周期波动对股市估值有直接影响。在经济繁荣时期，股市估值通常较高；而在衰退期，估值则会下降。

# 第3章：核聚变技术的商业化进程

## 3.1 核聚变技术的基本原理

核聚变是通过高温高压使轻核聚合成重核的过程，释放巨大能量。与核裂变相比，核聚变更安全、更清洁。

## 3.2 核聚变技术的商业化现状

目前，核聚变技术仍处于研发阶段，但一些公司如ITER和General Fusion正在积极推进商业化进程。

## 3.3 核聚变技术的未来发展趋势

技术突破和政策支持是核聚变商业化的关键因素。未来，核聚变可能成为全球能源结构的重要组成部分。
