### ## 4.1 格雷厄姆价值评估的核心公式

格雷厄姆的价值评估模型基于以下几个核心公式：

#### ### 4.1.1 股票内在价值的计算公式

$$
\text{内在价值} = \frac{\text{净利润} \times (1 + g)}{r - g}
$$

其中，\( g \) 为净利润增长率，\( r \) 为期望回报率。

#### ### 4.1.2 股票安全边际的计算方法

$$
\text{安全边际} = \text{市场价格} \times \text{安全边际系数}
$$

安全边际系数通常介于 0.5 到 1 之间，表示市场价格与内在价值的比例关系。

### ## 4.2 格雷厄姆价值评估模型的算法实现

以下是使用 Python 实现格雷厄姆价值评估模型的代码示例：

```python
def calculate_intrinsic_value(net_profit, growth_rate, required_return):
    intrinsic_value = (net_profit * (1 + growth_rate)) / (required_return - growth_rate)
    return intrinsic_value

def calculate_margin_of_safety(market_price, intrinsic_value):
    margin_of_safety = market_price * 0.5  # 假设安全边际系数为0.5
    return margin_of_safety

# 示例数据
net_profit = 1000000  # 净利润（单位：元）
growth_rate = 0.05    # 净利润增长率
required_return = 0.10  # 期望回报率
market_price = 50  # 市场价格（单位：元）

intrinsic_value = calculate_intrinsic_value(net_profit, growth_rate, required_return)
margin_of_safety = calculate_margin_of_safety(market_price, intrinsic_value)

print(f"内在价值: {intrinsic_value}")
print(f"安全边际: {margin_of_safety}")
```
