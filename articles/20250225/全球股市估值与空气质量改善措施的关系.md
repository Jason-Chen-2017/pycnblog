## 第3章：股市估值的核心概念

### 3.1 估值指标
- **市盈率（P/E）**：股价与每股收益的比率。
- **市净率（P/B）**：股价与每股净资产的比率。
- **市值**：公司股票的总价值。

### 3.2 影响因素
- **经济指标**：GDP、利率、通胀。
- **行业趋势**：技术进步、市场需求。
- **公司基本面**：利润、增长潜力。

### 3.3 环境因素的影响
- **环境风险**：政策风险和法律诉讼对企业价值的影响。
- **市场情绪**：投资者对环境政策的反应。

## 第6章：项目实战

### 6.1 环境安装
- 安装Python、Pandas、Matplotlib、Scikit-learn。

### 6.2 核心实现代码
```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

# 数据加载
airquality = pd.read_csv('airquality.csv')
stock_data = pd.read_csv('stock_data.csv')

# 数据预处理
merged_data = pd.merge(airquality, stock_data, on='date')

# 模型构建
model = LinearRegression()
model.fit(merged_data[['AQI']], merged_data['stock_value'])

# 模型预测
predictions = model.predict(merged_data[['AQI']])

# 可视化
plt.scatter(merged_data['AQI'], merged_data['stock_value'])
plt.plot(merged_data['AQI'], predictions, color='red')
plt.xlabel('AQI')
plt.ylabel('Stock Value')
plt.show()
```
