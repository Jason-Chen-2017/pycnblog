    - Python代码实现
    ```python
    import numpy as np
    def linear_regression(X, y, learning_rate=0.01, iterations=1000):
        m = len(X)
        theta = np.zeros((1, X.shape[1]))
        for _ in range(iterations):
            hypothesis = np.dot(theta, X.T)
            loss = (1/(2*m)) * np.sum((hypothesis - y)**2)
            derivative = (1/m) * np.dot(X.T, (hypothesis - y))
            theta -= learning_rate * derivative
        return theta
    ```

    $$ h(x) = \theta^T x $$
