## 第三部分：资本配置的算法原理

### 第4章：资本配置的算法原理

#### 4.1 净现值法（Net Present Value, NPV）

##### 4.1.1 NPV的数学模型
$$NPV = \sum_{t=0}^{n} \frac{C_t}{(1+r)^t}$$
其中，$C_t$是第$t$期的现金流，$r$是贴现率。

##### 4.1.2 NPV算法的流程图（Mermaid）

```mermaid
graph TD
    A[开始] --> B[输入现金流和贴现率]
    B --> C[计算各期现金流现值]
    C --> D[求和得到NPV]
    D --> E[输出结果]
    E --> F[结束]
```

##### 4.1.3 NPV算法的Python实现

```python
def calculate_npv(cash_flows, discount_rate):
    npv = 0
    for t, cash_flow in enumerate(cash_flows):
        npv += cash_flow / (1 + discount_rate) ** t
    return npv

# 示例
cash_flows = [100, 200, 300]
discount_rate = 0.1
print("NPV =", calculate_npv(cash_flows, discount_rate))
```
