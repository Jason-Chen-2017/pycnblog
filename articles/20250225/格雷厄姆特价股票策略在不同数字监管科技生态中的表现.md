## 第1章: 格雷厄姆特价股票策略概述

### 1.1 格雷厄姆投资理论的核心理念
格雷厄姆的价值投资理论强调以低于内在价值的价格买入股票，注重安全边际和长期持有。其核心理念包括：
1. **内在价值计算**：通过基本面分析确定股票的合理价值。
2. **安全边际**：买入价格应远低于内在价值，以降低风险。
3. **长期投资**：避免短期市场波动，关注企业长期价值。

### 1.2 特价股票策略的关键要素
- **市盈率（P/E）**：用于衡量股票价格与盈利之间的关系。
- **内在价值公式**：
  $$\text{内在价值} = \frac{\text{净利润} \times (1 + \text{增长率})}{\text{折现率} - \text{增长率}}$$
- **安全边际**：买入价格与内在价值的折扣比例。

### 1.3 格雷厄姆策略的优缺点分析
- **优势**：风险较低，适合长期投资者。
- **劣势**：在高波动市场中可能表现不佳，且需要大量数据支持。

import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 示例数据加载
data = pd.read_csv('stock_data.csv')

# 内在价值计算
def calculate_intrinsic_value(data):
    # 假设净利润增长率和折现率
    growth_rate = 0.05
    discount_rate = 0.10
    intrinsic_value = (data['净利润'] * (1 + growth_rate)) / (discount_rate - growth_rate)
    return intrinsic_value

# 安全边际计算
def calculate_margin_of_safety(data, intrinsic_value):
    margin = (intrinsic_value - data['股价']) / intrinsic_value
    return margin

# 选股策略
def graham_strategy(data):
    iv = calculate_intrinsic_value(data)
    mos = calculate_margin_of_safety(data, iv)
    # 选择安全边际大于20%的股票
    selected_stocks = data[mos > 0.2]
    return selected_stocks

# 实战应用
selected_stocks = graham_strategy(data)
print(selected_stocks)
