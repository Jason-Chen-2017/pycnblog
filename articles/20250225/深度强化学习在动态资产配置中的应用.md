# 第2章: 深度强化学习基础

## 2.1 深度强化学习的核心概念
### 2.1.1 强化学习基本原理
强化学习通过智能体与环境的交互，学习最优策略。智能体通过试错，根据环境反馈（奖励或惩罚）调整行为，最终实现目标。

### 2.1.2 深度学习在强化学习中的应用
深度学习擅长处理高维数据，强化学习通过深度神经网络近似策略或价值函数，显著提升了处理复杂问题的能力。

### 2.1.3 深度强化学习的核心算法
- **Q-learning**：基于值函数的方法，通过Q表记录状态-动作对的最优价值。
- **策略梯度方法**：直接优化策略，通过梯度上升更新参数。
- **Deep Q-Network (DQN)**：结合Q-learning与深度学习，使用神经网络近似Q函数。

## 2.2 常见的深度强化学习算法
### 2.2.1 Q-learning与深度Q网络
**Q-learning**通过状态-动作空间的学习，找到最优策略。深度Q网络（DQN）通过神经网络近似Q函数，解决了高维状态空间的问题。

**代码示例**：
```python
import numpy as np
import gym

env = gym.make('CartPole-v0')
env.seed(123)
np.random.seed(123)

class DQN:
    def __init__(self, state_size, action_size, learning_rate):
        self.state_size = state_size
        self.action_size = action_size
        self.lr = learning_rate
        self.Q = np.zeros((state_size, action_size))
    
    def act(self, state):
        return np.argmax(self.Q[state])
    
    def learn(self, state, action, reward, next_state):
        self.Q[state][action] += self.lr * (reward + np.max(self.Q[next_state]) - self.Q[state][action])
```

### 2.2.2 策略梯度方法
策略梯度方法直接优化策略，通过梯度上升更新参数，代表算法包括**PPO**（Proximal Policy Optimization）和**A3C**（Asynchronous Advantage Actor-Critic）。

**代码示例**：
```python
import tensorflow as tf

class Actor:
    def __init__(self, state_dim, action_dim, lr):
        self.state_dim = state_dim
        self.action_dim = action_dim
        self.lr = lr
        self.Actor = self.build_actor()
    
    def build_actor(self):
        inputs = tf.keras.Input(shape=(self.state_dim,))
        x = tf.keras.layers.Dense(64, activation='relu')(inputs)
        x = tf.keras.layers.Dense(64, activation='relu')(x)
        outputs = tf.keras.layers.Dense(self.action_dim, activation='softmax')(x)
        model = tf.keras.Model(inputs=inputs, outputs=outputs)
        model.compile(optimizer=tf.keras.optimizers.Adam(self.lr))
        return model
```

## 3.1 动态资产配置的背景
动态资产配置是指根据市场环境的变化，实时调整资产组合的配置比例。其核心在于捕捉市场波动，优化投资收益。

## 3.2 动态资产配置的核心问题
动态资产配置需要解决以下问题：
1. **状态定义**：如何定义市场状态（如市场趋势、波动性）。
2. **动作选择**：如何选择最优的资产配置比例。
3. **奖励机制**：如何设计奖励函数，引导模型追求最大收益。

## 3.3 传统动态资产配置方法
传统方法包括**均值-方差优化**和**风险平价法**，但这些方法在面对复杂市场时表现有限。

6. 状态更新：更新市场状态。
7. 学习更新：更新Q网络参数。

### 5.1.2 代码实现
```python
class AssetAllocationDQN:
    def __init__(self, state_size, action_size, lr):
        self.state_size = state_size
        self.action_size = action_size
        self.lr = lr
        self.model = self.build_model()
        self.target_model = self.build_model()
        self.update_target()

    def build_model(self):
        model = tf.keras.Sequential()
        model.add(tf.keras.layers.Dense(64, activation='relu', input_dim=self.state_size))
        model.add(tf.keras.layers.Dense(64, activation='relu'))
        model.add(tf.keras.layers.Dense(self.action_size, activation='linear'))
        model.compile(loss='mse', optimizer=tf.keras.optimizers.Adam(self.lr))
        return model

    def act(self, state):
        state = np.array([state])
        predictions = self.model.predict(state)
        return np.argmax(predictions[0])

    def update_target(self):
        self.target_model.set_weights(self.model.get_weights())

    def learn(self, state, action, reward, next_state):
        state = np.array([state])
        next_state = np.array([next_state])
        target = self.model.predict(state)
        next_q = self.target_model.predict(next_state)
        target[0][action] = reward + np.max(next_q)
        self.model.fit(state, target, epochs=1, verbose=0)
        self.update_target()
```
