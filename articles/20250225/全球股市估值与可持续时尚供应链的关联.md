# 第2章: 全球股市估值的理论基础

## 2.1 资产定价模型
### 2.1.1 CAPM模型
$$ E(R_i) = R_f + \beta_i (E(R_m) - R_f) $$
- $E(R_i)$：资产的预期收益率
- $R_f$：无风险利率
- $\beta_i$：资产的系统性风险系数
- $E(R_m)$：市场预期收益率

### 2.1.2 APT模型
$$ E(R_i) = \sum_j \lambda_j \beta_{i,j} $$
- $\lambda_j$：因子的定价因子
- $\beta_{i,j}$：资产对因子的敏感度

### 2.1.3 市场风险与非系统性风险
- 市场风险：影响整个市场的风险
- 非系统性风险：特定资产的风险

## 2.2 股市估值方法
### 2.2.1 市盈率法
$$ P/E = \frac{Market\ Price}{Earnings\ Per\ Share} $$
- 低P/E比率可能表示低估，高P/E可能表示高估。

### 2.2.2 市净率法
$$ P/B = \frac{Market\ Price}{Book\ Value\ Per\ Share} $$
- 用于评估资产密集型企业的价值。

### 2.2.3 现金流折现法
$$ V = \sum_{t=1}^{\infty} \frac{CF_t}{(1 + r)^t} $$
- $V$：企业价值
- $CF_t$：未来现金流
- $r$：折现率

## 2.3 ESG投资理论
### 2.3.1 环境、社会和治理（ESG）的概念
- 环境：减少碳足迹、资源节约
- 社会：劳工权益、社区责任
- 治理：企业透明度、领导层责任

### 2.3.2 ESG对股市估值的影响
- 提高企业声誉，降低风险，提升股价。

### 2.3.3 可持续投资的回报分析
- 长期回报可能更高，但短期波动较大。

import numpy as np

def calculate_esg_score(company_data):
    esg_scores = []
    for index, row in company_data.iterrows():
        environmental = row['Environmental']
        social = row['Social']
        governance = row['Governance']
        total = environmental + social + governance
        esg_scores.append(total)
    return pd.Series(esg_scores, index=company_data.index)
