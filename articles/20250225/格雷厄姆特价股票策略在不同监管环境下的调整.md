## 第一部分: 引言

### 第1章: 格雷厄姆价值投资理论基础

#### 1.1 格雷厄姆价值投资的核心理念
格雷厄姆的价值投资理论强调以低于内在价值的价格购买优质股票，通过长期持有实现财富增值。其核心理念包括：
- **安全边际**: 购买价格低于内在价值，以降低风险。
- **市场先生**: 市场价格波动反映市场情绪而非真实价值。
- ** cigar butt 投资**: 寻找被市场遗忘的“烟蒂”股票，挖掘潜在价值。

#### 1.2 特价股票的定义与特征
- **定义**: 特价股票是指市场价格低于其内在价值的股票。
- **特征**: 低估值、高分红率、稳定的财务状况。

#### 4.2 核心实现源代码

```python
import pandas as pd
import numpy as np

def graham_strategy(stocks, market_value, regulation_impact):
    # 计算内在价值
    intrinsic_value = (market_value * (1 - regulation_impact)) 
    # 筛选特价股票
    undervalued_stocks = stocks[market_value < intrinsic_value]
    return undervalued_stocks

# 示例数据
stocks = pd.DataFrame({
    'stock_id': [1, 2, 3],
    'market_value': [50, 60, 40],
    'intrinsic_value': [60, 50, 45]
})

regulation_impact = 0.1  # 假设监管影响为10%
result = graham_strategy(stocks, 'market_value', regulation_impact)
print(result)
```
