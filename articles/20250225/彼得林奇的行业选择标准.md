# 第1章: 投资概述

## 1.1 彼得林奇及其投资方法

### 1.1.1 彼得林奇的生平简介

彼得·林奇（Peter Lynch）是美国著名的投资专家，曾任富达投资集团麦哲伦基金的经理。他在投资领域有着卓越的成就，以其独特的投资方法闻名。林奇的投资哲学强调长期投资和基本面分析，主张选择那些具有竞争优势和良好财务状况的公司。

### 1.1.2 彼得林奇的投资哲学

林奇的投资哲学基于以下几点：
1. **长期投资**：他认为投资者应该长期持有优质股票，避免频繁交易。
2. **基本面分析**：通过分析公司的财务报表和行业趋势，选择具有竞争优势的公司。
3. **分散投资**：避免将所有资金投入到单一行业或公司，以降低风险。

### 1.1.3 彼得林奇的成功案例

林奇管理麦哲伦基金期间，基金取得了显著的业绩。他成功投资了多家公司，如英特尔、微软等，这些公司的股价长期上涨，为投资者带来了丰厚的回报。

# 第3章: 行业选择标准的核心要素

## 3.1 行业选择的基本原则

### 3.1.1 行业的生命周期分析

行业通常经历初创期、成长期、成熟期和衰退期。投资者应选择处于成长期或成熟期的行业。

### 3.1.2 行业的竞争结构分析

分析行业内的竞争格局，选择具有竞争优势的公司。

### 3.1.3 行业的未来发展趋势

研究行业的发展趋势，选择具有增长潜力的行业。

---

## 3.2 财务指标分析

### 3.2.1 财务指标的定义与分类

财务指标包括盈利能力、成长能力、偿债能力等。

### 3.2.2 主要财务指标的计算公式

- 净利润：净利润 = 收入 - 成本 - 费用
- 营业利润率：营业利润率 = 净利润 / 营业收入
- 资产负债率：资产负债率 = 负债总额 / 资产总额

### 3.2.3 财务指标在行业选择中的应用

通过分析公司的财务指标，评估其财务健康状况和盈利能力。

---

## 3.3 行业竞争优势分析

### 3.3.1 竞争优势的定义

竞争优势是指公司在行业内相对于竞争对手的独特优势，如技术优势、成本优势等。

### 3.3.2 竞争优势的来源

- 技术创新：公司拥有独特的技术或专利。
- 成本优势：公司具有更低的生产成本。
- 市场地位：公司在市场中占据领先地位。

### 3.3.3 竞争优势的评估方法

通过分析公司的市场份额、技术创新和成本结构，评估其竞争优势。

def calculate_profitability_ratios(df):
    df['营业利润率'] = df['净利润'] / df['营业收入']
