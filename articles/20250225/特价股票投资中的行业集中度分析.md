## 第1章: 特价股票投资与行业集中度分析概述

### 1.1 特价股票投资的定义与特点

#### 1.1.1 特价股票的定义
特价股票指的是价格相对较低的股票，通常具有较高的市净率（P/B）或市盈率（P/E）比率，被认为被市场低估的股票。

#### 1.1.2 特价股票投资的核心特点
- 价格低廉：相对于内在价值，股票价格处于低位。
- 投资机会：可能隐藏着未被市场发现的投资价值。
- 风险较高：通常存在于经营不佳或被市场忽视的公司。

#### 1.1.3 特价股票投资的潜在机会与风险
- 机会：可能发现市场低估的股票，获得超额收益。
- 风险：公司基本面可能存在问题，导致股价持续低迷。

### 1.2 行业集中度分析的定义与意义

#### 1.2.1 行业集中度的定义
行业集中度是指行业内主要企业的市场份额集中程度，通常用CR4（前4大企业市场份额之和）和CR8（前8大企业市场份额之和）来衡量。

#### 1.2.2 行业集中度分析的重要性
- 识别市场主导企业：高集中度行业通常由少数几家企业主导。
- 评估行业竞争状况：低集中度行业竞争激烈，市场波动大。
- 投资决策支持：行业集中度高的行业可能更稳定，适合长期投资。

#### 1.2.3 行业集中度与投资策略的关系
行业集中度影响投资策略，高集中度行业适合选择龙头公司，低集中度行业适合寻找市场黑马。

### 1.3 特价股票投资中的行业集中度分析

#### 1.3.1 特价股票与行业集中度的关联
特价股票可能出现在低集中度行业，行业内的小公司可能因为价格低廉而被视为投资机会。

#### 1.3.2 行业集中度对投资决策的影响
高集中度行业可能更稳定，而低集中度行业可能有更多低价股票，但风险也更大。

#### 1.3.3 特价股票投资中的行业集中度分析方法
结合行业集中度指标和股票价格分析，寻找低估的股票。

### 1.4 本章小结
本章介绍了特价股票和行业集中度的基本概念，强调了行业集中度在投资决策中的重要性，并为后续分析奠定了基础。

## 第2章: 行业集中度分析的核心概念与原理

### 2.1 行业集中度的衡量指标

#### 2.1.1 CR4、CR8等集中度指标
CR4：前4大企业的市场份额之和。
CR8：前8大企业的市场份额之和。

#### 2.1.2 行业集中度指标的优缺点对比
| 指标 | 优点 | 缺点 |
|------|------|------|
| CR4 | 简单易计算，能快速反映行业集中度 | 可能忽略小企业的市场影响力 |
| CR8 | 更全面，考虑更多企业 | 计算复杂，数据需求高 |

#### 2.1.3 行业集中度指数的计算公式
$$CR_n = \sum_{i=1}^{n} market\_share_i$$

### 2.2 行业集中度分析的数学模型

#### 2.2.1 行业集中度指数的计算公式
$$CR_n = \sum_{i=1}^{n} market\_share_i$$

#### 2.2.2 行业集中度与市场结构的关系
- 高集中度市场：CR4和CR8较高，市场由少数企业主导。
- 低集中度市场：CR4和CR8较低，市场竞争激烈。

- 加权平均法：根据公司规模加权计算市场份额。

### 3.2 行业集中度分析的算法原理

#### 3.2.1 基于熵值法的行业集中度计算
熵值法是一种客观赋权方法，用于计算行业集中度指数。其步骤如下：

1. 收集行业内的市场份额数据。
2. 计算各企业的市场份额比例。
3. 计算各企业的熵值。
4. 根据熵值计算权重。
5. 计算行业集中度指数。

#### 3.2.2 基于因子分析法的行业集中度评估
因子分析法通过分析影响行业集中度的多个因素，提取主因子来评估集中度。步骤如下：

1. 确定影响集中度的因素，如市场份额、企业规模等。
2. 进行因子分析，提取主因子。
3. 根据主因子得分计算集中度指数。

#### 3.2.4 行业集中度分析的Python代码示例
```python
import pandas as pd
import numpy as np

# 数据收集与处理
market_share = [0.25, 0.15, 0.1, 0.05, 0.03, 0.02, 0.01, 0.01, 0.01, 0.01]
n = len(market_share)

# 计算熵值
entropy = 0
for i in market_share:
    if i != 0:
        entropy += (-i) * np.log2(i)
entropy = entropy / n

# 计算权重
weights = [np.exp(-entropy * i) for i in range(n)]

# 计算行业集中度指数
CR4 = sum(market_share[:4])
CR8 = sum(market_share[:8])
```
