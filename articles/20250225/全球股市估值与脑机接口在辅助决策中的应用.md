## 第2章：全球股市估值基础

### 2.1 股市估值的核心概念

股市估值是通过对公司财务数据、市场趋势和行业环境的分析，评估股票的内在价值。传统估值方法包括市盈率（P/E）、市净率（P/B）和股息率等指标，但这些方法往往忽视了投资者情绪和市场参与者的心理预期。

#### 图表：股市估值的关键指标对比

| 指标名称 | 计算公式 | 适用场景 | 局限性 |
|----------|----------|----------|--------|
| 市盈率    | P/E = 价格 / 每股收益 | 评估股票的相对价值 | 受会计准则影响 |
| 市净率    | P/B = 价格 / 每股净资产 | 评估资产密集型行业 | 无法反映收益能力 |
| 股息率    | Dividend Yield = 每股股息 / 股票价格 | 评估股息支付能力 | 适用于成熟市场 |

### 2.2 数据来源与特征分析

股市数据的获取与处理是估值的基础。数据来源包括历史价格、成交量、财务报表等。特征分析则需要提取这些数据中的有用信息，例如趋势、波动性和周期性特征。

### 3.1 脑机接口的基本原理

脑机接口是一种将大脑信号转化为控制指令的技术，其核心是采集和处理神经信号。常用的信号类型包括EEG（脑电图）和fMRI（功能性磁共振成像）。脑机接口的应用场景包括医疗康复、游戏控制和辅助决策。

### 7.2 核心代码实现

以下是一个基于EEG数据的回归模型实现：

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 假设X为EEG特征，y为股票价格
X = np.array([[1, 2], [3, 4], [5, 6]])
y = np.array([10, 20, 30])

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测
y_pred = model.predict(X)
print("预测值:", y_pred)
print("均方误差:", mean_squared_error(y, y_pred))
```
