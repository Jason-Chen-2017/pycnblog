## 第3章: 投资组合优化的数学模型

### 3.1 投资组合优化的数学模型

#### 3.1.1 最优化问题的建立

- 目标函数：最大化收益或最小化风险。
- 约束条件：如资产比例限制、风险承受等。

#### 3.1.2 常用目标函数与约束条件

- 收益最大化：maximize return.
- 风险最小化：minimize variance.

#### 3.1.3 数学模型的求解方法

- 常用优化算法：如拉格朗日乘数法。

### 3.2 投资组合优化的算法实现

#### 3.2.1 算法流程图（使用 Mermaid）

```mermaid
graph TD
A[开始] --> B[收集数据]
B --> C[计算收益和风险]
C --> D[建立优化模型]
D --> E[求解模型]
E --> F[输出结果]
```

#### 3.2.2 Python代码示例

```python
import numpy as np
from scipy.optimize import minimize

# 示例数据
returns = np.array([0.1, 0.15, 0.05])

def portfolio_variance(weights):
    return np.dot(weights.T, np.dot(np.diag(returns), weights))

# 初始权重
initial_guess = np.array([1/3, 1/3, 1/3])

# 约束条件
cons = ({'type': 'eq', 'fun': lambda w: sum(w) - 1})

# 求解
result = minimize(portfolio_variance, initial_guess, constraints=cons)

print("最优权重:", result.x)
```

### 3.3 数学模型的解释

#### 3.3.1 优化问题的数学表达

$$
\text{minimize } w^T \Sigma w \\
\text{subject to } 1^T w = 1
$$

其中，$w$ 是权重向量，$\Sigma$ 是协方差矩阵。
