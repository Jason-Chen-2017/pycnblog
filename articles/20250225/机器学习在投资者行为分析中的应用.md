# 第1章: 机器学习与投资者行为分析概述

## 1.1 机器学习的基本概念

### 1.1.1 机器学习的定义与核心概念  
机器学习是一种人工智能技术，通过数据训练模型，使其能够从经验中学习并做出预测或决策。其核心概念包括：  
- **监督学习**：基于标记数据的训练，预测目标变量。  
- **非监督学习**：在无标签数据中发现模式。  
- **强化学习**：通过与环境交互，学习最优策略。  

### 1.1.2 机器学习的分类与特点  
机器学习主要分为三类：  
1. **监督学习**：如线性回归、支持向量机（SVM）。  
2. **非监督学习**：如聚类分析、主成分分析（PCA）。  
3. **强化学习**：如Q-learning、深度强化学习。  

### 1.1.3 机器学习在金融领域的应用前景  
在金融领域，机器学习广泛应用于股票价格预测、风险评估、投资组合优化等场景。其优势在于能够处理大量非结构化数据，发现隐藏的模式。

import numpy as np

# 读取数据
data = pd.read_csv('investor_behavior.csv')

from sklearn.preprocessing import StandardScaler

---

### 6.2.2 模型训练代码  
```python
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(scaled_data, data['label'], test_size=0.2)

# 训练随机森林模型
model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)

# 预测结果
y_pred = model.predict(X_test)
print("准确率:", accuracy_score(y_test, y_pred))
```
