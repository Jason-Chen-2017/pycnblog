# 第三部分: 加拿大股市估值的数学模型与算法

## 第3章: 常用的股票估值模型

### 3.1 市盈率模型

#### 3.1.1 市盈率的定义
市盈率（P/E）是股票价格与每股收益的比率，用于衡量股票的估值。

#### 3.1.2 市盈率的计算公式
$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$

#### 3.1.3 市盈率的应用实例
假设某公司股价为100元，每股收益为10元，市盈率为10倍。

### 3.2 市净率模型

#### 3.2.1 市净率的定义
市净率（P/B）是股票价格与每股净资产的比率，适用于资产密集型行业。

#### 3.2.2 市净率的计算公式
$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

#### 3.2.3 市净率的应用实例
假设某公司股价为50元，每股净资产为25元，市净率为2倍。

### 3.3 股息率模型

#### 3.3.1 股息率的定义
股息率是每股股息与股价的比率，用于衡量股票的分红能力。

#### 3.3.2 股息率的计算公式
$$ \text{股息率} = \frac{\text{每股股息}}{\text{股价}} \times 100\% $$

#### 3.3.3 股息率的应用实例
假设某公司股息为2元，股价为50元，股息率为4%。

### 3.4 内在价值法

#### 3.4.1 内在价值法的定义
内在价值法通过分析公司的未来现金流，计算其合理价格。

#### 3.4.2 内在价值法的数学模型
$$ V = \frac{CF}{(1 + r)^n} $$
其中，CF为未来现金流，r为折现率，n为时间。

### 3.5 本章小结
本章介绍了常用的股票估值模型，并通过实例分析了它们的应用。内在价值法是较为复杂的模型，适用于长期投资者。

### 5.2 核心实现

#### 5.2.1 股票估值代码示例
```python
import pandas as pd

def calculate_pe(df):
    pe = df['股价'] / df['每股收益']
    return pe.mean()

def calculate_pb(df):
    pb = df['股价'] / df['每股净资产']
    return pb.mean()

# 示例数据
data = {
    '股价': [100, 50, 75],
    '每股收益': [10, 5, 7.5],
    '每股净资产': [20, 10, 15]
}
df = pd.DataFrame(data)

pe = calculate_pe(df)
pb = calculate_pb(df)

print(f"平均市盈率: {pe}")
print(f"平均市净率: {pb}")
```
