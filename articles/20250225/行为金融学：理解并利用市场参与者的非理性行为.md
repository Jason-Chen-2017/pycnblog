# 第一部分: 行为金融学基础

## 第1章: 行为金融学概述

### 1.1 行为金融学的定义与研究对象
行为金融学通过分析市场参与者的非理性行为，揭示其对资产定价和投资决策的影响。核心概念包括认知偏差、情绪影响和群体心理，其研究目标是理解非理性行为的规律。

### 1.2 行为金融学与传统金融学的区别
- 传统金融学假设参与者是理性的，而行为金融学关注非理性因素。
- 行为金融学强调情绪和认知偏差，传统金融学基于理性假设。

### 1.3 行为金融学的研究意义
通过理解非理性行为，改善投资决策和风险管理，提高市场效率。

---

## 第2章: 非理性行为的特征与分类

### 2.1 认知偏差与行为偏差
认知偏差包括确认偏差、损失厌恶，行为偏差包括过度自信和从众行为。认知偏差影响决策，行为偏差影响市场行为。

### 2.2 情感与情绪对决策的影响
情感在投资中起重要作用，情绪周期影响市场波动，如过度乐观导致泡沫。

### 2.3 群体心理与市场行为
群体心理引发羊群效应，情绪传播影响市场，群体决策有利弊。

# 第二部分: 行为金融学的核心理论

## 第3章: 行为金融学的核心理论

### 3.1 基于 prospect theory 的决策模型
Propect理论由Kahneman和Tversky提出，公式为：
$$V = \sum_{i=1}^n w_i v_i$$
其中，权重函数描述概率感知。

### 3.2 有限理性与 bounded rationality
有限理性模型由Simon提出，考虑认知限制，适用于复杂决策。

### 3.3 情绪驱动的决策模型
情绪指数如NAC指数量化市场情绪，影响资产定价。

# 第三部分: 行为金融学的数学模型与实证分析

## 第4章: 数学模型与实证分析

### 4.1 基于 prospect theory 的数学模型
公式：
$$P(p, x) = \sum_{i=1}^n w_i(p) v(x_i)$$
模型通过实验数据验证，显示投资者对损失更敏感。

### 4.2 情绪驱动的数学模型
情绪指数模型：
$$M_t = \alpha M_{t-1} + \beta E_t$$
用于预测市场情绪。

### 4.3 认知偏差的数学模型
认知偏差模型：
$$D = \sum_{i=1}^n b_i c_i$$
量化认知偏差。
