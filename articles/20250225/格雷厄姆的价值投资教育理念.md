# 第2章: 价值投资的核心概念与联系

## 2.1 核心概念原理  
- 2.1.1 安全边际的数学模型  
  - 安全边际公式：$ \text{安全边际} = V - P $  
  - $V$为内在价值，$P$为市场价格  

- 2.1.2 内在价值的计算公式  
  - DCF模型：$ V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $  
  - $CF_t$为第t年的现金流，$r$为折现率  

- 2.1.3 市场波动与投资者情绪的关系  
  - 市场先生的波动性对投资者决策的影响  

---

## 2.2 核心概念属性特征对比表格  
| 概念       | 安全边际 | 内在价值 | 市场先生 |  
|------------|----------|----------|----------|  
| 定义       | 投资者以低于内在价值的价格买入股票的安全空间 | 股票的公允价值 | 市场价格受投资者情绪影响 |  
| 计算公式   | $\text{安全边际} = V - P$ | $V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$ | 市场价格 = 投资者心理定价 |

import pandas as pd
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate):
    return np.npv(discount_rate, cash_flows[1:], cash_flows[0])

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例数据
cash_flows = [100, 120, 150, 200]
discount_rate = 0.10

IV = calculate_intrinsic_value(cash_flows, discount_rate)
MS = calculate_margin_of_safety(IV, 90)

print(f"安全边际: {MS:.2f}")
