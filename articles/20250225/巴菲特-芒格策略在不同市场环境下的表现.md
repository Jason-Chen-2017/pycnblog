## 第1章: 巴菲特-芒格策略的背景与核心思想

### 1.1 巴菲特与芒格的投资哲学

#### 1.1.1 巴菲特的生平与投资理念
巴菲特（Warren Buffett）是全球最著名的投资者之一，他的投资哲学以“价值投资”为核心。他强调寻找具有持续竞争优势的企业，并以合理的价格买入并长期持有。巴菲特的投资理念可以总结为以下几点：
- **安全边际**：买入价格低于内在价值，确保足够的安全空间。
- **竞争优势**：选择具有强大护城河的企业，能够持续创造价值。
- **长期视角**：关注企业的长期盈利能力，而非短期市场波动。

#### 1.1.2 芒格的智慧与决策思维
芒格（Charlie Munger）是巴菲特的长期合作伙伴，他的决策思维强调理性、逻辑和逆向思考。芒格认为，投资者应该避免情绪化决策，并专注于寻找那些“击倒球”（即容易获胜的投资机会）。芒格的思想弥补了巴菲特在微观分析上的不足，使两人形成了独特的投资组合。

#### 1.1.3 巴菲特-芒格策略的核心思想
巴菲特和芒格的策略结合了基本面分析和心理因素，形成了以下核心思想：
- **价值与价格的分离**：市场短期是投票器，长期是称重机。
- **逆向思维**：在市场恐慌时买入，在市场狂热时卖出。
- **安全边际**：确保投资的安全性，追求确定性收益。

## 第2章: 巴菲特-芒格策略的数学模型与分析方法

### 2.1 价值投资的数学模型

#### 2.1.1 股票内在价值的计算公式
巴菲特的内在价值计算公式如下：
$$
\text{内在价值} = \sum_{t=1}^{\infty} \frac{\text{现金流}_t}{(1 + r)^t}
$$
其中，$r$ 是投资者要求的收益率，$\text{现金流}_t$ 是第 $t$ 年的自由现金流。

#### 2.1.2 安全边际的计算公式
安全边际是内在价值与市场价格之间的差值：
$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

#### 2.1.3 市盈率与市净率的对比分析
市盈率（P/E）和市净率（P/B）是常用的估值指标：
- 市盈率：$$\text{P/E} = \frac{\text{股价}}{\text{每股收益}}$$
- 市净率：$$\text{P/B} = \frac{\text{股价}}{\text{每股净资产}}$$

### 4.1 安全边际计算算法

```python
def calculate_intrinsic_value(cash_flows, discount_rate):
    iv = 0
    for t in range(len(cash_flows)):
        iv += cash_flows[t] / (1 + discount_rate) ** t
    return iv

def calculate_margin_of_safety(iv, market_price):
    return iv - market_price
```
