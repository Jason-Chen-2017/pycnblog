### 1.1 格雷厄姆特价股票理论的背景与意义

#### 1.1.1 价值投资的起源与发展
价值投资是一种长期投资策略，起源于20世纪初，由本杰明·格雷厄姆和戴维·多德共同提出。格雷厄姆在《 Intelligent Investor》中强调，投资者应寻找那些市场价格低于其内在价值的股票，即“特价股票”。这种理论的核心在于通过深入分析企业的财务状况和市场估值，寻找被市场低估的投资标的。

#### 1.1.2 格雷厄姆投资理念的核心思想
格雷厄姆的价值投资理论强调以下几点：
1. **安全边际**：投资者应购买那些市场价格远低于其内在价值的股票，以确保投资的安全性。
2. **内在价值**：内在价值是股票的真正价值，与市场波动无关，可以通过对企业财务状况的分析来估算。
3. **长期投资**：价值投资是一种长期策略，投资者应耐心等待市场回归其内在价值。

#### 1.1.3 特价股票理论在绿色金融中的适用性

#### 6.2.2 数据分析
```python
# 计算企业的ESG得分

```

#### 6.2.3 投资标的筛选
```python
# 筛选出ESG得分高于80的企业

```

#### 6.2.4 内在价值评估
```python
# 计算企业的内在价值
def calculate_intrinsic_value(revenue, net_profit):
    return revenue * (net_profit / 100)
selected_companies['内在价值'] = selected_companies['营业收入'].apply(lambda x: calculate_intrinsic_value(x, selected_companies['净利润']))
```

#### 6.2.5 安全边际计算
```python
# 计算股票的安全边际
selected_companies['安全边际'] = selected_companies['市场价格'] * (1 + (selected_companies['内在价值'] - selected_companies['市场价格']) / selected_companies['内在价值'])
```

#### 6.2.6 投资决策
```python
# 选择安全边际大于市场价格的企业
investment_portfolio = selected_companies[selected_companies['安全边际'] > selected_companies['市场价格']]
```
