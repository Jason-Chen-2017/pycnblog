## 第1章: 引言

### 1.1 问题背景
随着金融市场的波动加剧和技术的进步，传统投资策略面临新的挑战。格雷厄姆的价值投资理论虽经典，但在数字化转型的背景下需重新审视其应用。

### 1.2 核心概念
- **格雷厄姆理论**：寻找市场价格低于内在价值的股票，强调安全边际。
- **再生金融**：利用新技术如区块链优化金融市场，提升效率和透明度。

## 第2章: 核心概念与理论框架

### 2.1 格雷厄姆理论的核心要素
- **内在价值**：股票的真实价值，与市场价可能偏离。
- **安全边际**：市场价格低于内在价值的部分，降低投资风险。

### 2.2 再生金融的特征
- **技术创新**：区块链、大数据提升金融效率。
- **透明化**：智能合约确保交易透明，降低信任成本。

def calculate_intrinsic_value(stock_data):
    # 假设stock_data包含市盈率和市净率等信息
    # 计算内在价值
    intrinsic_value = stock_data['eps'] * 10  # 示例计算
    return intrinsic_value

def select_undervalued_stocks(intrinsic_values, market_prices):
    undervalued = []
    for i in range(len(intrinsic_values)):
        if intrinsic_values[i] > market_prices[i]:
            undervalued.append(i)
    return undervalued
