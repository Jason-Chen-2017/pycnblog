### 第1章：彼得林奇与周期性行业投资概述

#### 1.1 彼得林奇投资理念的核心思想

- **1.1.1 彼得林奇的生平与投资风格**  
  彼得·林奇是全球著名投资家，以价值投资和深入研究企业基本面著称。他的投资理念强调长期持有优质企业股票，避免短期市场波动的干扰。

- **1.1.2 周期性行业的定义与特点**  
  周期性行业是指那些需求和供给随经济周期波动而显著变化的行业，如制造业、房地产、汽车等。这些行业的业绩表现往往与宏观经济波动密切相关。

- **1.1.3 彼得林奇对周期性行业的关注点**  
  彼得林奇关注周期性行业的低谷期投资机会，寻找那些在行业周期底部时具有低估价值的企业。

---

#### 1.2 周期性行业的基本分析框架

- **1.2.1 行业周期的四个阶段**  
  1. **衰退期**：行业需求下降，企业盈利能力减弱。  
  2. **复苏期**：需求逐步恢复，企业利润开始回升。  
  3. **增长期**：行业需求强劲，企业利润高速增长。  
  4. **成熟期**：行业需求稳定，企业利润趋于平稳。

- **1.2.2 影响周期性行业的关键因素**  
  - 宏观经济指标（GDP增长率、利率、通货膨胀率）  
  - 行业供需关系  
  - 政府政策（如税收、补贴、行业监管）  

- **1.2.3 周期性行业的财务特征**  
  - 利润波动性大  
  - 资产周转率高  
  - 估值受周期影响显著

### 第2章：周期性行业的核心概念与联系

#### 2.1 核心概念与原理

- **2.1.1 周期性行业的基本属性**  
  周期性行业的需求弹性较大，容易受到经济波动的影响。企业的盈利能力随周期波动而变化。

- **2.1.2 彼得林奇投资策略的数学模型**  
  彼得林奇的价值投资模型可以通过以下公式简化：  
  $$\text{内在价值} = \frac{\text{未来现金流}}{\text{折现率}}$$  
  该模型强调对企业未来现金流的预测和估值。

- **3.1.2 核心代码实现**  
  以下是一个简化的企业估值算法示例：  
  ```python
  def calculate_intrinsic_value(enterprise):
      # 假设enterprise包含未来现金流和折现率
      cash_flows = enterprise['future_cash_flows']
      discount_rate = enterprise['discount_rate']
      
      # 计算现值
      present_value = sum(cash_flow / (1 + discount_rate)**i for i, cash_flow in enumerate(cash_flows))
      return present_value
  ```
