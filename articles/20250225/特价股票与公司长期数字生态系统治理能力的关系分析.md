#### 附录B：完整代码实现

##### B.1 数据预处理代码
```python
import pandas as pd
import numpy as np
from sklearn.decomposition import FactorAnalysis
import matplotlib.pyplot as plt
import seaborn as sns

# 读取数据
data = pd.read_csv('governance_data.csv')

# 删除缺失值
data = data.dropna()

# 标准化处理
data = (data - data.mean()) / data.std()
```

##### B.2 因子分析代码
```python
# 因子分析
fa = FactorAnalysis(n_components=3)
fa.fit(data)

# 提取因子得分
factor_scores = fa.transform(data)

# 可视化因子得分
plt.figure(figsize=(10, 6))
sns.heatmap(factor_scores, cmap='viridis', annot=False)
plt.title('Factor Scores Heatmap')
plt.show()
```

##### B.3 结果分析与可视化
```python
# 绘制因子载荷图
plt.figure(figsize=(10, 6))
sns.barplot(x=np.arange(factor_scores.shape[1]), y=np.mean(factor_scores, axis=0))
plt.title('Factor Scores Distribution')
plt.show()
```
