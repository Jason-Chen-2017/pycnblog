### 教育不平等的数学模型举例
以下是一个简单但具有代表性的教育不平等数学模型：

$$
\text{教育不平等指数} = \frac{\sum_{i=1}^{N} (X_i - \bar{X})^2}{N}
$$

其中，$X_i$ 表示第 $i$ 个个体的教育资源或教育成果，$\bar{X}$ 表示平均教育资源或教育成果，$N$ 表示个体总数。

### 源代码实现
以下是一个简单的Python代码示例，用于计算教育不平等指数：

```python
import numpy as np

def calculate_inequality_index(data):
    mean_value = np.mean(data)
    variance = np.sum([(x - mean_value) ** 2 for x in data]) / len(data)
    return variance

# 示例数据
data = [80, 70, 60, 50, 40]
inequality_index = calculate_inequality_index(data)
print("教育不平等指数：", inequality_index)
```

### 代码解读与分析
代码首先计算了数据的平均值，然后计算了每个数据点与平均值的差的平方和，最后除以数据点的数量，得到教育不平等指数。
