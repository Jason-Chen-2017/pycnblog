## 数学图论的基本概念

### 图的定义与基本术语

图是由一组顶点和连接这些顶点的边组成的结构。在图论中，顶点表示实体，边表示实体之间的关系。基本术语包括：

- 顶点（Vertex）：图中的基本元素，表示一个实体。
- 边（Edge）：连接两个顶点的线段，表示两个实体之间的关系。
- 路径（Path）：顶点序列，其中任意两个相邻顶点之间都有边相连。
- 回路（Cycle）：路径中第一个顶点和最后一个顶点相同，且路径上的边不重复。

### 图的基本性质

图的基本性质包括：

- 连通性：图中任意两个顶点之间存在路径。
- 度数：顶点所连接的边的数量。
- 直径：图中任意两个顶点之间最长的路径长度。
- 路径长度：顶点序列中边的数量。

这些性质对于分析图的结构和关系具有重要意义。

### 图的基本算法

图的基本算法包括：

- 遍历算法：用于遍历图的所有顶点和边。
- 最短路径算法：找到图中两个顶点之间的最短路径。
- 最大流算法：找到图中源点和汇点之间的最大流量。
- 最小生成树算法：找到图中包含所有顶点且边数最少的树。

这些算法为解决图相关的问题提供了有效的工具。

#### 最短路径算法

- **Dijkstra算法**：找到图中两个顶点之间的最短路径。

```python
import heapq

def dijkstra(graph, start):
    distances = {vertex: float('infinity') for vertex in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)

        if current_distance != distances[current_vertex]:
            continue

        for neighbor, weight in graph[current_vertex].items():
            distance = current_distance + weight

            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

import numpy as np
import matplotlib.pyplot as plt

# 宇宙模拟参数
num_stars = 100
steps = 100
time_step = 1

# 初始化星体位置
positions = np.random.rand(num_stars, 2) * 100

# 宇宙模拟
for _ in range(steps):
    # 计算引力
    forces = np.zeros((num_stars, 2))
    for i in range(num_stars):
        for j in range(num_stars):
            if i != j:
                distance = positions[i] - positions[j]
                distance = np.linalg.norm(distance)
                force = -1 * distance
                forces[i] += force

    # 更新星体位置
    positions += forces * time_step

# 绘制星体位置
plt.scatter(positions[:, 0], positions[:, 1])
plt.xlabel('X Position')
plt.ylabel('Y Position')
plt.title('Universe Simulation')
plt.show()

                  ('Earth', 'Star2', {'weight': 10}),
                  ('Star1', 'Star2', {'weight': 3}),
                  ('Star2', 'Star3', {'weight': 2}),
                  ('Star3', 'Star4', {'weight': 6}),
                  ('Star4', 'Star5', {'weight': 3})])

# 计算从地球到其他星体的最短路径
start = 'Earth'
end = 'Star5'
path = nx.shortest_path(G, source=start, target=end, weight='weight')

# 输出路径

```python
import torch
import torch.nn as nn
import torchvision
import torchvision.transforms as transforms

# 创建一个简单的卷积神经网络
class CNN(nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, 3, 1)
        self.relu = nn.ReLU()
        self.pool = nn.MaxPool2d(2, 2)
        self.fc1 = nn.Linear(32 * 6 * 6, 128)
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.pool(self.relu(self.conv1(x)))
        x = self.pool(self.relu(self.fc1(x.view(-1, 32 * 6 * 6))))
        x = self.fc2(x)
        return x

# 实例化网络并设置损失函数和优化器
model = CNN()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# 加载训练数据
transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.5,), (0.5,))])
train_data = torchvision.datasets.MNIST(root='./data', train=True, download=True, transform=transform)
train_loader = torch.utils.data.DataLoader(train_data, batch_size=100, shuffle=True)

# 训练网络
for epoch in range(10):  # 数量仅为示例
    running_loss = 0.0
    for i, data in enumerate(train_loader, 0):
        inputs, labels = data
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        running_loss += loss.item()
    print(f'Epoch {epoch + 1}, Loss: {running_loss / len(train_loader)}')

# 测试网络
test_data = torchvision.datasets.MNIST(root='./data', train=False, download=True, transform=transform)
test_loader = torch.utils.data.DataLoader(test_data, batch_size=1000, shuffle=False)
with torch.no_grad():
    correct = 0
    total = 0
    for data in test_loader:
        images, labels = data
        outputs = model(images)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()
print(f'Accuracy: {100 * correct / total}%')
```
