## 数据结构的基本分类

### 2.1 线性结构

线性结构是指数据元素按照线性次序排列的数据结构，包括数组、链表、栈和队列等。

#### 2.1.1 数组

数组是一种最基本的数据结构，它将有限个类型相同的元素按一定顺序排列组成一个序列。数组的特点是支持随机访问，时间复杂度为O(1)。

#### 2.1.2 链表

链表由一系列节点组成，每个节点包含数据和指向下一个节点的指针。链表的特点是插入和删除操作的时间复杂度为O(1)，但随机访问的时间复杂度为O(n)。

#### 2.1.3 栈

栈是一种后进先出（LIFO）的数据结构，适用于处理递归、表达式求值等问题。

#### 2.1.4 队列

队列是一种先进先出（FIFO）的数据结构，适用于处理任务调度、缓冲区管理等。

### 2.2 树状结构

树状结构是一种层次结构，以分支关系表示元素之间的层次关系。包括二叉树、二叉搜索树、AVL树等。

#### 2.2.1 二叉树

二叉树是每个节点最多有两个子节点的树结构，适用于快速查找、排序等操作。

#### 2.2.2 二叉搜索树

二叉搜索树是一种特殊的二叉树，左子树的值小于根节点，右子树的值大于根节点，适用于快速查找和排序。

#### 2.2.3 AVL树

AVL树是一种自平衡的二叉搜索树，通过调整树的高度来保持平衡，适用于高效查找和插入操作。

### 2.3 图形结构

图形结构是一种复杂的数据结构，用于表示多对多关系，包括图、邻接矩阵等。

#### 2.3.1 图

图由一组节点和连接这些节点的边组成，适用于表示复杂关系和网络结构。

#### 2.3.2 邻接矩阵

邻接矩阵是一种用于表示图的二维数组，适用于处理图的基本操作和路径查找。

## 第2章 基础理论

### 2.1 数据结构的基本概念

数据结构是计算机科学中用于存储、组织和处理数据的方式。它是程序设计和算法设计的基础，直接影响程序的效率和质量。在本节中，我们将介绍数据结构的基本概念，包括数据的逻辑结构与存储结构，以及数据结构对算法的影响。

#### 2.1.1 数据与信息

数据是客观事物的符号记录，它可以是数字、文本、图像、声音等多种形式。信息则是数据经过解释和处理后的有意义的内容。在宇宙学研究中，数据通常包括天体的位置、速度、质量等信息，而信息则是对这些数据的解释和利用，如天体的运动轨迹、密度分布等。

#### 2.1.2 数据的逻辑结构与存储结构

数据的逻辑结构是指数据之间的逻辑关系，它是从抽象的角度来描述数据。常见的逻辑结构有线性结构、树状结构、图形结构等。

- **线性结构**：数据元素按照线性次序排列，包括数组、链表、栈和队列等。

- **树状结构**：数据元素以层次关系排列，包括二叉树、二叉搜索树、AVL树等。

- **图形结构**：数据元素以图的形式排列，包括图、邻接矩阵等。

数据的存储结构是指数据在计算机内存中的实际存储方式，它是从物理的角度来描述数据。常见的存储结构有顺序存储、链式存储、索引存储等。

- **顺序存储**：数据元素按照逻辑顺序依次存储在内存中，如数组。

- **链式存储**：数据元素通过指针链接存储在内存中，如链表。

- **索引存储**：数据元素通过索引表存储在内存中，如索引数组。

#### 2.1.3 数据结构对算法的影响

数据结构不仅影响程序的执行效率，还直接影响算法的设计和实现。

    def __init__(self):
        self.nodes = {}
        self.edges = {}

    def add_node(self, node):
        self.nodes[node] = []

    def add_edge(self, node1, node2):
        self.edges[(node1, node2)] = None
        self.nodes[node1].append(node2)
        self.nodes[node2].append(node1)

    def find_path(self, start, end):
        visited = set()
        queue = deque([start])

        while queue:
            current = queue.popleft()
            if current == end:
                return True
            visited.add(current)
            for neighbor in self.nodes[current]:
                if neighbor not in visited:
                    queue.append(neighbor)

        return False

graph.add_node('B')
graph.add_node('C')
graph.add_node('D')
graph.add_edge('A', 'B')
graph.add_edge('A', 'C')
graph.add_edge('B', 'D')
graph.add_edge('C', 'D')

# 查找路径
print(graph.find_path('A', 'D'))  # 输出：True
```

def calculate_gravity(celestial_body1, celestial_body2):
    distance = np.linalg.norm(celestial_body1.position - celestial_body2.position)
    force = G * celestial_body1.mass * celestial_body2.mass / distance**2
    direction = (celestial_body2.position - celestial_body1.position) / distance
    return force * direction

celestial_bodies = [CelestialBody([0, 0, 0], [0, 0, 0], 1.0), CelestialBody([10, 0, 0], [0, 1, 0], 1.0)]

for i in range(len(celestial_bodies)):
    for j in range(i+1, len(celestial_bodies)):
        force = calculate_gravity(celestial_bodies[i], celestial_bodies[j])
        celestial_bodies[i].velocity += force / celestial_bodies[i].mass
        celestial_bodies[j].velocity -= force / celestial_bodies[j].mass
```
