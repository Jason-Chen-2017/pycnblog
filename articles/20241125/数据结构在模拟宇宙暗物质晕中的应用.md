### Fundamental Concepts

#### Data Structures Basics

Data structures are fundamental components of computer science, providing a way to organize and manage data efficiently. At their core, data structures are designed to store and manipulate data in various formats, enabling efficient access, storage, and retrieval of information.

1. **Definition and Importance**

A data structure is an organized collection of data elements, along with the operations that can be performed on them. It is a fundamental building block for managing and processing data in computer programs. Data structures are essential for optimizing the performance of algorithms, improving the efficiency of data storage, and enabling complex data manipulations.

2. **Key Types of Data Structures**

There are several types of data structures, each with its own characteristics and use cases. Some of the most common data structures include:

   - **Arrays:** A collection of elements, each identified by an index or key.
   - **Linked Lists:** A linear data structure consisting of nodes, where each node contains data and a reference to the next node.
   - **Stacks and Queues:** Abstract data types that support specific insertion and deletion operations, resembling a stack (LIFO) or queue (FIFO), respectively.
   - **Trees:** A hierarchical data structure consisting of nodes, where each node has a parent and zero or more children.
   - **Graphs:** A collection of nodes (vertices) connected by edges, representing relationships and connections between elements.

3. **Basic Operations on Data Structures**

Data structures provide a set of operations that can be performed on the stored data. These operations include:

   - **Insertion:** Adding a new element to the data structure.
   - **Deletion:** Removing an existing element from the data structure.
   - **Access:** Retrieving the value of an element at a specific location.
   - **Traversal:** Visiting each element in the data structure exactly once.
   - **Sorting:** Arranging the elements in a specific order.
   - ** Searching:** Finding the location of a specific element within the data structure.

Understanding the fundamental concepts of data structures is crucial for designing efficient algorithms and solving complex problems in computer science. ### Graph Data Structures in Dark Matter Halos

#### Graph Theory Fundamentals

Graph theory is a branch of mathematics that deals with the study of graphs, which consist of nodes (also known as vertices) connected by edges. In the context of dark matter halos, graph theory provides a powerful framework for modeling the complex relationships and interactions between particles and regions within a halo. Understanding the fundamental concepts and definitions of graph theory is essential for effectively applying graph data structures to cosmology.

1. **Basic Graph Concepts and Definitions**

   - **Node (Vertex):** A node represents an individual particle or region within a dark matter halo. It is the fundamental building block of a graph.
   - **Edge:** An edge represents the connection between two nodes, indicating that there is some relationship or interaction between the particles or regions they represent.
   - **Graph:** A graph is a collection of nodes connected by edges. It can be either undirected (edges do not have a direction) or directed (edges have a direction from one node to another).
   - **Degree:** The degree of a node is the number of edges connected to it. In an undirected graph, the degree is the same for each end of an edge, while in a directed graph, it can be different.
   - **Connected Components:** Connected components are groups of nodes that are directly connected to each other. In a connected graph, there is a path between any two nodes, while in a disconnected graph, there are multiple connected components.
   - **Path and Cycle:** A path is a sequence of nodes connected by edges, while a cycle is a path that starts and ends at the same node.

2. **Graph Representations**

   Graphs can be represented in several ways, each with its own advantages and use cases. The most common representations include:

   - **Adjacency Matrix:** An adjacency matrix is a square matrix where the rows and columns represent nodes, and the values in the matrix indicate the presence of an edge between nodes. It is efficient for sparse graphs with a small number of nodes and edges.
   - **Adjacency List:** An adjacency list is a collection of lists, where each list corresponds to a node and contains the nodes adjacent to it. It is more efficient for sparse graphs with a large number of nodes and edges compared to the adjacency matrix.
   - **Incidence List:** An incidence list is a representation where each edge is associated with a list of nodes it connects. It is useful for representing graphs where the relationship between nodes and edges is important.

#### Tree Theory Fundamentals

Tree data structures are a hierarchical form of data organization that are particularly well-suited for representing hierarchical relationships, such as the nested structure of galaxy clusters within a dark matter halo. Understanding the fundamental concepts and definitions of tree theory is crucial for effectively applying tree data structures to the analysis of dark matter halos.

1. **Basic Tree Concepts and Definitions**

   - **Node:** A node is an individual element within a tree, which can represent a galaxy, cluster, or substructure within a dark matter halo.
   - **Root Node:** The root node is the topmost node in a tree, representing the starting point of the hierarchy.
   - **Child Node:** A child node is a node directly connected to another node, known as the parent node.
   - **Leaf Node:** A leaf node is a node with no child nodes, representing the lowest level of the hierarchy.
   - **Tree:** A tree is a collection of nodes connected in a hierarchical structure, with the root node at the top and leaf nodes at the bottom.
   - **Siblings:** Siblings are nodes that share the same parent node.
   - **Level:** The level of a node is the number of edges from the root node to the node itself.
   - **Depth:** The depth of a tree is the maximum level of any node in the tree.

2. **Tree Representations**

   Trees can be represented in several ways, each with its own advantages and use cases. The most common representations include:

   - **Parent-Child List:** In this representation, each node contains a reference to its parent node and a list of its child nodes.
   - **Binary Tree:** A binary tree is a tree in which each node has at most two child nodes, referred to as the left child and the right child.
   - **Binary Search Tree:** A binary search tree is a binary tree in which the left subtree of a node contains only nodes with values less than the node's value, and the right subtree contains only nodes with values greater than the node's value.
   - **Threaded Tree:** A threaded tree is a variant of a binary tree where each node has a reference to its in-order predecessor and successor, allowing for efficient traversal in both directions.

### Hash Tables in Dark Matter Halo Analysis

#### Hash Table Theory

Hash tables are a fundamental data structure that utilizes a hash function to map keys to values, providing efficient insertion, deletion, and lookup operations. In the context of dark matter halo analysis, hash tables can be particularly useful for managing large datasets and performing rapid queries.

1. **Hash Functions and Collision Resolution**

   - **Hash Function:** A hash function takes a key and maps it to a specific index in an array, known as a hash table. The goal of a good hash function is to distribute keys uniformly across the array to minimize collisions.
   - **Collision:** A collision occurs when two or more keys are mapped to the same index in the hash table. Collisions must be resolved to maintain the efficiency of the hash table.
   - **Collision Resolution Techniques:**
     - **Chaining:** In this method, each index of the hash table points to a linked list. When a collision occurs, the collided keys are added to the linked list at that index.
     - **Open Addressing:** In this method, when a collision occurs, the hash table searches for the next available slot in the table using a probing sequence, such as linear probing, quadratic probing, or double hashing.
     - **Rehashing:** When the load factor (the ratio of the number of entries to the size of the hash table) exceeds a certain threshold, the hash table is resized, and all the entries are rehashed to the new table.

2. **Hash Table Operations**

   Hash tables support several basic operations:

   - **Insertion:** Inserts a new key-value pair into the hash table.
   - **Deletion:** Removes a key-value pair from the hash table based on the key.
   - **Lookup:** Retrieves the value associated with a given key from the hash table.
   - **Resize:** Adjusts the size of the hash table to maintain performance.
