## 数据结构基础

### 1. 基本概念与术语

数据结构是计算机科学中的一个重要概念，指的是在计算机中存储和组织数据的方式。数据结构不仅决定了数据的存储方式，还影响了数据的操作效率。在数据结构中，有几种基本的术语需要了解：

1. **数据元素（Data Element）**：数据元素是数据结构中的基本单位，可以是单个的数值或对象。

2. **数据对象（Data Object）**：数据对象是由多个数据元素组成的集合，例如一个数组、一个列表或一个树。

3. **数据集合（Data Set）**：数据集合是由多个数据对象组成的集合，可以表示一个复杂的系统或问题。

4. **数据结构类型（Type of Data Structure）**：数据结构类型是根据数据元素的组织方式来分类的，常见的类型包括线性结构（如数组、链表、栈和队列）、树形结构（如二叉树、堆、平衡树）和图形结构（如图、网络图）。

### 2. 常见数据结构

在计算机科学中，有许多常见的数据结构，每种数据结构都有其特定的用途和特点。以下是几种常见的数据结构及其基本特点：

1. **数组（Array）**：数组是一种线性数据结构，用于存储一系列相同类型的数据元素。数组的特点是支持随机访问，即可以通过索引直接访问数组中的任意元素，时间复杂度为O(1)。

2. **链表（Linked List）**：链表是一种由节点组成的线性数据结构，每个节点包含数据和指向下一个节点的指针。链表的主要优点是插入和删除操作的时间复杂度为O(1)，但随机访问操作较慢，时间复杂度为O(n)。

3. **栈（Stack）**：栈是一种后进先出（LIFO）的数据结构，用于存储一系列元素。栈的主要特点是插入和删除操作都只能在栈顶进行，时间复杂度为O(1)。

4. **队列（Queue）**：队列是一种先进先出（FIFO）的数据结构，用于存储一系列元素。队列的主要特点是插入操作在队尾进行，删除操作在队头进行，时间复杂度为O(1)。

5. **树（Tree）**：树是一种层次结构的数据结构，由节点和边组成。每个节点都有一个父节点和零个或多个子节点。树的主要特点包括查找、插入和删除操作的时间复杂度通常为O(log n)。

6. **图（Graph）**：图是一种复杂的数据结构，由节点（也称为顶点）和边组成。图可以表示网络、社交关系等多种复杂系统。图的主要特点包括查找、路径搜索和图论算法等。

### 3. 数据结构的应用场景

数据结构在计算机科学中有着广泛的应用场景，以下是一些常见应用：

1. **数据库**：数据库管理系统（DBMS）使用各种数据结构来存储和检索数据。例如，关系型数据库使用数组结构来存储表，而索引结构则使用树结构来优化查询。

2. **算法设计**：许多算法都基于特定的数据结构。例如，排序算法通常使用数组或链表结构，图算法则基于图数据结构。

3. **操作系统**：操作系统中的进程管理、内存分配和文件系统管理等，都涉及数据结构的运用。例如，进程控制块（PCB）通常使用数组或链表结构来存储和管理进程信息。

4. **网络**：网络协议和数据包处理依赖于图数据结构来表示网络拓扑和路由算法。

5. **人工智能**：在人工智能领域，图神经网络（GNN）使用图数据结构来表示和处理复杂的网络结构，例如社交网络或知识图谱。

通过了解数据结构的基本概念、常见类型和应用场景，我们可以更好地理解和运用数据结构，解决各种复杂的计算机科学问题。

### 2.1.1 线性表

#### 2.1.1.1 线性表的定义与特点

线性表是一种基本的数据结构，用于存储一系列有序的数据元素。线性表的特点是数据元素在逻辑上呈线性排列，相邻元素之间具有固定的顺序关系。

线性表的定义如下：

- **数据元素**：线性表中的基本单位，可以是任何类型的对象。
- **元素个数**：线性表中数据元素的总数，用n表示。
- **线性关系**：线性表中元素之间存在着一对一的线性关系，即每个元素都有一个直接前驱和直接后继。

线性表可以用一个数组来实现，其中每个数组元素存储一个数据元素。例如，以下是一个简单的Python实现：

```python
# 线性表实现
class LinearList:
    def __init__(self, size):
        self.size = size
        self.elements = [None] * size

    def append(self, element):
        self.elements[self.length()] = element

    def length(self):
        return len(self.elements) - self.elements.count(None)

    def display(self):
        for element in self.elements:
            if element is not None:
                print(element, end=" ")
        print()
```

以下是一个使用上述实现的例子：

```python
# 创建一个线性表
linear_list = LinearList(5)

# 向线性表中添加元素
linear_list.append(1)
linear_list.append(2)
linear_list.append(3)
linear_list.append(4)
linear_list.append(5)

# 显示线性表
linear_list.display()  # 输出：1 2 3 4 5
```

#### 2.1.1.2 线性表的操作

线性表的基本操作包括：

1. **插入（Insert）**：在某个位置插入一个新元素。
2. **删除（Delete）**：删除某个位置的元素。
3. **查找（Search）**：查找某个元素的位置。
4. **显示（Display）**：显示线性表中的所有元素。

以下是这些操作的Python实现：

```python
# 插入操作
def insert(self, index, element):
    if index < 0 or index > self.length():
        raise IndexError("Index out of range")
    for i in range(self.length(), index, -1):
        self.elements[i] = self.elements[i - 1]
    self.elements[index] = element

# 删除操作
def delete(self, index):
    if index < 0 or index >= self.length():
        raise IndexError("Index out of range")
    for i in range(index, self.length() - 1):
        self.elements[i] = self.elements[i + 1]
    self.elements[self.length() - 1] = None

# 查找操作
def search(self, element):
    for i in range(self.length()):
        if self.elements[i] == element:
            return i
    return -1

# 显示操作
def display(self):
    for element in self.elements:
        if element is not None:
            print(element, end=" ")
    print()
```

以下是一个使用这些操作的例子：

```python
# 向线性表的第二个位置插入元素
linear_list.insert(1, 10)

# 删除线性表中的第三个元素
linear_list.delete(2)

# 查找元素3的位置
index = linear_list.search(3)

# 显示线性表
linear_list.display()  # 输出：1 10 4 5
```

通过以上实现，我们可以看到线性表的基本操作是如何在Python中实现的。线性表作为一种基本的数据结构，在计算机科学中有着广泛的应用，例如在数据库、算法设计和操作系统等领域。

### 2.1.2 栈和队列

#### 2.1.2.1 栈的定义与特点

栈（Stack）是一种后进先出（Last In, First Out, LIFO）的数据结构，意味着最后进入栈的元素将最先被取出。栈的基本特点如下：

- **栈顶（Top）**：栈顶是当前栈中的最后一个元素，也是可以访问的唯一元素。
- **栈底（Bottom）**：栈底是栈的起始位置，通常无法直接访问。
- **插入和删除**：所有插入和删除操作都在栈顶进行，插入元素通常称为“压栈”，删除元素称为“出栈”。

栈可以用数组或链表实现。以下是使用Python实现的栈类：

```python
class Stack:
    def __init__(self):
        self.items = []

    def is_empty(self):
        return len(self.items) == 0

    def push(self, item):
        self.items.append(item)

    def pop(self):
        if self.is_empty():
            raise IndexError("Stack is empty")
        return self.items.pop()

    def peek(self):
        if self.is_empty():
            raise IndexError("Stack is empty")
        return self.items[-1]

    def size(self):
        return len(self.items)
```

以下是一个使用栈的例子：

```python
stack = Stack()

# 压栈
stack.push(1)
stack.push(2)
stack.push(3)

# 出栈
print(stack.pop())  # 输出：3

# 查看栈顶元素
print(stack.peek())  # 输出：2

# 查看栈的大小
print(stack.size())  # 输出：2
```

#### 2.1.2.2 队列的定义与特点

队列（Queue）是一种先进先出（First In, First Out, FIFO）的数据结构，意味着最先进入队列的元素将最先被取出。队列的基本特点如下：

- **队头（Front）**：队头是队列的第一个元素，也是可以访问的唯一元素。
- **队尾（Rear）**：队尾是队列的最后一个元素，新的元素将插入到队尾。
- **插入和删除**：插入操作通常在队尾进行，删除操作在队头进行。

队列也通常可以用数组或链表实现。以下是使用Python实现的队列类：

```python
class Queue:
    def __init__(self):
        self.items = []

    def is_empty(self):
        return len(self.items) == 0

    def enqueue(self, item):
        self.items.append(item)

    def dequeue(self):
        if self.is_empty():
            raise IndexError("Queue is empty")
        return self.items.pop(0)

    def front(self):
        if self.is_empty():
            raise IndexError("Queue is empty")
        return self.items[0]

    def size(self):
        return len(self.items)
```

以下是一个使用队列的例子：

```python
queue = Queue()

# 入队
queue.enqueue(1)
queue.enqueue(2)
queue.enqueue(3)

# 出队
print(queue.dequeue())  # 输出：1

# 查看队头元素
print(queue.front())  # 输出：2

# 查看队列的大小
print(queue.size())  # 输出：2
```

通过以上实现，我们可以看到栈和队列的基本操作是如何在Python中实现的。栈和队列在计算机科学中有着广泛的应用，例如在算法设计、程序控制和数据管理等领域。

### 2.1.3 树

#### 2.1.3.1 树的定义与特点

树（Tree）是一种重要的非线性数据结构，由节点（Node）和边（Edge）组成。每个节点包含一个数据元素和一个或多个子节点，而每个子节点又可以有自己的子节点。树的特点如下：

- **根节点（Root）**：树中没有父节点的节点称为根节点。
- **叶子节点（Leaf）**：没有子节点的节点称为叶子节点。
- **节点层次（Level）**：根节点位于第1层，其子节点位于第2层，以此类推。
- **节点深度（Depth）**：一个节点的深度是从根节点到该节点的路径上的边的数量。
- **子树（Subtree）**：以某个节点为根的节点集合称为该节点的子树。

树可以用不同的方式实现，最常见的是使用数组或链表。以下是使用链表实现的树节点类：

```python
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.children = []

    def add_child(self, child_node):
        self.children.append(child_node)

    def remove_child(self, child_node):
        self.children.remove(child_node)

    def get_children(self):
        return self.children
```

以下是一个使用上述实现的简单树结构：

```python
# 创建根节点
root = TreeNode(1)

# 创建子节点
child1 = TreeNode(2)
child2 = TreeNode(3)

# 添加子节点到根节点
root.add_child(child1)
root.add_child(child2)

# 添加子节点到子节点
child1.add_child(TreeNode(4))
child2.add_child(TreeNode(5))
child2.add_child(TreeNode(6))
```

#### 2.1.3.2 二叉树

二叉树（Binary Tree）是一种特殊的树，每个节点最多有两个子节点，通常称为左子节点和右子节点。二叉树的基本特点如下：

- **二叉搜索树（Binary Search Tree, BST）**：左子节点的值小于根节点的值，右子节点的值大于根节点的值。
- **平衡二叉树（AVL Tree）**：每个节点的左右子树的高度差不超过1。
- **堆（Heap）**：一种特殊的树形数据结构，通常用于优先队列。

以下是二叉树的Python实现：

```python
class BinaryTree:
    def __init__(self, root_value):
        self.root = TreeNode(root_value)

    def insert(self, value, parent_value):
        parent_node = self.search(parent_value)
        if parent_node:
            new_node = TreeNode(value)
            parent_node.add_child(new_node)
        else:
            print("Parent node not found")

    def search(self, value):
        current_node = self.root
        while current_node:
            if current_node.value == value:
                return current_node
            elif value < current_node.value:
                current_node = current_node.left
            else:
                current_node = current_node.right
        return None

    def delete(self, value):
        current_node = self.root
        parent_node = None
        while current_node:
            if current_node.value == value:
                if current_node.left and current_node.right:
                    # 需要找到当前节点的最小子节点（右子节点的最左子节点）
                    successor_parent = current_node
                    successor = current_node.right
                    while successor.left:
                        successor_parent = successor
                        successor = successor.left
                    current_node.value = successor.value
                    if successor_parent.left == successor:
                        successor_parent.left = successor.right
                    else:
                        successor_parent.right = successor.right
                else:
                    # 当前节点只有左子节点或右子节点
                    child_node = current_node.left if current_node.left else current_node.right
                    if parent_node:
                        if parent_node.left == current_node:
                            parent_node.left = child_node
                        else:
                            parent_node.right = child_node
                    else:
                        self.root = child_node
            else:
                parent_node = current_node
                if value < current_node.value:
                    current_node = current_node.left
                else:
                    current_node = current_node.right
        if current_node is None:
            print("Value not found")

    def display_inorder(self, node=None):
        if node is None:
            node = self.root
        if node:
            self.display_inorder(node.left)
            print(node.value, end=" ")
            self.display_inorder(node.right)
```

以下是一个使用二叉树的例子：

```python
# 创建二叉树
binary_tree = BinaryTree(5)

# 插入节点
binary_tree.insert(3, 5)
binary_tree.insert(7, 5)
binary_tree.insert(2, 3)
binary_tree.insert(4, 3)
binary_tree.insert(6, 7)
binary_tree.insert(8, 7)

# 显示中序遍历结果
binary_tree.display_inorder()  # 输出：2 3 4 5 6 7 8
```

### 2.1.4 图

#### 2.1.4.1 图的定义与特点

图（Graph）是一种复杂的数据结构，由节点（Node）和边（Edge）组成。节点表示图中的实体，边表示节点之间的关系。图的特点如下：

- **无向图（Undirected Graph）**：边没有方向，任意两个节点都是连通的。
- **有向图（Directed Graph）**：边有方向，从一个节点指向另一个节点。
- **权图（Weighted Graph）**：边有权重，表示节点之间的距离或成本。
- **简单图（Simple Graph）**：没有自环（节点指向自己的边）和多重边（多个相同节点之间的边）。
- **连通图（Connected Graph）**：任意两个节点都是连通的。

图可以用邻接矩阵（Adjacency Matrix）或邻接表（Adjacency List）实现。以下是使用邻接表实现的图类：

```python
class Graph:
    def __init__(self, is_directed=False, is_weighted=False):
        self.is_directed = is_directed
        self.is_weighted = is_weighted
        self.nodes = []
        self.edges = {}

    def add_node(self, value):
        if value not in self.nodes:
            self.nodes.append(value)
            if self.is_directed:
                self.edges[value] = {}
            else:
                self.edges[value] = []

    def add_edge(self, from_node, to_node, weight=None):
        if from_node not in self.nodes:
            self.add_node(from_node)
        if to_node not in self.nodes:
            self.add_node(to_node)
        if self.is_directed:
            self.edges[from_node][to_node] = weight
        else:
            self.edges[from_node].append(to_node)
            if not self.is_directed:
                self.edges[to_node].append(from_node)

    def display(self):
        for node in self.nodes:
            print(f"{node}: ", end="")
            if self.is_directed:
                for adjacent_node, weight in self.edges[node].items():
                    print(f"{adjacent_node}({weight})", end=" ")
            else:
                for adjacent_node in self.edges[node]:
                    print(f"{adjacent_node}", end=" ")
            print()
```

以下是一个使用上述实现的图示例：

```python
# 创建图
graph = Graph(is_directed=True, is_weighted=True)

# 添加节点和边
graph.add_node(1)
graph.add_node(2)
graph.add_node(3)
graph.add_edge(1, 2, 5)
graph.add_edge(2, 3, 7)
graph.add_edge(3, 1, 3)

# 显示图
graph.display()  # 输出：1: 2(5) 3(3) 2: 1(5) 3(7) 3: 1(3) 2(7)
```

#### 2.1.4.2 图的表示方法

图的表示方法主要有邻接矩阵和邻接表两种。

1. **邻接矩阵（Adjacency Matrix）**：邻接矩阵是一个二维数组，其中`matrix[i][j]`表示节点i和节点j之间是否存在边。如果存在边，则`matrix[i][j]`为1（或边的权重）；如果不存在边，则为0。以下是一个邻接矩阵的示例：

```python
# 示例图的邻接矩阵
adjacency_matrix = [
    [0, 1, 0],  # 节点0
    [1, 0, 1],  # 节点1
    [0, 1, 0]   # 节点2
]
```

2. **邻接表（Adjacency List）**：邻接表是一个列表，其中每个元素是一个列表，表示与该节点相连的其他节点。以下是一个邻接表的示例：

```python
# 示例图的邻接表
adjacency_list = {
    0: [1],
    1: [0, 2],
    2: [1]
}
```

邻接矩阵适用于稀疏图，而邻接表适用于稠密图。在实际应用中，选择哪种表示方法取决于图的稀疏程度和具体应用需求。

    def __init__(self, value):

        self.children = []

    def add_child(self, child):
        self.children.append(child)

# 创建根节点
root = TreeNode(0)

# 添加子节点
child1 = TreeNode(1)
child2 = TreeNode(2)
root.add_child(child1)
root.add_child(child2)

child1.add_child(TreeNode(3))
child2.add_child(TreeNode(4))
child2.add_child(TreeNode(5))

# 创建二维数组
data = np.array([[1, 2], [3, 4], [5, 6]])

# 绘制树结构
plt.figure()
nx.draw(root, with_labels=True)
plt.show()

plt.figure()
plt.imshow(data, aspect='auto')
plt.colorbar()
plt.show()
