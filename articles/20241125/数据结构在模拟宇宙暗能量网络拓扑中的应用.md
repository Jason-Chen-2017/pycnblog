## 2.2 网络拓扑的基本理论

### 网络拓扑的定义与基本概念

网络拓扑是指网络中各个节点及其相互连接关系的抽象表示。它是计算机网络和通信领域的一个基础概念，用于描述网络的物理结构和逻辑结构。网络拓扑的基本概念包括节点、边、路径和连通性等。

- **节点**：节点是网络中的基本组成部分，通常表示计算机、设备或其他网络单元。
- **边**：边是节点之间的连接，表示数据传输的路径。
- **路径**：路径是数据从源节点到目标节点经过的一系列边。
- **连通性**：连通性描述了网络中节点之间的连接关系，如果一个网络中的任意两个节点之间都存在路径，则称该网络是连通的。

### 网络拓扑的数学模型

网络拓扑可以用数学模型来描述，常见的数学模型包括图论模型和图论算法。图论模型使用图（Graph）来表示网络，图中的节点表示网络中的设备，边表示设备之间的连接关系。

- **图**：图（Graph）是一个由节点（Vertex）和边（Edge）组成的集合，通常用 \( G = (V, E) \) 表示，其中 \( V \) 是节点集合，\( E \) 是边集合。
- **无向图**：无向图（Undirected Graph）是指边没有方向的图，例如，一个房间的布局可以表示为一个无向图。
- **有向图**：有向图（Directed Graph）是指边具有方向的图，例如，一个网站的超链接网络可以表示为一个有向图。
- **路径**：路径（Path）是图中的一个节点序列，其中每个节点都是其相邻节点的直接邻居，路径通常用序列 \( (v_1, v_2, ..., v_n) \) 表示。
- **连通性**：连通性（Connectivity）描述了图中的节点之间的连接关系。一个图是连通的，如果任意两个节点之间都存在路径。

### 网络拓扑的稳定性分析

网络拓扑的稳定性是指网络在遭受故障、攻击或外部扰动时保持正常运行的能力。稳定性分析是网络拓扑研究的一个重要方面，以下是一些关键指标：

- **连通性**：网络的连通性是评估其稳定性的重要指标。一个稳定的网络应确保在节点或边发生故障时，仍然保持连通。
- **冗余**：冗余是指在网络中通过备份路径和冗余连接来提高网络的稳定性。例如，使用多重路径和冗余设备可以增强网络的容错能力。
- **负载均衡**：负载均衡是指在网络中分配数据流量，以避免单个节点或边过载。通过合理的负载均衡策略，可以提高网络的稳定性和效率。

### 3.1 线性结构

线性结构是数据结构中最基本和常见的一种，它将数据元素按照线性顺序排列。这种结构的特点是每个元素只有一个直接前驱和一个直接后继，从而形成一个线性序列。常见的线性结构包括数组、链表和栈等。

**数组**：

数组是一种固定大小、连续内存分配的数据结构，用于存储一系列同类型的元素。数组提供了快速的随机访问能力，通过数组下标可以迅速访问任意位置的元素。数组的缺点是大小固定，不可动态扩展。

**链表**：

链表是一种动态数据结构，它由一系列节点组成，每个节点包含数据域和指向下一个节点的指针。链表可以根据需要动态地分配和释放内存，非常适用于数据动态变化的情况。链表的主要优点是插入和删除操作效率高，但随机访问效率较低。

**栈**：

栈是一种后进先出（Last In First Out, LIFO）的数据结构，它只允许在表的一端进行插入和删除操作。栈常用于实现递归、表达式的求值等场景。

**线性结构在模拟宇宙暗能量网络中的适用性**：

1. **数组**：在模拟宇宙暗能量网络时，数组可以用于存储大量的天体位置信息、速度和加速度等。由于数组提供了快速的随机访问能力，这有助于快速查询和更新天体的属性。

2. **链表**：链表适用于动态变化的数据，例如，当宇宙中的天体发生碰撞或新生成时，使用链表可以方便地插入和删除天体节点。链表的结构使得插入和删除操作的时间复杂度更低。

3. **栈**：栈在模拟宇宙中用于处理递归和回溯问题，例如，模拟天体之间的引力作用时，可以采用栈来记录每一步的运算状态，以便在需要时回溯。

通过合理选择和应用线性结构，可以有效地提高模拟宇宙暗能量网络的计算效率和结果的准确性。线性结构的简单性和高效性使得它们成为模拟宇宙暗能量网络中的有力工具。

### 3.2 树形结构

树形结构是一种层次化的数据结构，它通过节点之间的父子关系形成一个树状结构。每个节点有且仅有一个父节点，除了根节点外，每个节点可以有零个或多个子节点。树形结构在描述层次关系和嵌套结构方面具有独特优势，常见的树形结构包括二叉树、二叉搜索树、平衡树等。

**二叉树**：

二叉树是一种每个节点最多有两个子节点的树结构。二叉树常用于实现二叉搜索树（BST），其中节点的左子树包含小于父节点的值，右子树包含大于父节点的值。二叉树适用于快速查找、插入和删除操作。

**二叉搜索树**：

二叉搜索树（BST）是二叉树的一种特殊形式，其中每个节点的左子树只包含小于父节点的值，右子树只包含大于父节点的值。BST的这种特性使得查找、插入和删除操作的时间复杂度可以达到 \(O(\log n)\)，大大提高了操作效率。

**平衡树**：

平衡树（如AVL树、红黑树等）是二叉搜索树的一种扩展，它通过自平衡机制保持树的平衡，从而确保查找、插入和删除操作的时间复杂度始终为 \(O(\log n)\)。这种结构适用于需要频繁进行动态调整的场景。

1. **表示层次关系**：宇宙中存在多种层次结构，如星系团、星系和恒星等。树形结构能够很好地表示这些层次关系，使得模拟过程更加直观和高效。

2. **动态调整**：树形结构在插入和删除节点时具有高效的动态调整能力。例如，在模拟宇宙暗能量网络时，当发生天体碰撞或新天体生成时，可以使用树形结构方便地进行节点插入和删除操作。

3. **层次化数据访问**：树形结构允许层次化的数据访问，这使得在模拟过程中可以按层次进行数据操作和分析，提高了计算效率。

### 4.1 数据结构的操作

在模拟宇宙暗能量网络时，数据结构的操作效率直接影响整个模拟的效率和准确性。以下将详细探讨数据结构中的几个基本操作：插入、删除、查找和排序。

#### 插入操作

插入操作是在数据结构中添加新元素的过程。插入操作的效率对数据结构的性能有重要影响，常见的数据结构包括数组、链表、二叉树和图形结构等。

- **数组**：在数组中插入元素时，如果插入位置已满，则需要扩展数组，这会导致额外的内存分配和复制操作，时间复杂度为 \(O(n)\)。但如果在数组末尾插入，时间复杂度可以降低到 \(O(1)\)。
- **链表**：在链表中插入元素时，只需改变前后节点的指针，时间复杂度为 \(O(1)\)。但链表的插入操作需要遍历链表找到插入位置，如果需要频繁插入，可能会影响性能。
- **二叉树**：在二叉树（如二叉搜索树）中插入元素时，根据元素值逐步找到插入位置，时间复杂度为 \(O(\log n)\)，其中 \(n\) 是树中元素的数量。
- **图形结构**：在图形结构中插入节点和边时，需要更新节点的邻接表或边表，时间复杂度通常为 \(O(1)\) 或 \(O(\log n)\)，取决于具体实现。

#### 删除操作

删除操作是从数据结构中移除元素的过程。删除操作的效率同样对模拟性能有重要影响。

- **数组**：在数组中删除元素时，如果删除位置不在末尾，则需要将后续元素向前移动，时间复杂度为 \(O(n)\)。
- **链表**：在链表中删除元素时，只需改变前后节点的指针，时间复杂度为 \(O(1)\)。
- **二叉树**：在二叉树中删除元素时，需要找到删除位置，然后进行相应的树结构调整，时间复杂度为 \(O(\log n)\)。
- **图形结构**：在图形结构中删除节点和边时，需要更新节点的邻接表或边表，时间复杂度通常为 \(O(1)\) 或 \(O(\log n)\)。

#### 查找操作

查找操作是在数据结构中查找特定元素的过程。查找操作的效率直接影响数据的访问速度。

- **数组**：在数组中查找元素时，可以通过下标直接访问，时间复杂度为 \(O(1)\)。
- **链表**：在链表中查找元素时，需要逐个节点遍历，时间复杂度为 \(O(n)\)。
- **二叉树**：在二叉搜索树中查找元素时，可以根据元素值逐步缩小查找范围，时间复杂度为 \(O(\log n)\)。
- **图形结构**：在图形结构中查找节点或边时，可以通过邻接表或边表快速访问，时间复杂度通常为 \(O(1)\) 或 \(O(\log n)\)。

#### 排序操作

排序操作是对数据结构中的元素进行排序的过程，常见的排序算法包括冒泡排序、选择排序、插入排序、快速排序和归并排序等。

- **冒泡排序**：通过多次遍历数据，交换相邻的不排序元素，时间复杂度为 \(O(n^2)\)，适用于小规模数据。
- **选择排序**：每次选择未排序部分的最小（或最大）元素放到已排序部分的末尾，时间复杂度为 \(O(n^2)\)，适用于小规模数据。
- **插入排序**：通过逐步将未排序部分的元素插入到已排序部分，时间复杂度为 \(O(n^2)\)，适用于小规模数据。
- **快速排序**：选择一个基准元素，将数据分为两部分，然后递归地对两部分进行排序，时间复杂度为 \(O(n \log n)\)，适用于大规模数据。
- **归并排序**：将数据分为若干部分，分别排序后合并，时间复杂度为 \(O(n \log n)\)，适用于大规模数据。

通过合理选择和优化这些基本操作，可以显著提高模拟宇宙暗能量网络的效率，为复杂科学计算提供有力的支持。

### 4.2 搜索算法

搜索算法是计算机科学中用于在数据结构中查找特定元素的重要工具。在模拟宇宙暗能量网络时，搜索算法能够帮助我们在复杂的网络中快速找到目标节点或路径。以下将详细讲解三种常用的搜索算法：深度优先搜索（DFS）、广度优先搜索（BFS）和A*搜索算法。

#### 深度优先搜索（DFS）

深度优先搜索（DFS）是一种从初始节点开始，沿着路径不断深入搜索，直到找到目标节点或遍历完整个网络。DFS的特点是遍历路径深度较深，适用于寻找路径较长的情况。

**算法步骤**：

1. 初始化一个空栈，将起始节点压入栈中。
2. 循环执行以下步骤，直到栈为空：
   - 弹出栈顶节点，标记为已访问。
   - 遍历该节点的所有未访问的邻接节点，将它们压入栈中。
3. 如果找到目标节点，返回路径；否则，返回空。

**Python代码示例**：

```python
def dfs(graph, start, target):
    stack = [start]
    visited = set()
    path = []

    while stack:
        node = stack.pop()
        if node == target:
            return reconstruct_path(path, target)
        if node not in visited:
            visited.add(node)
            path.append(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    stack.append(neighbor)
            path.pop()

    return None

def reconstruct_path(path, target):
    result = []
    while target in path:
        result.append(target)
        target = path[target]
    return result[::-1]
```

#### 广度优先搜索（BFS）

广度优先搜索（BFS）是一种从初始节点开始，逐层搜索整个网络，直到找到目标节点。BFS的特点是遍历路径较短，适用于寻找路径较短的情境。

**算法步骤**：

1. 初始化一个空队列，将起始节点压入队列中。
2. 循环执行以下步骤，直到队列为空：
   - 从队列中取出队首节点。
   - 遍历该节点的所有未访问的邻接节点，将它们压入队列中。
   - 标记该节点为已访问。
3. 如果找到目标节点，返回路径；否则，返回空。

**Python代码示例**：

```python
from collections import deque

def bfs(graph, start, target):
    queue = deque([start])
    visited = set()
    path = {start: None}

    while queue:
        node = queue.popleft()
        if node == target:
            return reconstruct_path(path, target)
        if node not in visited:
            visited.add(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    queue.append(neighbor)
                    path[neighbor] = node

    return None

def reconstruct_path(path, target):
    result = []
    while target is not None:
        result.append(target)
        target = path[target]
    return result[::-1]
```

#### A*搜索算法

A*搜索算法（A*）是一种启发式搜索算法，它结合了DFS和BFS的优点，通过引入估价函数（heuristic function）来指导搜索方向。A*算法适用于寻找最优路径。

**算法步骤**：

1. 初始化两个集合：一个开放集合（open_set），用于存储待访问的节点；一个关闭集合（closed_set），用于存储已访问的节点。
2. 将起始节点和目标节点分别加入open_set和closed_set。
3. 循环执行以下步骤，直到找到目标节点或open_set为空：
   - 从open_set中选择一个具有最小f值的节点作为当前节点，将其从open_set中移除并加入closed_set。
   - 遍历当前节点的所有未访问的邻接节点：
     - 如果邻接节点是目标节点，则返回路径。
     - 如果邻接节点已存在于closed_set中，则跳过。
     - 计算邻接节点的g值、h值和f值，将其加入open_set。
4. 如果open_set为空，则无路径。

**Python代码示例**：

```python
import heapq

def a_star_search(graph, start, target):
    open_set = [(0, start)]
    closed_set = set()
    path = {start: None}

    while open_set:
        _, current = heapq.heappop(open_set)
        if current == target:
            return reconstruct_path(path, target)
        closed_set.add(current)

        for neighbor, weight in graph[current].items():
            if neighbor in closed_set:
                continue
            tentative_g = path[current][1] + weight
            if (tentative_g, neighbor) not in open_set:
                heapq.heappush(open_set, (tentative_g + heuristic(neighbor, target), neighbor))
                path[neighbor] = (current, tentative_g)

    return None

def reconstruct_path(path, target):
    result = []
    while target is not None:
        result.append(target)
        target = path[target]
    return result[::-1]

def heuristic(node, target):
    # 使用曼哈顿距离作为估价函数
    return abs(node[0] - target[0]) + abs(node[1] - target[1])
```

### 4.3 排序算法

排序算法是计算机科学中用于对数据集合进行排序的重要工具。在模拟宇宙暗能量网络时，排序算法能够帮助我们有效地处理和比较天体属性，如位置、速度和质量等。以下将详细介绍几种常用的排序算法：冒泡排序、选择排序、插入排序、快速排序和归并排序。

#### 冒泡排序

冒泡排序是一种简单的排序算法，它通过反复交换相邻元素，使较小的元素逐步“冒泡”到数组的一端。冒泡排序的时间复杂度为 \(O(n^2)\)，适用于小规模数据的排序。

**算法步骤**：

1. 从数组的第一个元素开始，比较相邻的两个元素。
2. 如果第一个元素大于第二个元素，交换它们。
3. 重复上述步骤，直到遍历完整个数组。

**Python代码示例**：

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr
```

#### 选择排序

选择排序是一种简单的选择算法，它每次从未排序部分选择最小（或最大）的元素放到已排序部分的末尾。选择排序的时间复杂度为 \(O(n^2)\)，适用于小规模数据的排序。

**算法步骤**：

1. 从未排序部分中选择一个最小（或最大）的元素。
2. 将该元素放到已排序部分的末尾。
3. 重复上述步骤，直到未排序部分为空。

**Python代码示例**：

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```

#### 插入排序

插入排序是一种基于比较的排序算法，它通过将未排序部分的数据元素逐步插入到已排序部分中的合适位置。插入排序的时间复杂度为 \(O(n^2)\)，但在数据基本有序时，效率会显著提高。

**算法步骤**：

1. 从数组的第二个元素开始，逐个将未排序部分的数据元素与已排序部分进行比对。
2. 找到合适的位置后，将该元素插入到已排序部分的适当位置。
3. 重复上述步骤，直到未排序部分为空。

**Python代码示例**：

```python
def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]
        j = i-1
        while j >= 0 and arr[j] > key:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key
    return arr
```

#### 快速排序

快速排序是一种高效的排序算法，它采用分治策略，将一个大数组划分为多个小数组，然后递归地对这些小数组进行排序。快速排序的时间复杂度为 \(O(n \log n)\)，适用于大规模数据的排序。

**算法步骤**：

1. 选择一个基准元素。
2. 将数组划分为两个子数组，一个包含小于基准元素的元素，另一个包含大于基准元素的元素。
3. 递归地对这两个子数组进行快速排序。

**Python代码示例**：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```

#### 归并排序

归并排序是一种基于比较的排序算法，它通过将数组划分为多个子数组，然后递归地对这些子数组进行排序，最后将排序后的子数组合并成完整的排序数组。归并排序的时间复杂度为 \(O(n \log n)\)，适用于大规模数据的排序。

**算法步骤**：

1. 将数组划分为多个子数组，每个子数组包含一个元素。
2. 递归地对这些子数组进行排序。
3. 将排序后的子数组合并成完整的排序数组。

**Python代码示例**：

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

### 5.1 图的连通性与路径长度

在宇宙暗能量网络的研究中，图的连通性与路径长度是两个关键概念。图的连通性描述了图中节点之间的连接关系，而路径长度则反映了节点之间的距离。理解这些概念有助于我们分析宇宙结构的稳定性和演化过程。

#### 连通性定义与判断

图的连通性是指图中任意两个节点之间都存在路径。一个图是连通的，如果从任意一个节点出发，都可以到达其他所有节点。

**连通图的定义**：如果图中任意两个节点之间都存在路径，则称该图为连通图。

**判断连通性**：有多种算法可以用于判断图的连通性，其中最常用的方法是深度优先搜索（DFS）和广度优先搜索（BFS）。

1. **深度优先搜索（DFS）**：从某个节点开始，递归地探索其邻接节点，直到所有节点都被访问。如果能够访问到所有节点，则图是连通的。
2. **广度优先搜索（BFS）**：从某个节点开始，依次访问其未访问的邻接节点，直到所有节点都被访问。如果能够访问到所有节点，则图是连通的。

#### 路径长度计算

路径长度是指图中两个节点之间的最短路径长度。计算路径长度通常使用最短路径算法，如Dijkstra算法和Floyd算法。

1. **Dijkstra算法**：适用于无向图和有向图，计算单源最短路径。该算法基于贪心策略，每次选择未访问的节点中距离源节点最近的节点，更新其他节点的最短路径。
2. **Floyd算法**：适用于有向图，计算所有节点之间的最短路径。该算法使用动态规划方法，通过逐步扩展路径长度，找到所有节点之间的最短路径。

#### 宇宙暗能量网络中的连通性与路径长度

在宇宙暗能量网络中，连通性反映了宇宙结构的稳定性，而路径长度则代表了天体之间的引力作用强度。以下是一些关键点：

1. **宇宙结构的连通性**：宇宙中的天体通过引力相互作用形成复杂的网络结构。连通性分析有助于我们了解宇宙结构的稳定性和演化过程。
2. **路径长度与引力强度**：宇宙中的天体之间的引力作用强度与路径长度密切相关。路径长度较短的天体之间引力较强，容易形成星系团和超星系团。
3. **模拟中的应用**：在宇宙暗能量网络的模拟中，连通性和路径长度分析有助于我们研究宇宙结构的形成和演化，以及预测宇宙的未来状态。

通过深入分析图的连通性与路径长度，我们可以更好地理解宇宙暗能量网络的特性，为宇宙学研究和天体物理学提供有力支持。

### 5.2 拓扑排序与最短路径算法

在模拟宇宙暗能量网络时，拓扑排序与最短路径算法是两个非常重要的工具。拓扑排序用于对节点进行排序，以便按照依赖关系进行操作；最短路径算法则用于计算节点之间的最短路径，这对于研究宇宙结构的演化和稳定性具有重要意义。

#### 拓扑排序

拓扑排序是一种基于拓扑结构的排序方法，主要用于对有向无环图（DAG）进行排序。拓扑排序的主要目标是生成一个线性序列，使得每个节点都排在它的所有直接后继节点之前。

**算法步骤**：

1. 初始化一个空的拓扑排序结果列表。
2. 计算每个节点的入度（即有多少个节点指向它）。
3. 将所有入度为0的节点加入结果列表，并从图中删除这些节点。
4. 重复步骤3，直到所有节点都被加入结果列表。

**Python代码示例**：

```python
from collections import defaultdict, deque

def topological_sort(graph):
    in_degree = defaultdict(int)
    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    queue = deque()
    for node in graph:
        if in_degree[node] == 0:
            queue.append(node)

    sorted_order = []
    while queue:
        node = queue.popleft()
        sorted_order.append(node)
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return sorted_order
```

#### 最短路径算法

最短路径算法用于计算图中两点之间的最短路径。其中，Dijkstra算法是一种经典的单源最短路径算法，而Floyd-Warshall算法则用于计算所有节点之间的最短路径。

**Dijkstra算法**：

Dijkstra算法通过贪心策略，逐步选择未访问节点中距离源节点最近的节点，更新其他节点的最短路径。

**算法步骤**：

1. 初始化一个距离表，将所有节点的距离设置为无穷大，源节点的距离设置为0。
2. 创建一个优先队列，用于存储未访问节点及其距离。
3. 将源节点加入优先队列。
4. 重复以下步骤，直到优先队列为空：
   - 弹出优先队列中距离最小的节点。
   - 更新该节点的所有邻接节点的距离。
   - 如果某个邻接节点的距离更新，将其加入优先队列。

**Python代码示例**：

```python
import heapq

def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        if current_distance > distances[current_node]:
            continue

        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

**Floyd-Warshall算法**：

Floyd-Warshall算法通过动态规划方法，逐步计算所有节点之间的最短路径。该算法适用于有向图和无向图。

**算法步骤**：

1. 初始化一个距离表，将所有节点之间的距离设置为无穷大，对角线上的距离设置为0。
2. 重复以下步骤 \(n\) 次，其中 \(n\) 是节点数量：
   - 对于每个节点 \(i\) 和每个节点 \(j\)，计算 \(i\) 经过某个中间节点 \(k\) 到 \(j\) 的距离，并更新最短距离。

**Python代码示例**：

```python
def floyd_warshall(graph):
    distances = [[float('infinity') for _ in range(len(graph))] for _ in range(len(graph))]
    for i in range(len(graph)):
        for j in range(len(graph)):
            if i == j:
                distances[i][j] = 0
            else:
                distances[i][j] = graph[i][j]

    for k in range(len(graph)):
        for i in range(len(graph)):
            for j in range(len(graph)):
                distances[i][j] = min(distances[i][j], distances[i][k] + distances[k][j])

    return distances
```

### 5.3 数学公式及应用举例

#### 图的连通性与路径长度

1. **连通性**：

连通性可以通过图的邻接矩阵来描述，矩阵中 \(A[i][j] = 1\) 表示节点 \(i\) 与节点 \(j\) 是连通的，否则为 0。

   **公式**：  
   $$ A[i][j] = \begin{cases} 
   1 & \text{如果节点 } i \text{ 与节点 } j \text{ 是连通的} \\
   0 & \text{否则} 
   \end{cases} $$

2. **路径长度**：

路径长度是指从节点 \(i\) 到节点 \(j\) 的最短路径长度。可以通过图中的边的权重来计算。

   **公式**：  
   $$ L(i, j) = \min_{\text{路径 } p} \sum_{k \in p} w(k) $$

   其中，\(w(k)\) 是边 \(k\) 的权重。

#### 拓扑排序与最短路径算法

1. **Dijkstra算法**：

Dijkstra算法用于计算单源最短路径。其核心公式是更新节点的距离。

   **公式**：  
   $$ d[j] = \min(d[j], d[v] + w(v, j)) $$

   其中，\(d[j]\) 是从源节点 \(s\) 到节点 \(j\) 的最短距离，\(w(v, j)\) 是节点 \(v\) 到节点 \(j\) 的边权重。

2. **Floyd-Warshall算法**：

Floyd-Warshall算法用于计算所有节点之间的最短路径。

   **公式**：  
   $$ d[i][j] = \min(d[i][j], d[i][k] + d[k][j]) $$

   其中，\(d[i][j]\) 是从节点 \(i\) 到节点 \(j\) 的最短距离，\(d[i][k]\) 和 \(d[k][j]\) 分别是节点 \(i\) 到节点 \(k\) 以及节点 \(k\) 到节点 \(j\) 的距离。

#### 应用举例

**例1：计算节点之间的最短路径**

graph = {
    's': {'a': 4, 'b': 2},
    'a': {'s': 4, 'b': 1, 'c': 3},
    'b': {'s': 2, 'a': 1, 'c': 1},
    'c': {'a': 3, 'b': 1, 'd': 7},
    'd': {'c': 7}

def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    unvisited = list(graph.keys())

    while unvisited:
        current_node = min(unvisited, key=lambda node: distances[node])
        unvisited.remove(current_node)
        for neighbor, weight in graph[current_node].items():
            alt = distances[current_node] + weight
            if alt < distances[neighbor]:
                distances[neighbor] = alt

    return distances

print(dijkstra(graph, 's'))
