**Python源代码**：
```python
import matplotlib.pyplot as plt
import numpy as np

# 假设我们有一组暗物质分布的数据
x = np.random.normal(size=1000)
y = np.random.normal(size=1000)
data = np.vstack([x, y]).T

# 利用Matplotlib绘制散点图
plt.scatter(data[:, 0], data[:, 1])
plt.xlabel('X坐标')
plt.ylabel('Y坐标')
plt.title('暗物质分布')

```

**数学模型**：

$$

其中，$\theta$ 是光线弯曲的角度，$G$ 是引力常数，$M$ 是暗物质的质量，$c$ 是光速，$r$ 是光线与暗物质的距离。
