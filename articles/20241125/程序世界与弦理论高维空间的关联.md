    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

# 示例

## 第3章 弦理论的数学模型

### 3.1 空间与维度的概念

在弦理论中，空间和维度的概念与传统的物理学有所不同。传统的物理学通常基于四维时空，包括三个空间维度和一个时间维度。然而，弦理论引入了额外的空间维度，这些维度通常被认为是高维或额外维度。

弦理论的基本假设是，宇宙的基本构成单元不是点状粒子，而是微小的弦。这些弦在不同的维度上振动，形成了我们观察到的物质和现象。根据弦理论，空间的最小单位不是点，而是弦的端点。

空间维度可以分为以下几类：

1. **空间维度**：我们通常观察到的三维空间，即长度、宽度和高度。
2. **时间维度**：用于描述事件的发生顺序和时间流逝。
3. **高维**：在弦理论中，除了我们观察到的三维空间和一个时间维度之外，还存在额外的空间维度。这些高维通常被认为是紧凑的，即它们在非常小的尺度上弯曲或折叠，使得我们无法直接观测到。

### 3.2 弦的振动模式

弦的振动模式决定了物质的性质。在弦理论中，弦的振动模式可以用数学模型来描述。一个简单的弦振动模式可以表示为：

$$
y(x, t) = A \sin(kx) \cos(\omega t)
$$

其中，\( y(x, t) \) 是弦的振动位移，\( A \) 是振幅，\( k \) 是波数，\( \omega \) 是角频率。

弦的振动模式可以分为几种基本类型，如横波、纵波和混合波。每种振动模式对应于不同的物理现象。

- **横波**：弦的振动方向垂直于弦的长度方向。横波可以产生振动模式，如波的传播、声波等。
- **纵波**：弦的振动方向与弦的长度方向相同。纵波可以产生振动模式，如电磁波、光波等。
- **混合波**：弦的振动方向既垂直于弦的长度方向，又与弦的长度方向有一定夹角。混合波可以产生更复杂的振动模式。

### 3.3 弦理论的数学公式与推导

弦理论的数学公式与推导是理解弦振动模式和高维空间的关键。以下是几个重要的数学公式：

1. **弦的振动方程**：

$$
\frac{\partial^2 y}{\partial t^2} = c^2 \frac{\partial^2 y}{\partial x^2}
$$

这表明了弦的振动模式与空间中的波动现象有关，其中 \( c \) 是光速。

2. **弦的振动模式**：

$$
y(x, t) = A \sin(kx) \cos(\omega t)
$$

这描述了一个简单的弦振动模式，其中 \( A \) 是振幅，\( k \) 是波数，\( \omega \) 是角频率。

3. **弦的振动能量**：

$$
E = \frac{1}{2}\mu \cdot L^2

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
