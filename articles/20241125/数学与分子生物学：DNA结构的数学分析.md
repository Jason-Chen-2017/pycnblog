similarity_matrix = np.zeros((length, length))

for i in range(length):

            similarity_matrix[i][j] = 1

print(f"序列相似度：{similarity_percentage:.2f}%")
```

                   V[i][j] = V[i - 1][j - 1] + 1

               else:

               i -= 1
               j -= 1

```python
import numpy as np
from Bio import Seq

# 定义DNA序列
seq1 = Seq.Seq("AGTCGA")
seq2 = Seq.Seq("AGTCCG")

# 计算序列长度
length = min(len(seq1), len(seq2))

# 初始化相似度矩阵
similarity_matrix = np.zeros((length, length))

# 计算相似度矩阵
for i in range(length):
    for j in range(length):
        if seq1[i] == seq2[j]:
            similarity_matrix[i][j] = 1

# 计算相似度分数
similarity_score = np.sum(similarity_matrix)

# 计算相似度百分比
similarity_percentage = (similarity_score / length) * 100

print(f"序列相似度：{similarity_percentage:.2f}%")
```

- **导入库**：我们使用了NumPy库来创建和操作相似度矩阵，以及Biopython库来处理DNA序列。

- **计算序列长度**：我们使用`min`函数确保只处理两个序列中较短的那一个。
- **初始化相似度矩阵**：我们使用NumPy的`zeros`函数创建一个长度为`length`的二维数组，用来存储相似度矩阵。
- **计算相似度矩阵**：我们使用两个嵌套的`for`循环遍历序列的每个位置，如果两个位置的碱基相同，则将对应矩阵元素设置为1。
- **计算相似度分数**：我们使用`np.sum`函数计算矩阵中所有元素的加和，得到相似度分数。
- **计算相似度百分比**：我们将相似度分数除以序列长度，并将结果乘以100得到相似度百分比。

   ```python
   def predict_secondary_structure(seq):
       # 初始化变量
       V = [[0 for _ in range(len(seq) + 1)] for _ in range(len(seq) + 1)]
       P = [["" for _ in range(len(seq) + 1)] for _ in range(len(seq) + 1)]

       # 动态规划计算
       for i in range(1, len(seq) + 1):
           for j in range(1, len(seq) + 1):
               if seq[i - 1] == seq[j - 1]:
                   V[i][j] = V[i - 1][j - 1] + 1
                   P[i][j] = "1"
               else:
                   V[i][j] = max(V[i - 1][j], V[i][j - 1])
                   if V[i - 1][j] > V[i][j - 1]:
                       P[i][j] = "1"
                   else:
                       P[i][j] = "2"

       # 反向构建二级结构
       structure = ""
       i, j = len(seq), len(seq)
       while i > 0 and j > 0:
           if P[i][j] == "1":
               structure += "1"
               i -= 1
               j -= 1
           elif P[i][j] == "2":
               structure += "2"
               if V[i - 1][j] >= V[i][j - 1]:
                   i -= 1
               else:
                   j -= 1

       return structure
   ```
