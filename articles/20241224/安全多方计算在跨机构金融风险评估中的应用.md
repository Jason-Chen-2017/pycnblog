## 第2章：背景与概述

### 2.1 安全多方计算的基本概念

#### 2.1.1 定义

安全多方计算（Secure Multi-Party Computation，SMPC）是一种计算模型，允许多个参与方在不泄露自身数据的情况下，通过协同计算得出共同的结果。它是一种基于密码学的计算模型，通过一系列加密算法和协议设计，实现多方数据的协同分析。

#### 2.1.2 特点

安全多方计算具有以下几个显著特点：

1. **数据隐私保护**：各参与方在不泄露自身数据的情况下，仍然能够协同计算得出共同结果。
2. **协同计算**：多个参与方共同参与计算过程，提高计算效率和结果准确性。
3. **安全性**：通过加密算法和协议设计，确保计算过程的安全性和可信性。
4. **去中心化**：不依赖于单一中心化实体，各参与方平等参与计算过程。

#### 2.1.3 应用领域

安全多方计算广泛应用于金融、医疗、电商、政府监管等多个领域，主要应用包括：

1. **金融领域**：跨机构金融风险评估、信贷审批、反洗钱等。
2. **医疗领域**：跨机构医疗数据共享、隐私保护数据分析等。
3. **电商领域**：隐私保护的用户行为分析、跨平台交易数据共享等。
4. **政府监管**：跨部门数据协同分析、隐私保护的数据共享等。

### 2.2 安全多方计算的发展历程

#### 2.2.1 起源

安全多方计算最早由Goldreich等人在1987年提出，作为密码学领域的一个研究课题。最初的目的是探索如何在多个参与方之间进行安全的协同计算，而无需直接交换敏感数据。

随着密码学、分布式计算、云计算等技术的发展，安全多方计算逐渐成为一个独立的研究领域。1990年代，多项重要的安全多方计算协议被提出，如 Yao 的百万富翁问题解决方案、Canetti 和 Goldreich 提出的可验证秘密共享方案等。

## 第3章：核心概念与原理

### 3.1 加密算法

#### 3.1.1 对称加密算法

对称加密算法是一种加密和解密使用相同密钥的加密算法。其核心思想是利用加密密钥对数据进行加密，只有拥有解密密钥的用户才能解密数据。对称加密算法的优点是加密速度快，适合对大量数据进行加密处理。

常见对称加密算法包括：

1. **AES（Advanced Encryption Standard）**：一种由美国国家标准与技术研究所（NIST）推出的加密标准，支持128位、192位和256位密钥长度。
2. **DES（Data Encryption Standard）**：一种早期的加密标准，使用56位密钥，但由于其密钥长度较短，已逐渐被AES取代。

对称加密算法的缺点在于密钥分发困难，因为如果多个机构需要共享加密数据，就必须确保密钥的安全传输和存储。

#### 3.1.2 非对称加密算法

非对称加密算法使用一对密钥，即公钥和私钥。公钥用于加密数据，私钥用于解密数据。这种算法的核心思想是利用公钥进行加密，只有拥有私钥的用户才能解密数据。非对称加密算法的优点是解决了密钥分发问题，但加密速度相对较慢。

常见非对称加密算法包括：

1. **RSA（Rivest-Shamir-Adleman）**：一种基于大整数分解问题的加密算法，广泛应用于数字签名和加密通信。
2. **ECC（Elliptic Curve Cryptography）**：一种基于椭圆曲线离散对数问题的加密算法，相对于RSA，具有更高的安全性和更小的密钥长度。

非对称加密算法在安全多方计算中具有重要作用，因为它们可以确保数据在传输过程中的隐私保护。

### 3.2 协议设计

#### 3.2.1 安全多方计算协议的基本框架

安全多方计算协议是一种确保多个参与方在不泄露自身数据的情况下，进行协同计算的方法。基本框架包括以下几个环节：

1. **初始化**：参与方进行注册和身份验证，确保只有合法的参与方能够参与计算。
2. **数据传输**：参与方传输加密后的数据，确保数据在传输过程中的隐私保护。
3. **计算**：参与方在保护数据隐私的前提下，共同进行计算。
4. **结果输出**：参与方得到计算结果，但不泄露其他参与方的数据。

#### 3.2.2 主要协议类型

#### 4.1.1 Yao的百万富翁问题协议

Yao的百万富翁问题协议是安全多方计算领域最早提出的经典算法之一。其核心思想是通过一系列的加密和交换步骤，使得两个参与方能够在不泄露各自数据的情况下，得到共同的最大值。具体步骤如下：

1. **初始化**：两个参与方A和B生成一对公钥和私钥，并将公钥交换给对方。
2. **加密数据**：A和B分别将自己的数据加密，并使用对方的公钥进行加密。
3. **交换加密数据**：A将加密后的数据发送给B，B将加密后的数据发送给A。
4. **解密结果**：A和B分别使用自己的私钥解密接收到的加密数据，得到对方加密后的数据。
5. **计算最大值**：A和B分别在自己的数据基础上，结合对方加密后的数据进行计算，得到最大值。

#### 4.1.2 Canetti-Goldreich协议

Canetti-Goldreich协议是一种基于可验证秘密共享方案的安全多方计算协议。其核心思想是将每个参与方持有的数据分成多个部分，通过加密和交换，使得各参与方能够在不泄露自身数据的情况下，共同计算出一个结果。具体步骤如下：

1. **初始化**：多个参与方A、B、C等各自生成一对公钥和私钥，并将公钥交换给其他参与方。
2. **加密数据**：每个参与方将自身的数据加密，并使用其他参与方的公钥进行加密。
3. **交换加密数据**：每个参与方将加密后的数据发送给其他参与方。
4. **验证加密数据**：每个参与方使用其他参与方的私钥解密接收到的加密数据，验证数据的有效性。
5. **计算结果**：各参与方在自己的数据基础上，结合其他参与方的验证结果，共同计算出一个结果。

2. **加密数据**：每个参与方将自身的数据加密，并使用其他参与方的公钥进行加密。

5. **解密结果**：各参与方使用自己的私钥解密接收到的加密结果，得到最终的计算结果。
