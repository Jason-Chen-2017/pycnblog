1. **个体幸福度计算**：

   假设一个个体有 $70\%$ 的物质追求和 $30\%$ 的精神成长，权重系数 $k_1=0.6$，$k_2=0.4$，则该个体的幸福度为：

   $$ \text{幸福度} = 0.6 \times 0.7 + 0.4 \times 0.3 = 0.42 + 0.12 = 0.54 $$

2. **社会和谐指数计算**：

   假设一个社会中有100个个体，其中 $60\%$ 的个体有 $70\%$ 的物质追求和 $30\%$ 的精神成长，$30\%$ 的个体有 $30\%$ 的物质追求和 $70\%$ 的精神成长，则该社会的和谐指数为：

   $$ \text{社会和谐指数} = 0.6 \times 0.7 \times 60\% + 0.4 \times 0.3 \times 30\% = 0.42 \times 0.6 + 0.12 \times 0.3 = 0.252 + 0.036 = 0.298 $$

通过上述数学模型和公式的推导，我们可以定量地分析物质追求和精神成长对幸福度和社会和谐指数的影响，从而更好地理解价值观重构的过程和效果。希望读者能够通过这一部分的讲解，对数学模型在价值观重构中的应用有更深入的认识。

from rest_framework import status
from rest_framework.response import Response
from rest_framework.views import APIView

from rest_framework.response import Response
from rest_framework.views import APIView

class UserLogin(APIView):

    def post(self, request):
        data = request.data
