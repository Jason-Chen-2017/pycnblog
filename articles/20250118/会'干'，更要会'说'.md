#### 3.1.2 算法原理

在本部分，我们将介绍一个常见的算法——快速排序（Quick Sort）的原理。

- **数学模型**：

$$
\begin{aligned}
    &\text{如果 } a_{l} < a_{r}, \\
    &\text{则 } \text{partition}(a, l, r) \\
    &\text{返回 } \text{pivot} = \text{partition}(a, l, r) \\
    &\text{其中 } \text{pivot} \text{ 为分区点} \\
    &\text{则 } a_{l} < \text{pivot} < a_{r}
\end{aligned}
$$

- **公式讲解**：

  - **公式1**：

  $$\text{pivot} = \text{partition}(a, l, r)$$

  解释：分区操作，返回分区点。

  - **公式2**：

  $$a_{l} < \text{pivot} < a_{r}$$

  解释：分区后的数组关系。

#### 3.1.3 举例说明

假设我们有以下数组：

```python
arr = [3, 1, 4, 1, 5, 9, 2, 6, 5]
```

使用快速排序算法后，数组将变为：

```python
arr = [1, 1, 2, 3, 4, 5, 5, 6, 9]
```
