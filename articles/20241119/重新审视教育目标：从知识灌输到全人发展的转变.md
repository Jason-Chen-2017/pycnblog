#### 1. 全面发展指数（T全面发展指数）

全面发展指数（T全面发展指数）是一个衡量学生全面发展水平的综合指标。它基于学生的学术成绩、情感发展、社交能力和创新能力等多个维度进行计算。以下是T全面发展指数的数学模型：

\[ TDI = \frac{AC + ED + SS + II}{4} \]

其中：
- \( AC \) 表示学术成绩（ Academic Performance），权重为0.3
- \( ED \) 表示情感发展（Emotional Development），权重为0.2
- \( SS \) 表示社交能力（Social Skill），权重为0.2
- \( II \) 表示创新能力（Innovation and Initiative），权重为0.3

#### 2. 情感发展评分模型

情感发展的评分模型通常使用标准化的问卷或量表进行评估。以下是一个简化的情感发展评分模型：

\[ ED_Score = \frac{P \cdot Q}{100} \]

其中：
- \( P \) 表示情感积极评分，最高分为100分
- \( Q \) 表示情感消极评分，最低分为0分

#### 3. 社交能力评估公式

社交能力评估通常通过角色扮演、小组讨论和实际社交情境来进行。以下是一个社交能力评估的公式：

\[ SS_Score = \frac{RA + GD + PA}{3} \]

其中：
- \( RA \) 表示角色扮演评分，满分100分
- \( GD \) 表示小组讨论评分，满分100分
- \( PA \) 表示实际社交情境表现评分，满分100分

#### 4. 创新能力评估公式

创新能力评估可以通过设计思维、问题解决和实验设计等多个方面进行。以下是一个简化的创新能力评估公式：

\[ II_Score = \frac{DT + PS + ED}{3} \]

其中：
- \( DT \) 表示设计思维评分，满分100分
- \( PS \) 表示问题解决评分，满分100分
- \( ED \) 表示实验设计评分，满分100分

- 学术成绩（AC）：85分
- 情感发展（ED）：80分

根据上述公式，我们可以计算出小明的全面发展指数（T全面发展指数）：

\[ TDI = \frac{85 + 80 + 90 + 88}{4} = 86.5 \]

同时，我们可以根据情感发展评分模型计算小明的情感发展评分：

\[ ED_Score = \frac{P \cdot Q}{100} = \frac{85 \cdot 80}{100} = 68 \]

类似地，我们可以计算小明的社交能力评估评分和创新能力评估评分：

\[ SS_Score = \frac{RA + GD + PA}{3} = \frac{90 + 80 + 85}{3} = 86.7 \]

\[ II_Score = \frac{DT + PS + ED}{3} = \frac{85 + 90 + 88}{3} = 87 \]

from django.shortcuts import render, redirect
from .models import User
from .forms import UserRegistrationForm, UserLoginForm

def register(request):
    if request.method == 'POST':
        form = UserRegistrationForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('login')
    else:
        form = UserRegistrationForm()
    return render(request, 'register.html', {'form': form})

def login(request):
    if request.method == 'POST':
        form = UserLoginForm(request.POST)
        if form.is_valid():
            user = form.get_user()
            request.session['user'] = user.id
            return redirect('home')
    else:
        form = UserLoginForm()
    return render(request, 'login.html', {'form': form})
```

            new_comment.save()

from django.shortcuts import render, redirect
from .models import Message
from .forms import MessageForm

def send_message(request, recipient_id):
    if request.method == 'POST':
        form = MessageForm(request.POST)
        if form.is_valid():
            message = form.save(commit=False)
            message.sender = request.user
            message.recipient = User.objects.get(id=recipient_id)
            message.save()
            return redirect('message_list')
    else:
        form = MessageForm()
    return render(request, 'send_message.html', {'form': form})

def message_list(request):
    messages = Message.objects.filter(sender=request.user).order_by('-timestamp')
    return render(request, 'message_list.html', {'messages': messages})
```
