### 个人主义的起源与发展

个人主义作为一种价值观体系，其起源可以追溯到古希腊哲学。在古希腊，哲学家如苏格拉底、柏拉图和亚里士多德等，都强调个人的价值和尊严。其中，亚里士多德认为，个人的幸福是实现其潜能的过程，而这种潜能的实现需要通过理性思考和实践。这一思想为后来的个人主义奠定了基础。

随着历史的发展，个人主义在近代哲学中得到了进一步的发展。约翰·洛克是个人主义的代表人物之一，他提出了“自然权利”的概念，认为每个人都拥有生命、自由和财产权。洛克的思想对后来的美国独立战争和《独立宣言》产生了深远影响。

个人主义的主要特点包括：

1. **个人自由与权利**：个人主义强调个人的自由和权利，认为每个人都应该有权决定自己的行为和生活方式。
2. **个人成就与自我实现**：个人主义鼓励个人追求自我实现和成就，认为个人的发展和进步是社会进步的基础。

个人主义的代表人物和思想还包括：

1. **罗伯特·舒勒**：他提出了“人类本性论”，认为人的本质是理性的，追求幸福和实现自我是人的本能。
2. **约翰·斯图亚特·密尔**：他是功利主义的代表人物，认为个人的行为应该以最大化幸福为目标。
3. **约翰·洛克**：他提出了“自然权利”的概念，认为每个人都应该拥有生命、自由和财产权。

### 新集体主义的兴起

新集体主义作为一种与个人主义相对的价值观体系，其兴起可以追溯到20世纪初期。第一次世界大战和第二次世界大战后，社会动荡和战争创伤使人们对个人主义产生了质疑，开始寻求一种新的价值观来重建社会秩序。

新集体主义的主要特点包括：

1. **社会责任与集体利益**：新集体主义强调个人的行为应该为社会和集体的利益服务，认为个人的利益应该服从于集体的利益。
2. **集体团结与协作**：新集体主义鼓励集体团结和协作，认为只有通过集体的力量才能实现社会的和谐和进步。

新集体主义的代表人物和思想包括：

1. **埃德蒙·伯克**：他主张社会应该保持稳定和传统，反对过度个人主义。
2. **费迪南德·马林诺夫斯基**：他是文化人类学的代表人物，强调文化和社会对个人行为的影响。

```python
        self.individuals = [Individual(freedom=np.random.uniform(0, 1), responsibility=np.random.uniform(0, 1)) for _ in range(num_individuals)]

    def simulate_one_year(self, collective_control):
        actions = []
        for individual in self.individuals:
            action = individual.make_decision(collective_control)
            actions.append(action)
        return actions

    def plot_actions(self, collective_controls, actions):
        for control, action_list in zip(collective_controls, actions):
            labels, counts = np.unique(action_list, return_counts=True)
            sizes = [count for label, count in zip(labels, counts) if label == "自由行动"]
            colors = ["green" if label == "自由行动" else "red" for label, count in zip(labels, counts)]
            plt.pie(sizes, labels=labels, colors=colors, autopct='%.1f%%', startangle=90)
            plt.title(f"集体控制：{control}")
            plt.axis('equal')
            plt.show()

# 社会模型初始化
society = Society(num_individuals=100)

# 模拟不同集体控制水平下的社会行为
collective_controls = [0.1, 0.5, 0.9]
actions = [society.simulate_one_year(control) for control in collective_controls]

# 绘制不同集体控制水平下的行动比例
society.plot_actions(collective_controls, actions)
```

#### 代码解读与分析

这段代码定义了两个类：`Individual` 和 `Society`。`Individual` 类表示社会中的个体，具有自由度和责任感属性。`Society` 类表示整个社会，包含一系列个体，并提供了模拟社会行为的函数。

- `__init__` 方法用于初始化个体和整个社会。
- `make_decision` 方法用于模拟个体在不同集体控制水平下的决策。
- `simulate_one_year` 方法用于模拟一年内社会行为的变化。
- `plot_actions` 方法用于绘制不同集体控制水平下的行动比例。

通过这段代码，我们可以模拟不同价值观体系下的社会行为，并分析集体控制对个体决策的影响。
