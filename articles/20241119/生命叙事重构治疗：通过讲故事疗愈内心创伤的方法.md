### 第2章：叙事治疗的理论基础

#### 2.1 心理创伤理论

心理创伤理论是叙事治疗的重要基础。心理创伤理论关注个体在遭遇极端负面事件后产生的心理反应和长期影响。这些事件可能包括战争、暴力、性侵、自然灾害等，它们会对个体的心理产生深远的负面影响。

**核心概念与联系**

心理创伤理论的核心概念包括：

1. **创伤后应激障碍（Post-Traumatic Stress Disorder，PTSD）**：PTSD 是一种常见的心理创伤后反应，表现为对创伤事件的过度反应，如闪回、失眠、过度警觉等。

2. **情感失调（Emotional Dysregulation）**：心理创伤可能导致个体的情感调节能力受损，从而出现情绪波动大、情感失控等问题。

3. **认知扭曲（Cognitive Distortion）**：心理创伤可能导致个体的认知出现扭曲，如负面的自我评价、对未来的悲观等。

4. **记忆重构（Memory Reconstruction）**：心理创伤可能导致个体的记忆出现重构，即记忆内容变得模糊或扭曲。

以下是心理创伤理论的核心概念及其相互关系的架构：

```mermaid

A[心理创伤] --> B[创伤后应激障碍]
B --> C[情感失调]
C --> D[认知扭曲]
D --> E[记忆重构]
```

**核心算法原理讲解**

心理创伤的算法原理可以理解为对个体心理状态的监控和调整。以下是心理创伤理论的伪代码解释：

- **情感失调**：个体可能会出现情绪波动大、情感失控等问题。
