以下是一个简单的Python脚本，用于监控和控制互联网使用时间。

```python
import time
from datetime import datetime, timedelta

def set_daily_limit(hours):
    return timedelta(hours=hours)

def check_usage_limit(start_time, daily_limit):
    end_time = start_time + daily_limit
    current_time = datetime.now()
    if current_time > end_time:
        return "超时了！请减少使用时间。"
    else:
        return "当前使用时间：{}。还可以使用{}。".format((current_time - start_time).total_seconds(), (end_time - current_time).total_seconds())

def main():
    daily_limit = set_daily_limit(2)  # 设定每日上网时间限制为2小时
    start_time = datetime.now()  # 记录开始时间
    print("每日上网时间限制：2小时。请合理使用互联网。")

    while True:
        print(check_usage_limit(start_time, daily_limit))
        time.sleep(60)  # 每分钟检查一次

if __name__ == "__main__":
    main()
```

### 代码解读与分析

这个Python脚本的主要功能是监控用户的每日上网时间，并提醒用户是否超时。

- `set_daily_limit(hours)`: 函数用于设定每日上网时间限制。
- `check_usage_limit(start_time, daily_limit)`: 函数用于检查当前上网时间是否超过限制，并返回提示信息。
- `main()`: 主函数，用于启动监控程序。

通过运行这个脚本，用户可以实时了解自己的上网时间，并受到提醒，有助于更好地控制上网时间。
