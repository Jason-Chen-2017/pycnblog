**5.1 基础冰淇淋配方**

制作经典手工冰淇淋的基础配方通常包括以下几种主要原料：

- 奶油：奶油是冰淇淋的重要组成部分，提供了丰富的口感和奶香味。
- 牛奶：牛奶为冰淇淋提供了柔和的口感和淡淡的奶香。
- 糖：糖是冰淇淋的甜味来源，同时也帮助保持冰淇淋的稳定性和口感。
- 稳定剂：稳定剂如明胶或果胶可以帮助冰淇淋在冷冻过程中保持均匀的质地。

以下是一个简单的经典手工冰淇淋配方：

```
材料：
- 奶油 200克
- 牛奶 200克
- 糖 100克
- 稳定剂（如明胶） 5克
- 鸡蛋 2个（蛋白和蛋黄分开）

步骤：
1. 将奶油和糖在室温下搅拌均匀，直到奶油发白。
2. 将牛奶加热至温热，然后缓慢倒入奶油混合物中，同时不断搅拌。
3. 将鸡蛋蛋黄和牛奶混合物混合均匀。
4. 加入稳定剂，搅拌均匀。
5. 将混合物放入冰箱冷藏至少4小时，使其充分凝固。
6. 将凝固的混合物取出，用搅拌机打至光滑细腻。
7. 将搅拌好的冰淇淋倒入冰淇淋机中，冷冻至完全凝固。
8. 完成后，将冰淇淋放入密封容器中，冷藏保存。
```

**核心算法原理讲解**

```

5. **掌握冰淇淋的装饰与保存技巧**：学习如何将冰淇淋装饰得美观诱人，以及如何正确保存冰淇淋，延长其保质期。
