### 伪代码：情感相似度计算

```plaintext
// 情感相似度计算伪代码
function calculateEmotionalSimilarity(networkA, networkB):
    # 初始化相似度分数
    similarityScore = 0

    # 遍历用户A的社交网络
    for friendA in networkA:
        # 遍历用户B的社交网络
        for friendB in networkB:
            # 如果用户A和用户B有共同的朋友，则增加相似度分数
            if friendA == friendB:
                similarityScore += 1

    # 返回相似度分数
    return similarityScore
```
