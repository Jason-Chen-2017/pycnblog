```plaintext
function evaluateEmotionalCapital(people):
    totalStrength = 0
    for person in people:
        emotions = [identifyEmotion(text) for text in person.interactions]
        strengths = [measureEmotionStrength(text, emotion) for text, emotion in zip(person.interactions, emotions)]
        totalStrength += sum(strengths)
    averageStrength = totalStrength / len(people)
    return averageStrength
```

## 数学模型和数学公式讲解

情感资本的测量通常涉及以下数学模型和公式：

### 1. 情感强度评分模型
情感强度评分模型用于计算单个情感事件的强度。以下是一个简单的情感强度评分模型公式：

$$
S_i = f(w_i, e_i)
$$

其中，$S_i$表示第$i$个情感事件的强度，$w_i$表示情感事件的权重，$e_i$表示情感事件的情感值。

### 2. 情感资本综合评分模型
情感资本综合评分模型用于计算个体或群体的情感资本水平。以下是一个简单的情感资本综合评分模型公式：

$$
E_c = \frac{1}{N} \sum_{i=1}^{N} S_i
$$

其中，$E_c$表示情感资本的综合评分，$N$表示情感事件的个数。

### 3. 情感资本相关性分析模型
情感资本相关性分析模型用于分析情感资本与人际关系质量的相关性。以下是一个简单的情感资本相关性分析模型公式：

$$
\rho_{ec} = \frac{Cov(E_c, Q)}{SD(E_c) \cdot SD(Q)}
$$

其中，$\rho_{ec}$表示情感资本与人际关系质量的相关性，$Cov$表示协方差，$SD$表示标准差，$E_c$表示情感资本的综合评分，$Q$表示人际关系质量的评分。
