**第一部分：跨年龄学习的背景与基本理论**

1. **跨年龄学习的概念与重要性**
   - 跨年龄学习是指在不同年龄段之间进行知识、技能和经验的交流和传递。它不仅包括不同年龄段人群之间的学习，也包括同一年龄段内不同认知水平人群之间的学习。
   - 跨年龄学习的重要性在于：
     - **促进知识更新与技能提升**：随着科技的迅速发展，知识更新速度加快，跨年龄学习有助于个人不断更新知识结构，提升技能水平。
     - **促进教育公平**：跨年龄学习可以帮助不同年龄段的人获得平等的学习机会，促进教育公平。
     - **丰富学习体验**：跨年龄学习可以提供多样化的学习体验，增加学习的趣味性和互动性。

2. **终身教育的概念与代际互助模式**
   - **终身教育**：终身教育是指一个人从出生到死亡，通过持续的学习和培训来适应社会发展和个人成长的需求。它强调教育的连续性和综合性，不仅包括正规教育，还包括非正规教育和非正式学习。
   - **代际互助模式**：代际互助模式是指在终身教育中，不同年龄段的人通过相互学习、交流和支持来实现共同成长。这种模式强调代际之间的互动和合作，有助于提升学习效果和社会凝聚力。

3. **跨年龄学习的代际互助模式概述**
   - **基本原理**：代际互助模式基于教育心理学、社会学和人类行为学等理论基础，强调代际之间的互动和学习。它通过建立互助小组、开展跨年龄交流和项目合作等方式，促进知识的共享和技能的提升。
   - **核心要素**：代际互助模式的核心要素包括：
     - **互动性**：通过面对面的交流、合作和互动，促进不同年龄段之间的理解和信任。
     - **共享性**：通过知识共享和经验交流，实现知识的传递和技能的提升。
     - **支持性**：通过提供支持和帮助，增强学习者的自信心和动力。
   - **分类与特点**：代际互助模式可以根据不同的应用场景和目标人群进行分类，如：
     - **家庭代际互助**：在家庭内部，不同年龄段的人通过共同学习和交流，促进家庭成员之间的沟通和理解。
     - **社区代际互助**：在社区层面，不同年龄段的人通过参与社区项目和服务，实现共同成长和社会贡献。
     - **教育机构代际互助**：在教育机构内，通过组织跨年龄的课程和活动，促进学生的全面发展。

@app.route('/login', methods=['POST'])
def login():
    data = request.json
    username = data['username']
    password = data['password']
    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({"message": "Login successful", "token": "generated_token"})
    else:
        return jsonify({"message": "Invalid credentials"}), 401

# 获取课程列表
@app.route('/courses', methods=['GET'])
def get_courses():
    courses = Course.query.all()
    return jsonify({"courses": [course.name for course in courses]})

    new_user = User(username=username, password=password, age=age, role=role)

    return jsonify({"message": "User registered successfully"}), 201

# 登录
@app.route('/login', methods=['POST'])
def login():
    data = request.json
    username = data['username']
    password = data['password']
    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({"message": "Login successful", "token": "generated_token"})
    else:
        return jsonify({"message": "Invalid credentials"}), 401

# 获取课程列表
@app.route('/courses', methods=['GET'])
def get_courses():
    courses = Course.query.all()
    return jsonify({"courses": [course.name for course in courses]})

if __name__ == '__main__':
    app.run(debug=True)

def register():
    data = request.json
    username = data['username']
    password = data['password']
    age = data['age']
    role = data['role']
    new_user = User(username=username, password=password, age=age, role=role)
    db.session.add(new_user)
    db.session.commit()
    return jsonify({"message": "User registered successfully"}), 201

# 登录
@app.route('/login', methods=['POST'])
def login():
    data = request.json
    username = data['username']
    password = data['password']
    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({"message": "Login successful", "token": "generated_token"})
    else:
        return jsonify({"message": "Invalid credentials"}), 401

@app.route('/courses', methods=['GET'])
def get_courses():
    courses = Course.query.all()
    return jsonify({"courses": [course.name for course in courses]})
