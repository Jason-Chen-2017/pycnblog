**未来社会背景下的核心素养**

为了培养适应未来社会的核心素养，我们可以构建一个包含以下几个方面的核心素养框架：

3. **信息素养**：培养能够高效获取、处理和应用信息的能力。

import matplotlib.pyplot as plt

# 创建图
G = nx.Graph()

# 添加节点和边

G.add_edges_from([('Alice', 'Bob'), ('Alice', 'Charlie'), ('Bob', 'Charlie'), ('Charlie', 'David')])

# 绘制图
nx.draw(G, with_labels=True)
