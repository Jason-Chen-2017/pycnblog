## 2.3 算法实现

```python
def calculate_sustainable_impact(material_innovation, market_data):
    # 计算材料创新对市场的影响
    impact = material_innovation * market_data.peg
    return impact

# 示例
class MarketData:
    def __init__(self, peg):
        self.peg = peg

innovation_score = 0.8  # 创新指数
market = MarketData(peg=1.5)
impact = calculate_sustainable_impact(innovation_score, market)
print(f"创新对市场的整体影响为: {impact}")
```

## 2.4 数学模型

$$
\text{创新影响} = \text{创新指数} \times \text{市盈率}
$$

其中，创新指数的范围是 $0 \leq \text{创新指数} \leq 1$，市盈率是企业市盈率指标。

import pandas as pd
import matplotlib.pyplot as plt

def main():
    # 数据加载
    data = pd.read_csv('market_data.csv')
    # 创新影响分析
    data['创新影响'] = data['创新指数'] * data['市盈率']
    # 可视化
    plt.scatter(data['创新指数'], data['市盈率'], c=data['创新影响'])
    plt.xlabel('创新指数')
    plt.ylabel('市盈率')
    plt.colorbar(label='创新影响')
    plt.show()

if __name__ == "__main__":
    main()
