# 第1章: 背景介绍

## 1.1 海洋塑料污染的背景与现状

### 1.1.1 海洋塑料污染的定义与问题背景

海洋塑料污染是指人类活动产生的塑料制品进入海洋环境，对生态系统造成破坏的现象。塑料在自然环境中难以降解，长期积累会对海洋生物、水质和人类健康造成严重威胁。据统计，全球每年有超过800万吨塑料垃圾进入海洋，预计到2050年，海洋中的塑料垃圾总量将超过鱼类。

### 1.1.2 全球海洋塑料污染的现状与趋势

近年来，海洋塑料污染问题日益严重，主要表现为：

1. **塑料碎片化**：塑料制品在海洋中逐渐分解成微小颗粒，称为微塑料。
2. **生物累积效应**：海洋生物误食塑料，导致生态链污染。
3. **经济影响**：塑料污染对渔业、旅游业和航运业造成巨大经济损失。

### 1.1.3 海洋塑料污染对环境和经济的影响

海洋塑料污染不仅破坏了海洋生态系统，还对全球经济和社会发展产生了深远影响。例如，渔业损失每年高达数亿美元，而清理海洋垃圾的费用也在不断增加。
