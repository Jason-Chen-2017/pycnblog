- **3.2 算法实现代码**
  - 使用 Python 实现核心算法：
  ```python
  import pandas as pd
  from sklearn import linear_model

  # 数据清洗
  data = pd.read_csv('smart_city_data.csv')
  data = data.dropna()

  # 特征提取
  features = data[['temperature', 'humidity']]
  target = data['energy_usage']

  # 模型训练
  model = linear_model.LinearRegression()
  model.fit(features, target)

  # 智能决策
  new_data = pd.DataFrame({'temperature': [25], 'humidity': [60]})
  prediction = model.predict(new_data)
  print(prediction)
  ```

- **3.3 算法原理的数学模型和公式**
  - 线性回归模型：
    $$ y = \beta_0 + \beta_1 x + \epsilon $$
  - 其中：
    - $$ y $$ 是目标变量（能源消耗）。
    - $$ x $$ 是特征变量（温度、湿度）。
    - $$ \beta_0 $$ 和 $$ \beta_1 $$ 是模型参数。
    - $$ \epsilon $$ 是误差项。
