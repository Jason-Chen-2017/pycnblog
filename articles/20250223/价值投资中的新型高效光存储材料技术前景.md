# 第1章: 光存储材料的基本概念

## 1.1 光存储材料的定义与分类

### 1.1.1 光存储材料的定义  
光存储材料是指能够通过光信号（如激光）进行数据存储和读取的材料。与传统的电子存储介质（如硬盘、光盘）不同，光存储材料通常具有更高的存储密度、更快的读写速度以及更长的使用寿命。

### 1.1.2 光存储材料的主要分类  
光存储材料主要分为以下几类：  
1. **光敏材料**：能够在外界光刺激下发生化学或物理变化的材料，如光敏树脂。  
2. **磁光材料**：具有磁性和光敏感性的材料，如光盘中的磁光记录材料。  
3. **全息存储材料**：能够记录三维全息图像的材料，如某些高分子聚合物。  

### 1.1.3 光存储材料的物理化学特性  
光存储材料的性能主要取决于其物理化学特性，包括光吸收率、热稳定性、耐久性等。

2. **第二代**：蓝光光盘（Blu-ray Disc）的出现，显著提高了存储容量。  
3. **第三代**：全息存储技术的突破，使得存储密度达到前所未有的高度。
