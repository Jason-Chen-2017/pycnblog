## 第5章: 机器学习算法原理与数学模型

### 5.1 机器学习算法原理

#### 5.1.1 线性回归
线性回归是一种简单而强大的回归算法，用于预测连续型变量。其基本假设是变量之间的线性关系。

**公式**：
$$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \cdots + \beta_nx_n + \epsilon $$

**流程图**：
```mermaid

    A[输入数据] --> B[特征提取]
    B --> C[模型训练]
    C --> D[风险预测]
    D --> E[结果输出]
```

#### 5.1.2 随机森林
随机森林是一种基于决策树的集成算法，通过随机选择特征和样本进行训练，具有较强的抗过拟合能力。

**公式**：
$$ y = \sum_{i=1}^{n} \text{Tree}(x_i) $$

#### 5.1.3 神经网络
神经网络是一种模拟人脑工作原理的深度学习模型，适用于复杂非线性关系的建模。

**公式**：
$$ y = \sigma(w_2 \cdot \sigma(w_1 x + b_1) + b_2) $$

**流程图**：
```mermaid

    Activation2 --> Output
```

### 5.2 数学模型与公式

#### 5.2.1 线性回归的最小二乘法
线性回归的目标是最小化预测值与实际值之间的平方差之和。

$$ \text{最小化} \quad \sum_{i=1}^{m}(y_i - (\beta_0 + \beta_1x_{i1} + \beta_2x_{i2} + \cdots + \beta_kx_{ik}))^2 $$

#### 5.2.2 随机森林的集成学习
随机森林通过投票或平均的方式进行预测，有效降低单棵决策树的方差。

$$ y = \text{平均值}(\text{Tree}_1(x), \text{Tree}_2(x), \cdots, \text{Tree}_n(x)) $$

#### 5.2.3 神经网络的激活函数
常用的激活函数包括sigmoid、ReLU和tanh，用于引入非线性因素。

### 5.3 算法实现与代码示例

#### 5.3.1 线性回归实现
```python
import numpy as np

class LinearRegression:
    def __init__(self):
        self.weights = None
        self.bias = None

    def fit(self, X, y):
        X = np.hstack([np.ones((X.shape[0], 1)), X])
        self.theta = np.linalg.inv(X.T @ X) @ (X.T @ y)
        self.bias = self.theta[0]
        self.weights = self.theta[1:]

    def predict(self, X):
        return self.bias + np.dot(X, self.weights.T)
```

```python
class RandomForestRegressor:
    def __init__(self, n_estimators=100):
        self.n_estimators = n_estimators
        self.estimators = []

    def fit(self, X, y):
        for _ in range(self.n_estimators):
            # 随机选择样本和特征
            sample_indices = random.sample(range(X.shape[0]), int(X.shape[0] * 0.8))
            feature_indices = random.sample(range(X.shape[1]), int(X.shape[1] * 0.8))
            X_subset = X[sample_indices, :][:, feature_indices]
            y_subset = y[sample_indices]
            tree = DecisionTreeRegressor(max_depth=5)
            tree.fit(X_subset, y_subset)
            self.estimators.append(tree)

    def predict(self, X):
        predictions = []
        for tree in self.estimators:
            predictions.append(tree.predict(X))
        return np.mean(predictions, axis=0)
```

### 7.2 核心代码实现

#### 7.2.1 数据预处理

```python
import pandas as pd
import numpy as np

# 加载数据
data = pd.read_csv('portfolio.csv')

# 数据清洗
data = data.dropna()
data = pd.get_dummies(data)
```

#### 7.2.2 模型训练与风险分解
```python
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.ensemble import RandomForestRegressor

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(data.drop('risk', axis=1), data['risk'], test_size=0.2)

# 线性回归模型
lr_model = LinearRegression()
lr_model.fit(X_train, y_train)

# 随机森林模型
rf_model = RandomForestRegressor(n_estimators=100)
rf_model.fit(X_train, y_train)
```

#### 7.2.3 风险分解与可视化
```python
import matplotlib.pyplot as plt

# 线性回归模型预测
lr_predictions = lr_model.predict(X_test)

# 随机森林模型预测
```
