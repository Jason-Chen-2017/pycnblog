## 2.1 自监督学习的核心原理

### 2.1.1 自监督学习的数学模型  
自监督学习的数学模型通常包括编码器和解码器两部分。编码器将输入数据映射到一个潜在空间，解码器则将潜在空间的表示还原为原始数据。数学表示如下：  
$$ \text{编码器: } z = f(x) $$  
$$ \text{解码器: } \hat{x} = g(z) $$  

### 2.1.2 自监督学习的算法流程  
自监督学习的算法流程包括以下步骤：  
1. **数据预处理**：将原始数据转换为模型输入格式。  
2. **特征提取**：通过编码器提取数据的潜在表示。  
3. **目标函数设计**：定义预训练目标函数。  
4. **模型优化**：通过反向传播优化模型参数。  

### 2.1.3 自监督学习的关键技术对比  
| 技术          | 对比点           | 优缺点           |

| 对比学习       | 基于相似性度量     | 能够有效提升特征表示质量，但需要设计合适的相似性度量。 |

## 3.2 自监督学习的数学模型与公式

### 3.2.1 预训练目标函数  
预训练目标函数通常包括重构损失和对比损失。  
- 重构损失：  
$$ L_{\text{recon}} = \mathbb{E}_{x \sim p(x)} [\mathcal{L}(x, \hat{x})] $$  
其中，$\mathcal{L}(x, \hat{x})$ 是衡量$x$和$\hat{x}$之间差异的损失函数。  

- 对比损失：  
$$ L_{\text{contrast}} = -\mathbb{E}_{x \sim p(x)} [\log \frac{p(x,y)}{p(x)p(y)}] $$  

### 3.2.2 损失函数设计  
损失函数通常由重构损失和对比损失组成：  
$$ L = \alpha L_{\text{recon}} + (1-\alpha) L_{\text{contrast}} $$  
其中，$\alpha$是平衡系数。

### 3.2.3 优化策略与数学推导  
自监督学习的优化过程通常采用随机梯度下降（SGD）或Adam优化器。数学推导如下：  
$$ \theta_{t+1} = \theta_t - \eta \nabla_{\theta} L $$  
其中，$\eta$是学习率。

## 5.2 项目核心实现

### 5.2.1 数据预处理与加载  
```python
import torch
import numpy as np
from torch.utils.data import Dataset, DataLoader

class CustomDataset(Dataset):
    def __init__(self, data, transform=None):
        self.data = data
        self.transform = transform

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        x = self.data[idx]
        if self.transform:
            x = self.transform(x)
        return x

# 示例数据
data = np.random.randn(100, 3, 224, 224)
dataset = CustomDataset(data)
dataloader = DataLoader(dataset, batch_size=32, shuffle=True)
```

### 5.2.2 模型定义与训练  
```python
import torch.nn as nn
import torch.optim as optim

class Encoder(nn.Module):
    def __init__(self, input_dim, hidden_dim):
        super(Encoder, self).__init__()
        self.encoder = nn.Sequential(
            nn.Conv2d(input_dim, hidden_dim, kernel_size=3, stride=2, padding=1)
        )

    def forward(self, x):
        return self.encoder(x)

class Decoder(nn.Module):
    def __init__(self, hidden_dim, output_dim):
        super(Decoder, self).__init__()
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(hidden_dim, output_dim, kernel_size=3, stride=2, padding=1)
        )

    def forward(self, z):
        return self.decoder(z)

# 模型实例化
encoder = Encoder(3, 64)
decoder = Decoder(64, 3)
```

### 5.2.3 损失函数与优化器  
```python
criterion = nn.MSELoss()
optimizer = optim.Adam(torch.cat([list(encoder.parameters()), list(decoder.parameters())], 
                                 ignore_keys=lambda x: x is None), lr=0.001)

# 训练过程
for epoch in range(100):
    for batch_x in dataloader:
        z = encoder(batch_x)
        recon_x = decoder(z)
        loss = criterion(recon_x, batch_x)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
```
