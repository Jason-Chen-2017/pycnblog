### 第5章：情感强度计算

#### 5.1 情感强度公式
$$ \text{情感强度} = \sum_{i=1}^{n} w_i \cdot e_i $$
其中，\( w_i \) 是情感词的权重，\( e_i \) 是情感词的情感值。

#### 8.2 核心代码
```python
import nltk
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC

# 情感词典
positive_words = ['good', 'excellent']
negative_words = ['bad', 'terrible']

def calculate_emotion(text):
    words = nltk.word_tokenize(text)
    vectorizer = TfidfVectorizer(vocabulary=positive_words + negative_words)
    tfidf = vectorizer.fit_transform([' '.join(words)])
    return 'positive' if sum(tfidf.toarray()[0][:2]) > sum(tfidf.toarray()[0][2:]) else 'negative'
```
