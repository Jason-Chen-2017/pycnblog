### 第1章: 格雷厄姆价值投资理论基础

#### 1.1 格雷厄姆投资理论的起源与发展

格雷厄姆的价值投资理论起源于20世纪30年代，由本杰明·格雷厄姆和他的学生戴维·多德共同提出。格雷厄姆强调以低于内在价值的价格购买股票，通过安全边际来降低投资风险。他的理论在《证券分析》一书中得到了详细阐述，成为价值投资的奠基之作。

#### 1.2 格雷厄姆特价股票策略的核心概念

格雷厄姆策略的核心在于“安全边际”和“内在价值”两个概念：

1. **内在价值**：企业未来现金流的现值，反映了企业的实际价值。
2. **安全边际**：购买价格低于内在价值的部分，用于降低投资风险。

#### 7.2 核心实现代码

```python
import numpy as np
import pandas as pd

def calculate_intrinsic_value(cash_flows, discount_rate, terminal_value):
    # 计算未来现金流的现值
    present_value = sum(cash_flows[i] / (1 + discount_rate) ** i for i in range(len(cash_flows)))
    # 计算终值的现值
    terminal_value_present = terminal_value / (1 + discount_rate) ** len(cash_flows)
    return present_value + terminal_value_present

# 示例数据
cash_flows = [100, 150, 200]
discount_rate = 0.1
terminal_value = 500

intrinsic_value = calculate_intrinsic_value(cash_flows, discount_rate, terminal_value)
print(f"内在价值: {intrinsic_value}")
```
