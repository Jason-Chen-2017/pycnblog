## 5.2 核心代码实现

### 5.2.1 文本预处理代码
```python
import transformers

def preprocess(text):
    tokenizer = transformers.BertTokenizer.from_pretrained('bert-base-uncased')
    inputs = tokenizer.encode_plus(text, add_special_tokens=True, return_token_ids=True)
    return inputs['input_ids'], inputs['attention_mask']
```

### 5.2.2 模型训练代码
```python
from transformers import BertForQuestionAnswering

model = BertForQuestionAnswering.from_pretrained('bert-base-uncased')
model.train()
```

### 5.2.3 模型推理代码
```python
def predict(text, question):
    inputs = tokenizer.encode_plus(text, question, add_special_tokens=True, return_token_ids=True)
    outputs = model(**inputs)
    start_index = outputs.start_logits.argmax()
    end_index = outputs.end_logits.argmax()
    return text[start_index:end_index+1]
```
