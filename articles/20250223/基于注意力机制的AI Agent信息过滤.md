# 第三章：注意力机制算法实现

## 3.1 注意力机制的数学模型

### 3.1.1 查询、键、值的定义
向量表示，维度相同。

### 3.1.2 注意力权重的计算公式
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

### 3.1.3 注意力机制的实现步骤
计算相似度、归一化、加权求和。

## 3.2 基于注意力机制的信息过滤算法

### 3.2.1 算法流程图
```mermaid
graph TD
A[输入数据] --> B[特征提取]
B --> C[计算注意力权重]
C --> D[加权求和]
D --> E[输出结果]
```

### 3.2.2 Python实现代码
```python
def attention(Q, K, V, d_k):
    # 计算注意力权重
    scores = (Q @ K.T) / (d_k ** 0.5)
    attention_weights = softmax(scores)
    # 加权求和
    output = attention_weights @ V
    return output
```

def attention(Q, K, V, d_k):
