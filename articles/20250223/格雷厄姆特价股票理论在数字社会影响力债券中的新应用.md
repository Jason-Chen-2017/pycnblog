## 第1章: 格雷厄姆投资理论的核心概念

### 1.1 格雷厄姆投资理论的核心概念

#### 1.1.1 价值投资的定义与原则
价值投资是一种以低于其内在价值的价格购买优质资产的投资策略，其核心原则包括：
- **长期思维**：关注企业的长期价值，而非短期市场波动。
- **安全边际**：购买价格应显著低于内在价值，以降低投资风险。
- **逆向投资**：在市场恐慌时寻找被低估的机会。

#### 1.1.2 格雷厄姆的安全边际理论
安全边际是格雷厄姆理论中的核心概念，它通过比较资产的市场价格与内在价值，为投资者提供一个风险可控的投资空间：
$$ \text{安全边际} = \frac{\text{内在价值} - \text{市场价格}}{\text{内在价值}} \times 100\% $$

#### 1.1.3 股票投资的内在价值计算方法
内在价值是基于企业未来现金流的现值计算得出的，公式如下：
$$ V = \frac{E}{k} $$
其中，\( E \) 表示企业的盈利，\( k \) 表示折现率。

```python
class Bond:
    def __init__(self, id, name, cash_flow, discount_rate, social_impact_score):
        self.id = id
        self.name = name
        self.cash_flow = cash_flow
        self.discount_rate = discount_rate
        self.social_impact_score = social_impact_score

    def calculate_intrinsic_value(self):
        return self.cash_flow / self.discount_rate * self.social_impact_score

class Investor:
    def __init__(self, id, name):
        self.id = id
        self.name = name
        self.portfolio = []

    def add_bond(self, bond):
        self.portfolio.append(bond)

# 示例
bond = Bond("1", "环保债券", 1000000, 0.05, 0.8)
print(f"{bond.name}的内在价值为：{bond.calculate_intrinsic_value()}")
```
