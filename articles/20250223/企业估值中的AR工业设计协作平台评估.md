## 第一部分：背景介绍

### 1.1 AR技术的基本概念与发展历程

#### 1.1.1 增强现实（AR）的定义与技术原理
- AR（Augmented Reality）通过将数字信息叠加在物理世界中，提供沉浸式的交互体验。
- 技术原理包括计算机视觉、三维建模、实时渲染和传感器融合。

#### 1.1.2 AR技术在工业设计中的应用场景
- 实时协作设计：设计师可以通过AR技术进行实时三维模型查看和编辑。
- 沉浸式体验：提供更直观的设计和模拟环境，提升设计效率。

#### 1.1.3 AR技术对企业估值的影响
- 提高设计效率和准确性，降低协作成本。
- 通过实时协作和沉浸式体验，提升企业竞争力和市场价值。

### 1.2 工业设计协作平台的现状与挑战

#### 1.2.1 工业设计协作的传统模式与痛点
- 传统协作模式依赖于二维图纸和面对面沟通，效率低且容易出错。
- 需要频繁的沟通和多次修改，导致时间和资源浪费。

#### 1.2.2 AR技术如何解决协作中的问题
- 提供实时三维可视化，减少沟通误差。
- 支持多人异地协作，降低时间和空间成本。

#### 1.2.3 AR工业设计协作平台的市场前景
- 随着AR技术的成熟，市场对高效协作工具的需求增加。
- 平台可以应用于汽车、建筑、电子等领域，市场潜力巨大。

### 1.3 AR工业设计协作平台的核心价值

#### 1.3.1 提高设计效率与准确性
- 通过实时渲染和三维模型，设计师可以快速验证和修改设计。
- 减少设计错误，提高产品质量。

#### 1.3.2 降低沟通成本与协作障碍
- 支持多人异地协作，减少面对面会议的需求。
- 提供统一的协作平台，避免信息不对称。

#### 1.3.3 增强设计的可视化与沉浸式体验
- AR技术提供更直观的设计和模拟环境，帮助设计师更好地理解设计。
- 提供沉浸式体验，提升设计灵感和创意。

def calculate_weights(criteria_matrix):
    eig, vec = np.linalg.eig(criteria_matrix)
    weights = eig / np.sum(eig)
    return weights

criteria_matrix = np.array([
    [1, 0.5, 0.8],
    [0.5, 1, 0.6],
    [0.8, 0.6, 1]
])

weights = calculate_weights(criteria_matrix)
print(weights)
