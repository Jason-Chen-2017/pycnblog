## 第三章：推荐算法的数学模型与实现

### 3.1 协同过滤算法

#### 3.1.1 协同过滤的定义
协同过滤基于用户相似性或物品相似性进行推荐。

#### 3.1.2 协同过滤的数学模型
用户-用户协同过滤公式：
$$similarity(u, v) = \frac{\sum_{i}(r_{u,i} - \bar{r}_u)(r_{v,i} - \bar{r}_v)}{\sqrt{\sum_{i}(r_{u,i} - \bar{r}_u)^2} \sqrt{\sum_{i}(r_{v,i} - \bar{r}_v)^2}}$$

#### 3.1.3 协同过滤的实现步骤
1. 数据预处理：处理缺失值、归一化数据。
2. 相似度计算：计算用户或物品的相似度。
3. 预测评分：基于相似度计算目标用户的预测评分。
4. 推荐生成：筛选高评分的物品作为推荐。

#### 3.1.4 协同过滤的优缺点
优点：考虑了用户偏好，实时性较强。缺点：计算复杂度高，稀疏性问题。

```python
from sklearn.metrics.pairwise import cosine_similarity

# 用户-用户协同过滤
def user_based_recommender(train, test):
    user_item_matrix = train.pivot('user', 'item', 'rating')
    user_item_matrix = user_item_matrix.fillna(0)
    similarity = cosine_similarity(user_item_matrix.T)
    # 预测评分
    predictions = {}
    for user in test['user'].unique():
        for item in test['item'].unique():
            similar_users = train[(train['user'] != user) & (train['item'] == item)]
            if len(similar_users) == 0:
                predictions[(user, item)] = 3.0
            else:
                weighted_sum = similar_users['rating'].mean()
                predictions[(user, item)] = weighted_sum
    return predictions
```
