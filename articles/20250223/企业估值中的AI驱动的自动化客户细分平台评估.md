## 第2章: 核心概念与联系

### 2.1 数据特征与客户细分
- **数据特征的分类与选择**
  - 客户的基本信息：年龄、性别、地理位置
  - 行为特征：购买频率、浏览时长
  - 产品偏好：购买的产品类型、价格敏感度

- **数据预处理的关键步骤**
  - 数据清洗：处理缺失值、异常值
  - 特征提取：从原始数据中提取有用特征
  - 数据标准化：统一特征的尺度

### 2.2 模型选择与评估指标
- **常见客户细分模型的对比**
  - K-means：适用于无监督学习，简单高效
  - DBSCAN：基于密度的聚类，适合处理噪声数据
  - 层次聚类：适合处理数据层次结构明确的情况

- **模型评估的常用指标**
  - 凝聚度（Clustering Quality）：衡量聚类的紧密程度
  - 分散度（Dispersion）：衡量聚类的多样性
  - 调整兰德指数（Adjusted Rand Index）：衡量聚类结果与真实标签的相似性

## 第3章: 算法原理讲解

### 3.1 数据预处理与特征工程
- **数据清洗的常见方法**
  - 删除缺失值
  - 处理异常值
  - 去重

- **特征提取的关键步骤**
  - 选择相关特征
  - 处理高维数据

- **数据标准化与归一化的处理**
  - 标准化：(x - μ)/σ
  - 归一化：(x - min)/(max - min)

### 3.2 聚类算法与客户细分
- **K-means算法的数学模型**
  - 目标函数：最小化簇内平方误差和
  - 优化方法：k-means++

  $$ J = \sum_{i=1}^{k} \sum_{j=1}^{n_i} (x_j - c_i)^2 $$
  其中，k为簇数，n_i为第i簇的样本数，c_i为第i簇的中心点。

- **K-means算法的流程图**

```mermaid
    B --> C[计算新的簇中心]
    C --> D[判断收敛，否则返回B]
    D --> E[输出结果]
```

### 5.1 环境安装与配置

### 5.2 核心代码实现
- **数据处理代码**
  ```python
  import pandas as pd
  from sklearn.preprocessing import StandardScaler

  # 数据加载
  data = pd.read_csv('customer_data.csv')
  
  # 数据清洗
  data.dropna(inplace=True)
  
  # 数据标准化
  scaler = StandardScaler()
  data_scaled = scaler.fit_transform(data)
  ```

- **模型训练代码**
  ```python
  from sklearn.cluster import KMeans

  # 模型训练
  kmeans = KMeans(n_clusters=3, random_state=42)
  kmeans.fit(data_scaled)
  
  # 获取聚类结果
  labels = kmeans.labels_
  ```
