# 第3章: 语义理解的算法原理

## 3.1 预训练语言模型的原理

### 3.1.1 预训练语言模型的结构
- Transformer架构：编码器和解码器
- BERT模型：双向Transformer
- GPT模型：单向Transformer

### 3.1.2 预训练任务的设计
1. 掩码语言模型：随机遮蔽部分词，预测被遮蔽词
2. 一致性训练：文本与摘要的一致性
3. 其他任务：情感分析、问答系统

### 3.1.3 预训练模型的训练过程
1. 输入文本：分割为token
2. 遮蔽部分token：随机遮蔽15%的token
3. 预测被遮蔽token：通过模型预测
4. 损失函数：交叉熵损失

### 3.1.4 模型训练的数学公式
- 损失函数：$$ L = -\sum_{i=1}^{n} y_i \log p(y_i) $$
- 优化方法：Adam优化器
- 学习率：$$ \eta = \eta_0 \cdot \frac{1}{1 + \frac{t}{\beta_1}} $$

#### 5.2.2.1 实体识别代码
```python
import spacy

nlp = spacy.load("en_core_web_sm")

def extract_entities(text):
    doc = nlp(text)
    entities = []
    for ent in doc.ents:
        entities.append((ent.text, ent.label_))
    return entities
```

#### 5.2.2.2 关系抽取代码
```python
from transformers import BertForTokenClassification, BertTokenizer

model = BertForTokenClassification.from_pretrained("bert-base")
tokenizer = BertTokenizer.from_pretrained("bert-base")

def extract_relations(text):
    inputs = tokenizer(text, return_tensors="np")
    outputs = model(inputs.input_ids, inputs.attention_mask)
    predictions = outputs.logits.argmax(-1).numpy()
    relations = []
    for i in range(len(predictions)):
        if predictions[i] == 1:  # 假设关系标签为1
            relations.append(text.split()[i])
    return relations
```

#### 5.2.2.3 知识图谱构建代码
```python
from neo4j import GraphDatabase

driver = GraphDatabase.driver("bolt://localhost:7687", auth=("neo4j", "password"))

def create_graph(entities, relations):
    with driver.session() as session:
        for entity in entities:
            session.run("CREATE (:Entity {name: $name})", name=entity)
        for relation in relations:
            session.run("MATCH (a), (b) WHERE a.name = $a AND b.name = $b CREATE (a)-[r:Related]->(b)", a=relation[0], b=relation[1])
```
