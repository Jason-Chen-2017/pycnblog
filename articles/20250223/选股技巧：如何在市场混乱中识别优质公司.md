## 第一部分: 股票市场与优质公司识别基础

### 第1章: 股票市场概述

#### 1.1 什么是股票市场
股票市场是投资者进行股票买卖的场所，分为一级市场和二级市场。一级市场是新公司首次公开发行（IPO）股票的市场，二级市场是已上市公司股票交易的市场。

#### 1.2 优质公司的定义与特征
优质公司通常具有稳定的盈利能力、健康的财务状况、强大的行业地位和良好的管理团队。它们能够在市场波动中保持稳健增长，为投资者带来长期收益。

#### 1.3 识别优质公司的必要性
在市场混乱时，优质公司更能抵御风险，实现长期增长。识别优质公司有助于投资者在市场低迷时找到价值投资的机会，避免短期亏损。

### 第2章: 公司基本面分析

#### 2.1 财务报表分析
- 利润表：显示公司在一定时期内的收入和利润。
- 资产负债表：显示公司在某一特定时点的资产、负债和所有者权益。
- 现金流量表：显示公司在一定时期内的现金流入和流出情况。

#### 2.2 财务指标分析
- 净利润率（ROE）：衡量公司盈利能力的重要指标。
- 净利润：衡量公司利润水平的关键指标。
- 负债率：衡量公司财务风险的重要指标。

#### 2.3 行业分析
- 行业生命周期：分析行业所处的阶段，判断行业增长潜力。
- 行业竞争结构：分析行业内的竞争情况，判断公司的竞争优势。
- 行业政策影响：分析政策对行业的影响，判断行业风险。

### 第3章: 技术分析与市场趋势

#### 3.1 技术分析基础
- 技术分析是通过分析股票价格和成交量的历史数据，预测未来的价格走势。
- 技术分析与基本面分析的区别：技术分析侧重于价格走势，基本面分析侧重于公司财务状况。

#### 3.2 常见技术指标
- 移动平均线（MA）：用于判断价格趋势的指标。
- 相对强弱指数（RSI）：用于判断超买超卖状态的指标。
- MACD：用于判断价格趋势和动能的指标。

#### 3.3 图表形态分析
- 头肩顶：看跌信号，预示价格将下跌。
- 头肩底：看涨信号，预示价格将上涨。
- 三角形：整理形态，预示价格将突破或延续趋势。

def calculate_financial_indices(data):
    # 示例：计算ROE和净利润率
    data['ROE'] = data['净利润'] / data['所有者权益']
    data['净利润率'] = data['净利润'] / data['营业收入']
    return data
