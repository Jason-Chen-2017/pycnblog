# 第2章: 股市估值的核心概念与技术

## 2.1 股市估值的定义与方法

### 2.1.1 市盈率法
市盈率法通过比较股票的市盈率与行业平均值，评估股票的估值是否合理。

$$市盈率 = \frac{股价}{每股收益}$$

### 2.1.2 市净率法
市净率法通过比较股票的市净率与行业平均值，评估股票的估值是否合理。

$$市净率 = \frac{股价}{每股净资产}$$

### 2.1.3 股息率法
股息率法通过比较股票的股息率与行业平均值，评估股票的估值是否合理。

$$股息率 = \frac{每股股息}{股价}$$

## 2.2 股市估值的关键技术

### 2.2.1 数据分析技术

机器学习模型通过历史数据训练，预测股票的价格走势，帮助投资者做出决策。

### 2.2.3 时间序列分析
时间序列分析通过分析历史数据，识别趋势和周期性，预测未来走势。
