## 第1章: 全球化人才策略的背景介绍

### 1.1 全球化人才策略的核心概念

#### 1.1.1 全球化人才策略的定义
全球化人才策略是指企业在跨国经营中，根据不同国家和地区的经济、文化、法律环境，优化人才配置和管理的策略。它不仅涉及人才的招聘、培养和保留，还包括如何在全球范围内高效利用人才资源。

#### 1.1.2 全球化人才策略的重要性
在全球化竞争日益激烈的今天，企业需要在全球范围内吸引、培养和留住顶尖人才，才能在市场中保持竞争优势。彼得林奇在其投资理念中强调，人才是企业最重要的资产，因此，科学的全球化人才策略是企业成功的关键。

#### 1.1.3 全球化人才策略的边界与外延
全球化人才策略的边界在于企业的组织架构和业务范围，而外延则涉及跨文化管理、法律合规、本地化运营等多个方面。

### 3.1 全球化人才策略的评估模型

#### 3.1.1 评估模型的数学模型

$$
\text{综合评分} = \sum (\text{维度权重} \times \text{维度评分})
$$

#### 3.1.2 评估模型的实现步骤
1. 确定评估维度和权重。
2. 收集各维度评分数据。
3. 计算综合评分。

#### 3.1.3 评估模型的代码实现

```python
def calculate_global_score(dimensions, weights):
    total_score = 0
    for dim, weight in zip(dimensions, weights):
        total_score += dim * weight
    return total_score

dimensions = [4, 3, 5]  # 技能、经验、适应能力
weights = [0.4, 0.3, 0.3]
print(calculate_global_score(dimensions, weights))
```

### 5.2 项目实战：代码实现与解读

#### 5.2.1 代码实现

```python
import pandas as pd
import numpy as np

def calculate_global_score(dimensions, weights):
    return sum(d * w for d, w in zip(dimensions, weights))

data = pd.DataFrame({
    '技能': [4, 3, 5],
    '经验': [3, 4, 2],
    '适应能力': [5, 2, 4]
})

weights = [0.4, 0.3, 0.3]
scores = []
for index, row in data.iterrows():
    scores.append(calculate_global_score([row['技能'], row['经验'], row['适应能力']], weights))

data['综合评分'] = scores
print(data)
```
