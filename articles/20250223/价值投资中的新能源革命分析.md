# 第1章: 价值投资与新能源革命概述

## 1.1 价值投资的核心理念

### 1.1.1 价值投资的定义与起源  
价值投资是一种以基本面分析为核心的长期投资策略，起源于20世纪初，由本杰明·格雷厄姆和戴维·多德提出。其核心理念是寻找市场价格低于其内在价值的股票，通过长期持有实现收益。

### 1.1.2 价值投资的基本原则  
- **安全边际**：买入价格低于内在价值，确保投资的安全性。  
- **长期视角**：关注企业的长期盈利能力，而非短期市场波动。  
- **竞争优势**：选择具有持续竞争优势的企业。  

### 1.1.3 价值投资在现代投资中的地位  
尽管现代投资理论强调多样化和分散化，价值投资仍是一种有效的策略，尤其在新能源等领域表现突出。

## 1.2 新能源革命的背景与现状

### 1.2.1 新能源革命的定义与内涵  
新能源革命是指通过技术创新和政策推动，实现从传统能源向可再生能源的转型，减少碳排放，应对气候变化。

### 1.2.2 全球能源结构转型的趋势  
- **化石能源占比下降**：全球能源结构逐步向可再生能源过渡。  
- **政策支持**：各国政府纷纷出台政策支持新能源发展。  
- **技术进步**：太阳能、风能等技术成本持续下降。  

### 1.2.3 新能源技术的发展与应用  
- **太阳能**：光伏发电效率不断提升，成本大幅下降。  
- **风能**：海上风电成为重要发展方向。  
- **储能技术**：电池技术进步推动可再生能源的广泛应用。

## 1.3 价值投资与新能源革命的结合

### 1.3.1 新能源革命对投资理念的影响  
- **技术驱动**：新能源技术的创新为投资提供了新机会。  
- **政策支持**：政府政策为新能源行业提供了稳定的增长环境。
