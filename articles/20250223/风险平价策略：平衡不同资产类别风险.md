# 第一部分：风险平价策略概述

## 第1章：风险平价的定义与背景

### 1.1 风险平价的基本概念
- 风险平价的定义
  - 风险平价是一种资产配置方法，旨在将投资组合中每种资产的风险贡献相等化。
  - 通过调整权重，使得每种资产对组合总风险的贡献相同。
- 风险平价的核心目标
  - 平衡不同资产类别之间的风险。
  - 降低投资组合的尾部风险。
  - 提高资产配置的稳健性。

### 1.2 风险平价在资产配置中的作用
- 资产配置的核心问题
  - 传统资产配置方法（如均值-方差优化）过于依赖对收益的预测，存在较大的不确定性。
  - 风险平价策略通过平衡风险贡献，降低了对收益预测的依赖。
- 风险平价的优势
  - 适用于不同市场环境下的资产配置。
  - 能够分散风险，避免单一资产类别过度暴露的风险。
  - 更加稳健，减少投资组合的波动性。

### 1.3 风险平价与其他资产配置策略的对比
- 均值-方差优化
  - 优点：能够找到最优风险-收益组合。
  - 缺点：对收益预测的依赖性强，且在极端市场条件下可能失效。
- 风险平价与等权重配置
  - 等权重配置：简单易行，但忽视了不同资产的风险差异。
  - 风险平价：考虑了资产的风险特征，更具灵活性。
- 风险平价与因子投资
  - 风险平价可以与因子投资结合，优化多因子投资组合的风险分配。

### 1.4 风险平价的理论基础
- 马科维茨的有效投资组合理论
  - 介绍：马科维茨提出的投资组合理论是现代资产配置的基础。
  - 风险平价与马科维茨理论的联系：风险平价是对马科维茨理论的补充，特别是在风险分配上的优化。
