## 第3章：股市估值的算法原理讲解

### 3.1 股市估值算法概述

股市估值的核心在于预测股票的内在价值，常用的方法包括市盈率（PE）、市净率（PB）和现金流折现法（DCF）。

#### 3.1.1 PE（市盈率）估值法

市盈率（Price-to-Earnings Ratio，PE）是股票价格与每股收益的比率，反映市场对公司盈利能力的评价。

- **公式**：$$PE = \frac{\text{股价}}{\text{每股收益}}$$

- **步骤**：
  1. 收集公司过去几年的净利润和股价数据。
  2. 计算每股收益（EPS）。
  3. 计算PE比率。
  4. 比较PE比率与行业平均水平，判断估值高低。

#### 3.1.2 PB（市净率）估值法

市净率（Price-to-Book Ratio，PB）是股票价格与每股净资产的比率，适用于资产密集型行业。

- **公式**：$$PB = \frac{\text{股价}}{\text{每股净资产}}$$

- **步骤**：
  1. 收集公司资产数据。
  2. 计算每股净资产。
  3. 计算PB比率。
  4. 比较PB比率与行业平均水平，判断估值高低。

#### 3.1.3 DCF（现金流折现法）估值法

DCF通过将未来现金流折现，计算股票的内在价值，适用于成长型企业。

- **步骤**：
  1. 估计未来自由现金流。
  2. 确定折现率（WACC）。
  3. 计算未来现金流的现值。
  4. 加上终值，得出企业整体价值。
  5. 计算每股价值。

### 3.2 用Python实现PE估值法

以下代码示例计算某公司的PE比率：

```python
import pandas as pd

# 示例数据
data = {'日期': ['2020-12-31', '2021-12-31', '2022-12-31'],
         '净利润': [100, 120, 150],
         '股价': [50, 55, 60]}
df = pd.DataFrame(data)

# 计算每股收益（EPS）
df['EPS'] = df['净利润'] / df['股价'].astype(float)

# 计算PE比率
df['PE'] = df['股价'] / df['EPS']

print(df)
```

## 第4章：数学模型与公式

### 4.1 市盈率模型

市盈率公式：$$PE = \frac{\text{股价}}{\text{EPS}}$$

### 4.2 市净率模型

市净率公式：$$PB = \frac{\text{股价}}{\text{BPS}}$$

### 4.3 现金流折现模型

DCF公式：$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$

其中，\( CF_t \) 是第t年的现金流，\( r \) 是折现率，\( TV \) 是终值。
