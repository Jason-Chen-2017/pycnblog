#### 5.2 系统核心实现

以下是动态规划算法的Python代码示例：

```python
def dynamic_programming(weights, capacities):
    n = len(weights)
    dp = [[0]*(capacities+1) for _ in range(n)]
    for i in range(n):
        for c in range(capacities+1):
            if i == 0:
                dp[i][c] = weights[i] if c >= weights[i] else 0
            else:
                dp[i][c] = max(dp[i-1][c], dp[i-1][c-weights[i]] + weights[i] if c >= weights[i] else 0)
    return dp[n-1][capacities]

# 示例使用
weights = [2, 3, 4]
capacities = 10
print(dynamic_programming(weights, capacities))
```
