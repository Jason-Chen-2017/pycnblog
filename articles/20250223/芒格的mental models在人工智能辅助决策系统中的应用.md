### 3.1.2 决策树算法的实现

```python
import numpy as np

X = np.array([[2, 3], [5, 7], [2, 8], [10, 6]])
y = np.array([0, 1, 0, 1])

```

### 3.1.3 概率模型的数学公式

$$ P(A|B) = \frac{P(B|A)P(A)}{P(B)} $$

其中，$P(A|B)$ 表示在 $B$ 发生的情况下，$A$ 发生的概率。
