$$
\text{特征权重} = \sum_{i=1}^{n} (w_i \times f_i)
$$

其中，$w_i$ 是特征的重要性权重，$f_i$ 是特征的值。

### 3.3.2 分类模型的训练过程

$$
y = f(x) + \epsilon
$$

其中，$y$ 是目标变量，$x$ 是输入特征，$f(x)$ 是模型函数，$\epsilon$ 是误差项。

## 3.4 代码实现

### 3.4.1 传感器数据读取

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 传感器数据读取
data = pd.read_csv('食材数据.csv')
X = data.drop('新鲜度', axis=1)
y = data['新鲜度']
```

### 3.4.2 模型训练与预测

```python
# 模型训练
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X, y)

# 模型预测
y_pred = model.predict(X)
print('准确率:', accuracy_score(y, y_pred))
```
