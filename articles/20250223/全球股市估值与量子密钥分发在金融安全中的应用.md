# 第1章 全球股市估值的基本概念

## 1.1 全球股市估值的定义与重要性

### 1.1.1 全球股市估值的定义
全球股市估值是指对全球范围内股票市场的整体价值进行评估的过程。它通过分析宏观经济、行业和公司基本面等因素，确定市场的整体价值。

### 1.1.2 全球股市估值的重要性
股市估值是投资者、机构和政策制定者的重要决策依据，能够反映经济状况、市场情绪和投资机会。

### 1.1.3 全球股市估值的核心要素
- **宏观经济因素**：GDP、利率、通货膨胀等。
- **行业因素**：行业周期、竞争格局等。
- **公司基本面**：盈利能力、财务状况等。

## 1.2 全球股市估值的影响因素

### 1.2.1 宏观经济因素
宏观经济指标如GDP增长率、利率水平和通货膨胀率直接影响股市估值。

### 1.2.2 行业因素
行业周期和竞争格局影响企业的盈利能力和股票价值。

### 1.2.3 公司基本面因素
公司财务状况、盈利能力和管理团队是股市估值的重要依据。

## 1.3 全球股市估值的传统方法

### 1.3.1 市盈率法
市盈率（P/E）= 股价 / 每股净利润。通过比较市盈率，评估股票的相对价值。

### 1.3.2 市净率法
市净率（P/B）= 股价 / 每股净资产。用于评估股票相对于其账面价值的高低。

### 1.3.3 股息率法
股息率 = 每股股息 / 股价。用于评估股票的分红能力。

## 1.4 传统估值方法的局限性

### 1.4.1 数据局限性
传统方法依赖历史数据，无法完全反映未来市场的变化。

### 1.4.2 市场波动性影响
市场波动可能导致估值结果出现偏差。

### 1.4.3 跨市比较的复杂性
不同市场的差异性增加了跨市场估值的难度。

## 1.5 本章小结
本章介绍了全球股市估值的基本概念、重要性及影响因素，并分析了传统估值方法的局限性。
