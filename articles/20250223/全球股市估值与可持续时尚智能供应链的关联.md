### 3.3.2 可持续时尚智能供应链模型的Python代码示例
```python
import numpy as np

# 模拟供应链优化问题
def supply_chain_optimization(costs, demands):
    n = len(costs)
    # 使用贪心算法优化供应链
    total_cost = 0
    for i in range(n):
        total_cost += min(costs[i], demands[i])
    return total_cost

# 示例数据
costs = [10, 15, 20]
demands = [5, 7, 3]

result = supply_chain_optimization(costs, demands)
print("优化后的总成本为：", result)
```
