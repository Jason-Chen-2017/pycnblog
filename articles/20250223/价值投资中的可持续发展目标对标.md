## 第1章: 价值投资与可持续发展目标的背景

### 1.1 价值投资的基本概念

- **核心理念**：寻找市场低估的公司，长期持有，等待价值回归。  
- **地位**：在现代投资中，价值投资强调基本面分析和长期视角。

- **特点**：长期性、系统性、多方利益相关。  

### 1.3 价值投资与可持续发展目标的关联

## 第3章: 价值投资中的数学模型与算法原理

### 3.1 贴现现金流模型（DCF）  
- **基本原理**：预测未来现金流，折现计算现值。  
- **公式推导**：  
  $$DCF = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n}$$  
- **步骤与应用**：数据收集、假设参数、计算现金流、折现率确定。  

### 3.2 可持续发展评分模型  
- **ESG评分体系**：根据环境、社会、治理因素评分。  
- **计算公式**：  
  $$ESG\_Score = \alpha \cdot E + \beta \cdot S + \gamma \cdot G$$

### 5.2 核心代码实现  
```python
import pandas as pd
import numpy as np

def calculate_dcf(cash_flows, discount_rate, terminal_value):
    return sum(cash_flows / (1 + discount_rate) ** t for t in range(len(cash_flows))) + terminal_value / (1 + discount_rate) ** len(cash_flows)

# 示例数据
cash_flows = [100, 150, 200]
discount_rate = 0.1
terminal_value = 500

dcf_value = calculate_dcf(cash_flows, discount_rate, terminal_value)
print(f"DCF Value: {dcf_value}")
```
