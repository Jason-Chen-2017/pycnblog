## 第3章：算法原理

### 3.1 数学模型

$$ \text{TalentFlow} = \beta_0 + \beta_1 \times ValuationDifferences + \epsilon $$

### 3.3 代码实现
```python
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据预处理
data = pd.read_csv('valuation_talent.csv')
X = data[['ValuationDifferences']]
y = data['TalentFlow']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 结果分析
r2 = r2_score(y, model.predict(X))
print(f'R² = {r2}')
```
