## 第1章: 企业估值的基本概念

### 1.1 企业估值的定义与意义

企业估值是确定企业在市场上的价值的过程，是投资决策中的关键步骤。企业估值的意义在于帮助投资者和管理层评估企业的内在价值，从而做出合理的收购、融资或投资决策。

### 1.2 企业估值的核心要素

企业估值的核心要素包括企业的资产、负债、收入、利润、市场地位等。这些要素共同决定了企业的整体价值。

### 1.3 企业估值与企业价值的关系

企业估值是确定企业价值的过程，企业价值是企业的整体价值，包括资产、负债、未来现金流等因素。

## 第2章: 企业估值的主要方法

### 2.1 资产基础法

资产基础法是通过对企业资产和负债的评估，计算企业价值的方法。其步骤包括：识别资产和负债、评估资产价值、计算净额。

### 2.2 收益法

收益法基于企业的未来现金流，使用折现率计算企业价值。其公式为：企业价值 = Σ(FCF / (1 + r)^t)，其中FCF是自由现金流，r是折现率。

### 2.3 市场法

市场法通过比较类似企业的交易价格，确定企业价值。其公式为：企业价值 = 市盈率 × 净利润，或市净率 × 净资产。

### 2.4 其他估值方法

包括股权自由现金流法、重置成本法等。

### 2.5 各种方法的对比与选择

不同方法适用于不同的场景，收益法适用于成长型企业，市场法适用于可比企业较多的情况。

## 第3章: 企业估值的数学模型与公式

### 3.1 DCF模型

DCF模型是基于未来现金流的折现，计算企业价值的模型。公式为：企业价值 = Σ(FCF / (1 + r)^t)。

### 3.2 市盈率与市净率

市盈率 = 价格 / 盈利，市净率 = 价格 / 净资产。

### 3.3 WACC模型

WACC模型是计算折现率的常用方法，公式为：WACC = (E/V × Re) + (D/V × Rd × (1 - Tc))。
