### 1.3 模型准确性的重要性

## 第6章：项目实战分析

### 6.1 环境安装

### 6.2 核心代码实现

#### 数据处理代码：

```python
import pandas as pd
import numpy as np

# 加载数据
data = pd.read_csv('customer_data.csv')

# 数据清洗
data.dropna(inplace=True)
data = data[~data.duplicated()]

# 特征工程
data['total_purchase'] = data['order_amount'].cumsum()
data['recency'] = (data['last_purchase_date'].max() - data['last_purchase_date']).dt.days
data['frequency'] = data['order_count'] / data['recency']
data['monetary'] = data['order_amount'].mean()

# 特征选择
features = ['order_amount', 'order_count', 'recency', 'frequency', 'monetary']
target = 'total_purchase'

X = data[features]
y = data[target]
```

#### 模型训练代码：

```python
from sklearn.model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

model = LinearRegression()
model.fit(X, y)

y_pred = model.predict(X)
mse = mean_squared_error(y, y_pred)
r2 = r2_score(y, y_pred)

print(f'MSE: {mse}, R²: {r2}')
```
