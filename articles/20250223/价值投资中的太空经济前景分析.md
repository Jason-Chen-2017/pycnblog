### 1.1 太空经济的定义与核心要素

#### 1.1.1 太空经济的定义

|----------|------|------|

| 空间探索 | 人类在外层空间的探索活动 | 登月任务、火星探测 |
| 太空资源 | 太空中的资源，如小行星、月球 | 矿产资源开发、太阳能利用 |

#### 1.1.2 太空经济的核心要素
- **技术驱动**：太空经济的核心是技术创新，尤其是卫星技术、发射技术和空间探索技术。
- **市场驱动**：需求来自通信、导航、遥感等领域，同时政府和企业的支持是关键。
- **政策驱动**：各国政府的政策和法规对太空经济的发展起着重要作用。

### 1.2 价值投资的基本概念

#### 1.2.1 价值投资的定义
价值投资是一种投资策略，强调以低于内在价值的价格购买优质资产，长期持有，等待市场对其价值的重新认识。

#### 1.2.2 价值投资的核心原则
- **安全边际**：买入价格低于内在价值。
- **长期持有**：关注企业的长期价值，而非短期波动。
- **基本面分析**：通过财务数据、行业地位等分析企业价值。

#### 1.2.3 价值投资与太空经济的结合
- **投资标的**：太空经济中的企业，如卫星通信公司、航天器制造商。
- **分析维度**：市场潜力、技术优势、财务状况。

# 示例代码：计算企业的内在价值
import pandas as pd
import numpy as np

def calculate_intrinsic_value(free_cash_flow, discount_rate, growth_rate):
    terminal_value = free_cash_flow * (1 + growth_rate) / (discount_rate - growth_rate)
    present_value = (free_cash_flow + terminal_value) / (1 + discount_rate)
    return present_value

# 数据获取与处理
data = pd.read_csv('space_economy_data.csv')
selected_company = data[data['Company'] == 'SpaceX']
free_cash_flow = selected_company['Free Cash Flow'].values[0]
discount_rate = 0.1
growth_rate = 0.05

intrinsic_value = calculate_intrinsic_value(free_cash_flow, discount_rate, growth_rate)
print(f"企业的内在价值为：{intrinsic_value}")
