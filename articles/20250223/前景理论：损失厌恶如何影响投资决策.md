## 第一部分: 前景理论基础

### 第1章: 前景理论的背景与核心概念

#### 1.1 前景理论的起源与发展
- **1.1.1 传统期望效用理论的局限性**  
  传统期望效用理论（Expected Utility Theory, EUT）假设投资者在决策时会理性地追求期望效用最大化。然而，实证研究表明，投资者在面对收益和损失时的反应并不对称。例如，面对相同金额的收益和损失，投资者对损失的厌恶程度远高于对收益的追求，这种现象无法用EUT解释。

- **1.1.2 前景理论的提出与核心思想**  
  前景理论（Prospect Theory）由心理学家Kahneman和Tversky在1979年提出，旨在解释投资者在决策过程中对收益和损失的非对称反应。前景理论的核心思想是：  
  - 投资者对收益和损失的感知是非线性的，且对损失的厌恶程度远高于对收益的追求。  
  - 投资者在决策时会基于一个参考点（通常是当前财富水平）进行判断，对参考点以上的收益和以下的损失分别赋予不同的权重。

- **1.1.3 前景理论在投资行为中的应用**  
  前景理论为理解投资者的实际行为提供了新的视角，尤其是在解释市场参与者的非理性行为（如过度交易、厌恶损失等）方面具有重要意义。

#### 1.2 损失厌恶的定义与特征
- **1.2.1 损失厌恶的定义**  
  损失厌恶是指投资者在面对损失时的负面情绪和规避行为。研究表明，投资者对损失的敏感度远高于对等金额收益的敏感度。

- **1.2.2 损失厌恶的特征**  
  - 损失厌恶具有非对称性：相同金额的损失比收益带来的心理影响更大。  
  - 损失厌恶具有局部性：投资者对损失的厌恶程度可能因参考点的变化而变化。  
  - 损失厌恶具有个体差异性：不同投资者的损失厌恶程度可能不同，取决于其风险偏好和投资经验。

- **1.2.3 损失厌恶与风险偏好的关系**  
  损失厌恶与风险偏好密切相关。通常情况下，损失厌恶程度较高的投资者更倾向于规避风险，而损失厌恶程度较低的投资者则可能更愿意承担风险以追求高收益。

#### 1.3 参考点与决策权重
- **1.3.1 参考点的定义**  
  参考点是指投资者在决策时用来比较收益和损失的基准点，通常是当前的财富水平或预期收益。

- **1.3.2 参考点的选择与影响**  
  参考点的选择对投资者的决策行为有重要影响。例如，当参考点为当前财富时，投资者更倾向于避免损失，而当参考点为预期收益时，投资者可能更愿意承担风险。

- **1.3.3 决策权重函数**  
  决策权重函数（Decision Weighting Function）描述了投资者在决策过程中对概率的感知和加权方式。Kahneman和Tversky提出的概率加权函数表明，投资者对高概率事件赋予的权重高于低概率事件。

#### 1.4 前景理论的核心公式
- **1.4.1 前景函数的数学表达**  
  前景函数描述了投资者在面对收益和损失时的效用变化：  
  $$ U(g) = \sum_{i=1}^n w(p_i) \cdot v(g_i) $$  
  其中，$w(p_i)$ 是概率加权函数，$v(g_i)$ 是收益或损失的效用函数。

- **1.4.2 损失函数的数学表达**  
  损失函数描述了投资者在面对损失时的效用变化：  
  $$ L(g) = -\sum_{i=1}^n w(p_i) \cdot v(g_i) $$  

- **1.4.3 决策权重函数的数学表达**  
  决策权重函数描述了投资者对概率的感知：  
  $$ w(p) = p^\alpha $$  
  其中，$\alpha$ 是一个指数参数，通常小于1，表示投资者对概率的递减加权。

#### 2.2 损失厌恶与风险态度
- **2.2.1 损失厌恶对风险态度的影响**  
  损失厌恶导致投资者在决策时更倾向于避免损失，这使得他们在面对风险时表现出保守的态度。

- **2.2.2 损失厌恶与投资组合优化**  
  在投资组合优化中，损失厌恶会影响投资者对风险资产的选择。通常，损失厌恶程度较高的投资者会倾向于选择风险较低的资产。

#### 3.1 投资者决策中的损失厌恶

- **3.1.2 损失厌恶与市场风险**  
  损失厌恶通过影响投资者的交易行为和资产选择，进而影响市场的系统性风险。

#### 3.2 投资组合优化中的前景理论
- **3.2.1 投资组合优化的定义**  
  投资组合优化是指通过选择最优的资产组合，使得投资者在风险和收益之间达到最佳平衡。

- **3.2.2 前景理论在投资组合优化中的应用**

### 第5章: 项目实战

#### 5.1 投资组合优化的实战
- **5.1.1 环境安装与配置**  
  - 安装Python和相关库（如NumPy、Pandas、Matplotlib）。
- **5.1.2 核心代码实现**  
  ```python
  import numpy as np
  import matplotlib.pyplot as plt

  def probability_weighting(p, alpha=0.88):
      return p**alpha

  def prospect_function(gains, losses, p):
      return np.sum(probability_weighting(p) * (gains - losses))

  # 示例数据
  p = 0.7
  gains = 100
  losses = 50

  # 计算前景效用
  utility = prospect_function(gains, losses, p)
  print("前景效用:", utility)

  # 可视化
  plt.plot(p, utility)
  plt.xlabel('概率')
  plt.ylabel('前景效用')
  plt.show()
  ```
