     $$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$

   - 加密过程通常涉及将数据与量子密钥进行异或操作。假设数据为$d = \{d_1, d_2, ..., d_n\}$，加密后的数据为$E(d)$，密钥为$K$，则加密过程可以表示为：
     $$E(d) = \{e_1, e_2, ..., e_n\}$$

#### 量子位的状态表示

量子位（qubit）的状态可以用复数线性组合来表示。假设我们有一个单量子位系统，其状态可以表示为：

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$

其中，$|0\rangle$ 和 $|1\rangle$ 分别表示量子位的基础状态，$\alpha$ 和 $\beta$ 是复数，满足归一化条件：

$$|\alpha|^2 + |\beta|^2 = 1$$

#### 量子密钥生成

量子密钥生成过程涉及对量子态进行测量。假设我们有一个$n$量子位的系统，通过一系列的量子门操作，将其初始化为叠加态：

$$|\psi\rangle = \frac{1}{\sqrt{2^n}}(|0\rangle^{\otimes n} + |1\rangle^{\otimes n})$$

然后，我们通过一系列的测量操作，获得量子密钥。假设测量结果为二进制序列 $K = (k_1, k_2, ..., k_n)$，则量子密钥可以表示为：

$$K = k_1|0\rangle + k_2|1\rangle + ... + k_n|1\rangle$$

其中，$k_i \in \{0, 1\}$。

#### 加密过程

量子加密过程通常涉及将数据与量子密钥进行异或操作。假设原始数据为 $D = (d_1, d_2, ..., d_n)$，量子密钥为 $K = (k_1, k_2, ..., k_n)$，则加密后的数据为：

$$E(D) = (e_1, e_2, ..., e_n)$$

其中，$e_i = d_i \oplus k_i$。异或操作满足以下性质：

1. 自反性：$x \oplus x = 0$
2. 交换性：$x \oplus y = y \oplus x$
3. 结合性：$(x \oplus y) \oplus z = x \oplus (y \oplus z)$

#### 解密过程

量子解密过程是将加密数据与量子密钥再次进行异或操作，恢复原始数据。假设加密数据为 $E(D) = (e_1, e_2, ..., e_n)$，量子密钥为 $K = (k_1, k_2, ..., k_n)$，则解密后的数据为：

$$D(E(D)) = D((e_1, e_2, ..., e_n)) = (d_1, d_2, ..., d_n)$$

其中，$d_i = e_i \oplus k_i$。

#### 测量与状态坍塌

在量子加密和解密过程中，测量操作起着关键作用。测量会导致量子态从叠加态坍塌到某个特定的基础态。例如，当我们对量子位进行测量时，它将从叠加态 $|\psi\rangle$ 坍塌到 $|0\rangle$ 或 $|1\rangle$ 状态。

$$|\psi'\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$$

其中，$\langle \psi'|\psi\rangle = \frac{1}{\sqrt{2}}$。
