```python
def send_data(data):
    url = 'http://edge_server_ip:port/data'
    headers = {'Content-Type': 'application/json'}
    response = requests.post(url, data=data, headers=headers)
    print(response.text)

# 循环读取传感器数据
while True:
    data = ser.readline()
    if data:
        # 数据解码和转换
        data = json.loads(data.decode('utf-8'))
        # 发送数据到边缘服务器
        send_data(data)
```

这段代码通过串口连接传感器，读取传感器数据，并将其转换为JSON格式，然后发送到边缘服务器。代码中的`send_data`函数负责将数据上传到服务器，确保数据的实时性。
