### Python代码

- **Python代码示例**：

```python
import numpy as np

# 定义一个简单的神经网络
class NeuralNetwork:
    def __init__(self):
        self.weights = np.random.rand(2, 1)
    
    def forward(self, x):
        return np.dot(x, self.weights)
    
    def train(self, x, y, epochs):
        for _ in range(epochs):
            output = self.forward(x)
            error = y - output
            delta = error * x
            self.weights += delta

# 创建一个神经网络实例
nn = NeuralNetwork()

# 训练神经网络
nn.train(np.array([[0, 1]]), np.array([[1]]), epochs=1000)

# 输出训练结果
print(nn.forward(np.array([[0, 1]])))
```
