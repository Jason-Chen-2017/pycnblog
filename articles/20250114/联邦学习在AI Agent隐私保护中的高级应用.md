#### 1.1 联邦学习的基本概念

联邦学习（Federated Learning）是一种分布式机器学习技术，其核心思想是让各个边缘设备在本地进行模型训练，然后将模型参数聚合起来，共同更新全局模型。这样，各个设备无需共享原始数据，只需交换模型参数，从而实现了数据隐私保护。

#### 1.1.1 联邦学习的定义

联邦学习是一种分布式机器学习框架，其中各个参与者（如智能手机、智能设备等）在本地进行模型训练，并通过加密的参数更新来协同优化全局模型。

#### 1.1.2 联邦学习的核心优势

1. **隐私保护**：联邦学习允许各个设备在本地训练模型，避免了数据集中的传输，从而降低了隐私泄露的风险。

2. **数据安全性**：联邦学习采用了加密技术，确保了模型参数在传输过程中的安全性。

3. **灵活性与可扩展性**：联邦学习可以支持大规模设备参与，适用于各种应用场景。

4. **减少通信成本**：联邦学习减少了数据传输的需求，降低了通信成本。

| ---- | ---- | ---- |
