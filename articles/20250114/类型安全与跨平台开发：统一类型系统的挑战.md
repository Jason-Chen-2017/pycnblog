首先，我们定义一组类型接口来描述应用中的基本数据结构，例如用户信息、动态信息和评论信息。

```typescript
interface User {
    id: string;
    name: string;
    email: string;
}

interface Post {
    id: string;
    userId: string;
    content: string;
    createdAt: Date;
}

interface Comment {
    id: string;
    postId: string;
    userId: string;
    content: string;
    createdAt: Date;
}
