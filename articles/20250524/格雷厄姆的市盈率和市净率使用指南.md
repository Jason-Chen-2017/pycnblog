## 第1章：市盈率与市净率概述

### 1.1 市盈率的概念与应用

#### 1.1.1 市盈率的定义与计算公式
市盈率（Price-to-Earnings Ratio，简称P/E）是衡量股票价值的重要指标，计算公式为：

$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$

#### 1.1.2 市盈率的用途与适用场景
市盈率常用于评估股票的相对价值，尤其适用于成长型企业。例如，可以通过比较同行业公司的市盈率，判断其股价是否合理。

#### 1.1.3 市盈率与股票价值的关系
市盈率反映了市场对每股收益的估值倍数，低市盈率可能意味着低估，而高市盈率可能表示高成长预期。

### 1.2 市净率的概念与应用

#### 1.2.1 市净率的定义与计算公式
市净率（Price-to-Book Ratio，简称P/B）计算公式为：

$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

#### 1.2.2 市净率的用途与适用场景
市净率适用于资产密集型企业，如银行和制造业，常用于判断企业资产的价值。

#### 1.2.3 市净率与股票价值的关系
低市净率可能意味着资产被低估，而高市净率可能表示资产被高估。

## 第2章：市盈率与市净率的比较

### 2.1 市盈率与市净率的差异

#### 2.1.1 计算基础的不同
- 市盈率基于收益，市净率基于资产。
- 市盈率反映市场对收益的估值，市净率反映市场对资产的估值。

#### 2.1.2 适用行业的不同
- 市盈率适用于成长型企业，如科技公司。
- 市净率适用于资产密集型企业，如银行。

### 2.2 市盈率与市净率的优缺点

#### 2.2.1 市盈率的优点与局限性
- **优点**：反映收益与股价的关系，适用于成长型企业。
- **局限性**：收益为负时，市盈率无意义。

#### 2.2.2 市净率的优点与局限性
- **优点**：适用于评估资产密集型企业。
- **局限性**：净资产可能因会计政策变化而波动。

## 第3章：格雷厄姆的价值投资理念

### 3.1 格雷厄姆的投资哲学

#### 3.1.1 价值投资的核心理念
格雷厄姆强调以低于内在价值的价格买入股票，注重安全边际。

#### 3.1.2 安全边际的概念与重要性
安全边际 = 内在价值 - 市场价格，确保投资的安全性。

### 3.2 市盈率与市净率在价值投资中的作用

#### 3.2.1 市盈率在价值投资中的应用
通过低市盈率筛选潜在低估股票，确保安全边际。

#### 3.2.2 市净率在价值投资中的应用
通过低市净率评估资产价值，寻找潜在低估企业。

#### 4.2.2 高市净率选股法
警惕高市净率，避免资产被高估的风险。

## 第8章：代码实现与工具使用

### 8.1 Python代码实现

#### 8.1.1 计算市盈率和市净率的代码
```python
import pandas as pd

def calculate_pe(stock_data):
    pe = stock_data['股价'] / stock_data['每股收益']
    return pe

def calculate_pb(stock_data):
    pb = stock_data['股价'] / stock_data['每股净资产']
    return pb

# 示例数据
data = {'股价': [100, 80, 120],
        '每股收益': [20, 10, 30],
        '每股净资产': [50, 40, 60]}
df = pd.DataFrame(data)
pe = calculate_pe(df)
pb = calculate_pb(df)
print("市盈率：", pe)
print("市净率：", pb)
```
