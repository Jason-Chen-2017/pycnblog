## 第5章: 接班人评估模型与算法分析

### 5.1 评估模型构建
- **5.1.1 核心评估指标**  
  - 投资能力（权重40%）：包括价值投资理念、风险控制能力、独立决策能力。  
  - 管理能力（权重30%）：包括分权管理能力、团队协作能力、企业文化传承。  
  - 个人特质（权重30%）：包括长期主义、谦逊与学习能力、领导力与决策力。  

- **5.1.2 评估流程**  
  使用层次分析法（AHP）对各指标进行量化，计算每个候选人的综合得分。

### 5.2 算法原理
- **5.2.1 层次分析法（AHP）**  
  $$\text{综合得分 = \sum (权重_i \times 评分_i)}$$  
  通过构建判断矩阵，计算每个指标的权重，并对候选人进行评分。

- **5.2.2 评估案例**  
  以阿吉特·贾因和查理·芒格为例，计算他们的综合得分。  
  $$\text{贾因综合得分 = 0.4 \times 90 + 0.3 \times 85 + 0.3 \times 90 = 87.5}$$  
  $$\text{芒格综合得分 = 0.4 \times 85 + 0.3 \times 90 + 0.3 \times 95 = 88.5}$$

import numpy as np
from scipy.stats import rankdata

def calculate_weighted_score(candidates, weights):
    scores = []
    for candidate in candidates:
        investment = candidate['investment']
        management = candidate['management']
        personal = candidate['personal']
        score = weights[0] * investment + weights[1] * management + weights[2] * personal
        scores.append(score)
    return scores

# 示例数据
candidates = [
    {'name': '阿吉特·贾因', 'investment': 90, 'management': 85, 'personal': 90},
    {'name': '查理·芒格', 'investment': 85, 'management': 90, 'personal': 95}
]
weights = [0.4, 0.3, 0.3]

scores = calculate_weighted_score(candidates, weights)
for i in range(len(candidates)):
    print(f"{candidates[i]['name']} 的综合得分为：{scores[i]:.1f}")
