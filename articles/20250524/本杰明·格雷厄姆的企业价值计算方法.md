## 第一部分：价值投资的背景与基础

### 第1章：价值投资的起源与发展

#### 1.1 本杰明·格雷厄姆的生平与投资理念

- **1.1.1 本杰明·格雷厄姆的早年经历**
  - 本杰明·格雷厄姆（Benjamin Graham）出生于1894年，是一位犹太裔美国投资者和教授。
  - 他在1920年代开始涉足华尔街，经历了1929年股市崩盘，这使他形成了价值投资的核心理念。

- **1.1.2 格雷厄姆与价值投资的起源**
  - 格雷厄姆与戴维·多德（David Dodd）共同开发了价值投资的方法，提出了“安全边际”概念。
  - 他的著作《证券分析》（1934年）和《 Intelligent Investor》（1949年）奠定了价值投资的基础。

- **1.1.3 格雷厄姆的价值投资核心思想**
  - 投资的本质是购买企业的一部分，而非股票的价格波动。
  - 价格是波动的，而价值是稳定的。投资者应寻找价格低于内在价值的股票。

#### 1.2 价值投资的基本概念

- **1.2.1 价值投资的定义**
  - 价值投资是一种投资策略，通过分析企业的基本面，寻找市场价格低于其内在价值的股票。

- **1.2.2 价值投资的核心原则**
  - 市场先生（Mr. Market）：市场的价格波动反映了市场的集体情绪，而非理性。
  - 安全边际：购买价格低于内在价值，以降低投资风险。

- **1.2.3 价值投资与其它投资策略的区别**
  - 与技术分析不同，价值投资注重企业的内在价值。
  - 与成长投资不同，价值投资更注重企业的当前价值而非未来的增长潜力。

## 第二部分：企业价值计算的核心方法

### 第2章：企业价值计算的基本原理

#### 2.1 企业价值的定义与构成

- **2.1.1 企业价值的定义**
  - 企业价值（Enterprise Value，EV）是企业整体价值的度量，包括股权和债权的价值。
  - EV = 公司市值 + 债务 - 现金储备

- **2.1.2 企业价值的构成要素**
  - 股权价值
  - 债务价值
  - 现金储备

- **2.1.3 企业价值与市场价值的区别**
  - 企业价值是企业的整体价值，而市场价值是股票的市场价格。
  - EV更全面地反映了企业的价值，而股价可能受市场情绪影响。

#### 2.2 格雷厄姆的企业价值计算模型

- **2.2.1 格雷厄姆的企业价值公式**
  - EV = 市盈率 × 盈利 × （1 + 增长率）
  - 或者 EV = 市净率 × 净资产 × （1 + 增长率）

- **2.2.2 格雷厄姆模型的核心假设**
  - 企业的未来盈利增长是有限的，且增长率会逐渐降低。
  - 企业的价值可以通过其盈利能力、资产质量等基本面指标来评估。

- **2.2.3 格雷厄姆模型的适用场景**
  - 适用于稳定增长的企业。
  - 适用于周期性较强的企业。

### 第3章：企业基本面分析与价值评估

#### 3.1 财务报表分析

- **3.1.1 资产负债表分析**
  - 流动资产：现金、应收账款、存货等。
  - 非流动资产：固定资产、无形资产等。
  - 负债：短期负债和长期负债。
  - 所有者权益：净资产价值。

- **3.1.2 利润表分析**
  - 收入：营业收入、其他收入。
  - 成本：营业成本、税金及附加。
  - 利润：净利润、息税前利润（EBIT）。

- **3.1.3 现金流量表分析**
  - 经营活动现金流：企业经营活动中产生的现金流。
  - 投资活动现金流：企业投资活动产生的现金流。
  - 筹资活动现金流：企业筹资活动产生的现金流。

#### 3.2 核心财务指标分析

- **3.2.1 市盈率（P/E）分析**
  - P/E = 股价 / 每股收益（EPS）
  - 低市盈率可能意味着低估，高市盈率可能意味着高成长或高风险。

- **3.2.2 市净率（P/B）分析**
  - P/B = 股价 / 每股净资产（BPS）
  - 低市净率可能意味着低估，高市净率可能意味着高成长或高泡沫。

- **3.2.3 股息率分析**
  - 股息率 = 每股股息（DIV） / 股价
  - 高股息率可能意味着高收益或低增长。

#### 3.3 企业成长性评估

- **3.3.1 营收增长率**
  - 营收增长率 = （本年营收 - 去年营收） / 去年营收 × 100%

- **3.3.2 净利润增长率**
  - 净利润增长率 = （本年净利润 - 去年净利润） / 去年净利润 × 100%

- **3.3.3 资产回报率（ROA）**
  - ROA = 净利润 / 平均总资产
  - 高ROA意味着资产使用效率高。

## 第三部分：企业价值计算的高级方法

### 第4章：内在价值计算的数学模型

#### 4.1 格雷厄姆的内在价值公式

- **4.1.1 内在价值的定义**
  - 内在价值是企业在未来现金流的现值。
  - EV = Σ（CF_t / (1 + r)^t）

- **4.1.2 格雷厄姆的内在价值计算公式**
  - EV = 股东权益 + 长期债务 - 现金储备
  - 或者 EV = 市盈率 × 盈利 × （1 + 增长率）

- **4.1.3 内在价值公式的数学推导**
  - 假设企业未来每年的现金流为CF_t，贴现率为r，永续增长率为g。
  - EV = (CF_1)/(1+r) + (CF_2)/(1+r)^2 + ... + (CF_n)/(1+r)^n
  - 如果现金流以恒定增长率g增长，EV = CF_1/(r - g)

#### 4.2 财务指标与企业价值的关系

- **4.2.1 财务指标对企业价值的影响**
  - 高盈利能力（如ROE、ROA）会增加企业价值。
  - 高成长性（如营收增长率）会增加企业价值。
  - 高负债率会降低企业价值。

- **4.2.2 财务指标的权重分配**
  - 根据企业所处行业和经营环境，调整各项指标的权重。

- **4.2.3 财务指标的动态变化**
  - 随着时间推移，财务指标会变化，需要定期重新评估。

def calculate_intrinsic_value(eps, pe_ratio, growth_rate):
    """
