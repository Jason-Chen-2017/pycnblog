## 第二部分：通货膨胀对资产定价的影响

### 第2章：通货膨胀与资产定价

#### 2.1 股票定价与通货膨胀

**背景介绍**：股票的内在价值公式为：

$$ V = \frac{CF}{(1 + r)^n} $$

其中，$CF$ 是未来现金流，$r$ 是折现率，$n$ 是时间跨度。通货膨胀会增加$CF$和$r$的不确定性。

**项目实战**：假设某公司的未来现金流为$100万，折现率为5%，通货膨胀率为3%，计算调整后的股票价值：

```python
def calculate_stock_value(CF, r, n, inflation):
    real_r = (1 + r) / (1 + inflation) - 1
    discounted_value = CF / (1 + real_r)
    return discounted_value

CF = 1000000
r = 0.05
n = 5
inflation = 0.03
print(calculate_stock_value(CF, r, n, inflation))
```

#### 2.2 债券定价与通货膨胀

**背景介绍**：债券的票面价值为$F$，到期收益率为$y$，通货膨胀会降低债券的实际收益率。

**算法原理讲解**：债券的通货膨胀调整后的实际收益率公式为：

$$ \text{实际收益率} = \frac{y - \text{通货膨胀率}}{1 + \text{通货膨胀率}} $$
