### 5.2 算法实现的代码示例

```python
def calculate_political_risk(factors, weights):
    risk_scores = {}
    for factor, weight in zip(factors, weights):
        risk_scores[factor] = weight * factor
    return risk_scores

# 示例调用
factors = ['政策稳定性', '经济状况', '社会矛盾']
weights = [0.4, 0.3, 0.3]
result = calculate_political_risk(factors, weights)
print(result)
```

### 5.3 模型优化的数学公式
$$风险值 = \sum_{i=1}^{n} w_i \cdot f_i$$

其中，$w_i$ 表示第 $i$ 个风险因子的权重，$f_i$ 表示第 $i$ 个风险因子的风险分数。
