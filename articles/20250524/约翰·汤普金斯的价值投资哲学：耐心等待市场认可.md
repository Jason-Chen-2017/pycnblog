## 第一章：价值投资的背景与核心概念

### 1.1 价值投资的定义与历史发展

#### 1.1.1 价值投资的定义
价值投资是一种基于对公司内在价值评估的投资策略，强调以低于内在价值的价格买入优质资产，长期持有，等待市场重新认识其价值。其核心在于寻找被市场低估的机会。

#### 1.1.2 价值投资的历史发展
价值投资起源于20世纪初，以本杰明·格雷厄姆和戴维·多德为代表，后来被约翰·汤普金斯发扬光大。汤普金斯进一步完善了价值投资的理论，提出了“安全边际”和“耐心等待市场认可”的理念。

#### 1.1.3 价值投资的核心要素
价值投资的核心要素包括：对公司基本面的深入分析、对安全边际的追求、对市场短期波动的耐心以及对长期价值的坚持。

### 1.2 价值投资与市场效率

价值投资基于市场的非有效性，认为市场短期波动为投资者提供了以低于内在价值买入资产的机会。通过分析市场周期和价格偏离，投资者可以在市场低估时进场。

```python
import pandas as pd

# 假设df为包含财务数据的DataFrame
def calculate_intrinsic_value(df):
    df['ROE'] = df['净利润'] / df['净资产']
    df['Growth'] = df['净利润'].pct_change()
    df['Intrinsic Value'] = df['净利润'] * (1 + df['Growth']) / df['资本成本']
    return df
```
