## 第一部分: 约翰伯格的指数投资理论概述

### 第1章: 指数投资的背景与核心概念

#### 1.1 指数投资的起源与发展

指数投资起源于20世纪70年代，约翰·伯格在1975年推出了第一只指数基金——Vanguard 500指数基金，标志着指数投资的开始。指数投资的起源可以追溯到市场效率理论，即市场参与者难以持续跑赢市场指数，尤其是通过主动管理。

| 核心概念 | 定义 | 优点 |
|----------|------|------|
| 指数基金 | 投资市场指数的基金 | 成本低、风险分散 |
| 被动投资 | 按指数成分股投资 | 简单、有效 |

#### 1.2 约翰·伯格的指数投资理论

约翰·伯格的投资理念强调市场效率和低成本。他提出，被动投资通过跟踪市场指数，能够以更低的成本获得市场平均收益。指数投资的优势在于分散化，降低个股风险。

#### 1.3 指数投资的数学模型与公式

指数投资的核心在于夏普比率，衡量风险调整后的收益。公式为：

$$\text{夏普比率} = \frac{E[r] - r_f}{\sigma}$$

其中，$E[r]$ 是预期收益，$r_f$ 是无风险利率，$\sigma$ 是收益的标准差。

### 第3章: 指数投资的算法原理与实现

#### 3.1 指数投资的算法原理

指数投资通过计算市场指数的收益和风险，优化投资组合。算法包括收益计算、风险评估和优化。

#### 3.2 指数投资的算法实现

使用Python计算指数基金的夏普比率：

```python
import numpy as np

def calculate_sharpe_ratio(returns, risk_free_rate):
    excess_returns = returns - risk_free_rate
    mean_return = np.mean(excess_returns)
    std_deviation = np.std(excess_returns)
    return mean_return / std_deviation

# 示例数据
returns = np.array([0.05, 0.06, 0.04, 0.07])
risk_free_rate = 0.02

sharpe_ratio = calculate_sharpe_ratio(returns, risk_free_rate)
print(f"夏普比率: {sharpe_ratio}")
```
