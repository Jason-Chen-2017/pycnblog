#### 5.2.2 稀缺性计算
```python
import pandas as pd

# 计算稀缺性指数
def calculateScarceIndex(data):
    data['scarce_index'] = data.groupby('resource')['price'].transform('mean')
    return data

scarce_data = calculateScarceIndex(data)
```

#### 5.2.3 预测模型
```python
from sklearn.linear_model import LinearRegression

# 构建预测模型
model = LinearRegression()
X = scarce_data[['scarce_index']]
y = scarce_data['price']
model.fit(X, y)

# 预测未来价格
predicted_prices = model.predict(X)
```
