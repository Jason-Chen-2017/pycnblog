# 第1章 本杰明·格雷厄姆的生平与投资哲学概述

## 1.1 本杰明·格雷厄姆的生平简介
### 1.1.1 格雷厄姆的早年经历与教育背景
本杰明·格雷厄姆（Benjamin Graham）出生于1894年，是一位英国移民的后代。他在纽约市长大，父亲是一位成功的 businessman。格雷厄姆在哥伦比亚大学获得经济学学士学位，随后进入华尔街工作，开始了他的投资生涯。

### 1.1.2 格雷厄姆的职业生涯与发展
格雷厄姆的职业生涯始于1914年，他在多家投资公司工作，逐渐积累了丰富的投资经验。他在职业生涯中撰写了多本关于投资的书籍，其中包括《安全边际》和《价值投资》等经典著作。

### 1.1.3 格雷厄姆对投资界的贡献与影响
格雷厄姆是价值投资的鼻祖，他的投资哲学影响了无数投资者。他的学生包括著名的沃伦·巴菲特，巴菲特曾称格雷厄姆为“投资导师”。

## 1.2 投资哲学的核心概念
### 1.2.1 价值投资的基本定义
价值投资是一种投资策略，强调购买被市场低估的股票，以低于其内在价值的价格买入，并长期持有。

### 1.2.2 格雷厄姆投资哲学的核心思想
格雷厄姆的核心思想是“安全边际”，即在购买股票时，确保价格远低于其内在价值，以降低投资风险。

### 1.2.3 格雷厄姆哲学对现代投资的影响
格雷厄姆的投资哲学奠定了现代价值投资的基础，他的思想被广泛应用于机构投资和个人投资中。

安全边际为投资者提供了风险缓冲，即使市场波动，投资者也能在价格回升时获利。

### 2.1.3 安全边际与风险控制的关系
通过保持安全边际，投资者可以降低投资组合的风险，避免重大亏损。

# 第4章 价值评估与内在价值计算

## 4.1 内在价值的定义与计算方法
### 4.1.1 内在价值的定义
内在价值是指公司未来现金流的现值，反映了公司的真实价值。

### 4.1.2 内在价值的计算公式与步骤
内在价值计算公式：
$$
\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t}
$$
其中，r是折现率，n是预测期数。

### 4.1.3 内在价值计算的注意事项
包括现金流预测的准确性、折现率的选择等。

## 4.2 市场波动与投资机会
### 4.2.1 市场波动的定义与影响
市场波动是指市场价格的频繁变动，可能会影响投资者的决策。

### 4.2.2 市场波动与内在价值的关系
市场波动可能导致市场价格偏离内在价值，为投资者提供投资机会。

### 4.2.3 如何利用市场波动寻找投资机会
投资者应关注市场价格低于内在价值的情况，寻找投资机会。

def calculate_intrinsic_value(cash_flows, discount_rate):
    present_value = 0
    for t in range(len(cash_flows)):
        present_value += cash_flows[t] / (1 + discount_rate) ** t
    return present_value

cash_flows = [100, 150, 200]
discount_rate = 0.10
iv = calculate_intrinsic_value(cash_flows, discount_rate)
print(f"内在价值: {iv}")
