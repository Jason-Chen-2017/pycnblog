**3.1 管理层质量评估的数学模型**

费雪方法的评估模型可以表示为一个加权评分系统。假设我们有n个评估维度，每个维度的权重为w_i，评估得分为s_i。总评分为：

$$
\text{总评分} = \sum_{i=1}^{n} (w_i \times s_i)

其中，w_i为各维度的权重，s_i为各维度的评分。

**5.2 核心实现源代码**

以下是费雪方法评估系统的Python代码示例：

```python
# 定义评估维度和权重
dimensions = ['战略思维', '团队领导力', '决策能力', '创新能力']
weights = [0.4, 0.3, 0.2, 0.1]

# 输入评估数据
data = {
    '战略思维': [90, 85, 95, 80],
    '团队领导力': [85, 88, 82, 87],
    '决策能力': [75, 80, 88, 78],
    '创新能力': [90, 85, 80, 92]
}

# 计算总评分
def calculate_total_score(dimensions, weights, data):
    total_scores = []
    for i in range(len(data[dimensions[0]])):
        score = 0
        for j in range(len(dimensions)):
            score += weights[j] * data[dimensions[j]][i]
        total_scores.append(score)
    return total_scores

# 输出结果
scores = calculate_total_score(dimensions, weights, data)
print("各管理者的总评分为：", scores)
```
