## 第4章：投资风格分类算法

### 4.1 聚类分析原理
- **4.1.1 K-means算法原理**
  - 算法步骤：初始化质心、计算距离、重新计算质心
  - 聚类效果评估：轮廓系数、肘部法则

- **4.1.2 层次聚类算法**
  - 算法步骤：计算距离矩阵、合并最近的簇、计算聚类树
  - 聚类结果的可视化：树状图

- **4.1.3 聚类评估指标**
  - 内部评估指标：轮廓系数、DBI指数
  - 外部评估指标：调整兰德指数

### 4.2 分类算法实现
- **4.2.1 K-means算法的Python实现**
  ```python
  from sklearn.cluster import KMeans

  kmeans = KMeans(n_clusters=3, random_state=0)
  kmeans.fit(scaled_data)
  labels = kmeans.labels_
  ```

- **4.2.2 聚类结果的可视化**
  ```python
  import matplotlib.pyplot as plt

  plt.scatter(scaled_data[:,0], scaled_data[:,1], c=labels)
  plt.xlabel('Feature 1')
  plt.ylabel('Feature 2')
  plt.title('Clustering Results')
  plt.show()
  ```

- **4.2.3 聚类效果评估**
  ```python
  from sklearn.metrics import silhouette_score

  print(silhouette_score(scaled_data, labels))
  ```

### 4.3 投资风格分类的数学模型
- **4.3.1 K-means算法公式**
  $$ J = \sum_{i=1}^{k} \sum_{j=1}^{n_i} \|x_{ij} - c_i\|^2 $$
  其中，$x_{ij}$ 是第 $i$ 个簇中的第 $j$ 个样本，$c_i$ 是第 $i$ 个簇的质心。
