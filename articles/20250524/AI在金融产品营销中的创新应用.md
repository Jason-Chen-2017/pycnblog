## 第三部分：AI算法原理与数学模型

### 第3章：机器学习算法原理

#### 3.1 线性回归与逻辑回归

线性回归适用于连续型变量的预测，而逻辑回归则适用于分类问题。以下是逻辑回归的损失函数：

$$ L(\theta) = -\frac{1}{m} \sum_{i=1}^{m} [y_i \ln h(x_i) + (1 - y_i) \ln (1 - h(x_i))] $$

其中，$h(x_i) = \frac{e^{\theta^T x_i}}{1 + e^{\theta^T x_i}}$ 是sigmoid函数。

#### 3.2 支持向量机（SVM）

SVM通过构建超平面实现数据的线性或非线性分类。其优化目标为：

$$ \min_{\theta, b, \xi} \frac{1}{2}||\theta||^2 + C\sum_{i=1}^{m}\xi_i $$

约束条件为：

$$ y_i (\theta^T x_i + b) \geq 1 - \xi_i $$
$$ \xi_i \geq 0 $$

#### 5.2 核心算法实现

以下是一个简单的客户画像算法实现：

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

# 数据预处理
data = pd.read_csv('customer_data.csv')
features = data[['age', 'income', 'purchase_frequency']]
scaler = StandardScaler()
scaled_features = scaler.fit_transform(features)

# K-means聚类
kmeans = KMeans(n_clusters=3, random_state=42)
clusters = kmeans.fit_predict(scaled_features)

# 可视化结果
print(clusters)
```
