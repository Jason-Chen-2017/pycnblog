## 第一部分：引言

### 第1章：投资学的基础与本杰明·格雷厄姆的贡献

#### 1.1 投资学的基本概念
投资是将资金投入到资产中以获取未来收益的行为。投资可以分为不同类型，包括股票、债券、房地产等。投资的基本原则包括分散投资、长期持有和价值评估。

本杰明·格雷厄姆（1897-1976）是美国著名的投资学家，被誉为“价值投资之父”。他在《证券分析》一书中提出了许多经典的财务分析方法，如内在价值计算、安全边际等。他的投资理念深刻影响了后来的投资者，包括沃伦·巴菲特。

## 第二部分：核心概念与联系

### 第2章：安全边际与内在价值

#### 2.1 安全边际的概念与重要性
安全边际是指股票的市场价格低于其内在价值的部分。通过安全边际，投资者可以降低投资风险，确保在市场波动中仍能获得收益。

| 安全边际 | 内在价值 | 市场价格 |
|----------|-----------|----------|
| 高       | 高        | 低于内在价值 |

#### 2.2 内在价值的计算方法
内在价值是通过分析公司的财务状况、盈利能力等因素，计算出股票的真正价值。公式为：

$$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}}{(1 + r)^t}$$

其中，\( r \) 是折现率，\( t \) 是时间。

#### 2.3 安全边际与内在价值的关系
安全边际 = 内在价值 - 市场价格

## 第三部分：财务报表分析

### 第3章：如何通过财务报表评估公司价值

#### 3.1 财务报表分析的基础知识
财务报表包括资产负债表、利润表和现金流量表。通过分析这些报表，可以了解公司的财务状况、盈利能力和发展潜力。

#### 3.2 格雷厄姆的财务指标分析方法
格雷厄姆常用市盈率、市净率和股息率等指标来评估公司价值。

- 市盈率 = 股价 / 每股收益
- 市净率 = 股价 / 每股净资产
- 股息率 = 每股股息 / 股价

#### 3.3 如何通过财务报表计算内在价值
格雷厄姆的现金流折现法是一种常用的内在价值计算方法。公式为：

$$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}}{(1 + r)^t} + \text{终值}$$

其中，终值是未来现金流的终值。

```python
def calculate_intrinsic_value(cash_flow, discount_rate, horizon):
    iv = 0
    for t in range(1, horizon + 1):
        iv += cash_flow[t] / (1 + discount_rate) ** t
    return iv

cash_flow = [100, 120, 150, 200]
discount_rate = 0.1
horizon = 4

intrinsic_value = calculate_intrinsic_value(cash_flow, discount_rate, horizon)
print("内在价值为：", intrinsic_value)
```
