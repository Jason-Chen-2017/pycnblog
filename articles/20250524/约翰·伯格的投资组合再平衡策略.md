## 第一部分: 投资组合再平衡策略概述

### 第1章: 投资组合再平衡的核心概念

#### 1.1 投资组合再平衡的定义与背景

投资组合再平衡是一种通过定期调整投资组合中的资产权重，以维持预期风险和收益水平的策略。其核心思想是根据市场变化和个人投资目标的变化，动态优化资产配置。再平衡的目的是降低风险、提高收益并避免过度集中。

**约翰·伯格的再平衡策略**是基于现代投资组合理论（MPT）的一种动态调整方法。其核心思想是通过定期调整资产权重，使投资组合的风险和收益达到最优状态。

#### 1.2 约翰·伯格再平衡策略的核心思想

约翰·伯格的投资组合再平衡策略强调：
1. **风险控制**：通过分散投资降低组合的整体风险。
2. **动态优化**：根据市场变化和个人目标调整组合。
3. **长期视角**：定期检查和调整组合，确保长期收益。

### 第2章: 投资组合再平衡的理论基础

#### 2.1 资产配置与风险分散

资产配置是投资组合管理的核心，通过将资金分配到不同资产类别（股票、债券、现金等），降低组合的波动性并提高收益。

**风险分散原理**：投资组合的风险低于单一资产的风险，因为不同资产的收益波动不完全相关。

#### 2.2 约翰·伯格再平衡策略的数学模型

约翰·伯格的再平衡策略基于**均值-方差优化模型**，目标是最小化组合的风险（方差）并最大化收益。

**公式推导**：
$$ E(r_p) = \sum w_i E(r_i) $$
$$ \sigma_p^2 = \sum w_i^2 \sigma_i^2 + 2 \sum_{i < j} w_i w_j \rho_{ij} \sigma_i \sigma_j $$

其中：
- $w_i$：资产i的权重
- $E(r_i)$：资产i的期望收益
- $\sigma_i$：资产i的收益波动率
- $\rho_{ij}$：资产i和j的相关性

#### 6.2 核心代码实现

```python
import numpy as np
from sklearn.covariance import LedoitWolf
import matplotlib.pyplot as plt

def mean_variance_optimization(risky_returns, risky_weights, risk_free_rate):
    # 计算协方差矩阵
    cov_matrix = np.cov(risky_returns)
    
    # 使用拉格朗日乘数法求解优化问题
    A = np.array([np.append(risky_weights, 1)])
    b = np.array([1])
    
    # 优化目标：最小化方差
    def objective(weights):
        return -np.dot(weights[:-1], np.dot(cov_matrix, weights[:-1]))
    
    # 约束条件：权重之和=1
    def constraint(weights):
        return np.dot(A, weights) - b
    
    # 使用scipy优化器
    from scipy.optimize import minimize
    weights = np.array([1.0/len(risky_weights)]*len(risky_weights))
    result = minimize(objective, weights, method='SLSQP', constraints={'type': 'eq', 'fun': constraint})
    
    return result.x[:-1]

# 示例数据
risky_returns = np.array([[0.1], [0.05], [0.08]])
risky_weights = [0.4, 0.3, 0.3]
risk_free_rate = 0.02

optimal_weights = mean_variance_optimization(risky_returns, risky_weights, risk_free_rate)
print("最优权重:", optimal_weights)
```

### 7.1 最佳实践
