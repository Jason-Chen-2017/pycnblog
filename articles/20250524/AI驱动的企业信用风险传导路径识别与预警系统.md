```python
from sklearn.preprocessing import StandardScaler

df = pd.read_csv('企业数据.csv')

# 标准化处理
scaler = StandardScaler()
scaled_data = scaler.fit_transform(df[['收入', '利润', '负债', '现金流']])
```

### 5.2.2 模型训练代码
