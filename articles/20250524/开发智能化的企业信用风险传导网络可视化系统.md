# 第一部分: 企业信用风险传导网络可视化系统背景与概述

## 第1章: 信用风险的基本概念与重要性

### 1.1 信用风险的定义与特性

#### 1.1.1 信用风险的基本定义
信用风险是指由于债务人或交易对手无法履行其合同义务，导致债权人或利益相关方遭受损失的可能性。在企业层面，信用风险通常涉及企业在供应链中的付款延迟、债务违约等情况。

#### 1.1.2 信用风险的主要特性
- **传染性**：信用风险可能通过供应链或金融网络从一家企业传导到另一家企业。
- **系统性**：单个企业的信用风险可能引发连锁反应，影响整个金融系统的稳定性。
- **复杂性**：涉及多个企业和金融机构的复杂网络关系，使得风险分析变得复杂。

#### 1.1.3 信用风险对企业的影响
- 企业声誉受损
- 资金链断裂
- 供应链中断
- 金融市场波动

### 1.2 企业信用风险传导的背景与问题

#### 1.2.1 企业信用风险传导的定义
信用风险传导是指由于一家企业的信用问题，导致其供应商、客户或其他相关企业也面临信用风险的过程。

#### 1.2.2 信用风险传导的主要途径
- 供应链直接传导：企业A违约，导致其供应商企业B面临应收账款无法收回的风险。
- 金融网络传播：企业A的违约可能引发金融机构的风险厌恶，进而影响其他企业的融资能力。

#### 1.2.3 信用风险传导中的关键问题
- 如何量化风险传导的路径和强度？
- 如何预测风险传导的可能性和影响范围？
- 如何通过可视化手段帮助决策者理解风险传导过程？

### 1.3 可视化系统在信用风险传导中的作用

#### 1.3.1 可视化技术的基本概念
可视化技术通过图形、图表等形式，将数据或信息以直观的方式呈现，帮助用户更好地理解和分析问题。

#### 1.3.2 可视化在信用风险分析中的应用
- 网络图展示企业之间的关系
- 风险热力图显示风险分布
- 时间序列图展示风险变化趋势

#### 1.3.3 网络可视化在信用风险传导中的优势
- 便于识别关键节点企业
- 可视化风险传导路径
- 有助于制定风险缓解策略

#### 3.3.1 风险传导的概率公式
$$ P_{i} = \sum_{j} P_{i|j} \cdot P(j) $$
其中，\( P_{i} \) 表示企业 i 违约的概率，\( P_{i|j} \) 表示在企业 j 违约的情况下，企业 i 违约的概率，\( P(j) \) 表示企业 j 违约的概率。

#### 3.3.2 风险传导的网络权重公式
$$ w_{i,j} = \frac{1}{1 + d_{i,j}} $$
其中，\( w_{i,j} \) 表示企业 i 和 j 之间的权重，\( d_{i,j} \) 表示两者之间的距离。

## 第5章: 信用风险传导网络的数学模型

### 5.1 概率传播模型

#### 5.1.1 概率传播的基本原理
- 假设企业 i 违约的概率为 \( p_i \)
- 企业 i 违约可能影响其关联企业 j 的违约概率
- 使用概率传播模型计算企业 j 的违约概率

#### 5.1.2 概率传播的公式
$$ p_j = \sum_{i} p_{i} \cdot w_{i,j} $$
其中，\( w_{i,j} \) 是企业 i 和 j 之间的权重，表示企业 i 的违约对企业 j 的影响程度。

#### 7.3.2 概率传播算法代码
```python
import numpy as np

def probability_propagation(network, initial_probabilities):
    n = len(network.nodes)
    P = np.zeros(n)
    for i in range(n):
        P[i] = initial_probabilities[i]
        for j in range(n):
            if i != j and network.has_edge(i, j):
                P[i] += P[j] * 0.5  # 假设权重为0.5
    return P
```
