# 第1章: 投资学基础与价值投资概述

## 1.1 投资学的基本概念

### 1.1.1 投资的基本定义
投资是指将资金投入某一实体或金融资产，以期在未来获得收益或资本增值的行为。投资的核心目标是通过科学的分析和决策，最大化资产的回报率。

### 1.1.2 金融市场的基本构成
金融市场由投资者、发行人、中介机构和监管机构构成。股票市场作为金融市场的重要组成部分，是企业融资和投资者投资的主要场所。

### 1.1.3 价值投资的起源与发展
价值投资起源于20世纪初，由本杰明·格雷厄姆和戴维·多德共同提出。其核心理念是寻找市场价格低于其内在价值的股票，长期持有以实现收益。

## 1.2 价值投资的核心理念

### 1.2.1 价值投资的定义
价值投资是一种投资策略，强调以低于内在价值的价格购买优质资产，长期持有，等待市场重新认识其价值。

### 1.2.2 格雷厄姆的价值投资理论
格雷厄姆提出，股票的价值应基于其未来现金流的现值计算，而非市场情绪或短期价格波动。他强调安全边际的重要性，即市场价格与内在价值之间的差距。

### 1.2.3 价值投资与其他投资策略的对比
与趋势投资和技术分析不同，价值投资注重基本面分析，寻找被市场低估的股票。其核心在于对企业的深入研究和对安全边际的追求。

## 1.3 格雷厄姆的生平与贡献

### 1.3.1 格雷厄姆的生平简介
本杰明·格雷厄姆（1897-1976）是20世纪最伟大的投资思想家之一，被誉为“价值投资之父”。他在哥伦比亚大学教授投资课程，并培养了包括沃伦·巴菲特在内的众多投资大师。

### 1.3.2 格雷厄姆对投资学的贡献
格雷厄姆提出了内在价值的概念，并强调安全边际的重要性。他的著作《证券分析》和《聪明的投资者》奠定了价值投资的理论基础。

### 1.3.3 格雷厄姆的投资哲学
格雷厄姆的投资哲学强调长期、稳健的投资策略，避免过度依赖市场预测，注重对企业基本面的深入研究。

# 第2章: 格雷厄姆的股票选择公式

## 2.1 格雷厄姆的选股标准

### 2.1.1 市盈率（P/E）的计算与应用
市盈率（P/E）= 股票价格 / 每股净利润。格雷厄姆建议选择市盈率低于某个阈值的股票，以确保安全边际。

### 2.1.2 市净率（P/B）的计算与应用
市净率（P/B）= 股票价格 / 每股净资产。格雷厄姆认为市净率低于某个值的股票具有较高的投资价值。

### 2.1.3 股息率的计算与应用
股息率= 每股股息 / 股票价格。格雷厄姆倾向于选择股息率较高的股票，以获得稳定的现金流。

## 2.2 格雷厄姆的内在价值公式

### 2.2.1 内在价值的定义
内在价值是股票基于未来现金流的现值计算出的理论价值，与市场价无关。

### 2.2.2 内在价值的计算公式
$$\text{内在价值} = \frac{\text{每股收益} \times (1 + \text{增长率})}{\text{折现率}}$$

### 2.2.3 内在价值与市场价的对比
如果市场价格低于内在价值，则股票具有投资价值。

## 2.3 安全边际的概念与应用

### 2.3.1 安全边际的定义
安全边际= 内在价值 - 市场价格。格雷厄姆建议选择安全边际较大的股票，以降低投资风险。

### 2.3.2 安全边际的计算方法
$$\text{安全边际} = \text{内在价值} - \text{市场价格}$$

### 2.3.3 安全边际在选股中的作用
安全边际是衡量股票投资风险的重要指标，较大的安全边际意味着更高的投资安全性。
