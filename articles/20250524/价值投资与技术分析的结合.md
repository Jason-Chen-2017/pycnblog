## 第一部分：价值投资与技术分析的概述

### 第1章：价值投资与技术分析的核心概念

#### 1.1 价值投资的基本概念
- **1.1.1 定义**：价值投资是一种基于公司基本面分析的投资方法，旨在寻找市场价格低于其内在价值的股票。
- **1.1.2 核心理念**：市场先生、安全边际、长期投资。
- **1.1.3 主要方法**：基本面分析、DCF模型、财务指标评估。

#### 1.2 技术分析的基本概念
- **1.2.1 定义**：技术分析通过分析历史价格和成交量数据，预测未来价格走势。
- **1.2.2 核心假设**：市场行为包含一切信息、价格走势具有趋势性、历史形态会重复。
- **1.2.3 主要工具与方法**：K线图、移动平均线、相对强弱指数（RSI）、布林带。

#### 1.3 价值投资与技术分析的结合意义
- **1.3.1 互补性**：价值投资提供长期价值判断，技术分析提供短期价格信号。
- **1.3.2 优势**：结合两者的投资策略能够在不同市场条件下灵活应对。
- **1.3.3 适用场景**：牛市、熊市、震荡市。

#### 1.4 经典案例
- **1.4.1 价值投资案例**：巴菲特投资可口可乐。
- **1.4.2 技术分析案例**：利用MA和RSI指标捕捉苹果股价波动。

## 第二部分：价值投资的理论与实践

### 第2章：价值投资的理论基础

#### 2.1 价值投资的基本原理
- **2.1.1 市场先生的概念**：市场情绪波动影响股价，投资者应利用市场的非理性。
- **2.1.2 安全边际的定义与作用**：安全边际 = 内在价值 - 市场价格，确保投资的安全性。
- **2.1.3 股票的价值评估方法**：DCF模型、市盈率、市净率。

#### 2.2 价值投资的主要方法
- **2.2.1 股票估值方法**：DCF模型、股息贴现模型。
- **2.2.2 财务指标分析**：ROE、ROA、净利率、债务率。
- **2.2.3 行业分析与竞争优势评估**：行业壁垒、竞争优势、护城河。

#### 2.3 价值投资的经典案例
- **2.3.1 巴菲特的选股方法**：寻找具有持续竞争优势的企业。
- **2.3.2 卡尔·费雪的投资理念**：投资优质成长股。
- **2.3.3 格雷厄姆的估值模型**：购买低于清算价值的股票。

## 第三部分：技术分析的理论与实践

### 第3章：技术分析的核心工具与方法

#### 3.1 技术分析的基本假设
- **3.1.1 市场行为包含一切信息**：价格反映所有信息，包括基本面和技术面。
- **3.1.2 价格走势具有趋势性**：趋势具有持续性，容易被识别和利用。
- **3.1.3 历史形态会重复**：形态如头肩顶、双底等具有重复性。

#### 3.2 技术分析的主要工具
- **3.2.1 K线图与成交量分析**：K线图显示价格波动，成交量辅助判断趋势强度。
- **3.2.2 移动平均线（MA）的应用**：MA用于过滤短期波动，识别趋势方向。
- **3.2.3 相对强弱指数（RSI）的使用**：RSI用于判断超买超卖状态。
- **3.2.4 布林带（Bollinger Bands）的原理**：布林带用于识别超买超卖和 volatility。

#### 3.3 技术分析的主要方法
- **3.3.1 趋势分析法**：利用趋势线和支撑阻力位判断价格走势。
- **3.3.2 形态分析法**：识别反转形态（如头肩顶）和持续形态（如矩形）。
- **3.3.3 指标分析法**：结合多个指标（如MACD、RSI）进行综合判断。

  ```python
  def calculate_rsi(df, period=14):
      df['RSI'] = df['Close'].rolling(period).apply(lambda x: (x[-1] - x[-2])/x[-2], raw=False)
      df['RSI'] = 100 - (100 - df['RSI'].rolling(period).apply(lambda x: (x[-1] - x[0])/x[-1], raw=False))
      return df
  ```
- **6.2.3 信号生成代码**：

  ```python
  def generate_signals(df):

      return df
  ```
