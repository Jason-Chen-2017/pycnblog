### 6.3 Python代码实现
```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(FCF, discount_rate):
    # 永续年金公式
    return FCF / (discount_rate - (1 - 1/(1+discount_rate)))

# 示例数据
FCF = 100
discount_rate = 0.1
intrinsic_value = calculate_intrinsic_value(FCF, discount_rate)
print(f"内在价值：{intrinsic_value}")
```
