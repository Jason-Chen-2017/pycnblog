## 第1章：投资组合管理概述

### 1.1 投资组合管理的背景与意义

#### 背景介绍：
投资组合管理是金融领域中的核心实践，旨在通过科学的资产配置和风险管理，帮助投资者在不同市场环境下实现投资目标。随着金融市场的发展，投资组合管理的重要性日益凸显。

#### 核心概念：
- **投资组合**：一组金融资产的集合，旨在通过多样化的投资降低风险。
- **风险调整后收益**：衡量资产或投资组合收益与风险的比值，帮助投资者做出更明智的决策。

#### 问题背景：
在金融市场中，投资者面临多样化的选择，如何在风险可控的前提下实现收益最大化，是投资组合管理的核心问题。

#### 问题解决：
通过资产配置和优化算法，投资组合管理能够在不同市场环境下优化资产组合，降低风险，提高收益。

#### 边界与外延：
- **边界**：主要关注金融资产的投资组合优化，不涉及房地产、艺术品等另类资产。
- **外延**：与风险管理、资产定价等密切相关，是金融学的重要分支。

#### 概念结构：
- **核心要素**：资产、权重、收益、风险。
- **核心目标**：最大化收益、最小化风险。

## 第2章：资产配置与风险调整

### 2.1 资产配置的基本原理

#### 资产配置的核心思想：
通过将资金分配到不同资产类别（如股票、债券、现金等），降低投资组合的波动性，实现风险分散。

#### 资产类别对比：
| 资产类别 | 风险特征 | 收益特征 |
|----------|----------|----------|
| 股票     | 高       | 高       |
| 债券     | 中       | 稳定     |
| 现金     | 低       | 低       |

#### 资产配置策略：
- **战略资产配置**：长期固定的资产分配。
- **战术资产配置**：根据市场变化进行短期调整。

## 第3章：现代投资组合理论（MPT）与优化算法

### 3.1 MPT的核心思想与数学模型

#### 核心思想：
通过优化资产组合，实现收益最大化和风险最小化的平衡。

#### 数学模型：
$$\text{Minimize } \sigma^2 \text{ subject to } \mathbf{w}^T \mathbf{μ} = \text{target return}$$

#### 优化算法流程图：
```mermaid

    A[开始] --> B[初始化权重]
    B --> C[计算收益和风险]
    C --> D[检查约束条件]
    D --> E[调整权重]
    E --> F[计算最优解]
    F --> G[结束]
```

### 3.2 均值-方差模型的实现步骤

#### 步骤分解：
1. **输入数据**：历史收益率数据。
2. **计算均值和方差**：使用Python计算各资产的期望收益和协方差矩阵。
3. **优化模型**：使用`scipy.optimize.minimize`进行优化。
4. **输出结果**：最优权重和最小方差。

#### Python代码实现：
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns):
    n = len(returns.columns)
    mu = returns.mean().values
    sigma = returns.cov().values

    def objective(weights):
        return (weights.T @ sigma @ weights)[0,0]

    constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
    bounds = [(0, 1) for _ in range(n)]

    result = minimize(objective, np.ones(n)/n, method='SLSQP', constraints=constraints, bounds=bounds)
    return result.x
```

#### 结果分析：
- 最优权重：每个资产的配置比例。
- 最小方差：投资组合的风险最小值。
