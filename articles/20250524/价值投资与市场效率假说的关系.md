## 第1章：引言

### 1.1 价值投资与市场效率假说的概述

#### 1.1.1 价值投资的定义与核心理念  
价值投资是一种投资策略，强调以低于内在价值的价格购买优质资产。其核心理念包括：  
1. **长期投资**：关注企业的长期价值，而非短期市场波动。  
2. **安全边际**：买入价格应低于企业的内在价值，以降低风险。  
3. **基本面分析**：通过分析企业的财务状况、行业地位和盈利能力来评估其价值。  

#### 1.1.2 市场效率假说的基本概念  
市场效率假说认为，金融市场的价格反映了所有可获得的信息。市场效率分为三类：  
1. **弱有效市场**：价格反映历史信息。  
2. **半强有效市场**：价格反映所有公开信息。  
3. **强有效市场**：价格反映所有公开和非公开信息。  

#### 1.1.3 价值投资与市场效率假说的关系  
价值投资假设市场存在非效率性，认为可以通过基本面分析找到被低估的资产。而市场效率假说则认为市场能够迅速反映所有信息，使套利机会消失。两者的矛盾在于，如果市场是强有效的，价值投资策略可能失效。

### 1.2 本书的研究意义与目标

#### 1.2.1 研究价值投资与市场效率假说的重要性  
探讨两者关系有助于投资者理解在不同市场条件下，价值投资策略的适用性和效果。

#### 1.2.2 本书的目标读者

## 第2章：价值投资的理论基础

### 2.1 价值投资的核心概念

#### 2.1.1 价值投资的起源与发展  
价值投资由本杰明·格雷厄姆和戴维·多德提出，强调以低于内在价值的价格买入股票。  

#### 2.1.2 价值投资的核心原则  
1. **安全边际**：买入价格低于内在价值。  
2. **长期持有**：避免频繁交易，降低交易成本。  
3. **基本面分析**：关注企业的盈利能力、财务状况和行业地位。  

#### 2.1.3 价值投资与市场效率假说的联系  
如果市场是强有效的，价值投资可能难以找到被低估的资产。但现实中，市场可能存在短期非效率性，为价值投资提供机会。

## 第3章：市场效率假说的理论基础

### 3.1 市场效率假说的核心概念

#### 3.1.1 市场效率的定义与分类  
市场效率假说认为，资产价格反映了所有相关信息。分类包括弱有效、半强有效和强有效市场。  

#### 3.1.2 市场效率假说的假设条件  
1. 市场参与者理性。  
2. 信息传播迅速且成本低。  
3. 不存在交易摩擦。  

#### 3.1.3 市场效率与价值投资的冲突  
市场效率假说认为市场难以被战胜，而价值投资认为可以通过发现价格偏差获利。

## 第5章：算法原理：CAPM模型的应用

### 5.1 CAPM模型的原理

#### 5.1.1 CAPM模型的定义  
CAPM（资本资产定价模型）用于计算资产的预期收益，公式为：  
$$ E(R_i) = R_f + \beta_i (R_m - R_f) $$  
其中，$R_f$ 是无风险利率，$\beta_i$ 是资产的贝塔系数，$R_m$ 是市场预期收益率。

#### 5.1.2 CAPM模型的应用场景  
CAPM适用于评估资产的预期收益，帮助投资者在有效市场中进行定价。

### 5.2 CAPM模型的实现

#### 5.2.1 Python代码实现  
以下是计算CAPM模型的Python代码示例：

```python
def calculate_expected_return(risk_free_rate, beta, market_return, market_risk_premium):
    return risk_free_rate + beta * (market_return - risk_free_rate)

# 示例参数
risk_free_rate = 0.05
beta = 1.2
market_return = 0.10
market_risk_premium = 0.05

expected_return = calculate_expected_return(risk_free_rate, beta, market_return, market_risk_premium)
print(f"Expected Return: {expected_return:.2f}")
```

#### 5.2.2 CAPM模型的公式推导  
CAPM模型的推导基于以下假设：  
1. 投资者可以以无风险利率借入资金。  
2. 资产的风险由贝塔系数衡量。  
3. 市场是半强有效的，价格反映所有公开信息。

### 7.2 核心代码实现

#### 7.2.1 资产分析代码  
以下是资产分析的Python代码示例：

```python
import pandas as pd
import numpy as np

def analyze_asset(asset_data, market_data):
    asset_data = pd.DataFrame(asset_data)
    market_data = pd.DataFrame(market_data)
    # 计算资产收益
    asset_returns = asset_data['price'].pct_change().dropna()
    market_returns = market_data['price'].pct_change().dropna()
    # 计算贝塔系数
    beta = np.cov(asset_returns, market_returns)[0,1] / np.var(market_returns)
    return beta

# 示例数据
asset_data = [{'price': 100}, {'price': 105}, {'price': 110}]
market_data = [{'price': 100}, {'price': 102}, {'price': 104}]

beta = analyze_asset(asset_data, market_data)
print(f"Beta: {beta:.2f}")
```
