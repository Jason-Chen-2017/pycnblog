## 第1章: 防御型投资的背景与核心概念

### 1.1 防御型投资的背景介绍

#### 1.1.1 投资市场的基本问题背景
投资市场的核心问题在于如何在不确定性和波动性中实现资产的保值与增值。格雷厄姆的防御型投资策略正是为了解决这一问题而提出的，它强调通过基本面分析和安全边际来降低投资风险。

#### 1.1.2 防御型投资的定义与核心问题描述
防御型投资是一种以稳健性和风险控制为核心的投资策略，旨在通过选择具有安全边际、低市盈率和低市净率的股票，构建一个能够在市场波动中稳定增长的投资组合。

#### 1.1.3 防御型投资的目标与解决方法
- **目标**：实现资产的长期稳健增长，避免重大损失。
- **解决方法**：通过价值评估和风险控制，选择具有安全边际的股票进行投资。

#### 1.1.4 防御型投资的边界与外延
防御型投资的边界在于其稳健性和低风险特性，而其外延则包括各种稳健型投资策略。

#### 1.1.5 防御型投资的核心要素组成
- **安全边际**：市场价格低于内在价值。
- **低市盈率**：市盈率低于行业平均水平。
- **低市净率**：市净率低于行业平均水平。
- **稳定股息**：公司具有持续支付稳定股息的能力。

### 1.2 防御型投资与其他投资策略的对比

#### 1.2.1 主流投资策略的分类
- **价值投资**：以低于内在价值的价格买入优质股票。
- **成长投资**：投资于具有高增长潜力的公司。
- **指数投资**：通过投资指数基金实现市场平均收益。
- **短期交易**：通过高频交易获利。

#### 1.2.2 防御型投资与进攻型投资的区别
- **进攻型投资**：高风险、高回报，注重短期收益。
- **防御型投资**：低风险、稳健回报，注重长期价值。

#### 1.2.3 防御型投资与其他稳健型策略的联系
- 防御型投资与指数投资的联系：两者都注重稳健收益，但防御型投资更注重个股选择。
- 防御型投资与债券投资的联系：两者都注重风险控制，但防御型投资更具灵活性。

## 第2章: 防御型投资的核心概念与联系

### 2.1 防御型投资的核心概念原理

#### 2.1.1 安全边际的数学模型
$$ 安全边际 = \frac{内在价值 - 市场价格}{市场价格} $$

#### 2.1.2 低市盈率与低市净率的特征对比
- **低市盈率**：市盈率低于行业平均水平，意味着股票价格被低估。
- **低市净率**：市净率低于行业平均水平，意味着股票价格相对于资产价值被低估。

#### 2.1.3 防御型投资的组合优化原理
通过组合优化，降低投资组合的整体风险，同时最大化收益。

### 2.2 核心概念的属性特征对比

| 概念       | 特性                     |
|------------|--------------------------|
| 安全边际   | 投资价格低于内在价值     |
| 低市盈率   | 估值低于行业平均水平     |
| 低市净率   | 资产价值高于市场定价     |
| 稳定股息   | 持续稳定的股息支付能力   |

### 3.3 算法实现代码

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(data):
    return data['净利润'] * 20  # 示例计算方式

def calculate_margin_of_safety(data):
    intrinsic_value = calculate_intrinsic_value(data)
    market_price = data['股价']
    margin_of_safety = (intrinsic_value - market_price) / market_price
    return margin_of_safety

# 示例数据
data = {
    '股价': [100, 200, 300],
    '净利润': [50, 100, 150]
}

df = pd.DataFrame(data)
margin_of_safety = calculate_margin_of_safety(df)
print("安全边际:", margin_of_safety)
```

#### 5.2.3 筛选代码

```python
def filter_defensive_stocks(data):
    # 计算市盈率
    pe = data['净利润'] / data['股价']
    # 计算市净率
    pb = data['股价'] / data['每股净资产']
    # 筛选市盈率低于行业平均水平的股票
    low_pe_stocks = pe[pe < pe.mean()].index
    # 筛选市净率低于行业平均水平的股票
    low_pb_stocks = pb[pb < pb.mean()].index
    # 返回同时满足两个条件的股票
    return low_pe_stocks.intersection(low_pb_stocks)
```

### A. 术语表

- **内在价值**：股票的真实价值，基于公司的基本面数据计算得出。
- **安全边际**：市场价格低于内在价值的部分，用于降低投资风险。
- **市盈率**：股价除以每股收益，用于衡量股票的估值水平。
- **市净率**：股价除以每股净资产，用于衡量股票的资产价值。
