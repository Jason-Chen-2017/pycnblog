## 第3章：算法原理

### 3.1 巴菲特银行业投资的数学模型
- 3.1.1 净息差（NIM）计算公式：
  $$ NIM = (贷款平均利率 - 存款平均利率) \times 贷款平均余额 $$
- 3.1.2 股东权益回报率（ROE）计算公式：
  $$ ROE = \frac{净利润}{股东权益} $$

### 3.2 银行风险评估的算法实现
- 3.2.1 信用评分模型（如FICO评分）：
  ```python
  def credit_score(loan_amount, term, interest_rate, credit_history):
      # 简化版信用评分模型
      score = 0
      if credit_history['逾期记录'] > 30天:
          score += 20
      if loan_amount > 100万:
          score += 15
      return score
  ```
- 3.2.2 风险调整后的资本回报率（RAROC）：
  $$ RAROC = \frac{净利润 - 风险调整成本}{资本使用} $$
