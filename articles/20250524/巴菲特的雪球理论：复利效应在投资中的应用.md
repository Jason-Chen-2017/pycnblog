### 第1章：雪球理论的起源与核心思想

#### 1.1 巴菲特雪球理论的起源

#### 1.2 雪球理论的核心理念
雪球理论的核心理念是通过选择具有竞争优势的企业进行长期投资，利用复利效应实现财富的指数级增长。巴菲特认为，投资的本质是寻找那些具有持续竞争优势、良好管理和合理估值的企业，并长期持有它们的股票，从而获得复利带来的收益。

#### 1.3 雪球理论与其他投资理论的区别
雪球理论与其他投资理论（如价值投资、成长投资）的区别在于其对复利效应的高度重视。雪球理论不仅关注企业的内在价值，还强调通过时间的积累，让价值不断增长，从而实现财富的雪球效应。

### 第3章：复利效应的数学模型

#### 3.1 复利的定义与公式
复利是指在一定时间段内，将收益再投资，从而产生更多的收益。复利的公式可以表示为：
$$ A = P \times (1 + r)^n $$
其中：
- \( P \) 是初始本金。
- \( r \) 是年化收益率。
- \( n \) 是投资的时间长度（年）。

#### 3.3 复利的几何级数增长
复利的几何级数增长可以用以下公式表示：
$$ A = P \times (1 + r)^n $$
这种增长方式意味着，随着时间的推移，财富增长的速度会越来越快。

雪球效应的算法流程可以表示为：

2. 输入年化收益率 \( r \)。
3. 输入投资时间长度 \( n \)。
4. 计算最终财富值 \( A = P \times (1 + r)^n \)。

以下是一个简单的Python代码示例，用于计算雪球效应下的最终财富值：

```python

    amount = principal * (1 + rate) ** years
```

#### 6.2 核心实现源代码
以下是一个完整的Python代码示例：

```python
def compound_interest(principal, rate, years):
    if principal <= 0:
        raise ValueError("本金不能为零或负数")
    if rate < 0:
        raise ValueError("收益率不能为负数")
    if years <= 0:
        raise ValueError("投资时间不能为零或负数")
    amount = principal * (1 + rate) ** years
    return amount

# 用户输入
P = float(input("请输入初始本金（元）："))
r = float(input("请输入年化收益率（如0.07）："))
n = int(input("请输入投资时间（年）："))

try:
    result = compound_interest(P, r, n)
    print(f"最终财富值为：{result:.2f} 元")
except ValueError as e:
    print(e)
```
