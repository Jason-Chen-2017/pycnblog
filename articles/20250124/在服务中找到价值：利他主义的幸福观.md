```python
from flask import Flask, request, jsonify
import pandas as pd
import mermaid

app = Flask(__name__)

# 假设的数据库，用于存储客户需求和反馈
customer_data = pd.DataFrame(columns=['id', 'name', 'demand', 'satisfaction'])

@app.route('/submit_demand', methods=['POST'])
def submit_demand():
    data = request.json
    customer_id = data['id']
    customer_name = data['name']
    customer_demand = data['demand']
    
    # 存储客户需求
    customer_data = customer_data.append({'id': customer_id, 'name': customer_name, 'demand': customer_demand, 'satisfaction': 0}, ignore_index=True)
    
    # 分析需求并给出建议
    suggestion = analyze_demand(customer_demand)
    
    return jsonify({'suggestion': suggestion})

@app.route('/get_feedback', methods=['GET'])
def get_feedback():
    customer_id = request.args.get('id')
    satisfaction = request.args.get('satisfaction')
    
    # 更新满意度
    customer_data.loc[customer_data['id'] == customer_id, 'satisfaction'] = satisfaction
    
    return jsonify({'status': 'success'})

# 需求分析函数
def analyze_demand(demand):
    if ' customization' in demand:
        return 'Offer personalized service'
    else:
        return 'Provide standard service'

if __name__ == '__main__':
    app.run(debug=True)
```

#### 代码应用解读与分析

1. **提交需求**：通过`/submit_demand`接口，客户可以提交需求。需求以JSON格式发送，包含客户ID、姓名和需求描述。系统会将需求存储在`customer_data`数据框中。

2. **需求分析**：系统根据客户的需求进行分析，并给出相应的建议。在这里，我们简单地将需求中的“customization”关键字作为个性化服务的判断依据。

3. **获取反馈**：通过`/get_feedback`接口，客户可以提供满意度反馈。系统会将反馈存储在数据框中，用于后续分析和优化。
