- **流程图**：
  ```mermaid

  E --> F[打印完成]
  F --> G[后处理]
  G --> H[成品输出]
  ```


  ```mermaid
  graph TD
  A[设计模型] --> B[导入雕刻软件]
  B --> C[细节雕刻]

  D --> E[导出雕刻数据]

  ```
