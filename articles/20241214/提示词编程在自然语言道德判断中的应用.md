## Step 3: 核心概念与联系

### 提示词编程

#### 概念原理

提示词编程是指利用预训练模型和提示词，生成符合预期的回答。预训练模型在大规模语料库上进行预训练，学习到了丰富的语言知识和模式。通过提示词，可以引导模型生成与特定问题相关的回答。

#### 属性特征对比表格

| 特征         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| 提示性       | 提示词引导回答的方向和内容。                                 |
| 自动化       | 提高道德判断的效率。                                         |
| 智能化       | 利用深度学习技术，实现对复杂语境的理解和判断。                 |

#### 大模型

##### 概念原理

大模型是指具有大规模参数和网络结构的神经网络模型，能够处理复杂的自然语言任务。通过大规模数据的训练，大模型能够学习到丰富的语言知识和模式，具备较强的语义理解能力。

##### 属性特征对比表格

| 特征         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| 规模大       | 参数和层数较多，能够处理复杂的语言现象。                       |
| 自适应       | 通过不断学习，能够适应不同的语言环境和应用场景。                 |
| 强泛化性     | 能够在多个领域和任务中表现出优秀的性能。                         |

#### 自然语言道德判断

##### 概念原理

自然语言道德判断是指对文本内容进行伦理和道德上的评估。通过分析文本的语义和上下文，判断其是否符合道德规范和伦理原则。

##### 属性特征对比表格

| 特征         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |

def call_model(prompt):

1. **预处理文本**：对输入文本进行清洗，去除无效字符和停用词，提高模型对文本的理解能力。

3. **调用预训练模型**：使用预训练模型对提示词进行编码，并进行预测。
4. **输出结果**：根据模型预测结果，输出道德判断结果。
