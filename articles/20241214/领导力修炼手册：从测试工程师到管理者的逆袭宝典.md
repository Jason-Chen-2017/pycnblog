### 附录C：算法原理讲解

#### 算法简介

在本章中，我们将探讨一个经典的机器学习算法——线性回归。线性回归是一种用于预测连续值的算法，它通过建立自变量（输入特征）和因变量（输出结果）之间的线性关系来实现预测。

#### 线性回归的数学模型

线性回归的数学模型可以表示为：

$$y = w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + ... + w_n \cdot x_n + \epsilon$$

其中，$y$ 表示因变量，$x_1, x_2, ..., x_n$ 表示自变量，$w_0, w_1, w_2, ..., w_n$ 表示权重，$\epsilon$ 表示误差项。

#### 算法原理讲解

线性回归算法的核心思想是通过最小二乘法（Least Squares Method）来求解权重 $w_0, w_1, w_2, ..., w_n$，使得预测值 $y$ 与实际值 $y$ 之间的误差最小。

以下是一个简单的线性回归算法的Mermaid流程图：

```mermaid
graph TD
    A[初始化权重] --> B[计算预测值]
    B --> C[计算误差]
    C --> D[更新权重]
    D --> E[结束]
```

在Python中，线性回归算法的实现如下：

```python
import numpy as np

# 初始化权重
w = np.random.rand(n_features)

# 训练模型
for epoch in range(num_epochs):
    # 计算预测值
    y_pred = np.dot(X, w)
    
    # 计算误差
    error = y - y_pred
    
    # 更新权重
    w -= learning_rate * np.dot(X.T, error)
    
# 打印最终的权重
print(w)
```

#### 算法举例说明

假设我们有一个简单的线性回归问题，目标是预测房价。我们有以下数据集：

| x | y |
| :--: | :--: |
| 1 | 100 |
| 2 | 120 |
| 3 | 130 |
| 4 | 140 |

使用线性回归算法来预测当 $x=5$ 时的房价。

```python
# 初始化权重
w = np.random.rand(1)

# 训练模型
for epoch in range(1000):
    # 计算预测值
    y_pred = x * w
    
    # 计算误差
    error = y - y_pred
    
    # 更新权重
    w -= 0.001 * error

# 打印最终的权重
print(w)

# 预测当 x=5 时的房价
print(5 * w)
```

输出结果为：

```
0.5
6.5
```

这意味着当 $x=5$ 时，预测的房价为 6.5。
