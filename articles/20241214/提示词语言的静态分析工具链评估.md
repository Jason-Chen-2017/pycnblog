#### 2.1.2 语义分析器

语义分析器负责分析AST，并检查代码的语义正确性。我们可以实现一个简单的语义分析器，用于检查变量是否被使用。

```python
def analyze_semantics(node):
    used_variables = set()
    visit(node, used_variables)

def visit(node, used_variables):
    if isinstance(node, ast.Name):
        used_variables.add(node.id)
    elif isinstance(node, ast.Assign):
        for target in node.targets:
            visit(target, used_variables)
    elif isinstance(node, ast.Expr):
        visit(node.value, used_variables)

ast_node = parse_source(source_code)
analyze_semantics(ast_node)
```

#### 2.1.3 检查器

检查器根据预定义的规则对代码进行检查，并报告潜在的问题。我们可以实现一个简单的检查器，用于检查未使用的变量。

```python
def check_code(node, used_variables):
    unused_variables = used_variables - set(vars())
    if unused_variables:
        print("未使用的变量：", unused_variables)

check_code(ast_node, used_variables)
```

#### 2.1.4 优化器

优化器对代码进行优化，以提高性能和可读性。我们可以实现一个简单的优化器，用于移除未使用的变量。

```python
def optimize_code(node):
    if isinstance(node, ast.Assign):
        for target in node.targets:
            if target.id not in used_variables:
                node.targets.remove(target)
    elif isinstance(node, ast.Expr):
        if node.value.id not in used_variables:
            node.value = None

optimize_code(ast_node)
```
