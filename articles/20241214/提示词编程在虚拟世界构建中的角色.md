##### 2.2.1.1 自然语言处理

- **分词**：将自然语言文本分割成单词或短语。例如，将“我想要一杯咖啡”分割成“我”、“想要”、“一杯”、“咖啡”。
- **词性标注**：为文本中的每个单词标注其词性，如名词、动词、形容词等。例如，将“一杯咖啡”中的“一杯”标注为量词，“咖啡”标注为名词。

- **语义理解**：理解文本的深层含义，包括语义关系和意图。例如，理解“我想要一杯咖啡”的意图是请求一杯咖啡。

任务分解是将复杂的自然语言描述分解为一系列简单、可执行的步骤。在提示词编程中，任务分解有助于将自然语言指令转化为计算机可以理解和执行的代码。

- **分解步骤**：将自然语言描述分解为一系列具体的操作。例如，将“我想要一杯咖啡”分解为以下步骤：
  1. 找到咖啡机。
  2. 添加咖啡粉。
  3. 加入热水。
  4. 倒入杯中。
- **逻辑处理**：处理步骤之间的逻辑关系，确保执行顺序正确。例如，在上面的例子中，必须先添加咖啡粉，再加入热水。
- **参数传递**：为每个步骤传递所需的参数。例如，在“加入热水”这个步骤中，需要传递热水温度作为参数。

- **执行**：根据任务步骤执行相应的操作。例如，根据步骤执行以下操作：

  2. 添加咖啡粉。
  3. 加入热水。
  4. 倒入杯中。
- **反馈**：提供任务执行的结果和状态信息。例如，反馈以下信息：

   ```python
   import numpy as np

   class GameLogic:
       def __init__(self, screen):
           self.screen = screen
           self.player = pygame.image.load("assets/characters/player.png")
           self.player_rect = self.player.get_rect()
           self.player_rect.center = (400, 300)

           self.velocity = np.array([0, 0])

       def update(self):
           keys = pygame.key.get_pressed()
           if keys[pygame.K_LEFT]:
               self.velocity[0] -= 2
           if keys[pygame.K_RIGHT]:
               self.velocity[0] += 2
           if keys[pygame.K_UP]:
               self.velocity[1] -= 2
           if keys[pygame.K_DOWN]:
               self.velocity[1] += 2

           self.player_rect.move_ip(self.velocity)

           # 碰撞检测
           if self.player_rect.left < 0 or self.player_rect.right > self.screen.get_width():
               self.velocity[0] *= -1
           if self.player_rect.top < 0 or self.player_rect.bottom > self.screen.get_height():
               self.velocity[1] *= -1

           self.screen.blit(self.player, self.player_rect)

       def draw(self):
           self.screen.fill((255, 255, 255))
           self.update()
           pygame.display.flip()
   ```
