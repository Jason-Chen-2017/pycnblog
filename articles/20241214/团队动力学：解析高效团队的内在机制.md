#### Python源代码

接下来，我们提供一个Python源代码示例，用于计算团队凝聚力指数。该示例包括输入团队成员角色和职责，计算凝聚力指数，并输出结果。

```python
import numpy as np

def calculate_cohesion(team_members):
    # 初始化团队凝聚力指数
    cohesion_index = 0
    
    # 计算团队凝聚力指数
    for i in range(len(team_members)):
        for j in range(i + 1, len(team_members)):
            cohesion_index += np.dot(team_members[i], team_members[j])
            
    cohesion_index /= (len(team_members) * (len(team_members) - 1))
    
    return cohesion_index

# 示例团队成员数据
team_members = [
    [0.5, 0.3, 0.2],  # 成员1的职责分配
    [0.4, 0.4, 0.2],  # 成员2的职责分配
    [0.3, 0.4, 0.3],  # 成员3的职责分配
]

# 计算团队凝聚力指数
cohesion_index = calculate_cohesion(team_members)

print(f"团队凝聚力指数: {cohesion_index}")
```

在这个示例中，我们定义了一个函数`calculate_cohesion`，用于计算团队凝聚力指数。该函数通过嵌套循环计算每个成员职责向量之间的内积，并计算平均值。最后，我们使用一个示例数据集来测试该函数。
