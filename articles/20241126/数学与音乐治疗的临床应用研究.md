#### 1.2.2 数学公式在音乐创作中的运用

数学公式在音乐创作中也有广泛应用。例如，五度循环公式可以帮助音乐家创作出和谐优美的音乐作品。

**五度循环公式：**

$$
f_n = f_0 \cdot \phi^n
$$

其中，$f_n$ 是第 $n$ 个音符的频率，$f_0$ 是起始音符的频率，$\phi$ 是黄金分割比例（约等于 1.618）。

例如，如果我们选择 C（261.63 Hz）作为起始音符，那么可以通过五度循环公式来计算其他音符的频率：

```python
f_0 = 261.63  # C 的频率
phi = 1.618   # 黄金分割比例

# 计算其他音符的频率
f_1 = f_0 * phi**1
f_2 = f_0 * phi**2
f_3 = f_0 * phi**3
f_4 = f_0 * phi**4

print("C:", f_0)
print("D:", f_1)
print("E:", f_2)
print("F#", f_3)
print("G#", f_4)
```

输出结果：

```
C: 261.63
D: 352.44
E: 466.22
F#: 618.29
G#: 816.42
```

通过这种方式，我们可以使用数学公式来创作音乐作品，从而实现音乐创作的自动化。
