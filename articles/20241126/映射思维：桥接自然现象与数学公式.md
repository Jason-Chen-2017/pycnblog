自然现象是指自然界中发生的各种现象，如地震、台风、气候变化等。这些现象具有以下基本特征：

### 2.1 时间序列数据的映射

时间序列数据是指在一定时间间隔内收集的数据。这些数据可以通过数学公式进行映射，例如：

$$z = f(x, y)$$

其中，$z$ 表示空间数据在点 $(x, y)$ 的值，$f(x, y)$ 表示与空间数据相关的函数。这个公式描述了空间数据与其相关变量之间的关系。

### 2.3 随机过程与概率分布的映射

随机过程是指在一定时间内随机变化的过程。概率分布是描述随机变量取值的概率分布情况。这些概念可以通过映射思维进行关联：

1. **随机过程映射**：将随机过程的时间序列数据与概率分布进行关联。
2. **概率分布映射**：将随机过程的概率分布与数学公式进行关联。

例如，假设随机过程 $X_t$ 的概率分布服从正态分布，可以用以下公式描述：

$$P(X_t \leq x) = \int_{-\infty}^{x} \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} dx$$

其中，$X_t$ 表示随机过程在时间 $t$ 的值，$\mu$ 和 $\sigma^2$ 分别为正态分布的均值和方差。

# 假设我们有以下历史气温数据
historical_temps = [18.2, 17.9, 16.5, 15.3, 14.1, 13.7, 14.5, 16.0, 17.8, 18.6]

alpha = np.polyfit(t, historical_temps, 1)[0]
beta = np.polyfit(t, historical_temps, 1)[1]

# 预测未来值
future_temps = alpha * t + beta
predicted_temp = future_temps[-1]  # 预测最后一天的气温

# 可视化结果
plt.figure(figsize=(10, 6))
plt.plot(t, historical_temps, 'o-', label='历史气温')

plt.ylabel('气温 (°C)')

plt.grid(True)
plt.legend()
plt.show()
print(f"预测的最后一天气温为：{predicted_temp}°C")
