## 3. 核心算法原理讲解

在这一部分，我们可以使用Python源代码来详细阐述推理性能监控的核心算法原理。

```python
import time

def inference_performance_monitoring(model, input_data):
    inference_times = []
    for data in input_data:
        start_time = time.time()
        model.inference(data)
        end_time = time.time()
        inference_times.append(end_time - start_time)
    return inference_times

# 示例
input_data = ["What is the capital of France?", "How old is the Eiffel Tower?"]
model = load_model()  # 假设load_model()函数用于加载预训练的模型
inference_times = inference_performance_monitoring(model, input_data)
print("Inference times:", inference_times)
```

**数学模型和公式：**
- 平均推理时间：$$\bar{t} = \frac{1}{n} \sum_{i=1}^{n} t_i$$，其中$$t_i$$是第i次推理的时间。
- 推理准确性：$$accuracy = \frac{correct_predictions}{total_predictions}$$，其中$$correct_predictions$$是正确预测的次数，$$total_predictions$$是总预测次数。

**通俗易懂的举例说明：**
- 假设我们有一个模型，需要回答两个问题。我们运行模型两次，每次测量推理时间。然后，我们可以计算平均推理时间，并评估模型输出的准确性。
