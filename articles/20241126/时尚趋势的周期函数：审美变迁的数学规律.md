## 周期函数基础

### 周期函数的概念

周期函数是指那些在一定区间内重复其值和形状的函数。在数学中，周期函数通常表示为 $f(x) = f(x + T)$，其中 $T$ 是周期。这意味着如果在一个周期内，函数的输出是固定的，那么这个函数就具有周期性。

### 常见周期函数

常见的周期函数包括正弦函数、余弦函数和正切函数。这些函数在数学和物理学中有着广泛的应用。

- **正弦函数（sin(x))**：正弦函数是最基本的周期函数之一，其周期为 $2\pi$。它描述了在单位圆上的角度和对应的y值之间的关系。

- **余弦函数（cos(x))**：余弦函数与正弦函数类似，但相位差为 $\pi/2$。它的周期也为 $2\pi$，描述了单位圆上角度和对应y值的另一部分。

- **正切函数（tan(x))**：正切函数是正弦函数和余弦函数的比值，其周期为 $\pi$。它通常用于描述角度的变化率。

### 周期函数的数学性质

周期函数具有以下数学性质：

- **周期性**：周期函数的输出在每一个周期内重复。
- **奇偶性**：正弦函数是奇函数，余弦函数是偶函数，正切函数是奇函数。
- **幅值和相位**：可以通过幅值和相位来调整周期函数的形状和位置。

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.optimize import minimize

# 数据预处理
def preprocess_data(data):
    # 数据清洗和缺失值填充
    data = data.dropna()
    # 数据标准化
    data['value'] = (data['value'] - data['value'].mean()) / data['value'].std()
    return data

# 数据拟合
def fit_model(data, T, initial_params):
    def loss_function(params):
        amplitude, phase = params
        predictions = sine_wave(data['year'], T, amplitude, phase)
        return np.mean((predictions - data['value'])**2)
    result = minimize(loss_function, initial_params, args=(data,))
    return result.x

# 正弦函数
def sine_wave(x, T, amplitude, phase):
    return amplitude * np.sin(2 * np.pi * x / T + phase)

# 主函数
def main():
    # 加载数据
    data = pd.read_csv('fashion_data.csv')
    # 数据预处理
    data = preprocess_data(data)
    # 特征提取
    T = data['year'] - data['year'][0]
    # 参数调优
    initial_params = [1, 0]
    params = fit_model(data, T, initial_params)
    # 预测
    future_years = np.arange(data['year'].iloc[-1] + 1, data['year'].iloc[-1] + 10)
    predictions = sine_wave(future_years, T, *params)
    # 可视化
    plt.plot(data['year'], data['value'], label='Actual')
    plt.plot(future_years, predictions, label='Predicted')
    plt.xlabel('Year')
