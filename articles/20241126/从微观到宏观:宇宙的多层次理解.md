- **夸克**：它们是构成原子核的基本单元，共有六种类型。

- **轻子**：它们是构成原子的基本单元，共有三种类型。

#### 2.4 弱相互作用与轻子

弱相互作用是四种基本相互作用之一，它主要作用于轻子。弱相互作用使得轻子之间发生相互作用，从而实现粒子的转换。

    // H0：哈勃常数

##### 源代码实现

```python
import numpy as np

def hubble_parameter(H0, z):
    a = 1 / (1 + z)
    H = H0 / np.sqrt(a)
    return H

H0 = 100  # 哈勃常数为100 km/s/Mpc
z = 0.5  # 初始红移值

H = hubble_parameter(H0, z)
print("在红移z={:.2f}处的哈勃参数为: {:.2f} km/s/Mpc".format(z, H))
```

#### 代码解读与分析

- `hubble_parameter` 函数接收两个参数：$H_0$（哈勃常数）和$z$（红移值）。
- 根据宇宙膨胀模型，计算尺度因子$a = \frac{1}{1+z}$。
- 使用哈勃常数和尺度因子计算哈勃参数$H = \frac{H_0}{\sqrt{a}}$。
- 返回计算得到的哈勃参数$H$。

#### 实际案例分析与详细讲解剖析

假设我们有一个星系，其红移值为$z = 0.5$，我们需要计算该星系的哈勃参数。

1. **计算尺度因子**：

$$
a = \frac{1}{1+z} = \frac{1}{1+0.5} = 0.67
$$

2. **计算哈勃参数**：

$$
H = \frac{H_0}{\sqrt{a}} = \frac{100}{\sqrt{0.67}} \approx 148.64 \text{ km/s/Mpc}
$$

因此，在红移值为$z = 0.5$的星系的哈勃参数约为$148.64$ km/s/Mpc。
