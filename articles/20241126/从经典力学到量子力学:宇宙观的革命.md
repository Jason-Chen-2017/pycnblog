## 经典力学基础

经典力学，又称牛顿力学，是描述宏观物体运动的物理学分支。其核心在于牛顿三大定律和万有引力定律。

### 牛顿三大定律

1. **第一定律（惯性定律）**：一个物体如果没有受到外力，将保持静止或匀速直线运动。
2. **第二定律（动力定律）**：一个物体的加速度与作用在它上面的外力成正比，与它的质量成反比，方向与外力方向相同。数学表达式为 $F=ma$。
3. **第三定律（作用-反作用定律）**：任何作用力都有一个大小相等、方向相反的反作用力。

### 万有引力定律

万有引力定律描述了两个物体之间的引力与它们的质量和距离的关系。公式为 $F = G\frac{m_1m_2}{r^2}$，其中 $G$ 是万有引力常数。

经典力学在宇宙中的应用非常广泛，如描述行星运动、行星轨道计算、天体力学等。然而，随着科学的发展，人们发现经典力学在描述微观粒子和高速运动现象时存在明显的局限性。

### 经典力学的局限性

经典力学的局限性主要体现在以下几个方面：

1. **微观粒子**：经典力学无法解释电子、光子等微观粒子的行为。例如，电子在原子核周围的运动无法用经典力学的轨道理论解释。
2. **高速运动**：经典力学无法准确描述物体在接近光速时的运动状态。当物体速度接近光速时，经典力学的预测与实际观测结果存在巨大偏差。

这些局限性促使科学家们探索新的理论，以更好地描述自然界的基本规律。量子力学应运而生，成为现代物理学的重要基石。

## 量子力学基础

量子力学是描述微观世界行为的物理学分支。与经典力学不同，量子力学提出了全新的概念和原理，如波粒二象性、算符与测量、状态叠加与纠缠。

### 波粒二象性

波粒二象性是量子力学中最基本的概念之一。它指出微观粒子既具有波动性又具有粒子性。

1. **波动性**：微观粒子可以像波一样传播，其波动性质由波函数描述。波函数的平方给出了粒子在某一位置出现的概率。
2. **粒子性**：微观粒子在特定时刻表现出粒子性，如电子在光电效应中的表现。

### 算符与测量

在量子力学中，算符用于描述物理量的变化。测量一个物理量，实际上就是对该物理量进行算符作用，并观察其结果。

1. **算符的定义**：算符是线性变换，将波函数映射到另一个波函数。
2. **测量的结果**：测量结果是一个概率分布，取决于波函数的形态。

### 状态叠加与纠缠

量子力学中，一个量子系统可以处于多个状态的叠加。此外，量子力学中存在一种特殊的现象——纠缠。

1. **状态叠加**：一个量子系统可以同时处于多个状态的叠加，如 $|\psi\rangle = c_1|\psi_1\rangle + c_2|\psi_2\rangle$。
2. **纠缠**：两个或多个量子系统可以形成纠缠态，其中一个系统的状态与另一个系统的状态紧密相关。

这些核心概念构成了量子力学的基本框架，使得科学家能够更好地理解微观世界的本质。

### Python 源代码

```python
# 波粒二象性示例
import numpy as np
import matplotlib.pyplot as plt

# 定义波函数
psi = np.sin(np.linspace(0, 2 * np.pi, 1000))

# 绘制波函数
plt.plot(psi)
plt.xlabel('位置')
plt.ylabel('波函数')
plt.title('波粒二象性示例')
plt.show()

# 算符与测量示例
psi_0 = np.array([1/np.sqrt(2), 1/np.sqrt(2)])  # 初始状态
H = np.array([[1, 0], [0, -1]])  # 氢原子哈密顿量

# 测量能量
E = H @ psi_0 @ H.conj().T
E = np.real(E[0, 0])

print(f"测量到的能量：{E}")

# 状态叠加与纠缠示例
psi_plus = (1/np.sqrt(2)) * (np.array([1, 1]))  # 纠缠态
psi_minus = (1/np.sqrt(2)) * (np.array([1, -1]))

# 测量粒子自旋
S_z = np.array([[1, 0], [0, -1]])
spin_plus = S_z @ psi_plus @ S_z.conj().T
spin_minus = S_z @ psi_minus @ S_z.conj().T

# 打印测量结果
print("粒子自旋向上：", spin_plus)
print("粒子自旋向下：", spin_minus)
```
