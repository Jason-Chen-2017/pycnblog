### 图论基础

#### 2.1 图论的基本概念

图论是研究图及其性质和应用的数学分支。在图论中，图由顶点（节点）和边（连接线）组成。顶点和边可以表示现实世界中的各种对象及其关系。

- **顶点**：图中的基本元素，通常表示实体或概念。
- **边**：连接顶点的线段，表示顶点之间的关系或联系。

图可以分为多种类型，包括：

- **无向图**：边没有方向，顶点之间的联系是对称的。
- **有向图**：边具有方向，表示顶点之间的单向联系。

#### 2.2 图的分类与性质

根据不同的标准，图可以分为多种类型。以下是一些常见的图分类：

- **连通图**：任意两个顶点之间都存在路径的图。
- **树**：连通且无环的图，树中的边数等于顶点数减一。
- **网络图**：包含有向边的图，常用于描述复杂的系统。
- **加权图**：顶点和边都赋予权重的图，常用于路径优化等问题。

图的性质包括：

- **连通性**：图中的任意两个顶点之间是否存在路径。
- **路径长度**：从一个顶点到另一个顶点的路径长度，通常用边的数量表示。
- **连通度**：图中任意顶点的最小连通度，即去掉该顶点后图变得不连通的顶点数量。

#### 2.3 图的表示方法

图可以通过多种方式表示，包括：

- **邻接矩阵**：用二维矩阵表示图，矩阵元素表示顶点之间的边或权值。
- **邻接表**：用一维数组表示图，每个数组元素包含一个顶点和与之相连的所有顶点。
- **图形表示**：用图形直观地表示图的结构，常用的图形表示工具包括Mermaid等。

图论在智慧城市中的应用非常广泛，通过图论的方法可以有效地分析城市功能的连接性和交互性，从而优化城市的管理和服务。下一章将介绍城市功能的分类与描述，以及城市功能与图论的联系。

### 核心算法原理与数学模型

#### 4.1 最短路径算法

最短路径算法是图论中的一种重要算法，用于寻找图中两点之间的最短路径。在智慧城市中，最短路径算法可以用于优化交通路线、能源分配和物流调度等问题。以下是几种常用的最短路径算法及其原理。

##### 4.1.1 Dijkstra算法

Dijkstra算法是一种基于优先级的贪心算法，用于求解无权图中两点之间的最短路径。该算法的基本原理如下：

1. 初始化：将所有顶点的距离初始化为无穷大，将起始顶点的距离设为0。
2. 选择未访问顶点中距离最小的顶点，将其标记为已访问。
3. 更新未访问顶点的距离：对于每个未访问的顶点，如果通过已访问顶点到达它的距离小于当前的距离，则更新其距离。
4. 重复步骤2和3，直到所有顶点都被访问。

Dijkstra算法的Python实现如下：

```python
import heapq

def dijkstra(graph, start):
    distances = {vertex: float('infinity') for vertex in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)

        if current_distance > distances[current_vertex]:
            continue

        for neighbor, weight in graph[current_vertex].items():
            distance = current_distance + weight

            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

##### 4.1.2 Bellman-Ford算法

Bellman-Ford算法是一种动态规划算法，可以求解带权图中两点之间的最短路径。与Dijkstra算法不同，Bellman-Ford算法可以处理负权边的存在。该算法的基本原理如下：

1. 初始化：将所有顶点的距离初始化为无穷大，将起始顶点的距离设为0。
2. 松弛操作：对于每条边，如果通过已访问顶点到达目标顶点的距离小于当前的距离，则更新其距离。
3. 重复步骤2，共执行\( V-1 \)次，其中\( V \)是顶点的数量。
4. 检查负权环：如果仍能通过松弛操作更新某个顶点的距离，则说明图中存在负权环。

Bellman-Ford算法的Python实现如下：

```python
def bellman_ford(graph, start):
    distances = {vertex: float('infinity') for vertex in graph}
    distances[start] = 0

    for _ in range(len(graph) - 1):
        for vertex in graph:
            for neighbor, weight in graph[vertex].items():
                if distances[vertex] + weight < distances[neighbor]:
                    distances[neighbor] = distances[vertex] + weight

    for vertex in graph:
        for neighbor, weight in graph[vertex].items():
            if distances[vertex] + weight < distances[neighbor]:
                return "Graph contains a negative weight cycle"

    return distances
```

#### 4.2 最大流算法

最大流算法是图论中的另一个重要算法，用于求解图中两点之间的最大流量。在智慧城市中，最大流算法可以用于优化水资源分配、电力输送和交通流量等问题。以下是几种常用的最大流算法及其原理。

##### 4.2.1 Ford-Fulkerson算法

Ford-Fulkerson算法是一种基于增广路径法的贪心算法，用于求解网络的最大流问题。该算法的基本原理如下：

1. 初始化：设定一个流\( f \)为0。
2. 寻找增广路径：利用广度优先搜索（BFS）或深度优先搜索（DFS）算法，找到从源点到汇点的增广路径。
3. 扩充流量：沿着增广路径，增加流量，使得该路径上的每条边的流量达到其容量限制。
4. 重复步骤2和3，直到无法找到增广路径。

Ford-Fulkerson算法的Python实现如下：

```python
from collections import deque

def bfs(graph, parent, source, sink):
    visited = [False] * len(graph)
    visited[source] = True
    queue = deque([source])

    while queue:
        vertex = queue.popleft()
        for neighbor, capacity in graph[vertex].items():
            if not visited[neighbor] and capacity > 0:
                queue.append(neighbor)
                visited[neighbor] = True
                parent[neighbor] = vertex
                if neighbor == sink:
                    return True

    return False

def ford_fulkerson(graph, source, sink):
    parent = [-1] * len(graph)
    max_flow = 0

    while bfs(graph, parent, source, sink):
        path_flow = float('inf')
        s = sink

        while s != source:
            path_flow = min(path_flow, graph[parent[s]][s])
            s = parent[s]

        max_flow += path_flow
        v = sink

        while v != source:
            u = parent[v]
            graph[u][v] -= path_flow
            graph[v][u] += path_flow
            v = parent[v]

    return max_flow
```

##### 4.2.2 Edmonds-Karp算法

Edmonds-Karp算法是Ford-Fulkerson算法的一个改进版本，利用广度优先搜索（BFS）来寻找增广路径，从而提高算法的效率。该算法的基本原理与Ford-Fulkerson算法相同，但通过使用BFS来优化路径搜索。
