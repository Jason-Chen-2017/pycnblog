## 第2章 数学在艺术中的应用

### 2.1 几何学在艺术中的运用

#### 2.1.1 几何图案设计

几何图案设计是艺术创作中常用的一种形式。利用几何图形的对称性、重复性等特点，艺术家可以创造出具有独特美感的图案。以下是一个简单的Python代码示例，用于生成具有对称性的几何图案。

```python
import matplotlib.pyplot as plt
import numpy as np

# 定义参数
n = 10
size = 5
angle = 45

# 创建图形
fig, ax = plt.subplots()

# 绘制等边三角形
for i in range(n):
    x = size * np.cos(np.pi / 3 * i) * np.cos(np.pi / 180 * angle * i)
    y = size * np.cos(np.pi / 3 * i) * np.sin(np.pi / 180 * angle * i)
    ax.plot(x, y, 'r-')

# 绘制正方形
for i in range(n):
    x = size * np.sin(np.pi / 2 * i) * np.cos(np.pi / 180 * angle * i)
    y = size * np.sin(np.pi / 2 * i) * np.sin(np.pi / 180 * angle * i)
    ax.plot(x, y, 'b-')

# 显示图形
plt.show()
```

上述代码使用Python的matplotlib库绘制了等边三角形和正方形的组合图案，展示了几何图案设计的对称性和规则性。

#### 2.1.2 几何艺术的数学原理

### 2.2 数学中的色彩理论

这个公式表示，任何颜色都可以通过红、绿、蓝三种原色的不同组合来生成。

### 4.1.1 项目背景与目标

项目背景：利用Python和OpenCV库，实现一个基于颜色分割和运动跟踪的艺术创作系统。

目标：通过实时捕捉视频中的颜色和运动，生成动态的艺术图案。

### 4.1.2 项目实施与成果

项目实施：

1. 使用OpenCV库实时捕捉视频帧。
2. 使用颜色分割算法将视频帧分割成不同的颜色区域。
3. 对颜色区域进行运动跟踪，生成动态的图案。

成果展示：

通过Python代码实现了一个动态艺术创作系统，用户可以通过改变颜色参数和运动轨迹来创造不同的艺术效果。

```python
import cv2
import numpy as np

# 初始化视频捕捉器
cap = cv2.VideoCapture(0)

# 循环捕捉视频帧
while True:
    # 捕捉视频帧
    ret, frame = cap.read()
    
    # 转换为HSV颜色空间
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    
    # 定义颜色范围
    lower_red = np.array([0, 50, 50])
    upper_red = np.array([10, 255, 255])
    mask1 = cv2.inRange(hsv, lower_red, upper_red)
    
    lower_blue = np.array([170, 50, 50])
    upper_blue = np.array([180, 255, 255])
    mask2 = cv2.inRange(hsv, lower_blue, upper_blue)
    
    # 合并颜色掩膜
    mask = cv2.add(mask1, mask2)
    
    # 显示掩膜
    cv2.imshow('Mask', mask)
    
    # 按下'q'键退出循环
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

# 释放视频捕捉器
cap.release()
cv2.destroyAllWindows()
```

通过上述代码，我们实现了一个基于颜色分割的视频处理系统，用户可以通过实时捕捉视频中的颜色变化，来创建动态的艺术图案。

import numpy as np
import matplotlib.pyplot as plt

# 定义参数
n = 100
size = 10

# 创建网格
x, y = np.ogrid[-size:size, -size:size]
z = np.cos(x) * np.sin(y)

# 绘制动态图案
fig, ax = plt.subplots()
line, = ax.plot(x, y, 'b-')
line.set_data(x, y)
ax.set_aspect('equal')

def animate(i):
    z = np.cos(x) * np.sin(y + i * 0.05)
    line.set_data(x, z)
    return line,

ani = matplotlib.animation.FuncAnimation(fig, animate, frames=100, interval=50, blit=True)

plt.show()
```
