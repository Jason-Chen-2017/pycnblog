#### 第2章：脑科学基本概念

脑科学是研究大脑的结构与功能、神经系统的发育与疾病、认知与行为等方面的学科。本章将介绍脑科学的基本概念，为后续讨论数学与脑科学的交叉领域研究提供背景知识。

##### 2.1 脑的结构与功能

大脑是人体最重要的器官之一，其结构和功能复杂多样。大脑的基本结构包括大脑皮层、白质、灰质等。大脑的不同区域具有不同的功能，例如：

- **视觉皮层**：负责处理视觉信息。
- **听觉皮层**：负责处理听觉信息。
- **运动皮层**：负责控制身体运动。
- **语言中枢**：负责语言理解和表达。

##### 2.2 脑科学研究的基本方法

脑科学研究的方法多种多样，包括脑成像技术、电生理技术、神经元活动记录等。这些方法为研究大脑的结构与功能提供了有力支持。

- **脑成像技术**：如磁共振成像（MRI）、功能性磁共振成像（fMRI）、正电子发射断层扫描（PET）等，可以非侵入性地观察大脑的结构与功能。
- **电生理技术**：如脑电图（EEG）、事件相关电位（ERP）等，可以直接记录大脑的电活动。
- **神经元活动记录**：如光遗传学、钙成像等，可以直接观察神经元的活动。

# 定义神经元类
class Neuron:
    def __init__(self, weights, biases):
        self.weights = weights
        self.biases = biases
    
    def activation_function(self, x):
        return 1 if x > 0 else 0
    
    def calculate_output(self, inputs):
        return self.activation_function(sum(inputs[i] * self.weights[i] + self.biases[i] for i in range(len(inputs))))

神经编码与解码模型是脑科学研究中的重要方向，旨在理解神经元如何将外部刺激转换为电信号，以及如何将电信号解码为外部刺激。本章将介绍神经编码与解码模型的基本原理，以及如何通过数学方法研究这些过程。

**伪代码：神经编码与解码模型**

# 定义神经编码模型
class NeuralEncodingModel:
    def __init__(self, stimuli, neurons):
        self.stimuli = stimuli
        self.neurons = neurons
    
    def encode(self, stimulus):
        # 将刺激编码为神经元的激活状态
        return [neuron.encode(stimulus) for neuron in self.neurons]
    
    def decode(self, neuron_activities):
        # 将神经元的激活状态解码为刺激
        return self.decode_activities_to_stimuli(neuron_activities)

# 定义神经元类
class Neuron:
    def __init__(self, activation_threshold):
        self.activation_threshold = activation_threshold
    
    def encode(self, stimulus):
        # 判断刺激是否大于激活阈值
        return 1 if stimulus > self.activation_threshold else 0
    
    def decode(self, activity):
        # 将激活状态解码为刺激
        return self.activation_threshold * activity
