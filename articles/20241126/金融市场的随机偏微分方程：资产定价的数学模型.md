### 附录B：Python代码示例

以下是用于求解随机偏微分方程的Python代码示例：

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义随机偏微分方程的参数
mu = 0.1
sigma = 0.2
gamma = 0.05

# 模拟时间步长和总时间
dt = 0.01
T = 1

# 初始化股票价格
S = np.array([100])

# 求解随机偏微分方程
for t in np.arange(0, T, dt):
    Z = np.random.normal(0, 1)
    dZ = np.sqrt(2 * gamma) * dt
    dS = (mu - 0.5 * sigma ** 2) * dt + sigma * dZ
    S = S * np.exp(dS)

# 绘制股票价格路径
plt.plot(S)
plt.xlabel('Time')
plt.ylabel('Stock Price')
plt.title('Stock Price Path')
plt.show()
```
