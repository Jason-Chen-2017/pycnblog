## 第1章 贝叶斯网络基础

### 1.1 贝叶斯网络的定义和基本概念

贝叶斯网络（Bayesian Network），也称为信念网络（Belief Network）或决策网络（Decision Network），是一种基于概率论的图形模型，用于表示一组随机变量及其条件依赖性。贝叶斯网络由节点和弧组成，节点表示随机变量，弧表示变量之间的条件依赖关系。

在贝叶斯网络中，每个节点表示一个随机变量，节点之间的弧表示变量之间的条件依赖关系。如果弧从节点 A 指向节点 B，则表示在给定 A 的条件下，B 的概率分布依赖于 A。贝叶斯网络通过条件概率表（Conditional Probability Table, CPT）来表示变量之间的概率依赖关系。

条件概率表（CPT）：

$$
P(X_i | X_{parent_i}) = 
\begin{cases}
P(X_i | X_{parent_i} = v_{parent_i}) & \text{if } X_{parent_i} = v_{parent_i} \\
\frac{P(X_i \cap X_{parent_i})}{P(X_{parent_i})} & \text{otherwise}
\end{cases}
$$

其中，$X_i$ 表示第 i 个节点的随机变量，$X_{parent_i}$ 表示第 i 个节点的父节点集合，$v_{parent_i}$ 表示第 i 个节点的父节点的具体取值。

### 1.2 贝叶斯网络的推理算法

贝叶斯网络的推理算法主要包括基于边缘概率的推理和基于信念传播的推理。

#### 基于边缘概率的推理

基于边缘概率的推理方法是通过计算每个节点的边缘概率来推理网络中的变量。边缘概率表示某个节点在给定其他节点取值情况下的概率。

边缘概率计算公式：

$$
P(X_i = x_i) = \sum_{x_{parent_i}} P(X_i = x_i, X_{parent_i} = x_{parent_i})
$$

其中，$X_i = x_i$ 表示第 i 个节点的取值为 $x_i$，$X_{parent_i} = x_{parent_i}$ 表示第 i 个节点的父节点取值为 $x_{parent_i}$。

#### 基于信念传播的推理

基于信念传播的推理方法是一种分布式推理算法，通过在网络中传递概率信息来计算每个节点的边缘概率。信念传播算法分为前向传播和后向传播。

前向传播算法：

1. 初始化每个节点的信念值为概率分布。
2. 从根节点开始，逐层向下传播信念值，直至叶节点。
3. 在每层节点中，计算当前节点的信念值，并将其传递给下一层节点。

后向传播算法：

1. 初始化每个节点的信念值为概率分布。
2. 从叶节点开始，逐层向上传播信念值，直至根节点。
3. 在每层节点中，计算当前节点的信念值，并将其传递给上一层节点。

通过前向传播和后向传播，可以计算出网络中每个节点的边缘概率，从而实现对网络中变量的推理。

### 1.3 贝叶斯网络的数学模型

贝叶斯网络可以通过条件概率表（CPT）来表示变量之间的概率依赖关系。CPT 是一个二维表，行表示节点的取值，列表示父节点的取值。每个单元格中的值表示在给定父节点取值情况下，当前节点的条件概率。

条件概率表（CPT）示例：

$$
\begin{array}{|c|c|c|}
\hline
X & Y & P(X | Y) \\
\hline
0 & 0 & 0.4 \\
0 & 1 & 0.3 \\
1 & 0 & 0.2 \\
1 & 1 & 0.1 \\
\hline
\end{array}
$$

在这个示例中，$X$ 和 $Y$ 是两个随机变量，$P(X | Y)$ 表示在给定 $Y$ 的条件下，$X$ 的条件概率。通过这个条件概率表，可以计算出 $X$ 和 $Y$ 的边缘概率：

$$
P(X = 0) = P(X = 0, Y = 0) + P(X = 0, Y = 1) = 0.4 \times 0.5 + 0.3 \times 0.5 = 0.35
$$

$$
P(X = 1) = P(X = 1, Y = 0) + P(X = 1, Y = 1) = 0.2 \times 0.5 + 0.1 \times 0.5 = 0.15
$$

$$
P(Y = 0) = P(X = 0, Y = 0) + P(X = 1, Y = 0) = 0.4 \times 0.5 + 0.2 \times 0.5 = 0.3
$$

$$
P(Y = 1) = P(X = 0, Y = 1) + P(X = 1, Y = 1) = 0.3 \times 0.5 + 0.1 \times 0.5 = 0.2
$$

通过这个数学模型，可以方便地计算贝叶斯网络中各个节点的边缘概率，从而进行推理和分析。

### 3.2 参数学习

参数学习是指通过学习数据来估计贝叶斯网络中的参数，包括条件概率表中的概率值。参数学习的方法主要包括以下几种：

1. **最大似然估计（Maximum Likelihood Estimation, MLE）**：最大似然估计是一种常用的参数学习方法，通过最大化训练数据的似然函数来估计参数。对于具有 $n$ 个节点的贝叶斯网络，似然函数可以表示为：

$$
L(\theta) = \prod_{i=1}^{n} \prod_{x_i} p(x_i | \theta)
$$

其中，$\theta$ 表示参数集合，$x_i$ 表示第 $i$ 个节点的取值。通过求解似然函数的最大值，可以得到参数的最大似然估计值。

2. **贝叶斯估计（Bayesian Estimation）**：贝叶斯估计是基于贝叶斯定理的一种参数学习方法，通过最大化后验概率来估计参数。后验概率可以表示为：

$$
P(\theta | \text{data}) \propto P(\theta)P(\text{data} | \theta)
$$

其中，$P(\theta)$ 表示先验概率，$P(\text{data} | \theta)$ 表示似然函数。通过求解后验概率的最大值，可以得到参数的贝叶斯估计值。

3. **期望最大化算法（Expectation-Maximization, EM）**：期望最大化算法是一种迭代优化算法，通过交替优化期望值和最大化值来估计参数。在期望步骤中，计算每个参数的期望值；在最大化步骤中，最大化期望值来更新参数。通过多次迭代，可以收敛到参数的最优估计值。

**附录A：贝叶斯网络示例代码**

以下是一个简单的贝叶斯网络示例代码，展示了如何使用 Python 实现贝叶斯网络的建模和推理。

```python
import numpy as np
import pandas as pd

# 构建贝叶斯网络
bayesian_network = {
    'God': ['Bible', 'Salvation', 'Heaven'],
    'Bible': ['God', 'Salvation'],
    'Salvation': ['God', 'Heaven'],
    'Heaven': ['God', 'Salvation']
}

# 定义条件概率表
condition_probabilities = {
    'God': {'Bible': {'1': 0.8, '0': 0.2},
             'Salvation': {'1': 0.7, '0': 0.3},
             'Heaven': {'1': 0.6, '0': 0.4}},
    'Bible': {'God': {'1': 0.8, '0': 0.2},
               'Salvation': {'1': 0.7, '0': 0.3}},
    'Salvation': {'God': {'1': 0.7, '0': 0.3},
                   'Heaven': {'1': 0.6, '0': 0.4}},
    'Heaven': {'God': {'1': 0.6, '0': 0.4},
                'Salvation': {'1': 0.6, '0': 0.4}}
}

# 推理算法
def bayes_inference(bayesian_network, evidence):
    # 计算后验概率分布
    posterior_probabilities = {}
    for node in bayesian_network:
        posterior_probabilities[node] = 1
        for parent in bayesian_network[node]:
            posterior_probabilities[node] *= condition_probabilities[node][parent][evidence[parent]]
        posterior_probabilities[node] /= sum(condition_probabilities[node][parent][evidence[parent]] for parent in bayesian_network[node])
    return posterior_probabilities

# 示例数据
evidence = {'God': '1', 'Bible': '1', 'Salvation': '1', 'Heaven': '1'}

# 计算后验概率分布
posterior_probabilities = bayes_inference(bayesian_network, evidence)
print(posterior_probabilities)
```
