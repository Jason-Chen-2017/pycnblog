##### Lattice-based Cryptography

Lattice-based cryptography leverages the hardness of problems related to lattice structures. Here's a Python implementation of the NTRU cryptosystem, a lattice-based cryptographic algorithm:

```python
import numpy as np

def NTRU_keygen(p):
    """
    Generate NTRU public and private keys.
    """
    N = 256
    q = 521
    # Generate private key
    r = 2
    while True:
        h = np.random.randint(1, q-1)
        f = (h * h - 1) % q
        if f != 0:
            break
    f_inv = pow(f, -1, q)
    g = (1 + r * f_inv) % q
    f_inv_g = (1 + r * f_inv * g) % q
    # Generate public key
    t = np.random.randint(1, q-1)
    while True:
        u = (t * f_inv_g) % q
        if np.remainder(u, r) != 0:
            break
    s = (u - t) % r
    public_key = (g, N, q, u)
    private_key = (f, g, N, q, s)
    return public_key, private_key

def NTRU_encrypt(public_key, m):
    """
    Encrypt a message using NTRU cryptosystem.
    """
    g, N, q, u = public_key
    m = (m % N) + 1
    # Generate random r
    r = np.random.randint(1, q-1)
    # Compute ciphertext
    c = (g ** r) % q
    c = (c * (m ** u)) % q
    c = (c ** r) % q
    return c

def NTRU_decrypt(private_key, c):
    """
    Decrypt a ciphertext using NTRU cryptosystem.
    """
    f, g, N, q, s = private_key
    f_inv = pow(f, -1, q)
    # Compute plaintext
    m = (c * (s ** f_inv)) % q
    return m - 1
```

##### Hash-based Cryptography

Hash-based cryptography uses hash functions to create fixed-size output from any size of input data. Here's a simple implementation of the SHA-256 hash function:

```python
import hashlib

def SHA256_hash(data):
    """
    Compute the SHA-256 hash of the input data.
    """
    hash_object = hashlib.sha256()
    hash_object.update(data)
    hex_dig = hash_object.hexdigest()
    return hex_dig

# Example usage
print(SHA256_hash(b'Hello, World!'))
```

#### Mathematical Models and Formulas

Quantum resistant algorithms rely on mathematical models and formulas to ensure their security. Here are some key components:

- **Lattice Problem**: Solving the Shortest Vector Problem (SVP) or Closest Vector Problem (CVP) on lattices.
- **Hash Functions**: Collision resistance and pre-image resistance.

$$
H(K, M) = \text{SHA-256}(K \oplus M)

- **Digital Signatures**: Non-repudiation and authenticity.

$$
s = (\text{H}(m) + r) \mod n
