量子比特（qubit）是量子信息的基本单元，类似于经典计算机中的比特。然而，量子比特能够同时存在于多个状态，这种特性被称为叠加态。叠加态使得量子比特可以同时处理多个信息，大大提高了信息处理的能力。例如，一个量子比特可以处于0和1的叠加状态，即$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，其中$\alpha$和$\beta$是复数系数，满足$|\alpha|^2 + |\beta|^2 = 1$。

在量子测量中，测量工具（量子传感器）会与被测系统发生相互作用，使被测系统的量子态发生坍缩。量子传感器的测量结果并非随机分布，而是具有概率分布，这取决于被测系统的初始状态。这种概率性使得量子传感器能够在微观尺度上实现高精度的测量。

   ```python
   from qdk import H, X, RY, Meas
   from qdk.components import QIRCompiler

   qc = QuantumCircuit(2)
   qc.append(H(0), qargs=[0])
   qc.append(RY(np.pi/4), qargs=[0])
   qc.append(X(1), qargs=[1])
   qc.append(Meas(0, 0), qargs=[0])

   compiler = QIRCompiler()
   qir_program = compiler.compile(qc)
   ```

```python
    # 将QDK生成的QASM代码转换为Qiskit格式
```
