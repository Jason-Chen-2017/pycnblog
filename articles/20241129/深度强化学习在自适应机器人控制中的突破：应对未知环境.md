### 第1章：深度强化学习概述

#### 1.1 深度强化学习背景

**传统强化学习的局限**

- **Q-Learning算法**：在面对复杂环境和高维状态时，Q值更新缓慢，容易陷入局部最优。
- **策略梯度算法**：在探索和利用之间难以平衡，需要大量的样本数据。

**深度强化学习的优势**

- **应对高维状态和动作空间**：通过神经网络将高维状态映射到决策空间，提高学习效率。
- **数据高效利用**：通过模型自主探索，充分利用环境中的信息，减少样本数量。

#### 1.2 深度强化学习核心概念

**状态、动作、奖励**

- **马尔可夫决策过程（MDP）**：描述环境和agent之间的交互。

**Q-学习算法**

- **Q值函数**：评估每个状态-动作对的预期奖励。
- **目标Q值**：通过目标网络降低偏差。
- **经验回放**：通过随机抽样减少序列依赖。
- **目标网络**：固定一部分网络参数，以降低梯度消失和梯度爆炸问题。

**策略梯度算法**

- **策略表示**：通过参数化策略，将决策表示为参数的函数。
- **策略评估**：通过模型评估策略的期望回报。
- **策略优化**：通过梯度下降优化策略参数。

### 第3章：深度强化学习算法详解

#### 3.1 DQN算法

**DQN算法原理**

- **经验回放**：通过随机抽样减少序列依赖。
- **目标网络**：固定一部分网络参数，以降低偏差。

**DQN算法伪代码**

```python
initialize Q-network Q and target network Q'
initialize experience replay buffer D
initialize exploration strategy ε-greedy
for each episode:
    for each step in episode:
        if ε > random number:
            choose action a randomly
        else:
            choose action a = argmax_a Q(s, a)
        take action a, observe reward r, next state s'
        store transition (s, a, r, s') in D
        if length(D) > capacity:
            sample a batch of transitions from D
            calculate target Q-values:
                target_Q(s', a') = r + γ * max_a' Q'(s', a')
            perform gradient descent step on Q-network Q:
                ∇Q(s, a) = r - Q(s, a) + target_Q(s', a)
        update target network Q' = τ * Q + (1 - τ) * Q'
        update exploration strategy ε
```

#### 3.2 DDPG算法

**DDPG算法原理**

- **Actor-Critic框架**：通过Actor网络生成动作，Critic网络评估动作价值。
- **经验回放**：通过随机抽样减少序列依赖。
- **目标网络**：固定一部分网络参数，以降低偏差。

**DDPG算法伪代码**

```python
initialize actor network π and target actor network π'
initialize critic network Q and target critic network Q'
initialize experience replay buffer D
initialize exploration noise η
for each episode:
    for each step in episode:
        sample initial state s
        while end of episode:
            if ε > random number:
                action a = sample random action
            else:
                action a = π(s) + η
            take action a, observe reward r, next state s'
            store transition (s, a, r, s') in D
            if length(D) > capacity:
                sample a batch of transitions from D
                calculate target Q-value:
                    target_Q(s', a') = r + γ * Q'(s', π'(s'))
                perform gradient descent step on critic network Q:
                    ∇Q(s, a) = r - Q(s, a) + target_Q(s', a')
                perform gradient descent step on actor network π:
                    ∇π(s) = ∇Q(s, π(s))
        update target networks π' = τ * π + (1 - τ) * π', Q' = τ * Q + (1 - τ) * Q'
        update exploration noise η
```

#### 3.3 A3C算法

**A3C算法原理**

- **异步学习**：多个并行代理同时学习，提高学习效率。
- **梯度聚合**：将多个代理的梯度聚合，更新全局模型。

**A3C算法伪代码**

```python
initialize global model θ and local models θ_i
initialize shared global optimizer
for each parallel agent i:
    while not end of episode:
        execute action a_i = π_i(s_i; θ) + ε
        observe reward r_i and next state s_i'
        compute local gradients:
            ∇θ_i = ∇θ_i[π_i(s_i; θ) * log π_i(a_i; θ) - V_i(s_i'; θ)]
        communicate gradients to global optimizer
        update global model θ
    aggregate local gradients and update local models θ_i
```
