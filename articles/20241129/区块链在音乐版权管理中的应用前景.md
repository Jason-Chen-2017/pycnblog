#### 2. 共识机制

共识机制是区块链网络中确保数据一致性的一种机制。在区块链中，常用的共识机制包括工作量证明（PoW）和权益证明（PoS）。

**工作量证明（PoW）示例**

```python
import hashlib
import random

def proof_of_work(difficulty):
    """计算工作量证明"""
    last_hash = "0000"  # 初始哈希值
    nonce = 0  # 随机数
    while True:
        message = f"{last_hash}{nonce}".encode('utf-8')
        hash_value = hashlib.sha256(message).hexdigest()
        if hash_value[:difficulty] == "0" * difficulty:
            return nonce
        nonce += 1

# 示例：计算工作量证明
difficulty = 4  # 难度
nonce = proof_of_work(difficulty)
print("Nonce:", nonce)
print("Hash value:", hashlib.sha256(f"{last_hash}{nonce}".encode('utf-8')).hexdigest())
```

工作量证明机制通过计算复杂的哈希值来确保区块链网络的一致性。难度参数用于调节计算难度。
