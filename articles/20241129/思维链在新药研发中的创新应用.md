   - **非线性变换**：DNN通过激活函数引入非线性特性，使得模型能够学习到更加复杂的非线性关系。

   - **平移不变性**：CNN具有平移不变性，使得模型对图像的旋转、翻转等变换具有较强的鲁棒性。
   - **多尺度特征提取**：CNN通过多层的卷积和池化操作，能够提取图像的多尺度特征，提高模型的识别能力。

3. **循环神经网络（RNN）**：循环神经网络是一种用于处理序列数据的深度学习模型，通过循环机制，将前一时间步的信息传递到当前时间步，实现对序列的长期依赖建模。RNN具有以下几个特点：

   - **长短时记忆（LSTM）**：LSTM是RNN的一种改进，通过引入门控机制，解决了传统RNN的梯度消失和梯度爆炸问题，使得模型能够学习到更长的序列依赖。
   - **序列建模**：RNN能够对序列数据进行建模，适用于自然语言处理、语音识别等领域。

新药筛选通常包括以下几个步骤：

3. **筛选策略制定**：根据靶点特性，制定相应的筛选策略，选择合适的生物标志物或生物模型进行筛选。

4. **实验验证**：对初步筛选出的化合物进行生物活性测试，评估其与靶点的结合能力、药效和毒性等。

5. **优化与筛选**：对初步筛选出的化合物进行结构优化，进一步筛选出具有更高活性、更低毒性的候选药物。

1. **毒性指标筛选**：根据药物的性质和作用机制，选择合适的毒性指标，如肝毒性、肾毒性、神经毒性等。
2. **实验设计**：设计合理的实验方案，包括药物剂量、给药途径、实验周期等。
3. **数据收集**：通过实验和临床观察，收集药物毒性相关的数据，包括生物指标、组织病理学检查等。
4. **数据分析**：对收集到的数据进行分析，评估药物的毒性效应，确定安全剂量范围。

### 6.2 传统方法

传统的药物毒性评估方法主要包括以下几种：

1. **动物实验**：通过实验动物（如小鼠、大鼠、兔子等）进行药物毒性实验，评估药物对动物生理和生化指标的影响。这种方法能够模拟药物在人体中的毒性效应，但存在动物个体差异和伦理问题。
2. **细胞实验**：通过体外细胞实验，如细胞毒性测试、基因表达分析等，评估药物对细胞的毒性效应。这种方法操作简便，但难以模拟体内复杂的生物环境。
3. **临床观察**：在药物临床试验过程中，对受试者进行密切观察，评估药物的毒性效应。这种方法能够直接反映药物在人体中的安全性，但存在样本量有限和结果滞后等问题。

虽然传统方法在药物毒性评估中取得了一定的成果，但仍存在以下局限性：

1. **耗时长、成本高**：动物实验和临床试验需要大量的时间和资源，成本高昂。
2. **结果不可靠**：动物实验和细胞实验结果难以直接推广到人体，存在较大的不确定性。
3. **伦理问题**：动物实验引发了伦理和道德争议，限制了其应用范围。
