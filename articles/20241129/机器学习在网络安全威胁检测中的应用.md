#### 5.1 支持向量机（SVM）

支持向量机（Support Vector Machine，SVM）是一种广泛应用于分类问题的监督学习算法。其基本思想是找到一个最优的超平面，将不同类别的数据点分开。SVM的核心在于“支持向量”，即那些位于分类边界上的数据点，它们对分类边界的影响最大。

**数学模型：**

SVM的优化目标是最小化分类边界到支持向量的距离。对于线性可分的数据，SVM的目标函数可以表示为：

$$
\min_{\mathbf{w}, b} \frac{1}{2} ||\mathbf{w}||^2
$$

其中，$\mathbf{w}$ 是分类边界向量的权重，$b$ 是偏置项。

约束条件是所有数据点都被正确分类，即：

$$
\mathbf{w} \cdot \mathbf{x}_i - b \geq 1, \forall i
$$

其中，$\mathbf{x}_i$ 是第$i$个数据点。

**Python伪代码：**

```python
from sklearn.svm import SVC
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

# 生成模拟数据集
X, y = make_classification(n_samples=100, n_features=20, n_informative=2, n_redundant=10, random_state=42)

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 创建SVM模型
model = SVC(kernel='linear')

# 训练模型
model.fit(X_train, y_train)

# 评估模型
accuracy = model.score(X_test, y_test)
print(f"Model accuracy: {accuracy}")
```

#### 5.2 决策树

决策树是一种简单但强大的分类和回归算法。它通过一系列的测试来将数据集中的每个样本分配到相应的类别或值。

**构建决策树的基本步骤：**

1. **选择一个属性（特征）作为分割标准。**
2. **计算每个属性的信息增益或基尼不纯度。**
3. **选择具有最高信息增益或基尼不纯度的属性作为分割标准。**
4. **根据该属性创建一个新的节点，并将数据集分割成子集。**
5. **递归地重复上述步骤，直到满足停止条件（例如，最大深度、最小叶节点大小等）。**

**数学模型：**

信息增益（Information Gain）是决策树的一个核心概念。它衡量了使用某个属性进行分割后数据的纯度增加程度。

$$
IG(D, A) = entropy(D) - \sum_{v \in \text{values}(A)} \frac{|D_v|}{|D|} \cdot entropy(D_v)
$$

其中，$D$ 是数据集，$A$ 是属性，$v$ 是属性 $A$ 的值，$D_v$ 是属性 $A$ 等于 $v$ 的数据子集。

**Python伪代码：**

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import load_iris

# 加载iris数据集
data = load_iris()
X = data.data
y = data.target

# 创建决策树模型
model = DecisionTreeClassifier(max_depth=3)

# 训练模型
model.fit(X, y)

# 预测
predictions = model.predict(X)

# 评估模型
accuracy = (predictions == y).mean()
print(f"Model accuracy: {accuracy}")
```

#### 5.3 集成学习方法

集成学习方法通过构建多个基础模型，并将它们的预测结果进行结合，以提高整体预测性能。常见的集成学习方法包括Bagging、Boosting和Stacking等。

**Bagging（集成贝叶斯）：**

Bagging通过从训练数据中随机抽取多个子集，并分别训练基础模型，然后将这些模型的预测结果进行平均。Bagging可以减少模型的方差，提高模型的泛化能力。

**Python伪代码：**

```python
from sklearn.ensemble import BaggingClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

# 生成模拟数据集
X, y = make_classification(n_samples=100, n_features=20, n_informative=2, n_redundant=10, random_state=42)

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 创建Bagging模型
model = BaggingClassifier(base_estimator=SVC(), n_estimators=10)

# 训练模型
model.fit(X_train, y_train)

# 评估模型
accuracy = model.score(X_test, y_test)
print(f"Model accuracy: {accuracy}")
```

**Boosting（提升法）：**

Boosting通过多次迭代训练基础模型，并调整每个模型的权重，使之前表现不佳的模型得到更多的训练机会。常见的Boosting算法包括Adaboost和GBDT（梯度提升树）。

**Python伪代码：**

```python
from sklearn.ensemble import AdaBoostClassifier
from sklearn.datasets import make_classification

# 生成模拟数据集
X, y = make_classification(n_samples=100, n_features=20, n_informative=2, n_redundant=10, random_state=42)

# 创建Adaboost模型
model = AdaBoostClassifier(n_estimators=50)

# 训练模型
model.fit(X, y)

# 评估模型
accuracy = model.score(X, y)
print(f"Model accuracy: {accuracy}")
```

## 第6章：数学模型与公式

在这一章节中，我们将深入探讨机器学习中的数学模型与公式，结合具体的算法进行详细解释。数学模型是机器学习算法的理论基础，而公式则是实现这些算法的核心。以下是几个关键的数学模型与公式的介绍：

### 6.1 概率论基础

概率论是机器学习中的重要工具，用于描述不确定性事件。以下是一些基本的概率论概念和公式：

**条件概率：**

$$
P(A|B) = \frac{P(A \cap B)}{P(B)}
$$

**贝叶斯定理：**

$$
P(A|B) = \frac{P(B|A)P(A)}{P(B)}
$$

**独立事件：**

$$
P(A \cap B) = P(A)P(B)
$$

### 6.2 线性回归模型

线性回归是一种广泛使用的监督学习算法，用于预测连续值。其基本模型如下：

$$
y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \ldots + \beta_nx_n + \epsilon
$$

其中，$y$ 是预测目标，$x_1, x_2, \ldots, x_n$ 是特征，$\beta_0, \beta_1, \ldots, \beta_n$ 是模型参数，$\epsilon$ 是误差项。

**最小二乘法：**

为了最小化预测误差，我们可以使用最小二乘法来估计模型参数：

$$
\min_{\beta} \sum_{i=1}^{n} (y_i - \beta_0 - \beta_1x_{i1} - \ldots - \beta_nx_{in})^2
$$

### 6.3 逻辑回归模型

逻辑回归是一种用于分类问题的算法，其基本模型如下：

$$
\log\left(\frac{P(Y=1)}{1 - P(Y=1)}\right) = \beta_0 + \beta_1x_1 + \beta_2x_2 + \ldots + \beta_nx_n
$$

其中，$Y$ 是二分类目标变量，$P(Y=1)$ 是目标变量为1的条件概率。

**sigmoid函数：**

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$

sigmoid函数将线性组合映射到概率值域（0到1）。

### 6.4 支持向量机（SVM）

支持向量机是一种有效的分类算法，其目标是最小化分类边界到支持向量的距离。以下是SVM的数学模型：

**目标函数：**

$$
\min_{\mathbf{w}, b} \frac{1}{2} ||\mathbf{w}||^2
$$

**约束条件：**

$$
\mathbf{w} \cdot \mathbf{x}_i - b \geq 1, \forall i
$$

**核函数：**

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)
$$

其中，$\mathbf{w}$ 是分类边界向量的权重，$b$ 是偏置项，$\phi$ 是核函数，$K$ 是核矩阵。

### 6.5 神经网络模型

神经网络是一种基于生物神经网络原理构建的机器学习模型。以下是一个简单的神经网络模型：

$$
\text{Output} = \sigma(\sum_{i=1}^{n} \beta_i \cdot \phi_i(x_i) + \theta)
$$

其中，$\sigma$ 是激活函数，$\beta_i$ 和 $\theta$ 是模型参数，$\phi_i(x_i)$ 是输入特征映射到高维空间的函数。

### 6.6 集成学习方法

集成学习方法通过组合多个基础模型来提高整体性能。以下是集成学习方法的基本概念：

**Bagging：**

$$
\hat{y} = \frac{1}{N} \sum_{i=1}^{N} f_i(x)
$$

其中，$f_i(x)$ 是第$i$个基础模型的预测结果，$N$ 是基础模型的数量。

**Boosting：**

$$
f(x) = \sum_{i=1}^{T} \alpha_i f_i(x)
$$

其中，$\alpha_i$ 是第$i$个基础模型的权重，$T$ 是基础模型的数量。

通过这些数学模型与公式，我们可以更好地理解机器学习算法的原理和实现。这些知识将有助于我们在实际应用中更好地选择和使用合适的算法。
