**Python源代码示例**：
```python
class KnowledgeRepresentation:
    def __init__(self):
        self.graph = defaultdict(list)

    def add_entity(self, entity):
        self.graph[entity] = []

    def add_relationship(self, entity1, entity2, relation):
        self.graph[entity1].append((entity2, relation))
        self.graph[entity2].append((entity1, 'inverse_' + relation))

knowledge_rep = KnowledgeRepresentation()
knowledge_rep.add_entity('Weather')
knowledge_rep.add_relationship('Weather', 'Location', 'is_in')
```

#### 3.1 基于规则的推理算法

**核心概念与联系**：
- 前提条件：规则推理的基础，用于确定规则的适用条件。
- 结论：基于前提条件得出的结果。

**Python源代码示例**：
```python
def forward_chaining(knowledge_base, rule, fact):
    if fact in rule['conditions']:
        return rule['conclusion']
    else:
        return None

rule = {'conditions': ['weather=rainy', 'wearing_jacket=true'], 'conclusion': 'take_an_umbrella'}
fact = 'weather=rainy'
print(forward_chaining(knowledge_base, rule, fact))
```

#### 3.2 基于框架的推理算法

**核心概念与联系**：

- 推理过程：根据框架和事实进行推理，得出结论。

**Python源代码示例**：
```python
class KnowledgeFrame:
    def __init__(self, frame):
        self.frame = frame

    def apply_rules(self, fact):
        for rule in self.frame['rules']:
            if all(condition in fact for condition in rule['conditions']):
                return rule['conclusion']
        return None

frame = {
    'entity': 'Person',
    'attributes': {'age': 30, 'occupation': 'engineer'},
    'rules': [
        {'conditions': {'age': 'over_30'}, 'conclusion': 'adult'}
    ]
}

knowledge_frame = KnowledgeFrame(frame)
print(knowledge_frame.apply_rules({'age': 35}))
```

```python
from rdflib import Graph

g = Graph()
g.parse("knowledge_graph.nt", format="nt")

query = """
PREFIX ex: <http://example.org/>
SELECT ?x ?y
WHERE {
  ?x ex:knows ?y .
}
"""
results = g.query(query)

for row in results:
    print(f"{row.x} knows {row.y}")
```
