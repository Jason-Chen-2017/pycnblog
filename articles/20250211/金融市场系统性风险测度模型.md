# 第一章：系统性风险的基本概念

## 1.1 系统性风险的定义与特点  
系统性风险是指由于金融体系中某些共同因素的变化，导致整个金融体系发生系统性崩溃的风险。其核心特点包括：  
1. **全局性**：影响整个金融体系，而非单一机构或资产。  
2. **传染性**：风险可能从一个市场或机构迅速蔓延至整个金融体系。  
3. **不可分散性**：无法通过资产多样化完全消除。  

## 1.2 金融市场中的系统性风险  
金融市场是一个复杂的生态系统，系统性风险的来源包括：  
- **市场波动**：资产价格的剧烈波动可能引发连锁反应。  
- **流动性风险**：市场流动性不足可能导致资产价格崩盘。  
- **信用风险**：金融机构的信用危机可能引发系统性风险。  

## 1.3 系统性风险测度模型的背景与意义  
随着金融市场的全球化和复杂化，系统性风险的测度与管理变得尤为重要。本文将通过多种模型（如VaR、CVaR、网络模型）分析系统性风险的测度方法，并探讨其在实际应用中的意义。

# 第二章：系统性风险测度模型的核心概念  

## 2.1 VaR模型  
**VaR（Value at Risk）**是衡量投资组合在给定置信水平下的潜在损失。  
- **公式**：  
  $$ VaR_{\alpha} = \text{最小损失} \text{使得} P(L \leq VaR_{\alpha}) \geq \alpha $$  
- **特点**：简单易懂，但无法反映尾部风险。  

## 2.2 CVaR模型  
**CVaR（Conditional Value at Risk）**是VaR的改进版，衡量在VaR水平下的平均损失。  
- **公式**：  
  $$ CVaR_{\alpha} = \mathbb{E}[L | L \geq VaR_{\alpha}] $$  
- **特点**：更稳健，能反映尾部风险。  

## 2.3 网络模型  
网络模型通过分析金融机构之间的关联性来测度系统性风险。  
- **核心思想**：机构之间的相互依赖性可能导致系统性风险的扩散。  

## 2.4 宏观经济模型  
宏观经济模型通过分析宏观经济指标（如GDP、失业率）来测度系统性风险。  
- **特点**：适用于宏观层面的系统性风险测度。

# 第五章：系统性风险测度模型的项目实战  

## 5.1 环境搭建  
- **工具安装**：Python、Pandas、NumPy。  
- **数据获取**：获取历史资产价格数据。  

## 5.2 核心代码实现  
```python
import numpy as np
import pandas as pd

# 示例数据：资产收益率
returns = pd.Series([0.01, -0.02, 0.03, -0.01, 0.02])

# 计算VaR
alpha = 0.95
sorted_returns = sorted(returns)
VaR = sorted_returns[int(len(sorted_returns) * (1 - alpha))]
print("VaR:", VaR)

# 计算CVaR
CVaR = np.mean(sorted_returns[sorted_returns >= VaR])
print("CVaR:", CVaR)
```
