### 第二部分：技术面与基本面结合的算法原理

#### 第3章：技术面与基本面结合的算法原理

##### 3.1 技术面分析的数学模型
- 3.1.1 移动平均线（MA）的计算公式
  $$ MA_n = \frac{1}{n} \sum_{i=1}^{n} P_i $$
  其中，$P_i$ 表示第i天的价格，$n$ 表示计算天数。
- 3.1.2 相对强弱指数（RSI）的计算公式
  $$ RSI = \frac{100}{1 + \frac{A}{B}} $$
  其中，$A$ 是上涨幅度，$B$ 是下跌幅度。

##### 3.2 基本面分析的数学模型
- 3.2.1 市盈率（PE）的计算公式
  $$ PE = \frac{股价}{每股收益} $$
- 3.2.2 市净率（PB）的计算公式
  $$ PB = \frac{股价}{每股净资产} $$

##### 3.4 技术面与基本面结合的Python实现示例
```python
import pandas as pd
import numpy as np

# 假设data是一个包含'收盘价'和'净利润'的DataFrame
# 技术指标：5日移动平均线
data['MA5'] = data['收盘价'].rolling(5).mean()

# 基本面指标：市盈率（PE）
data['PE'] = data['收盘价'] / (data['净利润'].rolling(5).mean())

# 综合判断：当MA5上穿价格且PE低于行业平均时，发出买入信号
data['信号'] = np.where((data['MA5'] > data['收盘价']) & (data['PE'] < data['PE'].mean()), '买入', '观望')
```

##### 5.2 核心代码实现
```python
import pandas as pd
import numpy as np
import requests

# 获取股票数据
def get_data(stock):
    url = f"https://query1.finance.yahoo.com/v8/finance/chart/{stock}"
    response = requests.get(url)
    data = response.json()
    df = pd.DataFrame(data['chart']['result'][0]['prices'])
    df['Date'] = pd.to_datetime(df[0])
    df = df.set_index('Date')
    df = df[['open', 'high', 'low', 'close', 'volume']]
    return df

# 计算技术指标
def calculate_technical_indicators(df):
    df['MA5'] = df['close'].rolling(5).mean()
    df['RSI'] = (100 / (1 + (df['close'].diff().apply(lambda x: x if x > 0 else 0).rolling(5).mean() / df['close'].diff().apply(lambda x: -x if x < 0 else 0).rolling(5).mean())))
    return df

# 计算基本面指标
def calculate_fundamental_indicators(stock):
    url = f"https://query1.finance.yahoo.com/v11/finance/peRatio/{stock}"
    response = requests.get(url)
    data = response.json()
    pe_ratio = data['peRatio']['value']
    return pe_ratio

# 综合判断
def generate_signal(stock_data, pe_ratio, industry_pe):
    if (stock_data['MA5'][-1] > stock_data['close'][-1]) and (pe_ratio < industry_pe):
        return '买入'
    elif (stock_data['MA5'][-1] < stock_data['close'][-1]) and (pe_ratio > industry_pe):
        return '卖出'
    else:
        return '观望'

# 主程序
def main():
    stock = 'AAPL'
    df = get_data(stock)
    df = calculate_technical_indicators(df)
    pe_ratio = calculate_fundamental_indicators(stock)
    industry_pe = 15  # 示例行业平均PE
    signal = generate_signal(df, pe_ratio, industry_pe)
    print(f"信号：{signal}")

if __name__ == '__main__':
    main()
```
