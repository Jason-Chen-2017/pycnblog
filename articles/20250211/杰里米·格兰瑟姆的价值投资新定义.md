## 第1章: 价值投资的演变与新定义

### 1.1 价值投资的历史演变

#### 1.1.1 价值投资的起源与发展
价值投资是一种基于对公司内在价值评估的投资策略，起源于20世纪初。本杰明·格雷厄姆和戴维·多德是该领域的先驱，他们提出了“安全边际”和“内在价值”等核心概念。格兰瑟姆师承格雷厄姆，进一步发展了价值投资理论。

#### 1.1.2 格兰瑟姆对价值投资的贡献
杰里米·格兰瑟姆（Jeremy Grantham）是价值投资领域的权威，他在传统价值投资的基础上，提出了新的定义和方法。他强调通过数据分析和系统化的方法来识别市场低估的机会，并在市场周期中进行投资。

#### 1.1.3 新定义的提出背景与问题背景
传统价值投资在实践中面临一些问题，如主观判断过多、难以量化、难以应对市场变化等。格兰瑟姆的新定义旨在解决这些问题，通过系统化的方法和量化工具来优化投资决策。

### 1.2 格兰瑟姆价值投资新定义的核心要素

#### 1.2.1 核心概念的结构与组成
格兰瑟姆的新定义将价值投资重新定义为一种系统化、数据驱动的投资方法。其核心要素包括：
1. **内在价值评估**：基于公司财务数据和行业趋势，计算公司的真实价值。
2. **市场情绪分析**：通过市场数据和投资者情绪指标，判断市场是否低估或高估资产。
3. **多因子模型**：结合多个因子（如市盈率、市净率、股息率等）进行综合评估。

#### 1.2.2 新定义与传统价值投资的对比
| **维度**       | **传统价值投资**                | **格兰瑟姆新定义**              |
|-----------------|----------------------------------|---------------------------------|
| 投资策略         | 侧重于基本面分析，注重安全边际 | 系统化分析，结合数据驱动方法    |
| 投资决策         | 主观判断为主                   | 数据驱动，量化决策为主          |
| 应用场景         | 单一资产或少量资产             | 多资产、多行业综合应用            |
| 风险管理         | 侧重于资产质量                 | 强调风险控制和组合优化           |

#### 1.2.3 新定义的边界与外延
格兰瑟姆的新定义不仅适用于股票投资，还可以扩展到其他资产类别（如房地产、债券等），并且可以应用于机构投资和个人投资。

### 2.1 新定义的特征分析

#### 2.1.1 核心概念的数学模型
格兰瑟姆的新定义引入了多因子模型，通过量化的方法评估资产的内在价值。其核心公式可以表示为：

def calculate_intrinsic_value(company_data):
    # 计算多因子模型
    factors = company_data[['市盈率', '市净率', '股息率']]
    weights = [0.4, 0.3, 0.3]

    return intrinsic_value

import numpy as np

def calculate_intrinsic_value(company_data):
    # 计算多因子模型

    weights = [0.4, 0.3, 0.3]
    intrinsic_value = sum(factors[i] * weights[i] for i in range(len(factors.columns)))
    return intrinsic_value

# 示例数据

    '公司': ['A', 'B', 'C'],

    '市净率': [2, 3, 4],

df = pd.DataFrame(data)
df['内在价值'] = df[['市盈率', '市净率', '股息率']].apply(lambda x: calculate_intrinsic_value(x), axis=1)
