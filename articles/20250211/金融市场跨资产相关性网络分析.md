6. [项目实战：跨资产相关性网络分析](#项目实战跨资产相关性网络分析)
   - [6.1 环境安装](#61-环境安装)

     - pandas、numpy、networkx、matplotlib
   - [6.2 系统核心实现](#62-系统核心实现)
     ```python
     import numpy as np
     import pandas as pd
     from sklearn.metrics import pairwise_distances

     # 示例数据：假设我们有多个资产的收益率序列
     df = pd.DataFrame({
         '资产A': [0.02, -0.01, 0.03, 0.00, -0.02],
         '资产B': [0.01, 0.02, -0.01, 0.03, 0.00],
         '资产C': [-0.03, 0.01, 0.02, 0.01, 0.04]
     })

     # 计算Pearson相关性矩阵
     correlation_matrix = df.corr()

     # 构建网络边
     edges = []
     for i in range(len(correlation_matrix)):
         for j in range(i+1, len(correlation_matrix)):
             edges.append((i, j, correlation_matrix.iloc[i,j]))

     # 网络可视化
     import networkx as nx
     G = nx.Graph()
     for node in range(len(df.columns)):
         G.add_node(df.columns[node])
     for edge in edges:
         G.add_edge(edge[0], edge[1], weight=edge[2])

     nx.draw(G, with_labels=True, edge_labels=True)
     plt.show()
     ```
