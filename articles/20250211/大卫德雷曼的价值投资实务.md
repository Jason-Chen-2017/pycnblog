### 1.1 价值投资的定义与背景

#### 5.2.1 Python代码实现DCF模型

```python
def calculate_intrinsic_value(financials, discount_rate):
    cash_flows = [f.cash_flow for f in financials]
    pv = sum(cash_flows / (1 + discount_rate) ** i for i in range(len(cash_flows)))
    return pv
```
