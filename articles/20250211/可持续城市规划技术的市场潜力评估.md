### 第3章：可持续城市规划技术的市场潜力评估算法

#### 3.1 算法原理
- 3.1.1 层次分析法（AHP）  
  - 理论基础：通过权重分配对各技术进行综合评估。  
  - 公式：$$ A = \lambda_{max} - \frac{1}{n-1} $$，其中，$\lambda_{max}$ 是最大特征值，$n$ 是指标个数。  

- 3.1.2 线性回归分析  
  - 理论基础：通过历史数据拟合市场潜力与技术性能的关系。  
  - 公式：$$ y = \beta_0 + \beta_1x + \epsilon $$  

- 3.1.3 综合评估模型  
  - 理论基础：结合定量与定性指标，构建综合评分模型。

### 第5章：项目实战

#### 5.1 环境安装与数据准备
- 环境需求：Python 3.8+，安装 numpy、pandas、scikit-learn 等库。  

#### 5.2 核心代码实现

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 示例数据：绿色建筑技术的能耗与市场潜力
X = np.array([[2.5], [3.0], [3.5], [4.0]])  # 能耗（单位： kWh/m²）
y = np.array([65, 70, 75, 80])  # 市场潜力评分

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测结果
predictions = model.predict(X)
print("预测值:", predictions)
print("R²值:", r2_score(y, predictions))
```

#### 5.3 案例分析与解读
- 数据分析结果：绿色建筑技术的市场潜力与能耗呈负相关。  
- 模型优化：引入更多变量（如政策支持度、用户接受度）以提高模型精度。
