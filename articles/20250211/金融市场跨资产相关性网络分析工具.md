## 第2章: 相关性网络分析的核心原理

### 2.1 相关性计算方法
- **协方差**：衡量资产价格变动的相似性。
  $$ \text{Cov}(X, Y) = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})(Y_i - \bar{Y}) $$
- **皮尔逊相关系数**：标准化的协方差，衡量线性相关性。
  $$ r_{xy} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y} $$

### 2.2 网络构建步骤
1. 数据预处理：清洗缺失值、异常值。
2. 计算相关性矩阵：使用皮尔逊相关系数。
3. 构建网络图：将相关性大于等于阈值的资产对连接成边。

### 2.3 网络属性分析
- **度**：节点的度数，表示资产与其他资产的相关性强度。
- **中心性**：节点在网络中的重要性，用于识别关键资产。
- **聚类系数**：节点邻居之间的连接程度，用于识别社区结构。

### 2.4 网络可视化工具
- **Gephi**：开源网络可视化工具，支持多种网络布局。
- **NetworkX**：Python网络分析库，支持网络构建和可视化。
- **Matplotlib**：Python绘图库，用于数据可视化。

### 3.2 算法实现代码

```python
import numpy as np
import pandas as pd
import networkx as nx
import matplotlib.pyplot as plt

def load_data():
    # 加载股票价格数据
    df = pd.read_csv('stock_prices.csv')
    return df

def preprocess_data(df):
    # 数据清洗：处理缺失值
    df.dropna(inplace=True)
    return df

def compute_correlation_matrix(df):
    # 计算皮尔逊相关系数矩阵
    correlation_matrix = df.corr()
    return correlation_matrix

def build_network(correlation_matrix, threshold=0.3):
    # 构建相关性网络
    G = nx.Graph()
    for i in range(len(correlation_matrix.columns)):
        for j in range(i+1, len(correlation_matrix.columns)):
            correlation = correlation_matrix.iloc[i, j]
            if correlation >= threshold:
                G.add_edge(correlation_matrix.columns[i], correlation_matrix.columns[j])
    return G

def visualize_network(G):
    # 可视化网络图
    nx.draw(G, node_size=800, node_color='red', edge_color='blue', with_labels=True)
    plt.show()

if __name__ == "__main__":
    df = load_data()
    df_processed = preprocess_data(df)
    correlation_matrix = compute_correlation_matrix(df_processed)
    G = build_network(correlation_matrix)
    visualize_network(G)
```

### 3.3 算法数学模型
- **相关性计算公式**
  $$ r_{xy} = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \sum (y_i - \bar{y})^2}} $$
- **网络构建逻辑**
  $$ \text{若 } r_{xy} \geq \text{阈值} \Rightarrow x \text{与} y \text{之间存在边} $$
