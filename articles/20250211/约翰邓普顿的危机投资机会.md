# 第1章 约翰邓普顿与危机投资概述

## 1.1 约翰·邓普顿的生平与投资哲学

### 1.1.1 约翰·邓普顿的生平简介

约翰·邓普顿（John Templeton，1912-2008）是一位传奇的投资家，被誉为“全球投资之父”。他出生于加拿大，在美国宾夕法尼亚州的兰开斯特长大。邓普顿的职业生涯始于1930年代，他最初在纽约证券交易所工作，后来成为复兴投资公司（Renaissance Investment Corporation）的创始人。邓普顿以其独特的投资风格和卓越的投资业绩闻名于世，尤其是在危机时期的出色表现。

---

### 1.1.2 约翰·邓普顿的投资哲学

约翰·邓普顿的投资哲学以“逆向投资”为核心，主张在市场恐慌时买入，而在市场繁荣时卖出。他强调安全边际的重要性，认为投资者应该在市场价格远低于内在价值时买入，以降低投资风险。此外，邓普顿还非常重视长期投资，反对频繁交易和短期投机。

---

### 1.1.3 约翰·邓普顿与危机投资的关系

约翰·邓普顿的投资理念与危机投资密切相关。他认为，危机是投资者的“朋友”，因为在市场恐慌时，许多优质资产的价格会被低估，这为投资者提供了廉价买入的机会。邓普顿在1973年和1987年的危机中都成功地进行了逆向投资，取得了巨大的收益。

---

## 1.2 危机投资的背景与意义

### 1.2.1 危机投资的定义与特点

危机投资是指在市场危机或经济衰退时期进行投资的策略。其特点是：市场波动大、资产价格被低估、投资机会丰富。与牛市投资不同，危机投资需要投资者具备冷静的心态和强大的心理素质。

---

### 1.2.2 危机投资的背景分析

危机投资的背景通常是市场恐慌和投资者情绪低落。这种情况下，许多资产的价格会被市场情绪所左右，出现超跌现象。然而，这也为具有洞察力的投资者提供了廉价买入的机会。

---

### 1.2.3 危机投资的意义与价值

危机投资的意义在于通过逆向思维，捕捉市场恐慌中的投资机会。成功的危机投资需要投资者具备深厚的投资知识、冷静的判断力和强大的心理承受能力。危机投资的价值在于能够在市场底部买入优质资产，为长期收益奠定基础。

---

## 1.3 约翰·邓普顿的危机投资策略

### 1.3.1 约翰·邓普顿的危机投资理念

邓普顿的危机投资理念可以概括为“买当别人恐惧时”。他认为，市场恐慌时，投资者应该逆势买入，尤其是当市场价格远低于内在价值时。

---

### 1.3.2 约翰·邓普顿的危机投资方法

邓普顿的危机投资方法包括以下几个方面：
1. **安全边际**：确保买入价格远低于内在价值。
2. **分散投资**：避免过度集中投资，降低风险。
3. **长期持有**：坚持长期投资，不被短期波动所影响。
4. **逆向思维**：在市场恐慌时买入，而在市场繁荣时卖出。

---

### 1.3.3 约翰·邓普顿的危机投资案例

以1987年美国股市崩盘为例，邓普顿在市场恐慌时大量买入优质资产，随后市场反弹，他获得了丰厚的回报。

def calculate_intrinsic_value/assets:

    return calculate_intrinsic_value/assets * 0.9  # 确保买入价格低于内在价值

# 示例数据
assets = [100, 200, 300, 400, 500]
prices = [50, 100, 150, 200, 250]

# 计算内在价值和买入价格
intrinsic_values = [calculate_intrinsic_value(a) for a in assets]
buy_prices = [calculate_buy_price(p) for p in prices]

# 绘制图表

plt.plot(assets, prices, 'b-', label='Market Price')

plt.plot(assets, buy_prices, 'g-', label='Buy Price')
plt.xlabel('Assets')
plt.ylabel('Price')
plt.legend()
plt.show()
