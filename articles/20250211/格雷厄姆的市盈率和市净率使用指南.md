# 第1章: 投资基础与估值指标概述

## 1.1 投资的基本概念

### 1.1.1 投资的定义与分类
- 投资是指将资金投入到某个项目或资产中，以期望在未来获得收益或资本增值。
- 投资可以分为实物投资（如房地产、制造业）和金融投资（如股票、债券）。

### 1.1.2 估值指标在投资中的重要性
- 估值指标是衡量资产价值的重要工具，能够帮助投资者判断资产是否被高估或低估。
- 常见的估值指标包括市盈率（P/E）、市净率（P/B）、股息率等。

### 1.1.3 市盈率和市净率的起源与演变
- 市盈率和市净率是格雷厄姆在《证券分析》中提出的重要概念，至今仍然是价值投资的核心工具。

---

## 1.2 市盈率和市净率的定义与计算

### 1.2.1 市盈率的定义
- 市盈率（P/E）= 股价 / 每股净利润
- 用于衡量投资者为每股净利润愿意支付的价格。

### 1.2.2 市净率的定义
- 市净率（P/B）= 股价 / 每股净资产
- 用于衡量投资者为每股净资产愿意支付的价格。

### 1.2.3 市盈率和市净率的计算公式
- 市盈率公式：
  $$ P/E = \frac{\text{股价}}{\text{每股净利润}} $$
- 市净率公式：
  $$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

### 1.2.4 市盈率和市净率的优缺点
| 指标 | 优点 | 缺点 |
|------|------|------|
| 市盈率 | 反映盈利能力，适用于盈利稳定的公司 | 不适合亏损公司，行业差异大 |
| 市净率 | 反映资产价值，适用于净资产为重的行业 | 不反映盈利能力，行业适用性有限 |

---

## 1.3 市盈率和市净率的适用场景

### 1.3.1 市盈率适用的行业
- 利润稳定的行业，如公用事业、消费品行业。

### 1.3.2 市净率适用的行业
- 资产密集型行业，如银行、房地产。

### 1.3.3 市盈率和市净率的综合使用
- 结合行业特点和公司具体情况，综合使用市盈率和市净率进行估值。

# 第2章: 市盈率和市净率的核心概念与联系

## 2.1 市盈率与市净率的原理分析

### 2.1.1 市盈率的原理
- 市盈率反映了市场对公司盈利能力的预期，低市盈率可能意味着公司被低估。

### 2.1.2 市净率的原理
- 市净率反映了市场对公司资产价值的评估，低市净率可能意味着公司资产被低估。

### 2.1.3 市盈率与市净率的内在联系
- 市盈率关注收益，市净率关注资产，两者共同衡量公司的整体价值。

---

| 市净率 | 净资产 | 资产密集型行业 | 反映资产价值，但不反映盈利能力 |

## 5.2 核心代码实现

### 5.2.1 数据采集
```python
import pandas as pd

# 假设我们有一个包含股价、净利润和净资产的数据框
data = pd.DataFrame({
    '股价': [100, 80, 120],
    '净利润': [20, 15, 30],
    '净资产': [50, 40, 60]
})
```

### 5.2.2 计算市盈率和市净率
```python
data['市盈率'] = data['股价'] / data['净利润']
data['市净率'] = data['股价'] / data['净资产']
print(data)
```

### 5.2.3 可视化分析
```python
import matplotlib.pyplot as plt

plt.plot(data['公司名称'], data['市盈率'], label='市盈率')
plt.plot(data['公司名称'], data['市净率'], label='市净率')
plt.legend()
plt.show()
```

## 5.3 实际案例分析

### 5.3.1 案例背景
- 某公司股价为100元，净利润为20元，净资产为50元。
- 计算市盈率和市净率：
  $$ P/E = 100 / 20 = 5 $$
  $$ P/B = 100 / 50 = 2 $$

### 5.3.2 分析结果
- 市盈率为5，市净率为2，表明该公司可能被低估。
