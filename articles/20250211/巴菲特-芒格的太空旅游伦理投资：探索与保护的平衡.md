#### 7.2 核心代码实现
以下是核心代码实现：

```python
import pandas as pd

def calculate_financial_score(data):
    # 计算财务评分，例如ROE（净资产收益率）
    return data['ROE'].mean()

def calculate_environmental_score(data):
    # 计算环境评分，例如碳排放量
    return data['CO2_emissions'].mean()

def calculate_social_score(data):
    # 计算社会评分，例如员工满意度
    return data['employee_satisfaction'].mean()

def investment_decision(data):
    financial_score = calculate_financial_score(data)
    environmental_score = calculate_environmental_score(data)
    social_score = calculate_social_score(data)
    
    total_score = (financial_score + environmental_score + social_score) / 3
    return total_score > 0.7

# 示例应用
data = pd.read_csv('company_data.csv')
result = investment_decision(data)
print("投资决策结果：", result)
```

#### 7.3 案例分析
假设我们有以下企业数据：

| 公司名称 | ROE | CO2_emissions | employee_satisfaction |
|----------|-----|---------------|-----------------------|
| SpaceX   | 20% | 1000          | 90                    |
| Blue Origin | 15% | 500           | 85                    |

计算结果：
- 财务评分：17.5%
- 环境评分：750
- 社会评分：87.5%

综合评分：
$$
\text{综合评分} = \frac{17.5 + 750 + 87.5}{3} = 27.75
$$

由于27.75 > 70%，投资结果为“投资”。
