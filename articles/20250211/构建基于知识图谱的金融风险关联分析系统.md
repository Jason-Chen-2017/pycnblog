## 3.2 Python 实现

### 3.2.1 核心代码
```python
def count_paths(u, v):
    # 简单的路径计数算法
    count = 0
    visited = set()
    stack = [(u, [u])]
    while stack:
        node, path = stack.pop()
        if node == v:
            count += 1
            continue
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                new_path = path + [neighbor]
                stack.append((neighbor, new_path))
    return count
```

### 3.2.2 代码解读
该代码通过深度优先搜索的方式遍历图中所有路径，统计从 u 到 v 的路径数。

### 3.2.3 示例分析
假设图谱中有节点 A、B、C，且 A 连接 B，B 连接 C，那么 count_paths(A, C) 返回 1。
