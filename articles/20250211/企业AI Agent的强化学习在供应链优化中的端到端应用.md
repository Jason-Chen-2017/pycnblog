## 第2章: 强化学习算法基础

### 2.1 Q-learning算法
- 2.1.1 Q-learning的算法流程
  - 状态-动作价值函数的更新
  - $$ Q(s,a) = Q(s,a) + \alpha (r + \gamma \max Q(s',a') - Q(s,a)) $$
- 2.1.2 Q-learning的优缺点
  - 适用场景与局限性

### 2.2 Deep Q-Network (DQN) 算法
- 2.2.1 DQN的算法框架
  - 神经网络近似Q值函数
  - 经验回放机制
- 2.2.2 DQN与Q-learning的对比
  - $$ Q(s,a) = \theta \cdot \phi(s,a) $$

### 2.3 Policy Gradient方法
- 2.3.1 Policy Gradient的核心思想
  - 直接优化策略参数
  - $$ \theta = \theta + \alpha \nabla_\theta J(\theta) $$
- 2.3.2 Policy Gradient的实现方式
  - 基于概率的策略优化

  import torch
  import torch.nn as nn
  import torch.optim as optim

  class QNetwork(nn.Module):
      def __init__(self, state_space, action_space):
          super(QNetwork, self).__init__()
          self.fc1 = nn.Linear(state_space, 64)
          self.fc2 = nn.Linear(64, action_space)

      def forward(self, x):
          x = torch.relu(self.fc1(x))
          x = self.fc2(x)
          return x

  # 初始化网络
  q_network = QNetwork(state_space, action_space)
  optimizer = optim.Adam(q_network.parameters(), lr=0.001)
