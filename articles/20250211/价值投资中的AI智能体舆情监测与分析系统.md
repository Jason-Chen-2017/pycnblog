# 第1章: 价值投资与AI智能体的结合

## 1.1 价值投资的基本概念

### 1.1.1 价值投资的定义与核心思想
- **价值投资**：一种投资策略，旨在通过分析企业基本面，找到市场价格低于其内在价值的投资标的。
- 核心思想：市场短期是投票器，长期是称重机。

### 1.1.2 价值投资的核心要素
- **内在价值**：企业未来现金流的现值。
- **安全边际**：市场价格与内在价值的差距。
- **竞争优势**：企业护城河。

### 1.1.3 价值投资与现代金融的结合
- 现代金融学提供理论框架，价值投资注重实际操作。
- 数据驱动决策成为趋势。

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import BernoulliNB
import nltk

def preprocess(text):
    # 分词处理
    words = nltk.word_tokenize(text)
    return ' '.join(words)

def train_model(train_texts, train_labels):
    # 特征提取
    vectorizer = TfidfVectorizer(preprocessor=preprocess)
    features = vectorizer.fit_transform(train_texts)
    # 模型训练
    clf = BernoulliNB()
    clf.fit(features, train_labels)
    return clf, vectorizer

# 示例数据
train_texts = ["市场表现良好", "公司业绩不佳"]
train_labels = [1, 0]

model, vectorizer = train_model(train_texts, train_labels)
```
