# 第二章：资产配置的理论基础

## 2.1 资产配置的数学模型  
资产配置的核心是优化问题，目标是最大化收益，同时最小化风险。数学模型如下：  
$$\text{目标：} \quad \max \mu^T w - \lambda \cdot w^T \Sigma w$$  
其中，$w$ 是权重向量，$\mu$ 是收益向量，$\Sigma$ 是协方差矩阵，$\lambda$ 是风险厌恶系数。

## 2.2 资产配置的核心要素  
- **收益**：不同资产的预期收益。  
- **风险**：资产之间的波动性和相关性。  
- **权重**：各资产在组合中的分配比例。  

## 2.3 伯格的分散化策略  
伯格强调分散化的重要性。通过将资金分配到多个资产类别中，可以降低非系统性风险。

# 第三章：伯格资产配置的数学模型

## 3.1 最优化问题  
在资产配置中，我们需要求解以下最优化问题：  
$$\text{目标：} \quad \max \sum_{i=1}^n w_i r_i - \lambda \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij}$$  
其中，$r_i$ 是资产 $i$ 的预期收益，$\sigma_{ij}$ 是资产 $i$ 和 $j$ 的协方差，$\lambda$ 是风险厌恶系数。

## 3.2 均值-方差优化  
均值-方差优化是资产配置的核心方法。通过计算各资产的期望收益和协方差矩阵，找到最优权重。

## 5.2 核心代码实现  
```python
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def objective(weights, mu, Sigma):
    return -weights.T.dot(mu) + 0.5 * weights.T.dot(Sigma).dot(weights)

# 约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 求解优化问题
mu = np.array([0.1, 0.05])
Sigma = np.array([[0.2, 0.1], [0.1, 0.3]])
cons = {'type': 'eq', 'fun': constraint}
bounds = [(0, 1), (0, 1)]

result = minimize(objective, [0.5, 0.5], method='SLSQP', constraints=cons, bounds=bounds)
print(result.x)
```
