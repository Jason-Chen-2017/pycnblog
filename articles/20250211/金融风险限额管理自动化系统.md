### 第2章：核心概念与联系

#### 2.1 核心概念原理
- 2.1.1 金融风险的量化方法
  - VaR模型：$$VaR = \sqrt{n \cdot \sigma^2}$$
  - CVaR模型：$$CVaR = \frac{1}{\alpha} \sum_{i=1}^{\alpha} r_i$$
- 2.1.2 限额管理的数学模型
  - 风险限额计算公式：$$ \text{限额} = \text{风险暴露} \times \text{风险系数} $$
  - 风险系数的动态调整：$$ \text{风险系数} = f(\text{市场波动性}, \text{资产类别}, \text{时间周期}) $$
- 2.1.3 自动化系统的工作流程
  - 数据采集 → 风险评估 → 限额计算 → 预警触发 → 限额调整

#### 2.2 核心概念属性对比
- 2.2.1 风险类型对比表
  | 风险类型 | 描述 | 计算方法 |
  |----------|------|----------|
  | 市场风险 | 资产价格波动导致的风险 | VaR模型 |
  | 信用风险 | 债务人违约导致的风险 | PD（违约概率）× LGD（违约损失率） |
  | 操作风险 | 操作失误或内部欺诈导致的风险 | 小损失频率 × 大损失影响 |

- 2.2.2 限额计算方法对比表
  | 方法 | 描述 | 适用场景 |
  |------|------|----------|
  | 简单比例法 | 按资产规模的比例设定限额 | 适用于低风险场景 |
  | 风险调整法 | 根据风险系数动态调整限额 | 适用于高风险场景 |
  | 复合限额法 | 综合考虑多种风险因素 | 适用于复杂资产组合 |

- 2.2.3 系统功能模块对比表
  | 功能模块 | 描述 | 输入 | 输出 |
  |----------|------|------|------|
  | 数据采集 | 采集市场数据、交易记录 | 实时数据流 | 数据库存储 |
  | 风险评估 | 计算风险指标 | 数据库数据 | 风险评估报告 |
  | 限额计算 | 计算风险限额 | 风险评估报告 | 风险限额 |
  | 预警触发 | 发出预警信号 | 风险限额 | 预警信息 |

- 3.1.2 Python源代码实现
```python
import numpy as np
import pandas as pd

def calculate_risk(data):
    # 计算VaR
    data_sorted = np.sort(data)
    alpha = 0.95
    var = data_sorted[int(alpha * len(data_sorted))]
    return var

def main():
    # 读取数据
    data = pd.read_csv('risk_data.csv')
    # 计算风险值
    risk_value = calculate_risk(data['returns'])
    print(f"VaR at 95% confidence level: {risk_value}")
    
if __name__ == "__main__":
    main()
```

- 3.1.3 数学模型与公式
  - VaR公式：$$VaR = \sqrt{n \cdot \sigma^2}$$
  - CVaR公式：$$CVaR = \frac{1}{\alpha} \sum_{i=1}^{\alpha} r_i$$

#### 3.2 限额计算算法
- 3.2.1 算法流程图

- 3.2.2 Python源代码实现
```python
def calculate_limit(risk_exposure, risk_coefficient):
    return risk_exposure * risk_coefficient

def main():
    # 示例数据
    risk_exposure = 1000000  # 风险暴露
    risk_coefficient = 0.05  # 风险系数
    limit = calculate_limit(risk_exposure, risk_coefficient)
    print(f"计算的限额为: {limit}")

if __name__ == "__main__":
    main()
```
