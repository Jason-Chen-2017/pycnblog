# 第2章: 风险预算分配模型的核心概念与原理

## 2.1 风险预算分配模型的核心概念
### 2.1.1 风险敞口的定义与分类
风险敞口是投资组合对不同风险因素的敏感程度，分为市场风险、信用风险等。

### 2.1.2 风险预算的分配逻辑
根据投资者的风险偏好和收益目标，分配各类资产的风险敞口。

### 2.1.3 模型的输入与输出
- 输入：资产类别、历史收益与风险数据、风险承受能力。
- 输出：最优资产配置、风险预算分配结果。

## 2.2 风险预算分配模型的原理
### 2.2.1 风险与收益的权衡关系
收益与风险呈正相关，需在两者之间找到平衡点。

### 2.2.2 资产类别与风险因子的关联
不同资产类别对风险因子的敏感程度不同，需通过模型进行量化。

### 2.2.3 预算分配的数学模型
$$ \text{目标函数：} \quad \min \sum_{i} w_i^2 \cdot \text{Var}(r_i) $$
$$ \text{约束条件：} \quad \sum_{i} w_i = 1, \sum_{i} w_i \cdot E(r_i) = \text{目标收益} $$

## 3.3 算法实现的Python代码示例
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_variance(weights, covariance_matrix):
    return np.dot(weights.T, np.dot(covariance_matrix, weights))

def optimize_portfolio(risk_free_rate, expected_returns, covariance_matrix):
    n = len(expected_returns)
    initial_guess = np.array([0.0] * n + [1.0])
    result = minimize(
        portfolio_variance,
        initial_guess,
        args=(covariance_matrix,),
        method='SLSQP',
        constraints=[
            {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
            {'type': 'eq', 'fun': lambda w: np.dot(w, expected_returns) - target_return}
        ]
    )
    return result.x[:n]

# 示例数据
returns = np.array([0.1, 0.2, 0.15])
covariance = np.array([[0.04, 0.02, 0.01],
                       [0.02, 0.035, 0.01],
                       [0.01, 0.01, 0.02]])
target_return = 0.15

weights = optimize_portfolio(0, returns, covariance)
print(weights)
```

# 第4章: 风险预算分配模型的数学模型

## 4.1 数学模型的构建
### 4.1.1 优化目标
$$ \text{最小化风险：} \quad \min \sum_{i} \sum_{j} w_i w_j \sigma_{ij} $$
### 4.1.2 约束条件
$$ \sum_{i} w_i = 1 $$
$$ \sum_{i} w_i r_i = R_{\text{target}} $$

## 4.2 数学模型的求解
### 4.2.1 使用拉格朗日乘数法
$$ L = \sum_{i} \sum_{j} w_i w_j \sigma_{ij} + \lambda_1 (\sum_{i} w_i - 1) + \lambda_2 (\sum_{i} w_i r_i - R_{\text{target}}) $$

### 4.2.2 对权重求导并解方程
$$ \frac{\partial L}{\partial w_k} = 2 \sum_{j} w_j \sigma_{kj} + \lambda_1 + \lambda_2 r_k = 0 $$
