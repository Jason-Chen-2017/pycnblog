**背景介绍**：
概率思维是一种通过分析随机事件的可能性来做出决策的方法。它帮助人们在信息不完全的情况下，评估不同选择的可能结果，从而优化决策质量。芒格的概率思维不仅限于数学理论，更是一种哲学思考方式，强调通过经验、直觉和逻辑推理来评估可能性。

**问题背景**：
在投资领域，不确定性无处不在。市场波动、经济周期、政策变化等因素都会影响投资结果。传统的决策方法往往依赖于确定性假设，但在实际中，这种假设往往不成立。芒格的概率思维则提供了一种更灵活的框架，帮助投资者在不确定性中找到最优解。

**问题解决**：
芒格的概率思维通过以下步骤解决问题：
1. **识别不确定性**：识别影响决策的关键因素及其不确定性。
2. **评估可能性**：分析每种可能的结果及其概率。
3. **优化决策**：基于概率评估，选择预期收益最大化的方案。

**边界与外延**：
概率思维的应用范围不仅限于投资领域，还包括医疗诊断、工程设计、风险管理等多个方面。其核心在于通过概率分析，将复杂的不确定性转化为可操作的决策依据。

### 第2章：概率的基本概念与工具

#### 2.1 概率的基本概念

**背景介绍**：
概率论是概率思维的数学基础。概率是用来度量某件事情发生的可能性，从0（绝对不可能）到1（绝对可能）。

**核心概念**：
- **随机事件**：在相同条件下，可能有多种结果的事件。
- **概率空间**：所有可能结果的集合，及其概率分布。
- **独立事件**：两个事件的发生互不影响。

**公式与代码示例**：
- 计算简单事件的概率：$P(A) = \frac{\text{成功事件数}}{\text{总事件数}}$

```python
def calculate_probability(successes, trials):
    return successes / trials
```

#### 2.2 贝叶斯定理

**背景介绍**：
贝叶斯定理是一种用于更新概率的工具，基于先验概率和新证据，计算后验概率。

**公式推导**：
$$ P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)} $$

**应用案例**：
假设疾病A的患病率为1%，检测方法的准确性为99%，假阳性率为2%。计算一个检测为阳性的个体实际患病的概率。

**代码实现**：
```python
def bayes_theorem(p_a, p_b_given_a, p_b_given_not_a, p_not_a):
    p_b = p_b_given_a * p_a + p_b_given_not_a * p_not_a
    return (p_b_given_a * p_a) / p_b
```

#### 3.2 蒙特卡洛模拟

**背景介绍**：
蒙特卡洛模拟是一种通过随机采样来估计概率分布的方法，广泛应用于复杂系统的建模。

**原理与实现**：
$$ P(X \leq x) \approx \frac{\text{样本中满足} X \leq x \text{的数目}}{\text{总样本数}} $$

**代码示例**：
```python
import numpy as np
import matplotlib.pyplot as plt

# 生成10000个随机数，均值为0，标准差为1
samples = np.random.normal(0, 1, 10000)
plt.hist(samples, bins=30, density=True)
plt.show()
```
