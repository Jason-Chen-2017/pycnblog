# 第1章: 通胀挂钩债券的核心概念与背景

## 1.1 通胀挂钩债券的定义与特点

### 1.1.1 通胀挂钩债券的定义

通胀挂钩债券（Inflation-Linked Bonds）是一种特殊的债券类型，其本金或利息与通货膨胀率挂钩。与传统债券不同，通胀挂钩债券能够根据通胀水平调整收益，从而在通胀上升时保护投资者的购买力。

### 1.1.2 通胀挂钩债券的核心特点

1. **本金调整**：通胀挂钩债券的本金会根据通胀水平定期调整，通常每年或每五年调整一次。
2. **利息调整**：债券的票面利率与通胀挂钩，利息也会随通胀变化而调整。
3. **通胀对冲**：通过与通胀挂钩，投资者的收益能够部分抵消通胀带来的购买力损失。
4. **风险较低**：相比股票等高风险资产，通胀挂钩债券的风险较低，适合保守型投资者。

### 1.1.3 通胀挂钩债券与传统债券的区别

| 特性         | 传统债券           | 通胀挂钩债券       |
|--------------|--------------------|--------------------|
| 本金调整     | 固定               | 根据通胀调整        |
| 利息调整     | 固定               | 根据通胀调整        |
| 风险         | 利率风险为主         | 利率风险和通胀风险   |
| 通胀影响     | 通胀可能导致损失     | 部分对冲通胀影响     |

## 1.2 通胀对购买力的影响

### 1.2.1 通货膨胀的经济学原理

通货膨胀是指物价总水平在一段时间内持续上涨，导致货币购买力下降。通胀通常由需求拉动、成本推动或货币供应增加等因素引起。

### 1.2.2 通胀对固定收益资产的影响

1. **本金贬值**：通胀导致物价上涨，债券本金的实际购买力下降。
2. **利息贬值**：固定利率债券的利息在通胀环境下实际价值下降。
3. **再投资风险**：通胀上升可能导致债券收益率上升，但再投资时可能面临更高通胀的风险。

### 1.2.3 通胀对个人和机构购买力的威胁

- 对个人：生活成本增加，固定收入的实际购买力下降。
- 对机构：运营成本增加，利润被通胀侵蚀。
