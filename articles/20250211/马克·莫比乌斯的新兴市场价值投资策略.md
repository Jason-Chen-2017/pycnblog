## 第1章: 价值投资与新兴市场的背景介绍

### 1.1 价值投资的核心概念

#### 1.1.1 价值投资的定义与核心要素
价值投资是一种以基本面分析为基础的投资策略，其核心在于寻找市场价格低于其内在价值的资产。核心要素包括：
1. **内在价值**：资产的真实价值，通常通过 discounted cash flow（DCF）模型计算。
2. **安全边际**：市场价格与内在价值之间的差异，提供风险缓冲。
3. **长期视角**：关注企业的长期盈利能力，而非短期价格波动。

#### 1.1.2 新兴市场的定义与特点
新兴市场是指经济快速发展但尚未完全 industrialized 的国家市场，其特点包括：
1. **高增长潜力**：新兴市场的GDP增速通常高于发达市场。
2. **市场流动性较低**：部分新兴市场的交易量和流动性有限。
3. **政策风险较高**：新兴市场国家的政策变化可能对市场产生较大影响。

#### 1.1.3 价值投资在新兴市场的适用性
新兴市场中，价值投资的适用性主要体现在：
- **低估机会**：新兴市场中许多企业由于信息不对称或市场关注度低，市场价格可能低于内在价值。
- **分散投资风险**：通过在新兴市场中分散投资，可以降低整体投资组合的风险。

### 1.2 马克·莫比乌斯与新兴市场投资

#### 1.2.1 马克·莫比乌斯的背景与投资理念

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 数据获取与处理
data = pd.read_csv('emerging_market_data.csv')
data = data.dropna()

# 量化分析
def calculate_value(ticker):
    # 计算内在价值
    cash_flow = data[data['Ticker'] == ticker]['Cash Flow'].values[0]
    discount_rate = 0.08
    intrinsic_value = cash_flow / (1 + discount_rate)
    return intrinsic_value

# 投资决策
selected_tickers = []
for ticker in data['Ticker']:
    if calculate_value(ticker) > data[data['Ticker'] == ticker]['Price'].values[0]:
        selected_tickers.append(ticker)

print(selected_tickers)
