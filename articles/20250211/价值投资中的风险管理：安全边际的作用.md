### 第1章: 价值投资与风险管理概述

#### 1.1 投资的基本概念

投资是指将资金投入到某个项目或资产中，以期望在未来获得收益或资本增值的行为。投资可以分为多种类型，如股票、债券、房地产等。每种投资都有其独特的风险和收益特征。

#### 1.2 风险管理的核心概念

风险管理是指识别、评估和应对投资中的潜在风险，以确保投资目标的实现。风险可以是市场风险、流动性风险、信用风险等。风险管理的目标是在风险和收益之间找到最佳平衡点。

#### 1.3 价值投资中的风险管理特点

价值投资强调以低于内在价值的价格购买优质资产。风险管理在价值投资中至关重要，因为市场价格波动可能会影响投资组合的表现。安全边际是价值投资者用来保护自己免受市场波动影响的重要工具。

### 第2章: 安全边际的核心概念与原理

#### 2.1 安全边际的定义

安全边际是指内在价值与市场价格之间的差异，即 $ \text{安全边际} = \text{内在价值} - \text{市场价格} $。这个差异提供了投资者在市场价格波动时的保护空间。

#### 2.2 安全边际的属性特征对比

以下是安全边际与其他风险管理工具的对比表格：

| 特性          | 安全边际               | 市场价格波动对冲工具 |
|---------------|-----------------------|----------------------|
| 目标          | 确保内在价值的安全性   | 投资收益最大化       |
| 工具          | 内在价值评估           | 金融衍生品           |
| 使用场景      | 长期价值投资           | 短期对冲风险         |

def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(cash_flow / (1 + discount_rate) ** t for t, cash_flow in enumerate(cash_flows))

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

# 示例
cash_flows = [100, 100, 100]  # 假设现金流
discount_rate = 0.05
market_price = 80

intrinsic_value = calculate_intrinsic_value(cash_flows, discount_rate)
margin_of_safety = calculate_margin_of_safety(intrinsic_value, market_price)

print(f"内在价值: {intrinsic_value}")
print(f"安全边际: {margin_of_safety}")
