#### 1.2 价值投资的核心概念与公式背景
- **内在价值的定义与计算公式**
  - 内在价值是企业未来现金流的现值
  - $$ V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} $$
- **安全边际的内涵与作用**
  - 安全边际 = 内在价值 - 市场价格
  - $$ S = V - P $$
  - 安全边际的意义：降低投资风险，确保收益的可预测性

### 第3章: 格雷厄姆公式在Python中的实现

#### 3.1 内在价值计算的Python代码实现
```python
def calculate_intrinsic_value(enterprise_future_cash_flow, discount_rate):
    """
    计算企业的内在价值，基于未来现金流的现值法
    Args:
        enterprise_future_cash_flow (list): 未来各期的现金流
        discount_rate (float): 折现率
    Returns:
        float: 内在价值
    """
    present_value = 0
    for t in range(len(enterprise_future_cash_flow)):
        cf = enterprise_future_cash_flow[t]
        pv = cf / (1 + discount_rate) ** (t + 1)
        present_value += pv
    return present_value

# 示例：计算某企业的内在价值
enterprise_future_cash_flow = [100, 150, 200, 250]  # 单位：万元
discount_rate = 0.10  # 折现率10%
intrinsic_value = calculate_intrinsic_value(enterprise_future_cash_flow, discount_rate)
print(f"内在价值为：{intrinsic_value:.2f} 万元")
```

#### 3.2 安全边际的Python代码实现
```python
def calculate_margin_of_safety(intrinsic_value, market_price):
    """
    计算安全边际
    Args:
        intrinsic_value (float): 内在价值
        market_price (float): 市场价格
    Returns:
        float: 安全边际
    """
    margin_of_safety = intrinsic_value - market_price
    return margin_of_safety

# 示例：计算某企业的安全边际
intrinsic_value = 1000  # 内在价值
market_price = 800      # 市场价格
margin_of_safety = calculate_margin_of_safety(intrinsic_value, market_price)
print(f"安全边际为：{margin_of_safety} 万元")
```
