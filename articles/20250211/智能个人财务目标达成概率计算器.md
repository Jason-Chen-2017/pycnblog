### 3.3.2 Python实现代码
```python
import numpy as np
from sklearn.naive_bayes import GaussianNB

# 示例数据
X = np.array([[25000, 20000, 10000],
              [30000, 25000, 15000],
              [35000, 30000, 20000]])

y = np.array([1, 0, 1])  # 1代表达成，0代表未达成

# 训练模型
model = GaussianNB()
model.fit(X, y)

# 预测概率
test_sample = np.array([[30000, 25000, 18000]])
prob = model.predict_proba(test_sample)
print("预测概率:", prob)
```
