### 3.1.2 Python代码实现

```python
import numpy as np

def detect_anomalies(data, threshold=3):
    mean = np.mean(data)
    std = np.std(data)
    anomalies = []
    for point in data:
        z_score = (point - mean) / std
        if abs(z_score) > threshold:
            anomalies.append(point)
    return anomalies
```

### 3.1.3 数学模型

异常检测统计量：$$ z = \frac{x - \mu}{\sigma} $$

## 4.1 统计模型

### 4.1.1 正态分布模型
概率密度函数：$$ f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} $$

### 4.1.2 假设检验
Z检验：$$ z = \frac{\bar{x} - \mu}{\sigma/\sqrt{n}} $$

## 4.2 机器学习模型

### 4.2.1 支持向量机
目标函数：$$ \min_{\theta} \frac{1}{2}\|\theta\|^2 + C\sum_{i=1}^n \max(0, 1 - y_i\theta^T x_i - \theta_0) $$

### 4.2.2 随机森林
