## 第1章：周期调整市盈率的背景与理论基础

### 1.1 罗伯特·希勒与周期调整市盈率的提出

#### 1.1.1 罗伯特·希勒的学术背景与贡献

罗伯特·希勒（Robert Shiller）是耶鲁大学的经济学家，以其在金融市场和行为经济学领域的研究闻名。他提出了许多重要的金融指标和理论，其中最著名的之一就是周期调整市盈率（CAPE）。希勒的研究不仅推动了金融学的发展，还为投资者提供了新的工具来评估市场价值。

#### 1.1.2 市盈率指标的局限性与改进需求

传统的市盈率（P/E）是用当前股价除以最近一个会计年度的每股盈利（EPS）计算得出的。然而，市盈率有几个明显的局限性：
- **短期性**：市盈率只考虑了过去一年的盈利数据，无法反映更长周期的市场表现。
- **波动性**：市场波动可能导致市盈率在短期内偏离长期趋势。
- **周期性影响**：市盈率容易受到经济周期波动的影响，难以准确衡量市场的长期价值。

#### 1.1.3 周期调整市盈率的提出动机与目标

为了解决上述问题，希勒提出了周期调整市盈率（CAPE），其目标是通过考虑更长周期的盈利数据来消除短期波动的影响，从而更准确地衡量市场的长期价值。CAPE的核心思想是使用过去10年的平均盈利数据来计算市盈率，从而反映市场的长期趋势。

---

### 1.2 周期调整市盈率的核心概念与定义

#### 1.2.1 市盈率的定义与计算方法

市盈率（P/E）的公式为：
$$ P/E = \frac{\text{股价}}{\text{每股盈利}} $$

然而，市盈率的局限性在于它只考虑了最近一年的盈利数据。

#### 1.2.2 周期调整市盈率（CAPE）的定义

周期调整市盈率（CAPE）的公式为：
$$ \text{CAPE} = \frac{\text{股价}}{\text{过去10年的平均实际盈利}} \times 1.5 $$

其中，过去10年的平均实际盈利需要通过GDP平减指数进行通货膨胀调整。

#### 1.2.3 市盈率与周期调整市盈率的对比分析

| 指标 | 市盈率（P/E） | 周期调整市盈率（CAPE） |
|------|----------------|------------------------|
| 数据范围 | 最近一年盈利 | 过去10年平均盈利（通货膨胀调整） |
| 优点 | 简单易懂，反映短期市场情绪 | 反映长期市场趋势，减少短期波动干扰 |
| 缺点 | 易受短期波动影响，周期性较强 | 计算复杂，数据获取难度较高 |

### 1.3 周期调整市盈率的理论基础与应用范围

#### 1.3.1 市场周期波动对市盈率的影响

经济周期波动会影响企业的盈利能力和股价表现。在经济繁荣时期，企业盈利上升，股价可能被高估；在经济衰退时期，企业盈利下降，股价可能被低估。CAPE通过考虑过去10年的平均盈利，能够更好地反映市场在不同周期中的表现。

#### 1.3.2 长期价值投资的核心理念

长期价值投资的核心理念是寻找那些能够持续创造价值的企业，并在市场低估时买入，在市场高估时卖出。CAPE作为一种长期价值评估指标，能够帮助投资者更好地判断市场的整体估值水平。

#### 1.3.3 周期调整市盈率在投资决策中的作用

CAPE在投资决策中的作用主要体现在以下几个方面：
- **市场估值判断**：通过比较当前的CAPE值与历史平均水平，判断市场是否被高估或低估。
- **投资组合调整**：当市场被高估时，减少股票配置；当市场被低估时，增加股票配置。
- **风险管理**：通过CAPE的变化趋势，提前预警市场风险。

周期调整市盈率（CAPE）的数学模型如下：

#### 4.1.2 系统核心代码实现

以下是Python代码实现：

```python
import pandas as pd
import numpy as np
import requests
import datetime

def get_data(ticker):
    today = datetime.date.today()
    start_date = today - datetime.timedelta(days=10*365)
    end_date = today
    url = f"https://query1.finance.yahoo.com/v8/finance/chart/{ticker}?period1={start_date.timestamp()}&period2={end_date.timestamp()}"
    response = requests.get(url)
    data = response.json()
    prices = data['chart']['result'][0]['prices']
    df = pd.DataFrame(prices)
    df['date'] = df['time'].apply(lambda x: datetime.datetime.utcfromtimestamp(x).date())
    df.set_index('date', inplace=True)
    df = df[['open', 'high', 'low', 'close', 'volume']]
    return df

def calculate_cape(ticker):
    df = get_data(ticker)
    eps_data = df['close'].rolling(365).mean().iloc[-1]
    gdp_deflator = 1.5  # 示例中使用固定值，实际应从官方数据获取
    adjusted_eps = eps_data / gdp_deflator
    cape = df['close'][-1] / adjusted_eps
    return cape

ticker = "SPY"
print(f"周期调整市盈率（CAPE）：{calculate_cape(ticker)}")
```
