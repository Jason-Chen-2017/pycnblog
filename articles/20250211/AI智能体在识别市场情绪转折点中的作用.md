## 第1章 AI智能体与市场情绪概述

### 1.1 市场情绪与金融市场的基本概念
#### 1.1.1 市场情绪的定义与特征
市场情绪是金融市场参与者对市场走势的心理预期，通常表现为乐观、悲观、中立等状态。市场情绪具有波动性、传染性、滞后性和周期性等特点。

#### 1.1.2 市场情绪在金融中的作用
市场情绪直接影响投资者的决策行为，进而影响资产价格波动。情绪化决策可能导致市场泡沫或崩盘，是金融市场的重要研究对象。

#### 1.1.3 市场情绪转折点的定义与重要性
市场情绪转折点是指市场情绪从上升转为下降或从下降转为上升的关键时间点。识别转折点对投资者来说具有重要意义，有助于提前做出投资决策。

### 1.2 AI智能体的基本概念
#### 1.2.1 AI智能体的定义与分类
AI智能体是一种具有感知、决策和行动能力的智能系统，分为反应式和基于模型的智能体。

#### 1.2.2 AI智能体的核心能力
AI智能体具备数据感知、信息处理、决策制定和自主学习的能力。

AI智能体可以通过分析海量数据，识别市场情绪变化，帮助投资者做出更明智的决策。

import numpy as np

def detect_turning_point(data):
    # 假设data为情绪指数序列
    diff = np.diff(data)
    turning_points = np.where(np.abs(diff) > np.mean(np.abs(diff)))[0]
    return turning_points
