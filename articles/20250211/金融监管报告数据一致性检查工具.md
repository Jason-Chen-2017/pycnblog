### 第3章: 数据清洗与匹配算法

#### 3.1 数据清洗算法
- **基于规则的清洗算法**：通过预定义规则（如正则表达式）过滤无效数据。
  ```python
  def rule_based_cleaning(data):
      cleaned_data = []

          if re.match(r'^\d+$', item):
              cleaned_data.append(item)

  ```
- **基于机器学习的清洗算法**：使用聚类算法识别异常值。
  ```python
  def ml_cleaning(data):
      from sklearn.cluster import KMeans
      model = KMeans(n_clusters=2).fit(data)
      cleaned_data = model.predict(data)
      return cleaned_data
  ```

#### 3.2 数据匹配算法
- **基于字符串匹配的算法**：使用编辑距离（Levenshtein距离）匹配相似字符串。
  ```python
  def levenshtein_distance(s1, s2):
      m = len(s1)
      n = len(s2)
      # 创建二维数组存储子问题结果
      dp = [[0]*(n+1) for _ in range(m+1)]
      for i in range(m+1):
          for j in range(n+1):
              if i == 0:
                  dp[i][j] = j
              elif j == 0:
                  dp[i][j] = i
              else:
                  dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]+1)
      return dp[m][n]
  ```

#### 3.3 算法实现的代码示例
```python
def data_cleaning(data):
    cleaned_data = []
    for item in data:
        if isinstance(item, str) and len(item) > 0:
            cleaned_data.append(item.strip().lower())
        else:
            cleaned_data.append(item)
    return cleaned_data

def data_matching(data1, data2):
    matched_pairs = []
    for item1 in data1:
        for item2 in data2:
            if levenshtein_distance(item1, item2) <= 2:
                matched_pairs.append((item1, item2))
    return matched_pairs
```

#### 5.2 核心实现代码

```python
import pandas as pd
from sklearn.metrics.pairwise import pairwise_distances

def clean_and_match(data1, data2):
    # 数据清洗
    cleaned_data1 = data1.apply(lambda x: x.strip().lower())
    cleaned_data2 = data2.apply(lambda x: x.strip().lower())
    
    # 数据匹配
    distances = pairwise_distances(cleaned_data1, cleaned_data2)
    matched_pairs = []
    for i in range(distances.shape[0]):
        for j in range(distances.shape[1]):
            if distances[i][j] <= 2:
                matched_pairs.append((cleaned_data1.iloc[i], cleaned_data2.iloc[j]))
    return matched_pairs
```
