### 第1章：投资的基本定义

#### 1.1 投资的定义与分类

投资是将资金投入到特定资产或项目中，以期获得未来收益的行为。根据投资目标的不同，可以将投资分为以下几类：

- **防御型投资**：注重本金的安全性和稳定的收益，适合风险厌恶型投资者。
- **进攻型投资**：追求高收益，通常伴随着较高的风险。
- **长期投资**：注重资产的长期增值，通常需要较长的时间 horizon。
- **短期投资**：注重资产的短期收益，通常伴随着较高的流动性需求。

防御型投资的核心在于保护本金，避免在市场波动中遭受重大损失，同时通过合理配置资产实现稳定的收益。

---

#### 1.2 防御型投资的背景与特点

防御型投资的背景可以追溯到20世纪30年代的经济大萧条时期。当时，许多投资者因盲目追求高收益而遭受巨大损失，格雷厄姆通过研究和实践，提出了防御型投资的理念，强调安全边际和稳健收益。

防御型投资的特点包括：

- **注重安全边际**：在购买资产时，确保其价格远低于其内在价值，从而降低风险。
- **低风险偏好**：避免高风险资产，选择具有稳定收益的资产。
- **长期稳健**：通过长期持有优质资产，实现收益的稳步增长。

格雷厄姆是价值投资的鼻祖，他强调以低于内在价值的价格买入优质资产。他的核心思想包括：

import pandas as pd

def calculate_pe_ratio(stock_price, earnings_per_share):
    return stock_price / earnings_per_share

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price
