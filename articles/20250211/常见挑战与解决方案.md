#### 3.3 算法实现与优化
- **排序算法实现**  
  Python代码示例：
  ```python
  def bubble_sort(arr):
      n = len(arr)
      for i in range(n):
          for j in range(0, n-i-1):
              if arr[j] > arr[j+1]:
                  arr[j], arr[j+1] = arr[j+1], arr[j]
      return arr
  ```
- **搜索算法优化**  
  示例代码：
  ```python
  def depth_first_search(graph, start):
      visited = set()
      stack = [start]
      while stack:
          node = stack.pop()
          if node not in visited:
              visited.add(node)
              stack.extend(graph[node])
      return visited
  ```
- **动态规划案例**  
  数学模型：
  $$f(n) = f(n-1) + f(n-2)$$
  其中，$f(0) = 0$，$f(1) = 1$。
