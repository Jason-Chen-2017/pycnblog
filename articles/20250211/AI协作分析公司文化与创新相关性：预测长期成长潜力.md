- 应用：文化与创新的关联分析。

### 4.2 算法流程
```mermaid

    A[开始] --> B[数据预处理]
```

### 4.3 算法实现
```python
from mlxtend.frequent_itemsets import apriori

data = ...  # 输入数据
frequent_itemsets = apriori(data, min_support=0.2, use_colnames=True)
```

### 4.4 数学模型
- 支持度：$support(X) = \frac{\text{count}(X)}{\text{total}}$
- 置信度：$confidence(X \rightarrow Y) = \frac{\text{support}(X \cup Y)}{\text{support}(X)}$
