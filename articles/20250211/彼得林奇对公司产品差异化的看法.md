- 产品差异化的评估公式：$$D = \frac{P - C}{P} \times 100\%$$，其中D为差异化程度，P为产品价格，C为成本

  def calculate_differential(product_price, cost):
      return ((product_price - cost) / product_price) * 100

  # 示例数据

  cost = 50
  differential = calculate_differential(product_price, cost)
