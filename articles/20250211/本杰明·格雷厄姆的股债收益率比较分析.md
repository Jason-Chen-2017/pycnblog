## 第1章：股债收益率比较分析概述

### 1.1 股债收益率比较的核心概念

#### 1.1.1 股票收益率的定义与计算方法
股票收益率衡量投资者持有股票的收益，通常有两种计算方式：
- **股息率**：$股息率 = \frac{每股股息}{股价} \times 100\%$
- **资本利得收益率**：$资本利得收益率 = \frac{最终售价 - 买入价格}{买入价格} \times 100\%$

#### 1.1.2 债券收益率的定义与计算方法
债券收益率包括：
- **到期收益率（YTM）**：考虑债券的面值、当前价格、票面利率和剩余期限。
- **当前收益率**：$当前收益率 = \frac{年利息}{债券价格} \times 100\%$

#### 1.1.3 股债收益率比较的背景与意义
随着市场波动，投资者需要比较股债收益率以优化资产配置。本杰明·格雷厄姆强调长期稳健的投资，股债比较帮助识别低风险高收益的机会。

### 1.2 股债收益率比较的必要性

#### 1.2.1 投资者资产配置的需求
投资者需平衡风险与收益，通过比较股债收益率，合理配置资产。

#### 1.2.2 不同资产类别风险与收益的平衡
股票高风险高收益，债券低风险相对稳定，比较收益率助投资者选择适合策略。

#### 1.2.3 股债收益率比较的现实意义
经济周期变化影响股债表现，比较收益率帮助投资者在不同环境下做出最优选择。

## 第2章：股股票收益率与债券收益率的计算方法

### 2.1 股票收益率的计算

#### 2.1.1 股票收益率的定义
股票收益率包括股息收益和资本收益，影响投资者的总体收益。

#### 2.1.2 股票收益率的计算公式
- 股息率：$股息率 = \frac{每股股息}{股价} \times 100\%$
- 资本利得收益率：$资本利得收益率 = \frac{最终股价 - 购买股价}{购买股价} \times 100\%$

#### 2.1.3 股票收益率的类型与特点
股票收益率波动大，受市场情绪和公司业绩影响，高风险高收益。

### 2.2 债券收益率的计算

#### 2.2.1 债券收益率的定义
债券收益率反映债券的投资回报，考虑票面利率、期限和市场价格。

#### 2.2.2 债券收益率的计算公式
- 到期收益率（YTM）：$YTM = \frac{C + \frac{F - P}{n}}{P}$，其中$C$为年利息，$F$为面值，$P$为市场价格，$n$为剩余期限。
- 当前收益率：$当前收益率 = \frac{C}{P} \times 100\%$

#### 2.2.3 债券收益率的类型与特点
债券收益率相对稳定，适合风险厌恶型投资者，收益较低但风险可控。

### 2.3 股债收益率比较的数学模型

#### 2.3.1 股票收益率与债券收益率的对比公式
比较两者的收益率，选择较高的投资标的，同时考虑风险因素。

#### 2.3.2 股债收益率比较的数学模型

#### 2.3.3 股债收益率比较的边界条件

#### 3.1.2 股票收益率计算的代码实现

def calculate_stock_return(prices, dividends):
    stock_prices = [prices[i+1]/prices[i] for i in range(len(prices)-1)]
    stock_return = sum(stock_prices) / len(stock_prices)
    dividend_yield = sum(dividends) / prices[-1] * 100
    return stock_return, dividend_yield
```

import pandas as pd
import numpy as np

def calculate_stock_yield(prices, dividends):
    stock_returns = []
    for i in range(len(prices)-1):
        return_ = (prices[i+1] - prices[i]) / prices[i]
        stock_returns.append(return_)
    avg_stock_return = np.mean(stock_returns)
    total_dividends = sum(dividends)
    stock_dividend_yield = (total_dividends / prices[-1]) * 100
    return avg_stock_return, stock_dividend_yield
```
