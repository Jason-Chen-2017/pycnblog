## 第二部分：核心概念与联系

### 第2章：知识图谱的核心概念

#### 2.1 知识图谱的定义与原理
- 2.1.1 知识图谱的定义
  - 知识图谱是一种图结构，由节点和边组成，节点表示实体，边表示关系。
  - 示例：股票与公司之间的关系。

- 2.1.2 知识图谱的构建过程
  - 数据采集、清洗、抽取、构建和存储。

- 2.1.3 知识图谱的表示方法
  - 使用RDF三元组表示：（主语，谓词，宾语）。

#### 2.2 实体与关系
- 2.2.1 实体的定义
  - 实体是现实世界中的具体事物，例如公司、股票、市场。
  - 示例：苹果公司（Apple）是一个实体。

- 2.2.2 关系的定义
  - 关系描述了实体之间的关联，例如“投资”、“影响”。
  - 示例：苹果公司投资于某家初创公司。

- 2.2.3 实体与关系的对比
  - 实体是独立的，关系是连接实体的桥梁。

#### 2.3 知识图谱的属性特征对比
- 2.3.1 实体的属性特征
  - 名词性：实体通常为名词。
  - 独立性：实体可以独立存在。
  - 关联性：实体之间通过关系连接。

- 2.3.2 关系的属性特征
  - 动词性：关系通常为动词或动词短语。
  - 依赖性：关系依赖于实体。
  - 方向性：关系可能有方向。

#### 3.4 实体识别的 Python 实现

```python
import spacy

# 加载预训练模型
nlp = spacy.load("en_core_web_sm")

# 定义实体识别函数
def identify_entities(text):
    doc = nlp(text)
    entities = []
    for ent in doc.ents:
        entities.append((ent.text, ent.label_))
    return entities

# 示例
text = "Apple invests in Tesla."
result = identify_entities(text)
print(result)
```

#### 3.5 关系抽取的数学模型

- 3.5.1 简单的数学模型
  - 示例：计算两个实体之间的相似度。
  - 公式：$similarity(s, o) = \frac{1}{1 + |s - o|}$，其中 $s$ 和 $o$ 是实体的向量表示。

- 3.5.2 使用 Word2Vec 的关系抽取
  - 示例：计算两个实体之间的余弦相似度。
