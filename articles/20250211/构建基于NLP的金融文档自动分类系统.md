# 第三部分: 算法原理

## 第4章: 常见的金融分类算法与实现

### 4.1 支持向量机（SVM）
#### 4.1.1 算法原理
- SVM的几何解释
- 软边距与核函数

#### 4.1.2 优化问题
$$ \text{目标函数: } \min_{w,b,\xi} \frac{1}{2}||w||^2 + C \sum_{i=1}^n \xi_i $$
$$ \text{约束条件: } y_i(w \cdot x_i + b) \geq 1 - \xi_i, \xi_i \geq 0 $$

#### 4.1.3 算法流程
```mermaid
graph TD
    A[数据预处理] --> B[特征提取]
    B --> C[选择核函数]
    C --> D[训练模型]
    D --> E[模型优化]
```

### 4.2 卷积神经网络（CNN）
#### 4.2.1 算法原理
- 卷积层、池化层的作用
- 文本CNN的结构特点

#### 4.2.2 优化问题
$$ \text{损失函数: } \mathcal{L} = -\sum_{i=1}^n y_i \log(p_i) + (1-y_i)\log(1-p_i) $$
$$ \text{优化目标: } \min_{\theta} \mathcal{L} + \lambda ||\theta||^2 $$`

#### 4.2.3 算法流程
```mermaid
graph TD
    A[输入文本] --> B[嵌入层]
    B --> C[卷积层]
    C --> D[池化层]
    D --> E[全连接层]
    E --> F[输出结果]
```

### 4.3 循环神经网络（RNN）
#### 4.3.1 算法原理
- RNN的循环结构
- 长短期记忆网络（LSTM）的优势

#### 4.3.2 优化问题
$$ \text{损失函数: } \mathcal{L} = -\sum_{t=1}^T y_t \log(p_t) + (1-y_t)\log(1-p_t) $$
$$ \text{优化目标: } \min_{\theta} \mathcal{L} + \lambda ||\theta||^2 $$`

#### 4.3.3 算法流程
```mermaid

    C --> D[全连接层]

import jieba

def preprocess(text):
    # 分词
    words = jieba.lcut(text)
    # 去停用词
    stopwords = set()
    filtered_words = [word for word in words if word not in stopwords]
    return ' '.join(filtered_words)
```
