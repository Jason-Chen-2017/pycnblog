#### 1.1 经济周期的定义与特征

经济周期是指经济活动的波动，通常分为四个阶段：衰退、复苏、繁荣和衰退。经济周期的特征包括波动性、周期性、不确定性和复杂性。投资策略需根据经济周期的变化进行调整。

#### 1.2 巴菲特投资理念的核心要素

巴菲特的价值投资强调长期持有优质资产，寻找具有安全边际的投资机会。他的投资策略基于基本面分析和长期视角，注重公司内在价值和管理层质量。

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_variance(weights, covariance_matrix):
    return np.dot(weights.T, np.dot(covariance_matrix, weights))

cov_matrix = np.array([[0.01, 0.005], [0.005, 0.02]])
initial_guess = [0.5, 0.5]
result = minimize(portfolio_variance, initial_guess, args=cov_matrix, method='SLSQP')
print(result.x)
```
