## 4.2 系统核心实现
### 4.2.1 核心代码实现
```python
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 数据加载
data = pd.read_csv('pension_gap.csv')

# 数据预处理
data.dropna(inplace=True)
data['income'] = (data['income'] - data['income'].mean()) / data['income'].std()

# 模型训练
model = LinearRegression()
model.fit(data[['age', 'income']], data['pension_gap'])

# 模型预测
predicted_gap = model.predict(data[['age', 'income']])

# 模型评估
mse = mean_squared_error(data['pension_gap'], predicted_gap)
print(f"均方误差：{mse}")
```

### 4.2.2 代码应用解读与分析
- 数据加载：读取CSV文件。
- 数据预处理：处理缺失值，标准化收入数据。
- 模型训练：使用线性回归模型。
- 模型预测：基于训练好的模型进行预测。
- 模型评估：计算均方误差，评估模型性能。
