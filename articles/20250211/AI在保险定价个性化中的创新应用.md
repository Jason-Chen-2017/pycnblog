## 第6章：项目实战

### 6.1 环境配置

- **数据准备**：获取保险数据集，清洗和预处理。

### 6.2 核心代码实现

```python
import pandas as pd
from sklearn.model import LinearRegression

# 数据预处理
data = pd.read_csv('insurance.csv')
X = data[['age', 'sex', 'bmi', 'children', 'smoker', 'region']]
y = data['charges']

# 特征工程
from sklearn.preprocessing import OneHotEncoder
encoder = OneHotEncoder().fit(X[['sex', 'smoker', 'region']])
encoded_features = encoder.transform(X[['sex', 'smoker', 'region']]).toarray()
X_encoded = pd.concat([X[['age', 'bmi', 'children']], pd.DataFrame(encoded_features)], axis=1)

# 模型训练
model = LinearRegression()
model.fit(X_encoded, y)

# 模型预测
new_claim = X_encoded.iloc[0]
prediction = model.predict(new_claim.reshape(1, -1))
print(prediction)
```
