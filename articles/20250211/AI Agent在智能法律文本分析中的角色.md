# 第4章: 法律文本分析的算法原理

## 4.1 预训练语言模型的微调

### 4.1.1 微调流程
```mermaid
graph TD
    A[预训练模型] --> B[法律文本数据]
    B --> C[微调]
    C --> D[法律文本分析模型]
```

### 4.1.2 微调的数学模型
$$L = \sum_{i=1}^{n} (y_i - y_{\text{pred}}_i)^2$$
其中，\(L\) 是损失函数，\(y_i\) 是真实标签，\(y_{\text{pred}}_i\) 是预测标签。

## 4.2 监督学习算法

### 4.2.1 监督学习流程
```mermaid
graph TD
    A[输入文本] --> B[特征提取]
    B --> C[分类器]
    C --> D[输出结果]
```

### 4.2.2 分类器的数学模型
$$P(y|x) = \frac{e^{x^T w_y + b_y}}{\sum_{k=1}^{K} e^{x^T w_k + b_k}}$$
其中，\(P(y|x)\) 是给定输入\(x\)时标签\(y\)的概率，\(w_y\) 和 \(b_y\) 是参数。
