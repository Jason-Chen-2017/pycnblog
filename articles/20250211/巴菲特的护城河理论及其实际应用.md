**附录A：护城河强度指数计算公式**

$$
\text{护城河强度指数} = \sum_{i=1}^{n} w_i \times f_i
$$

其中，\(w_i\) 是第i个因素的权重，\(f_i\) 是第i个因素的特征值。

**附录B：Python代码示例**

```python
import pandas as pd
import numpy as np

# 加载数据
data = pd.read_csv('企业数据.csv')

# 数据预处理
data_clean = data.dropna()
data_clean = data_clean[~data_clean['行业'].str.contains('金融')]

# 提取特征
features = ['市场份额', '成本优势', '品牌优势', '网络效应', '法律优势']
target = '护城河强度'

# 计算护城河强度指数
data_clean['护城河强度'] = np.zeros(len(data_clean))
for i in range(len(data_clean)):
    # 权重分配
    weights = [0.3, 0.2, 0.2, 0.2, 0.1]
    # 特征值标准化
    normalized_features = data_clean[features].iloc[i] / data_clean[features].max()
    # 计算强度
    intensity = sum([weights[j] * normalized_features[j] for j in range(len(weights))])
    data_clean.loc[i, '护城河强度'] = intensity

# 可视化
import matplotlib.pyplot as plt
data_clean[['护城河强度']].hist(bins=10)
plt.show()
```
