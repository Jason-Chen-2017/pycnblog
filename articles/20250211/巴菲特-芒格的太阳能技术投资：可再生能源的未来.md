## 第三部分: 太阳能技术投资的算法原理

### 第5章: 太阳能项目评估的数学模型

#### 5.1 净现值（NPV）模型
净现值（Net Present Value, NPV）是评估投资项目盈利能力的重要指标。公式如下：
$$ NPV = \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t} $$
其中，$CF_t$ 是第 $t$ 年的现金流，$r$ 是贴现率，$n$ 是项目寿命。

#### 5.2 内部收益率（IRR）模型
内部收益率（Internal Rate of Return, IRR）是使 NPV 等于零的贴现率，公式如下：
$$ NPV = \sum_{t=0}^{n} \frac{CF_t}{(1 + IRR)^t} = 0 $$

```python
import numpy as np

def calculate_npv(cash_flows, discount_rate):
    return np.npv(discount_rate, cash_flows)

# 示例数据

discount_rate = 0.1

npv = calculate_npv(cash_flows, discount_rate)
```
