## 第2章: 公司估值的核心概念与联系

### 2.1 公司估值的核心概念原理
#### 2.1.1 股权价值与企业价值的关系
$$ 股权价值 = 企业价值 - 债务 - 优先股 $$

#### 2.1.2 现金流贴现模型的数学基础
$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n} $$

#### 2.1.3 股东权益与债务的分离定价
- 股东权益：剩余索取权

## 第3章: 公司估值的数学模型与公式

### 3.1 现金流贴现模型（DCF）
#### 3.1.1 DCF模型的基本公式
$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n} $$

#### 3.1.2 自由现金流的计算公式
$$ FCFF = EBIT(1 - 税率) + 折旧 - 资本支出 $$

### 3.2 股权价值与企业价值的关系
#### 3.2.1 企业价值公式
$$ EV = 债务 + 优先股 + 股权价值 $$

### 3.3 贴现率的计算
#### 3.3.1 WACC计算公式
$$ WACC = (D/E) \times (r_d \times (1 - 税率)) + r_e \times E $$

### 3.4 实例分析
#### 3.4.1 某公司DCF模型应用实例
- 假设公司未来5年现金流分别为100、120、150、180、200万元，贴现率为8%。
- 计算终值：$$ TV = \frac{200}{(1 + 0.08)^5} \approx 124.33万元 $$
- 现金流现值：$$ PV = \sum_{t=1}^{5} \frac{CF_t}{(1 + 0.08)^t} \approx 456.78万元 $$
- 总价值：$$ V = PV + TV \approx 581.11万元 $$

#### 3.4.2 可比公司法的实际应用
- 可比公司平均EV/EBITDA倍数为8.5倍。
- 目标公司EBITDA为500万元。
- 估值：$$ EV = 8.5 \times 500 = 4250万元 $$

### 5.2 核心实现源代码
```python
import numpy as np

def calculate_dcf(cash_flows, discount_rate, terminal_value):
    present_value = 0
    for t in range(len(cash_flows)):
        present_value += cash_flows[t] / (1 + discount_rate) ** t
    total_value = present_value + terminal_value / (1 + discount_rate) ** len(cash_flows)
    return total_value

# 示例数据
cash_flows = [100, 120, 150, 180, 200]
discount_rate = 0.08
terminal_value = 200 / (1.08)**5

# 计算DCF价值
dcf_value = calculate_dcf(cash_flows, discount_rate, terminal_value)
print(f"DCF估值：{dcf_value:.2f}万元")
```
