### 附录A：CAPM模型的Python代码示例

```python
import pandas as pd
import numpy as np

# 示例数据
returns = pd.Series([0.1, 0.05, -0.03, 0.08, 0.02], index=['A', 'B', 'C', 'D', 'E'])
market_return = 0.08
rf = 0.05

# 计算CAPM预期收益
beta = 1.2  # 示例beta值
expected_return = rf + beta * (market_return - rf)
print(expected_return)
```
