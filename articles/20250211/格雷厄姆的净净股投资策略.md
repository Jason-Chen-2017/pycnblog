# 第1章: 价值投资与净净股概述

## 1.1 价值投资的基本概念

### 1.1.1 价值投资的定义与核心理念

价值投资是一种以企业的内在价值为基础的投资策略，强调通过分析企业的财务状况、行业地位和竞争优势，寻找市场价格低于其内在价值的股票。格雷厄姆是价值投资的鼻祖，他提出的“安全边际”概念是这一策略的核心思想。

### 1.1.2 格雷厄姆的价值投资体系

格雷厄姆的价值投资体系强调以下几点：
1. **安全边际**：买入价格低于企业内在价值，以降低投资风险。
2. **Margin of Safety**：通过安全边际，确保投资的本金不会遭受重大损失。
3. **长期视角**：价值投资是一种长期投资策略，注重企业的基本面而非短期市场波动。

### 1.1.3 净净股投资策略的起源与发展

净净股投资策略是格雷厄姆提出的一种具体投资方法，主要用于寻找市场价格低于其净资产价值的股票。这种方法的核心在于识别那些被市场低估的企业，通过长期持有实现超额收益。

## 1.2 净净股的定义与特点

### 1.2.1 净净股的定义

净净股是指市场价格低于其账面价值的股票。具体来说，当股票的市场价格低于其每股净资产时，该股票即被视为净净股。净净股的核心在于利用市场的非理性定价，寻找那些被低估的企业。

### 1.2.2 净净股的核心属性

- **账面价值**：企业的净资产价值，包括资产减去负债。
- **市场价值**：股票的市场价格，反映市场对企业的估值。
- **安全边际**：市场价格与账面价值之间的差额，即安全边际。

### 1.2.3 净净股与传统估值方法的区别

| 概念       | 特点                          |
|------------|-------------------------------|
| 净值        | 账面价值与市场价值的差异      |
| 内在价值    | 股票的理论价值，基于未来现金流折现 |

## 2.1 核心概念原理

### 2.1.1 净净价值的计算公式

$$ \text{内在价值} = \frac{\text{净利润} \times (1 + g)}{r} $$

其中，$g$ 是净利润增长率，$r$ 是期望回报率。

### 2.1.2 净值与市场价值的关系

净值（账面价值）与市场价值之间的差异是净净股投资的核心依据。当市场价格低于净值时，股票具有投资价值。

### 2.1.3 安全边际的计算方法

$$ \text{安全边际} = \text{净值} - \text{市场价格} $$

```python
def calculate_intrinsic_value(net_income, growth_rate, discount_rate):
    future_cash_flow = net_income * (1 + growth_rate)
    intrinsic_value = future_cash_flow / discount_rate
    return intrinsic_value
```

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(net_income, growth_rate, discount_rate):
    future_cash_flow = net_income * (1 + growth_rate)
    intrinsic_value = future_cash_flow / discount_rate
    return intrinsic_value

def get_intrinsic_value_for_company(companies):
    intrinsic_values = []
    for company in companies:
        iv = calculate_intrinsic_value(company['net_income'], company['growth_rate'], company['discount_rate'])
        intrinsic_values.append({'company': company['name'], 'intrinsic_value': iv})
    return intrinsic_values
```
