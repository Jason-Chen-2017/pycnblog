### 第3章: 算法原理与数学模型  

#### 3.1 现代投资组合理论（MPT）的数学模型  
- 3.1.1 均值-方差优化  
  $$\text{目标函数：} \min \sigma^2 \quad \text{在约束条件下：} \sum w_i r_i = \mu$$  
  其中，\( w \) 是权重向量，\( r \) 是收益向量，\( \mu \) 是目标收益。

#### 5.2 核心算法实现

```python
import numpy as np
import pandas as pd

def optimize_portfolio(returns):
    # 计算协方差矩阵
    cov_matrix = returns.cov()
    # 使用MPT进行优化
    mu = returns.mean()
    w, _ = np.linalg.solve(cov_matrix, mu)
    return w
```
