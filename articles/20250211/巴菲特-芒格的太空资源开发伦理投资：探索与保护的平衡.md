#### 4.1 价值评估模型的定义与原理
价值评估模型是伦理投资的重要工具，用于评估企业的长期价值和潜在风险。

- **4.1.1 价值评估模型的定义**

  - 该模型综合考虑企业的财务状况、市场竞争力和可持续发展潜力。

- **4.1.2 价值评估模型的原理与特点**

  - 强调长期价值和可持续发展。

- **4.1.3 价值评估模型的数学公式**
  - 内在价值公式：
  $$ V = \frac{CF}{r - g} $$
  - 其中，CF为自由现金流，r为折现率，g为增长率。

import numpy as np

def calculate_intrinsic_value(free_cash_flow, discount_rate, growth_rate):
    return free_cash_flow / (discount_rate - growth_rate)

# 示例数据
free_cash_flow = 1000000  # 单位：美元
discount_rate = 0.08
growth_rate = 0.02
