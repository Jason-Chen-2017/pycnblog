# 第二章: 背景介绍

## 2.1 资产负债表外风险的定义与背景

### 2.1.1 什么是资产负债表外风险

资产负债表外风险是指那些不在企业资产负债表中直接反映，但可能对企业财务状况和经营成果产生重大影响的风险。这些风险通常包括法律风险、声誉风险、市场风险等。

### 2.1.2 资产负债表外风险的分类

资产负债表外风险可以分为以下几类：
1. **法律风险**：因法律诉讼、合规问题等可能对企业造成的财务损失。
2. **声誉风险**：因企业声誉受损可能影响其市场地位和业务发展的风险。
3. **市场风险**：因市场波动可能对企业经营成果造成的影响。
4. **流动性风险**：企业因资金流动性不足可能面临的财务危机。

### 2.1.3 资产负债表外风险的特征

- 隐含性：这些风险通常不直接体现在财务报表中，具有隐蔽性。
- 复杂性：涉及多个领域，如法律、市场、声誉等，具有交叉性。
- 突发性：某些风险可能在短时间内迅速爆发，具有不可预测性。
