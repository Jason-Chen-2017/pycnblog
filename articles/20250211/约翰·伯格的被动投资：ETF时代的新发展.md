## 第一部分：被动投资与ETF概述

### 第1章：被动投资的兴起与重要性

#### 1.1 被动投资的定义与特点

被动投资是一种投资策略，强调长期持有投资组合，不频繁交易，以避免市场波动和交易成本对收益的影响。其核心特点包括：

- **低交易成本**：被动投资通过减少交易次数降低佣金和买卖价差。
- **分散化**：通过广泛持有资产来降低非系统性风险。
- **长期视角**：关注长期收益，而非短期市场波动。

#### 1.2 ETF的基本概念与运作机制

ETF（交易所交易基金）是一种在交易所上市交易的基金，结合了封闭式基金和开放式基金的特点。其运作机制包括：

- **申购与赎回**：投资者可以通过基金管理公司以基金净值申购或赎回ETF份额。
- **二级市场交易**：ETF在交易所上市，投资者可以像买卖股票一样交易ETF。

#### 1.3 被动投资在现代金融中的地位

被动投资以其低成本和分散化的特点，逐渐成为主流投资策略。根据现代投资组合理论（MPT），被动投资通过优化投资组合，可以在相同风险下获得更高的收益。

#### 1.4 约翰·伯格的贡献与被动投资理念

约翰·伯格是被动投资的先驱，他创立了先锋集团（Vanguard），并推出第一只指数基金。他的理念强调低成本和分散化，认为普通投资者难以通过主动管理获得超额收益。

## 第二部分：被动投资的核心概念与策略

### 第2章：被动投资的核心原理

#### 2.1 投资组合理论

现代投资组合理论（MPT）由哈里·马科维茨提出，强调通过分散化降低风险。被动投资通过持有广泛市场的指数基金实现这一目标。

#### 2.2 被动投资的数学模型与公式

- **期望收益**：$$E(r) = \sum p_i r_i$$
- **方差**：$$\sigma^2 = \sum p_i^2 \sigma_i^2 + 2\sum_{i<j} p_i p_j \sigma_{ij}$$
- **投资组合优化**：通过调整资产权重，使风险最小化或收益最大化。

#### 2.3 被动投资的策略选择

- **指数基金投资策略**：选择宽基指数，如标普500，以分散风险。
- **行业指数与风格指数**：根据市场情况选择特定行业或风格的指数。

## 第三部分：ETF时代的新发展

### 第3章：ETF的运作机制与优势

#### 3.1 ETF的基本运作流程

- **发行与上市**：基金管理公司向证监会申请，ETF在交易所上市。
- **申购与赎回**：投资者按基金净值申购或赎回，机构投资者通常以大额交易。
- **二级市场交易**：投资者通过券商买卖ETF份额，价格随市场波动。

#### 3.2 ETF的成本优势

- **管理费用低**：被动管理ETF的费用低于主动管理基金。
- **交易成本低**：ETF通过二级市场交易，避免了申购赎回的高佣金。

#### 3.3 ETF的风险管理与投资策略

- **风险来源**：市场波动、流动性风险、信用风险。
- **风险分散策略**：通过持有多个行业和资产类别降低风险。
- **长期投资价值**：ETF通过分散化和低成本，长期跑赢市场。

def calculate_metrics(returns):
    expected_return = np.mean(returns)
    variance = np.var(returns)
    std_deviation = np.sqrt(variance)
    return expected_return, std_deviation

# 可视化
def plot_returns(daily_returns):
    plt.hist(daily_returns, bins=20, alpha=0.5)
    plt.xlabel('Return (%)')
    plt.ylabel('Frequency')
    plt.title('Distribution of Daily Returns')
    plt.show()

# 示例运行

    print(f"Standard Deviation: {std_deviation:.2%}")
