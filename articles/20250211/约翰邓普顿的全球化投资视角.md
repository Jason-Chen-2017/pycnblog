#### 1.1 约翰·邓普顿的生平简介

#### 1.2 全球化投资的背景与意义

## 第二部分: 全球化投资的核心概念与策略

### 第2章: 价值投资的核心理念

#### 2.1 价值投资的定义与特点
价值投资是一种投资策略，旨在以低于内在价值的价格购买优质资产。邓普顿的价值投资理念强调寻找被市场低估的股票，长期持有，耐心等待市场回归其真实价值。

#### 2.2 邓普顿的价值投资策略
邓普顿的价值投资策略包括：
1. 寻找具有强大基本面的公司。
2. 确保安全边际，即购买价格低于内在价值。
3. 长期持有，避免频繁交易。

#### 2.3 价值投资与全球化的关系
全球化使投资者能够在全球范围内寻找低估资产，扩大投资机会，降低市场风险。

### 第3章: 风险管理与投资组合优化

#### 3.1 风险管理的基本原则
风险管理是投资成功的关键。邓普顿强调分散投资，避免过度集中于某一资产或地区。

#### 3.2 投资组合优化的数学模型
投资组合优化可以通过现代投资组合理论（MPT）实现。以下是MPT的基本公式：

$$
\text{最优权重} = \frac{\mu - r}{\sum_{i,j} w_i w_j (i,j)}
$$

其中，$\mu$ 是资产的期望收益，$r$ 是无风险利率，$(i,j)$ 是资产之间的协方差矩阵。

#### 3.3 邓普顿的风险管理实践
邓普顿通过分散投资于全球市场来降低风险，同时定期评估和调整投资组合。

#### 5.2 系统核心实现源代码

```python
import pandas as pd

# 数据采集模块
def collect_data():
    data = pd.read_csv('market_data.csv')
    return data

# 分析模块
def assess_value(data):
    # 简单评估模型，计算市盈率
    data['PE'] = data['Price'] / data['Earnings']
    return data

# 决策模块
def make_decision(data):
    undervalued = data[data['PE'] < data['PE'].mean()]
    return undervalued

# 主程序
def main():
    data = collect_data()
    analyzed_data = assess_value(data)
    undervalued = make_decision(analyzed_data)
    print("Undervalued assets:", undervalued)

if __name__ == "__main__":
    main()
```
