##### 3.3 算法数学模型与公式
- 算法公式：
  $$ \theta_{t+1} = \theta_t + \eta \sum_{i=1}^n w_i \Delta\theta_i $$
  - 其中，$\theta_t$ 表示第 $t$ 轮的模型参数，$\eta$ 是学习率，$w_i$ 是第 $i$ 个客户端的权重，$\Delta\theta_i$ 是第 $i$ 个客户端的梯度更新。

##### 4.1 算法实现
- 环境搭建

- 核心代码实现
  ```python
  def fed_avg(clients, server_weights):
      # 计算客户端权重
      total = 0
      averaged_weights = {}
      for key in server_weights.keys():
          total += clients[key]
          averaged_weights[key] = total / len(clients)
      return averaged_weights
  ```
