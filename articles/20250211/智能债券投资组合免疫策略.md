## 1.1 债券投资的基本概念

### 1.1.1 债券的定义与分类
债券是一种债务工具，发行人承诺在特定时间内支付利息并偿还本金。主要分类包括政府债券、企业债券、可转换债券等。

### 1.1.2 债券市场的基本运作机制
债券价格受市场利率、信用风险、流动性等因素影响。投资者通过二级市场买卖债券，影响债券价格波动。

### 1.1.3 债券投资的风险与收益分析
债券投资面临利率风险、信用风险、流动性风险等，同时收益相对稳定，适合作为组合配置的一部分。

## 1.3 投资组合免疫策略的定义与目标

### 1.3.1 投资组合免疫的基本概念
免疫策略通过调整债券组合，使其在特定市场条件下的价格波动最小化，从而实现对利率风险的免疫。

## 3.1 均值-方差优化算法

### 3.1.1 算法原理与步骤
通过优化投资组合的收益与风险，找到最优配置。

### 3.1.2 算法的数学模型
$$ \text{目标函数} = \min \frac{1}{2} w^T \Sigma w $$
$$ \text{约束条件} = \sum w_i = 1 $$

### 3.1.3 算法实现的Python代码
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, weights):
    n = len(weights)
    def objective(weights):
        return np.dot(returns.T, weights) * weights.T
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    result = minimize(objective, weights, method='SLSQP', constraints=constraints)
    return result.x
```

## 3.2 风险中性组合构建算法

### 3.2.1 算法原理与步骤
构建风险中性组合，降低整体投资风险。

### 3.2.2 算法的数学模型
$$ \text{目标函数} = \min (w^T \Sigma w) $$
$$ \text{约束条件} = \sum w_i = 1 \quad \text{和} \quad \sum w_i r_i = r_f $$

### 3.2.3 算法实现的Python代码
```python
import numpy as np

def risk_neutral_portfolio(returns, risk_free_rate):
    n = len(returns)
    ones = np.ones(n)
    weights = np.linalg.solve(returns - risk_free_rate * ones, ones)
    return weights / sum(weights)
```
