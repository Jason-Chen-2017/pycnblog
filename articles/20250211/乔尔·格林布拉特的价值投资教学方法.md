## 第一部分: 价值投资的背景与核心理念

### 第1章: 价值投资的基本概念

#### 1.1 价值投资的定义与特点
- **1.1.1 价值投资的定义**
  - 价值投资是一种以内在价值为导向的投资方法，强调购买低于其内在价值的资产。
- **1.1.2 价值投资的核心特点**
  - 长期导向：关注企业的长期价值。
  - 安全边际：买入价格低于内在价值。
  - 逆向思维：在市场恐慌时寻找机会。

#### 1.2 乔尔·格林布拉特的生平与投资方法
- **1.2.1 乔尔·格林布拉特的简介**
  - 格林布拉特是价值投资领域的权威，著有《沃伦·巴菲特的思考方式》。
- **1.2.2 格林布拉特的投资哲学**
  - 以合理价格买入优秀企业。
- **1.2.3 格林布拉特投资方法的特点**
  - 强调安全边际和竞争优势。

### 第2章: 价值投资的核心理念

#### 2.1 市场先生与投资机会
- **2.1.1 市场先生的概念**
  - 市场情绪波动影响资产价格。
- **2.1.2 市场先生与投资决策的关系**
  - 投资者应独立于市场情绪做出决策。
- **2.1.3 市场先生的短期波动与长期价值**
  - 长期投资基于企业的内在价值。

#### 2.2 安全边际的重要性
- **2.2.1 安全边际的定义**
  - 资产价格与内在价值之间的折扣。
- **2.2.2 安全边际在投资中的作用**
  - 减少本金损失风险，增加收益潜力。
- **2.2.3 如何计算和评估安全边际**
  - 通过比较市盈率、市净率等指标。

### 第3章: 格林布拉特的价值投资模型

#### 3.1 模型的核心要素
- **3.1.1 财务指标分析**
  - 收益能力：ROE、ROA。
  - 财务健康：债务比率、现金流。
- **3.1.2 企业竞争优势**
  - 技术壁垒、成本优势、品牌价值。
- **3.1.3 行业分析与企业选择**
  - 行业前景、竞争格局。

#### 3.2 模型的数学公式与计算方法
- **3.2.1 核心财务指标的计算**
  - 市盈率（P/E）=股价/每股收益。
  - 市净率（P/B）=股价/每股净资产。
- **3.2.2 企业价值的评估公式**
  - 内在价值=未来现金流的现值。
- **3.2.3 安全边际的计算与应用**
  - 安全边际=内在价值×折扣率。

import numpy as np

def calculate_intrinsic_value(finance_data):
    # 计算ROE
    roe = finance_data['净利润'] / finance_data['股东权益']
    # 计算市净率
