## 第一部分：价值投资的背景与理念

### 第1章：价值投资的起源与发展

#### 1.1 价值投资的起源
价值投资是一种以低于内在价值的价格购买优质股票的投资策略，起源于20世纪初。其核心思想是寻找市场先生的错误定价，利用市场波动进行长期投资。约翰·聂夫作为该领域的先驱，以其严谨的投资方法和卓越的长期业绩闻名。

#### 1.2 价值投资的核心理念
价值投资的核心理念在于寻找市场低估的股票，强调安全边际和长期持有的重要性。约翰·聂夫提出，投资者应关注企业的基本面，而非市场的短期波动。他强调避免情绪化决策，坚持独立思考，以获得超额收益。

### 第2章：约翰·聂夫的投资理念

#### 2.1 价值投资的定义
价值投资是一种通过深入分析企业内在价值，以低于市场价购买股票的投资策略。约翰·聂夫将其细化为：寻找具有稳定收益、合理估值和强大护城河的企业。

#### 2.2 价值投资的核心要素
- **内在价值**：企业未来现金流的现值，计算公式为：$$ \text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1+r)^t} $$
- **安全边际**：买入价与内在价值的折扣，确保在市场波动中仍能获利。

#### 2.3 投资策略
约翰·聂夫的策略包括：长期持有、分散投资、逆向思维。他避免市场的短期波动，专注于企业的长期增长潜力。

### 第3章：价值投资的策略与分析框架

#### 3.1 安全边际的概念
安全边际是买入价与内在价值的差距，确保在市场低估时买入。计算公式：$$ \text{安全边际} = \text{内在价值} - \text{买入价} $$

#### 3.2 选股标准与分析方法
- **低市盈率**：$$ \text{市盈率} = \frac{\text{股价}}{\text{每股收益}} $$
- **低市净率**：$$ \text{市净率} = \frac{\text{股价}}{\text{每股净资产}} $$
- **高股息率**：$$ \text{股息率} = \frac{\text{每股股息}}{\text{股价}} $$

    return sum(enterprise.cash_flows / (1 + r)**t for t in range(len(enterprise.cash_flows)))

def calculate_margin_of_safety(intrinsic_value, price):
    return intrinsic_value - price
