## 第三部分: 算法原理

### 第3章: 优化模型与风险评估

#### 3.1 优化模型
目标是最小化风险（波动率）的同时最大化收益，数学模型如下：
$$ \text{目标函数：} \min \sigma^2 \quad \text{在} \quad \mu \geq \text{目标收益} $$

其中，$\mu$ 是投资组合的期望收益，$\sigma^2$ 是其方差。

#### 3.2 风险评估模型
使用VaR（Value at Risk）模型评估潜在损失：
$$ \text{VaR}_\alpha = \text{最小值} \{ x | P(L \leq x) \geq \alpha \} $$

其中，$\alpha$ 是置信水平，$L$ 是潜在损失。

#### 3.3 Python实现示例
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, weights):
    # 定义目标函数：最小化方差
    def objective(weights):
        return np.dot(weights.T, np.dot(returns.cov(), weights))
    
    # 约束条件：权重之和为1
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    
    result = minimize(objective, weights, constraints=constraints)
    return result.x

# 示例数据
returns = np.array([[0.1, 0.2, 0.15],
                    [0.05, 0.03, 0.07],
                    [0.12, 0.1, 0.08]])
weights_initial = [1/3, 1/3, 1/3]

optimal_weights = portfolio_optimization(returns, weights_initial)
print("Optimal weights:", optimal_weights)
```

from sklearn.decomposition import PCA
import pandas as pd

def dynamic_adjustment(portfolio, market_data):
    # 使用PCA提取主要市场因子
    pca = PCA(n_components=3)
    market_factors = pca.fit_transform(market_data)
    
    # 调整投资组合权重
    adjusted_weights = portfolio(weights=portfolio, market_factors=market_factors)
    return adjusted_weights

# 示例数据
market_data = pd.DataFrame({
    'stock': [0.1, 0.05, 0.12],
    'bond': [0.08, 0.03, 0.05],
    'gold': [0.02, 0.04, 0.06]
})

current_portfolio = [0.4, 0.3, 0.3]
adjusted_portfolio = dynamic_adjustment(current_portfolio, market_data)
print("Adjusted weights:", adjusted_portfolio)
