# 第3章: 定价优化算法的数学模型

## 3.1 线性回归模型
### 3.1.1 线性回归的数学公式
$$
y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon
$$

### 3.1.2 线性回归的假设检验
- 正态性检验
- 方差齐性检验
- 独立性检验
- 线性检验

### 3.1.3 线性回归的优缺点
- 优点：简单、可解释性强
- 缺点：假设严格，适用范围有限

## 3.2 非线性回归模型
### 3.2.1 非线性回归的数学公式
$$
y = f(x, \beta) + \epsilon
$$

### 3.2.2 非线性回归的优化方法
- 最小二乘法
- 迭代法：牛顿法、高斯-牛顿法

### 3.2.3 非线性回归的应用场景
- 非线性关系显著的情况
- 数据分布不符合正态分布的情况

## 3.3 优化算法的数学推导
### 3.3.1 梯度下降法的数学推导
$$
\theta_{new} = \theta_{old} - \eta \nabla J(\theta_{old})
$$

### 3.3.2 随机梯度下降法的数学推导
$$
\theta_{new} = \theta_{old} - \eta \nabla J(\theta_{old}, X_i, y_i)
$$

### 3.3.3 其他优化算法的简要介绍
- Adam优化器
- AdaGrad优化器
- RMSprop优化器

## 3.4 算法的比较与选择
### 3.4.1 算法的性能对比
- 收敛速度
- 计算复杂度
- 稳定性

### 3.4.2 算法的选择标准
- 数据规模
- 数据分布
- 计算资源

### 3.4.3 算法的适用场景
- 线性回归适用于线性关系
- 非线性回归适用于非线性关系
- 高维数据适用深度学习模型

# 第5章: 项目实战

## 5.1 环境安装与配置

## 5.2 核心实现源代码
### 5.2.1 数据预处理代码
```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('金融产品数据.csv')

# 数据清洗
data.dropna()
data = data[~data.duplicated()]

# 特征提取
features = data[['市场数据', '用户行为']]
label = data['定价']
```

### 5.2.2 模型训练代码
```python
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split

# 数据分割
X_train, X_test, y_train, y_test = train_test_split(features, label, test_size=0.2)

# 模型训练
model = LinearRegression()
model.fit(X_train, y_train)

# 模型预测
y_pred = model.predict(X_test)
```

### 5.2.3 模型评估代码
```python
from sklearn.metrics import mean_squared_error, r2_score

# �均方误差
mse = mean_squared_error(y_test, y_pred)
print(f'MSE: {mse}')

# R平方值
r2 = r2_score(y_test, y_pred)
print(f'R²: {r2}')
```
