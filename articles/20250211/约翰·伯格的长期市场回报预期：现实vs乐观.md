## 第一部分：背景介绍

### 第1章：约翰·伯格与长期市场回报预期

#### 1.1 约翰·伯格的生平与投资理念
- **1.1.1 约翰·伯格的生平简介**
  - 约翰·伯格出生于1940年，是美国著名投资家，指数基金之父。
  - 他创立了 Vanguard 集团，推动了低成本指数基金的发展。
- **1.1.2 伯格的投资哲学与价值投资理论**
  - 伯格强调长期投资，认为市场波动不可预测，但长期趋势可以把握。
  - 他倡导价值投资，注重企业的基本面分析，寻找被市场低估的投资标的。
- **1.1.3 伯格对市场的长期看法**
  - 市场长期趋于理性，回归企业内在价值。
  - 投资者应关注企业的盈利能力、财务健康和行业地位。

#### 1.2 长期市场回报预期的背景与问题
- **1.2.1 长期市场回报预期的定义**
  - 预测市场在较长时期内的平均收益水平。
- **1.2.2 现实与乐观两种视角的对比**
  - 现实视角：考虑经济周期波动、政策风险和企业盈利不确定性。
  - 乐观视角：基于长期增长趋势，忽视短期波动。
- **1.2.3 长期回报预期的核心问题**
  - 如何量化长期回报？
  - 如何平衡短期波动与长期趋势？
  - 如何在不同市场环境下调整投资策略？

### 第2章：长期市场回报预期的核心概念

#### 2.1 核心概念的定义与属性

#### 3.2 算法实现代码
```python
import pandas as pd

def calculate_expected_return(data, window=10):
    # 计算历史回报
    historical_returns = data.pct_change().dropna()
    # 计算长期平均回报
    average_return = historical_returns.mean() * 100
    return average_return

# 示例数据
data = pd.DataFrame({
    'Price': [100, 105, 110, 115, 120]
})
print(calculate_expected_return(data))
```

#### 3.3 数学模型与公式
- **CAPM模型**：
  $$ R_i = R_f + \beta_i (R_m - R_f) $$
  - \( R_i \)：资产的预期回报
  - \( R_f \)：无风险利率
  - \( \beta_i \)：资产的系统性风险
  - \( R_m \)：市场预期回报
- **长期回报公式**：
  $$ E[R] = \mu \times t + \epsilon $$
  - \( \mu \)：平均回报率
  - \( t \)：时间跨度
  - \( \epsilon \)：误差项
