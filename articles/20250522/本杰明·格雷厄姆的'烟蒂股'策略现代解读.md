- **起源**：20世纪初，格雷厄姆提出烟蒂股概念，强调通过基本面分析寻找低估股票。

#### 1.2 烟蒂股策略的核心理念与目标

烟蒂股策略的核心理念是通过分析公司基本面，识别市场低估的股票，追求长期稳定的投资回报。

- **核心理念**：寻找具有安全边际的低估值股票，注重内在价值而非市场情绪。
- **目标**：通过长期持有优质烟蒂股，实现超额收益。

### 第2章：烟蒂股策略的核心概念

#### 2.1 烟蒂股的定义与特征

烟蒂股是指那些市场价格低于其内在价值，且具有较高安全边际的股票。其主要特征包括低市盈率、低市净率和高股息率等。

- **定义**：市场价格显著低于内在价值的股票。
- **特征**：
  - 低估值：市盈率、市净率低于行业平均水平。
  - 高质量：公司财务状况健康，盈利能力稳定。
  - 高安全边际：市场价格与内在价值的差距较大。

#### 2.2 烟蒂股与成长股的对比

| 特性       | 烟蒂股             | 成长股             |
|------------|--------------------|--------------------|
| 价值评估   | 低估值             | 高成长性           |
| 投资逻辑   | 寻找低估            | 寻找高增长          |
| 风险偏好   | 低风险             | 高风险             |
| 代表公司   | 需求稳定的公司     | 高科技公司         |

烟蒂股策略的边界包括市场波动、公司基本面变化等，外延则包括结合技术分析和大数据技术。

## 第二部分：烟蒂股策略的核心概念与联系

### 第2章：烟蒂股策略的核心原理

#### 2.1 烟蒂股策略的数学模型

烟蒂股策略的核心是计算股票的内在价值，通常使用现金流贴现模型（DCF）。

- **内在价值公式**：
  $$ V = \frac{CF}{(r - g)} $$
  其中，CF为自由现金流，r为折现率，g为增长率。

- **安全边际公式**：
  $$ \text{安全边际} = V_{\text{估计}} - P $$
  其中，V_{\text{估计}}为内在价值估计值，P为市场价格。

```python
import pandas as pd

def calculate_intrinsic_value(cash_flow, discount_rate, growth_rate):
    return cash_flow / (discount_rate - growth_rate)

def calculate_margin_of_safety(intrinsic_value, price):
    return intrinsic_value - price

def screen_stidend_stocks(stocks_data):
    selected_stocks = []
    for stock in stocks_data:
        cf = stock['free_cash_flow']
        dr = stock['discount_rate']
        gr = stock['growth_rate']
        p = stock['price']
        
        iv = calculate_intrinsic_value(cf, dr, gr)
        mos = calculate_margin_of_safety(iv, p)
        
        if mos > 0:
            selected_stocks.append({
                'stock_code': stock['stock_code'],
                'stock_name': stock['stock_name'],
                'intrinsic_value': iv,
                'margin_of_safety': mos
            })
    return selected_stocks

# 示例数据
stocks = [
    {
        'stock_code': 'AAPL',
        'stock_name': '苹果',
        'free_cash_flow': 1000000,
        'discount_rate': 0.1,
        'growth_rate': 0.05,
        'price': 150
    },
    # 添加更多股票数据
]

selected = screen_stidend_stocks(stocks)
print(selected)
```

#### 5.2 核心代码实现

```python
import pandas as pd

def calculate_intrinsic_value(cf, dr, gr):
    return cf / (dr - gr)

def calculate_margin_of_safety(iv, p):
    return iv - p

def screen_stocks(stocks_df):
    selected = []
    for idx, row in stocks_df.iterrows():
        iv = calculate_intrinsic_value(row['free_cash_flow'], row['discount_rate'], row['growth_rate'])
        mos = calculate_margin_of_safety(iv, row['price'])
        if mos > 0:
            selected.append({
                'stock_code': idx,
                'intrinsic_value': iv,
                'margin_of_safety': mos
            })
    return pd.DataFrame(selected)

# 示例数据
data = {
    'stock_code': ['AAPL', 'MSFT', 'GOOGL'],
    'free_cash_flow': [1000000, 800000, 1200000],
    'discount_rate': [0.1, 0.1, 0.1],
    'growth_rate': [0.05, 0.04, 0.06],
    'price': [150, 100, 200]
}

df = pd.DataFrame(data)
result = screen_stocks(df)
print(result)
```
