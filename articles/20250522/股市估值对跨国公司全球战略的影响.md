## 第一章：股市估值的基本概念与方法

### 1.1 股市估值的定义与意义

股市估值是通过对企业财务数据和市场因素的分析，确定其股票的公允价值。它不仅反映了企业的当前状况，还预示了其未来表现，是投资者决策的重要依据。

### 1.2 股市估值的主要方法

- **市盈率法（P/E Ratio）**：基于每股收益，反映市场对公司的盈利能力预期。
- **市净率法（P/B Ratio）**：考虑资产价值，适用于重资产行业。
- **净现值法（Net Present Value）**：通过现金流折现计算企业价值。
- **股息率法（Dividend Yield）**：衡量分红回报，吸引注重收益的投资者。

## 第五章：算法原理讲解

### 5.1 CAPM模型

#### 5.1.1 算法步骤

1. 确定无风险利率和市场预期回报率。
2. 计算贝塔系数，衡量股票风险。
3. 应用CAPM公式计算期望回报率。

#### 5.1.2 Python代码实现

```python
def calculate_capm(risk_free_rate, market_return, beta, epsilon=0.01):
    return risk_free_rate + beta * (market_return - risk_free_rate) + epsilon
```

#### 5.1.3 数学模型

$$ CAPM = R_f + β (R_m - R_f) + ε $$
