## 第2章：成本敏感型投资的核心概念

### 2.1 投资成本的构成与影响

#### 2.1.1 投资成本的定义

投资成本包括显性成本（如管理费、托管费）和隐性成本（如交易佣金、市场冲击等）。这些成本直接影响投资组合的净收益。

#### 2.1.2 成本对投资回报的影响

通过公式化分析，可以发现投资成本的增加会显著降低净回报。例如，假设一个投资组合的年回报率为8%，而年管理费为1.5%，则实际净回报为6.5%。

### 2.2 投资成本的数学模型

#### 2.2.1 投资回报率公式

$$
\text{净回报} = \text{总回报} - \text{投资成本}
$$

#### 2.2.2 投资成本对复合收益的影响

$$
\text{最终价值} = \text{初始投资} \times (1 + \text{回报率} - \text{成本率})^t
$$

其中，\( t \) 是投资时间（年）。

## 第5章：成本敏感型投资的数学模型与算法

### 5.1 投资组合优化的数学模型

使用凸优化方法，最小化投资成本，最大化收益。

$$
\min_{w} \quad w^T \cdot \text{成本向量}
$$

$$
\text{约束条件} \quad w^T \cdot \text{资产回报向量} = \text{目标回报}
$$

### 5.2 算法实现

以下是基于Python的优化算法示例：

```python
import numpy as np
from scipy.optimize import minimize

def objective(w, cost_vector):
    return np.dot(w, cost_vector)

def constraint(w, return_vector, target_return):
    return np.dot(w, return_vector) - target_return

# 示例数据
return_vector = np.array([0.1, 0.12, 0.08])
cost_vector = np.array([0.01, 0.02, 0.015])
target_return = 0.1

# 优化
w = minimize(objective, np.array([1/3, 1/3, 1/3]), args=(cost_vector,),
              method='SLSQP', constraints={'type': 'eq', 'fun': constraint, 'args': (return_vector, target_return)})

print(w.x)
```
