# 第三部分: 数学模型与算法

## 第3章: 现代投资组合理论（MPT）解析

### 3.1 核心假设与数学公式
- **3.1.1 假设条件**：投资者风险厌恶、市场有效性等。
- **3.1.2 投资组合优化公式**：$$ \text{min} \sigma^2 \quad \text{subject to} \quad \mu \cdot w = R \quad \text{和} \quad w \cdot \mathbf{1} = 1 $$。

### 3.2 算法实现
- **3.2.1 Python代码示例**：
  ```python
  import numpy as np
  from scipy.optimize import minimize

  def portfolio_optimization(returns, cov_matrix, target_return):
      n = len(cov_matrix)
      # 定义目标函数
      def objective(w):
          return (w.T @ cov_matrix @ w)[0, 0]
      # 约束条件
      constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
                     {'type': 'eq', 'fun': lambda w: returns.T @ w - target_return}]
      # 边界条件
      bounds = [(0, None) for _ in range(n)]
      # 求解
      result = minimize(objective, np.ones(n)/n, method='SLSQP', bounds=bounds, constraints=constraints)
      return result.x
  ```

### 3.3 有效前沿的绘制
- **3.3.1 使用Python绘制有效前沿**：
  ```python
  import matplotlib.pyplot as plt
  # 假设 returns 和 cov_matrix已定义
  target_returns = np.linspace(min(returns), max(returns), 100)
  frontiers = []
  for ret in target_returns:
      w = portfolio_optimization(returns, cov_matrix, ret)
      frontiers.append((ret, w.T @ returns, np.sqrt(w.T @ cov_matrix @ w)))
  
  plt.plot(frontiers[:,1], frontiers[:,2])
  plt.xlabel('Expected Return')
  plt.ylabel('Volatility')
  plt.show()
  ```
