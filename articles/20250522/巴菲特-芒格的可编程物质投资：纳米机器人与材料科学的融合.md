### 5.2 核心代码实现
```python
import numpy as np
import pandas as pd

def optimize_portfolio(weights, returns):
    # 计算投资组合的收益和风险
    portfolio_return = np.dot(weights, returns)
    portfolio_variance = np.dot(weights.T, np.dot(weights, np.cov(returns.T)))
    return -portfolio_return + portfolio_variance

# 示例数据
returns = np.array([0.1, 0.2, 0.15])
weights = np.array([0.3, 0.4, 0.3])

# 优化投资组合
from scipy.optimize import minimize
result = minimize(optimize_portfolio, weights, args=(returns,))
print("最优权重：", result.x)
print("最优收益：", -result.fun)
```

### 5.3 代码解读
- **函数定义**：`optimize_portfolio`函数计算投资组合的收益和风险。
- **优化函数**：使用`scipy.optimize.minimize`进行优化，目标是最小化风险，同时最大化收益。
- **输出结果**：打印最优权重和收益。
