### 第1章: 特价股票与公司智能供应链的概述

#### 1.1 特价股票的定义与特点
特价股票是指在特定市场条件下，公司为了清理库存、促销产品或吸引客户而提供的价格低于市场价的股票。其核心特点包括价格敏感性、短期优惠性和目标客户精准性。

#### 1.2 公司智能供应链的定义与特点
公司智能供应链是指通过智能化技术（如物联网、大数据、人工智能）优化供应链管理，实现从原材料采购到产品交付的全链条智能化。其特点包括数据驱动、实时监控和自动化管理。

#### 1.3 网络效应的定义与特点
网络效应是指随着用户数量增加，系统价值呈指数级增长的现象。其特点包括正反馈循环、用户锁定和平台效应。

    data = []
    for row in soup.find_all('tr'):
        data.append({
            'stock_id': row.find('td').text,
            'price': float(row.find('td', {'class': 'price'}).text)
        })
    return data
