## 第一部分：背景介绍

### 第1章：格雷厄姆投资理论的起源

#### 1.1 格雷厄姆投资理论的起源

- **1.1.1 投资理论的发展历程**  
  格雷厄姆的投资理论起源于20世纪初，强调价值投资和安全边际。其核心思想是通过分析股票的内在价值，寻找被市场低估的投资机会。

- **1.1.2 格雷厄姆的价值投资理念**  
  格雷厄姆认为，股票不仅是价格标签，更是公司的一部分。投资者应关注公司的基本面，寻找市场价格低于内在价值的股票。

- **1.1.3 格雷厄姆投资理论的核心思想**  
  格雷厄姆强调“安全边际”，即买入价格低于内在价值的股票，以降低风险并确保收益。

#### 1.2 格雷厄姆特价股票策略的定义

- **1.2.1 特价股票的定义**  
  特价股票是指市场价格低于其内在价值的股票，通常具有较高的安全边际。

- **1.2.2 格雷厄姆特价股票的筛选标准**  
  格雷厄姆提出通过市盈率（P/E）、市净率（P/B）等指标筛选低估股票。

- **1.2.3 特价股票与普通股票的区别**  
  特价股票具有更高的安全边际和较低的估值，而普通股票的价格可能已反映市场预期。

#### 1.3 不同规模经济体的分类

- **1.3.1 小盘股、中盘股和大盘股的定义**  
  小盘股：市值较小的公司股票；中盘股：中等市值的公司股票；大盘股：市值较大的公司股票。

- **1.3.2 不同规模经济体的特点**  
  小盘股波动性大，风险高；大盘股稳定性强，风险较低；中盘股介于两者之间。

- **1.3.3 不同规模经济体对投资策略的影响**  
  不同规模的股票对市场波动、经济周期和公司基本面的反应不同，影响格雷厄姆策略的表现。

## 第二部分：核心概念与联系

### 第2章：格雷厄姆特价股票策略的核心原理

#### 2.1 格雷厄姆特价股票策略的原理

- **2.1.1 格雷厄姆的“安全边际”概念**  
  安全边际是股票市场价格与内在价值之间的差额，确保在市场价格波动时仍能获得收益。

- **2.1.2 特价股票的内在价值计算**  
  内在价值是基于公司基本面（如盈利能力、资产质量）计算的理论价值，与市场价格无关。

- **2.1.3 市场价格与内在价值的差异**  
  当市场价格低于内在价值时，股票具有投资价值。

#### 2.2 格雷厄姆特价股票策略与传统价值投资的对比

- **2.2.1 传统价值投资的定义与特点**  
  传统价值投资注重公司基本面，寻找低估股票，但不特别强调安全边际。

- **2.2.2 格雷厄姆策略的独特之处**  
  强调安全边际和数学模型，通过量化指标筛选股票。

- **2.2.3 两者的优缺点对比**  
  | 对比维度 | 格雷厄姆策略 | 传统价值投资 |
  |----------|--------------|---------------|
  | 优势     | 强调安全边际 | 侧重基本面分析 |
  | 劣势     | 依赖数学模型 | 主观性较强     |

#### 2.3 影响格雷厄姆策略表现的因素

- **2.3.1 市场波动性的影响**  
  市场波动可能导致策略失效，需动态调整。

- **2.3.2 经济周期的影响**  
  经济周期波动影响公司基本面，进而影响策略表现。

- **2.3.3 公司基本面的变化**  
  公司盈利能力、资产质量等变化影响内在价值。

## 第三部分：算法原理与数学模型

### 第3章：格雷厄姆特价股票筛选算法

#### 3.1 算法原理

- **3.1.1 市盈率（P/E）计算**  
  $$P/E = \frac{\text{股价}}{\text{每股收益}}$$

- **3.1.2 市净率（P/B）计算**  
  $$P/B = \frac{\text{股价}}{\text{每股净资产}}$$

- **3.1.3 股息率计算**  
  $$\text{股息率} = \frac{\text{股息支付率}}{\text{股价}} \times 100\%$$

#### 3.2 算法实现

- **3.2.1 使用Python代码实现筛选逻辑**  

```python
import pandas as pd

def graham_strategy(stocks):
    # 计算市盈率和市净率
    stocks['P/E'] = stocks['股价'] / stocks['每股收益']
    stocks['P/B'] = stocks['股价'] / stocks['每股净资产']
    
    # 筛选条件：P/E < 15 且 P/B < 1.5
    stocks = stocks[(stocks['P/E'] < 15) & (stocks['P/B'] < 1.5)]
    
    return stocks

# 示例数据
data = {
    '股票代码': ['A', 'B', 'C'],
    '股价': [10, 20, 30],
    '每股收益': [0.5, 1.0, 1.5],
    '每股净资产': [5, 10, 15]
}
stocks = pd.DataFrame(data)
result = graham_strategy(stocks)
print(result)
```

#### 3.3 数学模型和公式

- **3.3.1 格雷厄姆筛选公式**  
  $$\text{筛选条件} = P/E < 15 \text{ 且 } P/B < 1.5$$

- **3.3.2 内在价值计算公式**  
  $$\text{内在价值} = \frac{\text{净利润} \times (8.5 + 市盈率调整)}{\text{市盈率}}$$
