## 第1章: 投资组合再平衡概述

### 1.1 投资组合的基本概念

#### 1.1.1 投资组合的定义
投资组合是指将多种资产（如股票、债券、基金等）按照一定比例组合在一起的投资方式。通过多样化投资，可以降低风险，同时提高收益。

#### 1.1.2 投资组合的目标与特点
- **目标**：实现资产的长期保值与增值。
- **特点**：分散风险、优化收益、动态调整。

#### 1.1.3 投资组合的风险与收益
- **风险**：市场波动、资产贬值。
- **收益**：通过优化资产配置实现超额收益。

### 1.2 再平衡策略的背景与意义

#### 1.2.1 投资组合失衡的常见原因
- 市场波动导致资产价格变化。
- 经济周期影响不同资产表现。
- 资金流入流出导致比例失调。

#### 1.2.2 再平衡策略的核心目标
- 维持目标资产配置比例。
- 优化投资组合的风险收益比。
- 降低市场波动对投资组合的影响。

#### 1.2.3 约翰·伯格的再平衡策略背景
- 约翰·伯格是投资领域的权威，其再平衡策略强调长期稳健的投资。
- 再平衡策略的核心是动态调整资产配置，以应对市场变化。

## 第4章: 再平衡策略的数学模型与算法

### 4.1 投资组合优化的数学模型

#### 4.1.1 优化目标的定义
- 最大化投资组合的预期收益。
- 最小化投资组合的方差。

#### 4.1.2 约束条件的设定
- 投资比例限制。
- 资金总量约束。

#### 4.1.3 数学模型
$$
\min_w \frac{1}{2} w^T \Sigma w \\
s.t. \quad \mathbf{1}^T w = 1, \quad w \geq 0
$$
其中，\( w \) 是资产权重向量，\( \Sigma \) 是协方差矩阵。

### 4.2 均值-方差优化算法

#### 4.2.1 算法步骤
1. 确定各资产的预期收益和协方差矩阵。
2. 使用拉格朗日乘数法优化权重。
3. 计算最优权重并进行再平衡。

#### 4.2.2 代码实现
```python
import numpy as np

def mean_variance_optimization(expected_returns, covariance_matrix):
    n = len(expected_returns)
    Sigma = covariance_matrix
    mu = np.array(expected_returns).reshape(-1, 1)
    G = np.zeros(n)
    H = np.zeros((2, n))
    H[0] = 1
    h = np.array([1.0, 0.0]).T
    A = np.zeros(n)
    B = np.array([1.0]).T
    w = np.linalg.solve(Sigma, mu) * B
    w = w / np.sum(w)
    return w
```

    current_weights = (data.iloc[-1] * weights).sum()
    target_weights = weights
    rebalanced_weights = target_weights / current_weights * data.iloc[-1]
