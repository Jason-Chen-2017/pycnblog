## 第四章: 投资组合优化的数学模型

### 4.1 数学模型的建立

#### 4.1.1 资产配置的优化问题
- 优化目标：最大化收益，最小化风险。
- 约束条件：资金分配、风险承受能力等。

#### 4.1.2 使用Python实现投资组合优化
- 使用Python的优化库（如scipy.optimize）进行投资组合优化。
- 代码示例：
  ```python
  import numpy as np
  from scipy.optimize import minimize
  
  # 假设mu为资产期望收益，cov为协方差矩阵
  def portfolio_return(weights, mu):
      return np.dot(weights.T, mu)
  
  def portfolio_risk(weights, cov):
      return np.sqrt(weights.T @ cov @ weights)
  
  # 最小化风险，约束条件：sum(weights) = 1
  def optimize_portfolio(mu, cov):
      n = len(mu)
      constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
      result = minimize(portfolio_risk, np.ones(n)/n, args=cov, constraints=constraints)
      return result.x
  ```
