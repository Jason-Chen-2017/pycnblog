# 第1章: 投资组合管理的基本概念

## 1.1 投资组合管理的定义与目标

### 1.1.1 投资组合管理的定义
投资组合管理是通过科学配置资产，分散风险，以实现收益最大化的过程。它涉及对市场、经济和公司基本面的深入分析。

### 1.1.2 投资组合管理的目标
- 实现资产的长期稳健增长。
- 通过分散投资降低风险，避免重大损失。
- 根据市场变化及时调整投资策略，捕捉收益机会。

## 1.2 彼得·林奇与投资组合管理

### 1.2.1 彼得·林奇的生平简介
彼得·林奇是富达投资的传奇经理，以其长期优异的业绩闻名。他强调深入研究公司基本面，寻找被低估的投资标的。

### 1.2.2 彼得·林奇的投资理念
- 长期投资：避免短期波动，关注公司长期价值。
- 价值投资：寻找基本面良好、估值合理的公司。
- 分散投资：通过多样化降低特定风险。

### 1.2.3 彼得·林奇的成功案例

# 第2章: 投资组合管理的核心概念

## 2.1 资产配置与风险分散

### 2.1.1 资产配置的定义与作用
资产配置指将资金分配到不同资产类别（股票、债券、现金等）以平衡风险和收益。它帮助投资者在不同市场环境下保持稳定收益。

### 2.1.2 风险分散的原理与方法
- 风险分散：通过投资不同资产或行业，降低特定资产带来的风险。
- 现代投资组合理论（MPT）：通过优化资产配置，实现收益最大化和风险最小化。

## 2.2 投资组合的数学模型

### 2.2.1 投资组合的期望收益与风险
- 期望收益：各资产收益的加权平均。
- 风险：收益波动性，通常用方差或标准差衡量。

### 2.2.2 马科维茨的有效前沿理论
有效前沿展示了在给定风险下，收益最高的组合，或在给定收益下，风险最低的组合。通过优化算法找到最优投资组合。

### 2.2.3 投资组合的优化算法
- 均值-方差优化：寻找收益-风险平衡点。
- 距离最优化：基于特定目标优化组合。

# 第3章: 彼得·林奇的投资策略

## 3.1 长期投资与价值发现

### 3.1.1 长期投资的定义与优势
长期投资避免频繁交易成本和情绪影响，捕捉公司长期增长价值。

### 3.1.2 价值发现的原理与方法
通过分析公司基本面（财务报表、行业地位、管理层）寻找被低估的投资标的。

## 3.2 股票筛选与组合构建

### 3.2.1 彼得·林奇的选股标准
- 低市盈率、低市净率：寻找价值被低估的公司。
- 坍塌式下跌：公司因暂时问题导致股价大幅下跌，但基本面良好。
- 高ROE：股东权益回报率高的公司。

### 3.2.2 投资组合的构建步骤
1. 确定投资目标和风险承受能力。
2. 选择符合标准的个股。
3. 根据资产配置比例分配权重。
4. 定期审视和调整组合。

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, weights=None):
    n = returns.shape[0]
    if weights is None:
        weights = np.ones(n)/n
    def objective(weights):
        return -np.sum(weights * np.log(weights))
    def constraint(weights):
        return np.sum(weights) - 1
    bounds = [(0,1)] * n
    result = minimize(objective, weights, bounds=bounds, constraints=constraint)
    return result.x
```
