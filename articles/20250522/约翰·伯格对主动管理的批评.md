```python
def active_management_strategy(portfolio, market_data):
    # 分析市场数据
    analysis = analyze_market(market_data)
    # 构建投资组合
    new_portfolio = build_portfolio(portfolio, analysis)
    return new_portfolio

def analyze_market(market_data):
    # 示例分析：计算市场平均回报率
    return market_data.mean()

def build_portfolio(portfolio, analysis):
    # 示例构建：根据分析结果调整持仓
    return portfolio * analysis
```

#### 3.3 数学模型与公式
- 示例公式：
$$ E(r_i) = \beta_i (E(r_m) - r_f) + r_f $$
其中，$E(r_i)$ 是资产 $i$ 的预期回报率，$\beta_i$ 是资产的贝塔系数，$E(r_m)$ 是市场预期回报率，$r_f$ 是无风险利率。
