# 第1章: 约翰·邓普顿的生平与投资理念

## 1.1 约翰·邓普顿的生平简介
### 1.1.1 早年经历
约翰·邓普顿于1912年出生于美国密歇根州，早年在家族企业中积累了对商业和金融的理解。他在大学期间表现出对金融的浓厚兴趣，为日后的投资生涯奠定了基础。

### 1.1.2 投资生涯
约翰·邓普顿的职业生涯始于1930年代，他通过自学和实践逐渐发展出一套独特的投资策略。他的投资风格以逆向思维和价值投资为核心。

### 1.1.3 主要成就
- 创立邓普顿投资公司。
- 在1929年大萧条和1970年代石油危机中成功投资。
- 被誉为“价值投资之父”。

## 1.2 投资理念
### 1.2.1 价值投资的核心思想
约翰·邓普顿的价值投资理念强调购买被市场低估的股票，关注公司的内在价值而非市场情绪。

### 1.2.2 安全边际的概念与重要性
安全边际是约翰·邓普顿投资策略的核心。他通过计算股票的内在价值与市场价格的差距，确保投资的安全性。

### 1.2.3 投资哲学
- 长期投资：避免频繁交易，耐心等待市场回归理性。
- 分散投资：通过多样化降低风险。
- 逆向思维：在市场恐慌时寻找机会。

# 第2章: 危机投资的核心概念与理论基础

## 2.1 价值投资与市场周期
### 2.1.1 价值投资的定义与特点
价值投资是指以低于内在价值的价格购买优质资产。其特点是逆向性、长期性和安全性。

### 2.1.2 市场周期的波动规律
市场周期分为上升、下跌、筑底和复苏阶段。在危机时期，市场往往处于低估阶段，为价值投资者提供了机会。

### 2.1.3 危机时期的市场特征
- 资产价格大幅波动。
- 市场情绪极度恐慌。
- 优质资产价格被低估。

## 2.2 逆向投资的原理与应用
### 2.2.1 逆向投资的定义与特点
逆向投资是指在市场恐慌时买入，在市场狂热时卖出。其核心在于反市场情绪操作。

### 2.2.2 安全边际的数学模型
安全边际公式：  
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$  
通过计算安全边际，投资者可以识别低估资产。

### 2.2.3 经典案例分析
- 1929年大萧条：邓普顿在市场底部买入股票，实现高额收益。
- 1970年代石油危机：买入受冲击的能源公司股票，市场复苏后获利。

## 2.3 投资组合管理
### 2.3.1 分散投资的重要性
通过分散投资降低特定资产的风险。

### 2.3.2 投资组合优化的数学模型
使用现代投资组合理论（MPT）进行优化：  
$$ \text{风险} = \sqrt{\sum_{i=1}^{n} w_i^2 \sigma_i^2} $$  
其中，\( w_i \) 是资产权重，\( \sigma_i \) 是资产风险。

# 第4章: 危机投资的数学模型与算法

## 4.1 投资模型的数学公式
### 4.1.1 内在价值计算
使用现金流折现法（DCF）计算公司内在价值：  
$$ \text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} $$  
其中，\( CF_t \) 是第t年的现金流，\( r \) 是折现率。

### 4.1.2 安全边际计算
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

## 4.2 算法实现
### 4.2.1 Python代码示例
```python
def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(cf / (1 + discount_rate) ** t for t, cf in enumerate(cash_flows))

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price
```

### 4.2.2 案例分析
假设某公司未来5年的现金流为[100, 120, 150, 180, 200]，折现率为10%。  
计算内在价值：  
$$ \text{IV} = \frac{100}{1.1} + \frac{120}{1.1^2} + \frac{150}{1.1^3} + \frac{180}{1.1^4} + \frac{200}{1.1^5} \approx 465.03 $$  
假设市场价格为300，安全边际为：  
$$ 465.03 - 300 = 165.03 $$  
说明该股票被低估，具有投资价值。
