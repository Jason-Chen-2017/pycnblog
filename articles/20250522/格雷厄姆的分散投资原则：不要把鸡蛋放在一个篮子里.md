## 第二章：分散投资的数学模型与风险分析

### 2.1 投资组合的风险与收益

#### 2.1.1 投资组合的期望收益

在投资组合中，每种资产都有其期望的收益和风险。投资组合的期望收益是各资产期望收益的加权平均值。数学上，这可以表示为：

$$ E(r_p) = \sum_{i=1}^{n} w_i E(r_i) $$

其中，\( w_i \) 是第 \( i \) 项资产的投资比例，\( E(r_i) \) 是第 \( i \) 项资产的期望收益。

#### 2.1.2 投资组合的风险度量

投资组合的风险通常用方差或标准差来衡量。投资组合的方差计算公式为：

$$ \sigma_p^2 = \sum_{i=1}^{n} \sum_{j=1}^{n} w_i w_j \sigma_i \sigma_j \rho_{ij} $$

其中，\( \sigma_i \) 和 \( \sigma_j \) 分别是第 \( i \) 和第 \( j \) 项资产的标准差，\( \rho_{ij} \) 是它们之间的相关系数。

### 2.2 马科维茨的有效前沿理论

#### 2.2.1 投资组合理论的基本假设

马科维茨的有效前沿理论假设投资者是理性的，并且在投资时追求收益最大化，同时最小化风险。投资者还假设可以以无风险利率借入或贷出资金。

#### 2.2.2 有效前沿的定义与计算

有效前沿是指在给定风险水平下，能够提供最高期望收益的投资组合，或者在给定收益水平下，具有最小风险的投资组合的集合。有效前沿可以用以下步骤计算：

1. 计算各资产的期望收益、方差和协方差。
2. 使用优化算法（如均值-方差优化）求解各可能的组合的期望收益和方差。
3. 找到所有可能组合中，在相同风险下收益最大，或相同收益下风险最小的组合。
4. 这些最优组合构成有效前沿。

以下是一个简单的优化模型：

$$ \text{minimize } \sigma_p^2 $$
$$ \text{subject to } E(r_p) = \mu $$

其中，\( \mu \) 是目标期望收益。

#### 2.2.3 如何构建最优投资组合

构建最优投资组合需要考虑投资者的风险承受能力和收益目标。通过有效前沿，投资者可以选择位于前沿上的组合，以实现最佳的风险-收益平衡。

### 2.3 分散投资的数学模型实现

#### 2.3.1 投资组合优化的代码实现

以下是一个简单的投资组合优化的Python代码示例，使用`numpy`和`scipy`库：

```python
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def portfolio_variance(weights, covariance_matrix):
    return (weights.T @ covariance_matrix @ weights)[0, 0]

# 定义约束条件
def portfolio_return(weights, expected_returns):
    return weights.T @ expected_returns

# 示例数据
n_assets = 3
expected_returns = np.array([0.1, 0.15, 0.08])
covariance_matrix = np.array([
    [0.02, 0.01, 0.01],
    [0.01, 0.03, 0.01],
    [0.01, 0.01, 0.02]
])

# 初始化权重
initial_weights = np.array([1/3, 1/3, 1/3])

# 最小化方差，约束期望收益为0.1
cons = ({'type': 'eq', 'fun': lambda w: portfolio_return(w, expected_returns) - 0.1})
result = minimize(portfolio_variance, initial_weights, args=(covariance_matrix,), constraints=cons, method='SLSQP')

print("最优权重:", result.x)
print("最小方差:", result.fun)
```

#### 2.3.2 使用数学公式进行风险调整

在构建投资组合时，可以通过调整权重来降低风险。例如，如果两资产之间的相关性较低，可以通过增加低相关的资产权重来分散风险。相关性可以用以下公式表示：

$$ \rho_{ij} = \frac{Cov(r_i, r_j)}{\sigma_i \sigma_j} $$

通过选择相关性较低的资产，可以有效降低组合的整体风险。
