# 第1章: 特价股票投资的背景与概述

## 1.1 特价股票的基本概念  
### 1.1.1 特价股票的定义与特点  
- 特价股票是指价格低于市场平均值的股票，通常具有较高的投资潜力。  
- 特价股票的特点包括低估值、高增长潜力和较高的波动性。  

### 1.1.2 特价股票与传统股票投资的区别  
- 投资策略：传统投资注重长期价值，而特价股票投资更关注短期价格波动。  
- 风险水平：特价股票风险较高，但潜在回报也更大。  

### 1.1.3 特价股票的投资价值与风险  
- 投资价值：低估值股票可能被市场忽视，具有较高的反弹潜力。  
- 风险：高波动性和低流动性可能导致较大的投资风险。  

## 1.2 行为金融学的背景与核心理论  
### 1.2.1 行为金融学的定义与研究领域  
- 行为金融学研究投资者心理与行为对金融市场的影响。  
- 核心领域包括情绪决策、认知偏差和群体行为。  

### 1.2.2 行为金融学与传统金融学的区别  
- 传统金融学假设投资者是理性的，而行为金融学强调投资者的非理性行为。  
- 传统金融学基于数学模型，行为金融学结合心理学理论。  

### 1.2.3 行为金融学的核心理论与模型  
- 基础理论：有限理性理论、框架效应和心理账户理论。  
- 核心模型： prospect theory 和损失厌恶理论。  

## 1.3 神经科学与投资决策的关系  
### 1.3.1 神经科学的基本概念与研究方法  
- 神经科学研究大脑结构与功能。  
- 常用方法包括fMRI、EEG和TMS。  

### 1.3.2 大脑与投资决策的关系  
- 大脑的奖励机制影响投资者的风险偏好。  
- 情绪中枢（如杏仁核）影响投资决策的快感与恐惧。  

### 1.3.3 神经科学在金融领域的应用现状  
- 研究投资者情绪与决策的关系。  
- 应用神经技术优化投资策略。

## 3.1 行为金融学的基本理论

### 3.2.3 损失厌恶与风险偏好

## 3.3 行为金融学与群体行为

- 羊群效应：投资者模仿他人决策，导致市场波动。  

### 3.3.2 市场情绪与投资者行为  
- 市场情绪影响股价波动。  

### 3.3.3 行为金融学对市场波动的解释
