# 第2章 净净流动资产的数学模型与公式

## 2.1 净净流动资产的计算公式
- 净净流动资产 = 流动资产 - 流动负债
- $$\text{净净流动资产} = \text{流动资产} - \text{流动负债}$$

## 2.2 投资安全边际的计算
- $$\text{安全边际} = \text{内在价值} - \text{市场价格}$$

## 2.3 净净流动资产与企业价值的关系
- $$\text{企业价值} = \text{净净流动资产} \times \text{安全边际倍数}$$
