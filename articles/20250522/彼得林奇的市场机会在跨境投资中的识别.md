  ```python
  def calculate_market_opportunity(fundamental_indicators, technical_indicators, macro_indicators):
      # 計算基本面指標的加權和
      fundamental_score = sum(fundamental_indicators) / len(fundamental_indicators)
      # 計算技術指標的加權和
      technical_score = sum(technical_indicators) / len(technical_indicators)
      # 計算宏觀指標的加權和
      macro_score = sum(macro_indicators) / len(macro_indicators)
      # 組合指標得分
      market_opportunity_score = (fundamental_score + technical_score + macro_score) / 3
      return market_opportunity_score
  ```
