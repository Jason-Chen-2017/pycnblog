## 1.1 反周期投资的核心概念
### 1.1.1 什么是反周期投资
反周期投资是指在市场处于低谷期时进行投资，等待市场复苏时获得超额收益的投资策略。其核心思想是“买别人不愿买的东西，在别人恐慌时买入”。

### 1.1.2 反周期投资的起源与发展
反周期投资理念起源于20世纪80年代，彼得·林奇在其管理的麦哲伦基金中成功运用这一策略，取得了显著的投资业绩。

### 1.1.3 彼得林奇的反周期投资理念
彼得林奇认为，市场周期是可预测的，投资者应在市场低谷时寻找优质资产进行投资。

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 获取加密货币价格数据
def get_crypto_price(symbol):
    # 模拟数据获取
    return pd.DataFrame({'price': np.random.rand(100) * 100 + 50})

# 市场周期识别算法
def identify_market_cycle(data):
    model = LinearRegression()
    model.fit(pd.DataFrame(data.index), data['price'])
    return model.predict(pd.DataFrame(data.index))

# 反周期投资决策算法
def reverse_cycle_strategy(data, predicted_price):
    buy_price = data['price'].min()
    sell_price = data['price'].max()
    return buy_price, sell_price

# 主函数
def main():
    symbol = 'BTC'
    data = get_crypto_price(symbol)
    predicted_price = identify_market_cycle(data)
    buy_price, sell_price = reverse_cycle_strategy(data, predicted_price)
    print(f"买入价格：{buy_price}, 卖出价格：{sell_price}")

if __name__ == "__main__":
    main()
```
