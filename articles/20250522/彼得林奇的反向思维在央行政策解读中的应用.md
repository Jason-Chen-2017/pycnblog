## 第2章：央行政策的基础知识

### 2.1 央行政策的定义与目标
央行政策旨在通过调节货币供应和利率，实现经济稳定和物价控制。目标包括维持低通胀和促进就业。

### 2.2 央行政策的主要工具
- **利率政策**：调整基准利率影响借贷成本。
- **货币供应量控制**：通过公开市场操作调节货币供给。
- **公开市场操作**：买卖政府债券影响市场流动性。

```python
from statsmodels.tsa.arima.model import ARIMA

# 数据预处理
data = pd.read_csv('policy_data.csv')
data_diff = data['GDP_growth'].diff().dropna()

# 模型训练
model = ARIMA(data_diff, order=(1,1,0))
model_fit = model.fit()

# 预测
forecast = model_fit.forecast(steps=5)
```
