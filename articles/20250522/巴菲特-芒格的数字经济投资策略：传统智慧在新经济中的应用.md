#### 第1章：巴菲特与芒格的投资智慧

##### 1.1 巴菲特与芒格的背景介绍
###### 1.1.1 巴菲特的价值投资理念
沃伦·巴菲特是价值投资的代表人物，他强调以低于内在价值的价格购买优质资产，并长期持有。他的投资哲学基于基本面分析和安全边际。

###### 1.1.2 芒格的多元思维模型
查理·芒格提出“多元思维模型”，强调通过多学科交叉思考，找到投资中的“圆环”，即多个优势互补的领域，从而做出更明智的决策。

###### 1.1.3 两人合作的投资哲学
巴菲特和芒格的合作基于对价值投资的共同信仰，芒格的多元思维模型为巴菲特的投资决策提供了更广阔的视角。

##### 1.2 巴菲特-芒格投资策略的核心要素
###### 1.2.1 安全边际
安全边际是指买入价格低于内在价值的部分，确保在市场波动中仍能获得超额收益。

###### 1.2.2 竞争优势与护城河
巴菲特强调投资具有可持续竞争优势的企业，例如成本优势、品牌溢价或网络效应。

###### 1.2.3 长期视角与复利效应
长期投资和复利效应是巴菲特策略的核心，他选择能够长期增值的企业，通过时间的复利效应实现财富增长。

##### 1.3 数字经济的兴起与投资机会
###### 1.3.1 数字经济的定义与特征
数字经济是指以数字技术为核心驱动力，通过数据的产生、处理和应用来创造价值的经济形态。

###### 1.3.2 数字经济与传统经济的对比
数字经济具有数据驱动、网络效应强、边际成本低等特点，与传统经济差异明显。

###### 1.3.3 数字经济中的投资机会
数字经济的快速发展带来了大量投资机会，特别是在人工智能、云计算和大数据等领域。

### 第二部分：巴菲特-芒格投资策略的理论基础

#### 第2章：价值投资的基石

##### 2.1 价值投资的核心原则
###### 2.1.1 价格与价值的区分
价值投资的核心是区分资产的市场价格和内在价值，寻找价格低于内在价值的投资标的。

###### 2.1.2 市场先生的疯狂与理性
巴菲特将市场比作“市场先生”，认为市场情绪波动为投资者提供了低买高卖的机会。

###### 2.1.3 安全边际的计算方法
安全边际通过比较市场价格与内在价值，确保投资的安全性。

##### 2.2 竞争优势的分析框架
###### 2.2.1 经济护城河的类型
经济护城河包括成本优势、品牌溢价、网络效应和技术壁垒。

###### 2.2.2 成本优势的评估
通过分析企业的成本结构，判断其是否具备可持续的成本优势。

###### 2.2.3 品牌溢价的分析
品牌溢价能力强的企业能够通过品牌定价获得超额利润。

##### 2.3 长期视角与复利思维
###### 2.3.1 复利的数学模型
复利公式为：A = P(1 + r/n)^(nt)，其中A是终值，P是本金，r是年利率，n是每年的复利次数，t是时间。

###### 2.3.2 时间的复利效应
时间越长，复利效应越显著，长期投资能带来更大的收益。

###### 2.3.3 投资组合的长期优化
通过优化投资组合，分散风险，长期实现资产增值。

```python
import pandas as pd
import numpy as np

def calculate_value(stock_data):
    # 计算DCF模型
    free_cash_flow = stock_data['free_cash_flow']
    discount_rate = 0.1
    terminal_value = free_cash_flow[-1] * (1 + discount_rate)
    present_value = terminal_value / (1 + discount_rate)
    return present_value
```

```python
    model = linear_model.LinearRegression()
```
