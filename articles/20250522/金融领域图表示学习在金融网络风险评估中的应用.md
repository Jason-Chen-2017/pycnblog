## 第二部分: 图表示学习的核心算法与数学模型

### 第3章: 图表示学习的主流算法

#### 3.1 节点嵌入算法
- **Skip-Gram模型**
  - 基于概率的模型，通过优化目标函数生成节点表示。
  - 适用于处理大规模数据。
  - 公式：$$P(w_i|w_j) = \prod_{k=1}^n (P(w_k|w_j))^{A_{jk}}$$
- **CBOW模型**
  - 基于上下文的模型，通过平均向量生成节点表示。
  - 适用于处理局部上下文信息。
- **Word2Vec在图中的应用**
  - 将图中的节点视为词语，使用Word2Vec生成节点表示。
  - 适用于处理节点之间的局部关系。

#### 3.2 图嵌入算法
- **DeepWalk算法**
  - 基于随机游走的算法，通过生成句子来学习节点表示。
  - 适用于处理复杂图结构。
  - 公式：$$P(w_{i+1}|w_i) = \sum_{k=1}^n \theta_k P(w_k|w_i)$$
- **Node2Vec算法**
  - 基于随机游走的增强版本，支持可调节的探索深度。
  - 适用于处理不同类型的图结构。
- **GraphSAGE算法**
  - 基于归纳式学习的算法，适用于处理未知图结构。
  - 公式：$$h_i = \sigma(A h_j + b)$$

#### 3.3 对比学习算法
- **图对比学习的基本原理**
  - 通过最大化相似节点的表示相似性，最小化不相似节点的表示相似性。
  - 适用于处理图中的噪声和不确定性。
- **MoNet算法**
  - 基于对比学习的算法，通过学习节点的对比特征向量。
  - 适用于处理大规模图数据。
- **SimGNN算法**
  - 基于对比学习的图神经网络算法，通过学习图的对比表示。
  - 适用于处理复杂的图结构。

### 第4章: 图表示学习的数学模型

#### 4.1 节点表示模型
- **节点表示的数学表达**
  - 节点表示为低维向量，表示节点的语义信息。
  - 公式：$$z_i = f(x_i)$$
  - 其中，$x_i$是节点$i$的输入特征，$f$是表示函数。
- **节点表示的优化目标**
  - 优化节点表示，使得相似节点的表示相似，不相似节点的表示不同。
  - 公式：$$\min_{z} \sum_{i,j} w_{ij} ||z_i - z_j||^2$$
  - 其中，$w_{ij}$是节点$i$和$j$之间的权重。

#### 4.2 图结构特征的数学表达
- **图结构特征的表示**
  - 图结构特征包括社区结构、中心性等。
  - 公式：$$C_i = \sum_{j} A_{ij}$$
  - 其中，$A_{ij}$是节点$i$和$j$之间的边存在性矩阵，$C_i$是节点$i$的度数。
- **图结构特征的优化目标**
  - 优化图结构特征，使得图的结构特征能够反映节点的语义信息。
  - 公式：$$\min_{z} \sum_{i} \lambda ||z_i - f(C_i)||^2$$
  - 其中，$\lambda$是调节参数，$f$是图结构特征的函数。

#### 5.2 核心代码实现
- **数据加载与处理**
  ```python
  import networkx as nx
  G = nx.read_edgelist('financial_graph.edgelist')
  ```
- **节点表示学习**
  ```python
  from node2vec import Node2Vec
  model = Node2Vec(G, walks_per_node=10, context=5)
  model.fit()
  ```
- **风险评估**
  ```python
  from sklearn.cluster import KMeans
  embeddings = model.get_embeddings()
  kmeans = KMeans(n_clusters=3).fit(embeddings)
  clusters = kmeans.labels_
  ```
- **可视化**
  ```python
  import matplotlib.pyplot as plt
  plt.scatter(embeddings[:, 0], embeddings[:, 1], c=clusters, cmap='viridis')
  plt.show()
  ```
