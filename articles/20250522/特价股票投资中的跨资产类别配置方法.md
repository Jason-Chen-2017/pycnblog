### 第6章：投资组合优化的数学模型

#### 6.1 均值-方差优化模型
- 6.1.1 模型公式：
  $$ \min \sigma^2 = w^T \Sigma w $$
  $$ \text{约束条件：} \sum w_i = 1, \sum w_i r_i = \text{目标收益} $$
- 6.1.2 应用案例：假设三个资产类别（股票、债券、基金），通过Python优化求解最优权重。

#### 6.2 风险平价配置

- 6.2.2 实现步骤：计算各资产的风险贡献，调整权重以实现风险平价。

#### 7.2 投资组合优化代码
```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def portfolio_optimization(returns, cov_matrix, target_return=0.05):
    n = len(cov_matrix)
    # 定义目标函数
    def objective(weights):
        return np.dot(weights.T, np.dot(cov_matrix, weights))
    # 定义约束条件
    constraints = []
    # 总和为1
    constraints.append({'type': 'eq', 'fun': lambda w: sum(w) - 1})
    # 达到目标收益
    constraints.append({'type': 'eq', 'fun': lambda w: np.dot(returns.T, w) - target_return})
    # 初始权重
    initial_weights = np.array([1/n]*n)
    # 使用SLSQP求解器
    result = minimize(objective, initial_weights, constraints=constraints, method='SLSQP')
    return result.x
```

# 示例代码：计算最优资产配置
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def portfolio_optimization(returns, cov_matrix, target_return=0.05):
    n = len(cov_matrix)
    initial_weights = np.array([1/n]*n)
    # 目标函数：最小化方差
    def objective(weights):
        return np.dot(weights.T, np.dot(cov_matrix, weights))
    # 约束条件
    constraints = []
    constraints.append({'type': 'eq', 'fun': lambda w: sum(w) - 1})
    constraints.append({'type': 'eq', 'fun': lambda w: np.dot(returns.T, w) - target_return})
    result = minimize(objective, initial_weights, constraints=constraints, method='SLSQP')
    return result.x

# 示例数据
returns = np.array([0.1, 0.05, 0.08])
cov_matrix = np.array([
    [0.04, 0.02, 0.01],
    [0.02, 0.03, 0.01],
    [0.01, 0.01, 0.02]
])
weights = portfolio_optimization(returns, cov_matrix)
print(weights)
