##### 3.2 移动平均线的计算公式
- 3.2.1 简单移动平均线（SMA）的计算公式
  $$SMA = \frac{P_1 + P_2 + \dots + P_n}{n}$$
- 3.2.2 加权移动平均线（WMA）的计算公式
  $$WMA = \sum_{i=1}^{n} w_i \times P_i$$
  其中，$\sum_{i=1}^{n} w_i = 1$

##### 3.3 移动平均线的优缺点
- 3.3.1 优点
  - 简单易懂
  - 能够平滑价格波动
- 3.3.2 缺点
  - 无法预测价格趋势
  - 对于短期波动敏感

##### 3.4 移动平均线的实现代码
```python
import pandas as pd

def calculate_sma(data, window):
    return data['收盘价'].rolling(window).mean()

# 示例数据
data = pd.DataFrame({
    '收盘价': [100, 102, 101, 103, 104]
})
window = 3

sma = calculate_sma(data, window)
print(sma)
```

##### 3.5 移动平均线的数学模型
$$MA_t = \frac{1}{n}\sum_{i=1}^{n} P_{t-i}$$
其中，$P_{t-i}$ 是第 $t-i$ 天的收盘价，$n$ 是窗口大小。

import matplotlib.pyplot as plt

data = pd.DataFrame({

plt.title('简单移动平均线（SMA）')
plt.xlabel('日期')
plt.ylabel('价格')
plt.legend()
plt.show()
