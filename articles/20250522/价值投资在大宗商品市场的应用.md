# 第1章: 价值投资的基本概念

## 1.1 价值投资的起源与发展

### 1.1.1 价值投资的起源
价值投资起源于20世纪初，由本杰明·格雷厄姆和戴维·多德提出，强调以低于内在价值的价格购买优质资产。

### 1.1.2 核心思想
价值投资的核心是寻找市场先生的错误定价，通过深入分析企业的基本面，寻找价格与价值的偏差。

### 1.1.3 与其它投资策略的对比
- **趋势投资**：依赖价格趋势，短期波动性高。
- **技术分析**：基于价格形态和指标，主观性较强。
- **价值投资**：注重内在价值，长期持有，周期性波动中寻找机会。

## 1.2 大宗商品市场的特点与分类

### 1.2.1 大宗商品的分类
- **能源类**：原油、天然气。
- **金属类**：黄金、铜。
- **农业类**：小麦、大豆。

### 1.2.2 市场结构
- **交易所交易**：如纽约商品交易所。
- **场外交易**：非标准化合约。

### 1.2.3 影响价格的因素
- **供需关系**：宏观经济、行业需求。
- **政策因素**：政府干预、贸易政策。
- **市场情绪**：投资者心理。

## 1.3 价值投资与大宗商品市场的结合

### 1.3.1 价值投资的适用性
大宗商品市场的价格波动大，但具有周期性，适合价值投资。

### 1.3.2 周期性分析
- **上涨周期**：需求驱动。
- **下跌周期**：供给过剩或需求下降。

### 1.3.3 挑战
- **流动性风险**。
- **波动性高**。

### 2.1.2 需求端

## 2.2 周期性分析

### 2.2.1 行业周期
- **复苏期**：价格回升。
- **繁荣期**：需求旺盛。
- **衰退期**：价格暴跌。

## 2.3 风险管理

### 2.3.1 风险分类
- **市场风险**：价格波动。
- **流动性风险**：交易不畅。
- **信用风险**：交易对手违约。

### 2.3.2 风险管理原则
- **分散投资**：降低单一资产风险。
- **对冲策略**：使用期货对冲价格波动。
