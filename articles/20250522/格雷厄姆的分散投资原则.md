## 第一部分: 分散投资的背景与核心概念

### 第1章: 格雷厄姆与分散投资概述

#### 1.1 格雷厄姆的生平与投资理念

格雷厄姆（Benjamin Graham）是20世纪最重要的投资思想家之一，被誉为“价值投资之父”。他提出的分散投资原则是其投资理念的核心，旨在通过分散投资降低风险，实现长期稳定的收益。

- **生平简介**：格雷厄姆出生于1894年，20世纪初进入华尔街，经历了1929年大萧条，这使他形成了稳健的投资理念。
- **投资哲学**：格雷厄姆强调安全边际和长期价值，认为市场波动是投资机会的来源。
- **与价值投资的关系**：格雷厄姆的分散投资原则是价值投资的重要组成部分，强调在合理估值的基础上分散投资，降低风险。

#### 1.2 分散投资的核心概念

分散投资是指通过将资金分配到不同的资产或资产类别中，以降低投资组合的整体风险。其核心原则包括：

- **风险分散**：通过投资不同资产或行业，降低特定资产的风险。
- **资产配置**：根据市场环境和投资者风险偏好，合理分配资产比例。
- **长期收益**：分散投资不仅降低风险，还能通过资产配置实现长期稳定收益。

### 第2章: 分散投资的数学模型与原理

#### 2.1 投资组合的数学模型

现代投资组合理论（MPT）为分散投资提供了理论基础，其核心是通过优化投资组合的收益-风险比来实现收益最大化。

- **期望收益与方差**：投资组合的期望收益和风险（方差）是衡量投资组合优劣的核心指标。
  - 期望收益公式：$$ E(r_p) = \sum w_i E(r_i) $$
  - 方差公式：$$ Var(r_p) = \sum w_i^2 \sigma_i^2 + 2\sum_{i<j} w_i w_j \sigma_i \sigma_j \rho_{ij} $$

- **有效前沿**：在给定风险下，投资组合的收益最大；在给定收益下，风险最小的组合构成的曲线即为有效前沿。

#### 2.2 现代投资组合理论（MPT）

- **核心假设**：投资者是理性的，市场是有效的，资产收益服从正态分布。
- **投资组合优化模型**：通过优化数学模型实现投资组合的最优配置。
  - 最优化问题：$$ \text{Minimize } \sum w_i^2 \sigma_i^2 + 2\sum_{i<j} w_i w_j \sigma_i \sigma_j \rho_{ij} $$
  - 约束条件：$$ \sum w_i = 1 $$

  def optimize_portfolio(return_matrix):
      n = return_matrix.shape[0]
      cov_matrix = return_matrix.T.dot(return_matrix) / n
      mu = np.mean(return_matrix, axis=0)
      # 使用优化算法求解最优权重
      w = np.linalg.solve(cov_matrix, mu)
