### 第3章：智能优化算法的原理与实现

#### 3.1 算法原理概述
- 3.1.1 遗传算法
  - 3.1.1.1 算法流程图（Mermaid）
    ```mermaid
    graph TD
      A[初始化种群] --> B[计算适应度]
      B --> C[选择适应体]
      C --> D[进行交叉]
      D --> E[进行变异]
      E --> F[判断是否满足终止条件]
      F --> G[输出结果]
    ```
  - 3.1.1.2 Python代码示例
    ```python
    import random

    def fitness(x):
        # 定义适应度函数
        return x * (1 - x)

    def select_parents(population, fitness_values):
        # 选择父代
        total_fitness = sum(fitness_values)
        selection_prob = [f / total_fitness for f in fitness_values]
        parents = []
        for _ in range(2):
            r = random.random()
            for i in range(len(selection_prob)):
                if r < selection_prob[i]:
                    parents.append(population[i])
                    break
        return parents

    def crossover(parent1, parent2):
        # 单点交叉
        crossover_point = random.randint(1, len(parent1)-1)
        return parent1[:crossover_point] + parent2[crossover_point:], parent2[:crossover_point] + parent1[crossover_point:]

    def mutate(individual):
        # 突变
        mutation_point = random.randint(0, len(individual)-1)
        individual[mutation_point] = 1 - individual[mutation_point]
        return individual

    def genetic_algorithm(pop_size, gen_num):
        population = [[random.randint(0,1) for _ in range(2)] for _ in range(pop_size)]
        for _ in range(gen_num):
            fitness_values = [fitness(ind[0] + ind[1]) for ind in population]
            parents = select_parents(population, fitness_values)
            child1, child2 = crossover(parents[0], parents[1])
            child1 = mutate(child1)
            child2 = mutate(child2)
            new_population = [child1, child2] + [ind for ind in population if ind not in [child1, child2]]
            population = new_population
        return population
    ```

  - 3.1.1.3 数学模型与公式
    $$适应度函数：f(x) = x(1 - x)$$
