### 第1章: 逆向思维的基本概念

#### 1.1 逆向思维的定义与特点
- **1.1.1 逆向思维的定义**
  逆向思维是指从问题的对立面出发，寻找解决方案的一种思维方式。与正向思维不同，逆向思维强调从反面思考，通过排除错误来接近正确答案。

- **1.1.2 逆向思维的特点**
  - **反向性**：从对立面出发解决问题。
  - **独特性**：能够发现正向思维难以察觉的机会和风险。
  - **系统性**：需要结合多元思维模型，全面分析问题。

- **1.1.3 逆向思维与其他思维方式的对比**
  | 思维方式       | 定义                                   | 特点                                   |
  |----------------|--------------------------------------|--------------------------------------|
  | 正向思维       | 从正面出发解决问题                   | 直观，但可能忽视对立面的问题           |
  | 逆向思维       | 从对立面出发解决问题                 | 独特，能够发现潜在风险和机会           |
  | 综合思维       | 结合多种思维方式进行综合分析         | 全面，但复杂性较高                     |

- **6.2.1 数据分析代码**
  ```python
  import pandas as pd

  # 数据采集
  def collect_data():
      # 示例数据
      data = {'price': [100, 105, 98, 110], 'risk': [0.1, 0.2, 0.15, 0.05]}
      return pd.DataFrame(data)

  # 风险评估
  def assess_risk(data):
      return data['price'].std()

  # 投资策略
  def determine_strategy(price, risk):
      if price > 105 and risk < 0.1:
          return "买入"
      else:
          return "观望"

  # 主函数
  def main():
      data = collect_data()
      risk = assess_risk(data)
      price = data['price'].mean()
      strategy = determine_strategy(price, risk)
      print(f"当前策略：{strategy}")

  if __name__ == "__main__":
      main()
  ```
