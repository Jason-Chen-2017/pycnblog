# 第4章: 耐心资本的数学模型与算法

## 4.1 资产配置模型  

### 4.1.1 背景介绍  
资产配置是耐心资本的核心，通过科学分配各类资产比例，优化风险收益。

### 4.1.2 数学公式  
$$\text{最优资产配置} = \arg\min_w \left( w^T \Sigma w - \lambda w^T \mu \right)$$

### 4.1.3 算法实现  
使用均值-方差优化模型，通过求解上述公式找到最优资产配置比例。

## 4.2 风险调整收益模型  

### 4.2.1 背景介绍  
风险调整收益模型用于衡量投资组合的风险调整后收益，帮助决策者评估风险与收益的平衡。

### 4.2.2 数学公式  
$$\text{夏普比率} = \frac{\mu_p - \mu_f}{\sigma_p}$$

### 4.2.3 实现步骤  
计算投资组合的超额收益和标准差，计算夏普比率，评估风险调整收益。

```python
import numpy as np
import pandas as pd

def optimize_portfolio(returns):
    n = returns.shape[1]
    returns_cov = returns.cov()
    returns_mu = returns.mean(axis=0)
    
    w = np.zeros(n)
    w[0] = 1
    
    while True:
        inv = returns_cov.dot(w)
        inv = inv / inv.sum()
        new_w = returns_mu.dot(inv)
        if np.max(np.abs(new_w - w)) < 1e-5:
            break
        w = new_w
    return w
```

    excess_returns = returns - factor_returns
    sharpe_ratio = (excess_returns.mean() / excess_returns.std())
