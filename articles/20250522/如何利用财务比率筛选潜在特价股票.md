### 第3章：流动比率与速动比率

- 3.1 流动比率的计算与意义
  - 公式：流动比率 = 流动资产 / 流动负债
  - 示例计算：某公司流动资产为100万元，流动负债为50万元，流动比率为2。
  - 解释：流动比率越高，短期偿债能力越强。
- 3.2 速动比率的计算与意义
  - 公式：速动比率 = (流动资产 - 存货) / 流动负债
  - 示例计算：某公司流动资产为100万元，存货为30万元，流动负债为50万元，速动比率为(70/50)=1.4。
  - 解释：速动比率衡量公司在不依赖存货的情况下偿还短期债务的能力。
- 3.3 流动比率与速动比率在筛选特价股票中的应用
  - 示例：通过计算某公司的流动和速动比率，判断其短期偿债能力，进而评估其财务健康状况。

### 第4章：财务比率对公司的财务健康状况的影响

- 4.1 负债比率的计算与意义
  - 公式：负债比率 = 总负债 / 总资产
  - 示例计算：某公司总负债为80万元，总资产为200万元，负债比率为40%。
  - 解释：负债比率高意味着公司依赖债务融资，风险较大。
- 4.2 资产回报率（ROA）
  - 公式：ROA = 净利润 / 平均总资产
  - 示例计算：某公司净利润为50万元，平均总资产为200万元，ROA=25%。
  - 解释：ROA高表示公司资产使用效率高，盈利能力强。
- 4.3 净资产收益率（ROE）
  - 公式：ROE = 净利润 / 净资产
  - 示例计算：某公司净利润为50万元，净资产为100万元，ROE=50%。
  - 解释：ROE高表示公司使用股东资金的效率高，股东收益好。
- 4.4 毛利率
  - 公式：毛利率 = (营业收入 - 营业成本) / 营业收入
  - 示例计算：某公司营业收入为200万元，营业成本为120万元，毛利率=40%。
  - 解释：毛利率高表示公司在产品定价和成本控制上有优势。

### 第5章：如何通过财务比率筛选特价股票

- 5.1 确定筛选标准
  - 流动比率 ≥ 2
  - 速动比率 ≥ 1
  - 负债比率 ≤ 50%
  - ROA ≥ 10%
  - ROE ≥ 15%
  - 毛利率 ≥ 20%
- 5.2 实际案例分析
  - 案例：假设某公司财务数据如下：
    - 流动资产：150万元
    - 流动负债：75万元
    - 总负债：100万元
    - 总资产：300万元
    - 净利润：30万元
    - 营业收入：200万元
    - 营业成本：80万元
  - 计算各项比率并判断是否符合筛选标准：
    - 流动比率 = 150 / 75 = 2（符合）
    - 速动比率 = (150 - 假设存货为30万元) / 75 = 1.67（符合）
    - 负债比率 = 100 / 300 ≈ 33.33%（符合）
    - ROA = 30 / (300/2) = 20%（符合）
    - ROE = 30 / (300 - 100) = 15%（符合）
    - 毛利率 = (200 - 80) / 200 = 60%（符合）
  - 结论：该公司符合所有筛选标准，可能是一只特价股票。
