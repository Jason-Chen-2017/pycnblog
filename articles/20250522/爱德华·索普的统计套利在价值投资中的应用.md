## 第2章: 统计套利的数学基础

### 2.1 均值回归模型
- 均值回归假设价格会回归到历史平均值，常用于配对交易中。
- 公式：$$E(t) = E(t-1) + α \cdot (μ - E(t-1))$$
  其中，E(t)是当前价格，E(t-1)是上一期价格，μ是目标均值，α是收敛系数。

### 2.2 配对交易策略
- 通过选取相关资产对，利用它们的价格差异进行套利。
- 步骤：选择相关资产、计算价差、建立头寸、监控价差回归。

### 2.3 方差最小化模型
- 通过最小化投资组合的方差，优化风险。
- 公式：$$\text{Minimize } \sigma^2 = \mathbf{w}^T \mathbf{C} \mathbf{w}$$
  其中，w是权重向量，C是协方差矩阵。

def mean_reversion_strategy(prices, window=30):
    mean = prices.rolling(window).mean()
    std = prices.rolling(window).std()
    z_scores = (prices - mean) / std
    return z_scores
