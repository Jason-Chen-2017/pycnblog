# 第3章: 异常检测算法原理

## 3.1 基于统计的异常检测算法

### 3.1.1 马尔可夫链模型  
通过状态转移概率判断数据序列的异常性。  
$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$  

### 3.1.2 Z-Score方法  
通过计算数据点与均值的偏离程度。  
$$Z = \frac{x - \mu}{\sigma}$$  

### 3.1.3 LOF算法  
通过局部密度对比判断异常点。  
$$LOF(x) = \frac{d(x, k NN) }{d(k NN, x)}$$  

---

## 3.2 基于机器学习的异常检测算法

### 3.2.1 Isolation Forest算法  
通过随机森林算法，隔离异常点。  
代码示例：
```python
from sklearn.ensemble import IsolationForest
model = IsolationForest(contamination=0.05)
model.fit(X)
```

### 3.2.2 One-Class SVM算法  
通过支持向量机，学习正常数据的分布。  
代码示例：
```python
from sklearn.svm import OneClassSVM
model = OneClassSVM(nu=0.05)
model.fit(X)
```

---

## 3.3 时间序列异常检测算法

### 3.3.1 ARIMA模型  
通过时间序列建模，预测并识别异常。  
$$ARIMA(p, d, q)$$  

### 3.3.2 LSTM网络  
通过深度学习模型，捕捉时间序列的复杂模式。  
代码示例：
```python
import keras
from keras.layers import LSTM, Dense
model = keras.Sequential()
model.add(LSTM(64, input_shape=(timesteps, features)))
model.add(Dense(1))
model.compile(loss='mean_squared_error', optimizer='adam')
```
