## 第二部分: 格兰瑟姆的内在价值评估方法

### 第2章: 内在价值评估的核心方法

#### 2.1 现金流折现模型（DCF）
##### 2.1.1 DCF模型的步骤
1. 估计未来现金流。
2. 选择合适的折现率。
3. 计算现值并加总，得出内在价值。

#### 2.2 市盈率与市净率分析
##### 2.2.1 市盈率分析
通过比较市盈率与行业平均，识别低估或高估的股票。公式为P/E = 价格/每股收益。

##### 2.2.2 市净率分析
适用于资产密集型行业，公式为P/B = 价格/每股净资产。

## 第五部分: 投资策略的数学模型

### 第5章: 数学模型与实战应用

#### 5.1 内在价值计算公式
使用DCF模型计算内在价值：
$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n} $$
其中，CF_t是第t年的现金流，r是折现率，TV是终值。

#### 5.2 市场情绪指数计算
通过Python代码计算市场情绪指数：

import pandas as pd
import numpy as np

def calculate_market_sentiment(stocks, benchmark):

    avg_sentiment = np.mean(sentiment)
    return avg_sentiment
