## # 第二部分: 格雷厄姆财务分析方法的核心原理

### ## 第2章: 内在价值评估方法

#### ### 2.1 内在价值的定义与计算
- **2.1.1 内在价值的定义**：企业未来现金流的现值，不依赖于市场波动。
- **2.1.2 计算公式**：$$\text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$
  其中，$CF_t$ 是第 $t$ 年的现金流，$r$ 是折现率。
- **2.1.3 内在价值与市场价值的关系**：内在价值是目标，市场价值是结果。

#### ### 2.2 防御性投资策略
- **2.2.1 定义**：通过购买低于内在价值的股票，确保安全边际。
- **2.2.2 核心原则**：分散投资、避免过度集中、注重安全边际。
- **2.2.3 实施步骤**：识别低估股票、计算内在价值、评估安全边际。

#### ### 2.3 安全边际的概念与应用
- **2.3.1 安全边际的定义**：内在价值与市场价格之间的差距，提供缓冲空间。
- **2.3.2 计算公式**：$$\text{安全边际} = \text{内在价值} - \text{市场价格}$$
- **2.3.3 应用案例**：通过实际案例分析，展示安全边际在投资决策中的作用。

## # 第三部分: 格雷厄姆财务分析方法的数学模型与公式

### ## 第3章: 内在价值计算的数学模型

#### ### 3.1 内在价值计算的公式推导
- **3.1.1 基本公式**：使用股利折现模型或自由现金流模型计算内在价值。
- **3.1.2 变量解释**：现金流、折现率、增长率。
- **3.1.3 应用条件**：假设现金流稳定，企业处于成熟阶段。

#### ### 3.2 案例分析
- **3.2.1 案例背景**：假设某公司未来5年的现金流分别为100、120、140、160、180万元，折现率为10%。
- **3.2.2 计算过程**：
  - 第1年：$100 / (1.1)^1 = 90.91$
  - 第2年：$120 / (1.1)^2 = 96.12$
  - 第3年：$140 / (1.1)^3 = 99.68$
  - 第4年：$160 / (1.1)^4 = 97.93$
  - 第5年：$180 / (1.1)^5 = 95.64$
  - 内在价值 = $90.91 + 96.12 + 99.68 + 97.93 + 95.64 = 480.28$万元
- **3.2.3 结果分析**：计算出的内在价值为480.28万元，市场价格低于该值时值得投资。

#### ### 3.3 注意事项
- 数据准确性：现金流预测需基于历史数据和行业分析。
- 假设合理性：折现率和增长率的假设需合理。
- 结果解释：内在价值不是固定值，需定期更新。

      intrinsic_value = 0
