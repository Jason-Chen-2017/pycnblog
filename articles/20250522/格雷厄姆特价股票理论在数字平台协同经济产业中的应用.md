### 1.2 格雷厄姆的价值投资理念

#### 核心概念：
- **内在价值**：股票的真正价值是其未来现金流的现值。
- **安全边际**：购买价格低于内在价值，以降低投资风险。

### 1.3 格雷厄姆投资理论的数学模型

#### 格雷厄姆计算公式：
$$ V = \frac{P}{E} + \frac{P}{B} + \frac{P}{(E + B)} $$
其中，V为股票的内在价值，P为当前股价，E为每股盈余，B为每股账面价值。

### 1.4 现代化投资理论对格雷厄姆理论的继承与创新

#### 对比表格：
| 核心概念       | 格雷厄姆理论                     | 现代投资理论                     |
|----------------|---------------------------------|----------------------------------|
| 投资目标       | 寻找被低估的股票                | 多元化投资以降低风险             |
| 分析方法       | 基于基本面分析                  | 基于概率和统计分析               |
| 风险管理       | 安全边际                        | 标准差、夏普比率等                |

## 第二章: 格雷厄姆特价股票筛选模型

### 2.1 格雷厄姆筛选模型的数学实现

#### 算法流程图：
```mermaid
graph TD
    A[开始] --> B[输入股票数据]
    B --> C[计算市盈率和市净率]
    C --> D[判断是否低于内在价值]
    D --> E[输出符合标准的股票]
    E --> F[结束]
```

#### Python实现代码：
```python
import pandas as pd

def graham_screen(stock_data):
    # 计算内在价值
    stock_data['V'] = stock_data['P'] / stock_data['E'] + stock_data['P'] / stock_data['B'] + stock_data['P'] / (stock_data['E'] + stock_data['B'])
    # 筛选条件：股价 < 内在价值且市盈率 < 15
    filtered = stock_data[(stock_data['P'] < stock_data['V']) & (stock_data['PE'] < 15)]
    return filtered

# 示例数据
data = {
    'P': [50, 30, 40],
    'E': [10, 5, 8],
    'B': [15, 10, 12],
    'PE': [10, 12, 8]
}
stock_data = pd.DataFrame(data)
print(graham_screen(stock_data))
```

## 第六章: 项目实战

### 6.1 环境安装与数据准备

#### 环境要求：
- Python 3.8+
- Pandas库
- Matplotlib库

### 6.2 核心代码实现

#### 实现代码：
```python
import pandas as pd
import matplotlib.pyplot as plt

# 数据准备
data = {
    '股票代码': ['A', 'B', 'C'],
    '股价': [50, 30, 40],
    '每股盈余': [10, 5, 8],
    '每股账面价值': [15, 10, 12],
    '市盈率': [10, 12, 8]
}
df = pd.DataFrame(data)

# 计算内在价值
df['内在价值'] = df['股价'] / df['每股盈余'] + df['股价'] / df['每股账面价值'] + df['股价'] / (df['每股盈余'] + df['每股账面价值'])

# 筛选符合标准的股票
筛选标准：股价 < 内在价值 且 市盈率 < 15
符合标准的股票 = df[(df['股价'] < df['内在价值']) & (df['市盈率'] < 15)]

# 可视化结果
符合标准的股票.plot(kind='bar', x='股票代码', y='股价')
plt.title('符合格雷厄姆筛选标准的股票')
plt.show()
```
