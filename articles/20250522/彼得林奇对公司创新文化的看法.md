#### 3.3 算法实现代码
以下为创新文化评估的Python代码示例：

```python
def calculate_innovation_culture_score(criteria_scores, weights):
    # 计算加权平均
    weighted_scores = [score * weight for score, weight in zip(criteria_scores, weights)]
    total = sum(weighted_scores)
    return total / sum(weights)

# 示例数据
criteria_scores = [8, 7, 9]
weights = [0.4, 0.3, 0.3]

score = calculate_innovation_culture_score(criteria_scores, weights)
print(f"创新文化综合评分为: {score}")
```
