### 3.2 基于规则的舆情分析算法

#### 3.2.1 基于关键词匹配的舆情分析

**代码示例**：
```python
def sentiment_analysis(text):
    positive_words = ["great", "excellent"]
    negative_words = ["bad", "terrible"]
    score = 0
    for word in text.split():
        if word in positive_words:
            score += 1
        elif word in negative_words:
            score -= 1
    return score
```

#### 3.2.2 基于句法分析的舆情分析
