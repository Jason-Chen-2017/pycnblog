### 第1章：价值投资与格雷厄姆策略背景

#### 1.1 价值投资的起源与发展
- **1.1.1 价值投资的定义与核心理念**
  - 价值投资是一种以内在价值为导向的投资策略，强调以低于内在价值的价格买入优质资产。
  - 核心理念：市场先生是理性的，股票价格波动提供投资机会。

- **1.1.2 格雷厄姆与多德的价值投资体系**
  - 格雷厄姆和多德共同提出的价值投资理论，奠定了现代价值投资的基础。
  - 格雷厄姆的“安全边际”概念：内在价值与市场价格之间的差距，确保投资的安全性。

- **1.1.3 格雷厄姆策略的核心要素**
  - 专注于基本面分析，寻找被市场低估的股票。
  - 强调长期投资，避免短期波动的干扰。

#### 1.2 特价股票策略的基本概念
- **1.2.1 特价股票的定义与特征**
  - 特价股票：市场价格显著低于内在价值的股票。
  - 特征：低估值、高分红、稳定的财务状况。

- **1.2.2 格雷厄姆的安全边际理论**
  - 安全边际 = 内在价值 - 市场价格。
  - 安全边际越大，投资风险越小。

- **1.2.3 特价股票与市场周期的关系**
  - 特价股票在熊市中更容易出现，牛市中稀缺。
  - 市场周期影响安全边际的计算和投资机会的选择。

#### 1.3 格雷厄姆策略在现代投资中的地位
- **1.3.1 格雷厄姆策略的现代应用**
  - 现代投资者如何结合格雷厄姆策略进行投资。
  - 结合技术分析和基本面分析的综合策略。

- **1.3.2 与其他投资策略的对比分析**
  - 与成长型投资策略的区别与联系。
  - 与趋势投资策略的对比。

- **1.3.3 格雷厄姆策略的局限性与改进方向**

## 第2章：不同市场周期的特征与影响

### 2.1 市场周期的基本分类
- **2.1.1 牛市周期**
  - 特征：市场情绪乐观，股价高估。
  - 影响：格雷厄姆策略在牛市中难以找到足够的特价股票。

- **2.1.2 熊市周期**
  - 特征：市场情绪悲观，股价低估。
  - 影响：格雷厄姆策略在熊市中容易找到廉价的特价股票。

- **2.1.3 震荡市周期**
  - 特征：市场波动剧烈，股价波动频繁。
  - 影响：格雷厄姆策略需要频繁调整安全边际计算。

- **2.1.4 低波动市周期**
  - 特征：市场波动小，股价稳定。
  - 影响：格雷厄姆策略需要寻找稳定增长的内在价值。

### 2.2 不同市场周期对股票估值的影响
- **2.2.1 牛市中的高估值现象**
  - 市场情绪推动股价上涨，内在价值被高估。
  - 格雷厄姆策略难以找到合适的投资标的。

- **2.2.2 熊市中的低估现象**
  - 市场恐慌导致股价下跌，内在价值被低估。
  - 格雷厄姆策略可以找到廉价的特价股票。

- **2.2.3 震荡市中的估值波动**
  - 市场波动导致股价频繁波动，内在价值计算复杂。
  - 格雷厄姆策略需要动态调整。

- **2.2.4 低波动市中的稳定估值**
  - 市场稳定，股价波动小。
  - 格雷厄姆策略可以寻找稳定的内在价值增长。

### 2.3 市场周期对格雷厄姆策略的挑战
- **2.3.1 高估值环境下的策略调整**
  - 减少投资标的筛选标准，寻找相对低估的股票。
  - 降低安全边际要求，增加投资标的数量。

- **2.3.2 低估值环境下的策略优化**
  - 提高安全边际要求，增加投资标的筛选标准。
  - 增加投资标的数量，分散风险。

- **2.3.3 震荡环境下的策略适应性**
  - 动态调整安全边际计算，适应市场波动。
  - 增加风险管理措施，控制投资风险。

## 第3章：格雷厄姆特价股票策略的算法原理

### 3.1 格雷厄姆策略的核心算法
- **3.1.1 安全边际计算公式**
  $$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

- **3.1.2 内在价值评估模型**
  - 基于市盈率、市净率等指标计算内在价值。
  - 示例：$$ \text{内在价值} = \text{每股收益} \times \text{合理市盈率} $$

- **3.1.3 市场价格与内在价值的对比分析**
  - 通过对比分析确定安全边际。
  - 代码示例：
    ```python
    def calculate_margin_of_safety(intrinsic_value, market_price):
        return intrinsic_value - market_price
    ```

### 3.2 市场周期对策略算法的影响
- **3.2.1 不同周期下的算法调整**
  - 牛市：降低安全边际要求。
  - 熊市：提高安全边际要求。

- **3.2.2 周期识别算法的设计与实现**
  - 基于技术指标（如RSI、MACD）识别市场周期。
  - 代码示例：
    ```python
    def identify_market_cycle(rsi, macd):
        if rsi < 30 and macd < 0:
            return "bear"
        elif rsi > 70 and macd > 0:
            return "bull"
        else:
            return "oscillating"
    ```

- **3.2.3 周期适应性调整的数学模型**
  - 根据市场周期调整安全边际计算公式。
  - 示例：$$ \text{调整后安全边际} = \text{安全边际} \times \text{周期调整系数} $$

### 3.3 算法实现的代码示例
- **3.3.1 安全边际计算代码**
