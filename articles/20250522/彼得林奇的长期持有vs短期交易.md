# 第1章: 投资基础与策略概述

## 1.1 投资的基本概念

### 1.1.1 什么是投资
投资是指将资金投入某种资产，以期在未来获得收益的行为。投资的目标是通过资产增值或收入增加来实现财富增长。

### 1.1.2 投资的基本原则
- 分散投资：降低风险。
- 长期视角：时间是投资的朋友。
- 价值分析：寻找被低估的资产。

### 1.1.3 投资的分类与特点
- **长期投资**：注重资产的内在价值，适合价值投资者。
- **短期交易**：关注市场波动，适合技术分析者。

## 1.2 彼得林奇的投资理念

### 1.2.1 彼得林奇的生平简介
彼得·林奇是美国著名的投资经理，以管理富达麦哲伦基金而闻名，长期持有策略使他取得了卓越的业绩。

### 1.2.2 彼得林奇的投资哲学
- 买入优秀企业的股票，长期持有。
- 避免频繁交易，减少成本。

### 1.2.3 经典投资案例
- 投资于具有持续增长潜力的公司。

## 1.3 长期持有与短期交易的定义

### 1.3.1 长期持有的定义与特点
- 长期持有：买入并持有优质资产，等待其价值增长。
- 特点：低交易成本、高复利效应。

### 1.3.2 短期交易的定义与特点
- 短期交易：频繁买卖资产，利用价格波动获利。
- 特点：高流动性、高风险。

### 1.3.3 两种策略的优缺点对比

| 策略 | 优点 | 缺点 |
|------|------|------|
| 长期持有 | 稳定收益、低交易成本 | 忽略短期波动、需长期看好标的 |
| 短期交易 | 灵活、捕捉短期机会 | 高成本、高风险 |

## 1.4 本章小结
本章介绍了投资的基本概念，彼得林奇的投资理念，并对比了长期持有和短期交易的优缺点。

# 第3章: 短期交易的策略分析

## 3.1 短期交易的核心理念

### 3.1.1 短期交易的投资逻辑
- 利用市场波动，频繁买卖获利。

### 3.1.2 短期交易的优势
- 灵活应对市场变化。

### 3.1.3 短期交易的风险与挑战
- 高交易成本、高市场风险。

## 3.2 短期交易的策略类型

### 3.2.1 日内交易
- 当天买入并卖出，规避隔夜风险。

### 3.2.2 波动交易
- 利用价格波动，多次买卖。

### 3.2.3 事件驱动交易
- 基于公司事件（如并购）进行交易。

## 3.3 短期交易的数学模型

### 3.3.1 短期收益的计算公式
$$ \text{短期收益} = \sum_{i=1}^{n} (\text{卖出价}_i - \text{买入价}_i) $$

### 3.3.2 风险评估公式
$$ \text{风险} = \text{波动率} \times \text{交易次数} $$

## 3.4 本章小结
本章分析了短期交易的策略类型和数学模型，指出了其优缺点。

```python
import pandas as pd
import matplotlib.pyplot as plt

# 获取股票数据
data = pd.read_csv('stock.csv')

# 简单移动平均线策略
short_window = 10
long_window = 20

data['SMA_short'] = data['Close'].rolling(short_window).mean()
data['SMA_long'] = data['Close'].rolling(long_window).mean()

# 生成交易信号
data['signal'] = 0
data['signal'][data['SMA_short'] > data['SMA_long']] = 1
data['signal'][data['SMA_short'] < data['SMA_long']] = -1

# 计算收益
data['profit'] = data['signal'].shift(1) * data['Close'].pct_change()

print(data.tail())
```
