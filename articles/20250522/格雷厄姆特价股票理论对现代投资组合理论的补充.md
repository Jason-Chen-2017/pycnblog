# 第1章: 格雷厄姆特价股票理论与现代投资组合理论的背景

## 1.1 格雷厄姆与多德的价值投资理论

### 1.1.1 格雷厄姆的生平与贡献
本杰明·格雷厄姆（Benjamin Graham）是价值投资的鼻祖，他的投资理念深刻影响了沃伦·巴菲特等投资大师。格雷厄姆强调以低于内在价值的价格买入股票，注重安全边际和防御性投资策略。

### 1.1.2 多德对价值投资的影响
多德（David Dodd）是格雷厄姆的合作伙伴，两人共同提出了“安全边际”和“内在价值”概念。多德的研究为价值投资理论奠定了基础，特别是在股票筛选和估值方法上具有重要贡献。

### 1.1.3 价值投资的核心理念
价值投资的核心理念是寻找市场价格低于内在价值的股票，通过安全边际降低投资风险。格雷厄姆提出，投资者应关注企业的基本面，而非市场的短期波动。

## 1.2 现代投资组合理论的起源

### 1.2.1 马科维茨的均值-方差模型
马科维茨（Harry Markowitz）在1952年提出了均值-方差模型，这是现代投资组合理论的基础。该模型通过优化投资组合的期望收益与风险（方差）之比，帮助投资者找到最优投资组合。

### 1.2.2 资本资产定价模型（CAPM）
CAPM模型由夏普（William Sharpe）等人提出，用于计算资产的预期收益。CAPM假设市场是有效的，并通过系统性风险（beta）来衡量资产的风险。

### 1.2.3 投资组合理论的发展历程
从马科维茨的均值-方差模型到CAPM，现代投资组合理论不断完善，为投资者提供了科学的资产配置方法。然而，这些模型假设市场是理性的，忽略了投资者的行为偏差和市场非理性。

## 1.3 格雷厄姆特价股票理论与现代投资组合理论的异同

### 1.3.1 格雷厄姆特价股票理论的特点
格雷厄姆的理论注重股票的内在价值和安全边际，强调长期投资和防御性策略。其核心是寻找被市场低估的股票。

### 1.3.2 现代投资组合理论的核心假设
现代投资组合理论假设市场是有效的，资产收益符合正态分布，并且可以通过优化模型找到最优投资组合。

### 1.3.3 两者的联系与区别
两者都关注风险与收益的平衡，但格雷厄姆的理论更注重个股的估值和安全性，而现代投资组合理论更注重整体资产配置和风险分散。

# 第2章: 格雷厄姆特价股票理论的核心概念

## 2.1 安全边际的概念与计算

### 2.1.1 安全边际的定义
安全边际是市场价格与内在价值之间的差异，确保投资者在买入股票时有足够安全的空间。

### 2.1.2 安全边际的计算公式
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

### 2.1.3 安全边际在投资决策中的应用
投资者应选择安全边际较高的股票，以降低市场波动带来的风险。

## 2.2 内在价值的评估方法

### 2.2.1 内在价值的定义
内在价值是基于公司基本面（如盈利能力、现金流）计算出的股票合理价值。

### 2.2.2 内在价值的计算模型
$$ \text{内在价值} = \frac{\text{每股收益}}{\text{资本成本} - \text{增长率}} $$

### 2.2.3 内在价值评估的注意事项
内在价值评估需考虑公司成长性、行业竞争状况和宏观经济环境。

## 2.3 防御性投资策略

### 2.3.1 防御性投资的定义
防御性投资是指通过投资优质股票和债券，降低投资组合波动性的策略。

### 2.3.2 防御性投资的实施步骤
1. 筛选低市盈率、低市净率的股票；
2. 计算股票的内在价值；
3. 选择安全边际高的股票进行投资。

### 2.3.3 防御性投资的风险控制
通过分散投资和定期再平衡，降低投资组合的整体风险。

# 第3章: 现代投资组合理论的核心原理

## 3.1 马科维茨的均值-方差模型

### 3.1.1 均值-方差模型的数学公式
$$ \text{优化目标：} \min_w \sigma^2 $$
$$ \text{约束条件：} \sum_{i=1}^n w_i = 1 $$

### 3.1.2 均值-方差模型的假设条件
- 资产收益符合正态分布；
- 市场是有效的；
- 投资者风险偏好相同。

### 3.1.3 均值-方差模型的应用场景
用于优化投资组合的风险与收益比，特别是在市场波动性较低的情况下。

## 3.2 资本资产定价模型（CAPM）

### 3.2.1 CAPM的数学公式
$$ R_i = R_f + \beta_i (R_m - R_f) $$

### 3.2.2 CAPM的假设条件
- 市场是有效的；
- 资产收益符合CAPM模型；
- 投资者可以无成本借贷。

### 3.2.3 CAPM在投资组合优化中的应用
用于计算资产的预期收益，作为投资组合优化的输入。

## 3.3 投资组合的有效前沿

### 3.3.1 有效前沿的定义
有效前沿是所有可能投资组合中风险最低或收益最高的点的集合。

### 3.3.2 有效前沿的计算方法
通过马科维茨模型计算得出，考虑资产的期望收益和方差。

### 3.3.3 有效前沿在投资决策中的应用
帮助投资者找到最优风险收益比的投资组合。

### 7.2.2 应用马科维茨模型
```python
from scipy.optimize import minimize

def portfolio_variance(weights, covariance_matrix):
    return np.dot(weights.T, np.dot(covariance_matrix, weights))

# 优化目标函数
def min_variance(weights, covariance_matrix):
    return portfolio_variance(weights, covariance_matrix)

# 约束条件
def weight_sum(weights):
    return np.sum(weights) - 1

# 优化投资组合
covariance_matrix = data.cov()
result = minimize(min_variance, np.ones(len(covariance_matrix)) / len(covariance_matrix), 
                 constraints={'type': 'eq', 'fun': weight_sum})
```

### 7.2.3 可视化结果

import matplotlib.pyplot as plt

plt.legend()
plt.show()
