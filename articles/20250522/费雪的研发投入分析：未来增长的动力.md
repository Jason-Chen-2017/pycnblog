#### 4.2 Python实现代码

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据准备
data = pd.DataFrame({
    'R&D': [100, 200, 150, 300],
    'Capital_Efficiency': [0.8, 0.9, 0.7, 1.0],
    'GDP': [500, 600, 550, 700]
})

# 模型选择
model = LinearRegression()

# 参数估计
X = data[['R&D', 'Capital_Efficiency']]
y = data['GDP']
model.fit(X, y)

# 模型验证
predictions = model.predict(X)
print('预测值:', predictions)
print('系数:', model.coef_)
print('截距:', model.intercept_)
```
