## 第二部分: 机会资金的算法原理

### 第2章: 投资机会评估的算法原理

#### 2.1 净现值法（NPV）
- 2.1.1 净现值的定义与公式
  - $$NPV = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}$$
  - 其中，CF_t是第t年的现金流，r是贴现率
- 2.1.2 净现值计算的步骤
  - 确定现金流
  - 确定贴现率
  - 计算现值并求和
  - 减去初始投资
- 2.1.3 净现值法的优缺点
  - 优点：考虑了资金的时间价值，计算简单
  - 缺点：依赖于贴现率的选择，无法反映项目的收益能力

#### 2.2 内部收益率法（IRR）
- 2.2.1 内部收益率的定义与公式
  - $$IRR是使NPV=0的贴现率$$
- 2.2.2 内部收益率计算的步骤
  - 确定初始投资和未来现金流
  - 通过试算法或插值法计算IRR
- 2.2.3 内部收益率法的优缺点
  - 优点：直观反映了项目的收益能力
  - 缺点：假设项目现金流再投资于相同利率的假设不合理

#### 2.3 现金流贴现模型（DCF）
- 2.3.1 DCF模型的定义与公式
  - $$DCF = \sum_{t=1}^{\infty} \frac{CF_t}{(1+r)^t}$$
- 2.3.2 DCF模型的计算步骤
  - 确定现金流
  - 确定贴现率
  - 计算现值并求和
- 2.3.3 DCF模型的优缺点
  - 优点：全面考虑了项目未来现金流
  - 缺点：依赖于长期现金流的预测准确性

### 第5章: 投资机会评估的实战应用

#### 5.2 系统核心实现源代码
- 5.2.1 投资机会评估系统代码
```python
import numpy as np

def npv(cash_flows, discount_rate):
    return sum(cf / (1 + discount_rate) ** t for t, cf in enumerate(cash_flows))

def irr(cash_flows):
    return np.irr(cash_flows)

# 示例
cash_flows = [-100, 50, 60, 70]
discount_rate = 0.1

print("NPV:", npv(cash_flows, discount_rate))
print("IRR:", irr(cash_flows))
```

#### 5.3 实际案例分析
- 5.3.1 案例背景
  - 投资项目：开一家咖啡店
  - 初始投资：100万元
  - 预计现金流：第一年50万元，第二年60万元，第三年70万元
  - 贴现率：10%

- 5.3.2 计算NPV和IRR
  - NPV = 50/(1.1) + 60/(1.1)^2 + 70/(1.1)^3 - 100 ≈ 27.48 + 49.72 + 50.28 - 100 = 27.48
  - IRR ≈ 20%

- 5.3.3 投资决策
  - NPV > 0，项目可行
  - IRR > 贴现率，项目有利可图
