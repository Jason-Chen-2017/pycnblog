### 6.2 核心实现源代码

#### 6.2.1 数据分析与评估算法
```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('renewable_energy_companies.csv')

# 加权评分计算
weights = {'财务状况': 0.3, '技术优势': 0.4, '管理能力': 0.3}
scores = data[['财务状况', '技术优势', '管理能力']].apply(lambda x: sum(x[i] * weights[i] for i in weights), axis=1)
data['综合评分'] = scores

# 投资决策
threshold = 0.75
data['投资建议'] = data['综合评分'].apply(lambda x: '买入' if x >= threshold else '卖出')

print(data.head())
```
