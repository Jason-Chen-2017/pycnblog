# 第一部分: 引言

## 第1章: 格雷厄姆NCAV策略概述

### 1.1 NCAV策略的背景与重要性

#### 1.1.1 价值投资的起源与发展
价值投资是投资学中的一个重要流派，由本杰明·格雷厄姆和戴维·多德在20世纪初创立。格雷厄姆通过分析企业的基本面，寻找那些市场价格低于其内在价值的股票，从而实现长期稳定的收益。

#### 1.1.2 格雷厄姆的投资理念与NCAV策略
格雷厄姆认为，市场波动往往会导致股票价格与实际价值脱节。他提出NCAV（Net Current Asset Value）策略，即通过计算每股市净率（NCAV）来衡量股票的内在价值。当NCAV值低于股票的市场价格时，该股票被认为是被市场低估的投资机会。

#### 1.1.3 NCAV策略在现代投资中的应用价值
尽管NCAV策略是一种较为简单的价值评估方法，但在实际投资中仍具有重要的参考价值。特别是在当前市场环境下，通过NCAV策略可以帮助投资者发现那些被市场忽视的潜在价值股。

### 1.2 NCAV策略的核心概念

#### 1.2.1 NCAV的定义与计算公式
NCAV（Net Current Asset Value）是指每股市净率（即流动资产减去流动负债后的净值除以流通股数）。公式如下：
$$NCAV = \frac{流动资产 - 流动负债}{流通股数}$$

#### 1.2.2 NCAV与股票内在价值的关系
NCAV是衡量股票内在价值的重要指标。当NCAV值远低于股票市场价格时，说明该股票可能被市场低估，具有较大的上涨潜力。

#### 1.2.3 NCAV策略的适用场景与边界
NCAV策略适用于那些流动资产占比较高的公司，特别是那些负债较少、现金流稳定的公司。然而，该策略并不适用于所有类型的公司，例如那些需要大量固定资产支持的行业。

### 1.3 本章小结
本章介绍了格雷厄姆NCAV策略的背景、核心概念及其在现代投资中的应用价值。通过NCAV策略，投资者可以快速筛选出那些被市场低估的股票，为投资决策提供重要参考。

# 第二部分: 格雷厄姆NCAV策略的理论基础

## 第2章: 格雷厄姆NCAV策略的核心原理

### 2.1 格雷厄姆NCAV策略的数学模型

#### 2.1.1 NCAV的计算公式
$$NCAV = \frac{流动资产 - 流动负债}{流通股数}$$

#### 2.1.2 净资产的构成与计算
流动资产包括现金、应收账款、存货等，流动负债包括应付账款、短期借款等。通过计算流动资产减去流动负债，可以得到公司的净流动资产。

#### 2.1.3 流动资产与非流动资产的区分
流动资产是指可以在一年内变现的资产，而非流动资产则包括长期投资、固定资产等。在计算NCAV时，通常只考虑流动资产和流动负债。

### 2.2 NCAV与股票价值的关系

#### 2.2.1 NCAV低于股票价格的含义
当NCAV值低于股票市场价格时，说明该股票的市场价格被市场低估，具有较大的上涨空间。

#### 2.2.2 NCAV与市场价的偏离分析
通过对比NCAV与市场价格，投资者可以判断股票是否被低估。当NCAV远低于市场价格时，说明股票具有较高的投资价值。

#### 2.2.3 NCAV策略的选股逻辑
格雷厄姆NCAV策略的核心逻辑是通过寻找那些NCAV值远低于市场价格的股票，从而实现超额收益。

### 2.3 格雷厄姆NCAV策略的优缺点

#### 2.3.1 优点：简单、可操作性强
NCAV策略的计算方法简单，易于理解和操作，特别适合那些不熟悉复杂估值模型的投资者。

#### 2.3.2 缺点：忽略市场情绪与宏观经济因素
NCAV策略仅考虑了公司的基本面因素，忽略了市场情绪、宏观经济环境等其他因素，可能导致策略失效。

#### 2.3.3 补充策略的必要性
为了弥补NCAV策略的不足，投资者可以结合其他估值方法（如市盈率、市净率等）进行综合分析。

### 2.4 本章小结
本章详细讲解了格雷厄姆NCAV策略的数学模型、核心原理及其与股票价值的关系。通过对比分析，揭示了NCAV策略的优缺点，并提出了补充策略的必要性。

# 第三部分: 格雷厄姆NCAV策略的实战应用

## 第3章: NCAV策略的选股流程

### 3.1 确定选股范围

#### 3.1.1 行业选择与筛选标准
选择那些流动资产占比较高、负债较少的行业，如制造业、零售业等。

#### 3.1.2 市值与流动性要求
优先选择市值适中、流动性较强的股票，以确保交易的便捷性和流动性。

#### 3.1.3 财务数据的获取与处理
通过财务报表获取流动资产、流动负债等数据，并进行必要的数据清洗和处理。

### 3.2 计算NCAV值

#### 3.2.1 净资产的计算步骤
计算流动资产减去流动负债，得到净流动资产。

#### 3.2.2 流通股数的确定方法
通过公司公告或财务报表获取流通股数。

#### 3.2.3 NCAV值的计算与比较
将净流动资产除以流通股数，得到NCAV值，并与市场价格进行对比。

### 3.3 筛选极度低估的股票

#### 3.3.1 NCAV值低于股票价格的条件
当NCAV值远低于市场价格时，说明该股票被市场低估，具有较大的投资价值。

#### 3.3.2 市盈率与市净率的辅助分析
通过市盈率和市净率等指标，进一步验证股票的估值情况。

#### 3.3.3 财务健康状况的进一步验证
分析公司的盈利能力、成长能力等指标，确保公司具有良好的财务健康状况。

### 3.4 本章小结
本章详细介绍了NCAV策略的选股流程，包括行业选择、数据获取、NCAV计算以及股票筛选等步骤，为投资者提供了具体的实战指导。
