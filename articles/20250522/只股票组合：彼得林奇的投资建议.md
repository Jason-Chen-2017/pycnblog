## 第三章: 算法原理讲解

### 3.1 股票组合优化的数学模型

#### 3.1.1 最优化目标函数

$$ \text{最大化收益} = \sum_{i=1}^{n} w_i r_i $$

#### 3.1.2 约束条件

$$ \sum_{i=1}^{n} w_i = 1 $$
$$ w_i \geq 0 \quad \text{对所有} i $$

### 3.2 股票组合优化的Python实现

```python
import numpy as np
from scipy.optimize import minimize

# 定义目标函数
def objective(weights, returns):
    return -(weights.T @ returns).item()

# 定义约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 使用SLSQP优化算法
result = minimize(objective, np.ones(len(returns)) / len(returns), 
                  constraints={'type': 'equality', 'fun': constraint},
                  bounds=[(0, 1)] * len(returns))

# 输出优化结果
optimized_weights = result.x
print("优化后的权重:", optimized_weights)
```

### 5.2 核心实现源代码

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

# 数据加载与预处理
data = pd.read_csv('stock_data.csv')
returns = data.pct_change().dropna().values.T

# 定义目标函数
def objective(weights, returns):
    return -(weights.T @ returns).item()

# 定义约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 使用SLSQP优化算法
result = minimize(objective, np.ones(returns.shape[0]) / returns.shape[0], 
                  constraints={'type': 'equality', 'fun': constraint},
                  bounds=[(0, 1)] * returns.shape[0])

# 输出优化结果
optimized_weights = result.x
selected_stocks = np.where(optimized_weights > 0.01)[0]
print("优化后的权重:", optimized_weights)
print("精选股票:", selected_stocks)
```

### 5.3 代码应用解读与分析

代码首先加载数据并计算每只股票的收益率。然后定义目标函数和约束条件，使用优化算法求解最优权重。最终输出优化后的权重和精选股票。
