### 第三部分：算法原理讲解

#### 第3章：基于彼得林奇策略的投资组合优化算法

##### 3.1 算法原理  
- 投资决策流程：识别财务需求 → 确定资产配置 → 选择标的 → 定期调整  
- 基于CAPM模型的投资回报预测  
  $$ E(r) = r_f + β \cdot (E(r_m) - r_f) $$  

##### 3.2 算法流程图  
```mermaid
graph TD
    A[开始] --> B[确定财务目标]
    B --> C[评估风险承受能力]
    C --> D[选择资产配置]
    D --> E[选择具体标的]
    E --> F[定期 rebalancing]
    F --> G[结束]
```

##### 3.3 数学模型  
- 投资组合优化模型：  
  $$ \text{max} \quad \sum_{i=1}^{n} w_i \cdot r_i - \lambda \cdot \sum_{i=1}^{n} w_i^2 \cdot \sigma_i^2 $$  
  其中，\( w_i \) 为资产 \( i \) 的权重，\( r_i \) 为预期收益率，\( \sigma_i^2 \) 为波动率，\( \lambda \) 为风险厌恶系数。  

##### 3.4 代码实现  
```python
import numpy as np
from scipy.optimize import minimize

# 示例：优化投资组合
def portfolio_optimization(returns, cov_matrix, risk_aversion=1):
    n = len(returns)
    # 目标函数
    def objective(w):
        return -np.dot(w, returns @ w) + risk_aversion * w.T.dot(cov_matrix).dot(w)
    
    # 约束条件
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    
    # 初始猜测
    w0 = np.array([1.0/n]*n)
    
    # 最优化
    result = minimize(objective, w0, constraints=constraints, method='SLSQP')
    return result.x

# 示例数据
returns = np.array([0.1, 0.15, 0.08])
cov_matrix = np.array([
    [0.04, 0.01, 0.005],
    [0.01, 0.06, 0.01],
    [0.005, 0.01, 0.03]
])
weights = portfolio_optimization(returns, cov_matrix)
print(weights)
```

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 示例：模拟投资组合表现
def simulate_portfolio(assets, weights, returns, periods=10):
    portfolio_returns = []
    for _ in range(periods):
        current_return = np.dot(weights, returns)
        portfolio_returns.append(current_return)
        # 动态调整权重（示例）
        weights = weights * (1 + current_return)
        weights = weights / sum(weights)
    return portfolio_returns

# 示例数据
assets = ['股票', '债券', '房地产']
returns = np.array([0.1, 0.05, 0.08])
weights = np.array([0.6, 0.3, 0.1])

# 模拟
periods = 10
sim_returns = simulate_portfolio(assets, weights, returns, periods)
plt.plot(sim_returns)
plt.title('投资组合模拟回报')
plt.xlabel('年份')
plt.ylabel('回报率')
plt.show()
