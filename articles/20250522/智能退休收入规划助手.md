#### 6.1 核心代码实现

```python
import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据加载
data = pd.read_csv('retirement_data.csv')

# 特征与目标变量分离
X = data[['age', 'income', 'expenses']]
y = data['predicted_income']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测
predicted_income = model.predict(X)
```

#### 6.2 代码解读
