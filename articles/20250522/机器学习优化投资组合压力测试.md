# 第一部分: 机器学习与投资组合优化基础

## 第1章: 机器学习与投资组合优化概述

### 1.1 机器学习的基本概念

#### 1.1.1 机器学习的定义与核心概念
机器学习是一种人工智能技术，通过数据训练模型，使其能够从经验中学习并做出预测或决策。核心概念包括：
- **监督学习**：模型通过标记数据进行训练，预测新数据的标签。
- **无监督学习**：模型从无标记数据中发现结构。
- **特征工程**：选择和处理特征以提高模型性能。

#### 1.1.2 投资组合优化的定义与目标
投资组合优化是指在给定风险承受能力下，选择最优资产配置以最大化收益。目标包括：
- 最大化收益
- 最小化风险
- 确保资产配置的分散化

#### 1.1.3 机器学习在投资组合优化中的应用
机器学习可以用于预测资产价格、识别市场趋势和优化资产配置。

### 1.2 投资组合压力测试的背景与意义
压力测试用于评估投资组合在极端市场条件下的表现，帮助机构制定风险应对策略。

### 1.3 机器学习如何优化压力测试
通过分析历史数据和模拟极端情景，机器学习模型可以更准确地预测投资组合在压力下的表现。

## 第2章: 机器学习基础

### 2.1 监督学习与无监督学习

#### 2.1.1 监督学习
- **线性回归**：用于预测连续值，如股票价格。
- **随机森林**：用于分类和回归，具有高准确性和鲁棒性。

#### 2.1.2 无监督学习
- **聚类分析**：用于市场细分和客户群体划分。

### 2.2 常见机器学习算法

#### 2.2.1 线性回归
目标函数：$$\text{最小化} \sum (y_i - \hat{y_i})^2$$

#### 2.2.2 支持向量机 (SVM)
用于分类和回归，通过最大化边界间隔进行训练。

### 2.3 机器学习模型的评估与选择
- **准确率**：正确分类的比例。
- **召回率**：正确识别的正例比例。
- **F1值**：平衡准确率和召回率的指标。

### 6.2 核心实现

import pandas as pd
from sklearn.ensemble import RandomForestRegressor

# 数据加载
data = pd.read_csv('market_data.csv')

# 特征选择
features = data[['return', 'volatility', 'market_cap']]
labels = data['return']

# 模型训练
model = RandomForestRegressor()
model.fit(features, labels)

# 预测
new_data = pd.DataFrame({'return': [0.01], 'volatility': [0.15], 'market_cap': [1000000000]})
prediction = model.predict(new_data)
