## 第一部分：背景介绍

### 第1章：彼得·林奇的背景与投资理念

#### 1.1 彼得·林奇的生平与成就

彼得·林奇（Peter Lynch）是美国著名投资经理，曾管理富达麦哲伦基金，创造了年均29%的复合增长率。他强调基本面分析和管理层评估，认为高管团队的稳定性是投资成功的关键。

#### 1.2 高管团队稳定性的重要性

高管团队对公司战略执行、决策质量至关重要。稳定的高管团队通常能带来更高的业绩表现和股价稳定性。

#### 1.3 问题背景与描述

高管团队的稳定性影响公司长期发展，彼得·林奇通过分析高管 tenure、变动率等指标，评估团队稳定性，进而影响投资决策。

## 第二部分：核心概念与联系

### 第2章：彼得·林奇的核心投资理念

#### 2.1 高管团队稳定性的影响因素

- **tenure duration**：高管在公司服务的时间长度，长期 tenure 表示忠诚和稳定。
- **turnover rate**：高管的变动频率，低变动率表示稳定性高。
- **能力与决策质量**：高管的能力直接影响公司战略和业绩。

#### 2.2 彼得·林奇的高管团队评估模型

模型基于 tenure、turnover 和决策质量，综合评估团队稳定性。通过分析这些因素，彼得·林奇识别出具备长期稳定性的高管团队。

#### 3.2 Python代码实现

代码实现稳定性指数计算：

```python
import pandas as pd

def calculate_stability(data):
    data['tenure_score'] = data['tenure'].apply(lambda x: 0.5 if x > 10 else 0.3)
    data['turnover_score'] = data['turnover'].apply(lambda x: 0.7 if x < 5 else 0.4)
    data['decision_quality'] = data['decision_quality'].apply(lambda x: 0.8 if x > 7 else 0.5)
    data['stability_index'] = data[['tenure_score', 'turnover_score', 'decision_quality']].sum(axis=1)
    return data

# 示例数据
data = {
    'name': ['CEO', 'CFO', 'COO'],
    'tenure': [15, 8, 12],
    'turnover': [3, 7, 4],
    'decision_quality': [9, 6, 8]
}
df = pd.DataFrame(data)
result = calculate_stability(df)
print(result)
```

## 第四部分：数学模型与公式

### 第4章：稳定性指数模型

稳定性指数（SI）公式：

$$ SI = a \times \text{tenure} + b \times \text{turnover} + c \times \text{decision\_quality} $$

其中，$a$、$b$、$c$为权重系数，取值范围为$0 \leq a, b, c \leq 1$。通过实例验证模型的有效性，并进行参数优化。
