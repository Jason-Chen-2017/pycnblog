# 第3章 算法原理讲解

## 3.1 蒙特卡洛模拟
### 3.1.1 算法流程图
```mermaid

    Start --> InitializeParameters
```

### 3.1.2 Python实现
```python
import numpy as np

def monte_carlo_simulation(income, expense, target, years):
    simulations = 1000
    success_count = 0
    for _ in range(simulations):
        # 随机生成收入和支出变化
        income_growth = np.random.normal(0.05, 0.02)
        expense_growth = np.random.normal(0.03, 0.01)
        current_income = income * (1 + income_growth)
        current_expense = expense * (1 + expense_growth)
        savings = current_income - current_expense
        total = 0
        for _ in range(years):
            total += savings
            savings = savings * (1 + 0.02)  # 假设年回报率2%
        if total >= target:
            success_count += 1
    probability = success_count / simulations
    return probability

# 示例
income = 60000
expense = 40000
target = 1000000
years = 10
print(monte_carlo_simulation(income, expense, target, years))
```

### 3.1.3 举例说明
假设用户年收入6万元，年支出4万元，目标是100万元，期限10年。运行蒙特卡洛模拟，计算成功概率约为75%。

## 3.2 数学模型和公式
### 3.2.1 概率计算公式
$$ P(\text{成功}) = \frac{\text{成功模拟次数}}{\text{总模拟次数}} $$

### 3.2.2 期望值和方差
期望值：$$ E[X] = \mu $$
方差：$$ Var(X) = \sigma^2 $$
