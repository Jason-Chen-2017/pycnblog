# 第1章: 全球股市估值与碳捕获技术的背景介绍

## 1.1 全球股市估值的基本概念

### 1.1.1 股票估值的定义与意义
股票估值是通过对公司财务数据和市场环境的分析，估算公司股票的内在价值。股票估值的核心在于预测公司未来的盈利能力，并将其转化为当前的股票价值。股票估值是投资者决策的重要依据，也是股市运行的基础。

### 1.1.2 市场资本化率与企业价值评估
市场资本化率是衡量股市整体估值水平的重要指标，通常以市盈率（P/E）或市净率（P/B）来表示。企业价值评估则是通过对企业未来现金流的折现，估算企业的整体价值，进而得出每股价值。

### 1.1.3 股票估值的核心指标与方法
股票估值的核心指标包括市盈率（P/E）、市净率（P/B）、股息率（Dividend Yield）等。股票估值的方法主要有绝对估值法（DCF模型）和相对估值法（可比公司分析）。

## 1.2 碳捕获与存储技术的基本概念

### 1.2.1 碳捕获与存储技术的定义与分类
碳捕获与存储技术（CCS）是指将二氧化碳从工业过程或能源生产中捕获，并将其长期封存的过程。碳捕获技术主要包括吸收法、吸附法和膜分离法；碳存储技术主要包括地下储存和利用技术。

### 1.2.2 碳捕获技术的关键环节与流程
碳捕获技术的关键环节包括二氧化碳的分离、压缩、运输和封存。碳捕获技术的流程通常包括捕获、压缩、运输和封存四个阶段。

### 1.2.3 碳捕获技术的经济性与技术瓶颈
碳捕获技术的经济性主要体现在成本和收益的平衡上。目前，碳捕获技术的成本较高，主要瓶颈在于捕获效率和封存的安全性。

## 1.3 碳捕获技术与股市估值的关系

### 1.3.1 碳捕获技术对能源行业的潜在影响
碳捕获技术对能源行业的影响主要体现在减少碳排放和提高能源企业的环保形象。碳捕获技术的应用将减少能源企业的碳排放成本，提升企业的盈利能力。

碳捕获技术通过降低碳排放成本，间接提高了企业的盈利能力和市场竞争力，从而影响股市估值。
