## 第2章：小盘股价值评估的关键指标

### 2.1 市盈率（P/E）分析
- 公式：$$P/E = \frac{\text{股价}}{\text{每股净利润}}$$
- 低市盈率小盘股的筛选标准。

### 2.2 市净率（P/B）分析
- 公式：$$P/B = \frac{\text{股价}}{\text{每股净资产}}$$
- 市净率在小盘股评估中的应用。

### 2.3 股息率与股息支付率
- 股息率公式：$$\text{股息率} = \frac{\text{每股股息}}{\text{股价}}$$
- 股息支付率公式：$$\text{股息支付率} = \frac{\text{股息支付额}}{\text{净利润}}$$

```python
def filter_stocks(dataframe):
    # 筛选市值小于50亿元的股票
    mask = dataframe['Market Cap'] < 500000000
    dataframe = dataframe[mask]
    
    # 排除连续亏损的企业
    mask = dataframe['Net Profit'] > 0
    dataframe = dataframe[mask]
    
    # 筛选ROE高于行业平均的股票
    industry_avg_roe = dataframe['Industry ROE'].mean()
    mask = dataframe['ROE'] > industry_avg_roe
    dataframe = dataframe[mask]
    
    return dataframe
```

## 第5章：小盘股投资的风险控制

### 5.1 风险来源分析
- 市场风险：整体市场的波动。
- 个股风险：公司基本面变化。
- 流动性风险：小盘股的买卖价差大。

### 5.2 风险控制策略
- 仓位控制：单只股票不超过投资组合的5%。
- 风险分散：投资多个行业的小盘股。
- 定期复盘：及时调整持仓。

### 5.3 风险控制的代码实现
```python
def risk_control(portfolio):
    # 仓位控制
    for stock in portfolio:
        if portfolio[stock] > 0.05:
            portfolio[stock] = 0.05
    
    # 风险分散
    industry_weights = {}
    for stock in portfolio:
        industry = get_industry(stock)
        industry_weights[industry] = industry_weights.get(industry, 0) + portfolio[stock]
    
    # 超过行业权重上限的股票
    for industry in industry_weights:
        if industry_weights[industry] > 0.2:
            for stock in portfolio:
                if get_industry(stock) == industry:
                    portfolio[stock] *= 0.8
    
    return portfolio
```
