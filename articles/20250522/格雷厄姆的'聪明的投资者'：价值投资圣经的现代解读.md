## 第一章：价值投资的背景与核心概念

### 1.1 投资的基本概念与问题背景

#### 1.1.1 财务自由与投资的意义

- **财务自由**：通过投资实现收入超过支出，不再依赖于传统工作。
- **投资的意义**：资产增值、风险控制和财富保值。

#### 1.1.2 投资与投机的定义与区别

- **投资**：基于基本面分析，追求长期稳健收益。
- **投机**：基于市场波动，追求短期收益，风险较高。

#### 1.1.3 价值投资的定义和特点

- **定义**：购买低于内在价值的资产，长期持有。
- **特点**：注重安全边际，逆周期投资，分散风险。

### 1.2 价值投资的背景与问题描述

#### 1.2.1 现代投资环境的挑战

- 复杂的市场环境、信息过载、短期波动。
- 投资者情绪波动和认知偏差的影响。

#### 1.2.2 格雷厄姆价值投资理论的提出背景

- 20世纪30年代大萧条时期的市场教训。
- 格雷厄姆与巴菲特的合作奠定价值投资基础。

#### 1.2.3 当前市场中的价值投资机会与风险

- 低利率环境下的资产泡沫风险。
- 科技股高估值与传统行业的机会。

### 1.3 价值投资的核心要素与边界

#### 1.3.1 核心概念：安全边际、内在价值、市场先生

- **安全边际**：买入价格低于内在价值的部分，提供缓冲。
- **内在价值**：资产的真实价值，需通过基本面分析确定。
- **市场先生**：市场的波动性，投资者应利用而非跟随。

#### 1.3.2 价值投资的适用范围与边界

- 适用于成熟市场和可预测行业的资产。
- 不适合短期交易和高波动性资产。

## 第二章：价值投资的核心概念与联系

### 2.1 格雷厄姆的价值投资理论

#### 2.1.1 安全边际的定义与计算

- **定义**：买入价格与内在价值的差距。
- **计算**：内在价值 × 安全边际比例（如20%）。

#### 2.1.2 内在价值的评估方法

- **DCF模型**：通过现金流折现计算。
- **相对估值法**：比较市盈率、市净率等指标。

#### 2.1.3 市场先生的比喻与应用

- **市场波动**：投资者应利用市场先生的情绪，寻找低估资产。
- **独立思考**：不被市场情绪左右，坚持基本面分析。

### 2.2 价值投资与其他投资策略的对比

#### 2.2.1 价值投资与成长投资的对比

- **价值投资**：注重低估和安全边际。
- **成长投资**：注重高增长潜力，风险较高。

#### 2.2.2 价值投资与技术分析的对比

- **价值投资**：基本面分析为主。
- **技术分析**：市场走势预测，风险较高。

#### 2.2.3 价值投资与指数投资的对比

- **价值投资**：主动选择低估资产。
- **指数投资**：被动跟踪市场指数，风险分散。

## 第三章：价值投资的数学模型与量化分析

### 3.1 常用的估值指标

#### 3.1.1 市盈率（P/E）的计算与应用

- **公式**：P/E = 市场价 / 每股收益。
- **应用**：评估股票的相对估值。

#### 3.1.2 市净率（P/B）的计算与应用

- **公式**：P/B = 市场价 / 每股净资产。
- **应用**：适用于净资产驱动的行业。

#### 3.1.3 股息率的计算与应用

- **公式**：股息率 = 每股股息 / 市场价。
- **应用**：评估收益稳定性。

### 3.2 内在价值的数学模型

#### 3.2.1 现金流折现模型（DCF）的公式与应用

- **公式**：内在价值 = Σ（CF_t / (1 + r)^t） + 终值。
- **应用**：计算企业的真实价值。

#### 3.2.2 市场价值与内在价值的比较

- **市场价值**：市场价格波动，可能高于或低于内在价值。
- **内在价值**：基于基本面分析的理论价值。

#### 3.2.3 安全边际的量化计算

- **公式**：安全边际 = 内在价值 × 安全边际比例（如20%）。
- **应用**：确保买入价格低于内在价值。

### 5.2 核心实现源代码

#### 5.2.1 计算市盈率和市净率的Python代码

```python
import pandas as pd
import yfinance as yf

def get_stock_data(ticker):
    data = yf.download(ticker, start='2020-01-01', end='2023-12-31')
    return data

def calculate_pe_pb(ticker):
    data = get_stock_data(ticker)
    pe = data['Close'] / data['Adj Close'].rolling(4).mean()
    pb = data['Close'] / (data['Close'].rolling(4).mean() * 1.5)
    return pe, pb

ticker = 'AAPL'
pe, pb = calculate_pe_pb(ticker)
print(pe, pb)
```

#### 5.2.2 现金流折现模型的Python代码

```python
import numpy as np

def dcf_valuation(fcf, wacc, perpetuity_growth=0):
    terminal_value = fcf[-1] * (1 + perpetuity_growth) / (wacc - perpetuity_growth)
    dcfc = fcf / (1 + wacc)
    dcfc[-1] = terminal_value
    intrinsic_value = np.sum(dcfc)
    return intrinsic_value

dcf_valuation(fcf, wacc)
```
