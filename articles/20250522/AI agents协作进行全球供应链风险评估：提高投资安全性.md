## 第三部分: 算法原理

### 第5章: 基于图的网络风险传播模型

#### 5.1 算法原理
基于图的网络模型将供应链节点表示为图的节点，通过边权重表示影响程度。使用图传播算法计算每个节点的风险值。

#### 5.2 算法实现
```python
import networkx as nx

def calculate_risk(G):
    # 初始化风险值
    for node in G.nodes():
        G.nodes[node]['risk'] = 0
    # 传播过程
    for _ in range(10):
        for edge in G.edges():
            source, target = edge
            weight = G.edges[edge]['weight']
            G.nodes[target]['risk'] += G.nodes[source]['risk'] * weight
    return G
```
