##### 1.1 投资哲学的演变

###### 1.1.1 传统投资理论的局限性

传统投资理论，如基本面分析和价值投资，主要关注单个资产的内在价值。然而，这些方法在面对复杂市场和多变环境时显得力不从心，尤其是当投资者需要考虑多个变量和不确定性时。芒格的“智者圈”理论正是对传统投资理论的一种突破。

###### 1.1.2 芒格的投资哲学与"mental models"概念

芒格提出，投资者应该构建一个由多个“mental models”组成的知识网络，这些模型来自不同学科，如心理学、经济学、物理学等。通过这些模型，投资者可以更好地理解市场中的各种现象，并做出更明智的投资决策。

###### 1.1.3 "智者圈"理论的核心思想

“智者圈”理论强调，投资者应该专注于自己真正理解的领域，并与具有互补性知识的人建立信任关系。通过构建一个高质量的知识网络，投资者可以显著提高决策的准确性和投资的回报率。

##### 1.2 "智者圈"理论的背景与意义

###### 1.2.1 投资网络的概念与重要性

投资网络是指一组投资者之间通过共享信息、资源和知识而形成的网络。高质量的投资网络能够帮助投资者发现新的机会，降低风险，并提高整体投资回报。

###### 1.2.2 "智者圈"理论的提出与发展

芒格在《穷查理宝典》中首次系统性地提出了“智者圈”理论。该理论强调，投资者应该专注于自己的能力圈，并与具有互补性知识的人建立深度信任关系。

###### 1.2.3 理论在现代投资中的应用价值

在现代投资中，市场越来越复杂，单一的分析方法已经不足以应对各种风险和不确定性。“智者圈”理论为投资者提供了一种系统性的方法，通过构建高质量的知识网络来提高投资决策的质量。

##### 4.2 核心实现源代码

以下是系统的核心实现源代码：

```python
import networkx as nx

def build_investment_network(investors, knowledge_domains, trust_relationships):
    G = nx.Graph()
    G.add_nodes_from(investors)
    G.add_nodes_from(knowledge_domains)
    G.add_nodes_from(trust_relationships)
    G.add_edges_from([(investor, knowledge_domain) for investor in investors for knowledge_domain in knowledge_domains])
    G.add_edges_from(trust_relationships)
    return G

def calculate_network_stability(G):
    return nx.is_connected(G)

def main():
    investors = ['Investor1', 'Investor2', 'Investor3']
    knowledge_domains = ['Finance', 'Technology', 'Healthcare']
    trust_relationships = [('Investor1', 'Investor2'), ('Investor2', 'Investor3')]
    G = build_investment_network(investors, knowledge_domains, trust_relationships)
    print("Network stability:", calculate_network_stability(G))

if __name__ == "__main__":
    main()
```
