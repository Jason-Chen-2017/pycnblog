### 第1章: AI代理与宏观经济分析概述

  AI代理通过分析宏观经济指标，帮助投资者做出更精准的投资决策。

### 第3章: 宏观经济预测的算法原理

#### 3.1 时间序列预测模型
- **3.1.1 ARIMA模型原理**  
  ARIMA（自回归积分滑动平均）模型适用于线性时间序列数据的预测。
  - 自回归部分：$y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \epsilon_t$
  - 移动平均部分：$e_t = \theta_1 e_{t-1} + \epsilon_t$
- **3.1.2 LSTM模型的应用**  
  LSTM（长短期记忆网络）适合处理非线性时间序列数据。
  - LSTM单元结构：包括输入门、遗忘门和输出门。
  - 代码示例：
    ```python
    import tensorflow as tf
    from tensorflow.keras.layers import LSTM, Dense

    model = tf.keras.Sequential([
        LSTM(64, input_shape=(timesteps, features)),
        Dense(1)
    ])
    model.compile(optimizer='adam', loss='mse')
    ```
- **3.1.3 GARCH模型的优势**  
  GARCH模型用于预测金融时间序列的波动性，适合处理异方差性问题。
  - 模型公式：$a_t^2 = \alpha_0 + \alpha_1 a_{t-1}^2 + \beta_1 a_{t-1}^2$

#### 3.2 机器学习模型
- **3.2.1 线性回归模型**  
  简单线性回归模型用于预测连续型变量。
  - 回归方程：$y = \beta_0 + \beta_1 x + \epsilon$
- **3.2.2 支持向量回归(SVR)**  
  SVR适用于非线性数据的预测。
  - 核函数：常用的有线性核、多项式核、高斯核。
- **3.2.3 随机森林回归**  
  随机森林通过集成学习提高预测准确性。
  - 树的数量：通常选择100或更多。

#### 3.3 深度学习模型
- **3.3.1 卷积神经网络(CNN)**  
  CNN用于处理图像数据，但在时间序列预测中也有应用。
- **3.3.2 图神经网络(GNN)**  
  GNN适用于复杂网络结构的数据分析。
  - 图结构：节点和边表示经济主体和相互关系。
