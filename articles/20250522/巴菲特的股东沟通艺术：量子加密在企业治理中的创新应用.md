#### 2.1.1 量子加密的基本概念
量子加密是一种利用量子力学原理实现信息加密的技术。其核心在于利用量子态的不可克隆性和不可测量性，确保信息的安全传输。

#### 2.1.3 量子加密的核心原理
量子加密的核心原理基于量子力学中的测不准原理和不可克隆原理。通过量子态的传输和测量，通信双方可以检测到任何未经授权的窃听行为，并确保密钥的安全交换。

```python
def generate_quantum_key():

def encrypt_message(message, key):
    from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
    from cryptography.hazmat.backends import default_backend
    backend = default_backend()
    cipher = Cipher(algorithms.AES(128), modes.CFB, backend=backend)
    encryptor = cipher.encryptor()
    encrypted_data = encryptor.update(message.encode()) + encryptor.finalize()
    return encrypted_data

def decrypt_message(encrypted_data, key):
    from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
    from cryptography.hazmat.backends import default_backend
    backend = default_backend()
    cipher = Cipher(algorithms.AES(128), modes.CFB, backend=backend)
    decryptor = cipher.decryptor()
    decrypted_data = decryptor.update(encrypted_data) + decryptor.finalize()
    return decrypted_data.decode()
```
