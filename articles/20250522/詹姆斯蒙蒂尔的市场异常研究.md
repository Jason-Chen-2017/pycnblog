## 第1章：市场异常研究的背景与意义

### 1.1 什么是市场异常
- **定义**：市场异常是指价格波动、交易量变化等偏离正常模式的现象。
- **类型**：
  - **短期波动**：如闪崩、跳水。
  - **长期偏离**：如长期横盘或趋势反转。
- **研究价值**：帮助交易者识别潜在机会或风险。

### 1.2 蒙蒂尔研究的意义
- **技术分析**：利用价格和成交量数据预测未来走势。
- **量化投资**：通过算法捕捉市场异常信号，优化投资决策。

## 第3章：算法原理与实现

### 3.1 常用算法
- **MACD**：计算差值和信号线，用于识别趋势强度。
- **RSI**：计算相对强弱，判断超买超卖状态。

### 3.2 算法实现与优化
- **Python代码**：
  ```python
  import pandas as pd
  import numpy as np

  def calculate_rsi(df, period=14):
      # 计算相对强弱指数
      df['RSI'] = (100 * (df['收盘价'] - df['收盘价'].rolling(period).mean()) / 
                   df['收盘价'].rolling(period).std())
      return df

  def calculate_macd(df):
      # 计算MACD指标
      df['EMA26'] = df['收盘价'].ewm(span=26).mean()
      df['EMA12'] = df['收盘价'].ewm(span=12).mean()
      df['MACD'] = df['EMA12'] - df['EMA26']
      df['MACD信号线'] = df['MACD'].ewm(span=9).mean()
      return df
  ```

- **公式解释**：
  - RSI公式：$RSI = 100 \times \frac{(收盘价 - 收盘价的移动平均)}{收盘价的移动平均标准差}$
  - MACD公式：$MACD = EMA12 - EMA26$，$信号线 = EMA(MACD, 9)$

  ```python
  def generate_rsi_signal(df, period=14, threshold=70):
      df = calculate_rsi(df, period)
      df['RSI信号'] = 0
      df.loc[df['RSI'] > threshold, 'RSI信号'] = 1
      df.loc[df['RSI'] < (100 - threshold), 'RSI信号'] = -1
      return df
  ```
