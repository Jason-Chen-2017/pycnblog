# 第一部分: 成长股识别的核心模型

## 第1章: CAN SLIM模型的原理与应用

### 1.1 CAN SLIM模型的概述

CAN SLIM是威廉·欧奈尔提出的一种成长股筛选方法，其名称由8个字母组成，分别代表8个关键因素：

- **C** - Company（公司管理）：公司管理层是否优秀，是否具有扩张和创新能力。
- **A** - Annual Earnings（年收益）：公司每年的收益是否持续增长。
- **N** - New High（新高）：股价是否创出历史新高。
- **S** - Supply and Demand（供需关系）：市场上供需是否平衡，供不应求的股票更容易上涨。
- **L** - Leader（行业领头羊）：公司是否是行业中的领导者。
- **I** - Institutional Ownership（机构持股）：机构投资者是否大量持有该股票。
- **M** - Market Momentum（市场动量）：市场整体走势是否强劲。

### 1.2 CAN SLIM模型的核心要素

在CAN SLIM模型中，以下几个因素尤为重要：

1. **相对强度（Relative Strength）**：股价相对于市场指数的表现，是成长股筛选的关键指标。
2. **年收益增长率**：公司每年的收益是否持续增长，且增速是否快于行业平均水平。
3. **机构持股比例**：机构投资者的持股比例越高，股票的稳定性越强。

## 第2章: 数学模型与算法

### 2.1 相对强度指数（RSI）的计算公式

相对强度指数（RSI）是衡量股票强弱的重要指标，其计算公式如下：

$$
RSI = \frac{100 - \frac{S}{A + S} \times 100
$$

其中：
- $S$ 表示一定时期内的平均涨幅。
- $A$ 表示一定时期内的平均跌幅。

## 第4章: 项目实战

### 4.1 环境配置

- **编程语言**：Python
- **库**：pandas、numpy、matplotlib

### 4.2 核心代码实现

```python
import pandas as pd
import numpy as np

# 示例数据
data = {
    '股价': [100, 105, 110, 115, 120],
    '收益': [10, 20, 30, 40, 50],
    '机构持股比例': [20, 30, 40, 50, 60]
}

df = pd.DataFrame(data)

# 计算相对强度指数
df['相对强度'] = df['股价'].pct_change().cumsum()

# 筛选满足CAN SLIM条件的股票
筛选条件：
1. 收益年增长率 > 20%
2. 相对强度 > 0.1
3. 机构持股比例 > 40%

符合条件的股票 = df[(df['收益'] > 20) & (df['相对强度'] > 0.1) & (df['机构持股比例'] > 40)]
```
