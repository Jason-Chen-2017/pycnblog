### 3.4 决策一致性评分模型的数学模型
$$
\text{一致性指数} = \frac{\sum_{i=1}^{n} w_i \cdot s_i}{\sum_{i=1}^{n} w_i}
$$
其中，$w_i$ 是第 $i$ 个指标的权重，$s_i$ 是第 $i$ 个指标的评分。

### 3.5 算法实现的Python代码
```python
def calculate_consistency_index(scores, weights):
    weighted_sum = sum(scores[i] * weights[i] for i in range(len(scores)))
    weight_sum = sum(weights)
    return weighted_sum / weight_sum

scores = [0.8, 0.7, 0.9]
weights = [0.3, 0.4, 0.3]
consistency_index = calculate_consistency_index(scores, weights)
print(f"一致性指数: {consistency_index}")

### 4.1 决策一致性指数的计算
$$
C = \frac{\sum_{i=1}^{n} (s_i - \mu)^2}{N-1}
$$
其中，$s_i$ 是第 $i$ 个决策评分，$\mu$ 是平均评分，$N$ 是评分数量。

### 4.2 决策一致性评分的权重分配
$$
w_i = \frac{1}{1 + e^{-k_i}}
$$
其中，$k_i$ 是第 $i$ 个指标的标准化评分。

### 4.3 决策一致性模型的优化
$$
\text{优化目标} = \min \sum_{i=1}^{n} (w_i - \text{target}_i)^2
$$
其中，$w_i$ 是权重，$\text{target}_i$ 是目标权重。

import pandas as pd
from sklearn.metrics import mean_squared_error

def calculate_score(data):
    # 数据预处理
    data = data.dropna()
    # 计算一致性指数
    mean = data.mean()
    mse = mean_squared_error(data, [mean] * len(data))
    return 1 - mse / data.var()
```
