### 示例代码（DCF模型实现）

```python
import pandas as pd
import numpy as np

# 示例数据：企业自由现金流
cash_flows = [100, 150, 200, 250]
discount_rate = 0.08

# 计算净现值
npv = 0
for year, cash_flow in enumerate(cash_flows, 1):
    npv += cash_flow / (1 + discount_rate) ** year

print(f"净现值（NPV）为：{npv}")
```
