# 第1章: 全球股市估值的基本概念

## 1.1 股市估值的定义与重要性  
### 1.1.1 股市估值的基本定义  
股市估值是指通过对公司财务数据、市场环境和行业趋势的分析，估算公司股票的内在价值或市场价格的过程。它是投资者做出投资决策的重要依据。  

### 1.1.2 股市估值的重要性  
股市估值帮助投资者识别被低估或高估的股票，从而做出合理的投资决策。此外，股市估值还能反映宏观经济状况和行业发展趋势。  

### 1.1.3 股市估值的核心要素  
- **市盈率（P/E）**：股票价格与每股收益的比率。  
- **市净率（P/B）**：股票价格与每股净资产的比率。  
- **股息率**：股息与股票价格的比率。

## 1.2 可持续建筑智能材料的发展现状  
### 1.2.1 可持续建筑的概念  
可持续建筑是指在全生命周期内，最大限度地减少资源消耗和环境影响，同时提高建筑性能和舒适性的建筑方式。  

### 1.2.2 智能材料在建筑中的应用  
智能材料能够感知环境变化并做出响应，例如：  
- **智能窗户**：根据光照和温度调节透光率。  
- **智能墙体**：能够调节室内温湿度。  
- **智能地板**：能够储存和释放热量。  

### 1.2.3 可持续建筑智能材料的技术特点  
- **环保性**：材料生产过程低能耗、低污染。  
- **可循环性**：材料可以回收再利用。  
- **智能性**：材料具有感知和响应环境变化的能力。
