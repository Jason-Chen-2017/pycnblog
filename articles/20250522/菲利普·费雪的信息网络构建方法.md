$$ w_{ij} = \frac{count_{ij}}{\sum_{i} count_{ij}} $$

#### 11.1 信息网络构建的Python代码实现

```python
import networkx as nx
import pandas as pd

# 数据预处理
data = pd.read_csv('data.csv')
nodes = data['node'].unique()
edges = data[['from', 'to']]

# 构建网络
G = nx.Graph()
G.add_nodes_from(nodes)
G.add_edges_from(edges)

# 可视化
nx.draw(G, with_labels=True)
```

```python
    weights = {}
    for edge in G.edges():
```
