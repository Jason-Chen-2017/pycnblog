# 第一部分: 魔术公式的背景与核心概念

## 第1章: 魔术公式的起源与背景

### 1.1 乔尔·格林布拉特及其投资理念

#### 1.1.1 乔尔·格林布拉特的生平简介
乔尔·格林布拉特是一位著名的投资专家，以其创新的投资策略闻名。他提出的魔术公式是一种简单而有效的投资方法，帮助投资者识别被低估的优质企业。

#### 1.1.2 格林布拉特的投资哲学与理念
格林布拉特强调基本面分析和长期投资。他认为，企业的价值在于其盈利能力，而不仅仅是市场波动。

#### 1.1.3 魔术公式的提出背景与意义
魔术公式在20世纪90年代提出，旨在解决传统价值投资方法的局限性，提供一种更科学的投资评估工具。

### 1.2 魔术公式的定义与核心要素

#### 1.2.1 魔术公式的定义
魔术公式通过ROE和ROIC两个指标，评估企业的盈利能力，进而判断其投资价值。

#### 1.2.2 核心要素：ROE与ROIC的计算
- **ROE（净资产收益率）**：净利润/平均净资产
- **ROIC（投入资本回报率）**：净利润/平均投入资本

#### 1.2.3 魔术公式的应用场景与边界
适用于评估制造业、零售业等传统行业的企业价值，不适用于高增长科技企业。

### 1.3 魔术公式与传统投资方法的对比

#### 1.3.1 传统价值投资方法的局限性
传统方法过于依赖市盈率和市净率，忽视了企业的盈利能力。

#### 1.3.2 魔术公式的创新与优势
- 综合考虑盈利能力
- 简单易懂，易于应用

#### 1.3.3 魔术公式与其它投资模型的对比分析
与PEG模型相比，魔术公式更注重企业的盈利能力，而非市盈率。

## 第2章: 魔术公式的数学模型与公式推导

### 2.1 魔术公式的数学模型

#### 2.1.1 ROE（净资产收益率）的计算公式
$$ROE = \frac{净利润}{平均净资产}$$

#### 2.1.2 ROIC（投入资本回报率）的计算公式
$$ROIC = \frac{净利润}{平均投入资本}$$

#### 2.1.3 企业价值的计算公式
$$企业价值 = \frac{ROIC \times WACC^{-1}}{1 - \frac{1}{(1 + g)^n}}$$

### 2.2 魔术公式的公式推导与验证

#### 2.2.1 公式推导过程
- 确定ROE和ROIC的计算方法
- 结合企业价值公式，推导出最终的企业价值评估模型

#### 2.2.2 公式的数学验证与实证分析
通过历史数据验证魔术公式的准确性，分析其在不同市场环境下的表现。

### 4.2 核心实现代码

```python
def calculate_roe(net_profit, avg_equity):
    return net_profit / avg_equity

def calculate_roic(net_profit, avg_capital):
    return net_profit / avg_capital

# 示例数据
net_profit = 100
avg_equity = 500
avg_capital = 400

roe = calculate_roe(net_profit, avg_equity)
roic = calculate_roic(net_profit, avg_capital)
print(f"ROE: {roe:.2f}%")
print(f"ROIC: {roic:.2f}%")
```
