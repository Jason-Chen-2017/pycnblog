# 第一部分：低市净率投资的背景与核心概念

## 第1章：低市净率投资的背景与基本概念

### 1.1 低市净率投资的定义与特点  
低市净率投资是一种基于股票市净率（P/B）进行投资的策略，旨在寻找被市场低估的股票。其核心在于通过比较股票的市场价格与每股净资产，找到价格低于其内在价值的股票。  

#### 1.1.1 市净率的定义与计算公式  
市净率（P/B）的计算公式为：$$P/B = \frac{P}{B}$$，其中：
- $P$ 是股票的市场价格。
- $B$ 是每股净资产（即每股账面价值）。  

市净率反映了市场对股票价值的评估，通常认为市净率低于1的股票具有较高的投资价值。  

#### 1.1.2 低市净率投资的核心特点  
- **低估值**：市净率低于行业平均水平，意味着股票价格被低估。  
- **高稳定性**：低市净率股票通常来自成熟行业，具有较高的盈利能力和稳定的现金流。  
- **低风险**：相比于高市净率股票，低市净率股票的风险较低，适合保守型投资者。  

#### 1.1.3 低市净率投资的适用场景与边界  
低市净率投资适用于成熟行业的股票筛选，尤其在经济下行周期中表现更为稳定。其边界包括避免高负债企业、避免亏损企业以及避免周期性过强的行业。

### 1.2 约翰·聂夫与低市净率投资  
约翰·聂夫是低市净率投资的代表人物，他的投资理念强调长期持有和价值挖掘。  

#### 1.2.1 约翰·聂夫的生平简介  
约翰·聂夫是富达投资集团的资深基金经理，以其长期优异的投资业绩闻名。他的投资策略以低市净率为核心，强调安全边际和长期价值。  

#### 1.2.2 聂夫的投资理念与方法  
- **价值投资**：聂夫认为市场先生往往过于情绪化，投资者应关注企业的内在价值。  
- **安全边际**：通过低市净率筛选，确保买入价格低于企业的真实价值。  
- **长期持有**：聂夫的投资策略注重长期持有，避免频繁交易。  

#### 1.2.3 聂夫投资策略的演变与影响  
聂夫的投资策略对全球价值投资产生了深远影响，尤其是在企业估值和风险管理方面。

## 第2章：低市净率投资的核心概念与原理  

### 2.1 市净率与市盈率的对比分析  
市净率和市盈率是两种常用的估值指标，各有优缺点。  

#### 2.1.1 市净率的优缺点  
- **优点**：  
  - 适用于多种行业，尤其是金融、制造等行业。  
  - 更容易识别低估股票。  
- **缺点**：  
  - 对于亏损企业，市净率可能无效。  

#### 2.1.2 市盈率的优缺点  
- **优点**：  
  - 更直观地反映企业盈利能力。  
- **缺点**：  
  - 对于亏损企业，市盈率无意义。  

#### 2.1.3 两种估值指标的适用场景对比  
- 市净率适用于评估净资产较高的企业，市盈率适用于评估盈利能力强的企业。  

---

### 2.2 低市净率投资的筛选标准  

#### 2.2.1 市净率低于行业平均值的筛选标准  
通过比较目标企业的市净率与行业平均值，选择市净率低于行业平均的股票。  

#### 2.2.2 盈利能力与财务健康度的评估  
- 盈利能力：关注净利润率、ROE等指标。  
- 财务健康度：关注资产负债率、现金流等指标。  

#### 2.2.3 行业选择与风险控制  
选择低市净率股票时，应优先考虑成熟行业，避免高负债和周期性过强的行业。

## 第3章：低市净率投资的核心算法与数学模型  

### 3.1 市净率计算的数学公式  

#### 3.1.1 市净率公式  
$$P/B = \frac{P}{B}$$  

#### 3.1.2 每股净资产的计算公式  
$$BPS = \frac{净资产}{总股本}$$  

### 3.2 低市净率筛选算法  

#### 3.2.1 算法流程图（mermaid）  
```mermaid
graph TD
    A[开始] --> B[计算市净率]
    B --> C[判断市净率是否低于行业平均值]
    C --> D[符合条件：纳入投资池]
    D --> E[不符合条件：排除]
    E --> F[结束]
```

#### 3.2.2 算法实现与代码示例  
```python
import pandas as pd

# 示例数据：假设有一个包含股票信息的DataFrame df，包含'收盘价'和'每股净资产'两列
df['市净率'] = df['收盘价'] / df['每股净资产']

# 筛选市净率低于行业平均值的股票
行业平均市净率 = df['市净率'].mean()
低市净率股票 = df[df['市净率'] < 行业平均市净率]
```
