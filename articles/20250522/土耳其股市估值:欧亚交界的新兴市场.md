## 第二部分：核心概念与估值方法

### 第2章：股市估值的基本原理

#### 2.1 估值的基本概念
- **2.1.1 估值的定义与作用**
  - 估值是确定资产价值的过程，帮助投资者做出决策。
- **2.1.2 估值的核心要素**
  - 收益、现金流、资产、行业地位等。
- **2.1.3 估值与市场波动的关系**
  - 市场波动影响估值，但估值是内在价值的反映。

#### 2.2 土耳其股市的特殊性
- **2.2.1 地缘政治对估值的影响**
  - 地缘政治事件导致市场波动。
- **2.2.2 经济结构与市场特点**
  - 多样化的经济结构，影响不同行业估值。
- **2.2.3 货币与汇率的双重影响**
  - 里拉波动影响股市估值。

#### 2.3 估值方法的分类
- **2.3.1 市盈率（PE）法**
  - PE = 市价 / 每股收益。
- **2.3.2 市净率（PB）法**
  - PB = 市价 / 每股净资产。
- **2.3.3 现金流折现法（DCF）**
  - 通过预测现金流折现计算企业价值。

## 第三部分：估值方法的详细讲解

### 第3章：市盈率与市净率的分析

#### 3.1 市盈率（PE）的计算与应用
- **3.1.1 PE的定义与计算公式**
  - PE = 市价 / 每股收益。
- **3.1.2 PE在土耳其股市的应用**
  - 比较行业平均PE，判断股票估值。
- **3.1.3 PE的局限性与改进方法**
  - 忽略了资产价值，需结合PB分析。

#### 3.2 市净率（PB）的计算与应用
- **3.2.1 PB的定义与计算公式**
  - PB = 市价 / 每股净资产。
- **3.2.2 PB在土耳其股市的应用**
  - 适用于银行和房地产等行业。
- **3.2.3 PB的局限性与改进方法**
  - 未考虑盈利能力，需结合ROE分析。

#### 3.3 现金流折现法（DCF）的详细讲解
- **3.3.1 DCF的定义与计算步骤**
  - 现金流折现模型，计算企业未来现金流的现值。
- **3.3.2 DCF在土耳其股市的应用**
  - 适用于成长型企业，如科技和新兴行业。
- **3.3.3 DCF的数学模型与公式**
  - 企业价值 = Σ(FCFt / (1 + r)^t) + 终值。

import pandas as pd
import requests

def get_data(symbol):
    url = f"https://query1.finance.yahoo.com/ws/v1/finance/quote/{symbol}"
    response = requests.get(url)
    data = response.json()
    return data['quoteResponse']['result'][0]

def calculate_pe(ticker):
    data = get_data(ticker)
    pe = data['regularMarketPrice'] / data['.trailingPE']
    return pe

print(calculate_pe("TRGL.NS"))  # 示例：土耳其中东技术公司
