# 第1章: 巴菲特-芒格商业模式概述

## 1.1 巴菲特与芒格的投资理念

### 1.1.1 巴菲特的价值投资理论
巴菲特的价值投资理论强调以合理的价格投资于具有持续竞争优势的企业。他认为，市场的短期波动不可预测，但长期来看，股票的价格最终会反映其内在价值。他的投资策略包括：
- **长期投资**：避免频繁交易，专注于长期价值。
- **安全边际**：买入价格低于内在价值，以确保安全边际。
- **优质企业**：投资于具有强大竞争优势、稳定的管理层和良好财务状况的企业。

### 1.1.2 芒格的多元思维模型
芒格提倡多元思维模型，认为投资者需要从多个角度（如心理学、经济学、数学等）分析问题。他强调：
- **跨学科思维**：通过多学科的交叉应用，避免单一视角的局限性。
- **逆向思维**：从反方向思考问题，找到市场忽视的机会。
- **复利效应**：长期投资的复利效应能够带来巨大的财富增长。

### 1.1.3 两人合作的投资哲学
巴菲特和芒格的合作基于互补性：巴菲特擅长企业分析和估值，芒格擅长心理分析和风险控制。他们的合作模式为：
- **长期合作**：两人共同决策，避免短期波动。
- **价值导向**：始终坚持投资于具有内在价值的企业。
- **风险管理**：通过分散投资和安全边际控制风险。

3. **计算安全边际**：安全边际 = 内在价值 - 买入价格。
