### 1.2 “地图思维”的定义与特点

“地图思维”是一种以系统性分析为核心的投资方法。它通过构建多维度的分析框架，帮助投资者全面理解市场的复杂性。地图思维的核心特点包括：

- **系统性**：强调对市场、行业和企业的整体理解。
- **多学科**：结合经济学、心理学、统计学等多个学科的理论。
- **可扩展性**：适用于不同规模和类型的投资分析。

### 1.3 地图思维的背景与意义

在当前复杂的投资环境中，传统的单一维度分析方法已经难以应对市场的不确定性。地图思维通过多维度的分析，帮助投资者在复杂环境中做出更明智的决策。其意义在于：

- 增强对市场的适应能力。
- 降低投资风险。

# 投资组合优化
def portfolio_optimization(returns):
    n = returns.shape[1]
    returns_cov = returns.cov()
    w = np.random.random(n)
    w = w / np.sum(w)
    return w, np.dot(w, returns.mean())

weights, expected_return = portfolio_optimization(returns)
print(weights)
print(expected_return)
