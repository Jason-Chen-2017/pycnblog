## 第一部分：系统性风险与图神经网络背景

### 第1章：系统性风险的定义与特征

#### 1.1 系统性风险的定义
系统性风险是指由于金融体系中某些关键因素的影响，导致整个金融系统发生系统性危机的风险。这种风险通常由金融机构之间的相互关联引发，具有传染性和叠加性。

#### 1.2 系统性风险的核心特征
- **传染性**：风险从一个金融机构向另一个金融机构扩散。
- **叠加性**：多个风险因素共同作用，导致系统性危机。
- **扩散性**：风险可能从金融系统扩展到实体经济。

#### 1.3 图神经网络的基本概念
图神经网络（Graph Neural Network，GNN）是一种专门处理图结构数据的深度学习模型。它通过节点之间的关系进行信息传播，能够捕捉到数据中的复杂关联关系。

### 第2章：图神经网络在系统性风险中的应用

#### 2.1 系统性风险的传播机制
系统性风险的传播机制可以通过金融网络的结构来建模。金融机构之间的关联性是风险传播的关键因素。

#### 2.2 图神经网络的优势
- **捕捉复杂关系**：图神经网络能够有效捕捉金融机构之间的复杂关系，帮助识别系统性风险的潜在传播路径。
- **非线性建模能力**：深度学习模型能够处理复杂的非线性关系，适合金融风险的预测。

## 第二部分：图神经网络的理论基础

### 第3章：图论基础

#### 3.1 图的基本概念
- **节点（Nodes）**：代表金融机构。
- **边（Edges）**：代表金融机构之间的关联关系，如资金流动或业务往来。
- **权重（Weights）**：表示边的重要程度，如资金流动的规模。

#### 3.2 常见的图类型
- **无向图**：边没有方向，表示双向关联。
- **有向图**：边有方向，表示单向关联。
- **加权图**：边具有权重，表示关联强度。

### 第4章：概率论与神经网络基础

#### 4.1 概率论基础
- **概率分布**：描述随机变量可能取值及其概率。
- **贝叶斯定理**：用于条件概率的计算，常用于风险评估中的概率更新。

#### 4.2 神经网络基础
- **感知机**：单层神经网络，用于线性分类。
- **深度神经网络（DNN）**：多层结构，能够处理复杂的非线性关系。

## 第三部分：系统性风险传导的图神经网络建模

### 第5章：金融网络的构建

#### 5.1 数据采集与处理
- **数据来源**：金融机构的资产负债表、交易数据、信用评级等。
- **数据预处理**：清洗、归一化和特征提取。

#### 5.2 图结构的构建
- **邻接矩阵**：表示金融机构之间的关联关系。
- **节点特征**：金融机构的财务指标、信用评分等。

### 第6章：图神经网络模型的设计

#### 6.1 图卷积网络（GCN）
- **GCN的基本原理**：通过聚合邻居节点的信息进行特征更新。
- **GCN的数学模型**：
  $$ H^{(l+1)} = \text{ReLU}(A H^{(l)} W^{(l)}) $$
  其中，$A$ 是邻接矩阵，$H^{(l)}$ 是第$l$层的节点表示，$W^{(l)}$ 是权重矩阵。

#### 6.2 图注意力网络（GAT）
- **注意力机制**：动态调整节点之间的权重。
- **GAT的数学模型**：
  $$ \alpha_{i,j} = \text{softmax}(\frac{W_{i}^T h_j + b_i}{\|W_{i}\|}) $$
  其中，$\alpha_{i,j}$ 是注意力权重，$h_j$ 是节点$j$的特征向量。

#### 7.2 核心代码实现
```python
import tensorflow as tf
from tensorflow.keras import layers

class GraphConvolution(layers.Layer):
    def __init__(self, input_dim, output_dim, **kwargs):
        super(GraphConvolution, self).__init__(**kwargs)
        self.input_dim = input_dim
        self.output_dim = output_dim
        self.W = self.add_weight(shape=(input_dim, output_dim), 
                                  initializer='glorot_uniform')
    
    def call(self, inputs, adj):
        support = tf.matmul(inputs, self.W)
        output = tf.matmul(adj, support)
        return output
```

#### 7.3 模型训练
- **输入数据**：邻接矩阵和节点特征矩阵。

### 第8章：GAT的实现

#### 8.1 注意力机制实现

```python
def attention(inputs, adj):
    keys = tf.matmul(inputs, tf.constant([[1.0]]))  # 假设输入为节点特征向量
    queries = tf.matmul(inputs, tf.constant([[1.0]]))
    values = tf.matmul(inputs, tf.constant([[1.0]]))
    # 计算注意力权重
    attention_weights = tf.nn.softmax(tf.matmul(keys, queries, transpose_b=True))
    output = tf.matmul(attention_weights, values)
    return output
```
