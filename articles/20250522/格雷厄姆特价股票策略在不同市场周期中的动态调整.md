## 第一部分: 价值投资与格雷厄姆策略基础

### 第1章: 价值投资概述

#### 1.1 价值投资的基本概念

- **1.1.1 价值投资的定义**
  价值投资是一种以公司的基本面分析为基础，寻找市场价格低于其内在价值的股票的投资策略。它强调长期投资和安全边际，避免过度依赖市场情绪。

- **1.1.2 价值投资的核心理念**
  - **内在价值**：股票的真正价值是其未来现金流的现值。
  - **安全边际**：买入价格低于内在价值，以降低风险并确保收益。

- **1.1.3 价值投资与投机的区别**
  - 投资：基于基本面分析，追求长期稳定收益。
  - 投机：基于市场情绪，追求短期价格波动。

#### 1.2 格雷厄姆投资理论简介

- **1.2.1 格雷厄姆的生平与贡献**
  本杰明·格雷厄姆是价值投资之父，他的理论影响了沃伦·巴菲特等投资者。

- **1.2.2 格雷厄姆投资策略的核心思想**
  - **低市盈率（P/E）**：选择市盈率低于市场平均水平的股票。
  - **低市净率（P/B）**：选择市净率低于行业平均水平的股票。
  - **高股息率**：选择股息率高且稳定的公司。

- **1.2.3 格雷厄姆的"安全边际"概念**
  安全边际=内在价值 - 买入价格，确保即使价格波动，也能保证收益。

### 第2章: 特价股票的定义与特点

#### 2.1 特价股票的定义

- **2.1.1 什么是特价股票**
  特价股票是指市场价格低于其内在价值的股票，通常具有较高的安全边际。

- **2.1.2 特价股票的特征**
  - 低市盈率（P/E）：股价相对未来盈利的比率低。
  - 低市净率（P/B）：股价相对资产净值的比率低。
  - 高股息率：股息支付率高，且股息稳定。

- **2.1.3 特价股票与普通股票的区别**
  | 特性 | 特价股票 | 普通股票 |
  |------|----------|----------|
  | 市盈率 | 低于行业平均 | 无特定要求 |
  | 市净率 | 低于行业平均 | 无特定要求 |
  | 股息率 | 高且稳定 | 无特定要求 |

### 第3章: 不同市场周期中的投资策略

#### 3.1 市场周期的基本类型

- **3.1.1 牛市周期**
  市场情绪乐观，股价普遍上涨，可能出现高估。

- **3.1.2 熊市周期**
  市场情绪恐慌，股价普遍下跌，可能出现低估。

- **3.1.3 纾解周期**
  市场从熊市恢复，逐步上涨，投资者信心恢复。

- **3.1.4 增长周期**
  经济快速增长，企业盈利上升，股价稳步上涨。

#### 3.2 不同市场周期中的策略调整

- **3.2.1 牛市中的策略调整**
  - 降低投资组合的风险，减少高价股票的持有。
  - 选择具有防御性的股票，如公用事业和消费品行业。

- **3.2.2 熊市中的策略调整**
  - 增加对特价股票的投资，利用市场恐慌寻找低估机会。
  - 保持较高的现金储备，等待更好的投资机会。

- **3.2.3 纾解周期中的策略优化**
  - 逐步增加对股票的投资，分批买入。
  - 重点关注那些在熊市中表现相对稳定的股票。

- **3.2.4 增长周期中的策略应用**
  - 选择那些能够持续增长的企业，如科技和新兴产业。
  - 保持适度的市场参与度，避免过度乐观。

### 第4章: 格雷厄姆策略的核心算法

#### 4.1 格雷厄姆筛选算法

- **4.1.1 筛选条件的数学模型**
  $$ \text{安全边际} = \text{内在价值} - \text{买入价格} $$

- **4.1.2 市盈率（P/E）计算公式**
  $$ \text{P/E} = \frac{\text{股价}}{\text{每股盈利}} $$

- **4.1.3 市净率（P/B）计算公式**
  $$ \text{P/B} = \frac{\text{股价}}{\text{每股净资产}} $$

- **4.1.4 股息率计算公式**
  $$ \text{股息率} = \frac{\text{每股股息}}{\text{股价}} $$

### 第5章: 数学模型与算法实现

#### 5.1 格雷厄姆策略的数学模型

- **内在价值计算**
  $$ \text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1+r)^t} $$
  其中，r为折现率，现金流为未来现金流预测。

- **安全边际计算**
  $$ \text{安全边际} = \text{内在价值} - \text{买入价格} $$

#### 5.2 算法实现

```python
def calculate_intrinsic_value(cash_flows, discount_rate):
    return sum(cash_flows[i]/(1+discount_rate)**i for i in range(len(cash_flows)))

def calculate_margin_of_safety(intrinsic_value, price):
    return intrinsic_value - price
```

#### 5.3 实际案例分析

- 假设某公司未来三年现金流分别为100、120、150，折现率为10%。
  - 内在价值= 100/(1.1) + 120/(1.1)^2 + 150/(1.1)^3 ≈ 100/1.1 + 120/1.21 + 150/1.331 ≈ 90.91 + 99.17 + 112.72 ≈ 302.80
  - 如果股价为250，安全边际=302.80-250=52.80，买入。

import pandas as pd
import numpy as np

def filter_cheap_stocks(df, pe_threshold=15, pb_threshold=2, dividend_yield_threshold=2):
    filtered = df[df['PE'] < pe_threshold]
    filtered = filtered[filtered['PB'] < pb_threshold]
    filtered = filtered[filtered['Dividend Yield'] > dividend_yield_threshold]
    return filtered

# 示例数据
