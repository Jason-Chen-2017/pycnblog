### 第1章: 信息不对称的核心概念与问题背景

#### 1.1 信息不对称的定义与类型
- **信息不对称的定义**: 信息不对称是指市场参与者之间由于掌握的信息量或信息质量的差异，导致在交易中处于不平等地位的现象。
- **信息不对称的类型**:
  - **横向信息不对称**: 不同市场参与者之间信息掌握程度的差异。
  - **纵向信息不对称**: 同一市场参与者在不同时间点上信息掌握程度的差异。

#### 1.2 信息不对称在股票市场中的表现
- **公司内部信息优势**: 公司高管、大股东等掌握未公开的内部信息。
- **市场信息传播延迟**: 信息在市场中的传播速度不一致，导致部分投资者先知先觉。
- **投资者认知差异**: 不同投资者对同一信息的理解和反应存在差异。

#### 1.3 特价股票投资的定义与目标
- **特价股票的定义**: 特价股票是指市场价格显著低于其内在价值的股票，通常是由于市场信息不对称、市场情绪波动或其他外部因素导致的暂时性价格偏差。
- **特价股票投资的目标**: 利用信息不对称优势，发现被市场低估的股票，实现超额收益。

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 数据采集
def get_stock_data(ticker):
    data = pd.DataFrame()
    # 获取历史价格数据
    data['price'] = pd.get_data_yahoo(ticker, start='2020-01-01', end='2023-12-31')['Adj Close']
    return data

# 信息不对称检测
def detect_asymmetry(data):
    model = LinearRegression()
    X = data.index.astype(int)
    y = data['price']
    model.fit(X.reshape(-1, 1), y)
    predicted = model.predict(X.reshape(-1, 1))
    mse = mean_squared_error(y, predicted)
    return mse

# 交易策略实现
def trading_strategy(data, threshold=0.05):
    positions = []
    for i in range(1, len(data)):
        current_price = data.iloc[i]['price']
        prev_price = data.iloc[i-1]['price']
        if (current_price - prev_price) / prev_price < -threshold:
            positions.append('buy')
        elif (current_price - prev_price) / prev_price > threshold:
            positions.append('sell')
        else:
            positions.append('hold')
    return positions
```
