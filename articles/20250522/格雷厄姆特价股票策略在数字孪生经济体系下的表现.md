# 第2章: 格雷厄姆特价股票策略的核心原理

## 2.1 格雷厄姆投资理论的概述

### 2.1.1 格雷厄姆投资理论的起源

格雷厄姆投资理论由 Benjamin Graham 提出，是价值投资的鼻祖。该理论强调以低于内在价值的价格购买股票，通过长期持有实现投资收益。

### 2.1.2 格雷厄姆投资理论的核心思想

格雷厄姆投资理论的核心思想是“安全边际”，即以低于内在价值的价格购买股票，确保投资的安全性和收益性。

### 2.1.3 格雷厄姆投资理论的现代发展

随着市场环境的变化，格雷厄姆投资理论也在不断发展，逐渐融入了更多的现代投资理念和技术手段。

## 2.2 格雷厄姆特价股票策略的关键指标

### 2.2.1 市盈率（P/E）的计算与应用

市盈率（P/E）= 股价 / 每股净利润。市盈率低的股票通常被认为是被低估的股票。

### 2.2.2 市净率（P/B）的计算与应用

市净率（P/B）= 股价 / 每股净资产。市净率低的股票通常被认为是被低估的股票。

### 2.2.3 股息率（Dividend Yield）的计算与应用

股息率（Dividend Yield）= 每股股息 / 股价。高股息率的股票通常被认为是稳定的投资选择。

## 2.3 格雷厄姆特价股票策略的实施步骤

### 2.3.1 确定投资目标与策略

投资者需要明确自己的投资目标和风险承受能力，选择适合自己的投资策略。

### 2.3.2 数据收集与初步筛选

通过收集市场数据，筛选出市盈率、市净率等指标低于行业平均水平的股票。

### 2.3.3 深入分析与投资决策

对筛选出的股票进行深入分析，评估其内在价值和市场前景，做出最终的投资决策。

```python
import pandas as pd
import numpy as np

# 数据读取
data = pd.read_csv('stock_data.csv')

# 数据清洗
data = data.dropna()

# 计算市盈率、市净率和股息率
data['P/E'] = data['股价'] / data['每股净利润']
data['P/B'] = data['股价'] / data['每股净资产']
data['股息率'] = data['每股股息'] / data['股价']

# 数据保存
data.to_csv('processed_data.csv', index=False)
```

### 5.2.2 模型训练代码

```python
from sklearn.neural_network import MLPRegressor

# 数据加载
data = pd.read_csv('processed_data.csv')

# 特征选择
features = ['P/E', 'P/B', '股息率']
target = '股价'

# 数据分割
X = data[features]
y = data[target]

# 模型训练
model = MLPRegressor(hidden_layer_sizes=(10, 5))
model.fit(X, y)

# 模型预测
predictions = model.predict(X)
```
