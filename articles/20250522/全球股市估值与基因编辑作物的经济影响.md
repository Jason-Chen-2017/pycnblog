# 第一部分: 全球股市估值的基础概念

## 第1章: 全球股市估值的基础概念

### 1.1 股市估值的基本概念

#### 1.1.1 股市估值的定义与作用
股市估值是通过对公司财务数据和市场因素的分析，估算公司股票的内在价值。其作用在于帮助投资者做出理性决策，避免因市场波动盲目投资。

#### 1.1.2 股市估值的核心指标
- **市盈率（P/E）**：股价与每股收益的比率，反映市场对公司的估值。
- **市净率（P/B）**：股价与每股净资产的比率，适用于评估资产密集型行业。
- **股息率**：股息与股价的比率，反映投资回报潜力。

#### 1.1.3 股市估值与经济周期的关系
股市估值受经济周期影响显著。在经济繁荣期，企业盈利能力提升，股市估值上升；在衰退期，估值可能下降。

### 1.2 影响股市估值的主要因素

#### 1.2.1 宏观经济因素
- 利率水平：低利率环境通常推高股市估值。
- 汇率波动：影响跨国公司收入和利润。
- 通货膨胀：影响企业成本和消费者购买力。

#### 1.2.2 行业因素
- 行业周期：不同行业受经济周期影响不同。
- 行业政策：政府政策对企业盈利能力和市场结构有直接影响。

#### 1.2.3 公司基本面因素
- 收益能力：净利润增长率是关键指标。
- 财务状况：资产负债率、现金流等反映企业的财务健康。
- 竞争优势：企业的核心竞争力决定其长期盈利能力。

### 1.3 常用的股市估值方法

#### 1.3.1 市盈率（P/E）模型
市盈率模型通过比较股价与每股收益的比率，评估股票的估值水平。

公式：
$$ PE = \frac{Price}{Earnings} $$

#### 1.3.2 市净率（P/B）模型
市净率模型通过比较股价与每股净资产的比率，评估股票的估值水平。

公式：
$$ PB = \frac{Price}{Book\ Value} $$

#### 1.3.3 现金流折现模型（DCF）
现金流折现模型通过将未来现金流折现，估算企业的内在价值。

公式：
$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} $$

# 数据采集
data = pd.read_csv('stock_data.csv')

# 数据清洗
data.dropna(inplace=True)

data['PE'] = data['Price'] / data['Earnings']

# 现金流折现模型
def dcf_valuation(cash_flows, discount_rate):
    return sum(cash_flows / (1 + discount_rate) ** t for t in range(len(cash_flows)))

# 示例计算
cash_flows = [100, 120, 150]
discount_rate = 0.05
dcf_value = dcf_valuation(cash_flows, discount_rate)
print(f"DCF Valuation: {dcf_value}")
