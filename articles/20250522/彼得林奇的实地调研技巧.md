### 5.2 核心代码实现

#### 5.2.1 数据收集与清洗
```python
import pandas as pd

# 读取数据
data = pd.read_csv('investment_data.csv')

# 查看数据前五行
print(data.head())

# 清洗数据
data = data.dropna()
data = data[~data[' revenue'].isnull()]
```

#### 5.2.2 数据分析与建模
```python
import numpy as np
from sklearn import linear_model

# 计算收益与风险的关系
data[' risk'] = np.log(data[' risk'])
data[' return'] = np.log(data[' return'])

# 使用线性回归模型
model = linear_model.LinearRegression()
model.fit(data[[' risk']], data[' return'])
```

#### 5.2.3 投资决策优化
```python
import matplotlib.pyplot as plt

# 可视化投资决策
plt.scatter(data[' risk'], data[' return'], alpha=0.5)
plt.plot(data[' risk'], model.predict(data[[' risk]]), color='red')
plt.xlabel('Risk')
plt.ylabel('Return')
plt.show()
```

### 5.3 案例分析与结果解读
通过上述代码，我们对投资数据进行了建模分析，结果显示彼得林奇的实地调研方法能够有效降低投资风险，提高收益。
