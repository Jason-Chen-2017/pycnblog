### 第3章: 常见的信用风险评估算法

#### 3.1 逻辑回归算法
- 3.1.1 算法原理
- 3.1.2 算法流程图
```mermaid
graph TD
    A[数据预处理] --> B[特征选择]
    B --> C[模型训练]
    C --> D[模型预测]
```
- 3.1.3 逻辑回归的数学模型
$$ P(y=1|x) = \frac{1}{1 + e^{- (w^T x + b)}} $$
- 3.1.4 代码实现
```python

model = LogisticRegression()
model.fit(X_train, y_train)
```

#### 3.2 随机森林算法
- 3.2.1 算法原理
- 3.2.2 算法流程图
```mermaid

    A[数据预处理] --> B[特征选择]
    B --> C[模型训练]
    C --> D[模型预测]
```
- 3.2.3 随机森林的数学模型
$$ y = \sum_{i=1}^{n} w_i x_i + b $$
- 3.2.4 代码实现


#### 3.3 神经网络算法
- 3.3.1 算法原理
- 3.3.2 算法流程图
```mermaid
graph TD
    A[数据预处理] --> B[特征选择]
    B --> C[模型训练]
    C --> D[模型预测]
```
- 3.3.3 神经网络的数学模型
$$ y = \sigma(w^T x + b) $$
其中，$\sigma$ 是激活函数。
- 3.3.4 代码实现
```python
import tensorflow as tf
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(1, activation='sigmoid')
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
model.fit(X_train, y_train, epochs=10)
```
