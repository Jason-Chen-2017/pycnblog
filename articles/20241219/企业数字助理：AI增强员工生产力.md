以下是一个简单的Python代码示例，用于实现数字助理的任务自动化功能：

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier

# 样本数据
tasks = np.array([
    [0, 1, 0],  # 邮件处理
    [1, 0, 1],  # 日程管理
    [0, 1, 1],  # 报告生成
    [1, 1, 0],  # 沟通协调
])

labels = np.array([
    0,  # 邮件处理
    1,  # 日程管理
    2,  # 报告生成
    3,  # 沟通协调
])

# 构建决策树分类器
classifier = DecisionTreeClassifier()

# 训练模型
classifier.fit(tasks, labels)

# 预测任务类型
new_task = np.array([[0, 1, 0]])
predicted_label = classifier.predict(new_task)

print("预测的任务类型：", predicted_label)
```

在这个示例中，我们使用决策树算法对任务进行分类。首先，我们准备了一些任务数据（tasks）和对应的标签（labels）。然后，我们构建一个决策树分类器，并使用训练数据对其进行训练。最后，我们使用训练好的模型对一个新的任务进行预测，并输出预测的结果。

```python
from flask import Flask, request, jsonify
import mysql.connector

app = Flask(__name__)

# MySQL数据库连接配置
db_config = {
    'host': 'localhost',
    'user': 'root',
    'password': 'password',
    'database': 'digital_assistant'
}

# 连接数据库
def connect_db():
    return mysql.connector.connect(**db_config)

@app.route('/task', methods=['POST'])
def submit_task():
    data = request.json
    task = data['task']
    
    # 连接数据库
    connection = connect_db()
    cursor = connection.cursor()
    
    # 插入任务
    query = "INSERT INTO tasks (task_name) VALUES (%s)"
    cursor.execute(query, (task,))
    
    # 提交事务
    connection.commit()
    
    # 关闭数据库连接
    cursor.close()
    connection.close()
    
    return jsonify({'status': 'success', 'message': 'Task submitted successfully.'})

@app.route('/task/<int:task_id>', methods=['GET'])
def get_task(task_id):
    # 连接数据库
    connection = connect_db()
    cursor = connection.cursor()
    
    # 查询任务
    query = "SELECT task_name FROM tasks WHERE task_id = %s"
    cursor.execute(query, (task_id,))
    result = cursor.fetchone()
    
    # 关闭数据库连接
    cursor.close()
    connection.close()
    
    if result:
        return jsonify({'status': 'success', 'task': result[0]})
    else:
        return jsonify({'status': 'error', 'message': 'Task not found.'})

if __name__ == '__main__':
    app.run(debug=True)
```
