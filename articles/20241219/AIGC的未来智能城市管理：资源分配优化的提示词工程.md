import numpy as np
import pandas as pd
from scipy.optimize import linprog

# 数据集
data = pd.DataFrame({
    'region': ['A', 'B', 'C', 'D', 'E'],
    'event_frequency': [10, 20, 15, 30, 25],
    'required_policemen': [5, 7, 6, 8, 9]
})

# 定义目标函数
def objective_function(x):
    return -np.sum(x * data['event_frequency'])

# 定义约束条件
def constraint_function(x):
    return x @ data['required_policemen'] >= 100

# 初始化决策变量
x = np.zeros(len(data))

# 求解线性规划问题
result = linprog(objective_function, np.ones(len(data)), constraint_function, method='highs')

# 输出结果
print("最优解：", result.x)

1. **线性规划（Linear Programming，LP）**：
   - **目标函数**：最大化或最小化线性目标函数。

   - **决策变量**：决策变量通常是连续的，即可以取任意实数值。

2. **整数规划（Integer Programming，IP）**：
   - **目标函数**：与线性规划类似，但决策变量是整数。
   - **约束条件**：与线性规划相同。
   - **决策变量**：通常是整数或二进制变量（0或1）。

3. **动态规划（Dynamic Programming，DP）**：
   - **目标函数**：通常是一个时间序列上的优化问题。
   - **约束条件**：约束条件随时间变化。
   - **决策变量**：可以是连续的或整数的，具体取决于问题。

**整数规划数学模型**

以下是一个简化的整数规划数学模型：

$$
\begin{aligned}

\text{subject to} \quad Ax \leq b \\

\end{aligned}
$$

其中，\(c\)、\(A\)、\(b\)与线性规划相同，\(x\)是整数决策变量。

**动态规划数学模型**

以下是一个简化的动态规划数学模型：

$$
\begin{aligned}
\min \quad \sum_{t=1}^T c_t(x_t) \\
\text{subject to} \quad G(x_{t-1}, x_t) \leq 0, \forall t=1,2,...,T
\end{aligned}
$$

其中，\(c_t(x_t)\)是时间\(t\)的目标函数，\(G(x_{t-1}, x_t)\)是时间\(t-1\)到时间\(t\)的约束条件，\(x_t\)是时间\(t\)的决策变量。
