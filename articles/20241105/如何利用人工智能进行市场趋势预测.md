#### 第1章：人工智能概述与市场趋势预测

##### 1.1 人工智能的定义与发展历程

人工智能，简称为AI，是指由人制造出来的系统所表现出来的智能行为。这个定义涵盖了从简单的规则系统到复杂的神经网络，再到能够自主学习和适应环境的智能体。人工智能的发展历程可以追溯到20世纪50年代，当时图灵提出了著名的“图灵测试”，以判断机器是否具备人类智能。自那以后，人工智能经历了几个重要的发展阶段：

1. **符号人工智能（Symbolic AI）**：20世纪50年代到70年代，基于逻辑推理和知识表示的方法，如专家系统和规则引擎。
2. **连接主义人工智能（Connectionist AI）**：20世纪80年代到90年代，基于人工神经网络的方法，如BP神经网络和卷积神经网络。
3. **统计机器学习（Statistical Machine Learning）**：20世纪90年代至今，基于统计方法和概率模型，如支持向量机、决策树和随机森林。
4. **深度学习（Deep Learning）**：21世纪初至今，基于多层神经网络的方法，如深度神经网络、生成对抗网络和变分自编码器。

##### 1.2 人工智能的基本原理与框架

人工智能的基本原理主要包括以下几个方面：

1. **数据输入**：AI系统通过传感器、数据库或其他数据源接收输入数据。
2. **数据处理**：AI系统对输入数据进行预处理、清洗和特征提取，以便于模型训练和预测。
3. **模型训练**：AI系统使用机器学习算法对数据集进行训练，以建立预测模型。
4. **模型评估**：AI系统通过验证集或测试集对模型进行评估，以确定其预测性能。
5. **模型应用**：AI系统将训练好的模型应用到实际场景中，进行预测或决策。

人工智能的框架通常包括以下几个层次：

1. **感知层**：感知层是AI系统的输入端，用于接收和处理外界信息。
2. **认知层**：认知层是AI系统的核心，负责处理和分析感知层接收到的信息，以实现智能行为。
3. **行动层**：行动层是AI系统的输出端，用于将认知层处理的结果应用到实际环境中。

##### 1.3 市场趋势预测的重要性

市场趋势预测在商业决策中扮演着至关重要的角色。通过准确预测市场趋势，企业可以：

1. **制定战略计划**：了解市场未来的发展方向，有助于企业制定长期和短期的战略计划。
2. **优化资源配置**：通过预测市场需求，企业可以合理分配资源，避免过剩或短缺。
3. **风险控制**：预测市场波动和潜在风险，有助于企业采取应对措施，降低损失。
4. **抓住机遇**：及时发现市场机会，帮助企业抓住增长点和扩大市场份额。

##### 1.4 市场趋势预测的基本概念与方法

市场趋势预测，是指利用历史数据、统计分析和其他方法，对未来市场走向进行预测的过程。其主要概念包括：

1. **时间序列**：时间序列是指按时间顺序排列的数据序列，用于描述某一变量随时间的变化情况。
2. **趋势**：趋势是指时间序列中变量随时间变化的总体方向，可以是上升、下降或稳定。
3. **周期**：周期是指时间序列中变量重复出现的波动模式，如季节性波动。
4. **季节性**：季节性是指时间序列中的周期性波动，通常与季节变化有关。

市场趋势预测的方法主要包括：

1. **统计分析法**：使用统计学方法，如移动平均、指数平滑和回归分析，对时间序列进行建模和预测。
2. **机器学习方法**：使用机器学习算法，如神经网络、支持向量机和随机森林，对时间序列进行建模和预测。
3. **深度学习方法**：使用深度学习算法，如卷积神经网络和递归神经网络，对时间序列进行建模和预测。

1. **数据处理与特征提取**：人工智能可以高效地处理和清洗大量市场数据，提取关键特征，为预测模型提供高质量的数据输入。
2. **模型训练与优化**：人工智能可以自动训练和优化预测模型，提高模型的准确性和鲁棒性。
3. **实时预测与调整**：人工智能可以实时分析市场数据，对预测模型进行动态调整，以应对市场变化。

#### 第2章：数据科学与市场趋势预测

数据科学是人工智能（AI）的重要组成部分，它通过统计学、机器学习和深度学习等方法，从数据中提取有价值的信息和知识。在市场趋势预测中，数据科学发挥着至关重要的作用，从数据收集、预处理到分析和挖掘，每个环节都离不开数据科学的支持。本章节将详细介绍数据科学的基本概念，以及如何将其应用于市场趋势预测。

##### 2.1 数据科学的基本概念

数据科学是一门跨学科领域，它结合了统计学、计算机科学、信息科学和领域知识，以解决实际数据问题为目标。数据科学的核心概念包括：

1. **数据（Data）**：数据是数据科学的基础，可以是结构化的（如数据库、表格）或非结构化的（如文本、图像、音频）。
2. **数据预处理（Data Preprocessing）**：数据预处理是数据科学的关键步骤，包括数据清洗、数据整合、数据转换等，目的是将原始数据转换为适合分析和建模的形式。
3. **特征工程（Feature Engineering）**：特征工程是指通过选择、构造和转换特征，以提高模型性能的过程。
4. **数据可视化（Data Visualization）**：数据可视化是将数据以图形或图像的形式呈现，帮助人们理解和分析数据。
5. **数据分析（Data Analysis）**：数据分析是通过统计和机器学习等方法，对数据进行探索和解释，以发现数据中的模式、关联和趋势。
6. **数据挖掘（Data Mining）**：数据挖掘是从大量数据中提取有价值信息和知识的过程，通常使用机器学习和统计学方法。

##### 2.2 数据收集与处理

数据收集是市场趋势预测的第一步，也是至关重要的一步。数据源可以包括内部数据（如销售记录、客户数据）和外部数据（如市场调查、社交媒体数据）。有效的数据收集需要考虑以下几点：

1. **数据质量**：确保数据准确、完整、一致和可靠。
2. **数据来源**：选择可靠和多样化的数据源，以提高数据的代表性。
3. **数据采集方法**：使用适当的工具和技术，如API、爬虫、传感器等，进行高效的数据采集。

数据处理是对收集到的数据进行整理和转换，使其适合分析和建模。主要步骤包括：

1. **数据清洗**：去除噪声、纠正错误、填补缺失值，以提高数据质量。
2. **数据整合**：将来自多个来源的数据进行合并，形成统一的数据集。
3. **数据转换**：将数据转换为适合分析和建模的格式，如数值化、归一化、标准化等。

##### 2.3 数据可视化

数据可视化是将数据以图形或图像的形式呈现，帮助人们理解和分析数据。有效的数据可视化可以揭示数据中的趋势、异常和关联。常用的数据可视化工具和技术包括：

1. **图表**：如折线图、柱状图、饼图等，用于展示数据的分布、趋势和比较。
2. **交互式可视化**：如交互式图表、仪表盘等，允许用户动态地探索和分析数据。
3. **地理信息系统（GIS）**：用于展示地理数据，如地图、热力图等。
4. **网络可视化**：用于展示网络结构、节点关系等，如节点图、关系图等。

##### 2.4 数据分析与挖掘

数据分析是数据科学的核心步骤，通过统计和机器学习等方法，对数据进行探索和解释。数据分析的方法包括：

1. **描述性分析**：描述数据的基本特征，如均值、方差、中位数等。
2. **探索性分析**：通过可视化、回归分析等方法，探索数据中的潜在模式、关联和趋势。
3. **预测性分析**：使用机器学习算法，如回归、分类、聚类等，建立预测模型，对未来进行预测。

数据挖掘是从大量数据中提取有价值信息和知识的过程。常用的数据挖掘方法包括：

1. **关联规则挖掘**：发现数据中的关联关系，如频繁项集、关联规则等。
2. **分类与回归**：将数据分为不同的类别或预测连续值，如决策树、支持向量机等。
3. **聚类**：将数据分为若干个群组，以揭示数据中的内在结构，如K-means、层次聚类等。

##### 2.5 市场趋势预测的数据源选择

在市场趋势预测中，选择合适的数据源至关重要。以下是一些常用的数据源：

1. **历史销售数据**：包括销售额、销售量、客户购买行为等，是预测市场需求的基础。
2. **市场调查数据**：包括消费者调查、行业报告、竞争对手分析等，提供市场洞察。
3. **社交媒体数据**：包括社交媒体平台上的评论、点赞、分享等，反映消费者情绪和趋势。
4. **宏观经济数据**：包括GDP、失业率、利率等，影响市场总体趋势。
5. **天气数据**：影响某些行业（如农业、旅游业）的市场趋势。

选择数据源时，需要考虑以下几点：

1. **数据质量**：确保数据准确、完整、一致和可靠。
2. **数据多样性**：选择多种数据源，以提高预测的全面性和准确性。
3. **数据可用性**：考虑数据的获取难度和成本，确保数据可访问性。
4. **数据时效性**：选择最新和实时数据，以反映市场的最新动态。

#### 第3章：机器学习与市场趋势预测

机器学习是人工智能（AI）的核心技术之一，它通过算法和模型，使计算机系统能够从数据中自动学习和改进。在市场趋势预测中，机器学习技术发挥着至关重要的作用。本章节将详细探讨机器学习的基本原理，包括监督学习、无监督学习和强化学习，以及市场趋势预测的常用算法，并分析机器学习在市场趋势预测中的应用。

##### 3.1 机器学习的基本原理

机器学习的基本原理可以概括为以下几个步骤：

1. **数据输入**：机器学习系统通过输入大量数据进行训练。
2. **数据处理**：对输入数据进行分析和处理，提取有用的特征。
3. **模型训练**：使用训练数据，通过算法和模型对数据进行训练，建立预测模型。
4. **模型评估**：使用验证集或测试集对训练好的模型进行评估，以确定其性能。
5. **模型应用**：将训练好的模型应用到实际问题中，进行预测或决策。

机器学习算法可以分为三类：监督学习、无监督学习和强化学习。

##### 3.2 监督学习、无监督学习和强化学习

1. **监督学习（Supervised Learning）**：监督学习是机器学习中最常见的类型，它通过已知的输入和输出数据，训练出一个预测模型。监督学习的主要任务包括分类和回归。

   - **分类（Classification）**：分类任务是将数据分为若干个预定义的类别。常见的分类算法有决策树、支持向量机（SVM）、朴素贝叶斯、逻辑回归和随机森林等。
   - **回归（Regression）**：回归任务是预测一个连续的数值输出。常见的回归算法有线性回归、多项式回归、岭回归、LASSO回归和随机森林回归等。

2. **无监督学习（Unsupervised Learning）**：无监督学习不依赖于已知的输入和输出数据，其目标是发现数据中的内在结构和规律。无监督学习的主要任务包括聚类和降维。

   - **聚类（Clustering）**：聚类任务是将数据分为若干个群组，使得同一群组内的数据点彼此相似，而不同群组的数据点差异较大。常见的聚类算法有K-means、层次聚类和DBSCAN等。

##### 4.1 时间序列分析的基本原理

时间序列分析的核心在于理解数据随时间的变化规律，并利用这些规律来预测未来的趋势。时间序列分析的基本步骤包括：

1. **数据收集**：收集相关的历史时间序列数据，如销售数据、股票价格、天气数据等。
2. **数据预处理**：清洗和预处理数据，包括缺失值填补、异常值处理、数据归一化等。
3. **特征提取**：从时间序列数据中提取有用的特征，如趋势、季节性和周期性。
4. **模型选择**：根据数据特征选择合适的预测模型，如ARIMA、LSTM等。
5. **模型训练与优化**：使用历史数据训练模型，并调整模型参数以优化预测性能。
6. **模型评估**：使用验证集或测试集评估模型的预测性能，如均方误差（MSE）、均方根误差（RMSE）等。
7. **预测与调整**：利用训练好的模型进行预测，并根据实际情况对模型进行调整和优化。

##### 4.2 常见的时间序列预测算法

时间序列预测算法可以根据其处理数据的方式分为统计方法和机器学习方法。以下是一些常见的时间序列预测算法：

1. **移动平均法（Moving Average）**：
   移动平均法是一种简单的时间序列预测方法，通过计算一段时间内的平均值来平滑数据中的波动。
   $$\text{MA}(t) = \frac{1}{n}\sum_{i=1}^{n} X(t-i)$$
   其中，\(X(t-i)\) 是时间 \(t-i\) 的观测值，\(n\) 是移动平均的窗口长度。

2. **指数平滑法（Exponential Smoothing）**：
   指数平滑法是一种更先进的时间序列预测方法，通过赋予不同时间段的观测值不同的权重，来平滑数据。
   $$S_t = \alpha X_t + (1-\alpha) S_{t-1}$$
   其中，\(S_t\) 是时间 \(t\) 的预测值，\(X_t\) 是时间 \(t\) 的观测值，\(\alpha\) 是平滑系数。

3. **ARIMA模型（Autoregressive Integrated Moving Average）**：
   ARIMA模型是一种经典的统计预测方法，它结合了自回归（AR）、差分（I）和移动平均（MA）三个部分，可以有效地处理时间序列中的趋势和季节性。
   $$X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + ... + \phi_p X_{t-p} + \theta_1 \epsilon_{t-1} + \theta_2 \epsilon_{t-2} + ... + \theta_q \epsilon_{t-q}$$
   其中，\(X_t\) 是时间 \(t\) 的观测值，\(c\) 是常数项，\(\phi_i\) 和 \(\theta_i\) 是模型参数，\(\epsilon_t\) 是误差项。

4. **LSTM（Long Short-Term Memory）**：
   LSTM是一种基于深度学习的循环神经网络，可以有效地处理长时依赖问题，在时间序列预测中表现出色。
   $$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$
   $$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$
   $$g_t = \tanh(W_g \cdot [h_{t-1}, x_t] + b_g)$$
   $$o_t = \sigma(W_o \cdot [h_{t-1}, g_t] + b_o)$$
   $$h_t = o_t \odot g_t$$
   其中，\(i_t\)、\(f_t\)、\(g_t\) 和 \(o_t\) 分别是输入门、遗忘门、生成门和输出门，\(\sigma\) 是sigmoid函数。

### 第5章：回归分析与预测

回归分析是市场趋势预测中常用的一种统计方法，通过建立自变量和因变量之间的数学模型，预测因变量的值。在市场趋势预测中，回归分析可以用来预测销售额、股票价格、消费者行为等。本章节将详细探讨回归分析的基本原理，包括线性回归、多项式回归和广义线性回归，并展示相关的伪代码和数学公式。

#### 5.1 回归分析的基本原理

回归分析的基本原理是通过建立数学模型，将因变量（目标变量）与自变量（特征变量）之间的关系表示出来。回归模型通常表示为：

\[ Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + ... + \beta_nX_n + \epsilon \]

其中，\( Y \) 是因变量，\( X_1, X_2, ..., X_n \) 是自变量，\( \beta_0, \beta_1, \beta_2, ..., \beta_n \) 是回归系数，\( \epsilon \) 是误差项。

回归分析可以分为线性回归和非线性回归。线性回归是最简单和最常用的回归方法，它的特点是自变量和因变量之间存在线性关系。非线性回归则通过引入非线性函数来描述自变量和因变量之间的复杂关系。

#### 5.2 线性回归、多项式回归与广义线性回归

1. **线性回归（Linear Regression）**：

线性回归是回归分析的基础，它假设因变量和自变量之间存在线性关系。线性回归模型的数学表达式为：

\[ Y = \beta_0 + \beta_1X + \epsilon \]

其中，\( \beta_0 \) 是截距，\( \beta_1 \) 是斜率。

线性回归的伪代码如下：

```python
# 数据预处理
X = sm.add_constant(X) # 添加截距项

# 模型训练
model = sm.LinearRegression()
model_fit = model.fit(X, y)

# 模型参数
print(model_fit.params)

# 预测
y_pred = model_fit.predict(X)
```

相关的数学公式如下：

\[ \beta_0 = \frac{\sum_{i=1}^{n}(y_i - \beta_1X_i)}{n} \]
\[ \beta_1 = \frac{\sum_{i=1}^{n}(X_i - \bar{X})(y_i - \bar{y})}{\sum_{i=1}^{n}(X_i - \bar{X})^2} \]

2. **多项式回归（Polynomial Regression）**：

多项式回归是一种扩展的线性回归方法，它通过引入多项式函数来描述自变量和因变量之间的非线性关系。多项式回归的数学表达式为：

\[ Y = \beta_0 + \beta_1X + \beta_2X^2 + ... + \beta_nX^n + \epsilon \]

多项式回归的伪代码如下：

```python

# 模型参数

# 预测

```

相关的数学公式如下：

\[ \beta_0 = \frac{\sum_{i=1}^{n}(y_i - \beta_1X_i - \beta_2X_i^2 - ... - \beta_nX_i^n)}{n} \]
\[ \beta_1 = \frac{\sum_{i=1}^{n}(X_i - \bar{X})(y_i - \bar{y})}{\sum_{i=1}^{n}(X_i - \bar{X})^2} \]
\[ ... \]
\[ \beta_n = \frac{\sum_{i=1}^{n}(X_i - \bar{X})^n(y_i - \bar{y})}{\sum_{i=1}^{n}(X_i - \bar{X})^{2n}} \]

3. **广义线性回归（Generalized Linear Regression）**：

广义线性回归是一种更灵活的回归方法，它可以处理非线性关系和不同的数据分布。广义线性回归的数学表达式为：

\[ g(E(Y)) = \eta = \beta_0 + \beta_1X + \beta_2X^2 + ... + \beta_nX^n + \epsilon \]

其中，\( g \) 是链接函数，用于将线性模型与响应变量的实际分布联系起来。广义线性回归的伪代码如下：

```python

model_fit = model.fit()

# 模型参数
print(model_fit.params)

# 预测
y_pred = model_fit.predict(X)
```

相关的数学公式如下：

\[ \eta = \beta_0 + \beta_1X + \beta_2X^2 + ... + \beta_nX^n \]
\[ g(E(Y)) = g(\beta_0 + \beta_1X + \beta_2X^2 + ... + \beta_nX^n) \]

### 第6章：聚类分析与预测

聚类分析是一种无监督学习方法，它通过将数据点分组为不同的簇，使同一簇内的数据点彼此相似，而不同簇的数据点差异较大。在市场趋势预测中，聚类分析可以帮助企业发现数据中的潜在模式，细分市场，了解客户行为等。本章节将详细探讨聚类分析的基本原理，常见的聚类算法，以及相关的伪代码与数学公式。

#### 6.1 聚类分析的基本原理

聚类分析的目标是将数据集划分为多个簇，使得同一簇内的数据点具有相似性，而不同簇的数据点具有差异性。聚类分析的基本步骤包括：

1. **数据预处理**：清洗和预处理数据，包括缺失值填补、异常值处理、数据归一化等。
2. **选择聚类算法**：根据数据特征和需求，选择合适的聚类算法。
3. **初始化簇中心**：随机选择或基于某种策略初始化簇中心。
4. **分配数据点**：将每个数据点分配到最近的簇中心所在的簇。
5. **更新簇中心**：重新计算每个簇的中心点。
6. **迭代计算**：重复执行步骤4和步骤5，直到满足停止条件（如收敛准则、最大迭代次数等）。
7. **评估聚类结果**：使用内部评估指标（如轮廓系数、类内方差等）和外部评估指标（如轮廓系数、类内方差等）评估聚类结果。

聚类分析的基本原理可以通过以下数学模型描述：

\[ C = \{C_1, C_2, ..., C_k\} \]

其中，\( C \) 表示聚类结果，\( C_i \) 表示第 \( i \) 个簇，\( k \) 表示簇的数量。

#### 6.2 常见的聚类算法

聚类算法根据簇的生成方式可以分为以下几种：

1. **K-means聚类**：
   K-means聚类是最常用的聚类算法之一，它通过迭代计算最小化簇内方差来生成簇。K-means聚类的基本步骤如下：

   - **初始化簇中心**：随机选择 \( k \) 个数据点作为初始簇中心。
   - **分配数据点**：将每个数据点分配到最近的簇中心所在的簇。
   - **更新簇中心**：计算每个簇的中心点，即簇内数据点的均值。
   - **迭代计算**：重复执行步骤2和步骤3，直到满足停止条件。

   K-means聚类的伪代码如下：

   ```python
   # 初始化簇中心
   centroids = initialize_centroids(k, X)

   # 迭代计算
   while not_converged:
       # 分配数据点
       clusters = assign_clusters(X, centroids)
       
       # 更新簇中心
       centroids = update_centroids(clusters, k)
   ```

   相关的数学公式如下：

   \[ \text{簇中心} = \frac{\sum_{i=1}^{n} x_i}{n} \]

2. **层次聚类**：
   层次聚类是一种基于层次结构的聚类算法，它通过自底向上或自顶向下的方法逐步合并或分裂聚类簇。层次聚类可以分为两类：

   - **自底向上（Agglomerative Clustering）**：自底向上层次聚类从每个数据点开始，逐步合并相似度最高的数据点，直到满足停止条件。
   - **自顶向下（Divisive Clustering）**：自顶向下层次聚类从所有数据点构成一个簇开始，逐步分裂簇，直到每个数据点构成一个簇。

   层次聚类的伪代码如下：

   ```python
   # 初始化簇
   clusters = initialize_clusters(k, X)

   # 迭代合并或分裂
   while not_converged:
       # 更新簇
       clusters = merge_or_split_clusters(clusters, X)
   ```

   相关的数学公式如下：

   \[ d(i, j) = \min_{x_i, x_j} \|x_i - x_j\| \]

3. **密度聚类**：
   密度聚类是一种基于密度的聚类算法，它通过计算数据点的密度来生成簇。密度聚类中最常用的是DBSCAN（Density-Based Spatial Clustering of Applications with Noise）算法。

   - **核心点**：如果某个点的邻域内的点数量超过设定阈值 \( min\_pts \)，则该点为核心点。
   - **边界点**：如果某个点的邻域内的点数量介于 \( min\_pts \) 和 \( min\_pts - 1 \) 之间，则该点为边界点。
   - **噪声点**：如果某个点的邻域内的点数量少于 \( min\_pts - 1 \)，则该点为噪声点。

   DBSCAN的伪代码如下：

   ```python
   # 初始化
   core_points = find_core_points(X, min_pts, epsilon)

   # 聚类
   while core_points:
       # 扩展簇
       cluster = expand_cluster(core_points, X, min_pts, epsilon)

       # 更新核心点
       core_points = remove_used_points(core_points, cluster)

       # 记录簇
       clusters[cluster] = len(cluster)
   ```

   相关的数学公式如下：

   \[ \text{密度} = \frac{\text{邻域点数}}{\text{邻域半径}} \]

#### 10.1 案例一：某电商平台的销售额预测

**背景**：

某电商平台希望通过AI技术预测未来30天的每日销售额，以便优化库存管理和营销策略。

**数据收集**：

电商平台提供了过去一年的销售额数据，包括每日销售额、促销活动、节假日信息等。数据来源于电商平台内部系统，包括商品销售记录、订单数据和用户行为数据。

**数据预处理**：

- 数据清洗：去除异常值和重复记录。
- 数据整合：将不同来源的数据进行整合，形成统一的数据集。
- 特征提取：提取历史销售额、月份、星期、促销活动等特征。

**模型选择**：

考虑到销售额数据具有时间序列特征和促销活动的影响，我们选择了ARIMA（自回归积分移动平均模型）进行预测。

**模型训练**：

使用过去一年的数据，我们训练了ARIMA模型，并使用交叉验证方法确定了最佳参数。

**模型评估**：

我们使用过去三个月的数据对模型进行评估，计算预测误差，如均方误差（MSE）和均方根误差（RMSE）。评估结果显示，模型具有较高的预测准确性和稳定性。

**模型应用**：

将训练好的模型应用到未来30天的预测中，得到每日销售额的预测结果。

**结果解读**：

通过分析预测结果，我们发现未来30天的销售额将呈现波动性增长，特别是在促销活动期间销售额显著上升。这有助于电商平台优化库存管理和营销策略，确保在关键时期有足够的库存和促销资源。

**代码实现**：

```python
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
from sklearn.metrics import mean_squared_error

# 读取数据
sales_data = pd.read_csv('sales_data.csv')
sales_data['Date'] = pd.to_datetime(sales_data['Date'])
sales_data.set_index('Date', inplace=True)

# 数据预处理
sales_data.fillna(method='ffill', inplace=True)
sales_data['Sales'] = sales_data['Sales'].astype(float)

# 模型训练
model = ARIMA(sales_data['Sales'], order=(1, 1, 1))
model_fit = model.fit()

# 模型预测
forecast = model_fit.forecast(steps=30)

# 模型评估
test_data = sales_data[-90:]
y_pred = model_fit.predict(start=len(sales_data), end=len(sales_data) + 29)
mse = mean_squared_error(test_data['Sales'], y_pred)
print(f'MSE: {mse:.3f}')

# 结果可视化
plt.figure(figsize=(10, 5))
plt.plot(sales_data['Sales'], label='Actual Sales')
plt.plot(pd.date_range(sales_data.index[-1], periods=30, freq='D'), forecast, label='Forecast Sales')
```
