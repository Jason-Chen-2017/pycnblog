### 1.1 宇宙背景辐射的起源与特性

#### 1.1.1 宇宙背景辐射的起源

#### 1.1.2 宇宙背景辐射的基本特性

宇宙背景辐射具有以下基本特性：

- **温度**：宇宙背景辐射的温度约为2.725 K，这是宇宙中最冷的温度之一。
- **辐射频谱**：宇宙背景辐射的频谱呈现黑体辐射特征，其峰值位于微波频段。
- **各向同性**：在早期宇宙中，宇宙背景辐射在各个方向上具有几乎相同的强度，呈现出高度各向同性的特征。

#### 附录B：代码示例

以下是一个简单的Python代码示例，用于读取宇宙背景辐射数据、进行数据预处理和描述性统计分析。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 读取宇宙背景辐射数据
data = pd.read_csv('CMB_data.csv')

# 数据预处理
# 填补缺失值
data.fillna(data.mean(), inplace=True)

# 剔除异常值
q1 = data.quantile(0.25)
q3 = data.quantile(0.75)
iqr = q3 - q1
data = data[~((data < (q1 - 1.5 * iqr)) | (data > (q3 + 1.5 * iqr))).any(axis=1)]

# 描述性统计分析
mean_temp = data['temperature'].mean()
std_temp = data['temperature'].std()
skew_temp = data['temperature'].skew()
kurt_temp = data['temperature'].kurt()

print(f"平均值：{mean_temp}")
print(f"标准差：{std_temp}")
print(f"偏度：{skew_temp}")
print(f"峰度：{kurt_temp}")

# 数据可视化
plt.figure(figsize=(8, 6))
plt.hist(data['temperature'], bins=30, alpha=0.5, label='温度分布')
plt.xlabel('温度')
plt.ylabel('频数')
plt.title('宇宙背景辐射温度分布')
plt.legend()
plt.show()
```
