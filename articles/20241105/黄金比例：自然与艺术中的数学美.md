#### 递归方法

递归方法是通过不断重复计算得到黄金比例的近似值。其基本思想是每次迭代计算下一个值是前两个值的比值。

**伪代码**：

```python
def golden_ratio(n):
    if n == 0:
        return 1
    elif n == 1:
        return 1
    else:
        return (golden_ratio(n-1) + golden_ratio(n-2)) / 1.0
```

通过递归调用，我们可以得到黄金比例的近似值。例如，`golden_ratio(10)` 将返回一个接近黄金比例的值。
