### Python源代码示例：量子态叠加与测量

以下是一个Python代码示例，用于演示量子态叠加和测量的实现。该示例使用NumPy库来定义量子态、进行量子态叠加和测量。

```python
import numpy as np

# 定义量子态
psi0 = np.array([1, 0])  # 基底态 |0>
psi1 = np.array([0, 1])  # 基底态 |1>

# 量子态叠加
psi_plus = (psi0 + psi1) / np.sqrt(2)  # 态叠加态 |+>

# 打印叠加态
print("叠加态：", psi_plus)

# 测量
prob_plus = np.dot(psi_plus, psi_plus.conj())  # 测量结果概率 |+>
prob_minus = np.dot(psi1, psi1.conj())  # 测量结果概率 |->

# 打印测量结果
print("测量结果：")
print(f"概率 |+>: {prob_plus}")
print(f"概率 |->: {prob_minus}")
```

在这个示例中，我们首先定义了两个基底态`psi0`和`psi1`，然后创建了一个叠加态`psi_plus`，它是基底态`psi0`和`psi1`的线性组合。接着，我们使用内积（dot product）计算了测量到叠加态`psi_plus`的概率和测量到基底态`psi1`的概率。这段代码演示了量子态叠加和测量的基本原理。

#### 系统核心实现源代码

以下是一个简单的示例，展示了如何使用Python实现量子态叠加和测量。这个示例将使用NumPy库进行计算。

```python
import numpy as np

# 定义量子态
psi0 = np.array([1, 0])  # 基底态 |0>
psi1 = np.array([0, 1])  # 基底态 |1>

# 量子态叠加
psi_plus = (psi0 + psi1) / np.sqrt(2)  # 态叠加态 |+>

# 打印叠加态
print("叠加态：", psi_plus)

# 测量
prob_plus = np.dot(psi_plus, psi_plus.conj())  # 测量结果概率 |+>
prob_minus = np.dot(psi1, psi1.conj())  # 测量结果概率 |->

# 打印测量结果
print("测量结果：")
print(f"概率 |+>: {prob_plus}")
print(f"概率 |->: {prob_minus}")
```

这段代码定义了两个基底态`psi0`和`psi1`，然后创建了一个叠加态`psi_plus`，它是基底态`psi0`和`psi1`的线性组合。接着，我们使用内积（dot product）计算了测量到叠加态`psi_plus`的概率和测量到基底态`psi1`的概率。

这段代码展示了量子态叠加和测量的基本原理。具体来说：

2. **量子态叠加**：
   - `psi_plus = (psi0 + psi1) / np.sqrt(2)` 创建了一个叠加态，它同时包含了 |0> 和 |1> 的成分。这个叠加态的振幅是两个基底态振幅的平均值，并除以根号2，以保持归一化。
