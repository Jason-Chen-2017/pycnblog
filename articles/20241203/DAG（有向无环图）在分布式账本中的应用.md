## 第一部分：DAG基础理论

### 第1章：DAG基本概念

#### 1.1 什么是DAG

**DAG的定义**：DAG（Directed Acyclic Graph，有向无环图）是由节点（或称为顶点）和边组成的图形结构，其中节点表示数据元素，边表示节点之间的关系，并且边的方向是有向的。DAG中的每一条边都指向一个特定的后续节点，而不会形成环。

**DAG与无向图、有向图的关系**：无向图是没有方向的边，而DAG则是具有方向的边。有向图可能包含环，但DAG不允许存在任何环。

#### 1.2 DAG的基本特性

**无环性**：DAG中的节点通过有向边连接，但不会形成闭合路径，即不存在环。

**有向性**：DAG的边是有方向的，即从源节点指向目标节点。

**节点与边的关系**：每个节点可以有一个或多个前驱节点和后继节点，但不会有形成闭环的情况。

#### 1.3 DAG与区块链的关系

**DAG在区块链中的应用背景**：传统的区块链技术使用链式结构来记录交易信息，而DAG提供了一种新的数据结构，可以实现多条并行链，提高了系统性能。

**DAG与区块链的区别与联系**：DAG在区块链中的应用主要体现在其去中心化和高扩展性上，它允许交易并行处理，提高了系统的吞吐量。同时，DAG解决了传统区块链中的“双花”问题。

## Python代码示例

**DAG拓扑排序实现**：

```python
from collections import defaultdict

def topological_sort(graph):
    in_degree = defaultdict(int)
    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    queue = [node for node, degree in in_degree.items() if degree == 0]
    sorted_nodes = []

    while queue:
        node = queue.pop(0)
        sorted_nodes.append(node)

        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return sorted_nodes
```

```python
import numpy as np

def longest_path(dag, source):
    dist = {node: float('inf') for node in dag}
    dist[source] = 0

    for _ in range(len(dag) - 1):
        for node in dag:
            for neighbor in dag[node]:
                if dist[node] + 1 < dist[neighbor]:
                    dist[neighbor] = dist[node] + 1

    return dist
```
