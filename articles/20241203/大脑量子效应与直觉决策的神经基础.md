## 6.1 实验一：脑电图与量子纠缠

```python
import numpy as np
import matplotlib.pyplot as plt

# 生成脑电图数据
brain_eeg_data = np.random.normal(size=1000)

# 绘制脑电图
plt.figure()
plt.plot(brain_eeg_data)
plt.title('Brain EEG Data')
plt.xlabel('Time (s)')
plt.ylabel('Amplitude')
plt.show()

# 生成量子纠缠数据
quantum_entanglement_data = np.random.normal(size=500) + 1j * np.random.normal(size=500)

# 绘制量子纠缠图
plt.figure()
plt.plot(quantum_entanglement_data.real, quantum_entanglement_data.imag, 'o')
plt.title('Quantum Entanglement')
plt.xlabel('Real Part')
plt.ylabel('Imaginary Part')
plt.show()
```
