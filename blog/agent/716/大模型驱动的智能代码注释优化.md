### 2.1 代码注释的基本概念

代码注释是程序员在代码中添加的用于解释代码功能、逻辑和意图的文本。注释可以分为以下几类：

1. **单行注释**：通常用于解释代码行的功能或用途，例如：
   ```python
   # 计算两个数的和
   result = a + b
   ```

2. **多行注释**：用于解释复杂代码块或函数的逻辑，例如：
   ```python
   """
   计算两个数的和，并返回结果。
   如果输入参数无效，则返回错误消息。
   """
   def add_numbers(a, b):
       if not isinstance(a, (int, float)) or not isinstance(b, (int, float)):
           return "输入参数无效"
       return a + b
   ```

3. **文档注释**：如Java中的Javadoc或Python中的Docstrings，用于生成代码的文档，例如：
   ```python
   """
   计算两个数的和。
   :param a: 第一个数
   :param b: 第二个数
   :return: 两个数的和
   """
   def add_numbers(a, b):
       return a + b
   ```
