为了更直观地理解数字极简主义算法的原理，以下提供一个简单的Python代码示例，展示算法的实现过程。这个示例将使用几个常见的Python库，如`re`（正则表达式）和`numpy`（数学运算）。

```python
import re
import numpy as np

# 信息收集
def collect_information(information):
    return information

# 筛选信息
def filter_information(information, keywords):
    filtered_info = [info for info in information if any(keyword in info for keyword in keywords)]
    return filtered_info

# 信息分类
def classify_information(information):
    classified_info = {'high_priority': [], 'low_priority': []}
    for info in information:
        if "urgent" in info or "high-priority" in info:
            classified_info['high_priority'].append(info)
        else:
            classified_info['low_priority'].append(info)
    return classified_info

# 优先级排序
def prioritize_information(information):
    sorted_info = sorted(information, key=lambda x: (-1 if "urgent" in x else 1, x))
    return sorted_info

# 处理与反馈
def process_and_feedback(information):
    processed_info = [info for info in information if "processed" not in info]
    for info in processed_info:
        print(f"Processing: {info}")
    return processed_info

# 主函数
def digital_minimalism_algorithm(information, keywords):
    collected_info = collect_information(information)
    filtered_info = filter_information(collected_info, keywords)
    classified_info = classify_information(filtered_info)
    sorted_info = prioritize_information(classified_info['high_priority'] + classified_info['low_priority'])
    processed_info = process_and_feedback(sorted_info)
    return processed_info

# 测试数据
information = [
    "urgent meeting tomorrow",
    "low-priority email from a friend",
    "urgent report due next week",
    "low-priority notification from social media",
    "high-priority reminder to call client"
]

# 运行算法
result = digital_minimalism_algorithm(information, ["urgent", "high-priority"])

print("Processed Information:")
for info in result:
    print(info)
```

这个Python代码示例实现了以下功能：

- **信息收集**：从列表中收集信息。
- **筛选信息**：利用关键字筛选信息，只保留包含关键字的信息。
- **信息分类**：将筛选后的信息分为高优先级和低优先级。
- **优先级排序**：根据信息中的关键字（如"urgent"或"high-priority"）对信息进行排序。
