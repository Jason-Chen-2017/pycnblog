- **数组（Array）**：数组是一种线性数据结构，它通过连续的内存地址存储一系列元素。数组的特点是支持随机访问，即可以快速访问任何位置的元素。然而，数组的长度在创建时即确定，因此不能动态扩展。

- **树（Tree）**：树是一种非线性数据结构，由节点和边组成，具有层次结构。二叉树、平衡树（如AVL树）、红黑树等是常用的树结构。树在搜索和排序算法中广泛应用。

- **图（Graph）**：图是一种由节点（或称为顶点）和边组成的数据结构，可以表示复杂的网络关系。图结构广泛应用于社交网络、交通网络、通信网络等。

每种数据结构都有其适用的场景。例如，数组适合处理连续的数据序列，链表适合动态扩展的数据，栈和队列用于模拟特定的操作顺序，而树和图则用于表示复杂的关系和网络结构。

```python
import numpy as np

def calculate_force(magnetic_poles, distance):
    k = 1  # 库仑常数
    q1, q2 = magnetic_poles
    r = distance
    force = k * (q1 * q2) / (r ** 2)
    return force

def simulate_magnetic_poles(magnetic_poles, positions, velocities, time_step):
    num_poles = len(magnetic_poles)
    total_force = np.zeros(num_poles)
    
    for i in range(num_poles):
        for j in range(i+1, num_poles):
            distance = np.linalg.norm(positions[i] - positions[j])
            force = calculate_force(magnetic_poles[i], distance)
            total_force[i] += force
            total_force[j] -= force

    for i in range(num_poles):
        velocities[i] += total_force[i] * time_step
        positions[i] += velocities[i] * time_step

# 示例数据
magnetic_poles = [[1, 0], [0, 1]]  # 磁单极子磁极强度
positions = [[0, 0], [1, 0]]  # 磁单极子初始位置
velocities = [[0, 0], [0, 1]]  # 磁单极子初始速度
time_step = 0.1  # 时间步长

simulate_magnetic_poles(magnetic_poles, positions, velocities, time_step)
print("更新后的位置:", positions)
```
