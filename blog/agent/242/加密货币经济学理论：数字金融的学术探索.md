**Python 源代码**

```python
class MarketModel:
    def __init__(self, supply, demand):
        self.supply = supply
        self.demand = demand

    def calculate_price(self):
        if self.demand > self.supply:
            return self.supply * 1.1
        elif self.supply > self.demand:
            return self.demand * 0.9
        else:
            return self.supply

# 示例
market = MarketModel(100, 120)
print(market.calculate_price())  # 输出：110
```

**算法原理的数学模型和公式**

假设市场需求量为 D，市场供应量为 S，则市场均衡价格 P 可表示为：

\[ P = \frac{D + S}{2} \]

如果需求大于供应，则价格上升，否则价格下降。

**举例说明**

市场需求量为 120，市场供应量为 100，根据上述模型，市场均衡价格为：

\[ P = \frac{120 + 100}{2} = 110 \]

### 3.2 Python 源代码

```python
class MarketModel:
    def __init__(self, supply, demand):
        self.supply = supply
        self.demand = demand

    def calculate_price(self):
        if self.demand > self.supply:
            return self.supply * 1.1
        elif self.supply > self.demand:
            return self.demand * 0.9
        else:
            return self.supply

# 示例
market = MarketModel(100, 120)
print(market.calculate_price())  # 输出：110
```

### 3.3 算法原理的数学模型和公式

假设市场需求量为 D，市场供应量为 S，则市场均衡价格 P 可表示为：

\[ P = \frac{D + S}{2} \]

如果需求大于供应，则价格上升，否则价格下降。

### 3.4 举例说明

市场需求量为 120，市场供应量为 100，根据上述模型，市场均衡价格为：

\[ P = \frac{120 + 100}{2} = 110 \]
