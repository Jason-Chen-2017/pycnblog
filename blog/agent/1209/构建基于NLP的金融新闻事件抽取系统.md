**2.1 NLP关键概念**

**2.1.1 词向量表示**

词向量表示是NLP中的一个基础概念，它将单词映射到高维空间中的向量。词向量不仅有助于表示单词的语义信息，还为文本数据的机器学习模型提供了输入。常见的词向量模型有Word2Vec、GloVe和BERT等。

- **Word2Vec**：通过训练词的上下文来生成词向量，其核心思想是将单词与其上下文关联起来，从而捕捉单词的语义信息。
- **GloVe**：全局向量表示（Global Vectors for Word Representation），通过训练词的共现矩阵来生成词向量，能够捕捉单词的语义和语法信息。

深度学习模型在NLP任务中表现出色，能够自动学习文本中的复杂模式和关系。以下三种模型在金融新闻事件抽取中具有广泛应用：

**3.1.1 Transformer模型**

Transformer模型是由Vaswani等人在2017年提出的一种基于自注意力机制的深度学习模型。它通过多头自注意力机制和前馈神经网络，能够捕捉文本中的长距离依赖关系。

- **自注意力机制**：Transformer模型中的自注意力机制允许模型在处理每个词时，根据其他所有词的重要性来调整其权重，从而捕捉长距离依赖关系。
- **多头自注意力**：多头自注意力机制将输入序列分成多个子序列，每个子序列独立进行自注意力计算，从而增加模型的表达能力。
- **前馈神经网络**：在自注意力机制之后，Transformer模型还会经过一个简单的前馈神经网络，进一步增加模型的非线性表达能力。

**3.1.2 BERT模型**

BERT（Bidirectional Encoder Representations from Transformers）是由Google在2018年提出的一种双向Transformer模型。BERT通过在预先训练的语料库上大规模预训练，然后针对特定任务进行微调，能够在各种NLP任务中取得优异的性能。

- **双向编码表示**：BERT模型使用两个方向（前向和后向）的Transformer编码器，能够同时捕捉输入文本的前后依赖关系，从而提高模型的语义理解能力。
- **预训练与微调**：BERT模型在预训练阶段，通过无监督学习从大量文本数据中学习语言规律，然后在特定任务上进行微调，从而提高任务性能。

**3.1.3 GPT模型**

GPT（Generative Pre-trained Transformer）是由OpenAI在2018年提出的一种自回归Transformer模型，主要用于生成文本。

- **自回归机制**：GPT模型通过自回归机制生成文本，每个时间步的输出依赖于前面的所有时间步的输入，从而生成连贯的文本。
- **前向Transformer编码器**：GPT模型使用前向Transformer编码器，通过多头自注意力机制和前馈神经网络，学习文本中的序列依赖关系。
- **预训练与生成**：GPT模型通过在预先训练的语料库上进行大规模预训练，然后生成文本，从而生成连贯、符合语义的文本。

model = BertForSequenceClassification.from_pretrained('bert-base-uncased')

# 预处理文本数据
def preprocess_text(text):
    inputs = tokenizer(text, padding=True, truncation=True, return_tensors="pt")
    return inputs

# 事件抽取函数
def extract_events(text):
    inputs = preprocess_text(text)
    with torch.no_grad():
        outputs = model(inputs)
    logits = outputs.logits
    probabilities = torch.softmax(logits, dim=1)
    predicted_class = torch.argmax(probabilities).item()
    return predicted_class
