## 第2章 Self-Consistency理论基础

### 2.1 Self-Consistency的定义

Self-Consistency是指网络中节点和边的关系保持一致性的一种属性。具体来说，如果一个网络在演化过程中，其节点和边的关系始终保持一致，即网络结构不发生大的变化，那么该网络就具有Self-Consistency属性。Self-Consistency可以从以下几个方面进行理解：

1. **节点和边的定义**：在复杂网络中，节点表示个体或实体，边表示节点之间的联系或相互作用。
2. **一致性的概念**：一致性指的是网络在演化过程中，节点和边的关系保持稳定，不发生大幅度的变化。
3. **自我参照性**：Self-Consistency强调网络结构的自我参照性，即网络中的节点和边在演化过程中，遵循一定的规律，使得网络结构具有一定的稳定性和规律性。

### 2.2 Self-Consistency的性质

Self-Consistency具有以下性质：

1. **稳定性**：具有Self-Consistency属性的网络在演化过程中能够保持稳定，不易受到外部干扰。
2. **自适应性**：网络中的节点和边可以根据外部环境的变化进行自适应调整，以保持网络结构的Self-Consistency。
3. **层次性**：网络中的节点和边可以按照层次结构进行组织，层次结构能够体现网络的功能和稳定性。
4. **动态性**：Self-Consistency是一个动态过程，网络在演化过程中，节点和边的关系会发生变化，但总体上保持一致性。

## 第3章 复杂网络分析方法

### 3.1 复杂网络的特性

复杂网络具有以下几个主要特性：

1. **高度连接性**：复杂网络中的节点和节点之间存在大量的连接关系，这使得网络具有较高的连接性。
2. **高度动态性**：复杂网络中的节点和边会随着时间的推移发生变化，网络结构具有高度动态性。
3. **异质性**：复杂网络中节点的类型和属性存在较大差异，网络结构具有异质性。
4. **小世界效应**：复杂网络中任意两个节点之间可以通过较少的中间节点相互访问，表现出小世界效应。
5. **长尾分布**：复杂网络中节点的度分布往往呈现出长尾分布，即少数节点拥有大量连接，而大多数节点连接较少。

这些特性使得复杂网络分析成为一项极具挑战性的任务。为了有效分析复杂网络，我们需要了解网络的基本属性和常用的分析方法。

### 3.2 复杂网络分析的基本步骤

复杂网络分析通常包括以下基本步骤：

1. **网络数据的获取**：通过网络爬虫、数据库访问或传感器采集等方式获取网络数据。
2. **网络数据的预处理**：对获取的网络数据进行清洗、去重、去噪声等处理，以获得高质量的数据集。
3. **网络结构的分析**：通过绘制网络图、计算网络基本属性（如节点度、边密度、聚类系数等）来分析网络结构。
4. **网络动力学的分析**：研究网络中节点和边的动态变化，分析网络的稳定性和演化规律。
5. **网络功能分析**：基于网络结构和动力学特性，识别网络中的关键节点和关键路径，分析网络的功能和作用。

### 3.3 常用的复杂网络分析方法

以下是一些常用的复杂网络分析方法：

1. **网络聚类分析**：将网络中的节点划分为不同的聚类，用于识别网络中的模块和社区结构。
2. **网络社区检测**：识别网络中的紧密连接的节点集合，用于分析网络中的社群关系。
3. **网络传播分析**：研究网络中信息、疾病或其他现象的传播过程，用于预测和控制网络中的传播现象。
4. **网络拓扑分析**：通过分析网络图的拓扑特性（如节点度、路径长度、聚类系数等），理解网络的拓扑结构。
5. **网络稳定性分析**：研究网络在受到外部干扰时的稳定性和恢复能力。
6. **网络进化分析**：分析网络中节点和边的演化过程，理解网络的演化规律。

## 第5章 Self-Consistency算法设计

### 5.1 Self-Consistency算法的基本原理

Self-Consistency算法是一种用于评估复杂网络中节点和边的一致性程度的算法。其基本原理是通过计算网络中的节点和边的关系保持一致性的一种度量，从而识别网络中的关键节点和边。

#### 5.1.1 Self-Consistency算法的数学模型

为了理解Self-Consistency算法的基本原理，我们首先需要定义一些基本的概念和符号：

- **网络G(V, E)**：表示一个复杂网络，其中V是节点集合，E是边集合。
- **节点i的度度数**：表示节点i在网络上与其他节点相连的边的数量，记为\(d_i\)。
- **边(u, v)的一致性度**：表示边(u, v)在网络上与其他边的连接关系保持一致性的程度，记为\(C(u, v)\)。
- **网络的整体一致性度**：表示网络中所有边的一致性度的平均值，记为\(C_G\)。

Self-Consistency算法的数学模型可以表示为：

$$
C_G = \frac{1}{|E|} \sum_{(u, v) \in E} C(u, v)
$$

其中，\(C(u, v)\)可以通过以下公式计算：

$$
C(u, v) = \frac{d_u + d_v - 2}{d_u \times d_v}
$$

这个公式表示，边(u, v)的一致性度是其两端节点的度之和减去2，再除以两端节点的度的乘积。这个公式基于以下假设：如果一个边的两端节点的度较高，那么这个边在网络中可能更重要，因此它的一致性度也较高。

#### 5.1.2 Self-Consistency算法的基本流程

Self-Consistency算法的基本流程可以分为以下几个步骤：

1. **数据读取**：从网络数据源读取节点和边的数据，构建网络图。
2. **度计算**：计算网络中每个节点的度，即每个节点与其他节点相连的边的数量。
3. **一致性度计算**：对于网络中的每一条边(u, v)，计算其一致性度\(C(u, v)\)。
4. **整体一致性度计算**：计算网络的整体一致性度\(C_G\)，即所有边的一致性度的平均值。
5. **结果输出**：输出网络的整体一致性度以及每个节点和边的一致性度。

        degrees[edge.second]++;
    }

}

map<pair<int, int>, double> calculate_edge_consistency(const map<int, int>& degrees, const vector<pair<int, int>>& edges) {

        total_consistency += ec.second;
    }
    total_consistency /= edge_consistency.size();
    return total_consistency;
}
