形式主义的起源可以追溯到德国数学家戴德金（Richard Dedekind）和弗雷格（Gottlob Frege）的工作。戴德金通过提出实数的构造理论，强调数学概念可以通过明确的定义和构造来建立。他的工作为形式主义奠定了基础。弗雷格则通过发展逻辑符号主义，将数学命题表示为逻辑公式，从而为形式主义提供了理论基础。

在20世纪初，希尔伯特（David Hilbert）进一步推动了形式主义的发展。他提出了形式化数学体系的构想，主张将数学理论建立在严格的符号操作和逻辑推理之上。希尔伯特认为，数学命题的真假应该通过符号操作和证明来确定，而不是依赖于直观或经验。

哥德尔（Kurt Gödel）和图灵（Alan Turing）的工作进一步深化了形式主义的内涵。哥德尔在1931年提出了著名的“不完备性定理”，揭示了形式系统中的不完全性。他的工作表明，即使在严格的逻辑框架内，也存在一些数学命题是无法证明的。这一发现对形式主义提出了挑战，但也推动了形式主义方法的发展。

```python
# Django 模型定义
from django.db import models

class User(models.Model):
    username = models.CharField(max_length=100)
    password = models.CharField(max_length=100)

class Product(models.Model):
    name = models.CharField(max_length=100)
    price = models.DecimalField(max_digits=10, decimal_places=2)

class ShoppingCart(models.Model):
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    products = models.ManyToManyField(Product)

class Order(models.Model):
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    total_price = models.DecimalField(max_digits=10, decimal_places=2)
    status = models.CharField(max_length=50)

class Payment(models.Model):
    order = models.ForeignKey(Order, on_delete=models.CASCADE)
    amount = models.DecimalField(max_digits=10, decimal_places=2)
    status = models.CharField(max_length=50)
```

- 订单模型（Order）定义了订单的基本信息，包括用户、总价格和订单状态。
- 支付模型（Payment）定义了支付的基本信息，包括订单、支付金额和支付状态。
