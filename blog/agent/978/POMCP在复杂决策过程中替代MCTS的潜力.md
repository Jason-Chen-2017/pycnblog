POMCP是一种用于解决不确定决策问题的蒙特卡洛树搜索算法，其核心思想是通过概率采样来选择动作，从而提高搜索效率。

#### 2.1.2 POMCP的特点

1. 引入概率信息，优化搜索过程。
2. 相对于MCTS，具有更高的搜索效率和更好的收敛速度。
3. 适用于复杂决策问题，特别是在不确定性较高的场景中。

#### 2.1.3 POMCP的优势

1. 在复杂决策场景中，POMCP具有更高的计算效率和更好的收敛速度。
2. 相对于MCTS，POMCP能够更好地处理不确定性问题。
3. POMCP适用于多种决策场景，如游戏AI、自动驾驶和资源分配等。

### 2.2 MCTS简介

MCTS（Monte Carlo Tree Search）是一种基于蒙特卡洛方法的树搜索算法，常用于解决不确定决策问题。它通过在树结构中进行随机采样和评估，来选择最优动作。

        self.value = 0

def ucb1(node, c=1):

        return float('inf')
