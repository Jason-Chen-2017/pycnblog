### 5.2 系统核心实现源代码

以下是系统核心实现源代码，包括数据收集、预处理、提示词生成和智能分析等部分。

```python
# 数据收集与预处理
import pandas as pd
import numpy as np
from sklearn.preprocessing import MinMaxScaler

# 加载数据集
data = pd.read_csv('ocean_data.csv')

# 数据预处理
data = data.dropna()
data = MinMaxScaler().fit_transform(data)

# 提示词生成
from sklearn.feature_extraction.text import TfidfVectorizer

# 加载训练数据
train_data = data['text']

# 初始化TF-IDF向量器
vectorizer = TfidfVectorizer()

# 转换为向量
X = vectorizer.fit_transform(train_data)

# 智能分析
from sklearn.linear_model import LogisticRegression

# 加载测试数据
test_data = data['text']

# 转换为向量
X_test = vectorizer.transform(test_data)

# 训练模型
model = LogisticRegression()
model.fit(X, data['label'])

# 预测
predictions = model.predict(X_test)

# 输出预测结果
print(predictions)
```

1. 数据收集与预处理：使用pandas库加载数据集，并使用scikit-learn中的MinMaxScaler对数据进行归一化处理。
2. 提示词生成：使用scikit-learn中的TfidfVectorizer对文本数据进行向量化处理，生成与文本相关的特征向量。
3. 智能分析：使用scikit-learn中的LogisticRegression对特征向量进行分类预测，实现对海洋资源的智能分析。
