#### 3.3 系统架构设计（Mermaid架构图）

```mermaid
sequenceDiagram
  User ->> LoginService: 登录请求

  User ->> CreateComment: 创建评论
  CreateComment ->> CommentService: 保存评论
  CommentService ->> CommentRepository: 保存到数据库
  CommentRepository ->> CommentService: 返回保存结果
  CommentService ->> UserInterface: 显示评论

  User ->> SubscribeJournal: 订阅日志
```

在这个架构图中，我们定义了以下核心服务：

- **UserService**（用户服务）：提供用户相关的业务逻辑，如创建、更新和查询用户信息。
- **JournalEntryService**（日志条目服务）：处理日志条目的创建、更新和查询。
- **CommentService**（评论服务）：处理评论的创建、更新和查询。
- **SubscriptionService**（订阅服务）：处理用户的订阅请求，如创建、更新和查询订阅信息。

通过这个架构图，我们可以清晰地看到系统中的各个服务和它们之间的关系。
