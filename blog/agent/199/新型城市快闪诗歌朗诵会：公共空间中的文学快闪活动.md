#### 2.1.3 诗歌朗诵

诗歌朗诵是一种通过声音、语调、节奏等手段，将诗歌的意境、情感和思想传达给听众的艺术形式。诗歌朗诵不仅是对诗歌的解读和欣赏，更是一种情感表达和思想交流的方式。

### 3.3 数学模型和数学公式

$$
P = R \cdot S \cdot T \cdot E \cdot V
$$

其中，$P$表示活动成功概率，$R$表示场地选择合适度，$S$表示时间安排适宜度，$T$表示参与者招募充分度，$E$表示活动宣传效果，$V$表示反馈收集有效性。

### 3.4 举例说明

假设一场快闪诗歌朗诵会的场地选择合适度为0.8，时间安排适宜度为0.9，参与者招募充分度为0.7，活动宣传效果为0.85，反馈收集有效性为0.8，则活动成功概率为：

$$
P = 0.8 \cdot 0.9 \cdot 0.7 \cdot 0.85 \cdot 0.8 \approx 0.431
$$

即活动成功概率约为43.1%。

在本节中，我们将介绍系统核心功能的实现代码。以下是详细的代码和解释：

```python
# core.py

from flask import Flask, request, jsonify
import pymysql

app = Flask(__name__)

# 数据库连接配置
db_config = {
    'host': 'localhost',
    'user': 'root',
    'password': 'password',
    'db': 'activity_management'
}

# 连接数据库
def connect_db():
    connection = pymysql.connect(**db_config)
    return connection

# 创建活动
@app.route('/create_activity', methods=['POST'])
def create_activity():
    data = request.get_json()
    activity_name = data['activity_name']
    activity_date = data['activity_date']
    activity_time = data['activity_time']
    
    connection = connect_db()
    cursor = connection.cursor()
    
    query = "INSERT INTO activities (name, date, time) VALUES (%s, %s, %s)"
    cursor.execute(query, (activity_name, activity_date, activity_time))
    connection.commit()
    
    cursor.close()
    connection.close()
    
    return jsonify({'status': 'success', 'message': '活动创建成功'})

# 查询活动
@app.route('/get_activities', methods=['GET'])
def get_activities():
    connection = connect_db()
    cursor = connection.cursor()
    
    query = "SELECT * FROM activities"
    cursor.execute(query)
    activities = cursor.fetchall()
    
    cursor.close()
    connection.close()
    
    return jsonify(activities)

if __name__ == '__main__':
    app.run(debug=True)
```

   - 系统返回活动的列表，用户可以查看新创建的活动。
