import pandas as pd

#### 5.3 LaTeX 数学模型讲解

在工业设备寿命预测中，常用的数学模型包括线性回归模型和支持向量机模型。

**线性回归模型**：

$$y = \beta_0 + \beta_1 \cdot x_1 + \beta_2 \cdot x_2 + \ldots + \beta_n \cdot x_n + \epsilon$$

其中，$y$ 是预测值，$x_1, x_2, \ldots, x_n$ 是特征值，$\beta_0, \beta_1, \beta_2, \ldots, \beta_n$ 是模型参数，$\epsilon$ 是误差项。

**支持向量机模型**：

$$\max_{\beta, \beta_0, \xi} \frac{1}{2} ||\beta||^2 - C \sum_{i=1}^{n} \xi_i$$

$$s.t. y_i (\beta \cdot x_i + \beta_0) \geq 1 - \xi_i$$

$$\xi_i \geq 0, \forall i$$

其中，$\beta$ 是模型参数，$\beta_0$ 是偏置项，$\xi_i$ 是松弛变量，$C$ 是惩罚参数，$y_i$ 是标签，$x_i$ 是特征向量。

### 总结

y_pred = model.predict(X_test)

# 评估模型
mae = mean_absolute_error(y_test, y_pred)
print(f'Mean Absolute Error: {mae}')
