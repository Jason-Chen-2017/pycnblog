##### 2.1 图神经网络基础

图神经网络（GNN）是一种专门用于处理图结构数据的深度学习模型。其基本原理是通过节点和边的特征，学习一种映射函数，将图结构转化为特征向量，从而实现对图数据的理解和分析。

**核心概念：**

- **节点特征：** 节点特征是指节点在图中的属性，如节点的度、标签等。
- **边特征：** 边特征是指边在图中的属性，如边的权重、类型等。
- **图卷积操作：** 图卷积操作是一种将节点特征和其邻居节点的特征进行融合的运算，从而生成新的节点特征。

**原理讲解：**

图神经网络的核心思想是通过图卷积操作，逐步聚合节点及其邻居的信息，从而生成高层次的特征表示。具体过程如下：

1. **初始化：** 初始化每个节点的特征向量。
2. **图卷积操作：** 对每个节点，利用其特征和邻居节点的特征，通过卷积操作生成新的特征向量。
3. **激活函数：** 对生成的特征向量进行激活函数处理，如ReLU函数。
4. **层叠：** 将上述过程进行多次迭代，从而生成更高层次的特征表示。

**属性特征对比表格：**

| 特征类型 | 描述 | 对比 |
| -------- | ---- | ---- |
| 节点特征 | 节点的属性信息 | 与边特征进行融合，生成新的节点特征 |
| 边特征 | 边的属性信息 | 用于描述节点之间的关系 |
| 图卷积操作 | 融合节点及其邻居的特征 | 与传统的卷积操作类似，但适用于图结构数据 |

##### 2.2 时序数据基础

时序数据（Temporal Data）是指在一定时间范围内产生、记录的数据，如时间序列、日志数据、传感器数据等。时序数据具有时间顺序性、时间间隔性和时间依赖性等特点。

- **时间序列：** 时间序列是一组按时间顺序排列的数据点，用于描述某个变量随时间的变化情况。
- **时间间隔：** 时间间隔是指两个连续时间点之间的时间长度。
- **时间依赖性：** 时间依赖性是指一个时间点的数据受到前面时间点数据的影响。

**原理讲解：**

时序数据的特点决定了其处理方法与传统数据不同。时序数据的分析通常包括以下几个方面：

##### 3.2 模型架构

**图卷积操作**

1. **初始化**：初始化每个节点的特征向量。
2. **聚合**：对每个节点，聚合其邻居节点的特征，形成新的特征向量。
3. **变换**：对新的特征向量进行非线性变换，如ReLU函数。
4. **更新**：将变换后的特征向量更新为当前节点的特征。
