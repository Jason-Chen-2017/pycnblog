    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({'status': 'success', 'message': 'Login successful.'})

if __name__ == '__main__':

### 附录B：相关公式与计算方法

1. **K-Means算法**：
   用于对数据进行聚类分析，公式为：
   $$ \text{centroids} = \frac{1}{N} \sum_{i=1}^{N} x_i $$
   其中，$x_i$ 为数据点，$centroids$ 为聚类中心。

2. **特质评估得分**：
   用于评估个人特质，公式为：
   $$ \text{score} = \frac{\text{正确答案数}}{\text{总题目数}} $$
   其中，$\text{正确答案数}$ 和 $\text{总题目数}$ 分别为用户在问卷中的正确答案数和题目总数。

3. **成长计划完成度**：
   用于衡量成长计划的执行情况，公式为：
   $$ \text{completion rate} = \frac{\text{已完成任务数}}{\text{总任务数}} \times 100\% $$
   其中，$\text{已完成任务数}$ 和 $\text{总任务数}$ 分别为用户已完成的任务数和总任务数。
