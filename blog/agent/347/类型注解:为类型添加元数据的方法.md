#### 2.1.3 类型注解的语法

不同编程语言中的类型注解语法有所不同，但通常都遵循以下基本语法规则：

1. **注解定义**：类型注解通常以`@`符号开头，后面跟注解名称和参数。例如，在TypeScript中，`@MyAnnotation(value)` 是一个自定义注解的定义。
2. **参数传递**：类型注解可以传递参数，这些参数通常用于提供额外的信息。参数可以通过键值对的形式传递，如`@MyAnnotation(value: "example")`。
3. **应用位置**：类型注解可以应用在变量、函数、类、模块等元素上。例如，`@MyAnnotation` 可以用于标记一个类或方法。

```typescript
class ShoppingCart {
    private items: Map<string, Product>;

    constructor() {
        this.items = new Map<string, Product>();
    }

    addItem(product: Product) {
        if (this.items.has(product.sku)) {
            console.error("Product already exists in the cart.");
            return false;
        }

        this.items.set(product.sku, product);
        console.log("Item added to the cart.");
        return true;
    }

    removeItem(sku: string) {
        if (this.items.has(sku)) {
            this.items.delete(sku);
            console.log("Item removed from the cart.");
        } else {
            console.error("Product not found in the cart.");
        }
    }

    getTotal(): number {
        return Array.from(this.items.values()).reduce((total, product) => total + product.price, 0);
    }
}
```

**案例剖析**

**1. 数据校验**

在这个案例中，我们使用了三种自定义类型注解：`@unique`、`@nonEmpty` 和 `@positive`。这些注解用于确保产品数据的完整性。

- `@unique`：确保产品的SKU是唯一的，防止重复添加相同的产品到购物车。
- `@nonEmpty`：确保产品的名称不为空，防止添加空名称的产品。
- `@positive`：确保产品的价格是正数，防止添加负数价格的产品。

**2. 购物车操作**

购物车类（`ShoppingCart`）提供了添加、删除和计算总价的操作。通过类型注解，我们可以确保这些操作中的数据是合法的。

- `addItem`：添加产品到购物车前，会检查产品的SKU是否唯一，名称是否非空，价格是否为正。
- `removeItem`：删除购物车中的产品，会检查SKU是否存在于购物车中。
- `getTotal`：计算购物车的总价，确保所有产品的价格都是正数。
