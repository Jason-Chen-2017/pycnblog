```python
from nltk.tokenize import word_tokenize
from gensim.models import Word2Vec

def feature_extraction(data):
    # 提取词频、词向量、词性标注等特征
    w2v_model = Word2Vec(sentences=data['text'].tolist(), vector_size=100, window=5, min_count=1, workers=4)
    feature_list = []
    for text in data['text']:
        tokens = word_tokenize(text)
        token_vectors = [w2v_model[token] for token in tokens if token in w2v_model]
        if token_vectors:
            feature_vector = np.mean(token_vectors, axis=0)
            feature_list.append(feature_vector)
    return np.array(feature_list)
```

这段代码的主要目的是从预处理后的文本数据中提取特征。具体操作包括：

1. **分词**：使用`word_tokenize()`方法对文本进行分词，以得到每个文本的单词列表。
2. **词向量表示**：使用`Word2Vec`模型对单词进行向量化表示，将每个单词映射为一个向量。
3. **特征向量计算**：将每个文本的单词向量求平均，得到一个特征向量，用于后续的模型训练。
