### 算法原理

#### 基本概念
本算法旨在实现一个简单的计算器，能够根据用户输入的两个数字和一个运算符，计算并输出结果。算法的基本流程如下：

1. 初始化：创建必要的变量，如数字1、数字2、运算符和结果。
2. 检查输入：判断用户输入的数字和运算符是否有效。
3. 执行算法：根据输入的运算符，执行相应的计算。
4. 输出结果：将计算结果输出。

#### 数学模型和公式

- 计算两个数的加法：$$ result = num1 + num2 $$
- 计算两个数的减法：$$ result = num1 - num2 $$
- 计算两个数的乘法：$$ result = num1 \times num2 $$
- 计算两个数的除法：$$ result = num1 \div num2 $$

#### Python源代码

```python
def calculate(num1, num2, operator):
    if operator == '+':
        return num1 + num2
    elif operator == '-':
        return num1 - num2
    elif operator == '*':
        return num1 * num2
    elif operator == '/':
        return num1 / num2
    else:
        raise ValueError("Invalid operator")

try:
    num1 = float(input("请输入第一个数字："))
    num2 = float(input("请输入第二个数字："))
    operator = input("请输入运算符（+、-、*、/）：")

    result = calculate(num1, num2, operator)
    print(f"{num1} {operator} {num2} = {result}")
except ValueError as e:
    print(e)
```

#### 系统核心实现

```python
from flask import Flask, request, jsonify
from models import User, Product, Order
from database import init_db

app = Flask(__name__)

@app.route('/register', methods=['POST'])
def register():
    username = request.form['username']
    password = request.form['password']
    email = request.form['email']
    address = request.form['address']
    
    user = User(username=username, password=password, email=email, address=address)
    user.register()
    
    return jsonify({"status": "success", "message": "User registered successfully."})

@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    
    user = User(username=username, password=password)
    if user.login():
        return jsonify({"status": "success", "message": "Login successful."})
    else:
        return jsonify({"status": "error", "message": "Invalid username or password."})

@app.route('/add_product', methods=['POST'])
def add_product():
    name = request.form['name']
    price = float(request.form['price'])
    category = request.form['category']
    
    product = Product(name=name, price=price, category=category)
    product.add_product()
    
    return jsonify({"status": "success", "message": "Product added successfully."})

@app.route('/create_order', methods=['POST'])
def create_order():
    user_id = int(request.form['user_id'])
    product_id = int(request.form['product_id'])
    
    order = Order(user_id=user_id, product_id=product_id)
    order.create_order()
    
    return jsonify({"status": "success", "message": "Order created successfully."})

if __name__ == '__main__':
    init_db()
    app.run(debug=True)
```

- **用户注册**：通过`/register`接口接收用户信息，保存到数据库。
