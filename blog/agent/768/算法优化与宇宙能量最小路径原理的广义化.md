### 算法 1：Dijkstra 算法

#### 算法结构及步骤

Dijkstra 算法是一种经典的单源最短路径算法。它的基本思想是：从源点出发，逐步扩展到其他节点，每次扩展都选择未访问节点中距离源点最近的节点。具体步骤如下：

1. 初始化：设置源点到所有其他节点的距离为无穷大，源点到自身的距离为 0。将所有节点放入一个优先队列中，源节点优先级最高。
2. 扩展节点：从优先队列中取出优先级最高的节点，记为 \(u\)。
3. 更新邻居节点：对于 \(u\) 的每个邻居节点 \(v\)，计算 \(u\) 到 \(v\) 的距离 \(d(u, v)\)，如果 \(d(u, v) + w(u, v) < d(v)\)，则更新 \(d(v)\) 并将 \(v\) 加入优先队列。
4. 重复步骤 2 和 3，直到优先队列为空。

#### Python 代码示例

```python
import heapq

def dijkstra(graph, source):
    distances = {node: float('infinity') for node in graph}
    distances[source] = 0
    priority_queue = [(0, source)]

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)

        if current_distance > distances[current_node]:
            continue

        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight

            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

#### 数学模型及解释

Dijkstra 算法的数学模型可以用图 \(G = (V, E)\) 来表示，其中 \(V\) 是节点集合，\(E\) 是边集合。设 \(d(v)\) 为节点 \(v\) 到源点 \(s\) 的距离，初始时 \(d(s) = 0\)，\(d(v) = \infty\)（\(v \neq s\)）。算法的核心思想是不断更新 \(d(v)\)，使得每个节点最终都得到到源点的最短路径。

$$
d(v) = \min\{d(u) + w(u, v) | u \in N(v)\}
$$

其中，\(N(v)\) 表示节点 \(v\) 的邻居节点集合，\(w(u, v)\) 表示 \(u\) 到 \(v\) 的边权重。

#### 实例分析

假设我们有如下的图 \(G\)：

```
     1 -- (5) -- 3
    /            \
   0 -- (2) -- 4 -- (3)
```

使用 Dijkstra 算法计算从节点 0 到其他节点的最短路径：

1. 初始化：\(d(0) = 0\)，\(d(1) = \infty\)，\(d(2) = \infty\)，\(d(3) = \infty\)，\(d(4) = \infty\)。
2. 扩展节点 0：\(d(0) = 0\)，更新 \(d(1) = 5\)，\(d(2) = 2\)。
3. 扩展节点 1：\(d(1) = 5\)，更新 \(d(3) = 8\)。
4. 扩展节点 2：\(d(2) = 2\)，更新 \(d(3) = 5\)，\(d(4) = 5\)。
5. 扩展节点 3：\(d(3) = 5\)。
6. 扩展节点 4：\(d(4) = 5\)。

最终得到的最短路径为：

- \(d(1) = 5\)
- \(d(2) = 2\)
- \(d(3) = 5\)
- \(d(4) = 5\)

### 算法 2：A* 算法

#### 算法结构及步骤

A* 算法是一种启发式最短路径算法，它结合了 Dijkstra 算法的最优性原则和贪心算法的效率。A* 算法的核心思想是使用一个启发函数 \(h(n)\) 来估计从节点 \(n\) 到目标节点的距离，并通过 \(f(n) = g(n) + h(n)\) 来决定节点的优先级，其中 \(g(n)\) 是从源节点到节点 \(n\) 的实际距离。

A* 算法的主要步骤如下：

1. 初始化：设置源点到所有其他节点的距离为无穷大，源点到自身的距离为 0。将所有节点放入一个优先队列中，源节点优先级最高。
2. 扩展节点：从优先队列中取出优先级最高的节点，记为 \(n\)。
3. 更新邻居节点：对于 \(n\) 的每个邻居节点 \(m\)，计算 \(g(m) = g(n) + w(n, m)\)，并使用 \(h(m)\) 估计 \(f(m) = g(m) + h(m)\)。如果 \(f(m)\) 小于当前 \(m\) 的优先级，则更新 \(m\) 的优先级并将 \(m\) 加入优先队列。
4. 重复步骤 2 和 3，直到找到目标节点或优先队列为空。

$$
f(n) = g(n) + h(n)

其中，\(h(n)\) 需要满足单调递增条件，即 \(h(n) \leq d(n, goal)\)（\(d(n, goal)\) 表示从节点 \(n\) 到目标节点的实际距离）。
