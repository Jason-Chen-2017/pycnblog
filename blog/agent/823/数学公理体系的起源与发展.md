### 第1章：数学公理体系概述

**背景介绍**
数学公理体系是数学研究的基础，它由一组无需证明的基本假设（公理）组成，这些假设被广泛应用于各种数学理论和证明中。数学公理体系的建立为数学提供了严谨的逻辑基础，使得数学理论得以系统化、规范化。

**核心概念与联系**
数学公理体系的核心概念包括点、线、平面等基本几何概念，以及公理系统的逻辑结构。这些概念相互关联，构成了数学公理体系的基本框架。

### 第2章：古代数学公理体系的起源与发展

**背景介绍**
古代数学公理体系主要包括古希腊数学公理体系、古印度数学公理体系和古埃及数学公理体系。这些体系为后来的数学发展奠定了基础。

**核心概念与联系**
古希腊数学公理体系的核心是欧几里得的《几何原本》，它提出了一系列公理，这些公理构成了古希腊数学的基础。古印度数学公理体系则更注重数论和代数，其公理体系以梵文数学为基础。古埃及数学公理体系则以其独特的几何计算方法而闻名。

```python

def distance(p1, p2):
    return math.sqrt((p1[0] - p2[0])**2 + (p1[1] - p2[1])**2)

p1 = (0, 0)
p2 = (3, 4)
print(f"The distance between point {p1} and point {p2} is {distance(p1, p2)}")
```
