#### 数学模型和公式：

假设输入图像为 \( I(x, y) \)，经过预处理后得到增强图像 \( I'(x, y) \)。特征提取阶段使用卷积神经网络（CNN）模型，模型输出为 \( \hat{y} \)。

$$
\hat{y} = \text{CNN}(I'(x, y))
$$

#### 详细讲解和举例说明：

卷积神经网络（CNN）是一种广泛应用于计算机视觉的深度学习模型。其基本原理是通过多层卷积、池化和全连接层对图像进行特征提取和分类。以下是一个简单的例子：

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

# 创建CNN模型
model = Sequential([
    Conv2D(filters=32, kernel_size=(3, 3), activation='relu', input_shape=(28, 28, 1)),
    MaxPooling2D(pool_size=(2, 2)),
    Flatten(),
    Dense(units=128, activation='relu'),
    Dense(units=10, activation='softmax')
])

# 编译模型
model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])

# 训练模型
model.fit(x_train, y_train, epochs=10, batch_size=64)
```

在这个例子中，我们使用了TensorFlow框架创建了一个简单的CNN模型，该模型用于识别手写数字。输入图像是28x28的灰度图像，经过卷积层、池化层、全连接层后，输出10个类别（0-9）的概率分布。

    defect_type = np.argmax(prediction)
    return defect_type
