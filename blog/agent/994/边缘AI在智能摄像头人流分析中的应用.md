## 第1章：边缘AI概述

### 1.1 边缘AI的定义与特点

边缘AI，即边缘人工智能，是指将人工智能的计算和数据处理任务从云端转移到网络边缘，即在数据生成的地方进行处理。这种技术的主要目的是提高数据处理的速度和效率，减少数据传输的延迟，同时降低带宽消耗，确保数据安全和隐私。

**边缘AI的概念**

边缘AI的核心概念是将数据处理和计算从集中式的数据中心转移到靠近数据源的边缘设备。这些边缘设备可以是智能手机、路由器、智能摄像头、工业机器人等，它们可以在本地执行数据处理和分析任务，而不需要将数据上传到云端。

**边缘AI与传统云计算的区别**

与传统云计算相比，边缘AI有以下显著区别：

1. **计算位置**：传统云计算是在远程数据中心进行数据处理，而边缘AI是在数据生成的设备上进行数据处理。
2. **延迟**：边缘AI显著降低了数据传输的延迟，因为数据处理在本地进行，不需要跨越广域网。
3. **带宽**：边缘AI减少了数据传输的带宽需求，因为不需要将大量数据上传到云端。
4. **安全性**：边缘AI在本地处理数据，减少了数据泄露的风险。

**边缘AI的核心优势**

边缘AI的核心优势包括：

1. **实时性**：边缘AI可以实时处理数据，满足对实时性要求较高的应用需求。
2. **低延迟**：由于数据处理在本地进行，边缘AI显著降低了数据处理的延迟。
3. **节省带宽**：边缘AI减少了数据传输的带宽需求，降低了网络拥堵的风险。
4. **数据隐私保护**：边缘AI在本地处理数据，减少了数据泄露的风险，增强了数据安全性。

3. **人脸识别**：智能摄像头利用人脸识别算法，识别人脸图像，实现人脸识别功能。
