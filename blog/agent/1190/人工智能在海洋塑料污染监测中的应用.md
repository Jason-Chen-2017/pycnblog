    # 使用 OpenCV 库读取卫星图像和无人机图像

    # 对图像进行归一化处理

#### 2.1.3 算法原理的数学模型和公式

在海洋塑料污染监测中，常用的数学模型和公式包括：

1. **归一化公式：**

   $$\text{normalized\_image} = \frac{\text{image} - \text{min}}{\text{max} - \text{min}}$$

   其中，image 表示原始图像，normalized\_image 表示归一化后的图像，min 和 max 分别表示图像的最小值和最大值。

2. **特征提取公式：**

   $$\text{feature\_vector} = \text{extractFeature}(\text{image})$$

   其中，extractFeature 是一个提取图像特征的函数，可以采用不同的特征提取方法，如 LBP（局部二值模式）、HOG（方向梯度直方图）等。

3. **支持向量机（SVM）模型公式：**

   $$w = \arg\min_w \frac{1}{2}||w||^2 + C\sum_{i=1}^{n}\xi_i$$

   其中，w 表示权重向量，C 表示惩罚参数，ξi 表示第 i 个样本的误差。

4. **预测公式：**

   $$\hat{y} = \text{sign}(w \cdot x + b)$$

   其中，x 表示特征向量，y 表示标签，sign 表示符号函数。
