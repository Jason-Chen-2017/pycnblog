### 2.1 区块链技术架构

区块链技术架构是构建安全可靠区块链系统的基石。它由多个节点、数据块、链、加密算法等组成部分构成。以下是对这些核心组件的详细描述：

1. **节点**：节点是区块链网络的基本单位，每个节点都存储了一份完整的数据副本。节点可以是任何连接到区块链网络的计算机，包括矿工节点、普通节点和验证节点。矿工节点负责生成新的区块，普通节点负责存储和验证区块，验证节点负责对交易进行验证。

2. **数据块**：数据块是区块链的基本组成单元，每个数据块包含了若干条记录。数据块通常由区块头和区块体组成。区块头包含了区块的元数据，如版本号、时间戳、难度目标、前一个区块哈希等。区块体包含了交易记录和其他数据。

3. **链**：链是指由多个数据块连接而成的数据结构。每个区块都包含了一个指向前一个区块哈希的引用，从而形成了一个时间戳序列。区块链系统的安全性依赖于链的不可篡改性。

4. **加密算法**：加密算法是区块链系统的核心组成部分，用于保护区块链网络的数据安全和隐私。常见的加密算法包括哈希算法（如SHA-256）、椭圆曲线加密算法（如SECP256K1）等。加密算法确保了数据的完整性和安全性。

### 2.2 共识机制

共识机制是区块链网络中节点达成一致的方法。它决定了如何处理交易、生成新的区块以及确保区块链的稳定性。以下是几种常见的共识机制：

1. **工作量证明（PoW）**：PoW机制通过要求节点解决一个计算难题来生成新的区块。解决计算难题的过程称为挖矿。节点需要不断尝试，直到找到一个满足难度目标的解。PoW机制确保了区块链网络的去中心化和安全性，但同时也消耗大量计算资源。

2. **权益证明（PoS）**：PoS机制通过节点的权益（如持有的代币数量）来决定节点的挖矿权。节点持有的代币数量越多，其挖矿概率越高。PoS机制相对于PoW机制更节能，但可能会导致富者愈富的问题。

3. **委托权益证明（DPoS）**：DPoS机制通过选举出若干个代表节点来生成新的区块。代表节点按照一定的算法进行轮换，持有代币的节点可以投票支持自己信任的代表节点。DPoS机制具有较高的共识效率，但可能会出现中心化风险。

### 2.3 智能合约

智能合约是一种自动化执行合约条款的计算机程序。它运行在区块链网络上，确保了合约条款的执行和不可篡改性。智能合约通常使用特定的编程语言（如Solidity）编写，并在区块链上进行部署和执行。智能合约的运行受区块链网络的安全性和稳定性影响，因此其安全性至关重要。

### 2.4 加密算法

加密算法是区块链系统的核心组成部分，用于保护区块链网络的数据安全和隐私。常见的加密算法包括：

1. **哈希算法**：哈希算法将任意长度的数据映射为固定长度的哈希值。常见的哈希算法有SHA-256、SHA-3等。哈希算法确保了数据的完整性和不可篡改性。

2. **椭圆曲线加密算法**：椭圆曲线加密算法（如SECP256K1）用于生成公钥和私钥，确保区块链网络中的身份验证和数据加密。椭圆曲线加密算法具有较高的安全性和效率。

#### 3.1.1 哈希算法

哈希算法是一种将任意长度的数据映射为固定长度的哈希值的算法。哈希算法具有以下特点：

1. **单向性**：哈希算法是不可逆的，即无法从哈希值推导出原始数据。
2. **抗碰撞性**：不同的输入数据产生的哈希值是唯一的，几乎不可能出现两个不同的输入数据产生相同的哈希值。
3. **固定长度**：哈希值长度固定，常见的哈希算法如SHA-256的哈希值长度为256位。

#### 3.1.1 哈希算法

哈希算法是一种将任意长度的数据映射为固定长度的哈希值的算法。哈希算法具有以下特点：

1. **单向性**：哈希算法是不可逆的，即无法从哈希值推导出原始数据。
2. **抗碰撞性**：不同的输入数据产生的哈希值是唯一的，几乎不可能出现两个不同的输入数据产生相同的哈希值。
3. **固定长度**：哈希值长度固定，常见的哈希算法如SHA-256的哈希值长度为256位。

import hashlib

def sha256_hash(data):

        self.chain = []
        self.current_transactions = []

        # 创建创世区块
        self.new_block(previous_hash='1', proof=100)

    def new_block(self, proof, previous_hash=None):
        block = {
            'index': len(self.chain) + 1,
            'timestamp': time(),
            'transactions': self.current_transactions,
            'proof': proof,
            'previous_hash': previous_hash or self.hash(self.chain[-1]),
        }
        self.current_transactions = []
        self.chain.append(block)
        return block

    def new_transaction(self, sender, recipient, amount):
        self.current_transactions.append({'sender': sender, 'recipient': recipient, 'amount': amount})
        return self.last_block['index'] + 1

    @staticmethod
    def hash(block):
        block_string = json.dumps(block, sort_keys=True)
        return hashlib.sha256(block_string.encode()).hexdigest()

    @property
    def last_block(self):
        return self.chain[-1]

def proof_of_work(last_proof):
    proof = 0
    while not valid_proof(last_proof, proof):
        proof += 1
    return proof

    guess = f"{last_proof}{proof}".encode()
    guess_hash = hashlib.sha256(guess).hexdigest()
    return guess_hash[:4] == "0000"

from flask import Flask, jsonify, request
from uuid import uuid4

app = Flask(__name__)

blockchain = Blockchain()

class Blockchain:
    def __init__(self):
        self.chain = []
        self.current_transactions = []

        # 创建创世区块
        self.new_block(previous_hash='1', proof=100)

    def new_block(self, proof, previous_hash=None):
        block = {
            'index': len(self.chain) + 1,
            'timestamp': time(),
            'transactions': self.current_transactions,
            'proof': proof,
            'previous_hash': previous_hash or self.hash(self.chain[-1]),
        }
        self.current_transactions = []
        self.chain.append(block)
        return block

    def new_transaction(self, sender, recipient, amount):
        self.current_transactions.append({'sender': sender, 'recipient': recipient, 'amount': amount})
        return self.last_block['index'] + 1

    @staticmethod
    def hash(block):
        block_string = json.dumps(block, sort_keys=True)
        return hashlib.sha256(block_string.encode()).hexdigest()

    @property
    def last_block(self):
        return self.chain[-1]

def proof_of_work(last_proof):
    proof = 0
    while not valid_proof(last_proof, proof):
        proof += 1
    return proof

def valid_proof(last_proof, proof):
    guess = f"{last_proof}{proof}".encode()
    guess_hash = hashlib.sha256(guess).hexdigest()
    return guess_hash[:4] == "0000"

@app.route('/mine', methods=['GET'])
def mine():
    last_block = blockchain.last_block
    last_proof = last_block['proof']
    proof = proof_of_work(last_proof)

    blockchain.new_transaction(
        sender="0",
        recipient=request.args.get('recipient'),
        amount=request.args.get('amount')
    )

    block = blockchain.new_block(proof, last_block['previous_hash'])

    response = {
        'message': "New Block Forged",
        'index': block['index'],
        'transactions': block['transactions'],
        'proof': block['proof'],
        'previous_hash': block['previous_hash'],
    }
    return jsonify(response), 200

@app.route('/transactions/new', methods=['POST'])
def new_transaction():
    values = request.get_json()

    required = ['sender', 'recipient', 'amount']
    if not all(k in values for k in required):
        return 'Missing values', 400

    index = blockchain.new_transaction(values['sender'], values['recipient'], values['amount'])
    response = {'message': f'Transaction will be added to Block {index}'}
    return jsonify(response), 201

@app.route('/chain', methods=['GET'])
def full_chain():
    response = {
        'chain': blockchain.chain,
        'length': len(blockchain.chain),
    }
    return jsonify(response), 200

if __name__ == '__main__':

from Cryptodome.PublicKey import ECC
from Cryptodome.Signature import DSS
from Cryptodome.Random import get_random_bytes

def generate_key_pair():
    key = ECC.generate(curve='SECP256K1')
    return key

def sign_message(message, private_key):
    sign = DSS.new(private_key, 'fips-186-3')
    sign.update(message.encode())
    signature = sign.sign()
    return signature

def verify_signature(message, signature, public_key):
    sign = DSS.new(public_key, 'fips-186-3')
    sign.update(message.encode())
    is_valid = sign.verify(signature)
    return is_valid

# 生成密钥对
private_key = generate_key_pair()
public_key = private_key.public_key()

# 签名消息
message = "Hello, World!"
signature = sign_message(message, private_key)

# 验证签名
is_valid = verify_signature(message, signature, public_key)
print(is_valid)

import hashlib
import time

def pow_mining(difficulty):
    nonce = 0
    while True:
        hash_value = hashlib.sha256(f"{nonce}".encode()).hexdigest()
        if hash_value[:difficulty] == "0" * difficulty:
            return nonce
        nonce += 1
        time.sleep(0.01)

difficulty = 4
solution = pow_mining(difficulty)
print(f"Solution found: {solution}")
