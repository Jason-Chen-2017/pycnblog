#### 2.6.1 谜题生成算法

谜题生成算法是城市密室逃脱游戏设计中的一个重要环节，它决定了谜题的难度和趣味性。以下是一个简单的谜题生成算法示例：

**Python源代码示例：**

```python
import random

def generate_riddle(answer):
    options = []
    for _ in range(3):
        option = random.randint(1, 100)
        while option == answer:
            option = random.randint(1, 100)
        options.append(option)
    options.append(answer)
    random.shuffle(options)
    return f"What is {answer}? (Options: {options})"

answer = random.randint(1, 100)
print(generate_riddle(answer))
```

**算法原理：**
- 生成一个随机数字作为谜题的答案。
- 生成三个随机选项，其中一个为正确答案，其他两个为错误答案。
- 将答案和选项混合，随机排列，形成最终的谜题。

#### 2.6.2 谜题难度调整算法

谜题难度调整算法可以根据玩家的回答正确率动态调整谜题的难度。以下是一个简单的难度调整算法示例：

C --> E[更新谜题难度]

**Python源代码示例：**

```python
class RiddleGame:
    def __init__(self):
        self.difficulty = 1

    def ask_riddle(self):
        if self.difficulty == 1:
            return "What is 2 + 2?"
        elif self.difficulty == 2:
            return "What is 5 * 7?"
        else:
            return "What is the square root of 144?"

    def check_answer(self, answer):
        correct_answer = {
            "What is 2 + 2?": 4,
            "What is 5 * 7?": 35,
            "What is the square root of 144?": 12,
        }
        if answer == correct_answer[self.ask_riddle()]:
            self.difficulty += 1
            return True
        else:
            self.difficulty -= 1
            return False

game = RiddleGame()
for _ in range(5):
    print(game.ask_riddle())
    user_answer = int(input("Your answer: "))
    if game.check_answer(user_answer):
        print("Correct!")
    else:
        print("Incorrect.")
```

**算法原理：**
- 初始化谜题难度。
- 根据玩家的回答正确与否动态调整难度。如果玩家连续多次回答正确，难度增加；如果玩家连续多次回答错误，难度降低。
- 通过更新谜题难度，保持谜题的挑战性和趣味性。
