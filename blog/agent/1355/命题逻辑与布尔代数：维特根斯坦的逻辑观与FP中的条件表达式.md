#### 合取（AND）

#### 析取（OR）

析取运算表示两个命题中至少有一个为真。用符号“∨”表示。例如，P ∨ Q 表示P和Q中至少有一个为真。

## 布尔代数基础

### 1. 布尔代数的基本概念

布尔代数是一种以布尔值（真或假）为基础的代数系统。它由三个基本元素组成：变量、运算和恒等式。

#### 变量

布尔变量是表示布尔值的基本元素，通常用大写字母表示，如A、B、C等。布尔变量只能取两个值：真（T）和假（F）。

#### 运算

布尔运算用于操作布尔变量，产生新的布尔值。布尔运算包括：

- **合取（AND）**：表示两个布尔变量的逻辑与，结果为真当且仅当两个布尔变量都为真。用符号“·”或“∧”表示。例如，A · B 或 A ∧ B 表示A和B的逻辑与。
- **析取（OR）**：表示两个布尔变量的逻辑或，结果为真当且仅当至少有一个布尔变量为真。用符号“+”或“∨”表示。例如，A + B 或 A ∨ B 表示A和B的逻辑或。
- **非（NOT）**：表示一个布尔变量的取反，结果为真当且仅当布尔变量为假。用符号“﹁”或“¬”表示。例如，﹁A 或 ¬A 表示A的逻辑非。

#### 恒等式

布尔代数中的恒等式是用于简化布尔表达式的规则。常见的恒等式包括：

- **恒等律**：A · T = A；A + F = A
- **反演律**：A · F = F；A + T = T
- **分配律**：A · (B + C) = (A · B) + (A · C)；A + (B · C) = (A + B) · (A + C)
- **结合律**：A · (B · C) = (A · B) · C；A + (B + C) = A + (B · C)
- **德摩根律**：(A · B) = (﹁A + ﹁B)；(A + B) = (﹁A · ﹁B)

### FP中的条件表达式

### 1. 条件表达式的概念

条件表达式是一种根据条件选择执行不同操作的编程结构。在函数式编程（FP）中，条件表达式通常用if-then-else结构表示。条件表达式的基本形式如下：

```haskell
if 条件 then 表达式1 else 表达式2
```

条件表达式根据条件的真假来选择执行表达式1或表达式2。如果条件为真，则执行表达式1，否则执行表达式2。

### 2. 条件表达式的分类

条件表达式可以根据条件的形式和执行策略进行分类。常见的分类方法包括以下几种：

#### 简单条件

简单条件表达式的条件通常是一个布尔值，根据布尔值的真假来选择执行不同的操作。例如：

```haskell
if x > 0 then print (x * 2) else print (x * -2)
```

#### 复合条件

复合条件表达式使用逻辑运算符（如AND、OR、NOT）来组合多个简单条件。例如：

```haskell
if (x > 0 && y > 0) then print (x + y) else print (x * y)
```

#### 多重条件

多重条件表达式使用多个if-then-else结构来处理多个条件。例如：

```haskell
if x > 0 then
  if y > 0 then print (x + y) else print (x * y)
else
  if y < 0 then print (x - y) else print (x / y)
```

### 3. 条件表达式的应用

条件表达式在FP编程中有着广泛的应用，如下所述：

#### 输入验证

条件表达式常用于验证输入参数的有效性。例如，检查输入的数值是否在指定范围内，或者字符串是否为空。

```haskell
isValidInput :: String -> Bool
isValidInput input =
  if length input > 0 then
    True
  else
    False
```

#### 流程控制

条件表达式可以用于控制程序的流程。例如，根据不同的条件选择执行不同的函数或操作。

```haskell
process :: Int -> String
process x =
  if x > 0 then
    "Positive"
  else if x < 0 then
    "Negative"
  else
    "Zero"
```

#### 错误处理

条件表达式可以用于处理程序中的错误。例如，当遇到无法处理的错误时，选择执行特定的错误处理逻辑。

```haskell
handleError :: Exception -> String
handleError e =
  if is egregious e then
    "Error: Critical Failure"
  else
    "Error: Minor Issue"
```

#### 条件表达式的优化

在FP编程中，条件表达式可以通过模式匹配和不可变数据结构进行优化。例如，使用模式匹配可以消除冗余的条件判断，提高代码的可读性和性能。

```haskell
process' :: Int -> String
process' x =
  case x of
    x | x > 0 -> "Positive"
      | x < 0 -> "Negative"
      | otherwise -> "Zero"
```

### 4. 条件表达式的优缺点
