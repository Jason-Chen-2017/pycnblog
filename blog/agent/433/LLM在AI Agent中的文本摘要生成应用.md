- **参数规模与计算能力**：大规模参数使LLM能够捕捉到复杂的语言规律，从而在语言理解任务中表现出色。此外，随着计算能力的提升，LLM的参数规模也在不断增长，这使得LLM在处理大规模数据时具有更高的效率。

- **编码器输出**：设输入文本为\[x_1, x_2, ..., x_n\]，编码器输出为\[h_1, h_2, ..., h_n\]。其中，\[h_i\]表示文本中第\[i\]个词的编码表示。

- **解码器输出**：解码器接收编码器的输出\[h_1, h_2, ..., h_n\]，并生成文本摘要\[y_1, y_2, ..., y_m\]。其中，\[y_i\]表示生成的摘要中第\[i\]个词。

  $$ h_i = \text{Encoder}(x_i) $$

  $$ y_i = \text{Decoder}(h_i) $$
