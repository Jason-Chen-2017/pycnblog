```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint

def model(y, t):
    # 模型参数
    a = 0.1
    b = 0.2
    c = 0.3
    d = 0.4

    # 状态变量
    N = y[0]
    M = y[1]

    # 时间变量
    dt = 0.01

    # 方程组
    dNdt = a * N - b * N * M
    dMdt = c * N * M - d * M

    return [dNdt, dMdt]

# 初始条件
y0 = [100, 0]

# 时间序列
t = np.arange(0, 100, 0.01)

# 解方程
result = odeint(model, y0, t)

# 绘图
plt.plot(t, result[:, 0], label='N(t)')
plt.plot(t, result[:, 1], label='M(t)')
plt.xlabel('Time')
plt.ylabel('Population')
plt.legend()
plt.show()
```

#### 8.3.1 定义数学模型

我们选择Lotka-Volterra模型，这是一个经典的捕食者-被捕食者模型，描述了两个种群之间的相互作用。模型的数学表达式如下：

\[ \frac{dx}{dt} = x(\alpha - \beta y) \]
\[ \frac{dy}{dt} = y(\gamma - \delta x) \]

其中，\( x(t) \) 表示猎物的数量，\( y(t) \) 表示捕食者的数量，\( \alpha \) 是猎物的自然增长率，\( \beta \) 是捕食者对猎物的捕食率，\( \gamma \) 是捕食者的自然增长率，\( \delta \) 是捕食者的死亡率。

我们将使用以下参数值：

- \( \alpha = 1 \)
- \( \beta = 0.1 \)
- \( \gamma = 0.2 \)
- \( \delta = 0.3 \)

#### 8.3.2 编写Python代码

我们将使用Python编写一个脚本，定义模型并求解ODE。以下是实现步骤：

1. **导入库**：

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt
```

2. **定义模型**：

```python
def model(y, t):
    x, y = y
    alpha = 1
    beta = 0.1
    gamma = 0.2
    delta = 0.3
    dxdt = x * (alpha - beta * y)
    dydt = y * (gamma - delta * x)
    return [dxdt, dydt]
```

3. **初始化参数和初始条件**：

```python
t = np.linspace(0, 100, 1000)
x0 = 10  # 初始猎物数量
y0 = 1   # 初始捕食者数量
y0 = [x0, y0]
```

4. **求解ODE**：

```python
result = odeint(model, y0, t)
```

5. **绘制结果**：

```python
plt.figure(figsize=(10, 5))
plt.plot(t, result[:, 0], label='Prey (x)')
plt.plot(t, result[:, 1], label='Predator (y)')

plt.ylabel('Population')
plt.title('Lotka-Volterra Model')
plt.legend()
plt.show()
```
