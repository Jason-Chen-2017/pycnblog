   例如，最小化损失的目标函数可以表示为：
   \[
   \min Z = \sum_{i=1}^{n} \sum_{j=1}^{m} c_{ij} x_{ij}
   \]
   其中，\(c_{ij}\) 表示从资源 \(i\) 分配到任务 \(j\) 的成本，\(x_{ij}\) 是一个二进制变量，如果资源 \(i\) 分配到任务 \(j\)，则 \(x_{ij} = 1\)，否则为 0。

2. **确定约束条件**：根据实际情况，列出各种约束条件，如资源限制、时间限制、人员限制等。约束条件通常以不等式或等式的形式表示。

   \[
   \sum_{j=1}^{m} x_{ij} \leq R_i
   \]
   其中，\(R_i\) 是资源 \(i\) 的可用总量。

3. **建立模型**：将目标函数和约束条件结合起来，形成完整的数学优化模型。

   例如，一个简单的线性规划模型可以表示为：
   \[
   \min Z = \sum_{i=1}^{n} \sum_{j=1}^{m} c_{ij} x_{ij}
   \]
   subject to
   \[
   \sum_{j=1}^{m} x_{ij} \leq R_i, \quad \forall i=1,2,\ldots,n
   \]
   \[
   x_{ij} \in \{0,1\}, \quad \forall i=1,2,\ldots,n \quad \forall j=1,2,\ldots,m
   \]

4. **求解模型**：利用数学优化算法求解模型，得到最优解。

#### 5.1.2 经典优化算法介绍

以下是几种经典优化算法的介绍，包括线性规划、非线性规划、动态规划和遗传算法。

1. **线性规划（Linear Programming，LP）**

线性规划是最简单的优化算法，适用于目标函数和约束条件均为线性情况的问题。其基本形式如下：

\[ \min Z = \sum_{i=1}^{n} c_i x_i \]
\[ subject \ to \]
\[ a_{ij} x_j + b_j = c_i, \quad \forall i=1,2,\ldots,n \]
\[ x_i \in [0,1], \quad \forall i=1,2,\ldots,n \]

- **求解方法**：单纯形法、内点法。
- **适用场景**：资源分配、调度问题。

2. **非线性规划（Nonlinear Programming，NLP）**

非线性规划适用于目标函数或约束条件中有非线性元素的问题。其基本形式如下：

\[ \min Z = f(x) \]
\[ subject \ to \]
\[ g_i(x) \leq 0, \quad \forall i=1,2,\ldots,m \]
\[ h_i(x) = 0, \quad \forall i=1,2,\ldots,m \]

- **求解方法**：梯度下降法、牛顿法、序列二次规划法。
- **适用场景**：损失函数优化、约束条件复杂的优化问题。

3. **动态规划（Dynamic Programming，DP）**

动态规划适用于具有时间序列特征的问题，如多阶段决策问题。其基本形式如下：

\[ \min Z = \sum_{t=1}^{T} f(x_t) \]
\[ subject \ to \]
\[ g(x_t, x_{t+1}) \leq 0, \quad \forall t=1,2,\ldots,T-1 \]

- **求解方法**：逆向递推、正向递推。
- **适用场景**：多阶段决策问题、路径规划问题。

4. **遗传算法（Genetic Algorithm，GA）**

遗传算法是一种基于生物进化的优化算法，适用于复杂、非线性、多峰值的优化问题。其基本形式如下：

\[ \min Z = \sum_{i=1}^{n} f(x_i) \]
\[ subject \ to \]
\[ g_i(x_i) \leq 0, \quad \forall i=1,2,\ldots,m \]

- **求解方法**：选择、交叉、变异。
- **适用场景**：复杂路径规划、多目标优化问题。

### 第2章：数学优化方法简介

#### 2.1.1 优化问题的基本概念

优化问题是指在一定约束条件下，寻找一个或多个最优解的过程。优化问题通常由目标函数和约束条件组成。目标函数是一个需要优化的数学表达式，可以是最大值或最小值。约束条件则限制了决策变量的取值范围，确保问题的解是实际可行的。

优化问题可以分为以下几类：

- **无约束优化**：目标函数和约束条件都不存在。
- **单约束优化**：存在一个约束条件。
- **多约束优化**：存在多个约束条件。

优化问题的求解方法分为两大类：解析方法和数值方法。

- **解析方法**：通过解析推导，找到最优解的表达式。这种方法通常适用于目标函数和约束条件较为简单的优化问题。
- **数值方法**：通过迭代计算，逐步逼近最优解。这种方法适用于目标函数和约束条件复杂的优化问题。

#### 2.1.2 常见的数学优化算法

数学优化算法是一种求解优化问题的方法，根据算法的特点和应用场景，可以分为以下几类：

1. **线性规划（Linear Programming，LP）**
   - 线性规划是最简单的优化算法，适用于目标函数和约束条件均为线性的问题。
   - **常见算法**：单纯形法、内点法。
   - **应用场景**：资源分配、调度问题。

2. **非线性规划（Nonlinear Programming，NLP）**
   - 非线性规划适用于目标函数或约束条件中有非线性元素的问题。
   - **常见算法**：梯度下降法、牛顿法、序列二次规划法。
   - **应用场景**：损失函数优化、约束条件复杂的优化问题。

3. **动态规划（Dynamic Programming，DP）**
   - 动态规划适用于具有时间序列特征的问题，如多阶段决策问题。
   - **常见算法**：逆向递推、正向递推。
   - **应用场景**：多阶段决策问题、路径规划问题。

#### 5.1.1 算法选择与评估

在灾害响应中，选择合适的数学优化算法至关重要。不同的优化算法适用于不同类型的问题，且在计算复杂度、收敛速度和可扩展性等方面存在差异。以下是一些常见优化算法及其选择和评估方法：

1. **线性规划（Linear Programming, LP）**
   - **选择标准**：适用于目标函数和约束条件均为线性的问题，求解速度快，结果稳定。
   - **评估方法**：通过求解时间、求解精度和稳定性来评估。

   - **选择标准**：适用于目标函数或约束条件中有非线性元素的问题，需要考虑函数的连续性和可微性。
   - **评估方法**：通过收敛速度、求解精度和稳定性来评估。
   - **适用场景**：损失函数优化、复杂约束条件问题。

3. **动态规划（Dynamic Programming, DP）**
   - **选择标准**：适用于具有时间序列特征的问题，如多阶段决策问题。
   - **评估方法**：通过求解时间、存储空间和结果的有效性来评估。
   - **适用场景**：多阶段决策问题、路径规划问题。

4. **遗传算法（Genetic Algorithm, GA）**
   - **选择标准**：适用于复杂、非线性、多峰值的优化问题，具有全局搜索能力。
   - **评估方法**：通过适应度函数值、收敛速度和解的稳定性来评估。
   - **适用场景**：复杂路径规划、多目标优化问题。

5. **模拟退火算法（Simulated Annealing, SA）**
   - **选择标准**：适用于复杂、非线性、多峰值的优化问题，能够跳出局部最优。
   - **评估方法**：通过适应度函数值、收敛速度和稳定性来评估。
   - **适用场景**：组合优化、调度问题。

#### 5.1.2 经典优化算法介绍

以下介绍几种经典优化算法，包括线性规划、非线性规划、动态规划和遗传算法。

1. **线性规划（Linear Programming, LP）**

线性规划是优化算法中最简单的一种，适用于目标函数和约束条件均为线性情况。

- **目标函数**：\( \min Z = c^T x \)
- **约束条件**：\( Ax \leq b \) 或 \( Ax = b \)

其中，\( x \) 是决策变量，\( c \) 是目标函数系数向量，\( A \) 和 \( b \) 分别是约束条件的系数矩阵和常数向量。

- **求解方法**：单纯形法（Simplex Method）、内点法（Interior Point Method）。

2. **非线性规划（Nonlinear Programming, NLP）**

非线性规划适用于目标函数或约束条件中有非线性元素的情况。

- **目标函数**：\( \min f(x) \)
- **约束条件**：\( g_i(x) \leq 0 \) 或 \( h_i(x) = 0 \)

其中，\( f(x) \) 是目标函数，\( g_i(x) \) 和 \( h_i(x) \) 分别是非线性约束条件。

- **求解方法**：梯度下降法（Gradient Descent）、牛顿法（Newton's Method）、序列二次规划法（Sequential Quadratic Programming, SQP）。

3. **动态规划（Dynamic Programming, DP）**

动态规划适用于具有时间序列特征的问题，通过递推关系求解最优解。

- **状态变量**：\( s_t \)
- **决策变量**：\( a_t \)
- **目标函数**：\( V(s_t) = \min \{ f(s_t, a_t) + V(s_{t+1}) \} \)

其中，\( s_t \) 是状态变量，\( a_t \) 是决策变量，\( f(s_t, a_t) \) 是状态-决策函数，\( V(s_t) \) 是状态值函数。

- **求解方法**：逆向递推（Backward Induction）、正向递推（Forward Induction）。

4. **遗传算法（Genetic Algorithm, GA）**

遗传算法是一种基于自然进化的优化算法，适用于复杂、非线性、多峰值的优化问题。

- **个体编码**：使用二进制编码或实数编码表示决策变量。
- **适应度函数**：\( f(x) \)

- **遗传操作**：
  - **选择**：选择适应度值较高的个体进行交叉和变异。
  - **交叉**：交换两个个体的部分基因，产生新的个体。
  - **变异**：对个体进行随机变异，增加种群的多样性。
