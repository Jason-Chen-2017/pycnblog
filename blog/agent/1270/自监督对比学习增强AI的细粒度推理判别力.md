#### 3.1.2 数学模型

自监督对比学习的核心是对比损失函数，以下是常用的对比损失函数及其数学模型：

1. **信息性损失（InfoNCE）**

信息性损失函数是自监督对比学习中常用的损失函数，其数学模型如下：

$$
L(\theta) = -\sum_{i=1}^{N} \sum_{j=1, j\neq i}^{N} \frac{z_i \cdot z_j^T}{\epsilon} \cdot \log \frac{e^{z_i \cdot z_j^T}}{\sum_{k=1, k\neq i}^{N} e^{z_i \cdot z_k^T}}
$$

其中，$z_i$和$z_j$分别是编码器对正样本对和负样本对编码后的特征向量，$\epsilon$是温度参数，用于调节相似度的计算。

2. **三元组损失（Triplet Loss）**

三元组损失函数主要用于图像分类任务，其数学模型如下：

$$
L(\theta) = \sum_{i=1}^{N} \sum_{j=1, j\neq i}^{N} \max(0, d(z_i, z_j) - d(z_i, z^+) + \alpha)
$$

其中，$z_i$和$z_j$分别是编码器对正样本对和负样本对编码后的特征向量，$z^+$是正样本的编码特征向量，$d(\cdot, \cdot)$表示特征向量之间的距离，$\alpha$是调节参数。

tf.random.set_seed(42)

# 定义编码器模型
def encoder_model(input_shape):
    model = tf.keras.Sequential([
        tf.keras.layers.InputLayer(input_shape=input_shape),
        tf.keras.layers.Conv2D(filters=32, kernel_size=(3, 3), activation='relu'),
        tf.keras.layers.MaxPooling2D(pool_size=(2, 2)),
        tf.keras.layers.Flatten()
    ])
    return model

# 定义对比损失函数
def contrastive_loss(z_i, z_j, z_pos, epsilon=0.07, temperature=0.5):
    logits = z_i @ z_j.T / temperature
    logits_pos = z_i @ z_pos.T / temperature
    log_probs = tf.nn.softmax(logits)
    log_probs_pos = tf.nn.softmax(logits_pos)
    loss = -tf.reduce_sum(log_probs * tf.math.log(log_probs_pos + epsilon))
    return loss

# 构造数据集
N = 1000  # 数据集大小
z_i = np.random.normal(size=(N, 100))  # 编码器对正样本的编码特征
z_j = np.random.normal(size=(N, 100))  # 编码器对负样本的编码特征
z_pos = np.random.normal(size=(N, 100))  # 正样本的编码特征

# 训练模型
model = encoder_model(input_shape=(28, 28, 1))
model.compile(optimizer='adam', loss=contrastive_loss(z_i, z_j, z_pos))

# 生成正样本对和负样本对
pos_pairs = np.random.choice(N, size=N, replace=False)
neg_pairs = np.random.choice(N, size=N, replace=False)

# 训练模型
model.fit(x=pos_pairs, y=np.zeros(N), batch_size=32, epochs=10)

# 打印训练结果
print(model.evaluate(x=neg_pairs, y=np.ones(N), batch_size=32))
