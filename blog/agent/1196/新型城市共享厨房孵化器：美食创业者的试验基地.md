class ResourceAllocator:
    def __init__(self, capacity):
        self.capacity = capacity
        self.resources = {resource: 0 for resource in capacity}

    def collect_demand(self, demand):
        for resource, quantity in demand.items():
            if resource not in self.capacity or quantity > self.resources[resource]:
                return False
        return True

    def calculate_capacity(self, demand):
        return {resource: self.capacity[resource] - demand.get(resource, 0) for resource in self.capacity}

    def allocate_resources(self, demand):
        if not self.collect_demand(demand):
            return False
        for resource, quantity in demand.items():
            self.resources[resource] += quantity
        return True

    def validate_result(self):
        return all(resource <= self.capacity[resource] for resource in self.capacity)

# 初始化资源分配器
allocator = ResourceAllocator(capacity={'kitchen': 100, 'fridge': 50, 'cooking_equipment': 20})

# 收集需求
demand = {'kitchen': 70, 'fridge': 40, 'cooking_equipment': 15}

# 资源分配
if allocator.allocate_resources(demand):
    print("Resources allocated successfully!")
else:
    print("Resource allocation failed!")

# 验证结果
if allocator.validate_result():
    print("Resource allocation is valid.")
else:
    print("Resource allocation is invalid.")

##### 数学模型和数学公式

资源分配算法的数学模型主要涉及以下几个关键参数：

- \( R \)：资源集合，如 \( R = \{kitchen, fridge, cooking_equipment\} \)
- \( C \)：每个资源的容量，如 \( C = \{kitchen: 100, fridge: 50, cooking_equipment: 20\} \)
- \( D \)：需求集合，如 \( D = \{kitchen: 70, fridge: 40, cooking_equipment: 15\} \)

资源分配的目标是找到一个最优解，使得每个资源的使用量不超过其容量。这可以用以下数学模型表示：

$$
\text{Minimize} \quad \sum_{r \in R} (C_r - D_r)
$$

其中，\( C_r \) 表示资源 \( r \) 的容量，\( D_r \) 表示资源 \( r \) 的需求量。
