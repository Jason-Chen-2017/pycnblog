## 2. 核心概念与联系

### 2.1 几何建模

几何建模是数学建模在游戏引擎物理系统中的应用基础。通过几何建模，可以精确地描述游戏中的各种几何对象，如角色、环境等。几何建模的核心概念包括点、线、面等，它们之间通过拓扑关系相互关联。

#### 点

点是最基本的几何对象，用于表示空间中的一个位置。点的主要属性包括坐标、半径等。

```latex
点 P(x, y, z)
坐标：(x, y, z)
半径：r
```

#### 线

线是连接两个点的几何对象，用于表示空间中的一条直线。线的主要属性包括起点、终点、长度等。

```latex
线 L(P1, P2)
起点：P1(x1, y1, z1)
终点：P2(x2, y2, z2)
长度：L = \sqrt{(x2 - x1)^2 + (y2 - y1)^2 + (z2 - z1)^2}
```

#### 面

面是连接多个点的几何对象，用于表示空间中的一个平面。面主要属性包括顶点、法线、面积等。

```latex
面 S(P1, P2, P3)
顶点：P1(x1, y1, z1)，P2(x2, y2, z2)，P3(x3, y3, z3)
法线：N = (A, B, C)
面积：S = \frac{1}{2} \cdot |(P2 - P1) \times (P3 - P1)|
```

### 2.2 物理建模

物理建模用于描述物体的物理属性，如质量、惯性矩等。物理建模的核心概念包括质量、动量、能量等。这些概念与几何建模密切相关，通过几何建模确定物体的形状，再通过物理建模确定物体的物理属性。

#### 质量

质量是物体惯性的度量，用于描述物体的重量。质量的主要属性包括质量值、分布等。

```latex
质量 m
质量分布：m(x, y, z)
```

#### 动量

动量是物体运动状态的度量，用于描述物体在空间中的运动。动量的主要属性包括动量值、方向等。

```latex
动量 p = m \cdot v
动量值：p
方向：v
```

#### 能量

能量是物体运动的潜力度量，用于描述物体的动能和势能。能量的主要属性包括能量值、类型等。

```latex
能量 E
能量类型：动能、势能
动能：K = \frac{1}{2} \cdot m \cdot v^2
势能：U = m \cdot g \cdot h
```

### 2.3 动力学建模

动力学建模用于描述物体的运动规律，如刚体运动、流体运动等。动力学建模的核心概念包括牛顿运动定律、流体动力学方程等。这些概念用于描述物体在外力作用下的运动，是物理系统模拟的关键。

#### 牛顿运动定律

牛顿运动定律是描述物体运动的基本定律，包括运动第一定律、第二定律和第三定律。

```latex
运动第一定律：物体在没有受到外力作用时，保持静止或匀速直线运动。
运动第二定律：物体的加速度与所受外力成正比，与物体质量成反比。
运动第三定律：作用力与反作用力大小相等、方向相反。
```

#### 流体动力学方程

流体动力学方程是描述流体运动的基本方程，包括连续性方程、动量方程和能量方程。

```latex
连续性方程：\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{v}) = 0
动量方程：\rho \frac{\partial \mathbf{v}}{\partial t} + \mathbf{v} \cdot \nabla \rho + \rho \nabla \cdot \mathbf{v} = -\nabla p + \mu \nabla^2 \mathbf{v}
能量方程：\rho c_p \frac{\partial T}{\partial t} + \mathbf{v} \cdot \nabla T + c_v \nabla \cdot (\mathbf{v} T) = \nabla \cdot (\kappa \nabla T) + \mu \nabla^2 T
```

### 2.4 随机过程建模

随机过程建模用于描述随机事件，如粒子碰撞、流体湍流等。随机过程建模的核心概念包括概率分布、随机变量等。这些概念用于模拟不确定性事件，增强物理系统模拟的真实性。

#### 概率分布

概率分布是描述随机变量取值的概率分布情况。常见的概率分布包括正态分布、泊松分布等。

```latex
正态分布：N(\mu, \sigma^2)
概率密度函数：f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
泊松分布：P(\lambda)
概率质量函数：p(k) = \frac{e^{-\lambda} \lambda^k}{k!}
```

#### 随机变量

随机变量是描述随机事件结果的变量。随机变量的取值服从某种概率分布。

```latex
随机变量 X
概率分布：P(X = x)
取值：x
```

## 3. 算法原理讲解

### 3.1 碰撞检测算法

碰撞检测是游戏引擎物理系统中的一个重要环节。常用的碰撞检测算法包括分离轴定理（SAT）、Bresenham算法等。

#### 分离轴定理（SAT）

分离轴定理是一种基于几何原理的碰撞检测算法。其基本思想是：如果两个物体在某一轴上的投影不重叠，那么它们在这个轴上的实际碰撞也不可能发生。

以下是分离轴定理的Mermaid流程图：

```mermaid
graph TD
A[初始化] --> B[选择测试轴]
B -->|轴a的间距小于阈值| C[判断相交]
B -->|轴a的间距大于阈值| D[选择下一个测试轴]
C -->|相交| E[记录碰撞点]
C -->|不相交| D
E --> F[结束]
```

以下是Python代码实现：

```python
import numpy as np

def separate_axis_theorem(A, B):
    minA = np.min(A, axis=0)
    maxA = np.max(A, axis=0)
    minB = np.min(B, axis=0)
    maxB = np.max(B, axis=0)

    for i in range(3):
        if maxA[i] < minB[i] or maxB[i] < minA[i]:
            return False
    return True
```

#### Bresenham算法

Bresenham算法是一种基于数值计算的碰撞检测算法。其基本思想是：通过计算两个物体之间的距离，判断是否小于某一阈值，从而判断是否发生碰撞。

以下是Bresenham算法的Mermaid流程图：

```mermaid
graph TD
A[初始化] --> B[计算两点距离]
B -->|距离小于阈值| C[判断相交]
B -->|距离大于阈值| D[继续计算下一个点]
C -->|相交| E[记录碰撞点]
C -->|不相交| D
E --> F[结束]
```

以下是Python代码实现：

```python
import numpy as np

def bresenham(A, B, threshold):
    distance = np.linalg.norm(A - B)
    if distance < threshold:
        return True
    return False
```

### 3.2 刚体运动模拟算法

刚体运动模拟算法主要包括刚体动力学方程的求解。刚体动力学方程描述了物体在外力作用下的运动规律。

#### 刚体动力学方程

刚体动力学方程可以表示为：

```latex
m \mathbf{a} = \mathbf{F}
```

其中，$m$表示物体的质量，$\mathbf{a}$表示物体的加速度，$\mathbf{F}$表示作用在物体上的合外力。

#### 牛顿-欧拉方法

牛顿-欧拉方法是一种求解刚体动力学方程的数值方法。其基本思想是：通过迭代计算，逐步逼近物体的加速度、速度和位置。

以下是牛顿-欧拉方法的Mermaid流程图：

```mermaid
graph TD
A[初始化] --> B[计算加速度]
B --> C[更新速度]
C --> D[更新位置]
D --> E[结束]
```

以下是Python代码实现：

```python
import numpy as np

def newton_euler(mass, force, dt):
    acceleration = force / mass
    velocity = acceleration * dt
    position = velocity * dt
    return acceleration, velocity, position
```

### 3.3 流体模拟算法

流体模拟算法主要包括流体动力学方程的求解。流体动力学方程描述了流体的运动规律。

#### 流体动力学方程

流体动力学方程可以表示为：

```latex
\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{v}) = 0
\rho \frac{\partial \mathbf{v}}{\partial t} + \mathbf{v} \cdot \nabla \rho + \rho \nabla \cdot \mathbf{v} = -\nabla p + \mu \nabla^2 \mathbf{v}
\rho c_p \frac{\partial T}{\partial t} + \mathbf{v} \cdot \nabla T + c_v \nabla \cdot (\mathbf{v} T) = \nabla \cdot (\kappa \nabla T) + \mu \nabla^2 T
```

#### 算法实现

以下是流体模拟算法的Python代码实现：

```python
import numpy as np

def fluid_simulation(rho, v, p, T, dt):
    # 计算质量守恒方程的更新项
    rho_diff = np.diff(rho, axis=0) / dt
    v_diff = np.diff(v, axis=0) / dt
    
    # 计算动量守恒方程的更新项
    v_diff_rho = v_diff * rho
    p_diff = np.diff(p, axis=0) / dt
    
    # 计算能量守恒方程的更新项
    T_diff = np.diff(T, axis=0) / dt
    
    # 更新流体状态
    rho = rho - rho_diff
    v = v - v_diff_rho
    p = p - p_diff
    T = T - T_diff
    
    return rho, v, p, T
```

### 3.4 粒子系统模拟算法

粒子系统模拟算法主要用于模拟各种物理效果，如爆炸、火焰、烟雾等。粒子系统模拟算法主要包括粒子生成、粒子更新和粒子销毁等步骤。

#### 粒子系统模拟流程

以下是粒子系统模拟的Mermaid流程图：

```mermaid
graph TD
A[初始化] --> B[生成粒子]
B --> C[更新粒子]
C --> D[判断粒子是否存在]
D -->|是| E[继续更新]
D -->|否| F[销毁粒子]
E --> C
F --> G[结束]
```

以下是Python代码实现：

```python
import numpy as np

def particle_systemsimulation(num_particles, dt):
    # 初始化粒子状态
    positions = np.random.uniform(low=-1, high=1, size=(num_particles, 3))
    velocities = np.random.uniform(low=-1, high=1, size=(num_particles, 3))
    exists = np.ones(num_particles, dtype=bool)

    while True:
        # 更新粒子状态
        positions = positions + velocities * dt
        velocities = velocities * 0.99  # 粒子速度衰减

        # 判断粒子是否存在
        if np.any(positions < 0) or np.any(positions > 1):
            exists = np.where(np.any(positions < 0) | np.any(positions > 1), False, exists)

        # 销毁粒子
        if np.any(~exists):
            num_particles = num_particles - np.sum(~exists)
            positions = positions[exists]
            velocities = velocities[exists]

        if np.sum(exists) == 0:
            break

    return positions, velocities, exists
```

#### 案例描述

假设有一个刚体小球在水平方向上以恒定速度运动，当小球与墙壁发生碰撞时，小球会在垂直方向上反弹。

#### 案例实现

以下是案例实现的代码：

```python
import numpy as np
import pygame

# 初始化Pygame
pygame.init()

# 设置窗口大小
width, height = 800, 600
screen = pygame.display.set_mode((width, height))

# 创建刚体
mass = 1.0
velocity = np.array([5.0, 0.0])
acceleration = np.array([0.0, -9.8])
force = np.array([0.0, 0.0])

# 设置墙壁位置和大小
wall_thickness = 10
wall_height = height - wall_thickness
wall_position = np.array([0, height - wall_height])

# 主循环
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # 更新刚体状态
    acceleration = force / mass
    velocity = velocity + acceleration * dt
    positions = positions + velocity * dt

    # 判断是否碰撞墙壁
    if (positions[0] < 0 or positions[0] > width) or (positions[1] < wall_position[1] or positions[1] > wall_position[1] + wall_height):
        # 碰撞墙壁，计算反弹角度
        normal = np.array([1.0 if positions[0] < 0 or positions[0] > width else 0.0, 1.0 if positions[1] < wall_position[1] or positions[1] > wall_position[1] + wall_height else 0.0])
        dot_product = np.dot(velocity, normal)
        reflection_vector = 2 * dot_product * normal - velocity
        velocity = reflection_vector

    # 绘制
    screen.fill((255, 255, 255))
    pygame.draw.rect(screen, (0, 0, 255), (positions[0], positions[1], 10, 10))
    pygame.display.flip()

# 退出
pygame.quit()
```
