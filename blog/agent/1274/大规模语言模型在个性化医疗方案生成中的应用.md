from sklearn.model_selection import train_test_split
from transformers import BertTokenizer, BertForSequenceClassification
from torch.utils.data import DataLoader, TensorDataset

# 数据收集
data = pd.read_csv('disease_prediction_data.csv')

# 数据预处理
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
input_ids = []
attention_mask = []

for text in data['text']:

    input_ids.append(encoded['input_ids'])
    attention_mask.append(encoded['attention_mask'])

input_ids = torch.tensor(input_ids)
attention_mask = torch.tensor(attention_mask)
labels = torch.tensor(data['label'])

# 模型训练
train_data = TensorDataset(input_ids, attention_mask, labels)
train_loader = DataLoader(train_data, batch_size=32)

model = BertForSequenceClassification.from_pretrained('bert-base-uncased', num_labels=2)
optimizer = torch.optim.Adam(model.parameters(), lr=2e-5)

for epoch in range(3):

        outputs = model(**inputs)
        loss = outputs.loss
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

# 模型评估
model.eval()

#### 附录B：Transformer自注意力机制详解

**核心概念**：自注意力机制（Self-Attention Mechanism）是一种用于计算序列中每个元素与其他元素之间关联性的机制，能够捕捉长距离依赖关系。

**算法原理讲解**：

自注意力机制的计算过程包括三个步骤：

1. **查询（Query）**：表示当前元素的表示向量。
2. **键（Key）**：表示序列中所有元素的表示向量。
3. **值（Value）**：表示序列中所有元素的表示向量。

具体计算公式如下：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

其中，$Q$、$K$、$V$分别为查询向量、键向量和值向量，$d_k$为键向量的维度。

**通俗易懂地举例说明**：

假设有一个包含3个单词的序列（Word1, Word2, Word3），我们希望计算Word1对Word2和Word3的影响。首先，分别计算Word1的查询向量$Q_1$，Word2和Word3的键向量$K_2$和$K_3$以及值向量$V_2$和$V_3$。然后，计算$Q_1$与$K_2$和$K_3$的点积，并通过softmax函数生成权重。最后，将这些权重与$V_2$和$V_3$相乘，得到Word1对Word2和Word3的加权表示。
