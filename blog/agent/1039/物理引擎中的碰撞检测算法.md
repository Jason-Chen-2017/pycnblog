## 核心概念与联系

### 算法原理与联系

碰撞检测算法的核心是判断物体之间的空间位置关系。常用的碰撞检测算法包括：

- **边界盒碰撞检测**：基于物体边界盒的空间包围结构进行碰撞检测。
- **分离轴定理（SAT）**：基于物体的最小边界矩形（MBR）进行碰撞检测。
- **空间分割算法**：将空间划分为多个子区域，减少需要检测的物体对数。

## 算法原理讲解

### 普通扫描算法

#### 原理与流程

普通扫描算法是一种简单的几何碰撞检测算法，它通过逐行或逐列扫描物体边界来检测碰撞。具体步骤如下：

1. 将所有物体的边界转换为离散点集合。
2. 对每个物体，按照某个轴（如x轴或y轴）进行排序。
3. 逐行或逐列扫描物体边界，比较相邻物体的边界，判断是否发生碰撞。

#### Python源代码实现

```python
def bound_box_collision检测(物体1, 物体2):
    # 获取物体1和物体2的边界点
    points1 = 获取边界点(物体1)
    points2 = 获取边界点(物体2)
    
    # 对边界点按轴排序
    points1_sorted = sorted(points1, key=lambda p: p[0])
    points2_sorted = sorted(points2, key=lambda p: p[0])
    
    # 扫描边界点，检测碰撞
    for i in range(len(points1_sorted) - 1):
        p1 = points1_sorted[i]
        p2 = points1_sorted[i+1]
        for j in range(len(points2_sorted) - 1):
            q1 = points2_sorted[j]
            q2 = points2_sorted[j+1]
            if (p1[1] <= q2[1] and p2[1] >= q1[1]) and (q1[0] <= p2[0] and q2[0] >= p1[0]):
                return True
    return False
```

### 基于空间分割的算法

#### 原理与流程

基于空间分割的算法通过将空间划分为多个子区域，减少需要检测的物体对数。常见的方法包括：

- **AABB树（Axis-Aligned Bounding Boxes）**：将空间划分为多个平行的轴对齐边界框（AABB），递归分割，直到达到叶节点。
- **空间排序算法（Spatial Partitioning Algorithms）**：如空间填充曲线（Space-Filling Curves），将空间划分为多个连续的子区域。

#### Python源代码实现

```python

    # 构建AABB树的递归函数

    right_node = 构建AABB树(right物体列表)
    
    node = AABB节点(left_bound, right_bound, [])
    node.子节点列表.append(left_node)
    node.子节点列表.append(right_node)
    
    return node

def 检测碰撞(物体1, AABB树):
    # 遍历AABB树，检测碰撞
    if AABB树.min_bound[0] > 物体1.x_max or AABB树.max_bound[0] < 物体1.x_min or AABB树.min_bound[1] > 物体1.y_max or AABB树.max_bound[1] < 物体1.y_min:
        return False
    
    if len(AABB树.物体列表) > 1:
        for 物体2 in AABB树.物体列表:
            if 碰撞检测(物体1, 物体2):
                return True

        if 检测碰撞(物体1, 子节点):
            return True
    
    return False
```

### 数学模型与公式讲解

碰撞检测算法的数学模型主要包括几何计算和物理计算。

#### 几何计算

- **点与线的距离公式**：

  $$ d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}} $$

  其中，$(x_0, y_0)$ 是点坐标，$ax + by + c = 0$ 是直线方程。

- **点与圆的距离公式**：

  $$ d = \sqrt{(x_1 - x_0)^2 + (y_1 - y_0)^2} - r $$

  其中，$(x_0, y_0)$ 是圆心坐标，$(x_1, y_1)$ 是点坐标，$r$ 是圆的半径。

#### 物理计算

- **弹性碰撞**：

  $$ v_{1f} = \frac{m_1 - m_2}{m_1 + m_2} v_{1i} + \frac{2m_2}{m_1 + m_2} v_{2i} $$
  $$ v_{2f} = \frac{2m_1}{m_1 + m_2} v_{1i} + \frac{m_2 - m_1}{m_1 + m_2} v_{2i} $$

  其中，$v_{1i}$ 和 $v_{1f}$ 分别是物体1的初始速度和最终速度，$v_{2i}$ 和 $v_{2f}$ 分别是物体2的初始速度和最终速度，$m_1$ 和 $m_2$ 分别是物体1和物体2的质量。

- **非弹性碰撞**：

  $$ v_{1f} = \frac{m_1 - m_2}{m_1 + m_2} v_{1i} + \frac{2m_2}{m_1 + m_2} v_{2i} $$
  $$ v_{2f} = v_{2i} $$

  其中，$v_{1i}$ 和 $v_{1f}$ 分别是物体1的初始速度和最终速度，$v_{2i}$ 和 $v_{2f}$ 分别是物体2的初始速度和最终速度，$m_1$ 和 $m_2$ 分别是物体1和物体2的质量。
