### 第一部分：个性化健身计划概述

#### 第1章：个性化健身计划的背景与意义

随着科技的发展和健康意识的提升，健身行业正在发生深刻变革。传统的健身计划往往一刀切，忽视了个体差异，导致很多人无法达到理想的健身效果。个性化健身计划应运而生，它通过定制化的方案，为每个人提供最适合的健身指导。

#### 1.1 健身计划的现状

当前，大多数健身计划都是基于一般性的指导原则，适用于大多数人，但并不能满足所有人的需求。例如，对于不同的年龄、性别、身体状况和健身目标，同一套训练计划的效果可能相差很大。

#### 1.2 个性化健身计划的定义

个性化健身计划是指根据个人的身体数据、健康状况、健身目标和偏好，定制化的健身方案。它不仅考虑了生理因素，还包括心理因素和生活方式，旨在帮助个人实现最佳的健身效果。

#### 1.3 利用提示词定制健身计划的优势

提示词在个性化健身计划中扮演着重要角色。它们可以提供具体的训练建议，如运动类型、强度、时间和频率。通过提示词，健身计划可以更灵活、更科学，从而提高健身效果。

#### 1.4 提示词在健身计划中的作用

提示词不仅能够帮助个人制定适合自己的训练计划，还可以实时监控和调整训练效果。例如，通过监测心率、血压等生理指标，提示词可以动态调整运动强度，确保训练的安全性和有效性。

from database import Base

class User(Base):
    __tablename__ = 'users'

    id = Column(Integer, primary_key=True)
    username = Column(String(50), unique=True)
    password = Column(String(50))
    email = Column(String(100), unique=True)
    birthdate = Column(Date)

class ExercisePlan(Base):
    __tablename__ = 'exercise_plans'

    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, ForeignKey('users.id'))
    start_date = Column(Date)
    end_date = Column(Date)
    description = Column(String(500))

class ExercisePlanItem(Base):
    __tablename__ = 'exercise_plan_items'

    id = Column(Integer, primary_key=True)
    exercise_plan_id = Column(Integer, ForeignKey('exercise_plans.id'))
    exercise_type = Column(String(50))
    intensity = Column(String(50))
    duration = Column(Integer)
