**1. 均匀分布模型**

在均匀分布模型中，样本点在参数空间中的生成遵循均匀分布。均匀分布的概率密度函数为：

$$
f(x) = \frac{1}{b-a} \quad \text{for} \quad a \leq x \leq b
$$

其中，$a$和$b$分别为参数空间的上界和下界。这个公式表明，在区间$[a, b]$内，每个样本点的概率是相等的。

**2. 高斯分布模型**

在引力波源参数空间中，高斯分布模型也经常被使用。高斯分布的概率密度函数为：

$$
f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} \quad \text{for} \quad \mu \leq x \leq \infty

**3. 蒙特卡洛模型**

蒙特卡洛模型是一种基于随机抽样的方法。在蒙特卡洛模型中，我们通过生成大量随机样本点来估计参数空间的特性。蒙特卡洛模型的公式为：

在优化模型中，我们通过搜索参数空间来找到最优或近似最优的样本点。优化模型的公式为：

$$
\min_{x} f(x) \quad \text{subject to} \quad g(x) = 0
$$

其中，$f(x)$为目标函数，$g(x)$为约束函数。这个公式表明，我们需要在满足约束条件的情况下，找到使得目标函数最小的样本点。

import mermaid

class SamplingSystem:
    def __init__(self, num_samples, sample_range):
        self.num_samples = num_samples
        self.sample_range = sample_range

    def generate_samples(self):
        samples = np.random.uniform(self.sample_range[0], self.sample_range[1], size=(self.num_samples, 2))
        return samples

    def plot_samples(self, samples):
        plt.scatter(samples[:, 0], samples[:, 1])
        plt.xlabel("X坐标")
        plt.ylabel("Y坐标")
        plt.title("随机样本点")
        plt.show()

    def output_mermaid(self, samples):
        print(mermaid.mmd_to_svg(f"""
        graph TD;
            A[样本点 {len(samples)}];
            {','.join([f"{i}[(x={sample[0]}, y={sample[1]})]" for i, sample in enumerate(samples, start=1)])};
            A --> {len(samples)};
        """))

# 创建采样系统实例
system = SamplingSystem(num_samples=1000, sample_range=(0, 10))

# 生成样本点

# 绘制样本点
system.plot_samples(samples)

# 输出mermaid图
system.output_mermaid(samples)
