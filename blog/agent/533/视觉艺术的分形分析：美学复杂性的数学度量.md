## 3.1 迭代函数系统（IFS）

迭代函数系统（Iterated Function System，IFS）是一种用于生成分形图案的算法，其基本思想是通过对一个初始图案进行一系列变换，然后迭代这些变换，最终生成复杂的分形图案。

### 3.1.1 算法原理

IFS算法的核心在于定义一组变换函数，每个函数将原始图案映射到不同的区域。这些变换函数可以是缩放、旋转、反射等几何变换。在每次迭代中，IFS算法将根据概率分布选择其中一个变换函数，对当前图案进行变换。

### 3.1.2 Mermaid流程图

下面是IFS算法的Mermaid流程图：

```mermaid

    A[初始图案] --> B[选择变换函数]
    B -->|概率分布| C{变换函数}
    C -->|变换| D[更新图案]
    D -->|迭代次数| A
```

### 3.1.3 Python源代码实现

以下是一个简单的IFS算法的Python源代码实现，使用Matplotlib库进行图像绘制：

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义变换函数
def transform(p, x, y):
    if p == 0:
        return (x * 0.5, y)
    elif p == 1:
        return (x, y * 0.5)
    elif p == 2:
        return (x - 2 * y, y + x)
    else:
        return (x + y, y - x)

# IFS算法
def iterateIFS(p1, p2, p3, p4, x_init, y_init, n):
    x, y = x_init, y_init
    for _ in range(n):
        p = np.random.choice([0, 1, 2, 3], p=[p1, p2, p3, p4])
        x, y = transform(p, x, y)
    return x, y

# 初始参数
p1, p2, p3, p4 = 0.25, 0.25, 0.25, 0.25
x_init, y_init = 0.5, 0.5
n = 100

# 迭代IFS
x, y = iterateIFS(p1, p2, p3, p4, x_init, y_init, n)

# 绘制结果
plt.plot(x, y, 'o')
plt.axis('equal')
plt.show()
```

### 3.1.4 算法原理讲解

通过上述Python代码和流程图，我们可以看到IFS算法的基本实现过程。算法首先定义了一组变换函数，每个函数对应一个概率分布。在每次迭代中，算法根据概率分布随机选择一个变换函数，对当前点的坐标进行变换。经过多次迭代后，原始图案逐渐演变为复杂的分形图案。

### 3.1.5 举例说明

假设我们有一个初始图案，其坐标为(0.5, 0.5)。在第一次迭代中，算法可能选择缩放变换（概率为0.25），将点的坐标变为(0.25, 0.5)。在第二次迭代中，算法可能选择旋转变换（概率为0.25），将点的坐标变为(0.25, 0.25)。随着迭代次数的增加，点的坐标将不断变化，最终形成复杂的分形图案。

### 3.1.6 边界与外延

IFS算法不仅适用于二维空间，还可以扩展到三维空间和高维空间。在实际应用中，IFS算法可以用于生成各种复杂的几何形状，如蜥蜴状图案、雪花图案等。

## 3.2 分形布朗运动（FBM）

分形布朗运动（Fractal Brownian Motion，FBM）是一种用于生成自然纹理和景观的算法，其基本思想是通过随机游走的方式模拟自然界中的随机过程。

### 3.2.1 算法原理

FBM算法的核心在于定义一个随机过程，该过程通过递归地添加随机扰动来模拟自然现象。每次迭代中，算法都会根据预先设定的参数，如尺度、噪声强度等，生成一个新的随机扰动，并将其加到当前点上的值。通过多次迭代，生成的序列将呈现出分形特征。

### 3.2.3 Python源代码实现

以下是一个简单的FBM算法的Python源代码实现，使用numpy和matplotlib库进行计算和图像绘制：

```python
import numpy as np
import matplotlib.pyplot as plt

# 初始化参数
height, width = 100, 100
scale = 0.5
noise_intensity = 0.1
iterations = 10

# FBM算法
def fractalBrownianMotion(height, width, scale, noise_intensity, iterations):
    image = np.zeros((height, width))
    for _ in range(iterations):
        for i in range(height):
            for j in range(width):
                noise = np.random.normal(0, noise_intensity)
                image[i, j] += scale * noise
                scale /= 2
    return image

# 计算FBM
image = fractalBrownianMotion(height, width, scale, noise_intensity, iterations)

# 绘制结果
plt.imshow(image, cmap='gray')
plt.axis('off')
plt.show()
```

通过上述Python代码和流程图，我们可以看到FBM算法的基本实现过程。算法首先初始化一个二维数组（图像），然后通过递归地添加随机扰动来生成图像。每次迭代中，算法都会根据尺度参数和噪声强度生成一个新的随机扰动，并将其加到当前像素的值上。经过多次迭代后，生成的图像将呈现出自然纹理的分形特征。

### 3.2.5 举例说明

假设我们有一个初始点，其值为0。在第一次迭代中，算法可能生成一个随机扰动值，将其加到当前点的值上，得到一个新的值。在第二次迭代中，算法可能生成一个新的随机扰动值，并将其加到当前点的值上。随着迭代次数的增加，点的值将不断变化，最终形成复杂的自然纹理图像。

## 4.1 豪斯多夫维数

豪斯多夫维数（Hausdorff Dimension）是一种用于度量分形复杂性的方法，它通过覆盖分形所需的覆盖集的尺度来确定分形的维数。

### 4.1.1 计算公式

豪斯多夫维数的计算公式如下：

$$
D_H = \lim_{\varepsilon \to 0} \frac{\log N(\varepsilon)}{\log \varepsilon^{-D}}
$$

其中，$N(\varepsilon)$ 表示覆盖分形所需的覆盖集的个数，$\varepsilon$ 表示覆盖集的尺度，$D$ 表示豪斯多夫维数。

例如，如果我们选择三个不同的尺度 $\varepsilon_1 = 0.1$，$\varepsilon_2 = 0.05$，$\varepsilon_3 = 0.025$，并计算出相应的覆盖集个数 $N(\varepsilon_1) = 10$，$N(\varepsilon_2) = 20$，$N(\varepsilon_3) = 40$，则我们有：

$$

### 6.2.1 迭代函数系统（IFS）生成分形图案

```python
import numpy as np
import matplotlib.pyplot as plt
from mermaid import mermaid

def iterate_ifs(p1, p2, p3, p4, x_init, y_init, n):
    x, y = x_init, y_init
    for _ in range(n):
        p = np.random.choice([0, 1, 2, 3], p=[p1, p2, p3, p4])
        if p == 0:
            x, y = x * 0.5, y
        elif p == 1:
            x, y = x, y * 0.5
        elif p == 2:
            x, y = x - 2 * y, y + x
        else:
            x, y = x + y, y - x
    return x, y

def draw_ifs(p1, p2, p3, p4, x_init, y_init, n):
    x_values, y_values = [], []
    x, y = x_init, y_init
    for _ in range(n):
        x_values.append(x)
        y_values.append(y)
        x, y = iterate_ifs(p1, p2, p3, p4, x, y, 1)
    
    plt.scatter(x_values, y_values)
    plt.axis('equal')
    plt.show()

# 示例参数
p1, p2, p3, p4 = 0.25, 0.25, 0.25, 0.25
x_init, y_init = 0.5, 0.5
n = 100

# 生成IFS分形图案
draw_ifs(p1, p2, p3, p4, x_init, y_init, n)
```

### 6.2.2 分形布朗运动（FBM）生成分形图案

```python
import numpy as np
import matplotlib.pyplot as plt
from mermaid import mermaid

def fBM(height, width, scale, noise_intensity, iterations):
    image = np.zeros((height, width))
    for _ in range(iterations):
        for i in range(height):
            for j in range(width):
                noise = np.random.normal(0, noise_intensity)
                image[i, j] += scale * noise
                scale /= 2
    return image

def draw_fBM(height, width, scale, noise_intensity, iterations):
    image = fBM(height, width, scale, noise_intensity, iterations)
    plt.imshow(image, cmap='gray')
    plt.axis('off')
    plt.show()

# 示例参数
height, width = 100, 100
scale = 0.5
noise_intensity = 0.1
iterations = 10

# 生成FBM分形图案
draw_fBM(height, width, scale, noise_intensity, iterations)
```

### 6.2.3 计算分形维数

```python
import numpy as np

def box_counting_dimension(image, levels):
    height, width = image.shape
    counts = np.zeros(levels)
    for i in range(levels):
        scale = 1 / (2 ** i)
        boxes = (height // scale, width // scale)
        counts[i] = (image > i * scale).sum() // boxes[0] // boxes[1]
    return np.log(counts).sum() / np.log(levels)

def hausdorff_dimension(image, levels):
    height, width = image.shape
    max_distance = min(height, width) / 2
    distances = np.linspace(0, max_distance, levels)
    cover_counts = []
    for distance in distances:
        pixels = np.abs(image - distance).flatten()
        cover_counts.append((pixels <= 1).sum())
    return np.log(sum(cover_counts)) / np.log(len(cover_counts))

# 示例图像
image = np.random.rand(100, 100)

# 计算盒计数维数
box_dimension = box_counting_dimension(image, 10)
print("Box Counting Dimension:", box_dimension)

# 计算豪斯多夫维数
hausdorff_dimension = hausdorff_dimension(image, 10)
print("Hausdorff Dimension:", hausdorff_dimension)
```
