                 

## 1. 引言

### 1.1 数学人类学背景

数学人类学（Mathematical Anthropology）是一个相对新兴的交叉学科领域，它将数学理论与方法应用于人类学研究。这一领域的起源可以追溯到20世纪中叶，当时学者们开始意识到数学方法在理解和解释人类行为、文化和社会结构中的潜在价值。

数学人类学的核心理念在于通过数学模型和统计分析来揭示人类行为和文化的规律性。例如，数学方法可以用来研究社会网络结构、人口迁移模式、语言演变规律等。这些研究不仅丰富了人类学的研究方法，也为数学领域提供了新的应用场景。

数学人类学的研究对象广泛，包括但不限于人口统计学、社会学、文化人类学、认知人类学等多个分支。通过跨学科的合作，数学人类学试图解答一系列关键问题，如人类社会的组织模式、文化多样性的来源、认知能力的进化等。

### 1.2 文化模式的数学研究

文化模式（Cultural Patterns）是指在不同社会和文化背景下，人们共同遵守的、具有普遍性的行为规范、价值观和生活方式。文化模式的数学研究是数学人类学的核心内容之一，它关注如何利用数学工具来揭示文化模式的形成、传播和演变过程。

文化模式的数学研究通常包括以下几个方面：

1. **文化多样性的量化**：使用数学模型和算法来量化文化差异，如使用聚类分析方法对文化群体进行分类，或者使用社会网络分析方法来研究文化网络的密度和连通性。

2. **文化模式的预测与模拟**：通过建立数学模型，对文化模式的传播、演化过程进行预测和模拟。例如，使用博弈论模型来研究文化冲突和融合，或者使用微分方程模型来研究文化的扩散。

3. **文化适应与变化的数学分析**：研究人类如何适应不同文化环境，以及文化变化对人类行为和认知的影响。例如，通过分析语言习得过程中的概率分布，来研究文化对认知发展的作用。

4. **文化认同的数学表征**：探索如何使用数学语言来表征和解释文化认同，例如通过符号系统和形式逻辑来分析宗教符号的意义。

在接下来的部分，本文将详细探讨数学人类学的基本理论、文化模式的理论框架、数学与文化模式关系的具体探讨，以及数据收集、分析方法和技术。通过这些内容，我们将深入理解数学在文化模式研究中的重要作用，并探讨未来可能的研究方向。

## 2. 研究问题与目标

### 2.1 研究问题

在数学人类学和文化模式研究领域，存在几个关键问题亟待解决：

1. **数学模型的有效性**：如何构建有效的数学模型来描述和解释文化模式的形成和演变？
2. **文化多样性的量化**：如何精确量化不同文化群体之间的差异，并揭示这些差异背后的原因？
3. **文化适应与变化的机制**：文化适应和变化过程中，人类认知和行为模式如何发生改变，这种变化是否具有普遍性？
4. **文化认同的形成与表征**：文化认同是如何通过数学模型进行表征和解释的？

为了回答上述问题，本研究将重点关注以下研究目标：

1. **建立文化模式的数学模型**：通过文献综述和实证研究，探索并建立能够有效描述文化模式形成和演变的数学模型。
2. **量化文化多样性**：采用多种数据分析方法，如聚类分析、社会网络分析等，量化不同文化群体之间的差异，并探讨这些差异的文化动因。
3. **文化适应与变化的机制研究**：分析文化适应和变化过程中的认知和行为模式，探索这些模式背后的生物学和社会学机制。
4. **文化认同的数学表征**：探讨如何使用数学语言来表征和解释文化认同，为跨文化交流提供理论支持。

### 2.2 研究目标

通过本研究，我们希望实现以下目标：

1. **理论创新**：提出并验证新的数学人类学理论框架，为文化模式研究提供理论支持。
2. **方法创新**：发展新的数据分析方法和数学模型，提高量化文化多样性和解释文化模式的能力。
3. **应用拓展**：将数学人类学理论和方法应用于实际文化研究和跨文化交流，促进文化交流与融合。
4. **学术贡献**：为数学人类学和文化模式研究领域提供新的研究成果，推动学科发展。

### 2.3 研究边界与外延

本研究的主要边界和范围包括：

1. **研究对象**：主要研究现代文化模式，重点关注城市化、全球化背景下文化的变化和适应性。
2. **研究方法**：主要采用数学模型、统计分析、社会网络分析等量化研究方法，结合定性研究进行验证。
3. **研究范围**：本研究将主要关注人类学和文化模式领域的数学应用，不包括其他学科如物理学、计算机科学等领域的数学应用。

通过明确研究问题和目标，本文将为后续章节的详细探讨奠定基础，逐步揭示数学在文化模式研究中的关键作用，并探索未来可能的研究方向。

## 3. 理论基础

### 3.1 数学人类学基本理论

数学人类学的基本理论构建在数学方法论和文化人类学的基础之上。它涉及多个核心概念，包括数学思维、数学教育、数学文化等。

**数学思维**是指人类运用数学原理和方法解决问题的能力。这种思维包括逻辑推理、抽象能力、模式识别等。在数学人类学中，数学思维被用来分析人类行为和文化的逻辑结构，揭示其中的规律性和模式。

**数学教育**关注的是如何通过教育培养数学思维和技能。在数学人类学的研究中，数学教育理论提供了理解人类如何学习和应用数学的工具。例如，研究者可以探讨数学教育在不同文化背景下的差异，以及这些差异如何影响个体和群体的认知模式。

**数学文化**是指数学作为一种文化现象，其发展、传播和影响。数学文化研究包括数学历史、数学在各个文化中的地位和作用，以及数学如何影响和塑造文化。例如，数学文化研究可以揭示古代文明如古埃及、希腊和中国的数学成就，以及这些成就如何影响现代数学的发展。

### 3.2 文化模式理论

文化模式理论是理解文化多样性和共性的一组概念和理论。文化模式指的是在特定社会和文化背景下，人们共同遵循的行为规范、价值观和生活方式。

**文化特征**是指文化的基本属性，包括文化中的语言、艺术、宗教、习俗等。不同的文化特征构成了文化的多样性。例如，语言不仅是交流的工具，也是文化身份的重要组成部分。

**文化要素**是指构成文化的具体元素，如社会结构、经济制度、教育体系等。这些要素相互作用，共同决定了一个社会的文化模式和特征。

**文化类型**是指根据文化特征和要素的分类。常见的文化类型包括农业文化、工业文化、海洋文化等。每种文化类型都有其独特的文化模式和价值观。

文化模式理论为我们理解数学如何影响文化提供了框架。例如，数学作为一种重要的知识体系，不仅在科学和技术领域发挥着核心作用，也渗透到日常生活中的各个方面，从而影响和塑造了文化。

### 3.3 数学与文化模式关系探讨

数学与文化模式之间的关系可以从多个角度进行探讨：

**数学在文化模式中的表现**：数学作为一种普遍存在的知识体系，在不同文化中有着不同的表现和影响。例如，古代文明的数学成就如古埃及的几何、古巴比伦的算术等，不仅反映了这些文化的科学和技术水平，也成为了这些文化的重要组成部分。

**数学对文化模式的影响**：数学不仅反映了文化，还可能对文化模式产生深远的影响。例如，数学工具和方法的应用可以改变人类的生活方式、社会组织结构，以及价值观念。例如，现代交通系统、通信技术、金融系统等都是数学应用的体现，这些技术不仅改变了人类的生活，也影响了社会的文化模式。

**数学在文化模式研究中的应用**：数学在文化模式研究中的应用主要体现在数据分析和模型建立上。通过数学方法，研究者可以量化文化差异、预测文化模式的演变、分析文化适应性等。例如，社会网络分析可以用来研究文化网络的密度和结构，聚类分析可以用来分类不同的文化群体。

数学与文化模式之间的关系是一个复杂且多层次的问题。通过数学人类学的研究，我们可以更好地理解数学在文化发展中的作用，以及文化如何影响和塑造数学的发展。这种跨学科的研究不仅丰富了数学和文化人类学的理论，也为解决现实世界中的问题提供了新的视角和方法。

## 4. 方法与技术

### 4.1 数据收集方法

在数学人类学和文化模式研究中，数据收集是至关重要的一步。数据的质量和完整性直接影响到研究的可靠性和有效性。以下是几种常用的数据收集方法：

**文献调查**：通过查阅和分析相关文献，收集已有的理论和实证研究资料。文献调查可以提供丰富的背景信息和理论基础，有助于明确研究问题和目标。

**问卷调查**：设计问卷并分发给目标群体，以收集关于文化模式和个人行为的数据。问卷调查的优点是能够大规模收集数据，适用于分析文化差异和群体行为。

**实验研究**：通过设计和实施实验，观察和记录特定文化情境下的行为反应。实验研究可以控制变量，提高数据的一致性和可重复性。

**实地观察**：直接在目标文化环境中进行观察和记录，收集第一手数据。实地观察适用于研究文化模式的具体表现和演变。

**网络数据收集**：利用互联网平台和社交媒体，收集关于文化行为的数字数据。网络数据收集具有实时性和广泛性，适合研究现代文化情境下的行为模式。

### 4.2 数据分析方法

数据收集完成后，数据分析是揭示文化模式规律的关键步骤。以下是几种常用的数据分析方法：

**统计分析**：使用描述性统计和推断性统计方法，对收集到的数据进行量化和分析。描述性统计可以总结数据的基本特征，如均值、方差等；推断性统计可以推断总体特征，如置信区间、假设检验等。

**回归分析**：通过建立回归模型，分析自变量和因变量之间的关系。回归分析可以用来预测文化模式的变化趋势，以及识别影响文化模式的关键因素。

**聚类分析**：将数据分成若干组，以便于分析和理解。聚类分析可以用来识别不同文化群体，以及分析文化差异。

**社会网络分析**：通过分析个体之间的互动关系，研究文化网络的密度、结构和连通性。社会网络分析可以揭示文化模式在社会结构中的表现和影响。

**机器学习方法**：利用机器学习算法，如决策树、支持向量机、神经网络等，对数据进行分类、预测和模式识别。机器学习方法可以处理大量复杂数据，提高分析的精度和效率。

### 4.3 数学模型建立方法

在文化模式研究中，数学模型的建立是理解和解释文化模式的关键。以下是几种常用的数学模型建立方法：

**概率模型**：通过概率论和统计方法，建立描述文化模式不确定性的数学模型。概率模型可以用来分析文化行为的随机性和可能性。

**微分方程模型**：通过微分方程描述文化模式的时间演变和空间扩散。微分方程模型可以用来研究文化模式的动态变化和演化过程。

**博弈论模型**：通过博弈论分析不同文化群体之间的互动和策略选择。博弈论模型可以用来研究文化冲突、合作和融合。

**复杂网络模型**：通过复杂网络理论，建立描述文化网络结构和功能的数学模型。复杂网络模型可以用来研究文化网络中的信息传播和影响扩散。

**机器学习模型**：通过机器学习方法，如深度学习、强化学习等，建立自动学习和预测文化模式的模型。机器学习模型可以处理大规模复杂数据，提高文化模式识别的准确性。

通过综合运用这些方法，研究者可以全面深入地分析文化模式的数学本质，揭示其内在规律和特征，从而为文化研究和人类学的发展提供新的视角和工具。

4. **文化认同的数学表征**：通过符号系统和形式逻辑分析，我们提出了新的数学方法来表征和解释文化认同。这些方法能够将复杂的文化现象转化为可计算的数学模型，为跨文化交流提供了理论支持。

### 5.2 结果分析与讨论

对于上述研究发现，我们进行了深入的分析和讨论：

3. **文化适应与变化的机制**：文化适应是一个多层次、多维度的过程。我们的研究揭示了文化适应的多种机制，包括认知适应、社会适应和文化适应等。这些机制在不同文化背景下可能具有不同的表现形式，未来研究需要进一步探讨这些机制的动态变化和相互影响。

4. **文化认同的数学表征**：我们的方法为文化认同的数学表征提供了新的思路。然而，这些方法在应用中仍需解决符号系统的普适性和形式逻辑的复杂性等问题。未来的研究可以探索更有效的数学工具和方法，提高文化认同表征的精度和可靠性。

总的来说，本研究在数学人类学和文化模式研究领域取得了重要的理论创新和方法创新，为理解人类文化行为提供了新的视角和工具。然而，研究也存在一定的局限性，需要未来的研究进一步深化和完善。

## 7. 核心概念

### 7.1 数学概念

数学概念是人类理解和解释世界的基本工具，是数学人类学研究的核心内容。以下是一些关键的数学概念及其在研究中的应用：

**集合论**：集合论是数学的基础，用于定义和处理一组对象。在数学人类学中，集合论可以用来描述文化群体、社会网络等，揭示这些群体的结构特征。

**概率论**：概率论用于研究随机事件和不确定性。在文化模式研究中，概率论可以帮助我们量化文化行为的随机性和可能性，以及预测文化模式的演变趋势。

**统计分析**：统计分析是处理和分析数据的数学方法，包括描述性统计和推断性统计。在数学人类学中，统计分析用于总结和解释文化模式的数据特征，以及推断总体特征。

**集合论**：集合论是数学的基础，用于描述和处理一组对象。集合论的基本概念包括集合、元素、子集、并集、交集和补集等。在数学人类学中，集合论可以用来定义文化群体，分析不同文化群体之间的重叠和分离。

**概率论**：概率论用于研究随机事件和不确定性。概率论的基本概念包括概率空间、随机变量、概率分布和期望值等。在文化模式研究中，概率论可以用来量化文化行为的随机性和可能性，以及预测文化模式的演变趋势。

**统计分析**：统计分析是处理和分析数据的数学方法，包括描述性统计和推断性统计。描述性统计用于总结数据的基本特征，如均值、方差等；推断性统计用于推断总体特征，如置信区间、假设检验等。在数学人类学中，统计分析用于分析和解释文化模式的数据特征。

**微分方程**：微分方程用于描述动态系统的变化规律。在文化模式研究中，微分方程模型可以用来分析文化模式的动态变化和演化过程，揭示文化模式的演变规律。

**博弈论**：博弈论研究多个个体在策略互动中的行为模式。博弈论的基本概念包括博弈形式、策略、支付矩阵和纳什均衡等。在数学人类学中，博弈论可以用来研究文化冲突、合作和融合，揭示不同文化群体之间的互动机制。

**复杂网络**：复杂网络理论用于研究网络结构和功能。在文化模式研究中，复杂网络模型可以用来分析文化网络的密度、结构和连通性，揭示文化模式在社会结构中的表现。

### 10.2 数学公式与算法

为了更具体地展示这些数学原理，我们将介绍一些关键数学公式和算法，这些公式和算法在数学人类学和文化模式研究中具有广泛应用。

**概率分布函数（PDF）**：
\[ f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} \]
这是一个正态分布的概率密度函数，用于描述随机变量的概率分布。在文化模式研究中，正态分布可以用来模拟文化行为的随机性，分析文化模式的概率特征。

**线性回归模型**：
\[ Y = \beta_0 + \beta_1X + \epsilon \]
这是一个线性回归模型，用于分析自变量和因变量之间的关系。在数学人类学中，线性回归模型可以用来分析文化模式中的影响因素，预测文化行为的变化。

**社会网络分析算法**：
例如，K-means聚类算法和PageRank算法：
- **K-means聚类算法**：
\[ \min \sum_{i=1}^k \sum_{x \in S_i} \|x - \mu_i\|^2 \]
K-means算法用于将数据点划分为若干个簇，每个簇由其质心表示。在文化模式研究中，K-means可以用来分类不同的文化群体。
- **PageRank算法**：
\[ R_{ij} = \left(\frac{1-d}{N}\right) + d \sum_{k=1}^N \frac{R_{ik}}{L_i} \]
PageRank算法用于评估网页的重要性，也可以用于分析社会网络中的影响力。在数学人类学中，PageRank可以用来分析文化网络中的节点重要性和影响力。

这些数学公式和算法为理解和解释文化模式提供了强大的工具。通过实际案例，我们将进一步展示如何利用这些数学原理来分析文化模式。

### 10.3 数学原理应用实例

为了更直观地展示数学原理在文化模式研究中的应用，我们将通过一个实际案例来详细讲解。以下是一个关于文化认同度量的案例。

**案例背景**：假设我们研究一个多元文化社区，并希望了解不同文化群体之间的认同度。通过调查，我们收集了关于社区居民的文化特征数据，如语言使用频率、宗教信仰、节日庆祝习惯等。

**数据收集**：调查问卷收集了以下数据：
- 语言使用频率（如中文、英语、法语等）
- 宗教信仰（如基督教、伊斯兰教、佛教等）
- 节日庆祝习惯（如春节、圣诞节、清明节等）

**数学原理应用**：

1. **概率分布**：我们使用概率分布来分析社区内不同文化特征的使用情况。例如，我们可以计算中文使用的概率分布：
\[ f_{\text{中文}}(x) = \frac{1}{\sigma_{\text{中文}}\sqrt{2\pi}} e^{-\frac{(x-\mu_{\text{中文}})^2}{2\sigma_{\text{中文}}^2}} \]
其中，\( \mu_{\text{中文}} \) 是中文使用的平均值，\( \sigma_{\text{中文}} \) 是标准差。

2. **线性回归**：我们使用线性回归模型来分析文化特征之间的关系。例如，分析语言使用频率与宗教信仰之间的关系：
\[ Y_{\text{宗教}} = \beta_0 + \beta_1X_{\text{语言}} + \epsilon \]
其中，\( X_{\text{语言}} \) 表示语言使用频率，\( Y_{\text{宗教}} \) 表示宗教信仰。

3. **社会网络分析**：我们使用K-means聚类算法来分析社区内不同文化群体的结构：
\[ \min \sum_{i=1}^k \sum_{x \in S_i} \|x - \mu_i\|^2 \]
通过聚类分析，我们可以将社区划分为若干个文化群体，每个群体由其质心表示。

4. **PageRank算法**：我们使用PageRank算法来评估文化群体在网络中的影响力：
\[ R_{ij} = \left(\frac{1-d}{N}\right) + d \sum_{k=1}^N \frac{R_{ik}}{L_i} \]
通过计算每个文化群体的PageRank值，我们可以了解其在社区中的影响力和地位。

**结果分析**：通过上述数学模型的应用，我们得到了以下结果：
- 文化特征的使用情况分布，例如中文使用的概率分布。
- 文化特征之间的关系，如语言使用频率与宗教信仰之间的相关性。
- 社区内不同文化群体的结构，以及每个群体的特征。
- 文化群体在网络中的影响力，识别出具有较高影响力的文化群体。

这个案例展示了如何通过数学原理来分析文化模式，揭示文化群体之间的联系和差异。通过这些分析，我们可以更好地理解社区的文化结构，为文化交流和政策制定提供科学依据。

### 11. 数学模型建立方法

在文化模式研究中，数学模型建立是揭示和解释文化现象的关键步骤。以下是几种常用的数学模型建立方法及其适用场景：

概率模型是研究随机现象的基础，适用于分析文化行为的随机性和不确定性。例如，使用贝叶斯网络模型可以描述文化群体之间的概率依赖关系。这种方法适用于需要量化不确定性和进行预测的场景。

**2. 微分方程模型**：
微分方程模型用于描述动态系统的变化规律，适用于分析文化模式的演变过程。例如，使用常微分方程模型可以模拟文化行为的扩散过程，适用于研究文化模式的时间演变。

**3. 博弈论模型**：
博弈论模型用于分析多个个体在策略互动中的行为模式，适用于研究文化冲突、合作和融合。例如，使用纳什均衡模型可以分析不同文化群体之间的策略选择，适用于研究文化互动和竞争。

**4. 复杂网络模型**：
复杂网络模型用于研究网络结构和功能，适用于分析文化网络的密度、结构和连通性。例如，使用小世界网络模型可以描述文化网络的紧凑性和短路径效应，适用于研究文化网络的传播和影响。

**5. 机器学习模型**：
机器学习模型，如决策树、支持向量机和神经网络等，用于处理大规模复杂数据，适用于分类、预测和模式识别。例如，使用K最近邻算法可以分类不同的文化群体，适用于研究文化差异和聚类。

**6. 社会网络分析模型**：
社会网络分析模型，如K-means聚类和PageRank算法，用于分析社会网络中的结构和功能，适用于研究文化群体的结构和影响力。例如，使用K-means聚类可以分析社区内的文化群体结构，适用于研究文化多样性和聚类。

通过这些数学模型建立方法，研究者可以根据具体研究问题选择合适的模型，揭示文化模式的内在规律和特征。以下是一个数学模型建立过程的实例，用于解释具体步骤：

**实例：建立文化行为扩散模型**

1. **定义问题**：假设我们研究一个社区的文化行为扩散过程，目标是建立数学模型来描述文化行为的传播规律。

2. **收集数据**：通过问卷调查、观察等方法收集关于文化行为的数据，包括行为频率、传播路径等。

3. **建立假设**：根据问题背景，提出假设，例如认为文化行为的传播符合SIR模型（易感染者、已感染者、恢复者）。

4. **建立模型**：根据假设，使用微分方程建立文化行为扩散模型：
\[ \frac{dS}{dt} = -\beta SI \]
\[ \frac{dI}{dt} = \beta SI - \gamma I \]
\[ \frac{dR}{dt} = \gamma I \]
其中，\( S \)、\( I \) 和 \( R \) 分别表示易感染者、已感染者和恢复者的数量，\( \beta \) 和 \( \gamma \) 为模型参数。

5. **参数估计**：使用收集到的数据进行参数估计，确定模型参数的值。

6. **模型验证**：通过模拟和实际数据对比，验证模型的有效性。

7. **模型应用**：使用建立的模型进行预测和模拟，分析文化行为的传播趋势和影响因素。

通过上述步骤，我们可以建立用于分析文化模式扩散的数学模型，为文化研究和政策制定提供科学依据。

### 12. 数学模型详细讲解与举例说明

在本节中，我们将详细讲解一个用于分析文化模式的数学模型，并通过Python代码实现和案例分析，展示该模型的应用效果。

#### 12.1 数学模型公式讲解

**模型背景**：假设我们研究一个社区的文化行为传播问题，使用SIR模型（易感染者、已感染者、恢复者模型）来描述文化行为的扩散过程。SIR模型是一个常微分方程模型，用于描述传染病在人群中的传播，但在本文中，我们将将其应用于文化行为的传播。

**模型公式**：
\[ \frac{dS}{dt} = -\beta SI \]
\[ \frac{dI}{dt} = \beta SI - \gamma I \]
\[ \frac{dR}{dt} = \gamma I \]

其中，\( S(t) \)、\( I(t) \) 和 \( R(t) \) 分别表示在时间 \( t \) 时易感染者、已感染者和恢复者的比例。参数 \( \beta \) 表示感染率，即易感染者与已感染者接触后感染的概率；参数 \( \gamma \) 表示恢复率，即已感染者康复的概率。

**初始条件**：
\[ S(0) = 1 \]
\[ I(0) = \frac{\delta}{N} \]
\[ R(0) = 0 \]

其中，\( \delta \) 表示初始感染者的比例，\( N \) 为总人数。

#### 12.2 数学模型Python代码实现

下面是使用Python和SciPy库实现SIR模型的具体步骤和代码：

```python
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

# 模型参数
N = 1000  # 总人数
beta = 0.3  # 感染率
gamma = 0.1  # 恢复率
delta = 0.01  # 初始感染者比例

# 初始条件
S0 = N - delta
I0 = delta
R0 = 0

# SIR模型微分方程
def sir_model(t, y):
    S, I, R = y
    dSdt = -beta * S * I
    dIdt = beta * S * I - gamma * I
    dRdt = gamma * I
    return [dSdt, dIdt, dRdt]

# 时间范围
t_span = (0, 200)
t_eval = np.linspace(t_span[0], t_span[1], 100)

# 求解模型
sol = solve_ivp(sir_model, t_span, [S0, I0, R0], t_eval=t_eval)

# 可视化结果
plt.figure(figsize=(12, 6))
plt.plot(sol.t, sol.y[0], label='易感染者 (S)')
plt.plot(sol.t, sol.y[1], label='已感染者 (I)')
plt.plot(sol.t, sol.y[2], label='恢复者 (R)')
plt.xlabel('时间 (天)')
plt.ylabel('人数')
plt.legend()
plt.title('SIR模型：文化行为传播')
plt.show()
```

在这段代码中，我们首先定义了模型参数和初始条件，然后定义了SIR模型微分方程的求解函数。使用SciPy库的`solve_ivp`函数求解微分方程，并使用`matplotlib`库将结果可视化。

- **恢复率影响**：当恢复率 \( \gamma \) 增加时，已感染者数量 \( I(t) \) 减少速度加快，但易感染者数量 \( S(t) \) 减少速度减缓，最终达到平衡状态。
