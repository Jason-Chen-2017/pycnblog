### 个人英雄主义与领导力

个人英雄主义是一种领导模式，其核心在于领导者个人的才华、魅力和决策能力。在这种模式下，领导者被视为团队的中心，通过个人的力量和智慧来解决问题和推动团队前进。个人英雄主义在历史上有着深远的影响，许多成功的企业和团队都离不开这种领导模式。

然而，随着组织的规模扩大和复杂性的增加，个人英雄主义逐渐暴露出其局限性。首先，个人英雄主义依赖于领导者的个人能力和决策，这限制了团队的多样性和创新能力。其次，个人英雄主义容易导致权力集中和官僚主义，影响组织的灵活性和响应速度。

### 集体智慧与领导力

集体智慧是一种基于团队协作和共同决策的领导模式。在这种模式下，领导者不再是唯一的决策者，而是更多地扮演协调者和推动者的角色。团队中的每个成员都被视为宝贵的资源，他们的智慧和经验被充分挖掘和利用。

集体智慧具有以下优点：

1. **创新能力**：集体智慧能够汇集团队成员的不同观点和经验，激发创新思维，从而推动组织的持续发展。
2. **决策质量**：集体智慧通过多方面的讨论和评估，能够提高决策的质量和准确性。
3. **团队凝聚力**：集体智慧能够增强团队成员之间的信任和合作，提高团队的凝聚力。
4. **组织适应力**：集体智慧使组织能够更快速地适应外部环境的变化，提高组织的生存能力。

### 从个人英雄主义到集体智慧的转变

领导力的变革不仅仅是一种理念的转变，更是一个实践的过程。从个人英雄主义到集体智慧的转变，需要领导者、团队和组织共同努力。

1. **领导者角色的转变**：领导者需要从“指挥者”转变为“协调者”，更多地关注团队的合作和沟通，而不是个人的决策和执行。
2. **团队文化的建设**：组织需要建立一个开放、包容和信任的团队文化，鼓励团队成员积极参与决策和讨论。
3. **技能和工具的提升**：领导者需要掌握有效的沟通和协作技能，并运用各种工具和技术来支持集体智慧的实施。

### 集体智慧在实践中的应用

集体智慧在实践中的应用已经取得了显著的效果。例如，谷歌的“20%时间”政策，允许员工将20%的工作时间用于个人感兴趣的项目，这一政策激发了员工的创新潜力，推动了公司的发展。另一个例子是维基百科，通过全球志愿者共同协作，维基百科成为了一个庞大的知识库，展示了集体智慧的强大力量。

1. **领导者的角色**：领导者不再是权威的象征，而是团队的合作者和推动者。
2. **领导力的内涵**：领导力不仅包括决策和执行，更包括沟通、协调和激励。
3. **领导力的外延**：领导力不再局限于企业内部，而是扩展到整个社会，成为推动社会进步的重要力量。

   $$ TEI = \frac{LI + CI}{2} $$

   $$ LIR = \frac{LI_{new} - LI_{old}}{LI_{old}} \times 100\% $$

   其中，$LI_{new}$表示新领导力指数，$LI_{old}$表示旧领导力指数。

```python
from django.db import models
from django.contrib.auth.models import AbstractUser

class User(AbstractUser):
    department = models.ForeignKey('Department', on_delete=models.CASCADE)
    position = models.CharField(max_length=100)

class Department(models.Model):
    name = models.CharField(max_length=100)
    boss = models.ForeignKey(User, on_delete=models.CASCADE)

# organization_management.py
from django.db import models

class Organization(models.Model):
    name = models.CharField(max_length=100)
    structure = models.CharField(max_length=100)

# task_management.py
from django.db import models
from user_management.models import User

class Task(models.Model):
    title = models.CharField(max_length=100)
    content = models.TextField()
    status = models.CharField(max_length=50)
    assignee = models.ForeignKey(User, on_delete=models.CASCADE)
    creator = models.ForeignKey(User, on_delete=models.CASCADE)
```
