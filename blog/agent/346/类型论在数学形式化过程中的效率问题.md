def type_check(expression):
    # 假设expression是一个抽象语法树

    elif isinstance(expression, float):
        return "float"
    else:
        return "unknown"

def type_derive(expression, context):

在类型论中，数学公式用于描述类型系统、类型判断、类型等价性和类型依赖性等概念。以下是对这些数学公式的详细讲解：

- **类型系统公式**：类型系统公式用于定义数据类型的集合和操作规则。常见的类型系统公式包括类型定义、类型推导和类型等价性。
  - **类型定义**：类型定义用于定义数据类型。例如，整数类型可以定义如下：

  - **类型推导**：类型推导用于从表达式推导出类型。例如，从表达式`5 + 3`推导出整数类型：

    $$type(5 + 3) \equiv type(8)$$
- **类型判断公式**：类型判断公式用于确定一个表达式或语句的类型。常见的类型判断公式包括类型检查和类型推导。

  - **类型推导**：类型推导用于从表达式推导出类型。例如，从表达式`5 + 3`推导出整数类型：
    $$type_derive(5 + 3) = int$$
- **类型等价性公式**：类型等价性公式用于确定两个表达式在类型上等价。例如，表达式`5 + 3`和`8`在类型上等价：

- **类型依赖性公式**：类型依赖性公式用于描述类型之间的相互依赖关系。例如，整数类型依赖于浮点数类型：
