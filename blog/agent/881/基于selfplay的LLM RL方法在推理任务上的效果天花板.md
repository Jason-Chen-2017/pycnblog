在现代人工智能领域，自然语言处理（NLP）已经取得了显著进展，尤其是在生成式模型和推理任务方面。然而，传统的NLP方法往往依赖于大量的标注数据和预训练模型，这些方法在处理复杂推理任务时仍然存在诸多局限。为了解决这一问题，研究者们开始探索更加高效、智能的解决方案。

**1.1.1 self-play在游戏中的起源**

self-play是深度强化学习（Deep Reinforcement Learning, DRL）中的一种方法，最早应用于棋类游戏的研究。它的基本思想是让一个智能体在与自己多次对弈的过程中，不断优化自己的策略，以达到博弈的最优解。1992年，Arthur Samuel提出了self-play算法，该算法在围棋游戏中取得了突破性的成果，成为后来许多研究的基石。

**1.1.2 LLM与RL的结合**

**1.1.3 推理任务的需求与挑战**

推理任务在现实场景中具有广泛的应用，如问答系统、自然语言推理（NLI）、文本生成等。然而，传统的LLM和RL方法在处理推理任务时，往往面临以下挑战：

### 1.2 核心概念解析

为了深入探讨基于self-play的LLM RL方法在推理任务上的效果天花板，我们需要先理解三个核心概念：self-play、LLM和RL。

**1.2.1 self-play的定义与原理**

self-play是一种在封闭环境中通过自我对弈来学习策略的强化学习方法。具体来说，一个智能体A通过与自身进行多轮博弈，不断优化自己的策略π，使其在博弈中取得更好的表现。self-play算法通常包含以下步骤：

1. **初始化策略**：随机初始化一个策略π。
2. **自我对弈**：智能体A使用策略π与自身进行多轮博弈，每轮博弈结束后，智能体A会根据博弈结果更新策略π。
3. **策略更新**：使用某种策略更新方法（如策略梯度方法）来更新策略π。
4. **迭代**：重复步骤2和步骤3，直到策略π收敛。

**1.2.2 LLM的基本原理与优势**

LLM是一种基于深度学习的自然语言处理模型，通过大规模预训练和微调，可以生成高质量的自然语言文本。LLM的主要优势包括：

1. **强大的语言理解能力**：LLM能够理解自然语言的语义和语法，从而生成更加准确和自然的文本。
2. **多语言支持**：LLM通常具有多语言能力，可以处理多种语言的文本数据。
3. **端到端学习**：LLM采用端到端的学习方式，不需要手动设计特征提取和融合模块，降低了模型设计的复杂性。

**1.2.3 RL的基本原理与挑战**

RL是一种通过环境交互来学习策略的强化学习方法。在RL中，智能体A通过与环境的交互，学习一种策略π，使其能够在环境E中取得最优的回报。RL的基本原理包括：

1. **状态-动作-回报模型**：智能体A在某一时刻的状态s，执行动作a，获得回报r，然后进入下一状态s'。
2. **策略**：策略π是指智能体A在给定状态下选择动作的概率分布。
3. **价值函数**：价值函数V(·)用于评估智能体A在某一状态下的最优回报。

RL在处理推理任务时面临的挑战主要包括：

1. **探索与利用的平衡**：智能体需要在探索未知策略和利用已知策略之间找到平衡。
2. **数据效率**：RL通常需要大量的交互数据才能收敛，这对于数据稀缺的推理任务是一个挑战。
3. **模型可解释性**：RL模型在推理过程中的决策过程通常难以解释，这对实际应用提出了更高的要求。

## 2.1 self-play算法原理

### 2.1.1 self-play的基本流程

self-play算法是一种通过自我对弈来学习策略的强化学习方法。它的基本流程包括以下几个步骤：

1. **初始化策略**：首先，随机初始化一个策略π。策略π定义了智能体在给定状态下选择动作的概率分布。
   
2. **自我对弈**：智能体A使用策略π与自身进行多轮博弈。每轮博弈中，智能体A根据策略π选择动作，执行动作后，进入新的状态。

3. **策略更新**：在自我对弈的过程中，智能体A会根据博弈结果（回报）来更新策略π。常见的策略更新方法包括策略梯度方法、值函数方法等。

4. **迭代**：重复步骤2和步骤3，直到策略π收敛，或者达到预定的迭代次数。

**基本流程图如下：**

```mermaid
graph TD
    A[初始化策略π] --> B[自我对弈]
    B --> C[更新策略π]
    C --> D[迭代]
    D --> E[策略收敛]
```

### 2.1.2 self-play的优势与局限性

**优势：**

1. **无外部数据依赖**：self-play算法不需要外部数据集，完全依赖于自我对弈来学习策略。这在数据稀缺或数据获取成本高昂的场景中具有显著优势。
2. **自我优化**：通过自我对弈，智能体可以不断优化自己的策略，逐步提高博弈的表现。这种方法具有内在的循环迭代机制，有助于逐步逼近最优策略。
3. **高效性**：self-play算法在训练过程中可以快速收敛，因为它利用了自我对弈的过程来不断更新策略。

**局限性：**

1. **局部最优**：self-play算法容易陷入局部最优，难以找到全局最优策略。这是因为智能体在对弈过程中只能根据当前的状态和回报来更新策略，无法全局优化。
2. **计算资源消耗**：self-play算法需要大量的计算资源，因为需要智能体与自身进行多轮博弈。这可能导致训练时间过长，尤其是在复杂的游戏或任务中。
3. **策略多样性不足**：self-play算法可能会过度依赖单一策略，导致策略多样性不足。这可能会限制智能体在面对新情况时的适应能力。

### 2.1.3 self-play的数学模型与公式

在self-play算法中，我们通常使用马尔可夫决策过程（MDP）来建模智能体的决策过程。一个MDP由状态空间S、动作空间A、状态转移概率矩阵P(s' | s, a)和回报函数R(s, a)组成。

**状态空间S**：智能体在游戏或任务中的所有可能状态。

**动作空间A**：智能体可以选择的所有可能动作。

**状态转移概率矩阵P(s' | s, a)**：在给定当前状态s和动作a时，智能体进入下一个状态s'的概率。

**回报函数R(s, a)**：在执行动作a后，智能体从状态s转移到状态s'所获得的即时回报。

在self-play算法中，智能体A使用策略π来选择动作，策略π是一个概率分布，π(a | s)表示在状态s下选择动作a的概率。

**策略更新**：

常见的策略更新方法包括策略梯度方法和值函数方法。这里我们以策略梯度方法为例进行讲解。

策略梯度方法的更新公式为：

$$
\theta_{t+1} = \theta_{t} + \alpha \nabla_{\theta} J(\theta)
$$

其中，$\theta$表示策略参数，$\alpha$表示学习率，$J(\theta)$表示策略评估函数。

**策略评估函数**：

策略评估函数用于评估策略π在当前状态s下的预期回报。它的计算公式为：

$$
J(\theta) = \sum_{s'} P(s'|s,\pi)(R(s,a) + \gamma V(s'))
$$

其中，$V(s')$表示在状态s'下的期望回报，$\gamma$是折扣因子，用于考虑未来的回报。

**奖励函数**：

在self-play算法中，奖励函数的设计至关重要。一个有效的奖励函数需要能够反映智能体在游戏或任务中的表现。常见的奖励函数包括胜利奖励、胜率奖励等。

**胜利奖励**：

胜利奖励是最简单的一种奖励函数，当智能体A获胜时，给予一个正奖励；当智能体A失败时，给予一个负奖励。公式如下：

$$
R(s, a) = \begin{cases} 
+1 & \text{if } s' \text{ is a winning state for agent A} \\
-1 & \text{if } s' \text{ is a losing state for agent A} 
\end{cases}
$$

**胜率奖励**：

胜率奖励函数通过计算智能体A在游戏中的胜率来评估其表现。胜率越高，奖励越高。公式如下：

$$
R(s, a) = \frac{1}{N} \sum_{i=1}^{N} \text{win\_rate}(s_i)
$$

其中，$\text{win\_rate}(s_i)$表示在第i次自我对弈中智能体A的胜率，$N$是对弈的总次数。

### 2.1.4 self-play算法的应用场景

self-play算法在多个领域都有广泛的应用：

**游戏**：self-play算法在棋类游戏、格斗游戏等领域取得了显著成果。例如，DeepMind的AlphaGo使用self-play算法，在与自身对弈的过程中不断优化策略，最终战胜了人类围棋冠军。

### 2.1.6 self-play算法的优点与缺点

**优点：**

1. **无外部数据依赖**：self-play算法不需要外部数据集，完全依赖于自我对弈来学习策略，这在数据稀缺或数据获取成本高昂的场景中具有显著优势。

**缺点：**

1. **局部最优**：self-play算法容易陷入局部最优，难以找到全局最优策略。这是因为智能体在对弈过程中只能根据当前的状态和回报来更新策略，无法全局优化。

3. **策略多样性不足**：self-play算法可能会过度依赖单一策略，导致策略多样性不足。这可能会限制智能体在面对新情况时的适应能力。

### 2.1.7 总结

self-play算法是一种通过自我对弈来学习策略的强化学习方法。它具有无外部数据依赖、自我优化和高效性等优点，但同时也存在局部最优、计算资源消耗和策略多样性不足等缺点。在未来的研究中，我们可以进一步探索如何优化self-play算法，提高其性能和应用效果。

## 2.2 LLM原理讲解

### 2.2.1 LLM的基本构成

大型语言模型（Large Language Model，简称LLM）是一种基于深度学习的自然语言处理模型，通过大规模的预训练和微调，能够在多种语言任务中表现出色。LLM的基本构成主要包括以下几个部分：

1. **输入层**：输入层负责接收自然语言文本数据，将其转换为模型可以处理的向量形式。
2. **编码器**：编码器是LLM的核心部分，负责将输入的文本向量编码成语义向量，捕捉文本的语义信息。
3. **解码器**：解码器负责将编码后的语义向量解码成自然语言输出。
4. **注意力机制**：注意力机制是一种用于捕捉文本序列中重要信息的机制，可以显著提高模型的性能。

**基本结构图如下：**

```mermaid

    A[Input Layer] --> B[Encoder]
    B --> C[Attention Mechanism]
    C --> D[Decoder]
```

### 2.2.2 LLM的工作机制

LLM的工作机制可以分为两个主要阶段：预训练和微调。

**预训练阶段**：

1. **数据集准备**：首先，从互联网上收集大量的文本数据，如新闻、小说、社交媒体帖子等。
2. **数据处理**：对收集的文本数据进行预处理，包括分词、去噪、清洗等操作。
3. **模型初始化**：初始化编码器和解码器，通常使用预训练好的基础模型（如BERT、GPT等）。
4. **预训练**：在大量文本数据上进行预训练，通过自我注意力机制和多层神经网络，模型逐渐学会捕捉文本的语义信息。

**微调阶段**：

1. **数据集准备**：准备用于微调的任务数据集，如问答数据集、文本分类数据集等。
2. **模型初始化**：在预训练好的模型基础上，初始化微调模型。
3. **微调**：在任务数据集上进行微调，通过梯度下降等优化方法，模型逐渐适应特定任务。


### 2.2.3 LLM的数学模型与公式

在LLM中，常用的数学模型包括自注意力机制（Self-Attention）和多层感知机（Multi-Layer Perceptron，MLP）。

**自注意力机制**：

自注意力机制是一种用于捕捉文本序列中重要信息的机制，其计算公式如下：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
$$

其中，Q、K、V分别为编码器的输入、键和值向量，$d_k$为键向量的维度，softmax函数用于计算每个键的加权和。

**多层感知机**：

多层感知机是一种前馈神经网络，用于对自注意力机制的计算结果进行非线性变换。其计算公式如下：

$$
\text{MLP}(x) = \text{ReLU}(\theta_2 \sigma(\theta_1 x))
$$

其中，$\sigma$为激活函数，$\theta_1$和$\theta_2$为权重矩阵。

### 2.2.4 LLM的优势与挑战

## 2.3 RL原理讲解

### 2.3.1 RL的基本概念

强化学习（Reinforcement Learning，简称RL）是一种机器学习方法，通过智能体与环境的交互来学习最优策略。在RL中，智能体（Agent）通过不断试错，从环境中获取奖励，并逐步优化其行为策略，以达到最大化长期回报的目标。

**主要概念**：

1. **智能体（Agent）**：执行动作并从环境中获取反馈的实体。
2. **环境（Environment）**：智能体所处的环境，包括状态空间、动作空间和奖励函数。
3. **状态（State）**：描述智能体当前所处的环境条件。
4. **动作（Action）**：智能体可以采取的动作。
5. **奖励（Reward）**：智能体在采取某个动作后，从环境中获得的即时回报。
6. **策略（Policy）**：智能体在给定状态下选择动作的规则或函数。
7. **价值函数（Value Function）**：评估智能体在特定状态下执行最佳策略所能获得的预期回报。
8. **模型（Model）**：描述环境状态转移概率和奖励函数的数学模型。

### 2.3.2 RL的常见算法

RL算法种类繁多，常见的包括以下几种：

1. **Q-Learning**：Q-Learning是一种基于值函数的算法，通过更新Q值（状态-动作值函数）来优化策略。其核心思想是：在给定状态下，选择使Q值最大的动作。
   
   **更新公式**：
   $$ Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)] $$
   
   其中，$\alpha$是学习率，$\gamma$是折扣因子，$r$是奖励。

2. **SARSA（On-Policy）**：SARSA是一种基于策略的算法，使用当前策略来选择动作，并根据实际执行的动作更新Q值。

   **更新公式**：
   $$ Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma Q(s', a')] - Q(s, a) $$
   
3. **Deep Q-Network（DQN）**：DQN是一种基于深度学习的RL算法，使用深度神经网络来近似Q值函数。DQN通过经验回放（Experience Replay）和目标网络（Target Network）来减少策略偏差和避免过度探索。

   **更新公式**：
   $$ Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)] $$
   
4. **Policy Gradient（PG）**：Policy Gradient算法直接优化策略概率分布，以最大化预期回报。常见的策略梯度方法包括REINFORCE和PPO。

   **REINFORCE更新公式**：
   $$ \theta \leftarrow \theta + \alpha \nabla_\theta \log \pi_\theta(a|s) R(s, a) $$
   
5. **Actor-Critic**：Actor-Critic算法结合了策略和值函数方法，通过优化Actor（策略）和Critic（值函数）来提高性能。Critic提供状态价值的估计，而Actor根据这个估计来更新策略。

   **Critic更新公式**：
   $$ V(s) \leftarrow V(s) + \alpha [r + \gamma V(s') - V(s)] $$
   
   **Actor更新公式**：
   $$ \theta \leftarrow \theta + \alpha \nabla_\theta J(\theta) $$
   
   其中，$J(\theta)$是策略的损失函数。

### 2.3.3 RL的数学模型与公式

RL的数学模型通常基于马尔可夫决策过程（MDP），包括状态空间$S$、动作空间$A$、状态转移概率$P(s'|s, a)$、奖励函数$R(s, a)$和价值函数$V(s)$。

**MDP模型**：

$$
\begin{align*}
S &= \{s_1, s_2, ..., s_n\} \quad \text{（状态空间）} \\
A &= \{a_1, a_2, ..., a_m\} \quad \text{（动作空间）} \\
P(s'|s, a) &= \text{状态转移概率} \\
R(s, a) &= \text{奖励函数} \\
V(s) &= \text{价值函数} \\
\end{align*}
$$

**价值函数**：

**状态价值函数**（$V(s)$）：
$$
V(s) = \sum_{a \in A} \pi(a|s) \sum_{s' \in S} P(s'|s, a) [R(s, a) + \gamma V(s')]
$$

**动作价值函数**（$Q(s, a)$）：
$$
Q(s, a) = \sum_{s' \in S} P(s'|s, a) [R(s, a) + \gamma V(s')]
$$

**策略**：
$$
\pi(a|s) = P(a|s) \propto Q(s, a)
$$

### 2.3.4 RL算法的应用场景

RL算法在多个领域有广泛的应用：

**游戏**：RL算法在电子游戏、棋类游戏等领域取得了显著成果，如AlphaGo和Dota2。

**自动驾驶**：自动驾驶系统使用RL算法来学习最佳驾驶策略，提高行驶的安全性和效率。

**机器人**：机器人通过RL算法来学习与人类交互、执行任务等。

**金融**：RL算法用于股票交易、风险控制等金融领域。

**医疗**：RL算法用于诊断、治疗建议等医疗决策支持。

### 2.3.5 RL的案例分析

**案例1：AlphaGo**

AlphaGo是由DeepMind开发的围棋AI，通过RL算法（主要使用策略网络和值网络）击败了人类围棋冠军。AlphaGo的成功展示了RL算法在复杂博弈中的潜力。

### 2.3.6 RL的优势与挑战

**优势**：

1. **自适应能力**：RL算法可以自动适应复杂和动态的环境，通过不断学习和优化策略来应对新的挑战。
2. **灵活性**：RL算法适用于多种任务，从简单的棋类游戏到复杂的自动驾驶系统。

**挑战**：

3. **计算资源消耗**：RL算法需要大量的计算资源，特别是在训练深度神经网络时。

### 2.3.7 总结

RL是一种通过智能体与环境的交互来学习最优策略的机器学习方法。它具有自适应能力、灵活性强等优点，但同时也面临数据效率、可解释性和计算资源消耗等挑战。RL在游戏、自动驾驶、机器人、金融和医疗等领域有广泛的应用，随着研究的深入，RL算法的效率和性能将不断提高。

## 2.4 self-play、LLM与RL融合算法

### 2.4.1 融合算法的设计思路

self-play、LLM与RL的融合算法旨在利用各自的优势，提高智能体在推理任务上的性能。融合算法的设计思路主要包括以下几个方面：

1. **自博弈训练**：利用self-play算法，让智能体与自身进行博弈，从而不断优化其策略。self-play的过程为智能体提供了一个自我学习和自我优化的环境，使其能够适应复杂的推理任务。
   
2. **LLM语言建模**：结合LLM的语言建模能力，将self-play过程中产生的数据用于训练LLM。通过大规模预训练和微调，LLM可以学会生成高质量的文本，并在推理任务中提供有效的语言支持。

3. **RL策略优化**：利用RL算法，进一步优化LLM的策略。在RL的框架下，智能体可以通过与环境或其他智能体进行交互，学习如何在不同情境下做出最佳决策。

### 2.4.2 融合算法的流程图

融合算法的流程图如下：

具体流程如下：

3. **LLM训练**：使用self-play过程中产生的数据集，对LLM进行大规模预训练和微调。
4. **RL优化**：利用RL算法，进一步优化LLM的策略，使其在不同情境下表现更佳。
5. **推理**：使用优化后的策略，进行推理任务。

### 2.4.3 融合算法的数学模型与公式

融合算法的数学模型可以结合self-play、LLM和RL的数学模型进行构建。

其中，$\theta_{t+1}^{self-play}$、$\theta_{t+1}^{LLM}$和$\theta_{t+1}^{RL}$分别表示self-play、LLM和RL算法在下一个时间步的参数更新。

### 2.4.4 融合算法的优势与不足

**优势**：

1. **多模态学习**：融合算法可以将self-play的博弈经验、LLM的语言建模能力和RL的策略优化相结合，实现多模态学习，提高推理任务的性能。

## 2.5 算法比较与分析

### 2.5.1 self-play与LLM的比较

**self-play**和**LLM**都是人工智能领域的核心技术，但它们在原理和应用上有所不同。

**原理差异**：

1. **self-play**：self-play是一种强化学习方法，通过智能体与自身或环境的交互来学习策略。它侧重于博弈、决策和探索，不需要外部数据集，但需要大量的计算资源。
2. **LLM**：LLM是一种基于深度学习的自然语言处理模型，通过大规模预训练和微调来学习语言模式和生成文本。它侧重于语言理解和生成，需要大量高质量的数据集，但计算资源需求相对较低。

**应用差异**：

1. **self-play**：self-play广泛应用于游戏、策略优化和模拟交易等领域，如围棋、象棋和电子游戏等。它能够通过自我对弈不断优化策略，提高智能体在特定任务上的表现。
2. **LLM**：LLM广泛应用于文本生成、问答系统、机器翻译和文本分类等领域。它能够生成高质量的自然语言文本，并在多种自然语言处理任务中表现出色。

**优势对比**：

- **self-play**：具有自我优化和灵活性的优势，能够适应复杂的博弈环境和动态变化的任务。
- **LLM**：具有强大的语言理解和生成能力，能够处理多种语言任务，生成高质量的自然语言文本。

**劣势对比**：

- **self-play**：计算资源消耗大，训练时间较长，且易陷入局部最优。
- **LLM**：对数据集的要求较高，数据稀缺或数据质量差时，性能可能会受到较大影响。

### 2.5.2 LLM与RL的比较

**LLM**和**RL**都是人工智能领域的重要技术，但它们的关注点和应用场景有所不同。

**原理差异**：

1. **LLM**：LLM是一种基于深度学习的自然语言处理模型，通过大规模预训练和微调来学习语言模式和生成文本。它侧重于语言理解和生成，能够处理多种语言任务。
2. **RL**：RL是一种通过智能体与环境交互来学习策略的强化学习方法。它侧重于决策、探索和优化，能够适应复杂的动态环境。

**应用差异**：

1. **LLM**：广泛应用于文本生成、问答系统、机器翻译和文本分类等领域。例如，GPT-3可以生成高质量的自然语言文本，BERT可以用于问答系统和文本分类。
2. **RL**：广泛应用于游戏、自动驾驶、机器人控制和金融交易等领域。例如，AlphaGo在围棋游戏中战胜了人类冠军，自动驾驶系统使用RL来学习最佳驾驶策略。

**优势对比**：

- **LLM**：具有强大的语言理解和生成能力，能够生成高质量的自然语言文本，适应多种自然语言处理任务。
- **RL**：能够适应复杂的动态环境，通过探索和优化策略来提高智能体在特定任务上的表现。

**劣势对比**：

- **LLM**：对数据集的要求较高，数据稀缺或数据质量差时，性能可能会受到较大影响。另外，模型的计算资源需求较大。
- **RL**：训练时间较长，计算资源消耗大，且智能体的决策过程通常难以解释。

### 2.5.3 self-play、LLM与RL融合的优势与不足

**融合优势**：

1. **多模态学习**：融合算法可以将self-play的博弈经验、LLM的语言建模能力和RL的策略优化相结合，实现多模态学习，提高推理任务的性能。
2. **自适应优化**：融合算法可以根据不同情境动态调整策略，提高智能体的适应能力。
3. **高效推理**：通过融合算法，智能体可以快速生成高质量的推理结果，提高推理效率。

**融合不足**：

1. **计算资源消耗**：融合算法需要同时运行self-play、LLM和RL算法，计算资源消耗较大。
2. **模型复杂度**：融合算法的模型结构较为复杂，设计和实现难度较高。
3. **数据需求**：融合算法需要大量高质量的数据进行训练，数据获取和处理成本较高。

### 2.5.4 比较与分析总结

通过上述比较，我们可以看出self-play、LLM和RL各有优势和不足，融合算法在一定程度上可以弥补这些不足。融合算法在多模态学习、自适应优化和高效推理方面具有显著优势，但在计算资源消耗、模型复杂度和数据需求方面存在挑战。未来，我们需要进一步探索如何优化融合算法，提高其性能和应用效果。

```python
import numpy as np
import random

class SelfPlay:
    def __init__(self, model, env, epsilon=0.1):
        self.model = model
        self.env = env
        self.epsilon = epsilon
    
    def choose_action(self, state):
        if random.random() < self.epsilon:
            action = random.choice(self.env.action_space)
        else:
            action = self.model.predict(state)
        return action
    
    def train(self, episodes):
        for episode in range(episodes):
            state = self.env.reset()
            done = False
            total_reward = 0
            
            while not done:
                action = self.choose_action(state)
                next_state, reward, done = self.env.step(action)
                self.model.train(state, action, next_state, reward)
                state = next_state
                total_reward += reward
            
            print(f"Episode {episode}: Total Reward {total_reward}")
```

```python
import torch
import torch.optim as optim

class PolicyOptimizer:
    def __init__(self, model, learning_rate=0.001):
        self.model = model
        self.optimizer = optim.Adam(self.model.parameters(), lr=learning_rate)
    
    def train(self, states, actions, rewards, next_states):
        self.model.zero_grad()
        state_values = self.model.predict(states)
        next_state_values = self.model.predict(next_states)
        
        expected_values = []
        for i in range(len(states)):
            reward = rewards[i]
            done = 1 if i == len(states) - 1 else 0
            expected_value = reward + (1 - done) * next_state_values[i]
            expected_values.append(expected_value)
        
        expected_values = torch.tensor(expected_values).to('cuda')
        loss = torch.nn.functional.smooth_l1_loss(state_values, expected_values)
        loss.backward()
        self.optimizer.step()
```
