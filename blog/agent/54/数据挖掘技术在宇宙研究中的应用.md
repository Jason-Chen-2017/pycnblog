#### 3.1 K-均值聚类算法

K-均值聚类算法是一种迭代算法，它通过逐步优化聚类中心，将相似的数据点归为同一类别。以下是K-均值算法的基本步骤：

1. **初始化聚类中心**：随机选择K个数据点作为初始聚类中心。
2. **分配数据点**：计算每个数据点到每个聚类中心的距离，将每个数据点分配到距离最近的聚类中心所代表的类别。
3. **更新聚类中心**：计算每个类别的质心（所有数据点的平均值），用新的质心替换原来的聚类中心。
4. **重复步骤2和3**：重复迭代，直到聚类中心的变化小于某个阈值或达到最大迭代次数。

**数学模型：**

$$
\text{聚类中心} = \frac{1}{N} \sum_{i=1}^{N} x_i
$$

其中，\( x_i \)是数据点，\( N \)是数据点总数。

**Python代码实现：**

```python
import numpy as np

def k_means(data, k, max_iterations=100, tolerance=1e-4):
    # 初始化聚类中心
    centroids = data[np.random.choice(data.shape[0], k, replace=False)]
    
    for _ in range(max_iterations):
        # 分配数据点
        distances = np.linalg.norm(data - centroids, axis=1)
        labels = np.argmin(distances, axis=1)
        
        # 更新聚类中心
        new_centroids = np.array([data[labels == i].mean(axis=0) for i in range(k)])
        
        # 判断收敛条件
        if np.linalg.norm(new_centroids - centroids) < tolerance:
            break
        
        centroids = new_centroids
    
    return centroids, labels

# 示例数据
data = np.array([[1, 2], [1, 4], [1, 0], [10, 2], [10, 4], [10, 0]])

# K-均值聚类
centroids, labels = k_means(data, k=2)

print("聚类中心：", centroids)
print("数据点标签：", labels)
```

**示例讲解：**

假设我们有6个二维数据点，我们要将它们分为两类。首先随机选择两个数据点作为初始聚类中心。然后计算每个数据点到两个聚类中心的距离，将数据点分配到距离最近的聚类中心。接下来，计算每个类别的质心，并用新的质心替换原来的聚类中心。这个过程不断迭代，直到聚类中心的变化小于某个阈值。最后，我们得到了聚类中心和数据点的标签。

#### 3.2 决策树算法

决策树是一种树形结构，每个内部节点表示一个特征，每个分支表示该特征的取值，每个叶子节点表示一个类。决策树通过选择最优特征来划分数据，目的是使每个子集的类内方差最小。以下是决策树的基本步骤：

1. **选择特征**：计算每个特征的增益或信息增益，选择增益最大的特征作为节点。
2. **划分数据**：根据选择的特征，将数据集划分为不同的子集。
3. **递归构建**：对每个子集，重复上述步骤，直到满足停止条件（如最大深度、最小样本量等）。

**数学模型：**

信息增益（Information Gain）：

$$
IG(D, A) = H(D) - \sum_{v \in Values(A)} p(v) H(D_v)
$$

其中，\( H(D) \)是数据集\( D \)的熵，\( p(v) \)是特征\( A \)的取值\( v \)的频率，\( H(D_v) \)是条件熵。

**Python代码实现：**

```python
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier
import matplotlib.pyplot as plt

# 加载Iris数据集
iris = load_iris()
X = iris.data
y = iris.target

# 构建决策树模型
clf = DecisionTreeClassifier()
clf.fit(X, y)

# 绘制决策树
from sklearn.tree import plot_tree
plt.figure(figsize=(12, 12))
plot_tree(clf, filled=True, feature_names=iris.feature_names, class_names=iris.target_names)
plt.show()
```

**示例讲解：**

我们以Iris数据集为例，使用决策树算法对其进行分类。首先选择最优特征，然后根据该特征划分数据集。这个过程递归进行，直到满足停止条件。最后，我们得到了一个决策树模型，并用它进行分类预测。

#### 3.3 随机森林算法

随机森林（Random Forest）是一种集成学习方法，它通过构建多个决策树，并合并它们的预测结果来提高模型的准确性。随机森林的基本步骤如下：

1. **随机选择特征**：每次构建决策树时，从所有特征中随机选择一部分特征。
2. **构建决策树**：使用选择的特征构建决策树。
3. **合并预测结果**：对每个样本，计算所有决策树的预测结果，并取多数投票结果作为最终预测。

**数学模型：**

随机森林的准确性由以下公式给出：

$$
Accuracy = \frac{1}{N} \sum_{i=1}^{N} I(y_i = \hat{y}_i)
$$

其中，\( y_i \)是实际标签，\( \hat{y}_i \)是预测标签，\( I() \)是指标函数。

**Python代码实现：**

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris

# 加载Iris数据集
iris = load_iris()
X = iris.data
y = iris.target

# 构建随机森林模型
clf = RandomForestClassifier(n_estimators=100)
clf.fit(X, y)

# 预测
predictions = clf.predict(X)

# 计算准确率
accuracy = clf.score(X, y)
print("准确率：", accuracy)
```

**示例讲解：**

我们同样以Iris数据集为例，使用随机森林算法进行分类。首先随机选择特征，然后构建多个决策树。最后，合并这些决策树的预测结果，得到最终预测。随机森林通常比单个决策树有更好的性能和泛化能力。

**源代码解读：**

```python
import numpy as np
import pandas as pd
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

# 读取宇宙射线数据
def read_data(file_path):
    data = pd.read_csv(file_path)
    return data

# 数据预处理
def preprocess_data(data):
    # 填充缺失值
    data = data.fillna(data.mean())
    # 数据标准化
    data = (data - data.mean()) / data.std()
    return data

# K-均值聚类
def k_means_clustering(data, k):
    kmeans = KMeans(n_clusters=k, init='k-means++', random_state=42)
    kmeans.fit(data)
    return kmeans

# 结果分析
def analyze_results(kmeans, data):
    labels = kmeans.predict(data)
    centroids = kmeans.cluster_centers_
    print("聚类中心：", centroids)
    print("数据点标签：", labels)

    # 可视化聚类结果
    plt.scatter(data[:, 0], data[:, 1], c=labels, cmap='viridis')
    plt.scatter(centroids[:, 0], centroids[:, 1], c='red', marker='x')
    plt.xlabel('特征1')
    plt.ylabel('特征2')
    plt.title('K-均值聚类结果')
    plt.show()

# 主函数
def main():
    file_path = 'cosmic_rays_data.csv'
    data = read_data(file_path)
    data = preprocess_data(data)
    k = 3  # 聚类类别数
    kmeans = k_means_clustering(data, k)
    analyze_results(kmeans, data)

if __name__ == '__main__':
    main()
```

**代码应用分析：**

1. **数据读取**：我们使用Pandas库从CSV文件中读取宇宙射线数据。数据文件应包含多个特征，每个特征表示宇宙射线的某个属性。

2. **数据预处理**：首先，我们使用`fillna`函数填充缺失值，以避免数据挖掘过程中出现错误。然后，我们使用标准化处理，将每个特征缩放到相同的尺度，以便K-均值聚类算法能够有效地工作。

3. **K-均值聚类**：我们使用Scikit-learn库中的`KMeans`类来实例化K-均值聚类对象。我们选择初始化方法为'k-means++'，这有助于初始聚类中心的选择。

4. **结果分析**：我们首先打印出聚类中心，然后使用Matplotlib库将聚类结果可视化。每个类别用不同的颜色表示，聚类中心用红色交叉标记。
