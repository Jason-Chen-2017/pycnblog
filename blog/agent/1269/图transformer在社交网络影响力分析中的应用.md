### 第2章：核心概念与理论基础

#### 2.1 图Transformer的基本原理

图Transformer的核心包括自注意力机制和交互层结构。自注意力机制是一种在序列模型中广泛应用的技术，它允许模型在处理每个元素时考虑到其他元素的影响。在图Transformer中，自注意力机制被用来处理图数据，从而捕捉节点之间的复杂关系。

自注意力机制的基本思想是将每个节点的表示与所有其他节点的表示进行加权求和。具体来说，假设图中有 $N$ 个节点，每个节点的表示为 $x_i \in \mathbb{R}^d$，其中 $i=1,2,\ldots,N$。自注意力机制的目标是计算一个权重矩阵 $A \in \mathbb{R}^{d\times d}$，使得每个节点 $i$ 的表示 $h_i$ 能够综合考虑其他节点的信息：

$$
h_i = \text{softmax}(A \cdot x_i),
$$

其中，$\text{softmax}$ 函数用于将加权求和的结果转换为概率分布。

交互层结构则进一步扩展了自注意力机制，它不仅考虑节点之间的直接关系，还考虑了通过邻居节点的间接关系。具体来说，交互层结构包括两个子层：一个是内部交互层，用于整合节点及其邻居的信息；另一个是外部交互层，用于处理跨层的交互关系。通过这两个交互层，图Transformer能够更好地捕捉图数据中的复杂结构。

#### 4.2 性能评测

性能评测是评估图Transformer模型在社交网络影响力分析中效果的重要手段。以下将介绍常用的评测指标和评估方法：

##### 4.2.1 评测指标

在社交网络影响力分析中，常用的评测指标包括：

1. **准确率（Accuracy）**：准确率是分类问题中最基本的评价指标，计算公式为：
   $$
   \text{Accuracy} = \frac{\text{预测正确的样本数}}{\text{总样本数}}。
   $$
   准确率越高，表示模型对影响力评估的准确性越高。

2. **召回率（Recall）**：召回率是指模型能够召回所有实际影响力用户的比例，计算公式为：
   $$
   \text{Recall} = \frac{\text{预测正确的影响力用户数}}{\text{实际影响力用户数}}。
   $$
   召回率越高，表示模型能够识别出更多的实际影响力用户。

3. **精确率（Precision）**：精确率是指预测影响力用户中实际影响力用户的比例，计算公式为：
   $$
   \text{Precision} = \frac{\text{预测正确的影响力用户数}}{\text{预测的影响力用户数}}。
   $$
   精确率越高，表示模型预测的影响力用户越准确。

4. **F1值（F1-score）**：F1值是精确率和召回率的加权平均，计算公式为：
   $$
   \text{F1-score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}。
   $$
   F1值综合考虑了精确率和召回率，是评估影响力评估模型效果的重要指标。

##### 4.2.2 评测方法

性能评测通常包括以下方法：

1. **交叉验证**：交叉验证是一种常用的评估方法，通过将数据集划分为多个子集，轮流将每个子集作为测试集，其余子集作为训练集，进行多次训练和测试，从而获得模型的综合性能评估。

2. **混淆矩阵**：混淆矩阵是一种直观地展示模型预测结果与实际结果之间关系的工具。通过混淆矩阵，可以计算出准确率、召回率、精确率和F1值等指标。

3. **ROC曲线和AUC值**：ROC曲线（Receiver Operating Characteristic Curve）和AUC值（Area Under the Curve）是评估分类模型性能的重要指标。ROC曲线展示了模型在不同阈值下的准确率和召回率，而AUC值则反映了模型的分类能力。

通过以上评测方法，可以全面评估图Transformer模型在社交网络影响力分析中的性能，从而为模型的优化和改进提供依据。

import torch
import torch.nn as nn
import torch.optim as optim
from torch_geometric.nn import GATConv

# 定义图Transformer模型
class GraphTransformer(nn.Module):
    def __init__(self, num_features, hidden_channels, num_classes):
        super(GraphTransformer, self).__init__()
        self.conv1 = GATConv(num_features, hidden_channels)
        self.conv2 = GATConv(hidden_channels, hidden_channels)
        self.fc = nn.Linear(hidden_channels, num_classes)

    def forward(self, data):
        x, edge_index = data.x, data.edge_index

        x = self.conv1(x, edge_index)
        x = nn.functional.relu(x)
        x = self.conv2(x, edge_index)
        x = nn.functional.dropout(x, p=0.5)
        x = self.fc(x)

        return x

# 模型训练代码
model = GraphTransformer(num_features=768, hidden_channels=256, num_classes=2)
optimizer = optim.Adam(model.parameters(), lr=0.001)
criterion = nn.CrossEntropyLoss()

for epoch in range(200):
    model.train()
    optimizer.zero_grad()
    out = model(data)
    loss = criterion(out, data.y)
    loss.backward()
    optimizer.step()

    if (epoch + 1) % 10 == 0:
        print(f'Epoch {epoch + 1}: Loss = {loss.item()}')

model.eval()
with torch.no_grad():
    pred = model(data)
    acc = (pred.argmax(dim=1) == data.y).sum().item() / len(data)
    print(f'Accuracy: {acc}')
