##### 3.1 图Transformer的数学模型

图Transformer的数学模型主要包括输入层、变换器层和输出层。

1. **输入层**：图Transformer的输入是一个图结构数据，包括节点和边。每个节点和边都可以表示为向量，用于描述节点的特征和边的关系。
   
   \[
   G = (V, E)
   \]

   其中，\(V\) 表示节点集合，\(E\) 表示边集合。

2. **变换器层**：图Transformer通过多层变换器层对图数据进行特征变换和聚合。每一层的变换器层包括多头自注意力机制、前馈网络和层归一化。

   \[
   h^{(l)} = \text{LayerNorm}(h^{(l-1)} + \text{MultiHeadSelfAttention}(h^{(l-1)}))
   \]

   \[
   h^{(l)} = \text{LayerNorm}(h^{(l)} + \text{PositionwiseFeedForward}(h^{(l)}))
   \]

   其中，\(h^{(l)}\) 表示第 \(l\) 层的输出，\(\text{MultiHeadSelfAttention}\) 表示多头自注意力机制，\(\text{PositionwiseFeedForward}\) 表示前馈网络。

3. **输出层**：在最终的输出层，图Transformer会根据特定任务的需求生成预测结果，如节点分类、边预测等。

   \[
   \hat{y} = \text{OutputLayer}(h^{(L)})
   \]

   其中，\(\hat{y}\) 表示预测结果，\(h^{(L)}\) 表示最后一层的输出，\(\text{OutputLayer}\) 表示输出层。

##### 3.2 图Transformer的算法实现

图Transformer的算法实现主要分为以下几个步骤：

1. **图编码**：将图中的节点和边编码为向量表示。常见的图编码方法包括节点嵌入（Node Embedding）和图嵌入（Graph Embedding）。
   
   \[
   x_i = \text{NodeEmbedding}(i)
   \]

   \[
   e_{ij} = \text{EdgeEmbedding}(i, j)
   \]

2. **自注意力计算**：计算节点之间的注意力权重，并生成加权特征向量。

   \[
   a_{ij} = \text{Attention}(x_i, x_j)
   \]

   \[
   h_i = \sum_{j \in N(i)} a_{ij} x_j
   \]

3. **特征变换和聚合**：通过多层变换器层对图数据进行特征变换和聚合。

   \[
   h^{(l)} = \text{LayerNorm}(h^{(l-1)} + \text{MultiHeadSelfAttention}(h^{(l-1)}))
   \]

   \[
   h^{(l)} = \text{LayerNorm}(h^{(l)} + \text{PositionwiseFeedForward}(h^{(l)}))
   \]

4. **预测结果生成**：在最终的输出层，根据特定任务的需求生成预测结果。

   \[
   \hat{y} = \text{OutputLayer}(h^{(L)})
   \]

    def __init__(self, input_dim, hidden_dim, output_dim):

        self.feedforward = nn.Sequential(nn.Linear(hidden_dim, hidden_dim * 2), nn.ReLU(), nn.Linear(hidden_dim * 2, hidden_dim))

        node_embeddings = nn.Embedding(input_dim, hidden_dim)(nodes)

        attn_output, _ = self.self_attention(node_embeddings, node_embeddings, node_embeddings)

        transformed_nodes = attn_output + node_embeddings
        transformed_nodes = self.feedforward(transformed_nodes)
        
        # Prediction
