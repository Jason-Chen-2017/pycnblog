#### 第2章 人工智能概述

##### 2.1 人工智能的定义与发展历程

人工智能（Artificial Intelligence，简称AI）是一种通过模拟人类智能行为，实现自动化决策和智能任务执行的技术。其核心目标是在没有人类干预的情况下，使计算机系统能够自主学习、推理和解决问题。人工智能的定义可以从多个角度进行理解，主要包括模拟人类思维过程、实现自主学习和具有智能行为三个方面。

人工智能的发展历程可以追溯到20世纪50年代。当时，随着计算机技术的起步，一些科学家开始探索如何使计算机表现出类似人类的智能。1956年，在达特茅斯会议上，约翰·麦卡锡（John McCarthy）等人首次提出了“人工智能”这一术语，标志着人工智能作为一个独立学科的开始。此后，人工智能经历了多个发展阶段：

1. **初始阶段（1956-1969年）**：这一阶段主要集中于符号主义方法，即通过符号表示和逻辑推理来实现人工智能。代表性的工作是艾伦·图灵（Alan Turing）提出的“图灵测试”，用于评估机器是否具有人类智能。

2. **繁荣阶段（1970-1980年）**：由于符号主义方法在处理复杂问题时遇到困难，人工智能研究开始转向启发式搜索和知识表示。这一阶段出现了许多重要成果，如专家系统（Expert Systems）的提出，该系统能够模拟人类专家的决策过程。

3. **低谷阶段（1980-1990年）**：由于实际应用中的问题难以解决，加上计算能力的限制，人工智能研究进入低谷。许多研究机构和公司纷纷缩减或停止了对人工智能的投资。

4. **复兴阶段（1990年至今）**：随着计算能力的提升和大数据技术的发展，人工智能迎来了新一轮的繁荣。深度学习、强化学习等新方法的出现，使得人工智能在图像识别、语音识别、自然语言处理等领域取得了突破性进展。

在人工智能的发展过程中，核心技术不断演变和更新。目前，人工智能的主要核心技术包括：

1. **机器学习（Machine Learning）**：通过从数据中学习规律和模式，实现自动化的决策和预测。机器学习包括监督学习、无监督学习和强化学习等不同的学习方法。

2. **深度学习（Deep Learning）**：基于人工神经网络，通过多层次的神经网络结构，实现对复杂数据的自动特征提取和模式识别。深度学习在图像识别、语音识别和自然语言处理等领域取得了显著成果。

3. **自然语言处理（Natural Language Processing，NLP）**：通过对自然语言的文本进行分析和处理，实现人与计算机的交互。NLP技术包括词向量表示、语言模型、文本分类和语义理解等。

4. **计算机视觉（Computer Vision）**：通过计算机对图像和视频进行理解，实现对视觉信息的自动识别和处理。计算机视觉技术在自动驾驶、医疗影像分析等领域具有广泛的应用。

5. **强化学习（Reinforcement Learning）**：通过与环境的互动，学习最优策略，实现智能决策。强化学习在游戏、机器人控制等领域表现出色。

总之，人工智能的发展历程和核心技术不断推动着这一领域的进步。通过机器学习、深度学习、自然语言处理等技术的应用，人工智能在药物发现等多个领域展现出了巨大的潜力和应用价值。

##### 2.2 人工智能的核心技术

人工智能的核心技术涵盖了多个领域，包括机器学习、深度学习、自然语言处理等，每一种技术都有其独特的原理和应用场景。下面我们将逐一介绍这些核心技术，并探讨它们在人工智能中的重要性。

**1. 机器学习（Machine Learning）**

机器学习是人工智能的一个重要分支，它通过构建数学模型，从数据中学习规律和模式，实现自动化的决策和预测。机器学习可以分为监督学习、无监督学习和强化学习三种类型。

- **监督学习（Supervised Learning）**：监督学习是一种在有标注数据的情况下进行学习的方法。其目标是找到一个函数，将输入特征映射到已知的输出结果。常用的监督学习算法包括线性回归、决策树、支持向量机（SVM）和随机森林等。

- **无监督学习（Unsupervised Learning）**：无监督学习是在没有标注数据的情况下进行学习的方法。其主要目标是发现数据中的隐含结构和规律，常见的无监督学习算法包括聚类（如K-means、层次聚类）、降维（如PCA、t-SNE）和关联规则学习（如Apriori算法）等。

- **强化学习（Reinforcement Learning）**：强化学习是一种通过与环境的互动，学习最优策略的方法。其核心在于通过奖励和惩罚机制，不断调整策略，以最大化累积奖励。常见的强化学习算法包括Q学习、深度Q网络（DQN）和策略梯度算法等。

机器学习在人工智能中的应用非常广泛，包括图像识别、语音识别、自然语言处理、推荐系统等。它为人工智能提供了强大的数据处理和模式识别能力，是实现自动化和智能化决策的基础。

**2. 深度学习（Deep Learning）**

深度学习是机器学习的一个子领域，它基于人工神经网络，通过多层次的神经网络结构，实现对复杂数据的自动特征提取和模式识别。深度学习的关键在于“深度”，即网络的层次结构，这有助于网络从原始数据中提取更高级别的抽象特征。

- **卷积神经网络（Convolutional Neural Network，CNN）**：CNN是一种用于图像识别和处理的神经网络架构，其通过卷积层、池化层和全连接层，实现对图像的逐层特征提取。CNN在计算机视觉领域取得了巨大的成功，被广泛应用于图像分类、目标检测和图像分割等任务。

- **循环神经网络（Recurrent Neural Network，RNN）**：RNN是一种用于处理序列数据的神经网络架构，其通过记忆单元，实现序列数据的时序建模。RNN在自然语言处理、语音识别和时间序列分析等领域表现出色。

- **生成对抗网络（Generative Adversarial Network，GAN）**：GAN是一种由生成器和判别器组成的对抗性神经网络。生成器试图生成逼真的数据，而判别器则判断生成的数据是否真实。GAN在图像生成、数据增强和异常检测等方面具有广泛的应用。

深度学习的发展极大地推动了人工智能的进步，特别是在图像识别、语音识别和自然语言处理等领域的突破，为人工智能的应用提供了强大的技术支持。

**3. 自然语言处理（Natural Language Processing，NLP）**

自然语言处理是人工智能中的一个重要分支，它致力于使计算机理解和处理人类自然语言。NLP涵盖了多个技术领域，包括词向量表示、语言模型、文本分类和语义理解等。

- **词向量表示（Word Embedding）**：词向量表示是将单词映射到高维空间中的向量表示，用于捕捉单词的语义信息。常见的词向量表示方法包括Word2Vec、GloVe和FastText等。

- **语言模型（Language Model）**：语言模型是一种用于预测文本序列的概率分布的模型。基于语言模型，可以进行文本生成、机器翻译和语音识别等任务。常用的语言模型包括n-gram模型、神经网络语言模型（如RNN、LSTM）和Transformer等。

- **文本分类（Text Classification）**：文本分类是一种将文本数据分类到预定义类别的方法。常用的文本分类算法包括朴素贝叶斯、支持向量机和深度学习（如CNN、LSTM）等。

- **语义理解（Semantic Understanding）**：语义理解是NLP的核心目标，即理解文本中的语义含义。语义理解包括实体识别、关系抽取和文本生成等任务。

自然语言处理技术的发展，使得计算机能够更好地理解人类语言，为智能助手、搜索引擎和机器翻译等应用提供了基础。

**4. 强化学习（Reinforcement Learning）**

强化学习是人工智能中的一个重要方向，它通过智能体与环境的互动，学习最优策略，实现智能决策。强化学习主要分为基于值函数的方法和基于策略的方法。

- **基于值函数的方法**：基于值函数的方法，如Q学习，通过学习状态-动作值函数，确定最优动作。Q学习的核心思想是利用奖励和惩罚来调整值函数，使其能够最大化累积奖励。

- **基于策略的方法**：基于策略的方法，如策略梯度算法，通过直接学习策略函数，确定最优动作。策略梯度算法的核心思想是调整策略参数，使其能够最大化期望回报。

强化学习在游戏、机器人控制、推荐系统等领域具有广泛的应用。例如，深度强化学习算法（如DQN、PPO）在围棋、国际象棋等游戏中取得了与人类水平相当的表现。

**总结**

人工智能的核心技术包括机器学习、深度学习、自然语言处理和强化学习等，每一种技术都有其独特的原理和应用场景。这些核心技术的不断发展和创新，推动了人工智能在各个领域的应用和突破。通过理解这些核心技术，我们可以更好地把握人工智能的发展趋势，并为其在药物发现等领域的应用提供有力支持。

#### 第3章 药物发现概述

##### 3.1 药物发现的过程与挑战

药物发现是一个复杂而漫长的过程，通常包括以下几个主要阶段：药物靶点识别、药物筛选、先导化合物优化、临床试验和上市审批。每个阶段都有其独特的挑战和关键技术。

**1. 药物靶点识别**

药物靶点识别是药物发现的第一步，目标是确定能够与药物作用并产生治疗效果的生物分子。这一过程通常依赖于生物学和化学方法，如基因敲除、蛋白质纯化、分子对接等。挑战在于：

- **复杂性**：生物系统非常复杂，涉及多种生物分子和相互作用，难以准确预测哪些分子会成为有效的药物靶点。
- **多样性**：生物分子种类繁多，靶点识别需要处理大量的数据，并且需要对不同类型的生物分子进行深入分析。
- **特异性**：药物靶点识别需要确保药物与靶点的结合具有高特异性，以减少对非靶点的副作用。

**2. 药物筛选**

药物筛选是在确定药物靶点后，从大量的化合物中筛选出具有潜在治疗效果的候选药物。这一过程通常包括高通量筛选（HTS）和虚拟筛选（VS）等方法。挑战包括：

- **高成本和高时间消耗**：药物筛选过程涉及大量的实验和计算，需要大量的资金和时间投入。
- **化合物多样性**：化合物的种类繁多，需要高效的筛选方法来快速识别潜在的候选药物。
- **伪阳性问题**：高通量筛选可能会产生大量的伪阳性结果，需要进一步验证和筛选。

**3. 先导化合物优化**

先导化合物优化是将筛选出的候选药物进行结构改造，以改善其药理性质和降低副作用。这一过程通常包括结构优化、药代动力学优化和毒理学评估等。挑战包括：

- **化学合成复杂性**：先导化合物的优化通常涉及复杂的化学反应，需要专业的化学知识和技能。
- **药物代谢与毒性**：优化的药物需要具有良好的药代动力学特性和低毒性，这对化合物的设计提出了严格的要求。
- **多目标优化**：药物优化需要在多种属性之间进行权衡，如活性、稳定性、溶解度和毒性等。

**4. 临床试验**

临床试验是药物发现过程中的关键阶段，用于评估候选药物的安全性和有效性。这一过程通常分为三个阶段：I期临床试验、II期临床试验和III期临床试验。挑战包括：

- **样本数量与多样性**：临床试验需要足够的样本数量和多样化的患者群体，以确保结果的可靠性和代表性。
- **临床试验设计**：临床试验的设计需要科学合理，以确保能够准确评估药物的效果和安全性。
- **伦理问题**：临床试验的伦理问题不容忽视，如患者隐私保护、知情同意等。

**5. 上市审批**

上市审批是药物最终能够进入市场销售的必要步骤，通常需要提交大量的数据和报告，通过监管机构的审批。挑战包括：

- **数据完整性**：上市审批需要提供完整、可靠的数据，以证明药物的安全性和有效性。
- **审批流程**：上市审批的流程复杂，需要经过多个环节的审查和验证。

##### 3.3 传统药物发现方法与局限性

传统的药物发现方法主要包括基于经验的筛选、高通量筛选（HTS）、药物化学设计等，这些方法虽然在药物研发中发挥了重要作用，但也存在显著的局限性。

**1. 基于经验的筛选**

基于经验的筛选是药物发现的传统方法之一，它依赖于科学家对生物系统和药物作用机制的深入了解，通过实验筛选出具有潜在活性的化合物。这种方法的主要局限性包括：

- **依赖人工判断**：基于经验的筛选高度依赖科学家的主观判断，存在较大的主观性和不确定性。
- **低效率**：这种方法需要大量的实验和化合物，筛选过程耗时且耗资巨大。
- **局限性**：基于经验的筛选往往局限于已有的知识和数据，难以发现全新的药物靶点和化合物。

**2. 高通量筛选（HTS）**

高通量筛选（HTS）是一种在短时间内对大量化合物进行筛选的方法，通过自动化仪器和生物传感器，显著提高了筛选速度和精度。然而，HTS也存在以下局限性：

- **伪阳性问题**：HTS可能会产生大量的伪阳性结果，这些结果在实际应用中可能无效，需要进一步验证和筛选。
- **高通量筛选的高成本**：高通量筛选需要大量的设备和实验材料，增加了研发成本。
- **筛选后的进一步优化**：高通量筛选只是药物发现的第一步，筛选出的化合物还需要进行进一步的结构优化和活性评估。

**3. 药物化学设计**

药物化学设计是一种基于计算机模拟和分子对接技术，设计具有特定药理活性的化合物的方法。这种方法的主要局限性包括：

- **计算资源需求**：药物化学设计需要大量的计算资源，特别是在处理复杂分子时，计算时间较长。
- **设计结果的验证**：设计出的化合物需要通过实验验证其活性、稳定性和毒性等特性，验证过程耗时且耗资巨大。
- **化学合成的复杂性**：药物化学设计通常涉及复杂的化学反应和合成路径，需要专业的化学知识和技能。

**4. 传统药物发现方法的局限性**

综上所述，传统药物发现方法在药物研发中发挥了重要作用，但也存在显著的局限性。首先，这些方法高度依赖人工判断和经验，效率较低，且难以发现全新的药物靶点和化合物。其次，高通量筛选虽然提高了筛选速度和精度，但存在伪阳性问题和高成本。最后，药物化学设计需要大量的计算资源和实验验证，且设计结果的可靠性存在一定的不确定性。

##### 5.1 随机森林算法

随机森林（Random Forest）是一种集成学习方法，它通过构建多棵决策树，并对它们的预测结果进行投票来获得最终预测结果。随机森林在药物发现中具有广泛的应用，特别是在药物筛选和药物设计过程中。

**算法原理**

随机森林的核心是随机决策树，每个决策树都是基于随机特征集进行划分，这些特征集是从全部特征中随机抽取的。随机森林的算法步骤如下：

1. **特征选择**：从所有特征中随机选择一个子集。
2. **构建决策树**：使用选择好的特征子集构建决策树，每个决策树都是独立的。
3. **集成投票**：将每个决策树的预测结果进行投票，得到最终预测结果。

随机森林算法具有以下优点：

- **高准确性和鲁棒性**：由于多个决策树的集成，随机森林能够减少个别决策树的过拟合，提高整体预测准确性。
- **无需特征标准化**：随机森林对特征的处理较为鲁棒，不需要对特征进行标准化处理。
- **可解释性**：每个决策树都能够提供一定的可解释性，有助于理解模型的工作原理。

**应用场景**

1. **药物筛选**：随机森林可以用于药物筛选过程中，通过对药物分子特征进行分类或回归分析，快速识别出具有潜在活性的药物分子。
2. **药物设计**：在药物设计过程中，随机森林可以用于优化药物分子结构，提高其药理活性和稳定性。

**示例代码**

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris

# 载入鸢尾花数据集
iris = load_iris()
X, y = iris.data, iris.target

# 创建随机森林分类器
clf = RandomForestClassifier(n_estimators=100, random_state=0)

# 训练模型
clf.fit(X, y)

# 预测
predictions = clf.predict(X)

# 输出预测结果
print(predictions)
```

##### 5.2 支持向量机算法

支持向量机（Support Vector Machine，SVM）是一种基于间隔最大化的监督学习算法，主要用于分类和回归任务。在药物发现中，SVM可以用于药物筛选、药物设计和药物活性预测等。

**算法原理**

SVM的核心思想是在高维空间中找到最优的超平面，使得不同类别的样本点之间的间隔最大化。SVM算法分为线性SVM和核SVM。

- **线性SVM**：在特征空间中找到最优的超平面，使得正负样本点之间的间隔最大化。
- **核SVM**：当数据无法在高维特征空间中表示时，使用核函数将数据映射到高维空间，然后在高维空间中找到最优的超平面。

SVM的算法步骤如下：

1. **特征选择**：选择特征或使用核函数将数据映射到高维空间。
2. **构建超平面**：找到最优的超平面，使得正负样本点之间的间隔最大化。
3. **分类决策**：根据超平面的位置，对新的样本进行分类。

**优点**

- **良好的分类性能**：SVM能够找到最大间隔的超平面，从而提高分类的准确性。
- **对噪声和异常值的鲁棒性**：SVM对噪声和异常值具有较强的鲁棒性。
- **可解释性**：SVM的决策边界清晰，有助于理解模型的工作原理。

**应用场景**

1. **药物筛选**：SVM可以用于筛选具有潜在活性的药物分子，通过对药物分子特征进行分类，识别出有效的药物候选物。
2. **药物设计**：SVM可以用于优化药物分子结构，提高其药理活性和稳定性。

**示例代码**

```python
from sklearn.svm import SVC
from sklearn.datasets import load_iris

# 载入鸢尾花数据集
iris = load_iris()
X, y = iris.data, iris.target

# 创建SVM分类器
clf = SVC(kernel='linear')

# 训练模型
clf.fit(X, y)

# 预测
predictions = clf.predict(X)

# 输出预测结果
print(predictions)
```

##### 5.3 神经网络算法

神经网络（Neural Network，NN）是一种模仿人脑神经元结构和功能的计算模型，通过多层节点（神经元）的互联，实现数据的自动特征提取和模式识别。神经网络在药物发现中具有广泛的应用，特别是在药物活性预测、药物设计优化和生物医学数据分析等领域。

**算法原理**

神经网络的基本结构包括输入层、隐藏层和输出层。每个神经元都与其他神经元相连，并使用权重进行加权求和，然后通过激活函数进行非线性变换。

- **输入层**：接收外部输入数据。
- **隐藏层**：对输入数据进行特征提取和变换。
- **输出层**：输出最终的预测结果。

神经网络的训练过程包括：

1. **前向传播**：将输入数据通过网络传递到输出层，计算每个神经元的输出值。
2. **反向传播**：计算输出层与实际输出之间的误差，通过反向传播算法，更新网络的权重和偏置，以减小误差。

常用的神经网络算法包括：

- **多层感知机（MLP）**：一种简单的多层神经网络，用于分类和回归任务。
- **卷积神经网络（CNN）**：一种专门用于图像处理和识别的神经网络结构，通过卷积层和池化层，实现图像的自动特征提取。
- **循环神经网络（RNN）**：一种用于序列数据的神经网络，通过记忆单元，实现对序列数据的时序建模。

**优点**

- **强大的特征提取能力**：神经网络能够自动从数据中提取高级特征，减少人工干预。
- **灵活性和适应性**：神经网络可以适应不同类型的数据和任务，通过调整网络结构和参数，实现多样化的应用。
- **高准确性**：神经网络在许多任务上表现出色，能够达到甚至超过人类专家的水平。

**应用场景**

1. **药物活性预测**：神经网络可以用于预测药物分子的活性，通过对药物分子的结构特征进行建模，快速筛选出具有潜在活性的药物分子。
2. **药物设计优化**：神经网络可以用于优化药物分子的结构，提高其药理活性和稳定性。
3. **生物医学数据分析**：神经网络可以用于生物医学数据的分析和处理，如基因序列分析、蛋白质结构预测和医学影像分析等。

**示例代码**

from sklearn.datasets import load_iris

# 载入鸢尾花数据集
iris = load_iris()
X, y = iris.data, iris.target

# 创建MLP分类器

# 训练模型
clf.fit(X, y)

**1. 数据清洗**

数据清洗是数据处理的第一步，其目的是去除数据中的噪声、错误和重复值，确保数据的一致性和完整性。数据清洗的方法包括：

- **去除重复数据**：通过比较数据集中的记录，去除重复的样本。可以使用Pandas库中的`drop_duplicates()`函数实现。
- **处理缺失值**：对于缺失值，可以根据具体情况选择填补或删除。常用的填补方法包括均值填补、中值填补和插值法等。可以使用Pandas库中的`fillna()`函数进行填补。
- **去除噪声**：通过统计分析，识别出异常值并去除。例如，可以使用Z-score或IQR方法检测异常值。

**示例代码**：
```python
import pandas as pd

# 读取数据
df = pd.read_csv('data.csv')

# 去除重复数据
df = df.drop_duplicates()

# 填补缺失值
df = df.fillna(df.mean())

# 去除异常值
z_scores = (df - df.mean()) / df.std()
df = df[(z_scores < 3).all(axis=1)]
```

**2. 特征提取**

特征提取是从原始数据中提取出对模型预测有重要影响的关键特征。在药物发现中，特征提取的方法包括：

- **化学信息特征**：利用化学信息学方法，从药物分子结构中提取特征，如分子指纹、拓扑指数、分子属性等。可以使用RDKit库进行化学信息特征提取。
- **生物信息特征**：从生物医学数据中提取特征，如基因表达数据、蛋白质结构信息等。可以使用BioPython库进行生物信息特征提取。
- **文本特征**：从文献资料中提取特征，如关键词、摘要等。可以使用自然语言处理（NLP）技术进行文本特征提取。

**示例代码**：
```python
from rdkit import Chem
from rdkit.Chem import AllChem

# 读取药物分子数据
molecules = Chem.SDMolSupplier('molecules.sdf')

# 提取分子指纹
fingerprints = []
for mol in molecules:
    fingerprint = Chem.rdmolops.GetMolFragsAsMols(mol)
    fingerprints.append(AllChem.GetMorganFingerprintAsBitVector(fingerprint, 2))

# 转换为Pandas DataFrame
df_fingerprints = pd.DataFrame(fingerprints, columns=[f'Fingerprint_{i}' for i in range(len(fingerprints))])
```

- **描述性统计分析**：计算数据的基本统计量，如均值、中位数、标准差等，用于了解数据的分布特征。
- **相关性分析**：分析不同特征之间的相关性，识别出重要的特征关系。可以使用Pearson相关系数或Spearman秩相关系数。
- **聚类分析**：将数据划分为不同的类别，用于发现数据的内在结构和模式。常用的聚类算法包括K-means、层次聚类等。
- **分类和回归分析**：通过训练机器学习模型，对数据进行分类或回归分析，预测新的数据点的类别或数值。常用的算法包括支持向量机（SVM）、随机森林（Random Forest）等。

- **模型构建**：选择合适的算法，使用Python的Scikit-Learn、TensorFlow或PyTorch等库，构建机器学习模型。例如，对于分类问题，可以使用SVM、随机森林或深度学习模型。
- **模型训练**：使用训练数据集，对模型进行训练，调整模型参数，以提高预测性能。可以通过交叉验证和网格搜索等方法，找到最优的参数组合。
- **模型评估**：使用验证数据集，对模型进行评估，计算预测准确率、召回率、F1分数等指标，评估模型的性能。

**3. 算法优化**

在模型训练和评估过程中，可以通过以下方法进行算法优化：

- **超参数调优**：通过网格搜索、贝叶斯优化等方法，调整模型的超参数（如学习率、隐藏层神经元数量、正则化参数等），以最大化模型的预测性能。例如，可以使用Scikit-Learn的`GridSearchCV`或`BayesSearchCV`进行超参数调优。
- **特征工程**：通过特征选择、特征转换和特征提取等方法，优化特征质量，提高模型的预测性能。例如，可以使用Lasso、随机森林等方法进行特征选择，提取重要的特征。
- **模型集成**：通过集成多个模型（如Bagging、Boosting、Stacking等），提高模型的稳定性和预测性能。例如，可以使用Scikit-Learn的`BaggingClassifier`、`AdaBoost`或`StackingClassifier`进行模型集成。
- **模型正则化**：通过L1正则化（Lasso）、L2正则化（Ridge）等方法，减少模型过拟合，提高模型的泛化能力。例如，可以使用Scikit-Learn的`Lasso`或`Ridge`模型。

**4. 示例代码**

以下是一个使用Scikit-Learn库进行药物活性预测的示例代码，包括数据预处理、模型构建、超参数调优和模型评估。

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, classification_report

# 加载鸢尾花数据集
iris = load_iris()
X, y = iris.data, iris.target

# 数据预处理
# 这里假设数据已经清洗和标准化

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# 模型构建
rf = RandomForestClassifier(random_state=0)

# 超参数调优
param_grid = {
    'n_estimators': [100, 200, 300],
    'max_depth': [5, 10, 15],
    'min_samples_split': [2, 5, 10]
}
grid_search = GridSearchCV(rf, param_grid, cv=5, scoring='accuracy')
grid_search.fit(X_train, y_train)

# 最优参数
best_params = grid_search.best_params_
print("最优参数：", best_params)

# 模型评估
best_rf = grid_search.best_estimator_
y_pred = best_rf.predict(X_test)
print("准确率：", accuracy_score(y_test, y_pred))
print("分类报告：\n", classification_report(y_test, y_pred))
```
