from keras.preprocessing.text import Tokenizer
from keras.preprocessing.sequence import pad_sequences

# 加载停用词列表
stop_words = set(stopwords.words('english'))

# 分词、去停用词和词性标注
def preprocess_text(text):
    tokens = word_tokenize(text)
    filtered_tokens = [token for token in tokens if token not in stop_words]
    lemmatizer = WordNetLemmatizer()
    lemmatized_tokens = [lemmatizer.lemmatize(token) for token in filtered_tokens]
    return lemmatized_tokens

padded_sequences = pad_sequences(sequences, maxlen=100)

### **3.1 TF-IDF**

TF-IDF（Term Frequency-Inverse Document Frequency）是一种常用的文本特征提取方法，用于衡量一个词在文档中的重要程度。其公式如下：

\[ TF(t,d) = \frac{f(t,d)}{N} \]
\[ IDF(t,D) = \log \left( \frac{N}{|d_t|} \right) \]
\[ TF-IDF(t,d,D) = TF(t,d) \times IDF(t,D) \]

其中：
- \( f(t,d) \) 是词 \( t \) 在文档 \( d \) 中的词频。
- \( N \) 是文档总数。
- \( |d_t| \) 是包含词 \( t \) 的文档数量。

**例子**：
假设有一个包含两篇文档的数据集，文档 \( d_1 \) 包含词“happy”一次，文档 \( d_2 \) 包含词“happy”两次。文档总数为2。

\[ TF("happy", d_1) = \frac{1}{1} = 1 \]
\[ TF("happy", d_2) = \frac{2}{2} = 1 \]
\[ IDF("happy", D) = \log \left( \frac{2}{2} \right) = \log(1) = 0 \]
\[ TF-IDF("happy", d_1, D) = 1 \times 0 = 0 \]
\[ TF-IDF("happy", d_2, D) = 1 \times 0 = 0 \]

### **3.2 文本分类中的逻辑回归**

逻辑回归是一种常用的文本分类模型，用于预测文本属于某个类别的概率。其公式如下：

\[ P(y=c | x) = \frac{1}{1 + e^{-(\beta_0 + \sum_{i=1}^{n} \beta_i x_i)}} \]

其中：
- \( y \) 是标签，\( c \) 是类别。
- \( x_i \) 是特征向量中的第 \( i \) 个元素。
- \( \beta_0 \) 是截距，\( \beta_i \) 是系数。

**例子**：
假设有一个二元分类问题，类别为“讽刺”和“非讽刺”。特征向量 \( x \) 包含两个特征值，分别为0.5和0.3。

\[ P(y="讽刺" | x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 \cdot 0.5 + \beta_2 \cdot 0.3)}} \]
\[ P(y="非讽刺" | x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 \cdot 0.5 + \beta_2 \cdot 0.3)}} \]

通过比较这两个概率，可以判断文本属于哪个类别。

### **3.3 卷积神经网络（CNN）**

卷积神经网络（CNN）在文本分类任务中有着广泛应用。其核心思想是使用卷积操作提取文本特征。CNN的数学公式如下：

\[ h_{ij}^l = \sigma \left( \sum_{k} w_{ik}^l h_{kj}^{l-1} + b_l \right) \]

其中：
- \( h_{ij}^l \) 是第 \( l \) 层的第 \( i \) 个节点。
- \( w_{ik}^l \) 是第 \( l \) 层的第 \( i \) 个节点的权重。
- \( b_l \) 是第 \( l \) 层的偏置。
- \( \sigma \) 是激活函数，如ReLU函数。

**例子**：
假设有一个一层的卷积层，包含3个卷积核，每个卷积核的大小为3x3。输入的特征矩阵为3x3。

\[ h_{11}^1 = \sigma \left( w_{11}^1 \cdot x_{11} + w_{12}^1 \cdot x_{12} + w_{13}^1 \cdot x_{13} + b_1 \right) \]
\[ h_{12}^1 = \sigma \left( w_{11}^1 \cdot x_{12} + w_{12}^1 \cdot x_{13} + w_{13}^1 \cdot x_{14} + b_1 \right) \]
\[ \vdots \]
\[ h_{33}^1 = \sigma \left( w_{11}^1 \cdot x_{33} + w_{12}^1 \cdot x_{34} + w_{13}^1 \cdot x_{35} + b_1 \right) \]

通过卷积操作，可以从原始特征矩阵中提取局部特征，并传递到下一层。

### **3.4 深度学习中的反向传播算法**

深度学习中的反向传播算法是一种用于训练神经网络的优化方法。其核心思想是通过计算损失函数关于模型参数的梯度，更新模型参数，从而优化模型性能。其公式如下：

\[ \delta_j^l = \frac{\partial J}{\partial z_j^l} = \frac{\partial J}{\partial a_j^l} \frac{\partial a_j^l}{\partial z_j^l} \]

\[ w_{ij}^{l+1} = w_{ij}^{l+1} - \alpha \frac{\partial J}{\partial w_{ij}^{l+1}} \]
\[ b_{j}^{l+1} = b_{j}^{l+1} - \alpha \frac{\partial J}{\partial b_{j}^{l+1}} \]

其中：
- \( \delta_j^l \) 是第 \( l \) 层的第 \( j \) 个节点的误差。
- \( J \) 是损失函数。
- \( z_j^l \) 是第 \( l \) 层的第 \( j \) 个节点的输出。
- \( a_j^l \) 是第 \( l \) 层的第 \( j \) 个节点的输入。
- \( w_{ij}^{l+1} \) 和 \( b_{j}^{l+1} \) 是第 \( l+1 \) 层的第 \( i \) 个节点的权重和偏置。
- \( \alpha \) 是学习率。

**例子**：
假设有一个简单的神经网络，包含两层，输入层有3个节点，输出层有1个节点。

\[ \delta_1^2 = \frac{\partial J}{\partial z_1^2} = \frac{\partial J}{\partial a_1^2} \frac{\partial a_1^2}{\partial z_1^2} \]
\[ \delta_2^2 = \frac{\partial J}{\partial z_2^2} = \frac{\partial J}{\partial a_2^2} \frac{\partial a_2^2}{\partial z_2^2} \]
\[ \delta_3^2 = \frac{\partial J}{\partial z_3^2} = \frac{\partial J}{\partial a_3^2} \frac{\partial a_3^2}{\partial z_3^2} \]

\[ w_{11}^{3} = w_{11}^{3} - \alpha \frac{\partial J}{\partial w_{11}^{3}} \]
\[ w_{12}^{3} = w_{12}^{3} - \alpha \frac{\partial J}{\partial w_{12}^{3}} \]
\[ w_{13}^{3} = w_{13}^{3} - \alpha \frac{\partial J}{\partial w_{13}^{3}} \]
\[ b_1^{3} = b_1^{3} - \alpha \frac{\partial J}{\partial b_1^{3}} \]

通过反向传播算法，可以不断更新模型的权重和偏置，从而优化模型的性能。

#### **数据预处理模块**

```python
import nltk
from nltk.tokenize import word_tokenize
from nltk.corpus import stopwords
from nltk.stem import WordNetLemmatizer

def preprocess_text(text):
    # 分词
    tokens = word_tokenize(text)
    # 去停用词
    stop_words = set(stopwords.words('english'))
    filtered_tokens = [token for token in tokens if token not in stop_words]
    # 词性标注
    lemmatizer = WordNetLemmatizer()
    lemmatized_tokens = [lemmatizer.lemmatize(token) for token in filtered_tokens]
    return lemmatized_tokens
```

#### **特征提取模块**

```python
from sklearn.feature_extraction.text import TfidfVectorizer

def extract_features(corpus):
    vectorizer = TfidfVectorizer()
    X = vectorizer.fit_transform(corpus)
    return X, vectorizer
```

#### **模型训练模块**

```python
from keras.models import Sequential
from keras.layers import Conv1D, MaxPooling1D, Flatten, Dense
from keras.optimizers import Adam

def build_model(input_shape):
    model = Sequential()
    model.add(Conv1D(filters=128, kernel_size=5, activation='relu', input_shape=input_shape))
    model.add(MaxPooling1D(pool_size=5))
    model.add(Flatten())
    model.add(Dense(units=128, activation='relu'))
    model.add(Dense(units=1, activation='sigmoid'))

    optimizer = Adam(learning_rate=0.001)
    model.compile(optimizer=optimizer, loss='binary_crossentropy', metrics=['accuracy'])
    return model
```

#### **模型评估模块**

```python
from sklearn.metrics import accuracy_score, recall_score, f1_score

def evaluate_model(model, X_test, y_test):
    predictions = model.predict(X_test)
    predictions = (predictions > 0.5)

    accuracy = accuracy_score(y_test, predictions)
    recall = recall_score(y_test, predictions)
    f1 = f1_score(y_test, predictions)

    print("Accuracy:", accuracy)
    print("Recall:", recall)
    print("F1 Score:", f1)
```
