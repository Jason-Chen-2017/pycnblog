4. **社会公正**：基因编辑技术应遵循社会公正原则，确保技术发展不会加剧社会不平等，而是促进人类的整体福祉。

1. **基因编辑的安全性**：基因编辑技术尚未完全成熟，存在潜在的安全风险，如基因编辑导致的基因突变、不可预见的副作用等。
2. **人类生殖的应用**：基因编辑药物的应用可能涉及人类生殖过程，引发关于人类基因改造的伦理争议。
3. **社会不平等**：基因编辑药物可能加剧社会不平等，使得富有人群能够通过基因编辑获得竞争优势，而穷人则无法享受这一技术带来的好处。

#### 6.1.3 伦理分析

2. **知情同意**：实验必须确保参与者的知情同意，特别是在涉及未成年人时，更需要确保其父母充分理解基因编辑的潜在风险和长期影响。
3. **安全性**：基因编辑技术必须经过严格的科学验证，确保其安全性和有效性。在技术未完全成熟之前，应限制其临床应用。
4. **社会公正**：基因编辑技术应遵循社会公正原则，确保技术发展不会加剧社会不平等，而是促进人类的整体福祉。
