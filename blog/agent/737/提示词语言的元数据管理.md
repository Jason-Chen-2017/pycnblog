元数据模型是对元数据进行结构化描述的方法。常用的元数据模型包括XML、RDF和JSON等。这些模型定义了元数据的属性、关系和结构。

1. **XML（可扩展标记语言）**：XML是一种基于文本的结构化数据格式，它使用标签来表示数据元素，并通过属性和值来描述数据属性。XML模型具有灵活性和可扩展性，适用于各种数据类型和场景。

   ```xml
   <metadata>
     <data id="123">
       <type>text</type>
       <author>John Doe</author>
       <created>2023-01-01</created>
       <content>Example text content.</content>
     </data>
   </metadata>
   ```

2. **RDF（资源描述框架）**：RDF是一种基于图的元数据模型，它使用URI（统一资源标识符）来标识资源，并通过属性和值来描述资源之间的关系。RDF模型支持语义Web的数据表示和互操作性。

   ```turtle
   @prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
   @prefix ex: <http://example.org/> .

   <metadata>
     <rdf:Description>
       <rdf:type>ex:Data</rdf:type>
       <rdf:Property ex:author>John Doe</rdf:Property>
       <rdf:Property ex:created>2023-01-01</rdf:Property>
       <rdf:Property ex:content>Example text content.</rdf:Property>
     </rdf:Description>
   </metadata>
   ```

3. **JSON（JavaScript对象表示法）**：JSON是一种轻量级的数据交换格式，它使用键值对来表示数据结构和属性。JSON模型简单直观，易于编程和解析。

   ```json
   {
     "metadata": {
       "data": [
         {
           "id": "123",
           "type": "text",
           "author": "John Doe",
           "created": "2023-01-01",
           "content": "Example text content."
         }
       ]
     }
   }
   ```

### 2.4 元数据模型

元数据模型是对元数据进行结构化描述的方法。常用的元数据模型包括XML、RDF和JSON等。这些模型定义了元数据的属性、关系和结构。

1. **XML（可扩展标记语言）**：XML是一种基于文本的结构化数据格式，它使用标签来表示数据元素，并通过属性和值来描述数据属性。XML模型具有灵活性和可扩展性，适用于各种数据类型和场景。

   ```xml
   <metadata>
     <data id="123">
       <type>text</type>
       <author>John Doe</author>
       <created>2023-01-01</created>
       <content>Example text content.</content>
     </data>
   </metadata>
   ```

2. **RDF（资源描述框架）**：RDF是一种基于图的元数据模型，它使用URI（统一资源标识符）来标识资源，并通过属性和值来描述资源之间的关系。RDF模型支持语义Web的数据表示和互操作性。

   ```turtle
   @prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
   @prefix ex: <http://example.org/> .

   <metadata>
     <rdf:Description>
       <rdf:type>ex:Data</rdf:type>
       <rdf:Property ex:author>John Doe</rdf:Property>
       <rdf:Property ex:created>2023-01-01</rdf:Property>
       <rdf:Property ex:content>Example text content.</rdf:Property>
     </rdf:Description>
   </metadata>
   ```

3. **JSON（JavaScript对象表示法）**：JSON是一种轻量级的数据交换格式，它使用键值对来表示数据结构和属性。JSON模型简单直观，易于编程和解析。

   ```json
   {
     "metadata": {
       "data": [
         {
           "id": "123",
           "type": "text",
           "author": "John Doe",
           "created": "2023-01-01",
           "content": "Example text content."
         }
       ]
     }
   }
   ```
