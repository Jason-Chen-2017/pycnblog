#### 附录 C：代码示例

以下是一个简单的Python代码示例，用于模拟SEIR模型的运行过程：

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数设置
beta = 0.3
sigma = 0.1
gamma = 0.05

# 初始条件
S0 = 1000
E0 = 0
I0 = 1
R0 = 0

# 时间步长和总时间
dt = 0.1
t_end = 100

# 时间序列
t = np.arange(0, t_end, dt)

# 初始化状态变量
S = S0 * np.ones(len(t))
E = E0 * np.ones(len(t))
I = I0 * np.ones(len(t))
R = R0 * np.ones(len(t))

# 迭代计算
for i in range(1, len(t)):
    dSdt = -beta * S[i-1] * I[i-1]
    dEdt = beta * S[i-1] * I[i-1] - sigma * E[i-1]
    dIdt = sigma * E[i-1] - gamma * I[i-1]
    dRdt = gamma * I[i-1]
    
    S[i] = S[i-1] + dSdt * dt
    E[i] = E[i-1] + dEdt * dt
    I[i] = I[i-1] + dIdt * dt
    R[i] = R[i-1] + dRdt * dt

# 可视化结果
plt.plot(t, S, label='Susceptible')
plt.plot(t, E, label='Exposed')
plt.plot(t, I, label='Infected')
plt.plot(t, R, label='Recovered')
plt.legend()
plt.xlabel('Time')
plt.ylabel('Population')
plt.title('SEIR Model')
plt.show()
```

通过这段代码，我们可以模拟SEIR模型在一段时间内的运行过程，并可视化感染者的数量变化。
