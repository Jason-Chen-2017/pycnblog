#### 2.1 零样本学习的基本原理

零样本学习（Zero-Shot Learning，简称ZSL）是一种无需训练数据标签即可对未见过的类别进行预测的机器学习方法。其基本原理是通过学习类别之间的相似性或关系，使得模型能够在未见过的类别上表现良好。

零样本学习的核心挑战在于如何有效地表示类别，并利用这些表示来预测未见过的实例。常见的方法包括：

1. **原型匹配**：将类别表示为该类别样本的平均值，然后通过计算实例与类别原型之间的距离来进行预测。
2. **元学习**：通过训练一个适应新类别的模型来提高零样本学习性能。
3. **转移学习**：利用预训练的模型来增强对未见过的类别的表示能力。

#### 2.2 零样本学习与传统监督学习的区别

传统监督学习（Supervised Learning）依赖于大量带有标签的训练数据来训练模型，而零样本学习则不需要标签数据。以下是两者之间的主要区别：

| **对比项** | **传统监督学习** | **零样本学习** |
| :----: | :----: | :----: |
| **数据需求** | 需要大量带标签的数据 | 不需要标签数据 |
| **预测能力** | 能够准确预测已见过的类别 | 能够预测未见过的类别 |
| **泛化能力** | 在有标签数据上表现良好 | 在未见过的类别上表现良好 |
| **适用场景** | 标签数据丰富的情况 | 标签数据稀缺或不存在的情况 |

#### 2.1 零样本学习的基本原理

零样本学习（Zero-Shot Learning，简称ZSL）是一种无需训练数据标签即可对未见过的类别进行预测的机器学习方法。其基本原理是通过学习类别之间的相似性或关系，使得模型能够在未见过的类别上表现良好。

零样本学习的核心挑战在于如何有效地表示类别，并利用这些表示来预测未见过的实例。常见的方法包括：

1. **原型匹配**：将类别表示为该类别样本的平均值，然后通过计算实例与类别原型之间的距离来进行预测。
2. **元学习**：通过训练一个适应新类别的模型来提高零样本学习性能。
3. **转移学习**：利用预训练的模型来增强对未见过的类别的表示能力。

#### 2.2 零样本学习与传统监督学习的区别

传统监督学习（Supervised Learning）依赖于大量带有标签的训练数据来训练模型，而零样本学习则不需要标签数据。以下是两者之间的主要区别：

| **对比项** | **传统监督学习** | **零样本学习** |
| :----: | :----: | :----: |

| **预测能力** | 能够准确预测已见过的类别 | 能够预测未见过的类别 |
| **泛化能力** | 在有标签数据上表现良好 | 在未见过的类别上表现良好 |
| **适用场景** | 标签数据丰富的情况 | 标签数据稀缺或不存在的情况 |
