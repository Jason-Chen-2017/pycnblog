#### 基于提示词的异常检测算法

在异常检测中，基于提示词的算法通过利用提示词来提高检测的准确性和鲁棒性。以下介绍几种基于提示词的异常检测算法。

1. **基于统计学的异常检测算法**

基于统计学的异常检测算法主要通过分析数据分布来检测异常。其中，最常见的算法是**箱型图法**和**3-标准差法**。

- **箱型图法**：箱型图法通过计算数据的四分位数（Q1, Q2, Q3）和异常值范围（IQR = Q3 - Q1），将数据分为四部分：[Q1 - 1.5 * IQR, Q1 + 1.5 * IQR]、[Q1 + 1.5 * IQR, Q2]、[Q2, Q3] 和 [Q3 + 1.5 * IQR, Q3 + 3 * IQR]。落在[Q1 - 1.5 * IQR, Q1 + 1.5 * IQR]和[Q3 + 1.5 * IQR, Q3 + 3 * IQR]区间内的数据被认为是异常值。

  $$\text{IQR} = Q3 - Q1$$
  $$\text{箱型图区间} = \{x \in X \mid Q1 - 1.5 \times \text{IQR} \leq x \leq Q1 + 1.5 \times \text{IQR}\} \cup \{x \in X \mid Q3 + 1.5 \times \text{IQR} \leq x \leq Q3 + 3 \times \text{IQR}\}$$

- **3-标准差法**：3-标准差法通过计算数据的均值（\(\mu\)）和标准差（\(\sigma\)），将数据分为四部分：[ \(\mu - 3\sigma, \mu + 3\sigma\) ] 和 \([ \mu + 3\sigma, +\infty\) ]。落在[ \(\mu - 3\sigma, \mu + 3\sigma\) ]区间内的数据被认为是正常值，落在[ \(\mu + 3\sigma, +\infty\) ]的数据被认为是异常值。

  $$\text{正常值范围} = \{x \in X \mid \mu - 3\sigma \leq x \leq \mu + 3\sigma\}$$
  $$\text{异常值范围} = \{x \in X \mid x > \mu + 3\sigma\}$$

2. **基于机器学习的异常检测算法**

基于机器学习的异常检测算法通过训练模型来识别正常数据和异常数据。以下介绍几种常见的基于机器学习的异常检测算法：

- **孤立森林（Isolation Forest）**：孤立森林算法通过随机选取特征和切分点，将数据逐个隔离，异常数据通常需要较少的切分即可隔离，而正常数据则需要更多的切分。其基本流程如下：

  1. 随机选择特征列 \(X_j\)。
  2. 随机选择切分点 \(r\)。
  3. 切分数据集：\(X_r = X_r < r\) 和 \(X_r = X_r > r\)。
  4. 统计切分的路径长度：对于每个样本，统计其到达根节点的路径长度，记为 \(h\)。
  5. 异常分数计算：对于每个样本，计算其异常分数 \(score = \frac{h}{\log_2(n)}\)，其中 \(n\) 是样本数量。

    $$score = \frac{h}{\log_2(n)}$$

  异常分数越低，表示异常性越高。

- **K最近邻（KNN）**：KNN算法通过计算样本与训练集中最近邻的距离来预测其是否为异常。如果样本与训练集中的最近邻距离较远，则认为其是异常。

  $$d(x, y) = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2}$$
  其中，\(x\) 和 \(y\) 是两个样本，\(n\) 是特征数量。

  设定一个阈值 \(t\)，如果 \(d(x, y) > t\)，则 \(x\) 是异常。

3. **基于深度学习的异常检测算法**

基于深度学习的异常检测算法通过构建深度神经网络来识别异常数据。以下介绍几种基于深度学习的异常检测算法：

- **自动编码器（Autoencoder）**：自动编码器是一种无监督学习算法，通过训练一个编码器和解码器来重建输入数据。如果重建误差较大，则认为输入数据是异常。

  编码器：\(z = encoder(x)\)

  解码器：\(x' = decoder(z)\)

  重建误差：\(loss = \frac{1}{2} \sum_{i=1}^{n} (x_i - x_i')^2\)

  设定一个阈值 \(t\)，如果 \(loss > t\)，则 \(x\) 是异常。

- **卷积神经网络（CNN）**：卷积神经网络通过卷积操作和池化操作来提取图像特征。在异常检测中，可以使用CNN来识别图像中的异常。

  $$f(x) = conv_2d(x, w) + b$$
  $$h(x) = max_pooling(f(x))$$

  通过训练CNN，可以识别图像中的异常。

  $$z \rightarrow G(z) \rightarrow \text{Prompt Word}$$

- **判别器**：判别器 \(D\) 接受真实提示词和生成提示词作为输入，判断其质量。

  $$D(G(z)), D(\text{Real Prompt Word})$$

  $$\text{Prompt Word} = \text{Pre-trained Model}(\text{Task-specific Data})$$
