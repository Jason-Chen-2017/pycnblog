### 5.1 数学模型

宇宙概率分布的数学模型主要包括概率分布函数（PDF）、累积分布函数（CDF）和特征函数等。以下是对这些模型的基本介绍：

#### 5.1.1 概率分布函数（PDF）

概率分布函数（Probability Distribution Function，PDF）是一个随机变量取值的概率密度函数。它描述了随机变量在某个特定值附近的概率密度。在宇宙学中，PDF被用来描述宇宙中各种物理量的概率分布。

常见的概率分布函数包括：

1. **正态分布（Normal Distribution）**
   正态分布是最常见的连续概率分布函数，其概率密度函数为：
   $$
   f(x|\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}
   $$
   其中，$\mu$是均值，$\sigma^2$是方差。

2. **泊松分布（Poisson Distribution）**
   泊松分布用于描述在固定时间内某个事件发生的次数的概率分布，其概率质量函数为：
   $$
   f(k|\lambda) = \frac{e^{-\lambda}\lambda^k}{k!}
   $$
   其中，$\lambda$是事件的发生率，$k$是事件发生的次数。

3. **二项分布（Binomial Distribution）**
   二项分布用于描述在一系列独立的伯努利试验中，某个事件发生特定次数的概率分布，其概率质量函数为：
   $$
   f(k|n,p) = C_n^k p^k (1-p)^{n-k}
   $$
   其中，$n$是试验次数，$p$是每次试验中事件发生的概率，$k$是事件发生的次数。

4. **指数分布（Exponential Distribution）**
   指数分布用于描述在固定时间间隔内某个事件发生的概率分布，其概率密度函数为：
   $$
   f(x|\lambda) = \lambda e^{-\lambda x}
   $$
   其中，$\lambda$是事件的发生率。

#### 5.1.2 累积分布函数（CDF）

累积分布函数（Cumulative Distribution Function，CDF）是一个随机变量小于或等于某个值的概率。它描述了随机变量在某个区间内的累积概率分布。

常见的累积分布函数包括：

1. **正态分布的累积分布函数（Normal CDF）**
   正态分布的累积分布函数$\Phi(x)$定义为：
   $$
   \Phi(x) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{x} e^{-\frac{t^2}{2}} dt
   $$

2. **泊松分布的累积分布函数（Poisson CDF）**
   泊松分布的累积分布函数$F(k|\lambda)$定义为：
   $$
   F(k|\lambda) = \sum_{i=0}^{k} \frac{e^{-\lambda}\lambda^i}{i!}
   $$

3. **二项分布的累积分布函数（Binomial CDF）**
   二项分布的累积分布函数$F(k|n,p)$定义为：
   $$
   F(k|n,p) = \sum_{i=0}^{k} C_n^i p^i (1-p)^{n-i}
   $$

#### 5.1.3 特征函数

特征函数（Characteristic Function）是概率分布的另一种表示方法，它提供了随机变量所有可能取值的复数形式的概率幅。特征函数$\phi(t)$与概率分布函数$f(x)$的关系为：
$$
\phi(t) = \int_{-\infty}^{+\infty} e^{itx} f(x) dx
$$
特征函数在统计物理和量子力学中有着广泛的应用。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import poisson

# 假设星系位置数据
positions = np.random.rand(1000, 2)  # 1000个星系，每个星系有两个位置坐标

# 计算星系之间的距离
distances = np.linalg.norm(positions[:, np.newaxis] - positions, axis=2)

# 计算泊松分布概率
probs = poisson.cdf(distances, loc=0, scale=1)

plt.grid()
plt.show()
```
