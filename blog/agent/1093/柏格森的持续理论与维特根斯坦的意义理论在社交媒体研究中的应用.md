柏格森认为，时间不是一种均匀流动的连续体，而是一个充满断裂和差异的流动过程。这一观点与牛顿-莱布尼茨的连续性时间观形成了鲜明对比。牛顿-莱布尼茨的时间观认为时间是一个无限细分的连续体，每个瞬间都是均匀和相似的。而柏格森则强调时间的主观性和个体体验的独特性。

### 核心概念

柏格森的持续理论包含了几个核心概念，其中最重要的包括：

1. **时间**：在柏格森的视角中，时间不仅是物理上的持续，更是心理上的持续。时间不是一种简单的线性序列，而是一个充满流动性和复杂性的过程。

2. **流动性**：柏格森认为时间是一个不断变化的过程，每个瞬间都是独特的，不可重复的。这种流动性使得时间具有主观性，不同的人对时间的感知是不同的。

3. **直觉**：柏格森认为直觉是我们感知时间和现实的重要方式。通过直觉，个体能够直接感知到时间的流动和变化，而不需要通过抽象的概念或逻辑来理解。

4. **创造力**：柏格森将时间与创造力联系在一起，认为创造力是一种对时间流动的敏感性和响应能力。个体通过创造力能够超越传统的思维模式，创造出新的价值和意义。

```python
import pandas as pd
from textblob import TextBlob
import matplotlib.pyplot as plt

# 假设我们有一个社交媒体数据集，包含用户行为和时间信息
data = pd.read_csv('social_media_data.csv')

# 时间序列分析
data['timestamp'] = pd.to_datetime(data['timestamp'])
data.set_index('timestamp', inplace=True)
activity_counts = data.groupby('activity_type').size().resample('D').sum()

# 绘制活动分布图
activity_counts.plot()
plt.title('Daily Activity Distribution')
plt.xlabel('Date')
plt.ylabel('Activity Count')
plt.show()

# 语义分析
def analyze_text(text):
    return TextBlob(text).sentiment.polarity

data['polarity'] = data['text'].apply(analyze_text)

# 绘制情感分布图
data['polarity'].resample('D').mean().plot()
plt.title('Daily Average Sentiment')
plt.xlabel('Date')
plt.ylabel('Average Polarity')
plt.show()
```
