```python
def preprocess_data(data):
    # 删除缺失值
    data.dropna(inplace=True)
    
    # 处理异常值
    data = data[(data['income'] > 0) & (data['expense'] > 0)]
    
    # 数据标准化
    data[['income', 'expense']] = (data[['income', 'expense']] - data[['income', 'expense']].mean()) / data[['income', 'expense']].std()
    
    return data

data = preprocess_data(data)
```

### 5.2.4 压力测试

压力测试是评估用户财务状况在面对不同情境下的承受能力。以下是一个简单的压力测试示例，模拟用户收入减少20%和支出增加10%的情况：

```python
def stress_test(data, income_decrease=0.2, expense_increase=0.1):
    # 计算减少后的收入和增加后的支出
    reduced_income = data['income'] * (1 - income_decrease)
    increased_expense = data['expense'] * (1 + expense_increase)
    
    # 计算压力测试结果
    stress_result = reduced_income - increased_expense
    
    return stress_result

stress_result = stress_test(data)
```
