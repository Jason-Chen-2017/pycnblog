#### 算法流程图


#### Python 源代码

```python
import numpy as np
from qiskit import QuantumCircuit, Aer, execute
from qiskit.quantum_info import Statevector

# 初始化量子比特
n_qubits = 2
qc = QuantumCircuit(n_qubits)

# 生成纠缠态
qc.h(0)
qc.cx(0, 1)

# 测量量子比特
qc.measure_all()

# 执行量子电路
backend = Aer.get_backend('qasm_simulator')
result = execute(qc, backend).result()
counts = result.get_counts(qc)

# 输出测量结果
print("测量结果：", counts)
```

#### 算法原理

该算法实现了一个两量子比特的量子纠缠态，并对其进行测量。量子纠缠态是通过应用 Hadamard 门（H 门）和-controlled-NOT（CNOT）门生成的。测量量子比特时，会得到一系列的概率分布，这些分布反映了量子态的叠加和纠缠特性。

#### 数学模型和公式

$$
|\psi\rangle = \frac{1}{\sqrt{2}} (|0\rangle \otimes |0\rangle + |1\rangle \otimes |1\rangle)
$$

$$
\langle\psi|\psi\rangle = \frac{1}{2} (|00\rangle + |11\rangle)
$$

#### 举例说明

假设测量得到的结果为 `01`，则表示第一个量子比特处于状态 `0`，第二个量子比特处于状态 `1`。根据量子纠缠态的公式，这种情况的概率为：

$$
P(01) = \frac{1}{2}
$$
