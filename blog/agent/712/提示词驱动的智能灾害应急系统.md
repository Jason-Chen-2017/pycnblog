1. **信息采集**：
   系统从多个数据源实时采集灾害信息，包括气象数据、地质数据、交通数据等。这些数据源可以是气象卫星、传感器网络、社交媒体等。信息采集模块需要保证数据的实时性、全面性和高效性。

2. **自然语言处理**：
   利用自然语言处理技术对用户输入的提示词进行语义分析，提取关键信息。NLP模块的关键任务包括关键词提取、上下文理解和语义分析。关键词提取可以从提示词中提取出与灾害相关的关键词，如“洪水”、“地震”等。上下文理解则可以帮助系统理解关键词的含义和关系，从而更准确地提取信息。

3. **灾害识别**：
   结合历史数据和实时信息，利用机器学习算法对灾害类型和程度进行识别。灾害识别模块是系统的核心，它需要利用大量的历史数据进行训练，以便能够准确识别不同类型的灾害。常见的机器学习算法包括决策树、支持向量机（SVM）、神经网络等。通过这些算法，系统可以自动识别出灾害的类型和程度，如洪水、地震、台风等。

4. **预案生成**：
   根据识别结果和用户输入的提示词，自动生成相应的应急预案。预案生成模块可以根据不同的灾害类型和程度，从预案库中选择合适的预案。预案库是一个包含各种应急预案的数据库，可以根据实际情况进行定制和更新。预案生成过程需要保证预案的自动化、灵活性和可定制性。

5. **决策支持**：
   为决策者提供实时决策支持，包括风险预警、资源调度、应急措施等。决策支持模块可以根据应急预案和实时信息，为决策者提供具体的行动建议。例如，在洪水预警时，系统可以建议关闭危险地区的交通、疏散居民、调配救援物资等。

    tokens = word_tokenize(prompt)
    # 去除停用词
    stop_words = set(stopwords.words('english'))
    processed_prompt = [word.lower() for word in tokens if word.lower() not in stop_words]
    return processed_prompt
