   ```typescript
   interface Person {
     name: string;
     age: number;
   }
   ```
2. **类**：类是面向对象编程的基础，用于定义对象的属性和方法。类可以被实例化，并可以通过构造函数创建对象。
   ```typescript
   class Person {
     constructor(name: string, age: number) {
       this.name = name;
       this.age = age;
     }
     getName(): string {
       return this.name;
     }
     getAge(): number {
       return this.age;
     }
   }
   ```

#### 1.4.3 泛型

泛型（generic）是一种在编程语言中用于创建可重用组件的机制。泛型使得 TypeScript 能够编写更加灵活和通用的代码。

泛型的示例：
```typescript
interface GenericIdentityFn {
  <T>(value: T): T;
}

function identity<T>(value: T): T {
  return value;
}

let myIdentity: GenericIdentityFn = identity;
myIdentity<string>('hello');
```

#### 1.4.4 装饰器

装饰器（decorator）是一种特殊类型的声明，用于修改类或成员的行为。装饰器通过使用 `@decoratorName` 形式应用于类或成员上方。

装饰器的示例：
```typescript
function logClass(target: any) {
  console.log(`Class ${target.name} created.`);
}

@logClass

  constructor(name: string) {
    console.log(`Creating Person: ${name}`);
  }
}
```
