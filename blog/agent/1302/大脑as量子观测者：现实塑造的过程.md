##### 4.2.1 波函数

波函数是量子力学中描述量子系统状态的数学函数。波函数通常表示为复数函数，如：

ψ(θ, φ) = A * e^(i(θ + φ))

其中，θ 和 φ 是量子态的参数，A 是归一化常数。

##### 4.2.2 波函数坍缩

波函数坍缩是指量子系统的状态从叠加态坍缩为确定的量子态。波函数坍缩可以通过测量实现。以下是一个简单的波函数坍缩过程：

1. **初始化量子态**：ψ(θ, φ) = A * e^(i(θ + φ))
2. **进行测量**：选择特定的测量算符，如 Pauli 矩阵
3. **波函数坍缩**：根据测量结果，波函数坍缩为特定的量子态

##### 4.2.3 测量算符

测量算符是量子力学中描述测量过程的数学工具。常见的测量算符包括 Pauli 矩阵、位置算符、动量算符等。以下是一个简单的测量算符示例：

测量算符 M = |ψ⟩⟨ψ|

其中，|ψ⟩ 是量子系统的状态，⟨ψ| 是测量算符的共轭转置。

##### 4.2.4 波函数演化

波函数演化是指量子系统的状态随时间变化的过程。波函数演化可以通过 Schrödinger 方程描述：

iℏ ∂ψ/∂t = Hψ

其中，ℏ 是约化普朗克常数，H 是哈密顿算符，ψ 是波函数。

##### 4.2.5 量子态演化

量子态演化是指量子系统的状态随时间变化的过程。量子态演化可以通过薛定谔方程描述：

iℏ ∂ψ/∂t = Hψ

其中，ℏ 是约化普朗克常数，H 是哈密顿算符，ψ 是波函数。

##### 4.2.6 示例代码

以下是一个简单的量子态演化示例，使用 Python 实现 Schrödinger 方程：

```
import numpy as np

# 初始化量子态
psi = np.array([1/np.sqrt(2), 1/np.sqrt(2)]) # 初始态 |00⟩

# 初始化时间
t = 0

# 演化时间步长
dt = 0.01

# 演化总时间
T = 10

# 哈密顿算符
H = np.array([[0, 1], [1, 0]])

# 演化函数
def evolve(psi, t):
    return np.exp(-1j * H * t / (2 * np.pi)) * psi

# 演化过程
for _ in range(int(T / dt)):
    psi = evolve(psi, dt)
    print(psi)
```
