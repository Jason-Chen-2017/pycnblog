#### 4.2 系统核心实现

```python
import qiskit

# 创建量子电路
qubit = qiskit.QuantumRegister(1, name='q')
key = qiskit.QuantumRegister(1, name='key')
circuit = qiskit.QuantumCircuit(qubit, key)

# 生成量子纠缠态
circuit.h(qubit[0])
circuit.cx(qubit[0], key[0])

# 测量量子态
circuit.measure(qubit[0], 0)
circuit.measure(key[0], 1)

# 编译电路
backend = qiskit.Aer.get_backend('qasm_simulator')
compiled_circuit = circuit.compile()

# 执行电路
result = qiskit.execute(compiled_circuit, backend=backend, shots=1000)

# 输出结果
print(result.get_counts())
```

在上面的代码中，我们首先创建了一个包含一个量子比特和一个量子密钥的量子电路。接着，我们通过哈密顿量（`h`门）将量子比特设置为叠加态，并通过控制-非门（`cx`门）生成量子纠缠态。之后，我们测量量子比特和量子密钥，以获取加密密钥。
