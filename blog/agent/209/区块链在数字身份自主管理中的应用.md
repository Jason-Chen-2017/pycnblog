- **数据记录**：用户在区块链上进行交易时，会将交易信息发送到网络中的节点。

### 1.2 区块链技术概述

#### 1.2.1 区块链的基本概念

区块链是一种分布式账本技术，其基本概念包括以下几方面：

- **分布式账本**：区块链本质上是一个分布式数据库，它存储在多个节点上，而不是一个中心化的服务器上。这意味着每个节点都保存了一份完整的账本，并且这些节点之间相互协作来维护账本的完整性和一致性。

- **数据区块**：区块链由一系列按时间顺序排列的“区块”组成。每个区块包含一定数量的交易记录，这些交易记录在区块链中被永久存储。新区块通过加密算法与前一区块的哈希值相连接，形成链式数据结构。

- **共识机制**：区块链网络中的节点通过共识机制来达成对数据的共识。共识机制确保了所有节点对区块链的当前状态有一致的认识，避免了“双花”攻击等安全性问题。常见的共识机制包括工作量证明（PoW）、权益证明（PoS）和委托权益证明（DPoS）等。

- **加密算法**：区块链使用加密算法来保护数据的隐私和完整性。加密算法包括哈希函数、公钥加密、数字签名等，它们在区块链的多个环节中发挥作用，确保数据的不可篡改性和交易的安全性。

#### 1.2.2 区块链的工作原理

区块链的工作原理可以概括为以下几步：

1. **数据收集**：当用户在区块链上进行交易时，这些交易信息会被收集起来，暂时存储在交易池中。

2. **交易打包**：矿工（在PoW机制中）或验证者（在PoS机制中）会从交易池中选取一定数量的交易记录，并将它们打包成一个新区块。

3. **区块验证**：新区块在被添加到区块链之前，需要通过网络中的其他节点进行验证。验证过程通常涉及对区块中的交易进行双重检查，以确保它们符合区块链的规则，如交易的有效性和余额足够等。

4. **共识达成**：通过共识机制，网络中的节点就新区块的合法性达成一致。如果共识达成，新区块会被添加到区块链的末端。

5. **链式结构**：每个新区块都包含一个指向前一个区块的哈希值，形成链式结构。这种结构确保了区块链的不可篡改性，因为任何对区块链的修改都会破坏链式结构，导致全网节点的拒绝。

6. **网络同步**：一旦新区块被添加到区块链，网络中的其他节点会下载并验证新区块，以确保其与本地区块链的一致性。网络中的所有节点都维护了一份完整的区块链副本。
