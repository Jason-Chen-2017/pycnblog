#### 4.1 量子傅里叶变换（QFT）

量子傅里叶变换（Quantum Fourier Transform，QFT）是量子计算中的一个核心算法，它可以将量子态从位置表象转换为频率表象，类似于经典傅里叶变换。QFT在量子机器学习中具有重要的应用，例如用于量子机器学习中的特征转换和量子搜索算法。

**量子傅里叶变换的mermaid流程图：**

```mermaid
graph TD
    A[初始量子态] --> B[量子寄存器初始化]
    B --> C[应用量子门序列]
    C --> D[测量]
    D --> E[输出结果]
```

**Python代码实现：**

```python
from qiskit import QuantumCircuit, execute, Aer

# 创建量子电路
qc = QuantumCircuit(4)

# 初始化量子寄存器
qc.h(range(4))

# 应用量子门序列
qc.cnot(0, 1)
qc.cnot(1, 2)
qc.cnot(2, 3)
qc.cnot(0, 1)

# 测量量子寄存器
qc.measure_all()

# 执行量子电路
backend = Aer.get_backend('qasm_simulator')
result = execute(qc, backend).result()

# 输出结果
print(result.get_counts(qc))
```

**数学模型和公式：**

量子傅里叶变换的数学模型可以表示为：

$$
U_{QFT}(n) = \begin{pmatrix}
1 & 0 & \cdots & 0 \\
0 & \omega & \cdots & 0 \\
\vdots & \vdots & \ddots & \vdots \\
0 & 0 & \cdots & \omega^n
\end{pmatrix}
$$

其中，$\omega = e^{2\pi i / n}$。

通过上述Python代码和数学公式，我们可以直观地理解和实现量子傅里叶变换。
