**5.2.4 香水调配算法**

香水调配算法是香水调配系统的核心，主要用于生成最优香水配方。以下是香水调配算法的源代码：

```python
# algorithms/algorithm.py

import itertools

def optimal_combination(ingredients, weights, k):
    combinations = itertools.combinations_with_replacement(ingredients, k)
    max_score = 0
    best_combination = None

    for comb in combinations:
        score = sum([weights[i] for i in comb])
        if score > max_score:
            max_score = score
            best_combination = comb

    return best_combination
```
