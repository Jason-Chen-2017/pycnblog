#### 3.3 Python源代码与LaTeX公式讲解深度学习原理

以下是一个简单的Python源代码示例，用于展示深度学习的基本原理。代码中包含了LaTeX公式，用于解释神经网络的数学模型：

```python
import numpy as np

# 定义神经网络参数
weights = np.random.rand(3, 1)
bias = np.random.rand(1)

# 定义激活函数
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 定义神经网络模型
def neural_network(input_data):
    layer_1 = sigmoid(np.dot(input_data, weights) + bias)
    output = sigmoid(layer_1)
    return output

# 测试神经网络
input_data = np.array([1, 0])
output = neural_network(input_data)

print(output)
```

对应的LaTeX公式为：

$$
\begin{aligned}
    &\text{权重} \ W = \text{随机} \ \text{初始化}, \\
    &\text{偏置} \ b = \text{随机} \ \text{初始化}, \\
    &\text{激活函数} \ \sigma(x) = \frac{1}{1 + \text{e}^{-x}}, \\
    &\text{神经网络模型} \ y = \sigma(Wx + b).
\end{aligned}
$$

#### 4.3 Python源代码与LaTeX公式讲解机器学习原理

以下是一个简单的Python源代码示例，用于展示机器学习的基本原理。代码中包含了LaTeX公式，用于解释线性回归模型的数学模型：

```python
import numpy as np

# 定义线性回归模型参数
weights = np.random.rand(1)
bias = np.random.rand()

# 定义损失函数
def mean_squared_error(y_true, y_pred):
    return np.mean((y_true - y_pred)**2)

# 定义线性回归模型
def linear_regression(input_data, target_data):
    predictions = weights * input_data + bias
    mse = mean_squared_error(target_data, predictions)
    return mse

# 测试线性回归模型
input_data = np.array([1, 2])
target_data = np.array([3])
mse = linear_regression(input_data, target_data)

print(mse)
```

对应的LaTeX公式为：

$$
\begin{aligned}
    &\text{权重} \ w = \text{随机} \ \text{初始化}, \\
    &\text{偏置} \ b = \text{随机} \ \text{初始化}, \\
    &\text{损失函数} \ \text{均方误差} \ MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2, \\
    &\text{线性回归模型} \ \hat{y} = wx + b.
\end{aligned}
$$
