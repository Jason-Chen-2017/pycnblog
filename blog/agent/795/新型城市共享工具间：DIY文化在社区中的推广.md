## 第一部分：背景介绍

### 1.1 问题背景

#### 1.1.1 新型城市共享工具间的定义与需求

新型城市共享工具间是一种以社区为单位，通过共享工具、设备等资源，提高社区居民生活质量、促进社区互助的新型空间。随着城市化进程的加快和人们生活水平的提高，居民对城市资源共享的需求日益增长。共享工具间作为一种新型共享模式，能够有效满足居民对于工具共享的需求，提升社区整体生活品质。

DIY文化（Do It Yourself）是一种强调自主创造、自我动手的文化。它具有以下特点：

**models.py**

```python
from django.db import models

class User(models.Model):
    name = models.CharField(max_length=100)
    age = models.PositiveIntegerField()
    phone_number = models.CharField(max_length=11)

class Tool(models.Model):
    name = models.CharField(max_length=100)
    tool_number = models.CharField(max_length=20)
    tool_category = models.ForeignKey('ToolCategory', on_delete=models.CASCADE)

class ToolCategory(models.Model):
    category_name = models.CharField(max_length=100)

class Activity(models.Model):
    name = models.CharField(max_length=100)
    activity_number = models.CharField(max_length=20)
    activity_category = models.ForeignKey('ActivityCategory', on_delete=models.CASCADE)

class ActivityCategory(models.Model):
    category_name = models.CharField(max_length=100)

class Reward(models.Model):
    reward_name = models.CharField(max_length=100)
    reward_number = models.CharField(max_length=20)
    reward_category = models.ForeignKey('RewardCategory', on_delete=models.CASCADE)

class RewardCategory(models.Model):
    category_name = models.CharField(max_length=100)
```

**views.py**

```python
from django.shortcuts import render
from .models import User, Tool, ToolCategory, Activity, ActivityCategory, Reward, RewardCategory

def index(request):
    return render(request, 'index.html')

def tool_list(request):
    tools = Tool.objects.all()
    return render(request, 'tool_list.html', {'tools': tools})

def activity_list(request):
    activities = Activity.objects.all()
    return render(request, 'activity_list.html', {'activities': activities})

def reward_list(request):
    rewards = Reward.objects.all()
    return render(request, 'reward_list.html', {'rewards': rewards})
```

### 6.3 代码应用解读与分析

在上面的代码中，我们首先定义了四个模型类：`User`、`Tool`、`Activity`和`Reward`，分别对应用户、工具、活动和奖励。每个模型类都包含了相关的字段，例如姓名、年龄、工具名称等。

在`views.py`中，我们定义了三个视图函数：`index`、`tool_list`、`activity_list`和`reward_list`。这些视图函数分别对应了三个页面：首页、工具列表页、活动列表页和奖励列表页。
