2. **犯罪空间分布**：指犯罪案件在地理空间上的分布特征，包括均匀分布、集聚分布和随机分布等。
3. **犯罪传播**：指犯罪现象从一个地区传播到另一个地区的过程，例如犯罪的扩散、迁移等。
4. **犯罪环境**：指影响犯罪现象发生的各种地理和社会经济因素，如人口密度、经济水平、治安状况等。

#### 犯罪决策理论

犯罪决策理论主要研究犯罪者在实施犯罪行为过程中的决策过程。犯罪决策理论可以分为以下几个方面：

1. **理性犯罪决策理论**：理性犯罪决策理论认为犯罪者会进行成本效益分析，选择能带来最大收益的犯罪行为。该理论假设犯罪者具备完全理性，能够准确评估犯罪行为的风险和收益。

    $$ \text{Expected Utility} = \sum_{i=1}^{n} u_i \cdot p_i $$
    其中，$u_i$为犯罪行为$i$的效用，$p_i$为犯罪行为$i$发生的概率。

2. **非理性犯罪决策理论**：非理性犯罪决策理论认为犯罪者的决策过程可能受到情感、认知偏差等因素的影响，不完全遵循理性决策的原则。

3. **社会学习犯罪决策理论**：社会学习犯罪决策理论认为犯罪者的行为受到社会环境和其他犯罪者行为的影响，通过观察和学习他人的行为，形成自己的犯罪策略。

#### 数学模型在犯罪决策中的应用

数学模型在犯罪决策分析中用于描述犯罪者的决策过程，帮助揭示犯罪行为的动机和模式。以下是一些常见的数学模型：

1. **博弈论模型**：博弈论模型用于分析犯罪者之间的策略互动，揭示犯罪者的决策行为。例如，使用纳什均衡模型分析犯罪者如何在竞争环境中选择策略。

    $$ \text{Nash Equilibrium} = (s_1^*, s_2^*) \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ _1 \cdot s_1^* + _2 \cdot s_2^* $$

2. **贝叶斯决策理论**：贝叶斯决策理论用于分析犯罪者在不确定环境中的决策过程。通过历史数据和先验概率，犯罪者可以根据后验概率选择最优策略。

    $$ p(s_j | d) = \frac{p(d | s_j) \cdot p(s_j)}{\sum_{i=1}^{n} p(d | s_i) \cdot p(s_i)} $$
    其中，$s_j$为犯罪者选择的策略，$d$为观测到的结果，$p(d | s_j)$为在策略$s_j$下观测到结果$d$的概率，$p(s_j)$为先验概率。

3. **马尔可夫决策过程（MDP）**：马尔可夫决策过程用于描述犯罪者在动态环境中的决策过程。通过状态转移概率和奖励函数，犯罪者可以在不同状态下选择最优策略。

    $$ V(s) = \max_{a} \sum_{s'} p(s' | s, a) \cdot r(s', a) + \gamma V(s') $$
    其中，$V(s)$为在状态$s$下的最优值函数，$a$为犯罪者选择的动作，$r(s', a)$为在状态$s'$和动作$a$下的即时奖励，$\gamma$为折现因子。

1. **法律平等原则**：所有犯罪行为都应受到法律的平等对待，无论犯罪者的身份、地位和财富状况。
2. **无罪推定原则**：在刑事诉讼中，犯罪嫌疑人在未经法院判决之前，应被视为无罪。
3. **证据原则**：犯罪行为的认定和判决必须基于充分的证据，证据必须合法、可靠和有说服力。
4. **公正原则**：犯罪司法过程应确保公正，包括法官的独立性和程序的公正性。
5. **效率原则**：犯罪司法过程应尽可能高效，减少案件积压，保障司法公正。
