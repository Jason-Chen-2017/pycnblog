```python
# 基于规则的推理示例

class RuleBasedReasoner:
    def __init__(self, rules):
        self.rules = rules

    def reason(self, facts):
        for rule in self.rules:
            if all(fact in facts for fact in rule.conditions):
                return rule.action
        return None

# 定义规则
rules = [
    Rule("今天下雨", "出门要带伞"),
    Rule("气温低于10度", "需要穿厚衣服")
]

# 创建推理器
reasoner = RuleBasedReasoner(rules)

# 输入事实
facts = ["今天下雨"]

# 进行推理
result = reasoner.reason(facts)

# 输出结果
print(result)  # 输出：出门要带伞
```

这个例子展示了如何使用Python实现一个简单的基于规则的推理器。
