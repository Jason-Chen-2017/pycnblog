# 示例：量子叠加态的计算
import numpy as np

### 5.4 算法原理的数学模型和公式

量子叠加态的计算可以通过波函数的叠加实现。波函数的叠加可以表示为：

$$
|\psi\rangle = \sum_{i} c_i |i\rangle
$$

其中，$c_i$ 是复数系数，$|i\rangle$ 是量子状态的基向量。

### 5.5 举例说明

假设我们有一个量子系统，它可以处于两种状态 $|0\rangle$ 和 $|1\rangle$。如果我们应用 Hadamard 门，则系统的状态将变为叠加态：

$$
|\psi\rangle = \frac{1}{\sqrt{2}} (|0\rangle + |1\rangle)
$$

这意味着，系统同时存在于 $|0\rangle$ 和 $|1\rangle$ 两种状态。
