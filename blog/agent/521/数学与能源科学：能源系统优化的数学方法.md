##### Linear Programming

**Algorithmic Principles**

Linear programming (LP) is a mathematical method for optimizing a linear objective function subject to linear constraints. The primary algorithm used for solving LP problems is the Simplex Algorithm, which iteratively moves from one feasible solution to another until an optimal solution is found.

**Mermaid Flowchart**

```mermaid
flowchart TD
    A[Start] --> B[Create Initial Basic Feasible Solution]
    B --> C[Check for Optimal Solution]
    C -->|Yes| D[Optimal Solution]
    C -->|No| E[Perform Pivot Operation]
    E --> F[Pivot]
    F --> C
```

**Python Code Example**

```python
# Import required libraries
import numpy as np
from scipy.optimize import linprog

# Coefficients for the objective function
c = [-1, -1]  # Minimize the sum of x and y

# Coefficients for the inequality constraints
A = [[2, 1], [1, 2]]
b = [4, 2]

# Initial basic feasible solution
x0 = [0, 0]

# Options for the solver
options = {'maxiter': 1000}

# Solve the linear programming problem
result = linprog(c, A_ub=A, b_ub=b, x0=x0, method='highs', options=options)

# Print the results
print("Objective Value:", -result.fun)
print("Solution:", result.x)
```

**Mathematical Models and Formulas**

Consider a linear programming problem with the following form:

$$\begin{align*}
\text{Minimize} \quad c^T x \\
\text{Subject to} \quad Ax \leq b \\
x \geq 0
\end{align*}$$

where \( c \) is the coefficient vector, \( x \) is the variable vector, \( A \) is the constraint matrix, and \( b \) is the right-hand side vector. The Simplex Algorithm works by moving from one basic feasible solution to another until an optimal solution is found. The pivot operation is the heart of the Simplex Algorithm and involves selecting a pivot element to improve the objective function value.

##### Non-Linear Programming

**Algorithmic Principles**

Non-linear programming (NLP) deals with optimizing a non-linear objective function subject to linear or non-linear constraints. Unlike linear programming, there is no single universal algorithm for solving NLP problems. Common methods include gradient-based methods (e.g., sequential quadratic programming, gradient descent) and non-gradient-based methods (e.g., genetic algorithms, simulated annealing).

**Mermaid Flowchart**

```mermaid
flowchart TD
    A[Start] --> B[Numerical Gradient Calculation]
    B --> C[Check for Optimal Solution]
    C -->|Yes| D[Optimal Solution]
    C -->|No| E[Update Solution]
    E --> F[Numerical Hessian Calculation]
    F --> C
```

**Python Code Example**

```python
# Import required libraries
import numpy as np
from scipy.optimize import minimize

# Define the objective function
def objective(x):
    return x[0]**2 + x[1]**2

# Define the constraints
def constraint1(x):
    return x[0]**2 + x[1]**2 - 1

def constraint2(x):
    return - (x[0] - 1)**2 - (x[1] - 1)**2 + 1

# Initial guess
x0 = [1, 1]

# Options for the solver
options = {'maxiter': 1000}

# Solve the non-linear programming problem
result = minimize(objective, x0, method='L-BFGS-B', jac=objective, constraints=[{'type': 'ineq', 'fun': constraint1}, {'type': 'ineq', 'fun': constraint2}], options=options)

# Print the results
print("Objective Value:", result.fun)
print("Solution:", result.x)
```

**Mathematical Models and Formulas**

Consider a non-linear programming problem with the following form:

$$\begin{align*}
\text{Minimize} \quad f(x) \\
\text{Subject to} \quad g_i(x) \leq 0, \quad h_j(x) = 0
\end{align*}$$

where \( f(x) \) is the objective function, \( g_i(x) \) and \( h_j(x) \) are the constraint functions, and \( x \) is the variable vector. Gradient-based methods rely on the gradient of the objective function and constraints to iteratively improve the solution. Non-gradient-based methods, such as genetic algorithms and simulated annealing, use heuristic search strategies to find approximate solutions.

##### Heuristic Algorithms

**Algorithmic Principles**

Heuristic algorithms are problem-solving methods that use practical techniques to find approximate solutions quickly. These methods do not guarantee finding the optimal solution but often provide good solutions in a reasonable amount of time. Common heuristic algorithms include genetic algorithms, simulated annealing, and particle swarm optimization.

**Mermaid Flowchart**

```mermaid
flowchart TD
    A[Start] --> B[Initialize Population/Solutions]
    B --> C[Evaluate Fitness]
    C --> D[Selection]
    D --> E[Crossover/Mutation]
    E --> F[New Population]
    F --> G[Termination Condition]
    G -->|Yes| H[End]
    G -->|No| B
```

**Python Code Example**

```python
# Import required libraries
import numpy as np
from deap import base, creator, tools, algorithms

# Define the fitness function
def fitness(individual):
    return 1 / (individual[0]**2 + individual[1]**2 + 1)

# Define the genetic algorithm
def main():
    creator.create("FitnessMax", base.Fitness, weights=(1.0,))
    creator.create("Individual", list, fitness=creator.FitnessMax)

    toolbox = base.Toolbox()
    toolbox.register("attr_real", np.random.rand)
    toolbox.register("individual", tools.initIterate, creator.Individual, toolbox.attr_real, n=2)
    toolbox.register("population", tools.initRepeat, list, toolbox.individual)
    toolbox.register("evaluate", fitness)
    toolbox.register("select", tools.selTournament, tournsize=3)
    toolbox.register("mate", tools.cxBlend, alpha=0.5)
    toolbox.register("mutate", tools.mutGaussian, mu=0, sigma=1, indpb=0.1)
    toolbox.register("generate", tools.generateSimplex, size=2, range=(0, 1))

    pop = toolbox.population(n=50)
    hof = tools.HallOfFame(1)

    stats = tools.Statistics(lambda ind: ind.fitness.values)
    stats.register("avg", numpy.mean)
    stats.register("min", numpy.min)
    stats.register("max", numpy.max)

    algorithms.eaSimple(pop, toolbox, cxpb=0.5, mutpb=0.2, ngen=40, stats=stats, hallof fame=hof, verbose=True)

    best_ind = hof[0]
    print("Best individual is %s, with fitness = %s" % (best_ind, best_ind.fitness.values))

if __name__ == "__main__":
    main()
```

**Mathematical Models and Formulas**

Heuristic algorithms are typically based on simple principles, such as natural selection, random search, or simulated physical processes. The key advantage of heuristic algorithms is their ability to escape local optima and find good solutions in complex, high-dimensional search spaces. Commonly used heuristic algorithms include:

- **Genetic Algorithms**: Inspired by natural selection, genetic algorithms use operators such as selection, crossover, and mutation to evolve a population of solutions towards better fitness values.
- **Simulated Annealing**: Inspired by the physical process of annealing, simulated annealing uses a temperature parameter to control the acceptance of worse solutions, allowing the algorithm to escape local optima.
- **Particle Swarm Optimization**: Inspired by the social behavior of bird flocking or fish schooling, particle swarm optimization updates the position and velocity of particles based on their own best experience and the best experience of the entire swarm.
