#### 5.2 风险平价策略的数学模型
$$
\begin{aligned}
\text{目标函数}: & \ \min \ \sum_{i=1}^{n} w_i^2 \times \sigma_i^2 \\
\text{约束条件}: & \ \sum_{i=1}^{n} w_i = 1 \\
& \ w_i \geq 0 \quad \forall i
\end{aligned}
$$

#### 5.3 风险平价策略的Python代码示例

```python
import numpy as np

# 定义资产收益率和风险
assets_returns = np.array([0.10, 0.12, 0.08])
assets_risks = np.array([0.05, 0.06, 0.04])

# 计算权重
weights = np.optimize.fmincg(
    fun=lambda x: np.sum(x**2 * assets_risks**2),
    x0=np.ones(len(assets_returns)) / len(assets_returns),
    args=(),
    method='BFGS',
    options={'maxiter': 1000, 'disp': True}
)

# 输出结果
print("权重:", weights)
```

#### 6.1 资产配置优化算法的定义

#### 6.2 资产配置优化算法的数学模型
$$
\begin{aligned}
\text{目标函数}: & \ \max \ \sum_{i=1}^{n} w_i \times \mu_i \\
\text{约束条件}: & \ \sum_{i=1}^{n} w_i = 1 \\
& \ w_i \geq 0 \quad \forall i
\end{aligned}
$$

#### 6.3 资产配置优化算法的Python代码示例

```python
import numpy as np
from scipy.optimize import minimize

# 定义资产收益率和风险
assets_returns = np.array([0.10, 0.12, 0.08])
assets_risks = np.array([0.05, 0.06, 0.04])

# 定义目标函数
def objective(weights):
    return -np.sum(weights * assets_returns)

# 定义约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 初始权重
weights0 = np.ones(len(assets_returns)) / len(assets_returns)

# 最小化目标函数
result = minimize(objective, weights0, method='SLSQP', constraints={'type': 'eq', 'fun': constraint})

# 输出结果
print("最优权重:", result.x)
```

from scipy.optimize import minimize

# 定义资产收益率和风险
assets_returns = np.array([0.10, 0.12, 0.08])
assets_risks = np.array([0.05, 0.06, 0.04])

# 定义目标函数
def objective(weights):
    return -np.sum(weights * assets_returns)

# 定义约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 初始权重
weights0 = np.ones(len(assets_returns)) / len(assets_returns)
