```python
import turtle
import time

def draw_circle(radius):
    turtle.circle(radius)

def draw_maze():
    for i in range(10):
        draw_circle(50)
        time.sleep(1)

if __name__ == "__main__":
    turtle.speed(10)
    draw_maze()
    turtle.done()
```

在这个示例中，我们使用`turtle`库创建了一个简单的画布，并绘制了10个圆形。通过调整`radius`参数，可以改变圆形的大小。`time.sleep(1)`用于控制绘制速度，使其具有动态效果。

### 2.2 虚拟现实（VR）技术

虚拟现实（VR）技术是新媒体艺术中的一项重要技术。它通过计算机生成三维环境，使用户能够在其中自由探索和互动。VR技术广泛应用于艺术展览、互动装置和虚拟艺术表演等领域。以下是一个简单的VR场景示例，使用Unity引擎创建：

```csharp
using UnityEngine;

public class VRScene : MonoBehaviour
{
    public Material material;
    public Vector3 position;
    public Quaternion rotation;

    void Start()
    {
        GameObject sphere = new GameObject("Sphere");
        MeshFilter meshFilter = sphere.AddComponent<MeshFilter>();
        meshFilter.mesh = new Mesh();
        meshFilter.mesh.vertices = new Vector3[] { position };
        meshFilter.mesh.RecalculateBounds();
        meshFilter.mesh.RecalculateNormals();

        sphere.AddComponent<MeshRenderer>().material = material;
    }

    void Update()
    {
        transform.rotation = rotation;
    }
}
```

在这个示例中，我们创建了一个简单的三维球体，并通过调整`position`和`rotation`参数，实现球体的实时旋转。Unity引擎提供了丰富的VR开发工具和资源，使得VR艺术创作变得更加便捷。
