#### 5.4 数学模型与公式讲解

提示词生成算法通常涉及到以下数学模型：

1. **词频分布模型**：描述单词在文本中的频率分布。
   \[ P(w|T) = \frac{f(w, T)}{N} \]

#### 5.5 举例说明

```python
import nltk
from nltk.corpus import stopwords
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans

# 1. 预处理文本数据
nltk.download('stopwords')
stop_words = set(stopwords.words('english'))
text = ["我喜欢去旅游", "我想去度假", "我想了解最近的旅游资讯"]

preprocessed_texts = [text.lower().replace('.', '').replace(',', '') for text in text]
filtered_texts = [' '.join(word for word in text.split() if word not in stop_words) for text in preprocessed_texts]

# 2. 特征提取
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform(filtered_texts)

# 3. K-means聚类
kmeans = KMeans(n_clusters=3)
clusters = kmeans.fit_predict(tfidf_matrix)

# 4. 生成提示词
prompt_words = vectorizer.get_feature_names_out()
for i in range(3):
    cluster_words = [prompt_words[index] for index, cluster in enumerate(clusters) if cluster == i]
    print(f"Cluster {i}: {' '.join(cluster_words)}")
```

```
Cluster 1: 旅游 去哪里
Cluster 2: 旅游 资讯
```

根据这些聚类结果，我们可以生成相应的提示词，例如：“想去度假吗？”， “想了解旅游资讯吗？”等。
