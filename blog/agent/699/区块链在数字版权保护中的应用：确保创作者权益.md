### 3.1 哈希算法原理讲解

哈希算法是区块链技术中的核心组件之一，其作用是将任意长度的数据映射为固定长度的字符串。这种映射过程具有以下特性：

- **不可逆性**：给定一个哈希值，无法反推出原始数据。
- **确定性**：相同的输入数据将始终产生相同的哈希值。
- **抗碰撞性**：不同的输入数据产生相同哈希值的概率极低。

哈希算法在数字版权保护中的应用主要体现在：

1. **版权标识**：通过对数字内容进行哈希计算，生成唯一的哈希值，作为数字内容的版权标识。

#### Python代码示例

```python
from Crypto.PublicKey import RSA
from Crypto.Signature import pkcs1_15
from Crypto.Hash import SHA256

def generate_keypair():
    key = RSA.generate(2048)
    private_key = key.export_key()
    public_key = key.publickey().export_key()
    return private_key, public_key

def sign_data(data, private_key):
    rsakey = RSA.import_key(private_key)
    hasher = SHA256.new(data.encode())
    signature = pkcs1_15.new(rsakey).sign(hasher)
    return signature

def verify_signature(data, signature, public_key):
    rsakey = RSA.import_key(public_key)
    hasher = SHA256.new(data.encode())
    try:
        pkcs1_15.new(rsakey).verify(hasher, signature)
        print("Signature is valid.")
    except (ValueError, TypeError):
        print("Signature is not valid.")

# 测试
private_key, public_key = generate_keypair()
data = "This is a sample digital content."
signature = sign_data(data, private_key)
verify_signature(data, signature, public_key)
```
