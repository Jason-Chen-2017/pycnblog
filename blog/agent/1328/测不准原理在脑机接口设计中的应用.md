import numpy as np

# 设定参数
sample_rate = 1000  # 采样率
time_duration = 1  # 信号持续时间（秒）
noise_level = 0.1  # 噪声水平
signal_power = 0.5  # 信号功率

# 生成时间序列
t = np.linspace(0, time_duration, sample_rate*time_duration)

# 生成真实信号
true_signal = np.sin(2 * np.pi * 5 * t)

# 添加噪声
noise = noise_level * np.random.normal(0, 1, size=sample_rate*time_duration)
noisy_signal = true_signal + noise

# 应用测不准原理：降低噪声水平
uncertainty_adjustment = 1 / np.sqrt(2)  # 对噪声进行不确定性调整
adjusted_noise = uncertainty_adjustment * np.random.normal(0, 1, size=sample_rate*time_duration)

# 生成调整后的信号
adjusted_signal = noisy_signal - adjusted_noise

# 信号解码算法：简单阈值检测
def decode_signal(signal):
    threshold = 0
    decoded = []
    for i in range(len(signal) - 1):
        if signal[i] > threshold:
            decoded.append(1)
        else:
            decoded.append(0)
    return decoded

# 解码原始信号
decoded_noisy_signal = decode_signal(noisy_signal)
# 解码调整后信号
decoded_adjusted_signal = decode_signal(adjusted_signal)

# 打印结果
print("原始信号解码结果:", decoded_noisy_signal)
print("调整后信号解码结果:", decoded_adjusted_signal)

plt.legend()
plt.show()

脑机接口系统旨在帮助无法通过传统方式（如手指、嘴巴等）控制设备的用户，如瘫痪患者、中风康复者、肢体缺失者等，通过直接使用大脑信号来操控外部设备。问题场景包括：

1. **信号采集**：如何有效地从大脑中捕获和记录电信号。
2. **信号处理**：如何处理和预处理采集到的信号，以提高信号质量。
3. **信号解码**：如何将预处理后的信号解码为可操作的控制信号。
4. **信号传输**：如何将解码后的控制信号可靠地传输到外部设备。
5. **信号执行**：如何确保外部设备能够正确地响应解码后的控制信号。

### 系统功能设计

脑机接口系统的核心功能包括：

1. **信号采集**：使用脑电图（EEG）或其他脑信号检测设备实时采集大脑信号。
2. **信号预处理**：包括滤波、去噪、放大等步骤，以提高信号质量。
3. **特征提取**：从预处理后的信号中提取与控制意图相关的特征。
4. **信号解码**：使用机器学习算法或其他信号处理技术，将提取的特征解码为控制信号。
5. **信号传输**：将解码后的控制信号通过无线或有线方式传输到外部设备。
6. **信号执行**：外部设备根据接收到的控制信号执行相应的操作，如控制轮椅、假肢或游戏控制器等。

### 系统架构设计

脑机接口系统的整体架构设计如下：

1. **信号采集模块**：负责从用户的大脑中实时采集脑信号，通常包括脑电图（EEG）传感器、脑磁图（MEG）传感器等。
2. **信号预处理模块**：对采集到的原始脑信号进行滤波、去噪、放大等预处理步骤，以提高信号质量。
3. **特征提取模块**：从预处理后的信号中提取与控制意图相关的特征，如时域特征、频域特征、时频特征等。
4. **信号解码模块**：使用机器学习算法或其他信号处理技术，将提取的特征解码为控制信号。
5. **信号传输模块**：将解码后的控制信号通过无线或有线方式传输到外部设备。
6. **信号执行模块**：外部设备根据接收到的控制信号执行相应的操作。

### 系统接口设计

系统接口设计确保各个模块之间能够高效地通信和协作。以下是脑机接口系统的关键接口设计：

1. **信号采集接口**：定义了信号采集模块与预处理模块之间的接口，确保信号能够顺利传递。
2. **预处理接口**：定义了预处理模块与特征提取模块之间的接口，包括信号滤波、去噪、放大等功能。
3. **特征提取接口**：定义了特征提取模块与解码模块之间的接口，确保特征能够正确传递和利用。
4. **解码接口**：定义了解码模块与传输模块之间的接口，确保解码后的控制信号能够及时传递。
5. **传输接口**：定义了传输模块与执行模块之间的接口，确保控制信号能够准确传输到外部设备。
6. **执行接口**：定义了执行模块与其他系统（如轮椅控制、游戏控制系统等）之间的接口，确保操作能够正确执行。
