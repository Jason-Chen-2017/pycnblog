## 第2章 微分方程基本概念

### 2.1 微分方程的定义与分类

微分方程是描述未知函数及其导数之间关系的方程。具体来说，微分方程是包含未知函数及其导数的方程，通常表示为：

\[ F(x, y, y', y'', ...) = 0 \]

其中，\( F \) 是一个已知函数，\( x \) 是自变量，\( y \) 是未知函数，\( y' \)，\( y'' \) 等是 \( y \) 的导数。根据微分方程中导数的阶数，可以将微分方程分为以下几类：

1. **常微分方程**：导数的阶数是常数。例如，一阶常微分方程 \( y' + P(x)y = Q(x) \) 和二阶常微分方程 \( y'' + P(x)y' + Q(x)y = R(x) \)。
2. **偏微分方程**：导数的阶数是变量。例如，热传导方程 \( \frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2} \) 和波动方程 \( \frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2} \)。
3. **微分方程组**：包含多个未知函数及其导数的方程组。例如，牛顿第二定律 \( m\frac{d^2 x}{dt^2} = F(x, y) \) 和 \( m\frac{d^2 y}{dt^2} = G(x, y) \)。

### 2.2 微分方程的解法概述

微分方程的解法主要包括解析解法和数值解法。解析解法通过数学变换或积分等方法直接求解微分方程，适用于某些简单或特定类型的微分方程。数值解法则是通过迭代或逼近方法，将微分方程离散化，得到数值解。以下是几种常见的数值解法：

1. **欧拉法**：一种简单的迭代方法，适用于一阶常微分方程。基本思想是利用当前点的斜率预测下一个点的位置。公式如下：

   \[ y_{n+1} = y_n + h \cdot f(t_n, y_n) \]

   其中，\( h \) 是步长，\( f(t_n, y_n) \) 是函数值。

2. **改进的欧拉法**：也称为Heun方法，它是对欧拉法的一种改进，提高了解的精度。公式如下：

   \[ y_{n+1} = y_n + h \cdot \frac{f(t_n, y_n) + f(t_n + h, y_n + h \cdot f(t_n, y_n))}{2} \]

3. **龙格-库塔法**：一种多步迭代方法，适用于各种阶数的微分方程。常用的有二阶、四阶和六阶龙格-库塔法。四阶龙格-库塔法的公式如下：

   \[ y_{n+1} = y_n + \frac{h}{6} (k_1 + 2k_2 + 2k_3 + k_4) \]

   其中，\( k_1 = f(t_n, y_n) \)，\( k_2 = f(t_n + \frac{h}{2}, y_n + \frac{h}{2}k_1) \)，\( k_3 = f(t_n + \frac{h}{2}, y_n + \frac{h}{2}k_2) \)，\( k_4 = f(t_n + h, y_n + h \cdot k_3) \)。

### 2.3 微分方程的数学模型

微分方程的数学模型是描述实际问题的数学框架，通常包括以下部分：

1. **模型假设**：对现实世界的简化假设，如线性假设、稳态假设等。
2. **变量定义**：明确模型中的变量，包括自变量、因变量及它们的导数。
3. **微分方程**：描述变量之间关系的微分方程，通常包括一阶或高阶微分方程。
4. **边界条件**：定义模型在特定边界上的行为，如初值条件、终值条件等。

## 第3章 数值解法介绍

### 3.1 数值解法的概述

数值解法是一种通过离散化连续微分方程，求取其近似解的方法。由于解析解法在某些复杂情况下难以得到解析解或解过于复杂，数值解法成为解决这些问题的有效手段。数值解法的基本思想是将连续的微分方程转化为离散的方程组，通过迭代或逼近的方法求解。数值解法广泛应用于科学计算、工程仿真、金融模型等领域。

### 3.2 常见的数值解法算法

在数值解法中，有许多算法被广泛应用，每种算法有其独特的优势和局限性。以下是几种常见的数值解法算法：

#### 1. 欧拉法

欧拉法是最简单也是最直观的数值解法之一，适用于一阶常微分方程。其基本思想是使用当前点的斜率来预测下一个点的值。欧拉法的公式如下：

\[ y_{n+1} = y_n + h \cdot f(t_n, y_n) \]

其中，\( h \) 是时间步长，\( f(t_n, y_n) \) 是当前点的函数值。

#### 2. 改进的欧拉法

改进的欧拉法（Heun方法）是对欧拉法的一种改进，其通过计算当前点和预测点的函数值，得到更精确的解。改进的欧拉法的公式如下：

\[ y_{n+1} = y_n + h \cdot \frac{f(t_n, y_n) + f(t_n + h, y_n + h \cdot f(t_n, y_n))}{2} \]

#### 3. 龙格-库塔法

龙格-库塔法是一种多步迭代方法，适用于各种阶数的微分方程。常用的有二阶、四阶和六阶龙格-库塔法。四阶龙格-库塔法的公式如下：

\[ y_{n+1} = y_n + \frac{h}{6} (k_1 + 2k_2 + 2k_3 + k_4) \]

其中，\( k_1 = f(t_n, y_n) \)，\( k_2 = f(t_n + \frac{h}{2}, y_n + \frac{h}{2}k_1) \)，\( k_3 = f(t_n + \frac{h}{2}, y_n + \frac{h}{2}k_2) \)，\( k_4 = f(t_n + h, y_n + h \cdot k_3) \)。

#### 4. 马尔可夫链蒙特卡罗法

马尔可夫链蒙特卡罗法（MCMC）是一种基于概率统计的数值解法，适用于高维和非线性微分方程。其基本思想是通过构建马尔可夫链，模拟随机变量的采样，从而得到方程的近似解。

### 3.3 算法比较与选择

每种数值解法都有其适用范围和优缺点，选择合适的算法取决于具体的问题特点。以下是几种数值解法的比较：

| 算法         | 适用范围                   | 优点                                         | 缺点                                      |
|--------------|----------------------------|--------------------------------------------|--------------------------------------------|
| 欧拉法       | 一阶常微分方程             | 简单直观，易于实现                         | 精度低，稳定性差                           |
| 改进的欧拉法 | 一阶常微分方程             | 精度较欧拉法高，计算量适中                 | 仍存在稳定性问题                           |
| 龙格-库塔法 | 各种阶数的微分方程         | 高精度，稳定性好                         | 计算复杂度高，计算量较大                   |
| 马尔可夫链蒙特卡罗法 | 高维和非线性微分方程       | 能够处理复杂非线性问题，适用于高维问题     | 计算量巨大，收敛速度慢                     |

在实际应用中，选择数值解法时需要考虑以下因素：

1. **微分方程的类型**：根据微分方程的阶数和特性选择合适的算法。
2. **计算资源的限制**：计算资源（如CPU、内存）是选择算法的重要考虑因素。
3. **精度要求**：根据问题的精度要求选择合适的算法。
4. **稳定性**：选择稳定性好的算法可以避免数值解的失真。

通过以上分析，我们可以看到，数值解法在模拟器设计中的应用非常广泛。不同的数值解法适用于不同类型和特性的微分方程，选择合适的算法对于提高模拟器的精度和稳定性具有重要意义。在下一章中，我们将进一步探讨模拟器设计的基本原理和流程。

### 3.4 Python代码实现

#### 欧拉法实现

欧拉法的实现相对简单，以下是一个简单的Python代码示例：

```python
import numpy as np
import matplotlib.pyplot as plt

def euler_method(y0, x0, x_end, h, f):
    x = [x0]
    y = [y0]
    while x[-1] < x_end:
        y_new = y[-1] + h * f(x[-1], y[-1])
        x_new = x[-1] + h
        x.append(x_new)
        y.append(y_new)
    return x, y

def f(t, y):
    return 2 * y

y0 = 1
x0 = 0
x_end = 1
h = 0.1

x, y = euler_method(y0, x0, x_end, h, f)

plt.plot(x, y, 'ro-')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Euler Method')
plt.show()
```

```python
import numpy as np
import matplotlib.pyplot as plt

def runge_kutta_method(y0, x0, x_end, h, f):
    x = [x0]
    y = [y0]
    while x[-1] < x_end:
        k1 = h * f(x[-1], y[-1])
        k2 = h * f(x[-1] + 0.5 * h, y[-1] + 0.5 * k1)
        k3 = h * f(x[-1] + 0.5 * h, y[-1] + 0.5 * k2)
        k4 = h * f(x[-1] + h, y[-1] + k3)
        y_new = y[-1] + (k1 + 2 * k2 + 2 * k3 + k4) / 6
        x_new = x[-1] + h
        x.append(x_new)
        y.append(y_new)
    return x, y

def f(t, y):
    return 2 * y

y0 = 1
x0 = 0
x_end = 1
h = 0.1

x, y = runge_kutta_method(y0, x0, x_end, h, f)

plt.plot(x, y, 'ro-')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Runge-Kutta Method')
plt.show()
```

#### 微分方程的数学模型

微分方程的数学模型通常由以下部分组成：

1. **导数表示**：描述未知函数及其导数之间的关系。
2. **初始条件**：定义方程在某一时刻的初始状态。
3. **边界条件**：定义方程在某一边界上的特定行为。

常见的微分方程数学模型包括：

1. **常微分方程**：例如，一阶常微分方程 \( y' = f(x, y) \) 和二阶常微分方程 \( y'' = f(x, y, y') \)。

\[ y_{n+1} = y_n + h \cdot f(t_n, y_n) \]

其中，\( h \) 是时间步长，\( f(t_n, y_n) \) 是当前点的函数值。

#### 数学公式的详细解释

1. **初始条件**：初始条件用于确定微分方程的初始状态。例如，对于一阶常微分方程 \( y' = f(x, y) \)，初始条件可以表示为 \( y(x_0) = y_0 \)。

3. **函数值计算**：在数值解法中，函数值 \( f(t_n, y_n) \) 需要通过具体的函数形式来计算。例如，对于一阶常微分方程 \( y' = 2y \)，函数值可以计算为 \( f(t_n, y_n) = 2 \cdot y_n \)。

### 3.7 数值解法的实际应用案例

为了更好地展示数值解法在模拟器设计中的应用，我们将在以下部分讨论一个具体的实际应用案例。该案例涉及使用欧拉法求解一维热传导方程，并使用Python进行编程实现。

#### 案例背景

一维热传导方程描述了热量在固体或流体中的传播过程。该方程通常表示为：

\[ \frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2} \]

其中，\( u(x, t) \) 是温度分布，\( \alpha \) 是热扩散系数。假设一个长度为 \( L \) 的均匀杆，初始温度分布为 \( u(x, 0) = f(x) \)，两端温度保持恒定，即边界条件为 \( u(0, t) = T_0 \) 和 \( u(L, t) = T_1 \)。

#### 数学模型与公式

为了求解一维热传导方程，我们首先需要将其离散化。我们将时间 \( t \) 分成 \( N \) 个等间隔的小段，时间步长为 \( \Delta t \)，将空间 \( x \) 分成 \( M \) 个等间隔的小段，空间步长为 \( \Delta x \)。离散化后的热传导方程可以表示为：

\[ u_i^{n+1} = u_i^n + \alpha \frac{\Delta t}{\Delta x^2} (u_{i+1}^n - 2u_i^n + u_{i-1}^n) \]

其中，\( u_i^n \) 表示在 \( i \) 点和第 \( n \) 次迭代时的温度。

#### 欧拉法的Python实现

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数设置
L = 10  # 杆的长度
T0 = 100  # 左端温度
T1 = 0  # 右端温度
alpha = 0.1  # 热扩散系数
dx = 0.1  # 空间步长
dt = 0.01  # 时间步长
N = int(L / dx)  # 空间点的数量
M = int(L / dx)  # 时间点的数量

# 初始温度分布
u = np.zeros((N, M))
u[0, :] = T0
u[-1, :] = T1
u[1:-1, 0] = (T0 - T1) * np.linspace(0, 1, N-2)

# 欧拉法迭代
for n in range(1, M):
    for i in range(1, N-1):
        u[i, n] = u[i, n-1] + alpha * dt / dx**2 * (u[i+1, n-1] - 2*u[i, n-1] + u[i-1, n-1])

# 绘图
plt.imshow(u, extent=[0, L, 0, M*dt], aspect='auto')
plt.colorbar()
plt.xlabel('x')
plt.ylabel('t')
plt.title('Heat Conduction using Euler Method')
plt.show()
```

运行上述代码后，我们可以看到热量在杆中的传播过程。通过观察图像，我们可以发现：

2. 热量在杆中的传播速度取决于热扩散系数 \( \alpha \)。
3. 初始时刻的温度分布对最终的温度分布有显著影响。

通过这个实际应用案例，我们可以看到数值解法在模拟器设计中的应用。欧拉法作为一种简单的数值解法，可以用于求解热传导方程等一维微分方程。在实际工程和科学计算中，选择合适的数值解法对于提高模拟精度和效率至关重要。

### 4.1 模拟器设计的基本概念

模拟器是一种用于模拟现实世界系统行为的计算机程序。它通过建立数学模型，将现实世界的问题转化为可以在计算机上求解的方程，从而对系统行为进行预测和分析。模拟器设计的基本概念包括以下几个核心要素：

1. **数学模型**：模拟器的核心是数学模型，它描述了系统的行为和特性。数学模型可以是微分方程、差分方程、代数方程等。这些方程能够准确地描述系统在给定输入和条件下如何响应。
2. **输入与输出**：模拟器的输入是系统运行的环境参数和初始条件，输出是系统在不同时间点的状态和行为。通过输入和输出的交互，模拟器可以模拟系统的动态过程。
3. **时间步长**：模拟器通常采用离散时间步长来计算系统状态。时间步长决定了模拟的精度和效率，过小的时间步长会导致计算复杂度增加，而过大的时间步长可能导致模拟结果不准确。
4. **算法**：模拟器中使用数值解法（如欧拉法、龙格-库塔法等）来求解微分方程，获得系统在每个时间步的状态。
5. **可视化**：为了便于理解和分析模拟结果，模拟器通常提供可视化的功能，如数据可视化、动画展示等。

### 4.2 模拟器设计的流程与方法

```python
import numpy as np

def heat_conduction(u, alpha, dx, dt):

```

### 5.6 应用案例分析

为了更好地展示微分方程在模拟器设计中的应用，我们将在以下部分通过两个具体案例进行详细分析。

#### 案例一：流体动力学模拟

##### 案例背景

我们考虑一个二维不可压缩流体在矩形区域内的运动，流体速度入口设在左边界，压力出口设在右边界。流体速度入口设为 \( u = 1 \) m/s，压力出口设为 \( p = 0 \) Pa。我们使用Navier-Stokes方程来模拟流体的运动。

##### 数学模型

Navier-Stokes方程描述了流体运动的速度场和压力场。对于二维不可压缩流体，Navier-Stokes方程可以表示为：

\[ \frac{\partial u}{\partial t} + (u \cdot \nabla)u = -\frac{1}{\rho} \nabla p + \nu \nabla^2 u \]
\[ \frac{\partial v}{\partial t} + (v \cdot \nabla)u = -\frac{1}{\rho} \nabla p + \nu \nabla^2 v \]

其中，\( u \) 和 \( v \) 分别是流体速度在 \( x \) 和 \( y \) 方向上的分量，\( p \) 是压力，\( \rho \) 是流体密度，\( \nu \) 是动 viscosity。

##### 数值方法

我们使用有限体积法（Finite Volume Method，FVM）来离散Navier-Stokes方程。有限体积法将计算区域划分为一系列的小控制体，并在每个控制体上应用积分形式的Navier-Stokes方程。

##### 实现过程

1. **区域划分**：将计算区域划分为矩形网格，每个网格单元定义为一个控制体。

2. **离散化方程**：将Navier-Stokes方程离散化，得到在每个控制体上的差分方程。

3. **迭代求解**：使用迭代方法（如SIMPLE算法）求解离散化后的Navier-Stokes方程，迭代过程包括速度迭代和压力迭代。

4. **边界条件处理**：在边界上设置适当的边界条件，如入口速度边界条件和出口压力边界条件。

##### 案例结果

通过上述步骤，我们得到流体速度和压力分布。使用Matplotlib库，我们可以绘制流体速度和压力分布的等高线图。

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数设置
Lx = 10  # 区域长度
Ly = 5  # 区域宽度
Nx = 100  # 网格数
Ny = 50  # 网格数
dx = Lx / Nx  # 空间步长
dy = Ly / Ny  # 空间步长

# 初始化速度和压力数组
u = np.zeros((Ny+1, Nx+1))
v = np.zeros((Ny+1, Nx+1))
p = np.zeros((Ny+1, Nx+1))

# 边界条件
u[1:, 0] = 1  # 入口速度边界条件
p[-1, :] = 0  # 出口压力边界条件

# 迭代求解
for i in range(Ny):
    for j in range(Nx):
        # 速度迭代
        u[i+1, j] = (u[i, j] + 0.5 * dx * (p[i, j+1] - p[i, j-1]) / dx + 0.5 * dy * (p[i+1, j] - p[i-1, j]) / dy) / (1 + dx * dy)
        v[i, j+1] = (v[i, j] + 0.5 * dx * (p[i, j+2] - p[i, j]) / dx + 0.5 * dy * (p[i+1, j+1] - p[i-1, j+1]) / dy) / (1 + dx * dy)

# 绘制结果
plt.figure()
plt.contourf(u, levels=10)
plt.xlabel('x')
plt.ylabel('y')
plt.title('Streamlines of Velocity')
plt.show()

plt.figure()
plt.contourf(p, levels=10)
plt.xlabel('x')
plt.ylabel('y')
plt.title('Pressure Distribution')
plt.show()
```

##### 分析与讨论

通过上述实现，我们可以看到流体速度在入口处以较高的速度流入，逐渐在区域内扩散，并最终在出口处以较低的速度流出。压力分布则表现出从入口到出口的逐渐降低。

#### 案例二：电路模拟

##### 案例背景

我们考虑一个RLC电路，包括一个电阻 \( R = 10 \) 欧姆，一个电感 \( L = 1 \) 毫亨利，和一个电容 \( C = 1 \) 微法拉。电路受到一个幅值为 \( V_0 = 10 \) 伏特的正弦波激励信号。我们使用电路方程来模拟电压和电流的变化。

##### 数学模型

RLC电路的电压和电流关系由以下方程描述：

\[ V_R + V_L + V_C = V_0 \sin(\omega t) \]
\[ i_R = i_L + i_C \]

其中，\( V_R \)、\( V_L \) 和 \( V_C \) 分别是电阻、电感和电容上的电压，\( i_R \)、\( i_L \) 和 \( i_C \) 分别是电阻、电感和电容上的电流，\( \omega \) 是角频率。

##### 数值方法

我们使用欧拉法来求解电路方程，迭代计算电压和电流。

##### 实现过程

1. **初始化**：初始化电压和电流数组。

2. **迭代求解**：使用欧拉法迭代求解电路方程，直到达到预定的精度或迭代次数。

3. **绘制结果**：绘制电压和电流的波形。

##### 案例结果

通过上述实现，我们得到电压和电流的波形图。使用Matplotlib库，我们可以绘制电压和电流的波形。

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数设置
V0 = 10  # 激励电压幅值
R = 10  # 电阻
L = 1e-3  # 电感
C = 1e-6  # 电容
omega = 2 * np.pi * 1  # 角频率
dt = 0.01  # 时间步长
t_max = 0.5  # 最大时间
N = int(t_max / dt)  # 时间步数

# 初始化电压和电流数组
V_R = np.zeros(N)
V_L = np.zeros(N)
V_C = np.zeros(N)
i_R = np.zeros(N)
i_L = np.zeros(N)
i_C = np.zeros(N)

# 欧拉法迭代求解
V0 = 10
for i in range(N):
    V_R[i] = (V0 * np.sin(omega * t) - V_L[i] - V_C[i]) / R
    i_R[i] = V_R[i] / R
    V_L[i] = L * (i_L[i] - i_R[i])
    i_L[i] = V_L[i] / L
    V_C[i] = C * (i_C[i] - i_R[i])
    i_C[i] = V_C[i] / C

# 绘制结果
plt.figure()
plt.plot(t * dt, V_R, label='V_R')
plt.plot(t * dt, V_L, label='V_L')
plt.plot(t * dt, V_C, label='V_C')
plt.xlabel('Time (s)')
plt.ylabel('Voltage (V)')
plt.title('Voltage Waveform')
plt.legend()
plt.show()

plt.figure()
plt.plot(t * dt, i_R, label='i_R')
plt.plot(t * dt, i_L, label='i_L')
plt.plot(t * dt, i_C, label='i_C')
plt.xlabel('Time (s)')
plt.ylabel('Current (A)')
plt.title('Current Waveform')
plt.legend()
plt.show()
```

##### 分析与讨论

通过上述实现，我们可以看到电压和电流的波形呈现出振荡特性。电压和电流之间存在相位差，这是由电感和电容的储能特性所导致的。电阻上的电压和电流始终保持同相位，这是因为电阻不存储能量。

通过这两个具体案例，我们可以看到微分方程在模拟器设计中的广泛应用。无论是流体动力学模拟还是电路模拟，微分方程都提供了精确的数学模型，使得模拟器能够准确预测和解释系统的行为。

   ```python
   # 初始温度分布
   ```

   ```python
   def heat_conduction_step(u, alpha, dx, dt):

       return u_new
   ```

   ```python
   u_history = [u]

       u = heat_conduction_step(u, alpha, dx, dt)

   ```

5. **可视化**：

#### 实际案例分析与详细讲解剖析

为了更好地展示微分方程在模拟器设计中的应用，我们将通过以下实际案例进行分析：

##### 案例背景

假设我们有一个长度为 \( L = 20 \) 米的管道，其中含有流体，需要通过模拟器来分析流体在管道中的运动。管道的一端连接到一个恒定的流速源，另一端是一个压力传感器。流体的速度入口设为 \( u = 2 \) m/s，压力出口设为 \( p = 0 \) Pa。流体密度 \( \rho = 1000 \) kg/m\(^3\)，动 viscosity \( \mu = 0.01 \) Pa·s。

##### 数学模型

流体在管道中的运动可以由Navier-Stokes方程描述：

\[ \frac{\partial u}{\partial t} + (u \cdot \nabla)u = -\frac{1}{\rho} \nabla p + \nu \nabla^2 u \]
\[ \frac{\partial v}{\partial t} + (v \cdot \nabla)u = -\frac{1}{\rho} \nabla p + \nu \nabla^2 v \]

其中，\( u \) 和 \( v \) 分别是流体速度在 \( x \) 和 \( y \) 方向上的分量，\( p \) 是压力，\( \rho \) 是流体密度，\( \nu \) 是动 viscosity。

##### 数值方法

我们使用有限体积法（Finite Volume Method，FVM）来离散Navier-Stokes方程。FVM将计算区域划分为一系列的小控制体，并在每个控制体上应用积分形式的Navier-Stokes方程。

##### 实现过程

1. **区域划分**：将管道划分为矩形网格，每个网格单元定义为一个控制体。
2. **离散化方程**：将Navier-Stokes方程离散化，得到在每个控制体上的差分方程。
3. **迭代求解**：使用迭代方法（如SIMPLE算法）求解离散化后的Navier-Stokes方程，迭代过程包括速度迭代和压力迭代。
4. **边界条件处理**：在边界上设置适当的边界条件，如入口速度边界条件和出口压力边界条件。

##### 案例结果

通过上述步骤，我们得到流体速度和压力分布。以下是关键代码和结果解析：

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数设置
L = 20.0  # 管道长度（米）
u_inlet = 2.0  # 入口速度（m/s）
p_outlet = 0.0  # 出口压力（Pa）
rho = 1000.0  # 流体密度（kg/m^3）
mu = 0.01  # 动 viscosity（Pa·s）
dx = 0.1  # 空间步长（米）
dt = 0.001  # 时间步长（秒）
N = int(L / dx)  # 空间点的数量
M = int(1 / dt)  # 时间点的数量

# 初始化速度和压力数组
u = np.zeros((N+1,))
v = np.zeros((N+1,))
p = np.zeros((N+1,))

# 边界条件
u[0] = u_inlet
p[-1] = p_outlet

# 迭代求解
for i in range(N):
    for j in range(M):
        # 速度迭代
        u_new = u.copy()
        v_new = v.copy()
        # 压力校正
        p_new = p.copy()
        # 更新速度和压力
        u[i] = u_new[i]
        v[i] = v_new[i]
        p[i] = p_new[i]

# 绘制结果
plt.figure()
plt.plot(np.linspace(0, L, N+1), u, label='u')
plt.plot(np.linspace(0, L, N+1), v, label='v')
plt.xlabel('x (m)')
plt.ylabel('Velocity (m/s)')
plt.title('Velocity Distribution Over Time')
plt.legend()
plt.show()

plt.figure()
plt.plot(np.linspace(0, L, N+1), p, label='p')
plt.xlabel('x (m)')
plt.ylabel('Pressure (Pa)')
plt.title('Pressure Distribution Over Time')
plt.legend()
plt.show()
```

通过上述代码和结果，我们可以看到流体速度和压力分布随时间的变化。初始时刻，入口处的速度较高，随着流体向出口方向流动，速度逐渐降低。压力在入口处较低，在出口处较高，这是由于入口速度引起的动量变化所致。
