#### 5.2 系统核心实现

以下是一个简单的系统实现示例：

```python
from flask import Flask, request, jsonify
from gpt3 import *

app = Flask(__name__)
gpt = OpenAIApi(api_key='your-api-key')

@app.route('/api/question', methods=['POST'])
def handle_question():
    question = request.json['question']
    response = gpt.createCompletion(
        prompt=question,
        max_tokens=50
    )
    return jsonify({'answer': response.choices[0].text.strip()})

if __name__ == '__main__':
    app.run(debug=True)
```

在上面的代码中，我们使用Flask框架构建了简单的RESTful接口，并通过GPT-3 API调用ChatGPT模型生成回答。
