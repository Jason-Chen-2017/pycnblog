### 第2章：多粒度因果网络基础

#### 2.1 多粒度因果网络的定义

多粒度因果网络（Multi-Granularity Causal Network，简称MGCN）是一种特殊的因果网络模型，用于在时空数据中捕捉不同时间粒度和空间粒度之间的复杂关系。它通过将数据集划分为多个粒度级别，在每个粒度级别上构建因果模型，最终形成一个多层次、多维度的综合模型。多粒度因果网络的核心思想在于，通过不同粒度之间的交叉验证和融合，提高时空推理的准确性和鲁棒性。

在多粒度因果网络中，粒度是指数据在时间和空间上的细粒度或粗粒度划分。细粒度数据具有较高的时间分辨率和空间分辨率，能够提供更为详细的信息，但可能存在噪声和不确定性；而粗粒度数据则具有较低的时间分辨率和空间分辨率，但能够降低计算复杂度，提高模型的可解释性。通过在不同的粒度级别上构建因果模型，多粒度因果网络能够有效地捕捉数据在不同尺度上的变化规律。

#### 2.2 多粒度因果网络的结构

多粒度因果网络通常由多个子网络组成，每个子网络对应一个特定的粒度。这些子网络通过特定的规则相互连接，形成一个整体的多层次网络结构。以下是多粒度因果网络结构的几个关键组成部分：

1. **粒度层级划分**：多粒度因果网络的粒度层级划分是其核心特征。每个粒度层级上的子网络负责捕捉特定粒度级别的数据关系。粒度层级的划分可以根据具体应用场景进行调整，例如，在时间序列预测中，可以划分为分钟级、小时级、天级等多个层级。

2. **节点与边的关系**：多粒度因果网络中的节点表示数据特征，如时间点、空间位置等，而边表示节点之间的因果依赖关系。在多粒度因果网络中，不同层级之间的节点可以通过特定的规则进行连接，从而形成一个层次化的结构。边的关系可以通过条件概率分布或因果关系假设进行建模。

3. **多层次网络结构**：多粒度因果网络的结构是多层次的，每个子网络对应一个特定的粒度层级。这些子网络通过上下文信息进行交叉验证和融合，形成一个整体的多层次网络结构。这种结构能够有效地捕捉数据在不同尺度上的复杂关系，提高时空推理的准确性和鲁棒性。

##### 3.1.1 因果推断基本理论

因果推断是研究如何从观测数据中推断变量之间的因果关系的科学。在多粒度因果网络中，因果推断是关键的一步，它决定了网络中节点之间的因果关系是否成立。因果推断的基本理论包括以下几个方面：

1. **因果关系的定义**：因果关系是指一个变量（原因）对另一个变量（结果）产生的影响。在因果推断中，我们需要确定变量之间的因果关系是否显著。

2. **因果模型的类型**：因果模型可以分为两种类型：结构化因果模型和非结构化因果模型。结构化因果模型通常采用贝叶斯网络或图模型来表示变量之间的因果关系，而非结构化因果模型则依赖于统计模型，如线性回归或逻辑回归。

3. **因果推断的挑战**：因果推断面临许多挑战，包括数据缺失、测量误差、选择偏差等。为了克服这些挑战，研究者提出了多种因果推断方法，如工具变量法、双重差分法、因果图模型等。

2. **粒度转换**：在构建多粒度网络时，需要将不同粒度层级的数据进行转换和融合。例如，将细粒度时间序列数据聚合为粗粒度数据，或将局部空间数据扩展为全局空间数据。

3. **多层次网络结构**：构建多粒度网络时，通常采用多层次网络结构。每一层网络对应一个特定的粒度层级，层次之间通过特定的规则进行连接和融合。这种结构能够有效地捕捉数据在不同尺度上的复杂关系。

##### 3.2.1 因子分解机模型

因子分解机（Factorization Machine，简称FM）是一种用于特征组合和预测的机器学习模型，它在多粒度因果网络构建中具有重要的应用。FM模型通过将输入特征的线性组合表示为一个二次多项式，从而捕捉特征之间的复杂关系。

1. **模型表示**：
   FM模型的基本形式可以表示为：
   \[
   \hat{y} = \theta_0 + \sum_{i=1}^m \theta_i x_i + \sum_{i=1}^m \sum_{j=1}^m \langle i, j \rangle \theta_i \theta_j
   \]
   其中，\( \hat{y} \) 是预测目标，\( \theta_0 \) 是偏置项，\( \theta_i \) 是第 \( i \) 个特征的学习参数，\( x_i \) 是第 \( i \) 个特征，\( \langle i, j \rangle \) 是特征 \( i \) 和 \( j \) 的组合指数。

2. **损失函数**：
   为了优化模型参数，通常使用均方误差（Mean Squared Error，简称MSE）作为损失函数：
   \[
   L(\theta) = \frac{1}{2} \sum_{i=1}^n (y_i - \hat{y}_i)^2
   \]
   其中，\( y_i \) 是第 \( i \) 个样本的真实标签，\( \hat{y}_i \) 是第 \( i \) 个样本的预测值。

3. **优化算法**：
   FM模型的参数优化通常采用梯度下降法或其变种，如随机梯度下降（Stochastic Gradient Descent，简称SGD）和Adam优化器。

##### 3.2.2 贝叶斯网络模型

贝叶斯网络（Bayesian Network，简称BN）是一种基于概率论的图模型，用于表示变量之间的条件依赖关系。在多粒度因果网络中，贝叶斯网络用于捕捉不同粒度层级之间的因果关系。

1. **模型表示**：
   贝叶斯网络的模型表示由一个有向无环图（DAG）和一个概率表组成。图中的节点表示变量，边表示变量之间的条件依赖关系。概率表为每个变量的条件概率分布提供了数值支持。

2. **概率分布**：
   在贝叶斯网络中，每个变量的概率分布可以通过条件概率表（Conditional Probability Table，简称CPT）计算得到。CPT为每个变量的每个状态提供了给定其他变量状态的概率。

3. **推理算法**：
   贝叶斯网络的推理算法包括正向推理和反向推理。正向推理用于计算给定输入条件下的概率分布，而反向推理用于计算变量之间的因果关系。

```python

import pyro.distributions as dist
import torch
from torch import nn

# 构建网络结构
structure = [
    ('X1', [], {}),
    ('X2', ['X1'], {}),
    ('X3', ['X2'], {})
]

    'X1': dist.Categorical(logits=torch.tensor([0.7, 0.3])),
    'X2': dist.Categorical(logits=torch.tensor([0.6, 0.4])),
    'X3': dist.Categorical(logits=torch.tensor([0.6, 0.4]))
}

# 定义模型
model = pyro.random_variables_from_structure(structure, paramaters)

# 训练模型
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
num_iterations = 1000
for i in range(num_iterations):
    with pyro.plate("data", 100):
        X1 = pyro.sample("X1", dist.Categorical(logits=torch.tensor([0.7, 0.3])))
        X2 = pyro.sample("X2", dist.Categorical(logits=X1 * torch.tensor([0.6, 0.4])))
        X3 = pyro.sample("X3", dist.Categorical(logits=X2 * torch.tensor([0.6, 0.4])))
    loss = -pyro.log_prob_lines([X1, X2, X3])
    loss.backward()
    optimizer.step()

# 推理
with pyro.plate("data", 1):
    X1_pred = pyro.sample("X1", dist.Categorical(logits=torch.tensor([0.7, 0.3])))
    X2_pred = pyro.sample("X2", dist.Categorical(logits=X1_pred * torch.tensor([0.6, 0.4])))
    X3_pred = pyro.sample("X3", dist.Categorical(logits=X2_pred * torch.tensor([0.6, 0.4])))

print(f'Predicted X1: {X1_pred}')
print(f'Predicted X2: {X2_pred}')
print(f'Predicted X3: {X3_pred}')
```

##### 4.2.3.1 贝叶斯网络算法原理

贝叶斯网络是一种概率图模型，用于表示变量之间的条件依赖关系。它由一个有向无环图（DAG）和一个条件概率表（CPT）组成。DAG表示变量之间的因果关系，CPT提供每个变量的条件概率分布。

1. **DAG构建**：首先，根据领域知识或数据挖掘结果，构建一个有向无环图，表示变量之间的因果关系。DAG中的节点表示变量，边表示变量之间的依赖关系。

2. **CPT计算**：对于每个变量，根据DAG中的依赖关系，计算条件概率表。CPT中的每个条目表示在给定其他变量状态下，当前变量的概率分布。

3. **推理计算**：使用贝叶斯推理算法，计算给定观察数据下的变量概率分布。贝叶斯推理的核心是贝叶斯定理，它可以用来计算条件概率和边缘概率。

##### 4.2.3.2 Python代码实现

以下是一个简单的贝叶斯网络实现示例，使用Pyro库进行编程：

```python
import torch
import pyro
import pyro.distributions as dist
from pyro.infer import MCMC, NUTS

# 定义网络结构
structure = [
    ('X1', [], {}),
    ('X2', ['X1'], {}),
    ('X3', ['X2'], {}),
]

# 初始化参数
parameters = {
    'X1': dist.Categorical(logits=torch.tensor([0.7, 0.3])),
    'X2': dist.Categorical(logits=torch.tensor([0.6, 0.4])),
    'X3': dist.Categorical(logits=torch.tensor([0.6, 0.4])),
}

# 定义模型
def model_guide(x1, x2, x3):
    with pyro.plate("data", 1):
        x1 = pyro.sample("X1", dist.Categorical(logits=x1))
        x2 = pyro.sample("X2", dist.Categorical(logits=x1 * x2))
        x3 = pyro.sample("X3", dist.Categorical(logits=x2 * x3))

def model(x1, x2, x3):
    with pyro.plate("data", 1):
        x1 = pyro.sample("X1", parameters['X1'])
        x2 = pyro.sample("X2", dist.Categorical(logits=x1 * parameters['X2']))
        x3 = pyro.sample("X3", dist.Categorical(logits=x2 * parameters['X3']))

# 训练模型
guide = pyro.infer.AutoGuide(model=model, guide=model_guide)
kernel = NUTS(kernel=pyro.infer.HamiltonianMC())
mcmc = MCMC(guide, kernel, num_samples=1000, num_adapt_samples=100)
mcmc.run(torch.tensor([0.7, 0.3]), torch.tensor([0.6, 0.4]), torch.tensor([0.6, 0.4]))

# 输出结果
print(mcmc.get_samples())
```

在上面的代码中，我们首先定义了网络结构，然后初始化参数。接下来，我们使用Pyro框架中的MCMC（Markov Chain Monte Carlo）方法进行模型训练。MCMC方法采用NUTS（No-U-Turn Sampler）作为采样器，通过多次迭代生成多个参数样本，从而估计变量的后验概率分布。

import pyro.distributions as dist
from pyro.infer import MCMC, NUTS

    ('X1', [], {}),
    ('X2', ['X1'], {}),
    ('X3', ['X2'], {}),
]

parameters = {
    'X1': dist.Categorical(logits=torch.tensor([0.7, 0.3])),
    'X2': dist.Categorical(logits=torch.tensor([0.6, 0.4])),
    'X3': dist.Categorical(logits=torch.tensor([0.6, 0.4])),
}

# 定义模型
def model_guide(x1, x2, x3):
    with pyro.plate("data", 1):
        x1 = pyro.sample("X1", dist.Categorical(logits=x1))
        x2 = pyro.sample("X2", dist.Categorical(logits=x1 * x2))
        x3 = pyro.sample("X3", dist.Categorical(logits=x2 * x3))

def model(x1, x2, x3):
    with pyro.plate("data", 1):
        x1 = pyro.sample("X1", parameters['X1'])
        x2 = pyro.sample("X2", dist.Categorical(logits=x1 * parameters['X2']))
        x3 = pyro.sample("X3", dist.Categorical(logits=x2 * parameters['X3']))

# 训练模型
guide = pyro.infer.AutoGuide(model=model, guide=model_guide)
kernel = NUTS(kernel=pyro.infer.HamiltonianMC())
mcmc = MCMC(guide, kernel, num_samples=1000, num_adapt_samples=100)
mcmc.run(torch.tensor([0.7, 0.3]), torch.tensor([0.6, 0.4]), torch.tensor([0.6, 0.4]))
