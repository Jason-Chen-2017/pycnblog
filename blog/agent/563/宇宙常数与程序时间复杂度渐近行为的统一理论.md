#### 第3章：程序时间复杂度的基本概念

程序时间复杂度是算法分析中的重要概念，它用于衡量算法在处理不同规模输入时所需的时间。这一概念不仅有助于我们理解算法的性能，还能指导我们在实际应用中选择合适的算法。

##### 3.1.1 程序时间复杂度的定义

程序时间复杂度，通常用 \( T(n) \) 表示，描述了一个算法在输入规模为 \( n \) 时所需的计算时间。时间复杂度的定义通常基于渐进符号，如 \( O(n) \)、\( \Omega(n) \) 和 \( \Theta(n) \)：

- \( O(n) \)：表示算法的上界，即存在一个常数 \( c \) 和 \( n_0 \)，使得当 \( n \geq n_0 \) 时，算法的时间复杂度 \( T(n) \) 不超过 \( cn \)。
- \( \Omega(n) \)：表示算法的下界，即存在一个常数 \( c \) 和 \( n_0 \)，使得当 \( n \geq n_0 \) 时，算法的时间复杂度 \( T(n) \) 至少为 \( cn \)。
- \( \Theta(n) \)：表示算法的时间复杂度同时满足上界和下界，即存在常数 \( c_1 \)、\( c_2 \) 和 \( n_0 \)，使得当 \( n \geq n_0 \) 时，\( c_1 n \leq T(n) \leq c_2 n \)。

##### 3.1.2 时间复杂度的分类

根据时间复杂度的增长速度，算法可以分为以下几个类别：

- **线性时间复杂度**（\( O(n) \)）：算法的时间复杂度与输入规模 \( n \) 成正比。例如，线性查找算法。
- **对数时间复杂度**（\( O(\log n) \)）：算法的时间复杂度与输入规模的对数成正比。例如，二分查找算法。
- **多项式时间复杂度**（\( O(n^k) \)，其中 \( k \) 为常数）：算法的时间复杂度与输入规模的某个多项式成正比。例如，多项式时间算法，如快速排序。
- **指数时间复杂度**（\( O(2^n) \)）：算法的时间复杂度与输入规模的指数成正比。例如，暴力搜索算法。

##### 3.1.3 时间复杂度的重要性

时间复杂度是评估算法性能的一个重要指标。它不仅帮助我们理解算法在不同输入规模下的运行时间，还能指导我们在实际应用中选择合适的算法。以下是一些关于时间复杂度的重要性：

- **性能评估**：通过时间复杂度，我们可以快速评估算法在不同输入规模下的性能，从而选择最优的算法。

```python
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

# 示例

print(sorted_arr)
```

**模拟退火算法**

模拟退火算法是一种启发式搜索算法，它通过模拟物理系统中的退火过程，逐步降低系统的能量，以找到最优解。以下是一个简单的模拟退火算法的Python实现：

```python
import random
import math

def simulated_annealing(generation_size, initial_temp, cooling_rate):
    temp = initial_temp
    current_solution = random.randint(0, generation_size - 1)
    best_solution = current_solution
    for i in range(generation_size):
        next_solution = random.randint(0, generation_size - 1)
        if math.exp((current_solution - next_solution) / temp) > random.random():
            current_solution = next_solution
            if current_solution < best_solution:
                best_solution = current_solution
        temp *= (1 - cooling_rate)
    return best_solution

# 示例
solution = simulated_annealing(10, 100, 0.01)
print(solution)
```
