##### 3.1.4 Mathematical Models

- **Quantum States Representation:**
  $$ \left| \psi \right\rangle = \alpha \left| 0 \right\rangle + \beta \left| 1 \right\rangle $$
  where $\alpha$ and $\beta$ are complex numbers with $|\alpha|^2 + |\beta|^2 = 1$.

- **Quantum Entanglement:**
  $$ \left| \psi_{\text{entangled}} \right\rangle = \frac{1}{\sqrt{2}} \left( \left| 00 \right\rangle + \left| 11 \right\rangle \right) $$

- **Quantum Key Distribution Protocol:**
  - **Alice sends a quantum state to Bob.**
    $$ \left| \psi_{\text{key}} \right\rangle = \frac{1}{\sqrt{2}} \left( \left| 0 \right\rangle + \left| 1 \right\rangle \right) $$
  - **Bob measures the received state.**
    $$ \text{Result: } \left| 0 \right\rangle \text{ or } \left| 1 \right\rangle $$
  - **Alice and Bob share their measurement outcomes.**
    - If the outcomes differ, they repeat the process.
    - If the outcomes match, the corresponding qubit is part of the shared secret key.

- **Quantum Encryption with QKD:**
  - **Encryption:**
    $$ \left| \psi_{\text{encrypted}} \right\rangle = \frac{1}{\sqrt{2}} \left( \left| \psi_{\text{plaintext}} \right\rangle \left| 0 \right\rangle + \left| \psi_{\text{plaintext}} \right\rangle \left| 1 \right\rangle \right) $$
  - **Decryption:**
    $$ \left| \psi_{\text{decrypted}} \right\rangle = \frac{1}{\sqrt{2}} \left( \left| \psi_{\text{encrypted}} \right\rangle \left| 0 \right\rangle + \left| \psi_{\text{encrypted}} \right\rangle \left| 1 \right\rangle \right) = \left| \psi_{\text{plaintext}} \right\rangle $$
