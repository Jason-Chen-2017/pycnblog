  其中，$X_i$表示节点$i$，$x_i$表示节点$i$的取值，$X_{\text{parents}(i)}$表示节点$i$的父节点集合，$x_{\text{parents}(i)}$表示节点$i$的父节点集合的取值。

### 4.2.4 贝叶斯网络的推理算法

贝叶斯网络的推理算法用于计算变量之间的条件概率，常见的推理算法包括：

- **前向推理**：从根节点开始，依次计算每个节点的条件概率。
- **后向推理**：从叶子节点开始，逆序计算每个节点的条件概率。
- **信念传播**：结合前向推理和后向推理，同时更新节点的条件概率。

### 4.3.1 条件概率公式

条件概率公式是贝叶斯网络的核心公式之一，用于计算变量之间的条件概率。公式如下：

$$P(X_i = x_i|X_j = x_j) = \frac{P(X_j = x_j|X_i = x_i) \cdot P(X_i = x_i)}{P(X_j = x_j)}$$

### 4.3.2 贝叶斯定理

贝叶斯定理是贝叶斯网络推理的基础公式，用于计算后验概率。公式如下：

$$P(X_i = x_i|X_{\text{parents}(i)} = x_{\text{parents}(i)}) = \frac{P(X_{\text{parents}(i)} = x_{\text{parents}(i)}|X_i = x_i) \cdot P(X_i = x_i)}{P(X_{\text{parents}(i)} = x_{\text{parents}(i)})}$$

### 4.3.3 贝叶斯网络的概率分布

贝叶斯网络的概率分布由条件概率表（CPT）定义，每个节点上的概率分布函数（PDF）描述了该节点的状态分布。概率分布公式如下：

$$P(X_i = x_i|X_{\text{parents}(i)} = x_{\text{parents}(i)}) = \prod_{j \in \text{parents}(i)} P(X_j = x_j|X_{\text{parents}(j)} = x_{\text{parents}(j)})$$

### 4.3.4 贝叶斯网络的推理算法

贝叶斯网络的推理算法用于计算变量之间的条件概率，常见的推理算法包括前向推理、后向推理和信念传播。推理算法公式如下：

- **前向推理**：

  $$P(X_i = x_i|X_{\text{parents}(i)} = x_{\text{parents}(i)}) = \prod_{j \in \text{parents}(i)} P(X_j = x_j|X_{\text{parents}(j)} = x_{\text{parents}(j)})$$

- **后向推理**：

  $$P(X_i = x_i|X_{\text{parents}(i)} = x_{\text{parents}(i)}) = \prod_{j \in \text{children}(i)} P(X_j = x_j|X_{\text{parents}(j)} = x_{\text{parents}(j)})$$

- **信念传播**：

  $$P(X_i = x_i|X_{\text{parents}(i)} = x_{\text{parents}(i)}) = \frac{P(X_i = x_i) \cdot P(X_{\text{parents}(i)} = x_{\text{parents}(i)})}{P(X_{\text{parents}(i)} = x_{\text{parents}(i)})}$$
