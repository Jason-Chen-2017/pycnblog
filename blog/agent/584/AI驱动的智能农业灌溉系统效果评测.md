**Python 源代码：**
```python
# 导入必要的库
import pandas as pd
from sklearn.preprocessing import MinMaxScaler
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split

# 数据预处理
def preprocess_data(data):
    # 数据清洗
    data = data[data['humidity'] != -1]
    # 数据归一化
    scaler = MinMaxScaler()
    data[['temperature', 'humidity']] = scaler.fit_transform(data[['temperature', 'humidity']])
    return data

# 特征提取
def extract_features(data):
    features = data[['temperature', 'humidity']]
    target = data['water_usage']
    return features, target

# 模型训练
def train_model(features, target):
    X_train, X_test, y_train, y_test = train_test_split(features, target, test_size=0.2, random_state=42)
    model = RandomForestRegressor(n_estimators=100, random_state=42)
    model.fit(X_train, y_train)
    return model

# 预测结果
def predict_water_usage(model, features):
    return model.predict(features)

# 主函数
def main():
    # 加载数据
    data = pd.read_csv('agriculture_data.csv')
    # 数据预处理
    data = preprocess_data(data)
    # 特征提取
    features, target = extract_features(data)
    # 模型训练
    model = train_model(features, target)
    # 预测结果
    predicted_usage = predict_water_usage(model, features)
    print(predicted_usage)

if __name__ == '__main__':
    main()
```

**算法原理详细讲解：**

1. **数据预处理**：首先，对采集到的农业灌溉数据（如土壤湿度、温度等）进行预处理，包括数据清洗和归一化。数据清洗旨在去除异常值和缺失值，以保证数据的质量。归一化则是将不同特征的数据缩放到相同的量级，以便于模型训练。

2. **特征提取**：从预处理后的数据中提取用于模型训练的特征（如土壤湿度、温度）和目标变量（如灌溉用水量）。特征提取是模型训练的关键步骤，旨在从原始数据中提取有用的信息。

3. **模型训练**：采用随机森林回归算法（Random Forest Regressor）对特征和目标变量进行训练。随机森林是一种集成学习方法，通过构建多棵决策树，并利用投票机制来预测结果。这种方法在处理复杂数据和避免过拟合方面表现良好。

4. **预测结果**：使用训练好的模型对新的数据进行预测，生成灌溉用水量的预测结果。这一步是实现智能决策的关键，通过预测结果，系统能够自动调整灌溉策略，实现精准灌溉。

5. **决策生成**：根据预测结果，系统生成相应的灌溉决策，如调整灌溉时间、灌溉量和灌溉频率。这一步是将预测结果转化为实际操作的桥梁。

6. **执行灌溉**：根据决策生成的结果，自动调整灌溉设备，实现精准灌溉。这一步是智能农业灌溉系统的最终执行环节。

**数学模型和公式：**

1. **随机森林回归模型**：
$$
\hat{y} = f(\text{X}) = \sum_{i=1}^{n} \hat{w}_i \cdot h(\text{X}; t_i)
$$
其中，$\hat{y}$是预测的灌溉用水量，$f(\text{X})$是随机森林回归模型的输出，$h(\text{X}; t_i)$是第$i$棵决策树对输入特征$\text{X}$的预测，$\hat{w}_i$是第$i$棵决策树的权重。

2. **决策树模型**：
$$
h(\text{X}; t_i) = \prod_{j=1}^{m} g_j(\text{x}_{ij}; t_{ij})
$$
其中，$g_j(\text{x}_{ij}; t_{ij})$是第$i$棵决策树在第$j$个特征上的分割函数，$\text{x}_{ij}$是输入特征$\text{X}$在第$j$个特征上的值，$t_{ij}$是第$i$棵决策树在第$j$个特征上的分割阈值。
