### 第2章 核心概念与联系

#### 2.1 密度泛函理论的基本原理

密度泛函理论（Density Functional Theory，DFT）是量子力学中一种强大的计算方法，用于描述电子在多粒子系统中的行为。DFT的核心思想是通过电子密度来描述整个系统的性质，而不是直接处理多体电子问题。这一理论的基本原理包括以下几个方面：

##### 2.1.1 Kohn-Sham方程

Kohn-Sham方程是DFT的基础，它将多体问题转换为单体问题。具体来说，Kohn-Sham方程是一个非相对论薛定谔方程，它适用于非束缚电子系统。这个方程的形式为：

$$
\left( -\frac{\hbar^2}{2m} \nabla^2 + V_{KS}(r) \right) \phi_i(\mathbf{r}) = \varepsilon_i \phi_i(\mathbf{r})
$$

其中，$\phi_i(\mathbf{r})$是第i个单电子轨道的波函数，$m$是电子的质量，$\varepsilon_i$是相应能级的能量，$V_{KS}(r)$是Kohn-Sham势。

##### 2.1.2 Hohenberg-Kohn定理

Hohenberg-Kohn定理是DFT的理论基础，它证明了在一定条件下，系统的总能量是电子密度的单变量函数。这个定理分为两部分：

1. **构造性定理**：任意给定的电子密度函数，都存在一个非相对论势$V(r)$和一个单电子哈密顿量$H(\mathbf{r})$，使得电子的总能量可以作为电子密度$N(\mathbf{r})$的函数来表示。
2. **唯一性定理**：给定一个电子密度函数$N(\mathbf{r})$，其对应的总能量函数是唯一的。

##### 2.1.3 交换相关函数

在DFT中，交换相关函数（Exchange-correlation functional，$F_{xc}[\rho]$）是一个关键的概念，它描述了电子间的交换和关联效应。根据Hohenberg-Kohn定理，系统的总能量可以表示为：

$$
E = \int \rho(\mathbf{r}) V_{ext}(\mathbf{r}) d\mathbf{r} - \int \frac{\rho(\mathbf{r})^2}{2} v_{ext}(\mathbf{r}) d\mathbf{r} + F[\rho]
$$

其中，$V_{ext}(\mathbf{r})$是外部势场，$v_{ext}(\mathbf{r})$是相应的势场，$F[\rho]$是总的交换相关能量，它取决于电子密度$\rho(\mathbf{r})$。

##### 2.1.4 广义Hohenberg-Kohn定理

广义Hohenberg-Kohn定理是DFT在多电子系统中的应用，它证明了在一定条件下，系统的基态电子密度是能量泛函的最优解。具体来说，这个定理表明，基态电子密度不仅满足Kohn-Sham方程，而且它是使得系统能量最小化的最优解。

##### 3.3.1 自洽场方法的原理

自洽场方法是一种用于求解密度泛函理论的迭代算法。其基本原理是通过迭代求解Kohn-Sham方程，直到系统达到自洽状态。以下是自洽场方法的详细步骤：

1. **初始化**：选择一个初始的电子密度$\rho_0(\mathbf{r})$。这个初始密度可以根据先前的计算结果或经验进行选择。
2. **计算自洽势**：使用当前电子密度$\rho_0(\mathbf{r})$计算Kohn-Sham势$V_{KS}(\mathbf{r})$。这个势场包括外部势场和交换相关势场。
   $$V_{KS}(\mathbf{r}) = V_{ext}(\mathbf{r}) + v_{xc}(\mathbf{r}, \rho(\mathbf{r}))$$
3. **求解Kohn-Sham方程**：使用新的势场$V_{KS}(\mathbf{r})$求解Kohn-Sham方程，得到新的波函数$\phi_i(\mathbf{r})$和能量$\varepsilon_i$。
   $$\left( -\frac{\hbar^2}{2m} \nabla^2 + V_{KS}(\mathbf{r}) \right) \phi_i(\mathbf{r}) = \varepsilon_i \phi_i(\mathbf{r})$$
4. **更新电子密度**：使用新的波函数计算新的电子密度$\rho_1(\mathbf{r})$。
   $$\rho_1(\mathbf{r}) = \sum_i n_i \phi_i^*(\mathbf{r}) \phi_i(\mathbf{r})$$
   其中，$n_i$是单电子态的占据数。
5. **迭代**：判断电子密度和势场的变化是否小于预设的阈值。如果满足自洽条件，则停止迭代；否则，返回步骤2，继续迭代。

```python
import numpy as np

def scf(electronic_structure, potential, max_iter=100, threshold=1e-6):
    """
    自洽场方法求解Kohn-Sham方程。
    
    参数：
    electronic_structure: 电子结构对象，包含初始电子密度。
    potential: 势场对象，包含外部势场和交换相关势场。
    max_iter: 最大迭代次数。
    threshold: 自洽阈值。
    
    返回：
    electronic_structure: 自洽后的电子结构。
    """
    iteration = 0
    while iteration < max_iter:
        # 计算自洽势
        v_kin = potential.kinetic(electronic_structure.r)
        v_ext = potential.external(electronic_structure.r)
        v_xc = potential.exchange_correlation(electronic_structure.rho)
        vKS = v_kin + v_ext + v_xc
        
        # 求解Kohn-Sham方程
        electronic_structure.solve_hamiltonian(vKS)
        
        # 更新电子密度
        electronic_structure.update_density()
        
        # 判断自洽条件
        if np.linalg.norm(electronic_structure.rho - electronic_structure.rho_prev) < threshold:
            break
        
        electronic_structure.rho_prev = electronic_structure.rho
        iteration += 1
    
    return electronic_structure
```

1. **初始化参数**：设置模拟的初始参数，包括晶格常数、原子坐标、电子密度等。

   ```python
   from mercury import Simulation

   sim = Simulation()
   sim.set_lattice_constant(5.43)  # 设置晶格常数
   sim.set_atom_coordinates([[0, 0, 0], [2.71, 2.71, 2.71]])  # 设置原子坐标

   ```

2. **执行模拟**：调用Mercury的simulate方法执行电子结构模拟。

   ```python
   sim.simulate()
   ```

3. **获取结果**：从模拟结果中获取能带结构、电子态密度等物理量。

   ```python
   bands = sim.get_bands()
   ```


2. **执行模拟**：调用Mercury的simulate方法执行光学性质模拟。


3. **获取结果**：从模拟结果中获取吸收光谱、反射光谱等。
