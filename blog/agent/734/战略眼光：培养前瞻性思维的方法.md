### 4. 数学模型和数学公式 & 详细讲解 & 举例说明

**数学模型和公式**：

- **决策树模型**：用于分析和解决复杂决策问题，通过一系列的分支和节点来表示不同的决策路径和结果。

\[ 
决策树模型 = \{ Nodes, Edges, Labels \}
\]

- **期望值**：用于评估不同决策路径的期望收益，计算公式为：

\[ 
期望值 = \sum_{i} (P_i \times R_i) 
\]

其中，\( P_i \) 为第 \( i \) 条路径的概率，\( R_i \) 为第 \( i \) 条路径的收益。

**详细讲解**：

- **决策树模型**：决策树是一种树形结构，用于表示决策过程。每个节点表示一个决策点，每个分支表示一个决策选项，每个叶子节点表示一个结果。通过决策树模型，可以系统地分析和解决复杂决策问题。
- **期望值**：期望值是决策分析中的一个重要指标，用于评估不同决策路径的预期收益。通过计算期望值，可以帮助决策者选择最优的决策路径。

**举例说明**：

假设一家公司需要在A、B、C三个市场上进行产品推广，每个市场的成功概率和预期收益如下：

| 市场 | 成功概率 | 预期收益 |
|------|----------|----------|
| A    | 0.5      | 1000元   |
| B    | 0.4      | 800元    |
| C    | 0.3      | 600元    |

根据这些数据，可以计算每个市场的期望收益：

\[ 
期望收益_A = 0.5 \times 1000 = 500元 
\]
\[ 
期望收益_B = 0.4 \times 800 = 320元 
\]
\[ 
期望收益_C = 0.3 \times 600 = 180元 
\]

通过比较期望收益，可以得出最优的市场推广策略。例如，如果选择市场A进行推广，则期望收益为500元，而选择市场B或C，则期望收益较低。因此，公司应选择在市场A进行产品推广。

# 用户登录功能
@app.route('/login', methods=['POST'])
def login():
    user_data = request.get_json()
    user_id = user_data['id']
    user_password = user_data['password']
    
    # 验证用户信息
    cursor = mysql.connection.cursor()
    cursor.execute("SELECT * FROM users WHERE id = %s AND password = %s", (user_id, user_password))
    user = cursor.fetchone()
    
    if user:
        return jsonify({"status": "success", "message": "登录成功"}), 200
    else:
        return jsonify({"status": "error", "message": "用户名或密码错误"}), 401

# 获取课程列表功能
@app.route('/courses', methods=['GET'])
def get_courses():
    cursor = mysql.connection.cursor()
    cursor.execute("SELECT * FROM courses")
    courses = cursor.fetchall()
    
    return jsonify(courses), 200

# 获取视频信息功能
@app.route('/videos/<int:video_id>', methods=['GET'])
def get_video(video_id):
    cursor = mysql.connection.cursor()
    cursor.execute("SELECT * FROM videos WHERE id = %s", (video_id,))
    video = cursor.fetchone()
    
    return jsonify(video), 200

# 添加评论功能
@app.route('/comments', methods=['POST'])
def add_comment():
    comment_data = request.get_json()
    comment_content = comment_data['content']
    user_id = comment_data['user_id']

    return jsonify({"status": "success", "message": "评论添加成功"}), 201
