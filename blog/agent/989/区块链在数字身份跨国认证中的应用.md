### 1.1 问题背景

在当今数字化时代，个人隐私和数据安全已成为全球关注的焦点。随着互联网的快速发展，个人数据被大量收集、存储和利用，但同时也存在数据泄露、隐私侵犯等问题。为了解决这些问题，提出了数字身份跨国认证的需求。

    response = fabric_network.send_transaction(user_transaction)
    # 返回认证结果
    return json.loads(response)
