### 4.1 优化问题的数学模型

优化问题在数学上可以表示为一个带有目标函数和约束条件的数学问题。具体来说，一个标准的优化问题通常可以表述为：

\[ \text{minimize (or maximize) } f(x) \]
\[ \text{subject to } g_i(x) \leq 0, \quad h_j(x) = 0 \]

其中：
- \( f(x) \) 是目标函数，表示希望最大化或最小化的函数。
- \( x \) 是决策变量，可以是连续变量或离散变量。
- \( g_i(x) \leq 0 \) 和 \( h_j(x) = 0 \) 是约束条件，分别表示不等式约束和等式约束。

优化问题可以分为以下几种类型：

1. **无约束优化**：目标函数和约束条件都不存在。
2. **单约束优化**：只有一个约束条件。
3. **多约束优化**：存在多个约束条件。

在实际应用中，优化问题通常涉及以下几种常见类型：

- **线性规划**：目标函数和约束条件都是线性的。
- **非线性规划**：目标函数或约束条件是非线性的。
- **整数规划**：决策变量是整数。
- **动态规划**：涉及时间或阶段的概念。
