\text{绩效} = \frac{\text{效率}}{2} + \frac{\text{生活质量}}{2}

该算法通过时间管理和心理调节两个维度来评估工作与生活的平衡状态。时间管理得分反映了个体在时间规划和管理方面的能力，而心理调节得分则反映了个体在应对工作压力和保持心理健康方面的能力。这两个得分共同决定了工作绩效，进而影响工作与生活的平衡状态。

```python
# user_manager.py
from flask import Flask, request, jsonify
from flask_login import LoginManager, UserMixin, login_user, logout_user, login_required
from sqlalchemy import create_engine, Column, Integer, String, DateTime
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

app = Flask(__name__)
app.secret_key = 'your_secret_key'
login_manager = LoginManager()
login_manager.init_app(app)

Base = declarative_base()

class User(Base, UserMixin):
    __tablename__ = 'users'
    id = Column(Integer, primary_key=True)
    username = Column(String(150), unique=True, nullable=False)
    password = Column(String(150), nullable=False)
    email = Column(String(150), unique=True, nullable=False)
    last_login = Column(DateTime)

engine = create_engine('postgresql://username:password@localhost/db_name')
Base.metadata.create_all(engine)
Session = sessionmaker(bind=engine)
session = Session()

@login_manager.user_loader
def load_user(user_id):
    return User.query.get(int(user_id))

@app.route('/register', methods=['POST'])
def register():
    username = request.form['username']
    password = request.form['password']
    email = request.form['email']
    user = User(username=username, password=password, email=email)
    session.add(user)
    session.commit()
    return jsonify({'status': 'success', 'message': '注册成功'})

@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    user = User.query.filter_by(username=username).first()
    if user and user.password == password:
        login_user(user)
        return jsonify({'status': 'success', 'message': '登录成功'})
    else:
        return jsonify({'status': 'error', 'message': '用户名或密码错误'})

@app.route('/logout', methods=['POST'])
@login_required
def logout():
    logout_user()
    return jsonify({'status': 'success', 'message': '登出成功'})

if __name__ == '__main__':
    app.run(debug=True)
```

10. **定期休假**：每年安排至少一次休假，远离工作和日常事务，进行身心放松。休假有助于恢复精力，提高工作效率。
