```python
def preprocess_signal(signal, cutoff_freq, order):
    """
    对信号进行预处理，包括带通滤波和归一化。
    """
    # 设计带通滤波器
    b, a = butter(order, cutoff_freq, btype='band')

    filtered_signal = filtfilt(b, a, signal)
    
    # 归一化信号
    normalized_signal = filtered_signal / np.max(np.abs(filtered_signal))
    
    return normalized_signal
```

- **滤波**：使用 `scipy.signal.filtfilt` 函数对信号进行带通滤波。`filtfilt` 函数确保滤波器对信号的两次滤波过程互相抵消，从而实现平稳滤波。

```python
def extract_features(signal):
    """
    从信号中提取特征，包括时域和频域特征。
    """
    # 时域特征：均值和标准差
    mean_value = np.mean(signal)
    std_value = np.std(signal)
    
    # 频域特征：通过傅里叶变换计算频率成分的均值
    freq_signal = np.fft.fft(signal)
    freq_signal = np.abs(freq_signal[:len(freq_signal)//2])
    freq_mean = np.mean(freq_signal)
    
    # 拼接特征
    features = np.hstack((mean_value, std_value, freq_mean))
    
    return features
```

- **时域特征**：计算信号的均值和标准差，这两个统计量能够反映信号的中心趋势和分散程度。
- **频域特征**：使用 `numpy.fft.fft` 函数对信号进行傅里叶变换，得到信号的频域表示。由于傅里叶变换的对称性，我们只需要计算和处理前半部分的频率分量。然后，计算这些频率分量的均值。
- **特征拼接**：将时域特征和频域特征拼接成一个特征向量，以便后续的机器学习处理。
