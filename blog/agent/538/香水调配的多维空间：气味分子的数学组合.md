$$

其中，$n$ 表示气味分子的数量，$\text{成分}_i$ 表示第 $i$ 种气味分子的含量，$\text{含量}_i$ 表示第 $i$ 种气味分子的具体含量。

    total_content = sum(content)
    for name, c in zip(molecules, content):

    return formula

    concentration = sum([formula[name] * m['strength'] for name, m in formula.items()])
    return concentration

    return a * math.exp(b * concentration)

    compatibility = sum([math.cos(math.pi * formula[name] * m['compatibility']) for name, m in formula.items()])
