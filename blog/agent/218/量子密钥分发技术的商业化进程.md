### 1.1 量子密钥分发技术的定义与背景

量子密钥分发（Quantum Key Distribution，QKD）是一种基于量子力学原理的加密技术，用于在两个通信方之间安全地交换密钥。传统的加密方法依赖于复杂的数学算法来确保数据的保密性，但随着计算能力的提升，这些算法变得越来越容易被破解。量子密钥分发则利用量子力学的基本原理，提供一种理论上绝对安全的加密通信方式。

量子密钥分发技术的核心思想源于量子力学中的“不确定性原理”和“量子纠缠现象”。不确定性原理表明，一个量子系统的某些对偶属性（如位置和动量）不能同时被精确测量。量子纠缠现象则意味着，两个或多个量子系统在量子态上相互关联，即使它们相隔很远，一个系统的状态变化也会立即影响另一个系统的状态。

在量子密钥分发中，两个通信方（通常被称为Alice和Bob）通过一个量子信道交换量子比特。这些量子比特可以是光子的 polarization（偏振状态）或者原子内部的电子自旋状态。通过一系列的量子操作和测量，Alice和Bob可以共同生成一个共享的密钥。这个过程具有以下几个显著特点：

1. **安全性**：由于量子力学的基本原理，任何对量子通信的监听都会导致量子态的坍缩，从而暴露监听者的存在。这意味着量子密钥分发提供了一种对抗量子计算攻击的通信方式。
2. **无条件安全**：量子密钥分发理论上的安全性是基于量子力学的基本原理，而非复杂的数学算法。因此，它被认为是一种无条件安全的加密技术。
3. **量子态传输**：量子密钥分发依赖于量子态的传输，这意味着它需要高质量的量子信道和量子比特源。在实际应用中，光子是常用的量子载体。

量子密钥分发技术的背景可以追溯到1984年，当时Charles H. Bennett和Geordie Rose提出了BB84协议，这是第一个被广泛认可的量子密钥分发协议。随后，科学家们提出了多种改进的协议，如B92协议和E91协议，这些协议在实现过程和安全性上各有优势。

1. **量子比特（qubit）**：量子比特是量子计算机的基本单位，它不仅可以表示0或1，还可以处于0和1的叠加状态。这使得量子计算机在处理复杂问题时具有超越经典计算机的能力。
2. **量子纠缠**：量子纠缠是量子系统间的一种特殊关联现象。当两个量子系统处于纠缠态时，它们的状态不能独立存在，一个系统的变化会立即影响另一个系统，无论它们相隔多远。
3. **量子信道**：量子信道是用于传输量子比特的物理通道。它可以是光纤、自由空间或者量子中继器。
4. **量子密钥分发协议**：量子密钥分发协议是一系列操作步骤，用于在量子信道上实现安全密钥的交换。常见的协议包括BB84、B92和E91等。

### 3.2 BB84协议

import matplotlib.pyplot as plt

# 初始化量子比特
quantum_bits = np.array([[1, 0], [0, 1]])

# 随机选择基
base = np.random.randint(2)

sent_bits = np.array([[1, 0], [0, 1]]) if base == 0 else np.array([[0, 1], [1, 0]])

#### 3.2.4 数学模型与公式讲解

BB84协议的安全性基于量子态的叠加和纠缠特性。在数学上，量子比特可以表示为量子态的叠加：

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle
$$

其中，$\alpha$和$\beta$是复数系数，满足$|\alpha|^2 + |\beta|^2 = 1$。

在BB84协议中，Alice发送的量子比特状态是叠加态，而Bob随机选择基进行测量。如果Alice和Bob选择了相同的基，则测量结果为1，否则为0。这种测量过程可以表示为：

$$
\langle\psi|\hat{O}|0\rangle = \alpha^* \hat{O}_{00} + \beta^* \hat{O}_{10}
$$

其中，$\hat{O}$是测量算符，$\hat{O}_{00}$和$\hat{O}_{10}$是基对应的算符。

- Bob测量的结果：$|1\rangle$（水平偏振）
