#### 3.1.3 数学模型和公式

在能源分配优化过程中，数学模型和公式是描述和解决能源分配问题的重要工具。以下是一个简单的数学模型和公式，用于描述能源分配优化问题。

1. **数学模型**：

   目标函数：最小化能源分配的误差，即最小化实际能源需求与分配能源之间的差异。

   $$\text{Objective Function}:\min_{x} \sum_{i=1}^{n} (x_i - d_i)^2$$

   其中，$x_i$ 表示分配给第 $i$ 个能源源的能源量，$d_i$ 表示第 $i$ 个能源源的能源需求。

2. **公式解释**：

   - **目标函数**：该目标函数表示要最小化的误差，即实际分配的能源与实际需求之间的差异。误差越小，能源分配越合理。
   - **$x_i$ 和 $d_i$**：$x_i$ 表示分配给第 $i$ 个能源源的能源量，$d_i$ 表示第 $i$ 个能源源的能源需求。

3. **举例说明**：

   假设有一个新型融合能源系统，包含三个能源源（太阳能、风能、储能系统），其能源需求分别为 $d_1 = 200$、$d_2 = 150$、$d_3 = 100$。初始分配的能源量分别为 $x_1 = 250$、$x_2 = 200$、$x_3 = 150$。

   根据目标函数，可以计算出能源分配的误差：

   $$\text{Error} = \sum_{i=1}^{3} (x_i - d_i)^2 = (250 - 200)^2 + (200 - 150)^2 + (150 - 100)^2 = 2500 + 2500 + 2500 = 7500$$

   可以看到，能源分配的误差为 7500，这意味着能源分配并不合理，存在较大的能源浪费。为了优化能源分配，可以调整分配策略，使误差最小化。

   ```python
   # 构建模型

       Dropout(0.2),

       Dropout(0.2),
       Dense(1)
   ])

   ```

   ```python
   # 训练模型
   ```

