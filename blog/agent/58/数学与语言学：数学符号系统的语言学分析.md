#### 1.1.1 数学符号系统的起源与发展

数学符号系统的起源可以追溯到古巴比伦时期，当时人们开始使用各种符号和记号来记录数字和计算。随着数学的发展，特别是在古希腊时期，数学符号系统逐渐成熟。例如，毕达哥拉斯学派使用符号来表示数学概念和公式，阿基米德则使用符号来表示几何形状的面积和体积。

在现代，数学符号系统已经成为数学表达的核心工具。从基本的加号（+）、减号（-）、乘号（×）和除号（÷），到复杂的积分符号（∫）、微分符号（d），数学符号系统不断发展，以适应数学各个分支的需求。现代数学符号系统的设计和标准化工作，主要由国际数学协会（International Mathematical Union，简称IMU）负责。

#### 1.1.2 语言学的定义与分支

语言学是研究人类语言的科学，旨在探讨语言的结构、发展、功能及其在社会中的作用。语言学可以分为多个分支，包括：

1. **语音学（Phonetics）**：研究语音的物理属性和人类发音器官的生理机制。
2. **语音学（Phonology）**：研究语音的系统特征和语音之间的规则关系。
3. **句法学（Syntax）**：研究句子的结构规则。
4. **语义学（Semantics）**：研究语言的意义。
5. **语用学（Pragmatics）**：研究语言在具体语境中的使用。

语言学的起源可以追溯到古希腊哲学家对语言的探讨，如亚里士多德对修辞学和逻辑学的贡献。在现代，语言学得到了飞速发展，特别是在结构主义和生成语法理论的推动下，语言学的理论和方法不断丰富。

# 导入所需的库
import re
from mermaid import Mermaid

# 常用的数学符号和语言符号
math_symbols = ["+", "-", "*", "/", "=", ">", "<", "≈"]
language_symbols = ["a", "b", "c", "d", "e", "I", "the", "is"]

# 符号解析函数
def parse_symbols(expression):
    # 使用正则表达式解析数学和语言符号
    math_symbols_pattern = r'[' + re.escape(''.join(math_symbols)) + r']'
    language_symbols_pattern = r'[' + re.escape(''.join(language_symbols)) + r']'
    
    # 提取数学符号
    math_symbols_in_expression = re.findall(math_symbols_pattern, expression)
    
    # 提取语言符号
    language_symbols_in_expression = re.findall(language_symbols_pattern, expression)
    
    return math_symbols_in_expression, language_symbols_in_expression

# 语义分析函数
def semantic_analysis(symbols):
    # 根据符号列表进行语义分析
    analysis_results = {}
    for symbol in symbols:
        if symbol in math_symbols:
            analysis_results[symbol] = "数学符号"
        elif symbol in language_symbols:
            analysis_results[symbol] = "语言符号"
    return analysis_results

# 生成Mermaid图
def generate_mermaid_chart(symbols):
    # 创建Mermaid对象
    m = Mermaid()
    
    # 根据符号列表生成Mermaid图
    if symbols:
        m.add_sequence('Symbols', **{'actor': 'User', 'content': f'输入符号：{symbols}'})
        m.add_sequence('Symbols', **{'actor': 'System', 'content': f'解析符号：{symbols}'})
        m.add_sequence('Symbols', **{'actor': 'Semantic Analysis', 'content': f'语义分析：{semantic_analysis(symbols)}'})
    else:
        m.add_sequence('Symbols', **{'actor': 'User', 'content': f'无符号输入'})
    
    return m.generate_html()

# 主函数
def analyze_system(expression):
    # 解析符号
    math_symbols, language_symbols = parse_symbols(expression)
    
    # 语义分析
    semantic_results = semantic_analysis(math_symbols + language_symbols)
    
    # 生成Mermaid图
    mermaid_chart = generate_mermaid_chart(semantic_results.keys())
    
    # 输出结果
    print("符号分析结果：", semantic_results)
    print("Mermaid图：")
    print(mermaid_chart)

# 测试代码
expression = "3 + 4 = 7; I love coding"
analyze_system(expression)
