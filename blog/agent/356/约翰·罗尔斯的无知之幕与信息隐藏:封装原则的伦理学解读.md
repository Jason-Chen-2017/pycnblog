### Python源代码实现

```python
import hashlib
import base64

def encrypt_data(data):
    """
    对数据进行加密
    """
    # 使用SHA-256加密算法
    encrypted_data = hashlib.sha256(data.encode()).hexdigest()
    return encrypted_data

def decrypt_data(encrypted_data):
    """
    对数据进行解密
    """
    # 使用SHA-256加密算法
    decrypted_data = hashlib.sha256(encrypted_data.encode()).hexdigest()
    return decrypted_data

def store_data(data):
    """
    存储数据
    """
    # 使用base64编码，便于存储和传输
    stored_data = base64.b64encode(data.encode()).decode()
    return stored_data

def retrieve_data(stored_data):
    """
    获取存储的数据
    """
    # 使用base64解码，获取原始数据
    retrieved_data = base64.b64decode(stored_data.encode()).decode()
    return retrieved_data

# 测试算法
data = "Hello, World!"
encrypted_data = encrypt_data(data)
print(f"加密后的数据：{encrypted_data}")

stored_data = store_data(encrypted_data)
print(f"存储后的数据：{stored_data}")

retrieved_data = retrieve_data(stored_data)
print(f"获取后的数据：{retrieved_data}")

decrypted_data = decrypt_data(retrieved_data)
print(f"解密后的数据：{decrypted_data}")
```

### 算法原理讲解

1. **数据加密与解密**：该算法使用SHA-256加密算法对数据进行加密和解密。SHA-256是一种常用的哈希函数，可以确保数据的唯一性和完整性。在加密过程中，将数据转换为十六进制字符串；在解密过程中，将十六进制字符串转换为原始数据。

2. **数据存储与检索**：使用base64编码将加密后的数据转换为字符串，便于存储和传输。在存储过程中，将加密后的数据存储在文件中；在检索过程中，从文件中读取加密后的数据。

3. **隐私保护与安全性保障**：通过加密和解密算法，确保数据在传输和存储过程中的安全性。加密后的数据无法被未经授权的用户访问，从而保护个人隐私。

### 数学模型与公式

1. **加密算法**：使用SHA-256加密算法，将数据d转换为哈希值h。

   $$ h = \text{SHA-256}(d) $$

2. **解密算法**：使用SHA-256加密算法，将哈希值h转换为原始数据d。

   $$ d = \text{SHA-256}(h) $$

3. **base64编码与解码**：将加密后的数据转换为base64编码的字符串s，便于存储和传输。

   $$ s = \text{base64}\text{encode}(h) $$

   将base64编码的字符串s转换为原始数据h。

   $$ h = \text{base64}\text{decode}(s) $$

### 举例说明

假设有一个字符串`data = "Hello, World!"`，我们将对其进行加密、存储、检索和解密。

1. **加密**：使用SHA-256加密算法，将数据`data`转换为哈希值`h`。

   $$ h = \text{SHA-256}("Hello, World!") = 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1ef6502bcdb0279fbb2f64bf $$

2. **存储**：将加密后的哈希值`h`转换为base64编码的字符串`s`。

   $$ s = \text{base64}\text{encode}("2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1ef6502bcdb0279fbb2f64bf") = "QUFFLUhNQU5ET1RJME1vY3ROU2tDSkJTRkxSV0hBUlZBV1dFUVZ5Tk9sY0xtemJsc1JjMWk3" $$

3. **检索**：从文件中读取加密后的数据`s`。

   $$ s = "QUFFLUhNQU5ET1RJME1vY3ROU2tDSkJTRkxSV0hBUlZBV1dFUVZ5Tk9sY0xtemJsc1JjMWk3" $$

4. **解密**：使用SHA-256加密算法，将哈希值`h`转换为原始数据`data`。

   $$ data = \text{SHA-256}("2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1ef6502bcdb0279fbb2f64bf") = "Hello, World!" $$

```python
from cryptography.fernet import Fernet

def generate_key():
    """
    生成加密密钥
    """
    key = Fernet.generate_key()
    return key

def encrypt_data(data, key):
    """
    对数据进行加密
    """
    f = Fernet(key)
    encrypted_data = f.encrypt(data.encode())
    return encrypted_data

def decrypt_data(encrypted_data, key):
    """
    对数据进行解密
    """
    f = Fernet(key)
    decrypted_data = f.decrypt(encrypted_data).decode()
    return decrypted_data
```

#### 系统接口实现

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route("/encrypt", methods=["POST"])
def encrypt():
    data = request.form["data"]
    key = request.form["key"]
    encrypted_data = encrypt_data(data, key)
    return jsonify({"encrypted_data": encrypted_data})

@app.route("/decrypt", methods=["POST"])
def decrypt():
    encrypted_data = request.form["encrypted_data"]
    key = request.form["key"]
    decrypted_data = decrypt_data(encrypted_data, key)
    return jsonify({"decrypted_data": decrypted_data})

@app.route("/store", methods=["POST"])
def store():
    data = request.form["data"]
    store_data(data)
    return jsonify({"message": "Data stored successfully"})

@app.route("/retrieve", methods=["GET"])
def retrieve():
    data = retrieve_data()
    return jsonify({"data": data})
```
