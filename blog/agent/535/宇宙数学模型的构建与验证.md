1. **均方误差（MSE）**：评估模型预测值与实际值之间的平均平方误差，公式为：
   $$MSE = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$
   其中，$\hat{y}_i$是模型预测值，$y_i$是实际值，$N$是数据点的数量。

2. **决定系数（R²）**：评估模型对数据的解释能力，公式为：
   $$R^2 = 1 - \frac{\sum_{i=1}^{N} (\hat{y}_i - y_i)^2}{\sum_{i=1}^{N} (y_i - \bar{y})^2}$$
   其中，$\bar{y}$是实际值的平均值。

3. **平均绝对误差（MAE）**：评估模型预测值与实际值之间的平均绝对误差，公式为：
   $$MAE = \frac{1}{N} \sum_{i=1}^{N} |\hat{y}_i - y_i|$$

4. **均方根误差（RMSE）**：评估模型预测值与实际值之间的均方根误差，公式为：
   $$RMSE = \sqrt{MSE}$$
