### 4.1 心理韧性模型

心理韧性是指个体在面对逆境和压力时，能够迅速恢复和适应的能力。心理韧性模型通常包括以下几个方面：

- **恢复力（Resilience）**：表示个体在遭遇压力后恢复到正常状态的速度和能力。
- **适应力（Adaptability）**：表示个体在逆境中调整和适应的能力。
- **成长力（Growth）**：表示个体在面对挑战时能够学习和成长的能力。

#### 公式表示

$$
心理韧性 = \frac{恢复力 + 适应力 + 成长力}{3}
$$

#### 举例说明

假设一个个体在遭遇压力后，能够在2天内恢复正常状态（恢复力为2），能够很好地适应新环境（适应力为3），并且在挑战中不断学习（成长力为2），则其心理韧性为：

$$
心理韧性 = \frac{2 + 3 + 2}{3} = 2.67
$$

### 4.2 情绪调节模型

情绪调节模型用于描述个体如何通过不同的策略调节情绪状态。常见的情绪调节策略包括认知重构、情绪表达和放松训练等。

- **认知重构**：通过改变对事件的认知评价来调节情绪。
- **情绪表达**：通过表达情绪来缓解情绪压力。
- **放松训练**：通过身体放松来调节情绪。

#### 公式表示

$$
情绪调节效果 = \frac{认知重构效果 + 情绪表达效果 + 放松训练效果}{3}
$$

#### 举例说明

假设一个个体在遭遇压力时，通过认知重构（效果为0.8）、情绪表达（效果为0.6）和放松训练（效果为0.7）来调节情绪，则其情绪调节效果为：

$$
情绪调节效果 = \frac{0.8 + 0.6 + 0.7}{3} = 0.72
$$

自我认知模型用于描述个体对自我认知的理解和评估。自我认知包括自我效能感、自我认同和自我价值感等方面。

- **自我效能感**：指个体对自己完成特定任务的信心。
- **自我认同**：指个体对自己的认同和归属感。
- **自我价值感**：指个体对自己的价值和意义的认知。

#### 公式表示

$$
自我认知 = \frac{自我效能感 + 自我认同 + 自我价值感}{3}
$$

#### 举例说明

假设一个个体对自己的自我效能感评估为0.8，自我认同为0.7，自我价值感为0.9，则其自我认知为：

$$
自我认知 = \frac{0.8 + 0.7 + 0.9}{3} = 0.8
$$

行为塑造模型用于描述个体如何通过行为强化来培养健康行为。常见的行为强化策略包括正面激励和负面惩罚。

#### 公式表示

$$

$$

$$

```python
# user.py
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///users.db'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password = db.Column(db.String(120), nullable=False)

@app.route('/register', methods=['POST'])
def register():
    data = request.get_json()
    user = User(username=data['username'], password=data['password'])
    db.session.add(user)
    db.session.commit()
    return jsonify({'message': 'User registered successfully.'})

@app.route('/login', methods=['POST'])
def login():
    data = request.get_json()
    user = User.query.filter_by(username=data['username'], password=data['password']).first()
    if user:
        return jsonify({'message': 'Login successful.'})
    else:
        return jsonify({'message': 'Invalid credentials.'})

@app.route('/profile', methods=['GET'])
def profile():
    username = request.args.get('username')
    user = User.query.filter_by(username=username).first()
    if user:
        return jsonify({'username': user.username})
    else:
        return jsonify({'message': 'User not found.'})
```
