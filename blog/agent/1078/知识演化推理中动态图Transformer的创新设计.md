#### 第2章：图神经网络与动态图Transformer的基本原理

2.1 图神经网络的基本概念

图神经网络（Graph Neural Networks, GNN）是一种专门用于处理图结构数据的神经网络。与传统的卷积神经网络（CNN）和循环神经网络（RNN）不同，GNN直接操作图结构数据，通过学习节点和边的关系来捕捉图数据中的特征和结构信息。

**图神经网络的主要类型包括：**

1. **图卷积网络（GCN）：** GCN是GNN的一种典型形式，通过将卷积操作从图像域扩展到图域，对节点进行特征变换。GCN的核心思想是将节点的特征与其邻接节点的特征进行聚合，从而提取更高级的特征表示。

2. **图注意力网络（GAT）：** GAT在GCN的基础上引入了注意力机制，允许模型根据节点的邻接节点特征的重要性来自适应地加权聚合。这种动态的权重分配使得GAT能够更好地捕捉节点间的关系。

3. **图递归网络（GRN）：** GRN通过递归的方式对图数据进行特征提取，每个节点的特征更新依赖于其邻接节点的特征，这种递归操作可以不断加深对图数据结构的理解。

**图神经网络的核心特点：**

1. **节点特征聚合：** GNN通过聚合节点及其邻接节点的特征来更新节点的表示，从而捕捉节点间的依赖关系。
2. **结构依赖性：** GNN能够直接处理图的结构信息，通过学习节点和边的关系来提取图的特征。
3. **可扩展性：** GNN能够适应不同规模和类型的图数据，通过调整网络结构和超参数来优化性能。

3. **解码器（Decoder）：** 解码器负责将编码器输出的序列解码成节点和边的更新表示。解码器也使用了多头自注意力机制，使得模型能够根据历史状态来更新当前状态。

**动态图Transformer的层次结构：**

1. **多层结构：** 动态图Transformer采用了多层编码器-解码器结构，每层都能够提取更高层次的特征表示。这种层次结构使得模型能够逐渐从原始特征中提取出抽象信息。

2. **递归更新规则：** 动态图Transformer通过递归的方式更新节点和边的特征，每一层的更新都依赖于前一层的结果。这种递归操作使得模型能够捕捉到图数据中的长期依赖关系。

3. **残差连接与批量归一化：** 动态图Transformer在每一层中引入了残差连接和批量归一化，这有助于缓解梯度消失问题，提高模型的训练效果。

        updated_node_embeddings = node_embeddings + tf.reduce_sum(attention_weights * edge_embeddings, axis=1)
        
        return self.fc(updated_node_embeddings)

# 实例化模型
model = DynamicGraphTransformer(num_nodes=100, embedding_dim=64)

# 编译模型
model.compile(optimizer='adam', loss='mse')

# 训练模型
model.fit([nodes, edges], nodes, epochs=10)
