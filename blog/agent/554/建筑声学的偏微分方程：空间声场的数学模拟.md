#### 2.1 偏微分方程的数学模型

##### 2.1.1 偏微分方程的基本原理

偏微分方程描述了未知函数及其偏导数之间的关系。通常形式为：

\[ F(x_1, x_2, \ldots, x_n, u, \frac{\partial u}{\partial x_1}, \frac{\partial u}{\partial x_2}, \ldots, \frac{\partial^2 u}{\partial x_1 \partial x_2}, \ldots) = 0 \]

其中，\( u = u(x_1, x_2, \ldots, x_n) \) 是未知函数，\( F \) 是已知函数。

##### 2.1.2 偏微分方程的属性特征对比表格

| 类型         | 描述                                                         | 示例                  |
| ------------ | ------------------------------------------------------------ | --------------------- |
| 线性偏微分方程 | 各项都是未知函数及其偏导数的线性组合。                        | \( u_{xx} + u_{yy} = 0 \) |
| 非线性偏微分方程 | 包含未知函数或其偏导数的非线性项。                          | \( u^2_{xx} + u^2_{yy} = 0 \) |
| 常微分方程   | 只含有一个自变量的偏微分方程。                               | \( \frac{du}{dx} = f(u) \) |
| 部分微分方程 | 包含两个或多个自变量的偏微分方程。                          | \( \frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2} \) |

##### 2.1.3 偏微分方程的求解方法简介

- **分离变量法**：将多变量偏微分方程分解为几个单变量偏微分方程，分别求解后再组合。
- **傅里叶变换法**：将偏微分方程转化为频率域的方程，从而简化求解过程。
- **拉普拉斯变换法**：适用于线性偏微分方程，通过拉普拉斯变换将偏微分方程转化为代数方程。
