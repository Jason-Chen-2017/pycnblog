### 量子密码学背景

量子密码学是密码学的一个重要分支，它利用量子力学的基本原理来设计安全加密和解密方法。量子密码学的核心概念包括量子比特、量子纠缠和量子密钥分发等。

#### 量子比特与经典比特

量子比特（qubit）是量子计算机的基本单元，它与传统计算机中的经典比特（bit）有本质的不同。经典比特只能处于两种状态之一，即0或1。而量子比特可以同时处于多种状态的叠加，这种叠加态可以用一个复数系数来表示。量子比特的这一特性被称为量子叠加。

量子比特的另一个重要特性是量子纠缠。当两个或多个量子比特发生纠缠时，它们之间的状态会相互关联，即使它们相隔很远，一个量子比特的状态变化也会立即影响到另一个量子比特的状态。这种现象被称为量子纠缠。

#### 量子纠缠

量子纠缠是量子密码学的关键概念之一。它能够实现远距离的量子通信，使得量子密钥分发成为可能。在量子密钥分发中，发送方和接收方通过量子纠缠的量子比特来交换密钥。由于量子纠缠的特性，任何对量子比特的测量都会立即影响其他量子比特的状态，从而泄露信息。这使得量子密钥分发比传统加密方法更安全。

#### 量子密钥分发

量子密钥分发（Quantum Key Distribution, QKD）是量子密码学中的一个重要应用。QKD的基本思想是通过量子通信协议在发送方和接收方之间安全地交换密钥。常见的量子密钥分发协议包括BB84协议和E91协议。

BB84协议是由Charles H. Bennett和Giuseppe Ribordy于1984年提出的第一个量子密钥分发协议。该协议基于量子比特的叠加态和测量基底的选择。在BB84协议中，发送方将量子比特发送给接收方，并告知接收方发送时所选的测量基底。接收方测量接收到的量子比特并根据测量结果与发送方共享密钥。

E91协议是由Artur Ekert于1991年提出的量子密钥分发协议。E91协议利用量子纠缠态来实现密钥分发。在E91协议中，发送方和接收方通过量子纠缠对交换量子比特，然后通过经典通信协议共享部分密钥，并根据量子纠缠态的特性来筛选出安全的密钥。

##### BB84协议

BB84协议是由Charles H. Bennett和Giuseppe Ribordy于1984年提出的第一个量子密钥分发协议。该协议的基本原理是通过量子比特的叠加态和测量基底的选择来实现密钥的安全分发。

**步骤：**

1. **量子比特发送**：发送方A将处于叠加态的量子比特序列发送给接收方B。
2. **测量基底选择**：A和B各自选择一个随机的测量基底，并在通信结束后交换这些选择信息。
3. **密钥筛选**：A和B根据一致选择的测量基底，筛选出共享的密钥。

```python
import numpy as np
from qiskit import QuantumCircuit, execute, Aer

# 生成量子比特序列
n_qubits = 4
qubits = QuantumCircuit(n_qubits)

# 对每个量子比特初始化为叠加态
for i in range(n_qubits):
    qubits.h(i)

# 发送量子比特
class QuantumBitSender:
    def __init__(self, qubits):
        self.qubits = qubits

    def send(self):
        return self.qubits.toBytes()

sender = QuantumBitSender(qubits)
quantum_bits = sender.send()

# 接收量子比特并测量
class QuantumBitReceiver:
    def __init__(self, quantum_bits):
        self.quantum_bits = quantum_bits

    def measure(self):
        result = execute(self.quantum_bits, Aer.get_backend("qasm_simulator")).result()
        return result.get_counts()

receiver = QuantumBitReceiver(quantum_bits)
measurements = receiver.measure()

# 筛选共享密钥
selected_bits = [bit for bit, count in measurements.items() if count > 0.9]
print("共享密钥:", selected_bits)
```

```python
from qiskit.quantum_info import state_fidelity, BellState

# 生成量子纠缠对
n_qubits = 2
entangled_state = BellState(n_qubits)

# 传输量子比特
class QuantumBitTransmitter:
    def __init__(self, entangled_state):
        self.entangled_state = entangled_state

    def send(self, qubit_index):
        return self.entangled_state.qubit(qubit_index)

transmitter = QuantumBitTransmitter(entangled_state)
sent_bit = transmitter.send(0)

# 接收量子比特并基变换
class QuantumBitReceiver:
    def __init__(self, sent_bit):
        self.sent_bit = sent_bit

    def transform(self, basis):
        return self.sent_bit.transform(basis)

receiver = QuantumBitReceiver(sent_bit)
transformed_bit = receiver.transform('X')

# 筛选共享密钥
fidelity = state_fidelity(transformed_bit.state(), entangled_state.state())
```
