#### 2.1 认知心理学的基础理论

认知心理学的基础理论涵盖了多个研究领域，以下是其中的几个关键概念：

**2.1.1 注意力与感知**

注意力是认知过程的一个重要方面，它决定了我们能够集中精力和资源处理哪些信息。感知是注意力发挥作用的前提，它涉及我们对外部世界的感官体验。认知心理学研究表明，注意力的分配和感知过程对信息处理的质量和效率有着重要影响。

- **选择性注意力**：在复杂环境中，人们往往只能注意到一部分信息，而忽略其他信息。这种选择性注意力有助于我们在有限的认知资源下处理重要信息。
- **分配注意力**：当同时需要处理多个任务时，个体需要在不同任务间分配注意力。分配注意力的能力直接影响任务完成的效率和效果。

**2.1.2 记忆与遗忘**

记忆是认知过程的核心组成部分，它包括信息的存储、提取和遗忘。认知心理学对记忆的研究帮助我们理解如何优化信息存储和提取，以提高人机交互的效果。

- **短期记忆**：短期记忆是指能够保持几秒钟到几分钟的信息。它对当前任务的执行至关重要。
- **长期记忆**：长期记忆是指能够持续存储多年甚至终身的信息。它涉及到对新知识的理解和应用。

遗忘是记忆过程的一部分，认知心理学研究如何通过复述、复习等方法来减少遗忘，提高信息的持久性。

**2.1.3 决策与判断**

决策和判断是认知过程中高度复杂和重要的方面。人们常常需要基于有限的信息做出决策，而这些决策往往受到多种认知偏差的影响。

- **启发式策略**：在决策过程中，人们常常使用启发式策略，如代表性启发、可用性启发和锚定效应，这些策略虽然简化了决策过程，但也可能导致偏差。
- **判断力**：认知心理学研究如何提高个体的判断力，使其在不确定性和复杂性面前做出更明智的决策。

- **信息整合**：ChatGPT在生成响应时需要整合不同来源的信息，这与人类的注意力分配和信息整合过程相类似。
- **记忆与遗忘**：ChatGPT在生成响应时会参考其记忆库中的信息，而遗忘则是由于信息未得到有效强化或长期未使用。

```python
from transformers import pipeline

# 创建聊天机器人实例
chatbot = pipeline("chat", model="gpt-3.5-turbo", temperature=0.8)

# 设计提示词
def generate_response(input_prompt):
    context = []
    for turn in input_prompt:
        context.append(turn['role'] + ': ' + turn['content'])
    context = "\n".join(context)
    response = chatbot([{"role": "system", "content": "您是一个聪明的助手。"}, {"role": "user", "content": context}])[0]['content']
    return response

# 用户交互
while True:
    user_input = input("您有什么问题吗？ ")
    if user_input.lower() in ["退出", "结束"]:
        break
    user_input_data = [{"role": "user", "content": user_input}]
    print(generate_response(user_input_data))
```
