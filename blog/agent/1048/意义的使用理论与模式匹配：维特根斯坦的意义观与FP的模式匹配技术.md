#### 模式匹配机制

模式匹配是FP语言中的一个强大工具，它允许程序员将数据结构分解为多个部分，并根据这些部分的不同情况执行不同的操作。模式匹配的基本原理是通过定义一系列的模式，然后尝试将输入数据与这些模式进行匹配。如果匹配成功，相应的操作就会被执行。

在FP中，模式匹配通常通过构造器表达式（Constructor Expression）来实现。构造器表达式是一种特殊的函数，它接受一个数据结构作为输入，并返回一个值。构造器表达式可以识别数据中的不同分支，并执行相应的操作。例如，在Haskell中，可以使用以下构造器表达式来匹配一个列表：

```haskell
matchList :: [a] -> String
matchList [] = "空列表"
matchList (_:_) = "非空列表"
```

在这个例子中，`matchList` 函数尝试将输入的列表与两个模式进行匹配。如果输入列表为空，函数返回“空列表”；否则，返回“非空列表”。

构造器表达式不仅可以匹配基本数据类型，还可以匹配复合数据类型。例如，在Haskell中，可以使用以下构造器表达式来匹配一个树形数据结构：

```haskell
data Tree a = Leaf a | Node (Tree a) (Tree a)

matchTree :: Tree a -> String
matchTree (Leaf x) = "叶节点，值为：" ++ show x
matchTree (Node l r) = "内部节点，左子树：" ++ (matchTree l) ++ "，右子树：" ++ (matchTree r)
```

在这个例子中，`matchTree` 函数尝试将输入的树与两个模式进行匹配。如果输入树是一个叶节点，函数返回“叶节点，值为：”加上节点的值；如果输入树是一个内部节点，函数返回“内部节点，左子树：”加上左子树的匹配结果，“，右子树：”加上右子树的匹配结果。

```python
def match_students(students, name=None, min_age=None, max_age=None, min_score=None, max_score=None):
    result = []
    for student in students:
        if (name is None or student["name"] == name) and \
           (min_age is None or student["age"] >= min_age) and \
           (max_age is None or student["age"] <= max_age) and \
           (min_score is None or student["score"] >= min_score) and \
           (max_score is None or student["score"] <= max_score):
            result.append(student)
    return result
```

在这个函数中，我们使用了一个嵌套的`if`语句，根据不同的条件筛选学生数据。这实际上是一种简单的模式匹配实现，尽管不是FP中的构造器表达式，但我们可以将其视为一个模式匹配的雏形。
