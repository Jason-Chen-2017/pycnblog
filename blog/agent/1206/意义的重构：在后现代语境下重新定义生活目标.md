### 示例1：冒泡排序算法

#### mermaid流程图

```mermaid

    A[初始列表] --> B{是否已排序?}
    B -->|否| C[交换相邻元素]
    C --> D[再次检查]
    D -->|未排序| C
    B -->|是| E[结束排序]

#### Python源代码

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr

# 示例数据
arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = bubble_sort(arr)
print("排序后的数组：", sorted_arr)
```

#### 算法原理讲解

冒泡排序是一种简单的排序算法，它重复地遍历要排序的数列，一次比较两个元素，如果他们的顺序错误就把他们交换过来。遍历数列的工作是重复地进行直到没有再需要交换，也就是说该数列已经排序完成。

#### 数学模型和公式

冒泡排序的时间复杂度为O(n^2)，其中n为数组的长度。最好的情况是O(n)，当数组已经排序时。

$$
T(n) = \begin{cases}
O(n), & \text{如果数组已排序} \\
O(n^2), & \text{如果数组未排序}
\end{cases}
$$

### 示例2：二分查找算法

#### mermaid流程图

```mermaid
graph TD
    A[输入有序数组] --> B[输入目标值]
    B --> C{中间值 = (low + high) / 2}
    C -->|中间值 < 目标值| D[更新low = mid + 1]
    C -->|中间值 > 目标值| E[更新high = mid - 1]
    C -->|中间值 == 目标值| F[查找成功]
    D --> G{low <= high}
    E --> G
    G --> C
    F --> H[返回目标值]
    H --> I[查找失败]
```

#### Python源代码

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

# 示例数据
arr = [1, 3, 5, 7, 9, 11, 13, 15]
target = 7
index = binary_search(arr, target)
if index != -1:
    print(f"元素{target}在数组中的索引是：{index}")
else:
    print(f"元素{target}不在数组中")
```

#### 算法原理讲解

二分查找是一种在有序数组中查找特定元素的搜索算法。它将数组分为两半，每次将中间值与目标值进行比较，并根据比较结果调整搜索范围。通过不断缩小搜索范围，直到找到目标元素或确定其不存在。

#### 数学模型和公式

二分查找的时间复杂度为O(log n)，其中n为数组的长度。

$$
T(n) = O(\log n)
$$

### 示例3：快速排序算法

#### mermaid流程图

```mermaid
graph TD
    A[输入数组] --> B{选择基准元素}
    B --> C[分区操作]
    C --> D{递归排序左子数组}
    C --> E{递归排序右子数组}
    D --> F{递归结束}
    E --> F
```

#### Python源代码

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 示例数据
arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = quick_sort(arr)
print("排序后的数组：", sorted_arr)
```

#### 算法原理讲解

快速排序是一种高效的排序算法，它采用分治策略来排序。选择一个基准元素，将数组分为小于基准元素和大于基准元素的子数组，然后递归地对这些子数组进行排序。

#### 数学模型和公式

快速排序的平均时间复杂度为O(n log n)，最坏情况下的时间复杂度为O(n^2)。

$$
T(n) = O(n \log n) \quad \text{（平均情况）}
$$
$$
T(n) = O(n^2) \quad \text{（最坏情况）}
$$

### 示例1：冒泡排序算法

#### mermaid流程图

```mermaid
graph TD
    A[初始列表] --> B{是否已排序?}
    B -->|否| C[交换相邻元素]
    C --> D[再次检查]
    D -->|未排序| C
    B -->|是| E[结束排序]
    C --> F[已排序]
```

#### Python源代码

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr

# 示例数据
arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = bubble_sort(arr)
print("排序后的数组：", sorted_arr)
```

#### 算法原理讲解

冒泡排序是一种简单的排序算法，它重复地遍历要排序的数列，一次比较两个元素，如果他们的顺序错误就把他们交换过来。遍历数列的工作是重复地进行直到没有再需要交换，也就是说该数列已经排序完成。

#### 数学模型和公式

冒泡排序的时间复杂度为O(n^2)，其中n为数组的长度。最好的情况是O(n)，当数组已经排序时。

$$
T(n) = \begin{cases}
O(n), & \text{如果数组已排序} \\
O(n^2), & \text{如果数组未排序}
\end{cases}
$$

### 示例2：二分查找算法

#### mermaid流程图

```mermaid
graph TD
    A[输入有序数组] --> B[输入目标值]
    B --> C{中间值 = (low + high) / 2}
    C -->|中间值 < 目标值| D[更新low = mid + 1]
    C -->|中间值 > 目标值| E[更新high = mid - 1]
    C -->|中间值 == 目标值| F[查找成功]
    D --> G{low <= high}
    E --> G
    G --> C
    F --> H[返回目标值]
    H --> I[查找失败]
```

#### Python源代码

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

# 示例数据
arr = [1, 3, 5, 7, 9, 11, 13, 15]
target = 7
index = binary_search(arr, target)
if index != -1:
    print(f"元素{target}在数组中的索引是：{index}")
else:
    print(f"元素{target}不在数组中")
```

#### 算法原理讲解

二分查找是一种在有序数组中查找特定元素的搜索算法。它将数组分为两半，每次将中间值与目标值进行比较，并根据比较结果调整搜索范围。通过不断缩小搜索范围，直到找到目标元素或确定其不存在。

#### 数学模型和公式

二分查找的时间复杂度为O(log n)，其中n为数组的长度。

$$
T(n) = O(\log n)
$$

### 示例3：快速排序算法

#### mermaid流程图

```mermaid
graph TD
    A[输入数组] --> B{选择基准元素}
    B --> C[分区操作]
    C --> D{递归排序左子数组}
    C --> E{递归排序右子数组}
    D --> F{递归结束}
    E --> F
```

#### Python源代码

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 示例数据
arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = quick_sort(arr)
print("排序后的数组：", sorted_arr)
```

#### 算法原理讲解

快速排序是一种高效的排序算法，它采用分治策略来排序。选择一个基准元素，将数组分为小于基准元素和大于基准元素的子数组，然后递归地对这些子数组进行排序。

#### 数学模型和公式

快速排序的平均时间复杂度为O(n log n)，最坏情况下的时间复杂度为O(n^2)。

$$
T(n) = O(n \log n) \quad \text{（平均情况）}
$$
$$
T(n) = O(n^2) \quad \text{（最坏情况）}
$$
