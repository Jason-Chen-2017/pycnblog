import numpy as np
from keras.models import Model
from keras.layers import Input, Dense, Lambda
from keras.optimizers import RMSprop
from keras import backend as K

def build_vae(input_dim, latent_dim):
    # 编码器部分
    input_img = Input(shape=(input_dim,))
    x = Dense(20, activation='relu')(input_img)
    x = Dense(20, activation='relu')(x)
    encoded = Dense(latent_dim, activation='relu')(x)

    # 解码器部分
    encoded_mean = Dense(20, activation='relu')(encoded)
    encoded_log_sigma = Dense(20, activation='relu')(encoded)
    z_mean = encoded_mean
    z_log_sigma = encoded_log_sigma
    
    # 重新参数化技巧
    z = Lambda(lambda x: x[:, :, None])(z_log_sigma)
    z = Lambda(lambda x: K.exp(x))(z)
    z = Lambda(lambda x: x[:, :, 0])(z)
    z = z_mean + z
    
    decoded = Dense(input_dim, activation='sigmoid')(z)

    # VAE模型
    vae = Model(input_img, decoded)
    vae.compile(optimizer=RMSprop(), loss='binary_crossentropy')

    # 生成器模型
    generator = Model(z_mean, decoded)
    return vae, generator

def sampling(args):
    z_mean, z_log_sigma = args
    z_mean = K.reshape(z_mean, [-1, 1])
    z_log_sigma = K.reshape(z_log_sigma, [-1, 1])
    z = K.random_normal(shape=(K.shape(z_mean)[0], 1), mean=z_mean, std=z_log_sigma)
    return z

# 定义生成模型
input_img = Input(shape=(input_dim,))
z_mean = Dense(latent_dim, activation='relu')(input_img)
z_log_sigma = Dense(latent_dim, activation='relu')(input_img)
z = Lambda(sampling)([z_mean, z_log_sigma])
decoded = Dense(input_dim, activation='sigmoid')(z)

# 创建生成模型
generator = Model(input_img, decoded)

# 编译生成模型
generator.compile(optimizer=RMSprop())

# 创建变分自编码器模型
vae = Model(input_img, z_mean, z_log_sigma=-z_log_sigma)
vae.compile(optimizer=RMSprop(), loss='binary_crossentropy')

# 打印模型结构

#### 4.3 算法原理详细讲解

**数学模型和公式**

变分自编码器（VAE）的数学模型主要包括两部分：编码过程和解码过程。

**编码过程**：

设输入数据为\( x \)，通过编码器得到潜在空间中的表示\( z \)：

$$
z = \mu(x) + \sigma(x) \odot \epsilon
$$

其中：
- \( \mu(x) \)是编码器的均值函数，表示为\( x \)的映射。
- \( \sigma(x) \)是编码器的方差函数，表示为\( x \)的映射。
- \( \epsilon \)是均值为0、方差为1的高斯噪声。

**解码过程**：

在潜在空间中，生成器模型将潜在变量\( z \)解码回输入空间：

$$
x' = \phi(z)
$$

其中：
- \( \phi(z) \)是生成器的映射函数，通常采用神经网络来实现。

**损失函数**：

VAE使用两部分损失函数来训练模型：重构损失和KL散度损失。

- **重构损失**：

$$
L_{\text{recon}} = -\sum_x \log p(x'|z)
$$

其中：
- \( p(x'|z) \)是生成模型对重构数据的概率分布。

- **KL散度损失**：

$$
L_{\text{KL}} = -\sum_z \sum_x \log \frac{p(z|x)}{p(z)}
$$

其中：
- \( p(z|x) \)是编码器对潜在变量的概率分布。
- \( p(z) \)是潜在变量的先验分布，通常假设为标准正态分布。

**总体损失函数**：

$$
L = L_{\text{recon}} + \lambda L_{\text{KL}}
$$

其中：
- \( \lambda \)是KL散度损失和重构损失之间的平衡参数。

**通俗易懂的举例说明**

假设我们有一组手写数字的图像数据。VAE的目的是通过编码器将图像映射到一个低维的潜在空间，然后通过生成器将这些低维表示重新映射回图像。

- **编码过程**：编码器将图像映射到一个包含两个坐标的潜在空间点。例如，对于图像\( x \)，编码器输出\( (\mu, \sigma) \)。
- **解码过程**：生成器使用潜在空间中的点\( z = (\mu + \sigma \epsilon) \)生成新的图像\( x' \)。
- **训练过程**：VAE通过最小化重构损失和KL散度损失来训练模型。例如，如果生成的新图像\( x' \)与原始图像\( x \)非常相似，那么重构损失会很小。

通过这种方式，VAE能够学习到数据的有效表示，并且能够生成具有高相似度的数据样本。

### 第5章 数学模型和数学公式

#### 5.1 模型讲解

在上一章节中，我们简要介绍了变分自编码器（VAE）的数学模型。为了更加深入地理解VAE，我们在这里详细讲解其数学模型。

**变分自编码器（VAE）的数学模型主要包括两部分：编码过程和解码过程。**

**编码过程**：

设输入数据为\( x \)，通过编码器得到潜在空间中的表示\( z \)：

$$
z = \mu(x) + \sigma(x) \odot \epsilon
$$

其中：
- \( \mu(x) \)：编码器的均值函数，表示为\( x \)的映射。对于输入\( x \)，\( \mu(x) \)可以表示为：
  $$
  \mu(x) = \sigma_1(x_1, x_2, ..., x_n)
  $$
  其中，\( \sigma_1 \)是一个神经网络，用于学习输入数据的均值。

- \( \sigma(x) \)：编码器的方差函数，表示为\( x \)的映射。对于输入\( x \)，\( \sigma(x) \)可以表示为：
  $$
  \sigma(x) = \sigma_2(x_1, x_2, ..., x_n)
  $$
  其中，\( \sigma_2 \)是一个神经网络，用于学习输入数据的方差。

- \( \epsilon \)：均值为0、方差为1的高斯噪声。在实际计算中，通常使用随机噪声来表示。

**解码过程**：

在潜在空间中，生成器模型将潜在变量\( z \)解码回输入空间：

$$
x' = \phi(z)
$$

其中：
- \( \phi(z) \)：生成器的映射函数，通常采用神经网络来实现。对于潜在变量\( z \)，\( \phi(z) \)可以表示为：
  $$
  \phi(z) = \sigma_3(z_1, z_2, ..., z_n)
  $$
  其中，\( \sigma_3 \)是一个神经网络，用于学习潜在变量的映射。

**总体损失函数**：

VAE使用两部分损失函数来训练模型：重构损失和KL散度损失。

- **重构损失**：

$$
L_{\text{recon}} = -\sum_x \log p(x'|z)
$$

其中：
- \( p(x'|z) \)：生成模型对重构数据的概率分布。通常使用sigmoid函数或softmax函数来表示。

- **KL散度损失**：

$$
L_{\text{KL}} = -\sum_z \sum_x \log \frac{p(z|x)}{p(z)}
$$

其中：
- \( p(z|x) \)：编码器对潜在变量的概率分布。通常使用高斯分布来表示。
- \( p(z) \)：潜在变量的先验分布。通常假设为标准正态分布。

**总体损失函数**：

$$
L = L_{\text{recon}} + \lambda L_{\text{KL}}
$$

其中：
- \( \lambda \)：KL散度损失和重构损失之间的平衡参数。

通过以上数学模型和公式，我们可以看到VAE如何通过编码器和解码器学习输入数据的分布，并生成与输入数据相似的新数据。接下来，我们将使用LaTeX格式给出相关的数学公式，并进行详细解释。

#### 5.2 公式说明

**LaTeX格式数学公式**

下面我们将使用LaTeX格式给出VAE模型中的关键数学公式，并进行详细解释。

**1. 均值函数和方差函数**

$$
\mu(x) = \sigma_1(x_1, x_2, ..., x_n)
$$

$$
\sigma(x) = \sigma_2(x_1, x_2, ..., x_n)
$$

**解释**：这两个公式分别定义了编码器的均值函数和方差函数。均值函数将输入数据映射到一个潜在的均值值，方差函数将输入数据映射到一个潜在的方差值。

**2. 潜在变量**

$$
z = \mu(x) + \sigma(x) \odot \epsilon
$$

**解释**：这个公式定义了潜在变量\( z \)，它通过均值函数和方差函数，以及随机噪声\( \epsilon \)（均值为0、方差为1的高斯噪声）来生成。

**3. 解码器映射**

$$
x' = \phi(z)
$$

**解释**：这个公式定义了生成器的映射函数，它将潜在变量\( z \)映射回输入空间中的新数据\( x' \)。

**4. 重构损失**

$$
L_{\text{recon}} = -\sum_x \log p(x'|z)
$$

**解释**：重构损失函数衡量生成模型对输入数据的重构能力。它计算生成模型对重构数据的概率分布的对数似然。

**5. KL散度损失**

$$
L_{\text{KL}} = -\sum_z \sum_x \log \frac{p(z|x)}{p(z)}
$$

**解释**：KL散度损失函数衡量编码器对潜在变量的概率分布的学习能力。它计算编码器对潜在变量的先验分布和条件分布之间的Kullback-Leibler散度。

**6. 总体损失函数**

$$
L = L_{\text{recon}} + \lambda L_{\text{KL}}
$$

**解释**：总体损失函数是重构损失和KL散度损失的加权总和，用于训练变分自编码器。\( \lambda \)是一个超参数，用于调整两种损失函数之间的平衡。

通过以上LaTeX格式数学公式的给出和解释，我们可以更好地理解变分自编码器（VAE）的数学模型。接下来，我们将探讨如何在城市规划和智能应用中应用VAE模型。

x = Dense(512, activation='relu')(z)

decoder = Model(z, outputs)

- **数据来源**：城市土地使用数据、交通流量数据、环境监测数据等来源于城市规划部门、交通管理部门和环保部门。
