### 情感劳动的定义与起源

### 核心概念术语说明

#### 情感劳动

情感劳动是指员工在职场中通过情感表达、情绪管理和人际关系互动来完成的劳动。它不同于传统的身体劳动和智力劳动，情感劳动更多地依赖于员工的情感智商和人际关系能力。

#### 身体劳动

身体劳动指的是通过身体运动和体力活动完成的劳动，如建筑工人、农民等职业所从事的工作。

#### 智力劳动

智力劳动是指通过智力活动、思考和创造完成的劳动，如科学家、程序员等职业所从事的工作。

2. **情感劳动理论（Emotional Labor Theory）**：
   - 情感劳动理论由心理学家阿伦·布洛科维奇（Aaron Bluecove）提出，强调员工在工作中需要管理自己的情感，以满足组织的要求。这种管理包括表达适当的情感和抑制不适当的情感。

3. **情感资本（Emotional Capital）**：
   - 情感资本是指个人在情感管理、人际沟通和情感智力方面的能力。具有高情感资本的员工往往能在职场中表现出色，建立良好的人际关系。

4. **情感劳动与服务质量（Emotional Labor and Service Quality）**：

     ```python
         role = db.Column(db.Enum('customer', 'employee'), nullable=False)

     @app.route('/register', methods=['POST'])
     def register():
         data = request.get_json()
         new_user = User(username=data['username'], password=data['password'], role=data['role'])
         db.session.add(new_user)
         db.session.commit()
         return jsonify(message="User registered successfully"), 201

     @app.route('/login', methods=['POST'])
     def login():
         data = request.get_json()
         user = User.query.filter_by(username=data['username'], password=data['password']).first()
         if user:
             return jsonify(token="generated_token", message="Login successful"), 200
         else:
             return jsonify(message="Invalid credentials"), 401
     ```
