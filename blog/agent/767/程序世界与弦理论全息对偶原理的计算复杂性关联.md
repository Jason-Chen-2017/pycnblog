## 2. 核心概念与联系

### 2.1 计算复杂性基本概念

#### 2.1.1 时间复杂度

时间复杂度是指算法运行所需时间的增长速度。通常用大O符号表示，如 O(n),O(n^2) 等。

#### 2.1.2 空间复杂度

空间复杂度是指算法运行所需内存的增长速度。同样使用大O符号表示。

#### 2.1.3 经典算法复杂度分析

我们通过一个简单的算法来分析其时间复杂度和空间复杂度。

```python
# 示例算法：求和
def sum(n):
    result = 0
    for i in range(n):
        result += i
    return result
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)
