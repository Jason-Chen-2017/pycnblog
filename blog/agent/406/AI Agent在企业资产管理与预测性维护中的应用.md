from sklearn.metrics import accuracy_score

# 假设我们有一个训练数据集X和标签y

$$
P(Fault|X) = \frac{e^{\theta^T X}}{1 + e^{\theta^T X}}

其中，$P(Fault|X)$ 表示在特征 $X$ 下发生故障的概率，$\theta$ 是模型参数。
