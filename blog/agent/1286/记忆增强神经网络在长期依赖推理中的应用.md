## 第一部分：导言与背景

### 第1章：问题背景与概述

#### 1.1 长期依赖推理的重要性

长期依赖推理是指模型在处理序列数据时，能够理解和利用数据中的长期依赖关系。例如，在自然语言处理中，理解一句话的含义不仅需要考虑单个单词，还需要考虑单词之间的顺序和上下文。同样，在计算机视觉中，分析一幅图像也需要理解图像中对象的长期依赖关系。

- **问题描述**：传统的神经网络如RNN（循环神经网络）和LSTM（长短期记忆网络）在处理长期依赖问题上存在局限。这是因为这些模型在训练过程中容易受到梯度消失和梯度爆炸的影响，导致难以捕捉长序列中的依赖关系。
- **问题解决**：为了克服这些限制，研究人员提出了记忆增强神经网络，通过引入记忆机制来增强模型对长期依赖的捕捉能力。
- **边界与外延**：长期依赖推理不仅局限于自然语言处理和计算机视觉，还可以应用于时间序列预测、文本生成等领域。
- **核心要素组成**：长期依赖推理的核心要素包括序列数据、依赖关系捕捉和上下文理解。

#### 2.2 记忆增强神经网络的核心原理

- **原理讲解**：记忆增强神经网络的核心原理是利用外部记忆模块来存储和检索信息。在处理序列数据时，模型将当前输入与记忆内容进行交互，从而更新记忆内容。这种交互过程通过特殊的门控机制实现，包括读取门、写入门和忘记门。

  - **读取门**：决定从记忆中检索哪些信息。
  - **写入门**：决定将哪些信息写入记忆。
  - **忘记门**：决定从记忆中删除哪些信息。

- **数学模型与公式**：

  - **读取门**：\( h_t = \sigma(W_h h_{t-1} + W_x x_t + b_h) \)，其中 \( h_t \) 是当前隐藏状态，\( \sigma \) 是 sigmoid 函数，\( W_h \) 和 \( W_x \) 是权重矩阵，\( b_h \) 是偏置项。

  - **写入门**：\( g_t = \sigma(W_g [h_{t-1}, x_t] + b_g) \)，其中 \( g_t \) 是写入门控信号。

  - **忘记门**：\( f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \)，其中 \( f_t \) 是忘记门控信号。

  - **记忆更新**：\( M_t = (1 - f_t) \odot M_{t-1} + g_t \odot x_t \)，其中 \( M_t \) 是记忆内容，\( \odot \) 表示元素-wise 乘法。

  - **输出**：\( o_t = \sigma(W_o [h_{t-1}, x_t, M_t] + b_o) \)，其中 \( o_t \) 是输出。

#### 3.1 长期依赖问题

- **概念属性特征对比表格**：

| 概念       | 属性特征                               | 对比分析                           |
|------------|--------------------------------------|-----------------------------------|

| 记忆增强神经网络 | 外部记忆模块 + 神经网络                | 适用于长序列，灵活性强           |

#### 3.2 神经网络基础

- **基本结构**：神经网络由多个层组成，包括输入层、隐藏层和输出层。每层由多个神经元组成，神经元之间通过加权连接。
- **学习算法**：神经网络通过反向传播算法进行学习。在训练过程中，模型不断调整权重和偏置，以最小化损失函数。

### 第4章：记忆增强技术的实现

#### 4.1 记忆单元

- **功能**：记忆单元是记忆增强神经网络的核心组成部分，用于存储和检索信息。记忆单元可以存储任意类型的信息，如单词、图像或时间序列数据。
- **设计**：记忆单元通常由读取门、写入门和忘记门组成。这些门控机制决定了记忆单元中的信息如何更新和检索。

  - **读取门**：读取门决定从记忆单元中检索哪些信息。它通过一个 sigmoid 函数计算，输出介于 0 和 1 之间的值，表示每个记忆单元的重要性。
  - **写入门**：写入门决定将哪些信息写入记忆单元。它也是一个 sigmoid 函数，用于计算写入信号。
  - **忘记门**：忘记门决定从记忆单元中删除哪些信息。它通过一个 sigmoid 函数计算，输出介于 0 和 1 之间的值，表示每个记忆单元的遗忘概率。

#### 4.2 门控机制

- **原理**：门控机制是记忆增强神经网络的关键组成部分，用于控制信息的流动。读取门、写入门和忘记门共同作用，使模型能够灵活地更新和检索记忆。
- **实现**：门控机制的实现涉及三个 sigmoid 函数和三个乘法运算。每个门控函数都接受当前隐藏状态和输入作为输入，并输出一个 0 到 1 之间的值。

  - **读取门**：\( h_t = \sigma(W_h h_{t-1} + W_x x_t + b_h) \)
  - **写入门**：\( g_t = \sigma(W_g [h_{t-1}, x_t] + b_g) \)
  - **忘记门**：\( f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \)

- **记忆更新**：通过门控机制，记忆单元的信息进行更新。新的记忆内容由当前输入和旧记忆内容共同决定。

  - **记忆更新**：\( M_t = (1 - f_t) \odot M_{t-1} + g_t \odot x_t \)

#### 3.1 长期依赖问题

**背景介绍**：
长期依赖问题在序列数据建模中至关重要。在自然语言处理（NLP）和计算机视觉（CV）等领域，理解序列中的长期依赖关系是模型有效性的关键。例如，在NLP任务中，一个单词的含义往往取决于它在句子中的位置和上下文，而上下文又可能涉及到句子中的其他词，甚至之前的句子。在CV任务中，图像中某个对象的存在和状态也与其在图像中的位置及其周围对象有关。

**概念属性特征对比表格**：

|------------------|--------------------------------------------|-------------------------------------|

| 记忆增强神经网络 | 引入外部记忆模块，增强记忆能力           | 适用于长序列，灵活性强，计算效率高   |

#### 3.2 神经网络基础

**基本结构**：
神经网络由多层神经元组成，包括输入层、隐藏层和输出层。每个神经元都与前一层中的所有神经元相连，并通过权重和偏置进行加权求和。隐藏层的神经元通过激活函数产生输出，这个输出作为下一层的输入。

**学习算法**：
神经网络通过反向传播算法进行学习。在训练过程中，模型不断调整权重和偏置，以最小化损失函数。反向传播算法包括以下几个步骤：

1. **前向传播**：将输入数据传递到神经网络中，计算每个神经元的输出。
2. **计算损失**：将输出与实际标签进行比较，计算损失值。
3. **反向传播**：根据损失值，计算每个神经元的误差，并更新权重和偏置。

**设计**：

#### 4.2 门控机制

**原理**：
门控机制是记忆增强神经网络的关键组成部分，用于控制信息的流动。读取门、写入门和忘记门共同作用，使模型能够灵活地更新和检索记忆。

- **读取门**：读取门决定从记忆中检索哪些信息。它通过一个 sigmoid 函数计算，输出一个 0 到 1 之间的值，表示每个记忆单元的重要性。公式如下：
  $$ h_t = \sigma(W_h h_{t-1} + W_x x_t + b_h) $$
  其中，\( h_t \) 是当前隐藏状态，\( \sigma \) 是 sigmoid 函数，\( W_h \) 和 \( W_x \) 是权重矩阵，\( b_h \) 是偏置项。

- **写入门**：写入门决定将哪些信息写入记忆。它也是一个 sigmoid 函数，用于计算写入信号。公式如下：
  $$ g_t = \sigma(W_g [h_{t-1}, x_t] + b_g) $$
  其中，\( g_t \) 是写入门控信号。

- **忘记门**：忘记门决定从记忆中删除哪些信息。它通过一个 sigmoid 函数计算，输出一个 0 到 1 之间的值，表示每个记忆单元的遗忘概率。公式如下：
  $$ f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) $$
  其中，\( f_t \) 是忘记门控信号。

**实现**：
门控机制的实现涉及三个 sigmoid 函数和三个乘法运算。每个门控函数都接受当前隐藏状态和输入作为输入，并输出一个 0 到 1 之间的值。

在Python中，门控机制的实现示例代码如下：

```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def read_gate(h_t_1, x_t, W_h, W_x, b_h):
    return sigmoid(np.dot(W_h, h_t_1) + np.dot(W_x, x_t) + b_h)

def write_gate(h_t_1, x_t, W_g, b_g):
    return sigmoid(np.dot(W_g, np.concatenate((h_t_1, x_t))) + b_g)

def forget_gate(h_t_1, x_t, W_f, b_f):
    return sigmoid(np.dot(W_f, np.concatenate((h_t_1, x_t))) + b_f)
```

- **记忆更新**：通过门控机制，记忆单元的信息进行更新。新的记忆内容由当前输入和旧记忆内容共同决定。

  $$ M_t = (1 - f_t) \odot M_{t-1} + g_t \odot x_t $$
  其中，\( M_t \) 是记忆内容，\( \odot \) 表示元素-wise 乘法。

#### 3.2 神经网络基础

**基本结构**：
神经网络是一种由大量相互连接的简单计算单元组成的计算模型，这些单元被称为神经元。神经网络的基本结构包括输入层、隐藏层和输出层。每个神经元都与前一层中的所有神经元相连，并通过加权连接进行信息传递。

- **输入层**：接收外部输入，如文本、图像等。
- **隐藏层**：对输入进行特征提取和变换，通常包含多个隐藏层。
- **输出层**：生成最终输出，如分类标签、概率分布等。

**学习算法**：
神经网络通过训练数据学习特征映射，其核心是反向传播算法。反向传播算法分为两个阶段：前向传播和后向传播。

1. **前向传播**：将输入数据通过神经网络传递到输出层，计算输出值。
2. **后向传播**：计算输出值与真实值之间的误差，并反向传播误差到网络的每一层，更新权重和偏置。

**数学模型与公式**：

- **前向传播**：
  $$ z = \sum_{i} w_{ij} x_{i} + b_{j} $$
  $$ a = \sigma(z) $$
  其中，\( z \) 是神经元的净输入，\( w_{ij} \) 是权重，\( b_{j} \) 是偏置，\( \sigma \) 是激活函数，通常使用 sigmoid、ReLU 或 tanh 函数。

- **反向传播**：
  $$ \delta = (a - t) \odot \sigma'(z) $$
  $$ \Delta w_{ij} = \alpha \cdot \delta \cdot x_{i} $$
  $$ \Delta b_{j} = \alpha \cdot \delta $$
  其中，\( \delta \) 是误差，\( t \) 是目标输出，\( \sigma' \) 是激活函数的导数，\( \alpha \) 是学习率。

### 第4章：记忆增强技术的实现

#### 4.1 记忆单元

**功能**：
记忆单元是记忆增强神经网络的核心组成部分，它用于存储和检索信息。在处理长序列数据时，记忆单元可以帮助模型保持长期依赖关系，从而提高模型的性能。

**设计**：
记忆单元通常由三个主要部分组成：读取门、写入门和忘记门。

- **读取门**：决定哪些信息应该从记忆单元中读取。读取门通过一个 sigmoid 函数计算，输出介于 0 和 1 之间的值，表示每个记忆单元的重要性。
- **写入门**：决定哪些信息应该写入记忆单元。写入门也是一个 sigmoid 函数，用于计算写入信号。
- **忘记门**：决定哪些信息应该从记忆单元中删除。忘记门通过一个 sigmoid 函数计算，输出介于 0 和 1 之间的值，表示每个记忆单元的遗忘概率。

#### 4.2 门控机制

**原理**：
门控机制是记忆增强神经网络的关键组成部分，用于控制信息的流动。通过门控机制，模型可以动态地更新和检索记忆内容。

- **读取门**：读取门决定从记忆中检索哪些信息。它通过一个 sigmoid 函数计算，输出一个 0 到 1 之间的值，表示每个记忆单元的重要性。
  $$ h_t = \sigma(W_h h_{t-1} + W_x x_t + b_h) $$
  其中，\( h_t \) 是当前隐藏状态，\( \sigma \) 是 sigmoid 函数，\( W_h \) 和 \( W_x \) 是权重矩阵，\( b_h \) 是偏置项。

- **写入门**：写入门决定将哪些信息写入记忆。它也是一个 sigmoid 函数，用于计算写入信号。
  $$ g_t = \sigma(W_g [h_{t-1}, x_t] + b_g) $$
  其中，\( g_t \) 是写入门控信号。

- **忘记门**：忘记门决定从记忆中删除哪些信息。它通过一个 sigmoid 函数计算，输出一个 0 到 1 之间的值，表示每个记忆单元的遗忘概率。
  $$ f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) $$
  其中，\( f_t \) 是忘记门控信号。

#### 4.3 记忆更新机制

**原理**：
记忆更新机制通过读取门、写入门和忘记门共同作用，对记忆内容进行更新。

- **读取门**：读取门决定从记忆中检索哪些信息，其输出表示每个记忆单元的重要性。
- **写入门**：写入门决定将哪些新信息写入记忆，其输出表示写入的概率。
- **忘记门**：忘记门决定从记忆中删除哪些信息，其输出表示遗忘的概率。

**数学模型与公式**：

$$
M_t = f_t \odot M_{t-1} + g_t \odot x_t
$$

其中，\( M_t \) 是当前时间步的记忆内容，\( f_t \) 是忘记门控信号，\( g_t \) 是写入门控信号，\( M_{t-1} \) 是前一个时间步的记忆内容，\( x_t \) 是当前输入。

#### 3.2 神经网络基础

**基本结构**：
神经网络是一种由大量相互连接的简单计算单元组成的计算模型，这些单元被称为神经元。神经网络的基本结构包括输入层、隐藏层和输出层。每个神经元都与前一层中的所有神经元相连，并通过加权连接进行信息传递。

- **输入层**：接收外部输入，如文本、图像等。
- **隐藏层**：对输入进行特征提取和变换，通常包含多个隐藏层。
- **输出层**：生成最终输出，如分类标签、概率分布等。

**学习算法**：
神经网络通过训练数据学习特征映射，其核心是反向传播算法。反向传播算法分为两个阶段：前向传播和后向传播。

1. **前向传播**：将输入数据通过神经网络传递到输出层，计算输出值。
2. **后向传播**：计算输出值与真实值之间的误差，并反向传播误差到网络的每一层，更新权重和偏置。

**数学模型与公式**：

- **前向传播**：
  $$ z = \sum_{i} w_{ij} x_{i} + b_{j} $$
  $$ a = \sigma(z) $$
  其中，\( z \) 是神经元的净输入，\( w_{ij} \) 是权重，\( b_{j} \) 是偏置，\( \sigma \) 是激活函数，通常使用 sigmoid、ReLU 或 tanh 函数。

- **反向传播**：
  $$ \delta = (a - t) \odot \sigma'(z) $$
  $$ \Delta w_{ij} = \alpha \cdot \delta \cdot x_{i} $$
  $$ \Delta b_{j} = \alpha \cdot \delta $$
  其中，\( \delta \) 是误差，\( t \) 是目标输出，\( \sigma' \) 是激活函数的导数，\( \alpha \) 是学习率。

#### 4.1 记忆单元

**功能**：
记忆单元是记忆增强神经网络的核心组成部分，它用于存储和检索信息。在处理长序列数据时，记忆单元可以帮助模型保持长期依赖关系，从而提高模型的性能。

**设计**：
记忆单元通常由三个主要部分组成：读取门、写入门和忘记门。

- **读取门**：读取门决定哪些信息应该从记忆单元中读取。读取门通过一个 sigmoid 函数计算，输出介于 0 和 1 之间的值，表示每个记忆单元的重要性。
- **写入门**：写入门决定哪些信息应该写入记忆单元。写入门也是一个 sigmoid 函数，用于计算写入信号。
- **忘记门**：忘记门决定哪些信息应该从记忆单元中删除。忘记门通过一个 sigmoid 函数计算，输出介于 0 和 1 之间的值，表示每个记忆单元的遗忘概率。

#### 4.2 门控机制

**原理**：
门控机制是记忆增强神经网络的关键组成部分，用于控制信息的流动。通过门控机制，模型可以动态地更新和检索记忆内容。

- **读取门**：读取门决定从记忆中检索哪些信息。它通过一个 sigmoid 函数计算，输出一个 0 到 1 之间的值，表示每个记忆单元的重要性。
  $$ h_t = \sigma(W_h h_{t-1} + W_x x_t + b_h) $$
  其中，\( h_t \) 是当前隐藏状态，\( \sigma \) 是 sigmoid 函数，\( W_h \) 和 \( W_x \) 是权重矩阵，\( b_h \) 是偏置项。

- **写入门**：写入门决定将哪些信息写入记忆。它也是一个 sigmoid 函数，用于计算写入信号。
  $$ g_t = \sigma(W_g [h_{t-1}, x_t] + b_g) $$
  其中，\( g_t \) 是写入门控信号。

- **忘记门**：忘记门决定从记忆中删除哪些信息。它通过一个 sigmoid 函数计算，输出一个 0 到 1 之间的值，表示每个记忆单元的遗忘概率。
  $$ f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) $$
  其中，\( f_t \) 是忘记门控信号。

**原理**：
记忆更新机制通过读取门、写入门和忘记门共同作用，对记忆内容进行更新。

- **读取门**：读取门决定从记忆中检索哪些信息，其输出表示每个记忆单元的重要性。
- **写入门**：写入门决定将哪些新信息写入记忆，其输出表示写入的概率。
- **忘记门**：忘记门决定从记忆中删除哪些信息，其输出表示遗忘的概率。

**数学模型与公式**：

$$
M_t = f_t \odot M_{t-1} + g_t \odot x_t
$$

其中，\( M_t \) 是当前时间步的记忆内容，\( f_t \) 是忘记门控信号，\( g_t \) 是写入门控信号，\( M_{t-1} \) 是前一个时间步的记忆内容，\( x_t \) 是当前输入。

#### 3.2 神经网络基础

**基本结构**：
神经网络是一种由大量相互连接的简单计算单元组成的计算模型，这些单元被称为神经元。神经网络的基本结构包括输入层、隐藏层和输出层。每个神经元都与前一层中的所有神经元相连，并通过加权连接进行信息传递。

- **输入层**：接收外部输入，如文本、图像等。
- **隐藏层**：对输入进行特征提取和变换，通常包含多个隐藏层。
- **输出层**：生成最终输出，如分类标签、概率分布等。

**学习算法**：
神经网络通过训练数据学习特征映射，其核心是反向传播算法。反向传播算法分为两个阶段：前向传播和后向传播。

1. **前向传播**：将输入数据通过神经网络传递到输出层，计算输出值。
2. **后向传播**：计算输出值与真实值之间的误差，并反向传播误差到网络的每一层，更新权重和偏置。

**数学模型与公式**：

- **前向传播**：
  $$ z = \sum_{i} w_{ij} x_{i} + b_{j} $$
  $$ a = \sigma(z) $$
  其中，\( z \) 是神经元的净输入，\( w_{ij} \) 是权重，\( b_{j} \) 是偏置，\( \sigma \) 是激活函数，通常使用 sigmoid、ReLU 或 tanh 函数。

- **反向传播**：
  $$ \delta = (a - t) \odot \sigma'(z) $$
  $$ \Delta w_{ij} = \alpha \cdot \delta \cdot x_{i} $$
  $$ \Delta b_{j} = \alpha \cdot \delta $$
  其中，\( \delta \) 是误差，\( t \) 是目标输出，\( \sigma' \) 是激活函数的导数，\( \alpha \) 是学习率。

#### 4.1 记忆单元

**功能**：
记忆单元是记忆增强神经网络的核心组成部分，它用于存储和检索信息。在处理长序列数据时，记忆单元可以帮助模型保持长期依赖关系，从而提高模型的性能。

**设计**：
记忆单元通常由三个主要部分组成：读取门、写入门和忘记门。

- **读取门**：读取门决定哪些信息应该从记忆单元中读取。读取门通过一个 sigmoid 函数计算，输出介于 0 和 1 之间的值，表示每个记忆单元的重要性。
- **写入门**：写入门决定哪些信息应该写入记忆单元。写入门也是一个 sigmoid 函数，用于计算写入信号。
- **忘记门**：忘记门决定哪些信息应该从记忆单元中删除。忘记门通过一个 sigmoid 函数计算，输出介于 0 和 1 之间的值，表示每个记忆单元的遗忘概率。

#### 4.2 门控机制

**原理**：
门控机制是记忆增强神经网络的关键组成部分，用于控制信息的流动。通过门控机制，模型可以动态地更新和检索记忆内容。

- **读取门**：读取门决定从记忆中检索哪些信息。它通过一个 sigmoid 函数计算，输出一个 0 到 1 之间的值，表示每个记忆单元的重要性。
  $$ h_t = \sigma(W_h h_{t-1} + W_x x_t + b_h) $$
  其中，\( h_t \) 是当前隐藏状态，\( \sigma \) 是 sigmoid 函数，\( W_h \) 和 \( W_x \) 是权重矩阵，\( b_h \) 是偏置项。

- **写入门**：写入门决定将哪些信息写入记忆。它也是一个 sigmoid 函数，用于计算写入信号。
  $$ g_t = \sigma(W_g [h_{t-1}, x_t] + b_g) $$
  其中，\( g_t \) 是写入门控信号。

- **忘记门**：忘记门决定从记忆中删除哪些信息。它通过一个 sigmoid 函数计算，输出一个 0 到 1 之间的值，表示每个记忆单元的遗忘概率。
  $$ f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) $$
  其中，\( f_t \) 是忘记门控信号。

#### 4.3 记忆更新机制

**原理**：
记忆更新机制通过读取门、写入门和忘记门共同作用，对记忆内容进行更新。

- **读取门**：读取门决定从记忆中检索哪些信息，其输出表示每个记忆单元的重要性。
- **写入门**：写入门决定将哪些新信息写入记忆，其输出表示写入的概率。
- **忘记门**：忘记门决定从记忆中删除哪些信息，其输出表示遗忘的概率。

**数学模型与公式**：

$$
M_t = f_t \odot M_{t-1} + g_t \odot x_t
$$

其中，\( M_t \) 是当前时间步的记忆内容，\( f_t \) 是忘记门控信号，\( g_t \) 是写入门控信号，\( M_{t-1} \) 是前一个时间步的记忆内容，\( x_t \) 是当前输入。

    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    return x * (1 - x)

    print(f"Memory content at step {x_t}: {memory_content}")

### 第3章：长期依赖与神经网络基础

#### 3.2 神经网络基础

**基本结构**：
神经网络是一种由大量相互连接的简单计算单元组成的计算模型，这些单元被称为神经元。神经网络的基本结构包括输入层、隐藏层和输出层。每个神经元都与前一层中的所有神经元相连，并通过加权连接进行信息传递。

- **输入层**：接收外部输入，如文本、图像等。
- **隐藏层**：对输入进行特征提取和变换，通常包含多个隐藏层。
- **输出层**：生成最终输出，如分类标签、概率分布等。

**学习算法**：
神经网络通过训练数据学习特征映射，其核心是反向传播算法。反向传播算法分为两个阶段：前向传播和后向传播。

1. **前向传播**：将输入数据通过神经网络传递到输出层，计算输出值。
2. **后向传播**：计算输出值与真实值之间的误差，并反向传播误差到网络的每一层，更新权重和偏置。

**数学模型与公式**：

- **前向传播**：
  $$ z = \sum_{i} w_{ij} x_{i} + b_{j} $$
  $$ a = \sigma(z) $$
  其中，\( z \) 是神经元的净输入，\( w_{ij} \) 是权重，\( b_{j} \) 是偏置，\( \sigma \) 是激活函数，通常使用 sigmoid、ReLU 或 tanh 函数。

- **反向传播**：
  $$ \delta = (a - t) \odot \sigma'(z) $$
  $$ \Delta w_{ij} = \alpha \cdot \delta \cdot x_{i} $$
  $$ \Delta b_{j} = \alpha \cdot \delta $$
  其中，\( \delta \) 是误差，\( t \) 是目标输出，\( \sigma' \) 是激活函数的导数，\( \alpha \) 是学习率。

**原理**：
记忆更新机制通过读取门、写入门和忘记门共同作用，对记忆内容进行更新。

- **读取门**：读取门决定从记忆中检索哪些信息，其输出表示每个记忆单元的重要性。
- **写入门**：写入门决定将哪些新信息写入记忆，其输出表示写入的概率。
- **忘记门**：忘记门决定从记忆中删除哪些信息，其输出表示遗忘的概率。

**数学模型与公式**：

$$
M_t = f_t \odot M_{t-1} + g_t \odot x_t
$$

其中，\( M_t \) 是当前时间步的记忆内容，\( f_t \) 是忘记门控信号，\( g_t \) 是写入门控信号，\( M_{t-1} \) 是前一个时间步的记忆内容，\( x_t \) 是当前输入。

np.random.seed(0)

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    return x * (1 - x)

# 定义读取门、写入门和忘记门的计算
def read_gate(h_t_1, x_t, W_h, W_x, b_h):
    return sigmoid(np.dot(W_h, h_t_1) + np.dot(W_x, x_t) + b_h)

def write_gate(h_t_1, x_t, W_g, b_g):
    return sigmoid(np.dot(W_g, np.concatenate((h_t_1, x_t))) + b_g)

def forget_gate(h_t_1, x_t, W_f, b_f):
    return sigmoid(np.dot(W_f, np.concatenate((h_t_1, x_t))) + b_f)

    print(f"Memory content at step {x_t}: {memory_content}")
