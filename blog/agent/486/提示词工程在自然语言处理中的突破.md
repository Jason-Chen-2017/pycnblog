#### 3.1.2 基于统计的方法

基于统计的方法通过统计方法来选择提示词，例如使用互信息、条件概率等指标来评估词对模型的贡献。互信息（MI）可以衡量两个变量之间的相关性，条件概率则可以反映词对模型预测的影响。

**互信息（MI）**：MI(A, B) = ΣP(A, B)log(P(A, B) / (P(A)P(B)))

**条件概率**：P(B|A) = P(A and B) / P(A)

**优点**：具有较强的灵活性，能够适应复杂语言现象。

**缺点**：需要大量数据和计算资源。

$$

其中，$L$ 表示损失函数，$y_i$ 表示第 $i$ 个样本的真实标签，$\hat{y}_i$ 表示模型预测的标签。

在提示词设计中，我们需要选择一组提示词 $P = \{p_1, p_2, ..., p_n\}$，使得模型在包含这些提示词的数据集上的损失函数最小。这个过程可以看作是一个优化问题，可以使用梯度下降法进行求解：

其中，$w_t$ 表示第 $t$ 次迭代的权重，$\alpha$ 表示学习率，$\nabla L(w_t)$ 表示损失函数关于权重 $w_t$ 的梯度。

$$

    # 清洗文本数据（例如去除标点符号、转换为小写等）
    cleaned_data = [' '.join([word.lower() for word in doc.split() if word.isalpha()]) for doc in data]
    return cleaned_data

def train_model(X_train, y_train):
    # 创建CountVectorizer实例
    vectorizer = CountVectorizer()
    # 将文本数据转换为词频矩阵
    X_train_vectorized = vectorizer.fit_transform(X_train)
    # 创建Multinomial Naive Bayes模型
    model = MultinomialNB()
    # 训练模型
    model.fit(X_train_vectorized, y_train)
    return model, vectorizer

# 模型评估
def evaluate_model(model, vectorizer, X_test, y_test):
    # 将测试数据转换为词频矩阵
    X_test_vectorized = vectorizer.transform(X_test)
    # 进行预测
    predictions = model.predict(X_test_vectorized)
    # 打印分类报告
    print(classification_report(y_test, predictions))

# 可视化结果
def visualize_results(history):
    # 绘制训练过程中的损失变化
    plt.figure(figsize=(8, 4))
    plt.plot(history.history['loss'], label='训练集')
    plt.plot(history.history['val_loss'], label='验证集')
    plt.xlabel('Epochs')
    plt.ylabel('Loss')
    plt.title('模型训练损失变化')
    plt.legend()
    plt.show()

# 主函数
if __name__ == '__main__':
    # 加载数据（这里使用随机生成的数据作为示例）
    data = [
        "这是一个正面的评论。",
        "这是一个负面的评论。",
        "这是一个中性的评论。",
        "这是一个正面的评论。",
        "这是一个负面的评论。",
        "这是一个中性的评论。",
    ]
    labels = [1, 0, 2, 1, 0, 2]

    # 预处理数据
    cleaned_data = preprocess_data(data)

    # 划分训练集和测试集
    X_train, X_test, y_train, y_test = train_test_split(cleaned_data, labels, test_size=0.2, random_state=42)

    # 训练模型
    model, vectorizer = train_model(X_train, y_train)

    # 评估模型
    evaluate_model(model, vectorizer, X_test, y_test)

    # 可视化训练结果
    visualize_results(model.fit(X_train, y_train).history)
