#### 3.1 并行算法基本原理

##### 3.1.1 并行算法的定义

并行算法是指将一个大任务分解为多个小任务，并在多个处理单元上同时执行这些任务，以加速计算过程。并行算法通常适用于可以分解为多个独立子任务的计算问题。

##### 3.1.2 并行算法的特点

并行算法具有以下几个特点：

1. **并行性**：并行算法能够在多个处理单元上同时执行任务，从而提高计算速度。
2. **分布式**：并行算法通常在分布式系统上运行，涉及多个计算节点之间的通信和协作。
3. **可扩展性**：并行算法可以随着处理单元的增加而扩展，以适应更大的计算任务。

##### 3.1.3 并行算法的分类

并行算法可以根据不同的分类标准进行分类，例如：

1. **数据并行**：将一个大任务分解为多个小任务，并在不同处理单元上同时处理不同数据。
2. **任务并行**：将一个大任务分解为多个小任务，并同时在多个处理单元上执行这些任务。
3. **混合并行**：同时使用数据并行和任务并行的策略，以最大化并行效率。

import threading
import queue
from Node import Node

class TaskScheduler:
    def __init__(self, nodes):
        self.nodes = nodes
        self.task_queue = queue.Queue()

    def add_task(self, task):
        self.task_queue.put(task)

    def start(self):
        for node in self.nodes:
            thread = threading.Thread(target=self.allocate_tasks, args=(node,))
            thread.start()

    def allocate_tasks(self, node):
        while not self.task_queue.empty():
            task = self.task_queue.get()
            node.execute_task(task)
            node.commit_task()
