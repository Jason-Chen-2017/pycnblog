### 1.2 机器学习基础

#### 1.2.1 机器学习的基本概念

机器学习（Machine Learning，ML）是人工智能（Artificial Intelligence，AI）的一个重要分支，它通过算法让计算机从数据中自动学习和改进性能，而无需显式编程。以下是对机器学习基本概念的详细探讨：

##### 1.2.1.1 定义
- **机器学习**：机器学习是一门研究如何让计算机从数据中学习，并做出决策或预测的学科。它包括统计方法、算法和理论，旨在使计算机具备自主学习和适应新环境的能力。

##### 1.2.1.2 学习类型
- **有监督学习**：在有监督学习中，训练数据集包含输入和对应的输出（标签），算法通过这些数据学习如何将新的输入映射到正确的输出。例如，分类和回归任务。
- **无监督学习**：无监督学习不使用标签，算法需要从未标记的数据中学习模式和结构。常见任务包括聚类和降维。
- **强化学习**：强化学习是一种通过与环境的交互来学习最佳行为策略的机器学习方法。算法通过试错和奖励机制来优化其行为。

##### 1.2.1.3 关键要素
- **特征**：特征是数据集中的属性，用于描述输入样本。
- **模型**：模型是算法的实现形式，用于将输入映射到输出。
- **训练**：训练是使用数据集来调整模型参数的过程，以使模型能够准确预测未知数据。

##### 1.2.1.4 应用场景
- **分类**：将数据分为不同的类别。例如，电子邮件分类为垃圾邮件或非垃圾邮件。
- **回归**：预测数值输出。例如，房价预测。
- **聚类**：将相似的数据点分为不同的群组。例如，客户细分。

### 1.2.2 监督学习、无监督学习和强化学习

##### 1.2.2.1 监督学习

监督学习是一种最常见和广泛应用的机器学习方法，它的核心思想是通过学习输入和输出之间的关系来预测新的输出。以下是监督学习的详细分析：

- **基本概念**：
  - **输入**：监督学习中的输入是特征向量，它们代表了样本的属性。
  - **输出**：输出是标签，是已知的正确结果。
  - **损失函数**：损失函数用于衡量模型预测值与实际值之间的差异，优化算法会调整模型参数以最小化损失。

- **算法**：
  - **线性回归**：用于预测连续数值输出。
  - **逻辑回归**：用于预测二分类问题。
  - **支持向量机（SVM）**：通过找到一个最佳的超平面来分隔不同类别的数据点。

- **应用**：
  - **分类**：如邮件分类、垃圾邮件检测。
  - **回归**：如房屋价格预测、股票价格预测。

##### 1.2.2.2 无监督学习

无监督学习旨在发现数据中的隐含结构或模式，无需已知的输出。以下是几种常见无监督学习方法的详细描述：

- **聚类**：
  - **K-Means**：通过迭代优化目标函数将数据点分配到K个簇中。
  - **层次聚类**：基于层次结构将数据点逐步合并或划分成簇。
  - **DBSCAN**：基于密度的空间聚类方法。

- **降维**：
  - **主成分分析（PCA）**：通过保留最重要的特征来简化数据。
  - **t-SNE**：通过非线性变换将高维数据投影到二维或三维空间，便于可视化。

- **生成模型**：
  - **生成对抗网络（GAN）**：由生成器和判别器组成的框架，用于生成逼真的数据。
  - **变分自编码器（VAE）**：基于概率模型的自编码器，可以生成符合数据分布的新样本。

##### 1.2.2.3 强化学习

强化学习是通过与环境的交互来学习最优策略的机器学习方法。以下是强化学习的核心概念和算法：

- **基本概念**：
  - **状态**：系统当前所处的环境状态。
  - **动作**：系统能够采取的操作。
  - **奖励**：系统在执行动作后获得的即时反馈。
  - **策略**：指导系统选择动作的规则。

- **算法**：
  - **Q-Learning**：通过更新Q值来学习最优策略。
  - **Deep Q-Networks（DQN）**：使用深度神经网络来近似Q值函数。
  - **Policy Gradients**：直接优化策略的梯度。
  - **Actor-Critic Methods**：结合了策略优化和价值估计的方法。

- **应用**：
  - **游戏**：如电子游戏、棋类游戏。
  - **机器人控制**：如自主导航、无人驾驶。

### 结论

机器学习是人工智能的核心组成部分，其基本概念和主要方法包括监督学习、无监督学习和强化学习。每种学习方法都有其独特的应用场景和实现算法，为解决各种复杂问题提供了强有力的工具。掌握这些方法对于从事人工智能研究和开发的人员至关重要。

### 1.3 深度学习原理

#### 1.3.1 深度学习的定义与发展

深度学习（Deep Learning，DL）是机器学习的一个分支，其核心思想是通过多层神经网络（Neural Networks）对数据进行建模，以提取数据的复杂特征。以下是深度学习的定义、发展历程及其在人工智能领域的地位：

##### 1.3.1.1 定义

深度学习是一种基于人工神经网络的机器学习技术，通过构建具有多个隐藏层的神经网络模型来对数据进行建模。与传统的人工神经网络相比，深度学习模型能够自动提取数据的深层特征，从而在图像识别、自然语言处理等领域取得了显著的效果。

##### 1.3.1.2 发展历程

- **1986年**：Rumelhart、Hinton和Williams提出了反向传播算法（Backpropagation），为深度学习的发展奠定了基础。
- **2006年**：Geoffrey Hinton等人重新激发了深度学习的兴趣，提出了深度置信网络（Deep Belief Networks）。
- **2012年**：Alex Krizhevsky在ImageNet竞赛中使用了深度卷积神经网络（Convolutional Neural Network，CNN）取得了突破性的成绩，深度学习开始受到广泛关注。
- **2015年**：Google的深度学习模型在棋类游戏（如围棋）中战胜了人类世界冠军，标志着深度学习在复杂任务中的强大能力。

##### 1.3.1.3 在人工智能领域的地位

深度学习已经成为人工智能领域的重要基石，其在图像识别、语音识别、自然语言处理等多个领域的应用取得了显著的成果。以下是深度学习在各个领域的一些具体应用：

- **图像识别**：深度学习模型在ImageNet竞赛中连续多年取得冠军，广泛应用于人脸识别、物体检测、图像生成等领域。
- **语音识别**：深度学习技术在语音识别中取得了显著的效果，使得智能语音助手如Google Assistant、Amazon Alexa等得到了广泛应用。
- **自然语言处理**：深度学习在文本分类、机器翻译、情感分析等自然语言处理任务中表现优异，推动了自然语言处理技术的发展。

#### 1.3.2 神经网络与深度学习

神经网络（Neural Networks，NN）是深度学习的基础，其灵感来源于生物神经系统的信息处理机制。以下是关于神经网络和深度学习的一些基本概念：

##### 1.3.2.1 神经网络

神经网络由大量简单的计算单元（神经元）组成，这些神经元通过加权连接形成网络结构。每个神经元接收输入信号，通过激活函数进行非线性变换，产生输出信号。

- **基本组成**：
  - **输入层**：接收外部输入信号。
  - **隐藏层**：对输入信号进行处理和变换。
  - **输出层**：产生最终输出。

- **激活函数**：用于引入非线性特性，常用的激活函数包括Sigmoid、ReLU、Tanh等。

- **前向传播与反向传播**：
  - **前向传播**：输入信号从输入层开始，逐层传递至输出层。
  - **反向传播**：计算输出误差，通过梯度下降法调整网络参数。

##### 1.3.2.2 深度学习

深度学习是神经网络的一种扩展，具有多个隐藏层。深度学习模型通过多层神经网络提取数据的深层特征，从而能够更好地理解和表示复杂数据。

- **多层神经网络**：多层神经网络由多个隐藏层组成，每个隐藏层对数据进行加工和抽象，形成更高层次的特征表示。
- **深度神经网络**：深度神经网络（Deep Neural Network，DNN）是指具有多个隐藏层的神经网络模型，通常用于解决复杂的分类和回归问题。
- **卷积神经网络（CNN）**：卷积神经网络是一种专门用于处理图像数据的深度学习模型，通过卷积层、池化层和全连接层提取图像的局部特征和全局特征。
- **循环神经网络（RNN）**：循环神经网络是一种适用于序列数据的神经网络模型，通过循环连接实现对序列数据的长期依赖建模。
- **生成对抗网络（GAN）**：生成对抗网络由生成器和判别器组成，用于生成逼真的数据。

#### 1.3.3 常见的深度学习框架

深度学习框架是用于构建和训练深度学习模型的软件库，以下是一些常见的深度学习框架：

- **TensorFlow**：由Google开发的开源深度学习框架，具有灵活的架构和丰富的API，支持多种深度学习模型。
- **PyTorch**：由Facebook开发的开源深度学习框架，以其动态计算图和灵活的接口而受到研究者和开发者的喜爱。
- **Keras**：基于TensorFlow和Theano的开源深度学习框架，提供简洁的API和丰富的预训练模型，适合快速原型开发和实验。
- **MXNet**：由Apache Software Foundation开源的深度学习框架，支持多种编程语言，具有良好的性能和灵活性。
- **Caffe**：由伯克利深度学习小组开发的开源深度学习框架，特别适合图像分类和视觉任务。

### 结论

深度学习作为人工智能的一个重要分支，通过多层神经网络对数据进行建模，能够提取数据的深层特征，从而在图像识别、语音识别、自然语言处理等领域取得了显著的成果。掌握深度学习的原理和常见框架对于从事人工智能研究和开发的人员至关重要。

## 第二部分: 新编程视界

### 2.1 AI编程的新趋势

AI编程的新趋势代表了人工智能技术在不断发展的过程中，所涌现出的新方向和新方法。这些趋势不仅推动了AI技术的进步，也为开发者提供了更广阔的应用场景。以下是AI编程的几个新趋势：

#### 2.1.1 软计算与智能算法

软计算（Soft Computing）是一种通过结合不同计算方法，解决复杂问题的计算范式。它包括模糊逻辑、进化计算、神经网络等，旨在实现更接近人类思维方式的计算。智能算法是软计算的重要组成部分，通过模拟自然现象和人类思维过程，提高问题的求解能力和自适应能力。

- **模糊逻辑**：模糊逻辑通过处理不确定性和模糊性，为复杂系统提供灵活的解决方案。它在自动控制、决策支持等领域具有广泛的应用。
- **进化计算**：进化计算通过模拟自然进化的过程，如遗传算法、蚁群算法等，用于优化和搜索问题。它在优化设计、资源分配等领域具有重要应用。
- **神经网络**：神经网络作为一种模拟人脑神经元连接和计算方式的模型，通过深度学习等技术，已经取得了显著的应用成果。

#### 2.1.2 聚类分析与新数据挖掘技术

聚类分析（Cluster Analysis）是数据挖掘（Data Mining）的重要方法之一，旨在将数据分为若干个类别，以便更好地理解和分析数据。新数据挖掘技术不断涌现，为AI编程提供了更强大的数据处理和分析能力。

- **高维数据聚类**：在高维空间中，传统聚类方法如K-Means可能失效，新的聚类算法如层次聚类、DBSCAN等被提出，用于处理高维数据。
- **基于密度的聚类**：DBSCAN（Density-Based Spatial Clustering of Applications with Noise）是一种基于密度的聚类方法，能够识别出任意形状的簇，并处理噪声数据。
- **基于模型的聚类**：基于模型的聚类方法通过建立数学模型来描述簇的结构，如高斯混合模型（Gaussian Mixture Model）等。

#### 2.1.3 多智能体系统的编程

多智能体系统（Multi-Agent Systems）是一种分布式计算模型，通过多个智能体（Agents）之间的协作和交互，实现复杂任务的目标。在AI编程中，多智能体系统被广泛应用于无人驾驶、游戏AI、智能交通等领域。

- **通信机制**：多智能体系统需要有效的通信机制来协调智能体的行为，常见的通信机制包括直接通信和间接通信。
- **协调策略**：智能体的行为协调是多智能体系统成功的关键，协调策略包括中央式协调、分布式协调和混合式协调。
- **一致性维护**：在多智能体系统中，一致性维护是确保系统稳定运行的重要任务，一致性算法如时间同步算法、逻辑一致性算法等被广泛应用。

### 2.2 AI编程的新方法

AI编程的新方法不断涌现，为解决复杂问题提供了新的思路和工具。以下是几种重要的AI编程新方法，包括自动机器学习（AutoML）、联合学习和迁移学习，以及生成对抗网络（GAN）：

#### 2.2.1 自动机器学习（AutoML）

自动机器学习（Automated Machine Learning，AutoML）是一种自动化机器学习模型设计和调优的方法，旨在减少机器学习模型的开发时间和工作量。AutoML通过自动化选择最优算法、参数调优和模型评估，帮助开发者快速构建高效的机器学习模型。

- **关键思想**：AutoML通过自动化搜索和组合不同的算法、参数和特征，找到最优的模型配置。它利用了贝叶斯优化、遗传算法等优化技术，以及模型评估指标（如准确率、召回率等）来评估模型性能。
- **主要步骤**：
  - **数据预处理**：自动处理缺失值、异常值等数据问题。
  - **特征选择**：自动化选择对模型性能最有影响力的特征。
  - **模型搜索**：利用算法搜索空间，找到最优的模型配置。
  - **模型评估**：使用交叉验证等手段评估模型性能。
  - **模型部署**：自动化部署模型，提供API接口供应用程序调用。
- **应用场景**：AutoML在金融风控、医疗诊断、智能家居等领域具有广泛应用，通过自动化技术，快速构建和部署机器学习模型，提高了生产效率和准确性。

#### 2.2.2 联合学习和迁移学习

联合学习（Cooperative Learning）和迁移学习（Transfer Learning）是近年来在机器学习领域受到广泛关注的新方法，它们通过共享知识和资源，提高了模型的泛化能力和效率。

- **联合学习**：联合学习通过多个任务共享表示和参数，以提高模型的性能。它通过将多个任务中的特征表示统一，使得模型在不同任务间共享知识和经验。
  - **核心思想**：联合学习利用多任务间的相关性，通过优化多个任务的共同目标，提高每个任务的性能。
  - **主要步骤**：
    - **任务定义**：定义多个相关任务。
    - **共同表示学习**：学习一个共同的表示空间，使得不同任务的样本能够共享特征。
    - **任务优化**：优化每个任务的损失函数，同时考虑整体模型的性能。
- **迁移学习**：迁移学习通过将已在不同任务上训练好的模型迁移到新任务上，以减少新任务的训练时间和提高模型性能。
  - **核心思想**：迁移学习利用预训练模型在特定领域获得的知识，对新任务进行快速适应。
  - **主要步骤**：
    - **预训练模型**：使用大量数据对模型进行预训练，获得通用特征表示。
    - **模型微调**：在新的任务上对预训练模型进行微调，调整模型参数以适应新任务。
    - **模型评估**：评估迁移模型在新任务上的性能。

#### 2.2.3 生成对抗网络（GAN）

生成对抗网络（Generative Adversarial Network，GAN）是由生成器和判别器组成的框架，通过两个对抗网络的博弈，生成与真实数据分布相似的数据。

- **核心思想**：GAN通过生成器生成假数据，判别器判断生成数据与真实数据的真实性，生成器和判别器相互竞争，生成器不断优化生成数据，以达到与真实数据无法区分的水平。
  - **生成器**：生成器通过噪声数据生成假数据，目标是使其尽可能真实。
  - **判别器**：判别器判断输入数据是真实数据还是生成数据，目标是正确分类。
- **应用场景**：GAN在图像生成、数据增强、图像修复等领域具有广泛应用。例如，GAN可以用于生成逼真的图像、视频，甚至可以用于生成新的药物分子，提高药物研发的效率。

### 结论

AI编程的新方法不断推动人工智能技术的进步和应用拓展。自动机器学习（AutoML）简化了模型开发过程，提高了开发效率；联合学习和迁移学习通过知识共享，提升了模型的泛化能力和适应性；生成对抗网络（GAN）则在图像生成、数据增强等领域展示了强大的应用潜力。掌握这些新方法，将为开发者提供更强大的工具，推动AI技术的进一步发展。

#### 2.3.1 AI在自然语言处理中的应用

自然语言处理（Natural Language Processing，NLP）是AI的重要分支，旨在使计算机理解和生成自然语言。随着深度学习和神经网络技术的进步，AI在NLP领域取得了显著成果，以下是一些具体应用：

- **文本分类**：AI用于自动分类大量文本数据，如垃圾邮件过滤、新闻分类等。通过训练分类模型，系统能够识别并分类不同类型的文本。
  - **算法**：常见的文本分类算法包括朴素贝叶斯、支持向量机和深度学习模型如卷积神经网络（CNN）和长短期记忆网络（LSTM）。
  
- **情感分析**：情感分析用于理解文本数据中的情感倾向，如正面、负面或中性。这在市场调研、社交媒体监控等领域有广泛应用。
  - **算法**：情感分析常用模型包括朴素贝叶斯、SVM和深度学习模型如LSTM和BERT。

  - **算法**：机器翻译常用模型包括基于短语的翻译模型、基于神经网络的翻译模型。

- **图像识别**：图像识别用于识别和分类图像中的物体和场景。深度学习模型如卷积神经网络（CNN）在图像识别中取得了突破性成果。
  - **算法**：常见的图像识别算法包括CNN、YOLO（You Only Look Once）和SSD（Single Shot MultiBox Detector）。

- **目标检测**：目标检测用于识别图像中的特定目标并定位其位置。目标检测算法如YOLO、SSD和Faster R-CNN在工业检测、安防监控等领域有广泛应用。
  - **算法**：常见的目标检测算法包括R-CNN、Fast R-CNN、Faster R-CNN和RetinaNet。

- **图像生成**：图像生成通过生成对抗网络（GAN）等模型生成新的图像。GAN在图像修复、风格迁移、数据增强等领域具有广泛应用。
  - **算法**：常见的图像生成算法包括生成对抗网络（GAN）、变分自编码器（VAE）和深度卷积生成网络（DCGAN）。

- **游戏生成**：AI用于生成游戏地图、角色和故事情节，提供了更丰富和多样化的游戏内容。通过生成对抗网络（GAN）等技术，可以自动生成新的游戏元素。
  - **算法**：常见的游戏生成算法包括GAN、噪声生成模型和强化学习。

- **增强现实（AR）**：AI与增强现实（AR）技术的结合，为用户提供沉浸式的体验。AR应用如AR游戏、教育应用和营销活动，通过AI技术实现了实时场景理解、物体识别和交互。

- **隐私保护**：在处理个人数据时，需要确保数据隐私不被泄露。

- **安全框架**：采用安全框架，如加密算法、访问控制和审计日志等，保护系统的安全性。

## 第三部分: 新领域应用实战

### 3.1 AI编程项目实战：自然语言处理

#### 3.1.1 项目背景

自然语言处理（NLP）作为人工智能领域的一个重要分支，广泛应用于文本分类、情感分析、机器翻译等任务。在这个项目中，我们选择构建一个基于深度学习的文本分类系统，用于自动分类用户评论，以帮助电商网站分析用户反馈，优化商品和服务。

#### 3.1.2 系统设计

系统设计包括数据预处理、模型选择、训练和部署等关键步骤。

- **数据预处理**：从电商网站收集用户评论数据，进行数据清洗和预处理，包括去除停用词、标点符号、转换为小写等。
- **模型选择**：选择预训练的深度学习模型，如BERT（Bidirectional Encoder Representations from Transformers），进行文本表示学习。
- **训练**：使用预处理后的数据集，对BERT模型进行微调，训练文本分类器。
- **部署**：将训练好的模型部署到服务器上，实现实时文本分类功能。

#### 3.1.3 项目实现

以下是项目实现的核心步骤：

1. **数据收集与预处理**：

   ```python
   import pandas as pd
   import numpy as np
   from sklearn.model_selection import train_test_split

   # 加载评论数据
   data = pd.read_csv('user_comments.csv')
   # 数据清洗与预处理
   data['clean_text'] = data['comment'].str.lower().str.replace('[^\w\s]', '')
   data = data[data['clean_text'].str.len() > 0]
   data = data.dropna()

   # 分割数据集
   X_train, X_test, y_train, y_test = train_test_split(data['clean_text'], data['label'], test_size=0.2, random_state=42)
   ```

2. **模型选择与训练**：

   ```python
   from transformers import BertTokenizer, BertModel
   from transformers import BertForSequenceClassification
   from torch.utils.data import DataLoader, TensorDataset

   # 加载BERT模型和分词器
   tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
   model = BertForSequenceClassification.from_pretrained('bert-base-uncased', num_labels=2)

   # 预处理文本数据
   train_encodings = tokenizer(X_train.tolist(), truncation=True, padding=True)
   test_encodings = tokenizer(X_test.tolist(), truncation=True, padding=True)

   # 创建数据集
   train_dataset = TensorDataset(train_encodings['input_ids'], train_encodings['attention_mask'], torch.tensor(y_train))
   test_dataset = TensorDataset(test_encodings['input_ids'], test_encodings['attention_mask'], torch.tensor(y_test))

   # 训练模型
   model.train()
   for epoch in range(3):  # 训练3个epochs
       for batch in DataLoader(train_dataset, batch_size=16):
           inputs = {
               'input_ids': batch[0].to('cuda' if torch.cuda.is_available() else 'cpu'),
               'attention_mask': batch[1].to('cuda' if torch.cuda.is_available() else 'cpu'),
               'labels': batch[2].to('cuda' if torch.cuda.is_available() else 'cpu')
           }
           outputs = model(**inputs)
           loss = outputs.loss
           loss.backward()
           optimizer = torch.optim.AdamW(model.parameters(), lr=1e-5)
           optimizer.step()
           optimizer.zero_grad()

   # 评估模型
   model.eval()
   with torch.no_grad():
       for batch in DataLoader(test_dataset, batch_size=16):
           inputs = {
               'input_ids': batch[0].to('cuda' if torch.cuda.is_available() else 'cpu'),
               'attention_mask': batch[1].to('cuda' if torch.cuda.is_available() else 'cpu'),
           }
           outputs = model(**inputs)
           predictions = outputs.logits.argmax(-1)
           accuracy = (predictions == batch[2].to('cuda' if torch.cuda.is_available() else 'cpu')).float().mean()
           print(f'Accuracy: {accuracy.item()}')
   ```

3. **模型部署**：

   ```python
   # 使用Flask构建API
   from flask import Flask, request, jsonify

   app = Flask(__name__)

   @app.route('/classify', methods=['POST'])
   def classify():
       text = request.form['text']
       input_ids = tokenizer(text, return_tensors='pt')
       with torch.no_grad():
           outputs = model(**input_ids)
           prediction = outputs.logits.argmax(-1).item()
   ```

2. **智能体设计**：

   ```python
   class DeepQNetwork:
       def __init__(self, state_size, action_size):
           self.state_size = state_size
           self.action_size = action_size
           self.memory = []
           self.gamma = 0.95  # 折扣因子
           self.epsilon = 1.0  # 探索率
           self.epsilon_min = 0.01
           self.epsilon_decay = 0.995
           self.learning_rate = 0.001
           self.model = self._build_model()

       def _build_model(self):
           # 创建深度Q网络模型
           model = tf.keras.models.Sequential()
           model.add(tf.keras.layers.Dense(24, activation='relu', input_shape=(self.state_size,)))
           model.add(tf.keras.layers.Dense(24, activation='relu'))
           model.add(tf.keras.layers.Dense(self.action_size, activation='linear'))
           model.compile(loss='mse', optimizer=tf.keras.optimizers.Adam(lr=self.learning_rate))
           return model

       def remember(self, state, action, reward, next_state, done):
           # 记录经验
           self.memory.append((state, action, reward, next_state, done))

       def act(self, state):
           # 选择动作
           if np.random.rand() <= self.epsilon:
               return np.random.randint(self.action_size)
           else:
               q_values = self.model.predict(state)
               return np.argmax(q_values[0])

       def replay(self, batch_size):
           # 回放经验
           minibatch = random.sample(self.memory, batch_size)
           for state, action, reward, next_state, done in minibatch:
               target = reward
               if not done:
                   target = reward + self.gamma * np.amax(self.model.predict(next_state)[0])
               target_f = self.model.predict(state)
               target_f[0][action] = target
               self.model.fit(state, target_f, epochs=1, verbose=0)
           if self.epsilon > self.epsilon_min:
               self.epsilon *= self.epsilon_decay
   ```

3. **训练与评估**：

   ```python
   dqn = DeepQNetwork(4, 4)

   # 训练智能体

       state = env.reset()
       state = np.reshape(state, [1, 4])
       for step in range(100):
           action = dqn.act(state)
           next_state, reward, done, _ = env.step(action)
           next_state = np.reshape(next_state, [1, 4])
           dqn.remember(state, action, reward, next_state, done)
           state = next_state
           if done:
               print(f'Episode: {episode}, Step: {step}')
               break
           if episode % 100 == 0:
               dqn.replay(32)
   ```
