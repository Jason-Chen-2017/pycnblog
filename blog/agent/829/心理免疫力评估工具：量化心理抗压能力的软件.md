#### 5.1.1 数学模型

心理免疫力评估模型采用多元线性回归模型，将个体的自我效能感、应对策略、社会支持、心理弹性等关键因素纳入模型，计算综合得分。数学模型如下：

$$
\text{免疫力得分} = \alpha \cdot \text{自我效能感得分} + \beta \cdot \text{应对策略得分} + \gamma \cdot \text{社会支持得分} + \delta \cdot \text{心理弹性得分}
$$

其中，$\alpha$、$\beta$、$\gamma$ 和 $\delta$ 分别为各因素的权重系数。这些系数可以通过大量数据和统计学方法进行优化和调整，以提高模型的准确性。

#### 5.1.2 算法流程

心理免疫力评估算法的流程可以分为以下几个步骤：

1. **数据收集**：通过问卷或访谈等方式，收集个体的自我效能感、应对策略、社会支持、心理弹性等数据。
2. **数据预处理**：对收集到的数据进行分析和处理，包括数据清洗、归一化等步骤，确保数据的质量和一致性。
3. **模型训练**：使用收集到的数据，通过统计学方法（如线性回归）训练评估模型，确定权重系数。
4. **评估计算**：将个体的实际数据输入训练好的模型，计算心理免疫力得分。
5. **结果分析**：对评估结果进行分析，提供个性化的建议和指导。

    def generate_report(self, assessment_id):
        # 生成评估报告
        query = """
            SELECT f.name AS factor, AVG(IFNULL(a.answer, 0)) AS score
            FROM assessments a
            JOIN questions q ON a.questionnaire_id = q.questionnaire_id
            JOIN factors f ON q.factor_id = f.id
            LEFT JOIN answers a ON a.question_id = q.id AND a.assessment_id = a.id
            WHERE a.id = %s
            GROUP BY f.name
        """
        values = (assessment_id,)
        result = self.database.execute(query, values)
        report_data = result.fetchall()
        return report_data

    def export_report(self, assessment_id, report_data):
