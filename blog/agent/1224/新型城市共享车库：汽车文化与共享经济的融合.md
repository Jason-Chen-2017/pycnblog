def assign_parking_spots(demands, spots):
    assigned_spots = []
    for demand in demands:
        closest_spot = min(spots, key=lambda s: distance(demand['location'], s['location']))
        assigned_spots.append(closest_spot)
        spots.remove(closest_spot)
    return assigned_spots

**3.3 停车导航算法**

**3.3.1 算法流程**

停车导航算法旨在为用户提供从当前位置到目标停车位的最佳导航路径。

- **路径规划**：使用路径规划算法（如A*算法），计算从当前位置到目标停车位的最佳路径。
- **路径优化**：根据实时交通状况，对路径进行优化，避免拥堵和高峰时段。
- **导航输出**：将导航结果输出给用户，包括最佳路径和预计到达时间。

**3.3.2 Python源代码**

```python
import heapq

def heuristic(a, b):
    return abs(a[0] - b[0]) + abs(a[1] - b[1])

def a_star_search(start, goal, graph):
    open_set = []
    heapq.heappush(open_set, (heuristic(start, goal), start))
    came_from = {}
    g_score = {start: 0}
    
    while open_set:
        current = heapq.heappop(open_set)[1]
        
        if current == goal:
            break
        
        for neighbor in graph[current]:
            tentative_g_score = g_score[current] + graph[current][neighbor]
            
            if tentative_g_score < g_score.get(neighbor(), float('inf')):
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g_score
                f_score = tentative_g_score + heuristic(neighbor, goal)
                heapq.heappush(open_set, (f_score, neighbor))
    
    return came_from, g_score

# 假设start和goal分别为起始位置和目标位置，graph为路径图
came_from, g_score = a_star_search(start, goal, graph)
print(a_star_search(start, goal, graph))
```

**3.3.3 数学模型**

停车导航的数学模型可以表示为：

\[ \text{路径成本} = \sum_{i=1}^{n} w_i \]

其中，\( w_i \) 表示第 \( i \) 段路径的权重（如距离、速度等）。

        came_from = {}

                break

                tentative_g_score = g_score[current] + graph[current][neighbor]
                
                if tentative_g_score < g_score.get(neighbor(), float('inf')):
                    came_from[neighbor] = current
                    g_score[neighbor] = tentative_g_score
                    f_score = tentative_g_score + heuristic(neighbor, goal)
                    heapq.heappush(open_set, (f_score, neighbor))
        
        return came_from, g_score

    # 假设start和goal分别为起始位置和目标位置，graph为路径图
