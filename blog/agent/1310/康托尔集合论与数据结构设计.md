### 第3章 基础数据结构

#### 3.1 数组与链表

数组与链表是数据结构中的基础类型，它们在计算机科学中有着广泛的应用。

**1. 数组的定义**：

数组是一种线性数据结构，它由一组元素组成，每个元素可以通过一个整数索引来访问。

**2. 数组的表示**：

数组可以使用一维数组或多维数组来表示。一维数组是一个线性表，多维数组是一个多维表。

**3. 数组的操作**：

数组的操作包括插入、删除、查找等。插入和删除操作通常在数组的一端进行，称为尾插和尾删。查找操作可以通过遍历数组来实现。

**4. 数组的优缺点**：

- 优点：数组可以快速访问任意位置的元素，时间复杂度为O(1)。
- 缺点：数组的长度是固定的，无法动态扩展。

**2. 链表的定义**：

链表是一种线性数据结构，它由一组节点组成，每个节点包含数据和指向下一个节点的指针。

**2. 链表的表示**：

链表可以使用单向链表、双向链表或循环链表来表示。单向链表只能向前遍历，双向链表可以向前和向后遍历，循环链表的首尾节点相连。

**3. 链表的优缺点**：

- 优点：链表可以动态扩展，插入和删除操作的时间复杂度为O(1)。
- 缺点：链表需要额外的空间存储指针。

#### 3.3 栈与队列

栈和队列是两种特殊的线性数据结构，它们在程序设计中有着广泛的应用。

**1. 栈的定义**：

栈是一种后进先出（LIFO）的数据结构，它只能在顶部进行插入和删除操作。

**2. 栈的表示**：

栈可以使用数组或链表来表示。数组实现的栈通常使用一个变量记录栈顶的位置，链表实现的栈通常使用头节点作为栈顶。

**3. 栈的操作**：

栈的操作包括入栈、出栈和判空等。入栈操作在栈顶插入元素，出栈操作在栈顶删除元素，判空操作判断栈是否为空。

**4. 栈的优缺点**：

- 优点：栈可以快速插入和删除元素，时间复杂度为O(1)。
- 缺点：栈只能按照后进先出的顺序访问元素。

**2. 队列的定义**：

队列是一种先进先出（FIFO）的数据结构，它只能在队尾进行插入操作，在队头进行删除操作。

**2. 队列的表示**：

队列可以使用数组或链表来表示。数组实现的队列通常使用两个变量记录队头和队尾的位置，链表实现的队列通常使用头节点和尾节点。

**3. 队列的操作**：

队列的操作包括入队、出队和判空等。入队操作在队尾插入元素，出队操作在队头删除元素，判空操作判断队列是否为空。

**4. 队列的优缺点**：

- 优点：队列可以快速插入和删除元素，时间复杂度为O(1)。
- 缺点：队列只能按照先进先出的顺序访问元素。

### 第4章 高级数据结构

#### 4.1 图

图是一种复杂的数据结构，它由一组节点和边组成。图在计算机科学中有着广泛的应用，例如社交网络、搜索引擎和路由算法等。

**1. 图的定义**：

图是由一组节点（也称为顶点）和边组成的集合。节点表示图中的元素，边表示节点之间的关系。

**2. 图的表示**：

图可以使用邻接矩阵或邻接表来表示。邻接矩阵是一个二维数组，用于表示节点之间的边的关系。邻接表是一个数组，每个元素对应一个节点，数组中的每个元素包含指向相邻节点的指针。

**3. 图的操作**：

图的操作包括图的创建、节点的插入和删除、边的插入和删除等。图的创建可以通过初始化邻接矩阵或邻接表来实现。节点的插入和删除可以通过修改邻接矩阵或邻接表的元素来实现。边的插入和删除可以通过修改邻接矩阵的值或邻接表中的指针来实现。

**4. 图的优缺点**：

- 优点：图可以表示复杂的关系，例如社交网络中的关系。
- 缺点：图的存储空间较大，尤其是对于大规模图。

#### 4.2 散列表

散列表（Hash表）是一种高效的数据结构，它通过哈希函数将关键字映射到数组中的位置，以实现快速检索。

**1. 散列表的定义**：

散列表是一种基于哈希函数的数据结构，它将关键字映射到数组中的位置。关键字可以是任何可以比较的对象，例如字符串、整数等。

**2. 散列表的表示**：

散列表通常使用数组来表示，数组中的每个元素是一个链表。当多个关键字映射到同一位置时，这些关键字将被存储在链表中。

**3. 散列表的操作**：

散列表的操作包括插入、删除和查找等。插入操作通过哈希函数计算关键字的位置，并将关键字插入到对应的位置。删除操作通过哈希函数计算关键字的位置，并从对应的位置删除关键字。查找操作通过哈希函数计算关键字的位置，并从对应的位置查找关键字。

**4. 散列表的优缺点**：

- 优点：散列表可以实现快速的插入、删除和查找操作，时间复杂度为O(1)。
- 缺点：散列表可能存在冲突，需要解决冲突的问题。

        else:
            for i, (k, v) in enumerate(self.table[index]):
                if k == key:
                    self.table[index][i] = (key, value)
                    break
            else:
                self.table[index].append((key, value))

    # 查找操作
    def find(self, key):
        index = self.hash_function(key)
        if self.table[index] is None:
            return None
        for k, v in self.table[index]:
            if k == key:
                return v
        return None

    # 删除操作
    def delete(self, key):
        index = self.hash_function(key)
        if self.table[index] is None:
            return
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                del self.table[index][i]
                break
