```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch_geometric.nn import GCN

# 数据预处理
data = ...  # 假设已加载预处理后的数据

# 建立神经网络模型
model = GCN(in_features=data.num_features, hidden_features=16, out_features=1)

# 定义优化器和损失函数
optimizer = optim.Adam(model.parameters(), lr=0.001)
```

### 2.4 神经关系推理算法的数学模型

神经关系推理算法的数学模型主要包括两部分：神经网络模型和损失函数。

#### 神经网络模型

神经网络模型由多个层组成，包括输入层、隐藏层和输出层。每一层的计算公式如下：

$$
h^{(l)} = \sigma(W^{(l)}h^{(l-1)} + b^{(l)})
$$

其中，$h^{(l)}$ 表示第 $l$ 层的输出，$\sigma$ 是激活函数，$W^{(l)}$ 和 $b^{(l)}$ 分别是第 $l$ 层的权重和偏置。

在神经关系推理中，输入层和隐藏层通常包含节点特征和边特征，输出层用于预测节点之间的关系。

#### 损失函数

损失函数用于评估模型预测结果与真实结果之间的差距。在神经关系推理中，常用的损失函数是二进制交叉熵损失函数（BCELoss）：

$$
loss = -\frac{1}{N}\sum_{i=1}^{N} y_i \log(p_i) + (1 - y_i) \log(1 - p_i)
$$

其中，$y_i$ 表示真实标签，$p_i$ 表示模型预测的概率。
