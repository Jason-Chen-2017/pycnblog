### 2.2 类型驱动的算法实例

#### 2.2.1 快速排序

快速排序是一种高效的排序算法，其基本思想是通过一趟排序将待排序的记录分割成独立的两部分，其中一部分记录的关键字均比另一部分的关键字小，则可递归地将这两部分记录继续排序。

以下是一个快速排序的Python实现：

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

arr = [3, 6, 8, 10, 1, 2, 1]
print(quicksort(arr))
```

#### 2.2.2 二分查找

二分查找是一种在有序数组中查找特定元素的算法，其基本思想是不断将查找区间缩小一半，直到找到目标元素或确定其不存在。

以下是一个二分查找的Python实现：

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

arr = [1, 2, 3, 4, 5, 6, 7, 8, 9]
target = 5
print(binary_search(arr, target))
```

#### 2.2.3 贪心算法

贪心算法是一种在每一步选择中都采取当前最优解的策略。尽管这种方法在某些情况下不一定能保证全局最优解，但在很多实际问题中都能得到很好的结果。

以下是一个贪心算法的实例：求最小生成树。

```python
import heapq

def prim算法图(G, start):
    mst = []
    visited = set()
    edges = []
    for v in G:
        if v != start:
            edges.append((G[start][v], start, v))
    edges.sort()
    for edge in edges:
        if edge[2] not in visited:
            mst.append(edge)
            visited.add(edge[2])
    return mst

G = {
    'a': {'b': 2, 'c': 3},
    'b': {'a': 2, 'c': 1, 'd': 1},
    'c': {'a': 3, 'b': 1, 'd': 3},
    'd': {'b': 1, 'c': 3}
}

start = 'a'
print(prim算法图(G, start))
```

```python
from typing import List

def quicksort(arr: List[int]) -> List[int]:
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

arr = [3, 6, 8, 10, 1, 2, 1]
print(quicksort(arr))
```

在这个例子中，类型系统确保了输入和输出的类型一致性，从而提高了算法的可靠性。
