```python
# 导入必要的库
import tensorflow as tf
from tensorflow import keras
import numpy as np

# 准备数据
# 假设我们有100个输入和输出对，这里简化为只有两个特征和目标
x_train = np.random.random((100, 2))
y_train = np.random.randint(2, size=(100, 1))

# 定义模型
model = keras.Sequential([
    keras.layers.Dense(64, activation='relu', input_shape=(2,)),
    keras.layers.Dense(64, activation='relu'),
    keras.layers.Dense(1, activation='sigmoid')
])

# 编译模型
model.compile(optimizer='adam',
              loss='binary_crossentropy',
              metrics=['accuracy'])

# 训练模型
model.fit(x_train, y_train, epochs=10)

# 生成测试数据
x_test = np.random.random((10, 2))
y_test = model.predict(x_test)

# 输出测试结果
print("Test results:", y_test)

# 评估模型性能
test_loss, test_acc = model.evaluate(x_test, y_test)
print("Test accuracy:", test_acc)
```

在模型编译阶段，我们指定了优化器为Adam，损失函数为binary_crossentropy，并选择accuracy作为性能指标。接着，我们使用`fit`方法训练模型，设置了10个训练轮次（epochs）。

在训练完成后，我们使用随机生成的测试数据来评估模型的性能。`predict`方法用于生成预测结果，而`evaluate`方法则用于计算测试集上的损失和准确率。
