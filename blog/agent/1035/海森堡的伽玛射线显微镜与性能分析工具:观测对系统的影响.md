## 第一部分：背景介绍

### 1.1 伽玛射线显微镜的基本概念

伽玛射线显微镜（Gamma Ray Microscope）是一种利用伽玛射线进行成像的显微镜。伽玛射线是一种高能量、短波长的电磁波，具有很高的穿透能力，可以穿透大多数物质。伽玛射线显微镜利用伽玛射线的这一特性，通过探测伽玛射线的散射和吸收，实现对样品的微观结构进行成像。

### 1.2 伽玛射线显微镜的工作原理

伽玛射线显微镜的工作原理基于海森堡不确定性原理。海森堡不确定性原理指出，粒子的位置和动量不能同时被精确测量。在伽玛射线显微镜中，观测过程会扰动粒子的位置和动量，导致成像结果的不确定性。

伽玛射线显微镜通常由发射源、探测器和图像重建算法组成。发射源产生伽玛射线，照射到样品上，样品中的原子核会吸收伽玛射线并发生核反应，释放出新的伽玛射线。探测器检测这些新伽玛射线，并将其转化为电信号。图像重建算法通过对探测信号进行处理，重建出样品的微观结构图像。

### 1.3 伽玛射线显微镜的发展历程

伽玛射线显微镜的发展可以追溯到20世纪30年代，当时科学家们首次利用伽玛射线成像研究生物样品。随着科技的发展，伽玛射线显微镜的分辨率和灵敏度不断提高，应用领域也不断扩展。现在，伽玛射线显微镜已经成为材料科学、生物医学等领域的重要研究工具。

    x_init = np.random.uniform(0, 1)
    y_init = np.random.uniform(0, 1)
    theta_init = np.random.uniform(0, 2 * np.pi)
    return [x_init, y_init, theta_init]

def interaction(particle, sample):
    # 获取粒子的位置和方向
    x, y, theta = particle

    interaction_probability = np.random.uniform(0, 1)
    
    if interaction_probability < sample['scattering_probability']:
        # 粒子发生散射
        theta_new = theta + np.random.uniform(-np.pi/2, np.pi/2)
        particle[2] = theta_new
    elif interaction_probability < sample['absorption_probability']:
        # 粒子发生吸收
        particle[0] = -1
    else:
        # 粒子继续传播
        pass
    
    return particle

# 定义图像重建函数
def reconstruct_image(particles, detector):
    # 初始化图像
    image = np.zeros((detector['size'], detector['size']))
    
    for particle in particles:
        if particle[0] != -1:
            # 计算粒子与探测器的距离
            distance = np.sqrt((particle[0]-detector['center'][0])**2 + (particle[1]-detector['center'][1])**2)
            
            # 计算粒子与探测器的角度
            angle = np.arccos((particle[0]-detector['center'][0]) / distance)
            
            # 更新图像
            image[int(angle/detector['angle_resolution']), int(distance/detector['distance_resolution'])] += 1
    
    return image

def simulate(particles, sample, detector):
    # 初始化图像
    image = np.zeros((detector['size'], detector['size']))
    
    # 模拟粒子与样品的相互作用
    for particle in particles:
        particle = interaction(particle, sample)
        
        # 如果粒子仍在传播，继续模拟
        if particle[0] != -1:
            image = reconstruct_image([particle], detector)
    
    return image

# 定义参数

    'size': 100,
    'center': [50, 50],
    'angle_resolution': np.pi/180,
    'distance_resolution': 1
}

sample = {
    'scattering_probability': 0.5,
    'absorption_probability': 0.2
}

# 生成粒子
particles = [generate_particle() for _ in range(1000)]

# 模拟成像
image = simulate(particles, sample, detector)

# 绘制图像
plt.imshow(image, cmap='gray')
plt.show()
