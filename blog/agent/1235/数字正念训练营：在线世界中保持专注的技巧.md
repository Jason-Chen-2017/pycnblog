### 第二部分：提高专注力的技巧与方法

#### 第4章：基本专注力训练方法

**4.1 肌肉放松训练**

肌肉放松训练有助于减轻身体的紧张感，提高专注力。方法包括：

- **渐进性肌肉放松**：逐步放松身体各部位的肌肉。
- **呼吸训练**：通过深呼吸来放松身体和心灵。

**4.2 正念冥想**

正念冥想是一种有效的专注力训练方法，通过专注呼吸、身体感受等，提高注意力。方法包括：

- **坐姿冥想**：坐在舒适的姿势中，专注于呼吸。
- **动态冥想**：在行走、跑步等运动中进行冥想。

**4.3 定时专注训练**

定时专注训练是一种通过设定特定时间段，专注于特定任务的方法。方法包括：

- **番茄工作法**：每25分钟专注工作，然后休息5分钟。
- **时间块法**：将一天的时间分为多个时间段，每个时间段专注于特定任务。

from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)

db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password = db.Column(db.String(120), nullable=False)

class Task(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(80), nullable=False)
    description = db.Column(db.Text, nullable=True)
    start_date = db.Column(db.Date, nullable=False)
    end_date = db.Column(db.Date, nullable=False)
    status = db.Column(db.String(20), nullable=False)

class FocusLog(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    task_id = db.Column(db.Integer, db.ForeignKey('task.id'), nullable=False)
    start_time = db.Column(db.DateTime, nullable=False)
    end_time = db.Column(db.DateTime, nullable=True)
    duration = db.Column(db.Integer, nullable=True)
    user = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)

class Distraction(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(80), nullable=False)
    description = db.Column(db.Text, nullable=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)

@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({'status': 'success', 'user_id': user.id})
    else:
        return jsonify({'status': 'failure'})

@app.route('/logout', methods=['POST'])
def logout():
    user_id = request.form['user_id']
    # 实现登出逻辑
    return jsonify({'status': 'success'})

@app.route('/tasks', methods=['GET', 'POST'])
def tasks():
    if request.method == 'GET':
        user_id = request.form['user_id']
        tasks = Task.query.filter_by(user_id=user_id).all()
        return jsonify({'tasks': [task.to_dict() for task in tasks]})
    else:
        name = request.form['name']
        description = request.form['description']
        start_date = request.form['start_date']
        end_date = request.form['end_date']
        status = request.form['status']
        user_id = request.form['user_id']
        new_task = Task(name=name, description=description, start_date=start_date, end_date=end_date, status=status, user_id=user_id)
        db.session.add(new_task)
        db.session.commit()
        return jsonify({'status': 'success', 'task_id': new_task.id})

@app.route('/focus_logs', methods=['GET', 'POST'])
def focus_logs():
    if request.method == 'GET':
        user_id = request.form['user_id']
        focus_logs = FocusLog.query.filter_by(user_id=user_id).all()
        return jsonify({'focus_logs': [focus_log.to_dict() for focus_log in focus_logs]})
    else:
        task_id = request.form['task_id']
        start_time = request.form['start_time']
        end_time = request.form['end_time']
        duration = request.form['duration']
        user_id = request.form['user_id']
        new_focus_log = FocusLog(task_id=task_id, start_time=start_time, end_time=end_time, duration=duration, user_id=user_id)
        db.session.add(new_focus_log)
        db.session.commit()
        return jsonify({'status': 'success', 'focus_log_id': new_focus_log.id})

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
