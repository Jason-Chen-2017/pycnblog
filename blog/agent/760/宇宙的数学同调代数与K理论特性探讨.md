这个公式表示K群 \( K(G) \) 是所有从 \( H \) 到 \( G \) 的同态映射的集合，其中 \( f|_H = 0 \) 表示映射 \( f \) 在 \( H \) 上为零映射。

2. **K模性质公式**：

\[ \text{dim}(V) = \sum_{i=1}^{n} \text{dim}(V_i) \]

这个公式表示K模 \( V \) 的维度等于其子模 \( V_i \) 的维度的和。

### 6.1.3 举例说明

为了更好地理解这些数学公式，我们可以通过具体例子来说明。

**同调群公式举例**：

假设我们有两个同调群 \( G = \{1, 2, 3\} \) 和 \( H = \{4, 5, 6\} \)。

1. **同调加法**：

\[ \tilde{H}_0(G \oplus H) = \tilde{H}_0(G) \oplus \tilde{H}_0(H) = \{1, 2, 3\} \oplus \{4, 5, 6\} = \{1+4, 2+5, 3+6\} = \{5, 7, 9\} \]

2. **同调乘法**：

\[ \tilde{H}_1(G \otimes H) = \tilde{H}_1(G) \otimes \tilde{H}_1(H) = \{1, 2, 3\} \otimes \{4, 5, 6\} = \{1\otimes4, 2\otimes5, 3\otimes6\} = \{4, 10, 18\} \]

**K群公式举例**：

假设我们有一个群 \( G = \{1, 2, 3\} \)。

1. **K群分类**：

\[ K(G) = \{ f \in \text{Hom}(H, G) \mid f|_H = 0 \} \]

对于 \( H = \{4, 5, 6\} \)，我们可以得到 \( K(G) = \{ f \in \text{Hom}(H, G) \mid f|_H = 0 \} = \{ f \in \text{Hom}(H, G) \mid f(4) = f(5) = f(6) = 0 \} \)。

2. **K模性质**：

假设我们有一个K模 \( V = \{1, 2, 3\} \)，其子模为 \( V_1 = \{1\} \) 和 \( V_2 = \{2\} \)。

\[ \text{dim}(V) = \text{dim}(V_1) + \text{dim}(V_2) = 1 + 1 = 2 \]

    return result

def k_group_classification(group):
    result = np.zeros_like(group)

        if group[i] == 0:
            result[i] = 1
        else:
            result[i] = 0
    return result
