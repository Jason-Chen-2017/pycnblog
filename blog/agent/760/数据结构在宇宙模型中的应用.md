#### 第5章：树状数据结构在宇宙模型中的应用

**5.1 树的基本概念**

树（Tree）是一种重要的数据结构，用于表示具有层次关系的元素集合。树的基本概念包括：

- **节点（Node）**：树中的基本元素，包含数据和指向其他节点的指针。
- **根节点（Root）**：树的起始节点，没有前驱节点。
- **子节点（Child）**：某个节点的直接后代。
- **父节点（Parent）**：某个节点的直接前驱。
- **叶子节点（Leaf）**：没有子节点的节点。
- **兄弟节点（Siblings）**：具有相同父节点的节点。
- **树的高度（Height）**：从根节点到最远叶子节点的最长路径长度。
- **树的深度（Depth）**：某个节点的层数，根节点的深度为0。

**5.2 树的类型**

常见的树状结构包括：

- **二叉树（Binary Tree）**：每个节点最多有两个子节点。
  - **完全二叉树（Complete Binary Tree）**：每个层都是满的，除了最后一层可能不满。
  - **平衡二叉树（AVL Tree）**：任何节点的左右子树的高度差不超过1。
  - **红黑树（Red-Black Tree）**：是一种自平衡二叉搜索树。

- **二叉搜索树（Binary Search Tree）**：每个节点的左子树中的所有节点的值均小于该节点的值，右子树中的所有节点的值均大于该节点的值。

- **堆（Heap）**：一种特殊的树状结构，用于实现优先队列。

- **哈夫曼树（Huffman Tree）**：是一种用于数据压缩的树状结构。

**5.3 树的基本操作**

树的基本操作包括：

- **创建树**：初始化树结构，设置根节点。
- **插入节点**：在树中添加新节点，根据节点的值进行排序。
- **删除节点**：从树中删除指定节点，根据节点的位置和类型进行处理。
- **查找节点**：在树中查找指定节点，根据节点的值进行搜索。
- **遍历树**：遍历树的所有节点，通常有前序遍历、中序遍历和后序遍历。

**7.1 堆的基本概念**

堆（Heap）是一种特殊的树状数据结构，用于实现优先队列（Priority Queue）。堆分为最大堆和最小堆，其中每个节点的值都大于或小于其子节点的值。以下是堆的基本概念：

- **最大堆（Max Heap）**：每个父节点的值大于或等于其子节点的值。
- **最小堆（Min Heap）**：每个父节点的值小于或等于其子节点的值。
- **堆顶（Heap Top）**：堆顶是堆中值最大的或最小的元素。
- **堆调整（Heap Adjustment）**：用于保持堆的性质，如上浮和下沉操作。

- **插入（Enqueue）**：将元素插入到队列中。
- **删除（Dequeue）**：从队列中删除具有最高优先级的元素。
- **更新（Update）**：修改元素优先级。

```python
class Heap:
    def __init__(self):
        self.heap = []

    def insert(self, element, priority):
        self.heap.append((element, priority))
        self._bubble_up(len(self.heap) - 1)

    def delete(self):
        if len(self.heap) == 0:
            return None
        root = self.heap[0]
        self.heap[0] = self.heap.pop()
        self._sink_down(0)
        return root

    def _bubble_up(self, index):
        parent_index = (index - 1) // 2
        if index > 0 and self.heap[index][1] > self.heap[parent_index][1]:
            self.heap[index], self.heap[parent_index] = self.heap[parent_index], self.heap[index]
            self._bubble_up(parent_index)

    def _sink_down(self, index):
        left_child_index = 2 * index + 1
        right_child_index = 2 * index + 2
        largest = index

        if left_child_index < len(self.heap) and self.heap[left_child_index][1] > self.heap[largest][1]:
            largest = left_child_index

        if right_child_index < len(self.heap) and self.heap[right_child_index][1] > self.heap[largest][1]:
            largest = right_child_index

        if largest != index:
            self.heap[index], self.heap[largest] = self.heap[largest], self.heap[index]
            self._sink_down(largest)
```

#### 第8章：图算法在宇宙模型中的应用

**8.1 图算法的基本概念**

图算法是用于处理图数据结构的一类算法。图（Graph）是一种由节点（Vertex）和边（Edge）组成的非层次数据结构，用于表示复杂的关系和连接。以下是图算法的基本概念：

- **图**：由节点和边组成的集合，表示为 G = (V, E)，其中 V 是节点集，E 是边集。
- **节点**：图中的基本元素，表示为一个顶点或点。
- **边**：连接两个节点的线段，表示节点之间的连接。
- **有向图**：边的方向确定的图，边表示箭头。
- **无向图**：边没有方向确定的图。
- **加权图**：边的权重表示连接两个节点的成本或距离。

**8.2 图算法的分类**

图算法根据其目的和功能可以分为以下几类：

- **遍历算法**：用于遍历图的所有节点，如深度优先搜索（DFS）和广度优先搜索（BFS）。
- **路径算法**：用于找到两个节点之间的路径，如迪杰斯特拉算法（Dijkstra）和贝尔曼-福特算法（Bellman-Ford）。
- **连通性算法**：用于判断两个节点或子图是否连通，如Kruskal算法和Prim算法。
- **最优化算法**：用于解决最优化问题，如Dijkstra最短路径算法和网络流算法。
