区块链是一种去中心化的分布式数据库技术，通过加密算法和共识机制保证数据的安全性和可靠性。

##### **加密算法**

区块链采用密码学原理对数据进行加密，确保数据在传输和存储过程中的安全性。常见的加密算法包括：

- **哈希算法**：将任意长度的数据转化为固定长度的散列值，确保数据的一致性和不可篡改性。
- **非对称加密算法**：通过公钥和私钥对数据进行加密和解密，保障数据传输的安全。
- **对称加密算法**：使用相同的密钥对数据进行加密和解密，保障数据存储的安全。

##### **共识机制**

区块链网络中的节点通过共识机制达成数据的一致性，确保数据的真实性和可靠性。常见的共识机制包括：

- **工作量证明（PoW）**：节点通过解决计算难题来争夺记账权，解决节点间的共识问题。
- **权益证明（PoS）**：节点根据持有的币龄和权益来争夺记账权，降低能源消耗。
- **委托权益证明（DPoS）**：节点通过选举产生超级节点，超级节点争夺记账权。

#### 2.1.2 区块链的核心特点

区块链具有以下核心特点：

- **去中心化**：区块链不依赖于中心化的机构或服务器，节点之间直接进行数据交换和验证，提高了系统的可靠性和抗攻击能力。
- **不可篡改**：区块链的数据一旦记录下来，就很难被篡改，确保了数据的安全性和可靠性。
- **透明性**：区块链的数据对所有参与者都是透明的，任何参与者都可以查看和验证数据。

#### 2.1.3 区块链与传统数据库的区别

区块链与传统数据库在以下几个方面存在区别：

- **数据结构**：区块链采用链式数据结构，而传统数据库采用关系型或非关系型数据结构。
- **数据一致性**：区块链通过共识机制保证数据的一致性，而传统数据库依赖于中心化的服务器和备份机制。

def encrypt_identity_info(identity_info, public_key):
    hash_info = sha256(identity_info.encode('utf-8'))
    encrypted_hash = public_key.encrypt(hash_info, None)
    return encrypted_hash

# 签名身份信息
def sign_identity_info(identity_info, private_key):
    hash_info = sha256(identity_info.encode('utf-8'))
    signature = private_key.sign(hash_info, 'sha256')

def verify_identity_info(encrypted_hash, signature, public_key):
    try:
        decrypted_hash = public_key.decrypt(encrypted_hash, None)
        verified = public_key.verify(decrypted_hash, signature, 'sha256')
        return verified
    except ValueError:
        return False

# 创建区块链
blockchain = Blockchain()

# 注册身份信息
identity_info = "John Doe, 1234567890, john.doe@example.com"
encrypted_hash = encrypt_identity_info(identity_info, public_key)
blockchain.add_transaction({"identity_info_hash": encrypted_hash.hex()})

# 签名身份信息
signature = sign_identity_info(identity_info, private_key)

# 验证身份信息
verified = verify_identity_info(encrypted_hash, signature, public_key)
print("身份验证结果：", "通过" if verified else "失败")

from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives import serialization
from cryptography.hazmat.primitives.hashes import sha256
from blockchain import Blockchain

# 生成密钥对
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048,
)
public_key = private_key.public_key()

# 加密身份信息
def encrypt_identity_info(identity_info, public_key):
    hash_info = sha256(identity_info.encode('utf-8'))
    encrypted_hash = public_key.encrypt(hash_info, None)
    return encrypted_hash

# 签名身份信息
def sign_identity_info(identity_info, private_key):
    hash_info = sha256(identity_info.encode('utf-8'))
    signature = private_key.sign(hash_info, 'sha256')
    return signature

# 验证身份信息
def verify_identity_info(encrypted_hash, signature, public_key):
    try:
        decrypted_hash = public_key.decrypt(encrypted_hash, None)
        verified = public_key.verify(decrypted_hash, signature, 'sha256')
        return verified
    except ValueError:
        return False

# 创建区块链
blockchain = Blockchain()

# 注册身份信息
identity_info = "John Doe, 1234567890, john.doe@example.com"
encrypted_hash = encrypt_identity_info(identity_info, public_key)
blockchain.add_transaction({"identity_info_hash": encrypted_hash.hex()})

# 签名身份信息
signature = sign_identity_info(identity_info, private_key)

# 验证身份信息
verified = verify_identity_info(encrypted_hash, signature, public_key)
print("身份验证结果：", "通过" if verified else "失败")

# 打印区块链数据
print("区块链数据：")
