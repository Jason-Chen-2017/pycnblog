### 2.2 基本语法

正则表达式的基本语法包括字符匹配、字符集与范围匹配、重复匹配等。这些基本语法是构建复杂正则表达式的基石，理解它们有助于我们更有效地处理文本。

#### 2.2.1 字符匹配

字符匹配是正则表达式中最基本的部分，用于匹配单个字符。以下是一些常用的字符匹配符号：

- `.`：匹配除换行符以外的任意一个字符。
- `[abc]`：匹配字符集 `a`、`b` 或 `c` 中的任意一个字符。
- `[^abc]`：匹配不在字符集 `a`、`b` 或 `c` 中的任意一个字符。

#### 2.2.2 字符集与范围匹配

字符集和范围匹配用于定义一组字符的集合。以下是一些常见的字符集和范围匹配符号：

- `[abc]`：匹配字符集 `a`、`b` 或 `c` 中的任意一个字符。
- `[a-z]`：匹配从 `a` 到 `z` 的所有小写字母。
- `[A-Z]`：匹配从 `A` 到 `Z` 的所有大写字母。
- `[0-9]`：匹配从 `0` 到 `9` 的所有数字。

例如，正则表达式 `[a-z0-9]` 将匹配字符串中的任意一个字母或数字。

#### 2.2.3 重复匹配

重复匹配用于定义字符或模式的重复次数。以下是一些常见的重复匹配符号：

- `*`：匹配前一个字符或模式零次或多次。
- `+`：匹配前一个字符或模式一次或多次。
- `?`：匹配前一个字符或模式零次或一次。
- `{n}`：匹配前一个字符或模式恰好 `n` 次。
- `{n,}`：匹配前一个字符或模式至少 `n` 次。
- `{n,m}`：匹配前一个字符或模式至少 `n` 次但不超过 `m` 次。

例如，正则表达式 `a*` 将匹配字符串中的任意个 `a`，包括没有 `a` 的情况。正则表达式 `a{2}` 将匹配恰好两个 `a`，如字符串 `aa`。

#### 2.2.4 字符类别匹配

字符类别匹配用于匹配特定的字符类别，如数字、字母、空白字符等。以下是一些常用的字符类别匹配符号：

- `\d`：匹配任意一个数字。
- `\D`：匹配任意一个非数字字符。
- `\s`：匹配任意一个空白字符，如空格、制表符、换行符等。
- `\S`：匹配任意一个非空白字符。
- `\w`：匹配任意一个字母、数字或下划线。
- `\W`：匹配任意一个非字母、非数字、非下划线的字符。

例如，正则表达式 `\d+` 将匹配一个或多个连续的数字，如字符串 `123` 或 `123456`。

在正则表达式中，有些特殊字符具有特殊含义，如 `.`、`*`、`+`、`?` 等。如果需要匹配这些字符本身，可以使用反斜杠 `\` 进行转义。

### 2.3 高级语法

正则表达式的高级语法提供了更强大的功能和灵活性，使我们可以更精确地描述和匹配复杂的文本模式。以下是一些高级语法：

#### 2.3.1 分组和引用

分组（Grouping）是一种将部分正则表达式分组，以便对其进行操作的技巧。分组可以通过括号 `()` 实现。

1. **捕获组（Capture Groups）**：括号内的部分会捕获匹配的结果，可以通过 `\1`、`\2` 等引用。

   例子：`(\d+)\s+\d+` 匹配形如 `123 456` 的字符串，并捕获第一个数字 `123`。

2. **非捕获组（Non-capturing Groups）**：使用 `(?:...)` 表示，不会捕获匹配的结果。

   例子：`(?:\d+)\s+\d+` 匹配形如 `123 456` 的字符串，但不会捕获数字。

3. **向后引用（Backreference）**：使用 `\1`、`\2` 等引用之前捕获的组。

   例子：`\d+\s+\1` 匹配形如 `123 123` 的字符串，其中两个数字相同。

#### 2.3.2 断言

断言（Assertion）用于匹配文本而不改变匹配的位置。有两种类型的断言：

1. **肯定断言（Positive Lookahead）**：使用 `(?!...)`，表示在当前位置之后必须出现某个模式，但不会移动匹配位置。

   例子：`a(?!b)` 匹配 `a` 但后面不能紧跟 `b`。

2. **否定断言（Negative Lookahead）**：使用 `(?<!...)`，表示在当前位置之前必须出现某个模式，但不会移动匹配位置。

   例子：`a(?<!b)` 匹配 `a` 但前面不能紧跟 `b`。

#### 2.3.3 条件匹配

条件匹配允许我们根据不同的条件匹配文本。

1. **交替匹配（Alternation）**：使用 `|`，表示匹配多个模式中的任意一个。

   例子：`cat|dog` 匹配 `cat` 或 `dog`。

2. **分组和条件结合**：可以使用 `(A|B)?` 匹配零次或一次 `A` 或 `B`。

   例子：`(cat|dog)?` 匹配零次或一次 `cat` 或 `dog`。

#### 2.3.4 零宽度断言

零宽度断言匹配时不改变当前位置，常用于文本验证。

1. **位置断言**：如 `^`（行首）、`$`（行尾）、`(?<=...)`（向前看）、`(?=...)`（向后看）。

   例子：`(?<=\d)A` 匹配在数字之后紧跟的 `A`。

2. **零宽度否定断言**：如 `(?<!...)`（向前看否定）和 `(?!=...)`（向后看否定）。

   例子：`(?<!\d)A` 匹配不在数字之后紧跟的 `A`。

#### 2.3.5 多行匹配

多行匹配允许我们在多个行中进行匹配。

1. **多行模式（Multiline Mode）**：使用 `s` 修饰符，使 `^` 和 `$` 分别匹配每一行的开始和结束。

   例子：`^test$m` 在多行文本中匹配每行的开始和结束。

通过掌握这些高级语法，我们可以创建更复杂、更精确的正则表达式，以满足各种文本处理需求。

def match_data(text):
    # 匹配电子邮件地址
    email_pattern = r"\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b"
    emails = re.findall(email_pattern, text)

    return emails, phones, dates
