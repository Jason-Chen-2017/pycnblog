**Mathematical Formulation and Examples**

### Example: Naive Bayes Classifier for Sentiment Analysis

The Naive Bayes classifier is a popular algorithm for sentiment analysis. It is based on the Bayes' theorem and assumes that the features are conditionally independent given the class label. The mathematical formulation is as follows:

$$
P(Sentiment = +1 | Word = w) = \frac{P(Word = w | Sentiment = +1)P(Sentiment = +1)}{P(Word = w)}
$$

where \(P(Sentiment = +1 | Word = w)\) is the probability of the sentiment being positive given the word \(w\), and \(P(Sentiment = +1)\) is the prior probability of the sentiment being positive.

Example:
Suppose we have a word "happy" and we want to calculate the probability of the sentiment being positive given that the word "happy" is present in the text. We can calculate this as follows:

$$
P(Sentiment = +1 | Word = happy) = \frac{P(Word = happy | Sentiment = +1)P(Sentiment = +1)}{P(Word = happy)}
$$

where \(P(Word = happy | Sentiment = +1)\) is the likelihood of the word "happy" appearing in a positive sentiment text, \(P(Sentiment = +1)\) is the prior probability of positive sentiment, and \(P(Word = happy)\) is the prior probability of the word "happy" appearing in the text.

### Code Application

Here is an example of how to implement a simple sentiment analysis model using Python and scikit-learn:

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline

# Sample data
texts = ['I love this product!', 'This is the worst movie I have ever seen.']
labels = ['positive', 'negative']

# Create a TF-IDF vectorizer
vectorizer = TfidfVectorizer()

# Create a Naive Bayes classifier
classifier = MultinomialNB()

# Create a pipeline that combines the vectorizer and classifier
pipeline = make_pipeline(vectorizer, classifier)

# Train the model
pipeline.fit(texts, labels)

# Predict the sentiment of a new text
new_text = 'I am so happy with this purchase!'
predicted_sentiment = pipeline.predict([new_text])

print(predicted_sentiment)
```

This code snippet demonstrates how to use a TF-IDF vectorizer and a Naive Bayes classifier to perform sentiment analysis on a set of text data.
