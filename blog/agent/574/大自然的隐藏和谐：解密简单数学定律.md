    if n == 0 or n == 1:

    else:

##### 3.2 数学模型与公式

数学模型是描述数学定律的核心工具。以下是一个简单的线性回归模型：

$$
y = ax + b
$$

其中，$y$ 表示因变量，$x$ 表示自变量，$a$ 表示斜率，$b$ 表示截距。通过这个模型，我们可以分析两个变量之间的线性关系。

##### 3.3 举例说明

为了更直观地理解简单数学定律的应用，我们来看一个例子。假设我们要预测某个城市明天的温度。我们可以收集过去几天的温度数据，并使用线性回归模型来建立温度与时间的关系。通过计算斜率和截距，我们可以预测明天的大致温度。

```python
import numpy as np

# 假设过去五天的温度数据
data = np.array([20, 22, 25, 27, 24])

# 计算平均值
mean = np.mean(data)

# 计算斜率
slope = (data[-1] - data[0]) / (len(data) - 1)

# 计算截距
intercept = mean - slope * len(data)

# 构建线性回归模型
model = np.polyfit(range(len(data)), data, 1)

# 预测明天温度
next_day_temp = np.polyval(model, len(data))

# 输出结果
print(f"明天的大致温度为：{next_day_temp}度")
```
