### 图论基础

图论作为数学和计算机科学中一个重要的分支，其基本概念和性质是理解和应用图论算法的基础。在本节中，我们将详细探讨图论的基础概念、基本操作、分类、矩阵表示法以及图的遍历算法。

#### 基础概念

图（Graph）是由节点（Vertex）和边（Edge）组成的数学结构。节点可以表示任何实体，如城市、计算机等；边则表示节点之间的关系，如道路、网络连接等。图可以分为无向图（Undirected Graph）和有向图（Directed Graph）。

- **无向图**：边无方向，任意两个节点之间都是相互连接的。
- **有向图**：边有方向，表示从一个节点指向另一个节点。

此外，图还可以根据边的数量分为简单图（Simple Graph）和多重图（Multi Graph），简单图中的任意两个节点之间最多只有一条边，而多重图中可以存在多条边。

#### 基本操作

在图结构中，常用的基本操作包括：

- **添加节点和边**：在图中添加新的节点和边。
- **删除节点和边**：从图中移除节点和边。
- **查找节点和边**：在图中查找指定的节点或边。
- **遍历图**：从某个节点开始，访问图中的所有节点，遍历算法有深度优先搜索（DFS）和广度优先搜索（BFS）。

#### 分类

图可以根据不同的属性进行分类：

- **根据边的数量**：稠密图（Dense Graph）和稀疏图（Sparse Graph）。稠密图中的边数接近最大可能边数，稀疏图则相反。
- **根据节点的度**：平凡图（Trivial Graph）和非平凡图（Non-Trivial Graph）。平凡图只有单个节点或单条边，非平凡图则具有多个节点和边。
- **根据图的连通性**：连通图（Connected Graph）和断图（Disconnected Graph）。连通图中任意两个节点之间都存在路径，断图则存在多个连通分量。

#### 矩阵表示法

图可以通过矩阵进行表示，常用的有邻接矩阵（Adjacency Matrix）和邻接表（Adjacency List）。

- **邻接矩阵**：一个二维矩阵，其中`G[i][j]`表示节点i和节点j之间的边的情况（如无向图通常表示为`G[i][j] = 1`，有向图则需区分出度和入度）。
- **邻接表**：一个数组，每个数组元素对应一个节点，数组内存储与该节点相连的所有节点。

#### 图的遍历算法

图的遍历算法用于访问图中的所有节点，常用的有深度优先搜索（DFS）和广度优先搜索（BFS）。

- **深度优先搜索（DFS）**：从起始节点开始，尽可能深地搜索图的分支。DFS可以通过递归实现，也可以使用栈进行迭代。
- **广度优先搜索（BFS）**：从起始节点开始，逐层搜索图的邻接节点。BFS通常使用队列实现。

#### 基本性质和度量

图的基本性质包括连通性、度数、路径长度等。连通性是指图中任意两个节点之间都存在路径。度数是指节点的连接数，分为入度和出度。路径长度是指从一个节点到另一个节点的边的数量。

度量方面，有：

- **平均路径长度**：图中所有路径长度的平均值。
- **连通度**：描述图的最大连通分支的大小。
- **边数和节点数的关系**：根据图的不同类型，边数和节点数之间存在特定的关系。

#### 图的度数序列和平均度数

- **度数序列**：图中的所有节点度数按照升序排列形成的序列。
- **平均度数**：图中所有节点度数的平均值。

这些概念和性质是理解图论算法及其在网络优化中应用的基础。接下来，我们将深入探讨图论中的核心算法，包括最短路径算法、最小生成树算法和最大流最小割算法。

### 图的基本性质和度量

在深入探讨图论算法之前，了解图的基本性质和度量是至关重要的。这些性质和度量不仅帮助我们更好地理解图的结构，还为优化算法的设计和实现提供了理论基础。

#### 连通性

连通性是图论中一个非常重要的性质，描述了图中任意两个节点之间是否存在路径。具体来说，图可以分为以下几类：

1. **连通图（Connected Graph）**：图中任意两个节点之间都存在路径。
2. **断图（Disconnected Graph）**：图中存在至少一个连通分量，使得部分节点之间不存在路径。
3. **连通分量（Connected Component）**：断图中连通的部分。

连通性可以通过深度优先搜索（DFS）或广度优先搜索（BFS）算法进行判断。例如，在无向图中，如果一个节点可以通过DFS/BFS访问到其他所有节点，则该图是连通的。

#### 连通分量

连通分量是图的一个基本结构。对于一个断图，可以将它分解为若干个连通分量。连通分量的数量反映了图的复杂度。例如，在一个社交网络中，每个连通分量可能代表一个独立的社交圈。

#### 节点的度数

节点的度数（Degree）是指与该节点相连的边的数量。度数分为入度（In-degree）和出度（Out-degree）。在无向图中，节点的度数是入度和出度的总和。在有向图中，分别计算每个节点的入度和出度。

度数序列是节点度数按升序排列形成的序列。度数序列在图的应用中具有重要地位，例如，在社交网络分析中，度数序列可以帮助我们识别出中心节点和孤立节点。

#### 路径长度

路径长度是指从一个节点到另一个节点的边的数量。最小路径长度是指所有可能路径中的最短路径长度。路径长度和连通性密切相关，例如，在寻找最短路径问题时，连通性是保证存在路径的前提。

#### 平均度数

平均度数是图中所有节点的度数之和除以节点数量。平均度数反映了图的密度，例如，在社交网络中，平均度数可以用来衡量网络的紧密程度。

#### 连通度

连通度是描述图结构的一种度量，它关注图中最大连通分支的大小。在交通网络中，连通度可以用来衡量网络的可靠性，例如，在寻找最优路径时，我们希望路径的连通度尽可能高，以确保交通的畅通无阻。

#### 其他度量

除了上述常见的度量外，还有其他一些重要的图度量，例如：

- **直径（Diameter）**：图中任意两个节点之间的最长路径长度。
- **半径（Radius）**：图中任意节点到其他所有节点的最短路径长度中的最大值。
- **平均路径长度**：所有节点之间的路径长度的平均值。

这些度量可以帮助我们全面理解图的性质和结构，为优化算法的设计提供重要参考。

### 最短路径算法

最短路径算法是图论中非常重要的算法，用于寻找图中两点之间的最短路径。这类算法不仅在实际应用中具有广泛的应用，如导航系统、网络路由等，而且在理论研究中也具有重要意义。本节将详细讲解三种经典的最短路径算法：迪杰斯特拉算法（Dijkstra's Algorithm）、贝尔曼-福特算法（Bellman-Ford Algorithm）和A*算法（A* Algorithm）。

#### 迪杰斯特拉算法（Dijkstra's Algorithm）

迪杰斯特拉算法是一种适用于图中的所有节点非负权重的最短路径算法。它的基本思想是使用一个优先队列（通常是一个二叉堆）来维护当前找到的最短路径，并逐步扩展这些路径。

**算法原理**：

1. 初始化：设置一个优先队列，初始时将源点加入队列，并将所有其他点的距离初始化为无穷大。
2. 循环：从优先队列中取出距离最小的点u，并将其标记为已访问。
3. 对于u的每个未访问的邻接点v，计算从源点到v的路径长度，如果这个路径长度小于当前v的距离，则更新v的距离和前驱节点。
4. 重复步骤2和3，直到队列中只剩下源点。

**算法实现**：

```python
import heapq

def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        
        if current_distance > distances[current_node]:
            continue

        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

**示例**：

假设有一个无向图，如下所示：

```
A --1-- B
|      |
2      3
|      |
C --4-- D
```

使用迪杰斯特拉算法计算从A到其他节点的最短路径：

```
from A to B: 1
from A to C: 2
from A to D: 3
from B to C: 2
from B to D: 4
from C to D: 1
```

#### 贝尔曼-福特算法（Bellman-Ford Algorithm）

贝尔曼-福特算法是一种适用于图中的所有节点非负权重的最短路径算法。它可以通过检测负权重循环来确保路径的最优性。

**算法原理**：

1. 初始化：设置一个距离数组，初始时将源点距离设为0，其他点距离设为无穷大。
2. 循环：对于每个边，计算目标节点的距离，如果新计算的距离小于当前距离，则更新距离。
3. 检测：如果经过n-1轮循环后，仍然可以找到更短的路径，则图中存在负权重循环。

**算法实现**：

```python
def bellman_ford(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0

    for _ in range(len(graph) - 1):
        for u in graph:
            for v, weight in graph[u].items():
                if distances[u] + weight < distances[v]:
                    distances[v] = distances[u] + weight

    for u in graph:
        for v, weight in graph[u].items():
            if distances[u] + weight < distances[v]:
                return None  # 图中存在负权重循环

    return distances
```

**示例**：

假设有一个无向图，如下所示：

```
A --1-- B
|      |
2      3
|      |
C --4-- D
```

使用贝尔曼-福特算法计算从A到其他节点的最短路径：

```

from A to C: 2
from A to D: 3
from B to C: 2
from B to D: 3
from C to D: 1
```

#### A*算法（A* Algorithm）

A*算法是一种基于启发式搜索的最短路径算法，它结合了迪杰斯特拉算法和贪心搜索的优势。A*算法通过评估函数（f(n) = g(n) + h(n)）来估计从源点到目标节点的最短路径。

**算法原理**：

1. 初始化：设置一个开放列表和关闭列表，初始时将源点加入开放列表，并将所有其他点加入关闭列表。
2. 循环：选择一个f(n)最小的点n，从开放列表中移除，并将其加入关闭列表。
3. 对于n的每个未访问的邻接点v，计算从源点到v的路径长度，如果这个路径长度小于当前v的距离，则更新v的距离和前驱节点，并将v加入开放列表。

**算法实现**：

```python
import heapq

def heuristic(node1, node2):
    # 这里使用曼哈顿距离作为启发式函数
    return abs(node1[0] - node2[0]) + abs(node1[1] - node2[1])

def a_star(graph, start, goal):
    open_list = []
    heapq.heappush(open_list, (0, start))
    closed_list = set()

    while open_list:
        current = heapq.heappop(open_list)[1]
        closed_list.add(current)

        if current == goal:
            return reconstruct_path(current, start)

        for neighbor, weight in graph[current].items():
            if neighbor in closed_list:
                continue

            tentative_distance = distances[current] + weight
            if tentative_distance < distances[neighbor]:
                distances[neighbor] = tentative_distance
                f_score = tentative_distance + heuristic(neighbor, goal)
                heapq.heappush(open_list, (f_score, neighbor))

    return None  # 目标不可达

def reconstruct_path(current, start):
    path = []
    while current != start:
        path.append(current)
        current = parent[current]
    path.append(start)
    return path[::-1]
```

假设有一个无向图，如下所示：

```

|      |
2      3
|      |
C --4-- D
```

使用A*算法计算从A到D的最短路径：

```

from A to C: 2
from A to D: 3
from B to C: 2
from B to D: 3
from C to D: 1
```

### 最小生成树算法

最小生成树（Minimum Spanning Tree，MST）算法是图论中的一个重要课题，主要用于在无向图中寻找一棵包含所有节点的树，使得树中的边权总和最小。最小生成树在现实世界中有广泛的应用，如电信网络的构建、电路板布线、物流配送路径规划等。本节将详细讲解三种经典的最小生成树算法：普里姆算法（Prim's Algorithm）、克鲁斯卡尔算法（Kruskal's Algorithm）和最近公共祖先算法（Lowest Common Ancestor Algorithm）。

#### 普里姆算法（Prim's Algorithm）

普里姆算法是一种以贪心策略为基础的构造最小生成树的算法。它从某个起始节点开始，逐步扩展最小生成树，直到包含所有节点。

**算法原理**：

1. 初始化：选择一个起始节点，将其加入最小生成树，并将所有其他节点的距离初始化为无穷大。
2. 循环：从剩余节点中选择一个距离最小的节点，并将其加入最小生成树。每次选择时，需要更新其他节点的距离。
3. 重复步骤2，直到最小生成树包含所有节点。

**算法实现**：

```python
import heapq

def prim(graph, start):
    mst = {start}
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        
        if current_node in mst:
            continue

        mst.add(current_node)
        for neighbor, weight in graph[current_node].items():
            if neighbor not in mst and distance[neighbor] > weight:
                distances[neighbor] = weight
                heapq.heappush(priority_queue, (weight, neighbor))

    return mst
```

#### 克鲁斯卡尔算法（Kruskal's Algorithm）

克鲁斯卡尔算法也是一种以贪心策略为基础的构造最小生成树的算法。它与普里姆算法不同，不是从某个起始节点开始，而是从所有边开始，按照边的权重顺序选择。

**算法原理**：

1. 初始化：将所有边按权重排序，创建一个并查集（Union-Find）来管理节点。
2. 循环：依次选择权重最小的边，如果这条边不会形成环，则将其加入最小生成树。
3. 重复步骤2，直到最小生成树包含所有节点。

**算法实现**：

```python
def find(parent, i):
    if parent[i] == i:
        return i
    return find(parent, parent[i])

def union(parent, rank, x, y):
    xroot = find(parent, x)
    yroot = find(parent, y)

    if rank[xroot] < rank[yroot]:
        parent[xroot] = yroot
    elif rank[xroot] > rank[yroot]:
        parent[yroot] = xroot
    else:
        parent[yroot] = xroot
        rank[xroot] += 1

def kruskal(graph):
    result = []
    parent = {}
    rank = {}

    for node in graph:
        parent[node] = node
        rank[node] = 0

    edges = sorted(graph.items(), key=lambda item: item[1])

    for edge in edges:
        u, v, w = edge
        if find(parent, u) != find(parent, v):
            result.append(edge)
            union(parent, rank, u, v)

    return result
```

最近公共祖先算法主要用于计算树结构中两个节点的最近公共祖先。在计算最小生成树时，最近公共祖先算法可以帮助我们快速找到需要合并的两个连通分量。

### 最大流最小割算法

最大流最小割算法是图论中用于解决网络流问题的核心算法，广泛应用于通信网络、运输网络、经济分配等领域。这些算法不仅可以帮助我们优化资源分配，提高网络性能，还能在理论研究中揭示网络的流容量和结构特性。本节将详细讲解三种经典的最大流最小割算法：Ford-Fulkerson算法、Edmonds-Karp算法和Push-Relabel算法。

#### Ford-Fulkerson算法

Ford-Fulkerson算法是最早提出的网络流算法之一，其基本思想是通过寻找增广路径来逐步增加网络中的流量。该算法没有固定的算法时间复杂度，但其平均时间复杂度在实际应用中相对较高。

**算法原理**：

1. 初始化：设总流量为0。
2. 循环：找到一条增广路径，沿该路径增加流量，直到无法再增加。
3. 重复步骤2，直到找不到增广路径。

**算法实现**：

```python
def ford_fulkerson(graph, source, sink):
    flow = {edge: 0 for edge in graph}
    path = find_augmenting_path(graph, source, sink)
    
    while path:
        bottleneck = min(graph[u][v] - flow[(u, v)] for u, v in path)
        for u, v in path:
            flow[(u, v)] += bottleneck
            flow[(v, u)] -= bottleneck
        path = find_augmenting_path(graph, source, sink)

    return sum(flow[edge] for edge in flow if edge[0] != sink)
```

#### Edmonds-Karp算法

Edmonds-Karp算法是Ford-Fulkerson算法的一个改进版本，通过使用广度优先搜索（BFS）来寻找增广路径，从而提高了算法的效率。

**算法原理**：

1. 初始化：设总流量为0。
2. 循环：使用BFS寻找一条增广路径，沿该路径增加流量，直到无法再增加。
3. 重复步骤2，直到找不到增广路径。

**算法实现**：

```python
from collections import deque

def bfs(graph, source, sink, parent):
    visited = [False] * len(graph)
    queue = deque([source])
    visited[source] = True

    while queue:
        u = queue.popleft()
        for v, capacity in graph[u].items():
            if not visited[v] and flow[u][v] < capacity:
                queue.append(v)
                visited[v] = True
                parent[v] = u

    return visited[sink]

def edmonds_karp(graph, source, sink):
    flow = {edge: 0 for edge in graph}
    parent = [-1] * len(graph)
    while bfs(graph, source, sink, parent):
        path = []
        v = sink
        while v != source:
            u = parent[v]
            path.append((u, v))
            v = u
        path.reverse()

        for u, v in path:
            flow[(u, v)] += 1
            flow[(v, u)] -= 1

    return sum(flow[edge] for edge in flow if edge[0] != sink)
```

#### Push-Relabel算法

Push-Relabel算法是一种高效的最大流算法，其核心思想是通过推拉操作来优化流量的分配。该算法时间复杂度较低，适用于大规模网络流问题。

**算法原理**：

1. 初始化：设总流量为0。
2. 循环：执行推拉操作，直至达到最大流。
3. 推操作：将流量从满流量边推到相邻未满流量边。
4. 割操作：当某个节点达到高水位时，进行割操作，将节点划分到不同的集合。

```python
def push(graph, flow, source, sink):

def relabel(graph, flow, vertex):

    for u in graph[vertex]:
        if flow[(u, vertex)] > 0:
            find_augmenting_path(graph, vertex, u)

def push_relabel(graph, source, sink):

    while True:
        push(graph, flow, source, sink)
        if not any(flow[edge] > 0 for edge in flow if edge[0] != sink):
            break
        for vertex in graph:
            if flow[vertex] > 0:
                relabel(graph, flow, vertex)
```

### 网络路由算法

网络路由算法是网络通信中的关键部分，用于确定数据包从源节点到目标节点的传输路径。合理的路由算法能够提高网络性能、降低延迟、增强可靠性，并优化网络资源的使用。在本节中，我们将详细介绍两种常见的网络路由算法：距离向量路由算法（Distance Vector Routing Algorithm）和链路状态路由算法（Link State Routing Algorithm）。

#### 距离向量路由算法

距离向量路由算法是基于距离向量进行路由选择的一种算法，典型的实现包括RIP（Routing Information Protocol）和EIGRP（Enhanced Interior Gateway Routing Protocol）。该算法的基本原理是每个路由器维护一个距离向量，表示到各个节点的距离，并通过交换距离向量来更新路由表。

**算法原理**：

1. **初始化**：每个路由器初始化其距离向量，将所有未知节点的距离设为无穷大，并将自身距离设为0。
2. **距离向量交换**：路由器定期向相邻路由器发送自己的距离向量。
3. **距离更新**：接收到距离向量的路由器根据收到的信息更新自己的距离向量，选择最优路径。
4. **路由环路预防**：使用水平分割（Split Horizon）和毒性逆转（Toxic Reverse）等策略来防止路由环路。

**算法实现**：

```python
def distance_vector_routing(routers, router_id):
    # 初始化距离向量
    distance_vectors = {router: {neighbor: float('infinity') for neighbor in routers[router]} for router in routers}
    distance_vectors[router_id][router_id] = 0

    while True:
        updated = False
        for router in routers:
            if router == router_id:
                continue
            for neighbor in routers[router]:
                if neighbor == router_id:
                    continue
                new_distance = distance_vectors[router_id][router] + routers[router][neighbor]
                if new_distance < distance_vectors[router][neighbor]:
                    distance_vectors[router][neighbor] = new_distance
                    updated = True

        if not updated:
            break

    return distance_vectors[router_id]
```

#### 链路状态路由算法

链路状态路由算法是基于每个路由器维护一个完整的网络拓扑图来进行路由选择的算法，典型的实现包括OSPF（Open Shortest Path First）。与距离向量路由算法不同，链路状态路由算法通过洪泛（Flooding）机制广播链路状态信息，每个路由器根据这些信息计算最优路径。

**算法原理**：

1. **初始化**：每个路由器发送自己的链路状态信息到所有其他路由器。
2. **链路状态广播**：路由器将接收到的链路状态信息广播到网络中的所有其他路由器。
3. **链路状态数据库**：每个路由器构建一个链路状态数据库，包含所有其他路由器的链路状态信息。
4. **路由计算**：使用Dijkstra算法计算到各个节点的最短路径，并更新路由表。

**算法实现**：

```python
def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        
        if current_distance > distances[current_node]:
            continue

        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances

def link_state_routing(graph, router_id):
    # 初始化链路状态数据库
    link_state_database = {router: {neighbor: float('infinity') for neighbor in graph[router]} for router in graph}

    # 洪泛链路状态信息
    for router in graph:
        if router == router_id:
            continue
        link_state_database[router][router_id] = 1

    for _ in range(len(graph) - 1):
        for router in graph:
            if router == router_id:
                continue
            for neighbor in graph[router]:
                if neighbor == router_id:
                    continue
                distance = link_state_database[router][neighbor]
                if distance < float('infinity'):
                    link_state_database[router_id][neighbor] = distance

    # 计算路由表
    routing_table = {}
    for router in graph:
        distances = dijkstra(link_state_database, router)
        routing_table[router] = {neighbor: distance for neighbor, distance in distances.items() if neighbor != router}

    return routing_table
```

### 社交网络分析

社交网络分析是图论在网络科学中的一个重要应用，通过分析社交网络的拓扑结构和节点之间的关系，可以揭示社交网络的动态行为、社区结构、影响力传播等现象。在本节中，我们将详细介绍两种常用的社交网络分析算法：社区发现算法和影响力传播算法。

#### 社区发现算法

社区发现算法旨在识别社交网络中的紧密连接的子图，这些子图通常代表具有共同兴趣或关系的用户群体。常见的社区发现算法包括基于模块度优化（Modularity Optimization）的算法、基于标签相似度（Label Propagation）的算法等。

**基于模块度优化的社区发现算法**

模块度是衡量社区内部连接强度和社区之间连接强度的差别的指标。基于模块度优化的社区发现算法通过调整节点之间的边，使社区内的连接更紧密，社区之间的连接更弱。

**算法原理**：

1. **初始化**：随机分配每个节点到一个社区。
2. **迭代**：在每次迭代中，计算每个节点与其邻居节点的模块度，如果交换节点所在的社区可以增加模块度，则进行交换。
3. **收敛**：重复迭代，直至模块度不再显著增加。

**算法实现**：

```python
def modularity/community_detection(graph, num_communities):
    # 初始化社区分配
    communities = {node: i for i, node in enumerate(graph)}
    community_size = {i: [] for i in range(num_communities)}

    for node in graph:
        community_size[communities[node]].append(node)

    while True:
        modularity = calculate_modularity(graph, communities)
        new_communities = {}

        for node in graph:
            best_community = None
            best_modularity = -modularity

            for community in range(num_communities):
                if node in community_size[community]:
                    continue

                new_communities[node] = community
                new_modularity = calculate_new_modularity(graph, node, community, communities)
                if new_modularity > best_modularity:
                    best_modularity = new_modularity
                    best_community = community

            if best_community is not None:
                communities[node] = best_community

        if best_community is None:
            break

    return communities
```

#### 影响力传播算法

影响力传播算法用于分析在社交网络中信息或行为的扩散过程。这些算法可以识别具有高度影响力的人物或节点，了解信息的传播路径和传播速度。

**基于传播概率的影响力传播算法**

基于传播概率的影响力传播算法通过计算每个节点的传播概率，来确定影响力最大的节点。传播概率通常与节点的度数、邻居节点的传播概率等因素相关。

**算法原理**：

1. **初始化**：为每个节点设置一个初始传播概率，通常与节点的度数成反比。
2. **迭代**：在每次迭代中，更新每个节点的传播概率，使其向邻居节点传播信息。
3. **终止**：当传播概率低于某个阈值或传播达到稳定状态时，算法终止。

**算法实现**：

```python
def influence_spread(graph, initial_influence, propagation_prob):
    influence_prob = {node: initial_influence for node in graph}
    infected_nodes = set()

    while True:
        new_infected = set()
        for node in graph:
            if influence_prob[node] > random.random():
                new_infected.add(node)
                for neighbor in graph[node]:
                    influence_prob[neighbor] += propagation_prob

        if not new_infected:

        infected_nodes.update(new_infected)
```
