#### RSA加密算法

- **公钥**：\( (n, e) \)
- **私钥**：\( (n, d) \)
- **加密**：\( c = m^e \mod n \)

选择 \( e = 17 \)，则 \( d = 17^{-1} \mod 3120 = 2333 \)。

- **加密**：假设明文 \( m = 1234 \)，则加密后的密文 \( c = 1234^{17} \mod 3233 \)。
- **解密**：解密后的明文 \( m = 1234^{2333} \mod 3233 \)。

### 数字签名的原理

数字签名是一种确保数据完整性和真实性的技术。它利用密码学算法，生成一个与原始数据相关的唯一签名，只有拥有正确私钥的人才能生成和验证这个签名。

#### 基本原理

1. **私钥和公钥的生成**：
   数字签名首先需要一对密钥：私钥和公钥。私钥是保密的，只有签名者知道；公钥是公开的，可以随意分发。

2. **签名过程**：
   签名者使用私钥和哈希函数对数据进行签名。哈希函数将数据转换为一个固定长度的哈希值，私钥与哈希值进行加密，生成签名。

3. **验证过程**：
   验证者使用公钥和哈希函数对签名进行验证。如果验证成功，说明数据未被篡改且来自合法签名者。

#### 数学模型

假设我们使用RSA加密算法，其数学模型如下：

1. **密钥生成**：
   选择两个大素数 \( p \) 和 \( q \)，计算 \( n = p \times q \) 和 \( \phi(n) = (p-1)(q-1) \)。
   选择一个与 \( \phi(n) \) 互质的整数 \( e \)，计算 \( d \)，满足 \( d \times e \mod \phi(n) = 1 \)。
   公钥为 \( (n, e) \)，私钥为 \( (n, d) \)。

2. **签名过程**：
   对数据进行哈希，得到哈希值 \( H \)。
   计算签名 \( S = H^d \mod n \)。

3. **验证过程**：
   对签名和解密 \( S^e \mod n \) 进行哈希，得到 \( H' \)。
   比较哈希值 \( H \) 和 \( H' \)。如果相等，签名有效。

### 举例说明

假设我们选择两个素数 \( p = 61 \) 和 \( q = 53 \)，则 \( n = p \times q = 3233 \)，\( \phi(n) = (p-1)(q-1) = 3120 \)。

选择 \( e = 17 \)，则 \( d = 17^{-1} \mod 3120 = 2333 \)。

- **加密**：假设明文 \( m = 1234 \)，则加密后的密文 \( c = 1234^{17} \mod 3233 \)。
- **解密**：解密后的明文 \( m = 1234^{2333} \mod 3233 \)。

通过这种加密和解密过程，我们可以确保数据在传输过程中的完整性和真实性。

### Python代码实现

以下是一个简单的Python代码实现，用于生成和验证数字签名。

```python
import random
import hashlib

# RSA加密算法实现
def generate_keys(p, q):
    n = p * q
    phi = (p - 1) * (q - 1)
    e = random.randrange(2, phi)
    d = pow(e, -1, phi)
    return (n, e), (n, d)

def sign_message(message, private_key):
    n, d = private_key
    hashed_message = int(hashlib.sha256(message.encode()).hexdigest(), 16)
    signature = pow(hashed_message, d, n)
    return signature

def verify_signature(message, signature, public_key):
    n, e = public_key
    hashed_message = int(hashlib.sha256(message.encode()).hexdigest(), 16)
    verified_signature = pow(signature, e, n)
    return hashed_message == verified_signature

# 生成密钥
p = 61
q = 53
public_key, private_key = generate_keys(p, q)

# 生成签名
message = "Hello, World!"
signature = sign_message(message, private_key)

# 验证签名
is_valid = verify_signature(message, signature, public_key)
print(f"Message: {message}")
print(f"Signature: {signature}")
print(f"Is valid: {is_valid}")
```

```solidity
pragma solidity ^0.8.0;

contract DigitalNotary {
    struct Document {
        string id;
        string content;
        address creator;
        mapping(address => bool) signatures;
    }

    mapping(string => Document) public documents;

    function createDocument(string memory id, string memory content) public {
        require(documents[id].id == "", "Document already exists");
        documents[id] = Document(id, content, msg.sender, new mapping(address => bool));
    }

    function signDocument(string memory id) public {
        require(documents[id].id != "", "Document does not exist");
        require(!documents[id].signatures[msg.sender], "User has already signed");
        documents[id].signatures[msg.sender] = true;
    }

    function verifyDocument(string memory id) public view returns (bool) {
        require(documents[id].id != "", "Document does not exist");
        uint count = 0;
        for (uint i = 0; i < 100; i++) {
            if (documents[id].signatures[addresses[i]]) {
                count++;
            }
        }
        return count >= 2;
    }
}
```
