**特征提取示例**：

- 兴趣爱好（如阅读、运动、音乐等）

我们可以通过以下步骤进行特征提取：

3. **特征构造**：计算兴趣相似度，通过比较用户之间的兴趣爱好，得到一个兴趣相似度矩阵。

以下是一个简单的特征提取示例：

```python
# 示例：特征提取代码
import numpy as np
import pandas as pd

# 假设data是包含用户特征的DataFrame
data = pd.DataFrame({
    'age': [20, 30, 40],
    'interests': [['reading', 'sports'], ['music', 'travel'], ['reading', 'art']],
    'activity': [10, 5, 20]
})

# 年龄归一化
data['age_normalized'] = data['age'] / data['age'].max()

# 独热编码兴趣爱好
interests_encoded = pd.get_dummies(data['interests'])

# 计算兴趣相似度
def calculate_similarity(Interest1, Interest2):
    similarity = 0
    if Interest1 == Interest2:
        similarity = 1
    return similarity

interest_similarity_matrix = pd.DataFrame(np.zeros((len(data), len(data))))
for i in range(len(data)):
    for j in range(i, len(data)):
        interest_similarity = calculate_similarity(data['interests'][i], data['interests'][j])
        interest_similarity_matrix.at[i, j] = interest_similarity
        interest_similarity_matrix.at[j, i] = interest_similarity

# 合并特征
data_with_features = pd.concat([data, interests_encoded, interest_similarity_matrix], axis=1)
```

通过以上步骤，我们提取出用户的关键特征，为后续的匹配策略提供了基础。

**基于距离的匹配**：

1. **欧几里得距离**：计算用户特征向量之间的欧几里得距离，距离越小表示越相似。
2. **余弦相似度**：计算用户特征向量之间的余弦相似度，相似度越大表示越相似。

**基于相似度的匹配**：

1. **兴趣相似度匹配**：根据用户的兴趣爱好相似度进行匹配，相似度越高表示可能越容易建立友谊。
2. **社交活跃度匹配**：根据用户的社交活跃度进行匹配，活跃度越高表示更愿意参与社交活动。

**综合匹配策略**：

1. **加权综合匹配**：结合距离相似度和兴趣相似度，对用户进行加权综合匹配，以实现更精准的推荐。
2. **多特征匹配**：考虑多个特征（如年龄、兴趣爱好、社交活跃度等），进行多维度匹配。

    total_similarity = age_similarity * 0.5 + interest_similarity * 0.3 + activity_similarity * 0.2
    return total_similarity

for i in range(len(data_with_features)):
    user1 = data_with_features.iloc[i]
    for j in range(i + 1, len(data_with_features)):
        user2 = data_with_features.iloc[j]
        score = matching_strategy(user1, user2)
        matching_scores = matching_scores.append({'user1_id': user1['user_id'], 'user2_id': user2['user_id'], 'score': score}, ignore_index=True)

# 根据匹配分数进行排序
matching_scores_sorted = matching_scores.sort_values(by='score', ascending=False)
