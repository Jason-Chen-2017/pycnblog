### 3. 算法原理讲解

供应链管理的核心在于优化，而优化通常涉及到数学模型和算法的应用。以下是几种常见的供应链优化算法及其原理：

#### 3.1 线性规划算法

线性规划是一种数学优化方法，用于在给定约束条件下求解线性目标函数的最大值或最小值。以下是线性规划的一个简单例子：

$$
\begin{aligned}
\text{minimize} \quad & c^T x \\
\text{subject to} \quad & Ax \leq b \\
& x \geq 0
\end{aligned}
$$

其中，$c$ 是系数向量，$x$ 是决策变量，$A$ 是约束条件矩阵，$b$ 是约束条件向量。

下面是一个使用Python的`scipy.optimize`模块解决线性规划问题的示例代码：

```python
from scipy.optimize import linprog

# 系数向量
c = [-1, -1]
# 约束条件矩阵
A = [[2, 1], [1, 1]]
# 约束条件向量
b = [4, 2]
# 求解线性规划问题
result = linprog(c, A_ub=A, b_ub=b, method='highs')

print(result.x)
```

输出结果将是线性规划问题的最优解。

#### 3.2 整数规划算法

整数规划是一种特殊的线性规划，其中决策变量被限制为整数。以下是一个整数规划的问题示例：

$$
\begin{aligned}
\text{minimize} \quad & c^T x \\
\text{subject to} \quad & Ax \leq b \\
& x \in \{0, 1\}^n
\end{aligned}
$$

下面是一个使用Python的`scipy.optimize`模块解决整数规划问题的示例代码：

```python
from scipy.optimize import linprog

# 系数向量
c = [-1, -1]
# 约束条件矩阵
A = [[2, 1], [1, 1]]
# 约束条件向量
b = [4, 2]
# 求解整数规划问题
result = linprog(c, A_ub=A, b_ub=b, method='highs', integer=True)

print(result.x)
```

输出结果将是整数规划问题的最优解。

#### 3.3 启发式算法

启发式算法是一类不保证全局最优但能快速找到近似最优解的算法。以下是遗传算法的一个简单示例：

```python
import numpy as np

# 初始化种群
population = np.random.randint(2, size=100)

# 定义适应度函数
def fitness(x):
    return np.sum(x)

# 定义交叉操作
def crossover(parent1, parent2):
    crossover_point = np.random.randint(0, len(parent1))
    child1 = np.concatenate((parent1[:crossover_point], parent2[crossover_point:]))
    child2 = np.concatenate((parent2[:crossover_point], parent1[crossover_point:]))
    return child1, child2

# 定义变异操作
def mutate(individual, mutation_rate=0.01):
    for i in range(len(individual)):
        if np.random.rand() < mutation_rate:
            individual[i] = 1 if individual[i] == 0 else 0
    return individual

# 进化循环
for generation in range(100):
    # 计算适应度
    fitness_scores = np.array([fitness(individual) for individual in population])
    # 选择
    selected = population[fitness_scores.argsort()[:-20:-1]]
    # 交叉和变异
    for i in range(0, len(selected), 2):
        parent1, parent2 = selected[i], selected[i+1]
        child1, child2 = crossover(parent1, parent2)
        population[i] = mutate(child1)
        population[i+1] = mutate(child2)

# 输出最优解
best_fitness = np.max(fitness_scores)
best_individual = population[fitness_scores.argmax()]
print("最优解：", best_individual)
print("最优适应度：", best_fitness)
```

这个示例演示了遗传算法的基本流程，包括初始化种群、计算适应度、选择、交叉和变异。

@RestController
@RequestMapping("/api/purchase")
public class PurchaseController {

    @Autowired
    private PurchaseService purchaseService;

    @PostMapping
    public ResponseEntity<PurchaseOrder> createPurchaseOrder(@RequestBody PurchaseOrderRequest request) {
        PurchaseOrder purchaseOrder = purchaseService.createPurchaseOrder(request);
        return new ResponseEntity<>(purchaseOrder, HttpStatus.CREATED);
    }

    @GetMapping("/{orderId}")
    public ResponseEntity<PurchaseOrder> getPurchaseOrder(@PathVariable Long orderId) {
        PurchaseOrder purchaseOrder = purchaseService.getPurchaseOrder(orderId);
        return new ResponseEntity<>(purchaseOrder, HttpStatus.OK);
    }
}

// 采购服务模块
@Service
public class PurchaseService {

    @Autowired
    private PurchaseRepository purchaseRepository;

    public PurchaseOrder createPurchaseOrder(PurchaseOrderRequest request) {
        PurchaseOrder purchaseOrder = new PurchaseOrder();
        purchaseOrder.setOrderId(request.getOrderId());
        purchaseOrder.setOrderDate(new Date());
        purchaseOrder.setStatus(PurchaseOrderStatus.PENDING);
        return purchaseRepository.save(purchaseOrder);
    }

    public PurchaseOrder getPurchaseOrder(Long orderId) {
        return purchaseRepository.findById(orderId).orElseThrow(() -> new ResourceNotFoundException("采购订单不存在"));
    }
}
