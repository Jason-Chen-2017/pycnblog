##### 2.1 集合的定义与性质

集合是一个基本概念，它由一组无序的对象组成。在数学和计算机科学中，集合用于描述和分析对象之间的关系。集合的元素可以是任何类型的对象，包括数字、字符、字符串和其他集合。

集合的定义可以用描述法或列举法表示。描述法通过一组性质来定义集合的元素，例如，集合A可以定义为所有偶数的集合，记作A = {x | x 是偶数}。列举法则直接列出集合的所有元素，例如，集合B = {1, 2, 3, 4}。

集合的基本性质包括：

1. **确定性**：集合中的每个元素都是明确的，没有重复的元素。
2. **互异性**：集合中的元素是不同的，没有重复的元素。
3. **无序性**：集合中的元素没有特定的顺序。

##### 2.2 集合的基本运算

集合的基本运算包括并集、交集、差集和子集等。

1. **并集（Union）**：两个集合A和B的并集是一个包含A和B中所有元素的集合，记作A ∪ B。例如，集合A = {1, 2, 3}和集合B = {4, 5, 6}的并集为A ∪ B = {1, 2, 3, 4, 5, 6}。

2. **交集（Intersection）**：两个集合A和B的交集是一个包含A和B中共同元素的集合，记作A ∩ B。例如，集合A = {1, 2, 3}和集合B = {4, 5, 6}的交集为A ∩ B = {}（空集）。

3. **差集（Difference）**：两个集合A和B的差集是一个包含A中有而B中没有的元素的集合，记作A - B。例如，集合A = {1, 2, 3}和集合B = {4, 5, 6}的差集为A - B = {1, 2, 3}。

4. **子集（Subset）**：集合A是集合B的子集，如果A中的所有元素都是B中的元素，记作A ⊆ B。例如，集合A = {1, 2}是集合B = {1, 2, 3}的子集。

##### 2.3 集合论中的公理系统

集合论中的公理系统是一组基本假设或原则，用于推导出所有集合的性质。最著名的公理系统是Zermelo-Fraenkel集合论（ZFC），它由德国数学家恩斯特·策梅洛和哈恩·弗雷格提出。

ZFC包含以下基本公理：

1. **空集公理**：存在一个空集∅，它不包含任何元素。
2. **分离公理**：对于任何集合A和属性φ，存在一个包含A中满足φ的元素的集合。
3. **选择公理**：对于任何集合A的幂集的任意子集的集合，存在一个选择函数，该函数为A的每个非空子集选择一个元素。
4. **幂集公理**：对于任何集合A，存在一个包含A的所有子集的集合，称为A的幂集。
5. **无穷公理**：存在一个无限集合。

这些公理为集合论提供了坚实的基础，使得我们可以通过逻辑推理来研究集合的性质和关系。
