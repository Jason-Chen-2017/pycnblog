## 引言与背景

### 微型音乐节的概念

微型音乐节是指在相对较小的场地举办的音乐活动，通常以社区、街道或公园为举办地点。这种音乐节形式灵活，参与门槛低，能够更好地融入社区生活，满足居民的娱乐和文化需求。

### 众筹的兴起

众筹，即通过互联网平台向社会公众筹集资金，已成为一种新兴的融资方式。众筹不仅为项目提供了资金支持，还能够扩大项目的影响力，吸引更多参与者和支持者。

### 参与式筹办的意义

参与式筹办是指社区居民主动参与到音乐节的组织和筹办过程中，从策划、筹备到执行，各个环节都由社区居民共同参与。这种模式不仅能够提高社区居民的参与度和满意度，还能够增强社区的凝聚力和归属感。

### 众筹的起源与演变

众筹起源于2009年的Kickstarter平台，随后其他众筹平台如Indiegogo、GoFundMe等相继涌现。这些平台为各种创意项目提供了展示和筹集资金的渠道。

### 众筹平台在艺术文化领域的应用

众筹平台在艺术文化领域的应用十分广泛，不仅包括音乐项目，还涵盖了电影、艺术展览、书籍等多种形式。微型音乐节作为一个新兴的艺术形式，也得到了众筹平台的青睐。

1. **众筹成功概率**：设P(Success)为众筹成功概率，P(Fail)为众筹失败概率，则有P(Success) + P(Fail) = 1。

def simulate_crowdfunding_trials(success_probability, trials=10):
    """
    模拟众筹尝试过程，直到成功或达到尝试次数。

    :param success_probability: 众筹成功的概率
    :param trials: 尝试次数
    :return: True if 成功，False if 失败
    """
    for i in range(1, trials + 1):
        print(f"尝试众筹第 {i} 次")
        if random.random() < success_probability:
            print("众筹成功！")
            return True
        else:
            print("众筹失败，继续尝试...")
    
    print("众筹失败，尝试次数用尽。")
    return False

```python
# app.py
from flask import Flask, render_template, request, redirect, url_for
from flask_sqlalchemy import SQLAlchemy
from flask_login import LoginManager, login_user, logout_user, login_required, current_user
from models import User, Project, Crowdfunding, Finance
from forms import LoginForm, ProjectForm, CrowdfundingForm, FinanceForm

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///database.db'
app.config['SECRET_KEY'] = 'your_secret_key'

db = SQLAlchemy(app)
login_manager = LoginManager(app)
login_manager.login_view = 'login'

@login_manager.user_loader
def load_user(user_id):
    return User.query.get(int(user_id))

@app.route('/')
@login_required
def home():
    projects = Project.query.all()
    return render_template('home.html', projects=projects)

@app.route('/login', methods=['GET', 'POST'])
def login():
    form = LoginForm()
    if form.validate_on_submit():
        user = User.query.filter_by(username=form.username.data).first()
        if user and user.password == form.password.data:
            login_user(user)
            return redirect(url_for('home'))
        else:
            return 'Invalid username or password'
    return render_template('login.html', form=form)

@app.route('/logout')
@login_required
def logout():
    logout_user()
    return redirect(url_for('login'))

@app.route('/project/new', methods=['GET', 'POST'])
@login_required
def new_project():
    form = ProjectForm()
    if form.validate_on_submit():
        project = Project(name=form.name.data, description=form.description.data, user_id=current_user.id)
        db.session.add(project)
        db.session.commit()
        return redirect(url_for('home'))
    return render_template('new_project.html', form=form)

@app.route('/project/<int:project_id>')
@login_required
def project(project_id):
    project = Project.query.get_or_404(project_id)
    return render_template('project.html', project=project)

@app.route('/crowdfunding/new', methods=['GET', 'POST'])
@login_required
def new_crowdfunding():
    form = CrowdfundingForm()
    if form.validate_on_submit():
        crowdfunding = Crowdfunding(project_id=form.project_id.data, target_amount=form.target_amount.data, end_date=form.end_date.data)
        db.session.add(crowdfunding)
        db.session.commit()
        return redirect(url_for('home'))
    return render_template('new_crowdfunding.html', form=form)

@app.route('/finance', methods=['GET', 'POST'])
@login_required
def finance():
    form = FinanceForm()
    if form.validate_on_submit():
        finance = Finance(crowdfunding_id=form.crowdfunding_id.data, amount=form.amount.data, date=form.date.data)
        db.session.add(finance)
        db.session.commit()
        return redirect(url_for('finance'))
    return render_template('finance.html', form=form)

if __name__ == '__main__':
    app.run(debug=True)
```
