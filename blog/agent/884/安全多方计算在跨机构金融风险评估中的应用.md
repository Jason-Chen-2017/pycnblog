# 第二部分：安全多方计算原理

### 第2章：安全多方计算的基本原理

### 2.1 概念与基本原理

#### 2.1.1 安全多方计算的基本概念

安全多方计算（Secure Multi-Party Computation，SMPC）是一种分布式计算技术，允许两个或多个参与方在不泄露各自敏感数据的情况下，通过分布式计算方式共同完成某一计算任务。在SMPC中，每个参与方仅需要公开自己的部分输入数据，而不需要公开全部数据，从而确保了数据的隐私性。

#### 2.1.2 基本原理与目标

安全多方计算的基本原理是通过密码学技术，将参与方的输入数据加密，并在加密状态下进行计算。计算结果同样以加密形式返回，只有所有参与方共同解密后才能得到最终结果。SMPC的目标是在保持数据隐私性的同时，实现高效、准确的数据计算。

#### 2.1.3 安全多方计算的核心技术

安全多方计算的核心技术包括：

- **同态加密**：同态加密允许在加密状态下对数据进行计算，从而在数据传输和存储过程中保持隐私性。
- **秘密共享**：秘密共享是将一个秘密数据分成多个份额，每个份额只有与其他份额结合时才能恢复原始秘密数据。
- **安全通信**：安全通信确保参与方在数据传输过程中不受中间人攻击、重放攻击等威胁。
- **多方计算协议**：多方计算协议是确保参与方在分布式计算过程中，按照既定规则进行计算，从而实现计算任务的目标。

#### 2.2.3 协议设计与实现

安全多方计算协议的设计与实现需要考虑以下因素：

- **安全性**：确保参与方在计算过程中数据不会被泄露，协议需要具备抗攻击性。

- **兼容性**：协议需要兼容现有的计算环境和数据格式。
