```python
# type_check.py

def type_check(a, b):
    if isinstance(a, (int, float)) and isinstance(b, (int, float)):
        return a + b
    else:
        raise TypeError("Operands must be numeric types")
```

**运算执行模块（operation_executor.py）：**

```python
# operation_executor.py

from type_check import type_check

def add(a, b):
    type_check(a, b)
    return a + b

def subtract(a, b):
    type_check(a, b)
    return a - b

def multiply(a, b):
    type_check(a, b)
    return a * b

def divide(a, b):
    type_check(a, b)
    return a / b
```

**结果验证模块（result_validator.py）：**

```python
# result_validator.py

def validate_result(result):
    if isinstance(result, (int, float)):
        return True
    else:
        return False
```
