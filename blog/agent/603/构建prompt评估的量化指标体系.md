## 2. 量化指标体系的核心概念

### 2.1 指标类型

量化指标体系包括以下几种类型：

1. **基础指标**：用于评估prompt对模型基本性能的影响，如准确率、召回率等。
2. **扩展指标**：在基础指标的基础上，考虑更多因素的影响，如F1值、精确率等。
3. **综合指标**：综合考虑多个方面的因素，如用户满意度、模型效率等。

### 2.2 指标计算方法

不同类型的指标有不同的计算方法，以下为几种常见的计算方法：

1. **准确率**：正确预测的样本数占总样本数的比例。
   $$\text{准确率} = \frac{\text{正确预测的样本数}}{\text{总样本数}}$$
2. **召回率**：正确预测的样本数占所有实际正例样本数的比例。
   $$\text{召回率} = \frac{\text{正确预测的样本数}}{\text{实际正例样本数}}$$
3. **F1值**：综合考虑准确率和召回率的指标。
   $$\text{F1值} = 2 \times \frac{\text{准确率} \times \text{召回率}}{\text{准确率} + \text{召回率}}$$
4. **用户满意度**：用户对模型推荐的满意度评分，通常采用5分制或10分制。

### 2.3 指标权重

在量化指标体系中，不同指标对评估结果的影响程度不同，因此需要为每个指标分配权重。权重分配的方法包括以下几种：

1. **专家评分法**：由专家根据指标的重要性进行评分，将评分转换为权重。
2. **统计方法**：通过历史数据，分析每个指标与评估结果的相关性，将相关性强的指标赋予更高的权重。
3. **机器学习方法**：使用机器学习算法，通过训练数据学习每个指标对评估结果的影响程度，自动分配权重。
