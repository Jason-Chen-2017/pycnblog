## 第3章：纯函数式编程核心概念

### 纯函数式编程的基本原则

纯函数式编程是一种编程范式，它强调函数是一等公民，即函数可以作为参数传递，也可以作为返回值。纯函数式编程的基本原则包括以下几点：

1. **纯函数**：纯函数是一种没有副作用的函数，即它不会改变外部状态，也不会产生任何可观测的副作用。纯函数的输出仅依赖于其输入参数。

2. **不可变性**：在纯函数式编程中，变量通常是不可变的。一旦变量被赋值，其值就不能再改变。这种不可变性使得代码更加简洁、易于推理和测试。

3. **高阶函数**：高阶函数是一种可以接受其他函数作为参数，或者返回函数的函数。高阶函数是纯函数式编程的核心概念之一，它使得函数可以以更灵活的方式组合和复用。

4. **递归**：递归是一种编程技巧，它允许函数调用自身。在纯函数式编程中，递归是一种重要的编程模式，它用于解决许多复杂的问题。

### 纯函数式编程的优势

纯函数式编程具有以下优势：

1. **可测试性**：由于纯函数没有副作用，测试纯函数变得非常容易。每个函数都可以独立测试，无需担心外部状态的干扰。

2. **可维护性**：纯函数式编程使得代码更加模块化，每个函数都有明确的职责。这使得代码更易于维护和扩展。

3. **可组合性**：纯函数式编程允许函数以更灵活的方式组合和复用。通过高阶函数和组合函数，我们可以创建复杂的逻辑而无需重复代码。

4. **可扩展性**：纯函数式编程使得代码更加模块化，从而更容易扩展。新功能可以通过添加新的函数和模块来实现，而无需修改现有代码。

5. **并行化**：由于纯函数没有副作用，代码可以更轻松地并行化。这在多核处理器上运行时可以显著提高性能。

### 纯函数式编程与语言自足性的关系

纯函数式编程与语言自足性密切相关。语言自足性指的是编程语言能够提供足够的工具和特性，使得开发者可以独立地定义和操作数据结构和算法，而无需依赖于外部库或工具。

1. **数据结构自足性**：纯函数式编程依赖于编程语言能够提供丰富的数据结构支持，如列表、树、图等。这些数据结构使得纯函数式编程可以高效地处理复杂数据。

2. **算法自足性**：纯函数式编程依赖于编程语言能够提供强大的算法库，使得开发者可以方便地实现各种复杂算法。

3. **环境自足性**：纯函数式编程依赖于编程语言能够自我管理环境，包括内存分配、垃圾回收等。这使得纯函数式编程可以更加专注于逻辑实现，而不需要担心资源管理等问题。

### 纯函数式编程的实现

实现纯函数式编程需要编程语言提供以下支持：

1. **强类型系统**：强类型系统可以确保变量在定义时就被类型化，从而减少类型错误和运行时错误。

2. **不可变的集合**：编程语言需要提供不可变的集合类型，如列表、树等，以便开发者可以创建和操作不可变数据。

3. **高阶函数和递归**：编程语言需要支持高阶函数和递归，以便开发者可以编写纯函数式的逻辑。

4. **函数组合**：编程语言需要支持函数组合，使得开发者可以以更灵活的方式组合和复用函数。

5. **内存管理**：编程语言需要提供内存管理机制，如垃圾回收，以便开发者可以专注于逻辑实现，而不需要担心内存分配和回收等问题。

### 总结

纯函数式编程是一种强大的编程范式，它强调函数是一等公民，代码应尽量避免副作用和共享状态。纯函数式编程与语言自足性密切相关，通过提供丰富的数据结构、算法和环境支持，编程语言可以更好地实现纯函数式编程。理解纯函数式编程的基本原则和优势，可以帮助开发者编写更简洁、高效和可维护的代码。

from flask import Flask, request, jsonify

# 初始购物车状态
shopping_cart = {
    "product1": {"quantity": 0, "price": 19.99},
    "product2": {"quantity": 0, "price": 29.99},
    "product3": {"quantity": 0, "price": 39.99}
}

# 添加商品到购物车
def add_product(product_name: str, quantity: int, price: float) -> dict:
    new_product = {product_name: {"quantity": quantity, "price": price}}
    return {**shopping_cart, **new_product}

# 从购物车中删除商品
def remove_product(product_name: str) -> dict:
    return {k: v for k, v in shopping_cart.items() if k != product_name}

# 更新商品数量
def update_quantity(product_name: str, new_quantity: int) -> dict:
    if product_name in shopping_cart:
        shopping_cart[product_name]["quantity"] = new_quantity
    return shopping_cart

# 计算购物车总价
def calculate_total() -> float:
    total = 0
    for product in shopping_cart.values():
        total += product["quantity"] * product["price"]
    return total

# Flask路由
@app.route('/add_product', methods=['POST'])
def add_product_endpoint():
    product_name = request.form['name']
    quantity = int(request.form['quantity'])
    price = float(request.form['price'])
    global shopping_cart
    shopping_cart = add_product(product_name, quantity, price)
    return jsonify({"message": "Product added successfully", "shopping_cart": shopping_cart})

@app.route('/remove_product', methods=['POST'])
def remove_product_endpoint():
    product_name = request.form['name']
    global shopping_cart
    shopping_cart = remove_product(product_name)
    return jsonify({"message": "Product removed successfully", "shopping_cart": shopping_cart})

@app.route('/update_quantity', methods=['POST'])
def update_quantity_endpoint():
    product_name = request.form['name']
    new_quantity = int(request.form['quantity'])
    global shopping_cart
    shopping_cart = update_quantity(product_name, new_quantity)
    return jsonify({"message": "Quantity updated successfully", "shopping_cart": shopping_cart})

@app.route('/calculate_total', methods=['GET'])
def calculate_total_endpoint():
    total = calculate_total()
    return jsonify({"total": total})

if __name__ == '__main__':
    app.run(debug=True)
