#### 2.2 广义相对论

广义相对论是爱因斯坦于1915年提出的一种描述引力和宇宙时空弯曲的理论。广义相对论的核心观点是，引力不是一种作用在物体之间的力，而是由物质和能量引起的时空弯曲。在广义相对论的框架下，物质和能量会影响周围的时空结构，而时空的弯曲又反过来影响物体的运动轨迹。广义相对论不仅成功地解释了行星运动的异常，还预测了黑洞、引力波等宇宙现象。

广义相对论的属性特征可以通过以下表格进行对比：

| 特征 | 说明 |
| --- | --- |
| 时空间变 | 广义相对论认为时空是动态的，它会随着物质和能量的分布发生变化。 |
| 引力弯曲 | 广义相对论认为引力是由物质和能量引起的时空弯曲，而不是一种传统的力。 |
| 默希乌斯性质 | 广义相对论具有默希乌斯性质，即物理定律在所有参考系中都是相同的，无论这些参考系是静止的还是运动的。 |
