##### 1.1.1 群的概念与起源

群是数学中的一个基本概念，指的是一组对象（元素）的集合，这些对象满足一定的运算规则。具体来说，一个群必须满足以下四个条件：

1. **闭合性**：对于群中的任意两个元素a和b，其运算结果c也必须在群中。
2. **结合律**：对于群中的任意三个元素a、b和c，它们的运算满足结合律，即(a * b) * c = a * (b * c)。
3. **单位元**：群中存在一个元素e，使得对于任意元素a，有a * e = e * a = a。
4. **逆元**：对于群中的任意元素a，存在一个元素b，使得a * b = b * a = e。

群的起源可以追溯到18世纪的数学家欧拉和拉格朗日。他们在解决数学问题时，发现了某些运算具有群的性质。到了19世纪，数学家伽罗瓦进一步发展了群的概念，并应用于代数方程的求解。
