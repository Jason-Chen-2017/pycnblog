### 第2章：基本数学概念

#### 2.1 数学基础知识

数学作为一门科学，其基础概念涵盖了从最简单的算术到复杂的代数、几何和数论。这些基础概念在天文数据分析中扮演着至关重要的角色，为处理和分析天文数据提供了必要的数学工具。

**算术基础**

算术是数学中最基本的部分，包括加法、减法、乘法和除法等基本运算。这些运算在天文数据分析中用于处理观测数据、计算物理量、进行单位转换等。

- **加法和减法**：用于合并或分离数据集，计算总数量或差异。
- **乘法和除法**：用于计算天文数据中的面积、体积、密度等物理量。

**代数基础**

代数是研究变量和方程的数学分支，它是天体物理学的基石。代数方程用于描述天体运动、恒星演化等物理过程。

- **一元一次方程**：用于求解单一变量的值，如行星轨道方程。
- **一元二次方程**：用于描述抛物线运动，如卫星轨道。
- **多元方程组**：用于处理多个变量之间的关系，如恒星系统的运动。

**函数与极限**

函数是数学中描述变量之间关系的工具，极限则是函数在某一点附近的行为描述。在天文数据分析中，函数和极限用于描述天体运动的轨迹和趋势。

- **函数**：描述天体的运动规律，如正弦函数描述行星的轨道。
- **极限**：用于求解天文数据中的不确定性和边界情况。

**几何基础**

几何学研究空间中点的分布、形状和大小。几何概念在天文数据分析中用于描述天体的位置、形状和运动。

- **点、线、面**：用于表示天体的基本几何形态。
- **平面和空间几何**：用于计算天体的位置和形状，如星系的结构。

**数论基础**

数论是研究整数性质和关系的数学分支。在天文数据分析中，数论用于分析天文数据中的周期性、分布特征等。

- **素数**：用于分析星系团中星系的分布规律。
- **模运算**：用于求解天文数据中的周期性问题。

**代数几何**

代数几何是将代数方法和几何方法相结合的数学分支。在天文数据分析中，代数几何用于研究天体之间的空间关系和运动规律。

- **曲线和曲面**：用于描述天体的运动轨迹。
- **代数群**：用于分析星系的动力学特性。

**拓扑学**

拓扑学研究空间的结构和性质，而不考虑其形状或大小。在天文数据分析中，拓扑学用于研究天体的空间分布和相互作用。

- **拓扑空间**：用于描述星系团的结构。
- **同胚**：用于分析星系之间的相似性。

#### 2.2 线性代数

线性代数是研究向量空间、线性变换和矩阵理论的数学分支。在天文数据分析中，线性代数用于处理大规模数据和复杂系统。

**矩阵与行列式**

矩阵是线性代数中的基本工具，用于表示数据集和变换。行列式是矩阵的一个属性，用于计算矩阵的逆和特征值。

- **矩阵**：用于表示天文数据集，如星系的位置和速度。
- **行列式**：用于求解矩阵的逆和特征值，如分析星系的稳定性。

**线性方程组**

线性方程组是包含多个线性方程的方程组。在天文数据分析中，线性方程组用于求解变量之间的关系，如星系的质量分布。

- **高斯消元法**：用于求解线性方程组的解。
- **迭代法**：用于求解大型线性方程组。

**特征值与特征向量**

特征值和特征向量是矩阵的重要属性，用于描述矩阵的稳定性和动态行为。

- **特征值**：描述矩阵的稳定性，如星系的自转速度。
- **特征向量**：描述矩阵的动态行为，如星系的运动轨迹。

**线性变换**

线性变换是线性代数中的基本概念，用于描述空间中的向量如何变换。在天文数据分析中，线性变换用于处理天文数据中的变化和转换。

- **旋转变换**：用于描述星系的自转。
- **投影变换**：用于处理观测数据中的噪声和干扰。

#### 2.3 微积分

微积分是研究函数的极限、导数、积分和无穷级数的数学分支。在天文数据分析中，微积分用于描述物理现象的动态变化和空间变化。

**微积分的基本概念**

微积分的基本概念包括极限、导数、积分等，这些概念用于描述天文数据的连续变化。

- **极限**：用于求解天文数据中的不确定性和边界问题。
- **导数**：用于描述天文数据的瞬时变化率，如行星的瞬时速度。
- **积分**：用于求解天文数据中的累积量，如恒星的总质量。

**导数与微分**

导数是微积分中的核心概念，用于描述函数在某一点的变化率。

- **导数**：用于求解天文数据中的瞬时变化率。
- **微分**：用于描述函数的局部变化，如行星轨道的微小偏差。

**积分与无穷级数**

积分是微积分中的另一个核心概念，用于求解函数的累积量。

- **定积分**：用于求解天文数据中的面积和体积，如星系的分布密度。
- **无穷级数**：用于求解天文数据中的无穷小量，如宇宙背景辐射的温度波动。

**应用示例**

**行星运动**：通过导数，我们可以求解行星的瞬时速度，进而预测行星的未来位置。

**恒星演化**：通过积分，我们可以求解恒星的质量损失率，分析恒星的演化过程。

**宇宙膨胀**：通过无穷级数，我们可以求解宇宙的膨胀历史，分析宇宙的动态行为。

### 第3章：高级数学工具

#### 3.1 概率论与数理统计

概率论与数理统计是研究随机现象的数学分支。在天文数据分析中，概率论与数理统计用于分析观测数据的随机性和不确定性。

**概率论基础**

概率论基础包括概率分布、条件概率、随机变量等概念。

- **概率分布**：描述随机变量取值的概率分布，如正态分布、泊松分布。
- **条件概率**：描述在给定一个事件发生的情况下，另一个事件发生的概率。
- **随机变量**：描述天文数据中的不确定性，如星系团的随机分布。

**统计估计**

统计估计包括点估计和区间估计，用于估计未知参数的值。

- **点估计**：使用样本数据估计未知参数的具体值，如估计星系的中心位置。
- **区间估计**：使用样本数据估计未知参数的置信区间，如估计星系的年龄范围。

**假设检验**

假设检验用于验证观测数据是否支持某个假设。

- **单样本假设检验**：检验样本数据是否与某个已知分布相符，如检验星系团的分布是否均匀。
- **双样本假设检验**：比较两个样本数据之间的差异，如比较两个星系的运动特性。

**回归分析**

回归分析用于研究变量之间的线性或非线性关系。

- **线性回归**：描述两个变量之间的线性关系，如星系速度与距离的关系。
- **非线性回归**：描述两个变量之间的非线性关系，如恒星质量与光度的关系。

**应用示例**

**星系团分析**：使用概率分布分析星系团中星系的随机分布，估计星系团的密度和形状。
**恒星演化**：使用回归分析研究恒星的质量、年龄和光度之间的关系，预测恒星的演化路径。

#### 3.2 偏微分方程

偏微分方程是研究多变量函数及其偏导数的方程。在天文数据分析中，偏微分方程用于描述物理现象的时空变化。

**偏微分方程的基本概念**

偏微分方程的基本概念包括方程的导数、解的存在性和唯一性等。

- **导数**：描述函数在多个变量上的变化率。
- **解的存在性和唯一性**：研究方程在给定条件下解的存在性和唯一性。

**常见偏微分方程**

- **热方程**：描述热量在物体内部的传播，如恒星内部的能量传递。
- **波动方程**：描述波动现象，如引力波在宇宙中的传播。
- **流体力学方程**：描述流体运动，如星系中的气体流动。

**应用示例**

**恒星内部结构**：使用热方程分析恒星内部的热量传递，求解恒星的内部结构。
**引力波**：使用波动方程模拟引力波的产生和传播，研究宇宙中的极端物理现象。

#### 3.3 复杂系统理论

复杂系统理论是研究复杂系统的行为和特性的理论体系。在天文数据分析中，复杂系统理论用于研究天体系统的动态行为。

**复杂系统的基本概念**

复杂系统的基本概念包括系统、状态、演化等。

- **系统**：由多个相互作用的元素组成的整体，如星系系统。
- **状态**：系统在某一时刻的特性和行为。
- **演化**：系统随时间变化的动态过程。

**常见复杂系统模型**

- **自组织系统**：描述系统在没有外部控制下自发形成有序结构的过程，如星系的形成。
- **非线性系统**：描述系统内部非线性关系的动态过程，如行星轨道的混沌行为。

**应用示例**

**星系形成**：使用自组织系统模型分析星系的形成过程，预测星系的结构和演化。
**行星轨道**：使用非线性系统模型分析行星轨道的稳定性，预测行星的未来运动。

#### 3.4 代数拓扑学

代数拓扑学是研究拓扑空间与代数结构的数学分支。在天文数据分析中，代数拓扑学用于分析天体的空间分布和相互作用。

**代数拓扑学的基本概念**

代数拓扑学的基本概念包括拓扑空间、同胚、同伦等。

- **拓扑空间**：描述空间中点的分布和连接关系。
- **同胚**：描述两个拓扑空间的相似性。
- **同伦**：描述空间中路径的变化。

**常见代数拓扑工具**

- **同调群**：用于描述空间的连通性和洞的存在。
- **同伦群**：用于描述空间的形状和变形。

**应用示例**

**星系团结构**：使用同调群分析星系团的结构和洞的存在，研究星系团的稳定性。
**星系演化**：使用同伦群分析星系演化的路径和形状，预测星系的未来状态。

### 第4章：天文数据的类型

天文数据是研究宇宙现象的基础，其类型多种多样，包括星表、光谱、图像、时序数据等。每种数据类型都有其独特的特点和收集方法，同时也需要不同的预处理和分析技术。

#### 4.1 星表数据

星表数据是天文学中最基础的数据类型，它包含了天体（如恒星、行星、星系等）的位置、亮度和其他属性。星表数据通常由天文观测机构通过望远镜等设备收集得到。

- **数据特点**：星表数据通常以表格形式存储，包括天体的坐标（经度、纬度）、视星等、绝对星等、距离等。
- **收集方法**：地面望远镜和空间望远镜是收集星表数据的主要工具。地面望远镜受大气干扰较大，而空间望远镜则可以提供更精确的观测数据。
- **预处理方法**：星表数据的预处理通常包括数据清洗、去重、坐标转换等。例如，将赤道坐标转换为赤经和赤纬。

#### 4.2 光谱数据

光谱数据是通过分析光波的不同波长区域来获取的信息，它包含了天体的化学成分、温度、运动状态等。光谱数据对于天文学研究至关重要，特别是恒星和星系的研究。

- **数据特点**：光谱数据通常以光谱图或光谱序列的形式表示，包括连续谱、吸收线、发射线等。
- **收集方法**：光谱数据通过光谱仪收集，光谱仪可以分解光波为不同波长，并通过探测器记录下来。
- **预处理方法**：光谱数据的预处理包括背景去除、噪声过滤、波长校正等。例如，去除观测过程中产生的噪声和仪器误差，以获取准确的光谱信号。

#### 4.3 图像数据

图像数据是天文学中最重要的数据类型之一，它通过望远镜获取的图像包含了丰富的天体信息。图像数据可以用于识别新的天体、研究星系的形态和结构等。

- **数据特点**：图像数据通常是高分辨率的数字图像，包含大量像素点。每个像素点代表特定位置的亮度信息。
- **收集方法**：图像数据通过光学望远镜、射电望远镜等设备收集。光学望远镜收集可见光图像，射电望远镜收集射电图像。
- **预处理方法**：图像数据的预处理包括图像增强、去噪、模糊消除等。例如，通过图像增强提高图像的对比度，以便更好地识别天体。

#### 4.4 时序数据

时序数据是随时间变化的数据，它包含了天体在不同时间点的亮度、位置等属性。时序数据对于研究天体的变化规律和周期性现象至关重要。

- **数据特点**：时序数据通常是时间序列形式的，包括时间戳和对应的观测值。
- **收集方法**：时序数据可以通过望远镜、探测器等设备收集，特别是用于观测变星、彗星等天体的变化。
- **预处理方法**：时序数据的预处理包括时间校正、数据填充、趋势去除等。例如，通过时间校正修正时间误差，通过数据填充填补观测缺失，通过趋势去除消除系统误差。

#### 4.5 其他类型数据

除了上述主要类型外，天文学中还涉及其他类型的数据，如射电数据、X射线数据、γ射线数据等。这些数据提供了不同波长区域的信息，对于研究天体的极端物理现象至关重要。

- **射电数据**：射电望远镜收集的射电波段数据，用于研究星际介质、脉冲星等。
- **X射线数据**：X射线望远镜收集的X射线数据，用于研究黑洞、中子星等高能天体。
- **γ射线数据**：γ射线望远镜收集的γ射线数据，用于研究宇宙射线、超新星爆发等。

#### 4.6 数据类型的综合应用

不同类型的天文数据可以相互补充，通过综合分析，可以揭示更丰富的天文现象。例如，结合星表数据和光谱数据，可以确定天体的化学成分和运动状态；结合图像数据和时序数据，可以研究星系的形成和演化。

**示例分析**

假设我们有一组恒星的光谱数据和位置信息，我们可以通过以下步骤进行分析：

1. **数据收集**：使用光谱仪收集恒星的光谱数据，使用望远镜收集恒星的星表数据。
2. **数据预处理**：对光谱数据进行背景去除、噪声过滤等预处理，对星表数据进行去重、坐标转换等预处理。
3. **数据融合**：将预处理后的光谱数据和星表数据融合，形成包含恒星位置、光谱特征的数据库。
4. **数据分析**：使用回归分析等方法，研究恒星光谱特征与位置之间的关系，揭示恒星的化学成分和运动状态。
5. **结果验证**：通过比较分析结果与已有知识，验证分析结果的可靠性。

通过以上分析，我们可以获得关于恒星系统的新认识，为天文学研究提供有力支持。

### 第5章：数据收集方法

天文数据的收集方法多种多样，包括地面观测、空间观测、射电观测等。每种观测方法都有其独特的优势和局限性，适用于不同的天文学研究目标。

#### 5.1 地面观测

地面观测是天文数据收集的传统方法，通过架设在地面上的望远镜进行观测。地面观测的优点包括观测时间长、操作便捷、成本相对较低等。

- **优点**：
  - 观测时间长：地面望远镜可以连续进行多年观测，积累大量数据。
  - 操作便捷：地面观测不需要太复杂的设备和技术，操作人员相对容易掌握。
  - 成本相对较低：与空间观测相比，地面观测的成本较低，适合中小型研究机构。

- **局限性**：
  - 大气干扰：地面观测受大气干扰较大，如光晕、大气抖动等，影响观测精度。
  - 光学限制：大气中的水汽、氧气等会吸收部分光线，限制观测到的光谱范围。
  - 天文事件错过：地面观测无法避免天气变化和夜间限制，可能错过某些重要的天文事件。

- **应用示例**：
  - 星表数据的收集：地面望远镜常用于收集恒星的位置、亮度等基本信息，形成星表。
  - 恒星光谱的测量：通过光谱仪收集恒星的光谱数据，分析恒星的化学成分和温度。

#### 5.2 空间观测

空间观测是指将望远镜等观测设备放置在太空中进行观测。空间观测的优点包括观测环境纯净、观测时间长、观测范围广等。

- **优点**：
  - 观测环境纯净：太空没有大气干扰，可以获取更高的观测精度。
  - 观测时间长：空间望远镜可以连续观测多年，不受地面天气和光照限制。
  - 观测范围广：空间望远镜可以覆盖更大的天区，探测更遥远的天体。

- **局限性**：
  - 成本高昂：空间观测需要发射卫星、飞船等设备，成本相对较高。
  - 观测时间受限：空间观测设备发射和操作需要严格计划和调度，观测时间相对有限。
  - 技术复杂：空间观测设备的技术要求较高，操作和维护相对复杂。

- **应用示例**：
  - 宇宙背景辐射的观测：宇宙背景辐射探测器如COBE、WMAP、Planck等，通过空间观测揭示了宇宙早期的信息。
  - 恒星形成区的观测：红外天文望远镜如Spitzer、JWST等，通过空间观测揭示了恒星形成区的物理过程。

#### 5.3 射电观测

射电观测是利用射电望远镜收集来自宇宙的无线电波信号。射电观测适用于研究星际介质、脉冲星、黑洞等极端物理现象。

#### 6.1 数据清洗

数据清洗是数据预处理的第一步，目的是识别和纠正数据中的错误和异常。在天文数据分析中，数据清洗尤为重要，因为观测数据往往受到各种噪声和异常的影响。

- **识别错误和异常**：通过检查数据的一致性和逻辑性，识别出可能存在的错误和异常值。例如，检测数据中的重复记录、缺失值和逻辑错误。
- **处理缺失值**：缺失值处理包括填充缺失值和删除含有缺失值的记录。填充缺失值的方法有多种，如平均值填充、中值填充和插值填充等。

#### 6.2 数据归一化

数据归一化是将不同尺度或单位的数据转换为同一尺度或单位，以便进行比较和分析。在天文数据分析中，数据归一化有助于统一不同观测设备的数据格式，提高分析精度。

- **归一化方法**：常用的归一化方法包括最小-最大归一化、均值-方差归一化等。最小-最大归一化将数据映射到[0,1]区间，而均值-方差归一化将数据映射到[-1,1]区间。
- **应用示例**：例如，将不同观测设备的亮度数据归一化到相同的亮度尺度，以便进行对比分析。

#### 6.3 数据插值

数据插值是填充数据缺失部分的方法，它通过在已知数据点之间构建插值模型，预测未知数据点的值。在天文数据分析中，数据插值有助于提高数据的完整性和连续性。

- **插值方法**：常用的插值方法包括线性插值、多项式插值、样条插值等。线性插值简单易行，但可能无法很好地捕捉数据的复杂变化；多项式插值可以拟合更复杂的函数，但可能产生过拟合；样条插值在保证平滑性的同时，能较好地拟合数据。
- **应用示例**：例如，对缺失的恒星位置数据进行插值，以填补观测过程中的数据缺失，提高星表数据的完整性。

#### 12.1 星系形成与演化的理论模型

星系的形成和演化是一个复杂的过程，涉及到引力、气体动力学、恒星形成和星系相互作用等多个方面。以下是一些主要的星系形成与演化的理论模型：

**冷暗物质模型**

冷暗物质模型（CDM）是目前最广泛接受的宇宙学模型，它假设宇宙中大部分物质是看不见的冷暗物质，这种物质通过引力作用影响了星系的形成。

- **主要假设**：宇宙中存在大量看不见的冷暗物质，这些物质通过引力作用聚集形成星系。
- **形成过程**：星系的形成始于一个均匀分布的暗物质密度波峰，暗物质波峰吸引周围的普通物质，逐渐形成一个星系。
- **观测验证**：通过观测星系团的引力透镜效应和星系分布的统计特性，CDM模型得到了广泛验证。

**星系碰撞与合并**

星系碰撞与合并是星系演化中的重要过程，两个星系在碰撞后可能会合并形成更大的星系。

- **碰撞过程**：星系在引力的作用下相互靠近，发生碰撞和合并。碰撞过程中，星系内部的气体和恒星会发生剧烈的相互作用。
- **结果**：星系合并可能会形成更大的星系，同时产生大量的恒星形成区，导致新恒星的诞生。

**盘星系与椭圆星系**

根据星系的外观和内部结构，星系可以分为盘星系和椭圆星系。

- **盘星系**：具有扁平的旋转盘，恒星和气体沿盘面分布。典型的盘星系如我们的银河系。
- **椭圆星系**：形状更加椭圆化，恒星和气体分布更加均匀。椭圆星系通常形成于星系碰撞和合并过程中。

- **无线电波段**：射电望远镜可以探测到宇宙中发出的无线电波，这些波源包括恒星形成区中的分子云、脉冲星和伽玛射线暴。

**X射线观测**

X射线观测主要用于研究高能天体，如黑洞、中子星和活跃星系核。

#### 13.1 黑洞的基本概念

黑洞是一种极其密集的天体，它的引力场强大到连光也无法逃逸。黑洞的形成通常与恒星演化密切相关，当大质量恒星耗尽核燃料后，其核心会塌缩形成黑洞。

**黑洞的分类**

黑洞主要分为以下几类：

- **恒星质量黑洞**：由大质量恒星演化而来，质量大约在太阳质量的几倍到几十倍之间。
- **超大质量黑洞**：位于星系中心，质量可以达到太阳质量的数百万倍甚至更多。
- **中子星**：虽然不是传统意义上的黑洞，但质量与黑洞相近，密度极高。

**黑洞的特性**

黑洞具有以下主要特性：

- **事件视界**：黑洞的边界，一旦物体进入事件视界，就无法逃脱黑洞的引力。
- **霍金辐射**：根据量子力学理论，黑洞会以辐射的形式失去能量和质量。
- **引力透镜效应**：黑洞强大的引力场可以弯曲光线路径，从而在观测中产生多个图像，这种现象称为引力透镜效应。

#### 13.2 引力波的基本概念

引力波是宇宙中的一种波动现象，它由质量加速运动产生。爱因斯坦的广义相对论预言了引力波的存在，并认为引力波会以光速传播。

**引力波的特性**

引力波具有以下主要特性：

- **时空弯曲**：引力波会使时空发生弯曲，这种弯曲可以传播到远处。
- **振幅和频率**：引力波的振幅和频率取决于产生它的质量和加速运动。
- **极化**：引力波具有两个偏振方向，类似于电磁波的偏振。

**引力波的产生**

引力波通常由以下事件产生：

- **双星系统**：两个恒星围绕彼此旋转，产生的引力波。
- **黑洞碰撞**：两个黑洞或黑洞与恒星碰撞产生的引力波。
- **中子星碰撞**：两个中子星或中子星与黑洞碰撞产生的引力波。

### 第14章：天文数据分析的挑战

天文数据分析面临着许多挑战，这些挑战源于天文数据的复杂性、噪声的多样性以及宇宙现象的极端性。以下将详细讨论这些挑战以及应对策略。

#### 14.1 数据量大

天文数据分析的一个主要挑战是数据量大。随着观测技术的进步，天文观测设备能够收集到海量的数据，这些数据包含了宇宙中大量的信息。处理这些数据需要高效的计算资源和算法。

**挑战**：

- 数据存储和传输：天文数据通常以TB甚至PB级别存储和传输，这对数据存储设备和网络带宽提出了高要求。
- 数据处理时间：处理大量数据需要较长的计算时间，这可能限制实时数据分析的能力。

**应对策略**：

- **并行计算**：通过使用并行计算技术，将数据处理任务分解为多个子任务，并行处理，可以显著缩短处理时间。
- **分布式计算**：利用分布式计算架构，将数据分布到多个计算节点，实现数据的分布式处理，提高数据处理能力。
- **数据压缩**：采用数据压缩技术，减少数据的存储空间和传输带宽。

#### 14.2 噪声复杂

天文数据中包含大量的噪声，这些噪声可能来源于大气干扰、仪器误差、天文事件本身等。噪声的复杂性和多样性使得数据预处理和分析变得更加困难。

**挑战**：

- 噪声识别：识别和分离噪声和有用信号是一个复杂的任务，不同类型的噪声可能需要不同的处理方法。
- 噪声过滤：在去除噪声的同时，需要尽可能保留有用信号，避免引入新的误差。

**应对策略**：

- **自适应滤波**：根据数据的特点，动态调整滤波参数，以适应不同类型的噪声。
- **多模型拟合**：使用多个模型对数据拟合，通过比较拟合结果，识别和去除噪声。
- **机器学习**：利用机器学习算法，如神经网络、支持向量机等，自动识别和去除噪声。

#### 14.3 模型复杂

宇宙现象往往涉及复杂的物理过程，这些过程需要复杂的数学模型来描述。复杂模型的建立和求解是天文数据分析中的另一大挑战。

**挑战**：

- **计算复杂度**：复杂模型通常需要大量的计算资源，尤其是高维数据和复杂的数值求解。

- **机器学习**：利用机器学习算法，如深度学习、强化学习等，可以自动发现复杂模型，减少人为干预。

```python
import numpy as np
import matplotlib.pyplot as plt
from astropy.io import fits
from sklearn.cluster import KMeans

def collect_data():
    # 收集光学数据
    # 这里假设数据存储在文件夹data/中，以fits格式存储
    files = ['data/*.fits']
    data = []
    for file in files:
        with fits.open(file) as hdul:
            data.append(hdul[0].data)
    return np.array(data)

def preprocess_data(data):
    # 预处理数据
    # 包括数据清洗、归一化等
    # 这里简单示例，实际中会涉及更复杂的预处理步骤
    normalized_data = (data - np.mean(data, axis=0)) / np.std(data, axis=0)
    return normalized_data

def extract_features(data):
    # 提取恒星特征
    # 这里使用K均值聚类提取特征
    kmeans = KMeans(n_clusters=10, random_state=0).fit(data)
    return kmeans.labels_

def analyze_forming_zone(data, labels):
    # 分析恒星形成区
    # 绘制恒星分布图
    unique_labels = set(labels)
    colors = plt.cm.Spectral(np.linspace(0, 1, len(unique_labels)))
    for k, col in zip(unique_labels, colors):
        class_member_mask = (labels == k)
        xy = data[class_member_mask]
        plt.plot(xy[:, 0], xy[:, 1], 'o', markerfacecolor=col, markeredgecolor='k', markersize=6)
    plt.title('恒星形成区分布')
    plt.show()

if __name__ == '__main__':
    data = collect_data()
    preprocessed_data = preprocess_data(data)
    labels = extract_features(preprocessed_data)
    analyze_forming_zone(preprocessed_data, labels)
```
