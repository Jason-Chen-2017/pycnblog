### 2.1 区块链的定义与特点

**定义**：区块链是一种去中心化的分布式数据库，它通过密码学技术确保数据的真实性和不可篡改性。每个区块都包含一定数量的交易记录，这些区块按照时间顺序连接成一个链式结构。

**特点**：

1. **去中心化**：区块链不需要中心化的机构或第三方来验证交易，而是通过分布式网络中的节点共同维护。
2. **不可篡改**：一旦数据被记录在区块链上，就几乎无法篡改，保证了数据的真实性和可信度。
3. **透明化**：区块链上的数据是公开的，任何人都可以查询，但交易内容是加密的，保护了隐私。
4. **智能合约**：区块链平台支持智能合约，允许自动化执行合同条款。

### 2.2 区块链的工作原理

**哈希函数**：哈希函数是一种将任意长度的输入数据映射为固定长度的输出的函数。在区块链中，每个区块都有一个唯一的哈希值，用于确保区块内容的完整性和不可篡改性。

**链式结构**：区块链通过链式结构将各个区块连接起来。每个区块都包含前一个区块的哈希值，形成一个连续的链。

**智能合约**：智能合约是运行在区块链上的计算机程序，它可以在满足特定条件时自动执行特定的操作。智能合约通过预定义的逻辑规则，实现了自动化和去中心化的交易。

### 2.3 主流区块链平台简介

**Ethereum**：Ethereum是一个开源的智能合约平台，支持各种去中心化应用（DApp）。它通过Ether币作为交易媒介，实现了智能合约的自动化执行。

以下是一个简单的智能合约示例，用于记录供应链中的交易：

```solidity
pragma solidity ^0.8.0;

contract SupplyChain {
    mapping (address => uint) public balanceOf;

    function deposit() public payable {
        balanceOf[msg.sender()] += msg.value;
    }

    function withdraw(uint amount) public {
        require(amount <= balanceOf[msg.sender()], "Insufficient balance");
        balanceOf[msg.sender()] -= amount;
        payable(msg.sender()).transfer(amount);
    }
}
```

在这个示例中，我们定义了一个名为`SupplyChain`的智能合约，包含两个函数：`deposit`和`withdraw`。`deposit`函数用于向合约地址发送以太币，并将其记录在账本中。`withdraw`函数用于从合约地址提取以太币，前提是提取的金额不超过当前余额。

#### 7.3 代码应用解读与分析

**代码解读**：

- `pragma solidity ^0.8.0;`：指定智能合约使用的版本。
- `mapping (address => uint) public balanceOf;`：定义一个映射，用于记录每个地址的余额。
- `function deposit() public payable { ... }`：定义一个`deposit`函数，接收以太币并将其添加到发送者的余额。
- `function withdraw(uint amount) public { ... }`：定义一个`withdraw`函数，从发送者的余额中提取以太币。

**代码分析**：

- `deposit`函数：每次调用该函数时，都会将发送者的以太币添加到合约地址的余额中。
- `withdraw`函数：在调用该函数时，需要检查提取的金额是否小于等于发送者的余额，否则会抛出异常。

- **透明化（Transparency）**：信息对各方公开，可被查询和验证。
- **数据记录（Data Recording）**：将交易、物流、质检等信息记录在区块链上。
- **数据验证（Data Verification）**：通过共识机制验证区块链上数据的真实性和一致性。
- **供应链管理（Supply Chain Management）**：涉及从原材料采购到产品交付的整个流程的管理。
- **供应链金融（Supply Chain Finance）**：利用区块链技术提高供应链中资金流转效率的金融模式。

**示例1：供应链交易记录**

```solidity
pragma solidity ^0.8.0;

contract SupplyChain {
    mapping (address => uint) public balanceOf;

    function deposit() public payable {
        balanceOf[msg.sender()] += msg.value;
    }

    function withdraw(uint amount) public {
        require(amount <= balanceOf[msg.sender()], "Insufficient balance");
        balanceOf[msg.sender()] -= amount;
        payable(msg.sender()).transfer(amount);
    }
}
```

**示例2：供应链物流跟踪**

```solidity
pragma solidity ^0.8.0;

contract Logistics {
    struct Shipment {
        address sender;
        address receiver;
        string trackingId;
        bool delivered;
    }

    mapping (string => Shipment) public shipments;

    function createShipment(string memory _trackingId, address _receiver) public {
        shipments[_trackingId] = Shipment(msg.sender, _receiver, _trackingId, false);
    }

    function deliverShipment(string memory _trackingId) public {
        require(shipments[_trackingId].sender == msg.sender, "Not the sender");
        shipments[_trackingId].delivered = true;
    }
}
```

- **去中心化（Decentralization）**：系统或网络不存在中央控制机构，而是通过分布式方式运作。
- **透明化（Transparency）**：信息对各方公开，可被查询和验证。
- **数据记录（Data Recording）**：将交易、物流、质检等信息记录在区块链上。
- **数据验证（Data Verification）**：通过共识机制验证区块链上数据的真实性和一致性。
- **供应链管理（Supply Chain Management）**：涉及从原材料采购到产品交付的整个流程的管理。
- **供应链金融（Supply Chain Finance）**：利用区块链技术提高供应链中资金流转效率的金融模式。

**示例1：供应链交易记录**

```solidity
pragma solidity ^0.8.0;

contract SupplyChain {
    mapping (address => uint) public balanceOf;

    function deposit() public payable {
        balanceOf[msg.sender()] += msg.value;
    }

    function withdraw(uint amount) public {
        require(amount <= balanceOf[msg.sender()], "Insufficient balance");
        balanceOf[msg.sender()] -= amount;
        payable(msg.sender()).transfer(amount);
    }
}
```

**示例2：供应链物流跟踪**

```solidity
pragma solidity ^0.8.0;

contract Logistics {
    struct Shipment {
        address sender;
        address receiver;
        string trackingId;
        bool delivered;
    }

    mapping (string => Shipment) public shipments;

    function createShipment(string memory _trackingId, address _receiver) public {
        shipments[_trackingId] = Shipment(msg.sender, _receiver, _trackingId, false);
    }

    function deliverShipment(string memory _trackingId) public {
        require(shipments[_trackingId].sender == msg.sender, "Not the sender");
        shipments[_trackingId].delivered = true;
    }
}
```

```solidity
pragma solidity ^0.8.0;

contract SupplyChain {
    mapping (address => uint) public balanceOf;
```

```solidity
pragma solidity ^0.8.0;

contract Logistics {
    struct Shipment {
        address sender;
        address receiver;
        string trackingId;
        bool delivered;
    }

    mapping (string => Shipment) public shipments;

    function createShipment(string memory _trackingId, address _receiver) public {
        shipments[_trackingId] = Shipment(msg.sender, _receiver, _trackingId, false);
    }

    function deliverShipment(string memory _trackingId) public {
        require(shipments[_trackingId].sender == msg.sender, "Not the sender");
        shipments[_trackingId].delivered = true;
    }
}
```
