#### 核心概念原理

##### 数学概念

- **集合论**：集合论是数学的基础之一，研究集合的性质和运算。它包括集合的定义、集合的运算、集合的公理体系等。

- **拓扑学**：拓扑学研究空间的结构和性质。它包括拓扑空间的概念、拓扑空间的性质、连通性、紧性等。

- **微积分**：微积分研究函数的极限、导数、积分等概念。它包括极限、导数、积分的定义、性质和计算方法。

##### 类型论

- **类型系统**：类型系统定义程序中数据的类型，如整数、字符串、函数等。它包括类型的定义、类型检查和类型推导。

- **类型推导**：类型推导从程序中推断出变量的类型，确保程序的正确性和类型安全性。

def union(A, B):
    """
    计算两个集合的并集。
    
    :param A: 集合A
    :param B: 集合B
    :return: 并集
    """
    result = []
    for x in A:
        result.append(x)
    for y in B:
        result.append(y)
    return result

# 示例
