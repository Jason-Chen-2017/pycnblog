### **2.1.1 几何学的基本概念**

几何学是研究点的位置、线的性质、面的形状等空间关系的数学分支。在雕塑艺术中，几何学的基本概念如点、线、面等，为雕塑创作提供了基本的形状和结构支持。点作为最基本的元素，通过连接和组合，形成线条和面，进而构成复杂的雕塑形态。

#### **点**

点在几何学中是无维的，它仅代表空间中的一个位置。在雕塑艺术中，点可以表示雕塑作品的细节，如凸起、凹陷或雕刻的痕迹。通过精确的位置控制，雕塑艺术家可以创造出丰富的视觉效果。

#### **线**

线是由无数个点连接而成的，具有长度和方向。在雕塑艺术中，线条可以用来勾勒形状，形成边界和轮廓。不同类型的线条，如直线、曲线和折线，可以创造出不同的视觉感受。

#### **面**

面是由无数条线连接而成的，具有长度、宽度和高度。在雕塑艺术中，面可以用来构建三维形态，形成作品的表面和结构。不同类型的面，如平面、曲面和凸曲面，可以带来不同的空间感和视觉效果。

#### **正多面体**

正多面体是由相同数量的正多边形组成的立体图形，如正方体、正二十面体等。正多面体具有对称性和规则性，这些特性使它们成为雕塑设计的理想选择。例如，正方体可以用于构建简洁、有力的雕塑作品，而正二十面体则可以用于创造具有复杂结构和精致细节的作品。

#### **球体**

球体是一种完美的对称体，具有无限旋转的对称性。球体在雕塑艺术中广泛应用于各种题材，如人物、动物、自然景观等。球体的光滑表面和流线型形态，赋予雕塑作品柔和、优雅的视觉效果。

#### **圆锥体和圆柱体**

圆锥体和圆柱体在雕塑设计中也很常见，它们具有简洁、干净的外观，常用于表现稳定性和力量感。圆锥体通常用于塑造尖锐、向上的形态，而圆柱体则用于塑造稳固、结实的结构。

#### **椭圆体和椭球体**

椭圆体和椭球体具有类似于球体的流线型外观，但具有更复杂的几何形状。椭圆体和椭球体在雕塑艺术中常用于表现柔软、圆润的形态，如人物雕像的头部、手臂等。

### **2.2.1 拓扑学的基本概念**

拓扑学是研究空间结构和性质的一门数学分支，它与几何学不同，不关注对象的形状大小和位置变化，而是关注空间连接性和封闭性。拓扑学中的基本概念包括连通性、紧性和边界等。

#### **连通性**

连通性是指一个空间中的任意两点之间都存在路径相连。在拓扑学中，如果一个空间不能被分割成两个或多个不相连的部分，那么这个空间就是连通的。

#### **紧性**

紧性是指一个空间内的所有点都可以被包含在一个较小的空间范围内。在拓扑学中，紧性是衡量空间紧致程度的一个重要指标。

#### **边界**

边界是指一个空间与其外部空间之间的分界线。在拓扑学中，边界对于研究空间的形状和性质具有重要作用。

### **2.2.2 拓扑结构在雕塑设计中的运用**

拓扑学在雕塑艺术中的应用，主要体现在对空间结构的探索和创造上。通过拓扑学的原理，雕塑艺术家可以创造出具有复杂结构和独特视觉效果的雕塑作品。

#### **1. 拓扑优化**

拓扑优化是一种通过数学算法优化结构设计的手段，它基于拓扑变换原理，对雕塑的形态进行优化，以实现结构的最优性能。拓扑优化算法可以通过消除不必要结构、增加稳定性等方式，提升雕塑作品的美感和实用性。

#### **2. 拓扑雕塑**

拓扑雕塑是一种以拓扑学原理为基础的雕塑形式，它利用拓扑结构创造出独特的形态和空间感。拓扑雕塑的特点是形态复杂、结构稳定，具有很强的视觉冲击力。例如，理查德·萨奇的作品《内脏模型》就是典型的拓扑雕塑，它通过复杂的拓扑结构，表现出人体器官的形态和空间感。

#### **3. 拓扑变形**

拓扑变形是一种通过拓扑变换创造出不同形态的雕塑手法。在雕塑创作中，艺术家可以利用拓扑变形，将一个简单的形态通过连续的变换，变成复杂的形态。这种手法不仅增加了雕塑的趣味性，还使雕塑作品具有了动态的视觉效果。

### **附录B：拓扑学基本概念**

#### **1. 连通性**

#### **2. 紧性**

#### **3. 局部紧性**

- 一个空间内的每一个开集都是紧空间。

#### **4. 连通空间的分类**

- 欧几里得空间：满足局部紧性的连通空间。
- 拓扑空间：不满足局部紧性的连通空间。

```python
def create_fractal(mesh, depth, scale):
    vertices, faces = mesh
    new_vertices = vertices.copy()
    new_faces = faces.copy()

    # 分支比例
    branch_ratio = 0.5
    angle_deviation = np.pi / 4

    for _ in range(depth):
        for face in faces:
            v1, v2, v3 = vertices[face]
            center = (v1 + v2 + v3) / 3
            norm = np.linalg.norm(center)

                    new_vertices = np.vstack([new_vertices, new_center])
                    new_faces = np.vstack([new_faces, [face[i], face[i+1], len(new_vertices)-1]])

    write_mesh("fractal.obj", vertices=new_vertices, faces=new_faces)
    return new_vertices, new_faces
```

```python
def koch_curve(vertices, depth):
    if depth == 0:
        return [vertices]
    
    new_vertices = []
    for i in range(len(vertices) - 1):
        v1, v2 = vertices[i], vertices[i+1]
        vector = v2 - v1
        mid = (v1 + v2) / 2
        new_vertices.append(mid)

        angle = np.arccos(np.dot(vector / np.linalg.norm(vector), np.array([0, 0, 1])))
        v1_2 = v1 + vector * (1 / 3.0 * np.cos(angle) + 1 / 3.0 * np.sin(angle))
        v2_2 = v2 - vector * (1 / 3.0 * np.cos(angle) - 1 / 3.0 * np.sin(angle))
        new_vertices.extend([v1_2, v2_2])

    return koch_curve(new_vertices, depth - 1)

# 生成Koch曲线
koch_vertices = koch_curve(np.array([[0, 0, 0], [1, 0, 0], [0.5, np.sqrt(3)/2, 0]]), 3)
write_mesh("koch_curve.obj", vertices=koch_vertices, faces=[[0, 1, 2]])

# 绘制结果
fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')
ax.plot_wireframe(koch_vertices[:, 0], koch_vertices[:, 1], koch_vertices[:, 2], color='r')
plt.show()
```

**分析**

- `koch_curve` 函数接受一个顶点列表（`vertices`）和深度（`depth`）作为输入参数。
- 如果深度为0，函数返回当前顶点列表。
- 否则，函数计算每对相邻顶点之间的向量，并找到中点。接着，函数计算角度，并创建新的顶点，这些顶点位于原始顶点之间的三分之一处。
- 函数递归调用自身，直到达到指定的深度。

```python
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# 正方体的顶点坐标
vertices = np.array([
    [0, 0, 0],  # 顶点1
    [1, 0, 0],  # 顶点2
    [1, 1, 0],  # 顶点3
    [0, 1, 0],  # 顶点4

    [1, 1, 1],  # 顶点7
    [0, 1, 1]   # 顶点8
])

faces = np.array([
    [0, 1, 2, 3],  # 底面
    [4, 5, 6, 7],  # 顶面
    [0, 1, 5, 4],  # 前面
    [1, 2, 6, 5],  # 右侧面
    [2, 3, 7, 6],  # 后侧面
    [3, 0, 4, 7],  # 左侧面

    [5, 6, 2, 1],  # 右侧边
```

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建一个图
G = nx.Graph()

# 添加边
G.add_edges_from([(1, 2), (2, 3), (3, 1), (3, 4), (4, 5), (5, 6), (6, 1)])

# 计算拓扑排序
topo_sort = list(nx.topological_sort(G))

# 绘制图
pos = nx.spring_layout(G)
nx.draw(G, pos, with_labels=True)
plt.show()

# 打印拓扑排序
print("拓扑排序：", topo_sort)
```
