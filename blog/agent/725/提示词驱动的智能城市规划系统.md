#### 4.2 机器学习算法

机器学习算法是智能城市规划系统的重要组成部分，用于对城市数据进行预测和分析。以下介绍几种常用的机器学习算法及其实现：

1. **线性回归**：线性回归是一种简单的预测算法，通过拟合数据点之间的关系来实现预测。

   算法原理：$$y = wx + b$$

   Python代码示例：

   ```python
   import numpy as np
   import pandas as pd

   # 数据准备
   df = pd.DataFrame({'x': [1, 2, 3, 4, 5], 'y': [2, 4, 5, 4, 5]})
   X = df[['x']]
   y = df['y']

   # 模型训练
   w = np.linalg.inv(X.T.dot(X)).dot(X.T).dot(y)
   b = y - X.dot(w)

   # 预测
   def predict(x):
       return x * w + b

   # 实际应用
   print(predict(6))
   ```

2. **决策树**：决策树是一种基于树形结构的预测算法，通过一系列规则来分割数据集。

   算法原理：$$f(x) = \sum_{i=1}^{n} w_i * g(x_i)$$，其中$g(x_i)$为分割规则。

   Python代码示例：

   ```python
   from sklearn.tree import DecisionTreeRegressor

   # 数据准备
   df = pd.DataFrame({'x': [1, 2, 3, 4, 5], 'y': [2, 4, 5, 4, 5]})
   X = df[['x']]
   y = df['y']

   # 模型训练
   model = DecisionTreeRegressor()
   model.fit(X, y)

   # 预测
   def predict(x):
       return model.predict([[x]])[0]

   # 实际应用
   print(predict(6))
   ```

3. **神经网络**：神经网络是一种基于多层感知器（MLP）的预测算法，通过非线性变换来实现复杂函数的逼近。

#### 4.3 优化算法

优化算法用于求解城市规划中的优化问题，如路径规划、资源分配等。以下介绍几种常用的优化算法及其实现：

1. **遗传算法**：遗传算法是一种模拟自然进化过程的优化算法，通过遗传、变异和选择等操作来搜索最优解。

   算法原理：$$f(x) = \sum_{i=1}^{n} w_i * g(x_i)$$，其中$g(x_i)$为适应度函数。

   Python代码示例：

   ```python
   import numpy as np
   import random

   # 初始化种群
   def init_population(pop_size, gene_size):
       population = []
       for _ in range(pop_size):
           individual = [random.randint(0, 1) for _ in range(gene_size)]
           population.append(individual)
       return population

   # 适应度函数
   def fitness_function(individual):
       x = sum(individual)
       return 1 / (1 + np.exp(-x))

   # 遗传操作
   def genetic_operate(parent1, parent2):
       child1 = parent1[:]
       child2 = parent2[:]
       crossover_point = random.randint(1, len(parent1) - 1)
       for i in range(crossover_point, len(parent1)):
           child1[i], child2[i] = child2[i], child1[i]
       return child1, child2

   # 主程序
   def main():
       pop_size = 100
       gene_size = 10
       generations = 100

       population = init_population(pop_size, gene_size)
       for _ in range(generations):
           fitness_values = [fitness_function(individual) for individual in population]
           sorted_population = [individual for _, individual in sorted(zip(fitness_values, population), reverse=True)]
           for i in range(1, pop_size - 1, 2):
               child1, child2 = genetic_operate(sorted_population[i - 1], sorted_population[i + 1])
               population[i] = child1
               population[i + 1] = child2

       print("最优解：", sorted_population[0])

   # 实际应用
   main()
   ```
