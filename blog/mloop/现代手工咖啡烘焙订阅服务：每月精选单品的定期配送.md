## 咖啡烘焙基础知识

### 核心概念术语

- **咖啡豆**：咖啡树结出的种子，是咖啡的主要原料。
- **烘焙**：将咖啡豆在高温下加热，使其颜色、气味和口感发生变化的工艺过程。
- **烘焙曲线**：描述烘焙过程中温度随时间变化的曲线，是影响咖啡风味的关键因素。

### 问题背景

咖啡烘焙是一个复杂的过程，需要精确控制温度、时间和湿度等因素。不同的烘焙程度会产生不同的风味和口感，这也是手工烘焙的魅力所在。

### 问题描述

如何通过手工烘焙技术，创造出符合消费者需求的、高质量的咖啡单品？

### 问题解决

1. **选择优质咖啡豆**：优质的咖啡豆是手工烘焙成功的基础。根据不同的风味和用途，选择合适的咖啡豆。
2. **掌握烘焙曲线**：通过反复试验和调整，找到适合自己烘焙风格的烘焙曲线。
3. **个性化定制**：根据客户的需求和口味，提供定制化的烘焙服务。

### 边界与外延

1. **烘焙程度的边界**：过浅或过深的烘焙都会影响咖啡的风味和口感。
2. **烘焙曲线的外延**：不同种类的咖啡豆和烘焙设备需要不同的烘焙曲线，需要不断尝试和调整。

### 概念结构与核心要素组成

1. **咖啡豆种类**：阿拉比卡、罗布斯塔等。
2. **烘焙设备**：烤箱、烘焙机等。
3. **烘焙曲线**：温度-时间曲线。
4. **风味调整**：烘焙程度、烘焙时间、烘焙温度等。

## 手工咖啡烘焙技术

### 烤焙方法

1. **直接烘焙**：将咖啡豆直接放置在烤盘上，通过热量传递进行烘焙。
2. **间接烘焙**：通过热空气或其他介质传递热量，对咖啡豆进行烘焙。

### 烤焙设备选择

1. **烤箱**：适合家庭和小规模烘焙，操作简单。
2. **烘焙机**：适合商业规模烘焙，效率高，控制精准。

### 烤焙曲线调整

1. **温度调整**：根据咖啡豆的品种和烘焙程度，调整烘焙曲线中的温度段。
2. **时间调整**：根据烘焙曲线，调整烘焙时间，以达到理想的烘焙效果。

### 烤焙技巧与细节

1. **预热**：确保烘焙设备在烘焙开始前达到适当的温度。
2. **翻动**：定期翻动咖啡豆，确保均匀烘焙。
3. **观察与调整**：在烘焙过程中，不断观察咖啡豆的颜色、气味和声音，根据情况进行调整。

#### 数学模型和公式

1. **时间序列预测模型**：

   $$y_t = f(x_t, \theta)$$

   其中，$y_t$ 表示预测值，$x_t$ 表示时间序列的特征，$\theta$ 表示模型参数。

2. **回归模型**：

   $$y = \beta_0 + \beta_1x_1 + \beta_2x_2 + ... + \beta_nx_n$$

   其中，$y$ 表示预测值，$x_1, x_2, ..., x_n$ 表示自变量，$\beta_0, \beta_1, \beta_2, ..., \beta_n$ 表示模型参数。

3. **遗传算法适应度函数**：

   $$f(x) = \frac{1}{1 + e^{-\theta(x-\bar{x})}}$$

   其中，$f(x)$ 表示适应度值，$\theta$ 表示模型参数，$\bar{x}$ 表示平均适应度。

4. **贪心算法选择函数**：

   $$C(x) = \max_{i}(\frac{P_i}{C_i})$$

   其中，$C(x)$ 表示选择函数值，$P_i$ 表示产品$i$的利润，$C_i$ 表示产品$i$的库存成本。

#### 时间序列预测

使用时间序列分析法预测未来三天的销售量。首先，计算平均值和标准差：

$$\bar{x} = \frac{100+110+120+130+140}{5} = 120$$  
$$\sigma = \sqrt{\frac{(100-120)^2+(110-120)^2+(120-120)^2+(130-120)^2+(140-120)^2}{5}} = 10$$

然后，使用正态分布模型预测未来三天的销售量：

$$y_t = \bar{x} + \sigma \cdot N(0,1)$$

假设 $t=6,7,8$，则预测结果如下：

| 日期 | 预测销售量 |  
| ---- | ------ |  
| 2021-01-06 | 120 + 10 \cdot N(0,1) ≈ 130 |  
| 2021-01-07 | 120 + 10 \cdot N(0,1) ≈ 130 |  
| 2021-01-08 | 120 + 10 \cdot N(0,1) ≈ 130 |

#### 回归预测

假设我们有两个自变量（日期和促销活动），建立线性回归模型：

$$y = \beta_0 + \beta_1 \cdot 日期 + \beta_2 \cdot 促销活动$$

通过最小二乘法拟合得到模型参数：

$$\beta_0 = 100, \beta_1 = 5, \beta_2 = 10$$

然后，预测未来三天的销售量：

$$y = 100 + 5 \cdot 日期 + 10 \cdot 促销活动$$

假设 $日期=6,7,8$，$促销活动=0,1,0$，则预测结果如下：

| 日期 | 预测销售量 |  
| ---- | ------ |  
| 2021-01-06 | 100 + 5 \cdot 6 + 10 \cdot 0 ≈ 110 |  
| 2021-01-07 | 100 + 5 \cdot 7 + 10 \cdot 1 ≈ 120 |  
| 2021-01-08 | 100 + 5 \cdot 8 + 10 \cdot 0 ≈ 120 |

class Product(models.Model):

    type = models.CharField(max_length=50)
    description = models.TextField()
    price = models.DecimalField(max_digits=6, decimal_places=2)
    status = models.BooleanField(default=True)

    objects = ProductManager()

    def __str__(self):
        return self.name

# 订单管理
class Order(models.Model):
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    product = models.ForeignKey(Product, on_delete=models.CASCADE)
    quantity = models.IntegerField()
    status = models.CharField(max_length=20)

    def __str__(self):
        return f"{self.user.username} - {self.product.name}"

# 客户反馈管理
class CustomerFeedback(models.Model):
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    content = models.TextField()
    status = models.CharField(max_length=20)
