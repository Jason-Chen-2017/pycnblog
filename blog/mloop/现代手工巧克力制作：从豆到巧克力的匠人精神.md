### 第1章：巧克力基础知识

#### 1.1 巧克力的起源

巧克力，这种诱人的甜食，其历史可以追溯到数千年前的古代美洲。最早的巧克力并非我们今天所见的甜味糖果，而是由玛雅人和阿兹特克人使用的可可豆制成的饮料。这些古代文明将可可豆研磨成粉末，并加入水、香草和其他香料，形成了一种苦涩但具有刺激性的饮料。考古学家在墨西哥的特奥蒂瓦坎和特扎潘阿尔塔等地发现了公元前1000年左右的可可豆遗迹，这表明可可豆在当时已经被广泛使用。

到了阿兹特克时期，巧克力饮料被赋予了神圣的地位，只有王室和贵族才有资格享用。据历史记载，阿兹特克国王蒙特祖马一世在1521年接待西班牙探险家科尔特斯时，曾向他献上盛满巧克力的金杯，以示敬意和欢迎。这也标志着巧克力作为一种珍贵饮品，开始跨越大西洋传播到欧洲。

哥伦布于1502年第二次航行到美洲时，首次品尝到了可可豆饮品，并将其带回西班牙。西班牙人将可可豆引入欧洲后，巧克力的制作工艺逐渐得到改进。16世纪末，欧洲人开始将可可豆研磨成粉末，并加入糖和其他成分，使其成为一种甜味更浓的饮品。

#### 1.2 巧克力的分类

巧克力的种类繁多，根据不同的标准和成分，可以将其分为多种类型。以下是几种常见的巧克力分类：

1. **黑巧克力**：黑巧克力含有较高的可可固体含量，通常在70%以上。它以其浓郁的苦味和丰富的可可风味而闻名。黑巧克力中不含牛奶，因此更加强调可可的原味。

2. **牛奶巧克力**：牛奶巧克力含有较低的可可固体含量，通常在10%-40%之间，并添加了大量的牛奶。牛奶巧克力口感柔和，甜味较为突出。

3. **白巧克力**：白巧克力不含可可固体，主要成分是可可脂、牛奶和糖。它的口感甜腻，味道清新，但缺乏黑巧克力和牛奶巧克力那种浓郁的可可风味。

4. **无糖巧克力**：无糖巧克力通常不含蔗糖，而是使用其他甜味剂，如代糖或果糖。这种巧克力的热量较低，适合糖尿病患者或希望控制糖分摄入的人。

5. **酒心巧克力**：酒心巧克力是一种内部含有酒精的小巧克力，通常填充有各种烈酒或利口酒。这种巧克力不仅具有独特的口感，还能带来酒精的刺激感。

6. **巧克力涂层**：巧克力涂层通常用于覆盖其他食品，如水果、坚果或蛋糕。这类巧克力通常含有较低的可可固体含量，但具有良好的涂层效果和口感。

#### 1.3 巧克力的成分

巧克力的核心成分包括可可固体、可可脂、糖、牛奶和其他添加剂。以下是这些成分的具体作用：

1. **可可固体**：可可固体是巧克力中的主要成分，占巧克力总重量的15%-90%。它来自可可豆的研磨和提取，含有丰富的可可碱、咖啡因和多种酚类化合物，这些物质赋予了巧克力独特的苦味和风味。

2. **可可脂**：可可脂是从可可豆中提取的天然脂肪，占巧克力总重量的11%-30%。它是巧克力中的主要油脂成分，赋予了巧克力独特的光滑口感和丰富的口感层次。

3. **糖**：糖是巧克力的甜味来源，通常占巧克力总重量的30%-55%。糖的添加量可以根据巧克力类型进行调整，以平衡可可的苦味和提升整体的甜度。

4. **牛奶**：牛奶是牛奶巧克力的主要成分，通常占巧克力总重量的10%-40%。牛奶的添加使巧克力口感更加柔和，增加了奶香和甜味。

5. **添加剂**：巧克力的添加剂包括乳化剂、稳定剂和香料等。乳化剂如卵磷脂和可可脂稳定剂如单甘酯，有助于保持巧克力的稳定性和流动性。香料如香草粉则用于增强巧克力的风味。

#### 1.4 巧克力生产的步骤

巧克力生产是一个复杂的过程，涉及多个步骤和精细的工艺。以下是巧克力生产的基本步骤：

1. **可可豆的收获与处理**：可可豆生长在热带地区，成熟后从可可树上采摘下来。收获后的可可豆通常进行发酵、干燥和去皮等处理，以去除苦味并提升可可的香气。

2. **可可豆的研磨与提取**：经过处理的可可豆被研磨成粉末，并通过压榨提取出可可脂和可可固体。这个过程需要精确的温度控制，以确保可可粉的质量。

3. **巧克力混合与熔化**：将可可固体、可可脂、糖和其他添加剂混合在一起，并加热至熔化状态。这个过程需要不断搅拌，以确保成分均匀混合。

4. **巧克力调温**：调温是巧克力生产中至关重要的一步。通过控制温度，可以使巧克力在凝固时形成细腻的晶格结构，提升巧克力的光泽和口感。

5. **巧克力浇模**：熔化的巧克力被倒入模具中，并冷却凝固成块。这个过程中，巧克力的流动性、填充度和冷却速度都会影响最终的成品质量。

6. **巧克力切割与包装**：凝固后的巧克力被切割成小块，并进行包装。包装过程需要确保巧克力不受潮、不受污染，并保持其最佳风味和口感。

通过以上步骤，现代手工巧克力制作得以实现，每一块巧克力的背后都蕴含着匠人的智慧和匠心精神。

### 第2章：原料选择与处理

#### 2.1 可可豆的处理

可可豆是制作巧克力的核心原料，其质量直接影响最终产品的风味和品质。可可豆的处理过程包括采摘、发酵、干燥和去皮等步骤。

**采摘**：可可豆生长在可可树的果实中，果实通常在秋末至次年初成熟。采摘时，工人需要手工摘取成熟的果实，以确保每一颗可可豆都得到充分的成熟和养分。

**发酵**：采摘后的可可豆首先进行发酵处理。发酵过程中，可可豆内部的酶会分解豆内的糖分，产生一系列化学变化，包括酸度和风味的提升。传统的发酵方法是在木桶或塑料桶中堆积可可豆，并保持温度和湿度在适宜范围内，通常需要2-3天时间。

**干燥**：发酵后的可可豆需要进行干燥，以去除多余的水分，并进一步巩固风味。干燥方法包括自然晾晒和机械烘干。自然晾晒通常在阳光充足的地方进行，需要数天至一周时间。机械烘干则可以在较短时间内完成，但需要精确控制温度和湿度。

**去皮**：干燥后的可可豆需要去除其外层壳，得到可可豆的内核。去皮过程通常使用手工剥壳或机械剥壳设备，手工剥壳可以保留更多的可可风味，但效率较低；机械剥壳效率高，但可能会对可可豆的风味产生一定影响。

**研磨**：去皮后的可可豆被研磨成粉末，这一过程称为可可研磨。研磨需要在较低的温度下进行，以防止可可粉过热而破坏其风味和营养成分。研磨设备包括石磨和钢磨，石磨研磨出的可可粉具有更丰富的风味，但效率较低；钢磨则更高效，但可能对可可粉的口感产生一定影响。

**脱脂**：研磨后的可可粉中含有一定量的脂肪，需要通过脱脂处理分离出可可脂。脱脂过程通常使用溶剂萃取法，将可可粉与溶剂混合，通过加热和冷却分离出可可脂。脱脂后的可可粉即为可可固体，用于巧克力的制作。

**混合**：在最终制作巧克力之前，可可固体和可可脂通常需要与其他原料如糖、牛奶和添加剂混合。混合过程需要精确控制温度和搅拌速度，以确保各成分均匀分布。

通过以上步骤，可可豆从采摘到处理，再到最终成为巧克力的核心原料，这一过程中每一个环节都至关重要，影响着巧克力的风味和质量。

#### 2.2 糖的选择与使用

在巧克力制作过程中，糖起着至关重要的作用，不仅提供甜味，还影响巧克力的口感、质地和最终风味。不同类型的糖具有不同的物理和化学特性，因此选择合适的糖是制作高质量巧克力的重要环节。

**白砂糖**：白砂糖是最常用的糖类型，具有纯净的甜味和稳定的溶解性。它能够很好地与可可粉和可可脂混合，确保巧克力的口感和质地。白砂糖的颗粒大小也很重要，细砂糖能够更快地溶解，有助于巧克力的熔化过程，而粗砂糖则能够为巧克力带来轻微的颗粒感。

**黄糖**：黄糖在制作过程中加入了一些焦糖，使其具有独特的金黄色和略微的焦糖味。这种糖可以增强巧克力的风味，使其更加丰富和复杂。黄糖的颗粒较粗，可以增加巧克力的口感层次。

**糖粉**：糖粉是细磨的糖，非常适合用于涂抹和装饰巧克力。它的细腻质地使巧克力表面光滑，便于后续的涂层和装饰。糖粉也常用于巧克力蛋糕和甜点的填充和装饰，提升整体的甜度和口感。

**蜂蜜**：蜂蜜是一种天然的甜味剂，具有独特的花香和果味。在巧克力中加入蜂蜜，不仅能够提升巧克力的甜味，还能带来丰富的层次感和独特的风味。蜂蜜的黏性较高，有助于巧克力的粘合和涂抹，但需要注意其可能会影响巧克力的稳定性和保存时间。

**代糖**：对于需要控制糖分摄入的人群，可以使用代糖如赤藓糖醇、阿斯巴甜等替代普通糖。这些代糖具有较低的卡路里和甜度，能够在一定程度上模拟普通糖的口感。然而，代糖对巧克力的质地和风味有一定影响，可能使巧克力显得较为干燥或苦涩。

**混合使用**：在实际制作过程中，常常会混合使用多种糖类型，以实现最佳的口感和风味。例如，可以将白砂糖和黄糖混合使用，在保持巧克力的甜味的同时，增加其风味层次。糖粉和蜂蜜也可以与白砂糖混合，用于巧克力的涂抹和装饰，提升其整体的美观和口感。

选择合适的糖类型和调整糖的比例，不仅能够改善巧克力的口感，还能够显著影响其保存时间和稳定性。在巧克力制作过程中，需要根据具体需求和技术要求，精确控制糖的用量和使用方法，以确保最终产品的质量和风味。

#### 2.3 乳制品的应用

乳制品在巧克力制作中起着至关重要的作用，不仅提供了独特的风味，还显著影响了巧克力的质地和口感。乳制品的主要成分包括牛奶、奶油和乳脂，它们在巧克力中的应用各有特点。

**牛奶**：牛奶巧克力是以牛奶为主要成分的巧克力，其特点是口感柔和、甜味突出。牛奶巧克力中的牛奶含量通常在10%-40%之间，这种含量的牛奶可以平衡可可的苦味，并赋予巧克力丰富的奶香。牛奶的脂肪含量越高，巧克力口感越柔软，但同时也可能影响巧克力的稳定性和保存时间。

**奶油**：奶油在巧克力中的使用较为常见，主要用于增加巧克力的脂肪含量和口感。奶油的脂肪含量较高，可以显著提升巧克力的质地和滑顺度。奶油的加入可以使巧克力更加丰富和浓郁，但其较高的脂肪含量也意味着巧克力的热量较高。奶油的加入方式可以是直接混合，也可以是在巧克力熔化后慢慢加入，以确保均匀分布。

#### 3.1 巧克力的熔化与搅拌

**熔化过程**：

2. **温度控制**：将巧克力块放入熔化炉或搅拌机中，并逐渐加热至50-55°C。这个温度范围有助于巧克力逐渐熔化，同时保持其风味和营养成分。

3. **逐步加热**：在熔化过程中，应避免快速加热，以防止巧克力过热和出现结块。通常，熔化过程需要20-30分钟，期间应保持恒温。

4. **搅拌**：在巧克力熔化过程中，需要不断搅拌，以确保巧克力均匀混合。搅拌速度不宜过快，以免产生气泡或破坏巧克力的结构。

**搅拌过程**：

1. **均匀混合**：在巧克力完全熔化后，继续搅拌，以确保可可固体、可可脂、糖和牛奶等成分均匀分布。

2. **调温**：调温是巧克力搅拌过程中的一项关键操作，它能够确保巧克力在凝固时形成理想的晶格结构。巧克力熔化后的温度需要降至28-30°C，然后再升温至31-32°C。这个温度范围内，巧克力能够形成稳定、光滑的脂肪晶格。

3. **泡沫处理**：搅拌过程中，可能会产生一些泡沫。这些泡沫会影响巧克力的光滑度和口感，因此需要用搅拌棒或刮刀轻轻消除。

4. **结束搅拌**：当巧克力达到所需的温度和质地后，可以停止搅拌。此时，巧克力应具有良好的流动性和光滑度，没有明显的颗粒或结块。

3. **冷却**：将升温后的巧克力快速冷却至27-28°C。这个温度范围内，巧克力的脂肪晶格结构达到最佳状态，能够形成光滑、细腻的质地。

**调温的重要性**：

2. **口感**：调温后的巧克力质地细腻，口感顺滑，避免了因脂肪结晶不完全或过度结晶导致的颗粒感和苦味。

4. **美观**：调温后的巧克力在浇模和装饰时，能够更好地保持形状和细节，提升整体美观度。

通过精确的调温操作，巧克力的品质和风味能够得到显著提升。调温不仅需要掌握正确的温度范围，还需要在实际操作中不断调整和优化，以确保每一块巧克力的质量和口感达到最佳。

3. **冷冻保存**：将巧克力放入冷冻室，温度应控制在-18°C以下。冷冻保存可以延长巧克力的保质期，但取出后应尽快食用，以避免反复冷冻和解冻对巧克力质地的破坏。

2. **密封保存**：使用密封容器或食品保鲜膜，将巧克力密封保存。密封保存可以防止空气中的湿气和异味对巧克力的影响，同时保持巧克力的新鲜度和风味。

**储存位置**：

1. **远离光源**：避免将巧克力放置在阳光直射或强光照射的地方，光照可能导致巧克力变色或变质。

**注意事项**：

1. **避免振动**：在运输和储存过程中，避免振动对巧克力造成损害，振动可能导致巧克力内部结构受损，影响质地和口感。
2. **分开放置**：不同类型的巧克力应分开保存，避免相互影响。例如，黑巧克力与牛奶巧克力分开，以避免黑巧克力的苦味影响牛奶巧克力的口感。

2. **搅拌棒**：用于搅拌巧克力，使成分均匀混合。
3. **巧克力模具**：用于浇模和成型巧克力。
4. **刮刀**：用于平整巧克力表面，去除气泡。
5. **剪刀**：用于剪裁巧克力贴纸或装饰材料。
6. **喷枪**：用于喷涂巧克力涂层。
7. **巧克力贴纸或模具**：用于装饰巧克力。
8. **称量器**：用于精确称量巧克力和其他原料。

**使用说明**：

1. **巧克力熔化炉**：将巧克力块放入熔化炉中，预热至50-55°C，并缓慢加热至完全熔化。注意不要过热，以免巧克力变质。
2. **搅拌棒**：在巧克力熔化过程中，使用搅拌棒不断搅拌，以确保成分均匀混合。
3. **巧克力模具**：选择合适的模具，将熔化后的巧克力倒入模具中，轻轻震动模具，帮助气泡上升并排出。

5. **喷枪**：在巧克力凝固前，使用喷枪喷涂一层巧克力涂层，以增加其光泽和装饰性。
6. **巧克力贴纸或模具**：在巧克力凝固后，使用贴纸或模具进行装饰，创造独特的图案和形状。
7. **称量器**：在使用任何原料前，使用称量器精确称量，以确保巧克力配方的准确性和一致性。

**6. 保存与运输**：巧克力的保存和运输也是确保其质量和口感的关键。应将巧克力存放在干燥、阴凉的地方，避免高温和阳光直射。运输过程中，应使用防潮和防震的包装材料，确保巧克力在运输过程中不受损害。

### 注意事项

在手工巧克力制作过程中，有一些常见的错误和注意事项需要特别注意，以确保制作过程顺利，最终产品的质量和口感得到保障。

**1. 过度加热**：巧克力对温度非常敏感，过度加热会导致其变质或出现“烧焦味”。在熔化巧克力时，应控制好温度，避免超过60°C，以免破坏巧克力的结构和风味。

**2. 搅拌不均**：搅拌不均可能导致巧克力中产生气泡或出现分层现象，影响巧克力的光滑度和口感。在熔化过程中，应使用搅拌棒不断、均匀地搅拌，确保巧克力混合均匀。

**3. 温度控制不当**：巧克力在熔化、调温、冷却等过程中，温度控制至关重要。温度过高或过低都会影响巧克力的质地和口感。应严格按照推荐的温度范围进行操作。

**4. 模具清洁不彻底**：模具上的灰尘或油脂会导致巧克力无法顺利脱模或影响巧克力表面光滑度。在浇模前，应确保模具彻底清洗干净并完全干燥。

**5. 装饰不当**：巧克力装饰时，应选择合适的工具和材料，并按照正确的方法进行操作。喷涂、雕刻和贴纸等装饰技巧需要熟练掌握，以免影响巧克力的外观和质感。

**6. 保存环境不当**：巧克力的保存环境应干燥、阴凉，避免高温、阳光直射和潮湿。不当的保存环境会导致巧克力吸潮变软、变质或失去原有风味。

**7. 使用过期原料**：使用过期或变质的原料可能导致巧克力品质下降。在制作前，应检查所有原料的保质期，确保其新鲜、合格。

通过避免上述常见错误，并严格按照操作步骤进行，可以确保手工巧克力制作过程顺利进行，最终获得高质量的巧克力产品。
