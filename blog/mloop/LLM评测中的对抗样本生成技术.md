- **自然语言处理（NLP）**：研究如何让计算机理解和处理人类语言的技术，包括文本分类、情感分析、机器翻译等任务。

**问题背景说明**：

- **对抗性攻击**：一种通过在原始样本上添加微小扰动，导致模型预测错误的攻击手段。
- **对抗样本**：在原始样本基础上添加微小扰动后得到的样本，用于评估模型在对抗性攻击下的性能。

**问题描述说明**：

## 1.2 对抗样本生成技术的核心概念与联系

### 1.2.1 对抗性攻击

对抗性攻击是一种通过在原始样本上添加微小扰动，使模型预测错误的攻击手段。其核心在于扰动的大小和方向，使得人类无法察觉，但足以影响模型输出。

**概念属性特征对比表格**：

| 特征       | 对抗性攻击          | 非对抗性攻击          |
| ---------- | ------------------- | --------------------- |
| 不可检测性 | 微小扰动，人类难以察觉 | 明显扰动，人类容易察觉 |
| 破坏性     | 影响模型输出       | 不影响模型输出        |
| 针对性     | 针对特定模型       | 针对所有模型          |

**ER实体关系图架构的Mermaid流程图**：

```mermaid

  Model ||--|{ Attack }|--| Adversarial Attack
  Model ||--|{ Attack }|--| Non-Adversarial Attack
```

**对抗性攻击的特点**：

1. **不可检测性**：对抗性攻击添加的扰动微小，人类难以察觉。
2. **破坏性**：对抗性攻击可以导致模型预测错误，从而降低模型性能。
3. **针对性**：对抗性攻击可以根据特定目标，设计针对特定模型的攻击策略。

**对抗性攻击的类型**：

1. **白盒攻击**：攻击者拥有模型的内部结构信息，可以直接对模型进行攻击。
2. **黑盒攻击**：攻击者无法获取模型内部结构信息，只能通过观察模型输出进行攻击。

### 1.2.2 扰动生成方法

扰动生成方法是生成对抗样本的关键步骤，主要包括以下几种方法：

1. **线性变换**：通过线性变换将原始样本映射到对抗样本空间，如L2范数、L∞范数等。
2. **非线性变换**：通过非线性函数，如ReLU、Sigmoid等，将原始样本转换为对抗样本。
3. **生成对抗网络（GAN）**：通过生成对抗网络，将原始样本与对抗样本进行对抗训练，从而生成高质量的对抗样本。

| ---------- | ---------------- | ------------------- | --------------- |
| 可控性     | 较高            | 较高                | 较高            |
| 计算复杂度 | 较低            | 较低                | 较高            |
| 生成质量   | 较高            | 较高                | 较高            |

```mermaid
  Sample ||--|{ Transform }|--| Nonlinear Transform
  Sample ||--|{ Transform }|--| GAN
```

**扰动生成方法的特点**：

1. **可控性**：可以通过调整变换参数，控制扰动的大小和方向。
2. **高效性**：线性变换方法通常具有较低的计算复杂度。
3. **多样性**：非线性变换和GAN方法可以生成多种类型的对抗样本，提高攻击的多样性。

### 1.2.3 对抗性训练与对抗性测试

对抗性训练和对抗性测试是评估LLM鲁棒性的重要手段。

**对抗性训练的特点**：
