3. **关键词提取**：关键词提取是提示词优化的核心环节。通过分析文本内容，提取出对任务至关重要的关键词，从而为AI系统提供更精确的输入。

4. **语境调整**：语境调整是指根据上下文环境，对关键词进行适当的修改和调整。这有助于确保AI系统在处理任务时，能够更好地理解上下文信息。

    # 分词

    return tokens

def extract_keywords(text):
    # 使用TF-IDF模型提取关键词
    from sklearn.feature_extraction.text import TfidfVectorizer
    vectorizer = TfidfVectorizer()
    X = vectorizer.fit_transform([text])
    feature_array = vectorizer.get_feature_names_out()
    tfidf_scores = X.toarray().flatten()
    top_keywords = feature_array[np.argsort(tfidf_scores)[-10:]]
    return top_keywords

# 语义增强
def enhance_semantics(keywords, keyword_table):
    # 添加定义、解释等辅助信息

    return enhanced_keywords

# 语境调整
def adjust_context(keywords, context):
    # 根据上下文调整关键词

AI批判性思维能力是指人工智能系统在处理复杂问题时，能够运用逻辑推理、批判性分析、创造性思维等能力，对信息进行深入理解和评估。与传统的数据驱动和机器学习算法不同，批判性思维能力强调AI系统在处理任务时的主观判断和推理能力，从而能够更灵活、更智能地应对各种复杂的任务场景。

#### 3.1.1 AI批判性思维能力的概念

AI批判性思维能力主要包括以下几个核心概念：

1. **逻辑推理**：逻辑推理是指基于已知事实和前提，通过逻辑规则推导出新结论的过程。在AI系统中，逻辑推理可以帮助系统从输入信息中提取有用的知识，并推导出新的结论。

2. **批判性分析**：批判性分析是指对信息进行深入分析和评估，以识别信息中的矛盾、错误或偏差。在AI系统中，批判性分析可以帮助系统识别和纠正自身的错误，提高系统的鲁棒性。

3. **创造性思维**：创造性思维是指产生新想法、新方法和新解决方案的思维能力。在AI系统中，创造性思维可以帮助系统在面对未知或复杂问题时，提出创新的解决方案。

#### 3.1.2 AI批判性思维能力的核心要素

AI批判性思维能力的核心要素包括以下几个方面：

1. **知识表示**：知识表示是指将人类知识以计算机可处理的形式进行编码和存储。在AI系统中，知识表示是实现批判性思维能力的基础，通过准确的知识表示，系统可以更好地理解和应用知识。

2. **推理能力**：推理能力是指系统能够基于已知信息，通过逻辑推理得出新结论的能力。在AI系统中，推理能力是实现批判性思维能力的关键，通过高效的推理算法，系统可以在复杂环境中做出准确的判断。

3. **自主学习**：自主学习是指系统能够通过不断的学习和优化，提高自身的性能和适应能力。在AI系统中，自主学习是实现批判性思维能力的重要途径，通过不断的学习，系统可以不断提高自身的推理和分析能力。

4. **适应能力**：适应能力是指系统能够根据环境变化，灵活调整自身的策略和行为。在AI系统中，适应能力是实现批判性思维能力的关键，通过适应环境变化，系统可以更好地应对复杂和动态的任务场景。
