### 2.1 新斯多葛主义核心概念

新斯多葛主义的核心概念包括理性、自我控制和逆境。以下是这些概念的具体解释：

#### 理性

理性是新斯多葛主义的首要原则。它认为，理性是人类最重要的品质，通过理性思考，人们可以更好地认识自己和世界。理性不仅帮助人们做出明智的决策，还能使人们更加客观地看待问题，从而减少情绪的干扰。

$$
\text{理性} = \frac{\text{客观事实} + \text{逻辑推理}}{\text{情感因素}}
$$

#### 自我控制

自我控制是指人们应该学会控制自己的情绪和欲望，以实现内心的平和。新斯多葛主义认为，只有通过自我控制，人们才能在面对挑战时保持冷静和理智，从而更好地应对困境。

$$
\text{自我控制} = \frac{\text{情绪调节} + \text{欲望管理}}{\text{内心平和}}
$$

#### 逆境

新斯多葛主义认为，逆境是人生的常态。人们应该学会接受并面对逆境，从中汲取智慧，以实现个人成长。逆境并不是坏事，而是人生成长的一部分。

$$
\text{逆境} = \frac{\text{挑战} + \text{机会}}{\text{成长}}
$$

@RestController
@RequestMapping("/courses")
public class CourseController {

    @Autowired
    private CourseService courseService;

    @PostMapping
    public ResponseEntity<Course> createCourse(@RequestBody Course course) {
        Course savedCourse = courseService.createCourse(course);
        return new ResponseEntity<Course>(savedCourse, HttpStatus.CREATED);
    }

    @GetMapping
    public ResponseEntity<List<Course>> getAllCourses() {
        List<Course> courses = courseService.getAllCourses();
        return new ResponseEntity<List<Course>>(courses, HttpStatus.OK);
    }

    @PutMapping("/{courseId}")
    public ResponseEntity<Course> updateCourse(@PathVariable Long courseId, @RequestBody Course course) {
        Course updatedCourse = courseService.updateCourse(courseId, course);
        return new ResponseEntity<Course>(updatedCourse, HttpStatus.OK);
    }

    @DeleteMapping("/{courseId}")
    public ResponseEntity<Void> deleteCourse(@PathVariable Long courseId) {
        courseService.deleteCourse(courseId);
        return new ResponseEntity<Void>(HttpStatus.NO_CONTENT);
    }
}
