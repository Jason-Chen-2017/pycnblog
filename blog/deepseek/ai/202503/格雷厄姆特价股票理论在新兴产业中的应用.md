## 3. 核心算法原理 & 具体操作步骤 

### 核心算法原理
格雷厄姆特价股票理论的核心算法是计算股票的内在价值和安全边际。常见的计算内在价值的方法有市盈率法（PE）、市净率法（PB）和现金流折现法（DCF）。

#### 市盈率法（PE）
市盈率法是通过公司的每股收益（EPS）和行业平均市盈率（PE）来计算股票的内在价值。公式为：
$$V = EPS \times PE_{avg}$$
其中，$V$ 表示股票的内在价值，$EPS$ 表示每股收益，$PE_{avg}$ 表示行业平均市盈率。

#### 市净率法（PB）
市净率法是通过公司的每股净资产（BVPS）和行业平均市净率（PB）来计算股票的内在价值。公式为：
$$V = BVPS \times PB_{avg}$$
其中，$V$ 表示股票的内在价值，$BVPS$ 表示每股净资产，$PB_{avg}$ 表示行业平均市净率。

#### 现金流折现法（DCF）
现金流折现法是通过预测公司未来的现金流，并将其折现到当前时点来计算股票的内在价值。公式为：
$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$
其中，$V$ 表示股票的内在价值，$CF_t$ 表示第 $t$ 年的现金流，$r$ 表示折现率，$n$ 表示预测期数，$TV$ 表示终值。

### 具体操作步骤
以下是使用Python实现上述算法的具体代码：

```python
# 市盈率法计算内在价值
def pe_valuation(eps, pe_avg):
    """
    使用市盈率法计算股票的内在价值
    :param eps: 每股收益
    :param pe_avg: 行业平均市盈率
    :return: 股票的内在价值
    """
    return eps * pe_avg

# 市净率法计算内在价值
def pb_valuation(bvps, pb_avg):
    """
    使用市净率法计算股票的内在价值
    :param bvps: 每股净资产
    :param pb_avg: 行业平均市净率
    :return: 股票的内在价值
    """
    return bvps * pb_avg

# 现金流折现法计算内在价值
def dcf_valuation(cash_flows, discount_rate, terminal_value):
    """
    使用现金流折现法计算股票的内在价值
    :param cash_flows: 未来各年的现金流列表
    :param discount_rate: 折现率
    :param terminal_value: 终值
    :return: 股票的内在价值
    """
    n = len(cash_flows)
    present_value = 0
    for t in range(n):
        present_value += cash_flows[t] / ((1 + discount_rate) ** (t + 1))
    present_value += terminal_value / ((1 + discount_rate) ** n)
    return present_value

# 示例数据
eps = 2.0  # 每股收益
pe_avg = 15  # 行业平均市盈率
bvps = 10.0  # 每股净资产
pb_avg = 2.0  # 行业平均市净率
cash_flows = [100, 120, 150, 180, 200]  # 未来5年的现金流
discount_rate = 0.1  # 折现率
terminal_value = 1000  # 终值

# 计算内在价值
pe_value = pe_valuation(eps, pe_avg)
pb_value = pb_valuation(bvps, pb_avg)
dcf_value = dcf_valuation(cash_flows, discount_rate, terminal_value)

print(f"市盈率法计算的内在价值: {pe_value}")
print(f"市净率法计算的内在价值: {pb_value}")
print(f"现金流折现法计算的内在价值: {dcf_value}")
```

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 市盈率法（PE）
#### 数学公式
$$V = EPS \times PE_{avg}$$

#### 详细讲解
市盈率法是一种简单直观的计算股票内在价值的方法。每股收益（EPS）反映了公司的盈利能力，行业平均市盈率（$PE_{avg}$）反映了市场对该行业的估值水平。通过将每股收益乘以行业平均市盈率，我们可以得到一个大致的股票内在价值。

#### 举例说明
假设一家新兴产业公司的每股收益为 $2$ 元，该行业的平均市盈率为 $15$ 倍。则使用市盈率法计算的该股票的内在价值为：
$$V = 2 \times 15 = 30$$（元）

### 市净率法（PB）
#### 数学公式
$$V = BVPS \times PB_{avg}$$

#### 详细讲解
市净率法主要关注公司的净资产。每股净资产（BVPS）反映了公司每股股票所代表的净资产价值，行业平均市净率（$PB_{avg}$）反映了市场对该行业净资产的估值水平。通过将每股净资产乘以行业平均市净率，我们可以得到股票的内在价值。

#### 举例说明
假设一家新兴产业公司的每股净资产为 $10$ 元，该行业的平均市净率为 $2$ 倍。则使用市净率法计算的该股票的内在价值为：
$$V = 10 \times 2 = 20$$（元）

### 现金流折现法（DCF）
#### 数学公式
$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$

#### 详细讲解
现金流折现法是一种更为复杂但也更为准确的计算股票内在价值的方法。它考虑了公司未来的现金流和资金的时间价值。$CF_t$ 表示第 $t$ 年的现金流，$r$ 表示折现率，$n$ 表示预测期数，$TV$ 表示终值。通过将未来各年的现金流折现到当前时点，并加上终值的折现值，我们可以得到股票的内在价值。

#### 举例说明
假设一家新兴产业公司未来5年的现金流分别为 $100$ 万元、$120$ 万元、$150$ 万元、$180$ 万元、$200$ 万元，折现率为 $10\%$，终值为 $1000$ 万元。则使用现金流折现法计算的该股票的内在价值为：

首先计算每年现金流的折现值：
- 第1年：$\frac{100}{(1 + 0.1)^1} \approx 90.91$（万元）
- 第2年：$\frac{120}{(1 + 0.1)^2} \approx 99.17$（万元）
- 第3年：$\frac{150}{(1 + 0.1)^3} \approx 112.70$（万元）
- 第4年：$\frac{180}{(1 + 0.1)^4} \approx 122.94$（万元）
- 第5年：$\frac{200}{(1 + 0.1)^5} \approx 124.18$（万元）

然后计算终值的折现值：
$\frac{1000}{(1 + 0.1)^5} \approx 620.92$（万元）

最后将各年现金流折现值和终值折现值相加：
$V = 90.91 + 99.17 + 112.70 + 122.94 + 124.18 + 620.92 \approx 1170.82$（万元）

```python
import pandas as pd
import numpy as np

# 市盈率法计算内在价值
def pe_valuation(eps, pe_avg):
    return eps * pe_avg

# 市净率法计算内在价值
def pb_valuation(bvps, pb_avg):
    return bvps * pb_avg

# 现金流折现法计算内在价值
def dcf_valuation(cash_flows, discount_rate, terminal_value):
    n = len(cash_flows)
    present_value = 0
    for t in range(n):
        present_value += cash_flows[t] / ((1 + discount_rate) ** (t + 1))
    present_value += terminal_value / ((1 + discount_rate) ** n)
    return present_value

# 计算安全边际
def safety_margin(intrinsic_value, market_price):
    return (intrinsic_value - market_price) / intrinsic_value

# 示例数据
data = {
    '公司名称': ['新兴科技公司A', '新兴科技公司B'],
    '每股收益': [2.0, 1.5],
    '每股净资产': [10.0, 8.0],
    '行业平均市盈率': [15, 15],
    '行业平均市净率': [2.0, 2.0],
    '未来现金流': [
        [100, 120, 150, 180, 200],
        [80, 100, 120, 140, 160]
    ],
    '折现率': [0.1, 0.1],
    '终值': [1000, 800],
    '市场价格': [25, 20]
}

df = pd.DataFrame(data)

# 计算内在价值和安全边际
pe_values = []
pb_values = []
dcf_values = []
safety_margins_pe = []
safety_margins_pb = []
safety_margins_dcf = []

for index, row in df.iterrows():
    eps = row['每股收益']
    bvps = row['每股净资产']
    pe_avg = row['行业平均市盈率']
    pb_avg = row['行业平均市净率']
    cash_flows = row['未来现金流']
    discount_rate = row['折现率']
    terminal_value = row['终值']
    market_price = row['市场价格']

    pe_value = pe_valuation(eps, pe_avg)
    pb_value = pb_valuation(bvps, pb_avg)
    dcf_value = dcf_valuation(cash_flows, discount_rate, terminal_value)

    safety_margin_pe = safety_margin(pe_value, market_price)
    safety_margin_pb = safety_margin(pb_value, market_price)
    safety_margin_dcf = safety_margin(dcf_value, market_price)

    pe_values.append(pe_value)
    pb_values.append(pb_value)
    dcf_values.append(dcf_value)
    safety_margins_pe.append(safety_margin_pe)
    safety_margins_pb.append(safety_margin_pb)
    safety_margins_dcf.append(safety_margin_dcf)

df['PE内在价值'] = pe_values
df['PB内在价值'] = pb_values
df['DCF内在价值'] = dcf_values
df['PE安全边际'] = safety_margins_pe
```
