### 1.4 术语表
#### 1.4.1 核心术语定义
- **全球股市估值**：指对全球范围内各个股票市场上上市公司的价值进行评估的过程和结果。通常通过市盈率、市净率等指标来衡量。
- **可持续城市**：是指在满足当代人需求的同时，不损害后代人满足其自身需求的能力，实现经济、社会和环境协调发展的城市。
- **垂直绿化技术**：是一种在建筑物垂直表面种植植物的技术，包括墙面绿化、屋顶绿化等多种形式，旨在增加城市绿色空间、改善环境质量。

#### 1.4.2 相关概念解释
- **股市板块**：是对股票市场中具有相同特征或行业属性的股票进行分类的概念。例如，环保板块、科技板块等。
- **环境效益**：指垂直绿化技术在改善空气质量、降低城市热岛效应、减少噪音等方面所带来的环境改善效果。
- **经济效益**：包括垂直绿化技术在房地产增值、能源节约等方面所产生的经济收益，以及对相关股票市场的影响。

#### 1.4.3 缩略词列表
- **PE**：市盈率（Price-to-Earnings Ratio），是指股票价格除以每股收益的比率，用于衡量股票的估值水平。
- **PB**：市净率（Price-to-Book Ratio），是指股票价格与每股净资产的比率，反映了市场对公司净资产的估值。

## 2. 核心概念与联系 

### 2.1 全球股市估值的原理和架构
全球股市估值是一个复杂的过程，涉及到多个因素的综合考量。其基本原理是通过对上市公司的财务状况、盈利能力、市场前景等因素进行分析，来确定股票的合理价值。常见的估值方法包括市盈率法、市净率法、现金流折现法等。

从架构上看，全球股市估值受到宏观经济环境、行业发展趋势、公司自身业绩等多个层面的影响。宏观经济环境如GDP增长率、通货膨胀率、利率等会影响整个股市的表现；行业发展趋势决定了不同板块的估值差异；公司自身业绩则是影响个股估值的关键因素。

以下是全球股市估值的Mermaid流程图：
```mermaid

    A[宏观经济环境] --> B[全球股市估值]
    C[行业发展趋势] --> B
    D[公司自身业绩] --> B
    B --> E[股票价格]
```

### 2.2 可持续城市垂直绿化技术的原理和架构
可持续城市垂直绿化技术的核心原理是利用植物的生态功能，通过在建筑物垂直表面种植植物，实现城市生态环境的改善。其架构主要包括植物选择、种植系统设计、灌溉与养护等环节。

植物选择需要考虑当地的气候条件、建筑物朝向、植物的适应性等因素；种植系统设计包括种植容器、支撑结构等的设计，要确保植物能够稳定生长；灌溉与养护则是保证植物健康生长的关键，需要根据植物的需求进行合理的浇水、施肥和病虫害防治。

全球股市估值与可持续城市垂直绿化技术之间存在着多方面的联系。从经济层面来看，垂直绿化技术的发展可能会带动相关产业的兴起，如植物种植、绿化工程建设、灌溉设备制造等，这些产业的发展会影响相关上市公司的业绩，进而影响股市估值。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 4.1 皮尔逊相关系数
皮尔逊相关系数是衡量两个变量之间线性相关性的常用指标，其计算公式为：
$$
r = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n} (x_i - \bar{x})^2 \sum_{i=1}^{n} (y_i - \bar{y})^2}}
$$
其中，$x_i$ 和 $y_i$ 分别是两个变量的第 $i$ 个观测值，$\bar{x}$ 和 $\bar{y}$ 分别是两个变量的均值，$n$ 是观测值的数量。

皮尔逊相关系数的取值范围是 $[-1, 1]$，当 $r = 1$ 时，表示两个变量完全正相关；当 $r = -1$ 时，表示两个变量完全负相关；当 $r = 0$ 时，表示两个变量之间不存在线性相关性。

例如，假设我们有两组数据：$x = [1, 2, 3, 4, 5]$ 和 $y = [2, 4, 6, 8, 10]$，可以使用上述公式计算它们的皮尔逊相关系数：
```python
import numpy as np

x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 6, 8, 10])

corr_coef = np.corrcoef(x, y)[0, 1]
print(f'皮尔逊相关系数: {corr_coef}')
```

### 4.2 线性回归模型
线性回归模型是一种用于描述自变量和因变量之间线性关系的统计模型，其一般形式为：
$$
y = \beta_0 + \beta_1 x + \epsilon
$$
其中，$y$ 是因变量，$x$ 是自变量，$\beta_0$ 是截距，$\beta_1$ 是回归系数，$\epsilon$ 是误差项。

线性回归的目标是找到一组最优的 $\beta_0$ 和 $\beta_1$，使得模型的预测值与实际值之间的误差最小。常用的方法是最小二乘法，即最小化误差平方和：
$$
\min_{\beta_0, \beta_1} \sum_{i=1}^{n} (y_i - (\beta_0 + \beta_1 x_i))^2
$$

例如，假设我们有一组数据：$x = [1, 2, 3, 4, 5]$ 和 $y = [2, 4, 6, 8, 10]$，可以使用最小二乘法拟合线性回归模型：
```python
from sklearn.linear_model import LinearRegression
import numpy as np

x = np.array([1, 2, 3, 4, 5]).reshape(-1, 1)
y = np.array([2, 4, 6, 8, 10])

model = LinearRegression()
model.fit(x, y)

print(f'回归系数: {model.coef_[0]}')
print(f'截距: {model.intercept_}')
```
