### 1.4 术语表
#### 1.4.1 核心术语定义
- **净净股票（Net-Net Stocks）**：指那些股票价格低于其净流动资产价值（Net Current Asset Value，NCAV）的股票。净流动资产价值是指公司的流动资产减去全部负债后的价值。
- **净流动资产价值（NCAV）**：计算公式为 $NCAV = 流动资产 - 全部负债$。它反映了公司在清算情况下，股东可能获得的最低价值。
- **价值投资（Value Investing）**：一种投资策略，强调寻找市场中被低估的资产，通过分析公司的基本面，如财务状况、盈利能力等，以低于其内在价值的价格买入股票，等待市场发现其价值并实现价格回归。

#### 1.4.2 相关概念解释
- **流动资产**：指企业可以在一年或者超过一年的一个营业周期内变现或者运用的资产，包括现金、短期投资、应收账款、存货等。
- **负债**：指企业过去的交易或者事项形成的、预期会导致经济利益流出企业的现时义务，包括短期负债和长期负债。
- **清算价值**：指公司在面临破产清算时，将其资产出售变现后，扣除所有负债后股东可能获得的价值。

#### 1.4.3 缩略词列表
- **NCAV**：Net Current Asset Value，净流动资产价值

## 2. 核心概念与联系 

### 核心概念原理
格雷厄姆的净净股票策略基于一个简单而深刻的原理：当股票价格低于公司的净流动资产价值时，意味着市场对该公司的估值过低，存在投资机会。从理论上讲，即使公司立即停止运营并进行清算，股东也有可能获得高于股票市场价格的回报。

净净股票策略的核心在于对公司财务报表的分析，特别是对流动资产和负债的评估。通过计算净流动资产价值，投资者可以确定一个公司的内在价值底线。如果股票价格低于这个底线，那么该股票就被认为是极度低估的。

## 3. 核心算法原理 & 具体操作步骤 

### 核心算法原理
净净股票策略的核心算法是计算公司的净流动资产价值（NCAV），并将其与股票市场价格进行比较。具体步骤如下：
1. **获取公司财务数据**：从公司的财务报表中获取流动资产和全部负债的数据。
2. **计算净流动资产价值（NCAV）**：使用公式 $NCAV = 流动资产 - 全部负债$ 计算公司的净流动资产价值。
3. **获取股票市场价格**：通过金融数据提供商或证券交易所获取该公司股票的当前市场价格。
4. **比较股票价格与 NCAV**：如果股票价格低于 NCAV，则该股票被认为是净净股票，具有投资价值。

### Python 代码实现
```python
import pandas as pd

def calculate_ncav(current_assets, total_liabilities):
    """
    计算净流动资产价值（NCAV）
    :param current_assets: 流动资产
    :param total_liabilities: 全部负债
    :return: 净流动资产价值
    """
    return current_assets - total_liabilities

def find_net_net_stocks(financial_data, stock_prices):
    """
    寻找净净股票
    :param financial_data: 包含流动资产和全部负债的财务数据 DataFrame
    :param stock_prices: 包含股票价格的 DataFrame
    :return: 净净股票列表
    """
    net_net_stocks = []
    for index, row in financial_data.iterrows():
        company = index
        current_assets = row['Current Assets']
        total_liabilities = row['Total Liabilities']
        ncav = calculate_ncav(current_assets, total_liabilities)
        stock_price = stock_prices.loc[company, 'Stock Price']
        if stock_price < ncav:
            net_net_stocks.append(company)
    return net_net_stocks

# 示例数据
financial_data = pd.DataFrame({
    'Current Assets': [1000, 2000, 1500],
    'Total Liabilities': [500, 1200, 800]
}, index=['Company A', 'Company B', 'Company C'])

stock_prices = pd.DataFrame({
    'Stock Price': [400, 1300, 600]
}, index=['Company A', 'Company B', 'Company C'])

# 寻找净净股票
net_net_stocks = find_net_net_stocks(financial_data, stock_prices)
print("净净股票列表:", net_net_stocks)
```
### 代码解释
- `calculate_ncav` 函数：接受流动资产和全部负债作为输入，返回净流动资产价值。
- `find_net_net_stocks` 函数：遍历财务数据，计算每个公司的 NCAV，并与股票价格进行比较。如果股票价格低于 NCAV，则将该公司添加到净净股票列表中。
- 示例数据部分：创建了包含三家公司的财务数据和股票价格的 DataFrame。
- 最后调用 `find_net_net_stocks` 函数，输出净净股票列表。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 数学模型和公式
净净股票策略的核心数学模型是计算净流动资产价值（NCAV），公式为：
$$NCAV = 流动资产 - 全部负债$$

### 详细讲解
- **流动资产**：包括现金、短期投资、应收账款、存货等。这些资产通常可以在较短时间内变现，是公司短期内可支配的资源。
- **全部负债**：包括短期负债和长期负债，如应付账款、短期借款、长期债券等。这些是公司需要在未来偿还的债务。
- **净流动资产价值（NCAV）**：反映了公司在清算情况下，扣除所有负债后，股东可能获得的最低价值。如果股票价格低于 NCAV，意味着市场对公司的估值过低，可能存在投资机会。

### 举例说明
假设公司 X 的财务报表显示，其流动资产为 2000 万元，全部负债为 1200 万元。则该公司的净流动资产价值为：
$$NCAV = 2000 - 1200 = 800 \text{（万元）}$$
如果公司 X 的股票总市值为 600 万元，即股票价格低于其净流动资产价值，那么根据净净股票策略，该股票可能被认为是极度低估的，具有投资价值。

### 5.2  源代码详细实现和代码解读
```python
import pandas as pd
import yfinance as yf

def get_financial_data(ticker):
    """
    获取公司的财务数据
    :param ticker: 股票代码
    :return: 包含流动资产和全部负债的 DataFrame
    """
    stock = yf.Ticker(ticker)
    balance_sheet = stock.balance_sheet
    current_assets = balance_sheet.loc['Total Current Assets'].iloc[0]
    total_liabilities = balance_sheet.loc['Total Liab'].iloc[0]
    return pd.DataFrame({
        'Current Assets': [current_assets],
        'Total Liabilities': [total_liabilities]
    })

def get_stock_price(ticker):
    """
    获取股票的当前价格
    :param ticker: 股票代码
    :return: 股票当前价格
    """
    stock = yf.Ticker(ticker)
    data = stock.history(period='1d')
    return data['Close'].iloc[0]

def check_net_net_stock(ticker):
    """
    检查股票是否为净净股票
    :param ticker: 股票代码
    :return: 是否为净净股票的布尔值
    """
    financial_data = get_financial_data(ticker)
    current_assets = financial_data['Current Assets'].iloc[0]
    total_liabilities = financial_data['Total Liabilities'].iloc[0]
    ncav = calculate_ncav(current_assets, total_liabilities)
    stock_price = get_stock_price(ticker)
    return stock_price < ncav

# 示例：检查苹果公司（AAPL）是否为净净股票
ticker = 'AAPL'
is_net_net = check_net_net_stock(ticker)
print(f"{ticker} 是否为净净股票: {is_net_net}")
```
### 代码解读
- `get_financial_data` 函数：使用 `yfinance` 库获取指定股票代码公司的资产负债表数据，提取流动资产和全部负债信息，并返回一个包含这些信息的 DataFrame。
- `get_stock_price` 函数：使用 `yfinance` 库获取指定股票代码的当前收盘价。
- `check_net_net_stock` 函数：调用 `get_financial_data` 和 `get_stock_price` 函数，计算净流动资产价值（NCAV），并将股票价格与 NCAV 进行比较，返回该股票是否为净净股票的布尔值。
- 示例部分：检查苹果公司（AAPL）是否为净净股票，并输出结果。

### 5.3  代码解读与分析
- **数据获取**：通过 `yfinance` 库可以方便地获取股票的财务数据和市场价格。但需要注意的是，`yfinance` 库的数据可能存在一定的延迟和误差，在实际应用中可以考虑使用更专业的金融数据提供商。
- **净净股票判断**：通过比较股票价格和 NCAV 来判断股票是否为净净股票。如果股票价格低于 NCAV，则认为该股票具有投资价值。但需要注意的是，净净股票策略并不是绝对的，还需要考虑公司的基本面、行业前景等因素。

## 6. 实际应用场景 
### 价值投资组合构建
投资者可以使用净净股票策略筛选出被市场极度低估的股票，将其纳入价值投资组合中。通过分散投资多只净净股票，可以降低投资风险，同时期待这些股票在市场发现其价值后实现价格上涨，从而获得超额收益。

### 逆向投资策略
净净股票通常是市场上被忽视或不被看好的公司。采用逆向投资策略的投资者可以利用这一特点，在市场对这些公司悲观时买入，等待市场情绪好转和公司基本面改善，从而实现投资回报。

### 小型股和新兴市场投资
在小型股市场和新兴市场中，由于信息不对称和市场效率较低，更容易出现被低估的净净股票。投资者可以将净净股票策略应用于这些市场，寻找潜在的投资机会。

### 并购和重组分析
净净股票的低估值可能吸引潜在的收购者。投资者可以通过分析净净股票，寻找可能成为并购目标的公司。同时，在公司进行重组或资产剥离时，净净股票策略也可以帮助投资者评估公司的内在价值。
