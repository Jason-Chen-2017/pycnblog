    tokens = [token.text for token in doc]

def context_analysis(prompt, window_size=5):
    doc = nlp(prompt)
    context_tokens = []
    for token in doc:
        window = nltk.ngrams([t.text for t in doc], window_size)
        context_tokens.extend([t.text for t in window if t != token])
    return context_tokens

  - **损失函数**：\(L = \frac{1}{N} \sum_{i=1}^{N} L_i\)
  - **反向传播**：\(\frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial z} \frac{\partial z}{\partial \theta}\)
  其中，\(L\)为总损失，\(L_i\)为单个样本的损失，\(\theta\)为模型参数，\(z\)为中间变量。

- **多模态融合**：多模态融合可以通过以下公式实现：
  - **特征融合**：\(x_{fused} = w_1 \cdot x_1 + w_2 \cdot x_2\)
  - **模型融合**：\(\hat{y} = f(\text{concat}(x_1, x_2))\)
  其中，\(x_1\)和\(x_2\)分别为不同模态的数据，\(x_{fused}\)为融合后的特征，\(w_1\)和\(w_2\)为权重，\(\hat{y}\)为生成的输出。

- **强化学习**：强化学习使用以下公式：
  - **奖励函数**：\(R(s, a) = r(s, a)\)
  - **策略更新**：\(\pi(a|s) = \pi_{\theta}(a|s)\)
  其中，\(R(s, a)\)为奖励函数，\(s\)为状态，\(a\)为动作，\(r(s, a)\)为奖励值，\(\pi(a|s)\)为策略函数。

- **生成对抗网络（GAN）**：生成对抗网络（GAN）使用以下公式：
  - **生成器损失**：\(L_G = -\log(D(G(z)))\)
  - **判别器损失**：\(L_D = -[\log(D(x)) + \log(1 - D(G(z)))]\)
  其中，\(G(z)\)为生成器，\(D(x)\)为判别器，\(z\)为噪声向量。

4. **算法原理详细讲解**

- **提示词预处理**：提示词预处理是应用算法的基础步骤，包括分词、词性标注和实体识别。预处理步骤提取出提示词的基本语言特征，为后续分析提供数据支持。

- **语义分析**：语义分析通过词向量模型提取提示词的语义特征。语义特征用于描述提示词的含义和上下文关系，为模型生成内容提供语义支持。

- **情感分析**：情感分析通过情感分析模型识别提示词的情感倾向。情感分析结果用于指导生成内容的情感方向，提高生成内容的情感共鸣。

- **上下文分析**：上下文分析通过窗口分析和句法依存关系提取提示词在文本中的上下文信息。上下文信息用于补充和丰富提示词的语义，提高生成内容的连贯性和相关性。

- **生成内容**：利用训练好的AI模型生成创意性内容。生成模型（如GPT-2）通过提示词和上下文信息生成具有创意性和相关性的内容。

5. **数学模型与公式讲解**

- **语义分析**：语义分析通常使用词向量模型（如Word2Vec、BERT）进行。词向量模型通过训练数据学习词与词之间的语义关系。常用的词向量模型包括Word2Vec和BERT。

- **情感分析**：情感分析通常使用分类器（如SVM、神经网络）进行。情感分析模型通过训练数据学习文本的情感分类。常用的情感分析模型包括VADER和SentiWordNet。

- **上下文分析**：上下文分析通过窗口分析和句法依存关系进行。窗口分析选取提示词周围的一定范围内的词作为上下文，而句法依存关系分析通过构建依存句法树来识别词之间的语法关系。
