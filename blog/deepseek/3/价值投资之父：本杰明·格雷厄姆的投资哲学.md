### 格雷厄姆的投资哲学核心概念与联系

#### 安全边际（Margin of Safety）

安全边际是格雷厄姆投资哲学中的核心概念之一。它指的是投资者在购买股票时，所支付的价格应远低于其内在价值。安全边际的目的是为了应对市场的不确定性，包括对公司未来业绩的预测不准确、市场情绪的变化以及潜在的经济波动。

**概念属性：**
- **内在价值**：公司的内在价值是通过对其未来现金流量的折现计算得出的。这需要投资者对公司的财务状况、行业前景和宏观经济环境有深入的了解。
- **市场价格**：市场价格是投资者实际支付的股票价格。理想情况下，市场价格应低于公司的内在价值，从而为投资者提供安全边际。

**对比表格：**
| 概念               | 安全边际          | 抵押价值        |
|--------------------|------------------|----------------|
| 定义               | 价格低于内在价值 | 等于或低于债务 |
| 关键点             | 防止过度投资     | 防止公司破产   |
| 应用场景            | 长期投资策略     | 抵押贷款       |

#### 边际成本与边际效益

边际成本和边际效益是经济学中的基本概念，在格雷厄姆的投资哲学中也有重要应用。边际成本是指每增加一单位投资所增加的成本，而边际效益是指每增加一单位投资所增加的收益。

**概念属性：**
- **边际成本**：投资者在做出投资决策时，应考虑投资的边际成本，确保收益能够覆盖成本。
- **边际效益**：投资者应评估投资的边际效益，确保投资能够带来超额回报。

**对比表格：**
| 概念           | 边际成本         | 边际效益        |
|----------------|------------------|----------------|
| 定义           | 投资每增加一单位 | 收益每增加一单位 |
| 关键点         | 防止资源浪费     | 确保收益覆盖成本 |
| 应用场景        | 预算管理         | 投资决策       |

#### 风险与回报

格雷厄姆认为，风险和回报是投资过程中不可或缺的因素。投资者必须根据风险水平来调整期望回报，以确保投资决策的合理性。

**概念属性：**
- **风险**：风险是指投资可能遭受的损失。在价值投资中，风险包括市场波动、公司业绩不稳定等。
- **回报**：回报是指投资带来的收益。投资者应通过合理的风险控制，追求稳健的回报。

**对比表格：**
| 概念       | 风险           | 回报           |
|------------|----------------|----------------|
| 定义       | 损失的可能性    | 收益的期望值    |
| 关键点     | 风险评估与管理   | 回报预期与实现  |
| 应用场景    | 投资策略制定    | 资产配置       |

#### 核心概念的联系

这些核心概念之间存在着紧密的联系。安全边际是格雷厄姆投资哲学的基础，它通过提供价格与内在价值之间的缓冲，减少了投资风险。边际成本和边际效益则在投资决策中起到了指导作用，帮助投资者在预算和管理投资收益方面做出明智的选择。而风险与回报则确保了投资者能够在合理的风险水平上追求稳健的回报。

通过这些核心概念的相互作用，格雷厄姆的投资哲学提供了一种系统化的投资方法论，帮助投资者在复杂多变的金融市场中实现稳健的投资回报。

import pandas as pd
import numpy as np

# 假设已有公司财务报表数据
financial_data = pd.DataFrame({

# 计算内在价值
def calculate_intrinsic_value(eps, book_value, dividend_yield, pe_ratio):
    # 使用现金流折现模型
    discount_rate = 0.1  # 假设折现率为10%
    cash_flows = eps * (1 + discount_rate) / (1 + discount_rate)**2
    intrinsic_value = cash_flows / discount_rate
    return intrinsic_value

financial_data['Intrinsic_Value'] = financial_data.apply(
    lambda row: calculate_intrinsic_value(row['Earnings_Per_Share'], row['Book_Value_Per_Share'], row['Dividend_Yield'], row['Price_to_Earnings_Ratio']), axis=1)

# 筛选股票
def select_stocks(data, pe_threshold, pb_threshold):
    filtered_stocks = data[(data['Price_to_Earnings_Ratio'] < pe_threshold) & (data['Book_Value_Per_Share'] < pb_threshold)]
    return filtered_stocks

# 评估安全边际
def assess_marginal_safety(stock_data, intrinsic_value):
    current_price = stock_data['Current_Price']
    safety_margin = intrinsic_value - current_price
    return safety_margin

# 假设当前股价数据

    'Company': ['ABC', 'DEF', 'GHI'],
    'Current_Price': [80, 120, 100]

    print(f"{row['Company']} - Intrinsic Value: {row['Intrinsic_Value']}, Current Price: {current_price_data.loc[current_price_data['Company'] == row['Company']]['Current_Price'].values[0]}, Safety Margin: {safety_margin}")

#### 数学模型和数学公式

在价值投资中，数学模型和数学公式起着至关重要的作用。以下我们将使用LaTeX格式展示几个关键的数学公式，并对这些公式进行详细讲解。

首先，我们介绍格雷厄姆提出的现金流折现（DCF）模型，该模型用于计算公司的内在价值。

```latex
\newcommand{\intrinsicvalue}{IV}
\newcommand{\eps}{EPS}
\newcommand{\bvps}{BVPS}
\newcommand{\dy}{DY}
\newcommand{\pe}{PE}

\intrinsicvalue = \frac{\eps \times (1 + r)}{(1 + r)^2}
```

**公式解释：**

- \(\intrinsicvalue\)：公司的内在价值。
- \(\eps\)：每股收益。
- \(r\)：折现率，通常取市场利率或投资者要求的回报率。
- \(BVPS\)：账面价值每股。
- \(DY\)：股息收益率。
- \(PE\)：市盈率。

这个公式反映了未来现金流的折现，通过将未来现金流量折现到当前时点，得出公司的内在价值。在实际应用中，投资者需要根据具体情况进行调整，例如调整折现率或现金流预测。

接下来，我们介绍格雷厄姆投资哲学中的另一个关键公式——安全边际。

```latex
MS = IV - Price
```

**公式解释：**

- \(MS\)：安全边际。
- \(IV\)：内在价值。
- \(Price\)：股票的当前市场价格。

安全边际表示投资者支付的价格与其估计的内在价值之间的差额。理想情况下，安全边际应尽可能大，以降低投资风险。通过计算安全边际，投资者可以确定股票是否被市场低估。

最后，我们介绍市盈率（PE）与账面价值（BV）的比率，这是评估股票是否被低估的重要指标之一。

```latex
\frac{PE}{BV} = \frac{\frac{Price}{\eps}}{\frac{BVPS}{eps}}
```

**公式解释：**

- \(PE\)：市盈率。
- \(BVPS\)：账面价值每股。
- \(\eps\)：每股收益。

这个公式用于计算市盈率与账面价值的比率，可以帮助投资者判断股票是否被低估。如果该比率低于市场平均水平，可能表明股票价格低于其内在价值。

def calculate_intrinsic_value(eps, bvps, dividend_yield, pe_ratio):
    discount_rate = 0.1  # 假设折现率为10%
    cash_flows = eps * (1 + discount_rate) / (1 + discount_rate)**2
    intrinsic_value = cash_flows / discount_rate
    return intrinsic_value

def select_stocks(connection, pe_threshold, pb_threshold):

    WHERE price_to_earnings_ratio < %s AND book_value_per_share < %s
    '''

    cursor = connection.cursor()
    cursor.execute(query, (pe_threshold, pb_threshold))

    return pd.DataFrame(stocks)

    query = '''
    SELECT current_price
    FROM stock_price
    WHERE company_name = %s
    '''
    cursor = connection.cursor()
    cursor.execute(query, (company_name,))
    current_price = cursor.fetchone()[0]
    safety_margin = intrinsic_value - current_price
    return safety_margin
