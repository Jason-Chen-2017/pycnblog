主动学习是一种学习策略，其中学习器能够主动选择最具代表性的数据点进行标注，从而优化学习过程。

**原理**：
主动学习的基本原理是利用模型的不确定性来选择标注数据。具体来说，模型会评估数据点的预测不确定性，并选择那些预测不确定性最高的数据点进行标注。

**工作流程**：

1. **初始阶段**：模型在未标注的数据集上进行训练。
2. **采样阶段**：模型评估数据点的预测不确定性，选择最具代表性的数据点进行标注。
3. **更新阶段**：模型使用新获取的标注数据更新模型参数。

$$

$$

$$
w_{t+1} = w_t - \alpha \nabla_w J(w_t)
$$

$$
w_{t+1} = w_t - \alpha_t \nabla_w J(w_t; x_t, y_t)
$$

X_train, X_unlabeled, y_train, y_unlabeled = train_test_split(X, y, test_size=0.8, random_state=42)

# 模型初始化
model = LinearRegression()

# 采样策略
def uncertainty_sampling(X, y, model):
    predictions = model.predict(X)
    uncertainties = np.std(predictions)
    indices = np.argsort(uncertainties)[::-1]
    return indices[:10]

# 数据标注
def annotate_data(indices, X_unlabeled, y_unlabeled):
    annotated_data = []
    for index in indices:
        label = y_unlabeled[index]
        annotated_data.append((X_unlabeled[index], label))
    return annotated_data

# 模型更新
def update_model(model, annotated_data):
    X_annotated, y_annotated = zip(*annotated_data)
    model.fit(X_annotated, y_annotated)

# 迭代过程
for iteration in range(10):
    indices = uncertainty_sampling(X_unlabeled, y_unlabeled, model)
    annotated_data = annotate_data(indices, X_unlabeled, y_unlabeled)
    update_model(model, annotated_data)

# 性能评估
accuracy = model.score(X_train, y_train)
print(f"Model accuracy after {iteration+1} iterations: {accuracy}")
