知识管理系统（KMS）是一种用于收集、存储、共享和管理的工具，它帮助组织和个人高效地管理和利用知识资源。KMS通常包括文档管理、知识库、社交功能等模块，支持知识的检索和共享，提高团队协作效率。

**学习管理系统（LMS）**：

**功能模块**：

- **课程管理**：设计、发布和更新在线课程。

- **作业与考试**：布置作业、在线考试和成绩评估。
- **互动交流**：论坛、聊天室和即时通讯功能，促进学习者之间的交流。
- **资源库**：存储和管理课程资料，包括文本、视频、音频等多种形式。

**应用实例**：

在一个企业培训场景中，LMS可以帮助企业设计个性化的培训课程，根据员工的角色和需求进行分类。员工可以通过LMS在线学习，提交作业和参加考试，系统会自动记录学习进度和成绩，方便管理者进行评估和反馈。

# learning_resources.py

class LearningResource:
    def __init__(self, title, author, url):
        self.title = title
        self.author = author
        self.url = url

    def display_resource(self):
        print(f"Title: {self.title}")
        print(f"Author: {self.author}")
        print(f"URL: {self.url}")

class LearningResourceManager:
    def __init__(self):
        self.resources = []

    def add_resource(self, resource):
        self.resources.append(resource)

    def display_resources(self):
        for resource in self.resources:
            resource.display_resource()

# 使用示例
if __name__ == "__main__":
    manager = LearningResourceManager()
    manager.add_resource(LearningResource("Python教程", "Alice", "https://example.com/python"))

    manager.display_resources()
