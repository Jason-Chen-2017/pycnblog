## 5.2 系统核心实现源代码

```python
import git
from openai import API

def save_version(prompt, version):
    repo = git.Repo('.')
    file = 'prompt.txt'
    with open(file, 'w') as f:
        f.write(prompt)
    repo.git.add(file)
    repo.git.commit('-m', f'version {version}')
    return True

def optimize_prompt(prompts, api_key):
    client = API(api_key)
    for prompt in prompts:
        response = client.chat.completions.create(
            model="gpt-3.5-turbo",
            messages=[{"role": "user", "content": prompt}]
        )
        if response.choices[0].message.content:
            return prompt
    return None
```

上述代码展示了如何将提示词保存到版本控制系统，并通过OpenAI API进行优化测试。`save_version`函数将提示词保存到Git仓库，`optimize_prompt`函数通过API调用测试提示词的效果，并返回优化后的提示词。
