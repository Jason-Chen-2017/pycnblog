   - **功能**：负责接收和处理外部环境信息，如文本、图像、语音等。

   - **功能**：根据决策模块的决策结果，执行相应的操作，如生成法律文书、发送通知等。
   - **实现技术**：自动化工具、API接口等。

4. **交互模块（Interaction Module）**：

**3.3.1 朴素贝叶斯算法原理**

朴素贝叶斯算法是基于贝叶斯定理的一种分类算法，其基本原理如下：

$$
P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}
$$

其中，\(P(A|B)\) 是在给定 \(B\) 条件下 \(A\) 发生的概率，\(P(B|A)\) 是在 \(A\) 条件下 \(B\) 发生的概率，\(P(A)\) 是 \(A\) 的先验概率，\(P(B)\) 是 \(B\) 的总概率。

对于法律咨询领域的文本分类问题，我们可以将每个类别视为一个标签，文本特征视为特征向量。朴素贝叶斯算法通过计算每个特征向量属于每个类别的概率，选择概率最大的类别作为分类结果。

**3.3.2 Mermaid图：朴素贝叶斯算法流程图**

```mermaid
graph TD
    A[输入文本] --> B[特征提取]
    B --> C{计算先验概率}
    C -->|P(A)| D{计算条件概率}
    D --> E[计算P(B|A)}
    E --> F[选择最大概率类别]
```

**3.3.3 Python代码：朴素贝叶斯算法实现**

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline

# 特征提取
vectorizer = CountVectorizer()

# 朴素贝叶斯分类器
classifier = MultinomialNB()

# 构建管道
model = make_pipeline(vectorizer, classifier)

# 训练模型
X_train = ["这是一份合同", "我签了字", "这是一份协议"]
y_train = ["合同", "合同", "合同"]

model.fit(X_train, y_train)

# 预测
X_test = ["请帮我检查这份合同"]
predicted = model.predict(X_test)

print(predicted)
```
