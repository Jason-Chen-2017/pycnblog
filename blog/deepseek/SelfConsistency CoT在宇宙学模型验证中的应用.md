$$
H_0 = \frac{\dot{a}}{a} = \frac{\sqrt{\Omega_{m}0 \rho_{c,0}}}{a H_0}

其中，$H_0$是宇宙学常数，$\Omega_{m}0$是当前宇宙质量密度参数，$\rho_{c,0}$是当前宇宙临界密度，$a$是宇宙膨胀因子，$c$是光速，$H(z)$是红移$z$处的哈勃参数。

我们使用以下代码来验证模型：

```python
import numpy as np

# 定义宇宙学模型参数
H0 = 70 * np.pi / 180  # 宇宙学常数（单位：弧秒/年）
Om0 = 0.3  # 当前宇宙质量密度参数
rc = 3 * 10**5  # 当前宇宙临界密度（单位：Mpc）

# 计算哈勃参数
def H(z):
    return H0 * np.sqrt(Om0 * (1 + z)**3 + (1 - Om0))

# 计算理论距离
def theoretical_distance(z):
    return rc / H(z)

# 计算理论距离与观测距离的差异
def residual(z, observed_distance):
    return observed_distance - theoretical_distance(z)
```
