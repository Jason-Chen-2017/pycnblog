#### 4.1.2 常见的负载均衡算法

- **加权轮询算法**：介绍加权轮询算法的原理和实现。
  - **原理**：如何根据权重分配流量。
  - **实现**：使用Python代码实现加权轮询算法。

```python
import random

def weighted_round_robin(weights):
    total_weight = sum(weights)
    choices = [(w / total_weight) for w in weights]
    return random.choices(choices, k=1)

weights = [1, 2, 3]  # 示例权重
selected_server = weighted_round_robin(weights)
print(f"Selected server: {selected_server}")
```

- **最小连接算法**：介绍最小连接算法的原理和实现。

```python
import random

def least_connections(servers, connections):
    min_connections = min(connections.values())
    least_connections_servers = [s for s, c in connections.items() if c == min_connections]
    return random.choice(least_connections_servers)

servers = ['Server1', 'Server2', 'Server3']
connections = {'Server1': 10, 'Server2': 5, 'Server3': 3}
selected_server = least_connections(servers, connections)
print(f"Selected server: {selected_server}")
```

#### 4.1.3 使用Python代码实现负载均衡

- **综合实现**：结合加权轮询算法和最小连接算法，使用Python代码实现负载均衡器。

```python
import random

def load_balancer(servers, weights, connections):
    if random.random() < 0.5:
        return weighted_round_robin(weights)
    else:
        return least_connections(servers, connections)

servers = ['Server1', 'Server2', 'Server3']
weights = [1, 2, 3]
connections = {'Server1': 10, 'Server2': 5, 'Server3': 3}

for _ in range(10):
    selected_server = load_balancer(servers, weights, connections)
    print(f"Selected server: {selected_server}")
```

```python
import pika

# 连接消息队列
connection = pika.BlockingConnection(pika.ConnectionParameters('localhost'))
channel = connection.channel()

# 声明队列
channel.queue_declare(queue='llm_queue')

# 发送消息
for i in range(10):

    channel.basic_publish(exchange='',
                          routing_key='llm_queue',

# 关闭连接

# 消费者代码示例
import pika

# 连接消息队列
connection = pika.BlockingConnection(pika.ConnectionParameters('localhost'))
channel = connection.channel()

# 声明队列
channel.queue_declare(queue='llm_queue')

# 定义消息处理方法
def callback(ch, method, properties, body):
    print(f"Received {body}")

# 订阅队列
channel.basic_consume(queue='llm_queue',
                      on_message_callback=callback,
                      auto_ack=True)

# 开始消费
channel.start_consuming()
```
