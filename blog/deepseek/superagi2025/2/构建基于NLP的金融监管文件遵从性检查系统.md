### 3.2 Python 源代码详细阐述

```python
import jieba
import re

# 文本预处理
def preprocess_text(text):
    # 分词
    words = jieba.cut(text)
    # 去除停用词
    stop_words = set(['的', '了', '在', '是', '和'])
    words = [word for word in words if word not in stop_words]
    # 去除标点符号
    words = [re.sub(r'[^\w]', '', word) for word in words]
    return words

# 提取关键信息
def extract_key_info(words):
    # 关键词提取
    key_words = []
    for word in words:
        if len(word) >= 3:
            key_words.append(word)
    return key_words

# 合规性检查
def check_compliance(key_words, rule_library):
    for rule in rule_library:
        if rule in key_words:
            return True
    return False

# 生成报告
def generate_report(compliance_result):
    if compliance_result:
        print("文件符合监管要求")
    else:
        print("文件不符合监管要求")
```

### 3.3 算法原理的数学模型和公式

自然语言处理中的文本预处理主要包括分词、词性标注、实体识别等步骤。以下是一个简单的数学模型：

$$
\text{preprocess\_text}(text) = \{\text{分词}(text), \text{去停用词}(\text{分词}(text)), \text{去标点符号}(\text{去停用词}(text))\}
$$

关键信息提取可以使用TF-IDF算法，其数学模型为：

$$
\text{TF-IDF}(word) = \frac{f_{word}}{N} \cdot \log \left(\frac{N}{f_{word}}\right)
$$

其中，$f_{word}$ 表示词 $word$ 在文本中的出现次数，$N$ 表示文本中的总词数。

合规性检查可以使用规则匹配算法，其数学模型为：

$$
\text{check\_compliance}(key\_words, rule\_library) =
\begin{cases}
\text{True}, & \text{如果 rule\_library 中存在关键词} \\
\text{False}, & \text{否则}
\end{cases}
$$
