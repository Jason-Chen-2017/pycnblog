### Python 源代码实现
```python
import pandas as pd
import numpy as np
from statsmodels.tsa.arima.model import ARIMA
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, mean_absolute_error

# 数据收集和预处理
def data_preprocessing(file_path):
    data = pd.read_csv(file_path)
    # 去除缺失值
    data = data.dropna()
    # 标准化处理
    for column in data.columns:
        if column != 'date':
            data[column] = (data[column] - data[column].mean()) / data[column].std()
    return data

# 时间序列分析
def time_series_analysis(data, column):
    model = ARIMA(data[column], order=(1, 1, 1))
    model_fit = model.fit()
    predictions = model_fit.predict(start=0, end=len(data)-1)
    return predictions

# 回归分析
def regression_analysis(data, x_columns, y_column):
    X = data[x_columns]
    y = data[y_column]
    model = LinearRegression()
    model.fit(X, y)
    predictions = model.predict(X)
    mse = mean_squared_error(y, predictions)
    mae = mean_absolute_error(y, predictions)
    return model, mse, mae

# 主函数
def main():
    file_path = 'data.csv'
    data = data_preprocessing(file_path)
    
    # 时间序列分析
    stock_valuation_predictions = time_series_analysis(data, 'stock_valuation')
    energy_management_predictions = time_series_analysis(data, 'energy_management_index')
    
    # 回归分析
    x_columns = ['energy_management_index']
    y_column = 'stock_valuation'
    model, mse, mae = regression_analysis(data, x_columns, y_column)
    
    print(f"均方误差 (MSE): {mse}")
    print(f"平均绝对误差 (MAE): {mae}")

if __name__ == "__main__":
    main()
```

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 时间序列分析模型（ARIMA）
ARIMA（自回归积分滑动平均模型）是一种常用的时间序列分析模型，其数学表达式为：

$$
\phi(B)(1 - B)^d Y_t = \theta(B) \epsilon_t
$$

其中，$Y_t$ 是时间序列数据，$B$ 是滞后算子，$\phi(B)$ 是自回归多项式，$\theta(B)$ 是滑动平均多项式，$d$ 是差分阶数，$\epsilon_t$ 是白噪声序列。

### 回归分析模型（线性回归）
线性回归模型的数学表达式为：

$$
Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_n X_n + \epsilon
$$

其中，$Y$ 是因变量，$X_1, X_2, \cdots, X_n$ 是自变量，$\beta_0, \beta_1, \cdots, \beta_n$ 是回归系数，$\epsilon$ 是误差项。

### 详细讲解
- **ARIMA 模型**：ARIMA 模型通过对时间序列数据进行差分处理，使其成为平稳序列，然后建立自回归和滑动平均模型来预测未来值。差分阶数 $d$ 表示对时间序列数据进行差分的次数，自回归多项式 $\phi(B)$ 和滑动平均多项式 $\theta(B)$ 分别表示自回归和滑动平均的系数。
- **线性回归模型**：线性回归模型通过最小二乘法来估计回归系数 $\beta_0, \beta_1, \cdots, \beta_n$，使得误差项 $\epsilon$ 的平方和最小。回归系数表示自变量对因变量的影响程度。

### 举例说明
假设我们有新兴市场股市估值和智能家居能源管理行业销售额的时间序列数据。我们可以使用 ARIMA 模型对这两个时间序列数据进行分析，找出其变化规律和周期性特征。然后，我们可以使用线性回归模型建立新兴市场股市估值与智能家居能源管理行业销售额之间的关系模型，以定量分析两者之间的关系。

例如，通过线性回归分析得到的回归方程为：

$$
\text{股市估值} = 100 + 0.5 \times \text{智能家居能源管理行业销售额}
$$

这意味着智能家居能源管理行业销售额每增加 1 个单位，新兴市场股市估值将增加 0.5 个单位。
