## 2. 核心概念与联系 

### 全球股市估值模型
全球股市估值是一个复杂的过程，涉及多个因素和方法。常见的估值模型包括市盈率模型、市净率模型、现金流折现模型等。

- **市盈率模型**：市盈率（P/E）是指股票价格与每股收益的比率。其计算公式为 $P/E=\frac{股价}{每股收益}$。该模型假设市场对同行业公司的盈利预期具有相似性，通过比较不同公司的市盈率来评估股票的相对价值。例如，若某行业平均市盈率为20倍，而某公司市盈率为15倍，则该公司股票可能被低估。

- **市净率模型**：市净率（P/B）是指股票价格与每股净资产的比率。计算公式为 $P/B=\frac{股价}{每股净资产}$。市净率反映了市场对公司净资产的估值水平。一般来说，市净率较低的股票可能具有更高的投资价值。

- **现金流折现模型**：现金流折现模型（DCF）是一种基于公司未来现金流的估值方法。其基本原理是将公司未来的自由现金流折现到当前时点，得到公司的内在价值。公式为 $V=\sum_{t=1}^{n}\frac{FCF_t}{(1+r)^t}$，其中 $V$ 为公司内在价值，$FCF_t$ 为第 $t$ 期的自由现金流，$r$ 为折现率，$n$ 为预测期数。

### 量子通信原理
量子通信基于量子力学的基本原理，主要包括量子态的叠加性、量子纠缠和量子不可克隆定理。

- **量子态的叠加性**：量子系统可以处于多个状态的叠加态，即一个量子比特可以同时表示0和1。这种特性使得量子计算机能够并行处理大量信息，提高计算效率。

- **量子纠缠**：当两个或多个量子系统处于纠缠态时，它们之间存在一种特殊的关联。对其中一个量子的测量会瞬间影响另一个量子的状态，无论它们相隔多远。利用量子纠缠可以实现量子密钥分发和量子隐形传态。

- **量子不可克隆定理**：量子态不能被精确复制。这一特性保证了量子通信的安全性，因为任何试图窃听量子通信的行为都会改变量子态，从而被通信双方察觉。

## 3. 核心算法原理 & 具体操作步骤 

### 全球股市估值算法原理
#### 市盈率模型
市盈率模型的核心思想是通过比较不同公司的市盈率来评估股票的相对价值。以下是一个简单的Python代码示例：

```python
def pe_ratio_valuation(price, earnings_per_share, industry_pe):
    """
    市盈率模型估值函数
    :param price: 股票当前价格
    :param earnings_per_share: 每股收益
    :param industry_pe: 行业平均市盈率
    :return: 股票的合理价格
    """
    pe = price / earnings_per_share
    fair_price = industry_pe * earnings_per_share
    if pe < industry_pe:
        print("该股票可能被低估，合理价格为：", fair_price)
    elif pe > industry_pe:
        print("该股票可能被高估，合理价格为：", fair_price)
    else:
        print("该股票价格合理，合理价格为：", fair_price)
    return fair_price

# 示例数据
price = 50
earnings_per_share = 2
industry_pe = 20

fair_price = pe_ratio_valuation(price, earnings_per_share, industry_pe)
```

#### 现金流折现模型
现金流折现模型的核心是将公司未来的自由现金流折现到当前时点。以下是一个简化的Python代码示例：

```python
def dcf_valuation(free_cash_flows, discount_rate):
    """
    现金流折现模型估值函数
    :param free_cash_flows: 未来各期的自由现金流列表
    :param discount_rate: 折现率
    :return: 公司的内在价值
    """
    value = 0
    for i, fcf in enumerate(free_cash_flows):
        discounted_fcf = fcf / (1 + discount_rate) ** (i + 1)
        value += discounted_fcf
    return value

# 示例数据
free_cash_flows = [100, 120, 150, 180, 200]
discount_rate = 0.1

company_value = dcf_valuation(free_cash_flows, discount_rate)
print("公司的内在价值为：", company_value)
```

### 量子密钥分发算法原理
量子密钥分发的核心是利用量子态的特性生成和分发密钥。其中，BB84协议是一种经典的量子密钥分发协议。以下是BB84协议的Python代码示例：

```python
import random

# 定义量子态
QUANTUM_STATES = ['+0', '+1', 'x0', 'x1']

def generate_random_bits(length):
    """
    生成随机比特序列
    :param length: 比特序列长度
    :return: 随机比特序列
    """
    return [random.randint(0, 1) for _ in range(length)]

def generate_random_bases(length):
    """
    生成随机基序列
    :param length: 基序列长度
    :return: 随机基序列
    """
    return [random.choice(['+', 'x']) for _ in range(length)]

def encode_bits(bits, bases):
    """
    根据基对比特进行编码
    :param bits: 比特序列
    :param bases: 基序列
    :return: 编码后的量子态序列
    """
    encoded_states = []
    for bit, base in zip(bits, bases):
        if base == '+':
            if bit == 0:
                encoded_states.append('+0')
            else:
                encoded_states.append('+1')
        else:
            if bit == 0:
                encoded_states.append('x0')
            else:
                encoded_states.append('x1')
    return encoded_states

def measure_states(states, bases):
    """
    根据基对量子态进行测量
    :param states: 量子态序列
    :param bases: 基序列
    :return: 测量后的比特序列
    """
    measured_bits = []
    for state, base in zip(states, bases):
        if base == '+':
            if state == '+0':
                measured_bits.append(0)
            elif state == '+1':
                measured_bits.append(1)
            else:
                # 测量错误，随机返回0或1
                measured_bits.append(random.randint(0, 1))
        else:
            if state == 'x0':
                measured_bits.append(0)
            elif state == 'x1':
                measured_bits.append(1)
            else:
                # 测量错误，随机返回0或1
                measured_bits.append(random.randint(0, 1))
    return measured_bits

def sift_bits(alice_bits, alice_bases, bob_bases):
    """
    筛选出相同基下的比特
    :param alice_bits: 发送方的比特序列
    :param alice_bases: 发送方的基序列
    :param bob_bases: 接收方的基序列
    :return: 筛选后的比特序列
    """
    sifted_bits = []
    for i in range(len(alice_bits)):
        if alice_bases[i] == bob_bases[i]:
            sifted_bits.append(alice_bits[i])
    return sifted_bits

# 示例
key_length = 100
alice_bits = generate_random_bits(key_length)
alice_bases = generate_random_bases(key_length)
encoded_states = encode_bits(alice_bits, alice_bases)

bob_bases = generate_random_bases(key_length)
bob_bits = measure_states(encoded_states, bob_bases)

sifted_key = sift_bits(alice_bits, alice_bases, bob_bases)
print("筛选后的密钥：", sifted_key)
```

### 具体操作步骤
#### 全球股市估值操作步骤

#### 量子密钥分发操作步骤
1. **密钥生成**：发送方（Alice）生成随机的比特序列和基序列，并根据基序列对比特进行编码，生成量子态序列。

4. **基比对**：发送方（Alice）和接收方（Bob）通过经典信道交换基序列，筛选出相同基下的比特，得到筛选后的密钥。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 全球股市估值数学模型和公式
#### 市盈率模型
市盈率模型的基本公式为 $P/E=\frac{股价}{每股收益}$，变形可得 $股价 = P/E \times 每股收益$。

**详细讲解**：市盈率反映了市场对公司盈利的预期。较高的市盈率可能表示市场对公司的未来发展前景看好，愿意为其支付更高的价格；较低的市盈率可能表示市场对公司的预期较低，或者公司被低估。

**举例说明**：假设某公司的每股收益为2元，行业平均市盈率为20倍。根据市盈率模型，该公司的合理股价为 $20 \times 2 = 40$ 元。如果该公司当前股价为30元，则可能被低估；如果当前股价为50元，则可能被高估。

#### 市净率模型
市净率模型的基本公式为 $P/B=\frac{股价}{每股净资产}$，变形可得 $股价 = P/B \times 每股净资产$。

**详细讲解**：市净率反映了市场对公司净资产的估值水平。一般来说，市净率较低的股票可能具有更高的投资价值，因为投资者可以以较低的价格购买到公司的净资产。

**举例说明**：假设某公司的每股净资产为5元，行业平均市净率为3倍。根据市净率模型，该公司的合理股价为 $3 \times 5 = 15$ 元。如果该公司当前股价为12元，则可能被低估；如果当前股价为18元，则可能被高估。

#### 现金流折现模型
现金流折现模型的基本公式为 $V=\sum_{t=1}^{n}\frac{FCF_t}{(1+r)^t}$，其中 $V$ 为公司内在价值，$FCF_t$ 为第 $t$ 期的自由现金流，$r$ 为折现率，$n$ 为预测期数。

**详细讲解**：现金流折现模型的核心思想是将公司未来的自由现金流折现到当前时点，得到公司的内在价值。折现率反映了投资者对投资回报的要求，一般可以采用资本资产定价模型（CAPM）来确定。

**举例说明**：假设某公司未来5年的自由现金流分别为100万元、120万元、150万元、180万元、200万元，折现率为10%。则该公司的内在价值为：

\[
\begin{align*}
V&=\frac{100}{(1 + 0.1)^1}+\frac{120}{(1 + 0.1)^2}+\frac{150}{(1 + 0.1)^3}+\frac{180}{(1 + 0.1)^4}+\frac{200}{(1 + 0.1)^5}\\
&=\frac{100}{1.1}+\frac{120}{1.21}+\frac{150}{1.331}+\frac{180}{1.4641}+\frac{200}{1.61051}\\
&\approx 90.91 + 99.17 + 112.70 + 122.94 + 124.18\\
&= 549.90 \text{（万元）}
\end{align*}
\]

### 量子通信数学模型和公式
#### 量子态的表示
量子比特可以用二维希尔伯特空间中的向量表示。例如，基态 $|0\rangle$ 和 $|1\rangle$ 可以表示为：

$|0\rangle=\begin{bmatrix}1\\0\end{bmatrix}$，$|1\rangle=\begin{bmatrix}0\\1\end{bmatrix}$

量子比特的叠加态可以表示为 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，其中 $\alpha$ 和 $\beta$ 是复数，且满足 $|\alpha|^2 + |\beta|^2 = 1$。

#### 量子纠缠态
以两个量子比特的纠缠态为例，贝尔态 $|\Phi^+\rangle=\frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$ 是一种典型的纠缠态。其中，$|00\rangle = |0\rangle \otimes |0\rangle$，$|11\rangle = |1\rangle \otimes |1\rangle$。

#### 量子密钥分发的安全性分析
在BB84协议中，假设窃听者（Eve）试图窃听量子通信。由于量子不可克隆定理，Eve的窃听行为会改变量子态，从而被通信双方（Alice和Bob）察觉。

设Alice发送的量子态为 $|\psi\rangle$，Bob测量得到的量子态为 $|\varphi\rangle$。如果没有窃听，$|\psi\rangle$ 和 $|\varphi\rangle$ 应该相同；如果存在窃听，$|\psi\rangle$ 和 $|\varphi\rangle$ 会出现差异。通过比较双方的测量结果，可以检测到窃听行为。

例如，假设Alice发送的量子态为 $|+0\rangle$，Bob使用正确的基（$+$ 基）测量得到的结果应该为0。如果Eve在传输过程中进行窃听，她的测量行为会改变量子态，导致Bob测量得到的结果可能为1。通过统计测量结果的差异率，可以判断是否存在窃听。

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 模拟数据收集
data = {
    '股票代码': ['A', 'B', 'C', 'D', 'E'],
    '股价': [50, 60, 40, 70, 80],
    '每股收益': [2, 3, 1.5, 3.5, 4],
    '行业平均市盈率': [20, 20, 20, 20, 20]
}

df = pd.DataFrame(data)

# 市盈率模型估值
def pe_ratio_valuation(price, earnings_per_share, industry_pe):
    pe = price / earnings_per_share
    fair_price = industry_pe * earnings_per_share
    if pe < industry_pe:
        valuation_result = '低估'
    elif pe > industry_pe:
        valuation_result = '高估'
    else:
        valuation_result = '合理'
    return fair_price, valuation_result

df['合理价格'], df['估值结果'] = zip(*df.apply(lambda row: pe_ratio_valuation(row['股价'], row['每股收益'], row['行业平均市盈率']), axis=1))

# 数据可视化
plt.figure(figsize=(10, 6))
plt.bar(df['股票代码'], df['股价'], label='当前股价')
plt.bar(df['股票代码'], df['合理价格'], label='合理价格', alpha=0.7)
plt.xlabel('股票代码')
plt.ylabel('价格')
plt.title('全球股市估值（市盈率模型）')
plt.legend()
plt.show()

print(df)
```

2. **市盈率模型估值**：定义 `pe_ratio_valuation` 函数，根据市盈率模型计算股票的合理价格，并判断股票是被低估、高估还是价格合理。
3. **数据处理**：使用 `apply` 函数将 `pe_ratio_valuation` 函数应用到 DataFrame 的每一行，计算合理价格和估值结果，并将结果添加到 DataFrame 中。
4. **数据可视化**：使用 `matplotlib` 库绘制柱状图，比较当前股价和合理价格。

from qiskit import QuantumCircuit, Aer, execute
import numpy as np

# 生成随机比特序列
def generate_random_bits(length):
    return np.random.randint(0, 2, length)

# 生成随机基序列
def generate_random_bases(length):
    return np.random.randint(0, 2, length)

# 编码量子比特
def encode_qubits(bits, bases):
    qc = QuantumCircuit(len(bits), len(bits))
    for i in range(len(bits)):
        if bases[i] == 0:  # 标准基
            if bits[i] == 1:
                qc.x(i)
        else:  # 哈达玛基
            if bits[i] == 0:
                qc.h(i)
            else:
                qc.x(i)
                qc.h(i)
    return qc

# 测量量子比特
def measure_qubits(qc, bases):
    backend = Aer.get_backend('qasm_simulator')
    for i in range(len(bases)):
        if bases[i] == 0:  # 标准基
            qc.measure(i, i)
        else:  # 哈达玛基
            qc.h(i)
            qc.measure(i, i)
    job = execute(qc, backend, shots=1)
    result = job.result()
    counts = result.get_counts(qc)
    measured_bits = [int(bit) for bit in list(counts.keys())[0][::-1]]
    return measured_bits

# 筛选比特
def sift_bits(alice_bits, alice_bases, bob_bases):
    sifted_bits = []
    for i in range(len(alice_bits)):
        if alice_bases[i] == bob_bases[i]:
            sifted_bits.append(alice_bits[i])
    return sifted_bits

# 示例
key_length = 10
alice_bits = generate_random_bits(key_length)
alice_bases = generate_random_bases(key_length)
qc = encode_qubits(alice_bits, alice_bases)

bob_bases = generate_random_bases(key_length)
bob_bits = measure_qubits(qc, bob_bases)

sifted_key = sift_bits(alice_bits, alice_bases, bob_bases)
print("筛选后的密钥：", sifted_key)
```

1. **随机比特和基序列生成**：定义 `generate_random_bits` 和 `generate_random_bases` 函数，生成随机的比特序列和基序列。
2. **量子比特编码**：定义 `encode_qubits` 函数，根据基序列对比特进行编码，创建量子电路。
3. **量子比特测量**：定义 `measure_qubits` 函数，根据基序列对量子比特进行测量，得到测量后的比特序列。
4. **比特筛选**：定义 `sift_bits` 函数，筛选出相同基下的比特，得到筛选后的密钥。
5. **示例运行**：生成随机的比特序列和基序列，进行量子比特编码、测量和比特筛选，输出筛选后的密钥。

#### 问题1：不同估值模型的适用场景有哪些？
