#### 费雪访谈技巧的起源与影响

费雪的公司访谈技巧，最早可以追溯到彼得·德鲁克（Peter Drucker）的商业分析与管理咨询理论。德鲁克被誉为“现代管理学之父”，他的管理理念和方法深刻影响了全球的企业管理和商业实践。在他的诸多著作中，强调通过访谈获取真实、有价值的信息是至关重要的。这一思想后来被史蒂夫·费雪（Steve Fischer）进一步发扬光大，形成了独具特色的费雪访谈技巧。

费雪在长期的企业管理咨询实践中，不断总结和优化访谈方法，提出了系统性的访谈准备、精确的提问、高效的倾听和精准的引导等关键要素。他的访谈技巧在IT、金融、医疗等多个领域得到广泛应用，尤其对于技术企业和管理层决策者来说，提供了强有力的支持。

#### 费雪访谈技巧的核心要素

费雪的公司访谈技巧包含以下几个核心要素：

1. **系统性准备**：在访谈前，进行充分的准备工作，包括研究被访谈者的背景、明确访谈目标和问题、准备访谈所需材料和工具等。

2. **精确提问**：提出准确、有针对性的问题，避免模糊和不明确的问题，确保访谈的效率和质量。

3. **高效倾听**：不仅仅是听，还要理解、分析和消化被访谈者的回答，确保获取到真实、有价值的信息。

4. **精准引导**：在访谈过程中，引导被访谈者深入探讨关键问题，确保访谈方向的准确性和深度。

5. **信息提取**：通过系统性的访谈方法和技巧，从被访谈者那里提取出最真实、最有价值的信息。

6. **商业洞察**：通过对访谈信息的分析和解读，形成深刻的商业洞察，为企业决策提供有力支持。

7. **技术理解**：特别是在IT领域，通过访谈获取技术细节和背景信息，帮助企业更好地理解和应用新技术。

2. **创业公司**：在初创阶段，通过访谈创业者、团队成员和潜在客户，明确业务方向、市场定位和产品需求，助力企业发展。

3. **企业管理**：通过访谈管理层、员工和客户，获取企业运营状况、团队协作情况和市场反馈，帮助管理者做出科学的决策。

4. **市场调研**：通过访谈目标客户，了解市场需求、用户反馈和竞争对手情况，为企业制定市场策略提供依据。

5. **人力资源**：通过访谈应聘者、员工和离职者，了解人才需求、团队文化和员工满意度，优化人力资源管理。

**优势：**

3. **深度性**：通过精准引导，深入探讨关键问题，使得访谈内容更加丰富和深入，有助于获取深刻的商业洞察。

### 第2章 访谈前的准备工作

#### 研究被访谈者背景

在访谈前，深入研究被访谈者的背景是至关重要的。这一步骤不仅有助于了解被访谈者的个人经历、专业背景和职业成就，还能帮助我们把握其思维方式和沟通风格。以下是一些具体的准备工作：

1. **个人资料收集**：通过公司官网、LinkedIn等平台，收集被访谈者的基本信息，如教育背景、工作经历、专业资质和荣誉奖项等。

2. **社交媒体分析**：关注被访谈者的社交媒体账号，了解其公开的言论、观点和分享的内容，这有助于我们预测其可能在访谈中提到的主题。

3. **专业文章和研究报告**：搜索被访谈者发表的专业文章、研究报告或演讲稿，从中获取其专业见解和研究方向。

4. **行业和公司动态**：了解被访谈者所在行业的发展动态和公司内部情况，包括竞争对手、市场份额、近期项目等。

通过这些准备工作，我们不仅可以建立对被访谈者的初步认识，还能为后续的访谈问题设计提供参考。

#### 确定访谈目标和问题

明确访谈的目标和问题是访谈成功的关键。在制定访谈目标和问题之前，我们需要进行以下工作：

1. **明确访谈目的**：访谈的目的是什么？是为了获取某项具体的信息，还是为了深入了解某个问题？明确访谈目的有助于我们更有针对性地进行后续工作。

2. **制定访谈大纲**：根据访谈目的，制定一个详细的访谈大纲，包括需要探讨的主要话题、子话题和问题。访谈大纲应具有一定的灵活性，以应对访谈过程中可能出现的意外情况。

3. **设计问题**：设计问题时应遵循以下原则：
   - **开放性问题**：鼓励被访谈者进行详细回答，获取更多有价值的信息。
   - **封闭性问题**：用于确认事实或获取具体信息。
   - **引导性问题**：引导被访谈者深入探讨某个特定话题。
   - **假设性问题**：用于探讨某种假设情景下的影响和效果。

4. **预测试**：在正式访谈前，对访谈大纲和问题进行预测试，确保问题的准确性和有效性。

#### 准备访谈所需材料和工具

为了确保访谈的顺利进行，我们需要准备好以下材料和工具：

1. **访谈大纲和问题清单**：提前准备好访谈大纲和问题清单，以便在访谈过程中参考。

2. **录音设备**：确保录音设备正常工作，以便记录访谈内容。

3. **笔记工具**：准备好纸笔或电子笔记工具，随时记录关键信息和观点。

4. **参考资料**：根据访谈主题，准备相关的参考资料，如文献、报告、案例等，以便在访谈过程中参考。

5. **环境布置**：确保访谈环境安静、舒适，有助于双方集中注意力。

#### 调整访谈环境

访谈环境的布置对访谈的效果有着重要影响。以下是一些调整访谈环境的建议：

1. **物理环境**：选择一个安静、私密的空间进行访谈，避免外部干扰。

2. **座位安排**：确保访谈双方的座位相对舒适，有助于双方进行自然的对话。

3. **照明与温度**：调整照明和温度，使其适宜，确保双方在舒适的环境中进行访谈。

4. **技术设备**：确保所有技术设备，如录音设备、投影仪等正常运行，避免技术故障干扰访谈进程。

#### 预演访谈流程

预演访谈流程是确保访谈顺利进行的重要步骤。以下是一些预演访谈流程的建议：

1. **模拟练习**：与团队成员进行模拟练习，模拟真实的访谈场景，测试访谈问题和流程的可行性。

2. **角色扮演**：让团队成员扮演被访谈者和访谈者，进行角色扮演练习，熟悉访谈流程和应对策略。

3. **反馈与调整**：根据模拟练习的结果，收集反馈意见，对访谈流程进行必要的调整，以确保访谈的顺利进行。

4. **心理准备**：进行心理调适，确保访谈者在访谈过程中保持冷静、专注和积极的态度。

#### 准备意外应对策略

访谈过程中可能会出现各种意外情况，如技术故障、被访谈者情绪波动等。为了应对这些意外，我们需要做好以下准备：

1. **备份方案**：准备访谈录音和笔记的备份方案，以防主设备出现故障。

2. **应对策略**：提前准备应对策略，如如何应对被访谈者情绪波动、如何处理技术故障等。

3. **心理支持**：为访谈者提供心理支持，确保其能够在遇到困难时保持冷静和自信。

通过以上准备工作，我们能够确保访谈的顺利进行，从被访谈者那里获取到有价值的信息，为后续的分析和决策提供支持。

### 第3章 费雪的提问技巧

#### 提问的基本原则

费雪的提问技巧强调遵循以下几个基本原则，以确保提问的准确性和有效性：

1. **目标明确**：每次提问都应明确目标，即希望从被访谈者那里获取哪些具体信息。明确的目标有助于集中访谈者的注意力，避免偏离主题。

2. **开放性**：尽量使用开放性问题，鼓励被访谈者进行详细回答，而不是简单的是非题。开放性问题能获取更多有价值的细节和见解。

3. **中立性**：避免在提问中表达个人意见或暗示答案，保持中立，以便获取被访谈者的真实想法。

4. **层次性**：将问题按层次设计，从一般性问题到具体问题，逐步引导被访谈者深入探讨。

5. **简明扼要**：提问应简明扼要，避免冗长和复杂，以便被访谈者理解和回答。

#### 问题的类型与选择

在访谈中，不同类型的问题能起到不同的作用。费雪的提问技巧主要包括以下几种问题类型：

1. **开放性问题**：这类问题通常以“谁”、“什么”、“为什么”、“如何”等疑问词开头，鼓励被访谈者进行详细回答。例如：“您是如何看待当前技术发展趋势的？”

2. **封闭性问题**：这类问题通常用“是”或“否”来回答，用于确认事实或获取具体信息。例如：“您对这项技术的应用有实际案例吗？”

3. **引导性问题**：这类问题用于引导被访谈者深入探讨某个特定话题。例如：“在您的公司，如何处理用户反馈的问题？”

4. **假设性问题**：这类问题用于探讨某种假设情景下的影响和效果。例如：“如果市场环境发生变化，您的公司会如何应对？”

在选择问题时，应根据访谈目的和被访谈者的特点，灵活运用不同类型的问题，以达到最佳效果。

#### 高效提问的技巧

为了提高提问的效率，费雪提出了一些高效的提问技巧：

1. **问题顺序**：合理设计问题的顺序，先从容易回答的问题开始，逐渐过渡到更复杂和敏感的问题，以减少被访谈者的心理压力。

2. **适度重复**：在适当的时候重复问题，以确保被访谈者理解问题并给予完整回答。例如，可以采用“重复问题-等待-重复问题”的策略。

3. **沉默技巧**：在提问后保持沉默，给被访谈者留出思考时间，避免打断其回答。沉默技巧不仅有助于被访谈者思考，还能增加其回答的深度。

4. **非语言提示**：通过肢体语言、眼神接触和非言语反馈，向被访谈者传递支持和鼓励，帮助他们放松并畅所欲言。

#### 避免提问陷阱

在提问过程中，需要注意避免一些常见的陷阱，以确保访谈的公正性和有效性：

1. **倾向性问题**：避免在问题中表达个人意见或暗示答案，以避免引导被访谈者给出不符合实际的回答。

### 第5章 费雪的访谈引导技巧

#### 引导的目的与作用

在费雪的访谈技巧中，引导是确保访谈顺利进行、获取深入信息的关键环节。引导的目的和作用主要体现在以下几个方面：

1. **保持访谈方向**：通过引导，确保访谈紧紧围绕主题，避免偏离核心问题。引导可以帮助访谈者从被访谈者那里获取关键信息，而不被琐碎的细节所干扰。

2. **深入探讨问题**：引导技巧能够帮助访谈者引导被访谈者深入探讨某个特定话题，从而获取更详细、更深入的信息。例如，通过引导性问题，可以促使被访谈者从不同角度分析问题，提供更多见解。

3. **揭示隐性信息**：引导可以激发被访谈者揭示其背后的想法、感受和动机，从而获取更多隐性信息。这些信息往往对决策者了解实际情况、制定策略具有重要意义。

4. **提升访谈效率**：通过有效引导，可以在短时间内获取大量有价值的信息，提高访谈的效率。引导技巧可以缩短访谈时间，同时确保信息获取的深度和广度。

#### 引导的策略与方法

为了实现有效的引导，费雪提出了一系列具体的策略和方法：

1. **开放式引导**：开放式引导旨在鼓励被访谈者进行详细回答，提供更多信息。这种引导方式通常采用开放式问题，如“您能详细描述一下这个问题的解决过程吗？”或“您对这个问题的看法是什么？”

2. **封闭式引导**：封闭式引导用于获取特定信息或确认事实。封闭式问题通常以“是/否”、“多少”、“哪一个”等开头，如“这项技术已经应用于实际项目了吗？”或“您对这项技术的风险评价是多少？”

3. **假设式引导**：假设式引导用于探讨某种假设情景下的影响和效果。通过提出假设性问题，如“如果市场环境发生变化，您的公司会如何应对？”或“如果资源有限，您会如何优化项目？”来引导被访谈者进行思考。

4. **转换式引导**：转换式引导用于从被访谈者那里获取不同角度的信息。通过转换问题，如“除了这个问题，您还关注哪些方面？”或“这个观点与其他领域有何相似之处？”来引导被访谈者进行多角度思考。

5. **重复式引导**：在适当的时候，通过重复问题或问题关键词，帮助被访谈者明确问题和回答，确保信息的准确性和完整性。

#### 避免引导过度

尽管引导在访谈中起着重要作用，但过度引导可能会导致以下问题：

1. **影响被访谈者的自主性**：过度引导可能会使被访谈者感到压力，影响其自主性和表达真实想法的能力。

2. **限制信息的多样性**：过度引导可能会使访谈内容过于单一，限制被访谈者提供多样化观点和信息。

3. **影响访谈的深度**：过度引导可能会使访谈过于肤浅，难以深入探讨问题的本质。

为了避免过度引导，访谈者可以采取以下措施：

1. **尊重被访谈者的观点**：在访谈过程中，尊重被访谈者的观点和意见，避免强行引导。

2. **保持中立性**：在提问和引导过程中，保持中立，不表达个人意见或倾向。

3. **灵活调整**：根据访谈的进展和被访谈者的反应，灵活调整引导策略，避免过度干预。

4. **提供反馈**：通过积极的反馈，表明访谈者对被访谈者的观点和回答给予重视，鼓励其自主表达。

#### 引导中的问题处理

在访谈过程中，可能会遇到一些问题，如被访谈者沉默、回答模糊或偏离主题等。以下是一些处理这些问题的方法：

1. **沉默处理**：如果被访谈者沉默，可以适当给予时间和空间，等待其思考后回答。同时，可以通过开放式问题，如“您还有其他想法吗？”或“您对这个问题的看法是什么？”来引导其继续发言。

2. **模糊回答处理**：如果被访谈者给出模糊的回答，可以通过重复问题或提供具体情境，如“您能否详细说明一下？”或“在具体实施过程中，您有哪些挑战？”来引导其提供更详细的信息。

3. **偏离主题处理**：如果被访谈者偏离主题，可以通过简短的话语将话题拉回，如“非常感谢您的分享，接下来我们讨论一下这个问题。”或“这个话题很有意思，我们稍后再详细讨论，现在先回到原来的话题。”

#### 引导与倾听的结合

引导和倾听是相辅相成的，有效的结合可以提升访谈的整体效果。以下是一些建议：

1. **先倾听后引导**：在访谈过程中，先进行倾听，充分理解被访谈者的观点后，再进行引导。这样可以确保引导的针对性和有效性。

2. **交替进行**：在访谈中，交替进行倾听和引导，使访谈内容更加丰富和深入。例如，在倾听一段时间后，通过引导性问题深入探讨某个话题。

3. **反馈与确认**：在引导过程中，通过反馈和确认，确保自己正确理解了被访谈者的观点。例如，可以简要概括被访谈者的回答，并询问其是否正确。

通过掌握引导技巧，并在访谈过程中灵活运用，我们可以更好地引导被访谈者提供有价值的信息，确保访谈的顺利进行。

费雪的访谈引导技巧在访谈中起着至关重要的作用，通过保持访谈方向、深入探讨问题和揭示隐性信息，帮助我们获取关键信息。有效的引导策略和方法，如开放式引导、封闭式引导、假设式引导和转换式引导，可以提升访谈的效率和深度。同时，避免过度引导，尊重被访谈者的自主性和多样性，是确保访谈成功的关键。通过结合引导与倾听，我们可以实现更深入的交流和理解。通过本章的学习，读者可以掌握费雪访谈引导技巧的核心原理和应用方法，提升访谈能力。

### 第7章 费雪访谈技巧的实战应用

#### 实战案例1：对科技公司创始人的访谈

**案例背景**：
某科技公司初创公司正在开发一款创新型人工智能应用，需要进一步了解市场需求和潜在的技术挑战。为此，公司决定对创始人进行深入访谈，以获取其对项目发展的独到见解和具体建议。

**访谈目标**：
1. 了解创始人的业务愿景和长期战略。
2. 评估当前项目的市场前景和技术可行性。
3. 收集关于团队建设、资金筹措和市场营销等方面的建议。

**访谈过程**：

1. **准备阶段**：
   - 研究创始人背景，包括其创业经历、专业背景和公司的发展历程。
   - 制定详细的访谈大纲，包括主要话题和具体问题。
   - 准备访谈所需材料和工具，如访谈大纲、录音设备、笔记工具等。

2. **访谈阶段**：
   - 开场白：简要介绍访谈目的和流程，确保创始人了解访谈的目标和期望。
   - 话题一：业务愿景和长期战略。通过开放式问题，引导创始人详细阐述其业务愿景和长期战略，如“您对公司未来的发展方向有何规划？”和“您认为公司最大的竞争优势是什么？”。
   - 话题二：市场前景和技术可行性。探讨当前项目的市场前景和技术可行性，如“您如何看待当前市场对人工智能应用的需求？”和“在技术层面，您认为项目面临的最大挑战是什么？”。
   - 话题三：团队建设和资金筹措。讨论团队建设和资金筹措策略，如“您在团队建设中遇到的最大挑战是什么？”和“您打算如何筹集资金以支持项目的发展？”。
   - 话题四：市场营销策略。探讨市场营销策略，如“您计划如何推广这款人工智能应用？”和“您对市场营销策略有哪些具体建议？”。

3. **总结阶段**：
   - 对访谈内容进行总结，提取关键观点和见解。
   - 根据访谈结果，制定具体行动计划，包括团队建设、资金筹措和市场营销等方面的措施。
   - 将访谈总结报告反馈给创始人，确认信息的准确性和完整性，并征求其意见和建议。

**访谈心得**：
通过这次访谈，公司获取了创始人对业务发展、技术挑战和市场营销等方面的深入见解，为项目的发展提供了有力支持。同时，访谈过程中采用的费雪访谈技巧，如系统性的准备、精确的提问和有效的倾听，确保了访谈的顺利进行和信息的准确性。

#### 实战案例2：对行业专家的访谈

**案例背景**：
某企业计划引入一项新技术，以提升生产效率和降低成本。为了深入了解这项技术的实际应用效果、潜在风险和市场前景，企业决定对行业专家进行深入访谈。

**访谈目标**：
1. 了解新技术在行业中的应用情况。
2. 评估新技术对生产效率和成本的影响。
3. 收集关于技术风险和应对策略的建议。

**访谈过程**：

1. **准备阶段**：
   - 研究行业专家的背景，包括其专业领域、研究成果和行业影响力。
   - 制定详细的访谈大纲，包括主要话题和具体问题。
   - 准备访谈所需材料和工具，如访谈大纲、录音设备、笔记工具等。

2. **访谈阶段**：
   - 开场白：简要介绍访谈目的和流程，确保专家了解访谈的目标和期望。
   - 话题一：技术应用情况。通过开放式问题，引导专家详细阐述新技术在行业中的应用情况，如“您认为这项技术在哪些行业中具有广泛的应用前景？”和“目前这项技术在实际应用中遇到了哪些挑战？”。
   - 话题二：对生产效率和成本的影响。探讨新技术对生产效率和成本的影响，如“您如何评价这项技术对生产效率的提升？”和“在成本方面，这项技术有哪些优势？”。
   - 话题三：技术风险和应对策略。讨论技术风险和应对策略，如“您认为这项技术的主要风险是什么？”和“针对这些风险，您有哪些应对策略建议？”。
   - 话题四：市场前景。探讨新技术的市场前景，如“您如何看待这项技术在未来市场中的竞争态势？”和“您认为这项技术未来有哪些发展趋势？”。

3. **总结阶段**：
   - 对访谈内容进行总结，提取关键观点和见解。
   - 根据访谈结果，制定具体的技术引进计划，包括技术评估、风险控制和市场推广等方面的措施。
   - 将访谈总结报告反馈给专家，确认信息的准确性和完整性，并征求其意见和建议。

**访谈心得**：
通过这次访谈，企业对新技术在行业中的应用情况、潜在风险和市场前景有了更深入的了解，为技术引进决策提供了有力支持。访谈过程中采用的费雪访谈技巧，如系统性的准备、精确的提问和有效的倾听，确保了访谈的顺利进行和信息的准确性。

   - 话题二：购买行为和动机。探讨受访者的购买行为和动机，如“您通常如何选择购买产品？”和“是什么促使您购买这款产品？”。

   - 话题四：市场推广建议。探讨市场推广策略，如“您认为哪种推广方式最有效？”和“您对市场推广策略有哪些建议？”。

3. **总结阶段**：
   - 对访谈内容进行总结，提取关键观点和见解。
   - 根据访谈结果，制定具体的产品改进和市场推广计划。
   - 将访谈总结报告反馈给受访者，确认信息的准确性和完整性，并征求其意见和建议。

通过这次访谈，企业对消费者的需求、购买行为和改进建议有了更深入的了解，为产品改进和市场推广提供了有力支持。访谈过程中采用的费雪访谈技巧，如系统性的准备、精确的提问和有效的倾听，确保了访谈的顺利进行和信息的准确性。

#### 遇到的挑战与解决方法

在实战应用费雪访谈技巧的过程中，访谈者可能会遇到一些挑战，以下是一些常见的挑战及其解决方法：

1. **被访谈者不合作**：
   - **挑战**：有些被访谈者可能因为紧张、不熟悉访谈流程或对访谈目的不明晰而不愿意配合。
   - **解决方法**：在访谈开始时，花时间进行自我介绍和解释访谈目的，确保被访谈者了解访谈的重要性，并建立信任关系。可以采用轻松的谈话方式，逐渐缓解被访谈者的紧张情绪。

2. **时间限制**：
   - **挑战**：访谈时间有限，可能无法深入探讨所有话题。
   - **解决方法**：在访谈前制定详细的访谈大纲，确保时间分配合理。在访谈过程中，灵活调整时间，根据实际情况调整访谈话题的优先级。如果时间确实紧张，可以提前告知被访谈者，并请求其提供重点信息。

3. **信息不完整或不准确**：
   - **挑战**：被访谈者可能由于记忆不清或故意隐瞒，导致提供的信息不完整或不准确。
   - **解决方法**：在访谈过程中，通过重复提问和细节追问，确保获取的信息准确和完整。对于重要信息，可以要求被访谈者提供具体例子或数据支持。在访谈结束后，通过交叉验证和多方信息比对，确保信息的准确性。

4. **技术障碍**：
   - **挑战**：访谈过程中可能会遇到技术设备故障，如录音设备失效、网络中断等。
   - **解决方法**：在访谈前进行设备检查和测试，确保设备正常运行。备有备用设备，如额外的录音设备或备用网络。在访谈过程中，及时记录关键信息，以防设备故障导致信息丢失。

5. **语言和文化障碍**：
   - **挑战**：跨文化或语言障碍可能导致沟通不畅，影响访谈效果。
   - **解决方法**：在访谈前了解被访谈者的语言背景和文化特点，尽量使用简单易懂的语言。可以邀请专业的翻译或口译人员协助，确保沟通的顺畅和准确。

通过识别和应对这些挑战，访谈者可以更有效地应用费雪访谈技巧，确保访谈的顺利进行和信息的准确性。实战中的经验积累和灵活应对，将为访谈者提供宝贵的指导，提升访谈效果。
