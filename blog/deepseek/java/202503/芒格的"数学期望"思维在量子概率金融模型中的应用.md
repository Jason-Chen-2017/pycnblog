## 2. 核心概念与联系 

### 2.1 数学期望的原理
数学期望是概率论中的一个重要概念，它是对随机变量取值的一种平均度量。以一个简单的抛硬币游戏为例，假设抛硬币正面朝上可以获得 2 元，反面朝上则没有收益。硬币正面朝上和反面朝上的概率均为 0.5。那么获得收益这个随机变量 $X$ 的取值有两种情况：$x_1 = 2$（正面朝上），$x_2 = 0$（反面朝上），对应的概率 $p_1 = 0.5$，$p_2 = 0.5$。根据数学期望的定义 $E(X)=\sum_{i}x_{i}p_{i}$，可得 $E(X)=2\times0.5 + 0\times0.5 = 1$ 元。这意味着在多次进行这个抛硬币游戏时，平均每次可以获得 1 元的收益。

### 2.2 量子概率金融模型的原理
量子概率金融模型基于量子力学的基本原理，将金融市场中的资产价格、风险等因素看作量子系统中的量子态。在量子系统中，粒子可以处于多种状态的叠加态，类似地，金融资产的价格也可以处于多种可能价格的叠加态。量子概率通过波函数来描述这种叠加态，波函数的模的平方表示各个可能状态出现的概率。

例如，对于一只股票的价格，传统的概率模型可能只能给出有限个离散的价格状态及其对应的概率。而量子概率金融模型可以考虑更多的可能性，并且可以描述这些可能性之间的相互作用。假设股票价格有三种可能状态：上涨、下跌和不变，用量子概率模型可以用一个三维的波函数来描述这三种状态的叠加情况，通过对波函数的演化和测量，可以得到不同时间点股票价格处于各种状态的概率。

### 2.3 核心概念的联系
芒格的“数学期望”思维与量子概率金融模型的联系在于，“数学期望”为量子概率金融模型提供了一种决策的依据。在量子概率金融模型中，我们可以通过计算各种可能结果的数学期望来评估投资策略的优劣。例如，在考虑一个投资组合时，我们可以用量子概率模型计算出该投资组合在不同市场情况下的收益分布，然后根据数学期望的公式计算出该投资组合的期望收益。通过比较不同投资组合的期望收益，我们可以选择最优的投资策略。

## 3. 核心算法原理 & 具体操作步骤 

### 3.1 核心算法原理
在将芒格的“数学期望”思维应用于量子概率金融模型时，核心算法的目标是计算投资组合的期望收益。具体步骤如下：
1. **量子概率建模**：使用量子概率理论建立金融市场的模型，确定资产价格的可能状态及其对应的概率。这可以通过量子态的表示和演化来实现。
2. **收益计算**：对于每个可能的市场状态，计算投资组合在该状态下的收益。
3. **数学期望计算**：根据量子概率模型得到的每个市场状态的概率，结合相应的收益，使用数学期望的公式计算投资组合的期望收益。

### 3.2 具体操作步骤

#### 步骤 1：量子概率建模
假设我们有 $n$ 种资产，每种资产的价格有 $m$ 种可能状态。我们可以用量子态 $\vert\psi\rangle$ 来表示市场的状态，$\vert\psi\rangle=\sum_{i_1 = 1}^{m}\sum_{i_2 = 1}^{m}\cdots\sum_{i_n = 1}^{m}c_{i_1i_2\cdots i_n}\vert i_1i_2\cdots i_n\rangle$，其中 $c_{i_1i_2\cdots i_n}$ 是量子态的系数，$\vert i_1i_2\cdots i_n\rangle$ 表示第 1 种资产处于状态 $i_1$，第 2 种资产处于状态 $i_2$，$\cdots$，第 $n$ 种资产处于状态 $i_n$ 的基态。系数 $c_{i_1i_2\cdots i_n}$ 的模的平方 $\vert c_{i_1i_2\cdots i_n}\vert^2$ 表示市场处于该状态的概率。

#### 步骤 2：收益计算
对于每个市场状态 $\vert i_1i_2\cdots i_n\rangle$，我们可以根据资产的价格变化和投资组合的权重计算投资组合在该状态下的收益 $r_{i_1i_2\cdots i_n}$。假设投资组合中第 $j$ 种资产的权重为 $w_j$，第 $j$ 种资产在状态 $\vert i_1i_2\cdots i_n\rangle$ 下的价格变化为 $\Delta p_{j,i_j}$，则投资组合的收益为 $r_{i_1i_2\cdots i_n}=\sum_{j = 1}^{n}w_j\Delta p_{j,i_j}$。

#### 步骤 3：数学期望计算
根据数学期望的定义，投资组合的期望收益 $E(r)$ 为 $E(r)=\sum_{i_1 = 1}^{m}\sum_{i_2 = 1}^{m}\cdots\sum_{i_n = 1}^{m}\vert c_{i_1i_2\cdots i_n}\vert^2r_{i_1i_2\cdots i_n}$。

### 3.3 Python 代码实现
```python
import numpy as np

# 假设我们有 2 种资产，每种资产有 3 种可能状态
n_assets = 2
m_states = 3

# 初始化量子态的系数
coefficients = np.random.rand(m_states, m_states) + 1j * np.random.rand(m_states, m_states)
# 归一化系数
coefficients = coefficients / np.linalg.norm(coefficients.flatten())

# 计算每种状态的概率
probabilities = np.abs(coefficients) ** 2

# 投资组合的权重
weights = np.array([0.6, 0.4])

# 每种资产在不同状态下的价格变化
price_changes = np.random.rand(n_assets, m_states, m_states)

# 计算每种状态下投资组合的收益
returns = np.zeros((m_states, m_states))
for i1 in range(m_states):
    for i2 in range(m_states):
        returns[i1, i2] = np.sum(weights * price_changes[:, i1, i2])

# 计算期望收益
expected_return = np.sum(probabilities * returns)

print("投资组合的期望收益:", expected_return)
```

### 3.4 代码解释
1. **量子态系数初始化**：使用 `np.random.rand` 函数生成随机的复数系数，并进行归一化处理，确保量子态的概率之和为 1。
2. **概率计算**：通过计算系数的模的平方得到每种市场状态的概率。
3. **投资组合权重**：定义投资组合中每种资产的权重。
4. **价格变化**：随机生成每种资产在不同市场状态下的价格变化。
5. **收益计算**：根据投资组合的权重和资产的价格变化，计算每种市场状态下投资组合的收益。
6. **期望收益计算**：使用数学期望的公式，将每种市场状态的概率和相应的收益相乘并求和，得到投资组合的期望收益。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 4.1 数学模型和公式

#### 4.1.1 量子态表示
在量子概率金融模型中，市场状态可以用一个量子态 $\vert\psi\rangle$ 来表示。对于 $n$ 种资产，每种资产有 $m$ 种可能状态，量子态可以表示为 $\vert\psi\rangle=\sum_{i_1 = 1}^{m}\sum_{i_2 = 1}^{m}\cdots\sum_{i_n = 1}^{m}c_{i_1i_2\cdots i_n}\vert i_1i_2\cdots i_n\rangle$，其中 $\vert i_1i_2\cdots i_n\rangle$ 是基态，$c_{i_1i_2\cdots i_n}$ 是量子态的系数，满足 $\sum_{i_1 = 1}^{m}\sum_{i_2 = 1}^{m}\cdots\sum_{i_n = 1}^{m}\vert c_{i_1i_2\cdots i_n}\vert^2 = 1$。

#### 4.1.2 概率计算
市场处于状态 $\vert i_1i_2\cdots i_n\rangle$ 的概率 $p_{i_1i_2\cdots i_n}$ 为 $p_{i_1i_2\cdots i_n}=\vert c_{i_1i_2\cdots i_n}\vert^2$。

#### 4.1.3 收益计算
投资组合在状态 $\vert i_1i_2\cdots i_n\rangle$ 下的收益 $r_{i_1i_2\cdots i_n}$ 为 $r_{i_1i_2\cdots i_n}=\sum_{j = 1}^{n}w_j\Delta p_{j,i_j}$，其中 $w_j$ 是第 $j$ 种资产的权重，$\Delta p_{j,i_j}$ 是第 $j$ 种资产在状态 $\vert i_1i_2\cdots i_n\rangle$ 下的价格变化。

#### 4.1.4 数学期望计算
投资组合的期望收益 $E(r)$ 为 $E(r)=\sum_{i_1 = 1}^{m}\sum_{i_2 = 1}^{m}\cdots\sum_{i_n = 1}^{m}p_{i_1i_2\cdots i_n}r_{i_1i_2\cdots i_n}$。

### 4.2 详细讲解

#### 4.2.1 量子态表示
量子态的表示是量子概率金融模型的基础，它可以描述金融市场的不确定性。通过量子态的叠加，我们可以同时考虑多种可能的市场状态。系数 $c_{i_1i_2\cdots i_n}$ 决定了每种市场状态的重要性，其模的平方表示该状态出现的概率。

#### 4.2.2 概率计算
概率计算是根据量子态的系数进行的。由于量子态的系数是复数，我们通过取其模的平方得到实数概率，确保概率的非负性和总和为 1。

#### 4.2.3 收益计算
收益计算考虑了投资组合中每种资产的权重和价格变化。权重反映了投资者对不同资产的偏好，价格变化则根据市场状态的不同而不同。

#### 4.2.4 数学期望计算
数学期望计算是将每种市场状态的概率和相应的收益相乘并求和，得到投资组合的平均收益。这与芒格的“数学期望”思维一致，通过综合考虑各种可能结果的概率和收益来评估投资策略的优劣。

### 4.3 举例说明
假设我们有 2 种资产，每种资产有 2 种可能状态（上涨和下跌）。量子态可以表示为 $\vert\psi\rangle = c_{11}\vert 11\rangle + c_{12}\vert 12\rangle + c_{21}\vert 21\rangle + c_{22}\vert 22\rangle$，其中 $\vert 11\rangle$ 表示两种资产都上涨，$\vert 12\rangle$ 表示第一种资产上涨，第二种资产下跌，以此类推。

假设系数 $c_{11} = 0.3 + 0.4j$，$c_{12} = 0.2 - 0.3j$，$c_{21} = 0.1 + 0.2j$，$c_{22} = 0.4 - 0.1j$。则每种状态的概率为：
$p_{11}=\vert c_{11}\vert^2 = (0.3^2 + 0.4^2) = 0.25$
$p_{12}=\vert c_{12}\vert^2 = (0.2^2 + 0.3^2) = 0.13$
$p_{21}=\vert c_{21}\vert^2 = (0.1^2 + 0.2^2) = 0.05$
$p_{22}=\vert c_{22}\vert^2 = (0.4^2 + 0.1^2) = 0.17$

投资组合的权重 $w_1 = 0.6$，$w_2 = 0.4$。假设资产 1 在上涨状态下价格变化为 0.1，下跌状态下价格变化为 -0.1；资产 2 在上涨状态下价格变化为 0.08，下跌状态下价格变化为 -0.08。则每种状态下投资组合的收益为：
$r_{11}=0.6\times0.1 + 0.4\times0.08 = 0.092$
$r_{12}=0.6\times0.1 + 0.4\times(-0.08) = 0.028$
$r_{21}=0.6\times(-0.1) + 0.4\times0.08 = -0.028$
$r_{22}=0.6\times(-0.1) + 0.4\times(-0.08) = -0.092$

投资组合的期望收益为：
$E(r)=0.25\times0.092 + 0.13\times0.028 + 0.05\times(-0.028) + 0.17\times(-0.092) = 0.014$
