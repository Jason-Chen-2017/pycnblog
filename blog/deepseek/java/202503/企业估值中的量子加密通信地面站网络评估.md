## 3. 核心算法原理 & 具体操作步骤 
### 3.1 量子密钥分发算法原理
量子密钥分发的核心算法是 BB84 协议，该协议基于量子态的特性实现安全的密钥分发。以下是 BB84 协议的基本原理：

- **发送方操作**：发送方随机选择一组基（如水平垂直基或对角基），并根据要发送的比特信息制备相应的量子态。例如，在水平垂直基中，比特 0 可以用水平偏振态表示，比特 1 可以用垂直偏振态表示；在对角基中，比特 0 可以用 +45° 偏振态表示，比特 1 可以用 -45° 偏振态表示。
- **接收方操作**：接收方随机选择一组基进行测量。如果接收方选择的基与发送方相同，则测量结果与发送方发送的比特信息一致；如果选择的基不同，则测量结果是随机的。
- **密钥筛选**：发送方和接收方通过经典信道公开他们选择的基，只保留基相同的测量结果作为密钥。

### 3.2 Python 代码实现
以下是一个简单的 Python 代码示例，模拟 BB84 协议的密钥分发过程：

```python
import random

# 定义基和量子态
bases = ['X', 'Z']
states = {'Z0': '|0>', 'Z1': '|1>', 'X0': '|+>', 'X1': '|->'}

# 生成随机比特序列
def generate_bits(length):
    return [random.randint(0, 1) for _ in range(length)]

# 生成随机基序列
def generate_bases(length):
    return [random.choice(bases) for _ in range(length)]

# 制备量子态
def prepare_states(bits, bases):
    states_list = []
    for bit, base in zip(bits, bases):
        if base == 'Z':
            if bit == 0:
                states_list.append('Z0')
            else:
                states_list.append('Z1')
        else:
            if bit == 0:
                states_list.append('X0')
            else:
                states_list.append('X1')
    return states_list

# 测量量子态
def measure_states(states, bases):
    measured_bits = []
    for state, base in zip(states, bases):
        if base == 'Z':
            if state.startswith('Z'):
                measured_bits.append(int(state[1]))
            else:
                measured_bits.append(random.randint(0, 1))
        else:
            if state.startswith('X'):
                measured_bits.append(int(state[1]))
            else:
                measured_bits.append(random.randint(0, 1))
    return measured_bits

# 密钥筛选
def sift_keys(sender_bits, sender_bases, receiver_bases, receiver_bits):
    sifted_keys = []
    for i in range(len(sender_bases)):
        if sender_bases[i] == receiver_bases[i]:
            sifted_keys.append(receiver_bits[i])
    return sifted_keys

# 主程序
if __name__ == "__main__":
    length = 100
    sender_bits = generate_bits(length)
    sender_bases = generate_bases(length)
    sender_states = prepare_states(sender_bits, sender_bases)

    receiver_bases = generate_bases(length)
    receiver_bits = measure_states(sender_states, receiver_bases)

    sifted_keys = sift_keys(sender_bits, sender_bases, receiver_bases, receiver_bits)
    print("Sifted keys:", sifted_keys)
```

### 3.3 具体操作步骤
1. **初始化**：发送方和接收方分别生成随机的比特序列和基序列。
2. **量子态制备**：发送方根据比特序列和基序列制备相应的量子态。
3. **量子态传输**：发送方通过量子信道将制备好的量子态发送给接收方。
4. **量子态测量**：接收方根据自己的基序列对收到的量子态进行测量。
5. **密钥筛选**：发送方和接收方通过经典信道公开他们选择的基，只保留基相同的测量结果作为密钥。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 
### 4.1 量子态表示
在量子力学中，量子态通常用狄拉克符号表示。例如，一个单量子比特的状态可以表示为：

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$

其中，$\alpha$ 和 $\beta$ 是复数，满足 $|\alpha|^2 + |\beta|^2 = 1$。$|0\rangle$ 和 $|1\rangle$ 是两个基态。

### 4.2 量子测量
量子测量是量子态的一个重要操作。在测量过程中，量子态会塌缩到某个基态上。例如，在 $Z$ 基下测量量子态 $|\psi\rangle$，得到 $|0\rangle$ 的概率为 $|\alpha|^2$，得到 $|1\rangle$ 的概率为 $|\beta|^2$。

### 4.3 量子密钥分发的安全性分析
量子密钥分发的安全性基于量子力学的基本原理。根据海森堡不确定性原理，任何试图测量量子态的行为都会改变其状态。因此，在量子密钥分发过程中，如果存在窃听者，发送方和接收方可以通过比较测量结果的统计特性来检测到窃听行为。

例如，在 BB84 协议中，发送方和接收方可以通过比较基相同的测量结果的错误率来判断是否存在窃听。如果错误率超过了一个预先设定的阈值，则认为存在窃听，需要重新进行密钥分发。

### 4.4 举例说明
假设发送方制备的量子态为 $|\psi\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$，接收方在 $Z$ 基下进行测量。根据量子测量的原理，得到 $|0\rangle$ 的概率为 $|\frac{1}{\sqrt{2}}|^2 = \frac{1}{2}$，得到 $|1\rangle$ 的概率也为 $\frac{1}{2}$。
