### 1.4 术语表
#### 1.4.1 核心术语定义
- **特价股票**：指市场价格相对其内在价值被低估的股票。这些股票可能由于市场短期情绪、行业暂时困境或公司特定事件等原因，导致价格低于其实际应有的价值。
- **全球供应链重构**：指全球范围内的供应链网络、结构和运作模式发生重大变化的过程。这可能涉及到生产基地的转移、供应链环节的优化、贸易伙伴的重新选择等，以适应新的经济、政治和技术环境。
- **股票内在价值**：指股票所代表的公司的真实价值，通常基于公司的盈利能力、资产状况、发展前景等因素进行评估。

#### 1.4.2 相关概念解释
- **价值投资**：一种投资策略，强调通过分析股票的内在价值，寻找被低估的股票进行投资，以期在股票价格回归其内在价值时获得收益。
- **供应链风险**：指在供应链运作过程中，由于各种不确定因素导致的供应链中断、成本增加、效率降低等风险。
- **市场情绪**：指投资者对市场的整体看法和预期，会影响股票价格的短期波动。

#### 1.4.3 缩略词列表
- **PE**：市盈率（Price - Earnings Ratio），指股票价格与每股收益的比率，用于衡量股票的估值水平。
- **PB**：市净率（Price - Book Ratio），指股票价格与每股净资产的比率，反映股票价格相对于公司净资产的倍数。

## 2. 核心概念与联系 

### 2.1 全球供应链重构的影响
全球供应链重构是一个复杂且动态的过程，其影响广泛而深远。从宏观经济层面来看，供应链重构可能导致全球贸易格局的变化，一些传统的贸易强国可能会因为供应链的调整而面临经济增长的压力，而一些新兴经济体则可能迎来发展机遇。例如，随着劳动力成本的上升和环保要求的提高，一些制造业可能会从发达国家向劳动力成本更低、资源更丰富的发展中国家转移。

从行业层面来看，不同行业受到供应链重构的影响程度不同。一些依赖全球供应链的行业，如电子、汽车、航空等，可能会面临供应链中断、成本上升等问题。而一些本地市场导向的行业，如食品、医疗、零售等，受到的影响相对较小。例如，电子行业的芯片供应可能会因为全球供应链的重构而受到限制，导致电子产品的生产和销售受到影响。

从企业层面来看，供应链重构对企业的运营和竞争力产生重要影响。企业需要重新评估其供应链战略，优化供应链结构，降低供应链风险。一些企业可能会选择增加本地供应商的比例，以减少对海外供应商的依赖；一些企业可能会加强与供应商的合作，共同应对供应链挑战。例如，汽车企业可能会与本地的零部件供应商建立更紧密的合作关系，以确保零部件的稳定供应。

### 2.2 特价股票的特点与价值
特价股票通常具有以下特点：
- **低估值**：特价股票的市盈率、市净率等估值指标通常低于市场平均水平，这意味着投资者可以以较低的价格购买到相对较高价值的股票。
- **潜在增长潜力**：虽然特价股票目前可能处于困境，但由于其内在价值被低估，一旦公司解决了面临的问题，或者行业环境改善，股票价格可能会出现较大幅度的上涨。
- **市场忽视**：特价股票往往由于市场短期情绪或其他原因被投资者忽视，这为有眼光的投资者提供了机会。

特价股票的价值在于其投资回报潜力。通过投资特价股票，投资者可以在股票价格回归其内在价值时获得收益。此外，特价股票还可以作为投资组合的一部分，降低投资组合的整体风险。

### 2.3 全球供应链重构与特价股票投资的联系
全球供应链重构为特价股票投资带来了新的机遇和挑战。一方面，供应链重构导致一些行业和企业面临困境，股票价格下跌，从而产生了更多的特价股票投资机会。例如，一些受到供应链中断影响的企业，其股票价格可能会大幅下跌，而这些企业的内在价值可能并没有发生实质性的变化，这就为投资者提供了买入的机会。

另一方面，供应链重构也增加了投资的不确定性和风险。由于供应链重构的过程复杂且动态，投资者很难准确预测哪些企业能够在重构中受益，哪些企业会受到负面影响。因此，投资者需要更加深入地研究和分析企业的供应链状况，以降低投资风险。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 4.1 市盈率（PE）模型
市盈率（PE）是指股票价格与每股收益的比率，用于衡量股票的估值水平。其计算公式为：
$$PE = \frac{P}{EPS}$$
其中，$P$ 表示股票价格，$EPS$ 表示每股收益。

市盈率反映了投资者为获取公司每一元盈利所愿意支付的价格。一般来说，市盈率越低，股票越被低估，具有投资价值。例如，某股票的价格为 $50$ 元，每股收益为 $5$ 元，则该股票的市盈率为：
$$PE = \frac{50}{5} = 10$$

### 4.2 市净率（PB）模型
市净率（PB）是指股票价格与每股净资产的比率，反映股票价格相对于公司净资产的倍数。其计算公式为：
$$PB = \frac{P}{BVPS}$$
其中，$P$ 表示股票价格，$BVPS$ 表示每股净资产。

市净率越低，说明股票价格相对于公司净资产越便宜，股票越被低估。例如，某股票的价格为 $30$ 元，每股净资产为 $10$ 元，则该股票的市净率为：
$$PB = \frac{30}{10} = 3$$

### 4.3 线性回归模型
线性回归模型是一种常用的统计模型，用于预测连续变量的值。其基本形式为：
$$y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \cdots + \beta_nx_n + \epsilon$$
其中，$y$ 表示目标变量，$x_1, x_2, \cdots, x_n$ 表示特征变量，$\beta_0, \beta_1, \beta_2, \cdots, \beta_n$ 表示模型的参数，$\epsilon$ 表示误差项。

在股票价值评估中，我们可以使用线性回归模型来预测股票的内在价值。例如，我们可以将市盈率、市净率、净利润率、净资产收益率等作为特征变量，将股票价格作为目标变量，构建线性回归模型。

假设我们有以下数据：
| 市盈率（PE） | 市净率（PB） | 净利润率 | 净资产收益率 | 股票价格 |
| --- | --- | --- | --- | --- |
| 10 | 2 | 0.2 | 0.15 | 50 |
| 12 | 2.5 | 0.18 | 0.12 | 60 |
| 8 | 1.5 | 0.22 | 0.18 | 40 |

我们可以使用 Python 的 `sklearn` 库来构建线性回归模型：
```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 定义特征变量
X = np.array([[10, 2, 0.2, 0.15], [12, 2.5, 0.18, 0.12], [8, 1.5, 0.22, 0.18]])

# 定义目标变量
y = np.array([50, 60, 40])

# 构建线性回归模型
model = LinearRegression()

# 训练模型
model.fit(X, y)

# 预测新数据
new_data = np.array([[11, 2.2, 0.21, 0.16]])
prediction = model.predict(new_data)

print('预测的股票价格：', prediction)
```

### 4.4 逻辑回归模型
逻辑回归模型是一种常用的分类模型，用于预测离散变量的值。其基本形式为：
$$P(y = 1|x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x_1 + \beta_2x_2 + \cdots + \beta_nx_n)}}$$
其中，$P(y = 1|x)$ 表示在特征变量 $x$ 的条件下，目标变量 $y$ 取值为 $1$ 的概率，$\beta_0, \beta_1, \beta_2, \cdots, \beta_n$ 表示模型的参数。

在股票投资中，我们可以使用逻辑回归模型来预测股票是否为特价股票。例如，我们可以将市盈率、市净率、净利润率、净资产收益率等作为特征变量，将股票是否为特价股票作为目标变量，构建逻辑回归模型。

假设我们有以下数据：
| 市盈率（PE） | 市净率（PB） | 净利润率 | 净资产收益率 | 是否为特价股票 |
| --- | --- | --- | --- | --- |
| 10 | 2 | 0.2 | 0.15 | 1 |
| 12 | 2.5 | 0.18 | 0.12 | 0 |
| 8 | 1.5 | 0.22 | 0.18 | 1 |

我们可以使用 Python 的 `sklearn` 库来构建逻辑回归模型：
```python
import numpy as np
from sklearn.linear_model import LogisticRegression

# 定义特征变量
X = np.array([[10, 2, 0.2, 0.15], [12, 2.5, 0.18, 0.12], [8, 1.5, 0.22, 0.18]])

# 定义目标变量
y = np.array([1, 0, 1])

# 构建逻辑回归模型
model = LogisticRegression()

# 训练模型
```

```python
    balance_sheet = stock_data.balance_sheet
    cashflow = stock_data.cashflow

    # 将基本信息转换为 DataFrame
    info_df = pd.DataFrame.from_dict(info, orient='index').T
    info_df['Symbol'] = symbol

    # 将历史价格数据转换为 DataFrame
    history_data['Symbol'] = symbol
```

### 9.1 什么是特价股票？
特价股票是指市场价格相对其内在价值被低估的股票。这些股票可能由于市场短期情绪、行业暂时困境或公司特定事件等原因，导致价格低于其实际应有的价值。

### 9.2 如何判断一只股票是否为特价股票？
可以通过分析股票的估值指标（如市盈率、市净率）、公司的财务状况（如盈利能力、资产负债表）、行业前景等因素来判断一只股票是否为特价股票。此外，还可以使用一些专业的分析工具和模型来辅助判断。

全球供应链重构对股票投资的影响是多方面的。一方面，它可能导致一些行业和企业面临困境，股票价格下跌，从而产生更多的特价股票投资机会。另一方面，它也增加了投资的不确定性和风险，投资者需要更加深入地研究和分析企业的供应链状况，以降低投资风险。

### 9.4 如何降低利用特价股票投资的风险？

- 进行充分的研究和分析，了解公司的基本面和行业前景。
