## 1.1.1 创意的定义与特征

创意是指通过独特的思维方式和创新方法，将现有知识、资源、信息等进行重新组合、创造出新观念、新方法、新方案的过程。创意的核心在于新颖性和独特性，它不仅要求提出新的想法，还需要这些想法具有实用性和可行性。

### 1.1.2 创意的特征

1. **新颖性**：创意需要具有与众不同的特点，能够打破常规，提供全新的视角或解决方案。
2. **独特性**：创意的独特性体现在其无法被简单复制或模仿，具备较高的创新价值。
3. **实用性**：创意需要具有实际应用价值，能够在现实生活中得到有效运用。
4. **可行性**：创意不仅要新颖独特，还需要在技术、经济、社会等方面具备可行性，能够实现落地。
5. **影响性**：创意的影响性体现在其能够产生深远的影响，改变人们的思维方式、工作方式或生活方式。

2. **知识储备**：创新能力的提升需要基于深厚的知识储备，只有具备丰富的知识才能进行有效的创新。
3. **思维敏捷**：创新思维需要敏捷，能够迅速捕捉到新的机会或问题，并提出解决方案。

4. **实用性评估**：

   结合实际应用场景，对文本的实用性进行评分：

   $$\text{practicality}(T) = \sum_{s \in S} \text{utility}(s) \cdot \text{feasibility}(s)$$

   其中，\(S\) 为文本中的句子集，\(\text{utility}(s)\) 表示句子实用性，\(\text{feasibility}(s)\) 表示句子实现可能性。

```python
import nltk
from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize

nltk.download('punkt')
nltk.download('stopwords')

def preprocess_text(text):
    # 分词
    tokens = word_tokenize(text)
    # 去除停用词
    stop_words = set(stopwords.words('english'))
    filtered_tokens = [token for token in tokens if token.lower() not in stop_words]
    # 词形还原
    lemmatizer = nltk.WordNetLemmatizer()
    lemmatized_tokens = [lemmatizer.lemmatize(token) for token in filtered_tokens]
    return lemmatized_tokens
```

##### 6.2.2 特征提取

```python
from transformers import BertTokenizer, BertModel

tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

def extract_features(text):
    inputs = tokenizer(text, return_tensors='pt', padding=True, truncation=True)
    outputs = model(**inputs)
    return outputs.last_hidden_state[:, 0, :]
```
