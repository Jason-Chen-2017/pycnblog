### 5.2 系统核心实现源代码

以下是系统核心实现的部分源代码：

```python
# app.py

from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy
from sqlalchemy.orm import sessionmaker

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///experiment.db'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)

class Experiment(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(120), nullable=False)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'))

@app.route('/experiments', methods=['GET'])
def get_experiments():
    experiments = Experiment.query.all()
    return jsonify([{'id': e.id, 'name': e.name} for e in experiments])

@app.route('/experiments', methods=['POST'])
def create_experiment():
    data = request.json
    experiment = Experiment(name=data['name'], user_id=data['user_id'])
    db.session.add(experiment)
    db.session.commit()
    return jsonify({'id': experiment.id})

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```

在应用程序的路由中，我们定义了两个API接口：`/experiments`。第一个接口用于获取所有的实验信息，第二个接口用于创建新的实验。
