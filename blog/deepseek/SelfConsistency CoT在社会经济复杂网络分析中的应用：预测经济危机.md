**3.2 数学模型和公式讲解**

Self-Consistency CoT算法的核心在于识别网络中的自我一致性模式，为此需要借助一些数学模型和公式。下面介绍几个关键的数学模型和公式。

**3.2.1 自我一致性度量**

自我一致性的度量可以通过以下公式表示：

$$
SC = \frac{1}{N} \sum_{i=1}^{N} (s_i - \bar{s})^2
$$

其中，$SC$表示自我一致性度量，$s_i$表示节点$i$的状态，$\bar{s}$表示节点状态的均值，$N$表示节点总数。

**3.2.2 模式识别指标**

为了识别自我一致性模式，可以使用以下指标：

$$
PM = \frac{1}{T} \sum_{t=1}^{T} \left(1 - \frac{|s_i(t) - s_j(t)|}{\max(s_i(t), s_j(t))}\right)
$$

其中，$PM$表示模式识别指标，$s_i(t)$和$s_j(t)$分别表示节点$i$和节点$j$在时间$t$的状态，$T$表示时间窗口的长度。

**3.2.3 预测概率**

基于自我一致性模式，可以计算经济危机的预测概率：

$$
P(C) = \frac{1}{Z} \sum_{i=1}^{N} e^{-\alpha SC_i}
$$

其中，$P(C)$表示经济危机的预测概率，$Z$是归一化常数，$\alpha$是调节参数，$SC_i$是节点$i$的自我一致性度量。

    # 数据清洗
    data = clean_data(data)

def build_network(features):
    G = nx.Graph()
    # 添加节点和边
    for i in range(len(features)):
        G.add_node(i, feature=features[i])
        for j in range(i+1, len(features)):
            if features[i] == features[j]:
                G.add_edge(i, j, weight=1)
    return G

    return SC
