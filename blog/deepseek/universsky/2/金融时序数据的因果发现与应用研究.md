##### 3.1.3 相关性与因果性的关系

相关性与因果性是两个不同的概念。相关性是指变量之间的线性关系，而因果性是指变量之间的因果关系。在金融时序数据分析中，相关性和因果性之间的关系如下：

- **正相关**：当两个变量之间存在正相关关系时，一个变量的增加会导致另一个变量的增加。
- **负相关**：当两个变量之间存在负相关关系时，一个变量的增加会导致另一个变量的减少。
- **无相关**：当两个变量之间不存在相关关系时，一个变量的变化不会影响另一个变量。

相关性不能直接推断因果关系，因为相关性可能是由于偶然因素或共同的原因导致的。因果关系的识别需要通过因果推断方法，结合数据分析和统计模型，进行深入的分析和验证。

#### 3.3 数学模型与公式

在金融时序数据的因果发现中，常用的数学模型和公式包括自回归模型（AR）、移动平均模型（MA）和自回归移动平均模型（ARMA），以及DoCalculus方法和Causal Inference with Graphical Models方法。

##### 3.3.1 时间序列分析数学模型

- **自回归模型（AR）**：

  公式：\( X_t = c + \sum_{i=1}^p \phi_i X_{t-i} + \varepsilon_t \)

  其中，\( X_t \)表示时间序列数据在第\( t \)个时间点的值，\( c \)为常数项，\( \phi_i \)为自回归系数，\( \varepsilon_t \)为误差项。

- **移动平均模型（MA）**：

  公式：\( X_t = \mu + \sum_{i=1}^q \theta_i \varepsilon_{t-i} \)

  其中，\( X_t \)表示时间序列数据在第\( t \)个时间点的值，\( \mu \)为均值项，\( \theta_i \)为移动平均系数，\( \varepsilon_t \)为误差项。

- **自回归移动平均模型（ARMA）**：

  公式：\( X_t = c + \sum_{i=1}^p \phi_i X_{t-i} + \sum_{i=1}^q \theta_i \varepsilon_{t-i} + \varepsilon_t \)

  其中，\( X_t \)表示时间序列数据在第\( t \)个时间点的值，\( c \)为常数项，\( \phi_i \)为自回归系数，\( \theta_i \)为移动平均系数，\( \varepsilon_t \)为误差项。

##### 3.3.2 因果推断数学模型

- **DoCalculus方法**：

  公式：\( C(y|x) = \frac{\mathbb{E}[y \mid x, D(x) = 1]}{\mathbb{E}[y \mid x, D(x) = 0]} \)

  其中，\( C(y|x) \)表示变量\( y \)在变量\( x \)干预下的平均效果，\( \mathbb{E}[y \mid x, D(x) = 1] \)表示在干预变量\( x \)为1时的\( y \)的期望值，\( \mathbb{E}[y \mid x, D(x) = 0] \)表示在干预变量\( x \)为0时的\( y \)的期望值。

- **Causal Inference with Graphical Models方法**：

  公式：\( X \rightarrow Y \leftarrow Z \)

  其中，箭头表示变量之间的因果关系，\( X \rightarrow Y \)表示变量\( X \)是变量\( Y \)的原因，\( Y \leftarrow Z \)表示变量\( Z \)是变量\( Y \)的原因。
