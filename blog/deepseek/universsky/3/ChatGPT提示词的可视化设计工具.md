```python
from flask import Flask, request, jsonify
import spacy

app = Flask(__name__)
nlp = spacy.load("en_core_web_sm")

@app.route('/api/analyze', methods=['POST'])
def analyze_prompt():
    prompt = request.json['prompt']
    doc = nlp(prompt)
    keywords = []
    for token in doc:
        if token.is_alpha:
            keywords.append({'text': token.text, 'frequency': token.frequency})
    return jsonify({'keywords': keywords})

if __name__ == '__main__':
    app.run(debug=True)
```

这段代码定义了一个Flask后端API，用于接收前端发送的提示词文本，并进行文本分析。通过使用spaCy库，我们可以对文本进行分词和词频统计，提取关键词。分析结果将以JSON格式返回给前端，供图表展示。
