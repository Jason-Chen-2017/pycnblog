为了理解可观测性算法，我们需要引入一些基本的数学模型和公式。以下是一个简单的例子：

```python
import numpy as np

def train_model(X, y, learning_rate, lambda_, epochs):
    n_samples, n_features = X.shape
    weights = np.random.rand(n_features)
    
    for epoch in range(epochs):
        predictions = X.dot(weights)
        error = predictions - y
        dJ = X.T.dot(error) + lambda_ * weights
        
        weights -= learning_rate * dJ
        
        if epoch % 100 == 0:
            print(f"Epoch {epoch}: Loss = {np.mean(error**2)}")
    
    return weights
