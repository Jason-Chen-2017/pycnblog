**算法原理讲解：**

心率传感器和呼吸监测器的工作原理基于生物信号处理技术。通过传感器收集的数据，可以使用信号处理算法进行分析和反馈。

```python
import numpy as np

def heart_rate_detection(rpeaks):
    rrs = np.diff(rpeaks)
    heart_rate = 1 / np.mean(rrs)
    return heart_rate

def breath_rate_detection(breath_peaks):
    breath_intervals = np.diff(breath_peaks)
    breath_rate = 1 / np.mean(breath_intervals)
    return breath_rate

rpeaks = [100, 200, 300, 400, 500]
heart_rate = heart_rate_detection(rpeaks)
breath_peaks = [100, 200, 300, 400, 500, 600, 700, 800]
breath_rate = breath_rate_detection(breath_peaks)
print("Heart rate:", heart_rate)
print("Breath rate:", breath_rate)
```
