- **价值投资**：一种投资策略，通过分析股票的内在价值，寻找被市场低估的股票进行投资，以期在股票价格回归内在价值时获得收益。

- **EBIT**：Earnings Before Interest and Taxes（息税前利润）

- **IC**：Invested Capital（投入资本）

## 2. 核心概念与联系 

### 核心概念原理
格林布拉特的价值投资量化模型基于两个核心指标：资本回报率（ROIC）和股票收益率（Earnings Yield）。其基本原理是通过对这两个指标进行排序，筛选出ROIC较高且股票收益率较高的股票，构建投资组合。

- **资本回报率（ROIC）**：反映了企业运用资本创造利润的能力。ROIC越高，说明企业的盈利能力越强，能够更有效地利用投入的资本。
- **股票收益率（Earnings Yield）**：反映了股票的盈利能力和估值水平。股票收益率越高，说明股票的盈利能力越强，同时估值相对较低。

## 3. 核心算法原理 & 具体操作步骤 

### 核心算法原理
格林布拉特的价值投资量化模型的核心算法是通过对资本回报率（ROIC）和股票收益率（Earnings Yield）进行排序，然后综合排名，筛选出排名靠前的股票。具体步骤如下：

1. **数据收集**：收集股票市场的财务数据和市场数据，包括息税前利润（EBIT）、投入资本（IC）、企业价值（EV）等。
2. **指标计算**：计算每只股票的资本回报率（ROIC）和股票收益率（Earnings Yield）。
    - 资本回报率（ROIC）计算公式：$ROIC = \frac{EBIT}{IC}$
    - 股票收益率（Earnings Yield）计算公式：$Earnings\ Yield = \frac{EBIT}{EV}$
3. **排序**：分别对ROIC和股票收益率进行排序，得到每只股票在两个指标上的排名。
4. **综合排名**：将每只股票在ROIC和股票收益率上的排名相加，得到综合排名。
5. **筛选股票**：根据综合排名，筛选出排名靠前的股票，构建投资组合。

### 具体操作步骤的Python源代码实现
```python
import pandas as pd

# 假设我们已经有了一个包含股票数据的DataFrame，列名为 'EBIT', 'IC', 'EV'
# 这里我们简单创建一个示例DataFrame
data = {
    'Stock': ['A', 'B', 'C', 'D', 'E'],
    'EBIT': [100, 200, 150, 300, 250],
    'IC': [500, 800, 600, 1200, 1000],
    'EV': [1500, 2000, 1800, 3500, 2800]
}
df = pd.DataFrame(data)

# 步骤2：计算ROIC和股票收益率
df['ROIC'] = df['EBIT'] / df['IC']
df['Earnings_Yield'] = df['EBIT'] / df['EV']

# 步骤3：排序
df['ROIC_Rank'] = df['ROIC'].rank(ascending=False)
df['Earnings_Yield_Rank'] = df['Earnings_Yield'].rank(ascending=False)

# 步骤4：综合排名
df['Composite_Rank'] = df['ROIC_Rank'] + df['Earnings_Yield_Rank']

# 步骤5：筛选股票，假设我们选择排名前2的股票
top_stocks = df.nsmallest(2, 'Composite_Rank')['Stock']

print(top_stocks)
```
### 代码解释
1. **数据准备**：创建一个包含股票数据的DataFrame，包括股票名称、息税前利润（EBIT）、投入资本（IC）和企业价值（EV）。
2. **指标计算**：使用`df['ROIC'] = df['EBIT'] / df['IC']`和`df['Earnings_Yield'] = df['EBIT'] / df['EV']`计算每只股票的ROIC和股票收益率。
3. **排序**：使用`rank()`方法对ROIC和股票收益率进行排序，得到每只股票在两个指标上的排名。
4. **综合排名**：将ROIC排名和股票收益率排名相加，得到综合排名。
5. **筛选股票**：使用`nsmallest()`方法筛选出综合排名前2的股票。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 数学模型和公式
- **资本回报率（ROIC）**：$ROIC = \frac{EBIT}{IC}$
其中，$EBIT$ 表示息税前利润，$IC$ 表示投入资本。

- **股票收益率（Earnings Yield）**：$Earnings\ Yield = \frac{EBIT}{EV}$
其中，$EBIT$ 表示息税前利润，$EV$ 表示企业价值。

### 详细讲解
- **资本回报率（ROIC）**：ROIC反映了企业运用资本创造利润的能力。ROIC越高，说明企业的盈利能力越强，能够更有效地利用投入的资本。例如，一家企业的息税前利润为100万元，投入资本为500万元，则其ROIC为 $\frac{100}{500} = 0.2$ 或 20%。

- **股票收益率（Earnings Yield）**：股票收益率反映了股票的盈利能力和估值水平。股票收益率越高，说明股票的盈利能力越强，同时估值相对较低。例如，一家企业的息税前利润为100万元，企业价值为1000万元，则其股票收益率为 $\frac{100}{1000} = 0.1$ 或 10%。

### 举例说明
假设我们有以下三只股票的数据：

| 股票 | 息税前利润（EBIT） | 投入资本（IC） | 企业价值（EV） |
| ---- | ------------------ | -------------- | -------------- |
| A    | 200                | 1000           | 2500           |
| B    | 300                | 1500           | 3500           |
| C    | 150                | 800            | 2000           |

1. **计算ROIC**
    - 股票A的ROIC：$ROIC_A = \frac{200}{1000} = 0.2$ 或 20%
    - 股票B的ROIC：$ROIC_B = \frac{300}{1500} = 0.2$ 或 20%
    - 股票C的ROIC：$ROIC_C = \frac{150}{800} = 0.1875$ 或 18.75%

2. **计算股票收益率**
    - 股票A的股票收益率：$Earnings\ Yield_A = \frac{200}{2500} = 0.08$ 或 8%
    - 股票B的股票收益率：$Earnings\ Yield_B = \frac{300}{3500} \approx 0.0857$ 或 8.57%
    - 股票C的股票收益率：$Earnings\ Yield_C = \frac{150}{2000} = 0.075$ 或 7.5%

3. **排序**
    - ROIC排名：A = B > C
    - 股票收益率排名：B > A > C

4. **综合排名**
    - 股票A的综合排名：2 + 2 = 4
    - 股票B的综合排名：2 + 1 = 3
    - 股票C的综合排名：3 + 3 = 6

5. **筛选股票**
如果我们选择综合排名前1的股票，则应选择股票B。
