## 2. 核心概念与联系 

### 核心概念原理
约翰·奈夫的高股息价值投资策略基于以下几个核心原理：

1. **股息的稳定性**：股息是公司向股东分配的利润，稳定的股息发放通常意味着公司具有稳定的盈利能力和良好的财务状况。通过投资高股息股票，投资者可以获得持续的现金流入，降低投资组合的波动性。

2. **价值低估**：寻找那些市场价格低于其内在价值的股票。这些股票可能由于市场短期波动、行业负面消息或公司暂时的困境而被低估。当市场逐渐认识到其真实价值时，股票价格有望上涨，从而为投资者带来资本增值。

3. **长期投资**：高股息价值投资强调长期持有股票，以充分享受股息收入和股票价值增长的双重收益。短期市场波动可能会影响股票价格，但从长期来看，公司的基本面和内在价值将决定股票的表现。

## 3. 核心算法原理 & 具体操作步骤 

### 核心算法原理
高股息价值投资的核心算法主要包括股息率计算和价值评估两部分。

#### 股息率计算
股息率的计算公式为：
$$股息率 = \frac{年度股息}{股票价格}$$

年度股息可以通过公司的财务报表或公告获取，股票价格可以从证券交易所或金融数据提供商处获得。

#### 价值评估
常见的价值评估方法有市盈率法和现金流折现模型。

##### 市盈率法
市盈率法通过比较股票的市盈率与行业平均市盈率或历史市盈率来判断股票是否被低估。计算公式为：
$$市盈率 = \frac{股票价格}{每股收益}$$

如果股票的市盈率低于行业平均市盈率或历史市盈率，且公司具有良好的基本面，则该股票可能被低估。

##### 现金流折现模型
现金流折现模型通过预测公司未来的现金流，并将其折现到当前时刻来计算股票的内在价值。计算公式为：
$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$

其中，$V$ 表示股票的内在价值，$CF_t$ 表示第 $t$ 期的现金流，$r$ 表示折现率，$TV$ 表示终值，$n$ 表示预测期数。

### 具体操作步骤

#### 步骤 1：数据收集
收集股票的历史股息数据、财务报表数据（如每股收益、现金流等）、股票价格数据以及行业相关数据。

#### 步骤 2：股息率计算
使用上述股息率计算公式，计算每只股票的股息率。

#### 步骤 3：股息率筛选
设定一个股息率阈值，筛选出股息率高于该阈值的股票。

#### 步骤 4：价值评估
对筛选出的股票进行价值评估，可以使用市盈率法或现金流折现模型。

#### 步骤 5：投资组合构建
根据价值评估结果，选择具有较高投资价值的股票构建投资组合。同时，注意分散投资，降低投资风险。

#### 步骤 6：长期持有
持有投资组合，定期进行业绩评估和调整。

import pandas as pd

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 股息率公式
$$股息率 = \frac{年度股息}{股票价格}$$

#### 详细讲解
股息率反映了投资者从股息中获得的收益率。年度股息是公司在一年内向股东分配的每股股息总和，股票价格是当前股票的市场价格。股息率越高，说明投资者从股息中获得的收益越高。

#### 举例说明
假设某股票的年度股息为 2 元，当前股票价格为 50 元，则该股票的股息率为：
$$股息率 = \frac{2}{50} = 0.04 = 4\%$$

### 市盈率公式
$$市盈率 = \frac{股票价格}{每股收益}$$

#### 详细讲解
市盈率是衡量股票估值水平的重要指标。每股收益是公司每股股票的盈利情况，股票价格是当前股票的市场价格。市盈率越高，说明市场对该股票的预期越高，但也可能意味着股票被高估；市盈率越低，说明股票可能被低估。

#### 举例说明
假设某股票的当前价格为 30 元，每股收益为 3 元，则该股票的市盈率为：
$$市盈率 = \frac{30}{3} = 10$$

### 现金流折现模型公式
$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$

#### 详细讲解
现金流折现模型的核心思想是将公司未来的现金流折现到当前时刻，以计算股票的内在价值。$CF_t$ 表示第 $t$ 期的现金流，$r$ 表示折现率，$TV$ 表示终值，$n$ 表示预测期数。折现率反映了资金的时间价值和投资风险，终值是预测期结束后公司的价值。

#### 举例说明
假设某公司未来 3 年的现金流分别为 100 万元、120 万元、150 万元，折现率为 10%，预测期结束后的终值为 1000 万元。则该公司的内在价值为：

第 1 年现金流折现：
$$\frac{100}{(1 + 0.1)^1} = \frac{100}{1.1} \approx 90.91$$

第 2 年现金流折现：
$$\frac{120}{(1 + 0.1)^2} = \frac{120}{1.21} \approx 99.17$$

第 3 年现金流折现：
$$\frac{150}{(1 + 0.1)^3} = \frac{150}{1.331} \approx 112.69$$

终值折现：
$$\frac{1000}{(1 + 0.1)^3} = \frac{1000}{1.331} \approx 751.31$$

内在价值：
$$V = 90.91 + 99.17 + 112.69 + 751.31 = 1054.08$$

### 5.2  源代码详细实现和代码解读

```python
import yfinance as yf
import pandas as pd
import matplotlib.pyplot as plt

# 定义股票列表
stock_list = ['AAPL', 'MSFT', 'JNJ', 'PG']

# 获取股票数据
data = yf.download(stock_list, start='2020-01-01', end='2023-01-01')

# 提取收盘价和股息数据
close_prices = data['Close']
dividends = data['Dividends']

# 计算股息率
dividend_yields = dividends / close_prices

# 计算平均股息率
average_dividend_yields = dividend_yields.mean()

# 绘制股息率折线图
average_dividend_yields.plot(kind='line', title='Average Dividend Yields')
plt.xlabel('Stock')
plt.ylabel('Dividend Yield')
plt.show()

# 筛选出股息率最高的股票
highest_dividend_stock = average_dividend_yields.idxmax()
print(f"股息率最高的股票是: {highest_dividend_stock}")
```
