## 2. 核心概念与联系 
### 格雷厄姆特价股票策略原理
格雷厄姆特价股票策略的核心思想是寻找被市场低估的股票。其基本原理基于以下几点：
1. **安全边际原则**：投资者应该以低于股票内在价值的价格买入股票，以降低投资风险。安全边际越大，投资的风险越低。
2. **基本面分析**：通过对企业的财务报表、经营业绩、行业地位等基本面因素的分析，评估企业的内在价值。
3. **长期投资**：持有被低估的股票，等待市场发现其价值，从而实现股票价格的上涨。

### 高科技行业特点
高科技行业具有以下显著特点：
1. **技术创新快速**：高科技行业的技术更新换代速度极快，新产品和新技术不断涌现。例如，智能手机行业每隔几年就会推出具有重大技术突破的新产品。
2. **高研发投入**：为了保持技术领先地位，高科技企业需要投入大量的资金进行研发。研发投入占销售收入的比例通常较高。
3. **不确定性高**：由于技术创新的不确定性，高科技企业的未来发展存在较大的风险。一项新技术的研发可能成功，也可能失败，这会对企业的业绩产生重大影响。
4. **成长潜力大**：一旦高科技企业的技术创新取得成功，其产品和服务可能会迅速占领市场，实现高速增长。

## 3. 核心算法原理 & 具体操作步骤 
### 核心算法原理
格雷厄姆特价股票策略的核心算法是通过计算股票的内在价值，并与市场价格进行比较，以判断股票是否被低估。常见的计算内在价值的方法包括股息贴现模型（Dividend Discount Model，DDM）和自由现金流贴现模型（Discounted Cash Flow Model，DCF）。

#### 股息贴现模型（DDM）
股息贴现模型假设股票的价值等于其未来股息的现值之和。其基本公式为：
$$V = \frac{D_1}{(1 + r)^1} + \frac{D_2}{(1 + r)^2} + \cdots + \frac{D_n}{(1 + r)^n}$$
其中，$V$ 表示股票的内在价值，$D_i$ 表示第 $i$ 期的股息，$r$ 表示贴现率。

#### 自由现金流贴现模型（DCF）
自由现金流贴现模型假设股票的价值等于其未来自由现金流的现值之和。其基本公式为：
$$V = \frac{FCF_1}{(1 + r)^1} + \frac{FCF_2}{(1 + r)^2} + \cdots + \frac{FCF_n}{(1 + r)^n}$$
其中，$V$ 表示股票的内在价值，$FCF_i$ 表示第 $i$ 期的自由现金流，$r$ 表示贴现率。

### 具体操作步骤
#### 步骤 1：筛选财务指标
使用格雷厄姆提出的一些财务指标来筛选股票，例如：
- **低市盈率（P/E）**：一般认为，市盈率低于行业平均水平的股票可能被低估。
- **低市净率（P/B）**：市净率低于 1 的股票通常被认为具有较高的安全边际。
- **高股息率**：股息率较高的股票可能更具投资价值。

#### 步骤 2：评估内在价值
选择合适的内在价值计算模型（如 DDM 或 DCF），根据企业的财务数据和未来发展预测，计算股票的内在价值。

#### 步骤 3：比较内在价值和市场价格
将计算得到的内在价值与股票的市场价格进行比较，如果市场价格低于内在价值，则认为该股票被低估。

#### 步骤 4：买入并持有
在确定股票被低估后，买入该股票并长期持有，等待市场发现其价值，实现股票价格的上涨。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 
### 股息贴现模型（DDM）详细讲解
股息贴现模型基于股票的股息分配来评估其价值。其基本思想是，股票的价值等于其未来所有股息的现值之和。

#### 公式推导
假设股票每年的股息增长率为 $g$，第 1 期的股息为 $D_1$，贴现率为 $r$。则第 $i$ 期的股息为 $D_i = D_1(1 + g)^{i - 1}$。

股票的内在价值 $V$ 可以表示为：
$$V = \frac{D_1}{(1 + r)^1} + \frac{D_1(1 + g)^1}{(1 + r)^2} + \frac{D_1(1 + g)^2}{(1 + r)^3} + \cdots$$

当 $r > g$ 时，上式可以简化为：
$$V = \frac{D_1}{r - g}$$

#### 举例说明
假设某股票第 1 期的股息为 $D_1 = 2$ 元，股息增长率 $g = 0.05$，贴现率 $r = 0.1$。则该股票的内在价值为：
$$V = \frac{2}{0.1 - 0.05} = 40$$（元）

### 自由现金流贴现模型（DCF）详细讲解
自由现金流贴现模型基于企业的自由现金流来评估其价值。自由现金流是指企业在满足所有运营和投资需求后剩余的现金流量。

#### 公式推导
假设企业第 $i$ 期的自由现金流为 $FCF_i$，贴现率为 $r$。则企业的内在价值 $V$ 可以表示为：
$$V = \frac{FCF_1}{(1 + r)^1} + \frac{FCF_2}{(1 + r)^2} + \cdots + \frac{FCF_n}{(1 + r)^n}$$

在实际应用中，通常会将企业的未来分为两个阶段：预测期和永续期。预测期内的自由现金流可以根据企业的财务数据和未来发展预测进行估计，永续期的自由现金流通常假设以一个固定的增长率 $g$ 增长。

#### 举例说明
假设某企业预测期为 5 年，各年的自由现金流分别为 $FCF_1 = 100$ 万元，$FCF_2 = 120$ 万元，$FCF_3 = 140$ 万元，$FCF_4 = 160$ 万元，$FCF_5 = 180$ 万元。永续期的自由现金流增长率 $g = 0.03$，贴现率 $r = 0.1$。

首先，计算预测期内自由现金流的现值：
$$PV_1 = \frac{100}{(1 + 0.1)^1} + \frac{120}{(1 + 0.1)^2} + \frac{140}{(1 + 0.1)^3} + \frac{160}{(1 + 0.1)^4} + \frac{180}{(1 + 0.1)^5} \approx 523.6$$（万元）

然后，计算永续期自由现金流的现值：
$$V_5 = \frac{FCF_5(1 + g)}{r - g} = \frac{180(1 + 0.03)}{0.1 - 0.03} \approx 2631.4$$（万元）

$$PV_2 = \frac{V_5}{(1 + 0.1)^5} \approx 1637.7$$（万元）

最后，计算企业的内在价值：
$$V = PV_1 + PV_2 \approx 523.6 + 1637.7 = 2161.3$$（万元）

### 5.2  源代码详细实现和代码解读
```python
import pandas as pd
import yfinance as yf

# 步骤 1：获取股票数据
# 定义股票代码列表
tickers = ['AAPL', 'GOOG', 'MSFT']

# 创建一个空的 DataFrame 来存储股票数据
data = pd.DataFrame()

# 循环获取每只股票的数据
for ticker in tickers:
    stock = yf.Ticker(ticker)
    info = stock.info
    # 获取市盈率（P/E）、市净率（P/B）和股息率
    pe_ratio = info.get('trailingPE', None)
    pb_ratio = info.get('priceToBook', None)
    dividend_yield = info.get('dividendYield', None)
    
    # 将数据添加到 DataFrame 中
    data = data.append({
        '股票代码': ticker,
        '市盈率（P/E）': pe_ratio,
        '市净率（P/B）': pb_ratio,
        '股息率': dividend_yield
    }, ignore_index=True)

# 步骤 2：筛选财务指标
# 筛选低市盈率（P/E < 20）、低市净率（P/B < 2）和高股息率（股息率 > 0.02）的股票
filtered_data = data[(data['市盈率（P/E）'] < 20) & (data['市净率（P/B）'] < 2) & (data['股息率'] > 0.02)]

print("筛选后的股票：")
print(filtered_data)
```
