## 3. 核心算法原理 & 具体操作步骤 

### 市盈率法
#### 算法原理
市盈率法是一种基于盈利的估值方法，其基本原理是通过将股票价格除以每股收益（EPS）来计算市盈率（P/E），并将该市盈率与同行业其他股票或市场平均市盈率进行比较，以判断股票是否被高估或低估。计算公式为：
$$P/E = \frac{股价}{每股收益}$$

#### 具体操作步骤
1. 获取股票的当前价格和每股收益数据。
2. 计算该股票的市盈率。
3. 收集同行业其他股票或市场平均市盈率数据。
4. 将该股票的市盈率与同行业其他股票或市场平均市盈率进行比较。
5. 如果该股票的市盈率高于同行业其他股票或市场平均市盈率，则认为该股票被高估；反之，则认为该股票被低估。

#### Python 源代码实现
```python
# 定义股票价格和每股收益
stock_price = 100
eps = 5

# 计算市盈率
pe_ratio = stock_price / eps

# 假设同行业平均市盈率为 20
industry_avg_pe = 20

# 判断股票是否被高估或低估
if pe_ratio > industry_avg_pe:
    print("该股票被高估")
elif pe_ratio < industry_avg_pe:
    print("该股票被低估")
else:
    print("该股票估值合理")
```

### 市净率法
#### 算法原理
市净率法是一种基于资产的估值方法，其基本原理是通过将股票价格除以每股净资产（BVPS）来计算市净率（P/B），并将该市净率与同行业其他股票或市场平均市净率进行比较，以判断股票是否被高估或低估。计算公式为：
$$P/B = \frac{股价}{每股净资产}$$

#### 具体操作步骤
1. 获取股票的当前价格和每股净资产数据。
2. 计算该股票的市净率。
3. 收集同行业其他股票或市场平均市净率数据。
4. 将该股票的市净率与同行业其他股票或市场平均市净率进行比较。
5. 如果该股票的市净率高于同行业其他股票或市场平均市净率，则认为该股票被高估；反之，则认为该股票被低估。

# 定义股票价格和每股净资产
stock_price = 100

# 计算市净率
pb_ratio = stock_price / bvps

# 假设同行业平均市净率为 3
industry_avg_pb = 3

if pb_ratio > industry_avg_pb:

### 贴现现金流法
#### 算法原理
贴现现金流法是一种基于现金流的估值方法，其基本原理是将未来各期的现金流按照一定的贴现率折现到当前时点，得到股票的内在价值，并将该内在价值与当前市场价格进行比较，以判断股票是否被高估或低估。计算公式为：
$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$
其中，$V$ 为股票的内在价值，$CF_t$ 为第 $t$ 期的现金流，$r$ 为贴现率，$n$ 为现金流的期数。

#### 具体操作步骤
1. 预测未来各期的现金流。
2. 确定贴现率。
3. 将未来各期的现金流按照贴现率折现到当前时点，计算股票的内在价值。
4. 将股票的内在价值与当前市场价格进行比较。
5. 如果股票的内在价值高于当前市场价格，则认为该股票被低估；反之，则认为该股票被高估。

#### Python 源代码实现
```python
import numpy as np

# 预测未来 5 年的现金流
cash_flows = [10, 12, 15, 18, 20]

# 确定贴现率
discount_rate = 0.1

# 计算股票的内在价值
present_values = []
for i, cf in enumerate(cash_flows):
    pv = cf / (1 + discount_rate) ** (i + 1)
    present_values.append(pv)

intrinsic_value = np.sum(present_values)

# 假设当前市场价格为 50
market_price = 50

# 判断股票是否被高估或低估
if intrinsic_value > market_price:
    print("该股票被低估")
elif intrinsic_value < market_price:
    print("该股票被高估")
else:
    print("该股票估值合理")
```

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 市盈率模型
#### 公式
$$P/E = \frac{股价}{每股收益}$$

#### 详细讲解
市盈率模型是一种简单直观的估值方法，它反映了投资者为获取每一元收益所愿意支付的价格。一般来说，市盈率越高，说明投资者对该股票的未来盈利增长预期越高，但同时也意味着股票的风险相对较大；市盈率越低，说明投资者对该股票的未来盈利增长预期越低，但同时也意味着股票的风险相对较小。

#### 举例说明
假设某股票的当前价格为 100 元，每股收益为 5 元，则该股票的市盈率为：
$$P/E = \frac{100}{5} = 20$$
如果同行业其他股票的平均市盈率为 15，则说明该股票的估值相对较高，可能存在一定的高估风险。

### 市净率模型
#### 公式
$$P/B = \frac{股价}{每股净资产}$$

#### 详细讲解
市净率模型是一种基于资产的估值方法，它反映了投资者为获取每一元净资产所愿意支付的价格。一般来说，市净率越高，说明投资者对该股票的未来盈利能力和资产质量预期越高，但同时也意味着股票的风险相对较大；市净率越低，说明投资者对该股票的未来盈利能力和资产质量预期越低，但同时也意味着股票的风险相对较小。

#### 举例说明
假设某股票的当前价格为 100 元，每股净资产为 20 元，则该股票的市净率为：
$$P/B = \frac{100}{20} = 5$$
如果同行业其他股票的平均市净率为 3，则说明该股票的估值相对较高，可能存在一定的高估风险。

### 贴现现金流模型
#### 公式
$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$

#### 详细讲解
贴现现金流模型是一种基于现金流的估值方法，它考虑了资金的时间价值，通过将未来各期的现金流按照一定的贴现率折现到当前时点，得到股票的内在价值。贴现率的选择是该模型的关键，它反映了投资者对资金的时间价值和风险的预期。一般来说，贴现率越高，说明投资者对资金的时间价值和风险的预期越高，股票的内在价值越低；贴现率越低，说明投资者对资金的时间价值和风险的预期越低，股票的内在价值越高。

#### 举例说明
假设某股票未来 5 年的现金流分别为 10 元、12 元、15 元、18 元和 20 元，贴现率为 10%，则该股票的内在价值为：
$$V = \frac{10}{(1 + 0.1)^1} + \frac{12}{(1 + 0.1)^2} + \frac{15}{(1 + 0.1)^3} + \frac{18}{(1 + 0.1)^4} + \frac{20}{(1 + 0.1)^5} \approx 52.38$$
如果该股票的当前市场价格为 50 元，则说明该股票的估值相对较低，可能存在一定的投资价值。

df['valuation'] = ['高估' if pe > industry_avg_pe else '低估' if pe < industry_avg_pe else '合理' for pe in df['pe_ratio']]
