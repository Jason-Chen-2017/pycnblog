### 1.4 术语表
#### 1.4.1 核心术语定义
- **烟蒂股（Cigar - butt stocks）**：指那些价格极其低廉，看上去就像被人丢弃的烟蒂，但可能还残留着一点可吸价值的股票。通常这类股票的公司经营状况不佳，但股价已经充分反映了其负面因素，具有一定的安全边际。
- **价值投资（Value investing）**：一种投资策略，强调通过分析公司的内在价值，寻找被市场低估的股票进行投资，以获取长期的投资回报。
- **安全边际（Margin of safety）**：指股票的内在价值与市场价格之间的差额。安全边际越大，投资的风险越低。
- **净流动资产价值（Net current asset value，NCAV）**：是衡量公司内在价值的一个重要指标，计算公式为：净流动资产价值 = 流动资产 - 总负债。

#### 1.4.2 相关概念解释
- **内在价值（Intrinsic value）**：公司的内在价值是指其未来现金流的现值。它是一个理论上的价值，不受市场短期波动的影响，是价值投资者判断股票是否被低估的重要依据。
- **市场效率（Market efficiency）**：市场效率是指市场价格反映所有可用信息的程度。在有效市场中，股票价格能够迅速反映所有公开信息，因此很难找到被低估的股票。而“烟蒂股”策略的前提是市场并非完全有效，存在一些被市场忽视或错误定价的股票。

#### 1.4.3 缩略词列表
- **NCAV**：净流动资产价值（Net current asset value）
- **P/E**：市盈率（Price - to - Earnings ratio）
- **P/B**：市净率（Price - to - Book ratio）

## 3. 核心算法原理 & 具体操作步骤 

### 核心算法原理
“烟蒂股”策略的核心算法主要围绕股票的估值展开，常用的估值指标包括市盈率（P/E）、市净率（P/B）和净流动资产价值（NCAV）。

#### 市盈率（P/E）
市盈率是指股票价格与每股收益的比率，计算公式为：
```python
def calculate_pe(stock_price, earnings_per_share):
    if earnings_per_share == 0:
        return None
    return stock_price / earnings_per_share
```
市盈率反映了市场对公司盈利的预期。一般来说，低市盈率的股票可能被市场低估。

#### 市净率（P/B）
市净率是指股票价格与每股净资产的比率，计算公式为：
```python
def calculate_pb(stock_price, book_value_per_share):
    if book_value_per_share == 0:
        return None
    return stock_price / book_value_per_share
```
市净率反映了市场对公司净资产的估值。低市净率的股票可能具有较高的安全边际。

#### 净流动资产价值（NCAV）
净流动资产价值是指公司的流动资产减去总负债后的价值，计算公式为：
```python
def calculate_ncav(current_assets, total_liabilities):
    return current_assets - total_liabilities
```
如果股票价格低于净流动资产价值的一定比例（如 66%），则该股票可能被视为“烟蒂股”。

### 具体操作步骤
1. **数据收集**：收集股票的相关数据，包括股票价格、每股收益、每股净资产、流动资产、总负债等。
```python
# 示例数据
stock_price = 10
earnings_per_share = 1
book_value_per_share = 5
current_assets = 1000
total_liabilities = 500
```
2. **计算估值指标**：根据上述公式计算市盈率、市净率和净流动资产价值。
```python
pe = calculate_pe(stock_price, earnings_per_share)
pb = calculate_pb(stock_price, book_value_per_share)
ncav = calculate_ncav(current_assets, total_liabilities)
```
3. **筛选股票**：根据估值指标筛选出符合条件的股票。例如，选择市盈率低于行业平均水平、市净率低于 1 且股票价格低于净流动资产价值 66% 的股票。
```python
industry_average_pe = 15
if pe is not None and pe < industry_average_pe and pb < 1 and stock_price < 0.66 * ncav:
    print("该股票符合烟蒂股筛选条件")
else:
    print("该股票不符合烟蒂股筛选条件")
```
4. **价值评估**：对筛选出的股票进行更深入的价值评估，考虑公司的财务状况、行业前景、竞争优势等因素。
5. **投资决策**：根据价值评估结果，做出投资决策。如果认为股票具有足够的安全边际和投资价值，则可以考虑买入。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 数学模型和公式
#### 市盈率（P/E）
$P/E=\frac{P}{EPS}$
其中，$P$ 表示股票价格，$EPS$ 表示每股收益。

#### 市净率（P/B）
$P/B=\frac{P}{BVPS}$
其中，$P$ 表示股票价格，$BVPS$ 表示每股净资产。

#### 净流动资产价值（NCAV）
$NCAV = CA - TL$
其中，$CA$ 表示流动资产，$TL$ 表示总负债。

### 详细讲解
- **市盈率（P/E）**：市盈率是衡量股票估值的常用指标之一。较低的市盈率可能意味着股票被低估，但也可能反映了公司的盈利前景不佳。因此，在使用市盈率进行估值时，需要结合公司的行业特点、盈利增长情况等因素进行综合分析。
- **市净率（P/B）**：市净率反映了市场对公司净资产的估值。一般来说，市净率低于 1 的股票可能被视为低估。但对于一些轻资产行业的公司，市净率可能不具有代表性，需要结合其他指标进行分析。
- **净流动资产价值（NCAV）**：净流动资产价值是一种较为保守的估值方法，它只考虑了公司的流动资产和负债，不考虑固定资产和无形资产。如果股票价格低于净流动资产价值的一定比例，说明公司的股价已经充分反映了其负面因素，具有一定的安全边际。

### 举例说明
假设某公司的股票价格为 $10$ 元，每股收益为 $1$ 元，每股净资产为 $5$ 元，流动资产为 $1000$ 万元，总负债为 $500$ 万元。

- **计算市盈率**：
$P/E=\frac{10}{1}=10$
该公司的市盈率为 $10$，如果行业平均市盈率为 $15$，则该公司的市盈率低于行业平均水平，可能被低估。

- **计算市净率**：
$P/B=\frac{10}{5}=2$
该公司的市净率为 $2$，如果市净率的合理范围在 $1 - 3$ 之间，则该公司的市净率处于合理范围内。

- **计算净流动资产价值**：
$NCAV = 1000 - 500 = 500$（万元）
假设该公司的总股本为 $100$ 万股，则每股净流动资产价值为 $5$ 元。如果股票价格低于每股净流动资产价值的 $66\%$，即低于 $3.3$ 元，则该股票可能被视为“烟蒂股”。

### 5.2  源代码详细实现和代码解读
```python
import yfinance as yf
import pandas as pd

# 定义股票列表
tickers = ['AAPL', 'MSFT', 'GOOG', 'TSLA']

# 初始化空列表用于存储筛选结果
selected_stocks = []

# 遍历股票列表
for ticker in tickers:
    try:
        # 获取股票数据
        stock = yf.Ticker(ticker)
        info = stock.info
        
        # 获取股票价格
        stock_price = info.get('regularMarketPrice')
        
        # 获取每股收益
        earnings_per_share = info.get('trailingEps')
        
        # 获取每股净资产
        book_value_per_share = info.get('bookValue')
        
        # 获取流动资产和总负债
        balance_sheet = stock.balance_sheet
        current_assets = balance_sheet.loc['Total Current Assets'].iloc[0]
        total_liabilities = balance_sheet.loc['Total Liab'].iloc[0]
        
        # 计算市盈率
        pe = calculate_pe(stock_price, earnings_per_share)
        
        # 计算市净率
        pb = calculate_pb(stock_price, book_value_per_share)
        
        # 计算净流动资产价值
        ncav = calculate_ncav(current_assets, total_liabilities)
        
        # 假设行业平均市盈率为 20
        industry_average_pe = 20
        
        # 筛选条件
        if pe is not None and pe < industry_average_pe and pb < 1 and stock_price < 0.66 * ncav:
            selected_stocks.append(ticker)
            print(f"{ticker} 符合烟蒂股筛选条件")
        else:
            print(f"{ticker} 不符合烟蒂股筛选条件")
    
    except Exception as e:
        print(f"获取 {ticker} 数据时出现错误: {e}")

print("筛选出的烟蒂股列表:", selected_stocks)
```
### 代码解读与分析
- **导入库**：导入 `yfinance` 库用于获取股票数据，导入 `pandas` 库用于数据处理。
- **定义股票列表**：定义需要筛选的股票列表。
- **遍历股票列表**：使用 `for` 循环遍历股票列表，对每只股票进行筛选。
- **获取股票数据**：使用 `yfinance` 库的 `Ticker` 类获取股票的基本信息和资产负债表数据。
- **计算估值指标**：根据前面定义的函数计算市盈率、市净率和净流动资产价值。
- **筛选条件判断**：根据筛选条件判断股票是否符合“烟蒂股”的标准，如果符合则将其添加到筛选结果列表中。
- **异常处理**：使用 `try - except` 语句捕获可能出现的异常，确保程序的稳定性。

## 6. 实际应用场景 
### 熊市环境
在熊市中，市场整体下跌，许多股票的价格被低估。“烟蒂股”策略可以帮助投资者在熊市中寻找那些被过度抛售的股票，以较低的价格买入，等待市场反弹。例如，在 2008 年金融危机期间，许多金融股的价格大幅下跌，一些符合“烟蒂股”标准的金融股在随后的市场反弹中表现出色。

### 小型股和冷门股市场
小型股和冷门股往往容易被市场忽视，其价格可能无法充分反映公司的内在价值。“烟蒂股”策略可以帮助投资者挖掘这些被忽视的股票，发现潜在的投资机会。例如，一些小型制造业公司或区域性企业，可能由于规模较小、知名度不高而被市场低估。

### 价值投资组合构建
“烟蒂股”策略可以作为价值投资组合的一部分，与其他投资策略相结合，实现投资组合的多元化。通过投资不同行业、不同规模的“烟蒂股”，可以降低投资组合的风险，提高投资回报的稳定性。
