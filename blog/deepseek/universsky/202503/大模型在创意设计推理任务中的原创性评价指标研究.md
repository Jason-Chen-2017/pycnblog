## 2. 核心概念与联系 

### 核心概念原理
大模型在创意设计推理任务中的原创性评价涉及多个核心概念。首先，大模型通过对大量数据的学习和理解，能够生成与设计任务相关的方案。这些方案的原创性取决于其与已有设计的差异程度。

设计空间是一个抽象的概念，它包含了所有可能的设计方案。大模型在设计空间中搜索和生成设计方案，而原创性评价就是判断这些生成方案在设计空间中的位置和独特性。

特征提取是原创性评价的关键步骤。通过提取设计作品的特征，可以将设计作品转化为向量表示，便于进行相似度计算。相似度计算则是衡量两个设计作品之间的相似程度，相似度越低，说明设计作品的原创性越高。

3. **特征提取模块**：对生成的设计方案和已有设计作品进行特征提取。
4. **相似度计算模块**：计算生成设计方案与已有设计作品之间的相似度。

## 3. 核心算法原理 & 具体操作步骤 

### 核心算法原理
本研究采用基于特征向量相似度的原创性评价算法。其核心思想是将设计作品表示为特征向量，然后计算生成设计方案的特征向量与已有设计作品特征向量之间的相似度。相似度越低，说明生成设计方案的原创性越高。

### 具体操作步骤
1. **数据预处理**：对输入的设计作品数据进行清洗、归一化等处理，确保数据的质量和一致性。
2. **特征提取**：使用合适的特征提取算法，如卷积神经网络（CNN）提取图像特征，词嵌入模型提取文本特征，将设计作品转化为特征向量。
3. **相似度计算**：选择合适的相似度计算方法，如欧几里得距离、余弦相似度等，计算生成设计方案的特征向量与已有设计作品特征向量之间的相似度。
4. **原创性评价**：根据相似度计算结果，设定合适的阈值，判断生成设计方案的原创性。如果相似度低于阈值，则认为生成设计方案具有较高的原创性。

### Python源代码实现
```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 模拟已有设计作品数据集
existing_designs = ["This is a sample design description 1",
                    "Another sample design description 2",
                    "A different design description 3"]

# 模拟大模型生成的设计方案
generated_design = "A brand new design description"

# 数据预处理和特征提取
vectorizer = TfidfVectorizer()
existing_vectors = vectorizer.fit_transform(existing_designs)
generated_vector = vectorizer.transform([generated_design])

# 相似度计算
similarities = cosine_similarity(generated_vector, existing_vectors)

# 原创性评价
threshold = 0.3
is_original = all(similarities[0] < threshold)

print(f"Generated design is original: {is_original}")
```

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 数学模型和公式
#### 特征向量表示
设设计作品 $x$ 经过特征提取后得到的特征向量为 $\mathbf{v}_x=(v_{x1},v_{x2},\cdots,v_{xn})$，其中 $n$ 为特征向量的维度。

#### 相似度计算
- **欧几里得距离**：两个特征向量 $\mathbf{v}_x$ 和 $\mathbf{v}_y$ 之间的欧几里得距离定义为：
$$d(\mathbf{v}_x,\mathbf{v}_y)=\sqrt{\sum_{i = 1}^{n}(v_{xi}-v_{yi})^2}$$
- **余弦相似度**：两个特征向量 $\mathbf{v}_x$ 和 $\mathbf{v}_y$ 之间的余弦相似度定义为：
$$\text{cosine}(\mathbf{v}_x,\mathbf{v}_y)=\frac{\mathbf{v}_x\cdot\mathbf{v}_y}{\|\mathbf{v}_x\|\|\mathbf{v}_y\|}=\frac{\sum_{i = 1}^{n}v_{xi}v_{yi}}{\sqrt{\sum_{i = 1}^{n}v_{xi}^2}\sqrt{\sum_{i = 1}^{n}v_{yi}^2}}$$

#### 原创性评价
设生成设计方案的特征向量为 $\mathbf{v}_g$，已有设计作品的特征向量集合为 $\{\mathbf{v}_{e1},\mathbf{v}_{e2},\cdots,\mathbf{v}_{em}\}$，相似度阈值为 $\tau$。如果 $\text{sim}(\mathbf{v}_g,\mathbf{v}_{ei})<\tau$ 对于所有 $i = 1,2,\cdots,m$ 都成立，则认为生成设计方案具有较高的原创性，其中 $\text{sim}$ 表示相似度计算函数。

### 详细讲解
欧几里得距离衡量的是两个特征向量在空间中的实际距离，距离越大，说明两个设计作品越不相似。余弦相似度衡量的是两个特征向量的方向相似度，值越接近 1 表示越相似，越接近 - 1 表示越不相似。

在原创性评价中，通过设定合适的阈值，可以判断生成设计方案与已有设计作品的差异程度。如果所有相似度都低于阈值，则认为生成设计方案具有较高的原创性。

### 举例说明
假设有两个设计作品 $x$ 和 $y$，其特征向量分别为 $\mathbf{v}_x=(1,2,3)$ 和 $\mathbf{v}_y=(4,5,6)$。

- **欧几里得距离计算**：
$$d(\mathbf{v}_x,\mathbf{v}_y)=\sqrt{(1 - 4)^2+(2 - 5)^2+(3 - 6)^2}=\sqrt{9 + 9+9}=\sqrt{27}\approx5.2$$
- **余弦相似度计算**：
$$\text{cosine}(\mathbf{v}_x,\mathbf{v}_y)=\frac{1\times4 + 2\times5+3\times6}{\sqrt{1^2 + 2^2+3^2}\sqrt{4^2 + 5^2+6^2}}=\frac{4 + 10+18}{\sqrt{14}\sqrt{77}}=\frac{32}{\sqrt{1078}}\approx0.97$$

如果设定相似度阈值 $\tau = 0.8$，由于余弦相似度大于阈值，说明这两个设计作品比较相似，原创性较低。

import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 模拟已有设计作品数据集
existing_designs = ["This is a sample design description 1",

# 计算生成设计方案的特征向量与已有设计作品特征向量之间的余弦相似度

# 原创性评价
# 设定相似度阈值

# 判断生成设计方案是否具有较高的原创性

### 5.3  代码解读与分析
- **数据准备**：`existing_designs` 列表存储了已有设计作品的描述，`generated_design` 存储了大模型生成的设计方案描述。
- **特征提取**：`TfidfVectorizer` 是一种常用的文本特征提取方法，它将文本转换为词频 - 逆文档频率（TF - IDF）特征向量。`fit_transform` 方法用于对已有设计作品数据集进行拟合和转换，`transform` 方法用于对生成的设计方案进行转换。
- **相似度计算**：`cosine_similarity` 函数计算生成设计方案的特征向量与已有设计作品特征向量之间的余弦相似度。
- **原创性评价**：通过设定阈值 `threshold`，判断生成设计方案的原创性。如果所有相似度都低于阈值，则认为生成设计方案具有较高的原创性。
