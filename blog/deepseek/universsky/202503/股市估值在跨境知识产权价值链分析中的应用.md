## 3. 核心算法原理 & 具体操作步骤 
### 市盈率法（P/E 法）
#### 算法原理
市盈率法是一种相对估值法，通过比较目标企业的市盈率与同行业或类似企业的市盈率，来评估目标企业的价值。市盈率的计算公式为：

$$P/E = \frac{股票价格}{每股收益}$$

其中，股票价格是指当前股票的市场价格，每股收益是指企业每股普通股的盈利。通过已知的每股收益和可比企业的市盈率，可以计算出目标企业的股票价格：

$$股票价格 = 每股收益 \times 市盈率$$

#### Python 代码实现
```python
def pe_valuation(eps, pe_ratio):
    """
    市盈率法估值函数
    :param eps: 每股收益
    :param pe_ratio: 市盈率
    :return: 股票价格
    """
    return eps * pe_ratio

# 示例
eps = 2.0  # 每股收益为 2 元
pe_ratio = 15  # 可比企业的市盈率为 15
stock_price = pe_valuation(eps, pe_ratio)
print(f"根据市盈率法计算的股票价格为: {stock_price} 元")
```

#### 具体操作步骤
1. 确定目标企业的每股收益（EPS），可以通过企业的财务报表获得。
2. 选择可比企业或行业平均市盈率作为参考。可比企业应与目标企业在业务、规模、成长阶段等方面具有相似性。
3. 将每股收益乘以可比企业的市盈率，得到目标企业的股票价格。

### 市净率法（P/B 法）
#### 算法原理
市净率法也是一种相对估值法，通过比较目标企业的市净率与同行业或类似企业的市净率，来评估目标企业的价值。市净率的计算公式为：

$$P/B = \frac{股票价格}{每股净资产}$$

其中，股票价格是指当前股票的市场价格，每股净资产是指企业每股普通股的净资产。通过已知的每股净资产和可比企业的市净率，可以计算出目标企业的股票价格：

$$股票价格 = 每股净资产 \times 市净率$$

#### Python 代码实现
```python
def pb_valuation(bvps, pb_ratio):
    """
    市净率法估值函数
    :param bvps: 每股净资产
    :param pb_ratio: 市净率
    :return: 股票价格
    """
    return bvps * pb_ratio

# 示例
bvps = 10.0  # 每股净资产为 10 元
pb_ratio = 1.5  # 可比企业的市净率为 1.5
stock_price = pb_valuation(bvps, pb_ratio)
print(f"根据市净率法计算的股票价格为: {stock_price} 元")
```

#### 具体操作步骤
1. 确定目标企业的每股净资产（BVPS），可以通过企业的财务报表获得。
2. 选择可比企业或行业平均市净率作为参考。可比企业应与目标企业在业务、规模、资产质量等方面具有相似性。
3. 将每股净资产乘以可比企业的市净率，得到目标企业的股票价格。

### 现金流折现法（DCF 法）
#### 算法原理
现金流折现法是一种绝对估值法，通过预测企业未来的现金流，并将其折现到当前时刻，计算出企业的内在价值。现金流折现法的基本公式为：

$$V = \sum_{t=1}^{n} \frac{FCF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$

其中，$V$ 是企业的内在价值，$FCF_t$ 是第 $t$ 年的自由现金流，$r$ 是折现率，$n$ 是预测期数，$TV$ 是终值。

自由现金流（FCF）的计算公式为：

$$FCF = EBIT \times (1 - T) + Depreciation - Capex - \Delta NWC$$

其中，$EBIT$ 是息税前利润，$T$ 是税率，$Depreciation$ 是折旧，$Capex$ 是资本支出，$\Delta NWC$ 是净营运资本的变化。

终值（TV）的计算公式通常采用永续增长模型：

$$TV = \frac{FCF_{n+1}}{r - g}$$

其中，$FCF_{n+1}$ 是预测期最后一年的下一年的自由现金流，$g$ 是永续增长率。

#### Python 代码实现
```python
def dcf_valuation(fcf_list, r, g):
    """
    现金流折现法估值函数
    :param fcf_list: 未来各年的自由现金流列表
    :param r: 折现率
    :param g: 永续增长率
    :return: 企业的内在价值
    """
    n = len(fcf_list)
    present_value = 0
    # 计算预测期内现金流的现值
    for t in range(n):
        present_value += fcf_list[t] / ((1 + r) ** (t + 1))
    # 计算终值
    fcf_n_plus_1 = fcf_list[-1] * (1 + g)
    tv = fcf_n_plus_1 / (r - g)
    # 计算终值的现值
    tv_present_value = tv / ((1 + r) ** n)
    # 计算企业的内在价值
    value = present_value + tv_present_value
    return value

# 示例
fcf_list = [100, 120, 140, 160, 180]  # 未来 5 年的自由现金流
r = 0.1  # 折现率为 10%
g = 0.03  # 永续增长率为 3%
enterprise_value = dcf_valuation(fcf_list, r, g)
print(f"根据现金流折现法计算的企业内在价值为: {enterprise_value} 元")
```

#### 具体操作步骤
1. 预测企业未来的自由现金流（FCF），通常需要对企业的收入、成本、折旧、资本支出等进行详细的预测。
2. 确定折现率（r），折现率反映了投资者对企业未来现金流的风险预期，通常可以采用加权平均资本成本（WACC）作为折现率。
3. 确定永续增长率（g），永续增长率是指企业在预测期结束后长期保持的增长率，通常取值在 2% - 5% 之间。
4. 计算预测期内现金流的现值和终值的现值，将两者相加得到企业的内在价值。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 
### 市盈率法（P/E 法）
#### 数学公式
$$P/E = \frac{P}{EPS}$$

其中，$P$ 是股票价格，$EPS$ 是每股收益。

变形可得：

$$P = P/E \times EPS$$

#### 详细讲解
市盈率法的核心思想是通过比较目标企业和可比企业的盈利倍数来评估目标企业的价值。市盈率反映了市场对企业未来盈利的预期，市盈率越高，说明市场对企业的前景越看好。但是，市盈率法也存在一定的局限性，例如不同行业的市盈率水平可能差异较大，而且市盈率容易受到市场情绪的影响。

#### 举例说明
假设一家科技公司 A 的每股收益为 2 元，同行业可比公司的平均市盈率为 20 倍。则根据市盈率法，公司 A 的股票价格为：

$$P = 20 \times 2 = 40$$（元）

这意味着，如果市场对公司 A 的预期与同行业可比公司相似，那么公司 A 的股票价格应该为 40 元。

### 市净率法（P/B 法）
#### 数学公式
$$P/B = \frac{P}{BVPS}$$

其中，$P$ 是股票价格，$BVPS$ 是每股净资产。

变形可得：

$$P = P/B \times BVPS$$

#### 详细讲解
市净率法的核心思想是通过比较目标企业和可比企业的净资产倍数来评估目标企业的价值。市净率反映了股票的市场价格相对于公司净资产的倍数，市净率越低，说明股票的估值越低。市净率法适用于资产规模较大、净资产相对稳定的企业，如银行、钢铁等行业。

#### 举例说明
假设一家银行 B 的每股净资产为 15 元，同行业可比银行的平均市净率为 1.2 倍。则根据市净率法，银行 B 的股票价格为：

$$P = 1.2 \times 15 = 18$$（元）

这意味着，如果市场对银行 B 的预期与同行业可比银行相似，那么银行 B 的股票价格应该为 18 元。

### 现金流折现法（DCF 法）
#### 数学公式
$$V = \sum_{t=1}^{n} \frac{FCF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^n}$$

其中，$V$ 是企业的内在价值，$FCF_t$ 是第 $t$ 年的自由现金流，$r$ 是折现率，$n$ 是预测期数，$TV$ 是终值。

自由现金流（FCF）的计算公式为：

$$FCF = EBIT \times (1 - T) + Depreciation - Capex - \Delta NWC$$

终值（TV）的计算公式通常采用永续增长模型：

$$TV = \frac{FCF_{n+1}}{r - g}$$

#### 详细讲解
现金流折现法的核心思想是将企业未来的现金流折现到当前时刻，以反映货币的时间价值和风险因素。该方法考虑了企业的长期盈利能力和现金流状况，是一种较为科学的估值方法。但是，现金流折现法的计算过程较为复杂，需要对企业的未来现金流、折现率和永续增长率进行准确的预测。

#### 举例说明
假设一家企业 C 未来 5 年的自由现金流分别为 100 万元、120 万元、140 万元、160 万元和 180 万元，折现率为 10%，永续增长率为 3%。

首先，计算预测期内现金流的现值：

$$PV_1 = \frac{100}{(1 + 0.1)^1} = 90.91$$（万元）

$$PV_2 = \frac{120}{(1 + 0.1)^2} = 99.17$$（万元）

$$PV_3 = \frac{140}{(1 + 0.1)^3} = 105.18$$（万元）

$$PV_4 = \frac{160}{(1 + 0.1)^4} = 109.28$$（万元）

$$PV_5 = \frac{180}{(1 + 0.1)^5} = 111.72$$（万元）

预测期内现金流的现值总和为：

$$PV_{total} = 90.91 + 99.17 + 105.18 + 109.28 + 111.72 = 516.26$$（万元）

然后，计算终值：

$$FCF_6 = 180 \times (1 + 0.03) = 185.4$$（万元）

$$TV = \frac{185.4}{0.1 - 0.03} = 2648.57$$（万元）

终值的现值为：

$$PV_{TV} = \frac{2648.57}{(1 + 0.1)^5} = 1647.74$$（万元）

最后，计算企业的内在价值：

$$V = 516.26 + 1647.74 = 2164$$（万元）

这意味着，根据现金流折现法，企业 C 的内在价值为 2164 万元。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 模拟一家企业的财务数据
data = {
    'Year': [2020, 2021, 2022, 2023, 2024],
    'EPS': [1.0, 1.2, 1.4, 1.6, 1.8],  # 每股收益
    'BVPS': [10.0, 11.0, 12.0, 13.0, 14.0],  # 每股净资产
    'FCF': [100, 120, 140, 160, 180]  # 自由现金流
}

df = pd.DataFrame(data)

# 市盈率法估值
pe_ratio = 15  # 假设可比企业的市盈率为 15
df['PE_Valuation'] = df['EPS'] * pe_ratio

# 市净率法估值
pb_ratio = 1.2  # 假设可比企业的市净率为 1.2
df['PB_Valuation'] = df['BVPS'] * pb_ratio

# 现金流折现法估值
r = 0.1  # 折现率为 10%
g = 0.03  # 永续增长率为 3%
fcf_list = df['FCF'].tolist()
enterprise_value = 0
n = len(fcf_list)
# 计算预测期内现金流的现值
for t in range(n):
    enterprise_value += fcf_list[t] / ((1 + r) ** (t + 1))
# 计算终值
fcf_n_plus_1 = fcf_list[-1] * (1 + g)
tv = fcf_n_plus_1 / (r - g)
# 计算终值的现值
tv_present_value = tv / ((1 + r) ** n)
# 计算企业的内在价值
enterprise_value += tv_present_value
# 假设企业发行了 100 万股股票，计算每股价值
shares_outstanding = 100
df['DCF_Valuation'] = enterprise_value / shares_outstanding

print(df)

# 可视化估值结果
plt.figure(figsize=(10, 6))
plt.plot(df['Year'], df['PE_Valuation'], label='PE Valuation')
plt.plot(df['Year'], df['PB_Valuation'], label='PB Valuation')
plt.plot(df['Year'], df['DCF_Valuation'], label='DCF Valuation')
plt.xlabel('Year')
plt.ylabel('Stock Price')
plt.title('Stock Valuation Comparison')
plt.legend()
plt.grid(True)
plt.show()
```
