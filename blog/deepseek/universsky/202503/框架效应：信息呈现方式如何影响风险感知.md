### 1.4 术语表
#### 1.4.1 核心术语定义
- **框架效应（Framing Effect）**：指人们对一个客观上相同问题的不同描述导致了不同的决策判断。也就是说，信息的呈现方式会影响人们对问题的感知和决策。
- **风险感知（Risk Perception）**：个体对风险的认识、感受和判断，它受到多种因素的影响，包括信息呈现方式、个人经验、文化背景等。
- **决策（Decision Making）**：在多个可供选择的方案中，根据一定的标准和目标，选择一个最优或最满意的方案的过程。

#### 1.4.2 相关概念解释
- **收益框架（Gain Frame）**：信息以强调收益的方式呈现，例如“采用这种方案，有 80%的机会获得收益”。
- **损失框架（Loss Frame）**：信息以强调损失的方式呈现，例如“不采用这种方案，有 80%的机会遭受损失”。
- **风险偏好（Risk Preference）**：个体在面对风险时的态度，包括风险规避（Risk Aversion）、风险中立（Risk Neutrality）和风险追求（Risk Seeking）。

## 2. 核心概念与联系 
### 核心概念原理
框架效应的核心原理在于人类的认知和决策过程并非完全理性，而是受到信息呈现方式的影响。当信息以不同的框架呈现时，人们会对相同的问题产生不同的风险感知和决策偏好。

例如，在一个经典的实验中，研究人员向两组参与者描述了一个疾病防控方案：
- 对于第一组参与者，信息以收益框架呈现：“如果采用方案 A，有 200 人将获救；如果采用方案 B，有 1/3 的概率 600 人全部获救，2/3 的概率无人获救。”
- 对于第二组参与者，信息以损失框架呈现：“如果采用方案 A，有 400 人将死亡；如果采用方案 B，有 1/3 的概率无人死亡，2/3 的概率 600 人全部死亡。”

结果发现，在收益框架下，大多数参与者选择了方案 A；而在损失框架下，大多数参与者选择了方案 B。这表明，信息的呈现方式（收益或损失框架）改变了人们对风险的感知和决策。

## 3. 核心算法原理 & 具体操作步骤 
### 算法原理讲解
在研究框架效应时，我们可以使用期望效用理论来解释人们的决策过程。期望效用理论认为，人们在决策时会考虑每个方案的预期效用，即每个结果的效用乘以其发生的概率之和。

设 $x_i$ 表示第 $i$ 个结果，$p_i$ 表示第 $i$ 个结果发生的概率，$u(x_i)$ 表示第 $i$ 个结果的效用，则方案的期望效用 $EU$ 可以表示为：

$$EU = \sum_{i=1}^{n} p_i u(x_i)$$

在框架效应中，信息的呈现方式会影响人们对结果的效用评估。例如，在收益框架下，人们更倾向于规避风险，对确定的收益赋予更高的效用；而在损失框架下，人们更倾向于追求风险，对可能避免的损失赋予更高的效用。

### Python 源代码详细阐述
```python
# 定义一个函数来计算期望效用
def expected_utility(probabilities, utilities):
    """
    计算期望效用
    :param probabilities: 每个结果发生的概率列表
    :param utilities: 每个结果的效用列表
    :return: 期望效用
    """
    if len(probabilities)!= len(utilities):
        raise ValueError("概率列表和效用列表的长度必须相同")
    eu = 0
    for p, u in zip(probabilities, utilities):
        eu += p * u
    return eu

# 示例：收益框架下的决策
# 方案 A：有 100% 的概率获得 200 元
probabilities_a_gain = [1.0]
utilities_a_gain = [200]
eu_a_gain = expected_utility(probabilities_a_gain, utilities_a_gain)

# 方案 B：有 50% 的概率获得 400 元，50% 的概率获得 0 元
probabilities_b_gain = [0.5, 0.5]
utilities_b_gain = [400, 0]
eu_b_gain = expected_utility(probabilities_b_gain, utilities_b_gain)

print("收益框架下，方案 A 的期望效用:", eu_a_gain)
print("收益框架下，方案 B 的期望效用:", eu_b_gain)

# 示例：损失框架下的决策
# 方案 A：有 100% 的概率损失 200 元
probabilities_a_loss = [1.0]
utilities_a_loss = [-200]
eu_a_loss = expected_utility(probabilities_a_loss, utilities_a_loss)

# 方案 B：有 50% 的概率损失 400 元，50% 的概率损失 0 元
probabilities_b_loss = [0.5, 0.5]
utilities_b_loss = [-400, 0]
eu_b_loss = expected_utility(probabilities_b_loss, utilities_b_loss)

print("损失框架下，方案 A 的期望效用:", eu_a_loss)
print("损失框架下，方案 B 的期望效用:", eu_b_loss)
```

### 具体操作步骤
1. **确定决策方案**：明确需要进行决策的各个方案。
2. **确定结果和概率**：对于每个方案，确定可能出现的结果以及每个结果发生的概率。
3. **评估效用**：根据信息呈现方式（收益或损失框架），评估每个结果的效用。在收益框架下，对确定的收益赋予较高的效用；在损失框架下，对可能避免的损失赋予较高的效用。
4. **计算期望效用**：使用上述的期望效用公式，计算每个方案的期望效用。
5. **做出决策**：选择期望效用最高的方案。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 
### 数学模型和公式
#### 期望效用理论公式
如前文所述，期望效用 $EU$ 的计算公式为：

$$EU = \sum_{i=1}^{n} p_i u(x_i)$$

其中，$n$ 表示结果的数量，$p_i$ 表示第 $i$ 个结果发生的概率，$u(x_i)$ 表示第 $i$ 个结果的效用。

#### 前景理论公式
前景理论是对期望效用理论的改进，它考虑了人们在决策时对收益和损失的不同心理反应。前景理论的价值函数 $v(x)$ 可以表示为：

$$v(x) = \begin{cases}
x^{\alpha} & \text{if } x \geq 0 \\
-\lambda (-x)^{\beta} & \text{if } x < 0
\end{cases}$$

其中，$x$ 表示结果的价值，$\alpha$ 和 $\beta$ 是风险偏好参数，通常 $\alpha, \beta \in (0, 1)$，$\lambda$ 是损失厌恶系数，通常 $\lambda > 1$。

### 详细讲解
#### 期望效用理论
期望效用理论假设人们在决策时是理性的，会根据每个方案的期望效用来做出选择。然而，在实际决策中，人们往往会受到框架效应的影响，导致决策偏离期望效用理论的预测。

#### 前景理论
前景理论认为，人们在决策时会对收益和损失进行不同的评估。在收益领域，人们是风险规避的，即更倾向于选择确定的收益；在损失领域，人们是风险追求的，即更倾向于选择可能避免损失的方案。价值函数的形状反映了这种心理特征，在收益部分是凹函数，在损失部分是凸函数，且损失部分的斜率更大，反映了人们的损失厌恶心理。

### 举例说明
#### 期望效用理论举例
假设你面临两个投资方案：
- 方案 A：有 80% 的概率获得 1000 元，20% 的概率获得 0 元。
- 方案 B：有 100% 的概率获得 600 元。

使用期望效用理论计算：
- 方案 A 的期望效用：$EU_A = 0.8 \times 1000 + 0.2 \times 0 = 800$
- 方案 B 的期望效用：$EU_B = 1.0 \times 600 = 600$

根据期望效用理论，应该选择方案 A。

#### 前景理论举例
假设 $\alpha = 0.88$，$\beta = 0.88$，$\lambda = 2.25$。对于上述投资方案：
- 方案 A：
    - 获得 1000 元的价值：$v(1000) = 1000^{0.88} \approx 379.7$
    - 获得 0 元的价值：$v(0) = 0$
    - 方案 A 的期望价值：$EV_A = 0.8 \times 379.7 + 0.2 \times 0 \approx 303.8$
- 方案 B：
    - 获得 600 元的价值：$v(600) = 600^{0.88} \approx 271.4$
    - 方案 B 的期望价值：$EV_B = 1.0 \times 271.4 = 271.4$

根据前景理论，仍然应该选择方案 A。但如果考虑到框架效应，信息呈现方式可能会改变人们对价值的评估，从而影响决策。

### 5.2  源代码详细实现和代码解读
以下是一个更复杂的代码示例，模拟了不同框架效应下的决策过程：

```python
import numpy as np

# 定义前景理论的价值函数
def value_function(x, alpha=0.88, beta=0.88, lambda_=2.25):
    """
    前景理论的价值函数
    :param x: 结果的价值
    :param alpha: 收益领域的风险偏好参数
    :param beta: 损失领域的风险偏好参数
    :param lambda_: 损失厌恶系数
    :return: 价值函数的值
    """
    if x >= 0:
        return x ** alpha
    else:
        return -lambda_ * (-x) ** beta

# 定义一个函数来计算前景理论下的期望价值
def prospect_value(probabilities, values, alpha=0.88, beta=0.88, lambda_=2.25):
    """
    计算前景理论下的期望价值
    :param probabilities: 每个结果发生的概率列表
    :param values: 每个结果的价值列表
    :param alpha: 收益领域的风险偏好参数
    :param beta: 损失领域的风险偏好参数
    :param lambda_: 损失厌恶系数
    :return: 前景理论下的期望价值
    """
    if len(probabilities)!= len(values):
        raise ValueError("概率列表和价值列表的长度必须相同")
    pv = 0
    for p, v in zip(probabilities, values):
        pv += p * value_function(v, alpha, beta, lambda_)
    return pv

# 示例：收益框架和损失框架下的决策
# 方案 A：有 100% 的概率获得 200 元（收益框架）或损失 200 元（损失框架）
probabilities_a = [1.0]
values_a_gain = [200]
values_a_loss = [-200]

# 方案 B：有 50% 的概率获得 400 元，50% 的概率获得 0 元（收益框架）
# 或有 50% 的概率损失 400 元，50% 的概率损失 0 元（损失框架）
probabilities_b = [0.5, 0.5]
values_b_gain = [400, 0]
values_b_loss = [-400, 0]

# 计算收益框架下的前景理论期望价值
pv_a_gain = prospect_value(probabilities_a, values_a_gain)
pv_b_gain = prospect_value(probabilities_b, values_b_gain)

# 计算损失框架下的前景理论期望价值
pv_a_loss = prospect_value(probabilities_a, values_a_loss)
pv_b_loss = prospect_value(probabilities_b, values_b_loss)

print("收益框架下，方案 A 的前景理论期望价值:", pv_a_gain)
print("收益框架下，方案 B 的前景理论期望价值:", pv_b_gain)
print("损失框架下，方案 A 的前景理论期望价值:", pv_a_loss)
print("损失框架下，方案 B 的前景理论期望价值:", pv_b_loss)

# 根据前景理论期望价值做出决策
if pv_a_gain > pv_b_gain:
    print("收益框架下，选择方案 A")
else:
    print("收益框架下，选择方案 B")

if pv_a_loss > pv_b_loss:
    print("损失框架下，选择方案 A")
else:
    print("损失框架下，选择方案 B")
```

2. **前景理论期望价值函数 `prospect_value`**：根据输入的概率列表和价值列表，计算前景理论下的期望价值。

## 6. 实际应用场景 
### 市场营销
在市场营销中，框架效应可以用于产品宣传和促销活动。例如，商家可以采用收益框架来宣传产品的优点，如“使用我们的产品，你将获得 20%的效率提升”；也可以采用损失框架来制造紧迫感，如“错过这次促销活动，你将损失 30%的优惠”。通过不同的信息呈现方式，影响消费者的风险感知和购买决策。

### 金融投资
在金融投资领域，框架效应也起着重要作用。投资顾问可以通过不同的信息呈现方式，影响投资者对投资产品的风险感知。例如，在介绍股票时，可以采用收益框架：“这只股票有 70%的概率在未来一年上涨 20%”；也可以采用损失框架：“这只股票有 30%的概率在未来一年下跌 10%”。不同的框架可能会导致投资者做出不同的投资决策。

### 公共政策制定
在公共政策制定中，框架效应可以用于引导公众对政策的接受度。例如，在推广节能减排政策时，可以采用收益框架：“采用节能措施，你将为环境保护做出贡献，同时每年节省 500 元的能源费用”；也可以采用损失框架：“不采用节能措施，你将加剧环境污染，并且每年多花费 500 元的能源费用”。通过不同的信息呈现方式，提高公众对政策的支持率。

### 医疗决策
在医疗决策中，框架效应会影响患者对治疗方案的选择。医生可以采用收益框架：“这种治疗方法有 80%的成功率，可以有效缓解你的症状”；也可以采用损失框架：“不采用这种治疗方法，你有 20%的概率病情恶化”。不同的框架可能会导致患者对治疗方案的风险感知不同，从而影响他们的决策。

## 9. 附录：常见问题与解答
### 问题 1：框架效应是否总是会导致不理性的决策？
解答：框架效应并不总是导致不理性的决策。虽然框架效应会影响人们的风险感知和决策偏好，但在某些情况下，这种影响可能是合理的。例如，在某些紧急情况下，损失框架可能会促使人们采取更积极的行动，从而避免更大的损失。然而，在大多数情况下，框架效应可能会导致人们的决策偏离理性的期望效用理论，需要我们在决策时保持警惕。

### 问题 2：如何避免框架效应的影响？
解答：要避免框架效应的影响，可以采取以下措施：
- **多角度思考**：在面对决策时，尝试从不同的角度去思考问题，分析信息的本质，而不是仅仅被信息的呈现方式所左右。
- **了解框架效应**：通过学习和了解框架效应的原理和影响，提高自己对其的认知和敏感度，从而在决策时能够识别出可能存在的框架效应。
- **寻求客观信息**：尽量获取更多的客观信息，避免只依赖单一的信息来源，以减少框架效应的影响。

### 问题 3：框架效应在不同文化背景下是否存在差异？
解答：框架效应在不同文化背景下可能存在差异。文化因素会影响人们的价值观、思维方式和决策习惯，从而导致对框架效应的敏感程度和反应方式不同。例如，一些研究表明，集体主义文化背景下的人们可能对损失框架更为敏感，而个人主义文化背景下的人们可能对收益框架更为关注。但具体的差异还需要更多的研究来证实。
