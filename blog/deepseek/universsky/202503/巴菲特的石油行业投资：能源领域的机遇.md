## 2. 核心概念与联系 

### 石油行业的基本原理
石油行业是一个复杂的产业链，包括上游的勘探和开采、中游的运输和储存以及下游的炼制和销售。上游企业通过地质勘探寻找石油资源，并进行开采作业。中游企业负责将开采出来的石油运输到炼油厂或储存设施。下游企业则将石油炼制为各种石油产品，如汽油、柴油、煤油等，并销售给终端用户。

### 市场架构
石油市场是一个全球性的市场，受到供需关系、地缘政治、宏观经济等多种因素的影响。国际油价的波动对石油行业的各个环节都有着重要的影响。石油市场主要分为现货市场和期货市场。现货市场是指实际的石油交易，而期货市场则是进行石油期货合约的交易，投资者可以通过期货市场进行套期保值或投机交易。

## 3. 核心算法原理 & 具体操作步骤 

### 投资价值评估算法
在评估石油行业的投资价值时，我们可以采用以下步骤：

1. **确定关键指标**：选择与石油行业相关的关键指标，如市盈率、股息率、净资产收益率等。
2. **收集数据**：收集目标企业的财务数据和市场数据。
3. **计算指标值**：根据收集到的数据计算关键指标的值。
4. **比较分析**：将计算得到的指标值与同行业其他企业或市场平均水平进行比较。
5. **评估投资价值**：根据比较结果评估目标企业的投资价值。

### Python 代码实现
```python
import pandas as pd

# 定义一个函数来计算市盈率
def calculate_pe_ratio(stock_price, earnings_per_share):
    return stock_price / earnings_per_share

# 定义一个函数来计算股息率
def calculate_dividend_yield(dividend_per_share, stock_price):
    return (dividend_per_share / stock_price) * 100

# 假设我们有以下数据
data = {
    '公司名称': ['A公司', 'B公司', 'C公司'],
    '股票价格': [50, 60, 70],
    '每股盈利': [5, 6, 7],
    '每股股息': [2, 3, 4]
}

df = pd.DataFrame(data)

# 计算市盈率和股息率
df['市盈率'] = df.apply(lambda row: calculate_pe_ratio(row['股票价格'], row['每股盈利']), axis=1)
df['股息率'] = df.apply(lambda row: calculate_dividend_yield(row['每股股息'], row['股票价格']), axis=1)

# 输出结果
print(df)
```

### 代码解释
上述代码首先定义了两个函数 `calculate_pe_ratio` 和 `calculate_dividend_yield` 分别用于计算市盈率和股息率。然后创建了一个包含公司名称、股票价格、每股盈利和每股股息的 DataFrame。接着使用 `apply` 方法计算每个公司的市盈率和股息率，并将结果添加到 DataFrame 中。最后打印出计算结果。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 市盈率模型
市盈率（PE）是评估股票估值的常用指标，其计算公式为：
$$PE = \frac{P}{E}$$
其中，$P$ 表示股票价格，$E$ 表示每股盈利。

市盈率反映了投资者为获得每一元盈利所愿意支付的价格。一般来说，市盈率较低的股票可能被低估，具有较高的投资价值；而市盈率较高的股票可能被高估，投资风险相对较大。

例如，某石油公司的股票价格为 50 元，每股盈利为 5 元，则该公司的市盈率为：
$$PE = \frac{50}{5} = 10$$

### 股息率模型
股息率（Dividend Yield）是衡量股票分红收益的指标，其计算公式为：
$$Dividend\ Yield = \frac{D}{P} \times 100\%$$
其中，$D$ 表示每股股息，$P$ 表示股票价格。

股息率反映了投资者从股票分红中获得的收益率。较高的股息率通常意味着股票具有较好的分红能力，对于追求稳定收益的投资者具有吸引力。

例如，某石油公司的股票价格为 60 元，每股股息为 3 元，则该公司的股息率为：
$$Dividend\ Yield = \frac{3}{60} \times 100\% = 5\%$$

### 内在价值模型
内在价值是资产本身所具有的真实价值，常用的计算方法是现金流折现模型（DCF）。该模型的基本思想是将资产未来的现金流折现到当前时刻，以确定其内在价值。

现金流折现模型的公式为：
$$V = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$
其中，$V$ 表示资产的内在价值，$CF_t$ 表示第 $t$ 期的现金流，$r$ 表示折现率，$n$ 表示现金流的期数。

例如，某石油公司预计未来三年的现金流分别为 100 万元、120 万元和 150 万元，折现率为 10%，则该公司的内在价值为：
$$V = \frac{100}{(1 + 0.1)^1} + \frac{120}{(1 + 0.1)^2} + \frac{150}{(1 + 0.1)^3} \approx 295.37 \text{万元}$$

### 5.2  源代码详细实现和代码解读
以下是一个完整的石油行业投资分析项目的代码示例：

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 读取石油公司财务数据
data = {
    '公司名称': ['A公司', 'B公司', 'C公司'],
    '股票价格': [50, 60, 70],
    '每股盈利': [5, 6, 7],
    '每股股息': [2, 3, 4],
    '净资产': [100, 120, 150],
    '总股本': [10, 12, 15]
}

df = pd.DataFrame(data)

# 计算市盈率、股息率和市净率
df['市盈率'] = df['股票价格'] / df['每股盈利']
df['股息率'] = (df['每股股息'] / df['股票价格']) * 100
df['市净率'] = df['股票价格'] / (df['净资产'] / df['总股本'])

# 绘制市盈率、股息率和市净率的柱状图
labels = df['公司名称']
pe_ratios = df['市盈率']
dividend_yields = df['股息率']
pb_ratios = df['市净率']

x = np.arange(len(labels))
width = 0.25

fig, ax = plt.subplots()
rects1 = ax.bar(x - width, pe_ratios, width, label='市盈率')
rects2 = ax.bar(x, dividend_yields, width, label='股息率')
rects3 = ax.bar(x + width, pb_ratios, width, label='市净率')

ax.set_ylabel('指标值')
ax.set_title('石油公司投资指标比较')
ax.set_xticks(x)
ax.set_xticklabels(labels)
ax.legend()

def autolabel(rects):
    for rect in rects:
        height = rect.get_height()
        ax.annotate('{:.2f}'.format(height),
                    xy=(rect.get_x() + rect.get_width() / 2, height),
                    xytext=(0, 3),  # 3 points vertical offset
                    textcoords="offset points",
                    ha='center', va='bottom')

autolabel(rects1)
autolabel(rects2)
autolabel(rects3)

fig.tight_layout()

plt.show()

# 筛选出市盈率低于 10 且股息率高于 4% 的公司
selected_companies = df[(df['市盈率'] < 10) & (df['股息率'] > 4)]
print("筛选出的公司：")
print(selected_companies)
```

### 代码解读与分析
1. **数据读取和处理**：首先创建一个包含石油公司财务数据的字典，并将其转换为 DataFrame。然后计算每个公司的市盈率、股息率和市净率。
2. **数据可视化**：使用 `matplotlib` 库绘制市盈率、股息率和市净率的柱状图，以便直观地比较不同公司的投资指标。
3. **筛选投资标的**：根据市盈率低于 10 且股息率高于 4% 的条件筛选出符合要求的公司，并打印筛选结果。

通过这个项目实战，我们可以对石油公司的投资价值进行初步评估，并筛选出具有投资潜力的公司。
