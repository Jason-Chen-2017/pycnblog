### 1.4 术语表
#### 1.4.1 核心术语定义
- **对比资产价值投资策略**：戴维·德雷曼提出的一种投资策略，通过对比不同公司的资产价值，评估其股票的投资价值，以寻找被市场低估的股票进行投资。

- **市场效率**：指市场价格反映所有可用信息的程度。在有效市场中，股票价格能够及时、准确地反映公司的内在价值；而在非有效市场中，股票价格可能会偏离其内在价值，为价值投资者提供机会。
- **价值投资**：一种投资理念，强调寻找被市场低估的股票，通过长期持有来实现资产的增值。价值投资者关注公司的基本面，如资产价值、盈利能力等。

#### 1.4.3 缩略词列表
- **PE**：市盈率（Price - Earnings Ratio），是股票价格与每股收益的比率，用于衡量股票的估值水平。
- **PB**：市净率（Price - Book Ratio），是股票价格与每股净资产的比率，反映了市场对公司资产价值的认可程度。

## 3. 核心算法原理 & 具体操作步骤 
### 核心算法原理
该策略的核心算法主要是通过计算和对比各种财务指标来评估公司的资产价值和投资价值。以下是一些常用的财务指标及其计算方法：
- **市盈率（PE）**：$PE = \frac{股票价格}{每股收益}$
- **市净率（PB）**：$PB = \frac{股票价格}{每股净资产}$
- **净资产收益率（ROE）**：$ROE = \frac{净利润}{股东权益}$

投资者会选择那些市盈率和市净率较低，而净资产收益率较高的股票，认为这些股票可能被市场低估，具有较高的投资价值。

### 具体操作步骤（Python 源代码）
以下是一个使用 Python 实现的简单示例，用于计算和对比不同公司的财务指标：

```python
# 定义公司类
class Company:
    def __init__(self, name, stock_price, earnings_per_share, book_value_per_share, net_income, shareholders_equity):
        self.name = name
        self.stock_price = stock_price
        self.earnings_per_share = earnings_per_share
        self.book_value_per_share = book_value_per_share
        self.net_income = net_income
        self.shareholders_equity = shareholders_equity

    def calculate_pe(self):
        return self.stock_price / self.earnings_per_share

    def calculate_pb(self):
        return self.stock_price / self.book_value_per_share

    def calculate_roe(self):
        return self.net_income / self.shareholders_equity

# 创建公司对象
company1 = Company("Company A", 50, 5, 20, 1000000, 5000000)
company2 = Company("Company B", 30, 3, 15, 800000, 4000000)

# 计算财务指标
pe1 = company1.calculate_pe()
pb1 = company1.calculate_pb()
roe1 = company1.calculate_roe()

pe2 = company2.calculate_pe()
pb2 = company2.calculate_pb()
roe2 = company2.calculate_roe()

# 输出结果
print(f"{company1.name} 的市盈率: {pe1}")
print(f"{company1.name} 的市净率: {pb1}")
print(f"{company1.name} 的净资产收益率: {roe1}")

print(f"{company2.name} 的市盈率: {pe2}")
print(f"{company2.name} 的市净率: {pb2}")
print(f"{company2.name} 的净资产收益率: {roe2}")

# 对比评估
if pe1 < pe2 and pb1 < pb2 and roe1 > roe2:
    print(f"{company1.name} 可能更具投资价值")
elif pe2 < pe1 and pb2 < pb1 and roe2 > roe1:
    print(f"{company2.name} 可能更具投资价值")
else:
    print("需要进一步分析")
```

2. **创建公司对象**：创建了两个公司对象 `company1` 和 `company2`，并初始化了它们的财务数据。
3. **计算财务指标**：调用公司对象的方法计算市盈率、市净率和净资产收益率。
4. **输出结果**：打印出每个公司的财务指标。
5. **对比评估**：根据计算结果进行对比评估，判断哪个公司可能更具投资价值。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 
### 数学模型和公式
- **市盈率（PE）**：$PE = \frac{P}{EPS}$，其中 $P$ 表示股票价格，$EPS$ 表示每股收益。市盈率反映了投资者为获取每股收益所愿意支付的价格。一般来说，市盈率较低的股票可能被低估。
- **市净率（PB）**：$PB = \frac{P}{BVPS}$，其中 $P$ 表示股票价格，$BVPS$ 表示每股净资产。市净率反映了市场对公司净资产的认可程度。市净率较低的股票可能具有更高的安全边际。
- **净资产收益率（ROE）**：$ROE = \frac{NI}{SE}$，其中 $NI$ 表示净利润，$SE$ 表示股东权益。净资产收益率衡量了公司运用自有资本的效率。较高的净资产收益率表明公司具有较强的盈利能力。

### 详细讲解
- **市盈率（PE）**：市盈率是一种常用的估值指标，它可以帮助投资者判断股票的相对估值水平。例如，如果一只股票的市盈率为 10，意味着投资者需要支付 10 倍的每股收益来购买该股票。不同行业的市盈率水平可能会有所差异，因此在使用市盈率进行比较时，需要考虑行业因素。
- **市净率（PB）**：市净率反映了股票价格与每股净资产的关系。如果市净率小于 1，说明股票价格低于每股净资产，可能存在被低估的情况。市净率可以作为一种安全边际的指标，帮助投资者筛选出具有一定资产支撑的股票。
- **净资产收益率（ROE）**：净资产收益率衡量了公司的盈利能力和股东权益的回报水平。较高的净资产收益率表明公司能够有效地利用股东的资金创造利润。投资者通常会关注那些净资产收益率持续稳定较高的公司。

### 举例说明
假设公司 A 的股票价格为 50 元，每股收益为 5 元，每股净资产为 20 元，净利润为 1000 万元，股东权益为 5000 万元。则该公司的市盈率为：$PE = \frac{50}{5} = 10$；市净率为：$PB = \frac{50}{20} = 2.5$；净资产收益率为：$ROE = \frac{1000}{5000} = 0.2$ 或 20%。

假设公司 B 的股票价格为 30 元，每股收益为 3 元，每股净资产为 15 元，净利润为 800 万元，股东权益为 4000 万元。则该公司的市盈率为：$PE = \frac{30}{3} = 10$；市净率为：$PB = \frac{30}{15} = 2$；净资产收益率为：$ROE = \frac{800}{4000} = 0.2$ 或 20%。

通过对比可以发现，公司 B 的市净率较低，在市盈率和净资产收益率相同的情况下，公司 B 可能更具投资价值。

### 5.2  源代码详细实现和代码解读
以下是一个更复杂的项目实战代码示例，用于从 CSV 文件中读取公司财务数据，计算财务指标，并进行对比分析：

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 读取 CSV 文件
def read_data(file_path):
    data = pd.read_csv(file_path)
    return data

# 计算财务指标
def calculate_metrics(data):
    data['PE'] = data['Stock_Price'] / data['Earnings_Per_Share']
    data['PB'] = data['Stock_Price'] / data['Book_Value_Per_Share']
    data['ROE'] = data['Net_Income'] / data['Shareholders_Equity']
    return data

# 对比评估
def compare_evaluation(data):
    # 筛选出市盈率和市净率较低，净资产收益率较高的公司
    low_pe_pb_high_roe = data[(data['PE'] < data['PE'].mean()) & (data['PB'] < data['PB'].mean()) & (data['ROE'] > data['ROE'].mean())]
    return low_pe_pb_high_roe

# 可视化结果
def visualize_results(data):
    plt.figure(figsize=(10, 6))
    plt.scatter(data['PE'], data['PB'], c=data['ROE'], cmap='viridis')
    plt.colorbar(label='ROE')
    plt.xlabel('PE')
    plt.ylabel('PB')
    plt.title('PE vs PB with ROE')
    plt.show()

# 主函数
def main():
    file_path = 'company_data.csv'
    data = read_data(file_path)
    data = calculate_metrics(data)
    selected_companies = compare_evaluation(data)
    print("筛选出的具有投资价值的公司：")
    print(selected_companies[['Company_Name', 'PE', 'PB', 'ROE']])
    visualize_results(data)

if __name__ == "__main__":
    main()
```

### 代码解读与分析
1. **read_data 函数**：使用 `pandas` 库的 `read_csv` 函数从 CSV 文件中读取公司财务数据。
2. **calculate_metrics 函数**：计算每个公司的市盈率、市净率和净资产收益率，并将结果添加到数据框中。
3. **compare_evaluation 函数**：筛选出市盈率和市净率低于平均值，净资产收益率高于平均值的公司，认为这些公司可能具有投资价值。
4. **visualize_results 函数**：使用 `matplotlib` 库绘制散点图，将市盈率、市净率和净资产收益率进行可视化展示。
5. **main 函数**：调用上述函数完成数据读取、指标计算、对比评估和可视化操作，并打印出筛选出的具有投资价值的公司信息。
