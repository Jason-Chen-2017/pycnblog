### 1.4 术语表
#### 1.4.1 核心术语定义
- **自由现金流（Free Cash Flow，FCF）**：指企业在满足了营运资本投资和资本性支出需求之后，可以自由分配给企业资本供应者（包括债权人和股东）的现金流量。它反映了企业实际可用于各种用途的现金数量。
- **托马斯罗的自由现金流分析**：是一种基于自由现金流概念，结合特定的分析方法和模型，对企业财务状况和价值进行评估的分析体系，注重从现金流的角度深入理解企业的经营和财务状况。
- **营运资本（Working Capital）**：是指流动资产减去流动负债后的余额，反映了企业短期经营活动的资金需求和流动性状况。
- **资本性支出（Capital Expenditure，CapEx）**：是指企业为了获取长期资产（如固定资产、无形资产等）而发生的支出，通常用于维持或扩大企业的生产经营规模。

#### 1.4.2 相关概念解释
- **现金流折现模型（Discounted Cash Flow Model，DCF）**：是一种常用的企业估值方法，其基本原理是将企业未来各期的自由现金流按照一定的折现率折现到当前时刻，从而得到企业的内在价值。托马斯罗的自由现金流分析常常与现金流折现模型相结合，用于评估企业的投资价值。
- **企业价值（Enterprise Value，EV）**：是指企业的整体价值，包括股权价值和债权价值。在自由现金流分析中，通过对企业未来自由现金流的预测和折现，可以计算出企业的企业价值。
- **可持续增长率（Sustainable Growth Rate，SGR）**：是指企业在不依靠外部股权融资，仅依靠内部留存收益和合理的债务融资的情况下，能够实现的最大增长率。在自由现金流分析中，可持续增长率是预测企业未来自由现金流的重要参数之一。

## 2. 核心概念与联系 

### 核心概念原理
托马斯罗的自由现金流分析基于自由现金流这一核心概念。自由现金流反映了企业在经营活动中实际产生的、可供自由支配的现金流量。其原理在于，企业的价值最终取决于其未来能够产生的现金流量，而不是会计利润。会计利润可能受到会计政策、折旧方法等因素的影响，而自由现金流则更能真实地反映企业的经营能力和财务状况。

自由现金流可以分为两种常见的类型：企业自由现金流（FCFF）和股权自由现金流（FCFE）。企业自由现金流是指企业在满足了所有经营成本、营运资本投资和资本性支出之后，可供所有资本提供者（包括债权人和股东）分配的现金流量。其计算公式为：

$$FCFF = EBIT(1 - T) + Depreciation - CapEx - \Delta WC$$

其中，$EBIT$ 是息税前利润，$T$ 是企业所得税税率，$Depreciation$ 是折旧和摊销，$CapEx$ 是资本性支出，$\Delta WC$ 是营运资本的变化。

股权自由现金流是指企业在满足了所有经营成本、营运资本投资、资本性支出和债务偿还之后，可供股东分配的现金流量。其计算公式为：

$$FCFE = FCFF - Interest(1 - T) + Net Borrowing$$

其中，$Interest$ 是企业的利息支出，$Net Borrowing$ 是净借款（借款增加额减去借款偿还额）。

## 3. 核心算法原理 & 具体操作步骤 

### 核心算法原理
托马斯罗的自由现金流分析的核心算法主要围绕自由现金流的计算和企业价值的评估。其基本思路是通过对企业的财务报表进行分析，计算出企业的自由现金流，然后根据一定的折现率将未来的自由现金流折现到当前时刻，从而得到企业的内在价值。

### 具体操作步骤
1. **数据收集**：收集企业的财务报表，包括利润表、资产负债表和现金流量表。从这些报表中提取所需的数据，如息税前利润、折旧和摊销、资本性支出、营运资本等。
2. **计算自由现金流**：根据前面给出的公式计算企业自由现金流（FCFF）和股权自由现金流（FCFE）。
3. **预测未来自由现金流**：根据企业的历史数据、行业发展趋势和宏观经济环境等因素，对企业未来的自由现金流进行预测。可以采用线性增长模型、固定增长率模型或多阶段增长模型等方法进行预测。
4. **确定折现率**：折现率反映了投资者对投资风险的要求。对于企业自由现金流，通常使用加权平均资本成本（WACC）作为折现率；对于股权自由现金流，使用股权资本成本作为折现率。
5. **计算企业价值**：将预测的未来自由现金流按照折现率折现到当前时刻，然后将各期折现后的自由现金流相加，得到企业的内在价值。

### Python 代码实现
```python
import numpy as np

def calculate_fcff(ebit, tax_rate, depreciation, capex, delta_wc):
    """
    计算企业自由现金流（FCFF）
    :param ebit: 息税前利润
    :param tax_rate: 企业所得税税率
    :param depreciation: 折旧和摊销
    :param capex: 资本性支出
    :param delta_wc: 营运资本的变化
    :return: 企业自由现金流
    """
    return ebit * (1 - tax_rate) + depreciation - capex - delta_wc

def calculate_fcfe(fcff, interest, tax_rate, net_borrowing):
    """
    计算股权自由现金流（FCFE）
    :param fcff: 企业自由现金流
    :param interest: 利息支出
    :param tax_rate: 企业所得税税率
    :param net_borrowing: 净借款
    :return: 股权自由现金流
    """
    return fcff - interest * (1 - tax_rate) + net_borrowing

def discount_fcf(fcf, discount_rate, years):
    """
    对折现自由现金流进行折现计算
    :param fcf: 自由现金流列表
    :param discount_rate: 折现率
    :param years: 预测年份列表
    :return: 折现后的自由现金流列表
    """
    discounted_fcf = []
    for i in range(len(fcf)):
        discounted_fcf.append(fcf[i] / ((1 + discount_rate) ** years[i]))
    return discounted_fcf

# 示例数据
ebit = 1000
tax_rate = 0.25
depreciation = 200
capex = 300
delta_wc = 100
interest = 100
net_borrowing = 50
discount_rate = 0.1
years = [1, 2, 3, 4, 5]
fcf_forecast = [1200, 1300, 1400, 1500, 1600]

# 计算 FCFF 和 FCFE
fcff = calculate_fcff(ebit, tax_rate, depreciation, capex, delta_wc)
fcfe = calculate_fcfe(fcff, interest, tax_rate, net_borrowing)

# 对折现自由现金流进行折现计算
discounted_fcf = discount_fcf(fcf_forecast, discount_rate, years)

print("企业自由现金流（FCFF）:", fcff)
print("股权自由现金流（FCFE）:", fcfe)
print("折现后的自由现金流:", discounted_fcf)
```

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 数学模型和公式
#### 企业自由现金流（FCFF）公式
$$FCFF = EBIT(1 - T) + Depreciation - CapEx - \Delta WC$$

详细讲解：
- $EBIT(1 - T)$：表示企业在扣除所得税后的经营利润。$EBIT$ 是息税前利润，反映了企业的经营盈利能力；$T$ 是企业所得税税率，扣除所得税后得到企业实际可用于分配的经营利润。
- $Depreciation$：折旧和摊销是一种非现金支出，虽然在会计上会减少利润，但实际上并没有现金流出企业。因此，在计算自由现金流时需要将其加回。
- $CapEx$：资本性支出是企业为了维持或扩大生产经营规模而进行的长期投资，这部分支出会导致现金流出企业，所以需要从经营利润中扣除。
- $\Delta WC$：营运资本的变化反映了企业短期经营活动的资金需求变化。如果营运资本增加，意味着企业需要投入更多的资金用于运营，会导致现金流出；反之，如果营运资本减少，则会有现金流入。

#### 股权自由现金流（FCFE）公式
$$FCFE = FCFF - Interest(1 - T) + Net Borrowing$$

详细讲解：
- $FCFF$：是企业自由现金流，是可供所有资本提供者分配的现金流量。
- $Interest(1 - T)$：利息支出是企业向债权人支付的费用，扣除所得税后得到实际的利息支出。从企业自由现金流中减去这部分支出，得到可供股东分配的现金流量。
- $Net Borrowing$：净借款是企业借款增加额减去借款偿还额。如果净借款为正，意味着企业获得了额外的资金，会增加可供股东分配的现金流量；反之，如果净借款为负，则会减少可供股东分配的现金流量。

#### 现金流折现模型（DCF）公式
$$EV = \sum_{t = 1}^{n} \frac{FCFF_t}{(1 + WACC)^t} + \frac{TV}{(1 + WACC)^n}$$

其中，$EV$ 是企业价值，$FCFF_t$ 是第 $t$ 期的企业自由现金流，$WACC$ 是加权平均资本成本，$TV$ 是终值，$n$ 是预测期数。

详细讲解：
- $\sum_{t = 1}^{n} \frac{FCFF_t}{(1 + WACC)^t}$：表示预测期内各期企业自由现金流的折现值之和。将未来各期的自由现金流按照加权平均资本成本折现到当前时刻，考虑了资金的时间价值。
- $\frac{TV}{(1 + WACC)^n}$：终值是指预测期结束后企业的持续价值。通常采用永续增长模型计算终值，公式为 $TV=\frac{FCFF_{n + 1}}{WACC - g}$，其中 $FCFF_{n + 1}$ 是预测期结束后下一期的企业自由现金流，$g$ 是永续增长率。

### 举例说明
假设一家企业的息税前利润（$EBIT$）为 1000 万元，企业所得税税率（$T$）为 25%，折旧和摊销（$Depreciation$）为 200 万元，资本性支出（$CapEx$）为 300 万元，营运资本的变化（$\Delta WC$）为 100 万元。

1. **计算企业自由现金流（FCFF）**
根据公式 $FCFF = EBIT(1 - T) + Depreciation - CapEx - \Delta WC$，可得：
$$FCFF = 1000\times(1 - 0.25)+ 200 - 300 - 100$$
$$FCFF = 750 + 200 - 300 - 100 = 550$$（万元）

2. **假设该企业的利息支出（$Interest$）为 100 万元，净借款（$Net Borrowing$）为 50 万元，计算股权自由现金流（FCFE）**
根据公式 $FCFE = FCFF - Interest(1 - T) + Net Borrowing$，可得：
$$FCFE = 550 - 100\times(1 - 0.25)+ 50$$
$$FCFE = 550 - 75 + 50 = 525$$（万元）

3. **假设预测该企业未来 5 年的企业自由现金流分别为 600 万元、650 万元、700 万元、750 万元、800 万元，加权平均资本成本（$WACC$）为 10%，永续增长率（$g$）为 3%，计算企业价值（$EV$）**
首先计算终值 $TV$：
假设第 6 年的企业自由现金流 $FCFF_6 = 800\times(1 + 0.03)=824$（万元）
$$TV=\frac{FCFF_6}{WACC - g}=\frac{824}{0.1 - 0.03}=\frac{824}{0.07}\approx11771.43$$（万元）

然后计算预测期内各期自由现金流的折现值之和：
$$PV_{FCFF}=\frac{600}{(1 + 0.1)^1}+\frac{650}{(1 + 0.1)^2}+\frac{700}{(1 + 0.1)^3}+\frac{750}{(1 + 0.1)^4}+\frac{800}{(1 + 0.1)^5}$$
$$PV_{FCFF}\approx545.45 + 537.19 + 525.92 + 512.27 + 496.74 = 2617.57$$（万元）

最后计算企业价值 $EV$：
$$EV = PV_{FCFF}+\frac{TV}{(1 + 0.1)^5}$$
$$EV = 2617.57+\frac{11771.43}{(1 + 0.1)^5}$$
$$EV = 2617.57 + 7303.77 = 9921.34$$（万元）

## 9. 附录：常见问题与解答
### 问题 1：自由现金流和净利润有什么区别？
解答：自由现金流和净利润是两个不同的概念。净利润是按照会计准则计算的企业在一定时期内的盈利情况，它受到会计政策、折旧方法、非现金项目等因素的影响。而自由现金流是企业在满足了营运资本投资和资本性支出需求之后，可以自由分配给企业资本供应者的现金流量，更能反映企业实际可用于各种用途的现金数量。例如，一家企业可能净利润很高，但由于大量的资本性支出和营运资本增加，导致自由现金流为负。

### 问题 2：如何确定折现率？
解答：折现率反映了投资者对投资风险的要求。对于企业自由现金流，通常使用加权平均资本成本（WACC）作为折现率。WACC 的计算公式为：

$$WACC = w_d\times r_d\times(1 - T)+ w_e\times r_e$$

其中，$w_d$ 是债务资本的权重，$r_d$ 是债务资本成本，$T$ 是企业所得税税率，$w_e$ 是股权资本的权重，$r_e$ 是股权资本成本。

债务资本成本可以通过企业的债务利率来确定，股权资本成本可以使用资本资产定价模型（CAPM）来计算，公式为：

$$r_e = R_f+\beta\times(R_m - R_f)$$

其中，$R_f$ 是无风险利率，$\beta$ 是企业股票的贝塔系数，$R_m$ 是市场收益率。

### 问题 3：自由现金流分析适用于所有企业吗？
解答：自由现金流分析适用于大多数企业，但在某些情况下可能存在一定的局限性。对于处于快速成长阶段的企业，由于其需要大量的资本性支出用于扩张，可能会导致自由现金流为负，但这并不一定意味着企业的价值低。此外，对于一些新兴行业或特殊企业，如科技初创企业，其未来的现金流具有很大的不确定性，自由现金流分析的准确性可能会受到影响。在使用自由现金流分析时，需要结合企业的具体情况进行综合考虑。

### 问题 4：如何处理预测期后的终值？
解答：预测期后的终值通常采用永续增长模型来计算，公式为 $TV=\frac{FCFF_{n + 1}}{WACC - g}$，其中 $FCFF_{n + 1}$ 是预测期结束后下一期的企业自由现金流，$WACC$ 是加权平均资本成本，$g$ 是永续增长率。永续增长率的确定需要综合考虑企业的行业特点、市场竞争状况和宏观经济环境等因素。一般来说，永续增长率不宜过高，通常在 2% - 3% 左右。
