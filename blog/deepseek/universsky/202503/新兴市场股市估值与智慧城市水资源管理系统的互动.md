```python
def pe_valuation(earnings_per_share, industry_pe):
    """
    基于市盈率的股票估值方法
    :param earnings_per_share: 每股收益
    :param industry_pe: 行业平均市盈率
    :return: 股票的合理价格
    """
    return earnings_per_share * industry_pe

# 示例数据

# 计算股票合理价格

```

在上述代码中，`pe_valuation` 函数接受每股收益和行业平均市盈率作为输入，通过将两者相乘得到股票的合理价格。

### 智慧城市水资源管理系统数据分析算法
在智慧城市水资源管理系统中，数据分析是关键环节之一。以下是一个简单的 Python 代码示例，用于对水位数据进行异常检测：

```python
import numpy as np

def detect_water_level_anomaly(water_levels, threshold):
    """
    水位数据异常检测
    :param water_levels: 水位数据列表
    :param threshold: 异常阈值
    :return: 异常数据的索引列表
    """
    mean_level = np.mean(water_levels)
    std_level = np.std(water_levels)
    anomalies = []
    for i, level in enumerate(water_levels):
        if abs(level - mean_level) > threshold * std_level:
            anomalies.append(i)
    return anomalies

# 示例数据
water_levels = [1.2, 1.3, 1.5, 2.0, 1.1, 1.4, 3.0]
threshold = 2

# 检测异常数据
anomaly_indices = detect_water_level_anomaly(water_levels, threshold)
print(f"异常数据的索引为: {anomaly_indices}")
```

在上述代码中，`detect_water_level_anomaly` 函数接受水位数据列表和异常阈值作为输入，通过计算水位数据的均值和标准差，判断每个数据点是否超过阈值范围，将超过阈值的数据点的索引添加到异常列表中。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 新兴市场股市估值数学模型
#### 市盈率模型
市盈率（PE）是最常用的股市估值指标之一，其计算公式为：
$$PE = \frac{P}{EPS}$$
其中，$P$ 为股票价格，$EPS$ 为每股收益。通过变形可得股票价格的计算公式：
$$P = PE \times EPS$$

例如，某新兴市场上市公司的每股收益为 $3$ 元，行业平均市盈率为 $12$，则该股票的合理价格为：
$$P = 12 \times 3 = 36\text{（元）}$$

#### 股息贴现模型
股息贴现模型（DDM）是另一种常用的股市估值模型，其基本思想是将股票的价值视为未来股息的现值之和。对于固定增长的股息贴现模型，其计算公式为：
$$V = \frac{D_1}{r - g}$$
其中，$V$ 为股票价值，$D_1$ 为下一期预计股息，$r$ 为必要收益率，$g$ 为股息增长率。

例如，某新兴市场上市公司预计下一期股息为 $2$ 元，必要收益率为 $10\%$，股息增长率为 $5\%$，则该股票的价值为：
$$V = \frac{2}{0.1 - 0.05} = 40\text{（元）}$$

### 智慧城市水资源管理系统数学模型
#### 水资源供需平衡模型
水资源供需平衡模型用于描述城市水资源的供应和需求关系，其基本公式为：
$$S = I - O + R$$
其中，$S$ 为水资源的储存量变化，$I$ 为水资源的输入量（如降雨量、外来调水量等），$O$ 为水资源的输出量（如用水量、排水量等），$R$ 为水资源的再生量（如污水处理后的回用量等）。

例如，某城市在某一时间段内的降雨量为 $100$ 万立方米，外来调水量为 $50$ 万立方米，用水量为 $80$ 万立方米，排水量为 $30$ 万立方米，污水处理后的回用量为 $20$ 万立方米，则该城市水资源的储存量变化为：
$$S = (100 + 50) - (80 + 30) + 20 = 60\text{（万立方米）}$$

#### 水质预测模型
水质预测模型用于预测水体的水质变化情况，常用的模型之一是一阶线性回归模型：
$$y_t = \beta_0 + \beta_1 x_{t - 1} + \epsilon_t$$
其中，$y_t$ 为 $t$ 时刻的水质指标值，$x_{t - 1}$ 为 $t - 1$ 时刻的相关影响因素值（如污染物排放量、水温等），$\beta_0$ 和 $\beta_1$ 为回归系数，$\epsilon_t$ 为随机误差项。

例如，通过对某河流的水质数据进行分析，得到回归系数 $\beta_0 = 0.5$，$\beta_1 = 0.8$，上一时刻的污染物排放量为 $10$ 吨，则预测当前时刻的水质指标值为：
$$y_t = 0.5 + 0.8 \times 10 = 8.5$$
