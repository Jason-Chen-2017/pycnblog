## 3. 核心算法原理 & 具体操作步骤 

### 量子密钥分发（QKD）算法原理
量子密钥分发是量子加密技术中的核心算法之一，其最著名的协议是 BB84 协议。BB84 协议的基本原理是利用光子的偏振态来编码信息，并通过量子信道进行传输。

#### 基本步骤
1. **发送方准备量子态**：发送方（通常称为 Alice）随机选择一组偏振基（如水平/垂直偏振基或 +45°/-45°偏振基），并根据要发送的比特信息（0 或 1）制备相应的光子偏振态。例如，在水平/垂直偏振基中，水平偏振表示 0，垂直偏振表示 1；在 +45°/-45°偏振基中，+45°偏振表示 0，-45°偏振表示 1。
2. **发送量子态**：Alice 通过量子信道将制备好的光子发送给接收方（通常称为 Bob）。
3. **接收方测量量子态**：Bob 随机选择一组偏振基对接收到的光子进行测量。由于量子态的测量结果是随机的，只有当 Bob 选择的偏振基与 Alice 制备光子时使用的偏振基相同时，测量结果才与 Alice 发送的比特信息一致。
4. **基比对**：Bob 通过经典信道告诉 Alice 他所使用的偏振基，Alice 则告诉 Bob 哪些基是正确的。双方只保留使用相同基进行测量的结果，这些结果构成了初始密钥。
5. **纠错和隐私放大**：为了确保密钥的准确性和安全性，双方还需要进行纠错和隐私放大操作。纠错是通过经典信道交换部分密钥信息来检测和纠正可能存在的错误；隐私放大则是通过哈希函数等方法进一步压缩密钥，去除可能被窃听者获取的信息。

### Python 代码实现

```python
import random

# 定义偏振基
BASES = ['X', 'Z']
# 定义偏振态
STATES = {
    ('Z', 0): '|0>',
    ('Z', 1): '|1>',
    ('X', 0): '|+>',
    ('X', 1): '|->'
}

# 生成随机比特序列
def generate_random_bits(length):
    return [random.randint(0, 1) for _ in range(length)]

# 生成随机基序列
def generate_random_bases(length):
    return [random.choice(BASES) for _ in range(length)]

# 制备量子态
def prepare_states(bits, bases):
    return [STATES[(bases[i], bits[i])] for i in range(len(bits))]

# 测量量子态
def measure_states(states, bases):
    measured_bits = []
    for i in range(len(states)):
        if bases[i] == 'Z':
            if states[i] == '|0>':
                measured_bits.append(0)
            elif states[i] == '|1>':
                measured_bits.append(1)
            else:
                # 如果基不匹配，随机测量结果
                measured_bits.append(random.randint(0, 1))
        elif bases[i] == 'X':
            if states[i] == '|+>':
                measured_bits.append(0)
            elif states[i] == '|->':
                measured_bits.append(1)
            else:
                # 如果基不匹配，随机测量结果
                measured_bits.append(random.randint(0, 1))
    return measured_bits

# 基比对
def sift_bits(alice_bases, bob_bases, alice_bits, bob_bits):
    sifted_alice_bits = []
    sifted_bob_bits = []
    for i in range(len(alice_bases)):
        if alice_bases[i] == bob_bases[i]:
            sifted_alice_bits.append(alice_bits[i])
            sifted_bob_bits.append(bob_bits[i])
    return sifted_alice_bits, sifted_bob_bits

# 主函数
def bb84_protocol(length):
    # 生成随机比特和基
    alice_bits = generate_random_bits(length)
    alice_bases = generate_random_bases(length)
    bob_bases = generate_random_bases(length)
    
    # 制备和测量量子态
    states = prepare_states(alice_bits, alice_bases)
    bob_measured_bits = measure_states(states, bob_bases)
    
    # 基比对
    sifted_alice_bits, sifted_bob_bits = sift_bits(alice_bases, bob_bases, alice_bits, bob_measured_bits)
    
    return sifted_alice_bits, sifted_bob_bits

# 示例运行
key_length = 100
alice_key, bob_key = bb84_protocol(key_length)
print("Alice's sifted key:", alice_key)
print("Bob's sifted key:", bob_key)
```

### 代码解释
1. **生成随机比特和基**：`generate_random_bits` 函数用于生成指定长度的随机比特序列，`generate_random_bases` 函数用于生成随机的偏振基序列。
2. **制备量子态**：`prepare_states` 函数根据发送方的比特信息和基信息制备相应的量子态。
3. **测量量子态**：`measure_states` 函数根据接收方选择的基对量子态进行测量，并返回测量结果。如果接收方选择的基与发送方制备量子态时使用的基不匹配，则测量结果是随机的。
4. **基比对**：`sift_bits` 函数通过比较发送方和接收方使用的基，只保留使用相同基进行测量的结果，从而得到筛选后的密钥。
5. **主函数**：`bb84_protocol` 函数将上述步骤整合在一起，完成整个 BB84 协议的执行，并返回筛选后的密钥。

## 4. 数学模型和公式 & 详细讲解 & 举例说明 

### 量子态的表示
在量子力学中，量子态可以用向量来表示。例如，在二维希尔伯特空间中，一个量子比特的状态可以用基态 $|0\rangle$ 和 $|1\rangle$ 的线性组合来表示：

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$

其中，$\alpha$ 和 $\beta$ 是复数，且满足 $|\alpha|^2 + |\beta|^2 = 1$。$|\alpha|^2$ 表示测量量子比特得到 $|0\rangle$ 态的概率，$|\beta|^2$ 表示测量量子比特得到 $|1\rangle$ 态的概率。

### BB84 协议的数学原理
在 BB84 协议中，发送方（Alice）随机选择两个正交基：标准基 $\{|0\rangle, |1\rangle\}$ 和对角基 $\{|+\rangle, |-\rangle\}$，其中：

$$|+\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$$
$$|-\rangle = \frac{1}{\sqrt{2}}(|0\rangle - |1\rangle)$$

Alice 根据要发送的比特信息选择相应的基和态进行制备。例如，如果要发送比特 0，她可以选择标准基并制备 $|0\rangle$ 态，或者选择对角基并制备 $|+\rangle$ 态；如果要发送比特 1，她可以选择标准基并制备 $|1\rangle$ 态，或者选择对角基并制备 $|-\rangle$ 态。

接收方（Bob）也随机选择一个基进行测量。如果 Bob 选择的基与 Alice 制备态时使用的基相同，那么测量结果将准确地反映 Alice 发送的比特信息；如果基不同，那么测量结果将是随机的。

### 举例说明
假设 Alice 要发送比特序列 `[0, 1, 0]`，她随机选择的基序列为 `['Z', 'X', 'Z']`。根据上述规则，她制备的量子态序列为 `[|0>, |->, |0>]`。

Bob 随机选择的基序列为 `['Z', 'Z', 'X']`。他对接收到的量子态进行测量：
- 对于第一个量子态 $|0\rangle$，Bob 使用标准基 `Z` 进行测量，测量结果为 0。
- 对于第二个量子态 $|-\rangle$，Bob 使用标准基 `Z` 进行测量，测量结果是随机的，假设为 1。
- 对于第三个量子态 $|0\rangle$，Bob 使用对角基 `X` 进行测量，测量结果是随机的，假设为 0。

然后，Bob 通过经典信道告诉 Alice 他所使用的基，Alice 告诉 Bob 哪些基是正确的。在这个例子中，第一个基是相同的，所以双方保留第一个测量结果，得到筛选后的密钥比特为 `[0]`。

```python
    # 将比特序列转换为字节序列
    alice_key_bytes = bits_to_bytes(alice_key_bits)
    bob_key_bytes = bits_to_bytes(bob_key_bits)
    
    # 确保密钥长度为 16、24 或 32 字节
    alice_key_bytes = alice_key_bytes[:32]
    bob_key_bytes = bob_key_bytes[:32]
    
    # 明文信息
    message = "Hello, Quantum Encryption in Supply Chain!"
    
    # 加密信息
    encrypted_message = encrypt_message(message, alice_key_bytes)
    
    # 解密信息
    decrypted_message = decrypt_message(encrypted_message, bob_key_bytes)
    
    print("Original message:", message)
    print("Encrypted message:", encrypted_message)
    print("Decrypted message:", decrypted_message)

if __name__ == "__main__":
    main()
```

### 5.3  代码解读与分析
1. **量子密钥分发部分**：代码中的 `bb84_protocol` 函数实现了 BB84 协议的主要步骤，包括生成随机比特和基、制备和测量量子态、基比对等，最终得到筛选后的密钥比特序列。
2. **比特序列转换为字节序列**：`bits_to_bytes` 函数将筛选后的密钥比特序列转换为字节序列，以便后续使用 AES 加密算法进行加密和解密。
3. **AES 加密和解密**：`encrypt_message` 函数使用 AES 加密算法对明文信息进行加密，`decrypt_message` 函数使用相同的密钥对加密信息进行解密。
4. **主函数**：`main` 函数将上述步骤整合在一起，完成量子密钥分发、信息加密和解密的整个过程，并输出原始信息、加密信息和解密信息。

### 安全性分析
在这个项目中，量子密钥分发的安全性基于量子力学的基本原理，如量子不可克隆定理。只要量子信道没有被干扰，窃听者无法获取密钥信息。而 AES 加密算法是一种广泛使用的对称加密算法，具有较高的安全性。因此，整个系统在理论上可以提供较高的信息安全保障。
