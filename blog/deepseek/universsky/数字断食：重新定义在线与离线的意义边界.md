### 1.1 数字时代的来临与挑战

#### 1.1.1 数字化的快速发展

随着互联网、移动通信和智能设备的普及，数字化已经成为现代社会的主要特征。人们的生活、工作和娱乐都越来越依赖于数字技术。然而，这种高度依赖也带来了一系列挑战。

#### 1.1.2 在线与离线生活的界限模糊

在数字化时代，在线与离线生活的界限变得越来越模糊。许多人即使在日常生活中也难以摆脱数字设备的束缚，这导致了在线生活的过度扩展和离线生活的缺失。

#### 1.1.3 数字过载现象及其影响

数字过载是指人们在数字设备上消耗的时间过多，导致心理和生理压力增加。长期处于数字过载状态会导致注意力分散、睡眠质量下降、心理健康问题等。

### 1.2 数字断食的概念

#### 1.2.1 数字断食的定义

数字断食是指通过减少或暂停使用数字设备和技术，以达到改善身体和心理健康的目的。它是对传统断食概念的延伸，旨在解决数字依赖和数字过载问题。

#### 1.2.2 数字断食的起源与发展

数字断食最早起源于2012年的美国，随着人们对数字依赖问题的关注不断增加，数字断食逐渐成为了一种流行的生活方式。

#### 1.2.3 数字断食的核心价值

数字断食的核心价值在于帮助人们重新审视数字设备和技术在生活中的角色，培养数字自律和数字素养，从而实现身心健康和生活质量的提升。

### 1.3 数字断食与在线、离线的关系

#### 1.3.1 重新定义在线与离线的边界

数字断食通过减少对数字设备的依赖，帮助人们重新定义在线与离线的边界，使在线生活与离线生活达到平衡。

数字断食可以改变人们的生活习惯，提高生活质量，使人们更加关注身心健康和人际交往。

### 1.4 数字断食的实践方法

       user = models.ForeignKey(CustomUser, on_delete=models.CASCADE)
       daily_screen_time = models.IntegerField()
       social_media_usage = models.IntegerField()
       notification_checking = models.IntegerField()

           return total_usage / 24
