## 2.1 感官意象

### 2.1.1 定义

感官意象是指在描述某物时，通过调动读者的感官（如视觉、听觉、嗅觉、触觉、味觉）来形成的一种心理图像。在香水评论中，感官意象描绘了香水带给人的感官体验，如香气、气味、质感等。

### 2.1.2 感官意象的类型

感官意象可以按照感官类型进行分类，主要包括以下几种：

1. **嗅觉意象**：描述香水气味的特征，如花香、果香、木质香等。
2. **视觉意象**：描述香水包装、瓶身设计等视觉元素。
3. **听觉意象**：描述香水名称的发音、香水开启时的声音等。
4. **触觉意象**：描述香水在皮肤上的感觉，如清爽、温暖、滑润等。
5. **味觉意象**：虽然香水主要作用于嗅觉，但某些香水可能会在口中留下微妙的味觉感受。

### 2.1.3 感官意象的属性特征对比表

以下是一个感官意象属性特征对比表，展示了不同感官意象的特征：

| 视觉意象     | 描述视觉的吸引力、设计风格   | 明亮、简约、豪华、优雅    |
| 听觉意象     | 描述声音的质感、音调         | 柔和、清脆、低沉、悦耳    |

## 2.2 提示词设计

提示词（Trigger Words）是在写作中用于激发特定情感、意象或记忆的词汇。在AI生成香水评论中，提示词是为了引导AI生成具有文学性和感官描绘的文本而设计的。

### 2.2.2 提示词的分类

根据感官意象的不同类型，提示词可以分类如下：

1. **嗅觉提示词**：如“芬芳”、“馥郁”、“清新”、“优雅”等。
2. **视觉提示词**：如“精致”、“独特”、“奢华”、“淡雅”等。
3. **听觉提示词**：如“柔和”、“悠扬”、“响亮”、“宁静”等。
4. **触觉提示词**：如“清爽”、“柔软”、“温暖”、“细腻”等。
5. **味觉提示词**：如“柔和”、“甜美”、“辛辣”、“清新”等。

### 2.2.3 提示词的设计原则

设计提示词时，应遵循以下原则：

1. **精准性**：提示词应精准地描述香水的感官特征，避免模糊不清。
2. **多样性**：提供丰富的提示词，以便AI生成多样化的评论。
3. **文学性**：提示词应具有文学性，能够激发读者的感官体验和情感。
4. **相关性**：提示词应与香水的感官特征高度相关，确保评论的准确性。

### 3.1.2 数学模型

感官意象识别算法的数学模型主要基于条件概率计算。给定一个文本，算法计算每个词语属于感官意象的概率。具体模型如下：

$$
P(\text{感官意象}|\text{文本}) = \frac{\text{感官意象词频} \times \text{文本词频}}{\text{总词频}}
$$

其中，$\text{感官意象词频}$ 表示文本中感官意象词的出现次数，$\text{文本词频}$ 表示感官意象词在文本中的出现次数，$\text{总词频}$ 表示文本中所有词语的出现次数。

   - $P(\text{花香}|\text{文本}) = 0.3$
   - $P(\text{果香}|\text{文本}) = 0.5$

from sklearn.model_selection import train_test_split

    # 去除标点符号和停用词
    words = jieba.cut(text)
    filtered_words = [word for word in words if word not in jieba.get_stop_words()]
    return ' '.join(filtered_words)

# 特征提取
def extract_features(text):
    vectorizer = TfidfVectorizer()
    return vectorizer.fit_transform([text])

# 文学性评估模型训练

    print(f"文学性评分：{score}")

from lit_model import LitModel
