#### 1.2 Core Principles of Value Investing

| Principle         | Definition                                                                 | Importance                                      |

| Intrinsic Value   | The true worth of an asset based on its future cash flows.                   | Helps identify undervalued assets.                |
| Margin of Safety   | The difference between the intrinsic value and the purchase price.          | Reduces the risk of permanent capital loss.       |

- **Python Code:**
```python
def intrinsic_value(cash_flows, discount_rate):
    return sum([cf / (1 + discount_rate)**t for t, cf in enumerate(cash_flows)])

def margin_of_safety(intrinsic_value, purchase_price):
    return intrinsic_value - purchase_price

def make_investment_decision(margin_of_safety):
    if margin_of_safety >= 0.5:
        return "Invest"
    else:
        return "Hold or Sell"
```

#### 2.1 Stock Investing

##### 2.1.1 Stock Market Valuation

In this section, we will discuss methods to evaluate stock prices, such as discounted cash flow (DCF) analysis, price-to-earnings (P/E) ratio, and book value.

**Mathematical Model & Formula:**
$$
\text{Intrinsic Value} = \frac{\text{Sum of Expected Future Cash Flows}}{(1 + \text{Discount Rate})^n}
$$

**Example:**
Using DCF analysis to estimate the intrinsic value of a company with expected cash flows of $1 million in year 1, $1.2 million in year 2, and $1.5 million in year 3, assuming a discount rate of 10%.

```python
def discounted_cash_flow(cash_flows, discount_rate):
    return sum([cf / (1 + discount_rate)**t for t, cf in enumerate(cash_flows)])

cash_flows = [1000000, 1200000, 1500000]
discount_rate = 0.1
intrinsic_value = discounted_cash_flow(cash_flows, discount_rate)
print(f"Intrinsic Value: ${intrinsic_value:.2f}")
```
