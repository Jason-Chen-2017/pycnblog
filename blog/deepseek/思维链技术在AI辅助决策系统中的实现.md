##### 3.1.3 Python源代码实现

以下是一个简单的思维链技术实现的Python代码示例：

```python
import numpy as np

# 知识表示
facts = {'weather': 'sunny', 'temperature': 'hot'}
rules = {
    'if weather is sunny then temperature is hot': {'weather': 'sunny', 'temperature': 'hot'}
}

# 推理
def forward_chaining(facts, rules):
    new_facts = {}
    for rule in rules.values():
        for fact_key in rule.keys():
            if fact_key in facts and facts[fact_key] == rule[fact_key]:
                new_facts.update({k: v for k, v in rule.items()})
    return new_facts

# 评估
def evaluate(new_facts):
    if 'temperature' in new_facts and new_facts['temperature'] == 'hot':
        return "It's a hot day!"
    else:
        return "The weather is not hot."

# 主程序
if __name__ == "__main__":
    new_facts = forward_chaining(facts, rules)
    print(evaluate(new_facts))
```

在这个示例中，我们通过正向推理从事实库中推导出新的结论，并根据结论进行评估。
