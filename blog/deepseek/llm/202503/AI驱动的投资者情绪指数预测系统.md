import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

# 数据采集（这里假设数据已经存储在CSV文件中）

## 4. 数学模型和公式 & 详细讲解 & 举例说明 
### 自然语言处理中的数学模型和公式
#### 词袋模型（Bag of Words）
词袋模型是一种简单的文本表示方法，它将文本看作是一个无序的词语集合，忽略了词语的顺序和语法结构。具体步骤如下：
1. **构建词汇表**：将所有文本中的词语提取出来，去重后构建一个词汇表。
2. **文本向量化**：对于每个文本，统计词汇表中每个词语在该文本中出现的次数，将其作为该词语的特征值，从而将文本转换为一个向量。

假设词汇表为 $V = \{w_1, w_2, \cdots, w_n\}$，文本 $d$ 中词语 $w_i$ 出现的次数为 $f_{i,d}$，则文本 $d$ 的词袋模型表示为：
$$
\mathbf{x}_d = [f_{1,d}, f_{2,d}, \cdots, f_{n,d}]
$$

**举例说明**：假设有两个文本：$d_1 =$ "股票市场上涨"，$d_2 =$ "股票市场下跌"，词汇表为 $V = \{$ "股票", "市场", "上涨", "下跌" $\}$，则 $d_1$ 的词袋模型表示为 $\mathbf{x}_{d_1} = [1, 1, 1, 0]$，$d_2$ 的词袋模型表示为 $\mathbf{x}_{d_2} = [1, 1, 0, 1]$。

#### TF-IDF模型（Term Frequency-Inverse Document Frequency）
TF-IDF模型是一种常用的文本特征提取方法，它综合考虑了词语在文本中的出现频率和在整个语料库中的稀有程度。具体公式如下：
- **词频（Term Frequency，TF）**：表示词语在文本中出现的频率，计算公式为：
$$
TF_{i,d} = \frac{f_{i,d}}{\sum_{j=1}^{n} f_{j,d}}
$$
其中，$f_{i,d}$ 表示词语 $w_i$ 在文本 $d$ 中出现的次数，$\sum_{j=1}^{n} f_{j,d}$ 表示文本 $d$ 中所有词语的出现次数之和。

- **逆文档频率（Inverse Document Frequency，IDF）**：表示词语在整个语料库中的稀有程度，计算公式为：
$$
IDF_i = \log\frac{N}{n_i}
$$
其中，$N$ 表示语料库中的文本总数，$n_i$ 表示包含词语 $w_i$ 的文本数。

- **TF-IDF值**：表示词语在文本中的重要程度，计算公式为：
$$
TF - IDF_{i,d} = TF_{i,d} \times IDF_i
$$

**举例说明**：假设有三个文本：$d_1 =$ "股票市场上涨"，$d_2 =$ "股票市场下跌"，$d_3 =$ "经济形势良好"，词汇表为 $V = \{$ "股票", "市场", "上涨", "下跌", "经济", "形势", "良好" $\}$。计算词语 "股票" 在文本 $d_1$ 中的TF-IDF值：
- 词频 $TF_{股票,d_1} = \frac{1}{3}$
- 逆文档频率 $IDF_{股票} = \log\frac{3}{2}$
- TF-IDF值 $TF - IDF_{股票,d_1} = \frac{1}{3} \times \log\frac{3}{2}$

### 机器学习中的数学模型和公式
#### 线性回归模型
线性回归模型用于建立自变量与因变量之间的线性关系，其数学模型可以表示为：
$$
y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \cdots + \beta_nx_n + \epsilon
$$
其中，$y$ 表示因变量，$x_1, x_2, \cdots, x_n$ 表示自变量，$\beta_0, \beta_1, \cdots, \beta_n$ 表示回归系数，$\epsilon$ 表示误差项。

线性回归模型的目标是通过最小化误差平方和来估计回归系数，即：
$$
\min_{\beta_0, \beta_1, \cdots, \beta_n} \sum_{i=1}^{m} (y_i - (\beta_0 + \beta_1x_{i1} + \beta_2x_{i2} + \cdots + \beta_nx_{in}))^2
$$
其中，$m$ 表示样本数量，$y_i$ 表示第 $i$ 个样本的因变量值，$x_{i1}, x_{i2}, \cdots, x_{in}$ 表示第 $i$ 个样本的自变量值。

**举例说明**：假设有一个简单的线性回归问题，自变量为 $x$，因变量为 $y$，样本数据为 $(x_1, y_1) = (1, 2)$，$(x_2, y_2) = (2, 4)$，$(x_3, y_3) = (3, 6)$。则线性回归模型为 $y = \beta_0 + \beta_1x$，通过最小化误差平方和可以得到 $\beta_0 = 0$，$\beta_1 = 2$，即 $y = 2x$。

#### 逻辑回归模型
逻辑回归模型用于对分类问题进行建模，其数学模型可以表示为：
$$
P(y = 1|x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x_1 + \beta_2x_2 + \cdots + \beta_nx_n)}}
$$
其中，$P(y = 1|x)$ 表示在给定自变量 $x$ 的情况下，因变量 $y$ 取值为 1 的概率，$\beta_0, \beta_1, \cdots, \beta_n$ 表示回归系数。

逻辑回归模型的目标是通过最大化似然函数来估计回归系数，即：
$$
\max_{\beta_0, \beta_1, \cdots, \beta_n} \prod_{i=1}^{m} P(y_i|x_i)
$$
其中，$m$ 表示样本数量，$y_i$ 表示第 $i$ 个样本的因变量值，$x_i$ 表示第 $i$ 个样本的自变量值。

**举例说明**：假设有一个二分类问题，自变量为 $x$，因变量为 $y$，样本数据为 $(x_1, y_1) = (1, 1)$，$(x_2, y_2) = (2, 0)$，$(x_3, y_3) = (3, 1)$。通过最大化似然函数可以得到逻辑回归模型的回归系数，从而预测新样本的类别。

### 5.2  源代码详细实现和代码解读
以下是一个完整的AI驱动的投资者情绪指数预测系统的源代码实现：

```python
import pandas as pd
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score
import nltk
from nltk.corpus import stopwords
import re

# 数据采集（这里假设数据已经存储在CSV文件中）
data = pd.read_csv('investor_sentiment_data.csv')

# 数据预处理
def preprocess_text(text):
    # 去除特殊字符
    text = re.sub(r'[^\w\s]', '', text)
    # 转换为小写
    text = text.lower()
    # 分词
    tokens = text.split()
    # 去除停用词
    stop_words = set(stopwords.words('english'))
    filtered_tokens = [token for token in tokens if token not in stop_words]
    # 合并词语
    preprocessed_text = ' '.join(filtered_tokens)
    return preprocessed_text

data['text'] = data['text'].apply(preprocess_text)

# 提取文本数据和标签
texts = data['text'].tolist()
labels = data['label'].tolist()

# 使用TF-IDF进行特征提取
vectorizer = TfidfVectorizer()
features = vectorizer.fit_transform(texts)

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(features, labels, test_size=0.2, random_state=42)

# 模型训练
model = LogisticRegression()
model.fit(X_train, y_train)

# 模型评估
y_pred = model.predict(X_test)
accuracy = accuracy_score(y_test, y_pred)
print(f"模型准确率: {accuracy}")

# 预测与应用
new_texts = ["股票市场前景乐观", "经济形势不容乐观"]
new_texts = [preprocess_text(text) for text in new_texts]
new_features = vectorizer.transform(new_texts)
new_predictions = model.predict(new_features)
print(f"新文本的预测结果: {new_predictions}")
```

### 代码解读与分析

3. **特征提取**：使用 `TfidfVectorizer` 类将文本数据转换为TF-IDF特征向量。
4. **划分训练集和测试集**：使用 `train_test_split` 函数将数据划分为训练集和测试集，测试集占比为20%。
5. **模型训练**：使用逻辑回归模型对训练数据进行训练。
