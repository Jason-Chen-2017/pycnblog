最后，绿色生态系统对水资源管理也有积极作用。绿色植物可以通过根系吸收和储存水分，减少地表径流，同时防止土壤侵蚀。此外，绿色植物还能通过蒸腾作用，促进地下水的补给，维持地下水位。

#### 2.1 城市空中花园的类型

城市空中花园的类型多样，主要分为垂直花园、屋顶花园和墙面花园。

**2.1.1 垂直花园**

垂直花园是指通过垂直绿化手段，将植物种植在建筑物的外墙或室内墙体上。垂直花园的优点在于充分利用空间，可以在有限的城市区域内创造出更多的绿化面积。此外，垂直花园还具有美观、节能和降噪等功能。

垂直花园的设计要点包括植物选择、种植结构和支撑系统。植物选择上，应根据不同垂直高度和光照条件选择适合的植物种类。种植结构上，应采用模块化设计，方便维护和管理。支撑系统则应具备足够的强度和稳定性，确保植物生长所需的空间。

**2.1.2 屋顶花园**

屋顶花园是指将植物种植在建筑物的屋顶上。屋顶花园的优点在于可以有效利用建筑物的闲置空间，增加城市绿化面积，改善城市生态环境。此外，屋顶花园还具有隔热保温、减少雨水径流、降低噪声等功能。

屋顶花园的设计要点包括防水层、种植介质、排水系统、植物选择等。防水层是屋顶花园的基础，应选择耐久、防水的材料。种植介质应具备良好的透气性和保水性，以支持植物生长。排水系统则应确保雨水能够顺利排出，防止积水。植物选择上，应根据屋顶的光照和风力条件选择适合的植物种类。

**2.1.3 墙面花园**

墙面花园是指将植物种植在建筑物的外墙或围墙表面。墙面花园的优点在于可以美化城市景观，改善城市环境。此外，墙面花园还具有防尘降噪、减少热岛效应等功能。

墙面花园的设计要点包括植物选择、种植方式和墙面结构。植物选择上，应根据墙面高度和光照条件选择适合的植物种类。种植方式上，可以采用悬挂、攀爬或直立种植等形式。墙面结构应具备足够的承载能力和稳定性，以支持植物生长。

```python
# app.py

from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///garden.db'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password = db.Column(db.String(120), nullable=False)

class Plant(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(120), nullable=False)
    type = db.Column(db.String(120), nullable=False)
    watering_interval = db.Column(db.Float, nullable=False)

class IrrigationSystem(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    plant_id = db.Column(db.Integer, db.ForeignKey('plant.id'), nullable=False)
    last_watering = db.Column(db.DateTime, nullable=False)

class AirQuality(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    reading_time = db.Column(db.DateTime, nullable=False)
    pm2_5 = db.Column(db.Float, nullable=False)
    pm10 = db.Column(db.Float, nullable=False)

@app.route('/users', methods=['POST'])
def add_user():
    username = request.form['username']
    password = request.form['password']
    new_user = User(username=username, password=password)
    db.session.add(new_user)
    db.session.commit()
    return jsonify(message='User added successfully')

@app.route('/plants', methods=['POST'])
def add_plant():
    name = request.form['name']
    type = request.form['type']
    watering_interval = float(request.form['watering_interval'])
    new_plant = Plant(name=name, type=type, watering_interval=watering_interval)
    db.session.add(new_plant)
    db.session.commit()
    return jsonify(message='Plant added successfully')

@app.route('/irrigation', methods=['POST'])
def add_irrigation():
    plant_id = int(request.form['plant_id'])
    new_irrigation = IrrigationSystem(plant_id=plant_id, last_watering=datetime.now())
    db.session.add(new_irrigation)
    db.session.commit()
    return jsonify(message='Irrigation added successfully')

@app.route('/air_quality', methods=['POST'])
def add_air_quality():
    pm2_5 = float(request.form['pm2_5'])
    pm10 = float(request.form['pm10'])
    new_air_quality = AirQuality(pm2_5=pm2_5, pm10=pm10, reading_time=datetime.now())
    db.session.add(new_air_quality)
    db.session.commit()
    return jsonify(message='Air quality reading added successfully')

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```
