提示词工程的目标是通过优化提示词的设计，提高模型生成文本的质量、准确性和一致性。在多语言支持场景下，提示词工程需要确保不同语言的提示词能够准确传达意图，并与模型的输出保持一致。

#### 3.5.1 Transformer模型的数学基础

##### 3.5.1.1 自注意力机制
$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V

class PromptGenerator:
    def __init__(self, language):
        self.language = language
        self.templates = {
            'en': "Generate a paragraph about {} in English.",
            'zh': "生成一段关于 {} 的中文段落。"
        }
    
    def generate_prompt(self, topic):
        return self.templates[self.language].format(topic)
