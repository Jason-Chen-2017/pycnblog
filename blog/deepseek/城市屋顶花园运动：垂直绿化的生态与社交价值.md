以下是一个简单的Python脚本，用于模拟城市屋顶花园的建设过程。

```python
import numpy as np
import matplotlib.pyplot as plt
import pandas as pd

# 建立类和对象
class Plant:
    def __init__(self, name, type, sunlight, soil_quality):
        self.name = name
        self.type = type
        self.sunlight = sunlight
        self.soil_quality = soil_quality

    def plant(self, roof_garden):
        roof_garden.plant_list.append(self)

    def show(self):
        print(f"植物名称：{self.name}")
        print(f"植物类型：{self.type}")
        print(f"阳光需求：{self.sunlight}")
        print(f"土壤质量：{self.soil_quality}")

class RoofGarden:
    def __init__(self, name, area):
        self.name = name
        self.area = area
        self.plant_list = []

    def plant_plants(self, plants):
        for plant in plants:
            plant.plant(self)

    def show(self):
        print(f"花园名称：{self.name}")
        print(f"花园面积：{self.area}")
        print("种植的植物：")
        for plant in self.plant_list:
            plant.show()

# 创建植物对象
plant1 = Plant("向日葵", "花卉", 5, 7)
plant2 = Plant("草地", "草本植物", 3, 5)
plant3 = Plant("吊兰", "耐阴植物", 1, 6)

# 创建屋顶花园对象
roof_garden = RoofGarden("城市屋顶花园", 10000)

# 种植植物
plant1.plant(roof_garden)
plant2.plant(roof_garden)
plant3.plant(roof_garden)

# 显示花园信息
roof_garden.show()
```

**代码应用解读与分析：**

上述脚本中，我们定义了两个类：`Plant` 和 `RoofGarden`。`Plant` 类表示植物，包括植物名称、类型、阳光需求和土壤质量等属性。`RoofGarden` 类表示屋顶花园，包括花园名称、面积和种植的植物列表等属性。

在脚本中，我们创建了三个植物对象，并向城市屋顶花园中种植。最后，通过调用 `show` 方法，我们可以显示花园中的植物信息。
