#### 1.5 算法原理讲解

在手工香薰蜡烛制作过程中，调香是一个关键环节。调香不仅决定了香薰蜡烛的香气特点，还对消费者的使用体验产生重要影响。下面，我们将使用mermaid流程图和Python代码来详细讲解调香的基本算法原理。

**Mermaid流程图：**

```mermaid
flowchart LR
    A[开始] --> B[选择基础油]
    B --> C{选择香精}
    C -->|确定比例| D[混合精油]
    D --> E[调整香气]
    E --> F[测试香气]
    F -->|满意| G[完成]
    F -->|不满意| C
```

**Python代码：**

```python
import random

def choose_base_oil():
    """选择基础油"""
    base_oils = ['甜杏仁油', '橄榄油', '薰衣草油']
    return random.choice(base_oils)

def choose_essential_oil():
    """选择香精"""
    essential_oils = ['柠檬香精', '茉莉香精', '薰衣草香精']
    return random.choice(essential_oils)

def mix_oils(base_oil, essential_oil, ratio):
    """混合精油"""
    mixed_oil = f"{base_oil}与{essential_oil}（比例{ratio}）"
    return mixed_oil

def adjust_smell(mixed_oil):
    """调整香气"""
    smell_types = ['清新', '花香', '木质']
    adjusted_smell = f"{mixed_oil}，调整为{random.choice(smell_types)}型"
    return adjusted_smell

def test_smell(adjusted_smell):
    """测试香气"""
    test_results = ['满意', '不满意']
    return random.choice(test_results)

def main():
    base_oil = choose_base_oil()
    essential_oil = choose_essential_oil()
    ratio = random.uniform(0.01, 0.1)  # 比例在1%到10%之间
    mixed_oil = mix_oils(base_oil, essential_oil, ratio)
    adjusted_smell = adjust_smell(mixed_oil)
    test_result = test_smell(adjusted_smell)
    
    if test_result == '满意':
        print(f"调香完成：{adjusted_smell}")
    else:
        print(f"香气调整不满意，需要重新调整：{adjusted_smell}")

if __name__ == "__main__":
    main()
```

**算法原理与数学模型：**

1. **基础油与香精的选择**：从多个选项中随机选择基础油和香精。
2. **混合比例的确定**：混合比例在1%到10%之间随机设定。
3. **香气调整**：根据混合后的香气类型（如清新、花香、木质），进行相应调整。
4. **香气测试**：通过测试决定是否满意，如果不满意则重新调整。

**举例说明：**

假设我们选择了**甜杏仁油**作为基础油，**柠檬香精**作为香精，混合比例为5%。混合后的精油香气为“甜杏仁油与柠檬香精（比例5%）”。经过调整，香气调整为“花香型”。测试后，消费者表示满意。

通过以上算法，我们可以系统地设计出个性化的香薰蜡烛配方，为消费者提供定制化的家居香氛体验。

#### 1.8 最佳实践 tips

在制作手工香薰蜡烛时，以下是一些最佳实践和注意事项，可以帮助您避免常见问题，提高制作质量：

1. **材料存储**：香精和蜡应存放在干燥、阴凉的地方，避免阳光直射。香精开封后应密封保存，以防挥发。
2. **安全操作**：使用蜡烛熔炉时，务必遵循安全操作规程，避免烫伤和火灾。熔蜡过程中应保持通风，防止有害气体积聚。
3. **温度控制**：确保蜡烛熔炉的温度控制在合适的范围内，避免过高或过低导致蜡质变化。
4. **香精比例**：初次尝试调香时，建议从较低的比例开始，逐渐调整，以免香气过于浓烈。
5. **模具选择**：根据蜡烛形状和大小选择合适的模具，确保模具材质与蜡相容，便于脱模。
6. **蜡烛养护**：制作完成后，将蜡烛放置在阴凉干燥处，避免直接阳光照射，防止蜡烛变形或褪色。
7. **环保意识**：选择环保材料和可降解模具，减少对环境的影响。妥善处理蜡烛燃烧后的残渣，避免污染。

通过遵循这些最佳实践，您将能够制作出高质量的香薰蜡烛，同时保障制作过程的安全性和环保性。
