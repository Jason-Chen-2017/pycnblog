#### 4.1.2 数学模型建立

根据牛顿第二定律，物体的运动方程为：

$$
m\frac{d^2 y(t)}{dt^2} + c\frac{dy(t)}{dt} + ky(t) = f(t)
$$

其中，\( f(t) = 0 \) 表示无外力作用。

#### 4.1.3 求解过程

我们采用数值方法求解上述方程，使用Python实现。

```python

import matplotlib.pyplot as plt

# 参数设置

k = 10
c = 2

# 求解方程
def solve_eqn(t, y, ydot):
    dydt = ydot
    d2ydt2 = -k/m*y - c/m*dydt
    return d2ydt2

# 数值求解
t = np.linspace(0, 20, 1000)
y0 = 0
ydot0 = 1
y = np.zeros_like(t)
y[0] = y0
ydot = np.zeros_like(t)
ydot[0] = ydot0

for i in range(1, len(t)):
    y[i] = y[i-1] + ydot[i-1]*(t[i]-t[i-1])
    ydot[i] = ydot[i-1] + solve_eqn(t[i], y[i], ydot[i-1])*(t[i]-t[i-1])

# 绘图
plt.plot(t, y)
plt.xlabel('Time (s)')
plt.ylabel('Displacement (m)')
plt.title('Vibration Analysis')
plt.show()
```

#### 4.1.4 结果分析与验证

通过数值求解，我们得到物体的振动位移随时间的变化曲线。分析结果表明，物体在弹簧和阻尼器的共同作用下，振动幅度逐渐减小，最终趋于稳定。

from scipy.integrate import solve_ivp

# 参数设置

# 定义微分方程

m = 1
c = 0.1
k = 10

Ki = 0.1
Kd = 0.05

    return u

# 时间范围
