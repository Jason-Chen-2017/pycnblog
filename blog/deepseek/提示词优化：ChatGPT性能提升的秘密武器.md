   ```python
       tokens = word_tokenize(cleaned_input)
       # 去除停用词
       filtered_tokens = [token for token in tokens if token.lower() not in stopwords.words('english')]
       return filtered_tokens
   ```

   ```python
   from collections import Counter

   def extract_keywords(preprocessed_input):
       # 计算词频
       word_freq = Counter(preprocessed_input)

       keywords = word_freq.most_common(5)
   ```

   ```python
   def extend_context(user_input, history):

       vectorizer.fit(history)
       # 转换用户输入
       user_input_vector = vectorizer.transform([user_input])
       # 扩展上下文
       extended_context = vectorizer.get_feature_names_out()
       return extended_context
   ```

   在这个模块中，我们使用了`sklearn.TfidfVectorizer`类创建TF-IDF向量器，并使用历史对话信息进行训练。然后，我们使用这个向量器扩展用户输入的上下文。
