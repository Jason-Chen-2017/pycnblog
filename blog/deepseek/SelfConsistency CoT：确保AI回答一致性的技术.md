### 2.4.2 模型数学公式

模型的损失函数可以表示为：

$$
L(\theta) = -\sum_{i=1}^{N} y_i \log(p(x_i|\theta))
$$

其中，$\theta$ 是模型参数，$y_i$ 是标签，$p(x_i|\theta)$ 是模型在参数$\theta$下生成$x_i$的概率。

def evaluate_consistency(responses):
    # 计算一致性分数
    consistency_score = 0
    for i in range(len(responses)):
        for j in range(i+1, len(responses)):
            if responses[i] != responses[j]:
                consistency_score -= 1
    return consistency_score / (len(responses)*(len(responses)-1)/2)
