#### 6.2 系统核心实现源代码

以下是实现全天候投资组合系统的核心代码示例：

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 加载测试数据集
data = pd.read_csv('dataset.csv')

# 数据预处理
data = data[['Stock', 'Bond', 'Commodity', 'Currency']]
data_returns = data.pct_change().dropna()

# 计算各资产的预期收益和方差
expected_returns = data_returns.mean()
variances = data_returns.cov()

# 初始化权重
weights = np.linalg.inv(variances).dot(expected_returns)

# 动态调整策略
def adjust_weights(market_data, initial_weights, max_drawdown):
    current_returns = market_data.mean()
    current_variance = market_data.cov()
    
    if current_returns < max_drawdown:
        new_weights = np.linalg.inv(current_variance).dot(current_returns)
        return new_weights
    else:
        return initial_weights

# 模拟多次市场变化
market_changes = [0.1, -0.05, 0.03, -0.1]
for change in market_changes:
    weights = adjust_weights(data_returns[change], weights, max_drawdown)
    print(f"调整后权重：{weights}")

```

该代码首先加载测试数据集并进行预处理，然后计算各资产的预期收益和方差。接着，定义了动态调整策略函数 `adjust_weights`，用于根据当前市场数据调整资产权重。最后，模拟多次市场变化，展示动态调整的效果。
