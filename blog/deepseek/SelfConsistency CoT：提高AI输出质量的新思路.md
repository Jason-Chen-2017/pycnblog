```python
import networkx as nx

def extract_concepts(data):
    concepts = []
    for text in data:
        # 分词处理
        words = text.split()
        concepts.extend(words)
    return concepts
```

##### 5.2.2 关系构建代码

```python
def build_relations(concepts):
    relations = []
    for i in range(len(concepts)):
        for j in range(i+1, len(concepts)):
            relations.append((concepts[i], 'is_related_to', concepts[j]))
    return relations
```

##### 5.2.3 推理优化代码

```python
def optimize_graph(concepts, relations):
    G = nx.DiGraph()
    G.add_nodes_from(concepts)
    for r in relations:
        G.add_edge(r[0], r[2], relation=r[1])
    return G
```
