```mermaid
sequenceDiagram
  participant A as 系统
  participant B as 数据源
  participant C as 数据清洗工具
  A->>B: 收集数据
  B->>A: 提供数据
  A->>C: 预处理数据
  C->>A: 返回预处理后的数据
  A->>C: 清洗数据
  C->>A: 返回清洗后的数据
  A->>C: 验证数据
  C->>A: 返回验证结果
```

##### 3.3 数据清洗方法

数据清洗方法包括去重、缺失值处理、异常值检测和格式化等。

```python
# 去重
unique_data = list(set(data))

# 缺失值处理
data = [x for x in data if x is not None]

# 异常值检测
import numpy as np
z_scores = np.abs((data - np.mean(data)) / np.std(data))
threshold = 3
outliers = data[z_scores > threshold]

# 格式化
data = [str(x).upper() for x in data]
```
