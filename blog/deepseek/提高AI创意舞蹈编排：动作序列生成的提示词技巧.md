#### 7.3 Python源代码实现

以下是一个简单的动作序列生成算法的Python代码示例：

```python
import numpy as np

# 定义动作列表
actions = ['左转', '右转', '跳跃', '伸展']

# 定义概率转移矩阵
transition_matrix = np.array([
    [0.3, 0.4, 0.2, 0.1],
    [0.2, 0.5, 0.2, 0.1],
    [0.1, 0.3, 0.5, 0.1],
    [0.1, 0.2, 0.3, 0.4]
])

# 随机选择初始动作
current_action = np.random.choice(actions)

# 生成动作序列
sequence = [current_action]
for _ in range(5):
    # 根据概率转移矩阵生成下一个动作
    next_action = np.random.choice(actions, p=transition_matrix[:, actions.index(current_action)])
    sequence.append(next_action)
    current_action = next_action

print("生成的动作序列:", sequence)
```
