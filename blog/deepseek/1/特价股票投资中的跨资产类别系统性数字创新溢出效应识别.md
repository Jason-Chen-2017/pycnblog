### 3.3 算法实现代码
```python
import numpy as np
from statsmodels.tsa.stattools import grangercausality检验
import networkx as nx

# 示例数据：假设data为包含多个资产价格的DataFrame
data = pd.DataFrame(np.random.randn(100, 5), columns=['股票', '债券', '房地产', '商品', '指数'])

# 使用Granger因果检验
def granger_test(x, y):
    # x和y为两个时间序列
    model = grangercausality检验(x, y, max_lag=5)
    return model.pvalue

# 构建因果关系网络
edges = []
for i in range(len(data.columns)):
    for j in range(len(data.columns)):
        if i != j:
            pvalue = granger_test(data.iloc[:, i], data.iloc[:, j])
            if pvalue < 0.05:
                edges.append((data.columns[i], data.columns[j]))

G = nx.DiGraph()
G.add_edges_from(edges)

# 可视化网络图
nx.draw(G, with_labels=True, node_color='skyblue', edge_color='red')
plt.show()
```

### 3.4 数学模型与公式
#### 3.4.1 Granger因果检验模型
- 假设H0：变量X不能预测变量Y。
- 模型为：
  $$ Y_t = \alpha + \beta Y_{t-1} + \gamma X_{t-1} + \epsilon_t $$
- 检验统计量为F值，若F值显著，拒绝H0，认为X是Y的Granger原因。

#### 3.4.2 网络分析模型
- 构建资产价格波动网络，节点为资产类别，边表示因果关系。
- 使用网络中心性指标（如介数中心性）识别关键资产类别。
