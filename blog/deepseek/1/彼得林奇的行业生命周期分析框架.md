## 1.1 行业生命周期的概念

### 1.1.1 行业生命周期的定义
行业生命周期是指一个行业从诞生到衰退的完整发展过程，通常分为导入期、成长期、成熟期和衰退期四个阶段。彼得林奇的行业生命周期分析框架通过研究行业所处的生命周期阶段，帮助投资者制定相应的投资策略。

### 1.1.2 行业生命周期的核心要素
行业生命周期的核心要素包括：
1. **市场容量**：行业的市场规模和发展潜力。
2. **增长率**：行业收入的年增长率。
3. **竞争结构**：行业内竞争企业的数量和市场份额分布。
4. **技术发展**：行业的技术进步速度和技术成熟度。
5. **政策环境**：政府政策对行业的影响。

# 第2章: 行业生命周期的四个阶段

## 2.1 行业生命周期的四个阶段

### 2.1.1 导入期：行业的萌芽阶段
导入期是行业生命周期的初始阶段，市场容量较小，行业增长率较高，但行业内企业数量较少，竞争较为宽松。

### 2.1.2 成长期：行业的快速发展阶段
成长期是行业生命周期的第二阶段，市场容量迅速扩大，行业增长率持续上升，行业内企业数量增加，竞争逐渐加剧。

### 2.1.3 成熟期：行业的稳定发展阶段
成熟期是行业生命周期的第三阶段，市场容量趋于饱和，行业增长率放缓，行业内企业数量稳定，竞争达到最高水平。

### 2.1.4 衰退期：行业的衰退阶段
衰退期是行业生命周期的最后阶段，市场容量逐渐缩小，行业增长率变为负数，行业内企业数量开始减少，竞争逐步减弱。

## 2.2 每个阶段的特征与策略

### 2.2.1 导入期的市场特点与投资策略
在导入期，市场容量小，行业增长率高，行业内企业数量少，竞争宽松。投资者应关注行业的技术创新和市场潜力，寻找具有先发优势的企业进行投资。

### 2.2.2 成长期的市场特点与投资策略
在成长期，市场容量迅速扩大，行业增长率持续上升，行业内企业数量增加，竞争加剧。投资者应关注行业的市场扩展能力和企业的盈利能力，寻找具有较高增长潜力的企业进行投资。

### 2.2.3 成熟期的市场特点与投资策略
在成熟期，市场容量趋于饱和，行业增长率放缓，行业内企业数量稳定，竞争达到最高水平。投资者应关注行业的市场份额和企业的竞争优势，寻找具有稳定盈利能力的企业进行投资。

### 2.2.4 衰退期的市场特点与投资策略
在衰退期，市场容量逐渐缩小，行业增长率变为负数，行业内企业数量开始减少，竞争逐步减弱。投资者应关注行业的市场退出和企业的资产变现能力，寻找能够有效转型或退出的企业进行投资。

## 2.3 本章小结

### 2.3.1 行业生命周期的四个阶段总结
行业生命周期包括导入期、成长期、成熟期和衰退期四个阶段，每个阶段的市场容量、增长率和竞争结构都有其独特的特点。

### 2.3.2 不同阶段的投资策略特点
在不同行业生命周期阶段，投资者应采取不同的投资策略，关注行业的市场潜力、竞争结构和企业盈利能力，选择具有投资价值的企业进行投资。

import requests
from bs4 import BeautifulSoup

def get_industry_data(url):
    response = requests.get(url)
    soup = BeautifulSoup(response.text, 'html.parser')
    data = []
    for item in soup.find_all('div', class_='item'):
        industry_name = item.find('h2').text
        growth_rate = float(item.find('p').text.split(':')[1])
        data.append({'industry': industry_name, 'growth_rate': growth_rate})
    return data

industry_data = get_industry_data('https://example.com/industry_data')
