自我一致性（Self-Consistency）是指在多个情境或时间点下，个体或群体的行为、态度或表现保持一致。这种一致性可以表现为个体在面临不同情境时，其行为模式、偏好或价值观的一致性，或者群体在长时间内其社会结构和社会互动模式的一致性。例如，一个个体在不同的社交媒体平台上表现出相似的偏好和行为，或者一个群体在多个社会活动中表现出相似的行为特征，这些都是自我一致性的体现。

自我一致性的特征主要包括：

1. **持久性**：个体或群体的自我一致性在长时间内保持不变。
2. **一致性**：个体或群体的行为、态度或表现在不同情境下保持相似。
3. **差异性**：个体或群体在与其他个体或群体的互动中表现出差异。

#### 自我一致性度的定义

自我一致性度（Degree of Self-Consistency）是衡量个体或群体在多个情境或时间点下行为一致性的指标。数学上，自我一致性度可以用以下公式表示：

\[ D(x) = \frac{1}{n} \sum_{i=1}^{n} d(x_i, x_j) \]

其中，\( D(x) \) 表示个体\( x \)的自我一致性度，\( n \) 表示时间点或情境的数量，\( d(x_i, x_j) \) 表示个体在时间点或情境\( i \)和\( j \)之间的距离或差异。

例如，假设我们有一个个体在三个时间点上的行为数据，分别是\( x_1, x_2, x_3 \)。我们可以计算这三个时间点之间的差异，然后取平均值来得到自我一致性度：

\[ D(x) = \frac{1}{3} \left[ d(x_1, x_2) + d(x_2, x_3) + d(x_3, x_1) \right] \]

#### 自我一致性模式识别

自我一致性模式识别是Self-Consistency CoT中的关键步骤。通过聚类分析等方法，我们可以识别出个体或群体的自我一致性模式。以下是一个使用K-means算法进行自我一致性模式识别的数学模型：

\[ C = \{ c_1, c_2, ..., c_k \} \]

其中，\( C \) 是聚类中心集合，\( k \) 是聚类数量，\( c_i \) 是第\( i \)个聚类中心。

K-means算法的目标是最小化聚类中心之间的距离和内部距离，即：

\[ \min_{C} \sum_{i=1}^{k} \sum_{x_j \in C_i} d(c_i, x_j) \]

其中，\( C_i \) 是包含个体\( x_j \)的聚类。

例如，如果我们使用K-means算法将个体分为三个聚类，我们可以计算每个个体的聚类中心，然后根据距离公式计算每个个体到其聚类中心的距离，从而识别出自我一致性模式。

#### 自我一致性度的稳定性分析

自我一致性度的稳定性分析是评估自我一致性模式有效性的关键步骤。我们可以使用方差分析（ANOVA）来评估自我一致性度在不同情境或时间点上的稳定性。方差分析的基本公式如下：

\[ F = \frac{MS_{between}}{MS_{within}} \]

其中，\( F \) 是方差比，\( MS_{between} \) 是组间均方，\( MS_{within} \) 是组内均方。

组间均方（\( MS_{between} \)）计算公式为：

\[ MS_{between} = \frac{1}{k-1} \sum_{i=1}^{k} (\bar{x_i} - \bar{x})^2 \]

其中，\( \bar{x_i} \) 是第\( i \)组的均值，\( \bar{x} \) 是总均值。

组内均方（\( MS_{within} \)）计算公式为：

\[ MS_{within} = \frac{1}{n-k} \sum_{i=1}^{k} \sum_{j=1}^{n} (x_{ij} - \bar{x_i})^2 \]

其中，\( x_{ij} \) 是第\( i \)组的第\( j \)个观测值。

通过计算方差比\( F \)，我们可以判断自我一致性度在不同情境或时间点上的稳定性。如果\( F \)值较大，说明自我一致性度在不同情境或时间点上的差异较大，即自我一致性模式较为稳定。

   计算结果为：

   \[ MS_{between} = 0.25 \]
   \[ MS_{within} = 0.25 \]

   方差比为：

   \[ F = \frac{MS_{between}}{MS_{within}} = 1 \]

   由于\( F \)值接近1，说明自我一致性度在不同时间点上的差异不大，即自我一致性模式较为稳定。

import pandas as pd

import matplotlib.pyplot as plt

import MySQLdb

    time_diff = actions['action_time'].diff().abs().fillna(0)
    consistency_score = np.mean(time_diff)
    return consistency_score

users['consistency_score'] = users.apply(extract_consistency_features, axis=1)

# 模式识别
# 使用K-means算法进行聚类分析
kmeans = KMeans(n_clusters=3)
clusters = kmeans.fit_predict(users[['consistency_score']])

# 结果分析
# 分析聚类结果
users['cluster'] = clusters
users.groupby('cluster')['consistency_score'].describe()

# 可视化
sns.scatterplot(data=users, x='consistency_score', hue='cluster', style='cluster', legend=False)
plt.title('User Consistency Score by Cluster')
plt.show()

# 关闭数据库连接
conn.close()
