##### 第1章：算法基础

算法是解决问题的一系列明确、有限步骤。在算法面试中，了解算法的定义与特性至关重要。以下是对算法定义与特性的详细解释：

**算法的定义：** 算法是一种用于解决问题的明确、有序的步骤集合。它可以是数学公式、逻辑流程、计算机程序等。

**算法的特性：**
1. **确定性：** 对于同一问题，同一个算法总是能够得到相同的结果。
2. **有限性：** 算法的执行步骤是有限的，不会无限循环。
3. **输入：** 算法可以接受一个或多个输入。
4. **输出：** 算法能够产生一个或多个输出结果。
5. **可行性：** 算法的每一步都是可行的，即可以在实际中执行。

##### 第2章：核心算法原理讲解

**2.1 排序算法**

排序算法是计算机科学中一种重要的算法，用于对一组数据进行排序。以下是几种常见的排序算法：

1. **冒泡排序（Bubble Sort）**：冒泡排序是一种简单的排序算法。它重复遍历要排序的数列，比较每对相邻的项，如果它们的顺序错误就交换它们，直到没有需要交换的项。

   ```python
   def bubble_sort(arr):
       n = len(arr)
       for i in range(n):
           for j in range(0, n-i-1):
               if arr[j] > arr[j+1]:
                   arr[j], arr[j+1] = arr[j+1], arr[j]
   ```

2. **快速排序（Quick Sort）**：快速排序是一种高效的排序算法。它通过递归地将数组分成较小的子数组，然后对子数组进行排序。

   ```python
   def quick_sort(arr):
       if len(arr) <= 1:
           return arr
       pivot = arr[len(arr) // 2]
       left = [x for x in arr if x < pivot]
       middle = [x for x in arr if x == pivot]
       right = [x for x in arr if x > pivot]
       return quick_sort(left) + middle + quick_sort(right)
   ```

3. **归并排序（Merge Sort）**：归并排序是一种分治算法。它将数组分成较小的子数组，然后对子数组进行排序，最后将排好序的子数组合并成完整的数组。

   ```python
   def merge_sort(arr):
       if len(arr) <= 1:
           return arr
       mid = len(arr) // 2
       left = merge_sort(arr[:mid])
       right = merge_sort(arr[mid:])
       return merge(left, right)
   
   def merge(left, right):
       result = []
       i = j = 0
       while i < len(left) and j < len(right):
           if left[i] < right[j]:
               result.append(left[i])
               i += 1
           else:
               result.append(right[j])
               j += 1
       result.extend(left[i:])
       result.extend(right[j:])
       return result
   ```

4. **堆排序（Heap Sort）**：堆排序是一种利用堆这种数据结构的排序算法。堆是一个近似完全二叉树的结构，并同时满足堆积的性质：即子节点的键值或索引总是小于（或者大于）它的父节点。

   ```python
   def heapify(arr, n, i):
       largest = i
       left = 2 * i + 1
       right = 2 * i + 2
       if left < n and arr[i] < arr[left]:
           largest = left
       if right < n and arr[largest] < arr[right]:
           largest = right
       if largest != i:
           arr[i], arr[largest] = arr[largest], arr[i]
           heapify(arr, n, largest)
   
   def heap_sort(arr):
       n = len(arr)
       for i in range(n // 2 - 1, -1, -1):
           heapify(arr, n, i)
       for i in range(n - 1, 0, -1):
           arr[i], arr[0] = arr[0], arr[i]
           heapify(arr, i, 0)
   ```

**2.2 搜索算法**

搜索算法用于在数据结构中查找特定元素。以下是几种常见的搜索算法：

1. **二分查找（Binary Search）**：二分查找算法是用于在有序数组中查找特定元素的搜索算法。

   ```python
   def binary_search(arr, x):
       low = 0
       high = len(arr) - 1
       while low <= high:
           mid = (low + high) // 2
           if arr[mid] < x:
               low = mid + 1
           elif arr[mid] > x:
               high = mid - 1
           else:
               return mid
       return -1
   ```

2. **广度优先搜索（BFS，Breadth-First Search）**：广度优先搜索是一种用于图数据结构的搜索算法。它从源点开始，依次访问源点的邻接点，然后再访问邻接点的邻接点，直到找到目标节点。

   ```python
   from collections import deque
   
   def bfs(graph, start, target):
       visited = set()
       queue = deque([start])
       while queue:
           vertex = queue.popleft()
           if vertex not in visited:
               visited.add(vertex)
               if vertex == target:
                   return True
               for neighbour in graph[vertex]:
                   queue.append(neighbour)
       return False
   ```

3. **深度优先搜索（DFS，Depth-First Search）**：深度优先搜索是一种用于图数据结构的搜索算法。它与广度优先搜索类似，但优先访问当前节点的邻接点，而不是按顺序访问所有邻接点。

   ```python
   def dfs(graph, start, target, visited=None):
       if visited is None:
           visited = set()
       visited.add(start)
       if start == target:
           return True
       for neighbour in graph[start]:
           if neighbour not in visited:
               if dfs(graph, neighbour, target, visited):
                   return True
       return False
   ```

**2.3 图算法**

图算法是用于处理图数据结构的算法。以下是几种常见的图算法：

1. **Dijkstra算法**：Dijkstra算法是一种用于计算图中两点之间最短路径的算法。

   ```python
   def dijkstra(graph, start):
       distances = {vertex: float('infinity') for vertex in graph}
       distances[start] = 0
       priority_queue = [(0, start)]
       while priority_queue:
           current_distance, current_vertex = heapq.heappop(priority_queue)
           if current_distance > distances[current_vertex]:
               continue
           for neighbour, weight in graph[current_vertex].items():
               distance = current_distance + weight
               if distance < distances[neighbour]:
                   distances[neighbour] = distance
                   heapq.heappush(priority_queue, (distance, neighbour))
       return distances
   ```

2. **A*算法**：A*算法是一种用于计算图中两点之间最短路径的算法，它利用启发式函数来提高搜索效率。

   ```python
   def astar(graph, start, goal, heuristic):
       open_set = [(0, start)]
       came_from = {}
       g_score = {vertex: float('infinity') for vertex in graph}
       g_score[start] = 0
       f_score = {vertex: float('infinity') for vertex in graph}
       f_score[start] = heuristic(start, goal)
       while open_set:
           current = heapq.heappop(open_set)[1]
           if current == goal:
               return reconstruct_path(came_from, current)
           for neighbour, weight in graph[current].items():
               tentative_g_score = g_score[current] + weight
               if tentative_g_score < g_score[neighbour]:
                   came_from[neighbour] = current
                   g_score[neighbour] = tentative_g_score
                   f_score[neighbour] = tentative_g_score + heuristic(neighbour, goal)
                   if neighbour not in [item[1] for item in open_set]:
                       heapq.heappush(open_set, (f_score[neighbour], neighbour))
       return None
   
   def reconstruct_path(came_from, current):
       path = [current]
       while current in came_from:
           current = came_from[current]
           path.append(current)
       path.reverse()
       return path
   ```

3. **并查集（Union-Find）**：并查集是一种用于处理动态连通性问题的数据结构。它可以高效地合并两个集合，并检查两个元素是否在同一集合中。

   ```python
   def find(x, parent):
       if parent[x] != x:
           parent[x] = find(x, parent)
       return parent[x]
   
   def union(x, y, parent, rank):
       rootX = find(x, parent)
       rootY = find(y, parent)
       if rootX != rootY:
           if rank[rootX] > rank[rootY]:
               parent[rootY] = rootX
           elif rank[rootX] < rank[rootY]:
               parent[rootX] = rootY
           else:
               parent[rootY] = rootX
               rank[rootX] += 1
   ```

   ```python
   def matrix_addition(A, B):
   ```

##### 第4章：高频算法题解析

**第4章：动态规划**

动态规划是一种用于解决最优化问题的算法方法。它将问题分解为子问题，并通过求解子问题来得到原问题的最优解。以下是几个动态规划经典问题：

**4.1 最长递增子序列**

最长递增子序列是一个经典的最优化问题，要求找出一个序列的最长递增子序列。

**动态规划思路：**
- 定义一个数组 `dp`，其中 `dp[i]` 表示以第 `i` 个元素为结尾的最长递增子序列的长度。
- 遍历数组，对于每个元素 `nums[i]`，遍历所有前面的元素 `nums[j]`（`j < i`），如果 `nums[i] > nums[j]`，则更新 `dp[i]` 的值。

```python
def longest_increasing_subsequence(nums):
    if not nums:
        return []
    dp = [1] * len(nums)
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[i] > nums[j]:
                dp[i] = max(dp[i], dp[j] + 1)
    max_len = max(dp)
    if max_len == 1:
        return []
    result = []
    for i in range(len(nums)):
        if dp[i] == max_len:
            result.append(nums[i])
            max_len -= 1
    return result
```

**4.2 最长公共子序列**

最长公共子序列（Longest Common Subsequence，LCS）是指两个序列中长度最长的公共子序列。

**动态规划思路：**
- 定义一个二维数组 `dp`，其中 `dp[i][j]` 表示序列 `text1` 的前 `i` 个字符和序列 `text2` 的前 `j` 个字符的最长公共子序列的长度。
- 遍历两个序列，如果 `text1[i - 1] == text2[j - 1]`，则 `dp[i][j] = dp[i - 1][j - 1] + 1`；否则 `dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])`。

```python
def longest_common_subsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

**4.3 最小路径和**

给定一个包含正整数和负整数的二维网格，求从左上角到右下角的最小路径和。

**动态规划思路：**
- 定义一个二维数组 `dp`，其中 `dp[i][j]` 表示从左上角到 `(i, j)` 的最小路径和。
- 遍历网格，更新 `dp` 数组。

```python
def min_path_sum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = grid[0][0]
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
    return dp[-1][-1]
```

##### 第4章：贪心算法

贪心算法是一种通过不断选择当前最佳选择来解决问题的算法。以下是几个贪心算法经典问题：

**4.1 背包问题**

给定一组物品，每个物品都有重量和价值，以及一个背包的容量，求如何选择物品使得背包的总价值最大。

**贪心策略：**
- 选择价值与重量比最大的物品，直到背包容量不足为止。

```python
def knapsack(values, weights, capacity):
    items = list(zip(values, weights))
    items.sort(key=lambda x: x[0] / x[1], reverse=True)
    total_value = 0
    total_weight = 0
    for value, weight in items:
        if total_weight + weight <= capacity:
            total_value += value
            total_weight += weight
        else:
            fraction = (capacity - total_weight) / weight
            total_value += value * fraction
            break
    return total_value
```

**4.2 活动选择问题**

给定一组活动，每个活动都有开始时间和结束时间，选择一组相互不冲突的活动使得总持续时间最长。

**贪心策略：**
- 选择持续时间最长的活动，然后从下一个活动的开始时间开始选择下一个活动。

```python
def activity_selection(activities):
    activities.sort(key=lambda x: x[1])
    result = [activities[0]]
    for activity in activities[1:]:
        if activity[0] >= result[-1][1]:
            result.append(activity)
    return result
```

##### 第4章：分治算法

分治算法是一种将问题分解为子问题，分别解决子问题，然后将子问题的解合并为原问题的解的算法。以下是几个分治算法经典问题：

**4.1 快速幂算法**

给定一个整数 `base` 和一个非负整数 `exponent`，求 `base` 的 `exponent` 次幂。

**分治策略：**
- 如果 `exponent` 为 0，则返回 1。
- 如果 `exponent` 为 1，则返回 `base`。
- 如果 `exponent` 为偶数，则 `base^exponent = (base^(exponent/2))^2`。
- 如果 `exponent` 为奇数，则 `base^exponent = base * (base^(exponent-1))`。

```python
def quick_power(base, exponent):
    if exponent == 0:
        return 1
    if exponent == 1:
        return base
    if exponent % 2 == 0:
        half_power = quick_power(base, exponent // 2)
        return half_power * half_power
    else:
        half_power = quick_power(base, (exponent - 1) // 2)
        return base * half_power * half_power
```

**4.2 大数乘法**

给定两个大整数 `a` 和 `b`，求它们的乘积。

**分治策略：**
- 将大整数分解为较小的整数，分别计算乘积，然后合并结果。

```python
def large_number_multiplication(a, b):

    if len(a) > len(b):
```

线段树是一种用于高效处理区间查询和更新的二叉树。

**构建策略：**

```python
class SegmentTree:
    def __init__(self, nums):
        self.n = len(nums)
        self.tree = [0] * (2 * self.n)
        for i in range(self.n):
            self.tree[self.n + i] = nums[i]
        for i in range(self.n - 1, 0, -1):
            self.tree[i] = self.tree[i << 1] + self.tree[i << 1 | 1]

    def update(self, i, val):
        i += self.n
        self.tree[i] = val
        while i > 1:
            i >>= 1
            self.tree[i] = self.tree[i << 1] + self.tree[i << 1 | 1]

    def query(self, l, r):
        result = 0
        l += self.n
        r += self.n
        while l <= r:
            if l & 1:
                result += self.tree[l]
                l += 1
            if r & 1 == 0:
                result += self.tree[r]
                r -= 1
            l >>= 1
            r >>= 1
        return result
```

**4.1 KMP算法**

KMP算法（Knuth-Morris-Pratt Algorithm）是一种用于字符串匹配的高效算法。

**算法思路：**
- 构造一个部分匹配表（Next数组），用于记录模式的前缀与后缀的最长公共前缀长度。
- 当模式的前缀与后缀的最长公共前缀长度不为 0 时，跳过当前匹配不成功的字符。

```python
def kmp_match(s, p):
    def build_next(p):
        next = [0] * len(p)
        j = 0
        for i in range(1, len(p)):
            while j > 0 and p[i] != p[j]:
                j = next[j - 1]
            if p[i] == p[j]:
                j += 1
            next[i] = j
        return next

    next = build_next(p)
    i = j = 0
    while i < len(s):
        while j > 0 and s[i] != p[j]:
            j = next[j - 1]
        if s[i] == p[j]:
            i += 1
            j += 1
        if j == len(p):
            return i - j
        if i < len(s) and j > 0:
            j = next[j - 1]
    return -1
```

**算法思路：**

- 遍历文本，根据 DFA 的状态转移进行匹配。

```python
def match_regex(s, p):

        dfa = {}
        start = 0
        for char in p:
            if char not in dfa:
                dfa[char] = []
            dfa[char].append(start)
            start += 1
        dfa[p[-1]].append(start)
        return dfa

    dfa = build_dfa(p)
    state = 0
    for char in s:
        if char in dfa:
            state = dfa[char][-1]
        else:
            state = dfa['.']
        if state == len(p):
            return True
    return False
```

**4.3 网络流算法**

网络流算法是一类用于求解网络最大流问题的算法。

**算法思路：**
- 使用Ford-Fulkerson算法计算最大流。
- 使用BFS和DFS寻找增广路径。

```python
def bfs(source, sink, residual, parent):
    visited = [False] * len(residual)
    visited[source] = True
    queue = deque([source])
    while queue:
        vertex = queue.popleft()
        for i in range(len(residual)):
            if not visited[i] and residual[vertex][i] > 0:
                queue.append(i)
                visited[i] = True
                parent[i] = vertex
                if i == sink:
                    return True
    return False

def ford_fulkerson(source, sink, residual):
    parent = [-1] * len(residual)
    max_flow = 0
    while bfs(source, sink, residual, parent):
        path_flow = min(residual[source][i] for i in range(len(residual)) if parent[i] != -1 and residual[parent[i]][i] > 0)
        for i in range(len(residual)):
            if parent[i] != -1:
                residual[parent[i]][i] -= path_flow
                residual[i][parent[i]] += path_flow
        max_flow += path_flow
    return max_flow
```

```python
def longest_common_subsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

```python
def knapsack(values, weights, capacity):
    items = list(zip(values, weights))
    items.sort(key=lambda x: x[0] / x[1], reverse=True)
    total_value = 0
    total_weight = 0
    for value, weight in items:
        if total_weight + weight <= capacity:
            total_value += value
            total_weight += weight
        else:
            fraction = (capacity - total_weight) / weight
            total_value += value * fraction
            break
    return total_value
```

```python
    left = [x for x in arr if x < pivot]
```
