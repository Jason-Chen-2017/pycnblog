### 第一部分：编程基础

#### 第1章：编程语言基础

### 1.1 数据类型和变量

#### 数据类型介绍

在编程中，数据类型是基础中的基础。不同的编程语言支持不同的数据类型，但一般来说，常见的数据类型包括以下几种：

- **整型**（`int`）：表示整数，如`10`、`-5`。
- **浮点型**（`float`、`double`）：表示小数，如`3.14`、`-0.5`。
- **布尔型**（`bool`）：表示逻辑值，如`true`、`false`。
- **字符型**（`char`）：表示单个字符，如`'a'`、`'B'`。
- **字符串**（`String`）：表示一系列字符，如`"Hello World"`。

#### 变量定义

变量是编程中用于存储数据的容器。变量定义的一般语法如下：

```c
数据类型 变量名;
```

例如：

```c
int age;
float salary;
bool isVip;
```

#### 变量作用域

变量作用域决定了变量在代码中的可见性和生命周期。根据作用域的不同，变量可以分为以下几类：

- **局部变量**：在函数内部定义的变量，作用域仅限于该函数。
- **全局变量**：在函数外部定义的变量，作用域是整个程序。
- **静态变量**：具有静态存储期的变量，在程序运行期间始终存在。

#### 变量初始化

在变量定义后，我们需要为其赋初值。初始化的一般语法如下：

```c
数据类型 变量名 = 初始值;
```

例如：

```c
int age = 30;
float salary = 5000.0;
bool isVip = false;
```

#### 变量类型转换

在某些情况下，我们需要将一个变量的类型转换为另一个类型。类型转换的一般语法如下：

```c
数据类型(变量名);
```

例如：

```c
int a = 10;
float b = 3.14;
int c = (int)b;  // 将浮点型变量b转换为整型
```

### 1.2 控制结构

#### 条件判断

条件判断是编程中常用的一种控制结构，用于根据条件选择执行不同的代码块。常见的条件判断语句包括`if-else`和`switch`。

- **if-else语句**：

```c
if (条件) {
    // 当条件为真时执行的代码
} else {
    // 当条件为假时执行的代码
}
```

- **switch语句**：

```c
switch (表达式) {
    case 值1:
        // 当表达式的值为值1时执行的代码
        break;
    case 值2:
        // 当表达式的值为值2时执行的代码
        break;
    default:
        // 当表达式的值不匹配任何case时执行的代码
}
```

#### 循环结构

循环结构用于重复执行一段代码，直到满足某个条件为止。常见的循环结构包括`for`、`while`和`do-while`。

- **for循环**：

```c
for (初始化; 条件; 步进) {
    // 循环体
}
```

- **while循环**：

```c
while (条件) {
    // 循环体
}
```

- **do-while循环**：

```c
do {
    // 循环体
} while (条件);
```

### 1.3 函数与闭包

#### 函数定义

函数是编程中用于执行特定任务的代码块。函数定义的一般语法如下：

```c
返回类型 函数名(参数列表) {
    // 函数体
}
```

例如：

```c
int add(int a, int b) {
    return a + b;
}
```

#### 函数调用

函数调用是将函数的代码执行的一部分。函数调用的一般语法如下：

```c
函数名(参数列表);
```

例如：

```c
int result = add(3, 4);
```

#### 递归

递归是一种函数调用自身的方法。递归函数的一般形式如下：

```c
void 函数名(参数列表) {
    if (终止条件) {
        // 执行一些操作
    } else {
        // 执行递归调用
        函数名(新的参数列表);
    }
}
```

例如：

```c
int factorial(int n) {
    if (n == 0) {
        return 1;
    } else {
        return n * factorial(n - 1);
    }
}
```

#### 闭包

闭包是一种特殊的函数，它捕获并保留了定义时作用域内的变量。闭包的一般形式如下：

```c
函数名(参数列表) {
    // 使用捕获的变量
}
```

例如：

```c
int addFive() {
    int x = 5;
    return function(y) {
        return x + y;
    };
}
```

例如：


对象的创建和使用的一般语法如下：

```c
类名 对象名;
对象名.成员函数();
```

例如：

```c
Person person;
person.name = "Alice";
person.age = 25;
person.introduce();
```

#### 类的继承

继承是一种让一个类继承另一个类的属性和方法的方式。继承的一般语法如下：

```c
class 派生类名 : 公共/私有/保护 继承方式 基类名 {
    // 成员变量
    // 成员函数
};
```

例如：

```c
class Employee : public Person {
public:
    string position;
    
    void introduce() {
        cout << "Hello, my name is " << name << " and I work as a " << position << "." << endl;
    }

```

#### 封装与多态

封装是一种将数据和行为封装在类中的方式。多态是一种让对象根据其实际类型来执行不同方法的能力。

- **封装**：

```c
class Person {
private:
    string name;
    int age;

public:
    void setName(string newName) {
        name = newName;
    }

    string getName() {
        return name;
    }

    void setAge(int newAge) {
        age = newAge;
    }

    int getAge() {
        return age;
    }
};
```

- **多态**：

```c
class Animal {
public:
    virtual void makeSound() {
        cout << "The animal makes a sound." << endl;
    }
};

class Dog : public Animal {
public:
    void makeSound() override {
        cout << "The dog barks." << endl;
    }
};

class Cat : public Animal {
public:
    void makeSound() override {
        cout << "The cat meows." << endl;
    }
};

Animal* animals[] = {new Dog(), new Cat()};
for (Animal* animal : animals) {
    animal->makeSound();
}
```

#### 2.1 常见算法

##### 2.1.1 排序算法

排序算法是一种对数据进行排序的算法。常见的排序算法包括冒泡排序、选择排序、插入排序、快速排序等。

- **冒泡排序**：

```c
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
            }
        }
    }
}
```

- **选择排序**：

```c
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        swap(arr[i], arr[minIndex]);
    }
}
```

- **插入排序**：

```c
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

- **快速排序**：

```c
int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = (low - 1);
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return (i + 1);
}

void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}
```

##### 2.1.2 查找算法

查找算法是一种在数据集合中查找特定元素的方法。常见的查找算法包括二分查找和哈希查找。

- **二分查找**：

```c
int binarySearch(int arr[], int l, int r, int x) {
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (arr[m] == x) {
            return m;
        } else if (arr[m] < x) {
            l = m + 1;
        } else {
            r = m - 1;
        }
    }
    return -1;
}
```

- **哈希查找**：

```c
int hashFunction(int key, int size) {
    return key % size;
}

int hashSearch(int hashTable[], int key) {
    int index = hashFunction(key, size);
    while (hashTable[index] != -1 && hashTable[index] != key) {
        index = (index + 1) % size;
    }
    if (hashTable[index] == key) {
        return index;
    } else {
        return -1;
    }
}
```

##### 2.1.3 图算法

图算法是一种用于处理图结构数据的算法。常见的图算法包括深度优先搜索（DFS）和广度优先搜索（BFS）。

- **深度优先搜索（DFS）**：

```c
void dfs(int v, bool visited[], vector<int> adj[]) {
    visited[v] = true;
    cout << v << " ";
    for (int neighbor : adj[v]) {
        if (!visited[neighbor]) {
            dfs(neighbor, visited, adj);
        }
    }
}

vector<int> adj[100];
bool visited[100];

int n;  // 总节点数
int m;  // 总边数

// 建立图
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        adj[i].push_back(j);
        adj[j].push_back(i);
    }
}

visited[n - 1] = true;  // 初始化已访问节点
dfs(0, visited, adj);  // 从节点0开始搜索
```

- **广度优先搜索（BFS）**：

```c
void bfs(int start, vector<int> adj[], int n) {
    bool visited[n];
    memset(visited, false, sizeof(visited));
    queue<int> q;
    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        int node = q.front();
        q.pop();
        cout << node << " ";

        for (int neighbor : adj[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}

int n;  // 总节点数
int m;  // 总边数

// 建立图
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        adj[i].push_back(j);
        adj[j].push_back(i);
    }
}

bfs(0, adj, n);  // 从节点0开始搜索
```

#### 2.2 常见数据结构

##### 2.2.1 链表

链表是一种常见的数据结构，它由一系列节点组成，每个节点包含数据和指向下一个节点的指针。

- **单向链表**：

```c
struct ListNode {

    ListNode* curr = head;
    for (int i = 1; i < arr.size(); i++) {

}

head = createLinkedList(arr);
```

- **双向链表**：

```c
struct ListNode {

    ListNode *prev;

ListNode* createDoublyLinkedList(vector<int>& arr) {

    for (int i = 1; i < arr.size(); i++) {
        ListNode* newNode = new ListNode(arr[i]);
        curr->next = newNode;
        newNode->prev = curr;
```

```c
struct ListNode {

ListNode* createCircularLinkedList(vector<int>& arr) {
```

##### 2.2.3 哈希表

哈希表（Hash Table）是一种基于哈希函数进行数据存储和查找的数据结构。它通过计算键值和表的大小，将键值映射到表中一个位置来访问记录，从而实现快速查找。

- **哈希表**：

```c
struct HashTable {
    vector<int> data;
    int size;

    HashTable(int n) {
        size = n;
        data.resize(n, -1);
    }

    int hashFunction(int key) {
        return key % size;
    }

    void insert(int key) {
        int index = hashFunction(key);
        while (data[index] != -1 && data[index] != key) {
            index = (index + 1) % size;
        }
        data[index] = key;
    }

    bool search(int key) {
        int index = hashFunction(key);
        while (data[index] != -1 && data[index] != key) {
            index = (index + 1) % size;
        }
        return data[index] == key;
    }
};

HashTable hashTable(10);

hashTable.insert(1);
hashTable.insert(2);
hashTable.insert(3);

cout << hashTable.search(2) << " ";  // 输出 1（true表示找到键值2）
cout << hashTable.search(4) << " ";  // 输出 0（false表示未找到键值4）
```

##### 3.1 字符串处理

字符串处理问题在面试中非常常见，以下是一些典型的字符串处理题目：

- **实现一个有效的括号**

```c
bool isValid(string s) {
    stack<char> stk;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            stk.push(c);
        } else {
            if (stk.empty()) {
                return false;
            }
            char top = stk.top();
            if ((c == ')' && top != '(') || (c == ']' && top != '[') || (c == '}' && top != '{')) {
                return false;
            }
            stk.pop();
        }
    }
    return stk.empty();
}
```

- **最长公共前缀**

```c
string longestCommonPrefix(vector<string>& words) {
    if (words.empty()) {
        return "";
    }
    string prefix = words[0];
    for (int i = 1; i < words.size(); i++) {
        int j = 0;
        while (j < prefix.length() && j < words[i].length() && prefix[j] == words[i][j]) {
            j++;
        }
        prefix = prefix.substr(0, j);
        if (prefix.empty()) {
            break;
        }
    }
    return prefix;
}
```

- **有效数字**

```c
bool isNumber(string s) {
    int i = 0, n = s.length();
    while (i < n && (s[i] == ' ' || s[i] == '+' || s[i] == '-')) {
        i++;
    }
    bool hasDigit = false;
    bool hasE = false;
    for (; i < n; i++) {
        if (s[i] >= '0' && s[i] <= '9') {
            hasDigit = true;
        } else if (s[i] == 'e') {
            if (!hasDigit) {
                return false;
            }
            hasE = true;
            hasDigit = false;
        } else if (s[i] != '.' && s[i] != ' ') {
            return false;
        }
    }
    return hasDigit || hasE;
}
```

```c
void rotate(vector<vector<int>>& matrix) {
    int n = matrix.size();
    for (int i = 0; i < n / 2; i++) {
        for (int j = i; j < n - i - 1; j++) {
            int temp = matrix[i][j];
            matrix[i][j] = matrix[n - j - 1][i];
            matrix[n - j - 1][i] = matrix[n - i - 1][n - j - 1];
            matrix[n - i - 1][n - j - 1] = matrix[j][n - i - 1];
            matrix[j][n - i - 1] = temp;
        }
    }
}
```

```c
bool findRepeatNumber(vector<int>& nums) {

}
```

树和图是数据结构中的重要概念，以下是一些常见的树和图问题：

- **二叉树的遍历**

```c
void dfs(TreeNode* root) {
    if (root == nullptr) {
        return;
    }
    dfs(root->left);
    cout << root->val << " ";
    dfs(root->right);
}

TreeNode* createBinaryTree(vector<int>& nums) {
    TreeNode* root = new TreeNode(nums[0]);
    TreeNode* curr = root;
    for (int i = 1; i < nums.size(); i++) {
        TreeNode* newNode = new TreeNode(nums[i]);
        if (nums[i] < nums[i - 1]) {
            curr->left = newNode;
        } else {
            curr = curr->right;
            curr->right = newNode;
        }
    }
    return root;
}
```

- **图的遍历**

```c
void dfs(int v, bool visited[], vector<int> adj[]) {
    visited[v] = true;
    cout << v << " ";
    for (int neighbor : adj[v]) {
        if (!visited[neighbor]) {
            dfs(neighbor, visited, adj);
        }
    }
}

void bfs(int start, vector<int> adj[], int n) {
    bool visited[n];
    memset(visited, false, sizeof(visited));
    queue<int> q;
    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        int node = q.front();
        q.pop();
        cout << node << " ";

        for (int neighbor : adj[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}
```

- **路径总和**

```c
bool hasPathSum(TreeNode* root, int targetSum) {
    if (root == nullptr) {
        return false;
    }
    if (root->left == nullptr && root->right == nullptr && root->val == targetSum) {
        return true;
    }
    return hasPathSum(root->left, targetSum - root->val) || hasPathSum(root->right, targetSum - root->val);
}
```

```python
import threading

class DistributedMessageQueue:
    def __init__(self):
        self.messages = []
        self.lock = threading.Lock()

    def send_message(self, message):
        with self.lock:
            self.messages.append(message)
            self.persist_message(message)

    def persist_message(self, message):
        # 模拟消息持久化
        print("Persisting message: {}".format(message))

    def consume_message(self, consumer):
        with self.lock:
            while len(self.messages) > 0:
                message = self.messages.pop(0)
                self.consume_message_on_server(message, consumer)

    def consume_message_on_server(self, message, consumer):
        # 模拟消息消费
        print("Consuming message on server {}: message={}, consumer={}".format(consumer, message, consumer))
```
