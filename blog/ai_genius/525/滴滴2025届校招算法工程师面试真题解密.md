### 2.1 数据结构与算法

数据结构是计算机科学中用于存储和管理数据的各种方式，而算法则是解决问题的方法步骤。数据结构与算法是算法工程师的核心技能之一，以下是几个重要的基础数据结构和算法：

#### 2.1.1 基础数据结构

1. **数组**：数组是一种线性数据结构，用于存储一系列元素。数组的特点是访问元素的时间复杂度为O(1)，适用于需要频繁访问和修改元素的场景。
2. **链表**：链表是一种线性数据结构，每个节点包含数据域和指向下一个节点的指针。链表的优点是插入和删除操作的时间复杂度为O(1)，适用于频繁插入和删除元素的场景。
3. **栈**：栈是一种后进先出（LIFO）的数据结构，适用于需要按后进入先出顺序访问元素的场景，如递归、深度优先搜索等。
4. **队列**：队列是一种先进先出（FIFO）的数据结构，适用于需要按先进先出顺序访问元素的场景，如广度优先搜索等。

#### 2.1.2 树与二叉树

1. **树**：树是一种层级结构的数据结构，由一组节点组成，其中每个节点都有一个父节点和一个或多个子节点。树适用于表示层次关系和树形结构，如组织结构、文件系统等。
2. **二叉树**：二叉树是一种特殊的树，每个节点最多有两个子节点。二叉树在计算机科学中应用广泛，如二叉搜索树、平衡二叉树等。

#### 2.1.3 算法分析与设计

1. **时间复杂度**：时间复杂度是衡量算法执行时间与输入规模之间关系的一个指标，通常表示为O(f(n))，其中n为输入规模，f(n)为算法执行次数。
2. **空间复杂度**：空间复杂度是衡量算法所需存储空间与输入规模之间关系的一个指标，通常表示为O(g(n))，其中n为输入规模，g(n)为算法所需存储空间。
3. **排序算法**：常见的排序算法包括冒泡排序、选择排序、插入排序、快速排序、归并排序等。排序算法的目的是将一组数据按照特定规则排序，如升序或降序。
4. **查找算法**：常见的查找算法包括二分查找、线性查找、哈希查找等。查找算法的目的是在数据结构中查找特定元素。

##### 3.1.1 数组与链表

**题目1：实现一个有序链表**

**解题思路：** 
首先定义链表节点类，然后实现插入节点和删除节点的功能。插入节点时，需要根据链表是否为空、插入位置是否在头部、尾部或中间情况分别处理。删除节点时，需要找到待删除节点的前驱节点，将前驱节点的next指针指向待删除节点的下一个节点。

**伪代码：**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

public class SortedLinkedList {
    ListNode head;

    public void insert(int val) {
        ListNode newNode = new ListNode(val);
        if (head == null || val <= head.val) {
            newNode.next = head;
            head = newNode;
        } else {
            ListNode current = head;
            while (current.next != null && current.next.val < val) {
                current = current.next;
            }
            newNode.next = current.next;
            current.next = newNode;
        }
    }

    public void delete(int val) {
        if (head == null) return;
        if (head.val == val) {
            head = head.next;
            return;
        }
        ListNode current = head;
        while (current.next != null) {
            if (current.next.val == val) {
                current.next = current.next.next;
                return;
            }
            current = current.next;
        }
    }
}
```

**题目2：实现一个无序链表**

**解题思路：** 
与有序链表类似，但无需考虑插入和删除节点的顺序。

**伪代码：**
```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

public class UnsortedLinkedList {
    ListNode head;

    public void insert(int val) {
        ListNode newNode = new ListNode(val);
        newNode.next = head;
        head = newNode;
    }

    public void delete(int val) {
        if (head == null) return;
        if (head.val == val) {
            head = head.next;
            return;
        }
        ListNode current = head;
        ListNode prev = null;
        while (current != null) {
            if (current.val == val) {
                prev.next = current.next;
                return;
            }
            prev = current;
            current = current.next;
        }
    }
}
```

##### 3.1.2 栈与队列

**题目3：实现一个栈**

**解题思路：** 
可以使用数组或链表实现栈，主要操作包括入栈（push）、出栈（pop）和获取栈顶元素（peek）。

**伪代码：**
```java
public class Stack {
    private ListNode top;
    private int size;

    public void push(int val) {
        ListNode newNode = new ListNode(val);
        newNode.next = top;
        top = newNode;
        size++;
    }

    public int pop() {
        if (top == null) return -1;
        int val = top.val;
        top = top.next;
        size--;
        return val;
    }

    public int peek() {
        if (top == null) return -1;
        return top.val;
    }
}
```

**题目4：实现一个队列**

**解题思路：** 
可以使用两个栈实现队列，一个用于入队，一个用于出队。入队操作在入队栈中进行，出队操作在出队栈中进行，当出队栈为空时，将入队栈中的元素依次弹出并压入出队栈。

**伪代码：**
```java
public class Queue {
    private Stack inStack;
    private Stack outStack;

    public Queue() {
        inStack = new Stack();
        outStack = new Stack();
    }

    public void enqueue(int val) {
        inStack.push(val);
    }

    public int dequeue() {
        if (outStack.isEmpty()) {
            while (!inStack.isEmpty()) {
                outStack.push(inStack.pop());
            }
        }
        if (outStack.isEmpty()) return -1;
        return outStack.pop();
    }
}
```

##### 3.1.3 树与二叉树

**题目5：二叉树的遍历**

**解题思路：**

```java
// 递归实现
void preorderTraversal(TreeNode root) {

// 迭代实现（使用栈）
void preorderTraversalIterative(TreeNode root) {
    if (root == null) return;
    Stack<TreeNode> stack = new Stack<>();
    stack.push(root);
    while (!stack.isEmpty()) {
```

**题目6：平衡二叉树**

**解题思路：** 
平衡二叉树（AVL树）是一种自平衡的二叉搜索树，每个节点的左右子树高度差不超过1。可以通过递归计算每个节点的平衡因子来实现。

**伪代码：**
```java
int getHeight(TreeNode node) {
    if (node == null) return 0;
    int leftHeight = getHeight(node.left);
    int rightHeight = getHeight(node.right);
    return Math.max(leftHeight, rightHeight) + 1;
}

int getBalanceFactor(TreeNode node) {
    if (node == null) return 0;
    return getHeight(node.left) - getHeight(node.right);
}

TreeNode rotateLeft(TreeNode node) {
    TreeNode newRoot = node.right;
    node.right = newRoot.left;
    newRoot.left = node;
    return newRoot;
}

TreeNode rotateRight(TreeNode node) {
    TreeNode newRoot = node.left;
    node.left = newRoot.right;
    newRoot.right = node;
    return newRoot;
}

TreeNode insertIntoBST(TreeNode root, int val) {
    if (root == null) return new TreeNode(val);
    if (val < root.val) {
        root.left = insertIntoBST(root.left, val);
    } else {
        root.right = insertIntoBST(root.right, val);
    }
    int balanceFactor = getBalanceFactor(root);
    if (balanceFactor > 1) {
        if (val < root.left.val) {
            return rotateRight(root);
        } else {
            root.left = rotateLeft(root.left);
            return rotateRight(root);
        }
    }
    if (balanceFactor < -1) {
        if (val > root.right.val) {
            return rotateLeft(root);
        } else {
            root.right = rotateRight(root.right);
            return rotateLeft(root);
        }
    }
    return root;
}
```

#### 3.2 算法设计与分析

##### 3.2.1 排序算法

**题目7：冒泡排序**

**解题思路：** 
冒泡排序是一种简单的排序算法，通过多次遍历待排序的数组，比较相邻的两个元素并交换，直到整个数组有序。

**伪代码：**
```java
void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

**题目8：快速排序**

**解题思路：** 
快速排序是一种高效的排序算法，通过选取一个基准元素，将数组划分为两部分，一部分小于基准元素，一部分大于基准元素，然后递归地对这两部分进行快速排序。

**伪代码：**
```java
int partition(int[] arr, int low, int high) {
    int pivot = arr[high];
    int i = (low - 1);
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }
    int temp = arr[i + 1];
    arr[i + 1] = arr[high];
    arr[high] = temp;
    return i + 1;
}

void quickSort(int[] arr, int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}
```

##### 3.2.2 查找算法

**题目9：二分查找**

**解题思路：** 
二分查找是一种高效的查找算法，适用于有序数组。通过递归或迭代的方式，不断将查找范围缩小一半，直到找到目标元素或确定元素不存在。

**伪代码：**
```java
int binarySearch(int[] arr, int low, int high, int target) {
    if (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] < target) {
            return binarySearch(arr, mid + 1, high, target);
        } else {
            return binarySearch(arr, low, mid - 1, target);
        }
    }
    return -1;
}
```

**题目12：图的广度优先搜索**

**解题思路：**

**伪代码：**

```java
void bfs(TreeNode root) {

    queue.offer(root);
    while (!queue.isEmpty()) {

        System.out.print(node.val + " ");
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}
```

**伪代码：**
```

}

void sjf(Process[] processes) {
    Arrays.sort(processes, Comparator.comparingInt(p -> p.cpuBurst));
    for (Process p : processes) {
        execute(p);
    }
}

// 优先级调度
void priorityScheduling(Process[] processes) {
    PriorityQueue<Process> queue = new PriorityQueue<>(Comparator.comparingInt(p -> -p.priority));
    for (Process p : processes) {
        queue.offer(p);

    while (!queue.isEmpty()) {
        execute(queue.poll());
    }
}
```

##### 4.1.2 内存管理

**题目15：内存分配策略**

**解题思路：**

**伪代码：**
```
// 首次适配（FCFS）
void firstFit(List<Process> processes, List<MemoryPartition> partitions) {
    for (Process p : processes) {
        for (MemoryPartition partition : partitions) {
            if (partition.size >= p.requiredMemory) {
                allocateMemory(p, partition);
                break;
            }
        }
    }
}

// 最佳适配（BA）
void bestFit(List<Process> processes, List<MemoryPartition> partitions) {
    for (Process p : processes) {
        MemoryPartition bestPartition = null;
        for (MemoryPartition partition : partitions) {
            if (partition.size >= p.requiredMemory && (bestPartition == null || partition.size < bestPartition.size)) {
                bestPartition = partition;
            }
        }
        if (bestPartition != null) {
            allocateMemory(p, bestPartition);
        }
    }
}
```
