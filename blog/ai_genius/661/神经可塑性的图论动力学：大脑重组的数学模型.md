\[ w_{AB}(t+1) = w_{AB}(t) + \alpha \cdot x(t) \cdot y(t) \]

其中，\(\alpha\)为学习率，用于调整权重更新的幅度。

**推导2：概率分布更新公式的推导**

假设两个神经元A和B之间的连接概率为\(P_{AB}(t)\)。在时间t时，如果神经元A和B同时激活，则连接概率会增加；如果只有一个激活，则连接概率会减少。根据这个假设，我们可以推导出概率分布的更新公式：

\[ P_{AB}(t+1) = P_{AB}(t) + \beta \cdot (1 - P_{AB}(t)) \]

其中，\(\beta\)为更新率，用于调整概率分布的更新幅度。

```python
import numpy as np
import networkx as nx
import matplotlib.pyplot as plt

# 初始化神经网络
def initialize_network(num_nodes):
    G = nx.Graph()
    for i in range(num_nodes):
        G.add_node(i)
    return G

# 更新权重
def update_weights(G, alpha):
    for edge in G.edges():
        x = G.nodes[edge[0]]['activation']
        y = G.nodes[edge[1]]['activation']
        G[edge[0], edge[1]]['weight'] += alpha * x * y

# 更新激活状态
def update_activation(G):
    for node in G.nodes():
        G.nodes[node]['activation'] = np.random.choice([0, 1], p=[0.5, 0.5])

# 主函数
def main():
    num_nodes = 5
    alpha = 0.1
    G = initialize_network(num_nodes)
    
    for _ in range(10):
        update_activation(G)
        update_weights(G, alpha)
    
    # 绘制网络
    pos = nx.spring_layout(G)
    nx.draw(G, pos, with_labels=True)
    plt.show()

if __name__ == "__main__":
    main()
```
