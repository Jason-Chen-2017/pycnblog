```java
// Service层代码示例
public class UserService {
    private UserDao userDao;
    
    public UserService(UserDao userDao) {
        this.userDao = userDao;
    }
    
    public User getUserById(Integer id) {
        return userDao.getUserById(id);
    }
    
    public List<User> getAllUsers() {
        return userDao.getAllUsers();
    }
    
    public int addUser(User user) {
        return userDao.addUser(user);
    }
    
    public int deleteUserById(Integer id) {
        return userDao.deleteUserById(id);
    }
}
```

这段代码实现了`UserService`类，它依赖于`UserDao`接口，实现了用户管理的基本功能。通过这个类，Controller层可以方便地调用这些方法，处理HTTP请求。

```java
// Controller层代码示例
@Controller
public class UserController {
    private UserService userService;
    
    @GetMapping("/users")
    public List<User> getAllUsers(Model model) {
        return userService.getAllUsers();
    }
    
    @PostMapping("/users")
    public String addUser(@RequestBody User user, Model model) {
        int result = userService.addUser(user);
        if (result > 0) {
            model.addAttribute("message", "User added successfully!");
        } else {
            model.addAttribute("message", "Failed to add user!");
        }
        return "users";
    }
    
    @DeleteMapping("/users/{id}")
    public String deleteUser(@PathVariable Integer id, Model model) {
        int result = userService.deleteUserById(id);
        if (result > 0) {
            model.addAttribute("message", "User deleted successfully!");
        } else {
            model.addAttribute("message", "Failed to delete user!");
        }
        return "users";
    }
}
```

这段代码实现了`UserController`类，它依赖于`UserService`类，处理了HTTP请求，并实现了用户管理的接口。
