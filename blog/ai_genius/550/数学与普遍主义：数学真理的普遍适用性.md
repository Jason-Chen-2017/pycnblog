## 第二部分：数学基础

### 2.1 数的概念与性质

#### 2.1.1 自然数的定义与性质

自然数是从1开始的正整数，用来表示物体的数量。自然数的定义如下：

1. 1是最小的自然数。
2. 对于任意一个自然数n，其后续数是n+1。
3. 自然数是无限的。

自然数的性质包括：

1. **传递性**：如果a ≤ b且b ≤ c，则a ≤ c。
2. **可加性**：对于任意自然数a和b，a + b是自然数。
3. **乘法**：对于任意自然数a和b，a × b是自然数。

#### 2.1.2 整数的概念与运算

整数是自然数、0和负整数的集合。整数的定义如下：

1. 整数集合Z = {..., -3, -2, -1, 0, 1, 2, 3, ...}。
2. 对于任意整数a和b，a + b也是整数。

整数的运算包括加法、减法、乘法和除法。加法和减法遵循交换律、结合律和分配律等基本运算规律。乘法满足交换律、结合律和分配律。除法运算需要注意除数为0的情况。

#### 2.1.3 有理数的概念与运算

有理数是可以表示为两个整数之比的数，包括整数和分数。有理数的定义如下：

1. 有理数集合Q = {..., -2/3, -1/2, 0, 1/2, 2/3, 1, 2, 3, ...}。
2. 对于任意有理数a/b和c/d，其和为(a*c + b*d)/(b*d)，差为(a*c - b*d)/(b*d)，乘积为(a/b) × (c/d) = (a*c)/(b*d)，商为(a/b) ÷ (c/d) = (a*d)/(b*c)，其中b、d不等于0。

有理数的运算也遵循交换律、结合律和分配律等基本运算规律。

#### 2.1.4 无理数的概念与性质

无理数是不能表示为两个整数之比的数，如π（圆周率）和e（自然对数的底）。无理数的定义如下：

1. 对于任意实数x，如果存在一个整数n，使得x^n为有理数，则x为无理数。
2. 无理数具有无限不循环的小数表示。

无理数的性质包括：

1. **非零性**：无理数不等于0。
2. **不可约性**：无理数不能被约分为整数之比。
3. **发散性**：无理数的平方根具有无限不循环的小数表示。

### 2.2 函数与集合

#### 2.2.1 函数的定义与性质

函数是一种特殊的映射，将一个集合中的元素映射到另一个集合中的元素。函数的定义如下：

1. 设A和B为两个集合，如果存在一个规则f，使得对于A中的每个元素x，都存在B中的一个唯一元素y与之对应，则称f为从A到B的函数。
2. 函数通常表示为f: A → B，其中f(x)表示x在函数f下的像。

函数的性质包括：

1. **单射**：如果对于任意的x1、x2 ∈ A，当f(x1) = f(x2)时，必有x1 = x2，则称函数f为单射。
2. **满射**：如果对于任意的y ∈ B，都存在至少一个x ∈ A，使得f(x) = y，则称函数f为满射。
3. **双射**：如果函数f既是单射又是满射，则称函数f为双射。

#### 2.2.2 集合的概念与运算

集合是由元素组成的无序集合。集合的定义如下：

1. 集合通常用大写字母表示，如A、B等。
2. 集合中的元素用逗号分隔，如{1, 2, 3}。

集合的运算包括并集、交集、补集和差集。

- **并集**：A ∪ B表示由A和B中的所有元素组成的集合。
- **交集**：A ∩ B表示由A和B中共同元素组成的集合。
- **补集**：A'表示由不属于A的所有元素组成的集合。
- **差集**：A - B表示由A中的元素去掉B中的元素后组成的集合。

#### 2.2.3 集合的表示方法

集合的表示方法包括列举法、描述法和图示法。

- **列举法**：将集合中的所有元素一一列出，如{1, 2, 3, 4, 5}。
- **描述法**：用数学表达式描述集合的元素，如{1, 2, ..., n}表示由1到n的所有自然数组成的集合。
- **图示法**：用图形表示集合，如Venn图表示集合的交集、并集等。

### 2.3 数学原理与方法

#### 2.3.1 直观逻辑原理

直观逻辑原理是指通过直观推理和观察来发现数学规律。直观逻辑原理包括归纳推理和类比推理。

- **归纳推理**：从特殊情况推断出一般情况的推理方法。例如，通过观察几个自然数的性质，推断出所有自然数都满足某一性质。
- **类比推理**：通过比较两个相似情况，推断出它们具有相似性质的推理方法。例如，比较整数和有理数的性质，推断出无理数的一些性质。

#### 2.3.2 归纳推理原理

归纳推理原理是一种基于部分实例推断出一般规律的推理方法。归纳推理分为完全归纳和不完全归纳。

- **完全归纳**：通过对所有可能情况进行分析，得出一般性结论。例如，通过分析所有正整数，证明所有正整数都是无理数的平方根。
- **不完全归纳**：通过对部分实例进行分析，得出一般性结论。例如，通过观察几个自然数的性质，推断出所有自然数都满足某一性质。

#### 2.3.3 数学证明原理

数学证明是一种通过逻辑推理证明数学命题成立的方法。数学证明的基本步骤包括：

1. **假设**：假设某个命题成立。
2. **推理**：通过逻辑推理，从假设得出一系列结论。
3. **结论**：证明假设成立，从而证明原命题成立。

数学证明的方法包括直接证明、反证法和数学归纳法。

- **直接证明**：通过正向推理证明命题成立。
- **反证法**：通过反向推理证明命题不成立，从而证明原命题成立。
- **数学归纳法**：通过归纳推理证明命题对于所有正整数成立。
