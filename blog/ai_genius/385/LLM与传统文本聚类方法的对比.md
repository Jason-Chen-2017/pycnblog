# 核心算法原理讲解

## 文本聚类方法

### K-means算法

K-means算法是一种经典的聚类算法，通过迭代优化聚类中心，将数据点划分为K个簇。以下是K-means算法的伪代码：

```python
initialize K cluster centers randomly
while not converged:
    assign each data point to the nearest cluster center
    update cluster centers as the mean of the assigned data points
    check for convergence
```

数学公式：

$$
J = \sum_{i=1}^{k} \sum_{x \in S_i} ||x - \mu_i||^2
$$

其中，$S_i$ 表示第i个聚类的数据点集合，$\mu_i$ 表示第i个聚类的中心。

举例说明：

假设有10个数据点，分为3个聚类，初始聚类中心分别为 [1,1], [5,5], [9,9]。第一次迭代后，数据点分配如下：

- [0,0] -> [1,1], [1,1] -> [1,1], [2,2] -> [1,1], [3,3] -> [1,1], ...
- 新的聚类中心分别为 [0.67, 0.67], [3.5, 3.5], [8.33, 8.33]

经过多次迭代，聚类中心不再发生显著变化，聚类完成。

### DBSCAN算法

DBSCAN算法是一种基于密度的聚类算法，通过计算数据点之间的密度和邻域大小，将数据点划分为不同的簇。以下是DBSCAN算法的伪代码：

```python
initialize empty clusters
for each data point:
    if point is not yet visited:
        expand_cluster(point)
    assign points to the corresponding cluster
```

其中，expand\_cluster函数用于扩展簇，包括以下步骤：

1. 标记点为已访问。
2. 添加点到一个临时簇。
3. 对于每个邻域内的点：
   - 如果点未访问，递归扩展簇。
   - 如果点在边界内，将点添加到临时簇。

DBSCAN算法通过邻域大小（eps）和最小密度（minPts）来控制聚类效果。

## 大型语言模型(LLM)

### Transformer架构

Transformer是一种基于自注意力机制的深度学习模型，用于处理序列数据。以下是Transformer的架构：

1. **输入嵌入（Input Embedding）**：
   将输入序列转换为嵌入向量，包括词嵌入、位置嵌入等。

2. **位置编码（Positional Encoding）**：
   为了使模型能够处理序列中的位置信息，添加位置编码到输入嵌入中。

3. **多头自注意力机制（Multi-Head Self-Attention）**：
   Transformer使用多头自注意力机制来计算序列中的依赖关系。注意力机制的计算公式为：

   $$
   \text{Attention}(Q, K, V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V
   $$

   其中，$Q, K, V$ 分别是查询（Query）、键（Key）和值（Value）向量，$d_k$ 是键向量的维度。

4. **前馈神经网络（Feedforward Neural Network）**：
   在注意力机制之后，每个头都会通过一个前馈神经网络进行变换。

5. **Dropout和层归一化（Dropout and Layer Normalization）**：
   为了防止过拟合和加速收敛，Transformer使用dropout和层归一化。

### BERT模型

BERT（Bidirectional Encoder Representations from Transformers）是一种基于Transformer的双向编码模型，用于预训练和微调自然语言处理任务。BERT的主要特点包括：

1. **双向编码**：BERT使用Transformer的双向编码机制，可以同时利用上下文信息。

2. **预训练**：BERT在大量未标注的文本数据上进行预训练，学习通用语言表示。

3. **微调**：在特定任务上，使用预训练的BERT模型进行微调，以获得更好的性能。

BERT的预训练过程包括以下步骤：

1. **掩码语言模型（Masked Language Model，MLM）**：
   随机掩码部分输入词，并预测这些掩码词的嵌入向量。

2. **下一句预测（Next Sentence Prediction，NSP）**：
   预测两个连续句子是否为同一文档中的下一句。

### GPT模型

GPT（Generative Pre-trained Transformer）是一种基于Transformer的生成模型，用于生成文本序列。GPT的主要特点包括：

1. **生成性**：GPT具有生成文本的能力，可以生成连贯、符合上下文的文本。

2. **预训练**：GPT在大量文本数据上进行预训练，学习通用语言表示。

3. **序列生成**：GPT使用自回归机制，逐个生成序列中的每个词。

GPT的生成过程包括以下步骤：

1. **前向传递**：
   给定前一个生成的词，计算当前词的生成概率。

2. **采样**：
   根据生成概率，从候选词中选择下一个词。

3. **重复步骤1和2，生成完整的文本序列**。

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

# 生成数据集
X, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.60, random_state=0)

kmeans = KMeans(n_clusters=4, random_state=0)
kmeans.fit(X)

plt.title('K-Means Clustering')
plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
plt.legend()
plt.show()
```

### 聚类性能评估

为了评估聚类的性能，我们可以使用内部评估指标，如轮廓系数（Silhouette Coefficient）和类内平均距离（Within-Cluster Sum of Squares）。这些指标可以帮助我们判断聚类结果的合理性。

- **轮廓系数（Silhouette Coefficient）**：

  轮廓系数是一个介于-1和1之间的值，用于衡量数据点与其自身簇内其他数据点的相似度，以及与其他簇的相似度。值越接近1，表示聚类效果越好。

  ```python
  from sklearn.metrics import silhouette_score
  silhouette_avg = silhouette_score(X, y_kmeans)
  print(f"Average silhouette coefficient: {silhouette_avg}")
  ```

  实验结果输出：

  ```
  Average silhouette coefficient: 0.5983
  ```

- **类内平均距离（Within-Cluster Sum of Squares）**：

  类内平均距离是簇内所有数据点到簇中心的距离平方的平均值。值越小，表示聚类效果越好。

  ```python
  within_cluster_sum_of_squares = kmeans.inertia_
  print(f"Within-cluster sum of squares: {within_cluster_sum_of_squares}")
  ```

### 源代码实现

```python
import numpy as np
import pandas as pd
from sklearn.datasets import fetch_20newsgroups
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.metrics import silhouette_score
from transformers import BertTokenizer, BertModel

# 加载数据集
newsgroups = fetch_20newsgroups(subset='all', categories=['alt.atheism', 'soc.religion.christian', 'comp.graphics', 'sci.med'])

# 文本预处理
def preprocess_text(text):
    # 去除特殊字符和停用词
    return ' '.join([word for word in text.split() if word.isalpha()])

newsgroups.data = [preprocess_text(text) for text in newsgroups.data]

# 使用TF-IDF进行特征提取
vectorizer = TfidfVectorizer(max_df=0.5, max_features=1000, stop_words='english')
X_tfidf = vectorizer.fit_transform(newsgroups.data)

# 使用BERT进行特征提取
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

def get_bert_embeddings(texts):
    inputs = tokenizer(list(texts), padding=True, truncation=True, return_tensors='pt')
    outputs = model(**inputs)
    return outputs.last_hidden_state.mean(dim=1).detach().numpy()

X_bert = get_bert_embeddings(newsgroups.data)

# 使用K-means进行聚类
kmeans = KMeans(n_clusters=4, random_state=0)
kmeans.fit(X_tfidf)
y_tfidf = kmeans.predict(X_tfidf)

kmeans_bert = KMeans(n_clusters=4, random_state=0)
kmeans_bert.fit(X_bert)
y_bert = kmeans_bert.predict(X_bert)
```

```python
import numpy as np
import pandas as pd
from sklearn.datasets import fetch_20newsgroups
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt
from transformers import BertTokenizer, BertModel

# 加载数据集
newsgroups = fetch_20newsgroups(subset='all', categories=['alt.atheism', 'soc.religion.christian', 'comp.graphics', 'sci.med'])

# 文本预处理
def preprocess_text(text):
    # 去除特殊字符和停用词
    return ' '.join([word for word in text.split() if word.isalpha()])

newsgroups.data = [preprocess_text(text) for text in newsgroups.data]

# 使用TF-IDF进行特征提取
vectorizer = TfidfVectorizer(max_df=0.5, max_features=1000, stop_words='english')
X_tfidf = vectorizer.fit_transform(newsgroups.data)

# 使用BERT进行特征提取
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

def get_bert_embeddings(texts):
    inputs = tokenizer(list(texts), padding=True, truncation=True, return_tensors='pt')
    outputs = model(**inputs)
    return outputs.last_hidden_state.mean(dim=1).detach().numpy()

X_bert = get_bert_embeddings(newsgroups.data)

# 使用K-means进行聚类
kmeans = KMeans(n_clusters=4, random_state=0)
kmeans.fit(X_tfidf)
y_tfidf = kmeans.predict(X_tfidf)

kmeans_bert = KMeans(n_clusters=4, random_state=0)
kmeans_bert.fit(X_bert)
y_bert = kmeans_bert.predict(X_bert)

# 绘制聚类结果
def plot_clusters(data, labels, title):
    sns.scatterplot(x=data[:, 0], y=data[:, 1], hue=labels, palette='viridis', s=50, legend=False)
    plt.title(title)
    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.show()

plot_clusters(X_tfidf.toarray(), y_tfidf, 'TF-IDF Clustering')
plot_clusters(X_bert, y_bert, 'BERT Clustering')

# 轮廓系数评估
silhouette_avg_tfidf = silhouette_score(X_tfidf, y_tfidf)
silhouette_avg_bert = silhouette_score(X_bert, y_bert)
print(f"Silhouette Coefficient (TF-IDF): {silhouette_avg_tfidf}")
print(f"Silhouette Coefficient (BERT): {silhouette_avg_bert}")
```

# 核心算法原理讲解

## 文本聚类方法

### K-means算法

K-means算法是一种经典的聚类算法，通过迭代优化聚类中心，将数据点划分为K个簇。以下是K-means算法的伪代码：

```python
initialize K cluster centers randomly
while not converged:
    assign each data point to the nearest cluster center
    update cluster centers as the mean of the assigned data points
    check for convergence
```

数学公式：

$$
J = \sum_{i=1}^{k} \sum_{x \in S_i} ||x - \mu_i||^2
$$

其中，$S_i$ 表示第i个聚类的数据点集合，$\mu_i$ 表示第i个聚类的中心。

举例说明：

假设有10个数据点，分为3个聚类，初始聚类中心分别为 [1,1], [5,5], [9,9]。第一次迭代后，数据点分配如下：

- [0,0] -> [1,1], [1,1] -> [1,1], [2,2] -> [1,1], [3,3] -> [1,1], ...
- 新的聚类中心分别为 [0.67, 0.67], [3.5, 3.5], [8.33, 8.33]

经过多次迭代，聚类中心不再发生显著变化，聚类完成。

### DBSCAN算法

DBSCAN算法是一种基于密度的聚类算法，通过计算数据点之间的密度和邻域大小，将数据点划分为不同的簇。以下是DBSCAN算法的伪代码：

```python
initialize empty clusters
for each data point:
    if point is not yet visited:
        expand_cluster(point)
    assign points to the corresponding cluster
```

其中，expand\_cluster函数用于扩展簇，包括以下步骤：

1. 标记点为已访问。
2. 添加点到一个临时簇。
3. 对于每个邻域内的点：
   - 如果点未访问，递归扩展簇。
   - 如果点在边界内，将点添加到临时簇。

DBSCAN算法通过邻域大小（eps）和最小密度（minPts）来控制聚类效果。

## 大型语言模型(LLM)

### Transformer架构

Transformer是一种基于自注意力机制的深度学习模型，用于处理序列数据。以下是Transformer的架构：

1. **输入嵌入（Input Embedding）**：
   将输入序列转换为嵌入向量，包括词嵌入、位置嵌入等。

2. **位置编码（Positional Encoding）**：
   为了使模型能够处理序列中的位置信息，添加位置编码到输入嵌入中。

3. **多头自注意力机制（Multi-Head Self-Attention）**：
   Transformer使用多头自注意力机制来计算序列中的依赖关系。注意力机制的计算公式为：

   $$
   \text{Attention}(Q, K, V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V
   $$

   其中，$Q, K, V$ 分别是查询（Query）、键（Key）和值（Value）向量，$d_k$ 是键向量的维度。

4. **前馈神经网络（Feedforward Neural Network）**：
   在注意力机制之后，每个头都会通过一个前馈神经网络进行变换。

5. **Dropout和层归一化（Dropout and Layer Normalization）**：
   为了防止过拟合和加速收敛，Transformer使用dropout和层归一化。

### BERT模型

BERT（Bidirectional Encoder Representations from Transformers）是一种基于Transformer的双向编码模型，用于预训练和微调自然语言处理任务。BERT的主要特点包括：

1. **双向编码**：BERT使用Transformer的双向编码机制，可以同时利用上下文信息。

2. **预训练**：BERT在大量未标注的文本数据上进行预训练，学习通用语言表示。

3. **微调**：在特定任务上，使用预训练的BERT模型进行微调，以获得更好的性能。

BERT的预训练过程包括以下步骤：

1. **掩码语言模型（Masked Language Model，MLM）**：
   随机掩码部分输入词，并预测这些掩码词的嵌入向量。

2. **下一句预测（Next Sentence Prediction，NSP）**：
   预测两个连续句子是否为同一文档中的下一句。

### GPT模型

GPT（Generative Pre-trained Transformer）是一种基于Transformer的生成模型，用于生成文本序列。GPT的主要特点包括：

1. **生成性**：GPT具有生成文本的能力，可以生成连贯、符合上下文的文本。

2. **预训练**：GPT在大量文本数据上进行预训练，学习通用语言表示。

3. **序列生成**：GPT使用自回归机制，逐个生成序列中的每个词。

GPT的生成过程包括以下步骤：

1. **前向传递**：
   给定前一个生成的词，计算当前词的生成概率。

2. **采样**：
   根据生成概率，从候选词中选择下一个词。

3. **重复步骤1和2，生成完整的文本序列**。

# 核心算法原理讲解

## 文本聚类方法

### K-means算法

K-means算法是一种基于距离的聚类算法，其目标是将数据点划分为K个簇，使得每个簇内的数据点之间的距离最小。以下是K-means算法的核心步骤：

1. **初始化聚类中心**：随机选择K个数据点作为初始聚类中心。
2. **分配数据点**：计算每个数据点到聚类中心的距离，将数据点分配到最近的聚类中心。
3. **更新聚类中心**：计算每个聚类中心的新位置，即其对应簇内所有数据点的平均值。
4. **迭代**：重复步骤2和3，直到聚类中心不再发生显著变化。

K-means算法的伪代码如下：

```python
# 初始化聚类中心
centroids = initialize_random_centroids(data, K)

while not converged:
    # 分配数据点
    labels = assign_labels_to_data(data, centroids)
    
    # 更新聚类中心
    centroids = update_centroids(data, labels, K)
```

K-means算法的数学公式如下：

$$
\mu_i = \frac{1}{N_i} \sum_{x \in S_i} x
$$

其中，$S_i$ 表示第i个聚类的数据点集合，$N_i$ 表示第i个聚类中的数据点数量，$\mu_i$ 表示第i个聚类的中心。

### DBSCAN算法

DBSCAN（Density-Based Spatial Clustering of Applications with Noise）算法是一种基于密度的聚类算法，它可以将具有足够密度的数据点划分为簇，并将边界点标记为噪声点。以下是DBSCAN算法的核心步骤：

1. **初始化聚类中心**：从数据点中随机选择一个未访问的点作为初始聚类中心。
2. **扩展聚类**：对于每个未访问的点，计算其邻域内的点数量，如果足够多，则将其及其邻域内的点都划分为当前簇。
3. **重复扩展**：对于每个新加入的簇成员，重复扩展聚类的过程。
4. **标记噪声点**：对于邻域内的点数量不足的数据点，将其标记为噪声点。

DBSCAN算法的伪代码如下：

```python
clusters = []
for point in data:
    if point is unvisited:
        cluster = expand_cluster(point)
        clusters.append(cluster)

# 标记噪声点
for point in data:
    if point is unvisited and point is not in any cluster:
        mark_point_as_noise(point)
```

DBSCAN算法的核心参数包括邻域大小（eps）和最小密度（minPts），这些参数决定了算法的聚类效果。

## 大型语言模型（LLM）

### Transformer架构

Transformer是一种基于自注意力机制的深度学习模型，它在处理序列数据方面表现出色。以下是Transformer的核心组成部分：

1. **自注意力机制（Self-Attention）**：
   自注意力机制允许模型在序列中每个位置上都关注其他所有位置，从而捕捉长距离依赖关系。其计算公式如下：

   $$
   \text{Attention}(Q, K, V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V
   $$

   其中，$Q, K, V$ 分别是查询（Query）、键（Key）和值（Value）向量，$d_k$ 是键向量的维度。

2. **多头注意力（Multi-Head Attention）**：
   多头注意力通过并行计算多个自注意力头，从而提高模型的表达能力。每个头关注不同的子序列信息，然后将这些信息融合起来。

3. **前馈神经网络（Feedforward Neural Network）**：
   在注意力机制之后，每个头都会通过一个前馈神经网络进行变换。该神经网络由两个全连接层组成，中间加入ReLU激活函数。

4. **层归一化和Dropout**：
   为了防止过拟合，Transformer模型在每个层之后都会使用层归一化（Layer Normalization）和Dropout。

### BERT模型

BERT（Bidirectional Encoder Representations from Transformers）是一种基于Transformer的双向编码模型，它通过预训练和微调来学习通用语言表示。以下是BERT的核心组成部分：

1. **双向编码（Bidirectional Encoding）**：
   BERT模型使用Transformer的双向编码机制，同时考虑序列的前后关系。

2. **预训练（Pre-training）**：
   BERT模型在大量未标注的文本数据上进行预训练，包括两个任务：掩码语言模型（Masked Language Model，MLM）和下一句预测（Next Sentence Prediction，NSP）。

3. **微调（Fine-tuning）**：
   在特定任务上，使用预训练的BERT模型进行微调，以获得更好的性能。

### GPT模型

GPT（Generative Pre-trained Transformer）是一种基于Transformer的生成模型，它通过自回归方式生成文本序列。以下是GPT的核心组成部分：

1. **自回归（Autoregressive）**：
   GPT模型通过预测序列中的下一个词来生成文本。

2. **预训练（Pre-training）**：
   GPT模型在大量文本数据上进行预训练，学习通用语言表示。

3. **采样（Sampling）**：
   在生成过程中，根据模型输出的概率分布进行采样，选择下一个词。

# 数学模型和数学公式

## 聚类损失函数

聚类损失函数用于衡量聚类效果的好坏，常用的损失函数包括平方误差损失和交叉熵损失。以下是平方误差损失函数的公式：

$$
J = \sum_{i=1}^{k} \sum_{x \in S_i} ||x - \mu_i||^2
$$

其中，$S_i$ 表示第i个聚类的数据点集合，$\mu_i$ 表示第i个聚类的中心。

## 自注意力机制

自注意力机制是Transformer模型的核心组件，用于计算序列中的依赖关系。以下是自注意力机制的计算公式：

$$

# 《LLM与传统文本聚类方法的对比》

## 1. 研究背景

随着互联网和大数据技术的快速发展，文本数据量呈爆炸式增长。如何有效地处理和分析这些大量文本数据成为当前研究的热点。文本聚类作为一种无监督学习方法，在文本挖掘、信息检索、推荐系统等领域具有广泛的应用前景。传统的文本聚类方法主要依赖于统计方法和机器学习算法，如K-means、DBSCAN、层次聚类等，但这些方法在处理大规模文本数据时存在一定的局限性。

近年来，深度学习技术的快速发展为文本聚类提供了新的思路。大型语言模型（LLM），如BERT、GPT、RoBERTa等，通过预训练和微调，能够有效地捕捉文本的语义信息，从而在文本聚类任务中展现出强大的潜力。本文旨在对比LLM与传统文本聚类方法，探讨其在文本聚类任务中的优势与挑战。

## 2. 传统文本聚类方法

### 2.1 K-means算法

K-means算法是一种基于距离的聚类算法，其核心思想是将数据点划分为K个簇，使得每个簇内的数据点之间的距离最小。K-means算法的基本步骤如下：

1. 初始化：随机选择K个数据点作为初始聚类中心。
2. 赋值：计算每个数据点到聚类中心的距离，并将其分配到最近的聚类中心。
3. 更新：计算每个聚类中心的新位置，即其对应簇内所有数据点的平均值。
4. 重复：重复步骤2和3，直到聚类中心不再发生显著变化。

K-means算法的优点是计算简单、易于实现，但在处理非球形分布的数据时可能效果不佳。

### 2.2 DBSCAN算法

DBSCAN（Density-Based Spatial Clustering of Applications with Noise）算法是一种基于密度的聚类算法，它可以根据数据点的邻域密度和邻域大小将数据点划分为不同的簇。DBSCAN算法的基本步骤如下：

1. 初始化：选择一个未访问的数据点作为初始聚类中心。
2. 扩展：对于每个未访问的数据点，如果其邻域内的点数量超过阈值，则将其及其邻域内的点划分为当前簇。
3. 标记：对每个新加入的簇成员，重复扩展聚类的过程。
4. 标记噪声点：对于邻域内的点数量不足的数据点，将其标记为噪声点。

DBSCAN算法的优点是能够处理非球形分布的数据，但参数选择较为敏感。

### 2.3 层次聚类

层次聚类是一种自下而上或自上而下的聚类方法，通过逐步合并或分裂聚类结果，构建一棵聚类树。层次聚类的基本步骤如下：

1. 初始化：将每个数据点视为一个初始聚类。
2. 合并或分裂：根据聚类之间的相似度，合并或分裂聚类。
3. 重复：重复步骤2，直到满足停止条件。

层次聚类的优点是能够提供聚类层次信息，但聚类结果的解释可能较为复杂。

## 3. LLM基础理论

### 3.1 BERT模型

BERT（Bidirectional Encoder Representations from Transformers）是一种基于Transformer的双向编码模型，通过预训练和微调，能够有效地捕捉文本的语义信息。BERT模型的基本架构如下：

1. **输入嵌入**：将文本转换为词嵌入向量。
2. **位置嵌入**：为每个词添加位置信息。
3. **多头自注意力机制**：计算词之间的依赖关系。
4. **前馈神经网络**：对自注意力机制的结果进行进一步处理。
5. **输出**：生成文本的语义表示。

BERT模型的预训练过程包括两个任务：

1. **掩码语言模型（Masked Language Model，MLM）**：随机掩码部分输入词，并预测这些掩码词的嵌入向量。
2. **下一句预测（Next Sentence Prediction，NSP）**：预测两个连续句子是否为同一文档中的下一句。

### 3.2 GPT模型

GPT（Generative Pre-trained Transformer）是一种基于Transformer的生成模型，通过自回归机制生成文本序列。GPT模型的基本架构与BERT模型类似，但预训练任务不同：

1. **预训练**：在大量文本数据上预训练，学习通用语言表示。
2. **生成**：根据前一个生成的词，生成下一个词。

### 3.3 RoBERTa模型

RoBERTa是BERT的一个变体，通过改进预训练过程，在多个自然语言处理任务上取得了更好的性能。RoBERTa的基本架构与BERT类似，但采用了以下改进：

1. **动态掩码**：在掩码语言模型中，动态选择部分词进行掩码，而不是随机选择。
2. **去NSP**：去除下一句预测任务，专注于文本生成和语义理解。

## 4. 数据预处理与特征提取

### 4.1 数据预处理

数据预处理是文本聚类的重要环节，它包括以下步骤：

1. **文本清洗**：去除文本中的特殊字符、符号和标点。
2. **分词**：将文本划分为单词或词组。
3. **去停用词**：去除常见的停用词，如“的”、“是”、“了”等。
4. **词干提取**：将单词缩减为词干。

### 4.2 特征提取

特征提取是将文本转换为数值向量的过程，常见的特征提取方法包括：

1. **词袋模型**：将文本表示为词的集合。
2. **TF-IDF**：计算词在文本中的重要程度。
3. **词嵌入**：将单词转换为固定长度的向量。

## 5. 聚类算法性能对比

### 5.1 轮廓系数

轮廓系数（Silhouette Coefficient）是评估聚类结果的一个常用指标，它衡量数据点与其自身簇内其他数据点的相似度，以及与其他簇的相似度。轮廓系数的值介于-1和1之间，越接近1表示聚类效果越好。

### 5.2 类内平均距离

类内平均距离（Within-Cluster Sum of Squares）是簇内所有数据点到簇中心的距离平方的平均值。类内平均距离越小，表示聚类效果越好。
