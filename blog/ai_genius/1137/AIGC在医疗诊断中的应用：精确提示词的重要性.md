#### **2. 精确提示词的特征**

2. **全面性**：精确提示词不仅要描述当前的症状，还要涵盖相关的病史和并发症。
3. **上下文关联**：精确提示词需要考虑上下文关系，例如患者的性别、年龄、既往病史等。
4. **准确性**：精确提示词需要选择合适的词汇，确保模型能够准确理解病情。

在选择精确提示词时，需要考虑以下几个标准：

2. **多样性**：提示词需要丰富多样，涵盖不同类型的症状和疾病。
3. **一致性**：提示词需要确保数据的一致性和标准化，避免歧义和混淆。
4. **准确性**：提示词需要选择准确、含义清晰的词汇，避免使用模糊或误导性的词汇。

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Embedding, LSTM, Dense
from tensorflow.keras.optimizers import Adam

# 读取数据
data = pd.read_csv('medical_data.csv')
text = data['description']
labels = data['diagnosis']

# 数据预处理
text = text.apply(lambda x: x.lower().replace('.', '').replace(',', '').replace('?', ''))
vectorizer = TfidfVectorizer(max_features=1000)
X = vectorizer.fit_transform(text)

# 模型训练
model = Sequential()
model.add(Embedding(input_dim=1000, output_dim=64))
model.add(LSTM(units=64))
model.add(Dense(units=1, activation='sigmoid'))

model.compile(optimizer=Adam(learning_rate=0.001), loss='binary_crossentropy', metrics=['accuracy'])
model.fit(X, labels, epochs=10, batch_size=32)

# 诊断报告生成
def generate_diagnosis_report(plaintext):
    plaintext = plaintext.lower().replace('.', '').replace(',', '').replace('?', '')
    features = vectorizer.transform([plaintext])
    prediction = model.predict(features)
    diagnosis = 'Positive' if prediction[0][0] > 0.5 else 'Negative'
    return diagnosis

# 测试诊断报告生成
input_text = "Patient has a persistent cough and occasional chest pain."
diagnosis = generate_diagnosis_report(input_text)
print("Diagnosis:", diagnosis)
```
