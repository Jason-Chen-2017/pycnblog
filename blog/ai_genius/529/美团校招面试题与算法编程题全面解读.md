## 第二部分：算法编程题解析

### 第4章：基础数据结构与算法

#### 4.1 线性表

线性表是最基本的数据结构之一，包括数组、链表等。数组的特点是存储和访问快，但插入和删除操作相对较慢；链表则相反，插入和删除操作快，但存储和访问相对较慢。

#### 4.2 栈与队列

栈和队列都是重要的线性数据结构。栈遵循后进先出（LIFO）原则，适用于需要返回上次操作的场景，如递归函数调用；队列遵循先进先出（FIFO）原则，适用于需要按顺序处理的场景，如打印队列。

#### 4.3 链表

链表是一种由节点组成的线性结构，每个节点包含数据域和指针域。链表适用于插入和删除频繁的场景，如实现LRU缓存。

#### 4.4 树与图

树是一种重要的非线性数据结构，由节点和边组成。二叉树、红黑树等是常见的树结构，适用于需要快速查找的场景。图是一种由节点和边组成的复杂结构，适用于描述复杂的关系，如社交网络、地图等。

### 第5章：算法设计与分析

#### 5.1 排序算法

排序算法包括快速排序、归并排序、冒泡排序等。每种排序算法都有其特点和适用场景。快速排序是一种高效的排序算法，适用于大规模数据的排序；归并排序适用于多线程处理；冒泡排序适用于数据量较小的场景。

#### 5.2 搜索算法

搜索算法包括线性搜索、二分搜索等。线性搜索适用于数据量较小的场景，二分搜索适用于有序数据，具有更高的搜索效率。

#### 5.3 动态规划算法

动态规划算法是一种解决最优化问题的方法，通过将复杂问题分解为子问题，并存储子问题的解，避免重复计算。常见的动态规划问题有背包问题、最长公共子序列等。

#### 5.4 贪心算法

贪心算法是一种在每一步选择中都采取当前最优解的策略，适用于解决最优子结构问题。常见的贪心算法有活动选择问题、背包问题等。

### 第6章：高频面试算法题解析

#### 6.1 数组问题

数组问题是面试中的常见题型，包括找出数组中的重复元素、寻找两个有序数组的第k大元素等。解决数组问题通常需要利用数组的特点，如有序性、固定大小等。

#### 6.2 字符串问题

字符串问题包括最长公共子串、最长公共前缀等。解决字符串问题通常需要利用字符串的遍历和比较方法，如哈希表、双指针等。

#### 6.3 树相关问题

树相关问题包括二叉树的遍历、平衡二叉树等。解决树相关问题通常需要掌握递归、栈等数据结构，以及树的特点。

#### 6.4 图相关问题

图相关问题包括最短路径、最小生成树等。解决图相关问题通常需要利用图的遍历算法，如深度优先搜索、广度优先搜索等。

##### 4.1 线性表

线性表是一种常用的数据结构，包括数组、链表等。线性表的特点是数据元素按线性顺序排列，每个元素只有一个前驱和一个后继。

**数组**：

- 优点：存储和访问快，适用于固定大小的数据集合。
- 缺点：插入和删除操作相对较慢。

```java
// 数组初始化

// 数组访问
int element = arr[index];

// 数组插入

// 数组删除
int deletedElement = arr[index];
arr[index] = 0;
```

**链表**：

- 优点：插入和删除操作快，适用于动态大小的数据集合。
- 缺点：存储和访问相对较慢。

```java
// 链表节点定义

    ListNode next;
    ListNode(int x) { val = x; }
```

### 第5章：算法设计与分析

##### 5.1 排序算法

排序算法是一种将一组无序数据转换为有序数据的方法。常见的排序算法包括快速排序、归并排序、冒泡排序等。

**快速排序**：

- 原理：通过一趟排序将数据划分为独立的两部分，其中一部分的所有数据都比另一部分的所有数据要小，然后再按此方法对这两部分数据进行递归排序。
- 伪代码：

```java
void quicksort(int[] arr, int low, int high) {
    if (low < high) {
        int pivot = partition(arr, low, high);
        quicksort(arr, low, pivot - 1);
        quicksort(arr, pivot + 1, high);
    }
}

int partition(int[] arr, int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return i + 1;
}
```

**归并排序**：

- 原理：将待排序的序列不断分割成较小的子序列，再对子序列进行排序和合并。
- 伪代码：

```java
void mergeSort(int[] arr, int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        mergeSort(arr, low, mid);
        mergeSort(arr, mid + 1, high);
        merge(arr, low, mid, high);
    }
}

void merge(int[] arr, int low, int mid, int high) {
    int n1 = mid - low + 1;
    int n2 = high - mid;
    int[] left = new int[n1];
    int[] right = new int[n2];
    for (int i = 0; i < n1; i++) {
        left[i] = arr[low + i];
    }
    for (int j = 0; j < n2; j++) {
        right[j] = arr[mid + 1 + j];
    }
    int i = 0, j = 0, k = low;
    while (i < n1 && j < n2) {
        if (left[i] <= right[j]) {
            arr[k] = left[i];
            i++;
        } else {
            arr[k] = right[j];
            j++;
        }
        k++;
    }
    while (i < n1) {
        arr[k] = left[i];
        i++;
        k++;
    }
    while (j < n2) {
        arr[k] = right[j];
        j++;
        k++;
    }
}
```

**冒泡排序**：

- 原理：通过重复遍历要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来。
- 伪代码：

```java
void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
            }
        }
    }
}
```

##### 5.2 搜索算法

搜索算法是一种在数据结构中查找特定数据元素的方法。常见的搜索算法包括线性搜索、二分搜索等。

**线性搜索**：

- 原理：逐个遍历数据结构中的元素，直到找到目标元素或结束。
- 伪代码：

```java
int linearSearch(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i;
        }
    }
    return -1;
}
```

**二分搜索**：

- 原理：在有序数组中查找目标元素，通过不断缩小查找范围，每次将范围缩小一半。
- 伪代码：

```java
int binarySearch(int[] arr, int target) {
    int low = 0;
    int high = arr.length - 1;
    while (low <= high) {
        int mid = (low + high) / 2;
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] < target) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }
    return -1;
}
```

##### 5.3 动态规划算法

动态规划算法是一种解决最优化问题的方法，通过将复杂问题分解为子问题，并存储子问题的解，避免重复计算。

**斐波那契数列**：

- 原理：通过递归方式计算斐波那契数列，但递归方法存在大量重复计算。
- 伪代码：

```java
int fibonacci(int n) {
    if (n <= 1) {
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

**动态规划解法**：

- 原理：通过迭代方式计算斐波那契数列，并利用数组存储子问题的解。
- 伪代码：

```java
int fibonacci(int n) {
    if (n <= 1) {
        return n;
    }
    int[] dp = new int[n + 1];
    dp[0] = 0;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

##### 5.4 贪心算法

贪心算法是一种在每一步选择中都采取当前最优解的策略，适用于解决最优子结构问题。

**活动选择问题**：

- 原理：从多个活动中选择最优的活动，使总时间最大化。
- 伪代码：

```java
int activitySelection(int[] startTimes, int[] endTimes) {
    int n = startTimes.length;
    int[] durations = new int[n];
    for (int i = 0; i < n; i++) {
        durations[i] = endTimes[i] - startTimes[i];
    }
    Arrays.sort(durations);
    int maxDuration = 0;
    for (int i = 0; i < n; i++) {
        if (startTimes[i] >= maxDuration) {
            maxDuration = durations[i];
        }
    }
    return maxDuration;
}
```

##### 6.1 数组问题

数组问题是面试中的常见题型，包括找出数组中的重复元素、寻找两个有序数组的第k大元素等。

**找出数组中的重复元素**：

- 原理：利用哈希表或排序方法找出重复元素。
- 伪代码（哈希表方法）：

```java

    Set<Integer> set = new HashSet<>();
    for (int num : arr) {
        if (set.contains(num)) {
            System.out.println(num + " is a duplicate");
        } else {
            set.add(num);
        }
    }
}
```

**寻找两个有序数组的第k大元素**：

- 原理：利用快速选择算法在两个有序数组中找到第k大元素。
- 伪代码：

```java
int findKthLargest(int[] nums1, int[] nums2, int k) {
    int n1 = nums1.length;
    int n2 = nums2.length;
    int left = 0;
    int right = n1 + n2 - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (nums1[mid] > nums2[n2 - 1]) {
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return nums1[left - 1] > nums2[n2 - 1] ? nums1[left - 1] : nums2[n2 - left];
}
```

##### 6.2 字符串问题

字符串问题是面试中的另一类常见题型，包括最长公共子串、最长公共前缀等。

**最长公共子串**：

- 原理：利用动态规划方法计算最长公共子串。
- 伪代码：

```java
int longestCommonSubstring(String s1, String s2) {
    int[][] dp = new int[s1.length() + 1][s2.length() + 1];
    int maxLen = 0;
    for (int i = 1; i <= s1.length(); i++) {
        for (int j = 1; j <= s2.length(); j++) {
            if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
                maxLen = Math.max(maxLen, dp[i][j]);
            }
        }
    }
    return maxLen;
}
```

**最长公共前缀**：

- 原理：逐个比较字符串的前缀，直到找到不同的前缀。
- 伪代码：

```java
String longestCommonPrefix(String[] strings) {
    if (strings == null || strings.length == 0) {
        return "";
    }
    String prefix = strings[0];
    for (int i = 1; i < strings.length; i++) {
        while (strings[i].indexOf(prefix) != 0) {
            prefix = prefix.substring(0, prefix.length() - 1);
            if (prefix.isEmpty()) {
                return "";
            }
        }
    }
    return prefix;
}
```

```java
boolean isBalanced(TreeNode root) {
    if (root == null) {
        return true;
    }
    int leftHeight = getHeight(root.left);
    int rightHeight = getHeight(root.right);
```

##### 6.4 图相关问题

图相关问题包括最短路径、最小生成树等。

**最短路径**：

- 原理：利用迪杰斯特拉算法（Dijkstra）或贝尔曼-福特算法（Bellman-Ford）计算最短路径。
- 迪杰斯特拉算法：

```java
int[] dijkstra(int[][] graph, int start) {
    int n = graph.length;
    int[] dist = new int[n];
    boolean[] visited = new boolean[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    for (int i = 0; i < n; i++) {
        int minDist = Integer.MAX_VALUE;
        int minIndex = -1;
        for (int j = 0; j < n; j++) {
            if (!visited[j] && dist[j] < minDist) {
                minDist = dist[j];
                minIndex = j;
            }
        }
        visited[minIndex] = true;
        for (int j = 0; j < n; j++) {
            if (!visited[j]) {
                dist[j] = Math.min(dist[j], dist[minIndex] + graph[minIndex][j]);
            }
        }
    }
    return dist;
}
```

- 贝尔曼-福特算法：

```java
int bellmanFord(int[][] graph, int start) {
    int n = graph.length;
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n; j++) {
            for (int k = 0; k < n; k++) {
                if (graph[j][k] != 0 && dist[j] != Integer.MAX_VALUE && dist[j] + graph[j][k] < dist[k]) {
                    dist[k] = dist[j] + graph[j][k];
                }
            }
        }
    }
    for (int j = 0; j < n; j++) {
        for (int k = 0; k < n; k++) {
            if (graph[j][k] != 0 && dist[j] != Integer.MAX_VALUE && dist[j] + graph[j][k] < dist[k]) {
                return -1; // 存在负权重循环
            }
        }
    }
    return dist[n - 1];
}
```

**最小生成树**：

- 原理：利用克鲁斯卡尔算法（Kruskal）或普里姆算法（Prim）构建最小生成树。
- 克鲁斯卡尔算法：

```java
int kruskal(int[][] graph) {
    int n = graph.length;
    UnionFind uf = new UnionFind(n);
    int edges = 0;
    int cost = 0;
    Arrays.sort(graph, (a, b) -> a[2] - b[2]);
    for (int[] edge : graph) {
        int u = edge[0];
        int v = edge[1];
        int w = edge[2];
        if (uf.find(u) != uf.find(v)) {
            uf.union(u, v);
            cost += w;
            edges++;
            if (edges == n - 1) {
                break;
            }
        }
    }
    return cost;
}
```

- 普里姆算法：

```java
int prim(int[][] graph) {
    int n = graph.length;
    boolean[] visited = new boolean[n];
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[0] = 0;
    for (int i = 0; i < n; i++) {
        int minDist = Integer.MAX_VALUE;
        int minIndex = -1;
        for (int j = 0; j < n; j++) {
            if (!visited[j] && dist[j] < minDist) {
                minDist = dist[j];
                minIndex = j;
            }
        }
        visited[minIndex] = true;
        for (int j = 0; j < n; j++) {
            if (!visited[j] && graph[minIndex][j] != 0 && dist[j] > graph[minIndex][j]) {
                dist[j] = graph[minIndex][j];
            }
        }
    }
    int cost = 0;
    for (int i = 0; i < n; i++) {
        cost += dist[i];
    }
    return cost;
}
```

```java
String longestCommonPrefix(String[] words) {
    if (words == null || words.length == 0) {
        return "";
    }
    String prefix = words[0];
    for (int i = 1; i < words.length; i++) {
        while (words[i].indexOf(prefix) != 0) {
            prefix = prefix.substring(0, prefix.length() - 1);
            if (prefix.isEmpty()) {
                return "";
            }
        }
    }
    return prefix;
}
```

##### 7.2 算法竞赛案例分析

**问题1**：Google Code Jam 2018 年度竞赛题目——Minimum Scalar Product

**问题描述**：给定两个长度为n的整数数组A和B，求A和B的标量积的最小值。

**解题思路**：利用贪心算法，选择A和B中绝对值最小的两个数进行相乘，然后从数组中删除这两个数，继续选择下一个最小的数，直到数组为空。

```java
int minimumScalarProduct(int[] A, int[] B) {
    Arrays.sort(A);
    Arrays.sort(B);
    int n = A.length;
    int minProduct = Integer.MAX_VALUE;
    for (int i = 0; i < n; i++) {
        int product = A[i] * B[n - 1 - i];
        minProduct = Math.min(minProduct, product);
    }
    return minProduct;
}
```

**问题2**：Codeforces Round 727 题目——Watermelon

**问题描述**：给定一个整数数组，找出两个最大相邻元素之差的绝对值。

**解题思路**：遍历数组，找出最大值和第二最大值，计算它们之间的差值。

```java
int watermelon(int[] arr) {
    int max1 = Integer.MIN_VALUE;
    int max2 = Integer.MIN_VALUE;
    for (int num : arr) {
        if (num > max1) {
            max2 = max1;
            max1 = num;
        } else if (num > max2) {
            max2 = num;
        }
    }
    return Math.abs(max1 - max2);
}
```

```java
int fibonacci(int n) {
    if (n <= 1) {
        return n;
    }
    int[] dp = new int[n + 1];
    dp[0] = 0;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

```java
int activitySelection(int[] startTimes, int[] endTimes) {
    int n = startTimes.length;
    int[] durations = new int[n];
    for (int i = 0; i < n; i++) {
        durations[i] = endTimes[i] - startTimes[i];
    }
    Arrays.sort(durations);
    int maxDuration = 0;
    for (int i = 0; i < n; i++) {
        if (startTimes[i] >= maxDuration) {

        }
    }
```
