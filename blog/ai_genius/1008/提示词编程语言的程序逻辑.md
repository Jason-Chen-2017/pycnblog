#### 基础算法

基础算法是所有复杂算法的基础，包括常见的数学运算、数据结构操作和流程控制结构。以下是一些基础算法的例子：

1. **排序算法**

排序算法用于对数据进行排序，使其按照特定顺序排列。其中，冒泡排序和快速排序是最常见的两种排序算法。

**冒泡排序（Bubble Sort）**

冒泡排序通过重复遍历要排序的数列，比较相邻的两个元素，并交换它们的位置，直到整个序列按顺序排列。

伪代码描述如下：

```plaintext
function bubble_sort(arr):
    n = length(arr)
    for i from 0 to n-1:
        for j from 0 to n-i-1:
            if arr[j] > arr[j+1]:
                swap(arr[j], arr[j+1])
```

**快速排序（Quick Sort）**

快速排序是一种分治算法，通过选取一个基准元素，将序列划分为两部分，然后递归地对这两部分进行排序。

伪代码描述如下：

```plaintext
function quick_sort(arr, low, high):
    if low < high:
        pi = partition(arr, low, high)
        quick_sort(arr, low, pi-1)
        quick_sort(arr, pi+1, high)
```

2. **搜索算法**

搜索算法用于在数据集合中查找特定的元素。二分搜索算法是其中一种高效的方法，它通过不断将搜索范围缩小一半来查找元素。

**二分搜索（Binary Search）**

二分搜索的前提条件是数据集合已经排序。

伪代码描述如下：

```plaintext
function binary_search(arr, target):
    low = 0
    high = length(arr) - 1
    while low <= high:
        mid = (low + high) / 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

Dijkstra算法用于计算单源最短路径。

伪代码描述如下：

```plaintext
function dijkstra(graph, source):
    distances = [infinity] * length(graph)
    distances[source] = 0
    visited = []
    while length(visited) < length(graph):
        min_distance = infinity
        for vertex in graph:
            if vertex not in visited and distances[vertex] < min_distance:
                min_distance = distances[vertex]
                min_vertex = vertex
        visited.append(min_vertex)
        for neighbor in graph[vertex]:
            if distances[neighbor] > distances[vertex] + graph[vertex][neighbor]:
                distances[neighbor] = distances[vertex] + graph[vertex][neighbor]
    return distances
```

1. **线性回归模型**

线性回归模型是一种用于预测数值的数学模型，其公式如下：

$$y = \beta_0 + \beta_1 \cdot x + \epsilon$$

其中，`y` 是因变量，`x` 是自变量，`\beta_0` 和 `\beta_1` 是模型参数，`\epsilon` 是误差项。

**实例**

假设我们有一个数据集，其中 `x` 表示时间，`y` 表示温度。我们可以通过线性回归模型预测未来的温度。

数据集如下：

| 时间 (x) | 温度 (y) |
|----------|----------|
| 0        | 10       |
| 1        | 12       |
| 2        | 14       |
| 3        | 16       |

我们可以使用线性回归模型来预测第4个时间点的温度。

首先，我们需要计算模型参数 `\beta_0` 和 `\beta_1`：

$$\beta_0 = \frac{\sum y - \beta_1 \sum x}{n}$$
$$\beta_1 = \frac{n \sum xy - \sum x \sum y}{n \sum x^2 - (\sum x)^2}$$

代入数据计算：

$$\beta_0 = \frac{10 + 12 + 14 + 16 - (1 \times 10 + 1 \times 12 + 1 \times 14 + 1 \times 16)}{4} = 12$$
$$\beta_1 = \frac{4 \times (10 \times 1 + 12 \times 1 + 14 \times 1 + 16 \times 1) - (1 \times 10 + 1 \times 12 + 1 \times 14 + 1 \times 16)}{4 \times (1^2 + 1^2 + 1^2 + 1^2) - (1 + 1 + 1 + 1)^2} = 2$$

因此，线性回归模型为：

$$y = 12 + 2x$$

预测第4个时间点的温度：

$$y = 12 + 2 \times 4 = 20$$

2. **逻辑回归模型**

逻辑回归模型是一种用于分类问题的数学模型，其公式如下：

$$P(y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 \cdot x)}}$$

其中，`P(y=1)` 是目标变量为1的概率，`e` 是自然对数的底数，`\beta_0` 和 `\beta_1` 是模型参数，`x` 是特征。

**实例**

假设我们有一个二分类问题，其中 `x` 表示某种特征，`y` 表示目标变量。我们可以使用逻辑回归模型来预测目标变量的概率。

数据集如下：

| 特征 (x) | 目标变量 (y) |
|----------|--------------|
| 0        | 0            |
| 1        | 1            |
| 2        | 0            |
| 3        | 1            |

我们可以使用逻辑回归模型来预测第4个特征的目标变量。

首先，我们需要计算模型参数 `\beta_0` 和 `\beta_1`：

$$\beta_0 = \frac{\sum y - \beta_1 \sum x}{n}$$
$$\beta_1 = \frac{n \sum xy - \sum x \sum y}{n \sum x^2 - (\sum x)^2}$$

代入数据计算：

$$\beta_0 = \frac{0 + 1 + 0 + 1 - (0 \times 0 + 1 \times 1 + 0 \times 2 + 1 \times 3)}{4} = 1$$
$$\beta_1 = \frac{4 \times (0 \times 0 + 1 \times 1 + 0 \times 2 + 1 \times 3) - (0 + 1 + 0 + 1)}{4 \times (0^2 + 1^2 + 2^2 + 3^2) - (0 + 1 + 0 + 1)^2} = 1$$

因此，逻辑回归模型为：

$$P(y=1) = \frac{1}{1 + e^{-(1 + 1 \cdot x)}}$$

预测第4个特征的目标变量概率：

$$P(y=1) = \frac{1}{1 + e^{-(1 + 1 \cdot 4)}} = \frac{1}{1 + e^{-5}} \approx 0.9933$$

这意味着第4个特征的目标变量为1的概率约为99.33%。
