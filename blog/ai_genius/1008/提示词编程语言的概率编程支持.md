### 第2章 概率编程基础

#### 2.1 概率编程的概念

概率编程（Probabilistic Programming）是一种编程范式，它利用概率模型和概率分布来描述和解决问题。概率编程的核心思想是将问题的求解转化为概率计算，从而利用概率模型提供的灵活性来处理不确定性问题。

在概率编程中，开发者不是直接编写解决问题的算法，而是构建一个概率模型，然后利用模型提供的概率分布和概率规则来推断和解决问题。概率编程的模型通常包括随机变量、概率分布、条件概率和联合概率等基本概念。

#### 2.2 概率编程的基本原理

概率编程的基本原理主要包括以下几个方面：

1. **概率分布**：概率分布用于描述随机变量的概率特性。常见的概率分布包括正态分布、伯努利分布、泊松分布等。概率编程中，开发者可以通过定义不同的概率分布来模拟现实世界中的不确定性。
   
2. **随机变量**：随机变量是概率编程中的基本概念，它表示一个随机的结果或事件。在概率编程中，随机变量可以是连续的，也可以是离散的。

3. **条件概率**：条件概率描述了一个随机事件在另一个随机事件发生的条件下的概率。条件概率是概率编程中进行推理和决策的重要工具。

4. **联合概率**：联合概率描述了多个随机事件同时发生的概率。通过联合概率，开发者可以分析多个事件之间的相关性。

5. **贝叶斯推理**：贝叶斯推理是概率编程中的核心原理之一，它通过贝叶斯公式来更新和推断概率模型中的参数和变量。贝叶斯推理在概率编程中用于解决不确定性问题和参数估计问题。

```python
import numpy as np
from typing import List

# 定义概率分布函数
def probability_distribution(data: List[int]) -> List[float]:
    total = sum(data)
    return [float(value) / total for value in data]

# 假设数据为 [5, 3, 2, 7]
data = [5, 3, 2, 7]

# 计算每个值的概率分布
probabilities = probability_distribution(data)

# 打印概率分布
print(probabilities)
```
