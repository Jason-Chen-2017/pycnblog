```python
def linear_adjustment(spectrum, target_spectrum):
    # 计算目标光谱和当前光谱的差值
    delta_spectrum = target_spectrum - spectrum
    
    # 计算调节系数
    adjustment_coefficient = delta_spectrum / np.linalg.norm(delta_spectrum)
    
    # 应用线性调节
    adjusted_spectrum = spectrum + adjustment_coefficient
    
    return adjusted_spectrum
```
