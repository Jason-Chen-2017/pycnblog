```python
import requests
from bs4 import BeautifulSoup

def search_patents(search_terms):
    """
    检索专利信息
    :param search_terms: 检索关键词（列表）
    :return: 检索结果（列表）
    """
    base_url = "https://www.uspto.gov/patents-search-basics/search-USTPO"
    search_results = []
    
    for term in search_terms:
        # 构建检索URL
        url = f"{base_url}?q={term}"
        
        # 发送HTTP请求
        response = requests.get(url)
        
        # 解析HTML内容
        soup = BeautifulSoup(response.content, "html.parser")
        patents = soup.find_all("div", class_="uspto-patsearch-result")
        
        for patent in patents:
            # 提取专利信息
            patent_number = patent.find("div", class_="result-number").text.strip()
            patent_title = patent.find("div", class_="result-title").text.strip()
            
            # 添加到检索结果
            search_results.append({
                "Patent Number": patent_number,
                "Title": patent_title
            })
    
    return search_results

# 示例：检索智能家居和语音识别的专利信息
search_terms = ["smart home", "voice recognition"]
patent_results = search_patents(search_terms)

# 打印检索结果
for result in patent_results:
    print(f"Patent Number: {result['Patent Number']}")
    print(f"Title: {result['Title']}")
    print()
```

#### 数学模型和公式 & 详细讲解 & 举例说明

在专利布局策略制定中，可以使用数学模型来评估不同布局地点和技术的优先级。以下是一个简化的数学模型，用于评估布局地点的优先级：

$$
P_i = \frac{R_i \times C_i}{C}
$$`

其中：
- \(P_i\) 是第 \(i\) 个布局地点的优先级；
- \(R_i\) 是第 \(i\) 个布局地点的市场潜力；
- \(C_i\) 是第 \(i\) 个布局地点的成本；
