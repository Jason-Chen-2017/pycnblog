- **元素**：集合中的每个成员称为元素。我们通常用小写字母（如\(a\)、\(b\)）表示元素。
- **子集**：如果一个集合的所有元素都是另一个集合的元素，则前者是后者的子集。我们用\(A \subseteq B\)表示\(A\)是\(B\)的子集。
- **笛卡尔积**：两个集合的笛卡尔积是包含所有可能的有序对的集合。例如，集合\(A = \{1, 2\}\)和集合\(B = \{a, b\}\)的笛卡尔积是\(A \times B = \{(1, a), (1, b), (2, a), (2, b)\}\)。

### 6.2 公理集合论中的数学公式

公理集合论中的数学公式主要用于描述集合和集合之间的关系。以下是一些常用的数学公式：

- **集合的并集**：\(A \cup B\) 表示集合\(A\)和集合\(B\)的并集，即包含\(A\)和\(B\)中所有元素的集合。
- **集合的交集**：\(A \cap B\) 表示集合\(A\)和集合\(B\)的交集，即同时属于\(A\)和\(B\)的元素组成的集合。
- **集合的补集**：\(A^c\) 表示集合\(A\)的补集，即不属于\(A\)的元素组成的集合。

### 6.3 数学公式详细讲解与举例说明

#### 集合的并集

集合的并集公式表示为 \(A \cup B\)。它包含集合\(A\)和集合\(B\)中的所有元素，但不包含重复的元素。例如，如果 \(A = \{1, 2, 3\}\) 和 \(B = \{3, 4, 5\}\)，则 \(A \cup B = \{1, 2, 3, 4, 5\}\)。

#### 集合的交集

集合的交集公式表示为 \(A \cap B\)。它包含集合\(A\)和集合\(B\)中共有的元素。例如，如果 \(A = \{1, 2, 3\}\) 和 \(B = \{3, 4, 5\}\)，则 \(A \cap B = \{3\}\)。

#### 集合的补集

集合的补集公式表示为 \(A^c\)。它包含所有不属于集合\(A\)的元素。例如，如果 \(A = \{1, 2, 3\}\)，则 \(A^c = \{x \mid x \notin A\}\)，即所有非1、非2、非3的元素。
