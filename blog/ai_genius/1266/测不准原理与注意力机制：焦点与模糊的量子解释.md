#### 测不准原理

测不准原理是量子力学中一个基本且深刻的原理，揭示了在量子尺度上，某些物理量无法同时被精确测量。具体来说，由海森堡提出的测不准原理指出，粒子的位置和动量无法同时被精确知晓，两者的测量精度存在固有的限制。这一原理打破了经典物理学中关于确定性和精确性的传统观念，成为了量子力学的重要特征之一。

测不准原理的产生源于1927年，当时的量子力学正处于快速发展阶段。海森堡通过分析电子在原子中的行为，发现经典物理学中的观测工具和理论无法准确描述量子系统的状态。他提出了一种新的量子态描述方法——波函数，并通过数学公式（$$\Delta x \Delta p \geq \frac{h}{4\pi}$$）量化了位置和动量的测不准关系，其中$h$为普朗克常数。

#### 注意力机制

注意力机制是人类认知系统中的一个关键概念，描述了大脑如何选择关注某些信息而忽略其他信息。在日常生活中，我们的大脑会自动过滤掉大量无关的信息，将注意力集中在重要的、与当前任务相关的信息上。这一机制不仅存在于人类认知中，也在动物和机器学习模型中得到了广泛应用。

注意力机制的理论基础可以追溯到心理学和行为科学研究，但近年来，随着计算神经科学和深度学习的发展，注意力机制在人工智能领域也成为了研究的热点。通过设计特定的算法，如卷积神经网络（CNN）和变换器（Transformer）中的注意力机制，可以显著提高模型对关键信息的识别和提取能力。

#### 焦点与模糊现象

焦点与模糊现象是我们日常生活中常见的感知现象。在视觉感知中，我们往往能够清晰地看到某一个物体或场景中的特定部分，而其他部分则显得模糊不清。这种感知上的焦点与模糊，如何与量子力学中的测不准原理相联系，是本文探讨的核心问题。

在物理学中，焦点与模糊现象可以通过量子力学中的波粒二象性和量子态的叠加原理来解释。粒子的量子态在不同的位置和动量之间叠加，形成了复杂的波动模式。当我们在观察某个物体时，这个物体的量子态会坍缩到特定的位置，形成我们感知中的“焦点”，而其他可能的量子态则表现为“模糊”。

在认知科学中，焦点与模糊现象与注意力机制密切相关。大脑通过注意力机制，将有限的认知资源集中在一个特定的感知焦点上，同时忽略其他模糊的信息。这种机制不仅提高了信息处理的效率，也有助于我们在复杂环境中做出快速准确的决策。

### 第一部分：测不准原理的物理基础

#### 1.1 测不准原理的起源与历史背景

测不准原理（Uncertainty Principle）是量子力学中的一个基本原理，其起源可以追溯到20世纪早期。20世纪初，物理学界经历了一场深刻的变革，经典物理学已经无法解释某些微观粒子的行为，这促使科学家们开始探索一种新的理论框架。正是在这一背景下，测不准原理应运而生。

测不准原理的提出者是德国物理学家维尔纳·海森堡（Werner Heisenberg），他在1927年首次提出了这一原理。海森堡的测不准原理基于对电子在原子核周围的行为的研究。在经典物理学中，我们认为电子在原子核周围可以精确地确定其位置和动量。然而，海森堡发现，在量子尺度上，这种精确测量是不可能的。他提出了一个重要的观点：粒子的位置和动量无法同时被精确知晓，两者的测量精度存在固有的限制。

海森堡的测不准原理是在对电子的量子态进行分析时提出的。电子的量子态可以用波函数来描述，波函数包含了电子在空间中的概率分布信息。海森堡通过数学分析发现，波函数的平方给出了电子在某个位置出现的概率密度，而波函数的模长平方则给出了电子的动量分布。这两个分布函数是互补的，即当我们测量电子的位置时，它的动量信息会变得不确定，反之亦然。这一发现打破了经典物理学中的确定性观念，揭示了微观世界中存在的基本不确定性。

测不准原理的提出不仅在物理学领域引起了巨大的反响，也对哲学、逻辑和认识论等领域产生了深远的影响。它挑战了人类对自然世界的基本认知方式，引发了关于现实本质和测量问题的深刻讨论。

#### 1.1.2 测不准原理的核心概念

测不准原理的核心概念可以归纳为以下几点：

1. **不确定性关系**：测不准原理表达了粒子位置和动量之间的不确定关系。具体来说，海森堡不确定性原理可以用数学公式表示为：
   $$
   \Delta x \Delta p \geq \frac{h}{4\pi}
   $$
   其中，$\Delta x$表示位置的不确定性，$\Delta p$表示动量的不确定性，$h$为普朗克常数。这个公式表明，当位置的不确定性减小时，动量的不确定性必须增大，反之亦然。这意味着我们无法同时精确测量粒子的位置和动量。

2. **量子态叠加**：在量子力学中，粒子的状态可以用波函数来描述。波函数可以是多个可能状态的叠加，每个状态对应一个特定的位置或动量。当我们测量粒子的状态时，波函数会发生坍缩，变成一个特定的状态。这个过程体现了量子态的叠加性和测量结果的随机性。

3. **量子测量**：在量子力学中，测量过程并不是一个被动观察的过程，而是主动参与的过程。测量会影响被测粒子的状态，使其从叠加态坍缩到某个特定的态。这一观点与经典物理学中的测量概念有很大的不同。

4. **非定域性**：测不准原理还揭示了量子系统的非定域性特征。量子比特之间的关联可以跨越很大的空间距离，这种现象被称为量子纠缠。即使两个量子比特相隔很远，对其中一个比特的测量也会立即影响到另一个比特的状态，这违反了经典物理学中的局域实在论。

#### 1.1.3 测不准原理的数学表述

测不准原理的数学表述主要基于量子力学中的波函数和算符理论。以下是一些关键的数学公式和概念：

1. **波函数**：波函数是量子态的数学描述，通常用符号$\Psi(x, t)$表示。波函数的平方给出了粒子在空间中某点出现的概率密度，即：
   $$
   \rho(x) = |\Psi(x, t)|^2
   $$
   其中，$\rho(x)$表示粒子在位置$x$的概率密度。

2. **算符**：在量子力学中，物理量用算符表示。例如，位置算符用$\hat{x}$表示，动量算符用$\hat{p}$表示。这些算符作用在波函数上，可以得到对应的物理量。例如，位置的不确定性$\Delta x$可以通过以下公式计算：
   $$
   \Delta x = \sqrt{\langle \hat{x}^2 \rangle - \langle \hat{x} \rangle^2}
   $$
   其中，$\langle \hat{x}^2 \rangle$和$\langle \hat{x} \rangle$分别是位置算符的平方和期望值。

3. **不确定性原理的数学公式**：海森堡不确定性原理可以用以下数学公式表示：
   $$
   \Delta x \Delta p \geq \frac{h}{4\pi}
   $$
   这个公式说明了位置和动量的不确定性之间的关系。其中，$h$为普朗克常数。

4. **量子态的叠加**：量子态可以表示为多个可能状态的线性叠加。例如，一个电子的量子态可以表示为：
   $$
   \Psi(x, t) = c_1 \psi_1(x, t) + c_2 \psi_2(x, t)
   $$
   其中，$c_1$和$c_2$是复数系数，$\psi_1(x, t)$和$\psi_2(x, t)$是两个可能的量子态。

5. **量子纠缠**：量子纠缠是量子系统之间的特殊关联，可以用以下数学关系表示：
   $$
   \Psi(A) \otimes \Psi(B) = \sum_{i, j} c_{ij} \psi_i(A) \otimes \psi_j(B)
   $$
   其中，$\Psi(A)$和$\Psi(B)$分别是两个量子系统的波函数，$\otimes$表示量子态的叠加。

通过这些数学公式和概念，我们可以更深入地理解测不准原理的物理意义和数学表述。这些公式不仅揭示了量子力学中基本的不确定性关系，也为实验验证提供了理论基础。

### 第2章 测不准原理的实验验证

#### 2.1 量子态叠加与坍缩

量子态叠加与坍缩是测不准原理的核心内容之一，也是量子力学实验验证的关键现象。量子态叠加描述了粒子在量子尺度上的多种可能性，而坍缩则解释了量子态在测量过程中如何从多种可能性中确定到一个特定的状态。

**量子态叠加**：在量子力学中，粒子的状态可以用波函数来描述。一个典型的量子态可以表示为多个可能状态的叠加。例如，一个电子的量子态可以表示为：
$$
\Psi(x, t) = c_1 \psi_1(x, t) + c_2 \psi_2(x, t)
$$
其中，$c_1$和$c_2$是复数系数，$\psi_1(x, t)$和$\psi_2(x, t)$是两个不同的量子态。这种叠加态意味着电子同时具有多种状态的可能性。当我们对电子进行位置测量时，波函数会坍缩到一个特定的状态，这个状态由叠加态中的某个系数决定。

**量子态坍缩**：量子态坍缩是指波函数在测量过程中从叠加态变为一个确定态的过程。这一现象可以通过多个实验得到验证，其中最著名的实验是托马斯·杨（Thomas Young）的双缝实验。

**双缝实验**：双缝实验是一个经典的量子力学实验，它展示了量子态叠加和坍缩的现象。实验中，粒子（如电子或光子）通过两个狭缝，形成一个干涉图案。当粒子通过单个狭缝时，它表现为粒子行为，形成清晰的斑点。然而，当粒子同时通过两个狭缝时，它表现出波的行为，形成干涉图案。这个干涉图案表明，粒子在通过两个狭缝时处于叠加态。

在双缝实验中，当我们在屏幕后放置一个探测器以测量粒子通过哪个狭缝时，干涉图案会消失，粒子表现出粒子行为。这是因为测量过程导致量子态的坍缩，粒子只能通过一个特定的狭缝，失去了叠加态的特性。

**实验证据**：除了双缝实验，还有许多其他实验验证了量子态叠加和坍缩的现象。例如，量子比特的叠加态可以通过量子计算的量子叠加门来创建。在量子计算中，量子比特可以同时处于0和1的状态，这表明量子态的叠加性。

以下是一个简化的量子态叠加与坍缩的Python代码示例：
```python
import numpy as np

# 创建叠加态
psi_0 = np.array([1, 1]) / np.sqrt(2)

# 输出叠加态的概率分布
print("叠加态的概率分布：", psi_0**2)

# 对叠加态进行测量，得到坍缩态
result = np.random.choice([0, 1], p=[0.5, 0.5])

# 输出测量结果
print("测量结果：", result)

# 根据测量结果更新波函数
if result == 0:
    psi_1 = np.array([1, 0])
else:
    psi_1 = np.array([0, 1])

# 输出坍缩态的概率分布
print("坍缩态的概率分布：", psi_1**2)
```
在这个示例中，我们首先创建了一个叠加态，然后通过随机测量得到坍缩态。测量结果决定了波函数的状态，从而实现了量子态的坍缩。

通过这些实验和代码示例，我们可以更直观地理解量子态叠加和坍缩的现象，这些现象不仅验证了测不准原理，也为量子力学和量子计算提供了重要的理论基础。

### 2.1.2 双缝实验与量子干涉

双缝实验（Double Slit Experiment）是量子力学中一个非常重要的实验，它通过展示量子粒子的干涉现象，揭示了量子态叠加和测量坍缩的原理。这一实验不仅验证了测不准原理，还挑战了经典物理学的确定性观念，对量子力学的哲学意义和实验方法产生了深远的影响。

**实验原理**：双缝实验的基本原理可以归结为观察粒子（如电子、光子等）通过两个狭缝时产生的干涉现象。当粒子通过单个狭缝时，根据经典物理学的预期，我们应当观察到粒子在屏幕上形成离散的斑点。然而，当粒子同时通过两个狭缝时，屏幕上会出现干涉条纹，这种条纹的形成表明粒子具有波粒二象性。

干涉条纹的形成可以用波动理论来解释。当两个波相互叠加时，它们会产生干涉现象。如果两个波在某个位置相遇时相位相同，它们会相互增强，形成亮条纹；如果相位相反，它们会相互抵消，形成暗条纹。在双缝实验中，粒子通过两个狭缝时形成的两个波函数相互干涉，导致屏幕上的干涉条纹。

**实验结果**：双缝实验的结果展示了以下关键现象：

1. **干涉条纹**：当粒子通过两个狭缝时，屏幕上会出现一系列明暗交替的干涉条纹。这些条纹表明粒子在通过两个狭缝时处于叠加态，即粒子同时通过两个狭缝。
2. **测量影响**：当在两个狭缝之间放置探测器以测量粒子通过哪个狭缝时，干涉条纹会消失，屏幕上只显示出离散的斑点。这表明测量过程导致了量子态的坍缩，粒子只能通过一个特定的狭缝。
3. **量子比特**：在双缝实验中，如果将粒子视为量子比特，当量子比特处于叠加态时，它在两个狭缝之间同时存在，这体现了量子比特的叠加性。当进行测量时，量子比特会坍缩到一个特定的状态，这体现了量子态的坍缩原理。

**实验意义**：双缝实验对量子力学和测不准原理的验证具有深远的意义：

1. **量子态叠加**：双缝实验证明了量子粒子可以处于多个状态的叠加，这打破了经典物理学的确定性观念，揭示了量子世界中的叠加性和不确定性。
2. **测量坍缩**：双缝实验展示了测量过程对量子态的影响，即测量会导致量子态的坍缩。这一现象挑战了经典物理学中的观测者无关性观念，揭示了量子世界中的测量本质。
3. **波粒二象性**：双缝实验展示了量子粒子既具有粒子特性又具有波动特性，这表明量子世界中的现象不能简单地用经典物理学的粒子或波来描述。

**实验方法**：双缝实验可以通过多种方式进行，以下是两种常见的方法：

1. **电子双缝实验**：在实验室中，可以将电子束通过两个狭缝，然后测量电子在屏幕上的分布。通过改变电子束的强度和狭缝间距，可以观察到不同的干涉条纹。
2. **光子双缝实验**：利用激光器产生的光子束通过两个狭缝，然后通过检测器测量光子到达屏幕的位置。通过改变狭缝间距和光子束的强度，可以观察到不同的干涉条纹。

**实验扩展**：双缝实验不仅在实验室中得到验证，还在多个领域得到了扩展和应用。例如，在量子计算中，双缝实验的原理被用于实现量子叠加和量子纠缠。在量子通信中，双缝实验的原理被用于实现量子密钥分发。在量子模拟中，双缝实验的原理被用于模拟复杂量子系统的行为。

总之，双缝实验是量子力学中一个经典的实验，它通过展示量子态叠加和测量坍缩的现象，验证了测不准原理，对量子力学的理解和应用产生了深远的影响。未来，随着量子技术的发展，双缝实验将继续发挥重要作用，推动量子科学的发展。

### 2.1.3 量子比特与非定域性

量子比特（Quantum Bit，简称qubit）是量子计算的基本单位，它继承了经典比特（Classical Bit）的基本特性，但在量子力学的作用下，量子比特能够同时处于多种状态，这一特性使得量子计算在处理复杂问题时展现出巨大的潜力。在本节中，我们将探讨量子比特的定义、特性以及非定域性这一关键概念。

#### 量子比特的定义与特性

量子比特是量子计算的基本单位，与传统比特相比，量子比特具有以下特点：

1. **叠加态**：传统比特只能处于两种状态之一，即0或1。而量子比特可以同时处于多种状态的叠加，这一特性被称为叠加态。例如，一个量子比特可以同时处于状态$|0\rangle$和$|1\rangle$的叠加，即：
   $$
   \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)
   $$
   这种叠加态使得量子比特能够处理更多信息。

2. **量子门**：量子比特的操作通过量子门（Quantum Gate）实现。量子门是量子计算中的基本操作，类似于经典计算机中的逻辑门。量子门可以改变量子比特的状态，例如，通过一个X量子门，可以将量子比特的状态从$|0\rangle$翻转成$|1\rangle$，或者将$|1\rangle$翻转成$|0\rangle$。常见的量子门包括Hadamard门、Pauli门和控制非门（CNOT门）等。

3. **纠缠态**：量子比特之间可以形成特殊的关联，称为纠缠态（Entanglement）。当两个量子比特处于纠缠态时，一个量子比特的状态会立即影响到另一个量子比特的状态，即使它们相隔很远。这种非定域性的关联是量子计算和量子通信的重要特性。

#### 量子比特的应用

量子比特的这些特性使得它在多个领域具有广泛的应用：

1. **量子计算**：量子计算利用量子比特的叠加态和纠缠态来处理复杂问题。例如，量子计算可以用于求解线性方程组、大整数分解、量子模拟等领域。量子计算的理论优势在于其能够处理的问题规模远超经典计算机。

2. **量子通信**：量子比特可以用于实现量子密钥分发（Quantum Key Distribution，简称QKD）。QKD是一种安全的通信方式，通过量子比特的纠缠态实现密钥的分发，确保通信的保密性和完整性。

3. **量子模拟**：量子比特可以用于模拟复杂的量子系统，例如，量子化学中的分子模拟、量子材料的研究等。量子模拟有助于我们更好地理解量子系统的行为，为新材料和新技术的研究提供支持。

#### 非定域性

非定域性（Non-locality）是量子力学中一个重要且独特的特性，它表明量子比特之间的关联可以跨越很大的空间距离，这种现象被称为量子纠缠。非定域性挑战了经典物理学的局域实在论，即物理系统的性质和状态只能在空间的一个局部区域内存在。

1. **量子纠缠**：量子纠缠是指两个或多个量子比特之间的特殊关联，即使它们相隔很远，一个量子比特的状态变化也会立即影响到另一个量子比特的状态。这种非局域性的关联可以通过量子态的测量来验证。

2. **爱因斯坦-波多尔斯基-罗森佯谬（EPR佯谬）**：EPR佯谬是爱因斯坦等人提出的质疑量子纠缠非定域性的论证。他们认为，量子纠缠违背了局域实在论，但实验结果却支持了量子纠缠的非定域性。

3. **贝尔不等式**：贝尔不等式是用于检验量子纠缠非定域性的重要工具。如果量子系统的行为违反贝尔不等式，那么它必须处于非定域性状态。一系列实验验证了量子纠缠确实违反了贝尔不等式，从而证明了量子非定域性的存在。

通过量子比特的定义与特性，我们可以看到量子计算和量子通信的巨大潜力。而量子比特的非定域性不仅挑战了经典物理学的局域实在论，也为量子信息和量子计算的研究提供了新的方向。

### 第二部分：注意力机制

#### 3.1 注意力机制的基本理论

注意力机制（Attention Mechanism）是人类认知系统中的一个关键概念，描述了大脑如何选择关注某些信息而忽略其他信息。在认知科学、心理学和神经科学领域，注意力机制的研究已经取得了显著的进展，帮助我们更好地理解人类感知、学习和决策的过程。在本节中，我们将探讨注意力机制的定义、分类及其在认知科学中的应用。

#### 3.1.1 注意力机制的定义与分类

1. **定义**：注意力机制可以定义为大脑在信息处理过程中对某些信息进行选择和集中的能力。通过注意力机制，大脑可以有效地过滤掉大量无关的信息，将有限的认知资源集中在一个特定的目标上。这种选择性的关注有助于提高信息处理的效率和准确性。

2. **分类**：根据不同的功能和表现形式，注意力机制可以分为以下几种类型：

   - **选择性注意力（Selective Attention）**：选择性注意力是指大脑对特定信息进行选择和优先处理的能力。例如，当我们在嘈杂的环境中听讲时，会自动过滤掉背景噪音，将注意力集中在讲师的声音上。

   - **分配性注意力（Divided Attention）**：分配性注意力是指大脑同时处理多个任务或信息的能力。例如，我们可以一边开车一边听音乐，或者一边做笔记一边听讲座。

   - **持续注意力（Sustained Attention）**：持续注意力是指大脑在长时间内保持对特定任务的关注和专注。例如，学生需要长时间专注于学习，以便掌握知识。

   - **执行性注意力（Executive Attention）**：执行性注意力是指大脑在决策、规划和问题解决过程中进行的注意力控制。它涉及对注意力的分配、转移和调整，是高级认知功能的基础。

   - **选择性注意力与分配性注意力的平衡**：在某些任务中，选择性注意力和分配性注意力需要相互平衡。例如，在驾驶过程中，我们需要将选择性注意力集中在道路和车辆上，同时保持分配性注意力，以便应对突发情况。

#### 3.1.2 注意力机制的心理基础

注意力机制的心理基础涉及多个认知过程，包括感知、记忆、学习和决策。以下是一些关键的心理基础：

1. **感知**：感知是注意力机制的第一步，它涉及大脑对环境信息的接收和处理。通过感知，大脑可以识别和分类不同的刺激，如声音、光线、触觉等。

2. **记忆**：记忆是注意力机制的重要组成部分，它帮助大脑存储和检索重要的信息。选择性注意力和持续注意力有助于记忆关键信息，而分配性注意力则有助于同时处理多个任务的信息。

3. **学习**：学习过程中，注意力机制帮助大脑选择重要的信息进行加工和记忆。例如，通过选择性注意力，我们可以关注重要的学习材料，并通过持续注意力将知识巩固在记忆中。

4. **决策**：执行性注意力在决策过程中起到关键作用。它帮助大脑在多个选择中做出最优决策，并调整注意力的分配，以便应对不同的情况。

在计算机科学和人工智能领域，注意力机制被广泛应用于神经网络模型，特别是深度学习模型。以下是一些常见的注意力计算模型：

### 3.1.3 注意力机制的计算模型

在计算机科学和人工智能领域，注意力机制的计算模型已经成为深度学习，尤其是序列数据处理任务中不可或缺的一部分。注意力机制通过动态调整对输入数据的关注程度，提高了模型对重要信息的识别和提取能力。以下我们将详细介绍几种常见的注意力机制及其在计算模型中的应用。

#### 自注意力机制（Self-Attention）

自注意力机制是Transformer模型的核心组件，它通过计算输入序列中每个元素与所有其他元素之间的相似性，为每个元素分配注意力权重。具体步骤如下：

1. **输入编码**：首先将输入序列编码为向量表示。例如，对于一个单词序列，可以将其转换为词嵌入向量。
2. **计算相似性**：对于每个输入元素，计算其与其他所有元素之间的相似性。相似性通常通过点积（Dot Product）或余弦相似性来计算：
   $$
   \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
   $$
   其中，$Q$、$K$和$V$分别是查询（Query）、键（Key）和值（Value）向量，$d_k$是键向量的维度。
3. **加权求和**：根据计算得到的注意力权重，对值向量进行加权求和，得到最终的输出：
   $$
   \text{Output} = \text{softmax}(QK^T)V
   $$

自注意力机制的一个关键优点是它能够捕捉序列中的长距离依赖关系，从而在自然语言处理、文本生成等领域表现出色。

#### 对称注意力机制（Symmetric Attention）

对称注意力机制是对自注意力机制的一种变体，它简化了计算过程，通过将键（Key）和查询（Query）向量设置为相同，从而减少了计算复杂度。其计算公式为：
$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

与自注意力机制类似，对称注意力机制同样可以用于序列数据的处理，例如在图像描述生成任务中，它可以通过计算图像中每个像素与所有其他像素之间的相似性，生成图像的描述。

#### 对数注意力机制（Log-Scale Attention）

对数注意力机制通过引入对数缩放因子，进一步降低了注意力权重之间的差异，从而改善模型的稳定性和性能。其计算公式为：
$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k} + \alpha}\right)V
$$
其中，$\alpha$是对数缩放因子，通常设置为$10^{-6}$。

#### 多头注意力机制（Multi-Head Attention）

多头注意力机制是在自注意力机制的基础上，通过并行计算多个注意力头（Attention Head），从而增加模型的表示能力。每个注意力头可以学习不同类型的依赖关系，从而提高模型的泛化能力。其计算公式为：
$$
\text{Multi-Head Attention} = \text{Concat}(\text{head}_1, \text{head}_2, \ldots, \text{head}_h)W^O
$$
其中，$h$是注意力头的数量，$W^O$是输出变换权重。

#### 注意力机制的Python实现

以下是一个简单的Python实现，用于演示自注意力机制：
```python
import numpy as np

def scaled_dot_product_attention(q, k, v, scale_factor):
    # 计算点积
    scores = np.dot(q, k.T) / np.sqrt(np.shape(k)[1])
    
    # 应用缩放因子
    scores = scores / scale_factor
    
    # 计算softmax
    attn_weights = np.softmax(scores)
    
    # 加权求和
    output = np.dot(attn_weights, v)
    
    return output, attn_weights

# 示例输入
q = np.random.rand(5, 10)  # 查询向量
k = np.random.rand(5, 10)  # 键向量
v = np.random.rand(5, 10)  # 值向量

# 设置缩放因子
scale_factor = np.sqrt(np.shape(k)[1])

# 应用自注意力机制
output, attn_weights = scaled_dot_product_attention(q, k, v, scale_factor)

print("输出：", output)
print("注意力权重：", attn_weights)
```

通过以上实现，我们可以看到注意力机制在计算模型中的应用。未来，随着注意力机制研究的深入，我们有望在更多领域看到其应用，推动人工智能的发展。
