**3.1 格理论算法介绍**

格理论中的关键算法包括LLL算法和Babai算法。这些算法在处理格问题方面具有重要作用。

- **LLL算法**（Lenstra, Lenstra, Lovász）：


- **Babai算法**：
  - 用于快速求解格的最近点问题。
  - 流程图：

    ```mermaid

    B --> C[检查p是否是最近点]

    C -->|否| E[更新p，重复B]
    ```

**3.2 算法原理讲解**

接下来，我们将使用Python代码详细解释这些算法的原理。

**LLL算法示例代码**：

```python
import numpy as np

def lll(A):
    # 高斯消元
    L, U = np.linalg.qr(A)
    # 计算L的最小生成树
    M = np.linalg.inv(np.linalg.qr(L)[0])
    # 输出最小生成树
    return M

# 示例矩阵
A = np.array([[2, -1], [-1, 2]])
M = lll(A)
print(M)
```

**Babai算法示例代码**：

```python
def babai(G, v):
    p = G @ v
    while True:
        if np.linalg.norm(p - G @ p) < 1e-10:
            return p
        p = G @ p

# 示例格和向量
G = np.array([[1, 0], [0, 1]])
v = np.array([1, 0])
p = babai(G, v)
print(p)
```
