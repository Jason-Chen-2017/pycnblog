间接探测信号分析则是通过分析间接探测到的物理现象，来推断暗物质的存在和性质。这些间接探测信号包括宇宙微波背景辐射、星系旋转曲线、星系团引力透镜效应等。这些信号的检测和分析，为我们理解暗物质提供了重要的线索。

#### 1.1 暗物质的基本概念

暗物质最早是在20世纪30年代由瑞士天文学家费利克斯·布隆伯格（Felix Bloch）和美国人罗贝尔·迪克（Robert Dicke）提出的。当时，他们通过观测星系旋转曲线发现，星系外围的恒星运动速度远高于预期的牛顿引力定律所预测的速度。为了解释这一现象，科学家们提出了暗物质的存在，认为星系之间存在大量我们无法直接观测到的物质，这些物质通过引力作用影响星系的运动。

暗物质的主要特征包括：

- **非电磁性**：暗物质不与电磁波相互作用，因此不能通过电磁波（如光、X射线等）进行直接探测。
- **弱相互作用性**：暗物质粒子与其他物质的相互作用非常微弱，主要通过与引力相互作用来影响宇宙的演化。
- **宇宙普遍性**：暗物质遍布宇宙，从星系到星系团，甚至在宇宙早期就已经存在。

暗物质的存在对宇宙学的几个关键问题提供了重要线索，包括宇宙的大尺度结构形成、宇宙的膨胀速率、暗能量的存在等。然而，由于暗物质本身的性质，我们对其认识仍然有限，这需要通过间接探测信号分析等手段来进一步探索。

间接探测信号分析是研究暗物质的关键方法之一，通过分析这些信号，我们可以获得关于暗物质的一些重要信息。间接探测信号分析的意义主要体现在以下几个方面：

3. **探索宇宙早期历史**：通过分析早期宇宙中的信号，如宇宙微波背景辐射，我们可以追溯宇宙早期的历史，了解宇宙在大爆炸后的演化过程。

然而，间接探测信号分析也面临着一些挑战：

1. **信号弱且复杂**：间接探测信号通常非常微弱，并且常常伴随着各种噪声和干扰，这使得信号处理和分析变得复杂。

总之，间接探测信号分析是研究暗物质的重要手段，虽然面临着诸多挑战，但随着技术的不断进步和理论的不断完善，我们有望对暗物质有更深入的了解。

import numpy as np
from scipy.signal import butter, filtfilt

def butter_bandpass_filter(data, lowcut, highcut, fs, order=4):
    nyq = 0.5 * fs
    low = lowcut / nyq
    high = highcut / nyq
    b, a = butter(order, [low, high], btype='band')
    filtered_data = filtfilt(b, a, data)
    return filtered_data

def preprocess_data(data, lowcut, highcut, fs):
    filtered_data = butter_bandpass_filter(data, lowcut, highcut, fs)
    mean = np.mean(filtered_data)
    std = np.std(filtered_data)
    normalized_data = (filtered_data - mean) / std
    cleaned_data = np.where(np.isfinite(normalized_data), normalized_data, np.nan)
    return cleaned_data
