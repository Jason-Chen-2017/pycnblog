《微积分中的数值方法》

### 关键词：微积分、数值方法、微分方程、积分、误差分析、稳定性、应用实例

### 摘要

微积分作为数学的重要分支，在自然科学、工程技术以及经济学等多个领域具有广泛的应用。然而，微积分问题往往涉及复杂的计算，传统的解析方法难以应对。数值方法作为求解微积分问题的有力工具，通过近似计算，为各类科学和工程问题提供了可行的解决方案。本文将系统地介绍微积分中的数值方法，包括其基本概念、原理、应用实例以及误差分析与优化策略，旨在帮助读者全面了解和掌握这一重要的数学工具。

### 引言

微积分是数学中研究函数变化率以及积分计算的理论，其核心思想是通过局部线性化来近似求解复杂问题。然而，在实际应用中，许多微积分问题难以用传统的解析方法解决，如高维积分、非线性微分方程等。这时，数值方法作为一种近似计算手段，提供了有效且可行的解决方案。数值方法通过离散化、迭代计算等方式，将复杂的微积分问题转化为可以处理的数值问题，从而在工程计算、科学研究和数据分析等领域发挥了重要作用。

本文将围绕微积分中的数值方法，从基本概念出发，详细探讨数值方法的理论基础、应用场景以及误差控制和优化策略。首先，我们将介绍微积分的基本概念及其与数值方法的联系；接着，重点分析数值方法在微分方程和积分问题中的具体应用；随后，讨论数值方法的误差来源及稳定性问题；最后，通过实际案例展示数值方法在多领域的应用，并展望未来的发展趋势。

### 第一部分：微积分基本概念与数值方法概述

## 第1章：微积分与数值方法的基础理论

### 1.1 微积分的基本概念

#### 1.1.1 微积分的历史与发展

微积分的发展历程可追溯到17世纪，当时数学家们开始探索如何处理变化和累积的问题。法国数学家艾萨克·牛顿（Isaac Newton）和德国数学家戈特弗里德·威廉·莱布尼茨（Gottfried Wilhelm Leibniz）分别独立地创立了微积分学的基本理论，奠定了现代微积分的基石。

**牛顿的贡献：** 牛顿在他的著作《自然哲学的数学原理》中，引入了“流数”的概念，用以描述物体运动的速度和加速度。通过这一概念，他建立了微分学的基本原理。

**莱布尼茨的贡献：** 莱布尼茨则创立了积分学的符号表示方法，引入了积分符号∫，并定义了积分的基本性质和运算法则。他的工作使得微积分的运算变得直观和系统。

在牛顿和莱布尼茨的基础上，微积分得到了快速发展。19世纪末，德国数学家维尔斯特拉斯（Weierstrass）严格定义了实数和无穷小量，为微积分提供了严格的数学基础。

#### 1.1.2 微积分的基本原则

微积分的基本原则包括极限思想、导数和积分。以下是这些概念的基本定义和性质：

**极限：** 极限是微积分的基石，用于描述函数在某一点的局部行为。给定函数f(x)，当自变量x趋近于某一值a时，如果f(x)无限接近某一固定值L，则称L为f(x)在x趋近于a时的极限。

**导数：** 导数描述了函数在某一点的局部变化率。对于可导函数f(x)，在x点处的导数f'(x)定义为f(x)在x点处切线的斜率。

**积分：** 积分是导数的反过程，用于计算函数在某一区间上的累积总量。定积分∫f(x)dx表示函数f(x)在区间[a, b]上的积分值，表示f(x)在该区间内的累积和。

#### 1.1.3 微积分的基本公式

微积分中包含许多重要的基本公式，以下列举几个常用的公式：

**微分公式：**
\[ \frac{d}{dx}(x^n) = nx^{n-1} \]
\[ \frac{d}{dx}(\ln x) = \frac{1}{x} \]
\[ \frac{d}{dx}(\sin x) = \cos x \]
\[ \frac{d}{dx}(\cos x) = -\sin x \]

**积分公式：**
\[ \int x^n dx = \frac{x^{n+1}}{n+1} + C \]
\[ \int \ln x dx = x\ln x - x + C \]
\[ \int \sin x dx = -\cos x + C \]
\[ \int \cos x dx = \sin x + C \]

这些基本公式为微积分问题的求解提供了重要的工具，使我们可以处理各种复杂的函数问题。

### 1.2 数值方法的基本概念

#### 1.2.1 数值方法的定义与分类

数值方法是指通过离散化、迭代等手段，对连续的微积分问题进行近似求解的方法。数值方法可以分为以下几类：

**插值法：** 插值法用于根据有限的点来逼近未知的数据点。常见的插值方法有拉格朗日插值、牛顿插值等。

**数值微分法：** 数值微分法用于计算函数在离散点上的导数。常见的数值微分方法有前向差分、后向差分、中心差分等。

**数值积分法：** 数值积分法用于计算函数在区间上的积分。常见的数值积分方法有梯形法则、辛普森法则、高斯积分等。

**数值求解微分方程法：** 数值求解微分方程法用于求解初值问题和边值问题。常见的方法有欧拉法、改进欧拉法、龙格-库塔法等。

#### 1.2.2 数值方法的优缺点分析

**优点：**
1. 数值方法适用于复杂问题，尤其是解析方法难以处理的非线性问题。
2. 数值方法可以处理高维和复杂的边界条件。
3. 数值方法提供了灵活的求解策略，可以根据具体问题进行调整。

**缺点：**
1. 数值方法可能存在误差，特别是在不稳定的计算过程中。
2. 数值方法需要较高的计算资源和时间成本。
3. 数值方法的稳定性和收敛性需要严格验证。

### 1.3 微积分与数值方法的联系与融合

#### 1.3.1 微积分在数值方法中的应用

微积分的基本理论为数值方法提供了理论基础。例如，导数的概念被广泛应用于数值微分方法中，而积分的原理则被用于数值积分方法。通过微积分的基本公式，我们可以推导出多种数值方法的计算公式。

**示例：** 欧拉法求解一维线性微分方程，其基本思想是利用泰勒级数在一点处的线性近似来求解方程的下一个近似解。

#### 1.3.2 数值方法在微积分问题求解中的应用

数值方法在微积分问题求解中具有广泛的应用。例如：

1. **数值积分：** 用于求解复杂函数的定积分，如高维积分和无限区间积分。
2. **数值微分：** 用于求解无法用解析方法计算的函数导数。
3. **微分方程的数值解：** 用于求解初值问题和边值问题，如物理科学和工程中的问题。

综上所述，微积分与数值方法相互融合，互为补充。微积分为数值方法提供了理论指导，而数值方法则为微积分问题的求解提供了实际工具。这种融合使得微积分在科学研究和工程实践中具有更强的应用价值。

### 第2章：数值方法在微分方程求解中的应用

微分方程是描述自然现象和工程技术中动态过程的重要数学模型。然而，许多微分方程无法通过解析方法求解，因此需要采用数值方法进行近似计算。本章将介绍数值方法在求解微分方程中的应用，包括初值问题和边值问题的数值解法。

#### 2.1 微分方程的基本概念

**微分方程的定义：** 微分方程是指含有未知函数及其导数的方程。根据导数的阶数，微分方程可以分为常微分方程和偏微分方程。

**常微分方程：** 常微分方程是指导数的阶数为常数的微分方程。常微分方程可以表示为：
\[ a_n(x)y^{(n)}(x) + a_{n-1}(x)y^{(n-1)}(x) + \cdots + a_1(x)y'(x) + a_0(x)y(x) = f(x) \]
其中，\( y^{(n)}(x) \) 表示 \( y \) 的 n 阶导数，\( a_n(x), a_{n-1}(x), \ldots, a_0(x) \) 是已知函数，\( f(x) \) 是非齐次项。

**偏微分方程：** 偏微分方程是指含有多个自变量的导数的方程。常见的偏微分方程有波动方程、热传导方程等。

**微分方程的分类：**
- **线性微分方程：** 如果微分方程中的未知函数及其导数都是线性的，则称为线性微分方程。
- **非线性微分方程：** 如果微分方程中的未知函数及其导数包含非线性项，则称为非线性微分方程。

**微分方程的解法：** 微分方程的解法包括解析方法和数值方法。解析方法适用于一些特殊类型的微分方程，而数值方法则适用于更广泛的微分方程。

#### 2.2 初值问题的数值方法

初值问题是指给定微分方程在初始点处的函数值和导数值，求解该方程在后续区间上的解。常见的初值问题数值方法包括欧拉法、改进欧拉法和龙格-库塔法。

**欧拉法：**
欧拉法是一种简单的数值方法，其基本思想是利用函数的线性近似来求解下一个点处的函数值。欧拉法的计算公式为：
\[ y_{n+1} = y_n + h \cdot f(x_n, y_n) \]
其中，\( y_n \) 是当前点的函数值，\( h \) 是步长，\( f(x_n, y_n) \) 是函数在该点的导数值。

**改进欧拉法：**
改进欧拉法是在欧拉法的基础上进行改进，以提高解的精度。其计算公式为：
\[ k_1 = f(x_n, y_n) \]
\[ k_2 = f(x_n + h/2, y_n + k_1 \cdot h/2) \]
\[ y_{n+1} = y_n + h \cdot \frac{k_1 + k_2}{2} \]

**龙格-库塔法：**
龙格-库塔法是一种更精确的数值方法，适用于更广泛的微分方程。常见的龙格-库塔法包括二阶和四阶方法。

二阶龙格-库塔法的计算公式为：
\[ k_1 = f(x_n, y_n) \]
\[ k_2 = f(x_n + h/2, y_n + k_1 \cdot h/2) \]
\[ y_{n+1} = y_n + h \cdot \frac{k_1 + 2k_2}{3} \]

四阶龙格-库塔法的计算公式为：
\[ k_1 = f(x_n, y_n) \]
\[ k_2 = f(x_n + h/2, y_n + k_1 \cdot h/2) \]
\[ k_3 = f(x_n + h/2, y_n + k_2 \cdot h/2) \]
\[ k_4 = f(x_n + h, y_n + k_3 \cdot h) \]
\[ y_{n+1} = y_n + h \cdot \frac{k_1 + 2k_2 + 2k_3 + k_4}{6} \]

#### 2.3 边值问题的数值方法

边值问题是指给定微分方程在区间两端点的函数值，求解该方程在区间上的解。常见的边值问题数值方法包括迭代法、局部线性化法和最优化方法。

**迭代法：**
迭代法是一种基本的数值方法，其基本思想是通过逐步迭代，逼近边值问题的解。常见的迭代法包括牛顿迭代法和雅可比迭代法。

牛顿迭代法的计算公式为：
\[ F(x) = 0 \]
\[ x_{n+1} = x_n - \frac{F(x_n)}{F'(x_n)} \]

雅可比迭代法的计算公式为：
\[ A \cdot y = b \]
\[ y_{n+1} = A^{-1} \cdot b \]

**局部线性化法：**
局部线性化法是基于泰勒级数在一点处的线性近似，将边值问题转化为迭代问题。其基本思想是利用函数在一点处的导数，建立线性方程组，求解得到近似解。

**最优化方法：**
最优化方法利用最优化理论，求解边值问题。常见的方法有拉格朗日乘数法和序列二次规划法。

**示例：** 假设我们要求解以下边值问题：
\[ -\frac{d^2 u}{dx^2} = f(x) \]
\[ u(0) = u(L) = 0 \]

利用局部线性化法，我们可以将边值问题转化为以下迭代问题：
\[ u_{n+1}(x) = \frac{2}{L} \left[ \frac{1}{h} \left( \sum_{i=1}^{n} w_i \cdot (x - x_i) \right) - \frac{1}{h} \left( \sum_{i=n+1}^{m} w_i \cdot (x - x_i) \right) \right] \]
其中，\( w_i \) 是权函数，\( x_i \) 是离散点。

通过不断迭代，我们可以逼近边值问题的精确解。

### 第3章：数值方法在积分求解中的应用

积分在物理学、工程学和经济学等领域有着广泛的应用。数值积分方法通过离散化积分区间，提供了一种求解复杂积分的近似方法。本章将介绍数值积分的基本概念、一维数值积分方法、多维数值积分方法以及常见的误差分析和优化策略。

#### 3.1 积分的基本概念

**积分的定义：** 积分是微积分中的一种运算，用于计算函数在区间上的累积总量。定积分表示为：
\[ \int_{a}^{b} f(x) \, dx \]
其中，\( f(x) \) 是被积函数，\( a \) 和 \( b \) 是积分区间的端点。

**积分的性质：**
1. **线性性：** 积分具有线性性质，即：
\[ \int_{a}^{b} [cf(x) + g(x)] \, dx = c \int_{a}^{b} f(x) \, dx + \int_{a}^{b} g(x) \, dx \]
其中，\( c \) 是常数。

2. **可加性：** 积分具有可加性，即：
\[ \int_{a}^{b} f(x) \, dx = \int_{a}^{c} f(x) \, dx + \int_{c}^{b} f(x) \, dx \]
其中，\( a < c < b \)。

3. **奇偶性：** 如果 \( f(x) \) 是奇函数（即 \( f(-x) = -f(x) \)），则 \( \int_{-a}^{a} f(x) \, dx = 0 \)。

4. **中值性质：** 积分中值定理表明，如果函数 \( f(x) \) 在区间 \([a, b]\) 上连续，则至少存在一点 \( \xi \) 使得：
\[ \int_{a}^{b} f(x) \, dx = f(\xi) \cdot (b - a) \]

**积分的计算方法：** 对于简单的函数，可以使用积分表或积分公式直接计算定积分。然而，对于复杂的函数，特别是高维积分和无限区间积分，传统的解析方法难以处理，此时需要采用数值积分方法。

#### 3.2 一维数值积分方法

一维数值积分方法通过将积分区间划分为多个子区间，并在每个子区间上应用适当的近似公式，来计算整个积分的近似值。以下介绍几种常用的一维数值积分方法：

**梯形法则：**
梯形法则是最简单的一维数值积分方法，其基本思想是将积分区间划分为多个子区间，并在每个子区间上应用梯形面积公式。梯形法则的计算公式为：
\[ \int_{a}^{b} f(x) \, dx \approx \frac{h}{2} \left[ f(a) + 2 \sum_{i=1}^{n-1} f(x_i) + f(b) \right] \]
其中，\( h = \frac{b - a}{n} \) 是子区间的宽度，\( x_i = a + i \cdot h \) 是子区间的端点。

**辛普森法则：**
辛普森法则是梯形法则的改进，其基本思想是在每个子区间上应用二次函数的面积公式。辛普森法则的计算公式为：
\[ \int_{a}^{b} f(x) \, dx \approx \frac{h}{3} \left[ f(a) + 4 \sum_{i=1}^{n/2-1} f(x_{2i}) + 2 \sum_{i=1}^{n/2-1} f(x_{2i-1}) + f(b) \right] \]
其中，\( h = \frac{b - a}{n} \) 是子区间的宽度，\( x_i = a + i \cdot h \) 是子区间的端点。

**垂直切割法：**
垂直切割法通过在每个子区间上计算函数值的平均值，并利用平均值与积分值之间的关系，来近似计算整个积分。垂直切割法的计算公式为：
\[ \int_{a}^{b} f(x) \, dx \approx h \cdot \frac{1}{n} \sum_{i=1}^{n} f(x_i) \]
其中，\( h = \frac{b - a}{n} \) 是子区间的宽度，\( x_i = a + i \cdot h \) 是子区间的端点。

**高斯积分法：**
高斯积分法是一种高精度的数值积分方法，其基本思想是在积分区间上使用正态分布的节点和权重，来近似计算积分。高斯积分法的计算公式为：
\[ \int_{a}^{b} f(x) \, dx \approx w_1 f(x_1) + w_2 f(x_2) + \cdots + w_n f(x_n) \]
其中，\( x_i \) 是高斯积分节点，\( w_i \) 是高斯积分权重。

#### 3.3 多维数值积分方法

多维数值积分方法用于计算高维空间的积分。多维数值积分通常通过将高维积分转换为一系列一维积分来实现。以下介绍几种常见的多维数值积分方法：

**平方形法则：**
平方形法则是多维数值积分的基础方法，其基本思想是将积分区域划分为多个子区域，并在每个子区域上应用一维积分方法。平方形法则的计算公式为：
\[ \int_{R} f(x) \, dx \approx \sum_{i=1}^{m} \sum_{j=1}^{n} f(x_{ij}) \cdot \Delta x_i \cdot \Delta y_j \]
其中，\( R \) 是积分区域，\( m \) 和 \( n \) 分别是 \( x \) 和 \( y \) 方向上的子区域数量，\( \Delta x_i \) 和 \( \Delta y_j \) 分别是子区域的宽度和高度，\( x_{ij} \) 是子区域的中心点。

**高斯积分法：**
高斯积分法是多维数值积分的高精度方法，其基本思想是在高维空间中利用高斯积分节点和权重，来近似计算积分。高斯积分法的计算公式为：
\[ \int_{R} f(x) \, dx \approx \sum_{i=1}^{p} \sum_{j=1}^{q} w_{ij} f(x_{ij}) \]
其中，\( R \) 是积分区域，\( p \) 和 \( q \) 分别是 \( x \) 和 \( y \) 方向上的高斯积分节点数量，\( w_{ij} \) 是高斯积分权重，\( x_{ij} \) 是高斯积分节点。

**Monte Carlo 方法：**
Monte Carlo 方法是一种基于随机抽样的数值积分方法，其基本思想是通过大量的随机抽样，来估计积分的近似值。Monte Carlo 方法的计算公式为：
\[ \int_{R} f(x) \, dx \approx \frac{1}{N} \sum_{i=1}^{N} f(x_i) \]
其中，\( R \) 是积分区域，\( N \) 是随机抽样次数，\( x_i \) 是第 \( i \) 次抽样的样本点。

#### 3.4 误差分析与优化策略

数值积分方法的误差来源于多个方面，包括截断误差、舍入误差等。以下介绍数值积分方法的误差分析以及优化策略：

**误差来源：**
1. **截断误差：** 截断误差是由于数值方法的近似计算导致的误差。例如，梯形法则和辛普森法则的截断误差与子区间的数量有关。
2. **舍入误差：** 舍入误差是由于计算机浮点数表示的精度限制导致的误差。这种误差在多次运算中会逐渐累积。

**误差分析：**

2. **舍入误差分析：** 舍入误差可以通过数值方法的稳定性来分析。稳定性好的方法在多次运算中舍入误差的累积较小。

**优化策略：**
1. **增加子区间数量：** 增加子区间数量可以减少截断误差。然而，过多的子区间会导致计算复杂度增加。

### 第4章：数值方法的误差分析与稳定性

在数值方法的应用过程中，误差分析和稳定性是至关重要的。准确的误差估计和稳定的数值方法能够确保计算结果的可靠性和精度。本章将深入探讨数值方法的误差来源、误差分析、稳定性概念及其对数值方法的影响，并介绍一些误差控制和稳定性优化的策略。

#### 4.1 数值方法的误差来源

数值方法的误差主要来源于以下几个方面：

1. **截断误差：** 截断误差是由于数值方法的近似计算引起的误差。例如，在求解微分方程时，数值方法通常使用线性近似代替非线性方程，这会导致误差。截断误差与数值方法的步长或网格大小密切相关。

2. **舍入误差：** 舍入误差是由于计算机浮点数表示的有限精度限制而引起的误差。在计算过程中，浮点数的相加减、乘除等运算可能会导致数值的舍入误差，这些误差在多次运算中会逐渐累积。

3. **数值方法的特性：** 不同数值方法具有不同的误差特性。例如，某些方法可能在高精度要求下表现不佳，而另一些方法可能在处理复杂边界条件时具有优势。

4. **初值和边界条件的不确定性：** 初值和边界条件的不确定性也会引入误差。特别是在长时间积分或复杂系统中，初始条件的小幅变化可能导致最终结果的显著差异。

#### 4.2 数值方法的误差分析

误差分析是评估数值方法有效性和可靠性的关键步骤。以下介绍一些常见的误差分析方法：

1. **局部截断误差分析：** 局部截断误差分析用于评估在单个计算点上的误差。例如，在欧拉法中，局部截断误差可以通过泰勒级数展开来近似计算。

2. **整体误差分析：** 整体误差分析用于评估在整个计算区间上的误差累积。例如，通过计算误差项的积分或求和，可以得到整体误差的估计。

3. **稳定性分析：** 稳定性分析用于评估数值方法在长时间积分或大步长计算时的误差累积。稳定性分析通常基于特征值分析或能量估计。

**示例：** 假设我们使用欧拉法求解一维线性微分方程：
\[ y'(x) = -y(x) \]
\[ y(0) = 1 \]

局部截断误差可以通过以下公式计算：
\[ \epsilon_{local} = \frac{h^2}{2} \cdot |y''(x_0)| \]
其中，\( h \) 是时间步长，\( y''(x_0) \) 是在 \( x_0 \) 点的二阶导数。

整体误差可以通过计算整个时间区间上的误差累积来估计：
\[ \epsilon_{total} = \sum_{i=0}^{n} \epsilon_{local} \]

#### 4.3 数值方法的稳定性

稳定性是指数值方法在长时间积分或大步长计算时，能够保持误差在可接受范围内的特性。一个稳定的数值方法在长时间积分后，误差不会迅速发散，而是逐渐累积。

**稳定性概念：**

1. **绝对稳定性：** 绝对稳定性是指数值方法在任意初始条件和步长下，误差的累积都是有限的。

2. **条件稳定性：** 条件稳定性是指数值方法对于某些初始条件和步长是稳定的，但对其他初始条件和步长可能不稳定。

3. **稳定区域：** 稳定区域是指使数值方法稳定的初始条件和步长的范围。

**稳定性分析：**

稳定性分析通常基于特征值分析或能量估计。对于线性微分方程，可以通过特征值分析来评估数值方法的稳定性。例如，对于一维线性微分方程：
\[ y'(x) = -\lambda y(x) \]
\[ y(0) = 1 \]

如果特征值 \( \lambda \) 的模小于1，则数值方法在该步长下是稳定的。

**示例：** 假设我们使用欧拉法求解上述线性微分方程，步长为 \( h \)。欧拉法的稳定性可以通过以下不等式分析：
\[ |y_{n+1}| \leq |y_n| \cdot |1 + h \cdot \lambda| \]

如果 \( |1 + h \cdot \lambda| < 1 \)，则数值方法是稳定的。

#### 4.4 误差控制与稳定性优化

为了提高数值方法的精度和可靠性，我们可以采取以下误差控制和稳定性优化策略：

1. **选择合适的数值方法：** 选择适合问题的数值方法，例如对于线性微分方程，可以优先选择线性多步法或龙格-库塔法。

2. **调整步长：** 调整步长以控制误差的累积。通常，较小的步长可以降低误差，但会增加计算时间。

3. **多重网格方法：** 多重网格方法通过在不同尺度的网格上计算，来减少误差。这种方法在高维积分和复杂边界条件下特别有效。

4. **自适应步长：** 自适应步长方法根据误差的估计自动调整步长，以保持误差在可接受范围内。这种方法可以显著提高计算效率。

5. **预处理技术：** 预处理技术通过预处理方程，使数值方法更稳定。例如，利用预条件线性方程组求解器来提高线性微分方程求解的稳定性。

6. **并行计算：** 并行计算技术可以通过并行化计算过程来加速计算，同时减少由于舍入误差引起的累积误差。

通过上述误差控制和稳定性优化策略，我们可以有效提高数值方法的精度和可靠性，确保计算结果的准确性和稳定性。

**B.1 微积分基本公式**

**微分公式：**
\[ \frac{d}{dx}(x^n) = nx^{n-1} \]
\[ \frac{d}{dx}(\ln x) = \frac{1}{x} \]
\[ \frac{d}{dx}(\sin x) = \cos x \]
\[ \frac{d}{dx}(\cos x) = -\sin x \]

**积分公式：**
\[ \int x^n dx = \frac{x^{n+1}}{n+1} + C \]
\[ \int \ln x dx = x\ln x - x + C \]
\[ \int \sin x dx = -\cos x + C \]
\[ \int \cos x dx = \sin x + C \]

**B.2 欧拉法伪代码**

```python
function euler_method(y0, x0, h, n):
    y = y0
    for i in range(n):
        y = y + h * f(x0 + i * h, y)

```

**B.3 龙格-库塔法伪代码**

```python
function rk4_method(y0, x0, h, n):
    y = y0
    for i in range(n):
        k1 = f(x0 + i * h, y)
        k2 = f(x0 + i * h + 0.5 * h, y + 0.5 * h * k1)
        k3 = f(x0 + i * h + 0.5 * h, y + 0.5 * h * k2)
        k4 = f(x0 + i * h + h, y + h * k3)
        y = y + h * (k1 + 2 * k2 + 2 * k3 + k4) / 6
    return y
```

**B.4 梯形法则伪代码**

```python
function trapezoidal_rule(f, a, b, n):
    h = (b - a) / n
    s = 0.5 * (f(a) + f(b))
    for i in range(1, n):
        s = s + f(a + i * h)
    s = s * h
    return s
```

**B.5 高斯积分法伪代码**

```python
function gauss_integration(f, a, b, n):
    x = gauss_points(n)
    w = gauss_weights(n)
    s = 0
    for i in range(n):
        s = s + w[i] * f(a + (b - a) * x[i])
    return s
```
