### 第2章 暗物质基础概念

#### 2.1 暗物质的基本特性

暗物质具有几个显著的基本特性，这些特性决定了它与我们熟知的普通物质的不同。

首先，暗物质不发光。普通物质通过吸收和发射光子来发光，但暗物质不与电磁波发生相互作用，因此不会发出任何可见光。

其次，暗物质不发热。由于不与光子相互作用，暗物质不会因为吸收光子而升温。

第三，暗物质不反射电磁波。这使得我们无法直接观测到暗物质的存在，只能通过其引力效应来推断其存在。

第四，暗物质具有质量。尽管不发光、不发热，但暗物质具有质量，因此能够产生引力作用。

最后，暗物质可能具有一定的相互作用。虽然暗物质不与电磁波相互作用，但一些理论认为它可能通过弱相互作用与普通物质相互作用。

```python
def gravitational_lens_effect(density, distance, light_path):
    # 计算光线路径的弯曲角度
    angle = 2 * G * density * distance / c^2

    return light_path + angle
```

```python
print("Dark Matter Density:", rho)

plt.xlabel("Position [sol]")

plt.show()

angle = gravitational_lens_effect(rho, 1 * u.sol, light_path)
new_path = light_path + angle

plt.show()

# 计算暗物质流
J = dark_matter_flow(M, 1 * u.sol)
print("Dark Matter Flow:", J)
```

```python
    return (1 / np.sqrt(2 * np.pi * sigma**2)) * np.exp(-((x - mu)**2) / (2 * sigma**2))

# 计算引力透镜效应
def gravitational_lens_effect(density, distance, light_path):
    angle = 2 * G * density * distance / c**2
    return light_path + angle

# 计算暗物质流
def dark_matter_flow(M, r):
    return M / r**2

# 示例数据

V = 1e9 * u.sol  # 体积
mu = 0 * u.sol  # 平均值

c = 3e5 * u.km/u.s  # 光速
G = 6.67430e-11 * u.m**3/u.kg/u.s**2  # 万有引力常数

# 计算暗物质密度
rho = dark_matter_density(M, V)
print("Dark Matter Density:", rho)

# 计算暗物质分布函数
x = np.linspace(-5, 5, 100)
f = dark_matter_distribution(x, mu, sigma)
plt.plot(x, f)
plt.xlabel("Position [sol]")
plt.ylabel("Density [kg/m^3]")
plt.title("Dark Matter Distribution Function")
plt.show()

# 计算引力透镜效应
light_path = np.array([0, 0])
angle = gravitational_lens_effect(rho, 1 * u.sol, light_path)
new_path = light_path + angle

plt.xlabel("Position [sol]")
plt.ylabel("Position [sol]")

plt.show()

# 计算暗物质流
J = dark_matter_flow(M, 1 * u.sol)
print("Dark Matter Flow:", J)
```
