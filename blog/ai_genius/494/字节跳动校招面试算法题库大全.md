### 数组

数组是一种基础且常用的数据结构，用于存储固定大小的同类型元素。数组的优点在于元素访问时间非常高效，可以通过索引直接访问。

- **插入**：在数组中插入新元素。

### 链表

链表是一种动态数据结构，由一系列节点组成，每个节点包含数据和指向下一个节点的指针。链表的优点在于其插入和删除操作非常灵活，但访问元素需要遍历链表。

#### 核心操作

- **初始化**：创建一个链表。
- **插入**：在链表的指定位置或末尾插入新节点。
- **删除**：删除链表中的节点。
- **遍历**：遍历链表中的所有节点。

#### 伪代码示例

以下是一个单链表的插入和删除操作：

```pseudocode
struct Node
    value : integer
    next : Node

function LinkedList()
    head = null // 创建链表

function Insert(value : integer)
    newNode = new Node()
    newNode.value = value
    if head == null
        head = newNode
    else
        current = head
        while current.next != null
            current = current.next
        current.next = newNode

function Delete(value : integer)
    if head == null
        return
    if head.value == value
        head = head.next
        return
    current = head
    while current.next != null
        if current.next.value == value
            current.next = current.next.next
            return
        current = current.next
```

### 树

树是一种重要的非线性数据结构，由节点和边组成，节点包含数据和指向子节点的指针。树在计算机科学中应用广泛，如二叉搜索树、平衡树（AVL树）、堆等。

#### 核心操作

- **初始化**：创建一个空树。
- **插入**：在树中插入新节点。
- **删除**：从树中删除节点。
- **遍历**：遍历树的所有节点。

#### 伪代码示例

以下是一个二叉搜索树的插入操作：

```pseudocode
struct TreeNode
    value : integer
    left : TreeNode
    right : TreeNode

function BST()
    root = null // 创建空树

function Insert(value : integer)
    if root == null
        root = new TreeNode()
        root.value = value
    else
        current = root
        while current != null
            if value < current.value
                if current.left == null
                    current.left = new TreeNode()
                    current.left.value = value
                    break
                current = current.left
            else
                if current.right == null
                    current.right = new TreeNode()
                    current.right.value = value
                    break
                current = current.right
```

#### 空间复杂度分析

- **常量空间**：O(1)
- **线性空间**：O(n)
- **对数空间**：O(log n)

#### 第3章：动态规划与贪心算法

动态规划与贪心算法是解决复杂问题的重要策略，尤其在面试中经常出现。动态规划和贪心算法虽然表面上看起来不同，但它们的核心思想都是通过局部最优解推导出全局最优解。本章将深入讲解动态规划与贪心算法的基本原理，并通过经典例题进行详细解析。

### 动态规划

动态规划是一种将复杂问题分解为重叠子问题的方法，通过保存子问题的解来避免重复计算，从而提高算法的效率。

#### 核心概念

- **重叠子问题**：动态规划将原问题分解为多个子问题，而这些子问题之间存在重叠，即多个子问题的解是相互依赖的。
- **状态转移方程**：动态规划的核心在于找到状态转移方程，即如何根据子问题的解推导出原问题的解。
- **边界条件**：状态转移方程的定义需要边界条件来限定，确保算法的正确性。

#### 伪代码示例

以下是一个经典的动态规划问题——斐波那契数列：

```pseudocode
function Fibonacci(n : integer)
    if n <= 1
        return n
    dp[0] = 0
    dp[1] = 1
    for i = 2 to n
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
end function
```

在这个例子中，状态转移方程为 `dp[i] = dp[i-1] + dp[i-2]`，边界条件为 `dp[0] = 0` 和 `dp[1] = 1`。

#### 动态规划状态转移方程的推导

动态规划状态转移方程的推导通常需要以下几个步骤：

1. **确定状态**：定义问题中的状态，通常是一个数组或字典，用于存储子问题的解。
2. **找出状态转移关系**：分析子问题之间的依赖关系，推导出状态转移方程。
3. **确定边界条件**：定义状态转移方程的边界条件，确保算法的正确性。

以下是一个更复杂的动态规划问题——最长递增子序列（LIS）：

```pseudocode
function LongestIncreasingSubsequence(nums : array of integers)
    n = length(nums)
    dp = array of length n filled with 1
    for i = 1 to n
        for j = 0 to i - 1
            if nums[j] < nums[i]
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
end function
```

在这个例子中，状态 `dp[i]` 表示以 `nums[i]` 为结尾的最长递增子序列的长度。状态转移方程为 `dp[i] = max(dp[i], dp[j] + 1)`，其中 `j` 是小于 `i` 的所有索引。边界条件为 `dp[i] = 1`。

### 贪心算法

贪心算法是一种在每一步都做出局部最优选择，以期在整体上达到最优解的策略。与动态规划不同，贪心算法通常不需要考虑子问题的重叠性，它通过一系列贪心选择来逐步构造最终解。

#### 核心概念

- **贪心选择**：每一步都做出当前情况下最优的选择。
- **最优子结构**：问题的最优解包含其子问题的最优解。
- **无后效性**：当前状态只依赖于前面的状态，与前面状态的选择无关。

#### 伪代码示例

以下是一个经典的贪心算法问题——活动选择问题：

```pseudocode
function ActivitySelection(activities : array of pairs (start, finish))
    sort activities by finish time
    select activities[0]
    for i = 1 to length(activities) - 1
        if activities[i].start > activities[selected].finish
            select activities[i]
    end function
```

在这个例子中，贪心选择是每次选择最早结束的活动。通过这种方式，我们可以得到一个包含最多活动的集合。

#### 贪心算法的正确性证明

贪心算法的正确性通常通过以下两个性质来证明：

1. **最优子结构**：问题的最优解包含其子问题的最优解。
2. **贪心选择性质**：每一步的贪心选择都能保证问题的局部最优解，从而推导出全局最优解。

以下是一个贪心算法正确性的简单证明——背包问题：

```pseudocode
function Knapsack(values : array of integers, weights : array of integers, capacity : integer)
    items = [(value/weight), (value/weight), ..., (value/weight)]
    sort items in descending order
    totalValue = 0
    for each item in items
        if capacity >= item.weight
            add item.value to totalValue
            capacity -= item.weight
        end if
    end for
    return totalValue
end function
```

在这个例子中，贪心选择是按照价值与重量比从大到小排序，然后依次放入背包。由于每次选择都是局部最优的，因此最终得到的是全局最优解。

### 经典例题解析

以下是一些动态规划与贪心算法的经典例题，我们将通过伪代码和详细解析来展示解题思路。

1. **背包问题**

   - **问题描述**：给定一组物品和其价值、重量，以及一个最大承重，求解如何选取物品使得总价值最大且不超过承重。
   - **动态规划解法**：
     ```pseudocode
     function Knapsack(values : array of integers, weights : array of integers, capacity : integer)
         dp = array of size (capacity + 1) filled with 0
         for i = 1 to length(values)
             for w = capacity down to weights[i]
                 if w - weights[i] >= 0
                     dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
                 end if
             end for
         end for
         return dp[capacity]
     end function
     ```

2. **最长公共子序列（LCS）**

   - **问题描述**：给定两个字符串，求解它们的最长公共子序列。
   - **动态规划解法**：
     ```pseudocode
     function LongestCommonSubsequence(str1 : string, str2 : string)
         m = length(str1)
         n = length(str2)
         dp = array of size (m+1) x (n+1) filled with 0
         for i = 1 to m
             for j = 1 to n
                 if str1[i-1] == str2[j-1]
                     dp[i][j] = dp[i-1][j-1] + 1
                 else
                     dp[i][j] = max(dp[i-1][j], dp[i][j-1])
                 end if
             end for
         end for
         return dp[m][n]
     end function
     ```

     ```pseudocode
         sort edges by weight
         forest = empty forest

             if adding edge to forest does not create a cycle
                 add edge to forest
             end if
         end for

     end function
     ```

#### 第4章：图算法

图是计算机科学中重要的数据结构，用于表示对象及其之间的关系。在图算法中，我们使用图来解决问题，如最短路径、网络流等。本章将详细介绍图的基本概念、表示方法以及常见的图算法。

### 图的基本概念

#### 定义

- **图（Graph）**：由节点（或顶点）和边组成的集合。
- **节点（Vertex）**：图中的数据元素。
- **边（Edge）**：连接两个节点的线段。

#### 分类

- **无向图（Undirected Graph）**：边没有方向。
- **有向图（Directed Graph）**：边有方向。
- **连通图（Connected Graph）**：任意两个节点之间都有路径。
- **非连通图（Disconnected Graph）**：存在节点之间没有路径。

#### 特殊类型

- **树（Tree）**：连通且无环的无向图。
- **环（Cycle）**：图中的一条闭合路径，至少包含三个节点。
- **路径（Path）**：连接两个节点的序列。

### 图的表示方法

图的表示方法主要有邻接矩阵和邻接表。

#### 邻接矩阵

- **定义**：使用二维数组来表示图，其中 `matrix[i][j]` 表示节点 `i` 和节点 `j` 之间的边是否存在。
- **优点**：可以直接获取任意两个节点之间的边的信息，适合稀疏图。
- **缺点**：空间复杂度较高，不适合表示密集图。

#### 邻接表

- **定义**：使用数组来存储图中的节点，每个节点对应一个链表，链表中存储与该节点相连的所有节点。
- **优点**：空间复杂度较低，适合表示密集图。
- **缺点**：访问任意两个节点之间的边需要遍历链表，不适合大规模图的邻接关系查询。

### 常见的图算法

#### 深度优先搜索（DFS）

- **定义**：从起始节点开始，沿着某一路径遍历所有可能路径，直到路径的末端，然后从末端返回，重复这一过程。
- **伪代码**：
  ```pseudocode
  function DFS(graph : Graph, start : Vertex)
      stack = new Stack()
      visited = set()
      stack.push(start)
      while stack is not empty
          vertex = stack.pop()
          if vertex not in visited
              visited.add(vertex)
              for neighbor in vertex.neighbors
                  if neighbor not in visited
                      stack.push(neighbor)
      end while
  end function
  ```

#### 广度优先搜索（BFS）

- **定义**：从起始节点开始，逐层遍历图的所有节点，每一层节点都按顺序访问。
- **伪代码**：
  ```pseudocode
  function BFS(graph : Graph, start : Vertex)
      queue = new Queue()
      visited = set()
      queue.enqueue(start)
      while queue is not empty
          vertex = queue.dequeue()
          if vertex not in visited
              visited.add(vertex)
              for neighbor in vertex.neighbors
                  if neighbor not in visited
                      queue.enqueue(neighbor)
      end while
  end function
  ```

#### 最短路径算法

- **迪杰斯特拉算法（Dijkstra's Algorithm）**：用于求解单源最短路径问题。
  - **伪代码**：
    ```pseudocode
    function Dijkstra(graph : Graph, start : Vertex)
        distances = array of length V filled with INFINITY
        distances[start] = 0
        visited = set()
        while visited does not contain all vertices
            minDistance = INFINITY
            for each vertex in graph
                if vertex not in visited and distances[vertex] < minDistance
                    minDistance = distances[vertex]
                    currentVertex = vertex
            end for
            visited.add(currentVertex)
            for each neighbor of currentVertex
                if distances[currentVertex] + weight(currentVertex, neighbor) < distances[neighbor]
                    distances[neighbor] = distances[currentVertex] + weight(currentVertex, neighbor)
            end for
        end while
        return distances
    end function
    ```

- **贝尔曼-福特算法（Bellman-Ford Algorithm）**：用于求解单源最短路径问题，适用于有负权边的图。
  - **伪代码**：
    ```pseudocode
    function BellmanFord(graph : Graph, start : Vertex)
        distances = array of length V filled with INFINITY
        distances[start] = 0
        for i = 1 to V - 1
            for each edge (u, v) in graph
                if distances[u] + weight(u, v) < distances[v]
                    distances[v] = distances[u] + weight(u, v)
        end for
        for each edge (u, v) in graph
            if distances[u] + weight(u, v) < distances[v]
                return "Graph contains a negative weight cycle"
        end for
        return distances
    end function
    ```

#### Dijkstra算法与贝尔曼-福特算法的比较

- **时间复杂度**：Dijkstra算法的时间复杂度为 `O(E * log V)`（其中E为边数，V为节点数），而贝尔曼-福特算法的时间复杂度为 `O(V * E)`。
- **适用范围**：Dijkstra算法适用于没有负权边的图，而贝尔曼-福特算法可以处理有负权边的图。

### KMP算法

KMP（Knuth-Morris-Pratt）算法是一种高效的字符串匹配算法，由Donald Knuth、Vijay R. Pratt和James H. Morris共同提出。KMP算法通过避免字符串的重复比较，显著提高了字符串匹配的效率。

#### 核心思想

KMP算法的核心思想是当一次比较失败时，不是从字符串的开始位置重新比较，而是利用已经比较的信息，尽可能利用已有的部分匹配结果，继续进行后续匹配。

#### 部分匹配表（Next数组）

KMP算法的关键是构建一个部分匹配表（Next数组），它用于记录字符串的前缀和后缀的最长公共前缀的长度。这个数组可以帮助算法在匹配失败时，快速确定下一步的匹配位置。

#### 伪代码

以下是KMP算法的伪代码：

```pseudocode
function KMP(string s, string p)
    build partial match table (Next) for pattern p
    i = 0 (index for s)
    j = 0 (index for p)
    while i < length(s)
        if s[i] == p[j]
            i += 1
            j += 1
        else
            if j != 0
                j = next[j]
            else
                i += 1
        end if
        if j == length(p)
            return i - j
            j = next[j]
        end if
    end while
    return -1 (not found)
end function
```

#### 部分匹配表的构建

构建Next数组的方法如下：

```pseudocode
function buildNext(p)
    n = length(p)
    next = array of length n filled with 0
    j = 0
    i = 1
    while i < n
        if p[j] == p[i]
            next[i] = j + 1
            j += 1
            i += 1
        else
            if j != 0
                j = next[j - 1]
            else
                next[i] = 0
                i += 1
            end if
        end if
    end while
end function
```

### Rabin-Karp算法

Rabin-Karp算法是一种基于哈希函数的字符串匹配算法，由Richard M. Karp和Michael O. Rabin提出。该算法通过计算文本字符串和模式字符串的哈希值，快速定位模式字符串在文本字符串中的位置。

#### 核心思想

Rabin-Karp算法的核心思想是使用哈希函数快速比较字符串，而不是逐个字符比较。当哈希值不相等时，可以立即跳过不匹配的部分，从而提高匹配速度。

#### 伪代码

以下是Rabin-Karp算法的伪代码：

```pseudocode
function RabinKarp(s, p)
    h(s) = hash of s
    h(p) = hash of p
    q = large prime number
    t = h(s[0..m-1])
    for i = 0 to n-m
        if t == h(p)
            compare s[i..i+m-1] with p
        end if
        if i < n-m
            t = (t - s[i] * q) * q + s[i+m]
            if t < 0
                t += q
            end if
        end if
    end for
end function
```

#### 哈希函数的选择

哈希函数的选择对算法的性能有很大影响。通常选择一个简单但高效的哈希函数，并使用大质数`q`来避免冲突。例如：

```pseudocode
function hash(char c)
    return ASCII value of c
end function
```

#### 冲突处理

当两个不同的字符串具有相同的哈希值时，即发生冲突。Rabin-Karp算法使用`q`来处理冲突，确保在哈希值相等时进行字符比较。

### 大数定律

大数定律是概率论中的一个基本原理，它描述了在大量重复实验中，随机变量的一些统计特性会趋于其数学期望。大数定律主要有两种形式：

1. **切比雪夫不等式**：
   - **定义**：设随机变量 \( X \) 的期望为 \( \mu \)，方差为 \( \sigma^2 \)，则对于任意正数 \( \epsilon \)，都有
     \[
     P\left(\left| X - \mu \right| \geq \epsilon\right) \leq \frac{\sigma^2}{\epsilon^2}
     \]
   - **解释**：这意味着当样本量增大时，样本均值与总体均值之间的偏差概率会减小。

2. **大数定律**：
   - **定义**：设 \( X_1, X_2, \ldots, X_n \) 是相互独立且具有相同分布的随机变量序列，每个随机变量的期望为 \( \mu \)，则样本均值
     \[
     \bar{X}_n = \frac{X_1 + X_2 + \ldots + X_n}{n}
     \]
     将随着 \( n \) 的增大趋向于 \( \mu \)。
   - **解释**：这意味着在大量重复实验中，样本均值将接近总体均值。

### 中心极限定理

中心极限定理是概率论中的一个重要定理，它描述了在随机变量之和（或平均值）的分布接近正态分布的条件下，正态分布的适用范围。

- **定义**：设 \( X_1, X_2, \ldots, X_n \) 是独立同分布的随机变量，且每个随机变量的期望为 \( \mu \)，方差为 \( \sigma^2 \)，则当 \( n \) 趋于无穷大时，样本均值的分布函数将接近标准正态分布：
  \[
  \frac{\bar{X}_n - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} N(0,1)
  \]
- **解释**：这意味着大量独立随机变量的平均值的分布将趋于正态分布，这在统计学和算法分析中具有重要意义。

### 面试题1：最长公共子序列（LCS）

**问题描述**：给定两个字符串 `str1` 和 `str2`，找出它们的最长公共子序列。

**解题思路**：使用动态规划求解最长公共子序列问题。创建一个二维数组 `dp`，其中 `dp[i][j]` 表示 `str1` 的前 `i` 个字符和 `str2` 的前 `j` 个字符的最长公共子序列的长度。

**伪代码**：

```pseudocode
function LCS(str1, str2)
    m = length(str1)
    n = length(str2)
    dp = array of size (m+1) x (n+1) filled with 0
    for i = 1 to m
        for j = 1 to n
            if str1[i-1] == str2[j-1]
                dp[i][j] = dp[i-1][j-1] + 1
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
            end if
        end for
    end for
    return dp[m][n]
end function
```

**代码实现**：

```python
def lcs(str1, str2):
    m, n = len(str1), len(str2)
    dp = [[0] * (n+1) for _ in range(m+1)]

    for i in range(1, m+1):
        for j in range(1, n+1):
            if str1[i-1] == str2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

### 面试题2：单源最短路径（Dijkstra算法）

**问题描述**：给定一个无权图，从源点 `src` 开始，求出到达其他所有顶点的最短路径。

**解题思路**：使用Dijkstra算法求解单源最短路径问题。算法使用一个优先队列来选择当前未处理的顶点，每次选择具有最小距离的顶点，并更新其他顶点的最短路径。

**伪代码**：

```pseudocode
function Dijkstra(graph, src)
    distances = array of size V filled with INFINITY
    distances[src] = 0
    priorityQueue = new PriorityQueue()
    priorityQueue.enqueue((src, distances[src])
    while priorityQueue is not empty
        (vertex, dist) = priorityQueue.dequeue()
        for neighbor in graph[vertex].neighbors
            if distances[vertex] + graph[vertex].weight(neighbor) < distances[neighbor]
                distances[neighbor] = distances[vertex] + graph[vertex].weight(neighbor)
                priorityQueue.enqueue((neighbor, distances[neighbor])
        end for
    end while
    return distances
end function
```

**代码实现**：

```python
import heapq

def dijkstra(graph, src):
    distances = [float('inf')] * len(graph)
    distances[src] = 0
    priority_queue = [(0, src)]

    while priority_queue:
        current_dist, current_vertex = heapq.heappop(priority_queue)

        if current_dist > distances[current_vertex]:
            continue

        for neighbor, weight in graph[current_vertex].items():
            distance = current_dist + weight

            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

### 面试题3：最长递增子序列（LIS）

**问题描述**：给定一个整数数组 `nums`，找出最长递增子序列的长度。

**解题思路**：使用动态规划求解最长递增子序列问题。定义一个数组 `dp`，其中 `dp[i]` 表示以 `nums[i]` 为结尾的最长递增子序列的长度。

**伪代码**：

```pseudocode
function LIS(nums)
    n = length(nums)
    dp = array of length n filled with 1
    for i = 1 to n
        for j = 0 to i - 1
            if nums[j] < nums[i]
                dp[i] = max(dp[i], dp[j] + 1)
    end for
    return max(dp)
end function
```

**代码实现**：

```python
def lis(nums):
    n = len(nums)
    dp = [1] * n

    for i in range(1, n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)
```

### 面试题4：最大子序列和（Kadane算法）

**问题描述**：给定一个整数数组 `nums`，找出连续子序列的最大和。

**解题思路**：使用Kadane算法求解最大子序列和问题。算法通过遍历数组，维护当前子序列的和，并在遇到负数时重置子序列的开始位置。

**伪代码**：

```pseudocode
function MaxSubArray(nums)
    maxSum = nums[0]
    currentSum = nums[0]
    for i = 1 to length(nums)
        currentSum = max(nums[i], currentSum + nums[i])
        maxSum = max(maxSum, currentSum)
    end for
    return maxSum
end function
```

```python
def max_sub_array(nums):
    max_sum = current_sum = nums[0]

    for i in range(1, len(nums)):

        max_sum = max(max_sum, current_sum)
```
