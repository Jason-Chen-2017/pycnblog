## 2.1 风险管理中的数学模型

风险管理是金融领域中的核心任务之一。数学模型在风险识别、评估和管理中起到了关键作用。以下将介绍几种常见的数学模型在风险管理中的应用。

### 2.1.1 信用风险评估

信用风险评估是银行和金融机构在贷款决策中面临的重要问题。通过建立信用评分模型，银行可以评估客户的信用风险，从而决定是否发放贷款以及贷款的额度。以下将介绍两种常见的信用评分模型：逻辑回归和决策树。

#### 2.1.1.1 传统信用评分模型

逻辑回归是一种经典的信用评分模型，它基于客户的历史数据和信用记录，建立客户的信用评分。逻辑回归模型的原理如下：

给定客户的特征向量 \(X = (X_1, X_2, ..., X_n)\)，其中 \(X_i\) 表示第 \(i\) 个特征，假设客户的信用评分 \(Y\) 是一个二元变量，取值为0或1，0表示不良信用，1表示良好信用。逻辑回归模型通过建立 \(Y\) 与 \(X\) 之间的线性关系，计算客户的信用评分。

逻辑回归模型的公式为：

\[
\ln\left(\frac{P(Y=1|X)}{1-P(Y=1|X)}\right) = \beta_0 + \beta_1X_1 + \beta_2X_2 + ... + \beta_nX_n
\]

其中，\(\beta_0, \beta_1, \beta_2, ..., \beta_n\) 是模型的参数，可以通过最大似然估计方法进行估计。

以下是一个使用Python实现的逻辑回归模型：

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression

# 加载数据
data = pd.read_csv('credit_data.csv')
X = data.iloc[:, :-1].values
y = data.iloc[:, -1].values

# 初始化逻辑回归模型
model = LogisticRegression()

# 模型训练
model.fit(X, y)

# 模型预测
predictions = model.predict(X)

# 模型评估
accuracy = np.mean(predictions == y)
print(f'Model accuracy: {accuracy:.2f}')
```

#### 2.1.1.2 机器学习在信用评分中的应用

随着机器学习技术的发展，越来越多的金融机构开始采用机器学习算法进行信用评分。机器学习算法可以更好地捕捉复杂的数据特征，从而提高信用评分的准确性。以下将介绍一种常见的机器学习算法：随机森林。

随机森林是一种基于决策树的集成学习方法。它通过构建多棵决策树，并将它们的预测结果进行投票，得到最终的预测结果。随机森林的原理如下：

给定客户的特征向量 \(X = (X_1, X_2, ..., X_n)\)，随机森林通过以下步骤构建决策树：

1. 从特征集合中随机选择 \(m\) 个特征。
2. 根据这 \(m\) 个特征，在训练数据上构建一棵决策树。
3. 重复步骤1和步骤2，构建多棵决策树。

以下是一个使用Python实现的随机森林模型：

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier

# 加载数据
data = pd.read_csv('credit_data.csv')
X = data.iloc[:, :-1].values
y = data.iloc[:, -1].values

# 初始化随机森林模型
model = RandomForestClassifier(n_estimators=100)

# 模型训练
model.fit(X, y)

# 模型预测
predictions = model.predict(X)

# 模型评估
accuracy = np.mean(predictions == y)
print(f'Model accuracy: {accuracy:.2f}')
```

### 2.1.2 风险度量与资本管理

风险度量是金融机构在风险管理中的重要任务。风险度量模型可以帮助金融机构了解可能发生的最大损失和损失分布，从而制定有效的风险控制策略。以下将介绍两种常用的风险度量模型：VaR（Value at Risk）和CVaR（Conditional Value at Risk）。

#### 2.1.2.1 VaR模型

VaR（Value at Risk）是一种常用的风险度量模型，用于评估在给定置信水平下可能发生的最大损失。VaR的原理如下：

给定一个投资组合的收益序列 \{R_t\}，在置信水平 \(\alpha\) 下，VaR表示为：

\[
VaR = \inf\{x | P(R_t \leq x) \geq 1 - \alpha\}
\]

其中，\(P(R_t \leq x)\) 表示在置信水平 \(\alpha\) 下，投资组合收益小于或等于 \(x\) 的概率。

以下是一个使用Python实现的VaR模型：

```python
import numpy as np
from scipy.stats import norm

# 加载数据
data = pd.read_csv('portfolio_data.csv')
portfolio_returns = data['return'].values

# 计算均值和标准差
mu = np.mean(portfolio_returns)
sigma = np.std(portfolio_returns)

# 计算VaR
alpha = 0.05
z_score = norm.ppf(1 - alpha)
VaR = mu + z_score * sigma
print(f'1-day VaR: {VaR:.2f}')
```

#### 2.1.2.2 CVaR模型

CVaR（Conditional Value at Risk）是一种补充VaR的模型，它衡量在给定置信水平下，超过VaR值的平均损失。CVaR的原理如下：

给定一个投资组合的收益序列 \{R_t\}，在置信水平 \(\alpha\) 下，CVaR表示为：

\[
CVaR = \frac{1}{1 - \alpha} \int_{VaR}^{+\infty} [R_t - VaR] dP
\]

以下是一个使用Python实现的CVaR模型：

```python
import numpy as np
from scipy.stats import norm

# 加载数据
data = pd.read_csv('portfolio_data.csv')
portfolio_returns = data['return'].values

# 计算均值和标准差
mu = np.mean(portfolio_returns)
sigma = np.std(portfolio_returns)

# 计算VaR
alpha = 0.05
z_score = norm.ppf(1 - alpha)
VaR = mu + z_score * sigma

# 计算CVaR
prob_exceed_VaR = norm.cdf((VaR - mu) / sigma)
CVaR = (1 - prob_exceed_VaR) * VaR / (1 - alpha)
print(f'1-day CVaR: {CVaR:.2f}')
```

#### 2.1.2.3 累计风险度量方法

累计风险度量方法（Aggregate Risk Measures）是一种用于评估投资组合整体风险的模型。常见的累计风险度量方法包括最大累积损失（Maximum Loss）、累积期望损失（Aggregate Expected Loss）和累积VaR（Aggregate VaR）等。

以下是一个使用Python实现的累计VaR模型：

```python
import numpy as np
from scipy.stats import norm

# 加载数据
data = pd.read_csv('portfolio_data.csv')
portfolio_returns = data['return'].values

# 计算均值和标准差
mu = np.mean(portfolio_returns)
sigma = np.std(portfolio_returns)

# 计算投资组合的累计VaR
alpha = 0.05
z_score = norm.ppf(1 - alpha)
VaR = mu + z_score * sigma

# 计算累计VaR
prob_exceed_VaR = norm.cdf((VaR - mu) / sigma)
num_assets = portfolio_returns.size
cumulative_VaR = VaR * (1 - prob_exceed_VaR) / (1 - alpha)
print(f'1-day cumulative VaR: {cumulative_VaR:.2f}')
```

#### 2.1.4.1 蒙特卡罗模拟

蒙特卡罗模拟是一种通过模拟随机过程来评估风险和不确定性的方法。在风险管理中，蒙特卡罗模拟可以用于计算投资组合的VaR和CVaR等指标。

以下是一个使用Python实现的蒙特卡罗模拟案例：

```python
import numpy as np
import pandas as pd
from scipy.stats import norm

# 加载数据
data = pd.read_csv('risk_data.csv')
portfolio_returns = data['return'].values

# 蒙特卡罗模拟
num_simulations = 1000
simulated_returns = np.random.normal(mu, sigma, num_simulations)

# 计算VaR和CVaR
alpha = 0.05
VaR = np.percentile(simulated_returns, 100 * (1 - alpha))
prob_exceed_VaR = np.mean(simulated_returns > VaR)
CVaR = (1 - prob_exceed_VaR) * VaR / (1 - alpha)

# 输出结果
print(f'1-day VaR: {VaR:.2f}')
print(f'1-day CVaR: {CVaR:.2f}')
```

#### 2.1.4.2 情境分析

情境分析是一种用于评估不同情境下风险和收益的方法。通过模拟不同的市场情景，情境分析可以帮助金融机构了解不同情境下的风险暴露，从而制定有效的风险管理策略。

以下是一个使用Python实现的情境分析案例：

```python
import numpy as np
import pandas as pd
from scipy.stats import norm

# 加载数据
data = pd.read_csv('risk_data.csv')
portfolio_returns = data['return'].values

# 情境分析
alpha = 0.05
num_senarios = 10
scenarios = np.random.normal(mu, sigma, num_senarios)

# 计算VaR和CVaR
VaR_senarios = [mu + z_score * sigma for z_score in norm.ppf(1 - alpha)]
CVaR_senarios = [(1 - prob_exceed_VaR) * VaR for prob_exceed_VaR in norm.cdf((scenarios - mu) / sigma)]

# 输出结果
print(f'VaR by scenario: {VaR_senarios}')
print(f'CVaR by scenario: {CVaR_senarios}')
```

#### 2.2.1.1 时间序列分析

时间序列分析是一种用于分析时间序列数据的方法。在股票市场预测中，时间序列分析可以用于分析股票价格的历史数据，识别价格趋势和周期性变化。以下将介绍一种常见的时间序列分析方法：移动平均法。

移动平均法是一种通过计算股票价格的历史平均值来预测未来价格的方法。移动平均法分为简单移动平均（SMA）和指数移动平均（EMA）。

以下是一个使用Python实现的简单移动平均法：

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 加载数据
data = pd.read_csv('stock_data.csv')
prices = data['close'].values

# 计算移动平均
window = 5
sma = np.convolve(prices, np.ones(window), 'same') / window

# 模型训练
model = LinearRegression()
model.fit(sma.reshape(-1, 1), prices.reshape(-1, 1))

# 模型预测
predictions = model.predict(sma.reshape(-1, 1))

# 模型评估
mse = np.mean((predictions - prices)**2)
print(f'MSE: {mse:.2f}')
```

### 2.2.2 期权定价

期权定价是金融领域中的一个重要任务。期权定价模型用于计算期权的理论价格，为期权交易提供依据。以下将介绍几种常见的期权定价模型：Black-Scholes模型、二叉树模型和蒙特卡罗模拟。

#### 2.2.2.1 Black-Scholes模型

Black-Scholes模型是一种经典的期权定价模型，它基于无套利原理，用于计算欧式期权的理论价格。Black-Scholes模型的公式如下：

\[
C(S, t) = S_0N(d_1) - Ke^{-r(T-t)}N(d_2)
\]

其中，\(C(S, t)\) 表示欧式看涨期权的理论价格，\(S_0\) 表示当前股票价格，\(K\) 表示期权的执行价格，\(r\) 表示无风险利率，\(T\) 表示期权到期时间，\(N(\cdot)\) 是累积标准正态分布函数，\(d_1\) 和 \(d_2\) 分别为：

\[
d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}
\]
\[
d_2 = d_1 - \sigma\sqrt{T-t}
\]

以下是一个使用Python实现的Black-Scholes模型：

```python
import numpy as np
from scipy.stats import norm

# 参数设置
S0 = 100
K = 100
r = 0.05
T = 1
sigma = 0.2

# 计算d1和d2
d1 = (np.log(S0/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
d2 = d1 - sigma*np.sqrt(T)

# 计算看涨期权价格
C = S0*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d2)

# 输出结果
print(f'Call Option Price: {C:.2f}')
```

#### 2.2.2.2 二叉树模型

二叉树模型是一种用于计算欧式期权的理论价格的简单方法。二叉树模型假设股票价格在时间步长 \(\Delta t\) 内以概率 \(p\) 上升，以概率 \(1-p\) 下降。

以下是一个使用Python实现的二叉树模型：

```python
import numpy as np

# 参数设置
S0 = 100
K = 100
r = 0.05
T = 1
sigma = 0.2
u = np.exp(sigma * np.sqrt(T))
d = 1 / u
p = (np.exp(r * T) - d) / (u - d)

# 计算节点价格
node_prices = [0]
for t in range(int(T / \Delta t)):
    new_prices = []
    for price in node_prices:
        new_prices.append(price * u)
        new_prices.append(price * d)
    node_prices = new_prices

# 计算期权价格
C = 0
for price in node_prices:
    C += np.max([0, price - K]) * p

# 输出结果
print(f'Call Option Price: {C:.2f}')
```

#### 2.2.2.3 蒙特卡罗模拟

蒙特卡罗模拟是一种用于计算期权理论价格的数值方法。通过模拟大量的股票价格路径，蒙特卡罗模拟可以计算期权的期望收益，从而估算期权的理论价格。

以下是一个使用Python实现的蒙特卡罗模拟：

```python

```

### 2.3.1 货币市场工具定价

货币市场工具，如债券、存单和回购协议，是金融市场中重要的投资工具。数学模型在货币市场工具的定价中发挥了重要作用。以下将介绍债券定价和存单定价。

#### 2.3.1.1 债券定价

债券是一种固定收益证券，其价格取决于市场利率、债券期限和债券评级等因素。债券定价的基本原理如下：

假设一只债券的面值为 \(F\)，票面利率为 \(c\)，债券期限为 \(T\)，当前市场利率为 \(r\)。债券的价格 \(P\) 可以通过以下公式计算：

\[
P = \frac{c * (1 - (1 + r)^{-T})}{r} + \frac{F}{(1 + r)^T}
\]

以下是一个使用Python实现的债券定价模型：

```python
import numpy as np

# 参数设置
F = 1000
c = 0.05
T = 5
r = 0.03

# 计算债券价格
P = (c * (1 - (1 + r)**(-T))) / r + F / (1 + r)**T

# 输出结果
print(f'Bond Price: {P:.2f}')
```

#### 2.3.1.2 存单定价

存单是一种短期存款工具，其价格取决于存款期限、存款利率和市场利率等因素。存单定价的基本原理如下：

假设一只存单的本金为 \(P\)，存款期限为 \(T\)，存款利率为 \(r\)，当前市场利率为 \(r_m\)。存单的价格 \(P'\) 可以通过以下公式计算：

\[
P' = P * (1 + r)^{-T} * (1 + r_m)^{-T}
\]

以下是一个使用Python实现的存单定价模型：

```python
import numpy as np

# 参数设置

T = 3
r = 0.05
r_m = 0.04

# 输出结果
print(f'SCertificate of Deposit Price: {P':.2f}')
```

### 2.3.2 债券市场定价

债券市场是金融市场中重要的组成部分，债券市场的定价对整个金融市场的稳定和发展具有重要意义。以下将介绍债券市场定价的方法和策略。

#### 2.3.2.1 利率期限结构模型

利率期限结构模型用于分析市场利率的期限结构，从而为债券市场定价提供依据。常见的利率期限结构模型包括零息债券模型和收益率曲线模型。

零息债券模型假设市场利率是恒定的，通过计算零息债券的价格，可以推导出市场利率的期限结构。以下是一个使用Python实现的零息债券模型：

```python
import numpy as np
from scipy.optimize import fsolve

# 参数设置
F = 1000
r = 0.05
T = 5

# 零息债券价格函数
def bond_price(T, r):
    return F / (1 + r)**T

# 计算市场利率
def market_interest_rate(T, P):
    return (F - P) / (F * T)

# 求解市场利率
P0 = bond_price(T, r)
r0 = market_interest_rate(T, P0)
r = fsolve(market_interest_rate, r0, args=(P0,))

# 输出结果
print(f'Market Interest Rate: {r[0]:.2f}%')
```

收益率曲线模型假设市场利率是随时间变化的，通过拟合收益率曲线，可以推导出市场利率的期限结构。以下是一个使用Python实现的收益率曲线模型：

```python
import numpy as np
from scipy.optimize import curve_fit

# 参数设置
data = pd.read_csv('yield_data.csv')
yields = data['yield'].values
times = data['time'].values

# 收益率曲线拟合函数
def yield_curve(time, a, b, c):
    return a * (1 + b)**time + c

# 拟合收益率曲线
params, cov = curve_fit(yield_curve, times, yields)

# 计算市场利率
market_interest_rates = yield_curve(times, *params)

# 输出结果
print(f'Market Interest Rates: {market_interest_rates}')
```

#### 2.3.2.2 债券交易策略

债券交易策略是债券市场中的重要内容，通过分析债券市场的价格波动，可以制定有效的交易策略。以下将介绍几种常见的债券交易策略：摊销策略、反向套利策略和利率掉期策略。

- **摊销策略**：摊销策略是指通过买入低利率债券，并在债券到期时收回本金，从而实现收益的一种策略。摊销策略的基本原理如下：

  假设当前市场利率为 \(r_0\)，债券的到期收益率为 \(r\)，债券的面值为 \(F\)。摊销策略的成本为 \(C_0\)，摊销策略的收益为 \(R\)。摊销策略的成本和收益可以通过以下公式计算：

  \[
  C_0 = \frac{F - F * (1 + r_0)^{-T}}{r_0}
  \]
  \[
  R = \frac{F - F * (1 + r)^{-T}}{r}
  \]

  摊销策略的收益率为 \(r_1\)，可以通过以下公式计算：

  \[
  r_1 = \frac{R - C_0}{C_0}
  \]

  以下是一个使用Python实现的摊销策略：

  ```python
  import numpy as np

  # 参数设置
  F = 1000
  r = 0.05
  r_0 = 0.03
  T = 5

  # 计算摊销策略的成本和收益
  C_0 = (F - F * (1 + r_0)**(-T)) / r_0
  R = (F - F * (1 + r)**(-T)) / r

  # 计算摊销策略的收益率
  r_1 = (R - C_0) / C_0

  # 输出结果
  print(f'Discount Rate: {r_1:.2f}%')
  ```

- **反向套利策略**：反向套利策略是指通过发现市场利率的偏差，通过买卖债券来实现无风险收益的一种策略。反向套利策略的基本原理如下：

  假设当前市场利率为 \(r_0\)，债券的到期收益率为 \(r\)，债券的面值为 \(F\)。反向套利策略的成本为 \(C_0\)，收益为 \(R_0\)。反向套利策略的成本和收益可以通过以下公式计算：

  \[
  C_0 = \frac{F - F * (1 + r_0)^{-T}}{r_0}
  \]
  \[
  R_0 = \frac{F - F * (1 + r)^{-T}}{r}
  \]

  反向套利策略的收益率为 \(r_1\)，可以通过以下公式计算：

  \[
  r_1 = \frac{R_0 - C_0}{C_0}
  \]

  以下是一个使用Python实现的反向套利策略：

  ```python
  import numpy as np

  # 参数设置
  F = 1000
  r = 0.05
  r_0 = 0.03
  T = 5

  # 计算反向套利策略的成本和收益
  C_0 = (F - F * (1 + r_0)**(-T)) / r_0
  R_0 = (F - F * (1 + r)**(-T)) / r

  # 计算反向套利策略的收益率
  r_1 = (R_0 - C_0) / C_0

  # 输出结果
  print(f'Reverse Arbitrage Rate: {r_1:.2f}%')
  ```

- **利率掉期策略**：利率掉期策略是指通过交易利率掉期合约，实现固定利率和浮动利率互换的一种策略。利率掉期策略的基本原理如下：

  假设一方支付固定利率 \(r_1\)，另一方支付浮动利率 \(r_2\)。利率掉期策略的成本为 \(C_0\)，收益为 \(R_0\)。利率掉期策略的成本和收益可以通过以下公式计算：

  \[
  C_0 = \frac{F * (r_1 - r_2) * T}{1}
  \]
  \[
  R_0 = \frac{F * (r_1 - r_2) * T}{1}
  \]

  利率掉期策略的收益率为 \(r_1\)，可以通过以下公式计算：

  \[
  r_1 = \frac{R_0 - C_0}{C_0}
  \]

  以下是一个使用Python实现的利率掉期策略：

  ```python
  import numpy as np

  # 参数设置
  F = 1000
  r_1 = 0.05
  r_2 = 0.03
  T = 5

  # 计算利率掉期策略的成本和收益
  C_0 = F * (r_1 - r_2) * T
  R_0 = F * (r_1 - r_2) * T

  # 计算利率掉期策略的收益率
  r_1 = (R_0 - C_0) / C_0

  # 输出结果
  print(f'Interest Rate Swap Rate: {r_1:.2f}%')
  ```

### 2.3.3 保险精算

保险精算是保险领域中的重要任务，用于计算保险产品的保费和风险准备金。数学模型在保险精算中发挥了关键作用。以下将介绍几种常见的数学模型在保险精算中的应用。

#### 2.3.3.1 生命表与利差

生命表是一种用于计算人口寿命分布的表格。生命表提供了不同年龄人口的死亡率、生存率和平均寿命等信息。利差是指保险产品的保费和风险准备金之间的差额。以下将介绍生命表和利差的计算方法。

生命表的计算方法如下：

- 死亡率：死亡率是指在一定时间内，死亡人数与总人数之比。死亡率可以通过以下公式计算：

  \[
  \frac{D_t}{N_t} = \frac{\text{死亡人数}}{\text{总人数}}
  \]

  其中，\(D_t\) 是死亡人数，\(N_t\) 是总人数。

- 生存率：生存率是指在一定时间内，未死亡人数与总人数之比。生存率可以通过以下公式计算：

  \[
  \frac{S_t}{N_t} = \frac{\text{未死亡人数}}{\text{总人数}}
  \]

  其中，\(S_t\) 是未死亡人数。

- 平均寿命：平均寿命是指一个人从出生到死亡的平均年龄。平均寿命可以通过以下公式计算：

  \[
  \text{平均寿命} = \frac{\sum_{t=1}^{T} t \cdot S_t}{\sum_{t=1}^{T} S_t}
  \]

  其中，\(T\) 是寿命周期。

以下是一个使用Python实现的生命表计算：

```python
import numpy as np

# 参数设置
N_0 = 100000  # 初始人口
D_0 = 5000    # 初始死亡人数
T = 50        # 寿命周期

# 死亡率
death_rate = D_0 / N_0

# 生存率
survival_rate = 1 - death_rate

# 平均寿命
average_life_expectancy = np.mean([t * survival_rate for t in range(1, T+1)])

# 输出结果
print(f'Death Rate: {death_rate:.2f}')
print(f'Survival Rate: {survival_rate:.2f}')
print(f'Average Life Expectancy: {average_life_expectancy:.2f}')
```

利差的计算方法如下：

- 保费：保费是指保险公司向投保人收取的保险费用。保费可以通过以下公式计算：

  \[
  \text{保费} = \frac{D_t \cdot r_t}{N_t}
  \]

  其中，\(D_t\) 是死亡人数，\(r_t\) 是利率，\(N_t\) 是总人数。

- 风险准备金：风险准备金是指保险公司用于应对未来可能发生的赔偿支出。风险准备金可以通过以下公式计算：

  \[
  \text{风险准备金} = \frac{D_t \cdot r_t \cdot (1 + r_t)}{N_t}
  \]

  其中，\(D_t\) 是死亡人数，\(r_t\) 是利率，\(N_t\) 是总人数。

以下是一个使用Python实现的利差计算：

```python
import numpy as np

# 参数设置
N_0 = 100000  # 初始人口
D_0 = 5000    # 初始死亡人数
r = 0.05      # 利率

# 保费
premium = D_0 * r / N_0

# 风险准备金
risk_reserve = D_0 * r * (1 + r) / N_0

# 利差
commission = premium - risk_reserve

# 输出结果
print(f'Premium: {premium:.2f}')
print(f'Risk Reserve: {risk_reserve:.2f}')
print(f'Commission: {commission:.2f}')
```

#### 2.3.5.1 案例一：债券定价与交易

假设一家公司发行了一只5年期的债券，票面利率为5%，当前市场利率为4%。我们需要计算该债券的价格，并分析不同市场利率下的债券价格变化。

以下是一个使用Python实现的债券定价与交易：

```python
import numpy as np

# 参数设置
F = 1000  # 债券面值
c = 0.05  # 票面利率
T = 5  # 期限
r = 0.04  # 市场利率

# 计算债券价格
P = (c * (1 - (1 + r)**(-T))) / r + F / (1 + r)**T

# 输出结果
print(f'Bond Price: {P:.2f}')

# 分析不同市场利率下的债券价格变化
rates = np.linspace(0.02, 0.08, 100)
prices = [((c * (1 - (1 + rate)**(-T))) / rate + F / (1 + rate)**T) for rate in rates]

import matplotlib.pyplot as plt

plt.plot(rates, prices)
plt.xlabel('Market Interest Rate')
plt.ylabel('Bond Price')
plt.title('Bond Price vs Market Interest Rate')
plt.grid(True)
plt.show()
```
