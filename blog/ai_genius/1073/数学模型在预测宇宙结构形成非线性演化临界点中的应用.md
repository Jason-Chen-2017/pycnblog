### 1.5 数学模型和公式

在宇宙结构形成的非线性演化研究中，数学模型和公式起着核心作用。以下是几个关键模型和公式的详细解释和示例。

#### 1.5.1 牛顿引力公式

牛顿引力公式描述了两个质点之间的引力：

$$ F = G \frac{m_1 m_2}{r^2} $$

其中，\( F \) 是引力大小，\( G \) 是引力常数，\( m_1 \) 和 \( m_2 \) 是两个质点的质量，\( r \) 是它们之间的距离。

#### 1.5.2 洛伦兹力公式

在相对论框架下，洛伦兹力公式描述了带电粒子在电磁场中的受力情况：

$$ F = q(E + v \times B) $$

其中，\( F \) 是洛伦兹力，\( q \) 是粒子的电荷，\( E \) 是电场强度，\( v \) 是粒子的速度，\( B \) 是磁场强度。

#### 1.5.3 混沌吸引子公式

混沌吸引子是描述混沌系统长期行为的一个概念。一个典型的混沌吸引子公式如下：

$$ x_{n+1} = r x_n (1 - x_n) $$

其中，\( x_n \) 是第 \( n \) 次迭代的值，\( r \) 是控制参数。这个公式展示了系统如何在边界内无限复杂地迭代。

### 2.2 源代码实现与解读

```python
import numpy as np
import matplotlib.pyplot as plt

# 初始化天体
def initialize_bodies():
    # 生成随机位置和速度
    positions = np.random.rand(2, 100) * 100
    velocities = np.random.rand(2, 100) * 10
    return positions, velocities

# 计算引力
def calculate_gravities(bodies):
    # 获取位置和速度
    positions, velocities = bodies
    # 计算每个天体之间的引力
    for i in range(len(positions)):
        for j in range(i+1, len(positions)):
            # 计算距离
            distance = np.linalg.norm(positions[i] - positions[j])
            # 计算引力
            force = G * (masses[i] * masses[j]) / distance**2
            # 更新速度
            velocities[i] -= (positions[j] - positions[i]) * force / masses[i]
            velocities[j] += (positions[i] - positions[j]) * force / masses[j]

# 更新位置和速度
def update_positions_and_velocities(bodies, time_step=0.01):
    # 获取位置和速度
    positions, velocities = bodies
    # 更新位置
    positions += velocities * time_step
    # 更新速度
    calculate_gravities(bodies)

# 记录状态
def record_state(bodies, time_step):
    # 获取当前状态
    positions, velocities = bodies
    # 记录到文件
    with open(f"state_{time_step}.txt", "w") as f:
        for i in range(len(positions)):
            f.write(f"{positions[i]}, {velocities[i]}\n")

# 模拟过程
def run_simulation(steps=1000):
    # 初始化天体
    bodies = initialize_bodies()
    # 运行模拟
    for step in range(steps):
        # 计算引力
        calculate_gravities(bodies)
        # 更新位置和速度
        update_positions_and_velocities(bodies)
        # 记录状态
        record_state(bodies, step)

# 运行模拟
run_simulation()
