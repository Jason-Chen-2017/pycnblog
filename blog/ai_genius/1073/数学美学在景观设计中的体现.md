## 第1章 数学美学的基本原理

### 1.1 对称与平衡

对称与平衡是数学美学中的两个核心概念。对称性指的是物体或图形在某个轴、点或平面上的镜像对称。对称性在自然界和艺术作品中广泛存在，如蝴蝶的翅膀、人脸的对称、建筑的结构等。平衡则强调各个元素之间的协调与和谐，使整个设计达到一种稳定的状态。

对称性在景观设计中的应用非常广泛。例如，在园林设计中，对称的布局可以创造出宏伟、庄重的氛围。在公园设计中，对称的水体布局可以增加空间的层次感和韵律感。对称性的运用不仅可以提升景观设计的审美价值，还能增强空间的记忆点。

平衡则强调各个元素之间的协调。在景观设计中，平衡可以通过多种方式实现。例如，通过植被的合理配置，可以实现空间视觉上的平衡；通过水体的分布，可以实现功能上的平衡。平衡的景观设计不仅具有美感，还能提升用户的舒适度和满意度。

### 1.2 比例与和谐

比例是数学美学中的另一个重要概念。比例指的是物体或图形之间的大小、长度、宽度等关系。黄金比例（Golden Ratio，约等于1:1.618）是比例美学中最经典的应用。黄金比例在自然界和艺术作品中广泛存在，如人体的比例、古希腊的帕台农神庙、蒙娜丽莎的构图等。

在景观设计中，比例的应用同样非常重要。合理的设计比例可以创造出舒适、和谐的空间。例如，在园林设计中，树木、灌木、花卉的大小和高度比例要合理，才能形成美观的景观效果。在公园设计中，道路、广场、座椅等元素的尺寸和比例也需要经过精心设计，以达到空间利用的最大化。

和谐是比例美学中的高级概念，强调各个元素之间的协调与统一。和谐不仅涉及比例，还包括色彩、材质、形态等因素。在景观设计中，和谐的设计可以创造出宁静、宜人的空间氛围。例如，通过合理搭配不同颜色的植被，可以创造出丰富的色彩层次感；通过使用不同材质的铺装，可以增加空间的纹理感。

### 1.3 对称与平衡、比例与和谐的关系

对称与平衡、比例与和谐是数学美学中的核心概念，它们之间存在紧密的联系。对称与平衡强调的是物体或图形的内部结构，而比例与和谐则关注物体或图形之间的外部关系。

对称与平衡是实现比例和谐的基础。只有当物体或图形内部达到对称与平衡时，才能在外部形成和谐的比例关系。例如，在园林设计中，首先需要通过对称与平衡的布局来奠定整体结构，然后在此基础上进行比例和和谐的设计。

比例与和谐是对称与平衡的进一步发展。比例通过具体的数据关系来实现对称与平衡，而和谐则通过整体的协调与统一来提升设计的审美价值。在景观设计中，比例与和谐的应用不仅依赖于数学原理，还需要设计师的审美眼光和创造性思维。

## 第3章 数学模型在景观设计中的应用

### 3.1 线性规划模型

线性规划模型是数学模型在景观设计中的一个重要应用。线性规划模型通过建立目标函数和约束条件，可以帮助设计师在满足特定目标的同时，优化资源分配和设计方案。

#### 3.1.1 基本概念

线性规划模型涉及三个主要部分：目标函数、决策变量和约束条件。

- **目标函数**：描述设计目标的具体指标，如最小化成本、最大化美观度等。
- **决策变量**：影响目标函数的变量，如景观元素的尺寸、位置等。
- **约束条件**：限制决策变量的取值范围，确保设计方案的可行性和合理性。

#### 3.1.2 应用实例

在某住宅区的景观设计中，设计师希望通过线性规划模型来优化植被配置，以实现美观度和成本控制的目标。

- **目标函数**：最小化总成本（树木、灌木、花卉的成本之和）。
- **决策变量**：每类植被的种植面积。
- **约束条件**：1. 每类植被的种植面积不能超过其生长空间的限制；2. 总植被面积需满足绿化覆盖率的要求。

通过建立线性规划模型，设计师可以计算出最优的植被配置方案，从而在保证美观度的同时，实现成本的最小化。

```python
import numpy as np
from scipy.optimize import linprog

# 目标函数：最小化总成本
c = [-1, -1, -1]  # 树木、灌木、花卉的成本

# 约束条件
A = [[1, 0, 0, 10],  # 树木种植面积不超过100平方米
     [0, 1, 0, 10],  # 灌木种植面积不超过100平方米
     [0, 0, 1, 10],  # 花卉种植面积不超过100平方米]
B = [10, 10, 10]

# 解线性规划问题
result = linprog(c, A_ub=A, b_ub=B, method='highs')

# 输出结果
print("最优解：", result.x)
print("最小成本：", -result.fun)
```

```python
def fractal_terrain(height, depth, x_size, y_size):
    points = []
    for i in range(depth):
        x = np.random.uniform(0, x_size)
        y = np.random.uniform(0, y_size)
        points.append((x, y, height * (0.5 ** i)))
    return points

# 生成分形喷泉
def generate_fractal_spray(x_size, y_size, depth):
    points = fractal_terrain(1, depth, x_size, y_size)
    for i in range(depth):
        new_points = []
        for point in points:
            x, y, z = point
            new_points.append((x, y, z * (0.5 ** i)))
        points.extend(new_points)
    return points

# 绘制分形喷泉
def plot_fractal_spray(points, x_size, y_size):
    fig, ax = plt.subplots()
    for point in points:
        x, y, z = point
        ax.scatter(x, y, z, marker='o', s=1)
    ax.set_xlim(0, x_size)
    ax.set_ylim(0, y_size)
    ax.set_zlim(0, 1)
    plt.show()

# 测试分形喷泉生成
```
