- **对称差**：集合A和B的对称差，记作A Δ B，是包含所有属于A但不属于B的元素，以及所有属于B但不属于A的元素的集合。

## 第2章：集合的公理与性质

### 2.1 集合的公理系统

集合的公理系统是集合论的基础，它规定了集合的基本性质和运算规则。

### 2.1.1 基本集合公理

基本集合公理包括以下内容：

- **空集存在**：存在一个不包含任何元素的集合，称为空集，记作∅。
- **集合的并集**：对于任意两个集合A和B，它们的并集存在，记作A ∪ B。
- **集合的交集**：对于任意两个集合A和B，它们的交集存在，记作A ∩ B。
- **集合的补集**：对于任意一个集合A，它的补集存在，记作A'。

### 2.1.2 选择公理

选择公理是集合论中一个重要的公理，它保证了集合论中某些重要性质的存在。选择公理的内容如下：

- **存在选择函数**：对于任意集合A的子集族{Bα | α ∈ I}（其中I是一个指标集），存在一个函数f：I → ∪{Bα | α ∈ I}，使得f(α) ∈ Bα 对于所有的α ∈ I。

### 2.1.3 其他公理

其他公理如传递性、自反性等，它们保证了集合论的一致性和完整性。

### 2.2 集合的性质

集合的性质包括并集、交集、补集的基本性质和运算律。

- **结合律**：对于任意三个集合A、B和C，有(A ∪ B) ∪ C = A ∪ (B ∪ C) 和 (A ∩ B) ∩ C = A ∩ (B ∩ C)。
- **交换律**：对于任意两个集合A和B，有A ∪ B = B ∪ A 和 A ∩ B = B ∩ A。
- **分配律**：对于任意三个集合A、B和C，有A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) 和 A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)。
- **德摩根律**：对于任意两个集合A和B，有(A ∪ B)' = A' ∩ B' 和 (A ∩ B)' = A' ∪ B'。

### 2.2.1 并集、交集与补集

并集、交集和补集的基本性质和运算律如下：

- **并集**：对于任意两个集合A和B，有A ∪ B = {x | x ∈ A 或 x ∈ B}。并集的运算满足结合律、交换律和分配律。
- **交集**：对于任意两个集合A和B，有A ∩ B = {x | x ∈ A 且 x ∈ B}。交集的运算满足结合律、交换律和分配律。
- **补集**：对于任意一个集合A，有A' = {x | x ∉ A}。补集的运算满足德摩根律。

### 2.2.2 子集关系与等价关系

子集关系与等价关系的定义与性质如下：

- **子集关系**：若集合A的所有元素都属于集合B，则称A是B的子集，记作A ⊆ B。子集关系具有传递性和交换性。
- **等价关系**：等价关系是一个满足自反性、对称性和传递性的二元关系。对于任意两个集合A和B，如果它们之间存在一个等价关系，则称A和B是等价的。

### 2.2.3 集合的分类

集合的分类方法和分类性质如下：

- **有限集**：若集合中的元素数量有限，则称该集合为有限集。
- **无限集**：若集合中的元素数量无限，则称该集合为无限集。
- **可数集**：若集合中的元素可以与自然数一一对应，则称该集合为可数集。
- **不可数集**：若集合中的元素不能与自然数一一对应，则称该集合为不可数集。

### 4.1.1 并集的定义与性质

并集是指由两个或多个集合中所有元素组成的集合。并集的运算遵循以下性质：

- **结合律**：对于任意三个集合A、B和C，有(A ∪ B) ∪ C = A ∪ (B ∪ C)。
- **交换律**：对于任意两个集合A和B，有A ∪ B = B ∪ A。
- **分配律**：对于任意三个集合A、B和C，有A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)。

### 4.1.2 交集的定义与性质

交集是指由两个或多个集合中共有的元素组成的集合。交集的运算遵循以下性质：

- **结合律**：对于任意三个集合A、B和C，有(A ∩ B) ∩ C = A ∩ (B ∩ C)。
- **交换律**：对于任意两个集合A和B，有A ∩ B = B ∩ A。
- **分配律**：对于任意三个集合A、B和C，有A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)。

### 4.1.3 并集与交集的运算律

并集和交集的运算遵循以下运算律：

- **结合律**：对于任意三个集合A、B和C，有(A ∪ B) ∪ C = A ∪ (B ∪ C) 和 (A ∩ B) ∩ C = A ∩ (B ∩ C)。
- **交换律**：对于任意两个集合A和B，有A ∪ B = B ∪ A 和 A ∩ B = B ∩ A。
- **分配律**：对于任意三个集合A、B和C，有A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) 和 A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)。

### 4.2 集合的补集与对称差

### 4.2.1 补集的定义与性质

补集是指不属于某个集合的所有元素的集合。补集的运算遵循以下性质：

- **结合律**：对于任意三个集合A、B和C，有(A' ∩ B')' = A ∪ B'。
- **交换律**：对于任意两个集合A和B，有A' = B'。
- **德摩根律**：对于任意两个集合A和B，有(A ∪ B)' = A' ∩ B' 和 (A ∩ B)' = A' ∪ B'。

### 4.2.2 对称差的定义与性质

对称差是指由两个集合中属于A但不属于B的元素，以及属于B但不属于A的元素组成的集合。对称差的运算遵循以下性质：

- **结合律**：对于任意三个集合A、B和C，有(A Δ B) Δ C = A Δ (B Δ C)。
- **交换律**：对于任意两个集合A和B，有A Δ B = B Δ A。
- **分配律**：对于任意三个集合A、B和C，有A Δ (B ∩ C) = (A Δ B) ∪ (A Δ C) 和 A Δ (B ∪ C) = (A Δ B) ∩ (A Δ C)。

### 4.2.3 补集与对称差的运算律

补集和对称差的运算遵循以下运算律：

- **结合律**：对于任意三个集合A、B和C，有(A' ∩ B')' = A ∪ B' 和 (A Δ B) Δ C = A Δ (B Δ C)。
- **交换律**：对于任意两个集合A和B，有A' = B' 和 A Δ B = B Δ A。

- **分配律**：对于任意三个集合A、B和C，有A Δ (B ∩ C) = (A Δ B) ∪ (A Δ C) 和 A Δ (B ∪ C) = (A Δ B) ∩ (A Δ C)。

### 1.1 集合的定义与性质

集合是由若干确定的元素组成的整体，这些元素可以是具体的对象，也可以是抽象的符号。集合的元素具有互异性，即同一个集合中不能有重复的元素。

### 1.1.1 集合的概念

集合的概念是集合论的基础。一个集合可以用大括号“{}”表示，元素之间用逗号分隔。例如，集合A = {1, 2, 3}。

### 1.1.2 集合的表示方法

集合的表示方法主要有列举法和描述法。

- **列举法**：将集合中的所有元素一一列举出来。例如，集合B = {1, 2, 3, 4, 5}。
- **描述法**：用描述性的语言或符号来表示集合。例如，集合C = {x | x 是自然数且 x < 5}，表示集合C中的元素是小于5的自然数。

### 1.1.3 集合的运算

集合的基本运算包括并集、交集、补集和对称差。

- **并集**：集合A和B的并集，记作A ∪ B，是包含所有属于A或属于B的元素的集合。
- **交集**：集合A和B的交集，记作A ∩ B，是包含所有既属于A又属于B的元素的集合。
- **补集**：集合A的补集，记作A'，是包含所有不属于A的元素的集合。
- **对称差**：集合A和B的对称差，记作A Δ B，是包含所有属于A但不属于B的元素，以及所有属于B但不属于A的元素的集合。

### 1.2 子集与真子集

### 1.2.1 子集的定义

### 1.2.2 子集的性质

### 1.2.3 真子集的概念

### 2.2 集合的性质

集合的性质包括并集、交集、补集的基本性质和运算律。

- **结合律**：对于任意三个集合A、B和C，有(A ∪ B) ∪ C = A ∪ (B ∪ C) 和 (A ∩ B) ∩ C = A ∩ (B ∩ C)。

## 第一部分：集合论基础

### 第1章：集合论的基本概念

### 1.1 集合的定义与性质

集合是由若干确定的元素组成的整体，这些元素可以是具体的对象，也可以是抽象的符号。集合的元素具有互异性，即同一个集合中不能有重复的元素。

### 1.1.1 集合的概念

集合的概念是集合论的基础。一个集合可以用大括号“{}”表示，元素之间用逗号分隔。例如，集合A = {1, 2, 3}。

### 1.1.2 集合的表示方法

集合的表示方法主要有列举法和描述法。

- **列举法**：将集合中的所有元素一一列举出来。例如，集合B = {1, 2, 3, 4, 5}。
- **描述法**：用描述性的语言或符号来表示集合。例如，集合C = {x | x 是自然数且 x < 5}，表示集合C中的元素是小于5的自然数。

### 1.1.3 集合的运算

集合的基本运算包括并集、交集、补集和对称差。

- **并集**：集合A和B的并集，记作A ∪ B，是包含所有属于A或属于B的元素的集合。
- **交集**：集合A和B的交集，记作A ∩ B，是包含所有既属于A又属于B的元素的集合。
- **补集**：集合A的补集，记作A'，是包含所有不属于A的元素的集合。
- **对称差**：集合A和B的对称差，记作A Δ B，是包含所有属于A但不属于B的元素，以及所有属于B但不属于A的元素的集合。

### 1.2 子集与真子集

子集是指一个集合是另一个集合的子集，如果它包含的所有元素都属于另一个集合。例如，集合{1, 2}是集合{1, 2, 3}的子集。

### 1.2.1 子集的定义

若集合A中的所有元素都属于集合B，则称A是B的子集，记作A ⊆ B。

### 1.2.2 子集的性质

子集具有传递性和交换性，即若A ⊆ B，B ⊆ C，则A ⊆ C；且A ⊆ B与B ⊆ A等价。

### 1.2.3 真子集的概念

若集合A是集合B的子集，且A不等于B，则称A是B的真子集，记作A ⊊ B。

### 1.3 集合的势

集合的势是指集合中元素的数量，用符号n(A)表示。

## 第2章：集合的公理与性质

### 2.1 集合的公理系统

集合的公理系统是集合论的基础，它规定了集合的基本性质和运算规则。

### 2.1.1 基本集合公理

基本集合公理包括以下内容：

- **空集存在**：存在一个不包含任何元素的集合，称为空集，记作∅。
- **集合的并集**：对于任意两个集合A和B，它们的并集存在，记作A ∪ B。
- **集合的交集**：对于任意两个集合A和B，它们的交集存在，记作A ∩ B。
- **集合的补集**：对于任意一个集合A，它的补集存在，记作A'。

### 2.1.2 选择公理

选择公理是集合论中一个重要的公理，它保证了集合论中某些重要性质的存在。选择公理的内容如下：

- **存在选择函数**：对于任意集合A的子集族{Bα | α ∈ I}（其中I是一个指标集），存在一个函数f：I → ∪{Bα | α ∈ I}，使得f(α) ∈ Bα 对于所有的α ∈ I。

### 2.1.3 其他公理

其他公理如传递性、自反性等，它们保证了集合论的一致性和完整性。

### 2.2 集合的性质

集合的性质包括并集、交集、补集的基本性质和运算律。

- **结合律**：对于任意三个集合A、B和C，有(A ∪ B) ∪ C = A ∪ (B ∪ C) 和 (A ∩ B) ∩ C = A ∩ (B ∩ C)。
- **交换律**：对于任意两个集合A和B，有A ∪ B = B ∪ A 和 A ∩ B = B ∩ A。
- **分配律**：对于任意三个集合A、B和C，有A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) 和 A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)。
- **德摩根律**：对于任意两个集合A和B，有(A ∪ B)' = A' ∩ B' 和 (A ∩ B)' = A' ∪ B'。

### 2.2.1 并集、交集与补集

并集、交集和补集的基本性质和运算律如下：

- **并集**：对于任意两个集合A和B，有A ∪ B = {x | x ∈ A 或 x ∈ B}。并集的运算满足结合律、交换律和分配律。
- **交集**：对于任意两个集合A和B，有A ∩ B = {x | x ∈ A 且 x ∈ B}。交集的运算满足结合律、交换律和分配律。
- **补集**：对于任意一个集合A，有A' = {x | x ∉ A}。补集的运算满足德摩根律。

### 2.2.2 子集关系与等价关系

子集关系与等价关系的定义与性质如下：

- **子集关系**：若集合A的所有元素都属于集合B，则称A是B的子集，记作A ⊆ B。子集关系具有传递性和交换性。
- **等价关系**：等价关系是一个满足自反性、对称性和传递性的二元关系。对于任意两个集合A和B，如果它们之间存在一个等价关系，则称A和B是等价的。

### 2.2.3 集合的分类

集合的分类方法和分类性质如下：

- **有限集**：若集合中的元素数量有限，则称该集合为有限集。
- **无限集**：若集合中的元素数量无限，则称该集合为无限集。

- **不可数集**：若集合中的元素不能与自然数一一对应，则称该集合为不可数集。
