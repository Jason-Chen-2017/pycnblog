## 1. 集合的基本概念

### 1.1 集合的定义与性质

#### 集合的定义
集合是数学中的一个基础概念，用于表示一组确定的、互不相同的对象。这些对象可以是具体的元素，如数字、字母或几何图形，也可以是抽象的概念。

形式化地，集合可以定义为：
$$A = \{x | P(x)\}$$
其中，$A$ 是集合，$x$ 是集合中的元素，$P(x)$ 是一个性质或条件。

#### 集合的性质
集合具有以下基本性质：

1. **确定性**：集合中的元素是确定的，即给定一个集合，可以明确地知道它包含哪些元素。
2. **无序性**：集合中的元素没有固定的顺序。
3. **唯一性**：集合中的元素是互不相同的，不存在重复的元素。

### 1.2 集合的表示方法

#### 列表表示法
列表表示法是最直观的集合表示方法，它通过列出集合中的所有元素来定义集合。例如：
$$A = \{1, 2, 3, 4, 5\}$$

#### 描述表示法
描述表示法通过给出集合元素的共同属性或条件来定义集合。例如：
$$B = \{x | x \text{ 是自然数}, x < 6\}$$
这个集合表示所有小于6的自然数。

#### 集合的子集
一个集合的子集是指包含在该集合中的所有可能的子集。例如，集合 $A = \{1, 2, 3\}$ 的所有子集为：
$$\{\emptyset, \{1\}, \{2\}, \{3\}, \{1, 2\}, \{1, 3\}, \{2, 3\}, \{1, 2, 3\}\}$$

### 1.3 集合的运算

#### 并集
并集是两个或多个集合中所有元素的集合。形式化地，对于集合 $A$ 和 $B$，它们的并集表示为：
$$A \cup B = \{x | x \in A \text{ 或 } x \in B\}$$
例如，集合 $A = \{1, 2, 3\}$ 和 $B = \{4, 5\}$ 的并集为：
$$A \cup B = \{1, 2, 3, 4, 5\}$$

#### 交集
交集是两个或多个集合中共有的元素的集合。形式化地，对于集合 $A$ 和 $B$，它们的交集表示为：
$$A \cap B = \{x | x \in A \text{ 且 } x \in B\}$$
例如，集合 $A = \{1, 2, 3\}$ 和 $B = \{4, 5\}$ 的交集为：
$$A \cap B = \emptyset$$

#### 差集
差集是两个集合中第一集合的元素去掉第二集合的元素的集合。形式化地，对于集合 $A$ 和 $B$，它们的差集表示为：
$$A - B = \{x | x \in A \text{ 且 } x \not\in B\}$$
例如，集合 $A = \{1, 2, 3\}$ 和 $B = \{4, 5\}$ 的差集为：
$$A - B = \{1, 2, 3\}$$

#### 对称差
对称差是两个集合中互不相同的元素的集合。形式化地，对于集合 $A$ 和 $B$，它们的对称差表示为：
$$A \Delta B = (A - B) \cup (B - A)$$
例如，集合 $A = \{1, 2, 3\}$ 和 $B = \{4, 5\}$ 的对称差为：
$$A \Delta B = \{1, 2, 3, 4, 5\}$$

## 2. 集合的基数与性质

### 2.1 基数的定义与计算

#### 基数的定义
集合的基数（cardinality）是指集合中元素的数量。形式化地，集合 $A$ 的基数表示为：
$$|A|$$

#### 基数的计算
对于有限集合，基数的计算相对简单。假设集合 $A$ 有 $n$ 个元素，那么它的基数就是 $n$。例如，集合 $A = \{1, 2, 3, 4, 5\}$ 的基数为：
$$|A| = 5$$

对于无限集合，基数的计算则更为复杂。无限集合可以分为可数集合和不可数集合。

#### 可数集合
可数集合是指其基数等于自然数集合 $\mathbb{N}$ 的集合。形式化地，如果存在一个一一对应的映射 $f: \mathbb{N} \to A$，那么集合 $A$ 是可数的。例如，自然数集合 $\mathbb{N} = \{1, 2, 3, \ldots\}$ 是可数的。

#### 不可数集合
不可数集合是指其基数不等于自然数集合 $\mathbb{N}$ 的集合。形式化地，如果不存在一个一一对应的映射 $f: \mathbb{N} \to A$，那么集合 $A$ 是不可数的。例如，实数集合 $\mathbb{R}$ 是不可数的。

### 2.2 可数集合与不可数集合

#### 可数集合
可数集合的一个典型例子是自然数集合 $\mathbb{N}$。除了自然数集合，还有一些集合是可数的。例如，整数集合 $\mathbb{Z}$ 和有理数集合 $\mathbb{Q}$ 也是可数的。这是因为我们可以通过一一对应的映射将它们与自然数集合相联系。

例如，整数集合 $\mathbb{Z}$ 可以通过映射 $f: \mathbb{N} \to \mathbb{Z}$ 定义为：
$$f(n) = \begin{cases}
n, & \text{如果 } n \text{ 是正数} \\
-n, & \text{如果 } n \text{ 是负数} \\
0, & \text{如果 } n = 0
\end{cases}$$

#### 不可数集合
不可数集合的一个典型例子是实数集合 $\mathbb{R}$。实数集合中的每个数都可以表示为无限小数，这使得实数集合无法与自然数集合建立一一对应的映射。

#### 基数的比较与极限
两个集合的基数可以通过比较它们的可数性或不可数性来确定。如果集合 $A$ 是可数的，集合 $B$ 是不可数的，那么 $|A| < |B|$。

对于无限集合，基数的比较可以通过极限的概念来实现。假设集合 $A$ 和 $B$ 都是无限集合，如果存在一个一一对应的映射 $f: A \to B$，那么 $|A| = |B|$。

例如，考虑集合 $A = \{1, 2, 3, \ldots\}$ 和 $B = \{\frac{1}{n} | n \in \mathbb{N}\}$。我们可以通过映射 $f: A \to B$ 定义为：
$$f(n) = \frac{1}{n}$$
这个映射是一一对应的，因此 $|A| = |B|$。
