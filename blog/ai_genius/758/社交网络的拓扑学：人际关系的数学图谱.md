#### 第2章 社交网络的基本概念与模型

**2.1 社交网络的定义与特征**

- **定义**：社交网络是由个体（节点）及其之间的关系（边）构成的复杂系统。节点表示个体，如人、公司等，边表示个体之间的直接联系，如好友关系、合作关系等。
- **特征**：社交网络具有以下特征：
  - **稀疏性**：大多数节点之间的连接数量较少。
  - **高度动态性**：节点和边经常发生变化，如新关系的建立或旧关系的断裂。
  - **社区结构**：节点往往倾向于形成社区，即紧密连接的节点群体。

**2.2 常见的社交网络模型**

- **无标度网络**：这类网络的特征是节点度分布呈现幂律分布，即大部分节点度数较低，而少数节点度数极高。
- **小世界网络**：这类网络的特征是平均路径长度较短，同时具有高聚类系数。这意味着节点之间的距离较近，并且节点内部联系紧密。

**2.3 社交网络的构建方法**

#### 第3章 拓扑学与社交网络的联系

**3.1 拓扑学的基本概念**

- **拓扑空间**：定义了一组闭合路径的概念，用于研究网络中的连通性和路径结构。
- **连通性**：描述网络中任意两个节点之间是否可以通过一条路径相连。
- **路径**：网络中连接两个节点的边的序列。

**3.2 拓扑结构在社交网络分析中的应用**

- **连通性分析**：通过分析社交网络的连通性，可以发现网络中的关键节点和路径。
- **路径分析**：研究节点之间的最短路径，可以帮助理解社交网络的结构和节点之间的关系。

**3.3 社交网络中的连通性与路径分析**

- **连通性分析**：使用拓扑空间的概念，分析社交网络中节点的连通性。
- **路径分析**：使用Dijkstra算法或Floyd-Warshall算法计算节点之间的最短路径。

**数学模型与公式**

- **连通性**：定义两个节点u和v的连通性为`δ(u, v)`，若u和v之间可以通过一条路径相连，则`δ(u, v) = 1`，否则`δ(u, v) = 0`。
- **路径长度**：定义节点u和v之间的路径长度为`d(u, v)`，即连接u和v的最短路径上的边数。

**伪代码示例：**

```python
# 假设G是一个社交网络图，V是节点集合，E是边集合
def connectivity(G, u, v):
    # 使用深度优先搜索（DFS）算法检查连通性
    visited = set()
    stack = [(u, [u])]
    
    while stack:
        (vertex, path) = stack.pop()
        if vertex not in visited:
            visited.add(vertex)
            if vertex == v:
                return True
            for neighbor in G[vertex]:
                if neighbor not in visited:
                    stack.append((neighbor, path + [neighbor]))
    return False

# 示例：检查节点1和节点3是否连通
print(connectivity(G, 1, 3))
```

#### 第4章 人际关系的数学描述

**4.1 网络密度与聚类系数**

- **网络密度**：描述网络中边数与可能边数之比。公式为`ρ = |E| / (|V| * (|V| - 1))`，其中`|E|`是边数，`|V|`是节点数。
- **聚类系数**：描述网络中节点的紧密程度。公式为`C = 2 * |E'| / |N|`，其中`E'`是与节点v直接相连的节点对之间的边数，`N`是节点v的邻居数。

**4.2 人际关系的数学模型**

- **度模型**：描述节点度数分布的模型，如泊松分布、二项分布等。
- **邻接矩阵模型**：使用邻接矩阵表示网络结构，其中元素`a_{ij}`表示节点i和节点j之间是否存在边。

**4.3 数学模型的应用案例**

- **案例分析**：通过具体案例，展示如何使用网络密度和聚类系数分析人际关系。

**数学模型与公式**

- **网络密度**：ρ = |E| / (|V| * (|V| - 1))
- **聚类系数**：C = 2 * |E'| / |N|

**伪代码示例：**

```python
# 假设G是一个社交网络图，V是节点集合，E是边集合
def network_density(G):

    |V| = len(V)
    return |E| / (|V| * (|V| - 1))

def clustering_coefficient(G, v):
    N = len(G[v])
    E' = 0
    for i in range(N):
        for j in range(i + 1, N):
            if (v, G[v][i]) in E and (v, G[v][j]) in E:

    return 2 * E' / N
```
