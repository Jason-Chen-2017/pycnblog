### 1.2.1 时间序列模型

时间序列模型用于描述睡眠周期在时间维度上的变化规律。这种模型通常基于时间序列数据分析，通过统计方法或机器学习方法对睡眠周期的时间序列数据进行建模。

1. **自回归模型（AR）**：自回归模型是一种常用的统计模型，用于描述时间序列数据的自相关性。自回归模型的基本形式为：

   $$X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + ... + \phi_p X_{t-p} + \varepsilon_t$$

   其中，$X_t$ 表示时间序列的第 $t$ 个值，$c$ 为常数项，$\phi_1, \phi_2, ..., \phi_p$ 为自回归系数，$\varepsilon_t$ 为误差项。

2. **移动平均模型（MA）**：移动平均模型通过过去的误差值来预测当前值，其基本形式为：

   $$X_t = c + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + ... + \theta_q \varepsilon_{t-q}$$

3. **自回归移动平均模型（ARMA）**：自回归移动平均模型结合了自回归模型和移动平均模型的特点，用于描述既具有自相关性又具有移动平均特征的时间序列数据。其基本形式为：

   $$X_t = c + \phi_1 X_{t-1} + ... + \phi_p X_{t-p} + \theta_1 \varepsilon_{t-1} + ... + \theta_q \varepsilon_{t-q}$$

   $$X_t = A X_{t-1} + B u_t + \varepsilon_t$$

2. **非线性状态空间模型**：非线性状态空间模型适用于描述非线性系统的动态行为，其基本形式为：
