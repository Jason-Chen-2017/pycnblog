\[ m\frac{d^2x}{dt^2} + c\frac{dx}{dt} + kx + \delta x^3 = F_0 \cos(\omega t) \]

其中，\( m \)是质量，\( c \)是阻尼系数，\( k \)是弹性系数，\( \delta \)是非线性系数，\( F_0 \)是外力幅值，\( \omega \)是外力频率。

- **Lorenz系统**：描述大气对流运动的动力学行为，其方程为：

\[ \begin{cases} \frac{dx}{dt} = \sigma (y - x) \\ \frac{dy}{dt} = x (\rho - z) - y \\ \frac{dz}{dt} = xy - \beta z \end{cases} \]

- **Chen系统**：描述化学反应动力学行为，其方程为：

\[ \begin{cases} \frac{dx}{dt} = \mu (1 - x^2 - y^2) \\ \frac{dy}{dt} = \rho x y - (\beta + 1) y \\ \frac{dz}{dt} = \alpha x + \gamma z - \rho z y \end{cases} \]

1. 将方程转化为标准形式：

\[ \frac{d^2x}{dt^2} + 2\frac{dx}{dt} + (2 - 10\cos(t))x = 0 \]

2. 求解齐次方程：

\[ \frac{d^2x}{dt^2} + 2\frac{dx}{dt} + 2x = 0 \]

特征方程为：

\[ r^2 + 2r + 2 = 0 \]

解得特征根：

\[ r = -1 \pm i \]

\[ x_h(t) = e^{-t}(C_1 \cos(t) + C_2 \sin(t)) \]

\[ \frac{d^2x}{dt^2} + 2\frac{dx}{dt} + 2x = 10\cos(t) \]

\[ x_p(t) = A\cos(t) + B\sin(t) \]

\[ -A\cos(t) - B\sin(t) + 2(-A\sin(t) + B\cos(t)) + 2(A\cos(t) + B\sin(t)) = 10\cos(t) \]

比较系数，可以得到：

\[ A = 5, B = 0 \]

因此，非齐次方程的特解为：

\[ x_p(t) = 5\cos(t) \]

4. 综合齐次解和非齐次解，可以得到原方程的通解：

\[ x(t) = x_h(t) + x_p(t) = e^{-t}(C_1 \cos(t) + C_2 \sin(t)) + 5\cos(t) \]

其中，\( C_1 \)和\( C_2 \)是任意常数，可以通过初始条件确定。

#### 4.3.1 Python代码实现

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import savgol_filter

# 读取心率数据
def read_heart_rate_data(filename):
    with open(filename, 'r') as file:
        data = [line.strip() for line in file]
    heart_rate_data = np.array(data, dtype=float)
    return heart_rate_data

# 预处理心率数据
def preprocess_heart_rate_data(heart_rate_data):
    # 去除异常值
    threshold = np.mean(heart_rate_data) * 3
    valid_data = heart_rate_data[heart_rate_data < threshold]
    # 去除噪声
    filtered_data = savgol_filter(valid_data, window_length=15, polyorder=2)
    return filtered_data

# 计算心率变异性指标
def calculate_heart_rate_variation(heart_rate_data):
    # 计算标准差
    sdnn = np.std(heart_rate_data)
    # 计算标准差变异
    rmssd = np.sqrt(np.mean((heart_rate_data[1:] - heart_rate_data[:-1])**2))
    # 计算有效频率
    pnn50 = np.sum(np.abs(heart_rate_data[1:] - heart_rate_data[:-1]) > 50) / (len(heart_rate_data) - 1)
    return sdnn, rmssd, pnn50

# 绘制心率时间序列图
def plot_heart_rate_time_series(heart_rate_data):
    plt.figure()
    plt.plot(heart_rate_data)
    plt.xlabel('Time (s)')
    plt.ylabel('Heart Rate (bpm)')
    plt.title('Heart Rate Time Series')
    plt.show()

# 主函数
def main():
    filename = 'heart_rate_data.txt'
    heart_rate_data = read_heart_rate_data(filename)
    filtered_data = preprocess_heart_rate_data(heart_rate_data)
    sdnn, rmssd, pnn50 = calculate_heart_rate_variation(filtered_data)
    print('SDNN:', sdnn)
    print('RMSSD:', rmssd)
    print('pNN50:', pnn50)
    plot_heart_rate_time_series(filtered_data)

if __name__ == '__main__':
    main()
```
