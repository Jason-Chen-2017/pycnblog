**信息熵定义与计算**
信息熵的定义基于概率论，表示一个随机变量不确定性的度量。计算公式如下：
$$
H(X) = -\sum_{i} p(x_i) \log_2 p(x_i)
$$
其中，$X$ 是随机变量，$p(x_i)$ 是 $x_i$ 发生的概率。

```python
import numpy as np
```

**数据压缩算法讲解**
数据压缩算法可以分为无损压缩和有损压缩。无损压缩算法如霍夫曼编码和LZ77算法，有损压缩算法如JPEG和MP3编码。

**Python源代码实例**
```python
import numpy as np
import heapq

def huffman编码(p):
    """
    构建霍夫曼编码树
    """
    # 创建频率堆
    heap = [[-freq, sym] for sym, freq in p.items()]
    heapq.heapify(heap)

    # 构建霍夫曼编码树
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        merged = [-left[0] - right[0], [left[1], right[1]]]
        heapq.heapify(heap)

    # 构建编码表
    code = {}
    for sym, freq in p.items():
        code[sym] = ""
        node = merged
        while node[1] != sym:
            if node[1][0] == sym:
                code[sym] += "0"
                node = node[1]
            else:
                code[sym] += "1"
                node = node[1]

    return code

# 示例：使用霍夫曼编码压缩二进制随机变量
p = {"A": 0.5, "B": 0.5}
code = huffman编码(p)
encoded = ''.join(code[sym] for sym in p.keys())
print(f"Encoded string: {encoded}")
```
