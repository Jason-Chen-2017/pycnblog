### 示例：计算程序中的信息熵

```python
import math
from collections import Counter

def calculate_entropy(data):
    """
    计算数据的熵
    :param data: 数据列表
    :return: 熵值
    """
    # 计算每个字符出现的频率
    frequency = Counter(data)
    # 计算总字符数
    total_chars = len(data)
    # 计算每个字符的概率
    probabilities = [freq / total_chars for freq in frequency.values()]
    # 计算熵
    entropy = -sum(p * math.log2(p) for p in probabilities)
    return entropy

# 测试数据
text = "hello world"
entropy = calculate_entropy(text)
print(f"文本 '{text}' 的信息熵为：{entropy}")
```

在这个示例中，我们使用Python的`collections.Counter`类来计算字符串中每个字符的频率，然后使用概率和熵的计算公式来计算信息熵。通过这个示例，我们可以看到如何利用信息熵来评估程序中的信息复杂度，并为进一步的优化提供依据。
