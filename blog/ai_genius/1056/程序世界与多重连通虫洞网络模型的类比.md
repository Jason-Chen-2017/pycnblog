**1. 冒泡排序算法**

冒泡排序是一种简单的排序算法，它重复地遍历要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来。遍历数列的工作是重复地进行，直到没有再需要交换的元素为止。

**Python代码实现：**

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

# 示例数据
arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = bubble_sort(arr)
print(sorted_arr)
```

**LaTeX公式：**

$$

\begin{cases}
\text{for } i = 0 \text{ to } n-1: \\
\hspace{1cm} \text{for } j = 0 \text{ to } n-i-1: \\
\hspace{1.5cm} \text{if } arr[j] > arr[j+1]: \\
\hspace{2.5cm} \text{swap } arr[j] \text{ and } arr[j+1].
\end{cases}
$$

**2. 快速排序算法**

快速排序是一种高效的排序算法，其基本思想是通过递归分治策略将一个大问题分解成几个小问题，从而快速找到数列中的最小元素。该算法选择一个“基准”元素，将数列分成两部分，一部分比基准元素小，一部分比基准元素大，然后递归地对这两部分进行快速排序。

**Python代码实现：**

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 示例数据
arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = quick_sort(arr)
print(sorted_arr)
```

**LaTeX公式：**

$$
\text{快速排序算法：}
\begin{cases}
\text{if } n \leq 1: \\
\hspace{1cm} \text{return } arr. \\
\text{else:} \\
\hspace{1cm} \text{pivot} = arr[\frac{n}{2}] \\
\hspace{1.5cm} \text{left} = \{x \in arr \mid x < pivot\} \\
\hspace{1.5cm} \text{middle} = \{x \in arr \mid x = pivot\} \\
\hspace{1.5cm} \text{right} = \{x \in arr \mid x > pivot\} \\
\hspace{1cm} \text{return } quick_sort(left) + middle + quick_sort(right).
\end{cases}
$$
