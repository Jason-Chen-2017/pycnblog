                 

### 第3章：强化学习原理与算法

#### 3.1 强化学习的基本原理

强化学习（Reinforcement Learning，RL）是一种机器学习方法，通过使代理人（agent）在与环境的交互中学习到最优策略。其基本原理是代理人通过观察环境的状态（State）、选择动作（Action）、并接收环境给出的奖励（Reward），来不断调整自己的行为策略，以实现最大化长期奖励的目标。

**定义与目标**：强化学习的主要目标是找到一种策略（Policy），使得代理人在长期的交互过程中能够获得最大的累积奖励。策略通常是通过价值函数（Value Function）或策略函数（Policy Function）来表示的。

- **状态（State）**：描述代理人在某一时刻所处的环境状态。
- **动作（Action）**：代理人在某一状态可以选择的行动。
- **奖励（Reward）**：环境对代理人的动作给予的即时反馈，表示代理人的行为对目标的达成度。
- **价值函数（Value Function）**：表示代理人在某一状态选择某一动作的长期奖励期望。
- **策略（Policy）**：代理人在给定状态下的最优动作选择。

**基本术语**：

- **回报（Return）**：从当前时刻起直到学习终止时累计的奖励。
- **策略稳定性（Policy Stability）**：代理人的策略不再发生变化的状态。
- **探索（Exploration）**：代理人在学习过程中尝试新的动作，以获取更多信息的策略。
- **利用（Utilization）**：代理人在学习过程中使用已有信息，按照最优策略进行决策。

**学习过程**：强化学习的学习过程可以分为两个主要阶段：探索（Exploration）和利用（Utilization）。在探索阶段，代理人尝试不同的动作以获取更多的信息。在利用阶段，代理人使用已有的信息，按照学习到的策略进行决策，以最大化长期奖励。

强化学习的基本流程可以概括为以下几个步骤：

1. **初始化**：初始化代理人和环境的状态。
2. **选择动作**：根据当前状态和策略选择动作。
3. **执行动作**：代理人在环境中执行动作，并获得新的状态和奖励。
4. **更新策略**：根据奖励和新的状态来更新策略。
5. **重复**：重复上述步骤，直到学习终止。

强化学习的一个关键特点是，代理人在学习过程中需要处理不确定性和即时奖励与长期奖励之间的权衡。这使得强化学习在解决动态和复杂问题时具有独特的优势。

#### 3.2 Q-learning算法

Q-learning算法是一种基于值函数的强化学习算法，其核心思想是通过迭代更新值函数来学习最优策略。Q-learning算法通过不断地尝试和修正策略，以实现最大化累积奖励的目标。

**算法原理**：Q-learning算法通过一个Q值表来存储状态-动作值（Q-value），表示在某一状态选择某一动作所能获得的期望奖励。算法的基本思想是，通过迭代更新Q值表，使得代理人在长期中能够选择最优的动作。

Q-learning算法的更新公式如下：
$$
Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]
$$
其中，$s$ 和 $s'$ 分别表示当前状态和下一状态，$a$ 和 $a'$ 分别表示当前动作和下一动作，$\alpha$ 是学习率，$r$ 是即时奖励，$\gamma$ 是折扣因子。

**算法流程**：

1. **初始化Q值表**：初始化Q值表，通常将所有Q值初始化为0。
2. **选择动作**：在给定状态下，根据当前策略选择动作。可以选择贪心策略（即选择当前状态下Q值最大的动作），也可以选择随机策略（即按照某种概率分布选择动作）。
3. **执行动作**：在环境中执行所选动作，并获得新的状态和即时奖励。
4. **更新Q值**：根据更新公式，更新当前状态下的Q值。
5. **重复**：重复上述步骤，直到达到终止条件（如达到指定步数、学习到最优策略等）。

**代码伪实现**：

```python
# 初始化Q值表
Q = [[0 for _ in range(actions)] for _ in range(states)]

# Q-learning迭代过程
for episode in range(total_episodes):
    state = env.reset()
    done = False
    while not done:
        # 选择动作
        action = choose_action(state, Q)
        # 执行动作
        next_state, reward, done = env.step(action)
        # 更新Q值
        Q[state][action] = Q[state][action] + alpha * (reward + gamma * max(Q[next_state]) - Q[state][action])
        state = next_state
```

Q-learning算法的优点是简单易实现，不需要显式地定义策略函数，可以直接学习状态-动作值。然而，Q-learning算法存在几个问题：

1. **样本效率低**：Q-learning算法需要大量的样本才能收敛到最优策略。
2. **容易陷入局部最优**：Q-learning算法在更新Q值时只考虑了当前状态的最优动作，容易导致算法陷入局部最优。

为了解决这些问题，研究者提出了许多改进算法，如Deep Q-Network（DQN）、Policy Gradient算法等。

#### 3.3 Deep Q-Network（DQN）算法

Deep Q-Network（DQN）算法是Q-learning算法的改进版本，通过引入深度神经网络（Deep Neural Network，DNN）来近似Q值函数，从而提高算法的处理能力和收敛速度。

**算法原理**：DQN算法的核心思想是将Q值函数表示为一个DNN模型，通过训练DNN模型来学习状态-动作值。DQN算法利用经验回放（Experience Replay）技术，将历史经验存储在经验池中，以避免样本的相关性，提高学习效果。

DQN算法的基本流程如下：

1. **初始化DNN模型**：初始化DQN模型，包括输入层、隐藏层和输出层。输出层有多个节点，每个节点对应一个动作。
2. **选择动作**：在给定状态下，使用DNN模型预测状态-动作值，并根据预测结果选择动作。可以选择贪心策略或ε-贪心策略。
3. **执行动作**：在环境中执行所选动作，并获得新的状态和即时奖励。
4. **存储经验**：将当前状态、动作、奖励和下一状态存储到经验池中。
5. **更新DNN模型**：从经验池中随机抽取一组经验样本，计算目标Q值，并使用这些样本来更新DNN模型。
6. **重复**：重复上述步骤，直到达到终止条件。

**算法流程**：

1. **初始化经验池**：初始化经验池，用于存储历史经验。
2. **选择动作**：在给定状态下，使用DNN模型预测状态-动作值，选择动作。
3. **执行动作**：在环境中执行动作，并获得新的状态和即时奖励。
4. **存储经验**：将当前状态、动作、奖励和下一状态存储到经验池中。
5. **更新DNN模型**：
   - 随机从经验池中抽取一组经验样本。
   - 计算目标Q值：$$y = r + \gamma \max_{a'} \hat{Q}(s', a')$$
   - 使用经验样本和目标Q值来更新DNN模型。

**代码伪实现**：

```python
# 初始化DNN模型
model = build_dnn_model()

# DQN迭代过程
for episode in range(total_episodes):
    state = env.reset()
    done = False
    while not done:
        # 选择动作
        action = choose_action(state, model)
        # 执行动作
        next_state, reward, done = env.step(action)
        # 存储经验
        experience = (state, action, reward, next_state, done)
        replay_memory.append(experience)
        # 更新DNN模型
        if len(replay_memory) > batch_size:
            batch = random_sample(replay_memory, batch_size)
            state_batch, action_batch, reward_batch, next_state_batch, done_batch = zip(*batch)
            target_values = calculate_target_values(next_state_batch, reward_batch, done_batch)
            model.fit(state_batch, target_values, batch_size=batch_size)
        state = next_state
```

DQN算法的优点是能够处理高维的状态空间，并且通过经验回放技术避免了样本的相关性。然而，DQN算法也存在一些问题：

1. **目标Q值计算**：DQN算法需要计算目标Q值，这是一个复杂的计算过程，可能会降低算法的收敛速度。
2. **样本效率**：DQN算法的样本效率仍然较低，需要大量的样本才能收敛到最优策略。

为了解决这些问题，研究者提出了许多改进算法，如Double Q-learning、优先经验回放等。

#### 3.4 Policy Gradient算法

Policy Gradient算法是一种基于策略的强化学习算法，其核心思想是直接优化策略的概率分布，以最大化累积奖励。Policy Gradient算法通过梯度上升法更新策略参数，从而学习到最优策略。

**算法原理**：Policy Gradient算法通过估计策略梯度来更新策略参数。策略梯度可以表示为：
$$
\nabla_{\theta} J(\theta) = \sum_{s, a} \nabla_{\theta} \log \pi(a|s) R
$$
其中，$J(\theta)$ 表示策略的回报，$R$ 表示累积奖励，$\theta$ 表示策略参数。

Policy Gradient算法的基本流程如下：

1. **初始化策略参数**：初始化策略参数。
2. **执行动作**：在给定状态下，根据策略选择动作。
3. **更新策略参数**：根据策略梯度更新策略参数。
4. **重复**：重复上述步骤，直到达到终止条件。

**算法流程**：

1. **初始化策略参数**：初始化策略参数。
2. **执行动作**：在给定状态下，根据策略参数选择动作。
3. **更新策略参数**：
   - 计算策略梯度：$$\nabla_{\theta} J(\theta) = \sum_{s, a} \nabla_{\theta} \log \pi(a|s) R$$
   - 更新策略参数：$$\theta \leftarrow \theta + \alpha \nabla_{\theta} J(\theta)$$
4. **重复**：重复上述步骤，直到达到终止条件。

**代码伪实现**：

```python
# 初始化策略参数
theta = initialize_policy_parameters()

# Policy Gradient迭代过程
for episode in range(total_episodes):
    state = env.reset()
    done = False
    while not done:
        # 执行动作
        action = choose_action(state, theta)
        # 获得状态和奖励
        next_state, reward, done = env.step(action)
        # 计算策略梯度
        gradient = calculate_policy_gradient(state, action, reward, next_state, done, theta)
        # 更新策略参数
        theta = theta + alpha * gradient
        state = next_state
```

Policy Gradient算法的优点是能够快速收敛到最优策略，并且不需要显式地定义价值函数或Q值表。然而，Policy Gradient算法也存在一些问题：

1. **方差问题**：Policy Gradient算法的梯度估计存在较大的方差，可能导致算法不稳定。
2. **高维状态空间**：在处理高维状态空间时，Policy Gradient算法的效果较差。

为了解决这些问题，研究者提出了许多改进算法，如优势优势策略梯度（ Advantage Gradient）算法、演员-评论家（Actor-Critic）算法等。

#### 3.5 Actor-Critic算法

Actor-Critic算法是一种结合了策略优化和价值评估的优势的强化学习算法。其核心思想是，通过演员（Actor）和评论家（Critic）两个模块共同学习最优策略。演员模块负责执行动作，评论家模块负责评估动作的好坏。

**算法原理**：Actor-Critic算法通过两个独立的模块来学习策略。演员模块（Actor）使用策略函数来选择动作，评论家模块（Critic）使用价值函数来评估策略的好坏。通过同时更新演员和评论家模块，Actor-Critic算法能够更快地收敛到最优策略。

Actor-Critic算法的基本流程如下：

1. **初始化演员和评论家模块**：初始化演员和评论家的参数。
2. **执行动作**：在给定状态下，根据演员模块的策略函数选择动作。
3. **评估动作**：根据评论家模块的价值函数评估动作的好坏。
4. **更新演员和评论家模块**：根据评估结果更新演员和评论家模块的参数。
5. **重复**：重复上述步骤，直到达到终止条件。

**算法流程**：

1. **初始化演员和评论家模块**：初始化演员和评论家的参数。
2. **执行动作**：在给定状态下，根据演员模块的策略函数选择动作。
3. **评估动作**：根据评论家模块的价值函数评估动作的好坏。
4. **更新演员模块**：
   - 计算策略梯度：$$\nabla_{\theta_a} J(\theta_a) = \sum_{s, a} \nabla_{\theta_a} \log \pi(a|s) R$$
   - 更新演员参数：$$\theta_a \leftarrow \theta_a + \alpha_a \nabla_{\theta_a} J(\theta_a)$$
5. **更新评论家模块**：
   - 计算价值函数梯度：$$\nabla_{\theta_c} V(s) = \nabla_{\theta_c} \sum_{a} \pi(a|s) Q(s, a)$$
   - 更新评论家参数：$$\theta_c \leftarrow \theta_c + \alpha_c \nabla_{\theta_c} V(s)$$
6. **重复**：重复上述步骤，直到达到终止条件。

**代码伪实现**：

```python
# 初始化演员和评论家参数
actor_params = initialize_actor_parameters()
critic_params = initialize_critic_parameters()

# Actor-Critic迭代过程
for episode in range(total_episodes):
    state = env.reset()
    done = False
    while not done:
        # 执行动作
        action = actor.choose_action(state, actor_params)
        # 评估动作
        next_state, reward, done = env.step(action)
        value = critic.evaluate_value(state, action, reward, next_state, done, critic_params)
        # 更新演员和评论家
        actor.update_parameters(state, action, reward, next_state, done, actor_params)
        critic.update_parameters(state, action, reward, next_state, done, critic_params)
        state = next_state
```

Actor-Critic算法的优点是结合了策略优化和价值评估的优点，能够更快地收敛到最优策略。同时，Actor-Critic算法对环境变化和噪声的鲁棒性较好。然而，Actor-Critic算法也存在一些问题：

1. **参数更新**：演员和评论家的参数更新需要同时进行，这可能会导致算法的收敛速度较慢。
2. **梯度消失**：由于演员和评论家的参数更新是独立的，可能会导致梯度消失问题。

为了解决这些问题，研究者提出了许多改进算法，如Actor-Critic with Experience Replay、Actor-Critic with Trust Region Policy Optimization等。

### 小结

本章详细介绍了强化学习的原理与算法，包括Q-learning算法、Deep Q-Network（DQN）算法、Policy Gradient算法和Actor-Critic算法。这些算法通过不同的方式来优化代理人的策略，使其能够最大化长期奖励。

Q-learning算法是一种基于值函数的强化学习算法，通过迭代更新Q值表来学习最优策略。DQN算法通过引入深度神经网络来近似Q值函数，提高了算法的处理能力和收敛速度。Policy Gradient算法直接优化策略的概率分布，通过计算策略梯度来更新策略参数。Actor-Critic算法结合了策略优化和价值评估的优点，通过同时更新演员和评论家的参数来学习最优策略。

每种算法都有其优缺点和适用场景。在实际应用中，可以根据具体问题的需求和特点选择合适的算法，并通过改进和优化算法来提高其性能和效果。

### 第4章：提示词优化的强化学习

#### 4.1 提示词优化的基础理论

提示词优化（Prompt Optimization）是强化学习中的一个重要技术，旨在通过调整提示词（Prompt）来优化代理人在复杂环境中的决策过程。提示词是一种辅助信息，可以帮助代理人更好地理解当前状态，从而做出更合理的动作。

**定义**：提示词优化是指通过修改或调整提示词的内容、形式或结构，以优化代理人在强化学习过程中的决策质量。

**原理**：提示词优化的核心思想是，通过引入外部信息来增强代理人的决策能力。提示词可以提供额外的上下文信息，帮助代理人更好地理解当前状态，从而提高决策的准确性和鲁棒性。在强化学习中，提示词通常是一个向量或张量，可以与状态向量进行拼接，作为输入传递给代理人的模型。

**作用**：

1. **提高决策质量**：通过提示词优化，代理人可以更好地理解当前状态，从而做出更准确的决策。
2. **增强鲁棒性**：提示词优化可以帮助代理人应对环境中的不确定性和噪声。
3. **降低样本效率**：提示词优化可以减少代理人需要探索的状态空间，从而降低样本效率。

#### 4.2 提示词优化的具体实现方法

提示词优化的实现方法可以分为以下几类：

**方法1：基于经验的提示词优化**

基于经验的提示词优化是通过从历史经验中学习来设计提示词，从而提高代理人在特定情况下的决策能力。这种方法通常包括以下步骤：

1. **经验抽样**：从代理人的历史经验中随机抽取样本。
2. **特征提取**：从每个样本中提取关键特征，作为提示词的一部分。
3. **提示词设计**：根据提取的特征，设计提示词的形式和内容。
4. **模型训练**：使用设计的提示词对代理人模型进行训练。

**方法2：基于优化的提示词优化**

基于优化的提示词优化是通过优化算法来调整提示词，使其达到最优状态。这种方法通常包括以下步骤：

1. **目标函数设计**：设计一个目标函数，用于评估提示词的优劣。
2. **优化算法选择**：选择合适的优化算法，如梯度下降、遗传算法等。
3. **提示词调整**：通过优化算法调整提示词，使其达到最优状态。
4. **模型训练**：使用优化的提示词对代理人模型进行训练。

**方法3：基于知识的提示词优化**

基于知识的提示词优化是通过引入先验知识（如领域知识、专家经验等）来设计提示词，从而提高代理人的决策能力。这种方法通常包括以下步骤：

1. **知识获取**：从领域专家或知识库中获取相关知识。
2. **知识融合**：将获取的知识融合到提示词中，形成新的提示词。
3. **模型训练**：使用融合知识的提示词对代理人模型进行训练。

**方法4：基于生成模型的提示词优化**

基于生成模型的提示词优化是通过生成模型（如生成对抗网络、变分自编码器等）来生成提示词。这种方法通常包括以下步骤：

1. **生成模型训练**：训练一个生成模型，使其能够生成与真实数据分布相似的提示词。
2. **提示词生成**：使用生成模型生成提示词。
3. **模型训练**：使用生成的提示词对代理人模型进行训练。

#### 4.3 提示词优化在强化学习中的应用

提示词优化在强化学习中有广泛的应用，以下是一些典型应用场景：

**应用场景1：强化学习中的测试用例生成**

### 第5章：数学模型与公式

在强化学习中，数学模型和公式是理解算法原理和实现核心功能的基础。本章将详细阐述强化学习中的关键数学模型与公式，包括强化学习的基本模型、提示词优化的数学模型，以及相关的推导和证明。

#### 5.1 强化学习中的数学模型

强化学习的基本数学模型主要包括状态（State）、动作（Action）、奖励（Reward）、价值函数（Value Function）和策略（Policy）。

**状态（State）**：状态是代理人在某一时刻所处的环境情况，通常用一个向量表示。

**动作（Action）**：动作是代理人在某一状态下可以执行的行为，也用一个向量表示。

**奖励（Reward）**：奖励是环境对代理人行为的即时反馈，用于评价代理人行为的优劣。

**价值函数（Value Function）**：价值函数是评估代理人在某一状态下执行某一动作所能获得的长期奖励的函数。它有两个主要形式：状态价值函数（State-Value Function，$V(s)$）和动作价值函数（Action-Value Function，$Q(s, a)$）。

- **状态价值函数**：表示在状态 $s$ 下执行任意动作 $a$ 的期望回报，公式如下：
  $$V(s) = \sum_{a} \pi(a|s) Q(s, a)$$
  
- **动作价值函数**：表示在状态 $s$ 下执行动作 $a$ 的期望回报，公式如下：
  $$Q(s, a) = \sum_{s'} p(s'|s, a) [r(s', a) + \gamma V(s')]$$
  其中，$p(s'|s, a)$ 是从状态 $s$ 执行动作 $a$ 转移到状态 $s'$ 的概率，$r(s', a)$ 是在状态 $s'$ 执行动作 $a$ 所获得的即时奖励，$\gamma$ 是折扣因子，表示对未来的奖励进行折现。

**策略（Policy）**：策略是代理人在给定状态下选择动作的规则。有两种形式的策略：

- **确定性策略**：在给定状态下，总是选择使价值函数最大的动作。
  $$\pi_d(a|s) = \begin{cases} 
  1 & \text{if } a = \arg\max_a Q(s, a) \\
  0 & \text{otherwise} 
  \end{cases}$$

- **概率性策略**：在给定状态下，根据某个概率分布选择动作。
  $$\pi(a|s) = \frac{\exp(\theta(s) a)}{\sum_{a'} \exp(\theta(s) a')}$$
  其中，$\theta(s)$ 是策略参数向量。

#### 5.2 提示词优化的数学模型

提示词优化是强化学习中的一个重要技术，它通过调整提示词来优化代理人的决策过程。提示词优化的数学模型主要涉及目标函数、优化算法和提示词的设计。

**目标函数**：提示词优化的目标函数是最大化代理人在特定任务上的性能。具体的目标函数可以根据任务需求来设计，例如在测试用例生成中，目标函数可以是最大化测试覆盖率和测试用例的有效性。

- **基本目标函数**：
  $$\min_{p} \sum_{s, a} L(s, a) - \lambda \sum_{s, a} \log \pi(a|s)$$
  其中，$L(s, a)$ 是损失函数，用于评价代理人在状态 $s$ 下选择动作 $a$ 的性能，$\lambda$ 是正则化参数，用于平衡模型复杂性和性能。

**优化算法**：提示词优化的优化算法用于调整提示词，使其达到最优状态。常用的优化算法包括梯度下降、随机梯度下降（SGD）、遗传算法等。

- **梯度下降**：
  $$p_{t+1} = p_t - \alpha \nabla_p L(p)$$
  其中，$p_t$ 是第 $t$ 次迭代的提示词参数，$\alpha$ 是学习率，$\nabla_p L(p)$ 是目标函数关于提示词参数的梯度。

**提示词设计**：提示词设计是提示词优化的关键步骤，它决定了代理人在不同状态下的决策质量。提示词设计的方法可以基于经验、优化、知识或生成模型。

#### 5.3 公式推导与证明

**值函数的迭代更新公式**

值函数的迭代更新公式是强化学习算法的核心，用于在迭代过程中逐步优化代理人的策略。以下是一个常见的值函数迭代更新公式：

$$V(s_t) = r_t + \gamma V(s_{t+1})$$

**证明**：值函数 $V(s)$ 表示从状态 $s$ 开始并遵循策略 $\pi$ 的期望回报。考虑从状态 $s_t$ 开始的一步马尔可夫决策过程：

$$V(s_t) = \sum_{a} \pi(a|s_t) Q(s_t, a)$$

其中，$Q(s_t, a)$ 是从状态 $s_t$ 开始执行动作 $a$ 并遵循策略 $\pi$ 的期望回报。根据马尔可夫性质，下一状态 $s_{t+1}$ 的分布只与当前状态 $s_t$ 和当前动作 $a$ 有关：

$$Q(s_t, a) = \sum_{s_{t+1}} p(s_{t+1}|s_t, a) [r(s_{t+1}, a) + \gamma V(s_{t+1})]$$

将 $Q(s_t, a)$ 的表达式代入 $V(s_t)$ 的定义中，并使用概率分布的归一化性质，可以得到：

$$V(s_t) = \sum_{a} \pi(a|s_t) \sum_{s_{t+1}} p(s_{t+1}|s_t, a) [r(s_{t+1}, a) + \gamma V(s_{t+1})]$$

$$V(s_t) = \sum_{s_{t+1}} \sum_{a} p(s_{t+1}|s_t, a) \pi(a|s_t) [r(s_{t+1}, a) + \gamma V(s_{t+1})]$$

由于 $\pi(a|s_t)$ 是一个概率分布，它的期望为1：

$$V(s_t) = \sum_{s_{t+1}} [r(s_{t+1}, \arg\max_a Q(s_t, a)] + \gamma V(s_{t+1})]$$

令 $a^* = \arg\max_a Q(s_t, a)$，则：

$$V(s_t) = r_t + \gamma V(s_{t+1})$$

**策略优化的梯度公式**

策略优化的目标是最大化累积奖励。对于策略梯度算法，策略优化的梯度公式如下：

$$\nabla_{\theta} J(\theta) = \sum_{s, a} \nabla_{\theta} \log \pi(a|s) R$$

**证明**：策略函数 $\pi(a|s)$ 的梯度可以表示为：

$$\nabla_{\theta} \log \pi(a|s) = \frac{\partial \log \pi(a|s)}{\partial \theta}$$

累积奖励 $J(\theta)$ 可以表示为：

$$J(\theta) = \sum_{s, a} \pi(a|s) R(s, a)$$

对 $J(\theta)$ 关于 $\theta$ 求导，并使用链式法则：

$$\nabla_{\theta} J(\theta) = \sum_{s, a} \nabla_{\theta} \pi(a|s) R(s, a)$$

由于 $\nabla_{\theta} \pi(a|s) = \frac{\partial \pi(a|s)}{\partial \theta}$，并且 $R(s, a)$ 是关于 $\theta$ 的常数，可以进一步简化为：

$$\nabla_{\theta} J(\theta) = \sum_{s, a} \frac{\partial \pi(a|s)}{\partial \theta} R(s, a)$$

由于 $\pi(a|s)$ 是一个概率分布，其导数可以表示为：

$$\nabla_{\theta} \log \pi(a|s) = \frac{\pi(a|s)}{1 - \pi(a|s)} \nabla_{\theta} \theta$$

将 $\nabla_{\theta} \log \pi(a|s)$ 代入 $\nabla_{\theta} J(\theta)$ 中，可以得到：

$$\nabla_{\theta} J(\theta) = \sum_{s, a} \frac{\pi(a|s)}{1 - \pi(a|s)} R(s, a)$$

简化后得到策略优化的梯度公式：

$$\nabla_{\theta} J(\theta) = \sum_{s, a} \nabla_{\theta} \log \pi(a|s) R$$
