**2.3.2 机器人视觉系统**

机器人视觉系统结合计算机视觉和机器人技术，可以实现自动化装配和检测。

- **核心算法原理讲解（Python Code）**

  ```python
  import numpy as np
  import cv2
  from sklearn.cluster import KMeans

  # 加载图像
  image = cv2.imread('example.jpg')

  # 转换为HSV颜色空间
  hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

  # 定义颜色范围
  lower_blue = np.array([110, 50, 50])
  upper_blue = np.array([130, 255, 255])

  # 颜色过滤
  mask = cv2.inRange(hsv, lower_blue, upper_blue)

  # 使用K-means进行颜色聚类
  kmeans = KMeans(n_clusters=3, random_state=0).fit(mask.reshape(-1, mask.shape[0]))
  labels = kmeans.predict(mask.reshape(-1, mask.shape[0]))

  # 绘制颜色聚类结果
  image = cv2.cvtColor(np.reshape(labels, mask.shape), cv2.COLOR_GRAY2BGR)

  # 显示图像
  ```
