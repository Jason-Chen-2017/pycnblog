#### 起源：18世纪末到19世纪初

无畏主义的起源可以追溯到18世纪末和19世纪初的启蒙运动。在那个时期，启蒙思想家们开始对宗教和传统的价值观提出质疑，倡导理性和科学的方法。这个时期的哲学背景为无畏主义的兴起奠定了基础。

斯宾诺莎（Baruch Spinoza）是最早提出无畏主义思想的哲学家之一。他在其著作《伦理学》中，通过理性思考，否定了宗教信仰的权威，认为宇宙的本质是一致的、无限的，而人类的存在只是宇宙的一部分，没有独立存在的意义。这一思想对后来的无畏主义产生了深远的影响。

#### 发展：19世纪到20世纪

19世纪是无畏主义思想发展的关键时期。在这一时期，许多哲学家、文学家和思想家继续对宗教、道德和价值观进行批判，无畏主义逐渐成为一种具有广泛影响力的哲学思潮。

尼采（Friedrich Nietzsche）是无畏主义的重要代表之一。他在其著作《查拉图斯特拉如是说》中，提出了“上帝已死”的观点，认为人类需要重新定义自己的价值观和生活意义。尼采的无畏主义思想对后来的哲学家和艺术家产生了深远的影响。

克尔凯郭尔（Søren Kierkegaard）是另一位重要的无畏主义思想家。他在其著作中探讨了个体信仰、道德和存在的意义，提出了“个体化”和“存在主义”的概念，强调了个体在自由选择和自我认知中的重要性。

#### 无畏主义在现代的影响

无畏主义在现代依然具有广泛的影响。它挑战了传统的价值观和信仰，鼓励人们质疑和反思现有的社会秩序和伦理规范。这种思想在当代哲学、文学、艺术和心理学等领域得到了广泛的应用。

在哲学领域，无畏主义促进了批判性思维和理性思考的发展，推动了哲学研究的进步。在文学和艺术领域，无畏主义激发了大量的文学作品和艺术创作，许多作家和艺术家通过作品探讨了人类存在的意义和生活的真实。

#### 总结

无畏主义起源于18世纪末和19世纪初的启蒙运动，经过19世纪的发展，成为了一种具有广泛影响的哲学思潮。它挑战了传统的价值观和信仰，鼓励人们质疑和反思现有的社会秩序和伦理规范。无畏主义在现代依然具有深远的影响，对哲学、文学、艺术和心理学等领域产生了重要的影响。

-- users.sql
CREATE TABLE users (

**前端（Vue.js）**：

```html
<!-- src/components/Login.vue -->
<template>
  <div>
    <h1>Login</h1>
    <form @submit.prevent="login">
      <input type="text" v-model="username" placeholder="Username" required />
      <input type="password" v-model="password" placeholder="Password" required />
      <button type="submit">Login</button>
    </form>
  </div>
</template>

<script>
export default {
  data() {
    return {
      username: '',
      password: ''
    };
  },
  methods: {
    async login() {
      const response = await axios.post('/api/login', {
        username: this.username,
        password: this.password
      });
      if (response.data.success) {
        this.$store.commit('setUser', response.data.user);
        this.$router.push('/self-assessment');
      } else {
        alert('Invalid credentials');
      }
    }
  }
};
</script>
```

#### 代码应用解读与分析

**后端解读**：

- **Application.java**：这是 Spring Boot 的主类，用于启动应用程序。通过调用 `SpringApplication.run`，应用程序被启动，并监听 8080 端口上的 HTTP 请求。

- **数据库脚本**：`users.sql` 用于创建用户表，`self_assessment.sql` 用于创建自我评估表，`questions.sql` 用于创建问题表。这些表通过外键关联，确保数据的完整性。

- **前端解读**：

  - **src/components/Login.vue**：这是登录组件，它包含一个表单，用户可以在其中输入用户名和密码。当用户提交表单时，组件会调用 `login` 方法，该方法通过 Axios 发送 POST 请求到后端 `/api/login` 接口。

    - `v-model` 用于双向数据绑定，确保输入框中的数据与组件的 `data` 属性中的值保持一致。
    - `@submit.prevent` 用于阻止表单默认的提交行为，从而使用 JavaScript 处理提交逻辑。

**系统交互**：

- 用户在登录页面输入用户名和密码，提交表单。
- 前端将请求发送到后端 `/api/login` 接口。
- 后端验证用户名和密码，如果验证成功，返回包含用户信息的 JSON 响应。
- 前端接收到成功响应后，将用户信息存储到 Vuex 状态管理库中，并重定向到自我评估页面。
