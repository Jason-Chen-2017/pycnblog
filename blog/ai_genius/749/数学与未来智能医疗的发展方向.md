#### 线性回归

```markdown
## 3.1 线性回归

线性回归是一种常用的统计学方法，用于分析两个变量之间的线性关系。假设我们有两个变量 $x$ 和 $y$，线性回归试图找到一个直线方程 $y = ax + b$，使得 $y$ 的预测值与实际值尽可能接近。

### 3.1.1 线性回归原理

线性回归的基本原理是找到两个变量之间的最佳拟合直线。这个过程可以通过最小二乘法实现。

### 3.1.2 线性回归算法伪代码

```
// 输入：数据集X，数据集Y
// 输出：拟合直线的参数a和b

// 1. 计算X和Y的均值
meanX = mean(X)
meanY = mean(Y)

// 2. 计算X和Y的协方差
covariance = sum((X - meanX) * (Y - meanY))

// 3. 计算X的方差
varianceX = sum((X - meanX)^2)

// 4. 计算斜率a
a = covariance / varianceX

// 5. 计算截距b
b = meanY - a * meanX

// 返回参数a和b
return a, b
```

#### 支持向量机

```markdown
## 3.2 支持向量机

支持向量机（SVM）是一种二类分类模型，其基本模型定义为特征空间上的间隔最大的线性分类器，间隔最大使它成为实际的硬间隔分类器。SVM的学习策略就是间隔最大化，可形式化为一个求解凸二次规划问题的过程。

### 3.2.1 支持向量机原理

SVM的核心思想是找到一个最优的超平面，使得分类间隔最大化。这个超平面可以将两类数据点分开，同时最小化误分类的损失。

### 3.2.2 支持向量机算法伪代码

```
// 输入：训练数据集D，特征空间H，损失函数L
// 输出：最优超平面参数w和偏置b

// 1. 定义损失函数
L(w) = C * Σ(max(0, 1 - y_i * (w^T * x_i + b)))

// 2. 求解凸二次规划问题
min_w, b L(w)

// 3. 使用KKT条件求解w和b
// a. 确保w^T * x_i + b > 1 - ε_i 对于所有正样本
// b. 确保w^T * x_i + b < 1 + ε_i 对于所有负样本
// c. 确保a_i >= 0 对于所有样本

// 返回参数w和b
return w, b
```

```markdown
## 3.3 决策树

决策树是一种常见的学习算法，它以树形结构进行决策，通过训练数据生成一系列的规则，这些规则用于对新的数据进行分类或回归。

### 3.3.1 决策树原理

决策树通过一系列的测试来选择最优的特征并进行分割。每个测试都基于特征的一个值，并产生两个或更多的分支。树叶表示分类结果。

### 3.3.2 决策树算法伪代码

```
// 输入：训练数据集D，特征集合F
// 输出：决策树T

// 1. 如果数据集D纯度达到阈值，则返回D的多数类别
if purity(D) > threshold
    return D的多数类别

// 2. 如果特征集合F为空，则返回D的多数类别
if F为空
    return D的多数类别

// 3. 选择最优的特征f
f = 选择最优特征(D, F)

// 4. 对于每个可能的特征值v，创建分支
for v in feature_values(f)
    D_v = {d | d的特征值f = v}
    T_v = 构建决策树(D_v, F - {f})

// 5. 返回决策树
return Node(f, T_v)
```

## 4.1 正态分布

正态分布是一种连续概率分布，它在许多领域都有广泛的应用，如医学统计、质量控制等。正态分布的概率密度函数为：

### 4.1.1 正态分布公式

$$
f(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

其中，$\mu$ 是均值，$\sigma^2$ 是方差。

### 4.1.2 正态分布举例

假设一个正常分布的随机变量X，均值为100，标准差为15。我们需要计算X在区间[85, 115]的概率。

### 4.1.3 正态分布计算

使用计算器或软件，我们可以得到：

$$
P(85 \leq X \leq 115) = P\left(\frac{85-100}{15} \leq Z \leq \frac{115-100}{15}\right) = P(-1 \leq Z \leq 1) \approx 0.6827
$$
```

#### 损失函数

```markdown
## 4.2 损失函数

在机器学习中，损失函数用于评估模型预测结果与实际结果之间的差异。常见的损失函数有均方误差（MSE）和交叉熵损失（Cross-Entropy Loss）。

### 4.2.1 均方误差（MSE）

均方误差是最常用的回归损失函数之一，它计算预测值与实际值之间的平方差的平均。

### 4.2.2 均方误差公式

$$
MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

其中，$y_i$ 是实际值，$\hat{y}_i$ 是预测值，$n$ 是样本数量。

### 4.2.3 均方误差举例

假设我们有一个样本数据集，预测值与实际值的差异如下：

| 实际值 | 预测值 | 差异 |
| --- | --- | --- |
| 2 | 1 | -1 |
| 4 | 3 | 1 |
| 6 | 5 | 1 |
| 8 | 7 | 1 |

均方误差计算如下：

$$
MSE = \frac{1}{4} [(-1)^2 + 1^2 + 1^2 + 1^2] = \frac{1}{4} [1 + 1 + 1 + 1] = 1
$$
```

#### 反向传播算法

```markdown
## 4.3 反向传播算法

反向传播算法是神经网络训练的核心算法，用于计算输出层误差并将其反向传播到隐藏层，从而更新网络参数。

### 4.3.1 反向传播算法原理

反向传播算法分为两个阶段：

1. 前向传播：计算输入层到隐藏层、隐藏层到输出层的输出。
2. 反向传播：计算误差，并更新网络参数。

### 4.3.2 反向传播算法公式

假设我们有一个两层神经网络，输入层为 $X$，隐藏层为 $H$，输出层为 $Y$。输出层的误差为：

$$
\delta_Y = \frac{\partial L}{\partial Y}
$$

隐藏层的误差为：

$$
\delta_H = \frac{\partial L}{\partial H} = \sigma'(\text{激活函数的导数}) \cdot \frac{\partial L}{\partial Z}
$$

其中，$\sigma'$ 是激活函数的导数，$L$ 是损失函数。

### 4.3.3 反向传播算法举例

假设我们有一个简单的两层神经网络，输入为 $X = [1, 2]$，隐藏层神经元数为 2，输出为 $Y = [0.5, 0.5]$。损失函数为均方误差（MSE）。

1. 前向传播：

$$
Z_1 = X_1 \cdot W_{11} + X_2 \cdot W_{12} + b_1 \\
Z_2 = X_1 \cdot W_{21} + X_2 \cdot W_{22} + b_2 \\
H = \sigma(Z_1), \sigma(Z_2) \\
Y = H_1 \cdot W_{11} + H_2 \cdot W_{21} + b_2
$$

2. 反向传播：

$$
\delta_Y = \frac{\partial MSE}{\partial Y} = -[0.5 - 1] \cdot [0.5 - 0.5] = 0 \\
\delta_H = \sigma'(Z_1), \sigma'(Z_2) \cdot \delta_Y \\
dW_{11} = \delta_H \cdot X_1 \\
dW_{12} = \delta_H \cdot X_2 \\
db_1 = \delta_H \\
dW_{21} = \delta_H \cdot X_1 \\
dW_{22} = \delta_H \cdot X_2 \\
db_2 = \delta_H
$$

通过计算，我们可以更新网络参数 $W$ 和 $b$。
```

### 核心算法原理讲解

在这一部分，我们选择了几种核心算法进行讲解，并使用伪代码详细阐述了这些算法的原理。

#### 线性回归

线性回归是一种常用的统计学方法，用于分析两个变量之间的线性关系。假设我们有两个变量 $x$ 和 $y$，线性回归试图找到一个直线方程 $y = ax + b$，使得 $y$ 的预测值与实际值尽可能接近。

```markdown
## 3.1 线性回归

### 3.1.1 线性回归原理

线性回归的基本原理是找到两个变量之间的最佳拟合直线。这个过程可以通过最小二乘法实现。

### 3.1.2 线性回归算法伪代码

```
// 输入：数据集X，数据集Y
// 输出：拟合直线的参数a和b

// 1. 计算X和Y的均值
meanX = mean(X)
meanY = mean(Y)

// 2. 计算X和Y的协方差
covariance = sum((X - meanX) * (Y - meanY))

// 3. 计算X的方差
varianceX = sum((X - meanX)^2)

// 4. 计算斜率a
a = covariance / varianceX

// 5. 计算截距b
b = meanY - a * meanX

// 返回参数a和b
return a, b
```

#### 支持向量机

支持向量机（SVM）是一种二类分类模型，其基本模型定义为特征空间上的间隔最大的线性分类器，间隔最大使它成为实际的硬间隔分类器。SVM的学习策略就是间隔最大化，可形式化为一个求解凸二次规划问题的过程。

```markdown
## 3.2 支持向量机

### 3.2.1 支持向量机原理

SVM的核心思想是找到一个最优的超平面，使得分类间隔最大化。这个超平面可以将两类数据点分开，同时最小化误分类的损失。

### 3.2.2 支持向量机算法伪代码

```
// 输入：训练数据集D，特征空间H，损失函数L
// 输出：最优超平面参数w和偏置b

// 1. 定义损失函数
L(w) = C * Σ(max(0, 1 - y_i * (w^T * x_i + b)))

// 2. 求解凸二次规划问题
min_w, b L(w)

// 3. 使用KKT条件求解w和b
// a. 确保w^T * x_i + b > 1 - ε_i 对于所有正样本
// b. 确保w^T * x_i + b < 1 + ε_i 对于所有负样本
// c. 确保a_i >= 0 对于所有样本

// 返回参数w和b
return w, b
```

#### 决策树

决策树是一种常见的学习算法，它以树形结构进行决策，通过训练数据生成一系列的规则，这些规则用于对新的数据进行分类或回归。

```markdown
## 3.3 决策树

### 3.3.1 决策树原理

决策树通过一系列的测试来选择最优的特征并进行分割。每个测试都基于特征的一个值，并产生两个或更多的分支。树叶表示分类结果。

### 3.3.2 决策树算法伪代码

```
// 输入：训练数据集D，特征集合F
// 输出：决策树T

// 1. 如果数据集D纯度达到阈值，则返回D的多数类别
if purity(D) > threshold
    return D的多数类别

// 2. 如果特征集合F为空，则返回D的多数类别
if F为空
    return D的多数类别

// 3. 选择最优的特征f
f = 选择最优特征(D, F)

// 4. 对于每个可能的特征值v，创建分支
for v in feature_values(f)
    D_v = {d | d的特征值f = v}
    T_v = 构建决策树(D_v, F - {f})

// 5. 返回决策树
return Node(f, T_v)
```

### 数学模型和数学公式讲解

#### 正态分布

正态分布是一种连续概率分布，它在许多领域都有广泛的应用，如医学统计、质量控制等。正态分布的概率密度函数为：

$$
f(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

其中，$\mu$ 是均值，$\sigma^2$ 是方差。

```markdown
### 4.1 正态分布

#### 4.1.1 正态分布公式

$$
f(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

其中，$\mu$ 是均值，$\sigma^2$ 是方差。

#### 4.1.2 正态分布举例

假设一个正常分布的随机变量X，均值为100，标准差为15。我们需要计算X在区间[85, 115]的概率。

#### 4.1.3 正态分布计算

使用计算器或软件，我们可以得到：

$$
P(85 \leq X \leq 115) = P\left(\frac{85-100}{15} \leq Z \leq \frac{115-100}{15}\right) = P(-1 \leq Z \leq 1) \approx 0.6827
$$
```

#### 损失函数

在机器学习中，损失函数用于评估模型预测结果与实际结果之间的差异。常见的损失函数有均方误差（MSE）和交叉熵损失（Cross-Entropy Loss）。

```markdown
### 4.2 损失函数

#### 4.2.1 均方误差（MSE）

均方误差是最常用的回归损失函数之一，它计算预测值与实际值之间的平方差的平均。

#### 4.2.2 均方误差公式

$$
MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

其中，$y_i$ 是实际值，$\hat{y}_i$ 是预测值，$n$ 是样本数量。

#### 4.2.3 均方误差举例

假设我们有一个样本数据集，预测值与实际值的差异如下：

| 实际值 | 预测值 | 差异 |
| --- | --- | --- |
| 2 | 1 | -1 |
| 4 | 3 | 1 |
| 6 | 5 | 1 |
| 8 | 7 | 1 |

均方误差计算如下：

$$
MSE = \frac{1}{4} [(-1)^2 + 1^2 + 1^2 + 1^2] = \frac{1}{4} [1 + 1 + 1 + 1] = 1
$$
```

#### 反向传播算法

反向传播算法是神经网络训练的核心算法，用于计算输出层误差并将其反向传播到隐藏层，从而更新网络参数。

```markdown
### 4.3 反向传播算法

#### 4.3.1 反向传播算法原理

反向传播算法分为两个阶段：

1. 前向传播：计算输入层到隐藏层、隐藏层到输出层的输出。
2. 反向传播：计算误差，并更新网络参数。

#### 4.3.2 反向传播算法公式

假设我们有一个两层神经网络，输入层为 $X$，隐藏层为 $H$，输出层为 $Y$。输出层的误差为：

$$
\delta_Y = \frac{\partial L}{\partial Y}
$$

隐藏层的误差为：

$$
\delta_H = \frac{\partial L}{\partial H} = \sigma'(\text{激活函数的导数}) \cdot \frac{\partial L}{\partial Z}
$$

其中，$\sigma'$ 是激活函数的导数，$L$ 是损失函数。

#### 4.3.3 反向传播算法举例

假设我们有一个简单的两层神经网络，输入为 $X = [1, 2]$，隐藏层神经元数为 2，输出为 $Y = [0.5, 0.5]$。损失函数为均方误差（MSE）。

1. 前向传播：

$$
Z_1 = X_1 \cdot W_{11} + X_2 \cdot W_{12} + b_1 \\
Z_2 = X_1 \cdot W_{21} + X_2 \cdot W_{22} + b_2 \\
H = \sigma(Z_1), \sigma(Z_2) \\
Y = H_1 \cdot W_{11} + H_2 \cdot W_{21} + b_2
$$

2. 反向传播：

$$
\delta_Y = \frac{\partial MSE}{\partial Y} = -[0.5 - 1] \cdot [0.5 - 0.5] = 0 \\
\delta_H = \sigma'(Z_1), \sigma'(Z_2) \cdot \delta_Y \\
dW_{11} = \delta_H \cdot X_1 \\
dW_{12} = \delta_H \cdot X_2 \\
db_1 = \delta_H \\
dW_{21} = \delta_H \cdot X_1 \\
dW_{22} = \delta_H \cdot X_2 \\
db_2 = \delta_H
$$

通过计算，我们可以更新网络参数 $W$ 和 $b$。
```
