import cmath

def solve_quadric(a, b, c):
    D = b**2 - 4*a*c
    if D < 0:
        return "无实数解"
    elif D == 0:
        x = -b / (2 * a)
        return x
    else:

1. 当\(D < 0\)时，方程无实数解。
