1. **物光波**：首先，我们让一个已知的光波（称为参考光波）照射到物体上。物体表面的反射光波与参考光波发生干涉，形成一个干涉图样。这个干涉图样包含了物体表面的三维信息。

   $$ E_{物} = E_{0物} \cos(kx - \omega t) $$
   
   其中，$E_{0物}$ 是物光波的振幅，$k$ 是波数，$x$ 是位置坐标，$\omega$ 是角频率，$t$ 是时间。

2. **参考光波**：然后，我们使用一个相干性很高的参考光波照射到物体上。参考光波与物光波发生干涉，形成干涉条纹。这些干涉条纹记录了物体的三维信息。

   $$ E_{参考} = E_{0参考} \cos(kx' - \omega t) $$
   
   其中，$E_{0参考}$ 是参考光波的振幅，$x'$ 是参考光波的方向。

3. **干涉图样**：物体表面的反射光波与参考光波干涉后，形成干涉图样。这个干涉图样包含了物体的三维信息。

   $$ E_{干涉} = E_{物} + E_{参考} = E_{0物} \cos(kx - \omega t) + E_{0参考} \cos(kx' - \omega t) $$

### 3. 再现

在再现阶段，我们使用全息图样来生成三维图像。具体操作如下：

1. **再现光波**：使用与记录阶段相同的参考光波照射到全息图样上。参考光波与全息图样上的干涉图样发生干涉，形成再现光波。

   $$ E_{再现} = E_{参考} \cos(kx'' - \omega t) $$
   
   其中，$x''$ 是再现光波的方向。

2. **三维图像**：再现光波与物体表面的反射光波叠加，形成三维图像。这个图像与原始物体非常相似，具有高度的立体感和真实感。

   $$ E_{总} = E_{再现} + E_{物} = E_{参考} \cos(kx'' - \omega t) + E_{0物} \cos(kx - \omega t) $$

```python
# 导入必要的库
import numpy as np
import matplotlib.pyplot as plt

# 数据加载函数
def load_data(filename):
    data = np.loadtxt(filename)
    return data

# 数据清洗函数
def clean_data(data):
    cleaned_data = data[data[:, 0] > 0]
    return cleaned_data

# 数据预处理函数
def preprocess_data(data):
    preprocessed_data = data * data[:, 1]**2
    return preprocessed_data

# 特征提取函数
def extract_features(cmb_data, expansion_data):
    features = np.concatenate((cmb_data, expansion_data), axis=1)
    return features

# 数学模型构建函数
def build_model(features):
    model = np.polyfit(features[:, 0], features[:, 1], 2)
    return model

# 参数设置函数
def set_params(model):
    params = model[:, 1]
    return params

# 模型训练函数
def train_model(model, params):
    trained_model = np.polyfit(params[:, 0], params[:, 1], 2)
    return trained_model

# 模型预测函数
def predict_model(model, features):
    predictions = model * features[:, 1]**2
    return predictions

# 结果验证函数
def validate_results(predictions, actual_values):
    error = predictions - actual_values
    print("Error:", error)

# 结果解释函数
def explain_results(predictions):
    print("Predictions:", predictions)

# 主函数
def main():
    cmb_data = load_data('cmb_data.txt')
    expansion_data = load_data('expansion_data.txt')

    cleaned_cmb_data = clean_data(cmb_data)
    preprocessed_expansion_data = preprocess_data(expansion_data)

    features = extract_features(cleaned_cmb_data, preprocessed_expansion_data)
    model = build_model(features)
    params = set_params(model)
    trained_model = train_model(model, params)

    predictions = predict_model(trained_model, features)
    validate_results(predictions, features[:, 1])
    explain_results(predictions)

    plt.plot(features[:, 0], features[:, 1], 'ro')
    plt.plot(predictions, label='Prediction')
    plt.legend()
    plt.show()

if __name__ == "__main__":
    main()
```
