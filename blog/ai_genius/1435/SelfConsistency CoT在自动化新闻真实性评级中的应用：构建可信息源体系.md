Fact-checking involves verifying the accuracy of specific claims within a news story, while sentiment analysis focuses on the emotional tone of the content. In contrast, Self-Consistency CoT looks at the overall coherence of the story, including its content, sources, and references.

Reference consistency involves checking the consistency of the references used within the story.

#### **2.2.3 Python Code and Detailed Explanation**

The Python code for implementing the Self-Consistency CoT algorithm is provided below along with a detailed explanation. This section covers the key components of the code and their functionality.

```python
# 导入所需库
import nltk
from nltk.tokenize import word_tokenize
from nltk.corpus import stopwords
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 初始化停用词
nltk.download('stopwords')
stop_words = set(stopwords.words('english'))

# 输入新闻内容
news_content = "The new policy aims to reduce carbon emissions by 50% within the next decade."

# 解析内容
tokens = word_tokenize(news_content)
filtered_tokens = [token for token in tokens if token not in stop_words]

# 计算内容一致性分数
# 使用TF-IDF向量表示文本
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform([' '.join(filtered_tokens)])

# 计算内容相似度
similarity = cosine_similarity(tfidf_matrix[0:1], tfidf_matrix[0:1])

# 评估新闻真实性
if similarity[0][0] > 0.5:
    print("新闻真实性较高。")
else:
    print("新闻真实性较低，存在潜在问题。")
```
