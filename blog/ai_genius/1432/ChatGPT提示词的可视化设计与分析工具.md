#### 4.2 D3.js在提示词可视化中的应用

以下是一个简单的D3.js示例，展示如何创建一个词云图，用于展示ChatGPT提示词的分布和频率。

```javascript
// 数据准备
const data = [
  { word: "课程", count: 100 },
  { word: "作业", count: 80 },
  { word: "考试", count: 60 },
  { word: "教师", count: 40 },
  { word: "平台", count: 20 }
];

// 设置画布大小
const width = 800;
const height = 600;

// 创建SVG元素
const svg = d3.select("body")
  .append("svg")
  .attr("width", width)
  .attr("height", height);

// 设置词云的半径
const radius = Math.min(width, height) / 2 - 20;

// 创建词云
const wordCloud = d3.layout.cloud()
  .size([width, height])
  .words(data.map((d, i) => ({ text: d.word, size: d.count * 10 })))
  .padding(5)
  .rotate(() => 0)
  .font("Impact")
  .fontSize(d => d.size)
  .on("end", draw);

// 绘制词云
wordCloud.start();

function draw(words) {
  svg.selectAll("text").remove(); // 清除旧文本
  svg.selectAll(".word")
    .data(words)
    .enter().append("text")
      .attr("class", "word")
      .style("font-size", d => d.size + "px")
      .style("font-family", "Impact")
      .attr("text-anchor", "middle")
      .attr("transform", d => "translate(" + [d.x, d.y] + ")rotate(" + d.rotate + ")")
      .text(d => d.text);
}

```

在这个示例中，我们首先准备了一组提示词数据，并设置了画布大小和词云的半径。然后，我们使用D3.js的`cloud`布局函数创建词云，并根据提示词的频率调整字体大小。最后，我们使用`draw`函数绘制词云，并旋转文本以避免重叠。

通过这个简单的示例，我们可以看到D3.js在提示词可视化中的应用。D3.js的灵活性和强大功能，使得我们可以轻松创建各种复杂和动态的可视化图表，从而更好地理解和分析提示词数据。
