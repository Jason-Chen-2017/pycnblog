### 2.1 机器学习基础

机器学习是人工智能的一个分支，其主要目的是让计算机从数据中学习规律，并利用这些规律进行预测或决策。机器学习的基本概念包括监督学习、无监督学习和强化学习。

- **监督学习（Supervised Learning）**：监督学习是一种从标记数据中学习的方法。标记数据是指每一条数据都有一个对应的标签，学习目标是预测未知数据的标签。常见的监督学习算法有线性回归、逻辑回归、支持向量机（SVM）、决策树、随机森林等。

  - **线性回归（Linear Regression）**：
    - **目标**：通过已知输入和输出关系，预测新的输入值。
    - **公式**：
      $$
      y = \beta_0 + \beta_1x
      $$
    - **例子**：预测房价，输入是房屋面积，输出是房价。

  - **逻辑回归（Logistic Regression）**：
    - **目标**：用于分类问题，通过输入特征预测输出类别概率。
    - **公式**：
      $$
      P(y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x)}}
      $$
    - **例子**：判断邮件是否为垃圾邮件，输入是邮件特征，输出是垃圾邮件概率。

- **无监督学习（Unsupervised Learning）**：无监督学习是从未标记的数据中学习规律的方法。其目标通常是将数据分为若干类别或发现数据中的隐藏结构。常见的无监督学习算法有聚类算法、主成分分析（PCA）等。

  - **K均值聚类（K-Means Clustering）**：
    - **目标**：将数据分为K个簇，使每个簇内的数据点尽可能接近，簇间的数据点尽可能远。
    - **公式**：
      $$
      \text{簇中心} = \frac{1}{N}\sum_{i=1}^{N} x_i
      $$
    - **例子**：将顾客数据分为不同的群体，便于市场细分。

  - **主成分分析（PCA）**：
    - **目标**：降低数据维度，同时保留主要信息。
    - **公式**：
      $$
      Z = P\Lambda^{1/2}
      $$
    - **例子**：从多维数据中提取主要特征，简化数据结构。

- **强化学习（Reinforcement Learning）**：强化学习是一种通过试错法学习策略的机器学习方法。其目标是最大化长期奖励。常见的强化学习算法有Q学习、深度Q网络（DQN）等。

  - **Q学习（Q-Learning）**：
    - **目标**：学习最优策略，选择能够带来最大奖励的动作。
    - **公式**：
      $$
      Q(s, a) = Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]
      $$
    - **例子**：自动驾驶，通过不断尝试来学习最优行驶路径。

### 2.2 深度学习

深度学习是机器学习的一个重要分支，其核心思想是通过多层神经网络（Neural Networks）来模拟人脑的学习过程。深度学习在图像识别、语音识别、自然语言处理等领域取得了显著成果。

- **神经网络与深度学习的关系**：神经网络是深度学习的基础，深度学习通过增加网络层数来提高模型的表达能力。

  - **单层神经网络**：
    - **结构**：输入层、输出层和中间层。
    - **激活函数**：常用的激活函数有Sigmoid、ReLU、Tanh等。

    ```python
    import numpy as np

    def sigmoid(x):
        return 1 / (1 + np.exp(-x))

    def relu(x):
        return np.maximum(0, x)

    def tanh(x):
        return np.tanh(x)
    ```

  - **多层神经网络**：
    - **结构**：输入层、多个隐藏层和输出层。
    - **反向传播算法**：用于更新网络权重，提高模型准确性。

    ```python
    import numpy as np

    def forward(x, weights):
        return sigmoid(np.dot(x, weights))

    def backward(x, y, weights, learning_rate):
        output = forward(x, weights)
        error = y - output
        dweights = np.dot(x.T, error)
        return dweights
    ```

- **卷积神经网络（CNN）**：卷积神经网络是深度学习在图像处理领域的典型应用。

  - **基本结构**：卷积层、池化层、全连接层。
  - **卷积层**：通过卷积操作提取图像特征。
    ```python
    import numpy as np

    def conv2d(input, filter):
        return np.sum(input * filter, axis=1)
    ```

  - **池化层**：通过池化操作降低数据维度。
    ```python
    import numpy as np

    def max_pooling(input, pool_size=(2, 2)):
        return np.max(input[:, ::pool_size[0], ::pool_size[1]], axis=1)
    ```

- **循环神经网络（RNN）**：循环神经网络是深度学习在序列数据处理领域的典型应用。

  - **基本结构**：输入层、隐藏层、输出层。
  - **RNN单元**：通过循环结构处理序列数据。
    ```python
    import numpy as np

    def rnn(input, hidden_state, weights):
        return np.tanh(np.dot(input, weights['input_to_hidden']) + np.dot(hidden_state, weights['hidden_to_hidden']))
    ```

#### 时间序列预测方法

时间序列分析是一种用于分析和预测时间序列数据的统计方法。常见的时间序列预测方法包括ARIMA模型、指数平滑法等。

- **ARIMA模型（AutoRegressive Integrated Moving Average Model）**：ARIMA模型是一种常用的统计模型，用于分析和预测时间序列数据。它通过自回归、差分和移动平均三个步骤来建模时间序列。

  ```python
  from statsmodels.tsa.arima.model import ARIMA

  model = ARIMA(series, order=(1, 1, 1))
  model_fit = model.fit()
  forecast = model_fit.forecast(steps=10)
  ```

  - **自回归（AutoRegressive，AR）**：利用过去值的线性组合来预测当前值。
  - **差分（Integrated，I）**：通过差分操作来平稳时间序列。
  - **移动平均（Moving Average，MA）**：利用过去误差的线性组合来预测当前值。

- **指数平滑法（Exponential Smoothing）**：指数平滑法是一种简单而有效的时间序列预测方法，通过给定不同权重来平滑历史数据。

  ```python
  import numpy as np

  alpha = 0.2
  smoothed_series = [alpha * new_value + (1 - alpha) * prev_value for new_value, prev_value in zip(series[1:], series[:-1])]
  ```

水资源优化配置通常采用线性规划、整数规划、多目标规划等方法建立数学模型。
