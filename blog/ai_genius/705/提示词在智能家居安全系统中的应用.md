3. **数据安全**：保障用户数据在存储、传输和使用过程中的安全。

2. **信息化阶段**：随着计算机技术和网络技术的发展，家庭安全系统开始引入网络通信技术，实现了远程监控和报警功能。

智能家居安全系统的重要性体现在以下几个方面：

1. **数据保护**：随着智能家居设备数量的增加，用户产生的数据量也在不断上升，保护这些数据对于维护用户的隐私至关重要。
2. **设备安全**：确保家庭设备不被恶意攻击者操控，防止设备成为入侵家庭的工具。
3. **家庭安全**：智能家居安全系统能够及时发现和预防家庭安全事件，提高家庭的安全系数。

import speech_recognition as sr

def recognize_speech_from_mic():
    r = sr.Recognizer()
    
    with sr.Microphone() as source:

        audio = r.listen(source)

    try:
        text = r.recognize_google(audio, language='zh-CN')

        return text
    except sr.UnknownValueError:
        print("无法识别语音")
        return None
    except sr.RequestError as e:
        print("无法连接到语音服务；{0}".format(e))
        return None
