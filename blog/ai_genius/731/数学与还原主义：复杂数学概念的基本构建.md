```

```

**步骤 1**：分解方程

将方程组分解为两个基本方程：

```

**步骤 2**：求解基本方程

对每个基本方程进行求解：

对于方程 1：

```

x = (7 - 3y) / 2
```

对于方程 2：

```

x = (1 + y) / 4
```

**步骤 3**：求解整体方程组

将基本方程的解代入原方程组，得到：

```
x = (7 - 3y) / 2
x = (1 + y) / 4
```

**步骤 4**：求解解向量

通过解方程组，我们可以得到解向量：

```
