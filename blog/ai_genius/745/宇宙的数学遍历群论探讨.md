**1. 遍历群**

遍历群是一组映射，这些映射将一个集合中的元素映射到另一个集合中的元素。更具体地说，如果集合A和集合B之间存在一组映射f：A→B，那么这组映射构成了A到B的遍历群，记作\( \mathcal{T}(A, B) \)。

遍历群具有以下性质：

- **封闭性**：如果f和g是遍历群中的映射，那么它们的组合（即f∘g）也是遍历群中的映射。
- **交换性**：如果f和g是遍历群中的映射，那么它们的组合（即f∘g）与组合的顺序无关，即\( (f \circ g) = (g \circ f) \)。
- **存在单位元素**：对于任意的遍历群，都存在一个单位映射，即恒等映射id：A→A，使得对于任意的映射f，都有\( f \circ id = id \circ f = f \)。

**2. 自同态群**

自同态群是一组自同构映射，即这些映射将一个集合映射到自身。更具体地说，如果集合A存在一组自同构映射\( \mathcal{S}(A) \)，那么这组映射构成了A的自同态群。

自同态群具有以下性质：

- **封闭性**：如果f和g是自同态群中的映射，那么它们的组合（即f∘g）也是自同态群中的映射。
- **交换性**：如果f和g是自同态群中的映射，那么它们的组合（即f∘g）与组合的顺序无关，即\( (f \circ g) = (g \circ f) \)。

**3. 变换群**

变换群是一组连续变换，这些变换将一个空间映射到另一个空间。在数学和物理学中，变换群被广泛用于描述物理现象的对称性。例如，在经典力学中，变换群用于描述物理系统的对称性，而在量子力学中，变换群则用于描述量子态的对称性。

- **交换性**：如果f和g是变换群中的映射，那么它们的组合（即f∘g）与组合的顺序无关，即\( (f \circ g) = (g \circ f) \)。
