**类型判断的伪代码：**

```plaintext
function typeCheck(expression: Expression, typeSystem: TypeSystem):
    if expression is a variable:
        return typeSystem.getType(expression.name)
    elif expression is an operation:

        else:

    else:
        throw TypeError("Unknown expression")
```

在这个伪代码中，`typeCheck`函数递归地检查表达式的类型。如果表达式是变量，则直接返回其类型。如果表达式是操作，则分别检查左右表达式的类型，并确定操作是否合法。
