### 2.7.3 源代码实现

以下是一个简单的Python代码示例，用于处理学生旅行数据，计算旅行时间、距离和人均花费。

```python
import pandas as pd

# 加载数据
data = pd.read_csv('travel_data.csv')

# 计算旅行时间
total_time = data['duration'].sum()
average_time = total_time / len(data)

# 计算总距离
total_distance = data['distance'].sum()
average_distance = total_distance / len(data)

# 计算人均花费
total_cost = data['cost'].sum()
average_cost = total_cost / len(data)

# 输出结果
print(f"总旅行时间：{total_time}小时")
print(f"人均旅行时间：{average_time}小时")
print(f"总旅行距离：{total_distance}公里")
print(f"人均旅行距离：{average_distance}公里")
print(f"总花费：{total_cost}元")
print(f"人均花费：{average_cost}元")
```
