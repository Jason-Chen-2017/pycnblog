```python
# 露天电影社区管理系统

class Screening:
    def __init__(self, title, time, location):
        self.title = title
        self.time = time
        self.location = location
        self.tickets_sold = 0

    def sell_ticket(self):
        if self.tickets_sold < 100:  # 最大观众容量
            self.tickets_sold += 1
            return f"Ticket sold for {self.title}. Total sold: {self.tickets_sold}"
        else:
            return "Sorry, the screening is fully booked."

class Customer:
    def __init__(self, name, email):
        self.name = name
        self.email = email

    def register_for_screening(self, screening):
        if screening.tickets_sold < 100:
            screening.sell_ticket()
            return f"{self.name} has registered for {screening.title}."
        else:
            return "Sorry, the screening is fully booked."

# 演示
screening = Screening("The Godfather", "20:00", "Central Park")
customer = Customer("Alice", "alice@example.com")

print(screening.sell_ticket())  # 销售一张票
print(customer.register_for_screening(screening))  # Alice 注册观影

```

上述代码定义了两个主要类：`Screening` 和 `Customer`。`Screening` 类表示一场电影放映，具有标题、放映时间和场地属性，同时还记录了已售出的票数。`sell_ticket` 方法用于销售电影票，若票数未达到上限，则增加票数并返回成功信息；否则，返回满座信息。

`Customer` 类表示一个观众，具有姓名和邮箱属性。`register_for_screening` 方法用于观众注册观影，若放映仍有空位，则注册观众并返回成功信息；否则，返回满座信息。
