## 核心算法原理讲解（Python源代码）

```python
# 导入必要的库
import numpy as np

# 定义一个简单的神经网络结构
class SimpleNeuralNetwork:
    def __init__(self):
        # 初始化权重和偏置
        self.weights = np.random.rand(3, 1)
        self.bias = np.random.rand(1)

    # 定义前向传播函数
    def forward(self, x):
        self.x = x
        output = np.dot(x, self.weights) + self.bias
        return output

    # 定义反向传播函数
    def backward(self, d_output):
        d_weights = self.x.T.dot(d_output)
        d_bias = np.sum(d_output, axis=0, keepdims=True)
        return d_weights, d_bias

# 实例化神经网络
nn = SimpleNeuralNetwork()

# 输入数据
x = np.array([[1], [2], [3]])

# 前向传播
output = nn.forward(x)

# 反向传播
d_output = np.array([[0.5], [0.5], [0.5]])
d_weights, d_bias = nn.backward(d_output)

# 输出结果
print("Output:", output)
print("Derivative of Weights:", d_weights)
print("Derivative of Bias:", d_bias)
```

$$
y = \sigma(z)
$$

其中，$y$ 表示输出值，$\sigma$ 是 sigmoid 函数，$z$ 是输入值。

$$
\frac{dz}{dx} = \sigma'(z)
$$

这是 sigmoid 函数的导数，表示输入值 $x$ 对输出值 $z$ 的敏感性。

$$
\frac{dL}{dx} = \frac{dL}{dz} \cdot \frac{dz}{dx}
$$

这是损失函数 $L$ 对输入值 $x$ 的敏感性，$dL/dz$ 是损失函数对输出值 $z$ 的敏感性。

$$
w_{new} = w_{old} - \alpha \cdot \frac{dL}{dx}
$$

这是权重更新公式，$w_{new}$ 是新权重，$w_{old}$ 是旧权重，$\alpha$ 是学习率。
