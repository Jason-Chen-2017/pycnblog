### # 3.3 Python源代码实现

以下是一个简化的图注意力模型Python源代码实现：

```python
import torch
import torch.nn as nn

class GraphAttentionModel(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GraphAttentionModel, self).__init__()
        
        self.attention = nn.Linear(input_dim, hidden_dim)
        self.output = nn.Linear(hidden_dim, output_dim)
        
    def forward(self, inputs):
        attention_scores = self.attention(inputs)
        attention_weights = torch.softmax(attention_scores, dim=1)
        attended_inputs = torch.sum(attention_weights * inputs, dim=1)
        outputs = self.output(attended_inputs)
        return outputs
```

### # 3.4 数学模型与公式

图注意力模型的数学描述如下：

$$
\text{attention\_scores} = \text{attention}(\text{inputs})
$$

$$
\text{attention\_weights} = \text{softmax}(\text{attention\_scores})
$$

$$
\text{attended\_inputs} = \text{sum}(\text{attention\_weights} * \text{inputs}, \text{dim}=1)
$$

$$
\text{outputs} = \text{output}(\text{attended\_inputs})
$$
