## 第2章基本数据结构

### 2.1 数组和链表

#### 2.1.1 数组的基本操作

数组是一种线性数据结构，它由一系列元素组成，这些元素在内存中连续存储。数组的基本操作包括：

- **初始化**：创建一个数组，并为其分配内存空间。
- **插入**：在数组中的某个位置插入一个新元素。
- **删除**：删除数组中的一个元素。
- **查找**：在数组中查找一个特定的元素。

#### 2.1.2 链表的基本操作

链表是一种线性数据结构，它由一系列节点组成，每个节点包含一个数据和指向下一个节点的指针。链表的基本操作包括：

- **初始化**：创建一个链表，并初始化头节点。
- **插入**：在链表的某个位置插入一个新节点。
- **删除**：删除链表中的一个节点。
- **查找**：在链表中查找一个特定的节点。

### 2.2 栈和队列

#### 2.2.1 栈的运作原理

栈是一种后进先出（Last In First Out, LIFO）的数据结构。栈的操作主要包括：

- **压栈**：将一个元素插入到栈顶。
- **出栈**：从栈顶删除一个元素。
- **栈顶元素**：获取栈顶元素的值。

#### 2.2.2 队列的运作原理

队列是一种先进先出（First In First Out, FIFO）的数据结构。队列的操作主要包括：

- **入队**：将一个元素插入到队列尾部。
- **出队**：从队列头部删除一个元素。
- **队首元素**：获取队列头部的元素值。

### 2.3 树和图

#### 2.3.1 树的基本结构

树是一种非线性数据结构，它由一组节点组成，每个节点可以有零个或多个子节点。树的基本结构包括：

- **根节点**：树的起始节点，没有父节点。
- **内部节点**：拥有子节点的节点。
- **叶子节点**：没有子节点的节点。
- **子树**：以某个节点为根节点的子节点及其后代节点组成的树。

#### 2.3.2 图的基本结构

图是一种非线性数据结构，它由一组节点和连接这些节点的边组成。图的基本结构包括：

- **节点**：图中的数据元素。
- **边**：连接两个节点的线段，表示节点之间的某种关系。
- **路径**：连接两个节点的节点序列。
- **连通性**：图中的节点是否可以通过边相连。

### 4.1 图的基本算法

#### 4.1.1 图的遍历算法

图的遍历算法用于遍历图中的所有节点，常见的遍历算法包括深度优先搜索（DFS）和广度优先搜索（BFS）。

- **深度优先搜索（DFS）**：从某个节点开始，深入到最远的节点，然后回溯。
- **广度优先搜索（BFS）**：从某个节点开始，依次遍历其相邻的节点，然后再逐层遍历。

#### 4.1.2 图的连通性算法

图的连通性算法用于判断图中的节点是否连通。常见的连通性算法包括：

- **DFS判断连通性**：通过深度优先搜索，判断图中的节点是否在同一连通分量中。

```plaintext
    if node is null:
        return
    visit node
    for each child in node.children:
        DFS(child)
```

**广度优先搜索（BFS）**

核心算法原理讲解：
广度优先搜索是一种用于遍历或搜索树或图的算法。它从根节点开始，依次遍历其相邻的节点，然后再逐层遍历。

伪代码：

```plaintext
function BFS(graph):
    queue = empty queue
    enqueue(graph.root)
    while queue is not empty:
        node = dequeue(queue)
        visit node
        for each neighbor in node.neighbors:
            if neighbor is not visited:
                enqueue(neighbor)
```

```python
            # 更新速度
            particle.velocity += acceleration * dt
            # 更新位置

    def compute_gravity(self, particle):
        acceleration = np.zeros(3)
        for other_particle in self.particles:
            if particle != other_particle:
                dx = other_particle.position - particle.position
                r = np.linalg.norm(dx)
                f = G * particle.mass * other_particle.mass / r**2
```

```python
@jit(nopython=True)
def compute_gravity(particles, num_particles):
    accelerations = np.zeros((num_particles, 3))
    for i in range(num_particles):
        for j in range(i+1, num_particles):
            dx = particles[j].position - particles[i].position
            r = np.linalg.norm(dx)

                f = -G * particles[i].mass * particles[j].mass / r**2
                accelerations[i] += f * dx / r
                accelerations[j] += f * (-dx) / r
```
