    - **伪代码**：
      ```
      # 贝叶斯网络模型伪代码
      P(A|B) = (P(B|A) * P(A)) / P(B)

#### 2.2.3 数学公式在广告创意中的运用

- **广告效果计算**：
  - **点击率（CTR）**：\( CTR = \frac{点击次数}{展示次数} \)
  - **转化率（Conversion Rate）**：\( CR = \frac{转化次数}{点击次数} \)

- **极限**：用于描述函数的局部性质，常见的有：
  - **一元函数的极限**：\( \lim_{{x \to a}} f(x) \)
    - **公式**：\( \lim_{{x \to a}} f(x) = L \) 表示当 \( x \) 趋近于 \( a \) 时，函数 \( f(x) \) 的值趋近于 \( L \)
    - **伪代码**：
      ```
      # 一元函数的极限伪代码
      x = 变量
      a = 极限点
      L = limit(f, x, a)
      ```

- **导数**：用于描述函数的变化率，常见的有：
  - **一元函数的导数**：\( f'(x) = \lim_{{h \to 0}} \frac{{f(x+h) - f(x)}}{h} \)
    - **公式**：\( f'(x) \) 表示函数 \( f(x) \) 在点 \( x \) 的导数
    - **伪代码**：
      ```
      # 一元函数的导数伪代码
      x = 变量
      h = 微小增量
      f_prime(x) = limit((f(x+h) - f(x)) / h, h, 0)
      ```

- **积分**：用于计算函数在区间上的累积值，常见的有：
  - **一元函数的不定积分**：\( \int f(x) \, dx \)
    - **公式**：\( \int f(x) \, dx = F(x) + C \) 其中 \( F(x) \) 是 \( f(x) \) 的一个原函数，\( C \) 是积分常数
    - **伪代码**：
      ```
      # 一元函数的不定积分伪代码
      f = 函数
      F = indefinite_integral(f)
      ```
