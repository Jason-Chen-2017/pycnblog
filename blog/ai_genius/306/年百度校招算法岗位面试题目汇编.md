### 第1章：算法基础概念与数据结构

#### 1.1 算法概述

算法（Algorithm）是一系列定义明确的操作步骤，用于解决特定问题。算法的目的是在有限步骤内得到问题的解。在计算机科学中，算法研究如何高效地解决问题。算法的几个关键特性包括：

1. **确定性**：每一步都有明确的结果。
2. **有效性**：算法能够在有限时间内完成。
3. **有穷性**：算法在执行有限步骤后停止。

算法可以分为多种类型，如：

- **确定性算法**：如排序算法。
- **随机化算法**：如快速排序。
- **启发式算法**：如遗传算法。

#### 1.2 数据结构与算法

数据结构是组织和管理数据的方式。常见的数据结构包括：

- **数组**：一种固定大小的序列，用于存储元素。
- **链表**：一种动态数据结构，用于存储元素。
- **栈**：一种后进先出（LIFO）的数据结构。
- **队列**：一种先进先出（FIFO）的数据结构。
- **树**：一种层次化的数据结构，用于存储元素。
- **图**：一种由节点和边组成的数据结构。

不同的数据结构适用于不同的场景。算法通常依赖于数据结构来实现高效的操作。例如：

- **二分查找**：依赖于有序数组。
- **树的遍历**：依赖于树的结构。

#### 1.3 算法复杂度分析

算法复杂度是衡量算法性能的重要指标。算法复杂度分为两种：

- **时间复杂度**：描述算法执行时间与数据规模的关系。
- **空间复杂度**：描述算法占用内存与数据规模的关系。

常见的时间复杂度符号包括：

- \(O(1)\)：常数时间。
- \(O(n)\)：线性时间。
- \(O(n \log n)\)：对数时间。
- \(O(2^n)\)：指数时间。

#### 1.4 经典算法讲解

以下是一些经典算法及其应用：

- **排序算法**：冒泡排序、选择排序、插入排序、快速排序、归并排序等。
- **查找算法**：二分查找、哈希查找。
- **动态规划**：斐波那契数列、背包问题。
- **图算法**：最短路径算法（Dijkstra算法、Bellman-Ford算法）、最大流最小割算法。

### 第2章：动态规划与贪心算法

#### 2.1 动态规划基础

动态规划是一种优化算法，用于解决最优子结构问题。动态规划的关键在于将复杂问题分解为子问题，并存储子问题的解，避免重复计算。

动态规划通常包括以下三个步骤：

1. **定义状态**：将问题表示为状态转移方程。
2. **初始化边界条件**：为初始状态赋予初始值。
3. **递推计算**：根据状态转移方程，逐步计算最终状态。

以下是一个动态规划实例：**斐波那契数列**。

```python
# 斐波那契数列动态规划
def fibonacci(n):
    if n <= 1:
        return n
    dp = [0] * (n+1)
    dp[1] = 1
    for i in range(2, n+1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

#### 2.3 贪心算法基础

贪心算法是一种在每一步选择当前最优解的策略，旨在得到全局最优解。贪心算法通常包括以下两个步骤：

1. **局部最优选择**：在当前状态下，选择最优的局部解。
2. **递归或迭代**：不断更新状态，直至得到最终解。

以下是一个贪心算法实例：**最小生成树**（Kruskal算法）。

```python
# Kruskal算法：最小生成树
def kruskal(edges, n):
    parent = [i for i in range(n)]
    rank = [0] * n
    mst = []

    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]

    def union(x, y):
        rootX = find(x)
        rootY = find(y)
        if rootX != rootY:
            if rank[rootX] > rank[rootY]:
                parent[rootY] = rootX
            elif rank[rootX] < rank[rootY]:
                parent[rootX] = rootY
            else:
                parent[rootY] = rootX
                rank[rootX] += 1

    edges.sort(key=lambda x: x[2])
    for edge in edges:
        u, v, w = edge
        if find(u) != find(v):
            union(u, v)
            mst.append(edge)

    return mst
```

```python
# 深度优先搜索（DFS）
def dfs(graph, start, visited):
    visited[start] = True
    print(start)
    for neighbor in graph[start]:
        if not visited[neighbor]:
            dfs(graph, neighbor, visited)
```

```python
# 广度优先搜索（BFS）
from collections import deque

def bfs(graph, start):
    visited = [False] * len(graph)
    queue = deque([start])
    visited[start] = True

    while queue:
        vertex = queue.popleft()
        print(vertex)
        for neighbor in graph[vertex]:
            if not visited[neighbor]:
                queue.append(neighbor)
                visited[neighbor] = True
```

#### 3.3 最短路径算法

以下是一些最短路径算法：

- **迪杰斯特拉算法（Dijkstra）**：适用于权值非负的图。

```python
# Dijkstra算法：最短路径
import heapq

def dijkstra(graph, start):
    distances = {vertex: float('infinity') for vertex in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)

        if current_distance > distances[current_vertex]:
            continue

        for neighbor, weight in graph[current_vertex].items():
            distance = current_distance + weight

            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

- **贝尔曼-福德算法（Bellman-Ford）**：适用于权值可能为负的图。

```python
# Bellman-Ford算法：最短路径
def bellman_ford(graph, start):
    distances = {vertex: float('infinity') for vertex in graph}
    distances[start] = 0

    for _ in range(len(graph) - 1):
        for u in graph:
            for v, w in graph[u].items():
                if distances[u] + w < distances[v]:
                    distances[v] = distances[u] + w

    for u in graph:
        for v, w in graph[u].items():
            if distances[u] + w < distances[v]:
                return "Negative cycle detected"

    return distances
```

#### 3.4 最大流最小割算法

以下是一些最大流最小割算法：

- **最大流最小割定理**：最大流等于最小割。
- **Edmonds-Karp算法**：基于Ford-Fulkerson算法，使用广度优先搜索寻找增广路径。

```python
# Edmonds-Karp算法：最大流
from collections import deque

def edmonds_karp(graph, source, sink):
    flow = {vertex: {vertex2: 0 for vertex2 in graph} for vertex in graph}
    parent = {vertex: None for vertex in graph}

    def bfs(graph, source, sink):
        visited = {vertex: False for vertex in graph}
        queue = deque([source])
        visited[source] = True

        while queue:
            vertex = queue.popleft()
            for neighbor, capacity in graph[vertex].items():
                if not visited[neighbor] and capacity > 0:
                    queue.append(neighbor)
                    visited[neighbor] = True
                    parent[neighbor] = vertex

        return visited[sink]

    while bfs(graph, source, sink):
        path = []
        vertex = sink
        while vertex != source:
            path.append((vertex, parent[vertex]))
            vertex = parent[vertex]

        for u, v in path:
            flow[u][v] += 1
            flow[v][u] -= 1

    max_flow = 0
    for u in graph:
        for v in graph[u]:
            max_flow += flow[u][v]

    return max_flow
```

#### 6.1 算法设计与实现

以下是一个编程题实例：**最长公共子序列**。

**问题描述**：

给定两个字符串 `s1` 和 `s2`，求解它们的最长公共子序列。

**输入**：

```
s1 = "ABCD"
s2 = "ACDF"
```

**输出**：

```
"ACD"
```

**解决方案**：

```python
# 最长公共子序列
def longest_common_subsequence(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n+1) for _ in range(m+1)]

    for i in range(1, m+1):
        for j in range(1, n+1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    result = []
    i, j = m, n
    while i > 0 and j > 0:
        if s1[i-1] == s2[j-1]:
            result.append(s1[i-1])
            i -= 1
            j -= 1
        elif dp[i-1][j] > dp[i][j-1]:
            i -= 1
        else:
            j -= 1

    return ''.join(result[::-1])
```

#### 6.2 算法优化与改进

以下是一个编程题实例：**背包问题**。

**问题描述**：

给定一组物品和它们的重量和价值，以及一个背包的容量，求解在不超过容量的情况下，能够装入背包的最大价值。

**输入**：

```
weights = [1, 3, 4]

```

**输出**：

```
7
```

**解决方案**：

```python
# 背包问题
def knapsack(weights, values, W):
    n = len(weights)
    dp = [[0] * (W+1) for _ in range(n+1)]

    for i in range(1, n+1):
        for w in range(1, W+1):
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], dp[i-1][w-weights[i-1]] + values[i-1])
            else:
                dp[i][w] = dp[i-1][w]

    return dp[n][W]
```

**优化与改进**：

- **记忆化搜索**：使用递归和记忆化避免重复计算。
- **动态规划**：将递归转化为迭代，减少递归调用栈的使用。

#### 6.3 数据结构与算法应用

以下是一个编程题实例：**并查集**。

**问题描述**：

给定一组数对，表示若干个集合的合并操作，求解最终的集合划分。

**输入**：

```
pairs = [(1, 2), (2, 3), (1, 3), (4, 5)]
```

**输出**：

```
{{1, 2, 3}, {4, 5}}
```

**解决方案**：

```python
# 并查集
def find(parent, x):
    if parent[x] != x:
        parent[x] = find(parent, parent[x])
    return parent[x]

def union(parent, rank, x, y):
    rootX = find(parent, x)
    rootY = find(parent, y)
    if rank[rootX] > rank[rootY]:
        parent[rootY] = rootX
    elif rank[rootX] < rank[rootY]:
        parent[rootX] = rootY
    else:
        parent[rootY] = rootX
        rank[rootX] += 1

def find_partitions(pairs):
    parent = {}
    rank = {}
    for x, y in pairs:
        if x not in parent:
            parent[x] = x
            rank[x] = 0
        if y not in parent:
            parent[y] = y
            rank[y] = 0
        union(parent, rank, x, y)

    partitions = []
    visited = set()
    for key in parent:
        if key not in visited:
            visited.add(key)
            partition = {key}
            queue = deque([key])
            while queue:
                vertex = queue.popleft()
                for neighbor in parent:
                    if find(parent, vertex) == find(parent, neighbor) and neighbor not in visited:
                        visited.add(neighbor)
                        partition.add(neighbor)
                        queue.append(neighbor)
            partitions.append(partition)
    return partitions
```

```python
# 整数拆分
def count_partitions(n):
    dp = [[0] * (n+1) for _ in range(n+1)]
    for i in range(n+1):
        dp[i][0] = 1
    for i in range(1, n+1):
        for j in range(1, n+1):
            if j >= i:
                dp[i][j] = dp[i][j-1] + dp[i-j][j]
            else:
                dp[i][j] = dp[i][j-1]
    return dp[n][n]
```

```python
def combinations(n, k):
    return factorial(n) // (factorial(k) * factorial(n - k))
```

```python
# 二分查找
def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

**解读**：

- 初始化两个指针 `low` 和 `high`，分别指向数组的起始和结束位置。
- 使用 `while` 循环，当 `low` 小于等于 `high` 时，执行循环。
- 计算中间位置 `mid`，判断目标值 `target` 与中间值的比较结果。
- 如果 `target` 等于中间值，返回中间位置的索引。
- 如果 `target` 小于中间值，更新 `high` 的值为 `mid - 1`。
- 如果 `target` 大于中间值，更新 `low` 的值为 `mid + 1`。
- 当循环结束时，返回 `-1` 表示目标值不存在于数组中。

##### 快速排序（C++）

```cpp
// 快速排序
void quick_sort(int arr[], int low, int high) {
    if (low >= high) return;

    int pivot = arr[low];
    int i = low, j = high;
    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;
        arr[i] = arr[j];
        while (i < j && arr[i] <= pivot) i++;
        arr[j] = arr[i];
    }
    arr[i] = pivot;

    quick_sort(arr, low, i - 1);
    quick_sort(arr, i + 1, high);
}
```

**解读**：

- 快速排序是一种分治算法，其基本思想是通过一趟排序将待排序的数据分割成独立的两部分，其中一部分的所有数据都比另一部分的所有数据要小。
- 选择一个基准元素 `pivot`（此处选择第一个元素），将数组分成两部分，一部分是比 `pivot` 小的元素，另一部分是比 `pivot` 大的元素。
- 通过循环交换元素，将 `pivot` 放置在正确的位置，即所有比 `pivot` 小的元素都在其左侧，比 `pivot` 大的元素都在其右侧。
- 对左侧和右侧的数组分别递归调用 `quick_sort` 函数，直至整个数组有序。

##### 搜索引擎（Java）

```java
// 搜索引擎
import java.util.*;

public class SearchEngine {
    private List<String> index;
    private Map<String, List<Integer>> inverted_index;

    public SearchEngine(List<String> corpus) {
        this.index = new ArrayList<>();
        this.inverted_index = new HashMap<>();

        for (int i = 0; i < corpus.size(); i++) {
            String word = corpus.get(i);
            index.add(word);
            if (!inverted_index.containsKey(word)) {
                inverted_index.put(word, new ArrayList<>());
            }
            inverted_index.get(word).add(i);
        }
    }

    public List<Integer> search(String query) {
        List<Integer> results = new ArrayList<>();
        for (String word : query.split(" ")) {
            if (inverted_index.containsKey(word)) {
                List<Integer> positions = inverted_index.get(word);
                if (results.isEmpty()) {
                    results = positions;
                } else {
                    List<Integer> temp = new ArrayList<>();
                    for (int pos : results) {
                        if (positions.contains(pos)) {
                            temp.add(pos);
                        }
                    }
                    results = temp;
                }
            }
        }
        return results;
    }
```
