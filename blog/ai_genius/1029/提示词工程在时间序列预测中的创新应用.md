### 第二部分：基础理论

#### 2.1 时间序列预测的基本概念

时间序列（Time Series）是指一系列按照时间顺序排列的数据点。时间序列数据通常由随机过程生成，包含趋势、季节性、周期性和随机波动等特征。时间序列预测（Time Series Forecasting）是指通过分析历史时间序列数据，预测未来的数据值。

时间序列预测的目标是找到数据点之间的规律和模式，并利用这些规律和模式预测未来的数据值。常见的时间序列预测模型包括自回归模型（AR）、移动平均模型（MA）和自回归移动平均模型（ARMA）。

#### 2.1.1 时间序列的定义与特性

时间序列通常具有以下特性：

1. **时间连续性**：时间序列数据是按时间顺序排列的，每个数据点都有一个明确的时间戳。

2. **自相关性**：时间序列数据具有自相关性，即当前的数据点受到之前数据点的影响。自相关性可以通过自相关函数（Autocorrelation Function, ACF）和偏自相关函数（Partial Autocorrelation Function, PACF）来衡量。

3. **非平稳性**：大多数时间序列数据是非平稳的，即其统计特性（如均值、方差）随时间变化。非平稳性可以通过差分（Differencing）方法来处理。

4. **趋势性**：时间序列数据通常具有一定的趋势性，即数据值随时间增加或减少。趋势性可以通过趋势图（Trend Plot）和移动平均（Moving Average）来识别。

5. **季节性**：时间序列数据可能具有季节性，即数据值在特定的时间段内重复出现周期性的波动。季节性可以通过季节分解（Seasonal Decomposition）来识别。

#### 2.1.2 时间序列预测的目标与方法

时间序列预测的目标是根据历史数据预测未来的数据值。常见的时间序列预测方法包括：

1. **统计方法**：基于统计学原理和假设，通过分析和建模历史数据来预测未来数据值。常见的统计方法包括自回归模型（AR）、移动平均模型（MA）和自回归移动平均模型（ARMA）。

2. **机器学习方法**：利用机器学习算法，通过学习历史数据中的模式和规律来预测未来数据值。常见的机器学习方法包括线性回归、决策树、支持向量机和神经网络等。

3. **深度学习方法**：利用深度学习算法，通过多层神经网络学习复杂的时间序列模式。常见的深度学习模型包括循环神经网络（RNN）、长短期记忆网络（LSTM）和门控循环单元（GRU）等。

4. **混合方法**：结合统计方法和机器学习方法，利用不同方法的优势进行预测。常见的混合方法包括ARIMA-LSTM、AR-LSTM和MA-LSTM等。

#### 2.2 常见的时间序列预测模型

时间序列预测模型可以分为统计模型和机器学习模型。以下是常见的几种时间序列预测模型：

##### 2.2.1 自回归模型（AR）

自回归模型（Autoregressive Model, AR）是一种基于历史数据预测未来数据值的模型。AR模型假设当前数据点与之前若干个数据点之间存在线性关系。AR模型的数学表达式如下：

$$Y_t = c + \phi_1 Y_{t-1} + \phi_2 Y_{t-2} + ... + \phi_p Y_{t-p} + \varepsilon_t$$

其中，$Y_t$表示时间序列数据点，$c$表示常数项，$\phi_1, \phi_2, ..., \phi_p$表示自回归系数，$\varepsilon_t$表示误差项。

##### 2.2.2 移动平均模型（MA）

移动平均模型（Moving Average Model, MA）是一种基于历史误差预测当前数据值的模型。MA模型假设当前数据点可以由之前若干个数据点的加权平均得到。MA模型的数学表达式如下：

$$Y_t = c + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + ... + \theta_q \varepsilon_{t-q}$$

其中，$Y_t$表示时间序列数据点，$c$表示常数项，$\theta_1, \theta_2, ..., \theta_q$表示移动平均系数，$\varepsilon_t$表示误差项。

##### 2.2.3 自回归移动平均模型（ARMA）

自回归移动平均模型（Autoregressive Moving Average Model, ARMA）是AR模型和MA模型的结合。ARMA模型同时考虑了历史数据和误差项的影响。ARMA模型的数学表达式如下：

$$Y_t = c + \phi_1 Y_{t-1} + \phi_2 Y_{t-2} + ... + \phi_p Y_{t-p} + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + ... + \theta_q \varepsilon_{t-q}$$

其中，$Y_t$表示时间序列数据点，$c$表示常数项，$\phi_1, \phi_2, ..., \phi_p$表示自回归系数，$\theta_1, \theta_2, ..., \theta_q$表示移动平均系数，$\varepsilon_t$表示误差项。

   使用以下指标来评估模型的预测性能：

   - **均方误差（MSE）**：衡量预测值与实际值之间的差异。
   - **平均绝对误差（MAE）**：衡量预测值与实际值之间的绝对差异。
   - **决定系数（R²）**：衡量模型对数据的解释能力。

   公式如下：

   $$MSE = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$

   $$R² = 1 - \frac{\sum_{i=1}^{n} (\hat{y}_i - y_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2}$$

   其中，$n$为数据点的数量，$\hat{y}_i$为预测值，$y_i$为实际值，$\bar{y}$为实际值的平均值。

   - **《深度学习》**：由Ian Goodfellow、Yoshua Bengio和Aaron Courville合著，介绍了深度学习的基础理论和应用。

   - **《时间序列分析：案例与应用》**：由George E. P. Box、Gwilym E. Jenkins、Gareth Kitchen Priestley和J. Richard Evensen合著，介绍了时间序列分析的理论和应用。

2. **论文**：

   - **“Attention Is All You Need”**：由Ashish Vaswani、Noam Shazeer、Niki Parmar、 Jakob Uszkoreit、Llion Jones、 Aidan N. Gomez、Lukasz Kaiser 和 Illia Polosukhin 合著，介绍了Transformer模型。

   - **“A Theoretically Grounded Application of Prompt Engineering to Zero-shot Learning”**：由Zihang Dai、Zhiyuan Liu、Yiming Cui 和 Jiwei Li 合著，介绍了提示词工程在零样本学习中的应用。

3. **网站**：

   - **[TensorFlow官网](https://www.tensorflow.org/)**：提供了丰富的深度学习资源和教程。

   - **[PyTorch官网](https://pytorch.org/)**：提供了PyTorch库的文档和教程。
