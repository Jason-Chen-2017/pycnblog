在智能材料性能优化中，数学模型用于描述材料性能与输入参数之间的关系。以下是一个简化的数学模型：

$$
f(x) = \sum_{i=1}^{n} w_i \cdot (x_i - \bar{x_i})
$$

其中，$f(x)$ 表示材料性能，$x_i$ 表示输入参数，$w_i$ 表示权重，$\bar{x_i}$ 表示输入参数的均值。这个公式描述了材料性能与输入参数之间的线性关系，可以通过调整权重来优化材料性能。

#### 公式解释

- **材料性能**：$f(x)$ 表示材料在特定输入参数下的性能。对于不同的性能指标（如电导率、断裂韧性等），$f(x)$ 可以表示为相应的性能值。

- **输入参数**：$x_i$ 表示影响材料性能的输入参数。这些参数可以是材料的基本物理属性（如密度、弹性模量等），也可以是材料的制备参数（如烧结温度、冷却速度等）。

- **权重**：$w_i$ 表示输入参数对材料性能的影响程度。通过优化权重，可以调整材料性能与输入参数之间的关系。

- **均值**：$\bar{x_i}$ 表示输入参数的均值。这个值用于调整输入参数的相对重要性，使得模型更加关注关键性能指标。

import numpy as np
from tensorflow import keras
from tensorflow.keras import layers

X = data.drop(['conductivity'], axis=1).values

X = (X - X.mean()) / X.std()
Y = (Y - Y.mean()) / Y.std()

model = keras.Sequential([

    layers.Dense(64, activation='relu'),
    layers.Dense(1)
])

# 编译模型
model.compile(optimizer='adam', loss='mse')

# 训练模型
model.fit(X, Y, epochs=100, batch_size=32)

prompt_text = "预测材料的电导率，请考虑以下因素：原料配比、制备温度、冷却速度等。"
