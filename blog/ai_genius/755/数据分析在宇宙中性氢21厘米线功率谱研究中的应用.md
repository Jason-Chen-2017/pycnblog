   - **均值-标准差归一化**：将数据映射到标准正态分布的范围内，公式为：\[ x_{\text{规范化}} = \frac{x - \mu}{\sigma} \]，其中 \(\mu\) 是均值，\(\sigma\) 是标准差。

3. **数据融合**：当有多组观测数据时，可以通过数据融合技术将它们合并成一个完整的数据集。常用的数据融合方法包括：

   - **时间融合**：将多组观测数据在同一时间段内进行合并，如对多个望远镜在同一时间点的观测数据进行合并。
   - **空间融合**：将多组观测数据在同一空间范围内进行合并，如对多个星系在不同方向上的观测数据进行合并。

4. **数据特征提取**：数据特征提取是从原始数据中提取有助于模型拟合的变量。常用的数据特征提取方法包括：

   - **时域特征提取**：从时间序列数据中提取周期性、趋势性等特征，如傅里叶变换、小波变换等。
   - **频域特征提取**：从频率域数据中提取频率特征、功率谱等，如傅里叶变换、功率谱分析等。

### Step 6: 功率谱分析的理论和算法

功率谱分析是宇宙中性氢21厘米线研究中的一项关键技术，它能够将时间序列数据转换为频率域数据，从而揭示宇宙中中性氢的分布特征。本节将详细阐述功率谱分析的理论和算法，包括傅里叶变换、功率谱密度及其计算方法。

#### 傅里叶变换

傅里叶变换是一种将时间序列数据转换为频率信息的方法，它是功率谱分析的核心。傅里叶变换的基本思想是将时间序列数据分解为不同频率的正弦波和余弦波的组合。

**傅里叶变换公式**：

\[ F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-j\omega t} dt \]

其中，\( F(\omega) \) 是频率域数据，\( f(t) \) 是时间序列数据，\( \omega \) 是角频率，\( j \) 是虚数单位。

**逆傅里叶变换**：

\[ f(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} F(\omega) e^{j\omega t} d\omega \]

逆傅里叶变换用于将频率域数据转换回时间域数据。

#### 功率谱密度

功率谱密度（Power Spectral Density, PSD）是表示信号能量分布的物理量，它描述了信号在不同频率上的能量分布。功率谱密度通常以每赫兹（Hz）的能量来表示，单位为瓦特/赫兹（W/Hz）。

**功率谱密度公式**：

\[ P(\omega) = |F(\omega)|^2 \]

其中，\( P(\omega) \) 是功率谱密度，\( F(\omega) \) 是傅里叶变换结果。

#### 功率谱密度的计算方法

计算功率谱密度的步骤如下：

1. **傅里叶变换**：首先，对时间序列数据进行傅里叶变换，得到频率域数据。
2. **绝对值平方**：计算频率域数据的绝对值平方，得到功率谱密度。
3. **归一化**：为了使功率谱密度具有实际的物理意义，通常需要对其进行归一化。归一化方法包括时间归一化和频率归一化。

**时间归一化**：

\[ P(\omega)_{\text{时间}} = \frac{1}{T} \sum_{t=1}^{N} |F(\omega_t)|^2 \]

其中，\( T \) 是数据的时间长度，\( N \) 是数据点数量，\( F(\omega_t) \) 是第 \( t \) 个数据点的傅里叶变换结果。

**频率归一化**：

\[ P(\omega)_{\text{频率}} = \frac{1}{B} \sum_{\omega_i} |F(\omega_i)|^2 \]

其中，\( B \) 是频率带宽，\( \omega_i \) 是频率点的取值。

#### 实例讲解

为了更好地理解功率谱密度的计算方法，我们来看一个简单的实例。假设我们有一组时间序列数据如下：

\[ [1, 2, 3, 4, 5] \]

我们希望计算这组数据的功率谱密度。

1. **傅里叶变换**：首先，对这组数据进行傅里叶变换。使用离散傅里叶变换（DFT）方法，我们得到频率域数据如下：

\[ [0.707, 0, -0.707, 0, 0.707] \]

2. **绝对值平方**：计算频率域数据的绝对值平方，得到：

\[ [0.5, 0, 0.5, 0, 0.5] \]

3. **归一化**：假设我们采用时间归一化，则归一化后的功率谱密度为：

\[ P(\omega)_{\text{时间}} = \frac{1}{T} \sum_{t=1}^{N} |F(\omega_t)|^2 = \frac{1}{5} \sum_{t=1}^{5} |F(\omega_t)|^2 = \frac{1}{5} (0.5 + 0.5 + 0.5 + 0.5) = 0.5 \]

因此，这组数据的功率谱密度为0.5 W/Hz。

```python
import numpy as np

from scipy import signal

# 生成模拟数据
t = np.linspace(0, 100, 1000)  # 0到100秒，1000个点

fft_data = np.fft.fft(data)
freqs = np.fft.fftfreq(len(data), t[1] - t[0])

# 计算功率谱密度
psd = (abs(fft_data) ** 2) / len(data)

# 找到信号频率
signal_freq = freqs[np.argmax(psd)]

# 绘制功率谱图
plt.figure(figsize=(10, 6))
plt.semilogy(freqs, psd, color='blue')
plt.xlabel('Frequency (Hz)')
plt.ylabel('Power Spectral Density (V**2/Hz)')
plt.title('Power Spectrum of the Simulated Data')
plt.grid()
plt.axvline(x=signal_freq, color='red', linestyle='--')
plt.show()

print(f"The frequency of the signal is: {signal_freq} Hz")
```
