### 2.1 区块链技术简介

#### 2.1.1 区块链的基本原理

区块链是一种去中心化的分布式数据库技术，通过加密算法和共识机制保证数据的完整性和安全性。区块链由多个区块组成，每个区块包含一定数量的交易记录，区块之间通过哈希值连接形成一个链条。区块链的基本原理可以用以下Mermaid流程图表示：

```mermaid
graph TD
A[创建交易] --> B[交易验证]
B --> C[区块创建]
C --> D[区块添加]
D --> E[区块链更新]
```

#### 2.1.2 区块链的技术特点

区块链具有以下技术特点：

1. 去中心化：区块链没有中心化的管理机构，所有参与者都可以参与区块链的维护和更新。
2. 不可篡改：区块链上的数据一旦被写入，就难以篡改。这是因为每个区块都包含前一个区块的哈希值，形成一个链条，任何篡改都会导致哈希值不一致。
3. 透明性：区块链上的数据对所有参与者都是透明的，任何人都可以查看区块链上的交易记录。
4. 安全性：区块链通过加密算法和共识机制保证数据的安全性和完整性。

#### 2.1.3 区块链的应用领域

   ```solidity
   // SPDX-License-Identifier: MIT
   pragma solidity ^0.8.0;

   contract ArtworkRegistry {
       struct Artwork {
           string name;
           address creator;
           string hash;
           bool isRegistered;
       }

       mapping(string => Artwork) public artworks;

       function registerArtwork(string memory name, string memory hash) public {
           require(!artworks[name].isRegistered, "Artwork already registered");
           artworks[name] = Artwork(name, msg.sender, hash, true);
       }

       function getArtwork(string memory name) public view returns (Artwork memory) {
           return artworks[name];
       }
   }
   ```
   - `Artwork`结构体：用于存储数字艺术品的名称、创作者地址、哈希值和注册状态。
   - `registerArtwork`函数：用于注册数字艺术品，要求名称未被注册。
   - `getArtwork`函数：用于查询特定名称的数字艺术品信息。

2. 后端代码解读
   ```javascript
   const express = require('express');
   const bodyParser = require('body-parser');
   const ArtworkRegistry = require('./ArtworkRegistry');

   const app = express();
   app.use(bodyParser.json());

   const contractAddress = '0x...';
   const contractABI = require('./contractABI.json');
   const web3 = new Web3('http://localhost:8545');
   const artworkRegistry = new web3.eth.Contract(contractABI, contractAddress);

   app.post('/register', async (req, res) => {
       const { name, hash } = req.body;
       try {
           await artworkRegistry.methods.registerArtwork(name, hash).send({ from: req.body.creatorAddress });
           res.status(200).json({ message: 'Artwork registered successfully.' });
       } catch (error) {
           res.status(500).json({ message: 'Error registering artwork.', error });
       }
   });

   app.get('/artwork', async (req, res) => {
       const { name } = req.query;
       try {
           const artwork = await artworkRegistry.methods.getArtwork(name).call();
           res.status(200).json(artwork);
       } catch (error) {
           res.status(500).json({ message: 'Error retrieving artwork.', error });
       }
   });

   app.listen(3000, () => {
       console.log('Server listening on port 3000');
   });
   ```
   - 使用Express框架搭建后端服务。
   - 使用web3与以太坊节点交互，调用智能合约方法。
