```python
import spacy
from spacy.tokens import Doc
from neo4j import GraphDatabase

# 加载预训练的实体识别模型
nlp = spacy.load("en_core_web_sm")

# 连接Neo4j数据库
uri = "bolt://localhost:7687"
driver = GraphDatabase.driver(uri, auth=("neo4j", "password"))

# 构建知识图谱
def build_knowledge_graph(text):
    doc = nlp(text)
    for token in doc:
        if token.ent_type_:
            # 创建实体节点
            with driver.session() as session:
                session.run("CREATE (n:Entity {name: $name, type: $type})",
                            name=token.text, type=token.ent_type_)

            # 创建关系节点
            for prev_token in doc[token.i - 1:]:
                if prev_token.ent_type_:
                    with driver.session() as session:
                        session.run("MATCH (a:Entity {name: $nameA}), (b:Entity {name: $nameB}) "
                                    "CREATE (a)-[:RELATES_TO]->(b)",
                                    nameA=prev_token.text, nameB=token.text)

# 示例文本
text = "In computer science, an algorithm is a self-contained sequence of operations that specify a computation."

# 构建知识图谱
build_knowledge_graph(text)

# 关闭数据库连接
driver.close()
```

1. **加载实体识别模型**：使用spaCy库加载预训练的英语实体识别模型en_core_web_sm。

3. **构建知识图谱**：对输入文本进行分析，提取实体和关系，并将它们存储在Neo4j数据库中。
