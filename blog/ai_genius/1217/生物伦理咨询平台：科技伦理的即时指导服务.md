## 第2章 生物伦理学基础

### 2.1 伦理学的基本概念

伦理学是研究道德原则和道德规范的学科，它探讨人类行为的道德价值和道德义务。伦理学的基本概念包括道德原则、道德规范、道德判断和道德责任等。

道德原则是指指导人们行为的普遍性准则，如公正、仁慈、诚实等。道德规范是具体的行为规范，如不得杀人、必须偿还债务等。道德判断是评价行为是否符合道德原则和规范的判断，如评价某个行为是否正义、是否善良等。道德责任是行为主体对其行为的道德后果承担的责任，如因违法行为而受到法律制裁或道德谴责。

在Python中，我们可以使用以下代码来模拟道德判断过程：

        return "evil"
    else:
        return "neutral"

action = "拯救生命"
