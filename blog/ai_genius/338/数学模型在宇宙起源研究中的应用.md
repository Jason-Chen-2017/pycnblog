```pseudo
    # A是系数矩阵，b是常数向量
    # 使用高斯消元法求解线性方程组
    n = length(A)
    for i from 1 to n:
        # 选择主元
        pivot = A[i][i]
        for j from i+1 to n:
            # 行变换
            A[j] = A[j] - (A[j][i] / pivot) * A[i]
        # 列变换
        b = b - (A[j][i] / pivot) * b[i]
    # 回代求解
    x = [n]
    for i from n to 1:
        sum = 0
        for j from i+1 to n:
            sum = sum + A[i][j] * x[j]
        x[i] = (b[i] - sum) / A[i][i]
    return x
```

**结果**：

#### 微分方程模型

**例子**：求解常微分方程 $\frac{dy}{dx} = y$，初始条件 $y(0) = 1$。

**解法**：

1. 分离变量：$\frac{1}{y} dy = dx$。
2. 积分得到：$\ln|y| = x + C$，其中$C$是常数。
3. 解得：$y = e^{x + C} = e^x \cdot e^C$，令$e^C = C_1$，则$y = C_1e^x$。
4. 使用初始条件求解$C_1$：$y(0) = C_1e^0 = C_1 = 1$。

**结果**：

$y = e^x$。

#### 概率论与统计模型

**例子**：假设掷一枚公平的硬币10次，求至少出现一次正面的概率。

**解法**：

1. 定义事件$A$为“至少出现一次正面”，事件$\overline{A}$为“没有出现正面”。
2. 计算事件$\overline{A}$的概率：$P(\overline{A}) = (\frac{1}{2})^{10}$。
3. 计算事件$A$的概率：$P(A) = 1 - P(\overline{A}) = 1 - (\frac{1}{2})^{10}$。

**结果**：

$P(A) = 1 - (\frac{1}{2})^{10} = \frac{1023}{1024}$。
