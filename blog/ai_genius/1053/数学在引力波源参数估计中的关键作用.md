#### 4.1.1 线性规划

线性规划（Linear Programming，LP）是解决线性目标函数在一组线性不等式约束下的最优解问题。线性规划广泛应用于资源分配、调度优化等领域。

**目标函数：** 通常形式为 \( \min c^T x \) 或 \( \max c^T x \)，其中 \( c \) 是系数向量，\( x \) 是决策变量向量。

**约束条件：** 表示为 \( Ax \leq b \) 或 \( Ax \geq b \)，其中 \( A \) 是约束矩阵，\( b \) 是约束向量。

**求解方法：** 线性规划通常使用单纯形法、内点法等求解。单纯形法通过迭代逐渐逼近最优解。

**Python实现：**

```python
import numpy as np
from scipy.optimize import linprog

# 线性规划示例
c = [-1, -2]  # 目标函数系数
A = [[1, 2], [2, 1]]  # 约束矩阵
b = [3, 3]  # 约束向量

result = linprog(c, A_ub=A, b_ub=b, method='simplex')
print(result.x)  # 输出最优解
```

#### 4.1.2 非线性规划

非线性规划（Nonlinear Programming，NLP）用于解决非线性目标函数和约束条件的最优化问题。非线性规划比线性规划更复杂，没有统一的求解方法。

**目标函数：** 形式为 \( \min f(x) \) 或 \( \max f(x) \)，其中 \( f(x) \) 是非线性函数。

**约束条件：** 可以是线性或不线性，形式为 \( g(x) \leq 0 \)，\( h(x) = 0 \)。

**求解方法：** 常见方法包括梯度下降法、牛顿法、共轭梯度法等。

**Python实现：**

```python
import numpy as np
from scipy.optimize import minimize

# 非线性规划示例
def f(x):
    return x[0]**2 + x[1]**2

x0 = [1, 1]  # 初始猜测解

result = minimize(f, x0)
print(result.x)  # 输出最优解
```
