### 牛顿-拉夫逊迭代法

牛顿-拉夫逊迭代法是一种用于求解非线性方程组的算法，它基于牛顿法的基本原理，通过不断迭代逼近方程的根。在中间质量黑洞的研究中，牛顿-拉夫逊迭代法可以用来求解引力场的非线性方程。

**数学原理：**

$$
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}
$$

**Python代码实现：**

```python
def f(x):
    # 定义非线性方程
    return x**2 - 2

def df(x):
    # 定义非线性方程的导数

def newton_raphson(x0, tol=1e-6, max_iter=100):
```

### 高斯消元法

高斯消元法是一种用于解线性方程组的算法，通过高斯消元将线性方程组转化为上三角方程组，进而求解未知数。在中间质量黑洞的研究中，高斯消元法可以用来解线性引力方程。

**数学原理：**
设有线性方程组：
$$
Ax = b
$$
其中，$A$是系数矩阵，$x$是未知数，$b$是常数向量。高斯消元法通过以下步骤求解：
1. 将方程组写成增广矩阵形式：$[A | b]$。
2. 通过高斯消元将增广矩阵转化为上三角矩阵。
3. 从下往上回代求解未知数。

**Python代码实现：**
```python
import numpy as np

def gauss_elimination(A, b):
    n = len(A)
    # 将A和B合并成增广矩阵
    AB = np.hstack((A, b.reshape(-1, 1)))
    # 高斯消元
    for i in range(n):
        # 找到最大元素的位置
        max_index = np.argmax(np.abs(AB[i:, i])) + i
        # 交换行
        AB[[i, max_index]] = AB[[max_index, i]]
        # 消元
        for j in range(i+1, n):
            factor = AB[j, i] / AB[i, i]
            AB[j, i:] = AB[j, i:] - factor * AB[i, i:]
    # 回代求解
    x = np.zeros(n)
    for i in range(n-1, -1, -1):
        x[i] = (AB[i, n] - np.dot(AB[i, i+1:], x[i+1:])) / AB[i, i]
    return x

# 示例
A = np.array([[3, 2], [1, 4]])
b = np.array([18, 7])
x = gauss_elimination(A, b)
print("解：", x)
```
