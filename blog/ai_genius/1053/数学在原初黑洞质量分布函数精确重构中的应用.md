### 质量分布函数的数学模型

质量分布函数是描述一个系统中各个粒子的质量分布情况的重要数学工具。在原初黑洞研究中，质量分布函数有助于我们更好地理解黑洞的形成、演化以及宇宙的早期结构形成过程。在本节中，我们将详细讲解质量分布函数的定义、性质和数学公式。

#### 定义

质量分布函数 \( f(m) \) 是一个概率密度函数，用于描述系统中粒子质量 \( m \) 的分布情况。具体来说，质量分布函数表示在给定质量 \( m \) 附近的一个微小质量区间 \( [m, m + \Delta m] \) 内，系统包含的粒子数占总粒子数的比例。数学上，质量分布函数可以表示为：

\[ f(m) = \frac{dN(m)}{dm} \]

其中，\( dN(m) \) 表示在质量区间 \( [m, m + \Delta m] \) 内的粒子数，\( dm \) 表示质量区间的大小。

#### 性质

质量分布函数具有以下性质：

1. **非负性**：质量分布函数 \( f(m) \) 应该是大于等于零的，因为质量不能为负。
2. **归一性**：总粒子数 \( N \) 可以通过积分质量分布函数得到，即：

\[ N = \int_{0}^{\infty} f(m) dm \]

这意味着质量分布函数在所有质量范围内的积分应该等于总粒子数。
3. **可微性**：质量分布函数通常是一个连续函数，因此可以在大多数情况下对其求导。
4. **峰度**：质量分布函数的峰度描述了质量分布的集中程度，峰度越大，质量分布越集中。

#### 数学公式

质量分布函数的数学公式通常取决于具体的物理过程和系统特性。以下是几种常见的质量分布函数：

1. **泊松分布**：

泊松分布用于描述在给定时间内，某个事件发生的次数。在黑洞研究中，泊松分布可以用来描述原初黑洞形成的概率分布。泊松分布的概率质量函数为：

\[ f(m) = \frac{\lambda^m e^{-\lambda}}{m!} \]

其中，\( \lambda \) 是事件发生的平均频率，\( m \) 是事件发生的次数。

2. **伽玛分布**：

伽玛分布用于描述在多个独立事件中，某个特定事件发生的次数。在黑洞研究中，伽玛分布可以用来描述原初黑洞形成的累计概率分布。伽玛分布的概率质量函数为：

\[ f(m) = \frac{\lambda^\alpha}{\Gamma(\alpha)} m^{\alpha-1} e^{-\lambda m} \]

其中，\( \alpha \) 是形状参数，\( \lambda \) 是尺度参数，\( \Gamma(\alpha) \) 是伽玛函数。

3. **指数分布**：

指数分布用于描述在给定时间内，某个事件发生的持续时间。在黑洞研究中，指数分布可以用来描述原初黑洞的形成时间分布。指数分布的概率质量函数为：

\[ f(m) = \lambda e^{-\lambda m} \]

其中，\( \lambda \) 是事件发生的平均频率。

#### 示例

为了更直观地理解质量分布函数，我们可以通过一个简单的示例来说明。假设我们有一个系统，其中包含大量粒子，这些粒子的质量服从泊松分布。我们想知道在这个系统中，质量在 \( [m_1, m_2] \) 范围内的粒子数占总粒子数的比例。

根据泊松分布的概率质量函数，我们可以计算这个比例：

\[ P(m_1 \leq m \leq m_2) = \int_{m_1}^{m_2} \frac{\lambda^m e^{-\lambda}}{m!} dm \]

这个积分结果即为质量在 \( [m_1, m_2] \) 范围内的粒子数占总粒子数的比例。

**1. 梯度下降法**

梯度下降法是一种常用的优化算法，通过计算目标函数的梯度，沿着梯度的反方向逐步更新参数，以逼近最优解。其基本步骤如下：

- **初始化**：随机选择初始参数 \( \theta_0 \)。
- **计算梯度**：计算目标函数关于参数的梯度 \( \nabla_{\theta} J(\theta) \)。
- **更新参数**：根据梯度更新参数：\( \theta_{t+1} = \theta_t - \alpha \nabla_{\theta} J(\theta_t) \)，其中 \( \alpha \) 是学习率。
- **迭代**：重复步骤2和3，直至收敛。

**2. 粒子群优化算法**

粒子群优化算法是一种基于群体智能的优化算法，模拟粒子在搜索空间中的运动，通过个体和群体的信息共享，实现优化。其基本步骤如下：

- **初始化**：随机生成一群粒子，每个粒子代表一个潜在解。
- **更新速度和位置**：根据个体和群体的最优位置更新粒子的速度和位置。
- **评估适应度**：计算每个粒子的适应度，选择最优解。
- **迭代**：重复步骤2、3和4，直至收敛。

import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 质量分布函数
def mass_distribution_function(m, theta):
    return np.exp(-theta[0] * m) / (1 + np.exp(-theta[1] * m))

# 计算质量分布函数的梯度
def gradient(theta, X, y):
    m = X[:, 0]
    f = mass_distribution_function(m, theta)
    df = -theta[0] * f * (1 - f)
    dtheta = np.array([df.mean(), df.mean()])
    return dtheta

# 梯度下降法
def gradient_descent(theta, X, y, learning_rate, epochs):
    for epoch in range(epochs):
        gradient = gradient(theta, X, y)
        theta -= learning_rate * gradient
        if epoch % 100 == 0:
            print(f"Epoch {epoch}: theta = {theta}")
    return theta

# 加载观测数据

mass = data['mass']
distance = data['distance']
time = data['time']

y = time

# 初始化参数
theta = np.random.rand(2)

# 梯度下降法训练模型
theta = gradient_descent(theta, X, y, learning_rate=0.01, epochs=1000)

# 预测质量分布函数
predicted_mass_distribution = mass_distribution_function(X[:, 0], theta)
