## 第3章 核心概念与联系

### 3.1 提示词的定义

提示词（Prompt Word）是指用于引导或提示用户输入的特定词汇。在NLP中，提示词被用于引导用户输入特定类型的信息，以便模型能够更好地理解和处理。

### 3.2 提示词的类型

根据用途和性质，提示词可以分为以下几类：

- **引导型提示词**：用于引导用户输入特定类型的信息，如“请描述一下您今天的工作”。
- **确认型提示词**：用于确认用户输入的信息是否完整或准确，如“您的姓名是张三吗？”。
- **扩展型提示词**：用于扩展用户输入的信息，如“您最近有做过什么有趣的事情吗？”。

### 3.3 提示词工程的工作原理

提示词工程的工作原理可以分为以下几个步骤：

1. **数据收集**：从各种来源收集大量文本数据。
2. **数据预处理**：对收集的文本数据进行清洗、分词和特征提取。
3. **提示词生成**：利用训练好的语言模型生成合适的提示词。
4. **用户交互**：将生成的提示词展示给用户，并收集用户的反馈。
5. **模型优化**：根据用户的反馈对模型进行优化。

- **引导型提示词**：用于引导用户输入特定类型的信息，例如“请描述一下您今天的工作”。
- **确认型提示词**：用于确认用户输入的信息是否完整或准确，例如“您的姓名是张三吗？”。
- **扩展型提示词**：用于扩展用户输入的信息，例如“您最近有做过什么有趣的事情吗？”。

### 3.3 提示词工程的工作原理

提示词工程的工作原理可以分为以下几个步骤：

1. **数据收集**：从各种来源收集大量文本数据，例如社交媒体、新闻文章、用户评论等。
2. **数据预处理**：对收集的文本数据进行清洗、分词和特征提取，以提高数据质量。
3. **提示词生成**：利用训练好的语言模型生成合适的提示词。这通常涉及到提示词的优化和选择，以确保其能够有效地引导用户输入。
4. **用户交互**：将生成的提示词展示给用户，并收集用户的反馈。这一步对于提示词的进一步优化和改进至关重要。
5. **模型优化**：根据用户的反馈对模型进行优化，以提高提示词的质量和系统的交互效果。

def generate_text(model, vocabulary, length):

    text = []
    
    # 生成文本

        context = ' '.join(text[-context_size:])
