```python
import jieba

def extract_prompts(text):
    """
    从文本中提取提示词
    :param text: 输入文本
    :return: 提示词列表
    """
    # 使用jieba分词
    words = jieba.cut(text)
    # 统计词频，获取高频词作为提示词
    word_freq = {}
    for word in words:
        word_freq[word] = word_freq.get(word, 0) + 1
    # 设置词频阈值
    threshold = 5
    prompts = [word for word, freq in word_freq.items() if freq > threshold]
    return prompts
```

**提示词分类**：

接下来，根据预设的分类规则对提取出的提示词进行分类。分类规则可以根据业务需求自定义，例如，可以将提示词分为请求类、查询类、操作类等。以下是一个示例代码：

    :param prompts: 提示词列表
    :return: 分类结果字典

        '请求类': [],
        '查询类': [],
        '操作类': []

        if is_request(prompt):
            categories['请求类'].append(prompt)

            categories['查询类'].append(prompt)

    request_keywords = ['请求', '需要', '申请']

def is_query(prompt):

    :param prompt: 提示词

#### 1. 相关数学模型介绍

**词频分布模型**：

词频分布模型用于描述文本中各个词语出现的频率。常见的词频分布模型包括泊松分布、正态分布和二项分布。这些模型有助于我们理解文本中词语的重要性，从而在提示词提取和分类过程中提供有力支持。

条件概率模型用于描述在给定某个条件下，另一个事件发生的概率。在提示词分类中，条件概率模型可以帮助我们判断一个提示词属于哪个类别。常见的条件概率模型包括贝叶斯公式和马尔可夫模型。

#### 2. 公式解析

**词频分布公式**：

假设一个文本中有\( N \)个不同的词语，第\( i \)个词语出现的次数为\( f_i \)，则泊松分布可以表示为：

\[ P(f_i = k) = \frac{f_i^k e^{-f_i}}{k!} \]

其中，\( k \)为某个特定词语在文本中出现的次数。

**条件概率公式**：

贝叶斯公式是条件概率模型的基础，用于计算给定一个事件发生的条件下，另一个事件发生的概率。贝叶斯公式可以表示为：

\[ P(A|B) = \frac{P(B|A)P(A)}{P(B)} \]

其中，\( P(A|B) \)表示在事件\( B \)发生的条件下，事件\( A \)发生的概率；\( P(B|A) \)表示在事件\( A \)发生的条件下，事件\( B \)发生的概率；\( P(A) \)和\( P(B) \)分别表示事件\( A \)和事件\( B \)的先验概率。

**动态规划公式**：

动态规划模型用于解决多阶段决策问题，其基本思想是将复杂问题分解为若干个子问题，并利用子问题的最优解构造出整个问题的最优解。一个典型的动态规划公式为：

\[ V(x, y) = \max_{a \in A} \{ R(x, y, a) + V'(x', y') \} \]

其中，\( V(x, y) \)表示在状态\( (x, y) \)下的最优值；\( R(x, y, a) \)表示在状态\( (x, y) \)下采取动作\( a \)后的即时收益；\( V'(x', y') \)表示在状态\( (x', y') \)下的最优值。

#### 3. 举例说明

假设我们有一个文本数据集，其中包含多个句子。我们需要根据这些句子提取出重要的提示词，并对这些提示词进行分类。

**词频分布示例**：

假设文本中有5个不同的词语，它们的出现次数分别为：{“天气”：5次， “预报”：3次， “明天”：2次， “查看”：4次， “请求”：1次}。我们可以使用泊松分布模型来计算每个词语的词频分布：

\[ P(“天气” = 5) = \frac{5^5 e^{-5}}{5!} \approx 0.003 \]
\[ P(“预报” = 3) = \frac{3^3 e^{-3}}{3!} \approx 0.148 \]
\[ P(“明天” = 2) = \frac{2^2 e^{-2}}{2!} \approx 0.270 \]
\[ P(“查看” = 4) = \frac{4^4 e^{-4}}{4!} \approx 0.108 \]
\[ P(“请求” = 1) = \frac{1^1 e^{-1}}{1!} \approx 0.368 \]

**条件概率示例**：

假设我们有两个类别：“请求类”和“查询类”。根据历史数据，我们知道：
- “请求类”的提示词中有60%包含“请求”，40%包含“操作”；
- “查询类”的提示词中有70%包含“查询”，30%包含“查看”。

使用贝叶斯公式，我们可以计算一个提示词属于“请求类”的概率：

\[ P(请求类|“请求”) = \frac{P(“请求”|请求类)P(请求类)}{P(“请求”)} \]

假设先验概率\( P(请求类) = 0.5 \)，则：

\[ P(请求类|“请求”) = \frac{0.6 \times 0.5}{0.6 \times 0.5 + 0.3 \times 0.5} = \frac{3}{5} = 0.6 \]

这意味着，如果一个提示词包含“请求”，它属于“请求类”的概率为0.6。

**动态规划示例**：

假设我们有一个任务，需要从文本中提取出最重要的提示词。我们可以使用动态规划模型来解决这个问题。

假设我们有以下词语集合：{“天气”， “预报”， “明天”， “查看”， “请求”}。我们需要在这些词语中提取出最重要的一个词语。使用动态规划模型，我们可以计算每个词语的权重，然后选择权重最大的词语。

设\( V(w_i) \)为词语\( w_i \)的权重，动态规划公式为：

\[ V(w_i) = \max \{ P(w_i) + \sum_{j \neq i} P(w_j) \cdot V(w_j) \} \]

其中，\( P(w_i) \)为词语\( w_i \)的词频分布概率。

假设词频分布概率为：{“天气”：0.003， “预报”：0.148， “明天”：0.270， “查看”：0.108， “请求”：0.368}，则：

\[ V(“天气”) = \max \{ 0.003 + (0.148 + 0.270 + 0.108 + 0.368) \cdot V(w_j) \} \]

通过计算，我们可以找到最重要的提示词。
