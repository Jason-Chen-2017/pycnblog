## 第2章 动作优化的核心算法原理讲解

### 2.1 线性二次调节器（LQR）算法原理

线性二次调节器（LQR）是一种广泛应用于动作优化的算法。它通过求解一个线性优化问题，找到一组最优控制输入，使得系统的状态误差最小。

### 2.2 LQR 算法原理讲解

LQR 算法的核心是一个二次优化问题，其目标是最小化状态误差的二次代价函数。具体地，给定系统的状态矩阵 $A$、控制矩阵 $B$、权重矩阵 $Q$ 和 $R$，LQR 算法求解以下优化问题：

$$
\begin{aligned}
\min_{u} \quad & \int_{0}^{T} (x^T Q x + u^T R u) dt \\
\text{subject to} \quad & \dot{x} = A x + B u
\end{aligned}
$$

其中，$x$ 是系统的状态向量，$u$ 是控制输入向量，$Q$ 和 $R$ 是正定的权重矩阵。

### 2.3 LQR 算法 Python 源代码实现

下面是 LQR 算法的 Python 源代码实现，使用了 numpy 库来求解线性优化问题。

```python
import numpy as np

def lqr(A, B, Q, R):
    """
    Linear Quadratic Regulator (LQR) algorithm.

    Args:
        A (numpy.ndarray): State transition matrix.
        B (numpy.ndarray): Control matrix.
        Q (numpy.ndarray): State cost matrix.
        R (numpy.ndarray): Control cost matrix.

    Returns:
        numpy.ndarray: Optimal control gain matrix K.
        numpy.ndarray: Solution to the algebraic Riccati equation P.
    """
    P = np.linalg.inv(R) @ B.T @ np.linalg.inv(Q + B @ np.linalg.inv(R) @ B.T)
    K = -P @ B.T @ np.linalg.inv(R)

    return K, P
```

### 2.4 数学模型和数学公式讲解

在 LQR 算法中，我们考虑一个连续时间线性系统：

$$
\dot{x} = A x + B u
$$

其中，$x$ 是系统的状态向量，$u$ 是控制输入向量，$A$ 是状态矩阵，$B$ 是控制矩阵。

LQR 算法的目标是最小化如下的二次代价函数：

$$
J = \int_{0}^{T} (x^T Q x + u^T R u) dt
$$

其中，$Q$ 和 $R$ 是权重矩阵，它们确定了状态和控制输入的权重。

### 2.5 数学公式

$$
\begin{aligned}
J &= \int_{0}^{T} (x^T Q x + u^T R u) dt \\
&= \int_{0}^{T} (x^T Q A x + x^T Q B u + u^T R u) dt \\
&= \int_{0}^{T} (x^T Q A x + u^T R u) dt + \int_{0}^{T} x^T Q B u dt \\
&= \int_{0}^{T} (x^T Q A x + u^T R u) dt + \int_{0}^{T} (B^T Q^T B u^T + B^T Q^T A x^T) u dt \\
&= \int_{0}^{T} (x^T Q A x + u^T R u) dt + \int_{0}^{T} (B^T Q^T B u^T + x^T A^T B^T Q^T B u^T) u dt \\
&= \int_{0}^{T} (x^T Q A x + u^T R u + x^T A^T B^T Q^T B u^T) dt
\end{aligned}
$$

## 第2章 动作优化的核心算法原理讲解

### 2.1 线性二次调节器（LQR）算法原理

线性二次调节器（LQR）是一种广泛应用于动作优化的算法。它通过求解一个线性优化问题，找到一组最优控制输入，使得系统的状态误差最小。

### 2.2 LQR 算法原理讲解

LQR 算法的核心是一个二次优化问题，其目标是最小化状态误差的二次代价函数。具体地，给定系统的状态矩阵 $A$、控制矩阵 $B$、权重矩阵 $Q$ 和 $R$，LQR 算法求解以下优化问题：

$$
\begin{aligned}
\min_{u} \quad & \int_{0}^{T} (x^T Q x + u^T R u) dt \\
\text{subject to} \quad & \dot{x} = A x + B u
\end{aligned}
$$

其中，$x$ 是系统的状态向量，$u$ 是控制输入向量，$Q$ 和 $R$ 是正定的权重矩阵。

### 2.3 LQR 算法 Python 源代码实现

下面是 LQR 算法的 Python 源代码实现，使用了 numpy 库来求解线性优化问题。

```python
import numpy as np

def lqr(A, B, Q, R):
    """
    Linear Quadratic Regulator (LQR) algorithm.

    Args:
        A (numpy.ndarray): State transition matrix.
        B (numpy.ndarray): Control matrix.
        Q (numpy.ndarray): State cost matrix.
        R (numpy.ndarray): Control cost matrix.

    Returns:
        numpy.ndarray: Optimal control gain matrix K.
        numpy.ndarray: Solution to the algebraic Riccati equation P.
    """
    P = np.linalg.inv(R) @ B.T @ np.linalg.inv(Q + B @ np.linalg.inv(R) @ B.T)
    K = -P @ B.T @ np.linalg.inv(R)

    return K, P
```

### 2.4 数学模型和数学公式讲解

在 LQR 算法中，我们考虑一个连续时间线性系统：

$$
\dot{x} = A x + B u
$$

其中，$x$ 是系统的状态向量，$u$ 是控制输入向量，$A$ 是状态矩阵，$B$ 是控制矩阵。

LQR 算法的目标是最小化如下的二次代价函数：

$$
J = \int_{0}^{T} (x^T Q x + u^T R u) dt
$$

其中，$Q$ 和 $R$ 是权重矩阵，它们确定了状态和控制输入的权重。

### 2.5 数学公式

$$
\begin{aligned}
J &= \int_{0}^{T} (x^T Q x + u^T R u) dt \\
&= \int_{0}^{T} (x^T Q A x + x^T Q B u + u^T R u) dt \\
&= \int_{0}^{T} (x^T Q A x + u^T R u) dt + \int_{0}^{T} x^T Q B u dt \\
&= \int_{0}^{T} (x^T Q A x + u^T R u) dt + \int_{0}^{T} (B^T Q^T B u^T + B^T Q^T A x^T) u dt \\
&= \int_{0}^{T} (x^T Q A x + u^T R u + x^T A^T B^T Q^T B u^T) dt
\end{aligned}
$$
