动态规划是一种用于解决最优控制问题的算法，其核心是贝尔曼方程。贝尔曼方程通过递归关系，计算出系统在不同状态下的最优控制策略。以下是一个动态规划的伪代码描述：

```python
def dynamic_programming(states, actions, transition_function, reward_function):
    V = [0] * len(states)
    for state in states:
        V[state] = max([reward_function(state, action) + discount * V[next_state]
                       for action, next_state in transition_function(state)])
    return V
```
