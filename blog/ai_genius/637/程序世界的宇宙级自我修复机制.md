3. 应用修复：执行修复操作，生成修复后的程序。

**案例：修复一个简单的计算错误**

假设我们有一个程序，用于计算两个数字的和。但是，由于编程错误，程序在某些情况下返回了错误的答案。以下是一个错误的程序示例：

```python
def add(a, b):
    return a + b
```

现在，我们使用自我修复机制来修复这个错误。以下是修复过程：

1. **检测错误**：使用静态分析工具检测程序中的错误。在这种情况下，我们可以通过测试用例来发现错误。
2. **诊断错误**：根据测试结果，我们发现程序在处理负数时返回了错误的答案。
3. **应用修复**：我们修改程序，使其在处理负数时能够正确计算。

修复后的程序：

```python
def add(a, b):
    if a < 0 and b < 0:
        return -a - b
    else:
        return a + b
```

通过这个案例，我们可以看到自我修复机制是如何帮助我们发现和修复程序中的错误。
