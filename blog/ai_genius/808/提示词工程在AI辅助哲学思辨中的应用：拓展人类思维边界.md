  ```python
  # 输入：文本数据 corpus
  # 输出：n元语法模型 ngram_model
  
  ngram_model = {}
  for sentence in corpus:
      for i in range(len(sentence) - n + 1):
          key = tuple(sentence[i:i+n])
          ngram_model[key] = ngram_model.get(key, 0) + 1
  
  # 计算概率分布
  for key, count in ngram_model.items():
      ngram_model[key] = count / sum(ngram_model.values())
  ```

**第5章：AI辅助哲学思辨的应用**
- **5.1 提示词工程在哲学问题中的应用**

  ```python
  # 导入必要的库
  import nltk
  from nltk.tokenize import word_tokenize
  from nltk.corpus import stopwords
  
  # 加载停用词列表
  stop_words = set(stopwords.words('english'))
  
  # 输入文本
  text = "The mind is not a vessel to be filled but a fire to be ignited."
  
  # 分词
  words = word_tokenize(text)
  
  # 移除停用词
  filtered_words = [word for word in words if word.lower() not in stop_words]
  
  # 提取关键词
  keywords = nltk.FreqDist(filtered_words).most_common(5)
  
  # 输出关键词
  for word, frequency in keywords:
      print(f"{word}: {frequency}")
  ```
  - **代码解读**：
    - 我们首先导入了nltk库和其中的`word_tokenize`函数，用于对文本进行分词。
    - 接着加载了停用词列表，用于过滤掉常见的不相关词汇。
    - 然后对输入文本进行了分词，并移除了停用词。
    - 最后，我们使用`FreqDist`函数提取了文本中的高频词汇，并输出前五个关键词。
    - 通过这个案例，我们可以看到如何使用提示词工程提取文本中的关键信息，从而辅助哲学问题的探讨。
