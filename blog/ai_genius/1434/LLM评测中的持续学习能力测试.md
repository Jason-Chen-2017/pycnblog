#### 3.3 算法原理详细讲解

**数学模型与公式：**
- **持续学习能力评估**：通过计算模型在新数据集上的准确率、召回率和F1值，来评估其持续学习能力。

$$
\text{Accuracy} = \frac{\text{正确预测数}}{\text{总预测数}}
$$

$$
\text{Recall} = \frac{\text{正确预测的正例数}}{\text{实际正例数}}
$$

$$
\text{F1值} = 2 \times \frac{\text{准确率} \times \text{召回率}}{\text{准确率} + \text{召回率}}
$$

#### 3.3 算法原理详细讲解

**数学模型与公式：**
- **准确率（Accuracy）**：表示模型预测正确的样本数占总样本数的比例。

$$
\text{Accuracy} = \frac{\text{正确预测数}}{\text{总预测数}}
$$

- **召回率（Recall）**：表示模型预测正确的正例数占总正例数的比例。

$$
\text{Recall} = \frac{\text{正确预测的正例数}}{\text{实际正例数}}
$$

- **F1值（F1 Score）**：是准确率和召回率的调和平均值，用于综合评估模型的性能。

$$
\text{F1值} = 2 \times \frac{\text{准确率} \times \text{召回率}}{\text{准确率} + \text{召回率}}
$$

**举例说明：**
假设我们有一个二分类任务，数据集包含100个样本，其中60个正例和40个负例。模型预测结果如下：

| 样本编号 | 实际标签 | 预测标签 |
|----------|----------|----------|
| 1        | 正例     | 正例     |
| 2        | 负例     | 负例     |
| ...      | ...      | ...      |
| 100      | 正例     | 正例     |

根据上述预测结果，我们可以计算评估指标：

- **准确率**：

$$
\text{Accuracy} = \frac{60 + 40}{100} = 1.0
$$

- **召回率**：

$$
\text{Recall} = \frac{60}{60} = 1.0
$$

- **F1值**：

$$
\text{F1值} = 2 \times \frac{1.0 \times 1.0}{1.0 + 1.0} = 1.0
$$

在这个例子中，模型在所有评估指标上都取得了满分，这表明模型在当前数据集上表现优异。然而，在实际应用中，模型的表现往往不会这么理想，我们需要通过不断调整和优化模型来提高其性能。

    ])

    model.fit(X_train, y_train, epochs=5, batch_size=32)
    
    return model

# 模型评估

    # 使用训练好的模型对测试数据进行预测
    y_pred = model.predict(X_test)

    recall = recall_score(y_test, y_pred.round(), average='weighted')
    f1 = f1_score(y_test, y_pred.round(), average='weighted')
    return accuracy, recall, f1

# 主函数
def main():
    # 构建数据集
    df = build_dataset()

    print(f"Accuracy: {accuracy}, Recall: {recall}, F1: {f1}")

# 运行主函数
if __name__ == "__main__":
    main()
