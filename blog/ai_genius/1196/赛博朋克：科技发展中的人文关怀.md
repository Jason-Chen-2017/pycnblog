###### 神经网络原理

神经网络由多个神经元（或节点）组成，每个神经元都接受多个输入信号，并通过激活函数进行处理，最终产生一个输出信号。神经网络通过调整权重和偏置来优化模型的预测能力。

```python
import numpy as np

# 初始化参数
weights = np.random.rand(3, 1)
biases = np.random.rand(1)
learning_rate = 0.1

# 定义激活函数（Sigmoid函数）
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 训练神经网络
for i in range(1000):
    # 输入数据
    inputs = np.array([[0], [1], [2]])
    # 目标输出
    outputs = np.array([[0], [1], [1]])

    # 计算输出
    output = sigmoid(np.dot(inputs, weights) + biases)

    # 计算误差
    error = outputs - output

    # 更新权重和偏置
    weights += np.dot(inputs.T, error * output * (1 - output))
    biases += error * sigmoid(np.dot(inputs, weights) + biases) * (1 - sigmoid(np.dot(inputs, weights) + biases))

# 测试神经网络
test_inputs = np.array([[1]])
test_output = sigmoid(np.dot(test_inputs, weights) + biases)
print("Test output:", test_output)
```

```python
    distances = np.linalg.norm(data - centroids, axis=1)

    centroids = compute_centroids(data, centroids)

# 测试聚类结果
labels = np.argmin(np.linalg.norm(data - centroids, axis=1), axis=1)
print("Labels:", labels)
```

###### 数学公式

$$
c_j = \frac{1}{N_j} \sum_{i=1}^{N} x_i
$$

其中，$c_j$是第j个聚类中心，$N_j$是第j个聚类中的数据点数量，$x_i$是数据点。
