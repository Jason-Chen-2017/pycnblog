## 第一部分：版本控制基础

### 第1章：版本控制简介

#### 1.1 版本控制的定义

版本控制，也称为源代码管理（Source Code Management，简称SCM），是一种跟踪源代码变更的方法，确保代码库的完整性和一致性。它允许开发团队在多个版本之间切换，并跟踪每个版本的变更历史。

#### 1.2 版本控制的重要性

版本控制对于软件开发至关重要。它提供了以下关键功能：

- **协作开发**：允许多个开发者同时工作，避免代码冲突。
- **变更追踪**：记录代码的每次修改，便于问题的定位和解决。
- **历史记录**：保存项目的历史版本，便于回滚到特定版本。
- **代码备份**：提供代码的安全备份，防止数据丢失。

#### 1.3 常见的版本控制系统

目前，最流行的版本控制系统包括Git、Subversion（SVN）和Mercurial（Hg）。其中，Git由于其强大的分布式特性，成为了开发社区的主流选择。

### 第2章：Git版本控制系统

#### 2.1 Git的基本概念

Git是一个分布式版本控制系统，由Linus Torvalds创建。其主要特点包括：

- **分布式**：每个开发者都有一个完整的代码库，无需中央服务器。
- **快速**：使用基于内容的存储，能够高效地处理大量数据。
- **灵活性**：支持各种分支策略，适应不同的开发模式。

#### 2.2 Git的安装与配置

要在本地安装Git，请按照以下步骤操作：

1. 访问Git的官方网站（[https://git-scm.com/](https://git-scm.com/)）下载安装包。
2. 运行安装程序，并选择合适的选项。
3. 配置用户信息：

    ```bash
    git config --global user.name "Your Name"
    git config --global user.email "your-email@example.com"
    ```

#### 2.3 Git的基本操作

Git的基本操作包括初始化仓库、添加文件、提交更改、查看历史记录等。以下是这些操作的简要说明：

- **初始化仓库**：

    ```bash
    git init
    ```

- **添加文件**：

    ```bash
    git add <file>
    ```

- **提交更改**：

    ```bash
    git commit -m "Commit message"
    ```

- **查看历史记录**：

    ```bash
    git log
    ```

#### 2.4 Git分支管理

Git的分支管理是其强大的一个方面。以下是关于Git分支管理的一些基本概念和操作：

- **创建分支**：

    ```bash
    git branch <branch-name>
    ```

- **切换分支**：

    ```bash
    git checkout <branch-name>
    ```

- **合并分支**：

    ```bash
    git merge <branch-name>
    ```

- **删除分支**：

    ```bash
    git branch -d <branch-name>
    ```

#### Git基本操作

```python
import subprocess

def run_command(command):
    result = subprocess.run(command, shell=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    return result.stdout.decode(), result.stderr.decode()

def init_repo():
    output, error = run_command("git init")
    if error:
        print("Error initializing repository:", error)
    else:
        print("Repository initialized:", output)

def add_file(file_path):
    output, error = run_command(f"git add {file_path}")
    if error:
        print("Error adding file:", error)
    else:
        print("File added:", output)

def commit_changes(message):
    output, error = run_command(f"git commit -m '{message}'")
    if error:
        print("Error committing changes:", error)
    else:
        print("Changes committed:", output)

# 示例使用
init_repo()
add_file("example.py")
commit_changes("Initial commit of example.py")
```
