```python
import serial
import time

# 初始化串口连接
ser = serial.Serial('/dev/ttyUSB0', 9600)

# 循环读取传感器数据
while True:
    # 读取传感器数据
```

- **数据转换**：将读取到的字符串数据转换为浮点数。
- **灌溉控制**：如果土壤水分低于30%，发送命令启动水泵进行灌溉。
- **灌溉持续时间**：设定灌溉持续时间为10秒。
