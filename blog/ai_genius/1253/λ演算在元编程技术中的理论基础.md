                 

### 第一部分：λ演算基础

#### 第1章：λ演算的历史与发展

##### 1.1 逻辑演算与函数演算

逻辑演算（Logic Calculus）是数学和逻辑学中的一种基本工具，主要研究命题逻辑、谓词逻辑等形式的推理。函数演算（Functional Calculus）则是以函数作为基本元素来构建的演算系统，它最初起源于逻辑学，但后来逐渐发展出了独立的理论体系。

逻辑演算的基本概念包括命题、命题联结词（如“与”、“或”等）以及推理规则。这些概念为形式化推理提供了强有力的工具。例如，命题逻辑中的命题联结词可以用来表示复杂的逻辑关系，而推理规则则指导如何从已知命题推导出新命题。

函数演算则关注函数的定义、组合和应用。它的基本思想是将计算过程看作是函数的变换，这种变换可以是一步一步完成的。函数演算最初由数学家怀特海德（Alonzo Church）提出，目的是为了研究计算的本质。

##### 1.2 λ演算的发展历程

λ演算（λ-calculus）作为一种形式系统，它的历史可以追溯到20世纪30年代。当时，逻辑学家和数学家们正努力寻找一种能够形式化数学推理的方法。在这一背景下，λ演算逐渐发展起来。

1936年，阿尔图尔·卢文斯坦（Alonzo Church）和斯蒂芬·科尔·克莱尼（Stephen Cole Kleene）分别独立地提出了λ演算的雏形。此后，λ演算的理论体系不断完善，逐渐形成了今天我们所熟知的形式。

λ演算的发展历程中，有许多重要的事件和定理。例如，1936年，卢文斯坦提出了肯定前缀演算（Positive Prefix Calculus），这是一种能够实现任何可计算函数的简单演算系统。1936年，艾伦·图灵（Alan Turing）提出了图灵机模型，并证明了λ演算和图灵机之间等价性，这一结果被称为Church-Turing论题，是计算机科学和数学逻辑学中的基石之一。

此外，1940年，亨利·布卢赫（Henri P. Y. Bowland）证明了λ演算的可判定性，这意味着存在一种算法能够决定任意λ表达式是否能够化简到正常形式。1958年，马丁·戴维斯（Martin Davis）等人提出了λ演算的正常形式化，这是λ演算理论发展中的重要一步。

##### 1.3 λ演算在计算机科学中的应用

λ演算在计算机科学中有着广泛的应用，它不仅为理论计算机科学提供了强有力的工具，也在实际应用中发挥了重要作用。

首先，λ演算为形式化验证提供了基础。形式化验证是一种用数学方法证明计算机系统正确性的方法。λ演算的严格性和精确性使得它在形式化验证中成为一种重要的工具。例如，编译器的设计和验证、操作系统内核的验证、硬件电路的验证等，都可以使用λ演算来帮助证明系统的正确性。

其次，λ演算在编译器构造中也有着重要作用。编译器是将高级编程语言翻译成机器代码的程序，它的核心任务是实现语义的正确转换。λ演算作为一种形式系统，可以帮助编译器开发者理解编程语言的语义，从而实现更加精确的编译过程。

此外，λ演算还在编程语言设计、程序优化、分布式计算等领域有着广泛的应用。例如，λ演算可以用来实现函数式编程语言，如Haskell和Lisp；在程序优化中，λ演算可以帮助理解程序的行为，从而实现优化策略；在分布式计算中，λ演算可以用来描述并行计算的过程，帮助设计分布式算法。

总之，λ演算作为一种形式系统，不仅在理论计算机科学中有着重要的地位，也在实际应用中发挥着重要作用。它的发展和完善，为计算机科学的研究和应用提供了强有力的支持。

#### 第2章：λ演算的基本概念

##### 2.1 变量绑定与变量作用域

在λ演算中，变量绑定和变量作用域是两个基本且重要的概念。变量绑定指的是将一个变量与某个具体的值关联起来，而变量作用域则定义了变量绑定的有效范围。

在λ演算中，变量绑定通过λ抽象（λ-abstraction）来实现。λ抽象的形式为λx.M，其中x是一个变量，M是一个λ表达式。这个表达式表示“一个函数，它将变量x绑定到M所代表的表达式”。例如，λx.(x + 1) 表示一个函数，该函数将输入的变量x绑定到表达式x + 1上。

变量作用域则是指变量绑定的有效范围。在λ演算中，变量的作用域可以是局部的，也可以是全局的。局部作用域通常指在λ表达式内部定义的变量，它们只能在这个λ表达式中使用。全局作用域则指在整个λ表达式中定义的变量，它们可以在整个表达式中使用。

例如，考虑以下λ表达式：

λx. (λy. x + y)

这个表达式包含了两个λ抽象，第一个λ抽象将变量x绑定到内部表达式(λy. x + y)上，而第二个λ抽象将变量y绑定到内部表达式x + y上。这里，变量x的作用域是整个内部表达式，而变量y的作用域仅限于λy. x + y这个内部表达式。

变量绑定和变量作用域在λ演算中至关重要。它们不仅定义了函数的行为，还影响了λ表达式的化简过程。在λ演算中，化简过程中的变量绑定和作用域管理是关键步骤，只有正确处理这些概念，才能确保λ表达式能够正确地化简。

##### 2.2 λ抽象与λ应用

λ抽象（λ-abstraction）和λ应用（λ-application）是λ演算的两个核心操作，它们共同构成了λ演算的基本语义。

λ抽象表示函数的定义，它的形式为λx.M，其中x是一个变量，M是一个λ表达式。这个表达式表示“一个函数，它将变量x绑定到M所代表的表达式”。例如，λx.(x + 1) 表示一个函数，该函数将输入的变量x绑定到表达式x + 1上。λ抽象的作用是将变量绑定到某个表达式上，从而创建一个新的函数。

λ应用则表示函数的调用，它的形式为M N，其中M和N是两个λ表达式。这个表达式表示“将函数M应用到值N上”。例如，(λx.(x + 1)) 2 表示将函数λx.(x + 1) 应用到值2上，即计算2 + 1。

λ抽象和λ应用是λ演算中的两个基本操作，它们通过抽象和组合的方式，实现了函数的定义和调用。λ抽象将变量绑定到某个表达式上，定义了一个新的函数；而λ应用则将这个函数应用到某个值上，计算得到一个新的值。

例如，考虑以下λ表达式：

λx. (λy. x + y)

这个表达式包含了两个λ抽象，第一个λ抽象将变量x绑定到内部表达式(λy. x + y)上，而第二个λ抽象将变量y绑定到内部表达式x + y上。λ抽象和λ应用可以组合起来使用，例如：

(λx. (λy. x + y)) (λz. z + 1)

这个表达式表示将函数λx.(λy. x + y) 应用到函数λz. z + 1上，计算得到一个新的函数λy. (λz. z + 1) + y。

λ抽象和λ应用是λ演算的核心操作，通过它们，λ演算可以表达复杂的函数关系和计算过程。λ演算的强大之处在于它的抽象和组合能力，这种能力使得λ演算成为研究计算理论和编程语言设计的有力工具。

##### 2.3 演算的类型系统

λ演算的类型系统是其表达能力和可靠性的重要组成部分。类型系统为λ演算提供了语义指导，确保了表达式在计算过程中的合法性和正确性。

λ演算的类型系统包括基本类型、构造类型和类型构造器等。基本类型包括布尔类型（Bool）、整数类型（Int）和字符串类型（String）等。构造类型则是通过类型构造器构建的复合类型，例如列表类型（List）、函数类型（Func）和记录类型（Record）等。

类型构造器是类型系统的核心，它定义了如何组合基本类型和构造类型，以及如何创建新的类型。常见的类型构造器有Sum类型构造器（又称Union类型构造器）和Product类型构造器（又称记录类型构造器）。

Sum类型构造器用于创建具有多个可能值的类型。例如，我们可以使用Sum类型构造器创建一个表示天气的类型：

Type Weather = Sum [Sunny, Cloudy, Rainy]

这个类型定义了三种可能的天气值：Sunny、Cloudy和Rainy。

Product类型构造器用于创建具有多个属性的类型。例如，我们可以使用Product类型构造器创建一个表示人的类型：

Type Person = Product [Name: String, Age: Int]

这个类型定义了两个属性：Name和Age，分别表示人的名字和年龄。

在λ演算中，类型系统通过类型推导规则来确保λ表达式的类型一致性。类型推导规则定义了如何从λ表达式的结构推导出其类型。基本的类型推导规则包括：

- 变量绑定：如果λx.M是一个λ表达式，则它的类型为Type，其中Type是M的类型。
- λ应用：如果M和N是两个λ表达式，且M的类型为Func Type1 -> Type2，N的类型为Type1，则M N的类型为Type2。
- 变量引用：如果x是一个变量，其类型为Type，则x的类型为Type。

类型推导规则确保了λ表达式的每个子表达式都有正确的类型，从而保证了λ演算的语义一致性。例如，考虑以下λ表达式：

λx. (x + 1)

这个表达式的类型可以通过以下类型推导过程得到：

- 变量绑定：λx. (x + 1) 的类型为Type。
- 变量引用：x的类型为Type。
- 加法操作：（x + 1）的类型为Type。

因此，λx. (x + 1) 的类型为Func Type -> Type，其中Type是x的类型。

λ演算的类型系统不仅提供了语义指导，还提高了λ演算的可靠性和可维护性。通过类型推导规则，我们可以确保λ表达式的类型一致性，从而避免语义错误。同时，类型系统也为我们提供了更直观的方式来理解和分析λ演算的表达式。

总之，λ演算的类型系统是λ演算的核心组成部分，它通过类型推导规则确保λ表达式的类型一致性，从而提高了λ演算的可靠性和可维护性。λ演算的类型系统不仅为理论计算机科学提供了强有力的工具，也为实际编程语言的设计和应用提供了重要的参考。

#### 第3章：λ演算的语法与语义

##### 3.1 演算的基本语法

λ演算的基本语法包括项（terms）、表达式（expressions）和语句（statements）等组成部分。理解λ演算的基本语法是掌握λ演算的基础，它有助于我们构建和理解复杂的λ表达式。

项（terms）是λ演算中的基本构建块，它包括变量、λ抽象、λ应用和常量等。变量是λ演算中的一个标识符，它代表一个值。λ抽象（λ-abstraction）是一个函数定义，它将一个变量绑定到一个λ表达式中，表示一个函数。λ应用（λ-application）是将一个函数应用到某个值上，表示函数的调用。常量是预先定义的值，如数字、布尔值和字符串等。

表达式（expressions）是λ演算中的运算单位，它由项组成。λ演算中的表达式可以分为原子表达式和复合表达式。原子表达式是基本的数据值，如数字、布尔值和字符串等。复合表达式是通过运算符连接的项，如加法表达式（x + y）和函数调用表达式（f(x)）等。

语句（statements）是λ演算中的指令，它表示一个操作或一个计算过程。λ演算中的语句可以分为赋值语句、条件语句和循环语句等。赋值语句将一个值赋给一个变量，如x = y；条件语句根据条件的真假执行不同的操作，如if x > 0 then y else z；循环语句用于重复执行某个操作，如while x > 0 do y。

例如，考虑以下λ演算的表达式：

λx. (x + 1)

这个表达式是一个λ抽象，它将变量x绑定到表达式x + 1上，表示一个函数。再考虑以下表达式：

((λx. (x + 1)) 2)

这个表达式是一个复合表达式，它由两个部分组成：λx. (x + 1) 是一个λ抽象，(λx. (x + 1)) 2 是一个λ应用，表示将函数λx. (x + 1) 应用到值2上，计算得到3。

理解λ演算的基本语法有助于我们构建和理解复杂的λ表达式。通过熟悉变量、λ抽象、λ应用和常量等基本概念，我们可以编写和理解λ演算的程序，从而掌握λ演算的编程技巧。

##### 3.2 演算的语义模型

λ演算的语义模型是理解λ演算行为和性质的关键。它定义了λ表达式的计算过程和结果，为我们提供了分析λ演算的有效工具。

λ演算的语义模型主要包括β-化简（β-reduction）、η-化简（η-reduction）和正常形式（normal form）等概念。

β-化简是λ演算中最基本的化简操作。它表示将一个λ表达式替换为其函数体中的变量，然后进行求值。β-化简的形式为：(λx.M) N → M[N/x]，其中M和N是λ表达式，x是变量。例如，考虑以下λ表达式：

(λx. x + 1) 2

这个表达式可以经过β-化简得到：

x + 1 [2/x]

这里，λx. x + 1 是一个λ抽象，将变量x绑定到表达式x + 1上；2是一个值，表示将函数λx. x + 1 应用到值2上。β-化简过程将变量x替换为值2，得到表达式2 + 1，计算结果为3。

η-化简是λ演算中的另一个重要化简操作。它表示将一个函数应用于自身，然后将结果与函数本身进行比较。η-化简的形式为：M η → N，其中M和N是λ表达式，且M = λx. f(x)。η-化简可以看作是函数的恒等扩展。例如，考虑以下λ表达式：

λx. (x + 1) (λx. (x + 1))

这个表达式可以经过η-化简得到：

(λx. (x + 1)) (λx. (x + 1))

这里，λx. (x + 1) 是一个λ抽象，将变量x绑定到表达式x + 1上。η-化简过程将函数λx. (x + 1) 应用于自身，得到一个新的函数，然后与原来的函数进行比较，结果相等。

正常形式是λ演算中的一个重要概念。它表示一个λ表达式经过β-化简和η-化简后，无法再进一步化简的形式。λ演算的正常形式是唯一的，它是λ表达式最终的计算结果。例如，考虑以下λ表达式：

λx. (λy. (x + y)) (λz. (z + 1))

这个表达式可以经过β-化简和η-化简，最终得到正常形式：

λy. (λz. (y + z + 1))

这里，λy. (λz. (y + z + 1)) 是一个λ抽象，将变量y绑定到表达式λz. (y + z + 1) 上。这个表达式已经无法进一步化简，因此它是λ演算的正常形式。

λ演算的语义模型通过β-化简、η-化简和正常形式等概念，定义了λ表达式的计算过程和结果。它为我们提供了分析λ演算的有效工具，帮助我们理解和掌握λ演算的语义特性。通过理解λ演算的语义模型，我们可以更好地运用λ演算，解决各种计算问题。

#### 第4章：λ演算的核心算法

##### 4.1 化简与等价性

λ演算中的化简与等价性是理解λ演算行为和性质的关键。化简是指将一个λ表达式转换为等价但更简单的形式，而等价性则是指两个λ表达式在语义上具有相同的行为。

在λ演算中，化简的主要操作是β-化简（β-reduction）和η-化简（η-reduction）。β-化简表示将一个λ抽象应用到某个值上，即将λ抽象中的变量替换为实际值，然后计算得到的结果。η-化简表示将一个函数应用于自身，然后与函数本身进行比较。

β-化简是λ演算中最基本的化简操作。它的形式为：(λx.M) N → M[N/x]，其中M和N是λ表达式，x是变量。例如，考虑以下λ表达式：

(λx. x + 1) 2

这个表达式经过β-化简得到：

x + 1 [2/x]

这里，λx. x + 1 是一个λ抽象，将变量x绑定到表达式x + 1上；2是一个值，表示将函数λx. x + 1 应用到值2上。β-化简过程将变量x替换为值2，得到表达式2 + 1，计算结果为3。

η-化简是λ演算中的另一个重要化简操作。它的形式为：M η → N，其中M和N是λ表达式，且M = λx. f(x)。η-化简可以看作是函数的恒等扩展。例如，考虑以下λ表达式：

λx. (x + 1) (λx. (x + 1))

这个表达式经过η-化简得到：

(λx. (x + 1)) (λx. (x + 1))

这里，λx. (x + 1) 是一个λ抽象，将变量x绑定到表达式x + 1上。η-化简过程将函数λx. (x + 1) 应用于自身，得到一个新的函数，然后与原来的函数进行比较，结果相等。

化简与等价性在λ演算中有着重要的应用。例如，我们可以通过化简来简化复杂的λ表达式，使得程序更加易读和易理解。同时，化简还可以帮助我们分析λ演算的行为，从而更好地理解计算的本质。

等价性则为我们提供了另一种分析工具。如果两个λ表达式在语义上具有相同的行为，那么它们是等价的。通过证明两个λ表达式等价，我们可以确保它们的计算结果相同，从而避免在编程过程中出现意外的错误。

例如，考虑以下两个λ表达式：

λx. (x + 1) 和 (λy. y + 1)

这两个表达式是等价的，因为它们在语义上具有相同的行为。无论输入的值是多少，它们都返回输入值加1的结果。我们可以通过β-化简来证明这两个表达式等价：

(λx. (x + 1)) η → (λy. (y + 1))

这里，η-化简过程将变量x替换为变量y，得到：

x + 1 [y/x]

这个表达式与λy. (y + 1) 是等价的，因为它们在语义上具有相同的行为。

总之，化简与等价性是λ演算中的重要概念。通过β-化简和η-化简，我们可以简化复杂的λ表达式，提高程序的易读性和可维护性。而等价性则为我们提供了证明λ表达式行为一致性的工具，从而确保程序的可靠性。

##### 4.2 正规形式化

正规形式化（Normal Form）是λ演算中的一个重要概念，它定义了一个λ表达式在其化简过程中无法进一步化简的形式。正规形式是λ演算中的计算终止点，它代表了λ表达式的最终计算结果。

在λ演算中，一个λ表达式是否为正规形式可以通过β-化简来判定。如果一个λ表达式经过β-化简后无法进一步化简，那么它就是正规形式。正规形式具有唯一性，即每个λ表达式都有且仅有一个正规形式。

正规形式化在λ演算中有着重要的应用。首先，它为我们提供了一种判断λ表达式是否可化简的依据。如果一个λ表达式不是正规形式，那么它还可以通过β-化简进一步化简。其次，正规形式化可以帮助我们理解λ演算的计算过程，从而更好地掌握λ演算的语义特性。

例如，考虑以下λ表达式：

λx. (λy. (x + y)) (λz. (z + 1))

这个表达式可以经过β-化简得到：

λy. (λz. (y + z + 1))

这个表达式已经无法进一步化简，因此它是正规形式。

再考虑另一个λ表达式：

λx. (λy. (x + y))

这个表达式经过β-化简后得到：

λy. x + y

这个表达式也无法进一步化简，因此它也是正规形式。

然而，不是所有的λ表达式都能化简到正规形式。例如，考虑以下λ表达式：

λx. (λy. (x + y)) (λx. (x + y))

这个表达式无法化简到正规形式，因为它始终处于β-化简的状态。无论进行多少次β-化简，这个表达式都无法得到一个更简单的形式。

正规形式化为我们提供了一种判断λ表达式是否可化简的依据，同时也帮助我们理解λ演算的计算过程。通过理解正规形式化，我们可以更好地掌握λ演算的语义特性，从而在编程实践中更加得心应手。

##### 4.3 索引标注与折叠

在λ演算中，索引标注（Indexing）和折叠（Folding）是两个重要的概念，它们在处理大型λ表达式时非常有用。索引标注用于给变量绑定一个索引，而折叠则用于将λ抽象应用到一组值上。

索引标注是通过在变量前添加一个整数索引来实现的。这个整数索引用于标识变量的位置。例如，考虑以下λ表达式：

λx. (λy. (x + y)) (λz. (z + 1))

我们可以给变量绑定一个索引：

[0]λx. (λy. (x + y)) (λz. (z + 1))
这里，[0]表示变量x的索引为0。类似地，我们可以给其他变量绑定索引：

[0]λx. (λy. (x + y)) [1]λz. (λy. (z + y))

现在，我们有三个变量，每个变量都有一个唯一的索引。索引标注使得我们在处理大型λ表达式时，可以更清晰地追踪变量的绑定和作用。

折叠则是将λ抽象应用到一组值上。折叠分为两部分：应用（Application）和展开（Expansion）。应用是将λ抽象应用到值上，而展开则是将展开后的表达式进行合并。

例如，考虑以下λ表达式：

λx. (λy. (x + y)) [0]λy. 1 [1]λz. 2

我们可以对这个表达式进行折叠：

[0]λy. 1 [1]λz. (1 + 2)
这里，λx. (λy. (x + y)) 是一个λ抽象，[0]λy. 1 和 [1]λz. 2 是值。折叠过程将λ抽象应用到这两个值上，得到一个新的λ表达式。

现在，我们可以对折叠后的表达式进行展开：

[0]λy. 1 [1]λz. 3

展开后的表达式表示将λ抽象应用到值1和值2上，计算得到值3。

索引标注和折叠在处理大型λ表达式时非常有用。它们可以帮助我们更清晰地理解变量绑定和作用，同时简化λ表达式的处理过程。例如，在编译器设计中，索引标注和折叠可以帮助我们处理复杂的中间代码，从而提高编译效率。

总之，索引标注和折叠是λ演算中的重要概念，它们在处理大型λ表达式时非常有用。通过索引标注，我们可以清晰地追踪变量绑定和作用，而折叠则可以简化λ表达式的处理过程。理解这些概念对于掌握λ演算和其在实际应用中的运用至关重要。


在这个示例中，`MetaType` 是一个元类，它定义了类的创建过程。每当创建一个新的类时，`MetaType` 的`__init__` 方法就会被调用。

在这个示例中，`getattr` 函数用于获取对象的属性值，`setattr` 函数用于设置对象的属性值，而`hasattr` 函数用于检查对象是否具有特定的属性。


在这个示例中，`property_decorator` 是一个元类，它使用了反射来创建和操作类的属性。当`my_property` 被定义时，元类将其转换为实际的属性访问器。

**元对象**：


**动态绑定**：

动态绑定是指在运行时根据对象的类型和上下文动态地选择和调用方法。Python使用动态绑定来实现多态，这意味着相同的方法名在不同类型的对象上可以有完全不同的行为。

```python

    def speak(self):
        return "Woof!"

    def speak(self):
        return "Meow!"

    return animal.speak()
```

**元对象与动态绑定的关系**：

元对象和动态绑定在元编程中紧密相关。元对象定义了对象的属性和方法，而动态绑定则允许程序在运行时根据元对象的行为选择和调用方法。

例如，我们可以使用元对象和动态绑定来实现一个通用的属性访问器：

```python
class MetaObject(type):
    def __getattr__(cls, name):
        attr_name = f"_{name}__"
        getter = getattr(cls, attr_name + "getter")
        setter = getattr(cls, attr_name + "setter")
        return getter()

    def __setattr__(cls, name, value):
        attr_name = f"_{name}__"
        getter = getattr(cls, attr_name + "getter")
        setter = getattr(cls, attr_name + "setter")
        setter(value)

class MyMetaObject(type):
    def __new__(cls, name, bases, attrs):
        getter = attrs.get("getter")
        setter = attrs.get("setter")
        if getter or setter:
            attrs[f"_{name}__getter"] = getter
            attrs[f"_{name}__setter"] = setter
        return super().__new__(cls, name, bases, attrs)

class MyClass(metaclass=MyMetaObject):
    @property
    def my_property():
        return "value"

    @my_property.setter
    def my_property(self, value):
        print(f"Setting my_property to {value}")

obj = MyClass()
print(obj.my_property)  # 输出：value
obj.my_property = "new_value"  # 输出：Setting my_property to new_value
```

在这个示例中，`MetaObject` 是一个元对象，它使用了动态绑定来创建和操作对象的属性。当访问或设置对象的属性时，`MetaObject` 的`__getattr__` 和`__setattr__` 方法会被调用，从而实现属性访问器的动态绑定。

总之，元对象和动态绑定是元编程中的核心概念，它们提供了编程语言在运行时操作对象的能力。通过合理地使用元对象和动态绑定，我们可以实现灵活、高效的元编程技术。

**纯函数（Pure Functions）**：

纯函数是一种在给定相同输入时总是返回相同输出的函数，并且不会产生任何副作用。这意味着纯函数不会修改外部状态，也不会产生可观测的副作用。以下是一个简单的纯函数示例：

```haskell

```

在这个示例中，`sum` 函数是一个纯函数，它通过递归计算列表中元素的总和。每次调用`sum` 时，只要输入相同，它的输出就相同，且不会修改外部状态。

**λ演算实现纯函数**：

这个λ表达式表示一个函数，它接收一个参数`x`，并返回另一个函数，这个函数接收一个参数`y`，并将`x` 与`y` 相加。这个λ表达式是一个纯函数，因为它不会修改外部状态，且在给定相同输入时总是返回相同输出。

**高阶函数（Higher-Order Functions）**：

高阶函数是一种能够接收其他函数作为参数或将函数作为返回值的函数。以下是一个简单的Haskell高阶函数示例：


在这个示例中，`applyF` 函数接收一个函数`f` 和一个值`x`，然后将`f` 应用于`x` 上。这个函数是一个高阶函数，因为它接收一个函数作为参数。

**λ演算实现高阶函数**：

**不可变性（Immutability）**：

不可变性是一种编程原则，它要求数据在定义后不能被修改。以下是一个简单的Haskell不可变数据结构示例：
