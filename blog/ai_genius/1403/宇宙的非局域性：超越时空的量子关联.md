##### 系统核心实现源代码

```python
from qiskit import QuantumCircuit, execute, Aer
from qiskit.visualization import plot_bloch_vector

# 生成纠缠态
def create_entangled_state():
    qc = QuantumCircuit(2)
    qc.h(0)
    qc.cx(0, 1)
    return qc

# 测量量子态
def measure_quantum_state(qc):
    qc.h(0)
    qc.measure_all()
    return qc

# 运行模拟
def run_simulation(qc):
    backend = Aer.get_backend('qasm_simulator')
    job = execute(qc, backend, shots=1000)
    result = job.result()
    return result

# 可视化量子态
def visualize_quantum_state(state):
    vector = state.state()
    plot_bloch_vector(vector)

# 主函数
def main():
    qc = create_entangled_state()
    qc = measure_quantum_state(qc)
    result = run_simulation(qc)
    visualize_quantum_state(result.get_statevector())

if __name__ == "__main__":
    main()
```

1. **create_entangled_state()**：生成一个纠缠态。

3. **run_simulation(qc)**：运行量子计算机模拟。

最后，我们定义了一个主函数`main()`，用于执行整个流程。

在主函数中，我们首先创建了一个量子电路`qc`，然后通过`create_entangled_state()`函数生成纠缠态。接着，我们调用`measure_quantum_state(qc)`对量子态进行测量，并通过`run_simulation(qc)`运行模拟。最后，我们使用`visualize_quantum_state(result.get_statevector())`来可视化量子态。

量子非局域性的理论基础源于量子力学的核心原理，即量子纠缠。量子纠缠是两个或多个粒子在量子态上形成的一种紧密关联，即使它们相隔很远，一个粒子的状态变化也会立即影响到其他粒子的状态。这种即时的、超越时空的关联性是量子非局域性的本质特征。

$$

在这个例子中，$|0_A\rangle$和$|1_A\rangle$分别代表粒子A处于基态和激发态，$|0_B\rangle$和$|1_B\rangle$代表粒子B处于基态和激发态。这种纠缠态表明，粒子A和粒子B的状态是相互关联的，即如果对粒子A进行测量并得到基态，那么对粒子B的测量必定会得到激发态，反之亦然。

##### Bell不等式的实验验证

为了验证量子纠缠的存在，物理学家提出了Bell不等式。Bell不等式是经典物理学中的一个重要不等式，它描述了两个粒子之间关联性的最大可能值。然而，当量子纠缠态被用来进行实验时，实验结果往往违反了Bell不等式，这表明量子纠缠确实存在。
