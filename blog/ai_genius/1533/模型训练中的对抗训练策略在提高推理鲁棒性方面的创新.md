### 1.1 问题背景

在当今的计算机科学领域，人工智能（AI）的发展已成为不可阻挡的趋势。其中，机器学习（ML）作为AI的核心技术之一，正逐步改变着我们的生活方式。而机器学习模型训练的质量直接影响到模型的性能和可靠性。在模型训练过程中，对抗训练策略逐渐成为一种提高模型推理鲁棒性的有效手段。

### 1.2 问题描述

随着AI技术的广泛应用，越来越多的场景对模型的推理鲁棒性提出了更高的要求。在实际应用中，模型可能面临各种未知的干扰和攻击，如对抗性攻击（Adversarial Attack）。对抗性攻击是指通过在输入数据中加入微小的扰动，使模型的输出产生较大的误差，从而达到攻击模型的目的。这种攻击方式对模型的推理鲁棒性提出了严峻的挑战。

### 1.3 问题解决

为了提高模型在对抗性攻击下的推理鲁棒性，研究人员提出了对抗训练（Adversarial Training）策略。对抗训练的核心思想是通过在训练过程中引入对抗性样本，使模型能够更好地学习到数据的分布，从而提高模型的鲁棒性。

### 1.4 边界与外延

对抗训练策略的应用范围非常广泛，包括但不限于图像识别、语音识别、自然语言处理等领域。同时，对抗训练策略也在不断发展和完善，涌现出了许多新的算法和变种。本文将重点关注对抗训练策略在提高推理鲁棒性方面的创新，并探讨其实际应用和效果。

### 2.1 核心概念介绍

在深入探讨对抗训练策略之前，我们需要了解一些核心概念，如机器学习模型、对抗性攻击、对抗性样本、损失函数等。

- **机器学习模型**：一种能够根据输入数据进行预测或分类的数学模型。常见的机器学习模型有神经网络、支持向量机、决策树等。
- **对抗性攻击**：一种通过在输入数据中添加微小扰动来破坏模型预测的攻击方式。对抗性攻击可以分为白盒攻击、黑盒攻击和灰盒攻击。
- **对抗性样本**：经过对抗性攻击处理后的样本，其目的是使模型产生错误的预测。
- **损失函数**：用于评估模型预测结果与真实结果之间的差异，常见的损失函数有均方误差（MSE）、交叉熵损失等。

## 第3章 算法原理与数学模型

### 3.1 算法理论

对抗训练策略的核心思想是通过在训练过程中引入对抗性样本，使模型能够更好地学习到数据的分布，从而提高模型的鲁棒性。具体来说，对抗训练可以分为以下步骤：

1. **生成对抗性样本**：根据当前模型，生成对抗性样本。常用的方法有FGSM（Fast Gradient Sign Method）、PGD（Projected Gradient Descent）等。
2. **训练模型**：使用生成的对抗性样本和正常样本一起训练模型，以优化模型参数。
3. **评估模型**：使用对抗性样本评估模型的鲁棒性，并根据评估结果调整训练策略。

### 3.1.3 Python代码实现

以下是一个简单的Python代码示例，用于生成对抗性样本：

```python
import numpy as np
import tensorflow as tf

def generate_adversarial_sample(x, model, epsilon=0.01, alpha=0.01, steps=10):
    x_adv = x.copy()
    for _ in range(steps):
        with tf.GradientTape(persistent=True) as tape:
            tape.watch(x_adv)
            logits = model(x_adv)
            loss = tf.nn.softmax_cross_entropy_with_logits(logits=logits, labels=x_adv)
        grads = tape.gradient(loss, x_adv)
        x_adv = x_adv - alpha * grads.sign() # projected gradient descent
    return x_adv
```

### 3.1.4 数学模型与公式

对抗训练的数学模型主要涉及损失函数和优化算法。以下是相关的数学公式：

1. **损失函数**：$$L(\theta) = \frac{1}{N}\sum_{i=1}^{N}L_i(\theta)$$
   其中，$L_i(\theta)$ 表示第$i$个样本的损失，$\theta$ 表示模型参数。

2. **优化算法**：梯度下降（Gradient Descent）
   $$\theta_{t+1} = \theta_t - \alpha \nabla_{\theta}L(\theta_t)$$
   其中，$\alpha$ 表示学习率。

### 3.2 数学模型详细讲解

#### 3.2.1 损失函数

损失函数用于评估模型预测结果与真实结果之间的差异。在对抗训练中，常用的损失函数有均方误差（MSE）和交叉熵损失。

1. **均方误差（MSE）**：
   $$L(\theta) = \frac{1}{N}\sum_{i=1}^{N}(\hat{y}_i - y_i)^2$$
   其中，$\hat{y}_i$ 表示模型预测结果，$y_i$ 表示真实结果。

2. **交叉熵损失**：
   $$L(\theta) = -\frac{1}{N}\sum_{i=1}^{N}y_i\log(\hat{y}_i)$$
   其中，$y_i$ 表示真实结果的概率分布，$\hat{y}_i$ 表示模型预测结果。

#### 3.2.2 优化算法

在对抗训练中，常用的优化算法有梯度下降（Gradient Descent）和投影梯度下降（Projected Gradient Descent）。

1. **梯度下降**：
   $$\theta_{t+1} = \theta_t - \alpha \nabla_{\theta}L(\theta_t)$$
   其中，$\alpha$ 表示学习率，$\nabla_{\theta}L(\theta_t)$ 表示模型参数的梯度。

2. **投影梯度下降**：
   $$\theta_{t+1} = \theta_t - \alpha \nabla_{\theta}L(\theta_t) + \delta$$
   其中，$\delta$ 表示投影操作，用于防止梯度下降过程中越界。

### 3.3 举例说明

为了更好地理解对抗训练的数学模型，我们以下面这个简单的例子进行说明：

假设有一个二元分类问题，模型的损失函数为均方误差（MSE）。现有如下训练数据和参数：

$$
\begin{aligned}
    &x_1 = [1, 0], \quad y_1 = 1 \\
    &x_2 = [0, 1], \quad y_2 = 0 \\
    &\theta_0 = [1, 1]
\end{aligned}
$$

初始参数为 $\theta_0 = [1, 1]$，学习率 $\alpha = 0.1$。

#### 3.3.1 第一轮梯度下降

1. **计算损失**：
   $$L(\theta_0) = \frac{1}{2}((1-1)^2 + (1-0)^2) = 0.5$$
2. **计算梯度**：
   $$\nabla_{\theta}L(\theta_0) = [-0.5, 0.5]$$
3. **更新参数**：
   $$\theta_1 = \theta_0 - \alpha \nabla_{\theta}L(\theta_0) = [0.6, 0.6]$$

#### 3.3.2 第一轮投影梯度下降

1. **计算损失**：
   $$L(\theta_0) = 0.5$$
2. **计算梯度**：
   $$\nabla_{\theta}L(\theta_0) = [-0.5, 0.5]$$
3. **投影操作**：
   $$\delta = \min(\max(\theta_1 - \nabla_{\theta}L(\theta_0), 0), 1) = [0, 0.5]$$
4. **更新参数**：
   $$\theta_1 = \theta_0 - \alpha \nabla_{\theta}L(\theta_0) + \delta = [0.6, 0.5]$$

通过以上步骤，我们可以看到梯度下降和投影梯度下降在更新参数时有所不同。投影梯度下降通过引入投影操作，防止了参数越界，从而提高了模型的稳定性。

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

def create_model(input_shape):
    model = Sequential()
    model.add(Dense(64, activation='relu', input_shape=input_shape))
    model.add(Dense(64, activation='relu'))
    model.add(Dense(1, activation='sigmoid'))
    return model
```

#### 5.2.2 对抗性样本生成

接下来，我们使用FGSM（Fast Gradient Sign Method）方法生成对抗性样本。

```python
import numpy as np
import tensorflow as tf

def generate_adversarial_sample(x, model, epsilon=0.01):
    x_adv = x.copy()
    x_adv = tf.convert_to_tensor(x_adv, dtype=tf.float32)
    with tf.GradientTape(persistent=True) as tape:
        tape.watch(x_adv)
        logits = model(x_adv)
        loss = tf.nn.sigmoid_cross_entropy_with_logits(logits=logits, labels=x)
    grads = tape.gradient(loss, x_adv)
    x_adv = x_adv - epsilon * grads.sign()
    x_adv = x_adv.numpy()
    return x_adv
```

#### 5.2.3 模型训练

在模型训练过程中，我们将使用对抗性样本和正常样本一起训练模型。

```python
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.losses import BinaryCrossEntropy

def train_model(model, x_train, y_train, x_val, y_val, epochs=10, batch_size=32):
    optimizer = Adam(learning_rate=0.001)
    loss_fn = BinaryCrossEntropy()

    for epoch in range(epochs):
        for i in range(0, len(x_train), batch_size):
            x_batch = x_train[i:i+batch_size]
            y_batch = y_train[i:i+batch_size]

            # 生成对抗性样本
            x_adv_batch = generate_adversarial_sample(x_batch, model)

            # 训练模型
            with tf.GradientTape() as tape:
                logits = model(x_batch)
                loss = loss_fn(y_batch, logits)
                logits_adv = model(x_adv_batch)
                loss_adv = loss_fn(y_train, logits_adv)

            grads = tape.gradient(loss + loss_adv, model.trainable_variables)
            optimizer.apply_gradients(zip(grads, model.trainable_variables))

        # 评估模型
        val_loss = loss_fn(y_val, model(x_val))
        print(f"Epoch {epoch+1}, Loss: {val_loss.numpy()}")
```

随着AI技术的广泛应用，越来越多的场景对模型的推理鲁棒性提出了更高的要求。在实际应用中，模型可能面临各种未知的干扰和攻击，如对抗性攻击（Adversarial Attack）。对抗性攻击是指通过在输入数据中加入微小的扰动，使模型的输出产生较大的误差，从而达到攻击模型的目的。这种攻击方式对模型的推理鲁棒性提出了严峻的挑战。

### 1.3 问题解决

为了提高模型在对抗性攻击下的推理鲁棒性，研究人员提出了对抗训练（Adversarial Training）策略。对抗训练的核心思想是通过在训练过程中引入对抗性样本，使模型能够更好地学习到数据的分布，从而提高模型的鲁棒性。

### 1.4 边界与外延

对抗训练策略的应用范围非常广泛，包括但不限于图像识别、语音识别、自然语言处理等领域。同时，对抗训练策略也在不断发展和完善，涌现出了许多新的算法和变种。本文将重点关注对抗训练策略在提高推理鲁棒性方面的创新，并探讨其实际应用和效果。

## 第2章 基本概念与关系

对抗训练策略在提高模型推理鲁棒性方面具有重要意义，因此，理解相关的基本概念和关系是至关重要的。在这一章节中，我们将介绍对抗训练中的关键概念，如对抗性攻击、对抗性样本、损失函数等，并分析它们之间的关系。

### 2.1 核心概念介绍

#### 2.1.1 对抗性攻击

对抗性攻击（Adversarial Attack）是一种通过在正常输入数据中添加微小的扰动，从而破坏模型预测的攻击方法。这种攻击方式的核心思想是利用模型的敏感性，使得在人类看来几乎不可察觉的扰动，能够导致模型输出产生重大错误。常见的对抗性攻击方法包括：

- **Fast Gradient Sign Method (FGSM)**：通过计算梯度并取符号来生成对抗性样本，攻击过程简单，但效果有限。
- **Projected Gradient Descent (PGD)**：在梯度下降的基础上引入投影操作，提高对抗性样本的鲁棒性。

#### 2.1.2 对抗性样本

对抗性样本（Adversarial Sample）是经过对抗性攻击处理后的输入数据，其目的是欺骗模型，使其产生错误的预测。对抗性样本的生成通常基于以下步骤：

1. **输入选择**：从训练集中随机选择一个样本。
2. **攻击方法选择**：根据模型的特点选择适当的对抗性攻击方法。
3. **对抗性样本生成**：通过攻击方法对输入样本进行扰动，生成对抗性样本。

#### 2.1.3 损失函数

损失函数（Loss Function）用于评估模型预测结果与真实结果之间的差异，是优化模型参数的重要工具。在对抗训练中，常用的损失函数包括：

- **均方误差（Mean Squared Error, MSE）**：适用于回归问题，计算预测值与真实值之间的平方误差的平均值。
- **交叉熵损失（Cross-Entropy Loss）**：适用于分类问题，计算预测概率分布与真实概率分布之间的交叉熵。

#### 2.1.4 抗衡训练策略

抗衡训练策略（Adversarial Training）是一种通过在训练过程中引入对抗性样本来提高模型鲁棒性的方法。其核心思想是让模型在面对对抗性样本时能够更好地学习到数据的分布，从而提高模型在真实数据上的表现。抗衡训练策略主要包括以下步骤：

1. **对抗性样本生成**：使用对抗性攻击方法生成对抗性样本。
2. **混合训练**：将对抗性样本与正常样本混合，共同用于模型训练。
3. **模型优化**：通过优化损失函数来调整模型参数。

### 3.1.3 Python代码实现

为了更好地理解对抗训练的算法流程，我们使用Python代码实现一个简单的对抗训练过程。以下是一个简单的示例：

```python
import numpy as np
import tensorflow as tf

# 初始化模型
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu', input_shape=(784,)),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(10, activation='softmax')
])

# 生成对抗性样本
def generate_adversarial_sample(x, model, attack_type='fgsm', epsilon=0.1, steps=1):
    x_adv = x.copy()
    if attack_type == 'fgsm':
        with tf.GradientTape() as tape:
            tape.watch(x_adv)
            logits = model(x_adv)
            loss = tf.keras.losses.categorical_crossentropy(tf.one_hot(y, depth=10), logits)
        grads = tape.gradient(loss, x_adv)
        x_adv = x_adv - epsilon * grads.sign()
    elif attack_type == 'pgd':
        for _ in range(steps):
            with tf.GradientTape() as tape:
                tape.watch(x_adv)
                logits = model(x_adv)
                loss = tf.keras.losses.categorical_crossentropy(tf.one_hot(y, depth=10), logits)
            grads = tape.gradient(loss, x_adv)
            x_adv = x_adv - 0.01 * grads.sign()
    return x_adv

# 混合训练样本
def train_model(model, x_train, y_train, x_val, y_val, epochs=10, batch_size=32):
    optimizer = tf.keras.optimizers.Adam(learning_rate=0.001)
    loss_fn = tf.keras.losses.categorical_crossentropy
    
    for epoch in range(epochs):
        for x, y in zip(x_train, y_train):
            x_adv = generate_adversarial_sample(x, model, attack_type='fgsm')
            with tf.GradientTape() as tape:
                logits = model(x_adv)
                loss = loss_fn(y, logits)
            grads = tape.gradient(loss, model.trainable_variables)
            optimizer.apply_gradients(zip(grads, model.trainable_variables))
        
        val_loss = loss_fn(y_val, model(x_val))
        print(f"Epoch {epoch+1}, Loss: {val_loss.numpy()}")

# 评估模型鲁棒性
def evaluate_model(model, x_test, y_test, attack_type='fgsm', epsilon=0.1):
    x_val_adv = generate_adversarial_sample(x_test, model, attack_type=attack_type, epsilon=epsilon)
    val_loss_adv = tf.keras.losses.categorical_crossentropy(y_test, model(x_val_adv))
    print(f"Adversarial Loss: {val_loss_adv.numpy()}")

# 加载MNIST数据集
(x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data()
x_train = x_train.reshape(-1, 784).astype(np.float32) / 255.0
x_test = x_test.reshape(-1, 784).astype(np.float32) / 255.0
y_train = tf.one_hot(y_train, depth=10)
y_test = tf.one_hot(y_test, depth=10)

# 训练模型
train_model(model, x_train, y_train, x_test, y_test, epochs=10)

# 评估模型鲁棒性
evaluate_model(model, x_test, y_test, attack_type='fgsm', epsilon=0.1)
```

### 3.1.4 数学模型与公式

对抗训练的数学模型主要涉及损失函数、优化算法和对抗性样本的生成过程。以下是相关的数学公式和解释：

1. **损失函数**：

   假设我们的模型为$f(x; \theta)$，其中$x$为输入样本，$\theta$为模型参数。对抗性攻击的目标是最大化损失函数，即：

   $$L(\theta) = \arg\max_{\theta} -\frac{1}{N}\sum_{i=1}^{N}y_i \log f(x_i; \theta)$$

   其中，$y_i$为真实标签，$N$为样本数量。这个损失函数是交叉熵损失函数，用于评估模型预测概率分布与真实概率分布之间的差异。

2. **优化算法**：

   对抗训练通常使用梯度下降（Gradient Descent）或其变种，如随机梯度下降（Stochastic Gradient Descent, SGD）和批量梯度下降（Batch Gradient Descent, BGD）来优化模型参数。优化算法的基本形式为：

   $$\theta_{t+1} = \theta_t - \alpha \nabla_{\theta}L(\theta_t)$$

   其中，$\alpha$为学习率，$\nabla_{\theta}L(\theta_t)$为损失函数对模型参数的梯度。

3. **对抗性样本的生成过程**：

   对抗性样本的生成过程涉及梯度计算和扰动。以下是FGSM和PGD两种攻击方法的数学模型：

   - **FGSM**：

     $$x_{adv} = x + \epsilon \cdot \text{sign}(\nabla_{x}L(x; \theta))$$

     其中，$\epsilon$为扰动幅度，$\text{sign}(\cdot)$为取符号函数。

   - **PGD**：

     $$x_{adv} = x + \frac{\alpha}{\| \nabla_{x}L(x; \theta) \|_2} \cdot \nabla_{x}L(x; \theta)$$

     其中，$\alpha$为步长，$\| \cdot \|_2$为二范数。

### 3.2 数学模型详细讲解

#### 3.2.1 损失函数

损失函数是评估模型预测结果与真实结果之间差异的关键指标。在对抗训练中，常用的损失函数包括交叉熵损失（Cross-Entropy Loss）和均方误差（Mean Squared Error, MSE）。

1. **交叉熵损失（Cross-Entropy Loss）**：

   假设模型预测的概率分布为$\hat{y}$，真实概率分布为$y$，则交叉熵损失可以表示为：

   $$L(y, \hat{y}) = -\sum_{i=1}^{N} y_i \log \hat{y}_i$$

   其中，$y_i$和$\hat{y}_i$分别为真实标签和模型预测的标签概率。

   对于分类问题，通常使用一个向量$y$表示真实标签，一个向量$\hat{y}$表示模型预测的概率分布。则交叉熵损失函数可以扩展为：

   $$L(y, \hat{y}) = -\log \hat{y}^T y$$

2. **均方误差（Mean Squared Error, MSE）**：

   假设模型的预测值为$\hat{y}$，真实值为$y$，则均方误差可以表示为：

   $$L(y, \hat{y}) = \frac{1}{2} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$

   对于回归问题，均方误差是评估预测值与真实值之间差异的常用指标。

#### 3.2.2 优化算法

在对抗训练中，常用的优化算法包括梯度下降（Gradient Descent）和其变种，如随机梯度下降（Stochastic Gradient Descent, SGD）和批量梯度下降（Batch Gradient Descent, BGD）。

1. **梯度下降（Gradient Descent）**：

   梯度下降是一种基于损失函数梯度的优化算法。其基本思想是沿着梯度的反方向调整模型参数，以最小化损失函数。

   假设损失函数为$L(\theta)$，则梯度下降的迭代公式为：

   $$\theta_{t+1} = \theta_t - \alpha \nabla_{\theta}L(\theta_t)$$

   其中，$\alpha$为学习率，$\nabla_{\theta}L(\theta_t)$为损失函数对模型参数的梯度。

   梯度下降分为随机梯度下降（SGD）和批量梯度下降（BGD）：

   - **随机梯度下降（SGD）**：每次迭代只随机选择一个样本，计算其梯度并更新模型参数。
   - **批量梯度下降（BGD）**：每次迭代计算所有样本的梯度，并更新模型参数。

2. **对抗性攻击算法**：

   对抗性攻击算法是生成对抗性样本的关键。以下介绍两种常见的攻击方法：FGSM和PGD。

   - **FGSM（Fast Gradient Sign Method）**：

     FGSM是一种简单的攻击方法，其核心思想是计算梯度并取符号，用于生成对抗性样本。

     假设模型参数为$\theta$，输入样本为$x$，则FGSM生成的对抗性样本为：

     $$x_{adv} = x + \epsilon \cdot \text{sign}(\nabla_{x}L(x; \theta))$$

     其中，$\epsilon$为扰动幅度，$\text{sign}(\cdot)$为取符号函数。

   - **PGD（Projected Gradient Descent）**：

     PGD是一种更为复杂的攻击方法，其核心思想是利用投影操作防止模型参数越界。

     假设模型参数为$\theta$，输入样本为$x$，则PGD生成的对抗性样本为：

     $$x_{adv} = x + \frac{\alpha}{\| \nabla_{x}L(x; \theta) \|_2} \cdot \nabla_{x}L(x; \theta)$$

     其中，$\alpha$为步长，$\| \cdot \|_2$为二范数。

### 3.3 举例说明

为了更好地理解对抗训练的数学模型，我们以下面这个简单的例子进行说明：

假设我们有一个二元分类问题，模型的损失函数为交叉熵损失。现有如下训练数据和参数：

$$
\begin{aligned}
    &x_1 = [1, 0], \quad y_1 = 1 \\
    &x_2 = [0, 1], \quad y_2 = 0 \\
    &\theta_0 = [1, 1]
\end{aligned}
$$

初始参数为 $\theta_0 = [1, 1]$，学习率 $\alpha = 0.1$。

#### 3.3.1 第一轮梯度下降

1. **计算损失**：

   $$L(\theta_0) = -\log(0.5) - \log(0.5) = -2$$
2. **计算梯度**：

   $$\nabla_{\theta}L(\theta_0) = [-1, -1]$$
3. **更新参数**：

   $$\theta_1 = \theta_0 - \alpha \nabla_{\theta}L(\theta_0) = [0.9, 0.9]$$

   通过计算可以看出，梯度下降使得参数向损失函数梯度方向的反方向更新，从而减小损失。

#### 3.3.2 第一轮投影梯度下降

1. **计算损失**：

   $$L(\theta_0) = -2$$
2. **计算梯度**：

   $$\nabla_{\theta}L(\theta_0) = [-1, -1]$$
3. **投影操作**：

   $$\theta_1 = \theta_0 - \alpha \nabla_{\theta}L(\theta_0) = [0.9, 0.9]$$

   在投影梯度下降中，参数的更新受到投影操作的限制，从而避免了参数越界。

通过以上步骤，我们可以看到梯度下降和投影梯度下降在更新参数时有所不同。梯度下降直接沿着梯度方向更新参数，而投影梯度下降通过投影操作限制参数的更新范围，从而提高了模型的稳定性。

#### 5.2.2 对抗性样本生成

```python
import numpy as np
import tensorflow as tf

def generate_adversarial_sample(x, model, epsilon=0.01):
    x_adv = x.copy()
    x_adv = tf.convert_to_tensor(x_adv, dtype=tf.float32)
    with tf.GradientTape(persistent=True) as tape:
        tape.watch(x_adv)
        logits = model(x_adv)
        loss = tf.nn.sigmoid_cross_entropy_with_logits(logits=logits, labels=x_adv)
    grads = tape.gradient(loss, x_adv)
    x_adv = x_adv - epsilon * grads.sign()
    x_adv = x_adv.numpy()
    return x_adv
```

```python
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.losses import BinaryCrossEntropy

def train_model(model, x_train, y_train, x_val, y_val, epochs=10, batch_size=32):
    optimizer = Adam(learning_rate=0.001)
    loss_fn = BinaryCrossEntropy()

    for epoch in range(epochs):
        for i in range(0, len(x_train), batch_size):
            x_batch = x_train[i:i+batch_size]
            y_batch = y_train[i:i+batch_size]

            # 生成对抗性样本
            x_adv_batch = generate_adversarial_sample(x_batch, model)

            # 训练模型
            with tf.GradientTape() as tape:
                logits = model(x_batch)
                loss = loss_fn(y_batch, logits)
                logits_adv = model(x_adv_batch)
                loss_adv = loss_fn(y_train, logits_adv)

            grads = tape.gradient(loss + loss_adv, model.trainable_variables)
            optimizer.apply_gradients(zip(grads, model.trainable_variables))

        # 评估模型
        val_loss = loss_fn(y_val, model(x_val))
        print(f"Epoch {epoch+1}, Loss: {val_loss.numpy()}")
```
