##### 1.1.1 硅谷的崛起与变迁

硅谷，这个位于美国加利福尼亚州旧金山湾区南部的地区，是全球科技创新的圣地。它起源于20世纪50年代的半导体行业，随着英特尔、惠普、苹果等科技巨头的崛起，逐渐发展成为全球高科技产业的中心。硅谷的崛起离不开其独特的创新模式，这种模式在传统的产业中难以找到。

硅谷的创新模式主要表现在以下几个方面：

1. **产业与学术的结合**：硅谷的科技创新离不开学术界的支持。斯坦福大学、加州大学伯克利分校等顶尖高校的科研人员经常将最新的研究成果转化为实际应用，推动产业的技术创新。

2. **风险投资文化的形成**：硅谷的风险投资文化使创业公司能够快速获得资金支持，从而实现科技创新的商业化。

3. **创业文化的普及**：硅谷的企业文化鼓励创新和冒险，许多企业家在失败后仍然敢于重新创业，这种精神使得硅谷成为全球创业者的乐园。

def linear_regression(x, y):
    # 计算斜率
    slope = (mean(y) - mean(x) * mean(y)) / (var(x))
    
    # 计算截距
    intercept = mean(y) - slope * mean(x)
    
    # 线性回归方程
    equation = slope * x + intercept
    
    return equation

# 导入numpy库
import numpy as np

# 定义训练数据
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([[1], [2], [3], [4], [5]])

# 计算斜率
# 使用公式计算斜率：斜率 = (y的平均值 - x的平均值 * y的平均值) / x的方差
slope = (np.mean(y) - np.mean(X) * np.mean(y)) / np.std(X)

# 计算截距
# 使用公式计算截距：截距 = y的平均值 - 斜率 * x的平均值
intercept = np.mean(y) - slope * np.mean(X)

# 线性回归方程
# 使用公式计算线性回归方程：y = 斜率 * x + 截距
equation = slope * X + intercept

# 计算预测值
# 使用线性回归方程计算预测值
y_pred = equation

# 计算均方误差
# 使用公式计算均方误差：均方误差 = (y的实际值 - 预测值)的平方和的平均值
mse = np.mean((y - y_pred) ** 2)

# 打印结果
# 打印斜率、截距和均方误差
print("斜率:", slope)
