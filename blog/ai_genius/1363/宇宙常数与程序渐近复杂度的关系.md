## 附录：markdown格式说明

在撰写本文时，我们使用了markdown格式来组织文章结构，确保文章的可读性和一致性。以下是一些markdown格式的说明和示例，帮助读者更好地理解和应用markdown格式。

### 1. 标题

markdown使用井号（#）来表示标题。井号的数量决定了标题的级别，例如，一个井号表示一级标题，两个井号表示二级标题，以此类推。以下是一个示例：

```markdown
# 标题1
## 标题2
### 标题3
#### 标题4
```

输出结果：

- 标题1
- 标题2
- 标题3
- 标题4

### 2. 段落

markdown中的文本默认为段落。在两个标题之间或标题与正文之间，直接输入文本即可创建段落。以下是一个示例：

```markdown
这是一个段落。

这是一个新的段落。
```

输出结果：

这是一个段落。

这是一个新的段落。

### 3. 列表

markdown支持有序和无序列表。有序列表使用数字和英文句点（.）来表示，无序列表使用星号（*）、加号（+）或减号（-）来表示。以下是一个示例：

```markdown
- 无序列表项1
- 无序列表项2
- 无序列表项3

1. 有序列表项1
2. 有序列表项2
3. 有序列表项3
```

输出结果：

- 无序列表项1
- 无序列表项2
- 无序列表项3

1. 有序列表项1
2. 有序列表项2
3. 有序列表项3

### 4. 引用

markdown中的引用使用大于号（>）来标识。引用可以嵌套，使用多个大于号。以下是一个示例：

```markdown
> 这是一个引用。

>>> 这是一个嵌套的引用。
```

输出结果：

这是一个引用。

> 这是一个嵌套的引用。

### 5. 粗体和斜体

markdown使用两个星号（**）来表示粗体，一个星号（*）来表示斜体。以下是一个示例：

```markdown
**粗体文本**

*斜体文本*
```

输出结果：

**粗体文本**

*斜体文本*

### 6. 链接

markdown中的链接使用方括号（[]）和圆括号（()）来表示。方括号内是链接文本，圆括号内是URL。以下是一个示例：

```markdown
这是一个链接。[点我](https://www.example.com)
```

输出结果：

这是一个链接。[点我](https://www.example.com)

### 7. 表格

markdown中的表格使用竖线（|）和横线（-）来表示。以下是一个示例：

```markdown
| 标题1 | 标题2 | 标题3 |
|-------|------|------|
| 单元格1 | 单元格2 | 单元格3 |
| 单元格4 | 单元格5 | 单元格6 |
```

输出结果：

| 标题1 | 标题2 | 标题3 |
|-------|------|------|
| 单元格1 | 单元格2 | 单元格3 |
| 单元格4 | 单元格5 | 单元格6 |

### 8. 代码块

markdown中的代码块使用三个反引号（```)来标识。以下是一个示例：

```python
def hello_world():
    print("Hello, World!")
hello_world()
```

输出结果：

```python
def hello_world():
    print("Hello, World!")
hello_world()
```

### 9. LaTeX公式

markdown中的LaTeX公式使用两个美元符号（$$）来标识。以下是一个示例：

```markdown
$$
E = mc^2
$$
```

输出结果：

$$
E = mc^2
$$
