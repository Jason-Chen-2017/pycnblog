#### 3.1 梯度下降法

梯度下降法是最常用的优化算法之一，其基本思想是通过不断沿着目标函数梯度的反方向进行迭代，以逐步逼近最优解。

**伪代码：**

```python
Initialize: x0, learning rate α
for i = 1 to n_iterations do
  Compute gradient: ∇f(x)
  Update: x = x - α * ∇f(x)
  Check convergence: if |x - x_old| < ε then break
return x
```

**详细步骤：**
1. **初始化**：选择一个初始解 `x0` 和学习率 `α`。
2. **计算梯度**：在当前解 `x` 处计算目标函数的梯度 `∇f(x)`。
3. **更新解**：根据梯度方向和步长（学习率 `α`），更新解 `x = x - α * ∇f(x)`。
4. **检查收敛**：若当前解与上一轮解的差距小于预设阈值 `ε`，则算法收敛。

梯度下降法的关键在于选择合适的学习率 `α`，过大可能导致步长过长，无法收敛；过小则收敛速度过慢。在实际应用中，常用的技巧包括动量（Momentum）和自适应学习率（Adaptive Learning Rate）。

#### 3.2 随机梯度下降法（SGD）

随机梯度下降法是梯度下降法的变种，通过随机选择一部分数据进行梯度计算，以加速收敛。

**伪代码：**

```python
Initialize: x0, learning rate α, mini-batch size m
for i = 1 to n_iterations do
  Shuffle data
  for each sample xi in mini-batch do
    Compute gradient: ∇f(xi)
    Update: x = x - α * ∇f(xi)
  Check convergence: if |x - x_old| < ε then break
return x
```

**详细步骤：**
1. **初始化**：选择一个初始解 `x0`、学习率 `α` 和 mini-batch size `m`。
2. **数据打乱**：将数据集随机打乱。
3. **计算梯度**：对于每个 mini-batch 中的样本 `xi`，计算梯度 `∇f(xi)`。
4. **更新解**：根据梯度方向和步长（学习率 `α`），更新解 `x = x - α * ∇f(xi)`。
5. **检查收敛**：若当前解与上一轮解的差距小于预设阈值 `ε`，则算法收敛。

随机梯度下降法的优点是计算复杂度低，适合大规模数据集，但需要更多的迭代次数才能收敛。

#### 3.3 牛顿法

牛顿法是基于目标函数的一阶导数和二阶导数进行迭代的优化算法，其原理是基于泰勒展开式，通过线性近似来逼近最优解。

**伪代码：**

```python
Initialize: x0, learning rate α
for i = 1 to n_iterations do
  Compute gradient: ∇f(x)
  Compute Hessian: H = ∇²f(x)
  Update: x = x - α * (-H)^(-1) * ∇f(x)
  Check convergence: if |x - x_old| < ε then break
return x
```

**详细步骤：**
1. **初始化**：选择一个初始解 `x0` 和学习率 `α`。
2. **计算梯度**：在当前解 `x` 处计算目标函数的梯度 `∇f(x)`。
3. **计算Hessian矩阵**：计算目标函数的二阶导数矩阵 `H = ∇²f(x)`。
4. **更新解**：根据梯度和Hessian矩阵，更新解 `x = x - α * (-H)^(-1) * ∇f(x)`。
5. **检查收敛**：若当前解与上一轮解的差距小于预设阈值 `ε`，则算法收敛。

牛顿法的优点是收敛速度快，但需要计算二阶导数，对目标函数的要求较高。

#### 3.4 拉格朗日乘数法

拉格朗日乘数法是一种用于处理约束优化问题的算法，其基本思想是通过引入拉格朗日乘数，将约束优化问题转化为无约束优化问题。

**伪代码：**

```python
Initialize: λ0, x0

  Compute gradient: ∇f(x) and ∇g(x)
  Compute Lagrangian: L(x, λ) = f(x) + λ * g(x)
  Update: x = x - α * (-∇L(x, λ)) and λ = λ + β * ∇λ
  Check convergence: if |x - x_old| < ε then break
return x, λ
```

**详细步骤：**
1. **初始化**：选择一个初始解 `x0` 和拉格朗日乘数 `λ0`。
2. **计算梯度**：计算目标函数 `f(x)` 和约束函数 `g(x)` 的梯度 `∇f(x)` 和 `∇g(x)`。
3. **计算拉格朗日函数**：构建拉格朗日函数 `L(x, λ) = f(x) + λ * g(x)`。
4. **更新解和拉格朗日乘数**：根据梯度和拉格朗日乘数，更新解 `x = x - α * (-∇L(x, λ))` 和拉格朗日乘数 `λ = λ + β * ∇λ`。
5. **检查收敛**：若当前解和拉格朗日乘数的差距小于预设阈值 `ε`，则算法收敛。

拉格朗日乘数法适用于有约束的优化问题，可以通过引入拉格朗日乘数来处理约束条件。

#### 4.1 最优化问题

最优化问题是算法优化的核心，其基本形式可以表示为：

$$
\min_{x} f(x)
$$

其中，\( f(x) \) 是目标函数，\( x \) 是待优化的变量。

**例1：线性回归**

假设我们有数据集 \( D = \{ (x_1, y_1), (x_2, y_2), ..., (x_n, y_n) \} \)，我们的目标是找到直线 \( y = wx + b \) 的参数 \( w \) 和 \( b \)，使得预测值与实际值之间的误差最小。这是一个典型的线性回归问题，其目标函数可以表示为：

$$
\min_{w, b} \sum_{i=1}^{n} (wx_i + b - y_i)^2
$$

通过求解这个最优化问题，我们可以得到最优的 \( w \) 和 \( b \) 值，从而实现数据的最佳拟合。

**例2：支持向量机（SVM）**

在支持向量机中，我们希望找到一个超平面，将数据集中的正负样本尽可能分开。目标函数可以表示为：

$$
\min_{w, b, \xi_i} \frac{1}{2} ||w||^2 + C \sum_{i=1}^{n} \xi_i
$$

其中，\( C \) 是惩罚参数，\( \xi_i \) 是每个样本的松弛变量，用于处理不可分的情况。

#### 4.2 约束优化问题

约束优化问题是包含约束条件的最优化问题，其一般形式为：

$$
\min_{x} f(x) \quad \text{subject to} \quad g(x) \leq 0, \quad h(x) = 0
$$

其中，\( g(x) \) 和 \( h(x) \) 分别是约束条件。

**例1：二次规划**

二次规划问题是目标函数为二次函数的约束优化问题，其形式为：

$$
\min_{x} \frac{1}{2} x^T Q x + c^T x \quad \text{subject to} \quad Ax \leq b
$$

其中，\( Q \) 是对称矩阵，\( c \) 是向量，\( A \) 和 \( b \) 分别是约束矩阵和约束向量。

**例2：线性规划**

线性规划是目标函数为线性函数的约束优化问题，其形式为：

$$
\min_{x} c^T x \quad \text{subject to} \quad Ax \leq b
$$

线性规划在实际应用中非常广泛，如资源分配、生产调度等问题。

#### 4.3 非线性优化问题

非线性优化问题是目标函数或约束条件为非线性函数的优化问题，其形式为：

$$
\min_{x} f(x) \quad \text{subject to} \quad g(x) \leq 0, \quad h(x) = 0
$$

非线性优化问题通常没有解析解，需要使用数值方法求解。

**例1：非线性回归**

非线性回归问题类似于线性回归，但目标函数为非线性函数，其形式为：

$$
\min_{w, b} \sum_{i=1}^{n} (f(w x_i + b) - y_i)^2
$$

其中，\( f \) 是非线性函数，如多项式、指数函数等。

**例2：神经网络训练**

神经网络训练问题是一个复杂的非线性优化问题，其目标是找到网络参数 \( w, b \) 使得输出误差最小。目标函数可以表示为：

$$
\min_{w, b} \sum_{i=1}^{n} (y_i - \sigma(w x_i + b))^2
$$

其中，\( \sigma \) 是激活函数，如Sigmoid、ReLU等。

#### 4.4 拉格朗日乘数法

拉格朗日乘数法是一种用于处理约束优化问题的数值方法，其基本思想是通过引入拉格朗日乘数，将约束优化问题转化为无约束优化问题。

**公式：**

$$
L(x, \lambda) = f(x) + \lambda g(x)
$$

其中，\( L \) 是拉格朗日函数，\( \lambda \) 是拉格朗日乘数。

**详细步骤：**

1. **计算梯度**：计算拉格朗日函数 \( L \) 对 \( x \) 和 \( \lambda \) 的梯度。
2. **设置方程**：令梯度为零，得到以下方程组：
   $$
   \begin{cases}
   \nabla_x L(x, \lambda) = 0 \\
   \nabla_\lambda L(x, \lambda) = 0
   \end{cases}
   $$
3. **求解方程**：通过求解方程组，得到最优解 \( x \) 和拉格朗日乘数 \( \lambda \)。

**例：线性规划**

假设我们有以下线性规划问题：

$$
\min_{x} c^T x \quad \text{subject to} \quad Ax \leq b
$$

使用拉格朗日乘数法，我们可以引入拉格朗日乘数 \( \lambda \)，构建拉格朗日函数：

$$
L(x, \lambda) = c^T x + \lambda^T (Ax - b)
$$

通过计算梯度并设置方程组，我们可以得到最优解 \( x \) 和拉格朗日乘数 \( \lambda \)。

1. **幂律分布**：幂律分布是一种常用的宇宙能量分布模型，其形式为：
   $$
   P(E) \propto E^{-\gamma}
   $$
   其中，\( E \) 是能量，\( \gamma \) 是幂律指数。这种模型常用于描述宇宙中的星系和暗物质分布。

2. **高斯分布**：高斯分布模型是一种概率分布模型，其形式为：
   $$
   P(E) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(E-\mu)^2}{2\sigma^2}}

#### 6.2 宇宙能量分布规律模型验证的方法

模型验证的关键是评估模型对实验数据的拟合效果。以下是一些常用的验证方法：

1. **交叉验证**：交叉验证是一种常用的模型验证方法，通过将数据集划分为多个子集，分别用于训练和验证模型。具体步骤如下：
   - 将数据集 \( D \) 划分为 \( K \) 个子集 \( D_1, D_2, ..., D_K \)。
   - 对每个子集 \( D_k \)，使用其余 \( K-1 \) 个子集进行模型训练，并在 \( D_k \) 上进行验证。
   - 计算模型在每个子集上的验证误差，并取平均值作为最终验证误差。

2. **ROC曲线**：ROC曲线（Receiver Operating Characteristic curve）是一种评估二分类模型性能的方法。通过计算真阳性率（True Positive Rate, TPR）和假阳性率（False Positive Rate, FPR），可以绘制出ROC曲线。曲线下的面积（AUC）越大，表示模型的性能越好。

3. **均方误差（MSE）**：均方误差是衡量模型预测值与真实值之间差异的一种常用指标，其计算公式为：
   $$
   MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
   $$
   其中，\( y_i \) 是真实值，\( \hat{y}_i \) 是模型预测值，\( n \) 是样本数量。

4. **拟合优度（Goodness of Fit）**：拟合优度是衡量模型对数据拟合程度的一种指标，其计算公式为：
   $$
   GOF = \frac{1}{n} \sum_{i=1}^{n} \left| y_i - \hat{y}_i \right|
   $$
   其中，\( y_i \) 是真实值，\( \hat{y}_i \) 是模型预测值，\( n \) 是样本数量。

def stochastic_gradient_descent(E, P, n_iterations, learning_rate, gamma_init):
    gamma = gamma_init
    for i in range(n_iterations):
        indices = np.random.choice(len(E), size=len(E))
        E_sample = E[indices]
        P_sample = P[indices]
        gradient = -2 * np.mean(P_sample * (E_sample - mean)) * (E_sample - mean)
        gamma -= learning_rate * gradient
    return gamma

# 遗传算法优化模型参数
def genetic_algorithm(E, P, n_generations, population_size, crossover_rate, mutation_rate):
    population = [np.random.uniform(mean - std, mean + std) for _ in range(population_size)]
    for _ in range(n_generations):
        fitness = [-np.mean(P * (E - x)) for x in population]
        sorted_population = [x for _, x in sorted(zip(fitness, population), reverse=True)]
        next_population = []
        for i in range(int(population_size / 2)):
            parent1, parent2 = sorted_population[i], sorted_population[i + population_size // 2]
            child1, child2 = crossover(parent1, parent2, crossover_rate)
            next_population.extend([mutation(child1, mutation_rate), mutation(child2, mutation_rate)])
        population = next_population
    return max(population, key=lambda x: -np.mean(P * (E - x)))
