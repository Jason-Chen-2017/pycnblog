## 区块链基础

区块链是一种分布式账本技术，通过分布式网络维护一个不断增长的数据库记录，这些记录被称为“区块”，并以时间顺序相连形成“链条”。每个区块包含一系列交易记录，一旦记录被添加到区块链中，就几乎不可篡改。以下是区块链的基础组成部分及其工作原理的详细解释。

### 区块链的组成

1. **区块**：区块是区块链的基本组成单元，包含一定数量的交易记录。每个区块有一个唯一的标识符（哈希值），用于确保区块的完整性和唯一性。

2. **链**：区块链是由一系列按时间顺序排列的区块组成的链条。每个区块都包含一个指向前一个区块的哈希值，形成一个链接关系。

3. **分布式网络**：区块链通过分布式网络维护其数据库，网络中的每个节点都保存了一份完整的区块链副本。分布式网络使得区块链具有去中心化的特性，即没有单一节点可以控制或篡改整个系统。

4. **挖矿**：为了确保新区块的生成和区块链的安全，区块链采用了一种共识机制，如工作量证明（PoW）或权益证明（PoS）。在PoW机制中，节点需要通过解决复杂的数学问题（如比特币的SHA-256哈希运算）来竞争生成新区块，这个过程被称为“挖矿”。

### 工作原理

1. **交易记录**：区块链上的交易记录是区块链的核心内容。交易记录包含发送方、接收方、金额和附加信息等。每个交易记录都需要经过验证和确认，才能被添加到区块链中。

2. **验证和确认**：在区块链网络中，交易记录必须经过多个节点的验证和确认。节点通过共识机制对交易进行验证，确保交易的有效性和合法性。

3. **区块生成**：当一个区块满载交易记录时，节点开始竞争生成新区块。通过挖矿过程，一个节点将成功生成新区块并将其广播到网络中，其他节点会验证新区块的有效性。

4. **区块链扩展**：新区块生成后，会被添加到区块链的末尾，从而延长区块链的链条。每次新区块生成，区块链的总长度都会增加。

#### 工作量证明（PoW）

工作量证明（PoW）是区块链的一种共识机制，用于确保新区块的生成和区块链的安全。以下是PoW的基本原理：

1. **问题生成**：系统生成一个数学难题，需要通过计算找到满足特定条件的解。
2. **解决难题**：节点通过尝试不同的解决方案来求解难题。这个过程需要大量的计算资源。
3. **验证解**：一旦找到解，节点将解决方案广播到网络中，其他节点验证解的有效性。
4. **奖励**：验证成功的节点获得生成新区块的奖励。

Python代码示例：

```python
import hashlib
import time

def proof_of_work(last_proof, difficulty):
    nonce = 0
    while not valid_proof(last_proof, nonce, difficulty):
        nonce += 1
    return nonce

def valid_proof(last_proof, nonce, difficulty):
    hash = hashlib.sha256(f"{last_proof}{nonce}".encode()).hexdigest()
    return hash[:difficulty] == "0" * difficulty

last_proof = 100
difficulty = 4
proof = proof_of_work(last_proof, difficulty)
print(f"Proof: {proof}")
```

## 数字签名

数字签名是一种加密技术，用于验证信息的完整性和验证发送者的身份。在区块链技术中，数字签名发挥着重要作用，尤其是在数字内容版权追踪中，确保版权信息的真实性和不可篡改性。以下是数字签名的概述、工作原理和其在区块链中的应用。

### 数字签名概述

数字签名类似于传统的物理签名，但它是通过加密算法生成的，具有更强的安全性和可靠性。数字签名的主要功能包括：

1. **验证身份**：数字签名可以验证消息的发送者身份，确保消息确实来自指定的发送者。
2. **保证完整性**：数字签名可以验证消息在传输过程中未被篡改，确保消息的完整性。
3. **防止否认**：数字签名使得发送者无法否认发送了该消息，因为数字签名与发送者的私钥相关联。

### 工作原理

数字签名的工作原理可以分为以下几个步骤：

1. **生成密钥对**：数字签名使用一对密钥，即公钥和私钥。私钥是保密的，由用户自己保管；公钥是公开的，可以自由分发。

2. **创建消息摘要**：在发送消息之前，使用哈希函数生成消息摘要，即将消息转换为一个固定长度的数字摘要。

3. **签名**：发送者使用自己的私钥对消息摘要进行加密，生成数字签名。签名过程涉及复杂的数学运算，确保签名与私钥相关联。

4. **发送消息和签名**：发送者将原始消息和数字签名一起发送给接收者。

5. **验证签名**：接收者使用发送者的公钥对数字签名进行解密，并生成消息摘要。然后，接收者将接收到的消息摘要与发送者提供的消息摘要进行对比，以验证消息的完整性和发送者身份。

### 数字签名算法

数字签名算法有多种，其中最常用的包括RSA和ECDSA。以下是ECDSA算法的Python代码示例：

```python
from cryptography.hazmat.backends import default_backend
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import padding

def generate_ecdsa_key():
    private_key = ec.generate_private_key(
        ec.SECP256R1(),
        default_backend()
    )
    public_key = private_key.public_key()
    return private_key, public_key

def sign_message(private_key, message):
    signer = private_key.signer(
        padding.PSS(
            mgf=padding.MGF1(hashes.SHA256()),
            salt_length=padding.PSS.MAX_LENGTH
        ),
        hashes.SHA256()
    )
    signer.update(message)
    signature = signer.finalize()
    return signature

def verify_signature(public_key, message, signature):
    verifier = public_key.verifier(
        signature,
        padding.PSS(
            mgf=padding.MGF1(hashes.SHA256()),
            salt_length=padding.PSS.MAX_LENGTH
        ),
        hashes.SHA256()
    )
    verifier.update(message)
    try:
        verifier.finalize()
        return True
    except ValueError:
        return False

# 使用示例
private_key, public_key = generate_ecdsa_key()
message = b"Hello, World!"
signature = sign_message(private_key, message)
is_valid = verify_signature(public_key, message, signature)
print(f"Signature is valid: {is_valid}")
```

contract NFTMarketplace {
    mapping(uint256 => address) public nftOwners;
    mapping(uint256 => string) public nftInfo;

    function createNFT(uint256 tokenId, string memory info) public {
        nftOwners[tokenId] = msg.sender;
        nftInfo[tokenId] = info;
    }

        require(nftOwners[tokenId] != msg.sender, "NFT already owned");
        require(msg.value >= 0.01 ether, "Insufficient payment");
        address seller = nftOwners[tokenId];
        nftOwners[tokenId] = msg.sender;
        payable(seller).transfer(msg.value);
    }

    function getNFTInfo(uint256 tokenId) public view returns (string memory) {
        return nftInfo[tokenId];
    }
}
