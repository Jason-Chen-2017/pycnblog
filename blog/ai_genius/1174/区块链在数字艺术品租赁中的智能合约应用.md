## 区块链技术概述

### 2.1 区块链的基本概念

区块链是一种分布式数据库技术，其核心思想是通过去中心化的方式，实现数据的存储、传输和管理。与传统集中式数据库不同，区块链不存在中心化的管理者，而是通过多个节点共同维护整个数据库的状态。

区块链的基本组成单位是“区块”，每个区块包含一定数量的交易记录。区块之间通过密码学算法相互链接，形成链式结构，因此得名“区块链”。每一个区块都包含一个时间戳、一个唯一标识（哈希值）以及前一个区块的哈希值，这样形成一个不可篡改的链式结构。

### 2.2 区块链的工作原理

区块链的工作原理主要包括以下几个关键步骤：

1. **交易生成**：当用户在区块链上进行操作时，例如发送比特币，会生成一笔交易。
2. **交易验证**：交易生成后，需要多个节点进行验证，以确保交易的合法性和正确性。
3. **区块生成**：当一定数量的交易被验证通过后，会被打包成一个区块。
4. **区块链接**：新产生的区块会通过密码学算法与之前的区块链接起来，形成区块链。
5. **共识算法**：区块链网络中的所有节点通过共识算法来达成一致，确保区块链的完整性和一致性。

### 2.3 区块链的核心技术

区块链的核心技术主要包括以下几方面：

1. **哈希算法**：哈希算法是区块链技术的基石，用于生成数据块的唯一标识（哈希值）。常见的哈希算法包括SHA-256等。
2. **加密技术**：区块链采用加密技术来保护数据的安全性和隐私。常用的加密算法包括RSA、ECC等。
3. **共识算法**：共识算法是区块链网络中节点达成一致的重要机制。常见的共识算法包括工作量证明（PoW）、权益证明（PoS）等。
4. **分布式账本技术**：分布式账本技术是区块链的核心特点之一，通过去中心化的方式，实现数据的存储和管理。

### 2.4 区块链的应用场景

区块链技术具有去中心化、不可篡改、透明性等特性，使其在多个领域具有广泛的应用前景。以下是区块链的一些主要应用场景：

1. **金融领域**：区块链在金融领域的主要应用包括支付、结算、信用评估等。例如，比特币和以太坊等加密货币就是区块链在金融领域的典型应用。
2. **供应链管理**：区块链技术可以确保供应链的透明性和可追溯性，从而提高供应链的效率和信任度。
3. **医疗健康**：区块链技术可以用于医疗数据的安全存储和共享，确保患者隐私和数据安全。
4. **数字身份认证**：区块链技术可以提供去中心化的数字身份认证服务，增强用户身份验证的可靠性。
5. **数字艺术品租赁**：本文重点讨论的领域，区块链技术在数字艺术品租赁中可以提供安全的交易记录和不可篡改的版权保护。

contract DigitalArtLease {
    // 定义租赁结构体
    struct Lease {
        address artist; // 艺术家地址
        address tenant; // 租户地址
        uint256 rent; // 租金
        uint256 startTime; // 开始时间
        uint256 endTime; // 结束时间
        bool isPaid; // 是否已支付租金
    }

    // 定义租赁映射
    mapping(address => Lease) public leases;

    // 租赁艺术品
    function lease(address tenant, uint256 rent, uint256 duration) external {
        require(tenant != address(0), "Invalid tenant address");
        require(rent > 0, "Invalid rent");
        require(duration > 0, "Invalid duration");

        // 创建新的租赁记录
        leases[tenant] = Lease({
            artist: msg.sender,
            tenant: tenant,
            rent: rent,
            startTime: block.timestamp,
            endTime: block.timestamp + duration,
            isPaid: false
        });
    }

    // 支付租金
    function payRent(address tenant) external payable {
        require(tenant != address(0), "Invalid tenant address");
        require(leases[tenant].tenant != address(0), "No lease exists");
        require(!leases[tenant].isPaid, "Rent already paid");

        // 更新租赁记录状态
        leases[tenant].isPaid = true;

        // 将租金发送给艺术家
        payable(leases[tenant].artist).transfer(msg.value);
    }

    // 终止租赁
    function terminateLease(address tenant) external {
        require(tenant != address(0), "Invalid tenant address");
        require(leases[tenant].tenant != address(0), "No lease exists");

        // 更新租赁记录状态
        leases[tenant].endTime = block.timestamp;

        // 如果租期已满，将租金退还给租户
        if (block.timestamp > leases[tenant].endTime) {
            payable(tenant).transfer(leases[tenant].rent);
        }
    }

    // 查询租赁信息
    function getLease(address tenant) external view returns (Lease memory) {
        return leases[tenant];
    }
