3.1 DPO policy算法原理

DPO policy，即动态规划搜索策略，是一种在搜索过程中动态调整策略的方法。其主要思想是在搜索过程中根据当前状态和历史信息，选择最优的搜索方向。

DPO policy的基本原理可以分为以下几个步骤：

1. 初始化：首先，初始化搜索空间，包括初始状态和所有可能的动作。
2. 状态评估：对于每个状态，根据历史信息评估其价值，选择具有最高价值的动作作为当前动作。
3. 动作执行：执行选定的动作，更新当前状态。
4. 状态更新：根据执行结果，更新当前状态和历史信息。
5. 重复步骤2-4，直到找到目标状态或达到搜索深度限制。

D --> E[重复评估]

```python
import numpy as np

def dpo_policy(search_space, action_values, epsilon=0.1):
    """
    动态规划搜索策略
    :param search_space: 搜索空间
    :param action_values: 动作价值
    :param epsilon: 探索概率
    :return: 执行的动作
    """
    # 初始化当前状态
    current_state = search_space[0]

    while True:
        # 状态评估
        action_values[current_state] = np.random.choice(action_values[current_state], p=epsilon + (1 - epsilon) / len(action_values[current_state]))

        # 执行动作
        action = np.argmax(action_values[current_state])
        current_state = search_space[current_state][action]

        # 状态更新
        action_values[current_state] = np.random.choice(action_values[current_state], p=epsilon + (1 - epsilon) / len(action_values[current_state]))

        # 判断是否达到目标状态
        if is_goal_state(current_state):
            return action
```

3.2 ReST-MCTS算法原理

ReST-MCTS，即最近邻修剪树搜索算法，是一种基于蒙特卡洛树搜索（MCTS）的方法。其主要特点是通过最近邻修剪来减少搜索空间，提高搜索效率。

ReST-MCTS的基本原理可以分为以下几个步骤：

1. 初始化：首先，初始化搜索树，包括根节点和初始状态。
2. 树搜索：根据当前状态，从搜索树上选择一个子节点进行扩展。
3. 执行动作：在选择的子节点上执行动作，更新当前状态。
4. 回复：根据执行结果，从子节点回到父节点，更新树上的节点信息。
5. 重复步骤2-4，直到满足停止条件（如达到最大迭代次数或找到目标状态）。

#### 第4章 数学模型和数学公式

4.1 DPO policy数学模型

DPO policy的数学模型主要包括价值函数和策略迭代。价值函数用于评估状态的价值，策略迭代用于更新策略。

1. 价值函数（V(s)）

价值函数用于评估状态s的价值，通常表示为V(s)。V(s)的值越大，表示状态s越有利。价值函数的更新公式如下：

$$
V(s_{t+1}) = V(s_t) + \alpha [r_t - V(s_t)]
$$

其中，$s_t$表示当前状态，$s_{t+1}$表示下一个状态，$r_t$表示状态转移的奖励，$\alpha$表示学习率。

2. 策略迭代（π(s)）

策略迭代用于更新策略，选择具有最高价值的动作。策略迭代的基本公式如下：

$$
\pi(s) = \arg\max_{a} V(s)
$$

其中，$\pi(s)$表示在状态s下采取的动作，$a$表示所有可能的动作。

4.2 ReST-MCTS数学模型

ReST-MCTS的数学模型主要包括期望值、置信区间和选择策略。

1. 期望值（E）

期望值用于评估节点的价值，通常表示为E。期望值的计算公式如下：

$$
E = \frac{1}{n} \sum_{i=1}^{n} r_i
$$

其中，$n$表示节点上的样本数量，$r_i$表示第i个样本的回报。

2. 置信区间（CI）

置信区间用于评估期望值的可信度，通常表示为CI。置信区间的计算公式如下：

$$
CI = \pm z \sqrt{\frac{Var}{n}}
$$

其中，$z$表示正态分布的临界值，$Var$表示样本方差。

3. 选择策略

选择策略用于从搜索树上选择子节点。选择策略的基本公式如下：

$$
p = \frac{E}{E + \sqrt{\frac{2 \ln n}{n}}}
$$

其中，$E$表示期望值，$n$表示节点上的样本数量。
