## 第一部分：随机性基础

### 第1章：随机性的概念与历史

### 第1.1节：随机性的定义

随机性是指某个事件在多种可能性中随机出现的一种性质。在数学和计算机科学中，随机性被广泛应用于各种领域，包括概率论、统计学、机器学习和人工智能等。随机性的核心在于不可预测性和不确定性，这种特性使得我们在处理复杂系统时，需要采用概率模型来分析和预测。

### 第1.2节：随机性的历史背景

随机性的概念自古以来就受到哲学和科学家的关注。古希腊哲学家泰勒斯曾提到“万事万物皆由水构成”，这种观点隐含了随机性的思想。17世纪的概率论奠基人帕斯卡和费马，通过解决赌博问题，初步建立了概率论的基础。18世纪的拉普拉斯则提出了决定论的“拉普拉斯妖”思想，认为宇宙中的所有事件都是可以通过确定性原理预测的。然而，20世纪的量子力学和非决定论的出现，打破了这种绝对确定性，使得随机性成为物理学和数学研究的一个重要领域。

### 第1.3节：概率论的基本原理

概率论是研究随机事件的数学分支，其基本原理包括：

1. **概率的公理化定义**：概率被定义为事件发生的可能性，通常用0到1之间的实数表示。概率的加法定理、乘法定理和全概率公式是概率论的核心定理。

2. **条件概率**：在给定某一事件发生的情况下，另一事件发生的概率。条件概率公式表达了两个事件之间的关系，为后续的统计推断提供了理论基础。

3. **贝叶斯定理**：贝叶斯定理是概率论中用于更新事件概率的重要工具。通过贝叶斯定理，我们可以根据新的证据来修正对某个事件发生概率的估计。

4. **大数定律和中心极限定理**：大数定律描述了在大量重复实验中，事件发生的频率将趋近于其概率。中心极限定理则表明，大量独立同分布的随机变量的均值分布将趋近于正态分布。

## 第二部分：随机性算法

### 第2章：概率分布与随机变量

### 第2.1节：概率分布的概念

概率分布是描述随机变量取值概率的函数，它能够清晰地表达随机变量在不同取值下的概率分布情况。根据随机变量的类型，概率分布可以分为离散概率分布和连续概率分布。

1. **离散概率分布**：离散概率分布用于描述离散型随机变量，即随机变量的取值为有限个或可数无限个。常见的离散概率分布包括伯努利分布、二项分布、泊松分布和几何分布等。

2. **连续概率分布**：连续概率分布用于描述连续型随机变量，即随机变量的取值为某个区间内的实数。常见的连续概率分布包括均匀分布、正态分布、指数分布和伽马分布等。

### 第2.2节：随机变量

随机变量是概率论中的一个基本概念，它是一个从样本空间到实数集的函数。根据随机变量的取值类型，我们可以将其分为离散随机变量和连续随机变量。

1. **离散随机变量**：离散随机变量是指其取值为有限个或可数无限个的随机变量。离散随机变量的概率分布通常用概率质量函数（PMF）来描述，即P(X=x)。

2. **连续随机变量**：连续随机变量是指其取值为某个区间内的实数的随机变量。连续随机变量的概率分布通常用概率密度函数（PDF）来描述，即f(x)。

### 第2.3节：随机变量的数学期望与方差

数学期望和方差是描述随机变量分布特征的重要统计量。

1. **数学期望**：数学期望是随机变量取值的加权平均值，它反映了随机变量的集中趋势。对于离散随机变量，数学期望的定义为E(X)=ΣxP(X=x)；对于连续随机变量，数学期望的定义为E(X)=∫xf(x)dx。

2. **方差**：方差是描述随机变量取值离散程度的度量，它反映了随机变量的波动程度。对于离散随机变量，方差的定义为Var(X)=E[(X-E(X))^2]=Σ(x-E(X))^2P(X=x)；对于连续随机变量，方差的定义为Var(X)=E[(X-E(X))^2]=∫(x-E(X))^2f(x)dx。

### 第2.4节：离散与连续随机变量的期望和方差计算

为了更深入地理解离散和连续随机变量的期望和方差，我们来看一个具体的例子。

#### 离散随机变量

假设随机变量X表示投掷一枚公平的六面骰子的结果，其概率质量函数为P(X=x)=1/6，其中x为1到6的整数。我们可以计算X的数学期望和方差：

1. 数学期望：E(X)=ΣxP(X=x)=1*1/6 + 2*1/6 + 3*1/6 + 4*1/6 + 5*1/6 + 6*1/6 = 3.5
2. 方差：Var(X)=Σ(x-E(X))^2P(X=x)=(1-3.5)^2*1/6 + (2-3.5)^2*1/6 + (3-3.5)^2*1/6 + (4-3.5)^2*1/6 + (5-3.5)^2*1/6 + (6-3.5)^2*1/6 ≈ 2.917

#### 连续随机变量

假设随机变量Y表示在[0,1]区间上均匀分布的随机数，其概率密度函数为f(y)=1，其中0≤y≤1。我们可以计算Y的数学期望和方差：

1. 数学期望：E(Y)=∫yf(y)dy=∫0^1y*1dy=[y^2/2]0^1=1/2
2. 方差：Var(Y)=∫(y-E(Y))^2f(y)dy=∫0^1(y-1/2)^2*1dy=[(y-1/2)^3/6]0^1=1/12

通过这两个例子，我们可以看到离散和连续随机变量的期望和方差计算的基本方法。这些计算对于理解和分析随机变量的分布特征至关重要。

## 第3章：随机变量的数学期望与方差

### 第3.1节：数学期望的定义与性质

数学期望（Expected Value）是概率论中用于描述随机变量集中趋势的一个重要概念。数学期望的定义依赖于随机变量的类型，分别对离散随机变量和连续随机变量进行讨论。

#### 离散随机变量的数学期望

对于离散随机变量\( X \)，其取值为\( x_1, x_2, ..., x_n \)，对应的概率分别为\( P(X = x_1), P(X = x_2), ..., P(X = x_n) \)，则数学期望\( E(X) \)定义为：

\[ E(X) = \sum_{i=1}^{n} x_i \cdot P(X = x_i) \]

这个公式表示随机变量\( X \)的每个可能取值与其概率的乘积之和。

#### 连续随机变量的数学期望

对于连续随机变量\( Y \)，其概率密度函数为\( f(y) \)，则数学期望\( E(Y) \)定义为：

\[ E(Y) = \int_{-\infty}^{+\infty} y \cdot f(y) \, dy \]

这个积分表示随机变量\( Y \)的所有可能取值与其概率密度的乘积之和。

#### 数学期望的性质

1. **线性性**：对于任意两个随机变量\( X \)和\( Y \)，以及常数\( a \)和\( b \)，有：
   \[ E(aX + bY) = aE(X) + bE(Y) \]
   这表明数学期望具有线性性质。

2. **非负性**：数学期望总是非负的，即对于任意随机变量\( X \)，有\( E(X) \geq 0 \)。

3. **可加性**：如果\( X_1, X_2, ..., X_n \)是互相独立的随机变量，则：
   \[ E(\sum_{i=1}^{n} X_i) = \sum_{i=1}^{n} E(X_i) \]
   这表明数学期望对独立随机变量的和是可加的。

4. **方差的定义**：方差是数学期望的补充概念，用于描述随机变量取值的离散程度。对于随机变量\( X \)，其方差\( Var(X) \)定义为：
   \[ Var(X) = E[(X - E(X))^2] \]
   或者等价地：
   \[ Var(X) = E(X^2) - [E(X)]^2 \]

### 第3.2节：方差、标准差与变异度

方差（Variance）、标准差（Standard Deviation）和变异度（Variability）是描述随机变量取值离散程度的重要统计量。

1. **方差**：方差是数学期望的补充概念，用于描述随机变量取值的离散程度。方差的定义如前所述：
   \[ Var(X) = E[(X - E(X))^2] \]

2. **标准差**：标准差是方差的平方根，用于更直观地描述随机变量的离散程度。标准差的定义如下：
   \[ \sigma_X = \sqrt{Var(X)} \]
   标准差具有与方差相同的单位，并且能够更直观地反映数据的波动性。

3. **变异度**：变异度是方差与数学期望的比值，用于描述随机变量的离散程度与集中趋势的比例关系。变异度的定义如下：
   \[ \text{变异度} = \frac{Var(X)}{E(X)} \]
   变异度通常用来比较不同随机变量的离散程度。

### 第3.3节：离散与连续随机变量的期望和方差计算

#### 离散随机变量的期望和方差计算

1. **期望计算**：

   - **例子**：假设随机变量\( X \)表示投掷一枚公平的六面骰子的结果，其概率质量函数为\( P(X = x) = \frac{1}{6} \)，其中\( x \)为1到6的整数。则数学期望\( E(X) \)计算如下：
     \[ E(X) = \sum_{x=1}^{6} x \cdot \frac{1}{6} = \frac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = \frac{21}{6} = 3.5 \]

   - **一般情况**：对于任意离散随机变量\( X \)和其概率质量函数\( p(x) \)，数学期望计算为：
     \[ E(X) = \sum_{x} x \cdot p(x) \]

2. **方差计算**：

   - **例子**：继续使用六面骰子为例，计算其方差\( Var(X) \)如下：
     \[ Var(X) = E[(X - E(X))^2] = \sum_{x=1}^{6} (x - 3.5)^2 \cdot \frac{1}{6} \]
     \[ Var(X) = \frac{1}{6}[(1 - 3.5)^2 + (2 - 3.5)^2 + (3 - 3.5)^2 + (4 - 3.5)^2 + (5 - 3.5)^2 + (6 - 3.5)^2] \]
     \[ Var(X) = \frac{1}{6}[2.25 + 2.25 + 0.25 + 0.25 + 2.25 + 6.25] \]
     \[ Var(X) = \frac{14.5}{6} \approx 2.417 \]

   - **一般情况**：对于任意离散随机变量\( X \)和其概率质量函数\( p(x) \)，方差计算为：
     \[ Var(X) = \sum_{x} (x - E(X))^2 \cdot p(x) \]

#### 连续随机变量的期望和方差计算

1. **期望计算**：

   - **例子**：假设随机变量\( Y \)在区间\[0, 1\]上均匀分布，其概率密度函数为\( f(y) = 1 \)，则数学期望\( E(Y) \)计算如下：
     \[ E(Y) = \int_{0}^{1} y \cdot 1 \, dy = \left. \frac{y^2}{2} \right|_0^1 = \frac{1}{2} \]

   - **一般情况**：对于任意连续随机变量\( Y \)和其概率密度函数\( f(y) \)，数学期望计算为：
     \[ E(Y) = \int_{-\infty}^{+\infty} y \cdot f(y) \, dy \]

2. **方差计算**：

   - **例子**：继续使用均匀分布的随机变量\( Y \)，计算其方差\( Var(Y) \)如下：
     \[ Var(Y) = E[(Y - E(Y))^2] = E\left[\left(Y - \frac{1}{2}\right)^2\right] \]
     \[ Var(Y) = \int_{0}^{1} \left(y - \frac{1}{2}\right)^2 \cdot 1 \, dy = \left. \frac{(y - \frac{1}{2})^3}{3} \right|_0^1 = \frac{1}{12} \]

   - **一般情况**：对于任意连续随机变量\( Y \)和其概率密度函数\( f(y) \)，方差计算为：
     \[ Var(Y) = E[Y^2] - [E(Y)]^2 \]
     \[ E[Y^2] = \int_{-\infty}^{+\infty} y^2 \cdot f(y) \, dy \]

通过本章的学习，我们了解了数学期望和方差的基本定义及其计算方法。这些统计量在概率论和统计学中扮演着重要的角色，帮助我们分析和理解随机变量的分布特征。在接下来的章节中，我们将继续探讨随机过程的数学模型，进一步深化对随机性的理解。

### 第3.4节：随机变量的数学期望与方差的性质

随机变量的数学期望与方差是概率论中用于描述随机变量特征的重要统计量。下面我们讨论这些统计量的性质，以及它们在实际应用中的重要性。

#### 数学期望的性质

1. **线性性**：数学期望具有线性性，即对于任意两个随机变量\( X \)和\( Y \)，以及常数\( a \)和\( b \)，有：
   \[ E(aX + bY) = aE(X) + bE(Y) \]
   这意味着数学期望对随机变量的线性组合是线性的。

2. **非负性**：数学期望总是非负的，即对于任意随机变量\( X \)，有：
   \[ E(X) \geq 0 \]
   这表明随机变量的期望值不可能为负。

3. **可加性**：对于互相独立的随机变量\( X_1, X_2, ..., X_n \)，有：
   \[ E(\sum_{i=1}^{n} X_i) = \sum_{i=1}^{n} E(X_i) \]
   这意味着数学期望对于独立随机变量的和是可加的。

4. **有限性**：如果随机变量\( X \)是有限的，那么它的数学期望也是有限的。

#### 方差和标准差的性质

1. **方差与数学期望的关系**：方差是数学期望的一个补充概念，用于描述随机变量取值的离散程度。对于随机变量\( X \)，其方差\( Var(X) \)定义为：
   \[ Var(X) = E[(X - E(X))^2] \]
   或者等价地：
   \[ Var(X) = E(X^2) - [E(X)]^2 \]
   这表明方差依赖于数学期望。

2. **标准差**：标准差是方差的平方根，用于更直观地描述随机变量的离散程度。对于随机变量\( X \)，其标准差\( \sigma_X \)定义为：
   \[ \sigma_X = \sqrt{Var(X)} \]
   标准差具有与方差相同的单位，并且能够更直观地反映数据的波动性。

3. **变异度**：变异度是方差与数学期望的比值，用于描述随机变量的离散程度与集中趋势的比例关系。变异度的定义如下：
   \[ \text{变异度} = \frac{Var(X)}{E(X)} \]
   变异度通常用来比较不同随机变量的离散程度。

#### 性质在实际应用中的重要性

1. **风险管理**：在金融和投资领域，数学期望和方差被广泛应用于风险评估和投资组合管理。投资者使用期望收益和风险（方差或标准差）来评估不同投资机会的优劣。

2. **质量检验**：在制造业中，方差和标准差用于监控产品的质量。通过分析产品的质量指标（如尺寸、重量等），企业可以识别出潜在的问题，并采取相应的措施来提高产品质量。

## 第4章：马尔可夫链

### 第4.1节：马尔可夫链的定义

马尔可夫链（Markov Chain）是概率论和统计学中用于描述系统状态转移的一种数学模型。马尔可夫链的基本思想是，系统的未来状态仅取决于当前状态，而与过去状态无关。这一特性使得马尔可夫链在许多领域，如物理学、经济学、生物学和计算机科学中，都有广泛的应用。

#### 定义

一个马尔可夫链由以下元素组成：

1. **状态集合 \( S \)**：系统可能处于的所有状态的集合。
2. **转移概率矩阵 \( P \)**：一个 \( n \times n \) 的矩阵，其中 \( P_{ij} \) 表示系统从状态 \( i \) 转移到状态 \( j \) 的概率。

给定一个马尔可夫链，其状态转移可以表示为：

\[ P_{ij} = P(X_{n+1} = j | X_n = i) \]

其中，\( X_n \) 表示马尔可夫链在时间 \( n \) 的状态。

#### 齐次马尔可夫链

齐次马尔可夫链是指转移概率矩阵 \( P \) 不随时间变化，即对于任意 \( n \)，转移概率矩阵相同。齐次马尔可夫链在理论和实际应用中更为常见。

### 第4.2节：马尔可夫链的稳定性

马尔可夫链的稳定性是指系统在长时间运行后，状态分布趋于稳定，即状态概率分布不再变化。稳定性分析是马尔可夫链研究的一个重要方面。

#### 状态分类

在马尔可夫链中，状态可以根据其稳定性进行分类：

1. **暂态状态**（Transient States）：暂态状态是指在长时间运行后，状态概率趋近于0的状态。暂态状态通常不会对系统的长期行为产生显著影响。
2. **稳定状态**（Ergodic States）：稳定状态是指在长时间运行后，状态概率趋于某一固定分布的状态。稳定状态对系统的长期行为有重要影响。
3. **吸收状态**（Absorbing States）：吸收状态是指一旦进入该状态，系统将永远处于该状态，不会再次转移出去。

#### 马尔可夫链的稳定性条件

为了使马尔可夫链具有稳定性，需要满足以下条件：

1. **周期性**：马尔可夫链必须是周期的，即存在一个最小的正整数 \( k \)，使得对于任意状态 \( i \)，有 \( P^k_{ii} > 0 \)。
2. **遍历性**：马尔可夫链必须具有遍历性，即对于任意状态 \( i \) 和 \( j \)，存在一个足够大的 \( k \)，使得 \( P^k_{ij} > 0 \)。

满足这些条件的马尔可夫链被称为“可列出的”、“周期的”和“遍历的”，其稳定状态概率可以通过以下方程组求解：

\[ \pi P = \pi \]

其中，\( \pi \) 是稳定状态概率向量，\( P \) 是转移概率矩阵。

### 第4.3节：马尔可夫链的转移概率矩阵

转移概率矩阵是马尔可夫链的核心组成部分，它决定了系统状态之间的转移关系。一个 \( n \times n \) 的转移概率矩阵 \( P \) 具有以下性质：

1. **概率分布**：对于任意状态 \( i \)，有 \( \sum_{j=1}^{n} P_{ij} = 1 \)。这意味着从状态 \( i \) 转移到任意状态的概率之和为1。
2. **对称性**：转移概率矩阵通常是可逆的，即 \( P^{-1} \) 存在。这使得我们可以通过矩阵的逆来求解马尔可夫链的长期行为。

#### 转移概率矩阵的例子

假设一个马尔可夫链有3个状态 \( S = \{A, B, C\} \)，其转移概率矩阵如下：

\[ P = \begin{bmatrix}
0.4 & 0.3 & 0.3 \\
0.2 & 0.5 & 0.3 \\
0.1 & 0.2 & 0.7
\end{bmatrix} \]

这个矩阵表示从状态 \( A \) 转移到状态 \( B \) 的概率为0.3，从状态 \( B \) 转移到状态 \( A \) 的概率为0.5，等等。

### 第4.4节：马尔可夫链的稳定性分析

稳定性分析是理解马尔可夫链长期行为的重要手段。通过分析转移概率矩阵的幂次，我们可以得到马尔可夫链在长时间运行后的状态分布。

#### 状态分布的收敛性

对于一个齐次马尔可夫链，其状态分布随着时间趋于稳定。具体来说，对于任意状态 \( i \) 和 \( j \)，当 \( n \) 趋于无穷大时，有以下极限：

\[ \lim_{n \to \infty} P^n_{ij} = \pi_j \]

其中，\( \pi_j \) 是稳定状态概率向量中的第 \( j \) 个元素。

#### 稳定状态概率向量的求解

为了求解稳定状态概率向量 \( \pi \)，我们需要解决以下线性方程组：

\[ \pi P = \pi \]

这个方程组可以表示为矩阵形式：

\[ (\mathbf{I} - P)\pi = \mathbf{0} \]

其中，\( \mathbf{I} \) 是单位矩阵，\( P \) 是转移概率矩阵。通过求解这个方程组，我们可以得到稳定状态概率向量 \( \pi \)。

### 第5.1节：蒙特卡洛方法的基本原理

蒙特卡洛方法（Monte Carlo Method）是一种基于随机抽样和统计模拟的计算方法，其基本原理是通过模拟大量的随机试验来近似求解复杂的数学问题。蒙特卡洛方法得名于著名的赌城蒙特卡洛，因为这种方法在概率模型和赌博问题中有着广泛的应用。

#### 基本步骤

蒙特卡洛方法的基本步骤可以概括为：

1. **初始化随机数生成器**：选择合适的随机数生成器，确保随机数的生成具有均匀性和随机性。
2. **进行随机抽样**：根据问题的需求，从适当的概率分布中抽取随机样本。这些样本代表了问题的潜在解决方案。
3. **进行统计计算**：对抽取的随机样本进行统计分析，如计算均值、方差、概率分布等。
4. **迭代和收敛**：重复上述步骤，随着样本数量的增加，统计结果的稳定性会提高，最终得到问题的近似解。

#### 应用领域

蒙特卡洛方法广泛应用于以下领域：

1. **数值积分**：通过随机抽样计算复杂函数的定积分。
2. **概率估计**：用于估计概率分布、置信区间、假设检验等。
3. **优化问题**：在优化问题中，蒙特卡洛方法可以用于模拟搜索过程，找到最优解或近似最优解。

5. **金融工程**：在金融领域中，蒙特卡洛方法用于模拟资产价格、风险评估和期权定价等。

## 第6章：贝叶斯网络

### 第6.1节：贝叶斯网络的基本概念

贝叶斯网络（Bayesian Network），又称概率图模型或信念网络，是一种表示变量之间概率关系的图形化模型。它将变量及其条件依赖关系表示为有向无环图（DAG），其中每个节点代表一个随机变量，而边表示变量之间的条件依赖关系。贝叶斯网络在概率推理、机器学习和人工智能等领域具有广泛的应用。

#### 定义

贝叶斯网络由三个核心元素组成：

1. **节点**：每个节点代表一个随机变量，通常用字母表示。
2. **边**：边表示变量之间的条件依赖关系，从父节点指向子节点，表示子节点依赖于父节点。
3. **条件概率表**：每个节点对应一个条件概率表（CPT），描述该节点在给定其父节点状态下的概率分布。

#### 结构特性

贝叶斯网络具有以下特性：

1. **有向性**：贝叶斯网络中的边具有方向，表示变量之间的因果关系。
2. **无环性**：贝叶斯网络是无环的，即不存在循环依赖关系，保证了模型的简洁性和可解析性。
3. **条件独立性**：贝叶斯网络中的变量满足条件独立性，即如果某个变量已知，则其他变量的独立性不会受到影响。

### 第6.2节：贝叶斯网络的推理算法

贝叶斯网络的核心在于其推理算法，通过这些算法，我们可以计算网络中变量的概率分布。以下是贝叶斯网络推理的几种主要算法：

#### 条件概率表（CPT）计算

条件概率表（CPT）是贝叶斯网络的重要组成部分，用于表示每个节点在给定其父节点状态下的概率分布。CPT的计算基于贝叶斯定理：

\[ P(X_i | X_{pa_1}, X_{pa_2}, ..., X_{pa_n}) = \frac{P(X_{pa_1}, X_{pa_2}, ..., X_{pa_n} | X_i) \cdot P(X_i)}{P(X_{pa_1}, X_{pa_2}, ..., X_{pa_n})} \]

其中，\( X_i \) 是当前节点，\( X_{pa_1}, X_{pa_2}, ..., X_{pa_n} \) 是其父节点。

#### 割集算法

割集算法（Cutset Algorithm）是一种用于计算贝叶斯网络中变量条件概率分布的算法。割集是指一组边，将网络分割成两个部分。割集算法的基本思想是，通过遍历所有可能的割集，计算每个割集的概率，然后根据全概率公式计算变量的条件概率分布。

#### 熵和互信息

在贝叶斯网络中，熵（Entropy）和互信息（Mutual Information）是描述变量之间依赖关系的重要指标。

1. **熵**：熵是衡量随机变量不确定性的度量，定义为一个随机变量的信息量。对于离散随机变量，熵的计算公式为：
   \[ H(X) = -\sum_{x} P(X = x) \cdot \log_2 P(X = x) \]

2. **互信息**：互信息是衡量两个随机变量之间依赖程度的重要指标，定义为一个随机变量通过另一个随机变量获得的信息量。对于两个随机变量 \( X \) 和 \( Y \)，互信息的计算公式为：
   \[ I(X; Y) = H(X) - H(X | Y) \]

贝叶斯网络在多个领域都有广泛应用，以下是几个典型的应用领域：

1. **医疗诊断**：贝叶斯网络可以用于构建疾病诊断模型，通过患者的症状和检查结果，预测患者可能患有的疾病。

3. **金融风险管理**：贝叶斯网络可以用于金融风险分析，通过分析各种金融变量的依赖关系，预测金融市场的风险。
4. **自然语言处理**：贝叶斯网络可以用于文本分类和信息检索，通过分析文本中的词频和条件依赖关系，提高分类和检索的准确性。

import pandas as pd
from typing import List, Dict

class BayesianNetwork:
    def __init__(self, cpt: Dict[str, pd.DataFrame]):
        self.cpt = cpt

    def forward_inference(self, evidence: Dict[str, int]) -> Dict[str, float]:
        """
        使用前向推理算法计算给定证据下的变量条件概率分布。
        :param evidence: 给定的证据，键为变量名，值为证据的值
        :return: 条件概率分布，键为变量名，值为概率
        """
        variables = list(self.cpt.keys())
        probability_distribution = {variable: 1.0 for variable in variables}

        for variable in variables:
            parent_variables = [parent for parent, children in self.cpt[variable].columns.tolist()[1:] for parent in children]
            parent_values = [evidence[parent] for parent in parent_variables]

            if len(parent_variables) == 0:
                probability_distribution[variable] = self.cpt[variable].iloc[0, 0]
            else:
                probability_distribution[variable] = self.cpt[variable].loc[parent_values, 0]

        return probability_distribution

### 附录A：常用数学公式与符号

在本文中，我们使用了多种数学公式和符号来描述随机性的数学模型和相关算法。以下是一些常用数学公式与符号的简要介绍：

1. **概率质量函数（PMF）和概率密度函数（PDF）**：

   对于离散随机变量，概率质量函数（PMF）定义为：

   \[ P(X = x) \]

   对于连续随机变量，概率密度函数（PDF）定义为：

   \[ f(x) \]

2. **数学期望（Expected Value）**：

   对于离散随机变量，数学期望定义为：

   \[ E(X) = \sum_{x} x \cdot P(X = x) \]

   对于连续随机变量，数学期望定义为：

   \[ E(Y) = \int_{-\infty}^{+\infty} y \cdot f(y) \, dy \]

3. **方差（Variance）和标准差（Standard Deviation）**：

   对于离散随机变量，方差定义为：

   \[ Var(X) = E[(X - E(X))^2] \]

   对于连续随机变量，方差定义为：

   \[ Var(Y) = E(Y^2) - [E(Y)]^2 \]

   标准差是方差的平方根，定义为：

   \[ \sigma_Y = \sqrt{Var(Y)} \]

4. **贝叶斯定理（Bayes' Theorem）**：

   贝叶斯定理用于计算条件概率，定义为：

   \[ P(A | B) = \frac{P(B | A) \cdot P(A)}{P(B)} \]

5. **马尔可夫链（Markov Chain）**：

   转移概率矩阵 \( P \) 定义为：

   \[ P_{ij} = P(X_{n+1} = j | X_n = i) \]

   稳定状态概率向量 \( \pi \) 满足方程：

   \[ (\mathbf{I} - P)\pi = \mathbf{0} \]

6. **蒙特卡洛方法（Monte Carlo Method）**：

   蒙特卡洛方法用于计算积分，定义为：

   \[ \int_{a}^{b} f(x) \, dx \approx \frac{1}{n} \sum_{i=1}^{n} f(x_i) \]

   其中，\( x_i \) 是随机抽样得到的样本点。

7. **贝叶斯网络（Bayesian Network）**：

   条件概率表（CPT）定义为：

   \[ P(X_i | X_{pa_1}, X_{pa_2}, ..., X_{pa_n}) = \frac{P(X_{pa_1}, X_{pa_2}, ..., X_{pa_n} | X_i) \cdot P(X_i)}{P(X_{pa_1}, X_{pa_2}, ..., X_{pa_n})} \]

   互信息定义为：

   \[ I(X; Y) = H(X) - H(X | Y) \]

   其中，\( H(X) \) 是熵，\( H(X | Y) \) 是条件熵。

通过理解这些数学公式和符号，读者可以更深入地掌握随机性的数学模型和相关算法，并在实际应用中有效地使用它们。
