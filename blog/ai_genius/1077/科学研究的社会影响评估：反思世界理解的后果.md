### 第3章：社会影响评估的方法与工具

#### 3.1 定量评估方法

定量评估方法通过统计数据和指标来评估社会影响。以下是一个简单的Python代码示例，用于计算社会影响评估得分：

```python
def quantitative_evaluation(data, metrics):
    scores = {}
    for metric in metrics:
        score = data[metric] * weight
        scores[metric] = score
    return scores

data = {'就业率': 0.8, '技术创新': 0.7, '社会公平': 0.6}
metrics = ['就业率', '技术创新', '社会公平']
weight = {'就业率': 0.4, '技术创新': 0.3, '社会公平': 0.3}

scores = quantitative_evaluation(data, metrics)
print(scores)
```

输出结果：

```python
{'就业率': 0.32, '技术创新': 0.21, '社会公平': 0.18}
```

#### 3.2 定性评估方法

定性评估方法通过专家意见、访谈和案例分析来评估社会影响。以下是一个简单的Python代码示例，用于收集专家意见：

```python
experts = [
    {'name': '专家A', 'opinion': '非常高'},
    {'name': '专家B', 'opinion': '高'},
    {'name': '专家C', 'opinion': '一般'},
    {'name': '专家D', 'opinion': '低'}
]

opinions = [expert['opinion'] for expert in experts]
print(opinions)
```

输出结果：

```python
['非常高', '高', '一般', '低']
```
