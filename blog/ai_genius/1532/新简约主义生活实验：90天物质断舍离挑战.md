## 第1.1章: 简约主义的定义与起源

简约主义（Minimalism）作为一种生活方式和哲学思想，起源于20世纪中叶的美国，后来逐渐传播到世界各地。其核心理念是减少物质的占有，追求简单、清晰和有意义的生活方式。

### **定义与起源**

简约主义的定义可以归纳为：通过减少物质和非物质的负担，追求精神上的自由和内心平静。这一理念最早可以追溯到20世纪60年代，当时美国社会正处于消费文化的狂潮之中。人们通过不断购买和占有物质来提升自己的社会地位和满足心理需求。

然而，随着消费主义的泛滥，许多人开始感到压力和疲惫，精神状态逐渐恶化。于是，一些思想家和社会活动家开始呼吁回归简单、有意义的生活方式，这一思潮逐渐演变成了简约主义。

### **核心思想**

简约主义的核心思想包括：

1. **极简主义：** 强调减少物质占有，以减少生活中的压力和焦虑。
2. **意义至上：** 关注生活中真正重要的事物，如人际关系、个人成长和内心满足。
3. **可持续发展：** 倡导环保、节能和减少浪费的生活方式。

### **历史发展**

简约主义在20世纪70年代得到进一步发展，特别是在美国和日本。在美国，作家和设计师开始提倡通过减少物质占有来提升生活质量。在日本，简约主义被称为“极简主义”（Ma vie），逐渐成为一种生活方式和文化现象。

随着时间的推移，简约主义逐渐超越了物质层面的追求，成为一种更深层次的哲学和生活方式。人们开始关注精神层面的满足，强调内心平静和自由。

### **影响**

简约主义对现代社会产生了深远的影响。首先，它改变了人们的消费观念，促使人们重新审视自己的需求和生活方式。其次，简约主义倡导的环保和可持续发展理念，对环境保护和可持续发展产生了积极的影响。最后，简约主义的生活方式也为人们提供了更多的自由和选择，使人们能够更好地追求个人成长和内心满足。

class Item:
    def __init__(self, name, category, status):
        self.name = name
        self.category = category
        self.status = status

    def display_item(self):
        print(f"名称：{self.name}, 类别：{self.category}, 状态：{self.status}")

class Inventory:
    def __init__(self):
        self.items = []

    def add_item(self, item):
        self.items.append(item)

    def remove_item(self, name):
        for item in self.items:
            if item.name == name:
                self.items.remove(item)
                print(f"已成功移除物品：{name}")
                break
        else:
            print(f"物品：{name} 不存在。")

    def display_items(self):
        for item in self.items:
            item.display_item()

    def categorize_items(self, category):
        categorized_items = [item for item in self.items if item.category == category]
        for item in categorized_items:
            item.display_item()

def main():
    inventory = Inventory()

    # 添加物品
    inventory.add_item(Item("笔记本电脑", "电子产品", "使用中"))
    inventory.add_item(Item("沙发", "家具", "使用中"))
    inventory.add_item(Item("手机", "电子产品", "闲置"))

    # 显示所有物品
    print("当前物品清单：")
    inventory.display_items()

    # 分类显示物品
    print("\n电子品类物品：")
    inventory.categorize_items("电子产品")

    # 移除物品
    inventory.remove_item("手机")

    # 显示更新后的物品清单
    print("\n更新后的物品清单：")
    inventory.display_items()

if __name__ == "__main__":
    main()
