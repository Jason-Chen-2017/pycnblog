#### 2.1 排序与搜索

##### 2.1.1 排序算法

排序算法是算法面试中的常见题型，主要用于对数组、列表等数据进行有序排列。以下是一些基本的排序算法：

**冒泡排序（Bubble Sort）**

冒泡排序是一种简单的排序算法，它重复地遍历要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来。遍历数列的工作是重复地进行，直到没有再需要交换的元素为止。

**伪代码：**

```pseudo
for i from 0 to n-1
    for j from 0 to n-i-1
        if arr[j] > arr[j+1]
            swap(arr[j], arr[j+1])
```

**时间复杂度：** O(n^2)

**空间复杂度：** O(1)

**稳定性：** 稳定

**适用场景：** 数量较小的数据集

**优缺点：** 简单易懂，但效率较低，适用于小规模数据。

**改进：** 常用于与其他排序算法结合，如冒泡排序与其他排序算法结合，可以减少不必要的交换操作。

**适用场景：** 可以作为其他更高效算法的辅助算法，如快速排序的递归结束条件。

**优缺点：** 虽然效率较低，但稳定且易于实现，适用于要求稳定的排序场景。

**选择排序（Selection Sort）**

选择排序是一种简单的选择排序算法，它的工作原理是每次从待排序的数据元素中选出最小（或最大）的一个元素，存放在序列的起始位置，然后，再从剩余未排序元素中继续选择最小（或最大）的一个元素，然后放到已排序序列的末尾。

**伪代码：**

```pseudo
for i from 0 to n-1
    min_index = i
    for j from i+1 to n
        if arr[j] < arr[min_index]
            min_index = j
    swap(arr[i], arr[min_index])
```

**时间复杂度：** O(n^2)

**空间复杂度：** O(1)

**稳定性：** 不稳定

**适用场景：** 数量较小的数据集

**优缺点：** 简单易懂，但效率较低，适用于小规模数据。

**插入排序（Insertion Sort）**

插入排序是一种简单直观的排序算法，它的工作原理是通过构建有序序列，对于未排序数据，在已排序序列中从后向前扫描，找到相应位置并插入。

**伪代码：**

```pseudo
for i from 1 to n
    key = arr[i]
    j = i - 1
    while j >= 0 and arr[j] > key
        arr[j+1] = arr[j]
        j = j - 1
    arr[j+1] = key
```

**时间复杂度：** O(n^2)

**空间复杂度：** O(1)

**稳定性：** 稳定

**适用场景：** 数量较小的数据集或部分已经排序的数据集

**优缺点：** 简单易懂，适合小规模数据，效率较高。

**快速排序（Quick Sort）**

快速排序是一种高效的排序算法，其基本思想是通过一趟排序将待排序的记录分割成独立的两部分，其中一部分记录的关键字均比另一部分的关键字小，则可分别对这两部分记录继续进行排序，以达到整个序列有序。

**伪代码：**

```pseudo
def quick_sort(arr, low, high)
    if low < high
        pi = partition(arr, low, high)
        quick_sort(arr, low, pi - 1)
        quick_sort(arr, pi + 1, high)

def partition(arr, low, high)
    pivot = arr[high]
    i = low - 1
    for j from low to high-1
        if arr[j] < pivot
            i = i + 1
            swap(arr[i], arr[j])
    swap(arr[i+1], arr[high])
    return i + 1
```

**时间复杂度：** 平均 O(n log n)，最坏 O(n^2)

**空间复杂度：** O(log n)

**稳定性：** 不稳定

**适用场景：** 大规模数据集

**优缺点：** 效率高，但最坏情况下效率较低。

**改进：** 常用于改进其他排序算法，如三数取中法、随机化选择枢轴等，提高排序效率。

**适用场景：** 广泛应用于排序场景，尤其是大数据集。

**优缺点：** 高效但不稳定，适用于大规模数据集。

##### 2.1.2 搜索算法

搜索算法是用于在数据结构中查找特定元素的方法。常见的搜索算法包括线性搜索和二分搜索。

**线性搜索（Linear Search）**

线性搜索是一种最简单的搜索算法，它从数组的第一个元素开始，依次向后查找，直到找到目标元素或到达数组的末尾。

**伪代码：**

```pseudo
function linear_search(arr, target)
    for i from 0 to n
        if arr[i] == target
            return i
    return -1
```

**时间复杂度：** O(n)

**空间复杂度：** O(1)

**稳定性：** 稳定

**适用场景：** 数组无序或数据量较小

**优缺点：** 简单易懂，但效率较低。

**二分搜索（Binary Search）**

二分搜索是在有序数组中查找特定元素的算法。它的工作原理是将数组分成两半，根据目标值与中间值的比较结果决定下一次搜索的范围。

**伪代码：**

```pseudo
function binary_search(arr, target)
    low = 0
    high = n - 1
    while low <= high
        mid = (low + high) / 2
        if arr[mid] == target
            return mid
        elif arr[mid] < target
            low = mid + 1
        else
            high = mid - 1
    return -1
```

**时间复杂度：** O(log n)

**空间复杂度：** O(1)

**稳定性：** 不稳定

**适用场景：** 有序数组

**优缺点：** 效率极高，但需要数组已排序。

**改进：** 常用于实现其他更高效的搜索算法，如跳跃搜索等。

**适用场景：** 大数据集和已排序的数据集。

**优缺点：** 高效稳定，但需要有序数据集。

#### 2.2 图算法

图算法在数据结构中有着广泛的应用，用于解决网络、路径搜索、最优化等问题。以下介绍几种常见的图算法：

##### 2.2.1 图的基本概念

**图（Graph）**：由节点（Vertex）和边（Edge）组成的集合。

**有向图（Directed Graph）**：边的方向性有意义的图。

**无向图（Undirected Graph）**：边的方向性无意义的图。

**加权图（Weighted Graph）**：边有权重（或代价）的图。

**非加权图（Unweighted Graph）**：边无权重（或代价）的图。

##### 2.2.2 深度优先搜索（DFS）

深度优先搜索（DFS）是一种用于遍历或搜索图的算法。其基本思想是从一个起始节点开始，尽可能深地搜索图的分支。

**伪代码：**

```pseudo
function dfs(graph, start)
    visited = set()
    def visit(vertex)
        print(vertex)
        visited.add(vertex)
        for neighbor in graph[vertex]
            if neighbor not in visited
                visit(neighbor)
    visit(start)
```

**时间复杂度：** O(V+E)，其中V是节点数，E是边数。

**空间复杂度：** O(V)，用于存储递归栈。

**稳定性：** 不稳定

**适用场景：** 需要遍历图或查找图的连通性。

**优缺点：** 简单易懂，但效率较低。

**改进：** 常用于实现更高效的图遍历算法，如广度优先搜索（BFS）。

**适用场景：** 需要深度优先搜索的场景，如路径搜索、连通性检测。

**优缺点：** 高效稳定，但递归深度可能较深，适用于节点较少的图。

##### 2.2.3 广度优先搜索（BFS）

广度优先搜索（BFS）是一种用于遍历或搜索图的算法。其基本思想是从一个起始节点开始，先访问所有相邻节点，然后再访问下一层级的节点。

**伪代码：**

```pseudo
function bfs(graph, start)
    visited = set()
    queue = deque()
    queue.append(start)
    while queue
        vertex = queue.popleft()
        print(vertex)
        visited.add(vertex)
        for neighbor in graph[vertex]
            if neighbor not in visited
                queue.append(neighbor)
```

**时间复杂度：** O(V+E)，其中V是节点数，E是边数。

**空间复杂度：** O(V)，用于存储队列。

**稳定性：** 不稳定

**适用场景：** 需要遍历图或查找最短路径。

**优缺点：** 效率较高，但空间复杂度较高。

**改进：** 常用于实现更高效的图遍历算法，如双向广度优先搜索（Bidirectional BFS）。

**适用场景：** 需要广度优先搜索的场景，如最短路径搜索、连通性检测。

**优缺点：** 高效稳定，但空间复杂度较高。

##### 2.2.4 最短路径算法

最短路径算法用于找到图中两点之间的最短路径。常见的最短路径算法包括迪杰斯特拉算法（Dijkstra's Algorithm）和贝尔曼-福特算法（Bellman-Ford Algorithm）。

**迪杰斯特拉算法（Dijkstra's Algorithm）**

迪杰斯特拉算法是一种基于贪心策略的单源最短路径算法，用于找到图中从单源点到其他所有点的最短路径。

**伪代码：**

```pseudo
function dijkstra(graph, start)
    distances = {vertex: infinity for vertex in graph}
    distances[start] = 0
    priority_queue = PriorityQueue()
    priority_queue.push(start, 0)
    while not priority_queue.isEmpty()
        current = priority_queue.pop()
        for neighbor in graph[current]
            distance = distances[current] + graph[current][neighbor]
            if distance < distances[neighbor]
                distances[neighbor] = distance
                priority_queue.push(neighbor, distance)
    return distances
```

**时间复杂度：** O(V^2)，其中V是节点数。

**空间复杂度：** O(V)，用于存储距离表和优先队列。

**稳定性：** 不稳定

**适用场景：** 非负权图

**优缺点：** 效率高，但需要图已排序。

**贝尔曼-福特算法（Bellman-Ford Algorithm）**

贝尔曼-福特算法是一种基于松弛操作的单源最短路径算法，用于找到图中从单源点到其他所有点的最短路径。

**伪代码：**

```pseudo
function bellman_ford(graph, start)
    distances = {vertex: infinity for vertex in graph}
    distances[start] = 0
    for _ in range(n - 1)
        for edge in graph
            if distances[edge[0]] + edge[2] < distances[edge[1]]
                distances[edge[1]] = distances[edge[0]] + edge[2]
    for edge in graph
        if distances[edge[0]] + edge[2] < distances[edge[1]]
            return "Graph contains a negative weight cycle"
    return distances
```

**时间复杂度：** O(V*E)，其中V是节点数，E是边数。

**空间复杂度：** O(V)，用于存储距离表。

**稳定性：** 不稳定

**适用场景：** 有负权边的图

**优缺点：** 可以处理负权边，但效率较低。

**改进：** 常用于实现更高效的图遍历算法，如动态规划。

**适用场景：** 需要处理负权边的场景。

**优缺点：** 高效稳定，但需要图已排序。

##### 2.2.5 最小生成树算法

最小生成树算法用于找到图中的最小生成树，即包含图中所有节点的最小树。常见的最小生成树算法包括克鲁斯卡尔算法（Kruskal's Algorithm）和普里姆算法（Prim's Algorithm）。

**克鲁斯卡尔算法（Kruskal's Algorithm）**

克鲁斯卡尔算法是一种基于贪心策略的最小生成树算法，通过按权重顺序添加边，并确保不会形成环。

**伪代码：**

```pseudo
function kruskal(graph)
    parent = {vertex: vertex for vertex in graph}
    rank = {vertex: 0 for vertex in graph}
    edges = sorted(graph.keys(), key=lambda edge: edge[2])
    mst = []
    for edge in edges
        if find(parent, edge[0]) != find(parent, edge[1])
            union(parent, rank, edge[0], edge[1])
            mst.append(edge)
    return mst

function find(parent, x)
    if parent[x] != x
        parent[x] = find(parent, parent[x])
    return parent[x]

function union(parent, rank, x, y)
    rootX = find(parent, x)
    rootY = find(parent, y)
    if rank[rootX] > rank[rootY]
        parent[rootY] = rootX
    elif rank[rootX] < rank[rootY]
        parent[rootX] = rootY
    else
        parent[rootY] = rootX
        rank[rootX] += 1
```

**时间复杂度：** O(E log V)，其中E是边数，V是节点数。

**空间复杂度：** O(V)，用于存储节点和边。

**稳定性：** 稳定

**适用场景：** 大规模图

**优缺点：** 高效稳定，但需要图已排序。

**普里姆算法（Prim's Algorithm）**

普里姆算法是一种基于贪心策略的最小生成树算法，通过从某个节点开始，逐步添加最小权重的边，直到生成最小生成树。

**伪代码：**

```pseudo
function prim(graph, start)
    mst = []
    visited = {vertex: False for vertex in graph}
    while len(mst) < V
        min_edge = None
        for edge in graph
            if edge[0] in visited or edge[1] in visited
                continue
            if min_edge is None or edge[2] < min_edge[2]
                min_edge = edge
        mst.append(min_edge)
        visited[edge[0]] = True
        visited[edge[1]] = True
    return mst
```

**时间复杂度：** O(V^2)，其中V是节点数。

**空间复杂度：** O(V)，用于存储节点和边。

**稳定性：** 不稳定

**适用场景：** 中等规模图

**优缺点：** 简单易懂，但效率较低。

**改进：** 常用于实现更高效的图遍历算法，如贪心算法。

**适用场景：** 需要生成最小生成树。

**优缺点：** 高效稳定，但需要图已排序。

#### 2.3 动态规划

动态规划（Dynamic Programming，简称DP）是一种用于求解优化问题的算法方法，它将复杂的问题分解为更小的子问题，并存储子问题的解以避免重复计算。动态规划的核心思想是“记住以前的决定”，通过这种方式，我们可以有效地优化计算过程。

##### 2.3.1 动态规划的基本原理

动态规划通常涉及到以下三个基本要素：

1. **状态**：状态是问题的一个特定条件或约束，可以用一个或多个变量来表示。
2. **状态转移方程**：状态转移方程描述了如何从当前状态转移到下一个状态，通常表示为递推关系。
3. **边界条件**：边界条件是问题的初始状态，是递推关系的起点。

**递推关系**：动态规划通过递推关系逐步求解问题，每个状态的计算依赖于其前一个状态的结果。递推关系通常表示为：

\[ f(n) = \text{base\_case} + \sum_{i=1}^{n-1} f(i) \]

其中，\( f(n) \) 表示第 \( n \) 个状态的值，\( \text{base\_case} \) 是边界条件。

##### 常见动态规划问题

**1. 斐波那契数列**

斐波那契数列是一个经典的动态规划问题，其递推关系为：

\[ F(n) = F(n-1) + F(n-2) \]

其中，\( F(0) = 0 \)，\( F(1) = 1 \)。

**伪代码：**

```python
def fibonacci(n):
    if n <= 1:
        return n
    dp = [0] * (n+1)
    dp[0], dp[1] = 0, 1
    for i in range(2, n+1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

**2. 最长公共子序列（LCS）**

最长公共子序列问题是另一个常见的动态规划问题，用于找到两个序列中最长的公共子序列。

**伪代码：**

```python
def longest_common_subsequence(X, Y):
    m, n = len(X), len(Y)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if X[i-1] == Y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

**3. 背包问题**

背包问题是动态规划中的一种经典问题，用于求解在给定容量下，如何选择物品以最大化总价值。

**伪代码：**

```python
def knapsack(W, weights, values, n):
    dp = [[0] * (W+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for w in range(1, W+1):
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], dp[i-1][w-weights[i-1]] + values[i-1])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][W]
```

##### 动态规划与分治算法

动态规划和分治算法在某些情况下具有相似性，但它们也有一些关键区别：

1. **分治算法**：将问题划分为更小的子问题，独立解决子问题，然后合并子问题的解。
2. **动态规划**：将问题划分为更小的子问题，并存储子问题的解以避免重复计算。

动态规划通常更适用于具有重叠子问题的优化问题，而分治算法适用于无重叠子问题的问题。

#### 3.1 算法题真题解析

**真题一：寻找两个数组的交集**

问题描述：给定两个整数数组，找出它们的所有交集元素。

**解题思路：**

使用哈希表存储其中一个数组中的所有元素，然后遍历另一个数组，检查每个元素是否在哈希表中，如果在则加入结果集。

**代码实现（Python）：**

```python
def find_intersection(arr1, arr2):
    hash_set = set(arr1)
    result = []
    for num in arr2:
        if num in hash_set:
            result.append(num)
    return result
```

**复杂度分析：**

- 时间复杂度：\( O(m + n) \)，其中 \( m \) 和 \( n \) 分别是两个数组的长度。
- 空间复杂度：\( O(m) \)，用于存储哈希表。

**真题二：寻找两个数组的最长公共子序列**

问题描述：给定两个整数数组，找出它们的最长公共子序列。

**解题思路：**

使用动态规划的方法，定义一个二维数组 \( dp \)，其中 \( dp[i][j] \) 表示两个数组的前 \( i \) 个元素和前 \( j \) 个元素的最长公共子序列的长度。

**代码实现（Python）：**

```python
def longest_common_subsequence(X, Y):
    m, n = len(X), len(Y)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if X[i-1] == Y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

**复杂度分析：**

- 时间复杂度：\( O(m \times n) \)，其中 \( m \) 和 \( n \) 分别是两个数组的长度。
- 空间复杂度：\( O(m \times n) \)，用于存储动态规划数组。

**真题三：寻找数组中的最小缺失值**

问题描述：给定一个不包含重复元素的整数数组，找出数组中的最小缺失值。

**解题思路：**

首先将数组排序，然后遍历数组，检查每个元素与索引的关系，找到第一个不满足 \( arr[i] = i + 1 \) 的元素，即为最小缺失值。

**代码实现（Python）：**

```python
def find_smallest_missing(arr):
    arr.sort()
    n = len(arr)
    for i in range(n):
        if arr[i] != i + 1:
            return i + 1
    return n + 1
```

**复杂度分析：**

- 时间复杂度：\( O(n \log n) \)，由于需要排序。
- 空间复杂度：\( O(1) \)，不需要额外空间。

**真题一：链表反转**

问题描述：给定一个单链表，实现链表反转的功能。

**解题思路：**

使用三个指针分别指向当前节点、前一个节点和后一个节点，依次遍历链表，更新指针指向，实现链表反转。

**代码实现（Python）：**

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_linked_list(head):
    prev = None
    curr = head
    while curr:
        next_temp = curr.next
        curr.next = prev
        prev = curr
        curr = next_temp
    return prev
```

**复杂度分析：**

- 时间复杂度：\( O(n) \)，其中 \( n \) 是链表的长度。
- 空间复杂度：\( O(1) \)，不需要额外空间。

**真题二：二叉树的遍历**

问题描述：给定一个二叉树，实现先序遍历、中序遍历和后序遍历。

**解题思路：**

**代码实现（Python）：**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def preorder_traversal(root):
    if root:
        print(root.val)
        preorder_traversal(root.left)
        preorder_traversal(root.right)

def inorder_traversal(root):
    if root:
        inorder_traversal(root.left)
        print(root.val)
        inorder_traversal(root.right)

def postorder_traversal(root):
    if root:
        postorder_traversal(root.left)
        postorder_traversal(root.right)
        print(root.val)
```

#### 3.3 数学与逻辑题解析

**真题一：最大子序和**

问题描述：给定一个整数数组，找出该数组中连续元素的最大和。

**解题思路：**

使用动态规划的方法，定义一个变量 \( max_ending_here \) 用于存储以当前元素为结尾的最大子序和，另一个变量 \( max_so_far \) 用于存储全局最大子序和。

**代码实现（Python）：**

```python
def max_subarray_sum(arr):
    max_ending_here = max_so_far = arr[0]
    for x in arr[1:]:
        max_ending_here = max(x, max_ending_here + x)
        max_so_far = max(max_so_far, max_ending_here)
    return max_so_far
```

**复杂度分析：**

- 时间复杂度：\( O(n) \)，其中 \( n \) 是数组的长度。
- 空间复杂度：\( O(1) \)，不需要额外空间。

**真题二：素数环**

问题描述：给定一个整数 \( n \)，判断是否存在一个长度为 \( n \) 的环，其中每个节点都是素数。

**解题思路：**

使用递归方法，从每个节点开始，尝试构建一个长度为 \( n \) 的素数环。

**代码实现（Python）：**

```python
def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

def prime_circle(n):
    def dfs(start, length):
        if length == n:
            return True
        if start == n - 1:
            return dfs(0, length + 1)
        for i in range(n):
            if is_prime(i) and i != start and (length == 0 or (i + 1) % n != start + 1):
                if dfs(i, length + 1):
                    return True
        return False

    return dfs(0, 0)
```

**复杂度分析：**

- 时间复杂度：\( O(n^2) \)，其中 \( n \) 是整数。
- 空间复杂度：\( O(n) \)，用于递归栈。

                dp[i] = max(dp[i], dp[j] + 1)

#### 4.3 美团校招算法面试真题三

**题目描述：给定一个字符串，找出字符串中的最长回文子串。**

**解题思路：**

使用中心扩展算法，遍历字符串的每个字符，将其作为中心点，向两边扩展，找出最长回文子串。

**代码实现（Python）：**

```python
def longest_palindromic_substring(s):
    def expand_around_center(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1

    start, max_len = 0, 1
    for i in range(len(s)):
        len1 = expand_around_center(i, i)
        len2 = expand_around_center(i, i + 1)
        max_len = max(max_len, len1, len2)
        start = i - ((max_len - 1) >> 1)

    return s[start:start + max_len]

# 示例
s = "babad"
print(longest_palindromic_substring(s))  # 输出："bab" 或 "aba"
```

**复杂度分析：**

- 时间复杂度：\( O(n^2) \)，其中 \( n \) 是字符串的长度。
- 空间复杂度：\( O(1) \)，不需要额外空间。

- **自信**：对自己有信心，相信自己能够应对各种问题。
- **冷静**：面对面试官的问题，保持冷静，有条不紊地回答。
- **积极**：积极面对面试过程，展现出对工作的热情。

**5.1.2 算法题训练策略**

有效的训练策略能够显著提高解题能力。以下是一些建议：

- **刷题平台**：利用 LeetCode、HackerRank 等在线平台进行算法题训练。
- **分类练习**：按照算法题型进行分类练习，如排序、搜索、动态规划等。
- **复盘总结**：每次练习后，总结解题思路和代码，找出改进之处。

**5.1.3 面试官常见问题**

了解面试官可能会问到的问题，有助于提前做好准备。以下是一些常见问题及其回答策略：

**5.2.1 算法题解题思路**

在面试中，清晰、逻辑严密的解题思路至关重要。以下是一些建议：

- **理解问题**：仔细阅读题目，确保理解问题的要求和限制条件。
- **思考边界情况**：考虑问题的边界情况，如空数组、负数等。
- **分解问题**：将复杂问题分解为更简单的子问题，逐步解决。
- **算法框架**：在回答时，先给出算法的大致框架，再逐步完善。

**5.2.2 编程调试技巧**

编程调试是面试中的一个重要环节。以下是一些建议：

- **调试工具**：熟练使用调试工具，如断点、单步执行等。
- **错误处理**：考虑可能的错误情况，并编写相应的错误处理代码。

**5.2.3 面试沟通技巧**

良好的沟通能力是面试成功的关键。以下是一些建议：

- **清晰表达**：用简洁、准确的语言表达自己的观点。
- **倾听面试官**：认真倾听面试官的问题，确保理解问题意图。
- **适度提问**：适时向面试官提问，展示自己的积极性和求知欲。
- **保持自信**：在表达时保持自信，避免过度谦虚。

#### 5.3 面试后的反思与总结

面试结束后，及时进行反思和总结，有助于不断提高自己。以下是一些建议：

#### 6.1 常见面试数据结构与算法总结

- **数组**：用于存储有序集合，支持随机访问，时间复杂度为 \( O(1) \)。
- **链表**：包括单链表、双链表和循环链表，适合动态分配内存。
- **栈**：后进先出（LIFO）的数据结构，常用操作有 push、pop、isEmpty、peek。
- **队列**：先进先出（FIFO）的数据结构，常用操作有 enqueue、dequeue、isEmpty、peek。
- **哈希表**：基于关键字快速查找、插入和删除的数据结构，时间复杂度为 \( O(1) \)（平均情况）。
- **树**：包括二叉树、二叉搜索树、AVL树、红黑树等，适合表示层次结构。
- **图**：包括有向图和无向图，常用算法有深度优先搜索（DFS）、广度优先搜索（BFS）、最短路径算法（Dijkstra、Bellman-Ford）等。

#### 6.2 面试常用框架和库简介

- **Python**：一种广泛使用的编程语言，适合快速开发。
- **Java**：一种强类型的编程语言，适用于企业级应用。
- **C++**：一种多范式编程语言，适合高性能计算。
- **LeetCode**：一个在线编程平台，提供大量算法题目和解决方案。
- **Git**：一个分布式版本控制工具，用于代码管理。
- **GitHub**：一个基于 Git 的代码托管平台，方便协作开发。

#### 6.3 算法面试常用数学公式汇总

- **最大公约数（GCD）**：
  \[
  \text{GCD}(a, b) = \text{GCD}(b, a \mod b)
  \]
- **最小公倍数（LCM）**：
  \[
  \text{LCM}(a, b) = \frac{|a \times b|}{\text{GCD}(a, b)}
  \]
- **斐波那契数列**：
  \[
  F(n) = 
  \begin{cases}
  0 & \text{if } n = 0 \\
  1 & \text{if } n = 1 \\
  F(n-1) + F(n-2) & \text{otherwise}
  \end{cases}
  \]
- **二项式系数**：
  \[
  C(n, k) = \frac{n!}{k!(n-k)!}
  \]
- **概率公式**：
  \[
  P(A \cap B) = P(A) \times P(B \mid A)
  \]
  \[
  P(A \cup B) = P(A) + P(B) - P(A \cap B)
  \]
