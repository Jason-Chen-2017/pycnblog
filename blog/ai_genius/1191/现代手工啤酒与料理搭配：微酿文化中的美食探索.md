#### 4.1 酒菜搭配的基本原则（5级目录）

**核心概念与联系：**

- **搭配原理：**

  ```mermaid
  graph TD
  A[酒类] --> B[食材]
  A --> C[调味]
  B --> D[口感]
  C --> D
  ```

- **搭配方法：**

  - **协调搭配**：酒与菜在口感、风味上相互协调，形成和谐的味觉体验。

  - **对比搭配**：酒与菜在口感、风味上形成鲜明对比，产生层次丰富的味觉效果。

**核心算法原理讲解：**

```python

    """
    协调搭配算法
    :param wine: 酒的类型
    :param dish: 菜的类型
    :return: 搭配建议
    """
    pairing = {
        "wine": wine,

    }
    return pairing

def contrast_pairing(wine, dish):
    """
    对比搭配算法
    :param wine: 酒的类型
    :param dish: 菜的类型
    :return: 搭配建议
    """
    pairing = {
        "wine": wine,

    }

```

**数学模型和数学公式：**

$$
\text{协调搭配} = \frac{\text{酒与菜的相似度}}{\text{酒与菜的差异性}} > 1
$$

$$
\text{对比搭配} = \frac{\text{酒与菜的差异性}}{\text{酒与菜的相似度}} > 1
$$

**举例说明：**

- 协调搭配示例：一杯德国小麦啤酒搭配意大利披萨，两者的口感和风味相互协调，形成和谐的味觉体验。

- 对比搭配示例：一杯意大利瑞弗萨葡萄酒搭配美国烤牛肉，葡萄酒的酸度和牛肉的油腻形成鲜明对比，产生层次丰富的味觉效果。
