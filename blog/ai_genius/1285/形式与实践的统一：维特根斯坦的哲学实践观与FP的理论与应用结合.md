**FP理论**

函数式编程（Functional Programming，FP）是一种编程范式，强调计算过程作为函数的执行，而非命令式编程中的步骤序列。FP理论在计算机科学中有着广泛的应用。

- **不可变性**：FP强调不可变性，即数据一旦创建，就不能更改。这有助于提高代码的可读性和可维护性。在FP中，数据结构通常是不可变的，任何修改都会创建一个新的数据结构。

```python
# 计算阶乘的纯函数
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

# 使用纯函数计算5的阶乘
result = factorial(5)
print("5的阶乘是：", result)
```

1. **纯函数**：`factorial` 函数是一个纯函数，因为它不依赖于外部状态，且输入和输出之间的关系是明确的。这意味着每次调用`factorial(n)`时，都会得到相同的结果，只要输入参数相同。
2. **不可变性**：在这个函数中，我们只使用了输入参数`n`，并且没有修改任何外部状态或变量。这符合不可变性的原则，即数据结构一旦创建，就不能更改。
