- JDK 11
- IntelliJ IDEA

```java
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        System.out.println("加法运算结果： " + calculator.add(1, 2));  // 输出: 3
        System.out.println("加法运算结果： " + calculator.add(1, 2, 3));  // 输出: 6
    }
}
```

- `add(int a, int b)`方法实现了两个整数参数的加法运算。
- `add(int a, int b, int c)`方法实现了三个整数参数的加法运算。
- 通过方法重载，根据参数的不同调用相应的加法方法。

2. **指称理论**：弗雷格探讨了名词、句子的指称问题，提出了“名称指称唯一对象”的观点。他认为，一个名词的指称是固定的，不会因语境变化而改变。

3. **命题逻辑**：弗雷格对命题逻辑做出了重要贡献，他提出了“概念论”（Begriffsschrift），这是一种形式逻辑体系，为后来的命题逻辑和数理逻辑奠定了基础。

**1.3 弗雷格的意义与指称理论的概述**

弗雷格的意义与指称理论是哲学逻辑学中的核心内容。他的理论试图解答以下问题：

- **意义是什么？** 弗雷格认为，意义是名词或符号内在的、客观的属性，是与指称相关但又独立于指称的。

### 第5章：方法重载的概念与特点

**5.1 方法重载的定义**

方法重载（Method Overloading）是一种在编程语言中允许同一类（Class）中存在多个同名方法的技术。这些方法根据参数的数量、类型或顺序的不同，能够执行不同的操作。方法重载是面向对象编程（OOP）中的一个重要特性，它使得程序员可以通过相同的方法名来执行不同的功能，提高了代码的可读性和可维护性。

**5.2 方法重载的实现机制**

方法重载的实现机制主要依赖于编译器在编译期间对方法进行解析和匹配。编译器通过检查方法的参数列表来识别调用哪个方法。具体来说，方法重载的实现机制包括以下几个方面：

1. **参数数量**：如果两个方法的名称相同，但参数数量不同，编译器会根据调用时提供的参数数量来匹配相应的方法。
2. **参数类型**：如果两个方法的名称和参数数量相同，但参数类型不同，编译器会根据参数的类型来匹配相应的方法。
3. **参数顺序**：如果两个方法的名称、参数数量和类型都相同，但参数的顺序不同，编译器会根据参数的顺序来匹配相应的方法。

**5.3 方法重载的应用场景**

方法重载在编程中有着广泛的应用场景，主要包括以下几个方面：

1. **功能扩展**：通过方法重载，可以扩展类的方法，使得同一个方法名可以处理不同类型的数据。
2. **简化代码**：方法重载可以减少代码的冗余，提高代码的可读性和可维护性。
