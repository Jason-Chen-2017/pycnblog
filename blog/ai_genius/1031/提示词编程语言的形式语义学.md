动态语义分析则关注程序的动态行为，如执行过程中的变量绑定和函数调用。以下是动态语义分析的核心算法：

```

    executionGraph = interpret(sourceCode, environment)
    return executionGraph

function interpret(sourceCode, environment):
    while not end of sourceCode:
        execute statement
        update environment
    return executionGraph

function executeStatement(statement, environment):
    if statement is a variable assignment:
        assign value to variable
    elif statement is a function call:
        return value from function call
    else:
        execute control flow statement
```

**数学模型和公式讲解**：
静态语义分析中，变量类型检查可以通过集合论中的覆盖关系来描述。以下是变量类型检查的数学模型：

$$
\forall v \in \text{VariableSet}, T_v \in \text{TypeSet} \\
T_v \subseteq T_v'
$$

其中，$\text{VariableSet}$ 表示变量集合，$\text{TypeSet}$ 表示类型集合，$T_v$ 和$T_v'$ 分别表示变量$v$ 的声明类型和实际类型。

动态语义分析中，程序执行过程中的状态转换可以通过状态转移图来描述。以下是状态转移图的数学模型：

$$
S_{\text{next}} = S_{\text{current}} \circ \Delta
$$

其中，$S_{\text{current}}$ 表示当前状态，$\Delta$ 表示状态转换函数，$S_{\text{next}}$ 表示执行下一个语句后的新状态。

**举例说明**：
假设我们有一个简单的程序片段：

```

    int y = x;
} else {
    int y = -x;
}
```

静态语义分析可以检查变量$x$ 和$y$ 的类型，并确保类型的一致性。动态语义分析可以模拟程序执行过程，根据$x$ 的值来计算$y$ 的值。
