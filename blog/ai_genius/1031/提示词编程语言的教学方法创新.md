import nltk
from nltk.tokenize import word_tokenize
from nltk.corpus import stopwords
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline

# 数据预处理
nltk.download('punkt')
nltk.download('stopwords')

def preprocess_text(text):
    tokens = word_tokenize(text.lower())
    tokens = [token for token in tokens if token not in stopwords.words('english')]
    return ' '.join(tokens)

# 构建模型
model = make_pipeline(TfidfVectorizer(), MultinomialNB())

# 训练模型
X_train = ['This is a sample text for training.', 'This is another sample text for training.']
y_train = ['category1', 'category2']

model.fit(X_train, y_train)

# 预测
text_to_predict = 'This is a new sample text for prediction.'
processed_text = preprocess_text(text_to_predict)
predicted_category = model.predict([processed_text])[0]

print(f'Predicted category: {predicted_category}')

## 第二部分：教学方法探讨

### 2.1 传统教学方法

#### 2.1.1 教学流程

传统的编程教学方法通常包括以下几个步骤：

1. **知识传授**：教师通过讲解编程语言的基本概念和语法规则，向学生传授编程知识。
2. **实践操作**：学生通过编写代码，进行实践操作，巩固所学知识。
3. **问题解决**：学生在实践中遇到问题时，通过查阅资料或请教教师，解决编程问题。
4. **评估反馈**：教师通过评估学生的作业和项目，提供反馈，指导学生改进。

#### 2.1.2 优点与局限性

传统教学方法具有以下几个优点：

1. **系统性**：传统教学方法能够系统地传授编程知识，使学生掌握编程的基本概念和技能。
2. **针对性**：教师可以根据学生的实际情况，针对性地进行教学，提高教学效果。

然而，传统教学方法也存在一些局限性：

1. **学习曲线陡峭**：传统教学方法往往需要学生具备一定的编程基础，否则学习过程可能会比较困难。
2. **缺乏互动性**：传统教学方法以教师为中心，学生参与度较低，缺乏互动性。

### 2.2 创新教学方法

2. **互动性**：游戏化学习提高了学生的参与度，学生可以在游戏中与其他学生互动，分享学习经验。

项目驱动学习是一种以项目为中心的教学方法。教师设计一系列编程项目，学生通过完成项目，学习编程知识和技能。

2. **实践性**：项目驱动学习强调实践性，学生可以在实际项目中应用所学知识，提高编程能力。

2. **自主学习**：反思性实践鼓励学生自主学习，培养独立解决问题的能力。

#### 2.2.4 社交学习

社交学习是一种通过社交互动，促进学习的教学方法。学生通过与他人交流，分享学习经验和成果，提高编程能力。

1. **教学流程**：教师组织学生进行编程讨论和分享会，鼓励学生积极参与。
