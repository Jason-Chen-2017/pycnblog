```python
def performance_evaluation(employee, metrics):
    """
    绩效评估函数
    :param employee: 员工对象
    :param metrics: 绩效指标列表
    :return: 绩效评估得分
    """
    score = 0
    for metric in metrics:
        if metric['type'] == 'quantitative':
            score += employee.quantitative_performance(metric['target'])
        elif metric['type'] == 'qualitative':
            score += employee.qualitative_performance(metric['target'])
    return score
```

\text{绩效得分} = w_1 \times \text{定量绩效得分} + w_2 \times \text{定性绩效得分}

##### 2.1 绩效驱动型组织的实施步骤

###### 2.1.1 制定绩效目标

###### 2.1.2 设计绩效评估指标

1. **确定绩效指标类型**：根据组织的实际情况和员工的工作性质，选择合适的绩效指标类型，如定量指标、定性指标等。
2. **制定绩效指标标准**：为每个绩效指标设定明确的评分标准和权重，确保评估的公正性和客观性。

1. **定期进行绩效评估**：根据组织的实际情况，制定合理的绩效评估周期，如季度、半年、年度等。
2. **收集和整理评估数据**：通过多种渠道收集员工的绩效数据，如自评、他评、360度评估等，确保数据的全面性和准确性。

1. **及时反馈**：在绩效评估结束后，及时向员工提供绩效评估结果，帮助员工了解自己的优势和不足。
