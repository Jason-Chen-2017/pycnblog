### 第1章：AI模型泛化能力概述

#### 1.1 泛化能力的定义与重要性

泛化能力是指AI模型在面对未见过的数据时，能够准确地进行预测或分类的能力。在机器学习中，泛化能力是一个核心指标，直接影响模型的实际应用价值。具体来说，泛化能力强意味着模型不仅能在训练数据上表现良好，还能在新数据、甚至未见过的类别上保持稳定的性能。

在AI领域，泛化能力的重要性不言而喻。一方面，泛化能力决定了模型在现实世界中的适用性。如果一个模型只能在特定的、已知的数据集上表现优秀，而在实际应用中遇到未知情况时表现不佳，那么这个模型在实际场景中的价值将大打折扣。另一方面，泛化能力也是模型安全和可靠性的基础。如果一个模型容易受到攻击或产生错误预测，那么它就不能被视为一个可靠的决策工具。

#### 1.2 AI模型泛化能力的挑战

尽管泛化能力在AI研究中备受关注，但实际上提高模型的泛化能力面临着诸多挑战。首先，数据分布的不平衡是一个主要问题。在训练过程中，如果数据集中某些类别或特征的样本量远小于其他类别或特征，那么模型容易对少数类别产生偏差，从而降低泛化能力。

其次，模型复杂性也是一个关键因素。随着深度学习模型变得越来越复杂，模型的过拟合风险也相应增加。过拟合指的是模型在训练数据上表现良好，但在新数据上表现不佳的现象。这种情况下，模型并没有真正学会数据的本质规律，而是记住了训练数据的特定细节。

另外，样本量有限也是影响泛化能力的一个因素。当训练数据量不足时，模型很难捕捉到数据的真实分布，这会导致模型在新数据上的泛化性能下降。

#### 1.3 零样本学习任务的定义与特点

零样本学习（Zero-Shot Learning, ZSL）是一种重要的机器学习任务，其核心目标是使模型能够处理从未见过的类别或样本。在传统的监督学习任务中，模型通过学习已知类别的特征分布来预测未见过的类别。然而，在现实世界中，我们往往无法获取到所有类别的训练数据，尤其是在类别繁多、样本数量有限的情况下，零样本学习变得尤为重要。

零样本学习的主要特点包括：

1. **类别标签缺失**：在训练阶段，模型无法直接接触到未见过的类别的标签。
2. **转移学习**：零样本学习利用已有类别（即已见类别）的特征分布来推断未见类别。
3. **表示学习**：模型通过学习通用特征表示来提高泛化能力。

零样本学习不仅在计算机视觉领域有广泛应用，如图像分类和识别，还在自然语言处理、推荐系统等领域展现出巨大的潜力。

零样本学习（Zero-Shot Learning, ZSL）是一种机器学习任务，旨在使模型能够处理从未见过的类别或样本。在传统的监督学习任务中，模型通过学习已知类别的特征分布来预测未见过的类别。然而，在现实世界中，我们往往无法获取到所有类别的训练数据，尤其是在类别繁多、样本数量有限的情况下，零样本学习变得尤为重要。

零样本学习的关键概念包括：

2. **未见类别（Unseen Classes）**：模型在训练阶段尚未接触到的类别。
3. **特征表示（Feature Representation）**：模型通过学习得到的通用特征表示，用于描述所有类别的数据。
4. **类别关系（Class Relationship）**：不同类别之间的语义关系，如词义相近、形态相似等，用于辅助模型进行未见类别预测。

#### 2.2 零样本学习任务的数据准备

1. **已见数据集（Seen Data）**：收集并准备包含已见类别的数据集。这些数据集将用于训练模型。
2. **未见数据集（Unseen Data）**：准备包含未见类别的数据集。这些数据集将用于评估模型的泛化能力。
3. **类别词典（Class Dictionary）**：建立类别词典，将所有类别映射到唯一的标识符。类别词典有助于模型在处理未见类别时进行有效的分类。
4. **元数据（Metadata）**：元数据包括每个类别的描述信息，如词向量、标签等。这些信息将用于辅助模型学习类别关系和特征表示。

#### 3.1 零样本学习任务的主要算法框架

零样本学习任务的核心目标是使模型能够处理从未见过的类别，从而提高其泛化能力。为了实现这一目标，研究者们提出了多种算法框架，这些框架通常包括以下几个主要组成部分：

1. **特征表示学习**：该部分旨在学习通用特征表示，使模型能够捕捉数据的本质特征，而不仅仅是特定类别的特征。常用的方法包括基于深度神经网络的表示学习。
2. **类别关系建模**：该部分旨在建立类别之间的关系，从而帮助模型在未见类别上进行预测。这可以通过词义相近、形态相似等类别关系来实现。
3. **迁移学习**：迁移学习利用已有类别（已见类别）的特征分布来推断未见类别。这可以通过共享特征表示或直接利用已见类别的模型来实现。
4. **元学习**：元学习是一种通过学习如何学习的方法，其目标是在少量样本上快速适应未见类别。元学习算法通常包括模型更新和样本选择策略。

#### 3.2 零样本学习中的关键技术

在零样本学习任务中，一些关键技术对于提高模型的泛化能力至关重要。以下是这些关键技术的详细介绍：

1. **原型网络（Prototypical Network）**：
   - **概念**：原型网络是一种基于深度神经网络的零样本学习框架，其核心思想是通过学习每个类别的原型（即该类别的平均特征向量）来预测未见类别。
   - **实现**：原型网络通常包含两个部分：特征提取网络和原型表示学习网络。特征提取网络用于提取输入数据的特征表示，而原型表示学习网络则用于计算每个类别的原型。
   - **优缺点**：原型网络在处理未见类别时表现良好，但其性能依赖于数据集的规模和多样性。对于类别数量较少或数据分布不均匀的情况，原型网络的性能可能会受到影响。

2. **匹配网络（Matching Network）**：
   - **概念**：匹配网络是一种基于匹配分数的零样本学习框架，其核心思想是通过计算输入样本与每个类别的相似度来预测未见类别。
   - **实现**：匹配网络通常包含两个部分：特征提取网络和匹配分数计算模块。特征提取网络用于提取输入样本和类别的特征表示，而匹配分数计算模块则用于计算它们之间的相似度。
   - **优缺点**：匹配网络在处理未见类别时表现稳定，但其计算复杂度较高，特别是在类别数量较多时。此外，匹配网络的性能也依赖于特征提取网络的设计。

3. **度量学习（Metric Learning）**：
   - **概念**：度量学习是一种通过学习有效的距离度量来提高分类性能的方法，其目标是在特征空间中为不同类别找到适当的距离边界。
   - **实现**：度量学习通常包含两个部分：特征提取和距离度量学习。特征提取网络用于提取输入数据的特征表示，而距离度量学习模块则用于学习特征之间的距离度量。
   - **优缺点**：度量学习在处理未见类别时具有较好的泛化能力，但其性能依赖于特征提取网络的设计。此外，度量学习也面临着过拟合的风险。

4. **关系分类（Relation Classification）**：
   - **概念**：关系分类是一种通过学习类别之间的语义关系来提高零样本学习性能的方法。其核心思想是利用已见类别和未见类别之间的关系来预测未见类别。
   - **实现**：关系分类通常包含两个部分：关系提取和关系分类。关系提取模块用于学习类别之间的语义关系，而关系分类模块则用于利用这些关系进行未见类别预测。
   - **优缺点**：关系分类在处理未见类别时具有较好的泛化能力，但其性能依赖于类别关系的表示和质量。此外，关系分类也面临着数据稀疏和类别关系复杂的问题。

#### 3.3 零样本学习算法的评估指标

评估零样本学习算法的性能是衡量其泛化能力的重要手段。以下是一些常用的评估指标：

1. **准确率（Accuracy）**：
   - **定义**：准确率是指模型正确预测未见类别样本的比例。
   - **计算公式**：
     $$
     \text{准确率} = \frac{\text{正确预测的样本数}}{\text{总样本数}} \times 100\%
     $$
   - **优缺点**：准确率是一个简单直观的评估指标，但它容易受到类别不平衡的影响。当数据集中某些类别样本数量远小于其他类别时，准确率可能会受到严重扭曲。

2. **F1分数（F1 Score）**：
   - **定义**：F1分数是精确率和召回率的调和平均，综合考虑了预测的准确性和全面性。
   - **计算公式**：
     $$
     \text{F1分数} = 2 \times \frac{\text{精确率} \times \text{召回率}}{\text{精确率} + \text{召回率}}
     $$
   - **优缺点**：F1分数能够更好地平衡精确率和召回率，特别适用于类别不平衡的情况。但其仍依赖于准确率，因此在极端类别不平衡情况下可能会受到影响。

3. **平均准确率（Average Accuracy）**：
   - **定义**：平均准确率是指模型在所有未见类别上的准确率的平均值。
   - **计算公式**：
     $$
     \text{平均准确率} = \frac{1}{K} \sum_{i=1}^{K} \text{类别} i \text{的准确率}
     $$
   - **优缺点**：平均准确率能够更全面地评估模型在多个类别上的表现。然而，它容易受到极端类别的影响，特别是在类别数量较多时。

4. **宏平均准确率（Macro Average Accuracy）**：
   - **定义**：宏平均准确率是将所有类别的准确率按比例计算，然后取平均值。
   - **计算公式**：
     $$
     \text{宏平均准确率} = \frac{1}{K} \sum_{i=1}^{K} \text{类别} i \text{的准确率}
     $$
   - **优缺点**：宏平均准确率能够避免极端类别对评估结果的影响，特别适用于类别数量较多且类别不平衡的情况。但其可能未能充分考虑类别的重要性。

5. **微观准确率（Micro Average Accuracy）**：
   - **定义**：微观准确率是将所有类别的准确率加权平均，其中每个类别的权重为其样本数量。
   - **计算公式**：
     $$
     \text{微观准确率} = \frac{1}{N} \sum_{i=1}^{K} \text{类别} i \text{的准确率} \times \text{类别} i \text{的样本数}
     $$
   - **优缺点**：微观准确率能够全面反映模型的性能，特别适用于类别数量较多且类别不平衡的情况。但其对极端类别的影响较小。

6. **零样本准确率（Zero-Shot Accuracy）**：
   - **定义**：零样本准确率是指模型在未见类别上的准确率，不考虑已见类别的贡献。
   - **计算公式**：
     $$
     \text{零样本准确率} = \frac{\text{未见类别正确预测的样本数}}{\text{未见类别总样本数}} \times 100\%
     $$
   - **优缺点**：零样本准确率直接反映了模型在未见类别上的泛化能力，是评估零样本学习算法性能的重要指标。然而，它忽略了已见类别的贡献，可能未能全面评估模型的性能。

通过合理选择和使用这些评估指标，研究者可以更全面地评估零样本学习算法的性能，从而指导进一步的模型优化和改进。在接下来的章节中，我们将深入探讨如何通过数据增强、模型正则化、迁移学习、模型融合和元学习等技术来进一步提高零样本学习任务的泛化能力。### 第4章：数据增强与多样性

#### 4.1 数据增强的方法

数据增强是提高模型泛化能力的一种重要手段。在零样本学习任务中，数据增强尤为重要，因为它可以帮助模型学习到更多样化的特征表示，从而提高模型在未见类别上的性能。以下是一些常用的数据增强方法：

1. **随机裁剪（Random Crop）**：
   - **概念**：随机裁剪是指从原始图像中随机裁剪出一个小块作为输入样本。
   - **实现**：可以通过随机设置裁剪区域的大小和位置来实现。
   - **优缺点**：随机裁剪可以增加样本的多样性，有助于模型学习到图像的不同部分和特征。然而，这种方法可能引入噪声，影响模型的训练效果。

2. **随机旋转（Random Rotation）**：
   - **概念**：随机旋转是指将图像随机旋转一定角度作为输入样本。
   - **实现**：可以通过随机生成旋转角度来实现。
   - **优缺点**：随机旋转可以增加图像的多样性，有助于模型学习到图像的旋转不变性。但过度旋转可能导致图像失真。

3. **颜色调整（Color Augmentation）**：
   - **概念**：颜色调整是指对图像的颜色进行调整，如随机改变亮度、对比度和饱和度等。
   - **实现**：可以通过调整图像的通道值来实现。
   - **优缺点**：颜色调整可以增加图像的多样性，有助于模型学习到颜色的变化规律。但过度调整可能导致图像失真。

4. **混合输入（Mixup）**：
   - **概念**：混合输入是指将两个图像按一定比例混合作为输入样本。
   - **实现**：可以通过线性插值来实现。
   - **优缺点**：混合输入可以增加样本的多样性，有助于模型学习到图像的平滑过渡。但这种方法可能引入噪声，影响模型的训练效果。

5. **数据生成（Data Generation）**：
   - **概念**：数据生成是指通过生成新的图像作为输入样本。
   - **实现**：可以使用生成对抗网络（GAN）来实现。
   - **优缺点**：数据生成可以增加样本的多样性，有助于模型学习到更多样的特征。但生成数据的质量和真实性对模型训练效果有很大影响。

6. **对抗样本（Adversarial Example）**：
   - **概念**：对抗样本是指通过微小的扰动使模型产生错误预测的样本。
   - **实现**：可以通过生成对抗训练（GAN）来实现。
   - **优缺点**：对抗样本可以增强模型的鲁棒性，但过度生成可能导致模型性能下降。

#### 5.1 模型正则化技术

模型正则化是提高AI模型泛化能力的重要手段。通过引入正则化技术，可以防止模型过拟合，从而提高模型在未见类别上的泛化能力。以下是一些常用的模型正则化技术：

1. **L1正则化**：
   - **概念**：L1正则化通过在损失函数中添加模型参数的L1范数来实现。L1范数是模型参数绝对值之和。
   - **公式**：
     $$
     \text{正则化项} = \lambda \sum_{i} |\theta_i|
     $$
     其中，$\theta_i$ 是模型参数，$\lambda$ 是正则化参数。
   - **实现**：在损失函数中添加L1正则化项，可以使用 $L1$ 正则化损失函数。
   - **优缺点**：L1正则化能够产生稀疏解，即模型参数中的大部分值接近0，有助于模型简化。但其可能引入较大的计算开销。

2. **L2正则化**：
   - **概念**：L2正则化通过在损失函数中添加模型参数的L2范数来实现。L2范数是模型参数平方和的平方根。
   - **公式**：
     $$
     \text{正则化项} = \lambda \sum_{i} \theta_i^2
     $$
     其中，$\theta_i$ 是模型参数，$\lambda$ 是正则化参数。
   - **实现**：在损失函数中添加L2正则化项，可以使用 $L2$ 正则化损失函数。
   - **优缺点**：L2正则化能够防止模型参数过大，但不会产生稀疏解。其计算开销相对较小。

3. **Dropout**：
   - **概念**：Dropout是一种在训练过程中随机丢弃部分神经元的方法，以减少模型对特定训练样本的依赖性。
   - **实现**：在训练过程中，以一定的概率随机丢弃神经元输出，从而降低模型的复杂度和过拟合风险。
   - **优缺点**：Dropout能够提高模型的泛化能力，但可能导致训练时间延长，并影响模型在训练集上的性能。

4. **Early Stopping**：
   - **概念**：Early Stopping是一种在模型过拟合之前停止训练的方法。当模型在验证集上的性能不再提升时，停止训练。
   - **实现**：在训练过程中，同时训练模型并在验证集上评估其性能。当验证集性能不再提升时，停止训练。
   - **优缺点**：Early Stopping能够防止模型过拟合，但需要提前设置合适的停止条件，否则可能导致训练不足。

5. **数据增强**：
   - **概念**：数据增强是通过引入多样化的训练数据来提高模型泛化能力的方法。
   - **实现**：在训练过程中，通过随机裁剪、旋转、颜色调整等操作生成新的训练样本。
   - **优缺点**：数据增强能够增加模型的训练样本量，有助于模型泛化。但其可能引入噪声和计算开销。

#### 6.1 迁移学习的概念与原理

迁移学习（Transfer Learning）是一种利用已知任务（源任务）的知识来提高新任务（目标任务）性能的方法。其核心思想是将源任务的模型参数应用于目标任务，从而减少目标任务的训练时间并提高性能。迁移学习在零样本学习任务中具有重要作用，因为它可以帮助模型快速适应未见类别。

迁移学习的基本原理包括以下几个步骤：

1. **源任务训练**：在源任务上训练一个基模型（Base Model），使其在源任务上达到良好的性能。
2. **特征提取**：将基模型用于特征提取，将输入数据映射到特征空间。
3. **目标任务微调**：在目标任务上使用提取到的特征，对基模型进行微调（Fine-Tuning），以适应目标任务。

迁移学习的工作机制主要依赖于以下几点：

- **共享表示**：源任务和目标任务共享相同的特征表示，从而减少了模型在目标任务上的训练负担。
- **知识转移**：通过源任务训练得到的基模型，将知识转移到了目标任务，从而提高了目标任务的性能。
- **样本减少**：迁移学习减少了目标任务的训练样本需求，尤其是在目标任务数据稀缺的情况下。

#### 6.2 模型融合的技术

模型融合（Model Ensembling）是通过结合多个模型的预测结果来提高整体性能的一种方法。在零样本学习任务中，模型融合可以显著提升模型的泛化能力。模型融合的主要技术包括以下几种：

1. **简单平均（Simple Averaging）**：
   - **概念**：简单平均是将多个模型的预测结果进行平均，得到最终的预测结果。
   - **公式**：
     $$
     \text{预测结果} = \frac{1}{N} \sum_{i=1}^{N} \text{模型} i \text{的预测结果}
     $$
     其中，$N$ 是参与融合的模型数量。
   - **优缺点**：简单平均实现简单，计算成本低，但可能未能充分利用每个模型的独特优势。

2. **加权平均（Weighted Averaging）**：
   - **概念**：加权平均是在简单平均的基础上，为每个模型分配不同的权重，得到最终的预测结果。
   - **公式**：
     $$
     \text{预测结果} = \sum_{i=1}^{N} w_i \cdot \text{模型} i \text{的预测结果}
     $$
     其中，$w_i$ 是模型 $i$ 的权重，$N$ 是参与融合的模型数量。
   - **优缺点**：加权平均能够更充分利用每个模型的独特优势，但需要确定合理的权重分配，否则可能导致融合效果不佳。

3. **投票法（Voting）**：
   - **概念**：投票法是通过多数投票来决定最终的预测结果。
   - **实现**：在每个类别上，统计每个模型预测结果的数量，选取出现次数最多的类别作为最终预测结果。
   - **优缺点**：投票法在类别数量较少的情况下效果较好，但可能未能充分利用所有模型的信息。

4. **集成学习（Ensemble Learning）**：
   - **概念**：集成学习是通过构建多个独立的模型，并将它们的预测结果进行融合来提高整体性能。
   - **实现**：可以使用Bagging、Boosting等集成学习算法来构建多个模型，然后将它们进行融合。
   - **优缺点**：集成学习能够充分利用多个模型的信息，提高预测性能，但构建和融合多个模型的成本较高。

5. **混合模型（Hybrid Model）**：
   - **概念**：混合模型是将多个模型的特点结合起来，形成一个更复杂的模型。
   - **实现**：可以使用神经网络结构、深度强化学习等方法来构建混合模型。
   - **优缺点**：混合模型可以充分利用多个模型的优点，提高性能，但实现复杂度较高。

#### 6.3 迁移学习与模型融合在零样本学习中的应用

迁移学习和模型融合技术在零样本学习任务中具有广泛应用。以下是一些实际应用场景：

   - **方法**：使用简单平均或加权平均方法将多个模型的预测结果进行融合。

#### 7.1 元学习的定义与原理

元学习（Meta-Learning）是一种机器学习技术，旨在使模型能够在少量样本上快速适应新任务。在传统的机器学习任务中，模型通常需要大量训练数据来达到良好的性能。然而，在现实世界中，获取大量标注数据既困难又耗时。元学习通过学习如何学习，从而在少量样本上实现高效的模型训练。

元学习的基本原理包括以下几个关键概念：

1. **快速适应（Fast Adaptation）**：
   - **定义**：快速适应是指模型能够在短时间内从新任务中学习到有效的特征表示。
   - **实现**：通过元学习，模型可以在一个元学习框架下，快速适应新的任务。

2. **模型泛化（Generalization）**：
   - **定义**：模型泛化是指模型能够在未见过的数据上保持良好的性能。
   - **实现**：元学习通过在学习过程中关注模型的泛化能力，从而提高模型在新任务上的表现。

3. **任务样本减少（Sample Efficiency）**：
   - **定义**：任务样本减少是指模型在少量样本上能够达到与大量样本相同的性能。
   - **实现**：元学习通过设计有效的学习算法，降低模型对训练样本的需求。

元学习的主要目的是开发一种能够快速适应新任务的通用学习方法。其核心思想是通过在元学习任务中反复训练和优化模型，使其能够在新的任务上迅速达到良好性能。以下是一些常见的元学习算法：

1. **模型更新（Model Updating）**：
   - **概念**：模型更新是指在新任务上调整模型的参数，以适应新任务。
   - **实现**：通过梯度下降等优化算法，在元学习任务中调整模型参数。
   - **优缺点**：模型更新简单直观，但可能需要大量迭代才能收敛。

2. **样本选择（Sample Selection）**：
   - **概念**：样本选择是指在新任务中选择最有代表性的样本进行训练。
   - **实现**：通过选择性采样策略，从新任务中选择关键样本进行训练。
   - **优缺点**：样本选择有助于提高模型在新任务上的性能，但需要有效的样本选择策略。

3. **模型融合（Model Ensembling）**：
   - **概念**：模型融合是指将多个模型的预测结果进行融合，以提高整体性能。
   - **实现**：通过简单的平均或加权平均方法，将多个模型的预测结果进行融合。
   - **优缺点**：模型融合可以充分利用多个模型的优势，但需要确定合理的权重分配。

4. **梯度提升（Gradient Ascent）**：
   - **概念**：梯度提升是指通过更新模型参数，使模型在新任务上的预测误差最小。
   - **实现**：通过反向传播算法，更新模型参数以最小化损失函数。
   - **优缺点**：梯度提升是一种有效的优化方法，但可能需要大量的迭代次数。

- **$s(\textbf{x}, \textbf{ prototype}_c)$**：表示输入样本$\textbf{x}$与类别$c$的原型$\textbf{ prototype}_c$的余弦相似度。

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# 数据预处理
transform = transforms.Compose([
    transforms.Resize((224, 224)),  # 将图像调整为224x224
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

# 假设我们使用的是CIFAR-10数据集
train_set = datasets.CIFAR10(root='./data', train=True, download=True, transform=transform)
test_set = datasets.CIFAR10(root='./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_set, batch_size=64, shuffle=True)
test_loader = DataLoader(test_set, batch_size=64, shuffle=False)

# 模型定义
class ZeroShotCNN(nn.Module):
    def __init__(self):
        super(ZeroShotCNN, self).__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.fc1 = nn.Linear(64 * 56 * 56, 128)
        self.fc2 = nn.Linear(128, 10)  # 假设我们有10个类别

    def forward(self, x):
        x = nn.functional.relu(self.conv1(x))
        x = nn.functional.relu(self.conv2(x))
        x = nn.functional.adaptive_avg_pool2d(x, 1)
        x = x.view(x.size(0), -1)
        x = nn.functional.relu(self.fc1(x))
        x = self.fc2(x)
        return x

model = ZeroShotCNN()

# 损失函数和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 训练模型
num_epochs = 10
for epoch in range(num_epochs):
    model.train()
    running_loss = 0.0
    for images, labels in train_loader:
        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        running_loss += loss.item()
    print(f'Epoch [{epoch+1}/{num_epochs}], Loss: {running_loss/len(train_loader):.4f}')

# 测试模型
model.eval()
with torch.no_grad():
    correct = 0
    total = 0
    for images, labels in test_loader:
        outputs = model(images)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

accuracy = 100 * correct / total
print(f'Accuracy on the test set: {accuracy:.2f}%')
```

2. **模型定义**：我们定义了一个简单的卷积神经网络（CNN），包括两个卷积层、一个全连接层和Softmax激活函数。

3. **训练模型**：在训练过程中，我们使用交叉熵损失函数和Adam优化器，通过反向传播进行模型训练。

4. **测试模型**：在测试阶段，我们评估模型在测试集上的性能，并计算准确率。

```python
import torch.nn as nn

class PrototypicalNetwork(nn.Module):
    def __init__(self, feature_dim, num_classes):
        super(PrototypicalNetwork, self).__init__()
        self.feature_extractor = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(64, 64, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.AdaptiveAvgPool2d((1, 1))
        )
        
        self.classifier = nn.Sequential(
            nn.Linear(feature_dim, 256),
            nn.ReLU(inplace=True),
            nn.Linear(256, num_classes)
        )
        
    def forward(self, x):
        x = self.feature_extractor(x)
        x = x.view(x.size(0), -1)
        x = self.classifier(x)
        return x
```
