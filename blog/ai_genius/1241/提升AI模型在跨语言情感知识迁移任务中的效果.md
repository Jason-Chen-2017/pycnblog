## 第二部分：深度学习基础

### 2.1 深度学习概述

#### 2.1.1 深度学习的基本概念

深度学习是机器学习的一个分支，其核心思想是通过多层神经网络对数据进行自动特征提取和表示。深度学习通过多层非线性变换，能够捕捉到数据中的复杂结构和规律。

#### 2.1.2 深度学习的核心组成部分

深度学习的核心组成部分包括：

1. **神经元**：神经元是神经网络的基本单元，能够对输入数据进行加权求和并输出。
2. **神经网络**：神经网络由多个神经元组成，通过层与层之间的连接形成层次结构。
3. **激活函数**：激活函数用于引入非线性变换，使得神经网络能够捕捉到数据中的复杂结构。

#### 2.1.3 深度学习的常见模型架构

深度学习的常见模型架构包括：

1. **卷积神经网络（CNN）**：CNN适用于处理图像数据，通过卷积层和池化层对图像进行特征提取。
2. **循环神经网络（RNN）**：RNN适用于处理序列数据，能够捕获序列中的长期依赖关系。
3. **变换器（Transformer）**：Transformer是近年来发展起来的一种新型深度学习模型，其通过自注意力机制对序列数据进行建模。

import tensorflow as tf
import tensorflow_hub as hub

# 加载预训练的BERT模型
model = hub.load("https://tfhub.dev/google/bert_uncased_L-12_H-768_A-12/1")

# 定义输入文本

input_ids = model.tokenize(input_text)

# 使用BERT模型进行情感分析

# 获取情感分析结果
probabilities = tf.nn.softmax(outputs[0])

# 打印情感分析结果
print("正面情感概率：", probabilities[0][1].numpy())
print("负面情感概率：", probabilities[0][0].numpy())
```

import tensorflow as tf
import tensorflow_hub as hub

# 加载预训练的BERT模型
model = hub.load("https://tfhub.dev/google/bert_uncased_L-12_H-768_A-12/1")

# 定义输入文本
input_text = "这是一个关于电影的评论。这部电影非常有趣！"

# 对输入文本进行编码
input_ids = model.tokenize(input_text)

# 使用BERT模型进行情感分析
outputs = model(input_ids)

# 获取情感分析结果
probabilities = tf.nn.softmax(outputs[0])

# 打印情感分析结果
print("正面情感概率：", probabilities[0][1].numpy())
print("负面情感概率：", probabilities[0][0].numpy())
