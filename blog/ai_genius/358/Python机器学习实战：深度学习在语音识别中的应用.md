#### 第2章：数据预处理与特征工程

##### 2.1 数据预处理

数据预处理是机器学习过程中至关重要的一步，它包括数据清洗、数据归一化和标准化、数据分箱和离散化、数据缺失值处理等。

**数据清洗**

数据清洗是处理脏数据和异常数据的过程，包括删除重复数据、填充缺失数据、消除噪声等。数据清洗的目的是提高数据质量，为后续的模型训练提供可靠的数据基础。

**数据归一化和标准化**

数据归一化和标准化是处理不同特征之间尺度差异的方法。数据归一化是将数据缩放到相同的范围，如将数据缩放到[0,1]或[-1,1]之间；数据标准化是通过计算平均值和标准差，将数据转换为标准正态分布。

**数据分箱和离散化**

数据分箱和离散化是将连续数据转换为分类数据的方法。分箱是将连续数据划分为多个区间，每个区间对应一个类别；离散化是将连续数据映射到预定义的类别。

**数据缺失值处理**

数据缺失值处理是处理数据中缺失值的方法，包括删除缺失数据、填充缺失数据等。删除缺失数据是一种简单有效的方法，但可能导致数据丢失；填充缺失数据可以通过统计方法、插值方法等实现。

#### 第3章：线性模型与逻辑回归

##### 3.1 线性模型

线性模型是一种常见的机器学习模型，包括线性回归模型和线性判别分析（LDA）等。线性模型通过线性方程来描述数据之间的关系，具有较高的解释性和计算效率。

**线性回归模型**

线性回归模型是一种用于预测连续值的监督学习模型，其目标是找到一组线性方程，使模型预测值与真实值之间的误差最小。线性回归模型的数学公式为：

\[ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + ... + \beta_nx_n \]

其中，\( y \)是预测值，\( x_1, x_2, ..., x_n \)是特征值，\( \beta_0, \beta_1, \beta_2, ..., \beta_n \)是模型参数。

**线性回归模型评估**

线性回归模型的评估指标包括均方误差（MSE）、均方根误差（RMSE）、决定系数（R²）等。均方误差是预测值与真实值之间差的平方的平均值；均方根误差是均方误差的平方根；决定系数是模型解释能力的一个指标，取值范围在0到1之间，越接近1表示模型解释能力越强。

**线性回归模型优化**

线性回归模型的优化方法包括梯度下降、随机梯度下降等。梯度下降是一种迭代方法，通过更新模型参数，使模型预测值逐渐逼近真实值；随机梯度下降是梯度下降的一种变种，通过随机选取一部分样本进行参数更新，提高计算效率。

##### 3.2 逻辑回归

逻辑回归是一种用于预测类别的监督学习模型，其核心思想是通过线性方程将输入特征映射到概率值，然后通过阈值将概率值转换为类别。逻辑回归的数学公式为：

\[ P(y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x_1 + \beta_2x_2 + ... + \beta_nx_n )}} \]

其中，\( P(y=1) \)是预测为类别的概率，\( x_1, x_2, ..., x_n \)是特征值，\( \beta_0, \beta_1, \beta_2, ..., \beta_n \)是模型参数。

**逻辑回归模型应用**

逻辑回归模型广泛应用于分类任务，如二分类、多分类等。在二分类任务中，逻辑回归可以用于垃圾邮件分类、疾病诊断等；在多分类任务中，逻辑回归可以用于手写数字识别、文本分类等。

**逻辑回归模型评估**

逻辑回归模型的评估指标包括准确率、召回率、F1值等。准确率是预测正确的样本数占总样本数的比例；召回率是预测正确的正样本数占实际正样本数的比例；F1值是准确率和召回率的调和平均数，用于平衡准确率和召回率。

**逻辑回归模型优化**

逻辑回归模型的优化方法包括梯度下降、随机梯度下降等。梯度下降通过迭代更新模型参数，使模型预测值逐渐逼近真实值；随机梯度下降通过随机选取一部分样本进行参数更新，提高计算效率。

#### 第4章：树模型与集成模型

##### 4.1 决策树模型

决策树是一种基于树形结构的监督学习模型，通过一系列的决策规则将数据划分为不同的类别或数值。决策树的构建过程包括选择最佳划分特征、计算信息增益或基尼不纯度等。

**决策树基本原理**

决策树的基本原理是选择具有最大信息增益或最小基尼不纯度的特征进行划分。信息增益是特征对目标变量的预测能力的一种度量，计算公式为：

\[ IG(D, A) = H(D) - \sum_{v \in A} \frac{|D_v|}{|D|} H(D_v) \]

其中，\( D \)是数据集，\( A \)是特征，\( H(D) \)是数据集的熵，\( H(D_v) \)是数据集\( D_v \)的熵。

基尼不纯度是决策树划分的另一种度量，计算公式为：

\[ Gini(D, A) = 1 - \sum_{v \in A} \frac{|D_v|}{|D|} \left(1 - \frac{|D_v|}{|D|}\right) \]

**决策树分类与回归**

决策树可以用于分类和回归任务。在分类任务中，决策树通过一系列的判断规则将数据划分为不同的类别；在回归任务中，决策树通过一系列的线性方程预测连续值。

**决策树剪枝**

决策树剪枝是一种防止模型过拟合的方法，通过修剪过深的树结构来提高模型泛化能力。常见的剪枝方法包括预剪枝和后剪枝。预剪枝在树构建过程中提前停止划分，如基于验证集的剪枝；后剪枝在树构建完成后修剪过深的节点，如剪枝深度、最小叶子节点样本数等。

##### 4.2 随机森林模型

随机森林是一种基于决策树的集成学习模型，通过构建多棵决策树，并使用随机特征选择和投票来提高模型性能。随机森林的基本原理是集成多个弱学习器，通过投票或平均等方式获得最终预测结果。

**随机森林原理**

随机森林通过随机选取特征子集和随机种子构建多棵决策树，每棵树对样本进行预测，最终通过投票或平均等方式获得预测结果。随机森林的优点包括降低过拟合风险、提高模型泛化能力等。

**随机森林算法实现**

随机森林算法的实现主要包括以下步骤：

1. 随机选择特征子集，构建多棵决策树。
2. 对每棵决策树进行训练，并在训练数据上预测结果。
3. 对多棵决策树的预测结果进行投票或平均，获得最终预测结果。

**随机森林应用**

随机森林在多个领域有广泛应用，如分类任务、回归任务等。随机森林可以用于文本分类、图像分类、股票预测等场景。

##### 4.3 支持向量机模型

支持向量机是一种用于分类和回归的监督学习模型，其核心思想是找到一个最优的超平面，将数据集划分为不同的类别或数值。

**支持向量机原理**

支持向量机通过求解优化问题，找到一个最优的超平面，使数据集在超平面两侧的间隔最大化。支持向量机可以分为线性SVM和核SVM。线性SVM适用于线性可分的数据集，核SVM适用于非线性可分的数据集。

线性SVM的优化问题为：

\[ \min_{\beta, \beta_0} \frac{1}{2} ||\beta||^2 + C \sum_{i=1}^{n} \max(0, 1 - y_i (\beta^T x_i + \beta_0)) \]

其中，\( \beta \)是模型参数，\( \beta_0 \)是偏置项，\( C \)是惩罚参数，\( y_i \)是样本标签，\( x_i \)是样本特征。

核SVM的优化问题为：

\[ \min_{\beta, \beta_0, \alpha} \frac{1}{2} ||\beta||^2 + C \sum_{i=1}^{n} \alpha_i (1 - y_i (\beta^T \phi(x_i) + \beta_0)) \]

其中，\( \alpha_i \)是拉格朗日乘子，\( \phi \)是核函数。

**支持向量机算法实现**

支持向量机算法的实现主要包括以下步骤：

1. 选择核函数，如线性核、多项式核、径向基核等。
2. 求解优化问题，得到最优超平面和模型参数。
3. 使用训练好的模型进行预测。

**支持向量机应用**

支持向量机在多个领域有广泛应用，如文本分类、图像分类、情感分析等。支持向量机可以用于垃圾邮件分类、手写数字识别、图像分类等场景。

##### 4.4 集成模型

集成模型是通过组合多个弱学习器，提高模型性能的一种方法。常见的集成模型包括梯度提升树（GBDT）、XGBoost等。

**集成模型概述**

集成模型的基本思想是将多个弱学习器组合成一个强学习器，通过投票或平均等方式获得最终预测结果。集成模型可以提高模型的泛化能力和预测准确性。

**梯度提升树（GBDT）原理**

梯度提升树是一种基于决策树的集成学习模型，通过迭代更新模型参数，提高模型性能。梯度提升树的原理是通过求解损失函数的梯度，更新模型参数，使模型逐渐逼近最优解。

梯度提升树的优化问题为：

\[ \min_{\beta, \beta_0} \frac{1}{2} ||\beta||^2 + C \sum_{i=1}^{n} \max(0, 1 - y_i (\beta^T x_i + \beta_0)) \]

其中，\( \beta \)是模型参数，\( \beta_0 \)是偏置项，\( C \)是惩罚参数，\( y_i \)是样本标签，\( x_i \)是样本特征。

**XGBoost算法实现与应用**

XGBoost是一种高效的梯度提升树实现，其核心思想是引入正则化项，提高模型泛化能力。XGBoost的算法实现主要包括以下步骤：

1. 初始化模型参数。
2. 迭代更新模型参数，求解优化问题。
3. 使用训练好的模型进行预测。

XGBoost在多个领域有广泛应用，如分类、回归、排名等。XGBoost可以用于文本分类、图像分类、股票预测等场景。

#### 第5章：聚类与降维

##### 5.1 K均值聚类

K均值聚类是一种基于距离的聚类算法，通过迭代优化聚类中心，将数据划分为K个簇。K均值聚类的基本原理是选择初始聚类中心，然后通过迭代更新聚类中心，使聚类中心逐渐逼近最优解。

**K均值聚类原理**

K均值聚类的原理是通过计算数据点到聚类中心的距离，将数据划分为不同的簇。具体步骤如下：

1. 选择初始聚类中心，可以使用随机选择、K-means++等方法。
2. 计算每个数据点到聚类中心的距离，将数据划分为K个簇。
3. 计算每个簇的质心，作为新的聚类中心。
4. 重复步骤2和步骤3，直到聚类中心不再变化或达到最大迭代次数。

**K均值聚类算法实现**

K均值聚类的实现主要包括以下步骤：

1. 初始化聚类中心。
2. 计算每个数据点到聚类中心的距离，将数据划分为K个簇。
3. 计算每个簇的质心，作为新的聚类中心。
4. 判断聚类中心是否发生变化，如果发生变化则重复步骤2和步骤3，直到聚类中心不再变化或达到最大迭代次数。

**K均值聚类应用**

K均值聚类在多个领域有广泛应用，如文本聚类、图像聚类、社交网络聚类等。K均值聚类可以用于文本分类、图像分类、社交网络推荐等场景。

##### 5.2 主成分分析（PCA）

主成分分析（PCA）是一种常用的降维算法，通过将数据投影到新的正交坐标系中，提取主要的特征成分，降低数据维度。PCA的基本原理是通过求解特征值和特征向量，将数据映射到新的坐标系中。

**PCA原理**

PCA的原理是通过求解数据协方差矩阵的特征值和特征向量，将数据映射到新的正交坐标系中。新坐标系中的特征向量是原始数据的主要特征，可以用于降维。具体步骤如下：

1. 计算数据协方差矩阵。
2. 求解协方差矩阵的特征值和特征向量。
3. 选择特征值最大的特征向量作为新的坐标系。
4. 将数据投影到新的坐标系中，提取主要特征成分。

**PCA算法实现**

PCA的实现主要包括以下步骤：

1. 计算数据协方差矩阵。
2. 求解协方差矩阵的特征值和特征向量。
3. 选择特征值最大的特征向量作为新的坐标系。
4. 将数据投影到新的坐标系中，提取主要特征成分。

**PCA应用**

PCA在多个领域有广泛应用，如图像处理、文本分类、数据可视化等。PCA可以用于降维、特征提取、数据可视化等场景。

#### 第6章：强化学习与深度学习

##### 6.1 强化学习基础

强化学习是一种通过试错和反馈进行决策的人工智能技术，其核心思想是通过最大化长期回报来指导决策。强化学习的基本概念包括状态、动作、奖励和值函数等。

**强化学习基本概念**

- **状态（State）**：描述环境当前状态的变量集合。
- **动作（Action）**：在某个状态下，智能体可以采取的行动集合。
- **奖励（Reward）**：对智能体行为的即时评价，用于指导学习过程。
- **值函数（Value Function）**：表示在某个状态下执行某个动作的长期回报。

**强化学习算法**

强化学习算法可以分为基于值函数的算法和基于策略的算法。基于值函数的算法通过学习值函数来指导决策，如Q-Learning、SARSA等；基于策略的算法通过学习最优策略来指导决策，如Deep Q Network（DQN）等。

- **Q-Learning**：Q-Learning是一种基于值函数的强化学习算法，通过更新Q值来优化策略。Q值表示在某个状态下采取某个动作的预期回报。
- **SARSA**：SARSA是一种基于策略的强化学习算法，通过同时更新状态值函数和策略来优化学习过程。
- **Deep Q Network（DQN）**：DQN是一种基于深度学习的强化学习算法，通过神经网络来近似Q值函数，提高学习效率和性能。

##### 6.2 深度学习基础

深度学习是一种基于多层神经网络的学习方法，其核心思想是通过自动提取特征，实现复杂函数的拟合。深度学习的基本概念包括神经网络、激活函数、反向传播等。

**深度学习基本概念**

- **神经网络（Neural Network）**：神经网络是一种模拟生物神经网络的计算模型，由多个神经元（节点）和连接（边）组成。
- **激活函数（Activation Function）**：激活函数是神经网络中的一个关键组件，用于引入非线性特性，提高模型表达能力。
- **反向传播（Backpropagation）**：反向传播是一种用于训练神经网络的算法，通过计算损失函数关于网络参数的梯度，更新网络参数，使模型逐渐逼近最优解。

**深度学习框架**

深度学习框架是用于构建和训练深度学习模型的工具，常见的深度学习框架包括TensorFlow和PyTorch。TensorFlow是由Google开发的开源深度学习框架，提供丰富的API和工具；PyTorch是由Facebook开发的开源深度学习框架，具有灵活的动态计算图和高效的GPU支持。

##### 6.3 卷积神经网络（CNN）

卷积神经网络（CNN）是一种专门用于处理图像数据的深度学习模型，其核心思想是通过卷积操作和池化操作提取图像特征。CNN在图像分类、目标检测、图像生成等领域有广泛应用。

**CNN原理**

CNN的基本原理是通过多层卷积核和池化层提取图像特征，然后通过全连接层进行分类。具体步骤如下：

1. **卷积层**：卷积层通过卷积操作将输入图像与卷积核进行卷积运算，生成特征图。
2. **池化层**：池化层通过池化操作（如最大池化或平均池化）对特征图进行降采样，减少数据维度。
3. **全连接层**：全连接层将池化层输出的特征图进行展平，与输出层进行全连接运算，生成预测结果。

**CNN架构**

CNN的架构包括卷积层、池化层、全连接层等。常见的CNN架构有LeNet、AlexNet、VGG、ResNet等。

- **LeNet**：LeNet是最早的CNN架构之一，由卷积层、池化层和全连接层组成。
- **AlexNet**：AlexNet是第一个在ImageNet竞赛中取得显著成果的CNN架构，引入了ReLU激活函数和dropout正则化。
- **VGG**：VGG是一种深层CNN架构，通过增加卷积层和池化层的深度来提高模型性能。
- **ResNet**：ResNet是一种基于残差块的深层CNN架构，通过跳跃连接克服梯度消失问题，实现更深的网络结构。

**CNN在图像处理中的应用**

CNN在图像处理领域有广泛应用，如图像分类、目标检测、图像生成等。CNN可以用于图像分类任务，如ImageNet竞赛；目标检测任务，如Faster R-CNN、SSD等；图像生成任务，如生成对抗网络（GAN）等。

##### 6.4 循环神经网络（RNN）

循环神经网络（RNN）是一种适用于序列数据的深度学习模型，其核心思想是通过循环机制保留序列信息。RNN在自然语言处理、语音识别、时间序列预测等领域有广泛应用。

**RNN原理**

RNN的基本原理是通过循环连接将当前状态与前一状态相连接，保留序列信息。具体步骤如下：

1. **隐藏状态更新**：在RNN中，每个时间步的隐藏状态都依赖于前一时间步的隐藏状态和当前输入。
2. **输出生成**：在RNN中，每个时间步的输出都依赖于当前输入和隐藏状态。

**RNN架构**

RNN的架构包括输入层、隐藏层和输出层。常见的RNN架构有简单RNN、LSTM、GRU等。

- **简单RNN（Simple RNN）**：简单RNN是最基本的RNN架构，通过循环连接保留序列信息。
- **LSTM（Long Short-Term Memory）**：LSTM是一种改进的RNN架构，通过引入门控机制解决长期依赖问题。
- **GRU（Gated Recurrent Unit）**：GRU是另一种改进的RNN架构，通过门控机制和更新门简化LSTM结构。

**RNN在序列数据处理中的应用**

RNN在序列数据处理领域有广泛应用，如自然语言处理、语音识别、时间序列预测等。RNN可以用于文本分类、机器翻译、语音识别等任务。

#### 第7章：深度学习在语音识别中的应用

##### 7.1 语音识别基础

语音识别是一种将语音信号转换为文本的计算机技术，其核心任务是识别语音中的单词和句子。语音识别的基础包括语音信号处理、语音信号特征提取和语音识别模型。

**语音信号处理**

语音信号处理是语音识别的基础，包括语音信号的采集、预处理和增强等。语音信号的采集通过麦克风等设备实现，预处理包括去除噪声、回声等，增强包括提高信噪比、增强语音信号等。

**语音信号特征提取**

语音信号特征提取是将语音信号转换为适用于机器学习模型的特征表示。常见的语音信号特征包括频谱特征、倒谱特征、短时傅里叶变换（STFT）等。

**语音识别模型**

语音识别模型是语音识别的核心，包括传统的隐藏马尔可夫模型（HMM）和深度学习模型。深度学习模型如卷积神经网络（CNN）、循环神经网络（RNN）和Transformer等，在语音识别任务中表现出优异的性能。

##### 7.2 集成编码器-解码器（Seq2Seq）模型

集成编码器-解码器（Seq2Seq）模型是语音识别中的经典模型，通过编码器将输入序列编码为固定长度的向量，解码器将编码后的向量解码为输出序列。

**Seq2Seq模型原理**

Seq2Seq模型的基本原理是通过对输入序列进行编码，将序列信息压缩为固定长度的向量，然后通过解码器将向量解码为输出序列。编码器和解码器都是神经网络结构，编码器将输入序列映射到固定长度的编码向量，解码器将编码向量映射到输出序列。

**Seq2Seq模型实现**

Seq2Seq模型的实现主要包括以下步骤：

1. **编码器实现**：编码器通常采用RNN或Transformer结构，将输入序列编码为固定长度的编码向量。
2. **解码器实现**：解码器通常采用RNN或Transformer结构，将编码向量解码为输出序列。
3. **损失函数设计**：设计损失函数用于评估模型性能，常用的损失函数包括交叉熵损失函数等。

**Seq2Seq模型在语音识别中的应用**

Seq2Seq模型在语音识别任务中具有较好的性能，可以通过训练大量语音数据，实现高精度的语音识别。Seq2Seq模型可以用于实时语音识别、语音合成等应用场景。

##### 7.3 自注意力机制与Transformer模型

自注意力机制（Self-Attention）和Transformer模型是近年来在自然语言处理领域取得突破性成果的技术。自注意力机制通过计算输入序列中每个元素之间的关联性，提高模型的表达能力；Transformer模型是一种基于自注意力机制的深度学习模型，在语音识别、机器翻译等任务中表现出优异的性能。

**自注意力机制原理**

自注意力机制的基本原理是计算输入序列中每个元素之间的关联性，通过加权求和的方式提取关键信息。自注意力机制通过多头注意力机制和多层注意力机制，提高模型的表达能力。

**Transformer模型架构**

Transformer模型的基本架构包括编码器和解码器，编码器和解码器都是基于多头注意力机制的深度神经网络。编码器将输入序列编码为固定长度的编码向量，解码器将编码向量解码为输出序列。

**Transformer模型在语音识别中的应用**

Transformer模型在语音识别任务中表现出优异的性能，通过自注意力机制和多层注意力机制，可以提取输入序列中的关键信息，实现高精度的语音识别。Transformer模型可以用于实时语音识别、语音合成等应用场景。

**语音信号处理实战**

语音信号处理是语音识别的重要步骤，包括语音信号的采集、预处理和增强等。在本案例中，我们将使用Python中的`pyaudio`库实现语音信号的采集，并使用`scipy`库进行预处理和增强。

```python
import pyaudio
import numpy as np
import scipy.signal as signal

# 语音信号采集
def record_audio(duration, rate=44100, channels=1, width=2):
    p = pyaudio.PyAudio()
    stream = p.open(format=pyaudio.paInt16,
                     channels=channels,
                     rate=rate,
                     input=True,
                     frames_per_buffer=1024)
    
    frames = []
    for _ in range(int(rate / 1024 * duration)):
        data = stream.read(1024)
        frames.append(data)
    
    stream.stop_stream()
    stream.close()
    p.terminate()
    
    return np.concatenate([np.frombuffer(frame, dtype=np.int16) for frame in frames])

# 语音信号预处理
def preprocess_audio(audio_data, sample_rate=44100):
    # 噪声去除
    noise_remove = signal.dsp.noise_filter(audio_data, sample_rate, noise_power=0.01, num_seconds=5)
    
    # 滤波器
    butter = signal.butter(4, 300 / (0.5 * sample_rate), btype='low', analog=False)
    filtered = signal.lfilter(butter[0], butter[1], noise_remove)
    
    return filtered

# 语音信号增强
def enhance_audio(audio_data, sample_rate=44100):
    # 动态范围压缩
    compress = signal.dsp.compression(audio_data, sample_rate, compression_threshold=-30, compression_ratio=2)
    
    # 增加增益
    gain = signal.dsp.gain(compress, sample_rate, gain=20)
    
    return gain

# 实例
audio_data = record_audio(duration=5)
preprocessed = preprocess_audio(audio_data)
enhanced = enhance_audio(preprocessed)
```

**特征提取实战**

特征提取是将语音信号转换为适用于机器学习模型的特征表示。在本案例中，我们将使用梅尔频率倒谱系数（MFCC）作为特征提取方法。

```python
import numpy as np
import scipy.io.wavfile as wav
from sklearn.preprocessing import StandardScaler

# 读取语音文件
def read_wav(filename, sample_rate=44100):
    rate, data = wav.read(filename)
    return data

# 计算梅尔频率倒谱系数（MFCC）
def extract_mfcc(wav_data, sample_rate=44100, n_mel_bins=128, n Fighters=26):
    # 音频预处理
    audio = signal.resample(wav_data, int(sample_rate))
    audio = audio.astype(np.float32)
    audio = audio - np.mean(audio)
    audio = audio / np.std(audio)
    
    # 梅尔频率滤波器组
    fbank = signal.mel.fbank(audio, sample_rate, n_mel_bins)
    
    # 梅尔频率倒谱系数
    MFCFeatures = signal.mfcc(fbank, n_mel_bins, n Fighters)
    MFCC = np.log(1 + MFCFeatures)
    
    return MFCC

# 特征归一化
def normalize_features(features):
    scaler = StandardScaler()
    normalized = scaler.fit_transform(features)
    return normalized

# 实例
wav_data = read_wav("audio.wav")
mfcc = extract_mfcc(wav_data)
normalized = normalize_features(mfcc)
```

**模型训练与评估实战**

模型训练与评估是语音识别的关键步骤，包括数据集的准备、模型的选择、训练和评估等。在本案例中，我们将使用TensorFlow和Keras实现模型训练和评估。

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, LSTM, TimeDistributed, Embedding, Conv1D, MaxPooling1D, GlobalMaxPooling1D, Bidirectional

# 准备数据集
def prepare_dataset(features, labels, batch_size=32, epochs=10):
    features = np.array(features)
    labels = np.array(labels)
    
    dataset = tf.data.Dataset.from_tensor_slices((features, labels))
    dataset = dataset.shuffle(buffer_size=1000).batch(batch_size)
    
    return dataset

# 构建模型
def build_model(input_shape, output_size):
    model = Sequential([
        Embedding(input_shape[1], output_size, input_length=input_shape[0]),
        LSTM(128, return_sequences=True),
        GlobalMaxPooling1D(),
        Dense(64, activation='relu'),
        TimeDistributed(Dense(output_size, activation='softmax'))
    ])
    
    model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])
    return model

# 训练模型
def train_model(model, dataset, batch_size=32, epochs=10):
    model.fit(dataset, epochs=epochs, batch_size=batch_size)

# 评估模型
def evaluate_model(model, dataset):
    loss, accuracy = model.evaluate(dataset)
    print(f"Loss: {loss}, Accuracy: {accuracy}")

# 实例
input_shape = (128, 13)
output_size = 10
model = build_model(input_shape, output_size)
dataset = prepare_dataset(normalized, labels)
train_model(model, dataset)
evaluate_model(model, dataset)
```
