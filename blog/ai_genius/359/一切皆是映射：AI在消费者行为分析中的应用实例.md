#### 3.3.2 案例二：基于协同过滤的推荐系统

##### 3.3.2.1 案例背景

某视频平台希望通过协同过滤算法，为用户推荐个性化的视频内容。

##### 3.3.2.2 代码实现与解读

```python
# 导入相关库
import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity

# 加载数据
data = pd.read_csv('video_data.csv')

# 构建用户-视频矩阵
user_video_matrix = data.pivot(index='user_id', columns='video_id', values='rating')

# 计算余弦相似度
cosine_sim = cosine_similarity(user_video_matrix)

# 推荐视频
def recommend_video(user_id, cosine_sim, user_video_matrix):
    # 计算用户与其他用户的相似度
    sim_scores = list(enumerate(cosine_sim[user_id]))
    sim_scores = sorted(sim_scores, key=lambda x: x[1], reverse=True)
    sim_scores = sim_scores[1:11]

    # 获取相似用户喜欢的视频
    recommended_videos = [user_video_matrix.iloc[i][1] for i in sim_scores]

    return recommended_videos

# 为用户推荐视频
user_id = 1
recommended_videos = recommend_video(user_id, cosine_sim, user_video_matrix)
print(recommended_videos)
```
