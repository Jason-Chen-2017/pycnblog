##### 2.1.1 波函数表示与变分法

设 $|\psi\rangle$ 为变分函数，其形式可以表示为：

$$

其中，$|i\rangle$ 是量子比特的基态，$c_i$ 是变分参数。我们的目标是通过调整 $c_i$，使得 $|\psi\rangle$ 对应的演化算子 $U(t)$ 达到最优。

变分参数的优化是QAOA的核心步骤。我们通过梯度下降法来优化变分参数。具体来说，我们首先计算当前参数下的损失函数，然后根据损失函数的梯度更新参数。

$$
\theta_{new} = \theta_{old} - \alpha \nabla_{\theta} \mathcal{L}(\theta)
$$

其中，$\alpha$ 是学习率。

from qiskit import QuantumCircuit, execute, Aer
from qiskit.aqua.algorithms import QAOA
from qiskit.aqua.operators import PauliSumOp

# 定义哈密顿量
def construct_hamiltonian(n_qubits, problem_params):
    paulis = []
    for i in range(n_qubits):
        paulis.append(PauliSumOp({f'Z^{i}': problem_params['Z_i']}))
    hamiltonian = PauliSumOp(paulis)
    return hamiltonian

# 定义目标函数
def objective_function(params):
    circuit = QuantumCircuit(n_qubits)
    QAOA.append_variational_ansatz(circuit, params)
    result = execute(circuit, backend).result()
    return -np.real(result.get_counts()[0])

# 实例化QAOA算法
qaoa = QAOA(pauli_sum_op=hamiltonian, objective_function=objective_function)

result = qaoa.run()

print("最优解：", result.get_solution())
print("最优值：", result.get_solution_value())
