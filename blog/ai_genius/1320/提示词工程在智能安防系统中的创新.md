2. **关键词库的构建**：
   - **静态库**：预设一组固定的关键词，适用于特定场景。

3. **数据预处理**：
   - **数据清洗**：去除噪声和冗余数据，确保数据质量。

4. **模型训练**：
   - **有监督学习**：利用标注数据集，通过机器学习算法训练模型。
   - **无监督学习**：在无标注数据集上，通过聚类等方法自动生成关键词库。
   - **半监督学习**：结合标注数据和未标注数据，提高模型的泛化能力。

### 第4章：数学模型与详细讲解

#### 提示词工程的数学模型

提示词工程的数学模型主要包括关键词提取模型和分类模型。以下是各模型的详细说明：

1. **关键词提取模型**：

   - **TF-IDF模型**：
     - **公式**：\(TF-IDF(t,d) = \frac{tf(t,d)}{N} + \log \left( 1 + \frac{1}{1 - \frac{df(t,d)}{N}} \right)\)
     - **解释**：\(tf(t,d)\)表示词\(t\)在文档\(d\)中的词频，\(df(t,d)\)表示词\(t\)在所有文档中的文档频率，\(N\)表示文档总数。
     - **作用**：通过计算词的TF-IDF值，确定词在文档中的重要程度，从而提取出关键词。

   - **TextRank模型**：
     - **公式**：\(S(w_i) = \sum_{w_j \in E(w_i)} \frac{S(w_j)}{L(w_j)}\)
     - **解释**：\(S(w_i)\)表示词\(w_i\)的重要性分数，\(E(w_i)\)表示与词\(w_i\)相连的词集合，\(L(w_j)\)表示与词\(w_j\)相连的词的总数。
     - **作用**：基于链接分析原理，计算词的重要性分数，用于提取关键词。

2. **分类模型**：

   - **支持向量机（SVM）**：
     - **公式**：\(f(x) = \sum_{i=1}^{n} \alpha_i y_i (w \cdot x_i) + b\)
     - **解释**：\(\alpha_i\)为拉格朗日乘子，\(w\)为权重向量，\(b\)为偏置项，\(y_i\)为样本标签，\(x_i\)为输入特征向量。
     - **作用**：通过最大化分类边界，实现二分类任务。

   - **决策树（Decision Tree）**：
     - **公式**：根据特征值划分数据集，构建树形结构。
     - **解释**：树的每个节点代表一个特征，每个分支代表特征的不同取值，叶节点代表分类结果。
     - **作用**：通过递归划分数据集，实现多分类任务。

#### 数学模型详解

1. **TF-IDF模型详解**：

   - **步骤**：
     1. 计算每个词在文档中的词频（TF）。
     2. 计算每个词的文档频率（DF）。
     3. 计算每个词的TF-IDF值。
     4. 根据TF-IDF值，提取出关键词。

   - **示例**：
     - **文档**：{"智能安防", "系统", "提示词", "工程", "应用", "技术"}
     - **关键词提取**：
       - "智能安防"：TF=2, DF=1, TF-IDF=2.0
       - "系统"：TF=1, DF=1, TF-IDF=1.0
       - "提示词"：TF=1, DF=1, TF-IDF=1.0
       - "工程"：TF=1, DF=1, TF-IDF=1.0
       - "应用"：TF=1, DF=1, TF-IDF=1.0
       - "技术"：TF=1, DF=1, TF-IDF=1.0
     - **关键词**：{"智能安防", "提示词", "工程"}

2. **TextRank模型详解**：

   - **步骤**：
     1. 初始化关键词分数矩阵。
     2. 计算关键词的转移概率矩阵。
     3. 迭代计算关键词的重要性分数。
     4. 根据重要性分数提取出关键词。

   - **示例**：
     - **关键词集合**：{"智能", "安防", "系统", "提示词", "工程", "应用", "技术"}
     - **转移概率矩阵**：
       - \(P_{\text{智能}, \text{安防}} = 0.5\)
       - \(P_{\text{安防}, \text{系统}} = 0.3\)
       - \(P_{\text{系统}, \text{提示词}} = 0.2\)
       - \(P_{\text{提示词}, \text{工程}} = 0.4\)
       - \(P_{\text{工程}, \text{应用}} = 0.3\)
       - \(P_{\text{应用}, \text{技术}} = 0.5\)
     - **关键词重要性分数**：
       - "智能"：分数为0.5
       - "安防"：分数为0.3 + 0.2 \* 0.5 = 0.4
       - "系统"：分数为0.2 + 0.4 \* 0.3 = 0.26
       - "提示词"：分数为0.4 + 0.3 \* 0.4 = 0.46
       - "工程"：分数为0.3 + 0.4 \* 0.3 = 0.39
       - "应用"：分数为0.26 + 0.5 \* 0.3 = 0.39
       - "技术"：分数为0.5
     - **关键词**：{"提示词", "智能", "工程", "应用"}

   ```python
       cap = cv2.VideoCapture(video_path)
       frames = []

           ret, frame = cap.read()
           if not ret:
               break
           
           # 去噪与滤波
           frame = cv2.GaussianBlur(frame, (5, 5), 0)
           frame = cv2.medianBlur(frame, 3)
           
           # 缩放与归一化
           frame = cv2.resize(frame, (320, 240))
           frame = frame / 255.0
           
           frames.append(frame)
       
       cap.release()
       return frames
   ```
