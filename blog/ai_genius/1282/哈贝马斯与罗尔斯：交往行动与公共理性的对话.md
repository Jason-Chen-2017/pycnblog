哈贝马斯的交往行动理论是建立在“交往理性”基础上的，他认为交往行动是人类社会的基本形式。交往行动是指个体在平等、自由和合理的条件下，通过语言和符号系统进行交流和互动的过程。

哈贝马斯区分了交往行动和传统的社会行动。传统社会行动强调个体行为的目的性和工具理性，而交往行动则强调个体之间的互动和理解。在交往行动中，个体的行为不仅仅是为了实现特定的目标，更重要的是通过交流和对话，实现相互理解和共识。

#### 2.1.2 交往行动的结构要素

哈贝马斯认为，交往行动包含以下几个结构要素：

1. **参与者**：交往行动的参与者是互动的主体，他们在平等和自由的基础上进行交流。
2. **语言和符号系统**：交往行动通过语言和符号系统进行，语言和符号是交往行动的中介。
3. **理解**：交往行动的核心目标是实现参与者之间的相互理解，通过交流和对话，个体能够理解他人的观点和意图。
4. **共识**：通过交往行动，个体能够达成共识，形成共同的价值观和行动准则。

```python
class InteractionAct:
    def __init__(self, participants, purpose, norms):
        self.participants = participants
        self.purpose = purpose
        self.norms = norms
    
    def execute(self):
        print(f"执行交往行动：参与者：{self.participants}, 目的：{self.purpose}, 规范：{self.norms}")

class PublicRationality:
    def __init__(self, justice_principles, moral_values, rational_debate):
        self.justice_principles = justice_principles
        self.moral_values = moral_values
        self.rational_debate = rational_debate
    
    def apply(self):
        print(f"应用公共理性：正义原则：{self.justice_principles}, 道德价值：{self.moral_values}, 理性辩论：{self.rational_debate}")

# 创建交往行动实例
interaction = InteractionAct("参与者A、参与者B、参与者C", "讨论社会正义问题", "平等原则、自由原则、合理原则")

# 执行交往行动
interaction.execute()

# 创建公共理性实例
public_rationality = PublicRationality("公平正义原则", "道德价值", "理性辩论")

# 应用公共理性
public_rationality.apply()
```

通过以上Python代码示例，我们可以创建交往行动和公共理性的实例，并分别执行和应用程序中的核心概念。这有助于我们更好地理解和应用哈贝马斯与罗尔斯的交往行动与公共理性理论。
