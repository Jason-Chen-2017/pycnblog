##### 7.5 算法原理举例说明

为了更好地理解算法原理，我们可以通过一个简单的例子来详细讲解。以下是一个计算两个数最大公约数的示例：

```python
# 定义一个函数，用于计算两个数的最大公约数
def calculate_gcd(a, b):
    while b != 0:
        temp = b
        b = a % b
        a = temp
    return a

# 接收用户输入
num1 = int(input("请输入第一个数："))
num2 = int(input("请输入第二个数："))

# 调用函数计算结果
gcd_result = calculate_gcd(num1, num2)

# 输出结果
print(f"两个数的最大公约数为：{gcd_result}")
```

在这个示例中，我们首先定义了一个名为`calculate_gcd`的函数，用于计算两个数的最大公约数。然后，我们接收用户输入的两个数，并调用函数进行计算。最后，我们将结果输出给用户。

这个例子展示了如何使用循环和取模操作来计算最大公约数。具体来说，我们使用一个`while`循环来不断更新$a$ 和 $b$ 的值，直到$b$ 为0为止。此时，$a$ 的值即为最大公约数。
