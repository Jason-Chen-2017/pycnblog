```python
def initialize_chain():
    # 初始化思维链
    chain = []

    return chain

def update_chain(chain, node):
    # 更新思维链
    for neighbor in node.neighbors():
        # 如果邻居节点已经在思维链中，则跳过
        if neighbor in chain:
            continue

        # 将邻居节点添加到思维链中
        chain.append(neighbor)

def thinking_chain_algorithm(network):
    # 初始化思维链
    chain = initialize_chain()

    # 遍历网络中的每个节点
    for node in network.nodes():
        # 更新思维链
        update_chain(chain, node)

    # 返回思维链
    return chain
```

**举例说明**：
这个算法的目的是通过分析网络中的每个节点，将其邻居节点加入到思维链中，从而构建出一条从起点到终点的思维链。
