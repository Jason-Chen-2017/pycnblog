### 4.2.1 自注意力权重计算

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
$$

其中：
- $Q$ 是查询序列（query sequence）
- $K$ 是键序列（key sequence）
- $V$ 是值序列（value sequence）
- $d_k$ 是键向量的维度

### 4.2.2 自我一致性约束

$$
\text{Consistency Constraint} : \frac{1}{T} \sum_{t=1}^{T} \frac{1}{N} \sum_{n=1}^{N} \frac{\exp(A_{tn}) - 1}{\exp(A_{tn}) + 1} = C
$$

其中：
- $A_{tn}$ 是第 $t$ 个时间步第 $n$ 个单元的注意力得分
- $T$ 是时间步的数量
- $N$ 是序列中的单元数量
- $C$ 是一致性系数，用于衡量注意力分配的一致性程度

### 6.2.2 自注意力机制实现

```python
class SelfAttention(nn.Module):
    def __init__(self, d_model):
        super(SelfAttention, self).__init__()
        self.d_model = d_model
        self.query_linear = nn.Linear(d_model, d_model)
        self.key_linear = nn.Linear(d_model, d_model)
        self.value_linear = nn.Linear(d_model, d_model)
        self.out_linear = nn.Linear(d_model, d_model)
        self.dropout = nn.Dropout(p=0.1)

    def forward(self, src, mask=None):
        Q = self.query_linear(src)
        K = self.key_linear(src)
        V = self.value_linear(src)

        attn = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_model)
        if mask is not None:
            attn = attn.masked_fill(mask == 0, float("-inf"))
        attn = F.softmax(attn, dim=-1)
        attn = self.dropout(attn)
        out = torch.matmul(attn, V)
        out = self.out_linear(out)
        return out
```

```python
class ConsistencyConstraint(nn.Module):
    def __init__(self, d_model):
        super(ConsistencyConstraint, self).__init__()
        self.d_model = d_model
        self.constraint_linear = nn.Linear(d_model, d_model)

    def forward(self, attn_weights):
        consistency_loss = torch.mean(torch.abs(attn_weights[:, :-1] - attn_weights[:, 1:]))
        return consistency_loss
```
