```python
def bezier_curve(t, control_points):
    n = len(control_points) - 1
    matrix = np.zeros((n+1, n+1))
    for i in range(n+1):
        for j in range(n+1-i):
            matrix[i][j] = np.math.comb(n, i-j) * (1-t)**(n-i+j) * t**i
    return np.matmul(matrix, control_points)
```

```python
a, b, c, d = symbols('a b c d')

# 四维超立方体的方程
eq1 = Eq(a**2 + b**2 + c**2 + d**2, 1)

eq3 = Eq(c**2, d**2)

# 求解四维超立方体的坐标
solutions = solve((eq1, eq2, eq3), (a, b, c, d))

print("c:", solutions[c])

```

1. **方程 \(a^2 + b^2 + c^2 + d^2 = 1\)**：这个方程定义了四维超立方体的半径为1。
2. **方程 \(a^2 = b^2\)**：这个方程表示四维超立方体的两个相邻面的边长相等。
3. **方程 \(c^2 = d^2\)**：这个方程表示四维超立方体的另外两个相邻面的边长相等。
