#### 4.2 支持向量机算法

支持向量机（SVM）是一种有效的二分类算法，通过找到最佳分隔超平面将数据集划分为两个类别。在智能灌溉系统中，SVM算法可以用于根据环境参数判断是否进行灌溉。

**算法原理**

```python
# 导入相关库
import serial
import time
import requests
from sklearn.ensemble import RandomForestClassifier

# 设置串口参数
ser = serial.Serial('/dev/ttyUSB0', 9600, timeout=1)

# 训练数据集
X = [[20, 25, 50], [30, 30, 60], [40, 35, 70], [50, 40, 80]]
y = ['灌溉', '灌溉', '不灌溉', '灌溉']

# 训练模型
model = RandomForestClassifier()
model.fit(X, y)

# 模型预测
def predict_irrigation(data):
    prediction = model.predict([data])
    return prediction[0]

# 读取传感器数据
def read_sensor_data():
    data = ser.readline().decode('utf-8')
    return float(data)

# 执行灌溉操作
def execute_irrigation(action):
    if action == '灌溉':
        print("执行灌溉操作...")
    else:
        print("不执行灌溉操作...")

# 主程序
while True:
    soil_humidity = read_sensor_data()
    temperature = read_sensor_data()
    sunlight = read_sensor_data()
    
    data = [soil_humidity, temperature, sunlight]
    action = predict_irrigation(data)
    execute_irrigation(action)
    
    time.sleep(60)  # 每隔1分钟执行一次
```
