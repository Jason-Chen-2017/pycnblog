### 微分方程的基本原理

微分方程是数学中描述变量随时间变化的速率的方程。微分方程的基本形式为：

$$ \frac{dy}{dx} = f(x, y) $$

其中，$y$ 是要研究的变量，$x$ 是时间，$f(x, y)$ 是关于 $x$ 和 $y$ 的函数，称为微分方程的导数。

微分方程可以分类为常微分方程和偏微分方程。常微分方程描述了一个变量如何随着另一个变量的变化而变化，而偏微分方程描述了多个变量之间的相互作用。

#### 常微分方程

常微分方程的基本形式为：

$$ \frac{dy}{dx} + p(x)y = q(x) $$

其中，$p(x)$ 和 $q(x)$ 是已知的函数。

解决常微分方程的一般步骤如下：

1. **分离变量**：将方程中的变量分开，得到形式为 $\frac{dy}{y} = f(x)dx$ 的方程。
2. **积分**：对方程两边进行积分，得到 $y = \int f(x)dx + C$ 的形式，其中 $C$ 是积分常数。
3. **求解**：根据边界条件确定常数 $C$ 的值。

#### 偏微分方程

偏微分方程描述了多个变量之间的相互作用，其基本形式为：

$$ \frac{\partial u}{\partial t} = f(x, y, u, \frac{\partial u}{\partial x}, \frac{\partial u}{\partial y}) $$

其中，$u$ 是要研究的变量，$t$ 是时间，$f$ 是关于 $x, y, u$ 及其偏导数的函数。

解决偏微分方程通常需要使用特定的方法，如分离变量法、特征线法或有限元法等。

    参数:

$$

#### 模型解释

该模型表明，婚姻满意度受四个因素共同影响：

- **社交互动频率**：夫妻之间的互动越频繁，婚姻满意度越高。

- **外部因素**：外部压力和干扰会降低婚姻满意度。

$$

```python
import numpy as np
import matplotlib.pyplot as plt

# 微分方程模型参数
k1 = 1
k2 = 0.1
k3 = 0.5
k4 = 0.2

# 初始条件
H0 = 70  # 初始婚姻满意度
S0 = 2   # 初始社交互动频率
I0 = 8   # 初始情感投入
M0 = 20  # 初始外部因素影响

# 微分方程函数
def marriage_satisfaction_eq(H, S, I, M):
    return k1 * S - k2 * H - k3 * I + k4 * M

# 求解微分方程
def solve_diff_eq(H0, S0, I0, M0, time_steps):
    H = [H0]
    S = [S0]
    I = [I0]
    M = [M0]

    for _ in range(time_steps):
        dH_dt = marriage_satisfaction_eq(H[-1], S[-1], I[-1], M[-1])
        H.append(H[-1] + dH_dt)
        S.append(S[-1])
        I.append(I[-1])
        M.append(M[-1])

    return H, S, I, M

# 模拟时间
time_steps = 24 * 60  # 1天的分钟数

# 计算结果
H, S, I, M = solve_diff_eq(H0, S0, I0, M0, time_steps)

# 绘图
plt.plot(H)
plt.xlabel('Time (Minutes)')
plt.ylabel('Marriage Satisfaction')
plt.title('Marriage Satisfaction Over Time')
plt.show()
```
