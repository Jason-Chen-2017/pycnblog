#### 1.1.1 经典概率论的重要性

概率论作为数学的一个重要分支，在各个领域中都有着广泛的应用。从自然科学到社会科学，从工程技术到金融经济，概率论提供了理解和分析不确定性现象的重要工具。在计算机科学中，概率论更是基础性的理论，无论是在算法设计、数据分析，还是在机器学习等领域，概率论都扮演着至关重要的角色。

经典概率论的核心概念，如概率空间、随机变量、概率分布等，为理解和分析复杂系统的行为提供了基础。例如，在机器学习中，概率论被用来建模不确定性和估计模型参数；在算法分析中，概率论帮助评估算法的性能和复杂度。

#### 1.1.2 因果推断的历史背景

因果推断，即从观察数据中推断因果关系，是统计学和哲学中一个古老而复杂的议题。古希腊哲学家亚里士多德曾探讨过因果关系的概念，但直到20世纪初，因果推断才逐渐发展成为一门独立的学科。

20世纪30年代，统计学家罗纳德·费舍尔提出了随机抽样和假设检验的方法，为因果推断提供了统计学上的工具。此后，20世纪50年代，统计学家唐纳德·贝叶斯提出了贝叶斯统计理论，为因果推断提供了另一种重要的方法。

#### 1.1.3 本书概述

本书旨在深入探讨从经典概率论到因果推断之间的联系，通过逐步分析推理，帮助读者理解世界的因果关系。本书分为四个主要部分：

1. **经典概率论**：从基础概念开始，逐步介绍随机变量、概率分布、统计推断等核心概念。
2. **高级概率论**：进一步探讨马尔可夫链、随机过程等高级概率论概念，并讨论其在金融和经济学中的应用。
3. **因果推断**：介绍因果推断的基本概念、框架和算法，包括潜在结果框架和因果模型。
4. **实践与应用**：通过具体案例，展示如何在实际项目中应用因果推断，以及如何处理实际中的数据和分析问题。

本书的目标是不仅让读者掌握概率论和因果推断的理论知识，更希望通过具体实例，让读者理解这些理论在实际问题中的应用，培养解决实际问题的能力。

### 经典概率论

#### 2.1 概率基础

概率论的基本概念是理解和分析随机现象的基石。概率论的核心概念包括概率空间、随机变量、概率分布等。

**概率空间**是一个三元组（Ω，Σ，P），其中Ω是样本空间，包含所有可能的结果；Σ是事件空间，是Ω的一个子集构成的集合；P是概率函数，为每个事件赋予一个概率值。

**随机变量**是概率空间上的函数，将样本空间的每个结果映射到一个实数值。随机变量可以是离散的，也可以是连续的。

**概率分布**描述了随机变量取值的概率分布情况。对于离散随机变量，概率分布通常用概率质量函数（PMF）表示；对于连续随机变量，概率分布通常用概率密度函数（PDF）表示。

#### 2.2 条件概率与独立性

条件概率是概率论中的另一个核心概念。给定事件A和事件B，条件概率P(B|A)表示在事件A发生的条件下，事件B发生的概率。条件概率的计算公式为：

\[ P(B|A) = \frac{P(A \cap B)}{P(A)} \]

独立性是另一个重要的概率概念。两个事件A和B独立，如果其中一个事件的发生不影响另一个事件的概率。独立性可以用以下条件来检验：

\[ P(A \cap B) = P(A)P(B) \]

#### 2.3 贝叶斯定理

贝叶斯定理是概率论中一个极为重要的公式，它提供了在已知某个条件下，更新概率估计的方法。贝叶斯定理的基本形式为：

\[ P(A|B) = \frac{P(B|A)P(A)}{P(B)} \]

贝叶斯定理不仅在概率论中有广泛应用，在统计学习和数据科学中也扮演着核心角色。它为我们提供了一个从先验概率到后验概率的转换方法，帮助我们更好地理解和预测复杂系统的行为。

### 2.4 随机变量与概率分布

随机变量是概率论中的核心概念之一，用于描述随机实验的结果。随机变量可以分为离散随机变量和连续随机变量。

**离散随机变量**的取值是有限的或可数的，其概率分布通常用概率质量函数（PMF）来描述。概率质量函数的定义如下：

\[ P(X = x) = f_X(x) \]

对于离散随机变量，概率分布需要满足以下条件：

1. \( f_X(x) \geq 0 \) 对于所有的 \( x \)。
2. 所有取值的概率之和等于1，即 \( \sum_{x} f_X(x) = 1 \)。

**连续随机变量**的取值是无限的，其概率分布通常用概率密度函数（PDF）来描述。概率密度函数的定义如下：

\[ f_X(x) = P(X \leq x) \]

对于连续随机变量，概率分布需要满足以下条件：

1. \( f_X(x) \geq 0 \) 对于所有的 \( x \)。
2. 概率密度函数的积分在整个实数范围内等于1，即 \( \int_{-\infty}^{\infty} f_X(x) dx = 1 \)。

在概率论中，常见的随机变量分布包括：

1. **均匀分布**：所有取值的概率相等。
2. **二项分布**：在n次独立试验中，成功次数的概率分布。
3. **正态分布**：自然界中最常见的概率分布，许多随机变量都近似服从正态分布。
4. **泊松分布**：描述单位时间内事件发生的次数的概率分布。

### 2.5 中心极限定理

中心极限定理是概率论中一个极为重要的结果，它说明了当样本量足够大时，样本均值的分布会趋近于正态分布。中心极限定理有多个版本，其中最常见的是林德伯格-列维中心极限定理。

**林德伯格-列维中心极限定理**：设 \{X_i\} 是一组独立同分布的随机变量，具有期望 \( \mu \) 和方差 \( \sigma^2 \)。令 \( S_n = \sum_{i=1}^{n} X_i \) 为前 n 个随机变量的和，则 \( \frac{S_n - n\mu}{\sigma\sqrt{n}} \) 的分布趋近于标准正态分布。

中心极限定理的证明通常基于特征函数的方法。特征函数的定义为：

\[ \varphi_X(t) = E[e^{itX}] \]

利用特征函数的性质，可以证明当 \( n \) 趋于无穷大时， \( \frac{1}{\sqrt{n}} S_n \) 的特征函数趋近于标准正态分布的特征函数。

**应用实例**：

1. **抽样分布**：在统计学中，当从总体中随机抽取样本时，样本均值的分布会趋近于正态分布。这使得我们可以使用正态分布的性质来进行假设检验和置信区间的估计。

2. **金融工程**：在金融领域中，许多随机变量（如股票价格）近似服从正态分布，中心极限定理帮助我们理解和预测这些随机变量的行为。

### 2.6 统计推断

统计推断是概率论在统计学中的重要应用，它旨在利用样本数据推断总体特征。统计推断包括两种主要方法：参数估计和假设检验。

**参数估计**是统计推断的一个核心任务，目的是根据样本数据估计总体参数。常见的参数估计方法包括：

1. **点估计**：通过一个单一的数值来估计总体参数，如样本均值作为总体均值的点估计。
2. **区间估计**：给出一个区间，认为总体参数以一定的概率落在该区间内，如置信区间。

**假设检验**是另一个重要的统计推断方法，旨在判断样本数据是否支持某个假设。常见的假设检验方法包括：

1. **单样本检验**：仅基于一个样本数据，判断样本是否来自某个特定的总体。
2. **双样本检验**：基于两个样本数据，判断两个总体是否具有相同的分布。

**错误类型**是统计推断中的一个重要概念，包括：

1. **第一类错误**（α错误）：拒绝了真实的零假设。
2. **第二类错误**（β错误）：接受了错误的零假设。

**统计功效**（1-β）是衡量假设检验有效性的一个指标，表示正确拒绝错误假设的概率。

### 2.7 马尔可夫链

马尔可夫链是一种离散时间随机过程，它具有马尔可夫性质，即当前状态仅取决于前一个状态，而与之前的状态无关。马尔可夫链广泛应用于各种领域，包括物理学、经济学和计算机科学。

**定义**：一个马尔可夫链是一个五元组 \( \{S, \{s_i\}, p_{ij}, i_0\} \)，其中：

- \( S \) 是状态空间。
- \( \{s_i\} \) 是状态集。
- \( p_{ij} = P(S_t = s_j | S_{t-1} = s_i) \) 是转移概率矩阵，表示从状态 \( s_i \) 转移到状态 \( s_j \) 的概率。
- \( i_0 \) 是初始状态。

**性质**：

1. **无记忆性**：当前状态只依赖于前一个状态，而与之前的状态无关。
2. **稳态分布**：当时间趋于无穷时，马尔可夫链的状态分布将趋于一个稳定的分布，称为稳态分布。

**应用**：

1. **排队论**：马尔可夫链用于建模客户到达和服务时间的随机过程，帮助优化排队系统。
2. **金融工程**：马尔可夫链用于分析股票价格的动态变化，预测市场趋势。

### 2.8 随机过程

随机过程是概率论中的一个重要概念，它用于描述时间序列数据的随机行为。随机过程可以是离散的，也可以是连续的。

**定义**：一个随机过程是一个函数 \( X(t) \)，其中 \( t \) 是时间变量，取值在样本空间 \( \Omega \) 上。随机过程通常用 \( \{X(t), t \in T\} \) 表示，其中 \( T \) 是时间空间。

**性质**：

1. **随机性**：随机过程描述的是随机的变量序列。
2. **时间连续性**：随机过程可以是离散的（如时间序列），也可以是连续的（如连续时间随机过程）。

**应用**：

1. **金融数学**：随机过程用于建模股票价格、汇率等金融时间序列数据。
2. **信号处理**：随机过程用于分析随机信号，如噪声信号。

### 2.9 金融和经济学中的随机过程

在金融和经济学中，随机过程被广泛应用于建模和分析金融市场和宏观经济行为。

**Black-Scholes模型**：Black-Scholes模型是一个用于计算欧式期权价格的随机过程模型。该模型基于几何布朗运动，用于描述股票价格的随机波动。

**随机漫步**：随机漫步是一种基本的随机过程模型，用于描述股票价格的随机波动。随机漫步模型假设股票价格的变化是随机的，且未来价格的概率分布与当前价格无关。

**ARMA模型**：自回归移动平均模型（ARMA）是一种用于时间序列分析的经典随机过程模型。ARMA模型通过线性组合过去的观测值和过去的滞后误差项来预测未来值。

### 2.10 因果推断概述

因果推断是一种从数据中提取因果关系的方法，旨在识别和解释变量之间的因果联系。与传统的相关性分析不同，因果推断关注的是因果关系的建立，即确定一个变量的变化是否直接导致了另一个变量的变化。

#### 2.10.1 定义与重要性

因果推断的定义可以从多个角度进行阐述。在哲学领域，因果推断旨在解释为什么一个事件会发生在另一个事件之后；在统计学中，因果推断关注如何从观察数据中推断出因果关系。

因果推断的重要性体现在多个方面。首先，在科学研究中，因果推断帮助我们理解自然现象的本质，发现潜在的影响因素。其次，在政策制定中，因果推断帮助评估政策效果，确保决策基于准确的数据和合理的因果关系。此外，在医学研究中，因果推断用于评估药物的有效性和安全性，为临床决策提供科学依据。

#### 2.10.2 因果关系的层次结构

因果推断中，因果关系通常被划分为多个层次，形成一种层次结构。这种结构有助于我们系统地分析和理解复杂系统的因果关系。

1. **相关性**：相关性是因果关系的第一层次，描述的是两个变量之间的线性或非线性关系。相关性分析是因果推断的基础，但相关性本身并不足以证明因果关系。

2. **无因果关系**：无因果关系指的是两个变量之间没有因果关系，即一个变量的变化不会导致另一个变量的变化。

3. **关联性**：关联性是介于相关性和无因果关系之间的层次，描述的是两个变量之间的某种关联关系，但并不一定是因果关系。

4. **因果关系**：因果关系是指一个变量的变化直接导致了另一个变量的变化。因果推断的核心任务就是从数据中识别出这种因果关系。

5. **强因果关系**：强因果关系指的是一个变量的变化不仅在统计上显著，而且在生物学、物理学等实际意义上也是显著的。这种因果关系通常需要通过实验或严格的数据分析来验证。

6. **间接因果关系**：间接因果关系是指一个变量的变化通过多个中间变量间接导致了另一个变量的变化。识别间接因果关系是因果推断中的一个重要挑战。

#### 2.10.3 因果推断的挑战

因果推断在实际应用中面临着多种挑战。首先，数据的不完整性和噪声会严重影响因果推断的准确性。其次，因果关系的复杂性使得直接从数据中推断因果关系变得困难。此外，因果推断还面临着外部干扰和多重共线性等问题。

为了解决这些挑战，因果推断领域提出了一系列的方法和技术，包括：

1. **随机对照试验**：通过随机对照试验（RCT）建立因果关系是最直接和可靠的方法。RCT通过随机分配实验组和对照组，消除外部干扰，从而确保因果关系的准确性。

2. **因果模型**：因果模型是因果推断的重要工具，通过构建因果模型，我们可以更系统地分析和理解复杂系统的因果关系。常见的因果模型包括潜在结果框架和因果图模型。

3. **机器学习方法**：机器学习算法，如深度学习和强化学习，在因果推断中也发挥了重要作用。通过训练大规模数据集，机器学习算法可以识别出潜在的因果关系，为因果推断提供支持。

4. **因果推断算法**：因果推断算法是专门为解决因果推断问题而设计的方法，如倾向得分匹配、工具变量法和因果图模型等。这些算法通过优化数据和模型，提高因果推断的准确性和可靠性。

### 潜在结果框架

潜在结果框架是因果推断理论中的一个核心概念，它提供了一种系统的方法来理解和分析因果关系。潜在结果框架由三个主要部分组成：潜在结果、随机干扰和因果关系。

#### 3.1 潜在结果

潜在结果框架的核心思想是，每个个体在特定干预下会有一个潜在的结果。潜在结果是指在某种干预下，个体可能获得的不同结果。例如，在医疗研究中，潜在结果可以是患者接受药物治疗后的健康状态。

潜在结果的表示通常采用潜在结果函数 \( Y(t_i, A_i) \)，其中 \( t_i \) 是干预时间点，\( A_i \) 是干预措施。对于每个时间点 \( t_i \)，个体 \( i \) 在干预 \( A_i \) 下会有一个潜在结果 \( Y(t_i, A_i) \)。

#### 3.2 随机干扰

随机干扰是潜在结果框架中的另一个重要概念。随机干扰指的是那些无法通过干预控制的因素，如基因、环境和其他随机事件。这些随机干扰会导致个体在相同干预下产生不同的潜在结果。

随机干扰可以用随机变量 \( \varepsilon_i \) 来表示，它与干预 \( A_i \) 和潜在结果 \( Y(t_i, A_i) \) 之间的关系可以用 \( Y(t_i, A_i) = X_i(A_i) + \varepsilon_i \) 表示，其中 \( X_i(A_i) \) 表示在干预 \( A_i \) 下的可观察结果。

#### 3.3 因果关系

因果关系是潜在结果框架中的核心概念，它描述了一个变量对另一个变量的影响。在潜在结果框架中，因果关系可以通过比较不同干预下的潜在结果来识别。

具体来说，因果关系可以用 \( Y(t_i, A_i) = X_i(A_i) + \varepsilon_i \) 来表示，其中 \( X_i(A_i) \) 是在干预 \( A_i \) 下可观察的结果，\( \varepsilon_i \) 是随机干扰。

#### 3.4 随机对照试验

随机对照试验（RCT）是建立因果关系的一种最直接和有效的方法。在RCT中，参与者被随机分配到实验组或对照组，实验组接受干预，对照组不接受干预。

通过RCT，我们可以比较实验组和对照组的潜在结果，从而识别出干预对结果的影响。具体来说，假设 \( Y(t_i, A_i) = X_i(A_i) + \varepsilon_i \)，其中 \( A_i \) 为随机分配的干预措施，那么在RCT中，我们可以得到：

1. 实验组的结果 \( Y(t_i, A) = X(t_i, A) + \varepsilon_i \)
2. 对照组的结果 \( Y(t_i, \bar{A}) = X(t_i, \bar{A}) + \varepsilon_i \)

通过比较实验组和对照组的结果，我们可以计算出干预的效果，从而建立因果关系。

#### 3.5 ignorability假设

在潜在结果框架中，ignorability假设是一个重要的统计假设，它确保了我们能够从实验结果中正确推断因果关系。ignorability假设指的是，干预分配与潜在结果之间没有关联，即：

\[ P(A_i = A | Y(t_i, A_i)) = P(A_i = A) \]

ignorability假设确保了干预是随机分配的，从而使得我们可以将实验结果直接应用于总体，推断总体中的因果关系。

### 结构因果模型

结构因果模型（Structural Causal Models, SCM）是因果推断中的一个核心概念，它提供了一种形式化的方法来描述和分析因果关系。结构因果模型通过图形化表示变量之间的因果关系，帮助我们更清晰地理解复杂系统的因果结构。

#### 4.1 定义

结构因果模型是由三个核心部分组成的图形化模型：

1. **潜在变量**：表示系统中潜在的、不可直接观测的变量。
2. **直接因果效应**：表示一个变量对另一个变量的直接影响。
3. **混淆变量**：表示可能影响因果关系的其他变量。

结构因果模型通常用图表示，称为因果图或因果图模型。因果图中的节点表示潜在变量，有向边表示直接因果效应，无向边表示混淆变量。

#### 4.2 构建结构因果模型

构建结构因果模型通常包括以下步骤：

1. **识别潜在变量**：首先，我们需要识别出系统中潜在的变量，这些变量是因果关系的基本单元。
2. **确定直接因果效应**：接下来，我们需要确定每个潜在变量之间的直接因果效应。这通常需要依赖于领域知识和实验数据。
3. **考虑混淆变量**：最后，我们需要考虑可能影响因果关系的混淆变量，并确保这些变量在模型中得到适当的表示。

#### 4.3 因果推断在结构因果模型中的应用

结构因果模型为因果推断提供了一种形式化的方法。通过结构因果模型，我们可以利用实验数据推断因果关系。具体来说，有以下几种方法：

1. **直接推断**：通过直接观察模型中的因果效应，我们可以推断出潜在的因果关系。例如，如果模型显示变量 \( X \) 直接影响变量 \( Y \)，那么我们可以推断 \( X \) 是 \( Y \) 的原因。
2. **模型拟合**：我们可以通过拟合数据到结构因果模型，评估模型的合理性，从而推断因果关系。如果模型拟合良好，那么我们可以认为模型中的因果关系是可靠的。
3. **模型比较**：通过比较不同结构因果模型的拟合度，我们可以识别出最合理的因果关系。这种方法通常用于处理复杂系统中的多重因果关系。

### 因果推断算法

因果推断算法是用于从数据中推断因果关系的方法和技术。这些算法基于概率论、统计学和机器学习等多个领域，旨在解决实际中的因果推断问题。以下介绍几种常见的因果推断算法：

#### 4.4.1 倾向得分匹配

倾向得分匹配（Propensity Score Matching）是一种基于概率的因果推断方法，旨在解决观测数据中的选择偏差问题。倾向得分匹配的基本思想是，通过比较具有相似倾向得分的个体，来消除选择偏差，从而估计因果关系。

**定义**：倾向得分是一个个体接受特定干预的概率，通常用 \( \pi_i(A) \) 表示，计算公式为：

\[ \pi_i(A) = \frac{P(A_i = A | X_i)}{P(A_i = A | X_i)} \]

其中，\( A_i \) 是个体 \( i \) 接受的干预，\( X_i \) 是其他相关特征。

**步骤**：

1. **计算倾向得分**：对于每个个体，计算其倾向得分 \( \pi_i(A) \)。
2. **匹配个体**：将具有相似倾向得分的个体配对，形成匹配组。
3. **估计因果关系**：在匹配组中，比较干预组和对照组的结果，估计因果关系。

**优势**：倾向得分匹配能够有效地消除选择偏差，提高因果估计的准确性。

**局限性**：倾向得分匹配方法依赖于倾向得分的准确性，并且可能无法处理复杂的因果关系。

#### 4.4.2 工具变量法

工具变量法（Instrumental Variables, IV）是一种用于解决因果推断中内生性问题的方法。内生性问题指的是变量之间可能存在的反向因果关系或多重共线性，导致传统回归分析无法准确估计因果关系。

**定义**：工具变量是一个与干预变量相关，但与结果变量不相关的变量，通常用 \( Z_i \) 表示。

**步骤**：

1. **选择工具变量**：选择一个或多个工具变量 \( Z_i \)，满足与干预变量 \( A_i \) 相关，但与结果变量 \( Y_i \) 不相关。
2. **构建回归模型**：使用工具变量 \( Z_i \) 和其他相关特征 \( X_i \)，构建回归模型 \( Y_i = \alpha_0 + \alpha_1A_i + \alpha_2X_i + \varepsilon_i \)。
3. **估计因果关系**：通过回归模型的参数估计，估计干预变量 \( A_i \) 对结果变量 \( Y_i \) 的因果关系。

**优势**：工具变量法能够处理内生性问题，提高因果估计的准确性。

**局限性**：选择合适的工具变量是工具变量法的难点，且工具变量法可能无法处理复杂的因果关系。

### 4.4.3 图模型

图模型（Graphical Models）是一种用于表示变量之间因果关系的图形化方法，包括因果图（Causal Graphs）和贝叶斯网（Bayesian Networks）。图模型提供了一种形式化的方法，用于分析和推断因果关系。

**因果图**：

因果图是一种表示变量之间因果关系的有向图，其中节点表示变量，有向边表示因果关系。因果图通过结构方程模型（Structural Equations Models, SEM）来描述变量之间的因果关系。

**贝叶斯网**：

贝叶斯网是一种表示变量之间概率依赖关系的无向图，其中节点表示变量，边表示变量之间的概率依赖。贝叶斯网通过条件概率表（Conditional Probability Tables, CPTs）来描述变量之间的概率关系。

**优势**：图模型能够清晰地表示变量之间的因果关系，便于分析和推断。此外，图模型还可以用于处理复杂系统中的多重因果关系。

**局限性**：图模型依赖于领域知识和先验假设，且可能无法处理高度复杂的因果关系。

### 4.4.4 交叉验证

交叉验证（Cross-Validation）是一种用于评估因果推断算法性能的方法。交叉验证通过将数据集划分为训练集和验证集，多次训练和验证模型，评估模型在未知数据上的表现。

**步骤**：

1. **数据划分**：将数据集划分为训练集和验证集。
2. **模型训练**：使用训练集训练模型。
3. **模型验证**：使用验证集评估模型的性能，包括因果估计的准确性和稳定性。
4. **重复迭代**：多次重复上述步骤，选择性能最佳的模型。

**优势**：交叉验证能够全面评估模型的性能，减少模型过拟合和偏差。

**局限性**：交叉验证可能需要大量计算资源和时间，且可能无法处理高度复杂的数据集。

### 6.2 源代码实现

以下是一个简单的因果推断项目的源代码实现。该项目旨在分析某个城市居民的身高与体重之间的关系，并使用因果推断方法评估这一关系的因果关系。

```python
# 导入所需的库
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
import pymc3 as pm
import matplotlib.pyplot as plt
from graphviz import Digraph

# 加载数据
data = pd.read_csv('data.csv')

# 数据预处理
data['Height'] = pd.to_numeric(data['Height'])
data['Weight'] = pd.to_numeric(data['Weight'])

# 划分特征和标签
X = data[['Height']]
y = data['Weight']

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 训练随机森林模型
rf = RandomForestClassifier(n_estimators=100, random_state=42)
rf.fit(X_train, y_train)

# 预测测试集
y_pred = rf.predict(X_test)

# 计算预测误差
error = np.mean((y_test - y_pred)**2)

# 打印预测误差
print(f'Mean Squared Error: {error:.3f}')

# 使用PyMC3进行因果推断
with pm.Model() as model:
    # 定义潜变量
    alpha = pm.Normal('alpha', mu=0, sigma=10)
    beta = pm.Normal('beta', mu=0, sigma=10)
    sigma = pm.HalfNormal('sigma', sigma=1)

    # 定义潜在结果
    weight潜力 = pm.Deterministic('weight潜力', alpha + beta * X_test)

    # 定义观测数据
    obs = pm.Normal('obs', mu=weight潜力, sigma=sigma, observed=y_test)

    # 使用PyMC3进行推理
    trace = pm.sample(2000, tune=1000, return_inferencedata=True)

# 绘制因果图
dot = Digraph(comment='Causal Model')
dot.node('alpha', 'Alpha')
dot.node('beta', 'Beta')
dot.node('X', 'Height')
dot.node('weight潜力', 'Potential Weight')
dot.node('obs', 'Observed Weight')

dot.edge('alpha', 'weight潜力')
dot.edge('beta', 'weight潜力')
dot.edge('X', 'weight潜力')
dot.edge('weight潜力', 'obs')

dot.render('causal_model.dot', view=True)

# 打印PyMC3推理结果
print(pm.summary(trace))
```
