#### 决策树

决策树是一种基于规则的预测模型。它由多个内部节点和叶节点组成。每个内部节点表示一个特征，每个叶节点表示一个预测结果。以下是一个简单的决策树伪代码：

```python
# 构建决策树
def build_tree(data, target_attribute):
    # 如果所有数据都属于同一类，返回该类的名称
    if all_data_same_class(data, target_attribute):
        return data[target_attribute].mode()

    # 如果没有更多特征，返回多数类
    if no_more_attributes(data):
        return majority_class(data, target_attribute)

    # 选择最优特征
    best_attribute = select_best_attribute(data)

    # 创建内部节点
    node = Node(best_attribute)

    # 划分数据
    for value in data[best_attribute].unique():
        sub_data = data[data[best_attribute] == value]

        # 递归构建子树
        node.children[value] = build_tree(sub_data, target_attribute)

    return node

# 预测
def predict(tree, sample):
    if is_leaf_node(tree):
        return tree.label

    attribute = tree.best_attribute
    value = sample[attribute]

    return predict(tree.children[value], sample)
```

#### 随机森林

随机森林是一种集成学习方法，它由多个决策树组成。每个决策树对数据进行分类或回归，然后通过投票或平均值来得出最终结果。以下是一个简单的随机森林伪代码：

```python
# 构建随机森林
def build_random_forest(data, target_attribute, num_trees):
    forest = []
    for _ in range(num_trees):
        tree = build_tree(data, target_attribute)
        forest.append(tree)

    return forest

# 预测
def predict(forest, sample):
    predictions = []
    for tree in forest:
        prediction = predict(tree, sample)
        predictions.append(prediction)

    if all(predictions) == "class1":
        return "class1"
    else:
        return "class2"
```
