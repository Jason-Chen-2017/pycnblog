#### 第1章：问题背景

在探讨数学与自然界的镜像对称与旋转对称之前，我们需要先了解这两个对称性概念的定义及其重要性。

**镜像对称**指的是一个图形相对于某条直线（称为镜像轴）翻转后能够与原图形完全重合。这种对称性在自然界中非常常见，例如人类的面部结构、蝴蝶的翅膀图案等。镜像对称在物理学中也有重要应用，例如晶体结构中的平移对称性和一些粒子的排列方式。

**旋转对称**则是指一个图形绕某个点旋转一定角度后能够与原图形重合。这种对称性在自然界中的表现更加多样，如旋转对称的花瓣、星形图案以及自然界中的螺旋结构（如海螺壳、植物螺旋生长等）。

镜像对称与旋转对称在科学和工程领域都具有重要意义。例如，它们在分子生物学、晶体学、光学、电子学和计算机科学中都有广泛应用。例如，在计算机图形学中，利用镜像对称与旋转对称可以高效地渲染图像和动画；在电子学中，旋转对称可以帮助设计更加稳定的电路元件。

#### 第2章：核心概念

为了更好地理解镜像对称与旋转对称，我们需要明确它们的基本概念及其在数学中的表达。

**镜像对称的基本概念**：设一个平面上的图形G关于直线L镜像对称，如果将G沿直线L翻转后得到的新图形G'与原图形G完全重合。数学上，我们可以用矩阵乘法来表示这个翻转过程，例如：

$$
G' = A G
$$

其中，矩阵$A$是关于直线L的镜像变换矩阵。

**旋转对称的基本概念**：设一个平面上的图形G关于点O旋转θ度后得到的新图形G'与原图形G完全重合，则G具有旋转对称性。数学上，我们可以用旋转矩阵来表示这个旋转过程：

$$
G' = R(\theta) G
$$

其中，$R(\theta)$是旋转矩阵，其形式为：

$$
R(\theta) = 
\begin{bmatrix}
\cos \theta & -\sin \theta \\
\sin \theta & \cos \theta
\end{bmatrix}
$$

镜像对称与旋转对称在数学中有着广泛的应用，比如在几何图形的变换、方程的求解、群论等领域。

import numpy as np
import cv2

def is_mirror_symmetric(graph):
    # 假设图形已经转化为矩阵形式
    for i in range(graph.shape[0]):
        for j in range(graph.shape[1]):
            if not np.array_equal(graph[i][j], graph[graph.shape[0]-1-i][graph.shape[1]-1-j]):
                return False
    return True

def is_rotational_symmetric(graph, angle):
    # 假设图形已经转化为矩阵形式
    for i in range(graph.shape[0]):
        for j in range(graph.shape[1]):
            rotated_point = rotate_point((i, j), angle)
            if not np.array_equal(graph[i][j], rotated_point):
                return False
    return True

def rotate_point(point, angle):
    angle_rad = np.radians(angle)
    cos_angle = np.cos(angle_rad)
    sin_angle = np.sin(angle_rad)
    rotated_point = (
        point[0] * cos_angle - point[1] * sin_angle,
        point[0] * sin_angle + point[1] * cos_angle
    )
    return rotated_point

# 示例
graph = np.array([[1, 0, 1], [1, 1, 1], [1, 0, 1]])
print(is_mirror_symmetric(graph))  # 输出：True
print(is_rotational_symmetric(graph, 90))  # 输出：True

import numpy as np
import cv2

def is_mirror_symmetric(image):
    # 转为灰度图
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    # 翻转图像
    flip = cv2.flip(gray, 1)
    # 计算汉明距离
    distance = cv2.norm(gray, flip)
    # 判断是否小于阈值
    threshold = 10
    return distance < threshold

def is_rotational_symmetric(image, angles):
    for angle in angles:
        # 旋转图像
        M = cv2.getRotationMatrix2D((image.shape[1] // 2, image.shape[0] // 2), angle, 1)
        rotated = cv2.warpAffine(image, M, (image.shape[1], image.shape[0]))
        # 计算汉明距离
        distance = cv2.norm(image, rotated)
        # 判断是否小于阈值
        threshold = 10
        if distance < threshold:
            return True
    return False

# 测试图像
image = cv2.imread('test_image.jpg')

# 镜像对称检测
print(is_mirror_symmetric(image))

# 旋转对称检测
print(is_rotational_symmetric(image, [0, 90, 180, 270]))
