**4.2 贝叶斯推断的Python代码实现**

```python
import numpy as np
import scipy.stats as st

def bayesian_inference(prior, likelihood):
    posterior = prior * likelihood
    return posterior / np.sum(posterior)

# 示例
prior = np.array([0.5, 0.5])
likelihood = np.array([0.8, 0.2])
posterior = bayesian_inference(prior, likelihood)
print(posterior)
```

**4.3 数学模型和公式**

贝叶斯推断的数学模型基于贝叶斯定理，其核心公式如下：

$$
P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}
$$

其中，\(P(A|B)\) 是后验概率，\(P(B|A)\) 是似然函数，\(P(A)\) 是先验概率，\(P(B)\) 是边缘概率。

**4.4 举例说明**

假设我们有一个二项分布的例子，其中成功的概率为0.5，我们观察到了10次成功。通过贝叶斯推断，我们可以估计成功概率的后验分布。

```python
# 二项分布的先验概率
prior = st.binom.pmf(10, 0.5)

# 二项分布的似然函数
likelihood = st.binom.pmf(10, 0.5)

# 贝叶斯推断
posterior = bayesian_inference(prior, likelihood)

print(posterior)
```

通过上述代码，我们可以得到后验概率分布，从而对成功概率进行估计。

在引力波宇宙学中，常用的贝叶斯推断模型包括：

3. **泊松分布模型**：适用于事件发生次数的参数估计。

**5.1.1 二项分布模型**

二项分布模型描述了在固定次数的试验中成功次数的概率分布。其概率质量函数（PMF）为：

$$
P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}
$$

其中，\(n\) 是试验次数，\(k\) 是成功次数，\(p\) 是成功概率。

**5.1.2 正态分布模型**

正态分布模型描述了连续随机变量的概率分布。其概率密度函数（PDF）为：

$$
f(x|\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

其中，\(\mu\) 是均值，\(\sigma^2\) 是方差。

**5.1.3 泊松分布模型**

泊松分布模型描述了在固定时间内事件发生次数的概率分布。其概率质量函数（PMF）为：

$$
P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}
$$

其中，\(\lambda\) 是事件发生率。

**5.2.1 二项分布模型应用**

**先验概率**：

假设先验概率为均匀分布，即 \(p \sim U(0,1)\)。

**似然函数**：

似然函数为：

$$

$$

**后验概率**：

后验概率为：

$$
P(p|X=5) = \frac{L(p)}{C} = \frac{\binom{10}{5} p^5 (1-p)^5}{\int_0^1 \binom{10}{5} p^5 (1-p)^5 dp}
$$

通过贝叶斯推断，我们可以得到成功概率的后验分布，进而进行参数估计。
