#### 2.1.1 Introduction to Topology

Topology is a branch of mathematics that deals with the properties of spaces that are preserved under continuous deformations. These deformations include stretching, bending, and twisting, but they do not involve tearing or gluing. Topology provides a way to understand and classify spaces based on their connectivity and shape, without considering distances or angles. This makes topology a powerful tool for studying the large-scale structure of the universe, as it allows us to focus on the global properties of space-time that are not affected by local changes.

In the context of cosmic topological phase transitions, topology is crucial for understanding the changes in the universe's structure that occur during these transitions. For example, one of the key features of a topological phase transition is the formation of topological defects, which are regions where the global structure of space-time is not smoothly connected. These defects include cosmic strings, which are one-dimensional lines, and domain walls, which are two-dimensional surfaces. By studying topology, we can identify and characterize these defects, providing insights into their properties and how they affect the universe's evolution.

**Basic Concepts in Topology:**

1. **Open Sets:** An open set is a subset of a topological space that contains a neighborhood of each of its points. In other words, for every point in an open set, there exists a small ball (or neighborhood) around that point that is entirely contained within the open set.

2. **Closed Sets:** A closed set is a subset of a topological space that contains all its limit points. A limit point of a set is a point such that every neighborhood around it contains at least one point from the set other than itself.

3. **Connectedness:** A topological space is connected if it cannot be divided into two disjoint, nonempty open sets. Intuitively, a connected space is one that cannot be split into two separate pieces without breaking the continuity of its structure.

4. **Path-Connectedness:** A topological space is path-connected if any two points in the space can be connected by a continuous path. This means that there is a continuous function that maps a line segment (or interval) into the space, with one endpoint being the starting point and the other being the endpoint.

5. **Compactness:** A topological space is compact if every open cover of the space has a finite subcover. Compactness is an important property in topology, as it ensures that certain operations and analyses are well-behaved and can be performed within a finite amount of time.

**Topological Spaces and Continuous Functions:**

A topological space is a set equipped with a topology, which is a collection of subsets (open sets) that satisfy certain axioms. These open sets define how points in the space can be separated and how the space can be divided into smaller regions.

A continuous function between two topological spaces is a function that preserves the topological properties of the spaces. Formally, a function f from space X to space Y is continuous if the preimage of every open set in Y is open in X. This means that continuous functions do not disrupt the connectivity and continuity of the spaces they map between.

#### 2.1.2 Phase Transitions in Cosmology

Phase transitions in cosmology are pivotal phenomena that have shaped the evolution of the universe from its early moments to the present. These transitions occur when the universe undergoes significant changes in its fundamental properties, such as its structure, symmetry, and energy distribution. In cosmology, phase transitions are often associated with critical points in the universe's evolution, where small perturbations can trigger profound changes. Understanding the nature and dynamics of these phase transitions is essential for unraveling the mysteries of the universe's formation and evolution.

**Types of Phase Transitions in Cosmology:**

1. **Symmetry Breaking Phase Transitions:** One of the most important types of phase transitions in cosmology is symmetry breaking. In physics, a phase transition often involves a symmetry breaking event, where a system transitions from a state with high symmetry to a state with lower symmetry. In the context of the universe, symmetry breaking occurs when the initial state of the universe, which may have high spatial or temporal symmetry, evolves into a state with lower symmetry. This process is thought to be responsible for the generation of mass and the structure of the universe. For example, the early universe is believed to have undergone a symmetry breaking phase transition that gave rise to the Higgs mechanism, which is responsible for giving particles mass.

2. **First-order Phase Transitions:** First-order phase transitions are characterized by a discontinuous change in the properties of the system, often accompanied by the release of latent heat. In cosmology, first-order phase transitions can lead to the formation of topological defects, such as cosmic strings and domain walls. These defects are regions where the symmetry of the universe is broken in a way that creates a discontinuity in the space-time fabric. The formation of cosmic strings is believed to be associated with the early universe's first-order phase transition, where a high-energy state transitions into a lower-energy state, creating one-dimensional defects.

3. **Second-order Phase Transitions:** Second-order phase transitions are more gradual than first-order transitions and are characterized by a continuous change in the system's properties. These transitions are often associated with a divergence in the correlation length, which indicates that the system becomes more homogeneous as it transitions through the critical point. In cosmology, second-order phase transitions are thought to be responsible for the inflation of the universe. Inflation is a rapid expansion of the universe in its early moments, which is believed to have smoothed out the universe's initial irregularities and set the stage for the formation of large-scale structures.

**Significance of Phase Transitions in Cosmology:**

1. **Structure Formation:** Phase transitions play a crucial role in the formation of the universe's large-scale structure. The formation of topological defects, such as cosmic strings, can seed the growth of structures like galaxies and clusters of galaxies. These defects act as gravitational seeds that attract matter and give rise to the complex structures we observe today.

2. **Mass Generation:** Symmetry breaking phase transitions are believed to be responsible for the generation of mass in the universe. The breaking of symmetries in the early universe allows the Higgs field to acquire a non-zero vacuum expectation value, which is essential for giving particles mass.

3. **Cosmic Inflation:** The inflationary phase transition is one of the most important discoveries in modern cosmology. Inflation explains the observed flatness and homogeneity of the universe, as well as the origin of the cosmic microwave background radiation and the large-scale structure. Inflation is thought to have occurred shortly after the Big Bang and expanded the universe by a factor of at least 100 orders of magnitude in a fraction of a second.

4. **Energy Release:** First-order phase transitions in the early universe release a significant amount of energy in the form of radiation and particles. This energy release can have profound implications for the thermal history of the universe and the formation of the first generations of stars and galaxies.

**Mathematical Models of Phase Transitions:**

Mathematical models are essential for understanding the dynamics of phase transitions in cosmology. These models often involve complex systems of differential equations that describe the evolution of the universe's state variables, such as density, temperature, and symmetry. By solving these equations, researchers can make predictions about the behavior of the universe during and after phase transitions.

2. **Renormalization Group (RG) Methods:** Renormalization group methods are used to study the behavior of systems near critical points. These methods allow researchers to scale the system down to lower energies or length scales, where the critical behavior can be studied more easily. RG methods are particularly useful for understanding the universality classes of phase transitions and how different systems behave near critical points.

These simulations allow researchers to study the behavior of the universe under different conditions and to test the predictions of theoretical models against observational data.

**Lattice Boltzmann Method (LBM)**

LBM is a particle-based method that models fluid flow by simulating the distribution function of particles on a discrete lattice. The core idea behind LBM is to use a set of discrete velocity directions and a distribution function to approximate the continuum Navier-Stokes equations. The distribution function $f(\mathbf{x}, \mathbf{v}, t)$ represents the probability of finding a particle at position $\mathbf{x}$ with velocity $\mathbf{v}$ at time $t$.

The LBM is based on the following steps:

1. **Stream Step:** In the stream step, the distribution function is propagated along the discrete velocity directions. This step ensures that particles move according to the given velocity distribution.

2. **Collide Step:** In the collide step, the distribution function is updated to ensure that the system satisfies the conservation laws (mass, momentum, and energy). This step involves a relaxation process where the distribution function is adjusted to a local equilibrium distribution.

**Mathematical Description**

The LBM is described by the following equations:

1. **Stream Step:**
   $$
   f_f(\mathbf{x} + \mathbf{v}_i \Delta t, \mathbf{v}_i, t + \Delta t) = f_i(\mathbf{x}, \mathbf{v}_i, t)
   $$
   where $\mathbf{v}_i$ represents the discrete velocity direction and $\Delta t$ is the time step.

2. **Collide Step:**
   $$
   f_i(\mathbf{x}, \mathbf{v}_i, t + \Delta t) = f_i^{\text{eq}}(\mathbf{x}, \mathbf{v}_i, t) + \omega_i (f_i(\mathbf{x}, \mathbf{v}_i, t) - f_i^{\text{eq}}(\mathbf{x}, \mathbf{v}_i, t))
   $$
   where $f_i^{\text{eq}}$ is the local equilibrium distribution, $\omega_i$ is the relaxation time, and $f_i$ is the distribution function.

**Python Code Implementation**

Here is a Python code implementation of the LBM for a 2D grid:

```python

import matplotlib.pyplot as plt

# Parameters
L = 100        # Grid size
N = L**2       # Number of grid points
Vx, Vy = 0.2, 0.3  # Velocity components
delta_t = 0.01   # Time step
omega = 0.5     # Relaxation time

# Initial condition (均匀分布)
f = np.ones((L, L)) / N

# Stream step
def stream_step(f):
    f_stream = np.zeros((L, L))
    for i in range(L):
        for j in range(L):
            f_stream[i, j] = f[i, j]
            for vx in [-1, 0, 1]:
                for vy in [-1, 0, 1]:
                    x = i + vx * delta_t
                    y = j + vy * delta_t
                    if 0 <= x < L and 0 <= y < L:
                        f_stream[i, j] += f[x, y]
    return f_stream

# Collide step
def collide_step(f):
    f_collide = np.zeros((L, L))
    for i in range(L):
        for j in range(L):
            f_collide[i, j] = f[i, j]
            for vx in [-1, 0, 1]:
                for vy in [-1, 0, 1]:
                    x = i + vx * delta_t
                    y = j + vy * delta_t
                    if 0 <= x < L and 0 <= y < L:
                        f_collide[i, j] += (omega / delta_t) * (1 / N) * (f[i, j] - 1)
    return f_collide

# Main simulation loop
for _ in range(100):
    f = stream_step(f)
    f = collide_step(f)

# Visualization
plt.imshow(f, cmap='hot', interpolation='nearest')
plt.colorbar()
plt.show()
```

2. **Stream Step:** The `stream_step` function propagates the distribution function along the discrete velocity directions. It updates the distribution function by moving particles according to the given velocity components.

3. **Collide Step:** The `collide_step` function updates the distribution function by relaxing it to the local equilibrium distribution. The relaxation factor $\omega$ controls the speed of relaxation.

4. **Simulation Loop:** The simulation loop runs for a specified number of iterations, updating the distribution function at each step using the stream and collide steps.

5. **Visualization:** The final distribution function is visualized using a heat map, showing the concentration of particles at each grid point.
