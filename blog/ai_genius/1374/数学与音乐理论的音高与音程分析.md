```python
    return abs(frequency1 - frequency2)

def main():
    frequency = 440  # A4的频率
    speed_of_sound = 343  # 声速
```

### 算法原理的数学模型和公式

- **频率与波长关系**：$$ f = \frac{c}{\lambda} $$
  其中，\( f \) 是频率（Hz），\( c \) 是声速（m/s），\( \lambda \) 是波长（m）。

### 详细讲解

**频率**是音高的量化表示，它决定了音的高低。在物理学中，频率指的是声波在单位时间内振动的次数，通常以赫兹（Hz）为单位。

**波长**是声波在传播过程中两次相邻波峰或波谷之间的距离。声速是声波在介质中传播的速度，通常在空气中约为343米/秒。

音程描述了两个音之间的高低关系。音程的大小取决于两个音的频率差。例如，一个C5（频率880 Hz）和一个A4（频率440 Hz）之间的音程是三度，因为它们的频率差是A4的两倍。

以下是一个简单的Python代码示例，用于计算音高、波长和音程：

```python
import math

# 声速（空气中）
SOUND_SPEED = 343

def calculate_frequency(wavelength):
    return SOUND_SPEED / wavelength

def convert_wavelength(frequency):
    return SOUND_SPEED / frequency

def calculate_interval(frequency1, frequency2):
    return abs(frequency1 - frequency2)

# 示例：计算A4（440 Hz）的波长和与C5（880 Hz）的音程
a4_frequency = 440
c5_frequency = 880

a4_wavelength = convert_wavelength(a4_frequency)
c5_wavelength = convert_wavelength(c5_frequency)

a4_c5_interval = calculate_interval(a4_frequency, c5_frequency)

print(f"A4 Wavelength: {a4_wavelength} meters")
print(f"C5 Wavelength: {c5_wavelength} meters")
print(f"A4-C5 Interval: {a4_c5_interval} Hz")
```

在这个示例中，我们首先定义了声速常量`SOUND_SPEED`。然后，我们定义了三个函数：`calculate_frequency`用于计算给定波长的频率，`convert_wavelength`用于计算给定频率的波长，`calculate_interval`用于计算两个频率之间的音程。

我们使用A4（频率440 Hz）和C5（频率880 Hz）作为示例。首先，我们计算A4的波长，然后计算C5的波长，最后计算A4和C5之间的音程。输出结果如下：

```

C5 Wavelength: 0.390625 meters
A4-C5 Interval: 440.0 Hz
```

```python
import numpy as np
import matplotlib.pyplot as plt

# 声速（空气中）
SOUND_SPEED = 343

def calculate_frequency(wavelength):
    return SOUND_SPEED / wavelength

def convert_wavelength(frequency):
    return SOUND_SPEED / frequency

def calculate_interval(frequency1, frequency2):
    return abs(frequency1 - frequency2)

def plot_waveforms(frequency1, frequency2):
    t = np.linspace(0, 1, 1000)
    waveform1 = np.sin(2 * np.pi * frequency1 * t)
    waveform2 = np.sin(2 * np.pi * frequency2 * t)

    plt.figure()
    plt.plot(t, waveform1, label=f'Frequency: {frequency1} Hz')
    plt.plot(t, waveform2, label=f'Frequency: {frequency2} Hz')
    plt.legend()
    plt.show()

# 示例：计算A4（440 Hz）和C5（880 Hz）的波长和音程
a4_frequency = 440
c5_frequency = 880

a4_wavelength = convert_wavelength(a4_frequency)
c5_wavelength = convert_wavelength(c5_frequency)

a4_c5_interval = calculate_interval(a4_frequency, c5_frequency)

print(f"A4 Wavelength: {a4_wavelength} meters")
print(f"C5 Wavelength: {c5_wavelength} meters")
print(f"A4-C5 Interval: {a4_c5_interval} Hz")

# 示例：绘制A4和C5的波形
plot_waveforms(a4_frequency, c5_frequency)
```
