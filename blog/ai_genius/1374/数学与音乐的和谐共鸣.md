##### 第11章：音乐分析算法

###### 11.1 Fast Fourier变换（FFT）在音乐分析中的应用

Fast Fourier变换是一种重要的数学工具，它可以用来分析音乐中的频率成分。通过 FFT，我们可以将音乐信号转换为频域表示，从而更方便地分析其特性。

###### 11.2 短时傅里叶变换（STFT）原理与使用

短时傅里叶变换是对 FFT 的扩展，它可以用来分析音乐信号在不同时间点的频率成分。STFT 通过分段对音乐信号进行傅里叶变换，从而得到音乐信号的时频表示。

以下是一个简单的 Python 代码示例，用于对音乐信号进行 FFT 分析：

```python
import numpy as np
import matplotlib.pyplot as plt

# 生成音乐信号
t = np.linspace(0, 1, 1000)
f1 = 440  # 频率 440 Hz
f2 = 660  # 频率 660 Hz
x = 0.5 * np.sin(2 * np.pi * f1 * t) + 0.3 * np.sin(2 * np.pi * f2 * t)

# 进行 FFT 分析
X = np.fft.fft(x)
freq = np.fft.fftfreq(len(x), t[1] - t[0])

# 提取频率成分
f1_idx = np.where(np.abs(freq) == f1)
f2_idx = np.where(np.abs(freq) == f2)

# 绘制 FFT 图
plt.plot(freq, np.abs(X), 'b')
plt.scatter(freq[f1_idx], np.abs(X[f1_idx]), marker='o', color='r', label='440 Hz')
plt.scatter(freq[f2_idx], np.abs(X[f2_idx]), marker='x', color='g', label='660 Hz')
plt.xlabel('Frequency (Hz)')
plt.ylabel('Magnitude')
plt.legend()
plt.show()
```

###### 11.3 Python代码实现与示例

以下是一个简单的 Python 代码示例，用于对音乐信号进行 STFT 分析：

```python
import numpy as np
import matplotlib.pyplot as plt

# 生成音乐信号
t = np.linspace(0, 1, 1000)
f1 = 440  # 频率 440 Hz
x = 0.5 * np.sin(2 * np.pi * f1 * t)

# 进行 STFT 分析
N = 128  # 窗口长度
window = np.hamming(N)
Overlap = 0.5 * (N - 1)

# 计算频谱
freqs = np.fft.fftfreq(N, t[1] - t[0])
X = np.zeros((N, len(t) // N), dtype=np.complex)

for i in range(len(t) // N):
    x_win = x[i * Overlap: (i + 1) * Overlap + N]
    X[i, :] = np.fft.fft(x_win * window)

# 提取频率成分
f1_idx = np.where(np.abs(freqs) == f1)

# 绘制时频图
plt.imshow(np.abs(X), aspect='auto', origin='lower', extent=[t[0], t[-1], freqs[0], freqs[-1]])
plt.scatter(t[f1_idx], freqs[f1_idx], marker='o', color='r', label='440 Hz')
plt.xlabel('Time (s)')
plt.ylabel('Frequency (Hz)')
plt.legend()
plt.show()
```

###### 12.1 和弦分析中的数学模型

和弦分析是音乐分析中的一个重要方面。在数学模型中，和弦可以看作是一个向量空间中的点。例如，大三和弦可以表示为 (1, 1, 1)，小三和弦可以表示为 (1, 1, -1)。

以下是一个简单的 Python 代码示例，用于计算和弦的模：

```python
import numpy as np

# 定义和弦
chords = [
    (1, 1, 1),  # 大三和弦
    (1, 1, -1),  # 小三和弦
    (1, -1, -1),  # 减三和弦
]

# 计算和弦的模
moduli = [np.linalg.norm(chord) for chord in chords]

# 打印结果
print(moduli)
```

```python
import numpy as np
import soundfile as sf

def generate_music(frequencies, durations, output_path):
    t = np.cumsum(durations)
    x = np.zeros_like(t)
    for i, (f, d) in enumerate(zip(frequencies, durations)):
        x[t[i]:t[i] + d] = np.sin(2 * np.pi * f * t[i:t[i] + d])

    sf.write(output_path, x, 44100)  # 44.1 kHz采样率

# 生成 C 大调音乐
frequencies = [261.63, 293.66, 329.63, 349.23, 392.00]
durations = [1, 1, 1, 1, 1]
output_path = "C_major.wav"

generate_music(frequencies, durations, output_path)
```

def analyze_music(input_path, sample_rate=44100):
