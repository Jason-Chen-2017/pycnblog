### 第3章：function_call 参数的传递方式

#### 3.1 function_call 参数的传递方式

在函数调用时，参数可以通过按值传递和按引用传递两种方式传递。

##### 3.1.1 按值传递

按值传递是指将参数的值复制一份传递给函数，函数内部对参数的修改不会影响原始参数。按值传递适合不可变类型（如整数、浮点数、字符串）和不可变对象（如元组、字典）。

伪代码示例：

```python
def modify_value(value):
    value = value + 1
    print("函数内部值:", value)

# 按值传递整数
x = 10
modify_value(x)
print("外部值:", x)
```

输出结果：

```
函数内部值: 11
外部值: 10
```

##### 3.1.2 按引用传递

按引用传递是指将参数的引用（地址）传递给函数，函数内部对参数的修改会影响原始参数。按引用传递适合可变类型（如列表、字典）和可变对象（如类实例）。

伪代码示例：

```python
def modify_reference(list_ref):
    list_ref.append(3)
    print("函数内部列表:", list_ref)

# 按引用传递列表
my_list = [1, 2]
modify_reference(my_list)
print("外部列表:", my_list)
```

输出结果：

```
函数内部列表: [1, 2, 3]
外部列表: [1, 2, 3]
```

#### 参数传递方式的选择

选择按值传递还是按引用传递取决于函数的需求和参数的类型。以下是一些选择建议：

- **不可变类型**：优先选择按值传递，以避免意外修改原始数据。
- **可变类型**：根据需求选择按引用传递或按值传递。如果函数需要修改参数，则选择按引用传递；如果函数不需要修改参数，则选择按值传递。
- **对象类型**：根据对象类型的特点选择按引用传递或按值传递。如果对象是不可变的，则选择按值传递；如果是可变的，则选择按引用传递。

#### 小结

按值传递和按引用传递是两种不同的参数传递方式，适用于不同的参数类型和函数需求。通过合理选择参数传递方式，可以提高程序的效率和可靠性。

### 第3章：function_call 参数的调用方法

#### 3.2 function_call 参数的调用方法

在编程中，函数调用是执行函数代码的过程。调用函数时，需要按照一定的方法传递参数，包括直接调用和间接调用。

##### 3.2.1 直接调用

直接调用是最常见的函数调用方式。直接调用时，直接使用函数名和参数列表调用函数。参数列表中的参数需要按照函数定义中的参数顺序传递。

伪代码示例：

```python

# 直接调用函数

```

输出结果：

```

```

直接调用方法的优点是简单直观，但缺点是函数名称必须明确，不易进行代码重用和功能扩展。

##### 3.2.2 间接调用

间接调用通过变量或函数指针调用函数，而非直接使用函数名。间接调用时，首先获取函数的引用，然后通过引用调用函数。

伪代码示例：

```python
# 定义一个函数
def function_call(a, b):
    return a * b

# 获取函数引用
func_ref = function_call

# 间接调用函数
result = func_ref(2, 3)
print("结果:", result)
```

输出结果：

```
结果: 6
```

间接调用方法的优点是函数名称可以隐藏，方便代码重用和功能扩展，但缺点是代码可读性较差。

#### 5.1 function_call 参数传递异常

在函数调用过程中，参数传递可能会出现一些异常情况，以下是一些常见的问题和解决方案：

##### 5.1.1 传递错误类型参数

问题：函数调用时传递了错误的类型参数，导致程序无法正常运行。

解决方案：确保函数调用时传递的参数类型与函数定义中指定的参数类型一致。可以使用类型检查和类型转换来确保参数类型正确。

伪代码示例：

```python

    return a + 1

# 正确传递整数参数
result = add(5)
print("结果:", result)

# 错误传递字符串参数
# result = add("5")  # 引发类型错误
```

##### 5.1.2 参数传递顺序错误

问题：函数调用时参数的传递顺序与函数定义中的顺序不一致，导致程序无法正常运行。

解决方案：确保函数调用时参数的传递顺序与函数定义中的顺序一致。在编写函数时，可以使用明确的参数顺序和参数名称来避免顺序错误。

伪代码示例：

```python
# 定义一个函数，期望传入两个参数
def add(a: int, b: int):
    return a + b

# 正确传递参数
result = add(3, 4)
print("结果:", result)

# 错误传递参数顺序
# result = add(4, 3)  # 参数顺序错误，结果可能不正确
```

##### 5.1.3 忘记传递参数

问题：在函数调用时，忘记传递必要的参数，导致程序无法正常运行。

解决方案：在编写函数调用代码时，仔细检查是否忘记了传递必要的参数。可以使用代码注释或代码审查来确保所有必要的参数都被传递。

```python

    return "Hello, " + name

# 正确传递参数

# 忘记传递参数
# message = greet()  # 引发错误，因为未传递参数
```

解决方案：确保函数调用时使用的方法与函数定义中的方法一致。例如，如果函数是静态方法，则需要使用类名和双冒号调用，而不是使用对象调用。

```python
from sklearn.metrics.pairwise import cosine_similarity
from sklearn.preprocessing import Normalizer

def get_product_recommendations(user_id, num_recommendations=5):
    # 获取用户历史浏览记录
    user_history = UserProductHistory.query.filter_by(user_id=user_id).all()

    # 构建商品-用户历史浏览记录矩阵
    product_history_matrix = []
    for history in user_history:
        product_id = history.product_id
        product_history_matrix.append([product_id])

    # 计算商品相似度矩阵
    product_similarity_matrix = cosine_similarity(product_history_matrix)

    # 正则化相似度矩阵
    normalizer = Normalizer()
    product_similarity_matrix = normalizer.fit_transform(product_similarity_matrix)

    # 获取用户历史浏览记录对应商品索引
    user_history_product_ids = [history.product_id for history in user_history]

    # 计算用户历史浏览记录对应商品相似度分数
    product_similarity_scores = []
    for i, product_id in enumerate(user_history_product_ids):
        similarity_score = 0
        for j, other_product_id in enumerate(user_history_product_ids):
            if i != j:
                similarity_score += product_similarity_matrix[i][j]
        product_similarity_scores.append(similarity_score)

    # 对商品相似度分数进行降序排序
    sorted_product_similarity_scores = sorted(zip(product_similarity_scores, user_history_product_ids), reverse=True)

    # 获取推荐商品列表
    recommended_product_ids = [product_id for _, product_id in sorted_product_similarity_scores[:num_recommendations]]

    # 从数据库中获取推荐商品详细信息
    recommended_products = Product.query.filter(Product.id.in_(recommended_product_ids)).all()

    return recommended_products
```
