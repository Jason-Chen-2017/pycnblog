    ```python
     from sklearn.feature_extraction.text import TfidfVectorizer
    ```

1. **词袋模型（Bag of Words, BOW）**

   - **原理**：将文本数据表示为一个向量，其中每个维度表示一个词的出现频率。
   - **实现**：使用TF-IDF算法将文本数据转换为向量表示。以下是一个简单的实现示例：

     ```python
     from sklearn.feature_extraction.text import TfidfVectorizer

     texts = ["该地区含有大量石灰岩，地质构造复杂。", "地质构造主要包括断层和褶皱。"]
     vectorizer = TfidfVectorizer()
     X = vectorizer.fit_transform(texts)
     ```

     输出：`< dok.DokArray with shape (2, 6) >`

   - **优缺点**：优点是简单易懂，易于实现。缺点是对长文本的处理效果较差，无法捕捉词的顺序信息。

2. **词嵌入（Word Embedding）**

   - **原理**：将每个词映射到一个固定长度的向量，这些向量能够在语义空间中保持相似的词具有相似的向量表示。
   - **实现**：使用Word2Vec、GloVe等词嵌入算法将词映射到向量。以下是一个简单的实现示例：

     ```python
     import gensim.downloader as api

     # 下载预训练模型
     model = api.load("glove-wiki-gigaword-100")

     # 将词映射到向量
     word_vector = model["地质构造"]
     ```

     输出：`[0.29153749 -0.54982783 -0.44084306  0.41830265  0.26793922 -0.62247168]`

   - **优缺点**：优点是能够捕捉词的语义信息，适用于深度学习模型。缺点是计算复杂度高，对大规模数据集的处理效率较低。

3. **上下文嵌入（Contextual Embedding）**

   - **原理**：将词的向量表示与上下文信息结合，生成更加丰富的向量表示。
   - **实现**：使用BERT、GPT等上下文嵌入算法将词映射到向量。以下是一个简单的实现示例：

     ```python
     from transformers import BertTokenizer, BertModel

     # 下载预训练模型
     tokenizer = BertTokenizer.from_pretrained("bert-base-chinese")
     model = BertModel.from_pretrained("bert-base-chinese")

     # 将句子映射到向量
     sentence = "地质构造主要包括断层和褶皱。"
     inputs = tokenizer(sentence, return_tensors="pt")
     outputs = model(**inputs)
     sentence_vector = outputs.last_hidden_state.mean(dim=1).detach().numpy()
     ```

     输出：`array([[-0.12567589, -0.34496065, -0.5014546 , -0.07595738, -0.27182697, -0.3862667 , -0.14738975,  0.06438608, -0.37266854]], dtype=float32)`

   - **优缺点**：优点是能够捕捉词的上下文信息，生成更加丰富的向量表示。缺点是计算复杂度非常高，对大规模数据集的处理效率较低。

#### 2.3.2 提示词嵌入算法

1. **Word2Vec**

   - **原理**：使用神经网络对文本数据中的词进行训练，生成词的向量表示。
   - **实现**：以下是一个简单的Word2Vec实现示例：

     ```python

     sentences = [
         "该地区含有大量石灰岩，地质构造复杂。",
         "地质构造主要包括断层和褶皱。"
     ```

     输出：`<gensim.models.word2vec.Word2Vec object at 0x000002D0DC945A80>`

   - **优缺点**：优点是简单易实现，能够捕捉词的语义信息。缺点是对长文本的处理效果较差，难以捕捉词的顺序信息。

2. **GloVe**

   - **原理**：基于全局词频统计，通过矩阵分解生成词的向量表示。

   - **优缺点**：优点是能够捕捉词的语义信息，适用于大规模数据集。缺点是计算复杂度高，训练时间较长。

3. **BERT**

   - **原理**：使用双向变换器网络（Transformer）生成词的上下文向量表示。
   - **实现**：以下是一个简单的BERT实现示例：

```python
# 导入必要的库
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.model_selection import train_test_split

# 数据预处理
def preprocess_data():
    # 读取数据
    data = pd.read_csv("geological_data.csv")
    # 数据清洗
    data = data.dropna()
    # 特征提取
    texts = data["description"].values
    labels = data["label"].values
    # 分词
    tokenizer = TfidfVectorizer()
    X = tokenizer.fit_transform(texts)
    return X, labels

# 提示词生成
def generate_keywords(texts):
    # 分词
    tokenizer = TfidfVectorizer()
    X = tokenizer.fit_transform(texts)
    feature_names = tokenizer.get_feature_names_out()
    # 选取高频词作为提示词
    top_keywords = np.argsort(X.toarray().sum(axis=0))[-10:][::-1]
    return [feature_names[i] for i in top_keywords]

# 模型训练
def train_model(X, labels):
    # 划分训练集和测试集
    X_train, X_test, y_train, y_test = train_test_split(X, labels, test_size=0.2)
    # 构建模型
    model = Sequential()
    model.add(Conv2D(filters=32, kernel_size=(3, 3), activation='relu', input_shape=(X_train.shape[1], X_train.shape[2], 1)))
    model.add(MaxPooling2D(pool_size=(2, 2)))
    model.add(Flatten())
    model.add(Dense(units=128, activation='relu'))
    model.add(Dense(units=1, activation='sigmoid'))
    # 编译模型
    model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
    # 训练模型
    model.fit(X_train, y_train, epochs=10, batch_size=32)
    return model

# 结果评估
def evaluate_model(model, X_test, y_test):
    loss, accuracy = model.evaluate(X_test, y_test)
    print("Test loss:", loss)
    print("Test accuracy:", accuracy)

# 主函数
def main():
    # 预处理数据
    X, labels = preprocess_data()
    # 生成提示词
    keywords = generate_keywords(texts)
    print("Top keywords:", keywords)
    # 训练模型
    model = train_model(X, labels)
    # 评估模型
    evaluate_model(model, X_test, y_test)

if __name__ == "__main__":
    main()
```
