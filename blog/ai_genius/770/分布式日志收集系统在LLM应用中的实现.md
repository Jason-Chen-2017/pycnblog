### 1.10 LLM的基本概念和架构

LLM（Large Language Model）是一种基于深度学习的自然语言处理模型，具有强大的文本生成和理解能力。LLM的架构通常包括以下几个主要部分：

1. **输入层**：接收用户的输入文本，并将其转换为模型的输入。

4. **注意力机制**：用于关注输入文本中的关键信息，提高模型的生成质量。
5. **训练过程**：通过大量的文本数据对模型进行训练，使其能够生成符合人类语言的文本。

        # 对收集到的日志进行去重和过滤

        # 将日志写入分布式存储

        # 等待下一次收集周期
        sleep(collection_frequency)

### 1.22 项目实战：分布式日志收集系统的搭建

#### 2.1 环境准备

在开始搭建分布式日志收集系统之前，我们需要准备以下环境：

1. **操作系统**：建议使用Linux操作系统，如CentOS或Ubuntu。
2. **Java运行环境**：安装Java运行环境（JDK 8或更高版本）。
3. **Kafka**：安装Kafka，版本建议为2.8或更高版本。
4. **Elasticsearch**：安装Elasticsearch，版本建议为7.10或更高版本。
5. **Kibana**：安装Kibana，版本建议与Elasticsearch一致。

#### 2.2 搭建Kafka

Kafka是一个分布式消息队列系统，用于收集日志数据。以下步骤用于搭建Kafka：

1. **安装Kafka**：

   ```bash
   sudo apt-get update
   sudo apt-get install default-jdk
   sudo wget https://www-eu.kaltura.com/nginx-releaseubuntu1804kafka_2.13-2.8.0.zip
   sudo unzip kafka_2.13-2.8.0.zip -d /usr/local/kafka
   ```

2. **启动Kafka服务**：

   ```bash
   cd /usr/local/kafka/kafka_2.13-2.8.0
   sudo bin/kafka-server-start.sh config/server.properties
   ```

   在`config/server.properties`文件中，配置Kafka的日志目录和Zookeeper地址。

3. **创建主题**：

   ```bash
   bin/kafka-topics.sh --create --topic logs --partitions 3 --replication-factor 1 --bootstrap-server localhost:9092
   ```

#### 2.3 搭建Elasticsearch

Elasticsearch是一个分布式搜索引擎，用于存储和查询日志数据。以下步骤用于搭建Elasticsearch：

1. **安装Elasticsearch**：

   ```bash
   sudo wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-7.10.0-amd64.deb
   sudo dpkg -i elasticsearch-7.10.0-amd64.deb
   ```

2. **配置Elasticsearch**：

   编辑`/etc/elasticsearch/elasticsearch.yml`文件，配置Elasticsearch的节点名称、集群名称和日志目录。

```java

props.put("group.id", "test-group");

props.put("value.deserializer", "org.apache.kafka.common.serialization.StringDeserializer");

KafkaConsumer<String, String> consumer = new KafkaConsumer<>(props);
consumer.subscribe(Arrays.asList(new TopicPartition("logs", 0)));

while (true) {
    ConsumerRecords<String, String> records = consumer.poll(Duration.ofMillis(100));
    for (ConsumerRecord<String, String> record : records) {

                record.key(), record.value(), record.partition(), record.offset());
    }
}
```

- `props.put("bootstrap.servers", "localhost:9092")`：配置Kafka地址和端口。
- `props.put("group.id", "test-group")`：指定消费者组ID。
- `props.put("key.deserializer", "org.apache.kafka.common.serialization.StringDeserializer")`：指定键反序列化器。
- `props.put("value.deserializer", "org.apache.kafka.common.serialization.StringDeserializer")`：指定值反序列化器。

`KafkaConsumer`对象用于从`logs`主题中读取日志数据。在循环中，我们使用`poll`方法轮询Kafka主题，并打印每条接收到的日志记录。

    .source(new SearchSourceBuilder().query(new MatchQuery("message", "Log entry 1"))));
