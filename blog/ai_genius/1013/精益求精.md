### 3.3 应用示例

为了更好地理解数学模型和公式，我们可以通过具体示例来讲解：

#### 3.3.1 线性模型应用

假设我们要预测一个线性函数的值，可以使用线性模型来求解。

$$y = ax + b$$

其中，$a$ 和 $b$ 是线性模型的参数，$x$ 是自变量，$y$ 是因变量。

```python
# Python代码实现线性模型
def linear_model(x, a, b):
    return a * x + b

# 示例数据
x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

# 求解参数
a = sum([x[i] * y[i] for i in range(len(x))]) / sum([x[i] ** 2 for i in range(len(x))])
b = sum(y) - a * sum(x)

# 预测结果
predicted_y = [linear_model(x[i], a, b) for i in range(len(x))]

# 打印结果
print("实际值:", y)
print("预测值:", predicted_y)
```

#### 3.3.2 概率模型应用

假设我们要计算一个概率事件的概率，可以使用概率模型来求解。

$$P(A) = \frac{n(A)}{n(S)}$$

其中，$P(A)$ 是事件 $A$ 的概率，$n(A)$ 是事件 $A$ 的样本点数，$n(S)$ 是样本空间 $S$ 的样本点数。

```python
# Python代码实现概率模型
from itertools import combinations

# 计算概率
def probability(A, S):
    return len(A) / len(S)

# 示例数据
S = ['红', '蓝', '绿', '黄', '紫']  # 样本空间
A = ['红', '蓝', '绿']  # 事件A

# 计算结果
result = probability(A, S)
print("事件A的概率:", result)
```
