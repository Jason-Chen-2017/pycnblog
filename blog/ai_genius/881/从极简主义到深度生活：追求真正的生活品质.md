**极简主义的定义与发展**：
极简主义最早起源于20世纪中叶的美国，当时社会消费主义盛行，人们被物质诱惑所包围。极简主义作为一种反叛思想，提倡通过减少物质消费，简化生活方式，以追求内心的平静和自由。这种思想很快在欧美国家流行起来，并逐渐形成了一种生活方式和哲学。

**极简主义的哲学基础**：
极简主义深受禅宗哲学的影响。禅宗强调“少即是多”，通过减少杂乱和无意义的事物，达到内心的宁静。此外，极简主义也受到了现代心理学的研究支持。研究表明，过多的物质和情感负担会导致压力和焦虑，减少这些负担可以显著提升幸福感。

**极简主义的核心原则**：
1. **减少非必要物品**：极简主义主张通过减少不必要的物品，简化生活环境。这不仅可以减少杂乱，还可以节省时间和精力。
2. **简化生活**：极简主义鼓励人们简化日常活动，减少不必要的社交和娱乐，从而将更多的时间和精力投入到重要的事务中。
3. **聚焦重要事物**：极简主义强调专注于对生活有深度和意义的事物，如家庭、朋友、爱好和职业。

**极简主义的实践与应用**：
1. **家庭环境**：通过减少家具和装饰品，打造简洁、舒适的生活空间。
2. **工作环境**：通过减少工作台上的杂物，提高工作效率。
3. **时间管理**：通过减少社交媒体和娱乐活动，将更多时间用于个人成长和重要事务。

```python
from flask import Flask, request, jsonify
import sqlite3

app = Flask(__name__)

# 连接到SQLite数据库
conn = sqlite3.connect('minimalist_life.db')
c = conn.cursor()

# 创建表
c.execute('''CREATE TABLE IF NOT EXISTS items (id INTEGER PRIMARY KEY, name TEXT, importance INTEGER)''')
c.execute('''CREATE TABLE IF NOT EXISTS activities (id INTEGER PRIMARY KEY, name TEXT, importance INTEGER)''')
c.execute('''CREATE TABLE IF NOT EXISTS time_management (id INTEGER PRIMARY KEY, activity_id INTEGER, time_spent INTEGER, FOREIGN KEY (activity_id) REFERENCES activities (id))''')

# 插入数据
c.execute("INSERT INTO items (name, importance) VALUES (?, ?)", ('Book', 1))
c.execute("INSERT INTO items (name, importance) VALUES (?, ?)", ('Laptop', 1))
c.execute("INSERT INTO items (name, importance) VALUES (?, ?)", ('Phone', 0))

c.execute("INSERT INTO activities (name, importance) VALUES (?, ?)", ('Social Media', 0))
c.execute("INSERT INTO activities (name, importance) VALUES (?, ?)", ('Reading', 1))
c.execute("INSERT INTO activities (name, importance) VALUES (?, ?)", ('Exercise', 1))

c.execute("INSERT INTO time_management (activity_id, time_spent) VALUES (?, ?)", (2, 60))
c.execute("INSERT INTO time_management (activity_id, time_spent) VALUES (?, ?)", (3, 30))

conn.commit()

# 获取所有物品
@app.route('/items', methods=['GET'])
def get_items():
    c.execute("SELECT * FROM items")
    items = c.fetchall()
    return jsonify(items)

# 获取所有活动
@app.route('/activities', methods=['GET'])
def get_activities():
    c.execute("SELECT * FROM activities")
    activities = c.fetchall()
    return jsonify(activities)

# 更新时间管理记录
@app.route('/time_management', methods=['POST'])
def update_time_management():
    activity_id = request.form['activity_id']
    time_spent = request.form['time_spent']
    c.execute("UPDATE time_management SET time_spent = ? WHERE activity_id = ?", (time_spent, activity_id))
    conn.commit()
    return jsonify({'message': 'Time management updated successfully.'})

if __name__ == '__main__':
    app.run(debug=True)
```
