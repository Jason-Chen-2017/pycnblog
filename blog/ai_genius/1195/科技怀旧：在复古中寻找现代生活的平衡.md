###### 2.1.1 收音机与黑胶唱片

收音机和黑胶唱片是20世纪最受欢迎的复古科技产品之一。它们在当时的日常生活中扮演着重要角色，为人们提供了丰富的娱乐和信息来源。

1. **工作原理**：
   - 收音机：通过电磁波接收广播信号，将其转换为声音信号。
   - 黑胶唱片：通过旋转的唱片和针尖将物理信号转换为电信号。

2. **核心算法原理**：
   - 收音机：调制解调算法。
   - 黑胶唱片：信号放大和滤波算法。

3. **Python源代码示例**：

```python
# 收音机调制解调算法示例
def modulate(message, frequency):
    modulated_signal = []
    for bit in message:
        if bit == '1':
            modulated_signal.append(frequency)
        else:
            modulated_signal.append(-frequency)
    return modulated_signal

def demodulate(signal, frequency):
    demodulated_message = ""
    for i in range(0, len(signal), 2):
        if signal[i] == frequency:
            demodulated_message += '1'
        elif signal[i] == -frequency:
            demodulated_message += '0'
    return demodulated_message

# 测试代码
message = "10101010"
frequency = 100
modulated = modulate(message, frequency)
print(f"Modulated Signal: {modulated}")
demodulated = demodulate(modulated, frequency)
print(f"Demodulated Message: {demodulated}")
```

1. **工作原理**：

2. **核心算法原理**：
   - 语音编码与解码算法。
   - 无线通信算法。

3. **Python源代码示例**：

```python
# 语音编码与解码算法示例
def encode_audio(audio_signal, sample_rate):
    encoded_signal = []
    for sample in audio_signal:
        encoded_signal.append(sample * sample_rate)
    return encoded_signal

def decode_audio(encoded_signal, sample_rate):
    decoded_signal = []
    for sample in encoded_signal:
        decoded_signal.append(sample / sample_rate)
    return decoded_signal

# 测试代码

sample_rate = 1000
encoded = encode_audio(audio_signal, sample_rate)
decoded = decode_audio(encoded, sample_rate)

print(f"Decoded Audio: {decoded}")
```
