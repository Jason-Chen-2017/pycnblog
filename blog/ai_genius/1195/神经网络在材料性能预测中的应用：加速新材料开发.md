## 第1章 神经网络基础

### 1.1 神经网络的基本概念

神经网络是一种由大量简单计算单元（神经元）组成的复杂网络，这些神经元通过连接形成层次结构。神经网络的工作原理是模拟人脑神经元之间的交互，通过学习输入和输出之间的映射关系来完成任务。

### 1.2 前馈神经网络

前馈神经网络是神经网络的一种基本形式，其中数据从输入层流向输出层，中间经过多个隐藏层。每个神经元都通过加权连接与前一层的神经元相连接，并应用激活函数。

### 1.3 反向传播算法

反向传播算法是一种用于训练神经网络的通用方法。它通过不断调整网络中的权重和偏置，最小化预测误差。反向传播算法的核心思想是将误差从输出层反向传播到输入层，并更新权重。

### 1.4 深层神经网络

深层神经网络包含多个隐藏层，能够学习更复杂的特征和模式。随着层数的增加，神经网络的表示能力也显著提升。然而，深层神经网络训练过程相对复杂，容易出现梯度消失或梯度爆炸问题。

### 核心算法原理讲解

#### 前馈神经网络

前馈神经网络（Feedforward Neural Network）是神经网络中最简单的一种形式。其工作原理如下：

1. **输入层**：接收外部输入，例如材料的结构特征。
2. **隐藏层**：每个隐藏层中的神经元都通过加权连接从输入层接收输入，并通过激活函数进行处理。激活函数通常是一个非线性函数，如Sigmoid、ReLU或Tanh。
3. **输出层**：最终输出预测结果。

以下是一个简单的Python代码示例，展示了如何实现一个前馈神经网络：

```python
import numpy as np

# 定义一个简单的前馈神经网络
def feedforward_neural_network(input_data, weights, biases):
    # 初始输出
    layer_output = input_data
    
    # 遍历所有隐藏层和输出层
    for weights_layer, biases_layer in zip(weights, biases):
        layer_output = np.dot(layer_output, weights_layer) + biases_layer
        layer_output = np.sigmoid(layer_output)  # 使用Sigmoid激活函数
    
    return layer_output

# 输入数据
input_data = np.array([1, 0, 1])

# 权重和偏置
weights = [
    np.random.rand(3, 3),  # 输入层到第一隐藏层的权重
    np.random.rand(3, 1)    # 第一隐藏层到输出层的权重
]
biases = [
    np.random.rand(3, 1),  # 输入层到第一隐藏层的偏置
    np.random.rand(1, 1)    # 第一隐藏层到输出层的偏置
]

# 前馈计算
output = feedforward_neural_network(input_data, weights, biases)
print(output)
```

在这个例子中，我们首先定义了一个前馈神经网络函数`feedforward_neural_network`，它接受输入数据、权重和偏置作为输入，并逐步计算每个隐藏层的输出。我们使用了Sigmoid激活函数，这是由于Sigmoid函数可以引入非线性，使神经网络能够学习复杂的模式。

#### 反向传播算法

反向传播算法（Backpropagation Algorithm）是训练神经网络的通用方法。其核心思想是利用损失函数的梯度，通过反向传播来更新网络中的权重和偏置。

1. **前向传播**：计算输入数据通过神经网络的输出。
2. **计算损失**：使用损失函数（如均方误差MSE）计算输出误差。
3. **后向传播**：计算每个神经元的梯度，并反向传播到前一层。
4. **权重更新**：使用梯度下降或其他优化算法更新权重。

以下是一个简单的Python代码示例，展示了如何实现反向传播算法：

```python
# 定义损失函数
def mean_squared_error(y_true, y_pred):
    return np.mean((y_true - y_pred)**2)

# 定义反向传播算法
def backpropagation(input_data, target, weights, biases):
    output = feedforward_neural_network(input_data, weights, biases)
    loss = mean_squared_error(target, output)
    
    # 计算输出层的梯度
    output_error = output - target
    dweights_output = np.dot(output.T, output_error)
    dbiases_output = np.sum(output_error, axis=0, keepdims=True)
    
    # 反向传播到隐藏层
    for i in range(len(weights) - 1, 0, -1):
        error = np.dot(weights[i].T, output_error) * (1 - np.power(output, 2))
        dweights_hidden = np.dot(layer_output.T, error)
        dbiases_hidden = np.sum(error, axis=0, keepdims=True)
        
        # 更新权重和偏置
        weights[i] -= learning_rate * dweights_hidden
        biases[i] -= learning_rate * dbiases_hidden
        
        # 更新当前层的输出
        layer_output = np.dot(input_data, weights[i]) + biases[i]
    
    # 更新输入层到第一隐藏层的权重和偏置
    error = np.dot(weights[0].T, output_error) * (1 - np.power(input_data, 2))
    dweights_input = np.dot(input_data.T, error)
    dbiases_input = np.sum(error, axis=0, keepdims=True)
    
    weights[0] -= learning_rate * dweights_input
    biases[0] -= learning_rate * dbiases_input
    
    return loss

# 训练神经网络
learning_rate = 0.1
loss_history = []
for epoch in range(1000):
    loss = backpropagation(input_data, target, weights, biases)
    loss_history.append(loss)
    print(f'Epoch {epoch+1}, Loss: {loss}')
```

在这个例子中，我们首先定义了均方误差（MSE）作为损失函数。然后，我们定义了一个`backpropagation`函数，它执行前向传播、计算损失、后向传播和权重更新。每次迭代结束后，我们打印出当前的损失，并更新权重和偏置。

### 数学模型和公式

在神经网络中，一些核心的数学模型和公式对于理解其工作原理至关重要。以下是几个关键的概念和相应的数学公式：

#### 激活函数

激活函数是神经网络中的一个关键组件，它用于引入非线性。以下是几种常见的激活函数及其数学表示：

1. **Sigmoid函数**：

   $$ \sigma(x) = \frac{1}{1 + e^{-x}} $$

2. **ReLU函数**：

   $$ \text{ReLU}(x) = \max(0, x) $$

3. **Tanh函数**：

   $$ \text{Tanh}(x) = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}} $$

#### 损失函数

损失函数用于衡量预测结果与真实结果之间的差异。以下是几种常见的损失函数：

1. **均方误差（MSE）**：

   $$ \text{MSE}(y, \hat{y}) = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$

2. **交叉熵损失（Cross-Entropy Loss）**：

   $$ \text{Cross-Entropy}(y, \hat{y}) = -\sum_{i=1}^{n} y_i \log(\hat{y}_i) $$

#### 梯度下降

梯度下降是一种优化算法，用于更新网络中的权重和偏置。其核心公式如下：

$$ \theta_{\text{new}} = \theta_{\text{old}} - \alpha \cdot \nabla_{\theta} J(\theta) $$

其中，$\theta$ 表示权重和偏置，$\alpha$ 是学习率，$J(\theta)$ 是损失函数。

import numpy as np

# 激活函数
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 前向传播
def forward_propagation(x, weights, biases):
    z = np.dot(x, weights) + biases
    return sigmoid(z)

def backward_propagation(x, y, output, weights, biases):
    output_error = y - output
    doutput = output_error * (output * (1 - output))

    dbiases = np.sum(doutput, axis=0, keepdims=True)
    
    dx = np.dot(doutput, weights.T)
    
    return dx, dweights, dbiases

y = np.array([[0], [1], [1]])

for i in range(num_iterations):
    output = forward_propagation(x, weights, biases)
    dx, dweights, dbiases = backward_propagation(x, y, output, weights, biases)
    
    weights -= learning_rate * dweights
    biases -= learning_rate * dbiases

    if i % 100 == 0:
        print(f"Iteration {i}, Output: {output}")

print("Final weights:", weights)
print("Final biases:", biases)
