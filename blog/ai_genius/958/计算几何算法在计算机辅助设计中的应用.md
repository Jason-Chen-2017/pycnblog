### 第1章：计算几何的基本概念

### 1.1 几何图形的基本属性

### 1.1.1 几何图形的要素

几何图形是由点、线、面等基本元素构成的。在计算几何中，这些基本元素具有特定的数学定义和属性。

- **点**：点是一个位置的概念，可以用一个坐标对表示。在二维空间中，点通常表示为$(x, y)$。
- **线**：线是由无数个点连成的路径。一条直线可以用一个方程表示，如$y = mx + b$。
- **面**：面是由无数条线组成的二维平面。

### 1.1.2 几何图形的分类

几何图形可以根据其形状和性质进行分类。常见的分类有：

- **二维图形**：如点、线、圆、多边形等。
- **三维图形**：如立方体、球体、锥体等。

### 1.1.3 几何图形的基本性质

几何图形具有一些基本性质，如：

- **对称性**：几何图形关于某条线、点或面对称。
- **相似性**：两个几何图形的形状相似，但大小可以不同。
- **全等性**：两个几何图形在形状和大小上完全相同。

### 1.2 几何算法概述

### 1.2.1 几何算法的分类

几何算法可以按照其功能进行分类：

- **计算算法**：用于计算几何对象的属性，如距离、面积等。
- **变换算法**：用于对几何对象进行平移、旋转、缩放等变换。
- **交互算法**：用于与用户进行交互，如选择、移动等。

### 1.2.2 几何算法的研究方法

几何算法的研究方法包括：

- **数学方法**：使用数学公式和理论进行推导和证明。
- **计算机科学方法**：使用算法和数据结构进行设计和实现。
- **实验方法**：通过实验验证算法的有效性和性能。

### 1.2.3 几何算法的发展趋势

几何算法的发展趋势包括：

- **算法优化**：通过改进算法的效率和性能。
- **并行计算**：利用多核处理器和GPU等硬件加速算法。
- **人工智能**：结合机器学习和深度学习技术，提高几何算法的智能化程度。

## 第2章：几何图形的表示

### 2.1 点和线的表示方法

### 2.1.1 点的表示方法

在二维空间中，点通常用坐标对$(x, y)$表示。坐标原点为$(0, 0)$，$x$轴和$y$轴分别表示水平方向和垂直方向。

$$
(x, y) = (x_c + r\cos\theta, y_c + r\sin\theta)
$$

其中，$x_c$和$y_c$是点的中心坐标，$r$是点到坐标原点的距离，$\theta$是点与$x$轴的夹角。

### 2.1.2 线的表示方法

线可以用一条直线方程表示，如：

$$
y = mx + b
$$

其中，$m$是直线的斜率，$b$是直线与$y$轴的截距。

### 2.2 圆和圆弧的表示方法

### 2.2.1 圆的表示方法

圆可以用以下方程表示：

$$
(x - x_0)^2 + (y - y_0)^2 = r^2
$$

其中，$(x_0, y_0)$是圆心的坐标，$r$是圆的半径。

### 2.2.2 圆弧的表示方法

圆弧是圆的一部分，可以用以下方程表示：

$$
\theta_1 \leq \theta \leq \theta_2
$$

其中，$\theta_1$和$\theta_2$是圆弧的两个端点的极角。

### 2.3 多边形和曲线的表示方法

### 2.3.1 多边形的表示方法

多边形可以用一系列点的坐标表示，如：

$$
P_1, P_2, P_3, ..., P_n
$$

其中，$P_i$是多边形的第$i$个顶点。

### 2.3.2 曲线的表示方法

曲线可以用一系列点的坐标表示，如：

$$
C_1, C_2, C_3, ..., C_n
$$

其中，$C_i$是曲线上的第$i$个点。

## 第3章：几何算法的核心概念

### 3.1 几何变换

### 3.1.1 平移变换

平移变换是将几何对象沿着某个方向移动一定的距离。平移变换可以用以下公式表示：

$$
(x, y) \rightarrow (x + dx, y + dy)
$$

其中，$(dx, dy)$是平移向量。

### 3.1.2 旋转变换

旋转变换是将几何对象围绕某个点旋转一定的角度。旋转变换可以用以下公式表示：

$$
(x, y) \rightarrow (x\cos\theta - y\sin\theta, x\sin\theta + y\cos\theta)
$$

其中，$\theta$是旋转角度。

### 3.1.3 缩放变换

缩放变换是将几何对象按照一定的比例进行放大或缩小。缩放变换可以用以下公式表示：

$$
(x, y) \rightarrow (x\alpha, y\beta)
$$

其中，$\alpha$和$\beta$是缩放比例。

### 3.2 几何距离

### 3.2.1 点到点的距离

点到点的距离可以用以下公式计算：

$$
d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
$$

### 3.2.2 点到线的距离

点到线的距离可以用以下公式计算：

$$
d = \frac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}
$$

其中，$ax + by + c = 0$是线的方程。

### 3.3 几何交集

### 3.3.1 线与线的交集

线与线的交集可以用以下公式判断：

$$
x_1 + x_2 = x_3 + x_4
$$
$$
y_1 + y_2 = y_3 + y_4
$$

其中，$x_1, y_1, x_2, y_2$和$x_3, y_3, x_4, y_4$分别是两条线的端点坐标。

### 3.3.2 圆与圆的交集

圆与圆的交集可以用以下公式判断：

$$
d \leq r_1 + r_2
$$
$$
d \geq |r_1 - r_2|
$$

其中，$d$是两个圆心的距离，$r_1$和$r_2$是两个圆的半径。

### 3.3.3 多边形与多边形的交集

多边形与多边形的交集可以用以下公式判断：

$$
p_1 + p_2 = p_3 + p_4
$$
$$
q_1 + q_2 = q_3 + q_4
$$

其中，$p_1, p_2, p_3, p_4$和$q_1, q_2, q_3, q_4$分别是两个多边形的顶点坐标。

## 第4章：几何算法在曲线设计中的应用

### 4.1 B样条曲线的设计

### 4.1.1 B样条曲线的基本概念

B样条曲线是一种重要的曲线设计工具，它基于B样条函数构建。B样条函数是一种分段多项式函数，其定义域为$[0, 1]$。

### 4.1.2 B样条曲线的节点生成

B样条曲线的节点生成是曲线设计的关键步骤。节点序列通常使用以下公式生成：

$$
n_i(k) = \frac{(u - u_i)(u - u_{i+k})}{(u_{i+k-1} - u_i)(u_{i+k} - u)}
$$

其中，$u$是曲线参数，$u_i$和$u_{i+k}$是节点参数。

### 4.1.3 B样条曲线的伪代码实现

```python
# B样条曲线的伪代码实现
def B_Spline_curve(points, knots, degree):
    n = len(points)
    m = len(knots)
    control_points = [points[i] for i in range(n)]
    curve_points = []

    for u in range(1, m - degree):
        u_knots = knots[u:u + degree + 1]
        u_points = points[u:u + degree + 1]
        curve_points.append(calculate_point(u_points, u_knots, degree))

    return curve_points

# 计算B样条曲线上的点
def calculate_point(points, knots, degree):
    n = len(points)
    m = len(knots)
    N = [B_Spline_basis_function(points, knots, i, degree) for i in range(degree + 1)]

    x = 0
    y = 0

    for i in range(degree + 1):
        x += N[i] * points[i][0]
        y += N[i] * points[i][1]

    return (x, y)

# 计算B样条基函数
def B_Spline_basis_function(points, knots, i, degree):
    n = len(points)
    m = len(knots)
    u = knots[i] / knots[degree]

    if u > 1:
        u = 1

    N = 0

    for j in range(degree + 1):
        N += choose(degree, j) * (u - knots[i]) / (knots[i + j + 1] - knots[i])

    return N

# 计算组合数
def choose(n, k):
    if k > n:
        return 0
    if k == 0 or k == n:
        return 1
    return choose(n - 1, k - 1) + choose(n - 1, k)
```

def NURBS_curve(points, weights, knots, degree):

    m = len(knots)
    control_points = [points[i] for i in range(n)]

    y = 0

def NURBS_basis_function(points, weights, knots, i, degree):

    m = len(knots)
    u = knots[i] / knots[degree]

    if u > 1:
        u = 1

    N = 0

    for j in range(degree + 1):
        N += choose(degree, j) * (u - knots[i]) / (knots[i + j + 1] - knots[i])

### 5.1.2 B样条曲面的节点生成

def B_Spline_surface(points, knots_u, knots_v, degree_u, degree_v):
    n = len(points)
    m_u = len(knots_u)
    m_v = len(knots_v)
    control_points = [points[i] for i in range(n)]
    surface_points = []

    for u in range(1, m_u - degree_u):
        for v in range(1, m_v - degree_v):

            v_knots = knots_v[v:v + degree_v + 1]
            u_points = points[u:u + degree_u + 1]

    m = len(v_points)
    N_u = [B_Spline_basis_function(u_points, u_knots, i, degree_u) for i in range(degree_u + 1)]

    y = 0
    z = 0

        for j in range(degree_v + 1):

            y += N_u[i] * N_v[j] * u_points[i][1]

    return (x, y, z)

# 计算NURBS基函数
def NURBS_basis_function(points, weights, knots, i, degree):
    n = len(points)
    m = len(weights)
    u = knots[i] / knots[degree]

    if u > 1:
        u = 1

    N = 0

    for j in range(degree + 1):
        N += choose(degree, j) * (u - knots[i]) / (knots[i + j + 1] - knots[i])

    return N / weights[i]
```

def distance_point_line(point, line):
    x1, y1 = point
    x2, y2 = line[0], line[1]
    a = (y2 - y1) ** 2
    b = 2 * (x2 * (y1 - y2) + x1 * y2 - x1 * y1)
    c = x1 ** 2 + y1 ** 2 - x2 ** 2 - y2 ** 2

    distance = abs(a * x1 + b * y1 + c) / (a ** 0.5)

```

# 圆与圆的相交判断
def intersect_circles(circle1, circle2):
    x1, y1, r1 = circle1
    x2, y2, r2 = circle2
    d = ((x1 - x2) ** 2 + (y1 - y2) ** 2) ** 0.5

    if d > r1 + r2 or d < abs(r1 - r2):
        return False
    else:
        return True

# 多边形的最小外接圆
def minimum_enclosing_circle(points):
    n = len(points)
    points = [complex(x, y) for x, y in points]
    center = None

    for i in range(n):
        next_i = (i + 1) % n
        p1 = points[i]
        p2 = points[next_i]

        p0 = (p1 + p2) / 2
        p = (p1 - p2) / 2
        center = p0 + p0 / p.length()

    r = abs(p0 - center)

    return [center.real, center.imag], r
