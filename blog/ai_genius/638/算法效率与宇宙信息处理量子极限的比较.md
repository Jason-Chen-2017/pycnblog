### 1.2 算法效率的基本概念

算法效率是指算法在执行过程中所消耗的时间、空间和其他资源（如能源）的优化程度。一个高效的算法能够在有限的时间内完成更多的任务，或者在相同时间内完成更复杂的任务。算法效率通常通过算法复杂度来衡量，包括时间复杂度和空间复杂度。

**时间复杂度**描述了算法执行时间随着输入数据规模增长的变化趋势。常见的表示方法是用大O符号（O）来表示，如O(n)，O(n^2)，O(log n)等。时间复杂度越低，算法执行速度越快。

**空间复杂度**描述了算法在执行过程中所需存储空间的增长情况。它同样使用大O符号来表示，如O(1)，O(n)，O(n^2)等。空间复杂度越低，算法占用的内存资源越少。

在算法设计中，时间复杂度和空间复杂度是两个重要的考量因素。一个算法可能时间复杂度较低，但空间复杂度较高；反之，也可能时间复杂度较高，但空间复杂度较低。在实际应用中，需要根据具体场景和要求来平衡这两个因素，以找到最优的算法方案。

#### 二分查找算法

二分查找算法是一种用于在有序数组中查找特定元素的算法。其基本思想是通过不断将数组划分为两半，逐步缩小查找范围，直到找到目标元素或确定其不存在。

**伪代码：**

```
BINARY_SEARCH(A[0...n-1], key)
    low = 0
    high = n - 1
    while low <= high
        mid = (low + high) / 2
        if A[mid] == key
            return mid
        else if A[mid] < key
            low = mid + 1
        else
            high = mid - 1
    return -1
```

**时间复杂度分析：**
- 最差情况：O(log n)，当需要查找的元素位于数组的末端或不存在时。
- 平均情况：O(log n)，由于二分查找每次都能将查找范围缩小一半。
- 最优情况：O(1)，当目标元素正好位于数组中间。

**空间复杂度：**
- O(1)，二分查找算法在原地操作，不需要额外的存储空间。

#### 快速排序算法

快速排序算法是一种高效的排序算法，其基本思想是通过选取一个“基准”元素，将数组划分为两个子数组，一个包含小于基准元素的元素，另一个包含大于基准元素的元素。然后递归地对这两个子数组进行排序。

**伪代码：**

```
QUICKSORT(A[low...high])
    if low < high
        pi = PARTITION(A[low...high])
        QUICKSORT(A[low...pi-1])
        QUICKSORT(A[pi+1...high])

PARTITION(A[low...high], pivotIndex)
    pivot = A[pivotIndex]
    swap(A[pivotIndex], A[high])
    storeIndex = low
    for i = low to high-1
        if A[i] < pivot
            swap(A[storeIndex], A[i])
            increment storeIndex
    swap(A[storeIndex], A[high])
    return storeIndex
```

**时间复杂度分析：**
- 最差情况：O(n^2)，当数组已经排序或逆序时，每次划分都会导致大量元素的不必要比较。
- 平均情况：O(n log n)，由于快速排序通过递归划分将问题分解成更小的子问题，并利用随机性来避免最差情况。
- 最优情况：O(n log n)，当每次划分都能大致平衡子数组的大小。

**空间复杂度：**
- O(log n)，快速排序使用递归，其空间复杂度与递归深度相关。

- **空间复杂度**：二分查找算法的空间复杂度是O(1)，非常适合大规模数据的查找操作；而快速排序算法的空间复杂度是O(log n)，可能会在递归过程中占用较多内存。
