### 第一部分：数论基础

#### 第1章：数论概述

##### 1.1 数论的定义与应用

数论是数学的一个重要分支，主要研究整数及其性质。数论的应用非常广泛，从最基础的密码学算法，如RSA加密算法，到现代密码学协议，如Diffie-Hellman密钥交换协议，都离不开数论的支持。

##### 1.2 整除与同余

##### 1.2.1 整除的概念

整除是数论中的基本概念，如果一个整数a除以另一个整数b（b不等于0）得到的结果是整数而没有余数，那么我们说a能被b整除，或者说b能整除a。

##### 1.2.2 同余的概念

同余是数论中的一个重要概念，它描述了两个整数在模某个数m下的关系。如果两个整数a和b对某个正整数m取余的结果相同，即a ≡ b (mod m)，我们就说a和b在模m下同余。

##### 1.2.3 同余的运算性质

同余运算具有封闭性、结合律、分配律等性质，这些性质在密码学中有重要的应用。

##### 1.3 算术基本定理

##### 1.3.1 算术基本定理的内容

算术基本定理，也称欧拉定理，是数论中的一个重要定理。它指出，如果a和n是正整数，并且a和n互质，那么a的(n-1)次方对n取余等于1，即$$a^{(n-1)} \equiv 1 \pmod{n}$$。

##### 1.3.2 算术基本定理的应用

算术基本定理在密码学中有广泛的应用，特别是在RSA加密算法中，它用来计算公钥和私钥。

##### 1.4 最大公约数与最小公倍数

##### 1.4.1 最大公约数的定义与计算

最大公约数是指两个或多个整数的公共因子中最大的一个。计算最大公约数常用的算法是欧几里得算法。

##### 1.4.2 最小公倍数的定义与计算

最小公倍数是指两个或多个整数的公共倍数中最小的一个。计算最小公倍数的方法是先计算最大公约数，然后利用最大公约数和两个整数的乘积来求得。

##### 3.1.1 欧拉函数的定义

##### 3.2 费马小定理

##### 3.2.1 费马小定理的定义

费马小定理是数论中的一个基本定理，它指出，如果p是一个素数，那么对于任何与p互质的整数a，都有$$a^{(p-1)} \equiv 1 \pmod{p}$$。

##### 3.3 素数生成算法

##### 3.3.1 素数生成算法的介绍

素数生成算法是用来生成素数的算法，如米勒-拉宾素性测试等。

##### 3.3.2 素数生成算法的Python实现

下面是一个简单的Python代码示例，用于生成大素数。

```python
import random

def is_prime(n):
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6
    return True

def generate_prime():
    while True:
        num = random.randrange(2, 100)
        if is_prime(num):
            return num

# 生成一个大素数
prime = generate_prime()
print(f"Generated prime number: {prime}")
```

- **B.1 AES加密算法的Python实现**

  ```python
  from Cryptodome.Cipher import AES
  from Cryptodome.Random import get_random_bytes

  # 生成密钥和初始向量
  key = get_random_bytes(16)
  iv = get_random_bytes(16)

  # 创建AES加密对象
  cipher = AES.new(key, AES.MODE_CBC, iv)

  # 待加密的数据
  plaintext = b"Hello, World!"

  # 打印密文和初始向量

  ```

- **B.2 RSA加密算法的Python实现**
  ```python
  from Cryptodome.PublicKey import RSA
  from Cryptodome.Cipher import PKCS1_OAEP

  # 生成RSA密钥对
  key = RSA.generate(2048)
  private_key = key.export_key()
  public_key = key.publickey().export_key()

  # 加密数据
  cipher = PKCS1_OAEP.new(RSA.import_key(public_key))
  ciphertext = cipher.encrypt(b"Hello, World!")

  # 打印公钥和密文
  print("Public Key:", public_key.decode())
  print("Ciphertext:", ciphertext.hex())
  ```

- **B.3 Diffie-Hellman密钥交换协议的Python实现**

  ```python
  from Cryptodome.Random import get_random_bytes

  # 生成DSA密钥对
  key = DSA.generate(1024)
  private_key = key.export_key()
  public_key = key.publickey().export_key()

  # 生成随机数
  k = get_random_bytes(16)

  # 计算公钥
  public_key = pow(key.g, k, key.p)

  # 计算共享密钥
  shared_key = pow(public_key, private_key, key.p)

  # 打印公钥、私钥和共享密钥
  print("Public Key:", public_key.hex())
  print("Private Key:", private_key.decode())
  print("Shared Key:", shared_key.hex())
  ```
