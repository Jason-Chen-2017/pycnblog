## 第三部分：算法原理讲解与实现

### 第4章：核心算法原理

#### 4.1 算法概述

在可持续采购中，核心算法主要用于原料的筛选和风险评估。本文采用的一种常见算法是**K最近邻（K-Nearest Neighbors，KNN）**算法。

KNN算法的基本思想是：如果一个新样本在特征空间中的k个最近邻中的大多数属于某一个类别，则该样本也属于这个类别。

KNN算法的主要目的是预测新样本的类别，其优点包括：

1. **简单易实现**：不需要复杂的模型训练过程，只需计算距离和投票。
2. **可解释性**：通过查看最近的邻居，可以理解预测结果的原因。
3. **灵活性**：适用于各种类型的数据和分类问题。

#### 4.2 算法流程图

下面是KNN算法的流程图：

```mermaid
graph TB
A[输入新样本] --> B[计算距离]
B --> C{距离排序}
C -->|排序结果| D[选择最近的k个邻居]
D --> E[计算邻居的类别频率]
E --> F[预测新样本的类别]
F --> G[输出结果]
```

#### 4.3 数学模型与公式

KNN算法的数学模型主要包括距离计算和类别预测。

**距离计算**：常用的距离度量方法是欧氏距离，公式如下：

$$
d = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}
$$

其中，$x$和$y$是两个样本的向量，$n$是特征的数量。

**类别预测**：假设新样本的邻居中，有$m$个属于类别$C_1$，$n-m$个属于类别$C_2$，则新样本的预测类别为：

$$
\hat{y} = \begin{cases} 
C_1 & \text{if } \frac{m}{n} > \frac{1}{2} \\
C_2 & \text{otherwise}
\end{cases}
$$

#### 4.4 Python源代码实现

以下是KNN算法的Python实现：

```python
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import train_test_split
from sklearn.datasets import load_iris
import numpy as np

# 加载鸢尾花数据集
iris = load_iris()
X = iris.data
y = iris.target

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 创建KNN分类器
knn = KNeighborsClassifier(n_neighbors=3)

# 训练模型
knn.fit(X_train, y_train)

# 预测测试集
y_pred = knn.predict(X_test)

# 计算准确率
accuracy = np.mean(y_pred == y_test)
print("Accuracy:", accuracy)
```

```python
# 导入相关库
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler

# 数据收集
data = pd.read_csv("spice_data.csv")

# 数据清洗
data.dropna(inplace=True)
data = data[data["price"] > 0]

# 特征选择
X = data[["source", "process", "environment"]]
y = data["sustainability"]

# 数据标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.3, random_state=42)

# 模型训练
knn = KNeighborsClassifier(n_neighbors=3)
knn.fit(X_train, y_train)

# 用户界面
def predict_sustainability(source, process, environment):
    sample = np.array([[source, process, environment]])
    sample_scaled = scaler.transform(sample)
    prediction = knn.predict(sample_scaled)
    return "Sustainable" if prediction == 1 else "Not Sustainable"

# 测试
print(predict_sustainability(1, 2, 3))
```
