#### 3.1 搜索算法

搜索算法是解决宇宙大尺度空洞并合网络动力学问题的重要工具。搜索算法通过在给定数据结构中查找特定信息，以确定是否存在满足特定条件的路径或节点。以下是两种常用的搜索算法：深度优先搜索（DFS）和广度优先搜索（BFS）。

**深度优先搜索（DFS）**

深度优先搜索是一种逐层遍历数据结构的算法，它从起始节点开始，尽可能深地搜索树的分支。在DFS中，算法使用一个栈来存储访问的节点，从而实现递归遍历。

```python
def DFS(node):
    visited.add(node)
    for neighbor in node.neighbors:
        if neighbor not in visited:
            DFS(neighbor)
```

**广度优先搜索（BFS）**

广度优先搜索是一种逐层遍历数据结构的算法，它与DFS不同，先访问起始节点的所有直接邻居，然后再逐层访问邻居的邻居。在BFS中，算法使用一个队列来存储访问的节点。

```python
from collections import deque

def BFS(start_node):
    visited = set()
    queue = deque([start_node])
    while queue:
        node = queue.popleft()
        visited.add(node)
        for neighbor in node.neighbors:
            if neighbor not in visited:
                queue.append(neighbor)
```

**应用：**

- **连通性分析**：通过DFS或BFS算法，可以分析宇宙大尺度空洞网络的连通性，确定哪些空洞之间存在引力相互作用。

#### 3.2 排序算法

**冒泡排序**

冒泡排序是一种简单的排序算法，它通过重复遍历要排序的数列，比较相邻元素的大小，并交换它们的位置，直到整个序列有序。

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
```

**选择排序**

选择排序是一种简单的选择排序算法，它通过每次遍历选择未排序部分中的最小（或最大）元素，并将其放在已排序部分的末尾。

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
```

**插入排序**

插入排序是一种通过构建有序序列来排序的方法，它通过每次将一个元素插入到已排序序列中的正确位置来逐步构建最终排序序列。

```python
def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]
        j = i-1
        while j >= 0 and key < arr[j]:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key
```

**快速排序**

快速排序是一种高效的排序算法，它通过递归地将数组分成较小和较大的两个子数组，然后对这两个子数组进行排序。

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```

动态规划的核心思想是：将一个复杂问题分解为若干个相互重叠的子问题，然后按顺序解决这些子问题，并将子问题的解存储在一个表中，以便后续使用。

def dynamic_programming(subproblems):
    dp = [[None for _ in range(n+1)] for _ in range(m+1)]

    # 合并两个节点
    G.remove_node(node1)
    G.remove_node(node2)
    G.add_node(max(node1, node2))
    for neighbor in G.neighbors(node1):

    for neighbor in G.neighbors(node2):
        G.add_edge(max(node1, node2), neighbor)

# 模拟并合过程
merged_nodes = []
for node in G.nodes():

    if len(neighbors) > 1:

        merge_nodes(G, node, neighbor)
        merged_nodes.append((node, neighbor))
