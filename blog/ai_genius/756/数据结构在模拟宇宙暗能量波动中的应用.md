#### 1.1 暗能量的定义与性质

暗能量是一种假设存在的宇宙能量形式，它不发光、不发热，且对引力有排斥作用。根据宇宙学的研究，暗能量占据了宇宙总能量密度的约 68%，是推动宇宙加速膨胀的主要力量。暗能量的性质主要包括以下几个方面：

1. **宇宙加速膨胀**：暗能量与宇宙膨胀之间的相互作用导致了宇宙的加速膨胀。
2. **负压强**：暗能量具有负压强，这使其对引力产生排斥作用，进而推动宇宙加速膨胀。
3. **不可见**：暗能量不可见，因此无法直接观测到。
4. **均匀分布**：暗能量在宇宙中均匀分布，不依赖于物质分布。

宇宙膨胀是指宇宙中的所有物质（包括星系、星团、星云等）在时间维度上不断远离彼此的现象。暗能量是导致宇宙加速膨胀的主要原因。宇宙学研究表明，宇宙膨胀速度随着时间的推移而加快，这表明暗能量在宇宙演化中起着至关重要的作用。

```python
class Graph:
    def __init__(self):
        self.vertices = {}
    
    def add_edge(self, u, v):
        if u not in self.vertices:
            self.vertices[u] = []
        if v not in self.vertices:
            self.vertices[v] = []
        self.vertices[u].append(v)
        self.vertices[v].append(u)

    def bfs(self, start):
        visited = set()
        queue = deque([start])
        visited.add(start)
        
        while queue:
            vertex = queue.popleft()
            print(vertex)
            
            for neighbor in self.vertices[vertex]:
                if neighbor not in visited:
                    queue.append(neighbor)
                    visited.add(neighbor)

# 创建图
g = Graph()
g.add_edge(1, 2)
g.add_edge(1, 3)
g.add_edge(2, 4)
g.add_edge(3, 4)
g.add_edge(4, 5)

# 广度优先搜索
g.bfs(1)
```

```python
        self.max_level = max_level
        self.head = Node(-∞)
        self.level = 0
        
    def random_level(self):
        level = 1
        while random() < 0.5 and level < self.max_level:
            level += 1
        return level

    def search(self, x):
        current = self.head
        for i in range(self.level, -1, -1):
            while current.right[i].data < x:
                current = current.right[i]
        current = current.right[0]
        return current.data == x

    def insert(self, x):
        level = self.random_level()
        if level > self.level:
            for i in range(self.level + 1, level + 1):
                self.head.right.append(Node(-∞))
            self.level = level

        node = Node(x)
        current = self.head
        for i in range(self.level, -1, -1):
            while current.right[i].data < x:
                current = current.right[i]
            current.right[i] = node

class Node:
```
