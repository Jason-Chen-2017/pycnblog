#### 线性回归

线性回归是一种简单的机器学习算法，用于预测连续值输出。在探测宇宙暗流网络中，我们可以使用线性回归来预测星系的运动速度。具体步骤如下：

1. **数据准备**：收集大量星系的位置和速度数据，将位置数据作为特征输入，速度数据作为目标输出。

2. **模型构建**：使用线性回归算法构建预测模型，公式为：

   $$ y = wx + b $$

   其中，\( y \) 是星系的运动速度，\( x \) 是位置特征，\( w \) 是权重，\( b \) 是偏置。

3. **模型训练**：使用训练数据集对模型进行训练，调整权重和偏置，使预测值与实际值之间的误差最小。

4. **模型评估**：使用验证数据集对模型进行评估，计算预测值与实际值之间的均方误差（MSE），以评估模型性能。

   ```python
   import numpy as np
   from sklearn.linear_model import LinearRegression

   # 特征和目标数据
   X = np.array([[1], [2], [3], [4], [5]])
   y = np.array([1, 2, 3, 4, 5])

   # 构建模型
   model = LinearRegression()

   # 训练模型
   model.fit(X, y)

   # 预测
   prediction = model.predict([[6]])

   # 计算均方误差
   mse = np.mean((prediction - y)**2)
   print(f"MSE: {mse}")
   ```

mse_linear = np.mean((y_pred_linear - y_test)**2)

# 决策树评估
y_pred_tree = decision_tree.predict(X_test)
accuracy_tree = decision_tree.score(X_test, y_test)
print(f"决策树准确率：{accuracy_tree}")

# 随机森林评估
y_pred_forest = random_forest.predict(X_test)
accuracy_forest = random_forest.score(X_test, y_test)
print(f"随机森林准确率：{accuracy_forest}")

plt.show()
