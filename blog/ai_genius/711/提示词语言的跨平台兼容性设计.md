### 提示词语言的基本概念

提示词语言，又称提示符语言，是一种用于与计算机系统交互的编程语言。它通过提示符（Prompt）与用户进行交互，接收用户的输入并执行相应的操作。提示词语言在操作系统、命令行界面、脚本编程等领域中广泛应用。常见的提示词语言包括Bash（Linux系统）、CMD（Windows系统）和PowerShell（Windows系统）等。

**提示词语言的基本组成部分**：

1. **提示符**：提示符是用户与系统交互的入口，如Linux系统的`$`和Windows系统的`>`。
2. **命令**：命令是用户输入的指令，如`ls`、`mkdir`等。
3. **参数**：参数是命令的补充信息，如`ls -l`中的`-l`表示显示详细列表。
4. **控制结构**：控制结构用于控制程序流程，如循环、条件语句等。

**提示词语言的发展历史**：

- **1960年代**：早期计算机系统使用的是批处理系统，用户需要通过提交卡片或磁带进行作业提交。
- **1970年代**：Unix操作系统的出现，引入了命令行界面和提示符概念，Bash的前身Bourne Shell诞生。
- **1980年代**：Windows操作系统的兴起，引入了CMD命令行工具。
- **1990年代**：随着互联网的发展，提示词语言在脚本编程和自动化任务中得到了广泛应用。
- **2000年代**：PowerShell的出现，提供了更强大的脚本编程能力和自动化功能。

import argparse
import os

def read_file(file_path):

    else:

def main():

    parser.add_argument("--input", help="输入文件路径")
    parser.add_argument("--output", help="输出文件路径")

        if content:
            print("读取文件成功：")
            print(content)
        else:

    if args.output:

if __name__ == "__main__":
