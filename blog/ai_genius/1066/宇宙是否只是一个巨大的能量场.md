### 2. 数学模型

宇宙背景辐射的空间分布可以用一个高斯分布来描述。高斯分布的公式为：

$$
P(r) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(r - \mu)^2}{2\sigma^2}\right)
$$

其中，$P(r)$ 表示在位置 $r$ 的概率密度，$\mu$ 表示平均值，$\sigma$ 表示标准差。

### 1. 宇宙背景辐射温度分布

宇宙背景辐射的温度分布可以用普朗克分布（Planck distribution）来描述。普朗克分布是描述黑体辐射的光谱分布的公式，其表达式为：

$$
B(\lambda, T) = \frac{2hc^2}{\lambda^5} \frac{1}{e^{hc/\lambda k_B T} - 1}
$$

其中，$B(\lambda, T)$ 是波长 $\lambda$ 和温度 $T$ 下的辐射亮度，$h$ 是普朗克常数，$c$ 是光速，$k_B$ 是玻尔兹曼常数。

推导过程：

普朗克分布是通过对黑体辐射能量分布进行实验观察和理论推导得出的。实验结果表明，黑体辐射的能量分布与波长和温度有关。普朗克通过假设能量分布遵循特定的公式，最终推导出了上述公式。

应用场景：

普朗克分布广泛应用于天体物理学中，用于分析宇宙背景辐射的温度分布。通过对宇宙背景辐射光谱的测量，科学家们可以推断出宇宙早期的温度和密度。

示例：

假设宇宙背景辐射的温度为 $T = 2.725K$，我们可以使用普朗克分布计算在波长 $\lambda = 1\text{mm}$ 下的辐射亮度：

$$
B(\lambda, T) = \frac{2hc^2}{\lambda^5} \frac{1}{e^{hc/\lambda k_B T} - 1} \approx 1.4 \times 10^{-20} \text{W m}^{-2} \text{Hz}^{-1}
$$

### 2. 宇宙膨胀速度

宇宙膨胀速度可以用哈勃定律（Hubble's Law）来描述，其公式为：

$$
v = H_0 d
$$

其中，$v$ 是物体的膨胀速度，$H_0$ 是哈勃常数，$d$ 是物体与观察者之间的距离。

推导过程：

哈勃定律是通过观测远处星系的红移和距离之间的关系推导出来的。红移与距离成正比，意味着星系远离我们，且远离速度与距离成正比。这个比例系数就是哈勃常数。

应用场景：

哈勃定律是宇宙学中的基本定律，用于描述宇宙的膨胀速度。通过对宇宙背景辐射和星系运动的观测，科学家们可以估算出哈勃常数。

示例：

假设一个星系距离地球 $d = 100Mpc$，且根据哈勃定律其膨胀速度为 $v = H_0 d$。如果哈勃常数 $H_0 = 70 \text{km s}^{-1} \text{Mpc}^{-1}$，则星系的膨胀速度为：

$$
v = 70 \text{km s}^{-1} \text{Mpc}^{-1} \times 100 \text{Mpc} = 7000 \text{km s}^{-1}
$$

### 3. 黑洞质量与引力场

黑洞的质量与其引力场的关系可以用史瓦西半径（Schwarzschild radius）来描述，其公式为：

$$
r_s = \frac{2GM}{c^2}
$$

其中，$r_s$ 是史瓦西半径，$G$ 是引力常数，$M$ 是黑洞的质量，$c$ 是光速。

推导过程：

史瓦西半径是爱因斯坦的广义相对论推导出来的。当物体的引力场足够强时，其表面会形成一个事件视界，即光无法逃逸的区域。这个区域的半径就是史瓦西半径。

应用场景：

史瓦西半径用于描述黑洞的引力场强度。通过对黑洞的观测，科学家们可以估算出黑洞的质量和引力场的特性。

示例：

假设一个黑洞的质量为 $M = 10^6M_{\odot}$，其中 $M_{\odot}$ 是太阳质量。根据公式计算其史瓦西半径：

$$
r_s = \frac{2G \times 10^6M_{\odot}}{c^2} \approx 3 \times 10^3 \text{km}
$$

### 2. 源代码实现

下面是一个简单的Python脚本，用于模拟宇宙背景辐射的空间分布。我们将使用之前介绍的普朗克分布公式进行计算。

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数设置
mu = 0.0  # 平均值
sigma = 1.0  # 标准差
N = 1000  # 样本数量
c = 3e8  # 光速
k_B = 1.38e-23  # 玻尔兹曼常数
h = 6.626e-34  # 普朗克常数
lambda_max = 1e-2  # 波长最大值

# 普朗克分布函数
def planck_distribution(lambda_value, T):
    return (2 * h * c**2 / (lambda_value**5)) * (1 / (np.exp(h * c / (lambda_value * k_B * T)) - 1))

# 生成样本数据
lambda_values = np.random.uniform(1e-3, lambda_max, N)
T = 2.725  # 宇宙背景辐射温度

# 计算概率密度分布
P = planck_distribution(lambda_values, T)

# 绘制分布图
plt.hist(lambda_values, bins=30, weights=P, alpha=0.6, color='g')
plt.xlabel('波长（λ）')
plt.ylabel('概率密度（P(λ)）')
plt.title('宇宙背景辐射的概率密度分布')
plt.show()
```
