function SVD_Reconstruction(A, σ_min, σ_max):

### 数学公式与解释
#### 稀疏性度量
$$
\|\mathbf{x}\|_0 = \sum_{i=1}^n \mathbf{1}_{\{\alpha_i \neq 0\}}
$$
其中，$ \mathbf{1}_{\{\alpha_i \neq 0\}} $ 是指示函数，当 $ \alpha_i \neq 0 $ 时取值为1，否则为0。

#### 傅里叶变换
$$
\hat{\mathbf{f}}(\omega) = \int_{-\infty}^{\infty} \mathbf{f}(t)e^{-i\omega t} dt
$$
其中，$ \hat{\mathbf{f}}(\omega) $ 是信号 $ \mathbf{f}(t) $ 的傅里叶变换，$ \omega $ 是频率。

##### 第1章：数学基础知识回顾

在本章中，我们将回顾一些基础的数学概念，这些概念是理解和应用压缩感知技术的基石。

##### 1.1 集合与映射

集合是数学中最基本的概念之一。在集合论中，元素是任何可以被认为是对象的东西，而集合是一组不同的元素的集合。常见的集合运算包括并集（∪）、交集（∩）、补集（∁）和差集（−）。

映射（函数）是集合之间的一种对应关系。形式上，给定两个集合X和Y，映射f是从X到Y的函数，如果对于X中的每一个元素x，都有一个唯一的Y中的元素y与之对应。

##### 1.2 线性空间与线性变换

线性空间是向量空间的一种推广，其中向量可以是多维的。线性空间V中的元素被称为向量，而线性变换T是从V到另一个线性空间W的函数，它满足以下条件：
1. 线性组合封闭：对于任意的向量x, y ∈ V和标量α, β ∈ F，有T(αx + βy) = αT(x) + βT(y)。
2. 零向量映射：T(0) = 0。

矩阵可以表示线性变换，因此线性空间和线性变换在矩阵理论中有着重要的应用。

##### 1.3 矩阵理论

矩阵是二维数组的扩展，它们在数学和工程中广泛应用。矩阵的运算包括加法、数乘、乘法等。矩阵的行列式、逆矩阵、特征值和特征向量等概念是矩阵理论中的核心部分。

##### 1.4 概率论基础

概率论是研究随机事件及其概率的数学分支。基本概念包括随机实验、样本空间、事件、概率、条件概率和独立事件。常见的概率分布包括离散分布（如伯努利分布、几何分布）和连续分布（如正态分布、泊松分布）。

##### 第2章：信号处理基础

信号处理是利用数学方法对信号进行分析、处理和恢复的学科。本章将介绍信号处理的基础知识。

##### 2.1 信号的分类与表示

信号根据其特征可以分为连续信号和离散信号。连续信号可以用傅里叶变换来表示，而离散信号则通常使用Z变换或离散傅里叶变换来分析。

##### 2.2 离散时间系统与卷积

离散时间系统是指系统处理的是离散时间信号。卷积是离散时间系统中的一个基本运算，用于描述系统的响应与输入信号的相互作用。

##### 2.3 傅里叶变换与Z变换

傅里叶变换是分析信号频率信息的重要工具。它将时域信号转换为频域信号，使得我们可以从频率的角度来理解信号。Z变换则提供了将离散时间信号转换为复平面上的函数的方法。

##### 3.1 压缩感知原理

压缩感知的核心思想是信号的稀疏表示。稀疏信号可以在某个基底下用少量的非零系数来近似表示。通过在测量矩阵的作用下对信号进行压缩感知测量，我们可以利用这些少量的测量数据来重建原始信号。

##### 3.2 压缩感知模型

压缩感知模型通常包括三个部分：稀疏信号空间、测量矩阵和恢复算法。其中，测量矩阵的选择对压缩感知的性能至关重要。

#### 实现环境

- NumPy
- SciPy

#### 实现步骤
1. 加载图像数据。
2. 对图像进行随机采样。
3. 使用奇异值分解进行信号重建。
4. 绘制重建后的图像。

#### 代码实现
```python
import numpy as np
from scipy.linalg import svd
import matplotlib.pyplot as plt

# 加载图像数据
image = plt.imread('image.png')

# 对图像进行随机采样
measured_signal = np.random.rand(image.shape[0], image.shape[1])

# 使用奇异值分解进行信号重建
U, Σ, V = svd(image)
σ_min = np.mean(Σ)
σ_max = np.max(Σ)
S = np.diag(σ_min, ..., σ_min, σ_max, ..., σ_max)
reconstructed_image = U * S * V'

# 绘制重建后的图像
plt.figure()
plt.subplot(121)
plt.imshow(image, cmap='gray')
plt.title('Original Image')
plt.subplot(122)
plt.imshow(reconstructed_image, cmap='gray')
plt.title('Reconstructed Image')
plt.show()
```
