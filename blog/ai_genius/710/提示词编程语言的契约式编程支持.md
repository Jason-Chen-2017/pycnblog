```

    z := x * y
    return z
```

在这个例子中，前置条件和后置条件通过注释的形式给出，确保函数的执行符合预期的行为。

#### 契约式编程的基本概念

契约式编程的核心思想是通过定义一系列契约，确保程序在执行过程中满足预期的行为。契约通常包括以下几部分：

1. **前置条件（Preconditions）**：前置条件定义了函数或方法在执行前需要满足的条件。例如，一个计算两个数最大公约数的函数可能需要前置条件确保两个数都是正整数。

2. **后置条件（Postconditions）**：后置条件定义了函数或方法在执行后需要满足的条件。例如，一个计算两个数最大公约数的函数可能需要后置条件确保返回的值是两个数的公约数。

3. **不变量（Invariants）**：不变量定义了程序在执行过程中需要保持的不变状态。例如，一个银行账户的类可能有一个不变量确保账户的余额不会为负。

4. **异常条件（Exception Conditions）**：异常条件定义了在特定情况下函数或方法可能抛出的异常。例如，一个尝试从空列表中取值的函数可能抛出一个空列表异常。

通过这些契约，我们可以确保程序的正确性和可靠性。例如，如果一个函数违反了它的前置条件，那么它在执行时可能会出现未定义的行为，从而导致错误。

在这个例子中，我们使用了`ensure`提示词来定义前置条件和后置条件，以及`invariant`提示词来定义不变量。

2. **契约验证**：提示词编程语言可以提供编译时或运行时的验证机制，确保契约在执行过程中得到满足。例如，编译器可以在编译时检查契约是否满足类型要求，并在运行时检查契约是否满足逻辑条件。
