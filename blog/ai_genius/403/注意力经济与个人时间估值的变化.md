- **发展阶段（20世纪90年代）**：随着互联网的兴起，注意力经济研究逐渐深入，关注点从个人注意力转向市场机制和商业模式。
- **成熟阶段（21世纪初至今）**：注意力经济理论不断发展和完善，研究范围扩展到多个领域，如市场营销、广告、社交媒体等。

### 附录C：代码示例

```python
# 代码示例：注意力分配算法

def allocate_attention(working_hours, tasks):
    """
    计算注意力分配
    :param working_hours: 工作时长
    :param tasks: 任务列表
    :return: 注意力分配结果
    """
    attention分配 = {}
    total_attention = working_hours

    for task in tasks:
        effort = tasks[task]
        attention分配[task] = (total_attention * effort) / sum(effort for task in tasks)

    return attention分配

# 示例数据
working_hours = 8
tasks = {'任务1': 2, '任务2': 3, '任务3': 1.5}

# 计算注意力分配
attention分配 = allocate_attention(working_hours, tasks)

# 输出结果
print("注意力分配：", attention分配)
```

**代码解读与分析**

- `allocate_attention`函数：计算注意力分配
- `working_hours`：工作时长
- `tasks`：任务列表，包含任务名称和所需时间
- `attention分配`：注意力分配结果，以字典形式存储
- `total_attention`：总注意力值
- `effort`：任务所需时间
- `sum(effort for task in tasks)`：计算总努力值
- `attention分配[task]`：计算每个任务的注意力分配比例
- `print`：输出注意力分配结果

##### 1.1.1 注意力经济的起源与发展

**注意力经济**是一种基于人类注意力资源稀缺性的经济理论。它起源于20世纪80年代，由美国经济学家Richard L. Shavelson首次提出。随着信息技术的迅猛发展和社交媒体的普及，注意力经济逐渐成为现代经济学研究的一个重要领域。

**注意力经济的历史发展**

1. **早期阶段（20世纪80年代）**：注意力经济概念首次被提出，主要关注注意力资源的分配和利用。
2. **发展阶段（20世纪90年代）**：随着互联网的兴起，注意力经济研究逐渐深入，关注点从个人注意力转向市场机制和商业模式。
3. **成熟阶段（21世纪初至今）**：注意力经济理论不断发展和完善，研究范围扩展到多个领域，如市场营销、广告、社交媒体等。

#### 附录C：代码示例

```python
# 代码示例：注意力分配算法

def allocate_attention(working_hours, tasks):
    """
    计算注意力分配
    :param working_hours: 工作时长
    :param tasks: 任务列表
    :return: 注意力分配结果
    """
    attention分配 = {}
    total_attention = working_hours

    for task in tasks:
        effort = tasks[task]
        attention分配[task] = (total_attention * effort) / sum(effort for task in tasks)

    return attention分配

# 示例数据
working_hours = 8
tasks = {'任务1': 2, '任务2': 3, '任务3': 1.5}

# 计算注意力分配
attention分配 = allocate_attention(working_hours, tasks)

# 输出结果
print("注意力分配：", attention分配)
```

**代码解读与分析**

- `allocate_attention`函数：计算注意力分配
- `working_hours`：工作时长
- `tasks`：任务列表，包含任务名称和所需时间
- `attention分配`：注意力分配结果，以字典形式存储
- `total_attention`：总注意力值
- `effort`：任务所需时间
- `sum(effort for task in tasks)`：计算总努力值
- `attention分配[task]`：计算每个任务的注意力分配比例
- `print`：输出注意力分配结果
