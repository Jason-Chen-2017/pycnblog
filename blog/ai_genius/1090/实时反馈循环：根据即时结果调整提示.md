def linear_regression(x, y):
    n = len(x)
    sum_x = sum(x)
    sum_y = sum(y)
    sum_xy = sum(x[i] * y[i] for i in range(n))
    sum_xx = sum(x[i]**2 for i in range(n))

    a = (n * sum_xy - sum_x * sum_y) / (n * sum_xx - sum_x**2)
    b = (sum_y - a * sum_x) / n

    return a, b
```

##### 2.2 算法原理及伪代码讲解

###### 2.2.1 线性回归
**原理**：线性回归是一种简单但强大的算法，通过拟合一条直线，将输入特征映射到目标值。其数学模型可以表示为：

\[ y = w_0 + w_1 \cdot x \]

其中，\( y \) 是目标值，\( x \) 是输入特征，\( w_0 \) 和 \( w_1 \) 是模型的权重。

**伪代码**：

```
function linear_regression(x, y):
    n = length(x)
    sum_x = 0
    sum_y = 0
    sum_xy = 0
    sum_xx = 0

    for i in range(n):
        sum_x += x[i]
        sum_y += y[i]
        sum_xy += x[i] * y[i]
        sum_xx += x[i] * x[i]

    w_1 = (n * sum_xy - sum_x * sum_y) / (n * sum_xx - sum_x^2)
    w_0 = (sum_y - w_1 * sum_x) / n

    return w_0, w_1
```

###### 2.2.2 决策树
**原理**：决策树是一种树形结构，通过递归地将数据集分割成多个子集，直至满足停止条件。每个节点代表一个特征，每个分支代表一个分割规则。决策树的生成过程可以看作是一个贪心算法，在每个阶段选择最佳的特征和分割点。

**伪代码**：

```
function decision_tree(data, depth=0, max_depth=100):
    if depth >= max_depth or number_of_samples(data) == 0:
        return None

    best_gain = 0.0
    best_feature = -1

    for feature in range(number_of_features(data)):
        gain = information_gain(data, feature)
        if gain > best_gain:
            best_gain = gain
            best_feature = feature

    node = Node(feature, best_gain, depth)
    split = split_data(data, best_feature)

    node.left = decision_tree(split.left, depth+1, max_depth)
    node.right = decision_tree(split.right, depth+1, max_depth)

    return node
```

function forward_pass(inputs, weights):
    layer_0 = inputs
    layer_1 = sigmoid(np.dot(layer_0, weights[0]))
    layer_2 = sigmoid(np.dot(layer_1, weights[1]))
    return layer_2

function backward_pass(inputs, targets, weights):
    layer_2_error = layer_2 - targets
    layer_1_error = np.dot(layer_2_error, weights[1].T)
    layer_1_delta = layer_1 * (1 - layer_1)
    layer_2_delta = layer_2 * (1 - layer_2)

    weights[1] -= learning_rate * np.dot(layer_1, layer_2_delta)
    weights[0] -= learning_rate * np.dot(layer_0.T, layer_1_delta)
```
