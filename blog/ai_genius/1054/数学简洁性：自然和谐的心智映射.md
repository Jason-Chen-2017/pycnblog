```python
def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

n = 29
if is_prime(n):
    print(f"{n} 是素数")
else:
    print(f"{n} 不是素数")
```

上述代码展示了如何使用Python实现试除法判断素数。通过心智映射，我们可以将数学模型应用于实际问题，从而实现高效的计算。


   上面的代码生成了一个简单的社交网络图。

2. **计算互动强度**

   接下来，我们计算每个用户与其他用户的互动强度。我们使用度数中心性（Degree Centrality）作为互动强度的度量，度数中心性表示节点在图中的连接数。连接数越多，表示该用户与其他用户的互动越频繁。

   ```python
   # 计算度数中心性
   centrality = nx.degree_centrality(G)
   
   # 输出度数中心性
   for user, strength in centrality.items():
       print(f"用户{user}的互动强度为：{strength}")
   ```

   上面的代码计算并输出了每个用户的互动强度。

3. **识别高互动用户群**

   我们可以设置一个阈值，将度数中心性高于该阈值的用户视为高互动用户。例如，我们设置阈值为0.5，即度数中心性大于0.5的用户被视为高互动用户。

   ```python
   # 设置互动强度阈值
   threshold = 0.5
   
   # 识别高互动用户
   high_interactive_users = [user for user, strength in centrality.items() if strength > threshold]
   
   # 输出高互动用户
   print("高互动用户群：", high_interactive_users)
   ```

   上面的代码识别并输出了高互动用户群。

4. **分析互动模式**

   我们可以进一步分析用户之间的互动模式。例如，我们可以找出哪些用户之间的互动最为频繁。这可以通过计算邻接矩阵来实现。

   ```python
   # 计算邻接矩阵
   adj_matrix = nx.adjacency_matrix(G).toarray()
   
   # 输出邻接矩阵
   print("邻接矩阵：")
   print(adj_matrix)
   
   # 分析互动模式
   for i in range(adj_matrix.shape[0]):
       for j in range(adj_matrix.shape[1]):
           if adj_matrix[i][j] > 0:
               print(f"用户{i}与用户{j}互动频繁")
   ```

   上面的代码计算并输出了邻接矩阵，并分析了用户之间的互动模式。
