## 附录：Python 源代码

以下是一个简单的 Python 源代码，用于计算中性氢21厘米线偏振的偏振度：

```python
import numpy as np
import matplotlib.pyplot as plt

# 假设我们有一组观测数据，表示中性氢21厘米线辐射的偏振方向
polarization_data = np.array([[1, 0], [-1, 0], [0, 1], [0, -1]])

# 计算偏振度
polarization_degrees = np.arctan2(polarization_data[:, 1], polarization_data[:, 0])

# 绘制偏振度分布
plt.scatter(polarization_data[:, 0], polarization_data[:, 1], c=polarization_degrees, cmap='coolwarm')
plt.xlabel('X-axis')
plt.ylabel('Y-axis')
plt.title('Polarization Degree Distribution')
plt.colorbar(label='Polarization Degree (radians)')
plt.show()
```
