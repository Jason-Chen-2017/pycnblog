```python
def select_tool(criteria, tools):
    scores = []
    for tool in tools:
        score = 0
        for criterion in criteria:
            if criterion in tool.features:
                score += 1
        scores.append(score)
    best_tool_index = scores.index(max(scores))
    return tools[best_tool_index]
```
