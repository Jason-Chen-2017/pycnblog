#### 4.1 线性回归

- **背景介绍**：介绍线性回归的基本原理和应用场景。

- **核心算法原理讲解**：使用伪代码详细阐述线性回归的算法原理。

  ```python
  # 线性回归伪代码
  def linear_regression(X, y):
      # 梯度下降算法
      theta = [0 for _ in range(n_features)]
      alpha = 0.01
      iterations = 1000
      for i in range(iterations):
          errors = (X * theta) - y
          gradient = X.T * errors
          theta -= alpha * gradient
      return theta
  ```

#### 4.2 逻辑回归

- **背景介绍**：介绍逻辑回归的基本原理和应用场景。

- **核心算法原理讲解**：使用伪代码详细阐述逻辑回归的算法原理。

  ```python
  # 逻辑回归伪代码
  def logistic_regression(X, y):
      # 梯度下降算法
      theta = [0 for _ in range(n_features)]
      alpha = 0.01
      iterations = 1000
      for i in range(iterations):
          predictions = 1 / (1 + np.exp(-X * theta))
          errors = predictions - y
          gradient = X.T * errors
          theta -= alpha * gradient
      return theta
  ```

      prior = [np.mean(y_train == class_) for class_ in np.unique(y_train)]
