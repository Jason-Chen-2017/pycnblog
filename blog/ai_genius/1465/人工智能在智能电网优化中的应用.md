### 3.1 常规优化算法

常规优化算法是指利用数学建模和优化理论，解决特定优化问题的一类算法。在智能电网优化中，常用的常规优化算法包括：

#### 3.1.1 粒子群优化算法

粒子群优化算法（Particle Swarm Optimization，PSO）是一种基于群体智能的优化算法，通过模拟鸟群觅食行为，实现优化问题的求解。PSO算法的基本原理是，每个粒子都代表问题的一个潜在解，粒子通过迭代更新位置和速度，逐渐逼近最优解。

```python
def update_velocity(particle, global_best, w, c1, c2):
    r1, r2 = random.random(), random.random()
    v = w * particle.v + c1 * r1 * (particle.best_position - particle.position) + c2 * r2 * (global_best - particle.position)
    return v

def update_position(particle, v):
    particle.position += v
    return particle.position
```

遗传算法（Genetic Algorithm，GA）是一种基于自然选择和遗传学原理的优化算法。GA通过模拟生物进化过程，实现优化问题的求解。GA的基本原理是，通过交叉、变异等操作，生成新的个体，不断迭代，直到找到最优解。

#### 3.3.1 智能电网调度优化

import numpy as np

def fitness_function(x):
    # 定义目标函数
    return -sum((x - target)**2)

def pso(max_iterations, particle_num, dim, target):
    # 初始化粒子群
    particles = np.random.uniform(-1, 1, (particle_num, dim))
    velocities = np.random.uniform(-0.1, 0.1, (particle_num, dim))
    global_best = particles[0]
    global_best_fitness = fitness_function(particles[0])

    for _ in range(max_iterations):
        for i in range(particle_num):
            # 更新个体最佳
            if fitness_function(particles[i]) < fitness_function(particles[i].best_fitness):
                particles[i].best_fitness = fitness_function(particles[i])
                particles[i].best_position = particles[i].position
                
            # 更新全局最佳
            if fitness_function(particles[i].best_fitness) < global_best_fitness:
                global_best = particles[i].best_position
                global_best_fitness = particles[i].best_fitness
                
        # 更新速度和位置
        for i in range(particle_num):
            velocities[i] = update_velocity(particles[i], global_best, 0.5, 2, 2)
            particles[i].position = update_position(particles[i], velocities[i])
    
    return global_best

# 仿真实验

particle_num = 50
dim = 5
target = np.array([1, 2, 3, 4, 5])

global_best = pso(max_iterations, particle_num, dim, target)
print("Global best:", global_best)
