**数学模型和数学公式 & 详细讲解 & 举例说明**

- **数学公式：**

  $$y = f(x)$$

- **详细讲解：**

  映射可以将一个集合中的元素映射到另一个集合中，数学上通常用函数表示。例如，$y = f(x)$ 表示将 $x$ 映射到 $y$。

- **举例说明：**

  假设我们有一个输入集合 {1, 2, 3} 和一个输出集合 {4, 5, 6}，我们可以定义一个映射 $f$，使得 $f(1) = 4$，$f(2) = 5$，$f(3) = 6$。

#### 1.2 映射的分类

**核心概念与联系**

- **Mermaid 流程图：**

  ```python
      # 双射映射
      output = transform(input)
      return output
  ```

**数学模型和数学公式 & 详细讲解 & 举例说明**

- **数学公式：**

  - **单射：** 对于任意两个不同的输入 $x_1$ 和 $x_2$，有 $f(x_1) \neq f(x_2)$。
  - **满射：** 映射的输出集合是另一个集合的超集。
  - **双射：** 映射既是单射也是满射。

- **详细讲解：**

  单射、满射和双射是映射的几种分类方式。单射指的是每个输入元素映射到唯一的输出元素；满射指的是输出集合中的每个元素至少有一个输入元素映射到；双射则是单射和满射的结合。

- **举例说明：**

  假设我们有一个输入集合 {1, 2, 3} 和输出集合 {4, 5, 6}，可以定义以下映射：

  - 单射：$f(1) = 4$，$f(2) = 5$，$f(3) = 6$
  - 满射：$f(1) = 4$，$f(2) = 5$，$f(3) = 6$
  - 双射：$f(1) = 4$，$f(2) = 5$，$f(3) = 6$
