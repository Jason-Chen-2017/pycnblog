### 第2章：物质与能量的基本结构

#### 2.1 原子与分子的结构

原子是物质的基本单位，由原子核和围绕原子核的电子组成。原子核由质子和中子构成，其中质子带正电，中子不带电。电子带负电，围绕原子核高速旋转。分子是由两个或更多原子通过化学键结合而成的。化学键可以是离子键、共价键或金属键。

#### 2.2 核能和粒子物理

核能是原子核内部的能量，通过核裂变或核聚变过程释放。核裂变是重核分裂成两个较轻的核，同时释放大量能量。核聚变是轻核结合成重核，也释放大量能量。粒子物理研究基本粒子的性质和行为，包括电子、质子、中子、光子等。

#### 2.3 宇宙射线与高能粒子

宇宙射线是来自宇宙的高能粒子流，主要由质子和电子组成。这些粒子以接近光速的速度穿过地球大气层，产生了大量的次级粒子。宇宙射线的研究有助于我们了解宇宙的起源和演化。

import numpy as np
import matplotlib.pyplot as plt

# 星系演化模型
def galaxy_evolution(galaxy_number, time_steps=1000):
    positions = np.random.uniform(0, 100, galaxy_number)
    velocities = np.random.uniform(-10, 10, galaxy_number)
    for _ in range(time_steps):
        accelerations = np.zeros_like(positions)
        for i in range(galaxy_number):
            for j in range(galaxy_number):
                if i != j:
                    distance = np.linalg.norm(positions[i] - positions[j])
                    acceleration = -1 / (distance ** 2)
                    accelerations[i] += acceleration * (positions[j] - positions[i])
        velocities += accelerations
        positions += velocities
    return positions
