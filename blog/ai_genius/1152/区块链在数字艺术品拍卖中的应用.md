**SHA-256加密算法：**

SHA-256是一种加密算法，用于确保区块链上数据的完整性。其原理如下：

1. **哈希值计算：**将输入数据通过SHA-256算法计算出一个哈希值，该值固定为256位。
2. **数据完整性验证：**当数据发生改变时，其哈希值也会发生变化，通过比较哈希值，可以验证数据的完整性。

```python
import hashlib

def calculate_hash(data):
    hash_object = hashlib.sha256(data.encode())
    hex_dig = hash_object.hexdigest()
    return hex_dig

data = "This is a sample data"
hash_value = calculate_hash(data)
print(hash_value)
```

**PoW共识机制：**

PoW是一种通过计算证明来达成共识的机制。其原理如下：

1. **挖矿：**矿工通过计算找到一个满足特定条件的哈希值，作为新区块的唯一标识。
2. **区块验证：**新区块生成后，网络中的其他节点验证其合法性，通过后新区块将被添加到区块链上。

```python
import random

def find_nonce(block):
    nonce = random.randint(0, 1000000000)
    while calculate_hash(block + str(nonce))[:4] != "0000":
        nonce += 1
    return nonce

block = "This is a sample block"
nonce = find_nonce(block)
print("Nonce:", nonce)
```

```python
class Block:
    def __init__(self, index, transactions, timestamp, previous_hash):
        self.index = index
        self.transactions = transactions
        self.timestamp = timestamp
        self.previous_hash = previous_hash
        self.hash = self.calculate_hash()

    def calculate_hash(self):
        block_string = f"{self.index}{self.transactions}{self.timestamp}{self.previous_hash}"
        return hashlib.sha256(block_string.encode()).hexdigest()

class Blockchain:
    def __init__(self):
        self.unconfirmed_transactions = []
        self.chain = []
        self.create_genesis_block()

    def create_genesis_block(self):
        genesis_block = Block(0, [], timestamp.time(), "0")
        genesis_block.hash = genesis_block.calculate_hash()
        self.chain.append(genesis_block)

    def add_new_transaction(self, transaction):
        self.unconfirmed_transactions.append(transaction)

    def mine(self):
        if not self.unconfirmed_transactions:
            return False
        last_block = self.chain[-1]
        new_block = Block(index=last_block.index + 1,
                          transactions=self.unconfirmed_transactions,
                          timestamp=timestamp.time(),
                          previous_hash=last_block.hash)
        new_block.hash = new_block.calculate_hash()
        self.chain.append(new_block)
        self.unconfirmed_transactions = []
        return new_block.index

    def is_chain_valid(self):
        for i in range(1, len(self.chain)):
            current = self.chain[i]
            previous = self.chain[i - 1]
            if current.hash != current.calculate_hash():
                return False
            if current.previous_hash != previous.hash:
                return False
        return True

if __name__ == "__main__":
    blockchain = Blockchain()
    blockchain.add_new_transaction("Transaction 1")
    blockchain.add_new_transaction("Transaction 2")
    blockchain.mine()
    print("Blockchain validity:", blockchain.is_chain_valid())
```
