\[ x' = \gamma (x - vt) \]
\[ y' = y \]
\[ z' = z \]
\[ t' = \gamma (t - \frac{vx}{c^2}) \]

其中，\( \gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}} \) 是洛伦兹因子，\( v \) 是相对速度，\( c \) 是光速。

```python
    gamma = 1 / sqrt(1 - v**2 / c**2)
    x_prime = gamma * (x - v * t)
    y_prime = y
    z_prime = z
    t_prime = gamma * (t - v * x / c**2)
    return x_prime, y_prime, z_prime, t_prime
```

\[ x' = \gamma (x - vt) \]
\[ y' = y \]

\[ t' = \gamma (t - \frac{vx}{c^2}) \]

其中，\( \gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}} \) 是洛伦兹因子，\( v \) 是相对速度，\( c \) 是光速。

**洛伦兹变换的物理意义**：
