#### 附录A：信息熵计算公式

信息熵是衡量信息不确定性的重要指标。在概率论中，信息熵通常用来描述随机变量的不确定性。以下是一些常见的信息熵计算公式：

1. **离散随机变量熵（Entropy）：**

   $$H(X) = -\sum_{i} p(x_i) \log_2 p(x_i)$$

   其中，$X$ 是随机变量，$p(x_i)$ 是随机变量 $X$ 取值 $x_i$ 的概率。

2. **条件熵（Conditional Entropy）：**

   $$H(X|Y) = -\sum_{i} p(x_i|y_i) \log_2 p(x_i|y_i)$$

   其中，$X$ 和 $Y$ 是随机变量，$p(x_i|y_i)$ 是在 $Y$ 取值为 $y_i$ 的条件下，$X$ 取值为 $x_i$ 的概率。

3. **联合熵（Joint Entropy）：**

   $$H(X,Y) = -\sum_{i} \sum_{j} p(x_i,y_j) \log_2 p(x_i,y_j)$$

   其中，$X$ 和 $Y$ 是随机变量，$p(x_i,y_j)$ 是 $X$ 取值为 $x_i$ 且 $Y$ 取值为 $y_j$ 的联合概率。

4. **互信息（Mutual Information）：**

   $$I(X;Y) = H(X) - H(X|Y)$$

   其中，$I(X;Y)$ 表示 $X$ 和 $Y$ 之间的互信息，表示 $X$ 和 $Y$ 之间信息传递的量。

1. **时间复杂度（Time Complexity）：**

   $$T(n) = O(f(n))$$

   其中，$T(n)$ 表示算法在输入规模为 $n$ 时的运行时间，$f(n)$ 表示算法运行时间与输入规模的关系。

2. **空间复杂度（Space Complexity）：**

   $$S(n) = O(g(n))$$

   其中，$S(n)$ 表示算法在输入规模为 $n$ 时的空间消耗，$g(n)$ 表示算法空间消耗与输入规模的关系。

3. **常见算法复杂度符号：**

   - $O(n)$：线性时间复杂度。

   - $O(2^n)$：指数时间复杂度。
