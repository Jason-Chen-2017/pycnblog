### 1.2.1 算法复杂度

#### 1.2.1.1 时间复杂度

时间复杂度描述了算法在执行过程中所需时间的增长速度。通常用大O符号表示，如O(n)，O(n^2)等。

#### 1.2.1.2 空间复杂度

空间复杂度描述了算法在执行过程中所需空间的增长速度。同样使用大O符号表示。

### 1.2.2 宇宙信息熵

#### 1.2.2.1 定义

宇宙信息熵是衡量宇宙中信息不确定性的物理量，通常用熵（Entropy）表示。

#### 1.2.2.2 计算公式

信息熵的计算公式为：H = -Σ p(x) * log2(p(x))，其中p(x)为信息出现的概率。

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]

import math

def entropy(p):
