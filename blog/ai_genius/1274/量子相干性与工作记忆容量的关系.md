```python

from qiskit import QuantumCircuit, execute
from qiskit.quantum_info import state_fidelity
from qiskit.providers.aer import QasmSimulator

# 创建量子比特
qc = QuantumCircuit(2)

# 应用量子态叠加
qc.h(0)
qc.cx(0, 1)

# 执行电路
simulator = QasmSimulator()
result = execute(qc, simulator, shots=1000).result()

# 获取量子比特状态
state = result.get_statevector()

# 计算工作记忆容量
fidelity = state_fidelity(state, np.array([1/2, 1/2, 1/2, 1/2]))

print(f"Fidelity: {fidelity}")
```

1. **量子比特生成**：脚本首先创建两个量子比特。
2. **量子态叠加**：通过应用 Hadamard 门（`h` 函数），将量子比特处于叠加态。
3. **量子相干性测量**：通过应用 CNOT 门（`cx` 函数），生成量子比特之间的相干性。
4. **工作记忆测试**：计算量子比特状态与参考态之间的 fidelity，作为工作记忆容量的衡量指标。
