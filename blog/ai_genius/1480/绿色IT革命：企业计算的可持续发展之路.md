### 3.1 算法概述

#### 3.2.3 数学模型和公式

假设有N台服务器，每台服务器的能耗为Ei，性能为Pi，则绿色IT算法的目标是：

$$
\min \sum_{i=1}^{N} E_i \cdot P_i
$$

其中，$E_i \cdot P_i$表示每台服务器的能耗与性能的乘积。

#### 3.2.4 举例说明

假设有3台服务器，其能耗和性能如下表：

| 服务器 | 能耗(Ei) | 性能(Pi) |
| ------ | -------- | -------- |
| 服务器1 | 100      | 0.8      |
| 服务器2 | 150      | 1.2      |
| 服务器3 | 200      | 1.0      |

根据绿色IT算法，我们可以计算总能耗与性能乘积：

$$
\sum_{i=1}^{3} E_i \cdot P_i = 100 \cdot 0.8 + 150 \cdot 1.2 + 200 \cdot 1.0 = 840
$$

然后，我们可以通过调整服务器的使用策略，优化能耗与性能乘积，实现绿色IT目标。

```python
import pymysql
import sys

def query_data():
    # 连接数据库
    connection = pymysql.connect(host="localhost", user="root", password="password", database="mydb")
    try:
        with connection.cursor() as cursor:
            # 查询数据
            sql = "SELECT * FROM users"
            cursor.execute(sql)
            result = cursor.fetchall()
            return result
    finally:
        connection.close()

def main():
    # 处理数据
    data = query_data()
    for row in data:
        print(row)

if __name__ == "__main__":
    main()
```
