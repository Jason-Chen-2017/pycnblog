#### 模拟退火算法

模拟退火算法（Simulated Annealing, SA）是一种通用概率算法，它基于固体退火过程的一种模拟，用于在具有多个局部最小值的搜索空间中找到全局最优解。该算法通过控制温度参数来调整搜索过程中的概率，从而在搜索初期允许较大的随机性，以跳出局部最优，而随着搜索的进行，逐步减小温度，增加找到全局最优解的概率。

**基本原理：**
1. **初始化**：设定初始解和初始温度。
2. **迭代**：对于当前解，随机生成一个新解，计算新解与当前解之间的评价差。
3. **接受概率**：根据当前温度计算接受新解的概率，若评价差小于零则一定接受，若评价差大于零则按指数概率接受。
4. **更新当前解**：根据接受概率更新当前解。
5. **降温**：根据预设规则降低温度。
6. **终止条件**：达到预设的温度或迭代次数，算法终止。

#### 遗传算法

遗传算法（Genetic Algorithm, GA）是基于自然选择和遗传学原理的一种优化算法，通过模拟自然进化过程来搜索最优解。遗传算法通过选择、交叉、变异和遗传等操作，在代际间逐步优化解的群体，直到找到满意的最优解。

**基本原理：**
1. **初始化**：随机生成初始种群。
2. **适应度评估**：对每个个体进行适应度评估，适应度高的个体具有更高的生存和繁殖机会。
3. **选择**：从当前种群中选择适应度高的个体组成下一代种群。
4. **交叉**：随机选择两个父代个体，通过交叉操作生成子代。
5. **变异**：对子代个体进行变异操作，增加种群的多样性。
6. **遗传**：将交叉和变异后的子代与父代混合，形成新的种群。
7. **迭代**：重复上述过程，直到满足终止条件。

#### 源代码实现

以下是宇宙模拟项目的基本源代码实现。这个模拟将包含星系的生成、运动和相互作用的简单模型。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial.distance import cdist

# 初始化参数
N = 100  # 星系数量
G = 6.67430e-11  # 引力常数
dt = 0.01  # 时间步长
t_max = 100  # 最大时间
M = 1e12  # 星系质量

# 初始化星系位置和速度
positions = np.random.rand(N, 2) * 100
velocities = np.random.rand(N, 2) * 10

# 模拟主循环
for t in range(int(t_max / dt)):
    # 计算引力
    distances = cdist(positions, positions)
    forces = G * M * (positions / distances**3)
    
    # 更新速度和位置
    velocities += forces / M * dt
    positions += velocities * dt
    
    # 输出结果
    if t % 10 == 0:
        plt.figure(figsize=(10, 10))
        plt.scatter(positions[:, 0], positions[:, 1], s=10, c='blue')
        plt.xlabel('X-axis')
        plt.ylabel('Y-axis')
        plt.title(f'Universe Simulation - Time Step: {t}')
        plt.show()

# 项目小结
```
