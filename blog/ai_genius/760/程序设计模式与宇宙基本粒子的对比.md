### 程序设计模式基础

#### 2.1 设计模式概述

设计模式是软件开发中解决常见问题的通用方案。这些模式不仅提供了代码结构的最佳实践，还有助于提高代码的可读性和可维护性。设计模式通常分为三种类型：创建型模式、结构型模式和行为型模式。

- **创建型模式**：这类模式主要用于对象的创建，包括工厂方法模式、单例模式和建造者模式等。它们的主要目标是避免直接实例化对象，从而提高代码的灵活性和可扩展性。
  
- **结构型模式**：这类模式主要用于组合对象和类，以实现更大的功能。适配器模式、桥接模式和组合模式是其中的代表。它们的主要目标是将接口与实现分离，从而提高代码的模块化和可复用性。

- **行为型模式**：这类模式主要用于处理对象之间的交互，包括责任链模式、观察者模式和策略模式等。它们的主要目标是实现对象之间的松耦合，从而提高代码的灵活性和可维护性。

#### 2.2 创建型模式

在创建型模式中，工厂方法模式、单例模式和建造者模式是三种最常用的模式。

- **工厂方法模式**：该模式定义了一个创建对象的方法，该方法由子类重写，从而实现对象的创建。这种模式的主要目的是避免直接实例化对象，从而提高代码的灵活性和可扩展性。

  ```python
  class Creator:
      def create_product(self):
          return Product()

  class Product:
      pass
  ```

- **单例模式**：该模式确保一个类仅有一个实例，并提供一个访问它的全局访问点。这种模式的主要目的是避免创建多个实例，从而提高内存的使用效率。

  ```python
  class Singleton:
      _instance = None

      def __new__(cls):
          if cls._instance is None:
              cls._instance = super().__new__(cls)
          return cls._instance
  ```

- **建造者模式**：该模式将一个复杂的对象的构建与其表示分离，使得同样的构建过程可以创建不同的表示。这种模式的主要目的是提高代码的可读性和可维护性。

  ```python
  class Builder:
      def build_part_a(self):
          pass

      def build_part_b(self):
          pass

  class Product:
      def __init__(self, part_a, part_b):
          self.part_a = part_a
          self.part_b = part_b

  class Director:
      def __init__(self, builder):
          self._builder = builder

      def construct_product(self):
          self._builder.build_part_a()
          self._builder.build_part_b()
          return self._builder.get_product()
  ```

#### 2.3 结构型模式

在结构型模式中，适配器模式、桥接模式和组合模式是三种常用的模式。

- **适配器模式**：该模式将一个类的接口转换成客户希望的另一个接口，使得原本接口不兼容的类可以一起工作。这种模式的主要目的是提高类的复用性。

  ```python
  class Adaptee:
      def specific_method(self):
          pass

  class Adapter(Adaptee):
      def adaptee_method(self):
          self.specific_method()
  ```

- **桥接模式**：该模式将抽象部分与实现部分分离，使它们可以独立地变化。这种模式的主要目的是提高代码的灵活性和可扩展性。

  ```python
  class Abstraction:
      def operation(self):
          pass

  class RefinedAbstraction(Abstraction):
      def operation(self):
          pass

  class Implementor:
      def operation_impl(self):
          pass

  class ConcreteImplementor(Implementor):
      def operation_impl(self):
          pass

  class Bridge(Abstraction):
      def __init__(self, implementor):
          self._implementor = implementor

      def operation(self):
          self._implementor.operation_impl()
  ```

- **组合模式**：该模式将对象组合成树形结构以表示“部分-整体”的层次结构。这种模式的主要目的是提高代码的可扩展性和可复用性。

  ```python
  class Component:
      def operation(self):
          pass

  class Leaf(Component):
      def operation(self):
          print("Leaf operation")

  class Composite(Component):
      def __init__(self):
          self._components = []

      def add(self, component):
          self._components.append(component)

      def remove(self, component):
          self._components.remove(component)

      def operation(self):
          for component in self._components:
              component.operation()
  ```

#### 2.4 行为型模式

在行为型模式中，责任链模式、观察者模式和策略模式是三种常用的模式。

- **责任链模式**：该模式使多个对象都有机会处理请求，从而避免请求发送者和接收者之间的耦合关系。这种模式的主要目的是提高代码的灵活性和可扩展性。

  ```python
  class Handler:
      def handle(self, request):
          pass

  class ConcreteHandler1(Handler):
      def handle(self, request):
          if 0 < request <= 10:
              print("ConcreteHandler1 handles request: ", request)
          else:
              print("Cannot handle request: ", request)

  class ConcreteHandler2(Handler):
      def handle(self, request):
          if 10 < request <= 20:
              print("ConcreteHandler2 handles request: ", request)
          else:
              print("Cannot handle request: ", request)
  ```

- **观察者模式**：该模式定义了对象间的一对多依赖，当一个对象的状态发生改变时，所有依赖于它的对象都会得到通知并自动更新。这种模式的主要目的是提高代码的模块化和可扩展性。

  ```python
  class Observer:
      def update(self, subject):
          pass

  class Subject:
      def __init__(self):
          self._observers = []

      def attach(self, observer):
          self._observers.append(observer)

      def detach(self, observer):
          self._observers.remove(observer)

      def notify(self):
          for observer in self._observers:
              observer.update(self)

  class ConcreteObserver(Observer):
      def update(self, subject):
          print("Observer gets notification from subject: ", subject)
  ```

- **策略模式**：该模式定义了一系列算法，将每个算法封装起来，并使它们可以相互替换。这种模式的主要目的是提高代码的灵活性和可扩展性。

  ```python
  class Strategy:
      def algorithm(self):
          pass

  class ConcreteStrategyA(Strategy):
      def algorithm(self):
          print("Using ConcreteStrategyA's algorithm")

  class ConcreteStrategyB(Strategy):
      def algorithm(self):
          print("Using ConcreteStrategyB's algorithm")

  class Context:
      def __init__(self, strategy):
          self._strategy = strategy

      def set_strategy(self, strategy):
          self._strategy = strategy

      def execute_strategy(self):
          self._strategy.algorithm()
  ```

### 宇宙基本粒子概述

#### 3.1 宇宙基本粒子的定义

宇宙基本粒子是构成物质世界的最基本粒子，它们是宇宙演化的基石。根据现代物理学，宇宙基本粒子主要包括以下几种：

- **电子**：电子是原子中负电荷的基本粒子，是化学元素的基本组成部分。电子具有质量、电荷和自旋等特性。

- **质子**：质子是原子核中正电荷的基本粒子，与中子共同构成原子核。质子具有质量、电荷和自旋等特性。

- **中子**：中子是中性粒子，存在于原子核中，与质子共同构成原子核。中子具有质量、电荷和自旋等特性。

#### 3.2 常见宇宙基本粒子介绍

除了电子、质子和中子，还有一些重要的宇宙基本粒子，如：

- **光子**：光子是电磁辐射的基本粒子，是光和电磁波的基础。光子具有能量、动量和自旋等特性。

- **夸克**：夸克是构成质子和中子的基本粒子，具有质量、电荷和自旋等特性。夸克分为上夸克和下夸克等。

- **胶子**：胶子是传递强相互作用的粒子，负责将夸克和胶子束缚在一起。胶子具有质量、电荷和自旋等特性。

        pass

    def handle(self, request):

            self._order.add_product(request.product, request.quantity)
        else:

        if isinstance(request, DeleteProductRequest):
            self._order.delete_product(request.product)
        else:
            print("Cannot handle this request")

        self._handlers = [AddProductHandler(self), DeleteProductHandler(self)]

    def add_handler(self, handler):
        self._handlers.append(handler)

    def handle_request(self, request):
        for handler in self._handlers:

class OrderSubject:

        self._observers.append(observer)

    def detach(self, observer):
        self._observers.remove(observer)

    def notify(self):
        for observer in self._observers:
            observer.update(self)
