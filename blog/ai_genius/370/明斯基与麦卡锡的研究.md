### 1.1 明斯基与麦卡锡的生平简介

约翰·霍普金斯·明斯基（John Hopfield Minsky）和约翰·麦卡锡（John McCarthy）是计算机科学和人工智能领域的两位重要人物，他们的工作对现代计算机科学产生了深远的影响。

#### 明斯基

明斯基于1929年出生于美国纽约市，他在数学、物理学和计算机科学等多个领域都有着卓越的贡献。明斯基在1951年获得了哈佛大学数学学士学位，并在1954年获得了加州理工学院（Caltech）的物理学博士学位。在20世纪50年代，他开始对人工智能产生浓厚兴趣，并与艾伦·图灵等科学家有着密切的交流。

明斯基在1958年参与了著名的达特茅斯会议，这次会议被认为是人工智能的诞生日。他在这一领域的主要贡献包括：

- **感知机**：明斯基提出了感知机的概念，这是一种基于线性分类器的简单学习模型，为后来的神经网络研究奠定了基础。

- **计算机视觉**：明斯基对计算机视觉的研究提出了许多重要的理论和算法，包括光流计算和图像识别。

- **认知模拟**：他通过构建计算机模型来模拟人类思维，为认知科学的发展做出了贡献。

明斯基在其职业生涯中获得了许多荣誉，包括图灵奖，这是计算机科学领域的最高荣誉。

#### 麦卡锡

约翰·麦卡锡于1927年出生于美国加利福尼亚州，他在人工智能和计算机科学的理论基础方面做出了许多开创性工作。麦卡锡在1948年获得了加州理工学院的物理学学士学位，并在1951年获得了普林斯顿大学的哲学博士学位。

麦卡锡在1958年达特茅斯会议上发表了题为“人工智能”的论文，这被认为是人工智能这一领域的命名来源。他的主要贡献包括：

- **Lisp编程语言**：麦卡锡发明了Lisp语言，这是第一种高级函数式编程语言，对编程语言的发展产生了深远影响。

- **知识表示**：他提出了知识表示的概念，这是人工智能研究中的一个核心问题。

- **计算机哲学**：麦卡锡探讨了计算机与哲学之间的关系，提出了关于计算与意识、自由意志等哲学问题的思考。

麦卡锡同样获得了图灵奖，以表彰他在人工智能和计算机科学领域的杰出贡献。

### 2.1 计算机科学的基础理论

计算机科学的基础理论涵盖了计算理论、计算机体系结构和编程语言与编译原理。这些理论构成了计算机科学的核心，并为现代计算机技术的发展奠定了基础。

#### 计算理论概述

计算理论是研究计算过程和计算能力的学科。它主要包括以下几个核心概念：

- **计算模型**：计算模型是描述计算过程的抽象表示。常见的计算模型包括图灵机和随机访问存储器（RAM）计算机。图灵机是一种抽象的计算设备，由一个无限长的带子、一组状态和一组规则组成。RAM计算机则是一个更为实用的计算模型，它具有固定的存储空间和可编程的指令集。

- **计算复杂性**：计算复杂性是研究算法解决问题所需资源（如时间、空间等）的学科。它包括多项式时间算法、非确定性多项式时间算法和复杂性类等概念。计算复杂性理论的一个重要成果是P vs NP问题，即确定是否所有可验证问题都能在多项式时间内解决。

- **形式语言与自动机**：形式语言是计算机科学中的一个重要概念，它描述了计算机能够处理的数据。自动机是用于处理形式语言的抽象设备，包括有限自动机、图灵机和泵引理等。

#### 计算机体系结构

计算机体系结构是研究计算机硬件和软件组织结构的学科。它包括以下几个关键部分：

- **冯·诺伊曼体系结构**：冯·诺伊曼体系结构是现代计算机体系结构的基础。它主要包括中央处理单元（CPU）、内存、输入/输出设备和指令集。冯·诺伊曼体系结构的优点是能够高效地存储和执行程序指令。

- **存储器层次结构**：存储器层次结构是计算机体系结构中的一个重要概念，它描述了不同类型存储器的层次关系。常见的存储器层次结构包括寄存器、高速缓存、主存储器和辅助存储器。通过分层结构，计算机可以在需要时快速访问数据，从而提高系统的性能。

- **指令集架构（ISA）**：指令集架构是计算机硬件与软件之间的接口。它定义了计算机能够执行的操作指令和数据类型。常见的指令集架构包括复杂指令集计算机（CISC）和精简指令集计算机（RISC）。

#### 编程语言与编译原理

编程语言是用于编写计算机程序的语法和语义规则。编译原理是研究如何将编程语言编写的源代码转换为目标代码的学科。以下是编程语言与编译原理的一些核心概念：

- **高级语言与低级语言**：高级语言是更接近人类语言和数学表达式的编程语言，如Python、Java和C++。低级语言是更接近计算机硬件的编程语言，如汇编语言。高级语言通过编译器或解释器转换为机器语言，从而在计算机上执行。

- **编译过程**：编译过程是将源代码转换为机器代码的过程，包括词法分析、语法分析、语义分析、中间代码生成、代码优化和目标代码生成等步骤。编译器是一个将高级语言源代码转换为低级语言目标代码的程序。

- **解释器**：解释器是另一种执行编程语言的工具，它逐行读取源代码并立即执行。解释器不需要编译整个程序，因此通常比编译器更快，但性能较低。

- **静态类型与动态类型**：静态类型语言在编译时检查变量类型，如C++和Java。动态类型语言在运行时检查变量类型，如Python和JavaScript。静态类型语言通常有更好的性能和更严格的类型检查。

- **面向对象编程与函数式编程**：面向对象编程是一种编程范式，它将数据和操作数据的方法封装在对象中。函数式编程是一种编程范式，它将计算视为表达式的求值，而不是基于状态的变换。

通过计算理论、计算机体系结构和编程语言与编译原理的研究，计算机科学为现代技术的发展提供了坚实的基础。这些基础理论不仅指导了计算机硬件和软件的设计，也为人工智能、算法优化和软件开发提供了重要的理论支持。

#### 计算机体系结构

计算机体系结构是计算机科学中的一个核心领域，它研究计算机硬件的组成和设计原则。冯·诺伊曼体系结构是现代计算机体系结构的基础，它由约翰·冯·诺伊曼在1940年代提出。冯·诺伊曼体系结构的主要特点包括以下几个方面：

- **存储程序计算机**：冯·诺伊曼体系结构的核心概念是将程序指令和数据存储在同一存储器中，从而实现存储程序计算机。这一概念使得计算机可以像处理数据一样处理程序指令，从而大大提高了计算机的灵活性和效率。

- **CPU与存储器**：冯·诺伊曼体系结构包括中央处理单元（CPU）和存储器。CPU负责执行指令和进行数据处理，而存储器用于存储程序和数据。CPU与存储器之间的数据传输是通过数据总线进行的。

- **输入/输出设备**：冯·诺伊曼体系结构还包括输入/输出设备，如键盘、鼠标、显示器和打印机。输入设备用于将数据输入到计算机中，而输出设备用于将计算机处理的结果输出。

- **指令集**：指令集是计算机能够执行的操作集合。冯·诺伊曼体系结构通常采用固定长度指令，每个指令包括操作码和操作数。操作码指定要执行的操作，而操作数指定操作的对象。

- **控制单元**：控制单元是CPU的一个重要组成部分，它负责解释指令并控制计算机的执行流程。控制单元通常包括程序计数器、指令寄存器和指令译码器等组件。

#### 冯·诺伊曼体系结构的工作原理

冯·诺伊曼体系结构的工作原理可以概括为以下步骤：

1. **指令读取**：CPU通过程序计数器确定要执行的指令地址，从存储器中读取指令。

2. **指令译码**：控制单元对指令进行译码，确定要执行的操作和操作数。

3. **执行操作**：CPU根据指令执行相应的操作，如数据传输、算术运算或逻辑运算。

4. **更新程序计数器**：执行完指令后，程序计数器更新为下一条指令的地址。

5. **重复执行**：CPU重复上述步骤，直到程序结束。

通过这种方式，冯·诺伊曼体系结构实现了程序的自动执行。这种设计不仅使得计算机可以高效地处理复杂任务，也为编程语言的发展提供了基础。

#### 冯·诺伊曼体系结构的优缺点

冯·诺伊曼体系结构具有以下优点：

- **灵活性**：存储程序计算机的设计使得计算机可以执行各种不同的任务，具有很高的灵活性。
- **可扩展性**：冯·诺伊曼体系结构易于扩展，可以通过增加存储器和输入/输出设备来提高计算机的性能。
- **编程简单**：存储程序计算机使得编程变得更加简单，程序员可以直接操作存储器中的指令和数据。

然而，冯·诺伊曼体系结构也存在一些缺点：

- **瓶颈**：由于CPU和存储器之间的数据传输是通过数据总线进行的，因此数据传输速度可能成为计算机性能的瓶颈。
- **存储器开销**：存储程序计算机需要将指令和数据存储在同一存储器中，这可能导致存储器使用效率不高。
- **可变性**：冯·诺伊曼体系结构的控制单元较为复杂，这使得设计、制造和维护都相对困难。

尽管存在这些缺点，冯·诺伊曼体系结构依然是现代计算机体系结构的基础。许多现代计算机系统，如个人计算机、服务器和嵌入式系统，都是基于冯·诺伊曼体系结构的。随着计算机技术的发展，冯·诺伊曼体系结构的许多问题也得到了解决，例如通过采用高速缓存和并行处理技术来提高性能。

#### 编程语言与编译原理

编程语言是用于编写计算机程序的形式语言，它提供了人类与计算机之间的交互方式。编译原理则是研究如何将编程语言编写的源代码转换为目标代码（通常是机器代码）的学科。以下是编程语言与编译原理的一些核心概念：

- **高级语言**：高级语言是更接近人类语言和数学表达式的编程语言。与低级语言（如汇编语言）相比，高级语言提供了更抽象和更易读的语法结构。常见的编程语言包括C、C++、Java、Python、JavaScript等。

- **低级语言**：低级语言是更接近计算机硬件的编程语言。汇编语言是一种典型的低级语言，它使用机器码指令来表示程序的操作。由于汇编语言与机器码非常接近，因此程序员可以直接控制计算机的硬件操作。

- **编译过程**：编译过程是将高级语言源代码转换为目标代码的过程。编译过程通常包括以下几个步骤：

  1. **词法分析**：将源代码分解为单词和符号，通常使用正则表达式来实现。
  2. **语法分析**：将词法分析的结果组织成语法树，通常使用递归下降分析或LL(k)分析器来实现。
  3. **语义分析**：检查源代码的语法和语义是否正确，如类型检查、变量作用域等。
  4. **代码生成**：将语法树转换为目标代码，通常使用三地址代码或中间代码来实现。
  5. **优化**：对生成的目标代码进行优化，以提高程序的性能。
  6. **目标代码生成**：将优化后的中间代码转换为目标机器代码。

- **解释器与编译器**：解释器是一种执行编程语言的工具，它逐行读取源代码并立即执行。编译器则将源代码编译为目标代码，然后执行目标代码。解释器通常比编译器更快，但性能较低。编译器生成的目标代码通常性能更高，但开发周期较长。

- **静态类型与动态类型**：静态类型语言在编译时检查变量类型，如C++和Java。动态类型语言在运行时检查变量类型，如Python和JavaScript。静态类型语言通常有更好的性能和更严格的类型检查，但开发过程可能较为复杂。动态类型语言开发过程较为简单，但性能可能较低。

- **面向对象编程与函数式编程**：面向对象编程是一种编程范式，它将数据和操作数据的方法封装在对象中。函数式编程是一种编程范式，它将计算视为表达式的求值，而不是基于状态的变换。面向对象编程和函数式编程各有优缺点，适用于不同的应用场景。

通过编译原理的研究，我们可以更好地理解如何将高级语言编写的源代码转换为目标代码，从而提高程序的性能和可维护性。同时，编程语言的发展也为计算机科学和软件开发提供了强大的工具和平台。

### 2.2 人工智能与认知科学

#### 认知科学的基本概念

- **认知模型**：认知模型是用于模拟和解释认知过程的计算机模型。这些模型通常基于神经网络、产生式系统和规则系统等理论。认知模型可以帮助科学家理解人类智能的机制，并指导人工智能系统的设计。

### 2.3 计算机与哲学

计算机与哲学是两个看似截然不同的领域，但在实践中有着紧密的联系。在本节中，我们将探讨计算机哲学的基本问题、明斯基与麦卡锡的哲学观点以及计算机哲学与认知科学的关系。

#### 计算机哲学的基本问题

计算机哲学是研究计算机科学中哲学问题的学科，主要包括以下几个基本问题：

- **计算与意识**：计算机是否能够具有意识？这是计算机哲学中最基本的问题之一。一些哲学家认为，意识是计算的一种形式，计算机可以通过复杂的计算过程产生意识。而另一些哲学家则认为，意识与计算无关，它是一种不可还原的生物学现象。

- **计算与自由意志**：计算机是否能具有自由意志？自由意志是指个体在行动选择上的自主性。一些哲学家认为，计算机可以通过算法和数据处理来实现自由意志。而另一些哲学家则认为，自由意志是人类特有的，无法通过计算机模拟。

- **计算与伦理**：计算机技术和人工智能的应用带来了许多伦理问题，如隐私保护、自动化决策的公正性等。计算机哲学探讨如何确保计算机技术的伦理合规性和社会责任。

- **计算与真实**：计算机是否能够模拟现实？这是关于计算机仿真和模拟的哲学问题。一些哲学家认为，计算机可以通过虚拟现实技术模拟现实，而另一些哲学家则认为，虚拟现实永远无法完全模拟真实的现实。

#### 明斯基与麦卡锡的哲学观点

明斯基和麦卡锡在计算机哲学领域有着独特的观点，他们的工作对计算机哲学的发展产生了重要影响。

- **明斯基的哲学观点**：

  - **计算与意识**：明斯基认为，意识是一种复杂的计算现象，计算机可以通过模拟人类大脑的机制来实现意识。他提出了“思维引擎”的概念，认为计算机可以通过自我组织和自适应行为来模拟人类的意识。

  - **知识表示与推理**：明斯基研究了知识表示和推理的哲学问题，他认为知识应该以层次结构的形式表示，并且可以通过逻辑推理来获取新知识。

  - **认知模拟**：明斯基通过计算机模型来模拟人类思维，他的工作为认知科学提供了新的方法和工具。

- **麦卡锡的哲学观点**：

  - **计算与意识**：麦卡锡认为，意识与计算有关，但不是所有计算都会产生意识。他提出了“计算主义”的观点，认为计算可以模拟意识的某些方面，但无法完全等同于意识。

  - **知识表示与推理**：麦卡锡研究了知识表示和推理的哲学问题，他认为知识应该以形式化的方式表示，并通过逻辑推理来验证。

  - **计算机哲学**：麦卡锡探讨了计算机与哲学之间的关系，他认为计算机技术可以为哲学提供新的研究方法和工具。

#### 计算机哲学与认知科学的关系

计算机哲学与认知科学是相互关联的领域，它们共同探讨人类智能的机制和实现方法。

- **哲学视角下的认知科学**：

  - 计算机哲学为认知科学提供了新的研究方法，如形式化建模和计算模型。这些方法有助于科学家更好地理解和模拟人类思维过程。

  - 计算机哲学探讨了认知过程中的一些哲学问题，如意识、自由意志和伦理等。这些问题对于认知科学的研究具有重要的指导意义。

- **认知科学对哲学的挑战**：

  - 认知科学的研究结果对传统的哲学观点提出了挑战，如关于意识、自由意志和真实性的问题。这些挑战促使哲学家重新审视传统的哲学理论。

  - 认知科学提供了新的哲学问题，如计算与意识的界限、人工智能的道德责任等。这些问题对于计算机哲学的发展具有重要意义。

总的来说，计算机哲学与认知科学是相互促进的领域。计算机哲学为认知科学提供了新的研究方法和工具，而认知科学的研究结果为计算机哲学提供了新的问题和挑战。这种跨学科的融合有助于我们更好地理解人类智能的机制和实现方法。

### 6.1 计算机模拟人类思维

计算机模拟人类思维是人工智能领域的一个重要研究方向，旨在通过构建计算机模型来模拟人类的认知过程，以实现机器对复杂任务的自动处理。明斯基和麦卡锡在计算机模拟人类思维方面做出了重要贡献，他们的工作为这一领域奠定了基础。

#### ELIZA

ELIZA是由约瑟夫·魏斯纳（Joseph Weizenbaum）在1966年开发的一个早期聊天机器人，但明斯基对其进行了改进。ELIZA通过模式匹配和简单的语法分析来理解用户的输入，并以类似心理治疗师的方式与用户进行对话。其基本原理是使用一组预定义的规则来解析用户的输入，并根据这些规则生成回答。ELIZA虽然简单，但它在当时引起了广泛关注，展示了计算机模拟人类思维的潜力。

#### SIMULATION

SIMULATION是由明斯基在1960年代初开发的一个人工智能系统，旨在模拟人类的思维过程。SIMULATION采用了基于规则的知识表示方法，它使用一组规则来表示事实和推理过程。这些规则包括条件语句和结论，使得SIMULATION能够进行逻辑推理和问题解决。SIMULATION在认知模拟方面取得了显著进展，为后来的认知模拟研究提供了重要的理论基础。

#### 计算机模拟人类思维的方法

计算机模拟人类思维通常采用以下几种方法：

- **符号表示**：符号表示法使用符号和规则来表示知识和推理过程。这种方法类似于人类使用语言和逻辑进行思考，能够实现复杂的推理和问题解决。

- **神经网络**：神经网络通过模拟人脑的结构和功能来实现认知任务。神经网络由大量相互连接的神经元组成，通过学习和训练来适应不同的问题场景。

- **产生式系统**：产生式系统是一种基于规则的知识表示方法，它使用条件语句和结论来表示知识和推理过程。产生式系统在自然语言处理、专家系统等领域有广泛应用。

- **模糊逻辑**：模糊逻辑通过处理不确定性和模糊性来实现认知任务。模糊逻辑使用模糊集合来表示概念和规则，能够处理复杂的认知问题。

#### 计算机模拟人类思维的应用

计算机模拟人类思维在许多领域都有广泛应用，包括：

- **自然语言处理**：计算机模拟人类思维在自然语言处理领域有广泛应用，如机器翻译、语音识别和文本分类等。

- **专家系统**：专家系统是一种基于知识的系统，通过模拟人类专家的推理过程来解决问题。计算机模拟人类思维使得专家系统能够处理复杂的医学诊断、法律咨询等任务。

- **认知辅助工具**：计算机模拟人类思维可以用于开发认知辅助工具，如智能客服、智能教育系统等，这些工具能够提高人类工作效率和生活质量。

总的来说，计算机模拟人类思维是一个充满挑战和机遇的研究领域。通过模拟人类的认知过程，计算机可以更好地理解和处理复杂任务，为人工智能的发展提供了新的思路和方法。

#### 6.2 自然语言处理

自然语言处理（NLP）是人工智能领域的一个重要分支，旨在使计算机能够理解、生成和处理人类自然语言。明斯基和麦卡锡在NLP领域的研究奠定了基础，他们的工作对现代NLP技术的发展产生了深远影响。

#### Turing Test

图灵测试是由艾伦·图灵（Alan Turing）在1950年提出的一种测试方法，用于评估机器是否能够模仿人类思维。在图灵测试中，一个人类评判者与一个机器和一个真实的人类进行对话，通过判断谁更像是机器来评估机器的智能水平。明斯基和麦卡锡对图灵测试进行了深入研究，并提出了许多改进方案，以更准确地评估机器的智能。

### 7.1 深度学习与神经网络

深度学习（Deep Learning）是近年来人工智能领域的重要突破，它通过模拟人脑的结构和功能来实现复杂的任务，如图像识别、语音识别和自然语言处理等。神经网络（Neural Networks）是深度学习的基础，它由大量相互连接的神经元组成，通过学习和训练来适应不同的问题场景。

#### 卷积神经网络（CNN）

卷积神经网络（Convolutional Neural Network，CNN）是深度学习中最常用的模型之一，它在图像识别和计算机视觉任务中表现出色。CNN通过卷积层、池化层和全连接层等结构来提取图像特征，并最终进行分类。

- **卷积层**：卷积层通过卷积操作从输入图像中提取局部特征。卷积操作使用一组可训练的滤波器（也称为卷积核）来扫描输入图像，从而生成特征图。

- **池化层**：池化层用于降低特征图的维度，同时保留最重要的特征信息。常用的池化操作包括最大池化和平均池化。

- **全连接层**：全连接层将特征图中的每个像素与一个神经元相连接，并通过激活函数（如ReLU、Sigmoid和Tanh）进行非线性变换。

以下是一个简单的CNN模型伪代码：

```python

# 定义池化层
pool1 = MaxPooling2D(pool_size=(2, 2))

# 定义卷积层
```

- **基本RNN**：基本RNN由一个循环单元组成，它包含一个记忆单元和一个非线性激活函数。记忆单元用于存储序列中的信息，并用于生成当前输出。

- **长短期记忆网络（LSTM）**：LSTM是RNN的一种改进，它通过引入门控机制来避免梯度消失和爆炸问题。LSTM包含输入门、遗忘门和输出门，这些门用于控制信息的流动和记忆的更新。

### 7.2 强化学习

强化学习（Reinforcement Learning，RL）是机器学习的一个重要分支，旨在通过试错和反馈来训练智能体（agent）如何在一个动态环境中做出最佳决策。强化学习与监督学习和无监督学习不同，它不依赖于预先标注的数据集，而是通过与环境的交互来学习和改进策略。

#### Q-Learning算法

Q-Learning是一种基于值函数的强化学习算法，它通过迭代更新Q值来选择最佳动作。Q值表示在特定状态下采取特定动作的预期回报。以下是Q-Learning算法的基本步骤：

1. **初始化**：初始化Q值表，将所有Q值初始化为0。
2. **选择动作**：在给定状态下，选择具有最大Q值的动作。
3. **执行动作**：在环境中执行选定的动作，并观察环境的反馈（下一个状态和奖励）。
4. **更新Q值**：使用如下公式更新Q值：
   \[
   Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]
   \]
   其中，\( s \) 是当前状态，\( a \) 是当前动作，\( r \) 是奖励，\( s' \) 是下一个状态，\( a' \) 是下一个动作，\( \alpha \) 是学习率，\( \gamma \) 是折扣因子。
5. **重复步骤2-4**，直到达到终止条件（如达到目标状态或达到最大迭代次数）。

以下是一个简单的Q-Learning算法伪代码：

```python
# 初始化Q值表
Q = {s: {a: 0 for a in actions(s)} for s in states}

# 设置学习率和折扣因子
alpha = 0.1
gamma = 0.9

# 迭代更新Q值
for episode in range(max_episodes):
    state = initial_state()
    while not is_terminal(state):
        action = choose_action(state, Q)
        next_state, reward = environment.step(state, action)
        Q[state][action] = Q[state][action] + alpha * (reward + gamma * max(Q[next_state].values()) - Q[state][action])
        state = next_state
```

#### 深度强化学习

深度强化学习（Deep Reinforcement Learning，DRL）是将深度学习与强化学习相结合的一种方法，它通过深度神经网络来近似值函数或策略。DRL在处理高维状态空间和复杂决策问题时表现出色。

- **深度Q网络（DQN）**：DQN使用深度神经网络来近似Q值函数。它通过经验回放和目标网络来稳定学习过程，以避免由于样本偏差导致的收敛问题。

- **策略梯度方法**：策略梯度方法直接优化策略参数，使得策略能够最大化期望回报。常见的策略梯度方法包括REINFORCE和Actor-Critic算法。

以下是一个简单的DQN模型伪代码：

```python
# 定义深度神经网络

q_network.add(Dense(units=512, activation='relu', input_shape=(input_shape)))
q_network.add(Dense(units=512, activation='relu'))
q_network.add(Dense(units=num_actions, activation='linear'))

# 定义目标网络
target_network = Sequential()
target_network.add(Dense(units=512, activation='relu', input_shape=(input_shape)))
target_network.add(Dense(units=512, activation='relu'))
target_network.add(Dense(units=num_actions, activation='linear'))

# 定义DQN模型
dqn = Model(inputs=[input_image, action], outputs=[q_value])
dqn.compile(optimizer='adam', loss='mse')

# 定义经验回放缓冲区
experience_replay = deque(maxlen=replay_memory_size)

# 迭代更新DQN模型
for episode in range(max_episodes):
    state = initial_state()
    while not is_terminal(state):
        action = choose_action(state, q_network)
        next_state, reward = environment.step(state, action)
        experience_replay.append((state, action, reward, next_state, done))
        if done:
            next_q_value = reward
        else:
            next_q_value = reward + gamma * np.max(target_network.predict(next_state)[0])
        target_value = q_network.predict(state)[0]
        target_value[action] = next_q_value
        dqn.fit(np.array([state])[0], target_value, epochs=1, verbose=0)
        state = next_state
```
