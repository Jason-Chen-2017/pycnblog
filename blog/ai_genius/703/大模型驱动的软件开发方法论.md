- 非线性激活函数：非线性激活函数（如ReLU、Sigmoid、Tanh等）用于引入非线性特性，提高模型的表示能力。
- 参数优化：利用梯度下降等优化算法，对模型参数进行迭代优化，提高模型性能。

深度学习的主要算法包括：

- 卷积神经网络（CNN）：用于图像、语音等数据的特征提取和分类。

- 生成对抗网络（GAN）：用于生成逼真的数据、图像和文本。

#### 2.1.1 深度学习的基本原理

深度学习的基本原理是通过多层神经网络（Neural Network）对输入数据进行层次化表示和建模。神经网络由多个神经元（Neurons）组成，每个神经元都连接到前一个层的神经元，并通过权重（Weights）传递信息。神经网络的训练过程就是通过不断调整这些权重，使得网络能够更好地拟合训练数据。

1. **神经网络的基本结构**

   神经网络的基本结构包括输入层（Input Layer）、隐藏层（Hidden Layers）和输出层（Output Layer）。每个神经元都与上一层和下一层的神经元相连。

   ```mermaid
   graph TD
   A[输入层] --> B{隐藏层1}
   B --> C{隐藏层2}
   C --> D{输出层}
   ```

2. **前向传播（Forward Propagation）**

   前向传播是指将输入数据通过神经网络的各个层进行传递，最终得到输出。每个神经元都会计算输入信号与其权重的加权和，并应用激活函数（Activation Function）。

   ```mermaid
   graph TD
   A[输入] --> B{加权求和}
   B --> C{激活函数}
   C --> D{输出}
   ```

3. **反向传播（Backpropagation）**

   反向传播是指根据输出误差，逆向调整网络的权重。通过计算每个权重对误差的梯度，利用梯度下降（Gradient Descent）等优化算法，不断调整权重，以减少误差。

   ```mermaid
   graph TD
   D{输出误差} --> B{计算梯度}
   B --> A{权重更新}
   ```

1. **卷积神经网络（CNN）**

#### 2.2.1 大模型训练方法

   大模型训练通常采用批量训练（Batch Training）或小批量训练（Mini-batch Training）。批量训练每次使用整个数据集进行训练，计算量大但收敛速度慢。小批量训练每次使用一部分数据进行训练，计算量小但收敛速度快。
