## 第2章 计算机视觉基础算法

### 2.1 图像处理算法

图像处理是计算机视觉的基础，它包括对图像进行滤波、边缘检测、图像分割等操作。

#### 2.1.1 滤波算法

滤波算法用于去除图像中的噪声，常见的滤波算法包括：

- **均值滤波**：通过计算邻域内像素的平均值来去除噪声。
- **高斯滤波**：使用高斯函数作为核函数进行滤波，能够有效去除噪声并保留图像细节。

```python
import cv2
import numpy as np

# 读取图像
img = cv2.imread('example.jpg', cv2.IMREAD_GRAYSCALE)

# 高斯滤波
blurred = cv2.GaussianBlur(img, (5, 5), 0)
```

#### 2.1.2 边缘检测算法

边缘检测算法用于识别图像中的边缘，常见的边缘检测算法包括：

- **Sobel算子**：计算图像梯度，用于检测边缘。
- **Canny算法**：结合了梯度计算和双阈值处理，能够有效地检测边缘。

```python
# Sobel边缘检测
sobelx = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)
sobelx = np.uint8(np.absolute(sobelx))

# Canny边缘检测

```

#### 2.1.3 图像分割算法

图像分割是将图像划分为若干个不同的区域，常见的图像分割算法包括：

- **阈值分割**：将图像映射到二值图像，根据像素值是否大于某个阈值来划分区域。
- **区域增长分割**：从一组种子点开始，逐步扩大区域，直到满足某些条件。

```python
# 阈值分割
_, thresh = cv2.threshold(img, 128, 255, cv2.THRESH_BINARY+cv2.THRESH_OTSU)

# 区域增长分割
sure_bg = cv2.dilate(thresh, np.ones((3,3)), iterations=3)
dist_transform = cv2.distanceTransform(sure_bg, cv2.DIST_L2, 5)
ret, sure_fg = cv2.threshold(dist_transform, 0.7*dist_transform.max(), 255, 0)
sure_fg = np.uint8(sure_fg)
unknown = cv2.subtract(sure_bg,sure_fg)

# 区域增长
num_labels = cv2.connectedComponents(sure_fg, connectivity=8)[0]
cc_image = np.zeros(img.shape[:2], np.uint8)
cc_image[sure_fg==1] = 1
cc_image[unknown==255] = 255
```

### 2.2 特征提取算法

- **SIFT和SURF**：尺度不变特征变换（SIFT）和加速稳健特征（SURF）是两种常用的尺度不变特征提取方法。

# 示例
