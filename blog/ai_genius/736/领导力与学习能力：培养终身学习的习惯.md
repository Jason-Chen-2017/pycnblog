```python
class LearningManagementSystem:
    def __init__(self):
        self.courses = {}
        self.exam_results = {}

    def add_course(self, course):
        self.courses[course.id] = course

    def enroll_course(self, user, course_id):
        course = self.courses.get(course_id)
        if course:
            course.enroll(user)

    def take_exam(self, user, course_id):
        course = self.courses.get(course_id)
        if course:
            result = course.take_exam(user)
            self.exam_results[(user, course_id)] = result

    def get_exam_result(self, user, course_id):
        return self.exam_results.get((user, course_id))
```

**代码解读**：

该代码定义了一个`LearningManagementSystem`类，用于实现学习管理系统的功能。该类包含以下几个方法：

- `add_course()`：用于添加课程。
- `enroll_course()`：用于报名课程。
- `take_exam()`：用于参加考试。
- `get_exam_result()`：用于获取考试成绩。
