### 第1章 集合论概述

#### 1.1 集合的基本概念

##### 1.1.1 集合的定义与性质

- **定义**：集合是由确定的、互异的元素构成的整体。

- **性质**：

  - **确定性**：集合中的元素必须是确定的，即给定一个元素，能够明确判断它是否属于集合。

  - **互异性**：集合中的元素必须是互异的，即集合中不允许有重复的元素。

  - **无序性**：集合中的元素顺序不影响集合本身，即集合A和集合B中的元素相同，则集合A和集合B相等。

##### 1.1.2 集合的表示方法

- **列举法**：用花括号{}将集合的元素一一列举出来，例如{1, 2, 3}。

- **描述法**：用谓词描述集合的元素，例如{x | x 是正整数}。

##### 1.1.3 集合的分类

- **有限集**：元素个数有限的集合。

- **无限集**：元素个数无限的集合。

---

#### 1.2 集合的运算

##### 1.2.1 并集、交集、补集

- **交集（∩）**：两个集合A和B的交集是包含A和B共有的元素的集合。用公式表示为：A ∩ B。

  - **性质**：
    - **交换律**：A ∩ B = B ∩ A。
    - **结合律**：(A ∩ B) ∩ C = A ∩ (B ∩ C)。
    - **分配律**：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)。

- **并集（∪）**：两个集合A和B的并集是包含A和B所有元素的集合。用公式表示为：A ∪ B。

  - **性质**：
    - **交换律**：A ∪ B = B ∪ A。
    - **结合律**：(A ∪ B) ∪ C = A ∪ (B ∪ C)。
    - **分配律**：A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)。

- **补集（∁）**：一个集合A的补集是包含所有不属于A的元素的集合。用公式表示为：∁A。

  - **性质**：
    - **补集的补集**：∁(∁A) = A。
    - **德摩根律**：∁(A ∩ B) = ∁A ∪ ∁B；∁(A ∪ B) = ∁A ∩ ∁B。

##### 1.2.2 子集与超集

- **子集**：如果集合A的所有元素都是集合B的元素，则称A是B的子集，记作A ⊆ B。

  - **性质**：
    - **空集是任何集合的子集**：∅ ⊆ A。
    - **任意集合是其本身的子集**：A ⊆ A。
    - **子集的子集仍是子集**：如果A ⊆ B，则A的任何子集C也是B的子集：C ⊆ B。

- **超集**：如果集合B的所有元素都是集合A的元素，则称B是A的超集，记作B ⊇ A。

  - **性质**：
    - **任意集合是其本身和空集的超集**：A ⊇ A，∅ ⊇ A。
    - **超集的超集仍是超集**：如果B ⊇ A，则B的任何超集C也是A的超集：C ⊇ A。

##### 1.2.3 运算律与运算性质

- **交换律**：对于任意集合A和B，有A ∪ B = B ∪ A，A ∩ B = B ∩ A。

- **结合律**：对于任意集合A、B和C，有(A ∪ B) ∪ C = A ∪ (B ∪ C)，(A ∩ B) ∩ C = A ∩ (B ∩ C)。

- **分配律**：对于任意集合A、B和C，有A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)，A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)。

- **德摩根律**：对于任意集合A和B，有∁(A ∩ B) = ∁A ∪ ∁B，∁(A ∪ B) = ∁A ∩ ∁B。

### 第2章 集合的基数与有限集合

#### 2.1 集合的基数

##### 2.1.1 基数的定义与性质

- **定义**：集合中元素的数量称为集合的基数，通常用符号|A|表示。

- **性质**：

  - **唯一性**：每个集合的基数是唯一的。

  - **非负性**：集合的基数是非负整数，即|A| ∈ ℕ。

  - **可加性**：如果集合A和B是两个有限集，则它们的并集的基数等于它们基数的和，即|A ∪ B| = |A| + |B| - |A ∩ B|。

##### 2.1.2 基数的计算方法

- **直接计算法**：直接数出集合中的元素个数。

- **间接计算法**：利用集合的基本运算和基数性质进行计算。

##### 2.1.3 可数集与不可数集

- **定义**：

  - **可数集**：集合的基数是自然数（包括0）的集合称为可数集。

  - **不可数集**：集合的基数不是自然数的集合称为不可数集。

- **性质**：

  - **可数集**：集合中的元素可以一一列举，例如自然数集合{1, 2, 3, ...}。

  - **不可数集**：集合中的元素无法一一列举，例如实数集合。

#### 2.2 有限集合

##### 2.2.1 有限集合的定义与性质

- **定义**：集合中元素个数有限的集合称为有限集合。

- **性质**：

  - **基数唯一**：有限集合的基数是唯一的非负整数。

  - **元素互异**：有限集合中的元素必须是互异的。

  - **元素可列举**：有限集合中的元素可以一一列举。

##### 2.2.2 有限集合的构造方法

- **枚举法**：通过一一列举有限集合中的元素来构造集合。

  - **示例**：构造集合{1, 2, 3, ..., n}。

- **生成法**：通过定义集合的生成式来构造集合。

  - **示例**：构造集合{x | x 是自然数且x < n}。

##### 2.2.3 有限集合的应用

- **集合运算**：有限集合的并集、交集和补集运算具有明确的计算方法。

  - **示例**：计算有限集合的基数。

- **排列组合**：有限集合可以用于解决排列组合问题。

  - **示例**：计算组合数C(n, k)。

### 第3章 幂集与笛卡尔积

#### 3.1 幂集

##### 3.1.1 幂集的定义与性质

- **定义**：一个集合的所有子集组成的集合称为该集合的幂集。

- **性质**：

  - **幂集的基数**：一个集合A的幂集P(A)的基数是2的A的基数次幂，即|P(A)| = 2^|A|。

  - **幂集的大小**：幂集的大小随着原始集合的大小呈指数增长。

  - **幂集的元素**：幂集P(A)的元素是集合A的所有子集。

##### 3.1.2 幂集的计算方法

- **方法1**：通过枚举法逐一计算幂集中的元素。

  - **示例**：计算集合{1, 2, 3}的幂集。

- **方法2**：利用二进制位表示幂集中的元素。

  - **示例**：用二进制表示集合{1, 2, 3}的幂集。

##### 3.1.3 幂集的应用

- **集合运算**：幂集可以用于解决集合的并集、交集和补集问题。

  - **示例**：利用幂集计算集合的基数。

- **概率论**：幂集可以用于计算概率论中的样本空间。

  - **示例**：计算掷两个骰子的样本空间。

#### 3.2 笛卡尔积

##### 3.2.1 笛卡尔积的定义与性质

- **定义**：两个集合的笛卡尔积是包含两个集合所有可能的有序对的集合。

- **性质**：

  - **基数乘积**：两个集合A和B的笛卡尔积的基数是A和B的基数乘积，即|A × B| = |A| × |B|。

  - **有序对**：笛卡尔积中的有序对是无序的，即(A, B) ≠ (B, A)。

  - **元素个数**：笛卡尔积中的元素个数等于A和B的元素个数乘积。

##### 3.2.2 笛卡尔积的计算方法

- **方法1**：通过枚举法逐一计算笛卡尔积中的元素。

  - **示例**：计算集合{1, 2}和集合{a, b}的笛卡尔积。

- **方法2**：利用嵌套循环实现笛卡尔积的计算。

  - **示例**：使用Python代码计算集合{1, 2}和集合{a, b}的笛卡尔积。

##### 3.2.3 笛卡尔积的应用

- **关系表示**：笛卡尔积可以用于表示集合之间的关系。

  - **示例**：表示两个集合的交集中元素的关系。

- **图论**：笛卡尔积可以用于图论的邻接矩阵表示。

  - **示例**：计算两个图的邻接矩阵。

### 第4章 关系与函数

#### 4.1 关系

##### 4.1.1 关系的基本概念

- **定义**：集合中元素之间的联系称为关系。

- **性质**：

  - **传递性**：如果元素a与b有关系，元素b与c有关系，则元素a与c也有关系。

  - **对称性**：如果元素a与b有关系，则元素b与a也有关系。

  - **反对称性**：如果元素a与b有关系，且元素b与a有关系，则a与b之间的关系不成立。

##### 4.1.2 关系的性质

- **传递性**：如果集合R是传递的，则对于R中的任意元素a、b、c，如果(a, b) ∈ R且(b, c) ∈ R，则(a, c) ∈ R。

- **对称性**：如果集合R是反对称的，则对于R中的任意元素a、b，如果(a, b) ∈ R，则(b, a) ∉ R。

- **自反性**：如果集合R是自反的，则对于R中的任意元素a，都有(a, a) ∈ R。

##### 4.1.3 关系的表示方法

- **邻接矩阵**：用矩阵表示关系，矩阵中元素a_ij表示元素a与b之间的关系。

  - **示例**：表示无向图中的邻接关系。

- **关系表**：用表格表示关系，表格中包含关系中的元素对。

  - **示例**：表示集合之间的包含关系。

#### 4.2 函数

##### 4.2.1 函数的基本概念

- **定义**：集合X中的每个元素在集合Y中有且仅有一个对应的元素，这种对应关系称为函数。

- **性质**：

  - **域**：函数的定义域，即函数能够取到的所有输入值。

  - **值域**：函数的值域，即函数能够取到的所有输出值。

  - **对应关系**：对于定义域中的任意元素，在值域中都有且仅有一个对应的元素。

##### 4.2.2 函数的性质

- **单射**：如果对于定义域中的任意两个不同的元素a、b，都有f(a) ≠ f(b)，则函数f是单射。

- **满射**：如果对于值域中的任意一个元素y，都存在定义域中的某个元素x，使得f(x) = y，则函数f是满射。

- **双射**：如果函数既是单射又是满射，则函数是双射。

##### 4.2.3 函数的表示方法

- **表格法**：用表格列出函数的定义域、值域和对应关系。

  - **示例**：表示二元一次方程的函数关系。

- **图示法**：用图表示函数的定义域、值域和对应关系。

  - **示例**：表示一元二次函数的图像。

   - ∁(A ∩ B) = {x | x ∉ A ∩ B} = {x | x ∉ A 或 x ∉ B} = ∁A ∪ ∁B。
   - ∁(A ∪ B) = {x | x ∉ A ∪ B} = {x | x ∉ A 且 x ∉ B} = ∁A ∩ ∁B。
