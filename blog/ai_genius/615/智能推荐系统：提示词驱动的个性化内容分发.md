def collect_keywords(user_input):
    # 输入：用户输入文本
    # 输出：关键词列表
    keywords = []
    # 去除停用词
    stop_words = set(["a", "the", "and", "in", "of"])
    words = user_input.lower().split()
    for word in words:
        if word not in stop_words:

def preprocess_keywords(keywords):
    # 输入：关键词列表
    # 输出：预处理后的关键词列表
    processed_keywords = []
    for keyword in keywords:
        # 去重
        if keyword not in processed_keywords:
            # 词干提取
            stem = stemmer(keyword)
            processed_keywords.append(stem)
    return processed_keywords

### 第4章：基于提示词的推荐算法

本章将介绍基于提示词的多种推荐算法：

1. **协同过滤算法**：通过分析用户行为数据，发现用户之间的相似性，进行内容推荐。
2. **内容推荐算法**：基于内容特征进行推荐，如文本分类、关键词匹配等。
3. **混合推荐算法**：结合协同过滤和内容推荐，提高推荐效果。

### 数学模型

假设用户集为$U=\{u_1, u_2, ..., u_n\}$，项目集为$I=\{i_1, i_2, ..., i_m\}$。

1. **协同过滤算法**：
   $$r_{ui} = \sum_{j\in N(u)} r_{uj} \cdot s_{ij}$$
   其中，$r_{ui}$为用户$u$对项目$i$的评分，$N(u)$为与用户$u$相似的邻居用户集合，$s_{ij}$为项目$i$和邻居项目$j$的相似度。

2. **内容推荐算法**：
   $$score(i, u) = \sum_{k\in K(i) \cap K(u)} w_{ik} \cdot w_{uk}$$
   其中，$K(i)$和$K(u)$分别为项目$i$和用户$u$的关键词集合，$w_{ik}$和$w_{uk}$分别为关键词$i_k$和用户$u$的权重。

3. **混合推荐算法**：
   $$r_{ui} = \alpha \cdot r_{ui}^c + (1-\alpha) \cdot r_{ui}^c$$
   其中，$\alpha$为混合参数，$r_{ui}^c$为协同过滤推荐分数，$r_{ui}^c$为内容推荐分数。

### 举例说明

假设用户$u$对项目$i$的评分为3，项目$i$的关键词集合为$\{篮球，比赛，运动\}$，用户$u$的关键词集合为$\{篮球，运动\}$。

1. **协同过滤算法**：
   $$r_{ui} = \sum_{j\in N(u)} r_{uj} \cdot s_{ij} = 0.6 \cdot 0.8 + 0.4 \cdot 0.7 = 0.68$$
2. **内容推荐算法**：
   $$score(i, u) = \sum_{k\in K(i) \cap K(u)} w_{ik} \cdot w_{uk} = 0.8 \cdot 0.9 + 0.2 \cdot 0.7 = 0.98$$
3. **混合推荐算法**：
   $$r_{ui} = \alpha \cdot r_{ui}^c + (1-\alpha) \cdot r_{ui}^c = 0.5 \cdot 0.68 + 0.5 \cdot 0.98 = 0.87$$
