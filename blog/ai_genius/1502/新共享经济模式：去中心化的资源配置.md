去中心化资源配置系统的核心功能包括：

   pragma solidity ^0.8.0;

   contract ResourceAllocation {
       mapping(address => uint256) public balances;

       function deposit() public payable {
           balances[msg.sender()] += msg.value;
       }

       function allocateResource(address recipient, uint256 amount) public {
           require(balances[msg.sender()] >= amount, "Insufficient balance");
           balances[msg.sender()] -= amount;
           balances[recipient] += amount;
           // 通知接收方资源已分配

       }

   - `/deposit` 路径：用于接收用户存款请求，将请求的金额发送到智能合约的 `deposit()` 函数。

   Flask后端通过Web3.py库与智能合约进行交互，实现了用户接口和节点接口的功能。后端代码的逻辑相对简单，主要是处理HTTP请求，调用智能合约函数，并将结果返回给用户。

#### 5.4 实际案例分析和详细讲解剖析

在本节中，我们将通过一个实际案例，展示如何使用本系统进行资源分配。

**案例**：

用户A拥有一台闲置的笔记本电脑，用户B需要租用这台电脑。用户A和用户B通过系统平台进行资源分配和交易。

**步骤**：

1. 用户A在平台上发布电脑资源信息，设置租赁价格。
2. 用户B在平台上查询到用户A的电脑资源，并提交租赁请求。
3. 用户B向智能合约发送存款请求，将租赁金额存入智能合约。
4. 用户A调用智能合约的 `allocateResource()` 函数，将电脑资源分配给用户B。
5. 用户B从智能合约接收电脑资源，完成租赁交易。

**详细讲解**：

1. **资源发布**：

   用户A通过Web界面，将电脑资源信息（如型号、租赁价格等）发布到平台。平台将资源信息存储到区块链上，确保数据的透明性和不可篡改性。

2. **资源查询**：

   用户B在平台上查询到用户A发布的电脑资源信息，并确认租赁价格和期限。用户B决定租用这台电脑，并提交租赁请求。

3. **存款请求**：

   用户B向智能合约发送存款请求，将租赁金额（如100美元）存入智能合约。智能合约将接收到的金额记录到用户B的余额映射中。

4. **资源分配**：

   用户A调用智能合约的 `allocateResource()` 函数，将电脑资源分配给用户B。函数执行成功后，智能合约将扣除用户A的余额，并将电脑资源转移到用户B。

5. **完成交易**：

   用户B从智能合约接收电脑资源，完成租赁交易。此时，用户B拥有电脑的使用权，用户A获得了租赁收入。
