### 3.1 空间数据结构的基本概念

在计算机科学和工程领域，数据结构是用于存储和组织数据的方式。空间数据结构是专门用于处理空间数据的数据结构，广泛应用于地理信息系统（GIS）、计算机图形学、计算机视觉以及科学计算等领域。在宇宙大尺度空洞的模拟中，空间数据结构起着至关重要的作用，因为它们能够高效地组织和管理大量的天体和空间数据。

空间数据结构的基本概念包括：

- **空间点**：空间中的基本元素，通常用二维或三维坐标表示。
- **空间区域**：由一组空间点组成，可以是一个点、一条线、一个面或一个体积。
- **空间关系**：描述空间点或区域之间的相对位置关系，如相邻、包含、相交等。

### 3.2 四叉树

四叉树（Quadtree）是一种广泛应用于空间数据结构的方法，它将空间划分为四个等大的子区域。每个子区域再划分为四个子区域，以此类推。四叉树的特点是递归地将空间划分为更小的区域，直到达到某个终止条件，如区域内的点数达到某个阈值。

#### 四叉树的组成

- **节点**：四叉树的每个节点代表一个空间区域，节点可以包含点、线、面或体。
- **叶节点**：不包含子节点的节点，表示最小的空间区域。
- **内部节点**：包含子节点的节点，表示更大的空间区域。

#### 四叉树的优点

- **空间高效性**：通过递归划分空间，可以减少存储空间的需求。
- **查询效率**：可以快速定位空间中的点或区域，适用于范围查询和最近邻查询。
- **动态扩展**：可以灵活地处理空间数据的动态变化。

#### 四叉树的缺点

- **递归深度**：递归划分可能导致递归深度较大，增加计算复杂性。
- **数据不均匀性**：在处理不均匀分布的数据时，可能会出现部分区域划分过于细化，而另一部分区域划分过于粗糙的问题。

### 3.3 八叉树

八叉树（Octree）是四叉树的扩展，它将空间划分为八个等大的子区域。与四叉树类似，八叉树也通过递归划分空间，适用于处理三维空间数据。

#### 八叉树的组成

- **节点**：与四叉树类似，每个节点代表一个空间区域。
- **叶节点**：不包含子节点的节点，表示最小的空间区域。
- **内部节点**：包含子节点的节点，表示更大的空间区域。

#### 八叉树的优点

- **更高维度的适应性**：相比于四叉树，八叉树更适合处理三维及更高维度的空间数据。
- **局部性**：在三维空间中，局部区域内的数据往往具有更强的相关性，八叉树可以更好地利用这种局部性。

#### 八叉树的缺点

- **计算复杂性**：与四叉树相比，八叉树的递归划分和合并操作更为复杂，可能导致计算时间增加。
- **存储需求**：相比于四叉树，八叉树需要更多的存储空间，因为每个节点可以有更多的子节点。

#### 4.1.1 牛顿力学定律

牛顿力学定律是描述物体运动的基本定律，包括：

        return Rectangle(self.x1, self.y1, x, y), Rectangle(x, y, self.x2, self.y2)

# 粒子类
class Particle:
    def __init__(self, position, velocity, mass):
        self.position = position
        self.velocity = velocity
        self.mass = mass

# 模拟函数
def simulate_particles(particles, time_step, num_steps):
    tree = QuadtreeNode(Rectangle(-10, -10, 10, 10), 4)
    for _ in range(num_steps):
        for particle in particles:
            tree.insert((particle.position[0], particle.position[1]))
            # 计算引力
            total_force = np.zeros(2)
            for other_particle in particles:
                if other_particle != particle:
                    distance = np.linalg.norm(particle.position - other_particle.position)
                    force = G * particle.mass * other_particle.mass / distance**2
                    direction = (other_particle.position - particle.position) / distance
                    total_force += force * direction
            # 更新速度和位置
            particle.velocity += total_force / particle.mass * time_step
            particle.position += particle.velocity * time_step

# 生成粒子
num_particles = 100
particles = [Particle(np.random.uniform(-10, 10), np.random.uniform(-1, 1), 1) for _ in range(num_particles)]

# 运行模拟
simulate_particles(particles, 0.01, 1000)

fig, ax = plt.subplots()
