#### 3.1 快速傅里叶变换（FFT）

快速傅里叶变换（FFT）是一种高效的算法，用于将时域信号转换为频域信号。在模拟宇宙暗物质湍流中，FFT可以帮助我们分析暗物质的分布和运动规律。以下是FFT的mermaid流程图：

```mermaid
graph TD
    A[初始数据] --> B[分治策略]
    B -->|分解] C{N/2}
    C -->|蝶形运算] D{N/2}
    D --> E{重复}
    E --> F[逆变换]
    F --> G[输出]
```

**FFT算法原理**：

1. **分治策略**：将原始数据分成两个等长度的子序列，分别计算它们的离散傅里叶变换（DFT）。
2. **蝶形运算**：对每个子序列进行蝶形运算，将两个子序列的DFT结果组合成一个完整的序列的DFT。
3. **逆变换**：将得到的频域信号进行逆变换，得到时域信号。

**Python源代码示例**：

```python
import numpy as np

def fft(x):
    n = len(x)
    if n <= 1:
        return x
    even = fft(x[0::2])
    odd = fft(x[1::2])
    T = [np.exp(-2j * np.pi * k * k / n) for k in range(n // 2)]
    return [even[k] + T[k] * odd[k] for k in range(n // 2)] + [even[k] - T[k] * odd[k] for k in range(n // 2)]

x = np.array([0, 1, 2, 3, 4, 5, 6, 7])
y = fft(x)
print(y)
```

在模拟宇宙暗物质湍流中，FFT可以帮助我们快速分析暗物质的分布和运动规律，从而更好地理解宇宙的演化过程。

#### 3.2 粒子群优化（PSO）

粒子群优化（PSO）是一种基于群体智能的优化算法，适用于求解复杂的非线性优化问题。在模拟宇宙暗物质湍流中，PSO可以帮助我们找到最优的参数配置，从而提高模拟的精度和效率。以下是PSO的mermaid流程图：

```mermaid
graph TD
    A[初始化粒子群] --> B[计算适应度函数]
    B -->|更新粒子位置和速度] C{适应度函数值比较}
    C -->|更新全局最优解] D{结束条件判断}
    D -->|结束] E{输出最优解}
```

**PSO算法原理**：

1. **初始化粒子群**：随机初始化粒子的位置和速度。
2. **计算适应度函数**：根据粒子当前位置计算适应度函数值。
3. **更新粒子位置和速度**：根据个体最优解和全局最优解更新粒子的位置和速度。
4. **更新全局最优解**：根据粒子群中最佳粒子的适应度函数值更新全局最优解。
5. **结束条件判断**：判断是否满足结束条件，如迭代次数达到最大值或适应度函数值达到最优值。

**Python源代码示例**：

```python
import numpy as np

def pso(func, bounds, n_particles, max_iter):
    w = 0.5
    c1 = 1.0
    c2 = 2.0

    particles = np.random.rand(n_particles, len(bounds))
    velocities = np.zeros_like(particles)
    personal_best = particles.copy()
    personal_best_scores = np.zeros(n_particles)
    global_best = personal_best[0].copy()
    global_best_score = func(global_best)

    for _ in range(max_iter):
        for i in range(n_particles):
            current_score = func(particles[i])
            if current_score < personal_best_scores[i]:
                personal_best_scores[i] = current_score
                personal_best[i] = particles[i]
            if current_score < global_best_score:
                global_best = particles[i].copy()
                global_best_score = current_score

        for i in range(n_particles):
            velocities[i] = w * velocities[i] + c1 * np.random.rand() * (personal_best[i] - particles[i]) + c2 * np.random.rand() * (global_best - particles[i])
            particles[i] += velocities[i]

    return global_best, global_best_score

def rosenbrock(x):
    return sum(100 * (x[1:] - x[:-1] ** 2) ** 2 + (1 - x[:-1]) ** 2)

x_opt, score_opt = pso(rosenbrock, bounds=[(-5, 10)] * 2, n_particles=50, max_iter=100)
print(x_opt, score_opt)
```

```python
    def __init__(self, objective, bounds, n_particles, max_iter):

        self.bounds = bounds
        self.n_particles = n_particles
        self.max_iter = max_iter

        # 执行PSO优化
        particles = np.random.rand(self.n_particles, len(self.bounds))
        velocities = np.zeros_like(particles)
```

```python
import numpy as np

def fft(x):
    n = len(x)
    if n <= 1:
        return x
    even = fft(x[0::2])
    odd = fft(x[1::2])
    T = [np.exp(-2j * np.pi * k * k / n) for k in range(n // 2)]
    return [even[k] + T[k] * odd[k] for k in range(n // 2)] + [even[k] - T[k] * odd[k] for k in range(n // 2)]

x = np.array([0, 1, 2, 3, 4, 5, 6, 7])
y = fft(x)
print(y)
```

#### 2. 粒子群优化（PSO）代码

```python
import numpy as np
from scipy.optimize import minimize

def rosenbrock(x):
    return sum(100 * (x[1:] - x[:-1] ** 2) ** 2 + (1 - x[:-1]) ** 2)

def pso(objective, bounds, n_particles, max_iter):
    w = 0.5
    c1 = 1.0
    c2 = 2.0

    particles = np.random.rand(n_particles, len(bounds))
    velocities = np.zeros_like(particles)
    personal_best = particles.copy()
    personal_best_scores = np.zeros(n_particles)
    global_best = personal_best[0].copy()
    global_best_score = objective(global_best)

    for _ in range(max_iter):
        for i in range(n_particles):
            current_score = objective(particles[i])
            if current_score < personal_best_scores[i]:
                personal_best_scores[i] = current_score
                personal_best[i] = particles[i]
            if current_score < global_best_score:
                global_best = particles[i].copy()
                global_best_score = current_score

        for i in range(n_particles):
            velocities[i] = w * velocities[i] + c1 * np.random.rand() * (personal_best[i] - particles[i]) + c2 * np.random.rand() * (global_best - particles[i])
            particles[i] += velocities[i]

    return global_best, global_best_score

x_opt, score_opt = pso(rosenbrock, bounds=[(-5, 10)] * 2, n_particles=50, max_iter=100)
print(x_opt, score_opt)
```
