## 第二章：数据结构基础

### 2.1 数据结构的概念

数据结构是指一组数据元素及其之间的相互关系和操作的集合。数据结构是计算机科学中的基础概念，用于组织和存储数据，使其能够高效地支持各种操作，如插入、删除、查找和排序等。

数据结构可以分为两大类：线性结构和非线性结构。线性结构包括数组、链表、栈和队列等；非线性结构包括树和图等。

数据结构的关键要素包括：

1. **数据元素**：数据结构中的基本单位，如一个数字、一个字符串或一个复杂的数据对象。
2. **数据关系**：数据元素之间的逻辑关系，如线性结构中的前后关系，树结构中的父子关系，图结构中的相邻关系。
3. **数据操作**：对数据结构进行的各种操作，如插入、删除、查找、更新和排序等。

### 2.2 常见的数据结构

以下是一些常见的数据结构及其特点：

#### 数组（Array）

数组是一种线性数据结构，用于存储一系列相同类型的元素。数组通过索引（Index）访问元素，其优点是访问速度较快，缺点是长度固定，不便于动态扩展。

**特点**：

- 线性结构
- 索引访问
- 长度固定
- 存储密集

**应用场景**：适用于存储和访问固定大小的数据集，如数组索引、图像处理等。

#### 链表（Linked List）

链表是一种线性或非线性数据结构，由一系列节点（Node）组成，每个节点包含数据元素和指向下一个节点的指针（Pointer）。链表具有较好的动态扩展性，但访问速度较慢。

**特点**：

- 线性或非线性结构
- 链式连接
- 动态扩展
- 存储较分散

**应用场景**：适用于需要频繁插入和删除操作的场景，如链表实现栈和队列等。

#### 栈（Stack）

栈是一种后进先出（LIFO）的数据结构，适用于存储和处理顺序数据。栈的操作主要包括压栈（push）和出栈（pop）。

**特点**：

- 线性结构
- 后进先出
- 只能在一端进行操作

**应用场景**：适用于需要先进后出的数据处理场景，如递归、函数调用等。

#### 队列（Queue）

队列是一种先进先出（FIFO）的数据结构，适用于存储和处理顺序数据。队列的操作主要包括入队（enqueue）和出队（dequeue）。

**特点**：

- 线性结构
- 先进先出
- 只能在两端进行操作

**应用场景**：适用于需要先进先出的数据处理场景，如消息队列、缓冲区等。

#### 树（Tree）

树是一种非线性数据结构，由一系列节点组成，每个节点可以有零个或多个子节点。树常用于表示层次结构，如文件系统、组织结构等。

**特点**：

- 非线性结构
- 层次关系
- 父子节点
- 递归操作

**应用场景**：适用于表示和操作层次结构的数据，如目录结构、决策树等。

#### 图（Graph）

图是一种非线性数据结构，由一系列节点（称为顶点）和边组成。图常用于表示复杂的关系网络，如社交网络、交通网络等。

**特点**：

- 非线性结构
- 顶点和边
- 相邻关系
- 连通关系

**应用场景**：适用于表示和操作复杂关系网络的数据，如社交网络分析、路径规划等。

### 3.1 N-body模拟算法

N-body模拟算法是一种用于模拟宇宙中多个物体之间相互作用的方法，其中N表示物体的数量。N-body模拟算法的核心是万有引力定律，它描述了两个物体之间的引力相互作用。根据万有引力定律，两个物体之间的引力与它们的质量和距离的平方成反比。

N-body模拟算法的基本步骤如下：

1. **初始化**：确定宇宙中所有物体的初始位置、质量和速度。
2. **计算引力**：计算每个物体与其他物体之间的引力，并更新每个物体的加速度。
3. **迭代计算**：重复计算引力，并更新物体的速度和位置，直到模拟达到预定的结束条件。
4. **结果分析**：分析模拟结果，如物体的运动轨迹、星系的形成等。

在N-body模拟中，数据结构的选择和优化对算法的性能至关重要。常用的数据结构包括数组、链表、树和图等。例如，可以使用数组来存储物体的位置和速度信息，使用树结构（如四叉树）来高效地划分空间，并优化引力计算过程。

以下是一个简化的Python代码示例，用于演示N-body模拟算法的基本原理：

```python
import numpy as np

def compute_gravity(particles, G):
    accelerations = np.zeros_like(particles)
    for i in range(len(particles)):
        for j in range(i + 1, len(particles)):
            dx = particles[j][0] - particles[i][0]
            dy = particles[j][1] - particles[i][1]
            distance = np.sqrt(dx**2 + dy**2)
            if distance == 0:
                continue
            force = G * particles[i][2] * particles[j][2] / distance**2
            ax = force * dx / distance
            ay = force * dy / distance
            accelerations[i][0] += ax
            accelerations[i][1] += ay
            accelerations[j][0] -= ax
            accelerations[j][1] -= ay
    return accelerations

def update_particles(particles, accelerations, dt):
    velocities = np.zeros_like(particles)
    for i in range(len(particles)):
        velocities[i][0] = particles[i][3]
        velocities[i][1] = particles[i][4]
    particles[:, 3] += accelerations[:, 0] * dt
    particles[:, 4] += accelerations[:, 1] * dt
    particles[:, 0] += velocities[:, 0] * dt
    particles[:, 1] += velocities[:, 1] * dt
    return particles

# 初始化参数
G = 6.67430e-11  # 万有引力常数
dt = 1e-3        # 时间步长
num_steps = 100   # 模拟步数

# 初始化粒子
particles = np.array([[0, 0, 1e11, 0, 0], [1e21, 0, 1e11, 10, 0]])

# 模拟过程
for step in range(num_steps):
    accelerations = compute_gravity(particles, G)
    particles = update_particles(particles, accelerations, dt)

# 打印最终结果
print(particles)
```

2. **抽样**：在给定的边界条件下随机生成粒子的初始位置和速度。
3. **迭代计算**：模拟粒子的运动，并记录粒子间的相互作用。

```python
import numpy as np

def generate_particles(num_particles, boundary, random_seed=None):
    np.random.seed(random_seed)
    x = np.random.uniform(0, boundary[0], num_particles)
    y = np.random.uniform(0, boundary[1], num_particles)
    vx = np.random.uniform(-10, 10, num_particles)
    vy = np.random.uniform(-10, 10, num_particles)

def update_particles(particles, dt):
    x = particles[:, 0] + particles[:, 2] * dt
    y = particles[:, 1] + particles[:, 3] * dt
    vx = particles[:, 2]
    vy = particles[:, 3]
    particles = np.array([x, y, vx, vy]).T
    return particles

# 初始化参数
num_particles = 100
boundary = (100, 100)
dt = 1e-2
num_steps = 100

# 初始化粒子
particles = generate_particles(num_particles, boundary)

# 模拟过程
for step in range(num_steps):
    particles = update_particles(particles, dt)
```

### 4.1 暗物质分布的数学模型

暗物质分布的数学模型是宇宙模拟中的重要组成部分，它描述了暗物质在宇宙中的分布规律。常见的暗物质分布模型包括冷暗物质模型（CDM）和暖暗物质模型（WDM）。

#### 4.1.1 冷暗物质模型（CDM）

冷暗物质模型假设暗物质粒子在宇宙早期阶段以非相对论速度运动，其速度相对较低。在CDM模型中，暗物质遵循热力学平衡，并且其密度分布可以用一个幂律函数来描述：

$$
\rho(r) \propto r^{-\gamma}
$$

其中，$r$是距离原点的距离，$\gamma$是幂律指数。通常情况下，$\gamma$的取值范围在1到3之间。

#### 4.1.2 暖暗物质模型（WDM）

暖暗物质模型假设暗物质粒子在宇宙早期阶段以相对论速度运动，其速度相对较高。在WDM模型中，暗物质的密度分布通常使用高斯函数来描述：

$$

其中，$r_0$是中心位置，$\sigma$是高斯分布的标准差。

#### 4.1.3 暗物质相互作用

在宇宙模拟中，暗物质之间的相互作用是关键因素。根据牛顿万有引力定律，两个暗物质粒子之间的引力可以表示为：

其中，$r_i$是第$i$个粒子的位置，$F(r_i)$是第$i$个粒子所受的引力。

```python
            dx = particles[j][0] - particles[i][0]
            dy = particles[j][1] - particles[i][1]
            distance = np.sqrt(dx**2 + dy**2)
            if distance == 0:
                continue
            force = G * particles[i][2] * particles[j][2] / distance**2
            ax = force * dx / distance
            ay = force * dy / distance
            accelerations[i][0] += ax
            accelerations[i][1] += ay
            accelerations[j][0] -= ax
            accelerations[j][1] -= ay
    return accelerations

# 更新粒子位置和速度
def update_particles(particles, accelerations, dt):
    velocities = particles[:, 2:] * np.array([1, 1, 1, 1])
    particles[:, 2:] += accelerations * dt
    particles[:, 0] += velocities[:, 0] * dt
    particles[:, 1] += velocities[:, 1] * dt
    return particles

# 绘制粒子分布
def plot_particles(particles):
    x = particles[:, 0]
    y = particles[:, 1]
    plt.scatter(x, y, s=5, c='blue', marker='o')
    plt.xlabel('X')
    plt.ylabel('Y')
    plt.title('Dark Matter Distribution')
    plt.axis('equal')
    plt.grid(True)

# 动画模拟
def animate_particles(i, particles):
    accelerations = compute_gravity(particles)
    particles = update_particles(particles, accelerations, dt)
    plot_particles(particles)
    return plot_particles(particles)

# 创建动画
fig = plt.figure()
ani = FuncAnimation(fig, animate_particles, frames=num_steps, fargs=(particles,), interval=50, blit=True)

plt.show()
```
