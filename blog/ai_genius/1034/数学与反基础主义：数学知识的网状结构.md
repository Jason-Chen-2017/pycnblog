### 图的最短路径算法

在构建网状结构时，确定两个节点之间的最短路径是一个常见问题。Dijkstra算法是一种有效的最短路径算法。

**算法描述**：

Dijkstra算法的基本思想是从源点开始，逐步扩展到其他节点，并记录每个节点到源点的最短路径。具体步骤如下：

1. 初始化：设置一个距离表 $d$，其中 $d[v] = \infty$ 对于所有节点 $v$，除了源点 $d[s] = 0$。
2. 选择未访问过的节点 $u$，使得 $d[u]$ 最小。
3. 对于 $u$ 的每个邻居 $v$，更新 $d[v]$，如果 $d[u] + w(u, v) < d[v]$，则 $d[v] = d[u] + w(u, v)$。
4. 标记 $u$ 为已访问。
5. 重复步骤2-4，直到所有节点都被访问。

**伪代码**：

```python
def Dijkstra(G, s):
    d = [inf] * len(G)
    d[s] = 0
    visited = [False] * len(G)
    
    for _ in range(len(G)):
        u = min(d[v] for v, visited[v] in zip(d, visited) if not visited[v])
        visited[u] = True
        for v, w in G[u].items():
            if d[u] + w < d[v]:
                d[v] = d[u] + w
                
    return d
```

**举例说明**：

考虑一个简单的加权图，其中边权表示两点之间的距离：

$$

从节点1出发，使用Dijkstra算法计算到其他节点的最短路径：
