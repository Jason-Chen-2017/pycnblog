为了更好地理解信任经济中的信任评估，我们可以使用以下数学模型：

$$
\text{TrustScore} = \frac{\sum_{i=1}^{n} \text{Score}_{i}}{n}
$$

其中，$ \text{Score}_{i} $ 表示个体之间的每次交易的信任得分，$ n $ 表示共同交易的历史次数。

$$
\text{TrustScore} = \frac{1 \times 1 + 1 \times (-1) + 1 \times 1 + 1 \times (-1) + 1 \times 1}{5} = \frac{2}{5} = 0.4

因此，个体A对个体B的信任度为0.4。

```python
# 信任评估系统
class TrustScore:
    def __init__(self, transactions):
        self.transactions = transactions
    
    def calculate_score(self):
        total_score = 0
        for transaction in self.transactions:
            if transaction["result"] == "成功":
                total_score += 1
            else:
                total_score -= 1
        return total_score / len(self.transactions)

# 测试
transactions = [
    {"result": "成功", "rating": "好"},
    {"result": "失败", "rating": "差"},
    {"result": "成功", "rating": "好"},
    {"result": "失败", "rating": "差"},
    {"result": "成功", "rating": "好"}
]

trust_score = TrustScore(transactions)
print(f"信任度：{trust_score.calculate_score()}")
```
