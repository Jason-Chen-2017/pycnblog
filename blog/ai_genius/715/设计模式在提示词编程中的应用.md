#### 单例模式

单例模式是一种确保一个类只有一个实例，并提供一个访问它的全局点的设计模式。

**基本原理**：
- 创建一个类，该类负责创建自己的对象。
- 提供一个静态方法，该方法返回类的唯一实例。

**伪代码实现**：

```python
class Singleton:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super(Singleton, cls).__new__(cls)
        return cls._instance

singleton = Singleton()
```

**在提示词编程中的应用**：
- 可以用于创建全局配置对象，确保配置的一致性。
- 在提示词编程中，可以用于创建日志记录器，保证只有一个日志记录器实例。

#### 工厂模式

工厂模式是一种在创建对象时，不直接实例化对象，而是通过工厂类来创建对象的设计模式。

**基本原理**：
- 创建一个工厂类，该类负责创建不同类型的对象。
- 工厂类根据输入参数或内部逻辑，决定创建哪种类型的对象。

**伪代码实现**：

```python
class Factory:
    def create_object(self, type):
        if type == 'A':
            return ClassA()
        elif type == 'B':
            return ClassB()

factory = Factory()
object_a = factory.create_object('A')
object_b = factory.create_object('B')
```
