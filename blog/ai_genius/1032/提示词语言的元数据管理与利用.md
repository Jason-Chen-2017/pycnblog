### 基础概念

#### 元数据类型

元数据可以根据其形式和用途分为以下几类：

1. **文档元数据**：描述文档的基本信息，如标题、作者、创建日期等。
2. **结构化元数据**：描述数据结构的信息，如数据库模式、XML Schema等。
3. **非结构化元数据**：描述非结构化数据的信息，如文本、图像、音频等。

#### 元数据模型

元数据模型是对元数据组织的抽象表示，常见的元数据模型包括：

1. **XML元数据模型**：基于XML的元数据模型，具有良好的扩展性和互操作性。
2. **RDF元数据模型**：基于语义网络的元数据模型，适用于复杂的数据互联和共享。
3. **OWL元数据模型**：基于RDF的扩展，提供了更丰富的语义描述能力。

#### 元数据标准

元数据标准是确保元数据一致性和可互操作的规范。常见的元数据标准包括：

1. **DC（Dublin Core）**：一种简单、通用的元数据元素集，适用于各种类型的资源。
2. **OGC**：开放地理空间联盟的标准，包括地理空间数据的元数据规范。
3. **ISO 19115**：国际标准化组织发布的地理空间数据元数据标准。

### 代码案例

以下是一个简单的Python代码案例，用于元数据采集和存储：

```python
import json

# 元数据采集
def collect_metadata():
    metadata = {
        "title": "书籍标题",
        "author": "作者姓名",
        "created_date": "2023-01-01",
        "content": "书籍内容"
    }
    return metadata

# 元数据存储
def store_metadata(metadata):
    with open('metadata.json', 'w') as f:
        json.dump(metadata, f)

# 主函数
def main():
    metadata = collect_metadata()
    store_metadata(metadata)
    print("元数据采集和存储完成。")

if __name__ == "__main__":
    main()
```

from django.shortcuts import render
from .models import Metadata

def index(request):
    metadata_list = Metadata.objects.all()
    return render(request, 'index.html', {'metadata_list': metadata_list})

def add_metadata(request):
    if request.method == 'POST':
        title = request.POST['title']
        author = request.POST['author']
        created_date = request.POST['created_date']
        content = request.POST['content']
        Metadata.objects.create(title=title, author=author, created_date=created_date, content=content)
        return render(request, 'success.html')
    return render(request, 'add_metadata.html')

def delete_metadata(request, id):
    metadata = Metadata.objects.get(id=id)
    metadata.delete()
    return render(request, 'success.html')
