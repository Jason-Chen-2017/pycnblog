#### 1.1 城市创客的定义与特征

城市创客，是指那些生活在城市环境中，以创新和创造为核心驱动力，积极利用科技、艺术和设计来改善生活、解决问题的个体或团队。他们通常具有以下特征：

1. **跨领域技能**：城市创客不仅具备技术技能，还擅长设计、艺术和商业策略。
2. **动手实践**：他们热衷于将创意转化为实际项目，通过实践来验证和完善想法。
3. **社区参与**：城市创客重视社区互动，积极参与公共项目，以推动社会进步。
4. **创新思维**：他们习惯于从不同角度思考问题，勇于挑战传统观念，寻找新颖的解决方案。

#### 1.1.1 城市创客的定义

城市创客（Urban Maker）一词，最早起源于20世纪90年代的美国。它指的是那些在城市环境中，通过创新和技术实践来改变生活、推动社区发展的个体或团队。随着城市化和科技的发展，城市创客的概念逐渐成熟，并成为全球范围内的一种文化现象。

#### 1.1.2 城市创客的文化特征

城市创客的文化特征体现在以下几个方面：

1. **开源精神**：城市创客推崇开放共享，乐于将自己的知识和资源与他人分享。
2. **创新思维**：他们注重创新和创造力，勇于尝试新的技术和方法。
3. **跨学科合作**：城市创客通常具备跨学科的知识和技能，能够从不同领域寻找灵感，实现创新。
4. **社区参与**：城市创客积极参与社区事务，致力于改善社区环境和居民生活质量。

import random
import time

class TrafficLightSystem:
    def __init__(self):
        self.red_time = random.randint(30, 60)  # 红灯时间（秒）
        self.green_time = random.randint(30, 60)  # 绿灯时间（秒）

    def update_traffic_light(self):
        if self.red_time > 0:
            print("红灯亮，请停车等待。")
            self.red_time -= 1
        elif self.green_time > 0:
            print("绿灯亮，可以通行。")
            self.green_time -= 1
        else:
            print("系统故障，请手动调整。")

    def run(self):
        while True:
            self.update_traffic_light()
            time.sleep(1)

# 测试交通灯系统

traffic_light.run()
