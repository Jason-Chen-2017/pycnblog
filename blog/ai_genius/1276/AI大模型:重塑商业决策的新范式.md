**## Python 源代码示例**

```python
import numpy as np

# 创建数据集
X = np.random.rand(100, 10)
y = np.random.rand(100, 1)

# 初始化模型参数
weights = np.random.rand(10, 1)

# 训练模型
for i in range(1000):
    predictions = np.dot(X, weights)
    error = y - predictions
    weights += np.dot(X.T, error)

# 模型评估
accuracy = np.mean(np.square(y - np.dot(X, weights)))
print(f"Model accuracy: {accuracy}")
```
