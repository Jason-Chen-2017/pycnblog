    """

### 第1章：团队凝聚力的定义与重要性

#### 1.1 团队凝聚力的定义与类型

团队凝聚力是指团队成员之间相互吸引、相互依赖的程度，以及团队成员对团队认同感和归属感的表现。它是衡量一个团队整体协作水平和团队精神的重要指标。

团队凝聚力的类型可以分为以下几种：

1. **内部凝聚力**：指的是团队成员之间的相互吸引力，包括情感、信任、尊重和默契等方面。内部凝聚力较高的团队通常表现出较高的合作意愿和团队精神。
2. **外部凝聚力**：指的是团队对外界环境或目标的吸引力，包括对团队使命、愿景和价值观的认同感。外部凝聚力较高的团队通常能够更好地应对外部挑战，保持稳定的发展。
3. **任务凝聚力**：指的是团队在完成特定任务时的协作程度。任务凝聚力较高的团队在任务执行过程中通常表现出高效的协同合作，能够更好地实现任务目标。

#### 1.2 团队凝聚力的重要性

团队凝聚力对于团队绩效、员工满意度和组织文化等方面具有深远的影响：

1. **团队绩效**：高凝聚力的团队通常能够更好地完成工作任务，实现团队目标。团队成员之间的高效协作和默契配合能够提高工作效率，减少冲突和错误，从而提升团队的整体绩效。
2. **员工满意度**：团队凝聚力可以提升员工的工作满意度和归属感。团队成员之间的良好关系和相互支持能够使员工感受到团队的重要性和自身的价值，从而提高工作积极性和忠诚度。
3. **组织文化**：团队凝聚力有助于塑造和传播组织文化。一个具有高凝聚力的团队能够更好地传承和弘扬组织价值观，推动组织文化的建设和发展。

#### 1.3 团队凝聚力的影响因素

团队凝聚力的影响因素包括以下几个方面：

1. **团队成员的角色与互动**：团队成员的角色明确、互动积极，有助于增强团队凝聚力。
2. **团队共同目标与价值观**：明确的共同目标和共同的价值观可以增强团队成员的认同感和归属感，提高团队凝聚力。
3. **团队沟通与协作**：有效的沟通和协作可以提高团队成员之间的信任和默契，有助于增强团队凝聚力。
4. **领导者的角色与职责**：领导者的领导风格、沟通能力和激励策略对团队凝聚力具有重要影响。
5. **团队建设活动**：定期的团队建设活动可以提高团队成员之间的互动和沟通，增强团队凝聚力。

### 第2章：团队凝聚力建设的核心概念

#### 2.1 团队成员的角色与互动

团队成员的角色与互动是团队凝聚力建设的基础。每个团队成员都在团队中扮演着特定的角色，他们的互动和协作直接影响团队凝聚力的强弱。

1. **团队成员的角色分类**：

   - **领导者**：负责团队的方向、目标和资源配置，协调团队成员的工作。
   - **执行者**：负责执行团队计划，完成任务。
   - **支持者**：为团队成员提供支持和协助，解决团队遇到的困难。
   - **沟通者**：负责团队内部的沟通和外部联络，确保信息的流通。
   - **创新者**：为团队带来新的想法和创意，推动团队发展。

2. **团队成员之间的互动**：

   - **沟通**：团队成员之间的有效沟通是增强团队凝聚力的重要手段。通过沟通，团队成员能够了解彼此的需求和想法，建立信任和共识。
   - **协作**：团队成员之间的协作是实现团队目标的关键。通过协作，团队成员可以共同应对挑战，发挥各自的优势，提高团队的整体效能。

#### 2.2 团队共同目标与价值观

团队共同目标和价值观是团队凝聚力的核心。它们为团队成员提供了共同的方向和信念，增强了团队成员之间的凝聚力和归属感。

1. **团队共同目标**：

   - **明确的目标**：团队共同目标应当明确、具体，能够激发团队成员的积极性和参与感。目标应当与团队的核心价值和使命相一致，确保团队成员为之奋斗的愿景是一致的。
   - **实现目标的路径**：团队共同目标不仅要有明确的方向，还需要有实现目标的路径和策略。团队成员应当了解如何共同努力，实现团队目标。

2. **团队价值观**：

   - **价值观的定义**：团队价值观是团队成员共同遵循的原则和信仰。它们代表了团队的核心理念和行为准则，是团队成员共同奋斗的精神支柱。
   - **价值观的传递**：团队价值观应当通过团队文化的建设、领导者的示范和团队活动的传递，使每位团队成员深刻理解和认同。只有团队成员对团队价值观有共识，才能形成强大的团队凝聚力。

#### 2.3 团队沟通与协作

团队沟通与协作是团队凝聚力建设的关键环节。有效的沟通和协作能够增强团队成员之间的信任和合作，提高团队的整体效能。

1. **有效沟通的方法**：

   - **开放性沟通**：鼓励团队成员坦诚地表达自己的想法和意见，尊重彼此的观点。
   - **双向沟通**：不仅注重信息传递，还要注重信息反馈，确保沟通的双方都理解对方的意图。
   - **透明化沟通**：在团队内部建立信息共享机制，使团队成员能够及时了解团队动态和决策过程。

2. **团队协作的策略**：

   - **明确分工**：根据团队成员的特长和优势，合理分配任务，确保每个成员都能发挥最大的作用。
   - **协同合作**：鼓励团队成员在任务执行过程中相互协作，共同解决问题，提高工作效率。
   - **持续反馈**：团队成员之间定期进行工作反馈和总结，发现和解决协作中的问题，不断优化协作流程。

通过明确团队成员的角色与互动、建立团队共同目标和价值观、以及强化团队沟通与协作，可以有效提升团队凝聚力，为团队的发展奠定坚实的基础。

### 第3章：团队凝聚力建设的方法与实践

#### 3.1 培养团队信任的方法

信任是团队凝聚力的基石，是团队成员之间相互依赖和合作的前提。以下是一些培养团队信任的方法：

1. **建立透明化的沟通机制**：

   - **及时沟通**：团队成员应当及时分享信息，避免信息滞后和误解。领导者应当鼓励团队成员在遇到问题时，及时汇报和讨论，以便快速找到解决方案。
   - **开放性沟通**：鼓励团队成员在沟通中表达真实想法，营造一个开放、包容的沟通氛围。团队成员应当尊重彼此的观点，倾听他人的意见，共同寻找最佳解决方案。

2. **增强团队成员之间的互动**：

   - **定期团队建设活动**：通过定期的团队建设活动，如团队拓展训练、团队聚餐和团队旅游等，增进团队成员之间的了解和信任。这些活动有助于团队成员在轻松的环境中建立友谊，增强团队凝聚力。
   - **跨部门协作**：鼓励团队成员跨部门协作，参与不同项目和任务，增加团队成员之间的交流与合作，促进信任的建立。

3. **建立公平公正的激励机制**：

   - **奖励与认可**：领导者应当公正地奖励团队成员，根据团队成员的贡献和表现给予奖励。这不仅能激励团队成员，还能增强团队成员之间的信任。
   - **公平的晋升机制**：建立公平、透明的晋升机制，确保团队成员能够根据其能力和表现获得晋升机会。这有助于提高团队成员的积极性和归属感，增强团队凝聚力。

4. **树立榜样和价值观**：

   - **领导者的示范作用**：领导者应当以身作则，树立良好的榜样。通过自己的言行，向团队成员传递诚信、尊重和合作的价值观，引导团队成员形成良好的信任氛围。
   - **核心价值观的传递**：团队应当明确核心价值观，并通过团队文化、团队活动和领导者的示范，将核心价值观传递给每位团队成员。这有助于团队成员在行动中遵循共同的价值观，增强团队的信任。

#### 3.2 提高团队沟通效率的策略

高效的沟通是团队协作的关键，以下是一些提高团队沟通效率的策略：

1. **明确沟通目标和对象**：

   - **设定明确的目标**：在每次沟通前，明确沟通的目标和预期成果。这有助于团队成员集中注意力，提高沟通的效率。
   - **确定沟通对象**：确定需要参与沟通的人员，避免不必要的参与，减少沟通的复杂性。

2. **优化沟通渠道和方式**：

   - **多样化的沟通渠道**：根据沟通的内容和需求，选择合适的沟通渠道，如面对面会议、电话会议、电子邮件、即时通讯工具等。多样化的沟通渠道有助于提高沟通的灵活性和效率。
   - **简明扼要的表达**：在沟通中，尽量使用简单、明了的语言，避免使用复杂、冗长的句子和术语。这有助于团队成员快速理解沟通内容，提高沟通的效率。

3. **提高信息传递的准确性**：

   - **确认理解**：在沟通过程中，团队成员应当主动确认对方的理解，确保信息传递的准确性。可以采用“复述法”，即重复对方的主要观点，以确保双方对信息的理解一致。
   - **及时反馈**：在沟通后，及时反馈沟通结果，确保信息的接收者已经理解并执行了沟通的内容。这有助于提高沟通的效果，避免误解和误操作。

4. **建立高效的沟通流程**：

   - **规范化沟通流程**：制定规范的沟通流程，明确沟通的步骤、责任和时限。这有助于团队成员在沟通中遵循统一的流程，提高沟通的效率。
   - **定期沟通会议**：定期召开沟通会议，总结和反馈沟通情况，发现和解决沟通中的问题。这有助于保持沟通的持续性，提高沟通的整体效率。

通过培养团队信任和提高沟通效率，团队可以更好地协调合作，实现共同目标。有效的团队凝聚力建设不仅能够提升团队绩效，还能增强员工的满意度和忠诚度，为团队的长远发展奠定坚实的基础。

### 第4章：团队凝聚力建设的策略与工具

#### 4.1 团队建设活动的策划与实施

团队建设活动是增强团队凝聚力的重要手段。有效的团队建设活动可以增强团队成员之间的信任、沟通和协作，提高团队的整体效能。以下是如何策划与实施团队建设活动的一些建议：

1. **明确活动目标**：

   - 在策划团队建设活动时，首先明确活动的目标。活动目标应当与团队的当前任务和长远发展目标相一致。例如，增强团队合作、提升团队沟通能力或促进团队成员之间的相互了解等。

2. **选择合适的活动形式**：

   - 根据团队的特点和需求，选择适合的团队建设活动形式。常见的团队建设活动包括团队拓展训练、团队主题讨论、团队角色扮演、团队游戏等。每种活动形式都有其独特的优势，可以根据团队的具体需求进行选择。

3. **制定详细的活动计划**：

   - 在活动策划阶段，制定详细的活动计划，包括活动时间、地点、参与人员、活动流程和预期效果等。活动计划应当尽量详细，确保活动的顺利进行。

4. **提前进行准备工作**：

   - 在活动开始前，提前做好准备工作。例如，预订场地、准备活动材料、通知团队成员等。确保所有准备工作都按时完成，以避免活动当天出现不必要的延误。

5. **实施过程中关注团队成员的参与度**：

   - 在活动实施过程中，关注团队成员的参与度。鼓励团队成员积极参与，积极互动。在活动中，可以设置一些小组竞赛或互动环节，激发团队成员的参与热情。

6. **活动后的总结与反馈**：

   - 活动结束后，及时进行总结与反馈。邀请团队成员分享活动感受和收获，总结活动中的成功经验和不足之处。通过总结与反馈，可以为未来的团队建设活动提供宝贵的参考。

#### 4.2 团队评估与反馈机制

团队评估与反馈机制是团队凝聚力建设的重要组成部分。通过定期的评估与反馈，团队可以及时发现和解决问题，持续改进团队工作。

1. **建立评估指标**：

   - 团队评估指标应当包括团队凝聚力、团队绩效、团队成员满意度等方面。根据团队的具体情况，可以设定不同的评估指标，确保评估的全面性和准确性。

2. **制定评估计划**：

   - 制定定期的评估计划，确保团队评估的持续性。评估计划应当包括评估时间、评估内容和评估方法等。评估时间可以是一季度或半年一次，具体取决于团队的需求和实际情况。

3. **收集反馈信息**：

   - 在评估过程中，收集团队成员的反馈信息。可以通过问卷调查、面谈、会议讨论等形式收集反馈。确保反馈信息的真实性、客观性和全面性。

4. **分析评估结果**：

   - 收集到反馈信息后，进行评估结果的分析。分析团队成员的满意度、团队的协作效率、团队的绩效等方面，找出存在的问题和改进的方向。

5. **制定改进措施**：

   - 根据评估结果，制定具体的改进措施。改进措施应当有针对性，能够解决评估中发现的问题。同时，改进措施应当与团队的目标和发展战略相一致。

6. **跟踪改进效果**：

   - 实施改进措施后，定期跟踪改进效果。通过再次评估和反馈，验证改进措施的有效性。如果效果不明显，需要及时调整改进措施，确保团队凝聚力得到持续提升。

通过团队建设活动的策划与实施、团队评估与反馈机制的建立，团队可以持续提升团队凝聚力，实现团队的长远发展。

### 第7章：团队共同价值观的建立与维护

#### 7.1 团队共同价值观的定义与作用

团队共同价值观是指团队成员在长期合作中形成的、共同遵循和认同的核心信念和行为准则。它不仅是团队文化的基石，也是团队凝聚力和协作能力的重要保障。以下是团队共同价值观的定义与作用：

1. **定义**：团队共同价值观是团队成员共同认可和遵循的价值观体系，包括团队的使命、愿景、核心价值观和行为准则。它反映了团队的核心理念和共同目标，是团队成员共同的行为准则。

2. **作用**：

   - **指导行为**：团队共同价值观为团队成员提供了行为准则，使团队成员在面临决策和行动时，能够遵循共同的价值观，减少内部冲突，确保团队行动的一致性。
   - **增强凝聚力**：共同价值观能够增强团队成员的归属感和认同感，使团队成员在共同价值观的引导下，形成紧密的团队关系，提高团队凝聚力。
   - **促进协作**：共同价值观能够促进团队成员之间的协作和信任，使团队成员能够相互支持，共同应对挑战，提高团队的协作效率。
   - **塑造文化**：团队共同价值观是团队文化的核心组成部分，它通过团队的日常行为和互动，不断塑造和传播团队文化，形成独特的团队氛围。

#### 7.2 建立团队共同价值观的策略

建立团队共同价值观是一个系统性工程，需要从多个方面进行考虑和规划。以下是一些有效的策略：

1. **明确核心价值观**：

   - **界定使命和愿景**：团队应当明确自身的使命和愿景，使团队成员了解团队的目标和发展方向，从而为价值观的建立提供基础。
   - **讨论核心价值观**：组织团队成员进行讨论，共同界定和确定团队的核心价值观。通过集体讨论，可以确保价值观的广泛认同和内部一致性。

2. **宣传和普及**：

   - **内部培训**：通过内部培训，向团队成员普及团队核心价值观，使其深入人心。培训内容可以包括价值观的含义、实践案例以及如何在实际工作中应用价值观等。
   - **宣传材料**：制作宣传海报、手册等，将团队核心价值观展示在办公区域和内部平台上，使团队成员时刻受到价值观的熏陶。

3. **领导者示范**：

   - **以身作则**：领导者应当以身作则，成为团队价值观的典范。通过领导者的行为和决策，向团队成员展示如何将价值观体现在实际工作中。
   - **激励与认可**：领导者应当通过激励和认可，鼓励团队成员践行团队价值观。例如，对践行价值观的团队成员进行表彰和奖励，强化价值观的认同。

4. **融入团队文化**：

   - **团队活动**：将团队价值观融入团队活动和日常工作中。例如，在团队会议、项目讨论和团建活动中，强调团队价值观的重要性，引导团队成员在实践中践行价值观。
   - **文化建设**：通过团队文化建设，使价值观成为团队文化的核心元素。团队文化应当体现团队价值观，并通过各种方式传承和弘扬价值观。

#### 7.3 维护团队共同价值观的方法

建立团队共同价值观只是一个开始，维护团队共同价值观同样重要。以下是一些有效的方法：

1. **定期评估**：

   - **价值观评估**：定期对团队价值观的践行情况进行评估，了解团队成员对价值观的认同程度和实际应用情况。
   - **反馈机制**：建立反馈机制，鼓励团队成员提出对价值观的见解和建议，及时调整和优化价值观。

2. **持续宣传**：

   - **宣传材料更新**：定期更新宣传材料，保持对团队价值观的宣传力度，使团队成员时刻关注价值观的践行。
   - **内部交流**：鼓励团队成员在内部交流中分享价值观践行的心得和体会，促进价值观的深入理解和认同。

3. **培训与辅导**：

   - **价值观培训**：定期组织价值观培训，帮助团队成员深入理解和践行团队价值观。
   - **辅导与支持**：对在价值观践行中遇到困难的团队成员提供辅导和支持，帮助他们克服挑战，确保价值观的顺利实施。

4. **激励机制**：

   - **文化认同**：通过文化建设，使团队成员深刻认识到价值观对团队发展的重要性，增强价值观的认同感。

通过建立和维护团队共同价值观，团队可以形成强大的凝聚力和协作能力，实现持续发展和成功。共同价值观不仅是团队前进的动力，也是团队成员共同奋斗的精神支柱。

#### 8.1 领导者的角色与职责

领导者在团队凝聚力建设中扮演着至关重要的角色。领导者的行为和决策直接影响团队凝聚力的形成和发展。以下是领导者角色与职责的详细探讨：

1. **领导者角色**：

   - **愿景引领者**：领导者应当为团队设定清晰的愿景和目标，激励团队成员为之努力。通过愿景的引领，增强团队成员对团队目标和价值观的认同感，提高团队的凝聚力。
   - **决策者**：领导者负责制定团队的战略和决策，确保团队朝着正确的方向前进。领导者应当具备敏锐的洞察力和决策能力，能够在复杂多变的环境中做出明智的决策。
   - **协调者**：领导者需要协调团队成员之间的关系，解决团队内部的矛盾和冲突，确保团队内部的和谐与稳定。通过有效的沟通和协调，提高团队的协作效率。
   - **激励者**：领导者应当关注团队成员的成长和发展，激励团队成员发挥最大潜力。通过认可和奖励，激发团队成员的积极性和创造力，增强团队凝聚力。

2. **领导者职责**：

   - **明确团队目标**：领导者应当明确团队的目标和任务，将其转化为具体的行动计划，确保团队成员了解并认同团队的目标。
   - **培养团队文化**：领导者需要塑造和培养积极的团队文化，包括共同的价值观、行为准则和工作氛围。通过团队文化的建设，增强团队成员的归属感和认同感。
   - **促进团队沟通**：领导者应当鼓励团队成员之间的沟通和合作，建立有效的沟通机制，确保信息的畅通和及时反馈。
   - **解决团队问题**：领导者需要及时发现和解决团队中存在的问题，为团队成员提供支持和帮助。通过解决团队问题，增强团队的凝聚力和稳定性。
   - **发展团队成员**：领导者应当关注团队成员的个人发展和职业规划，提供培训和发展机会，帮助团队成员不断提升自己的能力和素质。

   - **协同工作**：领导者应当推动团队成员之间的协同工作，建立协作机制，确保团队成员能够有效地合作，共同完成任务。

   - **价值观传承**：领导者应当将团队的核心价值观传承给每位团队成员，确保团队成员在行动中遵循共同的价值观。

### 第9章：团队凝聚力建设的实战案例

#### 9.1 案例背景与目标

本案例选取了一家快速发展的互联网公司，该公司在经历了一轮业务扩展后，新成立了一个由不同部门成员组成的跨职能团队。由于团队成员来自不同的部门，文化背景和工作习惯差异较大，团队内部的沟通和协作存在一定的障碍，团队凝聚力较低，影响了项目的进度和绩效。为了提升团队凝聚力，公司决定开展一系列团队凝聚力建设活动。

1. **背景**：公司业务扩展，新成立跨职能团队，团队成员背景多样，沟通协作不畅。
2. **目标**：通过团队凝聚力建设活动，提升团队沟通协作能力，增强团队凝聚力，确保项目顺利进行。

#### 9.2 案例实施过程

1. **策划团队建设活动**：

   - **明确活动目标**：确定团队建设活动的主要目标，包括增强团队成员之间的信任、提高沟通效率、促进协作等。
   - **选择活动形式**：根据团队特点和需求，选择了团队拓展训练、团队主题讨论和团队游戏等多样化的活动形式。
   - **制定活动计划**：制定详细的活动计划，包括活动时间、地点、参与人员、活动流程和预期效果等。

2. **实施团队建设活动**：

   - **团队拓展训练**：组织团队成员参加户外拓展训练，通过团队合作完成各种挑战性任务，增强团队成员之间的信任和协作能力。
   - **团队主题讨论**：开展团队主题讨论，让团队成员就团队目标、价值观和团队文化等话题进行深入交流，增强团队成员的认同感和归属感。
   - **团队游戏**：组织团队游戏，如团队拼图、团队拼字等，通过游戏的方式增进团队成员之间的互动和沟通。

3. **实施团队沟通技巧培训**：

   - **培训内容**：邀请专业的沟通培训师，为团队成员提供沟通技巧培训，内容包括有效沟通的方法、倾听技巧、非言语沟通等。
   - **实践演练**：在培训过程中，安排实践演练环节，让团队成员在实际情境中应用所学沟通技巧，提高沟通能力。

4. **鼓励团队成员参与团队决策**：

   - **设立团队委员会**：设立团队委员会，让团队成员参与到团队决策中，增强团队成员的责任感和参与感。
   - **定期会议**：定期召开团队会议，讨论项目进展、问题解决方案和团队目标等，鼓励团队成员积极发言，提出自己的意见和建议。

5. **定期进行团队凝聚力评估**：

   - **评估指标**：制定团队凝聚力评估指标，包括信任水平、沟通效率、协作效果等。
   - **评估方法**：采用问卷调查、访谈和团队反馈等方式，定期评估团队凝聚力水平。
   - **反馈与调整**：根据评估结果，及时反馈团队成员，针对存在的问题进行调整和改进。

#### 9.3 案例效果评估与反思

1. **效果评估**：

   - **团队信任水平提高**：通过团队拓展训练和主题讨论等活动，团队成员之间的信任水平显著提高，协作更加顺畅。
   - **沟通效率提升**：团队成员的沟通技巧得到提升，沟通效率明显提高，信息传递更加准确和及时。
   - **团队协作效果增强**：通过参与团队决策和协作活动，团队成员的协作效果得到增强，项目进展更加顺利。
   - **团队成员满意度提高**：团队成员对新团队的认同感和归属感增强，工作满意度提高。

2. **反思与改进**：

   - **持续关注团队凝聚力**：团队凝聚力建设不是一次性的活动，需要持续关注和努力。公司应当建立长期机制，定期评估团队凝聚力水平，确保团队凝聚力持续提升。

   - **文化传承**：将团队价值观和凝聚力建设融入公司文化，通过日常管理和团队活动，持续传承和弘扬团队文化。
   - **激励与认可**：建立激励与认可机制，对在团队凝聚力建设中表现突出的团队成员进行奖励和表彰，激发团队成员的积极性和创造力。

通过本案例的实践，公司成功提升了新团队的凝聚力和协作能力，为项目的顺利推进提供了有力保障。案例中的经验和方法也为其他团队提供了借鉴和参考。

### 核心算法原理讲解：团队信任培养算法

```plaintext
算法名称：团队信任培养算法

输入参数：
- T：团队成员数量
- R：团队成员初始信任矩阵（T x T矩阵）
- P：团队成员初始合作概率

算法步骤：
1. 初始化信任矩阵 R 和合作概率矩阵 P
2. 循环执行以下步骤，直到满足停止条件：
   a. 对于每个团队成员 i，计算其与其他团队成员 j 的信任值更新 ΔR_ij
      ΔR_ij = (1 - α) * R_ij + α * P_ij
   b. 更新信任矩阵 R，使用 ΔR_ij 的值
   c. 更新合作概率矩阵 P，根据新的信任矩阵 R 计算
3. 输出最终的信任矩阵 R 和合作概率矩阵 P

停止条件：
- 达到预设的迭代次数或信任矩阵变化小于预设阈值

目标：
- 实现团队成员之间高水平的信任，提高团队凝聚力和协作效率
```

```python
# 团队凝聚力评估函数
def team_coherence(trust_scores, communication_scores, collaboration_scores):
    """
    计算团队的凝聚力评分。
    
    :param trust_scores: 信任评分列表
    :param communication_scores: 沟通效率评分列表
    :param collaboration_scores: 协作效果评分列表
    :return: 团队凝聚力评分
    """
    # 计算信任、沟通和协作的平均值
    avg_trust = np.mean(trust_scores)
    avg_communication = np.mean(communication_scores)
    avg_collaboration = np.mean(collaboration_scores)
    
    # 计算团队凝聚力评分
    coherence_score = 0.5 * (avg_trust**2 + avg_communication**2 + avg_collaboration**2 
                             + 2 * avg_trust * avg_communication + 2 * avg_trust * avg_collaboration 
                             + 2 * avg_communication * avg_collaboration)
    
    return coherence_score

# 示例数据

communication_scores = [0.85, 0.9, 0.8]
collaboration_scores = [0.8, 0.75, 0.85]

# 计算团队凝聚力评分

print("团队的凝聚力评分：", coherence)
```
