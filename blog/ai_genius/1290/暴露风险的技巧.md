## 核心概念与联系

### 风险评估的方法与模型

风险评估是风险管理的重要环节，其核心目标是识别和评估潜在的风险，以便采取相应的措施进行控制。在实际操作中，风险评估通常分为定量评估和定性评估两种方法。

#### 定量评估

定量评估是通过数值指标对风险进行评估的方法。这种方法通常基于统计分析和数学模型，具有较高的准确性和可操作性。常见的定量评估方法包括：

1. **风险矩阵法**：通过构建风险矩阵，将风险发生的概率和影响进行量化，从而计算风险得分。
2. **蒙特卡洛模拟法**：通过模拟大量随机事件，估计风险的概率分布和期望损失。
3. **价值损失法**：计算风险可能导致的财务损失，从而评估风险的大小。

#### 定性评估

定性评估是基于主观判断的风险评估方法。这种方法通常依赖于专家的经验和知识，适用于风险因素难以量化的场景。常见的定性评估方法包括：

1. **专家评估法**：邀请领域专家对风险进行评估，综合其经验和判断得出风险评估结果。
2. **故障树分析（FTA）**：通过构建故障树模型，分析风险发生的可能性和影响，从而评估风险。
3. **事件树分析（ETA）**：通过构建事件树模型，分析风险事件的发展和结果，从而评估风险。

### 风险评估框架

为了系统地进行风险评估，我们需要一个全面的评估框架。以下是一个典型的风险评估框架：

1. **风险识别**：识别潜在的风险因素，包括内部和外部因素。
2. **风险评估**：对已识别的风险进行评估，确定其概率和影响。
3. **风险排序**：根据评估结果，对风险进行排序，确定优先级。
4. **风险应对**：制定应对措施，包括风险规避、风险转移、风险缓解等。
5. **风险监控**：持续监控风险的变化，确保应对措施的有效性。

### 模型与算法

在风险评估中，常用的模型和算法包括：

一个有效的风险评估框架能够帮助企业全面、系统地识别和管理风险。以下是一个典型的风险评估框架，包括关键步骤和方法：

#### 1. 风险识别

风险识别是风险评估的第一步，旨在识别企业内部和外部可能面临的所有潜在风险。具体方法包括：

- **历史数据分析**：分析以往的风险事件和历史数据，识别常见和潜在的风险。

#### 2. 风险评估

在风险识别完成后，需要对已识别的风险进行评估，确定其概率和影响。常用的评估方法包括：

- **风险矩阵**：通过构建风险矩阵，将风险发生的概率和影响进行量化，计算风险得分。

根据评估结果，对风险进行排序，确定优先级。排序的方法可以基于风险得分、影响范围和紧急程度等。常用的排序方法包括：

- **优先级矩阵**：根据风险得分和影响范围，将风险分为高、中、低三个等级。
- **风险地图**：通过绘制风险地图，直观展示各个风险的位置和优先级。

#### 4. 风险应对

在确定风险排序后，需要制定相应的应对措施，以减轻或消除风险。常见的风险应对策略包括：

- **风险规避**：通过调整业务策略，避免风险的发生。
- **风险转移**：通过购买保险或签订合同，将风险转移给第三方。
- **风险缓解**：通过改进流程、增加资源或实施控制措施，减轻风险的影响。

#### 5. 风险监控

风险评估不是一次性的过程，而是一个持续的活动。为了确保风险评估和应对措施的有效性，需要建立风险监控机制，持续跟踪和评估风险。具体方法包括：

- **定期检查**：定期对风险状态进行检查，确保应对措施的有效性。
- **预警系统**：建立风险预警系统，及时识别和报告潜在的风险。
- **反馈机制**：建立反馈机制，收集和分析风险应对的效果，不断优化风险管理策略。

### 定量风险评估

在风险管理中，定量风险评估是一种重要的方法，它通过数值指标对风险进行评估，以便进行更精确的决策。以下将详细探讨定量风险评估的方法及其应用。

#### 1. 风险矩阵法

风险矩阵法是一种常用的定量风险评估方法，通过构建一个矩阵，将风险发生的概率和影响进行量化。具体步骤如下：

1. **确定风险因素**：首先，识别项目中可能面临的所有风险因素，例如市场风险、技术风险、财务风险等。
2. **定义概率和影响**：为每个风险因素定义一个概率值和影响值。概率值表示风险发生的可能性，影响值表示风险发生后的影响程度。通常，概率和影响值可以是0到1之间的数值。
3. **构建风险矩阵**：将概率和影响值填入风险矩阵中，计算每个风险因素的得分。得分可以通过概率和影响的乘积计算，也可以通过加权方法计算。
4. **排序和优先级**：根据得分对风险因素进行排序，确定优先级。

以下是一个简单的风险矩阵示例：

| 风险因素 | 概率 | 影响 | 得分 |
| --- | --- | --- | --- |
| 市场风险 | 0.3 | 0.8 | 0.24 |
| 技术风险 | 0.5 | 0.7 | 0.35 |
| 财务风险 | 0.2 | 0.6 | 0.12 |

在这个例子中，市场风险的得分最低，因此应优先关注。

#### 2. 蒙特卡洛模拟法

蒙特卡洛模拟法是一种基于随机抽样的定量风险评估方法，适用于复杂系统的风险评估。具体步骤如下：

1. **定义随机变量**：首先，识别系统中的关键随机变量，例如市场波动、技术延迟等。
2. **生成随机样本**：通过随机抽样方法，生成大量随机样本，每个样本代表一个可能的状态。
3. **计算结果**：对每个随机样本进行模拟，计算系统的输出结果，例如损失、收益等。
4. **统计分析**：对模拟结果进行统计分析，估计风险的概率分布和期望损失。

以下是一个简单的蒙特卡洛模拟示例：

```python
import numpy as np

# 参数设置
num_simulations = 1000
market_volatility = np.random.normal(0, 1, num_simulations)
technical_delay = np.random.normal(0, 1, num_simulations)

# 计算损失
loss = market_volatility * technical_delay

# 计算期望损失
expected_loss = np.mean(loss)
print(f"Expected Loss: {expected_loss:.2f}")
```

在这个例子中，我们通过模拟1000次，计算了市场波动和技术延迟的乘积，作为损失。期望损失为-0.12，表示平均每次模拟的损失。

#### 3. 价值损失法

价值损失法是一种通过计算风险可能导致的财务损失进行评估的方法。具体步骤如下：

1. **定义损失指标**：首先，确定系统中的关键损失指标，例如市场价值、运营成本等。
2. **计算潜在损失**：根据当前状态和未来预测，计算潜在损失。例如，如果市场波动增加10%，技术延迟增加5%，可能导致的市场价值损失为1000万元。
3. **概率分配**：根据历史数据和专家判断，为每个潜在损失分配一个概率。
4. **计算期望损失**：通过概率加权，计算期望损失。

以下是一个简单的价值损失法示例：

```python
# 参数设置
market_change = 10
technical_delay_change = 5
potential_loss = 10000000

# 概率设置
probability_of_loss = 0.5

# 计算期望损失
expected_loss = potential_loss * probability_of_loss
print(f"Expected Loss: {expected_loss:.2f}")
```

在这个例子中，如果市场波动增加10%，技术延迟增加5%，可能导致的市场价值损失为1000万元，概率为50%，因此期望损失为500万元。

通过上述定量评估方法，企业可以更准确地评估风险，制定更有效的风险管理策略。定量评估不仅提供了数值支持，还帮助企业更好地理解风险，从而做出更明智的决策。

### 定性风险评估

定性风险评估是一种基于主观判断的风险评估方法，适用于风险因素难以量化的场景。以下将详细探讨定性风险评估的方法及其应用。

#### 1. 专家评估法

专家评估法是一种通过邀请领域专家对风险进行评估的方法。具体步骤如下：

1. **组建评估团队**：首先，组建一个由领域专家、项目经理、风险管理专家等组成的评估团队。
2. **确定评估标准**：为每个风险因素定义评估标准，例如风险发生的可能性、影响程度等。
3. **评估风险**：邀请专家根据评估标准对风险进行评估，通常采用评分制或打分制。
4. **综合评估结果**：将专家的评估结果进行综合，得出最终的风险评估结果。

以下是一个简单的专家评估法示例：

| 风险因素 | 可能性 | 影响程度 | 评估结果 |
| --- | --- | --- | --- |
| 市场风险 | 高 | 高 | 3.0 |
| 技术风险 | 中 | 中 | 2.0 |
| 财务风险 | 低 | 低 | 1.0 |

在这个例子中，市场风险被评估为最高优先级，应重点关注。

#### 2. 故障树分析（FTA）

故障树分析是一种通过构建故障树模型，分析风险发生的可能性和影响的方法。具体步骤如下：

1. **定义顶事件**：首先，确定顶事件，即可能导致风险的关键事件。
2. **构建故障树**：根据顶事件，构建故障树模型，包括基本事件、中间事件和顶事件。
3. **分析故障树**：通过分析故障树，确定故障发生的概率和影响。
4. **优化故障树**：根据分析结果，优化故障树，降低故障发生的概率。

以下是一个简单的故障树分析示例：

```mermaid
graph TD
    A[顶事件] --> B[基本事件1]
    A --> C[基本事件2]
    B --> D[中间事件1]
    C --> E[中间事件2]
    D --> F[底事件1]
    E --> G[底事件2]
```

在这个例子中，顶事件是“系统崩溃”，基本事件包括“基本事件1”和“基本事件2”，中间事件包括“中间事件1”和“中间事件2”，底事件包括“底事件1”和“底事件2”。

#### 3. 事件树分析（ETA）

事件树分析是一种通过构建事件树模型，分析风险事件的发展和结果的方法。具体步骤如下：

1. **定义初始事件**：首先，确定初始事件，即可能导致风险的事件。
2. **构建事件树**：根据初始事件，构建事件树模型，包括可能的结果和后续事件。
3. **分析事件树**：通过分析事件树，确定事件发生的概率和影响。
4. **优化事件树**：根据分析结果，优化事件树，降低事件发生的概率。

以下是一个简单的事件树分析示例：

```mermaid

    A[初始事件] --> B{成功或失败}
    B -->|成功| C[后续事件1]
    B -->|失败| D[后续事件2]
    C --> E[结果1]
    D --> F[结果2]
```

在这个例子中，初始事件是“系统升级”，可能的结果是“成功”或“失败”，后续事件包括“后续事件1”和“后续事件2”，结果包括“结果1”和“结果2”。

通过以上定性评估方法，企业可以更全面地识别和管理风险，尤其是那些难以量化的风险因素。定性评估方法虽然依赖于专家的主观判断，但通过与定量评估方法结合，可以提供更准确的风险评估结果。

在这个例子中，市场风险、技术风险和财务风险是顶级节点，供应链中断和信用风险是中间节点，项目延迟是结果节点。每个节点之间的边表示它们之间的概率关系。

使用Python和Pymc3库，我们可以构建贝叶斯网络并计算风险暴露：

```python
import pymc3 as pm

with pm.Model() as model:
    # 定义节点概率
    market_risk = pm.Bernoulli('market_risk', p=0.3)
    tech_risk = pm.Bernoulli('tech_risk', p=0.5)
    fin_risk = pm.Bernoulli('fin_risk', p=0.2)
    
    # 定义中间节点
    supply_chain = pm.Bernoulli('supply_chain', p=0.7 * market_risk + 0.5 * tech_risk)
    credit_risk = pm.Bernoulli('credit_risk', p=0.8 * fin_risk)
    
    # 定义结果节点
    project_delay = pm.Bernoulli('project_delay', p=0.9 * supply_chain + 0.6 * credit_risk)
    
    # 执行MCMC采样
    trace = pm.sample(1000)

# 绘制结果
pm.plot_trace(trace)
plt.show()
```

在这个模型中，我们使用了Bernoulli分布来表示每个节点的概率。通过MCMC采样，我们可以估计风险暴露的概率分布。

### 风险暴露的数学模型与推导

在风险管理中，数学模型是评估风险暴露的关键工具。以下将详细探讨风险暴露的数学模型，包括其基本原理、数学公式以及具体推导过程，并使用LaTeX格式进行公式展示。

#### 1. 风险暴露的定义

风险暴露（Risk Exposure, RE）是指在特定时间段内，一个系统或组织可能遭受的风险损失。其数学模型通常表示为：

\[ \text{RE} = \sum_{i=1}^{n} \text{R}_i \times \text{P}_i \]

其中，\( R_i \) 表示第 \( i \) 种风险的概率损失，\( P_i \) 表示第 \( i \) 种风险的概率。

#### 2. 基本原理

风险暴露的数学模型基于概率论和统计学原理。通过计算每种风险的概率损失，并对其进行加权求和，可以得到总的预期风险暴露。

#### 3. 数学公式与推导

以下是一个简单的数学模型示例，用于计算单一风险因素的风险暴露：

\[ \text{RE} = R \times P \]

其中，\( R \) 表示风险损失，\( P \) 表示风险概率。

推导过程如下：

1. **确定风险损失**：假设一个企业的潜在风险损失为 \( R \)，这可能是由于市场波动、技术故障或其他因素引起的。
2. **确定风险概率**：根据历史数据和专家判断，确定风险发生的概率 \( P \)。
3. **计算风险暴露**：将风险损失 \( R \) 乘以风险概率 \( P \)，得到风险暴露 \( \text{RE} \)。

例如，假设企业的潜在风险损失为 \( R = \$100,000 \)，风险概率为 \( P = 0.1 \)，则风险暴露为：

\[ \text{RE} = \$100,000 \times 0.1 = \$10,000 \]

这表示企业在未来一年内可能遭受的预期风险损失为 \$10,000。

#### 4. 多因素风险暴露计算

在实际应用中，企业可能面临多种风险因素。为了计算总的风险暴露，我们需要对每个风险因素进行加权求和：

\[ \text{RE}_{\text{total}} = \sum_{i=1}^{n} \text{R}_i \times \text{P}_i \]

其中，\( \text{R}_i \) 和 \( \text{P}_i \) 分别表示第 \( i \) 种风险的因素损失和概率。

例如，假设企业面临三种风险因素，每种风险的因素损失和概率如下：

| 风险因素 | 因素损失（\$） | 概率 |
| --- | --- | --- |
| 风险1 | 50,000 | 0.3 |
| 风险2 | 30,000 | 0.4 |
| 风险3 | 20,000 | 0.3 |

则总的风险暴露为：

\[ \text{RE}_{\text{total}} = 50,000 \times 0.3 + 30,000 \times 0.4 + 20,000 \times 0.3 = 15,000 + 12,000 + 6,000 = 33,000 \]

这表示企业在未来一年内可能遭受的总预期风险损失为 \$33,000。

通过上述数学模型和公式，我们可以系统地计算企业面临的风险暴露，为制定有效的风险管理策略提供依据。使用LaTeX格式展示公式，可以确保公式的准确性和规范性：

\[ \text{RE}_{\text{total}} = \sum_{i=1}^{n} \text{R}_i \times \text{P}_i \]

其中：
\[ R_i = \text{因素损失}_i \]
\[ P_i = \text{风险概率}_i \]

这种数学模型不仅适用于单一风险因素的评估，还可以扩展到复杂的多因素风险评估，为企业提供全面的风险管理视角。

### 风险暴露在金融领域的应用

在金融领域，风险暴露的管理至关重要。金融机构面临的风险类型多样，包括信用风险、市场风险、操作风险等。以下将详细介绍风险暴露在金融领域的应用，并通过具体案例分析展示如何评估和管理这些风险。

#### 1. 信用风险暴露

信用风险是指借款人或交易对手无法履行债务的风险。金融机构需要评估借款人的信用状况，以确定其违约的概率和可能导致的损失。以下是一个案例分析：

**案例：某银行贷款信用风险评估**

- **借款人信息**：借款人为一家中小企业，年营业收入为1000万元，负债率为50%。
- **信用评级**：根据信用评级模型，该企业的违约概率为5%。
- **贷款金额**：银行拟提供100万元的贷款。

使用信用风险暴露公式，我们可以计算：

\[ \text{信用风险暴露} = \text{违约概率} \times \text{贷款金额} \]
\[ \text{信用风险暴露} = 0.05 \times 100万元 = 5万元 \]

这表示该笔贷款的信用风险暴露为5万元。金融机构可以根据此数据制定相应的风险管理策略，如调整贷款条件、增加担保措施等。

#### 2. 市场风险暴露

市场风险是指由于市场价格波动导致金融机构资产或负债价值变化的风险。以下是一个案例分析：

**案例：某投资公司股票投资市场风险暴露**

- **投资组合**：投资公司持有100万股某股票，当前市值为5000万元。
- **市场波动**：根据市场波动性分析，该股票的波动率为20%。

使用市场风险暴露公式，我们可以计算：

\[ \text{市场风险暴露} = \text{投资市值} \times \text{波动率} \]
\[ \text{市场风险暴露} = 5000万元 \times 0.2 = 1000万元 \]

这表示投资公司的市场风险暴露为1000万元。在市场波动较大时，投资公司需要采取对冲策略，如购买期权、期货等，以降低市场风险。

#### 3. 操作风险暴露

操作风险是指由于内部操作失误、系统故障、欺诈等导致的风险。以下是一个案例分析：

**案例：某银行操作风险暴露**

- **事件**：银行系统发生故障，导致大量交易数据丢失。
- **损失估计**：根据历史数据和风险评估模型，系统故障可能导致的损失为100万元。

使用操作风险暴露公式，我们可以计算：

\[ \text{操作风险暴露} = \text{事件损失} \]
\[ \text{操作风险暴露} = 100万元 \]

这表示银行因系统故障可能面临的风险暴露为100万元。银行需要建立有效的应急响应机制，以迅速应对和缓解此类风险。

#### 4. 综合风险管理

金融机构需要综合考虑各类风险，建立综合的风险管理体系。以下是一个综合风险管理案例：

**案例：某金融机构综合风险暴露评估**

- **信用风险暴露**：500万元
- **市场风险暴露**：1000万元
- **操作风险暴露**：100万元

使用综合风险暴露公式，我们可以计算：

\[ \text{综合风险暴露} = \text{信用风险暴露} + \text{市场风险暴露} + \text{操作风险暴露} \]
\[ \text{综合风险暴露} = 500万元 + 1000万元 + 100万元 = 1600万元 \]

这表示该金融机构的综合风险暴露为1600万元。金融机构应制定详细的应对措施，包括风险分散、风险转移、风险控制等，以确保风险在可接受范围内。

通过以上案例分析，我们可以看到，风险暴露在金融领域的应用涵盖了信用风险、市场风险和操作风险等多个方面。通过准确的评估和管理，金融机构可以有效降低风险，保障业务稳定运行。

### 风险暴露在供应链管理中的应用

在供应链管理中，风险暴露的管理至关重要。供应链涉及多个环节，包括供应商、制造商、分销商和零售商，任何一环出现问题都可能影响整个供应链的运行。以下将详细介绍风险暴露在供应链管理中的应用，并分析如何进行评估和管理。

#### 1. 供应链风险类型

供应链管理中常见的风险类型包括：

- **供应链中断**：由于自然灾害、战争、政治不稳定等原因导致供应链中断。
- **供应不稳定**：供应商无法按时交付原材料或产品，导致供应链延迟。
- **运输风险**：运输过程中的意外事件，如交通事故、货物损坏等。
- **库存管理风险**：库存过多或不足，导致资金占用或库存积压。

#### 2. 风险评估方法

为了评估供应链风险暴露，企业可以采用以下方法：

- **风险矩阵法**：通过构建风险矩阵，对每种风险的概率和影响进行量化。
- **蒙特卡洛模拟**：通过模拟大量随机事件，分析供应链中断的概率和损失。
- **事件树分析**：构建事件树模型，分析供应链中断的路径和可能的结果。

#### 3. 案例分析

以下是一个供应链中断风险暴露的案例分析：

**案例：某电子产品制造商供应链中断风险暴露评估**

- **供应链现状**：制造商依赖一家主要供应商供应关键部件，供应商位于地震频发地区。
- **风险评估**：根据历史数据和专家判断，供应链中断的概率为10%，中断影响可能包括生产延迟、订单丢失等。

使用蒙特卡洛模拟，我们可以计算供应链中断的期望损失：

```python
import numpy as np

# 参数设置
num_simulations = 1000
probability_of_interruption = 0.1
average_loss_per_interruption = 100000  # 每次中断的平均损失

# 生成随机样本
random_losses = np.random.choice([0, average_loss_per_interruption], size=num_simulations, p=[1 - probability_of_interruption, probability_of_interruption])

# 计算总损失
total_loss = np.sum(random_losses)

# 计算期望损失
expected_loss = total_loss / num_simulations
print(f"Expected Loss: {expected_loss:.2f}")
```

运行上述代码，我们得到期望损失为10,000元。这表示在1000次模拟中，供应链中断的平均损失为10,000元。

#### 4. 风险管理策略

为了降低供应链中断风险暴露，企业可以采取以下风险管理策略：

- **多元化供应商**：增加供应商数量，降低对单一供应商的依赖。
- **建立应急储备**：在关键部件库存中建立应急储备，以应对供应链中断。
- **签订长期合同**：与供应商签订长期合同，确保供应稳定性。
- **风险转移**：购买保险，将供应链中断风险转移给保险公司。

通过以上方法和策略，企业可以有效降低供应链中断风险暴露，保障供应链的稳定运行。

#### 1. 健康风险管理

健康风险管理旨在识别和管理个人或群体健康风险，以预防和控制健康问题。以下是一个健康风险管理的案例：

**案例：某保险公司健康风险管理**

- **客户信息**：一名45岁的男性客户，有吸烟史，家族中有心脏病史。
- **风险评估**：根据客户的个人和家族病史，评估其患有心脏病的风险概率。

使用贝叶斯网络模型，我们可以计算心脏病的风险暴露：

```python
import pymc3 as pm

# 构建贝叶斯网络模型
with pm.Model() as model:
    # 定义变量
    age = pm.DiscreteUniform('age', lower=30, upper=60, shape=1)
    smoking = pm.Categorical('smoking', p=[0.5, 0.5])
    family_history = pm.Categorical('family_history', p=[0.4, 0.6])
    heart_disease = pm.Bernoulli('heart_disease', p=0.01)

    # 定义条件概率
    pm.math_pfpm('heart_disease', p=(0.7 if age > 50 and smoking else 0.2 if family_history else 0.05))

    # 采样
    trace = pm.sample(1000)

# 分析结果
print(pm.summary(trace)["heart_disease"]["mean"])
```

运行上述代码，我们得到客户患有心脏病的平均风险概率为0.05。这表示该客户在当前情况下患有心脏病的风险较高。保险公司可以根据此风险概率为该客户制定相应的健康保险计划，如增加保费或提供额外的健康建议。

#### 2. 环境风险管理

环境风险管理旨在评估和管理环境风险，以减少对生态系统和人类健康的影响。以下是一个环境风险管理的案例：

**案例：某化工公司环境风险管理**

- **工厂信息**：某化工厂生产过程中可能产生有害废气，需要评估其对周边环境的潜在影响。
- **风险评估**：根据废气排放量和周边人口密度，评估有害废气对环境的潜在影响。

使用蒙特卡洛模拟，我们可以计算废气排放的环境风险暴露：

```python
import numpy as np

# 参数设置
num_simulations = 1000
mean_emission = 100  # 平均每日排放量
std_emission = 10  # 排放量标准差
population_density = 5000  # 人/平方公里

# 生成随机样本
daily_emissions = np.random.normal(mean_emission, std_emission, num_simulations)

# 计算累积暴露
cumulative_exposure = daily_emissions * population_density

# 计算最大暴露
max_exposure = np.max(cumulative_exposure)

print(f"Maximum Exposure: {max_exposure:.2f}")
```

运行上述代码，我们得到最大环境风险暴露为1200人。这表示在某一时刻，化工厂的废气可能对周边1200人造成最大风险。企业应根据此数据调整生产工艺或采取减排措施，以降低环境风险。

#### 术语解释

1. **风险（Risk）**：指不确定性事件或情况，可能对目标造成负面影响。
2. **风险评估（Risk Assessment）**：对潜在风险进行识别、分析和评价的过程。
3. **风险暴露（Risk Exposure）**：系统、项目或组织面临的风险程度。
4. **定量评估（Quantitative Assessment）**：使用数值指标进行风险评估的方法。
5. **定性评估（Qualitative Assessment）**：使用主观判断进行风险评估的方法。
6. **贝叶斯网络（Bayesian Network）**：一种概率图模型，用于表示风险因素之间的概率关系。
7. **蒙特卡洛模拟（Monte Carlo Simulation）**：通过模拟大量随机事件，估计风险的概率分布和期望损失。
8. **价值损失法（Value at Risk, VAR）**：计算风险可能导致的财务损失，从而评估风险的大小。
9. **风险矩阵（Risk Matrix）**：用于表示风险发生的概率和影响，并进行风险评估的工具。
10. **故障树分析（Fault Tree Analysis, FTA）**：通过构建故障树模型，分析风险发生的可能性和影响。
11. **事件树分析（Event Tree Analysis, ETA）**：通过构建事件树模型，分析风险事件的发展和结果。
