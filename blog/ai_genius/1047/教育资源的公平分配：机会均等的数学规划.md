### 第3章 数学规划基础

#### 3.1 数学规划的基本概念

数学规划是一种优化方法，通过建立数学模型，求解目标函数的最优解。数学规划的基本概念包括目标函数、约束条件、变量和求解算法。

1. **目标函数**：目标函数是数学规划的核心，它描述了优化问题的目标，通常是最大化或最小化某个指标。例如，在教育资源分配中，目标函数可以是最大化教育效益或最小化资源浪费。

2. **约束条件**：约束条件描述了变量在优化过程中的限制条件，确保求解出的最优解满足实际情况。例如，学校容量、师资力量、财政预算等都是约束条件。

3. **变量**：变量是数学规划中的决策变量，它们代表了资源配置的量。例如，学生的数量、教师的数量、学校的数量等。

4. **求解算法**：求解算法是用于求解最优解的方法，常见的求解算法包括线性规划、非线性规划、整数规划、动态规划等。

#### 3.2 线性规划

线性规划是数学规划中的一种特殊形式，其目标函数和约束条件都是线性的。线性规划适用于解决简单的资源分配问题，如学校设施和师资力量的配置。

1. **线性规划模型**：

   - **目标函数**：最大化或最小化某个线性函数。
   - **约束条件**：一组线性不等式或等式。
   - **变量**：决策变量，通常是连续的。

2. **线性规划求解**：

   - **单纯形法**：一种经典的求解线性规划的方法，通过迭代逐步优化目标函数。
   - **对偶问题**：通过求解对偶问题来找到最优解，对偶问题与原问题有紧密的联系。

3. **Python实现**：

   ```python
   import numpy as np
   from scipy.optimize import linprog

   # 目标函数
   c = np.array([1, 2])
   # 约束条件
   A = np.array([[1, 2], [-1, 3]])
   b = np.array([5, -2])
   # 求解
   result = linprog(c, A_ub=A, b_ub=b)
   print(result)
   ```

   这段代码使用Scipy库中的`linprog`函数求解线性规划问题。

#### 3.3 非线性规划

非线性规划是数学规划中的一种更复杂的形式，其目标函数和约束条件可能是非线性的。非线性规划适用于解决更复杂的资源分配问题，如课程设置和财政支持。

1. **非线性规划模型**：

   - **目标函数**：最大化或最小化某个非线性函数。
   - **约束条件**：一组非线性不等式或等式。
   - **变量**：决策变量，通常是连续的。

2. **非线性规划求解**：

   - **梯度下降法**：一种迭代求解方法，通过不断更新变量值来逼近最优解。
   - **牛顿法**：基于梯度下降法，通过二次近似来加速收敛。
   - **遗传算法**：一种基于自然进化的优化方法，适用于求解复杂非线性规划问题。

3. **Python实现**：

   ```python
   import numpy as np
   from scipy.optimize import minimize

   # 目标函数
   def objective(x):
       return x[0]**2 + x[1]**2
   # 约束条件
   constraints = {'type': 'ineq', 'fun': lambda x: x[0] + x[1] - 1}
   # 求解
   result = minimize(objective, x0=np.array([0, 0]), constraints=constraints)
   print(result)
   ```

   这段代码使用Scipy库中的`minimize`函数求解非线性规划问题。

# 教育资源公平分配项目代码示例
import numpy as np
from scipy.optimize import linprog

schools = [
    {'name': '学校1', 'students': 200, 'max_students': 500, 'buildings': 800, 'teachers': 10},

result = linprog(c, A_ub=A, b_ub=b, method='highs')

2. **模型建立**：目标函数 `c` 是一个长度为学校数量的向量，每个元素代表学校的学生人数的权重。在这个例子中，我们假设所有学校的学生人数权重相同。
3. **求解**：使用 `linprog` 函数求解线性规划问题。`method='highs'` 指定了使用 `highs` 算法，这是一种高效的线性规划求解算法。
4. **结果分析**：如果求解成功，`result.x` 输出最优解，即每个学校的学生人数分配方案；`result.fun` 输出目标函数值，即教育效益的最大化值。如果求解失败，`result.message` 输出失败原因。

- **目标函数**：最大化教育效益，即每个学校的学生人数最大化。
- **约束条件**：每个学校的学生人数不能超过其最大容量。

4. **求解线性规划问题**：
