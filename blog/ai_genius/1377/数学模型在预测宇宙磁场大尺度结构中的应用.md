高斯定律是电磁学中一个基本的定理，它描述了电场和磁场在空间中的分布。高斯定律指出，对于一个闭合曲面，穿出该曲面的电通量总和等于该闭合曲面内部的总电荷量除以电常数。对于磁场，高斯定律同样适用，其表述为：

$$
\oint_{S} \mathbf{B} \cdot d\mathbf{A} = 0
$$

其中，$\mathbf{B}$ 表示磁场强度，$d\mathbf{A}$ 表示闭合曲面上的微小面积元素。这个方程表明，闭合曲面上的磁场通量总和为零，即磁场线是闭合的，不会从一个区域出发而不返回。

高斯定律在预测宇宙磁场大尺度结构中具有重要作用，因为它提供了磁场分布的基本约束条件。在实际应用中，高斯定律可以用于估计宇宙中磁场的总体分布，从而为其他更复杂的模型提供参考。

$$

from scipy.integrate import quad

# 高斯定律计算
def guass_law(B, r):
    S = 4 * np.pi * r**2
    flux = quad(lambda x: B * x[0]**2, 0, r)[0]
    B_intensity = flux / S
    return B_intensity

# 数据输入
r = 1000  # 设定半径
B = np.array([1, 0, 0])  # 设定磁场强度

# 计算磁场强度
B_intensity = guass_law(B, r)

# 可视化结果
plt.plot(r, B_intensity)
plt.xlabel('Radius (km)')
plt.ylabel('Magnetic Field Intensity (Tesla)')
plt.title('Gauss Law: Magnetic Field Intensity Distribution')
plt.show()
