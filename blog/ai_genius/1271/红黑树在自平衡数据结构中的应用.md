### 第2章：基础概念与原理

#### 2.1 自平衡数据结构概述

自平衡数据结构是一种特殊的树形数据结构，能够在插入、删除等操作后自动保持平衡，从而保证操作的时间复杂度接近O(logn)。这种数据结构通过特定的机制，确保树的高度始终保持在O(logn)的范围内，从而避免普通二叉搜索树可能出现的退化情况。

自平衡树的定义最早由Adelson-Velsky和Erlang在1970年代提出，他们定义了一类特殊的数据结构，称为AVL树。AVL树通过记录每个节点的平衡因子（节点的左子树高度与右子树高度的差值），并在每次插入或删除操作后调整节点的平衡因子，从而保持树的平衡。然而，AVL树的操作复杂度较高，每次旋转操作都会调整两个子树的高度差，导致在某些情况下性能不如红黑树。

除了AVL树，还有其他类型的自平衡树，如红黑树、伸展树（Splay Tree）和AVL树的变种等。每种自平衡树都有其独特的平衡机制和操作策略，适用于不同的应用场景。例如，红黑树通过限制节点的颜色和旋转操作，提高了树的平衡效率；伸展树通过将最近访问的节点移动到树的根部，提高了查找操作的效率。

自平衡树的应用场景非常广泛，包括数据库索引、缓存系统、哈希表实现、堆排序等。在数据库索引中，自平衡树常用于实现B树、B+树等索引结构，从而提高数据的查询效率；在缓存系统中，自平衡树可以实现LRU（最近最少使用）缓存算法，优化缓存空间的使用；在哈希表实现中，自平衡树可以用于解决哈希冲突，提高哈希表的查询性能；在堆排序中，自平衡树可以用于构建优先队列，优化排序算法的时间复杂度。

与普通二叉搜索树相比，自平衡树具有更好的性能和更高的灵活性。普通二叉搜索树在插入、删除等操作后可能会退化成链表，导致查询时间复杂度退化到O(n)。而自平衡树通过保持树的高度平衡，确保了操作的时间复杂度始终保持在O(logn)的范围内，从而提高了数据的查询效率。

#### 2.2 红黑树的基本概念

红黑树是一种常见的自平衡二叉搜索树，通过限制节点的颜色和旋转操作，保持树的高度平衡。红黑树的节点颜色包括红色和黑色，红色节点代表不平衡状态，黑色节点代表平衡状态。在红黑树中，每个节点都有特定的颜色属性，通过这些颜色属性和旋转操作，红黑树能够保持树的平衡。

红黑树的基本性质如下：

1. **根节点是黑色**：根节点是黑色的，用于标记树的根节点为平衡状态。

2. **每个叶子节点（NIL节点）是黑色**：在红黑树中，NIL节点（表示空节点）都是黑色的，用于简化树的操作和保持树的平衡。

3. **每个红色节点的两个子节点都是黑色或都是红色**：红色节点代表不平衡状态，其两个子节点要么都是红色，要么都是黑色，从而避免连续的红色节点造成的树的高度不平衡。

4. **从任一节点到其每个叶子的所有路径都包含相同数目的黑色节点**：红黑树通过这个性质保证了树的平衡性。这个性质要求任意一条从根节点到叶子节点的路径上，黑色节点的数量相同，从而确保树的高度平衡。

红黑树的节点结构通常包括以下属性：

- **数据**：存储节点的实际数据。
- **左右子节点**：指向左右子节点的指针。
- **父节点**：指向父节点的指针。
- **颜色**：节点的颜色属性，可以是红色或黑色。

在红黑树中，插入和删除操作可能会破坏树的平衡性，导致树的高度不平衡。为了恢复树的平衡，红黑树使用特定的旋转操作。旋转操作包括左旋转和右旋转，通过这些旋转操作，红黑树能够保持树的高度平衡。

左旋转和右旋转的具体操作如下：

- **左旋转**：当节点的右子节点是红色时，进行左旋转操作，将右子节点作为新的根节点，同时更新相关节点的颜色。
- **右旋转**：当节点的左子节点是红色时，进行右旋转操作，将左子节点作为新的根节点，同时更新相关节点的颜色。

通过左旋转和右旋转操作，红黑树能够保持树的高度平衡，从而保证操作的时间复杂度为O(logn)。红黑树的旋转操作是红黑树的核心机制，通过旋转操作，红黑树能够快速恢复树的平衡状态，确保操作的高效性和稳定性。

#### 2.3 红黑树的旋转操作

红黑树通过旋转操作保持树的高度平衡，旋转操作包括左旋转和右旋转。左旋转和右旋转分别用于调整节点的位置和颜色，以恢复树的平衡状态。

**左旋转**：
当节点的右子节点是红色时，需要进行左旋转操作。左旋转的具体步骤如下：

1. **确定旋转轴**：以当前节点（假设为节点x）作为旋转轴。
2. **进行旋转**：将节点x的右子节点（假设为节点y）作为新的根节点，节点y的左子节点作为节点x的新右子节点，节点x的新左子节点作为节点y的新左子节点。
3. **更新节点颜色**：将节点x的颜色更新为红色，将节点y的颜色更新为黑色。

左旋转的效果是将节点x和节点y交换位置，同时调整它们的颜色，以保持树的高度平衡。

**右旋转**：
当节点的左子节点是红色时，需要进行右旋转操作。右旋转的具体步骤如下：

1. **确定旋转轴**：以当前节点（假设为节点x）作为旋转轴。
2. **进行旋转**：将节点x的左子节点（假设为节点y）作为新的根节点，节点y的右子节点作为节点x的新左子节点，节点x的新右子节点作为节点y的新右子节点。
3. **更新节点颜色**：将节点x的颜色更新为红色，将节点y的颜色更新为黑色。

右旋转的效果是将节点x和节点y交换位置，同时调整它们的颜色，以保持树的高度平衡。

### 第3章：红黑树操作

#### 3.1 红黑树的插入操作

红黑树的插入操作是在二叉搜索树的基础上进行的，当新节点插入后，可能破坏树的平衡性。因此，我们需要通过旋转操作来恢复树的平衡。

**插入操作流程**：

1. **插入节点**：首先，将新节点插入到树中，根据二叉搜索树的规则，找到合适的位置进行插入。

2. **恢复平衡**：插入新节点后，需要检查新节点的父节点和祖父节点的颜色，并根据颜色情况执行相应的旋转操作，以恢复树的平衡。

以下是红黑树插入操作的具体步骤：

1. **将新节点设置为红色**：在插入新节点时，将其颜色设置为红色。

2. **检查插入后的树是否平衡**：从新节点开始，向上检查父节点和祖父节点的颜色。

   - 如果父节点和祖父节点的颜色都是红色，说明树出现了“两个红色节点连续”的情况，需要进行旋转操作。

   - 如果父节点是红色，祖父节点的左子节点是红色，说明树出现了“左-左情况”，需要进行右旋转操作。

   - 如果父节点是红色，祖父节点的右子节点是红色，说明树出现了“右-右情况”，需要进行左旋转操作。

   - 如果父节点是红色，祖父节点的左子节点是红色，且祖父节点的左子节点的左子节点是红色，说明树出现了“左-左-左情况”，需要进行两次右旋转操作。

   - 如果父节点是红色，祖父节点的左子节点是红色，且祖父节点的左子节点的右子节点是红色，说明树出现了“左-左-右情况”，需要进行一次右旋转和一次左旋转操作。

3. **更新节点颜色**：在旋转操作后，需要更新相关节点的颜色，确保树的平衡性。

以下是红黑树插入操作的Python源代码实现：

```python
class Node:
    def __init__(self, data, color="red"):
        self.data = data
        self.color = color
        self.left = None
        self.right = None
        self.parent = None

class RedBlackTree:
    def __init__(self):
        self.root = None

    def insert(self, data):
        node = Node(data)
        if not self.root:
            self.root = node
            node.color = "black"
        else:
            parent = None
            current = self.root
            while current:
                parent = current
                if data < current.data:
                    current = current.left
                else:
                    current = current.right
            node.parent = parent
            if data < parent.data:
                parent.left = node
            else:
                parent.right = node
            self.fix_insert(node)

    def fix_insert(self, node):
        while node != self.root and node.parent.color == "red":
            if node.parent == node.parent.parent.left:
                uncle = node.parent.parent.right
                if uncle and uncle.color == "red":
                    node.parent.color = "black"
                    uncle.color = "black"
                    node.parent.parent.color = "red"
                    node = node.parent.parent
                else:
                    if node == node.parent.right:
                        node = node.parent
                        self.left_rotate(node)
                    node.parent.color = "black"
                    node.parent.parent.color = "red"
                    self.right_rotate(node.parent.parent)
            else:
                uncle = node.parent.parent.left
                if uncle and uncle.color == "red":
                    node.parent.color = "black"
                    uncle.color = "black"
                    node.parent.parent.color = "red"
                    node = node.parent.parent
                else:
                    if node == node.parent.left:
                        node = node.parent
                        self.right_rotate(node)
                    node.parent.color = "black"
                    node.parent.parent.color = "red"
                    self.left_rotate(node.parent.parent)
        self.root.color = "black"
```

上述代码实现了红黑树的插入操作，包括节点的插入和平衡恢复过程。通过旋转操作和节点颜色的更新，红黑树能够保持树的平衡状态。

#### 3.2 红黑树的删除操作

红黑树的删除操作也是基于二叉搜索树进行的，当删除节点后，可能破坏树的平衡性，因此需要通过旋转操作和颜色更新来恢复树的平衡。

**删除操作流程**：

1. **删除节点**：首先，根据节点的值找到待删除的节点，将其从树中删除。

2. **替换节点**：如果待删除节点有子节点，需要找到待删除节点的后继节点（即待删除节点的右子树中的最小节点），将待删除节点的值替换为后继节点的值，并将后继节点从其原位置删除。

3. **恢复平衡**：删除节点后，需要检查删除节点的父节点和祖父节点的颜色，并根据颜色情况执行相应的旋转操作，以恢复树的平衡。

红黑树的空间复杂度主要与树的高度和节点数量有关。由于红黑树的平衡特性，树的高度始终保持在O(logn)的范围内，因此红黑树的空间复杂度可以通过以下公式计算：

n ≈ 2^(h+1) - 1

空间复杂度 ≈ 2^(h+1) - 1 * c

空间复杂度 ≈ 2^(logn+1) - 1 * c ≈ n * c

因此，红黑树的空间复杂度主要取决于节点的大小，通常在O(n)的范围内。

        y.left = x.right
        if x.right:
            x.right.parent = y
        x.parent = y.parent
        if not y.parent:
            self.root = x
        elif y == y.parent.right:
            y.parent.right = x
        else:
            y.parent.left = x
        x.right = y
        y.parent = x

    def search(self, key):
        return self._search(self.root, key)

    def _search(self, node, key):
        if node is None:
            return None
        if key == node.key:
            return node.value
        elif key < node.key:
            return self._search(node.left, key)
        else:
            return self._search(node.right, key)

rb_tree.insert(40, "Value 40")
