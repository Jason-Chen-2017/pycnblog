```python
class StockTrade:
    def __init__(self, symbol, amount):
        self.symbol = symbol
        self.amount = amount

class StockExchange:
    def __init__(self):
        self.trades = []

    def buy_stock(self, trade):
        if trade.amount > 0:
            self.trades.append(trade)
            print("Stock purchased successfully.")
        else:
            print("Invalid amount for purchase.")

    def sell_stock(self, trade):
        if trade.amount > 0:
            for i, trade_in_list in enumerate(self.trades):
                if trade_in_list.symbol == trade.symbol and trade_in_list.amount >= trade.amount:
                    self.trades[i] = StockTrade(trade.symbol, trade_in_list.amount - trade.amount)
                    print("Stock sold successfully.")
                    return
            print("Insufficient stock to sell.")
```

在这个代码中，我们定义了`StockTrade`类来表示一次交易，以及`StockExchange`类来表示股票交易所。`StockExchange`类中有`buy_stock`和`sell_stock`方法，用于执行购买和卖出操作。

3. **验证结果输出**：
   - 根据语义分析的结果，输出验证结果。如果购买或卖出操作成功，则输出成功信息；如果操作失败，则输出错误信息。
