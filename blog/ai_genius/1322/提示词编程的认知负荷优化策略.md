### 3.4 Python 代码与详细解释

以下是一个完整的 Python 提示词编程实现，包括提示词生成、匹配和执行：

```python
# 提示词生成
def generate_prompt(task):
    return f"执行{task}操作"

# 提示词匹配
def match_prompt(prompt, task):
    return prompt == task

# 编程任务执行
def execute_task(task):
    if match_prompt("计算两个数之和", task):
        a, b = map(int, input("请输入两个数，用空格分隔：").split())
        return a + b
    else:
        raise ValueError("未匹配到有效提示词")

# 主程序
if __name__ == "__main__":
    task = input("请输入要执行的任务：")
    prompt = generate_prompt(task)
    print("生成的提示词：", prompt)
    result = execute_task(task)
    print(f"执行结果：{result}")
```
