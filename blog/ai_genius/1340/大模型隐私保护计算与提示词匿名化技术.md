### 1.4 大模型隐私保护的策略

#### 数据加密

数据加密是保护数据隐私的重要手段，主要包括以下类型：

- **对称加密**：使用相同的密钥进行加密和解密，如AES。
- **非对称加密**：使用一对公钥和私钥进行加密和解密，如RSA。
- **哈希加密**：通过哈希函数将数据转换为固定长度的字符串，如SHA-256。

#### 数据脱敏

数据脱敏是一种通过修改数据的方式，使数据无法直接识别或关联到真实个体，主要包括以下方法：

- **掩码**：将敏感数据替换为特定的掩码字符，如将姓名替换为XXX。
- **随机化**：将敏感数据替换为随机生成的数据，如将电话号码替换为假号码。
- **扰动**：对敏感数据进行数学运算，如添加噪声或进行四舍五入。

#### 隐私保护算法

隐私保护算法是保护数据隐私的核心技术，主要包括以下类型：

- **差分隐私**：通过在输出中加入随机噪声，确保单个记录的隐私，如Laplace机制和Gaussian机制。
- **同态加密**：允许在加密数据上进行计算，从而避免解密数据的需要，如全同态加密和部分同态加密。
- **安全多方计算**：允许多个参与方共同计算结果，而无需透露各自的私有数据，如安全多方计算协议和安全多方机器学习。
- **联邦学习**：通过分布式训练，将数据分散在多个设备或服务器上，从而降低数据泄露的风险。

def encrypt_prompt(prompt, key):
    f = Fernet(key)
    encrypted_prompt = f.encrypt(prompt.encode())
    return encrypted_prompt

def anonymize_prompt(prompt):

    key = Fernet.generate_key()
    
    # 加密提示词
    encrypted_prompt = encrypt_prompt(prompt, key)
