```python
def process_keyword(keyword):
    # 解析提示词并执行相应操作
    if keyword == "add":
        return 1 + 1
    elif keyword == "subtract":
        return 1 - 1
    else:
        raise ValueError("Invalid keyword")

try:
    # 获取用户输入
    user_input = input("Enter a keyword (add or subtract): ")
    # 执行操作并记录结果
    result = process_keyword(user_input)
    print(f"The result is: {result}")
except ValueError as e:
    # 错误诊断并输出
    print(f"Error: {e}")
```

在这个代码示例中，我们定义了一个名为`process_keyword`的函数，用于处理用户输入的提示词。函数根据不同的提示词执行相应的操作，如加法或减法。我们通过`try-except`语句来捕获和处理可能的异常，确保程序的健壮性。

```python
# core.py

def parse_keyword(keyword):
    operations = {
        'add': lambda x, y: x + y,
        'subtract': lambda x, y: x - y,
        'multiply': lambda x, y: x * y,
    }
    return operations.get(keyword)

def execute_operation(operator, x, y):
    if operator:
        return operator(x, y)
    else:
        raise ValueError("Invalid operator")

def main():
    x = float(input("Enter the first number: "))
    y = float(input("Enter the second number: "))
    keyword = input("Enter a keyword (add, subtract, multiply): ")

    operator = parse_keyword(keyword)
    try:
        result = execute_operation(operator, x, y)
        print(f"The result is: {result}")
    except ValueError as e:
        print(f"Error: {e}")

if __name__ == "__main__":
    main()
```

在这个示例中，我们定义了三个核心函数：`parse_keyword` 用于解析用户输入的提示词，`execute_operation` 用于执行相应的操作，而 `main` 函数则负责整个程序的运行流程。
