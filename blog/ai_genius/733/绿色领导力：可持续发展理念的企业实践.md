### 1.1 可持续发展的概念与背景

可持续发展是一种旨在满足当前需求而不损害后代满足其需求的能力的发展模式。这一概念最早在1987年的《我们共同的未来》报告中提出，随后被广泛接受并应用于各个领域。在企业层面，可持续发展不仅关乎环境，还涉及经济、社会等多个方面。

随着全球环境问题的日益严峻，企业面临的环境和社会责任压力不断增加。绿色领导力作为可持续发展的重要组成部分，逐渐成为企业管理者和决策者关注的焦点。绿色领导力强调企业领导者在推动绿色管理、绿色战略和绿色文化等方面的作用，旨在实现企业的长期可持续发展。

绿色领导力的核心要素包括以下几个方面：

2. **绿色战略**：企业将可持续发展理念融入战略规划，确保在追求经济效益的同时，关注环境和社会责任。

绿色领导力要求企业领导者在战略层面进行创新，将绿色理念贯穿于企业的各个层面，从而实现企业的可持续发展。

def get_system_usage():
    # 获取系统CPU、内存、存储和网络的实时使用情况
    cpu_usage = os.popen("top -b -n 1 | grep 'Cpu(s)' | awk '{print $2 + $4}'").readline()
    memory_usage = os.popen("free -m | grep 'Mem' | awk '{print $3/$2 * 100}'").readline()
    disk_usage = os.popen("df -H | grep '/$' | awk '{print $5}'").readline()
    network_usage = os.popen("ip link | grep 'ether' | awk '{print $9,$11}'").readline()
    
    return cpu_usage, memory_usage, disk_usage, network_usage

def log_usage(usage):
    # 将系统使用情况记录到日志文件
    with open("system_usage.log", "a") as log_file:
        log_file.write(f"{usage}\n")

def main():
    while True:
        usage = get_system_usage()
        log_usage(usage)
        time.sleep(60)  # 每60秒记录一次系统使用情况

if __name__ == "__main__":
