- **Core Algorithm Principles:**
  The carrier sense multiple access with collision detection (CSMA/CD) protocol is used in local area networks (LANs) to manage data transmission.

  ```python
  # Python code to simulate CSMA/CD
  import random

  def csma_cd(frame, channel):
      if channel.is_idle():
          channel.start_frame_transmission(frame)
      else:
          wait_time = random.uniform(0, 2)  # Random backoff time
          time.sleep(wait_time)
          csma_cd(frame, channel)

  class Channel:
      def __init__(self):
          self.is_idle = True

      def start_frame_transmission(self, frame):
          self.is_idle = False
          print(f"Transmitting frame: {frame}")
          time.sleep(1)
          self.is_idle = True
          print("Channel is now idle.")

  channel = Channel()
  csma_cd("Frame 1", channel)
  ```

- **Mathematical Models and Formulas:**
  The mathematical model for CSMA/CD can be expressed as:

  $$  
  P_{success} = \frac{1}{1 + \sum_{i=1}^{N} P_{i}}, \quad \text{where} P_{i} = \frac{S}{1 - S} \left(1 - \frac{1}{N}\right)^{i-1}, \quad \text{and} S = \frac{\lambda}{1 - \lambda} \quad \text{is the traffic intensity}.  
  $$

  Where \( \lambda \) is the average arrival rate of frames, and \( N \) is the number of devices attempting to transmit.

- **Core Algorithm Principles:**
  PID (Proportional-Integral-Derivative) control is a common algorithm used for actuator control. Python code for a PID controller:

  ```python
  import numpy as np

  class PIDController:
      def __init__(self, Kp, Ki, Kd):
          self.Kp = Kp
          self.Ki = Ki
          self.Kd = Kd
          self.error_integral = 0
          self.error_derivative = 0

      def update(self, setpoint, current_value):
          error = setpoint - current_value
          self.error_integral += error
          self.error_derivative = error - self.previous_error
          output = (self.Kp * error) + (self.Ki * self.error_integral) + (self.Kd * self.error_derivative)
          self.previous_error = error
          return output

  controller = PIDController(Kp=1, Ki=0.1, Kd=0.05)
  setpoint = 100
  current_value = 90
  output = controller.update(setpoint, current_value)
  print(f"Control output: {output}")
  ```

- **Mathematical Models and Formulas:**
  The PID controller output can be expressed as:

  $$  
  \text{Output} = K_p \times (\text{Error}) + K_i \times (\text{Error Integral}) + K_d \times (\text{Error Derivative})  
  $$

  Where \( K_p \), \( K_i \), and \( K_d \) are the proportional, integral, and derivative constants, respectively.

  ```python

      return data_rate * distance * (1 + alpha) / (2 * (1 - alpha))
  ```

- **Mathematical Models and Formulas:**
  The coverage probability in a WSN can be modeled using the probability that a sensor node's signal reaches a data fusion center:

  $$  
  P_c = 1 - F_c(d_c), \quad \text{where} F_c(d_c) \text{is the cumulative distribution function of the distance between a sensor node and the data fusion center}.  
  $$

  Assuming a uniform distribution for distances, \( F_c(d_c) \) can be expressed as:

  $$  
  F_c(d_c) = 1 - \left(1 - \frac{d_c}{R}\right)^n, \quad \text{where} R \text{is the communication range and} n \text{is the number of sensor nodes}.  
  $$

  ```python
  from Crypto.Cipher import AES
  from Crypto.Util.Padding import pad, unpad
  from Crypto.Random import get_random_bytes

  key = get_random_bytes(16)
  cipher = AES.new(key, AES.MODE_CBC)
  plaintext = b"Hello, World!"
  ciphertext = cipher.encrypt(pad(plaintext, AES.block_size))

  print(f"Key: {key.hex()}")
  print(f"Ciphertext: {ciphertext.hex()}")

  cipher = AES.new(key, AES.MODE_CBC, cipher.iv)

  print(f"Decrypted Text: {decrypted_text}")
  ```

- **Mathematical Models and Formulas:**
  The AES encryption algorithm operates on blocks of data using a symmetric key. The mathematical model for AES can be expressed using the following steps:

  1. **Key Expansion:** Generate round keys from the original key using a key schedule.
  2. **Initialization:** Initialize the state with the plaintext and the initial round key.
  3. **Encryption Rounds:** Perform a series of transformations on the state, including byte substitution, row shifting, and column mixing, using the round keys.
  4. **Finalization:** Perform an additional round of transformations, followed by byte inversion.

#### 5.2 Digital Signature Models

- **Background Introduction:**
  Digital signatures provide a way to verify the authenticity and integrity of IoT data. They ensure that data has not been tampered with and originated from a specific sender.

- **Core Concepts and Connections:**
  A Mermaid flowchart can illustrate the process of creating and verifying digital signatures, including message hashing, signature generation, and signature verification.

  ```mermaid
  graph TD
    A[Hash Message] --> B[Sign Message]
    B --> C[Verify Signature]
  ```

- **Core Algorithm Principles:**
  The RSA algorithm is commonly used for generating and verifying digital signatures.

  ```python
  from Crypto.PublicKey import RSA
  from Crypto.Signature import pkcs1_15
  from Crypto.Hash import SHA256

  key = RSA.generate(2048)
  private_key = key.export_key()
  public_key = key.publickey().export_key()

  message = b"Hello, World!"
  h = SHA256.new(message)
  signature = pkcs1_15.new(key).sign(h)

  print(f"Public Key: {public_key}")
  print(f"Signature: {signature.hex()}")

  h = SHA256.new(message)
  pkcs1_15.new(RSA.import_key(public_key)).verify(h, signature)
  print("Signature is valid.")
  ```

- **Mathematical Models and Formulas:**
  The RSA signature scheme involves the following steps:

  1. **Key Generation:** Generate a pair of keys (public and private) based on large prime numbers.
  2. **Message Hashing:** Hash the message using a secure hash function.
  3. **Signature Generation:** Compute the signature using the private key and the hash value.
  4. **Signature Verification:** Verify the signature using the public key and the hash value.

- **PID控制器实现：**

  ```python
  import numpy as np

  class PIDController:
      def __init__(self, Kp, Ki, Kd):
          self.Kp = Kp
          self.Ki = Ki
          self.Kd = Kd
          self.error_integral = 0
          self.error_derivative = 0

      def update(self, setpoint, current_value):
          error = setpoint - current_value
          self.error_integral += error
          self.error_derivative = error - self.previous_error
          output = (self.Kp * error) + (self.Ki * self.error_integral) + (self.Kd * self.error_derivative)
          self.previous_error = error
          return output

  controller = PIDController(Kp=1, Ki=0.1, Kd=0.05)
  setpoint = 100
  current_value = 90
  output = controller.update(setpoint, current_value)
  print(f"Control output: {output}")
  ```
