## 第一部分：经典物理学基础

### 第1章 经典力学

经典力学是物理学的基础，它主要研究物体的运动和力的作用。牛顿运动定律是经典力学的核心，描述了物体在力的作用下的运动状态。

#### 牛顿第一定律

牛顿第一定律，又称惯性定律，指出一个物体如果没有受到外力的作用，它将保持静止状态或匀速直线运动。

伪代码：
```python
if 力为零:
    if 物体静止:
        物体保持静止
    else:
        物体保持匀速直线运动
```

#### 牛顿第二定律

牛顿第二定律描述了力和加速度之间的关系，公式为 F = ma，其中 F 是力，m 是质量，a 是加速度。

伪代码：
```python
力 F = 质量 m * 加速度 a
```

#### 牛顿第三定律

牛顿第三定律指出，对于每一个作用力，都有一个大小相等、方向相反的反作用力。

伪代码：
```python
if 有作用力 F:
    存在反作用力 -F
```

### 第2章 经典电磁学

经典电磁学主要研究电磁场和电磁波的传播。麦克斯韦方程组是经典电磁学的核心，描述了电场和磁场的分布和变化。

#### 麦克斯韦方程组

麦克斯韦方程组包括四个方程，分别描述了电场的旋度和散度、磁场的旋度和散度。

```latex
\nabla \cdot \mathbf{E} = \frac{\rho}{\varepsilon_0}
\nabla \cdot \mathbf{B} = 0
\nabla \times \mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}
\nabla \times \mathbf{B} = \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \frac{\partial \mathbf{E}}{\partial t}
```

#### 电磁波

电磁波是电场和磁场交替变化而产生的波动。其传播速度等于光速 c。

伪代码：
```python
电磁波速度 c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}}
```

#### 光的波动性

光的波动性可以通过干涉和衍射现象来证明。这些现象都符合波动理论。

伪代码：
```python
if 光通过双缝:
    干涉现象发生
if 光经过狭缝:
    衍射现象发生
```

### 第3章 经典热力学

内能变化 ΔU = 吸收的热量 Q - 做的功 W

## 第二部分：相对论与量子力学

### 第4章 相对论

相对论是由爱因斯坦提出的一种物理学理论，它颠覆了经典力学的基本假设，提出了时间和空间的相对性。

#### 狭义相对论

狭义相对论主要研究了在恒定参考系中，时间和空间的变化。其核心公式是洛伦兹变换。

$$
x' = \gamma (x - vt)
$$

$$
t' = \gamma \left(t - \frac{vx}{c^2}\right)
$$

其中，$x'$ 和 $t'$ 是相对论时间，$x$ 和 $t$ 是经典时间，$v$ 是相对速度，$c$ 是光速，$\gamma$ 是洛伦兹因子。

伪代码：
```python
洛伦兹因子 γ = 1 / sqrt(1 - v^2 / c^2)
```

#### 广义相对论

广义相对论是狭义相对论的扩展，它研究了非惯性参考系中的物理现象。其核心是引力场的几何描述，即物质和能量会影响时空的几何结构。

伪代码：
```python
时空弯曲 = 物质和能量
```

### 第5章 量子力学

量子力学是研究微观粒子的行为和相互作用的理论。它提出了波粒二象性、不确定性原理和量子纠缠等概念。

#### 波函数与薛定谔方程

波函数是量子力学中描述粒子状态的数学函数，其演化由薛定谔方程描述。

$$
i\hbar \frac{\partial \Psi}{\partial t} = \hat{H} \Psi
$$

其中，$i$ 是虚数单位，$\hbar$ 是约化普朗克常数，$\Psi$ 是波函数，$\hat{H}$ 是哈密顿算符。

伪代码：
```python
波函数演化：Psi_new = e^(-i * H * Δt / hbar) * Psi_old
```
