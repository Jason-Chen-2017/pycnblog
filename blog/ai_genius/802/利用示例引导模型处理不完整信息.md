### 1.1 示例引导模型的基本概念

示例引导模型（Example-Guided Model）是一种基于示例学习的机器学习模型。其核心思想是通过从示例中学习规律，从而对新的、未知的信息进行推理和预测。示例引导模型广泛应用于自然语言处理、计算机视觉、数据挖掘等领域，尤其在处理信息不完整的情况下具有显著优势。

1. **监督学习中的示例引导模型**：此类模型在训练阶段需要大量已标记的示例，通过这些示例学习得到模型参数。常见的监督学习示例引导模型包括决策树、支持向量机等。

2. **无监督学习中的示例引导模型**：此类模型在训练阶段无需已标记的示例，而是通过无监督学习方式从数据中发现规律。常见的无监督学习示例引导模型包括聚类算法、自编码器等。

### 1.3 示例引导模型的应用领域

```python
from sklearn.feature_extraction.text import CountVectorizer

# 示例数据
texts = ["我很高兴", "我很不开心", "这是一个好日子", "这是一个糟糕的天气"]

# 模型训练

model.fit(X, labels)

# 预测
text = "我很开心"

prediction = model.predict(X_new)
print(prediction)  # 输出预测结果
```
