**Step 3: Fundamental Cryptographic Algorithms**

Cryptography relies on various algorithms to ensure secure communication. Two main types of algorithms are used: symmetric-key algorithms and asymmetric-key algorithms.

**Symmetric-Key Algorithms:**
These algorithms use the same key for both encryption and decryption. The security of these systems is based on the secrecy of the key. Examples include:

- **Data Encryption Standard (DES):** A block cipher developed by IBM in the 1970s.
- **Advanced Encryption Standard (AES):** A more secure successor to DES, adopted by the U.S. government in 2001.
- **International Data Encryption Algorithm (IDEA):** A symmetric-key block cipher designed in 1991.

**Asymmetric-Key Algorithms:**
These algorithms use a pair of keys: a public key for encryption and a private key for decryption. They are based on complex mathematical problems. Examples include:

- **RSA:** One of the most widely used public-key cryptosystems.
- **Diffie-Hellman Key Exchange:** A method for secure communication over an untrusted channel.
- **ElGamal Encryption:** A public-key cryptosystem based on the Diffie-Hellman problem.

**Example: RSA Algorithm**

The RSA algorithm is one of the fundamental asymmetric-key cryptosystems. Here is a simple Python code snippet to illustrate the basic steps:

```python
from math import gcd
from sympy import isprime

def compute_e(n):
    e = 2
    while gcd(e, n) != 1:
        e += 1
    return e

def compute_d(e, n):
    d = 1
    for i in range(1, n):
        if ((e * i) % n) == 1:
            d = i
            break
    return d

def rsa_encrypt(plaintext, e, n):
    ciphertext = [(ord(char) ** e) % n for char in plaintext]
    return ciphertext

def rsa_decrypt(ciphertext, d, n):
    plaintext = [chr((char ** d) % n) for char in ciphertext]
    return ''.join(plaintext)

# Example usage
n = 61  # A prime number
e = compute_e(n)
print("Public key:", e, n)
d = compute_d(e, n)
print("Private key:", d)

plaintext = "hello"
ciphertext = rsa_encrypt(plaintext, e, n)
print("Ciphertext:", ciphertext)

decrypted_text = rsa_decrypt(ciphertext, d, n)
print("Decrypted text:", decrypted_text)
```

**Step 4: Cryptographic Analysis Techniques**

Cryptographic systems are not immune to attacks. Various techniques are used to analyze and potentially break cryptographic systems. These techniques can be categorized into several types:

- **Statistical Analysis:** Uses patterns in ciphertext to infer information about the plaintext or the encryption key.
- **Brute Force Attack:** Attempts all possible keys until the correct one is found.
- **Cryptographic distinguisher attacks:** Techniques that distinguish between different cryptographic primitives or their instances.
- **Man-in-the-Middle Attack:** An attack where an unauthorized party intercepts and possibly alters communications between two parties who believe they are directly communicating with each other.

**Example: Statistical Analysis**

Consider the following statistical attack on a simple substitution cipher:

```python
from collections import Counter
from string import ascii_lowercase

def letter_frequencies(text):
    text = text.lower()
    return Counter(c for c in text if c in ascii_lowercase)

def guess_keyspace(frequencies):
    most_common = frequencies.most_common(1)[0][0]
    least_common = frequencies.most_common()[-1][0]
    return {most_common: least_common, least_common: most_common}

plaintext = "The quick brown fox jumps over the lazy dog"
frequencies = letter_frequencies(plaintext)

keyspace_guess = guess_keyspace(frequencies)
print(keyspace_guess)
```

**Example: Digital Signature**

A simple digital signature can be created using RSA encryption:

```python
import hashlib
from Cryptodome.PublicKey import RSA
from Cryptodome.Signature import pkcs1_15
from Cryptodome.Random import get_random_bytes

# Generate keys
key = RSA.generate(2048)
private_key = key.export_key()
public_key = key.publickey().export_key()

# Create a message
message = b"Hello, world!"

# Hash the message
hash_object = hashlib.sha256(message)
digest = hash_object.digest()

# Sign the message
signature = pkcs1_15.new(public_key).sign(digest)

# Verify the message
is_valid = pkcs1_15.new(key).verify(digest, signature)
print("Signature is valid:", is_valid)
```
