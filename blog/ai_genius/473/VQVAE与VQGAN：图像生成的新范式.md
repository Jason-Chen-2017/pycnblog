### 第一部分：基础知识与原理

#### 第1章：VQVAE与VQGAN概述

##### 1.1 图像生成技术简介

**传统图像生成方法**

在传统图像处理中，图像生成主要依赖于规则方法和频率分析方法。规则方法包括基于几何变换、模板匹配和图像合成等技术。频率分析方法如傅里叶变换和小波变换则用于图像的频率域处理。然而，这些方法在复杂图像生成任务中存在明显的局限性，难以产生高质量且多样化的图像。

**图像生成的重要性**

随着深度学习技术的发展，图像生成成为计算机视觉领域的重要研究方向。图像生成技术不仅在艺术创作、图像修复和增强等任务中具有广泛应用，还在数据增强、虚拟现实和增强现实等领域展现出巨大的潜力。

**VQVAE与VQGAN的核心地位**

VQVAE与VQGAN作为深度学习领域的新兴算法，因其独特的架构和高效的图像生成能力，成为当前图像生成技术的研究热点。VQVAE基于自动编码器结构，通过量化变量实现图像的编码与重构。而VQGAN则结合了生成对抗网络（GAN）的思想，通过对抗训练生成高质量图像。

##### 1.2 VQVAE原理详解

**VQVAE概念与背景**

VQVAE（Vector Quantized Variational Autoencoder）是一种基于自动编码器的图像生成模型。它通过将编码过程中的连续变量量化为离散变量，以降低模型复杂度，提高训练效率。

**VQVAE模型结构**

VQVAE模型主要由编码器、量化器和解码器组成。编码器将输入图像映射到潜空间，量化器将潜空间中的连续变量量化为离散向量，解码器则将量化后的向量重构为图像。

**VQVAE训练过程**

VQVAE的训练过程包括编码器和解码器的训练，以及量化器的优化。在训练过程中，通过最小化重建损失和量化损失，模型能够学习到图像的潜在特征。

##### 1.3 VQGAN原理详解

**VQGAN概念与背景**

VQGAN（Vector Quantized Generative Adversarial Network）是一种结合了生成对抗网络（GAN）和VQVAE思想的图像生成模型。它通过对抗训练生成高质量的图像，并在生成过程中引入量化机制。

**VQGAN模型结构**

VQGAN模型由生成器、判别器和量化器组成。生成器生成图像，判别器判断图像的真实性，量化器对生成图像进行量化处理。

**VQGAN训练过程**

VQGAN的训练过程涉及生成器、判别器和量化器的联合训练。通过对抗训练，生成器不断优化生成图像的质量，判别器则提高对真实图像和生成图像的鉴别能力。

##### 1.4 VQVAE与VQGAN联系与区别

**相似性**

VQVAE与VQGAN均采用量化技术，以降低模型复杂度和提高训练效率。两者都基于自动编码器和生成对抗网络的思想，通过对抗训练实现图像的生成。

**区别**

尽管VQVAE与VQGAN具有相似性，但它们的实现方式和应用场景有所不同。VQVAE更适用于图像重构任务，而VQGAN则更擅长生成多样化且高质量的图像。

**综合评价**

VQVAE与VQGAN在图像生成领域表现出强大的潜力。VQVAE通过量化技术提高训练效率，适用于多种图像处理任务；VQGAN则通过对抗训练生成高质量图像，在艺术创作和生成任务中具有广泛应用。

##### 2.2 VQVAE算法流程

**编码器与解码器工作流程**

**去噪自动编码器（DNVAE）原理**

VQVAE中的去噪自动编码器（DNVAE）通过添加噪声扰动，提高模型的鲁棒性。DNVAE的编码器和解码器分别用于提取和重构图像特征。

**VQVAE训练伪代码**

```
# 初始化模型参数
初始化编码器、量化器和解码器参数

# 训练过程
for epoch in range(num_epochs):
    for image in data_loader:
        # 前向传播
        latent_code = encoder(image)
        quantized_code = quantizer(latent_code)
        reconstructed_image = decoder(quantized_code)

        # 计算损失函数
        reconstruction_loss = compute_reconstruction_loss(image, reconstructed_image)
        quantization_loss = compute_quantization_loss(latent_code, quantized_code)

        # 反向传播
        optimizer.zero_grad()
        loss = reconstruction_loss + quantization_loss
        loss.backward()
        optimizer.step()
```

##### 2.3 VQVAE数学模型

**模型损失函数**

VQVAE的损失函数通常包括重建损失和量化损失。重建损失用于衡量重构图像与原始图像之间的差异，量化损失用于衡量量化后的向量与原始潜空间特征之间的差异。

**模型优化算法**

VQVAE的训练过程采用基于梯度的优化算法，如Adam或SGD。通过最小化损失函数，模型能够学习到图像的潜在特征。

**数学公式与推导**

假设输入图像为 \( x \)，编码器输出的潜空间特征为 \( z \)，量化后的向量为 \( q \)，重构图像为 \( x' \)。则VQVAE的损失函数可以表示为：

\[ L = L_{\text{reconstruction}} + L_{\text{quantization}} \]

其中，重建损失 \( L_{\text{reconstruction}} \) 可以表示为：

\[ L_{\text{reconstruction}} = \frac{1}{N} \sum_{i=1}^{N} \sum_{j=1}^{C} \sum_{k=1}^{K} \mathcal{L}_{\text{KL}}(\mu_{jk} || \mu_{i} / \sigma_{i}^2) \]

量化损失 \( L_{\text{quantization}} \) 可以表示为：

\[ L_{\text{quantization}} = \frac{1}{N} \sum_{i=1}^{N} \sum_{j=1}^{C} \sum_{k=1}^{K} \mathcal{L}_{\text{KL}}(\log \sigma_{ik}^2 || \log \sigma_{i}^2) \]

其中，\( \mathcal{L}_{\text{KL}} \) 表示KL散度。

##### 3.2 VQGAN算法流程

**生成器与判别器工作流程**

生成器从潜空间生成图像，判别器则对生成的图像和真实图像进行鉴别。通过对抗训练，生成器不断优化生成图像的质量，判别器则提高对真实图像和生成图像的鉴别能力。

**条件生成对抗网络（cGAN）原理**

VQGAN采用条件生成对抗网络（cGAN）的结构，通过条件输入生成特定类别的图像。cGAN的生成器和判别器分别对图像内容和条件输入进行建模。

**VQGAN训练伪代码**

```
# 初始化模型参数
初始化生成器、判别器、量化器参数

# 训练过程
for epoch in range(num_epochs):
    for image, label in data_loader:
        # 前向传播
        generated_image = generator(z, label)
        real_image = discriminator(image, label)
        fake_image = discriminator(generated_image, label)

        # 计算损失函数
        generator_loss = compute_generator_loss(fake_image)
        discriminator_loss = compute_discriminator_loss(real_image, fake_image)

        # 反向传播
        optimizer.zero_grad()
        loss = generator_loss + discriminator_loss
        loss.backward()
        optimizer.step()
```

##### 3.3 VQGAN数学模型

**模型损失函数**

VQGAN的损失函数包括生成器损失和判别器损失。生成器损失用于衡量生成图像的质量，判别器损失用于衡量判别器对真实图像和生成图像的鉴别能力。

**模型优化算法**

VQGAN的训练过程采用基于梯度的优化算法，如Adam或SGD。通过最小化损失函数，模型能够学习到图像的潜在特征。

**数学公式与推导**

假设输入图像为 \( x \)，生成器输出的图像为 \( x' \)，判别器的输出为 \( p(x'|x) \)，则VQGAN的损失函数可以表示为：

\[ L = L_{\text{generator}} + L_{\text{discriminator}} \]

其中，生成器损失 \( L_{\text{generator}} \) 可以表示为：

\[ L_{\text{generator}} = -\mathbb{E}_{z, label} [\log p(x'|z, label)] \]

判别器损失 \( L_{\text{discriminator}} \) 可以表示为：

\[ L_{\text{discriminator}} = -\mathbb{E}_{x, label} [\log p(x'|x, label)] - \mathbb{E}_{z, label} [\log (1 - p(x'|z, label))] \]

其中，\( \mathbb{E} \) 表示期望。

#### VQVAE概述

VQVAE（Vector Quantized Variational Autoencoder）是一种基于变分自编码器（Variational Autoencoder，VAE）的图像生成模型。传统VAE模型通过编码器和解码器学习图像的潜在特征，并利用这些特征生成新的图像。然而，VAE模型在训练过程中存在两个主要问题：一是模型的输出质量受限于潜在变量的分布，二是训练过程较为复杂且容易陷入局部最优。为了解决这些问题，VQVAE引入了量化技术，通过将潜在变量量化为离散的向量，提高模型的生成质量和训练效率。

VQVAE模型的核心思想是将编码器输出的连续潜在变量映射到一组预定义的离散向量上，这些离散向量称为代码书（codebook）。量化器负责找到与编码器输出最接近的离散向量，并将编码器输出转换为这些离散向量。解码器则根据这些离散向量重构图像。通过这样的量化过程，VQVAE能够有效降低模型的复杂度，提高训练效率，同时生成高质量的图像。

#### VQGAN概述

VQGAN（Vector Quantized Generative Adversarial Network）是一种结合了生成对抗网络（Generative Adversarial Network，GAN）和VQVAE思想的图像生成模型。GAN是由生成器（Generator）和判别器（Discriminator）组成的对抗性网络。生成器的任务是生成逼真的图像，判别器的任务是区分真实图像和生成图像。在训练过程中，生成器和判别器相互对抗，生成器不断优化生成图像的质量，判别器则提高对真实图像和生成图像的鉴别能力。这样的对抗训练过程使得GAN能够生成高质量的图像。

VQGAN在GAN的基础上引入了量化技术，通过量化器将生成器的输出转换为离散向量，再通过解码器重构图像。与传统的GAN相比，VQGAN在生成图像的过程中引入了量化步骤，从而降低了模型的复杂度，提高了训练效率。同时，VQGAN通过对抗训练，能够生成多样化且高质量的图像。

#### VQVAE与VQGAN的关系

VQVAE和VQGAN虽然在模型结构上有一定的相似性，但它们在实现方式和应用场景上存在差异。VQVAE是一种基于变分自编码器的图像生成模型，通过量化技术提高训练效率。而VQGAN则结合了生成对抗网络的思想，通过对抗训练生成高质量图像。

两者的主要区别在于VQVAE侧重于图像的重构和生成，适用于需要高质量重构的场景。而VQGAN则更擅长生成多样化且高质量的图像，适用于需要多样性的生成任务。

VQVAE（Vector Quantized Variational Autoencoder）是一种基于变分自编码器（Variational Autoencoder，VAE）的图像生成模型，通过引入量化技术，提高了训练效率并降低了模型复杂度。在VAE的基础上，VQVAE通过将编码器输出的连续潜在变量量化为离散的向量，从而实现了更高效的图像生成。

#### VQVAE概念与背景

VQVAE的核心思想是将编码器和解码器组成的变分自编码器（VAE）与量化技术相结合。在传统的VAE中，编码器通过映射输入图像到一个潜在空间，解码器则从潜在空间中重构输入图像。然而，VAE中潜在变量的分布通常是连续的，这导致训练过程复杂且容易陷入局部最优。为了解决这些问题，VQVAE引入了量化器，将潜在变量量化为离散的向量。

量化器通过预定义的代码书（codebook）将编码器输出的连续潜在变量映射到离散向量上。代码书是一组预定义的向量，用于表示潜在空间中的不同区域。量化器找到与编码器输出最接近的代码书向量，并将编码器输出转换为这些离散向量。这样，VQVAE通过量化器将连续的潜在变量转换为离散的向量，从而降低了模型复杂度，提高了训练效率。

#### VQVAE模型结构

VQVAE模型主要由编码器、量化器和解码器组成。编码器用于将输入图像映射到潜在空间，量化器用于将潜在空间中的连续变量量化为离散向量，解码器则将量化后的向量重构为图像。

**编码器**

编码器是一个全连接网络，其输入为图像，输出为潜在空间中的编码向量。编码器通常由多个隐层组成，每个隐层都使用非线性激活函数，如ReLU函数。通过多层神经网络，编码器能够提取输入图像的潜在特征。

**量化器**

量化器负责将编码器输出的连续潜在向量量化为离散的向量。量化器的核心是代码书（codebook），代码书是一个预定义的向量集，用于表示潜在空间中的不同区域。量化器的任务是找到与编码器输出最接近的代码书向量，并将编码器输出转换为这些离散向量。通常，量化器使用最近邻搜索方法找到最佳匹配的代码书向量。

**解码器**

解码器是一个反向过程，它将量化后的向量从潜在空间重构为图像。解码器也是一个全连接网络，其输入为量化后的向量，输出为重构的图像。解码器的结构与编码器类似，但层数通常较少，以避免过拟合。

#### VQVAE训练过程

VQVAE的训练过程涉及编码器、量化器和解码器的联合训练。在训练过程中，通过最小化重建损失和量化损失，模型能够学习到图像的潜在特征。

**重建损失**

重建损失用于衡量重构图像与原始图像之间的差异。在VQVAE中，重建损失通常采用均方误差（Mean Squared Error，MSE）或交叉熵损失函数。重建损失可以表示为：

\[ L_{\text{reconstruction}} = \frac{1}{N} \sum_{i=1}^{N} \| x_i - \hat{x}_i \|^2 \]

其中，\( x_i \)是输入图像，\( \hat{x}_i \)是重构图像。

**量化损失**

量化损失用于衡量量化后的向量与编码器输出之间的差异。量化损失通常采用KL散度（Kullback-Leibler Divergence）来衡量。KL散度可以表示为：

\[ L_{\text{quantization}} = \frac{1}{N} \sum_{i=1}^{N} \sum_{j=1}^{C} \mathcal{L}_{\text{KL}}(\mu_{jk} || \mu_{i} / \sigma_{i}^2) \]

其中，\( \mu_{i} \)和\( \sigma_{i}^2 \)是编码器输出的均值和方差，\( \mu_{jk} \)和\( \sigma_{ik}^2 \)是量化器输出的均值和方差，\( C \)是代码书中的向量数量。

**总损失**

VQVAE的总损失是重建损失和量化损失的和：

\[ L = L_{\text{reconstruction}} + \lambda \cdot L_{\text{quantization}} \]

其中，\( \lambda \)是量化损失的权重。

在训练过程中，通过优化总损失函数，编码器、量化器和解码器能够学习到图像的潜在特征，从而生成高质量的图像。

#### VQVAE数学模型

VQVAE的数学模型包括编码器、量化器和解码器的数学描述。以下是对这些模型的详细数学描述。

**编码器**

编码器是一个全连接网络，其输入为图像 \( x \)，输出为潜在空间中的编码向量 \( z \)。假设输入图像的维度为 \( D \)，编码器的输出维度为 \( K \)，则编码器可以表示为：

\[ z = \mu(x) = \phi(Wx + b) \]

其中，\( \phi \) 是激活函数，通常采用ReLU函数；\( W \) 和 \( b \) 分别是权重和偏置。

**量化器**

\[ q(z) = \arg\min_{j} \| z - \mu_j \| \]

其中，\( \mu_j \) 是代码书中的向量。

**解码器**

解码器是一个反向过程，它将量化后的向量 \( q(z) \) 从潜在空间重构为图像 \( \hat{x} \)。解码器也是一个全连接网络，其输入为量化后的向量 \( q(z) \)，输出为重构的图像。解码器可以表示为：

\[ \hat{x} = \hat{\mu}(q(z)) = \psi(W'q(z) + b') \]

其中，\( \psi \) 是激活函数，通常采用ReLU函数；\( W' \) 和 \( b' \) 分别是权重和偏置。

VQGAN（Vector Quantized Generative Adversarial Network）是一种结合了生成对抗网络（GAN）和量化技术的图像生成模型。其核心在于通过对抗训练生成高质量图像，同时引入量化器优化生成图像的质量。以下将详细解析VQGAN的算法流程，包括生成器与判别器的工作流程、条件生成对抗网络（cGAN）的原理，以及VQGAN的训练伪代码。

#### 生成器与判别器工作流程

**生成器**

生成器的任务是从潜空间生成逼真的图像。在VQGAN中，生成器首先从潜空间采样编码向量，然后通过多层神经网络生成图像。生成器的输入是一个潜在向量 \( z \)，输出是一个图像 \( x' \)。

1. **从潜空间采样编码向量**：生成器从潜空间中采样一个编码向量 \( z \)，这个向量决定了生成图像的基本特征。
2. **生成图像**：生成器通过多层神经网络将编码向量 \( z \) 映射到生成图像 \( x' \)。通常，这个映射过程包括多个卷积层和ReLU激活函数。

**判别器**

判别器的任务是判断图像的真实性。在VQGAN中，判别器接收真实图像和生成图像，输出一个概率值，表示图像是真实图像的概率。判别器的输入是一个图像 \( x \) 或 \( x' \)，输出是一个概率 \( p(x|G(z)) \)。

1. **判断真实图像**：判别器接收一个真实图像 \( x \)，并输出一个概率值，表示图像是真实图像的概率。
2. **判断生成图像**：判别器接收一个生成图像 \( x' \)，并输出一个概率值，表示图像是生成图像的概率。

#### 条件生成对抗网络（cGAN）原理

VQGAN采用了条件生成对抗网络（cGAN）的结构，通过条件输入生成特定类别的图像。在cGAN中，生成器和判别器不仅接收图像作为输入，还接收一个条件输入，如类别标签。

**生成器（cGAN）**

生成器在cGAN中从潜空间采样一个编码向量 \( z \)，然后结合条件输入（如类别标签 \( c \)），生成特定类别的图像 \( x' \)。

\[ x' = G(z, c) \]

**判别器（cGAN）**

判别器在cGAN中不仅接收图像 \( x \) 和 \( x' \)，还接收条件输入 \( c \)。判别器的目标是判断输入图像是否是真实图像。

\[ p(x|c) \quad \text{和} \quad p(x'|c) \]

```
初始化生成器、判别器、量化器参数

        x_real = D(x, c)
        x_fake = D(x_fake, c)
```

VQGAN（Vector Quantized Generative Adversarial Network）作为一种结合了生成对抗网络（GAN）和量化技术的图像生成模型，其核心在于通过对抗训练生成高质量图像，同时引入量化器优化生成图像的质量。以下是VQGAN的数学模型，包括模型损失函数、优化算法、以及相关的数学公式与推导。

#### 模型损失函数

VQGAN的损失函数主要包括生成器损失、判别器损失和量化器损失。这些损失函数共同作用，指导模型在训练过程中学习到有效的图像特征。

**生成器损失**

生成器损失主要用于衡量生成图像的质量。在VQGAN中，生成器生成图像 \( x' \)，判别器 \( D \) 对生成图像进行判断。生成器损失通常采用以下形式：

\[ L_{\text{generator}} = -\mathbb{E}_{z, c} [\log D(x', c)] \]

其中，\( z \) 是潜空间中的编码向量，\( c \) 是条件输入，\( D(x', c) \) 表示判别器判断生成图像 \( x' \) 为真实图像的概率。

**判别器损失**

判别器损失主要用于衡量判别器对真实图像和生成图像的鉴别能力。判别器 \( D \) 对真实图像 \( x \) 和生成图像 \( x' \) 进行判断。判别器损失通常采用以下形式：

\[ L_{\text{discriminator}} = -\mathbb{E}_{x, c} [\log D(x, c)] - \mathbb{E}_{z, c} [\log D(x', c)] \]

其中，\( D(x, c) \) 表示判别器判断真实图像 \( x \) 为真实图像的概率，\( D(x', c) \) 表示判别器判断生成图像 \( x' \) 为真实图像的概率。

**量化器损失**

量化器损失主要用于衡量量化器对生成图像的优化效果。量化器 \( Q \) 将生成图像的编码向量 \( z \) 量化为离散的向量。量化器损失通常采用KL散度（Kullback-Leibler Divergence）来衡量，形式如下：

\[ L_{\text{quantizer}} = \mathbb{E}_{z} [\log \frac{Q(z)}{p(z)}] \]

其中，\( Q(z) \) 表示量化器对编码向量 \( z \) 的量化结果，\( p(z) \) 表示编码向量 \( z \) 的先验分布。

#### 优化算法

VQGAN的训练过程采用基于梯度的优化算法，如Adam或SGD。通过最小化总损失函数，模型能够学习到图像的潜在特征。

**总损失函数**

VQGAN的总损失函数是生成器损失、判别器损失和量化器损失的和：

\[ L = L_{\text{generator}} + L_{\text{discriminator}} + \lambda \cdot L_{\text{quantizer}} \]

其中，\( \lambda \) 是量化器损失的权重。

#### 数学公式与推导

以下是对VQGAN相关数学公式的详细推导。

**生成器损失**

生成器损失采用对抗性损失函数，表示为：

\[ L_{\text{generator}} = -\mathbb{E}_{z, c} [\log D(x', c)] \]

其中，\( D(x', c) \) 是判别器判断生成图像 \( x' \) 为真实图像的概率。为了最小化生成器损失，生成器需要生成逼真的图像，使判别器难以区分真实图像和生成图像。

**判别器损失**

判别器损失采用对抗性损失函数，表示为：

\[ L_{\text{discriminator}} = -\mathbb{E}_{x, c} [\log D(x, c)] - \mathbb{E}_{z, c} [\log D(x', c)] \]

其中，\( D(x, c) \) 是判别器判断真实图像 \( x \) 为真实图像的概率，\( D(x', c) \) 是判别器判断生成图像 \( x' \) 为真实图像的概率。为了最小化判别器损失，判别器需要提高对真实图像和生成图像的鉴别能力。

**量化器损失**

量化器损失采用KL散度，表示为：

\[ L_{\text{quantizer}} = \mathbb{E}_{z} [\log \frac{Q(z)}{p(z)}] \]

其中，\( Q(z) \) 是量化器对编码向量 \( z \) 的量化结果，\( p(z) \) 是编码向量 \( z \) 的先验分布。为了最小化量化器损失，量化器需要找到与编码向量 \( z \) 最接近的量化向量。

损失函数优化是提高模型性能的关键环节。以下是一些常用的损失函数优化策略：

1. **引入多样性损失**：在生成对抗网络（GAN）中，引入多样性损失可以促使生成器生成更多样化的图像。多样性损失通常采用Inception Score（IS）或Frechet Inception Distance（FID）等指标。

2. **引入感知损失**：在图像生成任务中，引入感知损失可以促使生成器生成的图像更符合人类的感知。常用的感知损失包括感知损失（Perceptual Loss）和结构相似性指数（SSIM）。

3. **动态调整权重**：通过动态调整不同损失函数的权重，可以平衡模型在生成质量、多样性和稳定性之间的折中。例如，在训练过程中，可以逐步减小重建损失权重，增加对抗损失权重。

4. **损失函数融合**：通过将不同类型的损失函数（如L1、L2损失、感知损失等）进行融合，可以设计出更有效的损失函数，提高模型性能。

#### 并行计算

通过并行计算，可以充分利用多核CPU和GPU的计算资源，提高VQVAE与VQGAN的实时性能。以下是一些并行计算方法：

1. **数据并行**：数据并行是将数据集分为多个子集，分别在不同的GPU或CPU上训练模型。这种方法可以提高模型训练的并行度，缩短训练时间。

2. **模型并行**：模型并行是将模型分为多个子模型，分别在不同的GPU或CPU上执行。这种方法适用于大型深度学习模型，可以显著提高模型推理的速度。

3. **流并行**：流并行是在实时应用场景下，将图像流分为多个子流，分别在不同的GPU或CPU上处理。这种方法可以提高模型对实时数据流的处理能力。

在实时应用中，降低模型推理的延迟是提高用户体验的关键。以下是一些低延迟优化方法：

1. **模型剪枝**：通过剪枝模型中的冗余权重和神经元，可以减小模型体积，降低模型推理的延迟。常见的剪枝方法包括权重剪枝和结构剪枝。

2. **量化**：量化是一种将模型中的浮点数参数转换为低精度的整数表示的方法，可以显著降低模型推理的延迟。通过量化，可以减少计算量和内存占用，提高模型推理速度。

3. **异步推理**：异步推理是在模型推理过程中，将不同层的计算任务并行执行，以减少模型推理的等待时间。通过异步推理，可以进一步提高模型推理的实时性能。

4. **缓存优化**：通过优化模型缓存策略，可以减少模型推理过程中的数据传输和存储延迟。例如，使用局部缓存存储常用数据，可以减少数据访问时间。

```python
            nn.ReLU(),
```

```python
            nn.BatchNorm2d(256),
            nn.LeakyReLU(0.2),
            nn.Conv2d(256, 1, 4),
            nn.Sigmoid()
        )
```

**VQVAE代码示例**

```python
import torch
import torch.nn as nn
import torch.optim as optim

class VectorQuantizer(nn.Module):
    def __init__(self, num_embeddings, embedding_dim):
        super(VectorQuantizer, self).__init__()
        self.num_embeddings = num_embeddings
        self.embedding_dim = embedding_dim
        self.embeddings = nn.Parameter(torch.randn(num_embeddings, embedding_dim))
        
    def forward(self, x):
        # 计算每个编码向量与输入向量的距离
        distances = (x.unsqueeze(1) - self.embeddings).pow(2).sum(-1)
        # 找到最近邻编码向量
        quantized_idx = distances.argmin(-1)
        # 使用索引获取编码向量
        quantized_embed = self.embeddings[quantized_idx]
        return quantized_embed

class VQVAE(nn.Module):
    def __init__(self, image_size, latent_dim, num_embeddings, embedding_dim):
        super(VQVAE, self).__init__()
        self.encoder = nn.Sequential(
            nn.Conv2d(image_size[0], 64, kernel_size=4, stride=2),
            nn.ReLU(),
            nn.Conv2d(64, 128, kernel_size=4, stride=2),
            nn.ReLU(),
            nn.Conv2d(128, latent_dim, kernel_size=4, stride=2),
        )
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(latent_dim, 128, kernel_size=4, stride=2),
            nn.ReLU(),
            nn.ConvTranspose2d(128, 64, kernel_size=4, stride=2),
            nn.ReLU(),
            nn.ConvTranspose2d(64, image_size[0], kernel_size=4, stride=2),
            nn.Sigmoid()
        )
        self.vq = VectorQuantizer(num_embeddings, embedding_dim)

    def forward(self, x):
        z_e = self.encoder(x)
        z_q = self.vq(z_e)
        x_recon = self.decoder(z_q)
        return x_recon
```
