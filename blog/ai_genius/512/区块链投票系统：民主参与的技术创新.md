**2.1.1 密码学基础**

密码学是研究加密和解密技术的学科。加密是指将明文信息转换为密文的过程，而解密则是将密文还原为明文的过程。密码学主要涉及以下几个方面：

- **加密与解密**：加密是将明文信息转换为密文的过程，解密则是将密文还原为明文的过程。加密和解密需要使用密钥，密钥是加密算法的核心组成部分。
- **对称加密与非对称加密**：对称加密使用相同的密钥进行加密和解密，而非对称加密则使用一对公钥和私钥进行加密和解密。

**2.1.2 常见的加密算法**

- **对称加密**：对称加密算法使用相同的密钥进行加密和解密。常见的对称加密算法包括AES（高级加密标准）和DES（数据加密标准）。
- **非对称加密**：非对称加密算法使用一对公钥和私钥进行加密和解密。常见的非对称加密算法包括RSA（Rivest-Shamir-Adleman算法）和ECC（椭圆曲线加密）。

**4.2.1 投票合约**

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Voting {
    // 存储候选人的名称和得票数
    mapping(string => uint256) public candidates;
    // 存储已投票的地址
    mapping(address => bool) public voters;

    // 事件记录投票
    event VoteRecorded(address voter, string candidate);

    // 投票
    function vote(string memory candidate) public {
        require(!voters[msg.sender], "已经投票");
        voters[msg.sender] = true;
        candidates[candidate] += 1;
        emit VoteRecorded(msg.sender, candidate);
    }

    // 查询得票数
    function getCandidates() public view returns (mapping(string => uint256) memory) {
        return candidates;
    }
}
```
