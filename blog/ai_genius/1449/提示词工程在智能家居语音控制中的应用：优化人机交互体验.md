```python
import jieba

def generate_prompt(word):
    # 使用jieba分词工具进行分词
    words = jieba.cut(word)
    # 合并分词结果，形成提示词
    prompt = " ".join(words)
    return prompt

word = "打开电视"

print(prompt)  # 输出：打开电视
```

```python
   tokens = word_tokenize(text)

   chunk_parser = RegexpParser('NP: {<DT>?<JJ>*<NN>}')

   ```

   ```python
   command = ""

       if subtree.label() == 'NP':
           noun = subtree.leaves()[1][0]
           if noun.lower() in ['打开', '关闭', '调整']:
               action = noun.lower()
               object = tokens[tokens.index(subtree.leaves()[1][0]):]
               command = f"{action} {object}"
               break
   ```

   这里遍历句法分析树，查找包含名词（NP）的子树。如果名词是“打开”、“关闭”或“调整”，则将其作为操作指令的前缀，并根据分词结果提取出操作对象，生成完整的指令。
