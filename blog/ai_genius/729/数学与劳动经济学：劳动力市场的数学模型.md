# 输出：劳动者选择的工作机会 i*

def discrete_choice_model(X, Y, W):
    # 初始化选择概率分布
    P = [0 for _ in range(len(Y))]
    
    # 计算每个工作机会的吸引力指数
    for i in range(len(Y)):
        attractiveness = X * Y[i] - W[i]
        P[i] = 1 / (1 + exp(-attractiveness))
    
    # 计算选择概率
    total_prob = sum(P)
    for i in range(len(P)):
        P[i] /= total_prob
    
    # 选择概率最大的工作机会
    i* = argmax(P)
    return i*

**## 3.1 离散选择模型**

离散选择模型（Discrete Choice Model，简称DCM）是劳动经济学中常用的数学模型之一，用于分析个体在多种选择中的决策行为。离散选择模型广泛应用于劳动力市场分析、消费者行为研究等领域。

离散选择模型的基本原理如下：

1. **选择集**：离散选择模型假设个体在选择过程中面临多个可选方案，这些方案构成了选择集。每个方案都包含一组特征属性。

2. **概率分布**：离散选择模型通过构建概率分布函数，描述个体选择某个方案的概率。概率分布函数通常基于个体特征和方案特征之间的关系。

3. **最大化效用**：离散选择模型假设个体在选择过程中追求最大化个人效用。个体会选择使自身效用最大化的方案。

3. **构建劳动力需求模型**：假设劳动力需求函数为 \( D(E, W) = 800 + 20W \)，其中 \( D \) 表示劳动力需求量，\( E \) 表示企业特征，\( W \) 表示工资水平。
