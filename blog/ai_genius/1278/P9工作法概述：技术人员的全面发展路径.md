### 代码实际案例和详细解释说明

以下是一个使用Python实现的P9工作法中的时间管理功能的示例代码。

```python
import time

class TimeManager:
    def __init__(self):
        self.tasks = {}

    def add_task(self, task_name, duration):
        self.tasks[task_name] = duration

    def start_task(self, task_name):
        if task_name in self.tasks:
            start_time = time.time()
            print(f"开始任务：{task_name}")
            return start_time
        else:
            print(f"任务：{task_name} 不存在")
            return None

    def end_task(self, task_name):
        if task_name in self.tasks:
            end_time = time.time()
            print(f"结束任务：{task_name}")
            task_duration = end_time - self.tasks[task_name]
            print(f"任务耗时：{task_duration}秒")
        else:
            print(f"任务：{task_name} 不存在")

# 创建时间管理器实例
time_manager = TimeManager()

# 添加任务和持续时间
time_manager.add_task("编写代码", 3600)  # 假设任务持续1小时
time_manager.add_task("学习人工智能", 1800)  # 假设任务持续30分钟

# 开始和结束任务
start_time = time_manager.start_task("编写代码")
if start_time:
    time.sleep(3600)  # 模拟任务持续1小时
    time_manager.end_task("编写代码")

start_time = time_manager.start_task("学习人工智能")
if start_time:
    time.sleep(1800)  # 模拟任务持续30分钟
    time_manager.end_task("学习人工智能")
```

#### 代码应用解读与分析

1. **类定义**：`TimeManager` 类用于管理任务和持续时间。类中定义了四个方法：`add_task()` 用于添加任务及其持续时间，`start_task()` 用于开始任务，`end_task()` 用于结束任务。

2. **添加任务**：通过调用 `add_task()` 方法，可以将任务及其持续时间添加到 `tasks` 字典中。

3. **开始任务**：调用 `start_task()` 方法，传入任务名称，如果任务已存在，则记录开始时间并返回；否则，提示任务不存在。

4. **结束任务**：调用 `end_task()` 方法，传入任务名称，如果任务已存在，则记录结束时间，计算任务耗时，并打印；否则，提示任务不存在。

5. **模拟任务执行**：通过 `time.sleep()` 函数模拟任务的执行时间，以测试 `start_task()` 和 `end_task()` 方法。
