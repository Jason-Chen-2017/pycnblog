### 数学模型和数学公式详细讲解与举例说明

**线性回归模型公式：**
$$ y = \beta_0 + \beta_1 \cdot x + \epsilon $$
举例：假设我们要预测房价，使用线性回归模型。自变量$x$是房子的面积，因变量$y$是房价。通过训练数据集，我们可以得到模型的参数$\beta_0$和$\beta_1$，进而预测新的房子面积对应的房价。

**逻辑回归模型公式：**
$$ \sigma(z) = \frac{1}{1 + e^{-z}} $$
举例：假设我们要预测一个病人是否患有某种疾病，使用逻辑回归模型。自变量$z = \beta_0 + \beta_1 \cdot x$，其中$x$是病人的体征特征向量，$\sigma(z)$是疾病发生的概率。

**支持向量机模型公式：**
$$ \max \frac{1}{2} \sum_{i=1}^{n} w_i^2 $$
$$ s.t. y^{(i)}(\langle \phi(x^{(i)}), w \rangle - b) \geq 1 $$
举例：假设我们要进行手写数字识别，使用支持向量机模型。$\phi(x^{(i)})$是输入的特征映射，$w_i$是权重，$b$是偏置。通过训练数据集，我们可以得到最优的权重和偏置，从而实现手写数字的识别。

**代码实现：**

```python
import numpy as np

# 线性回归模型
class LinearRegression:
    def __init__(self):
        self.w = None
        self.b = None

    def fit(self, X, y):
        X = np.concatenate((np.ones((X.shape[0], 1)), X), axis=1)
        self.w = np.linalg.inv(X.T @ X) @ X.T @ y
        self.b = self.w[0]

    def predict(self, X):
        X = np.concatenate((np.ones((X.shape[0], 1)), X), axis=1)
        return X @ self.w

# 测试代码
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([2, 4, 5, 4, 5])
model = LinearRegression()
model.fit(X, y)
```
