  $$ Validity = Check(UserID, TargetEntityID, Permission, ExpirationTime) $$

- **授权执行**：根据智能合约审核结果，执行授权操作，可表示为：
  $$ Execute = \begin{cases}
  GrantAccess() & \text{if } Validity = True \\
  DenyAccess() & \text{if } Validity = False
  \end{cases} $$

- **授权记录存储**：将授权记录存储在区块链上，可表示为：
  $$ Blockchain = Add(AuthorizationRecord) $$

##### 4.3.3 算法原理举例说明

- **示例3**：授权请求的有效期为1天，到期后智能合约自动撤销授权。

- **用户接口**：
  ```python
  #!/usr/bin/env python
  from blockchain import Blockchain
  from datetime import datetime, timedelta

  # 初始化区块链
  blockchain = Blockchain()

  def request_authorization(user, target_entity, permission, expiration_time):
      request = {
          'user': user,
          'target_entity': target_entity,
          'permission': permission,
          'expiration_time': expiration_time
      }
      blockchain.add_transaction('AuthorizationRequest', request)
      result = blockchain.smart_contract_review(request)
      if result:
          blockchain.execute_authorization(request)
          return True
      return False

  # 用户请求授权
  request_authorization('Alice', 'Doctor', 'ViewHealthInfo', datetime.now() + timedelta(days=1))
  ```

          'target_entity': target_entity,
          'permission': permission
      }
