#### 1.3.1.3 数学模型和公式

为了更深入地理解后消费主义生活实验的算法原理，我们可以引入一些数学模型和公式。以下是一些核心的数学模型和公式：

1. **总消费金额**：总消费金额是指在一定时间内所有消费的总和。公式为：
   $$ \text{总消费金额} = \sum_{i=1}^{n} \text{消费金额}_i $$
   其中，\( n \) 是消费记录的数量。

2. **各类型消费金额**：各类型消费金额是指按照消费类型分类后的消费总和。公式为：
   $$ \text{各类型消费金额} = \sum_{i=1}^{n} \text{消费金额}_i \times \text{消费类型}_i $$
   其中，\( \text{消费类型}_i \) 是消费类型的权重。

3. **减少消费计划**：减少消费计划是指根据各类型消费金额制定的一个减少消费的目标。公式为：
   $$ \text{减少消费计划} = \sum_{i=1}^{n} \text{消费金额}_i \times (\text{目标减少比例}) $$
   其中，\( \text{目标减少比例} \) 是一个预设的比例，用于确定各类型消费的减少程度。

4. **实施后的消费记录**：实施后的消费记录是指根据减少消费计划调整后的消费记录。公式为：
   $$ \text{实施后的消费记录} = \text{原始消费记录} - \text{减少消费计划} $$
   其中，\( \text{原始消费记录} \) 是实验开始前的消费记录。

通过这些数学模型和公式，我们可以更科学地制定和实施后消费主义生活实验的计划，评估实验的效果，并不断优化实验方案。

from flask_cors import CORS

db = SQLAlchemy(app)
CORS(app)

# 定义模型
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)

class Consumption(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    amount = db.Column(db.Float, nullable=False)
    type = db.Column(db.String(80), nullable=False)
    date = db.Column(db.Date, nullable=False)

class Experience(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    content = db.Column(db.Text, nullable=False)
    date = db.Column(db.Date, nullable=False)

def register():
    username = request.form['username']
    # 在数据库中添加用户
    new_user = User(username=username)
    db.session.add(new_user)
    db.session.commit()
    return jsonify({'message': '注册成功'})

# 添加消费记录接口

def add_consumption():

    new_consumption = Consumption(user_id=user_id, amount=amount, type=type, date=date)
    db.session.add(new_consumption)
    db.session.commit()
    return jsonify({'message': '添加成功'})

# 添加内心体验记录接口

    user_id = request.form['user_id']
    content = request.form['content']
    date = request.form['date']

    new_experience = Experience(user_id=user_id, content=content, date=date)
    db.session.add(new_experience)
    db.session.commit()
    return jsonify({'message': '添加成功'})

if __name__ == '__main__':
