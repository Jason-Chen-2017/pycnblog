线性回归是一种简单而有效的预测算法，适用于线性关系的预测。其基本思想是通过建立自变量（水质指标）和因变量（污染程度）之间的线性关系模型，从而预测新的数据点的污染程度。

**伪代码**：
```plaintext
输入：特征矩阵X，标签向量y
输出：模型参数w，b

初始化：w = 0，b = 0

for i = 1 to n：
    计算梯度：Δw = -2/X.T * X * y - w
    Δb = -2/X.T * y - b

更新参数：w = w - α * Δw
b = b - α * Δb

返回：w，b
```

**决策树**：
决策树是一种基于树形结构进行决策的算法，能够将输入数据分成不同的类别或数值。在水质监测中，决策树可以用于分类或回归任务。

**伪代码**：
```plaintext
输入：特征矩阵X，标签向量y

构建决策树：
    if 满足停止条件：
        返回叶节点，标签为y的均值
    else：
        选择最佳分割特征和阈值：
            Gini不纯度最小或信息增益最大
        
        根据分割特征和阈值，将数据划分为左右子集
        递归调用构建子树
        
返回：决策树
```

**支持向量机**：
支持向量机（SVM）是一种强大的分类算法，通过找到最优的决策边界，实现数据的分类。在水质监测中，SVM可以用于分类任务，识别不同污染程度的水质样本。

**伪代码**：
```plaintext
输入：训练数据集(X, y)

初始化：参数C，核函数K(x, x')

求解最优化问题：
    最小化：1/2 * ||w||^2 + C * Σ(λ_i)

    满足：y_i * (w.T * x_i + b) >= 1 - ε_i
    λ_i >= 0

得到：模型参数w，b

返回：模型参数w，b
```

#### 4.3 算法性能评估

算法性能评估是评价机器学习模型优劣的关键步骤。常用的评估指标包括准确率、召回率、F1分数和均方误差（MSE）等。

- **准确率**：分类正确的样本数占总样本数的比例，适用于二分类问题。
- **召回率**：实际为正类别的样本中被正确分类为正类别的比例，侧重于识别所有正类样本。
- **F1分数**：准确率和召回率的调和平均，用于平衡两者。
- **均方误差（MSE）**：回归问题中预测值与真实值之间差的平方的平均值，用于评估模型的预测能力。

**性能评估伪代码**：
```plaintext
输入：模型f，测试数据集(X, y)

预测：y_pred = f(X)

计算评估指标：
    正确预测数 = Σ(1 if y_pred[i] == y[i] else 0)
    总样本数 = len(y)

准确率 = 正确预测数 / 总样本数

召回率 = 正确预测正类数 / 实际正类总数

F1分数 = 2 * (准确率 * 召回率) / (准确率 + 召回率)

返回：准确率，召回率，F1分数
```

#### 5.1 卷积神经网络（CNN）应用

卷积神经网络（Convolutional Neural Network，CNN）是一种专门用于处理具有网格结构数据（如图像和时空序列数据）的深度学习模型。CNN在水质监测中的应用主要体现在以下几个方面：

**CNN基本架构**：
- **卷积层（Convolutional Layer）**：通过卷积操作提取输入数据的特征。
- **池化层（Pooling Layer）**：用于降低数据的维度和减少计算量。
- **激活函数（Activation Function）**：引入非线性，使网络能够处理复杂数据。
- **全连接层（Fully Connected Layer）**：将卷积特征映射到输出结果。

**CNN模型训练伪代码**：
```plaintext
输入：训练数据集（图像X，标签y）
输出：模型参数θ

初始化：θ = 初始化随机权重

for epoch in 1 to E：
    for (x, y) in training_data：
```

#### 5.2 递归神经网络（RNN）应用

递归神经网络（Recurrent Neural Network，RNN）是一种能够处理序列数据的神经网络。RNN在水质监测中的应用主要体现在以下几个方面：

1. **时间序列预测**：利用RNN对水质时间序列数据进行建模，预测未来的水质变化。
2. **异常检测**：通过RNN监测水质时间序列中的异常值，及时发现污染事件。

**RNN基本架构**：
- **隐藏层（Hidden Layer）**：用于对输入数据进行处理和记忆。
- **递归连接（Recurrence Connection）**：通过时间步之间的连接，实现数据的记忆功能。
- **激活函数（Activation Function）**：引入非线性，使网络能够处理复杂数据。

**RNN模型训练伪代码**：
```plaintext
输入：训练数据集（序列X，标签y）
输出：模型参数θ

初始化：θ = 初始化随机权重

for epoch in 1 to E：
    for (x, y) in training_data：
        前向传播：h_t = f(h_{t-1}, x_t; θ)
        计算损失：L = loss(h_T, y)

```

#### 5.3 长短期记忆网络（LSTM）应用

长短期记忆网络（Long Short-Term Memory，LSTM）是RNN的一种变体，专门用于解决RNN中的长期依赖问题。LSTM在水质监测中的应用主要体现在以下几个方面：

1. **长时间序列预测**：利用LSTM对长时间序列数据进行建模，预测未来的水质变化趋势。
2. **多步预测**：通过LSTM对多步水质数据进行预测，为污染控制提供决策支持。

**LSTM基本架构**：
- **输入门（Input Gate）**：决定哪些信息需要被存储在记忆单元中。
- **遗忘门（Forget Gate）**：决定哪些信息需要从记忆单元中遗忘。
- **输出门（Output Gate）**：决定哪些信息需要输出到下一层。

**LSTM模型训练伪代码**：
```plaintext
输入：训练数据集（序列X，标签y）
输出：模型参数θ

初始化：θ = 初始化随机权重

for epoch in 1 to E：
    for (x, y) in training_data：
        前向传播：
            i_t = input_gate(x_t, h_{t-1}, θ_i)
            f_t = forget_gate(x_t, h_{t-1}, θ_f)
            C_t = C_{t-1} * f_t + i_t * tanh(C候选_t)
            o_t = output_gate(x_t, h_{t-1}, θ_o)
            h_t = o_t * tanh(C_t)

        反向传播：
            δh_t = ∂L/∂h_t
            δC_t = δh_t * o_t * (1 - o_t)
            δf_t = ∂L/∂f_t
            δC候选_t = ∂L/∂C候选_t
            δi_t = ∂L/∂i_t
            δx_t = ∂L/∂x_t
        
        更新参数：θ = θ - α(∇θL)

返回：训练完成的模型参数θ
```
