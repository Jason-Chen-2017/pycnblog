### 第二部分：智能环境监测基础

#### 2.1 智能环境监测概述

智能环境监测是指利用先进的信息技术和传感器技术，对环境中的各种参数进行实时、动态、全方位的监测和分析，从而为环境保护和管理提供科学依据。智能环境监测系统通常由传感器网络、数据传输和处理系统、数据分析和可视化平台等多个部分组成。

#### 2.1.1 智能环境监测的定义

智能环境监测是一种综合利用传感器技术、数据通信技术、人工智能技术等手段，对环境中的各种参数（如空气质量、水质、土壤质量、气象参数等）进行监测和分析的技术体系。通过这种技术，可以实现环境信息的自动化采集、传输、处理和反馈，从而实现对环境的实时监控和动态管理。

#### 2.1.2 智能环境监测的发展历程

智能环境监测的发展历程可以分为以下几个阶段：

1. **传统监测阶段**：这一阶段主要依赖于人工监测和简单的仪器设备，监测范围和精度有限，监测数据不及时且难以共享。
2. **自动化监测阶段**：随着传感器技术和数据通信技术的发展，监测系统逐渐实现了自动化，能够自动采集和处理监测数据，监测效率和精度得到了显著提升。
3. **智能化监测阶段**：这一阶段主要特点是引入了人工智能技术，通过对海量监测数据的分析和挖掘，可以实现对环境变化的智能预警和预测，进一步提高了监测的智能化水平。

#### 2.1.3 智能环境监测的核心技术

智能环境监测的核心技术主要包括以下几个方面：

1. **传感器技术**：传感器是智能环境监测系统的感知器官，用于采集环境中的各种参数。随着传感器技术的不断发展，传感器的精度、灵敏度、稳定性等方面得到了大幅提升。
2. **数据通信技术**：数据通信技术是智能环境监测系统的信息传输通道，负责将传感器采集的数据传输到处理中心。目前，无线传感器网络（WSN）和物联网（IoT）技术已经成为智能环境监测数据通信的主要手段。
3. **数据处理和分析技术**：数据处理和分析技术是智能环境监测系统的“大脑”，负责对采集到的环境数据进行处理、分析和挖掘，从中提取有价值的信息。常用的数据处理技术包括数据清洗、数据集成、数据挖掘、机器学习等。
4. **可视化技术**：可视化技术是智能环境监测系统的“窗口”，通过图形化界面，将环境数据以直观、易理解的方式展示出来，帮助决策者进行环境管理和决策。

#### 2.1.4 智能环境监测的应用领域

智能环境监测技术在多个领域得到了广泛应用，主要包括：

1. **环境保护**：通过智能环境监测系统，可以实时监测环境质量，及时发现污染源，为环境管理和污染治理提供科学依据。
2. **城市安全**：智能环境监测系统可以监测城市的气象、空气质量、水质等参数，为城市安全预警和应急管理提供支持。
3. **生态保护**：智能环境监测系统可以监测生态系统的健康状况，及时发现生态破坏和污染问题，为生态修复和保护提供依据。
4. **农业和林业**：智能环境监测系统可以监测土壤质量、气象条件、植物生长状况等参数，为农业生产和林业管理提供决策支持。

通过以上介绍，我们可以看出，智能环境监测作为一种先进的技术手段，在环境保护、城市安全、生态保护和农业林业等领域发挥着重要作用，为推动社会可持续发展提供了有力支持。

#### 2.2 环境监测数据类型与处理

环境监测数据是智能环境监测系统的重要输出，其类型和特点直接影响到监测系统的性能和应用效果。以下是几种常见的环境监测数据类型及其处理方法。

#### 2.2.1 环境监测数据的类型

环境监测数据主要包括以下几种类型：

1. **气象数据**：包括气温、湿度、风速、风向、气压、降水等参数。气象数据对农业生产、城市规划、生态保护等具有重要影响。
2. **水质数据**：包括pH值、溶解氧、氨氮、总氮、总磷、重金属等参数。水质数据是评估水环境质量、指导水资源管理和防治水污染的重要依据。
3. **空气质量数据**：包括颗粒物（如PM2.5、PM10）、二氧化硫（SO2）、氮氧化物（NOx）、一氧化碳（CO）、臭氧（O3）等参数。空气质量数据是评估大气环境质量、制定空气质量管理和污染防治政策的重要参考。
4. **土壤数据**：包括土壤酸碱度、养分含量、污染物质浓度等参数。土壤数据是评估土壤质量、指导土地管理和农业生产的科学依据。

#### 2.2.2 环境监测数据的特点

环境监测数据具有以下特点：

1. **多样性**：环境监测数据涵盖了气象、水质、空气质量和土壤等多个方面，具有多样性。
2. **实时性**：环境监测数据通常需要实时采集和更新，以反映环境变化的动态过程。
3. **动态性**：环境数据随时间和空间的变化而变化，具有动态性。
4. **不确定性**：环境数据受多种因素影响，存在一定的不确定性，如气象变化、人类活动等。

#### 2.2.3 环境监测数据处理方法

环境监测数据处理方法主要包括以下步骤：

1. **数据采集**：通过传感器网络、遥感技术等手段，实时采集环境数据。
2. **数据预处理**：对采集到的原始数据进行清洗、去噪、补缺等预处理操作，以提高数据的可靠性和一致性。
3. **数据集成**：将不同来源、不同格式的环境数据进行整合，形成统一的数据集。
4. **数据存储**：将处理后的环境数据存储到数据库或数据仓库中，以供后续分析和应用。
5. **数据分析和挖掘**：利用数据挖掘、机器学习等算法，对环境数据进行深度分析和挖掘，提取有价值的信息和规律。
6. **数据可视化**：将分析结果以图表、地图等形式直观展示，为环境管理和决策提供支持。

#### 2.2.4 环境监测数据处理的挑战

环境监测数据处理面临以下挑战：

1. **海量数据**：随着监测技术的进步，环境监测数据量呈现爆炸式增长，给数据处理和分析带来了巨大压力。
2. **数据质量**：环境监测数据存在噪声、缺失值、不一致等问题，需要通过数据清洗和预处理方法来保证数据质量。
3. **实时性**：环境监测数据需要实时处理和分析，对系统的响应速度和处理能力提出了高要求。
4. **不确定性**：环境监测数据受多种因素影响，存在不确定性，需要通过数据模型和算法来预测和解释。

通过以上对环境监测数据类型与处理方法的介绍，我们可以看出，环境监测数据在智能环境监测中起着至关重要的作用。有效的数据处理和分析方法可以大大提高监测系统的性能和应用效果，为环境保护、城市安全、生态保护和农业林业等领域提供科学依据。

#### 2.3 环境监测技术进展

随着科技的不断进步，环境监测技术也在不断发展，从传统的手工监测到现代的智能监测，技术的升级和进步极大地提高了监测的效率、精度和广度。

#### 2.3.1 传统环境监测技术的局限性

传统环境监测技术主要依赖于手工监测和简单的仪器设备，存在以下局限性：

1. **监测范围有限**：传统监测手段难以实现对大范围、全时段的监测，监测范围受限。
2. **数据精度不高**：手工监测和数据采集设备的技术限制导致监测数据精度不高，难以满足精细化管理需求。
3. **监测效率低**：手工监测和数据传输依赖于人工，效率低下，不利于实时监测和快速响应。
4. **数据共享困难**：传统监测数据往往分散在不同部门和单位，难以实现数据共享和综合利用。

#### 2.3.2 智能环境监测技术的发展趋势

智能环境监测技术的发展趋势主要体现在以下几个方面：

1. **高精度监测**：新一代的传感器技术提高了监测精度，能够更准确地检测环境中的微小变化，满足精细化管理需求。
2. **实时监测**：通过无线传感器网络（WSN）和物联网（IoT）技术，实现数据的实时采集、传输和处理，提高监测效率。
3. **多传感器融合**：多传感器融合技术通过整合不同类型、不同原理的传感器数据，提高监测数据的全面性和可靠性。
4. **大数据分析**：利用大数据技术和人工智能算法，对海量环境监测数据进行深度分析和挖掘，提取有价值的信息和规律。
5. **智能化预警与决策支持**：通过智能算法和模型，实现对环境变化的智能预警和预测，为环境保护和应急决策提供科学支持。

#### 2.3.3 先进环境监测技术的应用案例

以下是一些先进环境监测技术的应用案例：

1. **卫星遥感技术**：利用卫星遥感技术可以实现对大范围、全天候的环境监测，如大气污染物监测、土地覆盖监测等。
2. **无人机监测**：无人机可以搭载传感器，对难以到达的区域进行环境监测，如森林火灾监测、水质监测等。
3. **物联网传感器网络**：在城市的各个角落部署物联网传感器，实现对空气质量、水质、噪声等环境参数的实时监测。
4. **人工智能算法**：通过深度学习、机器学习算法，对环境数据进行实时分析和预测，提高监测的智能化水平。

通过以上对环境监测技术进展的介绍，我们可以看到，智能环境监测技术正迅速发展，不断推动环境监测领域的变革。这些先进技术的应用不仅提高了监测的效率和精度，也为环境保护和可持续发展提供了强有力的技术支持。

#### 2.4 生态保护背景知识

生态保护是指通过一系列措施来维护、修复和恢复生态系统的健康和功能，以保护生物多样性、保障人类福祉和促进可持续发展。生态保护的重要性不言而喻，它不仅关乎自然界的平衡，也与人类的生存和发展息息相关。

#### 2.4.1 生态保护的重要性

生态保护的重要性主要体现在以下几个方面：

1. **生物多样性保护**：生态系统中的每一个物种都有其独特的生态功能，保护生物多样性有助于维持生态系统的稳定性和完整性。
2. **水资源保护**：健康的生态系统对水资源的保护至关重要，它能够保持水源地的清洁和水质稳定，为人类提供安全的饮用水。
3. **气候调节**：森林、湿地等生态系统具有调节气候的作用，能够吸收二氧化碳，减缓全球变暖。
4. **土壤保护**：健康的土壤能够支持植物生长，维护土壤肥力，防止土壤侵蚀。
5. **人类福祉**：生态系统提供了大量的自然资源和生态系统服务，如食物、药材、旅游等，对人类的健康和生活质量有直接影响。

#### 2.4.2 生态保护的主要目标

生态保护的主要目标包括：

1. **生物多样性保护**：通过设立自然保护区、禁止非法狩猎和贸易等方式，保护珍稀濒危物种和其栖息地。
2. **生态系统修复**：通过植树造林、湿地恢复、荒漠化治理等方式，恢复被破坏的生态系统功能。
3. **污染控制**：通过减少污染物排放、治理污染场地等方式，减少对生态系统的污染。
4. **土地管理**：通过科学规划土地利用、推广可持续农业等方式，减少人类活动对生态系统的压力。

#### 2.4.3 生态保护的主要手段

生态保护的主要手段包括：

1. **法律法规**：通过制定和实施环境保护法律法规，规范人类活动，保护生态环境。
2. **政策措施**：通过政府引导和政策支持，鼓励企业和公众参与生态保护。
3. **科研与教育**：通过科学研究和技术创新，为生态保护提供科学依据和技术支持；通过教育普及，提高公众的生态保护意识。
4. **国际合作**：通过国际组织和多边协议，促进全球范围内的生态保护合作。

#### 2.4.4 生态保护面临的挑战

尽管生态保护的重要性得到了广泛认同，但生态保护仍然面临诸多挑战：

1. **资源开发与生态保护冲突**：在追求经济发展过程中，资源开发往往会对生态系统造成破坏，如何平衡经济发展和生态保护是一个重要课题。
2. **人口增长与生态压力**：随着人口的增长，对自然资源的需求不断增加，给生态系统带来更大的压力。
3. **气候变化**：气候变化导致的极端天气事件和海平面上升，对生态系统的稳定性构成严重威胁。
4. **污染问题**：环境污染问题日益严重，对生物多样性和人类健康造成严重影响。

综上所述，生态保护是一项长期而复杂的任务，需要政府、企业、社会和个人的共同努力，通过多种手段和措施，才能实现生态系统的可持续管理和保护。

### 第三部分：提示词工程原理

#### 3.1 提示词工程基本原理

提示词工程是信息检索和数据分析领域的一种关键技术，其核心思想是通过设计有效的提示词，提高数据检索和分析的效率和质量。提示词工程在智能环境监测中的应用，可以显著提升监测数据的可利用性和监测结果的准确性。

#### 3.1.1 提示词的定义

提示词（Query Terms）是指用于指导用户进行信息检索或数据分析的关键词或短语。在智能环境监测中，提示词是连接数据源和用户需求的重要桥梁，能够帮助用户快速定位和获取所需信息。

#### 3.1.2 提示词的作用

提示词在智能环境监测中的作用主要体现在以下几个方面：

1. **信息检索**：通过设计合适的提示词，用户可以快速定位相关监测数据，提高信息检索的效率。
2. **数据分析**：提示词有助于指导数据挖掘和分析算法，发现数据中的潜在信息和规律，提高数据分析的深度和广度。
3. **决策支持**：基于提示词提取的关键信息，可以为环境管理和生态保护决策提供科学依据，提高决策的准确性和及时性。
4. **数据整合**：通过提示词，可以将来自不同来源、不同格式的数据整合在一起，实现数据的统一管理和分析。

#### 3.1.3 提示词的类型

根据应用场景和目的，提示词可以分为以下几种类型：

1. **自然语言提示词**：这类提示词通常采用自然语言表达，如“空气质量”、“水污染”等，适合用于用户直接输入的检索查询。
2. **专业术语提示词**：这类提示词是特定领域的专业术语，如“氨氮浓度”、“PM2.5”等，适合于专业用户和数据分析师使用。
3. **数字提示词**：这类提示词以数字形式表达，如“2019年”、“5℃”等，常用于时间序列数据的检索和分析。
4. **组合提示词**：这类提示词是由多个关键词组合而成，如“2022年空气质量恶化原因分析”等，可以更精确地定位特定主题的信息。

#### 3.1.4 提示词的设计原则

为了提高提示词的有效性和实用性，设计提示词时应遵循以下原则：

1. **简洁性**：提示词应简洁明了，避免使用过于复杂或冗长的短语。
2. **准确性**：提示词应准确反映用户需求和数据内容，避免模糊不清的表述。
3. **全面性**：提示词应覆盖不同类型的数据和主题，确保能够涵盖用户的各种查询需求。
4. **易用性**：提示词应易于用户理解和记忆，便于在实际应用中快速使用。

#### 3.1.5 提示词工程的基本流程

提示词工程的基本流程通常包括以下几个步骤：

1. **需求分析**：明确用户需求，确定需要检索或分析的数据类型和主题。
2. **提示词设计**：根据需求分析结果，设计一组符合简洁性、准确性、全面性、易用性原则的提示词。
3. **提示词优化**：通过用户行为分析和数据质量评估，对提示词进行优化调整，提高其检索和数据分析效果。
4. **提示词应用**：将设计的提示词应用于智能环境监测系统的信息检索、数据分析和决策支持模块。
5. **效果评估**：对提示词工程的应用效果进行评估，通过用户反馈和数据指标分析，持续改进提示词的设计和应用。

通过以上对提示词工程基本原理的介绍，我们可以看到，提示词工程在智能环境监测中发挥着重要作用，通过合理设计和应用提示词，可以有效提升监测系统的效率和准确性，为生态保护提供有力支持。

### 3.2 提示词设计与生成

#### 3.2.1 提示词设计原则

提示词设计是提示词工程的核心环节，其质量直接影响到智能环境监测系统的效率和效果。为了确保提示词的有效性，设计提示词时需要遵循以下原则：

1. **简洁性**：提示词应简洁明了，避免使用过于复杂或冗长的短语。简洁的提示词易于用户理解和记忆，可以提高用户检索的效率和准确性。
2. **准确性**：提示词应准确反映用户需求和数据内容，避免模糊不清的表述。准确的提示词可以减少检索过程中的歧义，提高数据检索的精度。
3. **全面性**：提示词应覆盖不同类型的数据和主题，确保能够涵盖用户的各种查询需求。全面的提示词设计可以提高数据检索和数据分析的广度。
4. **易用性**：提示词应易于用户理解和记忆，便于在实际应用中快速使用。易用的提示词可以降低用户的学习成本，提高系统的用户友好性。

#### 3.2.2 提示词生成方法

提示词的生成方法可以分为手动生成、自动提取和半自动生成等几种。

1. **手动生成**：手动生成提示词是由专业人员在了解用户需求和数据内容的基础上，通过人工筛选和组合关键词生成的。这种方法适用于小规模、专业化的数据集，可以确保提示词的准确性和专业性，但效率较低。

   **步骤**：
   - 分析用户需求，确定需要检索或分析的数据类型和主题。
   - 阅读数据文档，了解数据内容和结构。
   - 根据数据内容和用户需求，手动设计一组提示词。

2. **自动提取**：自动提取提示词是利用自然语言处理（NLP）和机器学习算法，从大规模数据集中自动提取关键词的方法。这种方法适用于大规模、多样化数据集，可以显著提高提示词生成的效率。

   **步骤**：
   - 数据预处理：对原始文本数据进行清洗、去噪、分词等预处理操作。
   - 关键词提取：利用NLP算法和机器学习模型，从预处理后的数据中提取关键词。
   - 提示词筛选：根据提示词设计原则，对提取的关键词进行筛选和优化，生成最终的提示词集。

3. **半自动生成**：半自动生成提示词是结合手动和自动生成方法的中间方案，通过人工初步设计和自动优化相结合，生成高质量的提示词。

   **步骤**：
   - 初步设计：由专业人员根据用户需求和数据内容，设计一组初步的提示词。
   - 自动优化：利用自动提取算法，对初步设计的提示词进行优化和补充，生成最终的提示词集。

#### 3.2.3 提示词优化策略

提示词生成后，需要进行优化，以提高其检索和数据分析效果。以下是几种常见的提示词优化策略：

1. **基于用户行为的优化**：通过分析用户的检索行为，了解用户对提示词的使用偏好和反馈，对提示词进行调整和改进。这种方法可以根据用户的实际需求，提高提示词的准确性和适用性。

   **方法**：
   - 收集用户检索日志，分析用户的检索关键词、检索频率和检索结果。
   - 根据用户行为数据，对提示词进行筛选、调整和补充，优化提示词集。

2. **基于数据质量的优化**：通过评估数据质量，对提示词进行优化，以提高数据检索和分析的准确性。数据质量包括数据完整性、一致性、准确性和及时性等方面。

   **方法**：
   - 评估数据质量，识别数据中的错误、噪声和缺失值。
   - 根据数据质量评估结果，对提示词进行筛选、修正和补充，优化提示词集。

3. **基于主题模型的优化**：利用主题模型（如LDA）分析数据内容的主题分布，根据主题分布对提示词进行调整和优化，以覆盖更多主题和满足用户需求。

   **方法**：
   - 应用主题模型对数据内容进行主题分析，识别数据中的主要主题。
   - 根据主题分布，对提示词进行分类和调整，确保提示词能够覆盖主要主题。

4. **基于机器学习的优化**：利用机器学习算法（如回归分析、聚类分析等），对提示词的效果进行评估和优化。

   **方法**：
   - 收集提示词和检索效果的数据集，应用机器学习算法对提示词进行评估和优化。
   - 根据评估结果，对提示词进行筛选、调整和优化，提高提示词的检索效果。

**示例代码**：

```python
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 数据集加载
data = pd.read_csv('environment_data.csv')

# 提示词设计
query_terms = ["空气质量", "水质污染", "森林火灾"]

# 数据预处理
def preprocess_data(data):
    # 清洗和去噪处理
    data['text'] = data['description'].str.replace('[^\w\s]', '', regex=True)
    return data

preprocessed_data = preprocess_data(data)

# 提示词向量表示
def generate_query_vector(query_terms):
    vectorizer = TfidfVectorizer()
    query_vector = vectorizer.fit_transform([' '.join(query_terms)])
    return query_vector

query_vector = generate_query_vector(query_terms)

# 数据向量表示
def generate_data_vector(data):
    vectorizer = TfidfVectorizer()
    data_vector = vectorizer.fit_transform(data['text'])
    return data_vector

data_vector = generate_data_vector(preprocessed_data['text'])

# 相似度计算
def calculate_similarity(query_vector, data_vector):
    similarity_scores = cosine_similarity(query_vector, data_vector)
    return similarity_scores

similarity_scores = calculate_similarity(query_vector, data_vector)

# 提示词匹配与数据检索
def retrieve_data(similarity_scores, threshold=0.5):
    matched_indices = [index for index, score in enumerate(similarity_scores[0]) if score > threshold]
    matched_data = preprocessed_data.iloc[matched_indices]
    return matched_data

matched_data = retrieve_data(similarity_scores)

# 输出结果
print(matched_data)
```

**代码解读**：

1. **数据集加载**：
   使用Pandas库加载环境监测数据集。数据集应包含描述性的文本字段，如“description”。

2. **提示词设计**：
   设计一组包含关键词的提示词，如“空气质量”、“水质污染”和“森林火灾”。

3. **数据预处理**：
   对文本数据进行清洗，去除文本中的特殊字符，以提高向量表示的准确性。

4. **提示词向量表示**：
   使用TF-IDF向量器（TfidfVectorizer）将提示词转换为向量表示。TF-IDF是一种常用的文本特征提取方法，能够有效反映词的重要性和相关性。

5. **数据向量表示**：
   对环境监测文本数据集进行同样的向量表示处理。

6. **相似度计算**：
   使用余弦相似度（cosine_similarity）计算提示词向量与数据向量之间的相似度。余弦相似度是一种衡量两个向量夹角余弦值的度量，用于评估文本之间的相似程度。

7. **提示词匹配与数据检索**：
   根据设定的阈值（如0.5），筛选出与提示词相似度较高的数据记录。这些记录被视为匹配结果，并输出匹配的数据集。

**代码应用解读与分析**：

1. **数据预处理**：
   数据预处理是文本向量表示的重要步骤。通过去除文本中的特殊字符，可以降低文本中的噪声，提高向量表示的准确性。

2. **向量表示与相似度计算**：
   提示词和数据的向量表示是基于TF-IDF方法，能够有效反映文本中的关键词重要性和相关性。余弦相似度计算则用于评估提示词与数据之间的匹配程度。

3. **检索效果评估**：
   通过设定合适的阈值，可以控制匹配结果的精确度和召回率。阈值越高，匹配结果越精确，但召回率可能较低；阈值较低，则匹配结果更多，但可能包含噪声数据。

4. **扩展性**：
   该示例代码具有良好的扩展性，可以轻松集成到更复杂的环境监测系统中。通过调整提示词和阈值，可以适应不同的应用场景和数据集。

def preprocess_text(text):
    # 清洗文本
    text = text.lower()
    text = re.sub(r'\W+', ' ', text)
    # 分词
    words = nltk.word_tokenize(text)
    # 去停用词
    stop_words = set(nltk.corpus.stopwords.words('english'))
    words = [word for word in words if word not in stop_words]
    # 词干提取
    words = [nltk.stem.porter.PorterStemmer().stem(word) for word in words]
    return ' '.join(words)

# 文本向量表示
def vectorize_text(texts):
    vectorizer = TfidfVectorizer()
    vectors = vectorizer.fit_transform(texts)
    return vectors

##### 7.4.5 数学模型与公式

以下是一些在提示词工程中常用的数学模型和公式：

1. **TF-IDF公式**：
   $$ \text{TF-IDF}(t, d) = \frac{\text{TF}(t, d)}{\text{DF}(t)} + \log \frac{N}{\text{DF}(t)} $$
   - **TF**（词频）: 单词在文档中出现的频率。
   - **IDF**（逆文档频率）: 反映单词的重要程度。
   - **N**：文档总数。
   - **DF**（词频）: 单词在文档集合中出现的频率。

2. **余弦相似度**：
   $$ \text{cosine_similarity}(v_1, v_2) = \frac{v_1 \cdot v_2}{\lVert v_1 \rVert \lVert v_2 \rVert} $$
   - **$v_1$和$v_2$**：两个向量。
   - **$\cdot$**：点积。
   - **$\lVert \cdot \rVert$**：向量范数。

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 加载数据
data = pd.read_csv('environment_data.csv')

# 提示词
query_terms = ["空气质量", "水质污染"]

# 预处理
data['text'] = data['description'].str.replace('[^\w\s]', '', regex=True)

# 提取特征向量
vectorizer = TfidfVectorizer()
data_vector = vectorizer.fit_transform(data['text'])

# 提取查询向量
query_vector = vectorizer.transform([' '.join(query_terms)])

# 计算相似度
similarity_scores = cosine_similarity(query_vector, data_vector)

# 选择相似度最高的数据
top_n = 5
matched_indices = similarity_scores[0].argsort()[-top_n:][::-1]
matched_data = data.iloc[matched_indices]

# 输出匹配结果
print(matched_data)
```
