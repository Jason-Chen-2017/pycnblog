Input: 约束矩阵 A, 目标向量 b, 变量数量 n
Output: 最优解 x

function InteriorPoint(A, b, n):

    x = RandomInitialSolution()
    p = RandomDirection()

Output: 最优解 x*

function GradientDescent(x, α, iter_max):

    x_current = x

    for i = 1 to iter_max:

    // 没有可行解
