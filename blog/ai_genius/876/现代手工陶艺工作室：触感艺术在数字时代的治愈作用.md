$$

其中，实际使用面积是指工作室中被用于制作、展示和存储陶艺作品的面积，总面积是工作室的总面积。

#### 7.2 源代码实现

```python
import time
import serial

def print_3d_model(file_path):
    # 打开3D打印机端口
    with serial.Serial('COM3', 115200) as printer:
        # 发送G代码到打印机
        with open(file_path, 'r') as model_file:
            for line in model_file:
                printer.write(line.encode())

        # 打印完成后，关闭端口
        printer.close()

# 打印指定文件路径的3D模型
print_3d_model('model.gcode')
```
