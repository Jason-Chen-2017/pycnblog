## 算法效率基础

### 算法效率核心概念

### 常见算法效率指标
常见算法效率指标包括最坏情况时间复杂度、平均时间复杂度和最好情况时间复杂度。最坏情况时间复杂度是指算法在输入数据最不利情况下的执行时间；平均时间复杂度是指算法在所有可能输入数据情况下的执行时间平均值；最好情况时间复杂度是指算法在输入数据最优情况下的执行时间。

### 算法效率与时间复杂度关系
算法效率与时间复杂度密切相关。一个高效率的算法通常具有较低的时间复杂度。例如，线性查找算法的时间复杂度为O(n)，而二分查找算法的时间复杂度为O(log n)，显然二分查找算法的效率更高。因此，在算法设计中，我们应关注算法的时间复杂度，以提升算法效率。

## 算法优化方法

### 优化算法原理
优化算法是指通过改进算法设计，提高算法效率的方法。常见的优化算法包括贪心算法、动态规划、分治算法等。贪心算法通过每一步选择局部最优解，逐步逼近全局最优解；动态规划通过将问题划分为子问题，并利用子问题的解构建原问题的解；分治算法通过将问题划分为较小的子问题，递归求解并合并子问题的解。

### 优化算法分类
优化算法可以按照优化目标进行分类，包括最小化时间复杂度、最大化空间复杂度、最小化能源消耗等。例如，贪心算法主要用于最小化时间复杂度，动态规划主要用于最小化时间复杂度和空间复杂度。

### 实例：贪心算法、动态规划
贪心算法是一种简单有效的优化算法，常用于求解最短路径、最小生成树等问题。以下是一个贪心算法求解最短路径问题的伪代码：
```python
def greedy_shortest_path(graph, start):
    visited = set()
    path = [start]
    while start not in visited:
        visited.add(start)
        start = min(graph[start], key=graph[start].get)
        path.append(start)
    return path
```
动态规划是一种递归求解问题的优化算法，常用于求解最短路径、最长公共子序列等问题。以下是一个动态规划求解最短路径问题的伪代码：
```python
def dynamic_shortest_path(graph, start, end):
    dp = [[float('inf') for _ in range(len(graph))] for _ in range(len(graph))]
    dp[start][end] = 0
    for i in range(len(graph)):
        for j in range(len(graph)):
            for k in range(len(graph)):
                dp[i][j] = min(dp[i][j], dp[i][k] + graph[k][j])
    return dp[start][end]
```

    n = len(arr)

        for j in range(0, n-i-1):

    return arr
