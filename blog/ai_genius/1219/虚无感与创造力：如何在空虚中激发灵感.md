#### 3.2.4 代码示例：文本分析

文本分析是另一种可以帮助激发创造力的工具。以下是一个简单的Python代码示例，用于分析一篇文章的关键词和主题，帮助读者深入理解文本内容，从而激发新的灵感。

```python
import nltk
from nltk.tokenize import word_tokenize
from collections import Counter

# 加载nltk资源
nltk.download('punkt')

# 假设我们有一段文本
text = """虚无感与创造力之间的关系复杂而微妙。通过本文的探讨，我们了解到虚无感既可能成为抑制创造力的障碍，也可能成为激发灵感的契机。在实际生活中，个体可以通过积极的策略和管理方法，将虚无感转化为创造力，从而实现自我价值的提升。未来，随着对虚无感和创造力研究的不断深入，我们有望为个体提供更有效的管理和激发策略，促进社会的发展和进步。"""

# 分词
tokens = word_tokenize(text)

# 计算词频
word_freq = Counter(tokens)

# 打印前10个高频词
for word, freq in word_freq.most_common(10):
    print(f"{word}: {freq}")

# 分析关键词和主题
key_words = ["虚无感", "创造力", "策略", "管理", "研究", "社会", "发展"]
for word in key_words:
    print(f"{word} 分析：")
    if word in tokens:
        print(f"- {word}在文本中出现了{tokens.count(word)}次，是本文的核心概念之一。")
    else:
        print(f"- {word}在文本中没有出现，但与本文主题密切相关。")
```

该代码使用nltk库对文本进行分词，并计算每个词的频率，从而识别出文本中的关键词和主题。通过这种文本分析方法，读者可以更好地理解和掌握文章的核心内容，从而激发新的思考和创新。

#### 3.2.5 代码示例：项目实战

以下是一个简单的项目实战示例，用于解释如何在虚拟环境中搭建一个简单的创造力激发平台。该平台包括用户界面、文本分析模块和灵感生成模块。

```python
# 导入所需的库
import tkinter as tk
from tkinter import scrolledtext
from text_analysis import TextAnalysis

# 创建一个简单的文本分析工具类
class CreativityPlatform:
    def __init__(self, master):
        self.master = master
        self.master.title("创造力激发平台")
        
        # 创建文本输入框
        self.text_input = scrolledtext.ScrolledText(master, wrap=tk.WORD, width=50, height=10)
        self.text_input.pack(pady=10)
        
        # 创建分析按钮
        self.analyze_button = tk.Button(master, text="分析文本", command=self.analyze_text)
        self.analyze_button.pack(pady=5)
        
        # 创建结果显示框
        self.result_output = scrolledtext.ScrolledText(master, wrap=tk.WORD, width=50, height=10)
        self.result_output.pack(pady=10)
        
    def analyze_text(self):
        text = self.text_input.get(1.0, tk.END)
        analysis = TextAnalysis(text)
        result = analysis.analyze()
        self.result_output.delete(1.0, tk.END)
        self.result_output.insert(tk.END, result)

# 创建主窗口
root = tk.Tk()
app = CreativityPlatform(root)

# 运行程序
root.mainloop()
```

在这个示例中，我们创建了一个简单的文本分析工具，用户可以输入一段文本，然后通过分析按钮生成文本分析结果。这个平台结合了文本分析和灵感生成的功能，帮助用户更好地理解和激发创造力。
