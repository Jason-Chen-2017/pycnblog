#### 3.1 图像增强算法

图像增强是提升图像质量的重要技术，特别是在简约主义美食摄影中，图像的清晰度和对比度直接影响视觉营销效果。

**3.1.1 直方图均衡化**

直方图均衡化是一种常见的图像增强方法，它通过调整图像的像素分布，增强图像的对比度。

**算法原理：**

$$
\text{直方图均衡化} = \frac{\sum_{i=0}^{255} f(i) \cdot (L - i)}{\sum_{i=0}^{255} f(i)}
$$

其中，$f(i)$ 是原图的直方图，$L$ 是图像的像素级数（通常为256）。

**Python代码实现：**

```python
import cv2
import numpy as np

def histogram_equalization(image):
    image_yuv = cv2.cvtColor(image, cv2.COLOR_BGR2YUV)
    image_yuv[:, :, 0] = cv2.equalizeHist(image_yuv[:, :, 0])
    image_result = cv2.cvtColor(image_yuv, cv2.COLOR_YUV2BGR)
    return image_result

image = cv2.imread('example.jpg')
```

#### 3.2 色彩调整算法

色彩调整是简约主义美食摄影中的另一个关键步骤，它有助于营造简约而和谐的美学效果。

**3.2.1 色彩平衡**

色彩平衡是一种通过调整图像的色相、饱和度和亮度来改善图像色彩的技术。

**算法原理：**

$$
\text{色彩平衡} = \left( \frac{\text{色相}}{\text{饱和度}} \right) \cdot \text{亮度}
$$

**Python代码实现：**

```python
def color_balance(image, hue, saturation, brightness):
    image_hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)
    image_hsv[:, :, 0] = (image_hsv[:, :, 0].astype(int) + hue) % 180
    image_hsv[:, :, 1] = np.clip(image_hsv[:, :, 1] * saturation, 0, 1)
    image_hsv[:, :, 2] = np.clip(image_hsv[:, :, 2] * brightness, 0, 1)
    image_result = cv2.cvtColor(image_hsv, cv2.COLOR_HSV2BGR)
    return image_result
```

#### 3.3 滤波算法

滤波是图像处理中的基础操作，用于去除图像中的噪声，增强图像的细节。

**3.3.1 高斯滤波**

高斯滤波是一种常用的图像平滑技术，它利用高斯函数对图像进行卷积，以去除高频噪声。

**算法原理：**

$$
\text{高斯滤波} = \frac{1}{2\pi\sigma^2} e^{-\frac{(x-y)^2}{2\sigma^2}}
$$

**Python代码实现：**

```python
def gaussian_filter(image, sigma=1.0):
    kernel = cv2.getGaussianKernel(ksize=5, sigma=sigma)
    image_filtered = cv2.filter2D(image, -1, kernel)
    return image_filtered

image = cv2.imread('example.jpg', cv2.IMREAD_GRAYSCALE)
image_enhanced = gaussian_filter(image, sigma=1.5)
```
