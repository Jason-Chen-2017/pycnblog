### 第2章：图计算基础

#### 2.1 图论基础

图论是图计算的理论基础，主要研究图及其性质。在图论中，图（Graph）是由节点（Vertex）和边（Edge）组成的数学结构。节点代表数据实体，边表示实体之间的关系。

图的分类：

- **无向图**：边没有方向，如社交网络中的好友关系。
- **有向图**：边有方向，如网站之间的链接。
- **加权图**：边附带权重，如道路网络中的距离或交通量。

基本术语：

- **度**：节点拥有的边数，分为入度和出度。
- **路径**：节点序列，满足连续节点之间存在边。
- **连通性**：图中任意两个节点之间都存在路径。
- **连通分量**：图中所有连通节点的集合。

#### 2.2 图数据库介绍

图数据库（Graph Database）是专门用于存储、查询和处理的图结构数据的数据库系统。与关系型数据库不同，图数据库直接以图结构存储数据，通过节点和边之间的关系来查询和操作数据。

常见的图数据库：

- **Neo4j**：支持Cypher查询语言，功能强大，易于使用。
- **JanusGraph**：支持多种存储后端，如Cassandra、HBase等，适用于大规模分布式系统。
- **ArangoDB**：支持文档、图形和键值存储，功能丰富。

#### 2.3 图算法简介

图算法是图论在计算机科学中的具体应用，用于解决各种与图相关的计算问题。常见的图算法包括：

- **PageRank**：一种评估网页重要性的算法，基于链接分析。
- **单源最短路径**：找出从一个节点到所有其他节点的最短路径。
- **多源最短路径**：找出所有节点之间的最短路径。
- **社区检测**：找出图中的紧密连接的节点集合。
- **图同构**：判断两个图是否结构相同。

### 第3章：图计算核心概念

#### 3.1 核心概念原理

图计算涉及多个核心概念，这些概念构成了图计算的理论基础。

1. **节点（Node）**：图中的数据实体，代表具体的数据对象，如人、物品、地点等。
2. **边（Edge）**：节点之间的连接，表示节点之间的关系，如好友关系、供应链关系等。
3. **属性（Attribute）**：附加在节点或边上的信息，如人的年龄、物品的价格等。
4. **路径（Path）**：节点序列，满足连续节点之间存在边。
5. **图（Graph）**：由节点和边组成的结构，表示数据的整体关系。
6. **子图（Subgraph）**：从原图中提取的部分节点和边构成的图。

#### 3.2 概念属性特征对比表格

| 概念       | 定义                                                         | 属性特征对比       |
|------------|--------------------------------------------------------------|-------------------|
| 节点       | 图中的数据实体                                             | ID、属性、度      |
| 边         | 节点之间的连接                                             | 权重、方向        |
| 属性       | 附加在节点或边上的信息                                     | 类型、值          |
| 路径       | 节点序列，满足连续节点之间存在边                           | 长度、路径类型    |
| 图         | 由节点和边组成的结构，表示数据的整体关系                    | 连通性、密度      |
| 子图       | 从原图中提取的部分节点和边构成的图                         | 完整性、独立性    |

#### 3.3 ER实体关系图架构

实体关系图（Entity-Relationship Diagram，ERD）是用于表示实体及其关系的图形化工具。在图计算中，ERD可以帮助我们理解和设计图结构。

ERD的基本元素：

- **实体（Entity）**：代表具体的数据对象，如人、物品、地点等。
- **关系（Relationship）**：表示实体之间的关联。
- **属性（Attribute）**：附加在实体或关系上的信息。

ERD的表示方法：

- **实体**：用矩形表示，包含实体名和属性。
- **关系**：用菱形表示，连接两个或多个实体，包含关系名和属性。
- **属性**：用椭圆表示，附加在实体或关系的边上。

### 第4章：图算法原理与应用

#### 4.1 PageRank算法

PageRank是一种评估网页重要性的算法，由Google创始人拉里·佩奇和谢尔盖·布林提出。PageRank基于网页之间的链接关系，通过迭代计算每个网页的排名。

算法原理：

1. **初始化**：每个网页的初始排名相等。
2. **迭代计算**：每次迭代，网页的排名由其链接来源网页的排名加权计算。
3. **收敛**：当排名变化小于某个阈值时，算法收敛。

数学模型：

$$
PR(A) = \left(\frac{1-d}{N}\right) + d \cdot \left(\sum_{B \in I(A)} \frac{PR(B)}{out(B)}\right)
$$

其中，$PR(A)$表示网页A的排名，$d$为阻尼系数（通常取0.85），$N$为网页总数，$I(A)$表示链接到网页A的网页集合，$out(B)$表示网页B的出度。

应用示例：

假设有4个网页A、B、C、D，其初始排名均为1。经过几次迭代，排名结果如下：

- **第一次迭代**：
  - $PR(A) = \left(\frac{1-0.85}{4}\right) + 0.85 \cdot \left(\frac{PR(B)}{1} + \frac{PR(C)}{1} + \frac{PR(D)}{1}\right)$
  - 同理计算$PR(B)$、$PR(C)$、$PR(D)$
- **第二次迭代**：
  - 使用第一次迭代的结果，再次进行计算，直到排名稳定。

通过PageRank算法，网页A的重要性较高，因为它获得了其他重要网页的链接。

#### 4.2 单源最短路径算法

单源最短路径算法用于计算从一个源节点到所有其他节点的最短路径。Dijkstra算法和Bellman-Ford算法是常用的单源最短路径算法。

Dijkstra算法：

1. **初始化**：设置源节点的距离为0，其他节点的距离为无穷大。
2. **选择未处理的节点**：每次选择距离最小的未处理节点。
3. **更新距离**：对于每个邻居节点，计算从源节点到邻居节点的距离，如果更短则更新距离。
4. **重复步骤2和3**，直到所有节点都被处理。

Python代码实现：

```python
import heapq

def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)

        if current_distance > distances[current_node]:
            continue

        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight

            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

应用示例：

假设有一个加权图，节点之间的边权重如下：

```
{
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1}
}
```

从节点A开始计算最短路径：

- $d(A) = 0$
- $d(B) = 1$
- $d(C) = 4$
- $d(D) = \infty$
- 更新：$d(B) = 1$，$d(C) = 1 + 4 = 5$
- 更新：$d(C) = 1$
- 更新：$d(D) = 1 + 1 = 2$
- 最终结果：$d(A) = 0$，$d(B) = 1$，$d(C) = 1$，$d(D) = 2$

从节点A到节点D的最短路径为A -> B -> D，总距离为2。

Bellman-Ford算法：

1. **初始化**：设置源节点的距离为0，其他节点的距离为无穷大。
2. **迭代**：对于每个边，如果经过该边可以到达的目标节点的距离更短，则更新距离。
3. **检测负环**：如果经过V-1次迭代后，仍然存在距离更短的路径，则图中存在负环。

Python代码实现：

```python
def bellman_ford(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0

    for _ in range(len(graph) - 1):
        for u in graph:
            for v, weight in graph[u].items():
                if distances[u] + weight < distances[v]:
                    distances[v] = distances[u] + weight

    for u in graph:
        for v, weight in graph[u].items():
            if distances[u] + weight < distances[v]:
                raise ValueError("图中存在负环")

    return distances
```

应用示例同上。

#### 4.3 多源最短路径算法

多源最短路径算法用于计算所有节点之间的最短路径。Floyd-Warshall算法是常用的多源最短路径算法。

算法原理：

1. **初始化**：设置距离矩阵，对角线为0，其他元素为无穷大。
2. **迭代**：对于每个中间节点k，更新节点i到节点j的距离，如果经过k的距离更短，则更新。
3. **收敛**：当距离矩阵不再变化时，算法收敛。

数学模型：

$$
d_{ij} = \min(d_{ij}, d_{ik} + d_{kj})
$$

Python代码实现：

```python
def floyd_warshall(graph):
    distances = [[float('infinity') for _ in range(len(graph))] for _ in range(len(graph))]

    for i in range(len(graph)):
        distances[i][i] = 0

    for u in range(len(graph)):
        for v, weight in graph[u].items():
            distances[u][v] = weight

    for k in range(len(graph)):
        for i in range(len(graph)):
            for j in range(len(graph)):
                if distances[i][k] + distances[k][j] < distances[i][j]:
                    distances[i][j] = distances[i][k] + distances[k][j]

    return distances
```

应用示例：

假设有一个加权图，节点之间的边权重如下：

```
{
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1}
}
```

计算所有节点之间的最短路径：

```
[
    [0, 1, 5, 4],
    [1, 0, 3, 2],
    [5, 3, 0, 1],
    [4, 2, 1, 0]
]
```

从节点A到节点D的最短路径为A -> B -> D，总距离为2。
