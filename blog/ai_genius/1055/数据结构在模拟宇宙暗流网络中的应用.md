#### 1.1 数据结构概述

数据结构是计算机存储、组织数据的方式。它是计算机科学中一个核心概念，直接影响算法的性能和效率。基本数据结构包括线性结构（如数组、链表）、树形结构（如二叉树、平衡二叉树）和图结构（如无向图、有向图）。这些数据结构各自有其独特的应用场景和特点。

#### 1.2 基本数据结构

##### 1.2.1 线性结构

线性结构是最基本的数据结构，数据元素按照一定的顺序排列。常见的线性结构有数组、链表、栈和队列。

- **数组**：数组是一种固定大小的线性结构，每个元素可以通过索引直接访问。数组操作通常包括插入、删除和查找。
  
  ```python
  arr = [1, 2, 3, 4, 5]
  print(arr[2])  # 输出 3
  ```

- **链表**：链表是由一系列节点组成的线性结构，每个节点包含数据和指向下一个节点的指针。链表操作包括插入、删除和遍历。

  ```python
  class Node:
      def __init__(self, data):
          self.data = data
          self.next = None

  head = Node(1)
  second = Node(2)
  head.next = second
  print(second.data)  # 输出 2
  ```

- **栈**：栈是一种后进先出（LIFO）的线性结构。常见的栈操作包括入栈、出栈和遍历。

  ```python
  class Stack:
      def __init__(self):
          self.items = []

      def push(self, item):
          self.items.append(item)

      def pop(self):
          return self.items.pop()

  stack = Stack()
  stack.push(1)
  stack.push(2)
  print(stack.pop())  # 输出 2
  ```

- **队列**：队列是一种先进先出（FIFO）的线性结构。常见的队列操作包括入队、出队和遍历。

  ```python
  class Queue:
      def __init__(self):
          self.items = []

      def enqueue(self, item):
          self.items.insert(0, item)

      def dequeue(self):
          return self.items.pop()

  queue = Queue()
  queue.enqueue(1)
  queue.enqueue(2)
  print(queue.dequeue())  # 输出 1
  ```

##### 1.2.2 树形结构

树形结构是一种层次结构，由节点和边组成。常见的树形结构有二叉树、哈夫曼树和并查集。

- **二叉树**：二叉树是每个节点最多有两个子树的树结构。常见的二叉树操作包括插入、删除和遍历。

  ```python
  class TreeNode:
      def __init__(self, value):
          self.value = value
          self.left = None
          self.right = None

  root = TreeNode(1)
  root.left = TreeNode(2)
  root.right = TreeNode(3)
  print(root.left.value)  # 输出 2
  ```

- **哈夫曼树**：哈夫曼树是一种最优二叉树，用于数据压缩。哈夫曼树的构建算法是哈夫曼编码的基础。

- **并查集**：并查集是一种用于解决动态连通性问题数据结构。它通过合并和查找操作来维护集合的状态。

##### 1.2.3 图结构

图是一种由节点和边组成的集合。图结构用于描述复杂的关系和连接。常见的图结构包括无向图和有向图。

- **图的基本概念**：节点（或顶点）、边和路径。
  
- **图的存储结构**：邻接矩阵和邻接表。

- **图的遍历算法**：深度优先搜索（DFS）和广度优先搜索（BFS）。

#### 1.3 复杂数据结构

复杂数据结构是基本数据结构的扩展和应用。常见的复杂数据结构有散列表、平衡二叉树等。

- **散列表**：散列表通过哈希函数将数据映射到数组的位置。散列表操作包括插入、删除和查找。
  
- **平衡二叉树**：平衡二叉树（如AVL树、红黑树）是保持平衡的二叉树。平衡二叉树操作包括插入、删除和查找，具有O(log n)的时间复杂度。

      def __init__(self):
          self.nodes = {}
          self.edges = {}

      def add_edge(self, u, v):
          if u not in self.nodes:
              self.nodes[u] = []
          if v not in self.nodes:
              self.nodes[v] = []
          self.nodes[u].append(v)
          self.nodes[v].append(u)

      def dfs(self, node, visited, path):
          visited.add(node)
          path.append(node)
          for neighbor in self.nodes[node]:
              if neighbor not in visited:
                  self.dfs(neighbor, visited, path)

      def find_path(self, start, end):
          visited = set()
          path = []
          self.dfs(start, visited, path)
          return path

  graph = Graph()

  graph.add_edge("B", "C")
  graph.add_edge("C", "D")

  class Graph:
      def __init__(self):

      def add_edge(self, u, v):
          if u not in self.nodes:
              self.nodes[u] = []
          if v not in self.nodes:
              self.nodes[v] = []
          self.nodes[u].append(v)
          self.nodes[v].append(u)

      def dfs(self, node, visited, path):
          visited.add(node)
          path.append(node)
          for neighbor in self.nodes[node]:
              if neighbor not in visited:
                  self.dfs(neighbor, visited, path)

      def find_path(self, start, end):
          visited = set()
          path = []
          self.dfs(start, visited, path)
          return path
