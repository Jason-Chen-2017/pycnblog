#### 图论基础

在宇宙模型中，图论作为一种强大的数学工具，被广泛应用于描述星系之间的复杂关系。图论中的基本概念和算法为宇宙模型提供了有效的分析方法和工具。以下我们将详细探讨图论的基本概念、图的基本表示方法、图的基本性质以及图的遍历算法。

##### 图的基本概念

图（Graph）是由顶点（Vertex）和边（Edge）组成的数学结构。顶点表示图中的基本元素，如星系或节点，而边表示顶点之间的连接关系，如星系之间的引力相互作用。图可以分为无向图（Undirected Graph）和有向图（Directed Graph）。无向图的边没有方向，而有向图的边有方向，表示顶点之间的单向关系。

- **顶点**：图中的基本元素，如星系或节点。
- **边**：连接顶点的线段，表示顶点之间的关系。

##### 图的基本表示方法

图可以用多种方式表示，其中常见的有邻接矩阵（Adjacency Matrix）和邻接表（Adjacency List）。

- **邻接矩阵**：用二维数组表示图，矩阵中的元素表示顶点之间的连接关系。如果顶点i和顶点j之间存在边，则矩阵中的位置（i, j）为1，否则为0。邻接矩阵适用于稀疏图，即边数远小于顶点数的图。

- **邻接表**：用链表或数组表示图，每个顶点对应一个链表或数组，链表或数组中的元素表示与该顶点相连的其他顶点。邻接表适用于稠密图，即边数接近顶点数的图。

##### 图的基本性质

图的基本性质包括连通性、路径、圈等。

- **连通性**：图中的任意两个顶点之间都存在路径，则称该图为连通图。连通性是图的重要性质，它决定了星系之间的相互作用是否可能。
- **路径**：图中的顶点序列，其中任意两个相邻顶点之间存在边，则称该序列为路径。路径长度表示顶点之间的距离。
- **圈**：图中的一条闭合路径，其起点和终点相同，且路径上的所有顶点都不重复，则称该路径为圈。圈在宇宙模型中可以表示星系之间的引力束缚关系。

##### 图的遍历算法

图的遍历算法用于遍历图中的所有顶点和边，常见的遍历算法有深度优先搜索（DFS）和广度优先搜索（BFS）。

- **深度优先搜索（DFS）**：从某个顶点开始，尽可能深地搜索图，直到到达无法继续搜索的顶点，然后回溯到上一个顶点，并继续搜索其他未访问的路径。DFS适用于寻找路径和解决拓扑排序问题。
  
  ```python
  def dfs(graph, start):
      visited = set()
      stack = [start]

      while stack:
          vertex = stack.pop()
          if vertex not in visited:
              visited.add(vertex)
              print(vertex)  # 执行实际操作
              stack.extend(graph[vertex] - visited)
  ```

- **广度优先搜索（BFS）**：从某个顶点开始，逐层遍历图中的顶点，每层顶点的邻接点都按顺序访问。BFS适用于寻找最短路径和解决层序遍历问题。

  ```python
  def bfs(graph, start):
      visited = set()
      queue = deque([start])
      while queue:
          vertex = queue.popleft()
          if vertex not in visited:
              visited.add(vertex)
              print(vertex)  # 执行实际操作
              queue.extend(graph[vertex] - visited)
  ```

在宇宙模型的构建和分析中，树结构算法扮演着至关重要的角色。树结构是一种重要的非线性数据结构，能够高效地表示和操作层次化的数据。以下将详细探讨树结构的基本概念、基本算法，以及这些算法在宇宙模型中的应用。

##### 树的基本概念

树（Tree）是一种由节点（Node）组成的层次化数据结构，其中每个节点只有一个父节点（Root），除了根节点外，其他每个节点有零个或多个子节点。树的基本概念包括节点、父节点、子节点、叶子节点、树的高度和深度。

- **节点**：树中的基本元素，每个节点包含数据和一个指向子节点的指针。
- **父节点**：节点的直接上级节点。
- **子节点**：节点的直接下级节点。
- **叶子节点**：没有子节点的节点。
- **树的高度**：根节点到最远叶子节点的最长路径长度。
- **树的深度**：节点的层级深度，根节点的深度为0。

##### 树的基本算法

树结构的基本算法包括遍历算法、插入算法、删除算法和平衡树算法。

- **遍历算法**：用于访问树中的所有节点，常见的遍历算法有先序遍历、中序遍历和后序遍历。

  - **先序遍历**（Pre-order Traversal）：首先访问根节点，然后递归遍历左子树，最后递归遍历右子树。

    ```python
    def pre_order(node):
        if node is not None:
            print(node.val)  # 执行实际操作
            pre_order(node.left)
            pre_order(node.right)
    ```

  - **中序遍历**（In-order Traversal）：首先递归遍历左子树，然后访问根节点，最后递归遍历右子树。

    ```python
    def in_order(node):
        if node is not None:
            in_order(node.left)
            print(node.val)  # 执行实际操作
            in_order(node.right)
    ```

  - **后序遍历**（Post-order Traversal）：首先递归遍历左子树，然后递归遍历右子树，最后访问根节点。

    ```python
    def post_order(node):
        if node is not None:
            post_order(node.left)
            post_order(node.right)
            print(node.val)  # 执行实际操作
    ```

- **插入算法**：用于在树中插入新的节点，常见的插入算法包括按序插入和二叉搜索树插入。

  - **按序插入**：按照节点的值顺序插入，适用于有序树。

    ```python
    def insert_ordered(node, value):
        if node is None:
            return TreeNode(value)
        if value < node.val:
            node.left = insert_ordered(node.left, value)
        else:
            node.right = insert_ordered(node.right, value)
        return node
    ```

  - **二叉搜索树插入**：根据节点的值插入到二叉搜索树中，适用于二叉搜索树。

    ```python
    def insert_bst(root, value):
        if root is None:
            return TreeNode(value)
        if value < root.val:
            root.left = insert_bst(root.left, value)
        else:
            root.right = insert_bst(root.right, value)
        return root
    ```

Dijkstra算法是一种用于寻找图中两点之间最短路径的算法，适用于黑洞模拟中星系之间的引力路径计算。

```python
import heapq

def dijkstra(graph, start):
    distances = {vertex: float('infinity') for vertex in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)

        if current_distance > distances[current_vertex]:
            continue

        for neighbor, weight in graph[current_vertex].items():
            distance = current_distance + weight

            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

**1. 数组**

- **存储空间**：数组是一种固定大小的数据结构，需要预分配存储空间。对于大规模数据集，预分配过多存储空间可能导致浪费，而预分配过少则可能导致频繁的内存重分配。

- **操作复杂性**：数组的插入和删除操作通常需要移动后续元素，因此时间复杂度为O(n)。

**2. 链表**

- **存储空间**：链表是一种动态数据结构，可以根据需要分配和释放内存。这使得它在处理动态数据集时非常灵活。

**4. 图结构**

- **存储空间**：图结构如邻接矩阵和邻接表，可以根据图的密度选择。邻接矩阵适用于稀疏图，而邻接表适用于稠密图。

```python
    def simulate_motion(self, time_step, num_steps):
        for _ in range(num_steps):
            self.simulate_gravity(time_step)
            for star in self.stars:
                star.position += star.velocity * time_step

# 创建宇宙实例
universe = Universe()

# 添加星系
star1 = Star(1e30, np.array([0, 0]), np.array([0, 1e-10]))
star2 = Star(2e30, np.array([1e21, 0]), np.array([-1e-10, 0]))
universe.add_star(star1)
universe.add_star(star2)

# 模拟宇宙运动
universe.simulate_motion(1e6, 1000)
```

**代码解读与分析**

上述代码首先定义了星系类（`Star`）和宇宙类（`Universe`）。`Star`类包含星系的属性，如质量、位置和速度。`Universe`类用于管理星系，包括添加和删除星系的方法，以及模拟引力相互作用和星系运动的方法。

- **引力模拟**：`simulate_gravity`方法使用牛顿引力定律计算星系之间的引力，并更新星系的速度。通过双重循环遍历星系，计算每一对星系之间的引力作用。
- **运动模拟**：`simulate_motion`方法使用更新后的速度来计算星系的位置，模拟星系的运动。
