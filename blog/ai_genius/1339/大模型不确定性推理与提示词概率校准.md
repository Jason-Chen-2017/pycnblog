2.2.2 **最大后验推理**

最大后验推理是一种基于贝叶斯推理的优化方法，它通过最大化后验概率，找到最有可能的输出结果。最大后验推理可以用于模型参数估计和分类问题。

2.2.3 **信念传播算法**

信念传播算法是一种用于概率图模型推理的迭代算法，它通过传递概率信息，计算每个变量的后验概率。信念传播算法广泛应用于图像处理、自然语言处理和计算机视觉等领域。

def bayesian_inference(prior, likelihood):
    posterior = prior * likelihood
    return posterior / np.sum(posterior)

prior = np.array([0.4, 0.6])
likelihood = np.array([[0.8, 0.2], [0.1, 0.9]])

posterior = bayesian_inference(prior, likelihood)
print(posterior)
