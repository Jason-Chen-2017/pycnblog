##### 2.1 分形几何的定义与特点

分形几何最早由法国数学家曼德尔布罗特（Benoit Mandelbrot）提出，他将其定义为“一种部分以相似的方式无限重复的结构”。分形几何的基本概念包括分形维数、分形生成算法、分形分布等。

1. **分形维数**：分形维数是分形几何的核心概念之一，用来描述分形的复杂程度。分形维数不同于传统几何中的整数维数，它可以是分数或无理数。例如，海岸线的分形维数大约为1.26，这意味着其复杂性介于一维和二维之间。

2. **分形生成算法**：分形生成算法是创建分形图形的方法。常见的分形生成算法包括迭代函数系统（IFS）、曼德尔布罗特集、李雅普诺夫集等。这些算法通过重复迭代一个简单的规则，可以生成出复杂的分形结构。

3. **分形分布**：分形分布描述了分形在不同尺度上的分布规律。分形分布具有自相似性，即在不同尺度上呈现出相似的结构。

##### 2.2 分形几何的基本概念

1. **自相似性**：自相似性是分形几何的基本特征。一个分形结构在不同尺度上都具有相似的结构，这种性质使得分形几何能够有效描述自然界的复杂现象。

2. **分形维数**：分形维数是衡量分形复杂性的尺度。常见的分形维数包括赫斯特指数（Hurst Exponent）和相似维数（Similarity Dimension）。赫斯特指数用于描述时间序列的自相似性，相似维数用于描述空间结构的自相似性。

3. **分形生成算法**：分形生成算法包括迭代函数系统（IFS）、曼德尔布罗特集、李雅普诺夫集等。这些算法通过数学规则和迭代过程，可以生成出复杂的分形图形。

##### 2.5 分形几何的数学模型

分形几何的数学模型是理解和应用分形几何的关键。以下我们将介绍几个常见的分形几何数学模型，包括曼德尔布罗特集、李雅普诺夫集和迭代函数系统（IFS）。

1. **曼德尔布罗特集**

曼德尔布罗特集是最著名的分形集之一，由数学家曼德尔布罗特在1979年提出。它的定义如下：

$$ Z_0 = 0 $$
$$ Z_{n+1} = z_n^2 + c $$

其中，$c$ 是复数常数，$Z_n$ 是迭代过程中的复数点。曼德尔布罗特集的生成过程是将复平面上的每个点依次按照上述公式进行迭代，直到其绝对值超过2。所有不发生这种情况的点组成曼德尔布罗特集。

2. **李雅普诺夫集**

李雅普诺夫集是一类复杂的分形集，其生成过程依赖于动力系统的稳定性。李雅普诺夫集的数学模型可以表示为：

$$ x_{n+1} = f(x_n) $$

其中，$x_n$ 是迭代过程中的点，$f(x_n)$ 是动力系统的映射函数。李雅普诺夫集的特点是它能够捕捉系统在不同尺度上的自相似性，通常用于研究动力系统的长期行为。

3. **迭代函数系统（IFS）**

迭代函数系统是一种用于生成分形图形的算法，其基本思想是将整个空间划分为几个子区域，然后对每个子区域应用不同的函数映射。IFS的数学模型可以表示为：

$$ x_{n+1} = f_i(x_n) $$

其中，$f_i(x_n)$ 是第$i$个子区域的映射函数，$x_n$ 是迭代过程中的点。IFS的一个重要特点是它可以生成具有高度复杂性的分形图形，且这些图形在不同的尺度上表现出自相似性。

通过这些数学模型，分形几何能够有效地描述自然界的复杂现象，并在多个领域得到广泛应用。在园林设计中，这些模型可以用于模拟自然景观的构成规律，创造出具有自然美感的园林布局和植物配置。

#### 附录B：园林设计常用分形算法

1. **中位数法**

中位数法是一种常用的分形生成算法，其基本思想是通过迭代计算数据的中位数来生成分形图形。

伪代码如下：

```
function 中位数法(data):
    if length(data) <= 1:
        return data
    else:
        mid = 中位数(data)
        left = data[data < mid]
        right = data[data > mid]
        return [中位数法(left), mid, 中位数法(right)]
```

2. **四分位法**

四分位法是另一种常用的分形生成算法，其基本思想是通过计算数据的四分位数来生成分形图形。

伪代码如下：

```
function 四分位法(data):
    if length(data) <= 1:
        return data
    else:
        Q1 = 第一个四分位数(data)
        Q3 = 第二个四分位数(data)
        left = data[data < Q1]
        mid = data[data >= Q1 and data <= Q3]
        right = data[data > Q3]
        return [四分位法(left), mid, 四分位法(right)]
```

3. **密度法**

密度法是一种基于数据密度的分形生成算法，其基本思想是通过计算数据的密度分布来生成分形图形。

function 密度法(data):
