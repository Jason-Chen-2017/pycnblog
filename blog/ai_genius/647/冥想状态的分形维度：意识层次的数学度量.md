### 分形理论基础

分形理论作为研究复杂系统的重要工具，其核心在于描述系统中存在的非线性和自相似性。在数学中，分形是一种具有无限复杂性的几何形状，其特点是在不同尺度下都表现出相似的特性。这一特性使得分形成为研究复杂现象的理想选择。

#### 分形的定义与特性

分形最初由数学家曼德尔布罗特（Benoit Mandelbrot）提出。曼德尔布罗特将分形定义为：“在精细层次上，其结构和整体具有相似性的几何形状。”分形的几个关键特性如下：

1. **无限复杂性**：分形形状在不同的尺度下都表现出复杂结构，其细节在无穷远的地方也不会变得简单。
2. **自相似性**：分形在整体和局部之间具有相似性。这意味着，无论你观察分形的哪个部分，都会发现与整体相似的结构。
3. **非线性**：分形系统通常遵循非线性的动态规律，而不是简单的线性关系。

#### 分形的生成方法

分形的生成方法多种多样，以下介绍几种常见的分形生成方法：

1. **迭代函数系统（IFS）**：迭代函数系统是一种通过多个变换函数的组合来生成分形的方法。每个变换函数将空间映射到自身的一部分，经过多次迭代后，生成一个复杂的分形形状。

   IFS的数学描述如下：
   $$ T = \{ T_1, T_2, ..., T_n \} $$
   其中，每个变换函数$T_i$是一个压缩映射，满足：
   $$ |T_i(x) - T_i(y)| < |x - y| $$
   初始点$x_0$通过以下迭代过程生成分形：
   $$ x_{n+1} = T_i(x_n) $$
   
2. **随机分形**：随机分形通过随机过程来生成，例如布朗运动分形、随机森林等。这些分形形状通常具有高度的不规则性和自相似性。

3. **介数过程**：介数过程是一种通过连续迭代生成分形的方法。该方法基于介数矩阵，通过迭代更新矩阵的元素，最终生成一个复杂的分形结构。

   介数过程的伪代码如下：
   ```
   Initialize the matrix M with random values
   for i in range(N):
       for j in range(N):
           if i == j:
               M[i][j] = 0
           else:
               M[i][j] = 1 / (1 + distance(i, j))
   end
   while not convergence:
       Update M using the following formula:
       M[i][j] = (1 - alpha) * M[i][j] + alpha * (1 / distance(i, j))
   end
   return M
   ```

#### 分形的数学描述

分形的数学描述通常通过分形维数来实现。分形维数是衡量分形复杂性的一个指标，它不同于传统几何维数。例如，一个线段的传统维数是1，而一个立方体的维数是3。分形维数则是一个介于1和2之间的数值，它反映了分形结构在空间中的复杂程度。

分形维数的计算方法有多种，其中最常用的是盒计数法（box counting method）。盒计数法的基本思想是，将分形结构放在一个网格中，计算覆盖分形所需的最小盒数。分形维数可以通过以下公式计算：

$$ 
D = \frac{\log N}{\log L} 
$$

其中，$N$ 是覆盖分形所需的盒数，$L$ 是每个盒的边长。

#### 分形的统计意义

分形维数的统计意义在于，它能够量化分形结构的复杂性和不规则性。高维数的分形表示结构非常复杂，而低维数的分形则表示结构较为简单。在冥想状态的研究中，分形维数可以用来描述大脑活动在冥想过程中复杂性的变化，从而揭示冥想对意识层次的影响。

#### 脑电图（EEG）

脑电图是测量大脑电活动的一种非侵入性技术，它可以实时记录大脑的电信号。在冥想研究中，EEG被广泛用于监测冥想过程中大脑活动的变化。EEG信号可以揭示冥想状态下的不同脑波模式，如α波、β波、θ波和δ波。这些脑波模式与不同的心理状态和大脑功能有关。例如，α波通常与放松和冥想状态相关，而β波则与注意力集中和警觉性高有关。

##### 脑电图测量步骤：

1. **电极布置**：将EEG电极粘贴在头皮上，通常选择Fp1、Fp2、F3、F4、C3、C4、P3和P4等位置。
2. **信号采集**：使用放大器和滤波器采集EEG信号，并将其传输到数据记录设备。
3. **信号处理**：对采集到的EEG信号进行预处理，包括滤波、去噪和放大等步骤。
4. **分析**：通过脑电信号分析工具，提取不同频段的脑波，如α波、β波等，并计算其振幅和频率。

#### 功能性磁共振成像（fMRI）

功能性磁共振成像是一种无创的脑成像技术，它可以测量大脑的血液流动变化，从而反映大脑的活动。在冥想研究中，fMRI被用于观察冥想状态下大脑不同区域的活动模式。

##### fMRI测量步骤：

1. **成像准备**：受试者躺在MRI扫描仪中，并佩戴耳塞和眼罩以消除外部干扰。
2. **数据采集**：使用梯度磁场和射频脉冲改变氢原子核的状态，通过探测器检测核磁共振信号，生成大脑图像。
3. **数据处理**：对fMRI数据进行预处理，包括运动校正、空间标准化和时序平滑等步骤。
4. **分析**：通过统计参数映射（SPM）等方法，分析不同冥想状态下大脑活动区域的差异。

#### 心率变异性（HRV）

心率变异性是测量心电信号间时间间隔的变化，它反映了自主神经系统的活动。HRV与冥想状态密切相关，能够反映冥想对个体情绪和生理状态的影响。

##### HRV测量步骤：

1. **电极布置**：将心电图（ECG）电极粘贴在胸部或手腕上，以记录心电信号。
2. **信号采集**：使用放大器和滤波器采集ECG信号，并将其传输到数据记录设备。
3. **信号处理**：对ECG信号进行预处理，包括滤波、去噪和分割等步骤，以提取心跳间的时间间隔。
4. **分析**：通过HRV分析工具，计算心率变异性参数，如标准差（SDNN）、低频（LF）和高频（HF）功率等。

import numpy as np

# 读取数据

fs = 256  # 采样频率

def preprocess(signal):
    b, a = butter(4, [1, 30], btype='band')
    filtered_signal = filtfilt(b, a, signal)

lengths = [max_amplitude(segment) for segment in segments]

分形理论作为研究复杂系统的重要工具，其核心在于描述系统中存在的非线性和自相似性。在数学中，分形是一种具有无限复杂性的几何形状，其特点是在不同尺度下都表现出相似的特性。这一特性使得分形成为研究复杂现象的理想选择。

#### 分形的定义与特性

分形最初由数学家曼德尔布罗特（Benoit Mandelbrot）提出。曼德尔布罗特将分形定义为：“在精细层次上，其结构和整体具有相似性的几何形状。”分形的几个关键特性如下：

1. **无限复杂性**：分形形状在不同的尺度下都表现出复杂结构，其细节在无穷远的地方也不会变得简单。
2. **自相似性**：分形在整体和局部之间具有相似性。这意味着，无论你观察分形的哪个部分，都会发现与整体相似的结构。
3. **非线性**：分形系统通常遵循非线性的动态规律，而不是简单的线性关系。

#### 分形的生成方法

1. **迭代函数系统（IFS）**：迭代函数系统是一种通过多个变换函数的组合来生成分形的方法。每个变换函数将空间映射到自身的一部分，经过多次迭代后，生成一个复杂的分形形状。

   IFS的数学描述如下：
   $$ T = \{ T_1, T_2, ..., T_n \} $$
   其中，每个变换函数$T_i$是一个压缩映射，满足：
   $$ |T_i(x) - T_i(y)| < |x - y| $$
   初始点$x_0$通过以下迭代过程生成分形：
   $$ x_{n+1} = T_i(x_n) $$

2. **随机分形**：随机分形通过随机过程来生成，例如布朗运动分形、随机森林等。这些分形形状通常具有高度的不规则性和自相似性。

3. **介数过程**：介数过程是一种通过连续迭代生成分形的方法。该方法基于介数矩阵，通过迭代更新矩阵的元素，最终生成一个复杂的分形结构。

import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import butter, filtfilt
from pywt import detrend, dwt2, idwt2

# 读取数据
data = np.load('EEG_data.npy')
fs = 256  # 采样频率

# 滤波去噪
def preprocess(signal):
    b, a = butter(4, [1, 30], btype='band')
    filtered_signal = filtfilt(b, a, signal)
    trend = detrend(filtered_signal, wavelet='db4')
    coeffs = dwt2(trend, 'db4')
    denoised_signal = idwt2(coeffs, 'db4')
    return denoised_signal

# 分段
segment_size = 100  # 段长度
segments = [preprocess(signal[i:i+segment_size]) for i in range(0, len(data) - segment_size + 1)]

# 特征长度计算
def max_amplitude(segment):
    return np.sqrt(np.mean(segment**2))

lengths = [max_amplitude(segment) for segment in segments]

# 双对数图绘制
plt.scatter(np.log(lengths), np.log(np.arange(1, len(lengths) + 1)))
plt.xlabel('Log of Feature Length')
plt.ylabel('Log of Box Number')
plt.title('Double Log Plot of Feature Length vs. Box Number')
plt.show()

# 斜率计算
slope, _ = np.polyfit(np.log(lengths), np.log(np.arange(1, len(lengths) + 1)), 1)
fractal_dimension = -slope
print(f'Fractal Dimension: {fractal_dimension}')
```
