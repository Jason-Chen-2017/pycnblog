## 第1章：智能流程挖掘技术简介

### 1.1 智能流程挖掘的定义与价值

**定义：** 智能流程挖掘是指利用人工智能技术，从大量业务数据中自动识别和提取业务流程信息的过程。它不仅包括数据预处理、流程模型构建和智能分析算法，还涵盖了基于分析结果进行业务流程优化的一系列操作。

**价值：** 在当今信息爆炸的时代，企业积累的数据量日益庞大，如何从海量数据中提取有价值的信息成为一大挑战。智能流程挖掘技术通过自动化识别和分析业务流程，可以为企业提供以下价值：

1. **提高业务效率：** 通过优化业务流程，减少不必要的环节和重复操作，从而提高整体工作效率。
2. **提升数据利用率：** 智能流程挖掘能够全面分析业务数据，挖掘潜在的业务模式和规律，提高数据利用率。
3. **降低运营成本：** 优化后的业务流程能够减少人力资源的浪费，降低运营成本。
4. **增强决策支持：** 通过智能流程挖掘技术，企业可以获得更加准确和实时的业务信息，为决策提供有力支持。

## 第2章：智能流程挖掘的核心概念与架构

### 2.1 数据源概述

智能流程挖掘的第一步是收集和整理数据源。数据源可以是结构化数据（如数据库记录）、半结构化数据（如日志文件）和非结构化数据（如图像和文本）。以下是常见的数据源类型：

1. **内部数据源：** 包括企业的数据库、ERP系统、CRM系统等，提供了丰富的业务数据。
2. **外部数据源：** 包括市场调研数据、竞争对手信息、社交媒体数据等，能够补充和丰富内部数据。
3. **实时数据源：** 通过传感器、API接口等方式实时收集的数据，用于实时监控和动态调整业务流程。

### 2.2 数据预处理与清洗

数据预处理是智能流程挖掘的重要组成部分，它包括数据清洗、数据转换和数据集成等步骤。

1. **数据清洗：** 数据清洗的主要目标是去除数据中的噪声和异常值，保证数据的质量。常见的数据清洗方法有：
   - **缺失值处理：** 填充缺失值或删除缺失值较严重的记录。
   - **异常值处理：** 根据业务规则和统计学方法识别并处理异常值。
   - **数据格式化：** 将数据格式统一，如日期的标准化、字符串的编码转换等。

2. **数据转换：** 数据转换包括将不同数据源的数据进行整合，使其能够在同一平台上进行分析和处理。常见的数据转换方法有：
   - **数据归一化：** 将数据缩放到相同的范围，如使用Z-score或Min-Max方法。
   - **特征工程：** 提取和构建新的特征，以提升模型的效果。

3. **数据集成：** 数据集成是将来自多个数据源的数据整合到一个统一的数据集中，以便进行后续分析。常见的数据集成方法有：
   - **全量集成：** 将所有数据源的数据合并到一个表中，适用于数据量较小的情况。
   - **增量集成：** 只合并新增或更新的数据，适用于实时数据源。

### 2.3 流程模型构建

流程模型构建是智能流程挖掘的核心步骤，其目的是从数据中自动识别和提取业务流程信息。

1. **业务流程表示：** 业务流程可以通过流程图、活动图、网络图等形式进行表示。常用的业务流程表示方法有：
   - **Petri网：** 用于表示业务流程中的并发、选择、同步等复杂关系。
   - **活动图：** 用于描述业务流程中的活动及其之间的顺序和分支。

2. **流程模型生成算法：** 流程模型生成算法根据数据源和业务流程表示方法，自动生成流程模型。常用的流程模型生成算法有：
   - **基于约束的逻辑推理：** 通过业务规则和约束条件生成流程模型。
   - **基于数据流的挖掘：** 通过分析数据流中的模式生成流程模型。

3. **流程模型优化：** 流程模型优化是通过调整流程模型的参数和结构，提高流程的效率和效果。常见的流程模型优化方法有：
   - **基于启发式的方法：** 如遗传算法、模拟退火等，通过迭代优化流程模型。
   - **基于优化的方法：** 如线性规划、整数规划等，通过数学优化模型优化流程模型。

### 2.4 智能分析算法

智能分析算法是智能流程挖掘的核心技术，其目的是从流程模型中提取有价值的信息，如关键路径、瓶颈环节、异常行为等。

1. **聚类算法：** 聚类算法用于发现数据中的相似模式，可以帮助识别业务流程中的相似路径和环节。常用的聚类算法有：
   - **K-means算法：** 通过最小化距离平方和进行聚类。
   - **层次聚类算法：** 通过层次划分的方式进行聚类。

2. **关联规则挖掘：** 关联规则挖掘用于发现数据之间的关联关系，可以帮助识别业务流程中的依赖和联动关系。常用的关联规则挖掘算法有：
   - **Apriori算法：** 通过频繁项集生成关联规则。
   - **Eclat算法：** 通过递归搜索频繁项集。

3. **时序分析：** 时序分析用于分析数据的时间序列特性，可以帮助识别业务流程中的时间规律和趋势。常用的时序分析算法有：
   - **ARIMA模型：** 自回归积分滑动平均模型。
   - **LSTM模型：** 长短期记忆模型。

### 2.5 流程优化策略

流程优化策略是基于智能分析算法的结果，对业务流程进行调整和优化的方法。

1. **自动化调整：** 通过算法自动调整流程中的活动顺序、分支结构和资源分配，以优化流程性能。

2. **手动调整：** 根据分析结果，由业务专家对流程进行调整，以适应特定的业务需求。

3. **持续优化：** 通过实时监控和反馈，持续调整和优化业务流程，以适应不断变化的环境。

## 第3章：数据预处理与清洗

### 3.1 数据质量评估

数据质量是智能流程挖掘成功的关键因素之一。数据质量评估旨在评估数据的质量，包括数据的完整性、准确性、一致性、有效性和及时性。以下是常见的数据质量评估方法：

1. **完整性评估：** 检查数据集中是否存在缺失值或空值，以及缺失值的比例。常用的完整性评估指标有：
   - **缺失值比例：** 缺失值占总数据的比例。
   - **缺失值密度：** 缺失值占数据集总字节数的比例。

2. **准确性评估：** 检查数据的准确性，即数据是否与实际情况相符。常用的准确性评估指标有：
   - **错误率：** 错误数据占总数据的比例。
   - **Kappa系数：** 评估分类数据的一致性和准确性。

3. **一致性评估：** 检查数据在不同数据源或时间点之间的一致性。常用的一致性评估指标有：
   - **差异率：** 不同数据源或时间点之间数据差异的比例。
   - **一致性系数：** 数据一致性的评分。

4. **有效性评估：** 检查数据是否满足业务需求，即数据是否具有业务价值。常用的有效性评估指标有：
   - **业务覆盖率：** 满足业务需求的数据比例。
   - **业务准确性：** 满足业务需求的数据的准确性。

5. **及时性评估：** 检查数据的更新速度和实时性。常用的及时性评估指标有：
   - **延迟率：** 数据更新延迟的时间比例。
   - **更新频率：** 数据更新的时间间隔。

### 3.2 数据清洗方法

数据清洗是确保数据质量的关键步骤，其目的是去除数据中的噪声和异常值，提高数据的准确性和一致性。以下是常见的数据清洗方法：

1. **缺失值处理：**
   - **填充缺失值：** 使用平均值、中位数、最频繁的值等统计方法填充缺失值。
     ```python
     import numpy as np

     # 填充缺失值为平均值
     data = np.array([1, 2, np.nan, 4, 5])
     data = np.nan_to_num(data, nan=np.mean(data))
     ```
   - **删除缺失值：** 删除缺失值较严重的记录。
     ```python
     import pandas as pd

     # 删除缺失值较严重的记录
     df = pd.DataFrame({'A': [1, 2, np.nan, 4, 5]})
     df = df.dropna(thresh=len(df)*0.5)
     ```

2. **异常值处理：**
   - **Z-score方法：** 使用Z-score识别和删除异常值。
     ```python
     import numpy as np

     # 计算Z-score
     data = np.array([1, 2, 3, 100, 5])
     mean = np.mean(data)
     std = np.std(data)
     z_scores = (data - mean) / std
     # 删除Z-score大于3的异常值
     clean_data = data[z_scores < 3]
     ```
   - **IQR方法：** 使用IQR（四分位距）识别和删除异常值。
     ```python
     import numpy as np

     # 计算IQR
     data = np.array([1, 2, 3, 100, 5])
     Q1 = np.percentile(data, 25)
     Q3 = np.percentile(data, 75)
     IQR = Q3 - Q1
     # 删除IQR大于1.5倍的四分位距的异常值
     clean_data = data[(data >= Q1 - 1.5 * IQR) & (data <= Q3 + 1.5 * IQR)]
     ```

3. **数据格式化：**
   - **日期标准化：** 将不同格式的日期转换为统一格式。
     ```python
     import pandas as pd

     # 日期标准化
     df = pd.DataFrame({'date': ['2021-01-01', '01/02/2021', '02-01-2021']})
     df['date'] = pd.to_datetime(df['date'], format='%Y-%m-%d')
     ```
   - **字符串编码：** 将不同编码的字符串转换为统一的编码格式。
     ```python
     import chardet

     # 字符串编码转换
     s = '中文测试'
     encoding = chardet.detect(s)['encoding']
     s_encoded = s.encode(encoding)
     ```

### 3.3 数据转换与集成

数据转换与集成是确保数据能够一致性和高效性处理的关键步骤。

1. **数据归一化：**
   - **Z-score归一化：** 将数据缩放到相同的范围，使数据集的中心值和标准差一致。
     ```python
     import numpy as np

     # Z-score归一化
     data = np.array([1, 2, 3, 4, 5])
     mean = np.mean(data)
     std = np.std(data)
     normalized_data = (data - mean) / std
     ```
   - **Min-Max归一化：** 将数据缩放到[0, 1]的范围内。
     ```python
     import numpy as np

     # Min-Max归一化
     data = np.array([1, 2, 3, 4, 5])
     min_val = np.min(data)
     max_val = np.max(data)
     normalized_data = (data - min_val) / (max_val - min_val)
     ```

2. **特征工程：**
   - **提取新特征：** 通过组合现有特征或构建新特征，提高模型的效果。
     ```python
     import pandas as pd

     # 提取新特征
     df = pd.DataFrame({'A': [1, 2, 3, 4, 5], 'B': [5, 4, 3, 2, 1]})
     df['C'] = df['A'] * df['B']  # 新特征C为A和B的乘积
     ```

3. **数据集成：**
   - **全量集成：** 将所有数据源的数据合并到一个表中。
     ```python
     import pandas as pd

     # 全量集成
     df1 = pd.DataFrame({'A': [1, 2, 3]})
     df2 = pd.DataFrame({'B': [4, 5, 6]})
     df = df1.join(df2, how='outer')  # 外连接合并数据
     ```
   - **增量集成：** 只合并新增或更新的数据。
     ```python
     import pandas as pd

     # 增量集成
     df_old = pd.DataFrame({'A': [1, 2, 3]})
     df_new = pd.DataFrame({'A': [4, 5, 6], 'B': [7, 8, 9]})
     df = df_old.append(df_new)  # 合并新增数据
     ```

## 第4章：流程模型构建技术

### 4.1 业务流程表示

业务流程表示是将实际业务流程转化为计算机可以理解和处理的形式。常用的业务流程表示方法包括流程图、活动图和Petri网。

#### 流程图

流程图是一种直观表示业务流程的方法，通常使用节点和边来表示流程中的活动和连接关系。以下是流程图的表示方法：

1. **节点表示：** 每个节点表示一个具体的活动或决策。
   ```mermaid
   graph TD
   A[开始] --> B{决策}
   B -->|是| C[活动1]
   B -->|否| D[活动2]
   D --> E{决策2}
   E -->|是| F[活动3]
   E -->|否| G[结束]
   ```

2. **边表示：** 边表示节点之间的连接关系，可以是顺序、分支或并发关系。

#### 活动图

活动图是一种更详细的流程表示方法，不仅包括节点和边，还包括时间信息、资源分配和并行处理等。

1. **时间信息：** 表示每个活动的时间长度。
   ```mermaid
   graph TD
   A[开始] --> B{决策}[时长:2天]
   B -->|是| C[活动1][时长:3天]
   B -->|否| D[活动2][时长:1天]
   D --> E{决策2}
   E -->|是| F[活动3][时长:4天]
   E -->|否| G[结束]
   ```

2. **资源分配：** 表示活动所需的资源，如人力、设备等。
   ```mermaid
   graph TD
   A[开始]
   B{决策}
   C[活动1][资源:10人]
   D[活动2]
   E{决策2}
   F[活动3][资源:5台设备]
   G[结束]
   ```

#### Petri网

Petri网是一种形式化的流程表示方法，用于描述并发、同步和竞争等复杂关系。Petri网由库所、变迁和有向弧组成。

1. **库所（Place）：** 表示业务流程中的资源或状态。
2. **变迁（Transition）：** 表示业务流程中的活动或事件。
3. **有向弧（Arc）：** 表示库所和变迁之间的连接关系。

**示例：**

```mermaid
graph TD
A(库所1) --> B(库所2)
B --> C(库所3)
D(变迁1) --> A
D --> B
C --> E(变迁2)
E --> C
```

### 4.2 流程模型生成算法

流程模型生成算法是将业务流程转化为计算机可以处理的流程模型的方法。常用的流程模型生成算法包括基于约束的逻辑推理和基于数据流的挖掘。

#### 基于约束的逻辑推理

基于约束的逻辑推理方法通过业务规则和约束条件自动生成流程模型。

1. **业务规则：** 表示业务流程中的限制条件和规则，如“如果订单金额超过1000元，则需要进行审批”。
2. **约束条件：** 表示业务流程中的限制和依赖关系，如“活动A必须先于活动B执行”。
3. **流程模型生成：** 通过逻辑推理和约束条件生成流程模型。

**示例：**

```mermaid
graph TD
A[活动A] --> B[活动B]
A --> C{审批}
C --> D[活动D]
B --> E{审批}
E --> F[活动F]
```

#### 基于数据流的挖掘

基于数据流的挖掘方法通过分析数据流中的模式自动生成流程模型。

1. **数据流：** 表示业务流程中的数据流动和转换过程。
2. **模式挖掘：** 通过分析数据流中的模式识别业务流程。
3. **流程模型生成：** 根据挖掘出的模式生成流程模型。

**示例：**

```mermaid
graph TD
A(数据输入) --> B{处理1}
B --> C(数据存储)
C --> D{处理2}
D --> E(数据输出)
```

### 4.3 流程模型优化

流程模型优化是通过调整流程模型的参数和结构，提高流程的效率和效果的方法。常用的流程模型优化方法包括基于启发式的方法和基于优化的方法。

#### 基于启发式的方法

基于启发式的方法通过搜索和优化策略调整流程模型。

1. **搜索策略：** 通过搜索算法（如遗传算法、模拟退火等）在解空间中寻找最优解。
2. **优化策略：** 通过评估函数（如目标函数、适应度函数等）评估流程模型的性能，并调整模型参数以优化性能。

**示例：**

```python
def fitness_function(model):
    # 目标函数：评估流程模型的效率
    return 1 / (model['duration'] + model['resource'])

def optimize_model(model):
    # 模拟退火算法
    temperature = 10000
    cooling_rate = 0.95
    while temperature > 1:
        new_model = mutate_model(model)
        if fitness_function(new_model) > fitness_function(model):
            model = new_model
        else:
            probability = np.exp((fitness_function(new_model) - fitness_function(model)) / temperature)

        temperature *= cooling_rate
    return model
```

## 第5章：智能分析算法

### 5.1 聚类算法

聚类算法是一种无监督学习方法，用于将数据集中的对象划分为多个群组，使得属于同一群组的对象之间的相似度较高，而不同群组之间的相似度较低。常见的聚类算法包括K-means算法、层次聚类算法和DBSCAN算法。

#### K-means算法

K-means算法是一种基于距离的聚类算法，其目标是使得每个聚类中心到其内部成员的平均距离最小。以下是K-means算法的基本步骤：

1. **初始化聚类中心：** 随机选择K个数据点作为初始聚类中心。
2. **分配数据点：** 对于每个数据点，将其分配到最近的聚类中心所在的群组。
3. **更新聚类中心：** 计算每个群组的平均值，作为新的聚类中心。
4. **重复步骤2和步骤3，直到聚类中心不再变化或者达到预设的最大迭代次数。**

**Python代码示例：**

```python
from sklearn.cluster import KMeans
import numpy as np

# 数据集
data = np.array([[1, 2], [1, 4], [1, 0], [10, 2], [10, 4], [10, 0]])

# K-means算法
kmeans = KMeans(n_clusters=2, random_state=0).fit(data)
labels = kmeans.labels_

# 输出聚类结果
print("Cluster labels:", labels)
print("Cluster centers:", kmeans.cluster_centers_)
```

#### 层次聚类算法

层次聚类算法是一种基于层次结构进行聚类的算法，其目标是逐步将数据集划分为越来越小的群组，最终形成完整的聚类层次结构。常见的层次聚类算法包括自底向上的凝聚层次聚类（AGNES）和自顶向下的分裂层次聚类（DIANA）。

**Python代码示例：**

```python

import numpy as np

labels = clustering.labels_

# 输出聚类结果
print("Cluster labels:", labels)
```

#### DBSCAN算法

DBSCAN（Density-Based Spatial Clustering of Applications with Noise）算法是一种基于密度的聚类算法，其目标是发现数据集中的任意形状的聚类，并能够处理噪声和异常值。DBSCAN算法的基本思想是：

1. **选择邻域：** 对于每个数据点，根据邻域大小选择邻域点。
2. **标记聚类：** 根据邻域点的密度和连接性，将数据点划分为核心点、边界点和噪声点，并标记聚类。
3. **扩展聚类：** 对于每个核心点，将其邻域内的点扩展到同一聚类中。

**Python代码示例：**

```python
from sklearn.cluster import DBSCAN
import numpy as np

# 数据集

```

### 5.2 关联规则挖掘

关联规则挖掘是一种用于发现数据集中项目之间关联关系的方法。其核心任务是找出数据集中哪些项目经常一起出现，并通过支持度和置信度来评估关联规则的强度。常见的关联规则挖掘算法包括Apriori算法和Eclat算法。

#### Apriori算法

Apriori算法是一种基于频繁项集的关联规则挖掘算法。其主要思想是：

1. **频繁项集生成：** 通过递归搜索所有频繁项集。
2. **关联规则生成：** 通过支持度和置信度筛选频繁项集，生成关联规则。

**Python代码示例：**


## 第6章：数学模型与优化理论

### 6.1 线性规划

线性规划是一种用于求解线性目标函数在线性约束条件下的最优解的数学方法。线性规划广泛应用于资源分配、生产调度、库存管理等领域。

#### 定义

线性规划的目标是求解以下问题：

最大化 \( c^T x \)

或

最小化 \( c^T x \)

满足线性约束条件：

\( Ax \leq b \)

或

\( Ax \geq b \)

或

\( Ax = b \)

其中，\( x \) 是变量，\( c \) 是系数向量，\( A \) 是约束矩阵，\( b \) 是约束向量。

#### 算法

线性规划常用的求解算法包括单纯形法和内点法。

**单纯形法：**

1. **初始基本可行解：** 选择初始的基本可行解，通常是所有变量非负的解。
2. **迭代过程：** 根据目标函数和约束条件，迭代调整基本可行解，直到找到最优解。

**Python代码示例：**

```python
from scipy.optimize import linprog

# 目标函数
c = [-1, -2]

# 约束条件
A = [[2, 1], [1, 1]]
b = [4, 1]

# 求解线性规划问题
result = linprog(c, A_ub=A, b_ub=b, method='highs')

if result.success:
    x_opt = result.x
    print("最优解:", x_opt)
else:
    print("没有最优解")
```

**内点法：**

1. **初始内点解：** 选择初始的内点解，通常是目标函数的梯度方向。
2. **迭代过程：** 根据目标函数和约束条件，迭代调整内点解，直到找到最优解。

### 6.2 整数规划

整数规划是一种用于求解整数变量在约束条件下的最优解的数学方法。整数规划在组合优化、物流调度、资源分配等领域有广泛应用。

#### 定义

整数规划的目标是求解以下问题：

最大化 \( c^T x \)

或

最小化 \( c^T x \)

满足线性约束条件：

\( Ax \leq b \)

或

\( Ax \geq b \)

或

\( Ax = b \)

以及整数约束条件：

\( x \in Z^n \)

其中，\( x \) 是整数变量，\( c \) 是系数向量，\( A \) 是约束矩阵，\( b \) 是约束向量，\( Z \) 表示整数集。

#### 算法

整数规划常用的求解算法包括动态规划、分支定界和启发式算法。

**动态规划：**

1. **划分状态空间：** 将状态空间划分为多个子状态空间。
2. **状态转移方程：** 根据子状态空间的转移关系，建立状态转移方程。
3. **逆推求解：** 从目标状态逆推求解最优解。

**分支定界：**

1. **初始解：** 选择初始解，通常是所有变量非负的解。
2. **分支：** 根据约束条件和目标函数，将解空间划分为子空间。
3. **定界：** 根据子空间的最优解和目标函数，确定分支的上下界。
4. **迭代：** 重复分支和定界过程，直到找到最优解。

**启发式算法：**

1. **初始解：** 选择初始解，通常是通过随机选择或贪心算法得到。
2. **迭代：** 根据目标函数和约束条件，迭代调整解，直到找到满足约束条件的最优解。

### 6.3 遗传算法

遗传算法是一种基于自然选择和遗传机制的优化算法。遗传算法通过模拟生物进化过程，寻找问题的最优解。

#### 定义

遗传算法的目标是求解以下问题：

最大化 \( f(x) \)

或

最小化 \( f(x) \)

其中，\( x \) 是决策变量，\( f(x) \) 是目标函数。

遗传算法的基本过程包括：

1. **初始化种群：** 随机生成初始种群，每个个体代表一个潜在解。
2. **适应度评估：** 计算每个个体的适应度，适应度高的个体代表较好的解。
3. **选择：** 根据适应度进行选择，适应度高的个体有更大的机会被选中。
4. **交叉：** 对选中的个体进行交叉操作，产生新的个体。
5. **变异：** 对交叉后的个体进行变异操作，增加种群的多样性。
6. **迭代：** 重复适应度评估、选择、交叉和变异过程，直到满足终止条件。

#### Python代码示例

```python
import numpy as np

# 遗传算法
def fitness_function(x):
    return -x**2

def select(population, fitnesses, k):
    return np.random.choice(population, size=k, replace=False, p=fitnesses/np.sum(fitnesses))

def crossover(parent1, parent2):
    crossover_point = np.random.randint(1, len(parent1)-1)
    child1 = np.concatenate((parent1[:crossover_point], parent2[crossover_point:]))
    child2 = np.concatenate((parent2[:crossover_point], parent1[crossover_point:]))
    return child1, child2

def mutate(individual):
    mutation_point = np.random.randint(0, len(individual))
    individual[mutation_point] = np.random.randint(0, 10)
    return individual

def genetic_algorithm(population_size, generations, crossover_rate, mutation_rate):
    population = np.random.randint(0, 10, size=(population_size, 5))
    for _ in range(generations):
        fitnesses = np.array([fitness_function(individual) for individual in population])
        selected_population = select(population, fitnesses, population_size)
        children = []
        for i in range(0, population_size, 2):
            parent1, parent2 = selected_population[i], selected_population[i+1]
            if np.random.random() < crossover_rate:
                child1, child2 = crossover(parent1, parent2)
            else:
                child1, child2 = parent1, parent2
            children.append(mutate(child1))
            children.append(mutate(child2))
        population = np.array(children)
    best_individual = population[np.argmax(fitnesses)]
    return best_individual

# 求解最小值问题
best_solution = genetic_algorithm(population_size=100, generations=1000, crossover_rate=0.7, mutation_rate=0.01)
print("最优解:", best_solution)
```

### 6.4 支持向量机

支持向量机（SVM）是一种监督学习算法，用于分类和回归问题。SVM通过找到一个最佳的超平面，将不同类别的数据点尽可能分开。

#### 定义

SVM的目标是求解以下问题：

最大化 \( \frac{1}{\|w\|} \)

满足约束条件：

\( y_i (w^T x_i + b) \geq 1 \)

其中，\( x_i \) 是数据点，\( y_i \) 是标签，\( w \) 是权重向量，\( b \) 是偏置。

#### 算法

SVM常用的求解算法包括原始算法和启发式算法。

**原始算法：**

1. **拉格朗日乘数法：** 将原始问题转化为对偶问题，并通过求解对偶问题找到最优解。
2. **KKT条件：** 通过KKT条件筛选支持向量。

**启发式算法：**

1. **序列最小化算法：** 通过迭代求解对偶问题，逐步优化权重向量。
2. **SMO算法：** 通过简化对偶问题，提高求解效率。

#### Python代码示例

```python

# 数据集
X = [[0, 0], [1, 1], [1, 0], [0, 1]]
y = [0, 1, 1, 0]

```
