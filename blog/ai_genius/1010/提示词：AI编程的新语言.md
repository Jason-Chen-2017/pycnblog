       stack.append(start)
       visited = set()
       while stack:
           vertex = stack.pop()
           if vertex not in visited:

2. **冒泡排序**

   ```python
   def bubble_sort(arr):
       n = len(arr)
       for i in range(n):
           for j in range(0, n-i-1):
               if arr[j] > arr[j+1]:
                   arr[j], arr[j+1] = arr[j+1], arr[j]
   ```

3. **最小生成树算法**

   ```python
   def prim_mst(graph):
       mst = []
       visited = set()
       start = graph.keys()[0]
       visited.add(start)
       while len(visited) < len(graph):
           min_edge = None
           for vertex in visited:
               for edge in graph[vertex]:
                   if edge[0] not in visited and (min_edge is None or edge[1] < min_edge[1]):
                       min_edge = edge
           if min_edge:
               mst.append(min_edge)
               visited.add(min_edge[0])
       return mst
   ```

## 第5章 数学模型

### 5.1 基本数学公式

在AI编程中，数学模型是算法实现的基础。以下是几个常用的基本数学公式：

#### 5.1.1 概率论基础

1. **条件概率**：\( P(A|B) = \frac{P(A \cap B)}{P(B)} \)
2. **贝叶斯定理**：\( P(A|B) = \frac{P(B|A)P(A)}{P(B)} \)
3. **期望**：\( E(X) = \sum_{x} x \cdot P(X=x) \)
4. **方差**：\( Var(X) = E[(X - E(X))^2] \)

#### 5.1.2 最优化理论

1. **梯度下降**：\( \theta = \theta - \alpha \cdot \nabla J(\theta) \)
2. **最速下降法**：\( \theta = \theta - \alpha \cdot \nabla^2 J(\theta) \)
3. **牛顿法**：\( \theta = \theta - H^{-1} \cdot \nabla J(\theta) \)

### 5.2 数学公式详细讲解

#### 5.2.1 概率论实例解析

以掷骰子为例，设\( A \)为掷出偶数的事件，\( B \)为掷出小于4的事件，则有：

1. \( P(A) = \frac{1}{2} \)
2. \( P(B) = \frac{1}{3} \)
3. \( P(A \cap B) = \frac{1}{6} \)

计算条件概率：

1. \( P(A|B) = \frac{P(A \cap B)}{P(B)} = \frac{1/6}{1/3} = \frac{1}{2} \)
2. \( P(B|A) = \frac{P(A \cap B)}{P(A)} = \frac{1/6}{1/2} = \frac{1}{3} \)

应用贝叶斯定理：

1. \( P(A|B) = \frac{P(B|A)P(A)}{P(B)} = \frac{\frac{1}{3} \cdot \frac{1}{2}}{\frac{1}{3}} = \frac{1}{2} \)

#### 5.2.2 最优化理论应用

以最小二乘法为例，设目标函数为\( J(\theta) = \sum_{i=1}^{n} (h_\theta(x^{(i)}) - y^{(i)})^2 \)，其中\( h_\theta(x) = \theta_0 + \theta_1x \)为假设函数。

计算梯度：

$$
\nabla J(\theta) = \left[
\begin{array}{c}
\frac{\partial J(\theta)}{\partial \theta_0} \\
\frac{\partial J(\theta)}{\partial \theta_1}
\end{array}
\right] = \left[
\begin{array}{c}
-2\sum_{i=1}^{n} (h_\theta(x^{(i)}) - y^{(i)}) \\
-2\sum_{i=1}^{n} (h_\theta(x^{(i)}) - y^{(i)})x^{(i)}
\end{array}
\right]
$$

使用梯度下降法更新参数：

$$
\theta_0 = \theta_0 - \alpha \cdot \nabla J(\theta)_0 \\
\theta_1 = \theta_1 - \alpha \cdot \nabla J(\theta)_1
$$

##### 文本预处理

文本预处理是自然语言处理的重要步骤，用于将原始文本转换为可用于模型训练的数据。以下是文本预处理的基本步骤：

1. **分词**：将文本分割成单词或句子。
2. **词性标注**：为每个单词标注词性，如名词、动词、形容词等。
3. **去停用词**：去除常见的无意义词，如“的”、“和”、“是”等。
4. **词干提取**：将单词还原为词干形式，如将“running”还原为“run”。
5. **词向量化**：将单词转换为向量表示，如使用Word2Vec或BERT模型。

以下是文本预处理的伪代码：

```python
# 分词
words = tokenize(text)

# 词性标注
pos_tags = pos_tag(words)

# 去停用词
filtered_words = remove_stopwords(words)

# 词干提取
stemmed_words = stem_words(filtered_words)

# 词向量化
word_vectors = vectorize_words(stemmed_words)
```
