#### 1.1.1 注意力机制的定义

注意力机制是一种在计算机科学和人工智能领域中广泛应用的技术，用于解决序列数据中的依赖问题。它通过动态调整模型对输入数据的关注程度，实现更高效的信息处理。

#### 1.1.2 注意力机制的历史与发展

注意力机制的概念最早出现在20世纪80年代的心理学研究中。随着神经网络技术的发展，特别是在深度学习领域，注意力机制逐渐成为研究热点。2014年，Bahdanau等人提出的基于循环神经网络（RNN）的注意力模型标志着注意力机制在自然语言处理领域的突破。

注意力机制的基本模型通常包括三个部分：输入层、注意力层和输出层。输入层接收序列数据，注意力层计算序列中每个元素的重要程度，输出层根据注意力权重生成最终输出。

#### 1.2.2 注意力机制的数学公式与计算过程

注意力机制的数学公式如下：

$$
Attention(x) = \sum_{i=1}^{N} \alpha_i x_i
$$

其中，$\alpha_i$ 表示第 $i$ 个输入元素的重要性，$x_i$ 表示第 $i$ 个输入元素。计算过程包括三个步骤：计算注意力得分、生成注意力权重和计算输出。

##### 1.2 注意力机制的核心原理

###### 1.2.1 注意力机制的基本模型

注意力机制的基本模型包括三个部分：输入层、注意力层和输出层。关键组件如下：

- 输入层：接收序列数据
- 注意力层：计算注意力得分和权重
- 输出层：生成最终输出

###### 1.2.2 注意力机制的数学公式与计算过程

注意力机制的数学公式为：

$$
\alpha_{ij} = \text{softmax}\left(\frac{\text{Q} \cdot \text{K}^{T}}{\sqrt{d_k}}\right)
$$

其中，$Q$ 和 $K$ 分别表示查询向量和键向量，$\alpha_{ij}$ 为注意力权重。计算过程包括：

1. **计算查询向量 $Q$ 和键向量 $K$**：通常使用神经网络的中间层输出作为查询向量和键向量。
2. **计算注意力得分**：使用点积计算查询向量和键向量之间的相似度。
3. **计算注意力权重**：通过 softmax 函数将注意力得分转换为概率分布，表示每个输入元素的重要性。
4. **计算输出**：将注意力权重与输入数据相乘并求和，得到最终的输出。

##### 1.2.1 注意力机制的基本模型

注意力机制的基本模型通常包括三个部分：输入层、注意力层和输出层。

1. **输入层**：接收序列数据，如文本、图像或音频。
2. **注意力层**：计算注意力得分和权重，用于确定每个输入元素的重要程度。
3. **输出层**：根据注意力权重生成最终输出。

##### 1.2.2 注意力机制的数学公式与计算过程

注意力机制的数学公式为：

$$
\alpha_{ij} = \text{softmax}\left(\frac{\text{Q} \cdot \text{K}^{T}}{\sqrt{d_k}}\right)
$$

其中，$Q$ 和 $K$ 分别表示查询向量和键向量，$\alpha_{ij}$ 为注意力权重，$d_k$ 为键向量的维度。

计算过程如下：

1. **计算查询向量 $Q$ 和键向量 $K$**：通常使用神经网络的中间层输出作为查询向量和键向量。
2. **计算注意力得分**：使用点积计算查询向量和键向量之间的相似度。
3. **计算注意力权重**：通过 softmax 函数将注意力得分转换为概率分布，表示每个输入元素的重要性。
4. **计算输出**：将注意力权重与输入数据相乘并求和，得到最终的输出。

# 定义自注意力层
class SelfAttention(tf.keras.layers.Layer):
    def __init__(self, units):
        super(SelfAttention, self).__init__()
        self.Wq = self.add_weight(name='Wq', shape=(units, units), initializer='uniform', trainable=True)
        self.Wk = self.add_weight(name='Wk', shape=(units, units), initializer='uniform', trainable=True)
        self.Wv = self.add_weight(name='Wv', shape=(units, units), initializer='uniform', trainable=True)
        self.norm = tf.keras.layers.LayerNormalization(epsilon=1e-6)

    def call(self, inputs):
        query, key, value = self.norm(inputs)
        query = tf.matmul(query, self.Wq)
        key = tf.matmul(key, self.Wk)
        value = tf.matmul(value, self.Wv)

        attention_scores = tf.matmul(query, key, transpose_b=True)
        attention_weights = tf.nn.softmax(attention_scores, axis=1)
        output = tf.matmul(attention_weights, value)

        return output
