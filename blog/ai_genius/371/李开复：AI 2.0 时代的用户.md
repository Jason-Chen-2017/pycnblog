### 第2章：AI 2.0 技术基础

#### 2.1 机器学习基础

**机器学习的基本概念：**
机器学习是人工智能的核心技术之一，它使计算机系统能够从数据中学习并做出决策，而不需要显式地编程。

**监督学习、无监督学习、强化学习：**
1. **监督学习**：有标签数据训练模型，用于预测和分类。
2. **无监督学习**：无标签数据训练模型，用于聚类和降维。
3. **强化学习**：通过与环境的交互，不断优化决策策略，以实现最大化回报。

#### 2.2 深度学习原理

**深度学习的理论基础：**
深度学习是一种基于多层神经网络进行学习的机器学习技术，其理论基础包括神经网络的架构、反向传播算法等。

**神经网络的结构与训练：**
神经网络由输入层、隐藏层和输出层组成，通过反向传播算法，不断调整网络的权重和偏置，以优化模型性能。

**卷积神经网络与循环神经网络：**
1. **卷积神经网络（CNN）**：用于处理图像数据，通过卷积操作提取图像特征。
2. **循环神经网络（RNN）**：用于处理序列数据，如文本、时间序列等，通过循环连接实现序列信息的传递。

#### 2.3 自然语言处理

**语言模型与词嵌入：**
语言模型用于预测文本序列的概率，词嵌入将词汇映射为高维向量，以表示词汇的语义信息。

**文本分类与情感分析：**
文本分类用于将文本分为不同的类别，情感分析用于判断文本的情感倾向。

**自动问答与对话系统：**
自动问答系统用于回答用户提出的问题，对话系统用于实现人机对话，提供个性化服务。

### 核心算法原理讲解

#### 深度学习原理

**神经元激活函数：**
$$
f(x) = \sigma(x) = \frac{1}{1 + e^{-x}}
$$

**损失函数（均方误差）：**
$$
J(\theta) = \frac{1}{2m}\sum_{i=1}^{m}(h_\theta(x^{(i)}) - y^{(i)})^2
$$

#### 项目实战

**代码实际案例：**

```python
# 导入所需库
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

# 定义模型
model = keras.Sequential([
    layers.Dense(128, activation='relu', input_shape=(784,)),
    layers.Dropout(0.2),
    layers.Dense(10, activation='softmax')
])

# 编译模型
model.compile(optimizer='adam',
              loss='categorical_crossentropy',
              metrics=['accuracy'])

# 加载数据集
(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()

# 预处理数据
x_train = x_train.astype("float32") / 255
x_test = x_test.astype("float32") / 255
x_train = x_train.reshape((-1, 784))
x_test = x_test.reshape((-1, 784))

# 转换为one-hot编码
y_train = keras.utils.to_categorical(y_train, 10)
y_test = keras.utils.to_categorical(y_test, 10)

# 训练模型
model.fit(x_train, y_train, epochs=10, batch_size=32, validation_split=0.2)
```

**代码解读与分析：**

这段代码展示了如何使用 TensorFlow 和 Keras 创建一个简单的深度学习模型来处理手写数字识别任务。

1. **导入库**：引入 TensorFlow 和 Keras，这是两个常用的深度学习库。
2. **定义模型**：使用 Keras.Sequential 创建一个序列模型，包含两个全连接层（Dense），第一个层有 128 个神经元，使用 ReLU 激活函数，第二个层有 10 个神经元，用于分类，使用 softmax 激活函数。
3. **编译模型**：设置模型的优化器为 Adam，损失函数为 categorical_crossentropy（适合多分类问题），并设置准确率作为评估指标。
4. **加载数据集**：使用 Keras 内置的 MNIST 数据集，该数据集包含了 0 到 9 的手写数字图片。
5. **预处理数据**：将数据转换为浮点数并归一化到 [0, 1] 范围内，将输入数据的维度调整为 (样本数, 784)，因为每个图片是 28x28 像素。
6. **转换为 one-hot 编码**：将标签转换为 one-hot 编码，以便模型可以处理多分类问题。
7. **训练模型**：使用 fit 函数训练模型，设置训练轮数（epochs）为 10，批量大小（batch_size）为 32，并将 20% 的数据用作验证集。

通过这段代码，我们可以看到如何从头开始创建一个深度学习项目，从数据预处理到模型训练的完整流程。在实际开发中，我们可能需要更复杂的数据预处理步骤，比如图像增强、数据扩充等，以及更详细的模型调整和超参数优化。

#### 2.1 机器学习基础

**机器学习的基本概念**

机器学习（Machine Learning，ML）是人工智能（AI）的一个重要分支，它使计算机系统能够通过数据和经验进行学习和决策，而无需显式编程。机器学习的基本概念包括以下几个方面：

1. **数据集**：数据集是机器学习的基础，它包含了大量的样本数据，每个样本都带有对应的特征和标签。

2. **特征**：特征是描述数据样本的属性或变量，它们用于构建机器学习模型。

3. **标签**：标签是数据集的预期输出，用于训练模型，以便模型能够学习如何预测或分类新的数据样本。

4. **模型**：模型是机器学习算法通过数据训练得到的函数，它能够将输入特征映射到输出标签。

5. **损失函数**：损失函数用于衡量模型预测结果与真实标签之间的差距，是优化模型的重要指标。

6. **评估指标**：评估指标用于评估模型在测试集上的性能，如准确率、召回率、F1 分数等。

**监督学习、无监督学习、强化学习**

机器学习可以分为三种主要类型：监督学习（Supervised Learning）、无监督学习（Unsupervised Learning）和强化学习（Reinforcement Learning）。

1. **监督学习**：
监督学习是一种有监督的机器学习方式，训练数据集包含了输入特征和对应的标签。模型通过学习这些标签来预测新的数据样本的标签。常见的监督学习任务包括分类（如垃圾邮件检测）和回归（如房屋价格预测）。

2. **无监督学习**：
无监督学习是一种无监督的机器学习方式，训练数据集不包含标签。模型需要从数据中发现结构或模式，如聚类（如将相似的数据样本分组）和降维（如将高维数据投影到低维空间）。无监督学习在探索性数据分析、推荐系统和图像处理等领域有广泛应用。

3. **强化学习**：
强化学习是一种通过与环境互动进行学习的方式，其核心是学习策略以最大化回报。模型通过不断尝试和反馈，调整策略以实现长期目标。强化学习在自动驾驶、游戏AI和机器人控制等领域具有广泛应用。

**机器学习的基本流程**

机器学习的基本流程包括以下几个步骤：

1. **数据收集**：收集相关的数据，包括输入特征和标签。
2. **数据预处理**：清洗和整理数据，如缺失值处理、异常值检测和数据归一化等。
3. **特征工程**：选择和构建有效的特征，以提升模型的性能。
4. **模型选择**：选择合适的机器学习算法和模型结构。
5. **模型训练**：使用训练数据集训练模型，调整模型参数。
6. **模型评估**：使用验证集或测试集评估模型性能，选择最优模型。
7. **模型部署**：将训练好的模型部署到实际应用中，进行预测或决策。

#### 2.2 深度学习原理

**深度学习的基本概念**

深度学习（Deep Learning，DL）是机器学习的一个重要分支，它通过构建多层神经网络（Neural Network）来模拟人脑的学习机制。深度学习的基本概念包括：

1. **神经网络**：神经网络是一种由多个神经元组成的计算模型，每个神经元都是一个简单的函数单元，通过层与层之间的连接进行信息传递和处理。

2. **多层神经网络**：多层神经网络（Multi-Layer Neural Network）通过增加隐藏层，提高了模型的复杂度和表达能力。

3. **反向传播算法**：反向传播算法（Backpropagation Algorithm）是一种用于训练神经网络的优化方法，通过计算损失函数关于网络参数的梯度，不断调整网络参数，以最小化损失函数。

4. **激活函数**：激活函数（Activation Function）是神经网络中每个神经元在输出阶段使用的非线性函数，如 sigmoid、ReLU 和 tanh 等。

5. **损失函数**：损失函数（Loss Function）用于衡量模型预测结果与真实标签之间的差距，常见的损失函数包括均方误差（MSE）、交叉熵（Cross-Entropy）和 Huber损失等。

**深度学习的理论基础**

深度学习的理论基础主要包括以下几个方面：

1. **多层感知机（MLP）**：多层感知机是深度学习的基础，它由输入层、隐藏层和输出层组成，通过激活函数引入非线性，实现更复杂的函数映射。

2. **反向传播算法**：反向传播算法是一种通过反向传播误差信号来更新网络参数的优化方法，它通过计算损失函数关于网络参数的梯度，不断调整网络参数，以最小化损失函数。

3. **梯度下降（Gradient Descent）**：梯度下降是一种优化方法，通过迭代更新网络参数，使损失函数逐渐减小。梯度下降包括批量梯度下降（BGD）、随机梯度下降（SGD）和自适应梯度下降（如 Adam）等变体。

4. **卷积神经网络（CNN）**：卷积神经网络是一种专门用于处理图像数据的深度学习模型，通过卷积操作提取图像特征，并使用池化操作减少参数数量。

5. **循环神经网络（RNN）**：循环神经网络是一种用于处理序列数据的深度学习模型，通过循环连接实现序列信息的传递，可以处理文本、语音和视频等序列数据。

**神经网络的结构与训练**

神经网络由输入层、隐藏层和输出层组成，每个层由多个神经元组成。以下是神经网络的结构与训练的详细解释：

1. **输入层**：输入层接收外部输入数据，每个神经元对应一个输入特征。

2. **隐藏层**：隐藏层位于输入层和输出层之间，通过多个隐藏层，神经网络可以实现更复杂的函数映射。隐藏层的神经元通过激活函数引入非线性。

3. **输出层**：输出层产生模型的预测结果，每个神经元对应一个输出类别或连续值。

训练神经网络的基本步骤如下：

1. **初始化参数**：初始化网络参数，包括权重和偏置。

2. **前向传播**：将输入数据通过网络进行传播，计算每个神经元的输出。

3. **计算损失**：使用损失函数计算预测结果与真实标签之间的差距。

4. **反向传播**：计算损失函数关于网络参数的梯度，通过梯度下降更新网络参数。

5. **迭代训练**：重复前向传播和反向传播过程，不断优化网络参数，直到模型性能达到预期。

**卷积神经网络（CNN）与循环神经网络（RNN）**

1. **卷积神经网络（CNN）**：
卷积神经网络是一种专门用于处理图像数据的深度学习模型，其核心思想是通过卷积操作提取图像特征。

   - **卷积操作**：卷积神经网络通过卷积操作提取图像局部特征，如边缘、纹理等。
   - **池化操作**：池化操作用于减少参数数量和计算复杂度，常见的池化操作包括最大池化和平均池化。
   - **全连接层**：在卷积神经网络中，全连接层通常用于分类任务，将卷积层提取的特征映射到分类结果。

2. **循环神经网络（RNN）**：
循环神经网络是一种用于处理序列数据的深度学习模型，其核心思想是通过循环连接实现序列信息的传递。

   - **循环连接**：RNN 通过循环连接将当前时刻的输出与前一时刻的隐藏状态相连，实现序列信息的传递。
   - **门控机制**：为了解决 RNN 在处理长序列时出现的梯度消失和梯度爆炸问题，RNN 引入了门控机制（如 LSTM 和 GRU），通过门控单元控制信息的流动。

#### 2.3 自然语言处理

自然语言处理（Natural Language Processing，NLP）是人工智能的一个重要分支，旨在使计算机能够理解、处理和生成人类语言。随着深度学习技术的发展，NLP 在过去几年取得了显著的进展，广泛应用于文本分类、情感分析、机器翻译、问答系统等领域。

**语言模型与词嵌入**

语言模型（Language Model）是 NLP 的核心组件之一，用于预测下一个单词或词组。词嵌入（Word Embedding）则是将词汇映射为高维向量的过程，以捕捉词汇的语义信息。

1. **语言模型**：
   语言模型通过统计方法或深度学习算法，预测文本序列中的下一个单词或词组。常见的语言模型包括 n-gram 模型、神经网络语言模型（如 LSTM、GRU）和 Transformer 模型。

2. **词嵌入**：
   词嵌入是将词汇映射为高维向量的过程，通过词嵌入，可以捕捉词汇的语义信息。常见的词嵌入方法包括 Word2Vec、GloVe 和 FastText。

   - **Word2Vec**：Word2Vec 是基于神经网络的语言模型，通过负采样和目标词预测训练词向量。
   - **GloVe**：GloVe 是基于词频统计的词向量模型，通过全局矩阵分解和词频统计训练词向量。
   - **FastText**：FastText 是基于词袋模型的词向量模型，通过多层次的文本特征聚合训练词向量。

**文本分类与情感分析**

文本分类（Text Classification）是将文本数据分为不同的类别，情感分析（Sentiment Analysis）是判断文本的情感倾向（如正面、负面、中性）。

1. **文本分类**：
   文本分类是 NLP 的重要应用之一，常见的方法包括朴素贝叶斯、支持向量机（SVM）、神经网络等。

   - **朴素贝叶斯**：朴素贝叶斯是一种基于贝叶斯理论的分类算法，通过计算文本的词频和先验概率进行分类。
   - **支持向量机（SVM）**：支持向量机是一种基于最大间隔理论的分类算法，通过求解最优超平面进行分类。
   - **神经网络**：神经网络是一种基于多层感知机的分类算法，通过学习输入特征和输出标签之间的映射关系进行分类。

   - **基于规则的方法**：基于规则的方法通过定义情感词典和规则进行情感分析。
   - **机器学习方法**：机器学习方法通过训练分类模型进行情感分析，常见的模型包括朴素贝叶斯、SVM、决策树等。
   - **深度学习方法**：深度学习方法通过构建多层神经网络进行情感分析，常见的模型包括卷积神经网络（CNN）、循环神经网络（RNN）和 Transformer 等。

### 第五部分：AI 2.0 时代的挑战与对策

#### 7.3 AI 2.0 时代的挑战

尽管 AI 2.0 时代带来了巨大的机遇，但也伴随着一系列的挑战。以下是对这些挑战的详细探讨：

**1. 数据隐私与安全**

随着 AI 2.0 技术的广泛应用，数据隐私和安全问题变得尤为突出。AI 系统依赖大量的个人数据进行分析和训练，这些数据包括用户的浏览记录、购买行为、地理位置等。如果不妥善处理，这些数据可能会被滥用，导致隐私泄露和用户权益受损。

**挑战**：
- 数据泄露：AI 系统可能因安全漏洞而遭受黑客攻击，导致敏感数据泄露。
- 数据滥用：企业可能会滥用用户数据，进行市场操纵或不当广告推送。

**对策**：
- 强化数据保护法规：政府应制定和执行更严格的数据保护法规，确保用户数据的隐私和安全。
- 加密技术：采用先进的加密技术，对用户数据进行加密存储和传输，降低泄露风险。
- 用户教育：提高用户对数据隐私的意识，教育用户如何保护自己的数据。

**2. 算法偏见**

AI 2.0 技术依赖于大量数据训练，而这些数据可能存在偏见，导致算法在决策过程中产生不公平的结果。例如，在招聘、信用评分和贷款审批等场景中，算法偏见可能导致某些群体受到歧视。

**挑战**：
- 不公平决策：算法偏见可能导致决策不公平，损害特定群体的利益。
- 社会不满：公众对算法偏见的不满可能导致社会不稳定。

**对策**：
- 数据多样性：确保数据集的多样性，避免偏见数据的影响。
- 算法透明性：提高算法的透明度，使公众能够理解算法的决策过程。
- 定期审查：定期审查和更新算法，以消除潜在的偏见。

**3. 技术依赖性**

随着 AI 2.0 技术的广泛应用，社会对技术的依赖性日益增强。技术依赖性可能导致以下问题：

**挑战**：
- 技术故障：AI 系统可能因技术故障而停止运行，导致服务中断。
- 人才短缺：企业可能面临技术人才短缺问题，难以维护和优化 AI 系统。

**对策**：
- 增强冗余：设计冗余系统，确保在主系统故障时，备用系统能够接管。
- 技能培养：加强技术教育，培养更多的 AI 专业人才。
- 人才培养：建立持续的技能提升机制，帮助现有员工适应新技术。

**4. 伦理问题**

AI 2.0 技术的快速发展引发了一系列伦理问题，如机器自主权、责任归属等。这些问题的处理不当可能导致社会冲突和法律纠纷。

**挑战**：
- 机器自主权：随着 AI 系统的智能化，它们是否应该拥有自主权，如自主决策和行动能力。
- 责任归属：在 AI 系统造成损害时，责任应归咎于谁，是开发者、用户还是 AI 系统本身。

**对策**：

### 核心算法原理讲解

#### 深度学习原理

深度学习（Deep Learning，DL）是机器学习（Machine Learning，ML）的一个子领域，它通过构建多层的神经网络模型来模拟人脑的学习过程，实现对复杂数据的分析和建模。深度学习在图像识别、自然语言处理、语音识别等领域取得了显著的成果，成为当前 AI 领域的核心技术之一。

**神经网络基础**

神经网络（Neural Network，NN）是深度学习的基础构件。神经网络由多个神经元（或节点）组成，这些神经元通过层与层之间的连接进行信息传递和处理。一个典型的神经网络包括输入层、隐藏层和输出层。

1. **输入层**：输入层接收外部输入数据，每个神经元对应一个输入特征。

2. **隐藏层**：隐藏层位于输入层和输出层之间，通过多层连接实现更复杂的函数映射。隐藏层可以有多层，层数越多，模型的复杂度越高。

3. **输出层**：输出层产生模型的预测结果，每个神经元对应一个输出类别或连续值。

**激活函数**

激活函数是神经网络中每个神经元在输出阶段使用的非线性函数，它引入了非线性，使神经网络能够学习和建模复杂数据。常见的激活函数包括：

1. **Sigmoid 函数**：$ \sigma(x) = \frac{1}{1 + e^{-x}} $，输出范围为 (0, 1)，常用于二分类问题。

2. **ReLU 函数**：$ f(x) = max(0, x) $，常用于隐藏层，提高神经网络的学习速度。

3. **Tanh 函数**：$ f(x) = \frac{2}{1 + e^{-2x}} - 1 $，输出范围为 (-1, 1)，常用于隐藏层。

**损失函数**

损失函数是用于衡量模型预测结果与真实标签之间差距的函数，是优化模型的重要指标。常见的损失函数包括：

1. **均方误差（MSE）**：$ J(\theta) = \frac{1}{2m}\sum_{i=1}^{m}(h_\theta(x^{(i)}) - y^{(i)})^2 $，用于回归问题。

2. **交叉熵（Cross-Entropy）**：$ J(\theta) = -\frac{1}{m}\sum_{i=1}^{m}y^{(i)}\log(h_\theta(x^{(i)})) $，用于分类问题。

**反向传播算法**

反向传播算法（Backpropagation Algorithm）是一种用于训练神经网络的优化方法，它通过反向传播误差信号来更新网络参数，以最小化损失函数。反向传播算法的基本步骤如下：

1. **前向传播**：将输入数据通过网络进行传播，计算每个神经元的输出。

2. **计算损失**：使用损失函数计算预测结果与真实标签之间的差距。

3. **计算梯度**：计算损失函数关于网络参数的梯度。

4. **更新参数**：根据梯度下降方法更新网络参数，以减小损失函数。

5. **迭代训练**：重复前向传播和反向传播过程，不断优化网络参数，直到模型性能达到预期。

**深度学习模型**

深度学习模型包括卷积神经网络（Convolutional Neural Network，CNN）、循环神经网络（Recurrent Neural Network，RNN）、Transformer 等。以下是对这些模型的基本原理讲解：

1. **卷积神经网络（CNN）**：

   卷积神经网络是一种专门用于处理图像数据的深度学习模型。其核心思想是通过卷积操作提取图像特征。

   - **卷积操作**：卷积神经网络通过卷积操作提取图像局部特征，如边缘、纹理等。

   - **池化操作**：池化操作用于减少参数数量和计算复杂度，常见的池化操作包括最大池化和平均池化。

   - **全连接层**：在卷积神经网络中，全连接层通常用于分类任务，将卷积层提取的特征映射到分类结果。

2. **循环神经网络（RNN）**：

   循环神经网络是一种用于处理序列数据的深度学习模型，其核心思想是通过循环连接实现序列信息的传递。

   - **循环连接**：RNN 通过循环连接将当前时刻的输出与前一时刻的隐藏状态相连，实现序列信息的传递。

   - **门控机制**：为了解决 RNN 在处理长序列时出现的梯度消失和梯度爆炸问题，RNN 引入了门控机制（如 LSTM 和 GRU），通过门控单元控制信息的流动。

3. **Transformer 模型**：

   Transformer 模型是一种基于自注意力机制的深度学习模型，通过多头注意力机制和编码器-解码器结构，实现了高效和灵活的文本处理。

   - **自注意力机制**：Transformer 模型通过自注意力机制计算输入序列中每个元素之间的关联性，实现了对输入序列的全面关注。

   - **编码器-解码器结构**：Transformer 模型采用编码器-解码器结构，编码器处理输入序列，解码器生成输出序列，实现了序列到序列的建模。

### 项目实战

#### 代码实际案例

在本节中，我们将通过一个具体的代码实际案例来展示如何使用 TensorFlow 和 Keras 框架来构建一个简单的深度学习模型，以实现手写数字识别任务。这个案例将涵盖以下步骤：

1. **环境搭建**：安装所需的库和框架。
2. **数据准备**：加载数据集并进行预处理。
3. **模型构建**：定义模型结构。
4. **模型训练**：编译和训练模型。
5. **模型评估**：评估模型性能。
6. **代码解读与分析**：详细解析代码的每一步。

**1. 环境搭建**

在开始之前，我们需要确保已经安装了 Python、TensorFlow 和 Keras。可以使用以下命令来安装所需的库：

```bash
pip install tensorflow
pip install keras
```

**2. 数据准备**

我们使用 Keras 内置的 MNIST 数据集，这是一个广泛用于数字识别的手写数字数据集。

```python
# 导入所需库
from tensorflow import keras
from tensorflow.keras import layers

# 加载数据集
(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()

# 预处理数据
x_train = x_train.astype("float32") / 255
x_test = x_test.astype("float32") / 255
x_train = x_train.reshape((-1, 28, 28, 1))
x_test = x_test.reshape((-1, 28, 28, 1))

# 转换为 one-hot 编码
y_train = keras.utils.to_categorical(y_train, 10)
y_test = keras.utils.to_categorical(y_test, 10)
```

**3. 模型构建**

我们使用 Keras.Sequential 来构建一个简单的卷积神经网络模型，用于手写数字识别。

```python
# 定义模型
model = keras.Sequential([
    layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.Flatten(),
    layers.Dense(64, activation='relu'),
    layers.Dense(10, activation='softmax')
])
```

**4. 模型训练**

在模型训练过程中，我们需要编译模型并设置训练参数，然后使用训练数据集进行训练。

```python
# 编译模型
model.compile(optimizer='adam',
              loss='categorical_crossentropy',
              metrics=['accuracy'])

# 训练模型
model.fit(x_train, y_train, epochs=5, batch_size=32, validation_split=0.2)
```

**5. 模型评估**

在训练完成后，我们可以使用测试数据集来评估模型性能。

```python
# 评估模型
test_loss, test_acc = model.evaluate(x_test, y_test, verbose=2)
print('Test accuracy:', test_acc)
```

**6. 代码解读与分析**

以下是代码的逐行解析：

- **导入库**：我们从 TensorFlow 和 Keras 导入所需的库和模块。
- **加载数据集**：我们使用 Keras 的内置函数 `load_data()` 加载 MNIST 数据集，并对其进行预处理。数据集被分为训练集和测试集。
- **数据预处理**：我们将图像数据转换为浮点数，并将其归一化到 [0, 1] 范围内。此外，我们使用 `reshape()` 方法将图像数据调整为 (样本数, 28, 28, 1) 的形状，以便后续的卷积操作。同时，我们将标签转换为 one-hot 编码。
- **定义模型**：我们使用 `Sequential` 模型定义一个简单的卷积神经网络。模型包括两个卷积层（`Conv2D`），每个卷积层后跟一个最大池化层（`MaxPooling2D`）。然后，我们添加一个全连接层（`Dense`），用于分类。
- **编译模型**：我们使用 `compile()` 方法编译模型，指定优化器为 `adam`，损失函数为 `categorical_crossentropy`（适合多分类问题），并设置准确率作为评估指标。
- **训练模型**：我们使用 `fit()` 方法训练模型，设置训练轮数为 5，批量大小为 32，并将 20% 的数据用作验证集。
- **评估模型**：我们使用 `evaluate()` 方法评估模型的性能，在测试数据集上计算损失和准确率。
