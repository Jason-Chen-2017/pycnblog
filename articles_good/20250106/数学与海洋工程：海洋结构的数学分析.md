### 第二部分：数学分析基础

#### 第2章：微积分基础

#### 2.1 微积分的基本概念

##### 2.1.1 导数与微分

导数是微积分的核心概念之一，它描述了函数在某一点的变化率。具体来说，导数表示函数在一点处的切线斜率，即函数在该点的瞬时变化率。导数的定义如下：

$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

其中，$\Delta x$表示自变量的增量，$f(x)$表示函数值。

微分是与导数密切相关的概念，它描述了函数在某一点的变化量。微分的定义如下：

$$df = f'(x)dx$$

其中，$df$表示函数的微分，$dx$表示自变量的微分。

##### 2.1.2 积分与反导数

积分是导数的逆运算，它描述了函数在一个区间内的累积量。定积分的定义如下：

$$\int_a^b f(x)dx = \lim_{n \to \infty} \sum_{i=1}^n f(x_i^*)\Delta x$$

其中，$a$和$b$表示积分区间，$x_i^*$表示区间内的任意一点，$\Delta x$表示区间的宽度。

反导数是积分的结果，也称为不定积分。一个函数的不定积分表示所有可能的导数。例如，对于函数$f(x) = x^2$，其不定积分为：

$$F(x) = \frac{1}{3}x^3 + C$$

其中，$C$是积分常数。

##### 2.1.3 微积分基本定理

微积分基本定理将微分和积分联系起来，揭示了它们之间的内在关系。微积分基本定理分为两部分：

- 第一部分：原函数存在定理。该定理表明，如果一个函数在某一区间内可导，那么它在该区间内一定存在原函数。

- 第二部分：积分定理。该定理表明，如果$f(x)$在区间$[a, b]$上连续，那么函数$F(x)$在区间$[a, b]$上可积，且：

$$\int_a^b f(x)dx = F(b) - F(a)$$

#### 2.2 微积分的应用

##### 2.2.1 极限与无穷小

极限是微积分的基础概念之一，它描述了函数在某一点处的行为。具体来说，极限表示当自变量趋近某一值时，函数值的趋势。极限的定义如下：

$$\lim_{x \to a} f(x) = L$$

如果对于任意小的正数$\epsilon$，都存在一个正数$\delta$，使得当$0 < |x - a| < \delta$时，有$|f(x) - L| < \epsilon$。

无穷小是相对于有限量而言的，它表示一个非常小的量。在微积分中，无穷小通常用来描述函数的变化率。例如，当$x$趋近于$a$时，$f(x)$与$f(a)$之间的差值可以表示为无穷小量。

##### 2.2.2 函数的泰勒展开

泰勒展开是一种将函数表示为幂级数的方法，它描述了函数在某一点处的行为。具体来说，泰勒展开表示函数在一点处的邻域内的近似表达式。泰勒展开的定义如下：

$$f(x) = f(a) + f'(a)(x - a) + \frac{f''(a)}{2!}(x - a)^2 + \frac{f'''(a)}{3!}(x - a)^3 + \cdots$$

其中，$a$是展开点，$f'(a), f''(a), f'''(a), \ldots$是函数在$a$处的导数。

泰勒展开在微积分和数学分析中有着广泛的应用。通过泰勒展开，我们可以近似计算函数的值，分析函数的行为，解决实际问题。

##### 2.2.3 微分方程的基本解法

微分方程是描述物理现象和工程问题的重要数学工具。微分方程的基本解法包括变量分离法、积分因子法、齐次方程法、一阶线性方程法等。以下是这些方法的简要介绍：

- 变量分离法：适用于变量可分离的微分方程，即方程可以表示为两个函数的乘积的形式。具体步骤如下：

  1. 将方程两边同时除以$y$，得到$\frac{dy}{dx} = g(x)h(y)$。

  2. 变量分离，得到$\frac{1}{h(y)}dy = g(x)dx$。

  3. 对两边同时积分，得到$F(y) = G(x) + C$，其中$F$和$G$分别是$h$和$g$的积分。

- 积分因子法：适用于一阶线性微分方程，即方程可以表示为$y' + p(x)y = q(x)$的形式。具体步骤如下：

  1. 找到积分因子$\mu(x) = e^{\int p(x)dx}$。

  2. 将方程两边同时乘以积分因子，得到$\mu(x)y' + \mu(x)p(x)y = \mu(x)q(x)$。

  3. 变形得到$\frac{d}{dx}(\mu(x)y) = \mu(x)q(x)$。

  4. 对两边同时积分，得到$\mu(x)y = \int \mu(x)q(x)dx + C$，其中$C$是积分常数。

- 齐次方程法：适用于一阶齐次微分方程，即方程可以表示为$y' + p(x)y = 0$的形式。具体步骤如下：

  1. 找到特征方程$y'e^{-\int p(x)dx} = 0$。

  2. 求解特征方程，得到$y = Ce^{-\int p(x)dx}$，其中$C$是常数。

- 一阶线性方程法：适用于一阶线性微分方程，即方程可以表示为$y' + p(x)y = f(x)$的形式。具体步骤如下：

  1. 找到积分因子$\mu(x) = e^{\int p(x)dx}$。

  2. 将方程两边同时乘以积分因子，得到$\mu(x)y' + \mu(x)p(x)y = \mu(x)f(x)$。

  3. 变形得到$\frac{d}{dx}(\mu(x)y) = \mu(x)f(x)$。

  4. 对两边同时积分，得到$\mu(x)y = \int \mu(x)f(x)dx + C$，其中$C$是积分常数。

#### 第3章：线性代数基础

#### 3.1 线性代数的基本概念

##### 3.1.1 向量与矩阵

向量是线性代数中的基本概念，它表示一个有大小和方向的量。在二维空间中，一个向量可以表示为一个有序数对$(x, y)$，其中$x$和$y$分别表示向量在$x$轴和$y$轴上的分量。在三维空间中，一个向量可以表示为一个有序数对$(x, y, z)$。

矩阵是线性代数中的另一个基本概念，它表示一个二维数组。矩阵中的元素可以表示为$a_{ij}$，其中$i$和$j$分别表示行和列的索引。一个矩阵的行数称为其行数，列数称为其列数。

向量与矩阵之间有着密切的关系。一个向量可以看作是一个特殊类型的矩阵，即只有一行的矩阵。同样，一个矩阵可以看作是由多个向量组成的数组。

##### 3.1.2 线性变换

线性变换是线性代数中的核心概念，它描述了函数如何将一个向量空间映射到另一个向量空间。具体来说，线性变换可以看作是一个矩阵，它将一个向量映射到另一个向量。

线性变换的性质包括：

- 线性：线性变换满足线性组合的性质，即如果$T$是一个线性变换，那么对于任意向量$v_1$和$v_2$以及常数$c_1$和$c_2$，有$T(c_1v_1 + c_2v_2) = c_1T(v_1) + c_2T(v_2)$。

- 保持加法：线性变换保持向量的加法运算，即$T(v_1 + v_2) = T(v_1) + T(v_2)$。

- 保持标量乘法：线性变换保持向量的标量乘法运算，即$T(c_1v_1) = c_1T(v_1)$。

##### 3.1.3 特征值与特征向量

特征值和特征向量是线性变换中的重要概念，它们描述了线性变换的内在性质。特征值是指线性变换的矩阵在特定情况下所具有的值，而特征向量是指线性变换下的对应向量。

具体来说，如果$A$是一个$n \times n$的矩阵，$v$是一个非零向量，$\lambda$是一个标量，那么当$Av = \lambda v$时，$\lambda$称为$A$的特征值，$v$称为$A$的特征向量。

特征值和特征向量在许多实际应用中都有重要应用，例如：

- 线性方程组的求解：通过求解特征方程$Av = \lambda v$，可以求解线性方程组$Ax = b$。

- 特征值分解：特征值分解是一种将矩阵分解为对角矩阵和特征向量矩阵的方法，它对于矩阵的运算和分析具有重要意义。

##### 3.1.4 矩阵的基本运算

矩阵的基本运算包括矩阵的加法、减法、乘法和逆运算。

- 矩阵的加法和减法：两个矩阵相加或相减，要求它们的维度相同。具体来说，矩阵的加法和减法是通过对应元素相加或相减来实现的。

- 矩阵的乘法：矩阵的乘法是一个更为复杂的过程，它要求两个矩阵的维度满足乘法条件。具体来说，如果一个矩阵的行数为$m$，列数为$n$，另一个矩阵的行数为$n$，列数为$p$，那么它们的乘积是一个$m \times p$的矩阵。

- 矩阵的逆运算：矩阵的逆运算是指找到一个矩阵$A^{-1}$，使得$AA^{-1} = A^{-1}A = I$，其中$I$是单位矩阵。

##### 3.2 线性方程组与矩阵理论

##### 3.2.1 线性方程组的解法

线性方程组是线性代数中的一个重要问题，它描述了多个线性方程之间的关系。线性方程组的解法包括直接解法和迭代法。

- 直接解法：直接解法通过将线性方程组转化为矩阵形式，并利用矩阵运算求解。常用的直接解法包括高斯消元法和矩阵求逆法。

- 迭代法：迭代法通过不断迭代，逐步逼近线性方程组的解。常用的迭代法包括雅可比迭代法、高斯-赛德尔迭代法和共轭梯度法。

##### 3.2.2 矩阵的秩与行列式

- 矩阵的秩：矩阵的秩是指矩阵的行数或列数。一个矩阵的秩决定了它的线性相关性。如果一个矩阵的秩等于其行数或列数，那么它被称为满秩矩阵。

- 矩阵的行列式：矩阵的行列式是一个标量值，它描述了矩阵的线性相关性。一个矩阵的行列式为0，表示它是一个退化矩阵，即它的行向量线性相关。

##### 3.2.3 矩阵的秩与特征值的关系

- 矩阵的秩与特征值的关系：矩阵的秩与其特征值之间存在密切的关系。具体来说，如果一个矩阵的特征值全为0，那么它的秩为0；如果一个矩阵的特征值不全为0，那么它的秩至少为1。

#### 4.1 概率论的基本概念

##### 4.1.1 随机事件与概率

随机事件是指在某个试验中可能发生也可能不发生的事件。在概率论中，我们通常用集合来表示随机事件。例如，掷一枚硬币，出现正面的事件可以表示为集合{正面}。

概率是描述随机事件发生可能性的一种度量。具体来说，概率是指某个事件在所有可能事件中发生的比例。概率的取值范围在0到1之间，其中0表示不可能发生，1表示必然发生。

概率的基本性质包括：

- 非负性：概率值总是非负的，即$0 \leq P(A) \leq 1$，其中$P(A)$表示事件$A$的概率。

- 确定性：对于任何事件$A$，其概率$P(A)$必定存在。

- 归一性：所有可能事件的概率之和等于1，即$\sum_{i=1}^n P(A_i) = 1$，其中$A_1, A_2, \ldots, A_n$是所有可能事件。

##### 4.1.2 条件概率与独立事件

条件概率是指在某个条件下，某个事件发生的概率。具体来说，如果事件$A$和事件$B$同时发生，那么在事件$B$发生的条件下，事件$A$发生的概率可以表示为：

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

其中，$P(A \cap B)$表示事件$A$和事件$B$同时发生的概率，$P(B)$表示事件$B$发生的概率。

独立事件是指两个事件的发生互不影响。具体来说，如果事件$A$和事件$B$独立，那么在事件$B$发生的条件下，事件$A$发生的概率等于事件$A$的概率，即：

$$P(A|B) = P(A)$$

##### 4.1.3 贝叶斯定理

贝叶斯定理是概率论中的一个重要定理，它描述了在已知某个条件下，某个事件发生的概率如何更新。具体来说，如果事件$A$和事件$B$独立，那么在事件$B$发生的条件下，事件$A$发生的概率可以表示为：

$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

其中，$P(B|A)$表示在事件$A$发生的条件下，事件$B$发生的概率。

贝叶斯定理在统计学和机器学习中有着广泛的应用。通过贝叶斯定理，我们可以根据已有的数据和先验知识，更新对某个事件的概率估计。

- **连续性方程**：连续性方程描述了流体质量的守恒，数学表达式为：

  $$\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{u}) = 0$$

  其中，$\rho$是流体的密度，$\mathbf{u}$是流体的速度场，$t$是时间。

- **动量方程**：动量方程描述了流体动量的变化率，数学表达式为：

  $$\rho \left( \frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla) \mathbf{u} \right) = -\nabla p + \rho \mathbf{g} + \mathbf{F}_D$$

  其中，$p$是流体的压力，$\mathbf{g}$是重力加速度，$\mathbf{F}_D$是流体所受的附加力，如摩擦力、科里奥利力等。

- **能量方程**：能量方程描述了流体内部能量的变化，数学表达式为：

  $$\rho \left( \frac{\partial \mathcal{E}}{\partial t} + \mathbf{u} \cdot \nabla \mathcal{E} \right) = \mathbf{u} \cdot \nabla \left( p \mathbf{u} \right) - \nabla \cdot (\mathbf{u} \cdot \mathbf{T}) + \mathbf{Q}_D$$

  其中，$\mathcal{E}$是流体的内能，$\mathbf{T}$是应力张量，$\mathbf{Q}_D$是流体所受的热量。

海洋流体力学的边界条件是指流体与固体边界或自由表面之间的相互作用。常见的边界条件包括：

- **无滑移条件**：在固体边界上，流体速度的法向分量为零，即$\mathbf{u} \cdot \mathbf{n} = 0$，其中$\mathbf{n}$是边界法向单位向量。

- **压力边界条件**：在自由表面或固体边界上，流体的压力为常数，即$p = \text{const}$。

- **热传导边界条件**：在固体边界或自由表面，流体与固体之间的温度差导致热量的传递，即$-k \nabla T \cdot \mathbf{n} = 0$，其中$k$是热传导系数，$T$是温度。

   $$\rho(\mathbf{r}, t) = \rho(\mathbf{r}, t_0) - \int_{t_0}^{t} \nabla \cdot (\rho(\mathbf{r}, \tau) \mathbf{u}(\mathbf{r}, \tau)) d\tau$$

3. **边界条件**：考虑边界条件，如在自由表面，流体密度保持不变，因此：

   $$\nabla \cdot (\rho \mathbf{u}) = 0$$

   这意味着在自由表面，流体质量通量没有穿过边界。

- **表面波**：表面波是海洋波中最常见的一种，它主要在海洋表面传播，波的振幅随深度增加而减小。表面波又可以分为风激波（风浪）和涌浪（远海波）。

- **内部波**：内部波是指在海洋内部传播的波动，其能量主要在垂直方向上传递。内部波通常由潮汐力和海底地形变化引起，如潮波和内部波。

- **底波**：底波是指沿海底传播的波动，其能量主要在水平方向上传递。底波通常由海底地形变化或海底地震引起。

##### 6.1.2 海洋波的传播方程

海洋波的传播方程描述了波在海洋中的运动规律，常用的传播方程包括：

- **线性波浪理论**：线性波浪理论假设波速与波高无关，适用于小波高和短波长的波浪。线性波浪理论的传播方程为：

  $$\frac{\partial^2 h}{\partial t^2} = g \frac{\partial^2 h}{\partial z^2} - \frac{\partial^2 h}{\partial x^2} - \frac{\partial^2 h}{\partial y^2}$$

  其中，$h$是波高，$t$是时间，$z$是垂直方向，$x$和$y$是水平方向，$g$是重力加速度。

- **非线性波浪理论**：非线性波浪理论考虑波速与波高的关系，适用于大波高和长波长的波浪。非线性波浪理论的传播方程为：

  $$\frac{\partial^2 h}{\partial t^2} = g \frac{\partial^2 h}{\partial z^2} - \frac{\partial^2 h}{\partial x^2} - \frac{\partial^2 h}{\partial y^2} + \alpha h^2$$

  其中，$\alpha$是非线性系数。

##### 6.1.3 海洋波的边界条件

海洋波的边界条件描述了波在海洋表面、海底和侧面之间的相互作用。常见的边界条件包括：

- **自由表面条件**：在自由表面，波的高度的法向变化率等于波浪的压力梯度，即：

  $$\frac{\partial h}{\partial z} = -\frac{\partial p}{\partial h}$$

- **海底边界条件**：在海底，波的高度的法向变化率等于海底的压力梯度，即：

  $$\frac{\partial h}{\partial z} = -\frac{\partial p}{\partial h}$$

- **侧面边界条件**：在侧面，波的水平方向的变化率等于侧面的压力梯度，即：

  $$\frac{\partial h}{\partial x} = -\frac{\partial p}{\partial x}, \quad \frac{\partial h}{\partial y} = -\frac{\partial p}{\partial y}$$

#### 6.2 海洋波动理论的基本原理

##### 6.2.1 波动方程的解法

波动方程是描述海洋波动现象的基本方程，其解法包括解析解和数值解。

- **解析解**：解析解是指通过数学方法直接求解波动方程，得到波动特性的解析表达式。例如，在浅水区域，波动方程的解析解为：

  $$h(t, x) = \frac{A}{\left( 1 - \frac{gt}{2} \right)^{2/3}} \cos \left( \frac{2}{3} \sqrt{g} \frac{tx}{2} + \phi \right)$$

  其中，$A$是波高，$g$是重力加速度，$t$是时间，$x$是水平方向，$\phi$是初始相位。

- **数值解**：数值解是指通过数值方法求解波动方程，得到波动特性的数值结果。常用的数值解法包括有限差分法、有限元法和有限体积法。

##### 6.2.2 波的反射与折射

波的反射与折射是指波在遇到不同介质界面时，波的方向和速度发生变化的现象。在海洋波动中，波的反射与折射现象主要发生在海洋表面、海底和侧面之间。

- **波的反射**：当波从一种介质传播到另一种介质时，部分波能会被反射回原介质。反射角等于入射角，即：

  $$\theta_i = \theta_r$$

  其中，$\theta_i$是入射角，$\theta_r$是反射角。

- **波的折射**：当波从一种介质传播到另一种介质时，波的方向和速度会发生变化。折射角与入射角之间的关系由斯涅尔定律描述：

  $$\frac{\sin \theta_i}{\sin \theta_r} = \frac{v_1}{v_2}$$

  其中，$\theta_i$是入射角，$\theta_r$是折射角，$v_1$和$v_2$分别是波在两种介质中的速度。

##### 6.2.3 波的能量分布

波的能量分布描述了波在不同区域中的能量分布情况。在海洋波动中，波的能量主要分布在波浪峰面和波浪谷面之间。

- **波浪峰面**：波浪峰面是指波峰附近的区域，波的能量主要集中在这里。

- **波浪谷面**：波浪谷面是指波谷附近的区域，波的能量相对较低。

波的能量分布可以用波能密度函数描述，即：

$$\rho(h) = \frac{1}{2} \rho_0 A^2 \left( 1 - \cos \left( \frac{2}{3} \sqrt{g} \frac{z}{2} + \phi \right) \right)$$

其中，$\rho_0$是海水密度，$A$是波高，$z$是垂直方向。
