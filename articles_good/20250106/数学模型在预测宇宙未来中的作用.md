#### 3.4 算法举例说明

**例子**：假设宇宙中有两个质点，质量分别为 \(m_1\) 和 \(m_2\)，距离为 \(r\)。使用牛顿万有引力定律预测两个质点之间的引力。

**步骤**：

1. 输入质点质量 \(m_1\) 和 \(m_2\)，距离 \(r\)。
2. 计算引力 \(F = G\frac{m_1m_2}{r^2}\)。
3. 输出引力大小和方向。

**代码**：

```python
# 计算两个质点之间的引力
G = 6.674 * 10**-11  # 万有引力常数

def compute_gravity(m1, m2, r):
    F = G * (m1 * m2) / r**2
    return F

# 示例
m1 = 5.972 * 10**24  # 地球质量
m2 = 7.348 * 10**22  # 月球质量
r = 3.844 * 10**8    # 地月距离

F = compute_gravity(m1, m2, r)
print(f"The gravitational force between Earth and the Moon is {F} N.")
```
