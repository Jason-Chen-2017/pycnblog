import numpy as np

def calculate_displacement(start, end):
    return end - start

def plan_trajectory(start, end, steps):
    step_size = calculate_displacement(start, end) / steps
    trajectory = [start]
    for _ in range(steps - 1):
        trajectory.append(trajectory[-1] + step_size)
    return trajectory

start = np.array([0, 0, 0])
end = np.array([10, 10, 10])
steps = 100

trajectory = plan_trajectory(start, end, steps)
print(trajectory)

#### 2.1 向量与矩阵

**向量：** 向量是游戏物理引擎中最基本的概念之一。它用于描述物体在空间中的位置、速度和加速度。向量有大小和方向，通常表示为有向线段，用箭头表示。例如，一个二维向量可以表示为 $\vec{v} = (x, y)$，其中 $x$ 和 $y$ 分别是向量的水平和垂直分量。

在游戏物理中，向量主要用于以下方面：

- **位置表示**：用向量表示物体的位置，使得我们可以方便地计算物体的运动轨迹。
- **速度和加速度计算**：物体的速度和加速度可以用向量表示，从而便于计算物体的运动状态。
- **力的作用**：力是向量，表示物体间的相互作用。通过向量的加法和减法，我们可以计算多个力的合成。

**矩阵：** 矩阵是另一种重要的数学工具，用于表示线性变换。在游戏物理中，矩阵用于实现物体的旋转、缩放和变形。一个 $3 \times 3$ 的矩阵可以表示二维空间中的线性变换，例如旋转、缩放和平移。

矩阵在游戏物理中的应用包括：

- **旋转**：通过旋转矩阵，我们可以方便地实现物体的旋转操作。旋转矩阵是一个正交矩阵，其行列式为1。
- **缩放**：缩放矩阵用于实现物体的缩放操作，使得物体的尺寸可以按照比例进行放大或缩小。
- **变形**：通过矩阵的线性变换，我们可以实现复杂的物体变形操作。

**向量与矩阵的关系：** 向量和矩阵紧密相关。向量可以看作是一个特殊形式的矩阵，而矩阵可以看作是多个向量的集合。在游戏物理中，我们经常将向量与矩阵结合使用，例如，通过矩阵乘法实现向量的变换。

#### 2.2 三角函数与几何变换

**三角函数：** 三角函数（如正弦、余弦和正切）是描述物体旋转和变换的重要工具。在游戏物理中，三角函数主要用于以下方面：

- **旋转计算**：通过三角函数，我们可以计算物体在旋转过程中的角度和方向。
- **运动轨迹**：物体在旋转运动中，其轨迹可以通过三角函数描述。

**几何变换：** 几何变换是指对物体进行平移、旋转、缩放等操作。在游戏物理中，几何变换用于实现物体的各种变换效果。几何变换可以通过矩阵表示，例如，一个二维旋转变换可以表示为：

$$
\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} \cos(\theta) & -\sin(\theta) \\ \sin(\theta) & \cos(\theta) \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix}
$$

其中，$\theta$ 是旋转角度。

**三角函数与几何变换的联系：** 三角函数是几何变换的基础。在几何变换中，三角函数用于计算旋转角度和方向。例如，通过正弦和余弦函数，我们可以计算物体旋转后的新位置和方向。

#### 2.3 力学原理与碰撞检测

**力学原理：** 力学原理是游戏物理引擎的核心。在游戏物理中，力学原理用于计算物体的运动、碰撞和相互作用。以下是几个关键的力学原理：

- **牛顿运动定律**：牛顿运动定律描述了物体的运动规律。第一定律（惯性定律）指出，物体在没有外力作用时保持静止或匀速直线运动。第二定律（加速度定律）指出，物体的加速度与作用力成正比，与物体质量成反比。第三定律（作用与反作用定律）指出，任何作用力都有一个大小相等、方向相反的反作用力。
- **动量守恒定律**：动量守恒定律指出，在一个封闭系统中，总动量保持不变。这意味着，在没有外力作用的情况下，系统的总动量在碰撞前后保持不变。
- **能量守恒定律**：能量守恒定律指出，在一个封闭系统中，总能量保持不变。这意味着，能量可以转化为其他形式，但总量保持不变。

**碰撞检测：** 碰撞检测是游戏物理引擎中的重要环节，用于判断物体之间是否发生碰撞。碰撞检测方法包括：

- **球-球碰撞检测**：用于判断两个球体是否发生碰撞。通过计算两个球体中心之间的距离，并与两个球体的半径之和比较，可以判断是否发生碰撞。
- **球-面碰撞检测**：用于判断一个球体与一个平面是否发生碰撞。通过计算球体中心到平面的距离，并与球体半径比较，可以判断是否发生碰撞。

**力学原理与碰撞检测的联系：** 力学原理提供了物体运动的数学模型，而碰撞检测则是力学原理的具体应用。通过碰撞检测，我们可以判断物体之间是否发生碰撞，并计算碰撞后的运动状态。

#### 2.4 数学模型与算法

**数学模型：** 数学模型是游戏物理引擎的核心，用于描述物体的运动、碰撞和相互作用。以下是几个关键的数学模型：

- **位移模型**：描述物体在时间 $t$ 时刻的位置。位移模型通常表示为 $x(t) = x_0 + v_0t + \frac{1}{2}at^2$，其中 $x_0$ 是初始位置，$v_0$ 是初始速度，$a$ 是加速度。
- **速度模型**：描述物体在时间 $t$ 时刻的速度。速度模型通常表示为 $v(t) = v_0 + at$，其中 $v_0$ 是初始速度，$a$ 是加速度。
- **碰撞模型**：描述物体在碰撞时的相互作用。碰撞模型通常表示为动量守恒和能量守恒定律，例如 $m_1v_{1i} + m_2v_{2i} = m_1v_{1f} + m_2v_{2f}$ 和 $E_{ki} + E_{ki} = E_{kf} + E_{kf}$，其中 $m_1$ 和 $m_2$ 是两个物体的质量，$v_{1i}$ 和 $v_{2i}$ 是碰撞前的速度，$v_{1f}$ 和 $v_{2f}$ 是碰撞后的速度。

**算法：** 算法是实现数学模型的具体步骤。在游戏物理引擎中，常用的算法包括：

- **欧拉法**：用于数值求解微分方程，实现物体的连续运动模拟。欧拉法的迭代公式为 $x_{n+1} = x_n + v_n\Delta t$，其中 $x_n$ 是当前时刻的位置，$v_n$ 是当前时刻的速度，$\Delta t$ 是时间步长。
- **龙格-库塔法**：用于提高欧拉法的精度。龙格-库塔法的迭代公式为 $x_{n+1} = x_n + \frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)\Delta t$，其中 $k_1, k_2, k_3, k_4$ 是计算过程中的中间值。

通过数学模型和算法，我们可以精确地计算物体的运动、碰撞和相互作用，从而实现逼真的物理模拟。

#### 4.2 碰撞检测的数学模型

$$
d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}
$$

- **球-面碰撞检测**：

$$
d = \frac{|ax_1 + by_1 + cz_1 + d|}{\sqrt{a^2 + b^2 + c^2}}
$$

**举例说明：**

假设有两个球体，球体 A 的中心位置为 $(1, 2, 3)$，半径为 1；球体 B 的中心位置为 $(4, 5, 6)$，半径为 2。我们可以计算它们之间的距离：

$$
d = \sqrt{(4 - 1)^2 + (5 - 2)^2 + (6 - 3)^2} = \sqrt{3^2 + 3^2 + 3^2} = \sqrt{27} = 3\sqrt{3}
$$

由于球体 A 和球体 B 的半径之和为 3，所以它们没有发生碰撞。

再假设有一个平面，其方程为 $x + 2y - z = 1$。球体 A 的中心位置为 $(1, 2, 3)$，我们可以计算球体 A 与平面的距离：

$$
d = \frac{|1 \cdot 1 + 2 \cdot 2 - 3 \cdot 3 + 1|}{\sqrt{1^2 + 2^2 + (-1)^2}} = \frac{|1 + 4 - 9 + 1|}{\sqrt{6}} = \frac{|-3|}{\sqrt{6}} = \frac{3}{\sqrt{6}} = \frac{\sqrt{6}}{2}

由于球体 A 的半径为 1，所以球体 A 与平面发生了碰撞。

1. **创建弹球和墙体**：

   ball_radius = 20

           if event.type == pygame.QUIT:

       ball.x += ball_velocity[0]
       ball.y += ball_velocity[1]

       if pygame.sprite.collide_rect(ball, wall_top):

       pygame.draw.rect(screen, (0, 0, 0), wall_bottom)
