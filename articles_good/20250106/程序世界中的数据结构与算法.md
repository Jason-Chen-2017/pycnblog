### 2.1 线性表的定义与特性

线性表是一种基本的数据结构，它由一组元素组成，这些元素在计算机中按照线性顺序排列。线性表的特点是每个元素都有唯一的前驱和后继，除了第一个元素没有前驱，最后一个元素没有后继。

#### 2.1.1 线性表的定义

线性表可以看作是一个包含若干个元素的数据集合，这些元素按线性顺序排列。线性表通常用数组或链表来实现。数组实现线性表时，元素按照索引顺序存储；链表实现线性表时，元素通过指针链接。

#### 2.1.2 线性表的特点

线性表具有以下特点：
- 线性：元素在表中按线性顺序排列，每个元素只有一个前驱和一个后继。
- 唯一性：每个元素在表中唯一存在。
- 增长性：线性表可以动态地增加或删除元素。

### 2.2 线性表的存储结构

线性表的存储结构主要有两种：顺序存储结构和链式存储结构。

#### 2.2.1 顺序存储结构

顺序存储结构使用数组来存储线性表。在这种结构中，元素按照其在表中的顺序连续存储在数组中。顺序存储结构的特点是访问速度快，插入和删除操作较慢。时间复杂度如下：
- 访问操作：\(O(1)\)
- 插入操作：\(O(n)\)
- 删除操作：\(O(n)\)

#### 2.2.2 链式存储结构

链式存储结构使用链表来存储线性表。在这种结构中，每个元素由一个节点表示，节点包含数据和指向下一个节点的指针。链式存储结构的特点是插入和删除操作较快，但访问速度较慢。时间复杂度如下：
- 访问操作：\(O(n)\)
- 插入操作：\(O(1)\)
- 删除操作：\(O(1)\)

### 2.3 线性表的操作算法

线性表支持多种操作，包括插入、删除、查找等。以下介绍线性表的主要操作算法。

#### 2.3.1 插入算法

插入算法用于在表中添加新元素。在顺序存储结构中，插入操作需要将插入位置后的元素依次向后移动，时间复杂度为\(O(n)\)。在链式存储结构中，插入操作只需改变相应节点的指针，时间复杂度为\(O(1)\)。

Python代码示例：

```python
def insert(array, index, value):
    array.insert(index, value)

def insert_linked_list(head, index, value):
    new_node = Node(value)
    if index == 0:
        new_node.next = head
        head = new_node
    else:
        current = head
        for _ in range(index - 1):
            current = current.next
        new_node.next = current.next
        current.next = new_node
```

#### 2.3.2 删除算法

删除算法用于从表中移除元素。在顺序存储结构中，删除操作需要将删除位置后的元素依次向前移动，时间复杂度为\(O(n)\)。在链式存储结构中，删除操作只需改变相应节点的指针，时间复杂度为\(O(1)\)。

Python代码示例：

```python
def delete(array, index):
    if index < 0 or index >= len(array):
        return None
    return array.pop(index)

def delete_linked_list(head, index):
    if index < 0 or index >= length(head):
        return None
    if index == 0:
        head = head.next
    else:
        current = head
        for _ in range(index - 1):
            current = current.next
        current.next = current.next.next
```

#### 2.3.3 查找算法

查找算法用于在表中找到特定元素。线性表的查找算法通常使用线性查找或二分查找。线性查找的时间复杂度为\(O(n)\)，二分查找的时间复杂度为\(O(\log n)\)。

Python代码示例：

```python
def linear_search(array, target):
    for i, value in enumerate(array):
        if value == target:
            return i
    return -1

def binary_search(array, target):
    left, right = 0, len(array) - 1
    while left <= right:
        mid = (left + right) // 2
        if array[mid] == target:
            return mid
        elif array[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### 3.1 栈的定义与特性

栈（Stack）是一种后进先出（Last In, First Out, LIFO）的数据结构。它允许在一端进行插入和删除操作。栈的基本操作包括入栈、出栈和查看栈顶元素。

#### 3.1.1 栈的定义

栈可以看作是一种特殊的线性表，其中元素的插入和删除操作都限定在表的一端进行。这端被称为栈顶（Top），另一端被称为栈底（Bottom）。新加入的元素位于栈顶，而最先被移除的元素位于栈底。

#### 3.1.2 栈的特点

栈具有以下特点：
- 后进先出：最后入栈的元素最先出栈。
- 增长边界：栈的容量通常固定，当栈满时无法再进行入栈操作。
- 递归支持：栈是递归调用的基础，许多递归算法依赖于栈结构。

### 3.2 栈的存储结构

栈的存储结构主要有两种：顺序存储结构和链式存储结构。

#### 3.2.1 顺序存储结构

顺序存储结构使用数组来存储栈元素。在这种结构中，元素按照线性顺序存储在数组中，栈顶指针指向数组的最后一个元素。

时间复杂度：
- 入栈操作：\(O(1)\)
- 出栈操作：\(O(1)\)
- 查看栈顶元素：\(O(1)\)

Python代码示例：

```python
class Stack:
    def __init__(self):
        self.array = []
        self.top = -1

    def push(self, value):
        self.array.append(value)
        self.top += 1

    def pop(self):
        if self.is_empty():
            return None
        self.top -= 1
        return self.array.pop()

    def peek(self):
        if self.is_empty():
            return None
        return self.array[self.top]

    def is_empty(self):
        return self.top == -1
```

#### 3.2.2 链式存储结构

链式存储结构使用链表来存储栈元素。在这种结构中，栈顶节点存储栈顶元素，每个节点包含数据和指向下一个节点的指针。

时间复杂度：
- 入栈操作：\(O(1)\)
- 出栈操作：\(O(1)\)
- 查看栈顶元素：\(O(1)\)

Python代码示例：

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

class Stack:
    def __init__(self):
        self.top = None

    def push(self, value):
        new_node = Node(value)
        new_node.next = self.top
        self.top = new_node

    def pop(self):
        if self.is_empty():
            return None
        value = self.top.value
        self.top = self.top.next
        return value

    def peek(self):
        if self.is_empty():
            return None
        return self.top.value

    def is_empty(self):
        return self.top is None
```

### 3.3 栈的操作算法

栈支持的主要操作包括入栈、出栈和查看栈顶元素。

#### 3.3.1 入栈算法

入栈算法将新元素添加到栈顶。在顺序存储结构中，入栈操作只需将栈顶指针向后移动；在链式存储结构中，入栈操作只需创建新节点并将它设置为栈顶节点。

Python代码示例：

```python
def push(stack, value):
    stack.top = Node(value)
```

#### 3.3.2 出栈算法

出栈算法移除栈顶元素。在顺序存储结构中，出栈操作需要将栈顶指针向前移动；在链式存储结构中，出栈操作只需删除栈顶节点。

Python代码示例：

```python
def pop(stack):
    if stack.is_empty():
        return None
    value = stack.top.value
    stack.top = stack.top.next
    return value
```

#### 3.3.3 查看栈顶元素算法

查看栈顶元素算法返回栈顶元素的值，而不改变栈的状态。在顺序存储结构中，查看栈顶元素只需访问栈顶指针指向的元素；在链式存储结构中，查看栈顶元素只需访问栈顶节点的值。

Python代码示例：

```python
def peek(stack):
    if stack.is_empty():
        return None
    return stack.top.value
```

### 3.4 队列的定义与特性

队列（Queue）是一种先进先出（First In, First Out, FIFO）的数据结构。它允许在一端进行插入操作，在另一端进行删除操作。

#### 3.4.1 队列的定义

队列可以看作是一种特殊的线性表，其中元素的插入和删除操作分别限定在表的两端进行。插入操作在一端进行，称为队尾（Tail）；删除操作在另一端进行，称为队头（Head）。

#### 3.4.2 队列的特点

队列具有以下特点：
- 先进先出：最先进入队列的元素最先被移除。
- 增长边界：队列的容量通常固定，当队列满时无法再进行插入操作。
- 消息传递：队列广泛应用于消息传递系统，如邮箱、任务队列等。

### 3.5 队列的存储结构

队列的存储结构主要有两种：顺序存储结构和链式存储结构。

#### 3.5.1 顺序存储结构

顺序存储结构使用数组来存储队列元素。在这种结构中，元素按照线性顺序存储在数组中，队头指针指向数组的第一个元素，队尾指针指向数组的最后一个元素。

时间复杂度：
- 入队操作：\(O(1)\)
- 出队操作：\(O(1)\)
- 查看队首元素：\(O(1)\)

Python代码示例：

```python
class Queue:
    def __init__(self):
        self.array = []
        self.head = 0
        self.tail = 0

    def enqueue(self, value):
        self.array.append(value)
        self.tail += 1

    def dequeue(self):
        if self.is_empty():
            return None
        value = self.array[self.head]
        self.head += 1
        return value

    def is_empty(self):
        return self.head == self.tail

    def size(self):
        return self.tail - self.head
```

#### 3.5.2 链式存储结构

链式存储结构使用链表来存储队列元素。在这种结构中，队头节点存储队首元素，队尾节点存储队尾元素，每个节点包含数据和指向下一个节点的指针。

时间复杂度：
- 入队操作：\(O(1)\)
- 出队操作：\(O(1)\)
- 查看队首元素：\(O(1)\)

Python代码示例：

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

class Queue:
    def __init__(self):
        self.head = None
        self.tail = None

    def enqueue(self, value):
        new_node = Node(value)
        if self.is_empty():
            self.head = new_node
        else:
            self.tail.next = new_node
        self.tail = new_node

    def dequeue(self):
        if self.is_empty():
            return None
        value = self.head.value
        self.head = self.head.next
        if self.is_empty():
            self.tail = None
        return value

    def is_empty(self):
        return self.head is None

    def size(self):
        count = 0
        current = self.head
        while current:
            count += 1
            current = current.next
        return count
```

队列支持的主要操作包括入队、出队和查看队首元素。

#### 3.6.1 入队算法

入队算法将新元素添加到队尾。在顺序存储结构中，入队操作只需将队尾指针向后移动；在链式存储结构中，入队操作只需创建新节点并将它设置为队尾节点。

    def build_next(sub_string):
        next = [0] * len(sub_string)
        j = 0
        for i in range(1, len(sub_string)):
            while j > 0 and sub_string[i] != sub_string[j]:
                j = next[j - 1]
            if sub_string[i] == sub_string[j]:
                j += 1
            next[i] = j
        return next

    next = build_next(sub_string)
    i = j = 0
    while i < len(string) and j < len(sub_string):
        if string[i] == sub_string[j]:
            i += 1
            j += 1
        elif j > 0:
            j = next[j - 1]
        else:
            i += 1

广度优先搜索（BFS）是一种用于遍历广义表的算法，它从根节点开始，逐层遍历节点，直到找到目标节点或遍历整个广义表。

时间复杂度：
- BFS：\(O(n)\)

Python代码示例：

```python
from collections import deque

def bfs(table):
    if isinstance(table, str):
        print(table)
    else:
        queue = deque([table])
        while queue:
            current = queue.popleft()
            if isinstance(current, str):
                print(current)
            else:
                for element in current:
                    queue.append(element)
```

#### 6.3.3 前序遍历算法

前序遍历（Preorder Traversal）是一种用于遍历广义表的算法，它按照“访问根节点、遍历左子树、遍历右子树”的顺序进行。

时间复杂度：
- 前序遍历：\(O(n)\)

Python代码示例：

```python
def preorder_traversal(table):
    if isinstance(table, str):
        print(table)
    else:
        print(table[0], end=" ")
        for element in table[1:]:
            preorder_traversal(element)
```

### 7.1 树的定义与特性

树（Tree）是一种重要的非线性数据结构，由一组节点（Node）组成。每个节点包含一个数据元素和一个或多个子节点。树在计算机科学中广泛应用于组织数据、实现算法和表示复杂结构。

#### 7.1.1 树的定义

树是一种层次化的数据结构，具有以下特性：
- 根节点（Root）：树的第一个节点称为根节点，它是树的入口。
- 节点（Node）：树中的每个节点包含一个数据元素和一个或多个子节点。
- 子节点（Child）：一个节点可以有零个或多个子节点。
- 父节点（Parent）：每个节点都有一个唯一的父节点，根节点没有父节点。
- 叶节点（Leaf）：没有子节点的节点称为叶节点。

#### 7.1.2 树的特点

树具有以下特点：
- 层次结构：树中的节点按照层次排列，根节点位于第一层，其子节点位于第二层，以此类推。
- 分支结构：每个节点可以有零个或多个子节点，形成分支结构。
- 唯一根节点：树只有一个根节点，没有重复的节点。
- 无环：树中没有闭合的路径，即不存在环路。

### 7.2 树的存储结构

树的存储结构主要有两种：顺序存储结构和链式存储结构。

#### 7.2.1 顺序存储结构

顺序存储结构使用数组来存储树的节点。在这种结构中，数组的每个位置存储一个节点的数据，通过节点的索引可以访问其子节点。然而，顺序存储结构难以适应动态变化的树。

时间复杂度：
- 节点访问：\(O(1)\)
- 节点插入/删除：\(O(n)\)

Python代码示例：

```python
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.children = []

def build_tree(array):
    if not array:
        return None
    root = TreeNode(array[0])
    for value in array[1:]:
        root.children.append(build_tree([value]))
    return root
```

#### 7.2.2 链式存储结构

链式存储结构使用链表来存储树的节点。在这种结构中，每个节点包含一个数据元素和一个指向子节点的指针。链式存储结构适用于动态变化的树。

时间复杂度：
- 节点访问：\(O(n)\)
- 节点插入/删除：\(O(1)\)

Python代码示例：

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.parent = None
        self.children = []

def build_tree_linked(list):
    if not list:
        return None
    root = Node(list[0])
    for value in list[1:]:
        new_node = Node(value)
        new_node.parent = root
        root.children.append(new_node)
    return root
```

### 7.3 树的遍历算法

树的遍历算法用于遍历树中的所有节点。常见的遍历算法包括先序遍历、中序遍历和后序遍历。

#### 7.3.1 先序遍历

先序遍历（Preorder Traversal）按照“访问根节点、遍历左子树、遍历右子树”的顺序进行。先序遍历的顺序是先访问根节点，然后递归遍历左子树，最后递归遍历右子树。

时间复杂度：
- 先序遍历：\(O(n)\)

Python代码示例：

```python
def preorder_traversal(node):
    if node is None:
        return
    print(node.value, end=" ")
    for child in node.children:
        preorder_traversal(child)
```

#### 7.3.2 中序遍历

中序遍历（Inorder Traversal）按照“遍历左子树、访问根节点、遍历右子树”的顺序进行。中序遍历的顺序是先递归遍历左子树，然后访问根节点，最后递归遍历右子树。

时间复杂度：
- 中序遍历：\(O(n)\)

Python代码示例：

```python
def inorder_traversal(node):
    if node is None:
        return
    inorder_traversal(node.left)
    print(node.value, end=" ")
    inorder_traversal(node.right)
```

#### 7.3.3 后序遍历

后序遍历（Postorder Traversal）按照“遍历左子树、遍历右子树、访问根节点”的顺序进行。后序遍历的顺序是先递归遍历左子树，然后递归遍历右子树，最后访问根节点。

时间复杂度：
- 后序遍历：\(O(n)\)

Python代码示例：

```python

        return
    for child in node.children:
        postorder_traversal(child)
    print(node.value, end=" ")
```

### 8.1 二叉树的定义与特性

二叉树（Binary Tree）是一种重要的树形数据结构，每个节点最多有两个子节点，通常称为左子节点和右子节点。二叉树在计算机科学中广泛应用于算法实现、数据排序和查找等领域。

#### 8.1.1 二叉树的定义

二叉树是有限的节点集合，满足以下特性：
- 每个节点都有一个空树或一个根节点。
- 每个根节点有两棵子树，分别称为左子树和右子树。
- 左子树和右子树也是二叉树。
- 没有循环。

#### 8.1.2 二叉树的特点

二叉树具有以下特点：
- 每个节点最多有两个子节点。
- 树的高度是节点的最大层次。
- 树的叶子节点数量等于度为2的节点数量加1。

### 8.2 二叉树的存储结构

二叉树的存储结构主要有两种：链式存储结构和数组存储结构。

#### 8.2.1 链式存储结构

链式存储结构使用链表来存储二叉树的节点。在这种结构中，每个节点包含一个数据元素和一个指向左右子节点的指针。

时间复杂度：
- 节点访问：\(O(n)\)
- 节点插入/删除：\(O(1)\)

Python代码示例：

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

def create_tree(values):
    if not values:
        return None
    root = Node(values[0])
    for value in values[1:]:
        new_node = Node(value)
        current = root
        parent = None
        while current:
            parent = current
            if value < current.value:
                current = current.left
            else:
                current = current.right
        if value < parent.value:
            parent.left = new_node
        else:
            parent.right = new_node
    return root
```

#### 8.2.2 数组存储结构

数组存储结构使用数组来存储二叉树的节点。在这种结构中，数组索引表示节点的位置，左子节点和右子节点的索引分别为\(2i\)和\(2i+1\)。

时间复杂度：
- 节点访问：\(O(1)\)
- 节点插入/删除：\(O(n)\)

Python代码示例：

```python
def build_tree(values):
    n = len(values)
    tree = [None] * (2 * n)
    for i, value in enumerate(values):
        tree[i] = Node(value)
        left_index = 2 * i + 1
        right_index = 2 * i + 2
        if left_index < 2 * n:
            tree[left_index] = Node(tree[left_index].value)
        if right_index < 2 * n:
            tree[right_index] = Node(tree[right_index].value)
    return tree
```

### 9.1 图的定义与特性

图（Graph）是一种重要的非线性数据结构，由一组节点（Vertex）和连接这些节点的边（Edge）组成。图在计算机科学中广泛应用于网络结构、算法设计、社会网络分析和可视化等领域。

#### 9.1.1 图的定义

图是由节点（也称为顶点）和边组成的集合。节点表示图中的实体，边表示节点之间的联系。图可以用一个无序对集（无向图）或有序对集（有向图）来表示。

#### 9.1.2 图的特点

图具有以下特点：
- 多样性：图可以包含任意数量的节点和边。
- 连接性：节点通过边相互连接，形成复杂的网络结构。
- 无序性：图的边无方向性，无序对表示节点之间的连接。
- 有序性：有向图的边具有方向性，有序对表示节点的方向关系。
- 连通性：图中的任意两个节点之间存在路径。

### 9.2 图的存储结构

图的存储结构主要有两种：邻接矩阵和邻接表。

#### 9.2.1 邻接矩阵

邻接矩阵是一个二维数组，用于存储图中的节点及其之间的边。在无向图中，矩阵的对称轴是对角线，表示边的存在性；在有向图中，矩阵不对称，表示边的方向。

时间复杂度：
- 节点访问：\(O(1)\)
- 节点插入/删除：\(O(n^2)\)

Python代码示例：

```python
def create_adj_matrix(vertices, edges):
    matrix = [[0] * len(vertices) for _ in range(len(vertices))]
    for edge in edges:
        node1, node2 = edge
        matrix[node1][node2] = 1
        matrix[node2][node1] = 1
    return matrix
```

#### 9.2.2 邻接表

邻接表使用数组或链表来存储图中的节点及其边。在数组实现中，每个位置存储一个节点的边列表；在链表实现中，每个节点包含一个值和一个指向下一个节点的指针。

时间复杂度：
- 节点访问：\(O(n)\)
- 节点插入/删除：\(O(1)\)

Python代码示例（数组实现）：

```python
def create_adj_list(vertices, edges):
    adj_list = [[] for _ in range(len(vertices))]
    for edge in edges:
        node1, node2 = edge
        adj_list[node1].append(node2)
        adj_list[node2].append(node1)
    return adj_list
```

### 9.3 图的遍历算法

图的遍历算法包括深度优先搜索（DFS）和广度优先搜索（BFS）。

#### 9.3.1 深度优先搜索

深度优先搜索（DFS）是一种用于遍历图的方法，它从起点开始，沿一条路径深入到最远节点，然后回溯并探索其他路径。

时间复杂度：
- DFS：\(O(n+m)\)

Python代码示例：

```python
def dfs(graph, start):
    visited = set()
    stack = [start]
    while stack:
        vertex = stack.pop()
        if vertex not in visited:
            visited.add(vertex)
            print(vertex, end=" ")
            neighbors = graph[vertex]
            stack.extend([v for v in neighbors if v not in visited])
```

#### 9.3.2 广度优先搜索

广度优先搜索（BFS）是一种用于遍历图的方法，它从起点开始，逐层遍历节点，直到找到目标节点或遍历整个图。

时间复杂度：
- BFS：\(O(n+m)\)

Python代码示例：

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    while queue:
        vertex = queue.popleft()
        if vertex not in visited:
            visited.add(vertex)
            print(vertex, end=" ")
            neighbors = graph[vertex]
            queue.extend([v for v in neighbors if v not in visited])
```

#### 9.4.1 Dijkstra算法

Dijkstra算法是一种用于计算单源最短路径的算法，它能够找到从源节点到其他所有节点的最短路径。

时间复杂度：
- Dijkstra算法：\(O((n+m)\log n)\)

Python代码示例：

```python
import heapq

def dijkstra(graph, start):
    distances = {vertex: float('infinity') for vertex in graph}
    distances[start] = 0
    priority_queue = [(0, start)]
    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)
        if current_distance > distances[current_vertex]:
            continue
        for neighbor, weight in graph[current_vertex].items():
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    return distances
```
