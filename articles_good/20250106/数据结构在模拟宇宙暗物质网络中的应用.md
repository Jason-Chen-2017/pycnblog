### 第2章：数据结构的基础知识

#### 2.1 数据结构的基本概念

数据结构是计算机科学中用于存储和管理数据的组织形式。它包括数据元素的集合和数据的组织方式。数据结构的主要目的是高效地组织和访问数据，以满足特定的应用需求。

#### 2.2 常见的数据结构

常见的数据结构包括数组、链表、栈、队列、树和图等。每种数据结构都有其独特的特点和适用场景。

- **数组**：一种线性数据结构，用于存储一系列元素。数组在访问和修改元素时具有高效性。
- **链表**：一种动态数据结构，由一系列节点组成。链表在插入和删除元素时具有高效性。
- **栈**：一种后进先出（LIFO）的数据结构，用于存储和检索最近访问的元素。
- **队列**：一种先进先出（FIFO）的数据结构，用于存储和检索最早访问的元素。
- **树**：一种层次化的数据结构，由节点和边组成。树在表示层次结构和树形关系时非常有用。
- **图**：一种由节点和边组成的数据结构，用于表示复杂的关系和网络。

以下是一个简单的Python代码实现：

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

# 初始化链表
head = Node(1)
node2 = Node(2)
node3 = Node(3)

head.next = node2
node2.next = node3

# 数据输入
connections = [(1, 2), (2, 3)]

# 拓扑结构构建
for conn in connections:
    current = head
    while current.next:
        if current.value == conn[0]:
            new_node = Node(conn[1])
            new_node.next = current.next
            current.next = new_node
            break
        current = current.next

# 拓扑结构分析
current = head
while current:
    print(current.value)
    current = current.next
```

3. **聚集体构建**：根据输入的聚集关系，构建树结构，表示暗物质聚集体的层次结构。
4. **聚集体分析**：对构建好的树结构进行遍历和分析，提取有用的聚集特征。

以下是一个简单的Python代码实现：

```python
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.children = []

# 初始化树结构
root = TreeNode(1)

# 数据输入
parent_child_pairs = [(1, 2), (1, 3), (2, 4), (3, 5)]

# 聚集体构建
for pair in parent_child_pairs:
    parent = root
    while parent:
        if parent.value == pair[0]:
            child = TreeNode(pair[1])
            parent.children.append(child)
            break
        parent = parent.children

# 聚集体分析
def print_tree(node):
    print(node.value)
    for child in node.children:
        print_tree(child)

print_tree(root)
```
