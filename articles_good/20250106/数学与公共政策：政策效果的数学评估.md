#### 2.1 统计学方法

**描述性统计分析**

描述性统计分析主要是通过计算一些基本的统计量（如平均数、中位数、众数、标准差等）来描述数据的基本特征。在政策评估中，描述性统计分析可以帮助我们了解政策实施前后的数据变化情况。

- **政策实施前的数据描述**：例如，在教育政策评估中，可以统计政策实施前学生的平均成绩、及格率等。
- **政策实施后的数据描述**：同样地，可以统计政策实施后学生的平均成绩、及格率等。

**推断性统计分析**

推断性统计分析是基于样本数据对总体进行推断的一种方法。在政策评估中，我们通常无法获取所有受政策影响的数据，因此需要通过样本数据来推断总体的特征。

- **参数估计**：例如，可以通过对政策实施后学生成绩的样本平均数来估计总体学生的平均成绩。
- **假设检验**：例如，可以通过t检验来检验政策实施前后学生成绩的显著差异。

**应用实例**

假设我们正在评估一项新的教育政策对学生成绩的影响。我们可以收集政策实施前后的一组学生成绩数据，然后：

1. **描述性统计分析**：计算政策实施前后的平均成绩、标准差等。
2. **推断性统计分析**：使用t检验来比较政策实施前后学生成绩的显著性差异。

动态规划是一种解决多阶段决策问题的方法，通过递归关系和最优子结构原理，找到全局最优解。它常用于资源分配、路径规划等问题。

def dynamicPlanning(cashFlow, benefitMatrix):
    # 初始化动态规划表
    dp = [[0 for _ in range(len(cashFlow))] for _ in range(len(benefitMatrix))]

    # 填充动态规划表
    for i in range(1, len(benefitMatrix)):
        for j in range(1, len(cashFlow)):
            if cashFlow[j] >= benefitMatrix[i][j]:
                dp[i][j] = max(dp[i-1][j], dp[i-1][j-cashFlow[j]] + benefitMatrix[i][j])
            else:
                dp[i][j] = dp[i-1][j]

    # 返回最优解
    return dp[-1][-1]
