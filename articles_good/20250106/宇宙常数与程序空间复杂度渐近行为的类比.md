#### 二分查找算法的基本原理

二分查找算法是一种高效的查找算法，它通过将有序数组分成两半，逐步缩小查找范围，以实现对数组中某个元素的快速定位。其基本原理如下：

1. **初始条件**：给定一个有序数组 `A` 和一个目标值 `x`，设置两个指针 `low` 和 `high` 分别指向数组的第一个和最后一个元素。
2. **查找过程**：在每次迭代中，计算中间位置 `mid = (low + high) / 2`，然后比较目标值 `x` 与中间位置的值 `A[mid]`：
   - 如果 `x == A[mid]`，则查找成功，返回 `mid`；
   - 如果 `x < A[mid]`，则更新 `high = mid - 1`，继续在左侧子数组中查找；
   - 如果 `x > A[mid]`，则更新 `low = mid + 1`，继续在右侧子数组中查找。
3. **结束条件**：当 `low > high` 时，查找失败，返回 `-1`。

#### 时间复杂度分析

二分查找算法的时间复杂度主要取决于数组的大小 \( n \)。在最坏情况下，算法需要 \( \log_2(n) \) 次比较才能找到目标值或确定其不存在。因此，二分查找算法的时间复杂度为 \( O(\log n) \)。

我们可以通过递归树来可视化这个时间复杂度。每次递归都会将问题规模减半，直到找到目标值或确定其不存在。递归树的高度为 \( \log_2(n) \)，每个节点的时间复杂度为 \( O(1) \)，因此总时间复杂度为 \( O(\log n) \)。

#### 空间复杂度分析

二分查找算法的空间复杂度相对较低。它主要依赖于栈空间，用于存储递归过程中的中间变量。在最坏情况下，算法需要递归 \( \log_2(n) \) 次才能找到目标值或确定其不存在。因此，二分查找算法的空间复杂度为 \( O(\log n) \)。

通过递归树的视角，我们可以看到，每次递归都会在栈上分配一个新节点，直到达到叶节点。递归树的高度为 \( \log_2(n) \)，因此需要的栈空间也为 \( O(\log n) \)。

为了进一步深入理解二分查找算法，我们可以使用数学模型和公式来描述其时间复杂度和空间复杂度。

其中，\( T(n) \) 表示二分查找算法在数组大小为 \( n \) 时的最坏情况时间复杂度。

其中，\( S(n) \) 表示二分查找算法在数组大小为 \( n \) 时的最坏情况空间复杂度。

通过上述分析，我们可以看到二分查找算法在时间复杂度和空间复杂度方面都具有 \( O(\log n) \) 的渐近复杂度。这些复杂度特性使得二分查找算法在处理大规模数据时具有高效性。

   public class BinarySearch {
       public static int search(int[] arr, int x) {
           int low = 0;
           int high = arr.length - 1;
           while (low <= high) {
               int mid = (low + high) / 2;
               if (arr[mid] == x) {
                   return mid;
               } else if (arr[mid] < x) {
                   low = mid + 1;
               } else {
                   high = mid - 1;
               }
           }
           return -1;
       }
   }
