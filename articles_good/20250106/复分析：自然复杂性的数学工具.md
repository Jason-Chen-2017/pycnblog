### 第二部分：复分析的核心概念与原理

#### 第2章：复数的基本性质与复变量函数

##### 2.1 复数的基本性质

复数是复分析的基础，了解复数的基本性质是掌握复分析的关键。复数由实部和虚部组成，通常表示为 $a + bi$，其中 $a$ 和 $b$ 是实数，$i$ 是虚数单位，满足 $i^2 = -1$。

- **定义与表示**：复数可以表示为平面上的点，其实部表示横坐标，虚部表示纵坐标。例如，复数 $1 + 2i$ 可以表示为平面上的点 $(1, 2)$。

- **运算规则**：复数的基本运算包括加法、减法、乘法和除法。

  - 加法和减法类似于实数的运算，只是将虚数部分也考虑在内。
  - 乘法和除法则涉及到复数的模和幅角。

  例如，两个复数 $(a + bi)$ 和 $(c + di)$ 的乘法规则如下：
  $$ (a + bi)(c + di) = (ac - bd) + (ad + bc)i $$

- **模与幅角**：复数的模是指其长度，即 $|z| = \sqrt{a^2 + b^2}$。复数的幅角是指其在复平面上的旋转角度，通常用 $\theta$ 表示，满足 $\theta = \arctan(\frac{b}{a})$。

##### 2.2 复变量函数

复变量函数是复分析的研究对象，其定义域和值域都是复数。复变量函数可以看作是复数域上的映射，将一个复数映射到另一个复数。

- **定义与表示**：一个复变量函数通常表示为 $f(z)$，其中 $z$ 是复变量。例如，函数 $f(z) = z^2$ 表示将复数 $z$ 映射到它的平方。

- **分类**：复变量函数可以根据其性质进行分类。常见的分类包括：
  - **解析函数**：满足一定条件的复变量函数，如可以无限次微分。
  - **全纯函数**：解析函数的一种特殊类型，在整个复平面上都是解析的。
  - **非解析函数**：不满足解析函数条件的复变量函数。

- **基本性质**：复变量函数具有以下基本性质：
  - **可微性**：复变量函数可以在某些点或区域内可微，满足柯西-黎曼方程。
  - **不变性**：复变量函数具有一些不变性，如模的不变性、幅角的不变性等。
  - **积分性质**：复变量函数的积分可以通过柯西积分公式来计算。

##### 2.3 解析函数

解析函数是复分析中最核心的概念之一，它满足一定的条件，使得在复数域上有许多有趣的性质。

- **定义与性质**：一个复变量函数 $f(z)$ 在某个点 $z_0$ 是解析的，当且仅当它在 $z_0$ 的某个邻域内可以表示为幂级数。解析函数具有以下性质：
  - **无穷可微性**：解析函数可以在复数域上无限次微分。
  - **唯一性**：在某个解析区域内，解析函数是唯一的。
  - **可导性**：解析函数在解析区域内处处可导。

- **表示与分类**：解析函数可以通过幂级数来表示。一个解析函数 $f(z)$ 可以表示为：
  $$ f(z) = \sum_{n=0}^{\infty} a_n (z - z_0)^n $$
  其中 $a_n$ 是常数。根据幂级数的收敛性，可以将解析函数分为以下几类：
  - **局部解析函数**：在某个点或某个区域内解析的函数。
  - **全局解析函数**：在整个复平面上解析的函数。
  - **全纯函数**：在整个复平面上解析且无奇点的函数。

- **应用**：解析函数在数学和其他领域中都有广泛的应用。例如，在物理学中，解析函数可以用来描述电磁场、流体力学等现象。在工程学中，解析函数可以用于信号处理、控制理论等领域。

### 第三部分：复分析的基本定理与应用

#### 第3章：复分析的基本定理

##### 3.1 洛朗级数

洛朗级数是复分析中的一个重要工具，用于将复变量函数展开为幂级数。洛朗级数的定义与泰勒级数类似，但允许函数在某个点附近有一个奇点。

- **定义与性质**：洛朗级数的定义如下：
  $$ f(z) = \sum_{n=0}^{\infty} a_n (z - z_0)^n + \sum_{n=1}^{\infty} b_n (z - z_0)^{-n} $$
  其中 $z_0$ 是奇点，$a_n$ 和 $b_n$ 是常数。洛朗级数具有以下性质：
  - **收敛性**：洛朗级数在某个点的收敛性取决于函数在该点的奇点性质。
  - **展开性**：洛朗级数可以用来展开具有奇点的复变量函数。
  - **可微性**：洛朗级数可以用来计算复变量函数的高阶导数。

- **应用**：洛朗级数在复分析中有着广泛的应用。例如，在求解复积分、计算复函数的极限和无穷小量等方面，洛朗级数都起到了关键作用。此外，洛朗级数还可以用来研究复变量函数的奇点和留数。

##### 3.2 柯西积分定理

柯西积分定理是复分析中的一个重要定理，它揭示了复积分与复变量函数之间的关系。柯西积分定理分为两个部分：柯西积分公式和柯西积分定理。

- **柯西积分公式**：柯西积分公式是柯西积分定理的核心，它表述为：
  $$ f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_{C} \frac{f(z)}{(z - z_0)^{n+1}} dz $$
  其中 $f(z)$ 是解析函数，$z_0$ 是积分点，$C$ 是围绕 $z_0$ 的闭合曲线。柯西积分公式可以用来计算解析函数的高阶导数。

- **柯西积分定理**：柯西积分定理是柯西积分公式的推广，它表述为：
  $$ \oint_{C} f(z) dz = 0 $$
  其中 $f(z)$ 是在闭合曲线 $C$ 内部的区域内解析的函数。柯西积分定理揭示了复积分与函数解析性之间的关系。

- **应用**：柯西积分定理在复分析中有着广泛的应用。例如，在计算复积分、研究复函数的零点和极点等方面，柯西积分定理都起到了关键作用。此外，柯西积分定理还可以用来证明其他重要定理，如莫雷拉定理和洛朗级数定理。

##### 3.3 柯西积分公式

柯西积分公式是复分析中的一个重要工具，用于计算复积分。柯西积分公式分为两个部分：第一型柯西积分公式和第二型柯西积分公式。

- **第一型柯西积分公式**：第一型柯西积分公式表述为：
  $$ \oint_{C} \frac{f(z)}{z - z_0} dz = 2\pi i f(z_0) $$
  其中 $f(z)$ 是在闭合曲线 $C$ 内部的区域内解析的函数，$z_0$ 是积分点。第一型柯西积分公式可以用来计算函数在积分点的值。

- **第二型柯西积分公式**：第二型柯西积分公式表述为：
  $$ \oint_{C} \frac{f(z)}{(z - z_0)^2} dz = \pi i \left[ f(z_0) - f'(z_0) \right] $$
  其中 $f(z)$ 是在闭合曲线 $C$ 内部的区域内解析的函数，$z_0$ 是积分点。第二型柯西积分公式可以用来计算函数在积分点的导数。

- **应用**：柯西积分公式在复分析中有着广泛的应用。例如，在计算复积分、研究复函数的零点和极点等方面，柯西积分公式都起到了关键作用。此外，柯西积分公式还可以用来证明其他重要定理，如莫雷拉定理和洛朗级数定理。

### 第五部分：复分析的高级话题

#### 第5章：复解析几何

复解析几何是复分析的一个分支，研究复数域上的几何问题。复解析几何与实解析几何有很大的不同，它利用复数的特性来研究几何形状和变换。

##### 5.1 复解析几何的基本概念

- **复平面**：复平面是一个二维平面，用于表示复数。复平面上的点对应于复数，其实部表示横坐标，虚部表示纵坐标。

- **复解析变换**：复解析变换是一种将复平面上的点映射到另一个点的方法。复解析变换可以看作是复变量函数的复合，它保持了复平面的几何结构。

- **复解析映射**：复解析映射是一种将复平面上的开集映射到另一个开集的方法。复解析映射保持了复平面上的连通性和连续性。

##### 5.2 复解析几何的应用

- **复平面上的几何形状**：复解析几何可以用来研究复平面上的几何形状，如圆、椭圆、双曲线等。通过复解析变换，可以更方便地研究这些形状的对称性、交点和性质。

- **计算机图形学**：复解析几何在计算机图形学中有着重要的应用。通过复解析变换，可以生成复杂的几何图形，如曲面、螺旋线等。这些图形在计算机视觉、计算机辅助设计等领域有着广泛的应用。

- **量子计算**：复解析几何在量子计算中也有应用。量子计算机利用量子位（qubit）进行计算，这些量子位的态可以用复平面上的点来表示。通过复解析变换，可以研究量子态的演化和测量结果。

#### 第6章：复动力系统

复动力系统是研究复数域上的动力行为的一个分支。复动力系统具有复杂的动力学行为，可以用来模拟和预测自然现象。

##### 6.1 复动力系统的基本概念

- **动力系统**：动力系统是一组随时间演化的状态变量。在复动力系统中，状态变量是复数。

- **复映射**：复动力系统中的演化规则可以用复映射来描述。复映射是将复平面上的点映射到另一个点的函数。

- **不动点**：复动力系统中的不动点是指动力系统的演化规则在该点上不发生改变。不动点可以是稳定的，也可以是不稳定的。

- **周期轨道**：复动力系统中的周期轨道是指动力系统的演化规则在一个周期内回到原来的点。周期轨道可以是稳定的，也可以是不稳定的。

##### 6.2 复动力系统的应用

- **物理学中的应用**：复动力系统在物理学中有着广泛的应用。例如，在量子力学中，复动力系统可以用来研究粒子的运动和相互作用。

- **生物学中的应用**：复动力系统在生物学中也有应用。例如，在生态学中，复动力系统可以用来研究物种的演化和相互作用。

- **混沌理论**：复动力系统是混沌理论的重要基础。混沌现象是指系统在初始条件微小差异下，演化出完全不同的结果。复动力系统可以用来模拟和预测混沌现象。

def f(z):

def laurent_series(z0, z):
    n = 0
    while True:
        term = z**n / (1 - z)**(n+1)
        if abs(term) < 1e-6:
            break
        n += 1
        term *= z
    return sum(term for _ in range(n))
