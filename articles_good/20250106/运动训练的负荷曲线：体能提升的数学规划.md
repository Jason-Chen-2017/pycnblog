import random
import math

def sim annealing(objective_function, bounds, max_iterations, cooling_rate):
    current = [random.uniform(bound[0], bound[1]) for bound in bounds]
    current_value = objective_function(current)
    best = current.copy()
    best_value = current_value
    
    for _ in range(max_iterations):
        next = [current[i] + random.uniform(-1, 1) for i in range(len(current))]
        next_value = objective_function(next)
        
        if next_value < current_value:
            current = next
            current_value = next_value
        elif math.exp((current_value - next_value) / cooling_rate) > random.random():
            current = next
            current_value = next_value
            
        if current_value < best_value:
            best = current.copy()
            best_value = current_value
            
        cooling_rate *= (1 - _ / max_iterations)
        
    return best, best_value

# 示例目标函数

    return sum(v[i]**2 for i in range(len(v)))

# 参数设置

cooling_rate = 0.01

# 运行模拟退火算法
best_solution, best_solution_value = sim_annealing(objective_function, bounds, max_iterations, cooling_rate)

#### 算法原理与数学模型

**1. 模拟退火算法原理**

模拟退火算法的基本思想是，通过在解空间中随机搜索，并利用概率接受较差的解，以避免陷入局部最优。其核心包括：

- **初始解**：随机生成一个初始解。
- **新解生成**：通过随机扰动生成新的解。
- **接受概率**：根据当前解与新解之间的目标函数差值，计算接受新解的概率。
- **迭代过程**：不断迭代，更新最佳解和冷却率。

**数学模型**：

- 目标函数：\( f(x) \)
- 初始解：\( x_0 \)
- 新解：\( x_{new} \)
- 接受概率：\( P = \exp\left(-\frac{f(x_{new}) - f(x_{current})}{T}\right) \)
- 冷却率：\( T \) 随迭代次数线性递减。

**2. 机器学习算法原理**

机器学习算法通过从数据中学习规律，用于预测和决策。其基本过程包括：

- **数据收集**：收集大量带有标签的数据。
- **数据预处理**：对数据进行清洗、归一化等处理。
- **模型训练**：通过训练数据训练模型。
- **模型评估**：使用测试数据评估模型性能。
- **模型调整**：根据评估结果调整模型参数。

**数学模型**：

- 数据集：\( D = \{ (x_i, y_i) \} \)
- 特征空间：\( X \)
- 标签空间：\( Y \)
- 模型：\( f: X \rightarrow Y \)
- 损失函数：\( L(y, f(x)) \)
- 模型参数：\( \theta \)
