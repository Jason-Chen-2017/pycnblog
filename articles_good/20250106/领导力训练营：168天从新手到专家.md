### 领导力的核心概念原理

领导力是一个多维度的概念，包含了许多不同的核心要素。以下我们将详细阐述领导力的几个关键概念，包括影响力、信任和授权，并通过表格和ER图来进一步分析这些概念之间的关系。

#### 1. 影响力

影响力是领导力的核心要素之一，它指的是领导者能够影响和引导他人思想和行为的能力。影响力可以分为五种基本类型：

- **专家型影响力**：基于领导者的专业知识和技能，通过专业能力赢得他人的尊重和信任。
- **参考型影响力**：基于领导者的个人特质和魅力，如自信、魅力和领导风格，赢得他人的认同。
- **奖励型影响力**：基于领导者对团队成员的奖励机制，如薪酬、晋升等，激励团队成员。
- **惩罚型影响力**：通过惩罚手段来约束和规范团队成员的行为。
- **合法性影响力**：基于领导者的职位和权力，通过正式的组织结构和管理职能来影响他人。

#### 2. 信任

信任是领导者与团队成员之间建立良好关系的基础。信任体现在以下几个方面：

- **诚实与透明**：领导者需要诚实地与团队成员沟通，保持信息的透明度，避免误导和隐瞒。
- **可靠性**：领导者需要履行承诺，按时完成任务，保持言行一致，从而赢得团队成员的信任。
- **能力**：领导者需要具备解决问题的能力，能够帮助团队成员克服困难，增强团队的信心。
- **公正性**：领导者需要公平对待团队成员，不偏袒任何一方，确保团队内部的公平竞争。

#### 3. 授权

授权是指领导者将权力和责任分配给团队成员，鼓励他们自主决策和完成任务。授权的核心要素包括：

- **信任与支持**：领导者需要信任团队成员，提供必要的资源和支持，让他们自由地发挥自己的才能。
- **明确目标与期望**：领导者需要明确团队的目标和期望，确保团队成员理解任务的重要性和目标。
- **赋予责任**：领导者需要赋予团队成员相应的责任，让他们承担决策和执行任务的责任。
- **反馈与认可**：领导者需要给予团队成员及时的反馈和认可，鼓励他们持续改进，提升工作成效。

    return jsonify({"message": "注册成功"}), 200

@app.route('/courses', methods=['GET'])
def get_courses():
    courses = Course.query.all()
    return jsonify([{"id": course.id, "name": course.name, "description": course.description} for course in courses])

@app.route('/enroll', methods=['POST'])
def enroll():
    data = request.get_json()
    participant = Participant.query.filter_by(email=data['email']).first()
    course = Course.query.filter_by(id=data['course_id']).first()
    participant.courses.append(course)
    db.session.commit()
    return jsonify({"message": "报名成功"}), 200
