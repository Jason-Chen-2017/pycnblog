```python
def find_median(sequence):
    n = len(sequence)
    if n == 0:
        return None
    if n == 1:
        return sequence[0]
    
    sorted_sequence = sorted(sequence)
    mid = n // 2
    
    if n % 2 == 0:
        return (sorted_sequence[mid - 1] + sorted_sequence[mid]) / 2
    else:
        return sorted_sequence[mid]
```

#### 1.4.3 算法原理详细讲解

**数学模型和公式**：

为了更好地理解这个算法，我们可以使用LaTeX格式嵌入数学模型和公式：

$$
\text{median}(x_1, x_2, \ldots, x_n) = \begin{cases} 
\frac{x_{\frac{n}{2}} + x_{\frac{n}{2} + 1}}{2}, & \text{if } n \text{ is even} \\
x_{\frac{n+1}{2}}, & \text{if } n \text{ is odd}
\end{cases}
$$

**举例说明**：假设我们有一个输入序列 `[3, 1, 4, 1, 5, 9]`，我们如何计算它的中位数？

1. 首先，我们计算序列的长度 `n`，这里 `n = 6`。
2. 因为 `n` 是偶数，我们需要计算第3个数和第4个数的平均值。这两个数是 `4` 和 `1`。
3. 计算平均值得到中位数：`(\frac{4 + 1}{2} = 2.5)`。

因此，输入序列 `[3, 1, 4, 1, 5, 9]` 的中位数是 `2.5`。
