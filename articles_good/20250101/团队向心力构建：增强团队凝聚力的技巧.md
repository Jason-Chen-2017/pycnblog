@RestController
@RequestMapping("/api")
public class TaskController {

    @Autowired
    private TaskRepository taskRepository;

    @PostMapping("/tasks")
    public ResponseEntity<Task> createTask(@RequestBody Task task) {
        Task savedTask = taskRepository.save(task);
        return ResponseEntity.ok(savedTask);
    }

    @GetMapping("/tasks/{id}")
    public ResponseEntity<Task> getTaskById(@PathVariable Long id) {
        Optional<Task> taskOptional = taskRepository.findById(id);
        return taskOptional.map(ResponseEntity::ok).orElse(ResponseEntity.notFound().build());
    }
}

**### 团队向心力的定义与属性**

团队向心力是指团队成员在共同目标下形成的内在驱动力，它包括以下几个属性：

1. **信任**：团队成员之间的信任是团队向心力的重要基础。信任度高，团队成员更愿意分享信息和资源。
2. **尊重**：尊重使团队成员感到被重视，有助于建立良好的团队氛围。
3. **支持**：支持包括情感支持和实际帮助，使团队成员在面对挑战时感到不是孤军奋战。
4. **归属感**：归属感使团队成员感到自己是团队的一部分，愿意为团队的荣誉和利益而努力。

**### 团队向心力的特征与影响因素**

3. **协作性**：团队成员之间能够相互支持、协同工作，共同完成团队任务。
4. **适应性**：团队向心力强的团队能够适应环境变化，灵活调整策略和行动。
