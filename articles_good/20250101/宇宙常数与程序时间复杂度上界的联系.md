#### 2.1.1 时间复杂度的定义

时间复杂度是算法分析中的一个重要指标，它描述了算法在处理输入数据时的运行时间。通常，时间复杂度用大O符号（\(O\)）表示，例如 \(O(n)\)、\(O(n^2)\) 等。时间复杂度通常用于描述算法的渐进性能，即当输入规模趋近于无穷大时的增长趋势。

- **线性时间复杂度**（\(O(n)\)）：算法的运行时间与输入规模 \(n\) 成正比。
- **二次时间复杂度**（\(O(n^2)\)）：算法的运行时间与输入规模 \(n\) 的平方成正比。
- **对数时间复杂度**（\(O(\log n)\)）：算法的运行时间与输入规模 \(n\) 的以 2 为底的对数成正比。

#### 2.1.2 时间复杂度的分析方法

分析时间复杂度通常涉及以下步骤：

1. **渐进分析**：通过分析算法的运行时间与输入规模的关系，预测算法的性能。例如，对于线性搜索算法，其时间复杂度为 \(O(n)\)，因为最坏情况下需要检查每个元素。

2. **最好、最坏、平均情况分析**：分析算法在不同输入情况下的性能。例如，对于快速排序算法，其平均时间复杂度为 \(O(n\log n)\)，但在最坏情况下，时间复杂度可能上升到 \(O(n^2)\)。

3. **递归关系**：对于递归算法，通常使用递归关系来推导时间复杂度。例如，快速排序算法的时间复杂度可以通过递归关系来推导。

#### 2.1.3 时间复杂度的分类

根据算法的运行时间增长速度，时间复杂度可以分为以下几类：

- **常数时间复杂度**（\(O(1)\)）：算法的运行时间不随输入规模变化。
- **对数时间复杂度**（\(O(\log n)\)）：算法的运行时间与输入规模的以 2 为底的对数成正比。
- **线性时间复杂度**（\(O(n)\)）：算法的运行时间与输入规模 \(n\) 成正比。
- **线性对数时间复杂度**（\(O(n\log n)\)）：算法的运行时间与输入规模 \(n\) 和其对数 \(\log n\) 的乘积成正比。
- **二次时间复杂度**（\(O(n^2)\)）：算法的运行时间与输入规模 \(n\) 的平方成正比。
- **多项式时间复杂度**：算法的运行时间与输入规模的某个多项式成正比，如 \(O(n^3)\)。
- **指数时间复杂度**：算法的运行时间与输入规模的指数成正比，如 \(O(2^n)\)。

```python
import numpy as np
```
```python
import matplotlib.pyplot as plt

# 数据预处理
def preprocess_data(data):
    # 去噪：采用中值滤波
    median_filter = np.median(data, axis=0)
    filtered_data = np.where(np.abs(data - median_filter) > 3 * np.std(data), median_filter, data)
    
    # 归一化
    normalized_data = (filtered_data - np.mean(filtered_data)) / np.std(filtered_data)
    return normalized_data

# 数据分析
def analyze_data(data):
    # 计算功率谱密度
    power_spectrum = np.abs(np.fft.fft(data))
    freq = np.fft.fftfreq(len(data), d=1)
    
    # 绘制功率谱密度图
    plt.plot(freq, power_spectrum)
    plt.xlabel('Frequency [Hz]')
    plt.ylabel('Power Spectrum')
    plt.title('Power Spectrum of Cosmic Microwave Background Data')
    plt.show()

# 主程序
if __name__ == "__main__":
    # 假设从文件读取数据
    data = np.load("cosmic_microwave_background_data.npy")
    
    # 数据预处理
    preprocessed_data = preprocess_data(data)
    
    # 数据分析
    analyze_data(preprocessed_data)
```

```python
def preprocess_data(data):
    # 去噪：采用中值滤波

    filtered_data = np.where(np.abs(data - median_filter) > 3 * np.std(data), median_filter, data)
    
    # 归一化
    normalized_data = (filtered_data - np.mean(filtered_data)) / np.std(filtered_data)
    return normalized_data

# 数据分析

    # 计算功率谱密度
    power_spectrum = np.abs(np.fft.fft(data))
    freq = np.fft.fftfreq(len(data), d=1)
    
    # 绘制功率谱密度图
    plt.plot(freq, power_spectrum)
    plt.xlabel('Frequency [Hz]')
    plt.ylabel('Power Spectrum')
    plt.title('Power Spectrum of Cosmic Microwave Background Data')
    plt.show()
```

```python
import numpy as np
import matplotlib.pyplot as plt

# 数据预处理
def preprocess_data(data):
    # 去噪：采用中值滤波
    median_filter = np.median(data, axis=0)
    filtered_data = np.where(np.abs(data - median_filter) > 3 * np.std(data), median_filter, data)
    
    # 归一化
    normalized_data = (filtered_data - np.mean(filtered_data)) / np.std(filtered_data)
    return normalized_data

# 数据分析
def analyze_data(data):
    # 计算功率谱密度
    power_spectrum = np.abs(np.fft.fft(data))
    freq = np.fft.fftfreq(len(data), d=1)
    
    # 绘制功率谱密度图
    plt.plot(freq, power_spectrum)
    plt.xlabel('Frequency [Hz]')
    plt.ylabel('Power Spectrum')
    plt.title('Power Spectrum of Cosmic Microwave Background Data')
    plt.show()

# 主程序
if __name__ == "__main__":
    # 假设从文件读取数据
    data = np.load("cosmic_microwave_background_data.npy")
    
    # 数据预处理
    preprocessed_data = preprocess_data(data)
    
    # 数据分析
    analyze_data(preprocessed_data)
```
