### 数学模型与公式

#### 形式化证明的数学模型

形式化证明的数学模型通常涉及谓词逻辑和数学公式。以下是一些常用的数学模型和公式：

1. **谓词逻辑公式**  
   $$ \forall x (P(x) \rightarrow Q(x)) $$
   这个公式表示对于所有x，如果P(x)为真，则Q(x)也为真。

2. **谓词逻辑公式**  
   $$ \exists x (P(x) \land Q(x)) $$
   这个公式表示存在至少一个x，使得P(x)和Q(x)同时为真。

3. **数学归纳公式**  
   $$ \sum_{i=1}^{n} a_i = a_1 + a_2 + ... + a_n $$
   这个公式表示从1到n的自然数序列的求和。

4. **数学归纳公式**  
   $$ \prod_{i=1}^{n} a_i = a_1 \times a_2 \times ... \times a_n $$
   这个公式表示从1到n的自然数序列的乘积。

#### 定理证明的数学模型

在定理证明中，我们通常使用数学公式来描述定理的条件和结论。以下是一些常用的数学模型和公式：

1. **定理证明公式**  
   $$ P \implies (Q \implies R) $$
   这个公式表示如果P为真，则Q为真，进而R也为真。

2. **定理证明公式**  
   $$ \neg (P \land Q) \equiv (\neg P \lor \neg Q) $$
   这个公式表示非P和非Q的合取等价于P和Q的析取。

3. **定理证明公式**  
   $$ P \lor Q \equiv (\neg P \rightarrow Q) $$
   这个公式表示P或Q等价于非P推导出Q。

在形式化证明和定理证明中，虽然使用了许多相似的数学公式，但它们的侧重点和应用场景有所不同。以下是一个对比表格：

        # 根据当前情况选择下一步行动

        proof_plan.append(action)

        # 执行行动
        if action == 'deduction':
            statement = apply_deduction(statement)
        elif action == 'substitution':
            statement = apply_substitution(statement, symbols)

    # 输出证明计划
    return proof_plan

def choose_action(statement):
    # 根据当前状态选择行动
    if statement.is_equation():
        return 'deduction'
    else:
        return 'substitution'

def apply_deduction(statement):
    # 使用演绎推理来简化表达式
    return statement.simplify()

def apply_substitution(statement, symbols):
    # 使用替换来简化表达式
    return statement.subs({symbols[0]: 1})
