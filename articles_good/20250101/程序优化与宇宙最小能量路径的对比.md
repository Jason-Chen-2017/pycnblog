##### 3.2 最小能量路径的计算方法

计算宇宙最小能量路径的方法主要包括动态规划算法、贪心算法和支配表算法等。

1. **动态规划算法**

动态规划算法是一种解决优化问题的方法，通过将问题分解为子问题，并利用子问题的最优解来求解原问题。在宇宙最小能量路径的计算中，动态规划算法可以通过递归关系求解。

具体步骤如下：

- **状态定义**：定义状态`dp[i][j]`，表示从起点`(i, j)`到目标点的最小能量。
- **状态转移方程**：根据能量守恒定律，建立状态转移方程`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + E`，其中`E`为从`(i, j)`到`(i-1, j)`或`(i, j-1)`的能量消耗。
- **边界条件**：初始化起点`dp[0][0] = 0`，其他点`dp[i][j] = infinity`。

2. **贪心算法**

贪心算法是一种在每一步选择当前最优解的算法。在宇宙最小能量路径的计算中，贪心算法可以通过选择当前最小能量点来逐步逼近最小能量路径。

具体步骤如下：

- **初始选择**：从起点出发，选择能量最小的点作为当前点。
- **路径扩展**：根据当前点的邻接点，选择能量最小的点作为下一个当前点。
- **路径记录**：记录从起点到当前点的路径，直到达到目标点。

3. **支配表算法**

支配表算法是一种通过构建支配表来求解最小能量路径的方法。在支配表中，每个点都被分配一个支配关系，通过遍历支配表来求解最小能量路径。

具体步骤如下：

- **构建支配表**：对每个点`i`，找到其邻接点中能量最小的点`j`，将`j`分配给`i`作为支配点。
- **遍历支配表**：从起点出发，依次遍历支配表，找到从起点到目标点的最小能量路径。

def min_energy_path(data):
    n = len(data)
    dp = [[float('inf')] * n for _ in range(n)]
    dp[0][0] = 0
    
    for i in range(1, n):
        for j in range(1, n):
            dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + data[i][j]

def backtrack_path(dp, data):
    n = len(dp)
    path = []
    i, j = n-1, n-1
    
    while i > 0 and j > 0:
        if dp[i-1][j] < dp[i][j-1]:
            path.append(('up', data[i-1][j]))
            i -= 1
        else:
            path.append(('left', data[i][j-1]))
            j -= 1
    
    while i > 0:
        path.append(('up', data[i-1][j]))
        i -= 1

        j -= 1

1. **动态规划算法**

动态规划算法是一种解决优化问题的方法，通过将问题分解为子问题，并利用子问题的最优解来求解原问题。在宇宙最小能量路径的计算中，动态规划算法可以通过递归关系求解。

具体步骤如下：

- **状态定义**：定义状态`dp[i][j]`，表示从起点`(i, j)`到目标点的最小能量。
- **状态转移方程**：根据能量守恒定律，建立状态转移方程`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + E`，其中`E`为从`(i, j)`到`(i-1, j)`或`(i, j-1)`的能量消耗。
- **边界条件**：初始化起点`dp[0][0] = 0`，其他点`dp[i][j] = infinity`。

- **路径扩展**：根据当前点的邻接点，选择能量最小的点作为下一个当前点。
- **路径记录**：记录从起点到当前点的路径，直到达到目标点。

3. **支配表算法**

支配表算法是一种通过构建支配表来求解最小能量路径的方法。在支配表中，每个点都被分配一个支配关系，通过遍历支配表来求解最小能量路径。
