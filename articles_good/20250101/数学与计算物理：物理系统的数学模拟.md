### 1.1 数学模型的基本要素

在物理系统模拟中，数学模型起着至关重要的作用。一个完整的数学模型通常由以下几个基本要素组成：

1. **变量**：变量是数学模型中的核心，用于描述物理系统的状态和变化。根据不同的物理系统，变量可以是连续的（如温度、速度等）或离散的（如粒子的位置、时间步长等）。

2. **方程**：方程用于描述变量之间的关系。在物理系统中，常见的方程包括微分方程、差分方程和积分方程等。这些方程可以用来模拟物理系统的动态行为和静态特性。

3. **初始条件**：初始条件是指模型开始时的变量取值。对于动态系统，初始条件通常决定了系统随时间的演化过程。在模拟过程中，初始条件的设定非常重要，因为它直接影响模拟结果的准确性。

4. **边界条件**：边界条件用于描述系统在边界上的行为。在物理系统中，边界条件可以限制变量的取值或变化速率，从而更好地模拟实际情况。

5. **参数**：参数是模型中的常数，用于调整模型的行为和性能。不同的参数可以影响模型的结果，因此在进行模型设定时，参数的选择和调整是至关重要的。

### 1.2 数学模型的分类与特性

数学模型可以根据其表达形式、解决问题的方法以及应用的领域进行分类。以下是几种常见的数学模型及其特性：

1. **微分方程模型**：微分方程模型用于描述系统的动态行为，它通过描述变量随时间的变化来模拟物理系统。常见的微分方程包括常微分方程和偏微分方程。常微分方程主要用于单变量系统，而偏微分方程则适用于多变量系统。

2. **差分方程模型**：差分方程模型通过离散化连续变量来描述系统的行为。它将连续系统离散化为一系列时间步长的变量值，从而便于计算。差分方程模型在数值模拟中应用广泛，尤其是在计算物理和计算化学等领域。

3. **积分方程模型**：积分方程模型通过积分形式描述变量之间的关系，主要用于求解边界值问题。它通过求解积分方程来找到系统在边界上的变量分布，从而实现物理系统的模拟。

4. **概率统计模型**：概率统计模型通过概率分布函数来描述系统的随机行为。它主要用于模拟不确定性和随机性系统，如金融市场的波动、随机过程的模拟等。

### 1.3 数学模型与物理实验的联系

数学模型与物理实验密切相关。物理实验通过实际观测和测量，提供数据支持，而数学模型则通过理论分析和计算，对实验结果进行解释和预测。以下是数学模型与物理实验之间的几个关键联系：

1. **数据驱动模型**：在许多情况下，数学模型可以通过实验数据来建立。通过分析实验数据，可以确定变量之间的关系，进而构建数学模型。这种模型通常称为数据驱动模型，它依赖于实验数据的准确性和可靠性。

2. **验证与校准**：物理实验的数据可以用于验证和校准数学模型。通过将模型预测与实验结果进行对比，可以评估模型的准确性和稳定性。如果模型与实验结果存在较大偏差，则需要调整模型参数或重新设计模型。

3. **实验设计**：数学模型还可以指导物理实验的设计。通过分析模型，可以确定实验中需要测量的变量和参数，优化实验条件，提高实验的准确性和效率。

4. **预测与模拟**：数学模型可以用于预测物理系统的行为。在实验无法进行或成本高昂的情况下，通过数学模型进行模拟，可以提前了解系统的行为，为实验提供理论依据。

总之，数学模型与物理实验相辅相成，共同推动科学研究的进步。通过数学模型，我们可以更好地理解物理系统的本质，通过物理实验，我们可以验证和改进数学模型的准确性。两者结合，为我们提供了强大的工具，以应对复杂的物理问题。

### 2.1 常见的物理模拟算法

物理模拟算法是计算物理中的重要组成部分，用于在数学模型的基础上模拟物理系统的行为。以下介绍几种常见的物理模拟算法，包括它们的原理和应用场景：

#### 1. 欧拉方法

欧拉方法是最基本的数值解法，用于求解常微分方程。它的基本原理是将时间步长划分为小段，通过线性逼近在每个时间步上更新变量值。

**原理：**
欧拉方法通过以下公式迭代更新变量：
$$
x_{n+1} = x_n + f(x_n, t_n) \Delta t
$$
其中，\( x_n \) 和 \( t_n \) 分别为当前时间和变量值，\( f(x_n, t_n) \) 为微分方程的导数，\( \Delta t \) 为时间步长。

**应用场景：**
欧拉方法适用于求解简单的常微分方程，如自由落体运动、弹簧振子等。但由于其线性逼近的特性，欧拉方法在某些情况下可能产生较大的误差。

**示例：**
```python
def euler_method(v0, t0, t_end, dt):
    t = t0
    v = v0
    while t < t_end:
        v += v * dt
        t += dt
    return v

v0 = 10  # 初速度
t0 = 0   # 初始时间
t_end = 10  # 结束时间
dt = 0.1  # 时间步长
print(euler_method(v0, t0, t_end, dt))
```

#### 2. 龙格-库塔方法

龙格-库塔方法是更高精度的数值解法，适用于求解更复杂的常微分方程。它通过利用多项式逼近来提高解的精度。

**原理：**
龙格-库塔方法的基本步骤如下：
1. 计算前向差分：
$$
k_1 = f(x_n, t_n)
$$
2. 计算后向差分：
$$
k_2 = f(x_n + \frac{1}{2}k_1 \Delta t, t_n + \frac{1}{2}\Delta t)
$$
3. 计算最终更新：
$$
x_{n+1} = x_n + \frac{1}{6}k_1 + \frac{1}{3}k_2 + \frac{1}{3}k_1 + \frac{1}{6}k_2
$$

**应用场景：**
龙格-库塔方法适用于求解复杂的物理问题，如非线性动力系统、流体力学等。它具有较高的计算精度，但计算复杂度也相对较高。

**示例：**
```python
def runge_kutta_method(v0, t0, t_end, dt):
    t = t0
    v = v0
    while t < t_end:
        k1 = f(v, t)
        k2 = f(v + 0.5 * k1 * dt, t + 0.5 * dt)
        k3 = f(v + 0.5 * k2 * dt, t + 0.5 * dt)
        k4 = f(v + k3 * dt, t + dt)
        v += (k1 + 2 * k2 + 2 * k3 + k4) * dt / 6
        t += dt
    return v

v0 = 10  # 初速度
t0 = 0   # 初始时间
t_end = 10  # 结束时间
dt = 0.1  # 时间步长
print(runge_kutta_method(v0, t0, t_end, dt))
```

#### 3. 模拟退火算法

模拟退火算法是一种基于概率的优化算法，常用于求解物理系统的优化问题。它的基本原理是通过模拟固体退火过程来优化系统的能量状态。

**原理：**
模拟退火算法的基本步骤如下：
1. 初始化系统状态。
2. 在当前状态下进行随机扰动，生成新的状态。
3. 计算新状态与当前状态之间的能量差。
4. 根据能量差和温度，决定是否接受新状态。
5. 降低温度，重复步骤2-4，直到达到终止条件。

**应用场景：**
模拟退火算法适用于求解各种优化问题，如结构优化、神经网络训练等。它能够有效避免局部最优解，找到全局最优解。

**示例：**
```python
import random

def simulate_annealing(obj_func, initial_state, temperature, cooling_rate):
    current_state = initial_state
    while temperature > 1e-6:
        new_state = random_walk(current_state)
        energy_diff = obj_func(new_state) - obj_func(current_state)
        if energy_diff < 0 or random() < exp(-energy_diff / temperature):
            current_state = new_state
        temperature *= (1 - cooling_rate)
    return current_state

def random_walk(state):
    # 实现随机扰动
    return state + random() * (state - state)

def example_obj_func(state):
    # 实现目标函数
    return state ** 2

initial_state = 0  # 初始状态
temperature = 100  # 初始温度
cooling_rate = 0.01  # 冷却率
print(simulate_annealing(example_obj_func, initial_state, temperature, cooling_rate))
```

通过上述算法的介绍，我们可以看到不同物理模拟算法在原理和实现上的差异。选择合适的算法对于物理系统的模拟至关重要，本文后续章节将进一步探讨这些算法的应用和实现。

### 3.2 连续系统的数学模型

在计算物理中，连续系统的数学模型是非常重要的，因为它们能够描述物理系统在空间和时间上的连续变化。以下将详细讲解连续系统的数学模型，包括偏微分方程和常微分方程。

#### 偏微分方程

偏微分方程（PDE）用于描述多个变量（通常是空间和时间的变量）之间的依赖关系。以下是一个典型的偏微分方程：热传导方程。

**热传导方程：**
$$
\frac{\partial u}{\partial t} = \alpha \nabla^2 u
$$
其中，\( u(x, t) \) 表示温度分布，\( \alpha \) 是热扩散系数。

**解释：**
这个方程表示温度随时间的变化率（\( \frac{\partial u}{\partial t} \)）等于热扩散系数与温度梯度（\( \nabla^2 u \)）的乘积。它描述了热量在物体内部如何随时间和空间传播。

**示例：**
假设一个均匀的金属板，其初始温度分布为 \( u(x, 0) = 100 + \sin(\pi x) \)，求解在 \( t = 10 \) 时的温度分布。

```python
import numpy as np
import matplotlib.pyplot as plt

def heat_conduction(x, t, alpha):
    u = np.exp(-t / (alpha * x**2)) * (100 + np.sin(np.pi * x))
    return u

alpha = 0.1  # 热扩散系数
x = np.linspace(0, 1, 100)  # 空间离散点
t = 10  # 时间
u = heat_conduction(x, t, alpha)

plt.plot(x, u)
plt.xlabel('Position (x)')
plt.ylabel('Temperature (u)')
plt.title('Temperature Distribution after 10 Time Units')
plt.show()
```

#### 常微分方程

常微分方程（ODE）用于描述单个变量及其导数之间的关系。以下是一个典型的常微分方程：简单谐振子方程。

**简单谐振子方程：**
$$
\frac{d^2 x}{dt^2} + \omega^2 x = 0
$$
其中，\( x(t) \) 表示振子的位移，\( \omega \) 是角频率。

**解释：**
这个方程描述了一个振子在弹性力作用下的运动。\( \omega \) 越大，振动的频率越高，周期越短。

**示例：**
求解一个初始条件为 \( x(0) = 1 \)， \( \frac{dx}{dt}\big|_{t=0} = 0 \) 的简单谐振子，在 \( t = 5 \) 时的位移。

```python
import numpy as np
from scipy.integrate import solve_ivp

def simple_harmonic_oscillator(t, y, omega):
    x, v = y
    dxdt = v
    dvdt = -omega**2 * x
    return [dxdt, dvdt]

y0 = [1, 0]  # 初始条件
t = np.linspace(0, 5, 1000)  # 时间范围
omega = 1  # 角频率
sol = solve_ivp(simple_harmonic_oscillator, [0, 5], y0, args=(omega,), t_eval=t)

plt.plot(t, sol.y[0])
plt.xlabel('Time (t)')
plt.ylabel('Displacement (x)')
plt.title('Displacement of a Simple Harmonic Oscillator')
plt.show()
```

通过以上示例，我们可以看到如何使用Python来求解连续系统的数学模型。这些模型在计算物理中有着广泛的应用，读者可以根据具体问题进行相应的调整和扩展。

### 5.1 基本数学公式

在计算物理中，数学公式是描述物理现象和系统行为的关键工具。以下是几个基本且常用的数学公式，它们在物理系统的模拟中起着重要作用。

#### 1. 运动学公式

在描述物体运动时，以下几个公式非常关键：

$$
v = \frac{dx}{dt}  \quad \text{（速度）}
$$

$$
a = \frac{dv}{dt}  \quad \text{（加速度）}
$$

$$
x(t) = x_0 + v_0 t + \frac{1}{2} a t^2  \quad \text{（位移）}
$$

其中，\( x(t) \) 是物体在时间 \( t \) 的位移，\( x_0 \) 是初始位移，\( v_0 \) 是初始速度，\( a \) 是加速度。

#### 2. 动力学公式

牛顿第二定律是描述物体受力与加速度之间关系的核心公式：

$$
F = m a  \quad \text{（力）}
$$

其中，\( F \) 是作用在物体上的总力，\( m \) 是物体的质量，\( a \) 是加速度。

#### 3. 振动公式

对于简谐振动，以下几个公式描述了位移、速度和加速度随时间的变化：

$$
x(t) = A \cos(\omega t + \phi)  \quad \text{（位移）}
$$

$$
v(t) = -A \omega \sin(\omega t + \phi)  \quad \text{（速度）}
$$

$$
a(t) = -A \omega^2 \cos(\omega t + \phi)  \quad \text{（加速度）}
$$

其中，\( A \) 是振幅，\( \omega \) 是角频率，\( \phi \) 是初相位。

#### 4. 热传导公式

热传导方程描述了温度在空间和时间上的变化：

$$
\frac{\partial u}{\partial t} = \alpha \nabla^2 u  \quad \text{（热传导方程）}
$$

其中，\( u(x, t) \) 是温度分布，\( \alpha \) 是热扩散系数。

#### 5. 流体动力学公式

伯努利方程描述了流体在流动过程中速度、压力和高度之间的关系：

其中，\( \rho \) 是流体密度，\( v \) 是流速，\( g \) 是重力加速度，\( h \) 是高度，\( p \) 是压力。

### 5.2 数学公式的详细讲解

在计算物理中，数学公式的详细讲解至关重要，因为它们不仅帮助我们理解物理现象，还指导我们如何设计和实现物理模拟算法。以下是关于几个关键数学公式及其应用场景的详细讲解。

#### 1. 热传导方程

热传导方程描述了热量在固体、液体或气体中的传播过程。它具有以下形式：

$$
\frac{\partial u}{\partial t} = \alpha \nabla^2 u
$$

其中，\( u(x, t) \) 是温度分布，\( \alpha \) 是热扩散系数，\( \nabla^2 \) 是拉普拉斯算子。

**物理意义：**
- \( \frac{\partial u}{\partial t} \)：表示温度随时间的变化率。
- \( \alpha \nabla^2 u \)：表示热量的扩散率，它与温度梯度的平方成正比。

**应用场景：**
热传导方程广泛应用于材料科学、工程学、化学和医学等领域。例如，在电子设备散热、石油开采、核反应堆设计和生物医学成像等方面，热传导方程帮助我们理解和控制热量的传播。

**求解方法：**
为了求解热传导方程，我们可以使用有限元方法（FEM）或有限差分方法（FDM）。以下是一个简单的有限差分方法示例：

**有限差分方法：**
$$
u_i^{n+1} = u_i^n + \alpha \Delta t \left( \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2} \right)
$$

其中，\( u_i^n \) 是第 \( n \) 次迭代时第 \( i \) 个网格点的温度，\( \Delta x \) 是空间步长，\( \Delta t \) 是时间步长。

#### 2. 牛顿第二定律

牛顿第二定律描述了力与加速度之间的关系，其公式为：

$$
F = m a
$$

其中，\( F \) 是作用在物体上的力，\( m \) 是物体的质量，\( a \) 是加速度。

**物理意义：**
- \( F \)：表示作用在物体上的合力。
- \( m \)：表示物体的质量。
- \( a \)：表示物体的加速度。

**应用场景：**
牛顿第二定律广泛应用于经典力学，包括动力学模拟、碰撞检测、航天工程和汽车碰撞测试等领域。

**求解方法：**
在计算物理中，牛顿第二定律通常用于数值求解。以下是一个简单的欧拉方法示例：

**欧拉方法：**
$$
v_{i}^{n+1} = v_{i}^{n} + \frac{F_i}{m} \Delta t
$$

$$
x_{i}^{n+1} = x_{i}^{n} + v_{i}^{n+1} \Delta t
$$

其中，\( v_i^n \) 是第 \( n \) 次迭代时第 \( i \) 个物体的速度，\( x_i^n \) 是第 \( n \) 次迭代时第 \( i \) 个物体的位置。

#### 3. 简谐振动

简谐振动是许多物理系统的基础，其数学描述如下：

$$
x(t) = A \cos(\omega t + \phi)
$$

$$
v(t) = -A \omega \sin(\omega t + \phi)
$$

$$
a(t) = -A \omega^2 \cos(\omega t + \phi)
$$

其中，\( A \) 是振幅，\( \omega \) 是角频率，\( \phi \) 是初相位。

**物理意义：**
- \( x(t) \)：表示物体的位移。
- \( v(t) \)：表示物体的速度。
- \( a(t) \)：表示物体的加速度。

**应用场景：**
简谐振动广泛应用于机械振动分析、声学、光学和电子学等领域。

**求解方法：**
简谐振动可以通过直接解析法求解，也可以通过数值方法（如欧拉方法或龙格-库塔方法）求解。以下是一个简单的欧拉方法示例：

**欧拉方法：**

$$
v_{i}^{n+1} = v_{i}^{n} - A \omega \Delta t \cos(\omega t + \phi)

### 6.3 系统核心实现

在物理系统模拟中，实现系统的核心算法是关键步骤。本节将通过一个具体案例——使用Python实现热传导方程的数值模拟，详细讲解系统核心实现的代码。

#### 1. 热传导方程的数值模拟

热传导方程的数学形式为：
$$
\frac{\partial u}{\partial t} = \alpha \nabla^2 u
$$
其中，\( u(x, t) \) 是温度分布，\( \alpha \) 是热扩散系数。

#### 2. 代码实现

以下是一个简单的Python代码实现，使用有限差分法求解热传导方程。

```python
import numpy as np
import matplotlib.pyplot as plt

def heat_conduction_1d(x, t, alpha, u0, boundary_conditions):
    """
    一维热传导方程的数值解。
    
    参数：
    x: 空间离散点
    t: 时间离散点
    alpha: 热扩散系数
    u0: 初始温度分布
    boundary_conditions: 边界条件
    
    返回：
    u: 模拟的温度分布
    """
    n_x = len(x)
    n_t = len(t)
    dt = t[1] - t[0]
    dx = x[1] - x[0]
    
    # 初始化温度分布
    u = np.zeros((n_t, n_x))
    u[0] = u0
    
    # 应用边界条件
    if boundary_conditions == 'Dirichlet':
        u[:, 0] = 100  # 第一个节点固定温度为100
        u[:, -1] = 0  # 最后一个节点固定温度为0
    
    # 求解热传导方程
    for n in range(1, n_t - 1):
        for i in range(1, n_x - 1):
            u[n, i] = u[n - 1, i] + alpha * dt / dx**2 * (u[n - 1, i + 1] - 2 * u[n - 1, i] + u[n - 1, i - 1])
    
    return u

# 设置参数
x = np.linspace(0, 1, 100)  # 空间离散点
t = np.linspace(0, 10, 1000)  # 时间离散点
alpha = 0.1  # 热扩散系数
u0 = np.sin(np.pi * x) + 100  # 初始温度分布
boundary_conditions = 'Dirichlet'  # 边界条件

# 模拟
u = heat_conduction_1d(x, t, alpha, u0, boundary_conditions)

# 可视化
plt.plot(x, u[-1])
plt.xlabel('Position (x)')
plt.ylabel('Temperature (u)')
plt.title('Temperature Distribution at t=10')
plt.show()
```

#### 3. 代码解析

**初始化与参数设置：**
- `x` 和 `t` 分别是空间和时间上的离散点。
- `alpha` 是热扩散系数，用于控制热量的传播速度。
- `u0` 是初始温度分布，可以自定义初始条件。
- `boundary_conditions` 定义了边界条件，这里使用Dirichlet边界条件。

### 6.5 实际案例分析与讲解

为了更好地理解物理系统的数学模拟，下面我们将通过一个实际案例——模拟流体流动，详细分析其过程，并提供完整的代码实现和分析。

#### 案例背景

在流体力学中，我们经常需要对流体流动进行模拟，以便更好地理解流体在管道、容器或其他复杂形状中的运动行为。一个典型的流体流动问题是一个二维流动，其中流体在方形管道中从左向右流动，管道两侧存在压力差。

#### 案例目标

我们的目标是使用计算流体动力学（CFD）中的Navier-Stokes方程模拟这个流体流动问题，并分析其结果。具体步骤如下：

1. **建立数学模型**：使用Navier-Stokes方程描述流体流动。
2. **设置边界条件**：定义流体入口、出口和壁面的边界条件。
3. **离散化方程**：使用有限差分方法将连续方程离散化。
4. **实现数值求解**：编写代码实现方程的数值求解。
5. **结果分析与可视化**：分析求解结果并使用可视化工具展示流体流动。

#### 1. 数学模型

Navier-Stokes方程描述了流体在运动中的动量和能量传递。二维Navier-Stokes方程可以表示为：

$$
\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla) \mathbf{u} = -\frac{1}{\rho} \nabla p + \nu \nabla^2 \mathbf{u}
$$

其中，\( \mathbf{u} = (u, v) \) 是流体的速度向量，\( p \) 是压力，\( \rho \) 是流体密度，\( \nu \) 是流体的运动粘度。

#### 2. 边界条件

对于本案例，我们设置以下边界条件：

- **入口条件**：在管道的左侧（\( x = 0 \)），速度 \( u \) 为常数，假设为 \( u_0 \)，而 \( v \) 为零。
- **出口条件**：在管道的右侧（\( x = L \)），压力 \( p \) 为常数，假设为零梯度。
- **壁面条件**：在管道的壁面（\( y = 0 \) 和 \( y = H \)），流体速度的法向分量 \( u_y \) 和 \( v_y \) 为零，即无滑移条件。

#### 3. 离散化方程

使用有限差分方法，我们可以将连续的Navier-Stokes方程离散化为离散格点上的一系列代数方程。以下是二维Navier-Stokes方程的离散化形式：

$$
\frac{u_{i,j}^{n+1} - u_{i,j}^{n}}{\Delta t} + \frac{u_{i+1,j}^{n} - 2u_{i,j}^{n} + u_{i-1,j}^{n}}{\Delta x} + \frac{v_{i,j+1}^{n} - 2v_{i,j}^{n} + v_{i,j-1}^{n}}{\Delta y} = -\frac{p_{i+1,j}^{n} - 2p_{i,j}^{n} + p_{i-1,j}^{n}}{\Delta x \rho} - \frac{1}{\rho} \frac{p_{i,j+1}^{n} - 2p_{i,j}^{n} + p_{i,j-1}^{n}}{\Delta y} + \nu \left( \frac{u_{i+1,j+1}^{n} - 2u_{i,j+1}^{n} + u_{i-1,j+1}^{n}}{\Delta x \Delta y} + \frac{u_{i+1,j-1}^{n} - 2u_{i,j-1}^{n} + u_{i-1,j-1}^{n}}{\Delta x \Delta y} \right)
$$

$$
\frac{v_{i,j}^{n+1} - v_{i,j}^{n}}{\Delta t} + \frac{u_{i+1,j}^{n} - 2u_{i,j}^{n} + u_{i-1,j}^{n}}{\Delta x} + \frac{v_{i,j+1}^{n} - 2v_{i,j}^{n} + v_{i,j-1}^{n}}{\Delta y} = -\frac{p_{i+1,j}^{n} - 2p_{i,j}^{n} + p_{i-1,j}^{n}}{\Delta y \rho} - \frac{1}{\rho} \frac{p_{i+1,j}^{n} - 2p_{i,j}^{n} + p_{i-1,j}^{n}}{\Delta x} + \nu \left( \frac{v_{i+1,j+1}^{n} - 2v_{i,j+1}^{n} + v_{i-1,j+1}^{n}}{\Delta x \Delta y} + \frac{v_{i+1,j-1}^{n} - 2v_{i,j-1}^{n} + v_{i-1,j-1}^{n}}{\Delta x \Delta y} \right)
$$

#### 4. 代码实现

以下是使用Python实现的二维Navier-Stokes方程的数值模拟代码：

```python
import numpy as np
import matplotlib.pyplot as plt

def navier_stokes_2d(L, H, Re, nu, Nx, Ny, dt, n_iterations):
    """
    二维Navier-Stokes方程的数值模拟。

    参数：
    L: 流场长度
    H: 流场高度
    Re:  Reynolds数
    nu: 流体运动粘度
    Nx: x方向离散点数
    Ny: y方向离散点数
    dt: 时间步长
    n_iterations: 迭代次数
    
    返回：
    u, v: 流体速度分布
    p: 压力分布
    """
    x = np.linspace(0, L, Nx)
    y = np.linspace(0, H, Ny)
    dx = x[1] - x[0]
    dy = y[1] - y[0]
    
    u = np.zeros((n_iterations, Ny, Nx))
    v = np.zeros((n_iterations, Ny, Nx))
    p = np.zeros((n_iterations, Ny, Nx))
    
    # 初始条件
    u[0, :, :] = 0.0
    v[0, :, :] = 0.0
    p[0, :, :] = 0.0
    
    # 入口条件
    u[0, 0, :] = Re * dx / nu
    
    for n in range(n_iterations - 1):
        # 压力修正法（PISO方法）
        p[n+1, 1:-1, 1:-1] = p[n, 1:-1, 1:-1]
        
        # 计算动量修正
        for i in range(1, Nx - 1):
            for j in range(1, Ny - 1):
                Fx = -1/nu * (u[n, j+1, i] - u[n, j-1, i]) / dy
                Fy = -1/nu * (v[n, j, i+1] - v[n, j, i-1]) / dx
                u[n+1, j, i] = u[n, j, i] - dt * (1/(dx*dx) * (p[n, j+1, i] - p[n, j-1, i]) - Fx)
                v[n+1, j, i] = v[n, j, i] - dt * (1/(dy*dy) * (p[n, j, i+1] - p[n, j, i-1]) - Fy)
        
        # 压力修正
        for i in range(1, Nx - 1):
            for j in range(1, Ny - 1):
                p[n+1, j, i] = p[n, j, i] + dt * ((1/(2*dx) * (u[n+1, j+1, i] - u[n+1, j-1, i]) - u[n, j+1, i] + u[n, j-1, i]) / dy + (1/(2*dy) * (v[n+1, j, i+1] - v[n+1, j, i-1]) - v[n, j, i+1] + v[n, j, i-1)) / dx)
        
        # 边界条件
        u[n+1, 0, :] = Re * dx / nu
        u[n+1, Ny-1, :] = 0.0
        v[n+1, 0, :] = 0.0
        v[n+1, Ny-1, :] = 0.0
        
    return u, v, p

# 设置参数
L = 1.0  # 流场长度
H = 1.0  # 流场高度
Re = 100.0  # Reynolds数
nu = 0.01  # 流体运动粘度
Nx = 100  # x方向离散点数
Ny = 100  # y方向离散点数
dt = 0.01  # 时间步长
n_iterations = 1000  # 迭代次数

u, v, p = navier_stokes_2d(L, H, Re, nu, Nx, Ny, dt, n_iterations)

# 可视化
plt.figure(figsize=(10, 5))
plt.subplot(1, 2, 1)
plt.contourf(u[-1], cmap='viridis')
plt.colorbar(label='Velocity (u)')
plt.title('Streamlines')

plt.subplot(1, 2, 2)
plt.contourf(v[-1], cmap='plasma')
plt.colorbar(label='Velocity (v)')
plt.title('Streamlines')
plt.xlabel('x')
plt.ylabel('y')

plt.show()
```
