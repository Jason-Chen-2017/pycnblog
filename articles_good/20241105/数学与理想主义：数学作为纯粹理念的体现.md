    def __init__(self):
        self.elements = []

    def add(self, element):
        if element not in self.elements:
            self.elements.append(element)

    def remove(self, element):
        if element in self.elements:
            self.elements.remove(element)

    def contains(self, element):
        return element in self.elements

    def union(self, other_set):
        union_set = Set()
        for element in self.elements:
            union_set.add(element)
        for element in other_set.elements:
            union_set.add(element)
        return union_set

    def intersection(self, other_set):
        intersection_set = Set()
        for element in self.elements:
            if other_set.contains(element):
                intersection_set.add(element)
        return intersection_set

    def complement(self, universe_set):
        complement_set = Set()
        for element in universe_set.elements:
            if not self.contains(element):
                complement_set.add(element)
        return complement_set

### 拓展阅读

如果您希望进一步了解数学与理想主义的相关知识，以下是一些推荐的拓展阅读材料：

1. **柏拉图《理想国》**：探讨理想主义哲学观点的经典著作，对数学作为纯粹理念的观点有深刻阐述。
2. **康德《纯粹理性批判》**：康德对数学和哲学的深入探讨，强调了理性思维在数学中的重要性。
3. **罗素《数学原理》**：罗素和怀特海德共同撰写的数学哲学经典著作，详细探讨了数学的基础和逻辑结构。
4. **希尔伯特《几何基础》**：希尔伯特的公理化几何体系，展示了理想主义在几何学中的应用。
5. **赫尔曼·外尔《数学与科学》**：外尔对数学和科学的哲学探讨，强调了数学在科学研究中的核心作用。
6. **艾伦·图灵《计算机与智能》**：图灵对计算机科学和人工智能的奠基性工作，揭示了理想主义在计算机科学中的应用。
7. **克劳德·香农《信息论基础》**：香农对信息论的创立，展示了理想主义在信息科学中的应用。

这些书籍和论文将帮助您更深入地理解数学与理想主义的本质和相互关系。
