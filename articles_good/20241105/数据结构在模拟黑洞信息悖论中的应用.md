### 1.1 数据结构的基本概念

数据结构是计算机科学中一个重要的概念，它是指数据元素以及它们之间的相互关系和构造的数据集合。数据结构不仅包括数据的组织方式，还包括数据上的操作。选择合适的数据结构对于程序的效率、可读性和可维护性都有着至关重要的影响。

数据结构可以分为两类：线性结构和非线性结构。线性结构包括数组、链表、栈和队列等，它们具有明确的开始和结束位置，以及线性排列的特点。非线性结构包括树、图、哈希表等，它们可以表示复杂的逻辑关系和数据结构。

- **栈**：一种后进先出（LIFO）的线性数据结构，用于存储操作过程中的数据。

  ```python
      return -1
  ```

- **二分搜索**：在有序数据结构中查找特定元素，通过不断将数据结构分成两半，缩小搜索范围。时间复杂度为 O(log n)。

  ```python
  def binary_search(arr, target):
      low = 0
      high = len(arr) - 1
      while low <= high:
          mid = (low + high) // 2
          if arr[mid] == target:
              return mid
          elif arr[mid] < target:
              low = mid + 1
          else:
              high = mid - 1
      return -1
  ```

- **广度优先搜索（BFS）**：从起始节点开始，依次访问所有相邻节点，直到找到目标节点或结束。时间复杂度为 O(V+E)，其中 V 为节点数，E 为边数。

  ```python
      queue = deque([start])

          if node == target:
              return True
          visited.add(node)
  ```

  ```python
          return arr
  ```

  ```python
  def merge(left, right):
      result = []
      i = j = 0
      while i < len(left) and j < len(right):
          if left[i] < right[j]:
              result.append(left[i])
              i += 1
          else:
              result.append(right[j])
              j += 1
      result.extend(left[i:])
      result.extend(right[j:])
      return result
  ```
