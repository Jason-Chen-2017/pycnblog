#### 2.1 音高与频率

在音乐理论中，常用的音高标记包括C、D、E、F、G、A、B七个基本音级，每个音级对应一个特定的频率。例如，C音的频率通常取为261.63Hz。音高的计算公式如下：

\[ f = \frac{1}{2\pi} \cdot \ln{\left(\frac{f_0}{f}\right)} \]

其中，\( f \) 是音高，\( f_0 \) 是基准频率（通常取为440Hz），\( f \) 是频率。

**示例：计算G音的频率**

假设基准频率 \( f_0 \) 为440Hz，要计算G音的频率，我们使用上述公式：

\[ f = \frac{1}{2\pi} \cdot \ln{\left(\frac{440}{f}\right)} \]

通过求解这个方程，我们可以得到G音的频率约为392.00Hz。

一个四拍子的节奏模式可以是“1&2&3&4”，表示每个音符的时长相等，每个小节包含四个四分音符。

#### 2.4 模式识别与分组

模式识别是音乐理论中的一个重要概念，它涉及音乐中各种模式的识别和分类。模式可以是音阶、和弦、节奏或其他音乐元素。

#### 音色随机性

音色是音乐中的一个重要属性，它决定了声音的主观感觉。在概率论中，我们可以使用概率分布来生成新的音色组合，从而增加音乐的多样性。

**步骤：生成音色**

1. **定义音色组合**：假设我们有多种音色，每种音色具有不同的概率分布。

2. **使用概率分布生成音色**：通过随机选择，根据概率分布生成新的音色组合。

**示例：生成一个新的音色组合**

假设我们有五种音色，它们的出现概率分别为 \( P(A) = 0.2 \)，\( P(B) = 0.3 \)，\( P(C) = 0.4 \)，\( P(D) = 0.5 \)，\( P(E) = 0.6 \)。我们可以使用以下概率分布来生成新的音色组合：

\[ A: 0.2 \]
\[ B: 0.3 \]
\[ C: 0.4 \]
\[ D: 0.5 \]
\[ E: 0.6 \]

**伪代码：生成音色组合**

```python
import random

def generate_sound_color(probabilities):
    sound_colors = ['A', 'B', 'C', 'D', 'E']
    probabilities = probabilities / sum(probabilities)
    return random.choices(sound_colors, weights=probabilities)[0]

# 示例：生成一个新的音色组合
```

```python
def generate_melody(sound_probabilities, duration_probabilities):
```

```python
import numpy as np
import matplotlib.pyplot as plt

def generate_melody(duration=4):
    # 定义音高的概率分布
    note_probs = {'C': 0.5, 'D': 0.3, 'E': 0.2}
    # 定义时长的概率分布
    duration_probs = {1: 0.6, 2: 0.4}
    melody = []

    for _ in range(duration):
        # 随机选择音高
        note = np.random.choice(list(note_probs.keys()), p=list(note_probs.values()))
        # 随机选择时长
        note_duration = np.random.choice(list(duration_probs.keys()), p=list(duration_probs.values()))
        melody.append((note, note_duration))

    return melody

# 示例：生成一个简单的旋律
simple_melody = generate_melody(4)
print("简单旋律：", simple_melody)
```

```matlab
function music_synthesis(melody)
    % 初始化音频参数
    fs = 44100; % 采样频率
    duration = 4; % 每个音符的时长（秒）
    T = 1/fs; % 采样周期
    N = fs * duration; % 音频信号的总长度

    % 初始化音频信号
    audio_signal = zeros(1, N);

    % 合成旋律
    for i = 1:length(melody)
        note = melody{i, 1};
        duration = melody{i, 2};
        f = note_frequency(note); % 获取音高对应的频率
        for t = 1:duration * fs
            audio_signal(t) = cosine(2 * pi * f * t * T);
        end
    end

    % 保存音频文件
    wavwrite(audio_signal, fs, 'simple_melody.wav');
end

function f = note_frequency(note)
    % 定义音高与频率的映射关系
    freq_map = {'C': 261.63, 'D': 293.66, 'E': 329.63, 'F': 349.23, 'G': 392.00, 'A': 440.00, 'B': 493.88};
    f = freq_map{note};
end
```

**代码解读**：
- 定义了`music_synthesis`函数，该函数接受一个参数`melody`，表示生成的旋律。
- 初始化音频参数，包括采样频率`fs`、每个音符的时长`duration`和采样周期`T`。
- 初始化音频信号数组`audio_signal`，其长度为`N`。
- 通过循环遍历旋律中的每个音符，使用`cosine`函数生成正弦波信号，并将其叠加到`audio_signal`中。
- 调用`wavwrite`函数将音频信号保存为`simple_melody.wav`文件。
