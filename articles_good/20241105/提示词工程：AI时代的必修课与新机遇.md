    for sentence in training_data:
        for i in range(len(sentence) - n + 1):
            ngram = tuple(sentence[i:i + n])
            if ngram not in ngram_model:

def generate_sentence(ngram_model, n, max_sentence_length=50):
    sentence = []

    for _ in range(max_sentence_length):
        sentence.append(current_ngram[0])
        current_ngram = tuple([current_ngram[-1]] + current_ngram[1:])
        if current_ngram not in ngram_model:
            break
    return " ".join(sentence)

def multi_head_attention(inputs, hidden_size, num_heads):
    queries, keys, values = split_heads(inputs, num_heads)
    attention_scores = dot_product(queries, keys)
    attention_weights = softmax(attention_scores)
    attention_output = dot_product(attention_weights, values)
    return merge_heads(attention_output)

def feedforward_network(inputs, hidden_size):
    intermediate_size = hidden_size * 4
    outputs = relu(dense(inputs, intermediate_size))
    outputs = dense(outputs, hidden_size)
    return outputs

##### 6.1 概率论与数理统计

概率论与数理统计是提示词工程中不可或缺的数学工具，用于描述和分析数据分布、估计模型参数以及评估模型性能。

1. **概率论基本概念**

   - **概率**：事件发生的可能性，用0到1之间的数值表示。概率的加法规则和乘法规则是概率论的基础。

   - **随机变量**：用于描述不确定结果的变量，可以是离散的或连续的。概率分布函数（PDF）或概率质量函数（PMF）用于描述随机变量的概率分布。

   - **期望**：随机变量的平均值，表示随机变量在多次试验中的长期行为。

   - **方差**：随机变量与其期望之差的平方的平均值，用于描述随机变量的离散程度。

2. **数理统计基本方法**

##### 6.1.1 概率论的基本概念

概率论的基本概念包括：

- **条件概率**：在给定某个事件发生的条件下，另一个事件发生的概率。

  $$
  P(A|B) = \frac{P(A \cap B)}{P(B)}
  $$

- **贝叶斯定理**：用于计算后验概率，即给定某些观测数据，计算某个假设的概率。

  $$
  P(A|B) = \frac{P(B|A)P(A)}{P(B)}
  $$

- **马尔可夫性质**：描述随机过程在一定条件下，当前状态仅与前一状态有关，而与之前的状态无关。

  $$
  P(X_t|X_{t-1}, X_{t-2}, \ldots) = P(X_t|X_{t-1})
  $$

##### 6.1.2 数理统计的基本方法

数理统计的基本方法包括：

- **参数估计**：通过样本数据估计总体参数，如最大似然估计（MLE）。

  $$
  \hat{\theta} = \arg\max_{\theta} \ln L(\theta | x)
  $$

- **假设检验**：通过样本数据验证某个假设是否成立。

  $$
  H_0: \theta = \theta_0 \quad \text{vs.} \quad H_1: \theta \neq \theta_0
  $$

- **置信区间**：基于样本数据估计总体参数的范围。

  $$
  \theta \in ( \bar{x} - z_{\alpha/2} \frac{\sigma}{\sqrt{n}}, \bar{x} + z_{\alpha/2} \frac{\sigma}{\sqrt{n}})
  $$

3. **拉格朗日乘数法**
