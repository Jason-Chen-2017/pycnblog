#### 1.1 马克思主义的核心概念

马克思主义的核心概念包括历史唯物主义、剩余价值理论和资本主义批判。

**历史唯物主义**

历史唯物主义是马克思主义的基本观点，认为社会历史的发展是由物质生产力和生产关系的矛盾运动推动的。以下是历史唯物主义的核心原理：

- 生产力和生产关系的矛盾运动是社会发展的根本动力。
- 经济基础决定上层建筑。
- 社会形态的变化是由生产方式的变化引起的。

**剩余价值理论**

剩余价值理论是马克思主义经济学的重要组成部分，揭示了资本主义剥削的实质。以下是剩余价值理论的基本原理：

- 劳动者创造的价值大于其工资，差额即为剩余价值。
- 资本家通过剥削工人的剩余劳动获取利润。

**资本主义批判**

资本主义批判是马克思主义对资本主义社会的全面批判，揭示了资本主义制度的内在矛盾和危机。以下是资本主义批判的核心观点：

- 资本主义制度是剥削制度，导致了阶级矛盾和贫富分化。
- 资本主义经济危机是周期性的，源于生产的社会化和资本家占有生产资料之间的矛盾。

```python
# 马克思主义核心概念分析函数
def marxism_analyzer(labor_value, wage):
    surplus_value = labor_value - wage
    print(f"劳动力价值: {labor_value}")
    print(f"工资: {wage}")
    print(f"剩余价值: {surplus_value}")
    
    # 数据可视化
    data = [labor_value, wage, surplus_value]
    labels = ['劳动力价值', '工资', '剩余价值']
    plt.bar(labels, data)
    plt.xlabel('要素')
    plt.ylabel('价值（元）')
    plt.title('剩余价值分析')
    plt.show()

# 示例数据
labor_value = 8000
wage = 5000

# 执行分析
marxism_analyzer(labor_value, wage)
```
