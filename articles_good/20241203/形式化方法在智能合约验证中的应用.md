#### 实例一：一个简单的代币合约

假设我们有一个简单的代币合约，其核心功能是允许用户之间进行代币的转账和余额查询。以下是该合约的一个简化版本：

```solidity
pragma solidity ^0.8.0;

contract SimpleToken {
    mapping(address => uint256) public balanceOf;

    function transfer(address to, uint256 amount) external {
        require(balanceOf[msg.sender] >= amount, "Insufficient balance");
        balanceOf[msg.sender] -= amount;
        balanceOf[to] += amount;
    }

    function getBalance(address account) external view returns (uint256) {
        return balanceOf[account];
    }
}
```

**形式化建模：**
我们首先使用谓词逻辑来形式化描述这个代币合约的运行逻辑：

1. **状态变量**：`balanceOf` 是一个从地址到余额的映射。
2. **初始条件**：在合约部署时，所有地址的余额均为0。
3. **转移条件**：当用户发起转账请求时，必须满足以下条件：
   - 发送者地址的余额大于等于转账金额。
   - 转账后，发送者地址余额减少，接收者地址余额增加。

**形式化验证：**
我们使用模型检查器来验证该代币合约是否满足以下属性：
- **余额一致性**：在任何时刻，所有地址的余额总和保持不变。
- **非负余额**：任何地址的余额不会变为负数。

**验证结果：**
通过模型检查器，我们发现该代币合约满足上述属性。因此，我们可以确信该代币合约的行为是正确的。

s = z3.Solver()

# 假设我们有以下代币合约代码：
# pragma solidity ^0.8.0;

#     }

# 定义初始条件
balanceOf = {}
balanceOf['Alice'] = 100
balanceOf['Bob'] = 200

s.add(balanceOf['Alice'] >= 50)  # 假设Alice要转50给Bob
s.add(balanceOf['Bob'] + 50 == balanceOf['Alice'])

# 检查是否满足条件
if s.check():
    print("满足条件")
else:
    print("不满足条件")
