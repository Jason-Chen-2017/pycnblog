## 第2章 量子力学基础

### 2.1 量子态与量子比特

量子态是量子系统在量子力学中的一种描述方式，可以用波函数或态矢量表示。量子比特是量子计算的基本单元，可以表示为两个经典比特的叠加态。量子态与量子比特的关系如下：

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle
$$

其中，$|\alpha|^2 + |\beta|^2 = 1$，$\alpha$ 和 $\beta$ 分别表示量子态在基态和叠加态的概率幅。

### 2.2 量子门与量子计算

量子门是量子计算的基本操作，类似于经典计算中的逻辑门。量子门作用于量子比特，可以改变量子比特的状态。常见的量子门包括：

1. **保罗门**（Pauli Gate）：作用于单个量子比特，改变其自旋状态。
2. **控制-NOT门**（CNOT Gate）：作用于两个量子比特，实现量子比特之间的纠缠。
3. **相位门**（Phase Gate）：作用于单个量子比特，改变其相位。

量子计算的基本算法包括量子并行计算和量子纠错。量子并行计算利用量子态的叠加性质，可以在同一时间内处理多个计算任务。量子纠错则通过引入冗余信息，提高量子计算的可靠性。

### 2.3 量子退相干现象

量子退相干是指在量子系统中，由于与环境的相互作用，系统的量子相干性逐渐减弱甚至消失的现象。量子退相干会导致量子比特的状态逐渐变为经典概率分布，从而降低量子计算的效率。

量子退相干的数学描述如下：

$$
|\psi(t)\rangle = e^{-\frac{i}{\hbar}Ht}|\psi(0)\rangle
$$

其中，$H$ 为哈密顿量，$t$ 为时间。

### 2.4 量子退相干的控制方法

为了降低量子退相干对量子计算的影响，可以采用以下方法：

1. **量子噪声抑制**：通过在量子计算过程中引入噪声抑制技术，降低环境噪声对量子系统的干扰。

3. **量子干涉**：利用量子干涉效应，增强量子比特之间的相干性，降低量子退相干的影响。

## 第2章 量子力学基础

#### 2.1 量子态与量子比特

量子态是量子力学中描述粒子状态的数学工具，它可以表示为一个复数的线性组合。量子态通常用波函数或态矢量来表示。例如，一个两状态的量子系统可以用以下形式的量子态表示：

\[|\psi\rangle = \alpha|0\rangle + \beta|1\rangle\]

其中，\(|0\rangle\)和\(|1\rangle\)分别表示量子系统的基态和叠加态，而\(\alpha\)和\(\beta\)是复数，且满足归一化条件：

\[|\alpha|^2 + |\beta|^2 = 1\]

量子比特（qubit）是量子计算中的基本单元，它是量子态的抽象表示。一个量子比特可以同时处于0和1的状态，这种现象称为叠加。量子比特的叠加态可以用一个复数向量来表示，其长度为2，即：

\[|\psi\rangle = \begin{pmatrix} \alpha \\ \beta \end{pmatrix}\]

量子比特的状态可以通过量子门进行变换，这些量子门是量子计算中的基本操作单元。

#### 2.2 量子门与量子计算

量子门是类似于经典逻辑门的操作，但作用于量子比特。量子门通过线性变换将一个量子态映射到另一个量子态。量子门可以用来实现量子逻辑、量子旋转和量子干涉等操作。以下是几种基本的量子门：

1. **保罗门（Pauli Gates）**：保罗门是作用于单个量子比特的量子门，包括X门、Y门和Z门。
   - \(X\) 门（保罗-X门）：将量子比特的状态在0和1之间进行翻转。
     \[X|0\rangle = |1\rangle\]
     \[X|1\rangle = |0\rangle\]
   - \(Y\) 门（保罗-Y门）：将量子比特绕Y轴旋转。
     \[Y|0\rangle = i|1\rangle\]
     \[Y|1\rangle = -i|0\rangle\]
   - \(Z\) 门（保罗-Z门）：将量子比特绕Z轴旋转。
     \[Z|0\rangle = |0\rangle\]
     \[Z|1\rangle = -|1\rangle\]

2. **相位门（Phase Gate）**：相位门可以将量子比特的状态乘以一个相位因子。
   \[S|0\rangle = |0\rangle\]
   \[S|1\rangle = e^{i\phi}|1\rangle\]
   其中，\(\phi\) 是相位角度。

3. **控制-NOT门（Controlled NOT Gate，CNOT）**：CNOT门是最重要的量子门之一，它作用于两个量子比特。
   \[CNOT|00\rangle = |00\rangle\]
   \[CNOT|01\rangle = |10\rangle\]
   \[CNOT|10\rangle = |11\rangle\]
   \[CNOT|11\rangle = |01\rangle\]

量子计算的基本算法包括量子并行计算和量子纠错。量子并行计算利用量子态的叠加性，可以在同一时间内处理多个计算任务，从而极大地提高了计算速度。量子纠错则是通过引入冗余信息，提高量子计算的可靠性，降低量子退相干对计算结果的影响。

其中，\(|\psi(t)\rangle\) 是量子系统在时间 \(t\) 的态，\(H(t)\) 是系统的哈密顿量，表示系统的总能量。

3. **自注意力（Self-Attention）**：自注意力是指模型在处理序列数据时，对序列中的每个元素进行权重分配，以关注序列中的关键信息。自注意力机制广泛应用于Transformer模型中，是自然语言处理领域的一项重要技术。

互注意力模型是指模型在处理两个序列时，计算它们之间的相似度，并进行加权求和处理。其数学公式如下：

其中，\(Q\)、\(K\)、\(V\) 分别是查询序列、键序列和值序列，\(h\) 是头数，\(W^O\) 是输出权重。互注意力模型通过多头注意力机制，增强了模型对不同信息处理的灵活性。

    return tf.linalg.expm(-tf.cast(i, dtype=tf.complex64) * tf.linalg.matmul(H, qubits) * t)

def attention(q, k, v):
