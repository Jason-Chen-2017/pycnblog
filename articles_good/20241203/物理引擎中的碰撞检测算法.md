### 2.1 向量和矩阵运算

在碰撞检测中，向量和矩阵运算是核心部分。向量表示空间中的点，可以用来表示物体的位置、速度和加速度等物理量。矩阵则可以用来表示物体的变换，如旋转、缩放和平移等。

**向量运算**

向量运算包括向量的加法、减法、数乘和点积、叉积等。

1. **向量加法和减法**

   向量加法是将两个向量相加得到一个新的向量，表示两个向量的合成。向量减法则是将一个向量从另一个向量中减去，表示两个向量的差异。

   $$\vec{v}_1 + \vec{v}_2 = \vec{v}_3$$

   $$\vec{v}_1 - \vec{v}_2 = \vec{v}_3$$

2. **数乘**

   数乘是指将向量与一个标量相乘，改变向量的长度和方向。

   $$c\vec{v} = \vec{v}_c$$

3. **点积**

   点积是指两个向量的对应分量相乘后再相加，得到一个标量。点积可以用来判断两个向量的夹角，以及计算向量的模长。

   $$\vec{v}_1 \cdot \vec{v}_2 = v_{1x}v_{2x} + v_{1y}v_{2y}$$

4. **叉积**

   叉积是指两个向量的对应分量相乘后再相加，得到一个新的向量。叉积可以用来计算向量的模长、判断向量的正交性以及计算向量的旋转矩阵。

   $$\vec{v}_1 \times \vec{v}_2 = (v_{1y}v_{2z} - v_{1z}v_{2y}, v_{1z}v_{2x} - v_{1x}v_{2z}, v_{1x}v_{2y} - v_{1y}v_{2x})$$

**矩阵运算**

矩阵运算包括矩阵的加法、减法、数乘、乘法等。

1. **矩阵加法和减法**

   矩阵加法是将两个矩阵的对应元素相加，矩阵减法是将一个矩阵的对应元素从一个矩阵中减去。

   $$A + B = C$$

   $$A - B = C$$

2. **数乘**

   数乘是指将矩阵与一个标量相乘，改变矩阵的规模。

   $$cA = B$$

3. **乘法**

   矩阵乘法是将一个矩阵的每一行与另一个矩阵的每一列相乘，然后将结果相加。矩阵乘法可以用来实现向量的变换，如旋转、缩放和平移等。

   $$AB = C$$

   其中，\(A\) 是一个\(m \times n\)的矩阵，\(B\) 是一个\(n \times p\)的矩阵，\(C\) 是一个\(m \times p\)的矩阵。

   **矩阵乘法的结果是矩阵\(C\)，其元素\(c_{ij}\)计算如下：

   $$c_{ij} = \sum_{k=1}^{n} a_{ik}b_{kj}$$

### 2.2 空间中的几何形状

**矩形**

矩形是一个有四个直角的四边形，其对角线长度相等。矩形通常用来表示平面上的物体，如墙、地板等。

**球体**

**多边形**

多边形是一个有多个边的几何形状，每个顶点都是一个角点。多边形可以用来表示各种复杂的形状，如角色、障碍物等。

### 2.3 空间分解与划分

为了提高碰撞检测的效率，可以将空间进行分解与划分。常见的空间划分方法包括八叉树和BSP树等。

**八叉树**

八叉树是一种用于空间划分的数据结构，可以将三维空间划分为八个相等的子空间。每个子空间都可以进一步划分为八个子空间，从而形成一个递归的空间划分结构。

**BSP树**

BSP树（二分空间树）是一种用于空间划分的数据结构，可以将三维空间划分为两个不相交的子空间。通过递归地将空间划分为两个子空间，直到每个子空间只包含一个物体，从而提高碰撞检测的效率。

### 3.1 简单形状的碰撞检测

简单形状的碰撞检测主要包括矩形与矩形的碰撞检测、球与球的碰撞检测、球与矩形的碰撞检测等。

#### 3.1.1 矩形与矩形的碰撞检测

矩形与矩形的碰撞检测相对简单，主要步骤如下：

1. **计算矩形中心点之间的距离**：使用向量运算计算两个矩形中心点之间的距离。

   $$\vec{d} = \vec{p}_2 - \vec{p}_1$$

   其中，\(\vec{p}_1\) 和 \(\vec{p}_2\) 分别表示两个矩形的中心点。

2. **计算两个矩形边长的和**：计算两个矩形边长的和。

   $$\vec{l}_1 = \vec{w}_1 + \vec{h}_1$$

   $$\vec{l}_2 = \vec{w}_2 + \vec{h}_2$$

   其中，\(\vec{w}_1\) 和 \(\vec{h}_1\) 分别表示第一个矩形的宽和高，\(\vec{w}_2\) 和 \(\vec{h}_2\) 分别表示第二个矩形的宽和高。

3. **判断两个矩形是否碰撞**：判断两个矩形是否碰撞，即判断它们之间的距离是否小于或等于两个矩形边长的和。

   $$\vec{d} \leq \vec{l}_1 + \vec{l}_2$$

   如果上述条件成立，则认为两个矩形发生了碰撞。

以下是使用Python实现的矩形与矩形的碰撞检测算法：

```python
import numpy as np

def rectangle_collision(rect1, rect2):
    p1, w1, h1 = rect1['center'], rect1['width'], rect1['height']
    p2, w2, h2 = rect2['center'], rect2['width'], rect2['height']
    
    d = np.linalg.norm(p2 - p1)
    l1 = np.array([w1, h1])
    l2 = np.array([w2, h2])
    
    return d <= np.linalg.norm(l1 + l2)

# Example usage:
rect1 = {'center': [0, 0], 'width': 2, 'height': 2}
rect2 = {'center': [3, 3], 'width': 2, 'height': 2}
print(rectangle_collision(rect1, rect2))  # Output: True
```

#### 3.1.2 球与球的碰撞检测

球与球的碰撞检测相对简单，主要步骤如下：

1. **计算球心之间的距离**：使用向量运算计算两个球心之间的距离。

   $$\vec{d} = \vec{p}_2 - \vec{p}_1$$

   其中，\(\vec{p}_1\) 和 \(\vec{p}_2\) 分别表示两个球的中心点。

2. **判断两个球是否碰撞**：判断两个球是否碰撞，即判断它们之间的距离是否小于或等于两个球的半径之和。

   $$\vec{d} \leq r_1 + r_2$$

   其中，\(r_1\) 和 \(r_2\) 分别表示两个球的半径。

   如果上述条件成立，则认为两个球发生了碰撞。

以下是使用Python实现的球与球的碰撞检测算法：

```python
import numpy as np

def sphere_collision(sphere1, sphere2):
    p1, r1 = sphere1['center'], sphere1['radius']
    p2, r2 = sphere2['center'], sphere2['radius']
    
    d = np.linalg.norm(p2 - p1)
    
    return d <= r1 + r2

# Example usage:
sphere1 = {'center': [0, 0], 'radius': 2}
sphere2 = {'center': [3, 3], 'radius': 2}
print(sphere_collision(sphere1, sphere2))  # Output: True
```

#### 3.1.3 球与矩形的碰撞检测

球与矩形的碰撞检测相对复杂，需要考虑多个方面。主要步骤如下：

1. **计算球心到矩形平面的距离**：使用向量运算计算球心到矩形平面的距离。

   $$\vec{d} = \vec{p}_2 - \vec{p}_1$$

   其中，\(\vec{p}_1\) 和 \(\vec{p}_2\) 分别表示球心和矩形的中心点。

2. **计算球心到矩形边缘的距离**：使用向量运算计算球心到矩形边缘的最小距离。

   $$\vec{l} = \min_{i} (\vec{p}_2 - \vec{p}_{i1}, \vec{p}_2 - \vec{p}_{i2})$$

   其中，\(i\) 表示矩形的边，\(\vec{p}_{i1}\) 和 \(\vec{p}_{i2}\) 分别表示矩形边的两个端点。

3. **判断球与矩形是否碰撞**：判断球心到矩形平面的距离是否小于或等于球的半径，且球心到矩形边缘的最小距离是否大于等于球的半径。

   $$\vec{d} \leq r_1$$

   $$\vec{l} \geq r_2$$

   如果上述条件成立，则认为球与矩形发生了碰撞。

以下是使用Python实现的球与矩形的碰撞检测算法：

```python
import numpy as np

def sphere_rectangle_collision(sphere, rectangle):
    p1, r1 = sphere['center'], sphere['radius']
    p2, w2, h2 = rectangle['center'], rectangle['width'], rectangle['height']
    
    d = np.linalg.norm(p2 - p1)
    
    # Compute the minimum distance from the sphere's center to the rectangle's edges
    l = min(np.linalg.norm(p2 - np.array([p2[0], p1[1]])), np.linalg.norm(p2 - np.array([p1[0], p2[1]])))
    
    return d <= r1 and l >= r2
```

### 3.2 复杂形状的碰撞检测

#### 3.2.1 多边形与多边形的碰撞检测

多边形与多边形的碰撞检测相对复杂，需要考虑多个顶点之间的碰撞关系。主要步骤如下：

1. **计算多边形之间的最小距离**：使用向量运算计算两个多边形之间的最小距离。

   $$\vec{d} = \min_{i, j} (\vec{p}_{i1} - \vec{p}_{j1}, \vec{p}_{i2} - \vec{p}_{j2}, ..., \vec{p}_{ik} - \vec{p}_{jk})$$

   其中，\(i\) 和 \(j\) 分别表示两个多边形的顶点索引，\(\vec{p}_{i1}, \vec{p}_{i2}, ..., \vec{p}_{ik}\) 和 \(\vec{p}_{j1}, \vec{p}_{j2}, ..., \vec{p}_{jk}\) 分别表示两个多边形的顶点。

2. **判断多边形是否碰撞**：判断两个多边形之间的最小距离是否小于或等于两个多边形的边长之和。

   $$\vec{d} \leq l_1 + l_2$$

   其中，\(l_1\) 和 \(l_2\) 分别表示两个多边形的边长。

   如果上述条件成立，则认为两个多边形发生了碰撞。

以下是使用Python实现的简单多边形与多边形的碰撞检测算法：

```python
import numpy as np

def polygon_collision(polygon1, polygon2):
    p1 = np.array([point['x'] for point in polygon1])
    p2 = np.array([point['x'] for point in polygon2])

    l2 = np.linalg.norm(np.array([p2[0], p1[1]]))
    l3 = np.linalg.norm(np.array([p1[0], p2[1]]))
```

```python
        self.split_value = split_value
        self.left = left
        self.right = right

        return Node(axis, polygon[0][axis])

    else:

        return []

    if point[axis] < node.split_value[axis]:
        return query(node.left, point, axis)

    else:
        result.append([node.split_value[axis], point[axis]])

    return result

        if point[1] < polygon[1][1]:

        return True

    return False
```

#### 4.1.1 八叉树

**八叉树的工作原理**：

1. **初始化**：将整个空间划分为一个八叉树节点。
2. **递归划分**：对于每个非叶子节点，如果节点中的物体数量超过设定阈值，则将该节点划分为8个子节点，每个子节点代表空间中的一个立方体。
3. **插入物体**：将物体插入到八叉树中，每个物体都会被放置在适当的子节点中。
4. **查询碰撞**：当检测碰撞时，从根节点开始，逐步向叶子节点查询，找到与物体相交的子节点，然后在子节点内进行更精细的碰撞检测。

**八叉树的优点**：

- **高效的空间划分**：八叉树能够有效地处理动态物体，因为它可以根据物体的运动动态地调整空间划分。
- **易于实现**：八叉树的结构相对简单，易于实现和理解。

**八叉树的缺点**：

- **内存占用**：八叉树可能需要较多的内存，因为每个节点都需要存储分割平面的信息。
- **插入和删除**：动态调整八叉树可能需要插入和删除节点，这可能会增加复杂性。

### 4.2 代理对象

代理对象是一种优化碰撞检测的方法，通过使用简化的模型来代表复杂的物体。这些代理对象通常只包含足够的信息来检测碰撞，而不是模拟物体的所有物理特性。

### 4.3 碰撞检测缓存

碰撞检测缓存是一种优化方法，通过缓存已检测到的碰撞结果，以避免重复计算。这种方法特别适用于动态场景，其中一些碰撞对可能会多次出现。

3. **更新缓存**：如果碰撞结果发生变化，更新缓存中的结果。

**碰撞检测缓存的优点**：

- **提高效率**：通过减少实际碰撞检测的次数，可以提高碰撞检测的效率。

## 第5章 碰撞响应处理

碰撞响应处理是物理引擎中的另一个关键部分，它负责计算物体在碰撞后的运动状态，并确保物理现象的连贯性和合理性。本章将探讨碰撞响应处理的基本原理，包括动量守恒和势能守恒，并介绍碰撞接触方程和碰撞响应处理算法。

### 5.1 碰撞响应原理

碰撞响应原理基于物理学中的基本守恒定律，主要是动量守恒和势能守恒。这些原理确保了物体在碰撞过程中的物理行为符合现实世界的规律。

#### 5.1.1 动量守恒

动量守恒是指在一个封闭系统中，总动量保持不变。对于两个相互碰撞的物体，它们的总动量在碰撞前后是相等的。动量的定义是物体的质量乘以其速度。

$$\vec{p}_{\text{总前}} = \vec{p}_{\text{总后}}$$

其中，\(\vec{p}_{\text{总前}}\) 和 \(\vec{p}_{\text{总后}}\) 分别表示碰撞前后的总动量。

假设有两个物体A和B，质量分别为\(m_A\)和\(m_B\)，速度分别为\(\vec{v}_A\)和\(\vec{v}_B\)。在无外力作用的情况下，它们的动量守恒方程可以表示为：

$$m_A\vec{v}_A + m_B\vec{v}_B = m_A\vec{v}_A' + m_B\vec{v}_B'$$

其中，\(\vec{v}_A'\)和\(\vec{v}_B'\)分别表示碰撞后物体A和B的速度。

#### 5.1.2 势能守恒

势能守恒是指在闭合系统中，总势能保持不变。在碰撞过程中，物体的动能和势能之间可以相互转换，但总能量保持不变。对于碰撞问题，通常考虑的是动能守恒。

动能的表达式为：

$$K = \frac{1}{2}mv^2$$

其中，\(m\)是物体的质量，\(v\)是物体的速度。

在没有非弹性碰撞的理想情况下，两个物体的总动能守恒：

$$\frac{1}{2}m_Av_{A0}^2 + \frac{1}{2}m_Bv_{B0}^2 = \frac{1}{2}m_Av_{A'}^2 + \frac{1}{2}m_Bv_{B'}^2$$

其中，\(v_{A0}\)和\(v_{B0}\)分别表示碰撞前物体A和B的速度，\(v_{A'}\)和\(v_{B'}\)分别表示碰撞后物体A和B的速度。

### 5.2 碰撞接触方程

碰撞接触方程用于计算碰撞后物体的运动状态。这些方程通常基于牛顿第二定律和牛顿第三定律。

#### 5.2.1 单自由度接触方程

单自由度接触方程是最简单的碰撞响应方程，适用于物体在单个方向上的碰撞。假设物体A和B在x方向上发生碰撞，则它们的接触方程可以表示为：

$$m_Aa_A = -m_Ba_B$$

其中，\(a_A\)和\(a_B\)分别表示物体A和B在x方向上的加速度。

根据牛顿第二定律，加速度可以表示为：

$$a = \frac{F}{m}$$

其中，\(F\)是作用在物体上的力，\(m\)是物体的质量。

结合上述方程，可以得到：

$$m_A\frac{dv_A}{dt} = -m_B\frac{dv_B}{dt}$$

假设碰撞持续时间为\(\Delta t\)，则可以得到：

$$m_Av_{A, \text{final}} - m_Av_{A, \text{initial}} = -m_Bv_{B, \text{final}} + m_Bv_{B, \text{initial}}$$

简化后，可以得到单自由度碰撞方程：

$$m_Av_{A, \text{initial}} + m_Bv_{B, \text{initial}} = m_Av_{A, \text{final}} + m_Bv_{B, \text{final}}$$

#### 5.2.2 多自由度接触方程

多自由度接触方程用于处理物体在多个方向上的碰撞。假设物体A和B在x和y方向上发生碰撞，则它们的接触方程可以表示为：

$$m_Aa_{Ax} = -m_Ba_{Bx}$$

$$m_Aa_{Ay} = -m_Ba_{By}$$

其中，\(a_{Ax}\)和\(a_{Ay}\)分别表示物体A在x和y方向上的加速度，\(a_{Bx}\)和\(a_{By}\)分别表示物体B在x和y方向上的加速度。

根据牛顿第二定律，加速度可以表示为：

$$a_{Ax} = \frac{F_{Ax}}{m_A}$$

$$a_{Ay} = \frac{F_{Ay}}{m_A}$$

$$a_{Bx} = \frac{F_{Bx}}{m_B}$$

$$a_{By} = \frac{F_{By}}{m_B}$$

结合上述方程，可以得到：

$$m_A\frac{dv_{Ax}}{dt} = -m_B\frac{dv_{Bx}}{dt}$$

$$m_A\frac{dv_{Ay}}{dt} = -m_B\frac{dv_{By}}{dt}$$

假设碰撞持续时间为\(\Delta t\)，则可以得到：

$$m_Av_{Ax, \text{final}} - m_Av_{Ax, \text{initial}} = -m_Bv_{Bx, \text{final}} + m_Bv_{Bx, \text{initial}}$$

$$m_Av_{Ay, \text{final}} - m_Av_{Ay, \text{initial}} = -m_Bv_{By, \text{final}} + m_Bv_{By, \text{initial}}$$

简化后，可以得到多自由度碰撞方程：

$$m_Av_{Ax, \text{initial}} + m_Bv_{Bx, \text{initial}} = m_Av_{Ax, \text{final}} + m_Bv_{Bx, \text{final}}$$

$$m_Av_{Ay, \text{initial}} + m_Bv_{By, \text{initial}} = m_Av_{Ay, \text{final}} + m_Bv_{By, \text{final}}$$

### 5.3 碰撞响应处理算法

碰撞响应处理算法负责根据碰撞响应原理和接触方程计算物体在碰撞后的状态。以下是几种常见的碰撞响应处理算法：

#### 5.3.1 简单反弹

简单反弹是最简单的碰撞响应处理算法，它假设碰撞是完全弹性的，即碰撞后物体的速度方向和大小完全反转。

1. **计算碰撞前的速度**：

   $$\vec{v}_{\text{initial}} = \vec{v}_A + \vec{v}_B$$

   其中，\(\vec{v}_A\)和\(\vec{v}_B\)分别表示碰撞前物体A和B的速度。

2. **计算碰撞后的速度**：

   $$\vec{v}_{\text{final}} = -\vec{v}_{\text{initial}}$$

   碰撞后物体的速度大小和方向与碰撞前相反。

#### 5.3.2 粘滞碰撞

粘滞碰撞是一种非弹性碰撞，它假设碰撞后物体将粘在一起，即物体之间的速度差为零。

1. **计算碰撞前的速度**：

   $$\vec{v}_{\text{initial}} = \vec{v}_A + \vec{v}_B$$

   其中，\(\vec{v}_A\)和\(\vec{v}_B\)分别表示碰撞前物体A和B的速度。

2. **计算碰撞后的速度**：

   $$\vec{v}_{\text{final}} = \frac{m_A\vec{v}_A + m_B\vec{v}_B}{m_A + m_B}$$

   碰撞后物体的速度是两个物体碰撞前速度的加权平均。

通过使用这些碰撞响应处理算法，可以模拟出各种碰撞现象，从而提高物理引擎的逼真度和游戏体验。

#### 6.1.1 向量运算

向量是表示物体位置、速度和加速度的基本数学工具。以下是一些常用的向量运算：

1. **向量加法**：

   $$\vec{v} + \vec{w} = \vec{u}$$

   其中，\(\vec{v}\)和\(\vec{w}\)是两个向量，\(\vec{u}\)是它们的和。

2. **向量减法**：

   $$\vec{v} - \vec{w} = \vec{u}$$

   其中，\(\vec{v}\)和\(\vec{w}\)是两个向量，\(\vec{u}\)是它们的差。

3. **向量数乘**：

   $$c\vec{v} = \vec{w}$$

   其中，\(c\)是一个标量，\(\vec{v}\)是一个向量，\(\vec{w}\)是它们的乘积。

4. **向量点积**：

   $$\vec{v} \cdot \vec{w} = v_xw_x + v_yw_y + v_zw_z$$

   其中，\(\vec{v}\)和\(\vec{w}\)是两个三维向量，\(v_x, v_y, v_z\)和\(w_x, w_y, w_z\)分别是它们的分量。

5. **向量叉积**：

   $$\vec{v} \times \vec{w} = (v_yw_z - v_zw_y, v_zw_x - v_xw_z, v_xw_y - v_yw_x)$$

   其中，\(\vec{v}\)和\(\vec{w}\)是两个三维向量，它们的叉积结果是一个新的三维向量。

#### 6.1.2 矩阵运算

矩阵用于表示物体的变换，如旋转、缩放和平移。以下是一些常用的矩阵运算：

1. **矩阵加法**：

   $$A + B = C$$

   其中，\(A\)和\(B\)是两个矩阵，\(C\)是它们的和。

2. **矩阵减法**：

   $$A - B = C$$

   其中，\(A\)和\(B\)是两个矩阵，\(C\)是它们的差。

3. **矩阵数乘**：

   $$cA = B$$

   其中，\(c\)是一个标量，\(A\)是一个矩阵，\(B\)是它们的乘积。

4. **矩阵乘法**：

   $$AB = C$$

   其中，\(A\)是一个\(m \times n\)的矩阵，\(B\)是一个\(n \times p\)的矩阵，\(C\)是一个\(m \times p\)的矩阵。

   矩阵乘法的结果是矩阵\(C\)，其元素\(c_{ij}\)计算如下：

   $$c_{ij} = \sum_{k=1}^{n} a_{ik}b_{kj}$$

#### 6.1.3 几何形状方程

几何形状方程用于描述物体在空间中的位置和形状。以下是几种常见几何形状的方程：

1. **矩形**：

   一个矩形由四个顶点定义，其方程可以表示为：

   $$x_1 \leq x \leq x_2$$

   $$y_1 \leq y \leq y_2$$

   其中，\(x_1, y_1\)和\(x_2, y_2\)分别是矩形的两个对角顶点的坐标。

2. **球体**：

   一个球体由球心和半径定义，其方程可以表示为：

   $$(x - x_c)^2 + (y - y_c)^2 + (z - z_c)^2 = r^2$$

   其中，\((x_c, y_c, z_c)\)是球心的坐标，\(r\)是球的半径。

3. **多边形**：

   一个多边形由多个顶点定义，其方程可以表示为：

   $$P = \sum_{i=1}^{n} w_i \vec{p}_i$$

   其中，\(P\)是平面方程，\(\vec{p}_i\)是顶点，\(w_i\)是法线方向上的权重。

#### 6.2.1 矩形与矩形的碰撞检测公式

矩形与矩形的碰撞检测可以通过计算两个矩形中心点之间的距离和两个矩形的半宽和半高来实现。以下是矩形与矩形碰撞检测的步骤和公式：

1. **计算两个矩形中心点之间的距离**：

   $$\vec{d} = \vec{p}_2 - \vec{p}_1$$

   其中，\(\vec{p}_1\)和\(\vec{p}_2\)分别是两个矩形的中心点。

2. **计算两个矩形边长的和**：

   $$\vec{l}_1 = \vec{w}_1 + \vec{h}_1$$

   $$\vec{l}_2 = \vec{w}_2 + \vec{h}_2$$

   其中，\(\vec{w}_1, \vec{h}_1\)分别是第一个矩形的宽和高，\(\vec{w}_2, \vec{h}_2\)分别是第二个矩形的宽和高。

3. **判断两个矩形是否碰撞**：

   $$\vec{d} \leq \vec{l}_1 + \vec{l}_2$$

   如果上述条件成立，则两个矩形发生了碰撞。

```python
import numpy as np

def rectangle_collision(rect1, rect2):
    p1, w1, h1 = rect1['center'], rect1['width'], rect1['height']
    p2, w2, h2 = rect2['center'], rect2['width'], rect2['height']

    l2 = np.array([w2, h2])
```
