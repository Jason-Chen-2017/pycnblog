递归函数是计算机科学中一种重要的算法设计方法，它通过函数自身调用来解决问题。递归函数的基本概念相对简单，但理解其原理和运用却需要深入思考。

**递归函数的定义**：

递归函数是一种直接或间接调用自身的函数。递归可以分为两种基本形式：直接递归和间接递归。直接递归是指函数直接调用自身，例如，函数 `f(x) = f(x-1)`。而间接递归则是通过一系列函数调用链间接调用自身，例如，函数 `f(x)` 调用 `g(x)`，而 `g(x)` 又调用 `f(x)`。

**递归函数的特点**：

1. **自我重复性**：递归函数通过重复执行相同的操作来解决问题。
2. **终止条件**：递归函数必须有一个明确的终止条件，以确保递归能够结束，防止出现无限循环。
3. **简洁性**：递归函数通常比迭代函数更简洁，能够更直观地表达问题。

**递归算法的基本原理**：

递归算法通常遵循以下步骤：

1. **分解问题**：将复杂问题分解为若干个规模更小的同类问题。
2. **递归调用**：对规模较小的子问题进行递归调用。
3. **合并结果**：将子问题的解合并为原问题的解。

递归算法的优势在于其简洁和直观性，但同时也存在一定的劣势，如容易导致栈溢出和效率较低等问题。

**递归算法的优势与劣势**：

优势：
- **简洁性**：能够用更少的代码实现复杂的逻辑。
- **直观性**：能够直观地表示问题的分解和合并过程。

劣势：
- **栈溢出**：递归调用会消耗大量的栈空间，可能导致栈溢出。
- **效率问题**：递归算法的效率通常不如迭代算法，尤其是在数据量大时。

**典型递归问题**：

1. **计算阶乘**：`f(n) = n * f(n-1)`，终止条件为 `f(0) = 1`。
2. **递归遍历树结构**：如二叉树的遍历。
3. **递归解决汉诺塔问题**。

总结来说，递归函数作为一种强大的算法设计工具，其基本概念和原理简单但应用广泛。通过递归，我们可以更直观地分解和解决复杂问题，但在实际应用中需要注意其效率和栈空间限制。

### 递归函数的类型

递归函数根据其调用方式可以分为纯递归函数和部分递归函数。这两种递归函数在算法设计和实现中各有特点和应用场景。

**纯递归函数**：

纯递归函数是一种完全通过递归调用来实现功能的函数，没有使用循环结构。其基本形式如下：

```python
def pure_recursive(n):
    if n == 0:
        return 1
    else:
        return n * pure_recursive(n-1)
```

在这个例子中，`pure_recursive` 函数通过递归调用自身来计算阶乘。纯递归函数的优点在于其简洁性和直观性，使得问题的分解和解决过程更加清晰。然而，纯递归函数也存在一些缺点，如容易导致栈溢出和效率较低。因此，在实际应用中，我们需要谨慎选择是否使用纯递归。

**部分递归函数**：

部分递归函数则是一种结合递归和迭代结构的函数，通常通过递归调用和一些迭代操作来实现。其基本形式如下：

```python
def partial_recursive(n):
    result = 1
    while n > 0:
        result *= n
        n -= 1
    return result
```

在这个例子中，`partial_recursive` 函数通过迭代计算阶乘，并在过程中使用递归调用来更新变量。部分递归函数的优点在于其在处理大问题时的效率较高，同时不会像纯递归函数那样容易导致栈溢出。因此，部分递归函数在实际应用中更加常见。

**纯递归函数与部分递归函数的比较**：

| 特点 | 纯递归函数 | 部分递归函数 |
| ---- | ---------- | ------------ |
| 递归方式 | 完全依赖递归调用 | 结合递归与迭代 |
| 效率 | 较低，容易导致栈溢出 | 较高，更安全 |
| 简洁性 | 简洁，直观 | 相对复杂，但更灵活 |

在实际应用中，我们应根据具体问题选择合适的递归函数类型。对于一些复杂且规模较小的问题，纯递归函数可能更简洁；而对于规模较大或需要高效率的问题，部分递归函数可能更为合适。

### 递归函数的数学基础

递归函数在算法设计中具有重要的地位，其基础理论离不开数学归纳法和递推关系式。以下将详细讨论这两个数学基础概念，并说明它们如何与递归函数密切相关。

**数学归纳法**：

数学归纳法是一种证明方法，它基于两个基本步骤来证明一个数学命题对于所有自然数都成立：

1. **基础步骤**：证明当 `n` 取最小值（通常是 `n=1`）时，命题成立。
2. **归纳步骤**：假设当 `n=k` 时，命题成立，然后证明当 `n=k+1` 时，命题也成立。

数学归纳法在证明递归函数的正确性方面具有重要作用。例如，要证明递归函数 `f(n) = n!`（n的阶乘）的正确性，可以通过数学归纳法来证明：

- **基础步骤**：当 `n=1` 时，`f(1) = 1! = 1`，命题成立。
- **归纳步骤**：假设当 `n=k` 时，`f(k) = k!` 成立，需要证明当 `n=k+1` 时，`f(k+1) = (k+1)!` 成立。

根据递归函数的定义，我们有：

\[ f(k+1) = (k+1) \times f(k) \]

由于假设 `f(k) = k!` 成立，所以：

\[ f(k+1) = (k+1) \times k! = (k+1)! \]

因此，归纳步骤也成立。综上所述，通过数学归纳法，我们可以证明递归函数 `f(n) = n!` 对于所有自然数 `n` 都成立。

**递推关系式**：

递推关系式是一种数学表达式，用于描述序列中每个元素与其前一个或前几个元素之间的关系。递推关系式在递归函数中起到核心作用，因为它定义了递归调用的规则和终止条件。

递推关系式通常具有以下形式：

\[ a_n = f(a_{n-1}, a_{n-2}, \ldots) \]

其中，`a_n` 表示序列中的第 `n` 个元素，`f()` 是一个函数，用于根据前一个或前几个元素计算当前元素。

例如，考虑一个简单的斐波那契数列，其递推关系式为：

\[ f(n) = 
  \begin{cases} 
   0 & \text{if } n = 0 \\
   1 & \text{if } n = 1 \\
   f(n-1) + f(n-2) & \text{otherwise} 
  \end{cases}
\]

在这个递推关系式中，每个斐波那契数都是前两个斐波那契数之和。通过递归调用，我们可以计算任意一个斐波那契数。

**递归函数与数学归纳法和递推关系式的关系**：

数学归纳法和递推关系式是递归函数的基础。数学归纳法用于证明递归函数的正确性，而递推关系式则用于定义递归调用的规则。具体来说：

1. **数学归纳法**：通过数学归纳法，我们可以证明递归函数在所有自然数上的正确性。这是确保递归函数可靠性的关键。
2. **递推关系式**：递推关系式定义了递归函数的调用过程，它决定了递归函数如何通过递归调用解决子问题，并最终合并为原问题的解。

综上所述，递归函数的数学基础包括数学归纳法和递推关系式。这些基础概念不仅帮助我们理解和证明递归函数的正确性，还指导我们设计和优化递归算法。通过深入理解这些数学概念，我们可以更有效地运用递归函数解决复杂的问题。

### 递归算法的基本原理

递归算法是一种通过递归调用自身来解决子问题，然后将子问题的解合并为原问题解的算法设计方法。理解递归算法的基本原理对于掌握递归函数在算法设计中的应用至关重要。

**递归算法的基本结构**：

一个典型的递归算法通常包含以下几个关键部分：

1. **基线条件**：递归的终止条件，用于避免无限递归。基线条件定义了递归何时应该停止，例如，当输入数据达到某个最小规模或满足特定条件时，算法将返回一个确定的值。
2. **递归调用**：递归算法的核心部分，通过递归调用自身来解决规模较小的子问题。每次递归调用都会将问题规模缩小，直到达到基线条件。
3. **合并结果**：将子问题的解合并为原问题的解。这一步骤通常涉及到对子问题的解进行组合或转换，以得到最终的结果。

**递归算法的优化**：

虽然递归算法简洁直观，但在某些情况下，其性能可能不如迭代算法。因此，优化递归算法是非常必要的。以下是一些常见的优化策略：

1. **尾递归优化**：尾递归是指递归调用是函数执行的最后一项操作。在许多编程语言中，尾递归可以通过编译器自动优化为迭代结构，从而提高性能。
2. **递归记忆化**：通过存储已解决的子问题结果，避免重复计算。这种方法特别适用于具有重叠子问题的递归算法，如动态规划。
3. **减少递归深度**：通过调整递归调用的参数，减少递归的深度，从而降低栈空间的使用。

**常见的递归算法**：

递归算法在计算机科学中应用广泛，以下介绍几个典型的递归算法：

1. **快速排序**：快速排序是一种高效的排序算法，其基本思想是通过递归将数据分割成较小和较大的两部分，然后分别对两部分进行排序。
2. **汉诺塔问题**：汉诺塔问题是一个经典的递归问题，用于演示递归算法的原理。该问题要求将一组大小不等的盘子从一个柱子移动到另一个柱子，同时遵循一定的规则。
3. **递归遍历树结构**：在树结构中，递归算法用于遍历树的节点，如前序遍历、中序遍历和后序遍历。

**快速排序算法**：

快速排序的基本步骤如下：

1. **选择基准元素**：从数组中选择一个元素作为基准。
2. **分区操作**：将数组分为两部分，一部分包含小于基准的元素，另一部分包含大于基准的元素。
3. **递归排序**：分别对小于和大于基准的子数组进行快速排序。

以下是快速排序的Python代码示例：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    
    return quick_sort(left) + middle + quick_sort(right)

# 示例
arr = [3, 6, 8, 10, 1, 2, 1]
print(quick_sort(arr))
```

**汉诺塔问题**：

汉诺塔问题可以通过递归算法解决。该问题有三个柱子和若干大小不同的盘子，初始时盘子按从小到大的顺序放在一个柱子上。目标是将所有盘子移到另一个柱子上，同时遵循以下规则：

1. 每次只能移动一个盘子。
2. 盘子只能放在比它大的盘子上或直接放在柱子上。

以下是汉诺塔问题的Python代码示例：

```python
def hanoi(n, from_peg, to_peg, aux_peg):
    if n == 1:
        print(f"Move disk 1 from {from_peg} to {to_peg}")
        return
    hanoi(n-1, from_peg, aux_peg, to_peg)
    print(f"Move disk {n} from {from_peg} to {to_peg}")
    hanoi(n-1, aux_peg, to_peg, from_peg)

# 示例
hanoi(3, 'A', 'C', 'B')
```

**递归遍历树结构**：

在树结构中，递归算法常用于遍历树的节点。以下是一个简单的二叉树遍历示例：

```python
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

def inorder_traversal(node):
    if node is not None:
        inorder_traversal(node.left)
        print(node.value)
        inorder_traversal(node.right)

# 创建二叉树

root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.left = TreeNode(4)
root.left.right = TreeNode(5)

# 遍历二叉树
inorder_traversal(root)
```

### 递归函数在图算法中的应用

递归函数在图算法中有着广泛的应用，它能够有效地解决许多复杂的图论问题。以下将详细讨论图的相关概念、递归遍历算法以及具体实例。

**图的递归定义**：

图是由节点（也称为顶点）和边组成的集合。一个图可以形式地表示为 `G = (V, E)`，其中 `V` 是节点集合，`E` 是边集合。图可以分类为无向图和有向图，以及连通图和非连通图。

1. **无向图**：图中的边没有方向，任意两个顶点之间都是互相可达的。
2. **有向图**：图中的边有方向，从一个顶点指向另一个顶点。
3. **连通图**：对于任意两个顶点 `u` 和 `v`，存在路径将它们连接起来。
4. **非连通图**：图中存在一些顶点无法通过路径相互连接。

**图的递归遍历算法**：

图的递归遍历算法是图算法中的基础，常用的递归遍历算法包括深度优先搜索（DFS）和广度优先搜索（BFS）。

1. **深度优先搜索（DFS）**：

深度优先搜索是一种从起始节点开始，尽可能深地搜索图的过程。其基本思想是沿着当前路径一直搜索，直到达到一个终点，然后再回溯并选择另一条路径继续搜索。

以下是深度优先搜索的递归实现：

```python
def dfs(graph, node, visited):
    if node not in visited:
        visited.add(node)
        for neighbor in graph[node]:
            dfs(graph, neighbor, visited)

# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}
visited = set()
dfs(graph, 'A', visited)
```

2. **广度优先搜索（BFS）**：

广度优先搜索是一种从起始节点开始，按层次遍历图的过程。它使用一个队列来维护当前的搜索顺序。

以下是广度优先搜索的递归实现：

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    
    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            for neighbor in graph[node]:
                queue.append(neighbor)
    
    return visited

# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}
print(bfs(graph, 'A'))
```

**图的递归算法实例**：

1. **深度优先搜索（DFS）**：

深度优先搜索可以用于求解图的连通性、寻找路径以及拓扑排序等问题。

- **连通性检测**：通过DFS判断两个顶点是否连通。
- **路径搜索**：通过DFS寻找图中两点之间的路径。

以下是连通性检测的Python代码示例：

```python
def is_connected(graph, start, end):
    visited = set()
    dfs(graph, start, visited)
    return end in visited

# 示例
print(is_connected(graph, 'A', 'F'))  # 输出：True
```

2. **广度优先搜索（BFS）**：

广度优先搜索常用于求解最短路径问题。

- **单源最短路径**：使用BFS可以找到从单个源点到其他所有顶点的最短路径。
- **双源最短路径**：扩展BFS，可以找到两顶点之间的最短路径。

以下是单源最短路径的Python代码示例：

```python
def shortest_path(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    visited = set()
    queue = deque([start])
    
    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            for neighbor, weight in graph[node].items():
                distance = distances[node] + weight
                if distance < distances[neighbor]:
                    distances[neighbor] = distance
                    queue.append(neighbor)
    
    return distances

# 示例
graph = {
    'A': {'B': 1, 'C': 2},
    'B': {'A': 1, 'D': 3},
    'C': {'A': 2, 'E': 1},
    'D': {'B': 3, 'E': 1},
    'E': {'C': 1, 'D': 1}
}
print(shortest_path(graph, 'A'))  # 输出：{'A': 0, 'B': 1, 'C': 2, 'D': 4, 'E': 3}
```

通过以上示例，我们可以看到递归函数在图算法中的应用是如何有效地解决图的遍历和路径搜索问题。递归算法的简洁性和直观性使其在图算法中具有不可替代的地位。

### 递归函数在动态规划中的应用

递归函数在动态规划中的应用是算法设计中的一个重要领域。动态规划是一种优化递归算法的方法，通过将子问题的解存储起来，避免重复计算，从而提高算法的效率。以下将详细介绍动态规划的基本概念、原理以及递归实现动态规划的方法。

**动态规划的基本概念**：

动态规划（Dynamic Programming，DP）是一种用于解决最优子结构问题的高效算法设计方法。其核心思想是将问题分解为若干个子问题，并存储子问题的解，避免重复计算。

**动态规划的原理**：

动态规划通常遵循以下两个基本原则：

1. **最优子结构**：问题的最优解包含其子问题的最优解。这意味着可以通过求解子问题的最优解来构建原问题的最优解。
2. **重叠子问题**：在递归过程中，许多子问题会被多次计算。动态规划通过存储已计算的子问题的解来避免重复计算。

**动态规划的递归实现**：

动态规划可以通过递归实现，但传统的递归方法通常会导致大量的重复计算。为了解决这个问题，可以使用以下方法：

1. **递归记忆化**：通过存储已计算的子问题的解，避免重复计算。这种方法通过一个数组或哈希表来存储子问题的解。
2. **迭代方法**：将递归过程转换为迭代过程，从而减少递归调用和栈空间的使用。

**动态规划的递归实现示例**：

**问题背景**：

**动态规划的基本原理**：

动态规划的基本原理可以概括为以下两点：

1. **最优子结构**：问题的最优解包含其子问题的最优解。这意味着我们可以通过求解子问题的最优解来构建原问题的最优解。
2. **重叠子问题**：在递归过程中，许多子问题会被多次计算。动态规划通过存储已计算的子问题的解，避免重复计算，从而提高算法的效率。

**递归实现的基本步骤**：

2. **状态转移方程**：根据字符串的比较规则，可以推导出状态转移方程：
   - 如果 `s1[i] == s2[j]`，则 `LCS(i, j) = 1 + LCS(i-1, j-1)`；
   - 如果 `s1[i] != s2[j]`，则 `LCS(i, j) = max(LCS(i-1, j), LCS(i, j-1))`。
3. **初始化边界条件**：通常初始化 `LCS(0, 0)` 为 0，即空字符串的最长公共子序列长度为 0。
4. **递归求解**：根据状态转移方程递归求解 `LCS(i, j)`。

**记忆化技术**：

```python
def lcs(s1, s2):
    memo = [[0] * (len(s2) + 1) for _ in range(len(s1) + 1)]

    def dp(i, j):
        if i == 0 or j == 0:
            return 0
        if memo[i][j] != 0:
            return memo[i][j]
        
        if s1[i - 1] == s2[j - 1]:
            memo[i][j] = 1 + dp(i - 1, j - 1)
        else:
            memo[i][j] = max(dp(i - 1, j), dp(i, j - 1))
        
        return memo[i][j]

    return dp(len(s1), len(s2))
```

通过以上示例和比较，我们可以看到KMP算法和正则表达式匹配在字符串处理中的应用。KMP算法通过部分匹配表优化搜索过程，能够高效地处理字符串匹配问题，而正则表达式匹配则通过预定义的模式提供了强大的文本处理能力。

### 递归函数在其他算法中的应用

递归函数不仅在常见的排序和图算法中有着广泛的应用，还在其他类型的算法中发挥了重要作用。以下将介绍递归函数在背包问题、线性基算法和其他算法中的应用。

**背包问题**：

背包问题是组合优化领域中的一个经典问题，其目标是在给定物品的重量和价值之间找到一个最优组合，使得总价值最大化且不超过背包的容量限制。

1. **0-1背包问题**：

0-1背包问题是指每个物品只有两种选择：放入背包或不放入背包。以下是一个0-1背包问题的递归解法：

```python
def knapsack(values, weights, capacity):
    def dp(i, capacity):
        if i == 0 or capacity == 0:
            return 0
        if weights[i] > capacity:
            return dp(i - 1, capacity)
        else:
            return max(values[i] + dp(i - 1, capacity - weights[i]), dp(i - 1, capacity))
    
    return dp(len(values) - 1, capacity)

# 示例
values = [60, 100, 120]
weights = [10, 20, 30]
capacity = 50
print(knapsack(values, weights, capacity))  # 输出：220
```

在这个示例中，`knapsack` 函数使用递归和动态规划技术，通过分治策略逐步求解每个子问题，并利用记忆化避免重复计算。

2. **完全背包问题**：

完全背包问题是指每个物品可以有多个选择，可以放入背包多次。以下是一个完全背包问题的递归解法：

```python
def complete_knapsack(values, weights, capacity):
    def dp(i, capacity):
        if i == 0 or capacity == 0:
            return 0
        if weights[i] > capacity:
            return dp(i - 1, capacity)
        else:
            return max(dp(i - 1, capacity), values[i] + dp(i, capacity - weights[i]))
    
    return dp(len(values) - 1, capacity)

# 示例
values = [60, 100, 120]
weights = [10, 20, 30]
capacity = 50
print(complete_knapsack(values, weights, capacity))  # 输出：320
```

在这个示例中，`complete_knapsack` 函数同样使用递归和动态规划技术，通过分治策略逐步求解每个子问题，并利用记忆化避免重复计算。

**线性基算法**：

线性基算法是一种用于解决线性可行域问题的算法，它在多项式时间内在给定整数集合的线性组合中找到最大正整数。以下是一个简单的线性基算法实现：

```python
def linear_base(alphas):
    bases = []
    for alpha in sorted(alphas, reverse=True):
        if alpha <= 0:
            continue
        bases.append(alpha)
        for b in bases:
            alpha %= b
    return bases

# 示例
alphas = [3, 5, 7, 9, 14]
print(linear_base(alphas))  # 输出：[14, 7, 3]
```

在这个示例中，`linear_base` 函数通过递归调用，将整数集合中的元素按照降序排列，并逐步将较大的数减去较小的数，从而找到线性基。

### 递归函数的优化与并行化

递归函数虽然在算法设计中具有简洁性和直观性，但在处理大规模问题时可能存在效率低下和栈溢出的问题。为了提高递归函数的性能，我们可以通过优化和并行化技术来提升其执行效率。

**递归函数的优化**：

1. **尾递归优化**：

尾递归是指递归调用是函数执行的最后一项操作。许多现代编程语言可以通过编译器自动将尾递归优化为迭代结构，从而减少栈空间的使用。

例如，以下是一个尾递归函数和其优化后的迭代版本：

```python
# 尾递归版本
def factorial_recursive(n):
    if n == 0:
        return 1
    else:
        return n * factorial_recursive(n - 1)

# 迭代版本
def factorial_iterative(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result
```

2. **递归记忆化**：

递归记忆化通过存储已计算的子问题解来避免重复计算，特别适用于具有重叠子问题的递归算法。以下是一个使用记忆化优化递归的示例：

```python
def fibonacci(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo)
    return memo[n]

# 使用记忆化计算Fibonacci数列的前10项
for i in range(10):
    print(f"Fibonacci({i}) = {fibonacci(i)}")
```

3. **减少递归深度**：

在某些情况下，可以通过调整递归调用的参数来减少递归深度，从而降低栈空间的使用。例如，在二分查找算法中，可以通过中点值的偏移量来减少递归深度。

**递归函数的并行化**：

递归函数的并行化可以通过将递归树分解为多个独立的子任务来实现。以下是一些并行化递归函数的策略：

1. **分治并行化**：

分治并行化通过将大问题分解为多个小问题，并并行解决这些子问题。以下是一个使用并行化分治策略的例子：

```python
from concurrent.futures import ThreadPoolExecutor

def parallel_factorial(n, num_workers=4):
    if n == 0:
        return 1
    if n <= 1:
        return n
    
    with ThreadPoolExecutor(max_workers=num_workers) as executor:
        future_to_factorial = {executor.submit(factorial, i): i for i in range(1, n + 1)}
        result = 1
        for future in future_to_factorial.as_completed(future_to_factorial):
            result *= future.result()
    return result

# 并行计算Fibonacci数列的前10项
for i in range(10):
    print(f"Fibonacci({i}) = {parallel_factorial(i)}")
```

2. **并行树分解**：

并行树分解通过将递归树分解为多个独立的子树，每个子树可以并行处理。以下是一个简单的并行树分解示例：

```python
def parallel_fibonacci(n, num_workers=4):
    if n <= 1:
        return n
    
    with ThreadPoolExecutor(max_workers=num_workers) as executor:
        future_to_fib = {executor.submit(parallel_fibonacci, i, num_workers): i for i in range(1, n + 1)}
        a, b = 0, 1
        for future in future_to_fib.as_completed(future_to_fib):
            a, b = b, a + future.result()
    
    return b

# 并行计算Fibonacci数列的前10项
for i in range(10):
    print(f"Fibonacci({i}) = {parallel_fibonacci(i)}")
```

通过这些优化和并行化策略，我们可以显著提高递归函数在大规模数据上的性能。递归函数的优化与并行化不仅能够提高算法的效率，还能为处理复杂问题提供更强大的工具。

```java
import java.util.concurrent.RecursiveTask;
import java.util.concurrent.ForkJoinPool;

public class ParallelFactorial extends RecursiveTask<Integer> {
    private final int n;
    private static final int THRESHOLD = 10;

    public ParallelFactorial(int n) {
        this.n = n;
    }

    @Override
    protected Integer compute() {
        if (n <= THRESHOLD) {
            return factorial(n);
        }
        int mid = n / 2;
        ParallelFactorial left = new ParallelFactorial(mid);
        ParallelFactorial right = new ParallelFactorial(n - mid);
        left.fork();
        int rightResult = right.compute();
        int leftResult = left.join();
        return leftResult * rightResult;
    }

    private int factorial(int n) {
        if (n <= 1) {
            return 1;
        }
        return n * factorial(n - 1);
    }

    public static void main(String[] args) {
        ForkJoinPool pool = new ForkJoinPool();
        System.out.println(pool.invoke(new ParallelFactorial(10)));  // 输出：3628800
    }
}
```
