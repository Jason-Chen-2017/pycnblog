#### 二、LaTeX公式嵌入

1. **行内公式**：使用 `$` 和 `$$` 标记
    ```markdown
    这是一个行内公式：$E=mc^2$。
    这是一个更复杂的行内公式：$$\frac{d^2}{dx^2}(x^n) = n(n-1)x^{n-2}$$。
    ```

2. **独立段落公式**：使用 `$$` 标记
    ```markdown
    $$
    E=mc^2
    $$

    $$
    \sum_{i=1}^{n} i = \frac{n(n+1)}{2}
    $$
    ```

#### 三、伪代码嵌入

伪代码可以用来描述算法的流程，它比实际代码更易于理解和解释。在markdown中，可以使用特定的标记来书写伪代码。

```markdown
# 搜索算法伪代码

```
function binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
            
    return -1
```

```
# 算法描述

上述伪代码描述了一个二分搜索算法，用于在一个有序数组中查找目标值。算法的核心思想是通过不断缩小搜索范围，直到找到目标值或确定目标值不存在。
```
