### 3. 核心算法原理讲解

在地质勘探中，常用的机器学习算法包括线性回归、逻辑回归、支持向量机、神经网络等。下面将介绍这些算法的基本原理，并使用伪代码进行详细阐述。

#### 3.1 线性回归

线性回归是一种最简单的监督学习算法，用于建立输入变量和输出变量之间的线性关系。线性回归模型的数学表达式为：

$$ y = w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + ... + w_n \cdot x_n $$

其中，$y$ 为输出变量，$x_1, x_2, ..., x_n$ 为输入变量，$w_0, w_1, w_2, ..., w_n$ 为权重参数。

线性回归的伪代码如下：

```plaintext
// 线性回归伪代码
function linear_regression(X, y):
    # X: 特征矩阵，y: 标签向量
    # 找到最佳拟合直线：y = w0 + w1*x1 + w2*x2 + ... + wn*xn

    # 初始化权重
    w = [0] * n_features

    # 梯度下降法优化权重
    for i in range(num_iterations):
        # 计算预测值
        y_pred = X * w

        # 计算损失函数（均方误差）
        loss = (y - y_pred).dot(y - y_pred)

        # 计算梯度
        gradient = -2 * (X.T * (y - y_pred))

        # 更新权重
        w -= learning_rate * gradient

    return w
```

#### 3.2 逻辑回归

逻辑回归是一种用于分类问题的监督学习算法，它通过建立输入变量和输出变量之间的逻辑关系来预测类别。逻辑回归的数学表达式为：

$$ P(y=1) = \frac{1}{1 + e^{-(w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + ... + w_n \cdot x_n)}} $$

其中，$P(y=1)$ 为输出变量为1的概率，$e$ 为自然对数的底数。

逻辑回归的伪代码如下：

```plaintext
// 逻辑回归伪代码
function logistic_regression(X, y):
    # X: 特征矩阵，y: 标签向量
    # 找到最佳拟合直线：y = 1 / (1 + e^{-(w0 + w1*x1 + w2*x2 + ... + wn*xn)}

    # 初始化权重
    w = [0] * n_features

    # 梯度下降法优化权重
    for i in range(num_iterations):
        # 计算预测概率
        y_pred_prob = 1 / (1 + exp(-X * w))

        # 计算损失函数（交叉熵损失）
        loss = -y * log(y_pred_prob) - (1 - y) * log(1 - y_pred_prob)

        # 计算梯度
        gradient = X.T * (y_pred_prob - y)

        # 更新权重
        w -= learning_rate * gradient

    return w
```

#### 3.3 支持向量机

支持向量机（SVM）是一种强大的分类算法，它通过寻找一个最佳的超平面来将不同类别的样本分开。SVM的数学模型为：

$$ \max_{w, b} \frac{1}{2} ||w||^2 $$
$$ \text{subject to} \ \ y_i ( \langle w, x_i \rangle + b ) \geq 1 $$

其中，$w$ 为权重向量，$b$ 为偏置项，$x_i$ 为样本特征，$y_i$ 为样本标签。

SVM的伪代码如下：

```plaintext
// 支持向量机伪代码
function svm_train(X, y):
    # X: 特征矩阵，y: 标签向量
    # 训练SVM模型

    # 初始化权重和偏置
    w = [0] * n_features
    b = 0

    # 使用拉格朗日乘子法优化权重和偏置
    for i in range(num_iterations):
        # 计算损失函数和梯度
        loss = 0
        gradient_w = [0] * n_features
        gradient_b = 0

        for j in range(n_samples):
            # 计算预测值
            y_pred = dot(w, X[j]) + b

            # 计算损失函数
            loss += (y[j] - y_pred) * y[j]

            # 计算梯度
            gradient_w += (y[j] - y_pred) * y[j] * X[j]
            gradient_b += (y[j] - y_pred) * y[j]

        # 更新权重和偏置
        w -= learning_rate * gradient_w
        b -= learning_rate * gradient_b

    return w, b
```

#### 3.4 神经网络

神经网络是一种基于生物神经网络原理设计的机器学习算法，它可以模拟人脑的神经元结构和信息处理方式。一个简单的神经网络包含输入层、隐藏层和输出层，每层由多个神经元组成。神经网络的数学模型为：

$$ a_i^{(l)} = \sigma( \langle w^{(l)}, x^{(l-1)} \rangle + b^{(l)} ) $$

其中，$a_i^{(l)}$ 为第$l$层的第$i$个神经元的激活值，$\sigma$ 为激活函数，$w^{(l)}$ 和 $b^{(l)}$ 分别为第$l$层的权重和偏置。

神经网络的伪代码如下：

```plaintext
// 神经网络伪代码
function neural_network_train(X, y, layers_sizes, learning_rate, num_iterations):
    # X: 特征矩阵，y: 标签向量
    # layers_sizes: 网络层大小列表
    # learning_rate: 学习率
    # num_iterations: 迭代次数

    # 初始化权重和偏置
    W = [random_matrix(layers_sizes[l], layers_sizes[l-1]) for l in range(1, len(layers_sizes))]
    b = [random_matrix(layers_sizes[l], 1) for l in range(1, len(layers_sizes))]

    # 梯度下降法优化权重和偏置
    for i in range(num_iterations):
        # 前向传播
        a = [X]
        for l in range(1, len(layers_sizes)):
            z = dot(W[l-1], a[l-1]) + b[l-1]
            a.append.sigmoid(z)

        # 反向传播
        dL_dz = a[-1] - y
        dL_dz = dL_dz / n_samples

        for l in range(len(layers_sizes)-2, 0, -1):
            dL_dz = dot(W[l].T, dL_dz) * sigmoid_derivative(a[l])

            dL_dz += learning_rate * dL_dz

            # 更新权重和偏置
            W[l] -= learning_rate * dL_dz * a[l-1]
            b[l] -= learning_rate * dL_dz

    return W, b
```

### 4. 数学模型和数学公式

在地质勘探中，机器学习算法的应用涉及到许多数学模型和公式。以下是一些常见的数学模型和公式的详细解释和例子。

#### 4.1 均方误差（Mean Squared Error, MSE）

均方误差是衡量模型预测值与真实值之间差异的一种常用指标。其计算公式为：

$$ MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$

其中，$y_i$ 为真实值，$\hat{y}_i$ 为预测值，$n$ 为样本数量。

例子：假设我们有3个样本，真实值为 $[1, 2, 3]$，预测值为 $[\hat{1}, \hat{2}, \hat{3}]$，则均方误差为：

$$ MSE = \frac{1}{3} [(1 - \hat{1})^2 + (2 - \hat{2})^2 + (3 - \hat{3})^2] $$

#### 4.2 交叉熵（Cross-Entropy）

交叉熵是衡量模型预测概率分布与真实概率分布之间差异的一种指标。其计算公式为：

$$ H(y, \hat{y}) = -\sum_{i=1}^{n} y_i \cdot \log(\hat{y}_i) $$

其中，$y$ 为真实概率分布，$\hat{y}$ 为预测概率分布，$n$ 为样本数量。

例子：假设我们有3个样本，真实概率分布为 $[0.2, 0.5, 0.3]$，预测概率分布为 $[\hat{y}_1, \hat{y}_2, \hat{y}_3]$，则交叉熵为：

$$ H(y, \hat{y}) = -[0.2 \cdot \log(\hat{y}_1) + 0.5 \cdot \log(\hat{y}_2) + 0.3 \cdot \log(\hat{y}_3)] $$

#### 4.3 激活函数（Activation Function）

激活函数是神经网络中的一个关键组成部分，用于引入非线性因素。常见的激活函数有：

1. **sigmoid函数**：

$$ \sigma(x) = \frac{1}{1 + e^{-x}} $$

例子：计算 $sigmoid(2)$ 的值：

$$ \sigma(2) = \frac{1}{1 + e^{-2}} \approx 0.88139 $$

2. **ReLU函数**：

$$ \text{ReLU}(x) = \max(0, x) $$

例子：计算 $\text{ReLU}(-2)$ 和 $\text{ReLU}(2)$ 的值：

$$ \text{ReLU}(-2) = 0 $$
$$ \text{ReLU}(2) = 2 $$

3. **Tanh函数**：

$$ \text{tanh}(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} $$

例子：计算 $\text{tanh}(2)$ 的值：

$$ \text{tanh}(2) \approx 0.96497 $$

#### 4.4 梯度下降（Gradient Descent）

梯度下降是一种常用的优化算法，用于最小化损失函数。其基本思想是通过计算损失函数关于每个参数的梯度，然后沿着梯度方向更新参数。

梯度下降的基本公式为：

$$ \theta = \theta - \alpha \cdot \nabla_{\theta} J(\theta) $$

其中，$\theta$ 为参数，$\alpha$ 为学习率，$J(\theta)$ 为损失函数。

例子：假设损失函数为 $J(\theta) = (\theta - 1)^2$，学习率为 $\alpha = 0.1$，则梯度下降的迭代过程为：

$$ \theta_0 = 0 $$
$$ \theta_1 = \theta_0 - 0.1 \cdot \nabla_{\theta} J(\theta_0) = 0 - 0.1 \cdot (-2) = 0.2 $$
$$ \theta_2 = \theta_1 - 0.1 \cdot \nabla_{\theta} J(\theta_1) = 0.2 - 0.1 \cdot (-2 \cdot 0.2) = 0.4 $$
$$ ... $$

通过多次迭代，$\theta$ 将逐渐接近最优值。

def linear_regression(X, y, num_iterations, learning_rate):
    n_samples, n_features = X.shape
    w = np.zeros(n_features)

    for i in range(num_iterations):
        y_pred = X.dot(w)
        loss = np.mean((y - y_pred)**2)

        w -= learning_rate * gradient

2. `predict` 函数：实现线性回归模型的预测过程。输入参数为特征矩阵 $X$ 和权重向量 $w$，返回预测值。
