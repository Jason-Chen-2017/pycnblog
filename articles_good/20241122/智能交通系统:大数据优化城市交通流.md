**数学模型和公式：**

K-Means聚类和层次聚类的基本数学模型如下：

1. **K-Means聚类：**

   $$ 
   \begin{aligned}
   \text{Minimize} \quad & \sum_{i=1}^{k} \sum_{x_j \in S_i} ||x_j - \mu_i||^2 \\
   \text{Subject to} \quad & \mu_i = \frac{1}{|S_i|} \sum_{x_j \in S_i} x_j
   \end{aligned}
   $$

   其中，$S_i$表示第$i$个聚类，$\mu_i$表示第$i$个聚类中心。

2. **层次聚类：**

   \begin{aligned}
   \text{Minimize} \quad & \sum_{i=1}^{k} \sum_{j=1}^{n} ||x_j - c_i||^2 \\
   \text{Subject to} \quad & c_i = \frac{1}{|S_i|} \sum_{x_j \in S_i} x_j
   \end{aligned}
   $$

   其中，$S_i$表示第$i$个聚类，$c_i$表示第$i$个聚类中心。

    # 数据预处理
    processed_data = preprocess_data(data)
    
    # 初始化聚类中心
    centroids = initialize_centroids(processed_data, k)
    
    # 迭代计算
    for _ in range(max_iterations):
        # 计算每个数据点所属的聚类
        clusters = assign_data_to_clusters(processed_data, centroids)
        
        # 更新聚类中心
        centroids = update_centroids(processed_data, clusters)
        
    return centroids, clusters

def preprocess_data(data):
    # 数据预处理
    processed_data = np.array(data)
    return processed_data

def initialize_centroids(data, k):
    # 初始化聚类中心
    centroids = data[np.random.choice(data.shape[0], k, replace=False)]
    return centroids

def assign_data_to_clusters(data, centroids):
    # 计算每个数据点所属的聚类
    distances = calculate_distances(data, centroids)
    clusters = np.argmin(distances, axis=1)
    return clusters

def update_centroids(data, clusters):
    # 更新聚类中心
    new_centroids = np.array([data[clusters == i].mean(axis=0) for i in range(len(clusters))])
    return new_centroids

def calculate_distances(data, centroids):
    # 计算每个数据点到聚类中心的距离
    distances = np.linalg.norm(data - centroids, axis=1)
    return distances

    clusters = initialize_clusters(processed_data)
    
    # 迭代合并或分割聚类
    for _ in range(max_iterations):
        # 合并或分割聚类
        clusters = merge_or_split_clusters(clusters)
        
    return clusters
```

**数学模型和公式：**

K-Means聚类和层次聚类的基本数学模型如下：

1. **K-Means聚类：**

   $$ 
   \begin{aligned}
   \text{Minimize} \quad & \sum_{i=1}^{k} \sum_{x_j \in S_i} ||x_j - \mu_i||^2 \\
   \text{Subject to} \quad & \mu_i = \frac{1}{|S_i|} \sum_{x_j \in S_i} x_j
   \end{aligned}
   $$

   其中，$S_i$表示第$i$个聚类，$\mu_i$表示第$i$个聚类中心。

2. **层次聚类：**

   $$ 
   \begin{aligned}
   \text{Minimize} \quad & \sum_{i=1}^{k} \sum_{j=1}^{n} ||x_j - c_i||^2 \\
   \text{Subject to} \quad & c_i = \frac{1}{|S_i|} \sum_{x_j \in S_i} x_j
   \end{aligned}
   $$

   其中，$S_i$表示第$i$个聚类，$c_i$表示第$i$个聚类中心。

import numpy as np

def k_means_clustering(data, k, max_iterations):
    # 数据预处理
    processed_data = preprocess_data(data)
    
    # 初始化聚类中心
    centroids = initialize_centroids(processed_data, k)
    
    # 迭代计算
    for _ in range(max_iterations):
        # 计算每个数据点所属的聚类
        clusters = assign_data_to_clusters(processed_data, centroids)
        
        # 更新聚类中心
        centroids = update_centroids(processed_data, clusters)
        
    return centroids, clusters

def preprocess_data(data):
    # 数据预处理
    processed_data = np.array(data)
    return processed_data

def initialize_centroids(data, k):
    # 初始化聚类中心
    centroids = data[np.random.choice(data.shape[0], k, replace=False)]
    return centroids

def assign_data_to_clusters(data, centroids):
    # 计算每个数据点所属的聚类
    distances = calculate_distances(data, centroids)
    clusters = np.argmin(distances, axis=1)
    return clusters

def update_centroids(data, clusters):
    # 更新聚类中心
    new_centroids = np.array([data[clusters == i].mean(axis=0) for i in range(len(clusters))])
    return new_centroids

def calculate_distances(data, centroids):
    # 计算每个数据点到聚类中心的距离
    distances = np.linalg.norm(data - centroids, axis=1)
    return distances
