#### 3.1 决策树（Decision Tree）

**核心概念**：决策树是一种基于树形结构，通过一系列规则对数据进行分类或回归的算法。每个内部节点表示一个特征，每个分支表示该特征的不同取值，每个叶子节点代表一个类别或预测值。

**工作原理**：决策树通过递归分割数据集，选择具有最高信息增益的特征进行分割，直至满足停止条件（如达到最大深度或最小叶节点样本数）。

**伪代码**：
```plaintext
function DecisionTree(data, features, labels, max_depth):

        return leaf_node_value(data, labels)
    else:
        best_feature, best_value = find_best_split(data, features, labels)
        left_child = DecisionTree(split_left(data, best_feature, best_value), features, labels, max_depth - 1)
        right_child = DecisionTree(split_right(data, best_feature, best_value), features, labels, max_depth - 1)
        return TreeNode(best_feature, best_value, left_child, right_child)
```

**数学模型**：
信息增益（Information Gain）：
$$
IG(D, A) = Entropy(D) - \sum_{v \in Values(A)} \frac{|D[A = v]|}{|D|} \cdot Entropy(D[A = v])
$$
其中，\( D \) 是数据集，\( A \) 是特征，\( v \) 是特征的取值，\( Entropy \) 是熵函数。

**案例**：利用决策树对电子废弃物进行分类，根据不同的特征（如重量、尺寸、材质）将废弃物分成可回收和不可回收两类。

**工作原理**：随机森林在构建每棵决策树时，随机选择特征子集和样本子集，以避免过拟合。
