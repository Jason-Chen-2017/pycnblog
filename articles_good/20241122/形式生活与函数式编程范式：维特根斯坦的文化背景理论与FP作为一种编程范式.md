#### FP的基本概念与核心原理

函数式编程（Functional Programming，简称FP）是一种编程范式，其核心理念是使用纯函数式计算来处理数据和问题。FP与传统命令式编程范式相比，具有许多独特的优势，如更易测试、更易理解、更易并行化等。在本节中，我们将详细探讨FP的基本概念和核心原理。

##### 函数与高阶函数

在FP中，函数是最基本的构建块。函数是一种将输入映射到输出的过程，它具有以下几个特点：

1. **纯函数**：纯函数是一种没有副作用（side effects）的函数，即函数的输出仅取决于输入，不会修改外部状态或产生可观察的效果。例如，求两个数的和是一个纯函数，它的输出仅取决于输入的两个数，不会影响其他变量或函数。

2. **确定性**：纯函数在相同的输入下总是产生相同的输出，不会产生不确定的结果。这意味着我们可以安全地缓存纯函数的输出，以减少计算时间。

3. **可复用性**：由于纯函数没有副作用，我们可以轻松地将它们组合和复用，以构建更复杂的函数。

高阶函数（Higher-order functions）是FP中的一个重要概念，它们能够接受函数作为参数，或者返回函数。高阶函数允许我们将函数作为数据来处理，从而实现更灵活和强大的编程。

下面是一个使用Python实现的高阶函数示例：

```python
# 计算两个数的和
def add(a, b):
    return a + b

# 计算两个数的乘积
def multiply(a, b):
    return a * b

# 使用高阶函数实现计算
def apply_operator(a, b, operator):
    return operator(a, b)

# 调用高阶函数
result = apply_operator(3, 4, add)
print(result)  # 输出 7
```

在这个示例中，`apply_operator` 函数接受一个操作符（如加法或乘法）作为参数，并使用这个操作符计算两个数的和或乘积。通过这种方式，我们可以灵活地选择不同的操作符，而无需修改函数的核心逻辑。

##### 惰性求值与不可变性

惰性求值（Lazy Evaluation）是FP中的一个重要概念，它与命令式编程中的即时求值（Eager Evaluation）相对。在惰性求值中，函数的返回值仅在需要时才计算，而不是在定义时立即计算。这种求值方式可以减少不必要的计算，提高程序的效率。

不可变性（Immutability）是FP的另一个核心原理，它要求数据一旦创建，就不能被修改。相反，我们通过创建新的数据来修改状态。这种设计思想有助于减少副作用，提高代码的可读性和可维护性。

在FP中，不可变性可以通过以下几种方式实现：

1. **不可变数据结构**：使用不可变数据结构（如常量数组、不可变列表和映射）来存储数据。这些数据结构在创建后不能被修改，只能通过创建新实例来更新状态。

2. **纯函数**：通过纯函数来处理数据，确保不会修改外部状态。这种设计思想使得代码更加模块化和可复用。

3. **引用透明性**：引用透明性是指函数的输出可以由其输入确定，即函数的返回值不会依赖于外部状态或随机过程。这使得函数可以安全地缓存和重用，从而提高程序的效率和可靠性。

下面是一个使用Python实现的惰性求值和不可变性示例：

```python
# 惰性求值示例
def lazy_sum(numbers):
    total = 0
    for number in numbers:
        total += number
    return total

# 不可变性示例
def append_element(element, list_):
    return list_ + [element]

# 使用惰性求值和不可变性
result = lazy_sum([1, 2, 3, 4])
print(result)  # 输出 10

new_list = append_element(5, [1, 2, 3])
print(new_list)  # 输出 [1, 2, 3, 5]
```

在这个示例中，`lazy_sum` 函数通过惰性求值来计算列表中元素的总和，而 `append_element` 函数通过不可变性来扩展列表。

##### 函数组合与模块化

函数组合（Function Composition）是FP中的一个重要技巧，它允许我们将多个函数组合成一个更复杂的函数。通过函数组合，我们可以将简单的问题分解为更小的、易于管理的函数，从而提高代码的可读性和可维护性。

模块化（Modularity）是FP的另一个核心原理，它强调将程序分解为小的、功能明确的模块。每个模块可以独立开发、测试和部署，从而提高程序的灵活性和可维护性。

下面是一个使用Python实现的函数组合和模块化示例：

```python
# 函数组合示例
def square(x):
    return x * x

def add(x, y):
    return x + y

def compose(f, g):
    return lambda x: f(g(x))

# 模块化示例
def module_a(x):
    return x + 1

def module_b(x):
    return x * 2

# 使用函数组合和模块化
result = compose(module_a, module_b)(3)
print(result)  # 输出 8
```

在这个示例中，`compose` 函数通过组合 `module_a` 和 `module_b` 模块来计算结果，从而实现了模块化和函数组合。

```python
import functools
import itertools
import numpy as np

# 定义纯函数：计算阶乘
def factorial(n):
    return 1 if n == 0 else n * factorial(n - 1)

# 定义纯函数：判断素数
def is_prime(num):
    if num < 2:
        return False
    for i in range(2, int(np.sqrt(num)) + 1):
        if num % i == 0:
            return False
    return True

# 定义纯函数：素数分解
def prime_decomposition(num):
    primes = []
    for i in range(2, num + 1):
        if is_prime(i):
            while num % i == 0:
                primes.append(i)
                num //= i
    return primes

# 使用函数组合：计算数字的阶乘和素数分解
def compute(n):
    fact = factorial(n)
    primes = prime_decomposition(n)
    return fact, primes

# 主程序
if __name__ == "__main__":
    n = int(input("Enter a number: "))
    result = compute(n)
    print(f"Factorial: {result[0]}")
    print(f"Prime decomposition: {result[1]}")
```
