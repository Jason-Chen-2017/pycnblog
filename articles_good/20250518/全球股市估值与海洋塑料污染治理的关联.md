## 1.1 背景介绍

### 1.1.1 全球股市估值的现状
全球股市估值是衡量经济发展的重要指标，反映了市场的整体健康状况。近年来，随着经济全球化和金融化的深入，股市在资源配置和风险定价中的作用日益凸显。然而，股市的波动性也为全球经济带来了不确定性。

### 1.1.2 海洋塑料污染的严重性
海洋塑料污染已成为全球性环境问题。每年，大量塑料垃圾通过河流进入海洋，不仅破坏生态平衡，还对人类健康和经济活动造成威胁。海洋塑料污染的治理需要技术创新和政策支持。

## 3.4 代码实现
```python
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载与清洗
data = pd.read_csv('data.csv')
data = data.dropna()

# 特征提取
X = data[['pollution']]
y = data['market_valuation']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 模型评估
y_pred = model.predict(X)
r2 = r2_score(y, y_pred)
print(f'R² = {r2}')
```
