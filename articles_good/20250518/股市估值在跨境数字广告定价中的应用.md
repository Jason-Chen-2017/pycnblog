  - 现金流折现模型（DCF）：基于未来现金流的现值
- 1.1.3 股市估值的边界与外延

### 第二部分：核心概念与联系

#### 第2章：核心概念原理

##### 2.1 股市估值的原理
- 2.1.1 市盈率（P/E）模型
  - 股价 = 市盈率 × 每股收益
  - 示例：某公司每股收益为1元，市盈率为15，则股价为15元
- 2.1.2 市净率（P/B）模型
  - 股价 = 市净率 × 每股净资产
  - 示例：某公司每股净资产为2元，市净率为3，则股价为6元
- 2.1.3 现金流折现模型（DCF）
  - 通过预测未来现金流，折现计算当前价值
  - 示例：假设未来5年现金流分别为100、120、140、160、180万元，贴现率5%，计算其现值

##### 2.2 数字广告定价的原理
- 2.2.1 广告价值的评估
  - 广告价值 = 广告点击率 × 转化率 × 广告单价
- 2.2.2 广告效果的衡量
  - 点击率（CTR）= 广告点击次数/广告展示次数
  - 转化率（CR）= 点击广告的用户数/广告展示次数
- 2.2.3 广告定价的动态调整
  - 根据实时数据和市场反馈调整广告价格

##### 2.3 核心概念对比表格
| 核心概念 | 股市估值 | 数字广告定价 |
|----------|----------|-------------|
| 主体     | 上市公司 | 广告产品     |
| 价值基   | 盈利能力、资产状况 | 广告效果、用户行为 |
| 定价因   | 市盈率、市净率 | 点击率、转化率、目标受众 |

##### 3.3 Python实现
```python
def calculate_ad_value(clicks, conversions, industry_avg_clicks, industry_avg_conversions):
    # 计算广告价值
    ad_value = clicks * conversions
    # 计算行业平均价值
    industry_avg = industry_avg_clicks * industry_avg_conversions
    # 计算市盈率和市净率
    pe_ratio = ad_value / industry_avg
    return pe_ratio

# 示例数据
clicks = 1000
conversions = 200
industry_avg_clicks = 800
industry_avg_conversions = 150

pe_ratio = calculate_ad_value(clicks, conversions, industry_avg_clicks, industry_avg_conversions)
print(f"市盈率：{pe_ratio}")
```

##### 3.4 数学模型与公式
- 广告价值公式：
  $$ \text{广告价值} = \text{点击率} \times \text{转化率} \times \text{广告单价} $$
- 市盈率公式：
  $$ \text{市盈率} = \frac{\text{广告价值}}{\text{行业平均价值}} $$

import pandas as pd
import numpy as np

def calculate_price(clicks, conversions, industry_avg_clicks, industry_avg_conversions):
    ad_value = clicks * conversions
    industry_avg = industry_avg_clicks * industry_avg_conversions
    pe_ratio = ad_value / industry_avg
    return pe_ratio * industry_avg_clicks * industry_avg_conversions

# 示例数据
data = {
    '广告ID': [1, 2, 3],
    '点击率': [0.5, 0.4, 0.6],
    '转化率': [0.1, 0.08, 0.12],
    '行业平均点击率': [0.3, 0.3, 0.3],
    '行业平均转化率': [0.05, 0.05, 0.05]
}

df = pd.DataFrame(data)
df['广告价格'] = df.apply(lambda x: calculate_price(x['点击率'], x['转化率'], x['行业平均点击率'], x['行业平均转化率']), axis=1)
print(df)
