#### 3.2 算法实现
- Python代码示例
```python
import numpy as np

# 定义目标函数
def objective(x):
    return np.sum(x)

# 约束条件
def constraint(x):
    return np.sum(x) <= 100

# 使用 scipy 求解线性规划问题
from scipy.optimize import minimize

# 初始猜测值
x0 = np.array([0, 0, 0])

# 定义问题
problem = {
    'fun': objective,
    'cons': {'type': 'ineq', 'fun': constraint},
    'bounds': [(0, None), (0, None), (0, None)]
}

# 求解
result = minimize(objective, x0, method='SLSQP', constraints=problem['cons'], bounds=problem['bounds'])
print(result.x)
```

#### 3.3 数学模型
- 线性规划模型
$$ \text{minimize} \quad \sum_{i=1}^{n} c_i x_i $$
$$ \text{subject to} \quad \sum_{i=1}^{n} a_i x_i \leq b $$
$$ x_i \geq 0 $$
