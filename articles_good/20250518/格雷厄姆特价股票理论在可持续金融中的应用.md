# 第1章 格雷厄姆特价股票理论与可持续金融概述

## 1.1 格雷厄姆投资理论概述

### 1.1.1 价值投资的核心理念
价值投资是基于对公司内在价值的评估，寻找市场价格低于内在价值的股票。格雷厄姆提出的“安全边际”概念，强调在价格显著低于价值时买入。

### 1.1.2 格雷厄姆的选股标准
格雷厄姆提出了一系列选股标准，包括：
- 低市盈率（P/E < 15）
- 低市净率（P/B < 1.5）
- 高股息率
- 财务状况稳健（如低债务/股权比率）

### 1.1.3 特价股票的定义与特征
特价股票是指市场价格显著低于内在价值的股票，通常具有较高的安全边际，适合长期投资。

### 核心概念对比表
| 标准       | 格雷厄姆选股标准 | ESG评分标准 |
|------------|------------------|-------------|
| 市盈率     | <15              | -           |
| 市净率     | <1.5             | -           |
| ESG评分    | -                | A以上        |

## 1.2 可持续金融的基本概念

### 1.2.1 可持续金融的定义
可持续金融是指将环境、社会和公司治理（ESG）因素纳入投资决策，以实现长期价值创造和可持续发展的金融活动。

### 1.2.2 ESG投资的核心要素
ESG分别代表：
- **E**环境因素：关注公司在环境保护方面的表现。
- **S**社会因素：关注公司在社会责任方面的表现。
- **G**治理因素：关注公司治理结构和透明度。

### 1.2.3 可持续金融的发展历程
可持续金融从早期的伦理投资逐步演变为今天的ESG投资，成为全球投资的重要组成部分。

## 1.3 格雷厄姆理论与可持续金融的结合点

### 1.3.1 价值投资与可持续发展的契合
价值投资注重长期持有和基本面分析，与可持续金融的长期视角一致。

### 1.3.2 特价股票筛选中的ESG因素
在筛选特价股票时，加入ESG评分作为筛选条件，确保选出的股票不仅价格低估，还具有良好的社会和环境表现。

### 1.3.3 可持续金融对投资策略的影响
ESG因素的引入可以降低投资组合的系统性风险，提升长期回报。

## 1.4 本章小结
本章介绍了格雷厄姆投资理论和可持续金融的基本概念，并分析了两者的结合点。通过结合ESG因素，价值投资者可以在筛选特价股票时，进一步优化投资组合的长期表现。

# 第2章 格雷厄姆特价股票筛选模型

## 2.1 格雷厄姆筛选模型的核心算法

### 2.1.1 市盈率（P/E）计算公式
$$市盈率 = \frac{股票价格}{每股收益}$$

### 2.1.2 市净率（P/B）计算公式
$$市净率 = \frac{股票价格}{每股净资产}$$

### 2.1.3 股票内在价值计算公式
$$内在价值 = \frac{预期股息}{折现率}$$

### 2.1.4 基于ESG的筛选模型
$$ESG评分权重 = 0.3 \times E + 0.3 \times S + 0.4 \times G$$

### Mermaid图：格雷厄姆筛选模型流程图
```mermaid

A[数据获取] --> B[计算市盈率、市净率] --> C[计算内在价值]
C --> D[计算ESG评分] --> E[筛选符合标准的股票]
```

## 2.2 算法实现与案例分析

### 2.2.1 数据获取与预处理
使用Python的`pandas`和`yfinance`库获取标普500指数成分股的财务数据和ESG评分。

### 2.2.2 算法实现步骤
1. 计算市盈率和市净率。
2. 计算ESG评分。
3. 筛选出市盈率<15，市净率<1.5，ESG评分>80的股票。

### 2.2.3 案例分析
以下代码示例展示了如何筛选符合条件的股票：

```python
import pandas as pd
import yfinance as yf

# 获取数据
data = yf.download(tickers='^GSPC', start='2020-01-01', end='2023-12-31')

# 计算市盈率和市净率
data['PE'] = data['Close'] / data['EPS']
data['PB'] = data['Close'] / data['Book Value']

# 计算ESG评分（假设ESG评分已获取）
data['ESG'] = [85, 78, 92, ...]  # 示例数据

# 筛选条件
mask = (data['PE'] < 15) & (data['PB'] < 1.5) & (data['ESG'] > 80)
selected_stocks = data[mask]
```

### 2.2.4 结果解读
通过上述筛选，选出的股票既符合格雷厄姆的选股标准，又具有较高的ESG评分，适合长期投资。

## 2.3 本章小结
本章详细介绍了格雷厄姆筛选模型的核心算法，并结合ESG评分进行优化，通过案例分析验证了模型的有效性。
