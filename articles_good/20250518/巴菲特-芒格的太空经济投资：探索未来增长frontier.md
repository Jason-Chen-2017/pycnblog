  - 7.2.2 投资组合优化的代码实现
  ```python
  import numpy as np

  def portfolioOptimization(weights, returns, covariance):
      # 使用均值方差优化模型
      n = len(weights)
      return np.dot(returns, weights) / np.dot(weights.T, covariance @ weights)
      
  weights = [0.3, 0.4, 0.3]
  returns = [0.1, 0.2, 0.15]
  covariance = np.array([[0.05, 0.02, 0.03],
                         [0.02, 0.1, 0.04],
                         [0.03, 0.04, 0.15]])

  optimal_return = portfolioOptimization(weights, returns, covariance)
  print(f"Optimal Return: {optimal_return}")
  ```
