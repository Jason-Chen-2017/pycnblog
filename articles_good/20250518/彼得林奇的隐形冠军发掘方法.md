## 第1章：彼得·林奇与“隐形冠军”概述

### 1.1 彼得·林奇的投资理念

#### 1.1.1 彼得·林奇的生平与投资成就

彼得·林奇是全球知名的投资专家，以其在共同基金领域的卓越表现闻名。他在富达投资管理公司管理麦哲伦基金期间，取得了年均22.5%的复合收益率，为投资者创造了巨大价值。林奇的投资哲学强调长期价值和深入的企业基本面分析。

#### 1.1.2 “隐形冠军”概念的提出与定义

“隐形冠军”指的是那些在特定细分市场中占据领先地位，但知名度较低的公司。这些企业专注于狭窄的领域，具有强大的竞争优势和持续的盈利能力。

#### 1.1.3 “隐形冠军”与传统投资方法的区别

与传统的投资方法相比，“隐形冠军”策略更注重企业的独特性和市场专注性，而非单纯的市场规模或行业地位。

### 5.2 核心代码实现

#### 5.2.1 数据处理代码

```python
import pandas as pd

# 加载数据
df = pd.read_csv('enterprises.csv')

# 筛选隐形冠军
df = df[df['market_cap'] < 1000000000]

# 计算财务指标
df['pe_ratio'] = df['price'] / df['eps']
df['pb_ratio'] = df['price'] / df['book_value']
```
