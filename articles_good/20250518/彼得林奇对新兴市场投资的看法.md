#### 代码示例：计算市盈率

```python
import pandas as pd

# 假设有一个包含股票数据的 DataFrame
data = {'公司': ['公司A', '公司B', '公司C'],
        '股价': [50, 60, 70],
        '每股收益': [5, 6, 7]
       }
df = pd.DataFrame(data)

# 计算市盈率
df['市盈率'] = df['股价'] / df['每股收益']

print(df)
```

---

### **公式与数学模型**

#### 公式1：市盈率计算

$$ \text{市盈率} = \frac{\text{股价}}{\text{每股收益}} $$

#### 公式2：净资产收益率（ROE）

$$ \text{ROE} = \frac{\text{净利润}}{\text{净资产}} $$
