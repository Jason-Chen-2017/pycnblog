### 1.2.2 集成电路的基本概念与发展历程
- 集成电路的定义：将多个电子元件集成在单一芯片上的技术。
- 集成电路的发展历程：从分立元件到大规模集成电路（LSI）、超大规模集成电路（VLSI）。
- 光子集成电路与电子集成电路的区别：信号形式不同（光信号 vs 电信号）。

### 1.2.3 光子集成电路的优势与挑战
- 优势：高速、低能耗、抗电磁干扰。
- 挑战：制造工艺复杂、成本高、技术门槛高。

import numpy as np

def generate_light_signal(frequency, duration):
    t = np.linspace(0, duration, 1000)
    signal = np.sin(2 * np.pi * frequency * t)
    return signal

def intensity_modulation(signal, modulation_index):
    modulated_signal = signal * (1 + modulation_index * np.sin(2 * np.pi * 0.1 * t))
    return modulated_signal

def demodulation(modulated_signal):
    integrated_signal = np.cumsum(modulated_signal)
    return integrated_signal

# 示例代码
frequency = 1000
duration = 1
modulation_index = 0.5

signal = generate_light_signal(frequency, duration)
modulated_signal = intensity_modulation(signal, modulation_index)
demodulated_signal = demodulation(modulated_signal)

print("调制信号：", modulated_signal)
print("解调信号：", demodulated_signal)
