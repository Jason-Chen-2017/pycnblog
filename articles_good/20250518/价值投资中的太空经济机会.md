# 第1章: 太空经济的定义与现状

## 1.1 太空经济的定义与范围

### 1.1.1 太空经济的定义

太空经济（Space Economy）是指围绕地球大气层以外的宇宙空间所进行的所有经济活动的总和，涵盖卫星通信、太空资源开发、太空旅游等多个领域。太空经济的核心在于将太空资源和技术应用于商业目的，从而创造经济价值。

**太空经济的领域分布图**（Mermaid图）：

```mermaid
graph TD
    A[卫星通信] --> B[太空资源开发]
    B --> C[太空旅游]
    A --> D[太空制造]
    D --> E[太空探索]
```

### 1.1.2 太空经济的核心领域

太空经济的核心领域包括：

1. **卫星通信**：利用卫星提供全球通信服务，覆盖偏远地区。
2. **太空资源开发**：包括小行星采矿、月球和火星资源开发等。
3. **太空旅游**：商业化的太空旅行服务。
4. **太空制造**：在太空中制造材料或产品。
5. **太空探索**：政府和私营企业的联合探索任务。

### 1.1.3 太空经济的全球发展趋势

近年来，太空经济呈现快速增长态势。2022年，全球太空经济规模达到约4600亿美元，预计到2030年将超过1万亿美元。美国、中国、欧洲等地的企业和政府机构在太空经济中扮演重要角色。

## 1.2 价值投资的基本概念

### 1.2.1 价值投资的定义

价值投资是一种投资策略，强调以低于资产内在价值的价格购买优质资产。其核心在于寻找市场低估的公司，长期持有，等待其价值回归。

### 1.2.2 价值投资的核心原则

1. **安全边际**：买入价格低于内在价值。
2. **长期视角**：关注企业的长期盈利能力。
3. **基本面分析**：重视企业的财务状况、行业地位和竞争优势。

### 1.2.3 价值投资在现代金融中的地位

价值投资在金融市场上占据重要地位，尤其在长期投资中表现突出。它强调理性分析和风险控制，适合对市场波动不敏感的投资者。

### 6.2.1 价值投资框架实现

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(fundamentals):
    # 简单的内在价值计算模型
    return fundamentals['Revenue'] * 0.5 + fundamentals['Net Profit'] * 0.3

def value_investment_strategy(stocks):
    selected_stocks = []
    for stock in stocks:
        iv = calculate_intrinsic_value(stock.fundamentals)
        if iv > stock.current_price:
            selected_stocks.append(stock)
    return selected_stocks
```
