# 第3章: 数学模型与公式

## 3.3 随机森林模型
### 3.3.1 随机森林的数学公式
随机森林是一种基于树的集成方法，通过构建多个决策树并进行投票或平均来提高模型的准确性和鲁棒性。其数学公式可以表示为：

$$
\text{预测值} = \sum_{i=1}^{n} \text{决策树}_i(\text{输入特征})
$$

其中，\( n \) 是决策树的数量。

### 3.3.2 随机森林的优化方法
随机森林通过以下方式优化：
1. **袋装法（Bagging）**：通过有放回地抽样训练数据来生成多个训练集。
2. **特征子集选择**：在每个决策树的每个节点分裂时，随机选择部分特征进行分裂，减少相关特征之间的冗余。

### 3.3.3 随机森林的优缺点
- **优点**：高准确率、鲁棒性好、易于处理高维数据。
- **缺点**：计算复杂度高、模型解释性较差。

## 3.4 神经网络模型
### 3.4.1 神经网络的数学公式
神经网络的前向传播过程可以表示为：

$$
y = \sigma(w x + b)
$$

其中，\( y \) 是输出，\( w \) 是权重，\( b \) 是偏置，\( x \) 是输入，\( \sigma \) 是激活函数。

### 3.4.2 神经网络的训练过程
神经网络的训练通常使用反向传播算法（Backpropagation）和梯度下降优化：

1. **前向传播**：计算模型的预测值。
2. **计算损失**：使用损失函数（如均方误差）计算预测值与真实值之间的差异。
3. **反向传播**：通过链式法则计算损失对权重和偏置的梯度。
4. **更新权重**：使用梯度下降方法更新权重和偏置，以最小化损失。

### 3.4.3 神经网络的优缺点
- **优点**：能够处理复杂的非线性关系，模型表达能力强。
- **缺点**：计算复杂度高，需要大量的训练数据，模型解释性较差。

class NeuralNetwork(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(NeuralNetwork, self).__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)

        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x

# 初始化模型
