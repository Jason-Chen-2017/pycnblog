  ```python
  def screen_stocks(df):
      # 筛选市盈率小于行业平均的股票
      df['P/E'] = df['Close'] / df['Earnings per Share']
      selected = df[df['P/E'] < df['P/E'].mean()]
      return selected
  ```
- 9.3 投资组合构建模块
  ```python
  def build_portfolio(selected_stocks, initial_investment):
      portfolio = {}
      allocation = initial_investment / len(selected_stocks)
      for stock in selected_stocks:
          portfolio[stock] = allocation
      return portfolio
  ```
- 9.4 报告生成模块

  ```python
  def generate_report(portfolio, returns):
      # 生成收益报告
      report = {}
      for stock in portfolio:
          report[stock] = returns[stock] * portfolio[stock]
      return report
  ```
