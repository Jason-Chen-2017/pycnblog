# 第1章：全球股市估值与航空航天产业的关联概述

## 1.1 问题背景

### 1.1.1 全球股市估值的定义与重要性
股市估值是衡量市场整体健康状况的关键指标，通常通过指数（如道琼斯指数、纳斯达克指数）或市盈率（P/E比率）来衡量。股市估值反映了投资者对经济前景的信心，同时也受到宏观经济因素的影响。

### 1.1.2 航空航天产业的定义与特点
航空航天产业涵盖民用航空、军用航空和航天技术等领域。该产业具有高技术门槛、高投入和长周期的特点，通常被视为国家工业实力的象征。

### 1.1.3 问题解决：股市估值与产业关联的意义
研究股市估值与航空航天产业的关联，有助于理解宏观经济波动对特定产业的影响，为投资者提供决策依据，同时为政策制定者提供参考。

## 1.2 核心概念

### 1.2.1 股市估值的核心要素
- 市场指数：如标普500、纳斯达克指数。
- 市盈率（P/E比率）：衡量股票价格与每股收益的比例。
- 市净率（P/B比率）：衡量股票价格与每股净资产的比例。

### 1.2.2 航空航天产业的关键指标
- 订单量：如波音和空客的飞机订单。
- 生产量：飞机和航天器的年产量。
- 利润率：企业的盈利能力。

### 1.2.3 两者的边界与外延
- 股市估值是宏观指标，而航空航天产业是具体产业。
- 两者通过经济周期、政策变化和技术进步相互关联。

# 第3章：宏观经济与金融学基础

## 3.1 股票定价模型

### 3.1.1 CAPM 模型
CAPM 模型用于计算资产的期望收益率，公式为：
$$ CAPM = R_f + \beta (R_m - R_f) $$
其中：
- \( R_f \) 是无风险利率。
- \( R_m \) 是市场预期收益率。
- \( \beta \) 是股票的系统性风险系数。

### 3.1.2 实证分析流程
1. 数据收集：收集股票价格、市场指数和宏观经济数据。
2. 计算 beta 系数：通过回归分析确定 beta。
3. 计算期望收益率：使用 CAPM 模型。

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 示例数据
data = {
    'Market_Return': [5, 6, 4, 7, 8],
    'Stock_Return': [4, 5, 3, 6, 7]
}
df = pd.DataFrame(data)

# 计算 beta
model = LinearRegression()
model.fit(df[['Market_Return']], df['Stock_Return'])
beta = model.coef_[0]

# 计算 CAPM 预期收益率
R_f = 0.02  # 无风险利率
R_m = np.mean(df['Market_Return'])  # 市场预期收益率
CAPM_Return = R_f + beta * (R_m - R_f)
print(f"beta 系数为: {beta}")
print(f"CAPM 预期收益率: {CAPM_Return}")
```

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据加载
df = pd.read_csv('data.csv')

# 数据清洗
df.dropna(inplace=True)
df = pd.get_dummies(df)

# 特征选择
X = df[['order', 'production']]
y = df['stock_price']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 模型预测
predictions = model.predict(X)
print("预测值:", predictions)
print("真实值:", y.values)
```
