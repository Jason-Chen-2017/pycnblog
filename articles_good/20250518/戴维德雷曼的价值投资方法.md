# 第1章: 价值投资的背景与核心概念

## 1.1 价值投资的起源与发展

### 1.1.1 投资学的基本概念  
价值投资是一种以基本面分析为基础的投资策略，强调以低于内在价值的价格购买优质资产。其核心在于识别市场中的低估机会，并通过长期持有实现收益。  

### 1.1.2 价值投资的定义与特点  
价值投资的核心理念是寻找市场价格低于内在价值的证券。其特点包括：  
1. **长期视角**：注重长期收益，而非短期波动。  
2. **基本面分析**：基于财务报表和行业分析评估资产价值。  
3. **安全边际**：买入价格与内在价值的差距，用以降低投资风险。  

### 1.1.3 戴维德雷曼的贡献与影响力  
戴维德雷曼是价值投资的代表人物之一，他的《证券分析》和《聪明的投资者》奠定了价值投资的基础。他的方法强调安全边际和长期投资，对全球投资界产生了深远影响。  

---

## 1.2 戴维德雷曼的投资理念

### 1.2.1 安全边际的概念  
安全边际是戴维德雷曼提出的重要概念，指买入价格低于内在价值的部分。它为投资提供了缓冲区，降低因估值误差或市场波动带来的损失。  

### 1.2.2 市场先生与投资者的角色  
戴维德雷曼将市场比作“市场先生”，认为市场价格波动反映了市场先生的情绪，而非资产的真实价值。投资者应利用市场波动，寻找低估机会。  

### 1.2.3 长期投资与复利效应  
戴维德雷曼强调复利效应的重要性，认为长期持有优质资产是实现财富增长的最佳方式。  

---

## 1.3 价值投资的核心要素

### 1.3.1 股票的内在价值  
内在价值是资产的真实价值，与市场价格无关。计算内在价值通常采用现金流折现模型（DCF）。  

### 1.3.2 市场价格与内在价值的差异  
市场价格受市场情绪影响，可能高于或低于内在价值。价值投资者寻找市场价格低于内在价值的证券。  

### 1.3.3 投资决策的逻辑框架  
1. 确定目标：明确投资目标和风险承受能力。  
2. 基本面分析：评估资产的内在价值。  
3. 安全边际分析：计算买入价格与内在价值的差距。  
4. 投资决策：基于安全边际和市场环境做出决策。  

---

## 1.4 价值投资的适用场景与边界

### 1.4.1 价值投资的适用领域  
价值投资适用于股票、债券等资产，尤其在市场低估时期更具优势。  

### 1.4.2 价值投资的局限性  
1. **市场波动**：短期波动可能导致安全边际消失。  
2. **估值难度**：内在价值的计算需要准确的财务数据和模型假设。  
3. **时间成本**：长期投资需要耐心和纪律。  

### 1.4.3 如何避免投资陷阱  
1. **分散投资**：避免过度集中于单一资产。  
2. **持续学习**：关注行业动态和市场变化。  
3. **纪律性**：坚持投资策略，避免情绪化决策。

# 第3章: 价值投资的数学模型与公式

## 3.1 内在价值的计算公式

### 3.1.1 现金流折现模型（DCF）
DCF模型是计算内在价值的核心工具，公式如下：

$$
\text{内在价值} = \sum_{t=1}^{n} \frac{\text{自由现金流}_t}{(1 + r)^t} + \frac{\text{残值}}{(1 + r)^n}
$$

其中，$r$为折现率，$n$为永续年份。  

### 3.1.2 市盈率与市净率的比较  
市盈率（P/E）= 市场价格 / 每股收益  
市净率（P/B）= 市场价格 / 每股净资产  

### 3.1.3 内在价值与市场价格的关系  
价值投资者寻找市场价格低于内在价值的资产。  

---

## 3.2 安全边际的数学表达

### 3.2.1 安全边际的计算公式  
$$
\text{安全边际} = \text{内在价值} - \text{买入价格}
$$

### 3.2.2 安全边际与投资风险的关系  
安全边际越大，投资风险越小。

## 5.2 核心实现源代码

### 5.2.1 内在价值计算代码  

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(free_cash_flows, discount_rate, residual_value):
    n = len(free_cash_flows)
    intrinsic_value = 0
    for t in range(n):
        intrinsic_value += free_cash_flows[t] / (1 + discount_rate)**t
    intrinsic_value += residual_value / (1 + discount_rate)**n
    return intrinsic_value

# 示例数据
free_cash_flows = [100, 120, 150, 200]
discount_rate = 0.1
residual_value = 500

iv = calculate_intrinsic_value(free_cash_flows, discount_rate, residual_value)
print(f"内在价值为：{iv:.2f}")
```
