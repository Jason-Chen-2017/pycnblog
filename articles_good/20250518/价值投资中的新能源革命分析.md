## 第一部分：价值投资与新能源革命的背景

### 第1章：价值投资的基本概念

#### 1.1 价值投资的核心理念
- **价值投资的定义**：价值投资是一种以内在价值为核心的投资策略，强调通过分析企业的基本面，寻找市场价格低于内在价值的标的物。
- **价值投资的特点**：
  - 长期视角：关注企业的长期盈利能力。
  - 安全边际：买入价格低于企业的真实价值。
  - 质量优先：选择行业地位稳固、财务健康的公司。
- **价值投资与其他投资策略的对比**：
  | 对比维度 | 价值投资 | 股票投机 | 技术分析 |
  |----------|----------|----------|----------|
  | 投资依据 | 内在价值 | 市场情绪 | 技术指标 |
  | 持股时间 | 长期 | 短期 | 短期或中期 |
  | 风险控制 | 安全边际 | 随市场波动 | 技术信号 |

#### 1.2 新能源革命的背景与现状
- **新能源革命的定义**：指以可再生能源（如太阳能、风能、氢能等）为核心，替代传统化石能源的全球性能源转型过程。
- **新能源革命的核心驱动力**：
  - 环境问题：减少碳排放，应对气候变化。
  - 资源危机：化石能源的枯竭与不可再生性。
  - 技术进步：新能源技术的成熟与成本下降。
- **新能源革命的全球发展趋势**：
  - 全球能源结构向清洁化、低碳化转型。
  - 各国政府纷纷出台政策支持新能源发展。
  - 新能源技术快速迭代，产业规模持续扩大。

## 第二部分：新能源革命的经济影响

### 第2章：新能源产业链的经济分析

#### 2.1 新能源产业链的结构
- **上游资源**：锂、镍、钴等关键材料，以及光伏材料（如硅片）。
- **中游制造**：电池、组件、设备的生产。
- **下游应用**：电动汽车、光伏发电、智能电网等。

#### 2.2 新能源商业模式的创新
- **共享经济与新能源的结合**：如共享储能、共享充电桩。
- **订阅模式**：用户按月付费使用新能源服务，而非购买设备。
- **资产证券化**：将新能源项目打包成金融产品，吸引投资者。

#### 6.2 核心代码实现
```python
import pandas as pd
import numpy as np

# 示例：新能源企业的财务数据分析
def calculate_intrinsic_value(company_financials):
    # 计算自由现金流
    fcf = company_financials['free_cash_flow']
    # 计算加权平均资本成本
    wacc = company_financials['wacc']
    # 计算内在价值
    iv = fcf / (1 + wacc)
    return iv

# 示例：企业价值对比
def compare_market_intrinsic_value(company_data):
    market_value = company_data['market_value']
    intrinsic_value = company_data['intrinsic_value']
    # 判断是否低估
    is_undervalued = market_value < intrinsic_value
    return is_undervalued

# 应用示例
data = {
    'free_cash_flow': 100,
    'wacc': 0.1,
    'market_value': 80,
    'intrinsic_value': 120
}
print(compare_market_intrinsic_value(data))
```
