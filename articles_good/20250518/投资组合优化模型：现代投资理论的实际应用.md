# 第1章: 投资组合优化模型概述

## 1.1 投资组合优化模型的基本概念

### 1.1.1 投资组合的定义与特点
- **定义**：投资组合是将不同金融资产按特定比例组合，以分散风险、优化收益。
- **特点**：分散风险、收益最大化、动态调整。
- **公式**：投资组合收益计算公式：$$E(r_p) = \sum w_i E(r_i)$$
  其中，$w_i$是资产$i$的权重，$E(r_i)$是期望收益。

### 1.1.2 投资组合优化的定义与目标
- **定义**：寻找最优资产配置，最大化收益或最小化风险。
- **目标**：在给定风险下收益最大化，或在给定收益下风险最小化。
- **公式**：经典优化问题：$$\min_w \sigma_p^2 \quad \text{subject to} \quad \mu_p = \sum w_i \mu_i$$

### 1.1.3 现代投资理论的联系
- **马科维茨有效前沿**：通过优化模型找到最优投资组合，构成有效前沿。

---

## 1.2 现代投资组合理论（MPT）概述

### 1.2.1 MPT的核心思想
- 投资者应考虑资产的协方差矩阵，而非单一资产表现。
- 通过组合投资降低系统性风险。

### 1.2.2 风险与收益的平衡
- 风险调整后的收益：夏普比率：$$\text{夏普比率} = \frac{E(r_p) - r_f}{\sigma_p}$$

## 3.2 算法实现的Python代码

### 3.2.1 均值-方差模型的实现

```python
import numpy as np
from scipy.optimize import minimize

# 数据准备
mu = np.array([0.1, 0.2])
sigma = np.array([[0.1, 0.05], [0.05, 0.2]])

# 定义目标函数
def objective(w):
    return np.dot(w, np.dot(mu, w.T))

# 定义约束
def constraint(w):
    return np.sum(w) - 1

# 调用优化函数
w = minimize(objective, np.array([0.5, 0.5]), 
              constraints={'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
              bounds=[(0, None), (0, None)]).x

print(w)
```

## 4.1 均值-方差模型的数学推导

### 4.1.1 数学模型的建立
- 优化问题：$$\min_w w^T \Sigma w \quad \text{subject to} \quad \mu_p = \sum w_i \mu_i$$

### 4.1.2 求解过程
