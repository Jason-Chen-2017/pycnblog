# 第一部分：价值投资的核心概念

## 第1章：价值投资的核心概念

### 1.1 价值投资的定义与背景

价值投资是一种投资策略，强调以低于内在价值的价格购买优质资产。该理念由本杰明·格雷厄姆在20世纪初提出，至今仍是投资领域的重要理论之一。

#### 1.1.1 投资的基本问题与背景

- **问题背景**：投资者在市场中面临信息不对称、价格波动和情绪影响等挑战。
- **核心目标**：寻找被市场低估的资产，长期持有以实现收益。

#### 1.1.2 价值投资的起源与发展

- 格雷厄姆在《 Intelligent Investor》中首次系统阐述了价值投资理念。
- 现代价值投资结合了基本面分析和行为金融学，适应市场变化。

#### 1.1.3 格雷厄姆与价值投资的联系

- 格雷厄姆是价值投资的奠基人，其理念强调安全边际和长期投资。

### 1.2 格雷厄姆的价值投资理念

#### 1.2.1 安全边际的概念与重要性

- **安全边际**：指股票价格与内在价值之间的差距，确保投资的安全性。
- **重要性**：通过安全边际，投资者可以降低市场波动带来的风险。

#### 1.2.2 内在价值的计算方法

- 内在价值是企业未来现金流的现值，需考虑企业盈利能力、成长性和财务状况。

#### 1.2.3 股票与企业价值的关系

- 股票是企业的部分所有权，投资股票即投资企业。

## 第2章：格雷厄姆价值投资模型的核心原理

### 2.1 核心概念与联系

#### 2.1.1 核心概念对比表

|--------------|--------------------------|

### 2.2 格雷厄姆投资模型的数学公式

#### 2.2.1 内在价值公式

$$
\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t}
$$

其中，$r$为折现率，$\text{现金流}_t$为第$t$年的现金流。

#### 2.2.2 安全边际计算公式

$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

#### 2.2.3 举例说明与实际应用

例如，某企业内在价值为$50，市场价格为$40，则安全边际为$10，具有较高的投资价值。

#### 5.2.2 核心代码实现

```python
import pandas as pd
import numpy as np

# 示例：计算内在价值
def calculate_intrinsic_value(cash_flows, discount_rate):
    return np.sum(cash_flows / (1 + discount_rate) ** np.arange(len(cash_flows)))

cash_flows = [100, 120, 150]  # 示例现金流
discount_rate = 0.05
intrinsic_value = calculate_intrinsic_value(cash_flows, discount_rate)
print(f"内在价值为：{intrinsic_value:.2f}")
```
