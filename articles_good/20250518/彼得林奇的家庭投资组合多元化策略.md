## 第1章: 家庭投资组合概述

### 1.1 投资组合的基本概念

#### 1.1.1 投资组合的定义
投资组合是指将资金分配到不同资产类别（如股票、债券、房地产等）中的组合，以实现风险和收益的优化平衡。

#### 1.1.2 家庭投资组合的特殊性
家庭投资组合的目标是为家庭提供财务安全和长期财富增长，通常需要兼顾流动性、安全性和收益性。

#### 1.1.3 投资组合与个人财务规划的关系
投资组合是个人财务规划的重要组成部分，帮助家庭在不同生命周期阶段实现财务目标。

---

### 1.2 多元化投资的重要性

#### 1.2.1 多元化投资的基本原理
通过将资金分配到不同的资产类别，降低单一资产的风险，实现收益的稳定增长。

#### 1.2.2 多元化与风险控制的关系
多元化投资能够有效分散风险，避免因单一资产波动导致的重大损失。

#### 1.2.3 家庭投资组合的多元化策略
彼得·林奇强调通过投资不同类型的资产（如股票、债券、房地产等）来实现多元化，同时注重长期价值。

#### 6.2.2 Python代码实现
```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def portfolio_optimization(returns):
    # 定义目标函数
    def objective(weights):
        return np.dot(weights.T, np.dot(returns.cov(), weights))
    
    # 定义约束条件
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    
    # 初始化权重（等权）
    n_assets = len(returns.columns)
    init_weights = np.array([1.0/n_assets] * n_assets)
    
    # 使用SLSQP求解
    result = minimize(objective, init_weights, constraints=constraints)
    return result.x

# 示例数据
returns = pd.DataFrame({
    '股票': [0.1, 0.05, 0.03],
    '债券': [0.03, 0.04, 0.05],
    '房地产': [0.08, 0.06, 0.07]
})

optimal_weights = portfolio_optimization(returns)
print(optimal_weights)
```
