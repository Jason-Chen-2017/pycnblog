# 第1章 价值投资与风险管理概述

## 1.1 价值投资的起源与发展

### 1.1.1 价值投资的定义与核心理念  
价值投资是一种以基本面分析为基础的投资策略，强调以低于内在价值的价格购买优质资产。其核心理念是通过深入研究企业的财务状况、行业地位和竞争优势，寻找被市场低估的投资机会。

### 1.1.2 价值投资与成长投资的区别  
- **价值投资**：注重安全边际，追求低估值，适合稳健型投资者。  
- **成长投资**：注重未来增长潜力，愿意为高成长性支付溢价，适合风险承受能力强的投资者。  

### 1.1.3 风险管理在价值投资中的重要性  
价值投资并非“买入并持有”那么简单，市场波动和宏观经济变化会显著影响投资组合的表现。有效的风险管理可以帮助投资者在市场低迷时期减少损失，抓住优质资产的增持机会。

---

## 1.2 风险管理的核心概念

### 1.2.1 风险的定义与分类  
- **系统性风险**：影响整个市场的风险，如经济衰退、战争、政策变化等。  
- **非系统性风险**：特定于个别资产或行业的风险，如公司财务状况恶化、行业政策变化等。  

### 1.2.2 风险与收益的权衡  
在投资中，收益与风险是密切相关的。高收益通常伴随着高风险，而低风险投资往往收益较低。夏普比率是一个衡量风险调整后收益的重要指标。

### 1.2.3 风险管理的目标与原则  
- **目标**：在可接受的风险水平内实现最大收益。  
- **原则**：分散投资、定期再平衡、动态调整风险敞口。

# 第2章 现代投资组合理论与风险管理

## 2.1 现代投资组合理论（MPT）概述

### 2.1.1 MPT的核心假设  
- 投资者是理性的，追求效用最大化的。  
- 市场存在有效定价，资产价格反映所有公开信息。  

### 2.1.2 有效前沿的定义与应用  
有效前沿是指在给定风险水平下，能够提供最高预期收益的投资组合的集合。投资者可以通过调整投资组合在有效前沿上的位置，实现风险与收益的最佳匹配。

### 2.1.3 夏普比率的计算与意义  
夏普比率衡量的是投资组合单位风险所获得的超额收益，公式如下：
$$ \text{夏普比率} = \frac{E[r_p] - r_f}{\sigma_p} $$
其中，$E[r_p]$为投资组合的预期收益率，$r_f$为无风险利率，$\sigma_p$为投资组合的波动率。

---

## 2.2 风险与收益的权衡

### 2.2.1 风险溢价的定义  
风险溢价是投资者因承担额外风险而要求的额外收益。

### 2.2.2 风险中性定价的原理  
在无套利的情况下，资产的定价应使其风险调整后的收益等于无风险利率。

### 2.2.3 风险调整后的收益评估  
通过夏普比率等指标，评估投资组合的风险调整后收益，帮助投资者做出更明智的决策。

---

## 2.3 投资组合优化的数学模型

### 2.3.1 均值-方差优化的公式  
$$ \text{Minimize } \sigma^2 \text{ subject to } \mu \geq \text{target return} $$
其中，$\mu$为投资组合的预期收益率，$\sigma^2$为投资组合的方差。

### 2.3.2 风险平价的计算方法  
风险平价是一种将风险均匀分配给不同资产的策略，公式如下：
$$ w_i = \frac{\sigma_i}{\sum_{j=1}^n \sigma_j} $$
其中，$w_i$为第$i$个资产的权重，$\sigma_i$为第$i$个资产的风险贡献。

## 5.2 核心实现

### 5.2.1 投资组合优化的代码  
```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, cov_matrix):
    n = len(returns)
    # 目标函数：最小化方差
    def objective(weights):
        return np.dot(weights.T, np.dot(cov_matrix, weights))
    # 约束条件：权重和为1
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    # 解决器
    result = minimize(objective, np.ones(n)/n, constraints=constraints)
    return result.x
```

## 6.2 小结与注意事项
