### 第1章: 认知偏差的基本概念

#### 1.1 认知偏差的定义与分类

##### 1.1.1 什么是认知偏差  
认知偏差（Cognitive Bias）是指人在信息处理、记忆检索、逻辑推理等过程中产生的系统性偏离客观事实的倾向。认知偏差是人类思维的“盲点”，它源于大脑为了快速决策而简化信息处理的方式。  

**关键属性对比表：**

| 属性       | 认知偏差        | 理性决策         |
|------------|-----------------|------------------|
| 定义       | 系统性偏离事实   | 基于逻辑和事实    |
| 成因       | 快速决策需求     | 慢速、精确处理    |
| 表现形式   | 错误记忆、推理错误| 准确推理、判断    |

##### 1.1.2 认知偏差的分类与特点  
认知偏差种类繁多，常见的包括确认偏差（Confirmation Bias）、从众偏差（Conformity Bias）、过度自信偏差（Overconfidence Bias）等。每种偏差都有其独特的表现形式和影响范围。

##### 1.1.3 认知偏差的形成机制  
认知偏差的形成机制复杂，主要包括信息处理的简化、情感因素的干扰、社会环境的影响等。这些机制共同作用，导致人类在决策过程中偏离理性轨道。

##### 1.2.2 芒格认知偏差理论的核心观点  
芒格认为，认知偏差是人类思维的“基本单元”，理解和克服这些偏差是提升决策能力的关键。他提出了著名的“心理倾向清单”，列举了数十种常见的认知偏差，并分析了它们对决策的影响。

##### 1.2.3 芒格认知偏差理论的应用领域  
芒格的认知偏差理论广泛应用于心理学、经济学、管理学等领域。在技术领域，该理论为量子决策系统的构建提供了重要的理论基础。

import numpy as np
from qiskit import QuantumCircuit, execute, Aer

# 定义量子回路

result = job.result()

# 获取结果
counts = result.get_counts()
print(counts)
