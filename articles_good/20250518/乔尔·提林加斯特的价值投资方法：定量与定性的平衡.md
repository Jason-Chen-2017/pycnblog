## 3.1 基本比率分析

### 3.1.1 常用财务比率的计算公式

在定量分析中，财务比率是衡量企业财务健康状况的重要工具。以下是几种常用的财务比率及其计算公式：

#### 市盈率（P/E Ratio）
$$市盈率 = \frac{股票价格}{每股收益}$$

#### 市净率（P/B Ratio）
$$市净率 = \frac{股票价格}{每股净资产}$$

#### 股息率（Dividend Yield）
$$股息率 = \frac{每股股息}{股票价格}$$

#### 净利润增长率
$$净利润增长率 = \frac{本年净利润 - 去年净利润}{去年净利润} \times 100\%$$

### 3.1.2 市盈率与市净率的比较

市盈率和市净率是衡量股票估值的两个重要指标。市盈率适用于盈利稳定的公司，而市净率适用于资产密集型公司。以下是两者的比较：

| 比较维度 | 市盈率 | 市净率 |
|----------|--------|--------|
| 适用场景 | 盈利稳定的公司 | 资产密集型公司 |
| 计算公式 | $$市盈率 = \frac{股票价格}{每股收益}$$ | $$市净率 = \frac{股票价格}{每股净资产}$$ |
| 优点 | 反映盈利能力 | 反映资产价值 |
| 缺点 | 高增长公司可能偏高 | 未盈利公司可能偏高 |

### 3.1.3 行业比较与估值分析

在进行行业比较时，我们需要考虑行业的平均市盈率和市净率。以下是计算行业平均市盈率的步骤：

1. 获取行业内的所有公司股票数据。
2. 计算每家公司的市盈率。
3. 计算行业平均市盈率。
4. 比较目标公司的市盈率与行业平均市盈率，判断其估值是否合理。

#### 示例代码

```python
import pandas as pd
import yfinance as yf

# 下载行业内的股票数据
tickers = ['AAPL', 'MSFT', 'GOOGL']
data = yf.download(tickers, start='2022-01-01', end='2022-12-31')['Adj Close']

# 计算每家公司的市盈率
pe_list = []
for ticker in tickers:
    try:
        # 获取每股收益（EPS）
        df = yf.info(ticker)
        eps = df['eps']
        price = data[ticker][-1]
        pe = price / eps
        pe_list.append(pe)
    except:
        pe_list.append(None)

# 计算行业平均市盈率
average_pe = sum(pe_list) / len(pe_list)
print(f"行业平均市盈率为：{average_pe}")
```

### 3.1.5 数据清洗与预处理

在进行定量分析之前，数据清洗和预处理是必不可少的步骤。以下是一些常用的数据清洗方法：

1. **处理缺失值**：
   - 使用填充法（如均值、中位数）填充缺失值。
   - 删除缺失值较多的行或列。

2. **处理异常值**：
   - 使用Z-score或IQR方法检测异常值。
   - 删除或调整异常值。

3. **数据标准化**：
   - 使用标准差标准化或归一化处理数据。

#### 示例代码

```python
import pandas as pd
import numpy as np

# 创建示例数据
data = {
    'Date': ['2022-01-01', '2022-01-02', '2022-01-03', '2022-01-04', '2022-01-05'],
    'Price': [100, np.nan, 105, 80, np.nan]
}
df = pd.DataFrame(data)

# 处理缺失值
df['Price'].fillna(df['Price'].mean(), inplace=True)

# 处理异常值
z = np.abs((df['Price'] - df['Price'].mean()) / df['Price'].std())
df = df[(z < 3).all()]

print(df)
```

## 3.2 行业比较与估值分析

### 3.2.1 行业估值的基本方法

行业估值是通过比较行业内公司的估值指标（如市盈率、市净率）来判断整个行业的估值水平。以下是行业估值的基本步骤：

1. 获取行业内所有公司的估值指标。
2. 计算行业的平均估值指标。
3. 比较目标公司的估值指标与行业平均值，判断其估值是否合理。

#### 示例代码

```python
import yfinance as yf

# 下载科技行业内的股票
tickers = ['AAPL', 'MSFT', 'GOOGL', 'AMZN']
data = yf.download(tickers, start='2022-01-01', end='2022-12-31')['Adj Close']

# 计算每家公司的市盈率
pe_dict = {}
for ticker in tickers:
    try:
        df = yf.info(ticker)
        eps = df['eps']
        price = data[ticker][-1]
        pe = price / eps
        pe_dict[ticker] = pe
    except:
        pe_dict[ticker] = None

# 计算行业平均市盈率
average_pe = sum(pe_dict.values()) / len(pe_dict)
print(f"行业平均市盈率为：{average_pe}")
```

### 3.2.2 估值模型的优缺点

常用的估值模型包括：

| 模型名称 | 优点 | 缺点 |
|---------|------|------|
| 市盈率模型 | 简单易懂 | 受盈利能力影响较大 |
| 市净率模型 | 反映资产价值 | 受资产质量影响较大 |
| 股息率模型 | 适用于成熟企业 | 未成熟企业适用性较低 |

### 3.2.3 估值模型的实现

#### 示例代码

```python
import yfinance as yf
import pandas as pd

# 下载苹果公司（AAPL）的估值指标
aapl = yf.Ticker('AAPL')
aapl_info = aapl.info

# 计算市盈率
pe = aapl_info['currentPrice'] / aapl_info['eps']

# 计算市净率
pb = aapl_info['currentPrice'] / aapl_info['bookValue']

print(f"苹果公司的市盈率为：{pe}\n苹果公司的市净率为：{pb}")
```

### 3.3.2 市净率计算公式
