## 第1章: 格雷厄姆特价股票策略概述

### 1.1 格雷厄姆投资理论的核心思想

#### 1.1.1 价值投资的定义与核心原则
格雷厄姆的价值投资理论强调以低于内在价值的价格购买优质资产。其核心原则包括:
$$
\text{内在价值} = \text{未来现金流的现值}
$$
这种方法通过安全边际（$ \text{内在价值} - \text{市场价格} $）来降低投资风险。

#### 1.1.2 特价股票的定义与识别标准
特价股票是指市场价格显著低于内在价值的股票。识别标准包括:
- 低市盈率（$ P/E < 15 $）
- 高股息率（$ \text{股息率} > 5\% $）
- 低市净率（$ P/B < 2 $）

#### 1.1.3 格雷厄姆策略在现代投资中的应用
格雷厄姆策略常用于防御性投资，尤其在市场低迷时期表现优异。然而，其在现代金融市场的适应性需要结合监管科技进行优化。

### 1.2 格雷厄姆策略的关键要素

#### 1.2.1 股票内在价值的计算方法
内在价值计算公式：
$$
\text{内在价值} = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}
$$
其中，$CF_t$ 是第 $t$ 年的自由现金流，$r$ 是折现率。

#### 1.2.2 股市波动与安全边际的概念
安全边际公式：
$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$
安全边际越大，投资风险越小。

#### 1.2.3 稳健投资策略的实施步骤
1. 确定投资目标和风险承受能力。
2. 选择具有竞争优势的公司。
3. 以低于内在价值的价格买入并长期持有。

### 1.3 格雷厄姆策略的优缺点分析

#### 1.3.1 优点: 长期稳定收益与风险控制
- 通过安全边际降低市场波动风险。
- 稳定的复利增长。

#### 1.3.2 缺点: 短期波动风险与市场适应性
- 短期内可能跑输市场。
- 依赖于对内在价值的准确评估。

#### 1.3.3 现代市场环境对格雷厄姆策略的影响
- 信息透明度提高，内在价值评估更准确。
- 市场波动加剧，安全边际要求更高。

#### 8.2.1 内在价值计算
```python
def calculate_intrinsic_value(free_cash_flow, discount_rate, horizon):
    present_value = 0
    for t in range(1, horizon+1):
        present_value += free_cash_flow[t] / (1 + discount_rate)**t
    return present_value
```

#### 8.2.2 安全边际计算
```python
def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price
```

#### 8.2.3 投资决策模块

def investment_decision(margin_of_safety, threshold):
