### 3.2 公共卫生事件预测模型
#### 3.2.1 SIR模型
SIR模型代码示例：
```python
import numpy as np

def sir_model(S0, I0, R0, beta, gamma, days):
    S = [S0]
    I = [I0]
    R = [R0]
    for _ in range(days):
        s = S[-1]
        i = I[-1]
        r = R[-1]
        dS = -beta * s * i
        dI = beta * s * i - gamma * i
        dR = gamma * i
        S.append(s + dS)
        I.append(i + dI)
        R.append(r + dR)
    return S, I, R
```
