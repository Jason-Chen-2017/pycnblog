## 第一部分: 格雷厄姆特价股票理论与现代投资组合理论的背景介绍

### 第1章: 价值投资的起源与格雷厄姆理论

#### 1.1 价值投资的核心理念
价值投资是一种以基本面分析为基础的投资策略，其核心理念是寻找市场低估的股票，即市场价格低于其内在价值的股票。这种投资策略强调长期持有优质资产，追求安全边际和稳定的收益。

- **1.1.1 价值投资的定义与起源**
  - 价值投资起源于20世纪初，由本杰明·格雷厄姆和大卫·多德共同提出。
  - 格雷厄姆的“捡烟头”策略，即寻找市场忽视的廉价股票，是价值投资的核心思想。

- **1.1.2 格雷厄姆的投资理念与方法**
  - 格雷厄姆强调安全边际，即市场价格与内在价值之间的差距越大，投资风险越小。
  - 他提出了多种内在价值计算方法，如市盈率、市净率等指标。

- **1.1.3 格雷厄姆特价股票理论的核心观点**
  - 股票价格围绕内在价值波动。
  - 投资者应选择市场价格低于内在价值的股票，并长期持有。

#### 1.2 格雷厄姆特价股票理论的数学模型
格雷厄姆的内在价值计算公式可以表示为：
$$
\text{内在价值} = \frac{\text{预期收益}}{\text{折现率}}
$$
该公式强调了安全边际的重要性，即市场价格应低于内在价值的一定比例。

### 第2章: 现代投资组合理论的发展

#### 2.1 现代投资组合理论的概述
现代投资组合理论（MPT）由哈里·马科维茨在1952年提出，其核心思想是通过分散投资降低风险。

- **2.1.1 投资组合理论的基本概念**
  - 投资组合：将资金分配到多种资产中，以降低风险并提高收益。
  - 风险与收益的权衡：通过优化投资组合的收益-风险比，实现最大收益。

- **2.1.2 马科维茨的均值-方差模型**
  - 均值-方差模型通过计算资产的预期收益率和方差，寻找最优投资组合。
  - 该模型假设资产收益服从正态分布，并且可以通过数学优化找到最优解。

- **2.1.3 现代投资组合理论的演变与应用**
  - 进入21世纪，MPT逐渐与实际市场相结合，发展出多种投资策略，如指数基金、对冲基金等。

### 第3章: 格雷厄姆特价股票理论与现代投资组合理论的融合

#### 3.1 两种理论的共同点与差异
- **共同点**
  - 两者都强调长期投资和风险控制。
  - 都以数学模型为基础，具有较强的理论性。

- **差异**
  - 格雷厄姆理论更注重基本面分析和安全边际。
  - 现代投资组合理论更注重数学模型和风险分散。

#### 3.2 融合的必要性与优势
- **必要性**
  - 单一理论在实际投资中存在局限性，需要结合多种方法提高投资效率。
  - 通过融合两种理论，可以实现投资目标的多元化和风险控制的最优化。

- **优势**
  - 结合格雷厄姆的安全边际概念，降低投资组合的市场风险。
  - 利用现代投资组合理论的优化方法，提高投资组合的收益。

### 第4章: 格雷厄姆特价股票理论的核心原理

#### 4.1 格雷厄姆的内在价值计算
- **内在价值的计算步骤**
  1. 确定企业的基本面数据，如净利润、营业收入、现金流等。
  2. 通过格雷厄姆的估值模型计算企业的内在价值。
  3. 比较市场价格与内在价值，寻找低估股票。

- **内在价值计算的数学模型**
  $$
  \text{内在价值} = \frac{\text{净利润} \times (1 + \text{增长率})}{\text{折现率} - \text{增长率}}
  $$

- **案例分析**
  以某公司为例，假设其净利润为1000万元，增长率3%，折现率10%，则其内在价值为：
  $$
  \frac{1000 \times (1 + 0.03)}{0.10 - 0.03} = 145,454.55
  $$

### 第5章: 现代投资组合理论的数学模型与属性对比

#### 5.1 现代投资组合理论的数学模型
- **均值-方差模型**
  1. 计算各资产的预期收益率和方差。
  2. 通过优化算法寻找最优投资组合。

- **优化算法**
  使用拉格朗日乘数法求解优化问题：
  $$
  \min_{w} \sigma^2 = w^T \Sigma w
  $$
  $$
  \text{subject to} \quad w^T \mu = \mu_p, \quad w^T 1 = 1
  $$

| **属性**            | **格雷厄姆理论**             | **现代投资组合理论**       |

### 第6章: 算法原理

#### 6.1 格雷厄姆特价股票筛选算法
- **算法步骤**
  1. 收集目标股票的基本面数据。
  2. 计算每只股票的内在价值。
  3. 比较市场价格与内在价值，筛选低估股票。

- **Python代码示例**
  ```python
  def calculate_intrinsic_value(net_income, growth_rate, discount_rate):
      return (net_income * (1 + growth_rate)) / (discount_rate - growth_rate)
  
  # 示例数据
  net_income = 10000000
  growth_rate = 0.03
  discount_rate = 0.10
  
  iv = calculate_intrinsic_value(net_income, growth_rate, discount_rate)
  print(f"内在价值：{iv:.2f}")
  ```

#### 6.2 现代投资组合优化算法
- **算法步骤**
  1. 收集多只股票的收益率和协方差矩阵。
  2. 使用均值-方差模型计算最优投资组合。

- **Python代码示例**
  ```python
  import numpy as np
  from scipy.optimize import minimize
  
  def portfolio_optimization(returns, covariance):
      n = len(returns)
      # 目标是最小化方差
      objective = {'type': 'minimize', 'fun': lambda w: np.dot(w.T, covariance).dot(w)}
      # 约束条件：收益等于目标收益，且权重之和为1
      constraints = [
          {'type': 'equality', 'fun': lambda w: np.sum(w) - 1},
          {'type': 'equality', 'fun': lambda w: np.dot(w.T, returns) - target_return}
      ]
      # 初始权重
      initial_guess = np.array([1.0 / n] * n)
      # 求解优化问题
      result = minimize(objective['fun'], initial_guess, constraints=constraints)
      return result.x
  
  # 示例数据
  returns = np.array([0.1, 0.12, 0.08])
  covariance = np.array([
      [0.02, 0.01, 0.01],
      [0.01, 0.03, 0.02],
      [0.01, 0.02, 0.03]
  ])
  target_return = 0.1
  optimal_weights = portfolio_optimization(returns, covariance)
  print(f"最优权重：{optimal_weights}")
  ```
