## 第3章: 算法原理讲解

### 3.1 生成模型的算法原理
#### 3.1.1 Transformer模型的原理
- 注意力机制：$Attention(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}\}}\right)V$
- 解码器结构：通过自注意力和前向网络生成文本

#### 3.1.2 扩散模型的原理
- 步骤1：逐步添加噪声到数据
- 步骤2：逐步去噪，恢复原始数据
- 扩散过程：$x_t = \sigma_t \epsilon + \sqrt{1-\sigma_t^2}x_{t-1}$
- 去噪过程：学习如何从带噪数据中恢复原始数据

#### 3.1.3 其他生成模型的对比
- RNN与LSTM的区别
- Transformer与扩散模型的优劣对比

#### 3.2.3 Python代码实现
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class Transformer(nn.Module):
    def __init__(self, d_model, nhead, dff):
        super().__init__()
        self.attention = nn.MultiheadAttention(d_model, nhead)
        self.feedforward = nn.Sequential(
            nn.Linear(d_model, dff),
            nn.ReLU(),
            nn.Linear(dff, d_model)
        )

    def forward(self, x, mask=None):
        attn_output, _ = self.attention(x, x, mask)
        output = self.feedforward(attn_output)
        return output

# 示例用法
d_model = 512
nhead = 8
dff = 2048
transformer = Transformer(d_model, nhead, dff)
```

### 5.2 系统核心实现源代码
```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

class InvestmentReportGenerator:
    def __init__(self, model_name):
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModelForCausalLM.from_pretrained(model_name)

    def generate_report(self, user_id, market_data):
        inputs = self.tokenizer.encode(f"生成投资报告，用户ID：{user_id}, 市场数据：{market_data}", return_tensors="pt")
        outputs = self.model.generate(inputs, max_length=500)
        report = self.tokenizer.decode(outputs[0], skip_special_tokens=True)
        return report

# 示例用法
generator = InvestmentReportGenerator("gpt2")
report = generator.generate_report(123, "股票价格：300, 市场趋势：上升")
print(report)
```
