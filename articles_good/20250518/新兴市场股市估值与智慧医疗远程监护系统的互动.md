## 第2章: 股市估值的核心原理

### 2.1 股市估值的基本方法

#### 2.1.1 市盈率法
- 公式：市盈率 = 股价 / 每股收益（EPS）。
- 示例：某股票股价为10元，EPS为2元，则市盈率为5。

#### 2.1.2 市净率法
- 公式：市净率 = 股价 / 每股净资产（BPS）。
- 示例：某股票股价为15元，BPS为5元，则市净率为3。

#### 2.1.3 股息率法
- 公式：股息率 = 每股股息（DIV） / 股价。
- 示例：某股票股息为1元，股价为10元，则股息率为10%。

### 2.2 新兴市场的特殊性

#### 2.2.1 新兴市场的经济特征
- 经济增长快，但波动性大。
- 投资者行为受情绪影响较大。

#### 2.2.2 新兴市场的股市波动性
- 市场流动性不足。
- 缺乏长期投资者，短期交易行为主导。

#### 2.2.3 新兴市场的投资者行为
- 投资者结构以散户为主。
- 投资者对政策变化敏感。

```python
from sklearn.linear_model import LinearRegression

def preprocess_data(df):
    # 数据清洗与特征提取
    df['heart_rate'] = df['heart_rate'].astype(int)
    df['blood_pressure'] = df['blood_pressure'].str.split('/').apply(lambda x: int(x[0]))
    return df

def train_model(df, target):
    # 训练模型
    X = df.drop(target, axis=1)
    y = df[target]
    model = LinearRegression()
    model.fit(X, y)
    return model

if __name__ == '__main__':
    df = collect_data()
    processed_df = preprocess_data(df)
    model = train_model(processed_df, 'heart_rate')
    print(model.coef_)
```

```python
import numpy as np

def evaluate_model(model, X, y):
    # 评估模型
    y_pred = model.predict(X)
    mse = np.mean((y_pred - y) ** 2)

if __name__ == '__main__':
```
