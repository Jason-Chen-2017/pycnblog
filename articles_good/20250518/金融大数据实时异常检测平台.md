# 第三章：基于统计的异常检测算法

## 3.1 LOF算法原理
### 3.1.1 LOF算法的基本思想
LOF（局部 outlier factor）算法通过计算数据点的局部密度来识别异常点。

### 3.1.2 LOF算法的数学模型
$$d_{ki} = \frac{1}{\sum_{j \neq i} r_{kj}}$$

$$LOF(i) = \frac{d_{ki}}{d_{ki}^k}$$

### 3.1.3 LOF算法的实现步骤
1. 计算每个数据点的可达距离。
2. 计算每个数据点的局部密度。
3. 计算每个数据点的LOF值。

## 3.2 KNN算法原理
### 3.2.1 KNN算法的基本思想
KNN算法通过计算数据点的K近邻密度来识别异常点。

### 3.2.2 KNN算法的数学模型
$$\text{密度}(x) = \frac{1}{|N_k(x)|}$$

### 3.2.3 KNN算法的实现步骤
1. 计算每个数据点的K近邻。
2. 计算每个数据点的密度。
3. 根据密度值判断是否为异常点。

## 3.3 算法实现与对比分析
### 3.3.1 LOF算法的优缺点
- **优点**：能够捕捉局部结构。
- **缺点**：计算复杂度高。

### 3.3.2 KNN算法的优缺点
- **优点**：计算简单。
- **缺点**：对参数K敏感。

### 3.3.3 LOF与KNN的对比分析
