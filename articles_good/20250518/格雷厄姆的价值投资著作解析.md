## 第3章：格雷厄姆的价值投资模型

### 3.1 内在价值的计算模型

#### 3.1.1 格雷厄姆的内在价值公式
内在价值可以通过企业未来现金流的现值来计算。

$$ V = \sum_{t=1}^{n} \frac{C_t}{(1+r)^t} $$

其中，$V$ 是内在价值，$C_t$ 是第 $t$ 年的现金流，$r$ 是折现率。

#### 3.1.2 股息贴现模型的应用
股息贴现模型是另一种常用的内在价值计算方法。

$$ P = \sum_{t=1}^{\infty} \frac{D_t}{(1+r)^t} $$

其中，$P$ 是股票价格，$D_t$ 是第 $t$ 年的股息，$r$ 是股息增长率。

### 5.2 核心算法实现

#### 5.2.1 内在价值计算的Python实现
编写代码计算股票的内在价值。

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(revenue, profit_margin, discount_rate):
    # 计算未来现金流
    cash_flows = revenue * (1 + 0.05) ** np.arange(10)
    # 计算现值
    present_values = cash_flows / (1 + discount_rate)
    # 计算总和
    intrinsic_value = present_values.sum()
    return intrinsic_value

revenue = 10000000  # 示例收入
profit_margin = 0.1  # 示例利润率
discount_rate = 0.08  # 折现率

iv = calculate_intrinsic_value(revenue, profit_margin, discount_rate)
print(f"内在价值为：{iv}")
```
