## 第2章: 特价股票与可转债概述

### 2.1 特价股票的基本概念
#### 2.1.1 特价股票的定义
特价股票是指市场价格低于面值的股票，通常被视为市场低估的表现。

#### 2.1.2 特价股票的特点
- 价格低于面值
- 通常具有较高的股息率
- 投资风险较低，回报潜力较高

#### 2.1.3 特价股票的市场环境
- 市场熊市周期中常见
- 经济衰退或企业困境时出现
- 投资者情绪低落时增加特价股票供应

### 2.2 可转债的基本概念
#### 2.2.1 可转债的定义
可转债是一种可以在一定条件下转换为公司股票的债券，兼具债券和股票的特性。

#### 2.2.2 可转债的结构与特点
- 债券部分提供固定利息收入
- 股票部分提供潜在的资本增值机会
- 转换价格和期限是关键参数

#### 2.2.3 可转债的发行与交易
- 公开发行或私募发行
- 在证券交易所上市交易
- 投资者可选择持有债券或转换为股票

### 2.3 特价股票与可转债的关系
#### 2.3.1 特价股票对可转债的影响
- 特价股票的市场表现影响可转债的转换价值
- 特价股票的流动性影响可转债的交易活跃度
- 特价股票的信用风险影响可转债的信用评级

#### 2.3.2 可转债作为投资工具的优势
- 稳定的利息收入
- 股票增值的潜在收益
- 灵活的转换选择

#### 2.3.3 特价股票策略在可转债投资中的应用
- 通过特价股票策略筛选优质债券
- 利用特价股票的低估优势提升可转债投资回报
- 结合特价股票市场周期优化投资组合

## 第3章: 可转债投资的基本原理

### 3.1 可转债的定价模型
#### 3.1.1 理论定价公式
可转债的价值 = 债券价值 + 转换期权价值

#### 3.1.2 市场定价的影响因素
- 市场利率
- 股票价格波动
- 转换溢价
- 信用风险

#### 3.1.3 价格波动分析
- 股票价格波动对可转债价格的影响
- 市场利率变化对可转债价格的影响
- 转换溢价对可转债价格的影响

### 3.2 可转债的转换价值
#### 3.2.1 转换价值的计算公式
转换价值 = 转换价格 × 转换比例

#### 3.2.2 转换价值与债券价值的关系
- 转换价值是可转债的内在价值
- 债券价值是可转债的外在价值
- 转换价值受股票价格波动影响较大

#### 3.2.3 转换价值的市场表现
- 股票价格上涨时，转换价值增加
- 股票价格下跌时，转换价值减少
- 债券期限对转换价值的影响

### 3.3 可转债的信用风险与流动性风险
#### 3.3.1 信用风险的评估
- 发行人信用评级
- 债券违约风险
- 利息支付能力

#### 3.3.2 流动性风险的分析
- 市场交易活跃度
- 债券市场规模
- 市场参与者结构

#### 3.3.3 风险管理策略
- 分散投资组合
- 选择高信用评级债券
- 关注市场流动性状况

```python
import pandas as pd
import numpy as np

# 特价股票筛选函数
def screen_penny_stocks(stock_data, threshold=0.9):
    return stock_data[(stock_data['price'] < stock_data['face_value']) & 
                      (stock_data['dividend_yield'] > threshold)]

# 可转债价值评估函数
def evaluate_convertible_bond(convertible_data, stock_data):
    convertible_data['theoretical_value'] = convertible_data['bond_value'] + convertible_data['conversion_value']
    return convertible_data

# 投资决策函数
def investment_decision(convertible_data, threshold=0.1):
    convertible_data['investment_recommendation'] = np.where(convertible_data['theoretical_value'] > convertible_data['market_price'], '买入', '观望')
    return convertible_data

# 示例数据
stock_data = pd.DataFrame({
    'price': [10, 20, 15, 12],
    'face_value': [15, 25, 20, 18],
    'dividend_yield': [0.05, 0.03, 0.04, 0.06]
})

convertible_data = pd.DataFrame({
    'bond_value': [90, 85, 95, 80],
    'conversion_value': [10, 15, 5, 20],
    'market_price': [95, 88, 92, 83]
})

# 调用函数
screened_stocks = screen_penny_stocks(stock_data)
evaluated_bonds = evaluate_convertible_bond(convertible_data, stock_data)
investment_recommendation = investment_decision(evaluated_bonds)

print(screened_stocks)
print(evaluated_bonds)
print(investment_recommendation)
```

### 7.3 代码应用解读与分析
- `screen_penny_stocks`函数用于筛选特价股票，根据股票价格和面值的比值以及股息率进行判断。
- `evaluate_convertible_bond`函数评估可转债的理论价值，结合债券价值和转换价值。
- `investment_decision`函数根据理论价值和市场价格做出投资决策，推荐“买入”或“观望”。
