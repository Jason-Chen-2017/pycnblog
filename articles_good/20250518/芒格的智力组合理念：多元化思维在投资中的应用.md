#### 3.2 投资决策的数学公式
- $$ V = \sum_{j=1}^{m} p_j \times r_j $$
  - 其中，\( V \) 表示投资组合的总价值，\( p_j \) 表示第 \( j \) 个资产的购买价格，\( r_j \) 表示第 \( j \) 个资产的预期回报率

### 第6章: 项目核心实现

#### 6.1 项目核心代码实现
- **Python代码示例：**
  ```python
  import numpy as np
  import pandas as pd

  # 示例数据：股票、债券、房地产的预期收益率和风险
  stocks = {'股票1': {'预期收益率': 0.1, '标准差': 0.15},
            '股票2': {'预期收益率': 0.12, '标准差': 0.1}}
  bonds = {'债券1': {'预期收益率': 0.05, '标准差': 0.03},
           '债券2': {'预期收益率': 0.06, '标准差': 0.04}}
  real_estate = {'房地产1': {'预期收益率': 0.08, '标准差': 0.1}}

  # 计算投资组合的预期收益率和标准差
  def portfolio_return(weights, assets):
      return np.sum(weights * [assets[i]['预期收益率'] for i in weights.index])
  
  def portfolio_risk(weights, assets):
      cov_matrix = np.array([[assets[i]['标准差']**2 for i in weights.index] for _ in range(len(weights))])
      return np.sqrt(weights.T @ cov_matrix @ weights)
  
  # 示例权重：股票、债券、房地产各占40%、30%、30%
  weights = pd.Series({'股票': 0.4, '债券': 0.3, '房地产': 0.3})
  print(f"预期收益率：{portfolio_return(weights, [stocks, bonds, real_estate])}")
  print(f"标准差：{portfolio_risk(weights, [stocks, bonds, real_estate])}")
  ```
