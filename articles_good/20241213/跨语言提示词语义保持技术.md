#### 2.1 跨语言提示词定义

跨语言提示词是指在不同语言中具有相似或相同功能的词语或短语。它们在跨语言交流中起到了引导和指示的作用，帮助说话者传达意图，帮助听者理解内容。例如，英语中的“hello”在中文中对应“你好”，都是用于打招呼的词语。跨语言提示词可以是单个词汇，也可以是短语，甚至是句子。

#### 2.2 语义保持的基本原理

语义保持是指在跨语言转换过程中，保持原始文本的语义完整性。语义保持的基本原理包括以下几个方面：

1. **词汇映射**：通过建立不同语言之间的词汇映射关系，将源语言中的词汇映射到目标语言中。
2. **上下文理解**：利用上下文信息，理解词汇在不同语境中的具体含义，从而避免翻译错误。
3. **文化适应性**：考虑目标语言和文化背景，对翻译结果进行适当调整，使其更符合目标语言的语义表达。
4. **语义网构建**：通过语义网技术，将词汇、短语和句子之间的关系进行建模，实现语义的深度理解。

- **形容词**：形容词用来描述名词的特征或状态，但不同语言中的形容词用法和表达方式也有所不同。例如，英语中的“happy”（快乐的）和汉语中的“快乐”在语义上相似，但在语法位置和修饰对象上有所不同。

#### 4.1 提示词语义表示模型

提示词语义表示模型用于描述源语言提示词的语义特征。一个常见的表示方法是基于词向量模型，如Word2Vec、GloVe等。这些模型通过将词语映射到高维空间中的点，来表示其语义特征。

数学表示：
\[ \text{vec}(w) = \text{word2vec}(w) \]
其中，\(\text{vec}(w)\) 表示词语 \(w\) 的词向量表示，\(\text{word2vec}(w)\) 是一个向量空间中的高维向量。

举例：
假设英语中的“happy”和“joyful”在语义上有相似性，通过词向量模型，我们可以得到如下表示：

\[ \text{vec}(happy) = \text{[0.1, 0.2, 0.3, ...]} \]
\[ \text{vec}(joyful) = \text{[0.1, 0.3, 0.4, ...]} \]

可以看出，这两个词的词向量在某些维度上有较高的相似度，从而表明它们在语义上的相似性。

#### 4.2 跨语言映射模型

跨语言映射模型用于描述源语言和目标语言之间的语义映射关系。常见的跨语言映射方法包括基于翻译模型的翻译矩阵和基于深度学习的映射网络。

数学表示：
\[ \text{map}(w_s, w_t) = \text{翻译模型}(w_s, w_t) \]
其中，\(w_s\) 表示源语言中的词语，\(w_t\) 表示目标语言中的词语，\(\text{翻译模型}(w_s, w_t)\) 是一个将源语言词语映射到目标语言词语的函数。

举例：
假设我们有一个英语到中文的翻译矩阵，其中包含以下映射关系：

\[ \text{map}(happy, happy) = \text{[0.9, 0.0, 0.1]} \]
\[ \text{map}(happy, joyful) = \text{[0.2, 0.8, 0.0]} \]

这表明在英语中，词语“happy”在中文中映射为“快乐”的概率最高（0.9），而映射为“joyful”的概率较低（0.0）。

#### 4.3 语义保持评估模型

语义保持评估模型用于评估跨语言映射的语义保持效果。一个常见的评估方法是基于语义相似度计算，如余弦相似度、欧氏距离等。

数学表示：
\[ \text{similarity}(\text{vec}(w_s), \text{vec}(w_t)) = \text{相似度函数}(\text{vec}(w_s), \text{vec}(w_t)) \]
其中，\(\text{vec}(w_s)\) 和 \(\text{vec}(w_t)\) 分别表示源语言和目标语言中词语的词向量，\(\text{相似度函数}(\text{vec}(w_s), \text{vec}(w_t))\) 是一个计算词向量相似度的函数。

举例：
假设我们有两个词向量：

\[ \text{vec}(happy) = \text{[0.1, 0.2, 0.3, ...]} \]
\[ \text{vec}(happy\_zh) = \text{[0.3, 0.4, 0.5, ...]} \]

我们可以使用余弦相似度来计算这两个向量的相似度：

\[ \text{similarity}(\text{vec}(happy), \text{vec}(happy\_zh)) = \frac{\text{vec}(happy) \cdot \text{vec}(happy\_zh)}{||\text{vec}(happy)|| \cdot ||\text{vec}(happy\_zh)||} \]

通过计算得到的相似度值可以用来评估语义保持的效果。相似度值越高，说明跨语言映射的语义保持效果越好。

**4.4.3 语义保持评估模型**

关键公式：

讲解：

    entities = [(ent.text, ent.label_) for ent in doc.ents]

    context = " ".join([token.text for token in doc])
    
    return entities, context
