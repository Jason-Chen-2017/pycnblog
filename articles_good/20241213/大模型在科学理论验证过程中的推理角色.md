#### 4.1 大模型的基本数学模型

大模型的数学基础主要包括以下几个关键组成部分：激活函数、损失函数和优化算法。以下是对这些组成部分的详细解释。

#### 4.1.1 激活函数

激活函数是神经网络中的一个关键组件，它用于引入非线性特性，使神经网络能够拟合复杂的非线性关系。常见的激活函数包括：

1. **ReLU（Rectified Linear Unit）**：
   - **公式**：\[ f(x) = \max(0, x) \]
   - **作用**：ReLU函数在输入为负值时输出为零，在输入为正值时输出输入值。它具有简单的形式和高效的计算速度，同时能够避免梯度消失问题。

2. **Sigmoid**：
   - **公式**：\[ f(x) = \frac{1}{1 + e^{-x}} \]
   - **作用**：Sigmoid函数将输入映射到（0，1）区间，常用于二分类问题。然而，Sigmoid函数容易导致梯度消失。

3. **Tanh（Hyperbolic Tangent）**：
   - **公式**：\[ f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} \]
   - **作用**：Tanh函数类似于Sigmoid函数，但其输出范围是（-1，1），可以缓解梯度消失问题。

4. **Leaky ReLU**：
   - **公式**：\[ f(x) = \max(0.01x, x) \]
   - **作用**：Leaky ReLU在ReLU的基础上加入一个很小的斜率（0.01），解决了ReLU在输入为负值时的梯度消失问题。

#### 4.1.2 损失函数

损失函数是衡量模型预测值与真实值之间差异的度量，它在训练过程中起着核心作用。常见的损失函数包括：

1. **均方误差（Mean Squared Error, MSE）**：
   - **公式**：\[ MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2 \]
   - **作用**：MSE是回归任务中最常用的损失函数，它能够衡量预测值与真实值之间的平方误差。

2. **交叉熵损失（Cross-Entropy Loss）**：
   - **公式**：\[ CE = -\sum_{i=1}^{n}y_i\log(\hat{y}_i) \]
   - **作用**：交叉熵损失函数常用于分类任务，它能够衡量实际输出与预测输出之间的差异。

3. **Hinge损失（Hinge Loss）**：
   - **公式**：\[ Hinge = \max(0, 1 - y\hat{y}) \]
   - **作用**：Hinge损失函数在支持向量机（SVM）中应用广泛，用于优化分类模型的边界。

#### 4.1.3 优化算法

优化算法用于最小化损失函数，调整模型参数以获得更好的预测性能。常见的优化算法包括：

1. **梯度下降（Gradient Descent）**：
   - **公式**：\[ \theta = \theta - \alpha \nabla_{\theta} J(\theta) \]
   - **作用**：梯度下降是一种基于梯度的优化方法，通过不断更新参数以减小损失函数值。

2. **随机梯度下降（Stochastic Gradient Descent, SGD）**：
   - **公式**：\[ \theta = \theta - \alpha \nabla_{\theta} J(\theta; x^{(i)}, y^{(i)}) \]
   - **作用**：SGD是在梯度下降的基础上，每次迭代只随机选择一个小批量样本进行参数更新，提高了计算效率。

3. **Adam优化器**：
   - **公式**：\[ \theta = \theta - \alpha \frac{m}{1 - \beta_1^t} + \beta_2 \nabla_{\theta} J(\theta; x, y) \]
   - **作用**：Adam优化器结合了SGD和动量方法，能够更好地处理稀疏梯度，在许多任务中表现出色。

import tensorflow as tf

import numpy as np

              loss='categorical_crossentropy',
              metrics=['accuracy'])

model.fit(x_train, y_train, epochs=10, batch_size=64)

# 验证模型

print(f"Test accuracy: {test_acc:.4f}")

```python
import tensorflow as tf
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense, Conv2D, Flatten, MaxPooling2D
import numpy as np

# 数据预处理
def preprocess_data(data):
    # 数据清洗和归一化
    data = data.astype("float32")
    data = (data - np.mean(data)) / np.std(data)
    return data

# 加载QM4Chem数据集
data = np.load("qm4chem_data.npy")
X = preprocess_data(data[:, :10000])  # 特征数据
y = preprocess_data(data[:, 10000:])   # 标签数据

# 构建模型
input_shape = (X.shape[1],)
input_layer = Input(shape=input_shape)
x = Conv2D(32, (3, 3), activation='relu')(input_layer)
x = MaxPooling2D((2, 2))(x)
x = Conv2D(64, (3, 3), activation='relu')(x)
x = MaxPooling2D((2, 2))(x)
x = Flatten()(x)
x = Dense(64, activation='relu')(x)
output_layer = Dense(1, activation='sigmoid')(x)

model = Model(inputs=input_layer, outputs=output_layer)
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

# 训练模型
model.fit(X, y, epochs=10, batch_size=32)

# 验证模型
loss, accuracy = model.evaluate(X, y)
print(f"Validation loss: {loss:.4f}, Validation accuracy: {accuracy:.4f}")
```
