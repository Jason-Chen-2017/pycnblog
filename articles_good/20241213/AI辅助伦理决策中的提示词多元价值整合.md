   其中，$f(x)$ 是总目标函数，$w_i$ 是第 $i$ 个目标的权重，$f_i(x)$ 是第 $i$ 个目标函数。

2. **目标函数示例**

   假设我们有两个主要价值取向：成本（$C$）和效率（$E$），每个价值取向可以分别定义其目标函数：

   $$C(x) = \alpha \cdot C_1 + (1 - \alpha) \cdot C_2$$

   $$E(x) = \beta \cdot E_1 + (1 - \beta) \cdot E_2$$

   其中，$\alpha$ 和 $\beta$ 分别代表成本和效率的权重系数，$C_1$ 和 $C_2$ 是两个成本值，$E_1$ 和 $E_2$ 是两个效率值。

3. **权重系数调整**

   权重系数 $\alpha$ 和 $\beta$ 需要根据具体情境进行调整，以确保在多个价值取向之间实现平衡。一个常见的调整方法是使用线性加权法：

   $$w_i = \frac{\alpha_i}{\sum_{i=1}^{n} \alpha_i}$$

   其中，$\alpha_i$ 是第 $i$ 个目标的权重系数。

4. **约束条件**

   在实际应用中，我们还需要考虑一些约束条件，例如资源限制、法律法规要求等。约束条件可以表示为：

   $$g_i(x) \leq 0$$

   其中，$g_i(x)$ 是第 $i$ 个约束条件。

```python
# 导入相关库
import numpy as np
import scipy.optimize as spo
from sklearn.metrics.pairwise import euclidean_distances
import matplotlib.pyplot as plt

# 定义目标函数
def objective_function(values, patients, resources):
    # values: [成本，效率]
    # patients: 患者数据列表
    # resources: 资源数据列表
    costs = [patient['cost'] for patient in patients]
    efficiencies = [resource['efficiency'] for resource in resources]
    alpha = 0.5  # 成本权重
    beta = 0.5   # 效率权重
    cost = alpha * values[0]
    efficiency = beta * values[1]
    return 1 / (cost + efficiency)

# 定义约束条件
def constraints(values, patients, resources):
    # values: [成本，效率]
    # patients: 患者数据列表
    # resources: 资源数据列表
    constraints = []
    for patient in patients:
        constraints.append(patient['cost'] - values[0])
    for resource in resources:
        constraints.append(resource['efficiency'] - values[1])
    return constraints

# 初始化患者和资源数据
patients = [
    {'id': 1, 'name': 'Alice', 'cost': 500, 'medical_condition': '紧急'},
    {'id': 2, 'name': 'Bob', 'cost': 300, 'medical_condition': '一般'},
    {'id': 3, 'name': 'Charlie', 'cost': 200, 'medical_condition': '轻微'}
]

resources = [
    {'id': 1, 'type': '床位', 'quantity': 3, 'efficiency': 0.8},
    {'id': 2, 'type': '医生', 'quantity': 2, 'efficiency': 0.6},
    {'id': 3, 'type': '护士', 'quantity': 5, 'efficiency': 0.7}
]

# 执行多目标优化
bounds = [(0, 1000), (0, 1)]
result = spo.differential_evolution(objective_function, bounds, constraints=constraints, args=(patients, resources))

# 输出最优解
print("最优解：", result.x)

# 绘制决策结果
values = result.x
plt.bar(['成本', '效率'], values)
plt.xlabel('价值类型')
plt.ylabel('值')
plt.title('最优资源分配决策')
plt.show()
```
