## 第一部分：类型论的概述与历史

### 1.1 类型论的基本概念

类型论（Type Theory）是一种形式化的数学理论，旨在对对象和概念进行分类和结构化。在类型论中，每个对象都被赋予一个类型，类型定义了对象的性质和行为。类型论起源于20世纪30年代的逻辑学和数学基础研究，是对经典逻辑和集合论的扩展。

类型论的基本概念包括：

- **类型**：类型是对象的分类标准，用于区分不同对象。例如，在整数类型和实数类型之间，我们可以定义一个类型系统，确保对象不会被错误地赋值或操作。

- **类型构造**：类型可以通过构造操作来生成新的类型。常见的构造操作包括交集、并集、积类型等。

- **类型判断**：类型判断是类型论中的核心概念，用于确定对象是否属于某个类型。

类型论的发展历程可以追溯到以下几位重要人物的工作：

- **Turing**：Turing在1936年提出了图灵机模型，这一模型为类型论的发展奠定了基础。

- **Church**：Church在1936年提出了λ演算，这是一种形式化的计算模型，对类型论的发展产生了深远影响。

- **Curry**：Curry在1925年提出了组合演算，这是类型论的一个重要分支，对计算机科学和数学领域产生了重要影响。

类型论在数学中的应用包括以下几个方面：

            raise ValueError("Unsupported operator")

    def check_operand(self, operand):
        if isinstance(operand, int):
            return 'int'
        elif isinstance(operand, str):
            return 'str'
        else:
            raise TypeError("Unsupported operand type")

class Expression:
    def __init__(self, operand1, operand2, operator):
        self.operand1 = operand1
        self.operand2 = operand2
        self.operator = operator

def main():
    checker = TypeChecker()
    checker.declare_variable('x', 'int')
    checker.declare_variable('y', 'int')

    expression1 = Expression(10, 20, '+')
    print(checker.check_expression(expression1))  # 应该输出'int'

    expression2 = Expression('hello', 'world', '+')
    print(checker.check_expression(expression2))  # 应该抛出TypeError

if __name__ == '__main__':
    main()
