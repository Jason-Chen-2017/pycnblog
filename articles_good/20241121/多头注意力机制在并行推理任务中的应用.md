# 第二章：多头注意力机制算法原理

## 2.1 多头注意力机制的核心算法原理

### 2.1.1 自注意力机制

- 自注意力机制是多头注意力机制的基础，它通过计算序列中每个元素之间的相似性来生成注意力权重。

### 2.1.2 伪代码

- 以下是一个简化版的伪代码，展示自注意力机制的计算过程：

```python
def self_attention(q, k, v):
    # 计算查询向量和键向量的点积
    scores = q * k

    # 应用 Softmax 函数得到注意力权重
    attention_weights = softmax(scores)

    # 使用注意力权重对值向量进行加权求和
    output = attention_weights * v

    return output
```

### 2.1.3 多头注意力机制

- 多头注意力机制通过扩展自注意力机制，允许模型在多个子空间中学习注意力权重，从而提高模型的表示能力和泛化能力。

### 2.1.4 伪代码

- 以下是一个简化版的伪代码，展示多头注意力机制的计算过程：

```python
def multi_head_attention(q, k, v, num_heads):
    # 计算每个查询向量在每个子空间中的自注意力权重
    head_scores = [q * k] * num_heads

    # 应用 Softmax 函数得到每个子空间的注意力权重
    head_attention_weights = [softmax(h_scores) for h_scores in head_scores]

    # 使用注意力权重对每个子空间中的值向量进行加权求和
    head_outputs = [h_weights * v for h_weights in head_attention_weights]

    # 将每个子空间中的输出拼接起来
    output = concatenate(head_outputs)

    return output
```

# 第三章：多头注意力机制的数学模型

## 3.1 多头注意力机制的数学模型

### 3.1.1 自注意力权重计算

- 自注意力权重计算公式如下：

$$
\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

其中，$Q$ 是查询向量，$K$ 是键向量，$V$ 是值向量，$d_k$ 是键向量的维度。

### 3.1.2 多头注意力权重计算

- 多头注意力权重计算公式如下：

$$
\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \text{head}_2, ..., \text{head}_h)W^O
$$

其中，$h$ 是头数，$W^O$ 是输出权重矩阵。

### 3.1.3 举例说明

- 假设我们有一个序列 $x_1, x_2, ..., x_n$，我们需要计算序列中的每个元素 $x_i$ 的自注意力权重。

- 首先，我们将序列中的每个元素 $x_i$ 映射为一个查询向量 $q_i$，一个键向量 $k_i$，和一个值向量 $v_i$。

- 然后，我们使用自注意力权重计算公式计算每个元素 $x_i$ 的自注意力权重：

$$
\text{Attention}(q_i,k_i,v_i) = \text{softmax}\left(\frac{q_i k_i^T}{\sqrt{d_k}}\right)v_i
$$

- 最后，我们将所有元素 $x_i$ 的自注意力权重拼接起来，得到整个序列的自注意力权重：

$$
\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QQ^T}{\sqrt{d_k}}\right)V
$$

### 4.2.1 多头注意力层

- 我们将实现一个多头注意力层，其代码如下：

```python
import torch
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super(MultiHeadAttention, self).__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads

        self.query_linear = nn.Linear(d_model, d_model)
        self.key_linear = nn.Linear(d_model, d_model)
        self.value_linear = nn.Linear(d_model, d_model)

        self.out_linear = nn.Linear(d_model, d_model)

    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)

        query = self.query_linear(query).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        key = self.key_linear(key).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        value = self.value_linear(value).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)

        attn_scores = torch.matmul(query, key.transpose(-2, -1)) / (self.head_dim ** 0.5)

        if mask is not None:
            attn_scores = attn_scores.masked_fill(mask == 0, float("-inf"))

        attn_weights = torch.softmax(attn_scores, dim=-1)
        attn_output = torch.matmul(attn_weights, value).transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)

        attn_output = self.out_linear(attn_output)

        return attn_output
```

class TextClassifier(nn.Module):
