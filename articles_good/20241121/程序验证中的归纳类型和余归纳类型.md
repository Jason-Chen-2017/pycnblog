### 2.1 归纳类型的定义与性质

归纳类型是一种数学推理方法，用于证明某个陈述对于所有自然数都成立。归纳类型的基本步骤包括：

1. **基例**：证明当输入为最小值（通常为0或1）时，陈述成立。
2. **归纳假设**：假设当输入为某个值n时，陈述成立。
3. **归纳步骤**：证明当输入为n+1时，陈述也成立。

归纳类型的性质包括：

- **无二义性**：如果归纳类型证明成立，则陈述对于所有自然数都成立。
- **不可破性**：一旦找到反例，归纳类型证明即失效。

余归纳类型是一种类似于归纳类型的证明方法，但它的基例和归纳假设有所不同。余归纳类型的基本步骤包括：

3. **归纳步骤**：证明当输入为n-1时，陈述也不成立。

### 5.1 归纳类型在简单程序验证中的应用

让我们从一个简单的程序开始，该程序用于计算斐波那契数列。

```python
def fibonacci(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibonacci(n - 1) + fibonacci(n - 2)
```

我们需要证明该程序的正确性，即对于所有非负整数n，fibonacci(n)都返回正确的斐波那契数。

**基例**：当n=0时，fibonacci(0)=0，符合斐波那契数列的定义。当n=1时，fibonacci(1)=1，也符合定义。

**归纳假设**：假设当n=k时，fibonacci(k)返回正确的斐波那契数。

**归纳步骤**：我们需要证明当n=k+1时，fibonacci(k+1)也返回正确的斐波那契数。

根据递归定义，fibonacci(k+1) = fibonacci(k) + fibonacci(k-1)。根据归纳假设，fibonacci(k)和fibonacci(k-1)都返回正确的斐波那契数，因此fibonacci(k+1)也返回正确的斐波那契数。

因此，通过归纳类型，我们证明了该程序的正确性。
