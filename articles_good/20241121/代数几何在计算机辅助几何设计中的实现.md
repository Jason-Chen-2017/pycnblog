#### 6.1 代数几何中的数学模型

**多项式方程**：
```latex
P(x) = a_nx^n + a_{n-1}x^{n-1} + \ldots + a_1x + a_0 = 0
```

**参数方程**：
```latex
\begin{cases}
x(t) = x(t) \\
y(t) = y(t) \\
z(t) = z(t)

```

**曲面方程**：

#### 6.2 数学公式与定理的详细讲解

**韦尔斯特拉斯定理**：
```latex
\text{给定一个代数曲线 } C, \text{存在一条与之同宿的双曲曲线 } C'.
```

**曲率公式**：
```latex
K(t) = \frac{\kappa_p \kappa_v - \kappa_{pv}}{(\kappa_p^2 + \kappa_v^2)^{3/2}}
```

**挠率公式**：
```latex
T(t) = \frac{\kappa_p^2 - \kappa_v^2}{(\kappa_p^2 + \kappa_v^2)^{3/2}}
```
