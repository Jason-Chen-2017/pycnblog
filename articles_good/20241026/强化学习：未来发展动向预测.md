                 

### 第4章：深度强化学习

深度强化学习（Deep Reinforcement Learning，简称DRL）是强化学习领域的一个重要分支，它将深度学习的强大表示能力与强化学习的决策优化能力相结合，能够处理高维的状态和动作空间问题。本章将深入探讨深度强化学习的基本原理、核心算法，以及如何应用于复杂问题。

#### 4.1 深度强化学习的基本原理

深度强化学习的核心思想是利用深度神经网络（DNN）来近似Q函数，即状态-动作值函数（State-Action Value Function），从而在复杂的动态环境中进行有效的决策。DRL的基本原理可以概括为以下几点：

1. **状态编码**：使用深度神经网络将高维状态编码为低维特征向量，使得智能体能够更好地理解和处理状态信息。

2. **价值函数近似**：利用深度神经网络来近似Q函数，即\( Q(s, a) \)，预测在给定状态和动作下能够获得的累积奖励。

3. **策略优化**：通过策略梯度方法或者其他优化算法，不断调整神经网络的参数，以优化智能体的策略，使其能够最大化累积奖励。

4. **探索与利用**：在训练过程中，需要平衡探索新状态和利用已有知识，以便智能体能够快速适应环境。

5. **经验回放**：为了避免样本的相关性，DRL算法通常使用经验回放机制，将过去经历的经验进行随机抽样，从而提高学习效率。

深度强化学习的基本模型通常包括以下几个部分：

- **智能体（Agent）**：执行行动的实体，通过学习环境中的状态-动作值函数来优化其行为。
- **环境（Environment）**：智能体进行交互的实体，提供状态、动作空间以及奖励信号。
- **状态（State）**：描述智能体在环境中的状态，通常由一组特征向量表示。
- **动作（Action）**：智能体可以执行的操作，可以是离散的，也可以是连续的。
- **奖励（Reward）**：环境对智能体行为的即时反馈，用于指导智能体的学习。
- **策略（Policy）**：智能体在给定状态下选择动作的规则，可以是确定性策略或随机策略。
- **价值函数（Value Function）**：评估在给定状态下采取特定动作所能获得的期望累积奖励。
- **模型（Model）**：环境状态转移和奖励的预测模型。

#### 4.2 DQN算法详解

DQN（Deep Q-Network）是深度强化学习领域最著名的算法之一，由DeepMind提出。DQN的核心思想是使用深度神经网络来近似Q函数，并通过经验回放和目标网络来稳定Q值的学习过程。

##### 4.2.1 DQN算法的核心原理

DQN算法的主要步骤如下：

1. **初始化**：
   - 初始化深度神经网络\( Q \)的参数。
   - 初始化经验回放记忆池\( D \)。
   - 初始化目标神经网络\( Q^{\prime} \)。

2. **环境交互**：
   - 在初始状态下\( s \)，执行随机动作\( a \)。
   - 执行动作\( a \)，观察状态转移\( (s', a', r) \)。

3. **经验回放**：
   - 将\( (s, a, r, s') \)存入经验回放记忆池\( D \)。

4. **Q值更新**：
   - 从经验回放记忆池中随机抽取一批经验\( (s_i, a_i, r_i, s_i') \)。
   - 计算目标Q值：
     $$ Q^{\prime}(s_i, a_i) = r_i + \gamma \max_{a_i'} Q^{\prime}(s_i', a_i') $$
   - 更新Q值：
     $$ Q(s_i, a_i) \leftarrow Q(s_i, a_i) + \alpha [Q^{\prime}(s_i, a_i) - Q(s_i, a_i)] $$

5. **目标网络更新**：
   - 以固定的间隔更新目标神经网络\( Q^{\prime} \)的参数，使其跟踪Q网络的更新。

##### 4.2.2 经验回放与目标网络

经验回放（Experience Replay）是DQN算法中的一个重要机制，它通过将过去的经验进行随机抽样，减少了样本之间的相关性，从而提高了学习效率。经验回放机制能够模拟一个无限大的记忆池，使得智能体能够在训练过程中从更多的样本中学习。

目标网络（Target Network）是DQN算法的另一个关键组件，它通过定期更新，提供了一个稳定的Q值目标，用于Q值的更新过程。目标网络的目的是减少Q值的更新过程中的方差，提高算法的稳定性和收敛速度。

##### 4.2.3 DQN算法的伪代码

```plaintext
初始化 Q网络，目标Q网络，经验回放池D
对于每一个步骤 t：
    如果随机抽样：
        从D中随机抽取 (s_t, a_t, r_t, s_{t+1})
    否则：
        执行动作 a_t = epsilon-greedy策略(s_t)
        执行动作，获得 r_t 和 s_{t+1}
        存入经验池D
        选择下一动作 a_{t+1} = epsilon-greedy策略(s_{t+1})
        更新Q值：
            Q(s_t, a_t) = Q(s_t, a_t) + alpha * [r_t + gamma * max(Q(s_{t+1}, a_{t+1})) - Q(s_t, a_t)]
    更新目标网络参数：
        如果是更新周期：
            Q网络参数复制到目标网络
```

#### 4.3 A3C算法与PPO算法

除了DQN算法，深度强化学习领域还有许多其他重要的算法，如A3C（Asynchronous Advantage Actor-Critic）和PPO（Proximal Policy Optimization）。这些算法在分布式训练和策略优化方面进行了改进，使得深度强化学习能够更好地应用于复杂任务。

##### 4.3.1 A3C算法

A3C（Asynchronous Advantage Actor-Critic）是一种异步的深度强化学习算法，它通过并行化训练提高了训练速度。A3C算法的核心思想是多个智能体可以在不同的环境中异步地进行训练，并将各自的梯度更新到一个全局参数上。

A3C算法的主要步骤如下：

1. **初始化**：
   - 初始化多个智能体和相应的神经网络。
   - 初始化经验回放记忆池。

2. **环境交互**：
   - 每个智能体在独立的环境中执行动作，观察状态转移。

3. **梯度计算**：
   - 对于每个智能体，计算梯度并更新其神经网络。

4. **全局同步**：
   - 将各个智能体的神经网络参数同步到一个全局参数上。

A3C算法通过并行训练，提高了训练效率，特别适用于需要大量计算资源的问题。

##### 4.3.2 PPO算法

PPO（Proximal Policy Optimization）是一种改进的策略优化算法，它通过优化策略的更新过程，提高了算法的稳定性和性能。PPO算法的核心思想是使用一个优化步骤来近似策略梯度的更新，从而减少策略更新的方差。

PPO算法的主要步骤如下：

1. **初始化**：
   - 初始化神经网络和经验回放记忆池。

2. **环境交互**：
   - 在环境中执行动作，观察状态转移。

3. **策略优化**：
   - 计算策略梯度：
     $$ \nabla_{\theta} L(\theta) = \frac{\partial L(\theta)}{\partial \theta} $$
   - 使用优化步骤更新策略参数：
     $$ \theta \leftarrow \theta - \alpha \nabla_{\theta} L(\theta) $$

PPO算法通过优化策略的更新过程，提高了算法的收敛速度和稳定性，特别适用于长时间训练的任务。

#### 4.4 深度强化学习应用实例

深度强化学习在许多领域都有广泛的应用，如游戏、机器人、自动驾驶和金融交易等。以下是一些深度强化学习的实际应用实例：

- **游戏**：深度强化学习可以用于开发智能游戏对手，如AlphaGo在围棋比赛中的成功。
- **机器人**：深度强化学习可以用于机器人控制，使其能够自主地执行复杂的任务。
- **自动驾驶**：深度强化学习可以用于自动驾驶车辆的路径规划和决策。
- **金融交易**：深度强化学习可以用于量化交易策略的优化，提高交易收益。

深度强化学习的成功应用不仅展示了其在复杂决策问题中的强大能力，也为未来的研究提供了丰富的机会和挑战。

### 第5章：强化学习的策略优化

策略优化是强化学习中的核心任务之一，其目标是通过学习智能体的策略来最大化累积奖励。策略优化方法可以分为基于价值函数的方法和直接策略优化方法。本章将介绍几种常见的策略优化方法，包括策略梯度方法、REINFORCE算法、信任区域方法和actor-critic方法。

#### 5.1 策略梯度方法

策略梯度方法是一种直接优化策略的方法，其基本思想是通过计算策略的梯度，更新策略参数以最大化累积奖励。策略梯度方法可以分为基于价值函数的策略梯度和直接策略梯度。

##### 5.1.1 基于价值函数的策略梯度

基于价值函数的策略梯度方法使用Q函数或价值函数的梯度来更新策略。具体来说，使用Q值函数\( Q(s, a) \)来评估动作的好坏，并计算策略梯度：

$$
\nabla_{\theta} \log \pi(a|s;\theta) = \nabla_{\theta} \frac{\pi(a|s;\theta)}{\sum_{a'} \pi(a'|s;\theta)} Q(s, a)
$$

其中，\( \pi(a|s;\theta) \)是策略参数\( \theta \)下的策略分布，\( Q(s, a) \)是Q值函数。

基于价值函数的策略梯度的更新公式为：

$$
\theta \leftarrow \theta + \alpha \nabla_{\theta} \log \pi(a|s;\theta) Q(s, a)
$$

##### 5.1.2 直接策略梯度

直接策略梯度方法不依赖于价值函数，而是直接优化策略。其目标是最大化累积奖励的期望，即：

$$
\max_{\theta} \sum_{s,a} \pi(a|s;\theta) [R(s, a) + \gamma V(s)]
$$

直接策略梯度的更新公式为：

$$
\theta \leftarrow \theta + \alpha \sum_{s,a} \pi(a|s;\theta) \nabla_{\theta} \log \pi(a|s;\theta) [R(s, a) + \gamma V(s)]
$$

直接策略梯度方法的一个关键问题是策略的梯度可能不稳定，因此需要使用如渐近策略梯度方法（ASGD）或其他优化技术来稳定策略更新。

#### 5.2 REINFORCE算法

REINFORCE算法是一种基于策略梯度的简单直接策略优化方法，其基本思想是使用奖励的梯度来更新策略参数。REINFORCE算法的更新公式为：

$$
\theta \leftarrow \theta + \alpha \sum_{s,a} \pi(a|s;\theta) R(s, a)
$$

其中，\( R(s, a) \)是立即奖励。

REINFORCE算法的优点是计算简单，但缺点是梯度可能不稳定，特别是在奖励分布不均匀的情况下。为了解决这个问题，可以使用渐近策略梯度方法（ASGD）或LSTM等模型来稳定策略更新。

#### 5.3 信任区域方法（TRPO）

信任区域方法（Trust Region Policy Optimization，简称TRPO）是一种改进的策略优化方法，它通过引入信任区域来稳定策略更新，提高算法的收敛速度。TRPO的核心思想是同时优化策略和价值函数，使它们在梯度方向上保持一致。

TRPO的主要步骤如下：

1. **初始化**：
   - 初始化策略参数\( \theta \)和价值函数参数\( \phi \)。
   - 设置信任区域参数\( \lambda \)。

2. **模拟路径**：
   - 使用当前策略\( \pi_\theta \)模拟一批样本路径。

3. **计算梯度**：
   - 计算策略梯度和价值函数梯度。

4. **优化策略和价值函数**：
   - 在信任区域内，通过梯度上升更新策略参数和价值函数参数。
   - 更新策略参数：
     $$ \theta \leftarrow \theta + \lambda \nabla_{\theta} J(\theta) $$
   - 更新价值函数参数：
     $$ \phi \leftarrow \phi + \lambda \nabla_{\phi} J(\theta) $$

5. **收缩和扩张信任区域**：
   - 根据优化结果，调整信任区域的大小。

TRPO的优点是能够稳定策略更新，提高算法的收敛速度，但缺点是计算复杂度较高，需要多次模拟路径来计算梯度。

#### 5.4 actor-critic方法

actor-critic方法是一种结合策略优化和价值函数学习的方法，其目标是同时优化策略和价值函数，使它们在梯度方向上保持一致。actor-critic方法可以分为基于值函数的actor-critic方法和基于优势函数的actor-critic方法。

##### 5.4.1 基于值函数的actor-critic方法

基于值函数的actor-critic方法使用值函数\( V(s) \)来评估智能体的行为，并使用策略actor来选择动作。其基本步骤如下：

1. **初始化**：
   - 初始化策略参数\( \theta \)和值函数参数\( \phi \)。

2. **环境交互**：
   - 在环境中执行动作，观察状态转移和奖励。

3. **更新值函数**：
   - 使用当前策略和值函数估计期望值：
     $$ V(s) \leftarrow \sum_{a} \pi(a|s;\theta) [R(s, a) + \gamma V(s')] $$
   - 更新值函数参数：
     $$ \phi \leftarrow \phi + \alpha \nabla_{\phi} V(s) $$

4. **更新策略**：
   - 使用更新后的值函数，更新策略参数：
     $$ \theta \leftarrow \theta + \lambda \nabla_{\theta} J(\theta) $$

##### 5.4.2 基于优势函数的actor-critic方法

基于优势函数的actor-critic方法使用优势函数\( A(s, a) \)来评估智能体的行为，并使用策略actor来选择动作。其基本步骤如下：

1. **初始化**：
   - 初始化策略参数\( \theta \)和值函数参数\( \phi \)。

2. **环境交互**：
   - 在环境中执行动作，观察状态转移和奖励。

3. **更新优势函数**：
   - 使用当前策略和价值函数估计优势函数：
     $$ A(s, a) = Q(s, a) - V(s) $$
   - 更新优势函数参数：
     $$ \phi \leftarrow \phi + \alpha \nabla_{\phi} A(s, a) $$

4. **更新策略**：
   - 使用更新后的优势函数，更新策略参数：
     $$ \theta \leftarrow \theta + \lambda \nabla_{\theta} J(\theta) $$

actor-critic方法通过同时优化策略和价值函数，提高了智能体的学习效率，特别适用于复杂的动态环境。

#### 5.5 策略优化方法比较

策略优化方法各有优缺点，具体选择取决于问题的性质和应用场景：

- **策略梯度方法**：计算简单，但梯度可能不稳定，适用于简单的环境。
- **REINFORCE算法**：计算简单，但梯度可能不稳定，适用于简单环境。
- **TRPO算法**：稳定策略更新，计算复杂，适用于复杂环境。
- **actor-critic方法**：结合策略和价值函数优化，适用于复杂环境。

综上所述，策略优化方法是强化学习中重要的组成部分，通过不同的优化方法，智能体能够在复杂动态环境中学习到有效的策略，从而实现最优决策。

### 第6章：多智能体强化学习

多智能体强化学习（Multi-Agent Reinforcement Learning，简称MARL）是强化学习领域的一个重要分支，它研究多个智能体在不确定环境中通过学习相互协作或竞争，以实现共同目标或个体目标。本章将介绍多智能体强化学习的基本概念、挑战、交互机制以及经典算法。

#### 6.1 多智能体强化学习的挑战

多智能体强化学习面临以下挑战：

1. **环境复杂性**：多智能体系统通常具有复杂的状态空间和动作空间，这增加了学习的难度。
2. **相互作用**：智能体之间的相互作用会影响其学习结果，需要考虑合作与竞争的关系。
3. **通信限制**：在某些场景中，智能体之间的通信可能受限，这增加了协调和决策的难度。
4. **不确定性**：环境中的不确定性和其他智能体的行为增加了学习的复杂性。
5. **平衡**：在合作与竞争之间需要找到平衡点，以实现集体最优或个体最优。

#### 6.2 多智能体交互机制

多智能体交互机制是多智能体强化学习的核心，主要包括以下几种：

1. **协同机制**：智能体通过合作实现共同目标，如路径规划、资源分配等。
2. **竞争机制**：智能体在资源有限的场景中竞争，如拍卖、市场竞争等。
3. **协调机制**：智能体通过通信和协调机制，以实现共同目标，如多机器人协同、多无人机编队等。
4. **竞争-合作机制**：智能体在部分场景中既有竞争又有合作，如多智能体博弈、多人游戏等。

多智能体交互机制通常通过以下方式实现：

- **状态共享**：智能体共享部分或全部状态信息，以提高决策效率。
- **协调策略**：设计协调策略，以解决多智能体协作问题。
- **分布式学习**：智能体在本地更新策略，并通过通信进行全局同步。

#### 6.3 经典多智能体算法介绍

多智能体强化学习领域有许多经典的算法，下面介绍几种常用的算法：

1. **马尔可夫决策过程（MDP）**：

   MDP是描述多智能体强化学习问题的基本模型，它包括状态、动作、奖励和状态转移概率。多智能体MDP通过扩展单智能体MDP的模型来描述多个智能体之间的交互。

2. **分布式学习算法**：

   分布式学习算法通过在多个智能体之间共享信息，实现协同学习和决策。常见的分布式学习算法包括分布式Q-learning、分布式策略梯度方法等。

3. **多智能体DQN算法**：

   多智能体DQN算法是DQN算法在多智能体环境中的应用，它使用深度神经网络来近似Q值函数，并通过经验回放和目标网络来稳定学习过程。

4. **多智能体A3C算法**：

   多智能体A3C算法是A3C算法在多智能体环境中的应用，它通过异步并行训练，提高训练速度和性能。

5. **多智能体PPO算法**：

   多智能体PPO算法是PPO算法在多智能体环境中的应用，它通过优化策略和价值函数，实现稳定和高效的策略更新。

6. **合作性博弈算法**：

   合作性博弈算法用于解决多智能体合作问题，常见的算法包括多智能体Q-learning、多智能体策略梯度方法等。

#### 6.4 多智能体强化学习的应用

多智能体强化学习在多个领域都有广泛的应用，如：

- **多机器人协同**：在工业自动化、救援任务、物流配送等领域，多智能体强化学习用于实现多机器人之间的协调和任务分配。

#### 7.1 游戏强化学习概述

游戏强化学习（Game Reinforcement Learning，简称Game RL）是强化学习在游戏领域的重要应用，它通过智能体在游戏环境中的自主学习和决策，实现游戏的人工智能对手。游戏强化学习的目标是让智能体在未知环境中，通过试错和经验积累，学会策略以最大化累积奖励。

游戏强化学习的核心组件包括：

- **智能体（Agent）**：执行行动并从环境中接收奖励的实体。
- **环境（Environment）**：模拟游戏世界的状态、动作和奖励机制。
- **状态（State）**：描述智能体在游戏中的位置、资源、分数等信息。
- **动作（Action）**：智能体可以执行的操作，如移动、攻击、防御等。
- **策略（Policy）**：智能体在给定状态下选择动作的规则。
- **价值函数（Value Function）**：评估智能体在特定状态下执行最佳动作所能获得的累积奖励。
- **模型（Model）**：对环境动态的预测，包括状态转移概率和奖励预期。

##### A.1.1 Q-Learning算法

```python
import numpy as np

def q_learning(env, num_episodes, learning_rate=0.1, discount_factor=0.9, exploration_rate=1.0):
    Q = np.zeros((env.num_states, env.num_actions))
    for episode in range(num_episodes):
        state = env.reset()
        done = False
        while not done:
            action = select_action(Q, state, exploration_rate)
            next_state, reward, done = env.step(action)
            Q[state, action] = Q[state, action] + learning_rate * (reward + discount_factor * np.max(Q[next_state]) - Q[state, action])
            state = next_state
        exploration_rate *= 0.99  # 逐步减少探索概率
    return Q

def select_action(Q, state, exploration_rate):
    if np.random.rand() < exploration_rate:
        action = env.action_space.sample()
    else:
        action = np.argmax(Q[state])
    return action
```

```python
        while not done:
            action = select_action(Q, state)
            next_state, reward, done = env.step(action)
            next_action = select_action(Q, next_state)
            Q[state, action] = Q[state, action] + learning_rate * (reward + discount_factor * Q[next_state, next_action] - Q[state, action])
            state = next_state
            action = next_action
    return Q

def select_action(Q, state):
    return np.argmax(Q[state])
```

#### A.2 深度强化学习算法代码实现

以下展示了如何实现深度强化学习的DQN算法。

##### A.2.1 DQN算法

```python
import numpy as np
import random
from collections import deque
from keras.models import Sequential
from keras.layers import Dense, Conv2D, Flatten
from keras.optimizers import Adam

def dqn_learning(env, num_episodes, learning_rate=0.001, discount_factor=0.9, epsilon=1.0, epsilon_min=0.01, epsilon_decay=0.995, replay_memory_size=10000):
    # 初始化神经网络和经验回放
    model = build_dqn_model()
    optimizer = Adam(learning_rate)
    memory = deque(maxlen=replay_memory_size)
    
    for episode in range(num_episodes):
        state = env.reset()
        done = False
        total_reward = 0
        
        while not done:
            # 选择动作
            if np.random.rand() < epsilon:
                action = env.action_space.sample()
            else:
                action = np.argmax(model.predict(state.reshape(1, *state.shape)))
            
            # 执行动作
            next_state, reward, done, _ = env.step(action)
            total_reward += reward
            
            # 更新经验回放
            memory.append((state, action, reward, next_state, done))
            
            if len(memory) > replay_memory_size:
                memory.popleft()
            
            # 训练模型
            if len(memory) > batch_size:
                batch = random.sample(memory, batch_size)
                states, actions, rewards, next_states, dones = zip(*batch)
                target_q_values = model.predict(np.array(next_states))
                target_q_values = np.array(target_q_values)
                target_q_values[dones] = 0
                target_q_values[~dones] = rewards + discount_factor * np.max(target_q_values[~dones], axis=1)
                model.fit(np.array(states), np.array(target_q_values), verbose=0)
            
            state = next_state
        
        epsilon *= epsilon_decay
        epsilon = max(epsilon_min, epsilon)
        
        print(f"Episode {episode + 1}, Total Reward: {total_reward}")

def build_dqn_model(input_shape):
    model = Sequential()
    model.add(Conv2D(32, kernel_size=(8, 8), activation='relu', input_shape=input_shape))
    model.add(Conv2D(64, kernel_size=(4, 4), activation='relu'))
    model.add(Conv2D(64, kernel_size=(3, 3), activation='relu'))
    model.add(Flatten())
    model.add(Dense(512, activation='relu'))
    model.add(Dense(env.num_actions, activation='linear'))
    model.compile(loss='mse', optimizer=optimizer)
    return model
```

##### A.2.2 A3C算法

```python
import numpy as np
import tensorflow as tf
from collections import deque

def a3c_learning(env, num_episodes, learning_rate=0.001, discount_factor=0.99, max_steps=100):
    global_step = 0
    policy_network = build_policy_network()
    value_network = build_value_network()
    optimizer = tf.keras.optimizers.Adam(learning_rate)
    reward_memory = deque(maxlen=100)

    for episode in range(num_episodes):
        state = env.reset()
        total_reward = 0
        for step in range(max_steps):
            global_step += 1
            action, value, policy = select_action(policy_network, value_network, state)
            next_state, reward, done, _ = env.step(action)
            total_reward += reward

            # 计算优势值
            if done:
                advantage = reward
            else:
                next_value = value(next_state)
                advantage = reward + discount_factor * next_value - value(state)

            # 更新策略和价值网络
            with tf.GradientTape() as tape:
                log_prob = policy.log_prob(action)
                value_loss = tf.reduce_mean(tf.square(value(state) - reward - discount_factor * next_value))
                policy_loss = -tf.reduce_mean(log_prob * (reward + discount_factor * next_value - value(state)))
                loss = policy_loss + value_loss

            gradients = tape.gradient(loss, policy_network.trainable_variables + value_network.trainable_variables)
            optimizer.apply_gradients(zip(gradients, policy_network.trainable_variables))
            optimizer.apply_gradients(zip(gradients, value_network.trainable_variables))

            state = next_state
            if done:
                break

        reward_memory.append(total_reward)
        print(f"Episode {episode + 1}, Total Reward: {total_reward}, Average Reward: {np.mean(reward_memory)}")

def select_action(policy_network, value_network, state):
    value = value_network(state).numpy()[0]
    action_probabilities = policy_network(state).numpy()[0]
    if np.random.rand() < 0.1:
        action = env.action_space.sample()
    else:
        action = np.random.choice(env.action_space.n, p=action_probabilities)
    return action, value, action_probabilities

def build_policy_network():
    model = tf.keras.Sequential([
        tf.keras.layers.Dense(512, activation='relu', input_shape=(4,)),
        tf.keras.layers.Dense(env.action_space.n)
    ])
    return model

def build_value_network():
    model = tf.keras.Sequential([
        tf.keras.layers.Dense(512, activation='relu', input_shape=(4,)),
        tf.keras.layers.Dense(1)
    ])
    return model
```

```python
    num_agents = len(envs)
    models = [build_dqn_model(envs[i].observation_space.shape) for i in range(num_agents)]

        total_rewards = [0 for _ in range(num_agents)]

            actions = [select_action(model, state, epsilon) for model, state in zip(models, states)]
            next_states, rewards, done, _ = envs.simulate(actions)
            total_rewards = [total_rewards[i] + rewards[i] for i in range(num_agents)]

                    target_reward = rewards[i]

                memory[i].append((states[i], actions[i], rewards[i], next_states[i], done[i]))
```
