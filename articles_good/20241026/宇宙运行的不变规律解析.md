# 模拟宇宙膨胀
def simulate_expansion(time_steps, initial_distance, expansion_rate):
    distances = [initial_distance]
    for _ in range(time_steps):
        distances.append(distances[-1] * (1 + expansion_rate))
    return distances

##### 1.1 宇宙的起源理论

宇宙的起源理论主要包括以下几种：

1. **大爆炸理论**：这是目前最被广泛接受的宇宙起源理论。该理论认为，宇宙起源于一个极高温度和密度的奇点，随后开始膨胀。这一理论得到了大量的天文观测和物理理论的支持。
   
2. **稳态宇宙模型**：这一理论认为，宇宙是永恒不变的，不存在起源和终结。然而，这一模型已经被大爆炸理论所取代，因为后者的预言得到了更多的观测验证。

3. **量子宇宙学**：这一理论从量子力学的角度探讨宇宙的起源。它提出，宇宙的起源可能是一种量子波动，随后这种波动演化为我们观察到的宇宙。

##### 1.2 宇宙诞生的过程

宇宙诞生的过程可以分为以下几个阶段：

1. **奇点时期**：宇宙起源于一个密度和温度极高的奇点，所有的物质和能量都集中在这个奇点中。

2. **宇宙膨胀期**：在奇点时期之后，宇宙开始迅速膨胀。这一过程释放了巨大的能量，使宇宙的温度和密度逐渐降低。

3. **复合时期**：随着宇宙的冷却，温度降低到一定程度，原子核开始形成。这一时期被称为复合时期，因为电子与质子开始结合形成中性原子。

4. **结构形成期**：在复合时期之后，宇宙中的物质在引力作用下开始聚集形成星系、星团和其他宇宙结构。

##### 1.3 宇宙早期的状态

在宇宙早期，状态如下：

1. **宇宙背景辐射**：宇宙冷却后，残留的高能光子形成了宇宙背景辐射。这是宇宙早期状态的直接证据，也是大爆炸理论的一个重要验证。

2. **原初黑洞**：在宇宙早期，可能形成了大量的原初黑洞。这些黑洞是宇宙中物质聚集的早期形式，也是宇宙结构形成的关键。
