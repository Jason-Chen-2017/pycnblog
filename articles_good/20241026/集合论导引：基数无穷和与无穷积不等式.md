   - **德·摩根定理**：证明\((A \cup B)^c = A^c \cap B^c\)和\((A \cap B)^c = A^c \cup B^c\)。

     证明：
     - 对于任意元素\(x\)，如果\(x \in (A \cup B)^c\)，则\(x\)不属于\(A \cup B\)。这意味着\(x\)不属于\(A\)且\(x\)不属于\(B\)，因此\(x \in A^c \cap B^c\)。
     - 反之，如果\(x \in A^c \cap B^c\)，则\(x\)不属于\(A\)且\(x\)不属于\(B\)。这意味着\(x\)不属于\(A \cup B\)，因此\(x \in (A \cup B)^c\)。

   - **分配律**：证明\(A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\)和\(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\)。

     证明：
     - 对于任意元素\(x\)，如果\(x \in A \cup (B \cap C)\)，则\(x \in A\)或\(x \in B \cap C\)。这意味着\(x \in A\)或\(x \in B\)且\(x \in C\)，因此\(x \in (A \cup B) \cap (A \cup C)\)。
     - 反之，如果\(x \in (A \cup B) \cap (A \cup C)\)，则\(x \in A \cup B\)且\(x \in A \cup C\)。这意味着\(x \in A\)或\(x \in B\)，且\(x \in A\)或\(x \in C\)，因此\(x \in A \cup (B \cap C)\)。

   - **结合律**：证明\(A \cup B \cup C = A \cup (B \cup C)\)和\(A \cap B \cap C = A \cap (B \cap C)\)。

     证明：
     - 对于任意元素\(x\)，如果\(x \in A \cup B \cup C\)，则\(x \in A\)或\(x \in B\)或\(x \in C\)。这意味着\(x \in A\)或\(x \in B\)或\(x \in C\)，因此\(x \in A \cup (B \cup C)\)。
     - 反之，如果\(x \in A \cup (B \cup C)\)，则\(x \in A\)或\(x \in B \cup C\)。这意味着\(x \in A\)或\(x \in B\)或\(x \in C\)，因此\(x \in A \cup B \cup C\)。

   - **幂集**：证明集合\(A\)的幂集\(\mathcal{P}(A)\)的基数是\(2^{|A|}\)。

     证明：
     - 构造一个从集合\(A\)到集合\(\{\emptyset, \{a\}, \{b\}, \ldots, \{a, b\}\}\)的映射，其中\(a, b \in A\)。这个映射是一个双射，因此集合\(A\)的幂集的基数是\(2^{|A|}\)。

#### 附录 C 集合论导引习题与解答

为了巩固对集合论导引的学习，以下提供一些习题及解答，帮助读者更好地理解和掌握集合论的基本概念和定理。

**习题 1**：证明德·摩根定理。

**解答**：

德·摩根定理包括两个部分：

1. \( (A \cup B)^c = A^c \cap B^c \)

证明：

对于任意元素\( x \)，

- 如果\( x \in (A \cup B)^c \)，则\( x \)不属于\( A \cup B \)。这意味着\( x \)不属于\( A \)且\( x \)不属于\( B \)，即\( x \in A^c \)且\( x \in B^c \)，因此\( x \in A^c \cap B^c \)。
- 反之，如果\( x \in A^c \cap B^c \)，则\( x \)不属于\( A \)且\( x \)不属于\( B \)。这意味着\( x \)不属于\( A \cup B \)，因此\( x \in (A \cup B)^c \)。

因此，\( (A \cup B)^c = A^c \cap B^c \)。

2. \( (A \cap B)^c = A^c \cup B^c \)

证明：

对于任意元素\( x \)，

- 如果\( x \in (A \cap B)^c \)，则\( x \)不属于\( A \cap B \)。这意味着\( x \)不属于\( A \)或\( x \)不属于\( B \)，即\( x \in A^c \)或\( x \in B^c \)，因此\( x \in A^c \cup B^c \)。
- 反之，如果\( x \in A^c \cup B^c \)，则\( x \)不属于\( A \)或\( x \)不属于\( B \)。这意味着\( x \)不属于\( A \cap B \)，因此\( x \in (A \cap B)^c \)。

因此，\( (A \cap B)^c = A^c \cup B^c \)。

**习题 2**：证明集合\( A \)的幂集\( \mathcal{P}(A) \)的基数是\( 2^{|A|} \)。

**解答**：

要证明集合\( A \)的幂集\( \mathcal{P}(A) \)的基数是\( 2^{|A|} \)，需要构造一个从集合\( A \)到集合\( \{\emptyset, \{a\}, \{b\}, \ldots, \{a, b\}\}\)的双射。

设\( A = \{a_1, a_2, \ldots, a_n\} \)。

定义一个映射\( f: A \rightarrow \{\emptyset, \{a_1\}, \{a_2\}, \ldots, \{a_1, a_2\}, \ldots, \{a_1, a_2, \ldots, a_n\}\} \)如下：

- 如果\( i = 1 \)，则\( f(a_1) = \{a_1\} \)。
- 如果\( i = 2 \)，则\( f(a_2) = \{a_1, a_2\} \)。
- 对于\( i > 2 \)，如果\( i \)是集合\( A \)的索引，则\( f(a_i) = \{a_1, a_2, \ldots, a_i\} \)。

显然，\( f \)是一个双射，因为每个元素在集合\( A \)中都有一个唯一的对应元素在集合\( \{\emptyset, \{a_1\}, \{a_2\}, \ldots, \{a_1, a_2\}, \ldots, \{a_1, a_2, \ldots, a_n\}\} \)中，反之亦然。因此，集合\( A \)的幂集\( \mathcal{P}(A) \)的基数是\( 2^{|A|} \)。

**习题 3**：证明闵可夫斯基不等式。

**解答**：

闵可夫斯基不等式可以表述为：

\[
\left(\sum_{i=1}^n |a_i + b_i|\right)^2 \leq \left(\sum_{i=1}^n |a_i|^2\right)\left(\sum_{i=1}^n |b_i|^2\right)
\]

证明：

对于任意实数\( a_i \)和\( b_i \)，有：

\[
|a_i + b_i|^2 = (a_i + b_i)^2 = a_i^2 + 2a_i b_i + b_i^2
\]

因此，

\[
\left(\sum_{i=1}^n |a_i + b_i|\right)^2 = \sum_{i=1}^n |a_i + b_i|^2 = \sum_{i=1}^n (a_i^2 + 2a_i b_i + b_i^2)
\]

我们可以将上述和式重新排列：

\[
\sum_{i=1}^n (a_i^2 + 2a_i b_i + b_i^2) = \left(\sum_{i=1}^n a_i^2\right) + 2\left(\sum_{i=1}^n a_i b_i\right) + \left(\sum_{i=1}^n b_i^2\right)
\]

由于\( 2ab \leq a^2 + b^2 \)对于任意实数\( a \)和\( b \)成立，因此：

\[
2\left(\sum_{i=1}^n a_i b_i\right) \leq \left(\sum_{i=1}^n a_i^2\right) + \left(\sum_{i=1}^n b_i^2\right)
\]

将其代入前面的和式中，我们得到：

\[
\left(\sum_{i=1}^n |a_i + b_i|\right)^2 \leq \left(\sum_{i=1}^n a_i^2\right) + 2\left(\sum_{i=1}^n a_i b_i\right) + \left(\sum_{i=1}^n b_i^2\right) \leq \left(\sum_{i=1}^n a_i^2\right)\left(\sum_{i=1}^n b_i^2\right)
\]

因此，闵可夫斯基不等式得证。

**习题 4**：证明柯西不等式。

**解答**：

柯西不等式可以表述为：

\[
\left(\sum_{i=1}^n a_i b_i\right)^2 \leq \left(\sum_{i=1}^n a_i^2\right)\left(\sum_{i=1}^n b_i^2\right)
\]

证明：

考虑两个向量\( \mathbf{a} = (a_1, a_2, \ldots, a_n) \)和\( \mathbf{b} = (b_1, b_2, \ldots, b_n) \)的欧几里得内积（点积），即：

\[
\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^n a_i b_i
\]

根据柯西-施瓦茨不等式，有：

\[
|\mathbf{a} \cdot \mathbf{b}| \leq \|\mathbf{a}\| \|\mathbf{b}\|
\]

其中，\(\|\mathbf{a}\|\)和\(\|\mathbf{b}\|\)分别是向量\( \mathbf{a} \)和\( \mathbf{b} \)的欧几里得范数，即：

\[
\|\mathbf{a}\| = \sqrt{\sum_{i=1}^n a_i^2}, \quad \|\mathbf{b}\| = \sqrt{\sum_{i=1}^n b_i^2}
\]

因此，

\[
\left|\sum_{i=1}^n a_i b_i\right| \leq \sqrt{\sum_{i=1}^n a_i^2} \sqrt{\sum_{i=1}^n b_i^2}
\]

平方两边，得：

\[
\left(\sum_{i=1}^n a_i b_i\right)^2 \leq \left(\sum_{i=1}^n a_i^2\right)\left(\sum_{i=1}^n b_i^2\right)
\]

因此，柯西不等式得证。
