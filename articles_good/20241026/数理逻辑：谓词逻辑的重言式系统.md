## 第1章 引言

### 1.1 数理逻辑的背景和重要性

数理逻辑，又称符号逻辑或形式逻辑，是研究逻辑在数学中的应用，特别是对数学命题和推理进行形式化和精确描述的数学分支。数理逻辑的发展始于19世纪末，当时的数学家们开始寻求一种形式化的方法来避免数学基础中的逻辑混乱和悖论。

数理逻辑的重要性主要体现在以下几个方面：

1. **精确性**：数理逻辑提供了精确的符号语言来描述数学命题和推理过程，使得逻辑推理更加严谨和可靠。
2. **一致性**：数理逻辑通过严格的逻辑规则和证明理论，确保了推理过程的一致性，防止了推理过程中的错误。
3. **通用性**：数理逻辑不仅可以应用于数学，还可以广泛应用于计算机科学、哲学、语言学等领域。

### 1.2 谓词逻辑的基本概念

谓词逻辑是数理逻辑中的一个重要分支，用于表示和推理个体、属性和关系等概念。谓词逻辑的基本概念包括谓词、个体词、属性和关系等。

- **谓词**：谓词是一个可以用于描述个体性质的命题。例如，“x 是素数”是一个谓词，其中“x”是谓词的变量。
- **个体词**：个体词是指代表个体的词语，如“π”代表数学常数π。
- **属性**：属性是谓词的一种特殊情况，用于描述个体的性质。例如，“x 是偶数”是一个属性。
- **关系**：关系是用于描述个体之间关系的谓词。例如，“x 大于 y”是一个关系。

### 1.3 重言式系统的概念

重言式系统是谓词逻辑中的一个重要概念，它是指一个逻辑系统，其中的所有命题都是重言式。重言式是指无论前提如何，结论总是成立的命题。

在谓词逻辑中，重言式系统通常表示为：

$$
\forall x (P(x) \rightarrow Q(x))
$$

其中，$P(x)$ 和 $Q(x)$ 是谓词，$x$ 是个体词。这个命题表示“对于所有的 x，如果 P(x) 成立，则 Q(x) 也成立”。无论 P(x) 和 Q(x) 的具体内容如何，这个命题总是成立的，因此它是一个重言式。

重言式系统在谓词逻辑中具有重要意义，因为它提供了一种形式化的方法来验证逻辑推理的正确性。

## 第2章 谓词逻辑的基本概念

### 2.1 谓词与个体词

谓词逻辑的基础是谓词和个体词。谓词是描述个体性质或关系的命题，而个体词是代表特定个体的符号。

#### 2.1.1 谓词的定义与分类

谓词可以分为一元谓词、二元谓词和多元谓词。一元谓词仅涉及一个个体词，如“x 是素数”；二元谓词涉及两个个体词，如“x 大于 y”；多元谓词涉及多个个体词，如“x、y 和 z 都是素数”。

谓词还可以根据其含义进行分类，如性质谓词、关系谓词和函数谓词。性质谓词描述个体的性质，如“x 是红色的”；关系谓词描述个体之间的关系，如“x 大于 y”；函数谓词描述个体的映射关系，如“f(x) = x^2”。

#### 2.1.2 个体词的定义与作用

个体词是谓词逻辑中的基本变量，代表特定的个体。个体词可以是具体的名称，如“π”代表数学常数π，也可以是变量，如“x”、“y”等。

个体词在谓词逻辑中起到重要作用，用于替换谓词中的变量，使得谓词能够应用于具体的个体。例如，谓词“x 是素数”中的个体词“x”可以替换为具体的数字，如“2 是素数”。

### 2.2 属性与关系

属性和关系是谓词逻辑中的核心概念，用于描述个体的性质和个体之间的关系。

#### 2.2.1 属性的定义与分类

属性是谓词逻辑中的谓词，用于描述个体的性质。属性可以分为基本属性和组合属性。基本属性是直接描述个体性质的谓词，如“x 是红色的”；组合属性是通过基本属性组合而成的谓词，如“x 是红色的且大于 y”。

属性在谓词逻辑中起到重要作用，用于定义个体的分类和性质。例如，谓词“x 是素数”中的属性“素数”定义了个体 x 的数学性质。

#### 2.2.2 关系的定义与分类

关系是谓词逻辑中的谓词，用于描述个体之间的关系。关系可以分为基本关系和组合关系。基本关系是直接描述个体之间关系的谓词，如“x 大于 y”；组合关系是通过基本关系组合而成的谓词，如“x 大于 y 且小于 z”。

关系在谓词逻辑中起到重要作用，用于定义个体之间的逻辑关系。例如，谓词“x 是 y 的父亲”中的关系“是...的父亲”定义了个体 x 和 y 之间的父子关系。

### 2.3 谓词逻辑的基本公式

谓词逻辑的基本公式是构成谓词逻辑推理的基础。以下是一些基本的谓词逻辑公式：

#### 2.3.1 基本公式与推理规则

1. **全称量词引入**：$$\forall x (P(x) \rightarrow Q(x)) \rightarrow (\forall x P(x) \rightarrow \forall x Q(x))$$
   这个公式表示，如果对于所有 x，如果 P(x) 成立则 Q(x) 成立，那么如果对于所有 x，P(x) 成立，则对于所有 x，Q(x) 也成立。

2. **存在量词引入**：$$\exists x (P(x) \rightarrow Q(x)) \rightarrow (\exists x P(x) \rightarrow \exists x Q(x))$$
   这个公式表示，如果存在一个 x，使得如果 P(x) 成立则 Q(x) 成立，那么如果存在一个 x，P(x) 成立，则存在一个 x，Q(x) 也成立。

3. **全称量词消去**：$$\forall x P(x) \rightarrow P(y)$$
   这个公式表示，如果对于所有 x，P(x) 成立，则 P(y) 也成立。

4. **存在量词消去**：$$\exists x P(x) \rightarrow P(y)$$
   这个公式表示，如果存在一个 x，使得 P(x) 成立，则 P(y) 也成立。

5. **合取**：$$P \land Q \rightarrow R$$
   这个公式表示，如果 P 和 Q 都成立，则 R 也成立。

6. **析取**：$$P \lor Q \rightarrow R$$
   这个公式表示，如果 P 或 Q 成立，则 R 也成立。

7. **否定**：$$\neg P \rightarrow \neg Q$$
   这个公式表示，如果 P 不成立，则 Q 也不成立。

#### 2.3.2 谓词逻辑的推理方法

谓词逻辑的推理方法主要包括演绎推理和归纳推理。演绎推理是从一般到特殊的推理方法，即从普遍原理推导出特定情况下的结论。归纳推理是从特殊到一般的推理方法，即从特定情况推导出普遍原理。

1. **演绎推理**：演绎推理的基本形式是三段论，即：
   - 大前提：所有 A 都是 B。
   - 小前提：C 是 A。
   - 结论：C 是 B。

   例如，如果大前提是“所有素数都是自然数”，小前提是“2 是素数”，则结论是“2 是自然数”。

2. **归纳推理**：归纳推理的基本形式是：
   - 特例1：A 是 B。
   - 特例2：B 是 C。
   - 结论：A 是 C。

   例如，如果特例1是“2 是素数”，特例2是“素数都是自然数”，则结论是“2 是自然数”。

通过这些基本公式和推理方法，谓词逻辑能够有效地描述和推理个体的性质和关系，为计算机科学和其他领域提供了强有力的工具。

### 第3章 重言式系统

重言式系统是谓词逻辑中的一个重要概念，它指的是一个逻辑系统，其中的所有命题都是重言式。重言式是指无论前提如何，结论总是成立的命题。在谓词逻辑中，重言式系统具有特殊的地位，因为它们提供了一种形式化的方法来验证逻辑推理的正确性。

#### 3.1 重言式的定义

重言式是逻辑中的一个基本概念，它指的是一个命题，无论前提如何，结论总是成立的。在谓词逻辑中，重言式通常表示为：

$$
\forall x (P(x) \rightarrow Q(x))
$$

其中，$P(x)$ 和 $Q(x)$ 是谓词，$x$ 是个体词。这个命题表示“对于所有的 x，如果 P(x) 成立，则 Q(x) 也成立”。无论 $P(x)$ 和 $Q(x)$ 的具体内容如何，这个命题总是成立的，因此它是一个重言式。

例如，命题“所有的狗都会呼吸”是一个重言式，因为无论我们选择哪个个体作为狗，这个命题总是成立的。

#### 3.1.1 重言式的性质

重言式具有以下性质：

1. **不变性**：重言式在逻辑推理中不依赖于前提。无论前提是什么，重言式的结论总是成立。
2. **传递性**：如果 $P(x)$ 是重言式，$Q(x)$ 是重言式，那么 $P(x) \rightarrow Q(x)$ 也是重言式。
3. **结合性**：重言式可以与其他命题进行合取或析取，结果仍然是重言式。

例如，命题“所有的狗都会呼吸”是一个重言式，我们可以将其与“所有的猫都会呼吸”进行合取，得到“所有的狗和猫都会呼吸”，这个命题仍然是重言式。

#### 3.1.2 重言式的应用

重言式在逻辑推理和验证中具有广泛的应用。以下是一些具体的例子：

1. **证明**：在数学和逻辑中，证明一个命题通常需要证明该命题是重言式。例如，要证明“如果所有的素数都是自然数，那么2是自然数”，我们可以使用重言式来证明。
2. **验证**：在计算机科学中，重言式用于验证程序的正确性。例如，我们可以使用谓词逻辑来验证一个排序算法是否总是产生正确的输出。

通过定义和性质，重言式为逻辑推理提供了一个坚实的基础，使得我们能够形式化和验证复杂的逻辑推理过程。

#### 3.2 重言式系统的定义

重言式系统是一个逻辑系统，其中的所有命题都是重言式。重言式系统可以看作是一个逻辑语言，其中包括谓词、量词、连接词和逻辑常量等基本元素。

在重言式系统中，命题是通过谓词、量词和连接词组合而成的。谓词用于描述个体的性质或关系，量词用于引入全称量词或存在量词，连接词用于组合命题。

一个重言式系统通常包含以下元素：

1. **谓词**：谓词是用于描述个体性质或关系的命题。例如，“x 是素数”是一个谓词。
2. **个体词**：个体词是代表特定个体的符号。例如，“π”代表数学常数π。
3. **量词**：量词用于引入全称量词或存在量词。全称量词表示对于所有的个体都成立，存在量词表示至少存在一个个体成立。
4. **连接词**：连接词用于组合命题。常见的连接词包括合取（∧）、析取（∨）、蕴含（→）和否定（¬）。

一个重言式系统的命题可以表示为：

$$
\forall x (P(x) \rightarrow Q(x))
$$

其中，$P(x)$ 和 $Q(x)$ 是谓词，$x$ 是个体词。这个命题表示“对于所有的 x，如果 P(x) 成立，则 Q(x) 也成立”。无论 $P(x)$ 和 $Q(x)$ 的具体内容如何，这个命题总是成立的，因此它是一个重言式。

#### 3.2.1 重言式系统的性质

重言式系统具有以下性质：

1. **闭合性**：重言式系统中的所有命题都是重言式，因此该系统是闭合的。这意味着，如果我们能够证明一个命题在重言式系统中成立，那么它对于所有可能的个体都成立。
2. **一致性**：重言式系统不会产生矛盾。这意味着，如果我们能够在重言式系统中找到两个相互矛盾的命题，那么这个系统是不一致的。
3. **完备性**：重言式系统包含了所有可能的逻辑推理。这意味着，如果我们能够证明一个命题在重言式系统中成立，那么我们可以使用这个系统来证明该命题对于所有可能的个体都成立。

#### 3.2.2 重言式系统的构建方法

构建一个重言式系统需要以下步骤：

1. **定义谓词**：首先，我们需要定义系统中使用的谓词。这些谓词可以描述个体的性质或关系。例如，“x 是素数”是一个谓词。
2. **定义个体词**：然后，我们需要定义系统中使用的个体词。这些个体词可以代表特定的个体。例如，“π”代表数学常数π。
3. **定义量词**：接下来，我们需要定义系统中使用的量词。这些量词可以引入全称量词或存在量词。例如，全称量词表示“对于所有的个体都成立”。
4. **定义连接词**：最后，我们需要定义系统中使用的连接词。这些连接词可以组合命题。例如，合取表示“且”，析取表示“或”。
5. **构建命题**：使用定义的谓词、个体词、量词和连接词，我们可以构建出系统中的命题。

通过以上步骤，我们可以构建一个重言式系统，该系统包含所有可能的逻辑推理，并且所有命题都是重言式。

### 第4章 谓词逻辑的证明理论

谓词逻辑的证明理论是研究如何使用逻辑规则和推理方法证明命题是否成立的分支。谓词逻辑的证明理论在数学、计算机科学和哲学等领域有着广泛的应用。本章将介绍证明的基本概念、证明规则以及谓词逻辑的证明方法。

#### 4.1 证明的基本概念

证明是指通过一系列的逻辑推理步骤，从一个或多个已知命题（称为前提）推导出一个新的命题（称为结论）的过程。在谓词逻辑中，证明通常涉及以下基本概念：

1. **前提**：前提是用于证明的已知命题。在一个证明中，前提通常是公理或已知事实。
2. **结论**：结论是证明的目标，是希望证明的命题。
3. **推理规则**：推理规则是用于从前提推导出结论的规则。推理规则可以是演绎推理规则，也可以是归纳推理规则。
4. **证明形式**：证明形式是用于表示证明的结构和步骤的符号表示。常见的证明形式包括自然演绎式和形式证明系统。

#### 4.2 证明规则

谓词逻辑的证明规则是用于推导命题的规则。以下是一些基本的证明规则：

1. **合取引入**：如果 P 和 Q 都成立，则 P ∧ Q 也成立。形式化表示为：
   $$
   P \quad Q \quad \therefore P \land Q
   $$

2. **析取引入**：如果 P 或 Q 成立，则 P ∨ Q 也成立。形式化表示为：
   $$
   P \quad \quad Q \quad \therefore P \lor Q
   $$

3. **否定引入**：如果 ¬P 成立，则 P 不成立。形式化表示为：
   $$
   \neg P \quad \therefore P
   $$

4. **全称量词引入**：如果对于所有的 x，P(x) 成立，则 ∀x P(x) 也成立。形式化表示为：
   $$
   \forall x P(x) \quad \therefore P(x)
   $$

5. **存在量词引入**：如果存在一个 x，使得 P(x) 成立，则 ∃x P(x) 也成立。形式化表示为：
   $$
   \exists x P(x) \quad \therefore P(x)
   $$

6. **合取消除**：如果 P ∧ Q 成立，则 P 和 Q 都成立。形式化表示为：
   $$
   P \land Q \quad \therefore P \quad Q
   $$

7. **析取消除**：如果 P ∨ Q 成立，则 P 或 Q 成立。形式化表示为：
   $$
   P \lor Q \quad \therefore P \quad \quad Q
   $$

8. **全称量词消除**：如果 ∀x P(x) 成立，则对于任意的 x，P(x) 成立。形式化表示为：
   $$
   \forall x P(x) \quad \therefore P(a) \quad \text{其中} \; a \; \text{是任意个体词}
   $$

9. **存在量词消除**：如果 ∃x P(x) 成立，则存在一个个体词 a，使得 P(a) 成立。形式化表示为：
   $$
   \exists x P(x) \quad \therefore P(a) \quad \text{其中} \; a \; \text{是满足 P(a) 的个体词}
   $$

#### 4.3 谓词逻辑的证明方法

谓词逻辑的证明方法包括直接证明和间接证明两种。

1. **直接证明**：直接证明是通过一系列的推理规则，从前提直接推导出结论的过程。直接证明通常遵循以下步骤：

   - 假设前提成立。
   - 应用推理规则，逐步推导出结论。
   - 确认结论成立。

   例如，要证明命题“∀x (P(x) → Q(x)) → (∀x P(x) → ∀x Q(x))”，我们可以使用以下步骤：

   $$
   \begin{array}{l}
   1. \quad \forall x (P(x) \rightarrow Q(x)) \quad \text{前提} \\
   2. \quad P(a) \rightarrow Q(a) \quad \text{全称量词消除} \\
   3. \quad P(b) \rightarrow Q(b) \quad \text{全称量词消除} \\
   4. \quad \cdots \\
   5. \quad \forall x P(x) \quad \text{前提} \\
   6. \quad P(a) \quad \text{全称量词消除} \\
   7. \quad Q(a) \quad \text{蕴含消除，使用步骤 2 和 3} \\
   8. \quad \forall x Q(x) \quad \text{全称量词引入，使用步骤 7}
   \end{array}
   $$

   通过这些步骤，我们直接证明了命题“∀x (P(x) → Q(x)) → (∀x P(x) → ∀x Q(x))”。

2. **间接证明**：间接证明是通过假设结论不成立，然后推导出矛盾来证明结论成立的过程。间接证明通常遵循以下步骤：

   - 假设结论不成立。
   - 从前提和假设推导出矛盾。
   - 确认结论成立。

   例如，要证明命题“∀x (P(x) → Q(x)) → (∀x P(x) → ∀x Q(x))”，我们可以使用以下步骤：

   $$
   \begin{array}{l}
   1. \quad \forall x (P(x) \rightarrow Q(x)) \quad \text{前提} \\
   2. \quad \neg (\forall x P(x) \rightarrow \forall x Q(x)) \quad \text{假设结论不成立} \\
   3. \quad \forall x P(x) \quad \text{前提} \\
   4. \quad P(a) \quad \text{全称量词消除} \\
   5. \quad \neg Q(a) \quad \text{蕴含消除，使用步骤 2 和 3} \\
   6. \quad \neg \forall x Q(x) \quad \text{全称量词引入，使用步骤 5} \\
   7. \quad \neg P(a) \quad \text{蕴含消除，使用步骤 2 和 6} \\
   8. \quad \bot \quad \text{矛盾，使用步骤 4 和 7} \\
   9. \quad \therefore \forall x P(x) \rightarrow \forall x Q(x) \quad \text{否定引入，使用步骤 2 和 8}
   \end{array}
   $$

   通过这些步骤，我们间接证明了命题“∀x (P(x) → Q(x)) → (∀x P(x) → ∀x Q(x))”。

个体词是具体的对象或个体的代表，通常用大写字母如“A”、“B”表示。个体词与谓词结合，构成具体的命题，如“P(A)”表示“A”具有“P”属性。

#### 1. 谓词逻辑的基本公式

谓词逻辑的基本公式包括以下几种：

- **全称量词引入**：$$\forall x (P(x) \rightarrow Q(x)) \rightarrow (\forall x P(x) \rightarrow \forall x Q(x))$$
  这个公式表示，如果对于所有的 x，P(x) 蕴含 Q(x)，则如果对于所有的 x，P(x) 成立，那么对于所有的 x，Q(x) 也成立。

- **存在量词引入**：$$\exists x (P(x) \rightarrow Q(x)) \rightarrow (\exists x P(x) \rightarrow \exists x Q(x))$$
  这个公式表示，如果存在一个 x，使得 P(x) 蕴含 Q(x)，则如果存在一个 x，使得 P(x) 成立，那么也存在一个 x，使得 Q(x) 成立。

- **否定引入**：$$\neg P \rightarrow P \rightarrow \bot$$
  这个公式表示，如果 ¬P 成立，则 P 成立会导致矛盾（即 P ∨ ¬P）。

- **合取引入**：$$P \land Q \rightarrow R \rightarrow (P \rightarrow R) \land (Q \rightarrow R)$$
  这个公式表示，如果 P 和 Q 同时成立，则 P 和 Q 都蕴含 R。

- **析取引入**：$$P \lor Q \rightarrow R \rightarrow (P \rightarrow R) \lor (Q \rightarrow R)$$
  这个公式表示，如果 P 或 Q 成立，则 P 或 Q 都蕴含 R。

#### 2. 谓词逻辑的推理规则

谓词逻辑的推理规则包括：

- **全称量词消去**：$$\forall x P(x) \rightarrow P(a)$$
  这个规则表示，如果对于所有 x，P(x) 成立，则对于任意个体 a，P(a) 也成立。

- **存在量词消去**：$$\exists x P(x) \rightarrow P(a)$$
  这个规则表示，如果存在一个 x，使得 P(x) 成立，则对于这个特定的个体 a，P(a) 也成立。

- **蕴含消除**：$$P \rightarrow Q, Q \rightarrow R \rightarrow P \rightarrow R$$
  这个规则表示，如果 P 蕴含 Q，Q 蕴含 R，则 P 蕴含 R。

2. **初始状态**：

   - 初始数组 `arr` 可以是任意排列的，因此对于任意的 `i < j`，`P(i, j)` 可能不成立。

3. **执行排序过程**：

   - 在每次遍历中，算法比较相邻的元素并交换它们，如果 `arr[j] < arr[j+1]`，则交换它们，使得 `P(j, j+1)` 成立。
   - 在一轮遍历结束后，最大的元素会被“冒泡”到数组的末尾，因此对于下一轮遍历，我们只需要考虑前 `n-i-1` 个元素。

4. **终止条件**：

   - 当没有任何交换发生时，算法终止，此时数组已经是有序的，即对于所有的 `i < j`，`P(i, j)` 都成立。

#### 谓词逻辑公式

为了验证冒泡排序算法，我们可以使用以下谓词逻辑公式：

$$
\forall n (\exists i (\neg P(i, i+1)) \land \forall j (P(j, j+1)) \rightarrow S(n))
$$

这个公式表示，对于任意的数组长度 `n`，如果存在一个索引 `i` 使得 `arr[i] > arr[i+1]`（即初始状态不满足排序条件），且对于所有的 `j`，`arr[j] <= arr[j+1]`（即相邻元素满足排序条件），则数组最终是排序的。

#### 验证过程

我们可以通过以下步骤验证冒泡排序算法的正确性：

1. **初始化**：

   - 假设初始数组不满足排序条件，即存在 `i` 使得 `arr[i] > arr[i+1]`。

2. **执行排序**：

   - 在每次遍历中，比较相邻元素并交换，使得满足 `P(j, j+1)`。
   - 经过一轮遍历后，最大的元素被“冒泡”到最后，因此下一轮遍历的数组长度减少。

3. **终止条件**：

   - 当没有元素需要交换时，算法终止，此时数组满足排序条件，即对于所有的 `i < j`，`arr[i] <= arr[j]`。

通过上述谓词逻辑公式和验证过程，我们可以形式化地证明冒泡排序算法的正确性。这种方法不仅适用于冒泡排序，还可以应用于其他排序算法的验证，为算法的正确性和性能分析提供了有力的工具。

#### 神经网络模型

假设我们有一个简单的多层感知器（MLP）神经网络，其输入层、隐藏层和输出层分别有 3 个神经元。神经网络的输出由以下公式给出：

$$
y = \sigma(\sum_{i=1}^{n} w_i \cdot x_i + b)
$$

其中，$y$ 是神经网络的输出，$\sigma$ 是激活函数（例如 Sigmoid 函数），$w_i$ 是从输入层到隐藏层的权重，$x_i$ 是输入层的特征，$b$ 是隐藏层的偏置。

#### 谓词逻辑公式

为了验证神经网络中的权重和偏置是否满足特定的约束条件，我们可以定义以下谓词逻辑公式：

1. **权重和偏置范围约束**：

   - `W(i, j) ∈ [0, 1]`：表示权重 $w_i$ 和 $w_j$ 的范围在 0 到 1 之间。
   - `B(i) ∈ [-1, 1]`：表示偏置 $b_i$ 的范围在 -1 到 1 之间。

2. **激活函数约束**：

   - `σ(z) ∈ [0.5, 1]`：表示激活函数 $\sigma(z)$ 的输出范围在 0.5 到 1 之间，这通常意味着神经网络处于“激活”状态。

3. **输出约束**：

   - `y ∈ [0.25, 0.75]`：表示神经网络的输出 $y$ 的范围在 0.25 到 0.75 之间，这通常意味着神经网络的输出是“可靠”的。

#### 谓词逻辑验证

我们使用谓词逻辑来验证神经网络中的权重和偏置是否满足上述约束条件。

1. **初始化谓词**：

   - `init_weights()`：初始化权重 $w_i$ 和 $w_j$ 在 [0, 1] 范围内。
   - `init_bias()`：初始化偏置 $b_i$ 在 [-1, 1] 范围内。

2. **激活函数验证**：

   - `validate_activation()`：验证激活函数 $\sigma(z)$ 的输出范围在 [0.5, 1] 之间。

3. **输出验证**：

   - `validate_output()`：验证神经网络输出 $y$ 的范围在 [0.25, 0.75] 之间。

#### 验证过程

1. **初始化神经网络**：

   ```python
   def init_weights(n):

           for j in range(n):
               w[i][j] = random.uniform(0, 1)

   def init_bias(n):
       for i in range(n):
           b[i] = random.uniform(-1, 1)
   ```

2. **验证权重和偏置**：

   ```python
   def validate_weights():
       for i in range(n):
           for j in range(n):
               assert 0 <= w[i][j] <= 1

   def validate_bias():

           assert -1 <= b[i] <= 1
   ```

3. **激活函数验证**：

   ```python
   def validate_activation():

       y = sigmoid(z)
       assert 0.5 <= y <= 1
   ```

4. **输出验证**：

   ```python

       assert 0.25 <= y <= 0.75
   ```
