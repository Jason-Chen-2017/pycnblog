#### 第一部分：机器学习基础

##### 1.1 机器学习概述

机器学习（Machine Learning）是人工智能（Artificial Intelligence, AI）的一个分支，主要研究如何让计算机系统从数据中学习，并对未知数据进行预测或决策。机器学习可以分为两大类：监督学习（Supervised Learning）和无监督学习（Unsupervised Learning）。

**核心概念与联系**

以下是机器学习核心概念之间的联系：

```mermaid

```

**监督学习**

监督学习是一种从标注数据中学习的方法。常见的监督学习算法包括：

- **分类算法**：用于预测输出属于某个类别的算法，如逻辑回归、决策树、随机森林、支持向量机（SVM）等。
- **回归算法**：用于预测输出数值的算法，如线性回归、多项式回归、岭回归等。

**无监督学习**

无监督学习是从未标记的数据中学习，主要目的是发现数据中的隐藏结构。常见的无监督学习算法包括：

- **聚类算法**：将数据分为若干个组，如K-均值聚类、层次聚类等。
- **降维算法**：用于减少数据维度，提高计算效率，如主成分分析（PCA）、t-SNE等。

          recommended_items = train_data[similar_user].items

- **物品基于协同过滤**：

  ```python
  def itemBasedCollaborativeFiltering(train_data, user, num_recommendations):
      similar_items = findSimilarItems(train_data, user)
      recommendations = []
      for similar_item in similar_items:
          recommended_users = train_data[similar_item].users
          for recommended_user in recommended_users:
              if recommended_user != user and recommended_user not in train_data[user].items:
                  recommendations.append(recommended_user)
      return recommendations[:num_recommendations]
  ```

$$ r_{ij} = u_i \cdot u_j + v_i \cdot v_j $$

其中，$r_{ij}$ 表示用户 $i$ 对物品 $j$ 的评分，$u_i$ 和 $u_j$ 分别表示用户 $i$ 和 $j$ 的特征向量，$v_i$ 和 $v_j$ 分别表示物品 $i$ 和 $j$ 的特征向量。

假设我们有以下用户-物品评分矩阵：

| 用户 | 物品 | 评分 |
| ---- | ---- | ---- |
| $u_1$ | $a_1$ | 4    |
| $u_1$ | $a_2$ | 5    |
| $u_2$ | $a_1$ | 3    |
| $u_2$ | $a_2$ | 4    |
| $u_3$ | $a_1$ | 2    |
| $u_3$ | $a_2$ | 5    |
