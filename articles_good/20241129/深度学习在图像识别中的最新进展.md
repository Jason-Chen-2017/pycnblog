## 深度学习的基本概念

深度学习是一种基于人工神经网络的机器学习技术，通过多层神经网络来模拟人脑的思维方式，自动提取和整合特征，从而实现复杂任务的自动化。要深入理解深度学习，首先需要了解以下几个关键概念：

### 神经网络

神经网络是深度学习的基础，它由大量简单的人工神经元组成，通过调整神经元之间的连接权重来学习数据。每个神经元接收多个输入信号，并通过激活函数产生一个输出信号。神经网络通过前向传播和反向传播过程来学习数据。

#### 神经元结构

一个基本的人工神经元（也称为节点或单元）可以表示为以下数学模型：

$$
y = f(\sum_{i=1}^{n} w_i x_i + b)
$$

其中，$y$ 是神经元的输出，$x_i$ 是输入值，$w_i$ 是输入权重，$b$ 是偏置项，$f$ 是激活函数。

#### 激活函数

激活函数是神经网络中的一个关键组件，它用于引入非线性变换，使得神经网络能够学习复杂函数。常见的激活函数包括：

1. **sigmoid 函数**：
   $$
   f(x) = \frac{1}{1 + e^{-x}}
   $$

2. **ReLU 函数**：
   $$
   f(x) = \max(0, x)
   $$

3. **tanh 函数**：
   $$
   f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}
   $$

### 多层神经网络

多层神经网络（也称为深度神经网络）通过增加隐藏层来提高模型的表达能力。一个典型的多层神经网络包括输入层、一个或多个隐藏层和输出层。每个隐藏层都将前一层的信息进行处理，并传递给下一层。

#### 前向传播

在前向传播过程中，输入数据通过神经网络从输入层传递到输出层。每个神经元都会计算其输入值的加权和，并通过激活函数产生输出。这个过程在每一层重复进行，直到最后得到输出层的结果。

#### 反向传播

反向传播是神经网络训练的核心过程，用于更新神经元的权重和偏置项。在反向传播过程中，神经网络会计算输出层与实际标签之间的误差，并沿着网络逐层反向传播误差。通过计算误差的梯度，神经网络可以调整权重和偏置项，以最小化总误差。

#### 反向传播算法

反向传播算法主要包含以下几个步骤：

1. **计算输出层的误差**：
   $$
   \delta_L = \frac{\partial L}{\partial a_L} = \frac{\partial L}{\partial z_L} \cdot \frac{\partial z_L}{\partial a_L}
   $$

2. **反向传播误差**：
   对于隐藏层 $l$：
   $$
   \delta_l = (\frac{\partial L}{\partial z_{l+1}} \cdot \frac{\partial z_{l+1}}{\partial a_{l+1}}) \cdot \frac{\partial a_{l+1}}{\partial a_l}
   $$

3. **更新权重和偏置项**：
   $$
   w_{li} \leftarrow w_{li} - \alpha \frac{\partial L}{\partial w_{li}}
   $$
   $$
   b_{l} \leftarrow b_{l} - \alpha \frac{\partial L}{\partial b_{l}}
   $$

其中，$\alpha$ 是学习率。

### 深度学习模型

深度学习模型是由多个神经网络层组成的复杂网络结构，可以用于各种机器学习任务，如图像分类、物体检测、语音识别等。以下是一些常见的深度学习模型：

1. **卷积神经网络（CNN）**：通过卷积层、池化层和全连接层来处理图像数据，实现图像分类和物体检测。

2. **循环神经网络（RNN）**：通过循环结构来处理序列数据，适用于时间序列分析和语音识别等任务。

3. **生成对抗网络（GAN）**：由生成器和判别器组成，用于生成逼真的图像和语音。

4. **长短时记忆网络（LSTM）**：是 RNN 的一个变体，能够处理长序列数据，广泛应用于自然语言处理和语音识别等领域。

深度学习通过多层神经网络和复杂的训练过程，能够自动提取和整合特征，实现复杂的机器学习任务。了解神经网络的基本结构和训练过程，对于深入理解深度学习和其在图像识别中的应用具有重要意义。接下来，我们将进一步探讨图像识别的基础知识，为后续章节的详细讲解打下基础。----------------------------------------------------------------

## 图像识别的基础知识

图像识别是计算机视觉领域的一个重要分支，旨在通过计算机算法对图像中的内容进行理解和解释。为了更好地理解深度学习在图像识别中的应用，我们需要掌握一些基本概念，如图像特征提取、分类算法、评估指标等。

### 图像特征提取

图像特征提取是将图像数据转换为能够反映图像内容的抽象表示的过程。深度学习在图像识别中的核心优势之一就是能够自动提取有意义的特征，无需人工设计。以下是几种常用的特征提取方法：

1. **局部特征描述符**：局部特征描述符是用于描述图像局部区域的特征，如角点、边缘和纹理等。常见的局部特征描述符包括 SIFT（尺度不变特征变换）和 SURF（加速稳健特征）。

2. **全局特征描述符**：全局特征描述符用于描述整幅图像的整体特征，如颜色分布、形状和纹理。哈希（Hashing）技术是一种常用的全局特征提取方法，它将高维特征映射为低维二进制向量，便于快速处理和比较。

3. **深度学习特征提取**：深度学习模型，特别是卷积神经网络（CNN），可以通过多层卷积和池化操作自动提取高层次的图像特征。这些特征能够捕捉图像中的复杂结构，如物体边界、形状和上下文信息。

### 分类算法

图像识别的核心任务是分类，即将图像划分为不同的类别。以下是几种常用的分类算法：

1. **基于模板匹配的分类算法**：这类算法通过将图像与预先设计的模板进行匹配来识别目标。常见的算法包括欧氏距离、余弦相似度等。

2. **基于特征的分类算法**：这类算法通过提取图像特征，并将特征向量输入到分类器中进行分类。常见的分类器包括支持向量机（SVM）、决策树、随机森林和神经网络等。

3. **基于深度学习的分类算法**：深度学习模型，如卷积神经网络（CNN）和循环神经网络（RNN），可以直接对图像数据进行分类。CNN 是当前图像识别任务中最常用的模型，通过多层卷积和池化操作提取特征，并在全连接层进行分类。

### 评估指标

为了衡量图像识别模型的性能，我们使用一系列评估指标。以下是几种常用的评估指标：

1. **准确率（Accuracy）**：准确率是正确分类的样本数与总样本数的比值。它是评估分类模型性能的最简单指标。

2. **召回率（Recall）**：召回率是正确分类的样本数与实际为该类别的样本数的比值。召回率反映了模型在识别正样本方面的能力。

3. **精确率（Precision）**：精确率是正确分类的样本数与预测为该类别的样本数的比值。精确率反映了模型在避免误分类方面的能力。

4. **F1 分数（F1 Score）**：F1 分数是精确率和召回率的调和平均，综合考虑了模型在识别正样本和避免误分类方面的性能。

5. **ROC 曲线和 AUC（Area Under Curve）**：ROC 曲线和 AUC 是用于评估二分类模型性能的重要指标。ROC 曲线展示了不同分类阈值下的精确率和召回率，而 AUC 表示了模型在各个分类阈值下的整体性能。

## 卷积神经网络（CNN）的基本结构

卷积神经网络（CNN）是一种专为处理图像数据而设计的深度学习模型。与传统的全连接神经网络相比，CNN 通过特殊的网络结构来有效地提取图像特征，并实现高精度的图像识别。CNN 的基本结构包括卷积层、池化层和全连接层，下面将分别介绍这些层的功能和工作原理。

### 卷积层

卷积层是 CNN 中最重要的层之一，负责从图像中提取特征。卷积层通过卷积操作将输入图像与一组可学习的滤波器（也称为卷积核）进行卷积，从而产生特征图（也称为特征图或特征映射）。每个卷积核可以看作是一个小型过滤器，在图像上滑动，并提取特定的特征，如边缘、纹理和角落等。

#### 卷积操作

卷积操作的数学表示如下：

$$
\text{特征图}_{ij}^l = \sum_{k=1}^{m} w_{ijkl} \cdot \text{输入图像}_{ik}^{l-1}
$$

其中，$\text{特征图}_{ij}^l$ 表示第 $l$ 层第 $i$ 行第 $j$ 列的特征图值，$w_{ijkl}$ 表示第 $l$ 层第 $i$ 行第 $j$ 列的卷积核权重，$\text{输入图像}_{ik}^{l-1}$ 表示第 $l-1$ 层第 $i$ 行第 $k$ 列的输入图像值。这个公式表示将卷积核 $w_{ijkl}$ 在输入图像 $\text{输入图像}_{ik}^{l-1}$ 上滑动，并进行元素相乘和求和操作，得到特征图 $\text{特征图}_{ij}^l$ 的值。

#### 激活函数

为了引入非线性特性，卷积层通常会使用激活函数。常用的激活函数包括 ReLU（归一化指数函数）和 sigmoid 函数。ReLU 函数在零以上的输入值上输出相同的输入值，而零以下的输入值输出零，这有助于加速模型的训练。sigmoid 函数将输入值映射到 (0,1) 区间，但容易导致梯度消失问题。

### 池化层

池化层用于减少特征图的尺寸，从而减少模型的参数数量和计算复杂度。池化层通过在特征图上滑动窗口，并取窗口内的最大值或平均值来产生新的特征图。常见的池化方法包括最大池化和平均池化。

#### 最大池化

最大池化的操作如下：

$$
\text{特征图}_{ij}^l = \max(\text{特征图}_{i:i+w_j, j:j+h_j}^{l-1})
$$

其中，$w$ 和 $h$ 分别表示池化窗口的高度和宽度。

#### 平均池化

平均池化的操作如下：

$$
\text{特征图}_{ij}^l = \frac{1}{wh} \sum_{i'=i}^{i+w-1} \sum_{j'=j}^{j+h-1} \text{特征图}_{i'i'j'}^{l-1}
$$

其中，$w$ 和 $h$ 分别表示池化窗口的高度和宽度。

### 全连接层

全连接层是 CNN 的最后一层，负责将特征图映射到类别标签。全连接层中的每个神经元都与上一层的所有神经元相连，从而形成全连接结构。通过全连接层，模型可以学习到图像中的全局特征，并进行分类。

#### 前向传播

在全连接层的前向传播过程中，输入特征图被展平为一维向量，并将其输入到全连接层。每个神经元计算其输入值的加权和，并通过激活函数产生输出。输出层的结果即为模型的预测类别。

$$
\text{输出}_{k} = f(\sum_{i=1}^{n} w_{ik} \cdot \text{特征图}_{i} + b_{k})
$$

其中，$k$ 表示输出层的第 $k$ 个神经元，$n$ 表示特征图的大小，$w_{ik}$ 是连接权重，$b_{k}$ 是偏置项，$f$ 是激活函数。

### CNN 的工作流程

CNN 的工作流程可以概括为以下步骤：

1. **输入层**：输入图像被送入网络。
2. **卷积层**：通过卷积操作提取图像特征。
3. **池化层**：对特征图进行下采样，减少模型参数和计算复杂度。
4. **全连接层**：将特征图映射到类别标签。
5. **输出层**：输出预测类别。

通过这种结构，CNN 能够有效地提取图像中的多层次特征，从而实现高精度的图像识别任务。

### 总结

卷积神经网络（CNN）通过卷积层、池化层和全连接层的组合，能够自动提取图像中的特征，实现高精度的图像识别。卷积层通过卷积操作提取特征，池化层通过下采样减少模型复杂度，全连接层通过分类实现图像识别。了解 CNN 的基本结构和工作原理，对于深入理解深度学习在图像识别中的应用具有重要意义。接下来，我们将通过一个简单的 Python 示例，进一步探讨 CNN 的实现和训练过程。----------------------------------------------------------------

```python
import tensorflow as tf
```

接下来，我们加载数据集，并对其进行预处理：

```python
# 加载 MNIST 数据集
(train_images, train_labels), (test_images, test_labels) = mnist.load_data()

train_images = train_images / 255.0

train_images = train_images.reshape((60000, 28, 28, 1))
```

```python
# 创建模型
model = models.Sequential()

model.add(layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)))

# 添加第二个卷积层

model.add(layers.Flatten())
model.add(layers.Dense(64, activation='relu'))

```

这个模型包括两个卷积层和两个池化层，一个全连接层。第一个卷积层使用 32 个 3x3 的卷积核，第二个卷积层使用 64 个 3x3 的卷积核。全连接层使用 64 个神经元，输出层使用 10 个神经元，对应于 10 个类别。

接下来，我们编译和训练模型：

```python
# 编译模型

# 训练模型
model.fit(train_images, train_labels, epochs=5, batch_size=64)
```

最后，我们使用测试数据集来评估模型的性能：

```python
# 评估模型
test_loss, test_acc = model.evaluate(test_images, test_labels)
print(f"Test accuracy: {test_acc:.4f}")
```

我们可以使用训练好的模型来预测新的图像：

## 其他深度学习算法

在图像识别领域，除了卷积神经网络（CNN）外，还有许多其他深度学习算法被广泛应用。这些算法包括循环神经网络（RNN）、生成对抗网络（GAN）、注意力机制等。下面，我们将分别介绍这些算法的基本概念、原理和应用。

### 循环神经网络（RNN）

循环神经网络（RNN）是一种能够处理序列数据的神经网络。与传统的前向神经网络不同，RNN 具有循环结构，可以记住前面的输入信息，并将其用于后续的计算。这使得 RNN 适用于处理时间序列数据、自然语言处理和语音识别等任务。

#### 基本概念

RNN 的基本单元是循环单元，它包含一个隐藏状态 $h_t$ 和一个输入 $x_t$。隐藏状态 $h_t$ 既是当前时刻的输出，也是下一时刻的输入。RNN 的输入序列可以表示为：

$$
h_t = \sigma(W_h \cdot [h_{t-1}, x_t] + b_h)
$$

其中，$W_h$ 是权重矩阵，$b_h$ 是偏置项，$\sigma$ 是激活函数（通常使用 sigmoid 或 tanh 函数）。RNN 通过递归的方式更新隐藏状态，从而在序列中传递信息。

#### 应用

RNN 在图像识别中的应用主要包括序列建模和时空数据建模。例如，在视频识别任务中，RNN 可以用于提取视频帧的特征，并将这些特征用于分类或目标跟踪。此外，RNN 还可以用于图像字幕生成，将图像中的内容转换为自然语言描述。

### 生成对抗网络（GAN）

生成对抗网络（GAN）是由生成器和判别器组成的深度学习模型。生成器尝试生成逼真的数据，而判别器则试图区分真实数据和生成数据。通过这种对抗性训练，生成器可以学习到如何生成高质量的数据。

#### 基本概念

GAN 的基本结构包括两个神经网络：生成器和判别器。生成器的目标是生成与真实数据相似的数据，判别器的目标是正确分类真实数据和生成数据。GAN 的训练过程如下：

1. **生成器生成数据**：生成器接收随机噪声 $z$，并生成假数据 $G(z)$。

2. **判别器分类**：判别器对真实数据和生成数据进行分类。对于真实数据 $x$，判别器的目标是最大化分类概率 $D(x)$；对于生成数据 $G(z)$，判别器的目标是最小化分类概率 $D(G(z))$。

3. **优化目标**：GAN 的优化目标是在生成器和判别器之间建立一个平衡。通常使用以下目标函数：

   $$
   \min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}(x)} [\log D(x)] + \mathbb{E}_{z \sim p_z(z)} [\log (1 - D(G(z))]
   $$

其中，$p_{data}(x)$ 是真实数据的概率分布，$p_z(z)$ 是噪声的分布。

#### 应用

GAN 在图像识别中的应用主要包括图像生成、图像修复和图像风格转换。例如，GAN 可以用于生成逼真的图像，如图像到图像翻译、超分辨率图像生成等。此外，GAN 还可以用于图像去噪和图像增强。

### 注意力机制

注意力机制是一种用于提高神经网络性能的机制，它通过关注重要信息而忽略无关信息，从而提高模型的准确性和效率。

#### 基本概念

注意力机制的核心是注意力权重，它用于调整不同位置的特征的重要性。注意力权重通常通过一个计算过程得到，例如点积注意力或加性注意力。

点积注意力计算如下：

$$
\text{注意力权重}_{i,j} = \text{query}_{i} \cdot \text{key}_{j}
$$

其中，$\text{query}_{i}$ 和 $\text{key}_{j}$ 分别是查询向量和键向量。查询向量通常来自编码器的最后一层，而键向量来自编码器的所有层。

加性注意力计算如下：

$$
\text{注意力权重}_{i,j} = \text{softmax}(\text{query}_{i} \cdot \text{key}_{j})
$$

其中，$\text{softmax}$ 函数用于将点积结果归一化成概率分布。

#### 应用

注意力机制在图像识别中的应用主要包括图像分割、目标检测和文本图像识别。例如，在目标检测任务中，注意力机制可以帮助模型关注重要的目标区域，从而提高检测的准确率。在图像分割任务中，注意力机制可以用于调整边界和背景的特征权重，从而实现更精确的分割。

深度学习算法在图像识别领域具有广泛的应用。除了 CNN 外，RNN、GAN 和注意力机制等算法也在图像识别任务中发挥了重要作用。这些算法各自具有独特的优势和应用场景，为图像识别技术的发展提供了新的动力。在接下来的章节中，我们将进一步探讨迁移学习和模型集成技术在图像识别中的应用，以及实时图像识别和跨模态识别等前沿研究进展。----------------------------------------------------------------

## 迁移学习与模型集成

迁移学习与模型集成是深度学习在图像识别中常用的两种技术，它们分别通过不同的方法提升模型的性能和泛化能力。本节将介绍这些技术的原理和应用。

### 迁移学习

迁移学习是一种利用预训练模型在新任务上取得良好性能的技术。其基本思想是，将预训练模型在源任务上的知识迁移到目标任务上。源任务通常是一个大规模的通用任务，而目标任务则是一个特定领域的小规模任务。

#### 原理

迁移学习可以分为两类：基于特征的迁移学习和基于模型的迁移学习。

1. **基于特征的迁移学习**：这种方法将预训练模型中的特征提取器（通常是卷积层）应用于新任务，而重新训练全连接层以适应新的分类任务。这种方法利用了预训练模型提取的高层次特征，从而减少了新任务中的数据依赖。

2. **基于模型的迁移学习**：这种方法直接使用预训练模型在新任务上进行微调。在迁移学习过程中，预训练模型的权重作为起点，然后通过少量的额外数据对新权重进行调整。这种方法适用于当新任务与源任务相似时，能够快速提升新任务的表现。

#### 应用

迁移学习在图像识别中的典型应用包括：

1. **小样本学习**：当新任务数据量较少时，迁移学习能够利用预训练模型的知识，避免模型因数据不足而过拟合。

2. **跨域识别**：在源域和数据域之间存在差异时，迁移学习可以帮助模型适应新的数据分布，提高跨域图像识别的准确率。

3. **医疗影像分析**：在医疗影像领域，由于数据获取的困难，迁移学习可以帮助医生快速诊断和分析新的病例。

### 模型集成

模型集成是一种通过结合多个模型的预测来提高整体性能的技术。模型集成的核心思想是，不同的模型可能对数据有不同的理解，通过组合这些模型可以弥补单个模型的缺陷，提高预测的准确性。

#### 原理

模型集成可以分为以下几种方法：

1. **栈式集成**：这种方法将多个模型串联起来，每个模型的输出作为下一个模型的输入。例如，集成学习（Ensemble Learning）就是一种常见的栈式集成方法，包括随机森林、支持向量机等。

2. **加权平均**：这种方法将多个模型的预测结果进行加权平均。权重可以通过交叉验证或学习率调整得到。常见的加权平均方法包括贝叶斯回归、感知机等。

3. **投票法**：这种方法通过统计多个模型的预测结果，选择出现次数最多的类别作为最终预测。投票法适用于分类问题。

4. **集成学习框架**：这种方法使用特定的算法（如 Bagging、Boosting）来构建多个模型，并通过集成策略（如投票、加权平均）来提高整体性能。

#### 应用

模型集成在图像识别中的典型应用包括：

3. **疾病分类**：使用分类算法（如支持向量机、决策树或深度神经网络）将检测结果分类为不同的疾病类型。

实时图像识别是深度学习在图像识别中的一项重要应用，尤其是在自动驾驶、智能监控和安全检测等领域。为了实现高效的实时图像识别，研究人员提出了多种方法，包括优化网络结构和硬件加速等。

1. **网络结构优化**：研究人员通过设计轻量级网络结构，如 MobileNet 和 ShuffleNet，来提高模型在保持高准确率的同时降低计算复杂度。这些网络结构通过减少参数数量和计算量，使得模型能够在低资源设备上实现实时推理。

2. **硬件加速**：为了满足实时性要求，深度学习模型通常需要通过硬件加速来实现。例如，使用 GPU 或 TPU（张量处理单元）可以显著提高模型的推理速度。此外，一些研究还提出了基于 FPGAs（现场可编程门阵列）和 ASICs（专用集成电路）的硬件解决方案，以进一步提高实时图像识别的性能。

3. **端到端训练**：端到端训练是一种直接从原始图像到预测的完整训练过程，避免了传统方法中需要手工设计特征提取和分类器等步骤。通过端到端训练，模型可以更好地利用图像的上下文信息，提高识别的准确率。例如，EfficientDet 等模型通过端到端训练实现了高效的实时物体检测。

### 跨模态识别

跨模态识别是一种将不同模态（如文本、图像、声音等）的信息进行融合和理解的技术。近年来，随着深度学习技术的发展，跨模态识别取得了显著进展。

1. **多模态嵌入**：多模态嵌入是将不同模态的数据映射到一个共同的空间中，从而实现模态之间的信息共享。例如，TextCNN 和 Multimodal Transformer 等模型通过将文本和图像分别映射到共同的嵌入空间中，实现了多模态特征融合。

2. **多模态学习**：多模态学习是一种直接从多模态数据中学习特征的方法。例如，CoAttnNet 等模型通过引入注意力机制，将不同模态的信息进行有效融合，从而提高了跨模态识别的准确率。

3. **多任务学习**：多任务学习是一种同时解决多个相关任务的方法，可以在不同模态之间共享特征表示。例如，一些研究通过在多任务学习框架下同时进行图像分类和文本分类，提高了跨模态识别的性能。

### 医学影像识别

医学影像识别是深度学习在医疗领域的一个重要应用，通过自动分析和识别医学影像，可以为医生提供辅助诊断工具。以下是一些医学影像识别的最新研究进展：

2. **多尺度分析**：多尺度分析是一种同时考虑图像的不同尺度的分析方法。例如，DeepLabV3+ 模型通过引入解码器结构，实现了多尺度的上下文信息融合，从而提高了医学影像分割的准确率。

3. **端到端训练**：端到端训练在医学影像识别中得到了广泛应用。例如，Tiramisu 模型通过端到端训练实现了从医学影像到诊断的完整流程，从而提高了诊断的准确性和效率。

在本附录中，我们将提供一些用于实现本文中讨论的深度学习模型的代码示例。这些示例旨在帮助读者更好地理解相关算法和框架的应用。请注意，以下代码示例需要 TensorFlow 2.x 版本。

### 1. MNIST 数据集加载与预处理

```python
import tensorflow as tf
from tensorflow.keras import layers, models
from tensorflow.keras.datasets import mnist

# 加载 MNIST 数据集
(train_images, train_labels), (test_images, test_labels) = mnist.load_data()

# 归一化图像数据
train_images = train_images / 255.0
test_images = test_images / 255.0

# 将图像数据展平为一维数组
train_images = train_images.reshape((60000, 28, 28, 1))
test_images = test_images.reshape((10000, 28, 28, 1))

# 将标签转换为独热编码
train_labels = tf.keras.utils.to_categorical(train_labels)
test_labels = tf.keras.utils.to_categorical(test_labels)
```

### 2. 卷积神经网络（CNN）模型构建与训练

```python
# 创建模型
model = models.Sequential()

# 添加卷积层
model.add(layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)))
model.add(layers.MaxPooling2D((2, 2)))

# 添加第二个卷积层
model.add(layers.Conv2D(64, (3, 3), activation='relu'))
model.add(layers.MaxPooling2D((2, 2)))

# 添加全连接层
model.add(layers.Flatten())
model.add(layers.Dense(64, activation='relu'))
model.add(layers.Dense(10, activation='softmax'))

# 编译模型
model.compile(optimizer='adam',
              loss='categorical_crossentropy',
              metrics=['accuracy'])

# 训练模型
model.fit(train_images, train_labels, epochs=5, batch_size=64)
```

### 3. 模型评估与预测

```python
# 评估模型
test_loss, test_acc = model.evaluate(test_images, test_labels)
print(f"Test accuracy: {test_acc:.4f}")

# 预测
predictions = model.predict(test_images)
predicted_labels = np.argmax(predictions, axis=1)
print(predicted_labels[:10])  # 输出前 10 个预测结果
```
