- **挑战**：数据不足、类间差异大、类内差异小。

**核心算法原理**：

**伪代码**：

```python
def zero_shot_learning(data, prototypes):
    # 假设prototypes是每个类别的原型向量
    for instance in data:
        nearest Prototype = find_nearest(prototypes, instance)
        predict_label = label_of(nearest Prototype)
    return predict_label
```

**数学模型与公式**：

$$
d(x, p) = \min_{p' \in P} d(x, p')
$$

其中，$x$ 为输入实例，$p$ 为原型向量，$P$ 为原型集合，$d$ 为距离度量。
