3. **历史元素与现代科技的结合**：利用现代科技，如人工智能、大数据、物联网等，对历史元素进行深入分析和处理，使其在现代应用中发挥更大的作用。例如，通过AI技术，可以分析历史文献和资料，提取有价值的信息，为品牌设计提供灵感。

**算法原理**：
提示词生成算法基于自然语言处理（NLP）技术，通过分析文本数据，提取出与特定主题相关的关键词和短语。这些关键词和短语被称为“提示词”，可以用于指导设计过程。

**算法步骤**：

1. **文本预处理**：首先，对历史文献进行文本清洗和预处理，包括去除停用词、标点符号、数字等无关信息，并转换为统一格式。

2. **词向量化**：将预处理后的文本转换为词向量表示。词向量可以通过词嵌入模型（如Word2Vec、GloVe）进行训练和生成。

3. **关键词提取**：利用NLP技术中的文本分类和主题模型（如LDA、Latent Dirichlet Allocation）对词向量进行分析，提取出与特定主题（如香水、香料、仪式等）相关的高频关键词和短语。

4. **提示词生成**：将提取出的关键词和短语进行筛选和整理，形成一组提示词。这组提示词可以用于指导设计师进行创意设计。

import nltk

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import LatentDirichletAllocation

# 步骤1：文本预处理
def preprocess_text(text):
    # 去除标点符号、停用词等
    tokens = nltk.word_tokenize(text)
    filtered_tokens = [token for token in tokens if token not in stop_words]
    return filtered_tokens

# 步骤2：词向量化
def word_embedding(tokens):
    model = Word2Vec(tokens, size=100, window=5, min_count=1, workers=4)
    return model

# 步骤3：关键词提取
def extract_keywords(texts, n_topics=5):
    tfidf_vectorizer = TfidfVectorizer(max_df=0.95, max_features=1000, min_df=2, stop_words='english')
    tfidf = tfidf_vectorizer.fit_transform(texts)
    lda = LatentDirichletAllocation(n_components=n_topics, random_state=0)
    lda.fit(tfidf)
    topics = lda.transform(tfidf)
    feature_names = tfidf_vectorizer.get_feature_names_out()
    topics_df = DataFrame(topics).transpose()
    topics_df.columns = feature_names
    return topics_df

# 步骤4：提示词生成
def generate_prompts(topics_df, n_keywords=10):
    prompts = []
    for index, row in topics_df.iterrows():
        topic_top_words = row.nlargest(n_keywords).index.tolist()
        prompts.append(' '.join(topic_top_words))
    return prompts
