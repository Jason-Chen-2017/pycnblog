```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
from Crypto.Random import get_random_bytes

# Encrypt Data with AES
key = get_random_bytes(16)  # AES key must be either 16, 24, or 32 bytes long
cipher = AES.new(key, AES.MODE_CBC)
ct_bytes = cipher.encrypt(pad(b'This is a secret message!', AES.block_size))
iv = cipher.iv
print(f'Encrypted Data: {ct_bytes.hex()}')
print(f'Initialization Vector: {iv.hex()}')

# Decrypt Data with AES
cipher = AES.new(key, AES.MODE_CBC, iv)
pt = unpad(cipher.decrypt(ct_bytes), AES.block_size)
print(f'Decrypted Data: {pt.decode()}')
```

#### Mathematical Models and Formulas

**Encryption and Decryption in AES**:
The AES algorithm uses a symmetric key to encrypt and decrypt data. The mathematical model involves applying multiple rounds of substitutions, shifts, and XOR operations. The process can be summarized as follows:
$$
C = E_K(P, K_1, K_2, ..., K_n)
$$
$$
P = D_K(C, K_n, K_{n-1}, ..., K_1)
$$
where \( C \) is the ciphertext, \( P \) is the plaintext, and \( K_1, K_2, ..., K_n \) are the round keys derived from the encryption key \( K \).

**Hashing with SHA-256**:
The SHA-256 algorithm processes the input data and produces a fixed-size hash value. The mathematical model can be summarized as:
$$
H = SHA-256(D)
$$
where \( H \) is the hash value and \( D \) is the data.

**Authentication with HMAC**:
HMAC (Hash-based Message Authentication Code) is a cryptographic primitive used for authentication. It combines a hash function with a secret key. The mathematical model is:
$$
MAC = HMAC(K, M)
$$
where \( MAC \) is the authentication code, \( K \) is the secret key, and \( M \) is the message.

#### Example

To illustrate these mathematical models, let's consider an example where we encrypt a message using AES, hash it using SHA-256, and create an HMAC.

```python

import base64

print(f'Initialization Vector: {iv.hex()}')

hmac_value = hmac_obj.digest()
```

In this example, we encrypt a message using AES, hash it with SHA-256, and create an HMAC using the same hash function. This combination ensures that the message is secure, its integrity is maintained, and its authenticity is verified.
