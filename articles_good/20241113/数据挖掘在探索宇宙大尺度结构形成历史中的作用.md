#### 3.4 数据归一化

数据归一化是数据转换的一个重要步骤，旨在将不同来源、不同类型的数据进行归一化处理，以便进行统一分析和比较。数据归一化主要包括以下方法：

   $$
   x_{\text{norm}} = \frac{x - x_{\text{min}}}{x_{\text{max}} - x_{\text{min}}}
   $$

   $$
   x_{\text{norm}} = \frac{x - x_{\text{mean}}}{x_{\text{median}} - x_{\text{mean}}}
   $$

   其中，$x$为原始数据，$x_{\text{mean}}$为平均值，$x_{\text{median}}$为中位数。

   $$
   x_{\text{norm}} = \frac{x - x_{\text{mean}}}{\text{std}}
   $$

   其中，$x$为原始数据，$x_{\text{mean}}$为平均值，$\text{std}$为标准差。

### 4. 关联规则挖掘与宇宙大尺度结构分析

#### 4.1 关联规则挖掘的基本原理

关联规则挖掘是一种用于发现数据项之间潜在关联关系的方法。其核心目标是发现一组数据项之间的相关性，从而揭示数据中的隐含模式。关联规则通常表示为形如`A → B`的形式，表示如果数据项A出现，那么数据项B也很可能出现。

关联规则挖掘的基本原理包括支持度、置信度和lift等三个重要概念：

1. **支持度（Support）**：支持度表示在一个数据集中，同时包含A和B的数据项出现的频率。支持度可以用以下公式表示：

   $$
   \text{support}(A \rightarrow B) = \frac{|\{T | T \text{ 包含 } A \text{ 和 } B\}|}{|\{T | T \text{ 包含 } A\}|}
   $$

   其中，$T$表示数据集中的交易，$|\cdot|$表示集合的基数。

2. **置信度（Confidence）**：置信度表示在包含A的数据项中，同时包含B的数据项的概率。置信度可以用以下公式表示：

   $$
   \text{confidence}(A \rightarrow B) = \frac{|\{T | T \text{ 包含 } A \text{ 和 } B\}|}{|\{T | T \text{ 包含 } A\}|}
   $$

3. **Lift**：Lift值表示关联规则相对于随机概率的增强程度。如果Lift值大于1，表示关联规则比随机概率更强。Lift值可以用以下公式表示：

   $$
   \text{lift}(A \rightarrow B) = \frac{\text{confidence}(A \rightarrow B)}{\text{support}(B)}
   $$

通过上述三个概念，可以有效地发现数据中的潜在关联关系。

#### 4.2 Apriori算法

Apriori算法是一种经典的关联规则挖掘算法，适用于大规模交易数据的挖掘。Apriori算法的基本思想是通过逐层生成候选集，并计算其支持度，从而发现频繁项集。频繁项集是指支持度满足最小支持度阈值（min_support）的项集。

Apriori算法的基本步骤如下：

1. **生成候选1项集**：根据数据集中的所有交易，生成所有可能的1项集。

2. **计算候选1项集的支持度**：对每个候选1项集，计算其在数据集中的支持度。

3. **生成候选k项集**：对于每个满足最小支持度阈值的k-1项集，生成所有可能的k项集。

4. **计算候选k项集的支持度**：对每个候选k项集，计算其在数据集中的支持度。

5. **重复步骤3和4，直到无法生成新的频繁项集**。

Apriori算法的伪代码如下：

```
生成候选1项集：
for 每个交易T in 数据集D：
    对于T中的每个项项i：
        将i添加到候选1项集中

计算候选1项集的支持度：
for 每个候选1项集C1：
    C1的支持度 = |{T | T包含C1}| / |D|

生成候选k项集：
for 每个满足最小支持度阈值的k-1项集Ck-1：
    对于Ck-1中的每个项项i：
        将i从Ck-1中移除，生成Ck

计算候选k项集的支持度：
for 每个候选k项集Ck：
    Ck的支持度 = |{T | T包含Ck}| / |D|

while 存在新的频繁项集：
    更新频繁项集列表
    生成新的候选k项集
    计算新候选k项集的支持度
```

#### 4.3 FP-growth算法

FP-growth算法是一种基于前缀路径的关联规则挖掘算法，相对于Apriori算法，FP-growth算法在处理大规模数据集时具有更高的效率。FP-growth算法的基本思想是首先将数据集压缩成一个频繁模式树（FP-tree），然后使用该树生成频繁项集。

FP-growth算法的基本步骤如下：

1. **构建频繁模式树（FP-tree）**：将数据集转换为FP-tree，其中每个节点表示一个项，节点中的频次表示该项在数据集中的出现次数。

2. **挖掘频繁项集**：从FP-tree中递归地挖掘频繁项集。对于每个频繁项，递归地将其从FP-tree中移除，生成子树，并继续挖掘子树中的频繁项集。

3. **生成关联规则**：对于每个频繁项集，生成其满足最小支持度阈值的关联规则。

FP-growth算法的伪代码如下：

```
构建FP-tree：
for 每个交易T in 数据集D：
    对于T中的每个项项i：
        更新FP-tree中的节点i的频次

挖掘频繁项集：
生成频繁模式树（FP-tree）
for 每个频繁项i in FP-tree：
    递归挖掘i的子树中的频繁项集

生成关联规则：
for 每个频繁项集C：
    计算C的支持度
    对于每个非空子集B of C：
        计算关联规则C → B的置信度
        如果置信度大于最小置信度阈值，输出关联规则C → B
```

#### 5.1 聚类分析的基本原理

聚类分析的核心目标是将数据点划分为若干个群组（簇），使得同组内的数据点之间的距离较小，而不同组的数据点之间的距离较大。聚类分析通常分为以下几种类型：

1. **基于距离的聚类**：此类方法基于数据点之间的距离来划分簇，常用的算法包括K-means算法、层次聚类算法和DBSCAN算法等。

#### 5.2 K-means算法

K-means算法是一种基于距离的聚类算法，其基本思想是找到K个簇中心，并使得每个数据点与簇中心之间的距离最小。具体步骤如下：

1. **初始化簇中心**：随机选择K个数据点作为初始簇中心。

2. **分配数据点**：对于每个数据点，计算其与每个簇中心的距离，并将其分配到最近的簇中心。

3. **更新簇中心**：计算每个簇的数据点的均值，作为新的簇中心。

4. **重复步骤2和3，直到收敛**：当簇中心不再发生显著变化时，聚类过程结束。

```

分配数据点：
for 每个数据点x：
    计算x与每个簇中心的距离

更新簇中心：
for 每个簇：
    计算簇中所有数据点的均值

重复步骤2和3，直到收敛
```

#### 5.3 层次聚类算法

层次聚类算法是一种基于距离的聚类算法，通过递归地将数据点合并或分裂，形成层次结构。层次聚类算法可以分为两种类型：

1. **自底向上的方法**：自底向上的方法从单个数据点开始，逐步合并相似的数据点，形成层次结构。

2. **自顶向下的方法**：自顶向下的方法从所有数据点都属于同一簇开始，逐步分裂数据点，形成层次结构。

层次聚类算法的伪代码如下：

```

合并簇：
while 存在两个或更多簇：
    找到距离最近的两个簇
    合并这两个簇

自顶向下层次聚类算法：
初始化：所有数据点都属于同一簇

分裂簇：
while 不满足停止条件：
    对于每个簇：
        计算簇内数据点的距离
        如果距离小于某个阈值，继续分裂簇
        如果距离大于某个阈值，合并簇

停止条件可以是簇的数量达到某个阈值或簇内距离变化小于某个阈值
```
