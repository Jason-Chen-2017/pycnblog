#### 数学公式

社会力模型的数学公式如下：

$$ F = \frac{1}{r^2} (\nabla \phi + \nabla \phi_{d}) $$

其中：

- $ \nabla $ 表示梯度算子。

#### 举例说明

假设有两个个体 $ A $ 和 $ B $，它们之间的距离为 $ r $，个体 $ A $ 的势能为 $ \phi_A $，个体 $ B $ 的势能为 $ \phi_B $，动态势能为 $ \phi_{d_B} $。

$$ F_{AB} = \frac{1}{r^2} (\nabla \phi_A + \nabla \phi_{d_B}) $$

同样，个体 $ B $ 对个体 $ A $ 的作用力为：

$$ F_{BA} = \frac{1}{r^2} (\nabla \phi_B + \nabla \phi_{d_A}) $$

这两个力的大小相等，方向相反，符合牛顿第三定律。

#### 详细讲解

社会力模型通过模拟个体之间的相互作用力，实现了对集体行为的模拟。在这个模型中，个体之间的作用力取决于它们之间的距离和势能。当个体之间的距离小于某个阈值时，它们之间的相互作用力会增大，从而推动个体相互靠近或远离。

import numpy as np
import matplotlib.pyplot as plt
import pygame

# 初始化参数
N = 100            # 个体数量
size = 500         # 环境大小
velocity = 1       # 个体速度
time_step = 0.1    # 模拟时间步长
sim_time = 100     # 模拟总时间

# 初始化个体位置
positions = np.random.uniform(0, size, (N, 2))

# 初始化个体速度
velocities = np.random.uniform(-velocity, velocity, (N, 2))

# 模拟集体行为
for t in range(int(sim_time / time_step)):
    # 更新个体位置
    positions += velocities * time_step

    # 计算个体之间的相互作用力
    forces = compute_forces(positions)

    # 更新个体速度
    velocities += forces / N * time_step

    # 绘制个体
    draw_individuals(positions)

    # 检查是否需要保存图像
    if t % 100 == 0:
        plt.figure()
        plt.scatter(positions[:, 0], positions[:, 1])
        plt.title(f"Time Step: {t}")
        plt.savefig(f"images/{t}.png")

# 结束模拟
plt.show()

# 计算个体之间的相互作用力
def compute_forces(positions):
    forces = np.zeros((N, 2))
    for i in range(N):
        for j in range(N):
            if i != j:
                distance = np.linalg.norm(positions[i] - positions[j])
                force = -1 / (distance**2) * (positions[j] - positions[i])
                forces[i] += force
    return forces

# 绘制个体
def draw_individuals(positions):
    screen = pygame.display.set_mode((size, size))
    for i in range(N):
        pygame.draw.circle(screen, (255, 0, 0), (int(positions[i][0]), int(positions[i][1])), 2)
    pygame.display.update()
