## 数据结构基础

### 线性表

线性表是一种常用的数据结构，用于存储一系列元素，这些元素按照一定的顺序排列。线性表可以分为单向链表、双向链表和循环链表。单向链表由一系列节点组成，每个节点包含数据和一个指向下一个节点的指针。双向链表在单向链表的基础上，增加了指向前一个节点的指针。循环链表是一个首尾相连的链表，最后一个节点的指针指向第一个节点。

```mermaid
sequenceDiagram
    participant NodeA
    participant NodeB
    participant Head
    participant Tail
    
    Head->>NodeA: next
    NodeA->>NodeB: next
    NodeB->>Tail: next
    Tail->>Head: next
```

### 栈和队列

栈是一种后进先出（LIFO）的数据结构，而队列是一种先进先出（FIFO）的数据结构。栈和队列都是线性结构，但它们的操作方式不同。栈的操作主要包括入栈（push）和出栈（pop），而队列的操作主要包括入队（enqueue）和出队（dequeue）。

```mermaid
sequenceDiagram
    participant Stack
    participant Queue
    
    Stack->>Node: push
    Stack->>Node: pop
    
    Queue->>Node: enqueue
    Queue->>Node: dequeue
```

### 链表

链表是一种由节点组成的线性结构，每个节点包含数据和指向下一个节点的指针。链表可以根据指针的指向方式分为单向链表、双向链表和循环链表。单向链表由一系列节点组成，每个节点包含数据和一个指向下一个节点的指针。双向链表在单向链表的基础上，增加了指向前一个节点的指针。循环链表是一个首尾相连的链表，最后一个节点的指针指向第一个节点。

```mermaid
sequenceDiagram
    participant NodeA
    participant NodeB
    participant Head
    participant Tail
    
    Head->>NodeA: next
    NodeA->>NodeB: next
    NodeB->>Tail: next
    Tail->>Head: next
```

### 树

树是一种层级结构的数据结构，由节点和边组成。树中的节点可以分为根节点、内部节点和叶子节点。根节点是树的起点，内部节点是有子节点的节点，叶子节点是没有子节点的节点。树可以分为二叉树、二叉搜索树和堆等。

```mermaid
treeDiagram
    A --> B --> C
    A --> D --> E
    A --> F
```

### 图

图是一种由节点和边组成的非层级结构的数据结构。图中的节点可以表示实体，边表示实体之间的关系。图可以分为无向图和有向图，还可以根据边的权重分为加权图和无权图。

```mermaid
graph
    A --> B
    B --> C
    C --> D
```
