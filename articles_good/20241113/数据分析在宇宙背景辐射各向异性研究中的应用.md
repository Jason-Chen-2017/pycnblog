2. **无监督学习（Unsupervised Learning）**：无监督学习是一种没有标签数据的学习方法，通过观察数据的内在结构，模型可以学习数据的分布和模式。常见的无监督学习方法包括聚类分析、主成分分析（PCA）等。

4. **强化学习（Reinforcement Learning）**：强化学习是一种通过与环境交互来学习决策策略的方法，模型通过奖励和惩罚来优化其行为。

data_normalized = (data_processed - np.mean(data_processed)) / data_std

fft_shifted = fftshift(fft_data)

power_spectrum = np.abs(fft_shifted) ** 2
freq = np.fft.fftfreq(len(data_normalized), d=1)

# 绘制功率谱
plt.figure(figsize=(12, 6))
plt.subplot(1, 2, 1)

plt.xlabel('Time')
plt.ylabel('Normalized Temperature')
plt.title('COBE Satellite Temperature Data')
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(freq, power_spectrum, label='Power Spectrum')
plt.xlabel('Frequency')
plt.ylabel('Power')
plt.title('Power Spectrum of COBE Satellite Temperature Data')
plt.legend()

plt.tight_layout()
plt.show()

# 线性回归模型拟合
model = LinearRegression()
