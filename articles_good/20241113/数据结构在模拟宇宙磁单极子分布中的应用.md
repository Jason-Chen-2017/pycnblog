### 数据结构基础

#### 数组与链表

数组（Array）是一种线性数据结构，用于存储一系列元素。数组的特点是元素存储在连续的内存空间中，可以通过索引（index）直接访问。数组的优点是访问速度快，便于进行随机访问。然而，数组的缺点是大小固定，不能动态扩展。

链表（Linked List）也是一种线性数据结构，由一系列节点（Node）组成，每个节点包含数据和指向下一个节点的指针。链表的优点是大小可以动态扩展，插入和删除操作灵活。然而，链表的缺点是访问速度相对较慢，需要遍历链表。

#### 树与图

树（Tree）是一种非线性数据结构，由节点（Node）组成，每个节点可以有零个或多个子节点。树的特点是层次结构，每个节点只有一个父节点，除了根节点外。树的优点是易于表示层次关系，便于进行遍历和查找。树的缺点是插入和删除操作复杂，需要调整树的结构。

图（Graph）是一种非线性数据结构，由节点（Vertex）和边（Edge）组成。图的特点是节点之间的连接可以是不确定的，形成复杂的网络结构。图的优点是适用于表示复杂关系，如社交网络、交通网络等。图的缺点是遍历和查找操作复杂，需要考虑边的数量和类型。

#### 其他数据结构

除了上述常见的线性、树和图数据结构外，还有其他类型的数据结构，如堆（Heap）、散列表（Hash Table）等。堆是一种优先级队列，常用于排序和查找。散列表是一种基于散列函数的数据结构，用于快速查找和插入元素。

不同类型的数据结构各有优缺点，适用于不同的应用场景。在实际应用中，需要根据具体需求选择合适的数据结构，以优化程序的性能和效率。

```python
import numpy as np
import matplotlib.pyplot as plt

def initialize_grid(size):
    # 初始化宇宙空间网格
    grid = np.zeros((size, size), dtype=int)
    return grid

def add_magnetic_monopole(grid, x, y):
    # 在网格中添加磁单极子
    grid[y, x] += 1

def simulate_distribution(grid, monopoles):
    # 模拟磁单极子分布
    for monopole in monopoles:
        x, y = monopole
        grid[y, x] += 1

    return grid

def visualize_distribution(grid):
    # 可视化磁单极子分布
    plt.imshow(grid, cmap='hot', interpolation='nearest')
    plt.colorbar()
    plt.show()

# 设置宇宙空间大小和磁单极子数量
size = 100
monopoles = [(50, 50), (75, 75), (25, 25)]

# 初始化网格
grid = initialize_grid(size)

# 添加磁单极子
for monopole in monopoles:
    x, y = monopole
    add_magnetic_monopole(grid, x, y)

# 模拟磁单极子分布
simulated_grid = simulate_distribution(grid, monopoles)

# 可视化结果
visualize_distribution(simulated_grid)
```
