## 第二部分：图论基础与应用

### 2.1 图论基础

图论是研究图及其性质的一个数学分支，它在计算机科学、网络理论、生物学等多个领域中都有广泛应用。图由节点和边组成，节点表示图中的个体，边表示个体之间的关系。在宇宙暗能量网络拓扑的研究中，图论基础是理解和分析宇宙网络结构的重要工具。

#### 2.1.1 图的基本概念

图的基本概念包括：

1. **节点（Vertex）**：图中的个体，通常表示星系、恒星或其他天体。
2. **边（Edge）**：连接节点的线段，通常表示节点之间的相互作用或连接关系。
3. **路径**：连接两个节点的边的序列，路径可以是直接的，也可以是间接的。
4. **连通性**：如果两个节点可以通过一系列边直接或间接地连接，则称这两个节点是连通的。
5. **连通图**：图中任意两个节点都是连通的，这种图称为连通图。

#### 2.1.2 图的基本性质

图的基本性质包括：

1. **连通性**：连通性描述了图中节点的连接情况。连通图中的任意两个节点都是连通的，而在非连通图中，节点之间可能存在隔离。
2. **路径长度**：路径长度是指路径上边的数量。最短路径问题是一个经典的图论问题，它寻找图中两点之间的最短路径。
3. **图的度**：图中每个节点的度是指连接到该节点的边的数量。度大于等于2的节点称为连通节点，度等于1的节点称为孤立节点。
4. **图的密度**：图的密度是指边数与节点数的比值。密度越大，图的结构越密集。

#### 2.1.3 图的基本算法

图的基本算法包括：

1. **深度优先搜索（DFS）**：DFS是一种用于遍历图的算法，它从某个节点开始，沿着一条路径深入到每个分支，直到无法继续为止，然后回溯到上一个节点，继续沿其他路径深入。
2. **广度优先搜索（BFS）**：BFS是一种用于遍历图的算法，它从某个节点开始，首先遍历所有直接相邻的节点，然后逐层遍历更远的节点。
3. **最短路径算法**：Dijkstra算法和Floyd算法是两种常用的最短路径算法。Dijkstra算法适用于有向图和无权图，而Floyd算法适用于有向图和无向图。
4. **图的连通性检查**：可以使用DFS或BFS来检查图的连通性。如果从一个节点开始遍历，能够访问到所有其他节点，则图是连通的。

### 2.2 常见数据结构在图中的应用

在图论中，常见的数据结构包括邻接矩阵、邻接表和向量表示法。这些数据结构在不同的应用场景中各有优势。

#### 2.2.1 邻接矩阵

邻接矩阵是一种用于表示图的二维数组，其中行和列分别表示图的节点，而数组元素表示节点之间的边。如果节点i和节点j之间有边，则矩阵中的元素\[i][j]为1，否则为0。

邻接矩阵的优点是它允许快速随机访问节点之间的边，这使得在需要频繁查询节点连接关系时非常有效。但缺点是当图的边数较少时，邻接矩阵会浪费大量的存储空间。

伪代码：

```plaintext
function initializeGraph(n):
    create a n x n matrix adjMatrix filled with 0s
    return adjMatrix

function addEdge(adjMatrix, i, j):
    adjMatrix[i][j] = 1
    adjMatrix[j][i] = 1

function areConnected(adjMatrix, i, j):
    return adjMatrix[i][j] == 1
```

#### 2.2.2 邻接表

邻接表是一种使用数组存储节点的邻接关系的结构。每个节点都有一个链表，链表中存储了与该节点相连的所有其他节点。

邻接表的优点是它适用于稀疏图，可以节省存储空间。缺点是查询节点之间的连接关系可能需要遍历链表，效率较低。

伪代码：

```plaintext
class Graph:
    def __init__(self, n):
        self.adjLists = [[] for _ in range(n)]

    def addEdge(self, i, j):
        self.adjLists[i].append(j)
        self.adjLists[j].append(i)

    def areConnected(self, i, j):
        return j in self.adjLists[i]
```

#### 2.2.3 向量表示法

向量表示法是一种用于表示图的结构的方法，它使用向量来存储节点的邻接关系。每个向量对应一个节点，向量中的元素表示与该节点相连的其他节点。

向量表示法的优点是它简单直观，且适用于大规模稀疏图。缺点是访问特定节点的邻接关系可能需要线性搜索。

伪代码：

```plaintext
class Graph:
    def __init__(self, n):
        self.adjVectors = [[] for _ in range(n)]

    def addEdge(self, i, j):
        self.adjVectors[i].append(j)

    def areConnected(self, i, j):
        return j in self.adjVectors[i]
```

通过上述分析，我们可以看到，邻接矩阵、邻接表和向量表示法在图的应用中各有优势。选择合适的结构取决于具体的应用场景和需求。

1. **数组**：数组是一种线性数据结构，它使用连续的内存空间来存储元素。数组提供了快速随机访问的能力，但插入和删除操作可能需要移动大量数据。
2. **链表**：链表是一种线性数据结构，它使用非连续的内存空间来存储元素。链表提供了高效的插入和删除操作，但访问元素可能需要遍历链表。
3. **栈和队列**：栈和队列是特殊的线性结构，分别遵循后进先出（LIFO）和先进先出（FIFO）的原则。栈和队列在处理特定类型的操作时非常高效。
4. **树**：树是一种非线性结构，它由一组节点组成，每个节点可以有零个或多个子节点。树结构在处理层次关系和路径问题时非常有效。
5. **图**：图是一种复杂的非线性结构，它由一组节点和连接节点的边组成。图结构可以用于描述宇宙中复杂的相互作用关系。

##### 附录A.2 常见算法介绍

1. **深度优先搜索（DFS）**：DFS是一种用于遍历图的算法，它从某个节点开始，沿着一条路径深入到每个分支，直到无法继续为止，然后回溯到上一个节点，继续沿其他路径深入。
2. **广度优先搜索（BFS）**：BFS是一种用于遍历图的算法，它从某个节点开始，首先遍历所有直接相邻的节点，然后逐层遍历更远的节点。
3. **最短路径算法**：Dijkstra算法和Floyd算法是两种常用的最短路径算法。Dijkstra算法适用于有向图和无权图，而Floyd算法适用于有向图和无向图。
4. **社区发现算法**：如Girvan-Newman算法和Louvain算法，可以用来发现图中的社群结构。
5. **网络流算法**：如最大流-最小割定理和Edmonds-Karp算法，可以用来计算图中的交易流量。
