### 2.1 排序算法

排序算法是计算机科学中最为基础和常用的算法之一。以下是几种常见的排序算法及其复杂度分析：

#### 2.1.1 快速排序

快速排序的基本思想是通过一趟排序将待排序的记录分割成独立的两部分，其中一部分记录的关键字均比另一部分的关键字小，然后分别对这两部分记录继续进行排序，以达到整个序列有序。

**伪代码：**
```
function quicksort(arr):
    if length(arr) <= 1:
        return arr
    pivot = arr[length(arr) / 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
```

**时间复杂度：** 最坏情况下为O(n^2)，平均情况下为O(n log n)。

**空间复杂度：** O(log n)。

#### 2.1.2 归并排序

归并排序是一种典型的分治算法，其基本思想是将待排序的序列不断划分为更小的子序列，直到每个子序列只有一个元素，然后将这些子序列两两合并，直到整个序列有序。

**伪代码：**
```
function mergeSort(arr):
    if length(arr) <= 1:
        return arr
    mid = length(arr) / 2
    left = mergeSort(arr[:mid])
    right = mergeSort(arr[mid:])
    return merge(left, right)

function merge(left, right):
    result = []
    while length(left) > 0 and length(right) > 0:
        if left[0] < right[0]:
            result.append(left.pop(0))
        else:
            result.append(right.pop(0))
    result.extend(left)
    result.extend(right)
    return result
```

**时间复杂度：** O(n log n)。

**空间复杂度：** O(n)。

#### 2.1.3 堆排序

堆排序利用堆这种数据结构所设计的一种排序算法。堆是一种近似完全二叉树的结构，并同时满足堆积的性质：即子节点的键值或索引总是小于（或者大于）它的父节点。

**伪代码：**
```
function heapify(arr, n, i):
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2
    if left < n and arr[left] > arr[largest]:
        largest = left
    if right < n and arr[right] > arr[largest]:
        largest = right
    if largest != i:
        swap(arr[i], arr[largest])
        heapify(arr, n, largest)

function heapSort(arr):
    n = length(arr)
    for i = n // 2 - 1 to 0:
        heapify(arr, n, i)
    for i = n - 1 to 0:
        swap(arr[0], arr[i])
        heapify(arr, i, 0)
```

**时间复杂度：** O(n log n)。

**空间复杂度：** O(1)。

### 2.2 搜索算法

搜索算法用于在数据集合中查找特定元素，以下介绍几种常见的搜索算法：

#### 2.2.1 二分搜索

二分搜索算法是一种高效的查找算法，其基本思想是每次比较中间元素，然后根据比较结果排除一半的元素，逐步缩小查找范围。

**伪代码：**
```
function binarySearch(arr, target):
    low = 0
    high = length(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

**时间复杂度：** O(log n)。

**空间复杂度：** O(1)。

#### 2.2.2 暴力搜索

暴力搜索是一种简单的搜索算法，其基本思想是依次检查每个元素，直到找到目标元素或遍历整个数据集合。

**伪代码：**
```
function暴力搜索(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1
```

**时间复杂度：** O(n)。

**空间复杂度：** O(1)。

#### 2.2.3 深度优先搜索

深度优先搜索（DFS）是一种用于遍历或搜索树或图的算法。其基本思想是沿着一个路径一直走到底，然后回溯。

**伪代码：**
```
function DFS(graph, node):
    visited.add(node)
    for neighbor in graph[node]:
        if neighbor not in visited:
            DFS(graph, neighbor)
```

**时间复杂度：** O(V+E)，其中V是顶点数，E是边数。

**空间复杂度：** O(V)。

### 2.3 图算法

图算法广泛应用于网络分析、社交网络等场景。以下介绍几种常见的图算法：

#### 2.3.1 拓扑排序

拓扑排序是一种用于对有向无环图（DAG）进行排序的算法。其基本思想是按照每个节点的入度（指向该节点的边的数量）进行排序。

**伪代码：**
```
function topologicalSort(DAG):
    inDegree = [0 for _ in range(V)]
    for node in DAG:
        for neighbor in DAG[node]:
            inDegree[neighbor] += 1
    queue = [node for node in range(V) if inDegree[node] == 0]
    sortedOrder = []
    while queue:
        node = queue.pop(0)
        sortedOrder.append(node)
        for neighbor in DAG[node]:
            inDegree[neighbor] -= 1
            if inDegree[neighbor] == 0:
                queue.append(neighbor)
    return sortedOrder
```

**时间复杂度：** O(V+E)。

**空间复杂度：** O(V)。

#### 2.3.2 最短路径算法

最短路径算法用于计算图中两个顶点之间的最短路径。以下是几种常见最短路径算法的介绍：

##### 2.3.2.1 Dijkstra算法

Dijkstra算法是一种用于计算单源最短路径的贪心算法。其基本思想是维护一个优先队列，每次选择未访问过的顶点中距离源点最近的顶点进行扩展。

**伪代码：**
```
function Dijkstra(graph, source):
    distances = [infinity for _ in range(V)]
    distances[source] = 0
    priorityQueue = [(0, source)]
    while priorityQueue:
        currentDistance, currentNode = priorityQueue.pop(0)
        if currentDistance > distances[currentNode]:
            continue
        for neighbor, weight in graph[currentNode].items():
            distance = currentDistance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                priorityQueue.append((distance, neighbor))
    return distances
```

**时间复杂度：** O(V^2)，在图是稀疏的情况下，可以使用斐波那契堆优化到O((V+E)logV)。

**空间复杂度：** O(V)。

##### 2.3.2.2 Bellman-Ford算法

Bellman-Ford算法是一种用于计算单源最短路径的动态规划算法。其基本思想是迭代更新每个顶点的最短路径估计。

**伪代码：**
```
function BellmanFord(graph, source):
    distances = [infinity for _ in range(V)]
    distances[source] = 0
    for _ in range(V - 1):
        for edge in graph:
            if distances[edge[0]] + edge[2] < distances[edge[1]]:
                distances[edge[1]] = distances[edge[0]] + edge[2]
    for edge in graph:
        if distances[edge[0]] + edge[2] < distances[edge[1]]:
            return "Graph contains a negative weight cycle"
    return distances
```

**时间复杂度：** O(V*E)。

**空间复杂度：** O(V)。

#### 2.3.3 最小生成树算法

最小生成树算法用于计算无向加权图的最小生成树。以下是几种常见最小生成树算法的介绍：

##### 2.3.3.1 Prim算法

Prim算法是一种用于构建最小生成树的贪心算法。其基本思想是从一个顶点开始，逐步添加权重最小的边，直到所有顶点都被包含在最小生成树中。

**伪代码：**
```
function Prim(graph):
    visited = set()
    minEdge = (infinity, None)
    minimum = infinity
    while len(visited) < V:
        for edge in graph:
            if edge[2] < minimum and edge[1] not in visited:
                minimum = edge[2]
                minEdge = edge
        visited.add(minEdge[1])
        minimum = infinity
    return visited
```

**时间复杂度：** O(ElogV)，在图是稀疏的情况下，可以使用斐波那契堆优化到O(E)。

**空间复杂度：** O(V)。

##### 2.3.3.2 Kruskal算法

Kruskal算法是一种用于构建最小生成树的贪心算法。其基本思想是按权重顺序选择边，并确保不会形成环。

**伪代码：**
