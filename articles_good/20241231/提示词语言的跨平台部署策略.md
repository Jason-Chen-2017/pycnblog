- **语法分析**：语法分析是将输入文本分解成语法结构的过程。这一步骤通常使用递归下降分析器或LR（1）分析器等算法实现。

- **语义分析**：语义分析是将语法结构转换为抽象语法树（AST）的过程，用于确定每个表达式的语义和执行顺序。

- **代码生成**：代码生成是将AST转换为特定平台上的机器代码或字节码的过程。这一步骤通常使用编译器实现，例如CPython中的抽象语法树（AST）转换器。

- **跨平台转换**：跨平台转换是将生成的机器代码或字节码转换为特定平台上的可执行代码的过程。这通常需要依赖编译器或解释器，如JVM（Java虚拟机）或.NET运行时。

        print(f"Entering rule: {rule.symbol}")

    def exitEveryRule(self, rule):
        print(f"Exiting rule: {rule.symbol}")

def parse_prompt(prompt_text):
    input_stream = InputStream(prompt_text)
    lexer = parserLexer(input_stream)
    token_stream = CommonTokenStream(lexer)
    parser = parserParser(token_stream)
    listener = PromptParserListener()
    walker = ParseTreeWalker()
    walker.walk(parser, listener)
