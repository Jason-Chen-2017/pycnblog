from itertools import product

# 定义状态机模型
def build_state_machine():
    states = ['start', 'hello', 'world', 'end']
    transitions = [('start', 'hello', 'input == "hello"'),
                   ('hello', 'world', 'input == "world"'),
                   ('world', 'end', 'input == "exit"')]

    G.add_nodes_from(states)
    G.add_edges_from(transitions)

    state_space = set()
    for state in G.nodes():
        for input in inputs:
            state_space.add((state, input))
    return state_space

# 验证状态转换
def verify_transitions(G, state_space):
    for state, input in state_space:
        if (state, input) not in G.edges():
            return False
    return True

# 验证正确性
def verify_correctness(G, state_space, correct_states):
    for state, _ in state_space:
        if state not in correct_states:
            return False
    return True

# 测试

inputs = ["hello", "world", "exit", "exit"]
state_space = generate_state_space(G, inputs)

#### 状态机模型

状态机模型是一种常用的数学模型，用于描述系统的状态和行为。状态机模型由以下部分组成：

1. **状态集合（Q）**：系统可能处于的所有状态。
2. **输入集合（I）**：触发状态转换的输入。
3. **输出集合（O）**：系统执行特定操作后的输出。
4. **初始状态（q0）**：系统开始时的状态。
5. **状态转换函数（δ）**：描述状态转换的函数，δ: Q × I → Q，表示在当前状态q和输入i下，系统将转移到下一个状态q'。
6. **输出函数（σ）**：描述系统输出的函数，σ: Q × I → O，表示在当前状态q和输入i下，系统的输出o。

状态机模型可以用以下公式表示：

δ(q, i) = q'，表示在状态q和输入i下，系统将转移到状态q'。

σ(q, i) = o，表示在状态q和输入i下，系统的输出为o。

#### 形式化验证公式

形式化验证公式用于描述系统满足预定的属性和要求。以下是一些常用的形式化验证公式：

1. **一致性公式**：描述系统在所有可能输入下，状态转换是否一致。

   ∀q ∈ Q，∀i ∈ I，δ(q, i) ∈ Q

   这个公式表示对于系统中的任意状态q和任意输入i，状态转换的结果q'也是系统中的某个状态。

2. **完备性公式**：描述系统在所有可能输入下，状态是否可达。

   ∀q ∈ Q，∃i ∈ I，δ(q, i) ∈ Q

   这个公式表示对于系统中的任意状态q，存在某个输入i，使得系统能够从状态q转移到其他状态。

3. **正确性公式**：描述系统是否满足预定的属性和要求。

   ∀q ∈ Q，∀i ∈ I，∃o ∈ O，σ(q, i) = o

   这个公式表示对于系统中的任意状态q和任意输入i，系统会产生一个有效的输出o。
