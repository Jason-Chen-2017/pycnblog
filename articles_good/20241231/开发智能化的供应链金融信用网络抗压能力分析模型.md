**4.1 模型的数学基础**

抗压能力分析模型的数学基础主要建立在图论和概率论之上。图论提供了描述网络结构的基本工具，如节点度、路径长度等。概率论则帮助我们评估网络在面对不确定性因素时的稳健性。

模型的核心公式为：

$$
AP = \frac{1}{N} \sum_{i=1}^{N} \frac{1}{d(i)}
$$

其中，$N$ 表示网络中的节点数，$d(i)$ 表示节点 $i$ 的度，即与节点 $i$ 直接相连的其他节点数。度是一个重要的拓扑属性，可以反映节点在网络中的重要性。

**4.2 公式推导与解释**

我们可以通过以下步骤来推导上述公式：

1. **定义抗压能力**：抗压能力是网络在应对外部冲击（如节点失效、信息丢失等）时的能力。度越小，表示节点连接较少，受到的冲击越容易扩散。

2. **节点度与冲击**：假设节点 $i$ 的度 $d(i)$ 较小，则当节点 $i$ 失效时，对整个网络的影响较小，因为其连接的节点较少。

3. **平均度**：为了评估整个网络的抗压能力，我们计算所有节点度的平均值。这个平均值表示网络中节点的平均连接程度。

4. **公式推导**：根据定义，抗压能力可以表示为：

   $$
   AP = \frac{1}{N} \sum_{i=1}^{N} \frac{1}{d(i)}
   $$

   其中，$N$ 是节点总数，$d(i)$ 是节点 $i$ 的度。

**4.3 例子分析**

考虑一个由5个节点组成的信用网络，节点及其度数如下：

| 节点 | 度数 |
| --- | --- |
| A | 2 |
| B | 3 |
| C | 1 |
| D | 4 |
| E | 2 |

我们可以计算该网络的抗压能力：

$$
AP = \frac{1}{5} \left( \frac{1}{2} + \frac{1}{3} + \frac{1}{1} + \frac{1}{4} + \frac{1}{2} \right) = \frac{1}{5} \left( 0.5 + 0.3333 + 1 + 0.25 + 0.5 \right) = 0.7333

这个结果表明，网络的抗压能力相对较高。具体来说，节点度数较大的节点（如D节点，度数为4）对网络的抗压能力有显著影响，而度数较小的节点（如C节点，度数为1）对网络的抗压能力影响较小。

以下是实现抗压能力分析模型的核心源代码：

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler
from networkx import Graph
from collections import defaultdict

def collect_data():
    # 伪代码：从数据库或API收集数据
    data = pd.read_csv('supply_chain_data.csv')
    return data

def data_cleaning(data):
    # 伪代码：数据清洗和处理
    cleaned_data = data.dropna()
    return cleaned_data

def build_credit_network(cleaned_data):
    graph = Graph()
    for index, row in cleaned_data.iterrows():
        graph.add_node(row['entity_id'])
        for partner in row['partners'].split(','):
            graph.add_edge(row['entity_id'], partner)
    return graph

def compute_anti_pressure_ability(graph):
    ability_scores = defaultdict(float)
    for node in graph.nodes():
        degree = graph.degree(node)
        ability_scores[node] = 1 / degree
    return ability_scores

def assess_results(ability_scores):
    # 伪代码：评估结果并输出
    for node, score in ability_scores.items():
        print(f"节点 {node} 的抗压能力为：{score}")

# 主函数
if __name__ == "__main__":
    data = collect_data()
    cleaned_data = data_cleaning(data)
    graph = build_credit_network(cleaned_data)
    ability_scores = compute_anti_pressure_ability(graph)
    assess_results(ability_scores)
```
