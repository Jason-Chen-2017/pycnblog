#### 2.1 果酒分类

果酒是一种以新鲜水果为原料，通过发酵等工艺制成的酒类。根据酿造工艺和原料的不同，果酒可以分为多种类型。以下是一些常见的果酒分类：

1. **按原料分类**：
   - **葡萄果酒**：以葡萄为原料，如葡萄酒、葡萄汽酒等。
   - **水果果酒**：以其他水果为原料，如苹果酒、梨酒、草莓酒、蓝莓酒等。
   - **混合果酒**：由多种水果混合酿造而成，如混合果汁酒、水果利口酒等。

2. **按酿造工艺分类**：
   - **自然发酵果酒**：完全依靠自然酵母菌发酵，不添加人工酵母。
   - **快速发酵果酒**：使用人工酵母，加速发酵过程。
   - **调味果酒**：在发酵过程中添加其他成分，如蜂蜜、香料等。

3. **按酒精度数分类**：
   - **低酒精度果酒**：酒精度数在 5% 以下，适合日常饮用。
   - **中酒精度果酒**：酒精度数在 5% 到 15% 之间。
   - **高酒精度果酒**：酒精度数在 15% 以上。

4. **按口感分类**：
   - **干型果酒**：口感干涩，酒体轻盈。
   - **甜型果酒**：口感甜润，酒体丰满。
   - **半干型果酒**：口感介于干型和甜型之间。

#### 2.2 品酒术语

品酒术语是品酒过程中使用的专业词汇，了解这些术语有助于更准确地描述和评价果酒的口感和品质。以下是一些常见的品酒术语：

1. **外观**：
   - **清澈度**：指果酒是否清澈透明，无沉淀物。
   - **颜色**：指果酒的颜色深浅和色调，如红色、黄色等。
   - **光泽**：指果酒表面的光泽度，如明亮、暗淡等。

2. **香气**：
   - **果香**：指果酒中水果本身的香气。
   - **酒香**：指果酒中的酒精香气。
   - **复合香**：指果酒中多种香气混合的复杂香气。

3. **口感**：
   - **酸度**：指果酒中的酸味程度，影响口感平衡。
   - **甜度**：指果酒中的甜味程度。
   - **口感质感**：指果酒入口后的口感质感，如轻盈、饱满等。
   - **余味**：指果酒在口中留下的回味时间，如短、长等。

4. **风味**：
   - **果味**：指果酒中水果的风味。
   - **酒味**：指果酒中的酒精风味。
   - **调味风味**：指果酒中添加的调味成分的风味。

5. **平衡**：
   - **口感平衡**：指果酒中酸、甜、苦等味道的平衡。
   - **香气平衡**：指果酒中香气成分的平衡。

#### 2.3 品酒技巧

品酒技巧是品酒过程中需要掌握的基本技能，通过正确的品酒技巧，可以帮助我们更全面地评价果酒的品质。以下是一些品酒技巧：

1. **品酒顺序**：
   - 按照酒精度数从低到高品鉴，以避免高酒精度果酒对味觉的干扰。
   - 优先品鉴干型果酒，再品鉴甜型果酒。

2. **品酒温度**：
   - 根据果酒的品种和酒精度数，调整品酒温度。一般来说，低酒精度果酒宜在室温下饮用，高酒精度果酒宜在冷藏状态下饮用。

3. **品酒步骤**：
   - **观色**：将果酒倒入杯中，观察其清澈度、颜色和光泽。
   - **嗅香**：轻轻旋转酒杯，嗅闻果酒的香气，注意区分果香、酒香和复合香。
   - **尝味**：小口品尝，感受果酒的口感质感、酸度、甜度和余味。
   - **综合评价**：将观色、嗅香、尝味的感受综合起来，对果酒进行整体评价。

#### 3.1 味觉感知模型

味觉感知是指人体通过味蕾对食物中的味道进行感知的过程。味觉感知模型是一个涉及多个因素的复杂系统，其中最基础的是味觉感受器对特定化学物质的反应。以下是一个简化的味觉感知模型：

1. **味觉感受器**：分布在舌头上的味蕾是味觉感受的主要器官。每个味蕾包含多种味觉感受细胞，可以感知甜、酸、苦、咸和鲜等基本味道。

2. **神经信号传递**：当味蕾感受到食物中的化学物质时，会产生神经信号，通过神经通路传递到大脑的味觉中枢。

3. **大脑处理**：大脑对传递过来的神经信号进行处理，形成对味道的整体感知。

4. **感知阈值**：每种味道都有其感知阈值，即最小可感知的浓度。例如，酸味的感知阈值大约为0.0004摩尔/升。

5. **味觉感知变化**：味觉感知不仅受食物本身的影响，还受到口腔环境、情绪、健康状况等多种因素的影响。

#### 数学模型

味觉感知可以简化为一个输入-输出模型，其中输入是食物中的化学物质浓度，输出是味觉感受器的反应强度。一个简化的数学模型可以表示为：

$$
感知强度 = f(浓度, 感知阈值)
$$

其中，$f$是一个非线性函数，它表示浓度和感知强度之间的关系。通常，这个函数可以是S型函数或对数函数，用以模拟人类味觉的感知特性。

#### 3.2 酒精度数公式

酒精度数是指酒中酒精的含量，通常以体积百分比（ABV）或重量百分比（ABW）表示。酒精度数的计算公式如下：

对于体积百分比（ABV）：

$$
ABV = \frac{体积\ 酒精}{总体积} \times 100\%
$$

例如，如果一瓶酒中含有0.5升的酒精，总体积为1升，则其酒精度数为50% ABV。

对于重量百分比（ABW）：

$$
ABW = \frac{重量\ 酒精}{总重量} \times 100\%
$$

酒精的密度通常接近于水，即1克/毫升，因此重量百分比和体积百分比在数值上是相近的。

#### 实例计算

假设一瓶葡萄酒中含有0.75升的酒精，总重量为1.2千克，计算其酒精度数：

对于体积百分比：

$$
ABV = \frac{0.75\ 升}{1\ 升} \times 100\% = 75\% ABV
$$

对于重量百分比：

$$
ABW = \frac{0.75\ 千克}{1.2\ 千克} \times 100\% \approx 62.5\% ABW
$$

由于酒精的密度接近于水，所以两种计算方法得到的酒精度数在实际情况中差别不大。

#### 3.3 味觉感知与酒精度数的关系

酒精度数对味觉感知有显著影响。高酒精度数会增强果酒的酒精味，降低水果味的感知。而低酒精度数则更能凸显果酒的果香和口感。以下是酒精度数与味觉感知的一些关系：

- **低酒精度数**（<10% ABV）：果香更为明显，口感较为轻盈，适合日常饮用。
- **中酒精度数**（10%-15% ABV）：酒精味开始显现，果香与酒精味平衡，适合品鉴。
- **高酒精度数**（>15% ABV）：酒精味占主导，果香相对较弱，适合作为烈性酒饮用。

```python
# app.py

from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///wine.db'
db = SQLAlchemy(app)

# 定义数据库模型
class Wine(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(80), nullable=False)
    taste = db.Column(db.String(120), nullable=False)
    rating = db.Column(db.Float, nullable=False)

# 初始化数据库
db.create_all()

# 添加果酒信息
@app.route('/add_wine', methods=['POST'])
def add_wine():
    data = request.get_json()
    new_wine = Wine(name=data['name'], taste=data['taste'], rating=data['rating'])
    db.session.add(new_wine)
    db.session.commit()
    return jsonify({'message': 'Wine added successfully.'})

# 获取所有果酒信息
@app.route('/get_wines', methods=['GET'])
def get_wines():
    wines = Wine.query.all()
    return jsonify({'wines': [{'id': wine.id, 'name': wine.name, 'taste': wine.taste, 'rating': wine.rating} for wine in wines]})

# 更新果酒评价
@app.route('/update_rating/<int:wine_id>', methods=['PUT'])
def update_rating(wine_id):
    wine = Wine.query.get(wine_id)
    if wine:
        data = request.get_json()
        wine.rating = data['rating']
        db.session.commit()
        return jsonify({'message': 'Rating updated successfully.'})
    return jsonify({'message': 'Wine not found.'})

if __name__ == '__main__':
    app.run(debug=True)
```
