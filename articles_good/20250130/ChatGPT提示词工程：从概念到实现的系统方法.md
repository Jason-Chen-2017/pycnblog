#### 6.2 系统核心实现

**ChatGPT源代码解读**

```python
import openai

def generate_prompt(input_text):
    prompt = "基于以下文本生成一个高质量的提示词：\n\n" + input_text
    return prompt

def main():
    input_text = "请介绍一下ChatGPT是什么？"
    prompt = generate_prompt(input_text)
    response = openai.Completion.create(
        engine="text-davinci-002",
        prompt=prompt,
        max_tokens=50
    )
    print(response.choices[0].text.strip())

if __name__ == "__main__":
    main()
```

**提示词生成实现**

通过上述代码，我们可以实现基于输入文本生成高质量提示词的功能。
