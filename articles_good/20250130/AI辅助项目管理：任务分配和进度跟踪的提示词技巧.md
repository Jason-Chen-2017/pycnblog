import pandas as pd

# 示例数据
tasks = pd.DataFrame({
    'task_id': [1, 2, 3],
    'duration': [5, 3, 7],
    'resource_required': [2, 1, 3]
})

team_members = pd.DataFrame({
    'member_id': [1, 2, 3],
    'available_hours': [10, 8, 6]
})

def task_assignment(tasks, team_members):
    # 根据任务持续时间与团队成员可用时间进行匹配
    assignment = pd.merge_asof(tasks, team_members, left_on='duration', right_on='available_hours')
    return assignment

assignment = task_assignment(tasks, team_members)
print(assignment)

import numpy as np
import pandas as pd

# 示例数据
project_data = pd.DataFrame({
    'task_id': [1, 2, 3],
    'planned_duration': [5, 3, 7],
    'actual_duration': [4, 3, 6],
    'start_date': ['2023-01-01', '2023-01-05', '2023-01-10'],
    'end_date': ['2023-01-06', '2023-01-08', '2023-01-16']
})

def progress_tracking(project_data):
    # 计算挣值（Earned Value，EV）
    project_data['EV'] = project_data['planned_duration'] * project_data['actual_duration']
    # 计算成本绩效指数（Cost Performance Index，CPI）
    project_data['CPI'] = project_data['EV'] / project_data['actual_duration']
    # 计算进度绩效指数（Schedule Performance Index，SPI）
    project_data['SPI'] = project_data['EV'] / project_data['planned_duration']
    return project_data

tracked_data = progress_tracking(project_data)
print(tracked_data)

- **流程**：进度跟踪的基本步骤包括数据收集、数据预处理、进度分析和预测结果输出。

  - **数据收集**：收集项目进展的数据，包括任务完成情况、资源使用情况、项目成本等。

  - **进度分析**：对预处理后的数据进行分析，评估项目的实际进度与计划进度之间的差异，发现潜在的问题和风险。
  - **预测和调整**：根据进度分析的结果，对项目计划进行预测和调整，确保项目能够按计划进行。

### 第6章：AI辅助进度跟踪的提示词技巧

#### 6.1 进度跟踪算法原理与流程

- **算法介绍**：进度跟踪算法通过分析项目数据，实现对项目进度的实时监控和预测。常见的进度跟踪算法包括挣值管理算法、进度预测算法和风险评估算法等。

  - **挣值管理算法**：通过计算项目的挣值（Earned Value，EV）、实际成本（Actual Cost，AC）和计划价值（Planned Value，PV），评估项目的进度绩效和成本绩效。
  - **进度预测算法**：基于历史数据和项目模型，预测项目的未来进度，识别潜在的进度风险。
  - **风险评估算法**：通过对项目风险进行评估和分类，制定相应的风险应对策略。

- **流程**：进度跟踪的基本步骤包括数据收集、数据预处理、进度分析和预测结果输出。

  - **数据收集**：收集项目进展的数据，包括任务完成情况、资源使用情况、项目成本等。
  - **数据预处理**：对收集到的数据进行清洗和整理，确保数据的质量和准确性。
  - **进度分析**：对预处理后的数据进行分析，评估项目的实际进度与计划进度之间的差异，发现潜在的问题和风险。
  - **预测和调整**：根据进度分析的结果，对项目计划进行预测和调整，确保项目能够按计划进行。

#### 1.1 AI技术在项目管理中的应用

- **AI概述**：人工智能（Artificial Intelligence，AI）是一种模拟人类智能的技术，它通过计算机程序实现感知、理解、学习、推理和决策等功能。AI技术的发展历程可以追溯到20世纪50年代，随着计算能力和算法的进步，AI技术逐渐从理论走向应用。

- **项目管理概述**：项目管理是一种系统性的管理活动，通过规划、执行、监控和收尾等步骤，确保项目目标的实现。项目管理的基本流程包括项目规划、项目执行、项目监控和项目收尾。

- **AI在项目管理中的角色**：AI技术在项目管理中扮演着重要的角色，它可以帮助项目管理者提高任务分配的准确性，优化资源管理，提升项目进度跟踪的效率，甚至预测项目风险和优化项目决策。

import numpy as np
import pandas as pd

# 示例数据
project_data = pd.DataFrame({
    'task_id': [1, 2, 3],
    'planned_duration': [5, 3, 7],
    'actual_duration': [4, 3, 6],
    'start_date': ['2023-01-01', '2023-01-05', '2023-01-10'],
    'end_date': ['2023-01-06', '2023-01-08', '2023-01-16']
})

def progress_tracking(project_data):
    # 计算挣值（Earned Value，EV）
    project_data['EV'] = project_data['planned_duration'] * project_data['actual_duration']
    # 计算成本绩效指数（Cost Performance Index，CPI）
    project_data['CPI'] = project_data['EV'] / project_data['actual_duration']
    # 计算进度绩效指数（Schedule Performance Index，SPI）
    project_data['SPI'] = project_data['EV'] / project_data['planned_duration']
    return project_data

tracked_data = progress_tracking(project_data)
print(tracked_data)

### 第3章：任务分配算法原理与流程

#### 3.1 任务分配算法的基本原理

- **算法介绍**：任务分配算法是项目管理中的一种优化算法，旨在通过数学模型和计算方法，实现对任务的自动分配。常见的任务分配算法包括最短路径算法、资源分配算法和线性规划算法等。

  - **最短路径算法**：如迪杰斯特拉算法（Dijkstra's algorithm），用于计算从源点到其他节点的最短路径。

1. **数据收集**：收集项目进展的数据，包括任务完成情况、资源使用情况、项目成本等。
2. **数据预处理**：对收集到的数据进行清洗和整理，确保数据的质量和准确性。
3. **进度分析**：对预处理后的数据进行分析，评估项目的实际进度与计划进度之间的差异，发现潜在的问题和风险。
4. **预测和调整**：根据进度分析的结果，对项目计划进行预测和调整，确保项目能够按计划进行。

```python
import numpy as np
import pandas as pd

# 示例数据
project_data = pd.DataFrame({
    'task_id': [1, 2, 3],
    'planned_duration': [5, 3, 7],
    'actual_duration': [4, 3, 6],
    'start_date': ['2023-01-01', '2023-01-05', '2023-01-10'],
    'end_date': ['2023-01-06', '2023-01-08', '2023-01-16']

def progress_tracking(project_data):
    # 计算挣值（Earned Value，EV）
    project_data['EV'] = project_data['planned_duration'] * project_data['actual_duration']
    # 计算成本绩效指数（Cost Performance Index，CPI）
    project_data['CPI'] = project_data['EV'] / project_data['actual_duration']
    # 计算进度绩效指数（Schedule Performance Index，SPI）
    project_data['SPI'] = project_data['EV'] / project_data['planned_duration']
    return project_data

tracked_data = progress_tracking(project_data)
print(tracked_data)
```
