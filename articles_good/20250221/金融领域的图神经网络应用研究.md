# 第2章: 图神经网络的基础知识

## 2.1 图论基础
### 2.1.1 图的定义与表示
图由节点和边组成，可以用邻接矩阵或邻接表表示。例如，客户-交易图可以用邻接矩阵表示客户之间的交易关系。

### 2.1.2 图的类型与属性
图可以是无向图、有向图或加权图，节点和边可以具有属性（如节点表示客户类型，边表示交易金额）。

### 2.1.3 图的遍历算法
常见的图遍历算法包括深度优先搜索（DFS）和广度优先搜索（BFS）。这些算法在金融网络分析中用于发现社区结构或异常行为。

---

## 2.2 神经网络基础
### 2.2.1 神经网络的基本原理
神经网络通过多层感知机（MLP）对输入数据进行非线性变换，学习数据的特征表示。例如，在欺诈检测任务中，神经网络可以学习交易数据的特征。

### 2.2.2 深度学习的基本原理
深度学习通过堆叠多层神经网络，自动提取数据的高层特征。例如，在信用评估任务中，深度学习可以自动提取客户的关联特征。

### 2.2.3 图神经网络的独特性
图神经网络通过聚合邻居节点的信息，生成节点的表示，捕捉图的结构和语义信息。例如，在欺诈检测任务中，图神经网络可以识别异常交易行为。

---

## 2.3 图表示学习
### 2.3.1 图表示学习的定义
图表示学习旨在将图中的节点或边映射到低维向量空间，保持图的结构和语义信息。例如，客户节点可以被映射到低维向量，表示客户的特征。

### 2.3.2 常见的图表示学习方法
- 基于随机游走的方法：如Node2Vec。
- 基于矩阵分解的方法：如GAE（Graph Autoencoder）。
- 基于图神经网络的方法：如GCN、GAT。

### 2.3.3 图嵌入技术的优缺点
- 优点：低维表示，易于处理。
- 缺点：可能丢失部分图结构信息。

---

## 2.4 图神经网络模型
### 2.4.1 GCN（Graph Convolutional Networks）
GCN通过聚合邻居节点的信息，生成节点的表示。其核心公式为：
$$
h^{(l+1)}_i = \sigma\left(\sum_{j} A_{ij} h^{(l)}_j\right)
$$
其中，$A_{ij}$是邻接矩阵，$\sigma$是激活函数。

### 2.4.2 GAT（Graph Attention Networks）
GAT通过注意力机制聚合邻居节点的信息，公式为：
$$
h^{(l+1)}_i = \sigma\left(\sum_{j} \alpha_{ij} h^{(l)}_j\right)
$$
其中，$\alpha_{ij}$是注意力权重，用于捕捉节点之间的关系重要性。

### 2.4.3 GNN（Graph Neural Networks）的变体
- GraphSAGE：通过采样邻居节点进行特征聚合。
- GraphGCN：结合图卷积和图注意力机制。

## 2.5 图神经网络的训练与优化
### 2.5.1 图神经网络的训练方法
图神经网络通常采用端到端的训练方法，使用梯度下降优化模型参数。

### 2.5.2 模型优化策略
- 调整模型深度：增加或减少网络层数。
- 调整注意力权重：优化注意力机制的参数。
- 调整邻接矩阵：引入边权重或节点权重。

# 第4章: 图神经网络的算法原理

## 4.1 图卷积网络（GCN）
### 4.1.1 算法原理
GCN通过聚合邻居节点的信息，生成节点的表示。其核心公式为：
$$
h^{(l+1)}_i = \sigma\left(\sum_{j} A_{ij} h^{(l)}_j\right)
$$
其中，$A_{ij}$是邻接矩阵，$\sigma$是激活函数。

## 4.2 图注意力机制
### 4.2.1 注意力机制原理
注意力机制通过计算节点之间的注意力权重，聚合重要的邻居信息。其公式为：
$$
\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k} \exp(e_{ik})}
$$
其中，$e_{ij}$是节点$i$和$j$之间的相似性得分。

### 4.2.2 图注意力网络（GAT）
GAT通过注意力机制聚合邻居节点的信息，公式为：
$$
h^{(l+1)}_i = \sigma\left(\sum_{j} \alpha_{ij} h^{(l)}_j\right)
$$

import tensorflow as tf
from tensorflow.keras import layers

# 定义GCN层
class GCNLayer(layers.Layer):
    def __init__(self, input_dim, output_dim):
        super(GCNLayer, self).__init__()
        self.W = tf.keras.layers.Dense(output_dim, input_dim)
        self.sigma = tf.keras.layers.Activation('relu')

    def call(self, inputs, A):
        h = self.W(inputs)
        h = tf.matmul(A, h)
        h = self.sigma(h)
        return h
