# 第1章: 投资组合优化概述

## 1.1 投资组合优化的基本概念

### 1.1.1 投资组合的定义与目标
投资组合是指将资金分配到不同资产（如股票、债券、基金等）上的配置方式。其目标是在满足特定风险承受能力的前提下，实现收益的最大化。投资组合优化的核心问题是在给定的约束条件下，找到最优的资产配置比例。

$$ \text{目标函数：最大化收益或最小化风险} $$

### 1.1.2 投资组合优化的必要性
传统的投资组合优化方法（如现代投资组合理论，MPT）虽然有效，但在面对复杂市场环境和多样化资产时，其计算复杂度和适用性受到限制。引入人工智能技术可以提高优化效率并适应动态市场变化。

### 1.1.3 传统投资组合优化方法的局限性
- **计算复杂性**：当资产数量较多时，传统的优化方法（如二次规划）计算量巨大。
- **市场动态性**：传统方法假设市场参数不变，而实际市场环境不断变化。
- **非线性问题**：某些优化问题具有非线性特征，传统方法难以处理。

# 第2章: AI驱动优化的核心概念

## 2.1 现代投资组合理论（MPT）基础

### 2.1.1 均值-方差优化
均值-方差优化是MPT的核心方法，目标是最小化投资组合的方差（风险），同时满足收益目标。

$$ \text{目标函数：} \min \sigma^2 \quad \text{约束条件：} \sum w_i r_i = R $$

其中，$w_i$ 是资产$i$的权重，$r_i$ 是资产$i$的期望收益，$R$ 是目标收益。

### 2.1.2 马科维茨有效前沿
马科维茨有效前沿是指在给定风险水平下，能够提供最高收益的所有投资组合的集合。

### 2.1.3 MPT的局限性
MPT假设资产收益符合正态分布，且市场是有效的。然而，实际市场中存在非线性关系和市场失灵。

# 第3章: AI驱动优化的算法原理

## 3.1 遗传算法优化流程

### 3.1.1 初始化种群
随机生成一组初始解（种群）。

### 3.1.2 适应度函数计算
计算每个解的适应度值（即收益与风险的综合指标）。

### 3.1.3 选择与交叉操作
根据适应度值选择优秀个体，并进行交叉操作生成新个体。

### 3.1.4 变异与新种群生成
对新个体进行变异操作，生成新的种群。

### 3.1.5 收敛条件判断
若满足收敛条件（如达到最大迭代次数或适应度值不再变化），则停止优化，否则返回步骤3.1.2。

### 3.1.6 优化流程示意图

```mermaid
graph TD
    A[初始化种群] --> B[计算适应度]
    B --> C[选择优秀个体]
    C --> D[交叉操作]
    D --> E[变异操作]
    E --> F[生成新种群]
    F --> G{是否收敛}
    G -->|否| B
    G -->|是| 终止
```

## 3.2 模拟退火算法原理

### 3.2.1 初始解生成
随机生成一个初始解。

### 3.2.2 计算能量函数
能量函数用于衡量解的优劣，通常为风险或收益的相反数。

### 3.2.3 降温过程与状态转移
根据当前解和新解的能量差，按照一定概率接受或拒绝新解。随着温度的降低，接受差解的概率逐渐减小。

### 3.2.4 收敛条件判断
若满足收敛条件，则停止优化，否则继续降温。

### 3.2.5 优化流程示意图

```mermaid

    E -->|否| B
    B --> F[降温]
    F --> G{是否收敛}
    G -->|否| F
    G -->|是| 终止
```

### 5.2.2 遗传算法实现
```python
import random

def fitness(w, data):
    # 计算收益与风险
    return - (np.mean(data.dot(w)) / np.std(data.dot(w)))

def genetic_algorithm(data, pop_size=100, generations=100):
    n_assets = data.shape[1]
    pop = np.random.rand(pop_size, n_assets)
    
    for _ in range(generations):
        fitness_val = np.apply_along_axis(fitness, 1, pop, data)
        selected = pop[np.argsort(fitness_val)]
        pop = selected[:int(pop_size/2)] + selected[-int(pop_size/2):]
    
    best = pop[0]
    return best
```

### 5.2.3 强化学习实现
```python
import gym
import numpy as np

class InvestmentEnv(gym.Env):
    def __init__(self, data):
        self.data = data
        self.state = 0
        self.action_space = gym.spaces.Box(-1, 1, (1,))  # 资产权重调整
        self.observation_space = gym.spaces.Box(0, 1, ())  # 当前状态
        
    def step(self, action):
        # 执行动作，更新状态
        new_state = self.state + action
        reward = -np.std(self.data[new_state])  # 奖励为收益波动的相反数
        return new_state, reward, False, {}

    def reset(self):
        self.state = 0
        return self.state
```
