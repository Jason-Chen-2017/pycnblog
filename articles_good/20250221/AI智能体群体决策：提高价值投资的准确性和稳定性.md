以下是一个基于投票的群体决策算法的Python代码示例：

```python
def group_decision(votes, weights):
    weighted_votes = [vote * weight for vote, weight in zip(votes, weights)]
    total = sum(weighted_votes)
    return total

result = group_decision(votes, weights)
```
