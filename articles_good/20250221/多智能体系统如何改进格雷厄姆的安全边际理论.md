## 第1章: 多智能体系统概述

### 1.1 多智能体系统的定义与特点

#### 1.1.1 多智能体系统的定义
多智能体系统（Multi-Agent System, MAS）是由多个智能体（Agent）组成的分布式系统，这些智能体能够自主决策、协作和通信以完成共同目标。

#### 1.1.2 多智能体系统的核心特点
- **自主性**：每个智能体都具有自主决策能力。
- **协作性**：智能体之间通过通信和协作完成复杂任务。
- **分布式性**：系统中的智能体分布在网络中，不存在中心化控制节点。
- **动态性**：系统环境和智能体状态可能动态变化。

#### 1.1.3 多智能体系统与单智能体系统的区别
| 属性 | 单智能体系统 | 多智能体系统 |
|------|--------------|--------------|
| 控制方式 | 中央控制 | 分布式控制 |
| 任务处理 | 单点处理 | 分布式协作 |
| 系统复杂度 | 较低 | 较高 |

## 第2章: 格雷厄姆的安全边际理论概述

### 2.1 格雷厄姆投资理论的核心思想

#### 2.1.1 安全边际的定义
安全边际是指资产的内在价值与市场价格之间的差额，是投资中的“安全空间”。

#### 2.1.2 安全边际在投资决策中的作用
- **保护投资者免受市场波动的影响**。
- **提供投资的安全性**。
- **衡量资产的价值**。

#### 2.1.3 安全边际与价值投资的关系
安全边际是价值投资的核心思想，投资者通过寻找市场价格低于内在价值的资产来实现超额收益。

---

### 2.2 安全边际理论的数学模型

#### 2.2.1 安全边际的计算公式
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

#### 2.2.2 安全边际与资产价值的关系
- 当市场价格 < 内在价值时，存在正的安全边际，投资是安全的。
- 当市场价格 = 内在价值时，安全边际为零，投资风险增加。
- 当市场价格 > 内在价值时，安全边际为负，投资风险较大。

#### 2.2.3 安全边际在风险控制中的应用
- 通过计算安全边际，投资者可以量化投资风险。
- 安全边际为正时，投资风险较低；安全边际为负时，投资风险较高。

#### 7.2.1 多智能体系统核心代码（Python 实现）
```python
import numpy as np
import matplotlib.pyplot as plt

class Agent:
    def __init__(self, id):
        self.id = id
        self.state = "idle"
        self.actions = []
    
    def receive_task(self, task):
        self.actions.append(task)
        self.state = "busy"
    
    def complete_task(self):
        self.actions.pop()
        self.state = "idle"

class Task:
    def __init__(self, id, description, deadline):
        self.id = id
        self.description = description
        self.deadline = deadline

# 创建多个智能体
agents = [Agent(i) for i in range(5)]
tasks = [Task(i, "Task {}".format(i), "2023-10-{}".format(i+1)) for i in range(5)]

# 任务分配
for agent in agents:
    if agent.state == "idle":
        agent.receive_task(tasks[0])
        break
```
