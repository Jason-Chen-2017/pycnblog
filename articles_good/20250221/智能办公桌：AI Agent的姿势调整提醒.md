# 第1章：问题背景与需求分析

## 1.1 问题背景

### 1.1.1 办公环境中姿势问题的普遍性

现代办公环境中，长时间的久坐和不良姿势导致的健康问题日益严重。根据世界卫生组织的报告，长时间的久坐与多种慢性疾病相关，如肥胖、糖尿病和心血管疾病。此外，不良的坐姿还会导致背部疼痛和肌肉劳损，影响工作效率和生活质量。

### 1.1.2 长期不良姿势对健康的危害

长期不良姿势对身体健康的危害包括：

- **背部疼痛**：长时间的弯腰或驼背姿势会增加背部肌肉的负担，导致慢性疼痛。
- **颈椎问题**：低头看手机或电脑屏幕会导致颈椎僵硬和疼痛。
- **血液循环问题**：久坐不动会影响血液循环，导致腿部和臀部的血液回流不畅。
- **呼吸系统问题**：不良坐姿会影响肺部的扩张，导致呼吸不畅。

### 1.1.3 智能办公桌的出现背景

随着科技的发展，智能办公桌逐渐进入市场。这类办公桌通常配备可调节的桌腿和屏幕，能够根据用户的需求进行高度和角度的调整。然而，仅仅依靠手动调节并不能完全解决姿势问题，因为用户可能因为分心或其他原因忘记调整。

## 1.2 用户需求分析

### 1.2.1 用户痛点分析

用户在使用普通办公桌时面临的主要痛点包括：

- **姿势不正确**：用户可能因为缺乏意识或习惯，长时间保持不良姿势。
- **缺乏反馈**：用户无法实时了解自己的姿势是否正确，无法及时调整。
- **手动调节麻烦**：用户需要手动调节桌腿和屏幕角度，操作不够便捷。
