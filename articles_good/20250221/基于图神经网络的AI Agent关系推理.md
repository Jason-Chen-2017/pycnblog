#### 5.1.1 邻接矩阵表示

- 邻接矩阵的对称性：无向图的邻接矩阵是对称的
- 邻接矩阵的稀疏性：处理稀疏图的能力

#### 5.1.2 节点特征传播
- 节点特征传播的过程：$h_i^{(l+1)} = \sigma(\sum_{j} A_{ij} h_j^{(l)})$

- 节点特征的聚合方式：平均、最大、加权和

import torch
import torch.nn as nn
import torch.nn.functional as F

class GNNLayer(nn.Module):
    def __init__(self, in_dim, out_dim):
        super(GNNLayer, self).__init__()
        self.W = nn.Parameter(torch.randn(in_dim, out_dim))
        self.A = nn.Parameter(torch.randn(n, n))  # 邻接矩阵

    def forward(self, x):
        x = torch.mm(x, self.W)  # 节点特征矩阵乘以权重矩阵
        x = torch.mm(self.A, x)  # 邻接矩阵乘以节点特征矩阵
        x = F.relu(x)
        return x

class Graph Neural Network:
    def __init__(self, input_dim, hidden_dim, output_dim):
        self.gnn_layer = GNNLayer(input_dim, hidden_dim)
        self.classifier = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        x = self.gnn_layer(x)
        x = self.classifier(x)
        return x
