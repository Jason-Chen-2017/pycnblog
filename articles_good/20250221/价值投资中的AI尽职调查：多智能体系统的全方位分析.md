### 1.1 价值投资的核心理念

#### 1.1.1 价值投资的定义与特点
价值投资是一种以基本面分析为基础的投资策略，强调购买价格低于内在价值的资产。其核心理念包括长期投资、注重内在价值、关注公司基本面等。价值投资者通常寻找被市场低估的公司，并长期持有这些资产，以实现稳定的投资回报。

#### 1.1.2 价值投资的基本原则
价值投资的基本原则包括：
- **安全边际**：买入价格低于内在价值，以降低风险。
- **长期视角**：关注公司的长期盈利能力，而非短期波动。
- **公司基本面**：分析公司的财务状况、行业地位、竞争优势等。

#### 1.1.3 价值投资在现代金融中的地位
尽管价值投资在传统金融中占据重要地位，但随着市场的复杂化和数据量的增加，单纯依赖人工分析的效率和准确性逐渐受到限制。因此，引入AI技术成为提升价值投资效率的重要方向。

import numpy as np

def evaluate_portfolio(returns):
    # 计算夏普比率
    mean_return = np.mean(returns)
    std_deviation = np.std(returns)
    sharpe_ratio = mean_return / std_deviation
    return sharpe_ratio

# 示例数据
returns = np.array([0.05, 0.06, 0.04, 0.07, 0.05])
sharpe = evaluate_portfolio(returns)
print(sharpe)
