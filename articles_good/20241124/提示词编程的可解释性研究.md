#### 常用算法

常用的机器学习算法包括以下几种：

1. **线性回归**：
   - **基本原理**：通过最小化预测值与实际值之间的误差平方和，找到最佳拟合直线。
   - **数学公式**：
     $$ y = \beta_0 + \beta_1x $$
     $$ \beta = (\beta_0, \beta_1) $$
   - **伪代码**：
     ```
     for i = 1 to n:
         error = y[i] - (beta_0 + beta_1 * x[i])
         delta_beta_0 = error / n
         delta_beta_1 = error * x[i] / n
         beta_0 = beta_0 - delta_beta_0
         beta_1 = beta_1 - delta_beta_1
     return beta_0, beta_1
     ```

2. **逻辑回归**：
   - **基本原理**：通过最小化损失函数，找到最佳拟合直线，实现二分类问题。
   - **数学公式**：
     $$ P(y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x)}} $$
     $$ \log(P(y=1)) = \beta_0 + \beta_1x $$
   - **伪代码**：
     ```
     for i = 1 to n:
         error = y[i] - P(y=1)[i]
         delta_beta_0 = error / n
         delta_beta_1 = error * x[i] / n
         beta_0 = beta_0 - delta_beta_0
         beta_1 = beta_1 - delta_beta_1
     return beta_0, beta_1
     ```

3. **决策树**：
   - **基本原理**：通过递归划分特征空间，构建一棵树状模型，实现分类或回归任务。
   - **数学公式**：
     $$ Gini(\text{impurity}) = 1 - \sum_{i=1}^{n} p_i^2 $$
     $$ Entropy(\text{impurity}) = -\sum_{i=1}^{n} p_i \log_2 p_i $$
   - **伪代码**：
     ```
     function DecisionTree(X, y):
         if all(y[i] == y[1]):
             return y[1]
         if X is empty:
             return majority_vote(y)
         best_feature, best_split = FindBestSplit(X, y)
         left_tree = DecisionTree(X[best_split < threshold], y[best_split < threshold])
         right_tree = DecisionTree(X[best_split >= threshold], y[best_split >= threshold])
         return Node(best_feature, best_split, left_tree, right_tree)
     ```

4. **支持向量机（SVM）**：
   - **基本原理**：通过寻找最优超平面，实现分类或回归任务。
   - **数学公式**：
     $$ w^* = \arg\min_{w, b} \frac{1}{2} ||w||^2 $$
     $$ \text{subject to } y[(w \cdot x) - b] \geq 1 $$
   - **伪代码**：
     ```
     function SVM(X, y):
         if y[i] == 1:
             w[i] = -w
         return Optimize(w, b)
     ```

5. **神经网络**：
   - **基本原理**：通过多层神经元网络，实现复杂的非线性预测和分类。
   - **数学公式**：
     $$ a_{l} = \sigma(\sum_{i=1}^{n} w_{li}a_{l-1} + b_{l}) $$
   - **伪代码**：
     ```
     for l = 1 to L:
         for i = 1 to n:
             z[i][l] = \sum_{j=1}^{n} w[i][j][l-1]a[j][l-1] + b[i][l]
             a[i][l] = \sigma(z[i][l])
     return a[n][L]
     ```

    w = np.zeros((X.shape[1], 1))
