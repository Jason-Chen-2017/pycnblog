以下是一个简单的交叉验证的伪代码：

```python
# 初始化数据
X = np.array([[1, 2], [2, 4], [3, 6]])
y = np.array([0, 1, 1])

# 初始化模型
model = LinearRegression()

# 交叉验证
k = 5
for i in range(k):
    # 划分训练集和验证集
    X_train, X_val = np.split(X, [len(X) - (len(X) // k)])
    y_train, y_val = np.split(y, [len(y) - (len(y) // k)])
    
    # 训练模型
    model.fit(X_train, y_train)
    
    # 验证模型
    score = model.score(X_val, y_val)
    
    print("交叉验证分：", score)
```
