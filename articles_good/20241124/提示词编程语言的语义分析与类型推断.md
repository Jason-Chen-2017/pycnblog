## 第3章：语义分析基础

### 3.1 语义分析的定义

语义分析（Semantic Analysis）是编程语言处理过程中对程序语义的解析和理解。它确保程序在执行时能够正确地执行。语义分析通常包括变量绑定、作用域解析、类型推断等。

### 3.2 语义分析的层次结构

语义分析通常分为以下层次：

1. **词法分析**：将源代码分解成单词和符号。
2. **语法分析**：分析单词和符号的语法结构，构建抽象语法树（Abstract Syntax Tree，AST）。
3. **语义分析**：对AST进行语义分析，确定变量绑定、作用域、类型等信息。

### 3.3 语义分析的方法与工具

语义分析的方法与工具有多种：

1. **静态语义分析**：在编译时对程序进行语义分析，无需运行程序。
2. **动态语义分析**：在程序运行时对程序进行语义分析，可以实时了解程序的运行状态。
3. **语义网分析**：基于语义网对程序进行语义分析。
4. **形式化语义分析**：使用数学模型和形式化方法对程序进行语义分析。

类型推断（Type Inference）是编程语言处理过程中对变量和表达式类型的自动推导。类型推断有助于提高程序的稳定性，减少类型错误。

### 4.2 类型推断的类型系统

类型系统分为强类型系统和弱类型系统：

1. **强类型系统**：对变量和表达式的类型有严格限制，有助于提高程序的稳定性。
2. **弱类型系统**：对变量和表达式的类型限制较松，灵活性较高。

### 4.3 类型推断的算法

类型推断的算法有多种，包括：

1. **单向类型推断**：从表达式的一端开始推断类型，逐步推导整个表达式。
2. **双向类型推断**：同时从表达式的两端开始推断类型，逐步推导整个表达式。
3. **约束类型推断**：通过约束条件推导类型。

```python
class Node:
    def __init__(self, type=None):
        self.type = type

class NumberNode(Node):
    def __init__(self, value):
        super().__init__("int")
        self.value = value

class StringNode(Node):
    def __init__(self, value):
        super().__init__("string")
        self.value = value

def inferType(expression):
    if isinstance(expression, NumberNode):
        return "int"
    elif isinstance(expression, StringNode):
        return "string"
    else:
        return "unknown"

def semanticAnalysis(expression):
    if isinstance(expression, NumberNode):
        return NumberNode(expression.value)
    elif isinstance(expression, StringNode):
        return StringNode(expression.value)
    else:
        raise ValueError("Invalid expression")

# 测试代码
number_expression = NumberNode(10)
string_expression = StringNode("Hello, world!")
print(inferType(number_expression))  # 输出：int
print(inferType(string_expression))  # 输出：string
```

`inferType`函数用于推断表达式的类型。它接受一个`Node`类型的参数，并返回该表达式的类型。在`semanticAnalysis`函数中，我们根据输入的表达式类型，创建相应的`Node`对象，并返回。
