## 3.2 压力测试算法的数学模型
### 3.2.1 蒙特卡洛模拟
- **数学模型**: 使用随机数生成器模拟市场波动。
- **公式**: 
  - 生成随机数：$R \sim N(0,1)$
  - 计算波动率：$\sigma = \sqrt{\sum (x_i - \mu)^2 / N}$
  - 模拟市场走势：$S_{t+1} = S_t + \mu \Delta t + \sigma \sqrt{\Delta t} R$

### 3.2.2 时间序列分析
- **数学模型**: 使用ARIMA模型预测市场走势。
- **公式**: 
  - 自回归部分：$y_t = \alpha y_{t-1} + \beta y_{t-2} + \epsilon_t$
  - 移动平均部分：$y_t = \gamma \epsilon_{t-1} + \delta \epsilon_{t-2}$

### 3.2.3 网络流模型
- **数学模型**: 使用流网络模型模拟资金流动。
- **公式**: 
  - 流量分配：$f_{ij} = \min(s_i, d_j)$
  - 网络容量：$\sum_{j} f_{ij} \leq C_i$
