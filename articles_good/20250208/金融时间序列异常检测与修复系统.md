## 第3章: 异常检测的核心概念与分类

### 3.1 异常检测的定义与分类

#### 3.1.1 异常检测的定义
- 异常点：偏离预期模式的点或区间。
- 正常点：符合预期模式的点。

#### 3.1.2 异常检测的分类
| 方法类型       | 描述                                                                 |
|----------------|----------------------------------------------------------------------|
| 基于统计学     | 假设数据服从某种分布，识别偏离分布的点（如z-score法）。               |
| 基于机器学习   | 使用监督或无监督学习算法（如随机森林、Isolation Forest）。           |
| 基于深度学习   | 使用RNN、LSTM等模型捕捉复杂模式。                                    |
| 基于孤立点检测 | 识别数据中的孤立点（如DBSCAN）。                                   |

### 3.2 异常检测的挑战与解决方案

#### 3.2.1 异常检测的挑战
- 数据稀疏性：正常数据多，异常数据少。
- 数据依赖性：异常点可能与正常数据相似。
- 多维性：高维数据增加计算复杂度。

#### 3.2.2 统计方法的局限性
- 假设数据服从特定分布（如正态分布）。
- 无法捕捉复杂模式。

#### 3.2.3 机器学习方法的优势
- 适用于非线性关系。
- 可处理高维数据。

## 第4章: 基于统计学的异常检测方法

### 4.1 均值-标准差法

#### 4.1.1 方法原理
- 假设数据服从正态分布。
- 异常点定义为：$|x - \mu| > 3\sigma$，其中$\mu$是均值，$\sigma$是标准差。

#### 4.1.2 方法实现
```python
import numpy as np

def z_score_outliers(data, threshold=3):
    mean = np.mean(data)
    std = np.std(data)
    outliers = []
    for x in data:
        z = (x - mean) / std
        if abs(z) > threshold:
            outliers.append(x)
    return outliers
```

### 4.2 Grubbs检验

#### 4.2.1 方法原理
- 用于检测单个异常点。
- 统计量：$T = \frac{|x_i - \bar{x}|}{s}$，其中$x_i$是观测值，$\bar{x}$是均值，$s$是标准差。

#### 4.2.2 方法实现
```python
import numpy as np

def grubbs_test(data, alpha=0.05):
    n = len(data)
    if n < 2:
        return []
    mean = np.mean(data)
    std = np.std(data)
    t_critical = np.quantile(np.abs(np.random.normal(0, 1, 10000)), alpha/2)
    outliers = []
    for i in range(n):
        t = np.abs((data[i] - mean) / std)
        if t > t_critical:
            outliers.append(data[i])
    return outliers
```

### 4.3 统计方法的优缺点

#### 优点
- 实现简单，计算速度快。
- 适合正态分布数据。

#### 缺点
- 无法处理复杂模式。
- 对数据分布假设敏感。

import tensorflow as tf
from tensorflow.keras.layers import Dense, MultiHeadAttention

def transformer_anomaly_detection(X_train, X_test, num_heads=8, units=64, epochs=10):
    inputs = tf.keras.Input(shape=(None, X_train.shape[-1]))
    attention = MultiHeadAttention(num_heads=num_heads, key_dim=X_train.shape[-1])
    x = attention(inputs, inputs)
    x = Dense(1, activation='sigmoid')(x)
    model = tf.keras.Model(inputs=inputs, outputs=x)
    model.compile(optimizer='adam', loss='binary_crossentropy')
    model.fit(X_train, y_train, epochs=epochs, batch_size=32)
    y_pred = model.predict(X_test)
    return y_pred
```

# 系统实现代码示例
class AnomalyDetectionSystem:
    def __init__(self):
        self.data_processor = DataProcessor()
        self.detector = IsolationForest(n_estimators=100, random_state=42)
        self.repairer = RepairStrategy()

    def process_data(self, data):
        processed_data = self.data_processor.process(data)
        return processed_data

    def detect_anomalies(self, data):
        anomalies = self.detector.fit_predict(data)
        return anomalies

    def repair_data(self, data, anomalies):
        repaired_data = self.repairer.repair(data, anomalies)
        return repaired_data

# 数据处理器类
class DataProcessor:
    def process(self, data):
        # 数据清洗和标准化
        data.dropna(inplace=True)
        data['close'].fillna(data['close'].mean(), inplace=True)
        return data

# 修复策略类
class RepairStrategy:
    def repair(self, data, anomalies):
        # 删除异常点
        data = data[data['is_outlier'] == False]
        # 使用线性插值修复
        data['close'].interpolate(method='linear', inplace=True)
        return data
```
