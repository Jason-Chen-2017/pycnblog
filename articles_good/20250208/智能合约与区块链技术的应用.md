# 第一部分：智能合约与区块链技术的基础

## 第1章：区块链技术概述

### 1.1 区块链的定义与特点

#### 1.1.1 区块链的定义
- 区块链的定义：分布式账本技术，通过去中心化的方式记录交易。
- 核心特点：去中心化、不可篡改、透明性、匿名性、抗审查性。

#### 1.1.2 区块链的核心特点
- 分布式架构：数据存储在多个节点，去中心化。
- 去信任化：通过共识机制实现信任。
- 可追溯性：每笔交易可追溯，确保数据完整性。

#### 1.1.3 区块链的分类与应用场景
- 分类：公链、私链、联盟链。
- 应用场景：金融、供应链、医疗、版权保护等。

### 1.2 区块链的核心组件

#### 1.2.1 区块链的节点与网络
- 节点类型：全节点、轻节点。
- 网络通信：P2P网络，数据同步机制。

#### 1.2.2 区块链的共识机制
- 共识机制的作用：确保所有节点达成一致。
- 常见共识机制：PoW、PoS、Raft、Paxos。

#### 1.2.3 区块链的分布式账本
- 账本结构：区块、链式结构。
- 数据存储： Merkel树、哈希指针。

### 1.3 区块链的安全性与隐私保护

#### 1.3.1 加密算法在区块链中的应用
- 加密算法：SHA-256、ECDSA。
- 公钥与私钥：数字签名技术。

#### 1.3.2 数字签名原理
- 数字签名的作用：验证数据完整性和真实性。
- 签名过程：使用私钥生成签名，公钥验证签名。

#### 1.3.3 区块链隐私保护技术
- 隐私保护方法：零知识证明、同态加密。
- 区块链中的隐私问题：地址匿名性与交易透明性的平衡。

```solidity
pragma solidity ^0.8.0;

contract SupplyChain {
    struct Order {
        uint id;
        address supplier;
        address customer;
        uint amount;
        uint status;
    }

    event OrderCreated(uint indexed id, address indexed supplier, address indexed customer, uint amount);
    event PaymentTriggered(uint indexed id, uint amount);

    function createOrder(address supplier, address customer, uint amount) external {
        Order memory order = Order({
            id: 1,
            supplier: supplier,
            customer: customer,
            amount: amount,
            status: 0
        });
        emit OrderCreated(order.id, order.supplier, order.customer, order.amount);
    }

    function updateStatus(uint id, uint status) external {
        // 更新订单状态
        emit OrderCreated(id, msg.sender, ...);
    }

    function triggerPayment(uint id) external {
        // 触发支付
        emit PaymentTriggered(id, 100);
    }
}
```
