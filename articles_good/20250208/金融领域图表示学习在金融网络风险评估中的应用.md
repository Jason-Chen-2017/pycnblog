### 第1章: 金融网络风险评估的背景与问题

#### 1.1 金融网络风险评估的背景
- 1.1.1 金融网络的定义与特点
  - 金融网络是由金融机构、企业、个人等节点及其之间的金融交易关系构成的复杂网络。

- 1.1.2 金融网络风险的类型与影响

  - 操作风险：由于内部操作失误或外部事件导致的损失。
  - 系统性风险：由于整个金融系统不稳定导致的系统性崩盘风险。

## 第二部分: 图表示学习的核心概念与原理

### 第2章: 图表示学习的核心概念

#### 2.1 图结构与节点表示
- 2.1.1 图的基本结构
  - 节点：代表实体（如个人、企业、金融机构）。
  - 边：代表关系（如交易、投资、借贷）。
  - 权重：表示关系强度或概率。
- 2.1.2 节点表示的定义与特点
  - 节点嵌入：将高维节点表示为低维连续向量。
  - 嵌入空间：通常为低维实数空间。
  - 表示能力：能够捕捉节点的局部和全局特征。
- 2.1.3 边与权重的表示
  - 边权重：反映关系强度或重要性。
  - 边的表示：通过权重矩阵或邻接矩阵编码。

#### 2.2 图表示学习的原理
- 2.2.1 图嵌入的基本思想
  - 通过保留图的结构信息和语义信息，将图中的节点表示为低维向量。
- 2.2.2 节点嵌入的生成方法
  - 基于随机游走的节点表示。
  - 基于矩阵分解的节点表示。
- 2.2.3 图结构信息的保留与损失
  - 保留局部结构特征，忽略某些全局特征。
  - 通过优化目标函数平衡信息保留。

#### 2.3 图表示学习的分类与对比
- 2.3.1 基于矩阵分解的方法
  - 示例：Node2Vec、DeepWalk。
  - 优点：简单易实现，适合小规模图。
  - 缺点：难以捕捉复杂的网络结构特征。
- 2.3.2 基于深度学习的方法
  - 示例：GraphSAGE、GAT。
  - 优点：能够捕捉复杂的网络特征。
  - 缺点：计算复杂度较高。
- 2.3.3 基于生成对抗网络的方法
  - 示例：GAN-based embedding。
  - 优点：能够生成多样化的嵌入。
  - 缺点：训练不稳定，难以控制生成结果。

#### 3.2 GraphSAGE算法
- 3.2.1 算法原理
  - GraphSAGE是一种基于归纳式图神经网络的节点嵌入方法。
  - 通过聚合邻居节点的特征信息，生成节点的嵌入向量。
- 3.2.2 算法流程
  - 步骤1：初始化节点嵌入。
  - 步骤2：通过聚合邻居信息更新节点嵌入。
- 3.2.3 代码实现示例
  - Python代码示例：
  ```python
  import tensorflow as tf
  from tensorflow.keras.layers import Dense, Dropout

  class GraphSAGE(tf.keras.Model):
      def __init__(self, embed_dim):
          super(GraphSAGE, self).__init__()
          self.embed_dim = embed_dim
          self.dense1 = Dense(embed_dim, activation='relu')
          self.dropout = Dropout(0.5)
          self.dense2 = Dense(embed_dim, activation='relu')

      def call(self, inputs):
          # inputs: [node_features, adjacency_matrix]
          node_features = inputs[0]
          adj_matrix = inputs[1]
          # 聚合邻居信息
          neighbor_features = tf.matmul(adj_matrix, node_features)
          # 前向传播
          hidden = self.dense1(neighbor_features + node_features)
          hidden = self.dropout(hidden)
          output = self.dense2(hidden)
          return output
  ```

## 第四部分: 图表示学习的数学模型与公式

### 第4章: 图表示学习的数学基础

#### 4.1 图的表示形式
- 4.1.1 邻接矩阵的定义
  - 邻接矩阵$A$是一个$n \times n$的矩阵，其中$A_{i,j}=1$表示节点$i$和$j$之间有边相连。
- 4.1.2 节点特征向量的表示
  - 节点特征向量$X$是一个$n \times d$的矩阵，其中$n$是节点数，$d$是特征维度。
- 4.1.3 图的拉普拉斯矩阵
  - 拉普拉斯矩阵$L$定义为$L = D - A$，其中$D$是度矩阵。

#### 4.2 节点嵌入的数学模型
- 4.2.1 基于Skip-Gram的节点嵌入
  - 目标函数：$\min_{\theta} \sum_{(i,j)\in D} \log p(j|i;\theta)}$
  - 概率函数：$p(j|i;\theta) = \frac{\exp(e_j^T e_i)}{\sum_{k} \exp(e_k^T e_i)}}$
- 4.2.2 基于图神经网络的嵌入
  - 前向传播函数：$h_i = \sigma(A h_i + b)$
  - 注意力机制：$\alpha_i = \frac{\exp(e_i^T e_j)}{\sum_{k} \exp(e_i^T e_k)}}$
