3. **数据降维**：数据降维的目的是减少数据的维度，提高数据处理的效率。常用的降维方法包括主成分分析（PCA）、线性判别分析（LDA）等。

1. **线性回归**：线性回归是一种简单的预测算法，它通过建立线性关系来预测目标变量。线性回归适用于数据分布较为简单的场景。

2. **决策树**：决策树通过树形结构对数据进行划分，每个节点代表一个特征，每个叶节点代表一个预测结果。决策树适用于处理非结构化数据，能够提供直观的解释。

3. **支持向量机**：支持向量机通过寻找最佳的超平面来划分数据，以达到最大化分类效果。支持向量机适用于处理高维数据，具有较好的泛化能力。

深度学习算法是近年来机器学习领域的重要进展，它通过多层神经网络结构，能够自动学习数据的复杂特征。

2. **循环神经网络（RNN）**：循环神经网络是一种适用于序列数据的深度学习算法，它通过循环结构，能够捕捉序列数据的长期依赖关系。

3. **长短时记忆网络（LSTM）**：长短时记忆网络是循环神经网络的一种变种，它通过门控机制，能够更好地处理长序列数据。

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
