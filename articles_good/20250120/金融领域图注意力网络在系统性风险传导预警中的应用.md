## 第1章: 问题背景与核心概念

### 1.1 系统性风险传导预警的重要性

系统性风险是指对整个金融系统产生重大影响的风险，如银行危机、股市崩盘等。这些风险不仅会对个别金融机构造成重大损失，甚至可能引发整个金融系统的崩溃，从而对实体经济产生深远的影响。近年来，随着全球金融市场日益复杂化和互联互通，系统性风险的传导和扩散速度也大大加快，使得预警和防范系统性风险的重要性日益凸显。

系统性风险传导预警的重要性主要体现在以下几个方面：

1. **维护金融稳定**：通过及时预警和有效防范，可以降低系统性风险的发生概率，从而维护金融市场的稳定。这对于保护投资者的利益、促进金融市场的健康发展具有重要意义。

2. **保障经济安全**：系统性风险一旦爆发，会对经济产生广泛的负面影响，如资本外流、信贷紧缩、企业破产等。通过预警和防范，可以保障经济安全，为国家的长期稳定发展提供支持。

3. **提高决策效率**：预警系统可以为政府和金融机构提供及时、准确的风险信息，帮助它们做出更科学、更有效的决策，从而降低风险管理的成本。

### 1.1.1 系统性风险的定义与特征

系统性风险是指由于金融市场整体或某些重要部分的失灵，导致整个金融系统出现严重问题，从而对经济产生广泛负面影响的潜在风险。与个别金融机构的风险不同，系统性风险具有以下几个特征：

1. **全局性**：系统性风险的影响范围不仅仅局限于个别金融机构，而是涉及到整个金融系统，甚至可能波及实体经济。

2. **传染性**：系统性风险具有很强的传染性，一个金融机构的风险可能会迅速扩散到其他金融机构，导致整个金融系统出现连锁反应。

3. **复杂性**：系统性风险的传导机制非常复杂，涉及多个市场、多种金融工具和多种风险类型，使得预测和防范难度增大。

4. **突发性**：系统性风险往往具有突发性，可能在短时间内迅速爆发，使得预警和应对时间非常有限。

### 1.1.2 系统性风险传导的机制与影响

系统性风险的传导机制主要包括以下几个环节：

1. **市场信心丧失**：当投资者对金融系统的信心下降时，可能导致资本外流、股市崩盘等现象，从而加剧金融系统的风险。

2. **流动性危机**：金融机构在面临大规模资金需求时，可能因无法获得足够的流动性而陷入危机，进而导致整个金融系统的流动性危机。

3. **信贷紧缩**：金融机构在面临风险时，可能会收紧信贷政策，减少对实体经济的支持，导致经济活动放缓，甚至陷入衰退。

4. **跨市场传染**：金融市场的互联互通使得风险可以在不同市场之间快速传播，如股市风险可能传导到债券市场、货币市场等。

系统性风险的影响主要体现在以下几个方面：

1. **金融体系崩溃**：严重的系统性风险可能导致金融机构破产、金融体系崩溃，甚至引发金融危机。

2. **经济衰退**：系统性风险传导到实体经济，可能导致经济活动放缓，甚至陷入衰退，从而对国家经济产生深远的影响。

3. **社会动荡**：金融风险的爆发可能导致社会动荡，影响社会稳定。

### 1.1.3 预警系统建设的必要性

预警系统是防范和应对系统性风险的重要工具，其建设具有以下几个方面的必要性：

1. **实时监测**：预警系统可以实时监测金融市场的动态变化，及时发现潜在风险，为决策提供依据。

2. **风险识别**：预警系统可以利用大数据、人工智能等技术手段，对海量金融数据进行深度分析，识别出系统性风险的关键因素。

3. **早期干预**：预警系统可以在风险爆发前采取早期干预措施，降低风险发生的概率和影响。

4. **决策支持**：预警系统可以为政府和金融机构提供及时、准确的风险信息，帮助它们做出更科学、更有效的决策。

5. **风险预警标准**：预警系统可以制定和实施统一的风险预警标准，提高风险管理的标准化和规范化水平。

### 1.2 图注意力网络的基本原理

图注意力网络（Graph Attention Network，GAN）是一种基于注意力机制的图神经网络，它通过对图中的节点和边进行加权处理，提高了模型的表示能力和泛化能力。图注意力网络在处理图结构数据方面具有显著优势，因此在金融领域也得到了广泛应用。

#### 1.2.1 图注意力网络的定义

图注意力网络是一种结合了图神经网络（Graph Neural Network，GNN）和注意力机制（Attention Mechanism）的神经网络模型。它通过引入注意力机制，对图中的节点和边进行加权，从而实现对图结构数据的自适应表示。

#### 1.2.2 图注意力网络的结构与功能

图注意力网络主要由以下几个部分组成：

1. **节点嵌入层**：将图中的节点表示为高维向量，作为网络的输入。
2. **图注意力层**：对节点和边进行加权，通过注意力机制计算节点表示的权重。
3. **图卷积层**：利用加权的节点表示进行图卷积操作，提取图结构信息。
4. **输出层**：对图卷积结果进行分类或回归等操作，得到最终预测结果。

图注意力网络的主要功能是学习图结构数据的表示，并利用这些表示进行节点分类、关系预测等任务。

#### 1.2.3 图注意力网络的优势与局限

图注意力网络在金融领域具有以下优势：

1. **强大的表示能力**：通过注意力机制，图注意力网络可以学习到图结构数据中的复杂模式和关系，提高模型的表示能力。
2. **自适应调整**：图注意力网络可以根据不同的任务和数据特点，自适应地调整节点和边的权重，提高模型的泛化能力。
3. **可扩展性**：图注意力网络可以容易地扩展到大型图结构数据，处理复杂的金融网络。

然而，图注意力网络也存在一些局限性：

1. **计算复杂度**：图注意力网络涉及到大量的矩阵运算，计算复杂度较高，对计算资源要求较高。
2. **数据依赖性**：图注意力网络对图结构数据的质量和规模有较高要求，如果数据质量较差或规模较小，模型的性能可能会受到影响。
3. **解释性**：尽管图注意力网络可以学习到图结构数据中的复杂模式，但其内部机制较为复杂，解释性较差。

### 1.3 金融领域与图注意力网络的应用

金融领域是一个高度复杂的系统，涉及到大量的图结构数据，如图表、债券、股票等。图注意力网络在金融领域具有广泛的应用前景。

#### 1.3.1 金融领域中的系统性风险传导

金融领域中的系统性风险传导是指风险从一个金融机构或市场传递到另一个金融机构或市场，从而影响整个金融系统的过程。图注意力网络可以通过学习金融网络中的节点和边关系，识别出潜在的风险传导路径，为风险预警和防范提供支持。

#### 1.3.2 图注意力网络在金融领域的应用现状

图注意力网络在金融风险预警中具有以下优势：

## 第2章: 图注意力网络基础

### 2.1 图论基础

图论是研究图形的性质和应用的数学分支。在图注意力网络的研究和应用中，图论的基础知识是不可或缺的。本节将介绍图论的一些基本概念，包括图的定义与类型、基本操作与算法以及图的属性与特征。

#### 2.1.1 图的定义与类型

图是由节点（也称为顶点）和边组成的数学结构。在图注意力网络中，节点通常表示实体（如金融机构、股票等），边表示实体之间的关系（如投资关系、借贷关系等）。

1. **无向图**：无向图是指边没有方向的图。在无向图中，如果存在一条边连接节点A和节点B，那么也存在一条边连接节点B和节点A。

2. **有向图**：有向图是指边有方向的图。在有向图中，边只连接一对节点，没有反向边。

3. **加权图**：加权图是指边的权重为实数的图。边的权重可以表示两个节点之间的距离、相似度或其他相关度。

4. **多图**：多图是指图中存在多个边的图。在多图中，一对节点之间可以有多条边。

5. **简单图**：简单图是指没有自环（节点连接自己）和多重边（多个边连接同一对节点）的图。

#### 2.1.2 图的基本操作与算法

图的基本操作包括节点的添加、删除、查找以及边的添加、删除和查找。以下是一些常见的图算法：

1. **深度优先搜索（DFS）**：DFS是一种用于遍历图的算法，它从起始节点开始，沿着路径一直深入到不能再深入为止，然后回溯到上一个节点，继续寻找其他路径。

2. **广度优先搜索（BFS）**：BFS与DFS类似，但它是按照节点的距离层次进行遍历，即首先遍历起始节点的所有相邻节点，然后遍历这些节点的相邻节点，以此类推。

3. **最小生成树（MST）**：MST是一种用于构建图的最小子图，包含图中所有的节点，且边的权重之和最小。常用的MST算法有普里姆算法和克鲁斯卡尔算法。

4. **最短路径算法**：最短路径算法用于找到图中两个节点之间的最短路径。常用的最短路径算法有迪杰斯特拉算法（Dijkstra）和贝尔曼-福特算法（Bellman-Ford）。

5. **拓扑排序**：拓扑排序是一种用于排序图中节点的算法，它可以根据节点的依赖关系进行排序，确保没有节点依赖于其后续节点。

#### 2.1.3 图的属性与特征

图的属性和特征对于图注意力网络的设计和应用具有重要意义。以下是一些常见的图的属性和特征：

1. **连通性**：图是否连通，即任意两个节点之间是否都存在路径。

2. **度**：节点所连接的边的数量，也称为节点的度。

3. **路径长度**：连接两个节点的最短路径的长度。

4. **介数**：节点在图中的重要性，它表示节点作为其他节点之间路径的中间节点的数量。

5. **聚类系数**：节点邻居之间相互连接的概率，表示图的紧密程度。

6. **特征向量**：节点的特征向量可以表示节点的属性和关系，是图神经网络的重要输入。

通过理解图论的基础知识，我们可以更好地设计和应用图注意力网络，挖掘图结构数据中的潜在信息和模式，为金融领域系统性风险传导预警提供有效支持。

### 2.2 神经网络基础

神经网络（Neural Networks）是一种基于生物神经网络原理的人工智能模型，通过模拟生物神经元的结构和功能，实现从数据中学习规律和模式的能力。在图注意力网络的研究和应用中，神经网络的基础知识是不可或缺的。本节将介绍神经网络的基本结构、深度神经网络的工作原理以及神经网络的优化与训练。

#### 2.2.1 神经网络的基本结构

神经网络由多个层次组成，包括输入层、隐藏层和输出层。每个层次由多个神经元（也称为节点）组成，神经元之间通过连接（也称为边）进行信息传递。

1. **输入层**：输入层接收外部输入数据，每个输入神经元对应一个特征。例如，在金融数据中，输入层可能包括股票价格、交易量、利率等特征。

2. **隐藏层**：隐藏层对输入数据进行处理和变换，通过非线性激活函数引入非线性特性。隐藏层的神经元数量和层数可以根据任务需求进行调整。通常，隐藏层越深，模型的表示能力越强。

3. **输出层**：输出层对隐藏层的输出进行最终决策或预测。输出层的神经元数量和类型取决于具体的任务，如二分类任务通常只有一个神经元，回归任务可能有多個神经元。

神经元之间的连接权重（也称为权重矩阵）是神经网络的核心参数，通过训练过程进行调整，以最小化预测误差。

#### 2.2.2 深度神经网络的工作原理

深度神经网络（Deep Neural Networks，DNN）是具有多个隐藏层的神经网络，其工作原理可以概括为以下几个步骤：

1. **前向传播**：输入数据从输入层传递到隐藏层，经过多个隐藏层的非线性变换后，最终传递到输出层。在每个层次，神经元通过加权求和并应用激活函数，实现对输入数据的处理。

2. **激活函数**：激活函数用于引入非线性特性，常见的激活函数包括sigmoid、ReLU（Rectified Linear Unit）和Tanh（双曲正切函数）。ReLU函数在训练深层网络时尤其有效，因为它可以避免梯度消失问题。

3. **反向传播**：在输出层得到预测结果后，计算实际输出与预测输出之间的误差。然后，通过反向传播算法，将误差从输出层传递回隐藏层，并更新各层的权重矩阵。

4. **优化算法**：反向传播算法结合优化算法（如梯度下降、Adam等），不断调整权重矩阵，以最小化预测误差。优化算法的目标是找到使损失函数最小的权重配置。

#### 2.2.3 神经网络的优化与训练

神经网络的训练过程是一个迭代优化过程，其核心目标是找到最优的权重配置，使模型能够准确预测输入数据。以下是一些常见的优化与训练方法：

1. **梯度下降**：梯度下降是一种最简单的优化算法，其基本思想是沿着损失函数的梯度方向，反向调整权重矩阵。梯度下降可以分为批量梯度下降、随机梯度下降和小批量梯度下降等变体。

2. **动量**：动量（Momentum）是一种用于加速梯度下降的技巧，它可以利用之前迭代的梯度信息，增加步长的方向一致性。

3. **Adam**：Adam（Adaptive Moment Estimation）是一种结合了动量和自适应学习率的优化算法，它通过估计梯度的一阶矩（均值）和二阶矩（方差），自适应调整学习率。

4. **正则化**：正则化（Regularization）是一种用于防止模型过拟合的技术，其基本思想是在损失函数中添加一个正则化项，限制权重矩阵的大小。常见的正则化方法包括L1正则化、L2正则化和Dropout。

5. **学习率调整**：学习率调整是优化过程中的一项关键技术，它通过调整学习率的大小，平衡模型的收敛速度和精度。

通过以上优化与训练方法，深度神经网络可以逐步学习输入数据中的规律和模式，实现高效的预测和分类任务。

### 2.3 注意力机制基础

注意力机制（Attention Mechanism）是一种在深度学习领域广泛应用的技术，它通过对输入数据进行加权处理，提高了模型的表示能力和泛化能力。在图注意力网络中，注意力机制用于对图中的节点和边进行加权，从而实现对图结构数据的自适应表示。本节将介绍注意力机制的定义、作用以及实现方法。

#### 2.3.1 注意力机制的定义与作用

注意力机制是一种基于加权平均的机制，它通过将输入数据的某些部分赋予更高的权重，从而提高模型对重要信息的关注程度。注意力机制可以用于多种任务，如机器翻译、图像识别和文本分类等，其主要作用包括：

1. **提高模型表示能力**：通过注意力机制，模型可以自动学习到不同部分的重要性，从而提高对输入数据的表示能力。

2. **降低计算复杂度**：注意力机制可以减少模型对冗余信息的关注，从而降低计算复杂度。

3. **增强泛化能力**：通过注意力机制，模型可以更好地处理变量长度和变异性较强的数据，从而提高泛化能力。

4. **优化模型性能**：注意力机制可以显著提高模型的性能，特别是在处理复杂任务时。

#### 2.3.2 注意力机制的实现方法

注意力机制的实现方法有多种，以下介绍几种常用的实现方法：

1. **基于加权的平均池化**：这种方法通过对输入数据进行加权平均，实现对重要信息的关注。具体而言，对于每个输入数据，计算其权重，然后将权重与数据相乘，最后对乘积进行平均。

2. **基于加权的点积**：这种方法通过计算输入数据之间的点积，得到权重。点积越大，表示两个输入数据之间的关系越紧密，权重越高。具体而言，对于两个输入向量，其点积为两个向量的对应元素相乘后求和。

3. **基于加权的 Softmax**：这种方法通过对输入数据进行 Softmax 操作，得到权重。Softmax 操作可以将输入数据转换为概率分布，权重越大，表示输入数据的重要性越高。

4. **自注意力（Self-Attention）**：自注意力是一种特殊的注意力机制，它对输入数据进行自引用，从而实现对输入数据的内部结构进行建模。自注意力通常用于处理序列数据，如自然语言处理中的文本序列。

5. **多头注意力（Multi-Head Attention）**：多头注意力是一种扩展自注意力的方法，它通过多个注意力头来并行处理输入数据，从而提高模型的表示能力。多头注意力是 Transformer 模型的核心组件，已经在多种任务中取得了优异的性能。

#### 2.3.3 注意力机制的优势与挑战

注意力机制在深度学习领域具有显著的优势，但也存在一定的挑战：

1. **优势**：

- **高效性**：注意力机制可以显著提高模型的表示能力，减少冗余计算，提高计算效率。
- **灵活性**：注意力机制可以根据任务需求，自适应地调整对输入数据的关注程度，提高模型的适应性。
- **泛化能力**：注意力机制可以处理变异性较强的数据，从而提高模型的泛化能力。

2. **挑战**：

- **计算复杂度**：注意力机制涉及到大量的矩阵运算，计算复杂度较高，特别是在处理大型数据时。
- **解释性**：注意力机制内部机制较为复杂，对模型解释性带来一定挑战。
- **数据依赖性**：注意力机制对输入数据的质量和规模有较高要求，如果数据质量较差或规模较小，模型的性能可能会受到影响。

### 2.4 图注意力网络的结构

图注意力网络（Graph Attention Network，GAN）是一种结合了图神经网络（Graph Neural Network，GNN）和注意力机制的神经网络模型，它通过对图中的节点和边进行加权处理，提高了模型的表示能力和泛化能力。本节将介绍图注意力网络的基本结构，包括节点嵌入层、图注意力层、图卷积层和输出层。

#### 2.4.1 图注意力网络的基本结构

图注意力网络的基本结构可以分为以下几个部分：

1. **节点嵌入层**：节点嵌入层将图中的节点表示为高维向量，作为网络的输入。这些向量可以捕捉节点的属性信息和节点之间的关系。

2. **图注意力层**：图注意力层对节点和边进行加权处理，通过注意力机制计算节点表示的权重。具体而言，图注意力层计算每个节点对其他节点的注意力得分，并将这些得分与节点的嵌入向量相乘，得到加权的节点表示。

3. **图卷积层**：图卷积层利用加权的节点表示进行图卷积操作，提取图结构信息。图卷积操作可以捕捉节点和边之间的相互作用，从而提高模型的表示能力。

4. **输出层**：输出层对图卷积结果进行分类或回归等操作，得到最终预测结果。输出层的类型和数量取决于具体的任务需求。

#### 2.4.2 图注意力机制的计算过程

图注意力机制的计算过程可以分为以下几个步骤：

1. **节点嵌入**：将图中的节点表示为高维向量，这些向量可以由预训练的词向量、节点属性或其他特征生成。

2. **注意力得分计算**：对于每个节点，计算其对其他节点的注意力得分。注意力得分通常通过计算节点嵌入向量的点积、加权和等方法得到。

3. **加权节点表示**：将注意力得分与节点的嵌入向量相乘，得到加权的节点表示。加权的节点表示可以强调重要节点的信息，忽略冗余信息。

4. **图卷积操作**：利用加权的节点表示进行图卷积操作，提取图结构信息。图卷积操作可以捕捉节点和边之间的相互作用，从而提高模型的表示能力。

5. **多层递归**：通过多层图卷积操作，逐层提取图结构信息，加深模型的表示能力。

6. **输出层处理**：对图卷积结果进行分类或回归等操作，得到最终预测结果。输出层的类型和数量取决于具体的任务需求。

#### 2.4.3 图注意力网络的核心优势

图注意力网络在处理图结构数据方面具有以下核心优势：

### 2.5 图注意力网络的算法流程

图注意力网络（Graph Attention Network，GAN）的算法流程可以分为输入与预处理、图注意力层计算、网络输出与后处理等步骤。本节将详细阐述这些步骤，并展示如何实现图注意力网络的算法。

#### 2.5.1 算法输入与预处理

1. **输入数据**：图注意力网络的输入是图结构数据，包括节点、边和节点特征。节点特征可以是预训练的词向量、节点属性或其他特征。边可以是有向的或无向的，并可能带有权重。

2. **节点嵌入**：将图中的节点表示为高维向量，这些向量可以作为节点的嵌入表示。通常，节点嵌入可以通过预训练的词向量生成，也可以通过随机初始化并在训练过程中学习。

3. **预处理**：对输入数据进行标准化或归一化处理，以减少数据之间的差异。此外，还可以进行数据清洗，去除噪声数据或缺失值。

#### 2.5.2 图注意力层的计算

1. **注意力得分计算**：对于每个节点，计算其对其他节点的注意力得分。注意力得分通常通过点积、加权和等计算方法得到。具体而言，假设节点 \(i\) 的嵌入向量为 \(e_i\)，节点 \(j\) 的嵌入向量为 \(e_j\)，边 \(ij\) 的权重为 \(w_{ij}\)，则注意力得分可以表示为：

   \[
   s_{ij} = \text{Attention}(e_i, e_j, w_{ij})
   \]

   其中，Attention 函数可以是点积、加权和等。

2. **加权节点表示**：将注意力得分与节点的嵌入向量相乘，得到加权的节点表示。加权的节点表示可以强调重要节点的信息，忽略冗余信息。具体而言，假设 \(a_i\) 是节点 \(i\) 的加权表示，则有：

   \[
   a_i = \sum_{j} s_{ij} e_j
   \]

3. **图卷积操作**：利用加权的节点表示进行图卷积操作，提取图结构信息。图卷积操作可以捕捉节点和边之间的相互作用，从而提高模型的表示能力。常见的图卷积操作包括：

   - **邻接矩阵乘法**：通过邻接矩阵 \(A\) 和加权节点表示 \(a_i\) 的乘法，实现图卷积操作。
   - **卷积神经网络（CNN）**：将图卷积操作与卷积神经网络相结合，实现更复杂的图卷积操作。

#### 2.5.3 网络输出与后处理

1. **输出层计算**：对图卷积结果进行分类或回归等操作，得到最终预测结果。输出层的类型和数量取决于具体的任务需求。例如，在二分类任务中，输出层可能是一个 sigmoid 激活函数的神经元；在多分类任务中，输出层可能是一个 Softmax 激活函数的神经元。

2. **损失函数计算**：计算输出结果与实际标签之间的损失，常用的损失函数包括交叉熵损失、均方误差（MSE）等。通过损失函数评估模型的预测性能，并指导模型的优化。

3. **优化算法**：使用优化算法（如梯度下降、Adam等）调整模型参数，以最小化损失函数。优化算法的目标是找到使损失函数最小的权重配置。

4. **后处理**：根据任务需求，进行后处理操作，如阈值设置、结果可视化等。

#### 2.5.4 Python代码示例

以下是一个简单的图注意力网络的 Python 代码示例，展示了如何实现节点嵌入、注意力得分计算和图卷积操作：

```python
# 假设已有邻接矩阵和边权重
```

```python
import torch.nn as nn
import torch.nn.functional as F

class GraphAttentionNetwork(nn.Module):
    def __init__(self, num_nodes, embedding_dim, hidden_dim):
        super(GraphAttentionNetwork, self).__init__()
        self.embedding = nn.Embedding(num_nodes, embedding_dim)
        self.attn_head = nn.Linear(embedding_dim, hidden_dim)
        self.attn_dropout = nn.Dropout(p=0.1)
        self.fc = nn.Linear(hidden_dim, 1)

    def forward(self, node_idx, adj_matrix):
        embeddings = self.embedding(node_idx)
        attn_scores = self.attn_head(embeddings)
        attn_scores = F.softmax(attn_scores, dim=1)
        attn_scores = self.attn_dropout(attn_scores)
        attn_embeddings = torch.matmul(attn_scores, embeddings)
        output = self.fc(attn_embeddings)
        return output
```

#### 4.4.1 预测效果评估

预测效果的评估通常通过以下指标进行：

1. **准确率（Accuracy）**：预测结果与实际标签匹配的比例。准确率越高，模型预测效果越好。
2. **精确率（Precision）**：预测为正类别的样本中，实际为正类别的比例。精确率越接近 1，表示模型对正类别的预测越准确。
3. **召回率（Recall）**：实际为正类别的样本中被预测为正类别的比例。召回率越接近 1，表示模型对正类别的预测覆盖面越广。
4. **F1 分数（F1 Score）**：精确率和召回率的调和平均值，用于综合评估模型的预测效果。F1 分数越高，表示模型性能越好。
5. **ROC 曲线和 AUC（Area Under Curve）**：ROC 曲线展示了不同阈值下预测为正类别的概率与实际为正类别的概率的关系，AUC 值表示曲线下的面积，AUC 越大，表示模型区分能力越强。

```python

roc_auc = roc_auc_score(actual_labels, predictions)

print(f'Accuracy: {accuracy}')
print(f'Precision: {precision}')
print(f'Recall: {recall}')
print(f'F1 Score: {f1}')
print(f'ROC AUC: {roc_auc}')
```

```python
confusion_matrix = confusion_matrix(actual_labels, predictions)

plt.xlabel('Predicted Labels')

plt.title('Confusion Matrix')
plt.show()

# ROC 曲线和 AUC 图
fpr, tpr, _ = roc_curve(actual_labels, predictions)
plt.plot(fpr, tpr, label='ROC Curve (area = %0.2f)' % roc_auc)
plt.plot([0, 1], [0, 1], 'k--')
plt.xlabel('False Positive Rate')
plt.ylabel('True Positive Rate')
plt.title('ROC Curve')
plt.legend(loc='lower right')
plt.show()
```

#### 4.4.3 预测结果解读

4. **ROC 曲线和 AUC**：ROC 曲线和 AUC 反映了模型的区分能力和阈值选择。高 AUC 值表示模型在不同阈值下具有较好的区分能力。
