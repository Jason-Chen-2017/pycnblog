### 2.2 常见机器学习算法
#### 2.2.1 监督学习算法
- **线性回归**：
  - **原理**：建立输入和输出之间的线性关系，预测连续值。
  - **公式**：\(y = \beta_0 + \beta_1 \cdot x\)
  - **应用**：房价预测、股票市场分析等。

- **逻辑回归**：
  - **原理**：建立输入和输出之间的逻辑关系，预测概率。
  - **公式**：\(P(y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 \cdot x)}}\)
  - **应用**：分类问题，如邮件垃圾过滤、信用卡欺诈检测等。

- **决策树**：
  - **原理**：通过一系列条件判断，将数据划分成多个子集，每个子集对应一个类。
  - **公式**：无明确公式，但涉及信息增益、基尼不纯度等。
  - **应用**：分类和回归问题，如贷款审批、疾病诊断等。

- **随机森林**：
  - **原理**：通过构建多个决策树，并取平均值来降低过拟合。
  - **应用**：高维数据分类和回归，如信用卡欺诈检测、股票市场预测等。

#### 2.2.2 无监督学习算法
- **K-均值聚类**：
  - **原理**：将数据点分为K个簇，每个簇由质心表示。
  - **公式**：\(c_k = \frac{1}{N_k} \sum_{x_i \in S_k} x_i\)
  - **应用**：市场细分、文本分类等。

- **主成分分析（PCA）**：
  - **原理**：通过线性变换降低数据维度，保留主要信息。
  - **公式**：\(z = PC\)
  - **应用**：图像压缩、数据预处理等。

- **自编码器**：
  - **原理**：通过编码和解码器，学习数据的高效表示。
  - **公式**：\(x = \sigma(W_d \cdot z + b_d)\)
  - **应用**：特征提取、异常检测等。

#### 2.2.3 强化学习算法
- **Q学习**：
  - **原理**：通过学习状态-动作值函数，选择最优动作。
  - **公式**：\(Q(s, a) = r + \gamma \max_a' Q(s', a')\)
  - **应用**：游戏AI、自动驾驶等。

- **深度强化学习**：
  - **原理**：结合深度学习和强化学习，模拟复杂环境。
  - **应用**：智能机器人、游戏AI等。

#### 2.2.4 算法比较
- **监督学习**：
  - **优点**：能够明确预测结果，适用于分类和回归问题。
  - **缺点**：需要标注数据，对噪声敏感，可能过拟合。

- **无监督学习**：
  - **优点**：无需标注数据，能够发现数据中的隐含结构。
  - **缺点**：预测结果不明确，可能需要更多的数据。

- **强化学习**：
  - **优点**：能够处理动态环境，学习长期回报。
  - **缺点**：收敛速度慢，需要大量数据。

### 2.3 深度学习技术
#### 2.3.1 神经网络基础
- **神经元模型**：
  - **原理**：模拟生物神经元，接收输入，通过权重和偏置进行加权求和，并使用激活函数输出结果。
  - **公式**：\(z = \sum_{i=1}^{n} w_i \cdot x_i + b\)
  - **应用**：感知器、多层感知器等。

- **反向传播算法**：
  - **原理**：通过梯度下降法，反向传播误差，更新网络权重和偏置。
  - **公式**：\(w_{new} = w_{old} - \alpha \cdot \frac{\partial J}{\partial w}\)
  - **应用**：训练多层神经网络，提高模型性能。

#### 2.3.2 深度学习模型
- **卷积神经网络（CNN）**：
  - **原理**：利用卷积层自动提取图像特征，减少参数数量。
  - **公式**：\(h_{ij} = \sum_{k} w_{ik} \cdot g_{kj} + b_j\)
  - **应用**：图像分类、物体检测等。

- **循环神经网络（RNN）**：
  - **原理**：通过循环结构处理序列数据，捕捉时间依赖性。
  - **公式**：\(h_t = \sigma(W_h \cdot [h_{t-1}, x_t] + b_h)\)
  - **应用**：语音识别、自然语言处理等。

- **长短时记忆网络（LSTM）**：
  - **原理**：通过门控机制解决RNN的长短时依赖问题。
  - **公式**：\(i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)\)
  - **应用**：时间序列预测、语言建模等。

#### 2.3.3 深度学习框架
- **TensorFlow**：
  - **原理**：谷歌开发的端到端开源机器学习框架。
  - **特点**：灵活性强，支持多种深度学习模型。

- **PyTorch**：
  - **原理**：Facebook开发的开源深度学习框架。
  - **特点**：动态图模型，易于调试。

#### 2.3.4 深度学习应用场景
- **图像处理**：如人脸识别、自动驾驶等。
- **自然语言处理**：如机器翻译、文本生成等。
- **语音识别**：如语音助手、语音搜索等。

#### 2.3.5 深度学习的挑战
- **过拟合**：模型在训练数据上表现良好，但在新数据上性能下降。
- **计算资源需求**：深度学习模型通常需要大量的计算资源和时间进行训练。
- **数据标注**：对于有监督学习，需要大量标注数据，成本较高。

- **F1分数（F1 Score）**：精确率和召回率的调和平均，计算公式为 \( \frac{2 \cdot Precision \cdot Recall}{Precision + Recall} \)。
- **ROC曲线**：通过绘制真阳性率（True Positive Rate）和假阳性率（False Positive Rate）的关系，评估模型性能。

     List<double[]> features = cleanedTransactions.stream()
         .map(t -> extractFeatures(t))
         .collect(Collectors.toList());

     // 归一化处理
     double[] minMax = features.stream()
         .flatMapToDouble(Arrays::stream)
         .reduce(new double[]{Double.MAX_VALUE, Double.MIN_VALUE}, (a, b) -> {
             a[0] = Math.min(a[0], b);

      public ResponseEntity<List<Transaction>> getTransactions(@RequestParam("start_time") String startTime,

      }

          FraudResult result = fraudDetectionService.detectFraud(transaction);
          return ResponseEntity.ok(result);
      }
  }

### A. 术语表

- **信用卡欺诈**：指未经持卡人授权或不知情的情况下，恶意者非法获取和使用信用卡资金的行为。

- **深度学习**：机器学习的一个子领域，主要利用多层神经网络来模拟人脑的学习过程。
- **监督学习**：已知输入和输出，训练模型预测未知输出。
- **无监督学习**：仅知输入，通过发现数据中的隐含结构进行学习。
- **强化学习**：通过试错学习，最大化长期回报。
- **特征工程**：从原始数据中提取有助于模型学习的特征。
- **联邦学习**：一种分布式学习方法，多个机构可以在不共享数据的情况下共同训练模型。
- **多模态数据融合**：将多种数据来源（如交易数据、行为数据、图像数据等）进行融合，提高系统的检测能力。
