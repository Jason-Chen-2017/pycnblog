### 1.1 树搜索的基本概念

树搜索是一种搜索策略，用于在状态空间树中查找满足特定条件的节点。状态空间树是由问题的初始状态和所有可能的后续状态组成的树形结构。树搜索的核心思想是递归地扩展当前节点，并检查其子节点是否满足目标条件。根据搜索策略的不同，树搜索可以分为深度优先搜索、广度优先搜索和启发式搜索等。

- **深度优先搜索（DFS）**：深度优先搜索是一种逐层遍历状态空间树的方法，它首先扩展当前节点的子节点，然后再回溯到父节点继续扩展。DFS具有记忆性，容易陷入局部最优解。

- **广度优先搜索（BFS）**：广度优先搜索是一种逐层遍历状态空间树的方法，它首先扩展当前节点的所有子节点，然后再扩展下一个层次的节点。BFS能够找到最短路径，但可能需要较大的内存空间。

- **启发式搜索**：启发式搜索是一种基于问题领域知识进行搜索的方法。它利用启发式函数来评估节点的优先级，从而指导搜索方向。启发式搜索能够提高搜索效率，但需要精心设计启发式函数。

## 第3章：树搜索算法原理

树搜索算法是自动收集推理路径正确性数值的关键技术。本节将介绍几种常见的树搜索算法，包括深度优先搜索（DFS）、广度优先搜索（BFS）和启发式搜索。

### 3.1 深度优先搜索（DFS）

深度优先搜索是一种非启发式的树搜索算法，它从初始状态开始，沿着一条路径尽可能深地搜索。DFS算法的基本步骤如下：

1. **初始化**：设置当前节点为初始状态，打开一个栈，将初始状态压入栈中。

2. **搜索**：从栈顶节点开始，扩展当前节点的所有子节点，并依次将子节点压入栈中。

3. **回溯**：当当前节点无子节点时，从栈中弹出节点，并继续搜索其兄弟节点。

4. **终止条件**：当找到目标节点时，搜索结束。

### 3.2 广度优先搜索（BFS）

广度优先搜索是一种启发式的树搜索算法，它逐层搜索状态空间树。BFS算法的基本步骤如下：

1. **初始化**：设置当前节点为初始状态，打开一个队列，将初始状态入队。

2. **搜索**：从队列头部取出节点，扩展当前节点的所有子节点，并依次将子节点入队。

3. **回溯**：当当前节点无子节点时，从队列中出队节点，并继续搜索其兄弟节点。

4. **终止条件**：当找到目标节点时，搜索结束。

### 3.3 启发式搜索

启发式搜索是一种利用问题领域知识的搜索算法。它通过评估函数（启发式函数）来指导搜索方向，从而提高搜索效率。启发式搜索的基本步骤如下：

1. **初始化**：设置当前节点为初始状态，打开一个优先级队列，将初始状态入队。

2. **搜索**：从优先级队列头部取出评估值最小的节点，扩展当前节点的所有子节点，并计算每个子节点的评估值。

3. **更新队列**：将子节点按照评估值插入优先级队列中。

4. **回溯**：当当前节点无子节点时，从优先级队列中取出评估值最小的节点，并继续搜索其兄弟节点。

5. **终止条件**：当找到目标节点时，搜索结束。

    return abs(state['x'] - state['goal_x']) + abs(state['y'] - state['goal_y'])

    heapq.heappush(frontier, Node(initial_state))
    explored = set()

    while frontier:

    if state['y'] > 0:

    if state['y'] < state['goal_y']:
        actions.append({'direction': 'down', 'new_state': {'x': state['x'], 'y': state['y'] + 1}})

def apply_action(state, action):
    if action['direction'] == 'left':
        return {'x': state['x'] - 1, 'y': state['y']}
    elif action['direction'] == 'right':
        return {'x': state['x'] + 1, 'y': state['y']}
    elif action['direction'] == 'up':
        return {'x': state['x'], 'y': state['y'] - 1}
    elif action['direction'] == 'down':
        return {'x': state['x'], 'y': state['y'] + 1}

import heapq

class Node:
    def __init__(self, state, parent=None, action=None):
        self.state = state
        self.parent = parent
        self.action = action
        self.g = 0
        self.h = 0
        self.f = 0

    def __lt__(self, other):
        return self.f < other.f

def heuristic(state):
    return abs(state[0] - state[2]) + abs(state[1] - state[3])

def search(initial_state):
    frontier = []
    heapq.heappush(frontier, Node(initial_state))
    explored = set()

    while frontier:
        node = heapq.heappop(frontier)
        if node.state in explored:
            continue
        explored.add(node.state)

        if is_goal(node.state):
            return node

        for action in get_actions(node.state):
            next_state = apply_action(node.state, action)
            child = Node(next_state, node, action)
            child.g = node.g + 1
            child.h = heuristic(child.state)
            child.f = child.g + child.h
            heapq.heappush(frontier, child)

    return None

def is_goal(state):
    return state[2] == state[0] and state[3] == state[1]

def get_actions(state):
    actions = []
    if state[0] > 0:
        actions.append({'direction': 'left', 'new_state': (state[0] - 1, state[1])})
    if state[0] < state[2]:
        actions.append({'direction': 'right', 'new_state': (state[0] + 1, state[1])})
    if state[1] > 0:
        actions.append({'direction': 'up', 'new_state': (state[0], state[1] - 1)})
    if state[1] < state[3]:
        actions.append({'direction': 'down', 'new_state': (state[0], state[1] + 1)})
    return actions

def apply_action(state, action):
    if action['direction'] == 'left':
        return (state[0] - 1, state[1])
    elif action['direction'] == 'right':
        return (state[0] + 1, state[1])
    elif action['direction'] == 'up':
        return (state[0], state[1] - 1)
    elif action['direction'] == 'down':
        return (state[0], state[1] + 1)

def generate_path(node):
    path = []
    while node:
        path.append(node.state)
        node = node.parent
    return path[::-1]

# 初始状态
initial_state = (0, 0, 5, 5)

# 执行搜索
node = search(initial_state)
if node:
    print("找到了通向目标的路径。")
    print("路径长度：", node.g)
    print("路径：", generate_path(node))
else:
    print("没有找到通向目标的路径。")
