### 13.1 自我认知的项目实战

在自我认知的项目实战中，我们将利用Python编程语言，结合数据分析工具，实现对个体自我认知的自动分析。

**开发环境搭建：**
- 安装Python 3.8及以上版本
- 安装数据分析库：pandas、numpy、matplotlib

**源代码实现：**

```python
import pandas as pd

# 自我认知数据集
data = {
    "personality": ["内向", "外向", "平衡"],
    "interests": [["编程", "阅读", "旅游"], ["音乐", "运动", "电影"], ["学习", "编程", "旅游"]],
    "abilities": [["编程能力", "学习能力", "沟通能力"], ["音乐能力", "运动能力", "社交能力"], ["学习能力", "编程能力", "领导能力"]]
}

df = pd.DataFrame(data)

# 统计各个性格出现的频率
personality_count = df['personality'].value_counts()

# 统计各个兴趣出现的频率
interests_count = df['interests'].apply(pd.Series).stack().value_counts()

# 统计各个能力出现的频率
abilities_count = df['abilities'].apply(pd.Series).stack().value_counts()

# 打印结果
print("性格统计：\n", personality_count)
print("\n兴趣统计：\n", interests_count)
print("\n能力统计：\n", abilities_count)
```

**代码解读与分析：**

这段代码首先创建了一个包含个体自我认知数据的DataFrame，然后通过pandas库的value_counts方法，统计了各个性格、兴趣和能力出现的频率，最后打印出统计结果。这有助于个体了解自己的性格、兴趣和能力分布情况，从而更好地进行自我认知。

### 13.2 善恶判断的项目实战

在善恶判断的项目实战中，我们将开发一个简单的善恶判断系统，用于判断用户输入的行为是否属于善。

**开发环境搭建：**
- 安装Python 3.8及以上版本

**源代码实现：**

```python
def morality_judgment(action):
    # 善恶判断词库
    good_words = ["帮助", "关爱", "分享", "尊重"]
    bad_words = ["欺骗", "伤害", "背叛", "破坏"]

    # 分析行为
    words = action.split()

    # 判断行为是否属于善
    if any(word in good_words for word in words):
        return "善"
    elif any(word in bad_words for word in words):
        return "恶"
    else:
        return "中性"

# 测试善恶判断
action_desc = "帮助朋友解决问题"
judgment = morality_judgment(action_desc)
print(judgment)  # 输出：善
```
