#### 区块链技术基础

区块链技术是一种分布式账本技术，其核心思想是将数据分散存储在多个节点上，通过共识机制和加密算法确保数据的真实性和安全性。以下是区块链技术基础的相关内容：

##### 1.1 区块链的基本概念

区块链是一个分布式数据库，它将数据分块存储，并通过加密算法和共识机制将这些块连接成一个链条。每个区块包含一定数量的交易记录，并且每个区块都包含一个时间戳和一个指向前一个区块的哈希值。这种链接方式使得区块链具有不可篡改的特性。

区块链的基本组成部分包括：

- **区块**：区块是区块链的基本组成单位，包含一定数量的交易记录。每个区块有一个唯一的标识，即哈希值。
- **链**：链是指一系列按时间顺序排列的区块。
- **节点**：节点是指参与区块链网络的计算机，它们负责存储区块链数据、验证交易和参与共识机制。
- **共识机制**：共识机制是一种协议，用于确保区块链网络中的所有节点对数据的共识。常见的共识机制包括工作量证明（PoW）、权益证明（PoS）和委托权益证明（DPoS）等。

##### 1.2 区块链的工作原理

区块链的工作原理主要包括以下几个步骤：

1. **交易记录**：当用户在区块链上进行交易时，交易记录会被发送到区块链网络中的所有节点。
2. **区块生成**：节点将接收到的交易记录组合成一个区块，并对区块进行验证。验证通过后，节点会将区块添加到区块链上。
3. **链式结构**：每个区块都包含一个指向前一个区块的哈希值，这使得区块链形成了一个链式结构。由于每个区块都包含前一个区块的哈希值，任何对区块链数据的篡改都会导致哈希值的改变，从而被发现。
4. **共识机制**：在区块链网络中，节点通过共识机制来决定哪个区块将被添加到区块链上。常见的共识机制包括PoW、PoS和DPoS等。
5. **分布式存储**：区块链数据被分散存储在多个节点上，这使得区块链具有去中心化的特性。即使某个节点出现故障或遭受攻击，区块链数据仍然可以保持完整和安全。

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract RentalContract {
    address owner;
    mapping(uint => mapping(address => uint)) rentHistory;
    mapping(uint => bool) public isRented;

    constructor() {
        owner = msg.sender;
    }

    function rentArtwork(uint artworkId, address renter, uint rentTime) external {
        require(!isRented[artworkId], "Artwork is already rented");
        require(rentTime > 0, "Invalid rent time");

        isRented[artworkId] = true;
        rentHistory[artworkId][renter] = rentTime;
        payable(owner).transfer(msg.value);
    }

    function returnArtwork(uint artworkId, address renter) external {
        require(isRented[artworkId], "Artwork is not rented");
        
        uint rentTime = rentHistory[artworkId][renter];
        delete rentHistory[artworkId][renter];
        isRented[artworkId] = false;
        
        uint remainingTime = block.timestamp - rentTime;
        uint refund = msg.value * remainingTime / rentTime;
        payable(renter).transfer(refund);
    }
}
```
