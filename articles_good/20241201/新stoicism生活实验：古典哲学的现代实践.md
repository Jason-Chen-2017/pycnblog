### 1.1 斯多葛主义的历史背景

斯多葛主义起源于古希腊，约在公元前3世纪由塞内卡（Seneca）、爱比克泰德（Epictetus）和马可·奥勒留（Marcus Aurelius）等哲学家发展起来。斯多葛主义强调理性、自律、平静和内在自由，主张通过控制欲望和情感来达到心灵的平静和幸福。

斯多葛主义的历史背景可以追溯到希腊哲学的繁荣时期。当时，希腊城邦之间的战争和政治动荡不断，人民的生活充满了不确定性。斯多葛主义哲学家们试图寻找一种方法来帮助人们应对这些挑战，他们提出了一种以理性为中心的哲学体系，强调通过自我控制和内在力量来克服外部环境的压力。

### 1.2 斯多葛主义的核心原则

斯多葛主义的核心原则包括：

- **理性与真理**：斯多葛主义者认为理性是人类灵魂的核心，是理解世界和实现幸福的关键。他们追求真理，相信只有通过理性思考才能找到真正的幸福。

- **自律与自制**：斯多葛主义强调自律和自制，主张人们应该控制自己的欲望和情感，以保持内心的平静和稳定。

- **接受命运**：斯多葛主义者认为命运是不可改变的，人们应该接受现实，专注于自己能够控制的事情。

- **追求内在价值**：斯多葛主义者认为真正的幸福来自于内在价值的实现，而不是外在的财富和荣誉。

### 1.3 斯多葛主义与古希腊哲学的关系

斯多葛主义与古希腊哲学有着密切的关系，它继承了苏格拉底、柏拉图和亚里士多德等哲学家的思想。然而，斯多葛主义在许多方面与这些传统哲学有所不同。例如，与苏格拉底的关注道德和美德不同，斯多葛主义更强调理性和内在自由。与柏拉图强调超越现实世界的理念不同，斯多葛主义更加关注现实生活和人类幸福。

```python
from flask import Flask, render_template, request, redirect, url_for, flash
from flask_sqlalchemy import SQLAlchemy
from flask_login import LoginManager, UserMixin, login_user, logout_user, login_required, current_user
from werkzeug.security import generate_password_hash, check_password_hash

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///stoa_project.db'
app.config['SECRET_KEY'] = 'your_secret_key'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

db = SQLAlchemy(app)
login_manager = LoginManager()
login_manager.init_app(app)
login_manager.login_view = 'login'

class User(UserMixin, db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(100), unique=True, nullable=False)
    password = db.Column(db.String(100), nullable=False)

@login_manager.user_loader
def load_user(user_id):
    return User.query.get(int(user_id))

# 路由配置
@app.route('/')
@login_required
def home():
    return render_template('home.html')

@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        username = request.form['username']
        password = request.form['password']
        user = User.query.filter_by(username=username).first()
        if user and check_password_hash(user.password, password):
            login_user(user)
            return redirect(url_for('home'))
        else:
            flash('Invalid username or password', 'danger')
    return render_template('login.html')

@app.route('/register', methods=['GET', 'POST'])
def register():
    if request.method == 'POST':
        username = request.form['username']
        password = request.form['password']
        if not username or not password:
            flash('Username and password are required', 'danger')
        else:
            user = User.query.filter_by(username=username).first()
            if user:
                flash('Username already exists', 'danger')
            else:
                new_user = User(username=username, password=generate_password_hash(password, method='sha256'))
                db.session.add(new_user)
                db.session.commit()
                return redirect(url_for('login'))
    return render_template('register.html')

@app.route('/logout')
@login_required
def logout():
    logout_user()
    return redirect(url_for('login'))

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```
