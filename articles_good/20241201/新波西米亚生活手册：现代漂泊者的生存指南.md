#### 4.1 如何选择旅行目的地

选择旅行目的地时，需要考虑以下几个因素：

- **个人兴趣**：根据个人兴趣选择目的地，如历史文化、自然景观、美食等。
- **安全情况**：了解目的地的安全状况，确保旅行安全。
- **预算**：根据预算选择目的地，考虑交通、住宿和日常开销。

#### 4.2 如何找到合适的居所

找到合适的居所需要考虑以下几个因素：

- **地理位置**：选择离工作地点近的居所，提高工作效率。
- **居住条件**：考虑居住环境是否舒适，如交通便利、设施完善等。
- **预算**：根据预算选择合适的居所，确保生活质量。

#### 4.3 如何平衡旅行与居住

平衡旅行与居住需要注意以下几点：

- **规划**：提前规划旅行时间和行程，避免与重要工作冲突。
- **灵活**：保持灵活性，根据实际情况调整旅行计划。
- **预算**：合理分配旅行和居住的预算，确保生活质量。

    return total_budget

def calculate_weekly_budget(total_budget, weeks):
    weekly_budget = total_budget / weeks
    return weekly_budget

if __name__ == "__main__":
