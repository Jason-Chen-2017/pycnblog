# 第3章: 生物多样性保护的经济价值评估模型

## 3.1 模型原理

### 3.1.1 生物多样性保护的经济价值构成

生物多样性保护的经济价值包括：
1. **直接使用价值**：例如，药用植物的利用。
2. **间接使用价值**：例如，生态系统的碳汇功能。
3. **非使用价值**：例如，生物多样性的存在价值。

### 3.1.2 经济价值评估的数学模型

经济价值评估模型可以表示为：
$$
EV = \sum_{t=0}^{n} \frac{C_t}{(1 + r)^t}
$$
其中：
- \( EV \) 表示经济价值
- \( C_t \) 表示第 \( t \) 年的净收益
- \( r \) 表示贴现率
- \( n \) 表示评估周期

### 3.1.3 模型假设与限制条件

1. **假设**：生物多样性保护的收益可以在未来周期内逐步实现。
2. **限制条件**：模型仅考虑经济价值，不涉及生态系统的非经济价值。

---

## 3.2 数学模型与公式

### 3.2.1 生物多样性净现值计算

净现值（NPV）公式为：
$$
NPV = \sum_{t=0}^{n} \frac{C_t}{(1 + r)^t}
$$

其中：
- \( C_t \) 包括生物多样性保护的直接成本和间接收益。
- \( r \) 为贴现率，通常取企业的资本成本。

## 6.1 项目实战

### 6.1.1 环境安装

### 6.1.2 核心代码实现

```python
import numpy as np
import matplotlib.pyplot as plt

def calculate_npv(costs, rate):
    npv = 0
    for t in range(len(costs)):
        npv += costs[t] / (1 + rate) ** t
    return npv

# 示例数据
costs = [1000, 200, 200, 200, 200]
rate = 0.05

npv = calculate_npv(costs, rate)
print(f"NPV = {npv}")
```
