## 第一部分: 全球化视角下的价值投资基础

### 第1章: 全球化视角与价值投资概述

#### 1.1 全球化视角的定义与背景

- **全球化视角的定义**：从全球市场的角度分析投资机会，关注跨国公司的全球布局和不同市场的经济特点。
- **价值投资的核心理念**：寻找被市场低估的资产，长期持有，关注公司的基本面和长期盈利能力。
- **全球化视角与价值投资的结合**：在分析公司时，不仅要考虑本地市场，还要关注公司在全球市场中的竞争地位和战略布局。

#### 1.2 价值投资的基本原理

- **价值投资的定义与特点**：寻找价格低于内在价值的资产，强调安全边际和长期持有。
- **价值投资的核心要素**：公司基本面分析、财务指标评估、竞争优势分析。
- **价值投资的适用场景**：在市场恐慌或低估时期，价值投资策略表现尤为突出。

#### 1.3 全球化视角下的投资环境

- **全球经济与投资的关系**：全球经济周期、利率变化和通货膨胀对投资策略的影响。
- **不同国家与市场的特点**：新兴市场与发达市场的差异，汇率波动对投资的影响。
- **全球化视角下的投资风险**：国际政治经济风险、市场波动性增加、资产配置的复杂性。

### 第9章: 项目实战

#### 9.1 环境安装

#### 9.2 核心实现源代码

以下是一个基于全球化视角的简单价值投资策略代码示例：

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import yfinance as yf

# 下载数据
def get_data(ticker, start, end):
    data = yf.download(ticker, start=start, end=end)
    return data['Adj Close']

# 计算移动平均线（MA）
def calculate_ma(data, window):
    ma = data.rolling(window).mean()
    return ma

# 计算相对强弱指数（RSI）
def calculate_rsi(data, window):
    diff = data.diff().dropna()
    up = diff[diff > 0]
    down = diff[diff < 0]
    rs = up.rolling(window).mean() / down.rolling(window).mean().abs()
    rsi = 100 - 100 / (1 + rs)
    return rsi

# 主函数
def main():
    start_date = '2020-01-01'
    end_date = '2023-01-01'
    
    # 下载股票数据
    msft_data = get_data('MSFT', start_date, end_date)
    aapl_data = get_data('AAPL', start_date, end_date)
    google_data = get_data('GOOGL', start_date, end_date)
    
    # 计算移动平均线和RSI
    ma_msft = calculate_ma(msft_data, 20)
    rsi_msft = calculate_rsi(msft_data, 14)
    
    ma_aapl = calculate_ma(aapl_data, 20)
    rsi_aapl = calculate_rsi(aapl_data, 14)
    
    ma_google = calculate_ma(google_data, 20)
    rsi_google = calculate_rsi(google_data, 14)
    
    # 绘制图表
    plt.figure(figsize=(12, 6))
    plt.plot(msft_data, label='MSFT Price')
    plt.plot(ma_msft, label='MSFT 20-day MA')
    plt.plot(rsi_msft, label='MSFT RSI')
    plt.legend()
    plt.title('MSFT: Price, MA, RSI')
    plt.show()
    
    plt.figure(figsize=(12, 6))
    plt.plot(aapl_data, label='AAPL Price')
    plt.plot(ma_aapl, label='AAPL 20-day MA')
    plt.plot(rsi_aapl, label='AAPL RSI')
    plt.legend()
    plt.title('AAPL: Price, MA, RSI')
    plt.show()
    
    plt.figure(figsize=(12, 6))
    plt.plot(google_data, label='Google Price')
    plt.plot(ma_google, label='Google 20-day MA')
    plt.plot(rsi_google, label='Google RSI')
    plt.legend()
    plt.title('Google: Price, MA, RSI')
    plt.show()

if __name__ == '__main__':
    main()
```

- **图表绘制**：绘制股票价格、移动平均线和RSI的图表，帮助投资者识别趋势和超买超卖信号。
