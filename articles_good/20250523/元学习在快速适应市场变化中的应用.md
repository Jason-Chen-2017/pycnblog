### 3.2 元学习的数学模型
- 3.2.1 元学习的优化目标
  $$ \text{minimize}_{\theta} \mathbb{E}_{(x,y)} \mathcal{L}(f_\theta(x), y) $$
- 3.2.2 元学习的参数更新公式
  $$ \theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(f_\theta(x), y) $$

### 3.3 元学习的典型算法
- 3.3.1 Model-Agnostic Meta-Learning (MAML)
  - 算法步骤：
    1. 在支持集上进行内循环优化
    2. 在查询集上进行外循环优化
  - 代码实现：
    ```python
    def maml_update(params, inner_params, outer_params, learning_rate):
        # 内循环优化
        inner_optimizer = torch.optim.SGD(inner_params, lr=learning_rate)
        inner_optimizer.zero_grad()
        # 计算梯度并更新内参数
        inner_optimizer.step()
        # 外循环优化
        outer_optimizer = torch.optim.Adam(outer_params, lr=learning_rate)
        outer_optimizer.zero_grad()
        # 计算梯度并更新外参数
        outer_optimizer.step()
    ```
