- **5.2.1 数据处理代码**
```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('safety_data.csv')
# 数据清洗
data.dropna(inplace=True)
# 特征提取
features = data[['temperature', 'humidity', 'crime_rate']]
labels = data['risk_level']
```

- **5.2.2 预警模型实现**
```python
from sklearn.ensemble import RandomForestClassifier
from keras.models import Sequential
from keras.layers import LSTM, Dense

# 随机森林模型
rf_model = RandomForestClassifier()
rf_model.fit(features, labels)

# LSTM模型
model = Sequential()
model.add(LSTM(64, input_shape=(features.shape[1], 1)))
model.add(Dense(1))
model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
model.fit(features, labels, epochs=10, batch_size=32)
```

- **5.2.3 预警信息推送**

```python
import requests

def send_warning(level):
    payload = {'level': level}
    response = requests.post('http://localhost:8000/warning', json=payload)
    return response.status_code

send_warning(3)
```
