# 第1章 格雷厄姆投资理论概述

## 1.1 格雷厄姆投资理论的核心概念
### 1.1.1 价值投资的定义与核心思想
价值投资是一种以基本面分析为基础的投资策略，强调以低于内在价值的价格购买优质股票。格雷厄姆的价值投资理念强调安全边际、分散投资和长期持有的原则。

**关键概念对比表：**

| 格雷厄姆理念 | 传统量化指标 |
|-------------|---------------|
| 内在价值     | 市盈率 (P/E) |
| 安全边际     | 市净率 (P/B) |
| 股息率       | 股价波动率     |

### 1.1.2 格雷厄姆的安全边际理论
安全边际是指股票价格与内在价值之间的差距，用于降低投资风险。通过量化安全边际，投资者可以识别低估股票。

### 1.1.3 格雷厄姆的选股标准与策略
格雷厄姆推荐选择那些市盈率低、股息率高、财务状况稳健的公司。量化选股策略可以通过多因子模型实现。

# 第2章 量化投资策略的基础知识

## 2.1 量化投资的定义与特点
量化投资利用数学模型和算法进行投资决策，具有客观性、系统性和可重复性等特点。

### 2.1.1 常用数学模型
- 均值-方差模型：优化投资组合的收益与风险。
- CAPM 模型：评估资产的预期收益。

**CAPM 模型公式：**
$$ E(r_i) = r_f + \beta_i (E(r_m) - r_f) $$

## 2.2 量化投资的主要方法
### 2.2.1 基于因子的量化策略
利用因子模型（如 Fama-French 三因子模型）进行选股。

**Fama-French 三因子模型公式：**
$$ E(r_i) = \alpha + \beta_1 (SMB) + \beta_2 (HML) + \beta_3 (RMW) + \epsilon $$

### 2.2.2 基于算法的量化交易
高频交易和算法交易依赖复杂算法快速执行交易指令。

### 2.2.3 基于大数据的量化分析
利用大数据技术分析非传统数据（如社交媒体情绪）辅助投资决策。

# 第3章 格雷厄姆理论与量化指标的结合

## 3.1 格雷厄姆选股标准的量化指标
### 3.1.1 市盈率 (P/E) 的计算与应用
$$ P/E = \frac{\text{股价}}{\text{每股收益}} $$

### 3.1.2 市净率 (P/B) 的计算与应用
$$ P/B = \frac{\text{股价}}{\text{每股净资产}} $$

### 3.1.3 股息率的计算与应用
$$ 股息率 = \frac{\text{每股股息}}{\text{股价}} \times 100\% $$

## 3.2 格雷厄姆安全边际的量化评估
### 3.2.1 安全边际的定义与计算
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

### 3.2.2 安全边际在量化策略中的应用
通过筛选具有正安全边际的股票，构建价值投资组合。

## 3.3 基于格雷厄姆理论的多因子量化模型
### 3.3.1 多因子模型的定义与特点
多因子模型同时考虑多个因子（如价值、动量、质量等）进行选股。

### 3.3.2 格雷厄姆因子的引入与应用
将格雷厄姆的安全边际和价值因子纳入多因子模型，提升选股效果。

### 6.2.2 格雷厄姆选股策略代码
```python
def graham_strategy(data):
    # 计算 P/E 和 P/B
    data['PE'] = data['Price'] / data['EPS']
    data['PB'] = data['Price'] / data['BVPS']
    # 筛选 P/E 和 P/B 均低于行业平均的股票
    mean_pe = data['PE'].mean()
    mean_pb = data['PB'].mean()
    filtered = data[(data['PE'] < mean_pe) & (data['PB'] < mean_pb)]
    return filtered
```
