# 第一章：格雷厄姆特价股票策略概述

## 1.1 格雷厄姆投资理念的核心思想

### 1.1.1 价值投资的基本概念
价值投资是一种以股票的内在价值为导向的投资策略。格雷厄姆认为，股票的价格波动并不总能反映其真实的内在价值，市场短期可能疯狂，但长期会回归理性。

### 1.1.2 格雷厄姆的选股标准
格雷厄姆提出了一套严格的选股标准，包括：
1. **低市盈率（P/E）**：市盈率低于行业平均水平。
2. **低市净率（P/B）**：市净率低于行业平均水平。
3. **高股息率**：股息率高于行业平均水平。
4. **安全边际**：购买价格低于股票的内在价值。

### 1.1.3 特价股票的定义与特征
格雷厄姆定义的特价股票是指市场价格远低于其内在价值的股票。这类股票通常具有以下特征：
- 公司基本面稳健。
- 市场关注度低，信息不对称。
- 投资者情绪消极。

---

## 1.2 市场信息效率的基本概念

### 1.2.1 市场信息效率的定义
市场信息效率是指市场中信息的流动速度和传播范围。高效市场中，信息能够快速、充分地反映在股票价格中；低效市场中，信息传播缓慢，价格可能偏离实际价值。

### 1.2.2 不同市场信息效率的分类
1. **高效市场**：信息快速传播，价格反映所有可用信息。
2. **低效市场**：信息传播缓慢，价格反映部分信息。
3. **弱有效市场**：价格反映历史信息，但未来信息未被反映。

### 1.2.3 市场信息效率对股票定价的影响
在高效市场中，股票价格反映了所有相关信息，投资者难以通过分析获得超额收益。在低效市场中，信息不对称可能导致股票价格偏离其真实价值，为格雷厄姆策略提供了机会。

---

## 1.3 格雷厄姆策略与市场信息效率的关系

### 1.3.1 格雷厄姆策略在高效市场中的表现
在高效市场中，格雷厄姆策略的表现受限，因为股票价格已经反映了所有可用信息，难以找到市场价格低于内在价值的股票。

### 1.3.2 格雷厄姆策略在低效市场中的表现
在低效市场中，信息传播缓慢，股票价格可能低于其真实价值，格雷厄姆策略有机会找到被低估的股票。

### 1.3.3 市场信息效率对策略适用性的影响
市场信息效率越高，格雷厄姆策略的适用性越低；反之，市场信息效率越低，策略的适用性越强。

## 2.1 格雷厄姆安全边际理论

### 2.1.1 安全边际的定义
安全边际是指股票的市场价格与其内在价值之间的差距。格雷厄姆认为，购买价格低于内在价值时，投资具有安全边际。

### 2.1.2 安全边际的计算方法
安全边际 = 内在价值 - 市场价格

### 2.1.3 安全边际在选股中的应用
投资者应选择具有较大安全边际的股票，以降低投资风险。

### 4.1.1 筛选标准
1. 市盈率低于行业平均水平。
2. 市净率低于行业平均水平。
3. 股息率高于行业平均水平。

### 4.1.2 筛选流程
1. 收集目标行业股票数据。
2. 计算市盈率、市净率和股息率。
3. 筛选出满足标准的股票。

## 4.2 格雷厄姆策略的数学模型
### 4.2.1 安全边际公式
$$ \text{安全边际} = \text{内在价值} - \text{市场价格} $$

### 4.2.2 内在价值估算公式
$$ \text{内在价值} = \frac{\text{未来现金流}}{\text{折现率}} $$

## 4.3 算法实现
### 4.3.1 Python代码实现
```python
def calculate_pe(stock_price, net_income):
    return stock_price / net_income

def calculate_pb(stock_price, book_value):
    return stock_price / book_value
```

```python
def calculate_dividend_yield(dividend, price):
    return dividend / price

# 示例数据
data = {
    'stock_code': ['A', 'B', 'C'],
    'stock_price': [100, 80, 90],
    'net_income': [20, 15, 25],
    'book_value': [50, 40, 45],
    'dividend': [2, 1.5, 3]
}

df = pd.DataFrame(data)

# 计算指标
df['pe'] = df['stock_price'] / df['net_income']
df['pb'] = df['stock_price'] / df['book_value']
df['dividend_yield'] = df['dividend'] / df['stock_price']

print(df)
```

```python
def greaham_screen(stocks, industry_avg_pe, industry_avg_pb, industry_avg_dividend):
    selected_stocks = []
    for stock in stocks:
        if (stock['pe'] < industry_avg_pe) and \
           (stock['pb'] < industry_avg_pb) and \
           (stock['dividend_yield'] > industry_avg_dividend):
            selected_stocks.append(stock)
    return selected_stocks

# 示例数据
stocks = pd.DataFrame({
    'stock_code': ['A', 'B', 'C'],
    'pe': [10, 15, 8],
    'pb': [2, 3, 1.5],
    'dividend_yield': [5%, 3%, 6%]
})

industry_avg_pe = 12
industry_avg_pb = 2
industry_avg_dividend = 4%

selected = greaham_screen(stocks, industry_avg_pe, industry_avg_pb, industry_avg_dividend)
print(selected)
```
