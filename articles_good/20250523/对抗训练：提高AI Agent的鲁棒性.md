### 第2章: 对抗训练的核心原理

#### 2.1 对抗训练的基本原理

- **2.1.1 对抗训练的数学模型**
  - 生成器的目标是最小化判别器输出为假的概率。
  - 判别器的目标是最小化分类错误率。
  - 对抗训练的损失函数为：
    $$ \mathcal{L}_{\text{total}} = \mathcal{L}_G + \mathcal{L}_D $$
    其中，$\mathcal{L}_G$ 是生成器的损失，$\mathcal{L}_D$ 是判别器的损失。

- **2.1.2 对抗训练的目标函数**
  - 生成器的目标函数：
    $$ \mathcal{L}_G = -\mathbb{E}_{z}[ \log(D(G(z))) ] $$
    其中，$z$ 是生成器的输入，$D$ 是判别器，$G$ 是生成器。
  - 判别器的目标函数：
    $$ \mathcal{L}_D = -\mathbb{E}_{x}[ \log(D(x)) ] - \mathbb{E}_{z}[ \log(1 - D(G(z))) ] $$

- **2.1.3 对抗训练的优化过程**
  - 生成器和判别器交替优化，直到达到纳什均衡。
  - 使用梯度下降方法优化生成器和判别器的参数。

#### 2.2 对抗训练中的生成器与判别器

- **2.2.1 生成器的定义与作用**
  - 生成器通过给定的随机噪声，生成与真实数据分布相似的样本。
  - 生成器的目标是欺骗判别器，使其认为生成的样本是真实的。

- **2.2.2 判别器的定义与作用**
  - 判别器的目标是区分真实样本和生成样本。
  - 判别器的输出通常是一个概率值，表示样本是真实的概率。

- **2.2.3 生成器与判别器的博弈过程**
  - 初始阶段，生成器生成的样本质量较差，判别器能够轻松区分。
  - 随着训练的进行，生成器生成的样本质量逐步提高，判别器的区分能力也逐步增强。
  - 最终达到一个平衡点，生成器能够生成高质量的样本，判别器无法有效区分真实样本和生成样本。

#### 2.3 对抗训练的核心算法

- **2.3.1 GAN（生成对抗网络）的原理**
  - GAN由生成器和判别器组成，通过交替优化生成器和判别器的参数，使生成器生成的样本越来越逼真。

- **2.3.2 WGAN（Wasserstein GAN）的改进**
  - WGAN通过使用Wasserstein距离作为损失函数，避免了GAN训练中的模式崩溃问题。
  - WGAN的损失函数为：
    $$ \mathcal{L}_{\text{WGAN}} = \mathbb{E}_{x}[D(x)] - \mathbb{E}_{z}[D(G(z))] $$

- **2.3.3 其他对抗训练算法的概述**
  - Conditional GAN（cGAN）：条件生成对抗网络，生成条件的样本。
  - CycleGAN：通过循环结构生成跨领域样本。
  - DCGAN：使用深度卷积神经网络作为生成器和判别器。

import torch.nn as nn
import torch.optim as optim

class Generator(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(Generator, self).__init__()
        self.net = nn.Sequential(
            nn.ConvTranspose2d(input_size, hidden_size*2, kernel_size=4, stride=2, padding=1),
            nn.BatchNorm2d(hidden_size*2),
            nn.ReLU(True),
            nn.ConvTranspose2d(hidden_size*2, hidden_size, kernel_size=4, stride=2, padding=1),
            nn.BatchNorm2d(hidden_size),
            nn.ReLU(True),
            nn.ConvTranspose2d(hidden_size, output_size, kernel_size=4, stride=2, padding=1),
            nn.Tanh()
        )

    def forward(self, x):
        return self.net(x)

class Discriminator(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(Discriminator, self).__init__()
        self.net = nn.Sequential(
            nn.Conv2d(input_size, hidden_size, kernel_size=4, stride=2, padding=1),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(hidden_size, hidden_size*2, kernel_size=4, stride=2, padding=1),
            nn.BatchNorm2d(hidden_size*2),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(hidden_size*2, output_size, kernel_size=4, stride=2, padding=1),
            nn.Sigmoid()
        )

    def forward(self, x):
        return self.net(x)
