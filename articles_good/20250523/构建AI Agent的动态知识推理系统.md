- **3.1.2 基于图的推理算法**
  - 使用图遍历算法进行推理。
  - 示例：基于BFS的推理算法。
  ```python
  def bfs(start_node, target_node, graph):
      visited = set()
      queue = deque([start_node])
      visited.add(start_node)
      while queue:
          node = queue.popleft()
          if node == target_node:
              return True
          for neighbor in graph[node]:
              if neighbor not in visited:
                  visited.add(neighbor)
                  queue.append(neighbor)
      return False
  ```
