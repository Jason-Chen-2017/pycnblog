## 第6章 算法原理讲解

### 6.1 GAN模型的Mermaid流程图
```mermaid
graph LR
    GAN[生成对抗网络]
    GAN --> Generator[生成器]
    GAN --> Discriminator[判别器]
    Generator --> X[输入数据]
    Generator --> D_fake[生成数据]
    Discriminator --> D_real[真实数据]
    Discriminator --> D_fake[生成数据]
    Discriminator --> loss_G[生成器损失]
    Generator --> loss_D[判别器损失]
```

### 6.2 VAE模型的Mermaid流程图
```mermaid
graph LR
    VAE[变分自编码器]
    VAE --> Encoder[编码器]
    VAE --> Decoder[解码器]
    Encoder --> X[输入数据]
    Encoder --> Z[潜在空间]
    Z --> Decoder
    Decoder --> X'[重构数据]
```

### 6.3 图像生成模型的数学公式
- GAN损失函数：
  $$ \mathcal{L}_{\text{GAN}} = \mathcal{L}_\text{adv} + \mathcal{L}_\text{recon} $$
- VAE损失函数：
  $$ \mathcal{L}_{\text{VAE}} = \mathcal{L}_\text{recon} + KL(\mathbb{Q}(Z|X) || P(Z)) $$

import torch
import torch.nn as nn
import torch.optim as optim

class Generator(nn.Module):
    def __init__(self, latent_dim, img_size):
        super(Generator, self).__init__()
        self.latent_dim = latent_dim
        self.img_size = img_size
        self.model = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(256, 512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(512, img_size),
            nn.Tanh()
        )

    def forward(self, z):
        return self.model(z)

class Discriminator(nn.Module):
    def __init__(self, img_size):
        super(Discriminator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(img_size, 512),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )

    def forward(self, x):
        return self.model(x)

# 初始化模型和优化器

generator = Generator(latent_dim, img_size)
