## 第5章：跨代财富传承中的投资组合优化

### 5.1 投资组合优化的数学模型

#### 5.1.1 现代投资组合理论（MPT）的公式
$$ \text{最优权重} = \frac{\mu - r_f}{\sigma^2} $$
其中，$\mu$是资产的预期收益，$r_f$是无风险利率，$\sigma^2$是资产的波动率。

#### 5.1.2 资产分配的优化算法
$$ \text{风险调整后的收益} = E[r] - \lambda \sigma^2 $$
其中，$\lambda$是风险厌恶系数。

### 5.2 家庭股票在投资组合中的权重计算

#### 5.2.1 资产风险与收益的平衡
$$ \text{最优权重} = \frac{\text{收益权重}}{\text{风险权重}} $$

#### 5.2.2 股票收益与风险的量化分析
$$ \text{风险调整后的收益} = \text{收益} - \text{风险} \times \text{风险溢价} $$

#### 5.2.3 资产配置的动态调整
$$ \text{新权重} = \text{原权重} \times (1 + \text{调整系数}) $$

```python
import pandas as pd
import numpy as np

def select_family_stocks(stocks_df, target_sector):
    # 筛选目标行业的股票
    sector_mask = stocks_df['行业'] == target_sector
    # 筛选股息率高于平均的股票
    dividend_mask = stocks_df['股息率'] > stocks_df['股息率'].mean()
    # 筛选市盈率低于行业平均的股票
    pe_mask = stocks_df['市盈率'] < stocks_df['市盈率'].mean()
    # 返回满足条件的股票
    return stocks_df[sector_mask & dividend_mask & pe_mask]
```

import numpy as np
import matplotlib.pyplot as plt

def plot_efficient_frontier(expected_returns, cov_matrix, risk_free_rate):
    # 计算最优投资组合
    n = len(expected_returns)
    # 使用拉格朗日乘数法求解
    C = np.array(cov_matrix)
    inv_C = np.linalg.inv(C)
    mu = np.array(expected_returns)
    ones = np.ones(n)
    b1 = ones.T
    b2 = np.array([[1.0 for _ in range(n)]])
    B = np.concatenate([b1, b2])
    BT = B.T
    inv_BTB = np.linalg.inv(BT @ B)
    w = inv_BTB @ BT @ mu
    w = w[:-1]
