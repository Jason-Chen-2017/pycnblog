# 第1章: 格雷厄姆价值投资理论基础

## 1.1 价值投资的基本概念

### 1.1.1 价值投资的定义与核心理念
价值投资是一种以基本面分析为基础的投资策略，旨在通过识别市场低估的股票，实现长期稳定的收益。其核心理念是寻找市场价格低于其内在价值的股票。

$$
\text{内在价值} = \frac{\text{预期现金流的现值}}{\text{折现率}}
$$

### 1.1.2 格雷厄姆投资理论的起源与发展
格雷厄姆是价值投资的鼻祖，他在《证券分析》中提出了一系列选股标准，包括低市盈率、低市净率、股息率等。这些标准为后续的价值投资策略奠定了基础。

### 1.1.3 特价股票的定义与特点
特价股票是指市场价格显著低于其内在价值的股票。这类股票通常具有以下特点：
- 低市盈率（P/E ratio）
- 低市净率（P/B ratio）
- 高股息率（Dividend Yield）

---

## 1.2 格雷厄姆策略的核心要素

### 1.2.1 低市盈率策略
低市盈率策略的核心是寻找市场价格低于其未来现金流现值的股票。

$$
\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}
$$

### 1.2.2 低市净率策略
低市净率策略关注市场价格低于其账面价值的股票。

$$
\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}
$$

### 1.2.3 股息率与内在价值评估
股息率是衡量股票收益的重要指标，格雷厄姆建议选择股息率较高的股票。

$$
\text{股息率} = \frac{\text{股息/每股}}{\text{股价}}
$$

---

## 1.3 格雷厄姆策略的适用场景与限制

### 1.3.1 适用于市场低估的场景
当市场整体估值较低时，格雷厄姆策略表现较好。

### 1.3.2 策略在市场过热时的表现
在市场过热时，格雷厄姆策略可能表现不佳，因为市场价格可能被高估。

### 1.3.3 策略的局限性与改进方向
格雷厄姆策略主要适用于成熟市场，对新兴市场或高波动市场的适应性较低。

# 第4章: 格雷厄姆策略在不同监管市场中的实现算法

## 4.1 策略筛选算法的设计与实现

### 4.1.1 算法核心逻辑
格雷厄姆策略筛选算法的核心逻辑包括以下步骤：
1. 数据采集与清洗
2. 根据市盈率、市净率等指标筛选股票
3. 计算内在价值
4. 对比市场价格与内在价值，筛选出低估股票

### 4.1.2 算法实现的数学模型
$$
\text{筛选条件} = \begin{cases}
\text{P/E} < 15 \\
\text{P/B} < 2 \\
\text{Dividend Yield} > 3\%
\end{cases}
$$

### 4.1.3 算法实现的Python代码
```python
import pandas as pd
import yfinance as yf

# 数据采集
def get_stock_data(tickers):
    data = yf.download(tickers, start='2020-01-01', end='2023-12-31')
    return data['Adj Close']

# 筛选算法
def graham_screen(tickers, data):
    df = pd.DataFrame()
    df['Ticker'] = tickers
    df['Price'] = data.iloc[-1]
    df['PE'] = data['Adj Close'].pct_change() * 100
    df['PB'] = data['Adj Close'] / data['Book Value']
    df['Dividend Yield'] = data['Dividends'] / data['Adj Close']
    
    selected = df[(df['PE'] < 15) & (df['PB'] < 2) & (df['Dividend Yield'] > 0.03)]
    return selected

# 主程序
tickers = ['AAPL', 'MSFT', 'GOOGL']
data = get_stock_data(tickers)
result = graham_screen(tickers, data)
print(result)
```
