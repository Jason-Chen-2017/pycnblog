### 3.3 算法实现的数学模型与公式
- 3.3.1 机器学习模型的数学公式
  - 线性回归：$y = \beta_0 + \beta_1x + \epsilon$
  - 支持向量机：$\text{arg}\min_{\beta} \frac{1}{2}\beta^T\beta + C\sum_{i=1}^n \xi_i$
  - 神经网络：$a^{(l)} = \sigma(W^{(l)}a^{(l-1)} + b^{(l)})$

- 3.3.2 自然语言处理模型的数学公式
  - 词嵌入：$E(w) = \text{lookup}(w)$
  - 注意力机制：$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
  - 文本生成：$\log P(w_{1}w_{2}...w_{n}) = \sum_{i=1}^{n}\log P(w_i|w_{<i})$

- 3.3.3 图像识别模型的数学公式
  - 卷积操作：$f(x) = \sum_{i=1}^{k^2} w[i] \cdot x[i] + b$
  - 池化操作：$\text{max pooling}(x) = \max_{i \in \text{pool window}} x[i]$
  - 全连接层：$a = Wx + b$

import torch
import torch.nn as nn
import torch.nn.functional as F

# 示例模型：卷积神经网络
class ConvNet(nn.Module):
    def __init__(self):
        super(ConvNet, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, stride=1, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc = nn.Linear(32 * 7 * 7, 10)

    def forward(self, x):
        x = F.relu(self.conv1(x))
        x = self.pool(x)
        x = x.view(-1, 32 * 7 * 7)
        x = self.fc(x)
        return x

model = ConvNet()
