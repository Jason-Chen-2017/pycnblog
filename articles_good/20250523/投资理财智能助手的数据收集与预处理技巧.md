## 第3章: 数据收集与预处理的算法原理

### 3.1 数据清洗算法

#### 3.1.1 缺失值处理
- 删除法：直接删除有缺失值的样本
- 填充法：使用均值、中位数或特定值填充缺失值

#### 3.1.2 重复值处理
- 识别重复值
- 删除重复值

#### 3.1.3 异常值处理
- 统计方法：Z-score、IQR
- 机器学习方法：Isolation Forest

### 3.2 数据转换算法

#### 3.2.1 标准化与归一化
- 标准化公式：
$$ x_{标准化} = \frac{x - \mu}{\sigma} $$
- 归一化公式：
$$ x_{归一化} = \frac{x - x_{min}}{x_{max} - x_{min}} $$

#### 3.2.2 特征编码
- 独热编码：将分类变量转换为二进制向量
- 标签编码：将分类变量映射为整数

#### 3.2.3 时间序列数据处理
- 数据平滑：移动平均、指数平滑
- 数据分解：趋势、季节性、噪声

### 3.3 数据增强算法

#### 3.3.1 数据增强的基本原理
通过生成新的数据样本，增加数据多样性，提高模型泛化能力。

#### 3.3.2 基于机器学习的增强方法
- 数据扩展：使用数据增强库（如Keras ImageDataGenerator）
- 数据模拟：生成合成数据

import pandas as pd
import numpy as np

# 数据清洗
def clean_data(df):
    # 删除重复值
    df.drop_duplicates(inplace=True)
    # 填充缺失值
    df.fillna(df.mean(), inplace=True)
    # 删除异常值
    df = df[(np.abs(df - df.mean()) <= 3 * df.std())]
    return df

# 数据转换
def preprocess_data(df):
    # 标准化处理
    from sklearn.preprocessing import StandardScaler
    scaler = StandardScaler()
    df_scaled = pd.DataFrame(scaler.fit_transform(df), columns=df.columns)
    return df_scaled

# 数据增强

    return X_train, y_train
