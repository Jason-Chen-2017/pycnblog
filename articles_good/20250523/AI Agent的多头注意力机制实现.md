## 第二部分：多头注意力机制的核心概念与联系

### 第4章：多头注意力机制的原理

#### 4.1 多头注意力机制的数学模型
  - 4.1.1 查询、键、值的计算：
    - 查询：Q = W_q * x
    - 键：K = W_k * x
    - 值：V = W_v * x
  - 4.1.2 缩放与Softmax操作：
    - 缩放：score = QK^T / sqrt(d_k)
    - Softmax：alpha = softmax(score)
  - 4.1.3 加权求和：输出 = alpha * V

#### 4.2 多头机制的实现步骤
  - 1. 分解查询、键、值到多个子空间。
  - 2. 计算每个子空间的注意力权重。
  - 3. 合并所有子空间的输出，得到最终结果。

## 第四部分：项目实战与优化

### 第8章：项目实战

#### 8.1 环境安装

#### 8.2 核心代码实现
  - 8.2.1 多头注意力机制实现：
  ```python
  import numpy as np

  def multi_head_attention(query, key, value, num_heads):
      d_k = query.shape[-1] // num_heads
      query = query.reshape(-1, num_heads, d_k)
      key = key.reshape(-1, num_heads, d_k)
      value = value.reshape(-1, num_heads, d_k)
      
      scores = np.einsum('...,k,d -> ...,k,d', query, key)
      scores = scores / np.sqrt(d_k)
      alpha = np.softmax(scores, axis=-1)
      
      output = np.einsum('...,k,d,k -> ...,d', alpha, value)
      return output.reshape(-1, num_heads * d_k)
  ```
