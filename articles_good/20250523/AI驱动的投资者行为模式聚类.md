# 第4章: 投资者行为模式聚类的算法原理与实现

## 4.1 聚类算法

### 4.1.1 K-means算法

**步骤**：
1. **初始化**：随机选择k个质心。
2. **分配**：将每个数据点分配到最近的质心。
3. **更新**：重新计算质心。
4. **收敛**：直到质心不再变化或达到最大迭代次数。

**公式**：
$$ \text{距离} = \sqrt{(x_i - c_j)^2 + (y_i - c_j)^2} $$

---

## 4.2 层次聚类

**步骤**：
1. **初始化**：将每个数据点视为一个簇。
2. **合并**：根据相似度矩阵，合并最接近的两个簇。
3. **迭代**：重复合并直到所有数据点合并为一个簇。

**公式**：
$$ \text{相似度} = \frac{1}{n} \sum_{i=1}^{n} (x_i - \mu)^2 $$

---

## 4.3 DBSCAN算法

**步骤**：
1. **邻域搜索**：找到每个点的邻域点。
2. **密度聚类**：将密度足够高的区域划分为簇。
3. **噪声处理**：排除孤立点。

---

## 4.4 聚类算法的实现

### 4.4.1 K-means算法实现

```python
from sklearn.cluster import KMeans

# 初始化模型

# 训练模型

# 获取聚类结果
labels = kmeans.labels_
```

### 5.2.3 模型训练与优化

```python
# 确定最优聚类数
from sklearn.metrics import silhouette_score
import numpy as np

max_silhouette = 0
best_k = 1

for k in range(2, 11):
    kmeans = KMeans(n_clusters=k)
    labels = kmeans.fit_predict(X_pca)
    score = silhouette_score(X_pca, labels)
    if score > max_silhouette:
        max_silhouette = score
        best_k = k

print(f"最优聚类数：{best_k}")
```
