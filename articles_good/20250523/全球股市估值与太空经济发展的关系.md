- 使用 Python 实现回归分析模型的代码示例：

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 数据加载与预处理
data = pd.read_csv('stock_space.csv')
features = data[['P/E', 'P/B', 'market_cap']]
target = data['space_investment']

# 模型训练
model = LinearRegression()
model.fit(features, target)

# 模型预测与评估
predictions = model.predict(features)
print("R² Score:", r2_score(target, predictions))
```

#### 3.3 算法数学模型
- 使用 LaTeX 格式公式，展示回归分析的数学模型：

$$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \epsilon $$

其中：
- $y$ 是目标变量（如股市估值）。
- $x_1, x_2$ 是自变量（如 P/E、P/B）。
- $\beta_0, \beta_1, \beta_2$ 是回归系数。
- $\epsilon$ 是误差项。
