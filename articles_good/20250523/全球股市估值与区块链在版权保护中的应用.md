# 第1章: 全球股市估值概述

## 1.1 股市估值的定义与重要性

### 1.1.1 股市估值的基本概念  
股市估值是通过对公司财务数据和市场因素的分析，评估其股票的内在价值。常见的估值指标包括市盈率（P/E）、市净率（P/B）和股息率等。  

$$\text{市盈率（P/E）} = \frac{\text{股票价格}}{\text{每股净利润}}$$  
$$\text{市净率（P/B）} = \frac{\text{股票价格}}{\text{每股净资产}}$$  

### 1.1.2 股市估值在投资决策中的作用  
股市估值为投资者提供参考，帮助判断股票是否被高估或低估。例如，若一只股票的P/E比行业平均水平高，可能意味着其股价被高估。  

### 1.1.3 全球化视角下的股市估值特点  
全球股市估值受宏观经济、行业趋势和地缘政治等多种因素影响。不同市场的估值指标差异反映了其经济结构和投资者偏好。

## 1.2 股市估值的主要方法

### 1.2.1 市盈率（P/E）分析  
市盈率反映了市场对公司未来盈利能力的预期。例如，若某公司净利润为100万元，股价为500万元，则P/E为5。  

### 1.2.2 市净率（P/B）分析  
市净率适用于重资产行业。若某公司净资产为200万元，股价为400万元，则P/B为2。  

### 1.2.3 股息率与股息贴现模型（DDM）  
股息率 = （年股息/股票价格）× 100%。股息贴现模型通过预测未来股息的现值来评估股票价值。  

### 1.2.4 企业价值倍数（EV/EBITDA）分析  
EV/EBITDA = （企业价值）/ （息税折旧及摊销前利润）。该指标适用于跨市场比较。

# 第2章: 区块链技术基础

## 2.1 区块链的基本概念

### 2.1.1 区块链的定义与特点  
区块链是一种分布式账本技术，具有去中心化、不可篡改和透明性等特点。其核心在于通过共识机制维护数据完整性。

### 2.1.2 区块链的核心技术原理  
区块链由区块、链、节点、共识机制和智能合约组成。数据以区块形式存储，通过哈希指针链接形成链式结构。

### 2.1.3 区块链的分类与应用场景  
区块链分为公链、私链和联盟链，应用于金融、版权保护、供应链等领域。

## 2.2 区块链的共识机制

### 2.2.1 工作量证明（PoW）  
PoW通过计算哈希值竞争记账权，安全性高但效率低。

### 2.2.2 权益证明（PoS）  
PoS通过持有代币数量分配记账权，节能环保但可能面临“富者愈富”的问题。

### 2.2.3 股权证明（POS）与 delegated PoS  
POS和dPoS通过选举或委托方式分配记账权，兼顾效率与公平。

### 2.2.4 共识机制的优缺点对比  
| 共识机制 | 优点 | 缺点 |
|----------|------|------|
| PoW     | 安全性高 | 效率低 |
| PoS     | 节能环保 | 存在“富者愈富”风险 |
| POS/dPoS | 效率高 | 安全性较低 |

# 第3章: 区块链在版权保护中的应用

## 3.1 版权保护的痛点与挑战

### 3.1.1 版权保护的法律框架  
版权保护涉及《伯尔尼公约》等国际法律，但在数字化时代面临执行难题。

### 3.1.2 数字版权保护的技术难点  
数字内容易被复制和篡改，传统中心化存储方式存在信任问题。

### 3.1.3 现有版权保护体系的局限性  
传统体系依赖中心机构，存在效率低、成本高、难以追踪等问题。

## 3.2 区块链在版权保护中的优势

### 3.2.1 不可篡改性与透明性  
区块链记录每一步操作，确保内容创作时间、作者身份等信息不可篡改。

### 3.2.2 去中心化与分布式存储  
通过分布式账本，避免单点故障，提升数据安全性。

### 3.2.3 智能合约的应用潜力  
智能合约自动执行版权交易和 royalties 分配，降低信任成本。
