### 第2章：固定收益策略的核心概念与联系

#### 2.1 固定收益策略的定义与特点

- **2.1.1 固定收益策略的定义**
  - 通过投资固定收益产品实现稳定收益的策略。

- **2.1.2 固定收益策略的核心要素**
  - 利率预测、信用分析、久期管理。

- **2.1.3 固定收益策略与权益投资的区别**
  - 收益来源不同。
  - 风险特征不同。

#### 2.2 固定收益策略的分类与对比

- **2.2.1 利率策略与信用策略的对比**
  - 利率策略关注市场利率变化。
  - 信用策略关注信用风险。

- **2.2.2 短期策略与长期策略的差异**
  - 短期策略注重流动性管理。
  - 长期策略注重收益最大化。

- **2.2.3 主动管理与被动管理的优劣势**
  - 主动管理灵活性强但成本高。
  - 被动管理风险分散但收益稳定。

#### 2.3 固定收益策略的数学模型与公式

- **2.3.1 利率模型的数学表达**
  - 利率预测模型：
  $$i_t = \alpha + \beta i_{t-1} + \epsilon_t$$

- **2.3.2 债券定价公式**
  - 债券价格计算：
  $$P = \sum_{t=1}^{n} \frac{C}{(1 + y)^t} + \frac{F}{(1 + y)^n}$$

- **2.3.3 久期与凸性的计算公式**
  - 久期：
  $$Duration = \frac{1}{(1 + y)} \frac{\partial P}{\partial y}$$
  - 凸性：
  $$Convexity = \frac{1}{(1 + y)^2} \frac{\partial^2 P}{\partial y^2}$$

#### 5.2 系统核心实现源代码

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

# 示例：计算债券久期
def calculate_duration(y, c, f, n):
    duration = 0
    for t in range(1, n+1):
        duration += (c / (1 + y)**t) * t
    duration += f * n / (1 + y)**n
    duration = duration / (c * (1 - (1 + y)**-n))
    return duration

# 示例：计算凸性
def calculate_convexity(y, c, f, n):
    convexity = 0
    for t in range(1, n+1):
        convexity += (c / (1 + y)**t) * t * (t + 1) / 2
    convexity += f * n * (n + 1) / (2 * (1 + y)**n)
    convexity = convexity / (c * (1 - (1 + y)**-n))
    return convexity

# 示例：利率预测模型
def interest_rate_forecast(history_rates):
    # 使用简单线性回归预测
    t = np.arange(len(history_rates))
    slope = np.polyfit(t, history_rates, 1)
    return slope[0] * t + slope[1]

# 主程序
if __name__ == "__main__":
    y = 0.02  # 假设年化收益率为2%
    c = 100    # 每期利息
    f = 1000   # 面值
    n = 10     # 剩余期限
    print("久期:", calculate_duration(y, c, f, n))
    print("凸性:", calculate_convexity(y, c, f, n))
    history_rates = [2%, 2.5%, 3%, 3.5%]  # 历史利率
    forecast = interest_rate_forecast(history_rates)
    print("预测利率:", forecast)
```
