### 注意力机制基础

注意力机制（Attention Mechanism）是深度学习中的一个核心概念，起源于人类视觉系统和语言处理机制的自然观察。其基本思想是在处理序列数据时，通过动态调整不同部分的重要性，从而提高模型对关键信息的聚焦能力。

#### 定义与原理

注意力机制的定义可以理解为：在神经网络处理序列数据时，为每个输入序列元素分配一个权重，使得模型能够根据这些权重更有效地关注最有价值的部分。这个权重分配过程通常是一个可学习的参数，通过训练自动优化。

注意力机制的原理可以概括为以下几个步骤：

1. **编码器**：首先，对输入序列进行编码，生成固定长度的特征向量。
2. **注意力得分计算**：计算每个输入元素与目标元素之间的相似性得分，这个得分通常是通过一个计算复杂度较低的函数（如点积或加性模型）得到的。
3. **权重分配**：将得到的得分转换为权重，用于加权求和输入序列中的每个元素。
4. **解码器**：使用加权后的特征向量生成输出结果。

这种机制允许模型在处理长序列时，动态地调整其关注点，从而避免了对整个序列进行全局处理的低效问题。

#### 数学模型

注意力机制的数学模型通常包含以下几个关键组成部分：

1. **查询（Query）**：表示需要关注的元素，通常是模型的输出或当前状态。
2. **键（Key）**：表示序列中的每个元素，用于与查询进行匹配。
3. **值（Value）**：表示序列中的每个元素，用于输出结果的加权求和。

数学上，注意力机制可以表示为：

$$
\text{Attention}(\text{Query}, \text{Keys}, \text{Values}) = \text{softmax}(\text{Score}) \times \text{Values}
$$

其中，**Score** 是通过查询和键之间的相似性计算得到的，通常采用点积形式：

$$
\text{Score} = \text{Query} \cdot \text{Key}
$$

这种计算方式使得注意力机制在计算复杂度上具有优势，因为它可以通过并行计算来加速处理。

#### 工作流程

注意力机制的工作流程大致如下：

1. **输入编码**：首先，将输入序列编码为特征向量，这些特征向量将作为键和值。
2. **计算注意力得分**：通过计算查询与键之间的点积，得到注意力得分。
3. **应用Softmax函数**：将得分通过Softmax函数转换为概率分布，表示每个输入元素的重要性。
4. **加权求和**：使用概率分布加权求和值向量，生成最终的输出。

这种流程使得模型在处理序列数据时，能够自动学习到不同部分的重要性和相关性，从而提高模型的表示能力和预测效果。

#### 实现与优点

在实现方面，注意力机制通常通过以下几个步骤进行：

1. **编码器**：使用循环神经网络（RNN）或变换器（Transformer）等架构来编码输入序列。
2. **注意力机制**：在编码器的输出上应用注意力机制，通过点积或加性模型计算得分和权重。
3. **解码器**：使用加权求和后的特征向量作为输入，生成输出结果。

注意力机制的优点包括：

- **高效性**：通过动态调整关注点，模型能够更高效地处理长序列数据。
- **灵活性**：注意力机制可以应用于各种类型的任务和数据，具有较强的通用性。
- **可解释性**：注意力权重提供了模型决策过程的透明度，有助于理解模型的关注点。

总之，注意力机制作为一种强大的深度学习技术，不仅提高了模型的性能和表示能力，还为跨模态学习提供了关键的技术支持。

### 跨模态学习基础

跨模态学习（Cross-Modal Learning）是指处理和融合来自多个模态的数据，如文本、图像、音频等，以实现更全面和精准的语义理解。随着人工智能技术的不断发展，跨模态学习在多个领域展现出巨大的潜力和应用价值。

#### 定义与类型

跨模态学习可以简单定义为：从多个模态中提取信息，并将这些信息融合在一起，以实现单一模态学习无法达到的效果。跨模态学习的类型通常根据任务目标和数据来源的不同进行分类：

1. **文本到图像**（Text-to-Image）：给定一段文本描述，生成相应的图像。
2. **图像到文本**（Image-to-Text）：给定一张图像，生成描述图像的文本。
3. **文本到语音**（Text-to-Speech）：将文本转换为可听的语音。
4. **语音到文本**（Speech-to-Text）：将语音转换为文本。
5. **多模态融合**（Multimodal Fusion）：同时处理和融合多种模态的数据，如文本、图像、语音等，以实现更复杂的任务。

#### 挑战与机遇

跨模态学习面临诸多挑战，包括：

1. **模态差异**：不同模态的数据在维度、特征表达和结构上存在显著差异，如何有效融合这些信息是一个关键问题。
2. **数据稀缺**：高质量的跨模态数据集相对稀缺，数据不足会影响模型的训练效果和泛化能力。
3. **计算复杂度**：跨模态学习任务通常涉及复杂的模型和算法，计算资源需求较高。
4. **解释性**：跨模态学习模型的决策过程通常较为复杂，难以解释和验证。

尽管如此，跨模态学习也带来了许多机遇：

1. **多模态融合**：通过融合多种模态的数据，可以实现更全面和精确的语义理解，提高任务性能。
2. **人机交互**：跨模态学习技术可以增强人机交互体验，如语音识别、图像生成等。
3. **多领域应用**：跨模态学习在医疗、教育、娱乐等多个领域都有广泛的应用前景。

#### 常见方法

跨模态学习的方法主要包括以下几类：

1. **基于传统机器学习的方法**：如支持向量机（SVM）、决策树等，通过特征工程和特征匹配实现跨模态数据的融合。
2. **基于深度学习的方法**：如卷积神经网络（CNN）、循环神经网络（RNN）、变换器（Transformer）等，通过模型架构和端到端训练实现跨模态数据的处理和融合。
3. **基于对抗生成网络的方法**：如生成对抗网络（GAN），通过生成对抗训练实现跨模态数据的生成和转换。

#### 评估指标

评估跨模态学习模型的性能通常需要使用多个评估指标，这些指标可以分为以下几类：

1. **分类指标**：如准确率（Accuracy）、精确率（Precision）、召回率（Recall）和F1值（F1 Score），用于评估模型在分类任务中的表现。
2. **回归指标**：如均方误差（Mean Squared Error, MSE）和平均绝对误差（Mean Absolute Error, MAE），用于评估模型在回归任务中的表现。
3. **多模态一致性**：如多模态匹配度（Cross-Modal Consistency），用于评估不同模态之间的融合效果。
4. **用户满意度**：在实际应用中，用户对系统表现的满意度也是一个重要的评估指标。

通过结合上述方法和技术，跨模态学习在多个领域取得了显著的成果，为人工智能技术的发展开辟了新的路径。

### 大型语言模型（LLM）基础

大型语言模型（Large Language Model，简称LLM）是近年来人工智能领域的一个重要突破。LLM通过使用海量的文本数据进行训练，能够自动地学习语言的深层结构和规律，从而在文本生成、理解、翻译、问答等多个任务中展现出卓越的性能。

#### 定义与特点

LLM是一种基于深度学习技术的语言处理模型，通过学习大规模的文本数据，生成对语言结构、语义和上下文有深刻理解的模型。其定义可以概括为：一个能够理解和生成自然语言的深度神经网络模型，通常具有以下特点：

1. **大规模训练数据**：LLM使用数十亿甚至数千亿个句子进行训练，这使得模型能够捕捉到语言中的细微差异和复杂模式。
2. **强大的语言理解能力**：LLM不仅能够生成符合语法和语义规则的文本，还能理解复杂句子和长文本的深层含义。
3. **自适应学习能力**：LLM具有强大的自适应学习能力，能够在不同的任务和应用场景中快速调整和优化模型。

#### 训练与优化

LLM的训练过程可以分为以下几个主要步骤：

1. **数据预处理**：首先，对大规模的文本数据进行清洗、分词和标记等预处理操作，将其转化为模型可以处理的格式。
2. **构建词嵌入**：使用词嵌入技术将词汇映射到高维向量空间，这一步骤有助于模型理解词汇之间的语义关系。
3. **训练模型**：通过梯度下降等优化算法，训练深度神经网络模型，使其能够对输入文本进行编码和解码。
4. **超参数调整**：在训练过程中，调整学习率、批量大小等超参数，以优化模型的性能和收敛速度。

在优化方面，LLM通常采用以下几种方法：

1. **多层神经网络**：使用多层神经网络（如Transformer）来提高模型的表示能力和泛化能力。
2. **预训练与微调**：首先在大量的文本数据上进行预训练，然后针对具体任务进行微调，以提高模型的特定任务性能。
3. **正则化和dropout**：使用正则化技术和dropout来防止过拟合，提高模型的泛化能力。

#### 评测方法

LLM的评测方法主要包括以下几个方面：

1. **自动评测**：使用自动化评测工具，如BLEU、ROUGE、METEOR等，评估模型在生成文本的质量和一致性。
2. **人工评测**：通过人工阅读和评估模型生成的文本，评估其可读性、连贯性和准确性。
3. **任务性能评测**：在不同任务上评估LLM的性能，如文本生成、问答、翻译等，以综合评价其表现。

#### 应用场景

LLM在多个领域和应用场景中发挥了重要作用，包括：

1. **自然语言处理**：如文本生成、文本分类、情感分析、命名实体识别等。
2. **对话系统**：如聊天机器人、语音助手等，为用户提供自然、流畅的交互体验。
3. **内容审核**：通过检测和过滤不当内容，确保网络环境的健康和安全。
4. **教育**：如智能辅导系统、自动作文批改等，提高教学效率和个性化学习体验。

通过深入研究和应用LLM，我们能够更好地理解和利用语言数据，推动人工智能技术的发展。

### 注意力机制在LLM评测中的应用

注意力机制（Attention Mechanism）在大型语言模型（LLM）评测中发挥着至关重要的作用。它不仅能够提高模型对关键信息的处理能力，还能显著提升模型的评测效果和性能。以下是注意力机制在LLM评测中的具体应用和实现方式。

#### 注意力机制的作用

注意力机制的核心作用在于模型在处理输入序列时，能够动态地调整不同部分的重要性，使得模型能够更加聚焦于最有价值的部分。在LLM评测中，注意力机制能够实现以下几个关键作用：

1. **提高序列处理效率**：对于长文本或长句子，注意力机制可以帮助模型高效地聚焦于关键信息，避免对整个序列进行低效的全局处理。
2. **增强语义理解**：注意力机制能够帮助模型更好地捕捉文本中的上下文关系和语义信息，从而提高模型的语义理解能力。
3. **提高评测准确性**：通过动态调整不同部分的权重，注意力机制能够使得模型在评测任务中更准确地识别和分类文本内容。

#### 注意力机制在LLM评测中的实现

在LLM评测中，注意力机制可以通过多种方式实现，以下是几种常见的方法：

1. **Transformer架构**：Transformer是当前最流行的注意力机制实现方式之一，它通过自注意力（Self-Attention）和交叉注意力（Cross-Attention）机制，实现了对输入序列的全面理解和处理。在Transformer架构中，编码器和解码器分别使用自注意力和交叉注意力来提取和生成序列特征，从而实现高效的文本处理和评测。

2. **点积注意力模型**：点积注意力是一种简单而有效的注意力计算方式，通过计算查询（Query）和键（Key）之间的点积得到注意力得分，然后应用Softmax函数生成权重。点积注意力模型在许多自然语言处理任务中取得了显著的性能提升，特别是在文本分类、情感分析等评测任务中。

3. **加性注意力模型**：加性注意力通过将查询和键通过一个可学习的权重矩阵进行加权求和，然后计算点积得到注意力得分。加性注意力在计算上比点积注意力更为简单，同时保持了较好的性能，常用于一些需要高效计算的场景。

#### 注意力机制的优势

注意力机制在LLM评测中的优势主要体现在以下几个方面：

1. **高效性**：注意力机制能够通过并行计算提高处理效率，特别是在处理长序列时，显著减少了计算复杂度。
2. **灵活性**：注意力机制可以应用于各种类型的任务和数据，具有较强的通用性和适应性。
3. **可解释性**：注意力机制通过权重分配提供了模型决策过程的透明度，有助于理解和解释模型的行为和结果。

#### 注意力机制面临的挑战

尽管注意力机制在LLM评测中展现了强大的性能，但它也面临着一些挑战：

1. **计算复杂度**：注意力机制的计算复杂度较高，尤其是在大规模数据集上训练时，对计算资源和时间的要求较高。
2. **训练难度**：注意力机制需要大量的数据和高精度的标签进行训练，数据稀缺和标签错误会影响模型的性能和稳定性。
3. **模型解释性**：虽然注意力机制提供了模型关注的透明度，但有时难以直观地理解其决策过程，特别是在复杂的跨模态任务中。

综上所述，注意力机制在LLM评测中的应用不仅显著提升了模型的性能和效率，还带来了新的研究挑战。通过不断优化和改进注意力机制，我们有望在LLM评测中实现更准确、高效和可解释的模型。

### 跨模态LLM评测方法

在跨模态学习领域中，评测方法的合理性和有效性直接影响模型性能的评估和优化。针对跨模态LLM（Large Language Model）评测，我们主要关注分类、语义理解、情感分析等任务，并介绍几种常见的评测方法和评估指标。

#### 分类任务

分类任务是跨模态LLM评测中的基础，常见的评估指标包括准确率（Accuracy）、精确率（Precision）、召回率（Recall）和F1值（F1 Score）。

1. **准确率**：准确率表示模型正确分类的样本占总样本的比例，是评估分类任务最直观的指标。
   
   $$\text{Accuracy} = \frac{\text{正确分类的样本数}}{\text{总样本数}}$$

2. **精确率**：精确率表示被分类为正类的样本中实际为正类的比例，反映模型在正类上的准确性。
   
   $$\text{Precision} = \frac{\text{正确分类的正类样本数}}{\text{分类为正类的样本总数}}$$

3. **召回率**：召回率表示实际为正类的样本中被正确分类的比例，反映模型在负类上的准确性。
   
   $$\text{Recall} = \frac{\text{正确分类的正类样本数}}{\text{实际为正类的样本总数}}$$

4. **F1值**：F1值是精确率和召回率的调和平均值，用于综合评估分类任务的表现。
   
   $$\text{F1 Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$

在实际应用中，我们通常根据任务的特性和需求，选择合适的评估指标。例如，在医学诊断任务中，召回率尤为重要，因为漏诊可能带来严重的后果；而在垃圾邮件分类任务中，精确率可能更为关键，以减少误分类带来的用户困扰。

#### 语义理解任务

语义理解任务是评估模型对文本和图像、音频等多模态数据语义表示的一致性和准确性的关键任务。常见的评估方法包括：

1. **多模态一致性评估**：通过计算文本和图像、音频等模态的特征向量之间的相似性来评估模型的表现。常用的方法包括余弦相似度、欧氏距离等。

2. **信息增益评估**：通过计算文本和图像、音频等模态的信息增益来评估模型的表现。信息增益越大，表示模型对模态数据的理解越深刻。

3. **语义匹配评估**：通过评估文本和图像、音频等模态之间的语义匹配程度来评估模型的表现。常用的方法包括基于语义嵌入的相似性计算和基于知识图谱的语义匹配。

#### 情感分析任务

情感分析任务是评估模型对文本情感的识别和分类能力。常见的评估方法包括：

1. **情感分类准确率**：通过计算模型正确分类的情感类别占总类别数的比例来评估模型表现。

2. **情感极性分类准确率**：通过计算模型正确分类为积极、消极情感的比例来评估模型表现。

3. **情感强度分类准确率**：通过计算模型对情感强度（如非常积极、积极、一般、消极、非常消极）分类的准确性来评估模型表现。

#### 跨模态融合评估

跨模态融合评估是评估模型在多个模态数据融合后的整体性能。常见的评估方法包括：

1. **多模态一致度评估**：通过计算模型对多个模态数据融合后的一致性程度来评估模型表现。一致性越高，表示模型对多模态数据的理解越准确。

2. **多模态特征贡献度评估**：通过计算不同模态数据对最终融合特征向量的贡献度来评估模型的表现。贡献度越高，表示该模态数据对模型的最终决策影响越大。

3. **多模态融合性能评估**：通过综合评估模型在多个模态数据融合后的整体性能，如准确率、召回率、F1值等，来评估模型的表现。

综上所述，跨模态LLM评测方法涵盖了分类、语义理解、情感分析等多个方面，每种方法都有其特定的评估指标和应用场景。通过合理选择和组合这些方法，我们可以全面评估跨模态LLM的性能和效果。

```python
model.eval()

preprocess = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

def extract_image_features(image_path):
    image = Image.open(image_path).convert('RGB')
    image_tensor = preprocess(image)
    features = model(image_tensor.unsqueeze(0)) # 输入模型进行特征提取
    return features[:, 0, :, :] # 返回特征向量
```

##### 2. 文本生成

使用预训练的语言模型（如GPT-2）生成图像描述。

```python
from transformers import GPT2Model, GPT2Tokenizer

# 加载预训练的GPT-2模型和分词器
model = GPT2Model.from_pretrained('gpt2')
tokenizer = GPT2Tokenizer.from_pretrained('gpt2')

def generate_image_description(features, prompt='Describe this image: '):
    input_ids = tokenizer.encode(prompt, return_tensors='pt')
    input_ids = torch.cat((input_ids, features.unsqueeze(0)), dim=1)
    
    with torch.no_grad():
        outputs = model(input_ids)
    logits = outputs.logits[:, input_ids.shape[-1]:]
    
    prediction = logits.argmax(-1).item() # 选择最可能的输出
    description = tokenizer.decode(prediction, skip_special_tokens=True)
    return description
```

```python
from torchvision import datasets
from torch import nn, optim

val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)

# 定义损失函数和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 模型训练
for epoch in range(10): # 训练10个epoch
    model.train()
    for images, captions in train_loader:
        features = extract_image_features(images)
        captions = tokenizer.encode(captions, return_tensors='pt')
        
        optimizer.zero_grad()
        outputs = model(input_ids=captions)
        loss = criterion(outputs.logits.view(-1, outputs.logits.size(-1)), captions.view(-1))
        loss.backward()
        optimizer.step()

# 模型评测
model.eval()
with torch.no_grad():
    correct = 0
    total = 0
    for images, captions in val_loader:
        features = extract_image_features(images)
        captions = tokenizer.encode(captions, return_tensors='pt')
        
        outputs = model(input_ids=captions)
        _, predicted = torch.max(outputs.logits.view(-1, outputs.logits.size(-1)), dim=1)
        total += captions.size(1)
        correct += (predicted == captions.view(-1)).sum().item()

accuracy = 100 * correct / total
print(f'Validation Accuracy: {accuracy:.2f}%')
```

#### 原理

注意力机制的基本思想是动态调整输入序列中不同部分的重要性，使得模型能够关注到最有价值的部分。这种机制可以理解为一种“注意力分配”的过程，通过为输入序列中的每个元素分配一个权重，从而实现数据的筛选和聚焦。

#### 数学模型

注意力机制的数学模型主要包括三个关键部分：查询（Query）、键（Key）和值（Value）。以下是注意力机制的核心数学模型：

1. **查询（Query）**：表示需要关注的元素，通常是模型的输出或当前状态。
2. **键（Key）**：表示序列中的每个元素，用于与查询进行匹配。
3. **值（Value）**：表示序列中的每个元素，用于输出结果的加权求和。

注意力机制的计算步骤如下：

1. **计算注意力得分**：通过计算查询与键之间的相似性得分，得到注意力权重。常见的计算方式包括点积、加性模型和多头注意力。
   
   $$\text{Score} = \text{Query} \cdot \text{Key}$$
   
2. **应用Softmax函数**：将得分通过Softmax函数转换为概率分布，表示每个输入元素的重要性。
   
   $$\text{Attention}(\text{Query}, \text{Keys}, \text{Values}) = \text{softmax}(\text{Score}) \times \text{Values}$$
   
3. **加权求和**：使用概率分布加权求和值向量，生成最终的输出。

#### 实现与具体步骤

以下是一个简单的注意力机制实现，使用Python和PyTorch框架：

```python
import torch
import torch.nn as nn

class Attention(nn.Module):
    def __init__(self, d_model, num_heads):
        super(Attention, self).__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        
        self.query_linear = nn.Linear(d_model, d_model)
        self.key_linear = nn.Linear(d_model, d_model)
        self.value_linear = nn.Linear(d_model, d_model)
        
        self.out_linear = nn.Linear(d_model, d_model)
    
    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)
        
        # 计算键和值
        key = self.key_linear(key).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        value = self.value_linear(value).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        
        # 计算查询
        query = self.query_linear(query).view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        
        # 计算注意力得分
        scores = torch.matmul(query, key) / (self.head_dim ** 0.5)
        
        # 应用掩码
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float("-inf"))
        
        # 应用Softmax函数
        attention_weights = torch.softmax(scores, dim=2)
        
        # 加权求和
        attention_output = torch.matmul(attention_weights, value).transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        
        # 输出线性层
        output = self.out_linear(attention_output)
        
        return output, attention_weights
```

#### 举例说明

假设我们有一个序列 `[1, 2, 3, 4, 5]`，注意力权重为 `[0.1, 0.2, 0.3, 0.2, 0.2]`，对应的值序列为 `[10, 20, 30, 40, 50]`。

1. **计算注意力得分**：`[1*10, 2*20, 3*30, 4*40, 5*50] = [10, 40, 90, 160, 250]`
2. **应用Softmax函数**：`softmax([10, 40, 90, 160, 250]) = [0.08, 0.15, 0.25, 0.25, 0.27]`
3. **加权求和**：`0.1*10 + 0.2*20 + 0.3*30 + 0.2*40 + 0.2*50 = 17.5`

因此，基于注意力机制的输出结果为 `17.5`，这个结果反映了序列中不同元素的重要性分配。

#### 数学公式

以下是注意力机制的几个关键数学公式：

1. **点积注意力得分**：
   $$\text{Score} = \text{Query} \cdot \text{Key}$$
   
2. **注意力权重**：
   $$\text{Attention}(\text{Query}, \text{Keys}, \text{Values}) = \text{softmax}(\text{Score}) \times \text{Values}$$

3. **加权求和**：
   $$\text{Output} = \sum_{i} (\text{Attention\_weights}_i \cdot \text{Values}_i)$$

通过这些公式，我们可以理解注意力机制如何通过计算和加权求和来实现对输入数据的聚焦和筛选。

综上所述，注意力机制作为一种强大的深度学习技术，通过动态调整数据的重要性，显著提升了模型在处理序列和多模态数据时的性能。在实际应用中，注意力机制在自然语言处理、计算机视觉等领域已经取得了显著的成功，未来还有望在更多领域得到广泛应用。

```python
def preprocess_image(image_path):
    transform = transforms.Compose([
```

##### 2. 模型训练与优化

接下来，我们使用预训练的Transformer模型进行图像描述生成。

```python
from transformers import ViTImageCaptioningModel, ViTImageCaptioningProcessor

# 加载预训练的模型和分词器
model = ViTImageCaptioningModel.from_pretrained("google/vit-base-patch16-224")
tokenizer = ViTImageCaptioningProcessor.from_pretrained("google/vit-base-patch16-224")

def generate_caption(image_tensor):
    input_ids = tokenizer.encode("image caption:", return_tensors="pt")
    input_ids = torch.cat((input_ids, image_tensor), dim=1)
    outputs = model.generate(input_ids, max_length=40, num_return_sequences=1)
    caption = tokenizer.decode(outputs[0], skip_special_tokens=True)
    return caption
```

##### 3. 模型评测

```python
from torch.utils.data import DataLoader

# 加载测试集数据
test_dataset = MyDataset('coco_test2014')
test_loader = DataLoader(test_dataset, batch_size=16, shuffle=False)

# 模型评估
model.eval()
with torch.no_grad():
    correct = 0
    total = 0
    for images, captions in test_loader:
        image_tensors = preprocess_image(images)
        predicted_captions = generate_caption(image_tensors)
        total += captions.size(1)
        correct += (predicted_captions == captions).sum().item()

accuracy = 100 * correct / total
print(f"Test Accuracy: {accuracy:.2f}%")
```
