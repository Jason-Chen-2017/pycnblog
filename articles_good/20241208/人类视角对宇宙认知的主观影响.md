# 定义万有引力定律
def gravity(m1, m2, r):

    return G * m1 * m2 / r**2

# 定义行星轨道预测函数
def predict_orbit(m1, m2, r0, v0, dt, steps):
    r = r0
    v = v0
    orbits = []

    for _ in range(steps):
        a = gravity(m1, m2, r) / m2
        v -= a * dt
        r += v * dt

        orbits.append(r)

    return orbits

### **### 算法原理讲解**

**1. K-均值聚类算法**

K-均值聚类算法是一种基于距离度量的聚类算法。给定数据集和聚类数量K，算法的目的是将数据点划分为K个聚类，使得每个聚类内部的距离尽可能小，聚类之间的距离尽可能大。

算法步骤如下：

- 随机初始化K个聚类中心。
- 对于每个数据点，计算其与聚类中心的距离，并将其分配给最近的聚类中心。
- 更新聚类中心，计算所有数据点的均值。
- 重复步骤2和3，直到聚类中心不再发生变化或达到最大迭代次数。

**2. 距离度量**

在K-均值聚类中，常用的距离度量是欧氏距离。对于两个特征向量$x$和$y$，它们的欧氏距离计算公式为：

$$
d(x, y) = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2}
$$

其中，$x_i$和$y_i$分别是向量$x$和$y$的第$i$个元素。

**3. 聚类结果**

在上述代码中，我们使用K-均值聚类算法将宇宙数据点划分为3个聚类。每个聚类中心表示该聚类的特征均值。聚类结果通过为每个数据点分配最近的聚类中心来实现。
