### 3.1 电磁波的基本原理

#### 核心算法原理

电磁波是由振荡的电场和磁场组成的波动。以下是一个简单的Python代码示例，展示了电磁波的传播原理：

```python
import matplotlib.pyplot as plt
import numpy as np

# 电磁波传播方程
def electromagnetic_wave propagation(t):
    E = np.sin(2 * np.pi * 5 * t)  # 电场
    B = np.sin(2 * np.pi * 5 * t)  # 磁场
    return E, B

# 时间步长
dt = 0.01
t = np.arange(0, 10, dt)

# 计算电磁波
E, B = electromagnetic_wave_propagation(t)

# 绘图
plt.plot(t, E)
plt.xlabel('Time (s)')
plt.ylabel('Electric Field (V/m)')
plt.title('Electromagnetic Wave Propagation')
plt.show()
```

    # 发送量子态到外星文明
