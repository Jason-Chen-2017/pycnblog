4. **发行奖励**：根据共识算法的结果，确定每次发行的奖励金额。

**3.3 数学模型和数学公式**

在新型社区货币体系中，数学模型和数学公式起着至关重要的作用。这些模型和公式不仅帮助我们理解货币的供需关系，还可以预测货币价格的变化，从而为决策提供科学依据。

**供需模型**：

供需模型描述了货币的需求和供应之间的关系。在新型社区货币中，需求主要来自居民对本地产品和服务的消费需求，而供应则由社区组织或地方政府通过发行控制。

1. **需求曲线**：

   - **需求公式**：需求（D）= a - bP，其中a是需求的最大值，b是需求价格弹性系数，P是货币价格。
   - **解释**：需求曲线向下倾斜，表示价格上升时需求下降。b值越大，需求对价格变化的敏感度越高。

2. **供应曲线**：

   - **供应公式**：供应（S）= c + dP，其中c是供应的最小值，d是供应价格弹性系数，P是货币价格。
   - **解释**：供应曲线向上倾斜，表示价格上升时供应增加。d值越大，供应对价格变化的敏感度越高。

**供需平衡**：

供需平衡点是指需求量和供应量相等时的价格点。在新型社区货币中，供需平衡决定了货币的市场价格。

- **平衡价格**：P_eq = (a + c) / (2b + d)
- **解释**：平衡价格是市场需求和供给曲线的交点，即满足D = S的价格。

**价格模型**：

价格模型描述了货币价格的变化规律和影响因素。在新型社区货币中，价格模型通常包括以下几个方面：

1. **货币发行量**：

   - **公式**：货币价格（P）与货币发行量（M）成反比：P ∝ 1/M。
   - **解释**：发行量越大，货币越稀少，价格越高。

2. **货币需求**：

   - **公式**：货币价格（P）与货币需求（D）成正比：P ∝ D。
   - **解释**：需求越高，货币越受欢迎，价格越高。

3. **市场波动**：

   - **公式**：货币价格（P）受市场波动影响，可以表示为：P = P_eq ± ε，其中ε是市场波动幅度。
   - **解释**：市场波动会导致价格暂时偏离平衡价格。

**示例**：

假设一个社区货币的需求函数为D = 500 - 10P，供应函数为S = 200 + 5P。我们可以通过以下步骤求解供需平衡点：

1. **设定方程**：

   - D = S：
   - 500 - 10P = 200 + 5P

2. **解方程**：

   - 500 - 200 = 10P + 5P：
   - 300 = 15P：
   - P = 20

因此，供需平衡点的价格为20。这个价格点是在需求量和供应量相等时的价格，也是市场的稳定价格。
