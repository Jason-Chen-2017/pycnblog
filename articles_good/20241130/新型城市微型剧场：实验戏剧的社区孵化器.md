## 引言：新型城市微型剧场的背景与意义

### 1.1 新型城市微型剧场的起源与发展

#### 1.1.1 微型剧场的历史背景

微型剧场，顾名思义，是一种规模较小的戏剧表演场所。其历史可以追溯到古代，当时的民间表演常常在狭小的空间中进行。然而，现代微型剧场的发展则主要是在20世纪后期，特别是在城市化进程加速的背景下。

随着城市化进程的加快，城市空间的稀缺性日益突出。传统的剧场由于空间限制，无法满足多元化、个性化的表演需求。因此，微型剧场作为一种灵活、小型的表演场所应运而生，逐渐成为城市文化景观中的一部分。

#### 1.1.2 新型城市微型剧场的出现原因

新型城市微型剧场的出现有以下几个原因：

1. **城市空间稀缺**：城市化进程导致城市空间日益紧张，传统大型剧场难以在城市中找到合适的位置。微型剧场因其小规模、灵活性的特点，能够在城市中找到更多的生存空间。
2. **观众需求多样化**：随着社会的发展，观众对于戏剧表演的需求越来越多样化。微型剧场能够提供更加个性化的表演，满足不同观众的口味。
3. **实验戏剧的兴起**：实验戏剧作为一种创新、自由的戏剧形式，需要更多的实验场所。微型剧场因其独特的空间和氛围，成为了实验戏剧的理想场所。

#### 1.1.3 新型城市微型剧场的发展趋势

新型城市微型剧场的发展趋势主要有以下几个方面：

1. **多元文化融合**：微型剧场不仅成为本地文化的展示平台，也逐渐成为多元文化融合的场所。各种文化在此交汇、碰撞，为观众带来丰富的文化体验。
2. **社区参与度提高**：微型剧场通过组织各种社区活动，提高社区居民的参与度，成为社区文化建设的核心力量。
3. **技术手段创新**：随着科技的发展，新型城市微型剧场开始采用更多先进的技术手段，如虚拟现实、增强现实等，为观众带来全新的观看体验。

### 1.2 实验戏剧的概念与特点

#### 1.2.1 实验戏剧的定义

实验戏剧，又称前卫戏剧，是一种以创新、实验为特点的戏剧形式。它强调艺术家的主观表达，反对传统戏剧的规范和约束，追求戏剧形式、内容、表演手段的创新。

#### 1.2.2 实验戏剧的核心特点

1. **创新性**：实验戏剧鼓励艺术家进行大胆的创意尝试，打破传统戏剧的束缚，探索新的表演形式和内容。
2. **实验性**：实验戏剧注重实验过程，将戏剧创作视为一个不断探索、试错的过程，而非最终的结果。
3. **自主性**：实验戏剧强调艺术家的自主性，尊重艺术家的个性表达，反对权威和规范。

#### 1.2.3 实验戏剧与传统戏剧的区别

与传统戏剧相比，实验戏剧在以下几个方面有所不同：

1. **表演形式**：实验戏剧更加自由、多样，不拘泥于传统的表演形式。
2. **内容主题**：实验戏剧通常关注社会现实、人性探索等深刻主题，而非简单的情节叙述。
3. **观众体验**：实验戏剧注重观众的参与和互动，而非单纯的观看。

import random

class MicroTheater:
    def __init__(self, capacity):
        self.capacity = capacity
        self.current_occupancy = 0

    def book_ticket(self, num_tickets):
        if self.current_occupancy + num_tickets <= self.capacity:
            self.current_occupancy += num_tickets
            return True
        else:
            return False

    def release_tickets(self, num_tickets):
        if self.current_occupancy - num_tickets >= 0:
            self.current_occupancy -= num_tickets
            return True
        else:
            return False

    def get_occupancy(self):
        return self.current_occupancy

# 创建微型剧场实例
micro_theater = MicroTheater(100)

# 预订门票
micro_theater.book_ticket(10)

# 释放门票
micro_theater.release_tickets(5)

# 获取当前 occupancy
print(micro_theater.get_occupancy())
