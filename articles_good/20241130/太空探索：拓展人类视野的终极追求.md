## 第2章 太空探索的基础科学

### 2.1 重力与微重力

> **背景介绍**
>
> 重力和微重力对太空中的物体运动有重要影响。
>
> **核心概念与联系**
>
> - **重力**：地球对物体的吸引力，影响物体在地球表面的运动。
> - **微重力**：在轨道上的航天器中，由于离心力和地球引力的相互作用，物体处于近似失重状态。
>
> **Python 源代码讲解**
>
> ```python
> import matplotlib.pyplot as plt
> import numpy as np
>
> G = 6.67430e-11  # 万有引力常数
> M = 5.972e24  # 地球质量
> r = 6.371e6  # 地球半径
>
> def gravity_force(m1, m2, r):
>     return G * m1 * m2 / r**2
>
> m1 = 1000  # 物体质量
> r1 = np.array([0, 0, 0])  # 初始位置
> v1 = np.array([10, 0, 0])  # 初始速度
>
> t = np.linspace(0, 20, 1000)
> x = r1 + v1 * t
> a = -gravity_force(m1, M, np.linalg.norm(x)) / m1
>
> plt.plot(t, x[:, 0])
> plt.xlabel('Time (s)')
> plt.ylabel('Position (m)')
> plt.title('Orbit under Gravity')
> plt.show()
> ```

> **Python 源代码讲解**
>
> ```python
> import matplotlib.pyplot as plt
> import numpy as np
>
> def communication_range(gain, noise):
>     return 10 * np.log10(gain / noise)
>
> gain = 50  # 通信增益（dB）
> noise = 10**(-10)  # 噪声功率（W）
>
> range = communication_range(gain, noise)
> plt.plot([0, range], [0, 10], 'r-')
> plt.xlabel('Range (km)')
> plt.ylabel('Signal Strength (dB)')
> plt.title('Communication Range')
