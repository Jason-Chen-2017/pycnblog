3. **道德自律**

道德自律是斯多葛哲学的核心价值观之一。斯多葛哲学家强调，人们应该根据道德准则行事，追求内心的平静和满足。道德自律不仅体现在个人行为上，还体现在对待他人的态度上。通过道德自律，人们可以建立和谐的人际关系，实现社会的和谐。

### 斯多葛哲学的核心思想

在了解了斯多葛哲学的历史背景后，接下来我们将深入探讨其核心思想，这些思想不仅构成了斯多葛哲学的基石，也为现代社会中的个体提供了宝贵的指导。

**1. 意愿与理性**

斯多葛哲学强调意愿（volition）和理性（reason）的重要性。意愿是指个人内心的意图和动机，而理性则是通过思考和判断来指导行动的能力。斯多葛哲学家认为，个体应当依据理性来塑造自己的意愿，而不是被情绪或外部环境所左右。通过理性决策，人们能够更好地控制自己的行为，实现内心的平静与和谐。

**2. 自然法则与道德准则**

斯多葛哲学认为，宇宙中存在一套普遍的自然法则（natural law），人类的行为应当与之相适应。这一观点与儒家和道家等哲学思想有相似之处。斯多葛哲学家认为，道德准则（moral principles）是自然法则在人类社会的体现，个体应当遵循这些准则行事，以达到心灵的纯洁与完整。

**3. 精神自由与情感控制**

精神自由（spiritual freedom）是斯多葛哲学的核心理念之一。它指的是个体不受外界因素影响，保持内心独立和自主的状态。为了实现精神自由，斯多葛哲学家强调对情感的控制（emotional control）。他们认为，情感本身并不是问题，但过度依赖或失控的情感会导致痛苦和焦虑。通过练习自我控制和冥想，人们可以学会控制自己的情感，从而获得内心的平静。

  ```python

      print("冥想结束。")

  # 执行冥想练习

  ```

  ```python
  # Python代码示例：理性决策
  def 理性决策（选项A，选项B，权重）：
      print(f"分析选项A：{选项A}，权重：{权重[0]}。")

      # 计算总权重
      总权重 = sum(权重)

      print(f"选项A得分：{选项A得分}。")
      print(f"选项B得分：{选项B得分}。")
      
      # 根据得分选择最佳选项
      if 选项A得分 > 选项B得分：
          print("选择选项A。")
      else：
          print("选择选项B。")

  # 执行理性决策
  理性决策("选项A：阅读书籍"，"选项B：观看电影"，[30, 70])
  ```

```python
def 理性决策（选项A，选项B，权重）：
    print(f"分析选项A：{选项A}，权重：{权重[0]}。")
    print(f"分析选项B：{选项B}，权重：{权重[1]}。")

    print(f"选项B得分：{选项B得分}。")
    
    # 根据得分选择最佳选项
    if 选项A得分 > 选项B得分：
        print("选择选项A。")
    else：
        print("选择选项B。")
```
