#### 时间分配模型

假设一个人一天有24小时，可以将其分为工作、休息、娱乐和社交四个主要活动领域。每个领域占据的时间比例不同，反映了个体对各种活动的需求与偏好。我们可以使用一个概率分布模型来表示这一分配。

#### 数学模型

设 \( x_1, x_2, x_3, x_4 \) 分别表示一个人在工作、休息、娱乐和社交领域所占的时间比例，且满足以下条件：

$$
x_1 + x_2 + x_3 + x_4 = 1
$$

$$
0 \leq x_i \leq 1 \quad (i=1,2,3,4)
$$

#### Python源代码

以下是一个Python代码示例，用于生成一个符合上述条件的概率分布模型，并可视化每个活动领域的时间分配。

```python
import numpy as np
import matplotlib.pyplot as plt

# 生成一个符合均匀分布的随机向量
np.random.seed(0)
x = np.random.uniform(0, 1, size=4)

# 确保时间比例总和为1
x = x / np.sum(x)

# 可视化每个活动领域的时间分配
labels = ['工作', '休息', '娱乐', '社交']
sizes = x * 100  # 转换为百分比

fig1, ax1 = plt.subplots()
ax1.pie(sizes, labels=labels, autopct='%.1f%%', startangle=90)
ax1.axis('equal')  # 使饼图圆滑

plt.show()
```

```python
import numpy as np
import matplotlib.pyplot as plt
from datetime import datetime, timedelta

class NightLifeManager:
    def __init__(self, time分配模型，night_hours=10):
        self.time_model = time分配模型
        self.night_hours = night_hours
        self.activities = {
            '工作': [],
            '休息': [],
            '娱乐': [],
            '社交': []
        }
    
    def add_activity(self, activity, start_time, end_time):
        if end_time - start_time > timedelta(hours=self.night_hours):
            print("活动时间超出夜生活时长限制。")
            return False
        self.activities[activity].append((start_time, end_time))
        return True
    
    def schedule_activities(self):
        for activity, times in self.activities.items():
            for start, end in times:
                print(f"{activity}: {start} - {end}")
    
    def visualize_schedule(self):
        total_time = timedelta(hours=self.night_hours)
        hours = np.arange(0, total_time.total_seconds() / 3600, 0.5)
        counts = [len(self.activities[activity]) for activity in self.activities]
        
        plt.figure(figsize=(10, 5))
        plt.bar(hours, counts, width=0.1, align='center')
        plt.xticks(hours)
        plt.xlabel('时间（小时）')
        plt.ylabel('活动数量')
        plt.title('24小时活动时间分布图')
        plt.show()

# 示例：初始化NightLifeManager并添加活动
time_model = np.random.uniform(0, 1, size=4)
time_model /= sum(time_model)  # 确保时间比例总和为1
night_manager = NightLifeManager(time_model)

night_manager.add_activity('工作', datetime(2023, 10, 25, 20), datetime(2023, 10, 25, 22))
night_manager.add_activity('娱乐', datetime(2023, 10, 25, 22), datetime(2023, 10, 25, 23))
night_manager.add_activity('社交', datetime(2023, 10, 25, 21), datetime(2023, 10, 25, 23))

night_manager.schedule_activities()
night_manager.visualize_schedule()
```

2. **添加活动**：`add_activity` 方法用于添加一个活动，并检查其时间是否超出夜生活时长限制。
