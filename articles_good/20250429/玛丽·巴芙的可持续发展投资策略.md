### 第5章: 可持续投资的数学模型

#### 5.1 环境、社会和治理（ESG）评分模型

- 5.1.1 ESG评分模型的计算方法与权重分配
  - ESG评分的计算流程：数据收集、指标权重、综合评分
  - $$ESG\text{评分} = \alpha \times E + \beta \times S + \gamma \times G$$
    - 其中，$\alpha, \beta, \gamma$ 分别为环境、社会和治理的权重，满足 $\alpha + \beta + \gamma = 1$

  - ESG评分的优缺点：数据来源的可靠性、指标的主观性

- 5.1.2 用Mermaid流程图展示ESG评分模型的计算流程
```mermaid
graph TD
A[开始] --> B[收集环境数据]
B --> C[收集社会数据]
C --> D[收集治理数据]
D --> E[计算E、S、G评分]
E --> F[计算综合ESG评分]
F --> G[结束]
```

- 5.1.3 用Python代码实现ESG评分模型
```python
import pandas as pd

def calculate_esg_score(environment, social, governance):
    # 定义权重，可根据具体情况进行调整
    alpha = 0.4
    beta = 0.3
    gamma = 0.3

    # 计算ESG评分
    esg_score = alpha * environment + beta * social + gamma * governance
    return esg_score

# 示例数据
environment_scores = [0.8, 0.7, 0.9]
social_scores = [0.6, 0.8, 0.7]
governance_scores = [0.7, 0.6, 0.8]

# 计算并输出ESG评分
esg_scores = []
for e, s, g in zip(environment_scores, social_scores, governance_scores):
    esg_scores.append(calculate_esg_score(e, s, g))

print("ESG评分结果:", esg_scores)
```

#### 5.2 玛丽·巴芙投资组合优化模型

- 5.2.1 现代投资组合理论（MPT）与风险调整收益优化
  - MPT的核心思想：通过资产组合降低风险
  - 风险调整收益的优化目标：在风险可控的前提下，最大化收益

- 5.2.2 用数学公式展示投资组合优化模型
  - $$\text{收益最大化} = \sum_{i=1}^{n} w_i r_i$$
  - $$\text{风险最小化} = \sqrt{\sum_{i=1}^{n} \sum_{j=1}^{n} w_i w_j \sigma_{ij}}}$$
  - 其中，$w_i$ 是第i个资产的权重，$r_i$ 是第i个资产的期望收益，$\sigma_{ij}$ 是第i和第j个资产之间的协方差

- 5.2.3 用Mermaid流程图展示投资组合优化的步骤
```mermaid
graph TD
A[开始] --> B[确定可投资产列表]
B --> C[计算各资产的期望收益和协方差矩阵]
C --> D[根据风险承受能力设定目标风险水平]
D --> E[计算最优投资组合]
E --> F[调整权重以满足约束条件]
F --> G[输出最优投资组合]
G --> H[结束]
```

- 5.2.4 用Python代码实现投资组合优化模型
```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize

def portfolio_optimization(returns, cov_matrix, risk_tolerance=0.05):
    # 定义优化目标函数
    n = len(returns)
    # 目标是最小化风险，即最小化方差
    def objective(weights):
        return np.dot(weights.T, np.dot(cov_matrix, weights))

    # 约束条件：权重之和为1
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]

    # 初始猜测：等权重
    initial_guess = np.array([1.0/n] * n)

    # 最优化问题：最小化方差，受约束于权重之和为1
    result = minimize(objective, initial_guess, constraints=constraints)

    return result.x

# 示例数据
returns = [0.1, 0.12, 0.08, 0.15]
cov_matrix = [
    [0.02, 0.01, 0.015, 0.02],
    [0.01, 0.03, 0.01, 0.01],
    [0.015, 0.01, 0.03, 0.02],
    [0.02, 0.01, 0.02, 0.05]
]

# 计算最优投资组合
optimal_weights = portfolio_optimization(returns, cov_matrix)
print("最优权重:", optimal_weights)
```
