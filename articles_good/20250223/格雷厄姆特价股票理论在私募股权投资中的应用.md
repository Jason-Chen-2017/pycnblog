## 第1章: 格雷厄姆特价股票理论概述

### 1.1 格雷厄姆投资理论的核心概念

#### 1.1.1 价值投资的基本原理
价值投资是一种以低于内在价值的价格购买优质股票的投资策略。格雷厄姆强调，市场波动为投资者提供了以折扣价买入的机会。以下是价值投资的核心原理：

- **安全边际**：购买价格低于内在价值，确保即使出现估值错误，也能获得正收益。
- **长期视角**：关注企业的长期盈利能力，而非短期市场波动。
- **逆向思维**：在市场恐慌时买入，在市场狂热时卖出。

#### 1.1.2 特价股票的定义与特征
特价股票是指市场价格低于其内在价值的股票。以下是特价股票的主要特征：

| 特征 | 描述 |
|------|------|
| 低估值 | 市盈率、市净率等指标低于行业平均水平 |
| 高分红率 | 相对于股价，股息收益率较高 |
| 财务健康 | 资产负债表稳健，现金流充裕 |
| 行业地位 | 在行业内具有竞争优势 |

#### 1.1.3 格雷厄姆投资策略的核心要素
格雷厄姆的投资策略主要包括以下要素：

- **筛选标准**：基于财务指标（如市盈率、市净率）筛选低价股票。
- **安全边际**：确保买入价格低于内在价值。
- **分散投资**：通过投资多个标的降低风险。

### 1.2 格雷厄姆投资理论的哲学基础

#### 1.2.1 "安全边际"的概念
安全边际是格雷厄姆理论的核心，指买入价格与内在价值之间的差距。通过安全边际，投资者可以在估值错误时仍能获利。

#### 1.2.2 投资中的"margin of safety"
安全边际不仅提供保护，还能增加投资的确定性。以下是安全边际的重要性：

- **保护本金**：即使估值错误，也能避免重大损失。
- **提高收益潜力**：内在价值的提升带来的额外收益。

#### 1.2.3 价值与价格的长期关系

## 第2章: 私募股权投资的基本原理

### 2.1 私募股权投资的定义与特点

#### 2.1.1 私募股权的定义
私募股权是指通过非公开方式向特定投资者募集资金，投资于未上市公司或进行企业重组的投资形式。

#### 2.1.2 私募股权与传统投资的区别
| 方面 | 私募股权 | 传统投资 |
|------|----------|-----------|
| 流动性 | 低       | 高         |
| 风险 | 高       | 中/低     |
| 收益 | 高       | 中/低     |

#### 2.1.3 私募股权的运作模式
私募股权的运作模式包括：

- **收购**：购买现有企业部分或全部股权。
- **重组**：对企业进行财务或战略调整。
- **上市**：通过IPO或出售实现退出。

#### 2.3.1 投资阶段划分

1. **种子阶段**：初创企业。

### 3.2 格雷厄姆理论在私募股权估值中的应用

#### 3.2.1 贴现现金流模型（DCF）
贴现现金流模型是私募股权估值的核心工具。以下是DCF模型的步骤：

1. **预测现金流**：预测未来5-10年的现金流。
2. **计算加权平均资本成本（WACC）**：确定合适的折现率。
3. **贴现现金流**：将未来现金流贴现到现值。
4. **加总现值**：将各年的现值相加，得到企业价值。

DCF模型的公式如下：

$$
\text{企业价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + \text{WACC})^t}
$$`

### 4.1 格雷厄姆理论的数学模型

#### 4.1.1 贴现现金流模型
贴现现金流模型的Python实现如下：

```python
def discounted_cash_flow(cash_flows, discount_rate):
    present_value = 0
    for year, cash_flow in enumerate(cash_flows):
        discount_factor = (1 + discount_rate) ** year
        present_value += cash_flow / discount_factor
    return present_value
```

$$

$$
\text{P/B} = \frac{\text{股价}}{\text{每股净资产}}
