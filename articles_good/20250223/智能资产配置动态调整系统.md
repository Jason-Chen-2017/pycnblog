## 第2章: 算法原理与数学模型

### 2.1 动态规划算法

- **算法原理**：动态规划通过分阶段决策，优化当前阶段的选择，以达到整体最优。
- **数学模型与公式**：
  - 状态转移方程：$$V(t) = \max_{i} \{ V(t-1) + \alpha_i \}$$
  - 边界条件：$$V(0) = 0$$
- **代码实现**：
  ```python
  def dynamic_planning(asset_returns, weights):
      n_assets = len(asset_returns)
      n_periods = len(weights)
      # 初始化动态规划表格
      dp = [[0 for _ in range(n_assets)] for _ in range(n_periods)]
      for t in range(n_periods):
          for i in range(n_assets):
              if t == 0:
                  dp[t][i] = asset_returns[t][i]
              else:
                  max_val = max(dp[t-1][j] + weights[t][i] for j in range(n_assets))
                  dp[t][i] = max_val
      return dp
  ```

### 2.2 遗传算法

- **算法原理**：模拟生物进化过程，通过选择、交叉和变异生成新的解。
- **数学模型与公式**：
  - 适应度函数：$$fitness = \sum w_i \times r_i$$
  - 选择概率：$$p_i = \frac{fitness_i}{\sum fitness}$$
- **代码实现**：
  ```python
  import random

  def genetic_algorithm(asset_returns, population_size=100, generations=50):
      n_assets = len(asset_returns)
      population = [[random.random() for _ in range(n_assets)] for _ in range(population_size)]
      
      for _ in range(generations):
          fitness = [sum(r * w for r, w in zip(asset_returns, portfolio)) for portfolio in population]
          max_fitness = max(fitness)
          # 选择
          selected = [population[i] for i in range(population_size) if fitness[i] == max_fitness]
          # 交叉
          new_population = []
          for _ in range(population_size):
              parent1 = random.choice(selected)
              parent2 = random.choice(selected)
              child = [p1 if random.random() < 0.5 else p2 for p1, p2 in zip(parent1, parent2)]
              new_population.append(child)
          population = new_population
      best_portfolio = population[0]
      return best_portfolio
  ```

### 2.3 强化学习算法

- **算法原理**：通过智能体与环境的交互，学习最优策略。
- **数学模型与公式**：
  - 状态空间：$$S = \{s_1, s_2, ..., s_n\}$$
  - 动作空间：$$A = \{a_1, a_2, ..., a_m\}$$
  - Q-learning更新规则：$$Q(s, a) = Q(s, a) + \alpha [r + \gamma \max Q(s', a) - Q(s, a)]$$
- **代码实现**：
  ```python
  import numpy as np

  class QLearning:
      def __init__(self, state_size, action_size, gamma=0.99, alpha=0.1):
          self.Q = np.zeros((state_size, action_size))
          self.gamma = gamma
          self.alpha = alpha
      
      def update(self, state, action, reward, next_state):
          self.Q[state][action] += self.alpha * (reward + self.gamma * np.max(self.Q[next_state]) - self.Q[state][action])
  ```

### 3.1 动态资产配置的数学模型

- **资产权重调整公式**：
  $$w_t = w_{t-1} + \delta \times (\mu_t - w_{t-1})$$
- **风险收益优化模型**：
  $$\min_w \sigma^2, \quad \text{s.t.} \quad \mathbb{E}[r] = \omega, \quad \sum w_i = 1$$

### 3.2 优化算法的数学基础

- **动态规划的数学表达**：
  $$V(t) = \max_{w} \{ r \times w + V(t-1) \}$$
- **遗传算法的数学表示**：
  $$p_i = \frac{e^{fitness_i}}{\sum e^{fitness_j}}$$
- **强化学习的数学框架**：
  $$Q(s, a) = Q(s, a) + \alpha [r + \gamma Q(s', a) - Q(s, a)]$$

### 5.2 核心代码实现

```python
import pandas as pd
import numpy as np
from sklearn import preprocessing
import tensorflow as tf

def load_data(ticker):
    df = pd.read_csv(f'data/{ticker}.csv')
    df['Date'] = pd.to_datetime(df['Date'])
    df.set_index('Date', inplace=True)
    return df

def preprocess(data):
    # 标准化处理
    scaler = preprocessing.StandardScaler()
    scaled_data = scaler.fit_transform(data[['Close', 'Volume']])
    return scaled_data

# 加载数据
market_data = {}
tickers = ['AAPL', 'MSFT', 'GOOGL']
for t in tickers:
    market_data[t] = load_data(t)

# 预处理
processed_data = {}
for t in tickers:
    processed_data[t] = preprocess(market_data[t])

# 模型训练
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu', input_shape=(2,)),
    tf.keras.layers.Dense(32, activation='relu'),
    tf.keras.layers.Dense(1, activation='linear')
])
model.compile(optimizer='adam', loss='mean_squared_error')
model.fit(processed_data['AAPL'], epochs=10, batch_size=32)
```
