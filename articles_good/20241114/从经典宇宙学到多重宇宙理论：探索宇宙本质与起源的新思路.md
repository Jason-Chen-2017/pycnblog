宇宙学的基本概念包括：

- 宇宙的尺度：宇宙的大小和结构，通常用光年或秒差距来衡量。
- 宇宙的年龄：宇宙从大爆炸开始至今的时间。
- 宇宙的密度：宇宙中物质的平均密度。
- 宇宙的膨胀：宇宙在宇宙学时间尺度上不断扩张的现象。

#### 1.2 宇宙的膨胀

宇宙的膨胀是指宇宙中的星系、星团等天体在宇宙学时间尺度上相互远离的现象。哈勃定律描述了星系的退行速度与它们之间的距离之间的关系，即距离越远，退行速度越快。

暗物质是宇宙中一种不发光、不与电磁波相互作用，但通过引力影响宇宙演化的物质。暗物质的存在可以通过观测星系旋转曲线、宇宙大尺度结构的形成和宇宙背景辐射的温度异常来证实。

import numpy as np

# 设置参数
rho = 1e-26  # 宇宙平均密度
lambda_ = 1e-47  # 宇宙暗能量密度

# 弗里德曼方程
def hubble_parameter(rho, lambda_):
    h = np.sqrt((8 * np.pi * rho + lambda_) / (3 * np.exp(1)))
