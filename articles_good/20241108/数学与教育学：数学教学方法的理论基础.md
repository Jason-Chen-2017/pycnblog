   - 男生人数：15
   - 女生人数：15

2. **计算男女生比例：**
   - 比例公式：比例 = 男生人数 / 女生人数

3. **代入数据进行计算：**
   - 比例 = 15 / 15

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 加载学生成绩数据
data = pd.read_csv('student_scores.csv')

# 计算平均成绩
average_score = np.mean(data['score'])

# 绘制成绩分布图
plt.hist(data['score'], bins=10, edgecolor='black')
plt.axvline(average_score, color='red', linestyle='dashed', linewidth=1)
plt.xlabel('Score')
plt.ylabel('Frequency')
plt.title('Student Score Distribution')
plt.show()

# 输出平均成绩
print(f"The average score is: {average_score:.2f}")
```
