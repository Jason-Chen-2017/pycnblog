#### 广义相对论与爱因斯坦场方程

爱因斯坦的广义相对论是描述重力如何影响时空结构的重要理论。广义相对论的核心是爱因斯坦场方程，这是一个复杂的数学公式，描述了时空曲率与物质分布之间的关系。通过这个公式，科学家们能够预测黑洞、引力波的存在和性质。

```plaintext
爱因斯坦场方程（简化形式）：
G_μν + Λg_μν = -8πG T_μν
```

其中，G_μν 是爱因斯坦张量，描述了时空的曲率，T_μν 是能量-动量张量，描述了物质的分布，G 是引力常数，Λ 是宇宙学常数，g_μν 是度规张量。

量子力学是描述微观粒子行为的理论，薛定谔方程是量子力学的核心方程，用于描述微观粒子的波函数随时间的演化。

```latex
时间依赖的薛定谔方程：
iℏ \frac{\partial \Psi(x, t)}{\partial t} = \hat{H} \Psi(x, t)
```

其中，i 是虚数单位，ℏ 是约化普朗克常数，Ψ(x, t) 是波函数，描述了粒子在位置 x 和时间 t 的状态，\hat{H} 是哈密顿算子，描述了粒子的总能量。
