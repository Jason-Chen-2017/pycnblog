      visited = set()
      queue = deque([start])

          vertex = queue.popleft()
          if vertex not in visited:
              visited.add(vertex)
              if vertex == target:
                  return True
              for neighbour in graph[vertex]:
                  queue.append(neighbour)
      return False
  ```

  def DFS(graph, vertex, visited):

#### 3.1 量化指标的设定

为了量化观测者选择效应，我们需要设定一系列能够准确反映效应程度的指标。这些指标通常包括准确率、召回率、F1分数和ROC曲线等。

1. **准确率（Accuracy）**：准确率是评估分类模型性能的一个基本指标，定义为正确分类的样本数占总样本数的比例。公式如下：

   $$ Accuracy = \frac{TP + TN}{TP + TN + FP + FN} $$

   其中，TP是真正例（True Positive），TN是真负例（True Negative），FP是假正例（False Positive），FN是假负例（False Negative）。

2. **召回率（Recall）**：召回率是评估模型对正类样本的识别能力，定义为正确分类的正类样本数占总正类样本数的比例。公式如下：

   $$ Recall = \frac{TP}{TP + FN} $$

3. **F1分数（F1 Score）**：F1分数是准确率和召回率的调和平均值，能够更全面地评估分类模型的性能。公式如下：

   $$ F1 Score = 2 \times \frac{Precision \times Recall}{Precision + Recall} $$

   其中，Precision是精确率，定义为正确分类的正类样本数与所有预测为正类样本数的比例。

4. **ROC曲线（Receiver Operating Characteristic Curve）**：ROC曲线通过改变分类阈值，描绘真阳性率（True Positive Rate）对假阳性率（False Positive Rate）的关系。曲线下面积（Area Under Curve, AUC）是评估模型性能的一个重要指标。

   $$ AUC = \int_{0}^{1} \frac{TPR(t)}{FPR(t)} dt $$

   其中，TPR(t)是当前阈值下的真阳性率，FPR(t)是当前阈值下的假阳性率。

**Breadth-First Search (BFS)**：广度优先搜索是一种用于图的遍历算法，按照层次遍历的方式搜索图中的节点。以下是其伪代码：

    visited = set()
    queue = deque([start])
    
    while queue:
        vertex = queue.popleft()
        if vertex not in visited:
            visited.add(vertex)
            for neighbour in graph[vertex]:
                queue.append(neighbour)
```

**A.4 数学模型与公式**

**贝叶斯公式**：

$$ P(A|B) = \frac{P(B|A)P(A)}{P(B)} $$

**概率分布函数**：

$$ f(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} $$

**线性回归**：

$$ y = \beta_0 + \beta_1x + \epsilon $$

**逻辑回归**：

$$ P(y=1|x;\beta) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x)}} $$

**支持向量机（SVM）**：

$$ \min_{w, b, \xi} \frac{1}{2} ||w||^2 + C \sum_{i=1}^{n} \xi_i $$

约束条件：

$$ y_i (w \cdot x_i + b) \geq 1 - \xi_i $$

$$ \xi_i \geq 0 $$

其中，$w$是权重向量，$b$是偏置项，$C$是正则化参数，$x_i$是输入特征，$y_i$是标签，$\xi_i$是松弛变量。
