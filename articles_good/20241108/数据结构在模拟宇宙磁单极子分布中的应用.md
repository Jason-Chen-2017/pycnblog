### 2.1 基础数据结构

基础数据结构是构建复杂数据结构的基础，包括以下几种：

1. **数组**：数组是一种线性数据结构，用于存储固定大小的元素序列。数组在访问和操作元素时具有高效的性能，特别是在元素访问模式已知时。

   $$ \text{伪代码示例：} $$
   ```
   function arraySum(array):
       sum = 0
       for element in array:
           sum += element
       return sum
   ```

2. **链表**：链表是一种动态数据结构，用于存储可变大小的元素序列。链表在插入和删除操作时具有高效的性能，但访问特定元素可能需要遍历链表。

   $$ \text{伪代码示例：} $$
   ```
   function insertAtTail(head, value):
       new_node = new Node(value)
       if head is null:
           head = new_node
       else:
           current = head
           while current.next is not null:
               current = current.next
           current.next = new_node
       return head
   ```

3. **栈**：栈是一种后进先出（LIFO）的数据结构，用于存储元素的顺序。栈在插入和删除元素时具有高效的性能，适用于需要按照特定顺序处理数据的场景。

   $$ \text{伪代码示例：} $$
   ```
   function push(stack, value):
       new_node = new Node(value)
       new_node.next = stack
       stack = new_node
       return stack
   ```

4. **队列**：队列是一种先进先出（FIFO）的数据结构，用于存储元素的顺序。队列在插入和删除元素时具有高效的性能，适用于需要按照特定顺序处理数据的场景。

   $$ \text{伪代码示例：} $$
   ```
   function enqueue(queue, value):
       new_node = new Node(value)
       if queue is null:
           queue = new_node
       else:
           current = queue
           while current.next is not null:
               current = current.next
           current.next = new_node
       return queue
   ```

### 2.2 高级数据结构

高级数据结构是解决复杂问题的有效工具，包括以下几种：

1. **树**：树是一种层次化的数据结构，用于表示具有父子关系的节点。树在表示层次结构和进行层次遍历方面具有高效的性能。

   $$ \text{伪代码示例：} $$
   ```
   function inorderTraversal(root):
       if root is null:
           return
       inorderTraversal(root.left)
       print(root.value)
       inorderTraversal(root.right)
   ```

2. **图**：图是一种非层次化的数据结构，用于表示多个节点之间的复杂关系。图在表示网络结构和进行图遍历方面具有高效的性能。

   $$ \text{伪代码示例：} $$
   ```
   function breadthFirstSearch(graph, start):
       queue = emptyQueue()
       visited = emptySet()
       enqueue(queue, start)
       while not isEmpty(queue):
           node = dequeue(queue)
           if node not in visited:
               print(node.value)
               for neighbor in graph[node]:
                   enqueue(queue, neighbor)
                   visited.add(neighbor)
   ```

3. **哈希表**：哈希表是一种基于哈希函数的数据结构，用于快速查找和插入元素。哈希表在处理大量键值对数据时具有高效的性能。

### 2.3 数据结构的性能考量

数据结构的性能取决于多个因素，包括时间复杂度和空间复杂度。时间复杂度描述了算法执行时间与输入规模的关系，而空间复杂度描述了算法所需存储空间与输入规模的关系。

在宇宙模拟中，数据结构的选择和性能优化至关重要。以下是一些影响数据结构性能的关键因素：

1. **时间复杂度**：在处理大量数据时，选择时间复杂度低的数据结构可以显著提高模拟效率。例如，数组在随机访问时具有较低的时间复杂度（O(1)），而链表在访问特定元素时需要遍历链表，时间复杂度为O(n)。

2. **空间复杂度**：在宇宙模拟中，数据结构的空间复杂度也是一个重要的考量因素。选择空间复杂度低的数据结构可以减少内存占用，提高模拟的效率。例如，数组在存储大量数据时具有较低的空间复杂度（O(n)），而链表在存储大量数据时需要额外的空间来存储指针。

3. **可扩展性**：宇宙模拟中的数据结构需要能够适应数据规模的动态变化。具有可扩展性的数据结构可以灵活地适应不同规模的数据，提高模拟的效率。
