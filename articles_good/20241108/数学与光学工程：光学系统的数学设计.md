### 第一部分：光学系统基础知识

#### 第1章：光学系统概述

**1.1 光学系统基本概念**

光学系统是由一系列光学元件组成的，用于控制光的行为以实现特定光学效果的装置。这些元件包括透镜、镜片、反射镜、棱镜等。光学系统广泛应用于各种领域，如光学仪器、激光技术、医学成像、通信等。

**1.2 光学系统的分类与特点**

光学系统可以根据其功能和工作原理进行分类。常见的分类方法包括：

- **几何光学系统**：主要研究光的传播路径和成像特性，如透镜、反射镜等。
- **波动光学系统**：研究光的波动性质，如干涉、衍射等。
- **成像光学系统**：用于生成清晰图像的光学系统，如显微镜、望远镜等。
- **照明光学系统**：用于提供合适照明条件的光学系统，如摄影灯、投影仪等。

**1.3 光学系统的基本组成部分**

一个典型的光学系统通常包括以下几个基本部分：

- **光源**：提供光线的初始能量。
- **光学元件**：如透镜、反射镜等，用于改变光的方向和性质。
- **光路调节器**：如调焦装置、光阑等，用于调节光线路径和光强。
- **探测器或成像器件**：用于检测或记录光学系统的输出。

### 第2章：光学系统的数学模型

**2.1 几何光学基础**

几何光学是光学系统设计的基础，主要研究光线在均匀介质中的传播规律。几何光学的基本原理包括：

- **光线传播定律**：光线在两种介质的界面处发生折射，其入射角和折射角满足斯涅尔定律。
- **光线聚焦原理**：凸透镜或凹透镜可以使光线聚焦或发散，形成实像或虚像。
- **成像公式**：通过光学系统的光线满足薄透镜成像公式，即

  $$\frac{1}{f} = \frac{1}{u} + \frac{1}{v}$$

  其中，$f$ 是透镜的焦距，$u$ 是物距，$v$ 是像距。

**2.2 波动光学基础**

波动光学研究光的波动性质，包括干涉、衍射和偏振等现象。波动光学的基本原理包括：

- **波动方程**：描述光波的传播规律，即

  $$\nabla^2 \psi - \frac{1}{c^2} \frac{\partial^2 \psi}{\partial t^2} = 0$$

  其中，$\psi$ 是光波的电场或磁场分布，$c$ 是光速。
- **干涉现象**：两束相干光波叠加时会产生干涉条纹，即明暗相间的干涉图样。
- **衍射现象**：光波在通过狭缝或绕过障碍物时会发生衍射，形成衍射图样。

**2.3 光学系统的数学建模**

光学系统的数学建模是将光学系统的物理特性转化为数学模型，以便于分析和设计。常见的数学建模方法包括：

- **几何光学模型**：基于几何光学的原理，建立光学系统的几何模型。
- **波动光学模型**：基于波动光学的原理，建立光学系统的波动模型。
- **数值分析方法**：使用数值分析方法，如有限元法、有限差分法等，求解光学系统的数学模型。

```python
import opti
import numpy as np

# 定义光学系统参数
f = 100  # 透镜焦距
n = 1.5  # 透镜折射率

# 创建光学系统
system = opti.System()

# 添加透镜
lens = opti.Lens(f, n)
system.addObject(lens)

# 设置光源
source = opti.PointSource()
system.addObject(source)

# 设置探测器
detector = opti.Detector()
system.addObject(detector)

# 设置光学路径
source.connectTo(lens)
lens.connectTo(detector)

# 运行光学系统
system.run()

# 可视化成像结果
detector.image.plot()
```

在这个示例中，我们首先定义了光学系统的参数，然后创建了一个简单的光学系统，包括透镜、光源和探测器。通过运行光学系统，我们可以得到成像结果并可视化。
