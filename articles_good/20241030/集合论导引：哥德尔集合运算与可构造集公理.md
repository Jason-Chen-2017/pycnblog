## 第一部分：集合论基础

### 第1章：集合论的基本概念

#### 1.1 集合的定义与性质

集合是数学中最基本的概念之一，它是由确定的、互不相同的元素构成的整体。集合中的元素可以是具体的对象，如数字、字母，也可以是抽象的对象，如函数、关系。

**集合的概念**：
集合可以表示为大括号{}内的一组元素。例如，集合A = {1, 2, 3}。

**集合的基本性质**：
- 确定性：集合中的元素必须是明确的，不能存在模糊的元素。
- 无序性：集合中的元素不考虑顺序，即A = {1, 2, 3} 与 A = {3, 2, 1} 是同一个集合。
- 唯一性：集合中的元素是互不相同的，不能有重复的元素。

#### 1.2 集合的表示方法

集合可以通过多种方法表示：

**列表表示法**：
使用大括号{}列出集合中的所有元素。例如，A = {1, 2, 3}。

**描述法**：
使用描述性的语句来定义集合中的元素。例如，A = {x | x 是正整数}，表示A是所有正整数的集合。

**图表示法**：
使用Venn图或其他图形来表示集合之间的关系。例如，两个集合A和B的交集可以表示为一个相交的圆圈。

#### 1.3 集合之间的关系

集合之间有多种基本关系：

**子集与超集**：
如果集合A中的所有元素都属于集合B，则称A是B的子集，记作A ⊆ B。例如，{1, 2} 是 {1, 2, 3} 的子集。

**相交与不相交**：
如果集合A和B有至少一个共同的元素，则称它们相交，记作A ∩ B。如果A和B没有任何共同的元素，则称它们不相交。

**独立与依赖**：
如果集合A中的每个元素都与集合B中的某个元素一一对应，则称A与B独立。否则，如果A中的元素依赖于B中的元素，则称A与B依赖。

### 第2章：集合的基本运算

#### 2.1 并集与交集

**并集的定义与运算**：
并集是由两个集合中的所有元素构成的集合。记作A ∪ B。例如，{1, 2} ∪ {3, 4} = {1, 2, 3, 4}。

**交集的定义与运算**：
交集是由两个集合中共有的元素构成的集合。记作A ∩ B。例如，{1, 2} ∩ {3, 4} = ∅（空集）。

**并集与交集的运算性质**：
- 交换律：A ∪ B = B ∪ A，A ∩ B = B ∩ A
- 结合律：(A ∪ B) ∪ C = A ∪ (B ∪ C)，(A ∩ B) ∩ C = A ∩ (B ∩ C)
- 分配律：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)，A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

#### 2.2 补集与对称差集

**补集的定义与运算**：
补集是相对于某个集合的补集，即除了该集合之外的所有元素构成的集合。记作A'。例如，{1, 2, 3}' = {4, 5, 6}。

**对称差集的定义与运算**：
对称差集是由两个集合中不同时属于另一个集合的元素构成的集合。记作A Δ B。例如，{1, 2} Δ {3, 4} = {1, 3, 4}。

**补集与对称差集的运算性质**：
- 补集的性质：A ∪ A' = U，A ∩ A' = ∅（U表示全集）
- 对称差集的性质：A Δ A' = ∅，A Δ A = U

#### 2.3 集合的划分与等价关系

**集合的划分方法**：
划分是将一个集合分成若干个子集的过程。例如，将{1, 2, 3, 4}划分为{{1, 2}, {3, 4}}。

**等价关系的定义与性质**：
等价关系是集合上的一个二元关系，满足自反性、对称性和传递性。等价类是由等价关系划分得到的集合。

**等价类与划分**：
每个等价关系对应一个划分，每个划分对应一个等价关系。例如，根据模n同余关系，可以将自然数集合划分为若干个等价类。
