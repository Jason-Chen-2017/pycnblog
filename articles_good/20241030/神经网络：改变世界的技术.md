### 神经网络的基本概念

神经网络（Neural Networks）是一种模拟人脑神经元结构和功能的计算模型，由大量相互连接的神经元（或节点）组成。这些神经元通过传递和处理信息，实现数据输入到输出之间的转换。

#### 神经元的基本结构

一个典型的神经元包含以下几个部分：

1. **输入层**：接收外部输入信号，每个输入信号都对应一个权重值。
2. **激活函数**：对输入信号进行非线性变换，引入非线性特性，使得神经网络具有强大的学习和自适应能力。
3. **输出层**：输出处理后的信号，用于分类、预测或生成目标输出。
4. **连接权重**：神经元之间的连接具有权重值，用于表示连接的强度。
5. **偏置**：用于调整神经元的阈值，增强网络的泛化能力。

#### 神经网络的起源和发展历史

神经网络的起源可以追溯到20世纪50年代，当时美国心理学家McCulloch和Pitts提出了第一个模拟神经元功能的数学模型，即感知机（Perceptron）。虽然感知机只能处理线性可分问题，但它为神经网络的发展奠定了基础。

1. **1950年代**：感知机模型问世，成为神经网络的开端。
2. **1960年代**：马文·闵斯基（Marvin Minsky）和西摩尔·派普特（Seymour Papert）指出感知机无法解决非线性问题，导致神经网络研究陷入低潮。
3. **1980年代**：反向传播算法（Backpropagation Algorithm）的提出，使得多层神经网络训练成为可能。
4. **1990年代**：支持向量机（Support Vector Machine, SVM）等新算法的发展，使得神经网络在分类问题中的应用受到挑战。
5. **2006年**：杰弗里·辛顿（Geoffrey Hinton）等人提出深度学习（Deep Learning）概念，重新点燃了神经网络研究的热潮。
6. **2010年代至今**：随着计算硬件的进步和大数据的普及，深度学习取得了重大突破，在图像识别、语音识别、自然语言处理等领域取得了显著成果。

#### 深度学习与神经网络的联系

深度学习（Deep Learning）是一种基于多层神经网络的学习方法，通过多层次的非线性变换，自动提取特征并进行分类、预测和生成。深度学习与神经网络的关系如下：

1. **神经网络是深度学习的基础**：深度学习通过多层神经网络实现，因此神经网络是深度学习的重要组成部分。
2. **深度学习扩展了神经网络的应用范围**：深度学习通过引入多层神经网络，解决了传统神经网络在处理复杂任务时的局限性，从而扩展了神经网络的应用范围。
3. **深度学习推动了神经网络的发展**：深度学习的成功，促使研究人员不断改进神经网络的理论和方法，推动神经网络技术的发展。

### 神经网络的基本结构

神经网络（Neural Networks）的基本结构由多个层组成，每层包含多个神经元。这些神经元通过加权连接形成网络，从而实现数据的输入到输出的变换。以下是神经网络的主要组成部分及其工作原理：

#### 神经元的工作原理

神经元是神经网络的基本单元，类似于生物神经元。一个简单的神经元可以表示为：

\[ z = w \cdot x + b \]

其中，\( w \) 是权重（weight），\( x \) 是输入（input），\( b \) 是偏置（bias）。这个公式表示输入信号通过权重和偏置加权后，产生一个中间值 \( z \)。

接下来，通过激活函数（activation function）对中间值 \( z \) 进行非线性变换，以引入非线性特性。常见的激活函数有：

1. **sigmoid函数**：
\[ a = \frac{1}{1 + e^{-z}} \]

2. **ReLU函数**：
\[ a = \max(0, z) \]

3. **tanh函数**：
\[ a = \frac{e^z - e^{-z}}{e^z + e^{-z}} \]

这些激活函数可以增强神经网络的表征能力和学习能力。

#### 神经网络的结构组成

一个典型的神经网络包括以下几部分：

1. **输入层（Input Layer）**：接收外部输入数据，每个输入数据对应一个神经元。输入层不包含激活函数。

2. **隐藏层（Hidden Layers）**：一个或多个隐藏层，每个隐藏层包含多个神经元。隐藏层中的神经元接收前一层的输出，通过权重和偏置计算中间值，并传递给下一层。隐藏层的数量和神经元数量是可变的，需要根据具体问题进行调整。

3. **输出层（Output Layer）**：输出层接收隐藏层的输出，通过激活函数得到最终的输出结果。输出层的神经元数量和类型取决于具体任务。例如，在分类任务中，输出层通常是一个软性最大化函数（如softmax），用于计算每个类别的概率。

#### 神经网络的类型

根据网络结构和功能，神经网络可以分为以下几种类型：

1. **前馈神经网络（Feedforward Neural Networks）**：
   - **结构**：没有循环，信息从前向传播。
   - **应用**：广泛应用于分类、回归和生成任务。
   - **优点**：计算简单，易于理解和实现。
   - **缺点**：无法处理序列数据。

2. **卷积神经网络（Convolutional Neural Networks, CNN）**：
   - **结构**：包含卷积层、池化层和全连接层。
   - **应用**：广泛应用于图像分类、目标检测和图像生成。
   - **优点**：能够自动提取图像中的特征。
   - **缺点**：计算量大，需要大量训练数据。

3. **循环神经网络（Recurrent Neural Networks, RNN）**：
   - **结构**：包含循环结构，能够处理序列数据。
   - **应用**：广泛应用于自然语言处理、语音识别和时间序列预测。
   - **优点**：能够处理序列数据。
   - **缺点**：存在梯度消失和梯度爆炸问题。

4. **长短期记忆网络（Long Short-Term Memory Networks, LSTM）**：
   - **结构**：基于RNN，通过引入记忆单元和门控机制解决梯度消失问题。
   - **应用**：广泛应用于长序列数据分析和时间序列预测。
   - **优点**：能够处理长序列数据。
   - **缺点**：计算复杂度高，参数较多。

5. **生成对抗网络（Generative Adversarial Networks, GAN）**：
   - **结构**：由生成器和判别器组成，通过对抗训练生成数据。
   - **应用**：广泛应用于图像生成、视频生成和语音合成。
   - **优点**：能够生成高质量的数据。
   - **缺点**：训练过程不稳定，需要大量计算资源。

#### 多层神经网络的工作原理

多层神经网络通过多层次的非线性变换，逐步提取数据中的特征。具体过程如下：

1. **输入层**：接收外部输入数据，每个数据通过权重和偏置传递到下一层。
2. **隐藏层**：输入数据通过激活函数处理后，传递到下一层。每个隐藏层的神经元对输入数据进行特征提取和组合。
3. **输出层**：隐藏层的输出通过激活函数处理后，得到最终输出结果。

通过多次迭代训练，神经网络可以自动调整权重和偏置，优化网络结构，提高预测性能。

综上所述，神经网络的基本结构包括输入层、隐藏层和输出层，通过神经元之间的加权连接和激活函数，实现数据的输入到输出的变换。不同类型的神经网络适用于不同的应用场景，需要根据具体问题进行调整和优化。

### 主流神经网络架构

神经网络（Neural Networks）架构的多样性使得其能够应用于各种复杂任务。以下是几种主流的神经网络架构，包括前馈神经网络（Feedforward Neural Networks, FFNN）、卷积神经网络（Convolutional Neural Networks, CNN）、循环神经网络（Recurrent Neural Networks, RNN）和长短期记忆网络（Long Short-Term Memory Networks, LSTM），以及生成对抗网络（Generative Adversarial Networks, GAN）。

#### 前馈神经网络（FFNN）

前馈神经网络是最基本的神经网络结构，信息从前向传播，没有循环。其主要包括以下组成部分：

1. **输入层（Input Layer）**：接收外部输入数据，每个输入数据对应一个神经元。
2. **隐藏层（Hidden Layers）**：一个或多个隐藏层，每个隐藏层包含多个神经元。隐藏层中的神经元对输入数据进行特征提取和组合。
3. **输出层（Output Layer）**：隐藏层的输出通过激活函数处理后，得到最终输出结果。

前馈神经网络的工作原理如下：

1. **输入数据**：输入数据通过权重和偏置传递到隐藏层。
2. **激活函数**：隐藏层中的神经元通过激活函数进行非线性变换。
3. **权重和偏置更新**：通过反向传播算法（Backpropagation Algorithm）更新权重和偏置，以优化网络性能。

前馈神经网络在分类和回归任务中具有广泛应用，其优点在于计算简单、易于理解和实现。

#### 卷积神经网络（CNN）

卷积神经网络是一种专门用于处理图像数据的神经网络架构，其主要包括以下组成部分：

1. **卷积层（Convolutional Layers）**：卷积层通过卷积操作提取图像中的特征，卷积核用于提取局部特征。
2. **池化层（Pooling Layers）**：池化层用于减小特征图的尺寸，减少计算量。
3. **全连接层（Fully Connected Layers）**：全连接层将卷积层和池化层提取的特征进行组合，用于分类或回归任务。

卷积神经网络的工作原理如下：

1. **卷积操作**：卷积层通过卷积操作提取图像中的特征。
2. **非线性激活**：每个卷积核的输出通过激活函数进行非线性变换。
3. **池化操作**：池化层用于减小特征图的尺寸。
4. **特征组合**：全连接层将卷积层和池化层提取的特征进行组合。

卷积神经网络在图像分类、目标检测和图像生成等任务中具有广泛应用，其优点在于能够自动提取图像中的特征，减少人工特征工程的工作量。

#### 循环神经网络（RNN）

循环神经网络是一种能够处理序列数据的神经网络架构，其主要包括以下组成部分：

1. **隐藏状态（Hidden State）**：循环神经网络中的每个神经元具有隐藏状态，用于存储序列中的信息。
2. **门控机制（Gate Mechanism）**：门控机制包括输入门、遗忘门和输出门，用于控制信息的流动。

循环神经网络的工作原理如下：

1. **输入序列**：输入序列通过权重和偏置传递到隐藏状态。
2. **门控操作**：通过门控机制控制信息的流动，遗忘旧信息、保留新信息。
3. **输出序列**：隐藏状态的输出通过激活函数处理后，得到输出序列。

循环神经网络在自然语言处理、语音识别和时间序列预测等任务中具有广泛应用，其优点在于能够处理序列数据，保留历史信息。

#### 长短期记忆网络（LSTM）

长短期记忆网络是一种改进的循环神经网络，通过引入记忆单元和门控机制，解决了循环神经网络在处理长序列数据时的梯度消失问题。其主要包括以下组成部分：

1. **输入门（Input Gate）**：用于控制新的信息如何进入记忆单元。
2. **遗忘门（Forget Gate）**：用于控制哪些信息应该从记忆单元中遗忘。
3. **输出门（Output Gate）**：用于控制记忆单元的信息如何输出。

长短期记忆网络的工作原理如下：

1. **输入门**：根据新的输入信息，决定哪些信息需要更新记忆单元。
2. **遗忘门**：根据旧的输入信息，决定哪些信息需要遗忘。
3. **输出门**：根据记忆单元的状态，决定输出序列。

长短期记忆网络在长序列数据处理和时间序列预测等任务中具有广泛应用，其优点在于能够处理长序列数据，避免梯度消失问题。

#### 生成对抗网络（GAN）

生成对抗网络是一种由生成器和判别器组成的神经网络架构，其主要包括以下组成部分：

1. **生成器（Generator）**：生成器通过随机噪声生成数据，目标是生成尽可能真实的数据。
2. **判别器（Discriminator）**：判别器用于区分生成器和真实数据的差异，目标是判断数据是真实还是生成的。

生成对抗网络的工作原理如下：

1. **生成器生成数据**：生成器通过随机噪声生成数据。
2. **判别器判断数据**：判别器判断生成器和真实数据的差异。
3. **生成器和判别器的优化**：生成器和判别器通过对抗训练，不断优化，最终生成高质量的数据。

生成对抗网络在图像生成、视频生成和语音合成等任务中具有广泛应用，其优点在于能够生成高质量的数据。

综上所述，不同的神经网络架构具有不同的应用场景和特点。前馈神经网络适用于分类和回归任务，卷积神经网络适用于图像处理，循环神经网络和长短期记忆网络适用于序列数据处理，生成对抗网络适用于数据生成任务。选择合适的神经网络架构，是解决实际问题的重要一步。接下来，我们将进一步探讨神经网络的学习算法和数学原理。

### 神经网络学习算法

神经网络（Neural Networks）的学习过程是通过调整网络中的权重和偏置来优化模型的性能。这一过程依赖于一系列学习算法，其中最常用的方法是反向传播算法（Backpropagation Algorithm）。此外，还有梯度下降法（Gradient Descent）和深度学习优化算法，如Adam优化器、RMSProp优化器和Adagrad优化器等。以下将逐步解释这些学习算法的基本原理、推导与实现过程，并探讨如何优化反向传播算法。

#### 反向传播算法（Backpropagation Algorithm）

反向传播算法是一种用于多层神经网络训练的学习算法，其核心思想是通过反向传播误差来更新网络中的权重和偏置。以下是反向传播算法的基本步骤：

1. **前向传播（Forward Propagation）**：输入数据通过神经网络，从输入层传递到输出层，计算每个神经元的输出值。
2. **计算误差（Calculate Error）**：根据输出值和实际目标值，计算每个神经元的误差。
3. **后向传播（Backward Propagation）**：从输出层开始，将误差反向传播到输入层，计算每个权重和偏置的梯度。
4. **权重更新（Weight Update）**：根据梯度更新网络中的权重和偏置。

##### 反向传播算法的基本原理

反向传播算法的基本原理可以概括为以下几点：

1. **误差计算**：通过比较实际输出和预期输出，计算误差。
2. **梯度计算**：计算每个权重和偏置的梯度，即误差关于每个参数的偏导数。
3. **权重更新**：根据梯度更新权重和偏置，以最小化误差。

##### 反向传播算法的推导与实现

反向传播算法的推导主要依赖于链式法则（Chain Rule）和微分基本公式。以下是使用伪代码描述反向传播算法的推导过程和实现方法：

```python
# 输入数据
x = [x1, x2, ..., xn]
# 权重和偏置
w = [w1, w2, ..., wn]
b = [b1, b2, ..., bn]
# 激活函数
activation_function(z):
    return sigmoid(z)

# 前向传播
z = w * x + b
y = activation_function(z)

# 计算误差
error = y - target

# 计算梯度
gradient = [dy/dz * dz/dw, dy/dz * dz/db]

# 权重更新
w = w - learning_rate * gradient
b = b - learning_rate * gradient
```

在这个伪代码中，`sigmoid`函数是激活函数，`target`是预期输出。通过链式法则，可以计算误差关于权重和偏置的梯度。然后，根据梯度进行权重更新。

##### 优化反向传播算法

反向传播算法的优化主要包括以下几个方面：

1. **动量（Momentum）**：动量可以通过加速之前的梯度更新，减少收敛时间。
2. **自适应学习率（Adaptive Learning Rate）**：如Adam优化器，通过动态调整学习率，提高收敛速度和稳定性。
3. **批量归一化（Batch Normalization）**：通过对批量数据进行标准化，减少内部协变量转移，提高训练稳定性。
4. **dropout**：通过随机丢弃部分神经元，防止过拟合。

#### 梯度下降法（Gradient Descent）

梯度下降法是一种最常用的优化算法，其基本思想是通过迭代更新参数，以最小化损失函数。以下是梯度下降法的基本原理和实现：

1. **基本原理**：梯度下降法通过计算损失函数关于参数的梯度，更新参数。
2. **实现**：每次迭代，根据梯度方向和步长，更新参数。

##### 梯度下降法的基本原理

梯度下降法的基本原理如下：

1. **损失函数**：损失函数用于衡量预测值与实际值之间的差距，如均方误差（Mean Squared Error, MSE）。
2. **梯度计算**：计算损失函数关于参数的梯度。
3. **参数更新**：根据梯度方向和步长，更新参数。

##### 随机梯度下降（Stochastic Gradient Descent, SGD）

随机梯度下降是梯度下降法的一种变体，其基本思想是每次迭代只使用一个样本的梯度进行更新。以下是随机梯度下降的基本原理和实现：

1. **基本原理**：每次迭代使用一个样本的梯度进行更新，以加速收敛。
2. **实现**：从数据集中随机选择一个样本，计算其梯度，然后更新参数。

##### 批量梯度下降（Batch Gradient Descent）

批量梯度下降是梯度下降法的一种变体，其基本思想是每次迭代使用整个数据集的梯度进行更新。以下是批量梯度下降的基本原理和实现：

1. **基本原理**：每次迭代使用整个数据集的梯度进行更新，以减少方差。
2. **实现**：计算整个数据集的梯度，然后更新参数。

#### 深度学习优化算法

深度学习优化算法是一类专门用于优化神经网络训练过程的算法，其旨在提高训练速度和模型性能。以下是几种常用的深度学习优化算法：

1. **Adam优化器（Adam Optimizer）**：Adam优化器结合了AdaGrad和RMSProp的优点，通过动态调整学习率，提高训练速度和稳定性。
2. **RMSProp优化器（RMSProp Optimizer）**：RMSProp优化器通过计算梯度历史值的指数加权平均，动态调整学习率，减少振荡。
3. **Adagrad优化器（Adagrad Optimizer）**：Adagrad优化器通过计算梯度历史值的平方和，动态调整学习率，适用于稀疏数据。

##### Adam优化器

Adam优化器的基本原理如下：

1. **计算一阶矩估计（Mean）**：计算梯度的均值。
2. **计算二阶矩估计（Variance）**：计算梯度的方差。
3. **更新参数**：根据一阶矩估计和二阶矩估计，更新参数。

##### RMSProp优化器

RMSProp优化器的基本原理如下：

1. **计算梯度历史值的指数加权平均**：使用指数加权平均计算梯度历史值。
2. **更新参数**：根据梯度历史值的指数加权平均，更新参数。

##### Adagrad优化器

Adagrad优化器的基本原理如下：

1. **计算梯度历史值的平方和**：使用平方和计算梯度历史值。
2. **更新参数**：根据梯度历史值的平方和，更新参数。

通过这些优化算法，可以有效地提高神经网络训练的速度和模型性能。在实际应用中，选择合适的优化算法，可以大幅提升训练效果。

综上所述，神经网络的学习算法包括反向传播算法、梯度下降法以及深度学习优化算法。这些算法通过不断调整网络中的权重和偏置，优化模型性能，从而实现复杂任务。接下来，我们将进一步探讨神经网络中的数学原理。

### 神经网络中的数学原理

神经网络（Neural Networks）作为一种强大的机器学习模型，其高效运作离不开深厚的数学理论基础。以下是神经网络中涉及的几个关键数学领域：概率论基础、拉格朗日乘数法以及线性代数基础。

#### 概率论基础

概率论在神经网络中扮演着至关重要的角色，尤其是在误差校正、分类问题以及训练过程中。以下是一些核心概率论概念：

1. **随机变量（Random Variable）**：随机变量是定义在样本空间上的函数，用于描述可能的结果。
2. **概率分布（Probability Distribution）**：概率分布用于描述随机变量取值的概率。
3. **期望（Expected Value）**：期望是随机变量的平均值，用于衡量随机变量的中心趋势。
4. **方差（Variance）**：方差是随机变量期望的平方差，用于衡量随机变量的离散程度。

在神经网络中，概率论广泛应用于以下几个方面：

1. **误差校正**：在训练过程中，通过计算输出值与实际目标值之间的误差，调整网络权重和偏置，以减少误差。
2. **分类问题**：在分类任务中，通过计算每个类别的概率分布，确定最可能的类别。
3. **训练过程**：在训练过程中，使用概率论的方法来评估模型的性能，并进行参数调整。

#### 贝叶斯定理（Bayes' Theorem）

贝叶斯定理是概率论中的一个重要公式，它描述了后验概率与先验概率之间的关系。在神经网络中，贝叶斯定理可以用于误差校正和分类问题。以下是贝叶斯定理的基本形式：

\[ P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)} \]

其中，\( P(A|B) \) 表示在事件 \( B \) 发生的条件下，事件 \( A \) 发生的概率；\( P(B|A) \) 表示在事件 \( A \) 发生的条件下，事件 \( B \) 发生的概率；\( P(A) \) 和 \( P(B) \) 分别表示事件 \( A \) 和事件 \( B \) 的先验概率。

在神经网络中，贝叶斯定理的应用包括：

1. **误差校正**：通过更新先验概率，调整网络权重和偏置，以减少误差。
2. **分类问题**：通过计算后验概率，确定最可能的类别。

#### 最大似然估计（Maximum Likelihood Estimation, MLE）

最大似然估计是一种用于估计模型参数的方法，其基本思想是找到一组参数，使得观测数据的概率最大。在神经网络中，MLE可以用于训练模型，通过最大化训练数据的似然函数，确定网络中的权重和偏置。以下是MLE的基本原理：

1. **似然函数（Likelihood Function）**：似然函数是模型参数关于观测数据的概率密度函数。
2. **参数估计**：通过求解似然函数的最大值，确定模型参数。

在神经网络中，MLE的应用包括：

1. **权重和偏置初始化**：通过MLE方法初始化网络参数，以提高训练效果。
2. **模型评估**：通过MLE方法评估模型的性能，进行模型选择。

#### 拉格朗日乘数法（Lagrange Multiplier Method）

拉格朗日乘数法是一种用于解决约束优化问题的数学方法，其基本思想是通过引入拉格朗日乘子，将约束优化问题转化为无约束优化问题。在神经网络中，拉格朗日乘数法可以用于处理权重和偏置的约束优化问题。

拉格朗日乘数法的基本原理如下：

1. **构建拉格朗日函数**：拉格朗日函数是目标函数与约束条件的组合。
2. **求解拉格朗日方程**：通过求解拉格朗日方程，找到最优解。

在神经网络中，拉格朗日乘数法的应用包括：

1. **权重和偏置约束**：通过引入拉格朗日乘子，处理权重和偏置的约束，以提高模型的泛化能力。
2. **正则化**：通过拉格朗日乘数法，实现L1正则化和L2正则化，防止过拟合。

#### 线性代数基础

线性代数是神经网络中的重要数学工具，用于处理矩阵和向量运算、特征值和特征向量等。以下是线性代数在神经网络中的几个关键应用：

1. **矩阵和向量运算**：用于表示和操作神经网络中的权重和偏置，如矩阵乘法、向量加法等。
2. **特征值和特征向量**：用于分析神经网络中的权重矩阵，提取关键特征，如特征值和特征向量的计算、特征分解等。

#### 模型构建

接下来，构建用于图像分类的神经网络模型。以下是一个简单的卷积神经网络（CNN）模型：

1. **定义模型**：
   ```python
   class CNNModel(nn.Module):
       def __init__(self):
           super(CNNModel, self).__init__()
           self.conv1 = nn.Conv2d(1, 32, 5)
           self.fc1 = nn.Linear(32 * 14 * 14, 128)
           self.fc2 = nn.Linear(128, 10)

       def forward(self, x):
           x = F.relu(self.conv1(x))
           x = F.max_pool2d(x, 2)
           x = F.relu(self.fc1(x.view(-1, 32 * 14 * 14)))
           x = self.fc2(x)
           return x

   model = CNNModel()
   ```

2. **模型架构**：该模型包括一个卷积层、一个全连接层和一个输出层。卷积层用于提取图像特征，全连接层用于分类，输出层使用softmax函数计算每个类别的概率。

   ```python
   class RNNModel(nn.Module):
       def __init__(self, vocab_size, embed_dim, hidden_dim, output_dim, num_layers, bidirectional, dropout):
           super(RNNModel, self).__init__()
           self.embedding = nn.Embedding(vocab_size, embed_dim)
           self.rnn = nn.RNN(embed_dim, hidden_dim, num_layers=num_layers, bidirectional=bidirectional, dropout=dropout)
           self.fc = nn.Linear(hidden_dim * 2, output_dim)
           self.dropout = nn.Dropout(dropout)

           embedded = self.dropout(self.embedding(text))
           packed_embedded = nn.utils.rnn.pack_padded_sequence(embedded, text_lengths, batch_first=True)
           packed_output, (hidden, cell) = self.rnn(packed_embedded)
           hidden = self.dropout(torch.cat((hidden[-2,:,:], hidden[-1,:,:]), dim=1))
           return self.fc(hidden.squeeze(0))
   ```

以下是神经网络学习中常用的数学公式，使用LaTeX格式书写：

1. **损失函数**：

   \[ L(\theta) = -\frac{1}{m} \sum_{i=1}^{m} y^{(i)} \log(a^{(i)}) + (1 - y^{(i)}) \log(1 - a^{(i)}) \]

2. **梯度下降**：

   \[ \theta_j := \theta_j - \alpha \frac{\partial L}{\partial \theta_j} \]

3. **反向传播**：

   \[ \frac{\partial L}{\partial z^{(l)}_{ij}} = a^{(l-1)}_i \cdot \frac{\partial a^{(l)}_j}{\partial z^{(l)}_{ij}} \]

4. **ReLU激活函数**：

   \[ a^{(l)}_j = \max(0, z^{(l)}_{ij}) \]

5. **sigmoid激活函数**：

   \[ a^{(l)}_j = \frac{1}{1 + e^{-z^{(l)}_{ij}}} \]
