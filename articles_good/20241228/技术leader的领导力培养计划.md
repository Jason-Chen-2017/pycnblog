#### 系统核心实现源代码

以下是一个简单的示例，展示了如何使用Python实现一个领导力培养平台的核心功能。

```python
# 领导力培养平台示例代码

# 导入必要的库
import pymysql
from pymysql.cursors import DictCursor

# 数据库配置
db_config = {
    'host': 'localhost',
    'user': 'root',
    'password': 'password',
    'db': 'leadership_platform',
}

# 连接数据库
connection = pymysql.connect(**db_config)
cursor = connection.cursor(DictCursor)

# 创建表格
create_table_sql = """
CREATE TABLE IF NOT EXISTS users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
"""
cursor.execute(create_table_sql)

# 用户注册
def register_user(name, email, password):
    insert_user_sql = """
    INSERT INTO users (name, email, password)
    VALUES (%s, %s, %s);
    """
    cursor.execute(insert_user_sql, (name, email, password))
    connection.commit()
    return cursor.lastrowid

# 用户登录
def login_user(email, password):
    select_user_sql = """
    SELECT * FROM users WHERE email = %s AND password = %s;
    """
    cursor.execute(select_user_sql, (email, password))
    user = cursor.fetchone()
    return user

# 关闭数据库连接
def close_connection():
    cursor.close()
    connection.close()

# 测试代码
if __name__ == '__main__':
    # 创建用户
    user_id = register_user('John Doe', 'johndoe@example.com', 'password123')
    print(f'User {user_id} registered successfully.')

    # 登录用户
    user = login_user('johndoe@example.com', 'password123')
    if user:
        print(f'User {user["id"]} logged in successfully.')
    else:
        print('Invalid email or password.')

    # 关闭连接
    close_connection()
```

1. **数据库配置**：首先，我们定义了数据库的配置信息，包括主机地址、用户名、密码和数据库名称。
2. **连接数据库**：使用`pymysql`库连接到MySQL数据库，并使用`DictCursor`获取结果以更方便地处理数据。
3. **创建表格**：定义一个名为`users`的表格，用于存储用户信息，包括用户ID、姓名、电子邮件和密码。
4. **用户注册**：定义一个`register_user`函数，用于处理用户注册请求。该函数接受用户名、电子邮件和密码作为参数，并将这些信息插入到`users`表格中。
5. **用户登录**：定义一个`login_user`函数，用于处理用户登录请求。该函数接受电子邮件和密码作为参数，并在`users`表格中查找匹配的记录。
6. **关闭数据库连接**：定义一个`close_connection`函数，用于关闭数据库连接。
