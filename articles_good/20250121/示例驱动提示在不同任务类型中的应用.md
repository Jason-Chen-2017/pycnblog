#### 3.3.1 示例驱动的文本分类案例1

**案例背景：** 
假设我们有一个新闻分类任务，需要将新闻文本自动分类为“体育”、“政治”和“财经”三类。我们收集了1000篇新闻文本，并预先将其标注好类别。

**步骤1：数据预处理**
- **清洗文本：** 去除HTML标签、特殊字符和停用词。
- **分词：** 将文本分割成词语。

```python
import re
from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize

def clean_text(text):
    text = re.sub(r'<.*?>', '', text)  # 去除HTML标签
    text = re.sub(r'\W+', ' ', text)  # 去除特殊字符
    text = text.lower()  # 转小写
    tokens = word_tokenize(text)  # 分词
    tokens = [token for token in tokens if token not in stopwords.words('english')]  # 去停用词
    return ' '.join(tokens)

# 示例文本
text = "Apple Inc. has announced a new product."
cleaned_text = clean_text(text)
```

**步骤2：特征提取**
- **词频-逆文档频率（TF-IDF）：** 提取文本的TF-IDF特征向量。

```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform([cleaned_text])
```

**步骤3：模型训练**
- **支持向量机（SVM）：** 使用SVM进行分类。

```python
from sklearn.svm import SVC

model = SVC(kernel='linear')
model.fit(X, labels)  # labels为已标注的类别标签
```

**步骤4：分类预测**
- **新文本分类：** 对新文本进行分类预测。

```python
new_text = "The new iPhone is expected to launch next month."
cleaned_new_text = clean_text(new_text)
X_new = vectorizer.transform([cleaned_new_text])
predicted_category = model.predict(X_new)[0]
print(f"Predicted category: {predicted_category}")
```

**结果：** 新文本被预测为“财经”类别，符合实际新闻内容。
