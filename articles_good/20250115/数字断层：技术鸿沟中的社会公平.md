数字鸿沟的主要表现形式包括：

1. **接入鸿沟**：指不同社会群体在互联网接入和设备拥有率上的差异。
2. **技能鸿沟**：指不同社会群体在信息技术应用技能上的差异。
3. **内容鸿沟**：指不同社会群体在获取和创造数字内容上的差异。
4. **机会鸿沟**：指不同社会群体在利用信息技术获取机会和资源上的差异。

4. **机会获取差异**：不同社会群体在利用信息技术获取机会和资源上的差异。

**社会公平的内涵与衡量**

社会公平是指社会资源分配的合理性，确保每个社会成员都能在同等条件下享有平等的机会和权益。社会公平的内涵主要包括：

1. **机会公平**：每个社会成员都有平等的机会获得教育和培训，提高自身技能和素质。
2. **结果公平**：社会资源的分配能够确保不同社会群体在经济发展和社会进步中受益。
3. **程序公平**：社会决策和资源分配的程序是公正的，没有歧视和偏见。

社会公平的衡量标准包括：

1. **收入分配公平**：不同社会群体的收入差距是否合理。
2. **教育公平**：教育资源的分配是否均衡，是否每个社会成员都能获得良好的教育。
3. **社会福利公平**：社会保障体系的覆盖面和保障水平是否公平。

model.fit(X_train, y_train)

# 预测
y_pred = model.predict(X_test)

# 评估模型
mse = mean_squared_error(y_test, y_pred)
print('均方误差:', mse)

# 可视化
