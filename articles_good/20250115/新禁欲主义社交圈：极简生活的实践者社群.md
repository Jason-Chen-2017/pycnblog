### 第2章：核心概念与联系

### 2.1 新禁欲主义概念

新禁欲主义（New Asceticism）起源于对现代物质主义和社会消费文化的批判，强调精神层面的追求和内心的宁静。其核心思想是减少物质追求和社交活动，以追求更深层次的精神满足和自我实现。新禁欲主义不同于传统的禁欲主义，它不是简单地抑制欲望，而是通过有意识地减少不必要的物质消费和社会交往，达到一种内在的平和与专注。

在新禁欲主义社交圈中，成员们往往追求以下目标：

- **精神追求**：通过冥想、阅读、艺术创作等方式，提升精神层面的修养和深度。
- **内心平静**：通过减少外界的干扰和刺激，培养内心的平静和自控能力。
- **简化生活**：减少物质财富和社交活动，专注于个人的内在成长和需求。

### 2.2 社交圈概念

社交圈（Social Circle）是指一群具有共同兴趣、价值观或目标的人组成的互动网络。在社交圈中，成员之间通过分享信息、情感和资源，实现个人成长和社会连接。社交圈的形成通常基于共同的爱好、职业、文化背景或生活目标。

在新禁欲主义社交圈中，成员们通常具有以下特征：

- **共同的价值观**：强调精神追求、内在成长和简约生活。
- **互动形式**：通过线上或线下活动，如读书会、冥想小组、艺术展览等，加强成员之间的互动和联系。
- **长期关系**：社交圈成员往往建立深厚的信任和友谊，形成长期稳定的社交网络。

### 2.3 极简生活概念

极简生活（Minimalism）是一种追求物质简化、精神富足的生活方式。极简主义者认为，过度的物质消费会带来生活的负担和心理压力，而通过简化物质生活，专注于个人的内在需求和成长，可以提升生活质量，减少焦虑和压力。

极简生活的核心要素包括：

- **简化物质**：减少不必要的物品和消费，只保留对个人有价值的物品。
- **聚焦内在**：通过冥想、阅读、艺术创作等内在活动，提升精神层面的修养。
- **减少干扰**：减少外界的干扰和刺激，培养内心的平静和自控能力。

### 2.4 三者联系

新禁欲主义、社交圈和极简生活之间存在密切的联系，它们共同构成了一个多维度的社交和实践体系。

- **精神追求**：新禁欲主义和极简生活都强调精神层面的追求和内心平静，这种追求需要通过社交圈中的互动和分享来实现。

### 3.3 算法数学模型

为了更好地理解算法，我们需要引入一些数学模型。以下是算法中用到的几个关键数学模型：

1. **社交网络相似度模型**：用于评估社交圈成员之间的相似度。假设有n个成员，每个成员有m个属性，相似度可以用余弦相似度公式表示：
   $$\text{similarity}(i, j) = \frac{\text{dot}(x_i, x_j)}{\|\text{vec}(x_i)\|\|\text{vec}(x_j)\|}$$
   其中，$x_i$和$x_j$分别是成员i和成员j的属性向量，$\text{dot}$表示点积，$\|\text{vec}(x_i)\|$表示向量$x_i$的欧几里得范数。

2. **社交活动价值模型**：用于评估社交活动的价值。假设社交活动有k个维度，每个维度的重要性权重为$\lambda_1, \lambda_2, ..., \lambda_k$，那么社交活动i的价值可以表示为：
   $$\text{value}(i) = \sum_{j=1}^{k} \lambda_j \cdot \text{attribute}_j(i)$$
   其中，$\text{attribute}_j(i)$是社交活动i在第j个维度上的属性值。

3. **社交策略优化模型**：用于优化社交策略，最大化社交活动的总体价值。假设社交圈有m个成员，社交活动方案为矩阵$S \in \{0, 1\}^{m \times k}$，其中$S_{ij}=1$表示成员i参加活动j，$S_{ij}=0$表示成员i不参加活动j。社交策略优化的目标函数为：
   $$\text{maximize} \sum_{i=1}^{m} \sum_{j=1}^{k} S_{ij} \cdot \text{value}(j)$$
   约束条件为：
   $$S_{ij} \in \{0, 1\}, \forall i, j$$

### 3.4 算法公式

为了实现上述算法，我们需要使用以下公式：

1. **成员兴趣匹配公式**：
   $$\text{match}(i, j) = \text{similarity}(i, j) \cdot \text{interest\_align}(i, j)$$
   其中，$\text{interest\_align}(i, j)$表示成员i和成员j在兴趣上的对齐度。

2. **社交活动价值计算公式**：
   $$\text{value}(i) = \sum_{j=1}^{k} \lambda_j \cdot \text{attribute}_j(i)$$

3. **社交策略优化公式**：
   $$\text{maximize} \sum_{i=1}^{m} \sum_{j=1}^{k} S_{ij} \cdot \text{value}(j)$$
   约束条件为：
   $$S_{ij} \in \{0, 1\}, \forall i, j$$

### 4.2 数学公式讲解

以下是本章中将用到的关键数学公式：

1. **相似度公式**：用于计算成员之间的相似度。
   $$\text{similarity}(i, j) = \frac{\text{dot}(x_i, x_j)}{\|\text{vec}(x_i)\|\|\text{vec}(x_j)\|}$$
   其中，$x_i$和$x_j$是成员i和成员j的属性向量，$\text{dot}$表示点积，$\|\text{vec}(x_i)\|$表示向量$x_i$的欧几里得范数。

2. **活动价值公式**：用于计算社交活动的价值。
   $$\text{value}(i) = \sum_{j=1}^{k} \lambda_j \cdot \text{attribute}_j(i)$$
   其中，$\lambda_j$是第j个维度的权重，$\text{attribute}_j(i)$是成员i在第j个维度上的属性值。

3. **优化模型公式**：用于优化社交策略。
   $$\text{maximize} \sum_{i=1}^{m} \sum_{j=1}^{k} S_{ij} \cdot \text{value}(j)$$
   约束条件为：
   $$S_{ij} \in \{0, 1\}, \forall i, j$$
   其中，$S_{ij}$表示成员i是否参加活动j。

### 4.3 举例说明

为了更好地理解这些数学公式，我们将通过一个具体例子进行说明。

**例子：**

假设有5个成员，每个成员有3个兴趣维度（读书、运动、艺术）。我们有以下数据：

| 成员 | 读书 | 运动 | 艺术 |
|------|------|------|------|
| A    | 0.8  | 0.2  | 0.1  |
| B    | 0.3  | 0.6  | 0.1  |
| C    | 0.5  | 0.4  | 0.1  |
| D    | 0.6  | 0.3  | 0.1  |
| E    | 0.2  | 0.8  | 0.1  |

**步骤1：计算相似度**

使用相似度公式计算成员之间的相似度：

$$\text{similarity}(A, B) = \frac{0.8 \times 0.3 + 0.2 \times 0.6 + 0.1 \times 0.1}{\sqrt{0.8^2 + 0.2^2 + 0.1^2} \times \sqrt{0.3^2 + 0.6^2 + 0.1^2}} = \frac{0.24}{\sqrt{0.42} \times \sqrt{0.37}} \approx 0.45$$

**步骤2：计算活动价值**

假设活动有3个维度（读书活动、运动活动、艺术活动），权重分别为$\lambda_1 = 0.4, \lambda_2 = 0.3, \lambda_3 = 0.3$。计算每个活动的价值：

$$\text{value}(读书活动) = 0.4 \times 0.8 + 0.3 \times 0.2 + 0.3 \times 0.1 = 0.46$$
$$\text{value}(运动活动) = 0.4 \times 0.2 + 0.3 \times 0.6 + 0.3 \times 0.1 = 0.29$$
$$\text{value}(艺术活动) = 0.4 \times 0.1 + 0.3 \times 0.1 + 0.3 \times 0.8 = 0.29$$

**步骤3：优化社交策略**

使用优化模型公式，最大化社交活动的总体价值：

$$\text{maximize} \sum_{i=1}^{5} \sum_{j=1}^{3} S_{ij} \cdot \text{value}(j)$$

假设我们选择的活动方案为：成员A、B、C参加读书活动，成员D、E参加运动活动。计算总价值：

$$\text{total value} = 0.46 \times 3 + 0.29 \times 2 = 1.49$$

通过以上步骤，我们可以看到如何使用数学模型和公式来优化社交策略，实现新禁欲主义社交圈和极简生活实践者社群的目标。

**数据库模块（database.py）：**

```python
import sqlite3

class Database:
    def __init__(self):
        self.connection = sqlite3.connect("social_circle.db")
        self.cursor = self.connection.cursor()

    def connect(self):
        if self.connection:
            self.cursor.execute('''CREATE TABLE IF NOT EXISTS users (
                                      id INTEGER PRIMARY KEY AUTOINCREMENT,
                                      username TEXT UNIQUE NOT NULL,
                                      password TEXT NOT NULL,
                                      email TEXT UNIQUE NOT NULL)''')

            self.cursor.execute('''CREATE TABLE IF NOT EXISTS circles (
                                      id INTEGER PRIMARY KEY AUTOINCREMENT,
                                      name TEXT UNIQUE NOT NULL,
                                      description TEXT,
                                      creator TEXT NOT NULL)''')

            self.cursor.execute('''CREATE TABLE IF NOT EXISTS activities (
                                      id INTEGER PRIMARY KEY AUTOINCREMENT,
                                      name TEXT UNIQUE NOT NULL,
                                      description TEXT,
                                      circle INTEGER NOT NULL,
                                      time TEXT NOT NULL,
                                      location TEXT,
                                      FOREIGN KEY (circle) REFERENCES circles (id))''')

            self.cursor.execute('''CREATE TABLE IF NOT EXISTS circle_members (
                                      id INTEGER PRIMARY KEY AUTOINCREMENT,
                                      user TEXT NOT NULL,
                                      circle INTEGER NOT NULL,
                                      FOREIGN KEY (user) REFERENCES users (username),
                                      FOREIGN KEY (circle) REFERENCES circles (id))''')

            self.cursor.execute('''CREATE TABLE IF NOT EXISTS activity_attendance (
                                      id INTEGER PRIMARY KEY AUTOINCREMENT,
                                      user TEXT NOT NULL,
                                      activity INTEGER NOT NULL,
                                      FOREIGN KEY (user) REFERENCES users (username),
                                      FOREIGN KEY (activity) REFERENCES activities (id))''')

            self.connection.commit()

    def execute(self, query, params=None):
        if params:
            self.cursor.execute(query, params)
        else:
            self.cursor.execute(query)

    def commit(self):
        self.connection.commit()

    def close(self):
        self.connection.close()
```
