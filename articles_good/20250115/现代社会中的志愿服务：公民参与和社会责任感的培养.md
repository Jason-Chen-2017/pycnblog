**数学模型与公式**：

在志愿服务的评估中，我们可以使用参与度评分模型（Participation Score Model）来衡量公民的参与程度。公式如下：

$$
P_S = \frac{H_V}{T_H} \times 100
$$

其中：
- $P_S$ 是参与度评分（Participation Score）。
- $H_V$ 是志愿者在特定时期内参与志愿服务的总小时数（Hours Volunteered）。
- $T_H$ 是志愿者可分配的总小时数（Total Hours）。

**举例说明**：

假设一位志愿者John Doe在一个月内参与了10小时的志愿服务，而他每月可分配的时间是40小时。根据上述公式，他的参与度评分为：

$$
P_S = \frac{10}{40} \times 100 = 25\%
$$

这意味着John Doe在该月的志愿服务参与度为25%。

```python
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql+pymysql://username:password@localhost/uvsp'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100))
    email = db.Column(db.String(100))

class Service(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100))
    description = db.Column(db.String(255))

@app.route('/login', methods=['POST'])
def login():
    email = request.form['email']
    password = request.form['password']
    user = User.query.filter_by(email=email).first()
    if user and user.email == email:
        return jsonify({'status': 'success', 'message': '登录成功'})
    else:
        return jsonify({'status': 'error', 'message': '登录失败'})

@app.route('/services', methods=['GET'])
def services():
    services = Service.query.all()
    return jsonify({'services': [service.name for service in services]})

@app.route('/volunteer', methods=['POST'])
def volunteer():
    user_id = request.form['user_id']
    service_id = request.form['service_id']
    user = User.query.get(user_id)
    service = Service.query.get(service_id)
    if user and service:
        # 在数据库中记录参与时间
        # 这里可以添加记录逻辑
        return jsonify({'status': 'success', 'message': '参与成功'})
    else:
        return jsonify({'status': 'error', 'message': '参与失败'})

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```

- `/login` 接口用于用户登录验证。
