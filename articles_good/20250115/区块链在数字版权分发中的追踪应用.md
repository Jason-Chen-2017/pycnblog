**实现过程**：

1. **版权信息上链**：
   - 步骤一：音乐公司首先将音乐作品的版权信息（如歌曲名称、创作者、版权期限等）上传到区块链平台。

3. **版权信息查询**：
   - 步骤一：版权所有者或其他授权用户可以通过区块链平台查询音乐作品的版权信息。

通过区块链技术，音乐公司实现了音乐版权信息的透明、安全、不可篡改的追踪。版权所有者可以实时了解作品的使用情况，侵权行为得到了有效遏制，音乐版权的管理效率显著提高。

```python

from web3 import Web3

# 连接到区块链节点

    return hashlib.sha256(info.encode('utf-8')).hexdigest()
```
