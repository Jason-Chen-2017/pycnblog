### 1.1.2 格雷厄姆特价股票策略的核心思想

格雷厄姆建议投资者关注那些市盈率、市净率等估值指标远低于行业平均水平的股票。这些股票通常被视为“特价股票”，因为它们的价格低于其内在价值。通过计算安全边际（内在价值 - 市场价格），投资者可以识别出具有较高投资价值的股票。

### 1.1.3 市场流动性对股票估值的影响

市场流动性是指市场中买卖股票的交易量和交易速度。高流动性市场中，股票价格通常更接近其内在价值，而低流动性市场中，股票价格可能偏离其内在价值。市场流动性不足可能导致股票低估，从而为格雷厄姆策略提供更多的机会。

## 1.2 市场流动性结构的层次分析

### 1.2.1 整体市场流动性分析

整体市场流动性反映了整个市场的交易活跃程度。高流动性市场通常意味着投资者更容易以合理的价格买卖股票，而低流动性市场可能导致交易成本增加。

### 1.2.2 个股流动性分析

个股流动性是指特定股票的交易活跃程度。流动性高的个股通常具有较高的交易量和较小的买卖价差，而流动性低的个股则可能具有较大的买卖价差和较低的交易量。

### 1.2.3 市场流动性微观结构分析

市场流动性微观结构涉及订单簿、买卖价差、成交额等微观指标。这些指标可以帮助投资者更好地理解市场流动性对股票价格的影响。

## 1.3 格雷厄姆策略与市场流动性结构的关联

### 1.3.1 格雷厄姆策略在高流动性市场中的表现

在高流动性市场中，格雷厄姆策略的效果可能受到限制，因为股票价格通常接近其内在价值，低估的机会较少。然而，在市场波动加剧时，格雷厄姆策略仍能通过安全边际实现超额收益。

### 1.3.2 格雷厄姆策略在低流动性市场中的表现

在低流动性市场中，格雷厄姆策略通常表现较好。由于市场流动性不足，股票价格可能大幅低于其内在价值，为投资者提供了更多的特价股票机会。

### 1.3.3 市场流动性对策略效果的调节作用

# 第3章: 格雷厄姆特价股票策略的理论基础

## 3.1 格雷厄姆选股标准的数学模型

### 3.1.1 市盈率（P/E）的计算与应用

市盈率是衡量股票估值的重要指标之一，计算公式为：

$$
\text{市盈率} = \frac{\text{股票价格}}{\text{每股净利润}}
$$

格雷厄姆建议投资者关注那些市盈率低于行业平均水平的股票。

### 3.1.2 市净率（P/B）的计算与应用

市净率是另一个衡量股票估值的指标，计算公式为：

$$
\text{市净率} = \frac{\text{股票价格}}{\text{每股净资产}}
$$

格雷厄姆认为市净率低于行业平均水平的股票具有较高的投资价值。

### 3.1.3 股息率的计算与应用

股息率是衡量股票收益能力的指标，计算公式为：

$$
\text{股息率} = \frac{\text{每股股息}}{\text{股票价格}}
$$

格雷厄姆建议投资者关注那些股息率稳定的股票。

## 3.2 安全边际的概念与计算

### 3.2.1 安全边际的定义

安全边际是指股票的内在价值与市场价格之间的差额。计算公式为：

$$
\text{安全边际} = \text{内在价值} - \text{市场价格}
$$

### 3.2.2 安全边际的计算公式

格雷厄姆认为，股票的内在价值可以通过基本面分析估算，而市场价格则反映了市场的短期情绪。通过计算安全边际，投资者可以识别出具有较高投资价值的股票。

def generate_signals(df):
    # 计算市盈率和市净率
    df['PE'] = df['price'] / df['eps']
    df['PB'] = df['price'] / df['book_value']
    # 生成信号
    signals = []
    for index, row in df.iterrows():
        if row['PE'] < 15 and row['PB'] < 1.5:
            signals.append('buy')
        else:
            signals.append('hold')
    return signals
```

### 6.3.3 风险管理代码

def manage_risk(signals, positions):
    # 动态调整头寸
    new_positions = []
    for signal, pos in zip(signals, positions):
        if signal == 'buy':
            new_positions.append(pos * 1.5)
        else:
            new_positions.append(pos)
    return new_positions
```
