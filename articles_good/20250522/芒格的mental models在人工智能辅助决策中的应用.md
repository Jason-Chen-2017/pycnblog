# 第1章: 芒格的"mental models"核心概念

## 1.1 芒格思维模型的定义与特点

### 1.1.1 芒格思维模型的定义  
芒格思维模型是一种基于多元思维的决策框架，强调通过多个学科的视角来分析问题，避免单一思维的局限性。

### 1.1.2 芒格思维模型的核心特点  
1. **多元性**：涵盖多个学科的思维方式。
2. **系统性**：强调整体性思考，而非局部优化。
3. **动态性**：能够适应变化和不确定性。

### 1.1.3 芒格思维模型与传统决策模型的对比  
| 特性       | 芒格思维模型              | 传统决策模型              |
|------------|--------------------------|---------------------------|
| 思维方式     | 多元化、系统性             | 单一化、局部性             |
| 适应性       | 高度动态                   | 较低动态                   |

---

## 1.2 芒格思维模型在决策中的作用

### 1.2.1 芒格思维模型在决策中的优势  
1. 提高决策的全面性。
2. 增强决策的准确性。
3. 优化决策的效率性。

### 1.2.2 芒格思维模型在决策中的局限性  
1. 需要大量知识储备。
2. 实施成本较高。

### 1.2.3 芒格思维模型的实际应用场景  
1. 投资决策。
2. 商业策略制定。
3. 医疗诊断。

## 4.4 算法的数学模型与公式

### 4.4.1 概率论基础  
- 条件概率公式：$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

### 4.4.2 逻辑回归模型  
- 逻辑回归的损失函数：$$L = -\sum_{i=1}^{n} [y_i \ln h(x_i) + (1-y_i)\ln(1-h(x_i))]$$
- 其中，$$h(x) = \frac{1}{1 + e^{-\beta x}}$$

### 4.4.3 决策树模型  
- 信息增益公式：$$\text{InfoGain}(D, A) = \text{H}(D) - \text{H}(D|A)$$

### 附录B: 完整代码  
```python
import pandas as pd
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 数据加载
data = pd.read_csv('data.csv')

# 数据预处理
data = data.dropna()
X = data.drop('target', axis=1)
y = data['target']

# 数据划分
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 模型训练
model = DecisionTreeClassifier()
model.fit(X_train, y_train)

# 模型预测
y_pred = model.predict(X_test)

# 模型评估
print(accuracy_score(y_test, y_pred))
```
