# 第二部分: 格雷厄姆策略的核心算法与数学模型

## 第3章: 格雷厄姆策略的数学模型与公式

### 3.1 内在价值的计算公式
- **3.1.1 内在价值的定义与公式**  
  内在价值是格雷厄姆策略的核心，本文将介绍其计算公式：  
  $$ V = \frac{E}{k} $$  
  其中，V为内在价值，E为预期收益，k为折现率。

### 3.2 安全边际的计算与应用
- **3.2.1 安全边际的计算公式**  
  安全边际是内在价值与市场价格的差额：  
  $$ M = V - P $$  
  其中，M为安全边际，V为内在价值，P为市场价格。

### 3.3 市场成熟度对策略参数的影响
- **3.3.1 策略参数的动态调整公式**  
  根据市场成熟度调整折现率：  
  $$ k = k_0 \times (1 + \alpha \times S) $$  
  其中，k为折现率，S为市场成熟度指数，α为调整系数。

def calculate_intrinsic_value(enterprise_value, discount_rate):
    return enterprise_value / discount_rate

def calculate_margin_of_safety(intrinsic_value, market_price):
    return intrinsic_value - market_price

def dynamic_adjustment(discount_rate, market_maturity):
    adjustment_factor = 1 + alpha * market_maturity
    new_discount_rate = discount_rate * adjustment_factor
    return new_discount_rate
