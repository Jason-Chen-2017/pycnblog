# 第一部分: 本杰明·格雷厄姆与价值投资概述

## 第1章: 本杰明·格雷厄姆的生平与投资理念

### 1.1 本杰明·格雷厄姆的生平简介

本杰明·格雷厄姆（Benjamin Graham）是20世纪著名的投资学家，被誉为“价值投资之父”。他出生于1894年，曾在哥伦比亚大学教授证券分析课程，培养了包括沃伦·巴菲特在内的众多投资大师。格雷厄姆的投资理念奠定了价值投资的基础。

### 1.2 价值投资的核心理念

价值投资的核心思想是寻找市场上被低估的股票，即市场价格低于其内在价值的股票。格雷厄姆提出，投资者应关注公司的基本面，尤其是财务数据，以发现这些低估的投资机会。

### 1.3 防御性投资策略的提出

格雷厄姆强调防御性投资策略，即通过分散投资和选择具有安全边际的股票来降低风险。他认为，投资者应避免高风险的投资，而是选择那些具有稳定财务状况和良好前景的公司。

## 第2章: 净净股策略的背景与定义

### 2.1 什么是净净股

净净股是指市场价格低于其净资产价值（NAV）的股票。格雷厄姆认为，当市场价格低于NAV时，该股票具有投资价值，因为市场可能低估了公司的实际价值。

### 2.2 净净股策略的核心思想

净净股策略的核心思想是通过寻找市场价格低于NAV的股票，来实现长期稳定的收益。这种方法强调安全边际，即市场价格与内在价值之间的差距，以降低投资风险。

### 2.3 净净股策略与价值投资的关系

净净股策略是价值投资的一种具体应用。通过关注市场价格与NAV的差异，投资者可以找到被低估的股票，从而实现长期收益。

# 第二部分: 净净股策略的理论基础

## 第3章: 格雷厄姆的内在价值计算方法

### 3.1 内在价值的定义与计算公式

内在价值是指一家公司基于其财务状况和经营前景所具有的真实价值。格雷厄姆提出，内在价值可以通过对公司资产、负债和盈利能力的分析来估算。

$$ V = \frac{E}{(1 + r)^t} $$

其中，\( V \) 是内在价值，\( E \) 是预期收益，\( r \) 是折现率，\( t \) 是时间。

### 3.2 格雷厄姆的内在价值公式

格雷厄姆的内在价值公式强调了安全边际的重要性，即市场价格应远低于内在价值。

### 3.3 内在价值与市场价值的对比分析

市场价值是股票在市场上的交易价格，而内在价值是公司的真实价值。当市场价值低于内在价值时，股票具有投资价值。

## 第4章: 安全边际的数学模型

### 4.1 安全边际的定义

安全边际是指市场价格与内在价值之间的差距。格雷厄姆认为，安全边际越大，投资风险越小。

### 4.2 安全边际的计算公式

$$ S = V - P $$

其中，\( S \) 是安全边际，\( V \) 是内在价值，\( P \) 是市场价格。

### 4.3 安全边际与投资风险的关系

安全边际越大，投资风险越小。因此，投资者应选择具有较大安全边际的股票。

## 第5章: 市场先生理论与投资决策

### 5.1 市场先生的定义

市场先生是格雷厄姆提出的概念，代表市场的情绪和波动。市场先生可能会在短期内影响股票价格，但长期来看，价格会回归其内在价值。

### 5.2 市场先生与投资行为的关系

投资者应避免被市场先生的情绪所左右，而是应根据公司的基本面进行投资决策。

### 5.3 如何利用市场先生理论进行投资决策

投资者应关注市场先生的行为，当市场先生情绪低落时，可能是买入的机会；当市场先生情绪高涨时，可能是卖出的机会。

## 第7章: 净净股投资组合的构建

### 7.1 投资组合构建的原则

1. 分散投资：选择多个不同行业的净净股。
2. 长期持有：避免频繁交易。
3. 定期调整：根据市场变化进行调整。

### 7.2 投资组合构建的步骤

1. 确定投资目标和风险承受能力。
2. 选择具有安全边际的净净股。
3. 分散投资，降低风险。

### 7.3 投资组合的风险分散策略

通过选择不同行业的股票，可以降低投资组合的整体风险。

### 11.2 核心代码实现

```python
import pandas as pd
import numpy as np

def calculate_nav(company_data):
    return company_data['assets'] / company_data['liabilities']

def calculate_margin(nav, price):
    return nav - price

data = pd.read_csv('company_data.csv')
data['nav'] = data.apply(calculate_nav, axis=1)
data['margin'] = data.apply(lambda x: calculate_margin(x['nav'], x['price']), axis=1)
net_net_stocks = data[data['margin'] > 0]
```
