### 第2章：低成本投资的核心概念与原理

#### 2.1 费用率与投资收益的关系

##### 2.1.1 费用率的定义与计算公式
- 费用率的定义：投资产品的管理费、托管费等费用的总和。
- 费用率的计算公式：$$费用率 = \frac{管理费 + 托管费 + 其他费用}{资产规模}$$

##### 2.1.2 费用率对投资收益的影响
- 费用率对投资收益的长期影响：$$最终收益 = 初始资金 \times (1 + 收益率 - 费用率)^n$$，其中n为投资年数。

##### 2.1.3 费用率与投资期限的关系
- 长期投资中，费用率的累积效应更加明显。

#### 2.2 投资组合优化的数学模型

##### 2.2.1 现代投资组合理论（MPT）的简要介绍
- MPT的核心思想：通过资产组合优化，实现收益与风险的最佳平衡。

##### 2.2.2 投资组合优化的数学公式
- 最优化目标：最大化收益，最小化风险。
- 数学公式：$$\min \sigma^2 \quad \text{subject to} \quad \mathbf{w}^T \mathbf{1} = 1$$，其中$$\sigma^2$$为投资组合的方差，$$\mathbf{w}$$为权重向量。

#### 2.3 股票选择与市场时机的权衡

##### 2.3.1 股票选择的数学模型
- 股票选择的优化目标：$$\max \sum_{i=1}^n w_i r_i$$，其中$$w_i$$为第i只股票的权重，$$r_i$$为第i只股票的预期回报率。

##### 2.3.2 市场时机预测的挑战

import numpy as np

# 数据分析
returns = data.pct_change().dropna()

# 投资组合优化
def optimize_portfolio(returns):
    n = returns.shape[1]
    cov_matrix = returns.cov()
    mu = returns.mean()
    # 使用MPT进行优化
    from scipy.optimize import minimize
    def objective(weights):
        return weights.T @ cov_matrix @ weights
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1}]
    bounds = [(0, 1) for _ in range(n)]
    result = minimize(objective, np.ones(n)/n, bounds=bounds, constraints=constraints)
    return result.x

# 风险控制
def risk_control(weights, returns):
    portfolio_variance = weights.T @ returns.cov() @ weights
    return portfolio_variance
