### 第5章: 核心算法實現與優化

#### 5.1 机器学习算法实现
- 5.1.1 線性回歸算法實現
  ```python
  import numpy as np
  def linear_regression(X, y):
      X = np.hstack([np.ones((len(X), 1)), X])
      beta = np.linalg.inv(X.T.dot(X)).dot(X.T.dot(y))
      return beta
  ```
- 5.1.2 支持向量機實現
  ```python
  from sklearn import svm
  def svm_model(X, y):
      clf = svm.SVC(kernel='rbf', gamma='auto')
      clf.fit(X, y)
      return clf
  ```
