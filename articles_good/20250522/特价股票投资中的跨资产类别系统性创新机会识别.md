## 第四章：跨资产类别投资的系统性创新机会识别的数学模型

### 4.1 数学模型

#### 4.1.1 使用CAPM模型进行评估

$$ E(r_i) = r_f + \beta_i (r_m - r_f) $$

其中：
- \( E(r_i) \) 是资产i的预期收益。
- \( r_f \) 是无风险利率。
- \( \beta_i \) 是资产i的贝塔系数。
- \( r_m \) 是市场预期收益。

#### 6.2.1 核心代码实现

```python
import pandas as pd
from sklearn.ensemble import RandomForestRegressor

# 数据加载
data = pd.read_csv('assets.csv')

# 特征选择
features = ['资产类别', '收益']
target = '风险'

# 模型训练
model = RandomForestRegressor()
model.fit(data[features], data[target])

# 预测
new_data = pd.DataFrame({
    '资产类别': ['股票'],
    '收益': [0.1]
})
prediction = model.predict(new_data[features])
print("预测风险:", prediction[0])
```
