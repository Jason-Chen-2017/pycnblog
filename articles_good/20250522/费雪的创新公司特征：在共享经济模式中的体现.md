### 1.2 共享经济模式的定义与特点

#### 1.2.1 共享经济的定义
共享经济是一种基于共享资源使用权的经济模式，通过数字化平台连接供给方和需求方，实现资源的高效利用和共享。

#### 1.2.2 共享经济的核心特征
1. **资源共享**：资源的所有权与使用权分离，通过平台实现资源共享。
2. **平台驱动**：依赖数字化平台进行供需匹配和交易。
3. **灵活参与**：参与者可以根据需求灵活选择参与方式。

#### 1.2.3 共享经济与传统经济模式的区别
1. **所有权与使用权**：共享经济强调使用权而非所有权。
2. **平台角色**：传统经济依赖中间商，而共享经济依赖平台。
3. **参与方式**：共享经济允许个人和企业灵活参与，而传统经济更具刚性。

#### 5.2.2 供需匹配算法的实现
```python
def match_supply_demand(supply, demand):
    matched = []
    for s in supply:
        for d in demand:
            if s['resource'] == d['resource'] and s['location'] == d['location']:
                matched.append(s)
    return matched

supply = [{'resource': 'car', 'location': '北京'}, {'resource': 'bike', 'location': '上海'}]
demand = [{'resource': 'car', 'location': '北京'}, {'resource': 'bike', 'location': '上海'}]

matched_resources = match_supply_demand(supply, demand)
print("匹配的资源:", matched_resources)
```
