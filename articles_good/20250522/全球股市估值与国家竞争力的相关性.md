### 3.2 Python源代码实现

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 示例数据
data = {
    '国家': ['美国', '日本', '德国', '中国'],
    'GDP': [19000, 5000, 4000, 17000],
    '股市估值': [10000, 2000, 3000, 8000]
}

df = pd.DataFrame(data)

# 计算相关系数
correlation = df['GDP'].corr(df['股市估值'])
print(f'相关系数为: {correlation}')

# 可视化
plt.scatter(df['GDP'], df['股市估值'])
plt.xlabel('GDP')
plt.ylabel('股市估值')
plt.title('GDP与股市估值相关性分析')
plt.show()
```

### 3.3 数学模型与公式

- 相关系数公式：
