## 第一部分: 特价股票策略与主题投资概述

### 第1章: 特价股票策略与主题投资的背景介绍

#### 1.1 特价股票策略的核心概念

##### 1.1.1 特价股票的定义与特点
特价股票是指价格低于其内在价值的股票，通常具有较高的安全边际。其特点包括低市盈率、低市净率和高股息率。

##### 1.1.2 特价股票的市场周期
特价股票的表现与市场周期密切相关，通常在市场低迷时出现较多机会，而在市场繁荣时可能表现不佳。

##### 1.1.3 特价股票的优缺点分析
优点：低估值，潜在上涨空间大；缺点：流动性风险，可能需要长期持有。

#### 1.2 主题投资的核心概念

##### 1.2.1 主题投资的定义与特点
主题投资是基于特定主题（如科技、消费）进行投资，关注行业趋势和结构性机会。其特点包括高增长潜力和行业集中。

##### 1.2.2 主题投资的市场周期
主题投资的表现受行业周期和政策影响较大，通常在经济转型期表现突出。

##### 1.2.3 主题投资的优缺点分析
优点：高增长潜力，行业集中；缺点：波动性大，风险较高。

#### 1.3 特价股票与主题投资的结合意义

##### 1.3.1 结合的背景与动机
在市场低迷时，通过特价股票策略寻找低估的主题投资机会，既能控制风险，又能捕捉行业增长潜力。

##### 1.3.2 结合的潜在优势
结合了低估股票的安全性和主题投资的成长性，可能实现风险可控下的超额收益。

##### 1.3.3 结合的挑战与风险
需要平衡估值和成长性，可能导致在市场波动中表现不稳定。

from scipy.optimize import minimize

def optimize_portfolio(weights, returns, risk_free_rate):
    def objective(weights, returns, risk_free_rate):
        return - (weights.T @ returns @ weights) + 0.5 * weights.T @ (weights * (weights.T @ returns @ weights - 2 * risk_free_rate))
    
    result = minimize(objective, weights, args=(returns, risk_free_rate))
    return result.x
