### 3.2 代码实现

```python
import nltk
from nltk.sentiment import SentimentIntensityAnalyzer

nltk.download('vader_lexicon')

def analyze_sentiment(text):
    analyzer = SentimentIntensityAnalyzer()
    sentiment = analyzer.polarity_scores(text)
    return sentiment['compound']

text = "今天的会议非常顺利，我们成功达成了共识。"
print(analyze_sentiment(text))  # 输出一个数值，值越高表示情感越积极
```

### 3.3 数学模型与公式

情感倾向的计算公式：

$$ \text{sentiment\_score} = \frac{\text{positive\_words} - \text{negative\_words}}{\text{total\_words}} $$

其中，$\text{positive\_words}$ 表示积极词汇的数量，$\text{negative\_words}$ 表示消极词汇的数量，$\text{total\_words}$ 表示总词汇数量。
