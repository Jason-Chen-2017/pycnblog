## 第2章: 格雷厄姆股票估值模型的核心概念

### 2.1 格雷厄姆股票估值模型的原理
- 2.1.1 内在价值的定义与计算
  - 内在价值是股票的真实价值
  - 计算公式：$$内在价值 = \frac{股息}{折现率}$$
- 2.1.2 市场价值与内在价值的对比
  - 市场价值受情绪影响，内在价值更理性
  - 当市场价值低于内在价值时，股票具有投资价值
- 2.1.3 安全边际的定义与作用
  - 安全边际 = 内在价值 - 市场价格
  - 安全边际越大，投资风险越小

### 2.2 格雷厄姆股票估值模型的三重过滤器
- 2.2.1 低市盈率筛选
  - 市盈率（P/E）= 股价 / 每股收益
  - 筛选标准：P/E < 行业平均P/E
- 2.2.2 低市净率筛选
  - 市净率（P/B）= 股价 / 每股净资产
  - 筛选标准：P/B < 行业平均P/B
- 2.2.3 高股息率筛选
  - 股息率 = 每股股息 / 股价
  - 筛选标准：股息率 > 行业平均股息率

### 2.3 核心概念对比表格
| 概念       | 定义                                                                 |
|------------|----------------------------------------------------------------------|
| 内在价值    | 股票的真实价值，基于公司基本面计算得出                                   |
| 市场价值    | 市场交易中股票的当前价格                                                 |
| 安全边际    | 内在价值与市场价格之间的差额，用于降低投资风险                         |

## 第3章: 格雷厄姆股票估值模型的算法原理

### 3.1 内在价值计算算法
- 3.1.1 股息折现法
  - 使用股息贴现模型（DDM）计算内在价值
  - 计算公式：$$V = \frac{D}{k}$$，其中D是股息，k是折现率
- 3.1.2 股权自由现金流折现法
  - 使用股权自由现金流模型（DCF）计算内在价值
  - 计算公式：$$V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}$$，其中CF_t是第t年的现金流，r是折现率
- 3.1.3 内在价值的上下限
  - 内在价值的上限是市场价值
  - 内在价值的下限是清算价值

### 3.2 安全边际计算算法
- 3.2.1 计算内在价值与市场价格的差额
  - 安全边际 = 内在价值 - 市场价格
- 3.2.2 确定安全边际的合理范围
  - 一般建议安全边际至少为内在价值的10%
- 3.2.3 安全边际与投资风险的关系
  - 安全边际越大，投资风险越小

### 3.3 格雷厄姆股票筛选算法
- 3.3.1 筛选低市盈率股票
  - 通过公式$$P/E < 行业平均P/E$$筛选
- 3.3.2 筛选低市净率股票
  - 通过公式$$P/B < 行业平均P/B$$筛选
- 3.3.3 筛选高股息率股票
  - 通过公式$$股息率 > 行业平均股息率$$筛选

def calculate_intrinsic_value(stock_data, required_rate):

    return intrinsic_value

def calculate_margin_of_safety(intrinsic_value, market_price):
    margin_of_safety = intrinsic_value - market_price
    return margin_of_safety
