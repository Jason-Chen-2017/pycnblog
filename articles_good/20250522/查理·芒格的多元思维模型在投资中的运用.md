## 第三章: 投资的基本原理与数学模型

### 3.1 投资的基本原理

#### 3.1.1 投资的定义与分类
- **投资的定义**: 将资金投入某个项目或资产，期望在未来获得收益或资本增值。
- **投资的分类**: 包括股票、债券、房地产、外汇等多种形式。
- **投资的基本目标**: 实现财富增值，分散风险，追求收益与风险的最佳平衡。

#### 3.1.2 投资的收益与风险
- **收益**: 包括资本增值和分红收益。
- **风险**: 包括市场风险、流动性风险、信用风险等。
- **收益与风险的关系**: 高风险可能带来高收益，但同时也可能带来更大的损失。

#### 3.1.3 投资的基本数学公式
- **预期收益**: $$ E(r) = \sum (P_i \times r_i) $$
  其中，\( P_i \) 是第 \( i \) 种情况发生的概率，\( r_i \) 是第 \( i \) 种情况下的收益。
- **方差与标准差**: 用于衡量资产收益的波动性。
  $$ \sigma = \sqrt{\sum (P_i \times (r_i - E(r))^2)} $$

### 3.2 多元思维模型的数学模型

#### 3.2.1 多元回归模型
- **多元回归模型**: 用于预测多个自变量对因变量的影响。
  $$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon $$
  其中，\( \epsilon \) 是误差项。
- **应用**: 预测股票价格受多种因素（如 GDP 增长率、利率、企业盈利等）的影响。

#### 3.2.2 马科维茨投资组合理论
- **现代投资组合理论**: 通过优化投资组合来最大化收益，最小化风险。
- **公式**: 在给定风险下，选择收益最大的组合；或在给定收益下，选择风险最小的组合。
- **应用**: 通过多元思维模型优化投资组合配置，平衡风险与收益。

#### 3.2.3 代码实现
```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 示例数据：股票价格与相关因素
data = {
    'GDP增长率': [3.5, 4.2, 3.8, 4.0],
    '利率': [2.5, 3.0, 2.8, 3.2],
    '企业盈利': [10, 15, 12, 18],
    '股票价格': [50, 60, 55, 65]
}
df = pd.DataFrame(data)

# 多元回归模型
model = LinearRegression()
X = df[['GDP增长率', '利率', '企业盈利']]
y = df['股票价格']
model.fit(X, y)

# 预测股票价格
new_data = {
    'GDP增长率': [4.5],
    '利率': [3.5],
    '企业盈利': [16]
}
new_df = pd.DataFrame(new_data)
predicted_price = model.predict(new_df)
print("预测股票价格:", predicted_price)
```
