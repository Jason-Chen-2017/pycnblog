#### 5.2 系统核心实现源代码

- **计算内在价值和安全边际的代码**：
  ```python
  import pandas as pd

  def calculate_intrinsic_value(earnings, k_factor):
      return earnings / k_factor

  def calculate_margin_of_safety(intrinsic_value, market_price):
      return intrinsic_value - market_price

  # 示例数据
  df = pd.DataFrame({
      '股票代码': ['A', 'B', 'C'],
      '每股收益': [10, 15, 20],
      '市场价': [50, 60, 70],
      'k因子': [0.1, 0.12, 0.08]
  })

  # 计算内在价值和安全边际
  df['内在价值'] = df.apply(lambda x: calculate_intrinsic_value(x['每股收益'], x['k因子']), axis=1)
  df['安全边际'] = df.apply(lambda x: calculate_margin_of_safety(x['内在价值'], x['市场价']), axis=1)

  print(df)
  ```
