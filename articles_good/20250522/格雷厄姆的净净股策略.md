# 第1章 净净股策略的背景与核心概念

## 1.1 净净股策略的起源与发展

### 1.1.1 价值投资的鼻祖：本杰明·格雷厄姆

本杰明·格雷厄姆是20世纪最著名的价值投资者之一，他的投资理念深刻影响了巴菲特等一代投资者。格雷厄姆主张以低于内在价值的价格买入股票，并长期持有，直到市场认识到其真实价值。

### 1.1.2 净净股策略的提出背景

20世纪20年代末至30年代初，美国股市经历了剧烈的波动，投资者对稳健投资策略的需求日益迫切。格雷厄姆在这一背景下提出了净净股策略，旨在帮助投资者在市场低迷时期发现被低估的股票。

### 1.1.3 净净股策略在投资界的影响

格雷厄姆的净净股策略不仅是价值投资的基石，还为现代投资分析奠定了基础。许多投资者将其作为寻找低估股票的重要方法，尤其在市场下跌或经济危机时更为适用。

## 1.2 净净股策略的核心思想

### 1.2.1 价值投资理念

格雷厄姆强调以企业的内在价值为基础进行投资，而不是关注市场波动。他认为，股票的真正价值是其未来现金流的现值，而市场价格會围绕这个价值波动。

### 1.2.2 净净股策略的核心原则

净净股策略的核心是寻找市场价格低于其清算价值的股票。格雷厄姆认为，如果股票价格远低于其清算价值，那么该股票具有较大的安全边际，风险较低。

### 1.2.3 与其他投资策略的区别

与技术分析或动量策略不同，净净股策略注重基本面分析，尤其是企业的资产状况和财务健康状况。它更关注企业的内在价值，而非市场趋势。

## 1.3 净净股策略的基本框架

### 1.3.1 净净股的定义与计算

净净股（Net Net）是指股票的市场价格低于其账面价值的差额。计算公式为：

$$ 净净价值 = 资产 - 负债 - 市场价格 $$

如果市场价格低于净资产价值，则该股票被认为是被低估的。

### 1.3.2 净净股策略的适用场景

该策略适用于市场低迷、企业资产被低估的时期，尤其适合那些资产-heavy的行业，如银行、保险公司等。

### 1.3.3 净净股策略的优缺点

- **优点**：风险低，安全边际高。
- **缺点**：筛选难度大，需要详细分析财务报表。

### 2.1.2 净净股的属性特征对比

| 属性 | 净净股 | 非净净股 |

# 第3章 净净股策略的算法原理

## 3.1 净净价值的计算公式

$$ 净净价值 = \frac{资产 - 负债}{流通股数量} $$

## 3.2 净净股策略的筛选算法

### 3.2.1 算法流程图

```mermaid
graph TD
    A[输入股票数据] --> B[计算资产与负债]
    B --> C[计算净资产价值]
    C --> D[比较市场价格与净资产价值]
    D --> E[输出投资建议]
```

### 3.2.2 算法实现的Python代码

```python
def calculate_net_nets(stock_data):
    assets = stock_data['Total Assets']
    liabilities = stock_data['Total Liabilities']
    shares_outstanding = stock_data['Shares Outstanding']
    net_assets = assets - liabilities
    net_nets = net_assets / shares_outstanding
    return net_nets

# 示例数据
stock_data = {
    'Total Assets': 500,
    'Total Liabilities': 300,
    'Shares Outstanding': 100
}

net_nets = calculate_net_nets(stock_data)
print(f"净净价值为: {net_nets}")
```
