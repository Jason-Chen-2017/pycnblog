### 5.2 核心代码实现

- **5.2.1 环境配置**
  - Python 3.8+
  - 安装依赖：pip install requests、pymysql

- **5.2.2 核心代码实现**
  ```python
  import requests
  import pymysql

  def fetch_data(url):
      try:
          response = requests.get(url)
          return response.json()
      except requests.exceptions.RequestException:
          return None

  def store_data(db_config, data):
      try:
          conn = pymysql.connect(**db_config)
          cursor = conn.cursor()
          cursor.execute("INSERT INTO suppliers (name, id) VALUES (%s, %s)", (data['name'], data['id']))
          conn.commit()
          return True
      except pymysql.Error:
          return False

  if __name__ == "__main__":
      db_config = {
          'host': 'localhost',
          'user': 'root',
          'password': 'password',
          'database': 'company_ecosystem'
      }
      data = fetch_data('http://api.suppliers.com/suppliers')
      if data:
          store_data(db_config, data)
  ```
