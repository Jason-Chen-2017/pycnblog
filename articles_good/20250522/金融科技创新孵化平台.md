## 第二部分: 算法原理讲解

### 第3章: 区块链共识机制

#### 3.1 共识机制的定义与分类
- 共识机制是区块链中用于达成分布式系统中一致性的算法，常见的有PoW、PoS、Dpos等。  

#### 3.2 工作量证明机制（PoW）
- **流程图**：  
```mermaid
graph TD
    A[ miners 开始计算] --> B[找到符合条件的哈希值]
    B --> C[广播区块到全网]
    C --> D[其他节点验证]
    D --> E[区块确认加入链中]
```

- **Python代码示例**：  
```python
import hashlib

def compute_hash(input_str):
    return hashlib.sha256(input_str.encode()).hexdigest()

# 示例
input_str = "区块"
print(compute_hash(input_str))  # 输出哈希值
```

- **数学模型**：  
$$ H(x) = \text{hash}(x) $$  
其中，H(x)是输入x的哈希值，hash函数用于将任意长度的输入映射为固定长度的哈希值。

### 第4章: 人工智能中的机器学习算法

#### 4.1 机器学习算法的定义与分类
- 机器学习算法分为监督学习、无监督学习和强化学习。  

#### 4.2 线性回归算法
- **流程图**：  
```mermaid
graph TD
    A[输入数据] --> B[计算预测值]
    B --> C[计算误差]
    C --> D[更新权重]
    D --> E[迭代优化]
```

- **Python代码示例**：  
```python
import numpy as np

# 数据准备
X = np.array([1, 2, 3, 4], dtype=np.float32)
y = np.array([2, 4, 6, 8], dtype=np.float32)

# 线性回归模型
class LinearRegression:
    def fit(self, X, y):
        # 计算权重
        self.w = np.dot(X.T, X).inverse().dot(X.T).dot(y)
        return self.w

model = LinearRegression()
weights = model.fit(X, y)
print(weights)  # 输出权重
```

- **数学模型**：  
$$ y = wx + b $$  
其中，w是权重，b是截距，x是输入，y是输出。
