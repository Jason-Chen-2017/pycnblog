## 第1章 价值投资与特价股票概述

### 1.1 价值投资的起源与发展

价值投资是一种以基本面分析为基础的投资策略，起源于本杰明·格雷厄姆（Benjamin Graham）和戴维·多德（David Dodd）的理论。格雷厄姆是20世纪最著名的价值投资者之一，他提出的“安全边际”概念和“内在价值”计算方法，为现代投资理论奠定了基础。

#### 格雷厄姆的价值投资理论

格雷厄姆的价值投资理论强调买入被市场低估的股票，并在合理的价格区间内卖出。他认为，市场的短期波动反映了投资者的非理性行为，而股票的内在价值是其长期持有的基础。以下是格雷厄姆理论的核心要点：

1. **内在价值**：股票的内在价值是其未来现金流的现值，可以通过基本面分析计算得出。
2. **安全边际**：买入价格低于内在价值，以确保投资的安全性。
3. **长期投资**：价值投资强调长期持有，避免频繁交易。

#### 价值投资与其它投资策略的对比

- **技术分析**：技术分析依赖于价格和成交量的波动，而价值投资关注基本面。
- **基本面分析**：基本面分析侧重于公司财务数据，而价值投资更注重安全边际和长期价值。
- **趋势投资**：趋势投资跟随市场趋势，而价值投资则逆市操作，寻找低估股票。

#### 特价股票的定义与特征

特价股票是指市场价格低于其内在价值的股票。以下是特价股票的特征：

1. **低市盈率（P/E）**：市盈率低于行业平均水平。
2. **低市净率（P/B）**：市净率低于行业平均水平。
3. **高股息率**：股息收益率较高，且股息支付率稳定。
4. **稳定的财务状况**：公司财务健康，无重大负债风险。

### 1.2 价值投资的核心理念

价值投资的核心理念是购买低于其内在价值的股票，并在价格回升时卖出。以下是价值投资的几个关键点：

- **安全边际**：买入价格低于内在价值，以降低投资风险。
- **长期视角**：价值投资强调长期持有，避免短期波动的干扰。
- **逆向思维**：在市场恐慌时买入，在市场狂热时卖出。

### 1.3 价值投资的适用场景

价值投资适用于市场波动较大、个股被低估的情况。以下是价值投资的适用场景：

1. **市场低迷期**：市场恐慌时，许多股票被低估，是买入的好时机。
2. **行业周期低谷**：某些行业在周期低谷时，股票价格被低估，适合价值投资。
3. **个股基本面良好**：公司财务健康，具备长期竞争优势。

## 第2章 股票价值评估的核心概念

### 2.1 股票的内在价值计算

内在价值是股票的真正价值，与市场波动无关。以下是计算内在价值的主要方法：

1. **格雷厄姆的内在价值公式**：
   $$ 
   \text{内在价值} = \frac{\text{预期收益} \times (1 + \text{增长率})}{\text{折现率}} 
   $$
   该公式考虑了未来现金流的现值，用于评估股票的长期价值。

2. **市盈率（P/E）**：
   $$
   \text{市盈率} = \frac{\text{股价}}{\text{每股收益}}
   $$
   低市盈率通常意味着股票被低估。

3. **市净率（P/B）**：
   $$
   \text{市净率} = \frac{\text{股价}}{\text{每股净资产}}
   $$
   低市净率通常意味着股票被低估。

### 2.2 市场情绪与股价波动

市场情绪对股价波动有重要影响。以下是市场情绪对价值投资的影响：

1. **市场恐慌**：投资者恐慌时，股票价格可能大幅低于内在价值，是买入的好时机。
2. **市场狂热**：投资者狂热时，股票价格可能大幅高于内在价值，是卖出的好时机。

### 2.3 安全边际的重要性

安全边际是价值投资中的重要概念，用于降低投资风险。以下是安全边际的计算方法：

1. **安全边际 = 内在价值 - 市场价格**
   - 如果安全边际为正，说明股票被低估，适合买入。
   - 如果安全边际为负，说明股票被高估，适合卖出。

2. **安全边际率 = (内在价值 - 市场价格) / 内在价值**
   - 安全边际率越高，说明股票的安全边际越大，投资风险越小。

## 第3章 价值投资的算法与策略

### 3.1 价值投资的量化分析

价值投资的量化分析基于基本面数据和市场数据，以下是量化分析的主要步骤：

1. **数据采集**：收集股票的财务数据和市场数据。
2. **数据清洗**：处理缺失数据和异常数据。
3. **量化指标计算**：计算市盈率、市净率、股息率等指标。
4. **筛选股票**：根据量化指标筛选出被低估的股票。

### 3.2 价值投资的买卖时机判断

买卖时机的判断是价值投资的关键。以下是买卖时机的判断步骤：

1. **买入时机**：
   - 安全边际为正。
   - 市场恐慌时。
2. **卖出时机**：
   - 安全边际为负。
   - 市场狂热时。

### 3.3 投资组合的动态调整

投资组合的动态调整是价值投资的重要策略。以下是动态调整的主要步骤：

1. **定期评估**：定期评估投资组合的内在价值和市场价格。
2. **重新平衡**：根据市场变化和公司基本面，重新平衡投资组合。
3. **逐步卖出**：分批卖出高估股票，逐步降低投资组合的风险。

        # 获取股票数据
        df = pd.read_csv(f'data/{ticker}.csv')

def calculate_margin_of_safety(df):
    intrinsic_value = df['intrinsic_value']
    market_price = df['close']
    mos = intrinsic_value - market_price
    return mos

# 投资决策
def generate_signals(df):
    mos = calculate_margin_of_safety(df)
    signals = []
    for price, mos in zip(df['close'], mos):

            signals.append('Buy')
        elif mos < -0.1:

        else:

    return signals
