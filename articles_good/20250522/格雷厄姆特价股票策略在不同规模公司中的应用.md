## 第1章: 格雷厄姆策略概述

### 1.1 价值投资的核心理念

#### 1.1.1 投资的定义与分类

投资是通过将资金投入各种资产（如股票、债券、房地产等）以期望获得未来收益的行为。根据资产规模和市场流动性，股票可以分为小盘股、中盘股和大盘股。

| 分类标准 | 小盘股 | 中盘股 | 大盘股 |
|----------|--------|--------|--------|
| 市值范围 | 小于10亿美元 | 10亿至50亿美元 | 大于50亿美元 |
| 流动性   | 低     | 中等   | 高     |
| 波动性   | 高     | 中等   | 低     |

#### 1.1.2 价值投资的起源与发展

价值投资由本杰明·格雷厄姆在20世纪初提出，强调以低于内在价值的价格买入股票，长期持有以获得收益。其核心思想是市场先生的非理性导致短期波动，而企业内在价值才是长期投资的依据。

#### 1.1.3 格雷厄姆的价值投资理论

格雷厄姆的策略基于以下原则：
1. **安全边际**：买入价格应远低于内在价值，以降低风险。
2. **内在价值**：企业未来现金流的现值，可通过DCF模型计算。
3. **非理性市场**：利用市场波动寻找低估机会。

### 1.2 格雷厄姆策略的适用性分析

#### 1.2.1 小盘股、中盘股与大盘股的定义

- **小盘股**：市值较低，流动性差，波动性高，通常为成长型企业。
- **中盘股**：市值中等，流动性适中，风险和回报介于小盘和大盘之间。
- **大盘股**：市值高，流动性好，稳定性强，多为成熟企业。

#### 1.2.2 不同规模公司股票的特点对比

| 特性      | 小盘股       | 中盘股       | 大盘股       |
|-----------|--------------|--------------|--------------|
| 市值范围   | 小于10亿     | 10亿至50亿   | 大于50亿     |
| 波动性     | 高           | 中等         | 低           |
| 成长性     | 高           | 中等         | 低           |
| 风险       | 高           | 中等         | 低           |
| 流动性     | 低           | 中等         | 高           |

#### 1.2.3 格雷厄姆策略在不同规模公司的适用性

- **小盘股**：波动性高，但成长潜力大，适合寻找安全边际的投资者。
- **中盘股**：稳定性与成长性兼具，适合中长期投资。
- **大盘股**：稳定性高，适合追求稳定收益的投资者。

## 第2章: 格雷厄姆策略的核心原理

### 2.1 格雷厄姆策略的数学模型

#### 内在价值公式

$$ V = \frac{E}{(1 + r)^n} $$

其中：
- \( V \)：内在价值
- \( E \)：未来现金流
- \( r \)：折现率
- \( n \)：现金流的持续年限

#### 安全边际计算

$$ \text{安全边际} = \frac{\text{内在价值} - \text{市场价格}}{\text{市场价格}} \times 100\% $$

### 2.2 格雷厄姆策略的决策流程

1. 确定投资目标：根据风险承受能力和收益目标选择公司规模。
2. 筛选候选公司：基于估值指标（如市盈率、市净率）筛选。
3. 计算内在价值：使用DCF模型评估公司价值。
4. 确定安全边际：比较市场价格与内在价值，确保安全边际为正值。
5. 调整投资组合：分散投资以降低风险。

## 第7章: 项目实战

### 7.1 环境安装

- **工具**：Excel、Python（Pandas、NumPy）
- **数据源**：Yahoo Finance API

### 7.2 核心实现

```python
import pandas as pd
import numpy as np

def calculate_intrinsic_value(cash_flows, discount_rate):
    return np.sum(cash_flows / (1 + discount_rate)**range(len(cash_flows)))

def calculate_margin_of_safety(intrinsic_value, market_price):
    return (intrinsic_value - market_price) / market_price * 100

# 示例数据
cash_flows = [10, 12, 15, 20]  # 单位：百万美元
discount_rate = 0.08
market_price = 50

intrinsic_value = calculate_intrinsic_value(cash_flows, discount_rate)
margin_of_safety = calculate_margin_of_safety(intrinsic_value, market_price)

print(f"内在价值：{intrinsic_value:.2f}美元")
print(f"安全边际：{margin_of_safety:.2f}%")
```
