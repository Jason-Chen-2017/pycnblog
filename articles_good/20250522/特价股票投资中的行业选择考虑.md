## 第1章: 特价股票投资的背景与概念

### 1.1 特价股票的基本概念
#### 1.1.1 什么是特价股票
特价股票是指价格相对较低的股票，通常具有较高的市盈率（P/E）或市净率（P/B）等估值指标。这类股票可能处于价值洼地，具备较高的投资潜力。

#### 1.1.2 特价股票的特点与分类
- **特点**：
  - 价格低于行业平均水平。
  - 具备较高的潜在增长率。
  - 可能处于行业周期的低谷期。
- **分类**：
  - 周期性行业股票。
  - 新兴行业股票。
  - 成熟行业股票。

#### 1.1.3 特价股票投资的意义
- 低价买入，高价卖出。
- 分散投资风险。
- 捕捉行业复苏或增长的机会。

### 1.2 行业选择在股票投资中的重要性
#### 1.2.1 行业在股票投资中的地位
行业是股票投资的基础，同一行业的股票具有相似的市场表现和风险特征。

#### 1.2.2 行业选择的基本原则
- 行业的可持续增长潜力。
- 行业的竞争结构。
- 宏观经济环境的影响。

#### 1.2.3 特价股票行业选择的独特性
- 低价股票往往集中在特定行业。
- 行业周期波动影响股票价格。
- 行业政策变化影响投资价值。

### 1.3 特价股票投资的现状与趋势
#### 1.3.1 特价股票市场的现状分析
- 市场中存在大量低价股票。
- 投资者对低价股票的关注度逐渐增加。

#### 1.3.2 行业选择的演变与趋势
- 从单一关注价格转向综合评估行业基本面。
- 技术分析与基本面分析结合。

#### 1.3.3 投资者行为对行业选择的影响
- 机构投资者更注重行业基本面。
- 个人投资者更关注短期价格波动。

## 第3章: 特价股票行业选择的分析方法

### 3.1 基本面分析法
#### 3.1.1 财务指标分析
- 市盈率（P/E）：$P/E = \frac{股票价格}{每股收益}$。
- 市净率（P/B）：$P/B = \frac{股票价格}{每股净资产}$。
- 股息率：$\text{股息率} = \frac{\text{每股股息}}{\text{股票价格}} \times 100\%$。

#### 3.1.2 行业估值指标（如PE、PB等）
- 行业平均市盈率。
- 行业平均市净率。

#### 3.1.3 行业趋势分析
- 历史价格走势。
- 行业未来发展趋势预测。

### 3.2 技术分析法
#### 3.2.1 K线图分析
- 看涨吞吐线。
- 看跌吞吐线。

#### 3.2.2 技术指标（如MACD、RSI）
- MACD：$\text{MACD} = \text{短期EMA} - \text{长期EMA}$。
- RSI：$\text{RSI} = \frac{\text{上涨天数}}{\text{总天数}} \times 100\%$。

### 3.3 综合分析法
#### 3.3.1 量化分析模型
- 使用因子分析法，通过Python代码实现。
- 代码示例：
  ```python
  import pandas as pd
  import numpy as np

  # 加载数据
  df = pd.read_csv('stock_data.csv')

  # 计算因子
  df['PE'] = df['Price'] / df['EPS']
  df['PB'] = df['Price'] / df['Book Value Per Share']

  # 筛选低价股票
  cheap_stocks = df[df['PE'] < df['PE'].mean()]
  ```
