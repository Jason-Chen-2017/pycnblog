# 第一部分：格雷厄姆投资理论与股票选择公式基础

## 第1章：格雷厄姆投资理论概述

### 1.1 格雷厄姆投资理论的背景与起源

#### 1.1.1 20世纪初的金融环境
在20世纪初，美国股市经历了多次剧烈波动，投资者急需一种稳定可靠的选股方法。本杰明·格雷厄姆（Benjamin Graham）作为哥伦比亚大学的教授和投资顾问，以其独特的价值投资理念，为现代投资理论奠定了基础。

#### 1.1.2 格雷厄姆与巴菲特的合作关系
格雷厄姆的学生沃伦·巴菲特（Warren Buffett）继承并发展了其投资理念，两人合作期间共同创立了格雷厄姆-纽曼公司，进一步验证了价值投资的可行性。

#### 1.1.3 价值投资理念的形成
格雷厄姆提出的价值投资理念强调以低于内在价值的价格买入股票，注重企业的基本面分析，而非市场短期波动。

### 1.2 格雷厄姆股票选择公式的核心思想

#### 1.2.1 价值投资的核心理念
价值投资的核心在于寻找市场价格低于内在价值的股票，即“买入便宜的东西”。格雷厄姆认为，内在价值可以通过对企业财务指标的分析来估算。

#### 1.2.2 股票的内在价值计算
内在价值的计算涉及对企业未来现金流的折现，格雷厄姆常用的方法是通过市盈率（P/E）和市净率（P/B）来评估股票的价值。

#### 1.2.3 安全边际的概念与重要性
安全边际是指市场价格与内在价值之间的差距，确保在市场价格波动时，投资者仍能获得正收益。

### 1.3 格雷厄姆选股公式的基本框架

#### 1.3.1 市盈率与市净率的定义
- 市盈率（P/E）= 股价 / 每股净利润
- 市净率（P/B）= 股价 / 每股净资产

#### 1.3.2 股息率与股息支付率的计算
- 股息率 = 每股股息 / 股价
- 股息支付率 = 股息 / 净利润

#### 1.3.3 企业盈利能力的评估指标
- 净利润率 = 净利润 / 收入
- 资产周转率 = 收入 / 总资产

## 第2章：格雷厄姆选股公式的数学模型与公式

### 2.1 格雷厄姆选股公式的数学推导

#### 2.1.1 市盈率公式
$$ P/E = \frac{P}{E} $$
其中，P为股价，E为每股净利润。

#### 2.1.2 市净率公式
$$ P/B = \frac{P}{B} $$
其中，P为股价，B为每股净资产。

#### 2.1.3 股息率公式
$$ D/Y = \frac{D}{Y} $$
其中，D为每股股息，Y为股价。

### 2.2 格雷厄姆选股公式的综合模型

#### 2.2.1 综合评分模型的构建
综合评分模型将市盈率、市净率和股息率等多个指标进行加权，计算综合得分。

$$ Score = \alpha \cdot (P/E) + \beta \cdot (P/B) + \gamma \cdot (D/Y) $$

#### 2.2.2 参数α、β、γ的确定方法
参数α、β、γ分别代表市盈率、市净率和股息率的权重，通常根据历史数据和市场环境进行调整。

```python
import pandas as pd
import numpy as np

# 获取数据
data = pd.read_csv('stock_data.csv')

# 数据清洗
data.dropna(inplace=True)
data = data[~data['PE'].isinf()]
```

#### 5.2.2 公式计算与筛选
```python
# 计算市盈率、市净率和股息率
data['PE'] = data['Price'] / data['Earnings']
data['PB'] = data['Price'] / data['BookValue']
data['DivYield'] = data['Dividend'] / data['Price']

# 筛选条件：PE < 15，PB < 2，DivYield > 2%
selected_stocks = data[(data['PE'] < 15) & (data['PB'] < 2) & (data['DivYield'] > 0.02)]
```
