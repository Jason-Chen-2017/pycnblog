# 第1章：全球股市估值概述

## 1.1 股市估值的概念与意义

### 1.1.1 股市估值的基本概念

股市估值是通过分析公司基本面和市场因素，评估其股票的合理价格范围。常用的方法包括市盈率（P/E）和市净率（P/B）。

### 1.1.2 股市估值的重要性

准确的估值有助于投资者做出明智的投资决策，识别被低估或高估的股票。

### 1.1.3 股市估值的主体与客体

主体包括投资者、机构和分析师；客体是上市公司和市场整体表现。

---

## 1.2 股市估值的主要方法

### 1.2.1 市盈率法

市盈率 = 股票价格 / 每股收益（EPS）

**代码示例**：
```python
import pandas as pd
data = pd.read_csv('stock_data.csv')
data['PE'] = data['Price'] / data['EPS']
print(data.head())
```

### 1.2.2 市净率法

市净率 = 股票价格 / 每股净资产（BPS）

### 1.2.3 股息率法

股息率 = 每股股息（DIV） / 股票价格

### 1.2.4 现金流折现法

通过折现现金流模型评估公司价值。

---

## 1.3 影响股市估值的主要因素

### 1.3.1 宏观经济因素

包括利率、GDP增长率和通货膨胀率。

### 1.3.2 行业因素

行业竞争状况和市场趋势影响估值。

### 1.3.3 公司基本面因素

收入、利润和财务状况。
