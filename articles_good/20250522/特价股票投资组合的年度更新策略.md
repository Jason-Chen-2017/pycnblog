## 第1章: 特价股票与投资组合概述

### 1.1 特价股票的定义与特点
#### 1.1.1 特价股票的定义
特价股票通常指那些价格被低估、具有较大上涨潜力的股票。这些股票可能因市场波动、公司基本面改善或其他因素而被忽视，但具有长期投资价值。

#### 1.1.2 特价股票的核心特点
| 特点 | 描述 |
|------|------|
| 低估值 | 市盈率（P/E）或市净率（P/B）低于行业平均水平。 |
| 高股息率 | 相对于股票价格，股息收入较高。 |
| 弱势行业 | 来自表现不佳的行业，但具有复苏潜力。 |
| 高成长潜力 | 公司基本面良好，未来增长可期。 |

#### 1.1.3 特价股票与普通股票的对比
```mermaid
graph LR
A[特价股票] --> B[低估值]
A --> C[高股息率]
A --> D[高成长潜力]
E[普通股票] --> F[中等估值]
E --> G[普通股息率]
```

### 1.2 投资组合的基本概念
#### 1.2.1 投资组合的定义
投资组合是将资金分配到多种资产（股票、债券、现金等）以分散风险、优化收益的过程。

#### 1.2.2 投资组合的类型
| 类型 | 描述 |
|------|------|
| 股票型 | 以股票为主要投资标的。 |
| 债券型 | 以债券为主要投资标的。 |
| 混合型 | 组合股票和债券，平衡风险与收益。 |

#### 1.2.3 投资组合的目标与风险
| 目标 | 风险 |
|------|------|
| 资本增值 | 市场波动风险 |
| 现金流稳定 | 利率风险 |
| 资产保值 | 通货膨胀风险 |

### 1.3 年度更新策略的重要性
#### 1.3.1 市场环境的变化
经济周期、政策调整和行业趋势都会影响股票价值。

#### 1.3.2 投资目标的调整
个人财务状况变化可能需要调整投资目标。

#### 1.3.3 投资组合的再平衡
定期调整持仓比例，保持风险与收益的平衡。

### 1.4 本章小结
本章介绍了特价股票的特点和投资组合的基本概念，强调了年度更新策略的重要性。

## 第2章: 特价股票的筛选与分析

### 2.1 特价股票的筛选标准
#### 2.1.1 市盈率（P/E）分析
市盈率 = 股价 / 每股净利润（EPS）

```mermaid
graph TD
A[市盈率分析] --> B[筛选低估股票]
B --> C[计算P/E]
C --> D[与行业平均对比]
```

#### 2.1.2 市净率（P/B）分析
市净率 = 股价 / 每股净资产（BPS）

#### 2.1.3 股息率分析
股息率 = 每股股息（DIV） / 股价

### 2.2 特价股票的行业分析
#### 2.2.1 行业选择的基本原则
选择具有复苏潜力的行业，如周期性行业。

#### 2.2.2 公司基本面分析
| 指标 | 重要性 |
|------|------|
| 净利润增长率 | 高 |
| 资产负债率 | 低 |
| 营业利润率 | 高 |

### 2.3 特价股票的量化筛选模型
#### 2.3.1 筛选步骤
```mermaid
graph LR
A[数据收集] --> B[计算估值指标]
B --> C[筛选低估股票]
C --> D[行业分布]
```

#### 2.3.2 数学模型
$$
\text{综合得分} = 0.4 \times P/E + 0.3 \times P/B + 0.3 \times \text{股息率}
$$
