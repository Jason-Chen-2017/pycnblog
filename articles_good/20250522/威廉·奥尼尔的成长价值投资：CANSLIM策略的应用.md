## 第一章: 投资领域的背景与现状

### 1.1 投资领域的核心概念

#### 1.1.1 问题背景：传统投资与现代投资的冲突
传统投资方法依赖于基本面分析和市场情绪，但在信息爆炸和市场波动加剧的今天，这种方法往往显得力不从心。投资者需要更系统化、可量化的投资策略。

#### 1.1.2 问题描述：传统投资的局限性与现代投资的需求
传统投资方法主观性强、难以复制，且难以应对市场的快速变化。现代投资者需要一种基于数据和逻辑的系统化投资策略。

#### 1.1.3 问题解决：威廉·奥尼尔的成长价值投资方法
威廉·奥尼尔提出CANSLIM策略，结合成长、价值和安全边际，提供了一种可量化、可复制的投资方法。

#### 1.1.4 边界与外延：成长价值投资的适用范围与限制
成长价值投资适用于成长型企业，尤其在市场波动较大时表现优异，但对周期性行业和成熟企业效果有限。

#### 1.1.5 核心要素：成长、价值、安全边际的结合
CANSLIM策略将成长（C）、价值（A、S、L、M、I）和安全边际（N）有机结合，形成了一套完整的投资体系。

## 第二章: CANSLIM策略的核心概念与联系

### 2.1 CANSLIM策略的原理

#### 2.1.1 C：年化复合收益增长率的计算
年化复合收益增长率（C）是衡量企业成长性的核心指标。公式如下：
$$
C = \left( \frac{E_t}{E_0} \right)^{1/t} - 1
$$
其中，$E_t$为第$t$年的企业价值，$E_0$为初始价值。

#### 2.1.2 A：月度价格表现的评估
A指标衡量的是股票在最近6个月的相对表现，通过比较股票价格与行业指数的走势来判断。

#### 2.1.3 N：新上涨阶段的识别
N指标用于识别股票进入新的上涨周期，通常通过价格突破长期趋势线来判断。

#### 2.1.4 S：相对强度的衡量
相对强度（S）是股票价格相对于市场指数的表现，公式为：
$$
S = \frac{\text{股票价格}}{\text{市场指数价格}} \times 100
$$

#### 2.1.5 L：机构资金流入的监测
L指标通过追踪机构资金的流入情况，判断市场对股票的青睐程度。

#### 2.1.6 M：股价表现的分析
M指标分析股价走势，寻找突破点和支撑位。

#### 2.1.7 I：内部评级的确定
I指标通过对企业内部管理、财务状况的评估，给出内部评级。

```python
def get_stock_data(ticker):

```

#### 5.2.2 指标计算
```python
def calculate_cagr(data):
    revenue = data['Adj Close']
    cagr = ((revenue[-1]/revenue[0])** (1/len(revenue))) - 1
    return cagr

def calculate_relative_strength(stock, index):
    rs = (stock['Adj Close']/index['Adj Close']) * 100
    return rs
```

#### 5.2.3 策略筛选
```python
def screen_canslim(stocks):
    selected = []
    for stock in stocks:
        data = get_stock_data(stock)
        cagr = calculate_cagr(data)
        if cagr > 0.2:
            selected.append(stock)
    return selected
```
