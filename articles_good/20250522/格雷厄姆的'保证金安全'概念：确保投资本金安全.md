### 5.2 核心代码实现
以下是系统的核心代码：

```python
import numpy as np

class SecuritySystem:
    def __init__(self, asset_value, market_volatility, risk_adjustment_factor):
        self.asset_value = asset_value
        self.market_volatility = market_volatility
        self.risk_adjustment_factor = risk_adjustment_factor

    def calculate_security_coefficient(self):
        return (self.asset_value / self.market_volatility) * self.risk_adjustment_factor

# 示例应用
system = SecuritySystem(1000000, 0.2, 1.5)
print(f"安全系数: {system.calculate_security_coefficient()}")
```
