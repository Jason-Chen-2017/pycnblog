# 第一部分：格雷厄姆投资理论基础

## 第1章：格雷厄姆投资理论概述

### 1.1 格雷厄姆的生平与投资理念

#### 1.1.1 格雷厄姆的生平简介
 Benjamin Graham（1894-1976）是美国著名的投资学家、价值投资的鼻祖，被誉为“价值投资之父”。他曾在哥伦比亚大学教授证券分析课程，并与David Dodd合著了《证券分析》一书，为价值投资奠定了理论基础。

#### 1.1.2 价值投资的核心理念
 格雷厄姆倡导“安全边际”投资理念，主张以低于内在价值的价格买入股票，以确保投资的安全性和盈利能力。他认为市场短期是投票器，长期是称重机，投资者应关注企业的内在价值而非短期市场波动。

#### 1.1.3 安全边际的概念与重要性
 安全边际是格雷厄姆理论的核心，指买入价格低于内在价值的差额部分。通过安全边际，投资者可以在市场波动中减少损失，并在长期获得超额收益。

### 1.2 格雷厄姆的投资策略

#### 1.2.1 买入被低估的股票
 格雷厄姆专注于寻找市场价格低于内在价值的股票，这些股票通常具有较低的市盈率、市净率和股息率，反映了市场对其价值的低估。

#### 1.2.2 长期投资与耐心持有
 格雷厄姆反对频繁交易，主张长期持有优质股票，通过时间的积累获得复利效应，实现财富的稳定增长。

#### 1.2.3 分散投资以降低风险
 通过分散投资不同行业和公司的股票，格雷厄姆降低了单一股票波动带来的风险，提高了投资组合的稳定性。

## 第2章：股票估值方法

### 2.1 常见的股票估值指标

#### 2.1.1 市盈率（P/E）的计算与应用
 市盈率 = 股价 / 每股净利润（EPS）。格雷厄姆建议选择市盈率低于市场平均水平的股票，通常认为市盈率低于15倍具有吸引力。

#### 2.1.2 市净率（P/B）的计算与应用
 市净率 = 股价 / 每股净资产（BPS）。格雷厄姆推荐市净率低于2倍的股票，尤其适用于银行、制造业等资产密集型行业。

#### 2.1.3 股息率的计算与应用
 股息率 = 每股股息 / 股价。格雷厄姆倾向于选择股息率稳定且合理的股票，通常认为5%以上的股息率具有吸引力。

### 2.2 格雷厄姆的估值模型

#### 2.2.1 灵活使用内在价值计算公式
 格雷厄姆的内在价值公式考虑了企业的盈利能力、资产质量和行业地位等因素，通过调整各项指标计算出股票的合理价值。

#### 2.2.2 修正市盈率与市净率的应用
 通过修正历史数据和行业基准，格雷厄姆得出修正后的市盈率和市净率，进一步筛选出具有投资价值的股票。

#### 2.2.3 股息率与股息增长的结合
 结合股息率和股息增长率，格雷厄姆预测未来股息收益，评估股票的投资潜力。

#### 4.2.3 筛选策略模块

```python
def graham_screening(df):
    # 筛选条件：PE < 15，PB < 2，股息率 > 5%
    df['Dividend Yield'] = df['Dividend'] / df['Price']
    selected_stocks = df[(df['PE'] < 15) & (df['PB'] < 2) & (df['Dividend Yield'] > 0.05)]
    return selected_stocks
```
