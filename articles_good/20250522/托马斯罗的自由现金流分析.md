# 第一部分: 托马斯罗的自由现金流分析基础

## 第1章: 自由现金流的基本概念

### 1.1 自由现金流的定义与重要性

#### 1.1.1 自由现金流的定义
自由现金流（Free Cash Flow，FCF）是指企业在扣除所有运营和资本支出后的剩余现金流量，反映了企业实际产生的现金收益。其公式为：
$$\text{FCF} = \text{营业收入} - \text{运营成本} - \text{资本支出}$$

#### 1.1.2 自由现金流在企业价值评估中的重要性
自由现金流是衡量企业财务健康的重要指标，用于评估企业的内在价值和制定财务策略。它帮助投资者判断企业是否值得投资，并支持企业进行分红和再投资决策。

#### 1.1.3 自由现金流与企业财务健康的关系
健康的财务状况通常表现为稳定的自由现金流，表明企业能够维持日常运营并有足够的资金进行扩展。

### 1.2 自由现金流的计算方法

#### 1.2.1 操作现金流的计算
操作现金流是企业日常运营中产生的现金流，计算公式为：
$$\text{操作现金流} = \text{营业收入} - \text{运营成本} - \text{税金}$$

#### 1.2.2 投资现金流的计算
投资现金流涉及固定资产和其他长期资产的投资，计算公式为：
$$\text{投资现金流} = \text{折旧} + \text{摊销}$$

#### 1.2.3 融资现金流的计算
融资现金流涉及债务和股权融资，计算公式为：
$$\text{融资现金流} = \text{偿还债务} - \text{发行新股}$$

## 第2章: 自由现金流的核心公式与应用

### 2.1 自由现金流的核心公式

#### 2.1.1 自由现金流公式
$$\text{FCF} = \text{EBIT} - \text{税} - \text{折旧} - \text{摊销} - \text{资本支出}$$

#### 2.1.2 净现值公式
净现值（NPV）用于评估投资项目的盈利能力，公式为：
$$\text{NPV} = \sum_{t=1}^{n} \frac{\text{现金流}}{(1 + r)^t}$$
其中，\( r \) 是贴现率。

#### 2.1.3 内部收益率公式
内部收益率（IRR）是使净现值为零的贴现率，用于评估投资项目的回报率。

### 2.2 自由现金流在投资决策中的应用

#### 2.2.1 投资项目评估
通过自由现金流计算NPV和IRR，评估项目的可行性和盈利能力。

#### 2.2.2 资本预算决策
自由现金流用于确定资本预算项目是否值得投资。

#### 2.2.3 投资组合优化
通过分析多个项目的自由现金流，优化投资组合以实现最大收益。

## 第3章: 自由现金流分析的理论基础

### 3.1 资本资产定价模型（CAPM）

#### 3.1.1 CAPM的基本原理
CAPM用于确定资产的预期回报率，公式为：
$$\text{预期回报率} = r_f + \beta \times (r_m - r_f)$$
其中，\( r_f \) 是无风险利率，\( r_m \) 是市场预期回报率，\( \beta \) 是贝塔系数。

#### 3.1.2 CAPM在自由现金流分析中的应用
利用CAPM确定资本成本，从而影响自由现金流的计算。

### 3.2 时间价值理论

#### 3.2.1 时间价值的基本概念
时间价值是指资金随着时间的推移而产生的价值变化，包括现值和终值。

#### 3.2.2 时间价值在自由现金流计算中的应用
通过现值和终值计算，将未来现金流折算为当前价值。

### 3.3 财务报表分析基础

#### 3.3.1 资产负债表分析
分析企业的资产、负债和所有者权益，评估企业的财务状况。

#### 3.3.2 利润表分析
分析企业的收入和支出，计算净利润。

#### 3.3.3 现金流量表分析
分析经营活动、投资活动和融资活动的现金流，评估企业的现金流动性。

### 7.2 核心实现

```python
import pandas as pd
import numpy as np

def calculate_fcf(revenue, costs, tax, depreciation, capital_expenditure):
    fcf = revenue - costs - tax - depreciation - capital_expenditure
    return fcf

# 示例数据
data = {
    'Revenue': [100, 200, 300],
    'Costs': [50, 100, 150],
    'Tax': [20, 40, 60],
    'Depreciation': [10, 20, 30],
    'Capital Expenditure': [15, 30, 45]
}

df = pd.DataFrame(data)
df['Free Cash Flow'] = df.apply(lambda row: calculate_fcf(row['Revenue'], row['Costs'], row['Tax'], row['Depreciation'], row['Capital Expenditure']), axis=1)
print(df)
```
