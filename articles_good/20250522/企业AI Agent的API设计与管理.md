- 线性回归公式：$y = \beta_0 + \beta_1x + \epsilon$

- 支持向量机目标函数：$$\min_{\mathbf{w}, b, \xi} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^{n}\xi_i$$
