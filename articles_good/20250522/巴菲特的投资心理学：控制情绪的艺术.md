## 第五章: 数学模型与价值评估

### 5.1 价值评估模型

#### 5.1.1 现金流折现模型（DCF模型）
- 定义：通过预测公司未来现金流，折现到现值，评估公司内在价值。
- 公式：$$ V = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} + \frac{TV}{(1+r)^n} $$
  - $V$：公司价值
  - $CF_t$：第t年的现金流
  - $r$：折现率
  - $TV$：终值

#### 5.1.2 市盈率与市净率模型
- 市盈率：$$ P/E = \frac{P}{E} $$
  - $P$：股价
  - $E$：每股收益
- 市净率：$$ P/B = \frac{P}{B} $$
  - $P$：股价
  - $B$：每股净资产

```python
import numpy as np
import pandas as pd
import scipy.stats as stats

def discounted_cash_flow(cash_flows, discount_rate, terminal_value):
    """
    计算现金流的现值
    """
    present_value = 0
    for t, cf in enumerate(cash_flows):
        if t == 0:
            present_value += cf
        else:
            present_value += cf / (1 + discount_rate) ** t
    present_value += terminal_value / (1 + discount_rate) ** len(cash_flows)
    return present_value

# 示例数据
cash_flows = [100, 150, 200, 250]
discount_rate = 0.08
terminal_value = 500

# 计算现值
value = discounted_cash_flow(cash_flows, discount_rate, terminal_value)
print(f"公司价值: {value:.2f}")
```

def backtest_strategy(prices, strategy):
    """
    回测策略实现
    """
    portfolio = 0
    returns = []
    for i in range(len(prices)):
        if i == 0:
            portfolio = 100000  # 初始资金
            position = 0  # 初始持仓
        else:
            # 根据策略决定买卖
            if strategy[i] == 'Buy':
                position += (portfolio / prices[i])
                portfolio -= (portfolio / prices[i]) * prices[i]
            elif strategy[i] == 'Sell':
                position -= (portfolio / prices[i])
                portfolio += (portfolio / prices[i]) * prices[i]
        returns.append(portfolio)
    return returns

# 示例策略：当MA20 > MA50时买入，否则卖出
