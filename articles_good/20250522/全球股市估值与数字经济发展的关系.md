## 第二章：全球股市估值的基础概念与演变

### 2.1 股市估值的基本概念  
股市估值是评估企业价值的关键指标，常用市盈率（P/E）、市净率（P/B）等指标衡量。

### 2.2 数字经济的定义与特征  
数字经济是以数据和信息技术为驱动力的经济形态，具有数据驱动、创新性和全球化等特点。

### 2.3 两者的关系  
数字经济通过技术创新和数据优势，影响企业的盈利能力和成长潜力，从而影响股市估值。

- **数字经济**：以数据为关键生产要素的经济模式。

## 第四章：算法原理与数学模型

### 4.1 数据准备与预处理  
收集历史股价、市盈率、技术创新指数等数据，清洗和标准化。

### 4.2 算法选择  
采用多元回归模型，将数字经济指标（如技术创新指数）纳入模型，预测股市估值。

### 4.3 数学模型

$$ \text{预测估值} = \beta_0 + \beta_1 \times \text{技术创新指数} + \beta_2 \times \text{市盈率} $$

### 4.4 算法流程（Mermaid）

```mermaid
graph TD
A[数据采集] --> B[数据清洗] --> C[特征选择]
D[模型训练] --> E[模型预测]
```

### 4.5 Python代码实现

```python
import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据加载
data = pd.read_csv('stock_data.csv')

# 特征与目标分离
X = data[['技术创新指数', '市盈率']]
y = data['股价']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测
predicted = model.predict(X)
```

### 6.2 核心代码实现

from sklearn.metrics import mean_squared_error

# 数据加载
data = pd.read_csv('digital_economy_data.csv')
