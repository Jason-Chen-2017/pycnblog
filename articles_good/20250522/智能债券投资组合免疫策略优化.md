### 1.1 债券的基本概念与分类

#### 1.1.1 债券的定义与分类
- 债券是一种债务工具，发行人承诺在特定时间支付利息和本金。

#### 1.1.2 债券市场的运作机制
- 债券发行、交易、结算的基本流程。
- 市场参与者的角色：发行人、投资者、交易商等。

#### 1.1.3 投资组合的基本原理
- 投资组合的概念：将不同债券组合在一起以分散风险。
- 风险与收益的权衡：如何通过组合优化实现收益最大化。

#### 1.2.2 信用风险与市场风险
- 不同债券的信用评级对投资组合的影响。

import numpy as np
from scipy.optimize import minimize

# 定义优化目标函数
def portfolio_objective(weights, returns, risk_free_rate):
    portfolio_return = np.dot(weights, returns)
    portfolio_variance = np.dot(weights.T, np.dot(weights, np.cov(returns.T)))
    return portfolio_variance - risk_free_rate * (portfolio_return - risk_free_rate)

# 约束条件
def constraint(weights):
    return np.sum(weights) - 1

# 优化问题
def optimize_portfolio(returns, risk_free_rate):
    n = len(returns.columns)
    weights = np.ones(n) / n
    result = minimize(portfolio_objective, weights, args=(returns, risk_free_rate), method='SLSQP', constraints={'type': 'eq', 'fun': constraint})
    return result.x

# 使用优化后的权重构建投资组合
