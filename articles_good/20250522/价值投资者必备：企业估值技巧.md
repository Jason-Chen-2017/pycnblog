# 第1章: 价值投资概述

## 1.1 价值投资的核心理念

### 1.1.1 价值投资的定义与起源
价值投资是一种以低于内在价值的价格买入优质资产的投资策略。它起源于20世纪初，以本杰明·格雷厄姆和戴维·多德为代表，强调安全边际和对公司内在价值的深入研究。

### 1.1.2 价值投资的基本原则
- **安全边际**：买入价格低于内在价值，留有安全空间。
- **长期视角**：关注企业的长期盈利能力，而非短期价格波动。
- **独立思考**：避免盲目跟风，坚持独立分析。

### 1.1.3 价值投资与其它投资策略的区别
- **区别**：价值投资注重基本面分析，寻找低估标的；趋势投资关注价格走势，技术分析为主。
- **联系**：两者都以追求超额收益为目标，但方法和理念不同。

## 1.2 企业估值的基本概念

### 1.2.1 企业估值的定义
企业估值是通过对企业未来现金流的折现，估算其内在价值的过程。它是衡量企业投资价值的重要指标。

### 1.2.2 企业估值的核心要素
- **现金流**：企业未来产生的自由现金流。
- **折现率**：反映资金的时间价值和风险溢价。
- **永续增长率**：长期稳定增长的假设。

### 1.2.3 企业估值的常见方法
- **绝对估值法**：DCF模型、股权自由现金流模型。
- **相对估值法**：市盈率、市净率、EV/EBITDA。

## 1.3 价值投资者的思维模式

### 1.3.1 价值投资者的特质
- 理性、耐心、独立思考。
- 专注于长期价值，而非短期波动。

### 1.3.2 价值投资者的决策框架
- 确定投资目标。
- 深入研究标的公司。
- 评估安全边际。
- 严格执行纪律。

### 1.3.3 价值投资者的风险管理策略
- 分散投资，降低风险。
- 设置止损，避免重大损失。
- 定期复盘，优化策略。

# 第3章: 企业估值方法论

## 3.1 现金流贴现模型（DCF）

### 3.1.1 DCF模型的原理与步骤

**DCF模型原理**：
企业价值 = 现金流的现值，通过将未来现金流折现到当前价值。

**步骤**：
1. 预测未来现金流。
2. 确定折现率。
3. 计算现值。
4. 加上残值（如有）。

**Mermaid图表：DCF模型流程**

```mermaid
graph TD
    A[预测现金流] --> B[确定折现率]
    B --> C[计算现值]
    C --> D[企业价值]
```

### 3.1.2 DCF模型的假设与限制
- 现金流预测的准确性。
- 折现率的选择。
- 永续增长率的合理性。

### 3.1.3 DCF模型的优缺点

**优点**：
- 考虑了时间价值和风险。
- 更加注重基本面分析。

**缺点**：
- 对未来现金流预测敏感。
- 假设企业永续经营。

### 3.1.4 DCF模型的数学公式

$$
\text{企业价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} + \frac{\text{残值}}{(1 + r)^n}
$$

其中，$r$ 是折现率，$n$ 是预测期数。

**Python代码示例**：

```python
import numpy as np

def dcf_valuation(cash_flows, discount_rate, terminal_value):
    # 计算现值
    pv = 0
    for t, cf in enumerate(cash_flows):
        pv += cf / (1 + discount_rate) ** t
    # 加上残值
    pv += terminal_value / (1 + discount_rate) ** len(cash_flows)
    return pv

# 示例数据
cash_flows = [100, 150, 200]
discount_rate = 0.1
terminal_value = 500

# 计算企业价值
enterprise_value = dcf_valuation(cash_flows, discount_rate, terminal_value)
print(f"企业价值：{enterprise_value}")
```

## 3.2 相对估值法

### 3.2.1 市盈率（P/E）分析

$$
P/E = \frac{\text{股价}}{\text{每股净利润}}
$$

### 3.2.2 市净率（P/B）分析

$$
P/B = \frac{\text{股价}}{\text{每股净资产}}
$$`

### 3.2.3 EV/EBITDA倍数分析

$$
EV/EBITDA = \frac{\text{企业价值}}{\text{息税折旧及摊销前利润}}
$$

---

## 3.3 股权自由现金流模型

### 3.3.1 FCFF（Free Cash Flow to Firm）的计算

$$
\text{FCFF} = \text{净利润} + \text{非现金费用} - \text{资本支出}
$$`

### 3.3.2 WACC（Weighted Average Cost of Capital）的计算

$$
WACC = w_d \times r_d \times (1 - t) + w_e \times r_e
$$`

其中，$w_d$ 是债务权重，$r_d$ 是债务成本，$t$ 是税率，$w_e$ 是股权权重，$r_e$ 是股权成本。

### 3.3.3 股权价值的计算公式

$$
\text{股权价值} = \text{企业价值} - \text{债务价值}
$$`
