# 第一部分：多智能体系统基础

## 1.1 多智能体系统的核心概念

### 1.1.1 多智能体系统的定义与特点
多智能体系统（Multi-Agent System，MAS）是由多个智能体（Agent）组成的分布式系统，这些智能体通过协作完成共同目标。其特点包括：
- **自主性**：每个智能体能够独立决策和行动。
- **反应性**：智能体能够感知环境并实时响应。
- **协作性**：多个智能体通过通信和协作完成复杂任务。
- **分布式性**：系统中的智能体分布在网络中，不存在集中控制节点。

### 1.1.2 多智能体系统的分类与特点
多智能体系统可以分为以下几类：
1. **简单反射型智能体**：基于当前感知做出反应，不依赖历史信息。
2. **基于模型的反射型智能体**：利用内部模型进行规划和决策。
3. **目标驱动型智能体**：基于明确的目标进行决策和行动。
4. **效用驱动型智能体**：通过最大化效用函数来优化决策。

### 1.1.3 多智能体系统的协作机制
多智能体系统的协作机制包括：
- **通信机制**：智能体之间通过消息传递进行信息交换。
- **协调机制**：通过协商和协议确保各智能体目标一致。
- **分工机制**：根据智能体的能力和任务需求分配任务。

import numpy as np

class MultiAgent:
    def __init__(self, num_agents):
        self.num_agents = num_agents
        self.states = []
        self.actions = []

    def perceive(self, state):
        # 智能体感知环境状态
        self.states.append(state)
        return self.states[-1]

    def decide(self, state):
        # 智能体根据状态做出决策
        action = np.random.choice(len(state))
        return action

    def learn(self, state, action, reward):
        # 智能体学习更新Q值
        self.actions.append((state, action, reward))

class Environment:
    def __init__(self):
        self.agents = []
        self.states = []

    def add_agent(self, agent):
        self.agents.append(agent)

    def step(self):
        for agent in self.agents:
