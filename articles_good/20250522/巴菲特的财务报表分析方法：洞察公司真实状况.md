### 第2章: 财务报表分析的核心概念

#### 2.1 资产负债表
- **资产负债表的结构与内容**：资产、负债、所有者权益三部分构成。
- **资产、负债、所有者权益的定义与特征**：
  - 资产：企业拥有的资源，包括流动资产和非流动资产。
  - 负债：企业欠款，包括流动负债和非流动负债。
  - 所有者权益：企业净资产，等于资产减去负债。
- **资产负债表的编制与解读**：通过资产负债表可以了解企业的财务状况和偿债能力。

#### 2.2 利润表
- **利润表的结构与内容**：营业收入、成本、费用、净利润四部分构成。
- **收入、成本、利润的定义与计算**：
  - 收入：企业在一定时期内通过销售产品或服务获得的收入。
  - 成本：生产产品或提供服务所发生的直接成本。
  - 利润：收入减去成本和费用后的净收益。
- **利润表的编制与解读**：通过利润表可以了解企业的盈利能力。

#### 2.3 现金流量表
- **现金流量表的结构与内容**：经营活动、投资活动、筹资活动的现金流量三部分构成。
- **经营活动、投资活动、筹资活动的现金流量分析**：
  - 经营活动现金流：企业日常经营活动中产生的现金流。
  - 投资活动现金流：企业投资活动产生的现金流。
  - 筹资活动现金流：企业筹资活动产生的现金流。
- **现金流量表的编制与解读**：通过现金流量表可以了解企业的现金流入和流出情况，评估企业的流动性。

### 第3章: 财务报表分析的核心指标与比率

#### 3.1 财务比率分析
- **流动比率、速动比率、存货周转率的定义与计算**：
  - 流动比率 = 流动资产 / 流动负债。
  - 速动比率 = (流动资产 - 存货) / 流动负债。
  - 存货周转率 = 营业成本 / 平均存货。
- **资产负债率、权益乘数、利息保障倍数的定义与计算**：
  - 资产负债率 = 负债总额 / 资产总额。
  - 权益乘数 = 资产总额 / 所有者权益。
  - 利息保障倍数 = 息税前利润 / 利息支出。
- **毛利率、净利率、ROE的定义与计算**：
  - 毛利率 = (营业收入 - 营业成本) / 营业收入。
  - 净利率 = 净利润 / 营业收入。
  - ROE = 净利润 / 平均股东权益。

#### 3.2 财务比率分析的注意事项
- **财务比率的局限性**：财务比率分析受到行业差异、企业规模、会计政策等因素的影响。
- **财务比率的行业差异**：不同行业的财务比率有不同的标准。
- **财务比率的动态变化**：需要结合时间序列数据进行动态分析。

### 第4章: 财务报表分析的数学模型与公式

#### 4.1 财务比率计算公式
- **流动资产与流动负债的计算公式**：
  - 流动资产 = 货币资金 + 应收账款 + 存货 + 其他流动资产。
  - 流动负债 = 短期借款 + 应付账款 + 其他应付款。
- **净利润、营业收入、成本的计算公式**：
  - 净利润 = 营业收入 - 营业成本 - 费用 - 税费。
  - 营业收入 = 收入部分的总和。
  - 成本 = 生产产品或提供服务所发生的直接成本。
- **毛利率、净利率的计算公式**：
  - 毛利率 = (营业收入 - 营业成本) / 营业收入。
  - 净利率 = 净利润 / 营业收入。

#### 4.2 财务健康度评估模型
- **Z-Score模型的定义与公式**：
  - Z-Score = 1.2A + 1.4B + 3.3C + 3.6D + 1.0E。
  - 其中，A = 营业收入 / 平均总资产，B = 净利润 / 营业收入，C = 营业成本 / 营业收入，D = 净利润 / 总资产，E = 股东权益 / 总资产。
- **Altman Z-Score模型的计算公式**：
  - Altman Z-Score = 1.2(Working Capital/Total Assets) + 1.4(Revenue/Total Assets) + 3.3(COGS/Revenue) + 3.6(Net Profit/Total Assets) + 1.0(Net Profit/Total Assets)。
- **其他财务健康度评估模型的对比分析**：包括Altman Z-Score模型、Zmijewski模型等。
