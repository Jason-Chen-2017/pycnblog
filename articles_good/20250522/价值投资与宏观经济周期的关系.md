### 附录: 价值投资与宏观经济周期的代码示例

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 示例数据：宏观经济指标与股票价格
data = {
    'GDP增长率': [2.5, 3.1, 2.8, 3.5, 2.2],
    '失业率': [6.2, 5.8, 6.3, 5.9, 6.1],
    '股票价格': [100, 110, 95, 120, 90]
}

df = pd.DataFrame(data)

# 训练线性回归模型：宏观经济指标对股票价格的影响
model = LinearRegression()
model.fit(df[['GDP增长率', '失业率']], df['股票价格'])

# 预测股票价格
new_data = {'GDP增长率': [3.0], '失业率': [6.0]}
new_df = pd.DataFrame(new_data)
predicted_price = model.predict(new_df)
print(f'预测股票价格：{predicted_price[0]:.2f}')
```
