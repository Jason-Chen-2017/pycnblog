## 第四部分：分散投资与集中投资的对比分析

### 第4章：两种投资策略的优缺点对比

#### 4.1 分散投资的优点
- 风险分散，稳定性高
- 降低单一投资的风险
- 适合风险厌恶型投资者

#### 4.2 分散投资的缺点
- 可能错过大牛股
- 管理成本较高
- 需要更多的研究和分散投资品种

#### 4.3 集中投资的优点
- 高收益潜力
- 简化投资决策
- 适合长期看好少数优质企业

#### 4.4 集中投资的缺点
- 风险集中，波动性大
- 投资品种有限，可能错失其他机会
- 需要极高的选股能力

#### 8.2 核心实现源代码
- **数学模型与公式**：
  - 分散投资的风险模型：
    $$ \text{风险} = \sqrt{\sum_{i=1}^{n} w_i^2 \sigma_i^2} $$
  - 集中投资的回报模型：
    $$ \text{回报} = \sum_{i=1}^{m} w_i r_i $$
  - 风险调整后的回报：
    $$ \text{夏普比率} = \frac{(\text{平均回报} - \text{无风险利率})}{\text{标准差}} $$

- **源代码实现**：
  ```python
  import pandas as pd
  import numpy as np

  def calculate_risk(weights, returns):
      variances = np.array([r**2 for r in returns])
      return np.sqrt(np.dot(weights.T, variances.dot(weights)))

  def calculate_return(weights, returns):
      return np.sum(weights * returns)

  def calculate_sharpe(weights, returns, risk_free_rate):
      return calculate_return(weights, returns) - risk_free_rate / calculate_risk(weights, returns)

  # 示例数据
  returns = [0.1, 0.15, 0.05, 0.2]
  weights = [0.25, 0.3, 0.25, 0.2]

  # 计算并输出结果
  print("风险:", calculate_risk(weights, returns))
  print("回报:", calculate_return(weights, returns))
  print("夏普比率:", calculate_sharpe(weights, returns, 0.01))
  ```

#### 8.3 代码应用解读与分析
- 代码功能说明：
  - `calculate_risk`：计算投资组合的风险（标准差）
  - `calculate_return`：计算投资组合的预期回报
  - `calculate_sharpe`：计算夏普比率，评估风险调整后的回报

## 第八部分：结论与附录

### 第10章：结论

#### 10.1 核心观点总结
- 分散投资的优势：风险低，稳定性高。
- 集中投资的优势：回报潜力大，适合长期投资。
- 根据市场环境和个人情况选择策略。

#### 10.2 投资策略选择的建议
- 初期投资者建议采用分散投资降低风险。
- 高风险承受能力的投资者可以尝试集中投资。
- 组合策略：根据市场变化灵活调整投资比例。

#### 10.3 风险管理的重要性
- 无论采用哪种策略，风险管理都是不可忽视的部分。
- 定期 rebalancing 投资组合，控制风险敞口。
