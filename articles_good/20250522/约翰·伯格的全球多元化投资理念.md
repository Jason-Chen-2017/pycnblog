# 第2章：投资组合理论与多元化原理

## 2.1 投资组合理论的起源与发展

投资组合理论起源于20世纪，现代投资组合理论（MPT）由哈里·马科维茨提出，强调通过分散投资来优化风险与收益。

---

## 2.2 多元化投资的基本原理

多元化投资通过配置不同资产类别来降低特定风险。以下是几种常见的资产配置策略：

1. **股票配置**：包括不同行业的公司股票。
2. **债券配置**：包括政府债券和公司债券。
3. **房地产配置**：通过房地产投资信托（REITs）实现。
4. **商品配置**：如黄金、原油等。

---

## 2.3 现代投资组合理论（MPT）的数学模型

现代投资组合理论的核心是优化投资组合的风险与收益。以下是最优化问题的数学模型：

$$ \text{目标函数} = \min_w \{ \sigma^2(w) \} $$
$$ \text{约束条件} = w^T \mu = r, \quad w^T \mathbf{1} = 1 $$

其中，\( w \) 是权重向量，\( \mu \) 是收益向量，\( \sigma^2(w) \) 是投资组合的方差。

# 第4章：风险管理与投资组合优化

## 4.1 风险的定义与分类

风险是投资回报的不确定性。常见的风险类型包括市场风险、流动性风险和信用风险。

---

## 4.2 投资组合的风险调整收益分析

通过夏普比率（Sharpe Ratio）可以评估投资组合的风险调整收益：

$$ \text{夏普比率} = \frac{E[r_i - r_f]}{\sigma_i} $$

其中，\( E[r_i - r_f] \) 是投资组合的超额收益，\( \sigma_i \) 是其标准差。

---

## 4.3 约翰·伯格的风险管理实践

约翰·伯格强调定期再平衡投资组合，以保持目标配置，并根据市场变化进行调整。

## 5.1 投资组合优化的数学模型与算法

$$ \min_w \sum_{i=1}^n w_i^2 \sigma_i^2 $$
$$ \text{约束条件} = \sum_{i=1}^n w_i = 1 $$

## 7.2 核心算法实现

以下是Python代码实现：

```python
import numpy as np

def optimize_portfolio(returns):
    n = len(returns)
    # 计算协方差矩阵
    cov_matrix = np.cov(returns)
    # 使用拉格朗日乘数法优化
    C = np.dot(cov_matrix, np.ones(n))
    A = np.ones(n)
    b = np.array([1.0])
    # 解线性规划问题
    weights = np.linalg.solve(C, A)
    weights = weights / np.sum(weights)
    return weights

# 示例数据
returns = np.array([0.1, 0.12, 0.08])
weights = optimize_portfolio(returns)
print(weights)
```
