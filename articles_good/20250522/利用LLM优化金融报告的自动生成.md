### 第2章 LLM基础

#### 2.1 LLM的定义与特点
- 2.1.1 LLM的定义
  - 基于Transformer架构的模型
  - 能够处理长上下文
  - 支持多种任务，如生成、翻译和问答

- 2.1.2 核心特点
  - 自然语言理解能力强
  - 能够生成高质量文本
  - 具备上下文推理能力

- 2.1.3 与传统NLP的区别
  - 基于深度学习，而非浅层模型
  - 支持端到端训练，而非依赖规则
  - 能够处理复杂的语言结构

#### 2.2 LLM的训练与优化
- 2.2.1 基础训练方法
  - 预训练：使用大规模通用数据进行无监督训练
  - 微调：在特定领域数据上进行有监督训练
  - 适应性调整：根据任务需求优化模型参数

- 2.2.2 优化策略
  - 提示工程：设计合理的提示以引导生成内容
  - 温度参数调整：控制生成的随机性和创造性
  - 模型 ensemble：结合多个模型生成结果

- 2.2.3 模型评估指标
  - BLEU：评估生成文本与参考文本的相似度
  - ROUGE：基于召回率评估生成质量
  - 复算准确率：结合领域知识评估准确性

- 5.3.1 完整代码示例

  ```python
  import torch
  from transformers import AutoModelForCausalLM, AutoTokenizer

  def generate_report(data):
      model_name = "gpt2"
      tokenizer = AutoTokenizer.from_pretrained(model_name)
      model = AutoModelForCausalLM.from_pretrained(model_name)
      processed_data = preprocess(data)
      prompt = construct_prompt(processed_data)
      inputs = tokenizer.encode(prompt, return_tensors="pt")
      outputs = model.generate(inputs, max_length=500)
      generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
      return generated_text

  # 示例数据
  data = pd.DataFrame({
      'date': ['2023-01-01', '2023-01-02'],
      'revenue': [100000, 120000],
      'expenses': [80000, 95000]
  })
  print(generate_report(data))
  ```
