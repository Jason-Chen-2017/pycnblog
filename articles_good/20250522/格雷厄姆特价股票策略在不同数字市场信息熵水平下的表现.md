### 1.2 信息熵的基本概念

#### 1.2.1 信息论与熵的定义
熵是信息论中的基本概念，表示数据的不确定性。熵值越高，数据的不确定性越大。公式如下：

$$
H(X) = -\sum_{i=1}^{n} p_i \log p_i
$$

其中，$H(X)$ 是熵，$p_i$ 是第 $i$ 个事件发生的概率。

#### 1.2.2 信息熵在金融市场的应用
金融市场中的信息熵反映了市场的不确定性。高熵市场意味着信息混乱，低熵市场则表示信息集中。通过量化市场熵，投资者可以更好地理解市场的波动性。

#### 1.2.3 数字市场中的信息熵特征
数字市场具有高频交易、数据量大、信息传播快的特点。这些特点使得信息熵在数字市场中的应用更加重要。

import math

def calculate_entropy(data):
    # 计算概率分布
    prob = data.value_counts(normalize=True)
    # 计算熵
    entropy = -sum(prob * math.log(prob, 2))
    return entropy
