#### 第5章：投资者心理的数学模型
- **5.1 情绪指标的数学模型**
  - 公式：$$情绪指标 = \sum_{i=1}^{n} (情绪强度_i \times 权重_i)$$
  - 参数解释：情绪强度_i为各个投资者的情绪强度，权重_i为各个投资者的权重
  - 案例分析：假设三个投资者的情绪强度分别为0.8、0.6、0.5，权重分别为0.4、0.3、0.3，计算情绪指标：
    $$情绪指标 = 0.8 \times 0.4 + 0.6 \times 0.3 + 0.5 \times 0.3 = 0.32 + 0.18 + 0.15 = 0.65$$
- **5.2 认知偏差的数学模型**
  - 公式：$$认知偏差度 = \frac{\sum_{j=1}^{m} (偏差程度_j \times 类别权重_j)}{\sum_{j=1}^{m} 类别权重_j}$$
  - 参数解释：偏差程度_j为各个偏差的程度，类别权重_j为各个偏差类型的权重
  - 案例分析：假设三种偏差程度分别为0.7、0.5、0.3，权重分别为0.5、0.3、0.2，计算认知偏差度：
    $$认知偏差度 = \frac{0.7 \times 0.5 + 0.5 \times 0.3 + 0.3 \times 0.2}{0.5 + 0.3 + 0.2} = \frac{0.35 + 0.15 + 0.06}{1.0} = 0.56$$
