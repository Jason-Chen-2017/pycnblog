1. **自回归模型（AR）**：

- **定义**：AR模型假设当前时间点的值取决于之前若干时间点的值。
- **公式**：\( X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + \varepsilon_t \)

- **定义**：MA模型假设当前时间点的值是过去若干个时间点的值的加权平均。
- **公式**：\( X_t = c + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q} \)
- **特点**：适用于非平稳时间序列。

3. **自回归移动平均模型（ARMA）**：

- **定义**：ARMA模型结合了AR和MA模型的特点，即当前时间点的值既受过去值的直接影响，也受过去误差值的直接影响。
- **公式**：\( X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q} \)
- **特点**：适用于平稳时间序列。

4. **集成自回归移动平均模型（ARIMA）**：

- **定义**：ARIMA模型是ARMA模型在非平稳序列上的扩展，通过差分使时间序列平稳。
- **公式**：\( X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + (\theta_1 D(X_{t-1}) + \theta_2 D(X_{t-2}) + \cdots + \theta_q D(X_{t-q})) \)
- **特点**：适用于非平稳时间序列。

1. **自回归模型（AR）**：

   自回归模型假设当前时间点的值取决于之前若干时间点的值。其公式为：

   其中，$X_t$ 是当前时间点的值，$c$ 是常数项，$\phi_1, \phi_2, \cdots, \phi_p$ 是自回归系数，$\varepsilon_t$ 是随机误差项。

2. **移动平均模型（MA）**：

   移动平均模型假设当前时间点的值是过去若干个时间点的值的加权平均。其公式为：
   
   $$ X_t = c + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q} $$
   
   其中，$\theta_1, \theta_2, \cdots, \theta_q$ 是移动平均系数。

3. **自回归移动平均模型（ARMA）**：

   自回归移动平均模型结合了AR和MA模型的特点，其公式为：
   
   $$ X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q} $$
   
   其中，$\phi_1, \phi_2, \cdots, \phi_p$ 是自回归系数，$\theta_1, \theta_2, \cdots, \theta_q$ 是移动平均系数。

4. **集成自回归移动平均模型（ARIMA）**：

   集成自回归移动平均模型是ARMA模型在非平稳序列上的扩展，其公式为：
   
   $$ X_t = c + \phi_1 X_{t-1} + \phi_2 X_{t-2} + \cdots + \phi_p X_{t-p} + (\theta_1 D(X_{t-1}) + \theta_2 D(X_{t-2}) + \cdots + \theta_q D(X_{t-q})) $$
   
   其中，$D(X_t)$ 表示对时间序列进行差分操作。

这些时间序列模型通过分析历史数据，可以帮助预测未来金融时间序列的走势，是金融时间序列分析中的重要工具。

#### 2.5.2 因果关系网络算法

因果关系网络分析的核心在于从数据中推断出变量之间的因果关系。以下介绍几种常用的因果关系网络算法：

1. **结构方程模型（SEM）**：

   结构方程模型是一种统计方法，用于分析变量之间的直接和间接关系。其基本原理是通过构建路径图，分析变量之间的因果关系。

   SEM的公式为：
   
   $$ Y = \alpha_0 + \alpha_1 X + \varepsilon_y $$
   $$ X = \beta_0 + \beta_1 Y + \varepsilon_x $$
   
   其中，$Y$ 和 $X$ 是两个变量，$\alpha_0, \alpha_1, \beta_0, \beta_1$ 是路径系数，$\varepsilon_y$ 和 $\varepsilon_x$ 是误差项。

2. **因果发现算法**：

   因果发现算法是一种机器学习方法，通过分析数据自动识别变量之间的因果关系。常见的因果发现算法包括基于假设检验的方法和基于模型的方法。

   基于假设检验的方法如Do计算，通过构造干预实验来验证变量之间的因果关系。

   基于模型的方法如图神经网络，通过构建图模型来分析变量之间的因果关系。

3. **因果推断方法**：

   因果推断方法是一种逻辑推理方法，通过构建理论模型或使用假设检验方法来推断变量之间的因果关系。

   常见的因果推断方法包括倾向得分匹配、双重差分法等，这些方法通过对比不同条件下的结果，推断变量之间的因果关系。
