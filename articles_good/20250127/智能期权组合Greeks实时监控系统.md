#### 3.1 Greeks计算的基本原理

Greeks计算是基于布莱克-斯科尔斯模型（Black-Scholes Model）或其他期权定价模型。布莱克-斯科尔斯模型是期权定价理论的核心，它通过数学公式描述了期权价格与标的资产价格、波动率、执行价格、到期时间和无风险利率之间的关系。Greeks参数的数值可以通过对布莱克-斯科尔斯模型的偏导数计算得到。

**布莱克-斯科尔斯模型基本公式：**

$$
C = S_0 \cdot \phi(d_1) - K \cdot e^{-rT} \cdot \phi(d_2)
$$

$$
P = K \cdot e^{-rT} \cdot \phi(-d_2) - S_0 \cdot \phi(-d_1)
$$

其中：
- \( C \) 和 \( P \) 分别代表看涨期权和看跌期权的价格。
- \( S_0 \) 是标的资产当前价格。
- \( K \) 是期权的执行价格。
- \( r \) 是无风险利率。
- \( T \) 是期权到期时间。
- \( \phi \) 是标准正态分布的累积分布函数。

**Greeks参数计算公式：**

- **Delta（Δ）：**
  $$
  \Delta = \frac{\partial C}{\partial S_0} = \phi(d_1)
  $$

- **Gamma（Γ）：**
  $$
  \Gamma = \frac{\partial \Delta}{\partial S_0} = \frac{1}{S_0 \cdot \sigma \sqrt{T}} \cdot \phi(d_1)
  $$

- **Theta（Θ）：**
  $$
  \Theta = \frac{\partial C}{\partial T} = -S_0 \cdot \phi'(d_1) \cdot \sigma \sqrt{T} - r \cdot K \cdot e^{-rT} \cdot \phi(-d_2)
  $$

- **Vega（V）：**
  $$
  \Vega = \frac{\partial C}{\partial \sigma} = S_0 \cdot \phi'(d_1) \cdot \sqrt{T}
  $$

- **Rho（ρ）：**
  $$
  \rho = \frac{\partial C}{\partial r} = K \cdot T \cdot e^{-rT} \cdot \phi(-d_2)
  $$

import numpy as np
from scipy.stats import norm

def black_scholes(S0, K, r, T, sigma):
    d1 = (np.log(S0 / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    
    C = S0 * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    P = K * np.exp(-r * T) * norm.cdf(-d2) - S0 * norm.cdf(-d1)
    
    Delta = norm.cdf(d1)
    Gamma = (1 / (S0 * sigma * np.sqrt(T))) * norm.pdf(d1)
    Theta = -S0 * norm.pdf(d1) * sigma * np.sqrt(T) - r * K * np.exp(-r * T) * norm.cdf(-d2)
    Vega = S0 * norm.pdf(d1) * np.sqrt(T)
    Rho = K * T * np.exp(-r * T) * norm.cdf(-d2)
    
    return Delta, Gamma, Theta, Vega, Rho

# 示例参数

K = 100   # 执行价格
r = 0.05  # 无风险利率
T = 1     # 到期时间（年）
sigma = 0.2  # 波动率

Delta, Gamma, Theta, Vega, Rho = black_scholes(S0, K, r, T, sigma)

print("Gamma:", Gamma)
print("Theta:", Theta)
print("Vega:", Vega)
print("Rho:", Rho)
```

from flask import Flask, request, jsonify
import numpy as np
from scipy.stats import norm

app = Flask(__name__)

def black_scholes(S0, K, r, T, sigma):
    d1 = (np.log(S0 / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    
    C = S0 * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    P = K * np.exp(-r * T) * norm.cdf(-d2) - S0 * norm.cdf(-d1)
    
    Delta = norm.cdf(d1)
    Gamma = (1 / (S0 * sigma * np.sqrt(T))) * norm.pdf(d1)
    Theta = -S0 * norm.pdf(d1) * sigma * np.sqrt(T) - r * K * np.exp(-r * T) * norm.cdf(-d2)
    Vega = S0 * norm.pdf(d1) * np.sqrt(T)
    Rho = K * T * np.exp(-r * T) * norm.cdf(-d2)
    
    return {
        'Delta': Delta,
        'Gamma': Gamma,
        'Theta': Theta,
        'Vega': Vega,
        'Rho': Rho
    }

@app.route('/api/greeks/calculate', methods=['POST'])
def calculate_greeks():
    data = request.json
    S0 = data['S0']
    K = data['K']
    r = data['r']
    T = data['T']
    sigma = data['sigma']
    
    greeks = black_scholes(S0, K, r, T, sigma)
    return jsonify(greeks)

if __name__ == '__main__':
    app.run(debug=True)
```
