import numpy as np
import matplotlib.pyplot as plt

def sine_fit(x, y):
    """基于正弦函数拟合数据"""
    # 参数初始化
    A = np.mean(y)
    B = np.std(y)
    omega = 2 * np.pi / 24  # 假设周期为24小时
    phi = np.mean(x * np.sin(omega * x))

    # 拟合正弦曲线
    y_fit = A + B * np.sin(omega * x + phi)
    return y_fit

def main():
    # 生成模拟数据
    x = np.linspace(0, 24, 100)
    y = 0.5 * np.sin(np.pi * x / 12) + np.random.normal(0, 0.1, 100)

    # 拟合正弦曲线
    y_fit = sine_fit(x, y)

    # 绘制结果
    plt.plot(x, y, 'o', x, y_fit, '-')
    plt.xlabel('Time (hours)')
    plt.ylabel('Value')
    plt.title('Sine Fit of Biological Rhythm')
    plt.show()

if __name__ == "__main__":
    main()

### 4.1 生物节律数学模型

1. **周期模型**：
   周期模型是最基本的生物节律模型，通常使用正弦函数或余弦函数来描述。例如，昼夜节律可以用以下正弦函数模型表示：
   \[ y(t) = A \sin(\omega t + \phi) + B \]
   其中，\( A \) 是振幅，\( \omega \) 是角频率，\( \phi \) 是相位，\( B \) 是均值。

2. **非线性模型**：
   非线性模型用于描述生物节律中的复杂动态行为，例如多周期现象和混沌行为。一个常见的非线性模型是Logistic映射：
   \[ x_{n+1} = r x_n (1 - x_n) \]
   其中，\( x_n \) 是第 \( n \) 个时间点的状态，\( r \) 是控制参数。

3. **随机模型**：
   随机模型用于描述生物节律中的随机波动和不确定性。一个常见的随机模型是高斯过程：
   \[ y(t) = f(t) + \eta(t) \]
   其中，\( f(t) \) 是确定性部分，\( \eta(t) \) 是随机噪声。

### 4.2 周期性数学模型

周期性数学模型用于描述自然界中各种周期性现象，包括物理、化学和生物领域。以下是一些常见的周期性数学模型：

1. **正弦波模型**：
   正弦波模型是最简单的周期性模型，用于描述周期性变化的振荡现象。其公式为：
   \[ y(t) = A \sin(\omega t + \phi) \]
   其中，\( A \) 是振幅，\( \omega \) 是角频率，\( \phi \) 是相位。

2. **余弦波模型**：
   余弦波模型与正弦波模型相似，但使用余弦函数代替正弦函数。其公式为：
   \[ y(t) = A \cos(\omega t + \phi) \]

3. **方波模型**：
   方波模型用于描述周期性变化中的开关现象。其公式为：
   \[ y(t) = \text{rect}(\omega t - \phi) \]
   其中，\( \text{rect}(x) \) 是矩形函数，当 \( x \) 在 \([-\frac{\phi}{\omega}, \frac{\phi}{\omega}]\) 内时，取值为1，否则为0。

2. **余弦函数模型**：
   \[ y(t) = A \cos(\omega t + \phi) + B \]
   这与正弦函数模型相似，只是使用余弦函数代替正弦函数。余弦函数相对于正弦函数相位上有一个相位差 \(\frac{\pi}{2}\)。

3. **Logistic映射**：
   \[ x_{n+1} = r x_n (1 - x_n) \]
   这个模型是一个非线性模型，用于描述生物节律中的混沌现象。其中，\( r \) 是控制参数，\( x_n \) 是第 \( n \) 个时间点的状态。当 \( r \) 在某个特定范围内时，模型会产生周期性的混沌行为。

### 4.5 举例说明

为了更好地理解这些数学模型，我们可以通过一个实际例子来讲解。假设我们要分析某植物的光周期反应，并建立正弦函数模型来描述其光周期节律。

1. **数据收集**：
   假设我们收集了该植物在不同光照强度下的生长高度数据，数据如下：

   | 光照强度（lux） | 生长高度（cm） |
   |----------------|--------------|
   |     1000      |      10.0    |
   |     2000      |      15.0    |
   |     3000      |      18.0    |
   |     4000      |      12.0    |
   |     5000      |      20.0    |

2. **数据预处理**：
   首先，我们需要对数据进行预处理，包括去噪和归一化。假设我们通过差分方法去除噪声，并对数据进行归一化处理。

   ```python
   import numpy as np

   # 原始数据
   data = np.array([10.0, 15.0, 18.0, 12.0, 20.0])

   # 去噪
   noise = np.random.normal(0, 0.1, data.shape)
   data_noisy = data + noise

   # 归一化
   data_normalized = (data_noisy - np.mean(data_noisy)) / np.std(data_noisy)
   ```

3. **拟合正弦曲线**：
   接下来，我们使用正弦函数模型来拟合预处理后的数据，以识别节律。

   ```python
   from scipy.optimize import curve_fit

   # 拟合正弦曲线
   def sine_func(x, A, omega, phi, B):
       return A * np.sin(omega * x + phi) + B

   p0 = [1.0, 2 * np.pi / 24, 0, 0]  # 初始化参数
   params, _ = curve_fit(sine_func, x, data_normalized)

   # 拟合结果
   y_fit = sine_func(x, *params)
   ```

4. **绘制结果**：
   最后，我们绘制拟合结果，以验证识别的正确性。

   ```python
   import matplotlib.pyplot as plt

   plt.plot(x, data_normalized, 'o', x, y_fit, '-')
   plt.xlabel('Light Intensity (lux)')
   plt.ylabel('Growth Height (cm)')
   plt.title('Sine Fit of Plant Growth')
   plt.show()
   ```

通过这个例子，我们可以看到如何利用正弦函数模型来描述植物的光周期反应节律。这个过程不仅帮助我们理解了模型的应用，还展示了如何在实际数据中应用这些模型。
