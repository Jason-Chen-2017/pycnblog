### 6.2 数学公式的应用与讲解

以下是几个在探测原初引力波背景研究中常用的数学公式及其解释：

   $$ F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-j\omega t} dt $$
   
   其中，$F(\omega)$是频域信号，$f(t)$是时域信号，$\omega$是频率。

2. **小波变换**：小波变换是傅里叶变换的一种扩展，它能够同时提供时间和频率信息，有助于分析信号的局部特性。

   $$ W(f,t) = \int_{-\infty}^{\infty} f(t) \psi^*(f,t) df $$
   
   其中，$W(f,t)$是时频表示，$\psi^*(f,t)$是小波函数。

3. **最大似然估计**：最大似然估计是一种参数估计方法，用于找到使观测数据出现的概率最大的参数值。

   $$ \theta_{ML} = \arg \max_{\theta} p(data | \theta) $$
   
   其中，$\theta_{ML}$是最大似然估计值，$p(data | \theta)$是似然函数。

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.fft import fft
from sklearn.ensemble import RandomForestClassifier

# 数据加载
data = pd.read_csv('gravity_waves.csv')

# 数据预处理
data = data.dropna()  # 去除缺失值
data = data[data['amplitude'] > 0.1]  # 去除小振幅数据

# 特征提取
data['fft'] = fft(data['signal'])  # 进行傅里叶变换
data['freq'] = np.linspace(0, 1/(2*np.pi), len(data))  # 计算频率

# 特征选择
selected_features = data[['fft', 'freq', 'amplitude', 'phase']]

# 模型训练
model = RandomForestClassifier(n_estimators=100)
model.fit(selected_features, data['label'])

# 模型评估
predictions = model.predict(selected_features)
accuracy = np.mean(predictions == data['label'])
print(f'模型准确率：{accuracy:.2f}')
