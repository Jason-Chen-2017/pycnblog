### 3.2 查找算法

#### 3.2.1 线性查找

线性查找是最简单的查找算法之一，其基本思想是逐个比较数组中的元素，直到找到目标元素或到达数组末尾。

**时间复杂度**：O(n)，其中n为数据规模。

**空间复杂度**：O(1)，不占用额外空间。

def linear_search(arr, target):

#### 3.2.2 二分查找

二分查找是一种高效的查找算法，其基本思想是将有序数组分成两半，根据目标值与中间元素的比较结果，决定下一步查找的方向。

**时间复杂度**：O(log n)，其中n为数据规模。

**空间复杂度**：O(1)，不占用额外空间。

**Python代码示例**：

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

### 3.3 排序算法

#### 3.3.1 冒泡排序

冒泡排序是一种简单的排序算法，其基本思想是通过多次遍历待排序的数组，比较相邻的两个元素，如果顺序错误就交换它们，直到整个数组有序。

**时间复杂度**：O(n^2)，其中n为数据规模。

**空间复杂度**：O(1)，不占用额外空间。

**Python代码示例**：

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]

#### 3.3.2 快速排序

快速排序是一种高效的排序算法，其基本思想是通过选取一个基准元素，将数组分成两部分，一部分比基准元素小，一部分比基准元素大，然后递归地对这两部分进行快速排序。

**时间复杂度**：平均情况下为O(n log n)，最坏情况下为O(n^2)。

**空间复杂度**：O(log n)，需要额外的栈空间。

**Python代码示例**：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

### 3.4 图算法

#### 3.4.1 深度优先搜索（DFS）

深度优先搜索是一种用于图遍历的算法，其基本思想是沿着某一路径深人遍历图，直到该路径到尽头，然后退回上一个分支点再探索另一条路径。
