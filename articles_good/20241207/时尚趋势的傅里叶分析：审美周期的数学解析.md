### 2.1 傅里叶分析的基本原理

傅里叶分析是一种重要的数学工具，它能够将复杂的信号分解为简单的正弦波和余弦波的组合。这种分解方法在信号处理、图像处理、通信系统等多个领域都有广泛的应用。

#### 傅里叶级数

傅里叶级数的基本思想是将一个周期性信号表示为一系列正弦波和余弦波的叠加。对于一个周期为\(T\)的连续时间信号\(x(t)\)，其傅里叶级数可以表示为：

\[ x(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} [a_n \cos(n \omega_0 t) + b_n \sin(n \omega_0 t)] \]

其中，\(a_0\)、\(a_n\) 和 \(b_n\) 分别是傅里叶级数的系数，\(\omega_0 = \frac{2\pi}{T}\) 是基频。

#### 傅里叶变换

傅里叶变换是傅里叶级数在连续时间信号中的应用，它将时间域的信号转换到频率域。对于连续时间信号\(x(t)\)，其傅里叶变换定义为：

\[ X(f) = \int_{-\infty}^{\infty} x(t) e^{-j2\pi ft} dt \]

傅里叶变换具有许多重要的性质，如线性、时间移位、频移和频域缩放等，这些性质使得傅里叶变换在信号处理中非常有用。

#### 离散傅里叶变换

在实际应用中，通常处理的是离散时间信号。离散傅里叶变换（DFT）将离散时间信号转换为频率域的离散表示。对于长度为\(N\)的离散时间信号\(x[n]\)，其DFT定义为：

\[ X[k] = \sum_{n=0}^{N-1} x[n] e^{-j2\pi kn/N} \]

DFT的计算可以通过快速傅里叶变换（FFT）算法来实现，大大提高了计算效率。

### 2.2 傅里叶变换及其应用

傅里叶变换在信号处理中有着广泛的应用，主要包括信号分解与重构、频率域分析和图像处理。

#### 信号分解与重构

通过傅里叶变换，可以将一个复杂的信号分解为一系列不同频率的正弦波和余弦波的组合。这种分解方法有助于我们更好地理解信号的特征和结构。例如，在音频处理中，可以通过傅里叶变换将音频信号分解为不同的频率成分，然后对这些频率成分进行单独处理。

#### 频率域分析

#### 图像处理

傅里叶变换在图像处理中也具有重要作用。通过傅里叶变换，可以将图像从空间域转换到频率域，从而进行频率域滤波、边缘检测、图像压缩等操作。例如，傅里叶变换可以用于图像去噪，通过抑制高频噪声成分来提高图像质量。

import numpy as np
from scipy.fft import fft

N = len(normalized_sales_data)

n = np.arange(N)

T_n = 2/T * np.abs(fft(normalized_sales_data))
a0 = np.mean(normalized_sales_data)
a_n = 2/T * np.abs(fft(normalized_sales_data))[:N//2]
