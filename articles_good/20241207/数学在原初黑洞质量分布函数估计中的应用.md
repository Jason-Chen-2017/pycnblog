**2.1.2 相关数学公式的详细讲解**

在研究原初黑洞质量分布函数的过程中，我们还需要一些相关的数学公式，以下是一些常用的数学公式及其详细讲解：

1. **高斯分布**：

   高斯分布是一种常见的概率分布函数，其表达式为：

   \[
   \rho(M) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(M - \mu)^2}{2\sigma^2}}
   \]

   其中，\(\mu\) 表示均值，\(\sigma\) 表示标准差。高斯分布函数在数据分析中具有广泛的应用，可用于描述原初黑洞质量分布的统计学特征。

2. **最大似然估计**：

   最大似然估计是一种常用的参数估计方法，其基本思想是找到一组参数，使得观测数据的概率最大。对于质量分布函数的参数估计，我们可以使用最大似然估计方法：

   \[
   \hat{\mu} = \frac{1}{N} \sum_{i=1}^{N} M_i, \quad \hat{\sigma} = \sqrt{\frac{1}{N-1} \sum_{i=1}^{N} (M_i - \mu)^2}
   \]

   其中，\(N\) 表示观测数据总数，\(M_i\) 表示第 \(i\) 个观测值。

3. **马尔可夫链蒙特卡洛（MCMC）方法**：

   马尔可夫链蒙特卡洛方法是一种高效的参数估计方法，可用于解决复杂的概率分布问题。在质量分布函数的估计中，我们可以使用 MCMC 方法进行参数抽样和估计：

   \[
   M_{t+1} = f(M_t) + \xi_t, \quad \xi_t \sim N(0, I)
   \]

   其中，\(M_t\) 表示第 \(t\) 次抽样的参数值，\(\xi_t\) 表示随机噪声，\(I\) 表示单位矩阵。

其中，\(\mu\) 表示均值，\(\sigma\) 表示标准差。这个公式描述了黑洞质量 \(M\) 出现的概率，均值 \(\mu\) 反映了黑洞质量的集中程度，标准差 \(\sigma\) 反映了质量的分散程度。

**3.2.2 举例说明**

假设我们有一个观测数据集，其中包含10个黑洞的质量数据，分别为：

\[M_1 = 1.2, M_2 = 1.8, M_3 = 2.1, M_4 = 2.4, M_5 = 2.7, M_6 = 3.0, M_7 = 3.2, M_8 = 3.5, M_9 = 3.8, M_{10} = 4.1\]

我们希望使用高斯分布来估计黑洞的质量分布函数。

1. **计算均值和标准差**：

   首先计算观测数据的均值：

   \[
   \mu = \frac{1}{10} \sum_{i=1}^{10} M_i = \frac{1.2 + 1.8 + 2.1 + 2.4 + 2.7 + 3.0 + 3.2 + 3.5 + 3.8 + 4.1}{10} = 2.89
   \]

   接着计算观测数据的标准差：

   \[
   \sigma = \sqrt{\frac{1}{10-1} \sum_{i=1}^{10} (M_i - \mu)^2} = \sqrt{\frac{1}{9} \left[ (1.2 - 2.89)^2 + (1.8 - 2.89)^2 + \ldots + (4.1 - 2.89)^2 \right]} \approx 0.98
   \]

2. **构建高斯分布模型**：

   根据计算得到的均值和标准差，我们可以构建高斯分布模型：

   \[
   f(M) = \frac{1}{\sqrt{2\pi \times 0.98^2}} e^{-\frac{(M - 2.89)^2}{2 \times 0.98^2}}
   \]

3. **计算特定质量的概率**：

   例如，我们想知道质量为3.0的黑洞出现的概率。代入公式计算：

   \[
   f(3.0) = \frac{1}{\sqrt{2\pi \times 0.98^2}} e^{-\frac{(3.0 - 2.89)^2}{2 \times 0.98^2}} \approx 0.12
   \]

   这意味着质量为3.0的黑洞出现的概率约为12%。

通过这个例子，我们可以看到如何使用高斯分布模型来估计原初黑洞的质量分布函数，以及如何计算特定质量的概率。

plt.ylabel('f(M) (概率密度)')
