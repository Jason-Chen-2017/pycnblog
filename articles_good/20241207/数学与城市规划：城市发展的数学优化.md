#### 线性规划

线性规划是一种用于解决线性约束条件下优化问题的方法。它的核心思想是通过线性目标函数和线性约束条件，寻找最优解。以下是一个线性规划问题的示例：

**目标**：最大化利润，目标函数为 \( P = x_1 + x_2 \)
**约束条件**：
- \( x_1 + x_2 \leq 10 \)
- \( x_1 \geq 0 \)
- \( x_2 \geq 0 \)

我们可以使用Python的`scipy.optimize`库来求解这个线性规划问题。

```python
from scipy.optimize import linprog

# 目标函数系数
c = [-1, -1]

# 约束条件系数
A = [[1, 1]]
b = [10]

# 求解线性规划问题
result = linprog(c, A_ub=A, b_ub=b, bounds=(0, None))

# 输出结果
print(result)
```

运行上述代码，我们得到最优解为 \( x_1 = 0 \)，\( x_2 = 10 \)，最大利润为10。

#### 动态规划

动态规划是一种解决具有递推关系问题的优化算法。它的核心思想是将复杂问题分解为子问题，并利用子问题的最优解来构建整体问题的最优解。以下是一个典型的动态规划问题——斐波那契数列的求解：

**目标**：计算第\( n \)个斐波那契数
**状态转移方程**：
\[ f(n) = \begin{cases}
1, & \text{if } n = 1 \text{ or } n = 2 \\
f(n-1) + f(n-2), & \text{otherwise}
\end{cases} \]

我们可以使用Python代码实现动态规划算法：

```python
def fibonacci(n):
    if n <= 0:
        return 0
    elif n == 1 or n == 2:
        return 1
    else:
        a, b = 1, 1
        for i in range(2, n):
            a, b = b, a + b
        return b

# 计算第10个斐波那契数
print(fibonacci(10))
```

输出结果为55。
