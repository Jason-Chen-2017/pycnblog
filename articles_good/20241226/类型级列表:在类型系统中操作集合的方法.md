## 算法原理讲解

在集合操作中，交集（Intersection）、并集（Union）和差集（Difference）是三个基本且常见的运算。本节将使用Mermaid流程图和Python代码详细阐述这些集合操作的基本算法原理。

### 交集（Intersection）

交集运算获取两个集合的共有元素。假设有两个集合A和B，它们的交集记为A ∩ B。

#### Mermaid流程图

```mermaid
graph TD
    A1[(A中的第一个元素)] -->|比较| B
    B1[(B中的第一个元素)] -->|比较| A
    A2[A中的下一个元素] -->|比较| B
    B2[B中的下一个元素] -->|比较| A
    A3(A中的所有元素已比较) -->|返回| 共有元素
    B3(B中的所有元素已比较) -->|返回| 共有元素
```

#### Python代码

```python
def intersection(A, B):
    result = []
    i = j = 0
    while i < len(A) and j < len(B):
        if A[i] == B[j]:
            result.append(A[i])
            i += 1
            j += 1
        elif A[i] < B[j]:
            i += 1
        else:
            j += 1
    return result

A = [1, 2, 3, 4]
B = [2, 4, 6]
print(intersection(A, B))  # 输出：[2, 4]
```

#### 数学模型和公式

交集运算可以用集合运算符表示为：\( A \cap B = \{ x \mid x \in A \text{ 且 } x \in B \} \)

### 并集（Union）

并集运算将两个集合的所有元素合并。假设有两个集合A和B，它们的并集记为A ∪ B。

#### Mermaid流程图

```mermaid
graph TD
    A1[(A中的第一个元素)] -->|添加| 并集
    A2[A中的下一个元素] -->|添加| 并集
    B1[(B中的第一个元素)] -->|添加| 并集
    B2[B中的下一个元素] -->|添加| 并集
    A3(A中的所有元素已添加) -->|结束|
    B3(B中的所有元素已添加) -->|结束|
```

#### Python代码

```python
def union(A, B):
    return A + [x for x in B if x not in A]

A = [1, 2, 3, 4]
B = [2, 4, 6]
print(union(A, B))  # 输出：[1, 2, 3, 4, 6]
```

#### 数学模型和公式

并集运算可以用集合运算符表示为：\( A \cup B = \{ x \mid x \in A \text{ 或 } x \in B \} \)

### 差集（Difference）

差集运算获取一个集合中有而另一个集合中没有的元素。假设有两个集合A和B，它们的差集记为A - B。

#### Mermaid流程图

```mermaid
graph TD
    A1[(A中的第一个元素)] -->|判断| B
    A2[A中的下一个元素] -->|判断| B
    确定不存在的元素 -->|添加| 差集
    A3(A中的所有元素已判断) -->|结束|
```

#### Python代码

```python
def difference(A, B):
    result = []
    for x in A:
        if x not in B:
            result.append(x)
    return result

A = [1, 2, 3, 4]
B = [2, 4, 6]
print(difference(A, B))  # 输出：[1, 3]
```

#### 数学模型和公式

差集运算可以用集合运算符表示为：\( A - B = \{ x \mid x \in A \text{ 且 } x \notin B \} \)
