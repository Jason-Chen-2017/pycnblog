#### 2.1.1 柏格森哲学的基本概念

阿尔贝特·柏格森（Henri Bergson）是20世纪初期法国著名的哲学家，他的哲学思想对后世产生了深远的影响。柏格森哲学的核心概念包括直觉主义、创造力、生命力和形而上学等。

**直觉主义**是柏格森哲学的重要组成部分。他认为，直觉是一种超越逻辑思维的能力，是人类理解和感知世界的关键。直觉不同于理性思维，它不是通过推理和归纳得出的结论，而是直接感知和体验到的。柏格森认为，直觉是人类理解生命和宇宙的本质的关键。

**创造力**是柏格森哲学的另一个核心概念。他认为，生命本身就是一种不断创造的过程，人类的心灵和宇宙都是不断变化和发展的。创造力是生命的本质，是人类与宇宙之间联系的桥梁。

**生命力**（élan vital）是柏格森用来描述生命的特殊力量的概念。他认为，生命力是一种内在的、不断推动生命向前发展的力量。生命力不仅仅是生物学意义上的生命，更是一种哲学意义上的生命，是生命的本质和源泉。

**形而上学**是柏格森哲学的另一个重要方面。他认为，形而上学应该关注生命和宇宙的本质，而不是抽象的概念和逻辑结构。柏格森的形而上学强调直觉和创造力的作用，试图揭示生命和宇宙的深层本质。

    return df

    # 统计结果
    stats = df.describe()
    
    # 可视化

    plt.show()

# 主函数
def main():
    # 收集数据
