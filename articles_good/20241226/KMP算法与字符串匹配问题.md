## 1. 背景介绍

### 字符串匹配问题的背景

字符串匹配是计算机科学中的一个基础且重要的问题，广泛应用于文本编辑、文本搜索、数据挖掘、模式识别等领域。随着大数据时代的到来，如何快速、准确地匹配大量字符串成为了一个关键问题。

### KMP算法的发展历程

KMP算法是由Donald Knuth、 Vaughan Pratt 和 James H. Morris于1977年共同提出的，是一种高效的字符串匹配算法。相比于传统的暴力算法，KMP算法显著降低了时间复杂度，大大提高了字符串匹配的效率。

### 问题描述和解决方案

问题描述：给定一个文本字符串`S`和一个模式字符串`P`，要求找出`S`中所有`P`的匹配位置。

解决方案：传统的暴力算法通过逐个比较`S`中的字符与`P`中的字符，直到找到一个匹配或者`P`的末尾。而KMP算法通过预处理模式字符串`P`，构造一个部分匹配表（也称为最长公共前后缀表或失配值表），从而避免不必要的比较，提高匹配效率。

### 边界与外延

边界：字符串匹配问题不仅涉及简单的字符串匹配，还包括子串匹配、滚动哈希、后缀数组等多种解决方法。KMP算法在解决这类问题时具有独特的优势。

外延：KMP算法可以扩展应用于更复杂的场景，如多模式匹配、文本压缩、自动机理论等。

## 2. 核心概念与联系

### 概念定义

- **模式字符串（P）**：待匹配的字符串，通常长度较小。
- **文本字符串（S）**：包含模式字符串的字符串，通常长度较大。
- **部分匹配表（Next）**：用于优化匹配过程的预处理结果。

## 3. 算法原理讲解

### 算法流程图

```mermaid
flowchart TD
    A[初始化] --> B{计算Next数组}
    B --> C{匹配过程}
    C -->|匹配成功| D{记录匹配位置}
    C -->|匹配失败| E{回退文本指针}
    E --> C
```

### Python源代码实现

```python
def kmp_search(s, p):
    # 计算Next数组
    next = [0] * len(p)
    next[0] = -1
    j = -1
    for i in range(1, len(p)):
        while j >= 0 and p[j] != p[i]:
            j = next[j]
        if p[j] == p[i]:
            j += 1
        next[i] = j

    # 匹配过程
    i = j = 0
    while i < len(s):
        if j == -1 or s[i] == p[j]:
            i += 1
            j += 1
        if j == len(p):
            return i - j
        else:
            j = next[j]

    return -1
```

### 数学模型和公式

$$
\text{Next}[i] =
\begin{cases}
-1 & \text{if } i = 0 \\
\max\{j : 1 \le j < i, \text{ s[j] == s[i] } \} & \text{otherwise}
\end{cases}
$$

### 详细讲解和举例说明

#### 详细讲解

- **Next数组的计算**：Next数组记录了模式字符串中各个位置的最长公共前后缀长度。通过递归和模式匹配，可以计算出Next数组。
- **匹配过程**：在匹配过程中，如果当前字符匹配成功，文本指针和模式指针都向前移动；如果匹配失败，文本指针不移动，模式指针回退到Next值所指示的位置。

#### 举例说明

假设模式字符串`P = "ABCDABD"`，文本字符串`S = "ABCDABDABCDABD"`。

- **Next数组**：`Next = [-1, 0, 0, 1, 2, 0, 1]`
- **匹配过程**：
  - 初始状态：`i = j = 0`
  - 第1次匹配：`s[0] == p[0]`，`i = 1, j = 1`
  - 第2次匹配：`s[1] == p[1]`，`i = 2, j = 2`
  - 第3次匹配：`s[2] != p[2]`，回退到`Next[j] = 0`，`j = 0`
  - 第4次匹配：`s[2] == p[2]`，`i = 3, j = 2`
  - 第5次匹配：`s[3] == p[3]`，`i = 4, j = 3`
  - 第6次匹配：`s[4] != p[4]`，回退到`Next[j] = 1`，`j = 1`
  - 第7次匹配：`s[4] == p[1]`，`i = 5, j = 2`
  - 第8次匹配：`s[5] == p[2]`，`i = 6, j = 3`
  - 第9次匹配：`s[6] == p[3]`，`i = 7, j = 4`
  - 第10次匹配：`s[7] == p[4]`，`i = 8, j = 5`
  - 第11次匹配：`s[8] == p[5]`，`i = 9, j = 6`
  - 第12次匹配：`s[9] != p[6]`，回退到`Next[j] = 0`，`j = 0`
  - 第13次匹配：`s[9] == p[1]`，`i = 10, j = 1`
  - 第14次匹配：`s[10] == p[2]`，`i = 11, j = 2`
  - 第15次匹配：`s[11] == p[3]`，`i = 12, j = 3`
  - 第16次匹配：`s[12] != p[4]`，回退到`Next[j] = 1`，`j = 1`

### 代码解读

- `kmp_search`函数接受文本字符串`s`和模式字符串`p`作为输入，返回匹配的位置。
- `next`数组用于记录模式字符串的预处理结果。
- 在匹配过程中，如果`j == -1`或`s[i] == p[j]`，则文本指针和模式指针都向前移动；否则，模式指针回退到`Next[j]`的位置。

def main():
    # 创建KMP对象
    kmp = KMP()

    # 输入文本和模式
    text = "ABCDABDABCDABD"
    pattern = "ABCDABD"

    # 计算Next数组

if __name__ == "__main__":
