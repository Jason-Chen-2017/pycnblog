  - 聚合操作：$h_i^{(l+1)} = f(h_i^{(l)}, h_j^{(l)})$
- 3.4.2 异常检测的损失函数
  - 重构损失：$L = ||x - \hat{x}||^2$
  - 分类损失：$L = -\sum y_i \log p(y_i=1) + (1-y_i)\log p(y_i=0)$

#### 3.5 算法实现的代码示例
```python
import tensorflow as tf
from tensorflow.keras import layers

def build_model(input_dim):
    inputs = layers.Input(shape=(input_dim,))
    encoder = layers.Dense(64, activation='relu')(inputs)
    encoder = layers.Dense(32, activation='relu')(encoder)
    decoder = layers.Dense(64, activation='relu')(encoder)
    outputs = layers.Dense(input_dim, activation='sigmoid')(decoder)
    model = tf.keras.Model(inputs=inputs, outputs=outputs)
    return model

model = build_model(input_dim=128)
model.compile(optimizer='adam', loss='binary_crossentropy')
```
