## 第1章: 巴菲特与芒格的投资理念概述

### 1.1 巴菲特与芒格的投资哲学

#### 1.1.1 巴菲特的价值投资理念
- 巴菲特的价值投资理念强调寻找具有持续竞争优势的公司，关注其内在价值和安全边际。
- 投资不仅仅是买股票，而是买企业的一部分。
- 长期持有，避免频繁交易。

#### 1.1.2 芒格的多元思维模型
- 芒格倡导“多元思维模型”，即通过多个学科的思维方式来理解复杂问题。
- 强调交叉思维，将不同领域的知识结合起来，形成全面的分析框架。
- 通过“反过来想”来避免决策错误。

#### 1.1.3 两人投资理念的异同点
- 巴菲特更注重企业的财务指标和安全边际。
- 芒格更注重多维度的分析和风险控制。
- 两人共同点：长期投资、价值投资、避免情绪化决策。

### 1.2 医疗健康行业的特殊性

#### 1.2.1 医疗健康行业的定义与范围
- 医疗健康行业涵盖医疗服务、药品研发、医疗设备、健康保险等多个领域。
- 全球医疗健康市场规模庞大，且持续增长。

#### 1.2.2 医疗健康行业的特点与发展趋势
- 行业需求刚性强，受经济波动影响较小。
- 技术创新驱动行业增长，如基因编辑、人工智能在医疗中的应用。
- 人口老龄化加剧，医疗需求进一步增加。

#### 1.2.3 医疗健康行业与巴菲特投资理念的契合点
- 医疗健康行业具有稳定的现金流和持续的市场需求。
- 优秀的医疗企业具备强大的护城河，符合巴菲特的价值投资理念。

### 1.3 巴菲特与芒格对医疗健康行业的关注

#### 1.3.3 两人对医疗健康行业的长期看好理由

```python
class InvestmentPortfolio:
    def __init__(self, budget):
        self.budget = budget
        self.portfolio = {}

    def add_investment(self, company, amount):
        if company in self.portfolio:
            self.portfolio[company] += amount
        else:
            self.portfolio[company] = amount
        self.budget -= amount

    def remove_investment(self, company, amount):
        if company in self.portfolio:
            self.portfolio[company] -= amount
            if self.portfolio[company] == 0:
                del self.portfolio[company]
            self.budget += amount

    def get_portfolio_value(self):
        return sum(self.portfolio.values())
```
