## 第1章: 价值投资与循环经济的背景

### 1.1 价值投资的核心概念

#### 1.1.1 价值投资的定义与特点
- **定义**：价值投资是一种长期投资策略，关注企业的内在价值，寻找市场价格低于内在价值的投资机会。
- **特点**：
  - 长期视角
  - 专注于基本面分析
  - 寻找安全边际
- **核心原则**：
  - 买入被低估的资产
  - 长期持有
  - 风险控制

#### 1.1.2 循环经济的基本原理
- **定义**：循环经济是一种以资源高效利用和循环利用为核心，减少废物产生和排放的经济模式。
- **特点**：
  - 资源闭环
  - 减少环境污染
  - 提高资源利用效率
- **核心原则**：
  - 设计产品时考虑全生命周期
  - 优先使用可再生资源
  - 通过共享和再利用延长产品寿命

#### 1.1.3 价值投资与循环经济的结合
- **结合点**：
  - 循环经济中的企业具有长期可持续性
  - 价值投资关注企业内在价值
- **优势**：
  - 循环经济企业具有长期竞争优势
  - 符合可持续发展趋势
  - 投资风险较低

### 2.1 循环经济的商业模式类型

#### 2.1.1 产品即服务
- **定义**：企业通过提供产品服务，而不是出售产品，来实现收入。
- **特点**：
  - 按使用付费
  - 资源高效利用
  - 降低客户拥有成本
- **案例**：
  - 某公司提供共享办公空间服务
  - 某公司提供共享交通工具服务

#### 2.1.2 资源循环利用
- **定义**：企业通过回收和再利用资源，降低生产成本。
- **特点**：
  - 资源闭环
  - 节约资源
  - 降低成本
- **案例**：
  - 某公司回收废弃塑料生产新产品
  - 某公司回收电子废弃物提取稀有金属

#### 2.1.3 共享经济
- **定义**：通过共享资源，提高资源利用率。
- **特点**：
  - 分享经济模式

#### 5.2.2 投资回报预测
- **预测模型代码**：
  ```python
  import pandas as pd
  import numpy as np
  from sklearn.linear_model import LinearRegression
  from sklearn.metrics import mean_squared_error

  # 读取数据
  df = pd.read_csv('data.csv')

  # 数据预处理
  X = df[['收入', '利润', '成本']]
  y = df['回报率']

  # 模型训练
  model = LinearRegression()
  model.fit(X, y)

  # 模型预测
  y_pred = model.predict(X)

  # 模型评估
  mse = mean_squared_error(y, y_pred)
  print(f'均方误差: {mse}')
  print(f'回归系数: {model.coef_}')
  print(f'截距: {model.intercept_}')
  ```

- **代码解读**：
  - 使用线性回归模型预测投资回报率
  - 输入变量包括收入、利润和成本
  - 输出回归系数和截距
  - 计算均方误差评估模型性能
