### 第5章: 金融风险压力测试模型的项目实战

#### 5.2 系统核心实现源代码
- 示例代码：使用Python实现线性回归模型。
```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 输入数据
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 6])

# 线性回归模型
def linear_regression(x, y):
    n = len(x)
    denominator = n * np.sum(x**2) - (np.sum(x))**2
    numerator = n * np.sum(x*y) - np.sum(x) * np.sum(y)
    beta1 = numerator / denominator
    beta0 = (np.sum(y) - beta1 * np.sum(x)) / n
    return beta0, beta1

beta0, beta1 = linear_regression(x, y)
print(f"模型为：y = {beta0} + {beta1}x")

# 可视化
plt.scatter(x, y)
plt.plot(x, beta0 + beta1 * x, color='red')
plt.show()
```

- 代码实现了一个简单的线性回归模型，用于分析资产组合与风险因子的关系。
