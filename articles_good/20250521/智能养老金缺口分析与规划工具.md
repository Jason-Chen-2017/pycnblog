## 第二部分: 算法原理与实现

### 第3章: 算法原理

#### 3.1 线性回归模型
- 数学模型：$$y = a + b x + ε$$
  - $y$：预测的养老金缺口。
  - $a$：截距。
  - $b$：回归系数。
  - $x$：自变量（如收入、通胀率）。
  - $ε$：误差项。
- 算法流程：
  1. 数据清洗与特征工程。
  2. 模型训练。
  3. 模型评估与优化。

#### 3.2 算法流程图

#### 3.3 算法实现代码
```python
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# 数据加载
data = pd.read_csv('pension_gap.csv')

# 特征与目标变量分离
X = data[['income', 'inflation_rate']]
y = data['gap']

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测与评估
y_pred = model.predict(X)
print(f'MSE: {mean_squared_error(y, y_pred)}')
```
