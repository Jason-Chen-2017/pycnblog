### 数据结构与算法基础

在算法面试中，掌握数据结构与算法基础是至关重要的。数据结构是指计算机中的数据存储方式及其操作方法，而算法则是解决问题的步骤和策略。它们是计算机科学的基石，广泛应用于各类软件开发和系统设计中。下面我们将详细介绍基本数据结构、常见的算法设计思想，以及如何在面试中应用这些知识。

#### 基本数据结构

**线性表**：线性表是最基本的数据结构之一，它包含一系列元素，这些元素在内存中连续存储，可以通过索引来访问。常见的线性表有数组、链表等。

**栈与队列**：栈和队列都是操作受限的线性表。栈遵循“后进先出”（LIFO）原则，而队列遵循“先进先出”（FIFO）原则。它们在程序设计中广泛使用，如递归、任务调度等。

**链表**：链表是通过指针链接的一系列节点，每个节点包含数据和指向下一个节点的指针。与数组相比，链表更适合动态分配和插入删除操作。

**树与图**：树是一种层次结构，每个节点有零个或多个子节点，没有父节点的节点称为根节点。图则是由节点和边组成，适用于表示复杂关系，如社交网络、交通网络等。

#### 算法设计思想

**分治算法**：分治算法是将一个复杂问题分解成若干个规模较小的相同问题，递归解决这些子问题，然后将子问题的解合并为原问题的解。经典应用包括快速排序、归并排序等。

**动态规划**：动态规划适用于求解具有重叠子问题的最优化问题。它将问题分解为若干个子问题，并存储子问题的解，避免重复计算。动态规划的核心是状态转移方程和边界条件的设定。

**贪心算法**：贪心算法通过每一步选择局部最优解，期望在整体上得到全局最优解。它适用于具有最优子结构性质的问题，如背包问题、最短路径等。

**回溯算法**：回溯算法通过尝试所有可能的解，并在遇到不可行的解时回溯到上一个状态，重新选择。它适用于组合问题和图论问题，如八皇后问题、旅行商问题等。

**面试题实例**

1. **快速排序（Quick Sort）**：这是一个典型的分治算法问题。要求求职者编写一个函数，对数组进行快速排序。重点在于理解分区过程和递归调用。

   ```python
   def quick_sort(nums):
       if len(nums) <= 1:
           return nums
       pivot = nums[len(nums) // 2]
       left = [x for x in nums if x < pivot]
       middle = [x for x in nums if x == pivot]
       right = [x for x in nums if x > pivot]
       return quick_sort(left) + middle + quick_sort(right)
   ```

2. **最长公共子序列（LCS）**：这是一个动态规划问题。要求求职者编写一个函数，找出两个字符串的最长公共子序列。重点在于理解状态转移方程的设定和边界条件的处理。

   ```python
   def lcs(str1, str2):
       m, n = len(str1), len(str2)
       dp = [[0] * (n + 1) for _ in range(m + 1)]
       for i in range(1, m + 1):
           for j in range(1, n + 1):
               if str1[i - 1] == str2[j - 1]:
                   dp[i][j] = dp[i - 1][j - 1] + 1
               else:
                   dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
       return dp[m][n]
   ```

3. **背包问题**：这是一个贪心算法问题。要求求职者编写一个函数，求解给定物品重量和价值，选择最多价值的物品放入背包。重点在于理解贪心选择策略。

   ```python
   def knapsack(weights, values, capacity):
       n = len(values)
       values_per_weight = [v / w for v, w in zip(values, weights)]
       items = sorted(zip(values_per_weight, weights, values), reverse=True)
       total_value = 0
       for value, weight, _ in items:
           if capacity >= weight:
               capacity -= weight
               total_value += value
           else:
               break
       return total_value
   ```

#### 排序算法与查找算法

##### 快排（Quick Sort）

**问题分析**：快速排序是一种高效的排序算法，采用分治策略将数组分为较小的子数组，再递归排序。其核心在于选择一个基准元素，将数组分为两部分，一部分都比基准元素小，另一部分都比基准元素大。

**实现思路**：选择数组中的一个元素作为基准，将数组分为两部分，分别递归排序。

**代码实现**：

```python
def quick_sort(nums):
    if len(nums) <= 1:
        return nums
    pivot = nums[len(nums) // 2]
    left = [x for x in nums if x < pivot]
    middle = [x for x in nums if x == pivot]
    right = [x for x in nums if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```

##### 插入排序（Insertion Sort）

**问题分析**：插入排序是一种简单直观的排序算法，通过构建有序序列，对于未排序数据，在已排序序列中从后向前扫描，找到相应位置并插入。

**实现思路**：从第二个元素开始，依次插入到已排序的序列中。

**代码实现**：

```python
def insertion_sort(nums):
    for i in range(1, len(nums)):
        key = nums[i]
        j = i - 1
        while j >= 0 and nums[j] > key:
            nums[j + 1] = nums[j]
            j -= 1
        nums[j + 1] = key
    return nums
```

##### 归并排序（Merge Sort）

**问题分析**：归并排序是一种分治算法，将数组分成两半，分别递归排序，最后合并。其核心在于合并两个有序数组。

**实现思路**：将数组分为两个子数组，分别递归排序，最后合并。

**代码实现**：

```python
def merge_sort(nums):
    if len(nums) <= 1:
        return nums
    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

**问题分析**：二分查找是在有序数组中查找某一特定元素的搜索算法。其核心在于通过中间元素将数组分为两部分，递归或循环搜索。

**实现思路**：使用循环或递归，每次将搜索范围缩小一半。

**代码实现**：

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**哈希表（Hash Table）**

**问题分析**：哈希表通过哈希函数将关键字映射到数组位置，实现高效查找和插入。其核心在于选择合适的哈希函数和解决冲突的方法。

**实现思路**：使用哈希函数处理关键字，解决冲突，如链地址法或开放地址法。

**代码实现**（Python）：

```python
class HashTable:
    def __init__(self):
        self.size = 10
        self.table = [None] * self.size

    def hash_function(self, key):
        return key % self.size

    def insert(self, key, value):
        index = self.hash_function(key)
        if self.table[index] is None:
            self.table[index] = [(key, value)]
        else:
            self.table[index].append((key, value))

    def search(self, key):
        index = self.hash_function(key)
        if self.table[index] is None:
            return None
        for k, v in self.table[index]:
            if k == key:
                return v
        return None
```

            new_node.next = new_node

            last = last.next
        last.next = new_node

            return

        while current.next != self.head:
            if current.data == key:
                if current == self.head:
                    last = self.head
                    while last.next != self.head:
                        last = last.next
                    last.next = self.head.next
                    self.head = self.head.next
                else:
                    prev_node = current.prev
                    next_node = current.next
                    prev_node.next = next_node
                    next_node.prev = prev_node
                return
            current = current.next

        fast = self.head

**问题分析**：平衡树是为了保持树的高度平衡，以减少搜索操作的时间复杂度。AVL树和红黑树是两种常见的自平衡二叉搜索树。

        self.left = None
        self.right = None

        else:
            root.right = self.insert(root.right, data)

##### 图算法

**拓扑排序（Topological Sort）**

**问题分析**：拓扑排序用于对有向无环图（DAG）进行排序，使得每个顶点的入度小于等于其前驱的顶点。

**实现思路**：使用深度优先搜索（DFS）遍历图，记录每个顶点的入度，并按照遍历顺序输出。

**代码实现**（Python）：

```python
def topological_sort(graph):
    in_degree = {node: 0 for node in graph}
    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    queue = deque([node for node in in_degree if in_degree[node] == 0])
    sorted_list = []

    while queue:
        node = queue.popleft()
        sorted_list.append(node)
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return sorted_list
```

**最短路径算法**

**Dijkstra算法**

**问题分析**：Dijkstra算法用于计算单源最短路径，找到从源点到其他所有顶点的最短路径。

**实现思路**：使用优先队列（最小堆）保存当前未处理顶点的最小距离，并逐步更新距离。

**代码实现**（Python）：

```python
import heapq

def dijkstra(graph, start):
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        if current_distance > distances[current_node]:
            continue
        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances
```

**Floyd-Warshall算法**

**问题分析**：Floyd-Warshall算法用于计算所有顶点对之间的最短路径。

**实现思路**：使用动态规划思想，逐步计算中间顶点对的最短路径。

**代码实现**（Python）：

```python
def floyd_warshall(graph):
    distances = [[float('infinity') if i != j else 0 for j in range(len(graph))] for i in range(len(graph))]

    for k in range(len(graph)):
        for i in range(len(graph)):
            for j in range(len(graph)):
                distances[i][j] = min(distances[i][j], distances[i][k] + distances[k][j])

    return distances
```

**最小生成树（Minimum Spanning Tree, MST）**

**Prim算法**

**问题分析**：Prim算法用于构建最小生成树，选择最小权重的边逐步扩展树。

**实现思路**：使用贪心策略，从任意一个顶点开始，逐步添加最小权重的边。

**代码实现**（Python）：

```python
import heapq

def prim(graph, start):
    mst = {}
    distances = {node: float('infinity') for node in graph}
    distances[start] = 0
    priority_queue = [(0, start)]

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        if current_distance > distances[current_node]:
            continue
        if current_node not in mst:
            mst[current_node] = []
            for neighbor, weight in graph[current_node].items():
                if neighbor not in mst:
                    distances[neighbor] = weight
                    heapq.heappush(priority_queue, (weight, neighbor))
            mst[current_node].append((neighbor, weight) for neighbor, weight in graph[current_node].items())

    return mst
```

**Kruskal算法**

**问题分析**：Kruskal算法用于构建最小生成树，通过排序边并使用并查集逐步合并。

**实现思路**：使用贪心策略，选择权重最小的边，并使用并查集判断边是否构成环。

**代码实现**（Python）：

```python
def find(parent, i):
    if parent[i] == i:
        return i
    return find(parent, parent[i])

def union(parent, rank, x, y):
    xroot = find(parent, x)
    yroot = find(parent, y)

    if rank[xroot] < rank[yroot]:
        parent[xroot] = yroot
    elif rank[xroot] > rank[yroot]:
        parent[yroot] = xroot
    else:
        parent[yroot] = xroot
        rank[xroot] += 1

def kruskal(edges):
    edges = sorted(edges, key=lambda x: x[2])
    mst = []
    parent = []
    rank = []

    for node in range(len(edges)):
        parent.append(node)
        rank.append(0)

    for edge in edges:
        x, y, weight = edge
        if find(parent, x) != find(parent, y):
            union(parent, rank, x, y)
            mst.append(edge)

    return mst
```

##### 动态规划

**最长公共子序列（LCS）**

**问题分析**：LCS问题用于找出两个序列的最长公共子序列。

**实现思路**：使用二维动态规划数组，计算子问题的最优解。

**代码实现**（Python）：

```python
def lcs(X, Y):
    m, n = len(X), len(Y)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if X[i - 1] == Y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    return dp[m][n]
```

**最小路径和**

**问题分析**：给定一个包含正负整数的网格，找出从左上角到右下角的最小路径和。

**实现思路**：使用动态规划数组，逐步更新网格的最小路径和。

**代码实现**（Python）：

```python
def min_path_sum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]

    dp[0][0] = grid[0][0]

    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]

    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]

    return dp[-1][-1]
```

**整数划分**

**问题分析**：给定一个正整数，将其划分为若干个正整数的和，求划分方式的总数。

**实现思路**：使用动态规划计算子问题的个数。

**代码实现**（Python）：

```python
def num_ways_to划分为和(n):
    dp = [[0] * (n + 1) for _ in range(n + 1)]

    for i in range(n + 1):
        dp[i][0] = 1

    for i in range(1, n + 1):
        for j in range(1, n + 1):
            if i >= j:
                dp[i][j] = dp[i - j][j] + dp[i - 1][j]
            else:
                dp[i][j] = dp[i - 1][j]

    return dp[n][n]
```

def gcd(a, b):

### 真题一：最大子序和

#### 问题分析

给定一个整数数组 `nums`，找出一个连续子数组，使得该子数组的和最大。返回这个最大和。

**示例**：

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6。
```

**解题思路**：

这道题可以采用分治算法的思想，但更常见的是使用贪心算法。贪心算法的核心思想是，在每一步选择时，都选择当前状态下最好的选择，并期望在最终得到全局最优解。在最大子序和问题中，最好的选择是保留当前子数组的最大值。

具体实现步骤如下：

1. 初始化两个变量，`max_ending_here` 和 `max_so_far`，分别表示以当前元素结尾的最大子序和以及全局最大子序和。
2. 遍历数组，对于每个元素 `num`，更新 `max_ending_here` 为 `max(num, max_ending_here + num)`。这里的 `max(num, max_ending_here + num)` 确保了在每次迭代后，`max_ending_here` 总是保持为以当前元素结尾的最大子序和。
3. 更新 `max_so_far` 为 `max(max_so_far, max_ending_here)`，确保 `max_so_far` 总是保持为全局最大子序和。

#### 代码实现（Python伪代码）

```python
def maxSubArray(nums):
    max_so_far = nums[0]
    max_ending_here = nums[0]
    
    for i in range(1, len(nums)):
        max_ending_here = max(nums[i], max_ending_here + nums[i])
        max_so_far = max(max_so_far, max_ending_here)
        
    return max_so_far
```

#### 代码解读

- `max_so_far` 和 `max_ending_here` 分别初始化为 `nums[0]`，即第一个元素的值。
- 在循环中，对于数组中的每个元素 `nums[i]`，更新 `max_ending_here`，使其变为当前元素或当前元素加上前一个最大子序和中的较大值。这确保了 `max_ending_here` 总是最大子序和的可能值。
- 每次更新 `max_ending_here` 后，将其与 `max_so_far` 比较，如果 `max_ending_here` 更大，则更新 `max_so_far`。
- 最后，返回 `max_so_far`，即全局最大子序和。

这个算法的时间复杂度为 O(n)，空间复杂度为 O(1)，因此非常适合面试中的高效解题要求。

### 真题二：两数之和

#### 问题分析

给定一个整数数组 `nums` 和一个目标值 `target`，要求找出数组中两数之和等于 `target` 的那一对元素，并返回它们在数组中的索引。

**示例**：

```
输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]
解释：因为 nums[0] + nums[1] = 2 + 7 = 9，返回 [0, 1]。
```

**解题思路**：

这道题可以通过哈希表实现。哈希表提供 O(1) 的时间复杂度查找操作，非常适合用于这种查找配对元素的问题。

具体实现步骤如下：

1. 初始化一个空哈希表 `hash_map`。
2. 遍历数组 `nums`，对于每个元素 `num`，计算 `target - num` 的值。
3. 在哈希表中查找 `target - num` 的索引，如果找到，则返回当前元素和对应的配对元素索引。
4. 如果未找到，将当前元素的索引和值添加到哈希表中。

#### 代码实现（Python伪代码）

```python
def twoSum(nums, target):
    hash_map = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in hash_map:
            return [hash_map[complement], i]
        hash_map[num] = i
    return []
```

#### 代码解读

- `hash_map` 用于存储数组中元素的值和其索引。
- 在循环中，对于每个元素 `num`，计算 `complement`（目标值减去当前元素值）。
- 如果 `complement` 在哈希表中存在，说明找到了一个配对元素，返回其索引。
- 如果未找到，将当前元素的值和索引添加到哈希表中。

### 真题三：链表相交

#### 问题分析

给定两个单链表 `headA` 和 `headB`，它们可能相交也可能不相交。如果相交，找出相交节点；如果不相交，返回 `None`。

**示例**：

```
输入：headA = [4, 1, 8, 4, 5], headB = [5, 6, 1, 8, 4, 5]
输出：相交节点：Node 8
解释：链表在节点 8 处相交。
```

**解题思路**：

这道题可以通过哈希表或快慢指针法实现。以下是使用哈希表的方法：

1. 遍历第一个链表，将每个节点的地址（或值）存储在哈希表中。
2. 遍历第二个链表，检查每个节点的地址（或值）是否在哈希表中。如果在，说明两个链表相交，返回相交节点。
3. 如果遍历结束仍未找到相交节点，返回 `None`。

#### 代码实现（Python伪代码）

```python
def getIntersectionNode(headA, headB):
    hash_map = set()
    current = headA
    while current:
        hash_map.add(current)
        current = current.next

    current = headB
    while current:
        if current in hash_map:
            return current
        current = current.next
    return None
```

#### 代码解读

- `hash_map` 是一个存储节点地址的集合。
- 遍历第一个链表，将每个节点的地址添加到 `hash_map` 中。
- 遍历第二个链表，检查每个节点的地址是否在 `hash_map` 中。如果找到，说明两个链表相交，返回相交节点。
- 如果遍历结束仍未找到相交节点，返回 `None`。

**2. 实现一个无重复元素的队列**：

```java
import java.util.HashSet;
import java.util.LinkedList;
import java.util.Queue;

class UniqueQueue {
    private Queue<Integer> queue;
    private Set<Integer> set;

    public UniqueQueue() {
        queue = new LinkedList<>();
        set = new HashSet<>();
    }

    public void enqueue(int val) {
        if (!set.contains(val)) {
            queue.offer(val);
            set.add(val);
        }
    }

    public int dequeue() {
        if (queue.isEmpty()) {
            return -1; // 或者抛出异常
        }
        int val = queue.poll();
        set.remove(val);
        return val;
    }

    def __init__(self, val=0, next=None):

        self.next = next

class SortedList:
    def __init__(self):
        self.head = None

    def add(self, val):
        new_node = ListNode(val)
        if not self.head or val < self.head.val:
            new_node.next = self.head
            self.head = new_node
        else:
            current = self.head
            while current.next and current.next.val < val:
                current = current.next
            new_node.next = current.next
            current.next = new_node

    def display(self):
        current = self.head
        while current:
            print(current.val, end=" ")
            current = current.next
        print()

from collections import deque

class UniqueQueue:
    def __init__(self):
        self.queue = deque()
        self.set = set()

    def enqueue(self, val):
        if val not in self.set:
            self.queue.append(val)
            self.set.add(val)

    def dequeue(self):
        if self.queue:
            val = self.queue.popleft()
            self.set.remove(val)
            return val
        return None
```

def matrix_power(matrix, n):
    if n == 0:
        return [[1 if i == j else 0 for j in range(len(matrix))] for i in range(len(matrix))]
    if n == 1:
        return matrix
    
    result = matrix_power(matrix, n // 2)
    result = matrix_multiply(result, result)
    
    if n % 2 == 1:
        result = matrix_multiply(result, matrix)
    
    return result

def matrix_multiply(A, B):
    result = [[0] * len(B[0]) for _ in range(len(A))]
    for i in range(len(A)):
        for j in range(len(B[0])):
            for k in range(len(B)):
                result[i][j] += A[i][k] * B[k][j]
    return result

### 深度学习框架TensorFlow

TensorFlow是Google开发的一款开源深度学习框架，广泛应用于图像识别、自然语言处理、推荐系统等领域。其强大的功能和灵活的架构，使得研究人员和开发者能够轻松构建和训练复杂的神经网络模型。在本章节中，我们将介绍TensorFlow的基本概念、核心API以及如何在算法面试中运用这些知识。

#### TensorFlow基础

**Tensor**：在TensorFlow中，`Tensor` 是数据的基本单位，类似于多维数组。它可以是任意维度，包括标量（一维）、向量（一维）、矩阵（二维）等。

**Graph**：TensorFlow中的`Graph` 是表示计算图的数据结构，用于定义和存储神经网络中的各种计算操作。通过构建计算图，可以定义模型的参数、变量、算子等，并指定它们的依赖关系。

**Session**：`Session` 是执行计算图的环境。在`Session` 中，可以通过运行计算图的节点来计算张量值、更新变量等。通过`Session`，可以控制计算的执行顺序和资源分配。

**OP（Operation）**：OP 是计算图中的一种节点，表示一个具体的计算操作。常见的OP包括加法、减法、乘法、除法等。

#### TensorFlow核心API

**TensorFlow 1.x**：在TensorFlow 1.x版本中，主要使用`tf.Graph` 和`tf.Session` 进行模型构建和训练。

- **构造计算图**：通过创建`tf.Graph` 对象，构建计算图中的OP节点，定义模型结构。
- **定义变量**：使用`tf.Variable` 创建可训练的参数变量。
- **定义损失函数**：使用`tf.reduce_mean`、`tf.reduce_sum` 等函数计算损失值。
- **定义优化器**：使用`tf.train.optimizer` 选择并配置优化器，如SGD、Adam等。
- **训练过程**：在`Session` 中执行计算图，进行模型训练和参数更新。

**TensorFlow 2.x**：在TensorFlow 2.x版本中，引入了Eager Execution机制，使得计算图执行更加灵活和易于理解。

- **构造计算图**：虽然TensorFlow 2.x仍然支持计算图，但更推荐使用`tf.function` 装饰器将Eager Execution代码转换为计算图。
- **定义变量**：使用`tf.Variable` 创建可训练的参数变量。
- **定义损失函数**：使用`tf.keras.metrics` 定义各种损失函数。
- **定义优化器**：使用`tf.keras.optimizers` 选择并配置优化器。
- **训练过程**：使用`model.fit` 方法进行模型训练。
