#### 4.1 排序相关算法

排序算法是算法学习的基础，常见的排序算法包括冒泡排序、快速排序、归并排序等。

#### 4.1.1 冒泡排序

冒泡排序是一种简单的排序算法，通过反复交换相邻的未排序元素，使最大元素逐步“冒泡”到数组的末尾。

#### 4.1.1.1 冒泡排序的算法思路

```pseudo
for i from 0 to n-1
    for j from 0 to n-i-1
        if arr[j] > arr[j+1]
            swap(arr[j], arr[j+1])
```

#### 4.1.1.2 冒泡排序的Python实现

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = bubble_sort(arr)
print(sorted_arr)
```

#### 4.1.2 快速排序

快速排序是一种高效的排序算法，采用分治策略，通过递归将数组划分为较小的子数组，并对子数组进行排序。

#### 4.1.2.1 快速排序的算法思路

```pseudo
def quick_sort(arr, low, high):
    if low < high:
        pi = partition(arr, low, high)
        quick_sort(arr, low, pi - 1)
        quick_sort(arr, pi + 1, high)

def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] < pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i+1], arr[high] = arr[high], arr[i+1]
    return i + 1

# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
quick_sort(arr, 0, len(arr)-1)
print(arr)
```

#### 4.1.3 归并排序

归并排序是一种稳定的排序算法，采用分治策略，将数组划分为较小的子数组，然后对子数组进行排序并合并。

#### 4.1.3.1 归并排序的算法思路

```pseudo
def merge_sort(arr):
    if len(arr) > 1:
        mid = len(arr) // 2
        left = arr[:mid]
        right = arr[mid:]

        merge_sort(left)
        merge_sort(right)

        i = j = k = 0
        while i < len(left) and j < len(right):
            if left[i] < right[j]:
                arr[k] = left[i]
                i += 1
            else:
                arr[k] = right[j]
                j += 1
            k += 1

        while i < len(left):
            arr[k] = left[i]
            i += 1
            k += 1

        while j < len(right):
            arr[k] = right[j]
            j += 1
            k += 1

# 示例
```

#### 4.2.2 二分查找

二分查找是一种高效的查找算法，通过递归将数组划分为较小的子数组，并逐步逼近目标元素。

#### 4.2.2.1 二分查找的算法思路

```pseudo
function binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

#### 4.3 图算法

图算法是算法学习中的重要内容，常见的图算法包括深度优先搜索和广度优先搜索。

#### 4.3.1 深度优先搜索

深度优先搜索是一种用于遍历图或树的算法，通过递归或栈实现，逐步深入到图的每个分支。

#### 4.3.1.1 深度优先搜索的算法思路

```pseudo
function dfs(graph, start):
    visited = set()
    stack = [start]
    while stack:
        vertex = stack.pop()
        if vertex not in visited:
            visited.add(vertex)
            for neighbor in graph[vertex]:
                stack.append(neighbor)
    return visited
```

#### 4.3.3 最短路径算法

最短路径算法是用于求解图中两点之间最短路径的算法，常见的最短路径算法包括Dijkstra算法和Bellman-Ford算法。

##### 4.3.3.1 Dijkstra算法

Dijkstra算法是一种用于求解单源最短路径的算法，通过优先队列实现，逐步找到从源点到其他节点的最短路径。

###### 4.3.3.1.1 Dijkstra算法的算法思路

```pseudo
function dijkstra(graph, source):
    distances = [infinity] * len(graph)
    distances[source] = 0
    priority_queue = [(0, source)]
    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)
        if current_distance > distances[current_vertex]:
            continue
        for neighbor, weight in graph[current_vertex].items():
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    return distances
```

##### 4.3.3.2 Bellman-Ford算法

Bellman-Ford算法是一种用于求解单源最短路径的算法，通过迭代放松边，逐步找到从源点到其他节点的最短路径。

###### 4.3.3.2.1 Bellman-Ford算法的算法思路

```pseudo
function bellman_ford(graph, source):
    distances = [infinity] * len(graph)
    distances[source] = 0
    for _ in range(len(graph) - 1):
        for u in graph:
            for v, weight in graph[u].items():
                if distances[u] + weight < distances[v]:
                    distances[v] = distances[u] + weight
    for u in graph:
        for v, weight in graph[u].items():
            if distances[u] + weight < distances[v]:
                return "Graph contains a negative weight cycle"
    return distances
```

#### 4.4 动态规划算法

动态规划算法是一种用于求解最优子问题的算法，通过将问题分解为更小的子问题，并利用子问题的解来构建原问题的解。

##### 4.4.1 动态规划基本概念

动态规划算法的基本思想是，将问题分解为若干个子问题，并存储子问题的解，以避免重复计算。动态规划通常涉及三个要素：状态、状态转移方程和初始状态。

###### 4.4.2.3 最小路径和

最小路径和是一种常见的动态规划问题，其目标是在一个给定的网格中找到从左上角到右下角的最短路径。

```pseudo
function min_path_sum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = grid[0][0]
    for i in range(1, m):
        dp[i][0] = dp[i-1][0] + grid[i][0]
    for j in range(1, n):
        dp[0][j] = dp[0][j-1] + grid[0][j]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
    return dp[m-1][n-1]
```

#### 4.5 贪心算法

贪心算法是一种用于求解最优化问题的算法，其基本思想是，每一步都选择当前情况下最好的选择，从而得到全局最优解。

##### 4.5.1 贪心算法基本概念

贪心算法的基本概念包括局部最优解、全局最优解和贪心策略。局部最优解是指在当前状态下选择最好的选择，而全局最优解是所有局部最优解的集合中的最优解。

##### 4.5.2 常见贪心算法题型

常见的贪心算法题型包括背包问题和神牛问题。

###### 4.5.2.1 背包问题

背包问题是一种常见的贪心算法问题，其目标是选择一组物品，使得总价值最大且不超过背包的容量。

```pseudo
function knapsack(values, weights, capacity):
    items = [(value/weight, value, weight) for value, weight in zip(values, weights)]
    items.sort(reverse=True)
    total_value = 0
    for value, weight in items:
        if capacity >= weight:
            total_value += value
            capacity -= weight
        else:
            total_value += capacity * value / weight
            break
    return total_value
```

###### 5.2.1.1 面试题：排序与搜索

**题目描述**：给定一个整数数组`nums`和一个目标值`target`，请找出`nums`中目标值的位置。

**解题思路**：

- 首先，可以使用排序算法对数组进行排序，然后使用二分查找算法查找目标值的位置。
- 另一种方法是直接使用哈希表存储数组中的元素，然后通过哈希表查找目标值的位置。

**解题代码**：

```python
def search(nums, target):
    # 方法一：排序 + 二分查找
    nums.sort()
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

    # 方法二：哈希表查找
    nums_dict = {v: i for i, v in enumerate(nums)}
    return nums_dict.get(target, -1)
```

```python
def knapsack(values, weights, capacity):
    items = [(value / weight, value, weight) for value, weight in zip(values, weights)]
    items.sort(reverse=True)
    total_value = 0
    for value, weight in items:
        if capacity >= weight:
            total_value += value
            capacity -= weight
        else:
            total_value += capacity * value / weight
            break
    return total_value
```

###### 5.2.6.1 面试题：欧拉定理

**题目描述**：给定两个正整数`a`和`n`，求`a`的欧拉函数`phi(n)`。

**解题思路**：

- 使用欧拉定理，`phi(n)`等于`n`乘以除以每个素数`p`的积，其中`p`是小于等于`n`的素数。
- 可以使用素数分解的方法计算`phi(n)`。

**解题代码**：

```python
from math import sqrt

def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def prime_factors(n):
    factors = []
    for i in range(2, int(sqrt(n)) + 1):
        while n % i == 0:
            factors.append(i)
            n //= i
    if n > 1:
        factors.append(n)
    return factors

def phi(n):
    if n == 1:
        return 1
    result = n
    for p in prime_factors(n):
        result *= (1 - 1/p)
    return int(result)

# 示例
print(phi(10))  # 输出：4
```

##### 6.2.1 题目：单源最短路径

**问题描述**：给定一个加权无向图和一个源点，找出从源点到其他所有点的最短路径。

**解题思路**：

- 使用Dijkstra算法求解单源最短路径。
- 使用Bellman-Ford算法求解单源最短路径。

**示例解析**：

**Dijkstra算法**：

```python
import heapq

def dijkstra(graph, source):
    distances = [float('inf')] * len(graph)
    distances[source] = 0
    priority_queue = [(0, source)]
    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)
        if current_distance > distances[current_vertex]:
            continue
        for neighbor, weight in graph[current_vertex].items():
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    return distances

# 示例
graph = {
    0: {1: 4, 7: 8},
    1: {0: 4, 2: 8, 7: 11},
    2: {1: 8, 3: 7},
    3: {2: 7, 4: 9, 6: 14},
    4: {3: 9, 5: 10},
    5: {4: 10, 6: 2},
    6: {3: 14, 5: 2, 7: 1},
    7: {0: 8, 1: 11, 6: 1}
}
print(dijkstra(graph, 0))  # 输出：[0, 4, 8, 7, 9, 10, 6]
```

**Bellman-Ford算法**：

```python
def bellman_ford(graph, source):
    distances = [float('inf')] * len(graph)
    distances[source] = 0
    for _ in range(len(graph) - 1):
        for u in graph:
            for v, weight in graph[u].items():
                if distances[u] + weight < distances[v]:
                    distances[v] = distances[u] + weight
    for u in graph:
        for v, weight in graph[u].items():
            if distances[u] + weight < distances[v]:
                return "Graph contains a negative weight cycle"
    return distances

# 示例

    0: {1: 4, 7: 8},
    1: {0: 4, 2: 8, 7: 11},
    2: {1: 8, 3: 7},
    3: {2: 7, 4: 9, 6: 14},
    4: {3: 9, 5: 10},
    5: {4: 10, 6: 2},
    6: {3: 14, 5: 2, 7: 1},
    7: {0: 8, 1: 11, 6: 1}
}
```

##### 6.2.2 题目：拓扑排序

**问题描述**：给定一个有向无环图（DAG），对其进行拓扑排序。

**解题思路**：

- 使用深度优先搜索（DFS）或广度优先搜索（BFS）进行拓扑排序。

**示例解析**：

**深度优先搜索**：

```python
from collections import defaultdict

def dfs_topological_sort(graph):
    visited = set()
    topological_order = []

    def dfs(node):
        visited.add(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                dfs(neighbor)
        topological_order.append(node)

    for node in graph:
        if node not in visited:
            dfs(node)
    return topological_order[::-1]

# 示例
graph = {
    1: [2],
    2: [3],
    3: [4, 5],
    4: [],
    5: [6],
    6: []
}
print(dfs_topological_sort(graph))  # 输出：[1, 2, 3, 4, 5, 6]
```

**广度优先搜索**：

```python
from collections import defaultdict, deque

def bfs_topological_sort(graph):
    in_degree = {node: 0 for node in graph}
    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    queue = deque([node for node in in_degree if in_degree[node] == 0])
    topological_order = []

    while queue:
        node = queue.popleft()
        topological_order.append(node)
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return topological_order

# 示例

    1: [2],
    2: [3],
    3: [4, 5],
    4: [],
    5: [6],
    6: []
}
print(bfs_topological_sort(graph))  # 输出：[1, 2, 3, 4, 5, 6]
```

**Dijkstra算法**：

```python
import heapq

def dijkstra(graph, source):
    distances = [float('inf')] * len(graph)
    distances[source] = 0
    priority_queue = [(0, source)]
    while priority_queue:
        current_distance, current_vertex = heapq.heappop(priority_queue)
        if current_distance > distances[current_vertex]:
            continue
        for neighbor, weight in graph[current_vertex].items():
            distance = current_distance + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    return distances
```

##### 6.3.1 题目：背包问题

**问题描述**：给定一组物品的价值和重量，以及一个背包的容量，求最大价值。

**解题思路**：

- 使用动态规划方法求解。
- 使用贪心算法优化。

**示例解析**：

**动态规划**：

```python
def knapsack(values, weights, capacity):
    dp = [[0] * (capacity + 1) for _ in range(len(values) + 1)]
    for i in range(1, len(values) + 1):
        for w in range(1, capacity + 1):
            if weights[i - 1] <= w:
                dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - weights[i - 1]] + values[i - 1])
            else:
                dp[i][w] = dp[i - 1][w]
    return dp[-1][-1]

# 示例

weights = [10, 20, 30]
capacity = 50
print(knapsack(values, weights, capacity))  # 输出：220
```

**贪心算法**：

```python
def knapsack(values, weights, capacity):
    items = [(value / weight, value, weight) for value, weight in zip(values, weights)]
    items.sort(reverse=True)
    total_value = 0
    for value, weight in items:
        if capacity >= weight:
            total_value += value
            capacity -= weight
        else:
            total_value += capacity * value / weight
            break
    return total_value
```

- 使用贪心算法优化。

**示例解析**：

**动态规划**：

```python
def longest_increasing_subsequence(nums):
    dp = [1] * len(nums)
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[i] > nums[j]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

**贪心算法**：

```python
def longest_increasing_subsequence(nums):
    tails = []
    for num in nums:
        left, right = 0, len(tails)
        while left < right:
            mid = (left + right) // 2
            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid
        tails.insert(left, num)
    return len(tails)
```

```python
    lps = [0] * len(pattern)
    compute_lps(pattern)
    i = 0  # index for string
    j = 0  # index for pattern
    while i < len(string):
        if pattern[j] == string[i]:
            i += 1
            j += 1
        if j == len(pattern):
            return i - j
        elif i < len(string) and pattern[j] != string[i]:
            if j != 0:
                j = lps[j - 1]
            else:
                i += 1
    return -1

def compute_lps(pattern):
    length = 0
    lps = [0] * len(pattern)
    i = 1
    while i < len(pattern):
        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
            i += 1
        else:
            if length != 0:
                length = lps[length - 1]
            else:
                lps[i] = 0
                i += 1
```

```python
                primes[i] = False
        p += 1
    return [p for p, is_prime in enumerate(primes) if is_prime]
```
