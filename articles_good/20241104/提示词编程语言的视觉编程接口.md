   255 & \text{if } I(x, y) \ge T \\

**步骤**：

1. **加载图像**：首先，我们需要加载一幅原始图像，如图像中的噪声通常来自环境光照变化或图像压缩。

3. **应用高斯滤波**：然后，我们将高斯滤波器应用于原始图像，通过卷积操作实现滤波效果。

def applyGaussianFilter(image, sigma):

    filteredImage = cv2.filter2D(image, -1, kernel)

3. **计算梯度**：然后，我们计算图像在x方向和y方向的梯度，用于边缘检测。

4. **非极大值抑制**：接下来，我们应用非极大值抑制算法，减少边缘检测中的伪边缘。

5. **阈值处理**：最后，我们使用双阈值算法对检测到的边缘进行阈值处理，得到最终的边缘图像。

**伪代码示例**：

```python

def applyCannyEdgeDetection(image, threshold1, threshold2):
    # 应用高斯滤波
    blurredImage = cv2.GaussianBlur(image, ksize=(5, 5), sigmaX=1.5)

    # 计算梯度
    xGradient = cv2.Sobel(blurredImage, ddepth=cv2.CV_32F, dx=1, dy=0, ksize=3)
    yGradient = cv2.Sobel(blurredImage, ddepth=cv2.CV_32F, dx=0, dy=1, ksize=3)

    # 计算梯度幅值和方向
    magnitude = cv2.magnitude(xGradient, yGradient)
    direction = cv2.phase(xGradient, yGradient)

    # 非极大值抑制
    edgeImage = cv2.Canny(magnitude, threshold1, threshold2)

    return edgeImage

# 加载图像
image = cv2.imread('image.jpg')

# 应用Canny边缘检测

```

   def sobel_edge_detection(image):

4. **object_detection.py**

   ```python
   import cv2
   import numpy as np

   def load_yolo_model(config_file, weights_file):
       net = cv2.dnn.readNetFromDarknet(config_file, weights_file)
       return net

   def preprocess_image(image, size):
       blob = cv2.dnn.blobFromImage(image, 1/255.0, (size, size), (0, 0, 0), True, crop=False)
       return blob

   def yolo_detection(image, net, threshold):
       blob = preprocess_image(image, size=416)
       net.setInput(blob)
       layers_names = net.getLayerNames()
       output_layers = [layers_names[i[0] - 1] for i in net.getUnconnectedOutLayers()]
       outs = net.forward(output_layers)

       # 处理检测结果
       boxes = []
       confidences = []
       class_ids = []

       for out in outs:
           for detection in out:
               scores = detection[5:]
               class_id = np.argmax(scores)
               confidence = scores[class_id]
               if confidence > threshold:
                   center_x = int(detection[0] * image.shape[1])
                   center_y = int(detection[1] * image.shape[0])
                   width = int(detection[2] * image.shape[1])
                   height = int(detection[3] * image.shape[0])
                   x = int(center_x - width / 2)
                   y = int(center_y - height / 2)
                   boxes.append([x, y, x + width, y + height])
                   confidences.append(float(confidence))
                   class_ids.append(class_id)

       indices = cv2.dnn.NMSBoxes(boxes, confidences, threshold, threshold)

       return indices, boxes, confidences, class_ids
   ```

   - `load_yolo_model`函数：加载预训练的YOLO模型。
   - `preprocess_image`函数：预处理图像，使其与模型输入兼容。
   - `yolo_detection`函数：执行YOLO目标检测，并返回检测结果。

**示例三：目标检测**

```python
import cv2
import numpy as np

# 加载YOLO模型
model = cv2.dnn.readNet('yolov3.weights', 'yolov3.cfg')

# 加载图像
image = cv2.imread('image.jpg')

# 预处理图像
blob = cv2.dnn.blobFromImage(image, 1/255.0, (416, 416), (0, 0, 0), True, crop=False)

# 设置输入层
model.setInput(blob)

# 获取输出层
outs = model.forward(['detection_out'])

# 解析检测结果
boxes = []
confidences = []
class_ids = []

for out in outs:
    for detection in out:
        scores = detection[5:]
        class_id = np.argmax(scores)
        confidence = scores[class_id]
        if confidence > 0.5:
            center_x = int(detection[0] * image.shape[1])
            center_y = int(detection[1] * image.shape[0])
            width = int(detection[2] * image.shape[1])
            height = int(detection[3] * image.shape[0])
            x = int(center_x - width / 2)
            y = int(center_y - height / 2)
            boxes.append([x, y, x + width, y + height])
            confidences.append(float(confidence))
            class_ids.append(class_id)

# 非极大值抑制
indices = cv2.dnn.NMSBoxes(boxes, confidences, 0.5, 0.4)

# 绘制检测结果
for i in indices:
    i = i[0]
    box = boxes[i]
    x, y, x1, y1 = box
    cv2.rectangle(image, (x, y), (x1, y1), (0, 255, 0), 2)

# 显示结果
cv2.imshow('Object Detection', image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

以上代码示例展示了如何使用OpenCV和YOLO模型进行图像滤波、边缘检测和目标检测。这些示例代码为开发者提供了一个起点，通过进一步学习和实践，可以扩展和优化这些功能，以适应不同的应用场景。
