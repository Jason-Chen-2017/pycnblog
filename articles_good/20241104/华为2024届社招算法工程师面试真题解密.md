##### 1.1.1.1.2 链表

链表是另一种常见的数据结构，面试题目包括：链表反转、链表合并、链表节点删除等。以下是一个链表反转的示例：

**题目：给定一个单链表，实现链表反转功能。**

**解题思路：** 使用两个指针prev和current，遍历链表，不断将current的next指针指向prev，然后将prev和current向前移动。具体伪代码如下：

```python
def reverse_linked_list(head):
    prev = None
    current = head
    while current:
        next_node = current.next
        current.next = prev
        prev = current
        current = next_node
    return prev
```

**题目：使用栈实现一个队列。**

**解题思路：** 可以使用两个栈stack1和stack2，stack1用于入队操作，stack2用于出队操作。具体伪代码如下：

```python
class MyQueue:
    def __init__(self):
        self.stack1 = []
        self.stack2 = []

    def push(self, x):
        self.stack1.append(x)

    def pop(self):
        if not self.stack2:
            while self.stack1:
                self.stack2.append(self.stack1.pop())
        return self.stack2.pop()

    def peek(self):
        if not self.stack2:
            while self.stack1:
                self.stack2.append(self.stack1.pop())
        return self.stack2[-1]

    def empty(self):
        return not (self.stack1 or self.stack2)
```

##### 1.1.1.1.4 树和图

**题目：给定一个二叉树，实现其先序遍历、中序遍历和后序遍历。**

**解题思路：** 可以使用递归或迭代的方式实现二叉树的遍历。以下是一个递归实现的示例：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def preorderTraversal(self, root: TreeNode) -> List[int]:
        if root is None:
            return []
        stack, output = [root], []
        while stack:
            node = stack.pop()
            output.append(node.val)
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)
        return output

    def inorderTraversal(self, root: TreeNode) -> List[int]:
        if root is None:
            return []
        stack, output = [], []
        node = root
        while node or stack:
            while node:
                stack.append(node)
                node = node.left
            node = stack.pop()
            output.append(node.val)
            node = node.right
        return output

    def postorderTraversal(self, root: TreeNode) -> List[int]:
        if root is None:
            return []
        stack, output = [root], []
        while stack:
            node = stack.pop()
            output.append(node.val)
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)
        return output[::-1]
```

#### 1.1.1.2 常见算法

##### 1.1.1.2.1 排序算法

排序算法是算法工程师必备的基本技能。常见的排序算法包括冒泡排序、选择排序、插入排序、快速排序、归并排序、堆排序等。以下是一个冒泡排序的示例：

**题目：给定一个无序数组，使用冒泡排序算法进行排序。**

**解题思路：** 从第一个元素开始，比较相邻的两个元素，如果它们的顺序错误就把它们交换过来。遍历整个数组，重复这个过程直到排序完成。具体伪代码如下：

```python
def bubble_sort(array):
    n = len(array)
    for i in range(n):
        for j in range(0, n-i-1):
            if array[j] > array[j+1]:
                array[j], array[j+1] = array[j+1], array[j]
    return array
```

##### 1.1.1.2.2 搜索算法

搜索算法是寻找数据的过程，常见的搜索算法包括线性搜索、二分搜索、深度优先搜索、广度优先搜索等。以下是一个二分搜索的示例：

**题目：给定一个有序数组，使用二分搜索算法找出目标元素的位置。**

**解题思路：** 首先确定搜索的区间，然后不断缩小区间，直到找到目标元素或确定元素不存在。具体伪代码如下：

```python
def binary_search(array, target):
    left, right = 0, len(array) - 1
    while left <= right:
        mid = (left + right) // 2
        if array[mid] == target:
            return mid
        elif array[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

##### 1.1.1.2.3 动态规划

动态规划是一种解决优化问题的算法思想。常见的动态规划问题包括背包问题、最长公共子序列、最长上升子序列等。以下是一个最长公共子序列的示例：

**题目：给定两个字符串，求它们的最长公共子序列。**

**解题思路：** 使用动态规划表dp，其中dp[i][j]表示字符串s1的前i个字符和字符串s2的前j个字符的最长公共子序列的长度。具体伪代码如下：

```python
def longest_common_subsequence(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

##### 1.1.1.2.4 贪心算法

贪心算法是一种简化的动态规划算法，通过每一步选择局部最优解，从而得到全局最优解。常见的贪心算法包括最小生成树、最短路径问题等。以下是一个最短路径问题的示例：

**题目：给定一个带权无向图，求单源最短路径。**

**解题思路：** 使用Dijkstra算法，初始化源点到所有点的距离，然后不断更新距离，直到所有点的距离都已知。具体伪代码如下：

```python
import heapq

def dijkstra(graph, start):
    n = len(graph)
    dist = [float('inf')] * n
    dist[start] = 0
    priority_queue = [(0, start)]
    while priority_queue:
        current_dist, current_vertex = heapq.heappop(priority_queue)
        if current_dist > dist[current_vertex]:
            continue
        for neighbor, weight in graph[current_vertex].items():
            distance = current_dist + weight
            if distance < dist[neighbor]:
                dist[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    return dist
```

##### 1.1.2.2.2 推断性统计

推断性统计包括假设检验、置信区间等。以下是一个假设检验的示例：

**题目：给定一个正态分布的数据集，检验其均值是否等于某个特定值。**

**解题思路：** 使用t检验，计算t值，与临界值比较，判断是否拒绝原假设。具体伪代码如下：

```python
import numpy as np

def t_test(data, mu):
    n = len(data)
    mean = np.mean(data)
    std = np.std(data)
    t = (mean - mu) / (std / np.sqrt(n))
    critical_value = 1.96  # 95%置信水平下的临界值
    if abs(t) > critical_value:
        return "拒绝原假设"
    else:
        return "无法拒绝原假设"
```

##### 1.1.2.2.3 概率分布

概率分布包括二项分布、泊松分布、正态分布等。以下是一个二项分布的示例：

**题目：给定一个二项分布，求它的概率质量函数。**

**解题思路：** 使用概率质量函数P(X=k) = C(n, k) * p^k * (1-p)^(n-k)，其中n是试验次数，k是成功的次数，p是成功的概率。具体伪代码如下：

```python
from math import factorial

def binomial_pdf(n, k, p):
    return factorial(n) / (factorial(k) * factorial(n-k)) * p**k * (1-p)**(n-k)
```

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```

**解题步骤：**
1. 初始化左右边界。
2. 当左边界小于右边界时，计算中间元素。
3. 比较中间元素与目标元素，如果相等则返回，如果目标元素比中间元素大则搜索右半部分，如果目标元素比中间元素小则搜索左半部分。
4. 如果未找到目标元素，返回-1。

**伪代码：**

```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**解题思路：** 使用三个指针pre、cur和next，遍历链表，每次将当前节点的next指针指向pre，然后pre和cur向前移动。

```python
def reverse_linked_list(head):

    while cur:
        next_node = cur.next
        cur.next = pre
        pre = cur
        cur = next_node
    return pre
```

##### 2.1.3.1.1 用栈实现队列

**题目：使用两个栈实现一个队列。**

**解题思路：** 使用一个栈用于入队操作，一个栈用于出队操作。

**解题步骤：**

2. 出队时，如果出队栈为空，将入队栈中的所有元素依次压入出队栈。
3. 将出队栈顶元素弹出，即为队列的出队操作。

**伪代码：**

```python
class MyQueue:
    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def pop(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
        return self.out_stack.pop()

    def peek(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
        return self.out_stack[-1]

    def empty(self):
        return not (self.in_stack or self.out_stack)
```

```python
        else:

            a = stack.pop()
```

```python
        output.append(node.val)
```

```python
def is_balanced_tree(root):
    if root is None:
        return 0
    left_height = is_balanced_tree(root.left)
    if left_height == -1:
        return -1
    right_height = is_balanced_tree(root.right)
    if right_height == -1:
        return -1
    if abs(left_height - right_height) > 1:
        return -1
    return max(left_height, right_height) + 1
```

##### 2.1.4.2.2 最短路径问题

**题目：给定一个带权无向图，使用Dijkstra算法求单源最短路径。**

**解题思路：** 使用Dijkstra算法，初始化源点到所有点的距离，然后不断更新距离，直到所有点的距离都已知。

```python
import heapq

def dijkstra(graph, start):
    n = len(graph)
    dist = [float('inf')] * n
    dist[start] = 0
    priority_queue = [(0, start)]
    while priority_queue:
        current_dist, current_vertex = heapq.heappop(priority_queue)
        if current_dist > dist[current_vertex]:
            continue
        for neighbor, weight in graph[current_vertex].items():
            distance = current_dist + weight
            if distance < dist[neighbor]:
                dist[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
    return dist
```

##### 2.2.1.3.1 概率的基本性质

**题目：给定两个事件A和B，求它们同时发生的概率。**

**解题思路：** 根据概率的加法定理，P(A or B) = P(A) + P(B) - P(A and B)。

**伪代码：**

```python
def conditional_probability(A, B):
```

**题目：判断两个事件A和B是否独立。**

**伪代码：**

```python
def are_independent(A, B):
```

**题目：使用贝叶斯定理计算后验概率。**

**伪代码：**


### 2.2.2 概率分布

概率分布包括二项分布、泊松分布、正态分布等。以下是一些常见的面试题目。

#### 2.2.2.1 二项分布

**题目：给定一个二项分布，求它的概率质量函数。**

**解题思路：** 二项分布的概率质量函数为P(X=k) = C(n, k) * p^k * (1-p)^(n-k)，其中n是试验次数，k是成功的次数，p是成功的概率。

**伪代码：**

```python
from math import factorial

def binomial_pdf(n, k, p):
    return factorial(n) / (factorial(k) * factorial(n-k)) * p**k * (1-p)**(n-k)
```

#### 2.2.2.2 泊松分布

**题目：给定一个泊松分布，求它的概率质量函数。**

**解题思路：** 泊松分布的概率质量函数为P(X=k) = λ^k * e^(-λ) / k!，其中λ是泊松率，k是事件发生的次数。

**伪代码：**

```python
import math

def poisson_pdf(k, lambda_):
    return (lambda_ ** k) * math.exp(-lambda_) / math.factorial(k)
```

#### 2.2.2.3 正态分布

**题目：给定一个正态分布，求它的概率质量函数。**

**解题思路：** 正态分布的概率质量函数为P(X=x) = (1/σ√(2π)) * e^(-(x-μ)^2 / (2σ^2))，其中μ是均值，σ是标准差。

**伪代码：**

```python
import math

def normal_pdf(x, mu, sigma):
    return (1 / (sigma * math.sqrt(2 * math.pi))) * math.exp(-((x - mu) ** 2) / (2 * sigma ** 2))
```

```cpp
        maxHeap.push(num);
    }

        arr.push_back(maxHeap.top());
        maxHeap.pop();
    }
}
```
