   **伪代码**：
   ```
   function calculate_gcd(a, b):
       while b != 0:
           temp = b
           b = a % b
           a = temp
       return a
   ```

2. 使用递归：
   - 递归调用函数，每次传入较小数和较大数的余数。

   **伪代码**：
   ```
   function calculate_gcd_recursive(a, b):
       if b == 0:
           return a
       return calculate_gcd_recursive(b, a % b)
   ```

   **伪代码**：
   ```
   function find_min(data):
       min = data[0]
       for num in data:
           if num < min:
               min = num
       return min
   ```
