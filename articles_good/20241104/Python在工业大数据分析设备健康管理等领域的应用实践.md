**数据清洗：**

```python
def clean_data(data):
    # 去除重复值
    unique_data = list(set(data))
    
    # 去除无效值
    valid_data = [x for x in unique_data if x != '']
    
    return valid_data
```

**数据转换：**

```python
def convert_units(data, from_unit, to_unit):
    conversion_factor = {'seconds': 'hours', 'hours': 'days'}
    return [x * conversion_factor[from_unit][to_unit] for x in data]
```
