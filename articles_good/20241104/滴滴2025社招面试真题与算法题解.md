### 1.1 数据结构概述

数据结构是指计算机中存储、组织数据的方式。数据结构不仅要考虑数据的存储形式，还要考虑数据之间的关系以及数据的操作方法。常见的几种数据结构包括数组、链表、栈、队列等。

#### 1.1.1 数组

数组是一种线性数据结构，它由一组元素组成，每个元素都有一个索引，用于唯一标识。数组在计算机科学中应用广泛，如用于存储数据集、实现队列和栈等。

**数组的特点：**
- **元素位置固定**：每个元素的位置由索引确定，索引从0开始。
- **元素类型相同**：数组中的所有元素具有相同的类型。
- **访问元素速度快**：可以通过索引直接访问数组中的任意元素。

**数组的应用场景：**
- **存储数据集**：用于存储大量数据，如数组中的每个元素代表一个学生的成绩。
- **实现队列和栈**：通过数组的动态扩展和收缩，可以模拟队列和栈的数据结构。

#### 1.1.2 链表

链表是一种非线性数据结构，它由一系列节点组成，每个节点包含数据和指向下一个节点的指针。链表具有灵活的内存分配方式，可以根据需要进行动态扩展。

**链表的特点：**
- **元素位置不固定**：链表中的元素通过指针连接，元素的位置不固定。
- **内存分配灵活**：链表可以根据需要动态分配内存，不像数组需要预分配。
- **插入和删除操作高效**：在链表中插入和删除元素时，只需要改变相应节点的指针，操作时间复杂度为O(1)。

**链表的应用场景：**
- **实现栈和队列**：通过链表可以实现栈和队列的数据结构。
- **动态数据结构**：用于实现动态数据结构，如双向链表、循环链表等。

#### 1.1.3 栈

栈是一种后进先出（LIFO）的数据结构，它只允许在一端进行插入和删除操作。栈在程序设计中常用于处理递归、表达式的求值等。

**栈的特点：**
- **后进先出**：最后进入栈的元素最先出栈。
- **单一入口和出口**：栈只有一个顶部，所有的插入和删除操作都在顶部进行。

**栈的应用场景：**
- **递归函数调用**：用于存储函数调用的中间结果，如递归调用的返回值。
- **表达式的求值**：用于求解逆波兰表达式（Postfix）和前缀表达式（Prefix）。

#### 1.1.4 队列

队列是一种先进先出（FIFO）的数据结构，它只允许在一端进行插入操作，在另一端进行删除操作。队列常用于实现同步队列、缓存队列等。

**队列的特点：**
- **先进先出**：最早进入队列的元素最先出队列。
- **双端操作**：队列有两端，分别用于插入和删除操作。

**队列的应用场景：**
- **任务调度**：用于实现任务队列，管理任务的执行顺序。

### 1.3 排序算法

排序算法是计算机科学中的一种重要算法，用于对一组数据进行重新排列，使其按照某种规则有序。常见的排序算法包括冒泡排序、选择排序、插入排序、快速排序等。本节将介绍这些排序算法的基本原理、实现方式以及时间复杂度和空间复杂度。

#### 1.3.1 冒泡排序

冒泡排序（Bubble Sort）是一种简单的排序算法，它重复遍历要排序的数列，每次比较两个相邻的元素，如果它们的顺序错误就把它们交换过来。遍历数列的工作是重复进行直到没有再需要交换，也就是说该数列已经排序完成。

**冒泡排序的原理：**

- 首先从数组的第一个元素开始，比较相邻的元素，如果第一个比第二个大（假设升序排序），就交换它们，对每一对相邻元素做同样的工作，从开始第一对到结尾的最后一对。
- 再重复以上的步骤，除了最后一个元素。
- 重复步骤，直到排序完成。

**冒泡排序的实现：**

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

arr = [64, 25, 12, 22, 11]
sorted_arr = bubble_sort(arr)
print("排序后的数组：", sorted_arr)
```

**时间复杂度：**

- 最差情况（数组逆序）：O(n^2)
- 平均情况：O(n^2)
- 最佳情况（数组已排序）：O(n)

**空间复杂度：**

- O(1)（原地排序）

#### 1.3.2 选择排序

选择排序（Selection Sort）是一种简单的选择排序算法，它的工作原理是每次从未排序的剩余元素中找到最小（或最大）的元素，将其放到已排序序列的末尾。也就是说，每次遍历都从未排序的元素中找到最小值，然后将其交换到已排序序列的末尾。

**选择排序的原理：**

- 第一次遍历从数组的第一个元素开始，在未排序的元素中找到最小元素，将其交换到已排序序列的末尾。
- 第二次遍历从数组的第二个元素开始，在未排序的元素中找到最小元素，将其交换到已排序序列的末尾。
- 以此类推，直到所有元素都排好序。

**选择排序的实现：**

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

arr = [64, 25, 12, 22, 11]
sorted_arr = selection_sort(arr)
print("排序后的数组：", sorted_arr)
```

**时间复杂度：**

- 最差情况（数组逆序）：O(n^2)
- 平均情况：O(n^2)
- 最佳情况（数组已排序）：O(n^2)

**空间复杂度：**

- O(1)（原地排序）

#### 1.3.3 插入排序

插入排序（Insertion Sort）是一种简单直观的排序算法，它的工作原理是通过构建有序序列，对于未排序数据，在已排序序列中从后向前扫描，找到相应位置并插入。插入排序在实现上，通常采用in-place排序（即只需用到O(1)的额外空间的排序）。

**插入排序的原理：**

- 从第一个元素开始，该元素可以认为已经排序。
- 取出下一个元素，在已经排序的元素序列中从后向前扫描。
- 如果该元素（已排序）大于新元素，将该元素移到下一位置。
- 重复步骤3，直到找到已排序的元素小于或者等于新元素的位置。
- 将新元素插入到该位置后。
- 重复步骤2~5。

**插入排序的实现：**

```python
def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]
        j = i-1
        while j >= 0 and arr[j] > key:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key
    return arr

arr = [64, 25, 12, 22, 11]
sorted_arr = insertion_sort(arr)
print("排序后的数组：", sorted_arr)
```

**时间复杂度：**

- 最差情况（数组逆序）：O(n^2)
- 平均情况：O(n^2)
- 最佳情况（数组已排序）：O(n)

**空间复杂度：**

- O(1)（原地排序）

#### 1.3.4 快速排序

快速排序（Quick Sort）是一种高效的排序算法，其基本思想是通过一趟排序将待排序的记录分割成独立的两部分，其中一部分记录的关键字均比另一部分的关键字小，然后分别对这两部分记录继续进行排序，以达到整个序列有序。

**快速排序的原理：**

- 选择一个基准元素，通常选择第一个或最后一个元素作为基准。
- 将数组分为两部分，一部分记录的值小于基准，另一部分记录的值大于基准。
- 递归地对这两部分记录进行快速排序。

**快速排序的实现：**

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

arr = [64, 25, 12, 22, 11]
sorted_arr = quick_sort(arr)
print("排序后的数组：", sorted_arr)
```

**时间复杂度：**

- 最差情况（数组已逆序）：O(n^2)
- 平均情况：O(nlogn)
- 最佳情况：O(nlogn)

**空间复杂度：**

- O(logn)（递归调用栈）

通过以上内容，我们详细介绍了冒泡排序、选择排序、插入排序和快速排序这四种常见的排序算法。每种排序算法都有其特定的应用场景和优缺点。在实际开发过程中，根据具体需求选择合适的排序算法，可以有效地提高程序的性能。

### 1.4 查找算法

查找算法是计算机科学中用于在数据集合中查找特定元素的一类算法。常见的查找算法包括顺序查找和二分查找。本节将介绍这些查找算法的基本原理、实现方式以及时间复杂度和空间复杂度。

#### 1.4.1 顺序查找

顺序查找（Sequential Search）是一种最简单的查找算法，它从数据集合的第一个元素开始，依次向后查找，直到找到目标元素或查找到集合的末尾。

**顺序查找的原理：**

- 从数据集合的第一个元素开始，依次向后查找，每个元素都与目标元素进行比较。
- 如果找到目标元素，则返回其索引；如果查找到集合的末尾仍未找到目标元素，则返回-1。

**顺序查找的实现：**

```python
def sequential_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1

arr = [64, 25, 12, 22, 11]
target = 22
index = sequential_search(arr, target)
print("目标元素的索引：", index)
```

**时间复杂度：**

- 最差情况（目标元素在数组末尾或不存在）：O(n)
- 平均情况：O(n)
- 最佳情况（目标元素在数组第一个位置）：O(1)

**空间复杂度：**

- O(1)（原地查找）

#### 1.4.2 二分查找

二分查找（Binary Search）是一种高效的查找算法，它只适用于有序数据集合。二分查找的基本思想是将数据集合分为两部分，取中间元素与目标元素进行比较，根据比较结果，决定下一步在哪个部分进行查找。

**二分查找的原理：**

- 将数据集合分为两部分，取中间元素与目标元素进行比较。
- 如果中间元素等于目标元素，则查找成功。
- 如果中间元素大于目标元素，则在左侧子集合中继续查找。
- 如果中间元素小于目标元素，则在右侧子集合中继续查找。
- 重复上述步骤，直到找到目标元素或确定目标元素不存在。

**二分查找的实现：**

```python
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

arr = [11, 12, 22, 25, 64]
target = 22
index = binary_search(arr, target)
print("目标元素的索引：", index)
```

**时间复杂度：**

- 最差情况（目标元素不存在）：O(logn)
- 平均情况：O(logn)
- 最佳情况（目标元素在数组中间位置）：O(1)

**空间复杂度：**

- O(1)（原地查找）

通过以上内容，我们详细介绍了顺序查找和二分查找这两种常见的查找算法。顺序查找简单易实现，但时间复杂度较高，适用于数据量较小的情况。二分查找则适用于数据量较大的有序数据集合，具有更高的查找效率。

        i, j = 0, 0
        merged = []
        while i < len(arr1) and j < len(arr2):
            if arr1[i] < arr2[j]:
                merged.append(arr1[i])
                i += 1
            else:
                merged.append(arr2[j])
                j += 1
        while i < len(arr1):
            merged.append(arr1[i])
            i += 1
        while j < len(arr2):
            merged.append(arr2[j])
            j += 1
        return merged
    
    arr1 = [1, 3, 5]
    arr2 = [2, 4, 6]
    print(merge_sorted_arrays(arr1, arr2))  # 输出：[1, 2, 3, 4, 5, 6]

2. **系统设计题：设计一个缓存系统**
    - **题目描述**：设计一个缓存系统，支持以下操作：`set(key, value)`、`get(key)`。
    - **解答**：

    ```python
    class LRUCache:
        def __init__(self, capacity):
            self.capacity = capacity
            self.cache = OrderedDict()
        
        def get(self, key):
            if key not in self.cache:
                return -1
            self.cache.move_to_end(key)
            return self.cache[key]
        
        def set(self, key, value):
            if key in self.cache:
                self.cache.pop(key)
            elif len(self.cache) >= self.capacity:
                self.cache.popitem(last=False)
            self.cache[key] = value
    
    cache = LRUCache(2)
    cache.set(1, 1)
    cache.set(2, 2)
    print(cache.get(1))  # 输出：1
    cache.set(3, 3)
    print(cache.get(2))  # 输出：-1
    cache.set(4, 4)
    print(cache.get(1))  # 输出：-1
    print(cache.get(3))  # 输出：3
    print(cache.get(4))  # 输出：4
    ```

3. **算法题：最长公共子序列**
    - **题目描述**：给定两个字符串 `str1` 和 `str2`，找出它们的最长公共子序列。
    - **解答**：

    ```python
    def longest_common_subsequence(str1, str2):
        m, n = len(str1), len(str2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if str1[i - 1] == str2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]
    
    str1 = "ABCD"
    str2 = "ACDF"
    print(longest_common_subsequence(str1, str2))  # 输出：2
    ```

    # 冒泡排序
    def bubble_sort(arr):
        n = len(arr)
        for i in range(n):
            for j in range(0, n-i-1):
                if arr[j] > arr[j+1]:
                    arr[j], arr[j+1] = arr[j+1], arr[j]
    
    arr = [64, 34, 25, 12, 22, 11]
    bubble_sort(arr)
    print(arr)  # 输出：[11, 12, 22, 25, 34, 64]

    # 快速排序
    def quick_sort(arr):
        if len(arr) <= 1:
            return arr
        pivot = arr[len(arr) // 2]
        left = [x for x in arr if x < pivot]
        middle = [x for x in arr if x == pivot]
        right = [x for x in arr if x > pivot]
        return quick_sort(left) + middle + quick_sort(right)
    
    arr = [64, 34, 25, 12, 22, 11]
    print(quick_sort(arr))  # 输出：[11, 12, 22, 25, 34, 64]
    ```

    # 顺序查找
    def sequential_search(arr, target):
        for i in range(len(arr)):
            if arr[i] == target:
                return i
        return -1

    arr = [64, 34, 25, 12, 22, 11]
    print(sequential_search(arr, 25))  # 输出：2

    # 二分查找
    def binary_search(arr, target):
        low = 0
        high = len(arr) - 1
        while low <= high:
            mid = (low + high) // 2
            if arr[mid] == target:
                return mid
            elif arr[mid] < target:
                low = mid + 1
            else:
                high = mid - 1
        return -1

    arr = [11, 12, 22, 25, 64]
    print(binary_search(arr, 22))  # 输出：2
    ```
