Prompts can be in various forms, including natural language text, structured data, or a combination of both.

There are several types of prompts commonly used in Prompt Engineering:

1. **Direct Prompts:** These are explicit instructions given to the AI model, specifying the desired output or behavior.
2. **Indirect Prompts:** These are more subtle prompts that guide the model's learning process without explicitly specifying the desired outcome.
3. **Prompt Tuning:** This involves fine-tuning the prompts based on the model's performance to achieve better results.
4. **Data Augmentation Prompts:** These prompts are used to augment the training data, helping the model generalize better to unseen data.

**2.1.3 Attributes of Prompts**

The effectiveness of a prompt depends on several attributes:

1. **Relevance:** The prompt should be highly relevant to the task at hand.
2. **Precision:** The prompt should be precise and unambiguous.

## 3.1 Data Preprocessing Algorithms

**3.1.1 Data Cleaning**

Data cleaning is the process of identifying and correcting (or removing) inaccurate records from the dataset. In geological prospecting, this step is critical as it ensures the quality and reliability of the data used for model training and interpretation.

**Algorithm Explanation:**

1. **Identify Missing Values:** Check for missing or incomplete data points and decide on a strategy to handle them, such as deletion or imputation.
2. **Remove Outliers:** Detect and remove data points that deviate significantly from the norm. This can be done using statistical methods like the Z-score or IQR (Interquartile Range).
3. **Correct Data Format:** Ensure that all data points are in the correct format, such as numerical or categorical data.

**Python Code Example:**

```python
import pandas as pd

# Load the geological dataset
data = pd.read_csv('geological_data.csv')

# Identify and handle missing values
data.fillna(method='ffill', inplace=True)

# Remove outliers
z_scores = (data - data.mean()) / data.std()
data = data[(z_scores < 3).all(axis=1)]

# Ensure correct data format
data['category'] = data['category'].astype('category')
```

**3.1.2 Data Normalization**

Data normalization is the process of adjusting the values of attributes in the dataset to a common scale. This step is essential when the features in the dataset have different scales, which can lead to biased model training.

**Algorithm Explanation:**

1. **Min-Max Scaling:** Scale the data to a range between 0 and 1.
2. **Z-Score Standardization:** Scale the data to have a mean of 0 and a standard deviation of 1.

**Python Code Example:**

```python
from sklearn.preprocessing import MinMaxScaler, StandardScaler

# Apply Min-Max Scaling
scaler = MinMaxScaler()
data_normalized_minmax = scaler.fit_transform(data)

# Apply Z-Score Standardization
scaler = StandardScaler()
data_normalized_zscore = scaler.fit_transform(data)
```

Data augmentation involves creating synthetic data samples to increase the size of the training dataset. This helps improve the model's generalization ability and reduce overfitting.

**Algorithm Explanation:**

1. **Noise Injection:** Add random noise to the data points to simulate realistic variations.

## 3.5 Example of Mathematical Models and Formulas

In intelligent geological prospecting, mathematical models and formulas are essential for understanding and interpreting the data. Below are some examples of mathematical models and formulas used in the algorithms discussed in this chapter.

### 3.5.1 Loss Function

The loss function is a critical component of machine learning models, used to measure the discrepancy between the predicted and actual outputs. One commonly used loss function in binary classification is the binary cross-entropy loss:

$$
L = -\frac{1}{n}\sum_{i=1}^{n} (y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i))
$$

Where:
- \( y_i \) is the true label for the \( i \)-th data point.
- \( \hat{y}_i \) is the predicted probability of the \( i \)-th data point belonging to the positive class.
- \( n \) is the total number of data points.

### 3.5.2 Regularization

Regularization is used to prevent overfitting in machine learning models by adding a penalty term to the loss function. One common regularization technique is L2 regularization, which adds the squared magnitude of the weights to the loss function:

$$
L_{\text{reg}} = \frac{\lambda}{2} \sum_{i=1}^{n} w_i^2
$$

Where:
- \( \lambda \) is the regularization parameter.
- \( w_i \) is the weight of the \( i \)-th feature in the model.

### 3.5.3 SVM Decision Function

In Support Vector Machines, the decision function is used to classify new data points. For a linearly separable dataset, the decision function can be written as:

$$
w \cdot x - b = 0
$$

Where:
- \( w \) is the weight vector.
- \( x \) is the feature vector.
- \( b \) is the bias term.

### 3.5.4 Random Forest Classification

In Random Forest, the classification is based on the majority vote of the individual decision trees. The probability of a data point belonging to a particular class \( c \) can be calculated as:

$$
P(c) = \frac{1}{m} \sum_{t=1}^{m} I(y_t = c)
$$

Where:
- \( m \) is the number of decision trees in the Random Forest.
- \( I(y_t = c) \) is the indicator function, which is 1 if \( y_t \) equals \( c \) and 0 otherwise.

### 3.5.5 Neural Network Activation Function

Neural networks often use activation functions to introduce non-linearities into the model. A commonly used activation function is the rectified linear unit (ReLU):

$$
f(x) = \max(0, x)
$$

Where:
- \( x \) is the input to the activation function.
- \( f(x) \) is the output of the activation function.

These mathematical models and formulas are essential for understanding the inner workings of the algorithms used in intelligent geological prospecting. They provide a theoretical foundation for interpreting the data and making predictions.
