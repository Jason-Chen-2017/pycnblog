#### 1.1 暗物质的概念与背景

暗物质是一种看不见摸不着的物质，它不发光也不吸收电磁波，因此无法通过传统的天文观测手段直接探测。然而，暗物质对宇宙的演化起着至关重要的作用。根据宇宙学的观测数据，暗物质占据了宇宙总质量的大约27%，而普通物质（如星体和星际物质）只占约5%，剩余的68%则被认为是暗能量。

暗物质的发现可以追溯到20世纪30年代，由瑞士天文学家弗里茨·茨威基通过分析星系旋转曲线时发现，星系中心的质量远远大于其通过光观测得到的物质质量。这一现象表明星系中存在一种看不见的物质，即暗物质。随后的研究表明，暗物质不仅在星系中存在，而且在宇宙的大尺度结构中也起着关键作用。

#### 1.1.1 暗物质的历史与起源

暗物质的起源尚不完全清楚，但有两个主要的假设：热暗物质和冷暗物质。热暗物质假设认为，暗物质是由高能粒子组成的，这些粒子在宇宙早期的高温高密度环境中产生。而冷暗物质假设则认为，暗物质是由低质量、运动速度较慢的粒子组成，这些粒子在宇宙早期就形成了，并一直保持低温状态。

目前，大多数观测数据支持冷暗物质模型，该模型认为暗物质主要由某种未知粒子组成，这种粒子可能是一种超越标准模型的粒子，如弱相互作用大质量粒子（WIMPs）或其他类型的暗物质粒子。

#### 1.1.2 暗物质的性质与分类

暗物质具有以下几个主要性质：

1. **不可见性**：暗物质不与光相互作用，因此无法通过光学望远镜观测到。
2. **不可及性**：由于暗物质不与电磁波相互作用，因此也无法通过电磁波探测到。
3. **引力作用**：暗物质虽然不可见，但它仍然具有引力，能够影响周围的物质分布。
4. **非热性质**：暗物质在宇宙中的温度非常低，其温度远低于普通物质的温度。

根据暗物质的性质，可以将暗物质分为以下几类：

1. **热暗物质**：由高能粒子组成，如中微子。
2. **冷暗物质**：由低质量、运动速度较慢的粒子组成，如弱相互作用大质量粒子（WIMPs）。
3. **暖暗物质**：介于热暗物质和冷暗物质之间，由质量介于中微子和WIMPs之间的粒子组成。

**冷暗物质**：冷暗物质假设则认为，暗物质是由低质量、运动速度较慢的粒子组成，这些粒子在宇宙早期就形成了，并一直保持低温状态。冷暗物质的主要代表粒子是弱相互作用大质量粒子（WIMPs），它们的质量较大，运动速度较慢，因此不易被探测到。

3. **宇宙微波背景辐射**：宇宙微波背景辐射是宇宙早期留下的遗迹，通过分析宇宙微波背景辐射的波动，可以间接探测到暗物质的存在。

class DataProcessor:
    def __init__(self, data):
        self.data = data
    
    def clean_data(self):
        """
        清洗数据
        :return: 清洗后的数据
        """
        # 填充缺失值、去除异常值等
        cleaned_data = self.data.fillna(method='ffill').dropna()
        return cleaned_data
    
    def normalize_data(self):
        """
        归一化数据
        :return: 归一化后的数据
        """
        normalized_data = (self.data - self.data.mean()) / self.data.std()
        return normalized_data
    
    def extract_features(self):
        """
        提取特征
        :return: 特征数据
        """
        # 根据需求提取特征，如差分特征、时间序列特征等
        features = self.normalize_data()
        return features
