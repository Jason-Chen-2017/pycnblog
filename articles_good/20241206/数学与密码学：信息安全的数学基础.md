### 第1章：密码学基础

密码学是一门研究信息加密与解密技术的科学，其核心目的是保护信息的机密性、完整性和可用性。在信息时代，随着互联网的普及和信息的爆炸性增长，密码学的重要性日益凸显。密码学的基本概念包括加密、解密、密钥和加密算法。

#### 加密与解密

加密是将明文转换为密文的过程，目的是使信息对未授权者不可读。解密则是将密文还原为明文的过程，通常只有持有正确密钥的人才能完成。加密和解密是密码学中最基本的操作。

#### 密钥

密钥是加密和解密过程中使用的参数，用于控制加密算法的执行。密钥分为对称密钥和非对称密钥。对称密钥在加密和解密过程中使用相同的密钥，而非对称密钥则由一对密钥组成，即公钥和私钥。

#### 加密算法

加密算法是用于实现加密和解密过程的数学模型。根据加密方法的不同，加密算法可分为对称加密算法和非对称加密算法。对称加密算法使用相同的密钥进行加密和解密，如AES算法。非对称加密算法使用一对密钥（公钥和私钥）进行加密和解密，如RSA算法。

### 第2章：密码学的历史与发展

密码学有着悠久的历史，从古埃及的凯撒密码到现代的AES加密算法，经历了数千年的发展。早期的密码学主要依靠人类智慧和数学技巧，如凯撒密码、猪圈密码和多字母替换密码等。随着计算机科学和数学的进步，现代密码学应运而生。

#### 古代密码学

古代密码学最早可以追溯到古埃及，公元前1900年左右，古埃及人开始使用凯撒密码。凯撒密码是一种简单的替换密码，将字母表中的每个字母按照固定的位移进行替换。公元1世纪，古罗马的凯撒大帝将这种密码用于军事通信。

#### 中世纪密码学

中世纪时期，密码学得到了进一步的发展。阿拉伯数学家和天文学家阿尔·卡西发明了多字母替换密码，这种密码通过将字母替换为其他字母的组合，使密码更加复杂。中世纪晚期的密码学著作《论密码学》是密码学史上的一部重要文献。

#### 现代密码学

现代密码学起源于20世纪40年代，第二次世界大战期间，密码分析和密码学研究得到了极大的推动。当时，德国的恩尼格玛机是世界上最复杂的加密设备，但盟军的密码学家通过密码分析成功破解了恩尼格玛机。

战后，随着计算机科学的发展，密码学得到了迅速发展。1977年，美国国家标准局（NBS）发布了数据加密标准（DES），这是第一种公开的加密标准。1997年，美国国家标准与技术研究院（NIST）发布了高级加密标准（AES），取代了DES成为新的加密标准。

#### 密码体制分类

根据加密方法的不同，现代密码体制可分为对称加密体制和非对称加密体制。对称加密体制使用相同的密钥进行加密和解密，如AES算法。非对称加密体制使用一对密钥（公钥和私钥）进行加密和解密，如RSA算法。此外，还有基于哈希函数的数字签名技术，用于验证信息的完整性和身份认证。

### 第3章：密码体制分类

密码体制根据加密方法的不同可以分为对称加密、非对称加密和哈希函数。

#### 对称加密

对称加密是指加密和解密过程中使用相同密钥的加密体制。其优点是加密和解密速度快、计算成本低。典型的对称加密算法包括AES、DES和RC5。对称加密的密钥管理是一个重要问题，因为密钥的安全性和保密性直接影响到加密系统的安全性。

#### 非对称加密

非对称加密是指加密和解密过程中使用不同密钥的加密体制。非对称加密算法的主要优点是能够实现密钥的分发和管理，因此更适合网络通信。典型的非对称加密算法包括RSA、ECC和Diffie-Hellman密钥交换。非对称加密的缺点是加密和解密速度相对较慢，计算成本较高。

#### 哈希函数

哈希函数是将任意长度的输入数据映射为固定长度的输出数据的函数。哈希函数在密码学中用于数据完整性验证和数字签名。典型的哈希函数包括MD5、SHA-1和SHA-256。哈希函数的特点是单向性，即无法通过输出数据反推出原始输入数据。

### 第二部分：数学基础

#### 第4章：数论基础

数论是研究整数的性质及其相互关系的数学分支。在密码学中，数论的应用非常广泛，尤其是公钥密码系统的设计。以下将介绍数论中的一些基本概念和定理。

#### 基本概念

1. **素数**：素数是只能被1和自身整除的正整数，如2、3、5、7等。素数在数论中具有基础地位，因为它们是所有整数的基石。
2. **合数**：合数是除了1和自身外还能被其他数整除的正整数，如4、6、8、9等。
3. **模运算**：模运算是一种取余数的运算，通常表示为`a mod n`，其中`a`是被除数，`n`是除数。例如，`10 mod 3`等于1。

#### 定理和性质

1. **欧拉定理**：对于任意正整数`a`和`m`，如果`a`和`m`互质（即它们的最大公约数为1），则`a`的`(m-1)`次方模`m`的结果等于1。公式表示为：`a^(φ(m)) ≡ 1 (mod m)`，其中`φ(m)`是欧拉函数，表示小于或等于`m`且与`m`互质的正整数的个数。
2. **费马小定理**：对于任意素数`p`和任意整数`a`，如果`a`不等于`p`，则`a`的`(p-1)`次方模`p`的结果等于`a`的模`p`的结果。公式表示为：`a^(p-1) ≡ a (mod p)`。

#### 应用

数论在公钥密码系统中的应用非常广泛，以下是两个典型的例子：

1. **RSA算法**：RSA算法是一种基于数论原理的公钥密码系统，其安全性依赖于大素数生成的难度和模运算。RSA算法的安全性主要依赖于以下三个数学难题：
   - 大素数生成：找到两个大素数的乘积是困难的。
   - 模幂运算：对一个数进行大指数模运算也是困难的。
   - 模逆运算：在模数下找到一个数的逆元是困难的。

2. **椭圆曲线密码学**：椭圆曲线密码学是基于椭圆曲线离散对数问题的密码系统。椭圆曲线离散对数问题是在椭圆曲线上找到一个点，使得该点的倍数等于另一个给定的点。椭圆曲线密码学在公钥加密和数字签名中得到了广泛应用，具有高安全性和低计算成本的特点。

### 第5章：代数基础

代数是研究数、函数和方程的数学分支。在密码学中，代数被广泛应用于密码算法的设计和实现。以下将介绍代数中的一些基本概念和定理。

#### 基本概念

1. **群**：群是一种代数结构，由一组元素和一种二元运算组成，满足结合律、单位元和逆元。群在密码学中的应用非常广泛，如对称加密算法中的乘法群和加法群。
2. **环**：环是一种代数结构，由一组元素和两种二元运算组成，满足结合律、分配律和单位元。环在密码学中的应用包括RSA算法中的模运算。
3. **域**：域是一种代数结构，由一组元素和两种二元运算（加法和乘法）组成，满足结合律、分配律、单位元和逆元。域在密码学中的应用包括椭圆曲线密码学中的有理数域和有限域。

#### 定理和性质

1. **拉格朗日定理**：对于任意群`G`和群`G`的子群`H`，群`G`中元素的阶（即元素乘以自身至单位元的次数）等于子群`H`的指数（即子群`H`中元素的个数）。公式表示为：`o(a) | |H|`，其中`o(a)`是元素`a`的阶，`|H|`是子群`H`的指数。
2. **费马小定理**：对于任意素数`p`和任意整数`a`，如果`a`不等于`p`，则`a`的`(p-1)`次方模`p`的结果等于`a`的模`p`的结果。公式表示为：`a^(p-1) ≡ a (mod p)`。
3. **欧拉定理**：对于任意正整数`a`和`m`，如果`a`和`m`互质（即它们的最大公约数为1），则`a`的`(m-1)`次方模`m`的结果等于1。公式表示为：`a^(φ(m)) ≡ 1 (mod m)`，其中`φ(m)`是欧拉函数，表示小于或等于`m`且与`m`互质的正整数的个数。

#### 应用

代数在密码学中的应用主要体现在以下几个方面：

1. **对称加密算法**：对称加密算法中的加密和解密过程通常涉及各种代数运算，如乘法群和加法群。例如，AES算法中使用的S-盒是一个基于有限域的代数结构。
2. **公钥密码系统**：公钥密码系统如RSA算法和椭圆曲线密码学都依赖于复杂的代数运算。RSA算法中的模运算依赖于环和域的概念，而椭圆曲线密码学中的离散对数问题则依赖于椭圆曲线的代数性质。
3. **数字签名**：数字签名算法如RSA签名和椭圆曲线数字签名算法（ECDSA）都使用代数结构来保证签名的安全性和有效性。

**例子：RSA算法**

### 密码算法

#### 第12章：对称加密算法

对称加密算法是一种使用相同密钥进行加密和解密的密码系统。这种算法的优点是加密和解密速度快，计算成本低。常见的对称加密算法包括AES、DES和RC5。

**AES加密算法**

AES（Advanced Encryption Standard，高级加密标准）是美国国家标准与技术研究院（NIST）在2001年发布的一种加密标准。AES算法采用对称加密方式，加密过程包括多个轮次的替换、置换和混淆操作。AES算法支持128、192和256位的密钥长度，具有很高的安全性。

**AES加密过程**

1. **初始化**：输入明文和密钥，初始化初始状态。
2. **初始轮**：对明文块进行混合列操作，包括字节替换和行置换。
3. **加密轮**：进行若干轮加密操作，每轮包括字节替换、行置换和混淆操作。
   - 字节替换：使用S-盒进行字节替换。
   - 行置换：通过固定的行置换矩阵进行行置换。
   - 列混淆：通过固定的列混淆矩阵进行列混淆。
4. **最终轮**：最后一轮加密后，进行最终的行置换和字节替换。

**AES加密流程**

```mermaid
graph TD
    A[初始化] --> B[初始轮]
    B --> C{进行若干轮加密}
    C --> D[最终轮]
    D --> E[输出密文]
```

**AES解密过程**

AES解密过程与加密过程类似，但操作顺序相反。首先进行最后一轮的逆操作，然后逐步逆向每轮的操作，直到恢复出明文。

**AES加密算法的优点**

- **安全性高**：AES算法经过长时间的研究和测试，具有较高的安全性。
- **效率高**：AES算法采用固定长度的密钥和明文块，适合大规模数据处理。
- **适用范围广**：AES算法广泛应用于加密通信、存储保护和数据传输等场景。

**AES加密算法的缺点**

- **密钥管理复杂**：对称加密算法需要管理密钥的安全性和分发，确保密钥不被泄露。

**AES加密算法的实际应用**

- **网络通信**：AES算法广泛应用于VPN、TLS和SSH等网络通信协议，保障通信数据的安全。
- **数据存储**：AES算法用于加密存储在磁盘或数据库中的敏感数据，防止数据泄露。
- **文件加密**：AES算法用于加密个人电脑上的文件，保护用户隐私和数据安全。

#### 第13章：非对称加密算法

非对称加密算法是一种使用一对密钥（公钥和私钥）进行加密和解密的密码系统。这种算法的优点是解决了密钥分发的问题，具有更高的安全性。常见的非对称加密算法包括RSA、ECC和Diffie-Hellman密钥交换。

**RSA加密算法**

RSA（Rivest-Shamir-Adleman，瑞维斯特-沙米尔-阿德尔曼）算法是一种基于数论的公钥加密算法，其安全性依赖于大整数分解的难度。RSA算法的主要步骤包括密钥生成、加密和解密。

**RSA加密算法的步骤**

1. **密钥生成**：
   - 选择两个大素数`p`和`q`。
   - 计算`n = p * q`。
   - 计算`φ(n) = (p-1)(q-1)`。
   - 选择一个与`φ(n)`互质的整数`e`，通常选择`e = 65537`。
   - 计算`d`，使得`d * e ≡ 1 (mod φ(n))`，可以使用扩展欧几里得算法计算。

2. **加密过程**：
   - 公钥为`(n, e)`。
   - 私钥为`(n, d)`。
   - 加密明文`M`为密文`C`：`C ≡ M^e (mod n)`。

3. **解密过程**：
   - 使用私钥`(n, d)`解密密文`C`为明文`M`：`M ≡ C^d (mod n)`。

**RSA加密算法的优点**

- **安全性高**：RSA算法的安全性依赖于大整数分解的难度，目前尚未找到有效的破解方法。
- **密钥分发简单**：非对称加密算法使用一对密钥，公钥可以公开分发，私钥保持保密。

**RSA加密算法的缺点**

- **计算复杂度高**：RSA算法的加密和解密过程计算复杂度较高，不适合大规模实时数据处理。

**RSA加密算法的实际应用**

- **数字签名**：RSA算法用于实现数字签名，确保数据的完整性和身份认证。
- **安全传输**：RSA算法用于加密通信中的密钥交换，保障数据传输的安全。

**ECC加密算法**

椭圆曲线密码学（ECC，Elliptic Curve Cryptography）是一种基于椭圆曲线离散对数问题的密码算法。ECC算法在相同安全级别下比RSA算法具有更高的效率，且密钥长度更短。

**ECC加密算法的步骤**

1. **选择椭圆曲线**：选择一个定义在有限域上的椭圆曲线`E`。
2. **选择基点**：选择椭圆曲线上的一个基点`G`，满足`[n]G = O`（椭圆曲线的无限远点），其中`n`是椭圆曲线的阶。
3. **生成密钥**：
   - 选择一个随机整数`k`，使得`k < n`。
   - 计算私钥`d = k`。
   - 计算公钥`P = k * G`。

4. **加密过程**：
   - 加密明文`M`为密文`C`：`C = (c_1, c_2)`，其中`c_1 = M^k (mod p)`，`c_2 = G^m (mod p)`。

5. **解密过程**：
   - 使用私钥`d`解密密文`C`为明文`M`：`M = c_1^d (mod p)`。

**ECC加密算法的优点**

- **安全性高**：ECC算法基于椭圆曲线离散对数问题，目前尚未找到有效的破解方法。
- **效率高**：在相同安全级别下，ECC算法的密钥长度更短，计算复杂度更低。
- **计算速度快**：ECC算法的计算速度比RSA算法更快。

**ECC加密算法的实际应用**

- **加密通信**：ECC算法用于VPN、TLS和SSL等加密通信协议，保障通信数据的安全。
- **数字签名**：ECC算法用于实现数字签名，确保数据的完整性和身份认证。

**Diffie-Hellman密钥交换**

Diffie-Hellman密钥交换是一种基于离散对数问题的密钥交换协议，用于在不安全的通信信道上交换密钥。Diffie-Hellman密钥交换协议的核心思想是通过数学运算实现安全的密钥分发。

**Diffie-Hellman密钥交换的步骤**

1. **参数选择**：选择一个大素数`p`和一个生成元`g`。
2. **密钥生成**：
   - 发送方计算：`a = g^x (mod p)`，发送`a`。
   - 接收方计算：`b = g^y (mod p)`，发送`b`。
3. **密钥计算**：
   - 发送方计算：`k = b^x (mod p)`。
   - 接收方计算：`k = a^y (mod p)`。

**Diffie-Hellman密钥交换的优点**

- **安全性高**：Diffie-Hellman密钥交换协议利用数学运算实现安全的密钥分发，无需共享密钥。
- **计算复杂度低**：Diffie-Hellman密钥交换的计算复杂度相对较低，适合实时通信。

**Diffie-Hellman密钥交换的实际应用**

- **VPN**：Diffie-Hellman密钥交换用于VPN通信中的密钥交换，保障VPN连接的安全性。
- **SSL/TLS**：Diffie-Hellman密钥交换用于SSL/TLS协议中的密钥交换，保障网络通信的安全。

#### 第14章：数字签名

数字签名是一种用于验证信息完整性和身份认证的技术。数字签名利用公钥密码学实现，确保签名的唯一性和不可抵赖性。常见的数字签名算法包括RSA签名和椭圆曲线数字签名算法（ECDSA）。

**RSA签名算法**

RSA签名算法是一种基于RSA公钥密码系统的数字签名算法。RSA签名算法的主要步骤包括签名和验证。

**RSA签名算法的步骤**

1. **密钥生成**：与RSA加密算法类似，生成公钥`n, e`和私钥`n, d`。
2. **签名过程**：
   - 输入明文`M`，计算哈希值`H(M)`。
   - 计算签名`S = H(M)^d (mod n)`。

3. **验证过程**：
   - 输入签名`S`和公钥`(n, e)`。
   - 计算验证值`V = H(M)^e (mod n)`。
   - 比较验证值`V`与签名`S`，如果`V = S`，则签名有效。

**RSA签名算法的优点**

- **安全性高**：RSA签名算法利用公钥密码学的安全性，确保签名的唯一性和不可抵赖性。
- **通用性强**：RSA签名算法适用于各种数据类型，包括文本、图像和音频等。

**RSA签名算法的缺点**

- **计算复杂度高**：RSA签名算法的计算复杂度较高，不适合大规模实时数据处理。

**RSA签名算法的实际应用**

- **电子邮件**：RSA签名算法用于电子邮件的签名，确保邮件的完整性和身份认证。
- **文件传输**：RSA签名算法用于文件传输中的签名，确保文件的完整性和来源验证。

**ECDSA签名算法**

椭圆曲线数字签名算法（ECDSA，Elliptic Curve Digital Signature Algorithm）是一种基于椭圆曲线密码学的数字签名算法。ECDSA算法具有较高的安全性，且计算效率高。

**ECDSA签名算法的步骤**

1. **密钥生成**：与ECC加密算法类似，生成公钥`P`和私钥`d`。
2. **签名过程**：
   - 输入明文`M`，计算哈希值`h = H(M)`。
   - 生成随机数`k`，计算签名`r = (h * k) * G`，`s = k^{-1} * (h * d + r * x)`。

3. **验证过程**：
   - 输入签名`r, s`和公钥`P`。
   - 计算验证值`v1 = h * G`，`v2 = (s * P + r * P)`。
   - 如果`v1 = v2`，则签名有效。

**ECDSA签名算法的优点**

- **安全性高**：ECDSA算法基于椭圆曲线离散对数问题，具有很高的安全性。
- **效率高**：ECDSA算法的计算效率高于RSA算法。

**ECDSA签名算法的实际应用**

- **区块链**：ECDSA算法用于区块链中的签名，确保交易数据的完整性和身份认证。
- **物联网**：ECDSA算法用于物联网设备中的签名，确保设备通信的安全性和身份认证。

#### 第15章：加密哈希算法

加密哈希算法是一种将任意长度的输入数据映射为固定长度输出数据的函数。加密哈希算法在密码学中具有广泛的应用，包括数据完整性验证、数字签名和密码协议等。

**MD5加密哈希算法**

MD5（Message Digest Algorithm 5）是一种广泛使用的加密哈希算法，由RSA实验室开发。MD5算法将输入数据映射为128位的哈希值。

**MD5加密哈希算法的步骤**

1. **预处理**：将输入数据填充至512位的界限，然后添加长度信息。
2. **初始化**：初始化四个32位的变量`A, B, C, D`，初始值分别为`01 23 45 67`。
3. **处理分组**：将输入数据分成512位的分组，依次进行处理。
   - 对于每个分组，进行四轮处理，每轮包含16次循环操作。
   - 每次循环操作包括 bitwise-AND、bitwise-OR、XOR和右移操作。
4. **输出结果**：将四个变量的最终值拼接成128位的哈希值。

**MD5加密哈希算法的优点**

- **速度快**：MD5算法的计算速度相对较快。
- **简单实现**：MD5算法的实现相对简单。

**MD5加密哈希算法的缺点**

- **安全性较低**：MD5算法容易受到碰撞攻击，不适用于需要高安全性的应用。
- **不适用新标准**：随着安全性的需求提升，MD5已不再被视为安全哈希算法。

**MD5加密哈希算法的实际应用**

- **文件校验**：MD5算法用于文件的完整性校验，确保文件未被篡改。
- **身份认证**：MD5算法用于用户密码的存储和验证。

**SHA-256加密哈希算法**

SHA-256（Secure Hash Algorithm 256）是美国国家标准与技术研究院（NIST）发布的一种安全哈希算法，是SHA-2算法的一部分。SHA-256算法将输入数据映射为256位的哈希值。

**SHA-256加密哈希算法的步骤**

1. **初始化**：初始化八个32位的变量`a, b, c, d, e, f, g, h`，初始值分别为`A, B, C, D, E, F, G, H`。
2. **处理分组**：将输入数据分成512位的分组，依次进行处理。
   - 对于每个分组，进行64次循环操作，每轮包括压缩函数和消息扩展。
   - 压缩函数包括多种操作，如 bitwise-AND、bitwise-OR、XOR、右移和左移。
   - 消息扩展通过非线性函数对输入数据进行处理。
3. **输出结果**：将八个变量的最终值拼接成256位的哈希值。

**SHA-256加密哈希算法的优点**

- **安全性高**：SHA-256算法具有较强的抗碰撞能力，安全性高。
- **广泛使用**：SHA-256算法被广泛应用于数字签名、数据完整性验证和加密协议。

**SHA-256加密哈希算法的缺点**

- **计算复杂度高**：SHA-256算法的计算复杂度相对较高。

**SHA-256加密哈希算法的实际应用**

- **数字签名**：SHA-256算法用于数字签名，确保数据的完整性和身份认证。
- **区块链**：SHA-256算法用于区块链中的数据完整性验证和区块链协议。

通过本章的讨论，我们可以看到密码算法在保障信息安全中的关键作用。对称加密算法如AES和DES具有计算速度快、效率高的优点，适用于大规模数据处理。非对称加密算法如RSA和ECC具有高安全性、密钥分发简单的优点，适用于安全传输和数字签名。加密哈希算法如MD5和SHA-256在数据完整性验证和身份认证中具有重要作用。理解这些密码算法的工作原理和实际应用，有助于我们更好地保障信息安全。

#### 第16章：密码学在现代网络安全中的应用

网络安全是现代信息安全的基石，密码学在其中发挥着关键作用。密码学技术被广泛应用于网络通信、身份认证、数据保护和网络安全协议中。

**网络通信**

网络通信中的加密技术用于保护数据传输的机密性。对称加密算法如AES和非对称加密算法如RSA被用于加密通信数据，确保数据在传输过程中不被窃取或篡改。SSL/TLS协议是网络通信中的标准加密协议，通过使用对称和非对称加密算法，保障Web浏览、电子邮件和文件传输等网络服务的安全性。

#### 第20章：加密货币与区块链技术

加密货币如比特币和以太坊是密码学在现代金融领域中的创新应用。比特币利用密码学技术实现了去中心化的电子货币系统，而以太坊则通过智能合约进一步扩展了区块链技术的应用。

**比特币**

比特币是一种基于区块链技术的加密货币，其交易记录存储在去中心化的分布式账本中。比特币的安全性依赖于密码学技术，特别是SHA-256哈希函数和数字签名。

- **SHA-256哈希函数**：比特币的区块链通过SHA-256哈希函数确保每个区块的哈希值唯一。每当一个新的区块生成时，系统会计算其哈希值，并将其与前一个区块的哈希值相连接。这种链式结构使得任何试图篡改区块链数据的行为都会导致链的破坏。
- **数字签名**：比特币交易中的每个用户都需要使用公钥和私钥进行签名。私钥用于签名交易，公钥则用于验证交易。这种机制确保了交易的不可抵赖性和安全性，因为一旦交易被签名，就无法被修改或撤销。

**以太坊**

以太坊是一种基于区块链的智能合约平台，它不仅支持加密货币交易，还允许开发者在平台上创建去中心化的应用（DApp）。

- **智能合约**：以太坊的智能合约是一种自执行合同，其条款和操作以代码形式定义。智能合约的安全性依赖于密码学技术，如椭圆曲线密码学（ECC）和SHA-3哈希函数。这些密码学工具确保智能合约的执行是可信和安全的。
- **去中心化身份验证**：以太坊通过密码学技术实现了去中心化的身份验证。用户可以生成自己的数字身份，并通过公钥-私钥对进行签名和验证。这种身份验证方式避免了中心化机构的参与，提高了系统的安全性和透明度。

**实际案例分析**

- **以太坊去中心化交易所（DEX）**：以太坊上的去中心化交易所（DEX）如Uniswap和SushiSwap，通过密码学技术实现了安全的交易。这些交易所利用以太坊区块链上的智能合约进行交易，确保交易的安全性和透明性。

在云计算环境中，数据加密是保障数据安全的重要手段。云计算服务提供商（CSP）通常使用对称加密算法（如AES）和非对称加密算法（如RSA）对用户数据加密。

- **非对称加密**：非对称加密算法如RSA被用于加密数据传输和密钥交换。例如，在SSL/TLS协议中，客户端和服务器使用RSA算法交换加密密钥，确保通信数据的安全。

- **加密分区**：加密分区技术通过密码学确保不同用户的数据在存储和传输过程中相互隔离。每个用户的数据都通过加密存储，确保其他用户无法访问。

        address sender;

        uint256 amount;
    }

    address private owner;

    constructor() {
        owner = msg.sender;
    }

    function sendTransaction(address recipient, uint256 amount) public {

        transactions.push(Transaction(msg.sender, recipient, amount));

        return transactions.length;
    }

    function getTransaction(uint256 index) public view returns (Transaction memory) {
        require(index < transactions.length, "Index out of bounds");
        return transactions[index];
    }
}
