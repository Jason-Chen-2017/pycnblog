### 第一部分：古典概率基础

#### 第1章：概率论简介

**1.1 概率的基本概念**

概率论是数学的一个分支，主要研究随机事件及其概率。在概率论中，我们关注的是在一系列可能结果中，某个特定结果发生的可能性大小。概率的基本概念包括随机试验、样本空间、事件等。

- **随机试验**：指的是一次试验或观察，其结果具有不确定性。

- **样本空间**：指的是进行随机试验时所有可能结果的集合。通常用\( S \)表示。

- **事件**：指的是样本空间中的某个子集，表示试验结果的一个特定集合。例如，掷硬币出现正面的事件可以表示为一个包含“正面”这一结果的子集。

**1.2 古典概率模型的局限性**

古典概率模型是基于一些理想化的假设，例如所有可能结果等可能发生，这些假设在现实世界中往往不成立。因此，古典概率模型存在以下局限性：

- **结果不均匀性**：古典概率模型假设所有结果等可能发生，但在现实中，不同结果的发生概率往往是不均匀的。

- **条件概率的复杂性**：古典概率模型难以处理条件概率和独立性问题，需要引入更复杂的数学工具。

- **概率空间的限制**：古典概率模型依赖于特定的概率空间，使得其应用受到限制。

**1.3 概率的公理化定义**

为了克服古典概率模型的局限性，概率论引入了公理化定义，即通过一些公理来定义概率的基本性质和运算规则。这些公理包括：

- **非负性**：对于任意事件\( A \)，其概率\( P(A) \)满足\( P(A) \geq 0 \)。

- **规范性**：必然事件的概率为1，即\( P(S) = 1 \)。

- **可列可加性**：对于任意两两互斥的事件序列\( A_1, A_2, A_3, \ldots \)，其并集的概率等于各事件概率之和，即\( P(\bigcup_{i=1}^{\infty} A_i) = \sum_{i=1}^{\infty} P(A_i) \)。

通过公理化定义，概率论得以在更广泛的领域中应用，并发展出许多新的概率模型和方法。

### 第2章：条件概率与独立性

**2.1 条件概率的定义与计算**

条件概率是指在已知某个事件发生的条件下，另一个事件发生的概率。设\( A \)和\( B \)是两个事件，\( P(B) > 0 \)，则\( A \)在\( B \)条件下的条件概率表示为\( P(A|B) \)。条件概率的计算公式为：

\[ P(A|B) = \frac{P(A \cap B)}{P(B)} \]

其中，\( P(A \cap B) \)表示事件\( A \)和事件\( B \)同时发生的概率。

**2.2 独立性及其应用**

独立性是指两个事件的发生互不影响。设\( A \)和\( B \)是两个事件，如果\( P(A \cap B) = P(A)P(B) \)，则称\( A \)和\( B \)相互独立。独立性在概率计算中具有重要意义，因为它简化了许多问题的计算。

例如，假设我们掷两枚公平的硬币，事件\( A \)表示第一枚硬币出现正面，事件\( B \)表示第二枚硬币出现正面。由于硬币是公平的，\( P(A) = P(B) = 1/2 \)。可以验证，事件\( A \)和事件\( B \)是独立的，因为\( P(A \cap B) = (1/2) \times (1/2) = 1/4 = P(A)P(B) \)。

**2.3 贝叶斯定理**

贝叶斯定理是条件概率的一个重要应用，它提供了一个在已知部分信息后更新概率的方法。设\( A \)和\( B \)是两个事件，\( P(B) > 0 \)，则\( A \)在\( B \)条件下的条件概率可以表示为：

\[ P(A|B) = \frac{P(B|A)P(A)}{P(B)} \]

其中，\( P(B|A) \)表示在事件\( A \)发生的条件下，事件\( B \)发生的概率。

贝叶斯定理的推导过程基于全概率公式和条件概率的定义，可以证明如下：

\[ P(A|B) = \frac{P(B|A)P(A)}{P(B)} = \frac{P(B|A)P(A)}{P(A) + P(A^c) - P(B|A)P(A^c)} \]

其中，\( P(A^c) \)表示事件\( A \)不发生的概率。通过化简，可以得到贝叶斯定理的形式。

贝叶斯定理在许多实际问题中有广泛应用，例如医学诊断、金融分析和机器学习等。它提供了一个基于先验知识和新证据更新概率的方法，从而帮助我们更好地理解和预测现实世界中的不确定性。

### 第3章：随机变量与分布

**3.1 随机变量的定义与性质**

随机变量是一种将随机试验的结果映射为数值的函数。设\( \Omega \)是样本空间，\( \mathcal{F} \)是\( \Omega \)上的一个σ-代数，\( \mathbb{P} \)是\( \Omega \)上的概率测度。一个随机变量\( X \)是一个从\( \Omega \)到实数集\( \mathbb{R} \)的函数，即\( X: \Omega \rightarrow \mathbb{R} \)。

随机变量的性质包括：

- **分布函数**：随机变量\( X \)的分布函数定义为\( F_X(x) = P(X \leq x) \)，它描述了随机变量\( X \)小于或等于某个实数\( x \)的概率。

- **概率分布**：随机变量\( X \)的概率分布是指其取值对应的概率分布，可以用概率质量函数（对于离散型随机变量）或概率密度函数（对于连续型随机变量）来描述。

- **期望和方差**：随机变量\( X \)的期望定义为\( E(X) = \int_{\mathbb{R}} x f_X(x) dx \)，方差定义为\( Var(X) = E[(X - E(X))^2] = \int_{\mathbb{R}} (x - E(X))^2 f_X(x) dx \)，它们描述了随机变量的中心位置和离散程度。

**3.2 常见概率分布**

概率分布描述了随机变量取不同值的概率。以下是一些常见的概率分布：

- **伯努利分布**：一个离散型概率分布，用于描述只有两个可能结果的随机试验。参数\( p \)表示成功的概率，失败的概率为\( 1 - p \)。

- **二项分布**：一个离散型概率分布，用于描述进行多次独立的伯努利试验，成功次数的概率分布。参数\( n \)是试验次数，\( p \)是每次试验成功的概率。

- **几何分布**：一个离散型概率分布，用于描述在连续的伯努利试验中，首次成功所需的试验次数的概率分布。参数\( p \)是每次试验成功的概率。

- **泊松分布**：一个离散型概率分布，用于描述在固定时间内事件发生的次数的概率分布。参数\( \lambda \)是事件发生的平均速率。

- **正态分布**：一个连续型概率分布，用于描述许多自然现象的随机变量。参数\( \mu \)是均值，\( \sigma \)是标准差。

- **均匀分布**：一个连续型概率分布，用于描述在某个区间内随机变量取值的概率分布，参数为区间长度。

**3.3 随机变量的函数**

随机变量的函数也是一个随机变量。设\( X \)是一个随机变量，\( g \)是一个定义在\( \mathbb{R} \)上的可微函数，则\( g(X) \)是一个新的随机变量，称为\( X \)的函数。随机变量\( g(X) \)的期望和方差可以通过以下公式计算：

\[ E(g(X)) = \int_{\mathbb{R}} g(x) f_X(x) dx \]
\[ Var(g(X)) = E[(g(X) - E(g(X)))^2] = \int_{\mathbb{R}} (g(x) - E(g(X)))^2 f_X(x) dx \]

这些公式描述了函数对随机变量的期望和方差的影响。

通过引入随机变量和概率分布，概率论提供了一种量化不确定性的方法，使我们在处理复杂问题时能够做出更准确的预测和决策。

### 第4章：期望与方差

**4.1 期望的定义与计算**

期望是随机变量的一种重要属性，它表示随机变量取值的平均值。设\( X \)是一个离散型随机变量，其取值为\( x_1, x_2, \ldots, x_n \)，对应的概率为\( p_1, p_2, \ldots, p_n \)，则\( X \)的期望定义为：

\[ E(X) = \sum_{i=1}^{n} x_i p_i \]

对于连续型随机变量，期望的定义略有不同。设\( X \)的分布函数为\( F_X(x) \)，概率密度函数为\( f_X(x) \)，则\( X \)的期望定义为：

\[ E(X) = \int_{\mathbb{R}} x f_X(x) dx \]

期望在统计学和概率论中具有重要作用，它帮助我们理解随机变量的中心位置。

**4.2 方差的定义与计算**

方差是随机变量离散程度的度量，它表示随机变量取值与其期望的偏离程度。设\( X \)是一个随机变量，其期望为\( E(X) \)，则\( X \)的方差定义为：

\[ Var(X) = E[(X - E(X))^2] \]

对于离散型随机变量，方差可以表示为：

\[ Var(X) = \sum_{i=1}^{n} (x_i - E(X))^2 p_i \]

对于连续型随机变量，方差可以表示为：

\[ Var(X) = \int_{\mathbb{R}} (x - E(X))^2 f_X(x) dx \]

方差是描述随机变量取值分散程度的量度，它帮助我们了解随机变量的波动性。

**4.3 离散与连续随机变量的期望与方差**

为了更深入地理解期望和方差，我们需要考虑离散型和连续型随机变量的期望和方差的计算方法。

**离散型随机变量**：

对于离散型随机变量，我们通常通过枚举所有可能的取值及其对应的概率来计算期望和方差。具体步骤如下：

1. 确定随机变量的所有可能取值和对应的概率。
2. 计算期望：\( E(X) = \sum_{i=1}^{n} x_i p_i \)。
3. 计算方差：\( Var(X) = \sum_{i=1}^{n} (x_i - E(X))^2 p_i \)。

**连续型随机变量**：

对于连续型随机变量，我们通常通过积分来计算期望和方差。具体步骤如下：

1. 确定随机变量的分布函数\( F_X(x) \)或概率密度函数\( f_X(x) \)。
2. 计算期望：\( E(X) = \int_{\mathbb{R}} x f_X(x) dx \)。
3. 计算方差：\( Var(X) = \int_{\mathbb{R}} (x - E(X))^2 f_X(x) dx \)。

通过计算期望和方差，我们可以更好地理解随机变量的行为，并在实际应用中进行预测和决策。

### 第5章：大数定律与中心极限定理

**5.1 大数定律**

大数定律是概率论中的一个基本定理，它描述了在大量重复试验下，随机变量的频率会趋近于其期望值。大数定律有几种形式，其中最常见的是切比雪夫大数定律和伯努利大数定律。

- **切比雪夫大数定律**：设\( X_1, X_2, \ldots, X_n \)是相互独立的随机变量序列，每个随机变量的期望为\( \mu \)，方差为\( \sigma^2 \)。则对于任意的\( \epsilon > 0 \)，有：

\[ P\left(\frac{\sum_{i=1}^{n} X_i - n\mu}{\sigma\sqrt{n}} \right) \rightarrow 1 \text{ 当 } n \rightarrow \infty \]

- **伯努利大数定律**：设\( X_1, X_2, \ldots, X_n \)是独立同分布的伯努利随机变量，成功概率为\( p \)，则：

\[ \frac{1}{n} \sum_{i=1}^{n} X_i \rightarrow p \text{ 当 } n \rightarrow \infty \]

大数定律在实际应用中具有重要意义，它为我们在统计分析中提供了理论依据。例如，在统计学中，我们经常通过大量样本的数据来估计总体的参数，而大数定律保证了这种估计在足够大的样本量下是可靠的。

**5.2 中心极限定理**

中心极限定理描述了在大量独立同分布的随机变量之和的分布会趋近于正态分布。中心极限定理有几种形式，其中最常见的是林德伯格-列维中心极限定理。

- **林德伯格-列维中心极限定理**：设\( X_1, X_2, \ldots, X_n \)是独立同分布的随机变量序列，每个随机变量的期望为\( \mu \)，方差为\( \sigma^2 \)。则：

\[ \frac{\sum_{i=1}^{n} X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{D} N(0,1) \text{ 当 } n \rightarrow \infty \]

其中，\( \xrightarrow{D} \)表示渐近分布。

中心极限定理在实际应用中具有重要意义。例如，在统计学中，我们经常使用正态分布来近似估计概率分布，而中心极限定理为这种近似提供了理论依据。此外，中心极限定理在金融、工程和科学等领域也有广泛的应用。

**5.3 大数定律与中心极限定理的应用**

大数定律和中心极限定理在统计学和数据分析中有着广泛的应用。

- **统计分析**：在大数定律的指导下，我们可以通过大量样本的数据来估计总体的参数，例如平均值和方差。而中心极限定理则提供了在样本量足够大的情况下，这种估计是合理的理论依据。

- **假设检验**：在假设检验中，大数定律和中心极限定理可以帮助我们确定样本量的选择，以使检验的显著性水平达到预期。

- **数据拟合**：中心极限定理可以帮助我们将实际数据的分布拟合为正态分布，从而进行进一步的统计分析。

- **风险分析**：在金融和工程等领域，大数定律和中心极限定理可以帮助我们评估风险和不确定性，从而做出更明智的决策。

通过大数定律和中心极限定理，我们能够在不确定的世界中找到一种可靠的方法来处理和解释数据，从而更好地理解和预测现实世界中的事件。

### 第二部分：贝叶斯推断方法

#### 第6章：贝叶斯推断的基本原理

**6.1 贝叶斯推断的基本概念**

贝叶斯推断是一种基于概率理论的推断方法，它通过先验知识和新证据来更新概率，从而对未知参数或事件做出推断。贝叶斯推断的基本概念包括先验分布、后验分布和贝叶斯推理过程。

- **先验分布**：在贝叶斯推断中，先验分布是对未知参数或事件概率的初始估计。它基于专家知识、历史数据或先前的观察，提供了一个概率分布作为初始假设。

- **后验分布**：在贝叶斯推断中，后验分布是在获取新证据后对未知参数或事件概率的更新。它是先验分布与观测数据结合的结果，反映了我们对参数或事件的新的理解。

- **贝叶斯推理过程**：贝叶斯推理过程是通过贝叶斯定理来更新先验分布，从而得到后验分布。贝叶斯定理提供了一个从先验分布和观测数据计算后验分布的公式，它体现了概率更新的原理。

**6.2 先验分布与后验分布**

在贝叶斯推断中，先验分布和后验分布是两个关键概念。先验分布是对未知参数或事件的概率分布的初始估计，而后验分布是在获取新证据后对先验分布的更新。

- **先验分布**：先验分布通常基于专家知识、历史数据或先前的观察。例如，在医学诊断中，先验分布可能基于医生的经验和对疾病发生率的了解。在机器学习中，先验分布可能基于历史数据集或专家知识。

- **后验分布**：后验分布是先验分布与观测数据结合的结果，它反映了我们在获取新证据后对未知参数或事件的新的理解。例如，在医学诊断中，如果新证据表明某病人患有一种疾病的概率很高，那么后验分布将表明该病人患病的概率也较高。

**6.3 贝叶斯推理过程**

贝叶斯推理过程是通过贝叶斯定理来更新先验分布，从而得到后验分布的过程。贝叶斯定理提供了一个从先验分布和观测数据计算后验分布的公式，它是贝叶斯推断的核心。

贝叶斯推理过程可以分为以下几个步骤：

1. **设定先验分布**：根据专家知识、历史数据或先前的观察，设定对未知参数或事件的先验分布。

2. **收集观测数据**：通过实验、观测或数据分析，收集与未知参数或事件相关的数据。

3. **应用贝叶斯定理**：使用贝叶斯定理计算后验分布。贝叶斯定理的公式如下：

\[ P(A|B) = \frac{P(B|A)P(A)}{P(B)} \]

其中，\( P(A|B) \)表示在事件\( B \)发生的条件下，事件\( A \)发生的概率，称为后验概率；\( P(B|A) \)表示在事件\( A \)发生的条件下，事件\( B \)发生的概率，称为似然函数；\( P(A) \)称为先验概率；\( P(B) \)称为边缘概率。

4. **更新先验分布**：根据后验分布，更新先验分布，从而得到新的先验分布。

5. **重复过程**：根据新的先验分布，重复上述步骤，继续收集观测数据并更新先验分布，直到达到所需的置信水平或精度。

贝叶斯推理过程的核心在于概率的更新，它使得我们能够根据新的证据不断调整对未知参数或事件的估计，从而提高推断的准确性。

### 第8章：贝叶斯网络

**8.1 贝叶斯网络的概念**

贝叶斯网络是一种概率图模型，用于表示一组变量之间的条件依赖关系。它由一组节点和有向边组成，每个节点表示一个随机变量，有向边表示变量之间的条件依赖关系。

- **节点**：贝叶斯网络中的每个节点代表一个随机变量。节点的状态可以用一个离散值或连续值来表示。

- **边**：贝叶斯网络中的边表示变量之间的条件依赖关系。边的方向表示变量之间的因果关系。具体来说，如果节点\( X_i \)是节点\( X_j \)的父节点，则\( X_j \)在\( X_i \)的条件下独立于其其他父节点。

**8.2 贝叶斯网络的构建**

构建贝叶斯网络通常涉及以下步骤：

1. **变量选择**：根据问题的背景和需求，选择需要建模的变量。

2. **依赖关系分析**：分析变量之间的依赖关系，确定哪些变量是其他变量的父节点。

3. **条件概率表**：为每个节点构建条件概率表（CPT），描述在给定父节点条件下，节点状态的概率分布。

4. **网络结构**：根据依赖关系和条件概率表，构建贝叶斯网络的结构。

**8.3 贝叶斯网络在不确定性推理中的应用**

贝叶斯网络在不确定性推理中具有重要的应用价值。通过贝叶斯网络，我们可以解决以下问题：

- **概率推理**：贝叶斯网络提供了一种有效的概率推理方法，用于计算变量之间的条件概率。例如，给定某些变量的观测值，我们可以使用贝叶斯网络计算其他变量的概率分布。

- **状态估计**：贝叶斯网络可以用于状态估计问题，例如在动态系统或时间序列数据中，通过贝叶斯网络计算系统的当前状态。

- **决策分析**：贝叶斯网络可以帮助我们进行决策分析，例如在医疗诊断、金融投资和供应链管理中，通过贝叶斯网络计算不同决策方案的概率和效用，从而选择最佳方案。

**实例：疾病诊断**

假设我们要构建一个贝叶斯网络来诊断某种疾病。变量包括：

- \( D \)：表示疾病是否发生，\( D=1 \)表示疾病发生，\( D=0 \)表示疾病不发生。
- \( S \)：表示症状是否出现，\( S=1 \)表示症状出现，\( S=0 \)表示症状不出现。
- \( T \)：表示检查结果是否为阳性，\( T=1 \)表示检查结果为阳性，\( T=0 \)表示检查结果为阴性。

根据医学知识和经验，我们可以确定变量之间的依赖关系，并构建条件概率表：

- \( P(D=1) = 0.01 \)（疾病发生的概率）
- \( P(D=0) = 0.99 \)（疾病不发生的概率）
- \( P(S|D=1) = 0.8 \)（在疾病发生的情况下，症状出现的概率）
- \( P(S|D=0) = 0.2 \)（在疾病不发生的情况下，症状出现的概率）
- \( P(T|S=1, D=1) = 0.95 \)（在症状出现且疾病发生的情况下，检查结果为阳性的概率）
- \( P(T|S=1, D=0) = 0.05 \)（在症状出现但疾病不发生的情况下，检查结果为阳性的概率）
- \( P(T|S=0, D=1) = 0.1 \)（在症状不出现且疾病发生的情况下，检查结果为阳性的概率）
- \( P(T|S=0, D=0) = 0.01 \)（在症状不出现且疾病不发生的情况下，检查结果为阳性的概率）

根据这些条件概率表，我们可以构建贝叶斯网络，并使用它进行不确定性推理。例如，如果我们观察到症状出现（\( S=1 \)）且检查结果为阳性（\( T=1 \）），我们可以使用贝叶斯网络计算疾病发生的概率：

\[ P(D=1|S=1, T=1) = \frac{P(S=1|D=1)P(T=1|S=1, D=1)P(D=1)}{P(S=1)P(T=1)} \]

\[ P(D=1|S=1, T=1) = \frac{0.8 \times 0.95 \times 0.01}{0.8 \times 0.95 + 0.2 \times 0.05} \]

\[ P(D=1|S=1, T=1) = \frac{0.0076}{0.0076 + 0.001} \]

\[ P(D=1|S=1, T=1) = 0.825 \]

这表明在观察到症状出现且检查结果为阳性的情况下，疾病发生的概率为82.5%。

通过贝叶斯网络，我们可以更准确地处理不确定性，从而在医学诊断、金融分析、机器学习和自然语言处理等领域做出更明智的决策。

**案例：股票价格预测**

假设我们要使用贝叶斯推断来预测某个股票的未来价格。相关的变量包括：

- \( P \)：表示股票未来价格，\( P \)是一个连续的随机变量。
- \( I \)：表示投资者对股票未来价格的观点，\( I \)是一个离散的随机变量。
- \( D \)：表示过去的市场数据，\( D \)是一个离散的随机变量。

根据历史数据和投资者观点，我们可以确定变量之间的概率关系，如下所示：

- \( P(P|I) \)：表示在投资者观点给定的条件下，股票价格的分布。
- \( P(I|D) \)：表示在市场数据给定的条件下，投资者观点的分布。
- \( P(D) \)：表示市场数据的分布。

为了预测股票的未来价格，我们可以使用贝叶斯定理，如下所示：

\[ P(P|I, D) = \frac{P(I|D)P(P|I)P(D)}{P(I, D)} \]

通过历史数据和投资者观点，我们可以计算出\( P(P|I) \)、\( P(I|D) \)和\( P(D) \)的值。假设我们得到了以下数值：

- \( P(P|I=高) = N(50, 5) \)
- \( P(P|I=低) = N(40, 5) \)
- \( P(I|D=好) = 0.6 \)
- \( P(I|D=差) = 0.4 \)
- \( P(D=好) = 0.5 \)
- \( P(D=差) = 0.5 \)

将这些值代入上述公式，我们可以计算出股票未来价格的预测分布。这个结果可以帮助投资者了解股票未来价格的潜在范围，从而做出更合理的投资决策。

为了评估客户的信用评分，我们可以使用贝叶斯定理，如下所示：

\[ P(C|F, E) = \frac{P(F|E)P(C|F, E)P(E)}{P(F, E)} \]

通过历史数据和客户财务状况，我们可以计算出\( P(C|F, E) \)、\( P(F|E) \)和\( P(E) \)的值。假设我们得到了以下数值：

- \( P(F|E=差) = 0.4 \)
- \( P(E=好) = 0.5 \)
- \( P(E=差) = 0.5 \)

- \( P(D=好) = 0.5 \)
- \( P(D=差) = 0.5 \)

将这些值代入上述公式，我们可以计算出在不同风险偏好和市场环境下的投资组合收益率分布。这个结果可以帮助投资者制定更优的投资策略，从而提高投资收益。

def bayes_naive_classifier(test_sample, training_data, labels):

        predicted_label = None

    for sample in test_samples:
