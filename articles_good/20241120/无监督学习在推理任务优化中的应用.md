在无监督学习中，常见的算法包括主成分分析（PCA）、聚类算法和维度约减算法。这些算法各有特点，适用于不同的应用场景。

#### 主成分分析（PCA）

主成分分析（PCA）是一种降维算法，通过将数据投影到新的坐标轴上，来简化数据的表示。PCA的核心思想是找到数据中的主要变化方向，即主成分，并仅保留这些主要成分，从而减少数据的维度。

**算法原理**：
1. **数据标准化**：首先对数据进行标准化处理，使得每个特征的均值为0，方差为1。
2. **计算协方差矩阵**：计算数据点的协方差矩阵，该矩阵反映了数据点之间的相关性。
3. **计算协方差矩阵的特征值和特征向量**：对协方差矩阵进行特征分解，得到特征值和特征向量。
4. **选择主要成分**：根据特征值的大小选择前k个特征向量，这些特征向量对应的数据维度即为降维后的数据。
5. **投影数据**：将原始数据投影到新坐标轴上，得到降维后的数据。

**伪代码**：
```
function PCA(data, k):
    # 数据标准化
    standardized_data = (data - mean(data)) / std(data)
    
    # 计算协方差矩阵
    covariance_matrix = cov(standardized_data)
    
    # 计算协方差矩阵的特征值和特征向量
    eigenvalues, eigenvectors = eig(covariance_matrix)
    
    # 选择主要成分
    top_k_eigenvectors = eigenvectors[:, sorted(eigenvalues, reverse=True)[:k]]
    
    # 投影数据
    projected_data = standardized_data @ top_k_eigenvectors
    
    return projected_data
```

**数学模型和公式**：
主成分分析的关键步骤可以通过以下数学模型和公式来描述：
$$
\text{标准化数据} = \frac{\text{原始数据} - \text{均值}}{\text{标准差}}
$$
$$
\text{协方差矩阵} = \text{数据矩阵} \times \text{数据矩阵}^T
$$
$$
\text{特征分解} = \text{协方差矩阵} = \text{特征值矩阵} \times \text{特征向量矩阵}
$$
$$
\text{降维数据} = \text{标准化数据} \times \text{主要成分向量}
$$

**举例说明**：
假设我们有一个包含100个数据点的数据集，每个数据点有10个特征。通过PCA，我们可以将这个高维数据集降维到2个主要成分。降维后的数据不仅保留了原始数据的主要信息，而且计算量大大减少。

#### 聚类算法

聚类算法是一种无监督学习方法，用于将数据集划分为若干个群组，使得同一群组内的数据尽可能相似，而不同群组的数据尽可能不同。

**常见的聚类算法**：

1. **K-均值聚类**：K-均值聚类是一种基于距离的聚类算法，它将数据划分为K个群组，每个群组的中心点就是该群组的均值。

   **算法原理**：
   1. 初始化K个中心点。
   2. 计算每个数据点到每个中心点的距离，并将其分配到最近的中心点。
   3. 更新每个中心点的位置，使其成为其对应群组的均值。
   4. 重复步骤2和步骤3，直到聚类中心点不再发生变化。

   **伪代码**：
   ```
   function KMeans(data, K, max_iterations):
       # 初始化K个中心点
       centroids = initialize_centroids(data, K)
       
       for i = 1 to max_iterations:
           # 计算每个数据点的群组
           clusters = assign_points_to_clusters(data, centroids)
           
           # 更新中心点
           centroids = update_centroids(data, clusters)
           
           # 检查是否收敛
           if not has_changed(centroids):
               break
       
       return centroids, clusters
   ```

2. **层次聚类**：层次聚类是一种自上而下或自下而上的聚类方法，它逐步合并或分解数据点，形成层次结构的聚类结果。

   **算法原理**：
   1. 自底向上：从每个数据点开始，逐步合并距离最近的点，直到所有点合并为一个群组。
   2. 自顶向下：从所有数据点合并为一个群组开始，逐步分裂为更小的群组。

   **伪代码**：
   ```
   function HierarchicalClustering(data):
       # 初始化每个数据点为一个群组
       clusters = initialize_clusters(data)
       
       while number_of_clusters(clusters) > 1:
           # 找到最近的两个群组
           closest_clusters = find_closest_clusters(clusters)
           
           # 合并最近的两个群组
           clusters = merge_clusters(clusters, closest_clusters)
       
       return clusters
   ```

3. **DBSCAN（Density-Based Spatial Clustering of Applications with Noise）**：DBSCAN是一种基于密度的聚类算法，它将数据点划分为核心点、边界点和噪声点。

   **算法原理**：
   1. 核心点：周围有足够多其他点的点。
   2. 边界点：周围有一定数量的点，但不足以成为核心点。
   3. 噪声点：周围没有足够点或点的数量太少。

   **伪代码**：
   ```
   function DBSCAN(data, min_points, radius):
       # 初始化聚类结果和点状态
       clusters = {}
       point_statuses = {}
       
       for point in data:
           if point_status(point) == UNVISITED:
               # 找到核心点
               if isCorePoint(point, data, min_points, radius):
                   cluster_id = generate_cluster_id()
                   expand_cluster(point, data, cluster_id, min_points, radius)
       
       return clusters
   ```

**数学模型和公式**：
聚类算法通常涉及以下数学模型和公式：

1. **距离度量**：
   $$
   d(p, q) = \sqrt{\sum_{i=1}^{n} (p_i - q_i)^2}
   $$
   其中$p$和$q$是两个数据点，$n$是特征的数量。

2. **聚类中心**：
   $$
   c = \frac{1}{N} \sum_{x \in C} x
   $$
   其中$C$是一个群组，$c$是该群组的中心。

3. **相似度度量**：
   $$
   s(c_1, c_2) = \frac{\sum_{x \in C_1} \sum_{y \in C_2} s(x, y)}{\sum_{x \in C_1} \sum_{y \in C_2} s(x, y)}
   $$
   其中$C_1$和$C_2$是两个群组，$s(x, y)$是数据点$x$和$y$之间的相似度。

**举例说明**：
假设我们有一个包含100个数据点的数据集，每个数据点有3个特征。通过K-均值聚类，我们可以将这100个数据点划分为10个群组。聚类结果可以通过计算每个群组的中心点和数据点到中心点的距离来评估。

#### 维度约减算法

维度约减算法旨在减少数据集的维度，从而简化数据的表示和处理。常见的维度约减算法包括线性判别分析（LDA）和t-SNE。

1. **线性判别分析（LDA）**：LDA是一种用于特征提取和降维的算法，其核心思想是找到数据的主要变化方向，从而最大化类间方差和最小化类内方差。

   **算法原理**：
   1. 计算每个类别的均值向量。
   2. 构建协方差矩阵，并对其进行特征分解。
   3. 选择前k个特征向量，这些特征向量对应的数据维度即为降维后的数据。

   **伪代码**：
   ```
   function LDA(data, labels, k):
       # 计算类别均值
       means = calculate_means(data, labels)
       
       # 计算协方差矩阵
       covariance_matrix = calculate_covariance_matrix(data, means, labels)
       
       # 特征分解
       eigenvalues, eigenvectors = eig(covariance_matrix)
       
       # 选择主要成分
       top_k_eigenvectors = eigenvectors[:, sorted(eigenvalues, reverse=True)[:k]]
       
       # 投影数据
       projected_data = data @ top_k_eigenvectors
      
       return projected_data
   ```

2. **t-SNE**：t-SNE是一种非线性的降维算法，它通过计算局部邻居的相似度，将高维数据投影到二维或三维空间中。

   **算法原理**：
   1. 计算每个数据点的局部邻居。
   2. 使用梯度下降法优化数据点的位置，使其在低维空间中的邻居关系保持不变。
   3. 重复迭代，直到收敛。

   **伪代码**：
   ```
   function tSNE(data, k, iterations):
       # 初始化数据点的位置
       positions = initialize_positions(data, k)
       
       for i = 1 to iterations:
           # 计算局部邻居
           neighbors = calculate_neighbors(positions, data, k)
           
           # 更新数据点的位置
           positions = update_positions(positions, neighbors)
           
           # 检查是否收敛
           if has_converged(positions):
               break
       
       return positions
   ```

**数学模型和公式**：
维度约减算法的数学模型和公式如下：

1. **线性判别分析（LDA）**：
   $$
   \text{类内协方差矩阵} = \sum_{i=1}^{C} (\text{均值向量}_i - \text{总均值}) (\text{均值向量}_i - \text{总均值})^T
   $$
   $$
   \text{类间协方差矩阵} = \sum_{i=1}^{C} N_i (\text{均值向量}_i - \text{总均值}) (\text{均值向量}_i - \text{总均值})^T
   $$
   $$
   \text{特征分解} = \text{类间协方差矩阵} = \text{特征值矩阵} \times \text{特征向量矩阵}
   $$
   $$
   \text{降维数据} = \text{数据矩阵} \times \text{主要成分向量}
   $$

2. **t-SNE**：
   $$
   \text{相似度度量} = \exp(-\frac{||\text{数据点}_i - \text{数据点}_j||^2}{2\sigma^2})
   $$
   $$
   \text{损失函数} = -\sum_{i=1}^{N} \sum_{j=1}^{N} \text{相似度度量} \times \ln(\text{相似度度量})
   $$
   $$
   \text{梯度更新} = \frac{\partial \text{损失函数}}{\partial \text{数据点}_i}
   $$

**举例说明**：
假设我们有一个包含100个数据点的数据集，每个数据点有10个特征。通过LDA，我们可以将这个高维数据集降维到2个主要成分，从而简化数据的表示。t-SNE则可以将这个高维数据集投影到二维空间中，使得相似的数据点在低维空间中保持较近的距离。

#### 基于聚类的方法

聚类是一种常用的无监督学习方法，通过将数据划分为多个群组，使得同一群组内的数据点尽可能相似，而不同群组的数据点尽可能不同。聚类算法在推理任务中具有广泛的应用，以下是一些常见的聚类算法：

1. **K-均值聚类**：
   K-均值聚类是一种基于距离的聚类算法，通过迭代更新聚类中心和数据点的归属，最终将数据划分为K个群组。K-均值聚类的优点是实现简单、易于实现，但缺点是容易陷入局部最优解。
   
   **算法原理**：
   1. 初始化K个聚类中心。
   2. 计算每个数据点到每个聚类中心的距离，并将其分配到最近的聚类中心。
   3. 根据当前聚类结果更新每个聚类中心的位置。
   4. 重复步骤2和步骤3，直到聚类中心不再发生变化。

   **伪代码**：
   ```
   function KMeans(data, K, max_iterations):
       # 初始化K个聚类中心
       centroids = initialize_centroids(data, K)
       
       for i = 1 to max_iterations:
           # 计算每个数据点的群组
           clusters = assign_points_to_clusters(data, centroids)
           
           # 更新聚类中心
           centroids = update_centroids(data, clusters)
           
           # 检查是否收敛
           if not has_changed(centroids):
               break
       
       return centroids, clusters
   ```

2. **层次聚类**：
   层次聚类是一种自底向上或自顶向下的聚类方法，通过逐步合并或分解数据点，形成层次结构的聚类结果。层次聚类的优点是能够生成聚类树，有助于理解数据的层次结构，但缺点是计算复杂度较高。

   **算法原理**：
   1. 自底向上：从每个数据点开始，逐步合并距离最近的点，直到所有点合并为一个群组。
   2. 自顶向下：从所有数据点合并为一个群组开始，逐步分裂为更小的群组。

   **伪代码**：
   ```
   function HierarchicalClustering(data):
       # 初始化聚类结果和点状态
       clusters = initialize_clusters(data)
       
       while number_of_clusters(clusters) > 1:
           # 找到最近的两个群组
           closest_clusters = find_closest_clusters(clusters)
           
           # 合并最近的两个群组
           clusters = merge_clusters(clusters, closest_clusters)
       
       return clusters
   ```

3. **DBSCAN**：
   DBSCAN是一种基于密度的聚类算法，通过识别核心点、边界点和噪声点，将数据点划分为多个群组。DBSCAN的优点是能够处理非均匀分布的数据，但缺点是对参数的选择敏感。

   **算法原理**：
   1. 初始化聚类结果和点状态。
   2. 对每个未访问的点，检查其是否为核心点、边界点或噪声点。
   3. 将核心点及其邻域点划分为同一群组。
   4. 重复步骤2和步骤3，直到所有点都被访问。

   **伪代码**：
   ```
   function DBSCAN(data, min_points, radius):
       # 初始化聚类结果和点状态
       clusters = {}
       point_statuses = {}
       
       for point in data:
           if point_status(point) == UNVISITED:
               # 找到核心点
               if isCorePoint(point, data, min_points, radius):
                   cluster_id = generate_cluster_id()
                   expand_cluster(point, data, cluster_id, min_points, radius)
       
       return clusters
   ```

**数学模型和公式**：

1. **K-均值聚类**：
   $$
   d(p, q) = \sqrt{\sum_{i=1}^{n} (p_i - q_i)^2}
   $$
   $$
   c = \frac{1}{N} \sum_{x \in C} x
   $$
   $$
   \text{损失函数} = \sum_{i=1}^{N} d(p_i, c)
   $$

2. **层次聚类**：
   $$
   \text{距离度量} = \min_{i, j} d(p_i, p_j)
   $$
   $$
   \text{合并准则} = \min_{i, j} \sum_{x \in C_i \cup C_j} d(x, c)
   $$

3. **DBSCAN**：
   $$
   \text{核心点} = \text{存在} \sum_{i=1}^{n} d(p_i, p) < \text{给定半径}
   $$
   $$
   \text{边界点} = \text{存在} \sum_{i=1}^{n} d(p_i, p) < \text{给定半径} \text{，且邻域点数} < \text{给定最小点数}
   $$
   $$
   \text{噪声点} = \text{未访问点} \text{，且不是核心点或边界点}
   $$

**举例说明**：

假设我们有一个包含100个数据点的数据集，每个数据点有3个特征。通过K-均值聚类，我们可以将这100个数据点划分为10个群组。层次聚类和DBSCAN则可以生成聚类树，有助于理解数据的层次结构和密度分布。

#### 基于生成模型的方法

生成模型是一种无监督学习方法，通过学习数据点的生成过程，从而对数据进行建模和推理。生成模型在推理任务中具有广泛的应用，以下是一些常见的生成模型：

1. **高斯混合模型（Gaussian Mixture Model, GMM）**：
   高斯混合模型是一种概率模型，通过多个高斯分布的叠加来表示数据的分布。GMM在聚类、降维和异常检测等领域有广泛应用。

   **算法原理**：
   1. 初始化模型参数，包括高斯分布的均值、方差和权重。
   2. 使用EM算法迭代优化模型参数，使得数据点的似然函数最大化。
   3. 根据模型参数生成数据点，并进行聚类。

   **伪代码**：
   ```
   function GMM(data, K, max_iterations):
       # 初始化模型参数
       means, covariances, weights = initialize_parameters(data, K)
       
       for i = 1 to max_iterations:
           # E步：计算数据点的责任度
           responsibilities = calculate_responsibilities(data, means, covariances, weights)
           
           # M步：更新模型参数
           means, covariances, weights = update_parameters(data, responsibilities)
           
           # 检查是否收敛
           if not has_changed(means, covariances, weights):
               break
       
       return means, covariances, weights
   ```

2. **变分自编码器（Variational Autoencoder, VAE）**：
   变分自编码器是一种深度生成模型，通过编码器和解码器学习数据点的潜在分布，从而实现数据的生成和降维。

   **算法原理**：
   1. 编码器将数据映射到潜在空间，生成潜在分布的参数。
   2. 解码器从潜在空间采样，生成重构数据。
   3. 使用损失函数优化编码器和解码器的参数，使得重构数据尽可能接近原始数据。

   **伪代码**：
   ```
   function VAE(data, hidden_size, latent_size, learning_rate, epochs):
       # 初始化编码器和解码器的参数
       encoder_params, decoder_params = initialize_parameters(hidden_size, latent_size)
       
       for epoch = 1 to epochs:
           # 计算编码器的损失
           encoder_loss = calculate_encoder_loss(data, encoder_params)
           
           # 计算解码器的损失
           decoder_loss = calculate_decoder_loss(data, decoder_params)
           
           # 更新编码器和解码器的参数
           encoder_params, decoder_params = update_parameters(encoder_loss, decoder_loss, learning_rate)
           
           # 打印当前epoch的损失
           print(f"Epoch {epoch}: Encoder Loss = {encoder_loss}, Decoder Loss = {decoder_loss}")
       
       return encoder_params, decoder_params
   ```

3. **生成对抗网络（Generative Adversarial Network, GAN）**：
   生成对抗网络是一种由生成器和判别器组成的对抗性模型，通过最小化生成器和判别器的损失函数，学习数据的分布。

   **算法原理**：
   1. 生成器生成虚假数据，判别器判断数据是真实还是虚假。
   2. 生成器和判别器交替训练，生成器试图生成更真实的数据，判别器试图区分真实数据和虚假数据。
   3. 使用损失函数优化生成器和判别器的参数。

   **伪代码**：
   ```
   function GAN(data, generator_params, discriminator_params, learning_rate, epochs):
       for epoch = 1 to epochs:
           # 训练判别器
           discriminator_loss = train_discriminator(data, generator_params, discriminator_params, learning_rate)
           
           # 训练生成器
           generator_loss = train_generator(data, generator_params, discriminator_params, learning_rate)
           
           # 打印当前epoch的损失
           print(f"Epoch {epoch}: Generator Loss = {generator_loss}, Discriminator Loss = {discriminator_loss}")
       
       return generator_params, discriminator_params
   ```

**数学模型和公式**：

1. **高斯混合模型（GMM）**：
   $$
   p(x) = \sum_{i=1}^{K} \pi_i \cdot \mathcal{N}(x; \mu_i, \sigma_i^2)
   $$
   $$
   \text{似然函数} = \prod_{i=1}^{N} p(x_i)
   $$
   $$
   \text{损失函数} = -\ln(\text{似然函数})
   $$

2. **变分自编码器（VAE）**：
   $$
   q(z|x) = \mathcal{N}(z; \mu(x), \sigma(x))
   $$
   $$
   p(x|z) = \mathcal{N}(x; \mu(z), \sigma(z))
   $$
   $$
   \text{损失函数} = D(q(z|x)||p(z))
   $$
   其中$D$表示Kullback-Leibler散度。

3. **生成对抗网络（GAN）**：
   $$
   \min_G \max_D \mathbb{E}_{x \sim p_{\text{data}}}[D(x)] - \mathbb{E}_{z \sim p_z}[D(G(z))]
   $$
   其中$G(z)$表示生成器生成的数据，$D(x)$表示判别器对真实数据的判断。

**举例说明**：

假设我们有一个包含100个数据点的数据集，每个数据点有3个特征。通过高斯混合模型（GMM），我们可以将这100个数据点聚类为5个群组。变分自编码器（VAE）和生成对抗网络（GAN）则可以生成新的数据点，从而模拟数据的生成过程。

#### 基于图的方法

   **算法原理**：

   2. 对每个节点，计算其邻居节点的特征平均值。
   3. 更新节点的特征向量。
   4. 重复步骤2和步骤3，直到收敛。

   function GCN(data, adj_matrix, hidden_size, learning_rate, epochs):

           node_features = aggregate_neighbors(node_features, adj_matrix)
           
           # 更新节点特征向量
           node_features = update_node_features(node_features, learning_rate)
           
           # 打印当前epoch的损失
           print(f"Epoch {epoch}: Loss = {calculate_loss(node_features, data)}")
       
       return node_features
   ```

2. **图自动编码器（Graph Autoencoder, GAE）**：
   图自动编码器是一种基于图结构的自动编码器，通过编码器和解码器学习图节点的潜在表示。

   **算法原理**：

   2. 解码器从潜在空间采样，重构图节点的特征。
   3. 使用损失函数优化编码器和解码器的参数，使得重构节点特征尽可能接近原始节点特征。

   **伪代码**：

   function GAE(data, adj_matrix, hidden_size, learning_rate, epochs):
       # 初始化编码器和解码器的参数
       encoder_params, decoder_params = initialize_parameters(hidden_size)
       
       for epoch = 1 to epochs:
           # 计算编码器的损失

           # 打印当前epoch的损失
           print(f"Epoch {epoch}: Encoder Loss = {encoder_loss}, Decoder Loss = {decoder_loss}")
       
       return encoder_params, decoder_params
   ```

3. **图生成对抗网络（Graph Generative Adversarial Network, GGAN）**：
   图生成对抗网络是一种基于图结构的生成对抗性模型，通过生成器和判别器学习图的分布。

   **算法原理**：
   1. 生成器生成图结构，判别器判断图是真实还是虚假。
   2. 生成器和判别器交替训练，生成器试图生成更真实的图结构，判别器试图区分真实图和虚假图。
   3. 使用损失函数优化生成器和判别器的参数。

   **伪代码**：
   ```
   function GGAN(data, adj_matrix, generator_params, discriminator_params, learning_rate, epochs):
       for epoch = 1 to epochs:
           # 训练判别器
           discriminator_loss = train_discriminator(data, generator_params, discriminator_params, learning_rate)
           
           # 训练生成器
           generator_loss = train_generator(data, generator_params, discriminator_params, learning_rate)
           
           # 打印当前epoch的损失
           print(f"Epoch {epoch}: Generator Loss = {generator_loss}, Discriminator Loss = {discriminator_loss}")
       
       return generator_params, discriminator_params
   ```

**数学模型和公式**：

1. **图卷积网络（GCN）**：
   $$
   \mathbf{h}_i^{(l)} = \sigma(\sum_{j \in \mathcal{N}(i)} \mathbf{W}^{(l-1)} \mathbf{h}_j^{(l-1)} + \mathbf{b}^{(l)})
   $$
   其中$\mathcal{N}(i)$表示节点$i$的邻接节点集合，$\mathbf{W}^{(l-1)}$和$\mathbf{b}^{(l)}$分别是图卷积层的权重和偏置。

2. **图自动编码器（GAE）**：
   $$
   \mu = \mathbb{E}_{q(z|x)}[z]
   $$
   $$
   \log p(x) = \mathbb{E}_{z \sim q(z|x)}[\log p(x|z)]
   $$
   $$
   \text{损失函数} = - \mathbb{E}_{x}[\log p(x)]
   $$

3. **图生成对抗网络（GGAN）**：
   $$
   \min_G \max_D \mathbb{E}_{x \sim p_{\text{data}}}[D(x)] - \mathbb{E}_{z \sim p_z}[D(G(z))]
   $$

**举例说明**：

假设我们有一个包含100个节点的图结构，每个节点有3个特征。通过图卷积网络（GCN），我们可以学习到图节点的潜在表示。图自动编码器（GAE）和图生成对抗网络（GGAN）则可以生成新的图结构，从而模拟图的生成过程。

**算法原理**：

K-均值聚类算法是一种基于距离的聚类算法，其核心思想是将数据点划分到K个群组中，使得每个群组内的数据点尽可能接近群组的中心点。

**伪代码**：

    # 计算每个数据点到每个聚类中心的距离

    clusters = assign_points_to_clusters(data, centroids, distances)

#### 性能评估

性能评估是确保无监督学习算法有效性的重要步骤。以下介绍几种常见的性能评估指标：

1. **轮廓系数（Silhouette Coefficient）**：
   轮廓系数用于评估聚类结果的紧密程度和分离度。其取值范围为[-1, 1]，越接近1表示聚类效果越好。

   **计算公式**：
   $$
   \text{Silhouette Coefficient} = \frac{\text{平均值}(\text{邻近群组内的最近邻距离}) - \text{标准差}(\text{邻近群组内的最近邻距离})}{\text{最大值}(\text{邻近群组内的最近邻距离}) - \text{最小值}(\text{邻近群组内的最近邻距离})}
   $$

2. **平均平方误差（Mean Squared Error, MSE）**：
   平均平方误差用于评估聚类中心与实际数据点的距离。其值越小，表示聚类效果越好。

   **计算公式**：
   $$
   \text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (d(x_i, c_i) - \bar{d})^2
   $$
   其中$N$是数据点的数量，$d(x_i, c_i)$是数据点$x_i$与聚类中心$c_i$之间的距离，$\bar{d}$是所有数据点与聚类中心之间的平均距离。

3. **类内平均距离（Average Within-Cluster Distance, AWCD）**：
   类内平均距离用于评估每个群组内数据点的平均距离。其值越小，表示聚类效果越好。

   **计算公式**：
   $$
   \text{AWCD} = \frac{1}{K} \sum_{i=1}^{K} \frac{1}{N_i} \sum_{j=1}^{N_i} d(x_{ij}, c_i)
   $$
   其中$K$是群组的数量，$N_i$是第$i$个群组内的数据点数量，$d(x_{ij}, c_i)$是数据点$x_{ij}$与聚类中心$c_i$之间的距离。

**具体评估**：

```python
from sklearn.metrics import silhouette_score

# 计算轮廓系数
silhouette_coeff = silhouette_score(data, clusters)

# 计算平均平方误差
mse = np.mean((model.transform(data) - centroids)**2)

# 计算类内平均距离
awcd = np.mean([np.mean((data[model.labels_ == i] - centroid)**2) for i, centroid in enumerate(centroids)])

print("Silhouette Coefficient:", silhouette_coeff)
print("Mean Squared Error:", mse)
print("Average Within-Cluster Distance:", awcd)
```
