#### 2.1 零样本学习的定义和分类

##### 定义

零样本学习（Zero-Shot Learning，ZSL）是一种机器学习技术，它使得模型能够对从未见过的类别进行分类。与传统监督学习相比，零样本学习不需要对未知类别进行预训练或数据拟合，而是通过学习类别之间的关系和特征，使得模型能够在新类别上表现出色。

##### 分类方法

零样本学习可以根据不同的分类方法进行分类，主要包括以下几种：

1. **基于原型的方法（Prototype-based methods）**：
   这种方法将每个类别映射到一个原型向量，原型向量是类别成员的均值或中心点。新类别通过计算其特征向量与原型向量之间的相似度来进行分类。

2. **基于度量学习的方法（Metric Learning methods）**：
   度量学习方法通过学习一个度量函数，使得相同类别的特征向量之间距离较短，而不同类别的特征向量之间距离较长。常用的度量学习算法包括对比损失（Contrastive Loss）和三元组损失（Triplet Loss）。

3. **基于聚类的方法（Clustering-based methods）**：
   聚类方法通过将特征空间中的数据点进行分组，每个分组代表一个类别。新类别通过将其特征向量分配到最近的分组来进行分类。

4. **基于匹配的方法（Matching-based methods）**：
   匹配方法通过将新类别与已知类别进行匹配，基于匹配结果进行分类。常用的匹配方法包括最近邻（Nearest Neighbor）和基于梯度的匹配。

5. **基于关系的方法（Relation-based methods）**：
   关系方法通过学习类别之间的关系图，利用图结构进行分类。这种方法能够利用类别之间的复杂关系，提高分类性能。

#### 2.5 零样本学习的关键算法原理

##### 基于原型的方法（Prototype-based methods）

1. **算法原理**：
   - 将每个类别映射到一个原型向量。
   - 新类别通过计算其特征向量与原型向量之间的相似度来进行分类。
   - 伪代码：
     ```python
     def classify(x, prototypes):
         distances = []
         for prototype in prototypes:
             distance = euclidean_distance(x, prototype)
             distances.append(distance)
         return category with minimum distance
     ```

2. **数学模型和公式**：
   - 距离公式：$d(x, y) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}$
   - 分类决策：选择距离最小的原型向量对应的类别。

3. **举例说明**：
   - 假设有两个类别猫和狗，每个类别有两个原型向量。
   - 新类别通过计算其特征向量与两个原型向量的距离，选择距离最小的类别作为预测结果。

##### 基于度量学习的方法（Metric Learning methods）

1. **算法原理**：
   - 学习一个度量函数，使得相同类别的特征向量之间距离较短，而不同类别的特征向量之间距离较长。
   - 常用的度量学习算法包括对比损失（Contrastive Loss）和三元组损失（Triplet Loss）。

2. **数学模型和公式**：
   - 对比损失：$L_{contrastive} = \sum_{i=1}^{n} [1 - y \cdot d(x_i, y_i)]$
     - 其中，$x_i$和$y_i$分别是同一类别的特征向量，$y$是标签，$d$是度量函数。
   - 三元组损失：$L_{triplet} = \sum_{i=1}^{n} [a - d(x_i, y_i) + d(x_i, \tilde{y_i})]$
     - 其中，$a$是一个超参数，$\tilde{y_i}$是不同类别的特征向量。
