$$
Topsis(S_i) = \frac{d_i^+ + d_i^-}{d_i^+ + d_i^- + d_i^0}

其中，$d_i^+$ 是正理想解与评价对象之间的距离，$d_i^- $ 是负理想解与评价对象之间的距离，$d_i^0$ 是零参考点与评价对象之间的距离。

#### 2.1.1 计算机基本原理

计算机的基本原理可以追溯到其最核心的组件——中央处理器（CPU）。CPU是计算机的“大脑”，负责执行程序指令和处理数据。计算机的基本原理主要包括以下几个方面：

1. **冯诺依曼架构**：现代计算机通常基于冯诺依曼架构，该架构将计算机分为五个部分：输入设备、输出设备、存储器、运算器和控制器。

   **Mermaid 流程图：冯诺依曼架构**

2. **指令集**：指令集是计算机硬件能够理解并执行的指令集合。常见的指令集有复杂指令集（CISC）和精简指令集（RISC）。

3. **数据存储**：数据在计算机中的存储方式包括内存（RAM）和硬盘（HDD/SSD）。内存用于临时存储正在处理的数据，硬盘则用于长期存储数据。

#### 2.1.2 计算机硬件与软件

计算机硬件包括各种物理组件，如中央处理器（CPU）、内存（RAM）、存储器（硬盘、固态硬盘）、输入设备（键盘、鼠标）、输出设备（显示器、打印机）等。

1. **中央处理器（CPU）**：CPU是计算机的核心组件，负责执行指令和处理数据。其性能主要由主频和核心数决定。

3. **存储器（硬盘、固态硬盘）**：硬盘和固态硬盘用于长期存储数据。固态硬盘（SSD）相比传统硬盘（HDD）具有更快的数据读写速度和更长的使用寿命。

4. **输入设备**：输入设备用于向计算机输入数据，如键盘、鼠标、扫描仪等。

5. **输出设备**：输出设备用于向用户展示计算机处理结果，如显示器、打印机、音响等。

#### 2.2.1 因特网的基本概念

因特网（Internet）是一个全球性的网络系统，它通过路由器和交换机将数以亿计的计算机和网络连接起来，使得信息能够在全球范围内快速传递和共享。以下是因特网的基本概念：

1. **IP地址**：IP地址是因特网上每台计算机的唯一标识符，它由32位二进制数组成，通常表示为四组十进制数，如192.168.1.1。IP地址分为IPv4和IPv6两种类型，其中IPv6地址采用128位二进制数，解决了IPv4地址耗尽的问题。

   **伪代码示例：获取IP地址**

   ```python
   import socket

   def get_ip_address():
       s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
       s.connect(('www.example.com', 80))
       ip_address = s.getsockname()[0]
       s.close()
       return ip_address
   ```

2. **域名系统（DNS）**：域名系统（DNS）是将域名（如www.example.com）转换为IP地址的系统。DNS服务器存储了大量的域名和IP地址映射关系，使得用户可以通过容易记忆的域名访问网站。

   **伪代码示例：DNS查询**

   ```python
   import socket

   def query_dns(domain):
       s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
   ```
