### 第1章：集合论概述

集合论是现代数学的基础，它的概念和原理广泛应用于数学的各个分支。在这一章中，我们将简要回顾集合论的发展历史，介绍集合论的基本概念，并阐述集合论的基本定理。

##### 1.1 集合论的发展历史

集合论的发展可以追溯到19世纪末期，由德国数学家乔治·康托尔（Georg Cantor）创立。康托尔在研究无穷大问题时，提出了集合的概念，并建立了集合论的基础。他的工作引发了一系列关于集合的性质和结构的深入研究。在康托尔的努力下，集合论逐渐发展成为现代数学的一个独立分支。

##### 1.2 集合论的基本概念

集合论的基本概念包括集合、元素、集合的表示方法等。集合是由一些确定的、互不相同的对象组成的整体，这些对象称为集合的元素。集合可以用大写字母如A、B等表示，元素用小写字母如a、b等表示。集合的表示方法主要有列举表示法和描述表示法。

- 列举表示法：将集合的所有元素一一列举出来，用花括号{}括起来。例如，集合A = {1, 2, 3}表示一个包含元素1、2、3的集合。
- 描述表示法：用描述性语句来定义集合的元素。例如，集合B = {x | x是自然数}表示一个包含所有自然数的集合。

##### 1.3 集合论的基本定理

集合论的基本定理包括集合的并集、交集、差集和补集等。

- 并集（Union）：集合A和B的并集是由属于A或属于B的所有元素组成的集合，记作A ∪ B。例如，集合C = {1, 2, 3}和集合D = {4, 5}的并集是C ∪ D = {1, 2, 3, 4, 5}。
- 交集（Intersection）：集合A和B的交集是由既属于A又属于B的所有元素组成的集合，记作A ∩ B。例如，集合C = {1, 2, 3}和集合D = {4, 5}的交集是C ∩ D = {}（空集）。
- 差集（Difference）：集合A和B的差集是由属于A但不属于B的所有元素组成的集合，记作A - B。例如，集合C = {1, 2, 3}和集合D = {4, 5}的差集是C - D = {1, 2, 3}。
- 补集（Complement）：集合A的补集是由不属于A的元素组成的集合，记作A'。例如，集合A = {1, 2, 3}的补集是A' = {x | x不是自然数}。

### 第2章：集合的表示与运算

集合的表示和运算在集合论中占有重要地位。在这一章中，我们将详细讨论集合的表示方法、基本运算及其性质。

##### 2.1 集合的表示

集合的表示方法主要有列举表示法和描述表示法。

- 列举表示法

  列举表示法是将集合的所有元素一一列举出来，用花括号{}括起来。这种方法直观简单，适用于元素个数较少的集合。例如，集合A = {1, 2, 3}。

  ```markdown
  - A = {1, 2, 3}
  ```

- 描述表示法

  描述表示法是用描述性语句来定义集合的元素。这种方法适用于元素较多或无法一一列举的集合。例如，集合B = {x | x是自然数}表示所有自然数的集合。

  ```markdown
  - B = {x | x是自然数}
  ```

  描述表示法中的符号“|”表示“满足”，读作“这样的x构成集合B”。

##### 2.2 集合的基本运算

集合的基本运算包括并集、交集、差集和补集等。

- 并集（Union）

  并集是由属于A或属于B的所有元素组成的集合，记作A ∪ B。例如，集合C = {1, 2, 3}和集合D = {4, 5}的并集是C ∪ D = {1, 2, 3, 4, 5}。

- 交集（Intersection）

  交集是由既属于A又属于B的所有元素组成的集合，记作A ∩ B。例如，集合C = {1, 2, 3}和集合D = {4, 5}的交集是C ∩ D = {}（空集）。


- 差集（Difference）

  差集是由属于A但不属于B的所有元素组成的集合，记作A - B。例如，集合C = {1, 2, 3}和集合D = {4, 5}的差集是C - D = {1, 2, 3}。


- 补集（Complement）

  补集是由不属于A的元素组成的集合，记作A'。例如，集合A = {1, 2, 3}的补集是A' = {x | x不是自然数}。


##### 2.3 集合的性质

集合的性质包括封闭性、交换性、结合性和分配性等。

- 封闭性

  集合对于特定的运算结果是封闭的，即运算的结果仍然属于该集合。例如，自然数集合对于加法运算是封闭的。

  ```markdown
  - A = {1, 2, 3}
  - A + A = {2, 3, 4, 5}
  ```

- 交换性

  集合的运算满足交换律，即运算的顺序不影响结果。例如，并集和交集运算满足交换律。

  ```markdown
  - A ∪ B = B ∪ A
  - A ∩ B = B ∩ A
  ```

- 结合性

  集合的运算满足结合律，即多个运算的顺序不影响结果。例如，并集和交集运算满足结合律。

  ```markdown
  - (A ∪ B) ∪ C = A ∪ (B ∪ C)
  - (A ∩ B) ∩ C = A ∩ (B ∩ C)
  ```

- 分配性

  集合的运算满足分配律，即运算可以分配到括号内的每个元素。例如，并集和交集运算满足分配律。

  ```markdown
  - A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
  - A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
  ```

### 第3章：集合的划分与映射

集合的划分和映射是集合论中的重要概念，它们在数学和其他领域中有广泛的应用。在这一章中，我们将介绍集合的划分和映射的基本概念及其应用。

##### 3.1 集合的划分

集合的划分是指将一个集合划分为若干个子集合的过程。划分满足以下性质：

- 子集合互不相交：任意两个不同的子集合没有共同的元素。
- 子集合的并集等于原集合：所有子集合的并集等于原集合。

划分可以用集合的二元组表示，形式为D = {S1, S2, ..., Sn}，其中S1, S2, ..., Sn是原集合A的子集合。

划分的应用包括：

- 拓扑空间的划分：在拓扑学中，可以用划分来定义拓扑空间的不同区域。
- 代数结构的划分：在代数学中，可以用划分来研究群、环、域等的结构。

##### 3.2 映射的概念与分类

映射是指一个集合到另一个集合的元素之间的对应关系。映射可以用函数表示，形式为f: A → B，其中f是映射，A和B是两个集合。

映射的分类包括：

- 单射：对于集合A中的任意两个不同的元素x和y，如果f(x) ≠ f(y)，则映射f是单射。
- 满射：对于集合B中的任意一个元素y，存在至少一个元素x ∈ A，使得f(x) = y。
- 双射：如果映射既是单射又是满射，则称为双射。

划分和映射的关系：

- 划分可以看作是映射的特殊情况，即每个子集合都映射到同一个元素。
- 映射可以用来研究划分的性质，如映射的保序性、保号性等。

##### 3.3 映射的性质

映射具有以下性质：

- 单射：映射f是单射，即对于A中的任意两个不同的元素x和y，如果x ≠ y，则f(x) ≠ f(y)。
- 满射：映射f是满射，即对于B中的任意一个元素y，存在至少一个元素x ∈ A，使得f(x) = y。
- 双射：映射f是双射，即映射f既是单射又是满射。
- 同态：映射f保持集合的结构，即如果A和B都是群、环或域，则f保持运算。

划分和映射的应用：

- 拓扑学：在拓扑学中，划分和映射用于研究拓扑空间的性质，如连通性、紧致性等。
- 代数学：在代数学中，划分和映射用于研究代数结构的性质，如群、环、域的分解和分类。
- 计算机科学：在计算机科学中，划分和映射用于研究算法、数据结构等，如哈希表的实现、排序算法等。

### 第4章：集合的基数与公理系统

集合的基数和公理系统是集合论中的重要概念，它们在数学的许多领域有着广泛的应用。在这一章中，我们将介绍集合的基数和公理系统的基本概念及其应用。

##### 4.1 集合的基数

集合的基数是指集合中元素的数量。根据集合中元素的数量，集合的基数可以分为可数集合和不可数集合。

- 可数集合：如果一个集合的基数是自然数或者可以与自然数建立一一对应关系，则该集合称为可数集合。
- 不可数集合：如果一个集合的基数不是自然数，且无法与自然数建立一一对应关系，则该集合称为不可数集合。

常见的集合基数包括：

- 自然数集合：自然数集合的基数是无穷可数。
- 整数集合：整数集合的基数也是无穷可数。
- 有理数集合：有理数集合的基数是无穷可数。
- 实数集合：实数集合的基数是无穷不可数。

集合的基数具有以下性质：

- 基数相等：如果两个集合的基数相等，则它们是等势的。
- 基数比较：可数集合的基数小于不可数集合的基数。

##### 4.2 可数集合与不可数集合

可数集合和不可数集合在集合论中有着重要的地位。可数集合可以与自然数建立一一对应关系，而不可数集合则无法与自然数建立一一对应关系。

- 可数集合的性质：

  - 可数集合的基数是自然数或者无穷可数。
  - 可数集合可以进行划分和映射。

- 不可数集合的性质：

  - 不可数集合的基数不是自然数，且无穷不可数。
  - 不可数集合不能与自然数建立一一对应关系。
  - 不可数集合的划分和映射具有特殊性质。

##### 4.3 集合论的公理系统

集合论的公理系统是集合论的基础，它为集合论提供了一套基本原理和规则。常见的集合论公理系统包括：

- 基本集合论公理系统（Zermelo-Fraenkel集合论，简称ZFC）：

  - 基本集合论公理系统包括以下公理：

    - 存在公理：存在空集∅。
    - 分离公理：对于任意的集合A和属性P(x)，存在一个集合B，其中的元素都是A中满足属性P(x)的元素。
    - 联合公理：对于任意的集合A，存在一个集合B，其中的元素都是A的所有子集。
    - 全集公理：存在一个包含所有集合的集合。
    - 选择公理：对于任意的集合A的划分，存在一个选择函数，使得对于A中的任意一个元素，都有选择函数选出的子集包含这个元素。
    - 无限公理：存在无穷集合。

- 其他集合论公理系统：

  - 新基础论公理系统（New Foundations，简称NF）：
    - NF相对于ZFC取消了全集公理，并引入了等级（Hierarchy）的概念。
  - 基本集合论公理系统（Kripke-Platek集合论，简称KP）：
    - KP相对于ZFC取消了选择公理和幂集公理。

集合论的公理系统在数学的各个领域中都有重要的应用，包括数学分析、拓扑学、代数学等。

### 第5章：力迫论

力迫论是集合论中的一个重要分支，它提供了一种构建和分析模型的方法。在这一章中，我们将介绍力迫论的基本概念、定理和应用。

##### 5.1 力迫论的基本概念

力迫论的基本概念包括力、条件、模型等。

- 力（Forcing）

  力是集合论中的一种部分函数，它将势集（ground model）中的元素映射到一个集合的集合。力通常用F表示，其定义域是势集M，值域是集合的集合。

  ```markdown
  F: M → 2^M
  ```

  其中，2^M表示M的所有子集的集合。

- 条件（Condition）

  条件是势集M中的一个元素，它可以是任意的集合。条件通常用c表示。

- 模型（Model）

  模型是力迫论中的一个关键概念，它是一个满足一定条件的集合论模型。模型通常用M表示，它包含了势集M和一个力F。

  ```markdown
  M, F
  ```

  模型必须满足以下条件：

  - M是一个集合。
  - F是M的一个部分函数。
  - M中的所有元素都可以通过F映射到M的子集。

##### 5.2 力迫论的定理

力迫论包含了一系列重要的定理，这些定理揭示了力迫的性质和应用。

- 力迫定理1：单调性

  单调性是指如果一个条件c1满足某个性质P，则所有满足c1的条件c2也都满足性质P。

  ```markdown
  如果 c1 ⊆ c2，则对于任意的性质P，
  如果 c1 |= P，则 c2 |= P。
  ```

- 力迫定理2：连续性

  连续性是指力的变化不会导致模型中的性质发生剧烈变化。

  ```markdown
  如果 c1 和 c2 是相邻的条件，
  则 M, F, c1 和 M, F, c2 具有相似的性质。
  ```

- 力迫定理3：守恒性

  守恒性是指力迫过程中不会引入新的集合或关系。

  ```markdown
  如果 M, F, c 是一个模型，
  则在这个模型中可以证明的命题，
  在 M, F, c 的任何扩展模型中也可以证明。
  ```

##### 5.3 力迫论的应用

力迫论在数学的许多领域中都有广泛的应用，包括拓扑学、代数学、逻辑学等。

- 拓扑学中的应用

  在拓扑学中，力迫论用于证明某些拓扑空间的性质，如连通性、紧致性等。

- 代数学中的应用

- 逻辑学中的应用

  在逻辑学中，力迫论用于证明某些逻辑命题的成立或矛盾。

力迫论是集合论中的一个强大工具，它为数学家提供了构建和分析模型的新方法。在接下来的章节中，我们将继续探讨集合论的其他高级理论，包括饱和论和非荟萃理想论。

### 第6章：饱和论

饱和论是集合论中的一个重要分支，它研究集合的饱和性质。在这一章中，我们将介绍饱和论的基本概念、定理和应用。

##### 6.1 饱和论的基本概念

饱和论的基本概念包括饱和集合、饱和分解、饱和扩张等。

- 饱和集合（Saturated Set）

  饱和集合是指一个集合，其中不存在子集可以使得原集合中任意元素都与这个子集有交集。

  ```markdown
  如果 S 是一个饱和集合，
  则对于任意的 x ∈ S，不存在一个子集 T ⊆ S，使得 x ∈ T。
  ```

- 饱和分解（Saturated Decomposition）

  饱和分解是指将一个饱和集合分解为若干个互不交的饱和子集合的过程。

  ```markdown
  如果 S 是一个饱和集合，
  则可以找到一个划分 D = {S1, S2, ..., Sn}，
  使得每个 Si 都是饱和集合，并且 Si ∩ Sj = ∅（对于 i ≠ j）。
  ```

- 饱和扩张（Saturated Expansion）

  饱和扩张是指将一个饱和集合扩展为一个更大的饱和集合的过程。

  ```markdown
  如果 S 是一个饱和集合，
  则可以找到一个扩展 S'，
  使得 S' 是饱和集合，并且 S' 包含 S。
  ```

##### 6.2 饱和论的定理

饱和论包含了一系列重要的定理，这些定理揭示了饱和集合的性质和应用。

- 饱和定理1：饱和分解定理

  饱和分解定理指出，任何一个饱和集合都可以分解为若干个互不交的饱和子集合。

  ```markdown
  如果 S 是一个饱和集合，
  则可以找到一个划分 D = {S1, S2, ..., Sn}，
  使得每个 Si 都是饱和集合，并且 Si ∩ Sj = ∅（对于 i ≠ j）。
  ```

- 饱和定理2：饱和性质定理

  饱和性质定理指出，饱和集合具有一些重要的性质，如封闭性、交换性、结合性等。

  ```markdown
  如果 S 是一个饱和集合，
  则对于任意的运算 ∪、∩、-，S 都是封闭的，
  并且满足交换性和结合性。
  ```

- 饱和定理3：饱和扩张定理

  饱和扩张定理指出，任何一个饱和集合都可以扩展为一个更大的饱和集合。

  ```markdown
  如果 S 是一个饱和集合，
  则可以找到一个扩展 S'，
  使得 S' 是饱和集合，并且 S' 包含 S。
  ```

##### 6.3 饱和论的应用

饱和论在数学的许多领域都有广泛的应用，包括集合论、拓扑学、代数学等。

- 集合论中的应用

  在集合论中，饱和论用于研究集合的划分和映射问题。

- 拓扑学中的应用

  在拓扑学中，饱和论用于研究拓扑空间的性质，如连通性、紧致性等。

- 代数学中的应用

  在代数学中，饱和论用于研究代数结构的性质，如群、环、域的性质。

饱和论是集合论中的一个重要工具，它为数学家提供了研究集合性质的新方法。在接下来的章节中，我们将继续探讨集合论的其他高级理论，包括非荟萃理想论。

### 第7章：非荟萃理想论

非荟萃理想论是集合论中的一个重要分支，它研究集合的非荟萃理想性质。在这一章中，我们将介绍非荟萃理想论的基本概念、性质和应用。

##### 7.1 非荟萃理想论的基本概念

非荟萃理想论的基本概念包括非荟萃理想、非荟萃分解、非荟萃扩张等。

- 非荟萃理想（Non-Separated Ideal）

  非荟萃理想是指在一个集合中，不存在一个子集可以使得原集合中任意元素都与这个子集有交集。

  ```markdown
  如果 I 是一个非荟萃理想，
  则对于任意的 x ∈ I，不存在一个子集 T ⊆ I，使得 x ∈ T。
  ```

- 非荟萃分解（Non-Separated Decomposition）

  非荟萃分解是指将一个非荟萃理想分解为若干个互不交的非荟萃子理想的过程。

  ```markdown
  如果 I 是一个非荟萃理想，
  则可以找到一个划分 D = {I1, I2, ..., In}，
  使得每个 Ii 都是非荟萃理想，并且 Ii ∩ Ij = ∅（对于 i ≠ j）。
  ```

- 非荟萃扩张（Non-Separated Expansion）

  非荟萃扩张是指将一个非荟萃理想扩展为一个更大的非荟萃理想的过程。

  ```markdown
  如果 I 是一个非荟萃理想，
  则可以找到一个扩展 I'，
  使得 I' 是非荟萃理想，并且 I' 包含 I。
  ```

##### 7.2 非荟萃理想的性质

非荟萃理想具有一些重要的性质，如封闭性、交换性、结合性等。

- 封闭性

  非荟萃理想在添加新的元素或关系时，仍然保持非荟萃性。

  ```markdown
  如果 I 是一个非荟萃理想，
  则对于任意的 x ∈ I，任意的新元素 y，
  如果 y 与 x 没有交集，则 y ∈ I。
  ```

- 交换性

  非荟萃理想在添加新的元素或关系时，不改变其交换性。

  ```markdown
  如果 I 是一个非荟萃理想，
  则对于任意的 x, y ∈ I，
  如果 x 与 y 没有交集，则 y 与 x 没有交集。
  ```

- 结合性

  非荟萃理想在添加新的元素或关系时，不改变其结合性。

  ```markdown
  如果 I 是一个非荟萃理想，
  则对于任意的 x, y, z ∈ I，
  如果 x 与 y 没有交集，y 与 z 没有交集，
  则 x 与 z 没有交集。
  ```

非荟萃理想论在数学的许多领域都有广泛的应用，包括集合论、拓扑学、代数学等。

### 第8章：集合论在数学其他领域中的应用

集合论是现代数学的基础，它的概念和原理广泛应用于数学的各个领域。在这一章中，我们将探讨集合论在数学其他领域中的应用，包括拓扑学、代数学和逻辑学。

##### 8.1 集合论在拓扑学中的应用

拓扑学是研究空间性质和结构的数学分支，集合论在拓扑学中起着至关重要的作用。

- 拓扑空间的定义

  拓扑空间是由集合和集合上的关系构成的。一个拓扑空间由一个集合X和一组开集构成，开集满足以下条件：

  - 空集和全集是开集。
  - 开集的任意并集是开集。
  - 开集的有限交集是开集。

- 拓扑空间的性质

  拓扑空间具有一些重要的性质，如连通性、紧致性、分离性等。

  - 连通性

    一个拓扑空间是连通的，如果任意两点之间存在一条路径。

  - 紧致性

    一个拓扑空间是紧致的，如果任意开覆盖都存在一个有限子覆盖。

  - 分离性

    一个拓扑空间是分离的，如果对于任意两点x和y，存在开集U和V，使得x ∈ U，y ∈ V，且U ∩ V = ∅。

- 拓扑空间的运算

  拓扑空间支持并集、交集、补集等运算。

  ```markdown
  - 并集：X ∪ Y = {x ∈ X 或 x ∈ Y}
  - 交集：X ∩ Y = {x ∈ X 且 x ∈ Y}
  - 补集：X' = {x ∈ X 的补集}
  ```

##### 8.2 集合论在代数学中的应用

代数学是研究运算和结构的数学分支，集合论在代数学中也有着广泛的应用。

- 群、环、域的定义

  群、环、域是代数学中的基本结构。

  - 群

    群是一个集合G和一个二元运算∗，满足以下性质：

    - 封闭性：对于任意的a, b ∈ G，a ∗ b ∈ G。
    - 结合律：(a ∗ b) ∗ c = a ∗ (b ∗ c)。
    - 单位元：存在一个元素e ∈ G，使得对于任意的a ∈ G，a ∗ e = e ∗ a = a。
    -逆元：对于任意的a ∈ G，存在一个元素a' ∈ G，使得a ∗ a' = a' ∗ a = e。

  - 环

    环是一个集合R和一个二元运算+以及一个一元运算-，满足以下性质：

    - 封闭性：对于任意的a, b ∈ R，a + b ∈ R。
    - 结合律：(a + b) + c = a + (b + c)。
    - 分配律：(a + b) ∗ c = a ∗ c + b ∗ c。
    - 结合律：(a ∗ b) + c = a + (b ∗ c)。

  - 域

    域是一个环，其中除了零和单位元之外的所有元素都有乘法逆元。

- 群、环、域的性质

  群、环、域具有一些重要的性质，如交换性、结合性、分配性等。

  - 交换性

    对于群、环、域中的运算，如果运算满足交换律，即a ∗ b = b ∗ a，则称为交换性。

  - 结合性

    对于群、环、域中的运算，如果运算满足结合律，即(a ∗ b) ∗ c = a ∗ (b ∗ c)，则称为结合性。

  - 分配性

    对于群、环、域中的运算，如果运算满足分配律，即a ∗ (b + c) = a ∗ b + a ∗ c，则称为分配性。

- 群、环、域的运算

  群、环、域支持加法、乘法、逆元等运算。

  ```markdown
  - 加法：a + b
  - 乘法：a ∗ b
  - 逆元：a^{-1}
  ```

##### 8.3 集合论在逻辑学中的应用

逻辑学是研究推理和证明的数学分支，集合论在逻辑学中也有着广泛的应用。

- 命题逻辑的定义

  命题逻辑是研究命题之间的逻辑关系和推理的数学分支。

  - 命题

    命题是一个陈述句，它可以是真的或假的，但不能既真又假。

  - 命题联结词

    命题联结词用来连接命题，形成复合命题。

    - 合取（∧）

      两个命题A和B的合取是一个命题C，表示为A ∧ B，当且仅当A和B都为真时，C才为真。

    - 析取（∨）

      两个命题A和B的析取是一个命题C，表示为A ∨ B，当且仅当A或B至少有一个为真时，C才为真。

    - 蕴含（→）

      两个命题A和B的蕴含是一个命题C，表示为A → B，当且仅当A为真且B为假时，C才为假。

    - 否定（¬）

      一个命题A的否定是一个命题¬A，表示为¬A，当且仅当A为假时，¬A才为真。

- 命题逻辑的性质

  命题逻辑具有一些重要的性质，如交换性、结合性、分配性等。

  - 交换性

    对于命题逻辑中的联结词，如果运算满足交换律，即A ∧ B = B ∧ A，A ∨ B = B ∨ A，A → B = B → A，则称为交换性。

  - 结合性

    对于命题逻辑中的联结词，如果运算满足结合律，即(A ∧ B) ∧ C = A ∧ (B ∧ C)，(A ∨ B) ∨ C = A ∨ (B ∨ C)，(A → B) → C = A → (B → C)，则称为结合性。

  - 分配性

    对于命题逻辑中的联结词，如果运算满足分配律，即A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)，A ∨ (B ∧ C) = (A ∨ B) ∧ (A ∨ C)，则称为分配性。

- 命题逻辑的运算

  命题逻辑支持命题联结词的运算。

  ```markdown
  - 合取：A ∧ B
  - 析取：A ∨ B
  - 蕴含：A → B
  - 否定：¬A
  ```

### 附录A：集合论常用符号表

集合论中常用的一些符号和它们的含义如下：

- 集合：

  - A：表示一个集合。
  - {x | P(x)}：表示由满足条件P(x)的元素x组成的集合。

- 元素：

  - x：表示集合A中的一个元素。
  - ∈：表示元素x属于集合A。
  - ∉：表示元素x不属于集合A。

- 运算：

  - ∪：表示并集，A ∪ B表示集合A和集合B的并集。
  - ∩：表示交集，A ∩ B表示集合A和集合B的交集。
  - -：表示差集，A - B表示集合A中不属于集合B的元素组成的集合。
  - ∪'：表示补集，A'表示集合A的补集。

- 映射：

  - f：表示映射，f: A → B表示从集合A到集合B的映射。
  - |f|：表示映射f的像，|f|表示映射f映射到集合B的元素组成的集合。

- 基数：

  - |A|：表示集合A的基数，即集合A中元素的个数。
  - A ≈ B：表示集合A和集合B有相同的基数。

- 其他：

  - ω：表示自然数集合的基数。
  - Ω：表示实数集合的基数。
