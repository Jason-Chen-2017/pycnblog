#### 2.2 序列比对算法

**算法原理讲解**：

序列比对是生物计算中最基础的算法之一，用于比较两个或多个序列，找出它们之间的相似性和差异性。常见的序列比对算法包括局部比对算法（如BLAST）和全局比对算法（如Needleman-Wunsch算法）。

**mermaid流程图**：

```mermaid

  A[输入序列] --> B[预处理]
  B --> C[初始化得分矩阵]
  C --> D[计算得分矩阵]
  D --> E[找出最佳比对路径]
  E --> F[输出比对结果]
```

**Python源代码示例**：

```python
def NeedlemanWunsch(seq1, seq2):
    # 初始化得分矩阵
    score_matrix = [[0 for _ in range(len(seq2) + 1)] for _ in range(len(seq1) + 1)]

    # 计算得分矩阵
    for i in range(len(seq1)):
        for j in range(len(seq2)):
            match = score_matrix[i - 1][j - 1] + 1 if seq1[i] == seq2[j] else 0
            mismatch = score_matrix[i - 1][j - 1] - 1
            delete = score_matrix[i - 1][j] - 1
            score_matrix[i][j] = max(match, mismatch, delete)

    # 找出最佳比对路径
    path = []
    i, j = len(seq1), len(seq2)
    while i > 0 and j > 0:
        score = score_matrix[i][j]
        if score == score_matrix[i - 1][j - 1] + 1:
            path.append((seq1[i - 1], seq2[j - 1]))
            i -= 1
            j -= 1
        elif score == score_matrix[i - 1][j - 1] - 1:
            path.append(('-'))
            i -= 1
            j -= 1
        else:
            if score == score_matrix[i - 1][j] - 1:
                path.append('-')
                i -= 1
            else:
                path.append('|')
                j -= 1

    # 输出比对结果
    result = ''.join(seq1[i::-1] + ''.join(path[::-1]))
    return result
```

**数学模型和公式**：

在序列比对中，常用的数学模型包括动态规划模型。其基本思想是通过构建一个得分矩阵，逐步计算序列之间的相似性得分，并找到最佳比对路径。

$$
\text{score}(i, j) = \begin{cases}
\text{match} & \text{if } a_i = b_j \\
\text{mismatch} & \text{if } a_i \neq b_j \\
\text{delete} & \text{if } a_i \text{ is deleted} \\
\text{insert} & \text{if } b_j \text{ is inserted}
\end{cases}
$$

def OverlapLayoutConsensus(sequences):
    # 构建重叠群
    overlaps = []
    for i in range(len(sequences)):
        for j in range(i + 1, len(sequences)):
            overlap = FindOverlap(sequences[i], sequences[j])
            if overlap:
                overlaps.append((i, j, overlap))

    # 排序重叠群
    overlaps.sort(key=lambda x: len(x[2]), reverse=True)

    # 构建路径图
    path_graph = {}
    for i, j, _ in overlaps:
        if i not in path_graph:
            path_graph[i] = set()
        if j not in path_graph:
            path_graph[j] = set()
        path_graph[i].add(j)
        path_graph[j].add(i)

    # 路径图压缩
    compressed_graph = CompressGraph(path_graph)

    # 输出组装结果
    result = AssembleSequences(compressed_graph)
    return result

#### 4.1 序列比对中的数学模型

**核心概念**：序列比对是基因组学分析中的基础步骤，用于比较两个或多个序列，找出它们之间的相似性和差异性。常用的数学模型包括动态规划模型和评分系统。

**数学模型和公式**：

序列比对中的动态规划模型基于得分矩阵，通过递归计算最优路径，找出最佳比对结果。其基本思想是：

$$
\text{score}(i, j) = \text{match} \times \text{score}_{\text{match}} + \text{mismatch} \times \text{score}_{\text{mismatch}} + \text{gap} \times \text{score}_{\text{gap}}
$$

其中，$i$ 和 $j$ 分别表示两个序列的位置，$\text{match}$ 和 $\text{mismatch}$ 分别表示匹配和错配得分，$\text{gap}$ 表示间隙得分。

**实际应用实例**：

假设我们有两个序列 $A = AGCTTAC$ 和 $B = AACGGT$，使用Needleman-Wunsch算法进行比对，得分为：

$$
\text{score}(A, B) = 3 \times 1 + 2 \times -1 + 1 \times 0 = 1
$$

最佳比对路径为 $A = _AGCTTAC_G$ 和 $B = AACGGT$，其中下划线和横线表示间隙。
