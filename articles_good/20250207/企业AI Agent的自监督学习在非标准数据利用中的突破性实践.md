# 第2章: 自监督学习的核心原理

## 2.1 自监督学习的核心概念

### 2.1.1 对比学习  
对比学习是一种自监督学习方法，通过最大化正样本对的相似性，同时最小化负样本对的相似性来学习特征表示。其核心思想是通过对比损失函数优化模型。

公式如下：  
$$ L = \frac{1}{N}\sum_{i=1}^{N} \text{contrastive}(x_i, y_i) $$  

其中，$x_i$ 表示输入数据，$y_i$ 表示其对应的标签。

### 2.1.2 知识蒸馏  
知识蒸馏是一种通过教师模型指导学生模型学习知识的方法。在自监督学习中，教师模型通常通过对比学习生成伪标签，学生模型通过这些伪标签进行学习。

### 2.1.3 生成对抗网络  
生成对抗网络（GAN）是一种通过生成器和判别器的对抗过程进行学习的方法。在自监督学习中，生成器可以生成数据，判别器可以区分真实数据和生成数据，从而帮助模型学习数据的分布。

---

## 2.2 自监督学习的数学模型

### 2.2.1 对比学习的损失函数  
对比学习的损失函数通常包括正样本对和负样本对的相似性计算。  
- 正样本对的相似性：$s_{pos} = \frac{e^{z_i^T z_j}}{e^{z_i^T z_j} + e^{z_i^T z_k}}$  
- 负样本对的相似性：$s_{neg} = \frac{e^{z_i^T z_k}}{e^{z_i^T z_j} + e^{z_i^T z_k}}$  

损失函数：  
$$ L = -\log\left(\frac{s_{pos}}{s_{neg}}\right) $$  

### 2.2.2 生成对抗网络的损失函数  
生成器的损失函数：  
$$ L_G = \mathbb{E}_{z \sim p_z}[\log D(G(z))] $$  

判别器的损失函数：  
$$ L_D = -\mathbb{E}_{x \sim p_x}[\log D(x)] - \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))] $$

### 4.3.4 对比学习损失函数  
```python
def contrastive_loss(x, y, batch_size):
    # 正样本对的相似性计算
    positives = x*y
    # 负样本对的相似性计算
    negatives = (1 - x*y).sum() / (batch_size - 1)
    # 损失计算
    loss = -torch.mean(torch.log(positives + 1e-8) - torch.log(negatives + 1e-8))
    return loss
```

```python
def train(model, optimizer, loss_fn, data_loader, epochs):
    for epoch in range(epochs):
        for batch in data_loader:
            x, y = batch['x'], batch['y']
            optimizer.zero_grad()
            embeddings = model(x)
            loss = loss_fn(embeddings, y, batch_size=len(batch))
            loss.backward()
            optimizer.step()
    return model
```

```python
def train(model, optimizer, loss_fn, data_loader, epochs):
    for epoch in range(epochs):
        for batch in data_loader:
            x, y = batch['x'], batch['y']
            optimizer.zero_grad()
            embeddings = model(x)
            loss = loss_fn(embeddings, y, batch_size=len(batch))
            loss.backward()
            optimizer.step()
    return model
```
