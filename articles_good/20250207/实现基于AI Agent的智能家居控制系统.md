#### 1.1.2 智能家居的定义与特征
智能家居是指通过物联网技术将家中的设备连接到一起，通过中央控制平台实现设备的智能化管理和联动控制。其主要特征包括：
- **智能化**：设备能够自主感知环境并做出决策。
- **互联性**：设备之间能够通过网络进行通信和协作。

class AI_Agent:

        self.actuators = []
        self.rules = {}

    def add_sensor(self, sensor):
        self.sensors.append(sensor)

    def add_actuator(self, actuator):
        self.actuators.append(actuator)

    def set_rule(self, condition, action):
        self.rules[condition] = action

    def process(self, input):
        for condition, action in self.rules.items():
            if condition(input):
                action()
