## 1.2 因果推理的基本概念

### 1.2.1 因果关系的定义
因果关系是指一个事件（原因）导致另一个事件（结果）发生的必然联系。在商业决策中，因果推理用于识别哪些变量是结果的直接驱动因素。

### 1.2.2 因果关系与相关关系的区别
相关关系描述两个变量之间的关联程度，而因果关系则明确一个变量是否是另一个变量变化的原因。

### 1.2.3 因果推理在商业决策中的作用
因果推理能够帮助企业在复杂的市场环境中识别关键驱动因素，优化资源配置，提高决策的准确性和效果。

# 第2章 因果推理的核心理论与方法

## 2.1 因果关系的数学模型

### 2.1.1 结构因果模型
结构因果模型（SCM）通过因果图描述变量之间的因果关系。例如，因果图中的箭头表示因果关系。

**示例**：因果图表示客户满意度（C）受产品质量（P）和价格（P）的影响。

```mermaid
graph LR
    P --> C
    Q --> C
```

### 2.1.2 潜在结果框架
潜在结果框架通过假设每个变量的可能取值，计算因果效应。例如，计算在不同价格下的客户购买概率。

### 2.1.3 铃声模型
铃声模型（Rubin causal model）通过反事实推理估计因果效应。例如，计算如果价格降低10%，销量会增加多少。

---

## 2.2 因果推理的基本算法

### 2.2.1 反事实推理
反事实推理通过假设相反的情况，估计因果效应。例如，计算如果客户看到广告，他们的购买概率会增加多少。

**代码示例**：
```python
import dowhy

# 构建因果图
graph = dowhy.CausalGraph()
graph.add_edges([("A", "Y"), ("B", "Y")])

# 估计因果效应
estimator = dowhy.do_why.DOWhy.doWhy("Y", ["A", "B"], graph)
effect = estimator.estimate_effect()
print("因果效应:", effect)
```

### 2.2.2 倾向评分法
倾向评分法通过匹配样本，减少混杂变量的影响。例如，评估广告对销售额的影响。

### 2.2.3 多阶段回归法
多阶段回归法通过分阶段建模，估计因果效应。例如，首先建模广告点击率，再建模购买概率。

---

## 2.3 因果推理的验证与评估

### 2.3.1 因果效应的估计方法
1. **平均处理效应（ATE）**：整体样本的平均因果效应。
2. **子群体处理效应（SUTVA）**：特定子群体的因果效应。

### 2.3.2 因果推理的验证指标
1. **平衡性检查**：验证处理组和对照组的混杂变量是否均衡。
2. **稳健性检验**：通过不同的算法或数据集验证结果的稳健性。
