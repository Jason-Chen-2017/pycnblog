### 1.1 罗素类型论的基本概念

罗素类型论是由英国哲学家、数学家和逻辑学家贝特兰·罗素（Bertrand Russell）在20世纪初提出的一种逻辑和数学理论。类型论的核心思想是通过对对象进行分类，以避免逻辑和数学中的某些悖论，特别是集合论中的悖论。类型论的基本概念包括类型、类型层级、类型判断等。

#### 概念说明

- **类型（Type）**：类型是对象的一种分类方式，它定义了对象的类别。在类型论中，对象只能属于某个特定的类型。
- **类型层级（Type Hierarchy）**：类型层级是指不同类型之间的层次关系。通常，类型之间存在包含关系，如基本类型包含复合类型，复合类型包含用户定义类型。
- **类型判断（Type Judgment）**：类型判断是指对对象所属类型的判断。类型判断的目的是确保对象在逻辑和数学操作中的正确性。

#### 关键术语对比

| 术语 | 说明 |
| ---- | ---- |
| 基本类型（Primitive Type） | 最基本的数据类型，如整数、字符串等。 |
| 复合类型（Composite Type） | 由基本类型组合而成的类型，如数组、结构体等。 |
| 用户定义类型（User-Defined Type） | 用户自定义的类型，如枚举类型、类等。 |
