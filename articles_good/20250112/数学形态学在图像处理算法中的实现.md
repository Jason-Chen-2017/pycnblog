```python
    return cv2.morphologyEx(image, cv2.MORPH_RE Reconstruction, kernel)

# 示例
image = cv2.imread('image.jpg', cv2.IMREAD_GRAYSCALE)
kernel = np.ones((3, 3), np.uint8)

dilated = dilate(image, kernel)
eroded = erode(image, kernel)
opened = opening(image, kernel)
closed = closing(image, kernel)
reconstructed = reconstruction(image, kernel)

cv2.imshow('Original', image)
cv2.imshow('Dilated', dilated)
cv2.imshow('Eroded', eroded)
cv2.imshow('Opened', opened)
cv2.imshow('Closed', closed)
cv2.imshow('Reconstructed', reconstructed)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

**算法原理**

- **膨胀**：将图像中的目标区域向外扩展，增强图像中的目标特征。
- **腐蚀**：将图像中的目标区域向内收缩，减弱图像中的目标特征。
- **开运算**：先腐蚀后膨胀，去除细小结构，保留较大的目标。
- **闭运算**：先膨胀后腐蚀，填充小孔洞，连接分离的目标。
- **形态学重建**：通过开运算和闭运算的组合，恢复图像的原始形态。

**具体实现**

- **膨胀操作**：使用`cv2.dilate`函数实现。
- **腐蚀操作**：使用`cv2.erode`函数实现。
- **开运算**：使用`cv2.morphologyEx`函数实现，参数为`cv2.MORPH_OPEN`。
- **闭运算**：使用`cv2.morphologyEx`函数实现，参数为`cv2.MORPH_CLOSE`。
- **形态学重建**：使用`cv2.morphologyEx`函数实现，参数为`cv2.MORPH_RE Reconstruction`。
