### 第4章：数学模型和数学公式

#### 4.1 情感需求的数学模型

情感需求可以采用概念化模型和量化模型进行描述。

- **概念化模型**：

$$
\text{情感需求} = (\text{安全感}, \text{归属感}, \text{满足感})
$$

- **量化模型**：

$$
\text{情感需求得分} = w_1 \cdot \text{安全感} + w_2 \cdot \text{归属感} + w_3 \cdot \text{满足感}
$$

其中，$w_1, w_2, w_3$ 分别是安全感、归属感、满足感的权重。

#### 4.2 城市规划优化的数学模型

城市规划优化的数学模型包括目标函数和约束条件。

- **目标函数**：

$$
\max \sum_{i=1}^{n} u_i \cdot x_i
$$

其中，$u_i$ 是第 $i$ 个规划指标的用户满意度，$x_i$ 是第 $i$ 个规划指标的实现程度。

- **约束条件**：

$$
\begin{cases}
\sum_{i=1}^{n} x_i \leq C \\
\sum_{i=1}^{n} y_i \cdot x_i \leq D \\
x_i \geq 0, i=1,2,...,n
\end{cases}
$$

其中，$C$ 是总的规划资源，$D$ 是环境容量限制，$y_i$ 是第 $i$ 个规划指标的权重。

from sklearn.linear_model import LogisticRegression

# 加载情感数据
data = pd.read_csv('sentiment_data.csv')

# 文本预处理
def preprocess_text(text):
    # 去停用词、分词等处理
    return ' '.join([word for word in text.split() if word not in stop_words])

data['text'] = data['text'].apply(preprocess_text)

# 特征提取
vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(data['text'])

# 情感分类
model = LogisticRegression()
model.fit(X, data['label'])

# 情感分析
def analyze_sentiment(text):
    text = preprocess_text(text)
    features = vectorizer.transform([text])
    prediction = model.predict(features)
    return '正面' if prediction == 1 else '负面'

# 测试
print(analyze_sentiment('我喜欢这个城市'))
