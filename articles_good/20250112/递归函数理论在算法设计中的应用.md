### 第2章：核心概念与联系

#### 2.1 递归函数的定义

递归函数是一种直接或间接调用自身的函数。递归可以分为两种类型：直接递归和间接递归。

直接递归示例：
```python
def direct_recursion(n):
    if n == 0:
        return 1
    else:
        return n * direct_recursion(n - 1)
```

间接递归示例：
```python
def funcA(n):
    if n == 0:
        return 1
    else:
        return n * funcB(n - 1)

def funcB(n):
    if n == 0:
        return 1
    else:
        return n * funcA(n - 1)
```

#### 2.2 递归函数的特点

1. **自调用**：递归函数调用自身来解决问题。
2. **递归终止条件**：递归必须有一个明确的终止条件，否则会导致无限递归。
3. **层次结构**：递归函数通过层次结构来分解问题，每一层都处理问题的一部分。

#### 2.3 递归函数与迭代函数的比较

| 特性       | 递归函数                             | 迭代函数                            |
|------------|------------------------------------|-----------------------------------|
| 结构       | 层次结构，自调用                   | 循环结构，重复调用                 |
| 调用栈     | 使用大量栈空间                     | 空间效率较高                       |
| 表达能力   | 更易表达复杂问题                   | 更易优化和调试                     |

### 第4章：数学模型和数学公式

#### 4.1 算法原理的数学模型

斐波那契数列的递归关系可以用以下数学公式表示：

$$ F(n) = F(n-1) + F(n-2) $$

其中，$F(0) = 0$，$F(1) = 1$。

#### 4.2 算法原理的数学公式

递归函数的时间复杂度通常用大O符号表示。对于斐波那契数列，其时间复杂度为：

$$ T(n) = O(2^n) $$

#### 4.3 公式讲解与举例

斐波那契数列的递归公式和其时间复杂度说明了递归函数在计算上的效率较低。然而，通过优化递归，例如使用动态规划，可以显著提高效率。
