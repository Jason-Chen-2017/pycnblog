### 算法Python源代码

```python
def evaluate_craftsmanship(craft):
    if craft.has_value('传承价值'):
        return '传承成功'
    else:
        return '评估改进'
```

### 算法原理数学模型和公式

$$
传承成功 = \frac{传承价值}{总价值}
$$

### 详细讲解与举例说明

假设一个手工艺项目，其传承价值为80%，总价值为100%，根据上述公式计算得出传承成功率为80%。
