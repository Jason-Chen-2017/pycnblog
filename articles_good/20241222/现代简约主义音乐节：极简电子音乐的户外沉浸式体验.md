# 创建一个5秒的Sine波合成器声音，频率为440Hz（A音）
sine_wave = Sine(440).to_audio_segment(duration=5000)

# 将合成器声音保存为MP3文件

# 创建一个8秒的Square波合成器声音，频率为261.63Hz（C#音）

在这个示例中，我们使用了`Sine`生成器创建两个不同类型的合成器声音：一个Sine波和一个Square波。Sine波是一种正弦波形，而Square波则是一种方波波形，这两种波形都是极简电子音乐中常见的元素。
