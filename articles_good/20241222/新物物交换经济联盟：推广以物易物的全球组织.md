### 第11章：Python源代码详细阐述

以下是一段Python源代码，用于实现物物交换的智能合约：

```python
from web3 import Web3
from solc import compile_source

# 编译智能合约代码
contract_source = '''
pragma solidity ^0.8.0;

contract Exchange {
    struct Transaction {
        address buyer;
        address seller;
        uint256 itemId;
        bool completed;
    }

    mapping(uint256 => Transaction) public transactions;

    function createTransaction(uint256 itemId, address seller) public {
        transactions[itemId] = Transaction(msg.sender, seller, itemId, false);
    }

    function confirmTransaction(uint256 itemId) public {
        require(transactions[itemId].buyer == msg.sender, "Not the buyer");
        transactions[itemId].completed = true;
    }
}
'''
compiled_code = compile_source(contract_source)
contract bytecode = compiled_code['contracts'][':Exchange'].bytecode
contract_abi = compiled_code['contracts'][':Exchange'].interface

# 部署智能合约
w3 = Web3(Web3.HTTPProvider('http://127.0.0.1:8545'))
contract = w3.eth.contract(abi=contract_abi, bytecode=bytecode)
transaction = contract.constructor().transact()
tx_hash = w3.eth.getTransactionHash(transaction)
print("Contract deployed at:", w3.eth.getTransactionReceipt(tx_hash).contractAddress)
```

这段代码首先编译了智能合约代码，然后部署了智能合约。智能合约包含两个函数：`createTransaction` 和 `confirmTransaction`。`createTransaction` 用于创建交易，`confirmTransaction` 用于确认交易完成。
