        if user_emotion == "happy":
            return "很高兴看到您快乐！有什么我可以帮助您的吗？"

        elif user_emotion == "angry":
            return "我理解您可能很生气，我们可以一起找到解决问题的方法。"
        elif user_emotion == "surprised":
            return "怎么了？有什么让您感到惊讶的事情吗？"

禅与计算机程序设计艺术（Zen And The Art of Computer Programming）是作者Donald E. Knuth的经典著作，深入探讨了计算机程序设计中的哲学和艺术。Knuth是计算机科学领域的杰出学者，被誉为“计算机科学之父”之一，其著作对计算机科学教育和研究产生了深远影响。

本文作者结合了AI天才研究院和Knuth的丰富经验和深厚知识，从多个角度探讨了情感机器人伦理的道德边界，为读者提供了一场关于人工智能伦理的深刻思考。
