## 第二部分：核心概念与联系

### 2.1 无监督学习

无监督学习（Unsupervised Learning）是一种机器学习方法，其训练数据不包含标签信息，即训练样本没有对应的正确输出。无监督学习的目标是发现数据中的隐含结构或规律，如聚类、降维、异常检测等。

#### 无监督学习的核心特征：

1. **无标签数据**：无监督学习的核心在于处理无标签数据，这意味着算法需要从数据本身中提取特征。
2. **自动发现规律**：通过算法，无监督学习能够自动发现数据中的潜在规律和结构。
3. **广泛应用**：无监督学习在图像识别、自然语言处理、推荐系统等领域有广泛应用。

### 2.2 零样本学习

零样本学习（Zero-Shot Learning，ZSL）是一种特殊类型的学习任务，其目标是预测一个未知类别的标签，而训练数据中并不包含该类别的样本。ZSL通过预先学习到的知识，如类别的语义信息，来实现对未知类别的预测。

#### 零样本学习的核心原理：

1. **语义表示**：通过将类别表示为语义向量，ZSL能够在没有目标类别数据的情况下进行分类。
2. **知识迁移**：ZSL利用先验知识（如WordNet）来建立类别之间的关系，从而实现跨类别的推理。

### 2.3 零样本转换

零样本转换（Zero-Shot Transfer，ZST）是一种基于迁移学习的方法，其核心思想是将已学习的知识迁移到新的任务中。ZST通过在源域和目标域之间建立一种映射关系，将源域的知识应用于目标域，从而实现零样本学习。

#### 零样本转换的核心步骤：

1. **特征学习**：在源域数据上学习特征表示。
2. **跨域映射**：建立源域和目标域之间的映射关系。
3. **任务迁移**：将源域的特征表示应用于目标域的任务。

### 2.4 无监督学习与零样本学习、零样本转换的联系

无监督学习、零样本学习和零样本转换之间有着密切的联系。无监督学习为ZSL和ZST提供了理论基础和方法指导，而ZSL和ZST则扩展了无监督学习的应用范围，使得无监督学习在处理未知类别或任务时更加高效。

| 零样本学习 | 无标签   | 预测未知类别的标签 | 利用先验知识进行跨类别推理 |

## 第三部分：主流无监督学习算法简介

### 3.1 K-means聚类

K-means聚类是一种常见的无监督学习方法，其目标是将数据集划分为K个簇，使得每个簇内的数据点之间的距离最小，簇与簇之间的距离最大。

#### 算法流程：

1. **初始化**：随机选择K个质心。
2. **聚类分配**：将每个数据点分配到最近的质心所在的簇。
3. **质心更新**：计算每个簇的质心。
4. **收敛判断**：直到质心不再变化或达到预设的迭代次数。

#### 代码示例：

```python
from sklearn.cluster import KMeans

# 假设X是数据集
kmeans = KMeans(n_clusters=K)
kmeans.fit(X)
labels = kmeans.predict(X)
```

### 3.2 主成分分析（PCA）

主成分分析（Principal Component Analysis，PCA）是一种常用的降维技术，其目标是通过线性变换将高维数据映射到低维空间，同时保留数据中的重要信息。

#### 算法流程：

1. **数据标准化**：对数据进行标准化处理。
2. **协方差矩阵计算**：计算数据的协方差矩阵。
3. **特征值分解**：对协方差矩阵进行特征值分解，得到主成分。
4. **数据降维**：将数据投影到主成分空间。

#### 代码示例：

```python
from sklearn.decomposition import PCA

# 假设X是数据集
pca = PCA(n_components=n_components)
pca.fit(X)
reduced_X = pca.transform(X)
```
