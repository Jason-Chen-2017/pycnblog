# 代码案例

下面我们将通过一个Python代码案例来展示分分合合的概念。这个例子模拟了两个人之间的分分合合过程，其中每个人的行为是根据随机事件来决定的。

```python
import random

class Person:
    def __init__(self, name):
        self.name = name
        self.status = "和好" if random.random() > 0.5 else "分手"

    def decide(self):
        if self.status == "和好":
            self.status = "分手" if random.random() > 0.5 else "和好"
            print(f"{self.name}决定分手。")
        else:
            self.status = "和好" if random.random() > 0.5 else "分手"
            print(f"{self.name}决定和好。")

    def __str__(self):
        return f"{self.name}当前状态：{self.status}"

# 创建两个人物实例
person1 = Person("小明")
person2 = Person("小红")

# 模拟分分合合的过程
for day in range(1, 11):
    print(f"第{day}天：")
    person1.decide()
    person2.decide()
    print(f"{person1}")
    print(f"{person2}")
    print()
```

这段代码定义了一个`Person`类，它有两个状态：“和好”和“分手”。每个对象在初始化时会随机选择一个状态。`decide`方法用来决定下一步的状态，这个决定也是随机的。我们模拟了10天的分分合合过程，每天两个人都会根据自己的状态做出新的决定。

运行这段代码，可以看到小明和小红的状态是如何随时间变化的。这个例子展示了分分合合的随机性和不确定性，同时也反映了现实生活中人际关系的变化。

```python
db.init_app(app)

@app.route('/')
def index():
    return render_template('index.html')

@app.route('/add_friend', methods=['POST'])
def add_friend():
    username = request.form['username']
    friend_username = request.form['friend_username']
    user = User.query.filter_by(username=username).first()
    friend = User.query.filter_by(username=friend_username).first()
    if user and friend:
        if Friendship.query.filter(Friendship.user1_id==user.id, Friendship.user2_id==friend.id).first() is None:
            friendship = Friendship(user1_id=user.id, user2_id=friend.id)
            db.session.add(friendship)
            db.session.commit()
            return redirect(url_for('index'))
        else:
            return "您们已经是好友了！"
    else:
        return "用户不存在！"

if __name__ == '__main__':
    app.run(debug=True)
```
