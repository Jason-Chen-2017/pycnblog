观察者模式：定义对象间的一种一对多的依赖关系，当一个对象的状态发生变化时，所有依赖于它的对象都会得到通知并自动更新。

```python
class Observer:
    def update(self, subject):
        pass

class Subject:
    def attach(self, observer):
        self._observers.append(observer)
    
    def detach(self, observer):
        self._observers.remove(observer)
    
    def notify(self):
        for observer in self._observers:
            observer.update(self)

class ConcreteObserver(Observer):
    def update(self, subject):
        print(f"Observer: {subject} state has changed.")

subject = Subject()
observer = ConcreteObserver()
subject.attach(observer)
subject.notify()
```

class FLServer:

        total_weights = {}
        for client in self.clients:
            client_weights = client.train()
            for key, value in client_weights.items():
                if key in total_weights:
                    total_weights[key] += value
                else:
