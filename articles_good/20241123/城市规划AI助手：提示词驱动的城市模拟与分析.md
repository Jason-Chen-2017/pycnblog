```python
                if agent.interacts_with(other_agent):
                    agent.interact(other_agent)

# 示例：两个代理的交互
def agent1.update_state(agent2):
    if agent2.is_friend():
        self.add_resource()

def agent2.update_state(agent1):
    if agent1.has_resource():
        self.request_resource()
```

## 5.4 数学模型与公式

在城市模拟与分析中，数学模型和公式是不可或缺的工具。以下是一些常见的数学模型和公式，以及它们的详细解释和举例说明。

### 5.4.1 指数平滑模型

指数平滑模型是一种常用的时间序列预测方法，用于分析城市系统的时间动态变化。

**公式**：
$$
S_t = \alpha X_t + (1 - \alpha) S_{t-1}
$$
其中，$S_t$表示第t期的平滑值，$X_t$表示第t期的实际值，$\alpha$表示平滑系数。

**解释**：
- 指数平滑模型通过对历史数据进行加权平均，生成当前时期的预测值。
- $\alpha$的取值范围在0到1之间，$\alpha$越大，对近期数据的依赖性越强。

**举例**：
假设某城市的人口数据如下表所示：

| 年份 | 人口（万人） |
| ---- | ---------- |
| 2020 | 100        |
| 2021 | 105        |
| 2022 | 110        |
| 2023 | 115        |

使用指数平滑模型，取$\alpha = 0.5$，计算2024年的人口预测值。

**计算过程**：
$$
S_2021 = 0.5 \times 105 + (1 - 0.5) \times 100 = 102.5
$$
$$
S_2022 = 0.5 \times 110 + (1 - 0.5) \times 102.5 = 104.375
$$
$$
S_2023 = 0.5 \times 115 + (1 - 0.5) \times 104.375 = 106.21875
$$
$$
S_2024 = 0.5 \times 115 + (1 - 0.5) \times 106.21875 = 107.609375
$$
预测2024年的人口为107.6万人。

### 5.4.2 回归模型

回归模型是一种用于分析两个或多个变量之间关系的数学模型，广泛应用于城市规划和分析中。

**公式**：
$$
Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + ... + \beta_nX_n
$$
其中，$Y$表示因变量，$X_1, X_2, ..., X_n$表示自变量，$\beta_0, \beta_1, \beta_2, ..., \beta_n$为回归系数。

**解释**：
- 回归模型通过拟合数据点，找到因变量和自变量之间的关系。
- 回归系数$\beta_1, \beta_2, ..., \beta_n$表示自变量对因变量的影响程度。

**举例**：
假设某城市的房价（$Y$）与收入（$X_1$）和面积（$X_2$）之间存在线性关系，数据如下表所示：

| 房价（万元） | 收入（万元） | 面积（平方米） |
| ---------- | ---------- | ---------- |
| 100       | 30         | 100        |
| 120       | 35         | 120        |
| 140       | 40         | 140        |
| 160       | 45         | 160        |

使用回归模型拟合数据，计算房价的预测值。

**计算过程**：
首先，计算平均值：
$$
\bar{Y} = \frac{100 + 120 + 140 + 160}{4} = 125
$$
$$
\bar{X_1} = \frac{30 + 35 + 40 + 45}{4} = 36.25
$$
$$
\bar{X_2} = \frac{100 + 120 + 140 + 160}{4} = 125
$$

然后，计算协方差和方差：
$$
cov(Y, X_1) = \frac{(100 - 125)(30 - 36.25) + (120 - 125)(35 - 36.25) + (140 - 125)(40 - 36.25) + (160 - 125)(45 - 36.25)}{4} = -187.5
$$
$$
cov(Y, X_2) = \frac{(100 - 125)(100 - 125) + (120 - 125)(120 - 125) + (140 - 125)(140 - 125) + (160 - 125)(160 - 125)}{4} = 18750
$$
$$
var(X_1) = \frac{(30 - 36.25)^2 + (35 - 36.25)^2 + (40 - 36.25)^2 + (45 - 36.25)^2}{4} = 14.0625
$$
$$
var(X_2) = \frac{(100 - 125)^2 + (120 - 125)^2 + (140 - 125)^2 + (160 - 125)^2}{4} = 6250
$$

最后，计算回归系数：
$$
\beta_1 = \frac{cov(Y, X_1)}{var(X_1)} = \frac{-187.5}{14.0625} = -13.3
$$
$$
\beta_2 = \frac{cov(Y, X_2)}{var(X_2)} = \frac{18750}{6250} = 3
$$

回归模型为：
$$
Y = -13.3X_1 + 3X_2
$$

预测当收入为40万元，面积为140平方米的房价：
$$
Y = -13.3 \times 40 + 3 \times 140 = 104
$$
预测房价为104万元。

### 5.4.3 神经网络模型

神经网络模型是一种基于多层神经网络的数学模型，用于模拟城市系统的复杂行为。

**公式**：
$$
a_{i}^{(l)} = \sigma \left( \sum_{j=1}^{n_{l}} w_{j,i}^{(l)} a_{j}^{(l-1)} + b_{i}^{(l)} \right)
$$
其中，$a_{i}^{(l)}$表示第$l$层的第$i$个节点的激活值，$\sigma$表示激活函数，$w_{j,i}^{(l)}$表示第$l$层的第$i$个节点到第$l-1$层的第$j$个节点的权重，$b_{i}^{(l)}$表示第$l$层的第$i$个节点的偏置。

**解释**：
- 神经网络模型通过多层神经元的连接和激活函数，对输入数据进行处理和转换，从而模拟城市系统的复杂行为。
- 激活函数$\sigma$用于引入非线性变换，使神经网络具有非线性能力。

**举例**：
假设有一个两层神经网络，输入层有2个神经元，隐藏层有3个神经元，输出层有1个神经元。激活函数为$\sigma(x) = \frac{1}{1 + e^{-x}}$。输入数据为$(x_1, x_2) = (2, 3)$。

**计算过程**：
计算隐藏层的激活值：
$$
a_{1}^{(2)} = \sigma(w_{11}^{(2)}x_1 + w_{12}^{(2)}x_2 + b_{1}^{(2)}) = \sigma(2w_{11}^{(2)} + 3w_{12}^{(2)} + b_{1}^{(2)})
$$
$$
a_{2}^{(2)} = \sigma(w_{21}^{(2)}x_1 + w_{22}^{(2)}x_2 + b_{2}^{(2)}) = \sigma(2w_{21}^{(2)} + 3w_{22}^{(2)} + b_{2}^{(2)})
$$
$$
a_{3}^{(2)} = \sigma(w_{31}^{(2)}x_1 + w_{32}^{(2)}x_2 + b_{3}^{(2)}) = \sigma(2w_{31}^{(2)} + 3w_{32}^{(2)} + b_{3}^{(2)})
$$

计算输出层的激活值：
$$
y = \sigma(w_{1}^{(3)}a_{1}^{(2)} + w_{2}^{(3)}a_{2}^{(2)} + w_{3}^{(3)}a_{3}^{(2)} + b_{1}^{(3)})
$$

通过训练数据集，可以优化网络的权重和偏置，使输出结果更接近真实值。
