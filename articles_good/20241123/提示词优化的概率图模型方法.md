### 概率图模型的基本概念

概率图模型（Probabilistic Graphical Models，PGM）是一种用于表示变量之间概率依赖关系的图形化方法。它由贝叶斯网络（Bayesian Networks，BN）和马尔可夫网络（Markov Networks，MN）两大类组成。贝叶斯网络通过有向无环图（DAG）表示变量之间的条件依赖关系，而马尔可夫网络则通过无向图表示变量之间的联合概率分布。

#### 贝叶斯网络

贝叶斯网络是一种基于概率的图形化模型，它由节点和边组成，每个节点代表一个随机变量，边表示变量之间的条件依赖关系。贝叶斯网络的概率分布可以通过条件概率表（CPT）来定义。给定一个贝叶斯网络，我们可以利用贝叶斯定理和概率推理算法（如变量消除法）计算任意变量的条件概率分布。

```python
# 贝叶斯网络的变量消除算法伪代码
def variable_elimination(bn, query_variable):
    # 初始化概率分布
    prob_distribution = initialize_prob_distribution(bn, query_variable)
    
    # 遍历网络中的所有变量
    for variable in bn.variables():
        if variable != query_variable:
            # 消除变量
            prob_distribution = eliminate_variable(prob_distribution, variable)
            
    return prob_distribution
```

#### 马尔可夫网络

马尔可夫网络是一种基于概率的无向图模型，它通过边表示变量之间的转移概率。马尔可夫网络的一个重要性质是马尔可夫性，即给定当前状态，过去状态与未来状态是相互独立的。马尔可夫网络的概率分布可以通过条件概率分布来定义。

```python
# 马尔可夫网络的概率分布计算伪代码
def markov_network_probability(mn, states):
    probability = 1.0
    for edge in mn.edges():
        probability *= mn.get_probability(edge, states[edge])
    return probability
```

基于启发式的方法通常依赖于人工经验和规则，通过分析关键词的重要性和相关性来优化提示词。这种方法简单易行，但效果有限，难以应对复杂的文本数据。
