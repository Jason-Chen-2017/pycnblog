**4.2 机器学习模型**

机器学习模型是AIGC在智慧城市规划中的核心技术，用于从数据中学习并提取知识。常见的机器学习模型包括：

**4.2.1 线性回归模型**

线性回归模型是一种常见的监督学习模型，通过拟合线性模型，预测连续值输出。线性回归模型的公式如下：

$$
\text{y} = \text{w}_1 \text{x}_1 + \text{w}_2 \text{x}_2 + \cdots + \text{w}_n \text{x}_n
$$

其中，$\text{y}$ 表示输出值，$\text{x}_i$ 表示输入特征，$\text{w}_i$ 表示权重。

**4.2.2 支持向量机模型**

支持向量机（SVM）是一种常见的监督学习模型，通过构建超平面，分类数据点。SVM的公式如下：

$$
\text{max} \ \frac{1}{2} \sum_{i=1}^{n} (\text{w}_i)^2
$$

$$
\text{s.t.} \ \text{y} (\text{w} \cdot \text{x} + \text{b}) \geq 1
$$

其中，$\text{w}$ 表示权重向量，$\text{b}$ 表示偏置，$\text{y}$ 表示标签。

**4.2.3 决策树模型**

决策树是一种常见的无监督学习模型，通过递归划分数据，构建分类或回归模型。决策树的公式如下：

$$
\text{split} (\text{data}, \text{attribute}) = \{ \text{left}, \text{right} \}
$$

$$
\text{left} = \{ \text{data} \ | \ \text{attribute} < \text{threshold} \}
$$

$$
\text{right} = \{ \text{data} \ | \ \text{attribute} \geq \text{threshold} \}
$$

其中，$\text{data}$ 表示数据集，$\text{attribute}$ 表示特征，$\text{threshold}$ 表示阈值。

```python
# 导入所需库
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras

# 数据预处理
def preprocess_data(data):
    # 数据清洗
    data = data.fillna(data.mean())
    # 数据标准化
    data = (data - data.mean()) / data.std()
    return data

# 模型训练
def train_model(data):
    # 划分训练集和测试集
    train_data, test_data = data[:900], data[900:]
    # 创建模型
    model = keras.Sequential([
        keras.layers.Dense(64, activation='relu', input_shape=(train_data.shape[1],)),
        keras.layers.Dense(64, activation='relu'),
        keras.layers.Dense(1)
    ])
    # 编译模型
    model.compile(optimizer='adam', loss='mse')
    # 训练模型
    model.fit(train_data, train_data, epochs=100, batch_size=32, validation_data=(test_data, test_data))
    return model

# 模型应用
def apply_model(model, data):
    # 预测结果
    predictions = model.predict(data)
    # 提取预测值
    predicted_values = predictions[:, 0]
    return predicted_values

# 测试
if __name__ == '__main__':
    # 加载数据
    data = pd.read_csv('data.csv')
    # 数据预处理
    processed_data = preprocess_data(data)
    # 训练模型
    model = train_model(processed_data)
    # 应用模型
    predicted_values = apply_model(model, processed_data)
    # 输出预测结果
    print(predicted_values)
```
