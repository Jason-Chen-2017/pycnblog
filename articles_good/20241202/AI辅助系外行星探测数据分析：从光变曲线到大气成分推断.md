#### 2.1 光变曲线的基本概念

光变曲线是描述系外行星在其母星前经过时，母星亮度随时间变化的数据记录。它是行星探测中最常用的数据类型之一，通过对光变曲线的分析，可以提取行星的轨道特征、大气成分等信息。

##### 光变曲线的定义

光变曲线（Light Curve）是指随时间记录的恒星亮度变化数据。在系外行星探测中，光变曲线是观测者从地球上接收到的恒星光线信号，当系外行星从其母星前方经过时，母星的亮度会发生变化。这种亮度变化反映了行星的轨道特性、大小、质量以及大气成分。

##### 光变曲线的主要类型

1. **多周期光变曲线**：这类光变曲线具有多个周期，每个周期对应一个行星绕母星一周的运动周期。
2. **单周期光变曲线**：只包含一个周期的光变曲线，通常用于初步探测或特定任务的观测。
3. **非周期性光变曲线**：这类曲线没有明显的周期性特征，可能受到行星轨道异常或观测条件的影响。

##### 光变曲线的观测方法

光变曲线的观测主要通过以下几种方式：

1. **径向速度法**：通过观测恒星光谱的红移和蓝移来确定行星轨道参数。
2. **视向速度法**：通过测量恒星相对于地球的视向速度变化来确定行星轨道。
3. **凌星法**：当行星从其母星前方经过时，母星的亮度会出现下降，通过观测这种亮度下降可以确定行星的轨道和大小。

##### 大气成分的定义

大气成分（Atmospheric Composition）是指构成行星大气的所有气体分子和微粒的总和。行星大气成分的组成和比例决定了行星的物理特性和环境条件，对于判断行星的宜居性具有重要意义。

#### 示例1：周期识别

以下代码示例使用傅里叶变换进行周期识别：

```python
import numpy as np
from scipy.fft import fft, fftshift

# 假设data是光变曲线数据
data = np.random.rand(1000)

# 傅里叶变换
fourier_transform = fft(data)
shifted_transform = fftshift(fourier_transform)

# 找到傅里叶变换中的峰值
peak = np.argmax(np.abs(shifted_transform[500:-500]))

# 计算周期
周期 = 1 / (peak * (1 / len(data)))
print(f"识别出的周期为：{周期}")
```

以下代码示例使用最小二乘法进行光谱拟合：

```python
import numpy as np
from scipy.optimize import curve_fit

# 定义拟合函数
def fit_function(x, a, b, c):
    return a * x**2 + b * x + c

# 假设x是波长，y是光谱强度
x = np.linspace(300, 1100, 1000)
y = fit_function(x, 1, 0, 0) + np.random.normal(0, 0.1, x.shape)

# 拟合参数
params, covariance = curve_fit(fit_function, x, y)

# 输出拟合结果
print(f"拟合参数：a={params[0]}, b={params[1]}, c={params[2]}")
```

```python
from sklearn.svm import SVC
from sklearn.model_selection import train_test_split
```
