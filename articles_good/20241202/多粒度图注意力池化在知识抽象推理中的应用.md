## 多粒度图注意力池化的数学模型与实现

### 1.1 多粒度图注意力池化的数学模型

多粒度图注意力池化是一种结合了图神经网络（GNN）和注意力机制的图表示学习技术。它的核心在于能够处理不同粒度的图数据，并通过注意力机制聚合信息，从而提取更高层次的特征表示。下面将介绍多粒度图注意力池化的数学模型。

#### 节点表示和边表示

在多粒度图注意力池化中，节点和边都可以表示为向量。设图\( G = (V, E) \)，其中\( V \)是节点集合，\( E \)是边集合。对于节点\( v_i \)，其特征表示为\( \mathbf{x}_i \in \mathbb{R}^d \)，对于边\( e_{ij} \)，其特征表示为\( \mathbf{e}_{ij} \in \mathbb{R}^d \)。

#### 自注意力（Self-Attention）

自注意力机制是一种常用的注意力机制，它可以对节点自身的特征进行加权平均。设\( \mathbf{W} \)为权重矩阵，则自注意力机制可以表示为：

$$
\text{Self-Attention}(\mathbf{x}_i) = \text{softmax}(\mathbf{W} \cdot \mathbf{x}_i)
$$

其中，\( \mathbf{W} \)是一个\( d \times d \)的矩阵，\( \text{softmax}(\cdot) \)函数将加权向量转换为概率分布。

#### 边注意力（Edge-Attention）

边注意力机制用于处理节点和边之间的关系。设\( \mathbf{W}_e \)为边权重矩阵，则边注意力机制可以表示为：

$$
\text{Edge-Attention}(\mathbf{x}_i, \mathbf{e}_{ij}) = \text{softmax}(\mathbf{W}_e \cdot (\mathbf{x}_i \cdot \mathbf{e}_{ij}))
$$

其中，\( \mathbf{W}_e \)是一个\( d \times d \)的矩阵，\( \mathbf{x}_i \cdot \mathbf{e}_{ij} \)表示节点特征和边特征的内积。

#### 多粒度注意力池化

多粒度注意力池化通过组合自注意力和边注意力，以不同粒度对节点特征进行加权平均，从而得到更高层次的抽象表示。设\( \mathbf{W}_s \)为多粒度权重矩阵，则多粒度注意力池化可以表示为：

$$
\mathbf{h}_i^{(l+1)} = \text{softmax}(\mathbf{W}_s \cdot (\text{Self-Attention}(\mathbf{x}_i) + \text{Edge-Attention}(\mathbf{x}_i, \mathbf{e}_{ij})))
$$

其中，\( \mathbf{h}_i^{(l+1)} \)为经过多粒度注意力池化后的节点特征，\( l \)为当前的图层级。

### 1.3 多粒度图注意力池化的应用示例

以下是一个简单的Python代码示例，展示了如何实现多粒度图注意力池化。在这个示例中，我们将使用PyTorch框架。

```python
import torch
import torch.nn as nn
import torch.optim as optim

# 定义自注意力模块
class SelfAttention(nn.Module):
    def __init__(self, d_model):
        super(SelfAttention, self).__init__()
        self.query_linear = nn.Linear(d_model, d_model)
        self.key_linear = nn.Linear(d_model, d_model)
        self.value_linear = nn.Linear(d_model, d_model)
        self.softmax = nn.Softmax(dim=1)

    def forward(self, x):
        query = self.query_linear(x)
        key = self.key_linear(x)
        value = self.value_linear(x)
        attention = self.softmax(torch.matmul(query, key.t()))
        output = torch.matmul(attention, value)
        return output

# 定义多粒度图注意力池化模块
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super(MultiHeadAttention, self).__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_size = d_model // num_heads
        self.self_attention = SelfAttention(d_model)
        self.linear = nn.Linear(d_model, d_model)

    def forward(self, x):
        batch_size = x.size(0)
        query = x.view(batch_size, -1, self.num_heads, self.head_size).transpose(1, 2)
        key = x.view(batch_size, -1, self.num_heads, self.head_size).transpose(1, 2)
        value = x.view(batch_size, -1, self.num_heads, self.head_size).transpose(1, 2)
        attention = self.self_attention(query)
        attention = attention.transpose(1, 2).contiguous().view(batch_size, -1)
        output = self.linear(attention)
        return output

# 实例化模型
d_model = 512
num_heads = 8
multi_head_attention = MultiHeadAttention(d_model, num_heads)

# 定义损失函数和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(multi_head_attention.parameters(), lr=0.001)

# 模拟数据
batch_size = 32
x = torch.randn(batch_size, d_model)
y = torch.randint(0, 10, (batch_size,))

# 训练模型
for epoch in range(10):
    optimizer.zero_grad()
    output = multi_head_attention(x)
    loss = criterion(output, y)
    loss.backward()
    optimizer.step()
```

```python
import torch.optim as optim
```

```python
class GraphAttentionModule(nn.Module):
    def __init__(self, d_model, num_heads):
        super(GraphAttentionModule, self).__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_size = d_model // num_heads
        
        # 自注意力权重
        self.self_attn_weights = nn.Parameter(torch.Tensor(num_heads, d_model, self.head_size))
        # 边注意力权重
        self.edge_attn_weights = nn.Parameter(torch.Tensor(num_heads, d_model, self.head_size))
        # 多粒度池化权重
        self.pooling_weights = nn.Parameter(torch.Tensor(d_model, 2 * self.head_size))
        
        self.softmax = nn.Softmax(dim=1)
        
    def forward(self, h, r):
        batch_size = h.size(0)
        
        # 展平多头
        h = h.view(batch_size, -1, self.num_heads, self.head_size).transpose(1, 2)
        r = r.view(batch_size, -1, self.num_heads, self.head_size).transpose(1, 2)
        
        # 自注意力
        self_attn = torch.matmul(h, self.self_attn_weights)
        self_attn = self.softmax(self_attn)
        
        # 边注意力
        edge_attn = torch.matmul(h, self.edge_attn_weights)
        edge_attn = self.softmax(edge_attn)
        
        # 聚合注意力
        attn = self_attn + edge_attn
        
        # 多粒度池化
        pooled = torch.matmul(attn, r).transpose(1, 2).contiguous().view(batch_size, -1)
        pooled = torch.matmul(self.softmax(pooled), self.pooling_weights)
        
        return pooled
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super(MultiHeadAttention, self).__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_size = d_model // num_heads

        self.query_linear = nn.Linear(d_model, d_model)
        self.key_linear = nn.Linear(d_model, d_model)
        self.value_linear = nn.Linear(d_model, d_model)

        self.attn = nn.Linear(d_model, 1)

    def forward(self, query, key, value):
        batch_size = query.size(0)

        query = self.query_linear(query).view(batch_size, -1, self.num_heads, self.head_size)
        key = self.key_linear(key).view(batch_size, -1, self.num_heads, self.head_size)
        value = self.value_linear(value).view(batch_size, -1, self.num_heads, self.head_size)

        attn_scores = torch.bmm(query, key.transpose(1, 2))
        attn_scores = self.attn(attn_scores).squeeze(-1)

        attn_weights = F.softmax(attn_scores, dim=1)
        attn_applied = torch.bmm(attn_weights.unsqueeze(1), value).squeeze(1)

        return attn_applied
```
