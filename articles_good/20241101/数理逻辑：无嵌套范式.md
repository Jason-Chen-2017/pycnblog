## 第一部分：数理逻辑基础

### 第1章：数理逻辑概述

#### 1.1 数理逻辑的定义与历史

数理逻辑（Mathematical Logic）是研究数学语言、结构、证明和计算性质的形式学科。它起源于19世纪，由数学家乔治·坎特博里和贝恩·罗素等人首次提出。数理逻辑的目的是将数学证明转化为逻辑表达式，从而验证数学命题的真伪。

#### 1.2 数理逻辑的基本概念

数理逻辑的基本概念包括命题、逻辑运算符、推理规则和证明理论。命题是具有明确真值的陈述句，逻辑运算符用于组合命题，推理规则用于从已知命题推导出新命题，证明理论则研究证明的方法和性质。

#### 1.3 数理逻辑的研究内容

数理逻辑的研究内容包括命题逻辑、谓词逻辑、逻辑演算和证明理论。命题逻辑研究命题的真值关系，谓词逻辑研究量词和变量的作用，逻辑演算研究逻辑表达式的构造和推理规则，证明理论研究证明的过程和性质。

### 第2章：命题逻辑

#### 2.1 命题逻辑的基本结构

命题逻辑的基本结构包括原子命题、逻辑运算符和复合命题。原子命题是最基本的命题，不可再分解；逻辑运算符包括合取（∧）、析取（∨）、蕴含（→）和等价（↔）；复合命题是由原子命题和逻辑运算符组成的命题。

#### 2.2 命题逻辑的基本规则

命题逻辑的基本规则包括自反律、交换律、结合律、分配律、吸收律和德摩根律等。这些规则用于简化命题逻辑表达式，使得推理过程更加简洁和有效。

#### 2.3 命题逻辑的推理方法

命题逻辑的推理方法包括直接推理、逆否推理、构造性推理和反证法等。直接推理从已知命题直接推导出新命题；逆否推理从命题的逆命题和否命题推导出新命题；构造性推理通过构造反例来证明命题的否定；反证法通过假设命题的否定，然后推导出矛盾，从而证明原命题的真。

### 第3章：谓词逻辑

#### 3.1 谓词逻辑的基本结构

谓词逻辑的基本结构包括谓词、个体常项、变量、量词和复合谓词。谓词表示对象属性或关系；个体常项表示特定的对象；变量表示未指定的对象；量词表示对所有对象或某个对象的限制；复合谓词是由谓词和其他逻辑运算符组成的谓词表达式。

#### 3.2 谓词逻辑的基本规则

谓词逻辑的基本规则包括全称量词的规则、存在量词的规则和谓词逻辑的推理规则。全称量词的规则包括全称实例化和全称抽象；存在量词的规则包括存在实例化和存在抽象；谓词逻辑的推理规则包括全称实例化、存在实例化、全称抽象和存在抽象。

#### 3.3 谓词逻辑的推理方法

谓词逻辑的推理方法包括命题推理、谓词推理和谓词逻辑证明等。命题推理用于从已知命题推导出新命题；谓词推理用于从已知谓词表达式推导出新谓词表达式；谓词逻辑证明则用于证明一个谓词逻辑命题的真。

### 第4章：逻辑演算

#### 4.1 逻辑演算的基本概念

逻辑演算是一种形式系统，用于表达和推理逻辑命题。逻辑演算的基本概念包括命题演算和谓词演算。命题演算仅涉及命题和逻辑运算符，而谓词演算则引入了谓词、个体常项和量词。

#### 4.2 命题演算

命题演算是逻辑演算的基础，涉及命题符号和逻辑运算符。命题演算的命题公式可以通过合取、析取、蕴含和等价等运算符组合而成。命题演算的推理规则包括命题的公理和推理规则，如合取律、析取律和蕴含律。

#### 4.3 谓词演算

谓词演算是对命题演算的扩展，引入了谓词和量词。谓词演算的命题公式由谓词符号、个体常项和量词符号组成。谓词演算的推理规则包括全称量词的规则、存在量词的规则和谓词逻辑的推理规则。

### 命题逻辑中的合取范式转换

合取范式（Conjunctive Normal Form，简称CNF）是一种重要的逻辑范式，用于简化逻辑表达式的推理过程。命题逻辑中的合取范式转换是一个关键步骤。

#### 转换方法：

1. 对逻辑表达式进行分解，找到所有合取（∧）和析取（∨）运算。
2. 将蕴含（→）和等价（↔）运算转换为合取范式。
3. 使用分配律和结合律对表达式进行简化。

#### 伪代码实现：

```pseudo
function convertToCNF(expression):
    if expression is a negation:
        return negate(expression.child)
    else if expression is a conjunction:
        return expression
    else if expression is a disjunction:
        return distribute(expression)
    else if expression is an implication:
        return implicationToCNF(expression)
    else if expression is an equivalence:
        return equivalenceToCNF(expression)
    else:
        return error("Unsupported expression type")

function distribute(expression):
    if expression is a conjunction:
        if expression.left is a disjunction:
            newExpression = new conjunction()
            for term in expression.left.terms:
                newExpression.add(new conjunction(expression.right, term))
            return newExpression
        else:
            return new conjunction(expression.left, expression.right)
    else:
        return error("Unsupported expression type")

function implicationToCNF(expression):
    return distribute(new negation(expression.left), expression.right)

function equivalenceToCNF(expression):
    return distribute(new conjunction(expression.left, expression.right), new disjunction(expression.left, new negation(expression.right)))
```

### 数学模型和数学公式 & 详细讲解 & 举例说明

#### 命题逻辑公式

- 合取（∧）：表示两个命题同时为真。
  - 例子：$A \land B$ 表示命题A和命题B同时为真。
- 析取（∨）：表示两个命题中至少有一个为真。
  - 例子：$A \lor B$ 表示命题A或命题B为真。
- 蕴含（→）：表示如果A为真，则B也为真。
  - 例子：$A \rightarrow B$ 表示如果天气晴朗（A），那么我出门（B）。
- 等价（↔）：表示两个命题的真假情况相同。
  - 例子：$A \leftrightarrow B$ 表示天气晴朗（A）和我出门（B）是等价的。

#### 谓词逻辑公式

- 全称量词（∀）：表示对所有对象都成立。
  - 例子：$\forall x (Px \rightarrow Qx)$ 表示对于所有的x，如果x是素数（P），那么x大于2（Q）。
- 存在量词（∃）：表示至少存在一个对象成立。
  - 例子：$\exists x (Px \land Qx)$ 表示至少存在一个x，使得x是素数（P）且x大于2（Q）。

#### 无嵌套范式公式

- 合取范式：$F = \neg P \lor (Q \land R)$
  - 例子：假设P表示“我饿了”，Q表示“家里有食物”，R表示“我有钥匙”，则$F = \neg P \lor (Q \land R)$ 表示如果我不饿或者家里有食物且我有钥匙，那么我可以做饭。
- 析取范式：$F = (P \lor Q) \land (R \lor S)$
  - 例子：假设P表示“我饿了”，Q表示“家里有食物”，R表示“我有钥匙”，S表示“我可以借钱”，则$F = (P \lor Q) \land (R \lor S)$ 表示如果我不饿或家里有食物，且我有钥匙或我可以借钱，那么我可以做饭。

```python
class PropositionalLogicValidator:
    def __init__(self, expression):
        self.expression = expression

    def evaluate(self):
        if self.expression == "T":
            return True
        elif self.expression == "F":
            return False
        else:
            return self.evaluate_conjunction() or self.evaluate_disjunction() or self.evaluate_implication() or self.evaluate_equivalence()

    def evaluate_conjunction(self):
        return self.evaluate_left() and self.evaluate_right()

    def evaluate_disjunction(self):
        return self.evaluate_left() or self.evaluate_right()

    def evaluate_implication(self):
        return not self.evaluate_left() or self.evaluate_right()

    def evaluate_equivalence(self):
        return (self.evaluate_left() and self.evaluate_right()) or (not self.evaluate_left() and not self.evaluate_right())

    def evaluate_left(self):
        return PropositionalLogicValidator(self.expression.left).evaluate()

    def evaluate_right(self):
        return PropositionalLogicValidator(self.expression.right).evaluate()
```

```java
import java.util.HashMap;
import java.util.Map;

public class NNFParser {
    private Map<String, Boolean> facts = new HashMap<>();

    public void assertFact(String fact) {
        facts.put(fact, true);
    }

    public void retractFact(String fact) {
        facts.put(fact, false);
    }

    public boolean evaluate(String expression) {
        if (expression.startsWith("¬")) {
            return !evaluate(expression.substring(1));
        } else if (expression.startsWith("(") && expression.endsWith(")")) {
            return evaluate(expression.substring(1, expression.length() - 1));
        } else if (expression.contains("∧")) {
            String[] parts = expression.split("∧");
            for (String part : parts) {
                if (!evaluate(part)) {
                    return false;
                }
            }
            return true;
        } else if (expression.contains("∨")) {
            String[] parts = expression.split("∨");
            for (String part : parts) {
                if (evaluate(part)) {
                    return true;
                }
            }
            return false;
        } else {
            return facts.getOrDefault(expression, false);
        }
    }
}
```
