4.3. 数学模型公式与详细讲解

以下介绍几种常见的数学模型公式和详细讲解。

1. **线性回归：**
    $$ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + ... + \beta_nx_n $$
    线性回归模型通过最小二乘法估计模型参数，拟合一条直线来预测目标变量（如病虫害发生率）与自变量（如气象因素）之间的关系。

2. **逻辑回归：**
    $$ P(y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x_1 + \beta_2x_2 + ... + \beta_nx_n)}} $$
    逻辑回归模型是一种广义线性模型，用于预测概率型目标变量（如病虫害发生概率）与自变量之间的关系。通过最大化似然估计方法估计模型参数。

3. **支持向量机（SVM）：**
    $$ w^* = \arg\min_{w} \frac{1}{2} ||w||^2_2 \text{ s.t. } y_i ( \langle w, x_i \rangle - b ) \geq 1 $$
    支持向量机模型通过最大化分类间隔，找到最佳决策边界，实现分类任务。在病虫害预测中，SVM可以用于分类病虫害类型。

4. **神经网络（NN）：**
    $$ a_{i,j} = \sigma( \sum_{k=1}^{n} w_{i,k} a_{k,j-1} + b_{i} ) $$
    神经网络模型由多个神经元组成，通过多层非线性变换，实现从输入到输出的映射。在病虫害预测中，神经网络可以用于非线性特征提取和预测。

import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split

for epoch in range(10):
