模运算是一种在数学中常用的运算方式，用于计算两个整数相除后的余数。其基本公式为：\(a \mod n = r\)，其中a是被除数，n是除数，r是余数。模运算在密码学中的典型应用是模乘，即在模n下进行乘法运算。

**同余**：
同余是指两个整数在被某个正整数除时，余数相同。数学上表示为：如果整数a和b除以正整数n所得的余数相同，则称a和b对模n同余，记作\(a \equiv b \mod n\)。同余关系在密码学中有着广泛的应用，特别是在大数分解和离散对数问题中。

#### 3.1 椭圆曲线的定义

椭圆曲线在密码学中扮演着核心角色。首先，我们需要明确椭圆曲线的定义和特征。在数学上，椭圆曲线是一个二维平面上的曲线，其方程为 \(y^2 = x^3 + ax + b\)，其中a和b是常数，且a ≠ 0。

椭圆曲线具有以下几个重要特征：

1. **无穷远点**：椭圆曲线包括一个特殊的点O，称为无穷远点。在数学上，O可以看作是曲线上的一个“添加的”点，使得椭圆曲线成为一个闭合曲线。

2. **有限点**：除了无穷远点O之外，椭圆曲线上的点都是有限点。有限点可以表示为\( (x, y) \)，其中\( y^2 = x^3 + ax + b \)。

3. **双曲线形状**：椭圆曲线在平面上通常呈现出双曲线形状，这一点是其与其他类型的曲线（如圆或抛物线）区分开来的显著特征。

4. **点运算**：椭圆曲线上的点可以进行加、减和乘运算。这些运算遵循特定的规则，使得椭圆曲线上的点形成一个阿贝尔群。

#### 3.2 椭圆曲线上的点运算

在椭圆曲线密码学中，点运算起着至关重要的作用。以下介绍几种基本的点运算：

1. **点加**（加法）：
   - 给定两个点P和Q，椭圆曲线上的点加定义为找到它们之间的中点，并将该中点反射到椭圆曲线的另一侧。数学上，如果P和Q不重合，则\( P + Q \)是经过P和Q的中垂线与椭圆曲线的交点。

2. **点减**（减法）：
   - 点减是点加的逆运算。给定两个点P和Q，\( P - Q \)可以通过\( P + (-Q) \)计算，其中\( -Q \)是Q的相反点。

3. **点乘**（乘法）：
   - 点乘是将一个点与一个整数相乘，这实际上是将点重复加多次。例如，\( 3 \cdot P \)表示将点P加三次，即\( P + P + P \)。

点乘运算在密码学中非常重要，因为它是实现椭圆曲线加密和签名算法的基础。一个关键问题是找到有效的算法来快速计算大整数k倍的一个点P，这涉及到椭圆曲线离散对数问题。

#### 3.3 椭圆曲线离散对数问题

椭圆曲线离散对数问题（ECDLP，Elliptic Curve Discrete Log Problem）是椭圆曲线密码学的核心难题。它的定义如下：

- **ECDLP**：给定椭圆曲线E上的一个基点G和一个点P，找到整数k，使得\( k \cdot G = P \)。

**ECDLP的应用**：
1. **加密**：在椭圆曲线加密算法（ECC）中，加密过程通常涉及到找到椭圆曲线上的一个随机点，并将其与基点相乘。这个过程实际上是在解决ECDLP问题。
2. **签名**：在椭圆曲线数字签名算法（ECDSA）中，签名生成过程需要计算基点的k倍，这也是ECDLP问题的一个应用。

**ECDLP的算法**：

#### 4.2 椭圆曲线加密算法

椭圆曲线加密算法（ECC）是一种公钥加密算法。以下将介绍ECC加密算法的基本原理和步骤。

**原理**：
- **密钥生成**：选择一个随机数作为私钥，选择一个基点作为公钥。
- **加密过程**：使用公钥和随机数进行点乘运算，生成加密密文。
- **解密过程**：使用私钥求解ECDLP，恢复原始信息。

**步骤**：

1. **密钥生成**：
   - 选择一个安全的椭圆曲线E和一个基点G。
   - 选择一个随机数k作为私钥。
   - 计算公钥P = k \* G。

2. **加密**：
   - 选择一个随机数r。
   - 计算c1 = r \* G。
   - 计算c2 = r \* P。
   - 将(c1, c2)作为加密密文发送。

3. **解密**：
   - 使用私钥k计算s = k \* c2。
   - 解开s，得到明文m。

**示例**：

使用Python实现一个简化的ECC加密算法：

```python

# 密钥生成

public_key = curve.export_key(format='PEM', private=False)

# 加密

c1 = r * curve.G
c2 = r * public_key.public_key().point
ciphertext = (c1.x(), c2.x())

# 解密

m = s.x()

print(f"明文: {m}")
```

#### 4.3 椭圆曲线签名算法

椭圆曲线签名算法（ECDSA，Elliptic Curve Digital Signature Algorithm）是一种公钥数字签名算法。以下将介绍ECDSA签名和验证的基本原理和步骤。

**原理**：
- **签名生成**：使用私钥对消息进行签名。
- **签名验证**：使用公钥验证签名。

**步骤**：

1. **签名生成**：
   - 将消息m转换为整数m'。
   - 选择一个随机数k。
   - 计算r = (m' + k \* n) \mod n，其中n是椭圆曲线的阶。
   - 计算s = (k^-1 \* (m' + r \* x) \mod n)。
   - 签名为(r, s)。

2. **签名验证**：
   - 计算v1 = r \* Q + s \* G。
   - 计算v2 = m' \* R。
   - 如果v1 == v2，则签名有效。

**示例**：

```python

from Crypto.Signature import DSS
from Crypto.Random import get_random_bytes

# 密钥生成
curve = ECC.generate(curve='NIST P-256')
private_key = curve.export_key(format='PEM', private=True)
public_key = curve.export_key(format='PEM', private=False)

k = get_random_bytes(32)

# 签名验证

is_valid = verifier.verify(hash_message, r, s)

```

#### 5.1 椭圆曲线的数学模型

椭圆曲线在数学上的定义是通过一个二次方程表示的曲线。其标准方程形式为：
\[ y^2 = x^3 + ax + b \]
其中，a和b是常数，且a ≠ 0。这个方程定义了一个二维平面上的椭圆曲线。在密码学中，我们主要关注的是椭圆曲线上的点运算。

**椭圆曲线上的点**：
椭圆曲线上的点由其坐标\( (x, y) \)表示。特别地，椭圆曲线还包括一个无穷远点O，该点没有实际的坐标值，但它是椭圆曲线上的一个合法点。

**椭圆曲线的群性质**：
椭圆曲线上的点构成一个阿贝尔群（Abelian group）。这个群包括加法和逆运算。对于任意两个点P和Q，它们的和\( P + Q \)也是一个椭圆曲线上的点。同样地，每个点都有一个逆元，即点P的相反点-P。

**椭圆曲线的加法规则**：
设P和Q为椭圆曲线上的两个点，P+Q的计算规则如下：
1. 如果P和Q重合，则P+P是椭圆曲线上的另一个点R，其坐标可以通过以下公式计算：
   \[ x_R = \left( \frac{y_P^2 - 1}{2x_P} \right)^2 \]
   \[ y_R = \left( \frac{y_P^2 - x_R - ax_P}{2y_P} \right) \]
2. 如果P和Q不重合，则P+Q是经过P和Q的中垂线与椭圆曲线的交点。

#### 5.2 椭圆曲线密码学中的数学公式

在椭圆曲线密码学中，有几个关键的数学公式和定理，这些公式和定理对于理解ECC算法至关重要。

**点乘公式**：
给定椭圆曲线E上的一个点P和一个整数k，点乘公式用于计算k \* P。这个公式如下：
\[ k \cdot P = (x_{kP}, y_{kP}) \]
其中，\( k \cdot P \)是通过将点P重复加k次得到的。点乘的计算可以通过以下步骤进行：
1. 初始化：设\( P_x = x_P \)，\( P_y = y_P \)，\( k' = k \)，\( A = 1 \)。
2. 循环：当\( k' \neq 0 \)时，执行以下操作：
   - 如果\( k' \)是奇数，则\( (x_{kP}, y_{kP}) = P \)，并将\( k' \)减去1。
   - 否则，\( (x_{kP}, y_{kP}) = (x_{P_x}, y_{P_y})^2 \)，并将\( k' \)除以2。
   - 更新\( P_x \)和\( P_y \)的值，以准备下一次迭代。

**椭圆曲线离散对数问题（ECDLP）**：
椭圆曲线离散对数问题（ECDLP）是ECC算法的核心难题。其定义如下：
给定椭圆曲线E上的一个基点G和一个点P，找到整数k，使得：
\[ k \cdot G = P \]
ECDLP的难度为算法攻击提供了天然屏障，确保了ECC算法的安全性。

**拉格朗日乘法**：
拉格朗日乘法是一种用于在椭圆曲线上计算点乘的算法。其基本思想是通过分解k，将点乘运算分解为多个较小的点乘运算。具体步骤如下：
1. 将k分解为多个因子：\( k = k_1 \cdot k_2 \cdot ... \cdot k_n \)。
2. 计算每个因子对应的点乘：\( k_1 \cdot G, k_2 \cdot G, ..., k_n \cdot G \)。
3. 依次应用这些点乘结果：\( (k_1 \cdot G) + (k_2 \cdot G) + ... + (k_n \cdot G) \)。

#### 5.3 数学公式讲解与示例

为了帮助读者更好地理解这些数学公式，我们通过一个具体的示例进行讲解。

**示例**：给定椭圆曲线 \( y^2 = x^3 + 2x + 1 \)，基点 \( G(2, 3) \)，计算 \( 3 \cdot G \)。

1. **点乘公式**：
   \[ 3 \cdot G = (x_{3G}, y_{3G}) \]

2. **计算步骤**：
   - 初始化：\( P_x = 2 \)，\( P_y = 3 \)，\( k' = 3 \)，\( A = 1 \)。
   - \( k' = 3 \)是奇数，所以 \( (x_{3G}, y_{3G}) = G = (2, 3) \)。
   - 更新 \( P_x \)和 \( P_y \)：\( P_x = 2 \)，\( P_y = 3 \)。
   - \( k' = 0 \)，计算结束。

因此，\( 3 \cdot G = (2, 3) \)。

from solc import compile_source
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives.serialization import load_pem_private_key

class Contract:

        self.contract_bytecode, self.contract_interface = self.compile_contract()

    def compile_contract(self):
        source = '''
        // SPDX-License-Identifier: MIT
       pragma solidity ^0.8.0;

        contract Transaction {
            struct TransactionData {
                address sender;
                address receiver;
                uint256 amount;
                bytes32 transaction_hash;
            }

            TransactionData[] public transactions;

            function send_transaction(address sender, address receiver, uint256 amount) public {
                bytes32 hash = keccak256(abi.encode(sender, receiver, amount));
                transactions.push(TransactionData(sender, receiver, amount, hash));
            }
        }
        '''
        compiled = compile_source(source)
        contract_bytecode = compiled['<stdin>:Transaction']['bin']
        contract_interface = compiled['<stdin>:Transaction']['abi']
        return contract_bytecode, contract_interface

    def send_transaction(self, sender_id, receiver_id, amount):
        contract = self.w3.eth.contract(abi=self.contract_interface, bytecode=self.contract_bytecode)
        tx = contract.constructor().transact({'from': self.w3.eth.coinbase, 'gas': 500000})
        tx_hash = self.w3.eth.waitForTransactionReceipt(tx)
        return tx_hash
