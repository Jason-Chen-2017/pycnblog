#### 2.1.2 Manifold Learning

Manifold learning is a branch of machine learning that aims to uncover the underlying low-dimensional structure of high-dimensional data. The fundamental idea is that despite the high dimensionality of the data, it often resides on a lower-dimensional manifold, a curved surface embedded in a higher-dimensional space. Manifold learning algorithms seek to identify this intrinsic low-dimensional structure, allowing for more efficient data analysis and visualization.

**Basic Concepts and Principles:**

1. **Local Linearity:** Manifold learning assumes that within a small neighborhood, the data points are approximately linearly related. This assumption is crucial for algorithms like Locally Linear Embedding (LLE) and Isometric Mapping (ISOMAP), which use local linear models to reconstruct the manifold.

2. **Non-linear Dimensionality Reduction:** Unlike traditional linear dimensionality reduction techniques, such as Principal Component Analysis (PCA), manifold learning methods are designed to handle the non-linear relationships inherent in complex datasets.

3. **Embedding Algorithms:** Embedding algorithms map the high-dimensional data points onto a lower-dimensional space while preserving the local geometric structure. This allows for meaningful visualization and analysis of the data.

**Differences from Traditional Dimensionality Reduction:**

- **Preservation of Geometry:** Traditional methods like PCA discard the geometric structure of the data, focusing solely on the variance. In contrast, manifold learning aims to preserve the local and global geometry of the data.

- **Applicability to Non-linear Data:** While PCA is effective for linearly separable data, manifold learning algorithms are more suitable for non-linearly separable data, making them valuable in complex domains like art.

#### Key Principles and Applications

- **Data Visualization:** Manifold learning algorithms are instrumental in visualizing high-dimensional data in two or three dimensions, making it easier to interpret and analyze.

- **Feature Extraction:** By embedding high-dimensional data into a lower-dimensional space, manifold learning can extract meaningful features that are useful for various machine learning tasks, including classification and clustering.

- **Artistic Style Analysis:** In the context of art, manifold learning can be used to analyze and categorize artistic styles by identifying the intrinsic geometric structure of artistic features. #### 3.1.2 Locally Linear Embedding (LLE)

Locally Linear Embedding (LLE) is a manifold learning technique that aims to preserve the local linear relationships between neighboring points in a high-dimensional space. LLE is particularly useful in visualizing and analyzing complex, non-linear data by reducing its dimensionality while maintaining the local geometric structure. In this section, we will provide a detailed explanation of LLE, including its mathematical formulation, algorithmic steps, and a flowchart to illustrate the process.

**Mathematical Formulation:**

Let \( \mathbf{X} \) be a high-dimensional data matrix, where each row \( \mathbf{x}_i \) represents a data point in \( d \) dimensions. The goal of LLE is to find a low-dimensional representation \( \mathbf{Y} \) of the same data points, where each row \( \mathbf{y}_i \) is in \( k \) dimensions, with \( k \ll d \). The core idea behind LLE is to minimize the reconstruction error, i.e., the error introduced when reconstructing the original high-dimensional data points from their low-dimensional counterparts.

For each data point \( \mathbf{x}_i \), LLE constructs a local linear model using its \( n \) nearest neighbors \( \mathbf{x}_{i,1}, \mathbf{x}_{i,2}, \ldots, \mathbf{x}_{i,n} \). This local model can be represented as a linear combination of the neighbors:
\[ \mathbf{x}_i = \sum_{j=1}^{n} w_{ij} \mathbf{x}_{i,j}, \]
where \( w_{ij} \) are the weights that determine the contribution of each neighbor to the reconstruction of \( \mathbf{x}_i \).

To minimize the reconstruction error, LLE solves the following optimization problem:
\[ \min_{\mathbf{Y}} \sum_{i=1}^{m} \sum_{j=1}^{n} w_{ij} (\mathbf{x}_{i} - \sum_{j=1}^{n} w_{ij} \mathbf{y}_{i,j})^2, \]
where \( \mathbf{Y} \) contains the low-dimensional representations \( \mathbf{y}_i \).

**Algorithmic Steps:**

1. **Compute Nearest Neighbors:** For each data point \( \mathbf{x}_i \), compute the \( n \) nearest neighbors using a distance metric, such as Euclidean distance.

2. **Construct Local Linear Models:** For each data point \( \mathbf{x}_i \), construct a local linear model using its neighbors:
   \[ \mathbf{x}_i = \sum_{j=1}^{n} w_{ij} \mathbf{x}_{i,j}. \]

3. **Solve Weight Matrix:** Solve the linear system of equations to obtain the weight matrix \( \mathbf{W} \):
   \[ \mathbf{X} = \mathbf{WY}. \]

4. **Minimize Reconstruction Error:** Minimize the reconstruction error by updating the low-dimensional representations \( \mathbf{Y} \) using the weight matrix \( \mathbf{W} \):
   \[ \mathbf{Y} = \mathbf{W}^{-1} \mathbf{X}. \]

5. **Iterate:** Repeat steps 2-4 until convergence is achieved, i.e., the reconstruction error no longer decreases significantly.

**Python Implementation:**

Here's a Python code snippet demonstrating the LLE algorithm:

```python
import numpy as np

def lle(X, n_neighbors=10, n_components=2):
    # Compute nearest neighbors
    distances = np.linalg.norm(X[:, np.newaxis, :] - X[np.newaxis, :, :], axis=2)
    indices = np.argsort(distances, axis=2)[:, :, 1:n_neighbors+1]

    # Construct local linear models
    W = np.zeros((X.shape[0], n_neighbors))
    for i in range(X.shape[0]):
        neighbors = X[indices[i], :]
        W[i, :] = np.linalg.lstsq(neighbors, X[i], rcond=None)[0]

    # Solve weight matrix
    Y = np.linalg.inv(W @ np.linalg.inv(W.T)) @ X

    # Return low-dimensional representations
    return Y

# Example usage
X = np.random.rand(100, 10)  # Generate synthetic high-dimensional data
Y = lle(X, n_neighbors=5, n_components=2)
print(Y)
```

#### 3.1.3 Isometric Mapping (ISOMAP)

Isometric Mapping (ISOMAP) is a non-linear dimensionality reduction technique that aims to preserve the local geometric structure of high-dimensional data by mapping it onto a lower-dimensional space while maintaining the distances between neighboring points. ISOMAP is particularly effective in visualizing and analyzing complex, non-linear data, making it a valuable tool in various domains, including artistic style learning. In this section, we will provide a detailed explanation of ISOMAP, including its mathematical formulation, algorithmic steps, and a flowchart to illustrate the process.

**Mathematical Formulation:**

Let \( \mathbf{X} \) be a high-dimensional data matrix, where each row \( \mathbf{x}_i \) represents a data point in \( d \) dimensions. The goal of ISOMAP is to find a low-dimensional representation \( \mathbf{Y} \) of the same data points, where each row \( \mathbf{y}_i \) is in \( k \) dimensions, with \( k \ll d \). The core idea behind ISOMAP is to preserve the geodesic distances between neighboring points in the high-dimensional space when mapped to the low-dimensional space.

**Algorithmic Steps:**

1. **Compute Geodesic Distances:** For each pair of data points \( \mathbf{x}_i \) and \( \mathbf{x}_j \), compute the geodesic distance \( d_G(\mathbf{x}_i, \mathbf{x}_j) \) using the heat kernel:
   \[ d_G(\mathbf{x}_i, \mathbf{x}_j) = \frac{1}{\alpha} \log \left( \frac{\exp(-\alpha \cdot \|\mathbf{x}_i - \mathbf{x}_j\|)}{\int_{\mathbb{R}^d} \exp(-\alpha \cdot \|\mathbf{x} - \mathbf{x}_i\|) d\mathbf{x}} \right), \]
   where \( \alpha \) is a parameter controlling the smoothness of the geodesic distance.

2. **Construct Neighbor Graph:** Construct a neighbor graph \( G \) using the geodesic distances. For each data point \( \mathbf{x}_i \), include its \( n \) nearest neighbors as its neighbors in \( G \).

3. **Compute Shortest Paths:** Compute the shortest paths between all pairs of neighbors in \( G \), resulting in a distance matrix \( D \).

4. **Solve Low-Dimensional Embedding:** Solve the following optimization problem to obtain the low-dimensional representation \( \mathbf{Y} \):
   \[ \min_{\mathbf{Y}} \sum_{i=1}^{m} \sum_{j=1}^{m} w_{ij} (d_G(\mathbf{x}_i, \mathbf{x}_j) - \|\mathbf{y}_i - \mathbf{y}_j\|)^2, \]
   where \( w_{ij} \) are the weights assigned to each edge in \( G \), and \( \|\cdot\| \) denotes the Euclidean distance in the low-dimensional space.

5. **Normalize Embedding:** Normalize the low-dimensional embedding \( \mathbf{Y} \) to ensure that the distances between neighboring points in the low-dimensional space approximately match the geodesic distances in the high-dimensional space.

**Python Implementation:**

Here's a Python code snippet demonstrating the ISOMAP algorithm:

```python
import numpy as np
from scipy.sparse.csgraph import dijkstra
from sklearn.neighbors import NearestNeighbors

def isomap(X, n_neighbors=5, n_components=2, alpha=1.0):
    # Compute geodesic distances
    distances = np.linalg.norm(X[:, np.newaxis, :] - X[np.newaxis, :, :], axis=2)
    heat_kernel = np.exp(-alpha * distances)
    kernel_sum = np.sum(heat_kernel, axis=1)
    geodesic_distances = np.log(heat_kernel / kernel_sum)

    # Construct neighbor graph
    neighbors = NearestNeighbors(n_neighbors=n_neighbors).fit(X)
    indices = neighbors.kneighbors(X, return_distance=False)

    # Compute shortest paths
    D = dijkstra(X[indices], indices, weighted=True)

    # Solve low-dimensional embedding
    W = np.zeros((X.shape[0], n_neighbors))
    for i in range(X.shape[0]):
        neighbors = X[indices[i], :]
        W[i, :] = np.linalg.lstsq(neighbors, X[i], rcond=None)[0]
    Y = np.linalg.inv(W @ np.linalg.inv(W.T)) @ X

    # Normalize embedding
    Y = Y / np.linalg.norm(Y, axis=1)[:, np.newaxis]

    # Return low-dimensional representations
    return Y

# Example usage
X = np.random.rand(100, 10)  # Generate synthetic high-dimensional data
Y = isomap(X, n_neighbors=5, n_components=2)
print(Y)
```

```python
import cv2
import numpy as np

def extract_features(images):
    color_histograms = []
    texture_descriptors = []
    edge_maps = []

    for image in images:
        # Color Histogram
        color_hist = cv2.calcHist([image], [0, 1, 2], None, [8, 8, 8], [0, 256, 0, 256, 0, 256])
        color_histograms.append(color_hist.flatten())

        # Texture Descriptor
        texture_desc = cv2.Laplacian(image, cv2.CV_64F).var()
        texture_descriptors.append(texture_desc)

        # Edge Map
        edge_map = cv2.Canny(image, threshold1=50, threshold2=150)
        edge_maps.append(edge_map)

    return np.hstack((color_histograms, texture_descriptors, edge_maps))

features = extract_features(preprocessed_images)
```
