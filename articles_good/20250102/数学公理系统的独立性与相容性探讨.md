**例1：空集和自然数的独立性**

我们尝试证明空集和自然数的独立性。在ZFC系统中，空集可以被定义为所有不包含自身元素的集合。而自然数可以通过零和后继函数递归地定义。这两个概念是否独立？

```python
# 定义自然数

succ = sympy.Symbol('S', integer=True)

# 定义后继函数
def succ(n):
    return n + 1

# 定义空集
empty_set = set()

# 判断独立性的一个方法
from sympy import solve

# 尝试从自然数定义空集
eq1 = sympy.Eq(sympy.Symbol('x'), empty_set)
eq2 = sympy.Eq(sympy.Symbol('x'), {n for n in nat if n != n})

solutions = solve((eq1, eq2), {nat, empty_set})
print(solutions)
```

在这个例子中，我们尝试同时满足空集和自然数的定义，即寻找一个集合`x`，它既是自然数的集合，又满足空集的条件。如果存在这样的集合，则空集和自然数不是独立的。

**例2：选择公理的独立性**

我们再来看选择公理的独立性。选择公理允许我们从任意非空集合中选择一个子集。现在我们尝试在不使用选择公理的情况下证明存在这样的选择。

```python

from sympy import Eq, solve
```

在这个例子中，我们尝试证明从集合`A`中选择一个元素，即`A.pop()`，等于集合`A`本身。显然，这个等式不成立，因为选择一个元素后，集合的元素会减少。因此，选择公理是独立的。
