**Python源代码：**

```python
import heapq

def shannon_fano_encoding(characters, probabilities):
    # 计算字符概率并排序
    heap = [[weight, [symbol]] for symbol, weight in probabilities.items()]
    heapq.heapify(heap)
    
    # 构建编码树
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        weight = left[0] + right[0]
        symbol = [left[1][0], right[1][0]]
        heapq.heappush(heap, [weight, symbol])
    
    # 编码字符
    code_tree = {symbol: binarize(weight) for weight, symbol in heap}
    encoded_chars = {symbol: code_tree[symbol][0] for symbol in characters}
    
    return encoded_chars

def binarize(weight):
    binary = ''
    while weight:
        binary = str(weight % 2) + binary
        weight //= 2
    return binary

# 示例
characters = ['A', 'B', 'C']
probabilities = {'A': 0.4, 'B': 0.3, 'C': 0.3}
encoded_chars = shannon_fano_encoding(characters, probabilities)
print(encoded_chars)
```

**算法原理讲解**：

Shannon-Fano编码是一种基于概率的编码方法。其基本原理是首先计算每个字符的概率，然后根据概率大小对字符进行排序。接下来，构建编码树，将概率较大的字符放在左分支，概率较小的字符放在右分支。最后，对每个字符进行编码，编码结果为字符在编码树中的路径。

**数学模型和公式**：

Shannon-Fano编码的数学模型可以表示为：

$$
C = \sum_{i=1}^{n} p_i \cdot \log_2(1/p_i)
$$

其中，$C$为编码后的信息熵，$p_i$为字符$i$的概率。

**通俗易懂地举例说明**：

假设有三个字符'A'、'B'和'C'，它们的概率分别为0.4、0.3和0.3。首先，我们将这些字符按照概率排序，得到'A'、'B'、'C'。然后，构建编码树，将概率最大的字符'A'放在左分支，概率次大的字符'B'放在右分支，概率最小的字符'C'放在右分支。最后，对每个字符进行编码，'A'编码为'10'，'B'编码为'11'，'C'编码为'00'。
