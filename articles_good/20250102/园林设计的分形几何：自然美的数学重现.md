##### **1.1 分形的定义与特征**

分形是数学中的一种重要概念，其特点在于无限精细的结构。一个分形通常具有以下特征：

- **自相似性**：局部与整体在某些尺度上具有相似性。
- **无限精细**：无论放大多少倍，分形都表现出复杂的细节。
- **分形维数**：介于传统几何维数（如一维、二维、三维）之间。

分形的这些特征使其在自然界中广泛存在，如树的生长、云的形状等。

#### 1. 迭代函数系统（IFS）

迭代函数系统是一种生成分形图形的常见算法。以下是一个简单的IFS生成分形图形的Python代码示例：

```python
import numpy as np
import matplotlib.pyplot as plt

# IFS函数定义
def IFS(x, y):
    a = 1.61803398875  # 费波那契数列中F(1) = 1, F(2) = 1, F(3) = 2, ...
    return (a * x - y, a * y)

# 初始化点
x, y = 0.5, 0.5

# 迭代100次
for _ in range(100):
    x, y = IFS(x, y)

# 绘图
plt.plot(x, y, 'ro')
plt.show()
```

上述代码通过迭代函数系统生成一个简单的分形图形。

#### 2. 分形维数的计算

分形维数用于描述分形的复杂度。以下是一个计算分形维数的Python代码示例：

```python
import numpy as np

# 盒计数法计算分形维数
def box_counting(data, resolution):
    count = 0
    for i in range(len(data) - resolution + 1):
        for j in range(len(data) - resolution + 1):
            if np.linalg.norm(data[i:i+resolution, :], axis=1).max() < resolution:
                count += 1
    return np.log(count) / np.log(resolution)

# 生成分形数据
data = np.random.rand(100, 100)

# 计算分形维数
dimension = box_counting(data, 2)
print("分形维数:", dimension)
```

上述代码通过盒计数法计算给定分形数据的分形维数。

#### 3. 分形填充算法

分形填充算法用于生成分形图形的填充部分。以下是一个简单的分形填充算法Python代码示例：

```python
import numpy as np
import matplotlib.pyplot as plt

# 分形填充算法
def fractal_fill(grid, x, y, value):
    if x < 0 or x >= grid.shape[0] or y < 0 or y >= grid.shape[1]:
        return
    if grid[x, y] != 0:
        return
    grid[x, y] = value
    for i in range(-1, 2):
        for j in range(-1, 2):
            fractal_fill(grid, x + i, y + j, value)

# 初始化网格
grid = np.zeros((100, 100))

# 填充分形
fractal_fill(grid, 50, 50, 1)

# 绘图
plt.imshow(grid, cmap='gray')
plt.show()
```

上述代码通过分形填充算法生成一个简单的分形图形。
