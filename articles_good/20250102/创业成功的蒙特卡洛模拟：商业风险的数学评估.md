```python
def linear_congruential_generator(seed, a, c, m):
    """线性同余生成器"""
    while True:
        seed = (a * seed + c) % m
        yield seed
```

```python
def random_walk(n_steps, step_size):
```

```python
def monte_carlo_integration(f, a, b, n_samples):
    """蒙特卡洛积分"""
    samples = np.random.uniform(a, b, n_samples)
    integrals = f(samples)
    return np.mean(integrals) * (b - a)
```

### 2. 蒙特卡洛模拟原理

蒙特卡洛模拟的核心在于其随机抽样的思想，通过大量随机样本的模拟来逼近真实系统的行为和特性。以下是蒙特卡洛模拟的基本原理，包括随机数生成、随机变量模拟、蒙特卡洛积分以及模拟结果分析。

#### 随机数生成

随机数生成是蒙特卡洛模拟的基础。一个高质量的随机数生成器能够产生具有良好统计特性的随机数序列，以确保模拟结果的可靠性。常见的随机数生成算法包括线性同余生成器、梅森旋转算法和逆变换法等。

**线性同余生成器（Linear Congruential Generator, LCG）**是一种简单且广泛使用的随机数生成算法。其基本公式为：

\[ X_{n+1} = (aX_n + c) \mod m \]

其中，\( X_n \)是生成的随机数，\( a \)、\( c \)和\( m \)是算法的参数。选择合适的参数能够确保生成的随机数序列具有较长的周期和均匀的分布。

**梅森旋转算法（Marsaglia's Twisted Gausian Algorithm, TGauss）**是一种生成正态分布随机数的算法。其基本思想是，通过组合多个线性同余生成器来生成均匀分布的随机数，然后通过逆累积分布函数（Quantile Function）生成正态分布的随机数。

#### 随机变量模拟

在蒙特卡洛模拟中，随机变量是核心概念之一。通过模拟随机变量，可以分析系统的行为和特性。常见的随机变量包括离散随机变量和连续随机变量。

**离散随机变量**的模拟通常使用概率质量函数（Probability Density Function, PDF）或累积分布函数（Cumulative Distribution Function, CDF）。例如，对于二项分布（Binomial Distribution），可以通过以下公式进行模拟：

\[ P(X = k) = \binom{n}{k} p^k (1-p)^{n-k} \]

其中，\( n \)是试验次数，\( p \)是单次试验成功的概率。在Python中，可以使用`numpy.random.binomial()`函数来生成二项分布的随机数。

**连续随机变量**的模拟通常使用逆变换法或接受-拒绝法（Accept-Reject Method）。例如，对于正态分布（Normal Distribution），可以通过以下步骤进行模拟：

1. 生成两个独立的标准正态分布随机数\( X \)和\( Y \)。
2. 计算新的随机数\( Z = X^2 + Y^2 \)。
3. 计算概率密度函数值\( f(Z) \)。
4. 生成另一个随机数\( u \)（均匀分布）。
5. 如果\( u \leq f(Z)/2 \)，则接受\( Z \)作为正态分布随机数。

在Python中，可以使用`numpy.random.normal()`函数来生成正态分布的随机数。

#### 蒙特卡洛积分

蒙特卡洛积分是一种通过模拟大量随机样本来近似计算定积分的方法。其基本原理是将定积分转换为概率问题，通过随机抽样来近似计算。例如，对于函数\( f(x) \)在区间\[a, b\]上的定积分，可以通过以下步骤进行模拟：

1. 生成多个随机数\( x_i \)，使得它们在区间\[a, b\]上均匀分布。
2. 计算函数值\( f(x_i) \)。
3. 计算积分的近似值：

\[ \int_{a}^{b} f(x) dx \approx \frac{1}{N} \sum_{i=1}^{N} f(x_i) \]

其中，\( N \)是随机样本的数量。

在Python中，可以使用以下代码示例来计算定积分：

```python
import numpy as np

def f(x):
    return x * np.exp(-x**2)

a, b = 0, 1
N = 10000
samples = np.random.uniform(a, b, N)
integral = np.mean(f(samples)) * (b - a)
print(f"积分近似值：{integral:.4f}")
```
