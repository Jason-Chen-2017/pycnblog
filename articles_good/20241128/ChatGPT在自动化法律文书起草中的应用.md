以下是 ChatGPT 自动化法律文书起草系统的核心源代码。该代码基于 Flask 框架，实现了用户输入文本，并通过 ChatGPT API 自动生成法律文书的功能。

```python
# 初始化 Flask 应用
app = Flask(__name__)

# 设置 OpenAI API 密钥
openai.api_key = "your_openai_api_key"

# 定义生成法律文书的 API 路由
@app.route('/generate', methods=['POST'])
def generate_document():
    # 获取用户输入的文本
    data = request.get_json()
    text = data.get('text', '')

    # 调用 ChatGPT API 生成文本
    response = openai.Completion.create(
        engine="text-davinci-002",
        prompt=text,
        max_tokens=150,
        n=1,
        stop=None,
        temperature=0.5
    )

    # 返回生成的文本
    return jsonify({'generated_text': response.choices[0].text.strip()})

# 运行 Flask 应用
if __name__ == '__main__':
    app.run(debug=True)
```

   - `stop=None`：设置停止生成文本的条件。
