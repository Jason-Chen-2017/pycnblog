#### 关系权重计算

在Self-Consistency CoT中，生态要素之间的关系权重是通过特征向量之间的相似性来计算的。我们使用以下公式来计算两个要素 $ A $ 和 $ B $ 之间的关系权重：

生态系统的一致性规则用于评估生态系统内各要素之间的协调程度。一致性规则可以表示为：

$$ R = \sum_{i,j} w_{ij} \cdot (f_{ij} - \mu) $$

其中，$ R $ 表示生态系统的整体一致性，$ w_{ij} $ 是要素 $ i $ 与要素 $ j $ 之间的关系权重，$ f_{ij} $ 是要素 $ i $ 在特征 $ j $ 上的值，$ \mu $ 是特征 $ j $ 的均值。该公式通过权重和特征值之间的偏差来衡量生态系统的一致性，如果偏差较小，则表明生态系统较为一致。

        for j in range(i+1, len(feature_vectors)):
            weight = G[entities[i]][entities[j]]['weight']
            if abs(weight - 1 / (1 + np.exp(-0.1 * np.linalg.norm(feature_vectors[i] - feature_vectors[j])))) > threshold:
                consistency_results[(entities[i], entities[j])] = 'Inconsistent'
    return consistency_results

def adjust_system(G, consistency_results):
    for edge, result in consistency_results.items():
        if result == 'Inconsistent':
            weight = G[edge[0]][edge[1]]['weight']
            new_weight = 1 / (1 + np.exp(-0.1 * np.linalg.norm(G.nodes[edge[0]]['feature_vector'] - G.nodes[edge[1]]['feature_vector'])))
            G[edge[0]][edge[1]]['weight'] = new_weight
    return G
