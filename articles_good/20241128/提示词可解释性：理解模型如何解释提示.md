#### 4.4 Step-by-Step Explanation of Core Algorithms

To further elucidate the mathematical models used in prompt explanation, we will provide a step-by-step explanation of some core algorithms. These explanations will be accompanied by Python code to illustrate the concepts in action.

- **Gradient Descent**:
  - **Step 1:** Initialize model parameters
  - **Step 2:** Compute the loss function
  - **Step 3:** Calculate the gradients
  - **Step 4:** Update model parameters
  - **Step 5:** Repeat steps 2-4 until convergence

```python
import numpy as np

# Step 1: Initialize model parameters
w = np.random.randn(2, 2)

# Step 2: Compute the loss function
def loss_function(w):
    return np.linalg.norm(w * np.array([1, 1]))

# Step 3: Calculate the gradients
def compute_gradients(w, x, y):
    return -2 * x

# Step 4: Update model parameters
def update_parameters(w, gradients, learning_rate):
    return w - learning_rate * gradients

# Step 5: Repeat steps 2-4 until convergence
learning_rate = 0.1
for epoch in range(100):
    x = np.array([1, 1])
    y = np.array([0, 0])
    gradients = compute_gradients(w, x, y)
    w = update_parameters(w, gradients, learning_rate)
    loss = loss_function(w)
    print(f"Epoch {epoch + 1}, Loss: {loss}")
```

- **Attention Mechanism**:
  - **Step 1:** Compute attention scores
  - **Step 2:** Apply soft or hard attention
  - **Step 3:** Aggregate attention scores
  - **Step 4:** Compute the output based on attention weights

```python
import numpy as np

# Step 1: Compute attention scores
def compute_attention_scores(q, k):
    return np.dot(q, k.T) / np.sqrt(np.linalg.norm(q, 2) * np.linalg.norm(k, 2))

# Step 2: Apply soft or hard attention
def apply_attention(scores, mask=None):
    if mask is not None:
        scores = scores * mask
    attention_weights = np.softmax(scores)
    return attention_weights

# Step 3: Aggregate attention scores
def aggregate_attention(scores, values):
    return np.dot(scores, values)

# Step 4: Compute the output based on attention weights
def compute_output(values, attention_weights):
    return aggregate_attention(scores, values) * attention_weights

# Example usage
q = np.array([1, 2, 3])
k = np.array([4, 5, 6])
scores = compute_attention_scores(q, k)
mask = np.array([True, False, True])
attention_weights = apply_attention(scores, mask)
values = np.array([0.1, 0.2, 0.3])
output = compute_output(values, attention_weights)
print(f"Attention Weights: {attention_weights}")
print(f"Output: {output}")
```
