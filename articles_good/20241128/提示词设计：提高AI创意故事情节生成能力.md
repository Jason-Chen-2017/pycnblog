1. **关键词多样性**：提示词应包含多样化的关键词，以丰富故事情节的内容和场景。多样性可以激发生成模型的创意性，使其生成更加独特和有趣的故事情节。

5. **用户偏好**：提示词应考虑用户偏好，以生成符合用户需求的故事情节。用户偏好可以包括特定主题、风格、角色等，从而提高用户满意度和故事的可读性。

### 2.1 语言模型简介

语言模型是AI故事生成系统的基石，它是一种能够预测下一个词语概率的模型。语言模型通过对大量文本数据的学习，捕捉语言中的统计规律和模式，从而实现文本生成。以下是对几种常见语言模型的介绍：

- **n-gram模型**：n-gram模型是一种基于词汇序列概率的语言模型。它将文本划分为n个连续的词语，计算每个n-gram出现的频率，并利用这些频率预测下一个词语。

- **递归神经网络（RNN）**：递归神经网络（RNN）是一种能够处理序列数据的神经网络。RNN通过循环机制捕捉文本中的上下文信息，从而生成连贯的文本。

- **长短时记忆网络（LSTM）**：长短时记忆网络（LSTM）是RNN的一种改进，能够更好地处理长序列数据。LSTM通过门控机制控制信息的流入和流出，避免了传统RNN中梯度消失的问题。

- **变换器（Transformer）**：变换器（Transformer）是一种基于自注意力机制的深度学习模型。它通过多头自注意力机制和全连接层，实现了文本序列的高效处理和生成。

以下是使用Python代码实现的简单n-gram语言模型：

```python
import numpy as np

def n_gram_model(text, n):
    text = text.lower()
    words = text.split()
    n_gram_counts = np.zeros((len(words) - n, n))

    for i in range(len(words) - n):
        n_gram = tuple(words[i:i+n])
        n_gram_counts[i] = n_gram

    return n_gram_counts

text = "我是人工智能，我将帮助你解决问题。"
n = 2
n_gram_counts = n_gram_model(text, n)

print(n_gram_counts)
```

## 第3章：提示词设计原则与技巧

### 3.1 提示词分类与特点

在AI创意故事情节生成中，提示词设计至关重要。一个良好的提示词能够引导生成模型生成高质量、连贯和具有创意性的故事情节。本节将介绍提示词的分类与特点，帮助读者更好地理解和设计提示词。

#### 按功能分类

提示词可以根据其在故事情节中的作用进行分类，主要包括以下几类：

1. **主题型提示词**：主题型提示词用于定义故事的主题或背景，为故事提供整体方向。例如：“未来的科技世界”、“古老的神秘传说”等。

2. **情感型提示词**：情感型提示词用于引导故事的情感倾向，表达特定的情感色彩。例如：“悲伤的离别”、“激动的冒险”等。

3. **情境型提示词**：情境型提示词用于设定故事的具体场景，为故事提供具体的背景信息。例如：“在荒凉的沙漠”、“在一个现代化的城市”等。

4. **角色型提示词**：角色型提示词用于描述故事中的角色特征和关系。例如：“勇敢的青年”、“邪恶的巫师”等。

5. **情节型提示词**：情节型提示词用于引导故事情节的发展，提供具体的情节线索。例如：“遭遇神秘的挑战”、“追寻失落的宝藏”等。

#### 按来源分类

提示词还可以根据来源进行分类，主要包括以下几类：

1. **用户输入型提示词**：这类提示词直接来源于用户的需求和指令，反映了用户的具体要求和偏好。例如：“生成一个关于友谊的故事”、“创造一个科幻冒险故事”等。

2. **模板型提示词**：这类提示词基于预先设定的模板生成，模板中包含了一些固定的关键词和结构。例如：“在某个地方，有一个人，他/她遇到了一个困难，并最终克服了它”等。

3. **自动生成型提示词**：这类提示词通过算法自动生成，基于对大量文本数据的学习和统计。例如，基于n-gram模型、RNN、Transformer等生成模型自动生成的提示词。

#### 提示词特点

不同的提示词类型具有不同的特点，以下是一些常见的提示词特点：

1. **多样性**：提示词应具有多样性，以激发生成模型的创意性。多样性包括关键词的多样性、情感倾向的多样性等。

2. **明确性**：提示词应明确具体，避免模糊和含糊不清的表达。明确的提示词有助于生成模型更好地理解故事的需求和方向。

3. **连贯性**：提示词应保证故事情节的连贯性，避免出现逻辑错误或突兀的情节转换。连贯的提示词可以帮助生成模型构建更加流畅和自然的情节。

4. **灵活性**：提示词应具有一定的灵活性，允许生成模型在生成故事情节时进行适当的扩展和创造。灵活的提示词可以增强生成模型的生成能力。

### 第4章：AI创意故事情节生成算法

#### 4.1 生成模型简介

在AI创意故事情节生成中，生成模型起着核心作用。生成模型旨在从数据中学习，并生成新的、有创意的故事情节。本节将介绍几种常见的生成模型，包括生成对抗网络（GAN）、变分自编码器（VAE）和递归神经网络（RNN）。

##### 生成对抗网络（GAN）

生成对抗网络（GAN）由生成器和判别器组成。生成器的目标是生成尽可能真实的故事情节，而判别器的目标是区分生成器生成的故事情节和真实的故事情节。通过这种对抗性训练，生成器逐渐提高其生成能力，从而生成高质量的故事情节。

以下是GAN的基本结构：

```mermaid
graph TD
A[生成器] --> B[判别器]
B --> C{判别结果}
C -->|真实| D[更新判别器]
C -->|虚假| E[更新生成器]
A --> F[生成故事情节]
```

GAN的训练过程可以简化为以下步骤：

1. **生成器训练**：生成器从随机噪声中生成故事情节，并将其输入到判别器中。

2. **判别器训练**：判别器判断输入的故事情节是真实还是虚假。对于真实的故事情节，判别器输出接近1；对于虚假的故事情节，判别器输出接近0。

3. **对抗性训练**：通过调整生成器和判别器的参数，使判别器能够更准确地判断故事情节的真实性，同时使生成器能够生成更真实的故事情节。

##### 变分自编码器（VAE）

变分自编码器（VAE）是一种无监督学习的生成模型。VAE通过编码器和解码器将输入数据编码为一个潜在空间中的向量，然后从潜在空间中采样，通过解码器生成新的数据。VAE在生成故事情节时，可以保持数据的高斯分布，从而生成具有多样性和灵活性的故事情节。

以下是VAE的基本结构：

```mermaid
graph TD
A[编码器] --> B[潜在空间]
B --> C[解码器]
C --> D[生成故事情节]
```

VAE的训练过程可以简化为以下步骤：

1. **编码器训练**：编码器将输入的故事情节映射到潜在空间中的向量。

2. **解码器训练**：解码器从潜在空间中采样，并尝试重建输入的故事情节。

3. **生成故事情节**：通过从潜在空间中采样，解码器生成新的故事情节。

##### 递归神经网络（RNN）

递归神经网络（RNN）是一种能够处理序列数据的神经网络。RNN通过循环机制捕捉序列中的上下文信息，从而生成连贯的文本。RNN在故事情节生成中，可以用来处理自然语言文本序列，生成具有连贯性和逻辑性的故事情节。

以下是RNN的基本结构：

```mermaid
graph TD
A[输入层] --> B[隐藏层]
B --> C[输出层]
C --> D{下一时刻输入}
D --> A
```

RNN的训练过程可以简化为以下步骤：

1. **输入序列处理**：将输入的故事情节序列转化为神经网络可处理的格式。

2. **隐藏层更新**：RNN使用递归机制，将上一时刻的隐藏状态和当前输入相结合，生成新的隐藏状态。

3. **输出生成**：RNN的输出层生成新的故事情节序列，并更新隐藏状态，为下一时刻的输入做好准备。

#### 4.2 基于规则的故事生成

基于规则的故事生成是一种传统的故事生成方法，它通过定义一系列规则来生成故事情节。这种方法在故事生成系统中具有简单、高效和可解释性强的优点。基于规则的故事生成通常包括以下步骤：

1. **规则库构建**：构建一组故事生成规则，这些规则定义了故事情节的可能结构和转换。

2. **角色定义**：为故事中的角色分配特定的属性和行为模式。

3. **情节生成**：通过应用规则库，生成故事情节。故事情节的生成过程可以是线性的，也可以是非线性的，取决于规则的复杂性和故事生成策略。

基于规则的故事生成方法具有以下特点：

- **可解释性**：生成的故事情节遵循明确的规则，因此易于理解和解释。

- **可控性**：通过修改规则库，可以轻松控制故事情节的复杂度和多样性。

- **效率**：基于规则的生成方法通常比基于学习的生成方法更快，因为它们不需要复杂的训练过程。

然而，基于规则的故事生成方法也存在一些局限性：

- **创造性限制**：基于规则的生成方法可能无法生成高度创新和独特的故事情节。

- **规则复杂性**：构建一个完整和复杂的规则库需要大量时间和资源。

以下是一个简单的基于规则的情节生成算法：

```python
# 假设有一个简单的规则库，定义了几个基本情节结构
rules = {
    "start": [
        "Once upon a time, there was a brave adventurer named ...",
        "In the land of ... lived a wise old wizard named ...",
    ],
    "quest": [
        "He/She received a mysterious letter, which contained a map to a hidden treasure.",
        "The wizard decided to embark on a journey to find the legendary sword of ...",
    ],
    "challenges": [
        "Along the way, he/she encountered various challenges, such as ...",
        "The wizard faced a fierce dragon guarding the entrance to the ancient castle.",
    ],
    "end": [
        "After countless trials, the adventurer finally reached the treasure and claimed it.",
        "The wizard returned to his home, bringing the sword of justice with him.",
    ],
}

# 使用规则库生成一个故事情节
def generate_story():
    story = ""
    story += random.choice(rules["start"]) + "\n"
    story += random.choice(rules["quest"]) + "\n"
    story += random.choice(rules["challenges"]) + "\n"
    story += random.choice(rules["end"]) + "\n"
    return story

print(generate_story())
```

#### 4.3 基于数据的故事生成

基于数据的故事生成方法依赖于大量训练数据，通过学习这些数据中的模式和结构来生成新的故事情节。这种方法通常使用深度学习模型，如循环神经网络（RNN）、变换器（Transformer）等。以下将详细探讨基于数据的故事生成方法，包括文本数据的收集、处理和模型训练。

##### 文本数据的收集

基于数据的故事生成首先需要收集大量的文本数据。这些数据可以是各种来源的小说、电影剧本、游戏剧情等。收集数据时，应注意数据的质量和多样性，以确保模型能够学习到丰富的故事结构和情节元素。

##### 数据处理

收集到文本数据后，需要进行处理，以便用于模型训练。数据处理通常包括以下步骤：

1. **文本清洗**：去除文本中的无关信息，如标点符号、停用词等。

2. **分词**：将文本拆分成单个单词或词语。

3. **词向量化**：将文本中的单词或词语转换为数值表示，以便输入到神经网络中。常用的词向量化方法包括Word2Vec、GloVe等。

4. **构建数据集**：将处理后的文本数据划分为训练集、验证集和测试集，用于模型训练和评估。

##### 模型训练

基于数据的故事生成通常使用序列到序列（seq2seq）模型或变换器（Transformer）等深度学习模型。以下是一个基于序列到序列模型的简单训练流程：

1. **编码器训练**：编码器将输入的文本序列编码为固定长度的向量。

2. **解码器训练**：解码器使用编码后的向量生成新的文本序列。

3. **损失函数**：使用交叉熵损失函数来衡量预测序列与真实序列之间的差异，并更新模型参数。

以下是使用Python代码实现的简单seq2seq模型：

```python
import tensorflow as tf

# 假设已经预处理好了输入和目标文本序列
inputs = tf.keras.preprocessing.sequence.pad_sequences(input_texts, maxlen=max_length)
targets = tf.keras.preprocessing.sequence.pad_sequences(target_texts, maxlen=max_length)

# 构建seq2seq模型
model = tf.keras.models.Sequential([
    tf.keras.layers.Embedding(vocab_size, embedding_dim, input_length=max_length),
    tf.keras.layers.LSTM(128),
    tf.keras.layers.Dense(vocab_size, activation='softmax')
])

# 编译模型
model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])

# 训练模型
model.fit(inputs, targets, epochs=10, validation_split=0.2)
```

##### 数据增强

为了提高故事生成系统的性能和多样性，可以使用数据增强技术。数据增强包括以下几种方法：

1. **填充和截断**：通过填充或截断输入序列，使其符合模型的输入要求。

2. **随机插入和删除**：在输入序列中随机插入或删除单词或短语。

3. **词替换**：将输入序列中的单词随机替换为同义词或常见短语。

4. **序列重排**：随机重新排列输入序列中的单词或短语。

以下是使用Python代码实现的简单数据增强：

```python
import random

def random_insert_delete(text, p_insert=0.1, p_delete=0.1):
    words = text.split()
    n_insert = int(len(words) * p_insert)
    n_delete = int(len(words) * p_delete)
    
    for _ in range(n_insert):
        index = random.randint(0, len(words) - 1)
        words.insert(index, random.choice(["happy", "sad", "joy", "sorrow"]))
    
    for _ in range(n_delete):
        index = random.randint(0, len(words) - 1)
        del words[index]
    
    return " ".join(words)

text = "今天天气很好，我去公园散步。"
enhanced_text = random_insert_delete(text)
print(enhanced_text)
```

### 第5章：文本数据处理与预处理

##### 数据集构建

1. **数据收集**：收集来自各种来源的文本数据，如小说、剧本、新闻报道、社交媒体帖子等。数据源的选择应考虑故事情节的多样性、覆盖面和内容质量。

2. **数据预处理**：对收集到的数据进行预处理，包括去除标点符号、停用词、HTML标签等。预处理步骤应确保文本数据的一致性和可用性。

3. **文本分词**：将预处理后的文本拆分为单个单词或短语。常用的分词工具包括jieba、NLTK等。

4. **数据标注**：对文本数据进行标注，包括角色、情节、情感等。标注数据可以帮助模型更好地理解文本内容，从而生成更准确和连贯的故事情节。

##### 数据清洗

1. **去除重复数据**：删除数据集中重复的文本，以避免模型过度拟合。

2. **去除噪音数据**：删除含有噪声、错误或格式不规范的文本。例如，去除含有大量数字、特殊字符或格式不规范的文本。

3. **处理缺失值**：对于缺失数据的处理，可以选择填充或删除。填充方法包括使用平均值、中位数或特定值进行填充；删除方法是将包含缺失数据的样本从数据集中移除。

4. **标准化文本**：对文本进行标准化处理，包括小写转换、去除停用词、词干提取等。这些处理可以减少文本数据中的噪声，提高模型的训练效果。

### 5.2 文本向量化与嵌入

在AI创意故事情节生成中，文本向量化与嵌入是关键步骤，它们将原始文本数据转化为模型能够处理和学习的数值表示。文本向量化是将文本数据转化为向量表示，而文本嵌入则是将单词或短语映射到高维空间中的点。以下是对这两种技术的详细探讨。

#### 文本向量化

文本向量化是将原始文本数据转换为固定长度的向量表示的过程。这种表示方法有助于将文本数据输入到机器学习模型中。文本向量化主要有以下几种方法：

1. **计数向量器（CountVectorizer）**：计数向量器是一种常用的文本向量化方法，它通过计算单词或短语的词频来生成向量。这种方法简单有效，但在处理稀有词或停用词时可能存在不足。

   ```python
   from sklearn.feature_extraction.text import CountVectorizer

   corpus = [
       '人工智能是一种模拟人类智能的技术。',
       '深度学习是人工智能的一个重要分支。',
       '神经网络是深度学习的基础。',
   ]

   vectorizer = CountVectorizer()
   X = vectorizer.fit_transform(corpus)
   print(X.toarray())
   ```

2. **TF-IDF向量器（TfidfVectorizer）**：TF-IDF向量器在计数向量器的基础上加入了词语的重要程度计算。TF（词频）表示单词在文档中出现的频率，IDF（逆文档频率）表示单词在文档集合中出现的频率越低，其重要性越高。这种方法能够更好地处理稀有词和停用词。

   ```python
   from sklearn.feature_extraction.text import TfidfVectorizer

   vectorizer = TfidfVectorizer()
   X = vectorizer.fit_transform(corpus)
   print(X.toarray())
   ```

#### 文本嵌入

文本嵌入是将单词或短语映射到高维空间中的点，使其具有语义信息。文本嵌入通常用于神经网络模型，如循环神经网络（RNN）、变换器（Transformer）等。以下是一些常见的文本嵌入方法：

1. **Word2Vec**：Word2Vec是一种基于神经网络的文本嵌入方法，通过训练词向量模型，将单词映射到低维空间中的点。Word2Vec包括两种训练方法：CBOW（连续词袋）和SG（skip-gram）。

   ```python
   from gensim.models import Word2Vec

   sentences = [
       '人工智能是一种模拟人类智能的技术。',
       '深度学习是人工智能的一个重要分支。',
       '神经网络是深度学习的基础。',
   ]

   model = Word2Vec(sentences, vector_size=100, window=5, min_count=1, workers=4)
   print(model.wv['人工智能'])
   ```

2. **GloVe**：GloVe（Global Vectors for Word Representation）是一种基于全局统计的文本嵌入方法，它通过计算词对在语料库中的共现次数来学习词向量。GloVe可以生成高质量和具有语义信息的词向量。

   ```python
   from gensim.models import GloVe

   corpus = [
       '人工智能是一种模拟人类智能的技术。',
       '深度学习是人工智能的一个重要分支。',
       '神经网络是深度学习的基础。',
   ]

   model = GloVe(corpus, vector_size=100, window=5, min_count=1)
   print(model.wv['人工智能'])
   ```

3. **变换器（Transformer）**：变换器是一种基于自注意力机制的深度学习模型，它使用特殊的文本嵌入技术，如BERT（Bidirectional Encoder Representations from Transformers）和RoBERTa（A Robustly Optimized BERT Pretraining Approach）。这些模型通过双向编码器学习文本的上下文信息，生成高质量的词向量。

   ```python
   from transformers import BertModel, BertTokenizer

   tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
   model = BertModel.from_pretrained('bert-base-uncased')

   text = '人工智能是一种模拟人类智能的技术。'
   inputs = tokenizer(text, return_tensors='pt')
   outputs = model(**inputs)

   hidden_states = outputs.last_hidden_state
   print(hidden_states.shape)
   ```

通过文本向量化与嵌入技术，我们可以将原始文本数据转化为模型可处理的数值表示。这些技术不仅有助于提高模型的性能，还能够增强生成故事情节的语义连贯性和创意性。在下一节中，我们将讨论常见文本预处理方法，以及它们在故事生成中的应用。

#### 词干提取

词干提取是一种将单词缩减到其基本形式（词干）的文本预处理技术。通过词干提取，可以简化文本数据，减少模型需要处理的词汇量，从而提高模型的训练效率。常用的词干提取工具包括Snowball、Porter Stemmer和Lancaster Stemmer。

### 第6章：深度学习模型与优化

#### 6.1 深度学习基础

深度学习是AI创意故事情节生成中不可或缺的一部分。它通过多层神经网络结构，从大量数据中自动学习特征和模式，从而实现复杂的任务。本节将介绍深度学习的基础知识，包括神经网络、损失函数和优化算法。

##### 神经网络

神经网络（Neural Networks，NN）是深度学习的基础构件。一个简单的神经网络通常包括以下三个主要部分：

1. **输入层（Input Layer）**：输入层接收外部输入数据，并将其传递给下一层。

2. **隐藏层（Hidden Layers）**：隐藏层对输入数据进行处理和特征提取，每一层都可以提取更高层次的抽象特征。

3. **输出层（Output Layer）**：输出层生成最终预测或输出。

神经网络的计算过程如下：

1. **激活函数（Activation Function）**：激活函数用于引入非线性，常见的激活函数包括Sigmoid、ReLU和Tanh。

2. **前向传播（Forward Propagation）**：输入数据通过网络的每一层，每层计算输出并通过激活函数处理。

3. **反向传播（Backpropagation）**：通过反向传播算法，计算网络输出与实际输出之间的误差，并更新网络的权重和偏置。

##### 损失函数

损失函数用于衡量预测结果与真实结果之间的差异。在深度学习中，损失函数的目的是最小化预测误差。以下是一些常用的损失函数：

1. **均方误差（Mean Squared Error，MSE）**：MSE常用于回归任务，计算预测值与真实值之间平方差的平均值。

   $$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

2. **交叉熵（Cross-Entropy）**：交叉熵常用于分类任务，计算真实分布与预测分布之间的差异。

   $$\text{CE} = -\sum_{i=1}^{n} y_i \log(\hat{y}_i)$$

##### 优化算法

优化算法用于更新网络权重，以最小化损失函数。以下是一些常用的优化算法：

1. **随机梯度下降（Stochastic Gradient Descent，SGD）**：SGD通过随机选择一部分训练样本来更新权重。

2. **动量梯度下降（Momentum Gradient Descent）**：动量梯度下降在SGD的基础上引入了动量项，以减少权重的振荡。

3. **Adam优化器（Adam Optimizer）**：Adam优化器结合了SGD和动量梯度下降的优点，通过自适应调整学习率。

#### 6.2 语言模型训练与优化

在AI创意故事情节生成中，语言模型是核心组件。语言模型旨在预测下一个单词或词组，从而生成连贯的文本。以下是如何训练和优化语言模型：

##### 数据准备

1. **文本清洗**：去除文本中的无关信息，如HTML标签、标点符号等。

2. **分词**：将文本拆分为单个单词或词组。

3. **词向量化**：将单词或词组转换为词向量表示。

##### 训练过程

1. **构建神经网络**：设计神经网络结构，包括输入层、隐藏层和输出层。

2. **初始化参数**：随机初始化网络权重和偏置。

3. **前向传播**：输入文本数据，通过网络计算预测的词向量。

4. **计算损失**：使用损失函数计算预测结果与真实结果之间的误差。

5. **反向传播**：更新网络权重和偏置，以减少损失。

6. **迭代训练**：重复上述步骤，直至满足训练停止条件（如损失收敛或达到最大迭代次数）。

##### 优化策略

1. **学习率调整**：根据训练过程动态调整学习率，以避免过早收敛。

2. **正则化**：引入正则化项，如L1、L2正则化，防止过拟合。

3. **Dropout**：在训练过程中随机丢弃部分神经元，以增加模型的泛化能力。

#### 6.3 模型评估与改进

在训练完成后，我们需要评估模型的效果，并对其进行改进。以下是一些常用的评估指标和改进方法：

##### 评估指标

1. **准确率（Accuracy）**：预测正确的样本数占总样本数的比例。

2. **精确率（Precision）**：预测正确的正样本数与预测为正样本的总数之比。

3. **召回率（Recall）**：预测正确的正样本数与实际为正样本的总数之比。

4. **F1分数（F1 Score）**：精确率和召回率的调和平均。

##### 改进方法

1. **增加数据**：收集更多高质量的训练数据，以增加模型的泛化能力。

2. **模型融合**：结合多个模型的结果，以提高预测准确性。

3. **超参数调整**：调整神经网络的结构和超参数，如学习率、批量大小等。

4. **迁移学习**：使用预训练的语言模型作为基础模型，以减少训练时间和提高效果。

##### 源代码实现

以下是实现AI故事生成系统的基本源代码。我们将使用TensorFlow和spaCy来构建和训练模型。

```python
import tensorflow as tf
import spacy
from tensorflow.keras.layers import Embedding, LSTM, Dense
from tensorflow.keras.models import Sequential

# 加载spaCy模型
nlp = spacy.load('en_core_web_sm')

# 准备文本数据
def load_data(file_path):
    with open(file_path, 'r', encoding='utf-8') as f:
        text = f.read()
    doc = nlp(text)
    sentences = [sentence.text for sentence in doc.sents]
    return sentences

# 数据预处理
def preprocess_data(sentences):
    tokens = []
    for sentence in sentences:
        tokens.append([token.text for token in nlp(sentence)])
    return tokens

# 构建神经网络
def build_model(vocab_size, embedding_dim, sequence_length):
    model = Sequential([
        Embedding(vocab_size, embedding_dim, input_length=sequence_length),
        LSTM(128),
        Dense(vocab_size, activation='softmax')
    ])
    model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])
    return model

# 训练模型
def train_model(model, x, y, batch_size=64, epochs=10):
    model.fit(x, y, batch_size=batch_size, epochs=epochs, validation_split=0.2)

# 加载数据
sentences = load_data('story_data.txt')
tokens = preprocess_data(sentences)
vocab = set(sum(tokens, []))
vocab_size = len(vocab)
token_to_index = {token: i for i, token in enumerate(vocab)}
index_to_token = {i: token for token, i in token_to_index.items()}
sequences = [[token_to_index[token] for token in sentence] for sentence in tokens]
sequences = tf.keras.preprocessing.sequence.pad_sequences(sequences, maxlen=50)

# 构建和训练模型
model = build_model(vocab_size, 256, 50)
train_model(model, sequences, sequences, batch_size=32, epochs=10)

# 生成故事
def generate_story(seed_sentence, model, nlp, length=100):
    tokens = nlp(seed_sentence).tokenize()
    tokens = [token.text.lower() for token in tokens if token.is_alpha]
    for i in range(length):
        token_indices = [token_to_index[token] for token in tokens]
        probabilities = model.predict(np.array([token_indices]))
        next_token_index = np.argmax(probabilities[0, :])
        next_token = index_to_token[next_token_index]
        tokens.append(next_token)
        if next_token == '.' or len(tokens) > length:
            break
    return ' '.join(tokens)

# 生成一个故事
print(generate_story("In a world dominated by AI, a young programmer named Alex discovered a hidden mystery.", model, nlp))
```
