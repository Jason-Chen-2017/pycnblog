人工智能生成内容（AI-Generated Content，简称AIGC）是一种利用人工智能技术，尤其是深度学习模型，自动生成文本、图像、音频、视频等多种类型内容的技术。AIGC技术通过训练大规模数据集，使得模型能够理解和生成与人类创造的内容相似的高质量内容。这一技术在近年来随着计算能力的提升和算法的发展，得到了迅猛的发展和应用。

AIGC技术的发展历程可以追溯到2006年，当时由Ian Goodfellow等研究者提出的生成对抗网络（Generative Adversarial Networks，GAN）成为AIGC技术的基石。GAN由一个生成器（Generator）和一个判别器（Discriminator）组成，通过相互对抗的方式训练，生成器试图生成尽可能逼真的数据，而判别器则试图区分生成的数据和真实数据。随着GAN的成功，深度学习领域涌现出了许多类似的技术，如变分自编码器（VAE）、自注意力机制（Self-Attention）等，进一步推动了AIGC技术的发展。

在应用层面，AIGC技术已经深入到多个领域。例如，在文本生成方面，AIGC可以用于自动撰写新闻文章、撰写邮件、生成对话等。在图像生成方面，AIGC可以生成高清照片、艺术画作、人物肖像等。在音频和视频生成方面，AIGC可以自动合成音乐、视频特效等。这些应用不仅提高了内容生产的效率，还丰富了内容创作的形式，为个性化服务提供了新的可能性。

### 2.1 AIGC的基本概念

人工智能生成内容（AI-Generated Content，简称AIGC）是一种通过人工智能技术，尤其是深度学习模型，自动生成文本、图像、音频、视频等多种类型内容的方法。AIGC的核心在于其能够利用海量的数据和强大的计算能力，模拟人类的创作过程，生成与人类创造的内容相似甚至超高的质量内容。AIGC技术的应用领域广泛，从文学创作、艺术设计到音频生成、视频合成，都在不断扩展其应用边界。

首先，我们需要了解AIGC技术中的两个核心组件：生成器（Generator）和判别器（Discriminator）。生成器负责生成内容，它从随机噪声或已有数据中学习，生成新的、以前从未出现过的内容。判别器则负责判断生成内容是否真实，它通过对真实内容和生成内容的比较，不断调整生成器的输出，使其更加逼真。

AIGC技术的核心在于其强大的学习能力和自适应能力。通过大量的数据训练，生成器和判别器能够不断优化其模型，提高生成内容的逼真度和质量。具体来说，AIGC技术通常采用以下几种核心算法：

1. **生成对抗网络（Generative Adversarial Networks，GAN）**：GAN由生成器和判别器组成，通过两个模型的对抗训练，生成逼真的图像、音频和文本。GAN的基本原理是生成器和判别器之间的对抗博弈，生成器试图生成尽可能逼真的内容，而判别器则试图区分生成内容和真实内容。

2. **变分自编码器（Variational Autoencoder，VAE）**：VAE是一种基于概率模型的生成模型，通过编码器和解码器的协同工作，将输入数据转换为潜在空间中的表示，再从潜在空间中生成新的数据。VAE在生成逼真的图像和音频方面表现出色。

3. **自注意力机制（Self-Attention）**：自注意力机制是一种在序列数据上进行注意力分配的方法，能够捕捉序列中的长期依赖关系。自注意力机制在文本生成和图像生成中都有广泛应用。

4. **生成文本到图像模型（Text-to-Image Models）**：这类模型通过文本描述生成对应的图像，广泛应用于图像生成、虚拟现实和增强现实等领域。通过训练大规模的图像和文本数据集，模型能够理解文本描述的含义，并生成相应的图像。

除了上述核心算法，AIGC技术还涉及到多种优化技巧和改进方法，如损失函数的选择、梯度惩罚、数据增强等，这些方法都是为了提高生成内容的质量和稳定性。通过这些技术的结合和应用，AIGC技术能够在各种领域中实现高效的自动内容生成。

总的来说，AIGC技术通过深度学习和人工智能算法，实现了从数据到内容的高效转换。它在文本、图像、音频和视频等多种类型内容的生成中展现出强大的能力，为个性化服务、内容创作和智能应用提供了新的解决方案。随着技术的不断进步和应用场景的拓展，AIGC技术将在更多领域发挥重要作用，推动人工智能与人类创作的深度融合。

#### 模型训练

在数据收集完成后，AIGC技术通过深度学习模型对数据进行分析和训练，构建个性化的职业规划模型。常用的模型包括生成对抗网络（GAN）、变分自编码器（VAE）和自注意力机制等。以下以生成对抗网络（GAN）为例，介绍其基本原理和训练过程。

**生成对抗网络（GAN）的基本原理**：

GAN由生成器（Generator）和判别器（Discriminator）组成，通过两个模型的对抗训练，生成逼真的职业规划方案。生成器的任务是生成与真实职业规划方案相似的虚拟方案，而判别器的任务是区分真实方案和虚拟方案。

**GAN的训练过程**：

1. **初始化模型参数**：生成器和判别器初始化为随机参数。
2. **生成虚拟方案**：生成器从随机噪声中生成虚拟职业规划方案。
3. **判断虚拟方案**：判别器对生成的虚拟方案和真实职业规划方案进行判断。
4. **更新模型参数**：根据判别器的判断结果，通过反向传播算法更新生成器和判别器的参数。

通过多次迭代训练，生成器的输出质量会不断提高，生成的职业规划方案越来越接近真实方案。这一训练过程确保了AIGC技术能够生成高质量的个性化职业规划方案。

### 3.1 生成对抗网络（GAN）的基本原理

生成对抗网络（Generative Adversarial Networks，GAN）是AIGC技术中的一种核心算法，由生成器和判别器两个模型组成，通过对抗训练生成高质量的数据。GAN的提出者是Ian Goodfellow等研究者，于2004年首次提出并引起广泛关注。GAN的基本原理是通过生成器和判别器的博弈，使生成器生成的数据逐渐逼近真实数据。

#### GAN的结构

GAN由以下两部分组成：

1. **生成器（Generator）**：生成器的任务是生成与真实数据相似的数据。它通常是一个随机噪声生成器，将随机噪声通过多层神经网络转换成具体的数据形式，如图像、音频或文本。
2. **判别器（Discriminator）**：判别器的任务是区分输入数据是真实数据还是生成器生成的数据。它也是一个神经网络，通过学习真实数据和生成数据的特征，提高对两者的区分能力。

#### GAN的训练过程

GAN的训练过程是一个博弈过程，生成器和判别器相互对抗，目的是使生成器的输出尽可能逼近真实数据，而判别器尽可能准确地判断数据是真实还是生成。具体训练步骤如下：

1. **初始化生成器和判别器的参数**：生成器和判别器初始化为随机参数，通常使用正态分布初始化。
2. **生成虚假数据**：生成器接收随机噪声，通过神经网络生成虚假数据。
3. **判断虚假数据**：判别器将真实数据和生成器生成的虚假数据分别输入，并输出判断结果。判别器的目标是最大化其判断真实数据和生成数据的准确率。
4. **更新生成器和判别器的参数**：通过反向传播算法，根据判别器的判断结果，分别更新生成器和判别器的参数。生成器的目标是使其生成的虚假数据更接近真实数据，判别器的目标是提高对真实和虚假数据的区分能力。

这个训练过程通过多次迭代进行，每次迭代中生成器和判别器都会更新其参数。随着训练的进行，生成器的输出质量会逐渐提高，生成的虚假数据越来越逼真，而判别器的判断能力也会逐步增强，从而实现高质量的生成。

#### GAN的数学模型

GAN的数学模型可以表示为以下两个损失函数：

1. **生成器的损失函数**：生成器的目标是使其生成的数据尽可能接近真实数据，因此其损失函数通常定义为：
   $$
   L_G = -\log(D(G(z)))
   $$
   其中，\(D\)表示判别器，\(G(z)\)表示生成器生成的虚假数据，\(z\)是随机噪声。

2. **判别器的损失函数**：判别器的目标是正确判断输入数据是真实数据还是生成数据，其损失函数通常定义为：
   $$
   L_D = -[\log(D(x)) + \log(1 - D(G(z))]
   $$
   其中，\(x\)表示真实数据。

在训练过程中，通过交替优化这两个损失函数，使得生成器和判别器都达到最佳状态。具体来说，每次迭代过程中，先固定判别器的参数，更新生成器的参数，使其生成的虚假数据更逼真；然后固定生成器的参数，更新判别器的参数，提高其对真实和虚假数据的区分能力。

GAN的成功在于其独特的对抗训练机制，通过生成器和判别器的相互博弈，实现了高质量数据生成。GAN不仅在图像生成领域取得了显著成果，还在音频生成、视频合成等多个领域得到了广泛应用，为AIGC技术的发展奠定了坚实的基础。

### GAN的变体与优化

在GAN的基本架构基础上，研究者们提出了一系列变体和优化方法，以克服GAN训练中的挑战，提高生成质量和稳定性。以下将介绍几种常见的GAN变体和优化技巧。

#### 条件生成对抗网络（cGAN）

条件生成对抗网络（Conditional GAN，cGAN）在GAN的基础上引入了条件信息，使得生成器和判别器能够处理带有特定标签或条件的数据。cGAN通过在输入中添加条件向量，使得生成器和判别器能够生成和区分带有特定属性的数据。

**结构**：
- **生成器**：接受条件向量（如标签）和随机噪声，生成符合条件的假数据。
- **判别器**：输入假数据和条件向量，判断假数据是否符合条件。

**训练过程**：条件GAN的训练过程与标准GAN类似，但每次迭代时，生成器和判别器都会接收条件向量。条件GAN在图像生成、文本生成等领域表现出色，能够生成更具体的、符合特定条件的图像和文本。

**应用案例**：在图像合成任务中，cGAN可以生成带特定颜色、风格或场景的图像，如图像风格迁移、图像去噪等。

#### 深度卷积生成对抗网络（DCGAN）

深度卷积生成对抗网络（Deep Convolutional GAN，DCGAN）是GAN的一种变体，采用了深度卷积神经网络（Deep Convolutional Neural Networks）的结构，以解决传统GAN在图像生成中的模糊性和细节丢失问题。

**结构**：
- **生成器**：采用卷积层和反卷积层（Transposed Convolution），通过逐层生成图像。
- **判别器**：采用卷积层，逐层提取图像的特征。

**训练技巧**：
- **批量归一化**（Batch Normalization）：在生成器和判别器中引入批量归一化，提高训练稳定性。
- **梯度惩罚**：通过在判别器损失函数中加入梯度惩罚项，防止生成器梯度消失。

**应用案例**：DCGAN在图像生成、艺术创作、虚拟现实等领域有广泛应用，生成的高质量图像具有丰富的细节和逼真度。

#### cycleGAN

cycleGAN是一种用于图像到图像翻译的GAN变体，能够在没有成对训练数据的情况下，将一种类型的图像转换成另一种类型的图像，如将照片转换为艺术画。

**结构**：
- **生成器**：包含两个生成器，一个用于转换图像A到图像B，另一个用于转换图像B到图像A。
- **判别器**：用于区分转换后的图像和原始图像。

**训练技巧**：
- **循环一致性损失**：确保转换后的图像经过反向转换后能够恢复原始图像，提高生成质量。
- **多尺度训练**：在不同尺度上进行训练，增强生成器的鲁棒性。

**应用案例**：cycleGAN在图像风格迁移、图像去噪、医学图像处理等领域有广泛应用，能够实现高质量的图像转换。

#### �照相机视角生成对抗网络（CPGAN）

照相机视角生成对抗网络（Camera Pose GAN，CPGAN）是一种结合了生成对抗网络和多视图几何方法的变体，用于生成三维场景的视图。

**结构**：
- **生成器**：生成三维场景的三维点云，并通过投影生成不同视角的二维图像。
- **判别器**：用于区分真实图像和生成图像。

**训练技巧**：
- **三维数据增强**：通过旋转、缩放、倾斜等操作增强三维场景数据，提高生成器适应性。
- **视角一致性损失**：确保生成图像在不同视角上的一致性，提高生成质量。

**应用案例**：CPGAN在三维场景生成、自动驾驶、虚拟现实等领域有广泛应用，能够生成高质量的三维场景视图。

通过这些变体和优化方法，GAN的性能得到了显著提升，能够生成更高质量、更稳定的数据。这些技术不仅丰富了AIGC的应用场景，也为个性化职业发展规划提供了强大的技术支持。

### 3.2 强化学习的基本概念

强化学习（Reinforcement Learning，RL）是机器学习的一个重要分支，它通过智能体（Agent）在与环境的交互中不断学习，以实现某个目标。与监督学习和无监督学习不同，强化学习强调智能体在动态环境中通过试错来学习最优策略。

#### 强化学习的基本组成部分

1. **智能体（Agent）**：执行行动的实体，旨在通过学习获得最佳行动策略。
2. **环境（Environment）**：智能体执行行动的情境，提供状态（State）和奖励（Reward）。
3. **状态（State）**：智能体在环境中的当前情况，通常用一个向量表示。
4. **动作（Action）**：智能体可以采取的行动，也用一个向量表示。
5. **奖励（Reward）**：环境对智能体行动的即时反馈，用于评估行动的好坏。
6. **策略（Policy）**：智能体根据当前状态选择动作的规则。

#### 强化学习的主要概念

1. **值函数（Value Function）**：评估状态或状态-动作对的预期回报。主要有状态值函数（\(V(s)\)）和动作值函数（\(Q(s, a)\)）两种。
2. **策略迭代（Policy Iteration）**：通过迭代优化策略，使智能体逐步接近最优策略。
3. **模型预测（Model-Based）**：智能体根据环境模型预测未来的状态和奖励，从而优化策略。
4. **模型自由（Model-Free）**：智能体通过直接从经验中学习，不需要环境模型。

#### 强化学习的核心算法

1. **Q-Learning**：Q-Learning是一种模型自由算法，通过更新动作值函数来学习最优策略。其公式为：
   $$
   Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]
   $$
   其中，\(\alpha\)是学习率，\(\gamma\)是折扣因子，\(r\)是即时奖励。

2. **SARSA（On-Policy）**：SARSA是一种模型自由算法，更新当前策略下的动作值函数。其公式为：
   $$
   Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma Q(s', a')]
   $$

3. **Deep Q-Network（DQN）**：DQN是一种结合了深度学习和Q-Learning的算法，通过神经网络近似动作值函数。其核心思想是使用经验回放（Experience Replay）和目标网络（Target Network）来减少训练过程中的偏差。

4. **Policy Gradient**：Policy Gradient方法直接优化策略的参数，通过梯度上升法最大化策略下的期望回报。其公式为：
   $$
   \theta \leftarrow \theta + \alpha \nabla_\theta J(\theta)
   $$
   其中，\(J(\theta)\)是策略的损失函数。

#### 强化学习在职业规划中的应用

强化学习在职业规划中的应用主要体现在以下几个方面：

1. **职业路径推荐**：通过强化学习，智能体可以学习如何根据个人技能和兴趣推荐最优的职业路径。例如，智能体可以基于个人当前的状态（技能、经验等）选择最佳的下一步行动（选择某个职业方向或接受某个培训课程）。

### 4.1 损失函数

在深度学习领域，损失函数（Loss Function）是评估模型预测结果与真实标签之间差异的关键指标。在生成对抗网络（GAN）中，损失函数尤为重要，它直接影响生成器和判别器的训练效果。以下将介绍几种常见的损失函数，包括均方误差（MSE）、交叉熵损失（Cross Entropy Loss）和对抗损失（Adversarial Loss）等。

#### 均方误差（Mean Squared Error，MSE）

均方误差是最常见的损失函数之一，用于衡量预测值与真实值之间的差异。MSE的计算公式为：

$$
L_MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

其中，\(y_i\)为真实值，\(\hat{y}_i\)为预测值，\(n\)为样本数量。MSE的值越低，表示模型预测的准确性越高。

#### 交叉熵损失（Cross Entropy Loss）

交叉熵损失常用于分类问题，用于衡量预测概率分布与真实标签分布之间的差异。交叉熵损失的计算公式为：

$$
L_CE = -\sum_{i=1}^{n} y_i \log(\hat{y}_i)
$$

其中，\(y_i\)为真实标签，\(\hat{y}_i\)为模型预测的概率分布。交叉熵损失函数的值越低，表示模型对类别的预测越准确。

#### 对抗损失（Adversarial Loss）

在生成对抗网络（GAN）中，对抗损失函数用于衡量生成器生成的数据与真实数据之间的相似度，以及判别器对生成数据和真实数据的区分能力。GAN中常用的对抗损失函数包括以下几种：

1. **均方误差对抗损失（Mean Squared Error Adversarial Loss）**：
   $$
   L_{GAN-MSE} = \frac{1}{2} \sum_{i=1}^{n} [ (D(x_i) - 1)^2 + (D(G(z_i)) - 1)^2 ]
   $$

2. **二元交叉熵对抗损失（Binary Cross Entropy Adversarial Loss）**：
   $$
   L_{GAN-BCE} = \sum_{i=1}^{n} [-x_i \log(D(x_i)) - (1 - x_i) \log(1 - D(x_i))]
   $$

3. **Wasserstein距离对抗损失（Wasserstein Distance Adversarial Loss）**：
   $$
   L_{GAN-WD} = \sum_{i=1}^{n} w_i [D(x_i) - D(G(z_i))]
   $$

其中，\(x_i\)为真实数据，\(z_i\)为生成器生成的数据，\(D(x_i)\)和\(D(G(z_i))\)分别为判别器对真实数据和生成数据的判断结果。

对抗损失函数的设计旨在平衡生成器和判别器的训练过程，使生成器生成的数据更加真实，同时使判别器能够准确地区分生成数据和真实数据。

#### 损失函数的选择与优化

选择合适的损失函数对GAN的训练效果至关重要。以下是一些常见的损失函数选择与优化方法：

1. **组合使用多种损失函数**：为了提高GAN的训练效果，可以组合使用多种损失函数，如均方误差对抗损失和二元交叉熵对抗损失，以平衡生成器和判别器的训练过程。

2. **动态调整损失函数权重**：在训练过程中，可以动态调整不同损失函数的权重，以适应不同阶段的训练需求。例如，在生成器训练初期，可以增加对抗损失函数的权重，以促使生成器生成更真实的数据；而在判别器训练初期，可以增加均方误差对抗损失的权重，以提高判别器的区分能力。

3. **引入正则化项**：为了防止生成器和判别器出现过拟合现象，可以引入正则化项，如L1正则化、L2正则化等，以约束模型参数的取值范围。

4. **梯度惩罚**：在GAN训练过程中，生成器和判别器的梯度可能存在消失或爆炸现象，引入梯度惩罚项可以缓解这一问题，提高训练稳定性。

通过选择和优化合适的损失函数，可以显著提高GAN的训练效果，生成高质量的生成数据，为AIGC技术在个性化职业发展规划中的应用提供强有力的支持。

### 4.2 梯度下降算法

梯度下降算法是机器学习中一种核心的优化技术，用于通过调整模型参数以最小化损失函数。梯度下降算法的基本思想是沿着损失函数的负梯度方向逐步更新模型参数，从而找到损失函数的最小值。以下将详细介绍梯度下降算法的基本原理、计算过程、优化技巧及其在AIGC技术中的应用。

#### 梯度下降算法的基本原理

梯度下降算法基于一个简单的思想：如果我们要在一个多维度空间中找到某个函数的最小值，我们可以通过计算函数在每个维度上的变化率（即梯度）来更新我们的位置。具体来说，梯度是一个向量，其方向指向函数增长最快的方向，而其大小则表示函数在该点的增长速度。

在机器学习中，梯度下降算法用于优化模型参数，使其预测结果更接近真实值。具体步骤如下：

1. **初始化参数**：首先，随机初始化模型的参数。
2. **计算梯度**：计算损失函数关于每个参数的梯度。对于多维函数，梯度是一个向量，每个分量表示在相应参数方向上的变化率。
3. **更新参数**：根据梯度和学习率（learning rate），更新模型参数。更新公式为：
   $$
   \theta \leftarrow \theta - \alpha \nabla_\theta J(\theta)
   $$
   其中，\(\theta\)是模型参数，\(\alpha\)是学习率，\(J(\theta)\)是损失函数。

4. **迭代更新**：重复上述步骤，直到满足停止条件（如梯度变化很小、损失函数收敛等）。

#### 计算过程

梯度下降的计算过程可以分为以下几个步骤：

1. **前向传播**：计算输入数据通过模型后的预测值。
2. **计算损失**：计算预测值与真实值之间的差异，得到损失函数值。
3. **反向传播**：计算损失函数关于模型参数的梯度。
4. **参数更新**：根据梯度和学习率更新模型参数。

以下是一个简化的梯度下降算法步骤：
```python
# 假设有一个线性模型 y = wx + b
# 初始化参数 w = w0, b = b0
# 学习率 alpha
# 数据集 X, y

for epoch in range(num_epochs):
    for x, y in data_loader:
        # 前向传播
        y_pred = x @ w + b
        
        # 计算损失
        loss = (y_pred - y)**2
        
        # 反向传播
        grad_w = 2 * (y_pred - y) * x
        grad_b = 2 * (y_pred - y)
        
        # 参数更新
        w = w - alpha * grad_w
        b = b - alpha * grad_b
```

#### 优化技巧

为了提高梯度下降算法的收敛速度和效果，可以采用以下几种优化技巧：

1. **动量（Momentum）**：动量是一种累积梯度的方法，可以加速梯度下降过程。动量算法将当前梯度与先前梯度的加权平均作为新的梯度，从而减少梯度消失和振荡。
   $$
   v_t = \gamma v_{t-1} + (1 - \gamma) \nabla J(\theta_t)
   $$
   $$
   \theta_t = \theta_{t-1} - \alpha v_t
   $$
   其中，\(v_t\)是动量项，\(\gamma\)是动量系数。

2. **学习率调度（Learning Rate Scheduling）**：学习率调度是一种动态调整学习率的方法，可以在训练的早期阶段使用较大的学习率来加快收敛，在训练的后期阶段使用较小的学习率来避免过拟合。

3. **自适应学习率（Adaptive Learning Rate）**：自适应学习率方法可以自动调整学习率，以适应不同阶段的训练需求。常用的自适应学习率方法包括AdaGrad、RMSprop和Adam。

4. **批量归一化（Batch Normalization）**：批量归一化可以减少内部协变量转移，提高模型的稳定性和收敛速度。

#### 在AIGC技术中的应用

在AIGC技术中，梯度下降算法广泛应用于生成器和判别器的训练。以下是如何在AIGC技术中应用梯度下降算法的示例：

1. **生成器训练**：生成器旨在生成与真实数据相似的数据。通过计算生成数据与真实数据之间的损失函数，并使用梯度下降算法更新生成器参数，可以逐步提高生成数据的质量。

2. **判别器训练**：判别器旨在区分真实数据和生成数据。通过计算判别器的预测误差，并使用梯度下降算法更新判别器参数，可以提高判别器对生成数据的识别能力。

3. **协同训练**：生成器和判别器通过协同训练提高性能。在每轮迭代中，先固定一个网络的参数，更新另一个网络的参数。这种方法通过相互对抗的方式，使生成器生成的数据更加逼真，同时使判别器能够更准确地识别真实数据和生成数据。

通过这些应用，梯度下降算法在AIGC技术中发挥了关键作用，为生成高质量的内容提供了强有力的支持。随着算法的优化和改进，梯度下降算法在个性化职业发展规划和其他领域的AIGC应用中将继续发挥重要作用。

from tensorflow.keras.models import Sequential

# 生成器模型
def build_generator(z_dim):
    model = Sequential()
    model.add(Dense(128, input_shape=(z_dim,)))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Dense(256))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Dense(512))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Dense(1024))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Reshape((28, 28, 1)))
    model.add(Conv2D(128, kernel_size=(3, 3), strides=(2, 2), padding='same'))
    model.add(LeakyReLU(alpha=0.2))

    model.add(LeakyReLU(alpha=0.2))
    model.add(Conv2D(128, kernel_size=(3, 3), strides=(2, 2), padding='same'))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Conv2D(128, kernel_size=(3, 3), strides=(2, 2), padding='same'))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Conv2D(128, kernel_size=(3, 3), strides=(2, 2), padding='same'))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Flatten())
    model.add(Dense(10))  # 将输出映射到职业发展路径
    return model

def build_discriminator(img_shape):
    model = Sequential()
    model.add(Flatten(input_shape=img_shape))
    model.add(Dense(1024))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Dense(512))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Dense(256))
    model.add(LeakyReLU(alpha=0.2))
    model.add(Dense(1, activation='sigmoid'))

discriminator = build_discriminator(img_shape)
