Hartree-Fock自洽场方法（Hartree-Fock Self-Consistent Field method，HF-SCF）是一种常见的量子化学计算方法，用于求解分子的电子结构和能量。在HF-SCF方法中，自洽原理通过以下步骤实现：

3. **Fock矩阵计算**：利用电子密度矩阵，计算Fock矩阵。

4. **Hartree势计算**：通过Fock矩阵，计算每个电子所受到的Hartree势。

5. **波函数修正**：利用修正后的Hartree势，修正波函数。

6. **自洽迭代**：重复上述步骤，直到波函数和电子密度满足自洽条件，即Fock矩阵不变或者变化非常小。

```python
import numpy as np

# 初始化波函数和电子密度
def initialize_hf(mu, n_electrons, n_orbitals):
    # 创建初始波函数
    psi = np.eye(n_orbitals)[np.newaxis, :, :] * mu
    # 创建初始电子密度
    rho = np.zeros((n_orbitals, n_orbitals))
    rho[0, 0] = n_electrons
    return psi, rho

# 计算Fock矩阵
def compute_fock_matrix(rho, n_electrons, n_orbitals):
    # 创建Fock矩阵
    fock_matrix = np.zeros((n_orbitals, n_orbitals))
    # 计算对角元素
    fock_matrix += -1 / np.sqrt(rho.sum(axis=0))
    # 计算非对角元素
    fock_matrix += -1j * np.dot(rho, np.linalg.inv(np.eye(n_orbitals)))
    return fock_matrix

# 计算Hartree势
def compute_hartree_potential(rho, n_electrons, n_orbitals):
    # 创建Hartree势矩阵
    hartree_potential = np.zeros((n_orbitals, n_orbitals))
    # 计算对角元素
    hartree_potential += rho.sum(axis=0) / n_electrons
    return hartree_potential

# HF-SCF迭代过程
def hf_scf(psi, rho, n_electrons, n_orbitals, tolerance=1e-10, max_iterations=100):
    iteration = 0
    while iteration < max_iterations:
        # 计算Fock矩阵
        fock_matrix = compute_fock_matrix(rho, n_electrons, n_orbitals)
        # 计算Hartree势
        hartree_potential = compute_hartree_potential(rho, n_electrons, n_orbitals)
        # 修正波函数
        psi_new = np.linalg.solve(fock_matrix + hartree_potential, psi)
        # 计算新电子密度
        rho_new = np.dot(psi_new.T, psi_new)
        # 检查自洽条件
        if np.linalg.norm(rho_new - rho) < tolerance:
            break
        rho = rho_new
        psi = psi_new
        iteration += 1
    return psi, rho, iteration

# 示例：执行HF-SCF计算
mu = 0.5
n_electrons = 2
n_orbitals = 2
psi, rho, iterations = hf_scf(psi, rho, n_electrons, n_orbitals)
print("Final wavefunction:", psi)
print("Final electron density:", rho)
print("Iterations:", iterations)
```
