## 第6章 Self-Consistency CoT性能评估

### 6.1 性能评估指标

为了全面评估Self-Consistency CoT算法的性能，我们采用了一系列性能评估指标。这些指标包括：

1. **准确率（Accuracy）**：准确率是衡量模型预测结果与实际结果一致性的指标，计算公式为：
   \[ \text{Accuracy} = \frac{\text{预测正确的样本数}}{\text{总样本数}} \]

2. **精确率（Precision）**：精确率是衡量模型预测结果中实际为正样本的占比，计算公式为：
   \[ \text{Precision} = \frac{\text{预测正确且实际为正样本的样本数}}{\text{预测为正样本的样本数}} \]

3. **召回率（Recall）**：召回率是衡量模型预测结果中实际为正样本的占比，计算公式为：
   \[ \text{Recall} = \frac{\text{预测正确且实际为正样本的样本数}}{\text{实际为正样本的样本数}} \]

4. **F1值（F1 Score）**：F1值是精确率和召回率的调和平均值，计算公式为：
   \[ \text{F1 Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} \]

5. **均方误差（Mean Squared Error, MSE）**：均方误差是衡量预测结果与实际结果差异的指标，计算公式为：
   \[ \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2 \]
   其中，\( \hat{y}_i \) 是预测值，\( y_i \) 是实际值，\( n \) 是样本数量。

6. **决定系数（R-squared, R²）**：决定系数是衡量模型拟合优度的指标，计算公式为：
   \[ R^2 = 1 - \frac{\sum_{i=1}^{n} (\hat{y}_i - y_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2} \]
   其中，\( \bar{y} \) 是实际值的平均值。

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 数据预处理
def preprocess_data(data):
    # 数据清洗和标准化
    data = data.fillna(data.mean())
    data = (data - data.min()) / (data.max() - data.min())
    return data

# 模型初始化
def initialize_model():
    # 初始化模型参数
    model_params = {'weight': np.random.rand(), 'bias': np.random.rand()}
    return model_params

# 一致性检测
def check_consistency(model, data):
    # 检查模型内部一致性
    prediction = model['weight'] * data + model['bias']
    consistency = np.sum(prediction == data) / len(prediction)
    return consistency

# 参数优化
def optimize_params(model_params, data):
    # 使用梯度下降法优化参数
    for i in range(100):
        prediction = model_params['weight'] * data + model_params['bias']
        error = prediction - data
        model_params['weight'] -= error * 0.01
        model_params['bias'] -= error * 0.01
    return model_params

# 预测
def predict(model, data):
    # 根据模型参数进行预测
    prediction = model['weight'] * data + model['bias']
    return prediction

# 主函数
def main():
    # 加载数据
    data = pd.read_csv('data.csv')
    data = preprocess_data(data)
    
    # 划分训练集和测试集
    X_train, X_test, y_train, y_test = train_test_split(data[['feature']], data['target'], test_size=0.2)
    
    # 初始化模型
    model = initialize_model()
    
    # 一致性检测
    is_consistent = check_consistency(model, X_train)
    while not is_consistent:
        model = optimize_params(model, X_train)
        is_consistent = check_consistency(model, X_train)
    
    # 预测
    predictions = predict(model, X_test)
    
    # 计算准确率
    accuracy = accuracy_score(y_test, predictions)
    print(f'Accuracy: {accuracy:.2f}')

if __name__ == '__main__':
```
