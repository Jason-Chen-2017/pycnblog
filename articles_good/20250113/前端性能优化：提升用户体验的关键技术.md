**2.1 HTTP/HTTPS 性能优化**

**核心概念与联系**：

HTTP/HTTPS协议是前端资源加载的基础，性能优化主要集中在减少请求时间、压缩数据传输和减少重复请求等方面。

**算法原理讲解**：

- **请求压缩**：使用GZIP压缩响应数据，减少数据传输量。
- **缓存策略**：合理设置缓存过期时间，减少重复请求。
- **预加载**：预测用户行为，提前加载资源。

**数学公式使用**：

$$
\text{压缩前数据量} \times \text{压缩比} = \text{压缩后数据量}
$$

**Python源代码示例**：

```python
import requests
import gzip

def compress_data(url):
    response = requests.get(url)
    original_data = response.text
    compressed_data = gzip.compress(original_data.encode('utf-8'))
    return compressed_data

# 示例
url = "https://example.com/data.txt"
compressed_data = compress_data(url)
print("压缩前数据量：", len(original_data))
print("压缩后数据量：", len(compressed_data))
```

- **减少样式表体积**：压缩CSS文件，减少文件大小。

- **避免重绘与回流**：优化布局和样式，减少页面重绘和回流次数。

$$
\text{重绘次数} + \text{回流次数} = \text{渲染性能损失}
