## 第三部分：函数式编程（FP）

### 基本概念

函数式编程（Functional Programming，FP）是一种编程范式，它以函数作为基础，强调使用不可变数据和纯函数。与传统的面向对象编程（OOP）相比，FP具有独特的特点和优势。

#### 函数作为第一类对象

在FP中，函数被视为第一类对象，这意味着函数可以像其他数据类型（如整数、字符串等）一样被传递、存储和操作。这种特点使得函数可以更灵活地组合和复用，提高了代码的可读性和可维护性。

#### 高阶函数

高阶函数（Higher-order Function）是指能够接受其他函数作为参数或返回函数的函数。这种函数允许程序员将行为作为参数传递，从而实现更灵活和模块化的代码。例如，在Python中，`map()`、`filter()`和`reduce()`等函数都是高阶函数。

#### 闭包

闭包（Closure）是指一个函数及其所引用的环境。闭包允许函数访问并保持其定义时的环境，这使得函数可以记住并访问定义时的变量，从而实现更动态和灵活的编程。

#### 副作用与不可变性

在FP中，副作用（Side Effect）被认为是一种不良的编程习惯。副作用是指函数在执行过程中修改外部状态或产生不可预测的副作用。FP强调使用不可变数据，以减少副作用，提高代码的可预测性和可维护性。

### 与OOP的比较

#### FP的特点

- 强调函数的可组合性和复用性。
- 使用不可变数据，减少状态变化和副作用。
- 函数作为第一类对象，提高代码的灵活性和模块性。
- 支持高阶函数和闭包，实现更动态和灵活的编程。

#### OOP的特点

- 使用对象和类来组织代码，支持封装、继承和多态等特性。
- 强调数据和行为的一致性，通过对象来实现。
- 支持多线程和并发编程，通过对象的状态变化来实现。

#### FP与OOP的适用场景

- FP适用于数据处理、数学计算、算法设计等场景，特别是需要高可读性、高可维护性的场景。
- OOP适用于复杂系统开发、用户界面设计、实时系统等场景，特别是需要灵活性和扩展性的场景。

### FP在代码优化中的应用

#### 模式匹配

模式匹配（Pattern Matching）是一种用于匹配数据结构和值的机制。在FP中，模式匹配可以用于简化代码，提高可读性。例如，在Scala中，模式匹配可以用于解构数据结构，提取值并执行相应的操作。

#### 递归

递归（Recursion）是一种编程技巧，用于在函数中调用自身。在FP中，递归可以用于实现递归数据结构和算法，例如列表的遍历和树结构的递归遍历。

#### 函数组合与管道

函数组合（Function Composition）是一种将多个函数组合成一个新函数的技巧。在FP中，函数组合可以提高代码的模块性和复用性。管道（Pipeline）是函数组合的一种实现方式，它将多个函数连接起来，形成一个连续的数据处理流程。

### 小结

函数式编程（FP）是一种强大的编程范式，它通过强调函数、不可变数据和纯函数，提供了一种新的思考方式。FP在代码优化中具有广泛的应用，可以提高代码的可读性、可维护性和性能。在下一部分，我们将深入探讨FP中的代码优化技巧。

## 第四部分：FP中的代码优化

### 模式匹配

模式匹配是一种强大的编程工具，它允许我们将复杂的逻辑拆分为一系列简单的条件判断。在FP中，模式匹配可以用于解构数据、提取值并执行相应的操作。

#### Python中的模式匹配

Python中的模式匹配通过`match`语句实现。例如，我们可以使用模式匹配来解构一个列表，并根据不同的条件执行不同的操作：

```python
data = [1, 2, 3]

def process_data(data):
    match data:
        case [a, b, c]:
            return a + b + c
        case _:
            return "数据格式不正确"

print(process_data(data))
```

在这个例子中，我们使用模式匹配来处理一个包含三个元素的列表，并根据模式返回相应的结果。如果列表不符合模式，我们返回一个错误消息。

#### 应用场景

模式匹配在处理复杂的数据结构时非常有用。例如，在处理数据库查询结果或解析复杂的配置文件时，模式匹配可以帮助我们快速提取所需的数据，并执行相应的操作。

### 递归

递归是一种编程技巧，用于在函数中调用自身。在FP中，递归可以用于实现递归数据结构和算法，例如列表的遍历和树结构的递归遍历。

#### Python中的递归

Python中的递归通过函数的递归调用实现。例如，我们可以使用递归来计算斐波那契数列：

```python
def fibonacci(n):
    if n <= 1:
        return n
    else:
        return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(10))
```

在这个例子中，我们使用递归来计算斐波那契数列的第10个数字。

#### 应用场景

递归在处理递归数据结构时非常有用。例如，在处理树形数据结构（如文件系统、XML解析）时，递归可以帮助我们遍历并处理每个节点。

### 函数组合与管道

函数组合是一种将多个函数组合成一个新函数的技巧。在FP中，函数组合可以提高代码的模块性和复用性。管道（Pipeline）是函数组合的一种实现方式，它将多个函数连接起来，形成一个连续的数据处理流程。

#### Python中的管道

Python中的管道通过`functools.partial`函数实现。例如，我们可以使用管道来构建一个数据处理流程：

```python
from functools import partial

def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

def pipeline(func1, func2):
    return lambda x: func1(func2(x))

add_multiply = pipeline(add, multiply)

print(add_multiply(2, 3))  # 输出 8
```

在这个例子中，我们使用管道将`add`和`multiply`函数组合在一起，形成一个新函数`add_multiply`。

#### 应用场景

函数组合和管道在处理复杂的数据处理流程时非常有用。例如，在数据处理和机器学习应用中，我们可以使用函数组合和管道来构建复杂的数据处理管道，从而提高代码的可读性和可维护性。

### Python代码示例

下面是一个使用FP中代码优化技巧的Python代码示例：

```python
from functools import reduce

# 模式匹配
data = [1, 2, 3]
result = reduce(lambda x, y: x + y, data)
print(result)  # 输出 6

# 递归
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

print(factorial(5))  # 输出 120

# 管道
def apply_multiple(*functions):
    def pipeline(x):
        return reduce(lambda a, b: b(a), functions)(x)
    return pipeline

add_multiply = apply_multiple(lambda x: x + 1, lambda x: x * 2)
print(add_multiply(2))  # 输出 6
```

在这个例子中，我们使用了模式匹配、递归和管道等FP代码优化技巧，构建了一个简单但功能强大的数据处理流程。

def init_db():
    conn = sqlite3.connect("inventory.db")

    c.execute('''CREATE TABLE IF NOT EXISTS products
                 (name TEXT, quantity INT, price REAL)''')
    conn.commit()
    conn.close()

def add_product(name: str, quantity: int, price: float):
    conn = sqlite3.connect("inventory.db")
    c = conn.cursor()
    c.execute("INSERT INTO products (name, quantity, price) VALUES (?, ?, ?)", (name, quantity, price))
    conn.commit()
    conn.close()

def remove_product(name: str, quantity: int) -> Optional[str]:
    conn = sqlite3.connect("inventory.db")
    c = conn.cursor()
    c.execute("SELECT * FROM products WHERE name=?", (name,))
    result = c.fetchone()
    if result:
        if result[1] >= quantity:
            c.execute("UPDATE products SET quantity=quantity-? WHERE name=?", (quantity, name))
            conn.commit()
            conn.close()
            return "商品移除成功"
        else:
            conn.close()
            return "商品数量不足"
    else:
        conn.close()
        return "商品不存在"

def query_product(name: str) -> Optional[str]:
    conn = sqlite3.connect("inventory.db")
    c = conn.cursor()
    c.execute("SELECT * FROM products WHERE name=?", (name,))
    result = c.fetchone()
    if result:
        conn.close()
        return f"商品名称：{result[0]}, 数量：{result[1]}, 价格：{result[2]}"
    else:
        conn.close()
        return "商品不存在"

# 业务逻辑模块
def process_command(command: str) -> str:
    match command:
        case f"addProduct('{name}',['{quantity}', '{price}'])":
            return add_product(name, int(quantity), float(price))
        case f"removeProduct('{name}',['{quantity}'])":
            return remove_product(name, int(quantity))
        case f"queryProduct('{name}')":
            return query_product(name)
        case _:
            return "无效命令"

# 用户界面模块
def main():
    init_db()
    while True:
        command = input("请输入命令：")
        result = process_command(command)
        print(result)

if __name__ == "__main__":
    main()
