```python
# 感知信息
perception = np.array([0.3, 0.7])

# 处理信息
processed_info = np.dot(perception, np.array([0.5, 0.5]))

# 生成决策
decision = np.argmax(processed_info)

# 执行行动
action = np.random.choice([0, 1], p=processed_info)

# 评估结果
result = np.random.choice([0, 1], p=[0.4, 0.6])

# 反馈循环
if action == result:
    reward = 1
else:
    reward = 0

print(f"Decision: {decision}, Action: {action}, Result: {result}, Reward: {reward}")
```

在这个代码中，我们首先感知信息，然后处理信息以生成决策，接着执行行动并评估结果，最后通过反馈循环调整决策策略。
