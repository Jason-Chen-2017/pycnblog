#### 第2章：方法调用的概念

**2.1 方法调用简介**

方法调用是程序中函数或方法的使用和执行，它是编程语言的基本操作之一。在计算机科学中，方法调用是实现代码复用、模块化设计的重要手段。理解方法调用有助于我们深入理解编程语言的工作原理。

**2.2 方法调用属性特征对比**

为了更好地理解方法调用，我们需要对比不同方法调用之间的属性特征。以下是几种常见方法调用的属性对比：

| 方法调用类型 | 特征对比           | 说明                                                         |
| :----------: | :--------------- | :----------------------------------------------------------- |
| 静态方法调用 | 预编译、直接调用   | 在编译期间已知方法名称和参数类型，编译后直接调用               |
| 实例方法调用 | 动态绑定、实例调用 | 在运行时确定方法名称和参数类型，通过对象实例调用               |
| 局部方法调用 | 作用域限定         | 在函数内部调用，作用域仅限于函数内部                         |
| 静态绑定     | 编译时确定         | 方法调用在编译时就已经确定，无需运行时查找                   |
| 动态绑定     | 运行时确定         | 方法调用在运行时确定，支持多态和动态加载                     |

# library.py
class Library:
    def __init__(self, name, location):
        self.name = name
        self.location = location
        self.books = []
        self.users = []

    def add_book(self, book):
        self.books.append(book)

    def remove_book(self, book):
        self.books.remove(book)

    def add_user(self, user):
        self.users.append(user)

    def remove_user(self, user):
        self.users.remove(user)

# book.py
class Book:
    def __init__(self, title, author, isbn, available):
        self.title = title
        self.author = author
        self.isbn = isbn
        self.available = available

    def borrow(self, user):
        if self.available:
            self.available = False
            return Borrow(self, user)
        else:
            return None

    def return_book(self):
        self.available = True

# author.py
class Author:
    def __init__(self, name):
        self.name = name
        self.books = []

    def add_book(self, book):
        self.books.append(book)

    def remove_book(self, book):
        self.books.remove(book)

# library_card.py
class LibraryCard:
    def __init__(self, card_id, user):
        self.card_id = card_id
        self.user = user
        self.status = "active"

    def borrow_book(self, book):
        if self.status == "active":
            return book.borrow(self.user)
        else:
            return None

    def return_book(self, book):
        if self.status == "active":
            return book.return_book()
        else:
            return None

# user.py
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        self.library_card = None

    def issue_library_card(self, library):
        self.library_card = library.issue_library_card(self)

    def borrow_book(self, book):
        if self.library_card:
            return self.library_card.borrow_book(book)
        else:
            return None

    def return_book(self, book):
        if self.library_card:
            return self.library_card.return_book(book)
        else:
            return None

# borrow.py
class Borrow:
    def __init__(self, book, user):
        self.book = book
        self.user = user
        self.borrow_date = datetime.now()
        self.due_date = self.borrow_date + timedelta(days=14)

    def calculate_fine(self):
        return (datetime.now() - self.due_date).days * 1

# return.py
class Return:
    def __init__(self, book, user):
        self.book = book
        self.user = user
        self.return_date = datetime.now()
