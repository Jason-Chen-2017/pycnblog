### 第2章: 方法重载概述

#### 2.1 方法重载的概念与原理

##### 2.1.1 方法重载的定义

方法重载（Method Overloading）是面向对象编程中的一个重要特性。它允许在同一类中定义多个具有相同名称但参数类型或参数数量不同的方法。当调用方法时，编译器会根据参数的类型和数量来选择合适的方法执行。

##### 2.1.2 方法重载的实现机制

方法重载的实现依赖于编译器的静态类型检查。编译器会在编译时根据方法签名来确定调用哪个方法。这意味着方法重载不能依赖于运行时类型信息（即类型擦除），而必须依赖于参数的类型和数量。

##### 2.1.3 方法重载的优点与应用场景

方法重载的优点包括：

1. 提高了代码的可读性：通过为不同类型或数量的参数提供不同的方法，可以使得代码更加直观和易于理解。
2. 增强了代码的灵活性：方法重载允许在同一类中为不同情况提供不同的实现，增强了代码的适应性。
3. 避免了命名冲突：通过方法重载，可以为不同类型或数量的参数提供不同的方法名称，从而避免了命名冲突。

方法重载的应用场景包括：

1. 数据处理：在处理不同类型的数据时，可以通过方法重载提供针对不同数据类型的处理方法。
2. 函数库设计：在函数库中，可以通过方法重载为不同的参数类型提供不同的实现，从而提高函数库的灵活性和适用性。

##### 4.1.1 简单案例1：函数重载

在Java编程语言中，函数重载是一个常见的特性。以下是一个简单的函数重载案例：

class Calculator {

在这个案例中，`Calculator` 类中定义了两个名为 `add` 的方法。第一个 `add` 方法接收两个 `int` 类型的参数，第二个 `add` 方法接收两个 `double` 类型的参数。当调用 `calculator.add(5, 10)` 时，Java编译器会选择第一个 `add` 方法。当调用 `calculator.add(5.5, 10.5)` 时，Java编译器会选择第二个 `add` 方法。这体现了弗雷格的意义与指称理论在方法重载中的应用。

##### 4.1.2 中级案例2：方法重写

方法重写（Override）是面向对象编程中的另一个重要特性。在子类中，可以重写从父类继承的方法。以下是一个方法重写的案例：

```java
class Animal {
    public void makeSound() {
        System.out.println("动物发出声音");
    }
}

class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("狗汪汪叫");
    }
}

class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("猫喵喵叫");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal dog = new Dog();
        Animal cat = new Cat();
        dog.makeSound();
        cat.makeSound();
    }
}
```
