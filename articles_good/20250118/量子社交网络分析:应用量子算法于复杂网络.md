## 2.1 量子计算概述

### 2.1.1 量子比特与经典比特

量子比特（qubit）是量子计算的基本单位，与经典比特（classic bit）有着本质的不同。经典比特只能表示0或1两种状态，而量子比特可以同时处于0和1的叠加态。这种叠加态使得量子比特能够表示多种可能的状态，从而提高了计算效率。

量子比特的叠加态可以用一个向量来表示，称为量子态。例如，一个量子比特可以处于以下叠加态：

\[ \psi = \frac{1}{\sqrt{2}} |0\rangle + \frac{1}{\sqrt{2}} |1\rangle \]

其中，$|0\rangle$ 和 $|1\rangle$ 分别表示量子比特的基态。

此外，量子比特还可以处于两个或多个基态的纠缠态。例如，两个量子比特的纠缠态可以表示为：

\[ \psi = |00\rangle + |11\rangle \]

这种纠缠态使得量子比特之间的状态相互依赖，从而实现了量子计算中的并行计算能力。

### 2.1.2 量子比特的叠加态和纠缠态

量子比特的叠加态和纠缠态是量子计算的核心特性。叠加态使得量子比特能够同时表示多种可能的状态，从而提高了计算效率。例如，一个量子比特可以同时表示0和1两种状态，而两个量子比特可以同时表示4种状态（$|00\rangle$、$|01\rangle$、$|10\rangle$、$|11\rangle$）。

纠缠态进一步增强了量子比特的并行计算能力。两个或多个量子比特之间的纠缠态，使得它们的状态相互依赖。这种纠缠态可以用来实现量子并行计算，从而在多项式时间内解决某些经典算法难以处理的问题。

### 2.1.3 量子比特与经典比特的对比

量子比特与经典比特在以下方面有着本质的不同：

1. **状态表示**：经典比特只能表示0或1两种状态，而量子比特可以处于0和1的叠加态，甚至可以处于多个基态的纠缠态。
2. **计算效率**：量子计算可以利用叠加态和纠缠态实现并行计算，从而在多项式时间内解决某些经典算法难以处理的问题。而经典计算则需要逐步迭代，计算效率较低。
3. **存储容量**：量子比特的叠加态可以表示多种可能的状态，从而提高了存储容量。例如，一个量子比特可以表示2个经典比特的信息，而一个量子比特的叠加态可以表示多个经典比特的信息。
4. **量子纠错**：由于量子比特的叠加态和纠缠态易受外部干扰，量子计算中需要实现量子纠错机制，以保证计算结果的准确性。而经典计算则不需要考虑纠错问题。

## 2.2 量子门与量子电路

### 2.2.1 基础量子门

量子门是量子计算中的基本操作，类似于经典计算机中的逻辑门。量子门作用于量子比特，实现量子比特的状态变换。常见的量子门包括：

1. ** Hadamard门（H门）**：Hadamard门是量子计算中的基本门之一，可以将量子比特的基态$|0\rangle$ 转换为叠加态$\frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$。

\[ H|0\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) \]

2. **Pauli X门（X门）**：X门是作用于量子比特的翻转门，可以将量子比特的基态$|0\rangle$ 转换为$|1\rangle$，将$|1\rangle$ 转换为$|0\rangle$。

\[ X|0\rangle = |1\rangle \]
\[ X|1\rangle = |0\rangle \]

3. **Pauli Z门（Z门）**：Z门是作用于量子比特的相位翻转门，可以将量子比特的基态$|0\rangle$ 转换为$|0\rangle$，将$|1\rangle$ 转换为$-|1\rangle$。

\[ Z|0\rangle = |0\rangle \]
\[ Z|1\rangle = -|1\rangle \]

4. **Pauli Y门（Y门）**：Y门是作用于量子比特的另一个相位翻转门，可以将量子比特的基态$|0\rangle$ 转换为$-i|0\rangle$，将$|1\rangle$ 转换为$i|1\rangle$。

\[ Y|0\rangle = -i|0\rangle \]
\[ Y|1\rangle = i|1\rangle \]
