### 数学模型基础

数学模型是政治行为研究中的重要工具，它将政治现象转化为数学语言，以便进行定量分析和预测。本节将介绍数学模型的基本概念、结构和类型，并讨论其构建方法。

#### 数学模型的基本概念

数学模型是一种用数学语言描述现实世界的抽象结构，它包括变量、参数、假设和数学公式。在政治学中，数学模型通常涉及以下基本概念：

1. **变量**：变量是模型中的基本元素，用于表示政治行为中的不同因素，如选民投票意愿、政策效果等。
2. **参数**：参数是模型中的固定数值，它们决定了模型的特性。例如，逻辑斯蒂回归模型中的系数就是参数。
3. **假设**：假设是模型构建的基础，它们定义了模型中变量之间的关系。例如，博弈论模型中的纳什均衡假设。
4. **数学公式**：数学公式是模型的核心，它们将变量和参数之间的关系表达为数学形式。

#### 数学模型的结构与类型

数学模型的结构可以分为以下几个部分：

1. **输入**：输入是模型中需要预测或分析的变量。在政治学中，输入可能包括选民的特征、经济指标、政治事件等。
2. **处理**：处理是模型的核心部分，它将输入变量通过特定的数学公式进行处理，生成输出。处理过程可能涉及多种数学方法，如线性代数、概率论和统计学等。
3. **输出**：输出是模型预测或分析的结果，如选民投票结果、政策效果等。

数学模型的主要类型包括：

1. **统计模型**：统计模型是利用统计学方法对数据进行拟合和分析的模型。常见的统计模型包括线性回归、逻辑斯蒂回归、多元回归等。
2. **动态系统模型**：动态系统模型是描述变量随时间变化的模型，如微分方程模型。这些模型常用于分析政治过程的动态特性。
3. **博弈模型**：博弈模型用于分析个体或团体在相互竞争或合作中的策略选择，如纳什均衡模型。
4. **模拟模型**：模拟模型是通过模拟现实世界的过程来分析变量和结果之间的关系。这些模型常用于预测未来的政治行为。

#### 数学模型的构建方法

构建数学模型通常包括以下几个步骤：

1. **问题定义**：明确研究问题和目标，确定需要分析的变量和关系。
2. **数据收集**：收集与问题相关的数据，这些数据可以是定性的，也可以是定量的。
3. **模型假设**：根据问题定义和数据，提出合理的假设，这些假设将指导模型的选择和构建。
4. **模型构建**：根据假设，选择适当的数学方法，构建数学模型。这一步可能需要多次迭代和修正。
5. **模型验证**：使用验证数据集对模型进行验证，确保模型能够准确预测或解释政治行为。
6. **模型应用**：将模型应用于实际政治问题，进行分析和预测。

通过上述步骤，研究者可以构建出有效的数学模型，从而更好地理解政治行为，为政策制定提供科学依据。

### 政治选择的数学模型

在政治学研究中，政治选择是研究的核心问题之一。政治选择包括选民投票选择、政策制定者的决策过程以及政治互动中的策略选择。数学模型为这些复杂的选择过程提供了简明而精确的分析工具。

#### 逻辑斯蒂回归模型

逻辑斯蒂回归（Logistic Regression）是一种常用的统计模型，用于分析二分类或多分类变量的概率分布。在政治学中，逻辑斯蒂回归常用于预测选民投票行为。

**基本概念：**

逻辑斯蒂回归的模型公式如下：

$$\text{P}(Y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1X_1 + \beta_2X_2 + ... + \beta_nX_n)}}$$

其中：
- \( Y \) 是因变量，表示选民的投票选择（例如，1表示投票给候选人A，0表示投票给候选人B）。
- \( X_1, X_2, ..., X_n \) 是自变量，表示影响选民投票的各种因素（例如，选民的教育水平、收入、政策偏好等）。
- \( \beta_0, \beta_1, \beta_2, ..., \beta_n \) 是模型的系数，它们决定了自变量对因变量的影响程度。

**构建方法：**

逻辑斯蒂回归模型的构建通常包括以下步骤：

1. **数据收集**：收集关于选民投票行为的数据，包括选民的特征（自变量）和投票结果（因变量）。
2. **变量选择**：选择对选民投票有显著影响的变量作为自变量，可以使用统计方法（如卡方检验、方差分析等）进行变量选择。
3. **模型拟合**：使用最大似然估计（Maximum Likelihood Estimation，MLE）方法拟合逻辑斯蒂回归模型，计算出模型的系数。
4. **模型验证**：使用验证数据集对模型进行验证，评估模型的预测能力。

**示例：**

假设我们研究选民对某政治候选人的投票选择，根据调查数据，我们选择了以下自变量：

- 教育水平（高中以下、高中、本科及以上）
- 收入（低收入、中等收入、高收入）
- 政策偏好（保守、中间、自由）

构建逻辑斯蒂回归模型，得到以下公式：

$$\text{P}(Y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1X_1 + \beta_2X_2 + \beta_3X_3)}}$$

其中，系数 \(\beta_0, \beta_1, \beta_2, \beta_3\) 的估计结果如下：

- \(\beta_0 = -2.5\)
- \(\beta_1 = 1.2\)（高中相比高中以下）
- \(\beta_2 = 0.8\)（本科及以上相比高中）
- \(\beta_3 = 1.0\)（高收入相比低收入）

根据模型，可以计算出不同自变量的组合下，选民投票给候选人的概率。例如，一个具有高中教育水平、中等收入和中间政策偏好的选民，其投票给候选人的概率为：

$$\text{P}(Y=1) = \frac{1}{1 + e^{(-2.5 + 1.2 \cdot 1 + 0.8 \cdot 0 + 1.0 \cdot 1)}} \approx 0.655$$

#### 多元逻辑斯蒂回归模型

多元逻辑斯蒂回归模型可以处理多分类因变量。在政治学中，例如，可以用于分析选民在不同政治派别之间的选择。

**基本概念：**

多元逻辑斯蒂回归的模型公式如下：

$$\text{P}(Y=k) = \frac{e^{(\beta_{0k} + \beta_{1k}X_1 + \beta_{2k}X_2 + ... + \beta_{nk}X_n)}}{\sum_{i=1}^K e^{(\beta_{0i} + \beta_{1i}X_1 + \beta_{2i}X_2 + ... + \beta_{ni}X_n)}}$$

其中：
- \( Y \) 是多分类因变量，\( K \) 是类别数量。
- \( X_1, X_2, ..., X_n \) 是自变量。
- \( \beta_{0k}, \beta_{1k}, \beta_{2k}, ..., \beta_{nk} \) 是模型系数，分别对应于每个类别的回归系数。

**构建方法：**

与二分类逻辑斯蒂回归类似，多元逻辑斯蒂回归模型的构建也分为数据收集、变量选择、模型拟合和模型验证等步骤。

**示例：**

假设我们要分析选民对三个政治派别的选择：保守派、中间派和自由派。根据调查数据，我们选择了以下自变量：

- 教育水平（高中以下、高中、本科及以上）
- 政策偏好（保守、中间、自由）

构建多元逻辑斯蒂回归模型，得到以下公式：

$$\text{P}(Y=1) = \frac{e^{(\beta_{01} + \beta_{11}X_1 + \beta_{21}X_2)}}{\sum_{i=1}^3 e^{(\beta_{0i} + \beta_{1i}X_1 + \beta_{2i}X_2)}}$$
$$\text{P}(Y=2) = \frac{e^{(\beta_{02} + \beta_{12}X_1 + \beta_{22}X_2)}}{\sum_{i=1}^3 e^{(\beta_{0i} + \beta_{1i}X_1 + \beta_{2i}X_2)}}$$
$$\text{P}(Y=3) = \frac{e^{(\beta_{03} + \beta_{13}X_1 + \beta_{23}X_2)}}{\sum_{i=1}^3 e^{(\beta_{0i} + \beta_{1i}X_1 + \beta_{2i}X_2)}}$$

其中，系数 \(\beta_{0i}, \beta_{1i}, \beta_{2i}\) 的估计结果如下：

- \(\beta_{01} = -3.0\)
- \(\beta_{11} = 1.5\)（高中相比高中以下）
- \(\beta_{21} = 0.5\)（本科及以上相比高中）

根据模型，可以计算出不同自变量的组合下，选民选择不同政治派别的概率。例如，一个具有高中教育水平、保守政策偏好的选民，其选择保守派、中间派和自由派的概率分别为：

$$\text{P}(Y=1) = \frac{e^{(-3.0 + 1.5 \cdot 1 + 0.5 \cdot 0)}}{\sum_{i=1}^3 e^{(-3.0 + 1.5 \cdot 1 + 0.5 \cdot 0)}} \approx 0.400$$
$$\text{P}(Y=2) = \frac{e^{(-3.0 + 1.5 \cdot 0 + 0.5 \cdot 1)}}{\sum_{i=1}^3 e^{(-3.0 + 1.5 \cdot 0 + 0.5 \cdot 1)}} \approx 0.300$$
$$\text{P}(Y=3) = \frac{e^{(-3.0 + 1.5 \cdot 0 + 0.5 \cdot 1)}}{\sum_{i=1}^3 e^{(-3.0 + 1.5 \cdot 0 + 0.5 \cdot 1)}} \approx 0.300$$

通过逻辑斯蒂回归模型，研究者可以分析选民在不同政治派别之间的选择，以及影响这些选择的因素。

### 政治影响力的数学模型

在政治学中，政治影响力是指政治实体（如政府、政党、个人等）在决策过程中所产生的影响。理解政治影响力对于分析政策制定、政治互动和权力结构具有重要意义。数学模型为分析政治影响力提供了一种定量和结构化的方法。

#### 基本概念

政治影响力模型旨在量化不同政治实体在决策过程中的影响力。这些模型通常涉及以下基本概念：

1. **影响力**：影响力是指一个政治实体在决策过程中对其他实体的影响程度。
2. **权力**：权力是影响力的一种表现形式，它表示一个实体能够控制或影响其他实体的能力。
3. **网络**：政治网络是由政治实体及其相互作用构成的复杂系统。通过分析政治网络，可以更好地理解政治影响力的传递和分布。

#### 政治影响力模型

政治影响力模型通常采用线性回归模型来描述不同政治实体的影响力。以下是一个简单的政治影响力模型：

$$I_j = \alpha_j + \beta_1X_{1j} + \beta_2X_{2j} + ... + \beta_nX_{nj}$$

其中：
- \(I_j\) 是政治实体j的影响力。
- \(\alpha_j\) 是政治实体j的初始影响力。
- \(X_{1j}, X_{2j}, ..., X_{nj}\) 是影响实体j影响力的变量，如选民的投票意愿、政治网络的权重等。
- \(\beta_1, \beta_2, ..., \beta_n\) 是影响系数，用于量化每个变量对影响力的影响程度。

#### 构建方法

构建政治影响力模型通常包括以下步骤：

1. **数据收集**：收集与政治实体及其影响力相关的数据，包括政治实体之间的互动关系、选民投票数据等。
2. **变量选择**：选择对政治影响力有显著影响的变量。可以使用统计方法（如相关性分析、回归分析等）进行变量选择。
3. **模型拟合**：使用线性回归方法拟合政治影响力模型，计算出模型系数。
4. **模型验证**：使用验证数据集对模型进行验证，评估模型的预测能力。

#### 示例

假设我们要分析一个政治系统中三个政治实体A、B和C的影响力。我们选择以下变量：

- 选民A对实体A的支持率（X1）
- 选民B对实体B的支持率（X2）
- 政治网络中实体A到实体B的权重（X3）

构建线性回归模型，得到以下公式：

$$I_A = \alpha_A + \beta_1X_1 + \beta_2X_2 + \beta_3X_3$$
$$I_B = \alpha_B + \beta_1X_1 + \beta_2X_2 + \beta_3X_3$$
$$I_C = \alpha_C + \beta_1X_1 + \beta_2X_2 + \beta_3X_3$$

其中，系数 \(\alpha_A, \alpha_B, \alpha_C, \beta_1, \beta_2, \beta_3\) 的估计结果如下：

- \(\alpha_A = 1.0\)
- \(\alpha_B = 0.5\)
- \(\alpha_C = 0.5\)
- \(\beta_1 = 0.3\)（选民A对实体A的支持率）
- \(\beta_2 = 0.2\)（选民B对实体B的支持率）
- \(\beta_3 = 0.1\)（政治网络中实体A到实体B的权重）

根据模型，可以计算出不同变量组合下，每个政治实体的影响力。例如，当选民A对实体A的支持率为60%，选民B对实体B的支持率为40%，政治网络中实体A到实体B的权重为0.4时，三个政治实体的影响力分别为：

$$I_A = 1.0 + 0.3 \cdot 0.6 + 0.2 \cdot 0.4 + 0.1 \cdot 0.4 \approx 1.18$$
$$I_B = 0.5 + 0.3 \cdot 0.6 + 0.2 \cdot 0.4 + 0.1 \cdot 0.4 \approx 0.78$$
$$I_C = 0.5 + 0.3 \cdot 0.6 + 0.2 \cdot 0.4 + 0.1 \cdot 0.4 \approx 0.78$$

通过政治影响力模型，研究者可以分析不同政治实体在决策过程中的影响力，以及影响这些影响力的关键因素。

### 政治互动的数学模型

在政治学中，政治互动是政治行为的重要组成部分，涉及不同政治实体之间的合作与竞争。数学模型为分析政治互动提供了结构化和量化的方法，帮助我们理解政治互动的动态过程和结果。

#### 基本原理

政治互动的数学模型通常基于博弈论（Game Theory），特别是合作博弈（Cooperative Game Theory）。合作博弈模型分析多个参与者在资源分配、权力博弈和合作决策中的策略选择。

#### 合作博弈模型

合作博弈模型的基本概念包括：

1. **参与者**：博弈中的参与个体，可以是政府、政党、个人等。
2. **联盟**：参与者通过合作形成的团体。
3. **效用**：参与者在合作中获得的收益。
4. **策略**：参与者为达成目标而采取的行动。

合作博弈模型通常使用以下公式描述：

$$\sum_{i=1}^N u_i(x) = C$$
$$\sum_{i=1}^N x_{ij} = 1$$

其中：
- \(N\) 是参与者数量。
- \(u_i(x)\) 是参与者i的效用函数，表示参与者在联盟x中的收益。
- \(C\) 是总收益。
- \(x_{ij}\) 是二元变量，表示参与者i是否属于联盟j。

#### 构建方法

构建合作博弈模型通常包括以下步骤：

1. **定义参与者**：确定博弈中的参与者及其角色。
2. **确定联盟**：根据参与者之间的互动关系，定义可能的联盟。
3. **设定效用函数**：根据参与者利益，设定效用函数，描述参与者在不同联盟中的收益。
4. **模型优化**：使用优化方法，如线性规划、非线性规划等，求解最佳联盟结构。

#### 示例

假设有两个政治实体A和B，他们通过合作来分配公共资源。我们定义以下变量：

- \(u_A(x)\)：实体A的效用函数，表示实体A在联盟x中的收益。
- \(u_B(x)\)：实体B的效用函数，表示实体B在联盟x中的收益。
- \(C\)：总收益。

构建合作博弈模型，得到以下公式：

$$u_A(x) = 0.6x + 0.4(1 - x)$$
$$u_B(x) = 0.4x + 0.6(1 - x)$$

其中，\(x\) 表示实体A在联盟中的参与比例。

根据模型，可以计算出不同联盟结构下，实体A和B的效用。例如，当实体A在联盟中的参与比例为60%时，实体A和实体B的效用分别为：

$$u_A(0.6) = 0.6 \cdot 0.6 + 0.4 \cdot 0.4 = 0.36 + 0.16 = 0.52$$
$$u_B(0.6) = 0.4 \cdot 0.6 + 0.6 \cdot 0.4 = 0.24 + 0.24 = 0.48$$

通过合作博弈模型，研究者可以分析政治实体在不同联盟结构中的效用，以及最佳联盟选择。

### 政治决策的数学模型

政治决策是政治行为的核心，涉及政府、政党、官员在不同情境下的策略选择。数学模型为政治决策提供了结构化和量化的分析工具，帮助理解决策过程和优化策略。

#### 基本原理

政治决策模型通常基于多属性决策理论（Multi-Attribute Decision Making），考虑多个决策因素，并量化这些因素的权重和偏好。以下是一个简单的多属性决策模型：

$$Z_i = \sum_{j=1}^M w_jX_{ij}$$

其中：
- \(Z_i\) 是决策方案i的总得分。
- \(w_j\) 是决策因素j的权重。
- \(X_{ij}\) 是决策因素j在方案i中的评分。

#### 构建方法

构建政治决策模型通常包括以下步骤：

1. **确定决策因素**：识别影响决策的各个因素，如政策效果、经济成本、社会影响等。
2. **设定权重**：根据决策因素的重要性，设定各因素的权重。
3. **评分**：为每个决策方案在各个决策因素上进行评分。
4. **计算得分**：使用权重和评分计算每个方案的总得分。
5. **决策优化**：根据得分选择最优决策方案。

#### 示例

假设我们需要为三个政策方案（A、B和C）进行决策，考虑以下决策因素：

- 政策效果（高、中、低）
- 经济成本（高、中、低）
- 社会影响（高、中、低）

设定各因素的权重如下：

- 政策效果：权重为0.5
- 经济成本：权重为0.3
- 社会影响：权重为0.2

评分如下：

- 政策效果：方案A为高，方案B为中，方案C为低
- 经济成本：方案A为中，方案B为低，方案C为高
- 社会影响：方案A为低，方案B为中，方案C为高

根据模型，可以计算出每个方案的总得分：

$$Z_A = 0.5 \cdot 0.5 + 0.3 \cdot 0.5 + 0.2 \cdot 0.5 = 0.25 + 0.15 + 0.1 = 0.5$$
$$Z_B = 0.5 \cdot 0.5 + 0.3 \cdot 0.5 + 0.2 \cdot 0.5 = 0.25 + 0.15 + 0.1 = 0.5$$
$$Z_C = 0.5 \cdot 0.5 + 0.3 \cdot 0.5 + 0.2 \cdot 0.5 = 0.25 + 0.15 + 0.1 = 0.5$$

根据得分，我们可以选择最优方案。在这个例子中，所有方案得分相同，因此无法直接选择最优方案。但通过这个模型，我们可以更清晰地分析各个决策因素对政策方案的影响，为进一步优化提供依据。

### 政治行为的模拟与预测

在政治学研究中，模拟和预测政治行为是重要的任务，可以帮助研究者理解和预测政治现象。数学模型为政治行为的模拟与预测提供了有效的工具。以下将介绍政治行为模拟与预测的方法和模型。

#### 政治行为模拟的方法

政治行为模拟是指通过数学模型模拟政治行为的过程，从而预测政治结果。常见的模拟方法包括：

1. **蒙特卡洛模拟**：蒙特卡洛模拟通过随机抽样和累积计算来模拟政治行为。这种方法可以用于预测选举结果、政策影响等。

2. **系统动力学模拟**：系统动力学模拟通过微分方程描述政治系统的动态变化，模拟政治行为的长期趋势。这种方法适用于分析政策的影响和累积效应。

3. ** Agent-Based 模拟**：Agent-Based 模拟通过模拟个体行为和相互作用来分析整体政治现象。这种方法适用于分析政治互动和群体行为。

#### 政治行为预测的模型

政治行为预测模型是通过数学模型预测政治行为的结果。常见的预测模型包括：

1. **逻辑斯蒂回归模型**：逻辑斯蒂回归模型用于预测选民投票行为。通过分析选民的特征和变量，预测选民对候选人的投票倾向。

2. **时间序列模型**：时间序列模型通过分析历史数据，预测未来政治事件的时间序列变化。常见的时间序列模型包括ARIMA、AR、MA、ARMA等。

3. **神经网络模型**：神经网络模型通过学习历史数据，预测政治行为的结果。神经网络可以用于分类和回归任务，例如预测选举结果、政策影响等。

#### 示例

以下是一个简单的逻辑斯蒂回归模型用于预测选民投票行为的示例。

假设我们要预测选民对某政治候选人的投票行为，根据调查数据，我们选择了以下自变量：

- 教育水平（高中以下、高中、本科及以上）
- 收入（低收入、中等收入、高收入）
- 政策偏好（保守、中间、自由）

构建逻辑斯蒂回归模型，得到以下公式：

$$\text{P}(Y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1X_1 + \beta_2X_2 + \beta_3X_3)}}$$

其中，系数 \(\beta_0, \beta_1, \beta_2, \beta_3\) 的估计结果如下：

- \(\beta_0 = -2.5\)
- \(\beta_1 = 1.2\)（高中相比高中以下）
- \(\beta_2 = 0.8\)（本科及以上相比高中）
- \(\beta_3 = 1.0\)（高收入相比低收入）

根据模型，可以计算出不同自变量的组合下，选民投票给候选人的概率。例如，一个具有高中教育水平、中等收入和中间政策偏好的选民，其投票给候选人的概率为：

$$\text{P}(Y=1) = \frac{1}{1 + e^{(-2.5 + 1.2 \cdot 1 + 0.8 \cdot 0 + 1.0 \cdot 1)}} \approx 0.655$$

通过逻辑斯蒂回归模型，研究者可以预测选民在不同情境下的投票行为，为政策制定和选举策略提供依据。

#### 案例一：选举分析

选举分析是政治行为研究中最常见的应用场景之一。逻辑斯蒂回归模型在选举预测中发挥了重要作用。以下是一个具体的选举分析案例。

假设我们研究一个多党选举的情况，其中三个主要政党为A、B和C。根据选举前的一项民意调查，我们收集了以下数据：

- 选民教育水平：高中以下、高中、本科及以上
- 选民收入：低收入、中等收入、高收入
- 选民政策偏好：保守、中间、自由

我们构建了多元逻辑斯蒂回归模型，预测选民在三个政党之间的投票选择。模型公式如下：

$$\text{P}(Y=1) = \frac{e^{(\beta_{01} + \beta_{11}X_1 + \beta_{21}X_2)}}{\sum_{i=1}^3 e^{(\beta_{0i} + \beta_{1i}X_1 + \beta_{2i}X_2)}}$$
$$\text{P}(Y=2) = \frac{e^{(\beta_{02} + \beta_{12}X_1 + \beta_{22}X_2)}}{\sum_{i=1}^3 e^{(\beta_{0i} + \beta_{1i}X_1 + \beta_{2i}X_2)}}$$
$$\text{P}(Y=3) = \frac{e^{(\beta_{03} + \beta_{13}X_1 + \beta_{23}X_2)}}{\sum_{i=1}^3 e^{(\beta_{0i} + \beta_{1i}X_1 + \beta_{2i}X_2)}}$$

根据模型估计结果，得到以下预测概率：

| 教育水平 | 政策偏好 | 预测概率 |
| --- | --- | --- |
| 高中以下 | 保守 | 0.4 |
| 高中 | 中间 | 0.5 |
| 本科及以上 | 自由 | 0.6 |

根据模型预测，一个具有高中教育水平和中间政策偏好的选民，更有可能投票给政党B。通过这样的预测，政治分析者可以为选举策略提供科学依据，预测选举结果，为政党制定竞选策略。

#### 案例二：政策影响力分析

政策影响力分析是另一个重要的政治行为研究应用。通过构建政治影响力模型，研究者可以分析政策对政治实体和社会的影响。

假设我们研究一项新的社会福利政策对选民支持率的影响。我们选择了以下变量：

- 社会福利政策满意度：高、中、低
- 选民收入水平：低收入、中等收入、高收入

构建线性回归模型，得到以下公式：

$$I_j = \alpha_j + \beta_1X_1 + \beta_2X_2$$

其中，\(I_j\) 是选民对政策的影响力，\(X_1\) 是社会福利政策满意度，\(X_2\) 是选民收入水平。

根据模型估计结果，得到以下系数：

- \(\alpha_j = 1.0\)
- \(\beta_1 = 0.3\)（满意度高）
- \(\beta_2 = -0.1\)（收入高）

根据模型，可以计算出不同变量组合下的选民影响力。例如，一个满意度高且收入低的选民，其对政策的影响力为：

$$I_j = 1.0 + 0.3 \cdot 1 + (-0.1) \cdot 0 = 1.2$$

通过这样的分析，研究者可以了解政策对社会和选民的影响，为政策调整和优化提供依据。

#### 案例三：政治互动分析

政治互动分析关注不同政治实体之间的互动关系。通过构建合作博弈模型，研究者可以分析政治互动的动态过程和结果。

假设我们研究两个政治实体A和B之间的合作决策。我们选择了以下变量：

- 实体A的投入：高、中、低
- 实体B的投入：高、中、低

构建合作博弈模型，得到以下公式：

$$\sum_{i=1}^2 u_i(x) = C$$
$$\sum_{i=1}^2 x_{ij} = 1$$

其中，\(u_i(x)\) 是实体i的效用函数，\(x_{ij}\) 是实体i在联盟j中的投入比例。

根据模型估计结果，得到以下效用函数：

$$u_1(x) = 0.5x + 0.5(1 - x)$$
$$u_2(x) = 0.5x + 0.5(1 - x)$$

根据模型，可以计算出不同投入组合下的实体效用。例如，当实体A和实体B的投入均为中等时，实体A和实体B的效用分别为：

$$u_1(0.5) = 0.5 \cdot 0.5 + 0.5 \cdot 0.5 = 0.5$$
$$u_2(0.5) = 0.5 \cdot 0.5 + 0.5 \cdot 0.5 = 0.5$$

通过这样的分析，研究者可以了解不同政治实体在合作决策中的效用和互动关系，为政治合作提供依据。
