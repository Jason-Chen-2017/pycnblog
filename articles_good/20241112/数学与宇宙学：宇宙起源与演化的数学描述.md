#### 宇宙膨胀

宇宙膨胀是指宇宙中的所有物质和空间都在不断地向外扩展。这个概念最早由埃德温·哈勃在20世纪20年代提出，他的观测结果表明，几乎所有的星系都在相互远离。这种膨胀可以通过哈勃定律来描述，即星系的退行速度与其距离成正比。哈勃定律的数学表达式为：

$$ v = H_0 \cdot d $$

其中，$v$ 是星系的退行速度，$H_0$ 是哈勃常数，$d$ 是星系的距离。这个公式表明，宇宙的膨胀速度是均匀的，并且在过去和未来都是恒定的。

暗物质的数学描述通常使用拉格朗日方程，该方程描述了在引力场中的质点运动。在考虑暗物质的情况下，拉格朗日方程可以写为：

$$ \frac{d^2}{dt^2} \mathbf{r} = -\nabla \Phi $$

其中，$\mathbf{r}$ 是质点的位置向量，$\Phi$ 是引力势。

#### 广义相对论

广义相对论是由阿尔伯特·爱因斯坦在1915年提出的一种描述引力的理论。它将引力视为时空的曲率，而不是一种传统意义上的力。广义相对论的核心是爱因斯坦场方程，该方程描述了物质和能量如何影响时空的几何形状。

在宇宙学中，广义相对论被用来研究宇宙的膨胀、黑洞、宇宙背景辐射等现象。一个典型的例子是哈勃-勒梅特-邦迪模型（Hubble-Lemaitre-Bondi model），该模型使用广义相对论来描述宇宙的膨胀。哈勃定律是哈勃-勒梅特-邦迪模型的基础，它表明宇宙中的星系正在以恒定的速度相互远离。

**爱因斯坦场方程**：

$$ R_{\mu \nu} - \frac{1}{2} R g_{\mu \nu} + \Lambda g_{\mu \nu} = \frac{8 \pi G}{c^4} T_{\mu \nu} $$

其中，$R_{\mu \nu}$ 是里奇张量，$R$ 是里奇标量，$g_{\mu \nu}$ 是度规张量，$\Lambda$ 是宇宙学常数，$G$ 是引力常数，$c$ 是光速，$T_{\mu \nu}$ 是能量-动量张量。

在宇宙学中，量子场论被用来研究宇宙的早期阶段，如宇宙微波背景辐射（Cosmic Microwave Background，CMB）和宇宙大爆炸。量子场论的一个关键概念是真空涨落（Vacuum Fluctuations），这些涨落被认为是大爆炸后宇宙结构形成的基础。

**量子场论的数学框架**：

**伪代码示例：宇宙膨胀模型拟合**

```python
import numpy as np
import scipy.optimize as opt

# 定义宇宙膨胀模型
def HubbleLaw(z):
    H0 = 70  # 假设的哈勃常数
    return H0 * z

# 定义拟合函数
def fit_function(params, z, v):
    H0 = params[0]
    return HubbleLaw(z) - v

# 定义观测数据
z = np.array([0.01, 0.1, 0.5])  # 红移值
v = np.array([30, 100, 250])  # 退行速度

# 拟合参数
params = opt.curve_fit(fit_function, z, v)

# 输出拟合结果
print("Fitted Hubble constant:", params[0])
```

**数学公式解释：弗里德曼方程**

$$ \dot{a}^2 + \frac{8 \pi G}{3} \rho a^2 = \frac{c^2}{R^2} $$

这个公式描述了宇宙尺度因子的动态行为。$a$ 是宇宙尺度因子，$\rho$ 是宇宙的总能量密度，$G$ 是引力常数，$c$ 是光速，$R$ 是宇宙的曲率半径。

**数学公式示例：哈勃常数计算**

$$ H_0 = \frac{v}{d} $$

这个公式用于计算哈勃常数。$v$ 是星系的退行速度，$d$ 是星系的距离。
