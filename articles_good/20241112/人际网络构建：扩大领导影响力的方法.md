```python
# 定义图的数据结构
class Graph:
    def __init__(self, nodes, edges):
        self.nodes = nodes
        self.edges = edges
        self.adjacency_matrix = [[0 for _ in range(len(nodes))] for _ in range(len(nodes))]

    # 填充邻接矩阵
    def fill_adjacency_matrix(self):
        for edge in self.edges:
            self.adjacency_matrix[edge[0]][edge[1]] = 1
            self.adjacency_matrix[edge[1]][edge[0]] = 1

    # 打印邻接矩阵
    def print_adjacency_matrix(self):
        for row in self.adjacency_matrix:
            print(row)
```

#### 图的优化

```python
# 最短路径算法（Dijkstra）
def dijkstra(graph, start):
    distances = [float('inf')] * len(graph.nodes)
    distances[start] = 0
    visited = [False for _ in range(len(graph.nodes))]

    for _ in range(len(graph.nodes)):
        min_distance = float('inf')
        min_index = -1

        for i in range(len(graph.nodes)):
            if not visited[i] and distances[i] < min_distance:
                min_distance = distances[i]
                min_index = i

        visited[min_index] = True

        for i in range(len(graph.nodes)):
            if graph.adjacency_matrix[min_index][i] > 0 and (distances[i] > distances[min_index] + graph.adjacency_matrix[min_index][i]):
                distances[i] = distances[min_index] + graph.adjacency_matrix[min_index][i]

    return distances

# 社交网络中的影响力传播
def influence_spread(graph, start, threshold):
    influenced = [False for _ in range(len(graph.nodes))]
    queue = deque([start])

    while queue:
        node = queue.popleft()
        if not influenced[node]:
            influenced[node] = True
            if influenced.count(True) >= threshold:
                return True

            neighbors = [i for i, x in enumerate(graph.adjacency_matrix[node]) if x == 1]
            queue.extend([node for node in neighbors if not influenced[node]])

    return False
```

### 数学模型与公式

在人际网络构建中，理解网络密度和中心性的数学模型是非常重要的。以下将详细讲解这两个概念，并使用LaTeX格式展示相关的公式。

#### 网络密度

网络密度是衡量人际网络紧密程度的一个指标，通常用以下公式表示：

$$ \rho = \frac{m}{n(n-1)} $$

其中，$\rho$ 表示网络密度，$m$ 表示边的数量，$n$ 表示节点的数量。网络密度越高，表示节点之间的联系越紧密。

#### 中心性

中心性是衡量节点在网络中的重要程度的指标。以下是三种常见的中心性指标：度中心性、介数中心性和紧密中心性。

1. **度中心性**

度中心性（Degree Centrality）是节点拥有的边的数量。其公式如下：

$$ C_d(v) = \deg(v) $$

其中，$C_d(v)$ 表示节点$v$的度中心性，$\deg(v)$ 表示节点$v$的度（即节点$v$连接的边的数量）。

2. **介数中心性**

介数中心性（Closeness Centrality）是节点到其他所有节点的最短路径长度之和的倒数。其公式如下：

$$ C_c(v) = \sum_{u \in V} \text{dist}(u, v) $$

其中，$C_c(v)$ 表示节点$v$的介数中心性，$V$ 是节点集合，$\text{dist}(u, v)$ 是从节点$u$到节点$v$的最短路径长度。

3. **紧密中心性**

紧密中心性（Betweenness Centrality）是节点出现在所有最短路径中的频率。其公式如下：

$$ C_b(v) = \frac{\sum_{i \neq j} \text{numPaths}(i, j, v)}{ \text{numPaths}(i, j) } $$

其中，$C_b(v)$ 表示节点$v$的紧密中心性，$\text{numPaths}(i, j, v)$ 是从节点$i$到节点$j$经过节点$v$的最短路径数量，$\text{numPaths}(i, j)$ 是从节点$i$到节点$j$的最短路径总数。

#### 公式与解释

以下是以上公式的LaTeX表示：

```latex
\begin{align*}
\rho &= \frac{m}{n(n-1)} \\
C_d(v) &= \deg(v) \\
C_c(v) &= \sum_{u \in V} \text{dist}(u, v) \\
C_b(v) &= \frac{\sum_{i \neq j} \text{numPaths}(i, j, v)}{ \text{numPaths}(i, j) }
\end{align*}
```

通过理解这些数学模型和公式，我们可以更深入地分析人际网络的紧密程度和节点的重要性，从而制定更有效的构建策略。
