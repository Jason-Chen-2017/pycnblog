##### 源代码实现

我们使用Spring Boot来构建电商平台的核心功能。以下是用户注册模块的主要代码：

```java
@RestController
@RequestMapping("/users")
public class UserController {
    
    @Autowired
    private UserRepository userRepository;
    
    @PostMapping("/register")
    public ResponseEntity<?> registerUser(@RequestBody UserRegistrationRequest request) {
        if (userRepository.existsByUsername(request.getUsername())) {
            return ResponseEntity.badRequest().body("Error: Username is already taken!");
        }
        
        User user = new User(request.getUsername(), request.getPassword());
        userRepository.save(user);
        
        return ResponseEntity.ok("User registered successfully!");
    }
}
```

##### 代码解读

在上面的代码中，`UserController` 处理用户注册的HTTP请求。`@RestController` 注解表示这是一个RESTful控制器，`@RequestMapping` 注解定义了请求路径。`@Autowired` 注解用于注入`UserRepository`，用于操作用户数据。

`registerUser` 方法接收一个`UserRegistrationRequest` 对象，检查用户名是否已存在。如果不存在，则创建一个新的`User` 对象并将其保存到数据库中。如果用户名已存在，则返回错误消息。
