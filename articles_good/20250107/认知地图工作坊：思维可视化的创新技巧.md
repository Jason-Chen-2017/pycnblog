### 第1章：认知地图概述

#### 认知地图的定义、类型及其重要性

认知地图是一种用于表示个体对环境、知识和信息的理解和组织方式的心理模型。它起源于地理学，后来被认知心理学广泛采用。认知地图的核心思想是，个体通过创建和更新认知地图来理解复杂的环境和情境，从而进行有效的导航、规划和决策。

**1.1 认知地图的定义**

认知地图可以被定义为一种内在的心理图像或框架，它帮助我们组织、存储和处理信息，形成一个关于环境、知识和信息的抽象表示。这种表示不仅包括物理空间信息，如位置、路径和边界，还包括抽象概念、关系和知识结构。

**1.2 认知地图的类型**

认知地图可以分为多种类型，根据其表示的信息和组织方式的不同，可以有以下几种分类：

1. **文字型认知地图**：以文字为主，通过关键词、短语和句子来组织信息。这种类型的认知地图常见于笔记、文档和记忆术中。
2. **图像型认知地图**：以图像为主，通过图形、符号和颜色来表示信息。这种类型的认知地图在思维导图中非常常见，有助于提高信息的视觉识别和记忆。
3. **多媒体认知地图**：结合文字、图像、音频和视频等多种媒介来表示信息。这种类型的认知地图能够在不同感官层面提供信息，增强记忆和理解效果。

**1.3 认知地图的重要性**

认知地图在信息组织和知识管理中具有重要作用，主要体现在以下几个方面：

1. **信息组织**：认知地图能够帮助我们将大量的信息进行分类、整理和整合，形成结构化的知识体系。
2. **知识管理**：通过认知地图，我们可以更好地存储、检索和共享知识，提高信息利用效率。
3. **问题解决**：认知地图能够帮助我们理清思路，分析问题，找到解决方案。
4. **创新思维**：认知地图提供了直观的信息表示方式，有助于激发创造性思维和创新的产生。
5. **教育和培训**：认知地图在教育领域中的应用，可以帮助学生更好地理解和记忆知识，提高学习效果。

**1.4 认知地图的组成部分**

一个典型的认知地图通常包括以下几个组成部分：

1. **中心主题**：认知地图的核心，通常是一个关键词或短语，表示整体的主题或目标。
2. **分支**：从中心主题延伸出的主要分支，表示主要的分类或概念。
3. **子分支**：从分支延伸出的次级分支，表示更详细的信息或概念。
4. **链接**：连接各个分支和子分支的线或箭头，表示它们之间的关系。
5. **图形和符号**：用于增强信息的视觉识别和记忆效果。

通过了解认知地图的定义、类型及其重要性，我们可以更好地理解和应用这一工具，提高信息组织和知识管理的能力。

#### 认知地图与传统思维导图的对比

认知地图（Cognitive Map）和思维导图（Mind Map）虽然在形式上相似，但它们在应用场景、结构和目的上有着显著的差异。以下是对两者进行详细对比：

**1. 应用场景**

- **认知地图**：认知地图主要应用于导航、规划和决策等领域。它帮助个体理解环境、组织和处理空间信息，是一个心理上的抽象模型。认知地图在地理学、城市规划、军事行动等需要空间感知和决策的场景中具有重要应用。
  
- **思维导图**：思维导图则是一种图形化的思考工具，主要用于个人和组织的信息组织、问题解决、创意产生和项目管理等领域。它通过分支结构和关键词链接，帮助个体或团队梳理思路，促进创造性思维和高效沟通。

**2. 结构**

- **认知地图**：认知地图的结构通常较为抽象和复杂。它包括中心主题、主要分支、次级分支以及它们之间的链接。这些分支和链接不一定遵循线性的结构，可以呈现出网状或树状结构，以适应不同情境的需求。

- **思维导图**：思维导图的结构通常更加直观和层次分明。它以中心主题为核心，向外延伸出多个主要分支和次级分支，每个分支代表一个主题或概念。这种结构有助于快速捕捉和整理信息，便于理解和记忆。

**3. 目的**

- **认知地图**：认知地图的主要目的是帮助个体理解和组织复杂的环境和信息。它有助于个体在导航和规划过程中，建立心理模型，提高决策效率。

- **思维导图**：思维导图的主要目的是促进思考和创意的产生。它通过图形化的方式，将复杂的信息以视觉形式呈现，有助于激发个体的创造性思维，提高信息处理和沟通效果。

**4. 关联与区别**

- **关联**：认知地图和思维导图在形式上都使用图形化的方式表示信息，都具有结构化和层次化的特点，能够帮助个体更好地理解和记忆信息。

- **区别**：认知地图更侧重于空间感知和决策支持，是一个心理上的抽象模型；而思维导图则更注重信息组织和创意产生，是一个可视化的思考工具。

通过以上对比，我们可以看出，认知地图和思维导图虽然在某些方面有重叠，但它们在实际应用中有着不同的侧重和目的。了解这两者的区别，有助于我们根据具体情况选择合适的工具来提升信息处理和解决问题的能力。

### 1.5 认知地图的组成部分

认知地图作为一种强大的信息组织和知识管理工具，其结构和组成部分决定了其在不同应用场景中的表现效果。一个典型的认知地图通常包含以下几个关键部分：

**1. 中心主题**

中心主题是认知地图的核心，它通常表示整体的主题或目标。中心主题通常用一个大圆圈或方块来表示，位于认知地图的中心位置。中心主题的设定有助于在整个认知地图中建立统一的焦点，确保所有分支和子分支都围绕这一核心展开。

**2. 分支**

分支是从中心主题延伸出的主要分支，表示主要的分类或概念。每个分支通常用线条或箭头从中心主题向外延伸，并附有一个关键词或短语。分支的数量和内容根据认知地图的具体用途和需求而变化。良好的分支结构有助于清晰地展示信息的层级和关系。

**3. 子分支**

子分支是从分支延伸出的次级分支，用于表示更详细的信息或概念。子分支进一步细分了分支的内容，增加了认知地图的层次感。子分支通常也用线条或箭头连接到上一级分支，并在旁边附有相关的关键词或短语。子分支的数量和深度取决于认知地图的复杂度和详细程度。

**4. 链接**

链接是连接各个分支和子分支的线或箭头，用于表示它们之间的关系。链接不仅使认知地图的结构更加完整，还帮助个体理解不同部分之间的相互联系。通过链接，认知地图能够呈现出一种网络结构，使得复杂的信息在视觉上更加直观和易于理解。

**5. 图形和符号**

图形和符号是认知地图中的重要元素，用于增强信息的视觉识别和记忆效果。图形可以包括图标、符号、图片等，而符号则可以是各种标记、标签或颜色。这些元素有助于将抽象的信息以直观的形式呈现，使得认知地图更加生动和具有吸引力。例如，使用不同颜色表示不同类型的概念，或者使用图标表示关键事件或功能。

通过以上组成部分的有机结合，认知地图能够有效地帮助个体理解和组织复杂的信息。在实际应用中，不同类型的认知地图可能会根据具体需求调整其结构和组成，但上述基本部分是构建有效认知地图的基础。

### 第2章：思维可视化的基础

#### 视觉认知原理、心理学基础及其在思维可视化中的应用

思维可视化是一种通过图形化的方式表示思维过程和知识结构的工具，其基础离不开对视觉认知原理和心理学基础的理解。在这一章中，我们将深入探讨视觉认知原理、心理学基础以及思维可视化与创造力的关系，以帮助读者更好地掌握和应用思维可视化。

**2.1 视觉认知原理**

视觉认知是指人类如何通过视觉系统感知、处理和理解外部世界的认知过程。以下是几个关键的视觉认知原理：

1. **视觉感知**：视觉感知是指人类如何通过眼睛接收和处理光线信息，将其转化为可以理解的视觉信号。视觉感知受多种因素影响，包括光线条件、观察者的生理特征和心理状态。

2. **视觉记忆**：视觉记忆是指人类如何记忆和回忆视觉信息。视觉记忆可以分为瞬时记忆和长期记忆。瞬时记忆通常只能保持几秒钟，而长期记忆可以持续数分钟到数十年。视觉记忆的关键在于如何有效地编码和提取信息。

3. **视觉识别**：视觉识别是指人类如何识别和区分不同的视觉元素，如颜色、形状、大小和纹理。视觉识别依赖于大脑对视觉信息的分析和综合处理。

4. **视觉注意力**：视觉注意力是指人类如何选择关注特定的视觉信息，忽略其他不重要的信息。视觉注意力对信息处理和理解至关重要，因为大脑无法同时处理所有视觉信息。

**2.2 心理学基础**

心理学基础为思维可视化提供了理论支持，以下是几个重要的心理学概念：

1. **认知负荷**：认知负荷是指大脑处理信息时所承受的负担。过高的认知负荷可能导致信息处理效率下降。思维可视化通过减少文字信息，提供直观的图形表示，有助于降低认知负荷。

2. **记忆曲线**：记忆曲线是指记忆信息随时间推移而衰退的规律。艾宾浩斯遗忘曲线表明，如果不进行复习，大部分信息会在短时间内被遗忘。思维可视化通过图形化的方式增强信息的记忆效果，有助于长期记忆。

3. **联想记忆**：联想记忆是指通过将新信息与已知信息建立联系来记忆。思维可视化利用图形和符号，帮助个体建立信息之间的联想，从而提高记忆效果。

4. **情绪影响**：情绪对认知过程有显著影响。积极情绪有助于提高信息处理效率和创造力，而消极情绪则可能阻碍认知过程。思维可视化通过创造性的视觉表达，激发积极的情绪反应，有助于提升创造力。

**2.3 思维可视化与创造力的关系**

思维可视化与创造力之间存在密切的关系。以下是几个方面的探讨：

1. **激发创造性思维**：思维可视化通过直观的图形表示，激发个体的创造性思维。图形化的方式使得抽象概念变得具体和形象，有助于个体从不同角度思考问题，产生新的想法。

2. **促进信息整合**：思维可视化有助于个体整合各种信息，形成更加完整和系统的知识结构。通过将信息以图形化的方式呈现，个体能够更好地理解信息之间的联系，从而整合新信息和已有知识。

3. **提升思维灵活性**：思维可视化鼓励个体尝试不同的思路和解决方案，提高思维的灵活性。图形化的表示方式使得个体可以轻松地调整和重构信息结构，探索不同的可能性。

4. **增强问题解决能力**：思维可视化通过帮助个体清晰地分析和理解问题，提升问题解决能力。通过图形化的方式，个体能够更好地识别问题的核心，制定有效的解决方案。

总之，思维可视化作为视觉认知和心理学基础的应用，不仅有助于提高信息处理和记忆效果，还能够激发创造性思维和创新能力。通过理解视觉认知原理和心理学基础，我们可以更有效地应用思维可视化，提升个人和组织的创造力。

#### 视觉认知原理

视觉认知是指人类如何通过视觉系统感知、处理和理解外部世界的认知过程。这一过程涉及多个层面，包括感知、记忆、识别和注意力。以下是对视觉认知原理的详细探讨：

**1. 感知**

感知是视觉认知的第一步，它涉及眼睛接收光线并将其转化为电信号的过程。当光线进入眼睛，经过角膜和晶状体的折射后，最终在视网膜上形成图像。视网膜上的感光细胞（视杆细胞和视锥细胞）将这些图像信息转化为电信号，并通过视神经传递到大脑。

感知过程中，几个关键因素影响信息的处理：

- **光线条件**：光线强度、亮度和对比度对感知有重要影响。在低光照环境下，视觉感知能力会下降。
- **观察者的生理特征**：不同个体的眼睛结构和视力状况会影响感知效果。例如，近视和远视会影响对细节的识别能力。

**2. 记忆**

视觉记忆是指人类如何记忆和回忆视觉信息。视觉记忆可以分为瞬时记忆和长期记忆：

- **瞬时记忆**：瞬时记忆通常只能保持几秒钟，它是对视觉信息的短暂存储。例如，当我们快速扫视一个复杂场景时，瞬时记忆使我们能够捕捉到关键信息。
- **长期记忆**：长期记忆是指信息在较长时间内被存储和回忆的能力。视觉记忆的长期存储依赖于信息的编码和提取策略。图形和颜色等视觉特征在长期记忆中尤其重要。

**3. 识别**

视觉识别是指人类如何识别和区分不同的视觉元素，如颜色、形状、大小和纹理。视觉识别依赖于大脑对视觉信息的分析和综合处理。以下是几个关键方面：

- **颜色识别**：颜色是通过不同波长的光引起的，大脑能够区分多种颜色。颜色识别在视觉认知中起着重要作用，例如在识别物体和判断情绪方面。
- **形状识别**：形状是视觉识别的重要部分。大脑通过对比和上下文信息来识别和分类形状。例如，我们能够区分圆形、方形和三角形。
- **大小和比例**：大脑能够判断物体的大小和比例，并理解它们在不同距离下的相对大小。这有助于导航和空间感知。

**4. 注意力**

视觉注意力是指人类如何选择关注特定的视觉信息，同时忽略其他不重要的信息。视觉注意力对信息处理和理解至关重要，因为大脑无法同时处理所有视觉信息。

- **选择性注意力**：选择性注意力是指个体有选择性地关注某些信息，而忽略其他信息。例如，当我们专注于阅读一篇文章时，会忽略周围的噪音。
- **分配性注意力**：分配性注意力是指个体能够同时关注多个信息源。例如，司机在驾驶时需要同时注意道路、其他车辆和交通信号。

**5. 交互作用**

视觉认知的各个层面相互交互，共同影响信息处理和理解：

- **感知与记忆**：感知到的视觉信息需要通过记忆进行存储和回忆。
- **识别与注意力**：识别过程中，个体需要将注意力集中在特定元素上，以准确判断其特征。

通过理解视觉认知原理，我们可以更好地设计信息表示方式，提高信息处理和记忆效果。例如，在设计中使用颜色、形状和图形等视觉元素，可以提高信息的可读性和记忆性，从而促进思维可视化。

### 第3章：认知地图的绘制技巧

#### 手绘认知地图

手绘认知地图是一种传统且实用的方法，通过纸笔进行绘制，可以帮助个体更好地组织和记录信息。以下是如何绘制手绘认知地图的详细步骤和技巧：

**3.1 准备工具与材料**

- **纸张**：选择一张空白的大纸，以便有足够的空间绘制认知地图。
- **笔**：使用彩色笔或者铅笔，以便为不同的分支和概念添加颜色。
- **便签纸**：准备一些便签纸，用于在绘制过程中临时记录关键信息。

**3.2 绘制流程**

1. **确定中心主题**：
   - 在纸张的中心位置，用较大的字体写下或绘制中心主题。这一步骤有助于在整个认知地图中建立统一的焦点。
   - 中心主题可以用一个圆形或方块来表示，以便突出其重要性。

2. **绘制主要分支**：
   - 从中心主题向外延伸出主要分支，每个分支代表一个主要的分类或概念。
   - 使用线条或箭头连接中心主题和主要分支，并在每个分支旁边写下相关的关键词或短语。

3. **细化子分支**：
   - 在每个主要分支下，继续延伸出次级分支，表示更详细的信息或概念。
   - 使用线条或箭头连接次级分支和上一级分支，确保整个结构清晰有序。

4. **添加链接**：
   - 使用线条或箭头连接不同分支和子分支，表示它们之间的关系。
   - 通过链接，可以直观地展示各个部分之间的联系和交互。

5. **使用符号和图形**：
   - 在适当的位置使用符号和图形，如图标、颜色和图像，以增强认知地图的视觉效果和记忆性。
   - 例如，可以使用不同颜色表示不同类型的概念，或者使用图标来代表关键事件。

**3.3 绘制技巧**

1. **保持简洁**：
   - 避免在认知地图上写过多文字，尽量用简洁的关键词和短语表示信息。
   - 简洁的表示有助于提高信息的可读性和记忆效果。

2. **使用颜色**：
   - 使用不同颜色来区分不同的分支和概念，有助于视觉上的区分和记忆。
   - 颜色选择应与主题相关，以增强认知效果。

3. **合理安排空间**：
   - 留出足够的空间，使每个分支和子分支都能清晰展示，避免过于拥挤。
   - 合理的空间布局有助于提高认知地图的清晰度和易读性。

4. **注重美观**：
   - 尽量使认知地图美观、整洁，以增强视觉吸引力。
   - 美观的设计不仅有助于提高信息的可读性，还能激发创造力和灵感。

通过以上步骤和技巧，我们可以绘制出一份清晰、美观的手绘认知地图。这种传统方法虽然简单，但在实际应用中却非常有效，能够帮助我们更好地理解和记忆复杂的信息。

### 4.3 创意设计中的应用

思维可视化在创意设计中的应用极具价值，通过图形化的方式帮助设计师探索和记录创意发想，激发设计思维的发散和整合。以下将详细介绍思维可视化在创意设计中的应用，以及如何通过思维导图、情境地图等工具来提升设计创新。

**1. 思维导图**

思维导图是一种以中心主题为中心，向外延伸出多个分支和子分支的图形化工具。它可以帮助设计师快速记录和整理创意发想，将复杂的思维过程可视化。以下是如何使用思维导图进行创意设计的步骤：

- **确定主题**：首先，明确设计项目的核心主题或目标。这个主题将成为思维导图的核心，围绕它展开各种创意发想。
  
- **发散思维**：从核心主题出发，延伸出多个主要分支，代表不同的创意方向。这些分支可以包括功能、外观、用户体验等各个方面。
  
- **细化分支**：在每个主要分支下，继续细化出次级分支，进一步扩展创意。例如，在“外观设计”分支下，可以细化出颜色、形状、材质等子分支。
  
- **记录灵感**：在思维导图的各个分支和子分支上，记录下具体的创意点子和灵感。可以使用关键词、短语或简单的描述，确保每个创意都能够被清晰地表达。

- **整合创意**：通过连接不同分支和子分支，将创意进行整合和关联。这种方法可以帮助设计师发现创意之间的潜在联系，产生新的创意点子。

**2. 情境地图**

情境地图是一种通过图形化的方式展示用户在不同情境下行为的工具。它可以帮助设计师深入了解用户的需求和行为模式，从而产生更具针对性的创意。以下是如何使用情境地图进行创意设计的步骤：

- **确定用户情境**：首先，明确设计项目的目标用户和他们的使用情境。这些情境可以是用户在日常生活中使用产品的场景，也可以是在特定任务中遇到的场景。

- **绘制用户行为**：在情境地图上，绘制用户在不同情境下的行为路径。这些行为路径可以用线条或箭头表示，确保用户的行为流程清晰。

- **记录用户需求**：在每个情境中，记录用户的需求和痛点。这些需求可以是功能性的，也可以是情感上的。通过记录用户需求，设计师可以更好地理解用户的行为动机。

- **关联创意**：将情境地图中的用户需求和创意进行关联。例如，如果一个情境中用户需求是“方便携带”，设计师可以在此关联创意点子，如轻便的设计或便携包装。

- **优化设计**：通过情境地图，设计师可以直观地看到设计如何满足用户需求。在创意发想阶段，设计师可以根据情境地图进行设计调整和优化，确保设计符合用户期望。

**3. 设计思维**

设计思维是一种以用户需求为中心，通过迭代和测试不断优化设计的创新方法。思维可视化工具在设计思维中扮演着重要角色，帮助设计师系统地探索和记录创意。以下是如何使用思维可视化工具进行设计思维的步骤：

- **定义问题**：明确设计项目要解决的问题或满足的需求。这个问题将成为设计思维的起点。

- **收集创意**：使用思维导图或情境地图等工具，收集各种可能的创意点子。通过发散思维，设计师可以产生大量的创意。

- **筛选创意**：通过评估创意的可行性和有效性，筛选出最具潜力的创意。思维可视化工具可以帮助设计师快速评估和比较不同创意。

- **迭代和测试**：将选定的创意进行迭代和测试，不断优化设计。通过思维可视化工具，设计师可以清晰地记录每次迭代中的改动和反馈，确保设计不断进步。

通过思维可视化工具，设计师能够更好地理解和整合创意，提升设计创新的能力。无论是通过思维导图记录创意发想，还是使用情境地图深入了解用户需求，思维可视化都为设计师提供了一种直观、有效的工具，助力创意设计的发展。

在课堂上，某教师使用思维导图来帮助学生理解复杂的历史事件。教师首先确定中心主题“第二次世界大战”，然后延伸出主要分支，如“战争原因”、“主要国家”、“重要战役”等。在每个分支下，进一步细化出次级分支，如“德国的扩张”、“苏联的反击”等。通过这种结构化的方式，学生能够清晰地把握历史事件的发展和各个事件之间的关系，提高了学习效果。

**案例2：项目管理工作**

在一个IT项目团队中，项目经理使用项目地图来规划项目进度。项目地图中心主题为“项目计划”，主要分支包括“需求分析”、“设计”、“开发”和“测试”等。每个分支下细化出任务和里程碑，通过线条和箭头连接不同任务，明确任务的依赖关系和时间安排。这种方法帮助团队成员清晰地了解项目进度和任务分工，提高了协作效率。

**5.2 最佳实践技巧**

1. **简化信息**：避免在思维导图中写入过多的文字，尽量使用简洁的关键词和短语表示信息。这有助于提高信息的可读性和记忆效果。

2. **使用颜色和图形**：利用颜色和图形来区分不同的分支和概念，增强视觉识别和记忆效果。例如，可以使用不同颜色表示不同的主题或子主题，或者使用图标来代表关键事件。

3. **保持结构清晰**：确保思维导图的层次结构清晰，避免混乱和冗余。合理的结构有助于提高信息的逻辑性和连贯性。

4. **互动和协作**：在团队协作中，使用思维可视化工具进行互动和讨论。多人共同编辑和更新思维导图，可以激发更多的创意和灵感。

5. **定期更新**：定期回顾和更新思维导图，确保其与当前项目或任务的实际情况相符。这有助于及时发现和解决问题，保持思维的活跃和准确性。

**5.3 注意事项**

1. **避免过度复杂**：思维可视化工具的目的是简化复杂的信息，避免过度复杂化。过多的细节和分支可能导致信息失真，降低可视化效果。

2. **保持一致性**：在绘制思维导图时，保持格式和风格的统一性。这有助于提高认知地图的整洁度和易读性。

3. **注意隐私和安全**：在共享和存储思维导图时，注意保护敏感信息。避免将涉及隐私或商业秘密的内容公开分享。

4. **适应不同场景**：思维可视化工具适用于多种场景，但应根据具体需求选择合适的工具。例如，在紧急决策时，可以使用简单的思维导图快速捕捉关键信息；而在长期规划中，可以使用更复杂的项目地图或情境地图。

5. **实践与理论相结合**：思维可视化不仅是理论工具，更需要在实践中不断应用和优化。通过实际操作，读者可以更好地理解思维可视化原理，提高应用效果。

```python
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

# 初始化Flask应用
app = Flask(__name__)

# 设置数据库URI
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///task_platform.db'
db = SQLAlchemy(app)

# 定义用户模型
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password = db.Column(db.String(120), nullable=False)

# 用户注册API
@app.route('/register', methods=['POST'])
def register():
    username = request.json.get('username')
    password = request.json.get('password')
    if not username or not password:
        return jsonify({'error': 'Missing username or password'}), 400
    user = User(username=username, password=password)
    db.session.add(user)
    db.session.commit()
    return jsonify({'message': 'User registered successfully'}), 201

# 用户登录API
@app.route('/login', methods=['POST'])
def login():
    username = request.json.get('username')
    password = request.json.get('password')
    user = User.query.filter_by(username=username, password=password).first()
    if not user:
        return jsonify({'error': 'Invalid username or password'}), 401
    return jsonify({'token': user.id}), 200

# 创建任务API
@app.route('/task', methods=['POST'])
def create_task():
    token = request.json.get('token')
    title = request.json.get('title')
    description = request.json.get('description')
    if not token or not title or not description:
        return jsonify({'error': 'Missing required information'}), 400
    current_user = get_current_user(token)
    task = Task(title=title, description=description, user_id=current_user.id)
    db.session.add(task)
    db.session.commit()
    return jsonify({'message': 'Task created successfully'}), 201

# 获取任务列表API
@app.route('/task', methods=['GET'])
def get_tasks():
    token = request.json.get('token')
    current_user = get_current_user(token)
    tasks = Task.query.filter_by(user_id=current_user.id).all()
    return jsonify([{'id': task.id, 'title': task.title, 'description': task.description} for task in tasks])

# 任务进度API
@app.route('/task/<int:task_id>/progress', methods=['PUT'])
def update_progress(task_id):
    token = request.json.get('token')
    progress = request.json.get('progress')
    if not token or not progress:
        return jsonify({'error': 'Missing required information'}), 400
    current_user = get_current_user(token)
    task = Task.query.get(task_id)
    if task.user_id != current_user.id:
        return jsonify({'error': 'You do not have permission to update this task'}), 403
    task.progress = progress
    db.session.commit()
    return jsonify({'message': 'Task progress updated successfully'}), 200

# 获取当前用户
def get_current_user(token):
    user_id = token
    user = User.query.get(user_id)
    if not user:
        return None
    return user

# 启动Flask应用
if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```

在这个代码中，我们定义了用户和任务两个模型，并实现了注册、登录、创建任务、获取任务列表和更新任务进度等API接口。通过XMind，我们可以将这些接口的功能和流程可视化，便于理解和项目管理。
