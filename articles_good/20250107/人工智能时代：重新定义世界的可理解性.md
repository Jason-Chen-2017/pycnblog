###### 1.1 人工智能的定义与历史

- **人工智能：** 机器通过算法和数据进行学习，以执行特定任务。

**算法mermaid流程图：**


**Python源代码示例：**

```python
# 导入必要的库
import numpy as np

# 定义一个简单的线性模型
def linear_model(x, w):
    return x * w

# 训练模型
w = np.random.rand(1)
x = np.array([1, 2, 3, 4])
y = np.array([2, 4, 6, 8])

# 使用最小二乘法找到最佳权重
w = (x.dot(y) - x.mean() * y.mean()) / (x.dot(x) - x.mean() ** 2)

# 预测
print(linear_model(x, w))
```

**数学模型和公式：**

$$
w = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}
$$
