### 2.1 量子计算基本原理

量子计算是一种利用量子力学原理进行信息处理的新兴计算模型。与传统的经典计算模型不同，量子计算利用量子比特（qubit）的叠加和纠缠等特性，能够在复杂问题上实现高效的计算。

#### 2.1.1 量子比特（qubit）

量子比特是量子计算的基本单元，它具有两个重要的特性：叠加和纠缠。

1. **叠加**：量子比特可以同时处于多种状态的叠加，而不是像经典比特那样只能处于一个状态。这种叠加特性使得量子计算机能够在计算过程中同时处理多个问题。
   
   $$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$
   
   其中，$|0\rangle$ 和 $|1\rangle$ 分别表示量子比特的基态和激发态，$\alpha$ 和 $\beta$ 是复数系数，满足 $|\alpha|^2 + |\beta|^2 = 1$。

2. **纠缠**：当两个或多个量子比特处于纠缠态时，它们之间的状态将相互关联，一个量子比特的状态会立即影响到另一个量子比特的状态，即使它们相隔很远。这种纠缠特性使得量子计算机能够在计算过程中实现并行计算。

   $$|\psi_{AB}\rangle = \alpha(|0\rangle_A|0\rangle_B) + \beta(|1\rangle_A|1\rangle_B)$$

#### 2.1.2 量子门

量子门是实现量子比特状态变换的基本操作。类似于经典计算中的逻辑门，量子门也分为基本的和复合的。基本的量子门包括 Hadamard 门（H门）、Pauli 门（X门、Y门、Z门）和相位门（S门、T门）等。

1. **Hadamard 门（H门）**：将量子比特从基态 $|0\rangle$ 变换为叠加态。

   $$H|0\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$$

2. **Pauli 门（X门、Y门、Z门）**：分别对量子比特的 X、Y、Z 轴进行操作。

   $$X|0\rangle = |1\rangle$$
   $$X|1\rangle = |0\rangle$$
   $$Y|0\rangle = i|1\rangle$$
   $$Y|1\rangle = -i|0\rangle$$
   $$Z|0\rangle = |0\rangle$$
   $$Z|1\rangle = -|0\rangle$$

3. **相位门（S门、T门）**：对量子比特的相位进行操作。

   $$S|0\rangle = |0\rangle$$
   $$S|1\rangle = i|1\rangle$$
   $$T|0\rangle = |0\rangle$$
   $$T|1\rangle = e^{i\pi/4}|1\rangle$$

   $$|x\rangle = \frac{1}{\sqrt{N}}\sum_{i=1}^{N} |i\rangle$$
