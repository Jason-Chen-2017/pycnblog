def gcd(a, b):
    """
    计算两个数的最大公约数（GCD）。
    
    参数:
    a -- 第一个整数
    b -- 第二个整数
    
    返回:
    最大公约数
    """
    while b:
        a, b = b, a % b
    return a

# 本算法基于辗转相除法（也称为欧几里得算法），是一种用于计算两个整数最大公约数的经典算法。

# 2. 算法步骤
# （1）判断第二个参数是否为0。如果是，则最大公约数为第一个参数。
# （2）如果第二个参数不为0，则进行以下步骤：
#       a. 将第一个参数赋值给第二个参数。
#       b. 将第二个参数赋值给第一个参数除以第二个参数的余数。
# （3）重复步骤2，直到第二个参数为0为止。
# （4）此时，第一个参数即为两个数的最大公约数。

# 设 $a$ 和 $b$ 为两个整数，且 $a > b$。

#   $gcd(a, b) = gcd(b, a \mod b)$
