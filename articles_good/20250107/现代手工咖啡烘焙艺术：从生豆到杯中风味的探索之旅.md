### 第2章：烘焙原理

#### 2.1 烘焙过程中的化学反应

**背景介绍**：
咖啡豆在烘焙过程中会发生一系列复杂的化学反应，这些反应不仅改变了豆子的物理结构，还影响了豆子的风味。了解这些反应过程对于掌握烘焙技术至关重要。

**核心概念与联系**：

| 化学反应 | 描述 |  
| :--- | :--- |  
| 热解反应 | 豆子受热后分解产生的挥发性物质 |  
| 羰基反应 | 豆子中的糖类与氨基酸发生反应产生的风味物质 |  
| 热氧化反应 | 豆子中的脂肪和蛋白质在高温下氧化 |

**反应过程讲解**：
1. **热解反应**：豆子受热后，内部的细胞壁和细胞膜分解，释放出大量的挥发性物质，这些物质对风味有着重要影响。
2. **羰基反应**：豆子中的糖类和氨基酸在高温下发生反应，产生多种风味化合物，如醛、酮和酸类。
3. **热氧化反应**：豆子中的脂肪和蛋白质在高温下氧化，产生不同的气味和口感。

```mermaid
    E --> F[气味]

```

#### 2.2 烘焙曲线解析

**背景介绍**：
烘焙曲线是记录烘焙过程中温度和时间变化的图表，它直观地展示了烘焙过程中的关键阶段。通过解析烘焙曲线，可以更好地掌握烘焙的进程和结果。

**核心概念与联系**：

| 烘焙曲线阶段 | 描述 |  
| :--- | :--- |  
| 预热阶段 | 烤箱或烘焙机预热到设定温度 |  
| 加热阶段 | 温度逐渐升高，豆子开始发生物理和化学变化 |  
| 烘焙阶段 | 温度和时间达到最佳点，豆子风味和颜色发生变化 |  
| 结束阶段 | 温度逐渐降低，豆子完成烘焙 |

**烘焙曲线解析指南**：
1. **预热阶段**：确保烤箱或烘焙机达到设定温度，以保证烘焙过程的稳定性。
2. **加热阶段**：观察温度变化，调整烘焙策略，避免过度加热或不足加热。
3. **烘焙阶段**：关注温度和时间点，确保豆子达到理想的风味和颜色。
4. **结束阶段**：缓慢降低温度，避免豆子过度烘焙。
