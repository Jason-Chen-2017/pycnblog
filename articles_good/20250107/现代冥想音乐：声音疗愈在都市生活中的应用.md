### 现代冥想音乐

**定义**：现代冥想音乐是一种旨在通过音乐引导听众进入冥想状态的流派。它通常具有柔和的旋律、缓慢的节奏和简化的结构，旨在减少听众的焦虑和压力。

**历史**：现代冥想音乐起源于20世纪60年代，随着冥想运动的兴起而逐渐发展。早期的冥想音乐以自然音效和传统的东方音乐元素为主，随着时间的推移，逐渐融合了现代音乐元素，形成了独特的风格。

**特点与流派**：现代冥想音乐的特点包括柔和的旋律、缓慢的节奏和简化的结构。根据音乐风格和演奏形式的不同，可分为多种流派，如电子冥想音乐、自然音效冥想音乐和世界音乐冥想等。

**现代冥想音乐与传统冥想音乐的区别**：传统冥想音乐通常指的是印度古典音乐、禅乐等，这些音乐更注重音色的纯粹和冥想的深度。而现代冥想音乐则更注重音乐形式的多样性和普及性，使其更容易为大众所接受。

```python
import streamlit as st

def play_meditation_music(file_path):
    audio_path = file_path
    y, sr = librosa.load(audio_path)
    
    st.title("冥想音乐播放器")
    
    st.form("play_music_form"):
        with st.form_key("play_music_form_key"):
            play_button = st.button("播放")
        
        if play_button:
            st.audio(y, sr=sr)

    st.text_input("输入音乐名称", key="music_name")

    if st.form("play_music_form").submit_form():
        music_name = st.session_state.music_name
        st.write(f"当前播放：{music_name}")

play_meditation_music("meditation_music.mp3")
```
