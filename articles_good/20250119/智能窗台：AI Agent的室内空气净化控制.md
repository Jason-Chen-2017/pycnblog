### 2.4 室内空气净化数学模型与公式

#### 2.4.1 空气质量指数（AQI）模型

**公式推导**：

空气质量指数（AQI）是用于描述空气污染程度的一个指标，其计算公式如下：

$$
AQI = \frac{1}{C} \sum_{i=1}^{N} w_i \cdot \frac{C_i}{\sum_{j=1}^{N} w_j \cdot C_j}
$$

其中，$w_i$ 表示第 $i$ 个污染物的权重，$C_i$ 表示第 $i$ 个污染物的浓度。

**参数解释**：

- **权重（$w_i$）**：表示不同污染物对空气质量的影响程度。
- **浓度（$C_i$）**：表示第 $i$ 个污染物的浓度。

#### 2.4.2 机器学习算法数学模型

**模型介绍**：

机器学习算法是AI Agent的核心组成部分，常用的机器学习算法包括监督学习、无监督学习和强化学习。以下以监督学习为例，介绍其数学模型。

**公式推导**：

假设我们有一个包含 $N$ 个样本的训练集，每个样本包含 $D$ 个特征和对应的标签。监督学习的目标是通过训练集学习出一个函数 $f$，使得对于新的输入样本 $x$，能够预测其标签 $y$。

$$
y = f(x)
$$

其中，$f$ 是一个映射函数，$x$ 是输入样本，$y$ 是预测标签。

**参数解释**：

- **输入样本（$x$）**：包含 $D$ 个特征。
- **预测标签（$y$）**：通过学习得到的标签。
- **映射函数（$f$）**：通过训练得到的模型。

#### 3.5.2 系统核心代码

以下是一个简单的示例，展示了智能窗台系统的核心代码实现：

```python
import serial
import json
import paho.mqtt.client as mqtt
from sklearn.ensemble import RandomForestRegressor

# 传感器配置
ser = serial.Serial('COM3', 9600)

# MQTT配置
client = mqtt.Client()
client.connect("localhost", 1883, 60)

# 机器学习模型配置
model = RandomForestRegressor(n_estimators=100)

# 数据采集
def collect_data():
    data = ser.readline().decode().strip()
    return json.loads(data)

# 数据处理
def process_data(data):
    features = [data['pm2.5'], data['pm10'], data['temp'], data['humidity']]
    return features

# 数据预测
def predict_quality(features):
    prediction = model.predict([features])
    return prediction

# 控制空气净化器
def control_fan(prediction):
    if prediction > 50:
        client.publish("control/command", "fan_on")
    else:
        client.publish("control/command", "fan_off")

# 主程序
if __name__ == "__main__":
    while True:
        data = collect_data()
        features = process_data(data)
        prediction = predict_quality(features)
        control_fan(prediction)
```

#### 3.7.3 模型效果评估

为了评估模型的预测效果，我们可以使用以下指标：

- **均方误差（MSE）**：
  $$MSE = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$
- **决定系数（R²）**：
  $$R^2 = 1 - \frac{\sum_{i=1}^{N} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{N} (y_i - \bar{y})^2}$$

其中，$y_i$ 表示真实值，$\hat{y}_i$ 表示预测值，$\bar{y}$ 表示平均值。

通过计算MSE和R²，我们可以评估模型的预测性能。在实际应用中，我们可以根据评估结果调整模型参数，优化模型性能。
