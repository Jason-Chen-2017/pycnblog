```python
# 利用K-means聚类分析构建投资者画像
def build_investor_portraits(investor_df):
    kmeans = KMeans(n_clusters=5, random_state=0).fit(investor_df)
    investor_df['cluster'] = kmeans.labels_
    
    # 可视化投资者画像
    fig, ax = plt.subplots(1, 1, figsize=(8, 6))
    scatter = ax.scatter(investor_df['investment_amount'], investor_df['risk_preference'], c=investor_df['cluster'], cmap='viridis')
    ax.set_xlabel('Investment Amount')
    ax.set_ylabel('Risk Preference')
    ax.set_title('Investor Clusters')
    plt.show()

# 执行画像构建
build_investor_portraits(investor_df)
```

该模块使用K-means聚类算法，将投资者划分为不同的群体，并使用散点图展示不同群体的特征。
