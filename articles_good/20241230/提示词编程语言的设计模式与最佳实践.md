### 2.3 结构型模式

结构型模式主要关注类与类之间的关系，用于简化程序结构，提高代码的可读性和可维护性。在提示词编程语言中，结构型模式可以用于实现复杂的系统架构，提高代码的灵活性和可扩展性。以下是三种常见的结构型模式：

#### 2.3.1 适配器模式

适配器模式是一种将适配者（Adaptee）的接口转换成目标接口（Target）的设计模式。在提示词编程语言中，适配器模式可以用于将现有的组件集成到新的系统中，或者将不同的接口统一。

**实现方式**：

1. **定义抽象目标接口**：创建一个抽象目标接口，定义需要适配的方法。
2. **定义抽象适配器接口**：创建一个抽象适配器接口，实现抽象目标接口的方法。
3. **创建具体适配器类**：创建具体适配器类，实现抽象适配器接口，并将适配者的接口与目标接口关联。
4. **客户端调用**：客户端通过调用抽象目标接口的方法使用适配器。

```python
class Target:
    def request(self):
        pass

class Adaptee:
    def specific_request(self):
        pass

class Adapter(Target):
    def __init__(self, adaptee):
        self.adaptee = adaptee

    def request(self):
        return self.adaptee.specific_request()
```

**应用示例**：

假设我们有一个使用旧版 API 的组件，但新的系统要求使用新版的 API。我们可以使用适配器模式，将旧版 API 转换为新版 API。

```python

    def old_method(self):
        pass

# 新版 API
class NewApi:
    def new_method(self):
        pass

# 适配器
class ApiAdapter(OldApi, NewApi):
    def new_method(self):
        return self.old_method()

# 客户端代码
def main():
    api = NewApi()
    api.new_method()

    api = OldApi()
    api = ApiAdapter(api)
    api.new_method()

    main()
```

#### 2.3.2 桥接模式

桥接模式是一种将抽象部分与实现部分分离，使它们都可以独立地变化的设计模式。在提示词编程语言中，桥接模式可以用于实现复杂的系统架构，提高代码的可扩展性和灵活性。

**实现方式**：

1. **定义抽象部分接口**：创建一个抽象部分接口，定义需要实现的抽象方法。
2. **定义实现部分接口**：创建一个实现部分接口，定义需要实现的抽象方法。
3. **创建抽象部分类**：创建抽象部分类，实现抽象部分接口，定义一个实现部分对象引用。
4. **创建实现部分类**：创建实现部分类，实现实现部分接口。
5. **创建客户端类**：创建客户端类，使用抽象部分类和实现部分类。

```python
class ImplementorA:
    def operation(self):
        pass

class ImplementorB:
    def operation(self):
        pass

class Abstraction:
    def __init__(self, implementor):
        self.implementor = implementor

    def operation(self):
        self.implementor.operation()
```

**应用示例**：

假设我们有一个需要实现不同操作的系统，我们可以使用桥接模式，将操作与实现分离。

```python

    def operation(self):
        print("ConcreteImplementorA operation")

class ConcreteImplementorB(ImplementorB):
    def operation(self):
        print("ConcreteImplementorB operation")

# 抽象部分
class RefinedAbstraction(Abstraction):
    def operation(self):
        self.implementor.operation()

# 客户端代码
def main():
    implementor = ConcreteImplementorA()
    abstraction = RefinedAbstraction(implementor)
    abstraction.operation()

    implementor = ConcreteImplementorB()
    abstraction = RefinedAbstraction(implementor)
    abstraction.operation()

if __name__ == "__main__":
    main()
```

#### 2.3.3 组合模式

组合模式是一种将对象组合成树形结构以表示"部分 - 整体"的层次结构的设计模式。在提示词编程语言中，组合模式可以用于实现复杂的系统架构，提高代码的可扩展性和灵活性。

**实现方式**：

1. **定义组件接口**：创建一个组件接口，定义需要实现的抽象方法。
2. **创建叶节点类**：创建叶节点类，实现组件接口，代表树结构中的叶节点。
3. **创建容器类**：创建容器类，实现组件接口，代表树结构中的容器节点。
4. **组合组件**：容器类包含一组组件对象，可以通过遍历这些组件对象实现层次结构的操作。

```python
class Component:
    def operation(self):
        pass

class Leaf(Component):
    def operation(self):
        print("Leaf operation")

class Composite(Component):
    def __init__(self):
        self.components = []

    def add(self, component):
        self.components.append(component)

    def remove(self, component):
        self.components.remove(component)

    def operation(self):
        for component in self.components:
            component.operation()
```

**应用示例**：

假设我们有一个文件系统，可以使用组合模式表示文件和目录的层次结构。

```python
# 叶节点
class File(Component):
    def operation(self):
        print("File operation")

# 容器节点
class Directory(Composite):
    def operation(self):
        print("Directory operation")
        for component in self.components:
            component.operation()

# 客户端代码
def main():
    file1 = File()
    file2 = File()
    directory = Directory()
    directory.add(file1)
    directory.add(file2)
    directory.operation()

if __name__ == "__main__":
    main()
```

```python
class Observer:

class Subject:
    def __init__(self):

```

```python
class Iterator:
    def first(self):
        pass

    def next(self):
        pass

    def is_done(self):
        pass

    def current_item(self):
        pass

class ListIterator(Iterator):
    def __init__(self, list_data):
        self.list_data = list_data
        self.index = 0

    def first(self):
        self.index = 0
        return self.list_data[self.index]

    def next(self):
        self.index += 1
        if self.index < len(self.list_data):
            return self.list_data[self.index]
        return None

    def is_done(self):
        return self.index >= len(self.list_data)

    def current_item(self):
        if not self.is_done():
            return self.list_data[self.index]
        return None
```
