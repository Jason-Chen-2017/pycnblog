### 第2章: 图神经网络基础

#### 2.1 图的基本概念

##### 2.1.1 图的定义

图（Graph）是由节点（Node）和边（Edge）组成的离散结构。节点表示图中的实体，边表示节点之间的关系。

##### 2.1.2 图的表示方法

图可以用以下几种方式表示：

1. **邻接矩阵**：用二维数组表示图，其中元素表示节点之间的边。
2. **邻接表**：用列表表示图，其中每个列表元素包含节点和其邻居节点。
3. **边的集合**：用边的集合表示图，其中每条边由两个节点标识。

#### 2.2 图神经网络的基本结构

##### 2.2.1 图卷积网络（GCN）

图卷积网络（Graph Convolutional Network，GCN）是一种基于图结构的卷积神经网络。其核心思想是将节点特征与邻居节点特征进行加权融合，从而更新节点表示。

##### 2.2.2 图注意力网络（GAT）

图注意力网络（Graph Attention Network，GAT）是一种基于注意力机制的图神经网络。其核心思想是利用节点之间的注意力权重，动态调整邻居节点特征对节点表示的影响。

##### 2.2.3 图变换器网络（GATV）

图变换器网络（Graph Attention Transformer，GATV）是一种结合了图注意力网络和变换器网络的图神经网络。其核心思想是利用变换器网络进行特征转换，同时利用图注意力机制进行特征融合。

#### 2.3 图神经网络的算法原理

##### 2.3.1 图卷积算法原理

图卷积算法的核心思想是将节点特征与邻居节点特征进行加权融合，从而更新节点表示。具体步骤如下：

1. **初始化节点特征**：对图中的每个节点分配一个初始特征向量。
2. **计算邻居节点特征**：对于每个节点，计算其邻居节点的特征。
3. **加权融合**：利用邻居节点特征和节点特征之间的相似度，计算加权融合后的节点特征。
4. **更新节点特征**：将加权融合后的节点特征作为新的节点特征。

##### 2.3.2 图注意力算法原理

图注意力算法的核心思想是利用节点之间的注意力权重，动态调整邻居节点特征对节点表示的影响。具体步骤如下：

1. **计算注意力权重**：对于每个节点，计算其与邻居节点之间的注意力权重。
2. **加权融合**：利用注意力权重，动态调整邻居节点特征对节点表示的影响。
3. **更新节点特征**：将加权融合后的节点特征作为新的节点特征。

##### 2.3.3 图变换器算法原理

图变换器算法的核心思想是利用变换器网络进行特征转换，同时利用图注意力机制进行特征融合。具体步骤如下：

1. **变换器网络**：利用变换器网络对节点特征进行转换。
2. **图注意力机制**：利用图注意力机制，动态调整节点特征和转换后特征的影响。
3. **更新节点特征**：将转换后特征和加权融合后的特征作为新的节点特征。

#### 4.2 图神经网络推理的代码实现

以下是一个简单的图卷积网络（GCN）的Python代码实现示例：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import GCNConv

# 定义GCN模型
class GCN(nn.Module):
    def __init__(self, num_features, num_classes):
        super(GCN, self).__init__()
        self.conv1 = GCNConv(num_features, 16)
        self.conv2 = GCNConv(16, num_classes)

    def forward(self, data):
        x, edge_index = data.x, data.edge_index

        x = F.relu(self.conv1(x, edge_index))
        x = F.dropout(x, training=self.training)
        x = self.conv2(x, edge_index)

        return F.log_softmax(x, dim=1)

# 初始化模型、损失函数和优化器
model = GCN(num_features=7, num_classes=2)
criterion = nn.NLLLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

# 训练模型
for epoch in range(200):
    model.train()
    optimizer.zero_grad()
    out = model(data)
    loss = criterion(out, data.y)
    loss.backward()
    optimizer.step()

    if (epoch + 1) % 10 == 0:
        model.eval()
        _, pred = model(data).max(dim=1)
        correct = float(pred.data.sum())
        accuracy = correct / len(data)
        print(f"Epoch {epoch + 1}: Accuracy: {accuracy * 100:.2f}%")
```
