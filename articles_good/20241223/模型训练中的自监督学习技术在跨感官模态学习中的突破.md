### 第2章: 自监督学习基础

**核心概念原理：**
自监督学习（Self-Supervised Learning）是一种机器学习方法，它不需要依赖于人工标注的数据，通过利用数据中的某种内在结构，自动地生成监督信号来指导学习过程。

**概念属性特征对比表格：**

| 特征         | 自监督学习         | 监督学习         |
| ------------ | ---------------- | ---------------- |
| 数据需求     | 无需大量标注数据   | 需要大量标注数据 |
| 监督信号     | 自主生成          | 人工标注         |
| 训练效果     | 对未标注数据进行泛化 | 对标注数据进行精准 |
| 应用场景     | 数据稀缺、数据标注困难 | 数据丰富、需求精确 |
| 模型调整方式 | 监督信号驱动       | 标签驱动         |

```mermaid
      模型 --> 数据：训练
  }
  数据 ||--o{ 监督信号 } |{

  }
```
