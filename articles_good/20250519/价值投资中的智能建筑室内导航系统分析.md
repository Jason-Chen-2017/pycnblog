### 第3章: 智能建筑室内导航系统的算法原理

#### 3.1 常见的导航算法

- **3.1.1 Dijkstra算法**
  - **算法步骤**：  
    1. 初始化优先队列，将起点加入队列。  
    2. 取出队列中距离起点最近的节点，更新其邻居节点的距离。  
    3. 重复上述步骤，直到队列为空或找到目标节点。

  - **算法流程图**  
    ```mermaid
    graph TD
      A[起点] --> B[邻居节点]
      B --> C[目标节点]
    ```

  - **数学模型**  
    $$d = \min(d[v], d[u] + w(u, v))$$  
    其中，$d[v]$ 表示当前节点 $v$ 的最短距离，$d[u]$ 表示节点 $u$ 的最短距离，$w(u, v)$ 表示节点 $u$ 和 $v$ 之间的权重。

  - **Python实现示例**  
    ```python
    import heapq

    def dijkstra(graph, start, goal):
        distances = {node: float('infinity') for node in graph}
        distances[start] = 0
        heap = [(0, start)]
        visited = set()

        while heap:
            current_dist, current_node = heapq.heappop(heap)
            if current_node in visited:
                continue
            visited.add(current_node)
            if current_node == goal:
                break
            for neighbor, weight in graph[current_node].items():
                if distances[neighbor] > current_dist + weight:
                    distances[neighbor] = current_dist + weight
                    heapq.heappush(heap, (distances[neighbor], neighbor))
        return distances[goal]
    ```

- **3.1.2 A*算法**  
  A*算法在Dijkstra算法的基础上引入了启发式函数，用于优先探索更有可能到达目标节点的路径。

#### 5.2 核心代码实现
- **5.2.1 导航算法实现**  
  ```python
  import heapq

  def a_star(graph, start, goal):
      open_set = {start}
      closed_set = set()
      g_score = {node: float('infinity') for node in graph}
      g_score[start] = 0
      f_score = {node: float('infinity') for node in graph}
      f_score[start] = heuristic(start, goal)

      while open_set:
          current = heapq.heappop(open_set, key=lambda x: f_score[x])
          if current == goal:
              break
          closed_set.add(current)
          for neighbor in graph[current].keys():
              tentative_g_score = g_score[current] + graph[current][neighbor]
              if neighbor not in closed_set and tentative_g_score < g_score[neighbor]:
                  g_score[neighbor] = tentative_g_score
                  f_score[neighbor] = tentative_g_score + heuristic(neighbor, goal)
                  heapq.heappush(open_set, neighbor)
      return g_score[goal]

  def heuristic(a, b):
      return abs(a[0] - b[0]) + abs(a[1] - b[1])
  ```
