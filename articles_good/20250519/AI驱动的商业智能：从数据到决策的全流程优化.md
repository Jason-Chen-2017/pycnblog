### 4.2 算法实现与代码示例
#### 4.2.1 线性回归算法的实现
- 线性回归的数学模型：$$y = \theta_0 + \theta_1x$$
- 梯度下降优化过程
- Python代码实现：

```python
import numpy as np
def compute_cost(X, y, theta):
    m = len(y)
    cost = (1/(2*m)) * np.sum((X.dot(theta) - y)**2)
    return cost
```
