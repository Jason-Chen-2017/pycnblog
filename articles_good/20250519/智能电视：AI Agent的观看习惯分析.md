# 第3章：协同过滤算法

## 3.1 协同过滤算法的基本原理

### 3.1.1 基于用户的协同过滤

- **基本思想**：找到与当前用户相似的用户群体，推荐他们喜欢的内容。
- **实现步骤**：
  1. 计算用户之间的相似度。
  2. 找到相似用户的推荐列表。
  3. 综合推荐结果，生成个性化推荐。

### 3.1.2 基于物品的协同过滤

- **基本思想**：找到与当前用户感兴趣的内容相似的节目，推荐给用户。
- **实现步骤**：
  1. 计算内容之间的相似度。
  2. 找到相似内容的推荐列表。
  3. 综合推荐结果，生成个性化推荐。

## 3.2 协同过滤的数学模型

### 3.2.1 相似度计算公式

$$ sim(i,j) = \frac{\sum_{k} r_{ik} r_{jk}}{\sqrt{\sum_{k} r_{ik}^2} \sqrt{\sum_{k} r_{jk}^2}} $$

### 3.2.2 推荐评分预测公式

$$ \hat{r}_{ui} = \bar{r} + (r_u - \bar{r}_u) + (r_i - \bar{r}_i) $$

### 3.3.3 相似度计算


### 3.3.4 推荐结果

```python
# 假设用户ID为0，计算推荐结果
user_id = 0
similar_users = np.argsort(similarity[user_id])[::-1]
recommended_items = ratings[similar_users[0]]
print(recommended_items)
```
