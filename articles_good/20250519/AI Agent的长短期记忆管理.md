# 第1章: 长短期记忆管理概述

## 1.1 长短期记忆管理的基本概念

### 1.1.1 什么是长短期记忆
长短期记忆（Long Term Memory, 短期记忆（Short Term Memory）是AI Agent处理信息的两个关键部分。长记忆用于存储长期的知识和经验，而短记忆则处理当前任务的相关信息。

### 1.1.2 长短期记忆在AI Agent中的作用
长记忆确保智能体能够积累经验，而短记忆帮助处理当前任务，两者结合使智能体具备更强的智能水平。

### 1.1.3 长短期记忆的特征与区别
- **长记忆**：持久性、稳定性、累积性
- **短记忆**：临时性、快速更新、容量有限

class ShortMemory:
