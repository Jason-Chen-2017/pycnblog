### 3.2.1 SVM的基本原理
```mermaid
graph LR
A[输入数据] --> B[数据预处理]

C --> D[模型训练]
D --> E[分类结果]
```

### 3.2.2 SVM的数学模型
$$ \text{目标函数} \quad \frac{1}{2}\|w\|^2 $$
$$ \text{约束条件} \quad y_i(w \cdot x_i + b) \geq 1 $$
$$ \text{拉格朗日乘子法} \quad L = \frac{1}{2}\|w\|^2 + \sum \alpha_i (1 - y_i(w \cdot x_i + b)) $$

### 3.2.3 SVM算法的Python实现
```python
from sklearn import svm
# 初始化模型
model = svm.SVC(kernel='rbf', gamma='auto')
# 训练模型
model.fit(X_train, y_train)
# 预测
y_pred = model.predict(X_test)
```
