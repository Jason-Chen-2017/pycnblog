## 第2章：生物计算神经网络的基本原理

### 2.1 神经元模型
神经元模型是生物计算神经网络的基础，常用的模型包括：
- **麦卡洛克-帕斯卡模型（McCulloch-Pitts Model）**：基本的神经元模型，描述了神经元如何接收输入、计算加权和进行阈值判断。
- **霍普菲尔德网络（Hopfield Network）**：一种用于联想记忆的神经网络模型，具有自我纠正的特性。

### 2.2 网络结构
生物计算神经网络的结构通常包括输入层、隐藏层和输出层。隐藏层中的神经元通过权重和激活函数进行特征提取和非线性变换。

```mermaid

```

### 2.3 训练算法
- **前向传播**：输入数据经过网络层，计算输出。
- **反向传播**：计算预测误差，调整权重以最小化损失。
- **梯度下降**：优化权重参数，提高网络性能。

```mermaid

    X --> F1[前向传播]
    F1 --> E[误差计算]
    E --> G[反向传播]
    G --> W[权重更新]
```

### 2.4 数学模型
神经网络的损失函数通常采用均方误差或交叉熵损失。反向传播中使用链式法则计算梯度。

$$ L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y_i})^2 $$

### 2.5 代码实现
以下是一个简单的神经网络实现示例：

```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    return sigmoid(x) * (1 - sigmoid(x))

def train_neural_network(X, y, hidden_layer_size=5, learning_rate=0.1, epochs=100):
    np.random.seed(1)
    weights_input_hidden = np.random.randn(X.shape[1], hidden_layer_size)
    weights_hidden_output = np.random.randn(hidden_layer_size, 1)
    
    for epoch in range(epochs):
        # 前向传播
        hidden_layer_activation = sigmoid(np.dot(X, weights_input_hidden))
        output_layer_activation = sigmoid(np.dot(hidden_layer_activation, weights_hidden_output))
        
        # 反向传播
        output_error = y - output_layer_activation
        hidden_error = np.dot(output_error, weights_hidden_output.T) * sigmoid_derivative(hidden_layer_activation)
        
        # 更新权重
        weights_hidden_output += learning_rate * np.dot(hidden_layer_activation.T, output_error)
        weights_input_hidden += learning_rate * np.dot(X.T, hidden_error)
    
    return weights_input_hidden, weights_hidden_output
```
