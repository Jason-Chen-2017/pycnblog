## 第2章: 量子计算的基本原理

### 2.1 量子计算的核心概念  
#### 2.1.1 量子位（Qubit）的定义与特点  
- **量子位**：与经典计算机中的二进制位不同，量子位可以同时处于多个状态的叠加态。  
- **叠加态**：量子位可以同时表示0和1，或者任何中间状态。  
- **纠缠态**：多个量子位之间可以形成纠缠，一个量子位的状态会直接影响另一个量子位的状态。  

#### 2.1.2 量子叠加态与量子纠缠态  
- **叠加态**：$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$，其中$\alpha$和$\beta$是概率幅。  
- **纠缠态**：例如，贝尔态$|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$。  

#### 2.1.3 量子计算的运算方式  
- **量子门**：量子计算中的基本操作单元，如Hadamard门、CNOT门等。  
- **量子电路**：由多个量子门组成的电路，用于实现特定的量子算法。

#### 5.2.1 量子傅里叶变换的实现  
```python
from qiskit import QuantumCircuit, execute, Aer

def quantum_fourier_transform(n_qubits):
    qc = QuantumCircuit(n_qubits)
    # 实施量子傅里叶变换
    qc.h(0)
    qc.cnot(0, 1)
    qc.cnot(0, 2)
    return qc

# 执行量子电路
simulator = Aer.get_backend('statevector_simulator')
circuit = quantum_fourier_transform(3)
result = execute(circuit, simulator).result()
statevector = result.get_statevector()
print(statevector)
```

#### 5.2.2 量子优化算法的实现

from qiskit import QuantumCircuit, execute, Aer

def quantum_optimization():
    qc = QuantumCircuit(2)
    qc.h(0)
    qc.cnot(0, 1)
    qc.measure(0, 0)
    qc.measure(1, 1)
    return qc

simulator = Aer.get_backend('qasm_simulator')
circuit = quantum_optimization()
result = execute(circuit, simulator).result()
print(result.counts)
