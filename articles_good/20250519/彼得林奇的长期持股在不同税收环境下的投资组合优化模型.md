### 3.2 投资组合优化的数学模型

- **3.2.1 投资组合优化的数学表达式**
  - 线性规划模型：$$\max \sum w_i r_i (1 - t)$$
  - 非线性规划模型：$$\max \sum w_i r_i (1 - t) - \lambda \sum w_i^2$$

- **3.2.2 税收因素的数学建模**
  - 税率的数学表达：$$t = t_i$$
  - 税后收益的数学表达：$$r_i (1 - t_i)$$

### 3.3 算法实现与代码示例

- **3.3.1 Python代码实现**

  ```python
  import numpy as np
  from scipy.optimize import minimize

  def objective(weights, returns, tax_rate):
      tax_adj_returns = returns * (1 - tax_rate)
      return -sum(weights * tax_adj_returns)

  def constraint(weights):
      return np.sum(weights) - 1

  # 示例数据
  returns = np.array([0.1, 0.15, 0.08])
  tax_rate = 0.15

  # 初始权重
  init_weights = np.array([1/3, 1/3, 1/3])

  # 优化
  result = minimize(objective, init_weights, args=(returns, tax_rate), method='SLSQP', constraints={'type': 'eq', 'fun': constraint})

  # 输出结果
  print(result.x)
  ```
