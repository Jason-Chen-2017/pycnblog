#### 4.2.2 纳米技术应用的贴现率计算

贴现率计算通常采用加权平均资本成本（WACC）方法。WACC 公式如下：

$$
WACC = \left( \frac{D}{D + E} \times r_d \times (1 - t) \right) + \left( \frac{E}{D + E} \times r_e \right)

其中，\( D \) 表示债务，\( E \) 表示权益，\( r_d \) 表示债务利率，\( t \) 表示税率，\( r_e \) 表示权益利率。

```python
import numpy as np
import pandas as pd

def calculate_npv(cash_flows, discount_rate):
    npv = 0
    for t in range(len(cash_flows)):
        npv += cash_flows[t] / (1 + discount_rate) ** t
    return npv

cash_flows = [100, 200, 300, 400]
discount_rate = 0.1

npv = calculate_npv(cash_flows, discount_rate)
print("净现值：", npv)
```
