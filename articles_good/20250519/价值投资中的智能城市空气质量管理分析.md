# 第1章 价值投资的基本概念与方法

## 1.1 价值投资的定义与核心原则

### 1.1.1 价值投资的定义
价值投资是一种长期投资策略，强调以低于内在价值的价格买入优质资产。其核心在于识别被市场低估的机会，并长期持有。

### 1.1.2 价值投资的核心原则
- **安全边际**：买入价格低于内在价值，确保安全空间。
- **长期视角**：关注企业的长期盈利能力，而非短期波动。
- **基本面分析**：通过财务报表等数据评估企业价值。

### 1.1.3 价值投资与智能城市空气质量管理的联系
智能城市空气质量管理涉及环保技术、政策法规等多个方面，价值投资可以通过分析相关企业或项目的长期价值，寻找投资机会。

# 第4章 智能城市空气质量管理的算法原理

## 4.1 空气质量预测算法

### 4.1.1 算法流程图
```mermaid
graph TD
    A[数据预处理] --> B[特征提取]
    B --> C[选择模型]
    C --> D[训练模型]
    D --> E[预测空气质量]
```

### 4.1.2 算法实现代码
```python
import pandas as pd
from sklearn.linear_model import LinearRegression

# 数据预处理
data = pd.read_csv('air_quality.csv')
data = data.dropna()

# 特征提取
features = data[['温度', '湿度', '风速']]
target = data['PM2.5']

# 训练模型
model = LinearRegression()
model.fit(features, target)

# 预测空气质量
new_data = [[25, 60, 5]]  # 示例输入
prediction = model.predict(new_data)
print("预测PM2.5值:", prediction[0])
```

### 4.1.3 数学模型
$$ PM2.5 = \beta_0 + \beta_1 \times 温度 + \beta_2 \times 湿度 + \beta_3 \times 风速 $$
