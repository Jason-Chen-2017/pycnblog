# 第1章: 特价股票策略与风险平价投资的背景介绍

## 1.1 特价股票策略的基本概念

### 1.1.1 什么是特价股票策略
特价股票策略是指在特定市场条件下，以低于市场价购买股票的策略。这种策略通常适用于市场低估或公司困境时期，旨在通过低价买入高价卖出来获利。

### 1.1.2 特价股票策略的核心特点
- **低买高卖**：利用市场低估时买入，市场高估时卖出。
- **逆向投资**：在市场恐慌时买入，市场乐观时卖出。
- **风险管理**：通过分散投资和严格止损控制风险。

### 1.1.3 特价股票策略的应用场景
- 市场下跌周期。
- 公司困境时期。
- 市场恐慌阶段。

## 1.2 风险平价投资的基本概念

### 1.2.1 风险平价投资的定义
风险平价投资是一种投资策略，旨在在不同的资产或资产类别之间分配风险，使得每种资产的风险贡献相等。

### 1.2.2 风险平价投资的核心原理
- **风险分配**：根据波动率等风险指标，调整各资产的权重，使得每种资产的风险贡献相等。
- **动态调整**：根据市场变化，定期重新调整投资组合的风险分配。

### 1.2.3 风险平价投资与传统投资的区别
- **传统投资**：基于资产的预期收益和流动性进行投资。
- **风险平价投资**：基于资产的风险贡献进行投资。

## 1.3 特价股票策略与风险平价投资的结合

### 1.3.1 特价股票策略在风险平价投资中的作用
- **风险分散**：通过引入特价股票，降低投资组合的整体风险。
- **收益增强**：在市场低估时买入特价股票，提高投资组合的潜在收益。

### 1.3.2 风险平价投资视角下的特价股票策略优化
- **风险调整**：在风险平价框架下，优化特价股票的权重，确保其风险贡献与其他资产一致。
- **动态调整**：根据市场变化，动态调整特价股票的持有比例。

### 1.3.3 二者的结合对投资组合的影响
- **风险分散**：通过引入特价股票，降低投资组合的整体风险。
- **收益增强**：在市场低估时买入特价股票，提高投资组合的潜在收益。

```python
def risk_parity_weight(asset_returns, n_assets):
    # 计算波动率
    volatility = asset_returns.std(ddof=1)
    # 计算相关性矩阵
    correlation_matrix = asset_returns.corr()
    # 构建协方差矩阵
    covariance_matrix = volatility * volatility * correlation_matrix
    # 计算风险平价权重
    weight = np.ones(n_assets) / n_assets
    return weight
```
