#### 1.1.1 价值投资的起源

价值投资是一种基于对公司内在价值评估的投资策略，其核心在于寻找市场价格低于内在价值的股票。本节将介绍价值投资的起源及其核心思想，帮助读者理解格雷厄姆理论的历史背景。

- **“捡烟蒂”投资策略**  
  格雷厄姆将投资比作“捡烟蒂”。他认为，市场先生的情绪波动为理性投资者提供了廉价买入优质资产的机会。这种策略强调在市场恐慌时买入被低估的股票。

- **核心思想**  
  格雷厄姆的价值投资理论强调安全边际和内在价值。他主张投资者应以低于内在价值的价格买入股票，并长期持有，等待市场重新认识其价值。

#### 1.1.2 格雷厄姆的“捡烟蒂”投资策略

- **捡烟蒂策略的核心**

- **市场波动与投资机会**

### 2.2 内在价值

#### 2.2.1 内在价值的定义

- **内在价值的定义**  
  内在价值是股票的真实价值，不受市场波动的影响。

- **计算模型**  
  内在价值可以通过多种方法计算，其中现金流折现法（DCF）是常用的模型。

#### 2.2.2 内在价值的计算模型

- **现金流折现法（DCF）**  
  DCF模型通过预测未来现金流并将其折现，计算股票的内在价值。

- **公式**  
  $$\text{内在价值} = \sum_{t=1}^{n} \frac{\text{现金流}_t}{(1 + r)^t} + \frac{\text{终值}}{(1 + r)^n}$$  
  其中，\( r \) 是折现率，\( n \) 是预测期数。

- **案例分析**  
  例如，假设某公司未来5年的现金流分别为100、120、130、150、180万元，折现率为10%。计算其内在价值。

#### 5.2.1 内在价值计算代码

- **代码实现**  
  ```python
  import pandas as pd
  import numpy as np

  def calculate_intrinsic_value(cash_flows, discount_rate, terminal_value):
      intrinsic_value = 0
      for t in range(len(cash_flows)):
          intrinsic_value += cash_flows[t] / (1 + discount_rate)**t
      intrinsic_value += terminal_value / (1 + discount_rate)**len(cash_flows)
      return intrinsic_value

  # 示例
  cash_flows = [100, 120, 130, 150, 180]
  discount_rate = 0.1
  terminal_value = 200
  iv = calculate_intrinsic_value(cash_flows, discount_rate, terminal_value)
  print(f"内在价值为：{iv:.2f}万元")
  ```
