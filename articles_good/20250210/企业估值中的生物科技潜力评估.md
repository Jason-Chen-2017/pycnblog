## 3. 算法原理

### 3.1 潜力评估模型的数学模型

潜力评估模型通过加权平均的方式，将技术创新性、市场潜力、研发能力和知识产权等指标进行量化评估。

#### 公式

$$
\text{潜力指数} = \sum_{i=1}^{n} w_i \cdot x_i
$$

其中，\( w_i \) 是指标 \( i \) 的权重，\( x_i \) 是指标 \( i \) 的评分（1-10分）。

#### 示例

假设某企业技术创新性得分为8，市场潜力得分为7，研发能力得分为9，知识产权得分为6，各指标的权重分别为30%、30%、20%、20%。

$$
\text{潜力指数} = 0.3 \cdot 8 + 0.3 \cdot 7 + 0.2 \cdot 9 + 0.2 \cdot 6 = 2.4 + 2.1 + 1.8 + 1.2 = 7.5
$$

import numpy as np

def calculate_potential_index(technological_innovation, market_potential, R&D_capability, intellectual_property):
    weights = {
        'technological_innovation': 0.3,
        'market_potential': 0.3,
        'R&D_capability': 0.2,
        'intellectual_property': 0.2
    }
    index = (
        weights['technological_innovation'] * technological_innovation +
        weights['market_potential'] * market_potential +
        weights['R&D_capability'] * R&D_capability +
        weights['intellectual_property'] * intellectual_property
    )
    return index

# 示例数据
technological_innovation = 8
market_potential = 7
R&D_capability = 9
intellectual_property = 6

potential_index = calculate_potential_index(technological_innovation, market_potential, R&D_capability, intellectual_property)
print(f"潜力指数为：{potential_index}")
