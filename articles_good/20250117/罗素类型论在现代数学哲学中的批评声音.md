### 1. 类型判断示例

以下代码展示了如何使用Python的类型判断功能来验证两个对象是否属于同一类型。

```python
def is_type_equal(a, b):
    return type(a) == type(b)

a = 10
b = 20
c = "Hello"

print(is_type_equal(a, b))  # 输出：True

```

在这个示例中，`is_type_equal`函数通过比较两个对象`a`和`b`的类型，判断它们是否相等。由于`a`和`b`都是整数类型，所以返回`True`；而`a`是整数类型，`c`是字符串类型，所以返回`False`。

### 2. 类型错误处理示例

在处理不同类型的数据时，如果发生类型错误，Python会抛出一个`TypeError`异常。以下代码展示了如何捕获并处理类型错误。

```python
def add(a, b):
    if not (isinstance(a, (int, float)) and isinstance(b, (int, float))):
        raise TypeError("参数必须为数字类型")
    return a + b

try:
    result = add(10, "20")
except TypeError as e:
    print(e)  # 输出："参数必须为数字类型"
```

在这个示例中，`add`函数要求传入的两个参数都是数字类型（整数或浮点数）。如果参数类型不匹配，函数会抛出一个`TypeError`异常，并通过`except`语句捕获并打印错误信息。

### 3. 集合类型的区分

在Python中，集合（`set`）中的元素必须具有相同的类型。以下代码展示了如何创建和验证集合中的元素类型。

```python
def create_set(element_type, elements):
    if not all(isinstance(e, element_type) for e in elements):
        raise TypeError("集合中元素类型不一致")
    return set(elements)

int_set = create_set(int, [1, 2, 3])
str_set = create_set(str, ["a", "b", "c"])

print(int_set)  # 输出：{1, 2, 3}
print(str_set)  # 输出：{'a', 'b', 'c'}

# 下面尝试创建一个包含不同类型元素的集合，会抛出TypeError
try:
    mixed_set = create_set(int, [1, "2", 3])
except TypeError as e:
    print(e)  # 输出："集合中元素类型不一致"
```

在这个示例中，`create_set`函数要求所有传入的元素都具有相同的类型。如果元素的类型不一致，函数会抛出一个`TypeError`异常。

class Product:
    def __init__(self, id, name, price, stock, category):

        self.name = name
        self.price = price
        self.stock = stock
        self.category = category

        self.price = new_price

class Order:

        self.id = id
        self.status = status
        self.created_at = created_at
        self.updated_at = updated_at

    def update_status(self, new_status):
        valid_statuses = ["待支付", "已支付", "已发货", "已取消"]
        if new_status not in valid_statuses:
            raise ValueError("非法订单状态")

#### 支付处理模块

```python
class Payment:
    def __init__(self, id, status, created_at, updated_at, amount):
        self.id = id
        self.status = status
        self.created_at = created_at
        self.updated_at = updated_at
        self.amount = amount

    def verify_payment(self, expected_amount):
        if not isinstance(expected_amount, (int, float)):
            raise TypeError("支付金额必须为数值类型")
        if self.amount != expected_amount:
            raise ValueError("支付金额不正确")
        self.status = "已支付"
```
