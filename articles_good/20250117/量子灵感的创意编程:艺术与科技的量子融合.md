### 第3章：量子基本原理

#### 3.1 量子位与经典位的比较

量子计算的基本单位是量子位（qubit），与传统计算机中的经典位（bit）有本质的区别。以下是一个关于量子位与经典位比较的表格：

| 特性           | 量子位                     | 经 Classic 位                      |
|----------------|----------------------------|-----------------------------------|
| 存储信息方式   | 利用量子叠加与量子纠缠     | 二进制表示，0 或 1                |
| 速度           | 非线性增长，遵循量子叠加原理 | 线性增长，遵循经典计算规则         |
| 并行计算       | 能够同时处理多个计算任务   | 逐个处理计算任务                   |
| 漂移与纠错     | 易受外界干扰，需要纠错机制 | 稳定性较高，无需纠错机制           |

#### 3.2 量子叠加与量子纠缠

以下是一个使用Python和Qiskit库实现的量子计算算法示例：

```python
from qiskit import QuantumCircuit, execute, Aer
from qiskit.visualization import plot_bloch_vector

# 创建量子电路
qc = QuantumCircuit(2)

# 应用量子门
qc.h(0)  # Hadamard门，初始化量子位为叠加态
qc.cx(0, 1)  # 控制非门，实现量子位的纠缠

# 执行量子电路
backend = Aer.get_backend('statevector_simulator')
result = execute(qc, backend).result()

# 输出结果
print("量子电路输出：", result.get_statevector())

# 绘制量子态的Bloch图
state = result.get_statevector()
plot_bloch_vector(state, title='Quantum State')
```

这个示例中，我们创建了一个包含两个量子位的量子电路，并应用了Hadamard门和控制非门，以实现量子位的叠加和纠缠。
