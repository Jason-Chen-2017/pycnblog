#### 第2章: AI编程的核心算法

##### 2.1 监督学习算法

**定义和原理**: 监督学习是一种从标注数据中学习预测函数的机器学习技术。其核心是利用已知的输入输出对（特征和标签）来训练模型。

**常见监督学习算法**:
- 线性回归
- 决策树
- 集成方法（如随机森林、梯度提升树）

**应用**:
- 预测股票价格
- 医疗诊断
- 文本分类

**算法原理讲解** (Mermaid流程图):
```mermaid
flowchart LR
A[初始化模型] --> B[输入特征和标签]
B --> C{计算预测值}
C --> D[计算损失函数]
D --> E{更新模型参数}
E --> F[重复步骤B-D直至收敛]
```

**Python源代码示例**:
```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 假设我们有特征 X 和标签 y
X = np.array([[1], [2], [3], [4]])
y = np.array([1, 2, 3, 4])

# 初始化线性回归模型
model = LinearRegression()

# 训练模型
model.fit(X, y)

# 预测
predictions = model.predict(X)

# 输出预测结果
print(predictions)
```

**数学模型和公式**:
- 损失函数：$$ L(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2 $$
- 参数更新：$$ \theta_j := \theta_j - \alpha \frac{\partial L(\theta)}{\partial \theta_j} $$

**举例说明**: 假设我们有一组数据，特征和标签之间的关系是线性的。通过线性回归模型，我们可以预测未知数据的标签值。

##### 2.2 无监督学习算法

**定义和原理**: 无监督学习是一种在没有标注数据的情况下，从数据中学习结构和模式的方法。

**常见无监督学习算法**:
- K-means聚类
- 主成分分析（PCA）
- 自编码器

**应用**:
- 数据降维
- 图像分割
- 探索性数据分析

**算法原理讲解** (Mermaid流程图):
```mermaid
flowchart LR
A[初始化聚类中心] --> B[计算距离]
B --> C{分配数据点}
C --> D[重新计算聚类中心]
D --> E{重复步骤B-D直至收敛}
```

**Python源代码示例**:
```python
import numpy as np
from sklearn.cluster import KMeans

# 假设我们有数据 X
X = np.array([[1, 2], [1, 4], [1, 0], [4, 2], [4, 4], [4, 0]])

# 初始化 K-means 模型，设置聚类数量为2
kmeans = KMeans(n_clusters=2, random_state=0).fit(X)

# 输出聚类结果
print(kmeans.labels_)
```

**数学模型和公式**:
- 距离计算：$$ d(x_i, c_j) = \sqrt{\sum_{k=1}^{n} (x_i^k - c_j^k)^2} $$
- 聚类中心更新：$$ c_j := \frac{1}{N_j} \sum_{i=1}^{m} x_i^{(j)} $$

**举例说明**: 假设我们有一组二维数据，通过K-means算法，我们可以将数据分为两个簇。

##### 2.3 强化学习算法

**定义和原理**: 强化学习是一种通过与环境交互来学习最优策略的方法。其核心是利用奖励信号来调整行为。

**常见强化学习算法**:
- Q-Learning
- Deep Q-Network (DQN)
- Policy Gradient

**应用**:
- 游戏智能
- 自动驾驶
- 机器人控制

**算法原理讲解** (Mermaid流程图):
```mermaid
flowchart LR
A[初始化Q值] --> B[选择动作]
B --> C{执行动作并获取奖励}
C --> D[更新Q值]
D --> E{重复步骤B-D直至收敛}
```

**Python源代码示例**:
```python
import numpy as np
from reinforcement_learning import QLearning

# 初始化 Q-Learning 模型
ql = QLearning()

# 进行N次迭代
for i in range(N):
    state = env.reset()
    done = False
    while not done:
        action = ql.choose_action(state)
        next_state, reward, done = env.step(action)
        ql.learn(state, action, reward, next_state, done)
        state = next_state
```

**数学模型和公式**:
- Q值更新：$$ Q(s, a) := Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)] $$
- 策略更新：$$ \pi(s) := \arg\max_a [Q(s, a)] $$

**举例说明**: 假设我们使用Q-Learning算法来训练一个智能体在迷宫中找到出口。


**数学模型和公式**:
- 损失函数：$$ L(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2 $$
- 参数更新：$$ \theta_j := \theta_j - \alpha \frac{\partial L(\theta)}{\partial \theta_j} $$

**举例说明**: 假设我们有一组数据，特征和标签之间的关系是线性的。通过线性回归模型，我们可以预测未知数据的标签值。

##### 2.2 无监督学习算法

**定义和原理**: 无监督学习是一种在没有标注数据的情况下，从数据中学习结构和模式的方法。

**常见无监督学习算法**:
- K-means聚类
- 主成分分析（PCA）
- 自编码器

**应用**:
- 数据降维
- 图像分割
- 探索性数据分析

**算法原理讲解** (Mermaid流程图):
```mermaid
flowchart LR
A[初始化聚类中心] --> B[计算距离]
B --> C{分配数据点}
C --> D[重新计算聚类中心]
D --> E{重复步骤B-D直至收敛}
```

**Python源代码示例**:
```python
import numpy as np
from sklearn.cluster import KMeans

# 假设我们有数据 X
X = np.array([[1, 2], [1, 4], [1, 0], [4, 2], [4, 4], [4, 0]])

# 初始化 K-means 模型，设置聚类数量为2
kmeans = KMeans(n_clusters=2, random_state=0).fit(X)

# 输出聚类结果
print(kmeans.labels_)
```

**数学模型和公式**:
- 距离计算：$$ d(x_i, c_j) = \sqrt{\sum_{k=1}^{n} (x_i^k - c_j^k)^2} $$
- 聚类中心更新：$$ c_j := \frac{1}{N_j} \sum_{i=1}^{m} x_i^{(j)} $$

**举例说明**: 假设我们有一组二维数据，通过K-means算法，我们可以将数据分为两个簇。

##### 2.3 强化学习算法

**定义和原理**: 强化学习是一种通过与环境交互来学习最优策略的方法。其核心是利用奖励信号来调整行为。

**常见强化学习算法**:
- Q-Learning
- Deep Q-Network (DQN)
- Policy Gradient

**应用**:
- 游戏智能
- 自动驾驶
- 机器人控制

**算法原理讲解** (Mermaid流程图):
```mermaid
flowchart LR
A[初始化Q值] --> B[选择动作]
B --> C{执行动作并获取奖励}
C --> D[更新Q值]
D --> E{重复步骤B-D直至收敛}
```

**Python源代码示例**:
```python
import numpy as np
from reinforcement_learning import QLearning

# 初始化 Q-Learning 模型
ql = QLearning()

# 进行N次迭代
for i in range(N):
    state = env.reset()
    done = False
    while not done:
        action = ql.choose_action(state)
        next_state, reward, done = env.step(action)
        ql.learn(state, action, reward, next_state, done)
        state = next_state
```

**数学模型和公式**:
- Q值更新：$$ Q(s, a) := Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)] $$
- 策略更新：$$ \pi(s) := \arg\max_a [Q(s, a)] $$

**举例说明**: 假设我们使用Q-Learning算法来训练一个智能体在迷宫中找到出口。
