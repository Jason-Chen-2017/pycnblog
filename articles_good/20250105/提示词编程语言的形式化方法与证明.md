**形式化证明的案例分析**

以下是一个形式化证明的案例分析，它使用证明责任方法来证明一个简单的程序的正确性：

```
断言：对于所有整数 n，如果 n > 0，则 n * n > n。

证明：

- 归纳步骤：假设对于所有小于 n 的正整数，断言成立。
- 需要证明：对于 n > 0，断言成立。
- 根据归纳假设，n - 1 * (n - 1) > n - 1。
- 由于 n > n - 1，我们有 n * n > n - 1 * (n - 1)。
- 因此，n * n > n，断言成立。

结论：对于所有整数 n，如果 n > 0，则 n * n > n。
```

这个案例展示了如何使用证明责任方法来证明一个简单的数学断言的正确性。通过逻辑推理和归纳步骤，我们成功地证明了断言的普遍性。
