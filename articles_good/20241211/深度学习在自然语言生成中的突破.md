> 摘要：本文从自然语言生成的背景和挑战出发，详细探讨了深度学习在自然语言生成中的应用。通过分析生成模型、序列到序列模型以及预训练模型等核心技术的原理和应用，本文揭示了深度学习在自然语言生成中的突破，为后续研究提供了有益的参考。

### 引言

#### 自然语言生成的背景

自然语言生成（Natural Language Generation，NLG）是自然语言处理（Natural Language Processing，NLP）的一个重要分支，旨在利用计算机程序生成具有可读性的自然语言文本。自然语言生成技术的研究始于20世纪50年代，最初采用规则驱动的方法，即通过定义语法规则和语义规则来生成文本。然而，这些方法存在局限性，难以应对复杂的语言现象和多样性。

随着计算技术的发展，统计方法和深度学习逐渐成为自然语言生成的主要方法。统计方法通过分析大量语言数据，利用概率模型生成文本。而深度学习方法则利用神经网络模型，特别是生成对抗网络（GAN）和序列到序列（Seq2Seq）模型，实现了更高质量的自然语言生成。

#### 深度学习在自然语言生成中的应用背景

深度学习是一种基于多层神经网络的学习方法，具有强大的特征提取和建模能力。近年来，深度学习在计算机视觉、语音识别和自然语言处理等领域取得了显著的突破。自然语言生成作为NLP的重要方向，自然也成为深度学习研究的热点。

深度学习在自然语言生成中的应用主要体现在以下几个方面：

1. **词向量表示**：词向量是将词汇映射到高维空间中的向量表示，能够捕捉词汇的语义和语法信息。词向量在深度学习模型中起到了关键作用，为模型提供了有效的输入表示。

2. **生成模型**：生成模型是一类用于生成数据的高维概率分布模型，如生成对抗网络（GAN）和变分自编码器（VAE）。这些模型能够学习数据的潜在分布，从而生成高质量的自然语言文本。

3. **序列到序列模型**：序列到序列（Seq2Seq）模型是一种将输入序列映射到输出序列的神经网络模型，广泛应用于机器翻译、对话系统和文本摘要等领域。

4. **预训练模型**：预训练模型通过在大规模语料库上进行预训练，获得了丰富的语言知识和上下文理解能力，再通过微调适应特定任务。预训练模型在自然语言生成任务中表现出色，提高了生成文本的质量和多样性。

### 核心内容

#### 1. 生成模型

生成模型是一类用于生成数据的高维概率分布模型，包括生成对抗网络（GAN）和变分自编码器（VAE）等。这些模型通过学习数据的潜在分布，能够生成高质量的自然语言文本。

**生成对抗网络（GAN）**

生成对抗网络（GAN）由生成器（Generator）和判别器（Discriminator）两个神经网络组成。生成器旨在生成逼真的数据，判别器则用于区分真实数据和生成数据。在训练过程中，生成器和判别器相互对抗，生成器不断优化，使得生成的数据越来越逼真。

GAN在自然语言生成中的应用主要包括文本生成和图像生成。在文本生成方面，GAN可以生成连贯、自然的文本段落；在图像生成方面，GAN可以生成高质量的图像，甚至可以模拟不同的绘画风格。

**变分自编码器（VAE）**

变分自编码器（VAE）是一种基于概率模型的生成模型，通过编码器（Encoder）和解码器（Decoder）两个神经网络结构实现数据的生成。编码器将输入数据映射到一个潜在的分布上，解码器则从潜在分布中生成数据。

VAE在自然语言生成中的应用主要包括文本生成和数据增强。通过VAE，可以生成高质量的自然语言文本，同时还可以用于增强训练数据，提高模型的泛化能力。

#### 2. 序列到序列模型

序列到序列（Seq2Seq）模型是一种将输入序列映射到输出序列的神经网络模型，广泛应用于机器翻译、对话系统和文本摘要等领域。

**序列到序列模型的原理**

Seq2Seq模型通常由编码器（Encoder）和解码器（Decoder）两个部分组成。编码器将输入序列编码为一个固定长度的向量，解码器则根据编码器的输出和之前的隐藏状态生成输出序列。

编码器和解码器通常采用循环神经网络（RNN）或其变体，如长短时记忆网络（LSTM）和门控循环单元（GRU）。这些神经网络能够捕捉输入序列中的长期依赖关系，从而生成高质量的输出序列。

**序列到序列模型的应用**

机器翻译：Seq2Seq模型在机器翻译任务中表现出色。通过编码器和解码器，Seq2Seq模型可以将源语言的句子映射到目标语言的句子，实现了高质量的双语翻译。

对话系统：Seq2Seq模型在对话系统中也被广泛应用。编码器将用户输入的句子编码为一个固定长度的向量，解码器则根据编码器的输出和用户输入的上下文生成回复句子。

文本摘要：Seq2Seq模型在文本摘要任务中也取得了显著的效果。编码器将原始文本编码为一个固定长度的向量，解码器则根据编码器的输出生成摘要文本。

#### 3. 预训练模型与微调

预训练模型是一种在大规模语料库上进行预训练，然后在特定任务上进行微调的深度学习模型。预训练模型通过预训练获得了丰富的语言知识和上下文理解能力，从而提高了特定任务的性能。

**预训练模型**

预训练模型主要包括词向量模型（如Word2Vec和GloVe）和语言模型（如BERT和GPT）。这些模型通过在大规模语料库上进行预训练，学习到了词汇的语义和语法信息，为下游任务提供了有效的输入表示。

**微调**

微调是在预训练模型的基础上，针对特定任务进行进一步训练的过程。通过微调，预训练模型可以适应特定任务的需求，提高任务性能。

在自然语言生成任务中，预训练模型和微调相结合，能够生成高质量的自然语言文本。例如，GPT-2和GPT-3等大型预训练模型在文本生成任务中取得了显著的效果。

### 应用案例

#### 1. 文本摘要

文本摘要是一种将原始文本压缩为简洁、准确摘要的技术。深度学习在文本摘要任务中取得了显著的进展。

**提取式摘要**：提取式摘要通过从原始文本中提取关键句子来生成摘要。基于深度学习的提取式摘要方法，如Seq2Seq模型和BERT模型，能够生成高质量、简洁的摘要。

**生成式摘要**：生成式摘要以无监督的方式生成摘要，通常采用生成模型，如GAN和VAE。生成式摘要能够生成更具有创造性和灵活性的摘要，但质量可能不如提取式摘要。

**混合式摘要**：混合式摘要结合了提取式摘要和生成式摘要的优点，通过提取关键句子和生成补充信息来生成摘要。基于深度学习的混合式摘要方法，如Seq2Seq模型和BERT模型，取得了良好的效果。

### 1.1 自然语言生成的定义

自然语言生成（Natural Language Generation，NLG）是一种利用计算机程序生成具有可读性的自然语言文本的技术。NLG旨在使计算机能够理解和生成人类语言，从而实现人机交互、自动内容生成和智能客服等应用。

NLG的定义可以从以下几个方面来理解：

1. **生成目标**：NLG的目标是生成具有可读性和可理解性的自然语言文本。这些文本可以是句子、段落或整篇文章，能够传达作者意图、语义和信息。

2. **生成过程**：NLG的过程涉及多个步骤，包括文本输入、语义分析、语法生成和文本输出。文本输入可以是用户指令、文本片段或其他形式的数据。语义分析旨在理解输入文本的语义内容，语法生成则负责将语义内容转换为符合语法规则的句子结构。最后，文本输出是生成的自然语言文本。

3. **应用领域**：NLG的应用领域非常广泛，包括但不限于以下几方面：
   - **内容生成**：NLG可以用于生成新闻文章、博客文章、产品描述等，提高内容生产效率。
   - **对话系统**：NLG可以用于构建智能客服、聊天机器人等对话系统，实现自然语言交互。
   - **机器翻译**：NLG与机器翻译相结合，可以实现双语文本的实时转换。
   - **文本摘要**：NLG可以用于提取原始文本的关键信息，生成简洁、准确的摘要。

### 1.2 自然语言生成的发展历程

自然语言生成技术的研究始于20世纪50年代，经历了从规则方法到统计方法，再到深度学习方法的发展历程。

#### 1. 规则方法

早期的自然语言生成主要采用规则驱动的方法，通过定义语法规则和语义规则来生成文本。这种方法的主要优点是生成文本的语法和语义结构较为严格，但存在以下局限性：

1. **规则复杂度**：随着语言复杂度的增加，规则的数量和复杂度呈指数级增长，导致生成文本的质量难以保证。
2. **可扩展性**：规则方法难以应对多种语言和语言变体，可扩展性较差。
3. **灵活性和创造性**：规则方法生成文本的灵活性和创造性较差，难以生成具有个性化和创造性的文本。

#### 2. 统计方法

为了解决规则方法的局限性，自然语言生成领域开始探索统计方法。统计方法通过分析大量语言数据，利用概率模型生成文本。统计方法的发展可以分为以下几个阶段：

1. **基于语法分析的方法**：基于语法分析的方法利用概率图模型（如概率上下文无关文法PCFG）来生成文本。这种方法通过分析句子结构和语法规则，生成符合语法规则的文本。

2. **基于词序列的方法**：基于词序列的方法（如n-gram模型）通过统计词序列的频率来生成文本。这种方法简单高效，但生成的文本存在较长依赖关系问题。

3. **基于隐马尔可夫模型的方法**：隐马尔可夫模型（HMM）是一种统计模型，可以用于语音识别、语音合成和自然语言生成。HMM通过统计前后词汇的概率分布来生成文本。

4. **基于条件概率的方法**：条件概率方法利用条件概率分布来生成文本。例如，给定一个词序列，计算生成下一个词的概率分布，从而生成完整的文本。

#### 3. 深度学习方法

随着深度学习技术的发展，自然语言生成领域逐渐将深度学习方法应用于文本生成。深度学习方法具有强大的特征提取和建模能力，在自然语言生成中取得了显著突破。深度学习方法的发展可以分为以下几个阶段：

1. **基于循环神经网络的方法**：循环神经网络（RNN）是一种能够处理序列数据的长短时记忆网络。RNN在自然语言生成中应用于生成文本序列。然而，RNN存在梯度消失和梯度爆炸等问题，影响了模型的训练效果。

2. **长短时记忆网络（LSTM）和门控循环单元（GRU）**：为了解决RNN的问题，研究人员提出了长短时记忆网络（LSTM）和门控循环单元（GRU）。LSTM和GRU通过引入门控机制，有效地解决了梯度消失和梯度爆炸问题，提高了模型的训练效果。

3. **基于Transformer的方法**：Transformer模型是一种基于自注意力机制的深度学习模型，广泛应用于自然语言处理任务。Transformer模型在自然语言生成中表现出色，解决了长依赖关系问题，提高了生成文本的质量。

4. **生成对抗网络（GAN）**：生成对抗网络（GAN）是一种基于博弈论的生成模型，由生成器和判别器两个神经网络组成。生成器负责生成数据，判别器负责区分真实数据和生成数据。GAN在自然语言生成中应用于生成高质量的自然语言文本。

### 基本原理

生成模型的核心思想是通过学习数据的潜在分布，将潜在空间中的样本映射到数据空间中，从而生成新的数据。生成模型通常由两部分组成：生成器（Generator）和判别器（Discriminator）。

1. **生成器（Generator）**：生成器的任务是生成符合数据分布的新数据。生成器通常是一个神经网络，它将潜在空间中的随机样本映射到数据空间中。生成器的目标是最小化生成数据与真实数据之间的差异。

2. **判别器（Discriminator）**：判别器的任务是区分真实数据和生成数据。判别器也是一个神经网络，它接收数据空间中的样本，并输出一个概率值，表示样本是真实数据还是生成数据。判别器的目标是最小化生成数据与真实数据之间的相似性。

生成器和判别器相互竞争，生成器的目标是生成更逼真的数据，而判别器的目标是准确地区分真实数据和生成数据。这种博弈过程使得生成器的性能不断提高，从而生成高质量的新数据。

### 经典模型

生成模型有多种类型，以下是几种经典的生成模型：

1. **生成对抗网络（Generative Adversarial Network，GAN）**：生成对抗网络（GAN）是由 Ian Goodfellow 等人于2014年提出的一种生成模型。GAN由生成器和判别器两个神经网络组成，生成器和判别器之间进行博弈。生成器的目标是生成逼真的数据，判别器的目标是区分真实数据和生成数据。GAN在图像生成、文本生成和音频生成等领域取得了显著的成功。

2. **变分自编码器（Variational Autoencoder，VAE）**：变分自编码器（VAE）是一种基于概率模型的生成模型。VAE由编码器（Encoder）和解码器（Decoder）两部分组成。编码器将输入数据映射到一个潜在空间中的均值和方差，解码器从潜在空间中采样，并生成重构数据。VAE在图像生成、文本生成和语音生成等领域也得到了广泛的应用。

3. **深度信念网络（Deep Belief Network，DBN）**：深度信念网络（DBN）是一种基于概率模型的深度学习网络。DBN由多个隐层组成，每两层之间使用受限玻尔兹曼机（RBM）连接。DBN在图像生成、语音生成和文本生成等领域表现出色。

4. **生成扩散模型（Generative Diffusion Model）**：生成扩散模型（Generative Diffusion Model）是一种通过连续时间过程来生成数据的新型生成模型。生成扩散模型通过将数据从确定性的状态逐渐扩散到随机状态，再从随机状态重构出数据。生成扩散模型在图像生成和语音生成等领域取得了显著的成功。

### 生成模型在自然语言生成中的应用

生成模型在自然语言生成领域有广泛的应用，以下是一些典型的应用场景：

1. **文本生成**：文本生成是生成模型在自然语言生成中最典型的应用。生成模型可以用于生成新闻文章、博客文章、产品描述等。通过学习大量文本数据，生成模型可以生成具有可读性和连贯性的自然语言文本。

3. **语音生成**：生成模型可以用于生成高质量的语音。例如，变分自编码器（VAE）可以用于语音合成，生成与人类语音相似的合成语音。

序列到序列（Seq2Seq）模型是一种用于将输入序列映射到输出序列的神经网络模型，广泛应用于机器翻译、对话系统和文本摘要等领域。本节将介绍序列到序列模型的基本原理、常见架构和训练过程。

### 基本原理

序列到序列模型的核心思想是将输入序列的每个元素映射到输出序列的对应元素。这种模型通常由编码器（Encoder）和解码器（Decoder）两个部分组成，其中编码器负责将输入序列编码为一个固定长度的向量表示，解码器则根据编码器的输出和先前的隐藏状态生成输出序列。

1. **编码器（Encoder）**：编码器是一个神经网络，它将输入序列（如单词序列）编码为一个固定长度的向量表示。编码器的输出通常称为上下文向量（Context Vector），它包含了输入序列的语义信息。

2. **解码器（Decoder）**：解码器也是一个神经网络，它根据编码器的输出和先前的隐藏状态生成输出序列。解码器的输入是编码器的输出，输出是生成的单词序列。解码器在生成每个单词时，都会利用先前的隐藏状态，从而确保生成的单词序列具有连贯性和一致性。

3. **注意力机制（Attention Mechanism）**：为了更好地利用编码器的输出，序列到序列模型中常常引入注意力机制。注意力机制允许解码器在生成每个单词时，动态关注编码器的输出中的关键信息。这样，解码器可以更好地理解输入序列的上下文信息，从而提高生成文本的质量。

### 常见架构

序列到序列模型的常见架构包括以下几种：

1. **循环神经网络（RNN）架构**：循环神经网络（RNN）是一种能够处理序列数据的神经网络。在序列到序列模型中，编码器和解码器通常都采用 RNN 架构。RNN 通过隐藏状态来捕捉输入序列中的长期依赖关系，但 RNN 存在梯度消失和梯度爆炸等问题，影响了模型的训练效果。

2. **长短时记忆网络（LSTM）架构**：长短时记忆网络（LSTM）是一种改进的 RNN 架构，它通过引入门控机制来解决这个问题。LSTM 在编码器和解码器中都得到广泛应用，能够有效地捕捉输入序列中的长期依赖关系。

3. **门控循环单元（GRU）架构**：门控循环单元（GRU）是另一种改进的 RNN 架构，它在 LSTM 的基础上进行了简化。GRU 在编码器和解码器中也表现出色，同时计算效率更高。

4. **Transformer 架构**：Transformer 是一种基于自注意力机制的深度学习模型，它在序列到序列模型中取得了显著的成功。Transformer 通过多头自注意力机制和位置编码，能够捕捉输入序列中的长距离依赖关系，从而提高了生成文本的质量。

### 训练过程

序列到序列模型的训练过程可以分为以下几个步骤：

1. **输入序列编码**：首先，将输入序列编码为嵌入向量表示。嵌入向量是输入序列的离散表示，通常使用词向量模型（如 Word2Vec、GloVe）进行训练。

2. **编码器训练**：编码器的训练目标是学习输入序列的编码表示。通过在训练数据上训练编码器，编码器可以捕捉输入序列的语义信息。

3. **解码器训练**：解码器的训练目标是学习输入序列到输出序列的映射。在训练过程中，解码器在生成每个单词时，都会利用编码器的输出和先前的隐藏状态。通过反向传播和梯度下降算法，解码器可以不断优化其参数。

4. **注意力机制训练**：如果模型中使用了注意力机制，还需要训练注意力机制。注意力机制的训练目标是最小化解码器在生成每个单词时的损失函数。通过训练，注意力机制可以动态关注输入序列中的关键信息，从而提高生成文本的质量。

5. **损失函数优化**：在训练过程中，使用损失函数来衡量模型在预测输出序列时的性能。常见的损失函数包括交叉熵损失函数和均方误差损失函数。通过优化损失函数，模型可以不断调整参数，提高预测性能。

6. **评估与调整**：在训练过程中，定期评估模型的性能，并根据评估结果调整模型参数。通过调整参数，模型可以更好地适应不同任务和数据集。

### 预训练模型的基本概念

预训练模型是指在大规模语料库上进行训练，从而学习到丰富的语言知识和上下文理解能力的深度学习模型。预训练模型通常包括词向量模型（Word Embedding）和语言模型（Language Model）。

1. **词向量模型（Word Embedding）**：词向量模型是将词汇映射到高维空间中的向量表示，能够捕捉词汇的语义和语法信息。常见的词向量模型包括 Word2Vec、GloVe 和 BERT 等。

2. **语言模型（Language Model）**：语言模型是一种用于预测下一个单词或词组的概率分布模型。语言模型通过学习大量文本数据，能够理解自然语言的统计特性，从而提高文本生成和分类任务的性能。

### 常见的预训练模型

1. **Word2Vec**：Word2Vec 是一种基于神经网络的语言模型，它通过预测相邻单词的分布来学习词向量。Word2Vec 模型采用 skip-gram 方法，将每个单词作为中心词，预测其上下文词的概率分布。

2. **GloVe**：GloVe 是一种基于全局词汇向量的语言模型，它通过计算单词共现矩阵的奇异值分解来学习词向量。GloVe 模型能够更好地捕捉词汇的语义关系。

3. **BERT**：BERT（Bidirectional Encoder Representations from Transformers）是一种基于 Transformer 架构的双向编码器表示模型。BERT 通过预训练大量文本数据，学习到了丰富的语言知识和上下文理解能力，从而提高了文本分类和命名实体识别等任务的性能。

4. **GPT**：GPT（Generative Pre-trained Transformer）是一种基于 Transformer 架构的生成模型。GPT 通过预训练大量文本数据，学习到了语言生成的能力，从而提高了文本生成和问答等任务的性能。

5. **RoBERTa**：RoBERTa 是 BERT 模型的变体，它在 BERT 的基础上进行了改进，如去除预训练中的回显（Masked LM）和引入更多训练数据等。RoBERTa 在多个自然语言处理任务中取得了比 BERT 更好的性能。

### 微调过程

微调（Fine-tuning）是在预训练模型的基础上，针对特定任务进行进一步训练的过程。通过微调，预训练模型可以适应特定任务的需求，提高任务性能。微调过程通常包括以下步骤：

1. **数据预处理**：首先，对特定任务的数据集进行预处理，如分词、去停用词、标签编码等。

2. **加载预训练模型**：加载预训练模型，如 BERT 或 GPT 等。预训练模型已经在大规模语料库上进行了训练，学习到了丰富的语言知识和上下文理解能力。

3. **微调模型**：在预训练模型的基础上，针对特定任务进行微调。微调过程中，通常只调整模型的最后几层（或特定层）的参数，以避免过拟合。通过反向传播和梯度下降算法，模型可以不断调整参数，提高特定任务的性能。

4. **评估与调整**：在微调过程中，定期评估模型的性能，并根据评估结果调整模型参数。通过评估，可以确定模型的性能是否得到提高，以及是否需要进一步调整。

5. **应用**：微调完成后，模型可以应用于特定任务，如文本分类、命名实体识别、机器翻译等。通过微调，预训练模型可以更好地适应特定任务，提高任务性能。

1. **基于规则的方法**：基于规则的方法通过定义语法规则和翻译规则来生成翻译结果。这种方法通常需要大量的语言学知识和手动编写的规则。基于规则的方法在翻译准确性和灵活性方面存在一定局限性。

2. **基于统计的方法**：基于统计的方法通过分析大量双语文本对，学习翻译规律，从而生成翻译结果。这种方法利用统计模型（如 n-gram 模型）来预测目标语言的单词序列。基于统计的方法在翻译准确性方面取得了显著进步，但仍然存在长距离依赖关系处理不足的问题。

3. **基于深度学习的方法**：基于深度学习的方法利用神经网络模型，如循环神经网络（RNN）、长短时记忆网络（LSTM）、门控循环单元（GRU）和 Transformer，实现了更高质量的机器翻译。深度学习方法能够自动提取语言特征，捕捉长距离依赖关系，从而生成更准确、自然的翻译结果。

### 常见方法

1. **基于规则的方法**：

   - **短语转换规则**：将源语言短语转换为目标语言短语，通过查找规则库来实现。

   - **部分翻译规则**：将源语言文本分为若干部分，分别进行翻译，然后组合成完整的翻译结果。

   - **词性标注规则**：根据词性标注规则，对源语言文本进行词性转换，从而生成目标语言文本。

2. **基于统计的方法**：

   - **统计机器翻译（SMT）**：统计机器翻译通过训练模型，利用源语言和目标语言的双语数据，学习翻译规律，从而生成翻译结果。

3. **基于深度学习的方法**：

   - **循环神经网络（RNN）**：循环神经网络是一种能够处理序列数据的神经网络，通过隐藏状态来捕捉输入序列中的长期依赖关系。

   - **长短时记忆网络（LSTM）**：长短时记忆网络是循环神经网络的一种改进，通过门控机制来缓解梯度消失问题，更好地捕捉输入序列中的长期依赖关系。

   - **门控循环单元（GRU）**：门控循环单元是另一种改进的循环神经网络，它在 LSTM 的基础上进行了简化，计算效率更高。

   - **Transformer**：Transformer 是一种基于自注意力机制的深度学习模型，通过多头自注意力机制和位置编码，能够捕捉输入序列中的长距离依赖关系。

### 深度学习在机器翻译中的应用

深度学习在机器翻译中的应用主要体现在以下几个方面：

1. **编码器-解码器（Encoder-Decoder）模型**：编码器-解码器模型是一种将输入序列映射到输出序列的神经网络模型。编码器将源语言文本编码为一个固定长度的向量表示，解码器根据编码器的输出生成目标语言文本。深度学习方法，如循环神经网络（RNN）、长短时记忆网络（LSTM）、门控循环单元（GRU）和 Transformer，广泛应用于编码器-解码器模型。

2. **注意力机制**：注意力机制是一种在神经网络中用于关注输入序列中的关键信息的机制。在机器翻译中，注意力机制可以帮助解码器在生成每个目标单词时，动态关注编码器的输出中的关键信息，从而提高翻译的准确性和连贯性。

3. **多任务学习**：多任务学习是一种将多个任务联合训练的方法，可以提高模型的泛化能力。在机器翻译中，多任务学习可以同时训练机器翻译模型和命名实体识别模型，从而提高模型的性能。

4. **预训练模型**：预训练模型是一种在大规模语料库上进行预训练，然后在特定任务上进行微调的深度学习模型。预训练模型，如 BERT、GPT 和 T5，在机器翻译任务中表现出色，通过预训练获得了丰富的语言知识和上下文理解能力。

import torch
import torch.nn as nn
from torch.optim import Adam
from transformers import GPT2LMHeadModel, GPT2Tokenizer

# 加载预训练模型和分词器
model = GPT2LMHeadModel.from_pretrained("gpt2")
tokenizer = GPT2Tokenizer.from_pretrained("gpt2")

# 输入文本
input_text = "This is a simple example of text generation."

# 将输入文本转换为模型可处理的格式
input_ids = tokenizer.encode(input_text, return_tensors='pt')

# 生成文本
output = model.generate(input_ids, max_length=50, num_return_sequences=1)

# 将生成的文本解码为可读格式
decoded_output = tokenizer.decode(output[0], skip_special_tokens=True)
print(decoded_output)
