### 算法 Python 源代码实现

接下来，我们将使用Python实现上述流程，并详细介绍各个步骤的算法原理和数学模型。

```python
# 城市共享宠物系统算法实现

class User:
    def __init__(self, name, role):
        self.name = name
        self.role = role

class Pet:
    def __init__(self, name, type, owner):
        self.name = name
        self.type = type
        self.owner = owner
        self.is_available = True

class Reservation:
    def __init__(self, user, pet, start_date, end_date):
        self.user = user
        self.pet = pet
        self.start_date = start_date
        self.end_date = end_date

class PetSharingSystem:
    def __init__(self):
        self.users = []
        self.pets = []
        self.reservations = []

    def register_user(self, user):
        self.users.append(user)

    def add_pet(self, pet):
        self.pets.append(pet)

    def make_reservation(self, user, pet, start_date, end_date):
        reservation = Reservation(user, pet, start_date, end_date)
        self.reservations.append(reservation)
        return reservation

    def confirm_reservation(self, reservation):
        if reservation.pet.is_available:
            reservation.pet.is_available = False
            return "Reservation confirmed."
        else:
            return "Pet not available."

    def return_pet(self, reservation):
        reservation.pet.is_available = True
        return "Pet returned."

# 实例化系统
system = PetSharingSystem()

# 注册用户
user1 = User("Alice", "PetOwner")
user2 = User("Bob", "CommunityMember")
system.register_user(user1)
system.register_user(user2)

# 添加宠物
pet1 = Pet("Lucky", "Dog", user1)
system.add_pet(pet1)

# 用户预约宠物
reservation = system.make_reservation(user2, pet1, "2023-04-01", "2023-04-05")
print(reservation)

# 确认预约
print(system.confirm_reservation(reservation))

# 归还宠物
print(system.return_pet(reservation))
```

### 算法原理详细讲解

#### 数学模型与公式

在城市共享宠物系统中，关键在于如何合理地安排和调度宠物资源的借用和归还。这可以通过以下数学模型和公式来实现：

1. **时间调度模型**：使用时间戳（timestamp）来表示宠物借用和归还的时间点。每个预约都有一个开始日期和结束日期，我们需要确保宠物在这些时间段内是可用的。

   $$ start\_date < current\_date < end\_date $$

2. **资源分配模型**：定义一个二进制变量`is_available`来表示宠物是否可用。当宠物被预约时，将其设置为`False`；当宠物被归还时，将其设置为`True`。

   $$ is\_available = \begin{cases} 
   1 & \text{if the pet is available} \\
   0 & \text{if the pet is not available} 
   \end{cases} $$

#### 算法举例说明

假设我们有两位用户Alice和Bob，Alice是宠物主人，Bob是社区居民。Alice有一条宠物狗Lucky，Bob希望在4月1日至4月5日借用Lucky。以下是具体步骤的算法解释：

1. **用户注册**：Alice和Bob分别注册成为用户，系统保存他们的信息。

   ```python
   user1 = User("Alice", "PetOwner")
   user2 = User("Bob", "CommunityMember")
   system.register_user(user1)
   system.register_user(user2)
   ```

2. **添加宠物**：Alice将自己的宠物Lucky添加到系统中。

   ```python
   pet1 = Pet("Lucky", "Dog", user1)
   system.add_pet(pet1)
   ```

3. **预约宠物**：Bob通过系统预约从4月1日至4月5日借用Lucky。

   ```python
   reservation = system.make_reservation(user2, pet1, "2023-04-01", "2023-04-05")
   ```

   系统会创建一个预约对象，并检查Lucky是否在预约时间段内可用。如果可用，预约成功；否则，预约失败。

4. **确认预约**：系统确认预约，并更新Lucky的`is_available`状态。

   ```python
   print(system.confirm_reservation(reservation))
   ```

   输出结果为"Reservation confirmed."，表示预约成功。

5. **归还宠物**：预约结束后，Bob将Lucky归还给Alice。

   ```python
   print(system.return_pet(reservation))
   ```

   输出结果为"Pet returned."，表示归还成功。

通过上述算法，系统有效地实现了宠物的借用和归还管理，确保了宠物资源的合理利用。
