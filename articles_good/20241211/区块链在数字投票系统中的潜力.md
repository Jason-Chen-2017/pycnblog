### 1.6 核心概念原理

#### 分布式账本

**原理**：分布式账本是一种去中心化的数据存储方式，它将数据分散存储在多个节点上，每个节点都保存了一份完整的账本副本。这种分布式结构使得数据无法被单一实体控制或篡改，从而提高了系统的可靠性和安全性。

**属性特征**：去中心化、安全性高、数据一致性。

**对比**：与传统的中心化数据库相比，分布式账本不依赖于单一的中央服务器，因此更难以受到攻击。此外，分布式账本具有更高的容错性，即使某些节点出现故障，整个系统仍然可以正常运行。

#### 智能合约

**原理**：智能合约是一种基于区块链的计算机协议，它能够自动执行合同条款。当满足特定的条件时，智能合约会自动执行相应的操作，如转账、投票结果统计等。

**属性特征**：自动执行、减少纠纷成本、提高效率。

**对比**：与传统的合同执行方式相比，智能合约能够自动执行合同条款，减少了人工干预和纠纷成本。此外，智能合约的透明性和不可篡改性提高了合同执行的公正性和可信度。

#### 4.6.3 代码应用解读与分析

以下是选举智能合约的核心代码：

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Election {
    // 候选人列表
    address[] public candidates;
    // 每个候选人的得票数
    mapping(address => uint) public vote_counts;
    // 投过票的选民
    mapping(address => bool) public voters;

    // 构造函数：初始化候选人列表
    constructor(address[] memory _candidates) {
        candidates = _candidates;
    }

    // 投票函数
    function vote(address candidate) public {
        require(!voters[msg.sender], "选民已投票");
        require(isValidCandidate(candidate), "无效候选人");

        voters[msg.sender] = true;
        vote_counts[candidate]++;
    }

    // 判断候选人是否有效
    function isValidCandidate(address candidate) public view returns (bool) {
        for (uint i = 0; i < candidates.length; i++) {
            if (candidates[i] == candidate) {
                return true;
            }
        }
        return false;
    }

    // 获取最终结果
    function getResults() public view returns (address[] memory) {
        address[] memory results = new address[](candidates.length);
        for (uint i = 0; i < candidates.length; i++) {
            results[i] = candidates[i];
        }
        return results;
    }
}
```

该智能合约定义了候选人列表、得票数和已投票选民，并提供投票、判断候选人和获取结果的功能。
