```python
def mix_colors(color1, color2, ratio):
    """
    混合两种颜色的函数
    :param color1: 第一种颜色
    :param color2: 第二种颜色
    :param ratio: 混合比例
    :return: 混合后的颜色
    """
    red = color1[0] * (1 - ratio) + color2[0] * ratio
    green = color1[1] * (1 - ratio) + color2[1] * ratio
    blue = color1[2] * (1 - ratio) + color2[2] * ratio
    return (int(red), int(green), int(blue))
```

在这个示例中，`color1` 和 `color2` 是两种颜色的三元组表示（红、绿、蓝），`ratio` 是混合比例。函数通过线性混合两种颜色的红、绿、蓝值来计算混合后的颜色。
