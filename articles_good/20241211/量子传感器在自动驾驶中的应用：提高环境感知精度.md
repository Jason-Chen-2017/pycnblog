   $$I(x,y) = \int A(x,y)B^*(x,y) \exp(jk\phi(x,y)) \, dxdy$$

   $$\lvert \psi_f \rangle = \sqrt{p} \lvert 0 \rangle + \sqrt{1-p} \lvert 1 \rangle$$

   其中，\(p\) 是传输成功的概率。

   假设初始量子态为 \(\lvert \psi_i \rangle = \alpha \lvert 0 \rangle + \beta \lvert 1 \rangle\)，则传输后的量子态为：

   $$\lvert \psi_f \rangle = \sqrt{p\alpha^2} \lvert 0 \rangle + \sqrt{(1-p)\alpha\beta} \lvert 1 \rangle$$

   这表明传输后的量子态是初始量子态的线性组合。

2. **量子纠缠公式**：

   假设我们有两个量子位 \(\lvert \psi_1 \rangle\) 和 \(\lvert \psi_2 \rangle\)，它们之间存在量子纠缠。量子纠缠可以用以下公式表示：

   $$\lvert \psi_{12} \rangle = \alpha \lvert 0 \rangle \otimes \lvert 0 \rangle + \beta \lvert 1 \rangle \otimes \lvert 1 \rangle$$

   其中，\(\alpha\) 和 \(\beta\) 是叠加系数。

   假设我们对第一个量子位进行测量，得到结果 \(\lvert 0 \rangle\)，则第二个量子位的测量结果为：

   $$\lvert \psi_2 \rangle = \alpha \lvert 0 \rangle + \beta \lvert 1 \rangle$$

   这表明测量结果与叠加系数有关。

为了更好地理解这些数学模型和公式，我们来看一个具体的例子。

**例子：量子成像**

假设我们有一个道路场景，两个纠缠光子分别照射到道路的两个不同位置。经过道路后，光子对在探测器上产生干涉图案。我们希望利用量子成像算法重建道路的三维结构。

1. **量子干涉**：

   假设两个光波的振幅分别为 \(A_0 = 1\) 和 \(B_0 = 1\)，相位差为 \(\theta(x,y) - \phi(x,y) = \pi/2\)。则干涉图案的强度为：

   $$I(x,y) = 1 + \cos(\pi/2) = 1$$

   这表明干涉图案是一个均匀的光强分布。

2. **量子态测量**：

   假设探测器的输出状态为 \(\lvert \psi \rangle = \lvert 0 \rangle + \lvert 1 \rangle\)，则测量结果概率分布为：

   $$p_0 = |1|^2 = 1, \quad p_1 = |1|^2 = 1$$

   这表明探测器测量到两个光子同时到达的概率是1。

**例子：量子态测量**

假设我们有一个初始量子态 \(\lvert \psi_i \rangle = \lvert 0 \rangle + \lvert 1 \rangle\)，我们希望将其传输到另一个量子位 \(\lvert \psi_f \rangle\)。

1. **量子隐形传态**：

   假设传输成功的概率 \(p = 0.5\)，则传输后的量子态为：

   $$\lvert \psi_f \rangle = \sqrt{0.5} \lvert 0 \rangle + \sqrt{0.5} \lvert 1 \rangle$$

   假设两个量子位之间存在量子纠缠，则量子态为：

   $$\lvert \psi_{12} \rangle = \lvert 0 \rangle \otimes \lvert 0 \rangle + \lvert 1 \rangle \otimes \lvert 1 \rangle$$

   假设我们对第一个量子位进行测量，得到结果 \(\lvert 0 \rangle\)，则第二个量子位的测量结果为：

   $$\lvert \psi_2 \rangle = \lvert 0 \rangle + \lvert 1 \rangle$$
