### 2.3 运营模式

#### 定义

运营模式是指健身房或健康中心的日常运营方式，包括自营、加盟、合作等。

#### 类型

1. **自营**：由健身中心或健康中心自行运营，具有更高的自主权和灵活性。
2. **加盟**：加入品牌连锁体系，通过品牌效应和资源整合提高运营效率。
3. **合作**：与其他机构合作运营，共同分担运营成本和风险。

#### 选择依据

1. **成本**：自营模式成本较高，但自主权较大；加盟模式成本相对较低，但品牌影响力较强。
2. **管理效率**：自营模式管理效率较高，但人力资源需求较大；加盟模式管理效率较低，但品牌支持较强。
3. **服务质量**：自营模式服务质量较高，但人力资源限制较大；加盟模式服务质量相对较低，但品牌保障较强。

```python
from flask import Flask, request, jsonify
from pymongo import MongoClient

app = Flask(__name__)
client = MongoClient('mongodb://localhost:27017/')

@app.route('/register', methods=['POST'])
def register():
    data = request.json
    user = client['fitness_center']['users'].find_one({"username": data['username']})
    if user:
        return jsonify({"status": "error", "message": "User already exists."})
    else:
        client['fitness_center']['users'].insert_one(data)
        return jsonify({"status": "success", "message": "User registered successfully."})

@app.route('/login', methods=['POST'])
def login():
    data = request.json
    user = client['fitness_center']['users'].find_one({"username": data['username'], "password": data['password']})
    if user:
        return jsonify({"status": "success", "message": "Logged in successfully."})
    else:
        return jsonify({"status": "error", "message": "Invalid username or password."})

if __name__ == '__main__':
    app.run(debug=True)
```
