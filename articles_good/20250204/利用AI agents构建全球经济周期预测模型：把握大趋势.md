## 1.1 引言

### 1.1.1 全球经济周期概述

全球经济周期是指全球经济增长和衰退的周期性波动。这种波动通常由多种因素引起，包括政策变化、市场波动、自然灾害和地缘政治事件。历史上，全球经济周期呈现出明显的波动性，例如1929年的大萧条、1970年代的滞胀以及2008年的金融危机。

在经济周期的不同阶段，企业、投资者和政策制定者需要做出不同的决策。例如，在经济扩张阶段，企业可能会增加投资和招聘；而在经济衰退阶段，企业可能会裁员和减少投资。因此，准确预测全球经济周期对于企业和政策制定者来说至关重要。

### 1.1.2 AI agents的定义与能力

AI agents是指具有智能行为和自主决策能力的计算机程序。它们能够从数据中学习，并在特定环境中执行任务。AI agents在预测领域的应用非常广泛，包括天气预测、股票市场预测、交通流量预测等。

AI agents具有以下能力：
1. **学习能力**：AI agents可以通过机器学习和深度学习技术从数据中学习，并不断优化自己的预测模型。
2. **感知能力**：AI agents可以通过传感器和数据进行环境感知，识别出关键特征和模式。
3. **推理能力**：AI agents可以根据感知到的数据和已有知识进行逻辑推理，做出决策。
4. **操控行为能力**：AI agents可以执行特定的操作，如调整股票投资组合、控制机器人执行任务等。

### 1.1.3 为什么需要利用AI agents构建预测模型

传统的经济预测方法通常依赖于统计模型和经济学理论，但存在以下局限：

1. **数据量有限**：传统方法通常使用有限的样本数据，难以捕捉到复杂的全球经济增长模式。
2. **预测准确性不高**：传统方法往往依赖于历史数据和假设，难以适应不断变化的市场环境。
3. **缺乏实时性**：传统方法通常需要较长时间来收集、处理和分析数据，难以实现实时预测。

相比之下，AI agents具有以下优势：

1. **处理海量数据的能力**：AI agents可以处理来自多个来源的海量数据，包括经济指标、新闻文章、社交媒体数据等。
2. **高度自动化的预测流程**：AI agents可以自动化地收集、处理和分析数据，快速生成预测结果。
3. **高度的适应性与准确性**：AI agents可以通过不断学习和优化，提高预测模型的准确性和适应性。

## 2.1 AI agents的基本原理

### 2.1.1 什么是AI agents

AI agents，即人工智能代理，是指具备一定智能行为和决策能力的计算机程序。它们能够在复杂的动态环境中，根据感知到的信息和已有知识，自主地做出决策和采取行动。AI agents的核心在于其“智能”特征，这使得它们能够处理复杂任务，并适应不断变化的环境。

AI agents通常由以下几个部分组成：
1. **感知器**：用于感知环境信息，如传感器、摄像头、麦克风等。
2. **决策模块**：基于感知到的信息，使用算法进行推理和决策。
3. **执行器**：根据决策结果执行具体的行动，如机器人、机械臂等。

### 2.1.2 AI agents的智能层次

AI agents的智能层次可以分为以下几个级别：

1. **反应型AI agents**：
   - 特点：仅能对当前感知到的简单环境刺激做出反应。
   - 应用：如自动门、自动灯光控制等。

2. **目标型AI agents**：
   - 特点：具有明确的目标，并能根据环境变化调整行动策略。
   - 应用：如自动驾驶汽车、智能客服等。

3. **计划型AI agents**：
   - 特点：能够进行长期的规划和预测，并做出长远决策。
   - 应用：如自主机器人、智能城市管理系统等。

### 2.1.3 AI agents的核心能力

AI agents的核心能力主要包括以下几个方面：

1. **学习能力**：
   - AI agents可以通过机器学习和深度学习算法，从大量数据中学习，并不断优化自己的决策能力。

2. **感知能力**：
   - AI agents能够通过传感器和环境交互，获取外界信息，并识别出关键特征。

3. **推理能力**：
   - AI agents可以根据感知到的信息和已有知识，进行逻辑推理和决策。

4. **操控行为能力**：
   - AI agents可以执行具体的行动，如控制机器人、自动化系统等。

### 2.1.4 AI agents的体系结构

AI agents的体系结构可以分为以下几个层次：

1. **感知层**：用于感知环境信息，如温度、湿度、声音、图像等。
2. **决策层**：根据感知到的信息，使用算法进行决策，如基于规则的决策、基于机器学习的决策等。
3. **执行层**：根据决策结果，执行具体的行动，如移动、操作等。

### 2.1.5 AI agents的工作流程

AI agents的工作流程可以分为以下几个步骤：

1. **感知**：通过传感器获取环境信息。
2. **决策**：使用算法对感知到的信息进行分析和处理，做出决策。
3. **执行**：根据决策结果，执行具体的行动。
4. **反馈**：根据执行结果，调整感知、决策和执行过程。

### 2.1.6 AI agents的应用场景

AI agents在多个领域都有广泛的应用，包括：
1. **智能家居**：自动调节温度、照明等，提高生活质量。
2. **自动驾驶**：实时感知路况，自动控制车辆行驶。
3. **智能客服**：自动回答用户问题，提高客户服务质量。
4. **智能医疗**：辅助医生进行诊断和治疗。
5. **智能城市**：优化交通管理、能源利用等，提高城市运行效率。

## 2.2 AI agents的技术实现

### 2.2.1 机器学习基础

机器学习是AI agents实现智能行为的核心技术之一。机器学习通过从数据中学习规律，使计算机能够进行自主决策和预测。

机器学习的基本概念包括：

1. **监督学习**：通过已标记的样本数据训练模型，然后使用模型对新数据进行预测。常见的监督学习算法包括线性回归、逻辑回归、支持向量机等。
2. **无监督学习**：在没有标记的样本数据上进行学习，主要任务是发现数据中的结构或模式。常见的无监督学习算法包括聚类、降维、关联规则学习等。
3. **强化学习**：通过试错的方法，通过与环境的交互，不断优化决策策略，以实现最大化奖励。常见的强化学习算法包括Q学习、深度强化学习等。

### 2.2.2 深度学习技术

深度学习是机器学习的一个重要分支，通过构建深度神经网络来模拟人脑的决策过程。深度学习在图像识别、语音识别、自然语言处理等领域取得了显著成果。

深度学习的关键技术包括：

1. **神经网络**：神经网络是由多个神经元（节点）组成的层次结构，用于处理和传递信息。常见的神经网络包括全连接网络、卷积神经网络（CNN）、循环神经网络（RNN）等。
2. **卷积神经网络**：卷积神经网络（CNN）是一种适用于图像识别的神经网络，通过卷积操作提取图像特征。
3. **循环神经网络**：循环神经网络（RNN）是一种适用于序列数据处理的神经网络，通过循环结构处理输入序列，并保持长期依赖关系。

### 2.2.3 AI agents的编程框架

AI agents的编程框架主要包括TensorFlow、PyTorch和Keras等。

1. **TensorFlow**：TensorFlow是一个开源的深度学习框架，由Google开发。它提供了丰富的API，支持从数据预处理到模型训练和部署的完整流程。
2. **PyTorch**：PyTorch是一个开源的深度学习框架，由Facebook开发。它提供了动态计算图，使得模型的构建和调试更加灵活。
3. **Keras**：Keras是一个基于TensorFlow和Theano的深度学习框架，提供了简单而强大的API，使得深度学习模型的构建和训练更加容易。

## 2.3 AI agents的开发流程

### 2.3.1 数据采集与预处理

数据采集是AI agents开发的重要步骤之一。对于全球经济周期预测模型，数据来源可能包括官方统计数据、金融市场数据、新闻报道、社交媒体数据等。以下是一些常见的数据收集方法：

1. **网络爬虫**：使用爬虫工具（如Scrapy、BeautifulSoup）从互联网上抓取相关数据。
2. **数据库访问**：通过SQL查询或其他数据库接口（如MongoDB、Redis）获取数据。
3. **API接口调用**：利用公共API接口（如新浪财经、Google Trends API）获取数据。

在数据收集后，需要进行预处理，以确保数据的质量和一致性。以下是一些常用的数据预处理方法：

1. **数据清洗**：处理缺失值、异常值和重复值，以提高数据质量。
2. **数据归一化**：将不同量纲的数据进行归一化处理，以便于模型训练。
3. **特征提取**：从原始数据中提取有意义的特征，以辅助模型训练。
4. **数据分片**：将数据划分为训练集、验证集和测试集，以评估模型性能。

### 2.3.2 模型设计与训练

在数据预处理完成后，接下来是设计预测模型。对于全球经济周期预测，常见的模型包括时间序列模型（如ARIMA、LSTM）、回归模型（如线性回归、岭回归）和深度学习模型（如CNN、RNN）。以下是一些模型设计的关键步骤：

1. **选择模型类型**：根据预测任务的需求和数据特征，选择合适的模型类型。
2. **设计模型结构**：确定模型的层次结构、网络层和激活函数等。
3. **初始化参数**：为模型参数设置初始值，如权重和偏置。
4. **损失函数选择**：选择合适的损失函数，如均方误差（MSE）、交叉熵损失等。
5. **优化器选择**：选择优化算法，如随机梯度下降（SGD）、Adam等。

在模型设计完成后，需要进行模型训练。以下是一些常见的训练技巧：

1. **批量大小调整**：调整批量大小以平衡计算资源和训练效果。
2. **学习率调整**：根据训练进度调整学习率，以避免过拟合。
3. **正则化**：使用正则化技术（如L1、L2正则化）防止模型过拟合。
4. **早停法**：在验证集上监控模型性能，提前停止训练以避免过拟合。
5. **数据增强**：通过增加训练数据多样性来提高模型泛化能力。

### 2.3.3 模型评估与优化

在模型训练完成后，需要对模型进行评估和优化，以验证其性能和可靠性。以下是一些常见的评估方法：

1. **准确率**：衡量模型预测结果与实际结果的一致性。
2. **召回率**：衡量模型在预测为正样本时，正确识别为正样本的比例。
3. **F1分数**：结合准确率和召回率的综合指标。
4. **ROC曲线和AUC值**：评估模型对正负样本的分类能力。

在评估模型性能后，可以根据评估结果进行模型优化。以下是一些常见的优化策略：

1. **参数调整**：根据评估结果调整模型参数，以提高性能。
2. **模型重构**：修改模型结构，如增加或减少网络层、调整层的大小等。
3. **集成学习**：结合多个模型的优势，提高整体性能。

### 2.3.4 模型部署与维护

在模型优化完成后，需要将模型部署到实际应用环境中。以下是一些常见的部署方法：

1. **服务器部署**：将训练好的模型部署到服务器上，以提供在线预测服务。

## 3.2 数据预处理方法

### 3.2.1 数据清洗

数据清洗是数据预处理的重要步骤，目的是去除数据中的噪声、错误和不一致。以下是常见的数据清洗方法：

1. **处理缺失值**：缺失值可以采用以下方法进行处理：

   - **删除**：删除明显的异常值。
   - **变换**：使用变换方法（如对数变换、平方根变换）将异常值转换到合理范围。

## 4.3 AI agents预测模型评估

### 4.3.1 评估指标解释

在评估AI agents预测模型的性能时，常用的指标包括：

1. **均方误差（MSE）**：
   - 定义：MSE是预测值与实际值之间差异的平方的平均值。
   - 公式：\(MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2\)
   - 解释：MSE越低，表示模型预测的准确性越高。

2. **均方根误差（RMSE）**：
   - 定义：RMSE是MSE的平方根。
   - 公式：\(RMSE = \sqrt{MSE}\)
   - 解释：RMSE更易于理解，通常用于比较不同模型的误差大小。

3. **决定系数（R²）**：
   - 定义：R²表示模型解释方差的能力，取值范围在0到1之间。
   - 公式：\(R² = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y}_i)^2}\)
   - 解释：R²越接近1，表示模型对数据的拟合度越高。

4. **平均绝对误差（MAE）**：
   - 定义：MAE是预测值与实际值之间差异的绝对值的平均值。
   - 公式：\(MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|\)
   - 解释：MAE对异常值的影响较小，更稳健。

5. **准确率**：
   - 定义：准确率是正确预测的样本数与总样本数之比。
   - 公式：\(准确率 = \frac{TP + TN}{TP + FN + FP + TN}\)
   - 解释：准确率适用于分类问题。

6. **召回率**：
   - 定义：召回率是正确预测的正样本数与实际正样本数之比。
   - 公式：\(召回率 = \frac{TP}{TP + FN}\)
   - 解释：召回率关注的是对正样本的预测准确性。

7. **精确率**：
   - 定义：精确率是正确预测的正样本数与预测为正样本的总数之比。
   - 公式：\(精确率 = \frac{TP}{TP + FP}\)
   - 解释：精确率关注的是预测结果的可靠性。

### 4.3.2 评估方法比较

不同的评估方法适用于不同类型的问题。以下是几种常见评估方法的比较：

1. **回归问题**：
   - MSE和RMSE适用于回归问题，用于衡量预测值与实际值之间的误差。
   - R²用于衡量模型对数据的拟合度。

2. **分类问题**：
   - 准确率、召回率和精确率适用于分类问题，用于衡量模型对正样本的预测准确性。
   - F1分数是精确率和召回率的调和平均，用于综合评估分类模型的性能。

3. **时间序列问题**：
   - 对于时间序列问题，可以使用RMSE和MAE来评估模型的预测准确性。
   - 可以使用时间序列分解方法，如ARIMA，来比较模型的预测效果。

### 4.3.3 误差分析与优化

在评估模型时，需要对误差进行分析，以找出模型存在的问题，并进行优化。以下是一些常见的误差分析和优化方法：

1. **误差分析**：
   - **线性误差**：分析预测值与实际值之间的线性关系，判断是否存在系统性偏差。
   - **非线性误差**：分析预测值与实际值之间的非线性关系，判断是否存在过度拟合或欠拟合。

2. **优化策略**：
   - **超参数调整**：调整学习率、批量大小等超参数，以优化模型性能。
   - **模型重构**：调整模型结构，如增加隐藏层神经元数量，以改善模型拟合度。
   - **正则化**：使用L1、L2正则化方法，减少过拟合现象。
   - **数据增强**：通过增加数据多样性，提高模型泛化能力。

## 5.1 模型调参方法

### 5.1.1 超参数调整

超参数是深度学习模型中需要手动设置的参数，如学习率、批量大小、隐藏层神经元数量等。超参数的选取对模型性能有重要影响，以下是一些常见的超参数调整方法：

1. **网格搜索**：网格搜索是一种系统性的搜索策略，通过遍历所有可能的超参数组合，找到最优超参数。缺点是计算量大，适用于参数较少的情况。

2. **随机搜索**：随机搜索通过随机选取超参数组合，进行多次训练，选择最佳组合。相比网格搜索，随机搜索计算量较小，适用于参数较多的情况。

3. **贝叶斯优化**：贝叶斯优化是基于概率模型，通过迭代优化策略，找到最优超参数组合。优点是计算效率高，适用于复杂的多维超参数空间。

4. **自动化机器学习（AutoML）**：AutoML利用机器学习技术，自动搜索最优超参数和模型结构。常见工具包括Google的AutoML、H2O.ai等。

### 5.1.2 模型调参技巧

在进行模型调参时，以下技巧有助于提高调参效率和模型性能：

1. **学习率调整**：学习率的选择对模型训练过程有重要影响。常用的调整方法包括：
   - **逐步减小学习率**：在模型训练过程中，逐步减小学习率，有助于收敛到最优解。
   - **自适应学习率**：使用自适应优化器（如Adam），自动调整学习率。

2. **批量大小调整**：批量大小影响模型的训练速度和稳定性。较小批量大小可以减小方差，但训练速度较慢；较大批量大小可以减小偏差，但训练速度较快。

3. **隐藏层神经元数量调整**：隐藏层神经元数量的选择影响模型拟合能力和过拟合风险。可以通过交叉验证法，选择最佳神经元数量。

4. **正则化调整**：正则化方法可以防止模型过拟合。通过调整正则化强度（如L1、L2正则化系数），可以在拟合能力和泛化能力之间找到平衡点。

5. **数据增强**：通过增加数据的多样性，提高模型泛化能力。常见的数据增强方法包括：
   - **数据扩充**：生成新的数据样本，如旋转、缩放、裁剪等。
   - **特征变换**：对特征进行变换，增加非线性关系。

## 5.2 模型调参技巧

### 5.2.1 学习率调整

学习率是深度学习模型训练过程中非常重要的参数，它决定了模型在训练过程中步长的大小。学习率设置不当可能会导致训练过程不稳定，甚至无法收敛。以下是一些学习率调整的技巧：

1. **初始学习率选择**：初始学习率不宜过大，否则可能导致模型过快收敛到局部最优解；也不宜过小，否则可能导致训练过程缓慢。通常可以从小值开始，如0.001，然后根据训练效果逐步调整。

2. **逐步减小学习率**：在训练过程中，随着模型性能的提升，可以逐步减小学习率，以避免过快收敛到局部最优解。这种方法称为学习率衰减。常见的方法是每固定步数或达到一定性能提升时减小学习率。

3. **自适应学习率**：使用自适应学习率优化器（如Adam、Adadelta），这些优化器可以根据训练过程自动调整学习率，提高训练稳定性。

4. **学习率范围搜索**：通过网格搜索或随机搜索方法，在给定范围内寻找最优学习率。这种方法适用于参数较少的情况，但计算量较大。

### 5.2.2 批量大小调整

批量大小是深度学习模型训练过程中另一个关键参数，它决定了每次更新模型参数时使用的数据样本数量。批量大小对训练过程有重要影响，以下是一些调整技巧：

1. **批量大小选择**：批量大小通常选择为2的幂次，如32、64、128等。批量大小过大可能导致梯度消失或爆炸，过小可能导致梯度不稳定。

2. **批量大小对训练时间的影响**：较大批量大小可以加速训练过程，但需要更多内存；较小批量大小可以提供更稳定的梯度，但训练时间更长。

3. **批量大小对模型性能的影响**：批量大小对模型性能的影响取决于数据分布。对于高斯分布的数据，批量大小对模型性能影响较小；对于稀疏数据，批量大小对模型性能影响较大。

### 5.2.3 隐藏层神经元数量调整

隐藏层神经元数量是深度学习模型结构设计中的一个关键参数，它决定了模型的复杂度和拟合能力。以下是一些调整技巧：

1. **隐藏层神经元数量选择**：通常可以从较小值开始（如10、20），然后根据训练效果逐步增加。过多的隐藏层神经元可能导致模型过拟合，过少的隐藏层神经元可能导致模型欠拟合。

2. **网络深度和宽度的权衡**：增加隐藏层神经元数量可以提高模型拟合能力，但也会增加计算复杂度和过拟合风险。可以通过增加网络深度（层数）或增加每层的神经元数量来调整模型复杂度。

3. **交叉验证**：使用交叉验证方法选择最优隐藏层神经元数量，可以在模型拟合能力和过拟合风险之间找到平衡点。

### 5.2.4 正则化调整

正则化是防止深度学习模型过拟合的重要技术，以下是一些正则化调整技巧：

1. **L1和L2正则化**：L1正则化和L2正则化是常见的正则化方法。L1正则化可以促进特征选择，而L2正则化则可以减少梯度消失问题。

2. **正则化系数选择**：正则化系数（如L1和L2正则化的权重）需要调整。较小的正则化系数可能导致模型过拟合，而较大的正则化系数可能导致模型欠拟合。

3. **正则化强度权衡**：通过交叉验证方法，选择适当的正则化强度，可以在模型拟合能力和过拟合风险之间找到平衡点。

### 5.2.5 数据增强

数据增强是提高模型泛化能力的重要方法，以下是一些数据增强技巧：

1. **数据扩充**：通过旋转、缩放、裁剪、翻转等操作生成新的数据样本，增加数据多样性。

2. **特征变换**：对特征进行变换，如对数值特征进行归一化或标准化，对文本特征进行词嵌入等。

3. **生成对抗网络（GAN）**：使用生成对抗网络生成新的数据样本，可以显著提高模型泛化能力。

## 6.3 模型构建与训练

### 6.3.1 模型设计

在构建全球经济周期预测模型时，我们需要设计合适的模型结构，以捕捉经济数据的复杂性和变化趋势。在本案例中，我们选择LSTM（长短期记忆网络）模型进行预测，因为它在处理时间序列数据方面具有优势。

#### 模型结构

1. **输入层**：输入层接收预处理后的经济数据，包括GDP增长率、通货膨胀率、失业率等宏观经济指标。输入层的大小取决于特征的数量。

2. **隐藏层**：隐藏层包含多个LSTM层，用于处理时间序列数据。隐藏层的神经元数量和层数可以根据实验结果进行调整。

3. **输出层**：输出层是一个全连接层，用于生成预测结果。对于回归问题，输出层通常包含一个神经元，用于预测未来某一时刻的经济指标。

#### 模型架构

以下是一个简单的LSTM模型架构：

```python
class LSTMModel(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(LSTMModel, self).__init__()
        self.lstm = nn.LSTM(input_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        x, _ = self.lstm(x)
        x = self.fc(x[:, -1, :])
        return x
```

### 6.3.2 数据预处理

在训练模型之前，我们需要对数据进行预处理，以使其适合模型训练。以下是数据预处理的关键步骤：

1. **归一化**：将数据归一化到0-1范围内，以减少数据差异对模型训练的影响。

2. **窗口化**：将时间序列数据划分为窗口，每个窗口包含固定数量的时间步。例如，如果窗口大小为3，则每个样本由最近3个时间步的数据组成。

3. **序列化**：将预处理后的数据序列化，以便于模型训练。

### 6.3.3 模型训练

在模型训练过程中，我们需要定义损失函数、优化器和评估指标。以下是训练过程的步骤：

1. **损失函数**：通常使用均方误差（MSE）作为损失函数，用于衡量预测值与实际值之间的差异。

2. **优化器**：选择合适的优化器，如Adam或SGD，用于调整模型参数。

3. **训练策略**：
   - **批量大小**：选择适当的批量大小，如32或64，以提高训练效率和模型稳定性。
   - **学习率**：设置初始学习率，并在训练过程中逐步减小学习率。
   - **训练轮次**：设置训练轮次，以控制训练时间。

4. **评估**：在验证集上评估模型性能，以确定最佳模型参数。

### 6.3.4 模型评估

在训练完成后，我们需要在测试集上评估模型性能，以验证其泛化能力。常用的评估指标包括MSE、RMSE和R²等。以下是评估过程的步骤：

1. **计算预测值**：使用训练好的模型对测试集进行预测。

2. **计算评估指标**：计算MSE、RMSE和R²等评估指标，以评估模型性能。

3. **结果分析**：分析评估指标，确定模型预测的准确性和可靠性。

### 6.3.5 实际应用

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

# 加载数据
X, y = load_data()  # 加载数据
X = torch.tensor(X, dtype=torch.float32)
y = torch.tensor(y, dtype=torch.float32)

# 划分数据
train_size = int(len(X) * 0.8)
val_size = len(X) - train_size
X_train, X_val = X[:train_size], X[train_size:]
y_train, y_val = y[:train_size], y[train_size:]

# 创建数据集和数据加载器
train_dataset = TensorDataset(X_train, y_train)
val_dataset = TensorDataset(X_val, y_val)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=64, shuffle=False)

# 定义模型
model = LSTMModel(input_dim=X_train.shape[1], hidden_dim=50, output_dim=1)

# 编译模型
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# 训练模型
num_epochs = 100
for epoch in range(num_epochs):
    for inputs, targets in train_loader:
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, targets)
        loss.backward()
        optimizer.step()

    with torch.no_grad():
        val_outputs = model(X_val)
        val_loss = criterion(val_outputs, y_val)
        print(f"Epoch {epoch+1}/{num_epochs}, Validation Loss: {val_loss.item():.4f}")

# 评估模型
with torch.no_grad():
    test_outputs = model(X_test)
    test_loss = criterion(test_outputs, y_test)
    print(f"Test Loss: {test_loss.item():.4f}")

# 计算评估指标
mse = criterion(test_outputs, y_test).item()
rmse = torch.sqrt(mse)
r2 = 1 - (torch.mean((y_test - test_outputs)**2) / torch.mean((y_test - y_test.mean())**2))
print(f"RMSE: {rmse.item():.4f}, R²: {r2.item():.4f}")
```
