### 第二部分: 自监督表示学习基础

#### 第2章: 自监督表示学习基础

**2.1 自监督学习的定义与原理**

自监督学习（Self-Supervised Learning）是一种无需外部监督信号，仅利用数据自身的内在结构来进行学习和表示的方法。在这种学习模式中，模型通过预测数据中的某些部分来学习数据的潜在特征，而不是依赖标注的数据来指导学习过程。

自监督学习的核心原理是利用数据的自相似性和冗余性。在自监督学习中，数据通常被分成两个部分：一部分作为输入，另一部分作为输出。模型的任务是通过预测输出部分来学习输入部分的表示。这种预测过程可以看作是对数据的一种再解释，从而发现数据的内在结构和特征。

**2.2 代表性模型与算法**

自监督学习的发展历程中，涌现出了多种代表性模型和算法。以下是一些常见的自监督学习模型：

**自编码器（Autoencoder）**  
自编码器是一种最基本的自监督学习模型，它由一个编码器和一个解码器组成。编码器将输入数据映射到一个低维空间，解码器则试图从低维空间重建原始数据。通过最小化重建误差，自编码器可以学习输入数据的潜在特征表示。

**生成对抗网络（GAN）**  
生成对抗网络（GAN）由生成器和判别器组成。生成器生成假数据，判别器判断生成数据与真实数据之间的差异。通过训练生成器和判别器的对抗过程，GAN可以学习生成高质量的数据，并在图像、语音和自然语言处理等领域取得了显著成果。

**变分自编码器（VAE）**  
变分自编码器（VAE）是对自编码器的一种改进。VAE通过引入潜在变量，将自编码器的概率分布建模为连续的概率分布，从而提高了模型的灵活性和表达能力。

**生成式预训练（GPT）模型**  
生成式预训练（GPT）模型是基于Transformer架构的一种自监督学习模型。GPT通过大规模预训练，学习语言数据的潜在特征表示，并在自然语言处理任务中取得了优异的性能。

**2.3 自监督学习的挑战与机遇**

尽管自监督学习在许多领域取得了显著成果，但仍然面临着一些挑战和机遇：

**挑战：**  
1. **数据质量**：自监督学习依赖于数据自身的结构，因此数据的质量对学习效果有重要影响。噪声数据和缺失数据可能会干扰模型的学习过程，降低学习效果。
2. **模型选择**：自监督学习的模型选择和调参是一个复杂的问题。不同的模型和超参数组合可能会产生截然不同的学习效果，需要大量的实验和调试。
3. **计算成本**：自监督学习通常需要大量的计算资源，尤其是在处理大规模数据和复杂模型时。

**机遇：**  
1. **无监督数据的利用**：自监督学习可以充分利用无监督数据，从而提高模型的泛化能力。在许多实际应用场景中，获取标注数据是非常困难的，自监督学习提供了一种有效的解决方案。
2. **模型泛化能力**：自监督学习通过学习数据的潜在特征，可以提高模型的泛化能力。这种方法不仅适用于当前的任务，还可能对未来未知任务产生积极影响。
3. **跨领域应用**：自监督学习在不同领域具有广泛的应用前景。通过将自监督学习应用于新的领域，可以推动这些领域的技术进步和应用创新。

#### 第4章: 图神经网络与自监督表示学习

**4.1 图神经网络基础**

图神经网络（Graph Neural Networks，GNN）是一种专门用于处理图结构数据的神经网络模型。与传统的神经网络相比，GNN能够直接操作图结构数据，利用节点和边之间的关系进行学习。GNN的核心思想是将图中的节点和边映射到低维特征空间，并通过这些特征来预测节点属性或进行图分类。

**GNN的工作原理：**

1. **节点嵌入（Node Embedding）**：GNN首先将图中的每个节点映射到一个低维向量，这个向量代表了节点的特征。常见的节点嵌入方法包括基于矩阵分解的方法和基于深度学习的方法。

2. **消息传递（Message Passing）**：在GNN中，每个节点的特征是由其邻居节点的特征组合而成的。具体来说，GNN通过消息传递机制，将邻居节点的特征传递给当前节点，并将这些特征融合到当前节点的特征中。这个过程可以迭代多次，使得节点的特征能够更好地捕捉到全局信息。

3. **聚合与更新（Aggregation and Update）**：在消息传递过程中，GNN会聚合来自邻居节点的信息，并更新当前节点的特征。这种聚合与更新机制使得GNN能够捕捉到节点之间的关联关系。

**4.2 图自监督表示学习算法**

图自监督表示学习是一种利用图结构数据自监督地学习节点表示的方法。以下是一些常见的图自监督表示学习算法：

**节点分类（Node Classification）**：

- **DeepWalk**：DeepWalk是一种基于随机游走的方法。它通过生成图中的随机游走轨迹，然后将这些轨迹序列编码为向量，从而学习节点的表示。DeepWalk的目标是最大化节点的表示与其类别标签之间的相似性。

- **Node2Vec**：Node2Vec是对DeepWalk的一种改进。Node2Vec通过调节游走过程的随机性，生成更具有结构代表性的节点序列。Node2Vec的目标是同时最大化节点的局部结构和全局结构信息。

**图分类（Graph Classification）**：

- **Graph Convolutional Network（GCN）**：GCN是一种基于卷积操作的图神经网络。GCN通过聚合节点邻居的特征来更新节点的特征表示，从而学习图的全局特征。GCN在图分类任务中取得了显著的性能提升。

- **GraphSAGE**：GraphSAGE（Graph Sampling and Aggregation）是一种基于采样和聚合的图神经网络。GraphSAGE通过随机采样节点的邻居，然后聚合这些邻居的特征，从而学习节点的表示。这种方法能够更好地处理大规模图数据。

**图生成（Graph Generation）**：

- **GAE（Graph Autoencoder）**：GAE是一种基于自编码器的图生成模型。GAE通过编码器将图编码为低维特征，然后通过解码器重建原始图。GAE的目标是学习到图的结构和特征，从而生成新的图。

**4.3 图自监督表示学习应用案例**

图自监督表示学习在多个领域都取得了显著的应用成果。以下是一些典型的应用案例：

- **社交网络分析**：图自监督表示学习可以用于社交网络中用户的分类和推荐。例如，通过学习用户之间的相似性，可以为用户推荐相似的朋友或兴趣群体。

- **生物信息学**：图自监督表示学习可以用于生物分子图的分类和预测。例如，通过学习蛋白质结构中的节点和边特征，可以预测蛋白质的功能和相互作用。

- **图像识别**：图自监督表示学习可以用于图像中的物体和场景分类。例如，通过将图像中的物体和场景表示为图节点和边，可以学习到图像的复杂结构，从而实现更准确的分类。

本章介绍了图神经网络和图自监督表示学习的基础概念、算法原理以及应用案例。图神经网络能够有效地处理图结构数据，而图自监督表示学习通过自监督的方式学习节点的表示，具有广泛的应用前景。在接下来的章节中，我们将继续探讨基于Transformer的自监督表示学习和其他相关技术。

### 第五部分：自监督表示学习在AI Agent中的应用

#### 第6章：基于Transformer的自监督表示学习

**6.1 Transformer模型基础**

Transformer模型是由Vaswani等人于2017年提出的一种用于序列到序列学习的神经网络架构。与传统序列模型（如循环神经网络RNN和长短期记忆网络LSTM）不同，Transformer采用了自注意力机制（Self-Attention）和多头注意力机制（Multi-Head Attention），使得模型能够更好地捕捉序列中的长距离依赖关系。

**Transformer的工作原理：**

1. **编码器（Encoder）**：编码器由多个编码层（Encoder Layer）堆叠而成。每个编码层包含两个主要组件：多头自注意力机制（Multi-Head Self-Attention）和前馈神经网络（Feedforward Neural Network）。

   - **多头自注意力机制**：自注意力机制允许编码器层中的每个词都能够根据其与序列中其他词的关系进行权重计算，从而在处理长序列时保持高效的信息传递。
   - **前馈神经网络**：前馈神经网络对每个编码层的输出进行线性变换，进一步增强模型的表示能力。

2. **解码器（Decoder）**：解码器与编码器类似，也由多个解码层（Decoder Layer）堆叠而成。每个解码层包含两个主要组件：多头注意力机制（Multi-Head Attention）和多头自注意力机制。

   - **多头注意力机制**：多头注意力机制用于解码器处理输入和输出序列之间的关系，使得解码器能够根据上下文信息生成预测。
   - **多头自注意力机制**：多头自注意力机制用于解码器处理当前生成的词与其自身之间的关系。

**6.2 Transformer的自监督学习算法**

Transformer的自监督学习算法主要包括以下几个步骤：

1. **掩码语言建模（Masked Language Modeling，MLM）**：

   - **数据预处理**：将输入序列中的单词或子词随机掩码（Mask），生成带有掩码的序列。
   - **模型训练**：训练目标是最小化模型在预测掩码词时的损失。

2. **掩码目标语言建模（Masked Object Language Modeling，MOLM）**：

   - **数据预处理**：将输入序列中的对象（如图像、视频或音频）随机掩码，生成带有掩码的序列。
   - **模型训练**：训练目标是最小化模型在预测掩码对象时的损失。

3. **预测生成（Predictive Generation）**：

   - **数据预处理**：生成新的数据序列，并将其中的部分元素替换为掩码。
   - **模型训练**：训练目标是最小化模型在生成预测时的损失。

**6.3 Transformer在自监督表示学习中的应用**

Transformer在自监督表示学习中的应用非常广泛，以下是一些典型应用：

- **自然语言处理（NLP）**：在NLP任务中，Transformer通过预训练和微调，已经取得了显著的成果。例如，BERT（Bidirectional Encoder Representations from Transformers）通过预训练大规模语料库，学习到了语言的深层语义特征，并在多项NLP任务中取得了最优性能。

- **计算机视觉（CV）**：在计算机视觉任务中，Transformer可以用于图像分类、目标检测和语义分割。例如，ViT（Vision Transformer）通过将图像分割成多个块，然后通过Transformer编码器进行特征提取，实现了高效的自然图像分类。

- **多模态学习**：在多模态学习任务中，Transformer可以同时处理多种模态的数据，如文本、图像和音频。通过自监督学习，Transformer可以学习到不同模态数据之间的潜在关联，从而实现更准确的多模态任务。

**应用案例：**

1. **文本分类**：使用BERT模型，我们可以对文本进行分类。例如，在一个新闻分类任务中，BERT模型通过预训练学习到了语言的深层特征，然后通过微调，对新闻文本进行分类，取得了很高的准确率。

2. **图像识别**：使用ViT模型，我们可以对自然图像进行分类。例如，在一个动物图像分类任务中，ViT模型通过自监督学习，学习到了图像的潜在特征，然后通过微调，对图像进行分类，取得了优异的性能。

3. **语音识别**：使用Transformer模型，我们可以对语音信号进行识别。例如，在一个语音识别任务中，Transformer模型通过自监督学习，学习到了语音信号的潜在特征，然后通过微调，对语音信号进行识别，取得了很高的准确率。

**总结：**  
本章介绍了Transformer模型的基础知识、自监督学习算法以及其在自监督表示学习中的应用。Transformer通过自注意力机制，能够高效地捕捉序列中的长距离依赖关系，从而在自然语言处理、计算机视觉等领域取得了显著的成果。在接下来的章节中，我们将探讨多模态自监督表示学习以及其在不同领域的应用。

### 第六部分: 多模态自监督表示学习

#### 第7章: 多模态自监督表示学习

**7.1 多模态数据的理解**

多模态学习（Multimodal Learning）是人工智能领域的一个重要研究方向，旨在整合来自不同模态的数据（如文本、图像、音频和视频）进行联合学习和表示。多模态数据具有丰富的信息，能够提供更全面的上下文和更准确的表示，从而提高模型在多模态任务中的性能。

**多模态数据的类型：**

1. **文本（Text）**：文本数据包括自然语言文本、标签和注释等，是表达知识的重要形式。

2. **图像（Image）**：图像数据包含视觉信息，如颜色、形状、纹理和空间关系等。

3. **音频（Audio）**：音频数据包含语音、音乐和其他声音信息，能够提供情感、环境和场景的描述。

4. **视频（Video）**：视频数据是动态的图像序列，包含丰富的视觉和时序信息。

**多模态数据的挑战：**

1. **模态差异**：不同模态的数据在维度、结构和语义上存在显著差异，如文本是符号序列，图像是像素矩阵，音频是时间序列。

2. **数据不平衡**：不同模态的数据在数量和质量上可能存在不平衡，某些模态的数据可能更丰富或更重要。

3. **信息整合**：如何有效地整合来自不同模态的数据，以生成统一的表示，是多模态学习的核心挑战。

**7.2 多模态自监督学习算法**

多模态自监督学习算法通过利用数据自身的内在结构，无需外部监督信号，自动学习不同模态数据的潜在特征表示。以下是一些常见的多模态自监督学习算法：

**多模态自编码器（Multimodal Autoencoder）**：

- **数据融合**：多模态自编码器通过将不同模态的数据融合到一个共同的特征空间中，然后使用编码器和解码器进行特征提取和重建。

- **损失函数**：多模态自编码器的损失函数通常包括重构损失和特征匹配损失，以同时优化编码和解码过程。

**多模态生成对抗网络（Multimodal Generative Adversarial Network，MGAN）**：

- **生成器（Generator）**：生成器尝试生成与真实数据相似的多模态数据。

- **判别器（Discriminator）**：判别器判断生成数据和真实数据之间的差异。

- **训练过程**：生成器和判别器通过对抗训练相互优化，最终生成高质量的多模态数据。

**多模态图神经网络（Multimodal Graph Neural Network，MGNN）**：

- **节点嵌入**：MGNN将不同模态的数据映射到节点嵌入空间。

- **图结构**：MGNN通过构建模态间的图结构，将不同模态的数据关联起来。

- **消息传递**：MGNN通过消息传递机制，学习节点和边之间的潜在关系。

**7.3 多模态自监督学习的实践与挑战**

**实践应用：**

1. **情感分析**：通过整合文本和音频数据，可以更准确地捕捉用户的情感状态。

2. **视频摘要**：通过整合视频和文本数据，可以生成视频的高质量摘要。

3. **图像增强**：通过整合图像和深度数据，可以实现图像的深度增强和修复。

**挑战：**

1. **模态融合**：如何有效地融合不同模态的数据，以生成统一的表示，是一个重要挑战。

2. **计算资源**：多模态自监督学习通常需要大量的计算资源，尤其是在处理高维数据和复杂模型时。

3. **数据质量**：不同模态的数据在质量上可能存在差异，需要处理数据质量不一致的问题。

**未来展望：**

1. **模态融合算法**：开发更有效的模态融合算法，以生成更准确和统一的多模态表示。

2. **硬件加速**：利用硬件加速技术，如GPU和TPU，提高多模态自监督学习的计算效率。

3. **跨领域应用**：探索多模态自监督学习在医疗、教育、娱乐等领域的应用。

**总结：**  
本章介绍了多模态自监督学习的概念、算法和实践应用。多模态自监督学习通过整合不同模态的数据，自动学习数据的潜在特征表示，具有广泛的应用前景。然而，多模态融合和数据质量等问题仍需进一步研究。在接下来的章节中，我们将探讨自监督表示学习在自然语言处理和计算机视觉等领域的具体应用。

### 自监督表示学习在自然语言处理中的应用

#### 第8章: 自监督表示学习在自然语言处理中的应用

**8.1 语言模型与自监督学习**

自然语言处理（NLP）是人工智能领域的一个重要分支，旨在使计算机能够理解、处理和生成自然语言。在NLP中，语言模型（Language Model）是一个核心组成部分，它用于预测文本序列中的下一个单词或字符。自监督学习技术在语言模型中发挥着重要作用，通过无监督的方式学习文本的潜在结构，从而提高模型的性能。

**预训练语言模型（Pre-trained Language Model）**：

预训练语言模型通过在大规模文本语料库上进行预训练，学习到语言的普遍规律和上下文依赖关系。预训练模型通常包含数百万个参数，能够捕捉到丰富的语言特征，如词义、语法和语义关系。以下是一些著名的预训练语言模型：

- **Word2Vec**：Word2Vec是一种基于神经网络的语言模型，通过预测上下文单词来学习词汇的向量表示。Word2Vec将每个单词映射到一个低维向量，使得相似的单词在向量空间中更接近。

- **BERT**（Bidirectional Encoder Representations from Transformers）：BERT是一种基于Transformer的语言模型，通过双向编码器学习文本的上下文信息。BERT在多个NLP任务中取得了显著的性能提升，包括文本分类、问答系统和命名实体识别。

- **GPT**（Generative Pre-trained Transformer）：GPT是一种基于生成预训练的Transformer模型，通过预测下一个字符来学习语言的生成规律。GPT在生成文本和对话系统中表现出色，能够生成流畅且符合语言习惯的文本。

**自监督学习算法在语言模型中的应用**：

- **掩码语言建模（Masked Language Modeling，MLM）**：MLM是一种常用的自监督学习算法，通过随机掩码部分输入文本中的单词或字符，然后预测这些掩码部分。BERT就是基于MLM算法进行预训练的。

- **序列掩码（Sequence Masking）**：序列掩码算法通过随机掩码输入序列的一部分，使得模型在预测时只能依赖未掩码的部分。这种算法有助于模型学习到文本中的长距离依赖关系。

- **因果掩码（Causal Language Modeling，CaLM）**：因果掩码算法通过预测输入序列中的下一个单词，而不是整个序列。这种算法有助于模型学习到文本的前后关系和因果关系。

**8.2 文本分类与自监督学习**

文本分类是NLP中的一种常见任务，旨在将文本数据分类到预定义的类别中。自监督学习技术在文本分类中发挥着重要作用，通过无监督的方式学习文本的类别信息，从而提高分类模型的性能。

**无监督文本分类算法**：

- **聚类算法**：无监督文本分类通过聚类算法将文本数据分为不同的类别。常见的聚类算法包括K-均值聚类和层次聚类。这些算法通过分析文本的词向量或TF-IDF特征，将相似的文本聚集在一起。

- **图神经网络**：图神经网络（GNN）可以用于无监督文本分类。GNN通过构建文本的图结构，将文本中的词或句子作为节点，词之间的关系作为边，然后通过图卷积层学习文本的类别特征。

**自监督文本分类应用**：

- **新闻分类**：自监督文本分类可以用于自动分类新闻文章，将其分类到预定义的新闻类别中。例如，通过预训练的语言模型BERT，可以自动分类政治、体育、科技等不同类别的新闻。

- **情感分析**：自监督文本分类可以用于情感分析，将文本分类为正面、负面或中性。通过无监督的方式学习文本的情感特征，可以自动识别用户的情感倾向。

- **主题分类**：自监督文本分类可以用于文本主题分类，将文本分类到预定义的主题类别中。例如，通过预训练的语言模型GPT，可以自动识别文本的主题，如政治、娱乐、科技等。

**8.3 问答系统与自监督学习**

问答系统是NLP中的一种重要应用，旨在回答用户提出的问题。自监督学习技术在问答系统中发挥着重要作用，通过无监督的方式学习问题的语义和答案的关联性。

**自监督问答系统算法**：

- **检索式问答（Retrieval-based Question Answering）**：检索式问答系统通过从预定义的文本库中检索与问题相关的文档，然后从这些文档中提取答案。自监督学习可以用于优化文档检索和答案提取过程。

- **生成式问答（Generation-based Question Answering）**：生成式问答系统通过生成与问题相关的答案，然后从这些答案中选取最佳答案。自监督学习可以用于优化答案生成的过程。

- **多任务学习**：多任务学习（Multi-Task Learning）可以将问答系统与其他NLP任务（如文本分类、命名实体识别）结合起来，通过共享模型参数和优化目标，提高问答系统的性能。

**自监督问答系统应用**：

- **知识库问答**：自监督问答系统可以用于知识库问答，回答用户针对特定领域的问题。例如，通过预训练的语言模型BERT，可以构建一个自动问答系统，回答用户关于历史、地理或科技领域的问题。

- **对话系统**：自监督问答系统可以用于对话系统，回答用户在对话中的问题。例如，通过预训练的语言模型GPT，可以构建一个智能客服系统，回答用户关于产品咨询、售后服务等方面的问题。

**总结：**  
本章介绍了自监督表示学习在自然语言处理中的应用，包括语言模型、文本分类和问答系统。自监督学习通过无监督的方式学习文本的潜在特征和结构，显著提高了NLP任务的性能。在实际应用中，自监督学习技术为NLP系统提供了强大的工具，使得计算机能够更好地理解和生成自然语言。在接下来的章节中，我们将继续探讨自监督表示学习在计算机视觉和其他领域的应用。

#### 第9章：自监督表示学习在计算机视觉中的应用

**9.1 图像自监督表示学习**

计算机视觉领域中的一个核心任务是图像表示学习，即通过学习图像的潜在特征，使计算机能够理解和识别图像内容。自监督表示学习为图像自监督表示学习提供了有效的方法，使得模型可以在没有外部监督信号的情况下，自动学习图像的丰富特征。

**自监督图像表示学习算法**：

- **图像生成对抗网络（Image Generative Adversarial Network，Image GAN）**：GAN是一种生成模型，由生成器和判别器组成。生成器尝试生成逼真的图像，判别器则判断生成图像与真实图像的相似度。通过对抗训练，生成器可以学习到图像的潜在特征。

- **自编码器（Autoencoder）**：自编码器是一种无监督学习模型，它通过编码器将输入图像映射到一个低维特征空间，然后通过解码器重建原始图像。自编码器通过最小化重建误差，学习图像的潜在特征。

- **变分自编码器（Variational Autoencoder，VAE）**：VAE是对自编码器的一种扩展，它通过引入潜在变量，将图像的表示建模为连续的概率分布。VAE能够更好地捕捉图像的多样性和复杂性。

**自监督图像表示学习应用**：

- **图像分类**：自监督图像表示学习可以用于图像分类任务，通过学习图像的潜在特征，提高分类模型的性能。例如，通过预训练的自监督模型，可以在没有标注数据的情况下，对图像进行分类。

- **图像生成**：自监督图像表示学习可以用于图像生成任务，通过生成器生成逼真的图像。例如，通过预训练的GAN模型，可以生成高质量的艺术图像、人脸图像和场景图像。

- **图像修复**：自监督图像表示学习可以用于图像修复任务，通过学习图像的潜在特征，修复图像中的破损或噪声部分。例如，通过预训练的VAE模型，可以修复老照片或图像中的模糊区域。

**自监督视频表示学习算法**：

- **视频自编码器（Video Autoencoder）**：视频自编码器通过编码器将视频序列映射到一个低维特征空间，然后通过解码器重建原始视频序列。视频自编码器通过最小化重建误差，学习视频的潜在特征。

- **变分视频自编码器（Variational Video Autoencoder，VVAE）**：VVAE是对视频自编码器的一种扩展，通过引入潜在变量，将视频的表示建模为连续的概率分布。VVAE能够更好地捕捉视频的多样性和复杂性。

**自监督视频表示学习应用**：

- **视频分类**：自监督视频表示学习可以用于视频分类任务，通过学习视频的潜在特征，提高分类模型的性能。例如，通过预训练的自监督模型，可以在没有标注数据的情况下，对视频进行分类。

- **视频生成**：自监督视频表示学习可以用于视频生成任务，通过生成器生成逼真的视频序列。例如，通过预训练的GAN模型，可以生成高质量的电影片段、体育比赛视频和虚拟现实视频。

- **视频修复**：自监督视频表示学习可以用于视频修复任务，通过学习视频的潜在特征，修复视频中的破损或噪声部分。例如，通过预训练的VAE模型，可以修复老电影或视频中的破损片段或噪声区域。

**9.3 自监督学习在图像生成中的应用**

自监督学习在图像生成领域具有广泛的应用，通过无监督的方式，生成逼真的图像和视频。以下是一些自监督图像生成应用案例：

下面我们通过一个简单的Python代码示例，展示如何实现自监督表示学习中的变分自编码器（VAE）。

```python
import tensorflow as tf
from tensorflow.keras.layers import Input, Dense, Lambda
from tensorflow.keras.models import Model

# 设置超参数
 latent_dim = 2  # 潜在变量维度
 intermediate_dim = 256  # 编码器和解码器的中间维度
 batch_size = 32  # 批处理大小
 epsilon_std = 1.0  # 潜在变量的标准差

# 创建输入层
input_img = Input(shape=(28, 28, 1))  # 假设输入图像为28x28的单通道灰度图像

# 编码器部分
x = Dense(intermediate_dim, activation='relu')(input_img)
z_mean = Dense(latent_dim)(x)
z_log_var = Dense(latent_dim)(x)

# 从均值和方差中采样得到潜在变量z
z = Lambda(lambda x: x[0] + tf.random.normal(tf.shape(x[1]), 0, epsilon_std) * tf.exp(0.5 * x[1]))([z_mean, z_log_var])

# 解码器部分
x_decoded_mean = Dense(intermediate_dim, activation='relu')(z)
output = Dense(28 * 28 * 1, activation='sigmoid')(x_decoded_mean)

# 构建VAE模型
vae = Model(input_img, output)
vae.compile(optimizer='rmsprop', loss='binary_crossentropy')

# 打印模型结构
vae.summary()
```
