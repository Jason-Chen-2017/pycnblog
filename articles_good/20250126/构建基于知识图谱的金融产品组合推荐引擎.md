**Python源代码实现：**

```python
# 导入必要的库
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

# 用户评分矩阵
user_ratings = np.array([
    [5, 0, 3, 1],
    [0, 1, 2, 4],
    [4, 0, 0, 1],
    [3, 2, 0, 0]
])

# 计算用户间的相似度
similarity_matrix = cosine_similarity(user_ratings)

# 推荐产品
def recommend_products(user_index, similarity_matrix, user_ratings, k=3):
    # 获取相似度最高的 k 个用户
    similar_users = np.argsort(similarity_matrix[user_index])[1:k+1]

    # 计算相似用户对未知产品的评分预测
    product_scores = np.dot(similarity_matrix[user_index][similar_users], user_ratings[similar_users])

    # 推荐未知产品
    recommended_products = np.argsort(product_scores)[::-1]
    return recommended_products

# 测试推荐
user_index = 0
recommended_products = recommend_products(user_index, similarity_matrix, user_ratings)
print("推荐产品：", recommended_products)
```

**### 数学公式**

$$
\text{相似度} = \frac{\sum_{i=1}^{n} (r_{ui} - \bar{r_u})(r_{uj} - \bar{r_j})}{\sqrt{\sum_{i=1}^{n} (r_{ui} - \bar{r_u})^2} \sqrt{\sum_{i=1}^{n} (r_{uj} - \bar{r_j})^2}}
$$
