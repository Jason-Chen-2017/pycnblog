### 5.2 系统核心实现源代码

下面是系统核心实现的部分源代码。为了简洁，我们仅展示用户搜索商品、推荐商品和购物车管理的关键部分。

```python
# 导入必要的库
import pandas as pd
from sklearn.model_selection import train_test_split
from keras.models import Sequential
from keras.layers import Dense, Dropout
from keras.optimizers import Adam
from elasticsearch import Elasticsearch

# 连接到Elasticsearch
es = Elasticsearch("http://localhost:9200")

# 获取商品数据
def get_products():
    response = es.search(index="products", body={"query": {"match_all": {}}})
    products = response['hits']['hits']
    product_data = []
    for product in products:
        product_data.append(product['_source'])
    return pd.DataFrame(product_data)

# 训练推荐模型
def train_recommendation_model(product_data):
    # 分割数据集
    train_data, test_data = train_test_split(product_data, test_size=0.2, random_state=42)

    # 准备特征和标签
    X_train = train_data[['category', 'price']]
    y_train = train_data['id']

    # 编建模型
    model = Sequential()
    model.add(Dense(128, input_shape=(2,), activation='relu'))
    model.add(Dropout(0.2))
    model.add(Dense(64, activation='relu'))
    model.add(Dropout(0.2))
    model.add(Dense(1, activation='sigmoid'))

    # 编译模型
    model.compile(optimizer=Adam(), loss='binary_crossentropy', metrics=['accuracy'])

    # 训练模型
    model.fit(X_train, y_train, epochs=10, batch_size=32, validation_split=0.1)
    return model

# 推荐商品
def recommend_products(user_id, model, product_data):
    user_profile = product_data[product_data['id'] == user_id]
    user_profile = user_profile[['category', 'price']].values.reshape(1, -1)
    predictions = model.predict(user_profile)
    recommended_ids = predictions.argsort()[0][-3:][::-1]
    return product_data[product_data['id'].isin(recommended_ids)]

# 用户搜索商品
def search_products(query):
    response = es.search(index="products", body={"query": {"match": {"name": query}}})
    products = response['hits']['hits']
    return products

# 用户添加商品到购物车
def add_to_cart(user_id, product_id):
    cart = get_cart(user_id)
    cart.append(product_id)
    es.index(index="carts", id=user_id, body={"products": cart})

# 获取购物车商品
def get_cart(user_id):
    response = es.get(index="carts", id=user_id)
    cart = response['_source']['products']
    return cart
```

在代码中，我们使用Elasticsearch的`search`方法，传入索引名称为"products"，以及查询条件{"match": {"name": query}}。该方法返回包含匹配结果的文档列表，其中每个文档都包含商品的详细信息。

#### 训练推荐模型

推荐系统使用机器学习算法构建。在这个示例中，我们使用一个简单的神经网络模型进行训练。模型输入是商品类别和价格，输出是商品ID的概率。

```python
# 训练推荐模型
def train_recommendation_model(product_data):
    # 分割数据集
    train_data, test_data = train_test_split(product_data, test_size=0.2, random_state=42)

    # 准备特征和标签
    X_train = train_data[['category', 'price']]
    y_train = train_data['id']

    # 编建模型
    model = Sequential()
    model.add(Dense(128, input_shape=(2,), activation='relu'))
    model.add(Dropout(0.2))
    model.add(Dense(64, activation='relu'))
    model.add(Dropout(0.2))
    model.add(Dense(1, activation='sigmoid'))

    # 编译模型
    model.compile(optimizer=Adam(), loss='binary_crossentropy', metrics=['accuracy'])

    # 训练模型
    model.fit(X_train, y_train, epochs=10, batch_size=32, validation_split=0.1)
    return model
```

在这个函数中，我们首先将数据集分为训练集和测试集。然后，我们使用Keras库构建一个序列模型，包含三个全连接层和适当的正则化层。模型使用Adam优化器和二进制交叉熵损失函数进行编译。最后，我们使用训练集训练模型，并在测试集上验证模型性能。

#### 推荐商品

基于训练好的模型，我们可以为用户推荐商品。推荐过程首先获取用户浏览或购买的商品，然后根据这些商品的特征计算推荐概率，并返回概率最高的商品。

```python
# 推荐商品
def recommend_products(user_id, model, product_data):
    user_profile = product_data[product_data['id'] == user_id]
    user_profile = user_profile[['category', 'price']].values.reshape(1, -1)
    predictions = model.predict(user_profile)
    recommended_ids = predictions.argsort()[0][-3:][::-1]
    return product_data[product_data['id'].isin(recommended_ids)]
```

在这个函数中，我们首先获取用户的历史浏览或购买记录，并提取相应的特征（类别和价格）。然后，我们将这些特征输入到训练好的模型中，获取推荐概率。最后，我们根据概率对商品进行排序，并返回概率最高的三个商品。

#### 用户添加商品到购物车

用户可以将商品添加到购物车。购物车使用Elasticsearch中的文档存储，每个用户的购物车都有一个唯一的ID。

```python
# 用户添加商品到购物车
def add_to_cart(user_id, product_id):
    cart = get_cart(user_id)
    cart.append(product_id)
    es.index(index="carts", id=user_id, body={"products": cart})
```

在这个函数中，我们首先获取用户的购物车，然后添加新的商品ID到购物车列表中。最后，我们使用Elasticsearch的`index`方法更新购物车文档。

#### 获取购物车商品

获取购物车商品的功能相对简单，我们直接从Elasticsearch中获取用户的购物车文档。

```python
# 获取购物车商品
def get_cart(user_id):
    response = es.get(index="carts", id=user_id)
    cart = response['_source']['products']
    return cart
```
