\[ f(s, t) = \sum_{e \in \text{path}(s, t)} w(e) \]

其中，\(\text{path}(s, t)\)表示从源点\(s\)到目标点\(t\)的路径。

#### 12.1.3 优化路径算法的分类

根据路径优化问题的具体目标，优化路径算法可以分为以下几类：

1. **最短路径算法**：这类算法的目标是找到一条从源点到目标点的最短路径。
2. **最大权重路径算法**：这类算法的目标是找到一条从源点到目标点的路径，使得该路径的总权重最大。
3. **最优路径算法**：这类算法的目标是找到一条满足特定条件的最优路径。

#### 13.1 Dijkstra算法

Dijkstra算法是最短路径算法中的一种，它能够在一个加权图中找到从源点到所有其他节点的最短路径。Dijkstra算法的基本原理是使用一个优先队列来选择下一个访问的节点，并逐步扩展到其他节点。

下面是Dijkstra算法的伪代码：

```
Dijkstra(G, w, s):
    for each vertex v in G:
        dist[v] = INFINITY
        prev[v] = NULL
    dist[s] = 0
    Q = a priority queue containing all vertices
    Q.insert(s, dist[s])
    while Q is not empty:
        u = Q.extract_min()
        for each edge (u, v) in G:
            alt = dist[u] + w(u, v)
            if alt < dist[v]:
                dist[v] = alt
                prev[v] = u
                if v is not in Q:
                    Q.insert(v, dist[v])
    return dist, prev
```

其中，\(G\)是图，\(w\)是边权重函数，\(s\)是源点，\(dist\)是节点的最短路径距离，\(prev\)是节点的最短路径前驱节点。

#### 13.2 A*算法

A*算法是一种启发式搜索算法，它利用启发函数来指导搜索过程，从而在许多情况下能够比Dijkstra算法更快地找到最短路径。A*算法的目标是找到一条从源点到目标点的最优路径，其中启发函数\(h(v)\)是一个估计从节点\(v\)到目标点的距离的函数。

下面是A*算法的伪代码：

```

    open_set.insert(s, 0)
    came_from = an empty map
    g_score[s] = 0
    f_score[s] = h(s)
    while not open_set.isEmpty():

        if current == g:
            return reconstruct_path(came_from, current)
        for each neighbor in neighbors(current):
            tentative_g_score = g_score[current] + w(current, neighbor)
            if tentative_g_score < g_score[neighbor]:
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g_score
                f_score[neighbor] = g_score[neighbor] + h(neighbor)
                if neighbor is not in open_set:
                    open_set.insert(neighbor, f_score[neighbor])

```

其中，\(g\)是目标点，\(h\)是启发函数。
