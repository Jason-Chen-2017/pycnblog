## 第二部分：核心概念与联系

### 2.1 家庭结构的基本概念

家庭结构是指家庭成员的组成和关系，它是家庭模式的基础。常见的家庭结构包括核心家庭（夫妻及未成年子女）、主干家庭（夫妻及两个已婚子女）、单亲家庭（单亲及子女）等。

| 家庭结构类型 | 成员组成 | 特点 |
| :--: | :--: | :--: |
| 核心家庭 | 夫妻及未成年子女 | 成员关系紧密，家庭功能完整 |
| 主干家庭 | 夫妻及两个已婚子女 | 家庭规模较大，代际关系复杂 |
| 单亲家庭 | 单亲及子女 | 家庭责任集中于单亲成员 |

### 2.2 家庭模式的核心概念

家庭模式是家庭生活的基本形式和模式，它反映了家庭的结构、功能、角色等方面的特点。常见的家庭模式包括核心家庭、主干家庭、单亲家庭、丁克家庭、跨国家庭等。

| 家庭模式类型 | 成员组成 | 家庭功能 | 社会影响 |
| :--: | :--: | :--: | :--: |
| 核心家庭 | 夫妻及未成年子女 | 生活支持、教育抚养、情感交流 | 社会稳定基础 |
| 主干家庭 | 夫妻及两个已婚子女 | 家族传承、经济支持、情感互动 | 社会老龄化问题 |
| 单亲家庭 | 单亲及子女 | 经济独立、情感支持、教育责任 | 社会压力增大 |
| 丁克家庭 | 夫妻无子女 | 经济自由、职业发展 | 社会观念变化 |
| 跨国家庭 | 夫妻或单亲与跨国配偶 | 文化融合、家庭支持 | 国际婚姻趋势 |

### 2.3 传统价值观的核心概念

传统价值观是指在长期的社会发展中形成的关于家庭、婚姻、子女教育等方面的观念和信念。传统价值观的核心概念包括婚姻观、亲子观、家庭责任观等。

| 传统价值观概念 | 描述 |
| :--: | :--: |
| 婚姻观 | 强调婚姻的道德、法律和社会责任 |
| 亲子观 | 认为父母有抚养、教育和保护子女的责任 |
| 家庭责任观 | 重视家庭内部的互助、支持和责任分担 |

### 2.4 新型家庭模式的核心概念

新型家庭模式是在现代社会中出现的，与传统家庭模式不同的家庭形式。新型家庭模式的核心概念包括家庭结构、家庭功能、家庭角色等方面的变化。

| 新型家庭模式类型 | 核心概念 |
| :--: | :--: |
| 单亲家庭 | 独立、自主、经济压力 |
| 丁克家庭 | 无子女、经济自由、职业发展 |
| 跨国家庭 | 文化融合、远程支持、国际婚姻 |
| 组合家庭 | 成员多样化、角色互补、家庭责任 |

### 2.5 家庭结构多元化与核心概念的关联

家庭结构多元化与核心概念之间存在着密切的关联。家庭结构的多元化反映了家庭模式的变化，这种变化又受到传统价值观的影响。同时，新型家庭模式的核心概念也对传统价值观提出了挑战，推动了家庭结构的多元化。
