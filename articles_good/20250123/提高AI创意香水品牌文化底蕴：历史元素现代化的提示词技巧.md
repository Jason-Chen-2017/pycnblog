```python
# 数据预处理
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

def preprocess_data(data):
    # 数据清洗、标准化和划分训练集测试集
    df = pd.DataFrame(data)
    df = df.dropna()  # 数据清洗
    df = StandardScaler().fit_transform(df)  # 数据标准化
    X_train, X_test, y_train, y_test = train_test_split(df.iloc[:, :-1], df.iloc[:, -1], test_size=0.2, random_state=42)
    return X_train, X_test, y_train, y_test

# 模型训练
from sklearn.linear_model import LogisticRegression

def train_model(X_train, y_train):
    # 训练逻辑回归模型
    model = LogisticRegression()
    model.fit(X_train, y_train)
    return model

# 系统开发
def develop_system(model, X_test, y_test):
    # 预测并评估模型性能
    predictions = model.predict(X_test)
    accuracy = (predictions == y_test).mean()
    print(f"Model accuracy: {accuracy:.2f}")
    return model, accuracy
```

2. **数据标准化**：使用 `StandardScaler()` 将数据标准化，以便模型训练。
3. **数据划分**：使用 `train_test_split()` 方法将数据划分为训练集和测试集，比例为80%训练集，20%测试集。

接下来，定义了模型训练函数 `train_model`，该函数使用 `LogisticRegression()` 类创建逻辑回归模型，并使用 `fit()` 方法进行训练。

最后，定义了系统开发函数 `develop_system`，该函数接收训练好的模型和测试数据，执行以下步骤：

1. **预测**：使用 `predict()` 方法对测试数据进行预测。
2. **评估**：计算预测准确率，并打印结果。
