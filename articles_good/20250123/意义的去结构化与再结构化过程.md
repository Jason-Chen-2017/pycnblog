```python
import re
import nltk

def preprocess_text(text):
    # 清洗文本
    cleaned_text = re.sub(r'[^\w\s]', '', text)
    
    # 去除停用词
    stop_words = nltk.corpus.stopwords.words('english')
    cleaned_text = ' '.join([word for word in cleaned_text.split() if word not in stop_words])
    
    # 分词
    tokens = nltk.word_tokenize(cleaned_text)
    
    return tokens

# 测试文本
text = "我喜欢看电影。她喜欢听音乐。我们一起去旅游。"

# 数据预处理
preprocessed_text = preprocess_text(text)

print(preprocessed_text)
```

#### 3.1.3 去结构化与再结构化的关系

去结构化和再结构化是相互关联的过程。去结构化是为了更好地理解和分析数据，而再结构化则是为了将分析结果以结构化的形式保存和利用。二者之间存在着以下关系：

### 示例代码

下面是一个简单的Python示例，展示了去结构化和再结构化的过程。

```python
# 去结构化示例
data = [
    {"name": "Alice", "age": 30, "city": "New York"},
    {"name": "Bob", "age": 25, "city": "San Francisco"},
    {"name": "Charlie", "age": 35, "city": "Los Angeles"}
]

# 去结构化：提取姓名和年龄
def destructure(data):
    return [{"name": d["name"], "age": d["age"]} for d in data]

destructured_data = destructure(data)
print("去结构化后的数据：", destructured_data)

# 再结构化示例
# 假设我们已经有去结构化后的数据
destructured_data = [
    {"name": "Alice", "age": 30},
    {"name": "Bob", "age": 25},
    {"name": "Charlie", "age": 35}
]

# 再结构化：添加城市信息
def restructure(data):
    cities = {"New York": 1, "San Francisco": 2, "Los Angeles": 3}
    return [{"name": d["name"], "age": d["age"], "city": cities[d["city"]] } for d in data]

structured_data = restructure(destructured_data)
print("再结构化后的数据：", structured_data)
```

```
去结构化后的数据： [{'name': 'Alice', 'age': 30}, {'name': 'Bob', 'age': 25}, {'name': 'Charlie', 'age': 35}]
再结构化后的数据： [{'name': 'Alice', 'age': 30, 'city': 1}, {'name': 'Bob', 'age': 25, 'city': 2}, {'name': 'Charlie', 'age': 35, 'city': 3}]
```

在这个示例中，我们首先对原始数据进行去结构化，提取出姓名和年龄。然后，我们使用去结构化后的数据对城市信息进行再结构化，添加到每个数据项中。
