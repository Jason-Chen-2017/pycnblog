4. **打印过程**：3D打印机根据切片文件中的指令逐层添加材料，最终构建出三维实体。

#### A.3.1 模型切片算法实现

以下是一个简单的模型切片算法的伪代码示例：

```plaintext
function sliceModel(model, layerHeight):
    slices = []
    currentLayer = 0
    
    while currentLayer < model.height:
        currentSlice = []
        for layer in model.layers[currentLayer]:
            currentSlice.append(layer)
        slices.append(currentSlice)
        currentLayer += layerHeight
    
    return slices
```

**后处理**：
