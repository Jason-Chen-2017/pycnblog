#### 支持向量机（SVM）

支持向量机（Support Vector Machine，SVM）是一种常用的监督学习算法，主要用于分类任务。SVM的基本思想是找到能够将不同类别的数据点尽可能分开的决策边界。

**线性SVM（Linear SVM）**

线性SVM假设数据可以被一个超平面分隔，且超平面由一个线性函数（即权重向量）决定。给定特征向量 \( x \)，预测类别标签 \( y \) 的函数为：

\[ f(x) = \text{sign}(\omega \cdot x + b) \]

其中，\( \omega \) 是权重向量，\( b \) 是偏置项。

训练线性SVM的伪代码如下：

```python
def train_linear_svm(X, y):
    # X: 特征矩阵，y: 标签向量
    n_samples, n_features = X.shape
    
    # 初始化权重和偏置
    omega = np.random.randn(n_features)
    b = 0
    
    # 梯度下降迭代
    for epoch in range(num_epochs):
        for x, y in zip(X, y):
            prediction = sign(omega.dot(x) + b)
            delta_omega = (y - prediction) * x
            omega += learning_rate * delta_omega
            b += learning_rate * (y - prediction)
    
    return omega, b

# 使用训练数据（X, y）调用train_linear_svm函数，得到权重ω和偏置b
omega, b = train_linear_svm(X_train, y_train)
```

**非线性SVM（Non-linear SVM）**

非线性SVM通过核函数将低维数据映射到高维空间，使得原本线性不可分的数据在高维空间中变得可分。常见的核函数包括线性核、多项式核和径向基函数（RBF）核。

非线性SVM的伪代码如下：

```python
def train_non_linear_svm(X, y, kernel='rbf', C=1.0):
    # X: 特征矩阵，y: 标签向量
    n_samples = X.shape[0]

    # 初始化权重和偏置
    omega = np.random.randn(n_features)
    b = 0

    # 使用核函数计算特征空间中的内积
    def kernel_function(x1, x2):
        if kernel == 'linear':
            return np.dot(x1, x2)
        elif kernel == 'poly':
            return (gamma * np.dot(x1, x2) + 1)**degree
        elif kernel == 'rbf':
            return np.exp(-gamma * np.linalg.norm(x1 - x2)**2)

    # 梯度下降迭代
    for epoch in range(num_epochs):
        for x, y in zip(X, y):
            prediction = sign(np.dot(omega, kernel_function(x, X)) + b)
            delta_omega = (y - prediction) * kernel_function(x, X)
            omega += learning_rate * delta_omega
            b += learning_rate * (y - prediction)
    
    return omega, b

# 使用训练数据（X, y）调用train_non_linear_svm函数，根据需要设置核函数和参数
omega, b = train_non_linear_svm(X_train, y_train, kernel='rbf', C=1.0)
```

#### 决策树

决策树是一种流行的分类和回归算法，通过一系列的判断规则对数据进行划分，每个节点代表一个特征，分支代表该特征的取值范围。

**ID3算法**

ID3（Iterative Dichotomiser 3）算法是基于信息增益（Information Gain）来选择最优特征进行划分。

信息增益的计算公式为：

\[ IG(D, A) = Entropy(D) - \sum_{v \in Values(A)} \frac{|D_v|}{|D|} \cdot Entropy(D_v) \]

其中，\( Entropy(D) \) 是数据集 \( D \) 的熵，\( Values(A) \) 是特征 \( A \) 的所有可能取值，\( D_v \) 是数据集 \( D \) 中特征 \( A \) 取值为 \( v \) 的子集。

ID3算法的伪代码如下：

```python
def ID3(X, y):
    # X: 特征矩阵，y: 标签向量
    if all(y == y[0]):
        return y[0]  # 叶子节点，所有数据属于同一类别
    
    if len(X[0]) == 0 or len(set(y)) == 1:
        return majority_vote(y)  # 叶子节点，数据量不足或所有数据属于同一类别
    
    best_gain = -1
    best_feature = None
    
    for feature in set(X.T):
        gain = information_gain(X, y, feature)
        if gain > best_gain:
            best_gain = gain
            best_feature = feature
            
    left subtree = X[:, X.T == best_feature[0]]
    right subtree = X[:, X.T != best_feature[0]]
    
    tree = {}
    tree[best_feature] = {
        'left': ID3(left_subtree, y[left_subtree]),
        'right': ID3(right_subtree, y[right_subtree])
    }
    
    return tree

# 使用训练数据（X, y）调用ID3函数，构建决策树
tree = ID3(X_train, y_train)
```

**C4.5算法**

C4.5算法是ID3算法的改进版，它使用增益率（Gain Ratio）来选择最优特征，避免了信息增益偏向于选择具有更多值的特征的问题。

增益率的计算公式为：

\[ Gain Ratio(D, A) = \frac{IG(D, A)}{Split Info(A)} \]

其中，\( Split Info(A) \) 是特征 \( A \) 的分裂信息，计算公式为：

\[ Split Info(A) = -\sum_{v \in Values(A)} \frac{|D_v|}{|D|} \cdot \log_2 \frac{|D_v|}{|D|} \]

C4.5算法的伪代码如下：

```python
def C4.5(X, y):
    # X: 特征矩阵，y: 标签向量

    best_feature = None

        gain_ratio = gain_ratio(X, y, feature)

        'left': C4.5(left_subtree, y[left_subtree]),
        'right': C4.5(right_subtree, y[right_subtree])
    }
    
    return tree

#### 神经网络

神经网络（Neural Networks）是一种模拟生物神经系统的计算模型，通过多层神经元进行数据处理和特征提取。神经网络可以分为前向传播（Forward Propagation）和反向传播（Backpropagation）两个阶段。

**前向传播**

前向传播的过程是将输入数据通过网络的各个层传递，最终得到输出结果。每一层的输出通过激活函数进行非线性变换。

前向传播的伪代码如下：

def forward_propagation(x, weights, biases, activation_functions):
    # x: 输入数据，weights: 权重矩阵，biases: 偏置向量，activation_functions: 激活函数
    for layer in range(num_layers - 1):
        z = np.dot(weights[layer] * x + biases[layer])
        a = activation_functions[layer](z)
        x = a
    
    return a

# 示例：使用前向传播计算输出
output = forward_propagation(input_data, weights, biases, activation_functions)
```

**反向传播**

反向传播的过程是计算输出结果与实际标签之间的误差，并反向传播误差以更新网络的权重和偏置。

反向传播的伪代码如下：

```python
def backward_propagation(a, y, weights, biases, activation_functions, learning_rate):
    # a: 输出数据，y: 实际标签，weights: 权重矩阵，biases: 偏置向量，activation_functions: 激活函数
    for layer in range(num_layers - 1, 0, -1):
        z = np.dot(weights[layer - 1] * a + biases[layer - 1])
        delta = activation_functions[layer](z) * (1 - activation_functions[layer](z))
        d_weights[layer - 1] += np.dot(a.T, delta)
        d_biases[layer - 1] += delta
        a = delta
    
    # 计算输出层的误差
    output_error = a - y
    d_output_weights = np.dot(y.T, weights[-1])
    d_output_biases = output_error
    
    # 更新权重和偏置
    weights[-1] -= learning_rate * d_output_weights
    biases[-1] -= learning_rate * d_output_biases
    
    for layer in range(num_layers - 2, 0, -1):
        d_weights[layer] = np.dot(delta.T, weights[layer])
        d_biases[layer] = delta
        
        z = np.dot(weights[layer - 1] * a + biases[layer - 1])
        delta = activation_functions[layer](z) * (1 - activation_functions[layer](z))
        a = np.dot(delta.T, weights[layer])
        
        weights[layer] -= learning_rate * d_weights[layer]
        biases[layer] -= learning_rate * d_biases[layer]
    
    return weights, biases

# 示例：使用反向传播更新权重和偏置
weights, biases = backward_propagation(output, y, weights, biases, activation_functions, learning_rate)
```

### 数学模型和数学公式讲解

在环境污染预警中，核心算法的数学模型和公式至关重要。本文将详细讲解支持向量机（SVM）、决策树和神经网络等算法的数学模型，并使用LaTeX格式进行公式书写。

#### 支持向量机（SVM）

**线性SVM**

线性SVM的预测函数为：

\[ f(x) = \text{sign}(\omega \cdot x + b) \]

其中，\( \omega \) 是权重向量，\( b \) 是偏置项。线性SVM的目标是最小化损失函数，即：

\[ \min_{\omega, b} \frac{1}{2} \sum_{i=1}^{n} (w \cdot x_i + b)^2 \]

约束条件是：

\[ y_i (\omega \cdot x_i + b) \geq 1, \quad i=1,2,...,n \]

其中，\( y_i \) 是标签，\( x_i \) 是特征向量。

**非线性SVM**

非线性SVM通过核函数将低维数据映射到高维空间。常见的核函数包括：

1. **线性核**：

\[ K(x, x') = \omega \cdot x \cdot x' + b \]

2. **多项式核**：

\[ K(x, x') = (\gamma x \cdot x' + 1)^d \]

3. **径向基函数（RBF）核**：

\[ K(x, x') = \exp(-\gamma \|x - x'\|^2) \]

#### 决策树

**信息增益（Information Gain）**

信息增益是衡量特征划分数据集合后信息量的减少程度，计算公式为：

\[ IG(D, A) = Entropy(D) - \sum_{v \in Values(A)} \frac{|D_v|}{|D|} \cdot Entropy(D_v) \]

其中，\( Entropy(D) \) 是数据集合 \( D \) 的熵，计算公式为：

\[ Entropy(D) = -\sum_{v \in Values(A)} \frac{|D_v|}{|D|} \cdot \log_2 \frac{|D_v|}{|D|} \]

**增益率（Gain Ratio）**

增益率是信息增益与特征分裂信息之比，计算公式为：

\[ Gain Ratio(D, A) = \frac{IG(D, A)}{Split Info(A)} \]

其中，\( Split Info(A) \) 是特征 \( A \) 的分裂信息，计算公式为：

\[ Split Info(A) = -\sum_{v \in Values(A)} \frac{|D_v|}{|D|} \cdot \log_2 \frac{|D_v|}{|D|} \]

#### 神经网络

**前向传播**

神经网络的前向传播过程包括多层神经元，每层神经元之间的连接权重和偏置。前向传播的输入和输出关系可以表示为：

\[ z_l = \sum_{j} w_{lj} x_j + b_l \]

\[ a_l = \sigma(z_l) \]

其中，\( z_l \) 是第 \( l \) 层的净输入，\( w_{lj} \) 是权重，\( b_l \) 是偏置，\( a_l \) 是激活值，\( \sigma \) 是激活函数。

常见的激活函数包括：

1. **sigmoid函数**：

\[ \sigma(z) = \frac{1}{1 + e^{-z}} \]

2. **ReLU函数**：

\[ \sigma(z) = \max(0, z) \]

**反向传播**

神经网络的反向传播过程是计算输出误差并更新权重和偏置。反向传播的误差计算公式为：

\[ \delta_l = \frac{\partial J}{\partial z_l} = \sigma'(z_l) \cdot \delta_{l+1} \]

其中，\( \delta_l \) 是第 \( l \) 层的误差，\( J \) 是损失函数。

权重和偏置的更新公式为：

\[ w_{lj} \leftarrow w_{lj} - \alpha \cdot \frac{\partial J}{\partial w_{lj}} \]

\[ b_{l} \leftarrow b_{l} - \alpha \cdot \frac{\partial J}{\partial b_{l}} \]

其中，\( \alpha \) 是学习率。

#### 举例说明

1. **线性SVM**

   假设我们有两个特征向量 \( x_1 \) 和 \( x_2 \)，标签 \( y_1 = 1 \)，\( y_2 = -1 \)，则线性SVM的目标是最小化：

   \[
   \begin{aligned}
   \min_{\omega, b} \frac{1}{2} (\omega \cdot x_1 + b)^2 + (\omega \cdot x_2 + b)^2 \\
   \text{subject to:} \\
   1 \cdot (\omega \cdot x_1 + b) &\geq 1 \\
   -1 \cdot (\omega \cdot x_2 + b) &\geq 1
   \end{aligned}
   \]

   通过求解这个优化问题，可以得到权重 \( \omega \) 和偏置 \( b \) 的最优值。

2. **决策树**

   假设我们有一个特征集合 \( A = \{A_1, A_2, A_3\} \)，数据集合 \( D = \{D_1, D_2, D_3\} \)，则信息增益为：

   \[
   IG(D, A) = Entropy(D) - \frac{1}{3} \cdot Entropy(D_1) - \frac{1}{3} \cdot Entropy(D_2) - \frac{1}{3} \cdot Entropy(D_3)
   \]

   其中，\( D_1, D_2, D_3 \) 是按照特征 \( A_1, A_2, A_3 \) 分割的数据集合，\( Entropy(D_i) \) 是数据集合 \( D_i \) 的熵。

3. **神经网络**

   假设我们有一个两层神经网络，输入层有3个神经元，隐藏层有2个神经元，输出层有1个神经元。权重和偏置如下：

   \[
   \begin{aligned}
   w_{11} &= 0.5, \quad w_{12} = 0.3, \quad w_{13} = 0.7 \\
   w_{21} &= 0.1, \quad w_{22} = 0.6, \quad w_{23} = 0.8 \\
   b_1 &= 0.2, \quad b_2 = 0.4, \quad b_3 = 0.6
   \end{aligned}
   \]

   通过前向传播，可以得到隐藏层的净输入和激活值：

   \[
   \begin{aligned}
   z_1 &= 0.5 \cdot x_1 + 0.3 \cdot x_2 + 0.7 \cdot x_3 + 0.2 = 1.2 \\
   a_1 &= \sigma(z_1) = 0.794 \\
   z_2 &= 0.1 \cdot x_1 + 0.6 \cdot x_2 + 0.8 \cdot x_3 + 0.4 = 1.3 \\
   a_2 &= \sigma(z_2) = 0.866
   \end{aligned}
   \]

   通过反向传播，可以计算输出误差和权重更新：

   \[
   \begin{aligned}
   \delta_3 &= (y - a_3) \cdot \sigma'(a_3) = 0.2 \cdot 0.244 \\
   \delta_2 &= \delta_3 \cdot w_{32} \cdot \sigma'(a_2) = 0.2 \cdot 0.244 \cdot 0.136 \\
   \delta_1 &= \delta_2 \cdot w_{31} \cdot \sigma'(a_1) = 0.2 \cdot 0.244 \cdot 0.136 \cdot 0.207
   \end{aligned}
   \]

   权重和偏置的更新公式为：

   \[
   \begin{aligned}
   w_{31} &= w_{31} - \alpha \cdot \delta_1 \cdot x_1 = 0.5 - 0.1 \cdot 0.2 \cdot 0.244 \cdot 0.207 \\
   w_{32} &= w_{32} - \alpha \cdot \delta_1 \cdot x_2 = 0.3 - 0.1 \cdot 0.2 \cdot 0.244 \cdot 0.207 \\
   w_{33} &= w_{33} - \alpha \cdot \delta_1 \cdot x_3 = 0.7 - 0.1 \cdot 0.2 \cdot 0.244 \cdot 0.207 \\
   b_3 &= b_3 - \alpha \cdot \delta_3 = 0.6 - 0.1 \cdot 0.2 \\
   w_{21} &= w_{21} - \alpha \cdot \delta_2 \cdot x_1 = 0.1 - 0.1 \cdot 0.2 \cdot 0.244 \cdot 0.136 \\
   w_{22} &= w_{22} - \alpha \cdot \delta_2 \cdot x_2 = 0.6 - 0.1 \cdot 0.2 \cdot 0.244 \cdot 0.136 \\
   w_{23} &= w_{23} - \alpha \cdot \delta_2 \cdot x_3 = 0.8 - 0.1 \cdot 0.2 \cdot 0.244 \cdot 0.136 \\
   b_2 &= b_2 - \alpha \cdot \delta_2 = 0.4 - 0.1 \cdot 0.244 \cdot 0.136 \\
   b_1 &= b_1 - \alpha \cdot \delta_1 = 0.2 - 0.1 \cdot 0.244
   \end{aligned}
   \]
