## 第二部分: 3D生物打印技术基础

### 2.1 3D生物打印技术概述

#### 2.1.1 技术发展历程

3D生物打印技术的发展始于20世纪80年代，当时3D打印技术最初应用于制造业领域。随着计算机辅助设计和材料科学的进步，3D打印技术在20世纪90年代逐渐扩展到生物医学领域。2000年左右，3D生物打印技术开始应用于制造生物组织支架和个性化医疗植入物。近年来，随着生物材料和生物3D打印设备的不断改进，3D生物打印技术在器官制造和器官移植领域取得了显著进展。

#### 2.1.2 技术分类与应用

3D生物打印技术根据生物材料的不同和处理方法的不同，可以分为多种类型。常见的3D生物打印技术包括：

1. **立体光刻（SLA）**：利用光敏树脂材料，通过逐层固化来构建三维结构。SLA技术适用于制造高精度、复杂形状的器官支架。

2. **熔融沉积建模（FDM）**：利用热塑性材料，通过逐层堆积来构建三维结构。FDM技术适用于制造大尺寸、结构简单的器官模型。

3. **电子束熔融（EBM）**：利用电子束熔化金属粉末，通过逐层堆积来构建三维结构。EBM技术适用于制造高强度、耐高温的生物材料。

4. **选择性激光烧结（SLS）**：利用激光烧结粉末材料，通过逐层堆积来构建三维结构。SLS技术适用于制造复杂形状、高强度和高耐磨性的器官支架。

这些3D生物打印技术在不同领域有着广泛的应用。例如，在个性化医疗植入物方面，SLA和FDM技术被广泛应用于制造个性化牙冠、骨骼植入物和关节修复体。在器官制造方面，EBM和SLS技术被用于制造骨骼、牙齿和人工器官。

### 2.2 3D生物打印原理

#### 2.2.1 生物打印过程

3D生物打印过程主要包括以下几个步骤：

1. **建模与设计**：通过计算机辅助设计软件（如CAD）创建器官的三维模型，并根据需要生成切片文件。

2. **生物材料准备**：选择适合的生物材料，并进行预处理，如消毒、混合和调色。

3. **打印头移动与打印**：生物打印头按照切片文件中的信息，逐层沉积生物材料，构建三维结构。

4. **后处理**：打印完成后，进行去支持、脱脂、消毒等后处理步骤，以获得具有生物活性的三维结构。

#### 2.2.2 生物墨水与打印头

生物墨水是3D生物打印的核心材料，通常由生物材料、细胞、生长因子和支架材料组成。生物墨水的性能直接影响打印效果和生物相容性。常见的生物墨水包括：

1. **细胞墨水**：含有细胞的生物墨水，可以用于打印生物组织。

2. **细胞外基质墨水**：含有细胞外基质的生物墨水，可以用于打印组织支架。

3. **生物材料墨水**：含有生物材料（如胶原蛋白、透明质酸等）的生物墨水，可以用于打印复杂结构的器官。

打印头是3D生物打印设备的关键部件，负责将生物墨水逐层沉积并构建三维结构。常见的打印头类型包括：

1. **垂直移动打印头**：沿垂直方向移动，用于逐层构建三维结构。

2. **旋转打印头**：在打印过程中旋转，用于精确控制生物墨水的沉积位置和形状。

3. **多喷嘴打印头**：具有多个喷嘴，可以同时打印多种生物墨水，提高打印效率和精度。

### 2.3 相关材料与设备

#### 2.3.1 生物材料特性

生物材料是3D生物打印技术的核心，其性能直接影响打印效果和生物相容性。常见的生物材料包括：

1. **生物降解材料**：如聚乳酸（PLA）、聚羟基脂肪酸（PHA）等，可用于制造可生物降解的组织支架。

2. **生物活性材料**：如羟基磷灰石（HA）、生物玻璃（BG）等，具有生物相容性和骨传导性，可用于制造骨组织支架。

3. **生物响应材料**：如温度响应材料、pH响应材料等，可以用于制造具有特定响应功能的器官。

#### 2.3.2 设备技术与创新

3D生物打印设备是实施3D生物打印的关键，其性能和精度直接影响打印效果。常见的3D生物打印设备包括：

1. **光固化3D打印机**：如立体光刻（SLA）打印机，适用于制造高精度、复杂形状的器官支架。

2. **熔融沉积3D打印机**：如熔融沉积建模（FDM）打印机，适用于制造大尺寸、结构简单的器官模型。

3. **电子束熔融3D打印机**：如电子束熔融（EBM）打印机，适用于制造高强度、耐高温的生物材料。

近年来，随着技术的不断发展，3D生物打印设备也在不断创新。例如，多喷嘴打印头、多层打印技术、实时成像技术等，都为3D生物打印技术的进步提供了新的可能性。此外，一些新的打印材料（如生物墨水、纳米材料等）的研究和应用，也为3D生物打印技术的发展带来了新的机遇。

## 第三部分: 器官移植的基础知识

### 3.1 器官移植概述

#### 3.1.1 器官移植的分类

器官移植根据移植器官的不同可以分为以下几类：

1. **心脏移植**：心脏移植是心脏疾病患者的主要治疗手段，适用于终末期心脏疾病患者。

2. **肝脏移植**：肝脏移植是治疗终末期肝病、肝脏肿瘤和先天性肝脏疾病的重要手段。

3. **肾脏移植**：肾脏移植是治疗终末期肾病的主要手段，可以有效改善患者的肾功能和生活质量。

4. **肺脏移植**：肺脏移植适用于严重的肺气肿、肺纤维化和先天性肺疾病。

5. **胰腺移植**：胰腺移植可以用于治疗1型糖尿病和胰腺疾病。

6. **小肠移植**：小肠移植适用于短肠综合症、先天性肠道异常和严重肠道疾病。

#### 3.1.2 器官移植的重要性

器官移植对于治疗某些致命性疾病和改善患者生活质量具有重要作用。器官移植可以恢复器官的功能，挽救患者的生命，并提高他们的生活质量。例如，心脏移植可以延长患者的生命并改善心脏功能；肝脏移植可以清除患者的肝硬化并恢复肝功能；肾脏移植可以清除患者的尿毒症并恢复肾功能。

### 3.2 器官移植的技术挑战

尽管器官移植在治疗许多疾病方面取得了显著进展，但仍面临许多技术挑战：

#### 3.2.1 免疫排斥

免疫排斥是器官移植中最常见的并发症之一。患者的免疫系统会识别并攻击移植的器官，导致器官功能受损甚至移植失败。为了防止免疫排斥，移植患者需要长期服用免疫抑制剂，这可能导致感染、癌症等并发症。

#### 3.2.2 器官短缺

全球面临的器官短缺问题日益严重。每年有大量患者因器官衰竭而需要移植，但可供移植的器官远远无法满足需求。器官短缺的原因包括供体数量不足、器官保存技术和运输条件的限制等。

#### 3.2.3 器官保存问题

器官保存是器官移植中的关键环节。目前使用的器官保存液和保存技术仍存在一定的局限性，例如器官在保存过程中可能发生的细胞损伤和功能丧失。因此，开发更有效的器官保存技术是当前研究的重要方向。

### 3.3 器官移植的现状与未来

#### 3.3.1 当前移植手术技术

随着医学技术的进步，器官移植手术技术不断发展和完善。现代器官移植手术包括以下几个关键步骤：

1. **术前评估**：评估患者的身体状况、器官功能和潜在并发症，以确保患者适合进行移植手术。

2. **供体器官获取**：从捐献者身上获取适合的器官，并进行适当的处理和保存。

3. **器官移植手术**：根据移植器官的不同，进行相应的手术操作，包括器官的切除、植入和连接血管和神经。

4. **术后管理**：对移植患者进行术后监测和药物治疗，以防止免疫排斥和其他并发症。

#### 3.3.2 未来发展趋势

随着科技的发展，器官移植领域正在朝着更高效、更安全和更个性化的方向发展：

1. **个性化移植**：通过基因组学和生物信息学分析，为患者提供更精确的移植方案，降低免疫排斥风险。

2. **生物打印器官**：3D生物打印技术有望实现个性化器官制造，解决器官短缺问题，并提高移植成功率。

3. **生物反应性材料**：开发具有生物反应性的材料，用于制造能够与人体组织相互作用的植入物和器官。

4. **细胞疗法**：利用干细胞和再生医学技术，修复和再生受损的器官组织，减少对移植的依赖。

5. **远程手术**：借助远程手术技术和虚拟现实（VR）技术，实现跨区域的器官移植手术，提高手术的可达性和效率。

总之，器官移植领域的发展前景广阔，通过技术创新和跨学科合作，有望解决当前面临的挑战，为患者带来更多的治疗选择和希望。

### 4.2 核心算法原理讲解

在3D生物打印技术的实际应用中，算法原理是至关重要的。以下将详细讲解用于3D生物打印技术中的核心算法，包括数据处理算法、图像处理算法和优化算法。

#### 4.2.1 数据处理算法

数据处理算法在3D生物打印技术中用于处理和分析三维模型数据。这些算法的主要任务是生成可用的切片文件，以便3D打印机能够准确地构建出三维结构。

1. **三角剖分算法（Triangulation）**

   三角剖分是将三维模型划分为三角面的过程。三角剖分算法确保每个三角面都是平面三角形，从而简化了后续的打印过程。常见的三角剖分算法包括：

   - **Delaunay三角剖分**：通过最小化三角形的边长和角度来优化剖分结果。
   - **Voronoi图三角剖分**：根据点的邻近关系来构建三角剖分，具有较好的结构均匀性。

   伪代码示例：
   ```
   function DelaunayTriangulation(points):
       construct Voronoi diagram from points
       for each Voronoi region:
           compute Delaunay triangulation of the region
       return triangulation
   ```

2. **切片生成算法（Slicing）**

   切片生成是将三维模型沿垂直于打印方向的平面切割成多个二维切片的过程。切片算法需要考虑打印路径、打印速度和层厚等因素。

   伪代码示例：
   ```
   function generateSlices(model, layerHeight):
       slices = []
       currentZ = 0
       while currentZ < model.height:
           slice = []
           for layer in model:
               slice.append(layer[currentZ])
           slices.append(slice)
           currentZ += layerHeight
       return slices
   ```

#### 4.2.2 图像处理算法

图像处理算法在3D生物打印技术中用于处理和分析生物图像数据。这些算法确保打印出的组织结构能够精确地反映生物图像的特征。

1. **图像分割算法（Image Segmentation）**

   图像分割是将图像划分为不同区域的算法。在3D生物打印中，图像分割用于识别和组织不同的生物结构。

   - **阈值分割（Thresholding）**：根据像素值将图像二值化，适用于简单背景和前景区分。
   - **区域生长（Region Growing）**：从种子点开始，根据邻域像素的相似性逐渐扩展区域。

   伪代码示例：

   ```
   function thresholding(image, threshold):
   ```

### 4.3 数学模型和数学公式 & 详细讲解 & 举例说明

在3D生物打印技术的应用中，数学模型和数学公式是理解和分析打印过程的关键。以下将详细讲解几个关键的数学模型和公式，包括生物材料力学模型、细胞外基质模型和打印精度模型。

#### 4.3.1 生物材料力学模型

生物材料力学模型用于描述生物材料在受到外力作用时的变形和强度。常见的生物材料力学模型包括弹性模型和塑性模型。

1. **弹性模型**

   弹性模型描述了生物材料在应力小于屈服极限时的变形行为。胡克定律是弹性模型的基础，其公式如下：
   $$
   \sigma = E \cdot \epsilon
   $$
   其中，$\sigma$ 是应力，$E$ 是弹性模量，$\epsilon$ 是应变。

   举例说明：假设一种生物材料的弹性模量$E$为10 GPa，当施加10 MPa的应力时，其应变为：
   $$
   \epsilon = \frac{\sigma}{E} = \frac{10 \text{ MPa}}{10 \text{ GPa}} = 0.001
   $$
   这意味着材料在应力作用下将产生0.1%的应变。

2. **塑性模型**

   塑性模型描述了生物材料在应力大于屈服极限时的变形行为。一种常见的塑性模型是Drucker-Prager模型，其公式如下：
   $$
   \sigma = \sigma_0 + \frac{3}{2J_2} \cdot p
   $$
   其中，$\sigma$ 是应力，$\sigma_0$ 是屈服应力，$p$ 是压力，$J_2$ 是Jaumann率。

   举例说明：假设一种生物材料的屈服应力$\sigma_0$为20 MPa，压力$p$为10 MPa，则其应力为：
   $$
   \sigma = 20 \text{ MPa} + \frac{3}{2} \cdot 10 \text{ MPa} = 35 \text{ MPa}
   $$
   这表明材料在压力作用下将达到塑性变形。

#### 4.3.2 细胞外基质模型

细胞外基质（ECM）是生物材料的重要组成部分，其力学特性对细胞的附着、增殖和分化至关重要。常见的ECM模型包括弹性模量和孔隙率模型。

1. **弹性模量模型**

   ECM的弹性模量模型通常基于Gaussian分布，其公式如下：
   $$
   E = \frac{K}{2(1-\nu^2)}
   $$
   其中，$E$ 是弹性模量，$K$ 是Kronecker delta，$\nu$ 是泊松比。

   举例说明：假设一种ECM材料的泊松比为0.5，其弹性模量为5 MPa，则其Kronecker delta为：
   $$
   K = E \cdot (1-\nu^2) = 5 \text{ MPa} \cdot (1-0.5^2) = 3.75 \text{ MPa}
   $$

2. **孔隙率模型**

   ECM的孔隙率模型描述了细胞外基质中的孔隙分布和连通性。常用的孔隙率模型包括Lund模型，其公式如下：
   $$
   \phi = \frac{1}{1 + \exp\left(\frac{\alpha p - \beta}{p}\right)}
   $$
   其中，$\phi$ 是孔隙率，$\alpha$ 和 $\beta$ 是参数，$p$ 是压力。

   举例说明：假设一种ECM材料的孔隙率模型参数为$\alpha = 0.1$，$\beta = 0.05$，在压力$p$为1 MPa时，其孔隙率为：
   $$
   \phi = \frac{1}{1 + \exp\left(\frac{0.1 \cdot 1 - 0.05}{1}\right)} \approx 0.39
   $$
   这表示在1 MPa压力下，ECM材料的孔隙率约为39%。

#### 4.3.3 打印精度模型

打印精度是3D生物打印技术的重要指标，其模型用于描述打印过程中的精度和误差。常见的打印精度模型包括层厚模型和振动模型。

1. **层厚模型**

   层厚模型描述了打印过程中的层厚变化对打印精度的影响。其公式如下：
   $$
   h = h_0 \cdot \left(1 - \frac{\lambda}{2}\right)^n
   $$
   其中，$h$ 是实际层厚，$h_0$ 是设计层厚，$\lambda$ 是层间间隙，$n$ 是打印层数。

   举例说明：假设设计层厚为0.2 mm，层间间隙为0.05 mm，打印层数为10层，则实际层厚为：
   $$
   h = 0.2 \text{ mm} \cdot \left(1 - \frac{0.05}{2}\right)^{10} \approx 0.127 \text{ mm}
   $$

2. **振动模型**

   振动模型描述了打印头振动对打印精度的影响。其公式如下：
   $$
   \delta = A \cdot \sin(\omega t + \phi)
   $$
   其中，$\delta$ 是振动幅度，$A$ 是振幅，$\omega$ 是角频率，$t$ 是时间，$\phi$ 是相位。

   举例说明：假设打印头振动的振幅为1 mm，角频率为100 rad/s，则在0.1秒时的振动幅度为：
   $$
   \delta = 1 \text{ mm} \cdot \sin(100 \text{ rad/s} \cdot 0.1 \text{ s} + \phi) \approx 0.84 \text{ mm}
   $$

通过这些数学模型和公式的详细讲解，我们可以更好地理解和分析3D生物打印技术的原理和应用，为打印出高质量、生物相容性强的生物组织和器官提供理论基础。

#### 8.1.2 技术分类与应用

3D生物打印技术根据生物材料的不同和处理方法的不同，可以分为多种类型。常见的3D生物打印技术包括：

1. **立体光刻（SLA）**：立体光刻技术使用光敏树脂材料，通过逐层固化来构建三维结构。SLA技术适用于制造高精度、复杂形状的器官支架。

2. **熔融沉积建模（FDM）**：熔融沉积建模技术利用热塑性材料，通过逐层堆积来构建三维结构。FDM技术适用于制造大尺寸、结构简单的器官模型。

3. **电子束熔融（EBM）**：电子束熔融技术利用电子束熔化金属粉末，通过逐层堆积来构建三维结构。EBM技术适用于制造高强度、耐高温的生物材料。

4. **选择性激光烧结（SLS）**：选择性激光烧结技术利用激光烧结粉末材料，通过逐层堆积来构建三维结构。SLS技术适用于制造复杂形状、高强度和高耐磨性的器官支架。

### 8.2 3D生物打印原理

#### 8.2.1 生物打印过程

3D生物打印过程主要包括以下几个步骤：

### 10.2 核心算法原理讲解

#### 10.2.1 数据处理算法

数据处理算法在3D生物打印技术中用于处理和分析三维模型数据。这些算法的主要任务是生成可用的切片文件，以便3D打印机能够准确地构建出三维结构。

1. **三角剖分算法（Triangulation）**

   三角剖分是将三维模型划分为三角面的过程。三角剖分算法确保每个三角面都是平面三角形，从而简化了后续的打印过程。常见的三角剖分算法包括：

   - **Delaunay三角剖分**：通过最小化三角形的边长和角度来优化剖分结果。
   - **Voronoi图三角剖分**：根据点的邻近关系来构建三角剖分，具有较好的结构均匀性。

   伪代码示例：
   ```
   function DelaunayTriangulation(points):
       construct Voronoi diagram from points
       for each Voronoi region:
           compute Delaunay triangulation of the region
       return triangulation
   ```

2. **切片生成算法（Slicing）**

   切片生成是将三维模型沿垂直于打印方向的平面切割成多个二维切片的过程。切片算法需要考虑打印路径、打印速度和层厚等因素。

   伪代码示例：
   ```
   function generateSlices(model, layerHeight):
       slices = []
       currentZ = 0
       while currentZ < model.height:
           slice = []
           for layer in model:
               slice.append(layer[currentZ])
           slices.append(slice)
           currentZ += layerHeight
       return slices
   ```

图像处理算法在3D生物打印技术中用于处理和分析生物图像数据。这些算法确保打印出的组织结构能够精确地反映生物图像的特征。

1. **图像分割算法（Image Segmentation）**

   - **阈值分割（Thresholding）**：根据像素值将图像二值化，适用于简单背景和前景区分。
   - **区域生长（Region Growing）**：从种子点开始，根据邻域像素的相似性逐渐扩展区域。

   伪代码示例：

   - **边缘检测（Edge Detection）**：检测图像中的边缘信息，提高图像的细节。

### 10.3 数学模型和数学公式 & 详细讲解 & 举例说明

在3D生物打印技术的应用中，数学模型和数学公式是理解和分析打印过程的关键。以下将详细讲解几个关键的数学模型和公式，包括生物材料力学模型、细胞外基质模型和打印精度模型。

#### 10.3.1 生物材料力学模型

生物材料力学模型用于描述生物材料在受到外力作用时的变形和强度。常见的生物材料力学模型包括弹性模型和塑性模型。

1. **弹性模型**

   弹性模型描述了生物材料在应力小于屈服极限时的变形行为。胡克定律是弹性模型的基础，其公式如下：
   $$
   \sigma = E \cdot \epsilon
   $$
   其中，$\sigma$ 是应力，$E$ 是弹性模量，$\epsilon$ 是应变。

   举例说明：假设一种生物材料的弹性模量$E$为10 GPa，当施加10 MPa的应力时，其应变为：
   $$
   \epsilon = \frac{\sigma}{E} = \frac{10 \text{ MPa}}{10 \text{ GPa}} = 0.001
   $$
   这意味着材料在应力作用下将产生0.1%的应变。

2. **塑性模型**

   塑性模型描述了生物材料在应力大于屈服极限时的变形行为。一种常见的塑性模型是Drucker-Prager模型，其公式如下：
   $$
   \sigma = \sigma_0 + \frac{3}{2J_2} \cdot p
   $$
   其中，$\sigma$ 是应力，$\sigma_0$ 是屈服应力，$p$ 是压力，$J_2$ 是Jaumann率。

   举例说明：假设一种生物材料的屈服应力$\sigma_0$为20 MPa，压力$p$为10 MPa，则其应力为：
   $$
   \sigma = 20 \text{ MPa} + \frac{3}{2} \cdot 10 \text{ MPa} = 35 \text{ MPa}
   $$
   这表明材料在压力作用下将达到塑性变形。

#### 10.3.2 细胞外基质模型

细胞外基质（ECM）是生物材料的重要组成部分，其力学特性对细胞的附着、增殖和分化至关重要。常见的ECM模型包括弹性模量和孔隙率模型。

1. **弹性模量模型**

   ECM的弹性模量模型通常基于Gaussian分布，其公式如下：
   $$
   E = \frac{K}{2(1-\nu^2)}
   $$
   其中，$E$ 是弹性模量，$K$ 是Kronecker delta，$\nu$ 是泊松比。

   举例说明：假设一种ECM材料的泊松比为0.5，其弹性模量为5 MPa，则其Kronecker delta为：
   $$
   K = E \cdot (1-\nu^2) = 5 \text{ MPa} \cdot (1-0.5^2) = 3.75 \text{ MPa}
   $$

2. **孔隙率模型**

   ECM的孔隙率模型描述了细胞外基质中的孔隙分布和连通性。常用的孔隙率模型包括Lund模型，其公式如下：
   $$
   \phi = \frac{1}{1 + \exp\left(\frac{\alpha p - \beta}{p}\right)}
   $$
   其中，$\phi$ 是孔隙率，$\alpha$ 和 $\beta$ 是参数，$p$ 是压力。

   举例说明：假设一种ECM材料的孔隙率模型参数为$\alpha = 0.1$，$\beta = 0.05$，在压力$p$为1 MPa时，其孔隙率为：
   $$
   \phi = \frac{1}{1 + \exp\left(\frac{0.1 \cdot 1 - 0.05}{1}\right)} \approx 0.39
   $$
   这表示在1 MPa压力下，ECM材料的孔隙率约为39%。

#### 10.3.3 打印精度模型

打印精度是3D生物打印技术的重要指标，其模型用于描述打印过程中的精度和误差。常见的打印精度模型包括层厚模型和振动模型。

1. **层厚模型**

   层厚模型描述了打印过程中的层厚变化对打印精度的影响。其公式如下：
   $$
   h = h_0 \cdot \left(1 - \frac{\lambda}{2}\right)^n
   $$
   其中，$h$ 是实际层厚，$h_0$ 是设计层厚，$\lambda$ 是层间间隙，$n$ 是打印层数。

   举例说明：假设设计层厚为0.2 mm，层间间隙为0.05 mm，打印层数为10层，则实际层厚为：
   $$
   h = 0.2 \text{ mm} \cdot \left(1 - \frac{0.05}{2}\right)^{10} \approx 0.127 \text{ mm}
   $$

2. **振动模型**

   振动模型描述了打印头振动对打印精度的影响。其公式如下：
   $$
   \delta = A \cdot \sin(\omega t + \phi)
   $$
   其中，$\delta$ 是振动幅度，$A$ 是振幅，$\omega$ 是角频率，$t$ 是时间，$\phi$ 是相位。

   举例说明：假设打印头振动的振幅为1 mm，角频率为100 rad/s，则在0.1秒时的振动幅度为：
   $$
   \delta = 1 \text{ mm} \cdot \sin(100 \text{ rad/s} \cdot 0.1 \text{ s} + \phi) \approx 0.84 \text{ mm}
   $$

通过这些数学模型和公式的详细讲解，我们可以更好地理解和分析3D生物打印技术的原理和应用，为打印出高质量、生物相容性强的生物组织和器官提供理论基础。

#### 10.4.2 源代码实现

以下是一个简单的3D生物打印项目的源代码实现，包括生物墨水的准备、打印参数的设置和打印过程的执行：

```python
# 导入必要的库
import numpy as np
from bioprinting_python import BioPrinter
from bioprinting_python import BioMaterial
from bioprinting_python import PrintConfig

# 设置打印配置
print_config = PrintConfig(
    layer_height=0.2,  # 层高
    print_speed=50,    # 打印速度
    temperature=200,   # 打印温度
    bed_temperature=60,  # 床温
)

# 准备生物墨水
bio_material = BioMaterial(name="Collagen", 
                           material_type="Collagen",
                           viscosity=1e6, 
                           elasticity=1e5, 
                           density=1.1)

# 初始化3D生物打印机
bio_printer = BioPrinter(bio_material, print_config)

# 设置打印路径
print_path = [
    (0, 0, 0),  # 初始位置
    (20, 0, 2),  # 第一层
    (20, 10, 4),  # 第二层
    (0, 10, 6)  # 第三层
]

# 执行打印过程
for point in print_path:
    bio_printer.extrude(point)

# 完成打印
bio_printer.finish()
```
