3. **透明性**：区块链上的所有交易信息都是公开透明的，参与者可以实时查看和验证。

## 2.2 区块链分类

区块链根据其应用范围和参与者的不同，可以分为以下几类：

## 2.3.1 哈希算法

哈希算法是区块链技术的基础，用于确保数据的完整性和唯一性。哈希算法的基本原理是将任意长度的输入数据映射为固定长度的输出值，输出值被称为哈希值。哈希值具有以下特点：

1. **唯一性**：对于任意给定的输入数据，哈希算法生成的哈希值是唯一的。
2. **不可逆性**：哈希算法是不可逆的，无法通过哈希值反推出原始数据。
3. **固定长度**：哈希值长度固定，不会因为输入数据的长度变化而变化。

常见的哈希算法包括：

1. **MD5**：MD5算法生成一个128位的哈希值，适用于对数据进行快速哈希处理。
2. **SHA-1**：SHA-1算法生成一个160位的哈希值，是MD5的增强版本。
3. **SHA-256**：SHA-256算法生成一个256位的哈希值，是目前最常用的哈希算法。

## 2.3.2 链式数据结构

区块链采用链式数据结构，每个区块都包含一个指向前一个区块的哈希值，形成了一个连续的数据链条。这种结构使得区块链具有以下特点：

1. **不可篡改性**：由于每个区块都包含前一个区块的哈希值，如果试图篡改一个区块的数据，就会导致链式反应，使得整个区块链的数据不一致。
2. **可追溯性**：区块链上的每个区块都包含了生成它的区块的哈希值，可以通过哈希值追溯到区块链的起始点。
3. **安全性**：链式数据结构保证了区块链的数据安全性，任何节点都无法单独篡改区块链上的数据。

## 2.3.3 智能合约

智能合约是区块链上的自动执行合约，它通过编程语言实现，一旦触发条件就会自动执行。智能合约的基本原理包括：

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

struct License {
    address creator;
    address licensee;
    uint256 contentId;
    string contentTitle;
    string contentDescription;
    bool isRevoked;
    mapping(address => bool) authorizedActions;
}

mapping(uint256 => License) public licenses;

event LicenseCreated(
    uint256 contentId,
    address creator,
    address licensee,
    string contentTitle,
    string contentDescription
);

event LicenseRevoked(uint256 contentId, address licensee);

function createLicense(
    uint256 _contentId,
    address _licensee,
    string memory _contentTitle,
    string memory _contentDescription
) public {
    require(!licenses[_contentId].isRevoked, "License already exists or is revoked");
    licenses[_contentId] = License({
        creator: msg.sender,
        licensee: _licensee,
        contentId: _contentId,
        contentTitle: _contentTitle,
        contentDescription: _contentDescription,
        isRevoked: false,
        authorizedActions: mapping(address => bool)(true)
    });
    emit LicenseCreated(_contentId, msg.sender, _licensee, _contentTitle, _contentDescription);
}

function revokeLicense(uint256 _contentId) public {
    require(licenses[_contentId].creator == msg.sender, "Only the creator can revoke the license");
    licenses[_contentId].isRevoked = true;
    emit LicenseRevoked(_contentId, msg.sender);
}
```

2. **撤销版权许可**：`revokeLicense`函数用于撤销版权许可，将版权信息从区块链上删除。
