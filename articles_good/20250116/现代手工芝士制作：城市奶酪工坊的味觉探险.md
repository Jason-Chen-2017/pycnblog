## 第1章：探索城市奶酪工坊的魅力

### 1.1 芝士的历史与演变

芝士，又称奶酪，是一种通过发酵、凝乳和成熟等工艺制成的乳制品。它的历史可以追溯到数千年前，起源地主要在欧洲和中东地区。随着时间的推移，芝士的种类和制作工艺不断丰富和发展，逐渐形成了独特的饮食文化。

#### 1.1.1 芝士的起源与发展

据考古学家研究，最早的芝士制作工艺可以追溯到公元前2000年左右的美索不达米亚。当时的农民在储存牛奶时，无意中发现牛奶在经过发酵后，形成了类似芝士的凝固体。这种意外发现激发了人们对芝士的探索和制作。

随着时间的推移，芝士的制作工艺逐渐成熟，不同地区和国家形成了各自的特色芝士。例如，意大利的帕尔马干酪、法国的卡芒贝尔芝士、英国的切达芝士等，都享誉世界。

#### 1.1.2 西方芝士与东方芝士的区别

西方芝士通常以牛奶或羊奶为主要原料，通过不同的发酵过程和成熟时间，形成了多样化的口感和风味。而东方芝士则以水牛奶、山羊奶等为主要原料，具有独特的酸味和口感。

此外，西方芝士的制作工艺更为成熟和复杂，通常需要经过多次发酵、压榨和成熟过程。而东方芝士的制作工艺相对简单，但同样具有丰富的种类和独特的风味。

#### 1.1.3 芝士在饮食文化中的地位

芝士作为一种重要的乳制品，在全球范围内的饮食文化中占有重要地位。无论是在西方的早餐、午餐还是晚餐，芝士都是常见的食材之一。它既可以单独食用，也可以搭配面包、水果、酒水等，成为各种美食的组成部分。

此外，芝士在烘焙、烹饪等领域也有着广泛的应用，成为许多美食爱好者的必备食材。芝士的独特风味和丰富的营养价值，使其在全球饮食文化中占据了一席之地。

### 1.2 现代手工芝士制作的基础知识

现代手工芝士制作虽然继承了传统工艺，但在制作技术和设备方面有了很大的改进和创新。下面我们来了解一些现代手工芝士制作的基础知识。

#### 1.2.1 手工芝士的基本原料

手工芝士的主要原料是牛奶。牛奶的质量直接影响芝士的口感和品质。因此，选择优质的牛奶是手工芝士制作的第一步。

此外，还需要一些辅助原料，如凝乳酶、盐、乳酸菌等。这些原料在芝士发酵和凝乳过程中起着关键作用。

#### 1.2.2 芝士制作的主要工艺流程

现代手工芝士制作主要包括以下几个步骤：

1. **原料准备**：选择新鲜、优质的牛奶，并进行初步处理，如预热和消毒。
2. **添加凝乳酶**：将凝乳酶添加到牛奶中，使牛奶中的蛋白质凝结，形成凝乳和乳清。
3. **切割凝乳**：将凝乳切割成小块，以便更好地排出乳清。
4. **压榨凝乳**：通过压榨，将凝乳中的乳清排出，使其变得更加紧实。
5. **成型和成熟**：将压榨后的凝乳放入模具中，进行成型和熟成。不同类型的芝士，其熟成时间也有所不同。

#### 1.2.3 芝士发酵过程中微生物的作用

芝士的发酵过程主要依赖于微生物的作用，特别是乳酸菌和酵母菌。乳酸菌在发酵过程中产生乳酸，使芝士具有独特的酸味和风味。酵母菌则有助于芝士的膨胀和形成独特的口感。

不同类型的芝士，其发酵过程和微生物种类也有所不同。例如，蓝纹芝士的发酵过程中，主要依赖于青霉菌的发酵作用。

## 第2章：制作基础芝士

### 2.1 奶源的选择与处理

在制作基础芝士的过程中，奶源的选择和处理是至关重要的一步。优质的奶源不仅直接影响芝士的口感和品质，还会影响到后续的发酵和成熟过程。以下我们来详细探讨奶源的选择与处理方法。

#### 2.1.1 牛奶的选择标准

选择合适的牛奶是制作优质芝士的基础。以下是选择牛奶时需要考虑的一些关键标准：

1. **新鲜度**：牛奶应尽可能新鲜，以确保其营养丰富和品质优良。新鲜的牛奶通常具有浓郁的乳香味，无异味。
2. **品种**：不同品种的牛奶在脂肪含量、蛋白质含量等方面有所差异，从而影响芝士的口感和风味。一般来说，全脂牛奶和部分脱脂牛奶适用于制作大多数类型的芝士，而低脂牛奶则适用于制作低脂芝士。
3. **成分**：牛奶的成分，如蛋白质、脂肪、乳糖等，也会影响芝士的品质。蛋白质含量较高的牛奶有利于芝士的凝结，而脂肪含量较高的牛奶则有助于增加芝士的香味和口感。
4. **来源**：选择来自健康、无污染的牧场或养殖场的牛奶，以确保其安全性和质量。

#### 2.1.2 奶源的清洁处理

在将牛奶用于芝士制作前，需要进行一系列的清洁处理，以确保牛奶的品质和卫生。以下是常见的清洁处理步骤：

1. **过滤**：使用细孔过滤器或纱布，将牛奶中的杂质、尘埃和其他固体颗粒过滤掉，以防止这些杂质影响芝士的凝结和口感。
2. **预热**：将过滤后的牛奶预热至约37-38℃，以创造一个适合微生物生长的环境。过高的温度会杀死微生物，而温度过低则会影响发酵过程。
3. **消毒**：为了防止牛奶在发酵过程中受到污染，可以采用巴氏消毒法或其他消毒方法，将牛奶中的有害微生物杀死。巴氏消毒法通常在62-65℃下加热30秒至1分钟，可以有效地消灭大多数有害微生物，同时保留牛奶的营养成分和风味。

#### 2.1.3 奶的加热处理

在预热牛奶后，接下来需要进行加热处理，以确保牛奶达到适宜的温度和状态。以下是常见的加热处理方法：

1. **恒温水浴加热**：将牛奶置于恒温水浴锅中，缓慢加热至预定温度。这种方法可以避免牛奶因加热过快而产生泡沫或蛋白质凝结。
2. **蒸汽加热**：使用蒸汽加热设备，如蒸汽锅或蒸汽加热器，将牛奶加热至预定温度。这种方法加热迅速且均匀，适用于大规模生产。
3. **电热板加热**：将牛奶放在电热板上，通过电热传导加热至预定温度。这种方法加热较为缓慢，但操作简单且易于控制。

在加热过程中，需要注意以下几点：

1. **温度控制**：确保牛奶的温度均匀且稳定，避免温度波动过大，影响发酵过程和芝士品质。
2. **时间控制**：加热时间不宜过长，以免牛奶中的营养成分和风味物质受到破坏。
3. **防止溢出**：加热过程中，牛奶可能会产生泡沫或膨胀，需要特别注意防止溢出，以免造成浪费或污染。

通过以上步骤，我们可以选择和处理出适合制作优质芝士的奶源，为后续的芝士制作过程打下坚实基础。

### 2.2 酵母和乳酸菌的使用

在手工芝士制作过程中，酵母和乳酸菌起着至关重要的作用。它们不仅参与发酵过程，还直接影响芝士的口感、风味和品质。下面我们来详细探讨酵母和乳酸菌的选择、使用方法及其在发酵过程中的作用。

#### 2.2.1 酵母的选择与使用

酵母是一种微生物，能够将牛奶中的糖分转化为二氧化碳和酒精，从而促进芝士的发酵和膨胀。以下是选择和使用酵母时需要考虑的一些要点：

1. **种类**：市场上常见的酵母有干酵母和鲜酵母两种。干酵母保存时间长，使用方便，适合家庭和小规模制作。鲜酵母则口感更佳，但保存时间较短，适用于专业芝士工坊。

2. **活性**：选择活性良好的酵母至关重要。活性低的酵母发酵效果不佳，可能导致芝士口感不佳或发酵不充分。

3. **用量**：酵母的用量通常根据牛奶的量和发酵要求来确定。一般来说，每升牛奶添加5-10克的酵母即可。过多的酵母可能导致发酵过快，影响芝士的口感。

4. **添加时机**：在加热后的牛奶冷却到约38-40℃时，加入酵母。过高的温度会杀死酵母，而过低则影响其活性。同时，避免在高温下长时间搅拌，以免杀死或破坏酵母。

#### 2.2.2 乳酸菌的选择与培养

乳酸菌在芝士发酵过程中起到重要作用，能够产生乳酸，使芝士具有独特的酸味和风味。以下是选择和培养乳酸菌时需要考虑的一些要点：

1. **种类**：乳酸菌有多种类型，如保加利亚乳酸菌、嗜酸乳杆菌、乳酸链球菌等。不同种类的乳酸菌产生的风味和口感有所不同。例如，保加利亚乳酸菌和嗜酸乳杆菌常用于制作切达芝士，而乳酸链球菌则适用于制作蓝纹芝士。

2. **纯度**：选择纯度高的乳酸菌粉，以确保发酵过程的稳定性和一致性。纯度低的乳酸菌粉可能含有其他微生物，影响发酵效果。

3. **培养**：乳酸菌的培养通常在37-40℃的条件下进行。首先，将乳酸菌粉溶于少量温水中，然后加入牛奶中。培养过程中，需要保持适当的温度和湿度，以促进乳酸菌的生长和繁殖。

4. **添加时机**：与酵母相似，乳酸菌的最佳添加时机是在牛奶冷却到38-40℃时。此时，牛奶中的温度和酸度最适合乳酸菌的生长。

#### 2.2.3 酵母和乳酸菌的协同作用

酵母和乳酸菌在芝士发酵过程中相互协同，共同促进发酵过程。以下是它们在发酵过程中的协同作用：

1. **产生气体**：酵母在发酵过程中产生二氧化碳，使芝士膨胀，形成松软的质地。

2. **产生酸味**：乳酸菌在发酵过程中产生乳酸，使芝士具有独特的酸味和风味。

3. **抑制有害微生物**：乳酸菌产生的乳酸和其他抑菌物质，有助于抑制有害微生物的生长，保持芝士的卫生和安全。

4. **改善口感**：酵母和乳酸菌共同作用，可以改善芝士的口感，使其更加丰富和细腻。

通过合理选择和使用酵母和乳酸菌，我们可以确保芝士发酵过程的顺利进行，从而制作出口感和风味俱佳的手工芝士。

### 2.3 芝士凝乳的形成与切割

在手工芝士制作过程中，凝乳的形成和切割是关键步骤，直接影响芝士的质地和口感。以下是凝乳的形成过程、切割技巧以及相关注意事项。

#### 2.3.1 凝乳酶的作用与添加

凝乳酶是一种蛋白质分解酶，能够将牛奶中的乳清蛋白分解，使牛奶中的蛋白质凝结形成凝乳。凝乳酶的添加是芝士制作过程中的关键步骤。

1. **作用机制**：凝乳酶作用于牛奶中的乳清蛋白，将其分解成较小的蛋白质片段，形成凝乳和乳清。凝乳是芝士的主要成分，具有紧实的质地和独特的口感。

2. **添加方法**：在加热后的牛奶冷却到约43-44℃时，加入适量的凝乳酶。通常每升牛奶添加10-20毫升的凝乳酶。添加后，需要搅拌均匀，确保凝乳酶均匀分布。

3. **注意事项**：凝乳酶的添加量和温度对凝乳的形成至关重要。温度过低或过高都可能导致凝乳失败或质地不佳。因此，需要严格控制温度和凝乳酶的用量。

#### 2.3.2 芝士凝乳的形成过程

在凝乳酶的作用下，牛奶中的蛋白质开始凝结，形成凝胶状的凝乳。以下是凝乳形成的过程：

1. **凝结开始**：凝乳酶作用于牛奶中的乳清蛋白，使其开始凝结，形成微小的凝胶颗粒。

2. **凝胶网络形成**：随着凝结过程的进行，凝胶颗粒逐渐增多，形成三维的凝胶网络结构。这种网络结构将牛奶中的水分和蛋白质牢固地结合在一起，形成具有弹性和韧性的凝乳。

3. **乳清分离**：在凝乳形成过程中，乳清开始从牛奶中分离出来。乳清是含有大量水分和少量蛋白质的液体，其含量和性质直接影响芝士的质地和口感。

4. **成熟**：凝乳形成后，需要经过一段时间的成熟过程。在这段时间里，凝乳酶继续作用，使凝胶网络更加紧密和稳定，同时乳清中的水分逐渐被挤出。

#### 2.3.3 芝士的切割技巧

在凝乳形成并成熟后，需要对其进行切割。切割的目的是增加凝乳的表面积，有利于乳清的排出，从而改善芝士的质地和口感。以下是切割技巧：

1. **切割时机**：切割应在凝乳成熟后进行，一般在乳清停止流动后进行。这时，凝乳的质地较为柔软，更容易切割。

2. **切割工具**：切割工具通常使用长刀或专用芝士切割刀。切割刀的锋利程度对切割效果有很大影响，需要定期磨刃。

3. **切割方法**：首先，将凝乳切成小块，然后逐层向下切割。在切割过程中，要确保切割动作平稳、均匀，避免用力过猛或切割不均，以免破坏凝胶网络。

4. **注意事项**：切割时，应避免切割刀直接接触到凝乳底部，以免污染。同时，要确保切割过程中保持清洁，避免细菌污染。

通过以上步骤，我们可以成功地形成和切割出优质的芝士凝乳，为后续的成型和熟成步骤打下坚实基础。

### 2.4 成型与熟成

在手工芝士制作过程中，成型和熟成是两个关键步骤，直接影响芝士的质地、口感和风味。以下是成型与熟成的过程、环境控制、时间管理以及熟成标志与质量检测。

#### 2.4.1 芝士成型的模具选择

成型是手工芝士制作过程中的第一步，通过模具将凝乳塑造成所需的形状。以下是模具选择的相关要点：

1. **材料**：常用的模具材料有金属、塑料、木材等。金属材料坚固耐用，但需要定期清洁和消毒。塑料模具轻便易清洗，但使用寿命较短。木材模具具有自然纹理，但容易受潮和变形。

2. **形状**：根据芝士的用途和口感需求，选择合适的模具形状。常见的形状有圆形、方形、长条形等。例如，圆形模具适用于制作奶酪球，长条形模具适用于制作条状芝士。

3. **尺寸**：模具的尺寸应根据芝士的重量和体积来选择。一般而言，模具的尺寸应比芝士成品略大，以便于芝士在成型过程中的膨胀。

4. **孔洞**：部分模具具有孔洞设计，以便在成型过程中排出多余的水分。孔洞的大小和数量应适中，以免影响芝士的成型效果。

#### 2.4.2 芝士熟成的环境与时间

熟成是芝士制作过程中最重要的环节之一，直接影响芝士的质地、口感和风味。以下是熟成环境与时间的要点：

1. **温度**：芝士的熟成温度通常在12-18℃之间。过高的温度可能导致芝士成熟过快，影响风味；过低的温度则可能导致芝士成熟过慢，延长制作周期。

2. **湿度**：芝士的熟成湿度通常在80-90%之间。较高的湿度有助于芝士的风味发展和质地改善。然而，过高的湿度可能导致芝士发霉或变质。

3. **通风**：良好的通风有助于芝士的成熟和风味发展。但过强的风可能导致芝士表面干燥或开裂。

4. **时间**：不同类型的芝士，其熟成时间也有所不同。一般来说，硬质芝士的熟成时间较长，可达数月甚至数年；软质芝士的熟成时间较短，通常为几周至几个月。

#### 2.4.3 芝士熟成的标志与质量检测

在芝士熟成过程中，需要密切关注熟成的进展和质量，以下是一些常见的熟成标志和质量检测方法：

1. **色泽变化**：芝士在熟成过程中，颜色会逐渐加深。硬质芝士通常从白色或浅黄色变为深黄色或棕色；软质芝士则可能保持浅黄色或白色。

2. **质地变化**：芝士的质地会随着熟成时间的延长而变得更加紧实、细腻。硬质芝士的质地逐渐从柔软变为坚硬；软质芝士的质地则可能从柔软变为更加柔软。

3. **气味变化**：芝士在熟成过程中，气味会发生变化。硬质芝士的气味通常较为浓郁，带有明显的奶酪味；软质芝士的气味则较为清新，可能带有水果或花香。

4. **切割试验**：在熟成过程中，可以通过切割试验来检测芝士的质地和结构。硬质芝士在切割时，应感觉较为坚硬且不易断裂；软质芝士则应感觉较为柔软且容易切割。

5. **检测工具**：使用专业的检测工具，如质构仪、测色仪等，可以更精确地评估芝士的质地、颜色和风味。

通过以上方法，我们可以判断芝士是否已经达到理想的熟成状态，从而进行下一步的包装和销售。

### 2.5 常见问题与解决方案

在手工芝士制作过程中，可能会遇到一些常见问题，以下是一些常见问题及其解决方案：

#### 2.5.1 芝士变质的原因

1. **微生物污染**：微生物污染是导致芝士变质的主要原因，可能来自牛奶、工具或环境中的细菌、霉菌等。
2. **温度控制不当**：温度控制不当可能导致芝士发酵不充分或变质。过高的温度可能导致细菌滋生，而过低的温度则影响发酵过程。
3. **湿度控制不当**：湿度过高可能导致芝士发霉，过低则导致表面干燥或开裂。

#### 2.5.2 芝士口感不佳的原因

1. **发酵不足**：发酵不足可能导致芝士的酸味不足，口感淡薄。这可能是由于酵母或乳酸菌添加量不足或活性低。
2. **温度控制不当**：温度控制不当可能导致发酵不充分或过度。发酵温度过低可能导致发酵缓慢，而温度过高则可能导致发酵过快。
3. **水分控制不当**：水分控制不当可能导致芝士质地过于干燥或湿软。水分过多可能导致质地湿软，而水分过少则可能导致质地干燥。

#### 2.5.3 芝士制作中的常见问题及处理

1. **凝乳不凝结**：凝乳不凝结可能是由于凝乳酶添加量不足或温度控制不当。解决方法：增加凝乳酶的添加量，确保牛奶加热到合适的温度。
2. **乳清分离不足**：乳清分离不足可能是由于切割不均匀或压榨不够。解决方法：确保切割均匀，适当增加压榨力度。
3. **变质发霉**：变质发霉可能是由于微生物污染或湿度控制不当。解决方法：加强卫生管理，保持环境清洁和适当的湿度。

通过以上解决方案，我们可以有效地避免和解决手工芝士制作过程中遇到的问题，提高芝士的品质和口感。

#### 3.1.1 切达芝士的历史背景

切达芝士起源于英国切达郡（Cheshire），最初由当地农民在18世纪末开始制作。随着时间的推移，切达芝士的制作工艺逐渐成熟，并传播到美国。美国的切达芝士制作工艺在19世纪进一步发展，形成了具有独特风味的切达芝士。
