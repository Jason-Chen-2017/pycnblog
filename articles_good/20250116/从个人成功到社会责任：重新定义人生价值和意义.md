**系统核心实现源代码：**
下面是一个简单的员工社会责任管理平台的实现示例：

```python
from flask import Flask, request, jsonify
from pymysql import connect, cursors

app = Flask(__name__)

# 数据库连接信息
db_config = {
    'host': 'localhost',
    'user': 'root',
    'password': 'password',
    'database': 'responsibility_db'
}

# 连接到数据库
def connect_db():
    conn = connect(**db_config)
    cursor = conn.cursor(cursors.DictCursor)
    return conn, cursor

@app.route('/create_event', methods=['POST'])
def create_event():
    event_data = request.json
    conn, cursor = connect_db()
    query = "INSERT INTO events (name, type, date) VALUES (%s, %s, %s)"
    cursor.execute(query, (event_data['name'], event_data['type'], event_data['date']))
    conn.commit()
    event_id = cursor.lastrowid
    conn.close()
    return jsonify({'event_id': event_id})

@app.route('/participate_event', methods=['POST'])
def participate_event():
    participation_data = request.json
    conn, cursor = connect_db()
    query = "INSERT INTO participation (employee_id, event_id) VALUES (%s, %s)"
    cursor.execute(query, (participation_data['employee_id'], participation_data['event_id']))
    conn.commit()
    conn.close()
    return jsonify({'status': 'success'})

if __name__ == '__main__':
    app.run(debug=True)
```

这个代码实现了一个简单的Flask Web应用，用于处理创建活动和参与活动的请求。其中，`connect_db`函数用于连接到数据库，`create_event`函数用于创建活动，`participate_event`函数用于记录员工的参与信息。
