#### 4.2.1 电影放映系统

电影放映系统包括影片库管理和放映设备控制两个部分。

1. 影片库管理
- 功能：存储和管理影片信息。
- 实现：使用MongoDB数据库存储影片信息，包括影片名称、上映日期、时长、导演、演员等。
- 代码：

```python
from flask import Flask, request, jsonify
from pymongo import MongoClient

app = Flask(__name__)
client = MongoClient('localhost', 27017)
db = client['movie_db']
collection = db['movies']

@app.route('/movies', methods=['GET', 'POST'])
def movies():
    if request.method == 'GET':
        movies = list(collection.find())
        return jsonify(movies)
    elif request.method == 'POST':
        movie_data = request.json
        result = collection.insert_one(movie_data)
        return jsonify({'_id': str(result.inserted_id), 'status': 'success'})

if __name__ == '__main__':
    app.run(debug=True)
```

2. 放映设备控制
- 功能：控制放映设备的启停、切换、音量调节等。
- 实现：使用HTTP请求与放映设备进行通信，发送控制命令。
- 代码：

```python
import requests

def control_projector(action, projector_ip):
    url = f'http://{projector_ip}/api/{action}'
    response = requests.get(url)
    if response.status_code == 200:
        print(f'Projector {action} successfully.')
    else:
        print(f'Error occurred while {action} projector.')

control_projector('start', '192.168.1.100')
control_projector('stop', '192.168.1.100')
```

```python
import requests

def book_ticket(user_id, movie_id, seat_number):
    url = f'http://payment_api/book_ticket'
    data = {
        'user_id': user_id,
        'movie_id': movie_id,
        'seat_number': seat_number
    }
    response = requests.post(url, data=data)
    if response.status_code == 200:
        print('Ticket booked successfully.')
    else:
        print('Error occurred while booking ticket.')

book_ticket('user_1', 'movie_1', 'A1')
```
