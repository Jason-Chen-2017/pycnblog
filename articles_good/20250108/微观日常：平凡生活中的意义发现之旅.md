```python
# 设置参数
num_days = 365
chances_to_floss = 0.8  # 漏牙的概率

# 初始化变量
days_with_brush = 0
days_with_floss = 0

# 模拟刷牙和漏牙的过程
for day in range(num_days):
    brushed = random.random() < 0.9  # 模拟刷牙的概率
    flossed = random.random() < chances_to_floss  # 模拟漏牙的概率

    if brushed:
        days_with_brush += 1
        print(f"Day {day+1}: Brushed teeth.")

    if flossed:
        days_with_floss += 1
        print(f"Day {day+1}: Flossed teeth.")

# 输出结果
print(f"\nTotal days with brushing: {days_with_brush}")
print(f"Total days with flossing: {days_with_floss}")
```

在这个脚本中，我们模拟了一年的刷牙和漏牙过程。通过随机生成的事件，我们能够观察到刷牙和漏牙的频率，进而分析生活习惯对生活质量的影响。
