#### 1. 心理调适策略

**正念冥想**：正念冥想是一种通过专注于当前瞬间，提高自我意识和心理韧性的方法。它可以帮助我们减少焦虑、提高专注力，从而更好地应对社会压力。以下是正念冥想的步骤：

1. 找一个安静舒适的环境，选择一个舒适的姿势坐下或躺下。
2. 将注意力集中在呼吸上，观察呼吸的进出，不要评判或干扰。
3. 当注意力分散时，轻轻地将其带回到呼吸上。
4. 持续10-20分钟，每天练习。

**情绪管理**：情绪管理是另一个重要的心理调适策略。通过学习情绪管理技巧，我们可以更好地处理负面情绪，避免情绪失控。以下是一些情绪管理的技巧：

- **情绪识别**：学会识别和理解自己的情绪，不要压抑或忽视。
- **情绪表达**：找到健康的方式表达情绪，如与朋友、家人交流，或写日记。
- **情绪调节**：通过深呼吸、放松技巧或运动来调节情绪。
- **情绪重构**：改变对事物的看法和解释，以更积极的方式应对压力。

#### 2. 生活习惯改变

**改善睡眠质量**：良好的睡眠质量是应对社会压力的重要因素。以下是一些改善睡眠质量的建议：

- **规律作息**：每天保持相同的睡眠时间和起床时间。
- **避免咖啡因和酒精**：尤其在睡前几小时内避免摄入咖啡因和酒精。
- **放松身心**：睡前进行放松活动，如阅读、冥想或热水澡。
- **舒适的环境**：保持卧室安静、凉爽、舒适，使用舒适的床垫和枕头。

- **避免拖延**：通过设定具体的截止日期和任务分解，避免拖延。

**工作优先级的设定**：合理设定工作优先级可以帮助我们集中精力，提高工作效率。以下是一些建议：

#### 1. API定义

**基础URL**：所有接口的URL都以`/api`为前缀。

**身份验证**：所有请求必须包含身份验证信息，以JWT（JSON Web Token）的形式传递。

**数据传输格式**：所有请求和响应的数据传输格式均为JSON。

#### 2. 具体接口

**用户管理接口**：
- **注册（POST /api/users/register）**：
  - 功能：用户注册。
  - 参数：
    - `email`（字符串）：用户邮箱。
    - `password`（字符串）：用户密码。
    - `confirmPassword`（字符串）：确认密码。
  - 响应：
    - `message`（字符串）：注册结果消息。

- **登录（POST /api/users/login）**：
  - 功能：用户登录。
  - 参数：
    - `email`（字符串）：用户邮箱。
    - `password`（字符串）：用户密码。
  - 响应：
    - `token`（字符串）：JWT令牌。
    - `expiresIn`（整数）：令牌过期时间。

**日程管理接口**：
- **添加日程（POST /api/schedule/tasks）**：
  - 功能：添加新任务。
  - 参数：
    - `taskId`（字符串）：任务ID。
    - `title`（字符串）：任务标题。
    - `startTime`（日期时间字符串）：任务开始时间。
    - `endTime`（日期时间字符串）：任务结束时间。
    - `priority`（整数）：任务优先级。
  - 响应：
    - `message`（字符串）：添加结果消息。

- **获取日程（GET /api/schedule/tasks）**：
  - 功能：获取用户所有任务。
  - 参数：
    - `pageNumber`（整数）：页码。
    - `pageSize`（整数）：每页数量。
  - 响应：
    - `tasks`（数组）：任务列表。
    - `total`（整数）：任务总数。

**情绪管理接口**：
- **记录情绪（POST /api/emotions）**：

  - 功能：获取用户情绪记录。

- **添加联系人（POST /api/contacts）**：
  - 功能：添加联系人。
  - 参数：
    - `contactId`（字符串）：联系人ID。
    - `name`（字符串）：联系人姓名。
    - `email`（字符串）：联系人邮箱。
  - 响应：
    - `message`（字符串）：添加结果消息。

- **获取联系人列表（GET /api/contacts）**：
  - 功能：获取用户所有联系人。
  - 参数：
    - `pageNumber`（整数）：页码。
    - `pageSize`（整数）：每页数量。
  - 响应：
    - `contacts`（数组）：联系人列表。

**家庭管理接口**：
- **添加家庭日程（POST /api/family/schedule）**：
  - 功能：添加家庭日程。
  - 参数：
    - `scheduleId`（字符串）：日程ID。
    - `title`（字符串）：日程标题。
    - `startTime`（日期时间字符串）：日程开始时间。
    - `endTime`（日期时间字符串）：日程结束时间。
    - `participants`（数组）：参与者列表。
  - 响应：
    - `message`（字符串）：添加结果消息。

- **获取家庭日程（GET /api/family/schedule）**：
  - 功能：获取用户家庭日程。
  - 参数：

6. **显示结果**：

```python
# emotion_analysis.py
import pymongo
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

# 连接MongoDB数据库
client = pymongo.MongoClient("mongodb://localhost:27017/")
db = client["balanced_life_assistant"]
collection = db["emotions"]

# 获取情绪数据
emotions_data = list(collection.find())

# 切分数据集
X = [data['description'] for data in emotions_data]
y = [data['emotion'] for data in emotions_data]

# 特征提取
vectorizer = CountVectorizer()
X_vectorized = vectorizer.fit_transform(X)

# 模型训练
model = MultinomialNB()
model.fit(X_vectorized, y)

# 测试模型
test_data = ["今天心情很好", "我很烦躁"]
X_test = vectorizer.transform(test_data)
predictions = model.predict(X_test)

# 输出预测结果
for data, prediction in zip(test_data, predictions):
    print(f"数据：{data}，预测情绪：{prediction}")
```
