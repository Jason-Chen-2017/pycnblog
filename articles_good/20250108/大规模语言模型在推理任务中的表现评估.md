### 第2章 大规模语言模型概述

#### 2.1 语言模型基础

语言模型是自然语言处理领域中最基础的组件之一，其核心目标是根据输入的文本序列预测下一个词或字符的概率分布。语言模型的基本原理基于概率论和统计学，通过对大规模文本数据进行建模，学习语言中的统计规律和语法结构。

最简单的语言模型是N元语法（N-gram Model），它假设一个词的出现仅与它前面N-1个词有关。例如，二元语法（Bigram Model）只考虑当前词与前一个词的关系。N元语法模型可以通过统计词频或条件概率来生成文本，尽管其简单高效，但在处理长文本时效果有限，容易产生生硬的句子。

为了克服N元语法模型的局限性，研究人员提出了神经网络语言模型（Neural Network Language Model，NNLM）。NNLM通过深度神经网络学习词与词之间的复杂关系，可以捕捉到更长的依赖关系。随着神经网络技术的发展，例如循环神经网络（RNN）、长短期记忆网络（LSTM）和变换器模型（Transformer）等，NNLM的性能得到了显著提升。

#### 2.2 大规模语言模型的构建

大规模语言模型的构建通常分为两个阶段：预训练和微调。

预训练阶段，模型在大规模文本数据上进行训练，学习语言的一般规律。预训练过程中，模型会通过负采样等技术处理高频率词，以降低过拟合的风险。例如，GPT-3通过自回归的方式，在数十万亿个单词上进行训练，从而具备了强大的语言生成能力。

微调阶段，模型在特定任务数据上进行微调，以适应具体的应用场景。微调过程中，模型会通过调整参数，优化特定任务的性能。例如，BERT模型在预训练后，可以通过在特定任务数据上微调，应用于问答系统、文本分类等任务。

#### 2.3 大规模语言模型在推理任务中的应用

大规模语言模型在推理任务中具有广泛的应用。以下是几个典型的应用场景：

1. **机器翻译**：利用大规模语言模型进行机器翻译，可以生成更加流畅和自然的翻译结果。例如，GPT-3在翻译任务中展示了出色的性能，可以处理多种语言的互译。

2. **问答系统**：大规模语言模型可以用于构建问答系统，通过理解用户的问题和上下文，提供准确的答案。例如，BERT在SQuAD数据集上的表现显著优于传统的问答系统。

3. **文本分类**：大规模语言模型可以用于文本分类任务，如新闻分类、情感分析等。通过预训练和微调，模型可以学习到不同类别文本的特征，从而实现高效的分类。

4. **对话系统**：大规模语言模型可以用于构建对话系统，通过自然语言理解和生成，实现与用户的自然交互。例如，ChatGPT可以用于构建聊天机器人，提供24/7的客户服务。

#### 2.4 大规模语言模型的优势与挑战

大规模语言模型在推理任务中展示了显著的优势，主要体现在以下几个方面：

1. **强大的语言理解能力**：通过预训练，大规模语言模型可以学习到丰富的语言知识，从而具备强大的语言理解能力。

2. **灵活的任务适应性**：通过微调，大规模语言模型可以适应不同的任务和数据集，具备良好的任务适应性。

3. **高效的生成能力**：大规模语言模型可以生成高质量的自然语言文本，从而在文本生成任务中表现出色。

然而，大规模语言模型也面临一些挑战：

1. **计算资源需求**：大规模语言模型的训练和推理需要巨大的计算资源，这对硬件设施提出了高要求。

2. **数据隐私问题**：大规模语言模型的预训练过程需要大量文本数据，这些数据可能涉及用户隐私，如何保护用户隐私成为一个重要问题。

3. **模型解释性**：大规模语言模型通常被视为“黑箱”，其决策过程缺乏透明性，如何提高模型的解释性是一个亟待解决的问题。

#### 2.5 大规模语言模型的发展历程

大规模语言模型的发展历程可谓波澜壮阔，从最初的N元语法模型到现代深度学习驱动的Transformer模型，每一个里程碑都在推动NLP领域的进步。

最早的语言模型可以追溯到20世纪50年代，当时研究者们开始尝试使用统计学方法对文本进行建模。N元语法模型于20世纪60年代问世，通过统计相邻词序列的概率分布生成文本，为语言模型的研究奠定了基础。然而，N元语法模型的局限性很快显现，无法捕捉长距离依赖关系。

随着计算能力的提升和深度学习技术的发展，神经网络语言模型逐渐成为主流。循环神经网络（RNN）和长短期记忆网络（LSTM）是这一阶段的代表，通过引入门控机制，RNN和LSTM能够捕捉到更长的依赖关系。然而，这些模型在处理长期依赖问题和并行计算方面仍存在挑战。

21世纪初，Transformer模型的提出标志着大规模语言模型发展的一个重要里程碑。Transformer模型基于自注意力机制，能够并行处理任意长度的序列，克服了RNN和LSTM在处理长序列时的瓶颈。随着BERT模型的发布，预训练-微调（Pre-training and Fine-tuning）策略得到了广泛应用，模型在多个NLP任务上取得了显著突破。

近年来，GPT-3、T5等超大规模语言模型的涌现，进一步提升了语言模型的能力。这些模型通过预训练在数十万亿个单词上，具备了强大的文本生成和理解能力，成为NLP领域的重要工具。

总结来说，大规模语言模型的发展历程是从简单到复杂，从局部到全局，从统计模型到深度学习模型，每一次突破都推动了NLP领域的进步。在接下来的章节中，我们将继续探讨这些模型在推理任务中的性能评估方法和实际应用。

### 第3章 推理任务中的性能评价指标

#### 3.1 评价指标概述

在推理任务中，评估大规模语言模型的性能是一个复杂且关键的过程。为了全面、客观地评估模型的表现，我们需要使用一系列性能评价指标。这些指标不仅能够衡量模型在特定任务上的准确性，还能反映模型在速度、效率等方面的表现。

常用的性能评价指标包括准确率（Accuracy）、召回率（Recall）、精确率（Precision）、F1分数（F1 Score）、实时性（Latency）等。每种指标都有其独特的侧重点和适用场景，我们需要根据具体任务的需求选择合适的评估指标。

#### 3.2 准确度与召回率

准确度（Accuracy）是评估分类任务最直观的指标，表示模型正确分类的样本数占总样本数的比例。其计算公式为：

$$
Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
$$

其中，TP（True Positive）表示正确预测为正类的样本，TN（True Negative）表示正确预测为负类的样本，FP（False Positive）表示错误预测为正类的样本，FN（False Negative）表示错误预测为负类的样本。

然而，准确度并不能全面反映模型的性能，特别是在类别分布不均衡的情况下。例如，在一个正类样本远多于负类样本的数据集中，模型很可能会倾向于预测正类，从而获得较高的准确度，但这并不意味着模型在负类样本上的表现良好。

因此，我们需要召回率（Recall）来补充准确度的不足。召回率表示正确预测为正类的样本数占总正类样本数的比例。其计算公式为：

$$
Recall = \frac{TP}{TP + FN}
$$

召回率强调了对正类样本的识别能力，尤其是在负类样本数量较少或重要时，具有较高的参考价值。

#### 3.3 F1分数与精确率

F1分数（F1 Score）是准确度和召回率的调和平均，能够平衡两者之间的关系。其计算公式为：

$$
F1 Score = 2 \times \frac{Precision \times Recall}{Precision + Recall}
$$

其中，精确率（Precision）表示预测为正类的样本中实际为正类的比例，计算公式为：

$$
Precision = \frac{TP}{TP + FP}
$$

F1分数介于0和1之间，值越大表示模型的表现越好。当精确率和召回率的差距较大时，F1分数能够更好地反映模型的性能。

#### 3.4 实时性评估

在推理任务中，除了准确性和召回率等评价指标，实时性（Latency）也是一个重要的考量因素。特别是在需要实时响应的应用场景中，如智能对话系统、实时语音识别等，模型的响应速度直接影响到用户体验。

实时性评估通常通过计算模型在特定任务上的平均响应时间（Average Response Time）和最大响应时间（Maximum Response Time）来进行。平均响应时间表示模型处理一个样本的平均耗时，最大响应时间表示模型处理一个样本可能遇到的最长耗时。

为了在保证准确性的前提下提升实时性，研究者们提出了多种优化方法，如模型压缩（Model Compression）、量化（Quantization）、剪枝（Pruning）等。这些方法通过减少模型的参数规模或简化计算过程，提高了模型的推理速度。

#### 3.5 综合评价指标

在实际应用中，我们通常需要使用多个评价指标来综合评估大规模语言模型的表现。例如，在文本分类任务中，准确率、召回率和F1分数是常用的评价指标。在实时性要求较高的任务中，实时性评估也是一个重要的考量因素。

为了更全面地评估模型的表现，可以采用综合评价指标，如准确度与实时性的平衡（Accuracy-Latency Trade-off）。这种方法通过在不同实时性水平下评估模型的准确率，找到最优的平衡点，从而实现性能优化。

#### 3.6 其他性能评价指标

除了准确度、召回率、精确率和F1分数等常用评价指标外，还有许多其他指标在推理任务中具有重要价值。以下是一些重要的补充性能评价指标：

1. **错误率（Error Rate）**：错误率表示模型预测错误的样本占总样本数的比例。其计算公式为：

   $$
   Error Rate = \frac{FP + FN}{TP + TN + FP + FN}
   $$

   与准确度相反，错误率可以直观地反映模型预测的总体误差。

2. **Kappa系数（Kappa Score）**：Kappa系数是评估两个分类器或多个分类器之间一致性的指标。其计算公式为：

   $$
   \kappa = \frac{Accuracy - Pseudo\ Accuracy}{1 - Pseudo\ Accuracy}
   $$

   其中，Pseudo Accuracy 是假设所有样本都被正确分类时的准确度。Kappa系数的值介于-1和1之间，值越大表示分类器的一致性越好。

3. **ROC曲线与AUC值（ROC Curve & AUC Score）**：ROC曲线（Receiver Operating Characteristic Curve）和AUC值（Area Under Curve）用于评估二分类模型的分类能力。ROC曲线展示了不同分类阈值下模型的准确率和召回率，而AUC值表示ROC曲线下方的面积，反映了模型的总体分类能力。AUC值介于0和1之间，值越大表示模型的表现越好。

4. **Matthews相关系数（Matthews Correlation Coefficient，MCC）**：MCC是评估二分类模型准确性的综合指标，考虑了精确率、召回率和平衡性。其计算公式为：

   $$
   MCC = \frac{TP \times TN - FP \times FN}{\sqrt{(TP + FP) \times (TP + FN) \times (TN + FP) \times (TN + FN)}}
   $$

   MCC的值介于-1和1之间，接近1表示模型表现非常优秀，接近-1表示模型表现非常糟糕。

5. **Fowlkes-Mallows指数（Fowlkes-Mallows Index，FMI）**：FMI是用于评估多标签分类模型的性能指标。FMI通过计算所有标签对之间的交集和并集的比值，评估模型的分类一致性。其计算公式为：

   $$
   FMI = \frac{1}{\sum_{i<j} \frac{TP_{ij}}{max(TP_{i}, TP_{j})}}
   $$

   其中，\( TP_{ij} \) 表示标签i和标签j共同预测为正类的样本数。

6. **宏平均和微平均（Macro-average & Micro-average）**：宏平均和微平均是用于计算分类性能的平均指标。宏平均计算每个类别准确率的平均值，不考虑类别频率，适用于类别分布均衡的数据集。微平均计算总体准确率的平均值，考虑类别频率，适用于类别分布不均衡的数据集。

通过使用这些补充性能评价指标，我们可以更全面地评估大规模语言模型在推理任务中的表现，从而为模型优化和任务设计提供有力支持。

**案例一：文本分类任务**

在文本分类任务中，准确度、召回率、精确率和F1分数是最常用的评价指标。假设我们有一个新闻分类系统，需要将新闻文章分类为体育、财经、科技等类别。以下是一个示例数据集：

| 文本内容              | 实际类别 | 预测类别 |
|----------------------|----------|----------|
| 体育新闻文本          | 体育      | 体育      |
| 财经新闻文本          | 财经      | 科技      |
| 科技新闻文本          | 科技      | 科技      |
| 娱乐新闻文本          | 娱乐      | 体育      |

根据上述数据，我们可以计算各个评价指标：

- **准确度**：\( \frac{2+1+1}{4} = 0.75 \)
- **召回率**：\( \frac{2}{3} = 0.67 \)
- **精确率**：\( \frac{2}{3} = 0.67 \)
- **F1分数**：\( \frac{2 \times 0.67}{0.67 + 0.67} = 0.67 \)

从这个案例中，我们可以看到准确度和F1分数相对较高，说明模型在总体上能够正确分类新闻文章。但召回率较低，表示模型对负类别的识别不足。

**案例二：疾病诊断系统**

在疾病诊断任务中，错误率和Kappa系数是常用的评价指标。假设我们有一个疾病诊断系统，需要根据患者的症状进行疾病分类。以下是一个示例数据集：

| 症状组合              | 实际疾病  | 预测疾病  |
|----------------------|-----------|-----------|
| 头痛、发热、咳嗽      | 流感      | 流感      |
| 头痛、呕吐、腹泻      | 肠炎      | 肠炎      |
| 头痛、高血压          | 脑瘤      | 脑瘤      |
| 咳嗽、乏力、胸闷      | 肺炎      | 肺炎      |

根据上述数据，我们可以计算错误率和Kappa系数：

- **错误率**：\( \frac{0+0+1+0}{4} = 0.25 \)
- **Kappa系数**：\( \frac{0.75 - 0.5}{1 - 0.5} = 1.0 \)

这个案例中，错误率较低，Kappa系数为1，表明模型在疾病诊断任务中具有很高的准确性。

**案例三：目标检测任务**

在目标检测任务中，ROC曲线和AUC值是重要的评价指标。假设我们有一个自动驾驶系统，需要检测道路上的行人。以下是一个示例数据集：

| 真实目标              | 预测目标   | 预测概率 |
|----------------------|------------|----------|
| 行人存在              | 行人存在   | 0.95     |
| 行人不复存在          | 行人不复存在| 0.90     |
| 车辆存在              | 车辆存在   | 0.80     |
| 车辆不复存在          | 车辆不复存在| 0.85     |

根据上述数据，我们可以绘制ROC曲线并计算AUC值：

- **ROC曲线**：通过（0.85，0.90）和（0.95，1.0）两个点
- **AUC值**：接近1

这个案例中，AUC值较高，表明模型在目标检测任务中具有很好的分类能力。

### 第4章 评估方法与工具

#### 4.1 数据集与评估框架

首先，数据集的选择应该具备以下特点：

1. **代表性**：数据集应涵盖不同类型和场景的样本，以全面评估模型的泛化能力。
2. **多样性**：数据集中应包含不同地域、语言、领域等多样化的样本，以提高模型的适应性。
3. **质量**：数据集应经过严格清洗和处理，避免噪声和错误样本对评估结果的干扰。

目前，自然语言处理领域常用的数据集包括但不限于：

- **通用语言理解数据集**：如GLUE（General Language Understanding Evaluation）和SuperGLUE，涵盖多种任务，如文本分类、问答、推理等。
- **专用语言理解数据集**：如SQuAD（Stanford Question Answering Dataset）和CoQA（Conversational Question Answering），专门用于问答任务。
- **多语言数据集**：如WMT（Workshop on Machine Translation）和opus，提供多种语言之间的翻译任务数据。

其次，评估框架的设计应考虑以下几个方面：

1. **任务定义**：明确评估任务的目标和输入输出格式，以确保不同模型的评估具有可比性。
2. **评估指标**：选择合适的性能评价指标，如准确率、召回率、F1分数等，以便全面评估模型的表现。
3. **评估流程**：设计合理的评估流程，包括数据集划分（训练集、验证集、测试集）、模型训练和评估等步骤，确保评估过程的公平性和透明性。
4. **自动化评估**：利用工具和脚本自动化评估过程，提高评估效率和一致性。

常见的评估框架包括：

通过选择合适的评估框架和数据集，我们能够客观、全面地评估大规模语言模型在推理任务中的表现，为模型优化和任务设计提供有力支持。

#### 4.2 评估指标计算方法

在评估大规模语言模型性能时，正确计算各种评估指标是关键。以下将详细介绍常用评估指标的计算方法，包括准确率、召回率、精确率、F1分数、实时性等。

1. **准确率（Accuracy）**：

准确率是最常用的评估指标之一，表示模型正确预测的样本数占总样本数的比例。其计算公式为：

$$
Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
$$

其中，TP（True Positive）表示正确预测为正类的样本，TN（True Negative）表示正确预测为负类的样本，FP（False Positive）表示错误预测为正类的样本，FN（False Negative）表示错误预测为负类的样本。

2. **召回率（Recall）**：

召回率表示正确预测为正类的样本数占总正类样本数的比例，强调了对正类样本的识别能力。其计算公式为：

$$
Recall = \frac{TP}{TP + FN}
$$

3. **精确率（Precision）**：

精确率表示预测为正类的样本中实际为正类的比例，强调了对正类样本的识别精度。其计算公式为：

$$
Precision = \frac{TP}{TP + FP}
$$

4. **F1分数（F1 Score）**：

F1分数是精确率和召回率的调和平均，能够平衡两者之间的关系。其计算公式为：

$$
F1 Score = 2 \times \frac{Precision \times Recall}{Precision + Recall}
$$

5. **实时性（Latency）**：

实时性评估通常通过计算模型在特定任务上的平均响应时间（Average Response Time）和最大响应时间（Maximum Response Time）来进行。平均响应时间表示模型处理一个样本的平均耗时，最大响应时间表示模型处理一个样本可能遇到的最长耗时。

6. **其他指标**：

除了上述常用指标外，还有一些其他重要的性能评价指标，如错误率（Error Rate）、Kappa系数（Kappa Score）、ROC曲线与AUC值（ROC Curve & AUC Score）、Matthews相关系数（Matthews Correlation Coefficient，MCC）等。

通过掌握这些评估指标的计算方法，我们能够更准确地评估大规模语言模型在推理任务中的表现，为模型优化和任务设计提供有力支持。

### 第6章 性能评估中的挑战与未来方向

#### 6.1 数据质量与多样性挑战

大规模语言模型在推理任务中的性能评估首先面临的是数据质量与多样性挑战。数据质量直接影响模型的训练效果和评估结果的准确性。具体来说，数据集中可能存在噪声、偏差和错误标注等问题，这些问题会干扰模型的学习过程，导致评估结果失真。

- **噪声数据**：噪声数据包括文本中的错别字、标点符号错误、无关字符等，这些噪声会影响模型对语言规律的学习，进而影响模型的泛化能力。
- **偏差数据**：数据集中可能存在偏差，例如某些类别样本过多或过少，导致模型偏向于预测常见类别，从而忽视了其他类别的重要性。
- **错误标注**：错误标注的数据会导致模型学习到错误的规律，从而影响模型的性能。此外，数据集的标注一致性也是一个重要问题，不同标注者的主观判断可能导致标注不一致。

为了解决这些问题，可以采取以下措施：

- **数据清洗**：通过去除噪声数据、纠正错误标注等方式，提高数据集的质量。
- **数据增强**：通过数据合成、数据扩展等方法增加数据集的多样性，提高模型的泛化能力。
- **标注一致性检查**：引入自动化工具对标注进行一致性检查，减少标注错误。

#### 6.2 评估方法的优化

除了数据质量与多样性问题，评估方法本身也需要不断优化。现有的评估方法在准确度、实时性等方面还存在一些局限性，需要进一步研究和改进。

- **准确性**：现有的评估方法主要侧重于分类和回归任务的准确性，但在处理序列数据、时序数据等复杂数据类型时，评估方法的准确性可能不足。例如，在机器翻译任务中，BLEU分数虽然能衡量翻译文本的相似度，但无法准确反映翻译文本的语义准确性。
- **实时性**：在实时性要求较高的应用场景中，现有评估方法的响应时间可能无法满足需求。例如，在智能对话系统中，用户的交互速度很快，模型的响应速度需要尽可能快，以确保用户体验。

为了优化评估方法，可以采取以下措施：

- **多指标综合评估**：结合多种评估指标，如准确率、召回率、精确率、实时性等，从多个维度评估模型的表现，以获得更全面的结果。
- **自适应评估**：根据不同任务和应用场景，动态调整评估指标和方法，以提高评估的准确性和实时性。
- **新评估指标的开发**：探索和开发新的评估指标，例如基于语义相似度的评估指标，以更准确地衡量模型的性能。

##### Mermaid流程图

```mermaid

    A[Input Text] --> B[Tokenization]
```

##### Python源代码

```python
import torch
import torch.nn as nn
import torch.optim as optim

# 定义模型
class LanguageModel(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, n_layers):
        super(LanguageModel, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, n_layers)
        self.fc = nn.Linear(hidden_dim, vocab_size)
        
    def forward(self, inputs):
        embedded = self.embedding(inputs)
        output, (hidden, cell) = self.lstm(embedded)
        output = self.fc(output[-1, :, :])
        return output

# 实例化模型
model = LanguageModel(vocab_size=10000, embedding_dim=256, hidden_dim=512, n_layers=2)

# 定义损失函数和优化器
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 假设输入文本为[3, 1, 4, 2]
input_text = torch.tensor([3, 1, 4, 2])

# 前向传播
output = model(input_text)

# 计算损失
loss = criterion(output, torch.tensor([2]))

# 反向传播和优化
optimizer.zero_grad()
loss.backward()
optimizer.step()

print("Predicted Output:", output.argmax().item())
```

##### 解释

1. **模型定义**：我们使用Python和PyTorch库定义了一个简单的语言模型，该模型基于LSTM（长短期记忆网络）架构。模型包括嵌入层、LSTM层和输出层。
2. **前向传播**：输入文本被嵌入为词向量，通过LSTM层处理，最后通过输出层生成概率分布。
3. **损失计算**：使用交叉熵损失函数计算模型预测输出与实际标签之间的差异。
4. **反向传播和优化**：通过反向传播计算梯度，使用优化器更新模型参数，以最小化损失。

通过这个示例，我们可以看到大规模语言模型在推理任务中的基本原理和实现方法，这为我们理解和优化模型提供了坚实的基础。

#### 9.2 系统核心实现源代码

以下是一个简单的文本分类系统的核心实现，用于演示大规模语言模型在文本分类任务中的应用。

```python
import torch
from torch import nn, optim
from torchtext.data import Field, TabularDataset
from torchtext.vocab import Vocab
from evalmetrics import ClassificationMetrics

# 数据预处理
def preprocess_text(text):
    # 实现文本清洗和预处理逻辑
    return text.lower()

# 定义模型
class TextClassifier(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, num_classes):
        super(TextClassifier, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, num_classes)
        
    def forward(self, text):
        embedded = self.embedding(text)
        output, (hidden, cell) = self.lstm(embedded)
        hidden = hidden[-1, :, :]
        output = self.fc(hidden)
        return output

# 加载数据集
train_data, test_data = TabularDataset.splits(path='data',
                                            train='train.csv',
                                            test='test.csv',
                                            format='csv',
                                            skip_header=True,
                                            fields=[('text', Field(sequential=True, lower=True, tokenizer=preprocess_text)),
                                                    ('label', Field(sequential=False))])

# 创建词汇表
vocab = Vocab.build_from_iterator(train_data.text, min_freq=2)

# 初始化模型和优化器
model = TextClassifier(len(vocab), embedding_dim=128, hidden_dim=128, num_classes=2)
optimizer = optim.Adam(model.parameters(), lr=0.001)
criterion = nn.CrossEntropyLoss()

# 训练模型
def train_model(model, train_data, test_data, epochs=10):
    model.train()
    for epoch in range(epochs):
        for batch in train_data:
            optimizer.zero_grad()
            output = model(batch.text).squeeze(1)
            loss = criterion(output, batch.label)
            loss.backward()
            optimizer.step()
        
        # 验证模型
        model.eval()
        metrics = ClassificationMetrics()
        with torch.no_grad():
            for batch in test_data:
                output = model(batch.text).squeeze(1)
                prediction = output.argmax().item()
                true_label = batch.label.item()
                metrics.add(true_label, prediction)
        
        print(f"Epoch: {epoch+1}, Loss: {loss.item()}, Test Accuracy: {metrics.accuracy}")

# 运行训练
train_model(model, train_data, test_data, epochs=10)
```
