### 第1章：问题背景与概念介绍

### 1.1 问题背景

#### 1.1.1 生态足迹概念的提出

生态足迹这一概念最早由生态学家William Rees和生态经济学家Mathis Wackernagel于1996年提出。他们指出，为了维持人类目前的生活方式，地球需要拥有一个相当于1.7个地球的表面积来提供自然资源和吸收废弃物。这一观点引发了全球对于环境承载能力和可持续发展的关注。

#### 1.1.2 生态足迹计算方法

生态足迹的计算方法基于生物生产面积（Biochemical Production Area，BPA）和生物承载力（Biocapacity，BC）的概念。BPA是指每年能生产某种生物量的土地或水体面积，例如农作物、森林、草地等。BC是指每年能够再生资源的土地和水体面积，例如森林、草地、海洋等。生态足迹等于个人或国家所需的BPA减去BC。

#### 1.1.3 生态足迹与可持续发展

生态足迹与可持续发展密切相关。一个地区的生态足迹如果超过其生物承载力，意味着该地区处于生态赤字状态，长期下去将导致环境恶化和资源枯竭。因此，通过生态足迹交易平台来激励个人减少生态足迹，是实现可持续发展的重要途径。

### 1.2 生态足迹交易平台的定义与目的

生态足迹交易平台是一个基于互联网的技术平台，通过数字化手段实现生态足迹的测量、交易和激励。平台允许用户对其生态足迹进行监控，并通过交易机制减少其生态足迹。

#### 1.2.2 平台的主要功能

#### 1.2.3 平台对环保行为的激励作用

### 第2章：核心概念与联系

### 2.1 生态足迹指标

#### 2.1.1 指标定义

生态足迹指标是衡量个人或国家生态足迹的重要工具。具体来说，生态足迹指标包括以下几个方面：

- **生物生产面积（BPA）**：指的是每年能生产某种生物量的土地或水体面积，例如农作物、森林、草地等。
- **生物承载力（BC）**：指的是每年能够再生资源的土地和水体面积，例如森林、草地、海洋等。
- **生态赤字（Ecological Deficit）**：指的是一个地区的生态足迹超过其生物承载力的情况。
- **生态足迹账户（Ecological Footprint Account）**：用于记录和管理个人或国家的生态足迹。

| 生物承载力（BC） | 每年能够再生资源的土地和水体面积 | 衡量环境承载能力 | 比较不同地区或国家的环境承载能力 |

from flask import Blueprint, render_template, request, redirect, url_for, flash

from werkzeug.security import generate_password_hash, check_password_hash
from .models import User, Product, Transaction
from . import db

bp = Blueprint('main', __name__)

@bp.route('/')
def index():
    products = Product.query.all()
    return render_template('index.html', products=products)

@bp.route('/register', methods=['GET', 'POST'])
def register():
    if request.method == 'POST':
        username = request.form['username']
        password = request.form['password']
        email = request.form['email']
        if not username or not password or not email:
            flash('请填写完整的注册信息！', 'warning')
            return redirect(url_for('main.register'))
        if User.query.filter_by(username=username).first():
            flash('用户名已存在！', 'danger')
            return redirect(url_for('main.register'))
        if User.query.filter_by(email=email).first():
            flash('邮箱已存在！', 'danger')
            return redirect(url_for('main.register'))
        new_user = User(username=username, password=generate_password_hash(password, method='sha256'), email=email)
        db.session.add(new_user)
        db.session.commit()
        flash('注册成功！', 'success')
        return redirect(url_for('main.login'))
    return render_template('register.html')

@bp.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        username = request.form['username']
        password = request.form['password']
        user = User.query.filter_by(username=username).first()
        if user and check_password_hash(user.password, password):
            login_user(user)
            flash('登录成功！', 'success')
            return redirect(url_for('main.index'))
        else:
            flash('用户名或密码错误！', 'danger')
            return redirect(url_for('main.login'))
    return render_template('login.html')

@bp.route('/logout')
@login_required
def logout():
    logout_user()
    flash('退出成功！', 'success')
    return redirect(url_for('main.index'))

@bp.route('/buy/<int:product_id>')
@login_required
def buy(product_id):
    product = Product.query.get_or_404(product_id)
    transaction = Transaction(user_id=current_user.id, product_id=product_id, amount=product.price)
    db.session.add(transaction)
    db.session.commit()
    flash(f'购买{product.name}成功！', 'success')
    return redirect(url_for('main.index'))
