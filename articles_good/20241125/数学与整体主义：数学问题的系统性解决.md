    n = len(val)
    dp = [[0 for x in range(W + 1)] for x in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(1, W + 1):

                dp[i][w] = max(dp[i-1][w], dp[i-1][w-wt[i-1]] + val[i-1])

2. **循环**：我们使用两个嵌套循环，分别遍历物品 `i` 和背包容量 `w`。对于每个 `i` 和 `w`，我们执行以下操作：

   - 如果当前物品的重量大于背包容量 `w`，则只能选择不选择当前物品，即 `dp[i][w] = dp[i-1][w]`。

3. **结果**：最后，我们返回 `dp[n][W]`，即包含所有物品且背包容量为 `W` 时的最大价值。

#### 4.7.1 背包问题

**问题描述**：有若干个物品，每个物品都有一定的重量和价值，以及一个背包，背包有一定的最大容量。目标是选择一些物品放入背包中，使得背包的总价值最大，但不超过背包的最大容量。

**解决方案**：

1. **问题建模**：我们使用动态规划方法来解决这个问题。定义一个二维数组 `dp`，其中 `dp[i][w]` 表示前 `i` 个物品在背包容量为 `w` 时的最大价值。

2. **状态转移方程**：
   \[
   dp[i][w] = \begin{cases}
   dp[i-1][w], & \text{如果 } w < wt[i-1] \\
   \max(dp[i-1][w], dp[i-1][w-wt[i-1]] + val[i-1]), & \text{如果 } w \geq wt[i-1]
   \end{cases}
   \]

3. **初始化**：初始化 `dp` 数组的第一行和第一列，即当没有物品或背包容量为零时的最大价值为0。

4. **递推**：从第二个物品开始，依次填入 `dp` 数组。

5. **结果**：最后，`dp[n][W]` 将是背包能够达到的最大价值。

**Python代码实现**：
```python
def knapsack(W, wt, val):
    n = len(val)
    dp = [[0 for _ in range(W + 1)] for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(1, W + 1):
            if wt[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], dp[i-1][w-wt[i-1]] + val[i-1])
            else:
                dp[i][w] = dp[i-1][w]

    return dp[n][W]

# 示例数据
val = [60, 100, 120]
wt = [10, 20, 30]
W = 50

# 计算最大价值
max_value = knapsack(W, wt, val)
print("最大价值：", max_value)
```

**实例分析**：给定三个物品，重量分别为10kg、20kg和30kg，价值分别为60元、100元和120元。背包的最大容量为50kg。通过运行上述代码，我们可以得到背包能够达到的最大价值为280元。

#### 4.7.2 整数分拆问题

**问题描述**：将一个正整数分拆成若干个正整数的和，求出所有可能的分拆方法。

**解决方案**：

1. **问题建模**：我们使用动态规划方法来解决这个问题。定义一个一维数组 `dp`，其中 `dp[i]` 表示将整数 `i` 分拆成若干个正整数和的方法总数。

2. **状态转移方程**：
   \[
   dp[i] = \sum_{j=1}^{i-1} dp[i-j]
   \]

3. **初始化**：初始化 `dp` 数组的第一行和第一列，即当整数 `i` 为1时，只有一种分拆方法，即 `dp[1] = 1`。

4. **递推**：从第二个整数开始，依次填入 `dp` 数组。

5. **结果**：最后，`dp[n]` 将是整数 `n` 的分拆方法总数。

**Python代码实现**：
```python
def count_partitions(n):
    dp = [0] * (n + 1)
    dp[0] = 1
    for i in range(1, n + 1):
        for j in range(1, i):
            dp[i] += dp[i - j]
    return dp[n]

# 示例数据
n = 5

# 计算分拆方法总数
partition_count = count_partitions(n)
print("分拆方法总数：", partition_count)
```

**问题建模**：

我们可以使用一个二维数组 `dp` 来存储中间结果。其中，`dp[i][j]` 表示将整数 `i` 分解成若干个整数（每个整数不超过 `j`）的方法数量。

**状态转移方程**：

当 `i > j` 时，`dp[i][j] = 0`，因为无法将一个大于 `j` 的整数分解为若干个小于等于 `j` 的整数。

当 `i <= j` 时，我们可以有两种选择：
1. 不使用当前整数 `i`，即 `dp[i][j] = dp[i][j-1]`。
2. 使用当前整数 `i`，即 `dp[i][j] = dp[i-j][j]`。

\[
dp[i][j] = dp[i][j-1] + dp[i-j][j]

def count_integer_partitions(n, k):
    dp = [[0 for _ in range(k + 1)] for _ in range(n + 1)]
    for j in range(k + 1):
        dp[0][j] = 1
    for i in range(1, n + 1):
        for j in range(1, k + 1):
            dp[i][j] = dp[i][j - 1] + dp[i - j][j]
    return dp[n][k]

- 如果 \( \Delta < 0 \)，则方程无实数解。
- 如果 \( \Delta = 0 \)，则方程有一个整数解。
- 如果 \( \Delta > 0 \)，则方程有两个整数解。

**问题建模**：

我们可以通过枚举所有可能的整数 \( x \) 来求解方程。具体而言，对于每个 \( x \)，我们计算 \( ax^2 + bx + c \) 的值，并检查其是否等于0。

**Python代码实现**：
```python
def find_integer_solutions(a, b, c):
    delta = b**2 - 4*a*c
    if delta < 0:
        return "方程无实数解"
    elif delta == 0:
        x = -b / (2*a)
        return f"方程有一个整数解：{x}"
    else:
        solutions = []
        for x in range(-abs(delta), abs(delta) + 1):
            if a*x**2 + b*x + c == 0:
                solutions.append(x)
        return f"方程有两个整数解：{solutions}"

# 示例数据

b = -5
c = 6

# 求解方程
solutions = find_integer_solutions(a, b, c)
print(solutions)
```
