### 1.1 非欧几何的起源与发展

非欧几何的起源可以追溯到19世纪初，当时数学界对欧氏几何的基本公理开始产生质疑。欧氏几何是以古希腊数学家欧几里得（Euclid）的《几何原本》为基础的，它以平面和空间中的直线、圆、球体等基本概念为出发点，通过一系列公理和定理来研究几何图形的性质。然而，随着数学的发展，一些数学家开始意识到，欧氏几何的公理系统在某些情况下并不完全符合现实世界的几何特征。

这一思考的起点可以追溯到罗巴切夫斯基（Nikolai Lobachevsky），他是俄国的一位数学家和地理学家。在1829年，罗巴切夫斯基发表了《几何学原理的新系统》，首次系统地提出了双曲几何（Hyperbolic Geometry）。罗巴切夫斯基发现，在一个特定的空间中，可以通过改变几何学的基本假设，使得平行公理不再适用，从而形成了一种新的几何体系。双曲几何的特点是，在给定一个点和一条不经过该点的直线的情况下，可以画出无数条平行线。

几乎在同一时期，匈牙利数学家拜尔诺利（Johann Bolyai）也独立地提出了类似的几何体系——双曲几何。拜尔诺利在《几何学的新体系》中详细阐述了双曲几何的基本原理，并与罗巴切夫斯基的理论进行了比较。两位数学家的工作为非欧几何的诞生奠定了基础。

然而，非欧几何的真正发展和被接受，则是在19世纪末和20世纪初。德国数学家黎曼（Bernhard Riemann）在1854年的哥廷根大学就职演说中，提出了关于空间几何的广泛假设，并引入了“曲率”的概念。黎曼的工作进一步丰富了非欧几何的理论体系，并将其扩展到更广泛的空间几何领域。

在黎曼之后，许多数学家对非欧几何进行了深入的研究和扩展，如克莱因（Felix Klein）和庞加莱（Henri Poincaré）。克莱因通过“不变量”的概念，将非欧几何与其他数学分支联系起来，使得非欧几何成为了一个更加完整的数学体系。庞加莱则通过“庞加莱模型”将非欧几何具体化为一个可计算的几何模型，为后来的研究和应用提供了重要的工具。

### 1.2 非欧几何的基本概念

非欧几何的基本概念是理解其复杂性和应用性的关键。为了更好地理解这些概念，我们需要从欧氏几何的基本原理出发，逐步引入非欧几何的不同类型。

首先，回顾一下欧氏几何的基本原理。欧氏几何的主要特征是基于欧几里得的五个公理（也称为欧几里得公理）和一系列定理。这些公理包括：

1. **通过任意两点可以作一条唯一的直线。**
2. **直线无限延伸。**
3. **通过一个点可以作无数条直线。**
4. **任意两点间的距离是唯一的。**
5. **如果一直线与另一条直线相交，且内角和小于180度，则这两条直线将在无限远处相交。**

这些公理构成了欧氏几何的基础，并导出了许多重要的几何定理，如三角形内角和定理、平行线定理等。

非欧几何的核心在于对上述公理的修改或否定，从而产生不同的几何体系。下面，我们将详细介绍几种主要的非欧几何类型：

#### 双曲几何（Hyperbolic Geometry）

双曲几何是由罗巴切夫斯基提出的，其核心特征是违反了欧氏几何的第五公理。在双曲几何中，对于任意给定的直线和点，可以画出无数条不与该直线相交的平行线。这意味着在双曲空间中，没有平行公理，因此不存在唯一的最短路径。

双曲几何的基本公理包括：

1. **通过任意两点可以作一条直线。**
2. **直线无限延伸。**
3. **通过一个点可以作无数条直线。**
4. **任意两点间的距离不是唯一的。**
5. **如果一直线与另一条直线相交，且内角和小于180度，则这两条直线将在无限远处相交，且交点的数量可以多于两个。**

双曲几何的空间被称为双曲空间，其特点是具有负曲率。双曲空间的直观模型之一是“双曲平面”，这是一个二维空间，其中每个点都围绕其周围形成无限多的同心圆，而每个圆的半径都相等。

#### 椭圆几何（Elliptic Geometry）

椭圆几何是由黎曼引入的，其特征是违反了欧氏几何的第三公理。在椭圆几何中，通过任意两点只能作一条直线，这与欧氏几何完全不同。椭圆几何的基本公理包括：

1. **通过任意两点可以作一条唯一的直线。**
2. **直线无限延伸。**
3. **通过一个点不能作无数条直线。**
4. **任意两点间的距离是唯一的。**
5. **如果一直线与另一条直线相交，且内角和大于或等于180度，则这两条直线将在有限距离处相交。**

椭圆几何的空间被称为椭圆空间，其特点是具有正曲率。椭圆空间的直观模型之一是“球面”，在这个模型中，所有的直线都是大圆，即通过球心的平面与球面的交线。

#### 黎曼几何（Riemannian Geometry）

黎曼几何是一种更一般化的非欧几何，它可以包含双曲几何和椭圆几何作为特例。黎曼几何的基本特征是引入了“曲率”的概念，用于描述空间中几何图形的扭曲程度。黎曼几何的基本公理包括：

1. **通过任意两点可以作一条直线。**
2. **直线无限延伸。**
3. **通过一个点可以作无数条直线。**
4. **任意两点间的距离是唯一的。**
5. **空间的曲率可以是非零的。**

黎曼几何的应用非常广泛，包括在广义相对论中描述时空的几何结构。

在双曲几何中，两点之间的距离可以通过以下公式计算：

$$
d(P, Q) = \int_{P}^{Q} \frac{ds}{\sqrt{1 - \kappa^2 \cdot s^2}}
$$

其中，$s$是两点之间的路径长度，$\kappa$是空间的曲率。对于双曲几何，$\kappa$为负值。

以下是一个Python函数，用于计算双曲空间中两点之间的距离：

```python
def hyperbolic_distance(P, Q, kappa=-1):
    s = np.linalg.norm(P - Q)  # 计算路径长度
    distance = s / np.sqrt(1 + kappa * s**2)
    return distance

Q = np.array([0, 1])
```
