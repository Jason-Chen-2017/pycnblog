#### 3. 使用示例

以下是一个简单的示例，展示如何使用 Python 和 NetworkX 构建和模拟一个宇宙拓扑缺陷网络。

```python
import networkx as nx
import matplotlib.pyplot as plt
import random

# 创建一个简单的网络图
G = nx.Graph()
G.add_edges_from([(1, 2), (2, 3), (3, 1), (2, 4), (4, 5)])

# 模拟网络演化
for t in range(10):
    for node in G.nodes():
        if random.random() < 0.1:
            G.nodes[node]['state'] = 'active'
        else:
            G.nodes[node]['state'] = 'inactive'

    # 绘制网络
    nx.draw(G, node_color=[G.nodes[node]['state'] for node in G.nodes()], with_labels=True)
    plt.show()
```

在这个示例中，我们首先创建了一个简单的网络图，然后通过模拟网络演化过程，展示了如何使用 NetworkX 和 matplotlib 绘制网络的动态变化。
