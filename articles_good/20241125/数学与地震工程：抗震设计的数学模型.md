### 2.1 地震波传播模型

地震波传播模型是研究地震波如何通过地球介质传播的关键工具。这种模型主要描述地震波在弹性介质中的传播规律，包括纵波（P波）和横波（S波）的传播速度、衰减特性等。

为了更直观地理解地震波传播模型，我们可以使用伪代码来描述一个简单的地震波传播计算过程：

```plaintext
function seismic_wave_propagation(source_strength, material_properties, distance):
    P_wave_speed = material_properties['P_wave_speed']
    S_wave_speed = material_properties['S_wave_speed']
    time = 0
    P_wave_front = source_strength * exp(-distance / P_wave_speed * time)
    S_wave_front = source_strength * exp(-distance / S_wave_speed * time)
    return P_wave_front, S_wave_front
```

在这个模型中，`source_strength`代表地震源的能量，`material_properties`包括介质的物理性质，如P波速度和S波速度，`distance`是地震波传播的距离。通过这个模型，我们可以计算地震波在介质中的传播情况。

在实际应用中，地震波传播模型需要考虑多种因素，如地震源的类型、介质的不均匀性等。一个更复杂的模型可能会使用有限元方法或波动方程求解器来模拟地震波的传播，以便更准确地预测地震波到达地面时的特性。
