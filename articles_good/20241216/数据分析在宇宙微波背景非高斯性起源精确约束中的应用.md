### 1.1.1 宇宙微波背景辐射的基本概念

#### 1.1.1.1 宇宙微波背景辐射的历史发现

宇宙微波背景辐射（Cosmic Microwave Background Radiation, CMB）是宇宙早期阶段的残余辐射，它为我们提供了宇宙起源和演化的宝贵信息。这一辐射最早由阿诺·彭齐亚斯（Arno Penzias）和罗伯特·威尔逊（Robert Wilson）在1965年意外发现，他们的发现不仅证实了伽利略和开普勒的理论，还为宇宙学提供了重要的证据。

#### 1.1.1.2 宇宙微波背景辐射的物理特性

宇宙微波背景辐射具有以下主要特性：

- **各向同性**：CMB的温度波动极小，温度差小于0.001K，显示出高度各向同性。
- **黑体辐射**：CMB的频谱完美符合黑体辐射谱，这表明它起源于热平衡状态。

物理学家通过测量CMB的温度和频谱，可以推断出宇宙的大尺度结构。这些测量结果与我们目前对宇宙学的理解高度一致，例如：

- **宇宙微波背景辐射温度**：$$T_0 = 2.725 \pm 0.001 \text{K}$$
- **辐射光度**：$$I = \frac{2\pi hc^2k_B T_0^3}{\lambda^5}$$

### 1.1.2 宇宙微波背景非高斯性的定义

#### 1.1.2.1 高斯分布与非高斯分布

在统计学中，高斯分布（也称为正态分布）是最常见的数据分布形式。然而，宇宙微波背景辐射的数据并不完全符合高斯分布，这表明宇宙中可能存在非高斯性。

- **高斯分布**：数据符合正态分布，具有对称的钟形曲线。
- **非高斯分布**：数据不符合正态分布，可能具有尖峰、拖尾或偏态等特征。

#### 1.1.2.2 非高斯性的表现

非高斯性的数据表现出以下特征：

- **尖峰**：数据集中在较小的值域内，形成尖锐的峰值。
- **拖尾**：数据分布尾部较长，意味着有更多的极端值。
- **偏态**：数据分布不对称，可能呈现右偏或左偏。

### 1.1.3 非高斯性的起源与影响

#### 1.1.3.1 非高斯性的可能起源

宇宙微波背景非高斯性的起源可能源于多种因素，包括：

- **宇宙结构形成**：星系团、黑洞等引力效应可能导致非高斯性。
- **早期宇宙事件**：暴胀、暗物质、暗能量等早期宇宙现象可能引入非高斯性。

#### 1.1.3.2 非高斯性的影响

非高斯性对宇宙学研究具有重要意义：

## 第3章：宇宙微波背景非高斯性的数据分析方法

### 3.1.1 简单统计方法

简单统计方法是数据分析的基础，通过计算基本统计量，可以初步了解数据的特征。

#### 3.1.1.1 基本统计量

- **均值**：表示数据的平均水平，计算公式为：
  $$\bar{x} = \frac{1}{N}\sum_{i=1}^{N} x_i$$
  其中，\(N\) 为数据个数，\(x_i\) 为第 \(i\) 个数据点。

- **标准差**：表示数据的离散程度，计算公式为：
  $$\sigma = \sqrt{\frac{1}{N-1}\sum_{i=1}^{N}(x_i - \bar{x})^2}$$
  其中，\(\bar{x}\) 为均值。

#### 3.1.1.2 常用统计测试

- **t检验**：用于比较两组数据的均值是否有显著差异。
- **方差分析**（ANOVA）：用于比较多个组数据的均值是否有显著差异。
- **卡方检验**：用于检验数据分布的拟合度。

### 3.1.2 高斯过程模型

高斯过程模型（Gaussian Process, GP）是一种强大的非参数概率模型，适用于非线性数据建模。

#### 3.1.2.1 高斯过程基本原理

高斯过程是一种概率分布，其任意有限维分布都是高斯分布。高斯过程在数据建模中的应用，可以看作是贝叶斯线性回归的推广。

- **均值函数**：\(m(x) = \mu\)
- **协方差函数**：\(k(x, y) = \sigma^2\)

#### 3.1.2.2 高斯过程建模步骤

1. **选择合适的均值函数和协方差函数**。
2. **利用训练数据，通过最大似然估计或贝叶斯推理，估计模型参数**。
3. **使用估计的模型参数，预测新的数据点的函数值**。

### 3.1.3 偏微分方程模型

偏微分方程模型（Partial Differential Equation, PDE）在数据分析中有着广泛的应用，可以用于模拟复杂的物理现象和工程问题。

#### 3.1.3.1 偏微分方程基本概念

偏微分方程是包含未知函数及其偏导数的方程，通常表示为：
$$\frac{\partial u}{\partial t} + a\frac{\partial u}{\partial x} = f(x, t)$$

其中，\(u(x, t)\) 为未知函数，\(a\) 为常数，\(f(x, t)\) 为非齐次项。

#### 3.1.3.2 偏微分方程建模步骤

1. **定义问题背景和边界条件**。
2. **选择合适的偏微分方程模型**。
3. **利用数值方法（如有限元法、有限差分法等），求解偏微分方程**。
4. **分析求解结果，提取有用信息**。

```python
import pandas as pd

# 读取数据
data = pd.read_csv('cmb_data.csv')

# 缺失值处理
data.dropna(inplace=True)

# 异常值检测
Q1 = data.quantile(0.25)
Q3 = data.quantile(0.75)
IQR = Q3 - Q1
data = data[~((data < (Q1 - 1.5 * IQR)) | (data > (Q3 + 1.5 * IQR)))]

# 数据转换
data['temperature'] = (data['temperature'] - data['temperature'].mean()) / data['temperature'].std()
```

data['rpike_to_rms'] = data['peak_to_peak'] / data['std']
