### 第2章：数据结构概述

#### 2.1 数据结构的概念

数据结构是计算机存储、组织数据的方式。它不仅决定了数据的存储位置和方式，还影响了数据的操作效率和性能。在计算机科学中，数据结构是一个核心概念，贯穿于算法设计和程序开发的全过程。数据结构可以分为线性结构和非线性结构，线性结构包括数组、链表、栈、队列等，非线性结构包括树、图等。

#### 2.2 数据结构的分类

数据结构可以根据不同的标准进行分类。以下是一些常见的数据结构分类方法：

1. **按存储方式分类**：
   - **顺序存储结构**：如数组、顺序表等，数据元素按顺序存储在连续的内存空间中。
   - **链式存储结构**：如链表、双向链表等，数据元素存储在离散的内存空间中，通过指针连接。

2. **按逻辑结构分类**：
   - **线性结构**：如数组、链表、栈、队列等，数据元素之间是一对一的关系。
   - **树形结构**：如二叉树、AVL树、B树等，数据元素之间存在一对多的关系。
   - **图形结构**：如图、网状图等，数据元素之间存在多对多的关系。

3. **按数据结构特性分类**：
   - **静态数据结构**：如数组、顺序表等，数据结构在程序运行期间大小固定。

序列数据结构是一种线性数据结构，用于存储一组有序的元素。序列数据结构包括数组、链表、栈和队列等。在模拟宇宙中，序列数据结构被广泛用于存储和操作宇宙中的各种数据，如星系、恒星、行星等。

1. **数组**：数组是一种顺序存储结构，用于存储固定数量的元素。数组的特点是访问速度快，但大小固定，不能动态扩展。
2. **链表**：链表是一种链式存储结构，用于存储一组离散的元素。链表的特点是大小可变，插入和删除操作灵活，但访问速度相对较慢。
3. **栈**：栈是一种后进先出（LIFO）的序列数据结构，用于存储和操作元素的顺序。栈的特点是插入和删除操作在表的一端进行，这使得栈在模拟宇宙中的某些场景（如模拟恒星爆发）中非常有用。
4. **队列**：队列是一种先进先出（FIFO）的序列数据结构，用于存储和操作元素的顺序。队列的特点是插入操作在表的一端进行，删除操作在另一端进行，这使得队列在模拟宇宙中的某些场景（如模拟行星轨道）中非常有用。

树数据结构是一种重要的非线性数据结构，由节点和边组成。树结构在计算机科学和许多其他领域中都有广泛应用，如文件系统、组织结构、决策树等。在模拟宇宙中，树数据结构被用来表示宇宙中的层次结构和关系，如星系、恒星、行星的层次关系。

4. **边**：树中的边表示节点之间的父子关系。

5. **树的深度**：树的深度是从根节点到最远叶子节点的最长路径上的边数。

6. **树的度**：树中任意节点的度是指该节点的子节点数量。

树数据结构可以分为不同的类型，包括：

- **二叉树**：每个节点最多有两个子节点的树。

- **平衡二叉树**：每个节点的左右子树的高度差不超过1的二叉树，如AVL树和红黑树。

- **二叉搜索树**：每个节点都满足左子树中的所有节点值小于该节点值，右子树中的所有节点值大于该节点值的二叉树。

### 图数据结构的深度优先搜索（DFS）

深度优先搜索是一种用于遍历或搜索图的算法。它从初始节点开始，尽可能深地搜索图的分支。

```python
# 示例：使用深度优先搜索查找图中从源节点到目标节点的路径

def dfs(graph, start, target):
    visited = set()  # 记录已经访问的节点
    stack = [start]  # 使用栈实现深度优先搜索

    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            if node == target:
                return True  # 找到目标节点

            # 将未访问的邻居节点添加到栈中
            for neighbor in graph[node]:
                if neighbor not in visited:
                    stack.append(neighbor)

    return False  # 没有找到目标节点

# 示例图的邻接表表示
graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}

# 查找从A到F的路径
print(dfs(graph, 'A', 'F'))  # 输出：True
```

在模拟宇宙中，DFS可以用来寻找两个星系之间的最短路径，这有助于模拟星系之间的引力作用和物质流动。

### 图数据结构的广度优先搜索（BFS）

广度优先搜索是另一种用于遍历或搜索图的算法。它从初始节点开始，逐层地搜索图的节点。

```python
# 示例：使用广度优先搜索查找图中从源节点到目标节点的最短路径

from collections import deque

def bfs(graph, start, target):
    visited = set()  # 记录已经访问的节点
    queue = deque([start])  # 使用队列实现广度优先搜索

    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            if node == target:
                return True  # 找到目标节点

            # 将未访问的邻居节点添加到队列中
            for neighbor in graph[node]:
                if neighbor not in visited:
                    queue.append(neighbor)

    return False  # 没有找到目标节点

# 示例图的邻接表表示与DFS相同
graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}

# 查找从A到F的路径
print(bfs(graph, 'A', 'F'))  # 输出：True
```

在模拟宇宙中，BFS可以用来模拟行星的轨道运动，通过搜索找到最近的星系或恒星。

### 树数据结构的中序遍历

中序遍历是一种用于遍历二叉树的算法。它按照“左子树 - 父节点 - 右子树”的顺序访问二叉树的所有节点。

```python
# 示例：使用中序遍历访问二叉树的节点

def inorder_traversal(node):
    if node:
        inorder_traversal(node.left)  # 访问左子树
        print(node.value)  # 访问父节点
        inorder_traversal(node.right)  # 访问右子树

# 示例二叉树的构建
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.left = TreeNode(4)
root.left.right = TreeNode(5)

# 执行中序遍历
inorder_traversal(root)
# 输出：4 2 5 1 3
```

在模拟宇宙中，中序遍历可以用来模拟星系和恒星之间的层次结构，帮助我们理解宇宙的层次分布。
