#### 3.2 Python源代码与算法原理

下面是环境污染扩散方程的Python源代码实现，我们将结合代码进行算法原理的讲解。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.sparse.linalg import spsolve

# 参数设置
dx = 0.1        # 空间步长
dt = 0.1        # 时间步长
L = 10          # 空间长度
T = 100         # 总时间
N = int(L / dx) # 空间节点数
M = int(T / dt) # 时间步数

# 初始化浓度数组
C = np.zeros((M, N))

# 初始化初始浓度
C[0, :] = np.linspace(0, 1, N)

# 构建稀疏矩阵A
A = np.zeros((N, N))
for i in range(1, N-1):
    A[i, i-1] = A[i, i+1] = -1 / dx**2
    A[i, i] = 2 / dx**2

# 应用边界条件
A[0, 0] = 1
A[-1, -1] = 1

# 时间迭代
for t in range(1, M):
    C[t, :] = spsolve(A, C[t-1, :])

# 绘制浓度分布
plt.plot(C.T)
plt.xlabel('Position')
plt.ylabel('Concentration')
plt.title('Concentration Distribution over Time')
plt.show()
```

#### 3.2.2 算法原理的数学模型

扩散方程的数学模型如下：

$$
\frac{\partial C}{\partial t} = D \nabla^2 C
$$

其中，$C$是浓度，$t$是时间，$D$是扩散系数，$\nabla^2$是拉普拉斯算子。

为了将连续的扩散方程离散化，我们引入空间步长dx和时间步长dt，将连续空间和时间划分为离散网格点。在离散网格上，扩散方程可以表示为：

$$
C_{i,j}^{t+1} = C_{i,j}^{t} + \frac{D \Delta t}{\Delta x^2} \left( C_{i-1,j}^{t} - 2C_{i,j}^{t} + C_{i+1,j}^{t} \right)

其中，$C_{i,j}^{t}$表示在时间t、空间点x=i*dx处的浓度。

在代码实现中，我们使用了如下公式：

$$

其中，$A$是构建的稀疏矩阵，包含了离散化后的拉普拉斯算子。

通过稀疏矩阵A，我们可以将扩散方程转化为线性方程组：

$$
AC = b
$$

其中，$b = C_{i,j}^{t}$。利用线性求解器`spsolve`，我们可以高效地求解浓度分布。

$$

$$

$$
\frac{\partial C}{\partial t} = D \nabla^2 C
