3. **再现过程**：当再现光波照射到全息图上时，全息图会衍射再现出物体的三维图像。

   def generate_hologram(image, alpha=0.5):
       # 将图像转换为灰度图像
       gray_image = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
       
       # 计算图像的傅里叶变换

       return hologram
