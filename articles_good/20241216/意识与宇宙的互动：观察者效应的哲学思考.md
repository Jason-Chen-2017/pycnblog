**1. 标题**

markdown使用#号来表示标题，其中#号的数量代表标题的层级。例如：

```markdown
# 意识与宇宙的互动：观察者效应的哲学思考

```

以此类推，三级标题使用三个#号：

```markdown
### 1.1 意识与宇宙的互动概述
```

**2. 段落**

markdown中的段落默认是按行分隔的。一个段落通常由一行或多行连续文本组成，没有空行分隔。例如：

```markdown
这是一段文本。它将单独作为一个段落。

这是一段新的文本。它将作为另一段新的段落。
```

**3. 列表**

markdown支持有序列表和无序列表。有序列表使用数字和英文句点来标记，例如：

```markdown
1. 第一项
2. 第二项
3. 第三项
```

无序列表使用星号、加号或减号来标记：

```markdown
* 第一项
* 第二项
* 第三项
```

**4. 引用**

要引用他人的话或文本，我们可以使用反引号（`）来包裹引用内容。例如：

```markdown
根据爱因斯坦的说法，"E=mc²" 是相对论的核心公式。
```

**5. 代码**

markdown支持插入代码片段。使用反引号包裹代码，例如：

```markdown
print("Hello, World!")
```

对于多行代码，我们可以使用三个反引号：

```markdown
```
def hello(name):
    return "Hello, " + name

hello("World")
```

```markdown

|-------|-------|-------|
| 单元格1 | 单元格2 | 单元格3 |
| 单元格4 | 单元格5 | 单元格6 |
```

    A[开始] --> B{判断条件}

    B -->|否| D[操作2]
    C --> E[结束]
    D --> E

这将生成一个简单的流程图。
