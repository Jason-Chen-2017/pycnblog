```python
import numpy as np

# 构建线性模型
def linear_model(X, y):
    w = np.linalg.inv(X.T.dot(X)).dot(X.T).dot(y)
    return w

# 输入数据
X = np.array([[1, 1], [1, 2], [1, 3]])
y = np.array([2, 4, 6])

# 训练模型
w = linear_model(X, y)

# 输出模型参数
print(w)
```

以下是一个简单的系统核心实现源代码示例：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 数据
data = pd.DataFrame({
    'vehicle': [100, 200, 300, 400],
    'bus': [50, 70, 90, 110],
    'satisfaction': [80, 85, 90, 95]
})

# 数据预处理
data['total_traffic'] = data['vehicle'] + data['bus']
data = data[data['total_traffic'] <= 500]

# 模型构建
X = data[['vehicle', 'bus']]
y = data['satisfaction']
w = np.linalg.inv(X.T.dot(X)).dot(X.T).dot(y)

# 模型运算
satisfaction = X.dot(w)

# 展示结果
plt.scatter(data['vehicle'], data['satisfaction'])
plt.plot(data['vehicle'], satisfaction, color='red')
plt.xlabel('Vehicle')
plt.ylabel('Satisfaction')
plt.show()
```

以美国纽约市的交通政策制定为例，分析如何运用数学思维进行政策制定。

   - 实施高峰时段交通管制，限制私家车进入市中心区域。
   - 推广共享出行，如共享单车、共享汽车等。
4. **评估与优化**：通过模型运算和模拟，评估不同政策方案的效果。以提升市民出行满意度为评估指标，比较不同方案的效果。

   - 方案3：推广共享出行，市民满意度提升2%。

根据评估结果，选择方案1作为最佳政策方案，并在纽约市实施。经过一段时间后，评估结果显示交通拥堵有所缓解，市民出行满意度提升显著。
