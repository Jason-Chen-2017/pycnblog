    # 计算误差
    error = output - 1
    # 更新权重和偏置
    weights += learning_rate * np.dot(inputs.T, error)
    biases += learning_rate * error

# 绘制权重和偏置的变化
plt.plot(range(num_epochs), weights, label='Weights')
plt.plot(range(num_epochs), biases, label='Biases')
plt.xlabel('Epochs')
plt.ylabel('Value')
plt.legend()
plt.show()
```

#### 代码解读

- **初始化权重和偏置**：首先，我们初始化了一组随机权重和偏置。这些权重和偏置模拟了大脑中的突触连接和神经元之间的联系。
- **模拟学习过程**：在模拟学习过程中，我们使用随机生成的输入数据，通过计算输出和误差，不断调整权重和偏置，以使输出接近目标值（在此案例中为1）。
- **计算输出和误差**：输出是通过输入数据与权重相乘再加上偏置得到的。误差是输出与目标值之间的差异。
- **更新权重和偏置**：通过调整学习率，我们使用误差来更新权重和偏置。这类似于大脑中突触可塑性的机制，即通过反复练习来加强或减弱神经连接。

# 简单的线性回归模型实现
def linear_regression(x, y, learning_rate, num_epochs):
    # 初始化权重和偏置
    weights = np.random.rand(1)
    bias = np.random.rand(1)
    
    # 模拟学习过程
    for epoch in range(num_epochs):
        # 计算输出
        output = x * weights + bias
        # 计算误差
        error = y - output
        # 更新权重和偏置
        weights += learning_rate * x * error
        bias += learning_rate * error
    
    return weights, bias

# 测试数据
x = np.array([1, 2, 3, 4])
y = np.array([2, 4, 6, 8])

# 训练模型
weights, bias = linear_regression(x, y, learning_rate=0.1, num_epochs=100)

# 输出结果
print(f"Weights: {weights}, Bias: {bias}")

# 预测
new_x = np.array([5])
new_y = x * weights + bias
print(f"Prediction for x={new_x}: y={new_y}")
```

- **初始化权重和偏置**：我们初始化了随机权重和偏置，模拟了初始的神经网络状态。
