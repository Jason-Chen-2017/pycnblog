3. **决策能力**：基于感知到的信息，AI Agent使用算法进行决策，选择最优的行动方案。

**4.2 数学公式与Python代码**

在AI Agent的数学模型中，常用的数学公式和Python代码包括：

1. **线性回归**：
   - 数学公式：\( y = \beta_0 + \beta_1 \cdot x \)
   - Python代码：
     ```python
     import numpy as np

     # 假设 x 和 y 分别是输入和输出数据
     X = np.array([1, 2, 3, 4, 5])
     y = np.array([2, 4, 5, 4, 5])

     # 求解系数
     beta_0 = np.mean(y)
     beta_1 = np.mean((X - np.mean(X)) * (y - np.mean(y)))

     # 预测
     y_pred = beta_0 + beta_1 * X
     ```

**4.4 数学公式讲解与举例**

为了更直观地理解这些数学公式，我们将通过具体例子进行讲解：

1. **线性回归**：
   - 例子：假设我们有一个数据集，其中每个数据点的特征是\( x \)，标签是\( y \)。我们希望找到线性模型\( y = \beta_0 + \beta_1 \cdot x \)。
   - 公式推导：
     ```math
     \beta_0 = \frac{1}{n} \sum_{i=1}^{n} y_i
     \beta_1 = \frac{1}{n} \sum_{i=1}^{n} (x_i - \bar{x}) (y_i - \bar{y})
     ```
   - 计算过程：
     ```python
     X = [1, 2, 3, 4, 5]
     y = [2, 4, 5, 4, 5]
     n = len(y)
     bar_x = sum(X) / n
     bar_y = sum(y) / n
     beta_0 = bar_y
     beta_1 = sum([(x - bar_x) * (y - bar_y) for x, y in zip(X, y)]) / n
     print(f"beta_0: {beta_0}, beta_1: {beta_1}")
     ```

2. **支持向量机（SVM）**：

     ```math
     \min_{w, b} \frac{1}{2} \| w \|^2 + C \sum_{i=1}^{n} \max(0, 1 - y_i (w \cdot x_i + b))
     ```
   - 计算过程：
