增量更新算法的核心思想是只更新发生变化的实体和关系。以下是增量更新算法的Python代码示例：

```python
def incremental_update(graph_old, graph_new):
    entities_to_add = set(graph_new.entities) - set(graph_old.entities)
    entities_to_remove = set(graph_old.entities) - set(graph_new.entities)
    relationships_to_add = set(graph_new.relationships) - set(graph_old.relationships)
    relationships_to_remove = set(graph_old.relationships) - set(graph_new.relationships)
    
    graph_updated = graph_old.copy()
    graph_updated.add_entities(entities_to_add)
    graph_updated.remove_entities(entities_to_remove)
    graph_updated.add_relationships(relationships_to_add)
    graph_updated.remove_relationships(relationships_to_remove)
    
    return graph_updated
```
