#### 1.2 区块链的工作原理
区块链由一系列按时间顺序排列的区块组成，每个区块包含一定数量的交易记录。这些区块通过密码学算法相互链接，形成一个分布式数据库。区块链的工作原理包括区块生成、交易验证和链式结构。

```python
# 区块链节点数据结构
class Block:
    def __init__(self, transactions, previous_hash):
        self.transactions = transactions
        self.previous_hash = previous_hash
        self.hash = self.calculate_hash()

    def calculate_hash(self):
        # 使用SHA-256算法计算区块哈希值
        return sha256(self.previous_hash + str(self.transactions).encode('utf-8')).hexdigest()

# 区块链结构
class Blockchain:
    def __init__(self):
        self.unconfirmed_transactions = []
        self.chain = [self.create_genesis_block()]

    def create_genesis_block(self):
        return Block([], "0")

    def add_new_transaction(self, transaction):
        self.unconfirmed_transactions.append(transaction)

    def mine(self):
        if not self.unconfirmed_transactions:
            return "No transactions to mine"
        last_block = self.chain[-1]
        new_block = Block(self.unconfirmed_transactions, last_block.hash)
        new_block.hash = new_block.calculate_hash()
        self.chain.append(new_block)
        self.unconfirmed_transactions = []
```

### 6.4 智能合约示例代码解读

以下是一个简单的智能合约示例，用于管理捐赠资金。该合约定义了一个捐赠者地址和一个捐赠金额，捐赠者可以通过合约向特定地址发送以太币。

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract CharityDonation {
    address public owner;
    mapping(address => uint256) public donations;

    event DonationReceived(address donor, uint256 amount);

    constructor() {
        owner = msg.sender;
    }

    function donate() external payable {
        require(msg.value > 0, "捐赠金额必须大于0");
        donations[msg.sender] += msg.value;
        emit DonationReceived(msg.sender, msg.value);
    }

    function getDonation(address donor) external view returns (uint256) {
        return donations[donor];
    }

    function withdraw() external {
        require(msg.sender == owner, "只有管理员可以执行此操作");
        owner.transfer(address(this).balance);
    }
}
```

**代码解读：**

1. **合约声明**：`contract CharityDonation` 声明了一个名为 `CharityDonation` 的智能合约。
2. **变量声明**：
   - `owner`: 存储合约所有者的地址。
   - `donations`: 一个映射，存储每个捐赠者的捐赠金额。
3. **事件声明**：`event DonationReceived` 用于记录每次捐赠事件。
4. **构造函数**：`constructor()` 是合约的初始化函数，设置合约所有者。
5. **捐赠函数**：`donate()` 允许捐赠者向合约发送以太币，并记录捐赠金额。
6. **获取捐赠函数**：`getDonation()` 允许查询某个捐赠者的捐赠金额。
7. **提现函数**：`withdraw()` 允许合约所有者提取合约中的以太币余额。

通过这个示例，我们可以看到智能合约的基本结构和功能。在区块链慈善捐赠中，这样的合约可以用于管理捐赠资金，确保捐赠的透明度和安全性。
