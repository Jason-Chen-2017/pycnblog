线上运营模式主要通过互联网平台实现，用户可以在平台上查看厨房设施、价格、预订时间等信息，并进行在线预订。以下是线上运营模式的主要特点：

1. **便捷性**：用户可以随时随地进行预订，不受地理位置限制。
2. **高效性**：线上平台可以快速响应用户需求，提高运营效率。
3. **透明性**：用户可以清楚地了解厨房的设施和服务内容，增强信任感。

#### 3.1.2 线下运营模式

线下运营模式主要依赖实体厨房，用户需要亲自前往厨房进行使用。以下是线下运营模式的主要特点：

1. **稳定性**：实体厨房可以提供稳定的烹饪环境，确保食品安全和用户体验。
2. **个性化**：用户可以根据自己的需求选择不同的厨房设施和服务，提高满意度。
3. **面对面交流**：线下运营模式为用户提供了面对面交流的机会，有助于建立社区文化。

#### 3.1.3 混合运营模式

混合运营模式将线上和线下运营模式相结合，既能满足用户的便捷性需求，又能提供稳定的烹饪环境。以下是混合运营模式的主要特点：

1. **综合优势**：结合线上和线下模式的优势，提高运营效率和用户满意度。
2. **灵活性**：用户可以根据自己的需求选择线上预订或线下使用，提高灵活性。
3. **扩展性**：混合运营模式有利于拓展市场，吸引更多用户。

#### 5.1.1 供需函数

供需函数描述了用户需求量（D）与供给量（S）之间的关系。假设需求量D与供给量S之间的关系可以用以下线性函数表示：

\[ D(S) = a - bS \]

\[ a - bS = c + dC \]

\[ S^* = \frac{a - c}{b + d} \]

\[ C^* = \frac{a - bS^*}{d} \]

\[ a - b(S^* + \Delta S) = c + d(C^* + \Delta C) \]

       booking.setStartTime(bookingRequest.getStartTime());
       booking.setEndTime(bookingRequest.getEndTime());
       
       bookingRepository.save(booking);
       
       // 更新厨房状态
       kitchen.setStatus("booked");
       kitchenRepository.save(kitchen);
       
       return ResponseEntity.ok("Booking created successfully!");
   }
