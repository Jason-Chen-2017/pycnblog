### 6.2 系统核心实现

以下是新苦行者训练营系统核心实现的Python代码：

```python
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///new_ascetic_camp.db'
db = SQLAlchemy(app)

class Participant(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(120), nullable=False)
    self_management_score = db.Column(db.Float, nullable=False)

class Activity(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(120), nullable=False)
    description = db.Column(db.Text, nullable=False)

@app.route('/register', methods=['POST'])
def register():
    name = request.form['name']
    self_management_score = float(request.form['self_management_score'])
    participant = Participant(name=name, self_management_score=self_management_score)
    db.session.add(participant)
    db.session.commit()
    return jsonify(message="注册成功"), 201

@app.route('/activity', methods=['POST'])
def create_activity():
    name = request.form['name']
    description = request.form['description']
    activity = Activity(name=name, description=description)
    db.session.add(activity)
    db.session.commit()
    return jsonify(message="活动创建成功"), 201

@app.route('/feedback', methods=['POST'])
def submit_feedback():
    participant_id = request.form['participant_id']
    activity_id = request.form['activity_id']
    feedback = request.form['feedback']
    participant = Participant.query.get(participant_id)
    activity = Activity.query.get(activity_id)
    participant.self_management_score += float(feedback)
    db.session.commit()
    return jsonify(message="反馈提交成功"), 201

@app.route('/report', methods=['GET'])
def get_report():
    participant_id = request.args.get('participant_id')
    participant = Participant.query.get(participant_id)
    report = {
        'name': participant.name,
        'self_management_score': participant.self_management_score
    }
    return jsonify(report), 200

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```

### 6.3 代码应用解读与分析

1. **数据库设计**：我们使用SQLAlchemy作为ORM（对象关系映射）工具，简化数据库操作。数据库包含两个表：`Participant` 和 `Activity`。
   
2. **用户注册**：`register` 函数处理用户注册请求，接收用户名和自我管理能力分数，将其存储在 `Participant` 表中。

3. **活动创建**：`create_activity` 函数处理活动创建请求，接收活动名称和描述，将其存储在 `Activity` 表中。

4. **反馈提交**：`submit_feedback` 函数处理用户提交反馈请求，根据用户ID和活动ID更新用户的自我管理能力分数。

5. **报告获取**：`get_report` 函数处理获取报告请求，根据用户ID返回用户的自我管理能力分数。
