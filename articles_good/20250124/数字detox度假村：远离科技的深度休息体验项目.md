## 1. 数字detox介绍

### 1.1 数字detox的定义

数字detox，也称为数字戒毒或数字排毒，指的是人们有意识地减少对数字设备的依赖，以获得身体和心灵的休息。这包括但不限于减少智能手机、电脑、平板电脑等数字设备的接触时间，甚至是完全远离这些设备一段时间。

### 1.2 数字detox的重要性

随着科技的发展，数字设备已经成为我们生活中不可或缺的一部分。然而，过度依赖数字设备不仅会导致身体健康问题，如视力疲劳、颈椎病等，还会对心理健康产生负面影响，如焦虑、抑郁等。因此，进行数字detox对于维护身体健康和心理健康具有重要意义。

### 1.3 数字detox的历史与发展

数字detox这一概念最早可以追溯到2010年代初期。随着人们对智能手机和社交媒体的依赖程度不断增加，数字detox开始受到关注。2017年，美国作家Cal Newport在《深度工作：如何有效利用每一点脑力》一书中提出了“数字排毒”的概念，引起了广泛的讨论。此后，数字detox逐渐成为一种生活方式。

### 1.4 数字detox的理论基础

数字detox的理论基础主要涉及两个方面：心理学和生物学。

从心理学角度来看，数字detox旨在减少个体对数字设备的依赖，从而提高专注力和创造力。心理学研究表明，过度使用数字设备会导致个体的多任务处理能力下降，影响深度工作。

从生物学角度来看，数字detox有助于减轻身体疲劳和心理压力。长时间使用数字设备会导致眼睛疲劳、颈椎病等身体问题。此外，心理压力也会对身体健康产生负面影响。

from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///detox_db.sqlite3'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password = db.Column(db.String(120), nullable=False)
    is_admin = db.Column(db.Boolean, default=False)

class Booking(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    start_date = db.Column(db.Date, nullable=False)
    end_date = db.Column(db.Date, nullable=False)

@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    user = User.query.filter_by(username=username, password=password).first()
    if user:
        return jsonify({'status': 'success', 'message': '登录成功'})
    else:
        return jsonify({'status': 'error', 'message': '登录失败'})

@app.route('/book_room', methods=['POST'])
def book_room():
    user_id = request.form['user_id']
    start_date = request.form['start_date']
    end_date = request.form['end_date']
    new_booking = Booking(user_id=user_id, start_date=start_date, end_date=end_date)
    db.session.add(new_booking)
    db.session.commit()
    return jsonify({'status': 'success', 'message': '预订成功'})

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
