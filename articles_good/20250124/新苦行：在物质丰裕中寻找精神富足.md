**3.2 实践技巧与方法**

```python
def simplify_life(items):
    valuable_items = []
    unnecessary_items = []

    for item in items:
        if is_valuable(item):
            valuable_items.append(item)
        else:
            unnecessary_items.append(item)

    return valuable_items, unnecessary_items

def is_valuable(item):
    # 判断物品是否具有价值
    # 例如：书籍、衣物等有纪念意义的物品通常被认为是具有价值的
    return item in ["书", "衣服"]

items = ["书", "衣服", "电器", "废纸"]
valuable_items, unnecessary_items = simplify_life(items)
print("有价值物品:", valuable_items)
print("无价值物品:", unnecessary_items)
```

在这个示例中，`simplify_life` 函数接收一个物品列表，通过 `is_valuable` 函数判断每个物品是否具有价值，然后将物品分为有价值和无价值两类。
