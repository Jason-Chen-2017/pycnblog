**数学模型与公式**

1. **无意义感量表（Nihilistic Ideation Scale）**

无意义感量表是一种用于评估个体无意义感程度的工具。其计算公式如下：

\[ NIS = \frac{\sum_{i=1}^{n} (X_i - \mu)}{\sigma} \]

其中，\( NIS \) 是无意义感量表得分，\( X_i \) 是第 \( i \) 个问题的得分，\( \mu \) 是所有问题的平均得分，\( \sigma \) 是标准差。得分越高，表示个体的无意义感越强。

2. **心灵觉醒指数（Mindfulness Awakening Index）**

心灵觉醒指数用于衡量个体在心灵觉醒过程中的进步。其计算公式如下：

\[ MAI = \frac{SA + PA + AA + RA + CI}{5} \]

其中，\( MAI \) 是心灵觉醒指数，\( SA \) 是自我探索得分，\( PA \) 是心理疗法得分，\( AA \) 是艺术与心灵觉醒得分，\( RA \) 是宗教与心灵觉醒得分，\( CI \) 是社区与心灵觉醒得分。每个得分范围从 0 到 10，总分越高，表示个体在心灵觉醒方面的进步越大。

3. **生命意义感（Sense of Life Meaning）**

生命意义感是衡量个体对生活意义的认知程度。其计算公式如下：

\[ SLM = \frac{\sum_{i=1}^{n} (L_i \cdot W_i)}{\sum_{i=1}^{n} W_i} \]

其中，\( SLM \) 是生命意义感得分，\( L_i \) 是第 \( i \) 个生活领域的意义感得分，\( W_i \) 是第 \( i \) 个生活领域的权重。通过计算各个生活领域的得分，可以得到个体对生命意义的整体认知。

4. **心理弹性（Psychological Resilience）**

心理弹性是指个体在面对压力和挑战时的适应能力。其计算公式如下：

\[ PR = \frac{\sum_{i=1}^{n} (S_i \cdot C_i)}{\sum_{i=1}^{n} C_i} \]

其中，\( PR \) 是心理弹性得分，\( S_i \) 是第 \( i \) 个应对策略的有效性得分，\( C_i \) 是第 \( i \) 个应对策略的使用频率。得分越高，表示个体的心理弹性越强。

### 系统核心实现

1. **数据库配置**：
   - 创建数据库和用户表：
     ```python
     from flask_sqlalchemy import SQLAlchemy
     
     app = Flask(__name__)
     app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql+pymysql://username:password@localhost/mind_awareness_db'
     db = SQLAlchemy(app)
     
     class User(db.Model):
         id = db.Column(db.Integer, primary_key=True)
         username = db.Column(db.String(80), unique=True, nullable=False)
         password = db.Column(db.String(120), nullable=False)
         email = db.Column(db.String(120), unique=True, nullable=False)
     ```

2. **用户注册与登录**：
   - 注册功能：
     ```python
     from flask import request, redirect, url_for
     
     def register():
         username = request.form['username']
         password = request.form['password']
         email = request.form['email']
         
         new_user = User(username=username, password=password, email=email)
         db.session.add(new_user)
         db.session.commit()
         
         return redirect(url_for('login'))
     ```
   - 登录功能：
     ```python
     def login():
         username = request.form['username']
         password = request.form['password']
         
         user = User.query.filter_by(username=username).first()
         if user and user.password == password:
             return redirect(url_for('dashboard'))
         else:
             return '登录失败'
     ```

3. **自我探索模块**：
   - 记录内心反思日志：
     ```python
     def log_reflection():
         user_id = request.form['user_id']
         reflection = request.form['reflection']
         
         user = User.query.get(user_id)
         user.reflection = reflection
         db.session.commit()
         
         return redirect(url_for('dashboard'))
     ```
