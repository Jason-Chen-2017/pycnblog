### 1.1 区块链技术的起源与发展

#### 1.1.1 区块链的定义与核心特性
区块链是一种去中心化的分布式账本技术，通过密码学保证数据的安全性，并通过共识机制实现数据的一致性。其核心特性包括：
- **去中心化**：无须依赖中心机构，数据由所有节点共同维护。
- **不可篡改性**：数据一旦写入区块链，无法被修改或删除。
- **透明性**：所有交易记录对参与者公开可见。
- **匿名性**：参与者身份可通过加密地址部分隐藏。

#### 1.1.2 区块链的演进历程
区块链技术起源于比特币的白皮书，经历了从1.0（比特币）到2.0（智能合约）再到3.0（去中心化应用）的发展阶段。目前，区块链技术已经广泛应用于金融、医疗、法律等多个领域。

#### 1.1.3 区块链在企业估值中的应用前景
区块链技术的透明性和不可篡改性为企业估值提供了新的可能性。通过区块链记录企业资产、交易数据等信息，可以提高数据的可信度，从而提升估值的准确性。

### 5.2 系统核心实现源代码

#### 5.2.1 智能合约实现
以下是投票系统的智能合约代码（Solidity）：

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract VotingSystem {
    struct Voter {
        uint contribution;
        bool isRegistered;
    }

    struct Proposal {
        string title;
        uint endTime;
    }

    mapping(address => Voter) public voters;
    mapping(bytes32 => Proposal) public proposals;

    function registerVoter(address voter) public {
        voters[voter] = Voter(0, false);
    }

    function createProposal(string memory title) public {
        Proposal memory proposal = Proposal(title, block.timestamp + 1 days);
        proposals[keccak256(abi.encode(title))] = proposal;
    }

    function vote(bytes32 proposalId, uint weight) public {
        require(block.timestamp < proposals[proposalId].endTime, "投票已截止");
        voters[msg.sender].contribution += weight;
    }

    function getVoteResult(bytes32 proposalId) public view returns (uint totalWeight, uint result) {
        Proposal memory proposal = proposals[proposalId];
        require(block.timestamp >= proposal.endTime, "投票未截止");
        uint weight = 0;
        for (uint i = 0; i < voters.length; i++) {
            if (voters[i].contribution > 0) {
                weight += voters[i].contribution;
            }
        }
        result = weight / 2;
        return (weight, result);
    }
}
```
