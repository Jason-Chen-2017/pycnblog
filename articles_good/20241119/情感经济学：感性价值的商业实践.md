## 第3章：感性价值的测量与评估

### 3.1 感性价值的概念

感性价值是指消费者在购买和消费过程中感受到的情感满足，它是情感经济学研究的重要概念。感性价值不同于传统经济学中的价格、质量等客观指标，它更多地关注消费者主观的感受和体验。

### 3.2 感性价值的测量方法

测量感性价值的方法包括问卷调查、深度访谈、行为实验等。以下是一些常用的测量方法：

1. **问卷调查**：通过设计问卷，收集消费者对产品或服务的情感反应。
2. **深度访谈**：与消费者进行一对一的访谈，深入了解他们的情感体验。
3. **行为实验**：通过设计实验，观察消费者在特定情境下的行为反应。

### 3.3 感性价值的评估模型

评估感性价值的方法包括基于情感的盈利模型、基于价值的盈利模型等。以下是一些常见的评估模型：

1. **基于情感的盈利模型**：通过分析消费者情感，预测产品的盈利能力。
2. **基于价值的盈利模型**：通过分析消费者对产品价值的感知，评估产品的市场潜力。

# 输出：感性价值得分

    # 计算情感平均值
    average_emotion = sum(consumer_emotions) / len(consumer_emotions)

    std_emotion = std(consumer_emotions)

    sensory_value_score = (average_emotion / std_emotion) * 100
    
    return sensory_value_score
