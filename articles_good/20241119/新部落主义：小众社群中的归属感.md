1. **认同感**：个体认同群体成员的身份和价值观，愿意接受和遵循群体的规范和准则。
2. **安全感**：个体在群体中感受到的安全、被接受和保护的心理状态。
3. **归属感**：个体感受到自己是群体的一部分，拥有群体的支持和认同。

归属感的理论包括社会认同理论、社会归属理论和社会交换理论等。社会认同理论认为，归属感是个体通过比较自我与群体的差异而产生的心理状态；社会归属理论强调群体内部成员之间的情感联系和互动；社会交换理论则认为，归属感是个体与群体之间互动和资源交换的结果。

```python
# app.py

from flask import Flask, render_template, request, redirect, url_for
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///users.db'
db = SQLAlchemy(app)

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)

@app.route('/')
def index():
    users = User.query.all()
    return render_template('index.html', users=users)

@app.route('/register', methods=['GET', 'POST'])
def register():
    if request.method == 'POST':
        new_user = User(username=request.form['username'], email=request.form['email'])
        db.session.add(new_user)
        db.session.commit()
        return redirect(url_for('index'))
    return render_template('register.html')

if __name__ == '__main__':
    db.create_all()
    app.run(debug=True)
```
