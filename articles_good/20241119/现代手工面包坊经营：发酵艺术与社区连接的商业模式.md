### 附录A：发酵技术的详细说明

发酵技术是面包制作中至关重要的环节，它不仅决定了面包的口感和质地，还对面包的营养价值产生重要影响。以下是发酵技术的详细说明：

#### 1. 发酵剂的种类

发酵剂主要包括酵母、乳酸菌和天然酵母等。酵母是一种微生物，能够在适宜的温度和湿度下分解面包中的糖分和淀粉，产生二氧化碳气体，使面包膨胀。乳酸菌则主要应用于酸奶、发酵面包等食品中，其代谢产物具有抗菌作用，有助于改善食品的口感和质地。天然酵母是从自然界中筛选出来的微生物，具有较强的适应性和发酵能力。

#### 2. 发酵过程

发酵过程可以分为四个阶段：糖化、醇化、酸化和成熟。糖化阶段是指酵母分解面包中的糖分，产生醇和二氧化碳。醇化阶段是指醇在酵母的作用下进一步分解，产生二氧化碳和酸。酸化阶段是指乳酸菌代谢产生乳酸，使面包的pH值下降。成熟阶段是指发酵达到最佳状态，面包的口感和质地达到理想状态。

#### 3. 操作要点

在发酵过程中，温度、湿度和时间是关键因素。通常，酵母发酵的最佳温度为25-30℃，湿度为70%-80%。过高或过低的温度都会影响发酵效果。发酵时间则根据面包种类和发酵剂的种类而有所不同，通常为1-3小时。

def sugar_decomposition(dough):

    # 醇分解过程
    return dough * np.exp(-0.1 * (temperature - 30) * (humidity - 0.7))

def acid_generation(dough, temperature, humidity):
    # 酸生成过程
    return dough * np.exp(-0.05 * (temperature - 30) * (humidity - 0.7))

def maturity(dough):
    # 成熟过程
    return dough * np.random.normal(1, 0.1)

def fermentation(dough, temperature, humidity):
    # 发酵过程
    dough = sugar_decomposition(dough)
    dough = alcohol_decomposition(dough, temperature, humidity)
    dough = acid_generation(dough, temperature, humidity)
    dough = maturity(dough)
    return dough
