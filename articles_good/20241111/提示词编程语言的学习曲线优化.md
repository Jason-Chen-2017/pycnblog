#### 4.2 排序算法

排序算法是计算机科学中常见的一类算法，用于对数据进行排序。以下介绍几种常见的排序算法。

##### 4.2.1 冒泡排序

冒泡排序是一种简单的排序算法，通过不断比较和交换相邻的元素，将数据按升序或降序排列。

**冒泡排序伪代码**：
```c
for i from 0 to n-1 do
    for j from 0 to n-i-1 do
        if arr[j] > arr[j+1] then
            swap(arr[j], arr[j+1])
        end if
    end for
end for
```

**示例代码**：
```c
#include <stdio.h>

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    bubbleSort(arr, n);
    
    printf("Sorted array: \n");
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    
    return 0;
}
```

##### 4.2.2 选择排序

选择排序是一种简单的排序算法，通过每次选择未排序部分的最小（或最大）元素，将其放到已排序部分的末尾。

**选择排序伪代码**：
```c
for i from 0 to n-1 do
    min_index = i
    for j from i+1 to n do
        if arr[j] < arr[min_index] then
            min_index = j
        end if
    end for
    swap(arr[i], arr[min_index])
end for
```

**示例代码**：
```c
#include <stdio.h>

void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_index = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[min_index]) {
                min_index = j;
            }
        }
        int temp = arr[min_index];
        arr[min_index] = arr[i];
        arr[i] = temp;
    }
}

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    selectionSort(arr, n);
    
    printf("Sorted array: \n");

    return 0;
}
```

##### 4.2.3 插入排序

插入排序是一种简单的排序算法，通过将未排序部分的元素插入到已排序部分正确的位置，实现排序。

**插入排序伪代码**：
```c
for i from 1 to n-1 do
    key = arr[i]
    j = i - 1
    while j >= 0 and arr[j] > key do
        arr[j+1] = arr[j]
        j = j - 1
    end while
    arr[j+1] = key
end for
```

**示例代码**：
```c

void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j = j - 1;
        }
        arr[j + 1] = key;
    }
}

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    insertionSort(arr, n);
    
    printf("Sorted array: \n");

    }

    return 0;
}
```

### 4.3 搜索算法

搜索算法是计算机科学中用于在数据集合中查找特定数据的一类算法。以下介绍几种常见的搜索算法。

#### 4.3.1 线性搜索

线性搜索是一种简单的搜索算法，逐个检查数据集合中的元素，直到找到目标元素或检查完所有元素。

**线性搜索伪代码**：
```c
function linear_search(arr, target):
    for i from 0 to n-1 do
        if arr[i] == target then
            return i
        end if
    end for
    return -1
```

**示例代码**：
```c
#include <stdio.h>

int linearSearch(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return i;
        }
    }
    return -1;
}

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);
    int target = 25;
    
    int index = linearSearch(arr, n, target);
    
    if (index != -1) {
        printf("Element %d found at index %d\n", target, index);
    } else {
        printf("Element %d not found\n", target);
    }
    
    return 0;
}
```

#### 4.3.2 二分搜索

二分搜索是一种高效的搜索算法，适用于有序数据集合。它通过不断地将数据集合分为两部分，逐步缩小搜索范围，直到找到目标元素或确定元素不存在。

**二分搜索伪代码**：
```c
function binary_search(arr, target):
    low = 0
    high = n - 1
    while low <= high do
        mid = (low + high) / 2
        if arr[mid] == target then
            return mid
        else if arr[mid] < target then
            low = mid + 1
        else
            high = mid - 1
        end if
    end while
    return -1
```

**示例代码**：
```c
#include <stdio.h>

int binarySearch(int arr[], int n, int target) {
    int low = 0;
    int high = n - 1;
    
    while (low <= high) {
        int mid = (low + high) / 2;
        
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] < target) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }
    
    return -1;
}

int main() {
    int arr[] = {2, 5, 7, 10, 15, 18, 20, 25, 30, 35};
    int n = sizeof(arr) / sizeof(arr[0]);

        printf("Element %d not found\n", target);
    }
    
    return 0;
}
```

**案例：计算两个数的最大公约数**

**需求**：编写一个程序，计算两个整数的最大公约数。

**解决方案**：

1. **输入两个整数**：使用`input`函数从用户输入两个整数。
2. **使用辗转相除法计算最大公约数**：辗转相除法是一种常用的计算最大公约数的方法，通过不断用较大数除以较小数，直到余数为0，得到最大公约数。
3. **输出结果**：将计算出的最大公约数输出到控制台。

**代码实现**：
```c
#include <stdio.h>

int gcd(int a, int b) {
    int temp;
    while (b != 0) {
        temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    int num1, num2;
    printf("Enter two integers: ");
    scanf("%d %d", &num1, &num2);
    
    int result = gcd(num1, num2);
    printf("The greatest common divisor of %d and %d is %d\n", num1, num2, result);
    
    return 0;
}
```
