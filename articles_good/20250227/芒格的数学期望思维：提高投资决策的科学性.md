# 2. 数学期望的基本概念与原理

## 2.1 数学期望的定义与公式

### 2.1.1 数学期望的严格定义

数学期望是概率论中的基本概念，用于描述随机变量的平均值。其公式为：

$$ E[X] = \sum_{i=1}^{n} x_i P(x_i) $$

其中，\( E[X] \) 是随机变量 \( X \) 的期望值，\( x_i \) 是可能的取值，\( P(x_i) \) 是对应概率。

### 2.1.2 数学期望的性质与特点

数学期望具有线性性质，即：

$$ E[aX + b] = aE[X] + b $$

其中，\( a \) 和 \( b \) 是常数。

---

## 2.2 数学期望的直观理解

### 2.2.1 数学期望的几何意义

数学期望可以看作是概率分布在数轴上的重心，表示了随机变量在长期重复实验中的平均值。

### 2.2.2 数学期望与概率分布的关系

数学期望与概率分布密切相关，它是概率分布的加权平均值，反映了分布的中心位置。

### 2.2.3 数学期望的现实意义

在投资中，数学期望可以帮助投资者量化投资的预期收益和风险，为决策提供科学依据。

## 2.4 数学期望的计算方法

### 2.4.1 离散型随机变量的期望计算

对于离散型随机变量 \( X \)，其期望值为：

$$ E[X] = \sum_{i=1}^{n} x_i P(x_i) $$

### 2.4.2 连续型随机变量的期望计算

对于连续型随机变量 \( X \)，其期望值为：

$$ E[X] = \int_{-\infty}^{\infty} x f(x) dx $$

其中，\( f(x) \) 是概率密度函数。

### 2.4.3 期望值的线性性质

期望值的线性性质为：

## 5.4 投资组合优化的代码实现

### 5.4.1 Python代码示例

```python
import numpy as np
import pandas as pd

# 读取数据
data = pd.read_csv('stock_prices.csv')

# 计算收益率
returns = data.pct_change()

# 计算期望收益
expected_returns = returns.mean()

# 计算协方差矩阵
cov_matrix = returns.cov()

# 使用均值-方差优化
from pypfopt import EfficientFrontier

ef = EfficientFrontier(n_assets=len(expected_returns), mu=expected_returns, Sigma=cov_matrix)
weights = ef.max_sharpe()

# 输出最优权重
print(weights)
```

## 附录 B：投资组合优化的Python代码示例

```python
import numpy as np
import pandas as pd

# 读取数据
data = pd.read_csv('stock_prices.csv')

# 计算收益率
returns = data.pct_change()

# 计算期望收益
expected_returns = returns.mean()

# 计算协方差矩阵
cov_matrix = returns.cov()

# 使用均值-方差优化
from pypfopt import EfficientFrontier

ef = EfficientFrontier(n_assets=len(expected_returns), mu=expected_returns, Sigma=cov_matrix)
weights = ef.max_sharpe()

# 输出最优权重
print(weights)
```
