### 3.2.2 核心算法的Python代码实现

以下是一个多元思维模型的Python代码示例：

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义各个子模型
def model_i(x, a_i, b_i):
    return a_i * x + b_i

# 定义整体模型
def f(x, models):
    return sum(model_i(x, a_i, b_i) for model_i, a_i, b_i in models)

# 示例数据
models = [
    (lambda x: 1*x + 0, 1, 0),
    (lambda x: 2*x + 3, 2, 3),
    (lambda x: 0.5*x + 5, 0.5, 5)
]

x = np.linspace(0, 10, 100)
f_x = f(x, models)

plt.plot(x, f_x)
plt.xlabel('x')
plt.ylabel('f(x)')
plt.show()
```

    return a_i * x + b_i

    return sum(model_i(x, a_i, b_i) for model_i, a_i, b_i in models)
