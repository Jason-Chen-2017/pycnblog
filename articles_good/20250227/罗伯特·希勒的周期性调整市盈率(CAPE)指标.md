## 第1章: 罗伯特·希勒的周期性调整市盈率(CAPE)概述

### 1.1 传统市盈率的局限性
#### 1.1.1 市盈率的基本概念
市盈率（Price-to-Earnings Ratio，简称P/E）是衡量股票估值的重要指标，计算公式为：
$$P/E = \frac{\text{股价}}{\text{每股净利润}}$$  
市盈率反映了市场对每股收益的支付水平，但其局限性在于无法充分考虑经济周期波动对股价的影响。

#### 1.1.2 传统市盈率的缺陷
- 市盈率受短期经济波动影响较大，无法反映长期趋势。
- 在经济繁荣时期，市盈率可能被高估；在经济衰退时期，市盈率可能被低估。
- 传统市盈率未充分考虑企业盈利的周期性变化，可能导致估值偏差。

#### 1.1.3 经济周期波动对市盈率的影响
经济周期的波动会导致企业盈利和股价的波动，从而影响市盈率的准确性。在经济繁荣时期，企业盈利增长可能推动股价上涨，但市盈率未必能准确反映真实的估值。

### 1.2 罗伯特·希勒与CAPE的提出
#### 1.2.1 罗伯特·希勒的学术背景
罗伯特·希勒是美国耶鲁大学的经济学家，以其对市场波动性和估值的研究闻名。他提出的CAPE指标旨在克服传统市盈率的局限性。

#### 1.2.2 CAPE指标的提出动机
希勒认为，传统市盈率未能充分考虑经济周期对企业盈利的影响，尤其是在经济衰退期间，企业盈利可能大幅下降，导致市盈率失真。因此，他提出CAPE指标，通过调整企业盈利的周期性波动，提供更准确的估值指标。

#### 1.2.3 CAPE与传统市盈率的区别
CAPE与传统市盈率的主要区别在于其对盈利周期性波动的调整。传统市盈率仅考虑当前盈利，而CAPE使用过去10年的平均盈利数据，以消除短期波动的影响。

### 1.3 CAPE指标的核心理念
#### 1.3.1 周期性调整的基本概念
周期性调整是指通过对企业盈利的长期平均值进行调整，以消除短期经济波动的影响。CAPE指标通过使用过去10年的平均盈利数据，反映了企业盈利的长期趋势。

#### 1.3.2 市盈率与经济周期的关系
市盈率与经济周期密切相关。在经济繁荣时期，市盈率可能偏高；在经济衰退时期，市盈率可能偏低。通过周期性调整，可以更准确地反映企业的长期估值。

#### 1.3.3 CAPE指标的定义与公式
CAPE（周期性调整市盈率）的公式为：
$$CAPE = \frac{\text{当前股价}}{\text{过去10年平均净利润}}$$  
其中，过去10年平均净利润是指过去10年中每年净利润的几何平均值。

### 1.4 CAPE指标的经济意义
#### 1.4.1 CAPE在股市估值中的作用
CAPE指标通过调整企业盈利的周期性波动，提供了更为准确的股市估值指标。它可以帮助投资者更好地识别市场泡沫和低估。

#### 1.4.2 CAPE与市场泡沫的关系
在市场泡沫期间，股价可能远高于企业实际盈利水平，导致CAPE指标偏高。通过分析CAPE指标的变化趋势，可以帮助投资者识别市场泡沫。

#### 1.4.3 CAPE在投资决策中的应用
投资者可以通过分析CAPE指标的变化趋势，判断市场的长期估值水平，并据此进行投资决策。例如，当CAPE指标远高于历史平均水平时，可能意味着市场被高估，投资者应谨慎投资。

## 第2章: CAPE指标的核心概念与数学模型

### 2.1 CAPE指标的公式推导
#### 2.1.1 市盈率的基本公式
市盈率的计算公式为：
$$P/E = \frac{\text{股价}}{\text{每股净利润}}$$  
其中，每股净利润是企业过去一年的净利润。

#### 2.1.2 周期性调整的数学模型
周期性调整的核心思想是通过对企业盈利的长期平均值进行调整，消除短期波动的影响。数学上，周期性调整的净利润可以表示为过去10年的平均净利润的几何平均值：
$$\text{几何平均净利润} = \left(\prod_{i=1}^{10} \text{净利润}_i\right)^{1/10}$$  

#### 2.1.3 CAPE指标的最终公式
将几何平均净利润代入市盈率的公式，得到CAPE指标的计算公式：
$$CAPE = \frac{\text{股价}}{\text{几何平均净利润}}$$  

### 2.2 CAPE指标的属性特征对比
#### 2.2.1 CAPE与传统市盈率的对比分析
| 特性                | 传统市盈率                 | CAPE指标                   |
|---------------------|--------------------------|--------------------------|
| 计算基础            | 当前年净利润               | 过去10年平均净利润         |
| 时间跨度            | 1年                       | 10年                      |
| 对周期性波动的处理 | 未调整                   | 已调整                   |
| 优点                | 计算简单                 | 更能反映长期趋势         |
| 缺点                | 易受短期波动影响           | 计算复杂                 |

#### 2.2.2 CAPE与其他估值指标的对比
除了传统市盈率，CAPE还与其他估值指标如市净率（P/B）、股息率（Dividend Yield）等进行对比。CAPE的优势在于其对周期性波动的调整，使其更能反映企业的长期估值。

#### 2.2.3 CAPE指标的优缺点分析
- **优点**：通过周期性调整，CAPE指标能够更准确地反映企业的长期估值，减少短期波动的影响。
- **缺点**：计算复杂，且需要较长的历史数据支持。

#### 3.1.4 结果分析

### 3.2 CAPE指标的Python实现
#### 3.2.1 数据获取与处理
```python
import pandas as pd
import yfinance as yf

# 获取苹果公司过去10年的股价和净利润数据
data = yf.Ticker('AAPL').history(period='10y')
data = data[['Close', 'adj_close']]  # 获取收盘价和调整后收盘价
data.columns = ['股价', '调整后股价']
```

#### 3.2.2 几何平均净利润计算
```python
def calculate_cape(ticker):
    # 获取过去10年的净利润数据
    data = yf.Ticker(ticker).financials
    net_income = data.loc['net income', :].values
    # 计算几何平均净利润
    geometric_mean = (net_income.prod()) ** (1/len(net_income))
    return geometric_mean

# 计算苹果公司的几何平均净利润
geometric_mean_aapl = calculate_cape('AAPL')
print(f"苹果公司几何平均净利润为：{geometric_mean_aapl}")
```

#### 3.2.3 CAPE指标计算
```python
def calculate_cape(ticker):
    # 获取股价数据
    data = yf.Ticker(ticker).history(period='10y')
    current_price = data.iloc[-1]['Close']
    # 获取过去10年的净利润数据
    financials = yf.Ticker(ticker).financials
    net_income = financials.loc['net income', :].values
    # 计算几何平均净利润
    geometric_mean = (net_income.prod()) ** (1/len(net_income))
    # 计算CAPE
    cape = current_price / geometric_mean
    return cape

# 计算苹果公司的CAPE
cape_aapl = calculate_cape('AAPL')
print(f"苹果公司当前的CAPE为：{cape_aapl}")
```

#### 3.2.4 结果分析
通过上述代码，我们可以计算出苹果公司的CAPE指标，并将其与历史平均水平进行对比，分析市场估值水平。
