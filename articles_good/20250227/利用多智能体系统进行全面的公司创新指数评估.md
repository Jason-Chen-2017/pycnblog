### 1.1.1 多智能体系统的定义

多智能体系统（Multi-Agent System, 简称MAS）是由多个智能体（Agent）组成的分布式系统，这些智能体能够通过交互和协作完成特定任务。每个智能体都是一个具备感知、决策和执行能力的实体，能够独立工作，同时与其他智能体协同完成复杂任务。

$$\text{多智能体系统} = \{A_1, A_2, ..., A_n\}$$

其中，$A_i$ 表示第 $i$ 个智能体，每个智能体具备以下核心特征：

1. **自主性**：智能体能够自主决策和行动。
2. **反应性**：智能体能够感知环境并实时响应。
3. **协作性**：智能体能够与其他智能体协作完成任务。
4. **社会性**：智能体具备一定的社会行为，能够进行通信和协商。

| 反应性 | 智能体能够实时感知环境并做出反应。 |
| 动态性 | 系统环境和任务需求可能动态变化。 |

class InnovationIndexCalculator:
    def __init__(self):
        self.data = pd.DataFrame()
        self.weights = {
            '专利数量': 0.4,
            '新产品研发数量': 0.3,
            '创新团队人数': 0.2,
            '创新文化评分': 0.1
        }

    def calculate_index(self, data):
        # 计算创新指数
        innovation_index = 0
        for column in data.columns:
            innovation_index += self.weights[column] * data[column].values[0]
        return innovation_index
