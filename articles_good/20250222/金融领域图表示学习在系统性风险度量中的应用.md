# 第一章：系统性风险与图表示学习背景

## 1.1 系统性风险的基本概念

### 1.1.1 系统性风险的定义
系统性风险是指由于金融系统中某些关键因素的变化，导致整个系统发生连锁反应，引发大规模金融波动或危机的风险。这种风险通常来源于金融机构之间的高度关联性和相互依赖性。

### 1.1.2 系统性风险的影响
系统性风险的影响是全局性的，一旦发生，可能会引发市场崩盘、金融机构破产以及经济衰退等严重后果。因此，准确度量和预警系统性风险对于金融稳定具有重要意义。

### 1.1.3 传统风险度量方法的局限性
传统的风险度量方法通常基于单个金融机构的个体风险，难以捕捉系统性风险的网络特征和相互关联性。例如，VaR（Value at Risk）和CVaR（Conditional Value at Risk）等方法仅考虑单个资产或机构的风险，忽略了系统性风险的传播路径和网络结构。

---

## 1.2 图表示学习的背景与意义

### 1.2.1 图表示学习的定义
图表示学习是一种将图结构数据中的节点或边映射到低维向量空间的技术，旨在保留图的结构特征和语义信息。通过图表示学习，可以将复杂的金融网络简化为易于处理的向量表示。

### 1.2.2 图表示学习在金融领域的优势
在金融领域，图表示学习可以有效捕捉金融机构之间的关联性，揭示系统性风险的传播路径和关键节点。相比于传统方法，图表示学习能够更好地应对金融网络的动态变化和复杂性。

### 1.2.3 系统性风险度量中的应用潜力
通过图表示学习，可以构建金融网络的低维嵌入，用于识别系统性风险的关键节点、检测异常交易模式以及评估风险传播的路径和影响。

本章介绍了系统性风险的基本概念及其对金融稳定的影响，分析了传统风险度量方法的局限性，并提出了图表示学习在系统性风险度量中的潜力和意义。

# 第二章：图表示学习的核心概念

## 2.1 图论基础

### 2.1.1 图的基本概念
- **节点**：图中的基本单元，表示金融机构、资产或交易。
- **边**：连接节点的边，表示金融机构之间的关联性或资产之间的交易关系。
- **图的属性**：包括节点度、边权重、图的密度等。

### 2.1.2 图的表示方式
- **邻接矩阵**：直接表示节点之间的连接关系。
- **邻接列表**：以列表形式表示节点的邻居。
- **图的特征向量**：通过矩阵分解或特征分解提取图的特征。

### 2.1.3 图的属性特征
- **节点度**：节点的连接边数，反映节点的重要性和影响力。
- **中心性**：节点在图中的中心程度，包括度中心性、中间中心性等。
- **社区结构**：图中节点的聚类特征，反映金融机构之间的集群关系。

---

## 2.2 图表示学习的基本原理

### 2.2.1 节点表示
节点表示的目标是将图中的每个节点映射到低维向量空间，同时保留节点的局部和全局特征。例如，使用Node2Vec算法可以通过随机游走生成节点表示。

### 2.2.2 边表示
边表示的目标是捕捉节点之间关系的语义信息，例如使用边嵌入模型（如GraphSAGE）来生成边的向量表示。

### 2.2.3 图结构信息的捕获
图表示学习需要捕捉图的全局结构信息，例如图的连通性、社区结构等。可以通过图卷积网络（Graph Convolutional Networks, GCNs）等方法实现。

---

## 2.3 图嵌入方法

### 2.3.1 基于矩阵分解的图嵌入
- **方法**：通过矩阵分解（如SVD）将图的邻接矩阵分解为低维向量。
- **优点**：计算效率高，易于实现。
- **缺点**：难以捕捉图的非线性特征。

### 2.3.2 基于神经网络的图嵌入
- **方法**：使用深度学习模型（如GCN、GraphSAGE）进行图嵌入。
- **优点**：能够捕捉图的非线性特征和高层次语义信息。
- **缺点**：计算复杂度较高，需要大量训练数据。

### 2.3.3 对比学习在图嵌入中的应用
- **方法**：通过对比学习，将图中的节点或边映射到统一的向量空间。
- **优点**：能够有效区分不同节点或边的特征。
- **缺点**：需要设计合适的对比损失函数。

---

## 2.4 本章小结
本章介绍了图表示学习的核心概念，包括图论基础、图表示学习的基本原理以及常用的图嵌入方法。

## 7.3 模型实现

### 7.3.1 图表示学习模型实现
```python
import torch
import torch.nn as nn

class GCN(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GCN, self).__init__()
        self.embeddings = nn.Parameter(torch.randn(input_dim, hidden_dim))
        self.W = nn.Parameter(torch.randn(hidden_dim, output_dim))
    
    def forward(self, A, x):
        x = torch.matmul(A, x)
        x = torch.matmul(x, self.embeddings)
        x = torch.relu(x)
        x = torch.matmul(x, self.W)
        return x
```
