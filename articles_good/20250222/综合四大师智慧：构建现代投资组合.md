## 第一部分：投资学的基石——四大师智慧

### 第1章：四大师概述

#### 1.1 投资学的发展史

- **1.1.1 投资学的起源与演变**
  - 投资学的起源可以追溯到古代的商业活动和金融交易。
  - 19世纪末至20世纪初，现代投资理论开始形成，如道琼斯指数的创立。
  - 20世纪30年代，本杰明·格雷厄姆提出价值投资理论，奠定了现代投资学的基础。
  - 20世纪60年代，约翰·邓普勒的研究推动了理性决策框架的发展。
  - 20世纪70年代至今，现代投资组合理论（MPT）和资本资产定价模型（CAPM）成为主流。

- **1.1.2 传统投资理论的局限性**
  - 传统投资理论过于依赖历史数据，忽视了市场参与者的主观决策。
  - 格雷厄姆指出，市场波动性和投资者情绪会影响资产价格。
  - 费雪的成长性投资理念补充了传统理论的不足。

#### 1.2 四大师简介

- **1.2.1 本杰明·格雷厄姆：价值投资之父**
  - 格雷厄姆是哥伦比亚大学的教授，著有《证券分析》和《聪明的投资者》。
  - 他提出“安全边际”概念，强调以低于内在价值的价格买入资产。

- **1.2.2 菲利普·费雪：成长投资的倡导者**
  - 费雪是另一位哥伦比亚大学教授，著有《成长股的哲学》。
  - 他强调选择具有持续增长潜力的企业，关注企业的管理团队和竞争优势。

- **1.2.3 约翰·邓普勒：理性投资的实践者**
  - 邓普勒是芝加哥大学的教授，著有《投资学精要》。
  - 他提出了理性决策框架，强调通过基本面分析和风险控制来构建投资组合。

- **1.2.4 沃伦·巴菲特：整合四大师智慧的投资大师**
  - 巴菲特是格雷厄姆的学生，同时也是费雪和邓普勒理念的践行者。
  - 他成功地将价值投资、成长投资和理性决策框架整合，构建了独特的投资策略。

#### 1.3 四大师理论的核心要点

- **1.3.1 格雷厄姆的防御性投资策略**
  - 强调安全边际，通过买入低于内在价值的资产来降低风险。
  - 适合保守型投资者，注重长期稳健的收益。

- **1.3.2 费雪的成长性投资理念**
  - 关注企业的成长潜力和竞争优势，选择具有持续增长能力的企业。
  - 适合风险承受能力强的投资者，注重长期收益。

- **1.3.3 邓普勒的理性决策框架**
  - 强调基本面分析和风险控制，通过分散投资降低风险。
  - 适合专业投资者，注重系统性和科学性。

- **1.3.4 巴菲特的综合投资策略**
  - 综合运用价值投资、成长投资和理性决策框架，构建稳健且具有超额收益的投资组合。
  - 通过长期持有优质资产，获得稳定的收益。

### 第2章：四大师智慧的理论基础

#### 2.1 资产定价理论

- **2.1.1 马科维茨的现代投资组合理论（MPT）**
  - 马科维茨于1952年提出MPT，认为投资组合的风险可以通过分散投资来降低。
  - MPT的核心是通过优化资产配置，使投资组合的预期收益最大化，同时风险最小化。
  - 该理论假设资产价格符合正态分布，且投资者是理性的。

- **2.1.2 CAPM模型**
  - CAPM模型由夏普、林特耐和 Mossin 等人在1960年代提出，是MPT的重要扩展。
  - CAPM认为，资产的预期收益与其系统性风险（beta）相关，可以通过市场风险溢价来定价。

#### 2.2 四大师理论与现代投资组合理论的结合

- **2.2.1 格雷厄姆与MPT**
  - 格雷厄姆的价值投资理念强调安全边际，与MPT中的风险分散原则一致。
  - 通过买入低于内在价值的资产，可以降低投资组合的整体风险。

- **2.2.2 费雪与CAPM**
  - 费雪的成长性投资理念注重企业的成长潜力，与CAPM中的beta值相关。
  - 成长型企业通常具有较高的beta值，可以通过合理的资产配置来获得超额收益。

- **2.2.3 邓普勒与投资组合优化**
  - 邓普勒的理性决策框架强调基本面分析和风险控制，与MPT中的优化算法一致。
  - 通过分析资产的期望收益和风险，可以构建出最优的投资组合。

- **2.2.4 巴菲特的综合策略**
  - 巴菲特将四大师智慧整合，形成了独特的投资策略。
  - 通过长期持有优质资产，结合价值投资和成长投资理念，实现稳健的收益。

### 第3章：现代投资组合理论的算法实现

#### 3.1 投资组合优化的数学模型

- **3.1.1 均值-方差优化**
  - 均值-方差优化是MPT的核心，目标是通过优化资产配置，使投资组合的收益最大化，同时风险最小化。
  - 数学模型如下：
    $$ \text{minimize } \sigma^2 $$
    $$ \text{subject to } \mathbb{E}[R] \geq \mu $$
    $$ \mathbf{w}^T \mathbf{1} = 1 $$
    其中，$\sigma^2$ 是投资组合的方差，$\mathbb{E}[R]$ 是期望收益，$\mu$ 是目标收益，$\mathbf{w}$ 是资产权重向量，$\mathbf{1}$ 是全为1的向量。

- **3.1.2 均值-方差优化的实现步骤**
  1. 收集资产的历史收益和协方差数据。
  2. 构建优化模型，设定目标收益和约束条件。
  3. 使用优化算法（如拉格朗日乘数法）求解最优资产配置。
  4. 验证优化结果的可行性和稳健性。

#### 3.2 投资组合优化的Python实现

- **3.2.1 环境安装**
  - 需要安装Python、NumPy、Pandas和Scipy库。
  ```bash
  pip install numpy pandas scipy
  ```

- **3.2.2 核心代码实现**
  - 使用Scipy的优化模块实现均值-方差优化。
  ```python
  import numpy as np
  from scipy.optimize import minimize

  # 假设mu是资产的期望收益，cov是资产的协方差矩阵
  def portfolio_optimization(mu, cov, target_return=0.05):
      n = len(mu)
      # 定义目标函数：最小化方差
      def objective(weights):
          return np.dot(weights.T, np.dot(cov, weights))
      # 约束条件：收益等于目标收益
      def constraint(weights):
          return np.dot(weights, mu) - target_return
      # 约束条件：权重之和为1
      def constraint_sum(weights):
          return np.sum(weights) - 1
      # 初始化权重
      initial_weights = np.array([1.0/n]*n)
      # 使用拉格朗日乘数法求解
      result = minimize(objective, initial_weights, 
                        constraints=[{'type': 'eq', 'fun': constraint},
                                     {'type': 'eq', 'fun': constraint_sum}])
      return result.x
  ```

- **3.2.3 代码解读与优化**
  - 该代码实现了均值-方差优化，目标是找到在目标收益下的最小方差资产配置。
  - 使用拉格朗日乘数法处理约束条件，确保权重之和为1，同时满足收益约束。
  - 优化结果可以通过结果的x属性获取最优权重。

- **3.2.4 应用案例分析**
  - 假设我们有3种资产，历史收益分别为0.05、0.07、0.04，协方差矩阵如下：
    $$ \text{cov} = \begin{bmatrix}
    0.02 & 0.015 & 0.01 \\
    0.015 & 0.03 & 0.012 \\
    0.01 & 0.012 & 0.02
    \end{bmatrix} $$
  - 目标收益为5%。
  - 调用函数 `portfolio_optimization(mu, cov, 0.05)`，返回最优权重。
