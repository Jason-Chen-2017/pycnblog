### 1.1 特价股票的定义与特点
#### 1.1.1 特价股票的定义
特价股票是指那些市场价格低于其面值（即票面价值）的股票。这种股票通常出现在公司财务重组、破产清算或市场波动较大的情况下。由于其价格低廉，特价股票往往被视为高风险高回报的投资对象。

#### 1.1.2 特价股票的核心特点
| 特性 | 描述 |
|------|------|
| 低价格 | 市场价格低于票面价值 |
| 高风险 | 投资风险较高，波动性大 |
| 高潜在回报 | 有可能在短期内实现高收益 |
| 流动性低 | 交易量可能较小，流动性差 |

#### 1.1.3 特价股票与普通股票的区别
| 方面 | 特价股票 | 普通股票 |
|------|----------|-----------|
| 价格 | 低于面值 | 接近或高于面值 |
| 风险 | 高 | 中等或低 |
| 回报 | 高潜力 | 稳定或中等 |

- **分散风险**：通过将资金分配到不同资产，降低单一资产的风险。
- **优化收益**：根据市场趋势，合理分配资金，提高整体收益。
- **动态调整**：根据市场变化，及时调整资金分配比例。

#### 1.2.3 特价股票投资中的资金分配策略特点

- **量化分析**：依赖数学模型和数据分析，确保资金分配的科学性。
