## 第一部分: 价值投资的背景与核心理念

### 第1章: 价值投资的定义与核心理念

#### 1.1 价值投资的定义与历史发展
##### 1.1.1 价值投资的定义
价值投资是一种以低于内在价值的价格买入优质资产的投资策略，其核心在于寻找市场先生的错误定价。价值投资强调安全边际，即买入价格与内在价值之间的差距，以降低投资风险。

##### 1.1.2 价值投资的历史发展
价值投资的理论基础可以追溯到本杰明·格雷厄姆和戴维·多德的工作，乔尔·格林布拉特继承并发展了这一理论。格林布拉特通过量化模型，将价值投资的选股逻辑系统化，提出了著名的“烟蒂股”概念。

##### 1.1.3 价值投资的核心理念
- **安全边际**：买入价格低于内在价值，确保投资的安全性。
- **长期视角**：关注企业的长期价值，而非短期市场波动。
- **逆向思维**：在市场恐慌时寻找机会，避免追涨杀跌。

#### 1.2 价值投资与其他投资策略的对比
##### 1.2.1 价值投资的定义
价值投资强调通过基本面分析寻找被低估的股票，注重安全边际和长期回报。

##### 1.2.2 价值投资与成长投资的区别
- **价值投资**：注重低估值，关注企业的内在价值。
- **成长投资**：注重高成长性，关注企业的未来盈利潜力。
- **区别**：价值投资更注重当前估值，而成长投资更注重未来增长。

##### 1.2.3 价值投资与技术分析的对比
- **价值投资**：基于基本面分析，寻找低估的股票。
- **技术分析**：基于价格和成交量的走势，预测未来的价格变动。
- **区别**：价值投资注重内在价值，技术分析注重价格走势。

#### 1.3 价值投资的基本原则
##### 1.3.1 价值投资的基本原则
- **买入优质资产**：选择具有竞争优势的企业。
- **关注安全边际**：买入价格低于内在价值。
- **长期持有**：避免频繁交易，降低交易成本。

##### 1.3.2 价值投资的三大核心要素
- **内在价值**：企业的未来现金流的现值。
- **安全边际**：买入价格与内在价值的差距。
- **竞争优势**：企业相对于竞争对手的核心优势。

##### 1.3.3 价值投资的长期性与纪律性
- **长期性**：价值投资需要耐心，等待市场回归理性。
- **纪律性**：严格遵守投资原则，避免情绪化决策。

#### 1.4 价值投资的适用场景与局限性
##### 1.4.1 价值投资的适用场景
- **市场低估阶段**：市场恐慌时，更容易找到被低估的股票。
- **稳定成长行业**：选择具有稳定盈利能力和竞争优势的企业。

##### 1.4.2 价值投资的局限性
- **短期波动风险**：市场可能长期低估优质资产。
- **竞争优势变化**：企业的竞争优势可能被颠覆。
- **估值模型的局限性**：内在价值的计算存在主观性。

##### 1.4.3 价值投资的未来发展趋势
- **量化分析**：结合大数据和机器学习，优化选股模型。
- **多策略结合**：将价值投资与其他策略结合，降低风险。

## 第二部分: 价值投资的核心要素

### 第2章: 基本面分析的核心要素

#### 2.1 财务报表分析
##### 2.1.1 财务报表的基本结构
- **资产负债表**：企业的资产、负债和所有者权益。
- **利润表**：企业的收入、成本和利润。
- **现金流量表**：企业的现金流入和流出。

##### 2.1.2 资产负债表分析
- **资产**：流动资产和非流动资产。
- **负债**：流动负债和非流动负债。
- **所有者权益**：净资产的价值。

##### 2.1.3 利润表分析
- **收入**：企业的总收入。
- **成本**：企业的总成本。
- **利润**：企业的净利润。

##### 2.1.4 现金流量表分析
- **经营活动现金流**：企业日常经营产生的现金流。
- **投资活动现金流**：企业投资活动产生的现金流。
- **筹资活动现金流**：企业筹资活动产生的现金流。

#### 2.2 估值方法
##### 2.2.1 市盈率（P/E）分析
- **公式**：P/E = 市场价 / 每股收益
- **应用**：衡量股票的估值是否合理。

##### 2.2.2 市净率（P/B）分析
- **公式**：P/B = 市场价 / 每股净资产
- **应用**：适用于银行、保险公司等净资产较多的行业。

##### 2.2.3 股息率分析
- **公式**：股息率 = 每股股息 / 市场价
- **应用**：衡量股票的分红能力。

##### 2.2.4 内在价值计算公式
- **公式**：内在价值 = 未来现金流的现值
- **应用**：通过DCF模型计算企业的内在价值。

#### 2.3 企业的竞争优势分析
##### 2.3.1 企业的核心竞争力
- **成本优势**：企业是否具有成本优势。
- **技术优势**：企业是否具有技术优势。
- **品牌优势**：企业是否具有品牌优势。

##### 2.3.2 企业的市场地位
- **市场份额**：企业在市场中的份额。
- **竞争对手**：企业的竞争对手情况。

##### 2.3.3 企业的财务健康状况
- **盈利能力**：企业的净利润率。
- **周转能力**：企业的资产周转率。
- **偿债能力**：企业的资产负债率。

#### 2.4 本章小结
本章详细介绍了基本面分析的核心要素，包括财务报表分析、估值方法和竞争优势分析。通过这些分析，投资者可以更好地评估企业的内在价值。

## 第三部分: 乔尔·格林布拉特的选股策略

### 第3章: 乔尔·格林布拉特的选股策略

#### 3.1 烟蒂股的概念与特点
##### 3.1.1 烟蒂股的定义
- **烟蒂股**：指那些被市场遗忘的、具有较高内在价值的股票。

##### 3.1.2 烟蒂股的特点
- **低估值**：市盈率、市净率等指标低于行业平均水平。
- **高分红**：股息率较高，且股息支付率稳定。
- **竞争优势**：企业具有一定的竞争优势，但市场对其认识不足。

#### 3.2 安全边际的计算与应用
##### 3.2.1 安全边际的定义
- **安全边际**：买入价格与内在价值之间的差距。

##### 3.2.2 安全边际的计算方法
- **公式**：安全边际 = 买入价格 / 内在价值 - 1
- **应用**：确保投资的安全性，降低风险。

#### 3.3 格林布拉特选股模型
##### 3.3.1 模型的基本框架
- **输入变量**：市盈率、市净率、股息率、ROE等。
- **输出结果**：股票的内在价值和安全边际。

##### 3.3.2 模型的输入变量
- **市盈率（P/E）**：市场价格 / 每股收益。
- **市净率（P/B）**：市场价格 / 每股净资产。
- **股息率（Dividend Yield）**：每股股息 / 市场价格。
- **ROE（净资产收益率）**：净利润 / 平均净资产。

##### 3.3.3 模型的输出结果
- **内在价值**：通过DCF模型计算得出。
- **安全边际**：买入价格与内在价值的差距。

##### 3.3.4 模型的优缺点分析
- **优点**：量化分析，减少主观性。
- **缺点**：依赖于模型假设，可能忽略市场情绪。

### 第4章: 投资组合的构建与管理

#### 4.1 投资组合的基本原理
##### 4.1.1 投资组合的定义
- **投资组合**：将资金分散投资于不同的资产或股票，以降低风险。

##### 4.1.2 投资组合的构建原则
- **分散化**：通过投资不同类型资产降低风险。
- **长期视角**：关注企业的长期价值，避免短期波动。
- **定期调整**：根据市场变化和个人财务状况，调整投资组合。

#### 4.2 投资组合的构建策略
##### 4.2.1 资产配置
- **股票配置**：根据市场情况调整股票仓位。
- **债券配置**：用于降低投资组合的波动性。
- **现金配置**：用于应对突发事件和市场机会。

##### 4.2.2 个股选择
- **选择低估股票**：根据格林布拉特模型筛选股票。
- **分散投资**：避免过度集中于某一只股票。

#### 4.3 投资组合的动态调整
##### 4.3.1 定期评估
- **评估市场变化**：根据市场情况调整投资组合。
- **评估个股表现**：检查个股是否偏离内在价值。

##### 4.3.2 再平衡
- **再平衡策略**：定期调整投资组合，保持目标配置。

#### 4.4 投资组合的风险管理
##### 4.4.1 风险类型
- **市场风险**：市场波动对投资组合的影响。
- **流动性风险**：投资组合难以快速变现的风险。
- **信用风险**：债券发行人违约的风险。

##### 4.4.2 风险管理策略
- **分散化**：通过投资不同类型资产降低风险。
- **止损策略**：设定止损点，避免重大损失。
- **定期评估**：及时发现并调整投资组合中的风险因素。

import pandas as pd
import numpy as np

# 示例代码：计算股票的内在价值
def calculate_intrinsic_value(eps, growth_rate, discount_rate):
    # 使用DCF模型计算内在价值
    terminal_value = eps * (1 + growth_rate) / (discount_rate - growth_rate)
    intrinsic_value = (eps + terminal_value) / (1 + discount_rate)
    return intrinsic_value

# 示例代码：计算安全边际
def calculate_margin_of_safety(price, intrinsic_value):
    margin_of_safety = (intrinsic_value - price) / intrinsic_value
    return margin_of_safety

# 示例代码：筛选烟蒂股
def screen_stalwart(stocks, eps, growth_rate, discount_rate):
    intrinsic_values = []
    for stock in stocks:
        iv = calculate_intrinsic_value(stock['eps'], stock['growth_rate'], stock['discount_rate'])
        mos = calculate_margin_of_safety(stock['price'], iv)
        if mos > 0.2:  # 安全边际超过20%
            intrinsic_values.append(stock)
    return intrinsic_values
