                 

### 《后资本主义经济模型设计：共享与合作的未来经济蓝图》引言与背景

#### 一、后资本主义时代概述

后资本主义时代，是经济学理论中提出的一个概念，指的是在传统资本主义经济体制之后，人类可能进入的一种新型经济形态。这种经济形态强调不再以资本积累为核心目标，而是转向注重人的全面发展和社会整体福祉。这个时代的到来，是全球化、技术进步、生态危机、社会不平等等多重因素共同作用的结果。

在全球范围内，后资本主义时代的特征表现为：资源共享、合作共赢、可持续发展等。这种转变不仅体现在经济领域，还渗透到政治、文化、社会等多个层面。例如，共享经济的兴起，就体现了人们对于资源利用效率的重新认识；合作经济的推广，则反映了社会对于公平正义的追求。

#### 二、共享与合作的全球经济趋势

共享经济与合作经济是后资本主义时代的重要表现，它们在全球经济中正日益发挥着重要作用。

**共享经济的定义与原理**：

共享经济，也称为协同消费，指的是个体或组织通过互联网平台分享闲置资源，实现资源的高效利用。这种经济模式的核心在于，通过降低资源闲置率，提高资源利用效率，实现经济效益的最大化。例如，共享单车、共享汽车、共享住宿等都是共享经济的典型代表。

共享经济的原理在于，它通过去中心化的方式，打破了传统资源分配的壁垒，使得资源能够在更大范围内流动和共享。这种模式不仅降低了消费者的使用成本，还提高了资源的利用效率。

**合作经济的定义与原理**：

合作经济，则强调通过合作与共享，实现共同的目标和利益。这种经济模式以集体利益为导向，强调个体与集体之间的协作与共赢。例如，合作社、社区经济、公共事业管理等都属于合作经济的范畴。

合作经济的原理在于，它通过构建一种平等、互利的合作关系，使得个体和集体能够共同成长和进步。这种模式不仅有助于提升社会整体的福祉，还能够有效应对个体面临的种种挑战。

#### 三、后资本主义经济模型的驱动力

后资本主义经济模型的转型，是由多种因素共同推动的：

1. **技术进步**：信息技术、互联网、人工智能等新技术的迅猛发展，为资源共享和协作提供了技术支持。这些技术使得资源的分配和利用变得更加高效和灵活。
2. **生态危机**：随着全球环境问题的加剧，人们对可持续发展的需求日益迫切。后资本主义经济模型强调生态优先，旨在实现经济与环境的双赢。
3. **社会不平等**：社会不平等的加剧，使得人们对公平正义的渴望更加强烈。后资本主义经济模型试图通过重新分配资源和权力，实现社会公平。

#### 四、新经济模型的特征

后资本主义经济模型具有以下几个显著特征：

1. **资源共享**：资源不再集中在少数人手中，而是通过共享实现更广泛的社会参与和利用。
2. **合作共赢**：个体与集体之间不再是零和博弈，而是通过合作实现共同利益。
3. **可持续性**：经济活动不仅考虑短期利益，更注重长期发展和生态平衡。

### 五、后资本主义经济模型的应用

后资本主义经济模型的应用领域非常广泛，从个人生活到企业运营，再到国家治理，都展现了其强大的生命力和潜力。例如，在个人生活中，共享经济已经渗透到出行、住宿、教育、医疗等多个方面；在企业运营中，合作经济正逐渐取代传统的竞争模式，实现产业链的协同和创新；在国家治理中，后资本主义经济模型为政策制定者提供了新的思路和方法，帮助实现社会的公平和可持续发展。

### 六、后资本主义经济模型的边界与外延

**核心概念：后资本主义**：

后资本主义不是一个具体的、定义明确的术语，而是一个描述资本主义发展新阶段的宏观概念。它涉及到经济、社会、文化等多方面，旨在超越传统资本主义所固有的弊端，如资源分配不均、环境破坏、社会不公等。

**核心概念：共享经济**：

共享经济，作为一种新型经济模式，强调资源的共享和再利用。它不仅仅是物品或服务的共享，更是一种社会价值观的体现，即通过共享实现资源的最大化利用，减少浪费。

### 核心概念原理

#### 一、共享经济的定义与原理

共享经济，也称为协同消费，是一种基于互联网平台，通过分享闲置资源实现效益最大化的经济模式。其核心原理是通过去中心化的方式，将资源分配给最需要的人，从而提高资源利用效率，减少浪费。

**1. 定义**：

共享经济主要涉及三个主体：资源提供者、资源需求者和平台。资源提供者将自己的闲置资源（如房屋、汽车、设备等）分享给需求者，平台则作为中介，提供资源匹配、交易和安全保障等服务。

**2. 原理**：

共享经济的运作原理可以概括为以下几点：

- **去中心化**：共享经济平台通常采用去中心化的模式，使得资源分配更加灵活和高效。平台不控制资源，而是通过算法和用户行为数据，实现资源的自动匹配。

- **共享理念**：共享经济的核心理念是“共享”和“共赢”。通过共享闲置资源，可以实现资源的高效利用，降低社会成本。同时，资源提供者和需求者通过共享获得经济利益，实现共赢。

- **激励机制**：为了鼓励更多的资源提供者参与共享经济，平台通常会设置一系列激励措施，如积分、返现、奖励等。这些措施能够提高用户的参与度和忠诚度。

#### 二、合作经济的定义与原理

合作经济，是一种以合作与共享为基础，通过集体协作实现共同目标和利益的经济模式。它强调个体与集体之间的相互依赖和协作，旨在消除个体与集体之间的对立，实现共同繁荣。

**1. 定义**：

合作经济主要涉及两个主体：个体和组织。个体通过加入组织，实现资源共享、优势互补和风险共担。组织则通过协调个体之间的合作，实现共同的目标。

**2. 原理**：

合作经济的运作原理可以概括为以下几点：

- **协作理念**：合作经济的核心理念是“协作”和“共赢”。通过协作，个体能够实现优势互补，提高工作效率和创新能力。

- **组织结构**：合作经济通常采用组织结构来实现个体之间的协作。组织结构可以是合作社、社区组织、公共事业管理等形式。这些组织通过制定共同的规则和目标，引导个体行为，实现协作共赢。

- **利益分配**：合作经济强调公平的利益分配。通过合理的利益分配机制，确保每个个体都能从合作中获得合理的收益，从而激发个体的积极性和参与度。

#### 三、共享经济与资本主义经济对比

**1. 资源配置方式**：

- **共享经济**：去中心化，通过互联网平台实现资源的高效匹配和利用。

- **资本主义经济**：中心化，资源分配主要依赖市场机制，价格和供需关系决定资源的流向。

**2. 目标追求**：

- **共享经济**：注重资源的高效利用和环保，追求社会整体的可持续发展。

- **资本主义经济**：以利润最大化为核心目标，追求个体的经济利益。

**3. 经济模式**：

- **共享经济**：基于共享和共赢的理念，通过合作实现资源的高效利用。

- **资本主义经济**：基于竞争和私有制的理念，通过市场机制实现资源的配置。

#### 四、合作经济与传统经济对比

**1. 合作关系**：

- **合作经济**：个体与集体之间的合作关系，强调协作与共赢。

- **传统经济**：个体与个体之间的竞争关系，强调个体利益的最大化。

**2. 目标追求**：

- **合作经济**：以共同目标和利益为导向，追求社会整体的福祉。

- **传统经济**：以个体目标和利益为导向，追求个人财富和地位的提升。

**3. 经济模式**：

- **合作经济**：基于合作与共享的理念，通过集体协作实现共同目标。

- **传统经济**：基于私有制和市场竞争的理念，通过个体竞争实现资源分配。

通过上述对比，我们可以看到，共享经济和合作经济在资源配置方式、目标追求和经济模式等方面，与传统资本主义经济和传统经济有着显著的区别。这些区别不仅反映了后资本主义经济模型的新特点，也为未来的经济发展提供了新的思路和方向。

### 后资本主义经济模型的基础架构

#### 一、经济模型的组成要素

后资本主义经济模型的基础架构由多个关键要素组成，这些要素相互关联，共同构成了一个高效、可持续的经济生态系统。

**1. 主体要素**：

- **个体**：作为经济活动的核心，个体是资源的提供者和消费者。在共享经济中，个体通过分享自己的闲置资源实现收益；在合作经济中，个体通过参与集体活动实现共同目标。

- **组织**：组织是合作经济的重要载体，它通过协调个体之间的合作，实现资源共享和优势互补。组织形式多样，包括合作社、社区组织、公共机构等。

**2. 资源要素**：

- **物质资源**：包括房屋、汽车、设备、技术等实体资源。这些资源通过共享平台实现高效利用。

- **信息资源**：包括数据、知识、信息等虚拟资源。信息资源在现代经济中扮演着至关重要的角色，通过互联网平台实现信息的快速传播和共享。

**3. 平台要素**：

- **共享平台**：作为连接个体和组织的中介，共享平台提供资源匹配、交易和安全保障等服务。平台的去中心化特性使其在资源分配和利用方面具有显著优势。

- **合作平台**：作为个体和组织之间协作的桥梁，合作平台提供协作工具、沟通渠道和决策支持。通过合作平台，个体能够高效协作，实现共同目标。

**4. 机制要素**：

- **激励机制**：包括奖励、积分、返现等，用于激励个体和组织参与共享经济和合作经济。激励机制能够提高用户的积极性和忠诚度。

- **规则机制**：包括法律法规、行业标准、组织规则等，用于规范经济活动，保障各方的合法权益。规则机制是经济模型稳定运行的重要保障。

#### 二、经济模型的运作机制

后资本主义经济模型的运作机制可以概括为以下几个方面：

**1. 资源共享机制**：

- **资源识别与匹配**：个体将自己的闲置资源信息上传至共享平台，平台通过算法和大数据分析，实现资源的快速匹配。

- **交易与支付**：平台提供交易渠道，确保交易的安全性和便捷性。用户通过支付相应的费用，获得所需的资源。

**2. 合作协作机制**：

- **项目立项与规划**：个体和组织通过合作平台，共同确定项目目标和计划。

- **任务分配与执行**：项目成员根据任务分工，共同执行项目任务，实现资源共享和优势互补。

- **成果评估与奖励**：项目完成后，通过评估机制对成果进行评价，并给予相应的奖励和反馈。

**3. 激励与约束机制**：

- **激励机制**：通过奖励、积分、返现等方式，激励个体和组织积极参与经济活动。

- **约束机制**：通过法律法规、行业标准、组织规则等，约束个体的行为，保障经济活动的公正和透明。

#### 三、经济模型的优势与挑战

**1. 优势**：

- **资源高效利用**：共享经济和合作经济通过去中心化的方式，实现资源的高效利用，减少浪费。

- **社会整体福祉**：后资本主义经济模型强调合作与共赢，有助于提升社会整体的福祉。

- **可持续发展**：通过资源共享和合作共赢，实现经济与环境的双赢，促进可持续发展。

**2. 挑战**：

- **信息不对称**：在共享经济中，信息不对称可能导致资源匹配效率低下。

- **信任问题**：共享经济和合作经济依赖于信任，信任缺失可能导致经济活动的障碍。

- **法律规范**：共享经济和合作经济的新模式需要相应的法律法规支持，现有的法律体系可能无法完全适应。

#### 四、经济模型的设计原则

为了确保后资本主义经济模型的稳定运行和可持续发展，设计时应遵循以下原则：

- **开放性**：经济模型应具备开放性，允许各类主体自由参与和退出。

- **透明性**：经济模型应具备透明性，确保信息流的畅通，提高经济活动的可追溯性。

- **公平性**：经济模型应确保各方的公平待遇，避免资源分配不均。

- **灵活性**：经济模型应具备灵活性，能够适应经济环境的变化，实现持续优化。

通过上述基础架构和运作机制的设计，后资本主义经济模型能够实现资源的高效利用、合作共赢和可持续发展，为未来的经济发展提供有力支持。

### 经济模型设计方法

#### 一、设计原则

在后资本主义经济模型的设计过程中，我们需要遵循一系列基本原则，以确保经济模型的有效性和可持续性。

**1. 开放性**：

经济模型应具备开放性，允许各类主体自由参与和退出。开放性不仅能够吸引更多的资源提供者和需求者，还能够促进创新和竞争，提升经济模型的活力。

**2. 透明性**：

透明性是经济模型稳定运行的重要保障。通过构建透明的信息平台，确保各方的合法权益，提高经济活动的可追溯性，减少信息不对称和信任问题。

**3. 公平性**：

公平性是后资本主义经济模型的核心价值之一。经济模型应确保各方的公平待遇，避免资源分配不均，从而提升社会整体的福祉。

**4. 可持续性**：

经济模型的设计应考虑长期发展，确保经济与环境的双赢。可持续性不仅体现在资源的高效利用上，还应包括经济、社会和生态的协调发展。

**5. 灵活性**：

经济模型应具备灵活性，能够适应经济环境的变化。灵活性有助于经济模型在应对外部挑战时，实现持续优化和适应。

#### 二、设计流程

经济模型的设计过程可以分为以下几个主要步骤：

**1. 需求分析**：

首先，明确经济模型的目标和需求。这包括识别主要参与主体、确定关键资源、分析市场环境等。需求分析是设计的基础，有助于明确经济模型的功能和特性。

**2. 模型架构设计**：

在需求分析的基础上，设计经济模型的总体架构。这包括确定经济模型的组成要素、关键环节和功能模块。模型架构设计应遵循开放性、透明性、公平性和可持续性的原则。

**3. 算法与算法流程图**：

经济模型的设计离不开算法的支持。根据需求，设计相应的算法，并使用Mermaid等工具绘制算法流程图，以清晰地展示算法的执行流程。

**4. 数学模型与公式推导**：

\[

\[

其中，\( c_i \) 是资源 \( i \) 的成本，\( a_{ij} \) 是资源 \( i \) 对需求 \( j \) 的贡献，\( b_j \) 是需求 \( j \) 的总量，目标是选择资源的组合 \( x_i \) 使总成本最小，同时满足需求约束。

### 算法原理讲解

#### 一、资源分配算法原理

资源分配算法是后资本主义经济模型中的核心算法之一，它主要用于解决如何在多个需求者之间分配有限资源的问题。资源分配算法的核心目标是使资源的总效用最大化或总成本最小化。

**1. 问题描述**

假设有 \( N \) 个资源提供者和 \( M \) 个资源需求者，每个资源提供者 \( i \) 有 \( n_i \) 单位的资源，每个资源需求者 \( j \) 有 \( m_j \) 的需求。资源分配问题可以表示为：

最大化或最小化目标函数 \( f(x) \)：

\[
f(x) = \sum_{i=1}^{N} \sum_{j=1}^{M} (x_{ij} - n_i - m_j)^2
\]

其中，\( x_{ij} \) 表示资源提供者 \( i \) 分配给资源需求者 \( j \) 的资源量。

约束条件为：

\[
\sum_{i=1}^{N} x_{ij} \leq n_i, \quad j=1,2,...,M
\]

\[
\sum_{j=1}^{M} x_{ij} \leq m_j, \quad i=1,2,...,N
\]

**2. 算法流程**

资源分配算法通常采用贪心策略，其基本流程如下：

1. 初始化资源分配矩阵 \( x_{ij} \) 为 0。
2. 对于每个资源需求者 \( j \)：
   - 对于每个资源提供者 \( i \)：
     - 如果 \( n_i \geq m_j \)，则将 \( x_{ij} \) 设置为 \( m_j \)，\( n_i \) 减去 \( m_j \)。
     - 如果 \( n_i < m_j \)，则将 \( x_{ij} \) 设置为 \( n_i \)，\( m_j \) 减去 \( n_i \)。
3. 循环直到所有需求者 \( j \) 的需求 \( m_j \) 为 0。

```python
import numpy as np

def resource_allocation(n, m):
    x = np.zeros((len(n), len(m)))
    while True:
        j = np.argmax(m)
        if m[j] == 0:
            break
        i = np.argmax(n)
        if n[i] >= m[j]:
            x[i, j] = m[j]
            n[i] -= m[j]
            m[j] = 0
        else:
            x[i, j] = n[i]
            m[j] -= n[i]
            n[i] = 0
    return x

# 资源提供者和需求者数量
N = 3
M = 4

# 资源提供者的资源量
n = np.array([10, 20, 30])

# 资源需求者的需求量
m = np.array([5, 15, 25, 35])

# 资源分配结果
x = resource_allocation(n, m)

# 输出结果

print(x)
print("剩余资源：")
print(n)
print("剩余需求：")
print(m)
```

U(X) = \sum_{i=1}^{N} \sum_{j=1}^{M} u_{ij}(x_{ij})

其中，\( u_{ij}(x_{ij}) \) 表示资源提供者 \( i \) 将 \( x_{ij} \) 单位的资源分配给资源需求者 \( j \) 后的效用。

**2. 成本函数**

成本函数用于描述资源分配过程中所花费的总成本。假设资源提供者 \( i \) 的成本为 \( c_i \)，资源需求者 \( j \) 的成本为 \( d_j \)，则成本函数可以表示为：

\[
C(X) = \sum_{i=1}^{N} c_i x_{ij} + \sum_{j=1}^{M} d_j x_{ij}
\]

**3. 效率函数**

效率函数用于衡量资源分配的效率，通常表示为效用函数与成本函数的比值。效率函数可以表示为：

\[
\eta(X) = \frac{U(X)}{C(X)}

#### 二、公式推导与解释

**1. 资源效用函数推导**

资源效用函数 \( U(X) \) 是基于资源提供者和资源需求者的主观评价。假设每个资源提供者 \( i \) 将 \( x_{ij} \) 单位的资源分配给资源需求者 \( j \) 后，获得的效用为 \( u_{ij}(x_{ij}) \)。我们可以将效用函数表示为：

\[
u_{ij}(x_{ij}) = \alpha_i x_{ij} + \beta_j (1 - x_{ij})
\]

其中，\( \alpha_i \) 表示资源提供者 \( i \) 对资源分配的主观评价系数，\( \beta_j \) 表示资源需求者 \( j \) 对资源分配的主观评价系数。

因此，资源效用函数可以表示为：

\[
U(X) = \sum_{i=1}^{N} \sum_{j=1}^{M} (\alpha_i x_{ij} + \beta_j (1 - x_{ij}))
\]

通过展开和合并同类项，我们得到：

\[
U(X) = \sum_{i=1}^{N} \alpha_i \sum_{j=1}^{M} x_{ij} + \sum_{j=1}^{M} \beta_j \sum_{i=1}^{N} (1 - x_{ij})
\]

由于 \( \sum_{i=1}^{N} x_{ij} = n_i \) 和 \( \sum_{j=1}^{M} (1 - x_{ij}) = N - m_j \)，我们可以进一步简化为：

\[
U(X) = \sum_{i=1}^{N} \alpha_i n_i + \sum_{j=1}^{M} \beta_j (N - m_j)
\]

**2. 成本函数推导**

成本函数 \( C(X) \) 包括资源提供者和资源需求者的成本。假设资源提供者 \( i \) 的成本为 \( c_i \)，资源需求者 \( j \) 的成本为 \( d_j \)，则成本函数可以表示为：

\[
C(X) = \sum_{i=1}^{N} c_i \sum_{j=1}^{M} x_{ij} + \sum_{j=1}^{M} d_j \sum_{i=1}^{N} x_{ij}
\]

由于 \( \sum_{j=1}^{M} x_{ij} = n_i \) 和 \( \sum_{i=1}^{N} x_{ij} = m_j \)，我们可以进一步简化为：

\[
C(X) = \sum_{i=1}^{N} c_i n_i + \sum_{j=1}^{M} d_j m_j
\]

**3. 效率函数推导**

效率函数 \( \eta(X) \) 表示为资源效用函数与成本函数的比值：

\[
\eta(X) = \frac{U(X)}{C(X)}
\]

将 \( U(X) \) 和 \( C(X) \) 的表达式代入，我们得到：

\[
\eta(X) = \frac{\sum_{i=1}^{N} \alpha_i n_i + \sum_{j=1}^{M} \beta_j (N - m_j)}{\sum_{i=1}^{N} c_i n_i + \sum_{j=1}^{M} d_j m_j}
\]

通过化简，我们可以得到效率函数的具体形式：

\[
\eta(X) = \frac{\alpha_1 n_1 + \alpha_2 n_2 + ... + \alpha_N n_N + \beta_1 (N - m_1) + \beta_2 (N - m_2) + ... + \beta_M (N - m_M)}{c_1 n_1 + c_2 n_2 + ... + c_N n_N + d_1 m_1 + d_2 m_2 + ... + d_M m_M}
\]

#### 三、实例分析

**1. 资源效用函数实例**

假设有3个资源提供者和4个资源需求者，资源分配矩阵为：

\[
X = \begin{bmatrix}
2 & 1 & 1 \\
1 & 1 & 1 \\
1 & 2 & 2
\end{bmatrix}
\]

资源提供者的主观评价系数为：

\[
\alpha = \begin{bmatrix}
1.5 & 2.0 & 1.5
\end{bmatrix}
\]

资源需求者的主观评价系数为：

\[
\beta = \begin{bmatrix}
1.0 & 1.5 & 2.0 & 2.5
\end{bmatrix}
\]

资源效用函数可以计算为：

\[
U(X) = \alpha^T X \beta = \begin{bmatrix}
1.5 & 2.0 & 1.5
\end{bmatrix} \begin{bmatrix}
2 & 1 & 1 \\
1 & 1 & 1 \\
1 & 2 & 2
\end{bmatrix} \begin{bmatrix}
1.0 & 1.5 & 2.0 & 2.5
\end{bmatrix} = 14.25
\]

**2. 成本函数实例**

假设资源提供者和资源需求者的成本分别为：

\[
c = \begin{bmatrix}
3 & 4 & 5
\end{bmatrix}, \quad d = \begin{bmatrix}
1 & 2 & 3 & 4
\end{bmatrix}
\]

成本函数可以计算为：

\[
C(X) = c^T X d = \begin{bmatrix}
3 & 4 & 5
\end{bmatrix} \begin{bmatrix}
2 & 1 & 1 \\
1 & 1 & 1 \\
1 & 2 & 2
\end{bmatrix} \begin{bmatrix}
1 & 2 & 3 & 4
\end{bmatrix} = 54
\]

**3. 效率函数实例**

效率函数可以计算为：

\[
\eta(X) = \frac{U(X)}{C(X)} = \frac{14.25}{54} \approx 0.2647
\]

通过上述实例，我们可以看到如何使用数学公式和模型来计算资源效用、成本和效率。这些公式和模型不仅帮助我们理解和量化经济活动，还为实际操作提供了理论支持。

```python
from flask import Flask, request, jsonify
from flask_restful import Api, Resource
from pymysql import connect

app = Flask(__name__)
api = Api(app)

# 连接数据库
def get_db_connection():
    connection = connect(
        host=DB_HOST,
        user=DB_USER,
        password=DB_PASSWORD,
        database=DB_NAME
    )
    return connection

class UserRegistration(Resource):

        data = request.get_json()
        username = data['username']
        password = data['password']
        
        # 检查用户名是否已存在
        connection = get_db_connection()
        cursor = connection.cursor()
        cursor.execute("SELECT * FROM users WHERE username = %s", (username,))
        if cursor.fetchone():
            return {'message': 'Username already exists'}, 409
        
        # 插入用户数据
        cursor.execute("INSERT INTO users (username, password) VALUES (%s, %s)", (username, password))

        cursor.close()
        connection.close()

class UserLogin(Resource):
    def post(self):
        data = request.get_json()
        username = data['username']
        password = data['password']
        
        # 检查用户名和密码是否正确
        connection = get_db_connection()
        cursor = connection.cursor()
        cursor.execute("SELECT * FROM users WHERE username = %s AND password = %s", (username, password))
```

```python
from flask import Flask, request, jsonify
from flask_restful import Api, Resource
from pymysql import connect
```

```python
api = Api(app)

# 连接数据库
def get_db_connection():
    connection = connect(
        host=DB_HOST,
        user=DB_USER,
        password=DB_PASSWORD,
        database=DB_NAME
    )
    return connection

class BikeRental(Resource):
    def post(self, user_id, bike_id):
        # 开始租借单车
        connection = get_db_connection()
        cursor = connection.cursor()
        cursor.execute("SELECT * FROM bikes WHERE bike_id = %s", (bike_id,))
        bike = cursor.fetchone()
        if bike['status'] != 'available':
            return {'message': 'Bike not available'}, 404
        
        # 更新单车状态和租借记录
        cursor.execute("UPDATE bikes SET status = 'rented' WHERE bike_id = %s", (bike_id,))
        cursor.execute("INSERT INTO rentals (user_id, bike_id, start_time) VALUES (%s, %s, NOW())", (user_id, bike_id))
        connection.commit()
        cursor.close()
        connection.close()
        
        return {'message': 'Bike rented successfully'}, 200

    def delete(self, rental_id):
        # 结束租借并计算费用
        connection = get_db_connection()
        cursor = connection.cursor()
        cursor.execute("SELECT * FROM rentals WHERE rental_id = %s", (rental_id,))
        rental = cursor.fetchone()
        if not rental:
            return {'message': 'Rental not found'}, 404
        
        # 计算租借时间并更新租借记录
        end_time = NOW()
        duration = end_time - rental['start_time']
        cost = duration * 10  # 假设每分钟收费10元
        
        cursor.execute("UPDATE rentals SET end_time = %s, cost = %s WHERE rental_id = %s", (end_time, cost, rental_id))
        connection.commit()
        cursor.close()
        connection.close()
        
        return {'message': 'Bike returned successfully', 'cost': cost}, 200

api.add_resource(BikeRental, '/rentals/<int:user_id>/<int:bike_id>', '/rentals/<int:rental_id>')

if __name__ == '__main__':
```
