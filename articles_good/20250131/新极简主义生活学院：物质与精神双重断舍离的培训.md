## 第一部分：背景介绍

### 1.1 问题背景

在现代社会中，人们的生活节奏越来越快，物质生活日益丰富，但与此同时，精神压力也逐渐增大。这种双重负担使得许多人在追求物质满足的同时，逐渐忽略了精神层面的需求。为了解决这一问题，极简主义生活方式应运而生。

极简主义（Minimalism）是一种追求简单、高效的生活方式，主张通过减少不必要的物质和精神负担，专注于对自己真正重要的事物。它不仅仅是减少物品的拥有，更是一种对生活的重新审视和自我约束。

### 5.2 系统核心实现源代码

#### GoalManager.py

```python
from flask import Flask, request, jsonify
from sqlalchemy import create_engine, Column, Integer, String, Float
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

app = Flask(__name__)
engine = create_engine('sqlite:///minimalism.db')
Session = sessionmaker(bind=engine)
Base = declarative_base()

class PersonGoal(Base):
    __tablename__ = 'person_goals'
    id = Column(Integer, primary_key=True)
    goal = Column(String(255))
    progress = Column(Float)

Base.metadata.create_all(engine)

@app.route('/api/goals', methods=['GET'])
def get_goals():
    session = Session()
    goals = session.query(PersonGoal).all()
    session.close()
    return jsonify([{"id": goal.id, "goal": goal.goal, "progress": goal.progress} for goal in goals])

@app.route('/api/goals', methods=['POST'])
def create_goal():
    goal_data = request.get_json()
    session = Session()
    new_goal = PersonGoal(goal=goal_data['goal'], progress=0.0)
    session.add(new_goal)
    session.commit()
    session.close()
    return jsonify({"id": new_goal.id, "goal": new_goal.goal, "progress": new_goal.progress})

if __name__ == '__main__':
    app.run(debug=True)
```
