### Python源代码

```python
# 导入必要的库
import requests
from bs4 import BeautifulSoup

# 定义函数：检索信息
def search_info(search_term):
    # 发送请求
    url = f"https://www.example.com/search?q={search_term}"
    response = requests.get(url)
    
    # 解析网页
    soup = BeautifulSoup(response.text, 'html.parser')
    
    # 提取信息
    info_list = soup.find_all('div', class_='result')
    
    # 评估信息源
    trusted_info = []
    for info in info_list:
        source = info.find('a')['href']
        if is_trusted_source(source):
            trusted_info.append(info.text)
    
    # 返回可信信息
    return trusted_info

# 定义函数：评估信息源
def is_trusted_source(source):
    # 示例：仅当源地址以"example.com"开头时认为可信
    return source.startswith("https://example.com")

# 调用函数
search_results = search_info("数字素养")
print(search_results)
```

这个Python源代码提供了一个简单的信息检索算法，通过发送网络请求、解析网页内容和评估信息源的可信度，实现了对搜索结果的筛选。

### 数学模型和公式

信息检索中的相似度计算是一个核心问题。常见的相似度计算方法包括余弦相似度和欧氏距离。

$$
\text{相似度} = \frac{\text{共现词汇}}{\sqrt{\text{词汇a的频次} \times \text{词汇b的频次}}}
$$

这个公式用于计算两个文本之间的余弦相似度。其中，共现词汇表示两个文本中共同出现的词汇数量。

### 举例说明

假设我们需要比较两个文本A和B的相似度。文本A的词汇频次为{a:3, b:2, c:1}，文本B的词汇频次为{a:2, b:3, c:1}。

根据余弦相似度公式，我们可以计算出相似度为：

$$
\text{相似度} = \frac{3+2}{\sqrt{3\times3} \times \sqrt{2\times3}} = \frac{5}{\sqrt{9} \times \sqrt{6}} \approx 0.8165
$$

这意味着文本A和B的相似度约为81.65%，表示它们具有较高的相关性。

@RestController

    @Autowired
    private UserRepository userRepository;

    public ResponseEntity<?> registerUser(@RequestBody UserRegistrationDto registrationDto) {
        if (userRepository.existsByUsername(registrationDto.getUsername())) {
            return ResponseEntity.badRequest().body("Error: Username is already taken!");
        }

        // 创建用户
        User user = new User();
        user.setUsername(registrationDto.getUsername());
        user.setPassword(passwordEncoder.encode(registrationDto.getPassword()));
        user.setEmail(registrationDto.getEmail());
        userRepository.save(user);

        return ResponseEntity.ok("User registered successfully!");
    }
}
