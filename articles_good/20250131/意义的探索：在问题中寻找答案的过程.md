### 第3章 算法原理讲解

## 3.1 算法概述

算法是解决问题的重要工具。在本章中，我们将介绍一种经典的算法——深度优先搜索（DFS）。DFS是一种用于遍历或搜索树或图的算法，其基本思想是从树的根节点开始搜索，先搜索该节点的所有邻接点，再逐层向下搜索。

### 3.1.1 算法的目的

DFS的主要目的是在图中找到从一个节点到另一个节点的路径，或者确定图中是否存在这样的路径。在许多实际应用中，如社交网络分析、路径规划、游戏AI等，DFS都发挥着重要作用。

### 3.1.2 算法的基本概念

- **节点**：图中的每个元素。
- **边**：连接两个节点的路径。
- **邻接点**：与某个节点直接相连的其他节点。
- **路径**：从源节点到目标节点的序列。

## 3.2 算法原理

### 3.2.1 Mermaid流程图

以下是DFS算法的Mermaid流程图：

```mermaid
graph TD
    A[初始化]
    B{是否访问过根节点?}
    C[标记根节点为已访问]
    D[处理根节点]
    E{是否有未被访问的邻接点?}
    F[对每个邻接点递归执行DFS]

    A-->B
    B-->|是|C
    B-->|否|D
    D-->E
    E-->|有|F
    E-->|无|结束
```

### 3.2.2 Python代码实现

```python
def dfs(node, visited):
    if node not in visited:
        visited.add(node)
        print(node)  # 处理节点
        for neighbor in node.neighbors():
            dfs(neighbor, visited)

# 示例：遍历一个无向图
graph = {1: [2, 3], 2: [1, 4], 3: [1, 5], 4: [2, 5], 5: [3, 4]}
dfs(1, set())
```

### 3.2.3 数学模型与公式

DFS算法可以通过递归实现，其时间复杂度为$O(V+E)$，其中$V$是节点数，$E$是边数。

### 3.2.4 举例说明

假设我们有一个图，其中节点1到节点5之间存在边，如下所示：

```
1 --- 2 --- 4
|    |    |
3 --- 5
```

使用DFS算法，我们可以找到从节点1到节点4的路径：

1. 初始状态：节点1未被访问。
2. 访问节点1，并标记为已访问。
3. 节点1有未访问的邻接点2，4，递归执行DFS。
4. 访问节点2，并标记为已访问。
5. 节点2有未访问的邻接点4，递归执行DFS。
6. 访问节点4，并标记为已访问。
7. 节点4没有未访问的邻接点，返回。
8. 返回节点2，节点2没有未访问的邻接点，返回。
9. 返回节点1，节点1没有未访问的邻接点，返回。

通过上述步骤，我们找到了从节点1到节点4的路径。
