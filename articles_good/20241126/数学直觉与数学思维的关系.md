#### 源代码实现

以下是实现最大子数组问题的Python代码：

```python
import numpy as np

def max_subarray_sum(arr):
    """
    找到给定数组中的最大子数组之和
    :param arr: 输入数组
    :return: 最大子数组和
    """
    max_sum = arr[0]  # 初始化最大子数组之和为第一个元素
    current_sum = 0   # 当前子数组之和初始化为0

    for num in arr:
        current_sum = max(num, current_sum + num)  # 更新当前子数组之和
        max_sum = max(max_sum, current_sum)        # 更新最大子数组之和

    return max_sum

# 示例数据
input_array = [1, -2, 3, 4, -5, 7]

# 计算最大子数组之和
result = max_subarray_sum(input_array)

print(f"最大子数组之和为：{result}")
```

#### 代码解读

1. **导入库**：我们首先导入NumPy库，用于数组处理。
2. **定义函数**：`max_subarray_sum`函数接受一个数组作为输入，并返回最大子数组之和。
3. **初始化变量**：`max_sum`变量用于存储最大子数组之和，初始值为数组的第一个元素。`current_sum`变量用于存储当前子数组之和，初始值为0。
4. **循环计算**：我们遍历输入数组，对于每个元素，使用动态规划方法更新当前子数组之和和最大子数组之和。
5. **返回结果**：最后，函数返回最大子数组之和。
