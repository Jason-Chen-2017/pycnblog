### 实例：牛顿万有引力定律

牛顿万有引力定律是描述宇宙中物体相互作用的经典数学模型。该定律指出，任何两个物体都会相互吸引，其引力大小与两个物体的质量乘积成正比，与它们之间距离的平方成反比。

1. **公式**：
   $$ F = G \frac{m_1 m_2}{r^2} $$
   其中，\( F \) 是引力，\( G \) 是万有引力常数，\( m_1 \) 和 \( m_2 \) 是两个物体的质量，\( r \) 是它们之间的距离。

2. **实例**：
   假设有两个质量分别为 \( m_1 = 5 \times 10^{24} \) 千克的地球和 \( m_2 = 1 \times 10^{24} \) 千克的月球，它们之间的距离为 \( r = 3.84 \times 10^8 \) 米。

   代入公式计算引力：
   $$ F = G \frac{5 \times 10^{24} \times 1 \times 10^{24}}{(3.84 \times 10^8)^2} $$
   $$ F \approx 6.674 \times 10^{-11} \text{ N} $$
   这意味着地球和月球之间的引力约为 \( 6.674 \times 10^{-11} \) 牛顿，这一微小的力却维系了月球围绕地球的稳定运动，体现了宇宙中的和谐性。

### 算法实例：遗传算法

遗传算法是一种模拟自然进化的算法，用于解决优化和搜索问题。该算法通过模拟自然选择和遗传过程，逐步优化解空间中的个体。

1. **遗传算法原理**：
   - **初始种群**：随机生成一组个体作为初始种群。
   - **适应度函数**：定义适应度函数，用于评估个体优劣。
   - **选择**：根据适应度函数选择优质个体。
   - **交叉**：将优质个体进行交叉，产生新的后代。
   - **变异**：对后代进行变异，增加解空间的多样性。
   - **迭代**：重复选择、交叉和变异过程，直到满足终止条件。

2. **Python源代码实例**：
   ```python
   import random
   
   # 初始种群
   def initial_population(size, chromosome_length):
       return [[random.randint(0, 1) for _ in range(chromosome_length)] for _ in range(size)]
   
   # 适应度函数
   def fitness_function(individual):
       # 假设个体是二进制编码的整数
       binary_string = ''.join(str(x) for x in individual)
       decimal_number = int(binary_string, 2)
       return decimal_number
   
   # 选择
   def selection(population, fitnesses, size):
       weighted_population = [[ind, fit / sum(fitnesses)] for ind, fit in zip(population, fitnesses)]
       selected = random.choices(weighted_population, k=size)
       return [ind for ind, _ in selected]
   
   # 交叉
   def crossover(parent1, parent2, crossover_rate):
       if random.random() < crossover_rate:
           crossover_point = random.randint(1, len(parent1) - 1)
           child1 = parent1[:crossover_point] + parent2[crossover_point:]
           child2 = parent2[:crossover_point] + parent1[crossover_point:]
       else:
           child1, child2 = parent1, parent2
       return child1, child2
   
   # 变异
   def mutate(individual, mutation_rate):
       for i in range(len(individual)):
           if random.random() < mutation_rate:
               individual[i] = 1 if individual[i] == 0 else 0
       return individual
   
   # 遗传算法
   def genetic_algorithm(population_size, chromosome_length, generations, crossover_rate, mutation_rate):
       population = initial_population(population_size, chromosome_length)
       for _ in range(generations):
           fitnesses = [fitness_function(ind) for ind in population]
           new_population = []
           for _ in range(population_size // 2):
               parent1, parent2 = selection(population, fitnesses, 2)
               child1, child2 = crossover(parent1, parent2, crossover_rate)
               new_population.extend([mutate(child1, mutation_rate), mutate(child2, mutation_rate)])
           population = new_population
       return max(population, key=fitness_function)
   
   # 实例化遗传算法
   population_size = 100
   chromosome_length = 10
   generations = 100
   crossover_rate = 0.7
   mutation_rate = 0.01
   best_solution = genetic_algorithm(population_size, chromosome_length, generations, crossover_rate, mutation_rate)
   print("Best solution:", best_solution)
   ```

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义行星参数
G = 6.67430e-11  # 万有引力常数
M = 5.972e24  # 地球质量
m = 7.348e22  # 月球质量
r = np.array([6.371e6, 1.496e8])  # 地月距离
v = np.array([0, 1022])  # 月球初速度

# 模拟时间参数
t_max = 2.56e6  # 模拟总时间
dt = 1000  # 时间步长

# 初始化位置和速度
x = np.zeros((2, t_max // dt + 1))
y = np.zeros((2, t_max // dt + 1))
x[0, 0] = r[0]
y[0, 0] = 0
x[1, 0] = r[1]
y[1, 0] = 0

# 初始化速度
vx = np.zeros((2, t_max // dt + 1))
vy = np.zeros((2, t_max // dt + 1))
vx[0, 0] = 0
vy[0, 0] = 0
vx[1, 0] = v[0]
vy[1, 0] = v[1]

# 模拟行星运动
for t in range(1, t_max // dt + 1):
    # 计算引力
    F = G * M * m / r[1]**2
    
    # 更新速度
    dvx = F * x[1, t-1] / (m * r[1])
    dvy = F * y[1, t-1] / (m * r[1])
    
    # 更新位置
    dx = vx[1, t-1] * dt
    dy = vy[1, t-1] * dt
    
    # 更新变量
    vx[1, t] = vx[1, t-1] + dvx
    vy[1, t] = vy[1, t-1] + dvy
    x[1, t] = x[1, t-1] + dx
    y[1, t] = y[1, t-1] + dy
```
