### 数学建模理论基础

#### 非线性动力学

非线性动力学研究的是非线性系统的动态行为，这类系统具有非线性的相互作用，其行为往往难以预测。在神经科学中，非线性动力学被用来描述神经元之间的相互作用和神经信号的传播。

**核心概念**：

1. **非线性系统**：系统的动态行为不能通过线性关系来描述。
2. **吸引子**：系统在长时间演化后趋于稳定的状态。
3. **混沌**：系统在一定的参数范围内表现出高度随机的行为。

**模型描述**：

一个典型的非线性动力学模型是洛伦兹系统，其数学表达式如下：

$$
\begin{cases}
\frac{dx}{dt} = \sigma (y - x) \\
\frac{dy}{dt} = x (\rho - z) - y \\
\frac{dz}{dt} = xy - \beta z
\end{cases}
$$

其中，\(x\)、\(y\)、\(z\) 分别代表三个变量的状态，\(\sigma\)、\(\rho\)、\(\beta\) 是模型的参数。

**应用实例**：

在神经科学中，洛伦兹系统可以用来模拟神经元群体之间的相互作用。通过调整参数，可以观察到神经元群体从有序状态到混沌状态的转变，这有助于理解大脑活动中的复杂现象。

#### 神经网络模型

神经网络模型是模拟大脑神经元结构和功能的重要工具。它通过大量的节点（神经元）和连接（突触）来模拟神经信号的处理和传递。

**核心概念**：

1. **神经元**：神经网络的基本单元，通过接收输入信号并产生输出。
2. **激活函数**：用于确定神经元是否被激活，常见的激活函数有 sigmoid 函数和 ReLU 函数。
3. **学习规则**：用于调整神经网络中突触的权重，以优化网络的性能。

**模型描述**：

一个简单的神经网络模型可以表示为：

$$
\begin{aligned}
o_k &= \sigma \left( \sum_{i} w_{ik} x_i + b_k \right) \\
\end{aligned}
$$

其中，\(o_k\) 是第 \(k\) 个神经元的输出，\(\sigma\) 是激活函数，\(w_{ik}\) 是第 \(i\) 个输入与第 \(k\) 个神经元之间的连接权重，\(x_i\) 是第 \(i\) 个输入，\(b_k\) 是第 \(k\) 个神经元的偏置。

**应用实例**：

神经网络模型广泛应用于图像识别、语音识别和自然语言处理等领域。在神经科学中，它可以用来模拟大脑的信息处理过程，研究认知和学习机制。

#### 随机过程模型

随机过程模型用于描述时间序列数据的随机变化，它在神经科学中用于分析神经信号的时间特性。

**核心概念**：

1. **随机过程**：一个随时间变化的随机变量的集合。
2. **马尔可夫链**：一个状态转移概率只与当前状态有关，而与过去状态无关的过程。
3. **高斯过程**：一种常见的随机过程，其均值函数和协方差函数都为高斯函数。

**模型描述**：

一个简单的马尔可夫链模型可以表示为：

$$
P(X_t = j | X_{t-1} = i) = p_{ij}
$$

其中，\(X_t\) 是时间 \(t\) 的状态，\(p_{ij}\) 是从状态 \(i\) 转移到状态 \(j\) 的概率。

**应用实例**：

在神经科学中，随机过程模型可以用来分析脑电图（EEG）和功能性磁共振成像（fMRI）数据，研究大脑活动的动态变化。

#### 非线性动力学：洛伦兹系统

洛伦兹系统是一个典型的非线性动力学模型，它描述了在三维空间中受非线性作用力影响的粒子的运动。在神经科学中，洛伦兹系统可以用来模拟神经元群体之间的相互作用。

**算法原理讲解**：

洛伦兹系统的数学模型如下：

$$
\begin{cases}
\frac{dx}{dt} = \sigma (y - x) \\
\frac{dy}{dt} = x (\rho - z) - y \\
\frac{dz}{dt} = xy - \beta z
\end{cases}
$$

其中，\(\sigma\)、\(\rho\)、\(\beta\) 是模型的参数，\(x\)、\(y\)、\(z\) 分别代表粒子的位置和速度。

**Python 源代码示例**：

```python
import numpy as np
import matplotlib.pyplot as plt

# 洛伦兹系统参数
sigma = 10.0
rho = 28.0
beta = 8.0 / 3.0
t_final = 50.0
dt = 0.01

# 初始条件
x0 = 1.0
y0 = 1.0
z0 = 1.0

# 时间序列
t = np.arange(0, t_final, dt)
x, y, z = np.zeros_like(t), np.zeros_like(t), np.zeros_like(t)
x[0], y[0], z[0] = x0, y0, z0

# 洛伦兹系统方程求解
for i in range(1, len(t)):
    dxdt = sigma * (y[i-1] - x[i-1])
    dydt = x[i-1] * (rho - z[i-1]) - y[i-1]
    dzdt = x[i-1] * y[i-1] - beta * z[i-1]
    x[i] = x[i-1] + dxdt * dt
    y[i] = y[i-1] + dydt * dt
    z[i] = z[i-1] + dzdt * dt

# 绘图
plt.figure()
plt.plot(x, y, 'b', label='x vs y')
plt.plot(x, z, 'r', label='x vs z')
plt.plot(y, z, 'g', label='y vs z')
plt.xlabel('X')
plt.ylabel('Y')
plt.legend()
plt.title('Lorenz System')
plt.show()
```

这个代码展示了如何使用 Python 来求解洛伦兹系统，并绘制出系统的相图。通过调整参数，可以观察到不同类型的动态行为，如周期解、混沌解等。

#### 神经网络模型：反向传播算法

神经网络模型通过模拟神经元的连接和激活机制，实现复杂函数的拟合和预测。反向传播算法是训练神经网络的重要算法，它通过不断调整网络权重，使网络的输出更接近期望值。

**算法原理讲解**：

反向传播算法的核心思想是通过计算输出误差的梯度，反向更新网络权重。其步骤如下：

1. **前向传播**：计算输入层的输入，通过多层神经元的传递函数，最终得到输出层的输出。
2. **计算误差**：计算输出层输出与期望输出之间的误差。
3. **后向传播**：计算每个层的梯度，并更新权重。
4. **迭代优化**：重复前向传播和后向传播，直到误差达到预设阈值或达到最大迭代次数。

**Python 源代码示例**：

```python
import numpy as np

# 神经网络参数
input_size = 2
hidden_size = 2
output_size = 1

# 初始化权重
w1 = np.random.rand(input_size, hidden_size)
w2 = np.random.rand(hidden_size, output_size)

# 激活函数
sigmoid = lambda x: 1 / (1 + np.exp(-x))

# 前向传播
def forward(x):
    z1 = x.dot(w1)
    a1 = sigmoid(z1)
    z2 = a1.dot(w2)
    a2 = sigmoid(z2)
    return a2

# 反向传播
def backward(x, y):
    output = forward(x)
    error = y - output
    d_output = error * (output * (1 - output))
    
    d2 = d_output.dot(w2.T)
    d1 = d2.dot(w1.T)
    
    delta2 = d_output * w2
    delta1 = d1 * (sigmoid(z1) * (1 - sigmoid(z1)))
    
    w2 -= delta2
    w1 -= delta1

# 训练神经网络
x_train = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
y_train = np.array([[0], [1], [1], [0]])

for epoch in range(1000):
    for x, y in zip(x_train, y_train):
        backward(x, y)
        
    if epoch % 100 == 0:
        print(f"Epoch {epoch}: Error = {np.mean((forward(x_train) - y_train)**2)}")

# 测试神经网络
x_test = np.array([[0.5, 0.5]])
print(f"Test Output: {forward(x_test)}")
```

这个代码展示了如何使用 Python 来构建一个简单的神经网络，并使用反向传播算法进行训练。通过训练，神经网络可以学会区分输入向量，输出正确的二分类结果。

#### 随机过程模型：马尔可夫链

随机过程模型在神经科学中用于分析时间序列数据，如脑电图（EEG）和功能性磁共振成像（fMRI）数据。马尔可夫链是一种常用的随机过程模型，它假设未来的状态仅与当前状态有关，而与过去状态无关。

**算法原理讲解**：

马尔可夫链的数学模型可以表示为：

$$
P(X_t = j | X_{t-1} = i) = p_{ij}
$$

其中，\(X_t\) 是时间 \(t\) 的状态，\(p_{ij}\) 是从状态 \(i\) 转移到状态 \(j\) 的概率。

**Python 源代码示例**：

```python
import numpy as np
import matplotlib.pyplot as plt

# 马尔可夫链参数
states = 3
transitions = np.array([[0.5, 0.3, 0.2], [0.1, 0.6, 0.3], [0.2, 0.1, 0.7]])

# 初始状态
state = 0

# 马尔可夫链模拟
n_steps = 20
state_sequence = [state]
for _ in range(n_steps - 1):
    state = np.random.choice(states, p=transitions[state])
    state_sequence.append(state)

# 绘图
plt.figure()
plt.plot(state_sequence, 'o-')
plt.title('Markov Chain')
plt.xlabel('Time')
plt.ylabel('State')
plt.show()
```

这个代码展示了如何使用 Python 来模拟一个三状态的马尔可夫链，并绘制状态序列图。通过调整转移概率矩阵，可以观察到不同状态转移模式下的行为。

**数学公式与解释**：

在神经科学中，数学建模需要使用多种数学公式来描述神经系统的行为和机制。以下是一些常用的数学公式及其解释：

1. **神经元激活函数**：

   神经元的激活函数用于确定神经元是否被激活。最常见的激活函数是 sigmoid 函数：

   $$
   \sigma(x) = \frac{1}{1 + e^{-x}}
   $$

   其中，\(x\) 是输入值。sigmoid 函数将输入值映射到 \(0\) 到 \(1\) 之间，常用于二分类问题。

2. **神经网络输出**：

   在神经网络中，每个神经元的输出可以通过以下公式计算：

   $$
   o_k = \sigma \left( \sum_{i} w_{ik} x_i + b_k \right)
   $$

   其中，\(o_k\) 是第 \(k\) 个神经元的输出，\(\sigma\) 是激活函数，\(w_{ik}\) 是第 \(i\) 个输入与第 \(k\) 个神经元之间的连接权重，\(x_i\) 是第 \(i\) 个输入，\(b_k\) 是第 \(k\) 个神经元的偏置。

3. **误差计算**：

   在训练神经网络时，需要计算输出误差。输出误差可以通过以下公式计算：

   $$
   error = y - \sigma \left( \sum_{i} w_{ik} x_i + b_k \right)
   $$

   其中，\(y\) 是期望输出，\(\sigma \left( \sum_{i} w_{ik} x_i + b_k \right)\) 是实际输出。

4. **梯度计算**：

   为了优化神经网络，需要计算每个权重的梯度。梯度可以通过以下公式计算：

   $$
   \frac{d\sigma}{dx} = \sigma (1 - \sigma)
   $$

   这是 sigmoid 函数的导数，用于计算输出误差对每个输入的偏导数。

通过这些数学公式，我们可以对神经系统的行为进行量化描述和预测，为神经科学研究提供强有力的工具。

#### 案例一：脑电图（EEG）数据分析

脑电图（EEG）是一种记录大脑电活动的非侵入性技术，常用于监测癫痫发作、睡眠状态分析等。在本案例中，我们将使用数学建模方法来分析 EEG 数据，提取有用的信号特征。

**案例描述**：

我们选取了一组公开的 EEG 数据集，包含不同频率下的脑电信号。目标是通过数学建模提取出与特定认知任务相关的信号特征，例如 Alpha 波（8-12 Hz）和 Beta 波（13-30 Hz）。

**建模过程**：

1. **数据读取**：使用 Python 读取 EEG 数据。
2. **预处理**：进行滤波和去噪处理，以去除高频噪声和低频漂移。
3. **特征提取**：使用短时傅里叶变换（STFT）提取频率特征。
4. **模型构建**：使用支持向量机（SVM）进行分类。

**数学模型与算法**：

1. **短时傅里叶变换（STFT）**：

   $$
   \begin{aligned}
   X(k,\tau) &= \sum_{n} x(n) \cdot e^{-j2\pi kn/N} \cdot e^{j2\pi \tau f_s} \\
   &\text{其中，} X(k,\tau) \text{为频率 } k \text{ 和时间 } \tau \text{ 的信号，} f_s \text{ 为采样频率。}
   \end{aligned}
   $$

2. **支持向量机（SVM）**：

   $$
   \begin{aligned}
   \min_{w, b} \quad & \frac{1}{2} ||w||^2 \\
   \text{subject to} \quad & y_i (w \cdot x_i + b) \geq 1 \\
   \end{aligned}
   $$

   其中，\(w\) 和 \(b\) 分别为权重和偏置，\(x_i\) 和 \(y_i\) 分别为输入和输出标签。

**代码实现**：

```python
import numpy as np
from scipy import signal
from sklearn.svm import SVC
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 读取数据
eeg_data = np.load('eeg_data.npy')

# 预处理
def preprocess_data(data):
    filtered_data = signal.lfilter([1], [1, -0.98], data)
    return filtered_data

# 特征提取
def extract_features(data, sampling_rate):

    return f, t, Z

def train_model(X, y):

    model = SVC(kernel='linear')

    y_pred = model.predict(X_test)
```
