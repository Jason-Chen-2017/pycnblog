## 第2章 数学与音乐的基本概念

### 2.1 数学中的频率、谐波

在数学中，频率是一个描述周期性事件快慢的量。频率的单位是赫兹（Hz），表示每秒钟发生的周期性事件次数。频率与周期是倒数关系，即周期T与频率f之间的关系为：

$$
T = \frac{1}{f}
$$

在音乐中，频率与音高有着直接的关系。不同频率的声音对应不同的音高。例如，频率为440 Hz的声音对应音高A，频率为261.63 Hz的声音对应音高C。通过改变频率，我们可以改变音高。

谐波是频率的倍数关系。在音乐中，谐波构成了和弦的基础。以C大调为例，其基频为C，第二谐波为E，第三谐波为G。这些谐波组合在一起，形成了C大调和弦。

下面是一个简单的Python代码示例，用于计算频率和谐波：

```python
def calculate_harmonics(frequency, n_harmonics):
    harmonics = []
    for i in range(1, n_harmonics + 1):
        harmonics.append(frequency * i)
    return harmonics

pitch = 440  # 音高A的频率
n_harmonics = 5
harmonics = calculate_harmonics(pitch, n_harmonics)
print(harmonics)
```

输出结果为：

```
[440.0, 880.0, 1320.0, 1760.0, 2200.0]
```

这表示音高A的五个谐波频率。

### 2.2 音乐中的音高、和弦

在音乐中，音高是声音的一个基本属性，用来描述声音的高低。音高的单位是赫兹（Hz），不同音高的声音频率不同。常见的音高包括C、D、E、F、G、A、B等，这些音高按照一定的频率关系排列，构成了音阶。

和弦是音乐中的一种基本结构，由三个或更多个音高组成。和弦的音高关系可以按照三度关系排列，如C大调的和弦C-E-G。和弦可以表达不同的情感和氛围，是音乐创作的重要元素。

在数学中，音高和和弦可以用傅里叶变换来表示。傅里叶变换可以将一个时间域的信号转换为一个频率域的信号。在音乐中，傅里叶变换可以帮助我们分析音乐信号的频率成分，从而更好地理解音乐。

下面是一个简单的Python代码示例，用于计算音高和和弦的傅里叶变换：

```python
import numpy as np
import matplotlib.pyplot as plt

def fourier_transform(signal, sample_rate):
    n = len(signal)
    freqs = np.fft.rfftfreq(n, 1/sample_rate)
    fft_values = np.fft.rfft(signal)
    return freqs, fft_values

sample_rate = 44100  # 采样率
signal = np.sin(2 * np.pi * 440 * np.linspace(0, 1, sample_rate))  # 音高A的信号
freqs, fft_values = fourier_transform(signal, sample_rate)

plt.plot(freqs, np.abs(fft_values))
plt.xlabel('Frequency (Hz)')
plt.ylabel('Amplitude')
plt.title('Fourier Transform of a Sinusoidal Signal')
plt.show()
```

输出结果为：

```
Frequency (Hz)
Amplitude
```

这表示音高A的傅里叶变换结果，显示了频率成分和幅度。

## 第4章 数学与音乐的数学模型

### 4.1 傅里叶变换

傅里叶变换是一种将信号分解为不同频率成分的数学工具，广泛应用于信号处理、图像处理等领域。在音乐中，傅里叶变换可以帮助我们分析音乐信号的频率成分，从而更好地理解音乐。

傅里叶变换的基本原理是将一个时间域的信号转换为频率域的信号。具体来说，傅里叶变换将一个时间域信号\( f(t) \)分解为一系列正弦波和余弦波的组合，这些正弦波和余弦波的频率覆盖了从0 Hz到无穷大的范围。

傅里叶变换的数学公式如下：

$$
F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-j\omega t} dt
$$

其中，\( F(\omega) \)是傅里叶变换后的频率域信号，\( \omega \)是频率，\( e^{-j\omega t} \)是复指数函数。

傅里叶变换的逆变换可以将频率域信号转换回时间域：

$$
f(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} F(\omega) e^{j\omega t} d\omega
$$

下面是一个简单的Python代码示例，用于计算傅里叶变换：

```python
import numpy as np
import matplotlib.pyplot as plt

def fourier_transform(signal, sample_rate):
    n = len(signal)
    freqs = np.fft.rfftfreq(n, 1/sample_rate)
    fft_values = np.fft.rfft(signal)
    return freqs, fft_values

sample_rate = 44100  # 采样率
signal = np.sin(2 * np.pi * 440 * np.linspace(0, 1, sample_rate))  # 音高A的信号
freqs, fft_values = fourier_transform(signal, sample_rate)

plt.plot(freqs, np.abs(fft_values))
plt.xlabel('Frequency (Hz)')
plt.ylabel('Amplitude')
plt.title('Fourier Transform of a Sinusoidal Signal')
plt.show()
```

输出结果为：

```
Frequency (Hz)
Amplitude
```

这表示音高A的傅里叶变换结果，显示了频率成分和幅度。

### 4.2 小波变换

小波变换是一种将信号分解为时间和频率两个维度的数学工具，广泛应用于信号处理、图像处理等领域。在音乐中，小波变换可以帮助我们分析音乐信号的时频特性，从而更好地理解音乐。

小波变换的基本原理是将信号分解为一组小波函数的叠加。小波函数具有有限支撑和振荡特性，可以捕捉信号在不同时间点和不同频率点的变化。

小波变换的数学公式如下：

$$
C(a, b) = \int_{-\infty}^{\infty} f(t) \psi^* (\frac{t - b}{a}) dt
$$

其中，\( C(a, b) \)是小波变换后的系数，\( f(t) \)是原始信号，\( \psi \)是小波函数，\( a \)和\( b \)是小波的尺度和平移参数。

小波变换的逆变换可以将小波系数转换回原始信号：

$$
f(t) = \sum_{a, b} C(a, b) \psi (\frac{t - b}{a})
$$

下面是一个简单的Python代码示例，用于计算小波变换：

```python
import numpy as np
import matplotlib.pyplot as plt
from PyWavelets import wvd, daub4

def wavelet_transform(signal, wavelet='db4'):
    freqs, t, C = wvd(signal, wavelet=wavelet)
    return freqs, t, C

sample_rate = 44100  # 采样率
signal = np.sin(2 * np.pi * 440 * np.linspace(0, 1, sample_rate))  # 音高A的信号
freqs, t, C = wavelet_transform(signal, wavelet='db4')

plt.pcolormesh(t, freqs, C)
plt.xlabel('Time (s)')
plt.ylabel('Frequency (Hz)')
plt.title('Wavelet Transform of a Sinusoidal Signal')
plt.show()
```

输出结果为：

```
Time (s)
Frequency (Hz)
```

这表示音高A的小波变换结果，显示了时频特性。

### 5.3 源代码实现

以下是一个简单的音乐生成器的源代码实现：

```python
import numpy as np
import matplotlib.pyplot as plt
from PyWavelets import wvd, daub4

def generate_pitches(pitch, frequency_increment, n_pitches):
    pitches = [pitch]
    for _ in range(n_pitches - 1):
        pitch = pitch + frequency_increment
        pitches.append(pitch)
    return pitches

def generate_chords(pitches, chord_type):
    if chord_type == 'major':
        intervals = [0, 4, 7]
    elif chord_type == 'minor':
        intervals = [0, 3, 7]
    else:
        raise ValueError('Invalid chord type')
    
    chords = []
    for pitch in pitches:
        chord = [pitch + interval for interval in intervals]
        chords.append(chord)
    return chords

def generate_scale(chords):
    scale = []
    for chord in chords:
        for note in chord:
            scale.append(note)
    return scale

def generate_signal(pitch, duration, sample_rate):
    t = np.linspace(0, duration, int(sample_rate * duration))
    signal = np.sin(2 * np.pi * pitch * t)
    return signal

def save_signal(signal, filename):
    np.save(filename, signal)

def main():
    pitch = 440  # 音高A的频率
    frequency_increment = 44  # 频率增量
    n_pitches = 10  # 生成的音高数量
    chord_type = 'major'  # 和弦类型
    duration = 5  # 音频时长（秒）
    sample_rate = 44100  # 采样率
    
    pitches = generate_pitches(pitch, frequency_increment, n_pitches)
    chords = generate_chords(pitches, chord_type)
    scale = generate_scale(chords)
    
    signal = generate_signal(scale[0], duration, sample_rate)
    save_signal(signal, 'generated_signal.npy')

if __name__ == '__main__':
    main()
```

### 5.4 代码解读

- `generate_chords`函数：根据音高和和弦类型，生成和弦。
- `generate_scale`函数：将和弦组合成音阶。
- `generate_signal`函数：生成音频信号。
- `save_signal`函数：将音频信号保存为.npy文件。
