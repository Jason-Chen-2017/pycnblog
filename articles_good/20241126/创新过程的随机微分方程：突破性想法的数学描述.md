## 第一部分：随机微分方程基础

### 1.1 随机微分方程的基本概念

随机微分方程（Stochastic Differential Equations, SDEs）是一种描述随机过程的数学方程。与传统的确定性微分方程不同，SDEs包含了随机扰动项，可以更准确地描述系统在随机环境下的动态行为。

#### 1.1.1 随机过程

随机过程（Stochastic Process）是一种随时间变化的随机变量序列。它可以用来描述一个系统在不同时间点的状态。随机过程通常用符号 \( \{X(t), t \geq 0\} \) 表示，其中 \( X(t) \) 表示在时间 \( t \) 的状态。

#### 1.1.2 随机微分方程的基本形式

随机微分方程的一般形式为：
$$
dX_t = \mu(t, X_t) dt + \sigma(t, X_t) dW_t
$$
其中：
- \( X_t \) 是随机过程；
- \( \mu(t, X_t) \) 是期望项，表示确定性趋势；
- \( \sigma(t, X_t) \) 是噪声项，表示随机扰动；
- \( dW_t \) 是维纳过程（Wiener Process），表示随机扰动。

### 1.2 随机微分方程的核心原理

随机微分方程的核心原理在于其能够描述系统在随机环境下的动态行为。通过引入随机扰动项，SDEs可以捕捉系统在随机扰动下的波动和不确定性，从而提供更为准确的预测和优化结果。

#### 1.2.1 维纳过程

维纳过程是一种重要的随机过程，它在随机微分方程中起到关键作用。维纳过程具有以下性质：
- 均值为0，即 \( E[W_t] = 0 \)；
- 方差为 \( t \)，即 \( Var[W_t] = t \)；
- 自协方差函数为 \( R(s, t) = min(s, t) - s \)。

#### 1.2.2 随机微分方程的解法

随机微分方程的解法主要包括欧拉-马尔可夫（Euler-Maruyama）方法和龙格-库塔（Runge-Kutta）方法等。

- **欧拉-马尔可夫方法**：该方法是一种离散化随机微分方程的简单方法，通过迭代更新随机过程的值。其公式为：
  $$
  X_{n+1} = X_n + \mu(t_n, X_n) \Delta t + \sigma(t_n, X_n) \Delta W_n
  $$
  其中 \( \Delta t \) 是时间步长，\( \Delta W_n \) 是维纳过程的增量。

- **龙格-库塔方法**：该方法是一种更精确的离散化方法，通过多次迭代计算，可以提供更准确的解。龙格-库塔方法有多种形式，如Heun方法、Midpoint方法和Strong Order 1-2方法等。

## 第三部分：核心算法原理讲解

### 3.1 欧拉-马尔可夫方法

欧拉-马尔可夫方法是离散化随机微分方程的一种简单方法，适用于对随机微分方程进行初步分析和模拟。

#### 3.1.1 欧拉-马尔可夫方法的基本原理

欧拉-马尔可夫方法的基本原理是将随机微分方程离散化，通过迭代更新随机过程的值。其公式为：

$$
X_{n+1} = X_n + \mu(t_n, X_n) \Delta t + \sigma(t_n, X_n) \Delta W_n
$$

其中：
- \( X_n \) 是随机过程的当前值；
- \( \mu(t_n, X_n) \) 是期望项；
- \( \sigma(t_n, X_n) \) 是噪声项；
- \( \Delta t \) 是时间步长；
- \( \Delta W_n \) 是维纳过程的增量。

#### 3.1.2 欧拉-马尔可夫方法的Python实现

下面是一个简单的欧拉-马尔可夫方法的Python实现：

```python
import numpy as np

def euler_maruyama(X0, f, g, T, dt):
    X = [X0]
    t = [0]
    while t[-1] < T:
        dt = min(dt, T - t[-1])
        dW = np.random.normal(0, np.sqrt(dt))
        X_new = X[-1] + f(t[-1], X[-1]) * dt + g(t[-1], X[-1]) * dW
        X.append(X_new)
        t.append(t[-1] + dt)
    return np.array(X), np.array(t)

X0 = 0  # 初始值
f = lambda t, x: x  # 确定性项
g = lambda t, x: 1  # 噪声项
T = 10  # 时间上限
dt = 0.1  # 时间步长

X, t = euler_maruyama(X0, f, g, T, dt)
```

### 3.2 龙格-库塔方法

龙格-库塔方法是另一种常用的离散化随机微分方程的方法，具有较高的精度和稳定性。

#### 3.2.1 龙格-库塔方法的基本原理

龙格-库塔方法通过多次迭代计算，逐步逼近随机微分方程的解。其基本原理如下：

$$
X_{n+1} = X_n + \sum_{i=1}^s b_i f(t_n + c_i \Delta t, X_n + \sum_{j=1}^{i-1} a_{ij} f(t_n + c_j \Delta t, X_n) + \sum_{j=1}^{i-1} a_{ij} g(t_n + c_j \Delta t, X_n)
$$

其中：
- \( X_n \) 是随机过程的当前值；
- \( f(t_n, X_n) \) 是期望项；
- \( g(t_n, X_n) \) 是噪声项；
- \( s \) 是迭代次数；
- \( c_i \) 和 \( a_{ij} \) 是龙格-库塔方法的参数。

#### 3.2.2 龙格-库塔方法的Python实现

下面是一个简单的龙格-库塔方法的Python实现：

```python
import numpy as np

def rk4(X0, f, g, T, dt):
    X = [X0]
    t = [0]
    while t[-1] < T:
        k1 = f(t[-1], X[-1]) * dt + g(t[-1], X[-1]) * np.random.normal(0, np.sqrt(dt))
        k2 = f(t[-1] + 0.5 * dt, X[-1] + 0.5 * k1) * dt + g(t[-1] + 0.5 * dt, X[-1] + 0.5 * k1) * np.random.normal(0, np.sqrt(dt))
        k3 = f(t[-1] + 0.5 * dt, X[-1] + 0.5 * k2) * dt + g(t[-1] + 0.5 * dt, X[-1] + 0.5 * k2) * np.random.normal(0, np.sqrt(dt))
        k4 = f(t[-1] + dt, X[-1] + k3) * dt + g(t[-1] + dt, X[-1] + k3) * np.random.normal(0, np.sqrt(dt))
        X_new = X[-1] + (k1 + 2 * k2 + 2 * k3 + k4) / 6
        X.append(X_new)
        t.append(t[-1] + dt)
    return np.array(X), np.array(t)

X0 = 0  # 初始值
f = lambda t, x: x  # 确定性项
g = lambda t, x: 1  # 噪声项
T = 10  # 时间上限
dt = 0.1  # 时间步长

X, t = rk4(X0, f, g, T, dt)
```

### 3.3 采样路径方法

采样路径方法是一种基于蒙特卡洛方法的离散化随机微分方程的方法，适用于大规模随机微分方程的模拟。

#### 3.3.1 采样路径方法的基本原理

采样路径方法的基本原理是通过生成大量的随机路径，来模拟随机微分方程的解。其基本步骤如下：

1. 初始化随机数生成器。
2. 生成大量的随机路径。
3. 对每个路径进行离散化处理，得到离散时间点的随机过程值。
4. 对所有路径进行平均，得到随机微分方程的近似解。

#### 3.3.2 采样路径方法的Python实现

下面是一个简单的采样路径方法的Python实现：

```python
import numpy as np
import matplotlib.pyplot as plt

def sample_paths(X0, f, g, T, dt, N):
    paths = np.zeros((N, int(T / dt)))
    for i in range(N):
        X = [X0]
        t = [0]
        while t[-1] < T:
            dt = min(dt, T - t[-1])
            dW = np.random.normal(0, np.sqrt(dt))
            X_new = X[-1] + f(t[-1], X[-1]) * dt + g(t[-1], X[-1]) * dW
            X.append(X_new)
            t.append(t[-1] + dt)
        paths[i, :] = np.array(X)[::int(1 / dt)]
    return paths

X0 = 0  # 初始值
f = lambda t, x: x  # 确定性项
g = lambda t, x: 1  # 噪声项
T = 10  # 时间上限
dt = 0.1  # 时间步长
N = 1000  # 路径数量

paths = sample_paths(X0, f, g, T, dt, N)

for i in range(N):
    plt.plot(paths[i, :])

plt.show()
```
