### 2.1 自相似性与分形维数

#### 自相似性的数学描述

自相似性是分形理论的核心概念之一，它描述了一个结构在不同尺度上保持相似性的特性。在数学上，自相似性可以通过迭代函数系统（Iterated Function System, IFS）来描述。IFS由一组函数组成，这些函数将一个集合映射到自身，且每个函数都只作用在一个较小的子集上。

设\( X \)是一个集合，\( f_1, f_2, ..., f_n \)是\( X \)上的n个函数，且满足：
1. 每个函数\( f_i \)将\( X \)映射到自身，即\( f_i(X) \subseteq X \)。
2. 每个函数\( f_i \)将\( X \)划分成n个子集，即\( X = f_1(X) \cup f_2(X) \cup ... \cup f_n(X) \)。

那么，IFS可以表示为\( F = \{f_1, f_2, ..., f_n\} \)。对于任意一点\( x \)在\( X \)中，其迭代过程可以表示为：
\[ x_0 = x \]
\[ x_{k+1} = f_i(x_k) \]
其中，\( f_i \)是IFS中的某个函数，\( k \)是从0开始的迭代次数。

#### 分形维数的计算方法

分形维数是描述分形复杂度的一个量度，它介于整数维与分数维之间。常见的分形维数有Hausdorff维数和信息维数。

**Hausdorff维数**：Hausdorff维数是一种用来度量分形复杂度的方法，它定义了分形在不同尺度下的“覆盖度”。设\( E \)是一个分形集合，对于任意给定的正数\( \epsilon \)，\( E \)的\( \epsilon \)-覆盖数是指所有直径小于\( \epsilon \)的闭球所能覆盖\( E \)的最小数量。Hausdorff维数定义为：
\[ D = \lim_{\epsilon \to 0} \frac{\log N(\epsilon)}{\log \frac{1}{\epsilon}} \]
其中，\( N(\epsilon) \)是\( E \)的\( \epsilon \)-覆盖数。

**信息维数**：信息维数是一种基于概率和信息论的分形维数度量方法。它通过计算分形结构的信息熵来描述其复杂度。设\( E \)是一个分形集合，对于任意给定的正数\( \epsilon \)，\( E \)的\( \epsilon \)-分割数是指所有直径小于\( \epsilon \)的分割所能分割\( E \)的最小数量。信息维数定义为：
\[ D = \lim_{\epsilon \to 0} \frac{\log S(\epsilon)}{\log \frac{1}{\epsilon}} \]
其中，\( S(\epsilon) \)是\( E \)的\( \epsilon \)-分割数。

### 3.1 分形树的定义与结构

分形树是一种由无限分支构成的几何结构，其每个分支都与整体结构相似。分形树是分形理论中的重要应用，广泛存在于自然界中，如树枝、闪电和海岸线等。分形树具有以下几个显著特点：

1. **自相似性**：分形树的每一个分支都与其整体结构相似，无论放大或缩小，其形态始终保持一致。
2. **递归生成**：分形树的生成过程是通过递归迭代实现的，每个分支都是由上一级的分支经过某种规则演变而来。
3. **分形维数**：分形树的分形维数通常介于1和2之间，这是其区别于传统几何形态的关键特征。

常见的分形树包括Mandelbrot集、Cantor集和Sierpinski三角形。以下将分别介绍这些分形树的结构与生成算法。

### 3.2 分形树的生成算法

#### Mandelbrot集

Mandelbrot集是一个复杂的分形结构，其生成算法基于复数迭代。给定一个复数\( C \)，初始值为\( z_0 = 0 \)，通过以下迭代过程生成Mandelbrot集：

\[ z_{n+1} = z_n^2 + C \]

如果对于某个正整数\( N \)，\( z_N \)的模大于2，即\( |z_N| > 2 \)，则\( C \)不属于Mandelbrot集。否则，\( C \)属于Mandelbrot集。

以下是一个使用Python伪代码来描述Mandelbrot集生成算法的例子：

```python
import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter):
    z = 0
    for i in range(max_iter):
        z = z * z + c
        if abs(z) > 2:
            return i
    return max_iter

# 定义复数网格
x = np.linspace(-2, 1, 1000)
y = np.linspace(-1.5, 1.5, 1000)
X, Y = np.meshgrid(x, y)
C = X + 1j * Y

# 计算Mandelbrot集
Z = np.array([[mandelbrot(c, 256) for c in row] for row in C])

# 绘制Mandelbrot集
plt.imshow(Z, cmap='hot', extent=(x.min(), x.max(), y.min(), y.max()))
plt.colorbar()
plt.title('Mandelbrot Set')
plt.show()
```

#### Cantor集

Cantor集是一种通过递归删除中间部分生成的分形结构。给定一个闭区间\[a, b\]，通过以下步骤生成Cantor集：

1. 将闭区间\[a, b\]等分为两个子区间\[a, \frac{a+b}{2}\]和[\frac{a+b}{2}, b\]。
2. 保留两个子区间中的一个，丢弃另一个。
3. 递归步骤1和2，直到达到终止条件。

以下是一个使用Python伪代码来描述Cantor集生成算法的例子：

```python
def cantor_set(a, b, depth):
    if depth == 0:
        return [a, b]
    mid = (a + b) / 2
    left = cantor_set(a, mid, depth - 1)
    right = cantor_set(mid, b, depth - 1)
    return left + right

# 绘制Cantor集
plt.plot([x for pair in cantor_set(0, 1, 6) for x in pair], 'k')
plt.title('Cantor Set')
plt.show()
```

#### Sierpinski三角形

Sierpinski三角形是一种通过递归将三角形划分为更小的相似三角形的分形结构。给定一个等边三角形，通过以下步骤生成Sierpinski三角形：

1. 将等边三角形划分为三个更小的相似三角形。
2. 递归步骤1，直到达到终止条件。

以下是一个使用Python伪代码来描述Sierpinski三角形生成算法的例子：

```python
import numpy as np
import matplotlib.pyplot as plt

def sierpinski_triangle(points, depth):
    if depth == 0:
        return [points]
    new_points = []
    for point in points:
        mid_point = [(point[0] + point[2]) / 2, (point[1] + point[3]) / 2]
        new_points.append([point[0], point[1], mid_point[0], mid_point[1]])
        new_points.append([mid_point[0], mid_point[1], point[2], point[3]])
        new_points.append([point[0], mid_point[1], mid_point[0], point[3]])
    return new_points

# 绘制Sierpinski三角形
points = np.array([[0, 0], [1, 0], [1/2, np.sqrt(3)/2]])
plt.scatter(*zip(*sierpinski_triangle(points, 4)), c='k')
plt.title('Sierpinski Triangle')
plt.show()
```

    for i in range(max_iter):
        z = z * z + c
        if abs(z) > 2:
            return i
    return max_iter

def cantor_set(a, b, depth):

def sierpinski_triangle(points, depth):
    if depth == 0:

    new_points = []
    for point in points:
        mid_point = [(point[0] + point[2]) / 2, (point[1] + point[3]) / 2]
