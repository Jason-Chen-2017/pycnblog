### 第1章 个性化推荐系统基础

#### 1.1 推荐系统概述

个性化推荐系统是一种通过分析用户的历史行为、偏好和兴趣，自动为用户推荐符合其需求的内容或商品的技术。推荐系统的核心目标是通过提高用户的满意度、提升用户的黏性，从而增强商业变现能力。随着互联网的普及和用户数据的积累，推荐系统已经成为了电商平台、社交媒体、视频流媒体等众多领域的必备功能。

推荐系统按照应用场景和实现方法，可以分为以下几种类型：

1. **基于内容的推荐（Content-Based Recommendation）**：通过分析用户对特定内容的偏好，将相似的内容推荐给用户。这种推荐方式依赖内容的特征提取和相似度计算。

2. **协同过滤推荐（Collaborative Filtering）**：通过分析用户之间的行为模式，预测用户对未知内容的喜好。协同过滤又分为以下两种：

   - **用户基于的协同过滤（User-Based）**：找到与目标用户兴趣相似的其他用户，推荐这些用户喜欢的商品。
   - **物品基于的协同过滤（Item-Based）**：找到与目标商品相似的其它商品，推荐这些商品给用户。

3. **混合推荐（Hybrid Recommendation）**：结合多种推荐算法的优点，提高推荐的准确性和多样性。

#### 1.2 协同过滤算法原理

协同过滤算法是推荐系统中最常用的技术之一，其核心思想是通过用户和物品的交互行为（如评分、购买、浏览等）来发现用户之间的相似性，进而预测用户的未知喜好。协同过滤算法可以分为以下几类：

1. **基于用户的协同过滤（User-Based Collaborative Filtering）**：

   - **步骤1**：计算用户之间的相似度。常见的相似度计算方法包括余弦相似度、皮尔逊相关系数等。
   - **步骤2**：找出与目标用户最相似的用户群体。
   - **步骤3**：计算目标用户对未知物品的预测评分。常见的方法有加权平均评分、加权用户均值等。

   Python代码示例：

   ```python
   def cosine_similarity(rating1, rating2):
       dot_product = sum(rating1[i] * rating2[i] for i in range(len(rating1)) if rating1[i] and rating2[i])
       mag1 = sqrt(sum(x ** 2 for x in rating1 if x))
       mag2 = sqrt(sum(x ** 2 for x in rating2 if x))
       return dot_product / (mag1 * mag2)

   # 假设我们有两个用户评分矩阵
   user_ratings_1 = [5, 3, 0, 1]
   user_ratings_2 = [4, 0, 0, 1]
   print(cosine_similarity(user_ratings_1, user_ratings_2))
   ```

2. **基于物品的协同过滤（Item-Based Collaborative Filtering）**：

   - **步骤1**：计算物品之间的相似度。与用户相似度计算类似，可以使用余弦相似度等。
   - **步骤2**：找到与目标物品最相似的其它物品。
   - **步骤3**：计算目标用户对未知物品的预测评分。

   Python代码示例：

   ```python
   def item_similarity(item1, item2, ratings):
       ratings_vector1 = ratings[item1]
       ratings_vector2 = ratings[item2]
       return cosine_similarity(ratings_vector1, ratings_vector2)

   ratings = {
       'item1': [5, 3, 0, 1],
       'item2': [4, 0, 0, 1],
       'item3': [0, 5, 0, 2],
       'item4': [1, 0, 0, 3]
   }
   print(item_similarity('item1', 'item2', ratings))
   ```

#### 1.4 用户喜好预测的数学模型

在个性化推荐系统中，用户喜好预测是一个核心问题。通过构建数学模型，我们可以更好地理解用户的行为模式，从而提高推荐的准确性和效果。用户喜好预测的数学模型通常包括用户偏好表示、相似度计算和评分预测三个关键环节。

##### 1.4.1 用户偏好表示

用户偏好表示是将用户的行为数据转换为数学形式的过程。常见的用户偏好表示方法有向量表示和矩阵表示。

1. **向量表示**：

   向量表示法将用户的喜好视为一个向量，每个维度表示用户对某个项目的评分或偏好。例如，对于用户对5个物品的评分，我们可以将其表示为向量 `[5, 3, 0, 1, 4]`。

   ```python
   user_preferences = [5, 3, 0, 1, 4]
   ```

2. **矩阵表示**：

   矩阵表示法将用户与物品的关系表示为一个矩阵，矩阵的每个元素表示用户对物品的评分。例如，用户对5个物品的评分可以表示为矩阵：

   $$ 
   \begin{bmatrix} 
   5 & 3 & 0 & 1 & 4 \\ 
   4 & 0 & 2 & 3 & 1 \\ 
   0 & 5 & 4 & 0 & 2 
   \end{bmatrix}
   $$

   ```python
   user_ratings_matrix = [
       [5, 3, 0, 1, 4],
       [4, 0, 2, 3, 1],
       [0, 5, 4, 0, 2]
   ]
   ```

##### 1.4.2 相似度计算

相似度计算是评估用户之间或物品之间相似程度的过程。常见的相似度计算方法包括余弦相似度、皮尔逊相关系数等。

1. **余弦相似度**：

   余弦相似度衡量两个向量在空间中的夹角余弦值，范围在[-1, 1]之间。余弦相似度越大，表示两个向量越相似。

   $$ 
   \text{cosine\_similarity}(\vec{u}, \vec{v}) = \frac{\vec{u} \cdot \vec{v}}{||\vec{u}|| \cdot ||\vec{v}||}
   $$

   ```python
   def cosine_similarity(u, v):
       dot_product = sum(u[i] * v[i] for i in range(len(u)) if u[i] and v[i])
       norm_u = math.sqrt(sum(u[i] ** 2 for i in range(len(u))))
       norm_v = math.sqrt(sum(v[i] ** 2 for i in range(len(v))))
       return dot_product / (norm_u * norm_v)
   ```

2. **皮尔逊相关系数**：

   皮尔逊相关系数衡量两个变量之间的线性相关性，范围在[-1, 1]之间。皮尔逊相关系数越大，表示两个变量之间的线性关系越强。

   $$ 
   \text{pearson\_correlation}(u, v) = \frac{\sum{(u_i - \mu_u)(v_i - \mu_v)}}{\sqrt{\sum{(u_i - \mu_u)^2} \cdot \sum{(v_i - \mu_v)^2}}}
   $$

   ```python
   def pearson_correlation(u, v):
       mean_u = sum(u) / len(u)
       mean_v = sum(v) / len(v)
       diff_u = [u[i] - mean_u for i in range(len(u))]
       diff_v = [v[i] - mean_v for i in range(len(v))]
       numerator = sum(diff_u[i] * diff_v[i] for i in range(len(u)))
       denominator = math.sqrt(sum(diff_u[i] ** 2 for i in range(len(u))) * sum(diff_v[i] ** 2 for i in range(len(v))))
       return numerator / denominator
   ```

##### 1.4.3 评分预测

评分预测是根据用户和物品的相似度，预测用户对未知物品的评分。常见的评分预测方法有基于用户的协同过滤和基于物品的协同过滤。

1. **基于用户的协同过滤**：

   基于用户的协同过滤通过计算用户之间的相似度，预测用户对未知物品的评分。评分预测公式如下：

   $$ 
   \text{predicted\_rating} = \sum_{u' \in \text{neighbor\_users}} s_{u', i} \cdot \text{similarity}(u, u')
   $$

   其中，\(s_{u', i}\) 表示用户 \(u'\) 对物品 \(i\) 的评分，\(\text{similarity}(u, u')\) 表示用户 \(u\) 和 \(u'\) 之间的相似度。

   ```python
   def predict_ratings(user_similarity, user_ratings, known_ratings):
       predicted_ratings = []
       for i in range(len(user_ratings)):
           if i in known_ratings:
               predicted_ratings.append(known_ratings[i])
           else:
               predicted_rating = sum(user_similarity[u][i] * user_ratings[u] for u in user_similarity if u in known_ratings)
               predicted_ratings.append(predicted_rating)
       return predicted_ratings
   ```

2. **基于物品的协同过滤**：

   基于物品的协同过滤通过计算物品之间的相似度，预测用户对未知物品的评分。评分预测公式如下：

   $$ 
   \text{predicted\_rating} = \sum_{i' \in \text{neighbor\_items}} s_{i', i} \cdot \text{similarity}(i, i')
   $$

   其中，\(s_{i', i}\) 表示物品 \(i'\) 和 \(i\) 之间的相似度，\(\text{similarity}(i, i')\) 表示物品 \(i\) 和 \(i'\) 之间的相似度。

   ```python
   def predict_ratings(item_similarity, item_ratings, known_ratings):
       predicted_ratings = []
       for i in range(len(item_ratings)):
           if i in known_ratings:
               predicted_ratings.append(known_ratings[i])
           else:
               predicted_rating = sum(item_similarity[i][j] * item_ratings[j] for j in item_similarity if j in known_ratings)
               predicted_ratings.append(predicted_rating)
       return predicted_ratings
   ```

### 第3章 协同过滤算法原理

#### 3.1 协同过滤算法概述

协同过滤算法（Collaborative Filtering）是推荐系统中最常用的技术之一，其核心思想是通过分析用户之间的行为模式，预测用户对未知内容的喜好。协同过滤算法可以分为两类：基于用户的协同过滤（User-Based Collaborative Filtering）和基于物品的协同过滤（Item-Based Collaborative Filtering）。

**基于用户的协同过滤**：

基于用户的协同过滤通过计算用户之间的相似度，找到与目标用户兴趣相似的其他用户，并推荐这些用户喜欢的商品。以下是基于用户的协同过滤算法的基本步骤：

1. **用户相似度计算**：首先，需要计算用户之间的相似度。常用的相似度计算方法包括余弦相似度、皮尔逊相关系数等。
2. **找到相似用户**：根据用户相似度计算结果，找到与目标用户最相似的K个用户。
3. **评分预测**：对于目标用户未评分的物品，计算这些物品在这些相似用户中的平均评分，作为目标用户的预测评分。

**基于物品的协同过滤**：

基于物品的协同过滤通过计算物品之间的相似度，找到与目标物品相似的其它物品，并推荐这些物品给用户。以下是基于物品的协同过滤算法的基本步骤：

1. **物品相似度计算**：首先，需要计算物品之间的相似度。与用户相似度计算类似，可以使用余弦相似度等。
2. **找到相似物品**：根据物品相似度计算结果，找到与目标物品最相似的K个物品。
3. **评分预测**：对于目标用户未评分的物品，计算这些物品在这些相似用户中的平均评分，作为目标用户的预测评分。

**协同过滤算法的优点和缺点**：

- **优点**：

  1. **无监督学习**：协同过滤算法无需标签数据，适用于新用户和新物品的推荐。
  2. **高扩展性**：可以轻松处理大量用户和物品。
  3. **个性化推荐**：通过分析用户行为，提供个性化的推荐。

- **缺点**：

  1. **冷启动问题**：新用户或新物品由于缺乏历史数据，难以获得准确的推荐。
  2. **数据稀疏性**：用户行为数据通常是稀疏的，导致相似度计算不准确。
  3. **准确性问题**：协同过滤算法容易受到噪声数据和异常值的影响。

#### 3.2 用户相似度计算

用户相似度计算是协同过滤算法的关键步骤，其目的是找到与目标用户兴趣相似的其他用户。常用的相似度计算方法包括余弦相似度、皮尔逊相关系数等。

**余弦相似度**：

余弦相似度是一种衡量两个向量夹角余弦值的相似度度量。其计算公式如下：

$$
\text{cosine\_similarity}(\vec{u}, \vec{v}) = \frac{\vec{u} \cdot \vec{v}}{||\vec{u}|| \cdot ||\vec{v}||}
$$

其中，\(\vec{u}\) 和 \(\vec{v}\) 分别表示两个用户的行为向量，\(\cdot\) 表示点积，\(||\vec{u}||\) 和 \(||\vec{v}||\) 分别表示两个向量的欧几里得范数。

**皮尔逊相关系数**：

皮尔逊相关系数是一种衡量两个变量之间线性相关性的度量。其计算公式如下：

$$
\text{pearson\_correlation}(u, v) = \frac{\sum{(u_i - \mu_u)(v_i - \mu_v)}}{\sqrt{\sum{(u_i - \mu_u)^2} \cdot \sum{(v_i - \mu_v)^2}}}
$$

其中，\(u\) 和 \(v\) 分别表示两个用户的行为向量，\(\mu_u\) 和 \(\mu_v\) 分别表示两个用户行为的均值。

**相似度阈值设定**：

在计算用户相似度时，通常需要设定一个相似度阈值，用于筛选出相似度较高的用户。相似度阈值可以根据实际需求和数据分布进行设定。常用的方法包括基于统计学方法和基于经验值的方法。

**统计学方法**：

统计学方法通过计算用户相似度的分布，设定一个合适的阈值。例如，可以选择相似度分布的中位数或均值作为阈值。

**经验值方法**：

经验值方法通过尝试不同的阈值，选择能够获得最佳推荐效果的最优阈值。例如，可以通过交叉验证等方法，选择能够最大化准确率或召回率的阈值。

#### 3.3 评分预测

评分预测是根据用户相似度和用户对物品的评分，预测用户对未知物品的评分。常见的评分预测方法包括加权平均评分和加权用户均值等。

**加权平均评分**：

加权平均评分方法通过计算相似用户对物品的平均评分，作为目标用户的预测评分。其计算公式如下：

$$
\text{predicted\_rating} = \sum_{u' \in \text{neighbor\_users}} s_{u', i} \cdot \text{similarity}(u, u')
$$

其中，\(s_{u', i}\) 表示用户 \(u'\) 对物品 \(i\) 的评分，\(\text{similarity}(u, u')\) 表示用户 \(u\) 和 \(u'\) 之间的相似度。

**加权用户均值**：

加权用户均值方法通过计算相似用户对物品的评分与用户均值的差值，作为目标用户的预测评分。其计算公式如下：

$$
\text{predicted\_rating} = \mu_u + \sum_{u' \in \text{neighbor\_users}} (\text{similarity}(u, u') \cdot (s_{u', i} - \mu_{u'}))
$$

其中，\(\mu_u\) 和 \(\mu_{u'}\) 分别表示用户 \(u\) 和 \(u'\) 的均值。

**预测准确性评估**：

评分预测的准确性是评价推荐系统效果的重要指标。常见的评估方法包括均方误差（Mean Squared Error, MSE）、均绝对误差（Mean Absolute Error, MAE）等。

- **均方误差**：

  均方误差计算预测评分与实际评分之差的平方的平均值。其计算公式如下：

  $$
  \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (\text{predicted\_rating}_i - \text{actual\_rating}_i)^2
  $$

  其中，\(n\) 表示预测评分的数量，\(\text{predicted\_rating}_i\) 和 \(\text{actual\_rating}_i\) 分别表示第 \(i\) 个预测评分和实际评分。

- **均绝对误差**：

  均绝对误差计算预测评分与实际评分之差的绝对值的平均值。其计算公式如下：

  $$
  \text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |\text{predicted\_rating}_i - \text{actual\_rating}_i|
  $$

#### 4.1 数学模型概述

用户喜好预测是推荐系统中的核心任务之一，其目的是通过分析用户的历史行为，预测用户对未知物品的喜好程度。在数学模型中，用户喜好预测通常涉及到用户偏好表示、相似度计算和评分预测等步骤。本文将详细介绍这些步骤及其背后的数学原理。

**用户偏好表示**

用户偏好表示是将用户的历史行为数据转换为数学形式的过程。常见的表示方法有向量表示和矩阵表示。

1. **向量表示**：

   向量表示法将用户的喜好视为一个向量，每个维度表示用户对某个项目的评分或偏好。例如，对于用户对5个物品的评分，我们可以将其表示为向量 \([5, 3, 0, 1, 4]\)。

   ```python
   user_preferences = [5, 3, 0, 1, 4]
   ```

2. **矩阵表示**：

   矩阵表示法将用户与物品的关系表示为一个矩阵，矩阵的每个元素表示用户对物品的评分。例如，用户对5个物品的评分可以表示为矩阵：

   $$
   \begin{bmatrix}
   5 & 3 & 0 & 1 & 4 \\
   4 & 0 & 2 & 3 & 1 \\
   0 & 5 & 4 & 0 & 2
   \end{bmatrix}
   $$

   ```python
   user_ratings_matrix = [
       [5, 3, 0, 1, 4],

   ]
   ```

**相似度计算**

相似度计算是评估用户之间或物品之间相似程度的过程。常见的相似度计算方法包括余弦相似度、皮尔逊相关系数等。

1. **余弦相似度**：

   余弦相似度衡量两个向量在空间中的夹角余弦值，范围在 \([-1, 1]\) 之间。余弦相似度越大，表示两个向量越相似。

   $$
   \text{cosine\_similarity}(\vec{u}, \vec{v}) = \frac{\vec{u} \cdot \vec{v}}{||\vec{u}|| \cdot ||\vec{v}||}
   $$

   ```python
   def cosine_similarity(u, v):
       dot_product = sum(u[i] * v[i] for i in range(len(u)) if u[i] and v[i])
       norm_u = math.sqrt(sum(u[i] ** 2 for i in range(len(u))))
       norm_v = math.sqrt(sum(v[i] ** 2 for i in range(len(v))))
       return dot_product / (norm_u * norm_v)
   ```

2. **皮尔逊相关系数**：

   皮尔逊相关系数衡量两个变量之间的线性相关性，范围在 \([-1, 1]\) 之间。皮尔逊相关系数越大，表示两个变量之间的线性关系越强。

   $$
   \text{pearson\_correlation}(u, v) = \frac{\sum{(u_i - \mu_u)(v_i - \mu_v)}}{\sqrt{\sum{(u_i - \mu_u)^2} \cdot \sum{(v_i - \mu_v)^2}}}
   $$

   ```python
   def pearson_correlation(u, v):
       mean_u = sum(u) / len(u)
       mean_v = sum(v) / len(v)
       diff_u = [u[i] - mean_u for i in range(len(u))]
       diff_v = [v[i] - mean_v for i in range(len(v))]
       numerator = sum(diff_u[i] * diff_v[i] for i in range(len(u)))
       denominator = math.sqrt(sum(diff_u[i] ** 2 for i in range(len(u))) * sum(diff_v[i] ** 2 for i in range(len(v))))
       return numerator / denominator
   ```

**评分预测**

评分预测是根据用户和物品的相似度，预测用户对未知物品的评分。常见的评分预测方法有基于用户的协同过滤和基于物品的协同过滤。

1. **基于用户的协同过滤**：

   基于用户的协同过滤通过计算用户之间的相似度，找到与目标用户兴趣相似的其他用户，并推荐这些用户喜欢的商品。评分预测公式如下：

   $$
   \text{predicted\_rating} = \sum_{u' \in \text{neighbor\_users}} s_{u', i} \cdot \text{similarity}(u, u')
   $$

   其中，\(s_{u', i}\) 表示用户 \(u'\) 对物品 \(i\) 的评分，\(\text{similarity}(u, u')\) 表示用户 \(u\) 和 \(u'\) 之间的相似度。

   ```python
   def predict_ratings(user_similarity, user_ratings, known_ratings):
       predicted_ratings = []
       for i in range(len(user_ratings)):
           if i in known_ratings:
               predicted_ratings.append(known_ratings[i])
           else:
               predicted_rating = sum(user_similarity[u][i] * user_ratings[u] for u in user_similarity if u in known_ratings)
               predicted_ratings.append(predicted_rating)
       return predicted_ratings
   ```

   $$
   \text{predicted\_rating} = \sum_{i' \in \text{neighbor\_items}} s_{i', i} \cdot \text{similarity}(i, i')
   $$

   其中，\(s_{i', i}\) 表示物品 \(i'\) 和 \(i\) 之间的相似度，\(\text{similarity}(i, i')\) 表示物品 \(i\) 和 \(i'\) 之间的相似度。


**评价模型性能**

评价模型性能是评估推荐系统效果的重要步骤。常见的性能评价指标包括均方误差（MSE）、均绝对误差（MAE）等。

- **均方误差（MSE）**：

  均方误差计算预测评分与实际评分之差的平方的平均值。其计算公式如下：

  $$
  \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (\text{predicted\_rating}_i - \text{actual\_rating}_i)^2
  $$

  其中，\(n\) 表示预测评分的数量，\(\text{predicted\_rating}_i\) 和 \(\text{actual\_rating}_i\) 分别表示第 \(i\) 个预测评分和实际评分。

- **均绝对误差（MAE）**：

  均绝对误差计算预测评分与实际评分之差的绝对值的平均值。其计算公式如下：

  $$

  $$

  其中，\(n\) 表示预测评分的数量，\(\text{predicted\_rating}_i\) 和 \(\text{actual\_rating}_i\) 分别表示第 \(i\) 个预测评分和实际评分。

#### 7.1 协同过滤算法代码实现

协同过滤算法的核心在于用户和物品的相似度计算以及基于相似度预测用户对未评分物品的喜好。以下是一个简单的基于用户的协同过滤算法的实现，包含了用户相似度计算、评分预测和预测评分评估的关键步骤。

**数据准备**

首先，我们需要准备用户行为数据，该数据通常包含用户的ID、物品的ID以及用户的评分。以下是一个示例数据集：

```python
user_ratings = {
    'user1': {'item1': 5, 'item2': 3, 'item3': 0},
    'user2': {'item1': 4, 'item2': 0, 'item3': 2},
    'user3': {'item1': 0, 'item2': 5, 'item3': 4}
```

**用户相似度计算**

用户相似度计算是协同过滤算法的第一步。我们使用余弦相似度来衡量用户之间的相似度。以下是一个简单的余弦相似度计算函数：

```python
from math import sqrt

def cosine_similarity(user1, user2):
    common_items = set(user1.keys()) & set(user2.keys())
    if len(common_items) == 0:
        return 0
    
    sum_product = sum(user1[item] * user2[item] for item in common_items)
    sum_square_user1 = sum([user1[item]**2 for item in user1 if item in common_items])
    sum_square_user2 = sum([user2[item]**2 for item in user2 if item in common_items])
    
    return sum_product / sqrt(sum_square_user1 * sum_square_user2)
```

**评分预测**

在计算了用户相似度之后，我们可以利用这些相似度来预测用户对未评分物品的喜好。以下是一个简单的评分预测函数：

```python
def predict_ratings(user_similarity, user_ratings, known_ratings):
    predicted_ratings = {}
    for user, known_user_ratings in user_ratings.items():
        if user not in known_ratings:
            continue
        
        predicted_rating = sum(user_similarity[user][u] * known_user_ratings[u] for u in user_similarity[user] if u in known_ratings)
        predicted_ratings[user] = predicted_rating
    
    return predicted_ratings
```

**预测评分评估**

最后，我们需要评估预测评分的准确性。以下是一个简单的评估函数，使用均方误差（MSE）来评估预测评分与实际评分的差距：

```python
from sklearn.metrics import mean_squared_error

def evaluate_ratings(predicted_ratings, actual_ratings):
    mse = mean_squared_error(list(predicted_ratings.values()), list(actual_ratings.values()))
    return mse
```

#### 7.3 代码解读与分析

在本节中，我们将对上述代码进行详细解读，并分析协同过滤算法的关键步骤和核心实现。

**用户相似度计算**

用户相似度计算的核心是余弦相似度函数 `cosine_similarity`。该函数通过计算两个用户的评分向量之间的点积和欧几里得范数，得到相似度值。相似度值的范围在 [0, 1] 之间，越接近 1 表示两个用户越相似。关键代码如下：

```python
def cosine_similarity(user1, user2):
    common_items = set(user1.keys()) & set(user2.keys())
    if len(common_items) == 0:
        return 0
    
    sum_product = sum(user1[item] * user2[item] for item in common_items)
    sum_square_user1 = sum([user1[item]**2 for item in user1 if item in common_items])
    sum_square_user2 = sum([user2[item]**2 for item in user2 if item in common_items])
    
    return sum_product / sqrt(sum_square_user1 * sum_square_user2)
```

**评分预测**

评分预测函数 `predict_ratings` 利用用户相似度矩阵来预测新用户的评分。对于每个新用户，我们遍历已知用户和其评分，计算相似用户对未评分物品的平均评分，作为新用户的预测评分。关键代码如下：

```python
def predict_ratings(user_similarity, user_ratings, known_ratings):
    predicted_ratings = {}
    for user, known_ratings in user_ratings.items():
        if user not in known_ratings:
            continue
        
        predicted_rating = sum(user_similarity[user][u] * known_ratings[u] for u in user_similarity[user] if u in known_ratings)
        predicted_ratings[user] = predicted_rating
    
    return predicted_ratings
```

**预测评分评估**

预测评分评估函数 `evaluate_ratings` 使用均方误差（MSE）来评估预测评分的准确性。MSE反映了预测评分与实际评分之间的差距，值越小表示预测越准确。关键代码如下：

```python
def evaluate_ratings(predicted_ratings, actual_ratings):
    mse = mean_squared_error(list(predicted_ratings.values()), list(actual_ratings.values()))
    return mse
```
