## 第1章 分形几何基础

### 2.1 分形的定义与性质

分形是一种在几何和数学中描述非规则形状和结构的数学概念，具有自相似性和无限精细的特点。分形的基本定义可以归纳为以下几点：

1. **自相似性**：分形在不同尺度下保持相似性，即无论放大或缩小，其形状和结构都保持不变。
2. **无限精细**：分形的细节是无限精细的，即它包含了无限多个嵌套的结构。

分形的性质主要包括：

1. **不规则性**：分形具有高度不规则的结构，这种不规则性使其在传统几何中无法精确描述。
2. **非整数维数**：分形的维数不是整数，而是介于整数维数之间，如1.25维、2.25维等。

分形的分类可以根据其生成方法、形状特征和维数等不同标准进行。常见的分形类型包括：

1. **迭代函数系统（IFS）**：通过迭代映射生成分形，如康托集、谢宾斯基三角等。
2. **分形树**：通过递归生成分形，如卡拉塔利树、科赫曲线等。
3. **分形曲线**：通过数学方程生成分形，如费波那契序列、曼德尔布罗特集等。

### 2.2 分形维度的计算

分形维数是描述分形复杂程度的重要指标，它介于传统几何维数（如一维、二维、三维）之间。分形维数的计算方法主要有以下几种：

1. **盒计数法**：通过统计覆盖分形所需的盒子数量来计算分形维数。公式如下：
   \[
   D = \lim_{\epsilon \to 0} \frac{\log N(\epsilon)}{\log \epsilon}
   \]
   其中，\( N(\epsilon) \) 表示覆盖分形所需的盒子数量，\(\epsilon\) 表示盒子的边长。

2. **分形覆盖法**：通过覆盖分形所需的最小面积来计算分形维数。公式如下：
   \[
   D = \frac{\log A}{\log L}
   \]
   其中，\( A \) 表示分形的面积，\( L \) 表示分形的长度。

3. **维格纳斯特拉斯法**：通过计算分形曲线的长度与半径的关系来计算分形维数。公式如下：
   \[
   D = \frac{L}{R}
   \]
   其中，\( L \) 表示分形的长度，\( R \) 表示分形的半径。

### 2.3 分形的生成方法

分形的生成方法主要包括迭代函数系统（IFS）、分形树、分形曲线等。以下分别介绍这些方法的原理和特点：

1. **迭代函数系统（IFS）**：IFS是通过迭代映射生成分形的方法。它由一组函数组成，这些函数将平面上的点映射到另一个点上。通过多次迭代，可以得到一个复杂的分形结构。IFS的生成过程可以表示为：
   \[
   x_{n+1} = f(x_n)
   \]
   其中，\( x_n \) 表示第\( n \)次迭代的结果，\( f \) 表示迭代函数。

2. **分形树**：分形树是通过递归生成分形的方法。它从一个简单的结构开始，通过递归重复某个操作，生成一个复杂的分形结构。常见的分形树包括卡拉塔利树、科赫曲线等。

3. **分形曲线**：分形曲线是通过数学方程生成分形的方法。它通常是一个非线性方程，通过迭代计算可以得到一个复杂的分形结构。常见的分形曲线包括费波那契序列、曼德尔布罗特集等。

### 2.4 分形生成实例

以下是一个简单的分形生成实例：使用迭代函数系统（IFS）生成谢宾斯基三角。

```python
import matplotlib.pyplot as plt
import numpy as np

# 定义迭代函数系统（IFS）
def f1(x, y):
    return (1 - x, y)

def f2(x, y):
    return (x, y - 1)

def f3(x, y):
    return (2 - x, 1 - y)

# 初始化参数
N = 1000  # 迭代次数
x_min, x_max = 0, 1  # x坐标范围
y_min, y_max = 0, 1  # y坐标范围

# 创建画布
fig, ax = plt.subplots(figsize=(8, 8))
ax.set_xlim(x_min, x_max)
ax.set_ylim(y_min, y_max)

# 迭代生成分形
x, y = np.random.uniform(x_min, x_max), np.random.uniform(y_min, y_max)
for _ in range(N):
    x, y = f1(x, y) if x < y else f2(x, y) if x < 1 - y else f3(x, y)

# 绘制分形
ax.scatter(x, y, c='black', s=1)

# 显示图形
plt.show()
```
