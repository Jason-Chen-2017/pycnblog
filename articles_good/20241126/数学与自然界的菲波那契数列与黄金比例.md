#### 定义

菲波那契数列是由0和1开始的数列，后面的每一项都是前两项的和。其定义可以用数学公式表示为：
$$
F(n) =
\begin{cases}
0 & \text{如果 } n = 0 \\
1 & \text{如果 } n = 1 \\
F(n-1) + F(n-2) & \text{如果 } n > 1
\end{cases}
$$
这个数列的前几项为：0, 1, 1, 2, 3, 5, 8, 13, 21, ...

#### 递推关系

菲波那契数列的一个重要特点是它的递推关系。每一项都是前两项的和，即：
$$
F(n) = F(n-1) + F(n-2)
$$
这个递推关系可以用递归或迭代的方法来计算。递归实现的Python代码如下：

```python
def fibonacci_recursive(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibonacci_recursive(n-1) + fibonacci_recursive(n-2)

# 测试递归函数
print(fibonacci_recursive(10))  # 输出：55
```

递归方法虽然直观，但效率较低，因为它会进行大量的重复计算。迭代方法则更为高效：

```python
def fibonacci_iterative(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

# 测试迭代函数
print(fibonacci_iterative(10))  # 输出：55
```

### 黄金比例的基本性质

黄金比例（Golden Ratio），通常用希腊字母φ（Phi）表示，约为1.61803398875。它是一个无理数，可以通过将一条线段分割成两部分，使得较长部分与整体之比等于较短部分与较长部分之比来确定。这一比例在数学、艺术和科学中都有着重要的应用。本节我们将详细探讨黄金比例的定义、计算方法及其数学性质。

#### 定义

黄金比例的定义可以通过以下数学公式表示：

$$
\phi = \frac{1 + \sqrt{5}}{2}
$$

这个定义揭示了黄金比例与根号5的关系。实际上，这个定义可以转换为线段分割的形式：假设有一条线段AB，其中点C将其分割为AC和CB，使得AC与CB之比等于CB与AB之比，即：

$$
\frac{AC}{CB} = \frac{CB}{AB}
$$

由此可以得到：

$$
\frac{AC}{CB} = \frac{CB}{AC + CB} \Rightarrow AC^2 = CB \cdot (AC + CB)
$$

这个方程可以进一步化简为：

$$
AC^2 + CB^2 = AC \cdot CB
$$

这是一个典型的勾股定理形式，但在黄金比例的情况下，AC和CB的长度之比即为黄金比例φ。

#### 计算方法

计算黄金比例的方法有多种，其中一种简单的方法是基于递推关系：

$$
\phi = \frac{1 + \sqrt{5}}{2} = \frac{(1 + \sqrt{5})^2}{2 \cdot (1 + \sqrt{5})} = \frac{6 + 2\sqrt{5}}{2} = 3 + \sqrt{5}
$$

另一种常用的计算方法是基于迭代：

```python
def golden_ratio():
    a, b = 0, 1
    while True:
        a, b = b, a + b
        phi = b / a
        if abs(phi - (1 + sqrt(5)) / 2) < 1e-10:
            return phi

# 测试迭代函数
print(golden_ratio())  # 输出：1.61803398875
```

这个迭代方法通过不断计算$$ \frac{F(n+1)}{F(n)} $$，直到其值接近黄金比例φ。
