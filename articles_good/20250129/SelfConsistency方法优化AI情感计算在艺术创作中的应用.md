**3.4 算法原理的数学模型和公式**

自我一致性方法的数学模型和公式如下：

1. **目标函数**：

$$
\min_{\theta} L(\theta) = \sum_{i=1}^{n} (y_i - f(\theta, x_i))^2
$$

其中，$L(\theta)$ 是目标函数，$y_i$ 是真实标签，$f(\theta, x_i)$ 是模型在输入$x_i$下的预测输出，$\theta$ 是模型参数。

2. **更新规则**：

$$
\theta_{new} = \theta_{old} - \alpha \cdot \nabla_{\theta} L(\theta)
$$

其中，$\theta_{new}$ 和 $\theta_{old}$ 分别是更新前后的模型参数，$\alpha$ 是学习率，$\nabla_{\theta} L(\theta)$ 是目标函数关于参数$\theta$ 的梯度。

3. **一致性检查**：

$$
\text{if } \nabla_{\theta} L(\theta) \text{ is zero} \text{ or close to zero} \text{ then } \text{break}
$$

        x = x.view(x.size(0), -1)
        x = nn.functional.relu(self.fc1(x))
        x = nn.functional.relu(self.fc2(x))
        x = self.fc3(x)
        return x

# 定义自我一致性优化器
class SelfConsistencyOptimizer(optim.Optimizer):
    def __init__(self, params, consistency_loss_fn, consistency_weight=0.1):
        defaults = dict(consistency_weight=consistency_weight)
        super().__init__(params, defaults)
        self.consistency_loss_fn = consistency_loss_fn

    def step(self, closure=None):
        loss = self closure() if closure is not None else None
        for group in self.param_groups:
            for p in group['params']:
                if p.grad is None:
                    continue
                d_p = p.grad.data
                consistency_loss = self.consistency_loss_fn(d_p)
                p.data = p.data - group['lr'] * (d_p + group['consistency_weight'] * consistency_loss)
        if loss is not None:
            return loss
        else:
            return torch.tensor(0.0)

# 训练模型
def train(model, train_loader, optimizer, criterion, num_epochs=10):
    model.train()
    for epoch in range(num_epochs):
        running_loss = 0.0
        for inputs, labels in train_loader:
            optimizer.zero_grad()
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()
            running_loss += loss.item()
        print(f'Epoch {epoch+1}/{num_epochs}, Loss: {running_loss/len(train_loader)}')

# 加载训练数据集
train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),

train_dataset = ImageFolder(root='./data/train', transform=train_transform)

criterion = nn.MSELoss()
