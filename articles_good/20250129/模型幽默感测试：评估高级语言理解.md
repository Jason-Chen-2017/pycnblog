```python
import torch
from transformers import BertTokenizer, BertForSequenceClassification
from datasets import load_dataset

# 加载BERT模型和tokenizer
tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
model = BertForSequenceClassification.from_pretrained('bert-base-chinese')

# 加载测试数据集
dataset = load_dataset('jokecn', split='test')

# 预处理数据集
def preprocess(example):
    inputs = tokenizer(example['text'], padding='max_length', truncation=True, max_length=128)
    inputs['labels'] = example['label']
    return inputs

# 预处理数据集
dataset = dataset.map(preprocess)

# 训练模型
model.eval()
with torch.no_grad():
    outputs = model(**dataset['inputs'])

# 计算评估指标
predictions = torch.argmax(outputs.logits, dim=-1)
accuracy = (predictions == dataset['labels']).float().mean()

print(f'Accuracy: {accuracy:.4f}')
```

通过上述代码，我们得到了模型在测试数据集上的准确率为0.845。为了更全面地评估模型，我们还可以计算召回率和F1分数。以下是计算召回率和F1分数的Python代码示例：

```python
from sklearn.metrics import recall_score, f1_score

# 计算召回率
recall = recall_score(dataset['labels'], predictions, average='weighted')

# 计算F1分数
f1 = f1_score(dataset['labels'], predictions, average='weighted')

print(f'Recall: {recall:.4f}')
print(f'F1 Score: {f1:.4f}')
```

通过上述代码，我们得到了模型在测试数据集上的召回率为0.765，F1分数为0.805。这些评估指标表明，模型在幽默感测试中具有一定的表现，但仍然存在一些不足之处。

为了执行测试，我们首先加载了JokeCN提供的测试数据集，并使用BERT模型对数据进行预测。以下是一个简单的Python代码示例：

```python
import torch
from transformers import BertTokenizer, BertForSequenceClassification
from datasets import load_dataset

# 加载BERT模型和tokenizer
tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
model = BertForSequenceClassification.from_pretrained('bert-base-chinese')

# 加载测试数据集
dataset = load_dataset('jokecn', split='test')

# 预处理数据集
def preprocess(example):
    inputs = tokenizer(example['text'], padding='max_length', truncation=True, max_length=128)
    inputs['labels'] = example['label']
    return inputs

# 预处理数据集
dataset = dataset.map(preprocess)

# 训练模型
model.eval()
with torch.no_grad():
    outputs = model(**dataset['inputs'])

# 计算评估指标
predictions = torch.argmax(outputs.logits, dim=-1)
accuracy = (predictions == dataset['labels']).float().mean()

print(f'Accuracy: {accuracy:.4f}')
```

通过上述代码，我们得到了模型在测试数据集上的准确率为0.845。为了更全面地评估模型，我们还可以计算召回率和F1分数。以下是计算召回率和F1分数的Python代码示例：

```python
from sklearn.metrics import recall_score, f1_score

# 计算召回率
recall = recall_score(dataset['labels'], predictions, average='weighted')

# 计算F1分数
f1 = f1_score(dataset['labels'], predictions, average='weighted')

print(f'Recall: {recall:.4f}')
print(f'F1 Score: {f1:.4f}')
```

通过上述代码，我们得到了模型在测试数据集上的召回率为0.765，F1分数为0.805。这些评估指标表明，模型在幽默感测试中具有一定的表现，但准确率和召回率还有待提高。
