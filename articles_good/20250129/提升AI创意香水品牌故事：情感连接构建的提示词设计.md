#### 3.2 Python源代码

接下来，我们将提供一个简单的Python源代码示例，用于实现情感分析模型，从而生成提示词。以下是代码的基本框架：

```python
import nltk
from nltk.sentiment import SentimentIntensityAnalyzer

# 初始化情感分析器
sia = SentimentIntensityAnalyzer()

# 输入文本
text = "这款香水让我感到清新和愉悦。"

# 进行情感分析
sentiment_score = sia.polarity_scores(text)

# 根据情感得分生成提示词
if sentiment_score['compound'] > 0.05:
    keyword = "清新愉悦"
elif sentiment_score['compound'] < -0.05:
    keyword = "清新愉悦"
else:
    keyword = "清新愉悦"

print(keyword)
```

在这个代码示例中，我们使用了NLTK库中的情感分析器来计算输入文本的情感得分。根据情感得分的正负和大小，系统会生成相应的提示词。

#### 3.3 数学模型和公式

情感分析的核心在于计算文本的情感得分，这通常涉及到以下数学模型和公式：

$$
\text{sentiment\_score} = \text{SIA}\left(\text{compound}\right)
$$

其中，$\text{SIA}$代表情感分析器，$\text{compound}$代表情感得分。情感得分通常是一个介于-1到1之间的值，表示文本的情感极性。如果$\text{compound}$值接近1，表示文本具有积极的情感；如果$\text{compound}$值接近-1，表示文本具有消极的情感；如果$\text{compound}$值接近0，表示文本具有中性的情感。

为了更直观地展示情感得分，我们可以使用以下公式：

$$
\text{compound} = \frac{\sum_{i=1}^{n} \text{word\_score}_{i}}{n}
$$

其中，$\text{word\_score}_{i}$代表每个词汇的情感得分，$n$代表词汇的总数。通过计算每个词汇的情感得分的平均值，我们可以得到文本的整体情感得分。

# core.py

from flask import Flask, request, jsonify
from nltk.sentiment import SentimentIntensityAnalyzer
import sqlite3

app = Flask(__name__)
sia = SentimentIntensityAnalyzer()

# 数据库连接
def get_db_connection():
    conn = sqlite3.connect('database.db')
    conn.row_factory = sqlite3.Row
    return conn

# 情感分析
@app.route('/api/analyze', methods=['POST'])
def analyze():
    data = request.json
    text = data['text']
    sentiment_score = sia.polarity_scores(text)
    return jsonify(sentiment_score)

# 故事生成
@app.route('/api/generate_story', methods=['POST'])
def generate_story():
    data = request.json
    sentiment_score = data['sentiment_score']
    if sentiment_score['compound'] > 0.05:
        story = "你的故事充满了快乐和活力。"
    elif sentiment_score['compound'] < -0.05:
        story = "你的故事带有一种忧郁的浪漫。"
    else:
        story = "你的故事显得平和而宁静。"
    return jsonify(story)

# 用户反馈
@app.route('/api/feedback', methods=['POST'])
def feedback():
    data = request.json
    story_id = data['story_id']
    rating = data['rating']
    # 在数据库中记录反馈
    conn = get_db_connection()
    c = conn.cursor()
    c.execute("INSERT INTO feedback (story_id, rating) VALUES (?, ?)", (story_id, rating))
    conn.commit()
    conn.close()
    return jsonify({"status": "success"})

if __name__ == '__main__':
    app.run(debug=True)
