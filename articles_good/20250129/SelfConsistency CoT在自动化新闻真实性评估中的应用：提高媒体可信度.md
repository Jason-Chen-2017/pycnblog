### 1.1 问题背景

#### 1.1.1 自我一致性概念的产生与发展

自我一致性概念源于心理学领域，主要用于研究个体思维和行为的一致性。随着人工智能和大数据技术的不断发展，自我一致性概念逐渐应用于新闻真实性评估领域。在互联网时代，信息爆炸使得新闻真实性评估成为一大难题，自动化新闻真实性评估技术应运而生。

#### 1.1.2 自我一致性概念的定义与内涵

自我一致性概念指的是个体在思维和行为上保持一致性的倾向。在新闻真实性评估中，自我一致性概念表示新闻内容在逻辑、事实、来源等方面的一致性。一个高度自我一致性的新闻内容更可能是真实的。

#### 1.1.3 自我一致性概念在新闻真实性评估中的应用

自我一致性概念在新闻真实性评估中的应用主要体现在对新闻内容的一致性分析上。通过分析新闻内容的自我一致性，可以有效地识别虚假新闻和有误导性的信息。

### 1.2 核心概念

#### 1.2.1 自我一致性概念的性质与特征

自我一致性概念具有以下几个性质和特征：

1. **一致性**：新闻内容在逻辑、事实、来源等方面应保持一致。
2. **客观性**：新闻内容应基于客观事实，避免主观臆断。
3. **可信度**：新闻内容的自我一致性越高，其可信度越高。

#### 1.2.2 自我一致性概念与其他相关概念的联系与区别

自我一致性概念与其他相关概念，如真实性、准确性、可信度等有一定的联系和区别。真实性和准确性主要关注新闻内容与客观事实的符合程度，而自我一致性则关注新闻内容在内部逻辑和结构上的一致性。可信度则是对新闻内容可信程度的综合评价。

### 1.3 研究目的与意义

from nltk.tokenize import word_tokenize
from nltk.corpus import stopwords

def preprocess_text(text):
    # 去除停用词
    stop_words = set(stopwords.words('english'))
    word_tokens = word_tokenize(text)
    filtered_text = [word for word in word_tokens if not word in stop_words]
    return filtered_text

def calculate_similarity(text1, text2):
