### 5.3 数学模型和公式

#### 5.3.1 哈希函数

哈希函数用于生成数据块的唯一标识。常见的哈希函数包括SHA-256和SHA-3。公式如下：

$$H = SHA-256(D)$$

其中，$H$ 是生成的哈希值，$D$ 是原始数据。

#### 5.3.2 共识算法

$$Consensus = PoW\_Solution \ or \ PoS\_Stake$$

其中，$Consensus$ 是共识结果，$PoW\_Solution$ 是工作量证明解决方案，$PoS\_Stake$ 是权益证明质押量。

#### 5.3.3 智能合约执行

智能合约的执行是基于预定义的逻辑。执行过程包括输入验证、状态更新和事件触发。公式如下：

$$Contract\_Execution = Input\_Validation \ and \ State\_Update \ and \ Event\_Trigger$$

其中，$Contract\_Execution$ 是智能合约的执行结果，$Input\_Validation$ 是输入验证结果，$State\_Update$ 是状态更新结果，$Event\_Trigger$ 是事件触发结果。

import json
from eth_account import Account
from web3 import Web3

class Blockchain:
    def __init__(self, web3):
        self.web3 = web3
        self.chain = web3.eth.chain
        self.account = Account.privateKeyToAccount(web3.toBytes(hexstr="your_private_key"))

    def add_block(self, work_info):
        transaction = self.web3.eth.contract(
            abi=self.contract_abi,
            bytecode=self.contract_bytecode,
            address=self.contract_address
        )
        tx = transaction.functions.registerCopyright(work_info).transact({"from": self.account.address, "gas": 2000000})
        self.web3.eth.wait_for_transaction_receipt(tx)
        return tx

    def query_copyright(self, work_hash):
        transaction = self.web3.eth.contract(
            abi=self.contract_abi,
            bytecode=self.contract_bytecode,
            address=self.contract_address
        )
        tx = transaction.functions.queryCopyright(work_hash).call()
        return tx

    def is_infringement(self, work_hash):
        transaction = self.web3.eth.contract(
            abi=self.contract_abi,
            bytecode=self.contract_bytecode,
            address=self.contract_address
        )
        tx = transaction.functions.isInfringement(work_hash).call()
        return tx
