#### Python代码示例

以下是一个简单的神经网络算法的实现：

```python
import numpy as np

# 初始化权重
weights = np.random.rand(3, 1)

# 前向传播
def forward_pass(inputs):
    return np.dot(inputs, weights)

# 反向传播
def backward_pass(inputs, outputs):
    d_weights = (outputs - inputs) * inputs
    return d_weights

# 训练模型
for epoch in range(100):
    inputs = np.array([[1], [2], [3]])
    outputs = np.array([[1], [0], [-1]])
    forward_output = forward_pass(inputs)
    d_weights = backward_pass(forward_output, outputs)
    weights += d_weights
```
