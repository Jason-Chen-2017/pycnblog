### 2.1 量子密码学原理

#### 2.1.1 量子密钥分发

量子密钥分发是一种利用量子态传输密钥的方法，其基本原理是量子态的不可克隆定理。根据量子力学的原理，当一个量子态被观测时，其状态会发生变化，这种变化是无法隐藏的。因此，如果窃听者试图截获量子密钥，将会不可避免地引起量子态的变化，从而被通信双方检测到。

量子密钥分发的基本步骤如下：

1. **密钥生成**：通信双方（通常是Alice和Bob）通过量子通道生成原始密钥。这个过程通常涉及量子态的制备和测量，例如，使用光子的偏振态或时间量子态。

2. **密钥传输**：生成的原始密钥通过量子通道传输给对方。量子通道可以是光纤、自由空间或其他量子通信渠道。

3. **密钥筛选**：通信双方对传输的密钥进行筛选，去除因量子态变化或传输噪声导致的错误密钥。这一过程通常涉及量子态的纠缠测量和解纠缠操作。

4. **密钥确认**：通过经典的通信渠道（如互联网），双方对筛选后的密钥进行比对，确认密钥的正确性。

5. **密钥加密**：最终确认无误的密钥用于加密和解密通信数据。

#### 2.1.2 量子纠缠

量子纠缠是量子物理学中的一个基本现象，它描述了两个或多个粒子之间在量子态上的强烈关联。即使这些粒子相隔很远，一个粒子的状态变化也会立即影响到另一个粒子的状态。这种超距作用是经典物理学所无法解释的。

2. **非对称加密算法**：非对称加密算法使用一对密钥，即公钥和私钥。公钥用于加密，私钥用于解密。其优点是密钥分发简单，但计算复杂度较高，不适合大规模数据传输。

   $$\rho = |\psi\rangle\langle\psi|$$

在量子密钥分发过程中，由于信道噪声和其他因素，量子态可能会发生错误。误差校正的目的是检测并纠正这些错误。以下是一些基本的误差校正公式：

   $$|\psi_0\rangle = \frac{1}{\sqrt{32}} (|0000\rangle + |0001\rangle + |0010\rangle + |0011\rangle + |0100\rangle + |0101\rangle + ... + |1111\rangle)$$

2. **错误检测与纠正**：

     $$E = \frac{1}{\sqrt{2}} (|0\rangle - |1\rangle)$$
