# 编译代码
subprocess.run(["python", "setup.py", "build"], check=True)

# 打包代码

# 打包成功后更新版本号

1. **安装Docker**：确保您的系统上已安装Docker。如果未安装，请访问Docker官网下载并安装。

2. **创建Dockerfile**：在项目根目录下创建一个名为`Dockerfile`的文件，内容如下：

    ```Dockerfile
    FROM python:3.8-slim

    WORKDIR /app

    COPY requirements.txt .

    RUN pip install -r requirements.txt

    COPY . .

    CMD ["python", "app.py"]
    ```

    其中，`requirements.txt` 文件应包含项目所需的依赖库。

3. **构建Docker镜像**：在项目根目录下执行以下命令，构建Docker镜像：

    ```bash
    docker build -t my_project .
    ```

4. **运行Docker容器**：运行Docker容器，启动项目：

    ```bash
    docker run -d -p 8000:8000 my_project
    ```

    这将启动一个名为 `my_project` 的Docker容器，并将容器的8000端口映射到宿主机的8000端口。
