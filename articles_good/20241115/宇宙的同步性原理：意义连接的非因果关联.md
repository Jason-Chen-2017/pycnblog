在非因果关联中，两个事件A和B之间的关系可以通过条件概率来描述。条件概率公式为：

$$
P(A|B) = \frac{P(A \cap B)}{P(B)}
$$

其中，$P(A|B)$表示在事件B发生的条件下，事件A发生的概率，$P(A \cap B)$表示事件A和事件B同时发生的概率，$P(B)$表示事件B发生的概率。

**例子：计算事件A在事件B发生条件下的概率**

假设有两个事件A和B，已知以下概率：

- $P(A) = 0.3$
- $P(B) = 0.4$
- $P(A \cap B) = 0.2$

我们可以使用条件概率公式计算在事件B发生的条件下，事件A发生的概率：

$$
P(A|B) = \frac{P(A \cap B)}{P(B)} = \frac{0.2}{0.4} = 0.5
$$

这个结果表示在事件B发生的条件下，事件A发生的概率为0.5。

def visualize_correlation(correlation_matrix):
    fig, ax = plt.subplots()
    cax = ax.matshow(correlation_matrix)
    fig.colorbar(cax)
    plt.xlabel('GDP增长率')
    plt.ylabel('失业率')
    plt.title('GDP增长率与失业率、通货膨胀率之间的关联')

# 主函数

    data = read_economic_data(filename)
    correlation_matrix = calculate_correlation(data)
    print(f'经济指标之间的相关性矩阵：\n{correlation_matrix}')
    visualize_correlation(correlation_matrix)

if __name__ == '__main__':
    main()
