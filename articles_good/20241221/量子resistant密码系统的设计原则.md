#### 1.1 量子密码学的起源与历史

量子密码学起源于1980年代，其理论基础是量子力学的基本原理，特别是量子纠缠和量子叠加态。第一篇关于量子密码学的论文由Charles H. Bennett和Garrett J. Murphy在1984年发表，提出了量子密钥分发（Quantum Key Distribution，QKD）的概念。QKD利用量子力学的不可克隆定理，确保密钥传输的安全。

#### 1.2 量子密码学的基本原理

量子密码学的核心原理是量子纠缠和量子叠加态。量子纠缠是指两个或多个量子系统之间的强相关性，即使它们相隔很远，一个系统的状态也会即时影响另一个系统的状态。量子叠加态则允许一个量子系统同时处于多个状态。这两个原理为量子密码学提供了安全保障。

#### 1.3 量子密码学与经典密码学的区别

量子密码学与经典密码学在安全性原理上存在显著差异。经典密码学依赖于密钥的安全传输，而量子密码学则利用量子态的不可克隆性和测量干扰确保密钥的安全。此外，量子密码学在加密和解密过程中引入了量子态，使攻击者无法在不被察觉的情况下窃取信息。

```python
from Cryptodome.Cipher import AES
from Cryptodome.Random import get_random_bytes
import hashlib
import base64

def encrypt_message(message, key):
    cipher = AES.new(key, AES.MODE_EAX)
    ciphertext, tag = cipher.encrypt_and_digest(message.encode('utf-8'))
    return base64.b64encode(cipher.nonce + cipher.tag + ciphertext).decode('utf-8')

def decrypt_message(encrypted_message, key):
    data = base64.b64decode(encrypted_message)
    nonce, tag, ciphertext = data[:16], data[16:32], data[32:]
    cipher = AES.new(key, AES.MODE_EAX, nonce=nonce)
    return cipher.decrypt_and_verify(ciphertext, tag).decode('utf-8')

# 生成密钥
key = get_random_bytes(16)

# 加密消息
message = "Hello, World!"
encrypted_message = encrypt_message(message, key)
print("Encrypted message:", encrypted_message)

# 解密消息
decrypted_message = decrypt_message(encrypted_message, key)
print("Decrypted message:", decrypted_message)
```
