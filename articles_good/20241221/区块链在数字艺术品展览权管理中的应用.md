#### 1.1.1 分布式账本

分布式账本是区块链技术的核心组件之一。它不同于传统的集中式数据库，数据不是存储在一个中央服务器上，而是分布在网络中的多个节点上。每个节点都维护一份完整的数据副本，这些副本之间通过加密算法和共识机制进行同步和验证，以确保数据的完整性和一致性。

#### 1.1.2 去中心化

去中心化是区块链技术的重要特点之一。在去中心化的系统中，没有中央权威机构来控制和管理整个网络。所有节点都是平等的，每个节点都可以参与数据的记录、验证和传播。这意味着区块链网络具有较高的容错性和抗攻击性，因为即使某些节点失效或被攻击，整个网络仍然能够正常运行。

class Artwork:
    def __init__(self, title, creator, creation_date, copyright_info):
        self.title = title
        self.creator = creator
        self.creation_date = creation_date
        self.copyright_info = copyright_info
        self.hash = self.compute_hash()

    def compute_hash(self):
        # 使用SHA-256算法计算哈希值
        return hashlib.sha256(str(self.__dict__).encode()).hexdigest()

#### 4.1.2 上链过程

1. **数据收集**：艺术家或版权机构将数字艺术品的版权信息、创作信息等数据收集并封装为一个`Artwork`对象。

2. **数据加密**：为了保护数据隐私，可以使用加密算法对艺术品的版权信息进行加密。例如，可以使用RSA算法进行加密。

3. **数据上传**：将加密后的艺术品数据上传到区块链网络中的某个节点。节点接收到数据后，将其封装为一个区块链交易（Transaction）。

4. **交易验证**：节点对交易进行验证，确保交易的有效性和合法性。验证通过后，交易将被添加到区块中。

5. **区块生成**：节点将验证后的交易添加到区块中，并使用加密算法计算区块的哈希值。

6. **区块传播**：将生成的区块广播到网络中的其他节点，进行全网同步。
