2. **常见算法优化技术**：
   - **分治策略**：将复杂问题分解成若干个规模较小的子问题，分别解决，再合并结果。例如，快速排序和归并排序。
   - **动态规划**：通过存储子问题的解，避免重复计算，以减少时间复杂度。例如，计算斐波那契数列。
   - **贪心算法**：每一步都做出在当前状态下最优的选择，期望最终得到整体最优解。例如，找零问题。

3. **算法选择**：

    # 边缘检测
    edges = cv2.Canny(filtered_image, threshold1=100, threshold2=200)
    
    return edges
