  ```python
def build_demand_Tracking_Matrix(demands, projects):
    matrix = [[] for _ in range(len(demands) + 1)]
    for demand in demands:
        for project in projects:
            if demand in project.requirements:
                matrix[demands.index(demand) + 1].append(project.name)
  ```
```python
    return matrix
```

### 数学模型和数学公式

在需求追踪矩阵中，有两个重要的评估指标：跟踪覆盖率（Tracking Coverage）和变更影响（Change Impact）。

#### 需求追踪矩阵的评估指标

1. **跟踪覆盖率（Tracking Coverage）**：

   跟踪覆盖率是衡量需求追踪效果的一个重要指标，表示已追踪需求与总需求的比例。

   **数学公式**：

   $$\text{Tracking Coverage} = \frac{\text{Tracked Requirements}}{\text{Total Requirements}}$$

   **示例**：

   假设项目中有100个需求，其中80个需求已经在需求追踪矩阵中被实现，则跟踪覆盖率为：

   $$\text{Tracking Coverage} = \frac{80}{100} = 0.8 \text{ 或 } 80\%$$

2. **变更影响（Change Impact）**：

   变更影响是指需求变更对项目的影响程度，通常用于评估变更的紧急性和影响范围。

   **数学公式**：

   $$\text{Change Impact} = \sum_{i=1}^{n} \text{Impact of Change on Requirement } i$$

   **示例**：

   假设项目中有5个需求变更，每个需求变更的影响分别为：5, 10, 15, 20, 25。则总变更影响为：

   $$\text{Change Impact} = 5 + 10 + 15 + 20 + 25 = 75$$

#### 需求追踪矩阵的评估方法

为了更全面地评估需求追踪矩阵，我们可以结合跟踪覆盖率和变更影响，对项目进行综合评估。

**综合评估公式**：

$$\text{Project Assessment} = \text{Tracking Coverage} \times \text{Change Impact}$$

**示例**：

假设跟踪覆盖率为0.8，变更影响为75，则项目评估结果为：

$$\text{Project Assessment} = 0.8 \times 75 = 60$$

这个评估结果表示项目在需求追踪方面表现良好，但变更影响较大，需要进一步关注和管理。

```python
def build_demand_Tracking_Matrix(demands, projects):
    matrix = [[] for _ in range(len(demands) + 1)]
    for demand in demands:
        for project in projects:
            if demand in project.requirements:
                matrix[demands.index(demand) + 1].append(project.name)
    return matrix
```
