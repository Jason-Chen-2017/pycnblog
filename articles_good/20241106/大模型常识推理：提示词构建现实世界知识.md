#### 1.1 大模型概述

大模型（Large Models），也称为大规模模型，是深度学习领域近年来的一大突破。这类模型通常具有数十亿甚至数万亿个参数，通过对海量数据进行训练，以实现对复杂任务的高效处理。典型的大模型包括谷歌的BERT、微软的Turing Model、以及OpenAI的GPT系列等。

大模型的出现，使得自然语言处理（NLP）、计算机视觉（CV）等领域取得了显著的进展。例如，BERT在文本分类、问答系统、情感分析等任务上取得了超越传统方法的性能。GPT则展示了在生成文本、机器翻译等任务上的强大能力。

#### 1.2 常识推理的重要性

常识推理（Common Sense Reasoning）是人工智能研究中的一个重要方向。它指的是系统在处理信息时，运用日常生活中的常识进行推理，以解决复杂问题。例如，当我们看到一句话“太阳在天空中”，我们可以立即推理出“白天到了”。

常识推理在人工智能中的应用十分广泛，它不仅有助于提高系统的智能水平，还能帮助解决许多实际问题。例如，在智能客服中，系统需要运用常识推理来理解用户的意图，并提供合适的回应。

#### 1.3 提示词在常识推理中的作用

提示词（Prompt）是引导大模型进行推理的关键因素。一个好的提示词可以帮助大模型快速、准确地理解问题，从而提高推理的效率和准确性。

提示词的设计需要考虑多个因素，包括问题的背景、目标任务的性质、模型的特点等。例如，在问答系统中，提示词通常是一个问题，它需要引导模型生成合适的回答。

### 第2章：大模型基础

#### 2.1 大模型的基本概念

大模型通常基于神经网络架构，特别是深度神经网络（DNN）。这些模型具有大量的参数，通过前向传播和反向传播算法进行训练。大模型的训练通常需要大量的数据和计算资源。

#### 2.2 大模型的训练与优化

大模型的训练过程包括以下几个步骤：

1. 数据预处理：对数据进行清洗、归一化等处理。
2. 模型初始化：初始化模型的参数。
3. 前向传播：计算输入数据的特征表示。
4. 计算损失：计算预测值与真实值之间的差距。
5. 反向传播：更新模型参数，以减小损失。

大模型的优化策略包括：

1. 学习率调度：调整学习率以防止过拟合。
2. 正则化：添加惩罚项以防止模型过拟合。
3. 批量归一化：加速训练过程，提高模型稳定性。

#### 2.3 大模型的结构与架构

大模型的结构多样，但通常包括以下几个部分：

1. 输入层：接收外部输入，如文本、图像等。
2. 隐藏层：包含多层神经网络，用于特征提取和变换。
3. 输出层：生成预测结果，如文本、标签等。

常见的深度学习模型包括：

- 卷积神经网络（CNN）
- 循环神经网络（RNN）
- 生成对抗网络（GAN）

常识推理是指基于日常生活中的常识进行推理的过程。它涉及到信息的获取、处理、存储和利用。常识推理可以看作是一种基于规则的推理，它依赖于大量的背景知识和经验。

### 第1章：大模型与常识推理简介

#### 1.1 大模型概述

大模型（Large Models）是深度学习领域中的一个重要概念，它指的是具有数十亿甚至数万亿个参数的神经网络模型。这些模型通过对海量数据进行训练，能够学习到复杂的模式和规律，从而在自然语言处理、计算机视觉等多个领域取得了显著的突破。

大模型的发展可以追溯到20世纪90年代，当时神经网络的研究主要集中在简单的模型上，如多层感知机（MLP）和循环神经网络（RNN）。然而，随着计算能力的提升和数据量的增加，研究者们开始尝试训练更大规模的模型。2006年，Hinton提出了深度信念网络（DBN），开启了深度学习的新时代。此后，研究者们相继提出了卷积神经网络（CNN）、循环神经网络（RNN）、长短时记忆网络（LSTM）等模型，这些模型在处理复杂数据方面展现了强大的能力。

近年来，随着计算资源的进一步丰富和深度学习算法的优化，大模型的发展迎来了新的高潮。代表性的模型包括谷歌的BERT、微软的Turing Model、以及OpenAI的GPT系列。BERT在文本分类、问答系统、情感分析等任务上取得了超越传统方法的性能，GPT则在生成文本、机器翻译等任务上展示了强大的能力。

#### 1.2 常识推理的重要性

常识推理（Common Sense Reasoning）是人工智能研究中的一个重要方向，它指的是在处理信息时，利用日常生活中的常识进行推理。常识推理是人类智能的重要组成部分，它帮助我们在面对新情况时，能够迅速做出合理的判断和决策。

在人工智能领域，常识推理的应用非常广泛。例如，在自然语言处理中，常识推理可以帮助模型理解句子的含义，解决语义歧义问题；在计算机视觉中，常识推理可以帮助模型识别图像中的物体，理解物体的属性和关系；在智能客服中，常识推理可以帮助系统理解用户的意图，提供合适的回应。

此外，常识推理在自动驾驶、智能家居、医疗诊断等领域也有着重要的应用。例如，在自动驾驶中，常识推理可以帮助车辆理解交通规则，做出正确的驾驶决策；在智能家居中，常识推理可以帮助系统理解用户的行为习惯，提供个性化的服务。

提示词在常识推理中的作用主要体现在以下几个方面：

1. **引导模型理解问题**：提示词可以提供问题的背景信息和关键信息，帮助模型更好地理解问题的含义。例如，在问答系统中，提示词可以是一个具体的问题，引导模型生成合适的回答。

2. **增强模型推理能力**：通过设计合适的提示词，可以增强模型的推理能力。例如，在多轮对话中，可以将用户的上一轮回答和本轮问题组合作为提示词，帮助模型更好地理解上下文。

3. **提高模型泛化能力**：好的提示词可以引导模型学习到更通用的知识，提高模型的泛化能力。例如，在训练模型时，可以设计多样化的提示词，使模型能够处理不同类型的问题。

4. **优化模型性能**：通过调整提示词的长度、组合方式等，可以优化模型的性能。例如，较短的提示词可以更好地捕捉问题的核心信息，避免模型过拟合。

总之，提示词在常识推理中扮演着重要的角色，它不仅能够引导模型理解问题，还能增强模型的推理能力和泛化能力。提示词的设计需要考虑多个因素，包括问题的背景、目标任务的性质、模型的特点等。通过合理设计提示词，可以显著提高大模型在常识推理任务中的性能。

### 第2章：大模型基础

#### 2.1 大模型的基本概念

大模型（Large Models）是深度学习领域中的一种模型，其显著特征是具有大量参数，通常在数十亿到数万亿个参数之间。这种规模使得大模型能够处理复杂任务，具备较强的学习能力和泛化能力。

大模型的发展历程可以追溯到2006年，Hinton提出的深度信念网络（Deep Belief Network, DBN）。随后，研究者们相继提出了卷积神经网络（Convolutional Neural Network, CNN）、循环神经网络（Recurrent Neural Network, RNN）、长短时记忆网络（Long Short-Term Memory, LSTM）等模型，这些模型在图像识别、语音识别等任务上取得了显著成果。然而，随着数据量的增加和计算能力的提升，研究者们开始尝试训练更大规模的模型，从而诞生了如今的大模型。

大模型的应用领域广泛，包括但不限于自然语言处理（Natural Language Processing, NLP）、计算机视觉（Computer Vision, CV）、推荐系统（Recommender System）、强化学习（Reinforcement Learning, RL）等。例如，BERT（Bidirectional Encoder Representations from Transformers）在NLP任务中取得了突破性进展，GPT（Generative Pre-trained Transformer）在生成文本和机器翻译任务中表现出色。

#### 2.2 大模型的训练与优化

大模型的训练是一个复杂且资源消耗巨大的过程。其基本步骤包括数据预处理、模型初始化、前向传播、计算损失、反向传播和参数更新。

1. **数据预处理**：在训练大模型之前，需要对数据进行预处理。预处理步骤通常包括数据清洗、归一化、数据增强等。数据清洗旨在去除数据中的噪声和错误；归一化则通过缩放数据值，使得模型训练更加稳定；数据增强通过生成数据的不同版本，增加模型的泛化能力。

2. **模型初始化**：初始化模型的参数对于模型的训练过程至关重要。常用的初始化方法包括随机初始化、高斯初始化、Xavier初始化等。随机初始化简单易行，但可能导致梯度消失或爆炸；高斯初始化和Xavier初始化旨在解决梯度消失问题，提高模型训练的稳定性。

3. **前向传播**：在前向传播过程中，输入数据通过网络的各个层，最终生成输出。在这个过程中，网络通过权重和激活函数将输入映射到输出。前向传播的目的是计算输出值和相应的损失。

4. **计算损失**：损失函数用于衡量预测值和真实值之间的差距。常用的损失函数包括均方误差（MSE）、交叉熵（Cross Entropy）等。计算损失是评估模型性能的重要步骤，它帮助模型了解当前参数的优劣。

5. **反向传播**：反向传播是通过计算损失对网络参数的梯度，从而更新网络参数的过程。梯度是衡量损失相对于参数的变化率，通过反向传播，可以将损失从输出层传播到输入层，更新各个层的参数。

6. **参数更新**：更新参数的目的是减小损失，提高模型性能。常用的更新方法包括梯度下降（Gradient Descent）、Adam优化器等。梯度下降是一种简单有效的参数更新方法，而Adam优化器结合了动量和自适应学习率，在训练过程中表现出色。

#### 2.3 大模型的结构与架构

大模型的结构通常包含多个层次，每个层次负责不同的任务。以下是几种常见的大模型架构：

1. **卷积神经网络（CNN）**：CNN是一种用于图像识别和处理的神经网络架构，其核心是卷积层。卷积层通过卷积操作提取图像的特征，如边缘、纹理等。CNN在图像分类、目标检测等领域取得了显著成果。

2. **循环神经网络（RNN）**：RNN是一种能够处理序列数据的神经网络架构，其核心是循环单元。循环单元通过记忆机制，保留序列中的信息，使得模型能够捕捉序列中的长期依赖关系。RNN在自然语言处理、语音识别等领域表现出色。

3. **长短时记忆网络（LSTM）**：LSTM是RNN的一种变体，通过引入门控机制，解决了RNN在处理长序列数据时的梯度消失和梯度爆炸问题。LSTM在语音识别、机器翻译等领域得到广泛应用。

4. **生成对抗网络（GAN）**：GAN是一种由生成器和判别器组成的对抗性神经网络。生成器生成与真实数据相似的数据，判别器则用于区分真实数据和生成数据。GAN在图像生成、图像修复等领域展现了强大的能力。

5. **Transformer**：Transformer是一种基于自注意力机制的神经网络架构，特别适用于处理序列数据。Transformer通过多头自注意力机制和前馈神经网络，实现了对序列中信息的全局捕捉和局部建模。BERT、GPT等大模型都是基于Transformer架构。

这些大模型架构各有优缺点，选择合适的架构取决于任务需求和数据特性。通过合理设计模型结构，可以充分发挥大模型的优势，实现高性能的预测和推理。

### 第3章：常识推理机制

#### 3.1 常识推理的基本概念

常识推理（Common Sense Reasoning）是人工智能领域中一个重要的研究方向，它指的是在处理信息时，利用日常生活中的常识进行推理和决策。常识推理是人类智能的核心组成部分，它帮助我们理解世界、做出合理判断和预测。在人工智能领域，常识推理的研究旨在构建能够模拟人类常识推理能力的智能系统，以解决复杂的问题和任务。

常识推理的基本概念包括：

- **常识**：常识是指人们普遍认同的、无意识的知识和信念，它们通常不需要通过直接经验或学习来获取。常识包括各种领域的事实和规则，如物理规律、社会规范、文化习俗等。

- **推理**：推理是指从已知信息出发，通过逻辑推理得出新的结论或推断。在常识推理中，推理过程通常涉及从常识库中检索相关事实和规则，然后运用逻辑推理方法进行推理。

- **推理过程**：常识推理过程包括信息获取、信息处理、推理和知识整合等步骤。信息获取是指从各种来源获取信息，如文本、图像、声音等；信息处理是指对获取的信息进行清洗、分类、归纳等处理；推理是指运用常识和逻辑规则进行推理，形成假设或结论；知识整合是指将推理结果整合为有意义的知识体系。

#### 3.2 常识推理的过程

常识推理的过程可以分为以下几个步骤：

1. **信息获取**：常识推理的第一步是获取信息。信息可以来源于各种渠道，如感知、记忆、文本、图像、声音等。在人工智能系统中，信息获取通常涉及自然语言处理、图像识别、语音识别等技术，以提取有用的知识。

2. **信息处理**：获取到的信息需要经过处理，以便于后续的推理。信息处理包括数据的清洗、分类、归纳等操作。例如，在文本处理中，需要对文本进行分词、去停用词、词性标注等预处理操作。

3. **推理**：在信息处理完成后，系统根据常识库中的事实和规则进行推理。推理过程通常涉及逻辑推理、概率推理、归纳推理等方法。例如，在逻辑推理中，系统可以基于已知的事实和逻辑规则得出新的结论。

4. **知识整合**：推理结果需要整合为有意义的知识体系。知识整合包括将推理结果与已有的知识进行关联、更新和扩展。例如，在问答系统中，系统可以将推理结果整合为答案，并在知识库中进行更新。

#### 3.3 常识推理的挑战与问题

尽管常识推理在人工智能领域中具有广泛的应用前景，但仍然面临着许多挑战和问题：

1. **数据不足**：常识推理依赖于大量的背景知识，但实际获取到的数据往往有限。数据不足可能导致模型无法充分学习到常识，从而影响推理的准确性。

2. **异常情况处理**：现实世界中的情况复杂多变，常识推理系统需要能够处理异常情况。例如，当系统遇到从未见过的场景或问题时，如何进行合理的推理和决策。

3. **多模态整合**：常识推理通常涉及多种模态的信息，如文本、图像、声音等。如何有效地整合这些多模态信息，是常识推理中的一个重要问题。

4. **推理效率**：常识推理通常是一个复杂的过程，涉及到大量的计算和推理操作。如何提高推理效率，使得系统能够实时地处理问题，是一个重要的挑战。

5. **推理可解释性**：常识推理系统通常是一个黑盒模型，其内部的推理过程难以解释。如何提高推理的可解释性，使得用户能够理解系统的推理过程和结果，是一个重要的研究方向。

为了解决这些挑战，研究者们提出了许多方法和技术，如知识图谱、多模态学习、强化学习等。通过不断的研究和探索，常识推理在人工智能中的应用将越来越广泛，为构建更智能、更可靠的智能系统提供支持。

### 第4章：提示词设计原理

#### 4.1 提示词的生成方法

提示词（Prompt）是引导大模型（如BERT、GPT等）进行推理和生成的重要工具。有效的提示词设计能够显著提高模型的性能和推理质量。提示词的生成方法可以分为自动生成和手动设计两种。

**自动生成方法**：

1. **模板填充**：这是一种最常见的自动生成方法。它预先设计一组模板，根据不同的任务和输入数据，将模板中的特定部分进行填充。例如，对于问答任务，模板可能是“你对这个问题有什么看法？”对于分类任务，模板可能是“这段文本属于哪一类？”。

2. **语义生成**：这种方法利用自然语言处理技术，如词嵌入、语义分析等，自动生成具有特定含义的提示词。语义生成可以基于已有的语言模型或通过训练专门的模型实现。

**手动设计方法**：

手动设计提示词通常需要领域专家的知识和经验。这种方法的主要优势是能够根据具体任务的需求，设计出最合适的提示词。

1. **问题导向设计**：根据问题的类型和特点，设计特定的提示词。例如，在问答系统中，设计问题性的提示词；在情感分析中，设计引导模型识别情感的提示词。

2. **任务导向设计**：根据任务的性质和目标，设计符合任务需求的提示词。例如，在生成文本的任务中，设计引导模型生成连贯、有逻辑的文本的提示词。

#### 4.2 提示词的优化策略

提示词的优化策略对于提高模型性能至关重要。以下是一些常见的优化策略：

1. **提示词长度**：提示词的长度会影响模型的学习过程。较短的提示词可能无法提供足够的信息，而较长的提示词可能导致模型过拟合。因此，需要根据任务的具体需求，调整提示词的长度。

2. **提示词多样性**：通过设计多样化的提示词，可以增强模型对不同类型问题的适应能力。例如，对于同一问题，可以设计多个不同形式的提示词，如疑问句、陈述句等。

3. **上下文信息**：在提示词中加入上下文信息，可以帮助模型更好地理解问题的背景和含义。例如，在问答系统中，可以加入问题相关的背景信息，以提高答案的准确性。

4. **提示词组合**：将多个提示词组合使用，可以增强模型的推理能力。例如，在多轮对话中，可以将用户的上一轮回答和新问题组合作为提示词，以维持对话的连贯性。

5. **提示词定制**：根据具体的任务和场景，定制化设计提示词。例如，在特定领域的任务中，可以使用专业术语和领域知识作为提示词，以提高模型在特定领域的表现。

#### 4.3 提示词的有效性评估

评估提示词的有效性是提示词设计的重要环节。以下是一些常用的评估方法：

1. **性能指标**：通过评估模型在特定任务上的性能指标，如准确率、召回率、F1分数等，来评估提示词的效果。性能指标能够量化提示词对模型性能的提升。

2. **用户反馈**：通过用户对提示词和模型输出的反馈，评估提示词的用户体验。用户反馈可以提供定性的评估，帮助识别提示词的改进方向。

3. **对比实验**：设计对比实验，比较不同提示词的效果。通过对比实验，可以识别出哪些提示词能够显著提高模型的性能。

4. **迁移学习**：利用迁移学习的方法，评估提示词在新的任务或数据集上的效果。迁移学习能够验证提示词的泛化能力，确保其不仅在特定任务上有效，也能在更广泛的应用中表现良好。

通过以上方法，可以全面评估提示词的有效性，为提示词的设计和优化提供有力的支持。

### 第5章：大模型在常识推理中的应用

#### 5.1 大模型在常识推理中的集成

大模型在常识推理中的应用主要通过将大模型与常识推理机制相结合，以提升推理的效率和准确性。这一集成过程通常涉及以下几个步骤：

1. **数据预处理**：对输入数据进行预处理，包括文本的分词、去停用词、词性标注等操作。预处理步骤的目的是将原始数据转化为适合大模型处理的形式。

2. **特征提取**：利用大模型的特征提取能力，将预处理后的数据转化为高维向量表示。例如，BERT模型能够将输入文本转换为 contextualized word embeddings，从而捕捉文本中的上下文信息。

3. **推理过程**：通过大模型的推理机制，对提取的特征进行推理。在这一过程中，大模型运用其学到的知识库和模式识别能力，对输入问题进行推理，生成合理的答案或结论。

4. **知识整合**：将推理结果与已有的知识进行整合，形成完整、连贯的知识体系。知识整合步骤旨在确保推理结果的合理性和一致性。

### 第6章：现实世界知识的获取与表示

#### 6.1 现实世界知识的来源

现实世界知识（Real-World Knowledge）是人工智能系统理解和处理现实世界信息的重要基础。这些知识来源于多个渠道，涵盖了人类经验、科学研究和日常生活中的各种信息。以下是一些主要的知识来源：

1. **公开数据集**：许多公开的数据集提供了丰富的现实世界知识。这些数据集通常经过清洗和处理，可以用于训练和评估人工智能模型。例如，IMDB电影评论数据集、COCO物体检测数据集和WikiText-103文本数据集等。

2. **网页数据**：互联网上存在大量的网页数据，这些数据包含了各种现实世界知识。通过爬虫技术，可以从网页中提取信息，用于人工智能模型的训练和推理。

3. **社交媒体数据**：社交媒体平台如Twitter、Facebook等，是用户生成内容的宝库。这些数据包含了丰富的现实世界知识，但同时也需要处理噪声、隐私和误导性问题。

4. **专业数据库**：许多专业领域，如医学、法律和金融等，都有专门的知识库和数据库。这些数据库通常由专业人士维护，提供了高质量的领域知识。

5. **传感器数据和物联网（IoT）**：传感器和物联网设备可以实时收集各种环境数据，如温度、湿度、地理位置等。这些数据为人工智能系统提供了关于现实世界的实时信息。

6. **人类专家**：人类专家的知识是现实世界知识的重要来源。通过专家的指导和知识传授，可以将专家的经验和洞察力转化为系统的知识。

#### 6.2 现实世界知识的表示方法

现实世界知识的表示是构建人工智能系统的关键步骤。以下是一些常用的知识表示方法：

1. **知识图谱（Knowledge Graph）**：知识图谱是一种图形结构，用于表示实体及其之间的关系。在知识图谱中，实体用节点表示，关系用边表示。这种方法能够有效地组织和表示复杂的关系网络，便于推理和查询。

2. **本体论（Ontology）**：本体论是一种形式化的知识表示方法，用于描述领域中的概念及其之间的关系。本体论提供了领域知识的框架，使得知识表示更加系统和结构化。

3. **语义网络（Semantic Network）**：语义网络通过节点和边来表示概念和概念之间的关系。与知识图谱相比，语义网络通常更简单，更侧重于概念和关系的表示。

4. **知识库（Knowledge Base）**：知识库是一种包含事实和规则的集合，用于表示领域知识。知识库可以通过手工编写或自动抽取生成，可以用于支持推理和决策。

5. **文本表示**：文本表示是将自然语言文本转化为机器可处理的向量形式。常见的文本表示方法包括词袋模型、TF-IDF和词嵌入（如Word2Vec、BERT等）。这些方法能够捕捉文本的语义信息，为文本处理提供了有效的工具。

6. **图像表示**：图像表示是将图像数据转化为机器可处理的向量形式。常用的图像表示方法包括卷积神经网络（CNN）和生成对抗网络（GAN）。这些方法能够提取图像中的特征，为图像理解和分析提供了基础。

7. **音频表示**：音频表示是将音频信号转化为机器可处理的向量形式。常用的音频表示方法包括梅尔频率倒谱系数（MFCC）和卷积神经网络（CNN）。这些方法能够提取音频中的特征，用于语音识别和音频分类。

#### 6.3 现实世界知识的整合与更新

现实世界知识的整合与更新是确保知识库的时效性和准确性的重要步骤。以下是一些常用的方法：

1. **知识融合（Knowledge Fusion）**：知识融合是指将来自不同来源的知识进行整合，消除冗余和冲突，形成统一的知识体系。知识融合可以通过对知识进行比对、合并和更新实现。

2. **知识更新（Knowledge Update）**：知识更新是指定期更新知识库，以保持知识的时效性和准确性。知识更新可以通过定期从新的数据源中提取信息，或者通过用户反馈进行修正和改进。

3. **知识共享（Knowledge Sharing）**：知识共享是指通过知识共享平台和工具，实现知识的传播和利用。知识共享可以促进知识库的扩展和优化，提高整个组织的知识管理水平。

4. **知识图谱更新（Knowledge Graph Update）**：知识图谱更新是指对知识图谱中的节点和边进行修改和扩展，以反映现实世界的最新变化。知识图谱更新可以通过实时数据流和事件驱动的方式实现。

5. **机器学习（Machine Learning）**：机器学习技术可以用于自动发现和更新知识。通过监督学习或无监督学习，可以识别新的模式和关系，并将其融入知识库。

6. **自动化知识获取（Automated Knowledge Acquisition）**：自动化知识获取是指通过自动化的方法，从各种数据源中提取知识。自动化知识获取可以通过自然语言处理、图像识别和传感器数据融合等技术实现。

通过上述方法，可以有效地整合和更新现实世界知识，确保知识库的时效性和准确性，为人工智能系统提供可靠的知识基础。

import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset

# 构建时间序列数据集
prices = np.array([float(x) for x in open_prices.split(',')]) / 100.0
targets = np.array([prices[i + 1] for i in range(len(prices) - 1)])

# 转换为Tensor
prices_tensor = torch.tensor(prices).float()
targets_tensor = torch.tensor(targets).float()

# 创建数据加载器
batch_size = 32
train_data = TensorDataset(prices_tensor, targets_tensor)
train_loader = DataLoader(train_data, batch_size=batch_size, shuffle=True)

# 构建LSTM模型
class LSTMModel(nn.Module):
    def __init__(self, input_size, hidden_size, num_layers):
        super(LSTMModel, self).__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers)
        self.fc = nn.Linear(hidden_size, 1)
    
    def forward(self, x):
        h0 = torch.zeros(self.num_layers, x.size(1), self.hidden_size)
        c0 = torch.zeros(self.num_layers, x.size(1), self.hidden_size)
        
        out, _ = self.lstm(x, (h0, c0))
        out = self.fc(out[-1, :, :])
        return out

# 训练模型
model = LSTMModel(input_size=1, hidden_size=50, num_layers=2)
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

num_epochs = 100
for epoch in range(num_epochs):
    for i, (x, y) in enumerate(train_loader):
        x = x.unsqueeze(-1)
        y = y.unsqueeze(-1)
        
        # 前向传播
        outputs = model(x)
        loss = criterion(outputs, y)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        if (i + 1) % 100 == 0:
            print(f'Epoch [{epoch + 1}/{num_epochs}], Step [{i + 1}/{len(train_loader)}], Loss: {loss.item()}')

# 预测未来一周的股票价格
model.eval()
with torch.no_grad():
    future_prices = []
    current_price = torch.tensor([prices[-1]], dtype=torch.float32).unsqueeze(-1)
    for _ in range(7):
        output = model(current_price)
        future_price = output.item()
        future_prices.append(future_price)
        current_price = torch.tensor([future_price], dtype=torch.float32).unsqueeze(-1)

print(f'Predicted future prices for the next week: {future_prices}')
