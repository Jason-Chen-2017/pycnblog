```python
def generate_prompt(words):
    # 输入：words（一组单词）
    # 输出：prompt（提示词）

    # 初始化prompt为空
    prompt = ""

    # 遍历words中的每个单词
    for word in words:
        # 如果单词长度大于3，则将其添加到prompt中
        if len(word) > 3:
            prompt += word + " "

    # 去除prompt末尾的空格
    prompt = prompt.strip()

    return prompt
```

$$

- \( \theta \)：模型参数，需要通过优化算法（如梯度下降法）来调整。
