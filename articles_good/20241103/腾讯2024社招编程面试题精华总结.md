#### 第1章：C/C++编程基础

C语言和C++语言是计算机编程的重要基础，它们广泛应用于系统编程、嵌入式开发、操作系统、网络编程等领域。理解C和C++的核心概念和语言特性，对于程序员来说至关重要。

##### 1.1 C语言概述

C语言诞生于1972年，由贝尔实验室的Ken Thompson和Dennis Ritchie共同开发。C语言的简洁性和高效性使其成为编程语言中的经典。C语言的主要特点包括：

- **高级语言与低级语言结合**：C语言既具有高级语言的易用性，又能与汇编语言进行高效交互，适用于系统编程和硬件操作。
- **丰富的数据类型和运算符**：C语言提供了丰富的数据类型，包括整型、浮点型、字符型等，以及多种运算符，如算术运算符、逻辑运算符、位运算符等。
- **函数式编程**：C语言通过函数实现模块化编程，提高了代码的可重用性和可维护性。
- **指针和内存管理**：C语言中的指针提供了对内存的直接访问，通过指针可以实现复杂的内存操作和数据结构。

##### 1.2 数据类型与变量

在C语言中，数据类型是定义变量和常量的基础。C语言支持多种数据类型，包括基本数据类型和复合数据类型。

- **基本数据类型**：包括整型（int）、浮点型（float和double）、字符型（char）等。每种数据类型都有其特定的位数和取值范围。
  
- **复合数据类型**：包括数组、结构体（struct）、联合体（union）等。这些复合数据类型可以存储多个数据项，并支持复杂的内存布局。

变量是存储数据值的内存单元。在C语言中，变量的定义和使用遵循以下规则：

- **变量声明**：变量声明时需要指定其数据类型和名称。例如：`int a;`。
- **变量初始化**：变量可以在声明时进行初始化，例如：`int a = 10;`。
- **变量作用域**：变量的作用域决定了其可访问的代码范围。局部变量仅在函数内部有效，全局变量则在整个程序中可见。

##### 1.3 运算符与表达式

C语言提供了丰富的运算符，包括算术运算符、关系运算符、逻辑运算符、位运算符等。运算符的优先级和结合性决定了表达式的计算顺序。

- **算术运算符**：包括加（+）、减（-）、乘（*）、除（/）等，用于执行基本的算术运算。
- **关系运算符**：包括等于（==）、不等于（!=）、大于（>）、小于（<）等，用于比较两个值的关系。
- **逻辑运算符**：包括逻辑与（&&）、逻辑或（||）、逻辑非（!)等，用于执行逻辑运算。
- **位运算符**：包括按位与（&）、按位或（|）、按位异或（^）、左移（<<）和右移（>>）等，用于对整数进行位操作。

表达式是由运算符和操作数组成的计算单位，通过表达式的计算可以得出结果。C语言的表达式包括：

- **常量表达式**：由常量组成，例如：`5 + 3`。
- **变量表达式**：由变量组成，例如：`a + b`。
- **复合表达式**：由多个简单表达式通过运算符连接而成，例如：`a = b + c;`。

##### 1.4 控制流程

C语言提供了多种控制流程语句，用于控制程序的执行顺序，包括条件语句、循环语句和跳转语句。

- **条件语句**：用于根据条件的真假执行不同的代码块。主要包括`if`、`if-else`和`switch`语句。

  - `if`语句：根据条件执行代码块，例如：
    ```c
    if (condition) {
        // 执行代码块
    }
    ```

  - `if-else`语句：根据条件执行两个不同的代码块，例如：
    ```c
    if (condition) {
        // 执行代码块1
    } else {
        // 执行代码块2
    }
    ```

  - `switch`语句：根据不同的值执行多个代码块，例如：
    ```c
    switch (expression) {
        case value1:
            // 执行代码块1
            break;
        case value2:
            // 执行代码块2
            break;
        default:
            // 执行默认代码块
    }
    ```

- **循环语句**：用于重复执行一段代码，直到满足某个条件。主要包括`for`、`while`和`do-while`循环。

  - `for`循环：用于循环控制，例如：
    ```c
    for (初始化; 条件; 迭代表达式) {
        // 循环体
    }
    ```

  - `while`循环：根据条件重复执行代码块，例如：
    ```c
    while (condition) {
        // 循环体
    }
    ```

  - `do-while`循环：至少执行一次循环体，然后根据条件判断是否继续循环，例如：
    ```c
    do {
        // 循环体
    } while (condition);
    ```

- **跳转语句**：用于在程序中实现跳转操作。主要包括`goto`、`break`和`continue`语句。

  - `goto`语句：用于无条件跳转到指定标签位置，例如：
    ```c
    goto标签;
    标签:
        // 跳转到的标签位置
    ```

  - `break`语句：用于跳出当前的循环或switch语句，例如：
    ```c
    break;
    ```

  - `continue`语句：用于跳过当前循环迭代，继续下一次迭代，例如：
    ```c
    continue;
    ```

##### 1.5 函数

函数是C语言的核心概念之一，用于实现模块化编程和代码的重用。C语言提供了丰富的函数特性，包括函数的定义、声明和调用。

- **函数定义**：函数定义包括函数头部和函数体。函数头部指定了函数的名称、返回类型、参数列表和异常处理等，例如：
  ```c
  int add(int a, int b) {
      return a + b;
  }
  ```

- **函数声明**：函数声明用于告知编译器函数的存在及其参数和返回类型，例如：
  ```c
  int add(int a, int b);
  ```

- **函数调用**：函数调用通过函数名称和参数列表来执行函数体，例如：
  ```c
  int result = add(3, 4);
  ```

C语言还支持函数重载和默认参数等特性，提高了编程的灵活性和可读性。

##### 1.6 预处理

预处理是C语言的一个重要特性，它允许在编译之前对源代码进行操作。预处理指令以`#`符号开始，用于处理宏定义、包含头文件、条件编译等。

- **宏定义**：宏定义用于定义常量和函数，例如：
  ```c
  #define PI 3.14159
  ```

- **包含头文件**：头文件包含了常用的函数和变量声明，通过包含头文件可以实现代码的复用，例如：
  ```c
  #include <stdio.h>
  ```

- **条件编译**：条件编译用于根据特定的条件编译代码段，例如：
  ```c
  #ifdef DEBUG
      // 调试代码
  #endif
  ```

预处理指令可以提高代码的可维护性和可移植性。

##### 1.7 内存管理

内存管理是C语言编程中重要的一环，它涉及到动态内存的分配和释放。

- **动态内存分配**：通过`malloc`和`calloc`函数可以动态地分配内存，例如：
  ```c
  int *ptr = (int *)malloc(sizeof(int) * 10);
  ```

- **动态内存释放**：通过`free`函数可以释放动态分配的内存，例如：
  ```c
  free(ptr);
  ```

- **堆栈分配**：C语言中的堆栈用于局部变量的自动分配和释放，例如：
  ```c
  int a = 10;  // 在栈上自动分配内存
  ```

##### 2.2 继承与多态

- **派生类**：派生类（Derived Class）是基于基类（Base Class）创建的类。派生类继承了基类的所有属性和方法，并可以添加新的属性和方法。例如：


##### 2.6 并发编程

并发编程（Concurrency）是现代软件开发的重要方向，它允许程序同时执行多个任务，提高程序的效率和响应速度。C++11及以后的版本提供了丰富的并发编程支持，包括线程、互斥锁、条件变量等。

- **线程（Thread）**：线程是并发编程的基本单位，用于同时执行多个任务。C++11引入了线程库`<thread>`，简化了线程的使用。例如：
  ```cpp
  #include <thread>

      t.join();
      return 0;
  }
  ```

- **互斥锁（Mutex）**：互斥锁用于同步多个线程对共享资源的访问，防止数据竞争和死锁。C++11引入了互斥锁库`<mutex>`，例如：
  ```cpp
  #include <mutex>

  ```

- **条件变量（Condition Variable）**：条件变量用于线程之间的同步，使线程在满足特定条件时进行等待或唤醒。C++11引入了条件变量库`<condition_variable>`，例如：
  ```cpp
  #include <condition_variable>
  #include <thread>

  std::mutex mtx;
  std::condition_variable cv;
  bool dataAvailable = false;

  void producerFunction() {
      std::unique_lock<std::mutex> lock(mtx);
      dataAvailable = true;
      cv.notify_one();
  }

  void consumerFunction() {
      std::unique_lock<std::mutex> lock(mtx);
      cv.wait(lock, [] { return dataAvailable; });
      // 消费数据
  }
  ```

并发编程提高了程序的并行处理能力和性能。

##### 2.8 内存模型与优化

内存模型（Memory Model）描述了程序执行时的内存可见性和数据同步。C++11及以后的版本引入了内存模型的相关概念，如原子操作、内存序等。

- **原子操作**：原子操作是确保数据操作不被中断的操作。C++11引入了原子操作库`<atomic>`，例如：
  ```cpp
  #include <atomic>

  std::atomic<int> counter(0);

  void increment() {
      counter.fetch_add(1);
  }
  ```

- **内存序**：内存序描述了程序执行时内存可见性的规则。C++11定义了四种内存序级别，即顺序（Sequential Consistency）、释放顺序（Relaxed）、收购顺序（Acquire）和释放顺序（Release）。例如：
  ```cpp
  #include <atomic>

  std::atomic<int> x(0);
  std::atomic<int> y(0);
  std::atomic<int> z(0);

  void thread1() {
      x.store(1, std::memory_order_acquire);
  }

  void thread2() {
      y.store(2, std::memory_order_acquire);
  }

  void thread3() {
      int ax = x.load(std::memory_order_relaxed);
      int ay = y.load(std::memory_order_relaxed);
      if (ax == 1 && ay == 2) {
          z.store(3, std::memory_order_release);
      }
  }
  ```

内存模型和优化技术可以提高程序的性能和并发性。

##### 3.1 基本数据结构

- **链表（Linked List）**：链表是一种动态的线性数据结构，由节点组成。每个节点包含数据域和指向下一个节点的指针。链表支持插入、删除和查找操作。例如：

  ```cpp
  struct ListNode {

  ListNode* createList() {
  ```

- **栈（Stack）**：栈是一种后进先出（LIFO）的线性数据结构，用于存储元素的插入和删除。栈支持入栈（push）和出栈（pop）操作。例如：
  ```cpp
  struct Stack {
  ```

- **队列（Queue）**：队列是一种先进先出（FIFO）的线性数据结构，用于存储元素的插入和删除。队列支持入队（enqueue）和出队（dequeue）操作。例如：
  ```cpp
  struct Queue {

      int dequeue() {
          return data.front();
      }

  ```

- **树（Tree）**：树是一种非线性数据结构，由节点组成，每个节点有一个或多个子节点。树支持查找、插入和删除操作。常见的树结构包括二叉树、平衡树（AVL树）、红黑树等。例如：

  ```cpp
  struct TreeNode {
  ```

##### 3.2 算法概述

算法（Algorithm）是解决特定问题的一系列步骤。算法的效率直接决定了程序的执行速度和资源消耗。算法可以分为多种类型，如排序算法、搜索算法、图算法和动态规划等。

- **排序算法**：排序算法用于将一组数据按照特定顺序排列。常见的排序算法包括冒泡排序、选择排序、插入排序、快速排序、归并排序等。例如：
  ```cpp
  void bubbleSort(int arr[], int n) {
      for (int i = 0; i < n - 1; ++i) {
          for (int j = 0; j < n - i - 1; ++j) {
              if (arr[j] > arr[j + 1]) {
                  std::swap(arr[j], arr[j + 1]);
              }
          }
      }
  }
  ```

- **搜索算法**：搜索算法用于在数据结构中查找特定元素。常见的搜索算法包括顺序搜索、二分搜索、哈希搜索等。例如：
  ```cpp
  int binarySearch(int arr[], int l, int r, int x) {
      while (l <= r) {
          int m = l + (r - l) / 2;
          if (arr[m] == x) {
              return m;
          } else if (arr[m] < x) {
              l = m + 1;
          } else {
              r = m - 1;
          }
      }
      return -1;
  }
  ```

- **图算法**：图算法用于解决与图相关的问题，如图遍历、最短路径、最小生成树等。常见的图算法包括深度优先搜索（DFS）、广度优先搜索（BFS）、迪杰斯特拉算法（Dijkstra's algorithm）、Prim算法等。例如：
  ```cpp
  void DFS(int graph[][10], int v, bool visited[]) {
      visited[v] = true;
      std::cout << v << " ";
      for (int i = 0; i < 10; ++i) {
          if (graph[v][i] && !visited[i]) {
              DFS(graph, i, visited);
          }
      }
  }
  ```

- **动态规划**：动态规划是一种解决优化问题的算法方法，通过将问题分解为子问题并存储子问题的解，以避免重复计算。常见的动态规划问题包括背包问题、最长公共子序列、最长递增子序列等。例如：
  ```cpp
  int longestIncreasingSubsequence(int arr[], int n) {
      int dp[n];
      std::memset(dp, 0, sizeof(dp));
      for (int i = 0; i < n; ++i) {
          dp[i] = 1;
          for (int j = 0; j < i; ++j) {
              if (arr[j] < arr[i]) {
                  dp[i] = std::max(dp[i], dp[j] + 1);
              }
          }
      }
      int ans = 0;
      for (int i = 0; i < n; ++i) {
          ans = std::max(ans, dp[i]);
      }
      return ans;
  }
  ```

算法是解决编程问题和优化程序的核心工具。

##### 3.3 排序算法

排序算法是计算机科学中的经典问题，用于将一组数据按照特定顺序排列。本章将详细介绍常见的排序算法，包括冒泡排序、选择排序、插入排序、快速排序和归并排序等。

- **冒泡排序（Bubble Sort）**：冒泡排序是一种简单的排序算法，通过重复交换相邻的未排序元素，直到整个序列有序。冒泡排序的时间复杂度为O(n^2)，适用于小规模数据的排序。例如：
  ```cpp
  void bubbleSort(int arr[], int n) {
      for (int i = 0; i < n - 1; ++i) {
          for (int j = 0; j < n - i - 1; ++j) {
              if (arr[j] > arr[j + 1]) {
                  std::swap(arr[j], arr[j + 1]);
              }
          }
      }
  }
  ```

- **选择排序（Selection Sort）**：选择排序通过反复寻找最小（或最大）元素并放置在序列的起始位置，直到整个序列有序。选择排序的时间复杂度为O(n^2)，适用于小规模数据的排序。例如：
  ```cpp
  void selectionSort(int arr[], int n) {
      for (int i = 0; i < n - 1; ++i) {
          int minIndex = i;
          for (int j = i + 1; j < n; ++j) {
              if (arr[j] < arr[minIndex]) {
                  minIndex = j;
              }
          }
          std::swap(arr[i], arr[minIndex]);
      }
  }
  ```

- **插入排序（Insertion Sort）**：插入排序通过将未排序元素插入到已排序序列的正确位置，逐步构建有序序列。插入排序的时间复杂度为O(n^2)，适用于小规模数据的排序。例如：
  ```cpp
  void insertionSort(int arr[], int n) {
      for (int i = 1; i < n; ++i) {
          int key = arr[i];
          int j = i - 1;
          while (j >= 0 && arr[j] > key) {
              arr[j + 1] = arr[j];
              j--;
          }
          arr[j + 1] = key;
      }
  }
  ```

- **快速排序（Quick Sort）**：快速排序是一种高效的排序算法，通过选择一个基准元素，将序列分为两部分，然后递归地对两部分进行排序。快速排序的平均时间复杂度为O(n log n)，适用于大规模数据的排序。快速排序的伪代码如下：
  ```cpp
  function quicksort(arr, low, high)
      if low < high
          pivot = partition(arr, low, high)
          quicksort(arr, low, pivot - 1)
          quicksort(arr, pivot + 1, high)
  
  function partition(arr, low, high)
      pivot = arr[high]
      i = low - 1
      for j = low to high - 1
          if arr[j] <= pivot
              i = i + 1
              swap arr[i] with arr[j]
      swap arr[i + 1] with arr[high]
      return i + 1
  ```

- **归并排序（Merge Sort）**：归并排序是一种分治算法，通过将序列分为两部分，递归地对两部分进行排序，然后将结果合并。归并排序的时间复杂度为O(n log n)，适用于大规模数据的排序。归并排序的伪代码如下：
  ```cpp
  function mergesort(arr, low, high)
      if low < high
          mid = (low + high) / 2
          mergesort(arr, low, mid)
          mergesort(arr, mid + 1, high)
          merge(arr, low, mid, high)
  
  function merge(arr, low, mid, high)
      n1 = mid - low + 1
      n2 = high - mid
      left[] = new int[n1]
      right[] = new int[n2]
      for i = 0 to n1 - 1
          left[i] = arr[low + i]
      for j = 0 to n2 - 1
          right[j] = arr[mid + 1 + j]
      i = 0; j = 0; k = low
      while i < n1 and j < n2
          if left[i] <= right[j]
              arr[k] = left[i]
              i = i + 1
          else
              arr[k] = right[j]
              j = j + 1
          k = k + 1
      while i < n1
          arr[k] = left[i]
          i = i + 1
          k = k + 1
      while j < n2
          arr[k] = right[j]
          j = j + 1
          k = k + 1
  ```

排序算法是数据处理和分析的重要工具，不同的排序算法适用于不同的场景和规模。

##### 3.4 搜索算法

搜索算法是计算机科学中的基本问题，用于在数据结构中查找特定元素。本章将详细介绍常见的搜索算法，包括顺序搜索、二分搜索和哈希搜索等。

- **顺序搜索（Sequential Search）**：顺序搜索是一种简单的搜索算法，从数据结构的起始位置开始，逐个比较元素，直到找到目标元素或到达数据结构的末尾。顺序搜索的时间复杂度为O(n)，适用于数据量较小且无序的数据。例如：
  ```cpp
  int sequentialSearch(int arr[], int n, int x) {
      for (int i = 0; i < n; ++i) {
          if (arr[i] == x) {
              return i;
          }
      }
      return -1;
  }
  ```

- **二分搜索（Binary Search）**：二分搜索是一种高效的搜索算法，适用于有序数据结构。二分搜索通过将数据结构分为两部分，逐步缩小搜索范围，直到找到目标元素或确定其不存在。二分搜索的时间复杂度为O(log n)，适用于数据量较大且有序的数据。例如：
  ```cpp
  int binarySearch(int arr[], int l, int r, int x) {
      while (l <= r) {
          int m = l + (r - l) / 2;
          if (arr[m] == x) {
              return m;
          } else if (arr[m] < x) {
              l = m + 1;
          } else {
              r = m - 1;
          }
      }
      return -1;
  }
  ```

- **哈希搜索（Hash Search）**：哈希搜索通过哈希函数将元素映射到哈希表中，以实现快速查找。哈希搜索的时间复杂度为O(1)（平均情况），适用于具有良好散列特性的数据。例如：
  ```cpp
  struct HashTable {
      int size;
      std::vector<int> data;

      HashTable(int capacity) : size(0), data(capacity) {}

      int hash(int x) {
          return x % size;
      }

      void insert(int x) {
          int index = hash(x);
          while (data[index] != 0) {
              if (data[index] == x) {
                  return;
              }
              index = (index + 1) % size;
          }
          data[index] = x;
          size++;
      }

      bool search(int x) {
          int index = hash(x);
          while (data[index] != 0) {
              if (data[index] == x) {
                  return true;
              }
              index = (index + 1) % size;
          }
          return false;
      }
  };
  ```

搜索算法是数据处理和分析的重要工具，不同的搜索算法适用于不同的场景和数据结构。

##### 3.5 图算法

图算法是解决与图相关问题的核心工具，包括图遍历、最短路径、最小生成树等。本章将详细介绍常见的图算法，包括深度优先搜索（DFS）、广度优先搜索（BFS）、迪杰斯特拉算法（Dijkstra's algorithm）和Prim算法等。

- **深度优先搜索（DFS）**：深度优先搜索是一种遍历图的方法，通过递归地探索图中的边，直到找到一个目标节点或所有节点都被访问。DFS的时间复杂度为O(V+E)，其中V是节点数，E是边数。例如：
  ```cpp
  void DFS(int graph[][10], int v, bool visited[]) {
      visited[v] = true;
      std::cout << v << " ";
      for (int i = 0; i < 10; ++i) {
          if (graph[v][i] && !visited[i]) {
              DFS(graph, i, visited);
          }
      }
  }
  ```

- **广度优先搜索（BFS）**：广度优先搜索是一种遍历图的方法，通过逐层探索图中的节点，直到找到一个目标节点或所有节点都被访问。BFS的时间复杂度为O(V+E)，其中V是节点数，E是边数。例如：
  ```cpp
  void BFS(int graph[][10], int v, bool visited[]) {
      std::queue<int> q;
      visited[v] = true;
      q.push(v);
      while (!q.empty()) {
          int u = q.front();
          q.pop();
          std::cout << u << " ";
          for (int i = 0; i < 10; ++i) {
              if (graph[u][i] && !visited[i]) {
                  visited[i] = true;
                  q.push(i);
              }
          }
      }
  }
  ```

- **迪杰斯特拉算法（Dijkstra's algorithm）**：迪杰斯特拉算法是一种用于计算单源最短路径的算法，适用于加权无环图。Dijkstra's algorithm的时间复杂度为O(E*log(V))，其中E是边数，V是节点数。例如：
  ```cpp
  void dijkstra(int graph[][10], int V, int start) {
      std::vector<int> dist(V, INT_MAX);
      std::vector<bool> visited(V, false);
      dist[start] = 0;
      for (int i = 0; i < V; ++i) {
          int u = -1;
          for (int j = 0; j < V; ++j) {
              if (!visited[j] && (u == -1 || dist[j] < dist[u]) {
                  u = j;
              }
          }
          visited[u] = true;
          for (int j = 0; j < V; ++j) {
              if (!visited[j]) {
                  dist[j] = std::max(dist[j], dist[u] + graph[u][j]);
              }
          }
      }
      for (int i = 0; i < V; ++i) {
          std::cout << "Distance from " << start << " to " << i << ": " << dist[i] << std::endl;
      }
  }
  ```

- **Prim算法**：Prim算法是一种用于计算最小生成树的算法，适用于加权无环图。Prim算法的时间复杂度为O(E*log(V))，其中E是边数，V是节点数。例如：
  ```cpp
  void prim(int graph[][10], int V) {
      std::vector<int> key(V, INT_MAX);
      std::vector<bool> mst(V, false);
      key[0] = 0;
      for (int i = 0; i < V; ++i) {
          int u = -1;
          for (int j = 0; j < V; ++j) {
              if (!mst[j] && (u == -1 || key[j] < key[u]) {
                  u = j;
              }
          }
          mst[u] = true;
          for (int j = 0; j < V; ++j) {
              if (mst[j] && graph[u][j] && key[j] > graph[u][j]) {
                  key[j] = graph[u][j];
              }
          }
      }
      int weight = 0;
      for (int i = 0; i < V; ++i) {
          weight += key[i];
      }
      std::cout << "Minimum spanning tree weight: " << weight << std::endl;
  }
  ```

图算法是解决复杂图问题的核心工具，不同的图算法适用于不同的图结构和问题。

##### 3.6 动态规划

动态规划是一种解决优化问题的算法方法，通过将问题分解为子问题并存储子问题的解，以避免重复计算。动态规划适用于具有重叠子问题和最优子结构性质的问题。本章将详细介绍常见的动态规划问题，包括背包问题、最长公共子序列和最长递增子序列等。

- **背包问题（Knapsack Problem）**：背包问题是一种经典的动态规划问题，给定一组物品和它们的重量及价值，求解在给定重量限制下能够装入背包的最大价值。背包问题可以分为01背包和完全背包两种类型。

  - **01背包（01 Knapsack）**：01背包问题使用二位数组来存储子问题的解，时间复杂度为O(n*W)，其中n是物品数，W是背包的容量。例如：
    ```cpp
    int knapsack01(int weights[], int values[], int W, int n) {
        std::vector<std::vector<int>> dp(n + 1, std::vector<int>(W + 1, 0));
        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= W; ++j) {
                if (weights[i - 1] <= j) {
                    dp[i][j] = std::max(dp[i - 1][j], dp[i - 1][j - weights[i - 1]] + values[i - 1]);
                } else {
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }
        return dp[n][W];
    }
    ```

  - **完全背包（Full Knapsack）**：完全背包问题可以使用滚动数组来优化空间复杂度，时间复杂度为O(n*W)，其中n是物品数，W是背包的容量。例如：
    ```cpp
    int knapsackFull(int weights[], int values[], int W, int n) {
        std::vector<int> dp(W + 1, 0);
        for (int i = 1; i <= n; ++i) {
            for (int j = W; j >= weights[i - 1]; --j) {
                dp[j] = std::max(dp[j], dp[j - weights[i - 1]] + values[i - 1]);
            }
        }
        return dp[W];
    }
    ```

- **最长公共子序列（Longest Common Subsequence, L
