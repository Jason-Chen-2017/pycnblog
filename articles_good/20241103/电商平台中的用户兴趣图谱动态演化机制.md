## 第2章：核心概念与联系

### 2.1 电商平台与用户兴趣图谱概述

#### 2.1.1 电商平台的架构与运营模式

电商平台的基本架构通常包括前端展示层、业务逻辑层和数据管理层。前端展示层负责用户界面的设计，提供商品展示、搜索、购物车、支付等功能；业务逻辑层处理订单管理、库存管理、物流跟踪等业务逻辑；数据管理层则负责数据存储、数据分析和数据挖掘。

电商平台的运营模式主要包括C2C（如淘宝、eBay）、B2C（如京东、亚马逊）和O2O（线上线下结合）等。在这些模式中，电商平台通过提供商品、服务和交易场所，吸引和留住用户，实现商业价值。

#### 2.1.2 用户兴趣图谱的基本概念

用户兴趣图谱（User Interest Graph）是一种用于描述用户兴趣和行为的数据模型。它通常由用户节点、商品节点和关系边构成。用户节点表示平台上的每个用户，商品节点表示平台上的每种商品，关系边表示用户对商品的兴趣程度。

用户兴趣图谱的主要作用是揭示用户的兴趣偏好，为电商平台提供个性化的推荐服务。通过分析用户兴趣图谱，电商平台可以更好地理解用户需求，提高用户满意度和转化率。

#### 2.1.3 用户兴趣图谱的组成部分

用户兴趣图谱主要由以下几个部分组成：

1. **用户节点**：用户节点表示平台上的每个用户，通常包含用户的基本信息，如年龄、性别、地理位置等。
2. **商品节点**：商品节点表示平台上的每种商品，通常包含商品的基本信息，如商品名称、价格、类别等。
3. **兴趣关系边**：兴趣关系边表示用户与商品之间的兴趣程度。常见的兴趣关系包括点击、购买、收藏、评论等。

#### 2.1.4 用户兴趣图谱的构建方法

用户兴趣图谱的构建主要包括以下几个步骤：

1. **数据收集**：收集用户行为数据，如浏览记录、购买记录、收藏记录等。
2. **数据预处理**：对收集到的数据进行清洗、去噪和规范化处理。
3. **兴趣关系建模**：根据用户行为数据，建立用户与商品之间的兴趣关系模型。
4. **图谱构建**：将用户节点、商品节点和兴趣关系边构成用户兴趣图谱。

def collaborative_filtering(user_interest, user_id, k=5):
    user_vector = user_interest.loc[user_id]

            if item_id not in recommended_items and value > 0:

    return recommended_items
