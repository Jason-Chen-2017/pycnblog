# 第一部分: 威廉·奥尼尔的CAN SLIM概述

## 第1章: CAN SLIM的核心概念与背景

### 1.1 CAN SLIM的起源与发展

#### 1.1.1 投资策略的演变历程

投资策略从早期的简单筛选逐步发展为基于数据和算法的复杂系统。威廉·奥尼尔提出的CAN SLIM策略是这一演变过程中的重要里程碑。

#### 1.1.2 威廉·奥尼尔的CAN SLIM策略提出背景

威廉·奥尼尔通过分析大量市场数据，发现成长与价值的结合能够有效筛选出具有长期增长潜力的股票。CAN SLIM策略因此应运而生。

#### 1.1.3 CAN SLIM在现代投资中的地位

作为成长与价值投资的结合，CAN SLIM策略在现代投资中占据重要地位，广泛应用于个股筛选和资产配置。

### 1.2 CAN SLIM的核心理念

#### 1.2.1 成长与价值的融合

CAN SLIM策略将成长（CAGR、收入增长、净利润增长）与价值（市盈率、股价与收益比率）相结合，以筛选出具有成长潜力且估值合理的股票。

#### 1.2.2 CAN SLIM的核心要素分析

- CAGR（年复合增长率）：衡量公司成长能力的核心指标。
- 市盈率（P/E）：评估股票估值合理性的重要指标。
- 收入与利润增长：公司成长性的直接体现。

#### 1.2.3 CAN SLIM与传统投资策略的对比

| 指标       | CAN SLIM                | 传统价值投资     | 传统成长投资     |
|------------|-------------------------|------------------|------------------|
| 核心指标     | CAGR、收入增长、P/E     | P/E、股息率       | 收入增长率、净利润增长率 |
| 投资目标     | 成长与价值结合          | 低估值            | 高成长性          |

## 第2章: CAN SLIM的核心原理

### 2.1 CAN SLIM的数学模型

#### 2.1.1 成长与价值的量化公式

$$ 成长率 = \frac{收入增长率 + 净利润增长率}{2} $$

$$ 价值 = \frac{收入}{市盈率} \times 成长率 $$

#### 2.1.2 价值评估的数学表达

$$ 价值 = \frac{收入}{市盈率} \times 成长率 $$

def calculate_growth_rate(revenue_growth, net_profit_growth):
    return (revenue_growth + net_profit_growth) / 2

def calculate_value(revenue, p_e, growth_rate):

### 4.2 系统核心实现源代码

#### 4.2.1 股票筛选模块

```python
import pandas as pd

def calculate_growth_rate(revenue_growth, net_profit_growth):
    return (revenue_growth + net_profit_growth) / 2

def calculate_value(revenue, p_e, growth_rate):
    return (revenue / p_e) * growth_rate

# 示例数据
data = {
    '收入增长率': [0.2, 0.3, 0.1],
    '净利润增长率': [0.15, 0.2, 0.05],
    '市盈率': [15, 20, 25]
}

df = pd.DataFrame(data)

# 计算成长率
df['成长率'] = df.apply(lambda x: calculate_growth_rate(x['收入增长率'], x['净利润增长率']), axis=1)

# 计算价值
df['价值'] = df.apply(lambda x: calculate_value(x['收入增长率'], x['市盈率'], x['成长率']), axis=1)

print(df)
```
