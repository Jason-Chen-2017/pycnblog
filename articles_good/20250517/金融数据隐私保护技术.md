#### 2.1 同态加密算法
- 同态加密的基本原理
- 同态加密的数学模型与公式
  - 加密函数：$E(x) = x + r$
  - 解密函数：$D(E(x)) = x$
  - 加法同态性质：$D(E(x) + E(y)) = x + y$
- 同态加密的实现步骤与代码示例
  ```python

  def decrypt(ciphertext):
      return ciphertext - random.randint(1, 100)
  ```

#### 2.2 零知识证明算法
- 零知识证明的基本概念
- 零知识证明的数学模型与公式
  - 证明过程：$P \rightarrow V$，证明$P$知道$x$使得$y = x^2 \mod n$
  - 验证过程：$V$通过交互验证$P$确实知道$x$而无需知道$x$
- 零知识证明的实现步骤与代码示例
  ```python
  def prove(n, y):
      x = random.randint(1, n-1)
      a = pow(x, 2, n)
      return a
  def verify(n, y, a):
      return pow(a, 1, n) == y
  ```
