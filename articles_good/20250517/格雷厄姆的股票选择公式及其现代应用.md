## 第一部分: 格雷厄姆的股票选择公式基础

### 第1章: 格雷厄姆及其投资理念

#### 1.1 本杰明·格雷厄姆的简介
本杰明·格雷厄姆（Benjamin Graham）是20世纪最著名的投资理论家之一，被誉为“价值投资之父”。他于1894年出生于英国伦敦，后随家人移居美国。格雷厄姆在哥伦比亚大学学习期间，对金融和投资产生了浓厚兴趣。他在1926年出版的《新思想》（New Ideas）一书中首次提出了一些重要的投资理论。

#### 1.2 格雷厄姆的投资哲学
格雷厄姆的价值投资理念强调“安全边际”，即以低于内在价值的价格买入股票，以确保投资的安全性和 profitability。他认为，市场的波动性和非理性行为为投资者提供了以折扣价买入优质股票的机会。

#### 1.3 格雷厄姆的选股标准
格雷厄姆的选股标准主要包括以下几个方面：
1. **低市盈率（P/E）**：市盈率低于市场平均水平。
2. **低市净率（P/B）**：市净率低于市场平均水平。
3. **高股息率**：股息率较高，表明公司愿意将利润返还给股东。

### 第2章: 格雷厄姆的股票选择公式

#### 2.1 选股标准的数学模型
格雷厄姆的股票选择公式基于以下核心公式：

$$ \text{内在价值} = \frac{E}{P} + \frac{E}{P} \times \left(1 - \frac{D}{E}\right) $$

其中：
- \( E \) 表示公司股东权益。
- \( P \) 表示公司息税前利润（EBIT）。
- \( D \) 表示公司债务。

#### 2.2 公式中的变量与参数
- **息税前利润（EBIT）**：衡量公司盈利能力的核心指标。
- **股东权益（E）**：公司净资产的衡量标准。
- **债务（D）**：公司负债的总和。

#### 2.3 公式的适用场景与限制
格雷厄姆的选股公式主要适用于传统制造业和服务业公司，而不适合高科技公司和成长型企业。其主要限制在于对市场的假设过于简化。

import pandas as pd
import numpy as np

def calculate_intrinsic_value(e, p, d):
    return e/p + (e/p) * (1 - d/e)

# 数据加载
data = pd.read_csv('financial_data.csv')

# 计算内在价值
data['intrinsic_value'] = calculate_intrinsic_value(data['E'], data['P'], data['D'])

# 筛选股票

#### 7.3 实际案例分析
以下是实际案例分析：

- **案例公司**：假设某公司财务数据如下：
  - E = 1000万
  - P = 200万
  - D = 500万
  - 市场价格 = 8元

- **计算内在价值**：
  $$ \text{intrinsic\_value} = \frac{1000}{200} + \frac{1000}{200} \times \left(1 - \frac{500}{1000}\right) = 5 + 5 \times 0.5 = 7.5 \text{元} $$
