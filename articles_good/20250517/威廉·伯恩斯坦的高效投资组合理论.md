# 第1章: 有效市场假说与投资组合理论概述

## 1.1 有效市场假说的提出与发展

### 1.1.1 有效市场假说的起源  
有效市场假说（Efficient Market Hypothesis, EMH）由尤金·法玛于1970年提出，认为在有效市场中，证券价格已经反映了所有可获得的信息，因此投资者无法通过分析历史价格数据来获得超额收益。  

### 1.1.2 有效市场假说的核心观点  
- **弱有效市场假说**：价格反映了历史交易信息。  
- **半强有效市场假说**：价格反映了所有公开信息。  
- **强有效市场假说**：价格反映了所有公开和未公开信息。  

### 1.1.3 有效市场假说的分类与应用场景  
| 分类 | 描述 | 应用场景 |  
|------|------|----------|  
| 弱有效 | 历史价格已反映 | 技术分析无效 |  
| 半强有效 | 公开信息已反映 | 基本面分析受限 |  
| 强有效 | 所有信息已反映 | 无法通过内幕信息获利 |  

## 1.2 投资组合理论的基本概念

### 1.2.1 投资组合的定义与特点  
- **定义**：投资组合是指投资者持有的多种资产的集合。  
- **特点**：分散化、风险与收益的平衡。  

### 1.2.2 投资组合理论的核心要素  
- **资产分配**：决定每种资产在组合中的权重。  
- **风险与收益权衡**：在追求收益的同时，控制风险。  

### 1.2.3 投资组合理论与有效市场假说的关系  
在有效市场假说下，投资组合理论通过分散化投资来降低非系统性风险，从而实现收益最大化。

## 1.3 有效市场假说与投资组合理论的联系

### 1.3.1 有效市场假说对投资组合理论的影响  
- 在有效市场中，投资组合理论强调分散化投资的重要性。  
- 有效市场假说为投资组合理论提供了理论基础。  

### 1.3.2 投资组合理论在现代金融中的地位  
投资组合理论是现代金融学的核心理论之一，广泛应用于资产管理、风险管理和投资决策。  

### 1.3.3 有效市场假说与投资组合理论的实践意义  
- 有效市场假说指导投资者避免过度依赖技术分析。  
- 投资组合理论为投资者提供了科学的资产配置方法。  

## 1.4 本章小结

# 第2章: 投资组合理论的核心概念与数学模型

## 2.1 投资组合的收益与风险

### 2.1.1 投资组合的期望收益  
期望收益可以通过资产的期望收益和权重的加权平均计算：  
$$ E(r_p) = \sum_{i=1}^n w_i E(r_i) $$  

### 2.1.2 投资组合的风险度量  
- 方差衡量收益波动性：  
$$ \sigma_p^2 = \sum_{i=1}^n \sum_{j=1}^n w_i w_j \sigma_{ij} $$  
- 标准差是风险的主要指标。  

### 2.1.3 投资组合的夏普比率  
夏普比率衡量单位风险下的超额收益：  
$$ \text{夏普比率} = \frac{E(r_p) - r_f}{\sigma_p} $$  

## 2.2 资产配置与分散化投资

### 2.2.1 资产配置的定义与分类  
- **定义**：决定每种资产在组合中的比例。  
- **分类**：基于风险、收益和流动性。  

### 2.2.2 分散化投资的原理与效果  
- 分散化投资通过持有多种资产降低非系统性风险。  
- 散度与收益的关系：适度分散化可以提高收益与风险的性价比。  

### 2.2.3 资产配置与投资组合风险的关系  
- 资产配置影响组合的整体风险和收益。  
- 通过调整资产权重优化风险收益比。  

## 2.3 现代投资组合理论的数学模型

### 2.3.1 投资组合优化的数学公式  
目标函数：最大化收益，最小化风险。  
$$ \text{最大化 } E(r_p) \text{，最小化 } \sigma_p^2 $$  

### 2.3.2 均值-方差优化模型  
- 均值-方差模型由哈里·马科维茨提出，是投资组合理论的基础。  
- 通过优化算法找到最优资产组合。  

### 2.3.3 资产权重的确定与调整  
根据市场变化动态调整资产权重，以保持最优组合状态。

本章详细讲解了投资组合的收益与风险度量方法，并介绍了资产配置和分散化投资的原理，同时阐述了均值-方差优化模型的基本思想。

```python
def portfolio_optimization(returns):
    n = len(returns.columns)
    cov = returns.cov().values
    mu = returns.mean().values

    def objective(weights, cov, mu):
        return -np.dot(mu, weights) + 0.5 * np.dot(weights.T, np.dot(cov, weights))

    def constraint(weights):
        return np.sum(weights) - 1

    b = (0, 1)
    options = {'disp': False}
    result = minimize(objective, np.ones(n)/n, constraints={'type': 'eq', 'fun': constraint}, method='SLSQP', options=options)
    return result.x
```
