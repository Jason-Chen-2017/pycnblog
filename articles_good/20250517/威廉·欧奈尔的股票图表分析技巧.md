## 第九章: 数学模型与算法实现

### 9.1 相对强度指数（RSI）的数学模型
$$ RSI = \frac{\text{上涨幅度总和}}{\text{上涨幅度总和} + \text{下跌幅度总和}} \times 100 $$

### 9.2 移动平均线（MA）的计算公式
$$ MA_n = \frac{\sum_{i=1}^{n} P_i}{n} $$

### 9.3 算法实现
```python
import pandas as pd
import numpy as np

def calculate_rsi(data, period=14):
    diff = data['Close'].diff(1).dropna()
    up = diff.where(diff > 0, 0)
    down = diff.where(diff < 0, 0)
    rs = up.rolling(period).mean() / down.rolling(period).mean()
    rsi = 100 - 100 * (1 - rs)
    return rsi

def calculate_ma(data, period=20):
    ma = data['Close'].rolling(period).mean()
    return ma
```
