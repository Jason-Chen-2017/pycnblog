### 第一部分：全球股市估值分析

#### 第1章：全球股市估值概述

##### 1.1 股市估值的基本概念

- **1.1.1 股市估值的定义与作用**
  股市估值是指通过对公司财务数据的分析，估算其股票的合理价格范围。它是投资者评估公司价值的重要工具，帮助投资者做出理性投资决策。

- **1.1.2 股市估值的核心指标**
  - 市盈率（PE）：市盈率=股票价格/每股净利润。衡量股票的相对价值。
  - 市净率（PB）：市净率=股票价格/每股净资产。用于评估股票相对于其账面价值的高低。
  - 股权收益率（ROE）：ROE=净利润/股东权益。衡量公司盈利能力。

- **1.1.3 全球股市估值的多样性与差异性**
  不同国家和地区的股市估值受经济、政策和市场情绪影响，具有显著差异。例如，美国市场的PE通常高于新兴市场。

##### 1.2 股市估值的影响因素

- **1.2.1 宏观经济因素**
  - GDP增长率、利率水平、通货膨胀率等宏观经济指标直接影响股市估值。

- **1.2.2 行业因素与公司基本面**
  - 公司的盈利能力、成长性、资产负债率等基本面指标是估值的重要依据。

- **1.2.3 市场情绪与投资者行为**
  - 投资者情绪波动会导致短期估值偏离基本面。

##### 1.3 股市估值的方法与模型

- **1.3.1 市盈率法与市净率法**
  - 市盈率法适用于盈利稳定的公司，市净率法适用于净资产驱动型公司。

- **1.3.2 现金流折现法（DCF模型）**
  DCF模型通过预测未来现金流的现值，估算公司价值。

- **1.3.3 相对估值法与行业比较法**
  相对估值法通过比较同类公司的估值指标，确定目标公司的合理估值。

#### 第2章：纳米材料的基本特性与制备

  - 气相沉积法

#### Python代码实现

```python
import pandas as pd

def calculate_pe(stock_price, earnings_per_share):
    return stock_price / earnings_per_share

def calculate_pb(stock_price, book_value_per_share):
    return stock_price / book_value_per_share

def calculate_dcf(cash_flows, discount_rate):
    present_value = sum(cash_flow / (1 + discount_rate) ** t for t, cash_flow in enumerate(cash_flows))
    return present_value

# 示例数据
stock_price = 100
earnings_per_share = 2
book_value_per_share = 5
discount_rate = 0.05
cash_flows = [100, 120, 150, 180]

pe = calculate_pe(stock_price, earnings_per_share)
pb = calculate_pb(stock_price, book_value_per_share)
dcf = calculate_dcf(cash_flows, discount_rate)

print(f"PE: {pe}, PB: {pb}, DCF: {dcf}")
```

#### 数学公式讲解

$$ PE = \frac{\text{股票价格}}{\text{每股净利润}} $$

$$ DCF = \sum_{t=0}^{n} \frac{\text{现金流}_t}{(1 + r)^t} $$
