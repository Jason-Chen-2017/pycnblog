### 第三部分：自适应型估值模型的数学基础

#### 3.1 基础数学模型
- 3.1.1 线性回归模型
  - 简单线性回归：$y = \beta_0 + \beta_1x + \epsilon$
  - 多元线性回归：$y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon$
- 3.1.2 时间序列分析
  - ARIMA模型：$y_t = \phi y_{t-1} + \theta \epsilon_{t-1} + \epsilon_t$
  - LSTM网络：长短期记忆网络
- 3.1.3 贝叶斯网络
  - 贝叶斯定理：$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$

#### 3.2 基于AI代理的强化学习模型
- 3.2.1 强化学习的基本原理
  - 状态（State）、动作（Action）、奖励（Reward）的三元组
  - Q-learning算法：$Q(s, a) = r + \gamma \max Q(s', a')$
- 3.2.2 Q-learning算法
  - 状态空间：S
  - 动作空间：A
  - 奖励函数：R
- 3.2.3 策略梯度方法
  - 策略梯度：$\nabla\theta J(\theta) = \mathbb{E}[ \nabla\theta \log \pi(a|s) Q(s,a) ]$

#### 3.3 深度学习模型在估值中的应用
- 3.3.1 卷积神经网络（CNN）
  - 卷积层：提取空间特征
  - 池化层：降低维度
- 3.3.2 循环神经网络（RNN）
  - LSTM层：处理序列数据
  - GRU层：简化时序建模
- 3.3.3 图神经网络（GNN）
  - 图结构数据：节点与边的关系
  - GAT层：注意力机制
