## 第4章: 评分卡优化的算法原理

### 4.1 逻辑回归算法原理

#### 4.1.1 逻辑回归简介
逻辑回归是一种广泛应用于分类问题的算法，其核心思想是通过sigmoid函数将线性回归的结果映射到概率空间。

#### 4.1.2 逻辑回归的数学模型
$$ P(y=1|x) = \frac{1}{1 + e^{-\beta x}} $$
其中，$\beta$ 是模型参数，$x$ 是输入特征。

#### 4.1.3 逻辑回归的工作流程
```mermaid
graph TD
    A[输入特征] --> B[计算线性组合]
    B --> C[Sigmoid函数]
    C --> D[输出概率]
```

#### 4.1.4 逻辑回归在评分卡优化中的应用
通过将客户特征输入逻辑回归模型，计算客户违约的概率，从而生成评分。评分结果用于判断客户信用等级。

#### 4.1.5 逻辑回归的优缺点
- 优点：模型简单、易于解释、计算效率高。
- 缺点：对非线性关系的捕捉能力有限。

### 4.2 XGBoost算法原理

#### 4.2.1 XGBoost简介
XGBoost是一种基于树的集成算法，通过构建多个弱分类器（决策树）来提升模型性能。

#### 4.2.2 XGBoost的数学模型
$$ y = \sum_{i=1}^{n} \theta_i h_i(x) $$
其中，$\theta_i$ 是模型系数，$h_i(x)$ 是弱分类器。

#### 4.2.3 XGBoost的工作流程
```mermaid
graph TD
    A[输入特征] --> B[构建决策树]
    B --> C[计算特征重要性]
    C --> D[模型融合]
    D --> E[输出评分]
```

#### 4.2.4 XGBoost在评分卡优化中的应用
通过构建多个决策树，对客户特征进行非线性拟合，生成更精准的评分结果。

#### 4.2.5 XGBoost的优缺点
- 优点：模型表达能力强、能够捕捉复杂特征关系。
- 缺点：模型复杂度高、解释性较差。

### 4.3 算法对比与选择

#### 4.3.1 逻辑回归与XGBoost的对比
| 特性 | 逻辑回归 | XGBoost |
|------|-----------|----------|
| 模型复杂度 | 低       | 高       |
| 解释性 | 高       | 低       |
| 性能 | 中等      | 高       |

#### 4.3.2 算法选择策略
- 数据特征线性关系为主：选择逻辑回归。
- 数据特征复杂且非线性关系为主：选择XGBoost。

### 6.2 核心代码实现

#### 6.2.1 数据加载与预处理
```python
import pandas as pd
import numpy as np

# 加载数据
data = pd.read_csv('credit.csv')

# 处理缺失值
data = data.dropna()

# 特征选择
features = ['income', 'debt', 'age']
target = 'default'

X = data[features]
y = data[target]
```

#### 6.2.2 模型训练
```python
from sklearn.linear_model import LogisticRegression
from xgboost import XGBClassifier

# 逻辑回归模型
lr_model = LogisticRegression()
lr_model.fit(X, y)

# XGBoost模型
xgb_model = XGBClassifier()
xgb_model.fit(X, y)
```

#### 6.2.3 模型预测与评估
```python
from sklearn.metrics import accuracy_score

# 逻辑回归预测
lr_pred = lr_model.predict(X)
lr_accuracy = accuracy_score(y, lr_pred)
print(f"Logistic Regression Accuracy: {lr_accuracy}")

# XGBoost预测
xgb_pred = xgb_model.predict(X)
xgb_accuracy = accuracy_score(y, xgb_pred)
print(f"XGBoost Accuracy: {xgb_accuracy}")
```
