明确分析范围，包括直接成本、机会成本等。

## 第2章: 成本效益分析的核心原理与方法

### 2.1 成本效益分析的核心原理

#### 2.1.1 成本与效益的量化方法
- 定量分析：货币价值。
- 定性分析：非财务指标。

#### 2.1.2 成本效益分析的基本公式与模型
- 净现值（NPV）：评估投资收益。
- 内部收益率（IRR）：评估投资回报率。

#### 2.1.3 经济学视角下的成本效益分析
市场失灵、外部性等经济概念的影响。

### 2.2 成本效益分析的主要方法

#### 2.2.1 净现值法（NPV）
- **定义**：未来现金流的现值与初始投资的差额。
- **公式**：$$ NPV = \sum_{t=0}^{n} \frac{C_t}{(1 + r)^t} $$
- **案例**：某项目初始投资100万元，年现金流25万元，贴现率5%，计算NPV。

#### 2.2.2 内部收益率法（IRR）
- **定义**：使NPV为零的贴现率。
- **公式**：$$ NPV = 0 = \sum_{t=0}^{n} \frac{C_t}{(1 + IRR)^t} $$
- **案例**：计算项目IRR，判断投资回报。

#### 2.2.3 投资回收期法（Payback Period）
- **定义**：回收初始投资所需时间。
- **案例**：投资300万元，年现金流100万元，回收期3年。

#### 2.2.4 盈利指数法（Profitability Index）
- **定义**：收益与成本之比。
- **公式**：$$ PI = \frac{\text{未来现金流现值}}{\text{初始投资}} $$

### 2.3 成本效益分析的优缺点

#### 优点
- 定量分析，决策依据充分。

#### 缺点
- 忽略非财务因素，假设贴现率准确。

## 第3章: 成本效益分析的数学模型与公式

### 3.1 净现值（NPV）模型

#### 3.1.1 NPV的定义与公式
$$ NPV = \sum_{t=0}^{n} \frac{C_t}{(1 + r)^t} $$

#### 3.1.2 NPV计算实例
- 初始投资：100万元。
- 年现金流：25万元，贴现率5%。
- 计算NPV，判断项目可行性。

### 3.2 内部收益率（IRR）模型

#### 3.2.1 IRR的定义与公式
$$ NPV = 0 = \sum_{t=0}^{n} \frac{C_t}{(1 + IRR)^t} $$

#### 3.2.2 IRR计算实例
- 计算项目IRR，比较基准收益率。

### 3.3 投资回收期（Payback Period）模型

#### 3.3.1 定义与计算公式
- 初始投资：$I$。
- 年现金流：$CF_t$。
- 公式：$$ PP = \min t \text{ 使得} \sum_{t=0}^{t} CF_t \geq I $$

#### 3.3.2 投资回收期计算实例
- 投资300万元，年现金流100万元，回收期3年。

## 第5章: 成本效益分析的项目实战

### 5.1 环境安装

### 5.2 核心实现

#### 5.2.1 净现值计算代码
```python
import numpy as np

def calculate_npv(initial_cost, cash_flows, discount_rate):
    npv = 0
    for t, cash in enumerate(cash_flows):
        npv += cash / (1 + discount_rate) ** t
    npv -= initial_cost
    return npv

# 示例数据
initial_cost = 1000000
cash_flows = [250000, 250000, 250000]
discount_rate = 0.05

npv = calculate_npv(initial_cost, cash_flows, discount_rate)
print(f"NPV: {npv}")
```

#### 5.2.2 内部收益率计算代码
```python
def calculate_irr(initial_cost, cash_flows):
    return np.irr([initial_cost] + cash_flows)

irr = calculate_irr(initial_cost, cash_flows)
print(f"IRR: {irr}")
```

### 5.3 案例分析

#### 5.3.1 案例背景
评估某IT项目，初始投资100万元，三年现金流25万元，贴现率5%。

#### 5.3.2 分析结果
- NPV = 25,000 / 1.05 + 25,000 / 1.05^2 + 25,000 / 1.05^3 - 100,000 ≈ 23,809.52元。
- IRR ≈ 10%。
