# 第1章：背景介绍

## 1.1 大数据分析的定义与特点
### 1.1.1 大数据分析的定义
大数据分析是指对海量、多样化、高速生成的数据进行处理、分析和挖掘，以提取有价值的信息和洞察的过程。其核心在于从数据中提取可操作的见解，帮助决策者做出更明智的选择。

### 1.1.2 大数据分析的核心特点
- **数据量大**：处理PB级数据。
- **数据多样性**：包括结构化和非结构化数据。
- **处理速度快**：实时或近实时分析。
- **价值密度低**：数据中有大量噪声。

### 1.1.3 大数据分析与传统数据分析的对比
| 特性         | 大数据分析       | 传统数据分析     |
|--------------|------------------|-----------------|
| 数据量       | PB级及以上       | MB级或更小       |
| 数据类型     | 结构化+非结构化  | 主要结构化       |
| 分析速度     | 实时或近实时     | 离线为主         |
| 技术复杂度   | 高               | 中等             |

---

## 1.2 投资研究中的数据挑战
### 1.2.1 投资研究中的数据来源
- 市场数据：股票价格、交易量、指数等。
- 公司基本面数据：财务报表、管理层信息等。
- 新闻与社交媒体：市场情绪分析。
- 宏观经济数据：GDP、利率、通货膨胀等。

### 1.2.2 大数据在投资研究中的重要性
大数据分析能够捕捉市场中的隐含信息，例如通过社交媒体预测市场情绪变化，或通过高频交易数据发现短期价格波动规律。

### 1.2.3 数据量与数据质量的平衡
- 数据量大不一定意味着质量高。
- 数据清洗与预处理是投资分析的关键步骤。
