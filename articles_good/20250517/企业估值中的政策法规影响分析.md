  ```python
  import numpy as np

  # 数据加载

  # 数据清洗
  df.dropna(inplace=True)
  df = df[ df['行业'] == '科技' ]
  ```
- 6.3.2 模型构建代码
  ```python
  import statsmodels.api as sm

  # 线性回归模型
  X = df[['收入', '利润']]
  y = df['估值']

  # 模型训练
  model = sm.OLS(y, sm.add_constant(X)).fit()
  print(model.summary())
  ```
- 6.3.3 结果可视化代码

  ```python
  plt.xlabel('Revenue')
  plt.ylabel('Profit')
  plt.show()
  ```
