#### 3.2 算法实现的代码示例
- 3.2.1 相关性计算的Python代码
  ```python
  import numpy as np
  def calculate_correlation(matrix):
      # matrix: n_assets x n_assets
      n_assets = matrix.shape[0]
      correlation_matrix = np.zeros((n_assets, n_assets))
      for i in range(n_assets):
          for j in range(n_assets):
              # 计算协方差
              covariance = np.cov(matrix[i], matrix[j])
              # 计算标准差
              std_i = np.std(matrix[i])
              std_j = np.std(matrix[j])
              # 计算相关系数
              if std_i == 0 or std_j == 0:
                  correlation = 0.0
              else:
                  correlation = covariance / (std_i * std_j)
              correlation_matrix[i, j] = correlation
      return correlation_matrix
  ```

- 3.2.2 网络构建的Python代码
  ```python
  import networkx as nx
  def build_network(correlation_matrix, threshold=0.3):
      # 创建空图
      G = nx.Graph()
      n_assets = correlation_matrix.shape[0]
      # 添加节点
      G.add_nodes_from(range(n_assets))
      # 添加边
      for i in range(n_assets):
          for j in range(i+1, n_assets):
              if correlation_matrix[i, j] > threshold:
                  G.add_edge(i, j, weight=correlation_matrix[i, j])
      return G
  ```
