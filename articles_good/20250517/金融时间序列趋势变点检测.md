## 第1章: 金融时间序列与变点检测概述

### 1.1 时间序列的基本概念

#### 1.1.1 时间序列的定义与特征  
时间序列是指按照时间顺序记录的数据序列，通常表示为 $X = \{x_1, x_2, \dots, x_T\}$，其中 $T$ 是时间步数。时间序列具有以下特征：  
- **趋势性**：数据整体呈现上升或下降的趋势。  
- **周期性**：数据呈现一定的周期性波动，如月度或季度数据的周期性。  
- **随机性**：数据中无法用确定性模型描述的部分。  

#### 1.1.2 金融时间序列的独特性  
金融时间序列具有以下独特特征：  
- **波动性**：金融市场的波动性较高，容易受到突发事件的影响。  
- **非线性**：金融数据通常表现出非线性特征，如“肥尾”现象。  
- **异质性**：不同金融资产或市场的数据具有不同的统计特性。  

#### 1.1.3 变点检测的定义与重要性  
变点检测是指在时间序列中识别数据分布或趋势发生显著变化的时刻。变点检测在金融领域具有重要意义：  
- **风险管理**：及时发现市场趋势变化，帮助投资者规避风险。  
- **交易机会**：识别市场拐点，捕捉交易机会。  
- **异常检测**：发现异常交易行为或市场操纵。  

---

### 1.2 金融时间序列中的变点问题

#### 1.2.1 变点的类型与分类  
变点可以分为以下几种类型：  
1. **均值变点**：数据均值发生变化的时刻。  
2. **方差变点**：数据波动性发生变化的时刻。  
3. **趋势变点**：数据趋势方向发生变化的时刻。  
4. **混合变点**：同时涉及均值、方差和趋势的变化。  

#### 1.2.2 变点检测在金融中的应用场景  
- **股票市场分析**：检测股价趋势变化，帮助投资者做出买卖决策。  
- **外汇市场分析**：识别汇率波动的关键点，帮助外汇交易者制定策略。  
- **风险管理**：及时发现市场风险，避免重大损失。  

#### 1.2.3 变点检测的挑战与难点  
- **数据噪声**：金融数据通常受到噪声干扰，影响变点检测的准确性。  
- **小样本问题**：在某些情况下，可用来训练的样本数量较少，导致模型泛化能力不足。  
- **多变点检测**：同时检测多个变点时，需要考虑变点之间的相互影响。

## 第2章: 统计方法与变点检测

### 2.1 参数模型与变点检测

#### 2.1.1 均值变点的检测方法  
均值变点的检测可以通过以下方法实现：  
1. **卡方检验**：通过比较相邻段的均值差异，判断是否存在显著变化。  
2. **t检验**：在两个时间段内分别估计均值，比较两者差异是否显著。  

#### 2.1.2 方差变点的检测方法  
方差变点的检测方法包括：  
1. **F检验**：比较两个时间段的方差是否显著不同。  
2. **Levene检验**：适用于非正态分布数据的方差齐性检验。  

#### 2.1.3 统计检验方法  
常用的统计检验方法包括卡方检验和t检验，具体步骤如下：  
1. 将时间序列分成两段，计算每段的均值和方差。  
2. 使用卡方检验或t检验判断两段的均值或方差是否存在显著差异。  
3. 如果存在显著差异，则判断该时刻为变点。  

---

### 2.2 非参数方法与变点检测

#### 2.2.1 基于经验分布函数的方法  
经验分布函数（Empirical Distribution Function, EDF）可以用来检测数据分布的变化。通过比较不同时间段的经验分布函数，判断是否存在显著差异。  

#### 2.2.2 基于核密度估计的方法  
核密度估计（Kernel Density Estimation, KDE）是一种非参数密度估计方法。通过计算不同时间段的核密度估计，判断数据分布是否发生变化。  

#### 2.2.3 基于分位数回归的方法  
分位数回归（Quantile Regression）可以用来检测数据分布的变化。通过比较不同分位数的变化，判断是否存在变点。  

---

### 2.3 统计方法的优缺点分析

#### 2.3.1 统计方法的适用场景  
统计方法适用于数据分布简单、样本量较大的情况。  

#### 2.3.2 统计方法的局限性  
统计方法的局限性包括：  
- 对异常值的鲁棒性较差。  
- 仅适用于单一变点检测，难以处理多个变点的情况。  

#### 2.3.3 统计方法与机器学习方法的结合  
通过结合统计方法和机器学习方法，可以提高变点检测的准确性和鲁棒性。例如，利用统计方法初步筛选候选变点，再使用机器学习方法进行进一步验证。

### 6.2 系统核心实现

#### 6.2.1 统计方法实现  
```python
import numpy as np
from scipy import stats

def mean_change_test(data, t):
    # 分成两段
    segment1 = data[:t]
    segment2 = data[t:]
    
    # 计算均值
    mean1 = np.mean(segment1)
    mean2 = np.mean(segment2)
    
    # 卡方检验
    var1 = np.var(segment1)
    var2 = np.var(segment2)
    n1 = len(segment1)
    n2 = len(segment2)
    statistic = (n1 + n2) * ((mean1 - mean2)**2) / (var1/n1 + var2/n2)
    p_value = stats.chi2.sf(statistic, 1)
    
    return p_value < 0.05
```

def isoforest_detection(data, n_estimators=100):
