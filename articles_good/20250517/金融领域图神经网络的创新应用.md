## 第二部分：图神经网络的核心概念与原理

### 第2章：图结构与节点表示

#### 2.1 图的表示方法
- 邻接矩阵表示
  - 定义：一个二维矩阵，其中$A_{ij}=1$表示节点$i$和节点$j$之间有边相连
  - 优点：便于计算和矩阵运算
- 邻接表表示
  - 定义：使用列表存储每个节点的相邻节点
  - 优点：节省空间，适用于稀疏图
- 加权图与非加权图的区别
  - 非加权图：边无权重
  - 加权图：边具有权重，表示关系强度

#### 2.2 节点表示与图嵌入
- 节点表示的定义与目标
  - 通过低维向量表示节点的特征和关系
- 图嵌入的核心思想
  - 学习一个函数，将图中的节点映射到低维空间
  - 保留图的结构信息和语义信息
- 图嵌入在金融中的应用案例
  - 欺诈检测：通过嵌入捕捉异常交易模式
  - 信用评估：通过嵌入评估客户信用风险

#### 2.3 图注意力机制
- 注意力机制的基本原理
  - 通过计算节点之间的注意力权重，决定每个节点对目标节点的影响程度
- 图注意力机制的创新点
  - 考虑图结构中的全局信息，而非仅依赖局部邻域
- 图注意力机制在金融中的应用案例
  - 股票预测：通过注意力机制捕捉时间序列中的关键因素
  - 欺诈检测：通过注意力机制识别异常交易模式

## 第三部分：图神经网络的算法原理

### 第3章：图卷积网络（GCN）

#### 3.1 GCN的基本原理
- GCN的目标：通过图卷积操作，将图的结构信息与节点特征结合，生成新的节点表示
- GCN的数学公式
  $$ y = \sigma(A X W) $$
  其中，$A$ 是邻接矩阵，$X$ 是输入特征矩阵，$W$ 是权重矩阵，$\sigma$ 是激活函数

#### 3.2 GCN的实现步骤
1. 输入：图的邻接矩阵$A$和节点特征矩阵$X$
2. 计算邻接矩阵与节点特征的乘积：$A X$
3. 应用激活函数：$\sigma(A X W)$
4. 输出：节点表示$Y$

#### 3.3 GCN的优缺点
- 优点
  - 简单易实现
  - 能够捕捉图的全局信息
- 缺点
  - 参数量大，计算复杂度高
  - 对大规模图的处理能力有限

### 第4章：图注意力网络（GAT）

#### 4.1 GAT的基本原理
- GAT的目标：通过注意力机制，动态计算每个节点对目标节点的影响权重
- GAT的数学公式
  $$ \alpha_{ij} = \text{softmax}(e^{f(a_{ij})}) $$
  其中，$f(a_{ij})$ 是边的注意力权重计算函数

#### 4.2 GAT的实现步骤
1. 输入：图的邻接矩阵$A$和节点特征矩阵$X$
2. 计算注意力权重：$f(a_{ij}) = W^T \cdot [x_i; x_j]$
3. 应用softmax函数归一化权重：$\alpha_{ij} = \text{softmax}(e^{f(a_{ij})})$
4. 计算加权和：$Y = \sum_{j} \alpha_{ij} x_j W$
5. 输出：节点表示$Y$

#### 4.3 GAT的优缺点
- 优点
  - 能够捕捉节点之间的局部关系
  - 对大规模图的处理能力较强
- 缺点
  - 计算复杂度较高
  - 对注意力权重的计算可能存在过拟合风险

#### 6.3 核心实现代码
```python
import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow.keras import layers
import networkx as nx

# 定义图神经网络模型
class GNN(tf.keras.Model):
    def __init__(self, input_dim, hidden_dim):
        super(GNN, self).__init__()
        self.gcn = layers.GraphConvolution(input_dim, hidden_dim)
        self.dense = layers.Dense(hidden_dim)
        self.dropout = layers.Dropout(0.5)
        self.dense2 = layers.Dense(1)

    def call(self, inputs):
        x, A = inputs
        x = self.gcn([x, A])
        x = tf.nn.relu(x)
        x = self.dropout(x)
        x = self.dense2(x)
        return x

# 数据预处理
data = pd.read_csv('stock_data.csv')
X = data[['open', 'high', 'low', 'close']]
y = data['label']

# 构建图结构
G = nx.Graph()
for i in range(len(data)):
    G.add_node(i)
    if i > 0:
        G.add_edge(i-1, i)

# 转换为邻接矩阵
A = nx.adjacency_matrix(G).todense()

# 模型训练
model = GNN(input_dim=4, hidden_dim=8)
model.compile(optimizer='adam', loss='binary_crossentropy')
model.fit([X, A], y, epochs=10, batch_size=32)
```
