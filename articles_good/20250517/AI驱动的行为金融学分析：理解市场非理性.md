#### 第3章：行为金融学中的核心算法与模型

##### 3.1 强化学习在行为金融学中的应用

###### 3.1.1 强化学习的基本原理
- 强化学习（Reinforcement Learning）是一种机器学习范式，通过智能体与环境的交互，学习最优策略。
- 基本组成：智能体、环境、动作、奖励。

###### 3.1.2 Q-learning算法在投资决策中的应用
- Q-learning算法：通过更新Q值函数，学习最优策略。
- Q值函数更新公式：
  $$ Q(s, a) = Q(s, a) + \alpha (r + \gamma \max Q(s', a') - Q(s, a)) $$
- 应用场景：股票交易中的买卖决策。

###### 3.1.3 算法实现与案例分析
- 示例代码：
  ```python
  import numpy as np
  import gym

  env = gym.make('StockTrading-v0')
  env.seed(42)
  np.random.seed(42)

  # 初始化Q值表
  q_table = np.zeros([env.observation_space.shape[0], env.action_space.n])

  # 参数设置
  learning_rate = 0.1
  gamma = 0.9
  epsilon = 0.1

  # Q-learning算法实现
  for episode in range(1000):
      state = env.reset()
      done = False
      while not done:
          # 探索与利用
          if np.random.random() < epsilon:
              action = env.action_space.sample()
          else:
              action = np.argmax(q_table[state])
          
          # 执行动作，获取新状态和奖励
          next_state, reward, done, info = env.step(action)
          
          # 更新Q值表
          q_table[state][action] += learning_rate * (reward + gamma * np.max(q_table[next_state]) - q_table[state][action])
          
          state = next_state

  # 测试策略
  state = env.reset()
  total_rewards = []
  while not done:
      action = np.argmax(q_table[state])
      next_state, reward, done, info = env.step(action)
      total_rewards.append(reward)
      state = next_state
  print("Total rewards:", sum(total_rewards))
  ```

- 案例分析：通过Q-learning算法训练一个股票交易策略，实现对市场非理性行为的预测与利用。

#### 第4章：行为金融学中的数学模型与公式

##### 4.1 马科维茨投资组合理论

###### 4.1.1 投资组合理论的基本假设
- 投资者是风险厌恶的。
- 资产的收益符合正态分布。
- 市场是有效的。

###### 4.1.2 投资组合理论的数学公式
- 优化目标：
  $$ \min_{w} w^T \Sigma w $$
  $$ \text{s.t.} \quad w^T \mu = \mu_p, \quad w^T 1 = 1 $$
- 解释：在给定的收益约束下，最小化投资组合的方差。

##### 4.2 CAPM模型

###### 4.2.1 CAPM模型的基本假设
- 市场是有效的。
- 所有资产的收益可以用CAPM模型解释。

###### 4.2.2 CAPM模型的数学公式
- 单个资产的预期收益：
  $$ E[r_i] = r_f + \beta_i (E[r_m] - r_f) $$
- 解释：资产的预期收益由无风险利率和系统性风险决定。
