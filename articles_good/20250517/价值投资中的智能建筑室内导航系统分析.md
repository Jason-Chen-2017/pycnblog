### 第4章: 导航系统的算法原理

#### 4.1 路径规划算法
- Dijkstra算法：  
  用于计算图中两点之间的最短路径，适用于室内环境中的路径规划。

- A*算法：  
  在Dijkstra算法的基础上引入启发式函数，进一步提升路径规划效率。

- 算法流程图（mermaid）：
  ```mermaid
  graph TD
    A[起点] --> B[邻居节点]
    B --> C[目标点]
    A --> D[其他节点]
    C --> E[终点]
  ```

- Python实现示例：
  ```python
  import heapq

  def dijkstra(start, goal, graph):
      distances = {node: float('infinity') for node in graph}
      distances[start] = 0
      heap = []
      heapq.heappush(heap, (0, start))

      while heap:
          current_dist, current_node = heapq.heappop(heap)
          if current_node == goal:
              break
          if current_dist > distances[current_node]:
              continue
          for neighbor, weight in graph[current_node].items():
              if distances[neighbor] > current_dist + weight:
                  distances[neighbor] = current_dist + weight
                  heapq.heappush(heap, (distances[neighbor], neighbor))
      return distances[goal]
  ```

- 数学模型与公式：  
  Dijkstra算法的数学模型可以表示为：
  $$\text{距离}(u) = \min_{v \in V} \{ \text{距离}(v) + \text{权重}(u, v) \}$$
