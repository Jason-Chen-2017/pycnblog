## 第一部分：投资决策偏差概述

### 第1章：投资决策偏差的背景与影响

#### 1.1 投资决策偏差的定义与分类

**1.1.1 什么是投资决策偏差**  
投资决策偏差是指投资者在决策过程中由于认知、情感或环境因素的干扰，导致决策偏离理性或最优状态的现象。这些偏差通常源于人类心理的局限性，如过度自信、从众心理等。

**1.1.2 常见的投资决策偏差类型**  
投资决策偏差可以分为以下几类：  
1. **认知偏差**：如确认偏差、 Availability heuristic（可得性偏差）、锚定效应等。  
2. **情感偏差**：如损失厌恶、过度反应等。  
3. **社会偏差**：如从众心理、羊群效应等。  

**1.1.3 投资决策偏差的影响**  
偏差会显著影响投资者的决策质量，导致投资损失或错失良机。例如，过度自信可能导致过度交易，而损失厌恶可能使投资者错过反弹机会。

#### 1.2 投资者的行为偏差

**1.2.1 认知偏差**  
认知偏差是投资者在信息处理过程中产生的系统性错误。例如，确认偏差使投资者倾向于寻找支持自己观点的信息，忽略反面证据。

**1.2.2 情感偏差**  
情感偏差源于投资者的情绪波动，如恐惧和贪婪。这些情绪可能导致非理性决策，如在市场暴跌时恐慌抛售。

**1.2.3 社会偏差**  
社会偏差源于投资者对社会环境的反应，如从众心理。这可能导致跟风投资，忽视独立分析。

#### 6.2 核心代码实现

```python
import numpy as np
import pandas as pd

def preprocess(data):
    # 数据清洗和转换
    processed = data.dropna().astype(float)
    return processed

def detect_bias(data):
    # 识别偏差类型
    mean = np.mean(data)
    std = np.std(data)
    if data[0] > mean + 2*std:
        return 'anchoring bias'
    else:
        return 'availability heuristic'

def generate_strategies(data, bias_types):
    # 生成纠正策略
    strategies = []
    for bias in bias_types:
        if bias == 'anchoring bias':
            strategies.append('调整基准')
        elif bias == 'availability heuristic':
            strategies.append('扩大样本')
    return strategies
```
