# 第1章: 安全边际的核心概念与背景

## 1.1 安全边际的定义与背景

### 1.1.1 投资中的安全边际概念
安全边际是格雷厄姆价值投资理论中的关键概念，指股票的内在价值与市场价格之间的差额。它确保了投资者在市场波动中能够以较低的风险获得收益。

### 1.1.2 格雷厄姆的价值投资理论
格雷厄姆强调以低于内在价值的价格购买优质股票，安全边际提供了这种“Margin of Safety”，帮助投资者在市场低估时抓住机会，避免过度支付。

### 1.1.3 安全边际在投资中的重要性
安全边际通过降低投资风险，为投资者提供了心理上的缓冲区，尤其是在市场波动剧烈时，能够保护投资本金免受损失。

## 1.2 安全边际的核心原理

### 1.2.1 安全边际的数学模型
安全边际（ MOS ）的计算公式为：
$$ \text{MOS} = \text{内在价值} - \text{市场价格} $$

### 1.2.2 安全边际与市场波动的关系
市场波动会影响安全边际的大小，通常在市场下跌时，安全边际增大，为投资者提供了更多的买入机会。

### 1.2.3 安全边际与投资风险的平衡
通过合理配置资产和选择高安全边际的股票，投资者可以在不同市场环境下平衡风险与收益。

## 1.3 安全边际的应用场景

### 1.3.1 不同市场环境下的安全边际
在牛市中，安全边际较低，需谨慎选择；在熊市中，安全边际较高，适合价值投资。

### 1.3.2 安全边际在个股与组合投资中的应用
个股投资中，安全边际用于筛选低估股票；组合投资中，用于分散风险，平衡整体投资组合的安全边际。

### 1.3.3 安全边际与价值发现的关系
安全边际帮助投资者识别市场中的价值洼地，发现被低估的股票和投资机会。

# 计算内在价值（简化模型）
def calculate_intrinsic_value(stock_data):
    # 假设市盈率合理为15
    fair_price = stock_data['Close'] * 15
    return fair_price.mean()

# 计算安全边际
def calculate_margin_of_safety(fair_price, stock_price):
    mos = fair_price - stock_price
    return mos

# 示例计算
