## 第3章: 算法

#### 3.1 算法原理

### 3.1.1 AI Agent算法流程
```mermaid
graph TD
    A[数据采集] --> B[特征提取]
    B --> C[模型训练]
    C --> D[模型推理]
    D --> E[决策输出]
```

### 3.1.2 算法实现
```python
import numpy as np
from sklearn.svm import SVC

# 示例数据
X = np.array([[1, 2], [3, 4], [5, 6]])
y = np.array([0, 1, 0])

# 训练模型
model = SVC()
model.fit(X, y)

# 预测
print(model.predict([[2, 3]]))  # 输出: array([0])
```

### 3.1.3 数学模型
- **线性分类器**：
  $$ y = \text{sign}(w \cdot x + b) $$
  其中，$w$ 是权重向量，$x$ 是输入特征，$b$ 是偏置项。
- **支持向量机（SVM）**：
  $$ \text{maximize} \quad \frac{1}{2} \|w\|^2 $$
  $$ \text{subject to} \quad y_i (w \cdot x_i + b) \geq 1, \quad i=1,2,\dots,n $$
