### 第2章: 时间序列分析的核心算法

#### 2.1 时间序列分析的数学模型

- **2.1.1 线性回归模型**
  - 简单线性回归：$y = a + bt + e$，其中$t$是时间，$y$是预测值，$a$和$b$是回归系数，$e$是误差项。
  - 多元线性回归：扩展为多个自变量的回归模型。

- **2.1.2 自回归模型（AR）**
  - AR模型：$y_t = a + \sum_{i=1}^{p} \phi_i y_{t-i} + e_t$，其中$p$是阶数，$\phi_i$是自回归系数。

- **2.1.3 移动平均模型（MA）**
  - MA模型：$y_t = a + \sum_{i=1}^{q} \theta_i e_{t-i} + e_t$，其中$q$是阶数，$\theta_i$是移动平均系数。

- **2.1.4 自回归移动平均模型（ARMA）**
  - ARMA模型结合了AR和MA，适用于平稳时间序列的建模。

#### 2.2 时间序列分解的数学模型

- **2.2.1 趋势分解**
  - 线性趋势：$T_t = a + bt$。
  - 非线性趋势：可能使用多项式回归或其他非线性模型。

- **2.2.2 季节性分解**
  - 季节性成分：通过傅里叶分析或移动平均法提取季节性模式。

- **2.2.3 噪声分析**
  - 噪声通常被视为随机误差，可以通过统计方法进行建模和预测。

#### 2.3 时间序列预测的数学公式

- **2.3.1 线性预测公式**
  - 简单线性预测：$\hat{y}_{t+1} = a + bt$。
  - 加权移动平均：$\hat{y}_{t+1} = \sum_{i=1}^{n} w_i y_{t-i+1}$，其中$w_i$是权重。

- **2.3.2 指数平滑法公式**
  - 单期平滑：$\hat{y}_{t+1} = \alpha y_t + (1-\alpha)\hat{y}_t$。
  - 两期平滑：$\hat{y}_{t+1} = \alpha y_t + (1-\alpha)\hat{y}_t$。

- **2.3.3 自回归模型的预测公式**
  - AR模型的预测公式基于模型参数和历史数据。

### 第3章: 时间序列分析的经典算法

#### 3.1 ARIMA算法

- **3.1.1 ARIMA算法的基本原理**
  - ARIMA模型由AR、I（差分）和MA三个部分组成。
  - 差分部分用于处理非平稳序列，使其平稳。

- **3.1.2 ARIMA算法的参数选择**
  - 确定阶数p、d、q：通常通过自相关图和偏自相关图来确定。

- **3.1.3 ARIMA算法的优缺点**
  - 优点：适合处理非平稳时间序列，模型简单。
  - 缺点：假设误差项服从正态分布，可能不适用于复杂序列。

#### 3.2 LSTM算法

- **3.2.1 LSTM算法的基本原理**
  - LSTM是一种特殊的RNN，通过记忆单元和门控机制来捕捉长期依赖关系。

- **3.2.2 LSTM算法的网络结构**
  - 输入门、遗忘门、输出门，以及记忆单元。

- **3.2.3 LSTM算法的优缺点**
  - 优点：适合处理时间序列的长期依赖关系。
  - 缺点：参数较多，训练时间较长。

#### 3.3 Prophet算法

- **3.3.1 Prophet算法的基本原理**
  - 基于非负的、平滑的每天增长量和每年周期性的成分。

- **3.3.2 Prophet算法的适用场景**
  - 适合处理有明确周期性且包含趋势的时间序列。

- **3.3.3 Prophet算法的优缺点**
  - 优点：容易使用，适合非专业的数据科学家。
  - 缺点：对异常值敏感，可能不如其他模型准确。

  train_data = scaled_data[:700]

  # 构建训练集和测试集
  X_train = train_data[:-1]
  y_train = train_data[1:]
  X_test = test_data[:-1]
  y_test = test_data[1:]

  # 训练模型
  model = RandomForestRegressor()
