## 第一部分: 代表性偏差的背景与概念

### 第1章: 代表性偏差的定义与背景

#### 1.1 代表性偏差的定义

##### 1.1.1 偏差的定义与分类

偏差是指在决策过程中，由于认知局限或信息不全，导致决策偏离实际的情况。代表性偏差是一种常见的偏差类型，指人们基于不充分的样本或典型案例，过度概括整体情况。

##### 1.1.2 代表性偏差的特征

- **典型性**：关注典型案例，忽略边缘情况。
- **简化性**：倾向于简化复杂问题，导致判断偏差。
- **误导性**：可能导致错误的投资决策。

##### 1.1.3 代表性偏差在投资中的表现

投资者常基于历史表现或市场趋势，过度概括未来走势，忽视潜在风险。

#### 1.2 代表性偏差的成因

##### 1.2.1 心理学视角：认知偏差的来源

- **确认偏差**：倾向于寻找支持已有假设的信息。
- **记忆偏差**：容易记住极端案例，忽视普通情况。

##### 1.2.2 统计学视角：样本与总体的差异

- **样本偏差**：样本不代表总体特征。
- **小样本效应**：小样本容易受极端值影响。

##### 1.2.3 投资决策中的典型偏差案例

- **技术分析中的偏差**：依赖技术指标，忽视市场基本面。
- **情绪驱动的偏差**：受市场情绪影响，做出非理性决策。

#### 1.3 代表性偏差的边界与外延

##### 1.3.1 偏差与其他认知偏差的关系

- 与确认偏差、选择性偏差等密切相关。

##### 1.3.2 代表性偏差在不同投资场景中的表现

- **选股策略**：基于过去表现选择股票，忽视未来变化。
- **风险管理**：低估风险发生的概率，导致过度冒险。

##### 1.3.3 偏差的正反两面性

- **正面**：帮助投资者快速决策。
- **负面**：可能导致重大损失。

### 第2章: 代表性偏差的核心原理

#### 2.1 偏差的数学模型

##### 2.1.1 概率论视角：事件发生的概率计算

代表性偏差可以看作是概率估计的错误。例如，假设某股票过去三年年均收益为10%，投资者可能认为未来也会保持10%的收益，而忽略了市场波动可能带来的影响。

##### 2.1.2 统计学视角：样本分布与总体分布的关系

假设我们从总体中抽取样本，如果样本量过小，可能无法准确反映总体特征。例如，基于过去一年的表现选择股票，可能无法反映长期趋势。

#### 2.2 偏差的属性特征对比

| 典型性     | 高       | 低         |

#### 3.3 算法实现与代码示例

##### 3.3.1 Python代码示例

```python
import numpy as np

# 示例数据
data = np.random.normal(loc=0, scale=1, size=100)

# 偏差检测
def detect_bias(data):
    mean = np.mean(data)
    std = np.std(data)
    z_scores = [(x - mean) / std for x in data]
    threshold = 3
    biased = [x > threshold for x in z_scores]
    return biased

biased_data = detect_bias(data)
print("检测到偏差的数据点：", sum(biased_data))
```

```python
def detect_representative_bias(data, threshold=0.1):
    # 计算总体分布
    import scipy.stats as stats
    mean = np.mean(data)
    std = np.std(data)
    z_scores = [(x - mean) / std for x in data]
    # 判断偏差
    biased = [abs(x) > threshold for x in z_scores]
    return biased
```
