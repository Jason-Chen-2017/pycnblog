## 第1章：小盘股投资的定义与特点

### 1.1 小盘股的定义与特征

#### 1.1.1 小盘股的定义
小盘股通常指市值较小的公司股票，一般定义为市值在 50 亿至 500 亿美元之间的公司。这些公司具有较高的增长潜力，但市场关注度较低，流动性相对较小。

#### 1.1.2 小盘股市场的特点
- 市场波动性较大
- 增长潜力高
- 风险较高
- 交易量相对较小

#### 1.1.3 小盘股投资的潜在机会与风险
- 机会：未被市场充分挖掘的成长型企业
- 风险：高波动性与流动性风险

## 附录

### 附录 A：常用投资指标公式

#### 1. 市盈率（P/E）= 股价 / 每股净利润
#### 2. 市净率（P/B）= 股价 / 每股净资产
#### 3. 净资产收益率（ROE）= 净利润 / 平均净资产

### 附录 B：数据处理与分析的 Python 代码示例

```python
import pandas as pd
import numpy as np

# 示例数据加载
data = pd.read_csv('小盘股数据.csv')

# 基本面指标计算
data['PE'] = data['股价'] / data['每股净利润']
data['PB'] = data['股价'] / data['每股净资产']
data['ROE'] = data['净利润'] / data['平均净资产']

# 筛选低市盈率与低市净率的股票
筛选条件：PE < 15 且 PB < 2 且 ROE > 10%
selected_stocks = data[(data['PE'] < 15) & (data['PB'] < 2) & (data['ROE'] > 0.1)]
```
