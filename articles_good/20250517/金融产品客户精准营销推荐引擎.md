### 5.2.1 协同过滤算法实现
```python
def user_based_collaborative_filtering(users, user_id, n_recommendations):
    # 计算用户相似度
    similarities = {}
    for u in users:
        if u != user_id:
            similarities[u] = cosine_similarity(users[user_id], users[u])
    # 排序并返回推荐
    sorted_users = sorted(similarities.items(), key=lambda x: x[1], reverse=True)[:n_recommendations]
    return [u[0] for u in sorted_users]
```
