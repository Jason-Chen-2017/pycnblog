## 3.2 算法实现

### 3.2.1 线性回归的Python实现
```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据准备
X = np.array([[1], [2], [3], [4]])
y = np.array([2, 4, 5, 4])

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测
print(model.predict([[5]]))
```

### 3.2.2 随机森林的数学公式
- 预测公式：
  $$ y = \sum_{i=1}^{n} w_i x_i $$
- 模型参数：
  $$ w_i \sim \mathcal{N}(0, \sigma^2) $$
