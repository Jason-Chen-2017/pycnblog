## 第一部分: 格雷厄姆的市盈率和市净率基础

### 第1章: 市盈率和市净率的背景与概念

#### 1.1 投资学基础
##### 1.1.1 价值投资的起源与发展
价值投资是一种以低于内在价值的价格买入优质股票的投资策略，其核心在于识别市场中被低估的投资标的。这一投资理念的鼻祖是本杰明·格雷厄姆，他在20世纪初提出了许多至今仍被广泛使用的股票估值方法。格雷厄姆的学生大卫· Dodd 与其共同提出了“内在价值”概念，并将市盈率和市净率作为评估股票价值的重要指标。

##### 1.1.2 格雷厄姆的价值投资理论
格雷厄姆的价值投资理论强调，股票的价格并非完全由市场情绪决定，而是应该基于其内在价值进行评估。他认为，市场的短期波动是不可预测的，但长期来看，股票价格会回归其内在价值。因此，投资者应该关注企业的基本面，寻找那些市场价格低于内在价值的企业进行投资。

##### 1.1.3 市盈率和市净率在投资中的重要性
在格雷厄姆的价值投资体系中，市盈率（P/E ratio）和市净率（P/B ratio）是最常用的两个估值指标。市盈率反映了市场的预期收益能力，而市净率则反映了市场的资产价值评估能力。通过这两个指标，投资者可以更好地判断股票的估值是否合理。

#### 1.2 核心概念的定义与背景
##### 1.2.1 市盈率的定义与计算公式
市盈率（P/E ratio）是指股票的市场价格除以每股收益（EPS）。它反映了市场对公司未来盈利能力的预期。公式如下：
$$
\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}
$$

##### 1.2.2 市净率的定义与计算公式
市净率（P/B ratio）是指股票的市场价格除以每股净资产（BPS，即 book value per share）。它反映了市场对公司资产价值的评估。公式如下：
$$
\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}
$$

##### 1.2.3 市盈率与市净率的比较与区别
市盈率和市净率都是衡量股票估值的重要指标，但它们关注的焦点不同。市盈率侧重于企业的盈利能力，而市净率侧重于企业的资产价值。以下是两者的对比：

| 对比维度 | 市盈率 | 市净率 |
|----------|--------|--------|
| 计算依据 | 每股收益 | 每股净资产 |
| 适用场景 | 判断盈利能力 | 判断资产价值 |
| 优点     | 反映市场对收益的预期 | 反映市场对资产的评估 |
| 缺点     | 受企业盈利周期影响 | 受企业资产结构影响 |

## 第二部分: 市盈率和市净率的核心概念与联系

### 第2章: 市盈率和市净率的核心概念与联系

#### 2.1 核心概念的原理
##### 2.1.1 市盈率的原理与影响因素
市盈率的计算基于股票价格和每股收益。每股收益是衡量企业盈利能力的重要指标，而股票价格则反映了市场对企业的整体估值。市盈率的高低反映了市场对企业的未来盈利能力的预期。一般来说，市盈率较低的股票可能意味着市场对其未来盈利能力的预期较低，或者企业的盈利能力较为稳定。

##### 2.1.2 市净率的原理与影响因素
市净率的计算基于股票价格和每股净资产。每股净资产是衡量企业资产价值的重要指标，而股票价格则反映了市场对企业的整体估值。市净率的高低反映了市场对企业资产价值的评估。一般来说，市净率较低的股票可能意味着企业资产被市场低估，或者企业的资产质量较差。

##### 2.1.3 市盈率与市净率的综合分析
市盈率和市净率的综合分析可以帮助投资者更全面地评估企业的价值。例如，市盈率较低但市净率较高的股票可能意味着企业资产价值被高估，而市盈率较高但市净率较低的股票可能意味着企业盈利能力被高估。

#### 2.2 概念属性特征对比
市盈率和市净率在属性特征上有显著的不同，以下是具体对比：

| 比较维度 | 市盈率 | 市净率 |
|----------|--------|--------|
| 计算基础 | 每股收益 | 每股净资产 |
| 适用行业 | 高增长行业 | 低增长行业 |
| 优点     | 反映市场对收益的预期 | 反映市场对资产的评估 |
| 缺点     | 受企业盈利周期影响 | 受企业资产结构影响 |

## 第三部分: 市盈率和市净率的算法原理

### 第3章: 市盈率和市净率的算法原理

#### 3.1 市盈率的计算与分析
##### 3.1.1 市盈率计算公式
$$
\text{市盈率} = \frac{\text{股价}}{\text{每股收益}}
$$

##### 3.1.2 市盈率的算法流程图
```mermaid
graph TD
    A[开始] --> B[输入股价和每股收益]
    B --> C[计算市盈率]
    C --> D[输出结果]
    D --> E[结束]
```

##### 3.1.3 市盈率的Python实现
以下是一个计算市盈率的Python代码示例：

```python
def calculate_pe(stock_price, eps):
    return stock_price / eps

# 示例
stock_price = 100
eps = 2.5
pe = calculate_pe(stock_price, eps)
print(f"市盈率: {pe}")
```

##### 3.1.4 市盈率的实际案例分析
假设某公司的股价为100元，每股收益为2.5元，则市盈率为：
$$
\text{市盈率} = \frac{100}{2.5} = 40
$$
这意味着市场对公司未来每股收益的预期为40倍。

#### 3.2 市净率的计算与分析
##### 3.2.1 市净率计算公式
$$
\text{市净率} = \frac{\text{股价}}{\text{每股净资产}}
$$

##### 3.2.2 市净率的算法流程图
```mermaid

    A[开始] --> B[输入股价和每股净资产]
    B --> C[计算市净率]
    C --> D[输出结果]
    D --> E[结束]
```

##### 3.2.3 市净率的Python实现
以下是一个计算市净率的Python代码示例：

```python
def calculate_pb(stock_price, bps):
    return stock_price / bps

# 示例
stock_price = 100
bps = 5
pb = calculate_pb(stock_price, bps)
print(f"市净率: {pb}")
```

##### 3.2.4 市净率的实际案例分析
假设某公司的股价为100元，每股净资产为5元，则市净率为：
$$
\text{市净率} = \frac{100}{5} = 20
$$
这意味着市场对公司每股净资产的估值为20倍。
