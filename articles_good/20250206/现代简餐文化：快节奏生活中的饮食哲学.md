### 系统核心实现源代码
```python
import numpy as np
from sklearn.neighbors import NearestNeighbors

# 数据预处理
class SimpleDietRecommendation:
    def __init__(self, dataset):
        self.dataset = dataset
        self.model = NearestNeighbors(n_neighbors=5, algorithm='ball_tree')

    def train(self):
        self.model.fit(self.dataset)

    def recommend(self, user_preference):
        distances, indices = self.model.kneighbors(user_preference)
        return indices.flatten()

# 示例数据集（营养成分矩阵）
dataset = np.array([
    [80, 20, 15, 50],  # 简餐1：高纤维、中蛋白、低脂肪、中维生素
    [60, 30, 20, 40],  # 简餐2：中纤维、高蛋白、中脂肪、低维生素
    [70, 25, 10, 35],  # 简餐3：高纤维、低蛋白、低脂肪、中维生素
    [50, 25, 15, 45],  # 简餐4：中纤维、低蛋白、中脂肪、高维生素
    [75, 15, 20, 30],  # 简餐5：高纤维、低蛋白、中脂肪、中维生素
])

# 初始化推荐系统
recommender = SimpleDietRecommendation(dataset)
recommender.train()

# 用户偏好（假设用户偏好高纤维、低脂肪）
user_preference = np.array([80, 10, 10, 10])

# 推荐结果
recommendations = recommender.recommend(user_preference)
print("推荐的简餐索引：", recommendations)
```

### 实际案例分析
假设用户偏好高纤维、低脂肪的简餐，系统会基于营养成分矩阵，推荐相似的简餐。例如，推荐索引为0、2、4的简餐，这些简餐符合用户的营养需求。
