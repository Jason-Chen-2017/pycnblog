## 3.3 Python源代码与解释

```python
import random

def ant_colony_optimization(distances, num_ants, max_iterations):
    # 初始化参数
    n = len(distances)
    pheromone = [[1 for _ in range(n)] for _ in range(n)]
    best_distance = float('inf')
    best_path = []

    for _ in range(max_iterations):
        for ant in range(num_ants):
            # 当前路径
            current_path = [0]
            current_distance = 0
            visited = [0]

            for _ in range(n-1):
                # 随机选择下一个节点
                next_node = random.choices(
                    range(1, n), 
                    weights=[pheromone[i][j] for j in range(n) if j != i]
                )[0]
                current_path.append(next_node)
                current_distance += distances[current_path[-2]][current_path[-1]]
                visited.append(next_node)

            # 更新最优路径
            if current_distance < best_distance:
                best_distance = current_distance
                best_path = current_path

            # 更新信息素
            for i in range(n):
                for j in range(n):
                    if i != j and i in current_path and j in current_path:
                        pheromone[i][j] += 1/(current_distance)

    return best_path, best_distance

# 示例数据：距离矩阵
distances = [
    [0, 2, 3, 4],
    [2, 0, 5, 7],
    [3, 5, 0, 6],
    [4, 7, 6, 0]
]

path, distance = ant_colony_optimization(distances, 5, 10)
print("最优路径：", path)
print("最优距离：", distance)
```

### 第四部分：数学模型和数学公式

## 4.1 基本数学模型

社区放映网络的优化目标是最大化资源利用率，最小化运营成本。数学模型如下：

$$ \text{目标函数} = \sum_{i=1}^{n} \sum_{j=1}^{m} c_{ij} \cdot x_{ij} $$

其中：
- $c_{ij}$ 表示从影院 $i$ 到影院 $j$ 的成本
- $x_{ij}$ 表示从影院 $i$ 到影院 $j$ 的资源分配比例

约束条件：
$$ \sum_{j=1}^{m} x_{ij} = 1 \quad \forall i $$
$$ \sum_{i=1}^{n} x_{ij} = 1 \quad \forall j $$

## 4.2 公式详细讲解

目标函数表示在所有可能的影院组合中，选择资源分配比例 $x_{ij}$，使得总成本最小。约束条件确保每个影院的资源分配是唯一的，且每个目标影院只接收一个资源分配。

## 4.3 举例说明

假设我们有三个影院 A、B、C，成本矩阵如下：

|       | A | B | C |
|-------|---|---|---|
| **A** | 0 | 2 | 3 |
| **B** | 2 | 0 | 4 |
| **C** | 3 | 4 | 0 |

通过数学模型计算，最优资源分配为 A→B、B→C、C→A，总成本为 $2 + 4 + 3 = 9$。
