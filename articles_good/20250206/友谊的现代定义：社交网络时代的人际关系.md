##### 第1章：友谊的定义与演变

###### 1.1 传统友谊的定义与特征
友谊是一种基于互相尊重、信任和情感支持的人际关系。传统友谊通常建立在面对面的互动基础上，强调共同的经历、兴趣和价值观。友谊的核心特征包括互惠性、情感支持和长期性。

###### 1.2 社交网络时代的友谊特征
在社交网络时代，友谊的定义发生了显著变化。线上友谊的特点包括：
- **虚拟性**：友谊的建立和维护主要依赖于数字平台。
- **广泛性**：社交网络使得人们能够与来自世界各地的人建立联系。
- **即时性**：线上互动通常是即时的，且不受时间和空间的限制。
- **多样性**：线上友谊可以基于兴趣、职业或其他虚拟社区建立。

###### 1.3 友谊的定义演变
友谊的定义从传统的面对面互动扩展到了线上互动。现代友谊不仅包括情感支持，还涉及信息共享、资源共享和虚拟支持。友谊的定义正在向更广泛、更灵活的方向发展。

#### 第2章：社交网络对友谊的影响

##### 2.1 线上友谊的优势与局限
**优势**：

- **便捷性**：线上互动更加便捷，可以随时随地进行。
- **多样性**：线上友谊可以基于兴趣、职业或其他虚拟社区建立。

**局限**：
- **缺乏深度**：线上友谊往往缺乏面对面的情感交流，容易停留在表面。

##### 友谊质量评估算法
```python
import networkx as nx
import numpy as np

def calculate_friendship_quality(G, node):
    quality = 0
    neighbors = list(G.neighbors(node))
    if len(neighbors) == 0:
        return 0
    for neighbor in neighbors:
        common_neighbors = list(nx.common_neighbors(G, node, neighbor))
        quality += len(common_neighbors)
    return quality / len(neighbors)
```

##### 友谊推荐系统
```python
def recommend_friends(G, user):
    scores = {}
    for node in G.nodes():
        if node == user:
            continue
        common_neighbors = list(nx.common_neighbors(G, user, node))
        scores[node] = len(common_neighbors)
    sorted_friends = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    return sorted_friends
```
