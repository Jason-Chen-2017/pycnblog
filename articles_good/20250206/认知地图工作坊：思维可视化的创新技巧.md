### 3.2 Python 源代码实现

```python
import networkx as nx
import matplotlib.pyplot as plt

# 数据预处理
def preprocess_data(data):
    nodes = []
    edges = []
    for item in data:
        nodes.append(item['concept'])
        for relation in item['relations']:
            edges.append((item['concept'], relation))
    return nodes, edges

# 生成图谱
def generate_graph(nodes, edges):
    G = nx.DiGraph()
    G.add_nodes_from(nodes)
    G.add_edges_from(edges)
    return G

# 可视化输出
def visualize_graph(G):
    pos = nx.spring_layout(G)
    plt.figure(figsize=(10, 10))
    nx.draw(G, pos, node_size=1500, alpha=0.8, edge_color='blue')
    plt.show()

# 示例数据
data = [
    {'concept': '思维可视化', 'relations': ['定义', '历史', '作用']},
    {'concept': '定义', 'relations': ['核心概念', '功能']},
    {'concept': '历史', 'relations': ['发展', '演变']},
    {'concept': '作用', 'relations': ['优势', '应用场景']}
]

# 执行流程
nodes, edges = preprocess_data(data)
graph = generate_graph(nodes, edges)
visualize_graph(graph)
```

### 3.3 数学模型与公式

在思维可视化中，生成图谱的过程可以看作是一个图论问题。节点表示概念，边表示概念之间的关系。图的生成可以通过以下数学模型表示：

$$
G = (V, E)
$$

其中，$V$ 是节点的集合，$E$ 是边的集合。边的权重可以表示概念之间的关系强度：

$$
E = \{ (v_i, v_j, w_{ij}) \}
$$

其中，$w_{ij}$ 表示节点 $v_i$ 和 $v_j$ 之间的关系强度。
