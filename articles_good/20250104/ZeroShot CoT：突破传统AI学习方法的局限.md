5. **动态调整学习率**：动态调整学习率是一种根据训练过程中的性能变化自动调整学习率的策略。常见的方法包括学习率衰减、自适应学习率调整（如Adam优化器）等。通过动态调整学习率，可以使得模型在训练过程中更好地收敛。

   ```python
   from sklearn.metrics import accuracy_score

   predictions = model.predict(X_test)
   accuracy = accuracy_score(y_test, predictions)
   print("Accuracy:", accuracy)
   ```

2. **召回率（Recall）**：模型预测为正类的真实正类样本数占总真实正类样本数的比例。

   ```python
   from sklearn.metrics import recall_score

   recall = recall_score(y_test, predictions, average='weighted')
   print("Recall:", recall)
   ```

3. **F1分数（F1 Score）**：综合考虑准确率和召回率的指标，用于评估二分类模型的性能。

   ```python
   from sklearn.metrics import f1_score

   f1 = f1_score(y_test, predictions, average='weighted')
   print("F1 Score:", f1)
   ```

4. **混淆矩阵（Confusion Matrix）**：用于展示模型预测结果与真实结果的对比。

   ```python
   from sklearn.metrics import confusion_matrix

   cm = confusion_matrix(y_test, predictions)
   print("Confusion Matrix:\n", cm)
   ```
