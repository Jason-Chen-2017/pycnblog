- **护理资源短缺**：全球范围内，专业护理人员的短缺已成为一个普遍问题。尤其是在发展中国家，护理人员的培训和配置不足，难以满足日益增长的老龄化需求。

- **安全性**：协作机器人采用安全传感器和碰撞检测技术，能够在与人接触时避免造成伤害。
- **灵活性**：协作机器人具有高度的可编程性和灵活性，能够适应不同的工作场景和任务需求。
- **智能化**：协作机器人集成了多种传感器和智能算法，能够实现自主感知、决策和执行。

协作机器人在老年护理中的角色主要包括：

- **辅助日常活动**：协作机器人可以帮助老年人完成日常活动，如洗澡、穿衣、移动等，减轻护理人员的工作负担。
- **提供社交互动**：协作机器人可以通过语音、图像和触觉与人交互，为老年人提供社交互动，缓解孤独感。
- **监测健康状况**：协作机器人可以实时监测老年人的健康状况，如心率、血压、步态等，及时发现异常情况并报警。

        contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
        if contours:
            return "Object detected"
        else:
            return "No object"
