   ```python
   def greet(name):
       return f"Hello, {name}!"
   
   print(greet("Alice"))
   ```

3. **公式**：使用LaTeX格式嵌入数学公式，使用`$$`括起来的公式将独立成段，例如：
   $$ E = mc^2 $$

   $$ 1 < 2 $$

4. **列表和子列表**：使用`*`、`-`或`+`号创建无序列表，使用数字和点号创建有序列表，例如：
   - 无序列表项1
   - 无序列表项2
     - 子列表项1
     - 子列表项2

5. **引用和链接**：使用`>`号创建引用，使用`[链接文本](URL)`创建链接，例如：
   > 这是引用。
   [点击了解更多](https://example.com)

6. **图像和表格**：使用`![图像描述](图像URL)`插入图像，使用`|`分隔的表格项创建表格，例如：
   ```mermaid
   table
     Title | Header1 | Header2
     ------|---------|---------
     Row1  | Data1   | Data2
     Row2  | Data3   | Data4
   ```

通过上述markdown格式的应用，我们能够确保文章的结构清晰、格式统一，便于读者阅读和理解。同时，markdown的简洁性和易用性也使得文章的编辑和维护变得更加高效。
