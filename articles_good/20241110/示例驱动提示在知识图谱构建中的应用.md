## Key Mathematical Models

### Model 1: Graph Embedding

Graph embedding is a mathematical model that represents entities and relationships in a knowledge graph as high-dimensional vectors. These vectors capture the semantic information of the entities and relationships, enabling efficient similarity search and reasoning over the knowledge graph.

### Model 2: Entity Embedding

Entity embedding is a specific type of graph embedding that focuses on representing entities as vectors. These vectors are learned from data and capture the semantic information of the entities, such as their types, attributes, and relationships.

### Model 3: Relationship Embedding

Relationship embedding is another type of graph embedding that represents relationships as vectors. These vectors capture the semantic information of the relationships, such as their types, properties, and the entities they connect.

### Model 4: Attention Mechanism

The attention mechanism is a mathematical model used to weigh the importance of different parts of the input data. In the context of Example-Guided Prompting, attention mechanisms can be used to focus on the most relevant examples when constructing the knowledge graph.

### Model 5: Inference and Reasoning

Inference and reasoning models are mathematical models that enable the derivation of new information from the knowledge graph. These models include algorithms such as shortest path calculation, graph traversal, and rule-based reasoning.

## Detailed Explanation of Key Models

### Model 1: Graph Embedding

Graph embedding can be formalized using the following mathematical model:

$$
\text{vec}(G) = \phi(G)
$$

where $\text{vec}(G)$ is the vector representation of the graph $G$, and $\phi$ is the embedding function. The embedding function maps the graph nodes and edges to high-dimensional vectors, capturing their semantic information.

Example:
$$
\text{vec}(n_i) = \begin{bmatrix} v_{i1} & v_{i2} & \ldots & v_{id} \end{bmatrix}^T
$$

where $n_i$ is the $i$-th node in the graph, and $v_{ij}$ is the $j$-th dimension of the node's vector representation.

### Model 2: Entity Embedding

Entity embedding is based on the following mathematical model:

$$
\text{vec}(e_i) = \begin{bmatrix} e_{i1} & e_{i2} & \ldots & e_{id} \end{bmatrix}^T
$$

where $e_i$ is the $i$-th entity, and $e_{ij}$ is the $j$-th dimension of the entity's vector representation. The dimensions can include features such as entity type, attributes, and relationships.

Example:
$$
\text{vec}(e_1) = \begin{bmatrix} 1 & 0 & 0 & 1 & 0 \end{bmatrix}^T
$$

where $e_1$ is an entity representing a person with attributes "name" (1) and "age" (0).

### Model 3: Relationship Embedding

Relationship embedding is defined as follows:

$$
\text{vec}(r_j) = \begin{bmatrix} r_{j1} & r_{j2} & \ldots & r_{jd} \end{bmatrix}^T
$$

where $r_j$ is the $j$-th relationship, and $r_{ij}$ is the $j$-th dimension of the relationship's vector representation. The dimensions can include features such as relationship type, properties, and the entities it connects.

Example:
$$
\text{vec}(r_1) = \begin{bmatrix} 1 & 0 & 0 \end{bmatrix}^T
$$

where $r_1$ is a relationship representing "works_for" between two entities.

### Model 4: Attention Mechanism

The attention mechanism can be modeled using a weighted sum of input components, as shown below:

$$
\text{context\_vector} = \sum_{i=1}^{N} a_i \cdot \text{input}_i
$$

where $a_i$ is the attention weight for the $i$-th input component, and $\sum_{i=1}^{N} a_i = 1$. The attention weights are calculated based on the relevance of each input component to the task at hand.

Example:
$$
\text{context\_vector} = 0.5 \cdot \text{input}_1 + 0.3 \cdot \text{input}_2 + 0.2 \cdot \text{input}_3
$$

where $\text{input}_1$, $\text{input}_2$, and $\text{input}_3$ are three different input components.

### Model 5: Inference and Reasoning

Inference and reasoning models can be expressed using graph traversal algorithms, such as depth-first search (DFS) or breadth-first search (BFS). These algorithms enable the derivation of new information from the knowledge graph based on the relationships between entities.

Example (DFS):
$$
\text{inference}(G, v_i, r_j, v_j) = \text{DFS}(G, v_i, r_j, v_j)
$$

where $G$ is the knowledge graph, $v_i$ and $v_j$ are entities, and $r_j$ is a relationship connecting $v_i$ and $v_j$.

import spacy

# Load the Spacy language model
nlp = spacy.load('en_core_web_sm')

def analyze_example(example):
    doc = nlp(example)
    entities = []
    relationships = []

    for ent in doc.ents:
        entities.append(ent.text)

    for token in doc:
        if token.dep_ == 'pobj':
            relationships.append((token.head.text, token.text))

    return entities, relationships

# Analyze the examples

### Step 4: Knowledge Graph Construction

After analyzing the examples, we will construct a knowledge graph using the NetworkX library. We will create nodes for entities and edges for relationships.

```python
import networkx as nx

# Create an empty graph
G = nx.Graph()

# Add nodes and edges to the graph
for example in analyzed_examples:
    entities, relationships = example

    for entity in entities:
        G.add_node(entity)

    for relationship in relationships:
        G.add_edge(relationship[0], relationship[1])
```
