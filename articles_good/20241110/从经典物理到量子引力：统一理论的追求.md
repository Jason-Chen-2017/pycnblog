#### 1.1.2 经典力学的基本原理

经典力学是研究物体运动的科学，其基础是牛顿运动定律。牛顿三定律描述了物体在力的作用下的运动规律。经典力学的另一个重要部分是能量守恒定律，它表明在一个封闭系统中，总能量保持不变。

经典电磁学由麦克斯韦方程组描述，这些方程组总结了电磁场的动态行为。麦克斯韦方程组包括高斯定律、法拉第电磁感应定律、安培定律等，这些方程构成了现代电磁理论的基础。

## 第二部分：量子物理理论

### 2.1 量子物理的基本概念

#### 2.1.1 量子态与波函数

量子态是量子系统的状态，可以用波函数来描述。波函数提供了粒子位置和动量的概率分布。

**核心算法原理讲解：**
```plaintext
// 波函数的表示
|\psi\rangle = \sum_{i} c_i |i\rangle

// 波函数的物理意义
\langle x | \psi \rangle = \psi(x)
```

**数学模型和数学公式 & 详细讲解 & 举例说明：**
$$
\psi(x) = \int_{-\infty}^{\infty} \phi(p) e^{ipx/\hbar} dp
$$
**例子：** 计算一个自由粒子的波函数。

#### 2.1.2 量子力学的基本原理

量子力学是描述微观粒子的运动规律的科学。其基本原理包括波粒二象性、不确定性原理和量子态的叠加。

**核心算法原理讲解：**
```plaintext
// 波粒二象性
p = \hbar k

// 不确定性原理
\Delta x \Delta p \geq \hbar/2

// 量子态的叠加
|\psi\rangle = \frac{1}{\sqrt{2}} (|0\rangle + |1\rangle)
```

**数学模型和数学公式 & 详细讲解 & 举例说明：**
$$
\hat{H} |\psi\rangle = E |\psi\rangle
$$
**例子：** 计算一个粒子在势阱中的能量。
