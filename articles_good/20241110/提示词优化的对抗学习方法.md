### 3.2 Pseudocode Explanation

To provide a clear understanding of these algorithms, we will present their pseudocode explanations. Each algorithm will be explained step by step, and the pseudocode will be accompanied by a brief description of its purpose and functionality.

#### Gradient Descent

```pseudo
initialize: 
  parameters (w, b) 
  learning rate (alpha)
  number of iterations (epochs)

for epoch in range(epochs):
    for each data point (x, y) in the training set:
        Compute the loss (L) using the current parameters
        Compute the gradients (dw, db) using the loss function and the chain rule
        Update the parameters using the gradients and the learning rate:
            w <- w - alpha * dw
            b <- b - alpha * db
```

#### Adaptive Gradient Algorithm (AdaGrad)

```pseudo
initialize:
  parameters (w, b)
  learning rate (alpha)
  gradients squared sum (prev_grads_squared)

for epoch in range(epochs):
    for each data point (x, y) in the training set:
        Compute the loss (L) using the current parameters
        Compute the gradients (dw, db) using the loss function and the chain rule
        Update the gradients squared sum:
            prev_grads_squared <- prev_grads_squared + (dw)^2 + (db)^2
        Update the parameters using the gradients and the learning rate:
            w <- w - alpha * dw / sqrt(prev_grads_squared)
            b <- b - alpha * db / sqrt(prev_grads_squared)
```

### 4.4 Examples of Mathematical Models and Formulations

Here are some examples of mathematical models and formulations used in prompt optimization and adversarial learning:

#### Gradient Descent with Momentum

$$$
w_{t+1} = w_t - \alpha \cdot \frac{\partial L}{\partial w} + \beta \cdot (w_t - w_{t-1})
$$$

where:
- \(w_t\) is the weight vector at time step \(t\)
- \(\alpha\) is the learning rate
- \(\beta\) is the momentum coefficient
- \(\frac{\partial L}{\partial w}\) is the gradient of the loss function with respect to the weight vector

#### Cross-Entropy Loss

$$$
L = -\frac{1}{m} \sum_{i=1}^{m} [y_i \cdot \log(p_i) + (1 - y_i) \cdot \log(1 - p_i)]
$$$

where:
- \(y_i\) is the true label for the \(i^{th}\) example
- \(p_i\) is the predicted probability for the true label
- \(m\) is the number of examples in the training set
