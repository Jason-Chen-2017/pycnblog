#### 1.1 李群的定义

李群是一种特殊的群，它不仅满足群的性质，还满足李代数的性质。具体来说，李群是一个拓扑空间，其上的运算满足以下条件：

1. 封闭性：对于群中的任意两个元素 $a$ 和 $b$，它们的运算结果 $ab$ 仍然属于这个群。
2. 结合性：对于群中的任意三个元素 $a$、$b$ 和 $c$，有 $(ab)c = a(bc)$。
3. 存在单位元：存在一个元素 $e$，使得对于群中的任意元素 $a$，有 $ea = ae = a$。
4. 存在逆元：对于群中的任意元素 $a$，存在另一个元素 $a^{-1}$，使得 $aa^{-1} = a^{-1}a = e$。

李群的定义不仅限于此，它还包括了李代数的定义。李代数是李群的一个代数结构，它由一组向量及其线性运算构成，满足特定的条件。

#### 1.2 李群的性质

李群具有以下几个重要的性质：

1. **连续性**：李群作为一个拓扑空间，其上的运算和结构都是连续的。这意味着，如果李群中的元素依次趋近于某个值，那么它们的运算结果也会依次趋近于相应的值。
2. **可微性**：李群的运算和结构都具有可微性，这意味着它们可以用导数来描述。这对于我们在舞蹈编排中分析动作的平滑性和连贯性具有重要意义。
3. **局部欧氏性**：李群的每一个局部都可以看作是一个欧氏空间。这意味着，在李群中的任意一个开集内，都可以找到一种局部坐标系统，使得这个局部李群在这个坐标系统下呈现出欧氏空间的结构。

### 第3章：数学对称性原理

#### 3.1 对称性的定义

对称性是指物体或图形在某种变换下保持不变的性质。具体来说，对称性可以分为以下几种类型：

1. **轴对称**：物体或图形在某条直线（称为对称轴）的两侧是完全一样的。
2. **中心对称**：物体或图形绕某个点旋转180度后仍然保持不变。
3. **旋转对称**：物体或图形绕某个点旋转一定角度后仍然保持不变。
4. **镜像对称**：物体或图形的一部分与另一部分关于某个平面镜像对称。

对称性在数学中有着广泛的应用，它不仅是几何学中的一个重要概念，也在物理学、生物学、艺术等领域中发挥着重要作用。

2. **时间对称**：通过在时间上安排舞蹈者的动作，使得舞蹈动作在时间上具有对称性。例如，两个舞蹈动作在时间上的反演，或者一个动作的重复和反转。
3. **组合对称**：通过将多种对称性组合在一起，创造出复杂的对称性舞蹈动作。例如，同时具有空间对称和时间对称的舞蹈动作。
