```plaintext
Algorithm MindChainAlgorithm
Input: CaseData, LawRules
Output: Conclusion

2. for each Fact in CaseData do
```

#### 4.3 数学模型与公式

在思维链的算法设计中，常用的数学模型和公式包括：

1. **条件概率**：用于计算两个事件同时发生的概率。
2. **贝叶斯公式**：用于计算后验概率，即根据已知条件概率和先验概率计算新事件的概率。
3. **熵**：用于衡量信息的随机性和不确定性。

以下是这些数学模型和公式的具体内容：

**条件概率公式**：

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

**贝叶斯公式**：

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

**熵**：

$$H(X) = -\sum_{i=1}^{n} p_i \cdot \log_2(p_i)$$
