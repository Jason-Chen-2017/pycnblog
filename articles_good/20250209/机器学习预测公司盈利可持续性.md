# 第2章: 机器学习算法原理

## 2.1 线性回归算法
### 2.1.1 线性回归的基本原理
通过最小化预测值与实际值的差值平方和，找到最佳拟合直线。

### 2.1.2 线性回归的数学模型
$$ y = \beta_0 + \beta_1x + \epsilon $$

### 2.1.3 线性回归的实现步骤
1. 数据预处理：标准化、特征选择。
2. 模型训练：使用梯度下降法求解系数。
3. 模型评估：计算R²值、残差分析。

### 2.1.4 线性回归的优缺点
- 优点：简单、易于解释。
- 缺点：只能处理线性关系。

### 2.1.5 线性回归的Python代码示例
```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据准备
X = np.array([i for i in range(100)]).reshape(-1, 1)
y = np.array([2*i + 1 for i in range(100)])

# 模型训练
model = LinearRegression()
model.fit(X, y)

# 预测
print(model.predict(X))
```

## 2.2 支持向量机算法
### 2.2.1 SVM的基本原理
通过构建超平面，将数据点分为两类，适用于分类和回归问题。

### 2.2.2 SVM的数学模型
$$ \text{目标函数} = \frac{1}{2}\|w\|^2 + C\sum_{i=1}^n \xi_i $$

### 2.2.3 SVM的实现步骤
1. 数据预处理：标准化、降维。
2. 模型训练：使用svc函数训练模型。
3. 模型评估：计算准确率、F1分数。

### 2.2.4 SVM的优缺点
- 优点：适用于非线性关系，泛化能力强。
- 缺点：计算复杂度高。

### 2.2.5 SVM的Python代码示例
```python
from sklearn.svm import SVR

# 数据准备
X = np.array([i for i in range(100)]).reshape(-1, 1)
y = np.array([i**2 for i in range(100)])

# 模型训练
model = SVR(kernel='rbf')
model.fit(X, y)

# 预测
print(model.predict(X))
```

## 2.3 随机森林算法
### 2.3.1 随机森林的基本原理
通过构建多棵决策树，利用投票机制得出最终预测结果。

### 2.3.2 随机森林的数学模型
无明确数学公式，主要依赖树结构的投票机制。

### 2.3.3 随机森林的实现步骤
1. 数据预处理：特征选择、数据分割。
2. 模型训练：训练多棵决策树。
3. 模型评估：计算准确率、混淆矩阵。

### 2.3.4 随机森林的优缺点
- 优点：适用于高维度数据，抗过拟合。
- 缺点：计算资源消耗大。

### 2.3.5 随机森林的Python代码示例
```python
from sklearn.ensemble import RandomForestRegressor

# 数据准备
X = np.array([i for i in range(100)]).reshape(-1, 1)
y = np.array([i**3 for i in range(100)])

# 模型训练
model = RandomForestRegressor(n_estimators=10)
model.fit(X, y)

# 预测
print(model.predict(X))
```

## 2.4 神经网络算法
### 2.4.1 神经网络的基本结构
由输入层、隐藏层和输出层组成，通过多层感知机进行非线性映射。

### 2.4.2 神经网络的数学模型
$$ y = \sigma(wx + b) $$

### 2.4.3 神经网络的实现步骤
1. 数据预处理：标准化、归一化。
2. 模型训练：使用反向传播算法调整权重。
3. 模型评估：计算准确率、损失函数值。

### 2.4.4 神经网络的优缺点
- 优点：适用于复杂非线性关系，表达能力强。
- 缺点：训练时间长，容易过拟合。

### 2.4.5 神经网络的Python代码示例
```python
import keras
from keras.layers import Dense
from keras.models import Sequential

# 数据准备
X = np.array([i for i in range(100)]).reshape(-1, 1)
y = np.array([i**4 for i in range(100)])

# 模型训练
model = Sequential()
model.add(Dense(64, activation='relu', input_dim=1))
model.add(Dense(1))
model.compile(optimizer='adam', loss='mean_squared_error')
model.fit(X, y, epochs=100, batch_size=1)

# 预测
print(model.predict(X))
```

| 算法       | 优点                     | 缺点                       |

## 4.2 核心代码实现
### 4.2.1 数据预处理代码
```python
import pandas as pd
import numpy as np

# 数据加载
data = pd.read_csv('company_profit.csv')

# 数据清洗
data.dropna(inplace=True)

# 特征提取
X = data[['revenue', 'expenses', 'industry_index']]
y = data['profit']

# 数据标准化
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```

### 4.2.2 模型训练代码
```python
from sklearn.ensemble import RandomForestRegressor

# 模型训练
model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(X_scaled, y)

# 模型预测
X_new = np.array([[1000000, 800000, 1.2]]).reshape(1, -1)
X_new_scaled = scaler.transform(X_new)
y_pred = model.predict(X_new_scaled)
print(f'预测利润：{y_pred[0]:.2f}')
```
