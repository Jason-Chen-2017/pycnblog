## 群论基础

### 2.1 群的基本概念

群是一种代数结构，其定义如下：

- **群（Group）**：设G是一个非空集合，如果G中存在一个二元运算“·”（通常称为乘法），使得G对于·运算构成一个代数系统，即满足以下性质：

  1. **结合律**：对于任意的a, b, c ∈ G，都有 (a · b) · c = a · (b · c)。
  2. **存在单位元**：存在一个元素e ∈ G，使得对任意的a ∈ G，都有 e · a = a · e = a。
  3. **存在逆元**：对于任意的a ∈ G，都存在一个元素a' ∈ G，使得 a · a' = a' · a = e。

### 2.2 同态与同构

- **同态（Homomorphism）**：设G和H是两个群，如果存在一个映射f: G → H，满足对于任意的a, b ∈ G，都有 f(a · b) = f(a) · f(b)，那么称f是G到H的一个同态。

- **同构（Isomorphism）**：如果同态f: G → H是双射（即一一对应且满射），那么称f是G到H的一个同构。同构意味着两个群具有相同的结构。

### 2.3 群的直积与半直积

- **直积（Direct Product）**：设G1和G2是两个群，如果存在一个群G和一个同态π1: G → G1和π2: G → G2，满足π1和π2都是满同态，且对于任意的群G'和同态f1: G' → G1和f2: G' → G2，如果f1和f2都是同态，那么存在唯一的同态f: G' → G使得π1 ∘ f = f1和π2 ∘ f = f2，那么称G为G1和G2的直积。

- **半直积（Direct Sum）**：如果直积G = G1 × G2，且对于任意的a ∈ G1和b ∈ G2，都有a · b = e（其中e是G的单位元），那么称G是G1和G2的半直积。

## 表示论基础

### 3.1 表示空间的定义

- **表示空间（Representation Space）**：设G是一个群，V是一个向量空间，如果存在一个群同态φ: G → GL(V)，其中GL(V)是V上的线性变换群，那么称V是G的一个表示空间，φ称为一个表示。

### 3.2 线性表示

- **线性表示（Linear Representation）**：设G是一个群，V是一个线性空间，φ: G → GL(V)是一个群同态，那么称φ为G的一个线性表示。

### 3.3 矩阵表示

- **矩阵表示（Matrix Representation）**：设G是一个有限群，V是一个有限维线性空间，φ: G → GL(V)是一个群同态，那么φ可以表示为矩阵形式。具体地，对于每个g ∈ G，存在一个矩阵M_g ∈ GL(V)，使得φ(g)v = M_g v。

### 3.4 群表示的分类

- **可约表示（Irreducible Representation）**：设V是群G的一个表示，如果V不能被分解为两个或多个子空间的直和，那么称V为G的一个可约表示。

- **不可约表示（Invertible Representation）**：设V是群G的一个表示，如果V的任意子空间都是可约的，那么称V为G的一个不可约表示。

## 群与表示之间的联系

Maschke定理是群表示论中的一个重要定理，它描述了有限群的可约表示的性质。具体而言，Maschke定理指出，任何一个有限群G的可解子群的所有不可约表示的直和仍然是G的可约表示。

### 4.2 正交性定理

正交性定理是群表示论中的另一个重要定理，它描述了群表示之间的正交性。设V和W是群G的两个表示空间，如果对于任意的v ∈ V和w ∈ W，都有φ(g)v, w = 0，那么称V和W是正交的。

## 群论基础

### 2.1 群的基本概念

群是一种代数结构，它由一组元素及其运算组成，满足结合律、存在单位元和存在逆元等基本性质。

- **群的定义**：设G是一个非空集合，如果G中存在一个二元运算“·”（通常称为乘法），使得G对于·运算构成一个代数系统，即满足以下性质：

  1. **结合律**：对于任意的a, b, c ∈ G，都有 (a · b) · c = a · (b · c)。

  2. **存在单位元**：存在一个元素e ∈ G，使得对任意的a ∈ G，都有 e · a = a · e = a。

  3. **存在逆元**：对于任意的a ∈ G，都存在一个元素a' ∈ G，使得 a · a' = a' · a = e。

### 2.2 同态与同构

- **同态（Homomorphism）**：设G和H是两个群，如果存在一个映射f: G → H，满足对于任意的a, b ∈ G，都有 f(a · b) = f(a) · f(b)，那么称f是G到H的一个同态。

- **同构（Isomorphism）**：如果同态f: G → H是双射（即一一对应且满射），那么称f是G到H的一个同构。同构意味着两个群具有相同的结构。

### 2.3 群的直积与半直积

- **直积（Direct Product）**：设G1和G2是两个群，如果存在一个群G和一个同态π1: G → G1和π2: G → G2，满足π1和π2都是满同态，且对于任意的群G'和同态f1: G' → G1和f2: G' → G2，如果f1和f2都是同态，那么存在唯一的同态f: G' → G使得π1 ∘ f = f1和π2 ∘ f = f2，那么称G为G1和G2的直积。

- **半直积（Direct Sum）**：如果直积G = G1 × G2，且对于任意的a ∈ G1和b ∈ G2，都有a · b = e（其中e是G的单位元），那么称G是G1和G2的半直积。

## 表示论基础

### 3.1 表示空间的定义

- **表示空间（Representation Space）**：设G是一个群，V是一个向量空间，如果存在一个群同态φ: G → GL(V)，其中GL(V)是V上的线性变换群，那么称V是G的一个表示空间，φ称为一个表示。

### 3.2 线性表示

- **线性表示（Linear Representation）**：设G是一个群，V是一个线性空间，φ: G → GL(V)是一个群同态，那么称φ为G的一个线性表示。

### 3.3 矩阵表示

- **矩阵表示（Matrix Representation）**：设G是一个有限群，V是一个有限维线性空间，φ: G → GL(V)是一个群同态，那么φ可以表示为矩阵形式。具体地，对于每个g ∈ G，存在一个矩阵M_g ∈ GL(V)，使得φ(g)v = M_g v。

### 3.4 群表示的分类

- **可约表示（Irreducible Representation）**：设V是群G的一个表示，如果V不能被分解为两个或多个子空间的直和，那么称V为G的一个可约表示。

- **不可约表示（Invertible Representation）**：设V是群G的一个表示，如果V的任意子空间都是可约的，那么称V为G的一个不可约表示。

## 群与表示之间的联系

### 4.1 Maschke定理

Maschke定理是群表示论中的一个重要定理，它描述了有限群的可约表示的性质。具体而言，Maschke定理指出，任何一个有限群G的可解子群的所有不可约表示的直和仍然是G的可约表示。

### 4.2 正交性定理

正交性定理是群表示论中的另一个重要定理，它描述了群表示之间的正交性。设V和W是群G的两个表示空间，如果对于任意的v ∈ V和w ∈ W，都有φ(g)v, w = 0，那么称V和W是正交的。
