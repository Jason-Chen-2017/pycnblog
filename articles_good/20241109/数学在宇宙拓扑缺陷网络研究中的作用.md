## 数学工具介绍

### 2.1 拓扑学基础

拓扑学是研究空间性质而不考虑形状和大小的数学分支。在拓扑学中，空间被认为是由点、线、面等基本元素组成，而这些元素之间的关系和性质是研究的重点。拓扑学的基本概念包括连通性、紧致性、边界、同胚等。

- **连通性**：一个空间是连通的，当且仅当其中任意两个点都可以通过连续的路径连接起来。连通性是拓扑学中一个重要的性质，许多拓扑学问题都涉及到连通性的分析。

- **紧致性**：一个空间是紧致的，当且仅当它的每一个开覆盖都有有限的子覆盖。紧致性是拓扑空间的一个重要性质，它与空间的结构和性质密切相关。

- **边界**：在拓扑空间中，边界是指一个集合与其补集的交集。边界反映了空间中不同部分之间的分界线，是拓扑学中研究的重要内容。

- **同胚**：两个拓扑空间是同胚的，当且仅当它们之间存在一个双射映射，且这个映射的逆映射也是连续的。同胚关系反映了空间的结构和性质保持不变，是拓扑学中的一个重要概念。

### 2.2 图论基础

图论是研究图形及其性质和关系的数学分支。在图论中，图形由节点（顶点）和边（弧）组成，节点和边之间存在着特定的关系和性质。图论的基本概念包括连通性、路径、树、图同构等。

- **连通性**：一个图是连通的，当且仅当图中任意两个节点都存在一条路径相连。连通性是图论中的一个重要概念，反映了图形中的节点连接关系。

- **路径**：在一个图中，路径是指一系列相连的节点和边。路径的长度是指路径中节点的数量减去1。图论中研究路径的性质和关系，如最短路径、最长路径等。

- **树**：树是一种特殊的图，其中任意两个节点之间都存在一条路径相连。树是图论中的一个重要概念，它代表了图形中的最小连通结构。

- **图同构**：两个图是同构的，当且仅当它们具有相同的节点和边，且节点之间的连接关系相同。图同构反映了图形的拓扑结构保持不变，是图论中的一个重要问题。

### 2.3 网络理论基础

网络理论是研究网络结构、功能和性能的数学分支。在网络理论中，网络被看作是由节点和边组成的集合，节点和边之间存在特定的关系和性质。网络理论的基本概念包括网络拓扑、网络流、网络优化等。

- **网络拓扑**：网络拓扑是指网络的连接方式和结构。网络拓扑可以描述为节点和边的集合，节点和边之间的关系可以是邻接、相邻等。网络拓扑是网络理论中最基本的概念之一，反映了网络的物理结构和连接关系。

- **网络流**：网络流是指网络中的数据传输和信息流动。网络流可以通过流量矩阵、流方程等数学模型进行描述和分析。网络流理论研究了网络中数据传输的规律和性能，如最大流量、最小费用流等。

- **网络优化**：网络优化是指通过调整网络结构和参数，提高网络性能和稳定性。网络优化问题可以描述为在给定的网络拓扑和流量需求下，找到最优的网络结构或参数。网络优化理论研究了网络优化算法的设计和性能分析，如最小生成树、网络流算法等。

    # 假设G已经通过load_data函数加载完成

    degree_sequence = list(dict(G.degree()).values())

    network_density = nx.density(G)
    
    # 6.4.3 拓扑特征提取
    clustering_coefficient = nx.average_clustering(G)
    
    # 6.4.4 可视化
    nx.draw(G, with_labels=True)

    return average_degree, network_density, clustering_coefficient
