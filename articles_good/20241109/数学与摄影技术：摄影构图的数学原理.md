#### 光学原理与镜头公式

光学原理是摄影技术的基础，而镜头公式是光学原理在摄影中的应用。镜头公式描述了镜头焦距与镜头直径、光圈等参数之间的关系。常见的镜头公式如下：

\[ \text{镜头公式}：\frac{1}{f} = \frac{1}{d} + \frac{1}{s} \]

其中，\( f \) 是镜头的焦距，\( d \) 是镜头的直径，\( s \) 是物距（物体到镜头的距离）。通过调整镜头的焦距和光圈，可以控制成像的大小和清晰度。

#### 成像原理与景深

成像原理是指光线通过镜头后在感光材料上形成图像的过程。光线从物体反射后，通过镜头折射，最终在感光平面上聚焦。景深是指画面中能够清晰呈现的范围，其大小取决于镜头的焦距、光圈和拍摄距离。景深公式如下：

\[ \text{景深公式}：\text{景深} = \frac{f}{\text{光圈}} \times (\text{拍摄距离} - \text{焦距}) \]

通过调整光圈和焦距，可以控制景深的大小，从而实现不同的构图效果。

摄影中的构图算法主要通过数学模型和公式来实现，以下是几个关键的构图算法原理，使用伪代码进行详细阐述：

#### 1. 黄金比例算法

黄金比例是一种经典的构图原则，其核心是0.618的比率。以下是一个用于计算黄金比例分割点的伪代码：

```python
def golden_ratio_partition(length):
    """
    计算黄金比例分割点
    :param length: 总长度
    :return: 分割点
    """
    short_segment = length * 0.382
    long_segment = length - short_segment
    return short_segment, long_segment
```

对称是构图中的一个重要元素，以下是计算对称轴的伪代码：

def find_symmetry_axis(points):
    """
    计算多边形对称轴
    :param points: 多边形的顶点列表
    :return: 对称轴的参数
    """
    # 这里用简单的平均值方法计算对称轴
    x_coords = [p[0] for p in points]
    y_coords = [p[1] for p in points]
    symmetry_axis = (sum(x_coords) / len(points), sum(y_coords) / len(points))

#### 3. 景深计算算法

景深是摄影中一个重要的概念，以下是计算景深范围的基本伪代码：

```python
def calculate_depth_of_field(focus_distance, aperture, lens_focal_length):
    """
    计算景深范围
    :param focus_distance: 对焦距离
    :param aperture: 光圈大小
    :param lens_focal_length: 镜头焦距
    :return: 景深范围
    """
    circle_of_confusion = 0.03  # 根据相机类型调整
    hyperfocal_distance = (lens_focal_length ** 2) / (aperture * circle_of_confusion)
    near_limit = (hyperfocal_distance - focus_distance) * (1 - (aperture / (2 * lens_focal_length)))
    far_limit = (hyperfocal_distance + focus_distance) * (1 + (aperture / (2 * lens_focal_length)))
    return near_limit, far_limit
```

def color_correction(image, target_color):
    """
    对图像进行色彩校正
    :param image: 待校正的图像
    :param target_color: 目标色彩值
    :return: 校正后的图像
    """
    corrected_image = []
    for pixel in image:

#### 数学模型和公式

在摄影构图中，数学模型和公式扮演着至关重要的角色，它们不仅帮助我们理解和计算各种参数，还能指导我们进行有效的构图。以下是一些关键的数学模型和公式，以及它们在摄影中的应用和详细讲解。

##### 1. 黄金比例（Golden Ratio）

黄金比例，通常表示为φ（phi），大约等于1.618。在摄影构图中，黄金比例用于确定视觉焦点和平衡点。它可以通过以下公式计算：

\[ \phi = \frac{1 + \sqrt{5}}{2} \]

黄金分割点（即0.618）是构图中的一个重要比例，它能够吸引观众的目光。例如，在一个水平或垂直的图像中，如果将画面分成两个部分，较长部分与整体画面的比例接近黄金比例，那么这个构图通常看起来更加和谐和吸引人。

```latex
\phi = \frac{1 + \sqrt{5}}{2} \approx 1.618
```

在实际应用中，摄影师可以使用这一比例来确定图像中元素的放置位置，如将重要的元素放置在画面的黄金分割线上，以增强视觉吸引力。

##### 2. 对数螺旋（Logarithmic Spiral）

对数螺旋是一种无限增长的曲线，其每一圈的长度按比例增加。在摄影构图中，对数螺旋常用于创建动态和自然的构图。对数螺旋的极坐标方程为：

\[ r = a \cdot e^{b\theta} \]

其中，\( a \) 和 \( b \) 是常数。这个方程描述了随着角度 \( \theta \) 的增加，半径 \( r \) 按指数规律增长。

```latex
r = a \cdot e^{b\theta}
```

在摄影中，对数螺旋可以用来引导观众的视线，如用于表现植物的螺旋生长、星轨的旋转等。通过将关键元素放置在对数螺旋上，摄影师可以创造出动态且富有层次感的构图。

##### 3. 景深公式（Depth of Field Formula）

景深是摄影中的一个重要概念，它决定了图像中哪些区域是清晰的。景深公式帮助摄影师计算在不同参数下图像的清晰范围。基本的景深公式为：

\[ \text{DOF} = \frac{f \cdot D}{N} \]

其中，\( f \) 是镜头焦距，\( D \) 是物距（拍摄对象到镜头的距离），\( N \) 是镜头的数值光圈（例如f/2.8）。这个公式表明，焦距、物距和光圈大小共同决定了景深。

```latex
\text{DOF} = \frac{f \cdot D}{N}
```

摄影师可以使用这个公式来调整参数，以达到所需的景深效果。例如，为了获得更大的景深，摄影师可以选择较小的光圈（较大的数值光圈）和较远的物距。

##### 4. 三角形法则（Triangle Rule）

在摄影构图中，三角形法则是一种常用的构图技巧，它通过在图像中创建多个三角形来增强视觉稳定性。三角形可以是正三角形、等腰三角形或任意三角形。每个三角形的一边可以是一个边缘，另外两边可以是线条或物体。

```latex
\text{如果} \triangle ABC \text{是正三角形，则} AB \text{、} BC \text{和} AC \text{是相互平衡的。}
```

三角形法则有助于平衡图像，使观众的视线自然流动，增加视觉兴趣点。

##### 5. 比例分割（Proportional Division）

比例分割是一种通过数学比例来分割画面的方法，常见的比例包括黄金比例和黄金分割。通过将画面按比例分割，摄影师可以确定关键元素的位置，以实现和谐和吸引人的构图。

```latex
\text{例如，将画面分成三部分，按照黄金比例分割：} \frac{1}{2} : \frac{1}{3} : \frac{1}{6}
```

这种分割方法可以帮助摄影师在画面中安排多个元素，确保它们之间的关系和比例看起来自然且协调。

通过上述数学模型和公式，摄影师可以在构图中运用数学原理，创造出具有吸引力和视觉冲击力的作品。这些工具不仅帮助提高构图技巧，也加深了对摄影艺术的理解。

import cv2
from PIL import Image, ImageDraw

def calculate_depth_of_field(focus_distance, aperture, lens_focal_length):
    circle_of_confusion = 0.03
    hyperfocal_distance = (lens_focal_length ** 2) / (aperture * circle_of_confusion)

def golden_ratio_partition(length):
    short_segment = length * 0.382
    long_segment = length - short_segment
    return short_segment, long_segment

def draw_logarithmic_spiral(image, center, angle, radius):
    points = []
    for i in range(100):
        angle = angle + 1.27324
        radius = radius * 1.618
        x = int(center[0] + radius * np.cos(angle))
        y = int(center[1] + radius * np.sin(angle))
        points.append((x, y))
    image = cv2.polylines(image, [np.array(points)], True, (0, 255, 0), 2)
    return image

def color_correction(image, target_color):
    corrected_image = []
    for pixel in image:
        corrected_pixel = [
            int(pixel[0] * target_color[0] / 255),
            int(pixel[1] * target_color[1] / 255),
            int(pixel[2] * target_color[2] / 255)
        ]
        corrected_image.append(corrected_pixel)
    return corrected_image

def main():

    image = cv2.imread('image.jpg')

    # 设置镜头参数
    lens_focal_length = 50
    focus_distance = 1
    aperture = 2.8

    # 计算景深
    near_limit, far_limit = calculate_depth_of_field(focus_distance, aperture, lens_focal_length)
    print(f"Near Limit: {near_limit}m, Far Limit: {far_limit}m")

    # 应用黄金比例分割
    image = cv2.resize(image, (1000, 1000))
    short_segment, long_segment = golden_ratio_partition(image.shape[0])
    cv2.rectangle(image, (0, short_segment), (image.shape[1], long_segment), (255, 0, 0), 2)

    # 绘制对数螺旋
    center = (image.shape[1] // 2, image.shape[0] // 2)
    angle = np.pi / 4
    radius = 50
    image = draw_logarithmic_spiral(image, center, angle, radius)

    # 色彩校正
    target_color = (255, 255, 255)  # 目标白色
    image = cv2.cvtColor(np.array(image), cv2.COLOR_RGB2BGR)
    corrected_image = color_correction(image, target_color)
    image = cv2.cvtColor(np.array(corrected_image), cv2.COLOR_BGR2RGB)

    # 显示图像
    cv2.imshow('Photography Composition Tool', image)
    cv2.waitKey(0)
    cv2.destroyAllWindows()

if __name__ == "__main__":
    main()
