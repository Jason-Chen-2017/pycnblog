## 第2章 数学与音乐的基本概念

### 2.1 数学的基本概念

数学是一种研究数量、结构、变化和空间的学科。它不仅是一种工具，更是一种思维方式。数学的基本概念包括：

- 数：数是数学的核心概念，它表示物体的数量或顺序。常见的数有自然数、整数、有理数、无理数等。
- 几何：几何是研究形状、大小和位置关系的学科。常见的几何概念有点、线、面、体等。
- 代数：代数是研究符号和方程的学科。通过代数，我们可以将实际问题转化为数学问题，然后求解。
- 微积分：微积分是研究函数变化的学科。它包括微分和积分两部分，分别研究函数在某一点的变化率和整个函数的变化。

### 2.2 音乐的基本概念

音乐是一种通过声音来表达情感和思想的艺术。音乐的基本概念包括：

- 音调：音调是指声音的高低，由频率决定。高频率的声音音调高，低频率的声音音调低。
- 音色：音色是指声音的品质和特色，由声音的波形决定。不同的乐器或声音源有不同的音色。
- 节奏：节奏是指音乐中音的长短、强弱和时间的关系。节奏是音乐的基本元素之一。
- 和声：和声是指多个音同时发声，形成和谐的声音。和声是音乐创作的重要手段之一。
- 旋律：旋律是指音乐中音的高低变化，形成一条声音的轨迹。旋律是音乐创作的核心。

### 2.3 数学与音乐的联系

数学与音乐之间的联系可以从多个角度来理解：

- 音程：音程是指两个音之间的距离，可以用数学中的比例来描述。例如，纯五度音程的比例是3:2。
- 音律：音律是指音高的标准，可以用数学中的等比数列来描述。例如，十二平均律就是一个等比数列。
- 和声：和声是指多个音同时发声，可以看作是数学中的复数。例如，一个和弦可以看作是三个复数的和。
- 旋律：旋律可以用数学中的函数来描述。例如，一个旋律可以看作是时间函数。

```python
import matplotlib.pyplot as plt
import numpy as np

def mandelbrot(c, max_iter):
    z = 0
    n = 0
    while abs(z) <= 2 and n < max_iter:
        z = z*z + c
        n += 1
    return n

width, height = 800, 600
max_iter = 100

x = np.linspace(-2, 1, width)
y = np.linspace(-1.5, 1.5, height)
X, Y = np.meshgrid(x, y)
Z = X + 1j * Y

c = Z
M = mandelbrot(c, max_iter)

fig, ax = plt.subplots(figsize=(10, 7))
img = ax.imshow(M, cmap='gray', extent=[X.min(), X.max(), Y.min(), Y.max()])
fig.colorbar(img)
plt.show()
```

输出结果是一个漂亮的分形图案。
