### 2.1 宇宙网络的基本数学模型

宇宙网络的数学模型通常基于图论和拓扑学的基本概念。在图论模型中，宇宙网络被视为一个图，其中节点代表天体或物理现象，边代表它们之间的信息传递路径。这种模型提供了描述宇宙网络结构的基本框架，使我们能够从宏观上分析网络的特性。

#### 图论模型

图论模型中的关键概念包括：

- **节点（Vertex）**：代表宇宙中的天体或物理现象。
- **边（Edge）**：代表天体或现象之间的信息传递路径。
- **路径（Path）**：连接两个节点的边的序列。
- **连通性（Connectivity）**：网络中任意两个节点是否可以通过一条路径相互连接。

在图论模型中，宇宙网络可以表示为一个无向图或有权图，具体取决于信息传递路径的性质。无向图表示信息传递是双向的，有权图则表示每条路径都有一定的权重，如传输时间、能量消耗等。

#### 拓扑模型

拓扑模型从更抽象的角度描述宇宙网络的性质，强调网络的连通性和结构特性。在拓扑模型中，宇宙网络被视为一个拓扑空间，其中节点和边具有拓扑性质，如连通分量、路径连通性等。

拓扑模型中的关键概念包括：

- **连通分量（Connected Component）**：网络中无法通过断开任何一条边而分离的节点集合。
- **拓扑结构（Topology）**：网络的连通性和结构特性，不依赖于节点的具体位置和边的具体长度。
- **路径连通性（Path Connectivity）**：网络中任意两个节点是否存在一条连续的路径。

拓扑模型在描述宇宙网络的结构和特性方面具有优势，因为它们不受具体测量参数的限制，能够提供更加抽象和通用的描述。

### 2.2 宇宙网络的数学公式与算法

宇宙网络的数学公式和算法用于描述和优化网络的性质。以下是一些常见的数学公式和算法：

#### 图论中的数学公式

- **度（Degree）**：节点拥有的边数，表示节点的连接程度。
  \[ \text{degree}(v) = \sum_{u \in N(v)} w(u, v) \]
  其中，\( N(v) \) 是与节点 \( v \) 相连的所有节点的集合，\( w(u, v) \) 是边 \( (u, v) \) 的权重。

- **路径长度（Path Length）**：两个节点之间的最短路径长度。
  \[ \text{path\_length}(v, w) = \min_{p} \sum_{u, v \in p} w(u, v) \]
  其中，\( p \) 是从节点 \( v \) 到节点 \( w \) 的最短路径。

#### 常见算法

- **最短路径算法**：用于计算两个节点之间的最短路径。
  - **Dijkstra算法**：基于贪心策略，逐步扩展最短路径。
    \[ \text{Dijkstra}(G, s) \]
    初始时，所有节点的最短路径长度设为无穷大，源节点 \( s \) 的最短路径长度设为 0。算法通过迭代更新每个节点的最短路径长度，直到所有节点的最短路径长度都被计算出来。
  
  - **Floyd-Warshall算法**：用于计算所有节点对之间的最短路径。

#### 7.2 宇宙网络的核心算法伪代码

以下是一个典型的网络优化算法——Dijkstra算法的伪代码，该算法用于计算单源最短路径：

```python
Dijkstra(G, s):
    for each vertex v in G:
        dist[v] ← ∞
        prev[v] ← undefined
    dist[s] ← 0
    in_queue[s] ← true
    while in_queue contains at least one vertex:
        u ← vertex in in_queue with smallest dist[u]
        remove u from in_queue
        for each edge (u, v) in G:
            if dist[u] + weight(u, v) < dist[v]:
                dist[v] ← dist[u] + weight(u, v)
                prev[v] ← u
    return dist, prev
```

其中，`G` 是网络图，`s` 是源点，`dist[v]` 是从源点 `s` 到节点 `v` 的最短路径长度，`prev[v]` 是从源点 `s` 到节点 `v` 的最短路径上的前一个节点，`in_queue` 是一个布尔数组，表示节点是否在队列中。

以信息传播算法中的扩散算法为例，该算法通过多跳传播实现信息的快速扩散。以下是一个简化的扩散算法的伪代码：

```python
Diffusion(G, s, target):
    message_queue ← empty queue
    message_queue.enqueue((s, "initial message"))
    while message_queue is not empty:
        (current_node, message) ← message_queue.dequeue()
        if current_node == target:
            return message
        for each neighbor v of current_node:
            if v is not visited:
                message_queue.enqueue((v, message))
                mark v as visited
    return "message not found"
```

其中，`G` 是网络图，`s` 是源点，`target` 是目标节点，`message_queue` 是消息队列，`message` 是传递的消息。
