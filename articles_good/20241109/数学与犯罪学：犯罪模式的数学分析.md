#### 2.1 概率论基础

概率论是数学中用于量化不确定事件发生可能性的分支，在犯罪模式分析中具有重要的应用价值。

##### 2.1.1 事件与概率

事件是随机实验的一个结果或结果的集合。在犯罪模式分析中，事件可以是“某地区某一天发生盗窃案件”，或者“某嫌疑人涉嫌某项犯罪”。概率是指事件发生的可能性，通常用0到1之间的数字表示。例如，如果某个地区在过去一年中平均每天发生一起盗窃案件，那么在该地区某一特定天发生盗窃案件的概率可以近似为1/365。

##### 2.1.2 条件概率与贝叶斯定理

条件概率是指在某个事件已经发生的条件下，另一个事件发生的概率。例如，如果已知某嫌疑人有犯罪前科，那么他再次犯罪的条件概率会相对较高。贝叶斯定理是一个用于根据先验概率和条件概率计算后验概率的重要工具。其公式为：

$$ P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)} $$

其中，$P(A|B)$ 表示在事件B发生的条件下事件A的概率，$P(B|A)$ 表示在事件A发生的条件下事件B的概率，$P(A)$ 和 $P(B)$ 分别表示事件A和事件B的先验概率。

在犯罪模式分析中，贝叶斯定理可以帮助我们通过已有的证据（例如犯罪现场的特征）推断嫌疑人的嫌疑程度。

3. **回归分析**：用于预测或解释变量之间的关系。例如，通过回归分析，我们可以预测某一地区的犯罪率。

4. **聚类分析**：将相似的数据点归为一类，用于发现数据中的隐含结构。例如，通过聚类分析，我们可以识别犯罪团伙。

```
discriminant_analysis(
    X: array,
    y: array
):
    # 输入参数：特征矩阵、标签
    # 输出：判别函数
    
    # 计算均值和协方差矩阵
    mean = X.mean(axis=0)
    covariance = (X - mean).T @ (X - mean) / (X.shape[0] - 1)
```

聚类分析是一种用于识别相似数据点的方法，它通过将数据点分为若干类别，使同一类别内的数据点尽可能相似，不同类别内的数据点尽可能不同。在犯罪模式分析中，聚类分析可以用于识别潜在的犯罪团伙。

**伪代码示例：**

```
kmeans_clustering(
    X: array,
    k: int
):
    # 输入参数：特征矩阵、类别数
    # 输出：聚类结果
    
    # 初始化聚类中心
    centroids = X[np.random.choice(X.shape[0], k, replace=False)]
    
    # 聚类迭代
    while True:
        # 计算每个数据点到聚类中心的距离
        distances = np.linalg.norm(X - centroids, axis=1)
        
        # 分配类别
        labels = np.argmin(distances, axis=1)
        
        # 更新聚类中心
        new_centroids = np.array([X[labels == i].mean(axis=0) for i in range(k)])
        
        # 检查收敛
        if np.linalg.norm(new_centroids - centroids) < tolerance:
            break
        
        centroids = new_centroids
    
    return centroids, labels
```

```python
import pandas as pd
```
```python
from sklearn.cluster import KMeans
```

```python
import pandas as pd
```
```python
from sklearn.cluster import KMeans

# 加载数据
data = pd.read_csv('crime_data.csv')

# 特征分离
X = data[['region', 'crime_frequency']]

# 使用K-Means聚类分析
kmeans = KMeans(n_clusters=3, random_state=42)
clusters = kmeans.fit_predict(X)

# 添加聚类结果到数据集
data['cluster'] = clusters

# 绘制聚类结果
plt.scatter(data['region'], data['crime_frequency'], c=data['cluster'], cmap='viridis')
plt.xlabel('Region')
plt.ylabel('Crime Frequency')
plt.title('Crime Hotspots Clustering')
plt.show()
```
