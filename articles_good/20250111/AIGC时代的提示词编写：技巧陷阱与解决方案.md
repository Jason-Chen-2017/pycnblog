#### 1.1 问题背景

人工智能（AI）技术自诞生以来，经历了数个重要的发展阶段。从最初的符号主义人工智能（Symbolic AI），到基于规则的专家系统（Expert Systems），再到基于统计机器学习的深度学习（Deep Learning），AI技术不断演进，逐步实现了从简单的任务自动化到复杂问题的求解能力。

在AI技术不断发展的同时，生成式AI（Generative AI）也逐渐崭露头角。生成式AI的核心目标是能够根据给定的条件或提示生成新的内容，如文本、图像、音乐等。而自动生成内容（Auto Generated Content，简称AIGC）则是在生成式AI的基础上，结合了自动化和智能化的特点，使得生成内容的过程更加高效和精准。

AIGC的应用场景十分广泛，涵盖了内容创作、数据分析、智能客服、医疗诊断等多个领域。例如，在内容创作领域，AIGC可以自动生成新闻文章、博客文章、广告文案等；在数据分析领域，AIGC可以帮助快速生成数据可视化报告；在智能客服领域，AIGC可以自动回答用户的问题，提供个性化的服务；在医疗诊断领域，AIGC可以通过分析大量的医疗数据，辅助医生进行疾病诊断。

随着AIGC技术的不断成熟和应用范围的扩大，其在社会生产中的地位和作用也越来越重要。AIGC不仅提高了生产效率，降低了人力成本，还为创新和创意提供了新的可能性。然而，AIGC技术的广泛应用也带来了一系列挑战，如数据隐私、内容真实性、道德伦理等问题。

### 提示词编写的原则与方法

#### 2.1 提示词编写的基本原则

编写高质量的提示词是AIGC系统成功的关键。以下是一些提示词编写的基本原则，这些原则将指导我们如何创造清晰、精准且有效的提示词。

1. **清晰明了**：提示词应简洁明了，避免使用复杂、模糊的语言。这有助于确保生成模型能够准确理解用户的需求。

2. **精准准确**：提示词应精确描述生成内容的要求，避免任何形式的歧义或模糊。这有助于减少误解，提高生成内容的准确性和可靠性。

3. **简洁有效**：在满足上述两个原则的基础上，提示词还应尽量简洁。避免冗长的描述，确保提示词能够有效地传达所需信息。

#### 2.2 提示词编写的具体方法

编写高质量提示词不仅需要遵循基本原则，还需要采用一些具体的方法和技巧。以下是一些常用的方法：

1. **提取关键信息**：在编写提示词时，首先要识别并提取关键信息。这些关键信息应包括生成内容的核心要素，如主题、目标、限制条件等。

2. **使用明确的指令**：提示词应包含明确的指令，指导生成模型如何生成内容。例如，使用动词来指示生成动作，如“生成一篇关于人工智能的新闻报道”。

3. **调整语言风格**：根据生成内容的目标受众和场景，调整提示词的语言风格。例如，在编写技术文档时，应使用专业术语和严谨的语言；而在编写营销文案时，则可以更生动有趣。

4. **利用具体例子**：在提示词中提供具体例子可以帮助生成模型更好地理解需求。例如，“生成一篇关于深度学习的博客文章，包含以下三个部分：背景介绍、技术原理和应用案例”。

#### 3.1 提示词的基本语法

提示词的语法结构对于AIGC系统的输出效果具有直接影响。了解并掌握提示词的基本语法规则，有助于编写出更加清晰、准确且有效的提示词。

1. **句子结构**：

   提示词通常由一个或多个句子组成。每个句子应包含主语、谓语和宾语。以下是一个简单的句子结构示例：

   - **主语**：谁在执行动作
   - **谓语**：执行的动作
   - **宾语**：动作的对象

   示例：“生成一篇关于深度学习的新闻报道。”

   在这个例子中，“生成”是谓语，“一篇关于深度学习的新闻报道”是宾语。

2. **标点符号的使用**：

   提示词中的标点符号对于句子的完整性和可读性至关重要。以下是一些常用的标点符号及其用法：

   - **句号（.）**：用于结束句子。
   - **逗号（，）**：用于分隔并列的短语或句子。
   - **冒号（：）**：用于引出说明或列举。
   - **引号（“”或'”）**：用于引用直接引语或特定名词。

   示例：“生成一篇关于深度学习的新闻报道，包括背景介绍、技术原理和应用案例。”

3. **常见语法错误与修正**：

   在编写提示词时，常见的语法错误包括主谓不一致、缺少主语或谓语、用词不当等。以下是一些常见的语法错误及修正示例：

   - **错误**：“生成一篇新闻报道，深度学习。”
   - **修正**：“生成一篇关于深度学习的新闻报道。”

   - **错误**：“生成报道，深度学习。”
   - **修正**：“生成一篇关于深度学习的新闻报道。”

   通过注意这些基本语法规则，我们可以确保提示词的结构合理、语言流畅，从而提高生成内容的准确性和效果。

#### 3.2 提示词的复杂性分析

提示词的复杂性是指提示词在语义、结构和长度等方面的难度。分析提示词的复杂性有助于评估生成模型处理提示词的能力，并为优化提示词提供依据。

1. **提示词的长度**：

   提示词的长度对生成模型的处理能力有一定影响。通常，较长的提示词可能包含更多详细信息，有助于生成更精确的内容。然而，过长的提示词也可能导致模型处理困难，影响生成效率。因此，应保持提示词的适度长度。

   - **建议**：提示词的长度应在20-50个单词之间，具体长度应根据生成内容的复杂性和目标进行调整。

2. **提示词的语义复杂性**：

   提示词的语义复杂性取决于提示词中所包含的概念数量及其关系。语义复杂性较高的提示词可能涉及多个抽象层次的概念，对生成模型的要求更高。

   - **建议**：避免使用过于复杂或抽象的术语，尽量使用具体、明确的概念，以便于生成模型理解。

3. **难易程度评估**：

#### 4.1 语言理解偏差

语言理解偏差是提示词编写中常见的陷阱之一，主要表现在以下方面：

1. **歧义性**：

   - **问题**：歧义性提示词可能导致生成模型生成不符合预期的内容。
   - **示例**：提示词“生成一篇关于深度学习的新闻报道”，这里的“关于”可以理解为“涉及”或“针对”，可能导致不同的生成结果。
   - **应对策略**：避免使用歧义性词汇，明确表达意图。例如，将“关于”改为“针对”或“涉及”。

2. **模糊性**：

   - **问题**：模糊性提示词可能使生成模型难以理解需求，导致生成内容不准确或不符合要求。
   - **示例**：提示词“生成一篇有趣的文章”，这里的“有趣”是一个主观评价，没有明确的衡量标准。
   - **应对策略**：提供具体、明确的评价标准或例子，帮助生成模型理解需求。例如，改为“生成一篇以幽默风格介绍深度学习技术的文章”。

3. **情感色彩**：

   - **问题**：带有强烈情感色彩的提示词可能影响生成内容的客观性和准确性。
   - **示例**：提示词“生成一篇愤怒的批评文章”，这可能导致生成内容带有负面情绪。
   - **应对策略**：避免使用带有强烈情感色彩的词汇，保持客观中立。例如，改为“生成一篇对深度学习技术进行客观评价的文章”。

#### 4.2 提示词的模糊性

模糊性提示词是提示词编写中的另一个常见问题，主要表现在以下几个方面：

1. **不具体**：

   - **问题**：不具体的提示词可能导致生成模型无法准确理解需求，生成的内容缺乏针对性。
   - **示例**：提示词“生成一篇关于人工智能的应用”，这个提示词过于宽泛，没有明确的应用场景和目标。
   - **应对策略**：提供更具体的信息，明确生成内容的目标和应用场景。例如，改为“生成一篇关于人工智能在医疗诊断中的应用的文章”。

2. **不明确**：

   - **问题**：不明确的提示词可能使生成模型难以生成符合预期的内容。
   - **示例**：提示词“生成一篇优秀的报告”，这里的“优秀”没有具体的标准。
   - **应对策略**：提供具体的标准或指标，明确评价标准。例如，改为“生成一篇包含以下三个部分的优秀报告：背景介绍、技术原理和应用案例”。

3. **冗余**：

   - **问题**：冗余的提示词可能导致生成模型混淆，生成内容重复或不相关。
   - **示例**：提示词“生成一篇关于深度学习的重要论文，深度学习是当前人工智能领域的热点”，这里的“深度学习”重复了两次，可能导致生成内容重复。
   - **应对策略**：删除冗余信息，确保提示词简洁明了。例如，改为“生成一篇关于深度学习在人工智能应用中的重要论文”。

通过识别和解决这些语言理解偏差和模糊性问题，我们可以提高提示词的质量，确保生成模型能够准确理解需求，生成符合预期的内容。

#### 4.3 提示词的过于具体或抽象

提示词的过于具体或抽象是提示词编写中的另外两个常见问题，以下是对这些问题及其应对策略的详细分析：

1. **过于具体**：

   - **问题**：过于具体的提示词可能导致生成模型无法灵活处理，生成的内容可能过于局限。
   - **示例**：提示词“生成一篇关于深度学习在医疗诊断中应用的具体案例，如基于卷积神经网络的心电图分析”，这个提示词指定了具体的案例和应用场景，限制了生成模型的创造性。
   - **应对策略**：提供一般性的指导，而不是过于具体的要求。例如，改为“生成一篇关于深度学习在医疗诊断中的应用的文章，可以包括心电图分析等案例”。

2. **过于抽象**：

   - **问题**：过于抽象的提示词可能使生成模型难以理解，生成的内容缺乏针对性。
   - **示例**：提示词“生成一篇关于人工智能技术的前沿研究的综述”，这个提示词过于抽象，没有具体的方向和范围。
   - **应对策略**：提供具体的目标和范围，以便生成模型能够更好地理解和生成内容。例如，改为“生成一篇关于深度学习技术在图像识别领域的前沿研究的综述”。

通过避免提示词过于具体或抽象，我们可以确保提示词既具有指导性，又具有一定的灵活性，从而使生成模型能够更有效地生成所需的内容。

**附录B：算法原理讲解**

在本附录中，我们将探讨AIGC中常用的生成模型之一——生成对抗网络（GAN）的基本原理。

#### 算法原理

生成对抗网络（GAN）由两部分组成：生成器（Generator）和判别器（Discriminator）。生成器的任务是生成逼真的数据，而判别器的任务是区分生成的数据与真实数据。

1. **生成器（Generator）**：

   - **功能**：生成器通过学习真实数据的分布，生成新的数据。
   - **训练过程**：生成器不断尝试生成更逼真的数据，以欺骗判别器。

2. **判别器（Discriminator）**：

   - **功能**：判别器的任务是判断输入数据是真实数据还是生成器生成的数据。
   - **训练过程**：判别器通过学习真实数据和生成数据的特征，提高对数据的辨别能力。

#### 算法流程

GAN的训练过程通常包括以下几个步骤：

1. **初始化**：初始化生成器和判别器的权重。
2. **生成器生成数据**：生成器根据随机噪声生成数据。
3. **判别器评估**：判别器对生成的数据和真实数据进行评估。
4. **更新权重**：根据判别器的评估结果，更新生成器和判别器的权重。
5. **迭代**：重复上述步骤，直到生成器生成足够逼真的数据。

#### 数学模型和公式

以下是一个简化的GAN的数学模型：

$$
\begin{aligned}
&\text{生成器：} G(z) = \text{生成虚假数据} \\
&\text{判别器：} D(x) = P(\text{真实数据}) \quad \text{和} \quad D(G(z)) = P(\text{生成数据}) \\
&\text{损失函数：} L(G, D) = -\frac{1}{2} \left[ \mathbb{E}_{x \sim p_{data}(x)}[\log D(x)] + \mathbb{E}_{z \sim p_z(z)}[\log (1 - D(G(z)))] \right]
\end{aligned}
$$

在上述公式中，$G(z)$表示生成器生成的数据，$D(x)$和$D(G(z))$分别表示判别器对真实数据和生成数据的判断概率，$p_{data}(x)$和$p_z(z)$分别是真实数据和噪声分布。

#### 举例说明

假设我们使用GAN生成手写数字图像。以下是一个简化的过程：

1. **初始化**：随机初始化生成器和判别器的权重。
2. **生成器生成数据**：生成器根据随机噪声生成一组手写数字图像。
3. **判别器评估**：判别器对生成的手写数字图像和真实的手写数字图像进行评估。
4. **更新权重**：根据判别器的评估结果，更新生成器和判别器的权重。
5. **迭代**：重复上述步骤，直到生成器能够生成足够逼真的手写数字图像。

通过这个过程，生成器逐渐学会生成更逼真的手写数字图像，而判别器则学会更准确地判断图像的来源。

#### 系统核心实现源代码

以下是一个简化的AIGC系统的核心实现源代码，包括数据预处理、模型训练和生成提示词等功能：

```python
import jax
import jax.numpy as np
from transformers import AutoTokenizer, AutoModelForCausalLM
from typing import List

# 加载预训练模型和Tokenizer
model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# 数据预处理
def preprocess_data(user_data: List[str]) -> str:
    """
    预处理用户数据，生成提示词。
    :param user_data: 用户数据列表。
    :return: 预处理后的提示词。
    """
    prompt = " ".join(user_data)
    return prompt

# 模型训练
def train_model(model: AutoModelForCausalLM, prompt: str, num_epochs: int = 3) -> AutoModelForCausalLM:
    """
    训练AIGC模型。
    :param model: AIGC模型。
    :param prompt: 提示词。
    :param num_epochs: 训练轮数。
    :return: 训练后的AIGC模型。
    """
    input_ids = tokenizer.encode(prompt, return_tensors="jax")
    for epoch in range(num_epochs):
        outputs = model(input_ids)
        loss = outputs.loss
        grads = jax.grad(loss)(model.params)
        updates = jax.optimizers.sgd(learning_rate=0.01)(grads)
        model = jax.tree_map(lambda p, u: p - u, model.params, updates)
    return model

# 生成提示词
def generate_prompt(prompt: str, max_length: int = 100) -> str:
    """
    生成新的提示词。
    :param prompt: 原提示词。
    :param max_length: 生成的提示词最大长度。
    :return: 新的提示词。
    """
    input_ids = tokenizer.encode(prompt, return_tensors="jax")
    output_sequence = model.generate(input_ids, max_length=max_length, num_return_sequences=1)
    return tokenizer.decode(output_sequence[0], skip_special_tokens=True)

# 主函数
def main():
    # 用户数据示例
    user_data = ["我喜欢阅读科幻小说", "我最近在研究深度学习", "我对人工智能的未来充满好奇"]

    # 预处理数据
    prompt = preprocess_data(user_data)

    # 训练模型
    trained_model = train_model(model, prompt)

    # 生成新的提示词
    new_prompt = generate_prompt(prompt)

    print("原始提示词：", prompt)
    print("新的提示词：", new_prompt)

if __name__ == "__main__":
    main()
```

在上述代码中，我们首先加载了预训练的GPT-2模型和相应的Tokenizer。接着，定义了数据预处理函数`preprocess_data`，用于将用户数据列表转换为提示词。`train_model`函数用于训练AIGC模型，通过梯度下降优化模型参数。最后，`generate_prompt`函数使用训练后的模型生成新的提示词。

#### 代码应用解读与分析

在代码中，我们首先定义了数据预处理、模型训练和生成提示词的功能。以下是对关键步骤的解读和分析：

1. **数据预处理**：

   - `preprocess_data`函数将用户数据列表转换为单个字符串，形成初始的提示词。这种方法可以确保所有用户数据都被统一处理。

2. **模型训练**：

   - `train_model`函数通过循环进行多次训练，使用JAX的自动微分功能优化模型参数。我们使用的是SGD优化器，学习率设置为0.01。训练轮数默认为3，可以根据需要进行调整。

3. **生成提示词**：

   - `generate_prompt`函数使用训练后的模型生成新的提示词。这里，我们设置生成的提示词最大长度为100，可以生成一个简短但完整的提示词。`num_return_sequences`参数设置为1，表示只生成一个提示词。

7. **迭代优化**：编写提示词后，应通过测试和用户反馈不断优化。每次迭代都是一次改进机会，可以帮助我们发现并解决潜在问题，提高生成内容的质量。

8. **利用专业知识和工具**：结合专业知识和工具可以编写出更高质量的提示词。例如，利用领域专家的意见、使用专业的工具和平台，如GPT-3、BERT等，可以帮助提高生成内容的专业性和准确性。

#### 示例2：BERT模型分类

以下是一个使用BERT模型进行文本分类的Python代码示例：

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification
from torch.optim import AdamW
from torch.utils.data import DataLoader, TensorDataset

# 加载预训练的BERT模型
tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
model = AutoModelForSequenceClassification.from_pretrained("bert-base-uncased", num_labels=2)

# 输入文本和标签
texts = ["这是一个正面的评论。", "这是一个负面的评论。"]
labels = [0, 1]  # 0表示正面，1表示负面

# 将文本编码为模型可理解的输入
input_ids = tokenizer.encode_plus(texts, add_special_tokens=True, return_tensors="pt")
input_ids = input_ids["input_ids"]
attention_mask = input_ids.new_ones(input_ids.shape)

# 创建数据集和数据加载器
dataset = TensorDataset(input_ids, attention_mask, torch.tensor(labels))
dataloader = DataLoader(dataset, batch_size=2)

# 定义优化器和损失函数
optimizer = AdamW(model.parameters(), lr=1e-5)
criterion = torch.nn.CrossEntropyLoss()

# 训练模型
model.train()
for epoch in range(3):
    for batch in dataloader:
        inputs = {"input_ids": batch[0], "attention_mask": batch[1]}
        labels = batch[2]
        optimizer.zero_grad()
        outputs = model(**inputs)
        loss = criterion(outputs.logits, labels)
        loss.backward()
        optimizer.step()
        print(f"Epoch: {epoch}, Loss: {loss.item()}")

# 评估模型
model.eval()
with torch.no_grad():
    for batch in dataloader:
        inputs = {"input_ids": batch[0], "attention_mask": batch[1]}
        labels = batch[2]
        outputs = model(**inputs)
        _, predicted = torch.max(outputs.logits, dim=1)
        print(f"Predicted Labels: {predicted.tolist()}, True Labels: {labels.tolist()}")
```

在这个示例中，我们首先加载了BERT模型和Tokenizer。然后，我们提供了文本和标签，并将其编码为模型可理解的输入。接下来，我们创建了一个数据集和数据加载器，并使用AdamW优化器和交叉熵损失函数训练模型。最后，我们评估模型的性能，并输出预测结果。

#### 示例3：生成对抗网络（GAN）

以下是一个简单的生成对抗网络（GAN）示例，用于生成手写数字图像：

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
from torchvision.utils import save_image

# 设置设备
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 数据集和加载器
transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))])
train_dataset = datasets.MNIST(root='./data', train=True, download=True, transform=transform)
dataloader = DataLoader(train_dataset, batch_size=64, shuffle=True)

# 生成器模型
class Generator(nn.Module):
    def __init__(self):
        super(Generator, self).__init__()
        self.main = nn.Sequential(
            nn.ConvTranspose2d(100, 256, 4, 1, 0, bias=False),
            nn.BatchNorm2d(256),
            nn.ReLU(True),
            nn.ConvTranspose2d(256, 128, 4, 2, 1, bias=False),
            nn.BatchNorm2d(128),
            nn.ReLU(True),
            nn.ConvTranspose2d(128, 64, 4, 2, 1, bias=False),
            nn.BatchNorm2d(64),
            nn.ReLU(True),
            nn.ConvTranspose2d(64, 1, 4, 2, 1, bias=False),
            nn.Tanh()
        )

    def forward(self, input):
        return self.main(input)

# 判别器模型
class Discriminator(nn.Module):
    def __init__(self):
        super(Discriminator, self).__init__()
        self.main = nn.Sequential(
            nn.Conv2d(1, 16, 4, 2, 1, bias=False),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(16, 32, 4, 2, 1, bias=False),
            nn.BatchNorm2d(32),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(32, 64, 4, 2, 1, bias=False),
            nn.BatchNorm2d(64),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(64, 1, 4, 1, 0, bias=False),
            nn.Sigmoid()
        )

    def forward(self, input):
        return self.main(input)

# 实例化模型
netG = Generator().to(device)
netD = Discriminator().to(device)

# 损失函数和优化器
criterion = nn.BCELoss()
optimizerD = optim.Adam(netD.parameters(), lr=0.0002, betas=(0.5, 0.999))
optimizerG = optim.Adam(netG.parameters(), lr=0.0002, betas=(0.5, 0.999))

# 训练模型
for epoch in range(20):
    for i, data in enumerate(dataloader, 0):
        # 更新判别器
        netD.zero_grad()
        real_img = data[0].to(device)
        batch_size = real_img.size(0)
        label_real = torch.full((batch_size,), 1, device=device)
        output = netD(real_img)
        errD_real = criterion(output, label_real)
        errD_real.backward()

        noise = torch.randn(batch_size, 1, 28, 28, device=device)
        fake_img = netG(noise)
        label_fake = torch.full((batch_size,), 0, device=device)
        output = netD(fake_img.detach())
        errD_fake = criterion(output, label_fake)
        errD_fake.backward()
        optimizerD.step()

        # 更新生成器
        netG.zero_grad()
        label_fake = torch.full((batch_size,), 1, device=device)
        output = netD(fake_img)
        errG = criterion(output, label_fake)
        errG.backward()
        optimizerG.step()

        # 记录训练信息
        if i % 100 == 0:
            print(f'[{epoch}/{20}][{i}/{len(dataloader)}] Loss_D: {errD_real + errD_fake:.4f} Loss_G: {errG:.4f}')

    # 保存生成图像
    with torch.no_grad():
        fake_img = netG(noise).detach().cpu()
    img = fake_img[:5]
    save_image(fake_img, f'fake_samples_epoch_{epoch}.png', nrow=5, normalize=True)
```

在这个GAN示例中，我们首先设置了设备、数据集和加载器。然后，我们定义了生成器和判别器模型，并使用了BCE损失函数和Adam优化器。接下来，我们训练模型，通过交替更新生成器和判别器，生成逼真的手写数字图像。

**1. 生成对抗网络（GAN）的损失函数**

$$
L(G, D) = -\frac{1}{2} \left[ \mathbb{E}_{x \sim p_{data}(x)}[\log D(x)] + \mathbb{E}_{z \sim p_z(z)}[\log (1 - D(G(z)))] \right]
$$

其中，$G(z)$为生成器生成的数据，$D(x)$为判别器对真实数据的判断概率，$D(G(z))$为判别器对生成数据的判断概率，$p_{data}(x)$为真实数据的分布，$p_z(z)$为噪声分布。

**2. BERT模型的训练过程**

$$
\begin{aligned}
\text{输入：} & \text{输入序列} \\ 
\text{输出：} & \text{预测序列} \\
\text{损失函数：} & L = \frac{1}{N} \sum_{n=1}^{N} \sum_{i=1}^{T_n-1} -\log p(y_i^n | x^n_{1:i})
\end{aligned}
$$

其中，$N$为批量大小，$T_n$为第$n$个输入序列的长度，$y_i^n$为第$i$个时间步的标签，$x^n_{1:i}$为第$n$个输入序列的前$i$个时间步的输入。

$$

\end{aligned}
$$

texts = ["这是一个正面的评论。", "这是一个负面的评论。"]

input_ids = tokenizer.encode_plus(texts, add_special_tokens=True, return_tensors="pt")
input_ids = input_ids["input_ids"]
attention_mask = input_ids.new_ones(input_ids.shape)

# 创建数据集和数据加载器
dataset = TensorDataset(input_ids, attention_mask, torch.tensor(labels))
dataloader = DataLoader(dataset, batch_size=2)

# 定义优化器和损失函数

criterion = torch.nn.CrossEntropyLoss()

# 训练模型
model.train()
for epoch in range(3):
    for batch in dataloader:
        inputs = {"input_ids": batch[0], "attention_mask": batch[1]}
        labels = batch[2]
        optimizer.zero_grad()
        outputs = model(**inputs)
        loss = criterion(outputs.logits, labels)
        loss.backward()
        optimizer.step()
        print(f"Epoch: {epoch}, Loss: {loss.item()}")
