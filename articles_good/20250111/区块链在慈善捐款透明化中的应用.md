#### 2.1 区块链技术概述

区块链技术是一种分布式账本技术，其核心特点包括去中心化、不可篡改性和安全性。区块链由多个区块组成，每个区块包含一定数量的交易记录。这些区块按照时间顺序连接在一起，形成一条连续的链条，因此称为区块链。

区块链的去中心化特性意味着它不需要一个集中的中央机构来管理和验证交易。相反，区块链网络中的所有参与者（节点）都可以验证和记录交易，从而保证了系统的去中心化和去信任化。这意味着，即使某个节点出现问题，整个系统仍然可以正常运行。

不可篡改性是区块链的另一大特点。一旦交易记录被添加到一个区块中，并确认到区块链上，该记录就不可篡改。这种特性确保了区块链上数据的可靠性和透明度，使得捐赠者和受捐方都能清楚地了解捐款的去向和使用情况。

安全性是区块链技术的另一个重要优势。区块链使用加密算法来保护数据的安全和隐私。每个交易记录都被加密，只有拥有密钥的参与者才能解密和验证交易。此外，区块链的分布式特性使得攻击者很难同时攻击多个节点，从而增强了系统的安全性。

智能合约的核心特点包括自动化和不可篡改性。自动化意味着智能合约一旦满足预定的条件，就会自动执行操作，无需人工干预。这种特性使得智能合约非常适合用于自动化金融交易、投票和慈善捐款等场景。不可篡改性则确保了智能合约的代码和状态在区块链上无法被修改，从而保证了交易的可靠性和透明度。

   contract Donation {

   import "@openzeppelin/contracts/utils/Address.sol";
   import "./Donation.sol";

   contract ContractInteraction {
       Donation public donationContract;

       constructor(address _donationContractAddress) {
           donationContract = Donation(_donationContractAddress);
       }

       function donate() external payable {
           donationContract.donate{value: msg.value}();
       }

       function getDonationBalance() external view returns (uint256) {
           return donationContract.getBalance();
       }
