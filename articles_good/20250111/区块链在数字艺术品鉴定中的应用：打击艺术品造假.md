##### 3.4.3 数字签名

数字签名是确保数据来源可靠性和完整性的重要手段。在数字艺术品鉴定中，艺术家和鉴定机构可以使用数字签名对艺术品的信息进行签名，以证明其真实性。

Python代码示例：

```python
from Crypto.PublicKey import RSA
from Crypto.Signature import pkcs1_15
from Crypto.Hash import SHA256

# 生成密钥对
def generate_key_pair():
    key = RSA.generate(2048)
    private_key = key.export_key()
    public_key = key.publickey().export_key()
    return private_key, public_key

# 签名数据
def sign_data(private_key, data):
    rsakey = RSA.import_key(private_key)
    h = SHA256.new(data.encode('utf-8'))
    signature = pkcs1_15.new(rsakey).sign(h)
    return signature

# 验证签名
def verify_signature(public_key, data, signature):
    rsakey = RSA.import_key(public_key)
    h = SHA256.new(data.encode('utf-8'))
    try:
        pkcs1_15.new(rsakey).verify(h, signature)
        return "Signature is valid."
    except (ValueError, TypeError):
        return "Signature is invalid."

# 示例使用
private_key, public_key = generate_key_pair()
data = "This is a certified digital artwork."
signature = sign_data(private_key, data)
print(f"Signature: {signature}")

# 验证签名
result = verify_signature(public_key, data, signature)
print(result)
```

在这个示例中，我们使用了`Crypto`库生成RSA密钥对，并对数据进行了签名和验证。通过数字签名，我们可以确保数据的真实性和完整性。
