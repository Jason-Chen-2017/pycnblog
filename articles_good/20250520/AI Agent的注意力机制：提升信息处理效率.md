### 第2章: 注意力机制的核心概念与联系

#### 2.1 注意力机制的原理
自注意力机制通过计算查询、键、值的相似性，实现信息的聚焦。

##### 2.1.1 自注意力机制的定义与特点
自注意力机制允许模型在处理每个元素时，考虑所有其他元素的信息，从而捕捉全局依赖关系。

##### 2.1.2 多头注意力机制的原理
多头注意力机制通过并行计算多个子空间的注意力，提升了模型的表达能力。

##### 2.1.3 注意力机制的数学模型
自注意力机制的计算公式如下：
$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

#### 2.2 关键属性特征对比
通过对比不同注意力机制的属性，帮助读者更好地理解其优缺点。

##### 2.2.1 不同注意力机制的对比表格
| 特性 | 单头注意力 | 多头注意力 |
|------|------------|------------|
| 表达能力 | 较弱 | 较强 |
| 计算复杂度 | 较低 | 较高 |
| 应用场景 | 简单任务 | 复杂任务 |

##### 2.2.2 属性特征的详细说明
单头注意力适用于简单任务，而多头注意力在复杂任务中表现更佳。

##### 2.2.3 优缺点分析
多头注意力计算复杂度较高，但表达能力更强，适用于复杂场景。

## 第二部分: 注意力机制的算法原理

### 第3章: 注意力机制的算法原理

#### 3.1 自注意力机制的数学模型
自注意力机制通过计算序列中每个元素与其他元素的相关性，实现信息的聚焦。

##### 3.1.1 数学模型
$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

##### 3.1.2 示例
假设输入序列为$x_1, x_2, x_3$，计算每个元素的注意力权重并求和。

#### 3.2 多头注意力机制的算法流程
多头注意力机制通过并行计算多个子空间的注意力，提升模型的表达能力。

##### 3.2.1 算法流程
```mermaid
graph TD
A[输入序列] --> B[计算Query、Key、Value]
B --> C[分割为多个子空间]
C --> D[计算每个子空间的注意力]
D --> E[合并子空间结果]
E --> F[输出结果]
```

##### 3.2.2 Python代码示例
```python
import torch

def multi_head_attention(query, key, value, num_heads):
    # 线性变换
    q = linear(query, d_model//num_heads)
    k = linear(key, d_model//num_heads)
    v = linear(value, d_model//num_heads)
    
    # 计算注意力权重
    attention_weights = softmax((q @ k.T) / sqrt(d_k), dim=-1)
    
    # 加权求和
    output = (attention_weights @ v).view(batch_size, -1, num_heads, d_model//num_heads)
    output = output.permute(0, 2, 1, 3).contiguous().view(batch_size, -1, d_model)
    return output
```

```python
def attention(input_seq, key_size, value_size, num_units):
    query = tf.layers.dense(input_seq, units=num_units)
    key = tf.layers.dense(input_seq, units=num_units)
    value = tf.layers.dense(input_seq, units=num_units)
    
    attention_weights = tf.nn.softmax(tf.matmul(query, key, transpose_b=True) / tf.sqrt(num_units))
    output = tf.matmul(attention_weights, value)
    return output
```
