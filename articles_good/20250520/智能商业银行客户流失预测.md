### 3.3.4 XGBoost代码示例
```python
import xgboost as xgb
from sklearn.metrics import accuracy_score

# 数据预处理
X = ...  # 特征矩阵
y = ...  # 标签

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 转换数据格式
dtrain = xgb.DMatrix(X_train, label=y_train)
dtest = xgb.DMatrix(X_test, label=y_test)

# 参数设置
params = {
    'objective': 'binary:logistic',
    'learning_rate': 0.1,
    'max_depth': 6,
    'min_child_weight': 1,
    'gamma': 0,
    'subsample': 1,
    'colsample_bytree': 1,
    'n_estimators': 100
}

# 模型训练
model = xgb.train(params, dtrain, num_boost_round=100)

# 模型预测
y_pred = model.predict(dtest)

# 模型评估
print("Accuracy:", accuracy_score(y_test, y_pred))
```

## 3.4 数学模型与公式
### 3.4.1 逻辑回归的数学模型
$$ P(y=1|x) = \frac{1}{1 + e^{-\beta x}} $$
- $\beta$ 是模型的参数
- $x$ 是输入特征向量

### 3.4.2 决策树的分裂准则
$$ Gini指数 = \sum_{i=1}^{n} p_i(1 - p_i) $$
- $p_i$ 是第$i$个子节点的样本比例

### 3.4.3 随机森林的投票机制
- 多棵决策树的预测结果取平均值或多数投票

### 3.4.4 XGBoost的损失函数
$$ L = \sum_{i=1}^{n} \left( y_i - \hat{y}_i \right)^2 $$
- $y_i$ 是真实标签
- $\hat{y}_i$ 是模型预测值

## 3.5 算法比较与选择
### 3.5.1 各算法的优缺点对比
| 算法 | 优势 | 劣势 |
|------|------|------|
| 逻辑回归 | 简单、可解释性强 | 非线性关系处理能力差 |
| 决策树 | 易于解释、适合高维数据 | 容易过拟合 |
| 随机森林 | 高准确性、鲁棒性强 | 计算复杂度高 |
| XGBoost | 高准确性、支持并行计算 | 参数调优复杂 |

### 3.5.2 根据场景选择合适的算法
- 数据量小、特征少：逻辑回归或决策树
- 数据量大、特征多：随机森林或XGBoost
- 实时预测需求：逻辑回归或XGBoost
