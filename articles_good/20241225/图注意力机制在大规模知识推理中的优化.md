## 第2章 图注意力机制原理讲解

### 2.1 图注意力机制的数学模型

图注意力机制（Graph Attention Mechanism，GAM）是基于注意力机制的一种图神经网络（Graph Neural Network，GNN）扩展。在GNN的基础上，图注意力机制引入了注意力机制，能够自动学习节点间的权重关系，从而更好地建模节点间的相互作用。本节将详细介绍图注意力机制的数学模型，包括注意力机制的数学公式和图注意力机制的扩展。

#### 2.1.1 注意力机制的数学公式

注意力机制是一种用于计算节点间相似度的方法，它通过计算相似度矩阵来确定节点的重要性。在图注意力机制中，注意力机制的计算公式可以表示为：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
$$

其中，$Q$表示查询向量，$K$表示键向量，$V$表示值向量，$d_k$是键向量的维度。$\text{softmax}$函数用于将查询向量与键向量的点积转换为概率分布，从而为每个键分配一个权重。

在图注意力机制中，查询向量、键向量和值向量通常与图中的节点和边相关联。具体来说，查询向量表示节点自身，键向量表示节点的邻居，值向量表示节点的特征或属性。

#### 2.1.2 图注意力机制的扩展

图注意力机制的扩展主要包括以下几个方面：

1. **多头注意力**：多头注意力（Multi-head Attention）是一种扩展方法，它通过并行计算多个注意力机制，从而提高模型的性能。多头注意力可以表示为：

$$
\text{Multi-head Attention}(Q, K, V) = \text{Concat}(\text{head}_1, \text{head}_2, ..., \text{head}_h)W^O
$$

其中，$h$表示头数，$\text{head}_i$表示第$i$个注意力头的输出，$W^O$是一个线性变换矩阵。

2. **自注意力**：自注意力（Self-Attention）是一种在单个序列或图中计算注意力权重的方法。自注意力可以表示为：

$$
\text{Self-Attention}(Q, K, V) = \text{softmax}\left(\frac{QQ^T}{\sqrt{d_k}}\right) V
$$

3. **交互注意力**：交互注意力（Interative Attention）是一种结合自注意力和多头注意力的方法，它通过迭代计算注意力权重，从而提高模型的表示能力。

通过上述扩展，图注意力机制能够更好地建模节点间的复杂关系，从而提高知识推理的准确性和效率。

### 2.2 图注意力机制的计算过程

图注意力机制的计算过程主要包括输入数据的预处理、图注意力机制的运算步骤和图注意力机制的输出结果。本节将详细介绍这些步骤，并给出相应的计算公式和流程。

#### 2.2.1 输入数据的预处理

在图注意力机制中，输入数据主要包括节点特征、边特征和图结构。为了进行计算，需要对输入数据进行预处理，包括以下步骤：

1. **节点特征表示**：将节点特征表示为高维向量，通常可以使用嵌入层（Embedding Layer）来实现。嵌入层将节点ID映射为高维向量，从而表示节点的特征信息。

2. **边特征表示**：将边特征表示为高维向量，通常可以使用边嵌入层（Edge Embedding Layer）来实现。边嵌入层将边ID映射为高维向量，从而表示边的特征信息。

3. **图结构表示**：将图结构表示为一个邻接矩阵（Adjacency Matrix）或邻接列表（Adjacency List）。邻接矩阵用于表示节点之间的关系，其中元素$a_{ij}$表示节点$i$和节点$j$之间的边存在与否。

#### 2.2.2 图注意力机制的运算步骤

图注意力机制的运算步骤主要包括以下步骤：

1. **计算键值对**：根据节点特征和边特征，计算键（Key）和值（Value）对。具体来说，对于每个节点$i$，计算其邻居节点的键值对：

$$
K_i = \sum_{j \in \text{neighbor}(i)} W_{kj}v_j
$$

$$
V_i = \sum_{j \in \text{neighbor}(i)} W_{ij}v_j
$$

其中，$W_{kj}$和$W_{ij}$分别表示边嵌入层和节点嵌入层的权重矩阵，$v_j$表示节点$j$的值向量。

2. **计算注意力权重**：根据注意力机制的数学公式，计算节点$i$与其邻居节点之间的注意力权重：

$$
\alpha_{ij} = \text{softmax}\left(\frac{Q_iK_j^T}{\sqrt{d_k}}\right)
$$

其中，$Q_i$表示节点$i$的查询向量。

3. **计算节点表示**：根据注意力权重，计算节点$i$的新特征表示：

$$
\text{att}_{i} = \sum_{j \in \text{neighbor}(i)} \alpha_{ij} v_j
$$

#### 2.2.3 图注意力机制的输出结果

图注意力机制的输出结果主要包括节点的更新表示和图的更新表示。具体来说：

1. **节点表示**：每个节点的更新表示$\text{att}_i$可以作为节点的特征向量，用于后续的任务，如节点分类、节点属性预测等。

2. **图表示**：整个图的更新表示可以用于图的生成、图的分类等任务。具体来说，可以通过聚合所有节点的更新表示来生成图的表示：

$$
\text{att}_{\text{graph}} = \sum_{i} \text{att}_i
$$

通过上述计算过程，图注意力机制能够自动学习节点间的权重关系，从而更好地建模节点间的相互作用。这种交互式的特征表示方法使得图注意力机制在知识推理任务中具有广泛的应用前景。

#### 3.2.2 注意力机制的权重计算

注意力机制的权重计算是图注意力机制的核心，它决定了节点之间的相互作用关系。在图注意力机制中，我们可以使用以下公式计算注意力权重：

$$
\textbf{e}_{ij} = \textbf{h}_i^T\textbf{W}_a\textbf{h}_j
$$

其中，$\textbf{e}_{ij}$表示节点$i$和节点$j$之间的注意力得分，$\textbf{h}_i$和$\textbf{h}_j$分别表示节点$i$和节点$j$的特征向量，$\textbf{W}_a$表示注意力权重矩阵。

通过上述公式，我们可以计算每个节点与其邻居节点之间的注意力得分。然后，我们可以使用softmax函数将得分转换为概率分布，从而得到注意力权重：

$$
\textbf{a}_{ij} = \frac{\exp(\textbf{e}_{ij})}{\sum_{k \in \mathcal{N}(i)} \exp(\textbf{e}_{ik})}
$$

其中，$\textbf{a}_{ij}$表示节点$i$和节点$j$之间的注意力权重，$\mathcal{N}(i)$表示节点$i$的邻居节点集合。

3. **更新节点特征向量**：根据注意力权重，更新节点的特征向量$\textbf{h}_i$。

4. **迭代计算**：重复上述步骤，直到满足停止条件（如达到最大迭代次数或特征向量收敛）。

from torch_geometric.utils import add_self_loops, degree

class GraphAttentionLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super(GraphAttentionLayer, self).__init__()
        self.in_features = in_features
        self.out_features = out_features

        self.attention = nn.Linear(in_features * 2, out_features)
        self.fc = nn.Linear(out_features, out_features)
        self.dropout = nn.Dropout(0.5)
        self_activation = nn.LeakyReLU()

    def forward(self, h, adj):
        # h: [N, N, in_features]
        # adj: [N, N]

        # 1. Calculate edge features
        edge_index, _ = add_self_loops(h, num_nodes=h.size(0))
        edge_attr = torch.ones((edge_index.size(1), self.in_features), device=edge_index.device)
        edge_attr = edge_attr.unsqueeze(-1).repeat(1, 1, self.out_features)

        # 2. Compute attention scores
        att = self.attention(h[edge_index[0], :] * h[edge_index[1], :] + edge_attr)
        att = self_activation(att)
        att = self.dropout(att)

        # 3. Apply softmax activation
        att = torch.softmax(att, dim=2)

        # 4. Apply attention weights
        h = (att * h).sum(dim=1)

        # 5. Add self-connections and pass through the fully connected layer
        h = self.fc(h + torch.sparse.FloatTensor(edge_index.t().cpu().long(), [1] * edge_index.size(1), (h.size(0), h.size(1))).to(h.device))

        return h
