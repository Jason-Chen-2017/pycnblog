$$

$$

其中，$\sigma$ 是一个非线性激活函数，如sigmoid函数或ReLU函数。该公式将节点的嵌入向量 $h_i$ 和关系矩阵 $R$ 通过权重矩阵 $W_e$ 和 $W_r$ 相加，然后应用激活函数，得到节点 $i$ 的注意力分数。

$$

$$

其中，$\text{weight}_{ij}^{old}$ 和 $\text{weight}_{ij}^{new}$ 分别表示节点 $i$ 和节点 $j$ 之间的原始权重和更新后的权重，$\alpha$ 是一个调整系数。

$$
h_i^{new} = \sigma(W_e^T \cdot (\theta \cdot R))
$$

其中，$W_e^T$ 是嵌入权重矩阵的转置，$\theta$ 是所有节点的注意力分数向量，$R$ 是关系矩阵。

# 注意力层
dot = Dot(axes=1)
attention = Lambda(lambda x: x[0] * x[1], output_shape=(1,), name='attention')

# 输出层
output = Lambda(lambda x: tf.reduce_sum(x, axis=1), name='output')

# 构建模型

x = embeddings(inputs)
x = dot([x, x])
theta = attention([x, x])
output = output(theta)

model = Model(inputs=inputs, outputs=output)
model.compile(optimizer='adam', loss='mean_squared_error')

# 训练模型
model.fit(x_train, y_train, epochs=10, batch_size=32, validation_data=(x_val, y_val))

    node_embeddings = model.get_layer('embeddings').get_weights()[0]
    node_vectors = node_embeddings[node_ids]
    attention_scores = model.predict(node_vectors)
    return attention_scores
