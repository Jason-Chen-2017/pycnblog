### 图卷积网络的原理

图卷积网络的核心是图卷积操作。图卷积操作通过融合节点邻居信息，实现对节点的特征更新。具体来说，图卷积操作可以分为以下几个步骤：

2. **权重调整**：对邻居节点特征进行权重调整，以反映节点之间的相对重要性。
3. **非线性变换**：对聚合后的特征进行非线性变换，以提取更复杂的特征。

### 图卷积网络的分类

根据图卷积操作的不同，图卷积网络可以分为以下几类：

1. **邻域聚合型**：如GCN、GraphSAGE等，通过聚合节点邻域信息进行特征更新。

    # 初始化模型参数
    weights = np.random.rand(num_features, num_nodes)
    bias = np.random.rand(num_nodes)

    for epoch in range(epochs):
        # 计算梯度
        loss = 0
        for node in range(num_nodes):
            node_features = features[node, :]
            neighbors = adj_matrix[node, :].nonzero()[0]

            # 计算节点特征更新
            updated_features = graph_convolution(node_features, adj_matrix, weights, bias, activation)

            # 计算损失函数
            prediction = np.dot(updated_features, weights)
            error = prediction - labels[node]
            loss += error ** 2

            # 更新模型参数
            weight_grad = 2 * error * updated_features
            bias_grad = 2 * error

            weights -= learning_rate * weight_grad
            bias -= learning_rate * bias_grad

        # 打印训练进度
        if epoch % 100 == 0:
            print("Epoch", epoch, "Loss:", loss)

    return weights, bias
