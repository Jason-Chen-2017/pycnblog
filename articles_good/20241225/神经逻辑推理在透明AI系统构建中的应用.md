## 第二部分：神经逻辑推理算法

### 第2章：神经网络基础

神经网络（Neural Networks）是神经逻辑推理的核心组成部分，它通过模拟人脑神经元的工作原理，实现了对数据的自动学习和模式识别。在本章中，我们将详细探讨神经网络的原理和实现方法。

#### 2.1 神经网络原理

神经网络由大量的神经元（或节点）组成，这些神经元通过加权连接形成一个复杂的网络结构。每个神经元都可以接收来自其他神经元的输入信号，并通过激活函数产生输出信号。

##### 2.1.1 神经元模型

神经元模型是神经网络的基础，它由以下部分组成：

1. **输入层**：接收外部输入信号。
2. **隐藏层**：对输入信号进行加工和处理。
3. **输出层**：产生最终的输出信号。

每个神经元都可以看作是一个简单的计算单元，其输入和输出关系可以用以下公式表示：

$$
\text{output} = \text{activation}(\text{weight} \cdot \text{input} + \text{bias})
$$

其中：

- **output**：输出值。
- **activation**：激活函数，通常是一个非线性函数，如Sigmoid函数、ReLU函数等。
- **weight**：权重，表示神经元之间的连接强度。
- **input**：输入值。
- **bias**：偏置，用于调整神经元的输出。

##### 2.1.2 前向传播与反向传播

神经网络的学习过程可以分为两个主要阶段：前向传播和反向传播。

1. **前向传播**：在前向传播阶段，输入信号从输入层传递到输出层，每个神经元根据其权重和输入计算输出值。前向传播的过程可以用以下公式表示：

$$
\text{output}_{l}^{i} = \text{activation}(\sum_{j} \text{weight}_{l}^{i}_{j} \cdot \text{input}_{l}^{j} + \text{bias}_{l}^{i})
$$

其中：

- **output\_{l}^{i}**：第l层第i个神经元的输出值。
- **input\_{l}^{j}**：第l层第j个神经元的输入值。
- **weight\_{l}^{i}_{j}**：第l层第i个神经元到第l+1层第j个神经元的权重。
- **bias\_{l}^{i}**：第l层第i个神经元的偏置。

2. **反向传播**：在反向传播阶段，神经网络根据目标输出和实际输出之间的误差，反向更新权重和偏置。反向传播的过程可以分为以下几个步骤：

1. **计算误差**：计算输出层神经元的误差，误差可以使用以下公式表示：

$$
\text{error}_{l}^{i} = \text{output}_{l}^{i} - \text{target}_{l}^{i}
$$

其中：

- **error\_{l}^{i}**：第l层第i个神经元的误差。
- **output\_{l}^{i}**：第l层第i个神经元的输出值。
- **target\_{l}^{i}**：第l层第i个神经元的预期输出值。

2. **计算梯度**：计算每个权重和偏置的梯度，梯度可以使用以下公式表示：

$$
\text{gradient}_{l}^{i}_{j} = \frac{\partial \text{error}_{l}^{i}}{\partial \text{weight}_{l}^{i}_{j}}
$$

$$
\text{gradient}_{l}^{i} = \frac{\partial \text{error}_{l}^{i}}{\partial \text{bias}_{l}^{i}}
$$

其中：

- **gradient\_{l}^{i}_{j}**：第l层第i个神经元到第l+1层第j个神经元的权重梯度。
- **gradient\_{l}^{i}**：第l层第i个神经元的偏置梯度。

3. **更新权重和偏置**：使用梯度下降法更新权重和偏置，公式如下：

$$
\text{weight}_{l}^{i}_{j} := \text{weight}_{l}^{i}_{j} - \text{learning\_rate} \cdot \text{gradient}_{l}^{i}_{j}
$$

$$
\text{bias}_{l}^{i} := \text{bias}_{l}^{i} - \text{learning\_rate} \cdot \text{gradient}_{l}^{i}
$$

其中：

- **learning\_rate**：学习率，用于控制更新速度。

##### 2.1.3 梯度下降法

梯度下降法是一种常用的优化方法，用于在神经网络中更新权重和偏置。其核心思想是沿着损失函数的梯度方向进行迭代更新，以最小化损失函数。

梯度下降法可以分为以下几个步骤：

1. **初始化权重和偏置**：随机初始化权重和偏置。
2. **计算梯度**：计算每个权重和偏置的梯度。
3. **更新权重和偏置**：使用梯度下降法更新权重和偏置。
4. **重复步骤2和3**：重复计算梯度并更新权重和偏置，直到满足停止条件（如损失函数收敛或达到最大迭代次数）。

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

    layer Activations = []
    layer Activations.append(inputs)
    for layer in range(num_layers - 1):
        activation = sigmoid(np.dot(layer Activations[layer], weights) + biases)
        layer Activations.append(activation)
    return layer Activations[-1]

# 反向传播
def backwardPropagation(inputs, targets, layerActivations):
    deltas = [layerActivations[-1] - targets]
    for layer in reversed(range(num_layers - 1)):
        delta = np.dot(deltas[0], weights.T) * sigmoid_derivative(layerActivations[layer])
        deltas.insert(0, delta)
    return deltas

# 更新权重和偏置
def updateWeightsAndBiases(weights, biases, deltas, learningRate):
    for layer in range(num_layers - 1):
        weights[layer] -= learningRate * np.dot(layerActivations[layer].T, deltas[0])
        biases[layer] -= learningRate * deltas[0]

# 训练神经网络
def train(inputs, targets, learningRate, numIterations):
    for iteration in range(numIterations):
        layerActivations = forwardPropagation(inputs)
        deltas = backwardPropagation(inputs, targets, layerActivations)
        updateWeightsAndBiases(weights, biases, deltas, learningRate)

# 示例数据
inputs = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
targets = np.array([[0], [1], [1], [0]])

# 训练神经网络
train(inputs, targets, learningRate=0.1, numIterations=10000)

# 测试神经网络
print("Input: \n", inputs)
print("Predicted Outputs: \n", forwardPropagation(inputs))
```
