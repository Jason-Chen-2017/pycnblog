```python
from typing import Any
from ast import parse, NodeTransformer, literal_eval

class TypeChecker(NodeTransformer):
    def visit_BinOp(self, node: ast.BinOp) -> ast.BinOp:
        left_type = literal_eval(node.left)
        right_type = literal_eval(node.right)
        
        if isinstance(left_type, int) and isinstance(right_type, int):
            return ast.BinOp(
                left=node.left,
                op=ast.Add(),
                right=node.right
            )
        else:
            raise TypeError("Invalid types for binary operation")
        
    def visit_Literal(self, node: ast.Literal) -> ast.Literal:
        value = literal_eval(node)
        
        if isinstance(value, int):
            return ast.Literal(value=value)
        elif isinstance(value, str):
            return ast.Str(s=value)
        else:
            raise TypeError("Invalid literal type")

def check_expression(expression: str) -> ast.AST:
    try:
        parsed_expression = parse(expression)
        type_checker = TypeChecker()
        checked_expression = type_checker.visit(parsed_expression)
        return checked_expression
    except (SyntaxError, TypeError) as e:
        print(f"Error: {e}")
        return None

# 示例使用
expression = "1 + 2"
checked_expression = check_expression(expression)
print(ast.unparse(checked_expression))
```

#### 代码应用解读与分析

1. **输入表达式**：代码首先接受一个字符串形式的数学表达式，例如“1 + 2”。
2. **解析表达式**：使用`ast.parse`函数将输入字符串转换为抽象语法树（AST）。
3. **类型检查**：`TypeChecker`类继承自`NodeTransformer`类，用于对AST节点进行类型检查。具体来说，`visit_BinOp`方法用于检查二元操作符两侧的操作数类型是否为整数，并返回一个符合类型规则的AST节点。如果类型不匹配，则抛出`TypeError`。
4. **类型推断**：`visit_Literal`方法用于检查字面量类型是否为整数或字符串，并返回相应的AST节点。同样，如果类型不匹配，则抛出`TypeError`。
5. **错误报告**：如果类型检查过程中出现错误，代码将捕获异常并打印错误消息。
