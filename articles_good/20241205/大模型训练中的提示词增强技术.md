   $$ P(w_i | d) = \frac{f(w_i, d)}{f(d)} $$

```python
        top_keywords = vectorizer.get_feature_names_out()[tfidf_vector.toarray()[0].argsort()[::-1][:k]]
```

```python
    for i, prompt in enumerate(prompts):
        if similarities[i] > threshold:
            optimized_prompts.append(prompt)
    return optimized_prompts

# 应用到训练集
train_prompts = optimize_prompts(train_prompts, calculate_similarity(train_prompts, train_texts), threshold=0.8)
```

在这段代码中，我们计算每个提示词与训练文本之间的相似度，并根据设定的阈值对提示词进行优化。`calculate_similarity`和`optimize_prompts`函数分别实现了相似度计算和提示词优化。
