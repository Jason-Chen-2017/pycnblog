#### 2.2 形式化语言的基本结构

形式化语言是一种使用形式化语法和语义描述的语言。形式化语言的基本结构包括词汇、语法规则和语义规则。

1. **词汇**：词汇是形式化语言的基本元素，包括变量、常量、函数名、操作符等。词汇通常用符号表示，例如，"x"、"y"、"add"。

2. **语法规则**：语法规则定义了词汇的排列组合方式，形成有效的程序代码。语法规则通常使用形式化的文法规则，如BNF（Backus-Naur Form）或EBNF（Extended Backus-Naur Form）来描述。例如，以下是一个简单的语法规则示例：

   ```
   <program> ::= <statement>
                | <statement> <program>
   ```

   这个规则表示一个程序可以是单个语句，也可以是多个语句的组合。

3. **语义规则**：语义规则定义了词汇组合的含义和执行行为。语义规则通常与语法规则相关联，用于解释和执行程序代码。例如，以下是一个简单的语义规则示例：

   ```
   <statement> ::= <variable> = <expression>
   {
       <variable>.value = <expression>.value;
   }
   ```

   这个规则表示一个赋值语句将变量的值设置为表达式的值。
