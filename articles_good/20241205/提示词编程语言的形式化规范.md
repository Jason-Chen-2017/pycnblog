形式化规范有多种类型，每种类型都有其独特的特点和适用场景。以下是一些常见的形式化规范类型：

#### 语法规范

语法规范定义了编程语言的语法结构，即编程语言的语法规则。这种规范通常使用巴科斯-诺尔范式（BNF）或扩展巴科斯-诺尔范式（EBNF）来描述。语法规范确保编程语言的每一个组成部分都遵循一定的规则，从而使得编译器或解释器能够准确地解析代码。

- **BNF（巴科斯-诺尔范式）**：
  $$ 
  E :: = E + T | T 
  $$
  $$ 
  T :: = a | b 
  $$
  以上例子展示了如何使用BNF定义一个简单的算术表达式语法。

- **EBNF（扩展巴科斯-诺尔范式）**：
  $$ 
  E :: = E + F | F 
  $$
  $$ 
  F :: = (E) | a | b 
  $$
  EBNF扩展了BNF的功能，允许更复杂的语法描述。

#### 语义规范

语义规范描述了编程语言中每个语法结构的含义和操作。这种规范通常使用操作符表（Operator Table）或文法导出（Grammar Derivation）来表示。

- **操作符表**：
  $$ 
  + :: = \text{num} + \text{num} \rightarrow \text{num} 
  $$
  $$ 
  - :: = \text{num} - \text{num} \rightarrow \text{num} 
  $$
  操作符表定义了每个操作符的参数类型和操作结果。

- **文法导出**：
  $$ 
  E \rightarrow T + E | T 
  $$
  $$ 
  T \rightarrow F \times T | F 
  $$
  $$ 
  F \rightarrow (E) | a | b 
  $$
  文法导出展示了如何通过语法规则生成语法树。

#### 类型规范

类型规范定义了编程语言中数据的类型系统，包括数据类型的定义、类型检查和类型转换。类型规范通常使用抽象语法树（Abstract Syntax Tree, AST）或类型系统符号表（Type System Symbol Table）来表示。

- **AST（抽象语法树）**：
  ```python
  class ExpressionNode:
      def __init__(self, left, right):
          self.left = left
          self.right = right

  class NumNode:
      def __init__(self, value):
          self.value = value

  tree = ExpressionNode(NumNode(1), NumNode(1))
  ```
  AST是一个树形结构，表示了编程语言的抽象语法。

- **类型系统符号表**：
  ```python
  symbol_table = {
      'a': 'int',
      'b': 'bool',
      '+': {'int': 'int', 'bool': 'bool'},
      '-': {'int': 'int', 'bool': 'bool'},
  }
  ```
  类型系统符号表定义了变量和操作符的类型信息。

#### 行为规范

行为规范描述了编程语言中每个程序的行为和执行过程，通常使用状态机（Finite State Machine, FSM）或动态语义模型（Dynamic Semantics Model）来表示。

- **状态机**：
  ```mermaid
  stateMachine
  [
    state A
    state B
    state C
    transition A -> B on event1
    transition B -> C on event2
  ]
  ```
  状态机展示了程序在不同事件触发下的状态转换。

- **动态语义模型**：
  ```mermaid
  graph TD
  A[开始] --> B[执行语句1]
  B --> C[执行语句2]
  C --> D[结束]
  ```
  动态语义模型展示了程序在执行过程中的状态变化。
