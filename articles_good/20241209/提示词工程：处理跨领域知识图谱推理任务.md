```python
import networkx as nx

# 创建图
G = nx.Graph()

# 添加实体和关系
G.add_nodes_from(['张三', '李四', '北京', '上海'])
G.add_edges_from([('张三', '工作于', '北京'), ('李四', '工作于', '上海'), ('北京', '属于', '中国'), ('上海', '属于', '中国')])

# 打印图
print(G)

# 添加属性
G['张三']['年龄'] = 30
G['李四']['年龄'] = 35
G['北京']['人口'] = 2000万
G['上海']['人口'] = 2400万

# 打印属性
print(G.nodes(data=True))
print(G.edges(data=True))
```

1. 导入NetworkX库，用于构建图。
2. 创建一个图G。
3. 添加实体和关系，如“张三”和“李四”是实体，他们分别与“北京”和“上海”有“工作于”关系。
4. 添加属性，如实体的年龄和城市的人口。
