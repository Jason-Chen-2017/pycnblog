##### 1.2.1 提示词的定义与作用

提示词（Prompt Word）是指在AI系统或人机交互中，用来引导或激发系统或用户情感、行为或思考的关键词或短语。在自然语言处理（NLP）中，提示词常常被用来引导对话流程，帮助AI更好地理解和回应人类的意图和情感。

2. **情感激发**：提示词可以激发AI的情感反应，使其在对话中表现出更加人性化的互动。例如，通过使用温馨、关怀或鼓励的提示词，可以增强AI与用户之间的情感联系。

1. **情感识别**：同理心首先需要能够识别他人的情感状态，包括情绪、情感强度和情感背景等。

2. **情感共鸣**：在识别他人情感的基础上，同理心需要能够产生情感上的共鸣，即感同身受。这涉及到情感上的共情和情感状态的共享。

3. **行为响应**：同理心还要求个体能够对他人情感做出适当的情感和行为响应，以帮助对方缓解情绪或提供支持。

4. **理解与支持**：同理心的关键在于理解和支持他人，不仅仅是表面上的回应，还需要深入理解对方的情感和需求，并采取有效措施来帮助对方。

   conversation_state = {

   def understand_context(current_sentence):
       conversation_state["previous_sentence"] = current_sentence
       if "happy" in current_sentence.lower():
           conversation_state["emotion"] = "positive"
       elif "sad" in current_sentence.lower():
           conversation_state["emotion"] = "negative"
       else:
           conversation_state["emotion"] = "neutral"
       return conversation_state

3. **提示词生成**：根据情感识别和上下文理解的结果，生成相应的提示词。这里我们使用一个简单的提示词库。
