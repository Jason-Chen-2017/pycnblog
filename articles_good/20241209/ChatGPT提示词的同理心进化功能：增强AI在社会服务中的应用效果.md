### 1. 背景介绍

#### 1.1 核心概念术语说明

- **ChatGPT**：一种基于GPT（Generative Pre-trained Transformer）模型的预训练语言模型，能够理解和生成自然语言文本。
- **提示词（Prompt）**：用于引导ChatGPT生成目标文本的输入，通常包含关键词、问题或指令。
- **同理心**：理解和共享他人情感的能力，对于AI而言，是通过算法模拟人类情感理解和反应。
- **社会服务**：包括教育、医疗、公共服务、社会福利等领域，旨在提高人们的生活质量和社会福祉。

#### 1.3 问题描述

问题描述主要集中在以下几个方面：

- 提示词设计的优化，使其更贴近人类语言交流习惯。
- 引入同理心机制，使AI能够更好地理解和回应人类情感。
- 提高AI在社会服务中的实际应用效果，如教育、医疗、心理咨询等。

#### 3.2 Python源代码

```python
import openai

def generate_response(prompt, model="text-davinci-002", temperature=0.7):
    response = openai.Completion.create(
        engine=model,
        prompt=prompt,
        max_tokens=50,
        n=1,
        stop=None,
        temperature=temperature,
    )
    return response.choices[0].text.strip()

def main():
    prompt = "请描述一下你对慈善机构的看法。"
    response = generate_response(prompt)
    print(response)

if __name__ == "__main__":
    main()
```

```python
import random

def generate_prompt(user_input, domain="social_service"):
    templates = {
        "social_service": "请描述一下你对{domain}的看法。",
        "health_counseling": "请问您有什么健康方面的问题，我可以帮您解答。",
        "educational_help": "请问您在学习上遇到什么困难，我可以为您提供帮助。",
    }
    template = random.choice(templates[domain])
    return template.format(domain=domain).format(input=user_input)
```

**同理心评估模块**：

```python
from textblob import TextBlob

def assess_empathy(text):
```
