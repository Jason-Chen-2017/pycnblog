# 第3章: 算法原理讲解

## 3.1 协同过滤算法

### 3.1.1 基于用户的协同过滤
- 相似度计算：使用余弦相似度或皮尔逊相关系数。
- 推荐计算：基于相似用户的评分加权平均。

### 3.1.2 基于物品的协同过滤
- 物品相似度计算：基于物品的共现矩阵或余弦相似度。
- 推荐计算：基于物品相似度的加权平均。

### 3.1.3 混合协同过滤的实现
- 组合用户和物品的特征进行推荐。

## 3.2 矩阵分解算法

### 3.2.1 SVD矩阵分解原理
- 将用户-产品评分矩阵分解为用户特征矩阵和产品特征矩阵。
- 使用梯度下降法或随机梯度下降法进行优化。

### 3.2.2 矩阵分解的数学模型
$$ R = U \cdot V^T $$
其中，R是用户-产品评分矩阵，U是用户特征矩阵，V是产品特征矩阵。

### 3.2.3 算法实现步骤
1. 初始化U和V矩阵。
2. 计算评分矩阵R的残差。
3. 更新U和V矩阵，直到收敛。

# 第4章: 数学模型与公式

## 4.1 协同过滤模型

### 4.1.1 用户-物品评分矩阵
$$ R = (r_{ij}) \in \mathbb{R}^{m \times n} $$
其中，m是用户数量，n是产品数量，r_{ij}是用户i对产品j的评分。

### 4.1.2 相似度计算公式
- 余弦相似度：
$$ \text{sim}(u, v) = \frac{\sum_{i=1}^{n} r_{ui} r_{vi}}{\sqrt{\sum_{i=1}^{n} r_{ui}^2} \cdot \sqrt{\sum_{i=1}^{n} r_{vi}^2}} } $$
- 皮尔逊相关系数：
$$ \text{sim}(u, v) = \frac{\sum_{i=1}^{n} (r_{ui} - \bar{r_u})(r_{vi} - \bar{r_v})}{\sqrt{\sum_{i=1}^{n} (r_{ui} - \bar{r_u})^2} \cdot \sqrt{\sum_{i=1}^{n} (r_{vi} - \bar{r_v})^2}} } $$

### 4.1.3 推荐评分公式
$$ \hat{r}_{ui} = \frac{\sum_{v \in N(u)} w_{uv} r_{vj}}{\sum_{v \in N(u)} w_{uv}} } $$
其中，N(u)是与用户u相似的用户集合，w_{uv}是用户u和v的相似度。

## 4.2 矩阵分解模型

### 4.2.1 SVD分解公式
$$ R = U \cdot \Sigma \cdot V^T $$
其中，U是用户特征矩阵，Σ是奇异值矩阵，V是产品特征矩阵。

### 4.2.2 矩阵分解的优化目标
$$ \min_{U, V} \| R - U V^T \|_F^2 + \lambda (\|U\|_F^2 + \|V\|_F^2) $$
其中，λ是正则化参数。

### 4.2.3 算法实现步骤
1. 初始化U和V矩阵。
2. 计算评分矩阵R的残差。
3. 更新U和V矩阵，直到收敛。

### 6.2.1 协同过滤算法实现
```python
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

# 初始化用户-产品评分矩阵
R = np.array([[4, 3, 2],
              [5, 1, 4],
              [3, 5, 2]])

# 计算相似度矩阵
similarity = cosine_similarity(R)

# 基于用户的协同过滤推荐
def user_based_recommendation(user_id, similarity, R):
    similar_users = np.argsort(similarity[user_id])[::-1]
    similar_users = similar_users[similarity[user_id] > 0.5]
    recommendation = {}
    for u in similar_users:
        for j in range(len(R[u])):
            if R[user_id][j] == 0:
                recommendation[j] = R[u][j]
    return recommendation

# 示例推荐
user_id = 0
recommendation = user_based_recommendation(user_id, similarity, R)
print(recommendation)
```

### 6.2.2 矩阵分解算法实现
```python
import numpy as np

# 初始化矩阵分解参数
m, n = 3, 3
k = 2
U = np.random.randn(m, k)
V = np.random.randn(n, k)
lambda_reg = 0.1

# 计算残差
def compute_residual(U, V, R):
    return R - np.dot(U, V.T)

# 更新矩阵
def update_matrix(U, V, R, lambda_reg):
    UV = np.dot(U, V.T)
    residual = R - UV
    # 更新U
    for i in range(U.shape[0]):
        for j in range(V.shape[0]):
            U[i, :] += (residual[i, j] * V[j, :]) / (lambda_reg + np.linalg.norm(V[j, :])**2)
    # 更新V
    for j in range(V.shape[0]):
        for i in range(U.shape[0]):
            V[j, :] += (residual[i, j] * U[i, :]) / (lambda_reg + np.linalg.norm(U[i, :])**2)
    return U, V

# 矩阵分解实现
def matrix_factorization(R, k, lambda_reg, max_iter=100):
    U = np.random.randn(R.shape[0], k)
    V = np.random.randn(R.shape[1], k)
    for _ in range(max_iter):
        U, V = update_matrix(U, V, R, lambda_reg)
    return U, V

# 示例分解
U, V = matrix_factorization(R, k, lambda_reg)
print(U, V)
```
