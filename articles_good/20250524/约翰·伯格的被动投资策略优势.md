# 第一部分: 被动投资策略的背景与基础

## 第1章: 被动投资策略概述

### 1.1 被动投资的核心概念

#### 1.1.1 什么是被动投资
被动投资是一种以长期持有指数基金或 ETF（交易所交易基金）为核心的投资策略，其核心理念是通过复制市场表现而非试图预测市场波动来实现长期稳健的收益。

**关键术语对比表：**

| 概念         | 主动投资       | 被动投资       |
|--------------|----------------|----------------|
| 投资目标     | 超越市场指数   | 模拟市场指数     |
| 管理方式     | 积极选股       | 跟踪指数成分股   |
| 费用         | 较高（管理费、交易费） | 较低（管理费低） |
| 风险         | 较高           | 较低           |
| 适用场景     | 短期收益       | 长期稳健       |

#### 1.1.2 被动投资与主动投资的区别
被动投资的核心是“被动跟踪市场”，而主动投资的核心是“主动选股”。被动投资通过分散化投资降低风险，而主动投资则依赖于基金经理的选股能力。

#### 1.1.3 约翰·伯格的被动投资理念
约翰·伯格是被动投资的倡导者，他认为普通投资者难以通过主动投资持续跑赢市场，而指数基金能够以较低的成本实现市场平均收益。

### 1.2 被动投资的理论基础

#### 1.2.1 现代投资组合理论
现代投资组合理论（MPT）由哈里·马科维茨提出，认为通过合理分散投资可以降低非系统性风险，从而实现最优风险收益比。

#### 1.2.2 有效市场假说
有效市场假说认为市场价格反映了所有可获得的信息，因此普通投资者无法通过分析基本面或技术面获得超额收益。

#### 1.2.3 资本资产定价模型（CAPM）
CAPM模型用于计算资产的预期收益率，公式为：
$$ E(r_i) = r_f + \beta_i (E(r_m) - r_f) $$
其中，$r_f$为无风险利率，$\beta_i$为资产的贝塔系数，$E(r_m)$为市场预期回报率。

### 1.3 被动投资的实践意义

#### 1.3.1 被动投资的优势与劣势
被动投资的优势在于费用低、风险低、操作简单；劣势在于无法跑赢市场指数，且在市场下跌时会同步下跌。

#### 1.3.2 被动投资的适用场景
适合长期投资、风险承受能力较低的投资者，尤其适合普通散户。

#### 1.3.3 约翰·伯格的被动投资策略特点
伯格的策略强调长期持有、定期定额投资，以及通过分散化降低风险。

### 1.4 本章小结
被动投资是一种简单有效的投资策略，尤其适合普通投资者。约翰·伯格的被动投资理念强调长期持有和分散化，通过跟踪市场指数实现稳健收益。

# 第二部分: 被动投资策略的核心分析

## 第2章: 被动投资策略的数学模型与算法

### 2.1 现代投资组合理论的数学模型

#### 2.1.1 投资组合理论的基本假设
- 投资者是理性的，追求效用最大化。
- 市场是有效的，价格反映所有信息。
- 投资者可以无限分割投资组合。

#### 2.1.2 资产回报率的协方差矩阵
协方差矩阵用于衡量不同资产之间的相关性，公式为：
$$ \Sigma = \begin{bmatrix}
\sigma_{11} & \sigma_{12} & \cdots & \sigma_{1n} \\
\sigma_{21} & \sigma_{22} & \cdots & \sigma_{2n} \\
\vdots & \vdots & \ddots & \vdots \\
\sigma_{n1} & \sigma_{n2} & \cdots & \sigma_{nn}
\end{bmatrix} $$

#### 2.1.3 最小方差组合的计算公式
最小方差组合的权重计算公式为：
$$ \mathbf{w} = \arg \min \mathbf{w}^T \Sigma \mathbf{w} $$

### 2.2 资本资产定价模型（CAPM）

#### 2.2.1 CAPM的基本公式
$$ E(r_i) = r_f + \beta_i (E(r_m) - r_f) $$

### 2.3 被动投资组合优化的算法实现

#### 2.3.1 均值-方差优化算法
均值-方差优化的目标是最小化投资组合的波动率，公式为：
$$ \sigma_p^2 = \mathbf{w}^T \Sigma \mathbf{w} $$

#### 2.3.2 最小化跟踪误差的优化模型
跟踪误差是指投资组合的实际回报与目标指数回报之间的差异，公式为：
$$ \text{TE} = \sqrt{\mathbf{w}^T \Sigma \mathbf{w} - 2 \mathbf{w}^T \Sigma \mathbf{e} + \mathbf{e}^T \Sigma \mathbf{e}} $$
其中，$\mathbf{e}$为目标指数的权重向量。

#### 2.3.3 基于指数基金的组合优化
通过优化算法选择最优的指数基金组合，以实现最小的跟踪误差和最大的流动性。

### 2.4 本章小结
被动投资的数学模型和算法为投资组合优化提供了理论基础，通过均值-方差优化和最小化跟踪误差的模型，可以实现最优的被动投资组合。

```python
import numpy as np
import pandas as pd

# 定义协方差矩阵
cov_matrix = np.array([[0.02, 0.01], [0.01, 0.03]])

# 定义目标指数权重
index_weights = np.array([0.5, 0.5])

# 计算最优权重
def optimize_weights(cov_matrix, index_weights):
    # 定义目标函数
    def objective(weights):
        return np.dot(weights.T, np.dot(cov_matrix, weights))
    
    # 约束条件：权重之和为1
    constraints = ({'type': 'eq', 'fun': lambda w: sum(w) - 1})
    
    # 使用 scipy 最优化
    from scipy.optimize import minimize
    result = minimize(objective, np.array([0.5, 0.5]), method='SLSQP', constraints=constraints)
    return result.x

# 调用优化函数
optimal_weights = optimize_weights(cov_matrix, index_weights)
print("最优权重:", optimal_weights)
```

```python
import numpy as np
from scipy.optimize import minimize

def portfolio_optimization(returns, cov_matrix, target_return):
    n = len(returns)
    # 定义目标函数：最大化夏普比率
    def objective(weights):
        portfolio_return = np.dot(weights, returns)
        portfolio_variance = np.dot(weights.T, np.dot(cov_matrix, weights))
        return -portfolio_return
    
    # 约束条件：权重之和为1，且每个权重非负
    constraints = [{'type': 'eq', 'fun': lambda w: sum(w) - 1},
                   {'type': 'ineq', 'fun': lambda w: w[i] >= 0} for i in range(n)]
    
    # 初始权重
    initial_guess = np.array([1/n]*n)
    
    # 进行优化
    result = minimize(objective, initial_guess, method='SLSQP', constraints=constraints)
    return result.x

# 示例数据
returns = np.array([0.1, 0.15])
cov_matrix = np.array([[0.02, 0.01], [0.01, 0.03]])
target_return = 0.12

# 调用优化函数
optimal_weights = portfolio_optimization(returns, cov_matrix, target_return)
print("最优权重:", optimal_weights)
```

#### 4.2.2 跟踪误差计算
```python
def tracking_error(weights, returns, index_returns):
    # 计算投资组合回报
    portfolio_return = np.dot(weights, returns)
    # 计算指数回报
    index_return = np.dot(index_returns, np.array([1/len(index_returns)]*len(index_returns)))
    # 计算跟踪误差
    te = np.abs(portfolio_return - index_return)
    return te

# 示例计算
weights = np.array([0.6, 0.4])
returns = np.array([0.1, 0.15])
index_returns = np.array([0.12, 0.13])

te = tracking_error(weights, returns, index_returns)
print("跟踪误差:", te)
```
