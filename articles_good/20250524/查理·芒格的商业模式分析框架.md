## 第三部分：算法原理讲解

### 第3章：芒格思维模型的算法实现

#### 3.1 决策树模型构建

决策树是一种用于结构化决策的工具，可以直观地展示不同决策路径及其结果。以下是使用Python构建决策树的代码示例：

```python
import graphviz

def construct_decision_tree():
    # 创建决策树
    dot = graphviz.Digraph()
    dot.node('root', '决策起点')
    dot.node('A', 'A选项')
    dot.node('B', 'B选项')
    dot.edge('root', 'A')
    dot.edge('root', 'B')
    return dot

# 生成决策树并导出
dot = construct_decision_tree()
dot.render('decision_tree.gv', view=True)
```

#### 3.2 机会成本计算

机会成本是指放弃某项选择所付出的代价。计算机会成本的数学模型如下：

$$
\text{机会成本} = \text{最大可能收益} - \text{实际选择收益}
$$

例如，如果选择投资A项目放弃投资B项目，B项目的预期收益为$100，而A项目的实际收益为$80，那么机会成本为$20。
