## 3.1 理论的数学模型与公式

### 3.1.1 投资成本最小化的目标函数
$$ \text{Minimize } C = \sum_{i=1}^{n} c_i x_i $$

### 3.1.2 约束条件
$$ \text{Subject to } \sum_{i=1}^{n} w_i x_i \geq R $$

### 3.1.3 参数解释
- \( C \): 总投资成本
- \( c_i \): 第 \( i \) 项投资的成本
- \( x_i \): 第 \( i \) 项投资的金额
- \( R \): 投资收益目标
- \( w_i \): 第 \( i \) 项投资的预期收益权重

### 3.2.2 算法实现代码
```python
def min_investment_cost(c, w, R):
    n = len(c)
    import numpy as np
    from scipy.optimize import minimize

    def objective(x):
        return np.sum(c * x)

    def constraint(x):
        return np.sum(w * x) - R

    bounds = [(0, None) for _ in range(n)]

    result = minimize(objective, np.zeros(n), bounds=bounds, constraints={'type': 'ineq', 'fun': constraint})
    return result.x

# 示例数据
c = [0.05, 0.10, 0.08]  # 各投资的成本率
w = [0.1, 0.2, 0.15]    # 各投资的收益权重
R = 0.15                 # 收益目标

x = min_investment_cost(c, w, R)
print("最优投资组合:", x)
```

## 5.2 系统核心代码实现

### 5.2.1 核心代码实现
```python
import numpy as np
from scipy.optimize import minimize

def min_cost_model(c, w, R):
    n = len(c)
    bounds = [(0, None) for _ in range(n)]
    result = minimize(lambda x: np.dot(c, x), np.zeros(n), 
                      bounds=bounds, constraints={'type': 'ineq', 'fun': lambda x: np.dot(w, x) - R})
    return result.x

# 示例数据
c = np.array([0.05, 0.10, 0.08])
w = np.array([0.1, 0.2, 0.15])
R = 0.15

optimal_portfolio = min_cost_model(c, w, R)
print("最优投资组合:", optimal_portfolio)
```
