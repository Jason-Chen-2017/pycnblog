# 第1章: 多智能体强化学习概述

## 1.1 多智能体强化学习的定义与特点

### 1.1.1 多智能体强化学习的定义
多智能体强化学习是指多个智能体在共享环境中通过协作或竞争，学习策略以最大化全局目标。与单智能体不同，MARL强调智能体间的协作与信息共享。

### 1.1.2 多智能体强化学习的核心特点
| 特性 | 描述 |
|------|------|
| 分布式决策 | 每个智能体独立决策，降低计算复杂度 |
| 协作性 | 智能体通过协作提升整体性能 |
| 复杂性 | 环境和动作空间更复杂，需考虑智能体间交互 |

### 1.1.3 多智能体与单智能体强化学习的对比
| 对比维度 | 单智能体 | 多智能体 |
|----------|---------|----------|
| 智能体数量 | 1       | 多       |
| 决策独立性 | 高       | 低       |
| 应用场景   | 简单任务 | 复杂场景  |

## 1.2 多智能体强化学习的优势

### 1.2.1 分布式决策的优势
通过多个智能体分布式决策，提高系统的容错性和鲁棒性。

### 1.2.2 多智能体协作的重要性
协作机制提升整体性能，适用于复杂任务。

### 1.2.3 多智能体在投资中的应用背景
投资环境复杂，多智能体能处理多因素影响，优化再投资策略。

# 第2章: 多智能体强化学习的核心概念与原理

## 2.1 多智能体强化学习的基本概念

### 2.1.1 智能体的定义与角色
智能体是决策单元，可代表不同投资策略。

### 2.1.2 环境的定义与分类
环境包括市场数据，分为静态和动态环境。

### 2.1.3 状态、动作与奖励
- 状态：当前市场状况。
- 动作：投资行为。
- 奖励：收益或损失。

## 2.2 多智能体强化学习的核心原理

### 2.2.1 值函数与策略函数
- 值函数：评估状态价值。
- 策略函数：指导动作选择。

### 2.2.2 多智能体协作机制
通过通信模块共享信息，优化决策。

### 2.2.3 数学模型
状态空间S，动作空间A，奖励函数R，智能体协作模型：
$$ \max_{\theta} \sum_{i=1}^n J_i(\theta_i) $$

## 2.3 多智能体强化学习的算法分类

### 2.3.1 基于值函数的算法
Q-learning，公式：
$$ Q(s, a) = r + \gamma \max Q(s', a') $$

### 2.3.2 基于策略梯度的算法
策略梯度方法，公式：
$$ \theta \leftarrow \theta + \alpha \nabla J $$

### 2.3.3 基于Actor-Critic的算法
结合值函数和策略函数，公式：
$$ \theta_{\text{critic}} \leftarrow \text{update}(r + \gamma Q(s', a')) $$
$$ \theta_{\text{actor}} \leftarrow \text{update}(\nabla J) $$

# 第3章: 多智能体强化学习的数学模型与公式

## 3.1 值函数的数学表达

### 3.1.1 Q-learning的数学公式
$$ Q(s, a) = Q(s, a) + \alpha [r + \gamma \max Q(s', a') - Q(s, a)] $$

### 3.1.2 Actor-Critic的数学公式
- 批量更新批评家：
$$ \theta_{\text{critic}} \leftarrow \text{update}(r + \gamma Q(s', a')) $$
- 更新演员：
$$ \theta_{\text{actor}} \leftarrow \text{update}(\nabla J) $$

## 3.2 多智能体协作的数学模型

### 3.2.1 联合优化
$$ \max_{\theta_1, \theta_2} J(\theta_1, \theta_2) = \sum_{i=1}^n J_i(\theta_i) $$

### 3.2.2 纳什均衡
$$ \forall i, J_i(\theta_i, \theta_{-i}) \geq J_i(\theta_i^*, \theta_{-i}) $$

### 6.1.2 核心代码实现

```python
import gym
import numpy as np

class MultiAgentReinforcementLearning:
    def __init__(self, env):
        self.env = env
        self.num_agents = 2
        self.state_space = env.observation_space.shape[0]
        self.action_space = env.action_space.n

    def get_action(self, state, theta):
        # 简单策略，返回随机动作
        return np.random.randint(0, self.action_space)

    def update_critic(self, reward, next_state, theta):
        # 简单值函数更新
        return theta + 0.1 * (reward - np.dot(theta, next_state))

    def update_actor(self, critic_value, theta):
        # 策略梯度更新
        return theta + 0.1 * (critic_value)

env = gym.make('Multi-Agent-Stock-Trading-v0')
agent = MultiAgentReinforcementLearning(env)
state = env.reset()
theta = np.random.randn(env.observation_space.shape[0])

for _ in range(1000):
    action = agent.get_action(state, theta)
    next_state, reward, done, info = env.step(action)
    theta = agent.update_actor(reward, next_state, theta)
    state = next_state
    if done:
        break
```
