### # 第1章: 图表示学习与系统性风险的背景

#### 1.1 图表示学习的基本概念

##### 1.1.1 图表示学习的定义
图表示学习是一种将图结构数据转化为低维向量表示的技术。其核心目标是捕捉图中节点及其关系的关键特征，以便于后续的分析和应用。

##### 1.1.2 图表示学习的核心特点
- **全局性**：考虑图中所有节点的相互关系。
- **结构性**：保留图的拓扑结构特征。
- **可解释性**：向量表示具有一定的可解释性。

##### 1.1.3 图表示学习与传统表示学习的区别
| 特性         | 图表示学习             | 传统表示学习           |
|--------------|-----------------------|------------------------|
| 数据类型      | 图结构数据             | 单一类型数据（文本、图像等） |
| 表达方式      | 节点向量表示           | 全局或局部向量表示       |
| 应用场景      | 社交网络、金融网络等   | 文本分类、图像识别等    |

#### 1.2 系统性风险的定义与特征

##### 1.2.1 系统性风险的定义
系统性风险是指由于系统性因素（如经济危机、政策变化）导致整个金融系统发生崩溃的可能性。

##### 1.2.2 系统性风险的传播机制
系统性风险通常通过金融网络中的关联性传播。例如，一家银行的破产可能引发连锁反应，导致整个金融系统的崩溃。

##### 1.2.3 系统性风险与个体风险的关系
系统性风险是个体风险在系统中的相互作用和放大效应的结果。

#### 1.3 金融领域中的系统性风险度量

##### 1.3.1 传统系统性风险度量方法
- **VaR（Value at Risk）**：衡量资产在正常市场条件下的潜在损失。
- **CVaR（Conditional Value at Risk）**：衡量在损失超过 VaR 情况下的平均损失。

##### 1.3.2 传统方法的局限性
- **忽略了网络结构**：传统方法通常不考虑金融机构之间的相互依赖关系。
- **静态性**：传统方法难以捕捉动态风险的变化。

##### 1.3.3 图表示学习在系统性风险中的应用优势
- **捕捉网络结构**：图表示学习能够有效捕捉金融网络中的关联性。
- **动态性**：可以实时更新节点的表示，捕捉动态风险变化。

#### 1.4 本章小结
本章介绍了图表示学习的基本概念和系统性风险的定义、特征及传统度量方法的局限性，为后续内容奠定了基础。

### # 第2章: 图表示学习的核心概念与原理

#### 2.1 图结构与节点表示

##### 2.1.1 图的表示方式
图可以表示为 $G = (V, E)$，其中 $V$ 是节点集合，$E$ 是边集合。

##### 2.1.2 节点表示的意义
节点表示是将节点嵌入到低维空间中的向量，用于后续的分析和应用。

##### 2.1.3 图结构的特征提取
图结构的特征包括节点度数、中心性、社区结构等。

#### 2.2 图神经网络的基本原理

##### 2.2.1 图神经网络的定义
图神经网络（Graph Neural Network，GNN）是一种专门用于处理图结构数据的深度学习模型。

##### 2.2.2 图神经网络的输入与输出
- **输入**：图结构数据 $G = (V, E)$ 和节点特征 $X$。
- **输出**：节点的表示向量 $Z$ 或图的标签 $Y$。

##### 2.2.3 图神经网络的训练过程
1. **初始化**：为每个节点分配初始向量。
2. **传播**：通过消息传递机制（Message Passing）更新节点表示。
3. **聚合**：将相邻节点的信息聚合到当前节点。
4. **更新**：更新节点表示并传递到下一层。

#### 2.3 图表示学习的主要方法

##### 2.3.1 基于随机游走的表示学习
随机游走是一种通过遍历图中的节点来生成序列的方法，常用于捕捉节点的语义信息。

##### 2.3.2 基于矩阵分解的表示学习
矩阵分解是一种通过分解图的邻接矩阵来获取节点表示的方法。

##### 2.3.3 基于深度学习的图表示方法
深度学习方法（如 GNN）通过多层感知机（MLP）捕捉图的复杂结构特征。

#### 2.4 图表示学习的评价指标

##### 2.4.1 表示质量的评价指标
- **准确性**：表示向量能否准确反映节点的特征。
- **可区分性**：节点表示的区分度。

##### 2.4.2 应用效果的评价指标
- **分类准确率**：在分类任务中的准确率。
- **聚类指标**：如 NMI（Normalized Mutual Information）。

##### 2.4.3 评价指标的选择与应用
选择评价指标时需结合具体任务需求，例如分类任务更关注分类准确率，聚类任务更关注聚类指标。

#### 2.5 本章小结
本章详细介绍了图表示学习的核心概念和主要方法，并讨论了评价指标的选择与应用。

### # 第3章: 系统性风险的图表示建模

#### 3.1 金融网络的构建

##### 3.1.1 金融网络的节点定义
金融网络中的节点可以是银行、企业、投资者等。

##### 3.1.2 金融网络的边定义
边表示节点之间的关联性，例如，贷款关系、投资关系等。

##### 3.1.3 金融网络的构建方法
- **基于实际数据**：利用真实的金融交易数据构建网络。
- **基于统计方法**：通过协方差矩阵计算节点之间的相似性。

#### 3.2 系统性风险的传播模型

##### 3.2.1 系统性风险的传播机制
系统性风险通常通过金融网络中的直接和间接关联传播。

##### 3.2.2 基于图的系统性风险传播模型
- **直接传播**：相邻节点之间的风险传播。
- **间接传播**：通过多步传播将风险扩散到整个网络。

##### 3.2.3 系统性风险传播的数学表达
$$ R_i = \sum_{j \in N(i)} \alpha_{ij} R_j $$
其中，$R_i$ 表示节点 $i$ 的风险值，$N(i)$ 表示节点 $i$ 的邻居节点，$\alpha_{ij}$ 表示传播系数。

#### 3.3 图表示学习在系统性风险中的应用

##### 3.3.1 图表示学习在风险传播中的作用
通过图表示学习捕捉节点之间的关联性，从而更准确地预测风险传播路径。

##### 3.3.2 图表示学习在风险识别中的应用
利用图表示学习构建节点表示，识别具有高风险的节点。

##### 3.3.3 图表示学习在风险预警中的应用
实时更新节点表示，预警潜在的系统性风险。

#### 5.3 动态系统性风险的传播模型
$$ R_i(t) = \alpha R_i(t-1) + (1-\alpha) \sum_{j \in N(i)} \beta_{ij} R_j(t-1) $$
其中，$\alpha$ 是遗忘系数，$\beta_{ij}$ 是传播系数。

```python
import torch.nn as nn

# 定义图神经网络模型
class GNNModel(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(GNNModel, self).__init__()
        self.gcn = GCNLayer(input_dim, hidden_dim)
        self.fc = nn.Linear(hidden_dim, output_dim)
    
    def forward(self, x, adj):
        x = self.gcn(x, adj)
        x = self.fc(x)
        return x

# 定义图卷积层
class GCNLayer(nn.Module):
    def __init__(self, in_dim, out_dim):
        super(GCNLayer, self).__init__()
        self.weight = nn.Parameter(torch.FloatTensor(in_dim, out_dim))
    
    def forward(self, x, adj):
        x = torch.bmm(adj, x.unsqueeze(2)).squeeze(2)
        x = torch.mm(x, self.weight)
        return x
```
