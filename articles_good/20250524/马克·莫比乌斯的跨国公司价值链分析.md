## 第1章 背景介绍

### 1.1 跨国公司的定义与特点
跨国公司是指在多个国家设立分支机构或控股公司，进行跨国经营的企业。其特点包括全球化运营、多元化业务、复杂的组织结构和对本地化市场的适应能力。

价值链分析是一种通过分解企业内部和外部的价值创造过程，识别关键环节并优化资源配置的管理方法。其特点包括系统性、动态性和可操作性。

### 3.2 数学模型
莫比乌斯模型的数学公式如下：
$$
\text{总价值} = \sum_{i=1}^{n} (v_i \times w_i)
$$
其中，\(v_i\) 表示第 \(i\) 个环节的价值，\(w_i\) 表示权重。

### 3.3 代码实现
```python
def calculate_value_chain(data):
    value = 0
    for item in data:
        value += item['value'] * item['weight']
    return value

data = [
    {'value': 100, 'weight': 0.3},
    {'value': 80, 'weight': 0.5}
]
print(calculate_value_chain(data))  # 输出：74.0
```

```python
def optimize_supply_chain(data):
    optimized_data = []
    for item in data:
        optimized_item = {
            'value': item['value'],
            'new_weight': item['weight'] * 0.8
        }
        optimized_data.append(optimized_item)
    return optimized_data

data = [
    {'value': 100, 'weight': 0.3},
    {'value': 80, 'weight': 0.5}
]
optimized = optimize_supply_chain(data)
print(optimized)  # 输出：[{'value': 100, 'new_weight': 0.24}, {'value': 80, 'new_weight': 0.4}]
```
