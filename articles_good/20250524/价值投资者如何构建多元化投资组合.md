#### 8.2 投资组合优化的核心代码实现

- 8.2.1 均值-方差优化算法的实现
  - 使用scipy.optimize.minimize函数实现均值-方差优化
  - 代码示例：
    ```python
    import numpy as np
    from scipy.optimize import minimize

    def portfolio_optimization(returns):
        n = len(returns.columns)
        cov_matrix = returns.cov().values
        weights = np.ones(n) / n
        while True:
            portfolio_return = returns.dot(weights)
            portfolio_variance = weights.T.dot(cov_matrix).dot(weights)
            if portfolio_variance == 0:
                break
            # 使用均值-方差优化算法调整权重
            def objective(weights):
                return -weights.T.dot(returns.mean())
            constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
            result = minimize(objective, weights, constraints)
            weights = result.x
        return weights
    ```
- 8.2.2 资本资产定价模型（CAPM）的实现
  - 使用CAPM公式计算各资产的预期收益
  - 代码示例：
    ```python
    def capm(risk_free_rate, market_return, beta):
        expected_return = risk_free_rate + beta * (market_return - risk_free_rate)
        return expected_return
    ```
