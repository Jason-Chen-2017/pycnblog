# 第1章: 约翰·聂夫投资理念与小盘价值股背景

## 1.1 约翰·聂夫的投资哲学  
### 1.1.1 投资者的心理与行为分析  
约翰·聂夫认为，成功的投资需要在理性与感性之间找到平衡。他强调长期投资、分散风险和对市场情绪的深刻理解。  

### 1.1.2 小盘价值股的定义与特点  
小盘价值股是指市值较小、估值低于市场平均水平的股票。其特点包括：低市盈率（P/E）、低市净率（P/B）、高股息率和较高的安全边际。  

### 1.1.3 小盘价值股投资的历史与现状  
小盘价值股投资在历史上经历过多次周期性波动，但在长期来看，其回报率显著优于大盘股。  

## 1.2 小盘价值股的投资价值  
### 1.2.1 小盘股的市场定位与机会  
小盘股通常具有较高的增长潜力，因其市值较小，更容易通过内生增长实现价值提升。  

### 1.2.2 价值股的特征与优势  
价值股的核心特征包括低估值、高分红和较高的内在价值。其优势在于市场波动时的防御性较强。  

### 1.2.3 小盘价值股的长期回报分析  
研究表明，小盘价值股在长期表现上优于大盘成长股，尤其是在市场低迷时期，其防御性更加显著。  

## 1.3 本章小结  
约翰·聂夫的投资理念以基本面分析为核心，结合小盘价值股的低估值和高增长潜力，形成了独特的筛选标准。

# 第2章: 小盘价值股筛选标准的核心概念

## 2.1 筛选标准的背景与目标  
### 2.1.1 筛选标准的必要性  
为了避免盲目投资，筛选标准能够帮助投资者快速定位具备潜力的小盘价值股。  

### 2.1.2 筛选标准的目标与原则  
目标是筛选出具有低估值、高成长性和强竞争优势的股票。原则包括：低市盈率、低市净率、高股息率和财务健康。  

## 2.2 核心概念与联系  
### 2.2.1 筛选标准的核心要素  
1. 市盈率（P/E）：低于行业平均水平。  
2. 市净率（P/B）：低于行业平均水平。  
3. 股息率：高于行业平均水平。  
4. 净利润增长率：过去三年年均增长率不低于5%。  

### 2.2.2 核心要素之间的关系  
通过公式：  
$$ \text{筛选标准} = f(\text{P/E}, \text{P/B}, \text{股息率}, \text{净利润增长率}) $$  
可以看出，各指标相互补充，共同构成筛选模型。  

### 2.2.3 筛选标准的数学模型与公式  
以约翰·聂夫的筛选模型为例：  
$$ \text{筛选得分} = 0.4 \times (\text{P/E}) + 0.3 \times (\text{P/B}) + 0.2 \times (\text{股息率}) + 0.1 \times (\text{净利润增长率}) $$  

## 2.3 筛选标准的属性特征对比  
### 2.3.1 估值指标对比  
| 指标 | 标准值 |  
|------|--------|

### 2.3.2 财务指标对比

|--------------|--------|  
| 净利润增长率 | ≥5%    |

### 2.3.3 市场指标对比

## 5.2 系统核心实现源代码  
```python
import pandas as pd
import numpy as np

# 数据加载
df = pd.read_csv('stock_data.csv')

# 数据预处理
def calculate_score(row):
    pe = row['PE']
    pb = row['PB']
    dividend_yield = row['Dividend Yield']
    net_profit_growth = row['Net Profit Growth']
    return 0.4 * pe + 0.3 * pb + 0.2 * dividend_yield + 0.1 * net_profit_growth

# 计算得分
df['Score'] = df.apply(calculate_score, axis=1)

# 筛选结果
selected_stocks = df[df['Score'] > 70]
```
