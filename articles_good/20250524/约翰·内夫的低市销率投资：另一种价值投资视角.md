## 第一部分：低市销率投资的背景与基础

### 第1章：低市销率投资概述

#### 1.1 低市销率投资的定义与特点

- **1.1.1 低市销率投资的定义**
  - 低市销率投资是一种通过市销率（Price-to-Sales Ratio, PSR）指标来筛选具有较低估值的股票的投资策略。
  - PSR = 股票价格 / 营业收入（每股收入）

- **1.1.2 低市销率投资的核心特点**
  - 低市销率投资关注公司的收入而非利润，适合用于评估亏损公司或高增长行业的公司。
  - PSR < 1通常被视为低市销率的标志。

- **1.1.3 低市销率投资与传统价值投资的区别**
  - 传统价值投资侧重于市盈率（P/E）和市净率（P/B），而低市销率投资侧重于市销率。
  - PSR适用于评估亏损公司，而P/E适用于评估盈利公司。

#### 1.2 约翰·内夫的投资理念

- **1.2.1 约翰·内夫的生平简介**
  - 约翰·内夫是美国著名投资家，曾管理伯克希尔哈撒韦的投资组合。
  - 他以低市销率投资策略闻名，强调寻找被市场低估的股票。

- **1.2.2 内夫的投资哲学**
  - 内夫认为，市场先生的短期波动为投资者提供了以合理价格买入优质资产的机会。
  - 他注重长期投资，避免短期市场波动的干扰。

- **1.2.3 内夫对低市销率投资的贡献**
  - 内夫将市销率作为主要估值指标，提出了低市销率投资策略。
  - 他的策略强调对公司基本面的深入分析，而非市场情绪的驱动。

### 第2章：市销率（PSR）的计算与应用

#### 2.1 市销率的定义与计算方法

- **2.1.1 市销率的定义**
  - 市销率（PSR）= 股票价格 / 营业收入（每股收入）。
  - PSR衡量了市场对公司每股收入的估值。

- **2.1.2 市销率的计算公式**
  - PSR = 股票价格 / 营业收入。
  - PSR的计算需要考虑公司过去几年的平均营业收入，以平滑周期性波动。

- **2.1.3 市销率的应用场景**
  - 适用于亏损公司或高增长行业的公司。
  - 在评估公司未来增长潜力时，PSR比P/E更有效。

#### 2.2 市销率与市盈率的对比

- **2.2.1 市盈率的定义与计算**
  - 市盈率（P/E）= 股票价格 / 每股收益（EPS）。
  - P/E适用于评估盈利公司，而PSR适用于评估亏损公司。

- **2.2.2 市销率与市盈率的优缺点对比**
  | 指标 | 优点 | 缺点 |
  |------|------|------|
  | PSR | 适用于亏损公司，评估收入驱动型公司 | 不适用于高利润行业 |
  | P/E | 适用于盈利公司，反映盈利能力 | 不适用于亏损公司 |

- **2.2.3 何时选择市销率作为估值指标**
  - 当公司亏损时，PSR是更好的选择。
  - 在高增长行业，PSR能更好地反映公司价值。

### 第3章：低市销率投资的策略与实施

#### 3.1 低市销率投资的策略选择

- **3.1.1 确定投资目标与标准**

  - PSR < 1的公司被视为低市销率投资目标。

- **3.1.2 如何筛选低市销率股票**
  - 通过财务报表筛选PSR < 1的公司。
  - 考虑公司的行业地位、竞争优势和管理团队。

- **3.1.3 确定投资组合的构建方法**
  - 分散投资，降低风险。

#### 3.2 低市销率投资的实施步骤

## 第二部分：低市销率投资的数学模型与算法原理

### 第4章：市销率计算的数学模型

#### 4.1 市销率的计算公式

- **4.1.1 市销率的定义公式**
  $$ PSR = \frac{\text{股票价格}}{\text{每股收入}} $$

- **4.1.2 市销率的计算步骤**
  1. 收集目标公司的财务数据。
  2. 计算每股收入。
  3. 计算市销率。

- **4.1.3 市销率的数学表达式**
  $$ PSR = \frac{P}{S} $$

#### 4.2 市销率与股票价值的关系

- **4.2.1 市销率与股票价值的正向关系**
  - PSR越低，股票的相对价值越高。
  - PSR < 1通常被视为低估的标志。

- **4.2.2 市销率的阈值与投资决策**
  - PSR < 1：低估，值得买入。
  - 1 < PSR < 2：合理，值得持有。
  - PSR > 2：高估，值得卖出。

- **4.2.3 市销率的动态变化与投资机会**
  - PSR随市场波动而变化，提供投资机会。
  - 在市场下跌时，PSR可能低于1，提供买入机会。

### 第5章：低市销率投资的算法实现

#### 5.1 算法原理

- **5.1.1 算法目标**
  - 筛选出PSR < 1的股票，构建低市销率投资组合。

- **5.1.2 算法步骤**
  1. 收集目标公司的财务数据。
  2. 计算每股收入。
  3. 计算市销率。
  4. 筛选出PSR < 1的公司。
  5. 构建投资组合。

- **5.1.3 算法的输入与输出**
  - 输入：股票价格、每股收入。
  - 输出：PSR值、低市销率股票列表。

#### 5.2 算法实现的代码示例

```python
def calculate_psr(stock_price, revenue_per_share):
    psr = stock_price / revenue_per_share
    return psr

def low_psr_investment(stocks, stock_price_dict, revenue_dict):
    low_psr_stocks = []
    for stock in stocks:
        psr = calculate_psr(stock_price_dict[stock], revenue_dict[stock])
        if psr < 1:
            low_psr_stocks.append(stock)
    return low_psr_stocks

# 示例数据
stocks = ['A', 'B', 'C', 'D', 'E']
stock_price_dict = {'A': 50, 'B': 30, 'C': 40, 'D': 25, 'E': 60}
revenue_dict = {'A': 100, 'B': 50, 'C': 80, 'D': 30, 'E': 120}

# 筛选低市销率股票
low_psr = low_psr_investment(stocks, stock_price_dict, revenue_dict)
print("低市销率股票:", low_psr)
```

#### 7.2 系统实现代码

```python
def main():
    import sys
    from collections import defaultdict

    # 读取输入
    stocks = []
    stock_price = defaultdict(float)
    revenue_per_share = defaultdict(float)

    # 获取输入
    input_data = sys.stdin.read().split()
    idx = 0
    while idx < len(input_data):
        stock = input_data[idx]
        price = float(input_data[idx+1])
        revenue = float(input_data[idx+2])
        stocks.append(stock)
        stock_price[stock] = price
        revenue_per_share[stock] = revenue
        idx += 3

    # 筛选低市销率股票
    low_psr_stocks = []
    for stock in stocks:
        psr = stock_price[stock] / revenue_per_share[stock]
        if psr < 1:
            low_psr_stocks.append(stock)

    # 输出结果
    print("低市销率股票:", low_psr_stocks)

if __name__ == "__main__":
    main()
```
