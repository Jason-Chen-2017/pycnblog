## 第2章: 图神经网络的原理与算法

### 2.1 图神经网络的基本原理
- **图的表示与节点嵌入**：
  - **节点嵌入**：将节点映射到低维空间，保留节点的语义信息。
  - **边嵌入**：将边映射到低维空间，表示节点之间的关系。
- **图卷积网络（GCN）的原理**：
  - **邻域聚合**：通过聚合节点及其邻居的信息进行特征更新。
  - **传播机制**：通过多层传播捕捉长距离关系。
- **图注意力机制（GAT）的原理**：
  - **注意力权重**：根据节点的重要性动态分配注意力权重。
  - **自注意力机制**：通过全局注意力权重聚合邻居信息。

### 2.2 图神经网络的核心算法
- **GCN的数学模型**：
  $$ y = \sigma(A X X^T) $$
  - **A**：图的邻接矩阵。
  - **X**：节点的特征矩阵。
  - **σ**：激活函数。
- **GAT的注意力机制**：
  $$ \alpha_{ij} = \frac{e^{f_{\theta}(x_i, x_j)}}{\sum_{k \neq j} e^{f_{\theta}(x_i, x_k)}}} $$
  - **α_ij**：节点i对j的注意力权重。
  - **f_θ**：注意力函数。
- **图嵌入算法的对比分析**：
  - **GCN**：适用于规则的图结构，但难以捕捉长距离关系。
  - **GAT**：适用于不规则图结构，能够动态分配注意力权重。

### 2.3 图神经网络的训练与优化
- **图数据的预处理**：
  - **标准化**：归一化图的特征和边权重。
  - **分割**：将图数据划分为训练集、验证集和测试集。
- **图神经网络的训练策略**：
  - **批量训练**：将图数据分成小批量进行训练，减少内存占用。
  - **节点采样**：通过采样节点减少计算量。
- **模型优化**：
  - **超参数调优**：通过网格搜索或随机搜索优化学习率、批次大小等参数。
  - **正则化**：通过L2正则化防止过拟合。

class GAT(nn.Module):
    def __init__(self, in_channels, out_channels):
        super(GAT, self).__init__()
        self.W = nn.Parameter(torch.randn(in_channels, out_channels))
        self.A = nn.Parameter(torch.randn(out_channels, out_channels))

    def forward(self, x, adj):
        out = F.leaky_relu(x @ self.W)
        attention = F.softmax(out @ self.A, dim=1)
        out = (attention @ out.unsqueeze(-1)).squeeze(-1)
        return out
