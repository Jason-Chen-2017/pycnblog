### 第1章：价值投资的起源与核心理念

#### 1.1 价值投资的定义与核心要素

- **价值投资的定义**：价值投资是一种以低于其内在价值的价格购买优质股票的投资策略，旨在通过长期持有实现超额收益。
- **价值投资的核心要素**：
  1. **内在价值**：资产的内在价值是其未来现金流的现值。
  2. **安全边际**：以低于内在价值的价格购买资产，以降低风险。
  3. **长期视角**：关注企业的长期价值，而非短期市场波动。

#### 1.2 巴菲特的投资哲学

- **巴菲特的投资理念**：巴菲itore's investment philosophy revolves around purchasing undervalued companies with strong competitive advantages and holding them indefinitely.
- **巴菲特的价值观与投资观**：巴菲特强调企业质量、管理团队和长期盈利能力，而非短期市场波动。
- **巴菲特投资哲学的演变**：从早期的纯格雷厄姆式投资到后期融入芒格的多元思维模型，巴菲特的投资理念不断完善。

### 第2章：格雷厄姆的价值投资理论

#### 2.1 格雷厄姆的生平与贡献

- **格雷厄姆的生平简介**：本杰明·格雷厄姆（1894-1975）是20世纪最著名的价值投资者之一，他的著作《证券分析》奠定了价值投资的基础。
- **格雷厄姆的学术贡献**：格雷厄姆与戴维·多德共同撰写《证券分析》，提出内在价值和安全边际的概念。
- **格雷厄姆对巴菲特的影响**：巴菲特早期的投资理念深受格雷厄姆影响，尤其是安全边际和防御性投资策略。

#### 2.2 格雷厄姆的投资策略

- **防御性投资策略**：格雷厄姆主张通过购买低估股票，以确保投资的安全性和稳定性。
- **内在价值概念**：内在价值是企业未来现金流的现值，投资者应以低于内在价值的价格买入。
- **安全边际**：安全边际是买入价格与内在价值之间的差额，用于降低投资风险。

### 第3章：芒格的多元思维模型

#### 3.1 芒格的生平与贡献

- **芒格的生平简介**：查理·芒格（1924年生）是巴菲特的长期合作伙伴，他的多元思维模型深刻影响了巴菲特的投资理念。

#### 3.2 芒格的多元思维模型

- **多元思维模型的定义**：多元思维模型是一种通过多学科知识框架来分析问题的方法，强调横向思维和跨领域整合。
- **多元思维模型的核心要素**：

  2. **逆向思维**：从反方向思考问题，寻找市场的非共识性机会。

  ```python
  def calculate_intrinsic_value(company_financials):
      # 计算企业的未来现金流
      # 这是一个简化的实现，实际应用中需要更复杂的模型
      cash_flows = company_financials['未来现金流']
      discount_rate = company_financials['折现率']
      intrinsic_value = sum(cash_flows / (1 + discount_rate)**i for i in range(len(cash_flows)))
      return intrinsic_value

  def calculate_margin_of_safety(current_price, intrinsic_value):
      return intrinsic_value - current_price

  def investment_decision(company_data):
      intrinsic_value = calculate_intrinsic_value(company_data)
      margin_of_safety = calculate_margin_of_safety(company_data['当前价格'], intrinsic_value)
      if margin_of_safety > 0:
          return "买入"
      else:
          return "卖出"

  # 示例数据
  company_data = {
      '未来现金流': [100, 150, 200],
      '折现率': 0.08,
      '当前价格': 80
  }

  decision = investment_decision(company_data)
  print(f"投资决策：{decision}")
  ```
