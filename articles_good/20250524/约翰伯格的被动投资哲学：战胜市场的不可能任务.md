## 第一部分：被动投资的背景与基础

### 第1章：被动投资的定义与核心理念

#### 1.1 被动投资的定义

被动投资是一种投资策略，旨在通过跟踪市场指数而非主动选择个股来实现长期收益。其核心理念是相信市场是有效的，即市场价格反映了所有可获得的信息，因此试图通过主动管理超越市场回报几乎是不可能的。

##### 1.1.1 什么是被动投资
被动投资的核心在于“被动”——投资者不试图主动预测市场趋势或选择跑赢市场的个股，而是通过持有广泛分散的投资组合来跟踪市场指数的表现。

##### 1.1.2 被动投资的核心理念
- **市场有效性**：市场是有效的，价格反映了所有相关信息，因此主动投资难以长期跑赢市场。
- **分散化**：通过持有大量资产分散风险，降低特定资产或行业波动带来的影响。
- **低成本**：被动投资的费用较低，因为指数基金的管理费用远低于主动管理型基金。

##### 1.1.3 被动投资与主动投资的区别
| 方面         | 被动投资                        | 主动投资                        |
|--------------|---------------------------------|---------------------------------|
| 管理方式     | 跟踪指数，不主动选股            | 主动选股，试图跑赢市场          |
| 成本         | 低管理费                        | 高管理费                        |
| 风险         | 分散化风险低                    | 集中化风险高                    |
| 收益预期     | 期望与市场持平                | 期望跑赢市场                    |

#### 1.2 约翰·伯格的被动投资哲学

##### 1.2.1 约翰·伯格的生平简介
约翰·伯格（John C. Bogle）是被动投资的先驱，被誉为“指数基金之父”。他是先锋集团（Vanguard Group）的创始人，致力于推广低成本、分散化的投资方式。

##### 1.2.2 约翰·伯格的投资理念
- **长期投资**：伯格认为，短期市场波动无法预测，长期投资是实现财富增长的最佳方式。
- **分散化**：通过广泛分散投资降低风险，避免因个别资产表现不佳而影响整体收益。
- **低成本**：降低费用是提高投资回报的关键，指数基金的低成本使其成为理想的投资工具。

##### 1.2.3 约翰·伯格对被动投资的贡献
伯格创立了先锋集团，推出了第一只低成本指数基金——Vanguard 500 Index Fund，开创了被动投资的新纪元。

### 第2章：被动投资的历史与发展

#### 2.1 被动投资的起源

##### 2.1.1 被动投资的起源背景
20世纪60年代，随着市场有效性的理论逐渐被认可，被动投资开始兴起。投资者意识到，试图通过主动管理跑赢市场成本高且风险大。

##### 2.1.2 被动投资的早期实践
1975年，约翰·伯格创立先锋集团，并推出第一只指数基金，标志着被动投资的正式起步。

##### 2.1.3 被动投资的现代发展
随着技术的进步和市场的发展，被动投资逐渐普及，指数基金和其他被动投资工具成为投资者的主要选择。

#### 2.2 被动投资的核心理论

##### 2.2.1 市场有效性的理论基础
- **有效市场假说（EMH）**：市场参与者充分理性，价格反映所有信息，因此主动投资难以跑赢市场。
- **弱有效市场**：价格反映历史信息，但未来价格仍可通过分析预测。

##### 2.2.2 被动投资的数学模型
被动投资的核心是通过指数化分散风险，数学模型主要基于现代投资组合理论（MPT）。

#### 2.2.3 被动投资的经济原理
- **资本资产定价模型（CAPM）**：用于计算资产的预期收益，是被动投资的重要理论基础。
- **夏普比率**：衡量投资组合的风险调整后收益，用于评估被动投资的表现。

## 第二部分：指数基金的投资策略

### 第3章：指数基金的投资策略

#### 3.1 指数基金的定义与特点

##### 3.1.1 指数基金的定义
指数基金是一种跟踪特定市场指数的基金，其投资组合按照指数成分股的权重配置。

##### 3.1.2 指数基金的特点
- **分散化**：涵盖广泛市场，降低特定资产风险。
- **低成本**：管理费用低，适合长期投资。
- **简单易懂**：投资者无需选股，只需选择合适的指数基金。

#### 3.2 被动投资的组合管理

##### 3.2.1 投资组合的构建方法
- **广泛分散**：涵盖多个资产类别和市场，降低风险。
- **定期再平衡**：定期调整投资组合，保持与指数一致。

##### 3.2.2 投资组合的调整策略
- **定期检查**：根据市场变化调整权重，确保与指数一致。
- **税务优化**：通过税收亏损 harvesting 降低税务负担。

##### 3.2.3 投资组合的风险管理
- **风险分散**：通过多样化降低特定风险。
- **长期视角**：短期波动不影响长期收益。

### 第4章：被动投资的数学模型与算法

#### 4.1 被动投资的数学模型

##### 4.1.1 被动投资的CAPM模型
CAPM公式：$$ E(R_i) = R_f + β_i (E(R_m) - R_f) $$
其中，\( E(R_i) \) 是资产的预期收益，\( R_f \) 是无风险利率，\( β_i \) 是资产的贝塔系数，\( E(R_m) \) 是市场预期收益。

##### 4.1.2 被动投资的APT模型
套利定价理论（APT）：$$ E(R_i) = \sum_{j=1}^n λ_j x_{ij} + R_f $$
其中，\( x_{ij} \) 是资产对第 \( j \) 个因素的敏感性，\( λ_j \) 是第 \( j \) 个因素的风险溢价。

#### 4.2 被动投资的算法实现

##### 4.2.1 被动投资的算法原理
- **指数跟踪**：通过复制指数成分股的权重，实现指数表现的跟踪。
- **成本优化**：通过降低交易费用和管理费用，提高净收益。

##### 4.2.2 被动投资的算法实现
以下是Python实现的简单指数基金跟踪算法：

```python
import pandas as pd
import numpy as np

# 假设指数权重数据
index_weights = pd.Series([0.2, 0.3, 0.1, 0.15, 0.25], index=['A', 'B', 'C', 'D', 'E'])

# 投资组合初始化
portfolio = index_weights.copy()

# 每月再平衡函数
def rebalance(weights, portfolio):
    target = weights / weights.sum()
    rebalanced = target * portfolio.sum()
    return rebalanced

# 模拟一年的再平衡
for _ in range(12):
    portfolio = rebalance(index_weights, portfolio)

print("最终投资组合:", portfolio)
```

##### 7.2.2 投资组合风险评估

```python
import pandas as pd
import numpy as np

# 假设投资组合收益和市场收益
portfolio_returns = pd.Series([0.05, 0.03, 0.07, 0.04, 0.06])
market_returns = pd.Series([0.06, 0.05, 0.07, 0.04, 0.08])

# 计算夏普比率
def sharpe_ratio(portfolio, market, risk_free_rate):
    portfolio_excess = portfolio - risk_free_rate
    market_excess = market - risk_free_rate
    return (portfolio_excess.mean() / market_excess.std()) if market_excess.std() != 0 else 0

sharpe = sharpe_ratio(portfolio_returns, market_returns, 0.02)
print("夏普比率:", sharpe)
```
