## 第3章：社交网络影响力分析基础

### 3.1 影响力传播模型

#### 3.1.1 主流影响力传播模型对比
| 模型 | 描述               | 优缺点                |
|------|--------------------|-----------------------|
| 感染模型 | 节点依次感染       | 简单，但不考虑权重     |
| 最大影响力 | 选择影响力最大的节点 | 快速，但可能不够准确   |
| 模拟传播 | 模拟传播过程       | 精确，但计算复杂       |

#### 3.1.2 影响力传播模型的数学表达
$$ I(t+1) = \sum_{i} w_{i} \cdot I_i(t) $$

其中，$I(t)$ 表示时间 $t$ 时的影响力，$w_i$ 是权重。

#### 6.2.2 核心代码实现

```python
import networkx as nx
from sklearn.feature_extraction.text import TfidfVectorizer

# 数据预处理
def preprocess(text):
    return text.lower().strip()

# 文本特征提取
def extract_features(texts):
    vectorizer = TfidfVectorizer()
    features = vectorizer.fit_transform(texts)
    return features

# 影响力计算
def compute_influence(features):
    graph = nx.Graph()
    # 添加节点和边
    nodes = features.shape[0]
    for i in range(nodes):
        for j in range(i+1, nodes):
            graph.add_edge(i, j, weight=features[i,j])
    return graph

# 投资决策
def investment_decision(graph, weights):
    # 假设 weights 是影响力权重
    max_influence = max(weights)
    return max_influence
```
