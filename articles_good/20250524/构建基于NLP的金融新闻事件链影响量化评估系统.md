# 第1章 问题背景与需求分析

## 1.1 问题背景

### 1.1.1 金融新闻事件链的定义与特点
金融新闻事件链是指一系列与金融市场相关的新闻事件，这些事件之间存在因果关系或相关性。例如，一家公司发布的财务报告可能引发股价波动，进而影响市场整体走势。事件链的特点包括时间序列性、关联性和影响力递增性。

### 1.1.2 事件链对金融市场的影响
事件链能够影响市场的参与者决策，进而改变资产价格和市场走势。例如，负面新闻可能引发股价下跌，而积极消息则可能推动股价上涨。

### 1.1.3 当前金融分析的局限性
传统金融分析方法依赖于历史数据和统计模型，难以捕捉新闻中的隐含信息和情感因素。因此，事件链的影响往往被低估或遗漏。

## 1.2 问题描述

### 1.2.1 事件链量化评估的必要性
为了准确评估新闻事件对市场的影响，需要将事件链的影响进行量化，以便更好地指导投资决策。

### 1.2.2 现有技术的不足
传统方法难以从海量新闻中提取关键信息，且缺乏对事件链关系的建模。

### 1.2.3 构建系统的目标与意义
目标是构建一个能够自动分析金融新闻，量化事件链影响的系统。意义在于提高金融分析的效率和准确性，帮助投资者做出更明智的决策。

### 2.1.2 事件链的组成要素
事件链由事件、时间、影响程度组成，各要素之间存在因果关系。

## 2.2 核心概念属性对比

| 实体 | 属性 | 类型 | 示例 |
|------|------|------|------|
| 公司 | 名称 | 字符串 | 腾讯 |
| 事件 | 类型 | 字符串 | 财务报告发布 |
| 市场指数 | 值 | 浮点数 | 3000.01 |

## 2.3 核心概念的数学模型

### 2.3.1 事件链的表示模型
$$事件链 = \{ (e_1, t_1), (e_2, t_2), ..., (e_n, t_n) \}$$

其中，$e_i$表示事件，$t_i$表示事件发生时间。

### 2.3.2 事件链权重计算公式
$$权重 = \sum_{i=1}^{n} (影响程度_i \times 时间权重_i)$$

### 2.3.3 影响量化评估公式
$$影响评估 = \sum_{i=1}^{m} (权重_i \times 影响范围_i)$$

### 5.2.1 事件提取代码

```python
import spacy

nlp = spacy.load("en_core_web_sm")

def extract_events(text):
    doc = nlp(text)
    events = []
    for sent in doc.sents:
        events.append(sent.text)
    return events
```
