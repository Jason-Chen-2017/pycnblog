#### 6.2 核心实现源代码
- 6.2.1 均值-方差优化模型的实现
  ```python
  import numpy as np
  from scipy.optimize import minimize

  def portfolio_optimization(returns):
      n = len(returns.columns)
      def objective(weights, returns):
          return np.dot(weights.T, returns.mean())  # 最大化预期收益
      def constraint(weights, returns):
          return np.dot(weights.T, weights) - 1  # 权重之和为1
      # 初始化权重向量
      init_weights = np.array([1.0/n]*n)
      # 使用SLSQP求解器
      result = minimize(objective, init_weights, args=(returns,), method='SLSQP', 
                        constraints={'type': 'eq', 'fun': lambda w: np.sum(w) - 1})
      return result.x
  ```
