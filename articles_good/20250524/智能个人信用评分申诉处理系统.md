## 2.2 数学模型与公式

### 2.2.1 逻辑回归公式
$$ P(y=1|x) = \frac{1}{1 + e^{- (w \cdot x + b)}} $$

### 2.2.2 XGBoost损失函数
$$ \text{损失函数} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$`

## 2.3 算法优缺点对比

### 2.3.1 逻辑回归
- 优点：简单、解释性强
- 缺点：对复杂关系建模能力有限

### 2.3.2 XGBoost
- 优点：高精度、鲁棒性强
- 缺点：计算复杂度高

### 4.2.1 数据预处理

```python
import pandas as pd
import numpy as np

# 加载数据
data = pd.read_csv('credit.csv')

# 数据清洗
data = data.dropna()
data = pd.get_dummies(data)
```

### 4.2.2 构建逻辑回归模型
```python
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

# 划分数据集
X_train, X_test, y_train, y_test = train_test_split(data.drop('score', axis=1), data['score'], test_size=0.2)

# 训练模型
model = LogisticRegression()
model.fit(X_train, y_train)

# 预测
predictions = model.predict(X_test)
```

### 4.2.3 构建XGBoost模型
```python
import xgboost as xgb

# 转换数据格式
dtrain = xgb.DMatrix(X_train, label=y_train)
dtest = xgb.DMatrix(X_test, label=y_test)

# 训练模型
params = {'max_depth': 3, 'eta': 0.2, 'objective': 'binary:logistic'}
model = xgb.train(params, dtrain, num_boost_round=5)

# 预测
predictions = model.predict(dtest)
```
