# 第1章 格雷厄姆价值投资理论的核心概念

## 1.1 价值投资的基本定义

### 1.1.1 价值投资的起源与发展

- **定义**：价值投资是一种以低于股票内在价值的价格购买股票的投资策略。
- **历史背景**：起源于20世纪20年代，本杰明·格雷厄姆是该理论的奠基人。
- **发展**：经过沃伦·巴菲特等投资者的发展，价值投资理论不断完善。

### 1.1.2 格雷厄姆的价值投资理念

- **核心理念**：寻找市场先生的错误定价，以安全边际为核心。
- **安全边际**：购买价格低于内在价值的折扣部分，确保投资的安全性。
- **内在价值**：公司未来现金流的现值，计算公式为：
  $$
  \text{内在价值} = \frac{\text{每股收益} \times (5 + \text{增长率})}{\text{资本成本}}
  $$

### 1.1.3 价值投资的核心原则

- **长期投资**：避免短期市场波动的干扰。
- **安全边际**：确保买入价格远低于内在价值。
- **分散投资**：降低单一投资的风险。

### 1.2.2 格雷厄姆理论在新兴市场的适用性

- **挑战**：市场波动大、信息不透明、政策风险高。

### 1.2.3 新兴市场中的投资机会

- **低估股票**：新兴市场中许多公司估值低于其实际价值。
- **成长机会**：新兴市场经济增长快，具备长期增长潜力。

# 第2章 格雷厄姆价值投资理论的数学模型与算法

## 2.1 股票内在价值的计算公式

### 2.1.1 格雷厄姆的内在价值公式

- **公式**：
  $$
  \text{内在价值} = \frac{\text{每股收益} \times (5 + \text{增长率})}{\text{资本成本}}
  $$

### 2.1.2 案例分析：如何计算一家公司的内在价值

- **案例**：假设某公司每股收益为10元，增长率5%，资本成本为10%。
  $$
  \text{内在价值} = \frac{10 \times (5 + 5)}{10} = 10 \text{元}
  $$

## 2.2 安全边际的数学模型

### 2.2.1 安全边际的计算公式

- **公式**：
  $$
  \text{安全边际} = \text{内在价值} - \text{市场价格}
  $$

### 2.2.2 如何选择具有安全边际的股票

- **选择标准**：市场价格低于内在价值，且安全边际越大越好。

## 2.3 价值投资组合的优化算法

### 2.3.1 投资组合优化的数学模型

- **目标函数**：
  $$
  \text{最大化收益} - \text{最小化风险}
  $$

### 2.3.2 使用Python进行投资组合优化的代码示例

```python
import numpy as np
from scipy.optimize import minimize

# 示例代码：简单投资组合优化
def portfolio_value(weights, returns):
    return -sum(weights * returns)

weights = np.array([0.5, 0.5])
returns = np.array([0.1, 0.2])

result = minimize(portfolio_value, weights, method='SLSQP')
print(result)
```

```python
import pandas as pd
import numpy as np
import requests

def get_stock_data(ticker):
    url = f"https://query1.finance.yahoo.com/ws/v1/finance/quote/{ticker}"
    response = requests.get(url)
    data = response.json()
    return pd.DataFrame(data['quoteResponse']['result'][0])
```

### 5.2.2 数据分析代码

```python
def calculate_intrinsic_value(ticker):
    data = get_stock_data(ticker)
    earnings_per_share = data['eps'][0]
    growth_rate = 5  # 假设增长率为5%
    capital_cost = 0.12  # 假设资本成本为12%
    intrinsic_value = (earnings_per_share * (5 + growth_rate)) / capital_cost
    return intrinsic_value
```

### 5.2.3 投资策略代码

```python
def generate_portfolio(tickers):
    portfolio = []
    for ticker in tickers:
        iv = calculate_intrinsic_value(ticker)
        price = get_stock_price(ticker)
        if price < iv * 0.8:  # 安全边际为20%
            portfolio.append(ticker)
    return portfolio
```
