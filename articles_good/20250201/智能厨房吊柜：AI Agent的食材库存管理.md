```python
import numpy as np

# 去噪：使用移动平均滤波
def moving_average(data, window_size):
    return np.convolve(data, np.ones(window_size)/window_size, mode='valid')

# 数据归一化
def normalize_data(data):
    min_val = np.min(data)
    max_val = np.max(data)
    return (data - min_val) / (max_val - min_val)
```

### 决策算法

在预测出食材的保质期和库存量后，决策算法将根据预测结果生成提醒和补货计划。以下是决策算法的流程：

3. **生成补货计划**：根据用户的购物历史和库存预测，生成补货计划。

4. **执行计划**：根据生成的补货计划，执行相应的购买操作。

```python
# 设定阈值
expiration_threshold = 2  # 保质期阈值（天）

def generate_plan(expiration_pred, inventory_pred):

    else:
        replenishment_plan = "库存充足，无需购买。"

    return reminder_message, replenishment_plan

# 执行计划
def execute_plan(reminder_message, replenishment_plan):
```
