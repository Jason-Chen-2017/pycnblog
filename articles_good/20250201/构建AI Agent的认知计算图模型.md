**2. 知识图谱构建**  
```python
import networkx as nx

# 创建图结构
knowledge_graph = nx.Graph()

# 添加节点和边
for index, row in course_data.iterrows():
    knowledge_graph.add_node(row['course_id'], course_name=row['course_name'])
    knowledge_graph.add_edge(row['course_id'], row['teacher_id'])

# 添加用户节点
for index, row in user_behavior.iterrows():
    knowledge_graph.add_node(row['user_id'], user_name=row['user_name'])
    knowledge_graph.add_edge(row['user_id'], row['course_id'])
```

**3. 推荐算法实现**  
```python
from sklearn.metrics.pairwise import cosine_similarity

# 计算用户与课程之间的相似度
user_course_similarity = cosine_similarity(knowledge_graph.nodes.data('weight'))

# 推荐课程
def recommend_courses(user_id, top_n=5):
    user_similarity = user_course_similarity[user_id]
    sorted_indices = user_similarity.argsort()[::-1]
    recommended_courses = [knowledge_graph.nodes[i]['course_name'] for i in sorted_indices if i != user_id]
    return recommended_courses[:top_n]
```
