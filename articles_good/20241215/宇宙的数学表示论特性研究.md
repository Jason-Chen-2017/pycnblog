## 引言与背景介绍

### 1.1 宇宙的定义与历史发展

宇宙（Universe）指的是包含一切物质、能量、时空和信息的宏观宇宙，它是自然界中最广阔的概念。自古以来，人类对宇宙的认识不断深入，从早期的地心说到哥白尼的日心说，再到现代宇宙学的建立，宇宙观念经历了巨大的变革。

在古希腊时期，亚里士多德提出了地心说，认为地球是宇宙的中心，所有天体都围绕地球旋转。这一观念统治了西方天文学长达两千年。直到16世纪，哥白尼提出了日心说，认为太阳是宇宙的中心，行星围绕太阳旋转。这一革命性的观点对天文学和哲学产生了深远的影响。

进入20世纪，宇宙学发展迅速，爱因斯坦的广义相对论为理解宇宙提供了新的框架。广义相对论揭示了时空的弯曲性质，并预测了引力波的存在。随着观测技术的进步，人类发现了宇宙膨胀、暗物质和暗能量等现象，对宇宙的认识达到了前所未有的深度。

### 1.2 宇宙的观测与理论框架

宇宙的观测主要通过电磁波、粒子探测和引力波等方式进行。电磁波观测包括可见光、红外、紫外、X射线和伽马射线等。粒子探测包括宇宙射线和卫星观测。引力波观测则是近年来宇宙学研究的重要进展。

当前宇宙学的主要理论框架包括大爆炸理论、宇宙背景辐射、宇宙膨胀、暗物质和暗能量等。大爆炸理论认为宇宙起源于一个极其热密的初始状态，随后经历膨胀和冷却过程。宇宙背景辐射是宇宙大爆炸后残留的辐射，其观测为这一理论提供了强有力的支持。

宇宙膨胀是宇宙学研究的重要主题。哈勃定律揭示了宇宙中距离越远的星系运动速度越快，这表明宇宙正在加速膨胀。暗物质和暗能量是宇宙学中的两大谜团。暗物质不发光，但通过引力影响宇宙结构，其存在通过星系旋转曲线和宇宙大尺度结构得到证实。暗能量则是推动宇宙加速膨胀的神秘力量，其性质和起源仍是宇宙学研究的前沿问题。

import numpy as np

def blackbody_distribution(T, x):
    """
    计算黑体辐射分布函数
    T: 温度（开尔文）
    x: 波长（米）
    """
    h = 6.62607015e-34  # 普朗克常数
    c = 3e8              # 光速
    k = 1.380649e-23    # 玻尔兹曼常数

    xavenu = h * c / x
    expTerm = np.exp(xavenu / k / T)
    distribution = (1 / (np.exp(xavenu / k) - 1)) * (1 / x**2)
    return distribution

# 计算特定温度下的黑体辐射分布
T = 2.725e-5  # 宇宙微波背景辐射的温度
x = np.linspace(1e-4, 1e5, 1000)  # 波长范围
distribution = blackbody_distribution(T, x)

# 绘制黑体辐射分布
import matplotlib.pyplot as plt
plt.plot(x, distribution)
plt.xlabel('Wavelength (m)')
plt.ylabel('Blackbody Distribution')
plt.title('Blackbody Radiation Distribution at T = {:.2e} K'.format(T))
plt.show()
```

- **物理常量**：代码中定义了普朗克常数`h`、光速`c`和玻尔兹曼常数`k`，这些都是计算黑体辐射分布所需的基本物理常量。
