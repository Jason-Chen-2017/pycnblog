### 2. 社交网络分析基础

#### 2.1 社交网络分析概述

社交网络分析是一种利用图论和网络科学方法研究社交网络结构和动态的学科。其核心目的是揭示社交网络中的结构特征和关系模式。

#### 2.2 社交网络的定义与类型

社交网络是由个体（节点）及其相互关系（边）组成的复杂网络。根据网络的特征，社交网络可分为以下类型：

- **无向图**：个体间关系不具有方向性。
- **有向图**：个体间关系具有方向性。
- **加权图**：边具有权重。
- **无权图**：边无权重。

#### 2.3 社交网络的图论基础

图论是研究图的结构、性质和应用的数学分支。在社交网络分析中，图论方法用于描述和分析社交网络。

- **图的基本概念**：节点、边、度、路径等。
- **图的运算**：连接、合并、子图等。
- **图的算法**：最短路径、最大流、社区检测等。

#### 2.4 社交网络中的关键指标

社交网络分析中的关键指标包括：

- **度分布**：节点度的统计分布。
- **聚类系数**：节点之间连接的紧密程度。
- **平均路径长度**：节点间平均距离。
- **网络密度**：网络中边的数量与可能最大数量的比值。

#### 4.2 Python代码阐述

使用Python代码实现人际关系数学模型的构建：

```python
import networkx as nx

# 创建无向图
G = nx.Graph()

# 添加节点和边
G.add_nodes_from([1, 2, 3])
G.add_edges_from([(1, 2), (2, 3), (3, 1)])

# 计算度
degrees = nx.degree(G)

# 计算关系强度
weights = [1 if i == j else 0 for i, j in G.edges()]

# 输出结果
print("节点度：", degrees)
print("关系强度：", weights)
```

#### 4.3 数学模型与公式详细讲解

人际关系数学模型可以表示为：

\[ R = \sum_{i,j} w_{ij} \cdot d_i \cdot d_j \]

其中，\( R \) 表示关系强度，\( w_{ij} \) 表示边 \( i \) 和 \( j \) 的权重，\( d_i \) 和 \( d_j \) 表示节点 \( i \) 和 \( j \) 的度。

#### 4.4 举例说明

以一个简单的社交网络为例，说明人际关系数学模型的构建和应用：

- 节点：A、B、C
- 边：A-B、B-C、C-A
- 关系强度：权重为1

根据公式，计算关系强度：

\[ R_{AB} = w_{AB} \cdot d_A \cdot d_B = 1 \cdot 2 \cdot 2 = 4 \]

\[ R_{BC} = w_{BC} \cdot d_B \cdot d_C = 1 \cdot 2 \cdot 2 = 4 \]

\[ R_{CA} = w_{CA} \cdot d_C \cdot d_A = 1 \cdot 2 \cdot 2 = 4 \]

关系强度均为4，表示节点A、B、C之间的关系较强。

#### 7.2 系统核心实现源代码

以下是一个简单的系统实现示例：

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建无向图
G = nx.Graph()

# 添加节点和边
G.add_nodes_from([1, 2, 3])
G.add_edges_from([(1, 2), (2, 3), (3, 1)])

# 计算度
degrees = nx.degree(G)

# 计算关系强度
weights = [1 if i == j else 0 for i, j in G.edges()]

# 绘制图
nx.draw(G, with_labels=True)
plt.show()

# 输出结果
print("节点度：", degrees)
print("关系强度：", weights)
```
