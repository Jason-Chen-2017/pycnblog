### 2.1 优化算法概述

#### 2.1.1 优化算法的定义与分类

优化算法是指通过数学方法求解最优解的过程。常见的优化算法包括确定性算法和随机性算法两大类。确定性算法如梯度下降法、牛顿法等；随机性算法如遗传算法、模拟退火算法等。

### 2.2 梯度下降法

#### 2.2.1 梯度下降法的定义与原理

梯度下降法是一种常用的优化算法，其基本思想是沿着目标函数的梯度方向更新参数，以最小化目标函数。

#### 2.2.2 梯度下降法的数学模型

梯度下降法的数学模型可以表示为：$$ x_{\text{new}} = x_{\text{old}} - \alpha \cdot \nabla f(x_{\text{old}}) $$，其中，$ x_{\text{old}} $ 和 $ x_{\text{new}} $ 分别表示当前迭代点和下一迭代点，$ \alpha $ 是步长，$ \nabla f(x_{\text{old}}) $ 是目标函数在 $ x_{\text{old}} $ 处的梯度。

#### 2.2.3 梯度下降法的例子

以一维函数 $ f(x) = x^2 $ 为例，梯度下降法的迭代过程如下：

1. 初始化：选择一个初始点 $ x_0 $，例如 $ x_0 = 2 $。
2. 沿着梯度方向更新：$$ x_{\text{new}} = x_{\text{old}} - \alpha \cdot \nabla f(x_{\text{old}}) $$
3. 重复步骤2，直到收敛。

通过计算可以发现，随着迭代次数的增加，$ x_{\text{new}} $ 逐渐逼近最优解 $ x = 0 $。

#### 2.3.2 遗传算法的数学模型

遗传算法的数学模型包括以下几个关键组成部分：

1. **种群表示**：将解表示为一个个体的基因序列。
2. **适应度函数**：评估个体优劣的函数，通常为目标函数的相反数。
3. **选择**：根据适应度函数选择优质个体进行繁殖。
4. **交叉**：将两个优质个体的基因序列进行随机组合，生成新个体。
5. **变异**：对个体基因序列进行随机修改，以增加搜索的多样性。

#### 2.3.3 遗传算法的例子

2. **适应度评估**：计算种群中每个个体的适应度值，$ f(x_i) $。

import numpy as np

def gradient_descent(x0, alpha, n_iterations):

    for _ in range(n_iterations):
        gradient = 2 * x
        x_new = x - alpha * gradient
        x = x_new
    return x
