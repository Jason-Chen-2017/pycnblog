## 第2章：区块链技术概述

### 2.1 区块链的基本概念

区块链技术是一种分布式数据库系统，通过密码学和共识算法确保数据的不可篡改性和安全性。区块链最初由中本聪（Satoshi Nakamoto）提出，并作为比特币（Bitcoin）的基础技术被广泛应用。以下是区块链的一些基本概念：

1. **区块（Block）**：区块链的基本单元，包含一定数量的交易记录。每个区块都有一个唯一的标识符（哈希值），并且通过加密算法与前一个区块相连，形成链式结构。
2. **链（Chain）**：区块链的名称来源于其链式结构。新产生的区块会附加到区块链的末端，形成一条不断延伸的链。
3. **节点（Node）**：参与区块链网络计算和交易的计算机。每个节点都维护一份完整的区块链副本，并通过共识算法验证和传播交易。
4. **交易（Transaction）**：区块链上的数据交换行为，记录在区块中。交易可以是货币转账、信息记录等，具有不可篡改性和透明性。
5. **挖矿（Mining）**：通过计算解决数学难题，验证和添加新区块到区块链的过程。挖矿是区块链网络中的关键环节，用于确保区块链的安全性和稳定性。
6. **共识算法（Consensus Algorithm）**：区块链网络中的节点通过共识算法达成共识，确保区块链上所有节点的状态一致。常见的共识算法包括工作量证明（PoW）、权益证明（PoS）等。

```python
import json
from time import time

class Block:
    def __init__(self, index, transactions, timestamp, previous_hash):
        self.index = index
        self.transactions = transactions
        self.timestamp = timestamp
        self.previous_hash = previous_hash
        self.hash = self.compute_hash()

    def compute_hash(self):
        block_string = json.dumps(self.__dict__, sort_keys=True)
        return hashlib.sha256(block_string.encode()).hexdigest()

class Blockchain:
    def __init__(self):
        self.unconfirmed_transactions = []  # 未确认交易
        self.chain = []  # 区块链
        self.current_transactions = []  # 当前交易
        self.create_genesis_block()

    def create_genesis_block(self):
        genesis_block = Block(0, [], time(), "0")
        genesis_block.hash = genesis_block.compute_hash()
        self.chain.append(genesis_block)

    def add_new_transaction(self, transaction):
        self.unconfirmed_transactions.append(transaction)

    def mine(self):
        if not self.unconfirmed_transactions:
            return False

        last_block = self.chain[-1]
        new_block = Block(index=last_block.index + 1,
                          transactions=self.current_transactions,
                          timestamp=time(),
                          previous_hash=last_block.hash)

        proof = self.proof_of_work(new_block)
        new_block.hash = new_block.compute_hash()

        self.current_transactions = []
        self.chain.append(new_block)

        return new_block

    @staticmethod
    def proof_of_work(block):
        target = "0" * 64  # 以64个零为目标
        while True:
            hash = block.compute_hash()
            if hash.startswith(target):
                return hash
            else:
                block.nonce += 1

    def is_chain_valid(self, chain):
        for i in range(1, len(chain)):
            current = chain[i]
            previous = chain[i - 1]

            if current.hash != current.compute_hash():
                return False
            if current.previous_hash != previous.hash:
                return False

        return True

# 创建区块链实例

# 添加新交易

blockchain.add_new_transaction({"from": "Bob", "to": "Charlie", "amount": 5})

# 挖掘新区块
```

```python
import hashlib
import json
from time import time

class Block:
    def __init__(self, index, transactions, timestamp, previous_hash):
        self.index = index
        self.transactions = transactions
        self.timestamp = timestamp
        self.previous_hash = previous_hash
        self.hash = self.compute_hash()

    def compute_hash(self):
        block_string = json.dumps(self.__dict__, sort_keys=True)
        return hashlib.sha256(block_string.encode()).hexdigest()

class Blockchain:
    def __init__(self):
        self.chain = []
        self.current_transactions = []
        self.create_genesis_block()

    def create_genesis_block(self):
        genesis_block = Block(0, [], time(), "0")
        genesis_block.hash = genesis_block.compute_hash()
        self.chain.append(genesis_block)

    def add_new_transaction(self, transaction):
        self.current_transactions.append(transaction)

    def mine(self):
        if not self.current_transactions:
            return False

        last_block = self.chain[-1]
        new_block = Block(index=last_block.index + 1,
                          transactions=self.current_transactions,
                          timestamp=time(),
                          previous_hash=last_block.hash)

        proof = self.proof_of_work(new_block)
        new_block.hash = new_block.compute_hash()

        self.current_transactions = []
        self.chain.append(new_block)

        return new_block

    @staticmethod
    def proof_of_work(block):
        target = "0" * 64  # 以64个零为目标
        while True:
            hash = block.compute_hash()
            if hash.startswith(target):
                return hash
            else:
                block.nonce += 1

    def is_chain_valid(self, chain):
        for i in range(1, len(chain)):
            current = chain[i]
            previous = chain[i - 1]

            if current.hash != current.compute_hash():
                return False
            if current.previous_hash != previous.hash:
                return False

        return True

# 创建区块链实例

# 添加新交易
blockchain.add_new_transaction({"from": "Alice", "to": "Bob", "amount": 10})
blockchain.add_new_transaction({"from": "Bob", "to": "Charlie", "amount": 5})

# 打印区块链
```

#### 11.1.2 代码应用与分析

1. **区块生成**：在`Blockchain`类的`create_genesis_block`方法中，我们创建了一个创世区块，作为区块链的起点。创世区块的索引为0，包含空交易列表，前一个区块哈希值为0。

2. **交易添加**：通过`add_new_transaction`方法，我们可以将新交易添加到当前未确认交易列表中。这些交易将在下一次挖掘新区块时被包含进去。
