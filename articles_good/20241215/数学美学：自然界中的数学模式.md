### 第3章：数学模式在自然界中的对称性

#### 对称性的概念与类型

对称性是数学模式在自然界中的一个重要特征，它反映了事物在某种变换下保持不变的性质。对称性可以分为几种基本类型，包括点对称、轴对称、旋转对称和反射对称。

1. **点对称**：当一个物体围绕一个固定点旋转180度后，看起来与原来的物体完全相同，这种对称性称为点对称。例如，许多昆虫的腹部呈现出点对称的结构。

2. **轴对称**：当一个物体沿着一条直线（称为对称轴）翻转后，看起来与原来的物体完全相同，这种对称性称为轴对称。例如，人类的双手和双足都是轴对称的。

3. **旋转对称**：当一个物体围绕某个点旋转一定角度后，看起来与原来的物体完全相同，这种对称性称为旋转对称。例如，许多植物的叶子和花朵都具有旋转对称的特点。

4. **反射对称**：当一个物体沿着一条直线翻转后，看起来与原来的物体镜像对称，这种对称性称为反射对称。例如，许多动物的羽毛和鳞片都呈现出反射对称的结构。

#### 对称性在自然界中的应用

   - **动物体的对称性**：许多动物体，如蝴蝶和青蛙，都具有左右对称的结构。这种对称性有助于动物在捕食和逃避天敌时的灵活性和精确性。

2. **地球科学中的对称性**：

3. **天文学中的对称性**：
   - **星系对称性**：许多星系，如螺旋星系和椭圆星系，都具有对称性。这种对称性是星系在宇宙中演化的结果。

```python
# fibonacci.py

def fibonacci(n):
    sequence = []
    a, b = 0, 1
    while len(sequence) < n:
        sequence.append(a)
        a, b = b, a + b
    return sequence

def plot_fibonacci(n):
    sequence = fibonacci(n)
    with open('fibonacci.mmd', 'w') as f:
        f.write(f"""
        graph TB
        A[{n}-Term Fibonacci Sequence] --> B{sequence[0]}
        B{sequence[0]} --> C{sequence[1]}
        B{sequence[1]} --> D{sequence[2]}
        B{sequence[2]} --> E{sequence[-1]}
        """)
    !mermaid fibonacci.mmd

# 示例：生成前10个斐波那契数列并绘制图表
plot_fibonacci(10)
```
