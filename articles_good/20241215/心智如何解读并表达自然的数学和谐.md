几何结构的数学公式用于描述几何结构的基本属性，如面积、周长等。例如，矩形的面积公式为：

$$
面积 = 长 \times 宽
$$

矩形的周长公式为：

$$
周长 = 2 \times (长 + 宽)
$$

#### 3.2.2 周期性现象的数学公式

周期性现象的数学公式用于描述周期性现象的基本属性，如周期、振幅等。例如，正弦函数的周期公式为：

$$
周期 = \frac{2\pi}{角速度}
$$

正弦函数的振幅公式为：

$$
振幅 = \sqrt{最大值^2 - 均值^2}
$$

以下是一个简单的Python实现，用于描述季节变化的周期性：

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义参数
A = 10  # 振幅
omega = 2 * np.pi / 365  # 角速度（每年）
phi = 0  # 相位

# 计算时间
t = np.linspace(0, 365, 365)

# 计算温度
temp = A * np.sin(omega * t + phi)

# 绘制图形
plt.plot(t, temp)
plt.xlabel('时间（天）')
plt.ylabel('温度（摄氏度）')
plt.title('季节变化')
plt.show()
```
