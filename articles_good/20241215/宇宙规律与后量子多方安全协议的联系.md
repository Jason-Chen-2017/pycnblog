**例子：** 使用薛定谔方程求解一个粒子在势阱中的运动。

**步骤：**

1. **建立势阱模型**：考虑一个一维方势阱，其势能函数为：
   \[ V(x) = \begin{cases} 
   0, & \text{for } 0 < x < a \\
   \infty, & \text{otherwise} 
   \end{cases} \]

2. **写出薛定谔方程**：对于一维方势阱，薛定谔方程为：
   \[ \hat{H} \psi(x) = E \psi(x) \]
   其中，哈密顿算子 \(\hat{H}\) 和能量 E 是已知的。

3. **求解波函数**：根据薛定谔方程，波函数的形式通常为：
   \[ \psi(x) = \begin{cases} 
   A \sin\left(\frac{\pi x}{a}\right), & \text{for } 0 < x < a \\
   0, & \text{otherwise} 
   \end{cases} \]
   其中，\(A\) 是归一化常数。

4. **归一化波函数**：为了满足波函数的归一化条件，即：
   \[ \int_{-\infty}^{\infty} |\psi(x)|^2 dx = 1 \]
   我们可以确定 \(A\) 的值。

5. **结果验证**：通过计算能量本征值和波函数，我们可以验证薛定谔方程的正确性。

**例子：** 使用 BB84 协议生成共享密钥。

**步骤：**

1. **初始化量子态**：参与方 A 和 B 使用一个量子比特生成一个随机的量子态序列。例如，使用 \( |0\rangle \) 和 \( |1\rangle \) 的叠加态：
   \[ \psi_{AB} = \frac{1}{\sqrt{2}} (|00\rangle + |11\rangle) \]

2. **进行量子态传输**：参与方 A 将量子态序列通过量子信道传输给参与方 B。在这个过程中，假设信道是随机的，会引入噪声，导致部分量子态被破坏。

3. **测量量子态**：参与方 B 对接收到的量子态进行测量，测量结果有两种可能：0 或 1。假设 B 测量了 \( n \) 个量子态，得到了一个测量序列 \( (b_1, b_2, ..., b_n) \)。

4. **筛选有效密钥**：参与方 A 和 B 筛选出两者都测量的量子态，并交换对应的测量结果。例如，如果 A 和 B 都测量了第 \( i \) 个量子态，且结果相同，则保留这个量子态作为有效密钥。

5. **生成共享密钥**：将筛选出的有效密钥序列进行运算，生成最终的共享密钥。

6. **验证密钥**：参与方 A 和 B 使用共享密钥加密和解密一段信息，验证密钥的正确性和安全性。

    qvm = LocalQVM(2)  # 使用本地模拟器
    qvm.execute(q.Program(H(0), H(1)))  # 初始化量子比特

    # 信息解密
    decrypted_message = ''.join(chr(ord(c) ^ key[i % len(key)]) for i, c in enumerate(encrypted_message))
