## 数学模型和公式

### 黑洞质量分布的数学描述

在研究原初黑洞的质量分布时，我们通常采用概率密度函数（Probability Density Function, PDF）来描述不同质量黑洞的相对数量。令$f(M)$表示黑洞质量为$M$时的概率密度函数，则整个质量分布可以表示为：

$$
f(M) dM = P(M)dM
$$

其中，$P(M)$是黑洞质量为$M$的概率，$dM$是质量的无穷小变化量。概率密度函数$f(M)$的积分应该等于1，即：

$$
\int_{0}^{\infty} f(M) dM = 1
$$

### 常见的质量分布模型

在物理学中，有几种常见用于描述黑洞质量分布的模型。下面我们简要介绍两个主要的模型：幂律分布和对数正态分布。

1. **幂律分布（Power Law Distribution）**

   幂律分布是最简单的一种质量分布模型，其形式为：

   $$
   f(M) = C \cdot M^{-\alpha} \quad \text{for} \quad M > M_{\min}
   $$

   其中，$C$是归一化常数，$\alpha$是幂律指数，$M_{\min}$是最小可探测质量。这个模型假设小质量黑洞的数量随质量增加而增加，而大质量黑洞的数量随质量增加而减少。

2. **对数正态分布（Log-normal Distribution）**

   对数正态分布则假设黑洞质量的自然对数是正态分布，其形式为：

   $$
   f(M) = \frac{1}{M \sigma^2 \sqrt{2\pi}} \exp\left(-\frac{(\ln M - \mu)^2}{2\sigma^2}\right) \quad \text{for} \quad M > 0
   $$

   其中，$\mu$是质量对数的均值，$\sigma$是质量对数的标准差。这个模型假设黑洞的质量分布是随机形成的，且具有中心趋势和一定的分散度。

### 实例分析

假设我们采用幂律分布来描述原初黑洞的质量分布，且已知$\alpha = 1.3$和$M_{\min} = 10^3 M_{\odot}$。我们可以通过以下步骤计算特定质量范围内的黑洞数量：

1. **归一化常数$C$的计算**

   首先，我们需要计算归一化常数$C$，使概率密度函数的积分等于1：

   $$
   \int_{10^3 M_{\odot}}^{\infty} C \cdot M^{-1.3} dM = 1
   $$

   解这个积分，我们得到：

   $$
   C = \left(\frac{10^3 M_{\odot}}{1.3 - 1}\right)^{-1} = 10^{12} \text{ M}_{\odot}^{-0.3}
   $$

2. **特定质量范围内的黑洞数量**

   接下来，我们计算在$10^3 M_{\odot}$到$10^4 M_{\odot}$范围内的黑洞数量：

   $$
   \int_{10^3 M_{\odot}}^{10^4 M_{\odot}} 10^{12} \cdot M^{-0.3} dM
   $$

   这个积分的计算结果为：

   $$
   \frac{10^{12}}{-0.3} \left[ M^{-0.3 + 1} \right]_{10^3}^{10^4} = \frac{10^{12}}{0.7} \left( 10^{4.7} - 10^{3.7} \right) \approx 3.43 \times 10^{12} \text{ M}_{\odot}
   $$

因此，在$10^3 M_{\odot}$到$10^4 M_{\odot}$范围内，大约有$3.43 \times 10^{12}$个黑洞。

### 对数正态分布实例

如果采用对数正态分布，假设$\mu = 4.5$（单位：$\log_{10}(M_{\odot})$）和$\sigma = 0.5$，我们可以计算质量为$10^4 M_{\odot}$的概率：

$$
f(10^4 M_{\odot}) = \frac{1}{10^4 \cdot 0.5^2 \sqrt{2\pi}} \exp\left(-\frac{(4 - 4.5)^2}{2 \cdot 0.5^2}\right) \approx 1.13 \times 10^{-5}
$$

这意味着质量为$10^4 M_{\odot}$的黑洞出现的概率大约是$1.13 \times 10^{-5}$。

通过以上实例，我们可以看到如何使用数学模型和公式来描述和研究原初黑洞的质量分布。这不仅帮助我们理解黑洞的形成和演化，还为未来的观测提供了理论依据。

### Python代码实现

以下是一个简单的Python代码实现，用于计算幂律分布和对数正态分布的黑洞质量分布：

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数设置
alpha = 1.3
M_min = 10**3  # 最小质量
M_max = 10**4  # 最大质量
mu = 4.5
sigma = 0.5

# 幂律分布函数
def power_law_distribution(M_min, M_max, alpha):
    C = (M_min / (alpha - 1))**(-1)
    return C * (M_min / M)**(-alpha) for M in range(M_min, M_max+1)

# 对数正态分布函数
def log_normal_distribution(M_min, M_max, mu, sigma):
    return (1 / (M_max * sigma * np.sqrt(2 * np.pi))) * np.exp(-((np.log(M_min) - mu)**2) / (2 * sigma**2)) for M in range(M_min, M_max+1)

# 计算和绘图
def calculate_and_plot(alpha, M_min, M_max, mu, sigma):
    power_law_vals = power_law_distribution(M_min, M_max, alpha)
    log_normal_vals = log_normal_distribution(M_min, M_max, mu, sigma)
    
    plt.figure(figsize=(10, 6))
    plt.plot([10**x for x in range(int(np.log10(M_min)), int(np.log10(M_max))+1)], power_law_vals, label='Power Law')
    plt.plot([10**x for x in range(int(np.log10(M_min)), int(np.log10(M_max))+1)], log_normal_vals, label='Log Normal')
    plt.yscale('log')
    plt.xlabel('Mass (M$_{\odot}$)')
    plt.ylabel('Number Density')
    plt.legend()
    plt.title('Primordial Black Hole Mass Distribution')
    plt.grid()
    plt.show()

calculate_and_plot(alpha, M_min, M_max, mu, sigma)
```

2. **幂律分布计算**：`power_law_distribution`函数根据幂律分布的公式计算质量范围内的黑洞数量。我们通过计算每个质量点的概率密度，并将其累加得到总数量。

3. **对数正态分布计算**：`log_normal_distribution`函数使用对数正态分布的公式计算每个质量点的概率密度。我们同样通过累加每个质量点的概率密度，得到总数量。

4. **结果输出**：`calculate_and_plot`函数将计算结果以对数刻度绘图，直观展示不同质量范围内黑洞的数量。

import numpy as np

def power_law_distribution(M_min, M_max, alpha):
    C = (M_min / (alpha - 1))**(-1)
    return C * (M_min / M)**(-alpha) for M in range(M_min, M_max+1)
