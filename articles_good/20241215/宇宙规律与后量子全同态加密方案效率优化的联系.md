量子纠缠的基本原理可以通过以下数学公式描述：

\[ \Psi_{AB} = \alpha |0\rangle_A |0\rangle_B + \beta |1\rangle_A |1\rangle_B \]

其中，\(|0\rangle_A\) 和 \(|1\rangle_A\) 分别表示粒子A的量子态，\(|0\rangle_B\) 和 \(|1\rangle_B\) 分别表示粒子B的量子态，\(\alpha\) 和 \(\beta\) 是复数系数。

量子纠缠在加密中的应用主要体现在量子密钥分发（Quantum Key Distribution，简称QKD）中。QKD是一种基于量子力学原理的安全通信技术，可以确保通信双方秘密地交换密钥，同时检测到任何窃听行为。
