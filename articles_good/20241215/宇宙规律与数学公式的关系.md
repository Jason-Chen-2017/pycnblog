```python
# 导入相关库
import numpy as np

# 建立宇宙膨胀的数学模型
def expanduniverse(t):
    a0 = 1  # 初始宇宙半径
    H0 = 0.05  # 宇宙膨胀率
    return a0 * (1 + H0 * t)

# 使用数学公式预测宇宙膨胀
t = np.linspace(0, 10, 1000)  # 时间区间为0到10
r = expanduniverse(t)

# 绘图显示宇宙膨胀
import matplotlib.pyplot as plt
plt.plot(t, r)
plt.xlabel('Time (Gy)')
plt.ylabel('Universe Radius (Gpc)')
plt.title('Universe Expansion')
plt.show()
```

**算法原理的数学模型和公式**

- **宇宙膨胀模型**：\[ r(t) = a(t) \times r_0 \]
  - 其中，\( r(t) \) 是宇宙在时间 \( t \) 的半径，\( a(t) \) 是宇宙膨胀因子，\( r_0 \) 是初始半径。

- **哈勃定律**：\[ v = H_0 \times d \]
  - 其中，\( v \) 是星系的退行速度，\( H_0 \) 是哈勃常数，\( d \) 是星系的距离。
