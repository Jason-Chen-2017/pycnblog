### 第一部分：价值投资的起源与核心原理

#### 第1章：价值投资的历史与格雷厄姆的影响

**背景介绍：**
价值投资作为一种投资理念，起源于20世纪初，由美国著名投资家本杰明·格雷厄姆（Benjamin Graham）创立。格雷厄姆被誉为“现代投资之父”，其思想对后世产生了深远的影响。

**核心概念术语说明：**
- **价值投资（Value Investing）：** 一种投资理念，主张购买价格低于其内在价值的股票，长期持有，以期获得资本增值。
- **内在价值（Intrinsic Value）：** 股票的真正价值，通常通过财务分析计算得出。

**问题背景：**
在股票市场中，股票的价格往往受到市场情绪、宏观经济因素等影响，可能会偏离其内在价值。格雷厄姆认为，通过深入分析公司的财务状况和行业前景，可以找到那些被市场低估的股票。

**问题描述：**
如何通过格雷厄姆的价值投资公式，寻找被低估的股票，并在长期持有中获得收益？

**问题解决：**
格雷厄姆提出了一个价值投资的公式，通过计算公司的账面价值、股息收益率和市场价格等指标，来判断股票是否被低估。

**边界与外延：**
- **边界：** 公式主要适用于基本面分析，不涉及技术分析和市场趋势。
- **外延：** 格雷厄姆的价值投资理念可以应用于不同的市场环境和行业，但其核心原则不变。

**概念结构与核心要素组成：**
- **概念结构：** 价值投资的核心是寻找价格低于内在价值的股票。
- **核心要素：** 账面价值、股息收益率、市场价格等指标。

#### 第2章：格雷厄姆价值投资公式的基本概念

**核心概念与联系：**

**核心概念原理：**
格雷厄姆价值投资公式的基本概念包括：

- **账面价值（Book Value）：** 公司的净资产，即公司资产减去负债后的价值。
- **股息收益率（Dividend Yield）：** 股票每年派发的股息与股票当前价格的比率。
- **市场价格（Market Price）：** 股票在市场上的交易价格。

**概念属性特征对比表格：**

| 指标名称 | 定义 | 属性特征 | 对比分析 |
| --- | --- | --- | --- |
| 账面价值 | 净资产 | 客观、稳定 | 与市场价格可能存在差异 |
| 股息收益率 | 股息与股票价格比率 | 反映分红能力 | 与市场利率相关 |
| 市场价格 | 交易价格 | 受市场情绪影响 | 可能高于或低于内在价值 |

```python
def is_stock_underpriced(book_value, dividend_yield, market_price):
    """
    判断股票是否被低估的函数。
    
    参数:
    - book_value: 账面价值
    - dividend_yield: 股息收益率
    - market_price: 市场价格
    
    返回:
    - True: 如果股票被低估
    - False: 如果股票未被低估
    """
    intrinsic_value = book_value * dividend_yield / market_price
    return intrinsic_value > market_price
```

**数学模型和数学公式 & 详细讲解 & 举例说明：**

**数学模型：**
格雷厄姆的价值投资公式可以表示为：

$$ \text{Intrinsic Value} = \frac{\text{Book Value} \times \text{Dividend Yield}}{\text{Market Price}} $$

**详细讲解：**
- **Book Value（账面价值）：** 账面价值是指公司资产负债表上的净资产，反映了公司的实际资产价值。
- **Dividend Yield（股息收益率）：** 股息收益率是股票每年派发的股息与股票当前价格的比率，反映了公司的分红能力。
- **Market Price（市场价格）：** 市场价格是股票在市场上的交易价格，通常受市场情绪、公司业绩等因素影响。

通过计算账面价值、股息收益率和市场价格的比值，我们可以得到股票的内在价值。如果内在价值高于市场价格，则股票可能被低估。

**举例说明：**
假设某股票的账面价值为10元，股息收益率为5%，市场价格为20元。根据格雷厄姆的价值投资公式，我们可以计算股票的内在价值如下：

$$ \text{Intrinsic Value} = \frac{10 \times 0.05}{20} = 0.25 $$

由于内在价值0.25元低于市场价格20元，因此股票可能被低估。

```python
import numpy as np

def calculate_book_value(assets, liabilities):
    """
    计算账面价值。
    
    参数:
    - assets: 资产
    - liabilities: 负债
    
    返回:
    - 账面价值
    """
    return assets - liabilities

def calculate_dividend_yield(dividends, market_price):
    """
    计算股息收益率。
    
    参数:
    - dividends: 股息
    - market_price: 市场价格
    
    返回:
    - 股息收益率
    """
    return dividends / market_price

def calculate_intrinsic_value(book_value, dividend_yield, market_price):
    """
    计算内在价值。
    
    参数:
    - book_value: 账面价值
    - dividend_yield: 股息收益率
    - market_price: 市场价格
    
    返回:
    - 内在价值
    """
    return book_value * dividend_yield / market_price

# 示例数据
assets = 1000000
liabilities = 500000
dividends = 100000
market_price = 2000000

# 计算账面价值
book_value = calculate_book_value(assets, liabilities)
print(f"账面价值: {book_value}")

# 计算股息收益率
dividend_yield = calculate_dividend_yield(dividends, market_price)
print(f"股息收益率: {dividend_yield}")

# 计算内在价值
intrinsic_value = calculate_intrinsic_value(book_value, dividend_yield, market_price)
print(f"内在价值: {intrinsic_value}")
```

**实际案例分析和详细讲解剖析：**
假设我们有一家公司的资产为1000万元，负债为500万元，每年派发股息100万元，股票市场价格为2000万元。根据以上代码，我们可以计算出：

- 账面价值：1000万元 - 500万元 = 500万元
- 股息收益率：100万元 / 2000万元 = 5%
- 内在价值：500万元 * 5% / 2000万元 = 0.125万元

```python
    """
```

```python
import numpy as np
import pandas as pd
from tensorflow import keras

def train_ai_model(data, labels):
    """
    训练人工智能模型。
    
    参数:
    - data: 训练数据
    - labels: 训练标签
    
    返回:
    - 训练好的模型
    """
    model = keras.Sequential([
        keras.layers.Dense(64, activation='relu', input_shape=(data.shape[1],)),
        keras.layers.Dense(1)
    ])

    model.compile(optimizer='adam', loss='mean_squared_error')
    model.fit(data, labels, epochs=10, batch_size=32)
    return model

def predict_stock_value(model, stock_data):
    """
    预测股票价值。
    
    参数:
    - model: 训练好的模型
    - stock_data: 股票数据
    
    返回:
    - 预测的股票价值
    """
    return model.predict(stock_data.reshape(1, -1))[0][0]

# 假设数据
data = np.random.rand(100, 5)
labels = np.random.rand(100, 1)

# 训练模型
model = train_ai_model(data, labels)

# 预测股票价值
predicted_value = predict_stock_value(model, data[:1])
print(f"预测的股票价值：{predicted_value}")
```

**代码应用解读与分析：**
以上代码实现了两个核心函数：`train_ai_model`和`predict_stock_value`。`train_ai_model`函数用于训练人工智能模型，`predict_stock_value`函数用于预测股票价值。通过输入训练数据和预测数据，可以训练模型并预测股票价值。
