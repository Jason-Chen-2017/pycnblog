**4.1 数学模型概述**

投资成本控制的数学模型主要包括成本结构分析模型、成本效益分析模型和风险管理模型。成本结构分析模型用于量化投资成本的不同组成部分。成本效益分析模型用于评估投资成本与投资回报之间的关系。风险管理模型则用于识别和管理投资风险。

**4.2 数学公式**

以下是一些常见的数学公式：

- 成本结构分析：\( C = C_d + C_i + C_o \)
- 成本效益分析：\( R = \frac{C}{I} \)
- 风险管理：\( \sigma = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (X_i - \mu)^2} \)

- 成本结构分析：\( C = C_d + C_i + C_o = 10000 + 25000 + 7500 = 40000 \)
- 成本效益分析：\( R = \frac{C}{I} = \frac{40000}{50000} = 0.8 \)
- 风险管理：\( \sigma = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (X_i - \mu)^2} \)

其中，\( C_d \)为直接成本，\( C_i \)为间接成本，\( C_o \)为机会成本；\( I \)为投资回报率，\( \mu \)为预期收益，\( X_i \)为实际收益。
