### 附录：算法原理讲解

在本章节中，我们将使用Python代码和Mermaid流程图，详细阐述一个简单的数学问题求解算法原理。假设我们需要解决以下问题：

**问题**：给定一个整数数组，找出数组中的最大值和最小值。

**算法原理**：

1. 初始化最大值和最小值为数组的第一个元素。
2. 遍历数组中的每个元素，将当前元素与最大值和最小值进行比较，更新最大值和最小值。
3. 遍历完成后，输出最大值和最小值。

**Python代码**：

```python
def find_max_min(arr):
    if len(arr) == 0:
        return None, None
    
    max_val = arr[0]
    min_val = arr[0]
    
    for num in arr:
        if num > max_val:
            max_val = num
        elif num < min_val:
            min_val = num
            
    return max_val, min_val

# 示例
arr = [3, 1, 4, 1, 5, 9, 2, 6, 5]
max_val, min_val = find_max_min(arr)
print("最大值：", max_val)
print("最小值：", min_val)
```

**Mermaid流程图**：

```mermaid

    A[开始] --> B[初始化最大值和最小值为数组的第一个元素]
    B --> C{遍历数组中的每个元素}
    C -->|更新最大值和最小值| D[输出最大值和最小值]
    D --> E[结束]
```

**算法原理讲解**：

1. **初始化最大值和最小值为数组的第一个元素**：首先，我们将最大值和最小值初始化为数组的第一个元素，因为第一个元素是整个数组的基准。

2. **遍历数组中的每个元素**：接下来，我们遍历数组中的每个元素，与当前的最大值和最小值进行比较。

3. **更新最大值和最小值**：如果当前元素比最大值大，则更新最大值为当前元素；如果当前元素比最小值小，则更新最小值为当前元素。

4. **输出最大值和最小值**：遍历完成后，我们输出最大值和最小值。

通过上述算法原理和Python代码的讲解，读者可以更好地理解如何使用简单的算法解决实际问题。

    @Autowired

    @PostMapping("/register")
    public ResponseEntity<?> registerUser(@RequestBody User user) {
        if (userRepository.findByUsername(user.getUsername()).isPresent()) {
            return ResponseEntity.badRequest().body("Error: Username is already taken!");
        }

        userRepository.save(user);
        return ResponseEntity.ok("User registered successfully!");
    }

    @PostMapping("/login")
    public ResponseEntity<?> loginUser(@RequestBody LoginRequest loginRequest) {
        User user = userRepository.findByUsername(loginRequest.getUsername()).orElseThrow(() -> new RuntimeException("User not found!"));
        
        if (!user.getPassword().equals(loginRequest.getPassword())) {
            return ResponseEntity.badRequest().body("Error: Incorrect password!");
        }

        return ResponseEntity.ok("User logged in successfully!");
    }

    @PutMapping("/update")
    public ResponseEntity<?> updateUser(@RequestBody User user) {
        userRepository.save(user);
        return ResponseEntity.ok("User information updated successfully!");
    }
}

### 附录：算法原理讲解

在本章节中，我们将使用Python代码和Mermaid流程图，详细阐述一个简单的数学问题求解算法原理。假设我们需要解决以下问题：

**问题**：给定一个整数数组，找出数组中的最大值和最小值。

**算法原理**：

1. 初始化最大值和最小值为数组的第一个元素。
2. 遍历数组中的每个元素，将当前元素与最大值和最小值进行比较，更新最大值和最小值。
3. 遍历完成后，输出最大值和最小值。

**Python代码**：

```python
def find_max_min(arr):
    if len(arr) == 0:
        return None, None
    
    max_val = arr[0]
    min_val = arr[0]
    
    for num in arr:
        if num > max_val:
            max_val = num
        elif num < min_val:
            min_val = num
            
    return max_val, min_val

# 示例
arr = [3, 1, 4, 1, 5, 9, 2, 6, 5]
max_val, min_val = find_max_min(arr)
print("最大值：", max_val)
print("最小值：", min_val)
```

**Mermaid流程图**：

```mermaid

    A[开始] --> B[初始化最大值和最小值为数组的第一个元素]
    B --> C{遍历数组中的每个元素}
    C -->|更新最大值和最小值| D[输出最大值和最小值]
    D --> E[结束]
```

**算法原理讲解**：

1. **初始化最大值和最小值为数组的第一个元素**：首先，我们将最大值和最小值初始化为数组的第一个元素，因为第一个元素是整个数组的基准。

2. **遍历数组中的每个元素**：接下来，我们遍历数组中的每个元素，与当前的最大值和最小值进行比较。

3. **更新最大值和最小值**：如果当前元素比最大值大，则更新最大值为当前元素；如果当前元素比最小值小，则更新最小值为当前元素。

4. **输出最大值和最小值**：遍历完成后，我们输出最大值和最小值。

### 附录：算法原理讲解

在本章节中，我们将使用Python代码和Mermaid流程图，详细阐述一个简单的数学问题求解算法原理。假设我们需要解决以下问题：

**问题**：给定一个整数数组，找出数组中的最大值和最小值。

**算法原理**：

1. 初始化最大值和最小值为数组的第一个元素。
2. 遍历数组中的每个元素，将当前元素与最大值和最小值进行比较，更新最大值和最小值。
3. 遍历完成后，输出最大值和最小值。

**Python代码**：

```python
def find_max_min(arr):
    if len(arr) == 0:
        return None, None
    
    max_val = arr[0]
    min_val = arr[0]
    
    for num in arr:
        if num > max_val:
            max_val = num
        elif num < min_val:
            min_val = num
            
    return max_val, min_val

# 示例
arr = [3, 1, 4, 1, 5, 9, 2, 6, 5]
max_val, min_val = find_max_min(arr)
print("最大值：", max_val)
print("最小值：", min_val)
```

```mermaid

    C -->|更新最大值和最小值| D[输出最大值和最小值]
    D --> E[结束]
```

**算法原理讲解**：

1. **初始化最大值和最小值为数组的第一个元素**：首先，我们将最大值和最小值初始化为数组的第一个元素，因为第一个元素是整个数组的基准。

2. **遍历数组中的每个元素**：接下来，我们遍历数组中的每个元素，与当前的最大值和最小值进行比较。

3. **更新最大值和最小值**：如果当前元素比最大值大，则更新最大值为当前元素；如果当前元素比最小值小，则更新最小值为当前元素。

4. **输出最大值和最小值**：遍历完成后，我们输出最大值和最小值。

通过上述算法原理和Python代码的讲解，读者可以更好地理解如何使用简单的算法解决实际问题。
