**K-means聚类算法实现：**
```python
import numpy as np

def kmeans(data, k, max_iter=100):
    # 初始化聚类中心
    centroids = data[np.random.choice(data.shape[0], k, replace=False)]
    for _ in range(max_iter):
        # 计算每个样本与聚类中心的距离
        distances = np.linalg.norm(data[:, None] - centroids, axis=2)
        # 分配样本到最近的聚类中心
        labels = np.argmin(distances, axis=1)
        # 计算新的聚类中心
        new_centroids = np.array([data[labels == i].mean(axis=0) for i in range(k)])
        # 判断聚类中心是否收敛
        if np.linalg.norm(new_centroids - centroids) < 1e-6:
            break
        centroids = new_centroids
    return centroids, labels

# 示例数据
data = np.array([[1, 2], [1, 4], [1, 0], [4, 2], [4, 4], [4, 0]])
k = 2
centroids, labels = kmeans(data, k)
print("聚类中心：", centroids)
print("样本标签：", labels)
```

        for feature in range(len(data) - 1):
            feature_prob[data[-1]][feature] += 1
    
    for key in feature_prob.keys():
        for feature in feature_prob[key].keys():
            feature_prob[key][feature] /= num_samples
    
    # 预测类别
    predictions = []
    for data in test_data:
        probabilities = {}
        for class_ in class_prob.keys():
            probability = log(class_prob[class_])
            for feature in range(len(data) - 1):
                probability += log(feature_prob[class_][feature] if data[feature] > 0 else 1 / feature_prob[class_][feature])
            probabilities[class_] = probability
        predictions.append(max(probabilities, key=probabilities.get))
    
    return predictions

test_data = [[1, 3], [4, 1]]

print("预测结果：", predictions)

**神经网络算法实现：**
```python
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split

# 生成Moons数据集
X, y = make_moons(n_samples=100, noise=0.1, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 初始化参数
input_size = X_train.shape[1]
hidden_size = 5
output_size = 1
learning_rate = 0.1
epochs = 1000

# 初始化权重
weights_input_hidden = np.random.randn(input_size, hidden_size)
weights_hidden_output = np.random.randn(hidden_size, output_size)

# 激活函数
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 前向传播
def forward_pass(x):
    hidden_layer = sigmoid(np.dot(x, weights_input_hidden))
    output = sigmoid(np.dot(hidden_layer, weights_hidden_output))
    return output

# 反向传播
def backward_pass(x, y, output):
    output_error = y - output
    output_delta = output_error * output * (1 - output)
    
    hidden_error = np.dot(output_delta, weights_hidden_output.T)
    hidden_delta = hidden_error * hidden_layer * (1 - hidden_layer)
    
    # 更新权重
    weights_hidden_output -= learning_rate * np.dot(hidden_layer.T, output_delta)
    weights_input_hidden -= learning_rate * np.dot(x.T, hidden_delta)

# 训练模型
for epoch in range(epochs):
    output = forward_pass(X_train)
    backward_pass(X_train, y_train, output)
    
    if epoch % 100 == 0:
        train_loss = np.mean((output - y_train) ** 2)
        test_loss = np.mean((forward_pass(X_test) - y_test) ** 2)
        print(f"Epoch {epoch}: Train Loss: {train_loss:.4f}, Test Loss: {test_loss:.4f}")

# 预测测试集
y_pred = forward_pass(X_test)
print("预测结果：", y_pred)
```

#### 3.4 数学模型和公式

**K-means聚类算法**

- **目标函数**：最小化聚类中心到样本的距离平方和。

  $$ J = \sum_{i=1}^{n}\sum_{j=1}^{k} d(x_i, \mu_j)^2 $$

  其中，\( x_i \) 是第 \( i \) 个样本，\( \mu_j \) 是第 \( j \) 个聚类中心，\( d \) 是距离函数。

- **更新聚类中心**：

  $$ \mu_j = \frac{1}{N_j} \sum_{i=1}^{n} x_i $$

  其中，\( N_j \) 是属于第 \( j \) 个聚类中心的样本数量。

**朴素贝叶斯分类算法**

- **先验概率**：

  $$ P(y) = \frac{1}{N} $$

  其中，\( y \) 是类别，\( N \) 是样本总数。

- **条件概率**：

  $$ P(x|y) = \frac{P(y) \cdot P(x|y)}{P(y)} $$

  其中，\( x \) 是特征。

- **后验概率**：

  $$ P(y|x) = \frac{P(x|y) \cdot P(y)}{P(x)} $$

- **分类决策**：

  $$ \hat{y} = \arg \max_y P(y|x) $$

**决策树算法**

- **信息增益**：

  $$ IG(D, A) = H(D) - \sum_{v \in A} p(v) \cdot H(D|v) $$

  其中，\( D \) 是数据集，\( A \) 是特征集合，\( p(v) \) 是特征 \( v \) 的概率，\( H \) 是熵函数。

- **划分条件**：

  $$ G(D, A) = \sum_{v \in A} p(v) \cdot IG(D_v, A \setminus \{v\}) $$

  其中，\( D_v \) 是根据特征 \( v \) 划分后的数据集。

- **决策树构建**：

  选择最优特征 \( A^* \)，使得 \( G(D, A) \) 最大，递归构建子树。

**神经网络算法**

- **激活函数**：

  $$ a(x) = \frac{1}{1 + e^{-x}} $$

- **前向传播**：

  $$ z = X \cdot W + b $$
  $$ a(z) = \sigma(z) $$

  其中，\( X \) 是输入，\( W \) 是权重，\( b \) 是偏置，\( \sigma \) 是激活函数。

- **反向传播**：

  $$ \delta = (y - \hat{y}) \cdot \sigma'(z) $$
  $$ \delta_W = X^T \cdot \delta $$
  $$ \delta_b = \delta $$

  其中，\( \hat{y} \) 是预测值，\( y \) 是真实值，\( \sigma' \) 是激活函数的导数。

- **权重更新**：

  $$ W := W - \alpha \cdot \delta_W $$
  $$ b := b - \alpha \cdot \delta_b $$
